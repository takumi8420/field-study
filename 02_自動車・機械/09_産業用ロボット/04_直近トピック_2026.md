# 直近トピック（2026年9月時点）

報道・統計ベースの整理。**数値は公表時点のものであり、確定値ではないものを含む**。
一次情報（IR・業界団体・官公庁）で必ず裏取りすること。出典は末尾にまとめた。

このノートは**産業用ロボット（FA）の市場・企業・政策**に絞る。
ヒューマノイド／サービスロボット／AI基盤モデルの直近動向は
[ロボット（注目テーマ）の直近トピック](../../01_注目テーマ/09_ロボット/05_直近トピック_2026.md) を参照。

## 1. 国内メーカーの受注が過去最高を更新中（半導体投資が牽引）

日本ロボット工業会（JARA、会員ベース）の四半期統計は、**3四半期連続で受注額・生産額の過去最高を更新**している。

| 項目（2026年4〜6月期） | 実績 | 前年同期比 |
| --- | --- | --- |
| 受注 | 57,695台／**3,127億円** | 台数＋19.3%／金額**＋40.0%** |
| 生産 | 51,437台／2,520億円 | 台数＋11.4%／金額＋24.3% |
| 出荷（合計） | 2,577億円 | ＋24.1% |
| うち国内出荷 | **383億円** | ＋3.7% |
| うち輸出 | **2,194億円** | ＋28.5% |

JARAは2026年の年間見通しとして**受注額1兆2,200億円（前年比＋16.7%）、生産額1兆500億円（＋11.1%）**を示した
（2026年5月29日発表）。1月時点の見通しから1,900億円の上方修正で、**2022年以来4年ぶりの過去最高更新**の見込みと報じられる。

```
   何が伸びているのか（2026年）

   AI向けデータセンター需要
        ↓
   半導体メーカーの設備投資が拡大
        ↓
   前工程・後工程の搬送・検査ロボット、クリーン対応スカラが大量に必要
        ↓
   日本メーカーの受注が過去最高   ← 今ここ
        ↑
   ※ 国内出荷は＋3.7%と横ばい圏。伸びているのは「輸出」である
```

> 読み方の注意：**受注の伸びと国内の自動化は別の話**。
> 出荷の85%は輸出で、国内向けは15%にすぎない（2026年4〜6月期）。
> 「日本のロボット業界が絶好調＝日本の工場の自動化が進んだ」ではない。

## 2. 中国：市場の半分を占め、国産化が進む

世界の年間設置台数の**54%が中国**（2024年、IFR World Robotics 2025）。
そこで国産メーカーの比率が上がり続けている。

| 事象 | 内容 | 時点・性格 |
| --- | --- | --- |
| Estun（埃斯頓）が販売台数首位 | 中国市場シェア10.6%で1位 | 2025年、報道ベース |
| 6四半期連続で出荷台数1位 | **外資を含む全ブランド中**で1位（国産ブランドとしては8年連続） | 2026年上期、報道ベース |
| 国産化率の上昇 | 2017年24.2% → 2022年35.0%。中低付加価値領域では40%超 | 各種調査・推計 |
| Estunの香港重複上場 | 資金調達とヒューマノイドへの展開が報じられる | 2026年、報道ベース |
| 制御装置の国産化 | ロボットコントローラでも中国企業が輸入依存から脱却しつつあると報じられる | 2026年、報道ベース |

一方で、**日本勢が中国から追い出されているわけではない**。
ファナックは2026年3月期に中国のEV関連・一般産業向けが牽引して二桁増収、
第2四半期の中国向けロボット売上は前年同期比87%増と報じられた。
構図は「**低〜中付加価値は国産、高付加価値はまだ外資**」という二層化である。

## 3. 企業業績の明暗：ファナックと安川電機が分かれた

同じ市場にいながら、直近の業績は大きく割れている。

| 企業 | 直近実績 | 要因 |
| --- | --- | --- |
| **ファナック** | 2026年3月期：営業利益率19.9%→**21.4%**、純利益1,665億円（＋12.9%）、500億円の自社株買いを発表 | 中国のEV・一般産業向けロボットが牽引。CNCとの両輪 |
| ファナック（次期） | 2027年3月期はロボット好調で**11%増益**の見通しと報じられる | 半導体・中国需要の継続 |
| **安川電機** | 2026年2月期：売上収益5,421億円（＋0.8%）。ロボット2,470億円（47%）、モーションコントロール2,361億円（45%） | 増収だが利益は伸びず |
| 安川電機（直近四半期） | 2027年2月期第1四半期（2026年3〜5月）は**受注＋29%の一方、ロボットの営業利益は大幅減** | 基幹システム移行に伴う生産影響と欧州の事業構造改革費用。**需要が崩れたわけではない**と説明されている |

```
   両社の分かれ目（2026年）

           地域構成            製品構成            一時要因
   ファナック  中国EV・一般産業が厚い  CNC＋ロボット      ─
   安川電機   欧州の比率が相対的に高い ロボット＋モーション  基幹システム移行
                                     コントロール        欧州の構造改革費用
              ↓                      ↓                  ↓
           中国が効いた           半導体向けが効いた     利益を一時的に圧迫
```

> 示唆：産業用ロボット企業の業績は**「どの地域に、どの用途で売っているか」で決まる**。
> 本体の技術力の差ではない。ここを混同すると株価や決算の読み違いになる。

## 4. 政策：「フィジカルAI」が国家戦略の最重点に入った

2026年に入り、日本のロボット政策の主語が**「ロボット」から「フィジカルAI（現実世界で行動するAI）」**に置き換わった。

| 動き | 内容 | 時点 |
| --- | --- | --- |
| 半導体・デジタル産業戦略の改定 | 経済産業省がフィジカルAIを**最重点分野**に位置づけ | 2026年6月 |
| 官民投資ロードマップ（戦略17分野） | フィジカルAI（特にAIロボット）に**2040年度までに官民合計10.5兆円**の投資、経済波及効果144.4兆円を想定 | 2026年6月24日 合同会議で提示、7月21日に資料公表 |
| 市場目標 | AIロボット市場は2030年頃から急拡大し**2040年に約60兆円**規模。日本は**世界シェア3割超・20兆円**の獲得を目標 | 同上（政府の想定・目標値であり実績ではない） |
| 主要プレイヤーの名指し | 精密減速機でナブテスコとハーモニック・ドライブ・システムズが位置づけられていると報じられる | 2026年 |

> 注意：**10.5兆円も60兆円も「目標・想定」であって統計値ではない**。
> 政策文書の数字は、予算配分の根拠として作られる性質があるため、
> 実績（IFRやJARAの統計）と同じ扱いをしないこと。

なお中小企業向けの実務的な導入支援（省力化投資補助金のカタログ注文型、ものづくり補助金、
ロボットフレンドリー施策）は継続しており、制度の詳細は
[なぜロボットは普及しないのか](../../01_注目テーマ/09_ロボット/02_なぜロボットは普及しないのか.md) にまとめた。

## 5. 部品：減速機メーカーが半導体と医療で回復

産業用ロボットの関節を握る精密減速機メーカーは、ロボット本体より**遅れて・振れ幅を大きく**動く。
2026年は回復局面にある。

| 企業 | 直近の数値 | 中身 |
| --- | --- | --- |
| ハーモニック・ドライブ・システムズ | 2026年3月期 売上596億円。2027年3月期第1四半期は売上167億円（前年同期比＋23.6%）、**受注高＋55.7%** | 半導体製造装置向けの設備投資、北米の手術支援ロボット向けが牽引 |
| ハーモニック（中計） | 2026年度を初年度とする新中期経営計画で、**AIロボット・航空宇宙防衛・eモビリティ**を重点開拓分野に | 2026年5月13日 取締役会決議 |
| ナブテスコ | RV減速機で産業用ロボット関節向け世界シェア約6割とされる。ヒューマノイド向けの設備投資を計画と報じられる | 各種業界推計・報道 |

ヒューマノイド1台は20〜40関節を持ち、6軸の産業用アームの数倍の減速機を消費する。
減速機メーカーがヒューマノイドに期待を寄せるのはこのためだが、
**人型が本当に量産される保証はまだない**点は据え置きで読む必要がある
（詳細は [AIとロボットの結合](../../01_注目テーマ/09_ロボット/03_AIとロボットの結合.md)）。

## 6. 外部環境：米国の関税と、統計の更新タイミング

- **米国の半導体関連関税**：2026年1月14日の布告により、2026年1月15日から特定の高性能コンピュータチップ
  および指定派生製品に25%の従価税が適用された（米通商拡大法232条に基づく）。
  産業用ロボットそのものへの直接の関税ではないが、**顧客である半導体・電子業界の設備投資判断に影響する**
- **IFR World Robotics 2026 は2026年9月24日に公表予定**とされる。
  本ノートの世界統計は World Robotics 2025（2024年実績）に基づくため、**公表後に更新が必要**

## 7. 全体の構図

1. **需要は強いが、それは日本国内の話ではない**。出荷の85%は輸出で、伸ばしているのはAI関連の半導体設備投資。
   国内出荷は＋3.7%と横ばい圏にとどまる（2026年4〜6月期、JARA会員ベース）
2. **市場の半分は中国**で、そこでは国産化が着実に進んでいる。低〜中価格帯は国産へ移り、
   日本勢は高付加価値用途とサービス・保守で守る形になっている
3. **業績の差を決めているのは地域構成と用途構成**であって、本体の技術差ではない。
   同じ市場でファナックと安川電機が逆方向に振れたのがその証拠
4. **政策は「フィジカルAI」に張り替わった**。ただし10.5兆円・60兆円といった数字は目標値であり、統計とは分けて読む
5. **国内の詰まりは変わっていない**。SIer不足と中小企業の採算という構造問題は、
   受注統計が過去最高を更新しても改善しない別の問題である → [システムインテグレーション](02_システムインテグレーション.md)

## 用語メモ

- **World Robotics**：IFRが毎年公表する世界統計。産業用とサービスの2分冊。2026年版は2026年9月24日公表予定
- **JARA会員ベース**：日本ロボット工業会の正会員・賛助法人会員の合計値。国内全生産ではない点に注意
- **受注額／生産額／出荷額**：受注は将来の売上、生産は作った額、出荷は出した額。景気の先行指標は受注
- **フィジカルAI**：カメラ・センサ情報から現実世界を理解し、物理的な行動を生成するAI。2026年の政策キーワード
- **官民投資ロードマップ**：政府が戦略分野ごとに官民の投資額と経済効果の見通しを示す文書。**目標値であり実績ではない**
- **通商拡大法232条**：米国が安全保障を理由に輸入制限・関税を課す根拠法。半導体分野で適用された
- **国産化率**：ある国の市場で自国メーカーが占める比率。中国ロボット市場の中心指標
