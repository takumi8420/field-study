# ロボットの種類と用途

**このノートで分かること**：工場で使われるロボットが「形（機構）」でどう分かれ、
**可搬重量とリーチという2つの数字**でどう選ばれるか。溶接・塗装・組立・搬送という用途ごとに
何が違うか。そして主要4社（ファナック・安川電機・ABB・KUKA）がどこで棲み分けているか。

結論を先に書く。**産業用ロボットは「何でもできる汎用機」ではなく、用途ごとに形がほぼ決まっている機械**である。
カタログの先頭に必ず可搬重量とリーチが載っているのは、**この2つでほとんど機種が絞り込めてしまう**から。
逆に言えば、この2つを外すと他の性能が良くても現場では使えない。

ロボット全般の定義・5層構造（機構／アクチュエータ／センサ／制御／ソフト）・減速機の技術的中身は
[ロボットの分類と構成要素](../../01_注目テーマ/09_ロボット/01_ロボットの分類と構成要素.md) に書いた。
ここでは**工場の中（FA＝ファクトリーオートメーション）で実際に何が使われているか**に絞る。

## 1. 形で分ける：5つの機構形式

産業用ロボットは、関節の並べ方でほぼ5種類に分類される。
「どの軸がどう動くか」が、そのまま得意な仕事を決めている。

```
 ① 垂直多関節（6軸）      ② スカラ（4軸）        ③ 直交（ガントリ）
      ＿                        ┌──┐                ┌──────────┐
     /  \ 手首3軸               │  └──┐              │ ↔ 横行     │
    │    │                     └─┐   │↕             │  ↕ 昇降    │
    │    │ 肘                    水平旋回2軸          └──┬───────┘
   ┌┴────┴┐ 肩                    ＋上下＋回転              ↓
   │  旋回  │                                          つかむ
   └───────┘ ベース

 ④ パラレル（デルタ）         ⑤ 協働ロボット（コボット）
   ┌═══════════┐ 天吊り           ＿
    \   |   /                    /  \  柵なしで人の隣
     \  |  /  3本の腕で          │    │ 力・速度を制限
      \ | /   1点を動かす        │    │ 見た目は①と同じ6軸
       ＼|／                    ┌┴────┴┐
        ●  超高速                └───────┘
```

| 形式 | 軸数の目安 | 動きの特徴 | 得意な仕事 | 弱点 |
| --- | --- | --- | --- | --- |
| **垂直多関節** | 6軸（7軸もある） | 人の腕に近い。あらゆる姿勢を取れる | 溶接、塗装、組立、搬送。**出荷の主力** | 剛性が落ちるため超高精度は苦手 |
| **スカラ** | 4軸 | 水平方向だけ柔軟、上下は真っ直ぐ | 電子部品の挿入、ねじ締め、小物組立 | 横からの作業ができない |
| **直交（ガントリ）** | 3〜4軸 | XYZの直線移動のみ。門型 | 大型ワークの搬送、大面積の加工 | 場所を取る。姿勢を変えられない |
| **パラレル（デルタ）** | 3〜4軸 | 天井から3本の腕。軽くて超高速 | 食品・医薬品の高速ピッキング（毎分100個超） | 可搬重量が小さい（数kg） |
| **協働ロボット** | 6軸 | 垂直多関節だが出力・速度を制限 | 人の隣での組立補助、検査、小ロット | 遅い。タクトタイムが出ない |

> ポイント：**軸数は多いほど偉いのではない**。パレタイジング（箱積み）では
> 箱を水平に保ったまま運べればよいので、6軸ではなく**4軸のほうが速くて安い**。
> 「必要な自由度だけ持つ」のが正解である。

## 2. カタログの読み方：可搬重量とリーチ

機種選定は、次の2つの数字から始まる。

```
   可搬重量（ペイロード）
      ↑
  500kg┤ ■ 自動車ボディ搬送・大型スポット溶接
      │
  200kg┤   ■ パレタイジング（重量物）
      │
   50kg┤     ■ 汎用ハンドリング・組立
      │
   20kg┤       ■ アーク溶接・中型組立
      │
    6kg┤  ● パラレル  ■ 塗装・小物組立・協働
      │
    3kg┤ ● スカラ
      └────┬─────┬─────┬─────┬─────→ リーチ（mm）
          500   900   1,500  2,500  3,500
```

| 用語 | 意味 | つまずきやすい点 |
| --- | --- | --- |
| **可搬重量（ペイロード）** | 手先に持てる最大重量 | **ハンド（つかむ道具）の重量を含む**。ハンドが5kgあれば、10kg機で運べるワークは5kgまで |
| **リーチ（アーム長）** | 手首中心が届く最大距離 | 端では力も精度も落ちる。**7割程度で使う**のが実務 |
| **繰り返し位置決め精度** | 同じ指令を出したとき、何mmの範囲に戻るか | ±0.02〜0.1mm が一般的。ただしこれは**繰り返し**精度で、絶対精度は別物 |
| **許容イナーシャ（慣性モーメント）** | 手先の重さの「回しにくさ」の許容値 | 重心が遠いハンドは、重量が軽くても手首が耐えられない |
| **設置方式** | 床置き／天吊り／壁掛け／走行軸上 | 天吊りにすると可搬重量が落ちる機種がある |

> なぜこの2つが決定的か：**可搬重量とリーチはロボットの骨格そのもの**で、後から変えられない。
> 一方、速度や精度はプログラムと周辺装置である程度吸収できる。
> だから見積もり段階で「ワーク重量＋ハンド重量」と「最遠点までの距離」を測り違えると、
> 据え付けてから機種入れ替えという最悪の事故になる。

## 3. 用途で分ける：何を、どのスペックでやるか

| 用途 | 主な機構 | 可搬重量の目安 | 何が難しいか |
| --- | --- | --- | --- |
| **スポット溶接**（板を点で溶接） | 垂直多関節 | 150〜300kg | 溶接ガン自体が100kg超。ケーブル・冷却水の取り回し |
| **アーク溶接**（線で連続溶接） | 垂直多関節（6〜7軸） | 6〜20kg | 溶接線を一定速度でなぞる軌跡精度。歪みで狙いがずれる |
| **塗装** | 垂直多関節（中空手首） | 5〜15kg | **防爆構造**が必須（溶剤の蒸気に引火させない）。膜厚の均一性 |
| **組立・ねじ締め・嵌合** | スカラ、垂直多関節、協働 | 3〜20kg | 「入らないときに押し込む」加減。**力制御**と公差のばらつき |
| **マテリアルハンドリング**（機械への着脱） | 垂直多関節 | 10〜100kg | 工作機械の扉との干渉、切粉と切削油への耐性 |
| **パレタイジング**（箱積み） | 4軸専用機 | 50〜300kg | 積み付けパターンの計算、荷崩れ、段ボールの寸法ばらつき |
| **高速ピッキング**（食品・薬） | パラレル | 0.5〜6kg | 毎分100個超の速度。ベルト上を流れる不定位置のワーク認識 |
| **ばら積みピッキング** | 垂直多関節＋3Dカメラ | 3〜20kg | **箱の中で重なった部品の姿勢推定**。取り出し経路の干渉回避 |
| **クリーンルーム搬送**（半導体・液晶） | 専用スカラ／フロッグレッグ | 1〜20kg | 発塵ゼロ、真空対応。ウェーハを割らない |

### 用途がロボットの形を決める3つの実例

1. **スポット溶接が大型機になる理由**：溶接ガンが重い。ワークは薄い鉄板でも、
   手先に付く道具が100kgを超えるので、**可搬重量200kg級が必要になる**。
   自動車のボディ工場に大型アームが林立しているのはこのため。
2. **塗装ロボットが特殊な理由**：塗料の溶剤は可燃性なので、モータの火花が着火源になり得る。
   **内部を清浄空気で加圧する防爆仕様**が要求され、汎用機を転用できない。結果として塗装は専業色が強い。
3. **パレタイジングが4軸な理由**：箱を傾けてはいけない＝手先の姿勢は常に水平でよい。
   姿勢の自由度を捨てた分、同じ価格で重い物を速く運べる。

## 4. 協働ロボット（コボット）のFAでの実像

協働ロボット＝**安全柵なしで人の隣に置ける腕型ロボット**。
日本では労働安全衛生規則が産業用ロボットに柵での隔離を原則として求めるが、
定格出力80W以下などの例外規定があり、これが普及の入口になった
（安全規格の詳細は [なぜロボットは普及しないのか](../../01_注目テーマ/09_ロボット/02_なぜロボットは普及しないのか.md) 参照）。

```
  【通常の産業用ロボット】            【協働ロボット】
   ┌ 安全柵 ──────────┐             人 ← → ロボット
   │  ロボット 全速力   │             柵なし・同じ空間
   │  人は入れない      │             速度は 250mm/s 前後に制限
   └───────────────────┘
   速い（タクト最優先）                遅い（安全最優先）
   設置面積が大きい                    設置面積が小さい
```

- **期待されたほど爆発的には伸びていない**。世界の産業用ロボット出荷に占める協働ロボットは
  1割強にとどまる（2024年、IFR推計）。理由は単純で、**接触しても人が怪我しない速度に落とすと生産が間に合わない**から
- 実際に効いているのは「人と交代で同じセルを使う」「夜間だけ無人で動かす」といった**使い分け**の運用
- 中小企業にとっての本当の価値は速度ではなく、**安全柵ぶんの設置面積とリスクアセスメント工数が減ること**

## 5. 主要4社の構図

世界の産業用ロボットは長く「**日本2社（ファナック・安川電機）＋欧州2社（ABB・KUKA）**」の4強で語られてきた。

| 企業 | 本拠 | 強み | 弱み・特徴 |
| --- | --- | --- | --- |
| **ファナック** | 日本 | 黄色い機体。CNC（工作機械の頭脳）とロボットの両輪。自社工場での自動化実績とサービス網 | 2026年3月期は営業利益率21.4%（前期19.9%）と機械業界では突出。中国EV向けが牽引 |
| **安川電機** | 日本 | 青い機体。サーボモータとインバータの内製。アーク溶接に強い | 2026年2月期の売上収益5,421億円のうちロボット2,470億円（47%）。利益率はファナックに見劣り |
| **ABB** | スイス／スウェーデン | 白い機体。電機コングロマリットの一部。塗装・食品に強い | 欧州の自動車需要低迷の影響を受けやすい |
| **KUKA** | ドイツ | オレンジの機体。自動車ボディ組立ラインの設計まで請け負う | 2016年に中国・美的集団の傘下入り。欧州勢という位置づけが揺らいでいる |

国内の2番手グループも用途特化で確たる位置を持つ。

| 企業 | 位置づけ |
| --- | --- |
| 川崎重工業 | 日本初の国産産業用ロボット（1969年）。半導体ウェーハ搬送と医療に展開 |
| 不二越（NACHI） | ベアリング・工具・油圧を持つ総合部品メーカー。溶接・搬送用アーム |
| 三菱電機 | FA機器（PLC・サーボ）とセットで小型ロボットを供給 → [FA・制御機器](../../03_電機・電子部品/14_FA・制御機器/README.md) |
| デンソーウェーブ | 小型高速アーム。自動車部品メーカー発 |
| セイコーエプソン | スカラで世界上位。精密機器組立由来 |
| オムロン／ユニバーサルロボット（テラダイン傘下） | 協働・移動ロボット。中小向けの入口を作った |
| Estun（中国）、埃夫特、新松 | 中国勢。2025年にEstunが中国市場の販売台数首位（シェア10.6%と報じられる） |

```
    高単価・高精度                        低価格・大量
    ┌──────────────┬──────────────┬──────────────┐
    │ 半導体・液晶搬送 │ 自動車ライン   │ 一般産業・中小 │
    │ 川崎重工       │ ファナック     │ 中国勢（Estun  │
    │ 専用機メーカー   │ 安川・ABB・KUKA│ ・埃夫特・新松）│
    └──────────────┴──────────────┴──────────────┘
         ↑ 参入障壁：クリーン度と実績    ↑ 障壁が最も低く、価格競争が起きる
```

主要4社の世界シェアは合計で5割前後とされる（各種業界推計）が、
**中国市場だけを取り出すと国産メーカーが台数首位を取っている**（2025年、報道ベース）。
この市場構造の変化は [市場の波と競争](03_市場の波と競争.md) で扱う。

## 用語メモ

- **垂直多関節**：人の腕のように関節を縦に重ねた形式。6軸が標準で、産業用の主力
- **スカラ（SCARA）**：水平方向にだけ柔軟で上下は剛な4軸ロボット。「選択的コンプライアンス組立ロボットアーム」の略
- **パラレルリンク（デルタ）**：天井から3本の腕で1点を操る形式。軽量高速。食品ラインで多用
- **可搬重量（ペイロード）**：手先に持てる最大重量。**ハンドの重量を含む**
- **リーチ**：手首中心が届く最大距離。端では性能が落ちる
- **繰り返し位置決め精度**：同じ指令に対する戻り位置のばらつき。絶対精度とは別
- **タクトタイム**：1個を作るのにかかる時間。ラインの速度そのもの
- **ばら積みピッキング**：箱の中で無秩序に重なった部品を3Dカメラで認識して取り出す作業
- **防爆構造**：可燃性ガスの雰囲気中で着火源にならない構造。塗装ロボットの必須要件
- **エンドエフェクタ（ハンド）**：腕の先に付ける道具。吸着パッド、平行チャック、溶接ガン、塗装ガンなど
- **セル生産**：ライン方式に対し、1〜数人（または1台）で完結させる生産方式。協働ロボットの想定現場
