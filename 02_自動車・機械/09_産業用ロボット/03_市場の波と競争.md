# 市場の波と競争（需要先・中国・統計・部品）

**このノートで分かること**：産業用ロボットの需要が**自動車と電機電子という2本の柱**で決まること、
市場の重心が中国に移り国産化が進んでいること、IFRの統計（出荷／稼働ストック／ロボット密度）の読み分け、
そして価格が下がり続けるなかで、**減速機とサーボという基幹部品を日本が押さえている構図**。

結論を先に書く。**この業界は「設備投資の波」そのもの**である。
ロボットは工場を建てるときに買う機械なので、**顧客の設備投資が止まれば受注は即座に半減する**。
需要は増えるが、まっすぐ増えることは一度もない。

## 1. 需要の2本柱：自動車と電機電子

産業用ロボットの出荷先は、世界でも日本でも長く同じ2業種に偏っている。

```
  【需要先】                    【買う理由】                  【波の性格】
  自動車 ────────── 新車種・新工場・EV転換     ──▶ 数年周期。1回が巨額
   30%前後                     ボディ溶接・塗装・組立
                                                    ↓ 受注のロットが大きく振れる
  電機・電子 ──────── 新機種・微細化・工場新設  ──▶ 短周期（1〜2年）。半導体市況連動
   25〜30%前後                 実装・検査・ウェーハ搬送
                                                    ↓ 半導体の設備投資に強く追随
  金属・機械／食品／医薬 ── 人手不足・品質要求    ──▶ 相対的に安定。ただし単価が小さい
   残り
```

| 需要先 | 買われるロボット | 需要の動き方 |
| --- | --- | --- |
| 自動車 | スポット溶接（150〜300kg）、塗装、大型搬送 | **車種切り替えと新工場のタイミングで一気に発注**。間の年はほぼゼロ |
| 電機・電子／半導体 | スカラ、クリーン搬送、小型多関節、検査 | 半導体・液晶の設備投資サイクルに連動。上下が激しい |
| 金属・機械 | マシンテンディング（工作機械への着脱） | [工作機械](../07_工作機械/README.md) と同じ景気指標で動く |
| 食品・医薬・化粧品 | パラレル（高速ピッキング）、パレタイジング | 景気より人手不足で動く。近年の伸び代 |
| 物流倉庫 | 搬送・デパレタイズ | 産業用の外縁。→ [倉庫・3PL](../../13_運輸・物流/08_倉庫・3PL/README.md) |

> なぜ波が激しいのか：**ロボットは「工場を建てる部品」だから**。
> 消耗品ではないので、買う年と買わない年がはっきり分かれる。
> 同じ構図は [工作機械](../07_工作機械/README.md)・[FA・制御機器](../../03_電機・電子部品/14_FA・制御機器/README.md) にも共通し、
> この3業界の受注統計はほぼ同じ形で上下する。

## 2. 統計の読み方：出荷・ストック・密度は別物

産業用ロボットの世界統計は **IFR（国際ロボット連盟）の World Robotics** がほぼ唯一の共通基盤である。
ただし3つの指標が混同されやすいので、分けて覚える。

| 指標 | 意味 | 2024年の数値（IFR World Robotics 2025） | 何が分かるか |
| --- | --- | --- | --- |
| **年間設置台数（出荷）** | その年に新しく据え付けられた台数 | 世界 **542,000台**（2014年の約2倍。過去2番目の高水準） | **今年の景気**。設備投資の勢い |
| **稼働ストック** | 現在工場で動いている累計台数 | 世界 **4,664,000台**（前年比＋9%） | **自動化の蓄積**。保守・部品需要の母数 |
| **ロボット密度** | 製造業従業員1万人あたりの稼働台数 | 日本 **446台／万人**（世界4位） | **自動化の深さ**。国の比較に使う |

国別の年間設置台数（2024年、IFR）は次のとおり。

| 順位 | 国 | 設置台数 | 前年比 |
| --- | --- | --- | --- |
| 1 | 中国 | **295,000台**（世界の54%、過去最高） | 増 |
| 2 | 日本 | 44,500台 | ▲4% |
| 3 | 米国 | 34,200台 | ▲9% |
| 4 | 韓国 | 30,600台 | ▲3% |
| 5 | ドイツ | 26,982台 | ▲5% |

IFRは2025年の世界設置台数を575,000台（＋6%）、2028年に70万台超と予測している（2025年公表）。
なお **World Robotics 2026 は2026年9月24日に公表予定**とされており、最新値はそこで更新される。

```
  混同しやすい3つの数字（日本の例、2024年・IFR）

   年間設置    44,500台   ← 「今年売れた数」。景気で上下する
   稼働ストック 450,500台   ← 「今動いている数」。約10年分の蓄積
   ロボット密度  446台/万人  ← 「どれだけ濃いか」。従業員数で割った値

   ※ 密度は分母が製造業従業員数なので、
      「工場が減る」だけでも上がってしまう点に注意
```

## 3. 日本メーカーは「輸出産業」である

日本ロボット工業会（JARA）の会員ベース統計を見ると、この業界の本質が一発で分かる。

| 項目（2026年4〜6月期、会員ベース） | 金額 | 前年同期比 |
| --- | --- | --- |
| 受注額 | **3,127億円**（57,695台） | ＋40.0% |
| 生産額 | 2,520億円（51,437台） | ＋24.3% |
| 出荷額（合計） | 2,577億円 | ＋24.1% |
| うち **国内出荷** | **383億円** | ＋3.7% |
| うち **輸出** | **2,194億円** | ＋28.5% |

```
   日本のロボットメーカーの出荷（2026年4〜6月期、JARA会員ベース）

   国内 383億円  ██                    15%
   輸出 2,194億円 ████████████████████  85%
                 └────────────────────┘
       つまり「日本の産業用ロボット業界の景気」は
       日本国内ではなく、中国・米国・欧州の設備投資で決まる
```

> ここが最重要の構造：**出荷の8割超が輸出**。
> だから国内の人手不足がどれだけ深刻でも、メーカーの業績には直結しない。
> 逆に、**円安は輸出採算を押し上げ、中国の設備投資が止まれば日本の統計が凹む**。
> ニュースで「ロボット受注が過去最高」と出たとき、それは日本の工場の話ではないことが多い。

2026年の年間見通しとして、JARAは受注額1兆2,200億円（前年比＋16.7%）、生産額1兆500億円（＋11.1%）を示している
（2026年5月29日発表。1月時点の見通しから1,900億円の上方修正で、2022年以来4年ぶりの過去最高更新の見込みと報じられる）。
牽引役はAI向けを中心とする**半導体関連の設備投資**である。

## 4. 中国という最大市場と、国産化の進行

世界の年間設置の**54%が中国**（2024年、IFR）。つまり中国の設備投資が世界市場そのものになっている。
そしてその中国市場で、国産メーカーの比率が上がり続けている。

| 指標 | 数値 | 時点・性格 |
| --- | --- | --- |
| 中国の産業用ロボット国産化率 | 24.2% → 35.0% | 2017年 → 2022年（各種調査） |
| 中低付加価値領域の国産化率 | 40%超 | 2020年代半ば、調査会社の推計 |
| Estun（埃斯頓）の中国市場シェア | 10.6%で販売台数首位 | 2025年、報道ベース |
| Estunの出荷台数順位 | 外資含む全ブランドで1位（6四半期連続） | 2026年上期、報道ベース |

```
  中国市場の二層化（2020年代後半の構図）

   高付加価値（高速・高精度・自動車ライン）
   ┌──────────────────────────────┐
   │ ファナック・安川・ABB・KUKA      │ ← まだ外資が強い
   └──────────────────────────────┘
            ▲ 国産勢が上がってくる
   ┌──────────────────────────────┐
   │ Estun・埃夫特・新松ほか          │ ← 一般産業・搬送はほぼ国産に置き換わり
   └──────────────────────────────┘
   低〜中付加価値（搬送・簡易組立・パレタイジング）
```

Estunの強みは**垂直統合**にあるとされる。サーボモータ、コントローラ、モーション制御を自社で作ることで、
輸入部品への依存を下げ、価格を下げている。これは**かつて日本勢が取った戦略とまったく同じ**であり、
だからこそ効いている。

一方で、日本勢が中国から締め出されたわけではない。
ファナックは2026年3月期に中国のEV関連・一般産業向けが好調で二桁増収、
第2四半期の中国向けロボット売上は前年同期比87%増と報じられた。
**高難度の用途では依然として外資が選ばれている**のが現状である。

## 5. 価格下落と、差別化の置き場所

産業用ロボットは**台数が伸びても金額が同じ比率では伸びない**。1台あたり単価が下がり続けるからである。

| 下落の要因 | 中身 |
| --- | --- |
| 中国勢の低価格投入 | 同クラスで数割安い機種が一般産業向けに流れ込む |
| 量産効果 | 世界の稼働ストックが466万台（2024年）に達し、部品も量産段階 |
| 汎用化 | 6軸汎用機はカタログ商品化し、性能差が見えにくくなった |

ではメーカーは何で差をつけるのか。**本体の性能ではなく、本体の外側**である。

```
  【昔の差別化】             【今の差別化】
   速い・正確・壊れない  ──▶ ここは各社ほぼ横並びに
                             ＋
                          ・保守網（止まった瞬間に駆けつけられるか）
                          ・ソフト（オフライン教示・シミュレータ）
                          ・センサ／視覚との統合（ばら積み対応）
                          ・CNC／PLCとの一体提案（ラインごと売る）
                          ・SIerネットワーク（誰が据え付けるか）
```

- **保守・サービスが利益の下支えになる**。稼働ストックが466万台あるということは、
  景気に関係なく発生する保守部品・修理の母数が466万台あるということ。
  本体が売れない年でもここは残るので、**大手ほど利益が安定する**
- **ソフトと教示の簡便さ**が実質の競争軸になりつつある。導入コストの多くはSIerの工数であり、
  それを減らせるメーカーの機種が選ばれる → [システムインテグレーション](02_システムインテグレーション.md)

主要企業の収益性を並べると、この差がはっきり出る。

| 企業 | 直近の数値 | 出典・時点 |
| --- | --- | --- |
| ファナック | 営業利益率 19.9% → **21.4%**、純利益1,665億円（＋12.9%）、500億円の自社株買い | 2026年3月期、IR・報道 |
| 安川電機 | 売上収益5,421億円（＋0.8%）、うちロボット2,470億円（47%）／モーションコントロール2,361億円（45%） | 2026年2月期、IR・報道 |
| 安川電機（直近四半期） | 受注は前年同期比＋29%だが、基幹システム移行と欧州の構造改革費用でロボット営業利益は大幅減 | 2027年2月期第1四半期（2026年3〜5月）、報道 |

**同じ市場にいても業績が割れる**のは、地域構成（中国比率）と製品構成（半導体向けを持つか）が違うからである。

## 6. 基幹部品：日本が押さえている最後の砦

ロボットの原価の4〜5割は関節、つまり**モータ＋減速機＋ドライバ**である。
このうち精密減速機は、日本の2社が世界シェアの大半を握るとされる。

| 部品 | 主要メーカー | シェア（各種業界推計） | なぜ替えが効かないか |
| --- | --- | --- | --- |
| **波動歯車減速機**（小型関節） | ハーモニック・ドライブ・システムズ | 世界約5割 | 薄い歯車をたわませて減速する構造。材料・熱処理・研削の蓄積が必要 |
| **RV減速機**（大型関節） | ナブテスコ | 産業用ロボット関節向けで世界約6割 | 大トルクとゼロバックラッシュの両立。量産の歩留まりが壁 |
| サーボモータ・アンプ | 安川電機、ファナック、三菱電機、ニデック | — | ロボットメーカー自身が内製する領域 → [モーター](../15_モーター/README.md) |
| ベアリング | 日本精工、ジェイテクト、NTN ほか | — | → [ベアリング](../10_ベアリング/README.md) |

構造的な含意は2つある。

1. **中国メーカーがロボットを安く作っても、関節の一部は日本から買っている**（内製化も進むが、高精度帯では依然依存が残るとされる）。
   つまり**台数が増えれば、シェアを落としても日本の部品メーカーは潤う**
2. **ただしそれは「高精度が要る限り」の話**。性能を落として安くする競争が主流になれば、
   汎用減速機で足りてしまう。技術の詳細は
   [ロボットの分類と構成要素](../../01_注目テーマ/09_ロボット/01_ロボットの分類と構成要素.md) を参照

減速機メーカーの直近の動きも、半導体設備と医療ロボットで回復している。
ハーモニック・ドライブ・システムズは2026年3月期に売上596億円、
2027年3月期第1四半期は売上167億円（前年同期比＋23.6%）、受注高＋55.7%と、
半導体製造装置向けと北米の手術支援ロボット向けが伸びていると報じられる。

> まとめると、この業界の利益は**①ロボットメーカー（寡占・保守収益）と②精密減速機メーカー（2社寡占）**の2ヶ所に集中し、
> 間に挟まるSIerは薄利、という三層構造になっている。

## 用語メモ

- **IFR（International Federation of Robotics）**：国際ロボット連盟。年次報告 World Robotics が世界共通の統計基盤
- **年間設置台数（installations）**：その年に新規据付された台数。景気指標
- **稼働ストック（operational stock）**：現役で動いている累計台数。保守需要の母数
- **ロボット密度**：製造業従業員1万人あたりの稼働台数。国際比較の定番指標
- **JARA（日本ロボット工業会）**：国内メーカーの業界団体。四半期ごとに受注・生産・出荷統計を公表。**会員ベース**である点に注意
- **マシンテンディング**：工作機械にワークを着脱させる用途。工作機械業界と重なる領域
- **国産化率**：ある国の市場で自国メーカーが占める比率。中国市場を語るときの中心指標
- **垂直統合**：モータ・減速機・制御など主要部品を自社で作ること。原価と供給の両方を握れる
- **波動歯車減速機／RV減速機**：ロボット関節用の精密減速機。前者は小型関節、後者は大型関節向け
- **設備投資サイクル**：顧客の工場投資が数年周期で山谷を作ること。ロボット受注の振れの原因
