産業用ロボットを一言でいえば、「工場の中で人の腕を置き換える、設備投資財」。
売れるのは工場を建てるときだけなので、需要は増えるが一度もまっすぐには増えない。
そして本体は自動化投資全体の3〜4割にすぎず、残りはSIer（システムインテグレータ）が組む周辺装置と工数である。

このフォルダはFA（ファクトリーオートメーション）としての産業用ロボット、すなわち
市場・企業・収益構造・部品・政策を扱う。
サービスロボット、ヒューマノイド、AI基盤モデルとの結合は
ロボット（注目テーマ） に委ねる。

1. 業界の定義・範囲

産業用ロボットとは、工場の中で、決められた場所に固定して、繰り返し作業をさせる多関節機械を指す。
規格上の定義（ISO 8373／JIS B 0134）は「2軸以上の関節を持ち、プログラムで動きを書き換えられ、自動で動く機械」で、
カムやリンクで動きが固定された専用機は含まない。

含む 含まない（隣接業界）
垂直多関節・スカラ・直交・パラレル・協働ロボットサーボ・PLC・センサ単体 → FA・制御機器
ロボットコントローラ、ティーチングペンダント動きが固定された専用自動機 → 工作機械
精密減速機・サーボモータ（関節部品）ベアリング単体 → ベアリング／モータ全般 → モーター
SIerによるシステム構築（周辺装置・治具・教示）倉庫の自律搬送ロボット（AMR） → 倉庫・3PL
半導体・液晶のクリーン搬送ロボット配膳・清掃・介護などサービス用途 → ロボット

境界が動いているのは2ヶ所。①協働ロボット（工場の外にも出ていく）と、
②AI・フィジカルAI（ハードの価値がソフトへ移りつつある）。

5. 収益モデル・コスト構造

プレイヤー 何で儲けるか コストの中心 利益の出方
ロボットメーカー本体販売＋保守部品・サービス減速機・モータの調達、開発費本体は景気で振れるが、稼働ストック466万台分の保守が下支え。大手ほど安定
精密減速機メーカー部品販売設備投資と歩留まり（装置産業）寡占で利益率は高いが、稼働率が落ちると固定費で一気に悪化
SIer設計・製作・据付・教示の受託人件費がほぼ全部人月商売。案件ごとに作り直しでコピーが効かず、粗利10〜20%と薄い
商社・ディーラー仕入販売＋簡易SI在庫と人件費口銭商売。複数メーカーを扱える強み

この業界のクセ：設備投資財なので顧客の投資判断が全て。
加えて日本メーカーは出荷の85%が輸出（2026年4〜6月期、JARA会員ベース）なので、
国内の人手不足より中国・米国の設備投資と為替のほうが業績を動かす。

6. 競争要因（KSF）と参入障壁

KSF（成功要因）

  1. 基幹部品の内製または安定調達：減速機とサーボが量産のボトルネック
  2. 保守網：止まった瞬間に顧客の生産が止まる。駆けつけ体制がそのまま乗り換え障壁になる
  3. SIerネットワーク：本体が良くても据え付けられなければ売れない → 02_システムインテグレーション
  4. ソフトと教示の簡便さ：導入費の多くはSIerの工数。それを減らせる機種が選ばれる
  5. 地域と用途のポートフォリオ：中国比率・半導体比率の違いが、そのまま業績差になる

参入障壁

  • 実績（止まらない証明がないと産業ユーザーは買わない）、保守網の展開、
    安全規格・認証（ISO 10218／JIS B 8433）、精密減速機の調達
  • 逆に参入障壁が最も低いのは一般産業向けの中低価格帯。中国勢が台数を伸ばしたのはここ

7. 規制・法制度

制度 内容
労働安全衛生規則（日本）産業用ロボットの運転中は柵・囲いによる隔離が原則。定格出力80W以下などの例外が協働ロボット普及の起点
ISO 10218 / JIS B 8433産業用ロボットの安全要求。ロボット本体と「システムとしての統合」の両面を規定
ISO/TS 15066協働運転の技術仕様。人と接触したときの許容力・圧力を定める
特別教育（労働安全衛生法）産業用ロボットの教示・検査には所定の特別教育の受講が必要
中小企業省力化投資補助金カタログ注文型（登録済み汎用製品から選ぶ）と一般型。設計工数をなくすための制度設計
ものづくり補助金設備投資全般。SIer費用も対象になりうる
ロボットフレンドリー施策（経産省）現場・什器・業務フロー側をロボットに合わせて標準化する政策
フィジカルAI政策（2026年）半導体・デジタル産業戦略の改定（2026年6月）で最重点分野に。官民投資ロードマップで2040年度までに10.5兆円の投資を想定

8. 最近のトピック・技術トレンド

詳細と出典URLは 04_直近トピック_2026 に。要点は5つ。

  1. 受注が過去最高を更新中。2026年4〜6月期は受注3,127億円（＋40.0%）で3四半期連続の最高更新。
    年間見通しは受注1兆2,200億円（＋16.7%）。牽引役はAI向けを中心とする半導体設備投資
  2. ただし伸びているのは輸出。同期の国内出荷は383億円（＋3.7%）で横ばい圏、輸出は2,194億円（＋28.5%）
  3. 中国が市場の54%を占め、国産化が進む。Estunが2025年に中国市場の販売台数首位。
    低〜中価格帯は国産、高付加価値はまだ外資という二層化
  4. 同じ市場でも業績は割れる。ファナックは営業利益率21.4%と好調、安川電機は受注＋29%でも
    基幹システム移行と欧州構造改革費用でロボット利益が大幅減（2026年3〜5月期）
  5. 政策の主語が「フィジカルAI」に変わった。2040年度までに官民10.5兆円の投資想定。
    ただしこれは目標値であり統計ではない
