システムインテグレーション（SIerという第二の産業）

自動車・機械産業用ロボット
あこのページの単語集用語に触れると意味を確認できます13語
標準化・パッケージ化環境側を標準化する教示の自動化SIer（システムインテグレータ）ターンキー人月（にんげつ）／人工（にんく）治具（じぐ）ハンド（エンドエフェクタ）ライトカーテンリスクアセスメント立会検査（FAT）カタログ注文型生産技術部門

このノートで分かること：ロボットメーカーが売っているのは動かない半完成品であり、
それをラインに仕立てるSIer（システムインテグレータ）という別の産業が間に挟まっていること。
そのSIerが人月商売であるがゆえに規模が大きくならず、
中小企業の案件が構造的に受けられないという日本固有の詰まり方をしていること。

結論を先に書く。ロボット本体の売上は、自動化投資全体の3〜4割にすぎない。
残りはハンド・周辺装置・安全対策・設計・据付・教示で、そこを担うのがSIerである。
つまり、ロボット市場の規模を本体出荷額で測ると、産業の半分以下しか見ていないことになる。

導入費の内訳と投資回収年数の一般論、ロボットフレンドリー施策、補助金制度は
なぜロボットは普及しないのか に書いた。
このノートはSIerという事業者側の商売の構造に絞る。

1. ロボットは「半完成品」として出荷される

ロボットメーカーの箱から出てくるのは、腕とコントローラとティーチングペンダントだけである。
何を掴むかも、どこに置くかも、いつ動き出すかも決まっていない。

  【ロボットメーカーが売るもの】       【現場で必要なもの】
  ┌──────────────┐                 ハンド（掴む道具）
  │ アーム        │                 治具（ワークを固定する台）
  │ コントローラ   │  ＋             架台・安全柵・ライトカーテン
  │ ペンダント     │                 部品供給機・コンベア
  └──────────────┘                 画像センサ・照明
         ↓                          上位PLCとの通信配線
   これだけでは                      動作プログラム（ティーチング）
   1個も作れない                     リスクアセスメント文書・取説
                                     試運転・立ち上げ・作業者教育
                                            ↓
                                     全部まとめて「ロボットシステム」

ポイント：ロボットは道具箱ではなく、道具の取っ手だけ。
掴むもの・置く場所・タイミングを決める作業がなければ1個も生産できない。
この「決める」工程をまとめて引き受けるのがSIerである。

この構造のため、産業用ロボット業界の統計（日本ロボット工業会の受注・生産額など）は
本体とコントローラの金額しか数えていない。実際に動いている設備の金額はその2.5〜3倍あるが、
そこは「SIerの売上」として機械器具設置工事やエンジニアリングの数字に散っており、統一統計が存在しない。

2. SIerの4類型

「SIer」と一括りにされるが、出自によって得意分野も採算も違う。

類型 出自 強み 弱み
メーカー系ロボットメーカーの子会社・認定パートナー本体の癖を熟知。保守まで一気通貫親会社の機種に縛られる
商社・ディーラー系FA機器商社が技術部隊を持った部材調達力。複数メーカーを比較提案できる難易度の高い設計は外注に出しがち
独立系（専業SIer）設備設計・機械工作から発展特定工程（溶接、食品、検査など）への深い知見人手が全て。規模が小さい
ユーザー系（内製）自動車・電機メーカーの生産技術部門自社工程を知り尽くしている外販しない。ノウハウが社外に出ない

日本では、大手自動車・電機メーカーが生産技術部門という形で社内にSIer機能を抱えてきたのが大きな特徴である。
これがトヨタ生産方式のような現場主導の改善と結びつき、大企業の工場には世界最高水準の自動化が入った。
一方でノウハウが社内に閉じたため、外部のSIer産業が育ちにくかったという副作用がある。

  【大企業】                          【中小企業】
  生産技術部門が自前で設計              社内に設計できる人がいない
        ↓                                   ↓
  ロボットメーカーから直接買う           SIerに丸ごと頼むしかない
        ↓                                   ↓
  自動化が進む（密度が高い）             SIerが足りず・採算も合わず止まる

3. SIerの商売は「人月」である

SIerの原価は、材料ではなく人の時間が中心になる。ここが理解の要所。

費目 全体に占める目安 性質
ロボット本体・周辺機器の仕入40〜55%仕入原価。値引きの余地は小さい
設計（機械設計・電気設計・制御）15〜25%人件費。案件ごとにほぼ作り直し
製作・組立・配線10〜15%人件費＋外注費
据付・調整・ティーチング10〜20%人件費。現地に張り付く期間そのもの
粗利10〜20%（案件により大きく振れる）ここが薄いのが業界の慢性課題

なぜ規模の経済が効かないのか：案件が1件ごとに違うからである。
掴む物が違えばハンドは作り直し、工場の柱の位置が違えばレイアウトは作り直し、
前後の設備が違えば通信仕様も作り直しになる。
ソフトウェア産業と違ってコピーが効かないため、売上を倍にするには人を倍にするしかない。

関東経済産業局が全国374社のロボットSIerに実施した調査（回答144社、回収率38.5%）では、
次のような姿が報告されている。

  • 自動化需要の高まりで引き合い・売上ともに増加傾向という企業が多い
  • しかし仕事量の増加が利益率の増加に直結していない
  • 9割以上がエンジニア不足を感じている。機会損失、既存エンジニアの労働環境悪化、品質低下への危機感
  • ロボットエンジニアのスキル基準を設けている企業は2割程度。待遇の明確な基準がない企業が5割近く
  • 業界の課題として「業界の認知向上」「国家資格化などスキルの可視化」「ユーザー教育の強化」が挙がる

つまり仕事はあるが人がおらず、人がいないから単価も上げられず、単価が上がらないから人が来ないという循環に入っている。

4. なぜ中小企業にロボットが入らないのか（SIer側の理由）

ユーザー側の理由（回収年数が合わない、多品種少量、ティーチングが重い）は既存ノートで説明した。
ここではあまり語られないSIer側の採算を書く。

   SIer1案件あたりの固定的な手間（ほぼ案件規模に関係なくかかる）
   ┌──────────────────────────────────────────┐
   │ 現地調査 → 仕様ヒアリング → 概略設計 → 見積 │  ← 受注前。失注すればタダ働き
   │ 詳細設計 → 部品手配 → 組立 → 立会検査       │
   │ 現地据付 → 調整 → 教示 → 教育 → 引渡書類     │
   └──────────────────────────────────────────┘
        この帯の長さは、3,000万円の案件でも
        800万円の案件でも  ほとんど変わらない
案件規模 SIerの人工（にんく）の目安 SIerから見た採算
1億円（複数台のライン）設計〜立上げで延べ数十人月固定的な手間を吸収でき、採算に乗る
3,000万円（セル1式）延べ10〜20人月標準的。ここが主戦場
800万円（ロボット1台）延べ5〜8人月提案・調査の工数を回収しにくい。受けたがらない
300万円（協働1台＋治具）延べ2〜4人月ほぼ赤字。カタログ製品でないと成立しない

ここが決定的で、中小企業が買える金額（数百万円）は、SIerが受けたい金額の下限を下回っている。
需要側の「回収3年以内」という制約と、供給側の「この規模では人件費が出ない」という制約が、
ちょうど同じ帯域でぶつかっている。

これを解く方向は3つある。

  1. 標準化・パッケージ化：ハンドと治具を規格化し、毎回の設計をやめる。
    中小企業省力化投資補助金の「カタログ注文型」（登録済みの汎用製品から選ぶ方式）は、
    まさにSIerの設計工数をゼロにするための制度設計になっている
  2. 環境側を標準化する：経済産業省のロボットフレンドリー施策。現場をロボットに合わせる
  3. 教示の自動化：AI・オフラインティーチングで据付後の張り付き期間を短縮する
    → AIとロボットの結合

5. 投資回収はどこで決まるか（見積書の読み方）

ユーザー側の判断は、結局この一本の式に落ちる。

  回収年数 ＝ システム総額 ÷ （年間の人件費削減額 ＋ 不良削減・稼働改善額 − 年間保守費）

ここで実務上のポイントは分子（システム総額）のうち本体が4割しかないことである。

  よくある誤解                        実際
  「ロボットが500万円だから、          本体      500万円
   1人分（450万円）減れば1年で回収」    ハンド治具 250万円
                                      周辺装置   300万円
                                      安全対策   120万円
                                      設計・据付 380万円
                                      教示       150万円
                                      ─────────────────
                                      総額     1,700万円
                                      → 回収 約4年（保守費込み）

だから値引き交渉を本体価格に集中させても効果は小さく、
効くのは「治具を標準品にする」「安全柵を減らせる配置にする」「教示日数を削る」といった
SIerの工数側の圧縮になる。見積書を本体・部材・工数の3つに割ってもらうのが第一歩である。

6. ロボットメーカーとSIerの力関係

項目 ロボットメーカー SIer
何を売るか本体・コントローラ・保守部品動く設備（ターンキー）
顧客は誰か多くはSIerと商社（エンドユーザーへの直販は一部）エンドユーザー
利益率高い（ファナックは2026年3月期に営業利益率21.4%）低い（粗利10〜20%、営業利益率は1桁が多い）
景気耐性保守・部品が下支え受注が止まると人が余る
規模世界数社の寡占全国に数百社。大半が中小企業

構図としては、利益はメーカーに残り、手間はSIerが引き受ける形になっている。
メーカー側もこれを放置しているわけではなく、
認定パートナー制度、教育センター、オフラインティーチングソフトの提供、
簡易ティーチング機能の内蔵など、SIerの工数を減らす方向に投資している。
それはSIerのためというより、SIerが詰まるとロボットが売れないからである。

この業界を一言でまとめるなら：ロボットメーカーのボトルネックは工場ではなく、SIerの人数。

用語メモ

  • SIer（システムインテグレータ）：ロボット本体・周辺装置・安全対策・制御を組み合わせ、稼働する設備に仕立てる事業者。業界団体は日本ロボットシステムインテグレータ協会（JARSIA）
  • ターンキー：発注者が鍵を回せばすぐ動く状態で引き渡す契約形態。SIerの基本形
  • 人月（にんげつ）／人工（にんく）：1人が1ヶ月（1日）働く作業量の単位。SIerの原価と見積の基本単位
  • 治具（じぐ）：ワークを決まった位置・姿勢に固定する道具。案件ごとの専用設計になりやすい
  • ハンド（エンドエフェクタ）：腕の先に付けて物を掴む道具。吸着、平行チャック、多指など
  • ライトカーテン：光の幕を遮ると設備を止める安全装置。安全柵の代わりに出入口へ使う
  • リスクアセスメント：導入前に危険源を洗い出し安全方策を決める法定の手順
  • 立会検査（FAT）：SIerの工場で顧客が動作を確認する検査。合格後に現地へ移設する
  • カタログ注文型：中小企業省力化投資補助金の方式のひとつ。登録済みの汎用製品から選ぶことで設計工数をなくす
  • 生産技術部門：製造業の社内で設備・工程を設計する部署。日本ではここが実質的なSIerを兼ねてきた
