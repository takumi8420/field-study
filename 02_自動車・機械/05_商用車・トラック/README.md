## 1. 業界の定義・範囲

**商用車** ＝ 人や物を運ぶことを目的に、**事業に使われる車両**。
ナンバーの色や税制ではなく「誰が何のために買うか」で乗用車と分かれる。

```
【商用車の範囲】
 ┌────────────────────────────────────────────────┐
 │ トラック  大型（10t級）／中型（4t級）／小型（2t級）／軽貨物    │
 │ バ  ス   路線バス／観光バス／送迎バス                      │
 │ 特装車   ダンプ／ミキサー／タンクローリー／塵芥車／消防車      │
 │ 牽引系   トラクタ＋トレーラ                                │
 │ LCV     ピックアップトラック、小型バン（海外で巨大市場）      │
 └────────────────────────────────────────────────┘
      ▲ 車両メーカーが作るのは「シャシ＋キャブ」まで。荷台は架装メーカーが架ける（→ ①）
```

境界の引き方：

- **乗用車** は [自動車（完成車）](../01_自動車（完成車）/README.md)。軽貨物（ハイゼット等）は
  乗用車メーカーの製品なので、ここでは扱いを軽くする
- **運送事業そのもの**（運賃、ドライバー、荷主との関係）は
  [陸運・トラック](../../13_運輸・物流/06_陸運・トラック/README.md)
- **建設機械**（油圧ショベル等）は走行が主目的ではないので [建設機械](../06_建設機械/README.md)
- **架装メーカー**（極東開発、新明和など）は本ノートの守備範囲に含める。分業が業界理解の要だから

## 3. バリューチェーン（川上 → 川下）

```
 素材 ─▶ 部品 ─▶ 車両メーカー ─▶ 架装メーカー ─▶ 販売・リース ─▶ 運送会社 ─▶ 中古・輸出
 鋼材    エンジン   いすゞ/日野/     極東開発      ディーラー      稼働         アジア・
 アルミ  変速機     ふそう/UD        新明和        リース会社      ↓           アフリカへ
 樹脂    電装・電池  シャシ＋キャブ    トレクス      レンタル      整備・車検
                    認証（型式指定）  荷台・装置                   部品交換
   ▲利益率 中     ▲中          ▲販売は薄利      ▲寡占で安定    ▲金融の利ざや  ▲★ここが厚い
```

- **付加価値が集まるのは (a) 純正部品・整備、(b) 架装（寡占）、(c) 金融、(d) 中古・輸出**
- 車両メーカーの新車販売そのものは薄利。**保有台数（パーク）を積み上げて
  10〜15年かけてアフターで回収する**のが基本モデル（→ [②](02_儲け方の構造.md)）
- 架装は国内で **極東開発工業・新明和工業の2社で約7割**とされる寡占市場

## 5. 収益モデル・コスト構造

```
利益 ＝ 新車マージン（薄い）
      ＋ 保有台数 × 1台あたり年間アフター収益（★本体）
      ＋ リース・割賦の金利
      － 固定費（開発費・工場・拠点網）
```

| 論点 | 中身 |
| --- | --- |
| 新車の利益率 | 薄い。企業が相見積もりで買うため値引き圧力が強い |
| アフター | 走行距離が乗用車の5〜10倍。**事業用トラックは車検が毎年**で、整備需要が制度的に保証される |
| 営業利益率 | **5〜8%が標準的レンジ**。いすゞの2026年3月期は約5.9% |
| 固定費 | 開発費（電動化・自動運転で増加）、工場、そして**全国の整備・部品拠点** |
| 金融 | メンテナンスリースが主力。整備を自社網に固定でき、ユーザーはTCOが読める |
| 為替・関税 | 海外比率が高く、米関税・材料費・地政学の影響を直接受ける |

詳細は [② 儲け方の構造](02_儲け方の構造.md)。

## 6. 競争要因（KSF）と参入障壁

**KSF（成功の鍵）**

1. **保有台数の維持**：シェアを落とすと10年かけてアフター収益が細る
2. **整備網の密度**：幹線沿いに拠点があるかが購買を決める
3. **ダウンタイムの短さ**：部品供給の速さ、故障予知、代車手配
4. **TCOで勝つ燃費と積載**：1km/Lの差、100kgの軽量化が年間コストを動かす
5. **架装メーカーとの関係**：納期と適合性は架装側との連携で決まる
6. **認証の信頼**：型式指定が取り消されれば出荷が止まる（日野の事例）
7. **規制先読み**：排ガス・燃費・安全装備の施行に合わせた商品投入

**参入障壁**

| 障壁 | 強さ | 理由 |
| --- | --- | --- |
| 車両の製造 | 中 | 作るだけなら新興でも可能 |
| **全国の整備・部品網** | **強** | 最大の壁。車は作れても拠点は作れない |
| **長期部品供給** | 強 | 10〜15年の供給義務が事実上ある |
| **認証・型式指定** | 強 | 排ガス・安全の適合試験に時間と費用がかかる |
| **架装との擦り合わせ** | 中〜強 | 架装メーカーが対応してくれないと商品にならない |
| **ブランドと実績** | 中 | 止まらない実績がないと運送会社は乗り換えない |

## 7. 規制・法制度

| 分野 | 主な制度 |
| --- | --- |
| **車両の認証** | 道路運送車両法の**型式指定**。保安基準への適合を国が事前確認する |
| **検査（車検）** | 事業用トラックは**毎年**（自家用貨物は初回2年・以降1年が基本）。乗用車より周期が短い |
| **免許区分** | 2017年3月以降：普通（GVW3.5t未満）／準中型（7.5t未満）／中型（11t未満）／大型（11t以上） |
| **排出ガス規制** | ポスト新長期規制以降の段階的強化。DPF・尿素SCRが必須 |
| **重量車燃費基準** | トップランナー方式。**2025年度目標は2015年度基準比でトラック約13.4%、バス約14.3%の強化** |
| **安全装備の義務化** | 衝突被害軽減ブレーキ、車線逸脱警報、側方衝突警報などの順次義務化 |
| **労働規制** | 2024年4月からドライバーの時間外労働に**年960時間の上限**（2024年問題） |
| **物流効率化法** | **2026年4月施行の改正法**で一定規模以上の荷主にも効率化対応を求める（2026年問題） |
| **補助金** | 「商用車等の電動化促進事業」（2025年度補正で予算規模300億円）。ディーゼルとの差額の一定割合を補助。自治体の上乗せもあり |
| **競争法** | 2025年9月、荷台架装のカルテルで極東開発工業と日本トレクスに課徴金計約59億円（公取委） |

詳細は [③ 電動化と規制](03_電動化と規制.md)。

## 8. 最近のトピック

詳細と出典は [④ 直近トピック（2026年9月時点）](04_直近トピック_2026.md)。要点だけ挙げると:

- **2026年4月1日、ARCHION（日野＋三菱ふそう）が発足・東証プライム上場**（543A）。
  トヨタとダイムラートラックが各25%を目指す資本構成。ブランドと販売は残し、開発・調達・生産を統合
- **国内は二大陣営へ**。2026年上期の大・中型シェアは いすゞ＋UD 56.1%、ARCHION 43.9%
- **販売は好調、収益は逆風**。2026年3月期のいすゞは売上3兆4,790億円（+7.5%）ながら
  営業利益2,037億円（-11.2%）。米関税・材料費・中東情勢による生産混乱が要因
- **日野の認証不正は清算が一区切り**。2025年1月に米当局と計約12億ドル（約1,880億円）で和解
- **電動化はまだ普及率1.06%**（2025年3月末）。小型は補助金で進み、大型は水素FCV
  （日野プロフィアZ FCV、航続約650km）と自動運転（新東名でレベル4実証）が次の手
