# 商用車・トラック｜直近トピック（2026年9月時点）

報道・各社公表ベースの整理。数値は発表時点のもので、確定値は一次情報で裏取りすること。
2026年の商用車業界は、**国内の勢力図が30年ぶりに書き換わった年**として記録される。

```
【2026年の全体像】

  2026年4月1日 ─▶ ARCHION（日野＋三菱ふそう）発足・東証プライム上場
        │
        ├─▶ 国内は「いすゞ＋UD」対「ARCHION」の二大陣営へ
        │
        ├─▶ 販売は好調継続（大・中型が4年連続の前年超え）
        │
        ├─▶ ただし収益は関税・材料費・中東情勢で圧迫（増収減益）
        │
        └─▶ 電動化は小型から。大型はFCVと自動運転の実証段階
```

## 1. ARCHION（アーチオン）発足：国内が二大陣営に再編

2026年4月1日、日野自動車と三菱ふそうトラック・バスを100%子会社とする持株会社
**ARCHION株式会社**（証券コード 543A）が発足し、東証プライム市場に上場した。

| 項目 | 内容 |
| --- | --- |
| 発足・上場 | 2026年4月1日、東証プライム（コード543A）。初値400円、初日終値431円と報じられる |
| 資本構成 | トヨタ自動車とダイムラートラックが **各25%を保有する形を目指す**。残りは一般株主 |
| 議決権 | 報道ベースでトヨタ19.9%、ダイムラー26.7% |
| 経営 | CEOは三菱ふそう社長のカール・デッペン氏。本社は東京。取締役の3分の1超を独立社外とするガバナンス |
| 審査 | 2026年2月26日に公正取引委員会の審査結果が公表され、統合が実行可能となった |
| ブランド | **日野と三菱ふそうのブランド・販売は維持**し、競争させる。統合するのは開発・調達・生産と技術領域 |
| 業績見通し | 2027年3月期の売上収益予想 **2兆4,250億円**（2026年5月14日発表）。増収減益の見通しと報じられる |

**なぜ統合したのか**を分解すると3点。

1. **開発費の分散を止める**。電動化・水素・自動運転をそれぞれ単独で開発する体力が、
   国内メーカー単独ではもう足りない
2. **日野の信用回復**。エンジン認証不正（後述）で失った時間と資金を、単独では取り戻しにくい
3. **アジアでの規模**。ダイムラートラック（世界首位級）とトヨタの技術・資本を背景に、
   「日本とアジアにおける商用車のリーディング企業」を掲げる

> 見どころ：**ブランドは競わせ、中身は共通化する**という設計。
> 乗用車の経営統合でしばしば起きる「ブランド整理」をあえて避けている。
> 販売網と顧客（運送会社）がブランドに紐づいているため、統合すると顧客が逃げるからだと考えられる。

## 2. 国内シェア：56.1% 対 43.9% の全面対決

2026年上期（1〜6月）の大・中型トラック販売は **37,374台（前年同期比 +1.9%）** で、
暦年上期として **4年連続のプラス**。

| メーカー | 2026年上期 台数 | 前年同期比 | 陣営 |
| --- | --- | --- | --- |
| いすゞ自動車 | 14,877台 | -5.1% | いすゞ＋UD：**56.1%**（-3.1pt） |
| UDトラックス | 6,092台 | +0.9% | 同上（2021年にいすゞ傘下入り） |
| 日野自動車 | 9,728台 | +2.3% | ARCHION：**43.9%**（+3.1pt） |
| 三菱ふそう | 6,677台 | **+22.4%** | 同上 |

```
【国内 大・中型トラックの陣営シェア（2026年上期）】

 いすゞ＋UD     ■■■■■■■■■■■■■■■■■■■■■■■■■■■■  56.1%  （前年から -3.1pt）
 ARCHION       ■■■■■■■■■■■■■■■■■■■■■■         43.9%  （前年から +3.1pt）
                ▲ 三菱ふそうの+22.4%が押し上げた。統合前の駆け込み・在庫要因も指摘される
```

- 三菱ふそうの大幅増は、前年の反動と統合を控えた販売攻勢の両方が指摘される。
  **単月・半期の伸び率だけで実力を判断しない**ほうがよい
- 2025暦年の国内普通トラック販売は **75,689台（前年比 +4.7%）** で3年連続のプラス。
  2024年は72,265台（+8.7%）だった
- 好調の背景は、2024年問題後の運賃改善による運送会社の更新余力の回復
  （→ [③ 電動化と規制](03_電動化と規制.md)）

## 3. 収益は逆風：関税・材料費・中東情勢

販売が伸びても利益は減っている、というのが2026年3月期の共通した姿。

| 項目 | 数値 | 出典・時点 |
| --- | --- | --- |
| いすゞ 売上収益 | **3兆4,790億円**（+7.5%） | 2026年3月期 決算短信（IFRS） |
| いすゞ 営業利益 | **2,037億円**（-11.2%） | 同上。利益率は約5.9% |
| いすゞ 当期利益 | 1,746億円（-3.5%） | 同上 |
| いすゞ 総販売台数 | 565,858台（+8.1%） | 同上。国内81,741台（+5.5%） |
| ARCHION 2027年3月期 売上収益予想 | 2兆4,250億円 | 2026年5月14日発表。増収減益予想 |

減益要因として各社が挙げるのは次の4つ。

1. **米国の関税**：商用車・部品にも通商措置が及び、北米事業の採算を圧迫
2. **材料費・部材費の高騰**：鋼材、電子部品、安全装備の追加
3. **中東情勢による生産混乱**：原料・部材の供給が乱れ、生産計画に影響したと説明されている
4. **成長投資の増加**：電動化・コネクテッド・自動運転への開発費

> 構図：**国内は売れているが、稼ぎ頭は海外**。
> いすゞはタイを中心としたピックアップ（LCV＝小型商用車）と、北米・アジアの商用車が収益の柱で、
> ここが関税と地政学の直撃を受けている。乗用車側と同じ構造（→ [自動車（完成車）](../01_自動車（完成車）/README.md)）。

## 4. 日野のエンジン認証不正：清算が終わり、統合へ

2022年に発覚した日野自動車のエンジン排出ガス・燃費の認証不正は、2025〜2026年にかけて
**金銭的な清算が一区切り**した。

| 時期 | 内容 |
| --- | --- |
| 2022年 | 排出ガス・燃費データの不正が公表。出荷停止、型式指定の取り消し |
| 2023年10月 | 米国の集団訴訟で約350億円の和解と報じられる |
| 2025年1月 | 米当局と刑事・民事の制裁金 **計約12億ドル（約1,880億円）** で和解と発表。カナダの集団訴訟は約60億円 |
| 決算影響 | 和解費用を特別損失として計上し、2025年3月期は大幅赤字と報じられた |
| 再発防止 | エンジンの **開発機能と認証機能を分離**、コンプライアンス体制強化。3月4日を「再出発の日」と制定 |
| 2026年4月 | ARCHIONとして三菱ふそうと統合 |

> 教訓として業界が受け止めたのは、**認証（型式指定）は商用車の生命線**という点。
> 型式指定が取り消されると出荷が止まり、整備・部品の信頼も連鎖的に傷つく。
> [自動車（完成車）](../01_自動車（完成車）/README.md) 側でも型式指定不正が続いており、
> 認証制度そのものの見直しが業界横断の論点になっている。

## 5. 電動化：小型は補助金で動き、大型は水素と自動運転の実証段階

**現状の数字**

- EVトラックの普及率は **1.06%**、EV・FCEVトラックの保有台数は **計4,582台**（2025年3月末時点、業界資料ベース）
- つまり **まだ実験的な段階**。ディーゼルの置き換えは始まったばかり

**2026年に動いたこと**

| 動き | 内容 |
| --- | --- |
| 補助金 | 2025年度補正予算「商用車等の電動化促進事業」で **予算規模300億円**。ディーゼル車との価格差の一定割合（2/3など）を補助。車両と充電設備のセット導入枠もある |
| 執行 | 環境省・経産省・国交省の連携。トラックは環境優良車普及機構（LEVO）が窓口。2026年4月から新年度の公募開始 |
| 自治体 | 東京都が2026年4月30日からEVバス・EVトラック購入補助の受付を開始。**2035年までに都内でEVトラック7万台**が目標 |
| 水素 | 日野が2025年10月に大型FCトラック「プロフィアZ FCV」を発売（航続 **約650km**）。ホンダも大型FCトラックの実証を継続 |
| 自動運転 | 新東名（駿河湾沼津SA〜浜松SA）で **夜間22時〜5時に第一通行帯を自動運転トラック優先レーン**とする実証。いすゞ・日野・三菱ふそう・UDの4社が参画（RoAD to the L4 テーマ3）。幹線の社会実装は2026年度以降を目標 |

> 読み方：**補助金の年度予算が電動化の実質的なアクセル**になっている。
> 予算枠に達すると抽選・打ち切りになるため、「来年も同じ条件で買える」前提は置けない。
> 技術より制度の継続性を見るほうが、普及ペースを当てやすい。

## 6. 世界：ダイムラートラックが首位、上位5社で3割強

| 順位（2025年、大型トラック） | メーカー | 備考 |
| --- | --- | --- |
| 1 | **ダイムラートラック**（メルセデス、フレイトライナー、三菱ふそう） | 市場シェア12%超とされる（GMIなど調査会社の推計） |
| 2〜5 | PACCAR（ケンワース、DAF）、中国重汽（Sinotruk）、TRATON（MAN、スカニア、ナビスター）、ボルボ（ボルボ、ルノー、UD） | 上位5社の合計で約32%（同推計） |

- 乗用車と比べて **世界シェアが分散している**のが商用車の特徴。
  整備網が地域単位でしか作れないため、地場メーカーが生き残りやすい
- 欧州ではボルボが2024年の大型トラック市場でシェア約17.9%と首位に立ったと報じられ、
  TRATON傘下のスカニアは2024年に初めて年間10万台を超えた
- **ARCHIONの世界的な立ち位置**は、ダイムラートラックが三菱ふそう側の親でもあるため、
  「競合」と「資本の親」が重なる複雑な構造になっている

```
【商用車の資本関係（2026年時点の概略）】

  トヨタ ─25%─┐                    ┌─25%─ ダイムラートラック
               ├─ ARCHION ────────┤       （メルセデス、フレイトライナー）
               │   ├ 日野          │
               │   └ 三菱ふそう ───┘ 技術・資本の両面でつながる
               │
  いすゞ ───────┴─ UDトラックス（2021年にボルボから取得）
               └─ トヨタが出資（2018年に資本提携）
       ▲ トヨタは両陣営に関与している。国内商用車は「トヨタを介した二極」とも言える
```

## 7. 全体の構図（まとめ）

1. **2026年は再編の年**。ARCHION発足で、国内は「いすゞ＋UD（56.1%）」対
   「ARCHION（43.9%）」の二大陣営に固まった（2026年上期の大・中型ベース）
2. **販売は好調、収益は逆風**。2024年問題後の運賃改善が更新需要を支える一方、
   関税・材料費・中東情勢で利益が削られている
3. **利益の柱は依然としてアフター**。テレマティクスと故障予知で稼働率を売る競争が本番化
   （いすゞは約44万台と接続、突発故障を約7%低減と発表）
4. **電動化は普及率1%台**。小型から補助金で進み、大型は水素FCVと自動運転の実証段階。
   「電池が重いと積載が減る」という物理は2026年時点でも解けていない
5. **競争軸は車両からサービスへ**。誰が運送会社の稼働データを握り、
   整備と配車の効率化まで請け負うかが次の10年の勝負になる
