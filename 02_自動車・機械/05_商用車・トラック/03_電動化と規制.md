# 商用車・トラック｜電動化と規制

**このノートで分かること**：なぜ大型トラックのEV化だけが、乗用車と違って進まないのか。
答えは意識でも政策でもなく **物理**にある。電池が重いほど荷物が積めない。
その物理から、水素FCVの位置づけ、排ガス・燃費規制、そして2024年問題までを一本の線でつなぐ。

```
【この章の骨格】

 ①電池は重い ──▶ 積載が減る ──▶ 売上が減る ──▶ TCOが合わない
      │                                             │
      │                                             ▼ だから
      ▼ 距離が長いほど不利                    小型・近距離からEV化が進む
      │
      ▼ 長距離・大型は別解が要る ──▶ 水素FCV／合成燃料／モーダルシフト
      │
      ▼ それでも規制は迫る ──▶ 排ガス・燃費基準・補助金が買い替えを動かす
```

電動化そのものの技術・政策の総論は [EV・電動化](../../01_注目テーマ/03_EV・電動化/README.md)、
電池産業は [蓄電池](../../01_注目テーマ/04_蓄電池/README.md)、水素は
[水素・アンモニア](../../01_注目テーマ/06_水素・アンモニア/README.md) にある。
ここでは **商用車固有の事情だけ**を書く。

## 1. 出発点：電池の重さが積載を食う

トラックの売上は「何トン運んだか」で決まる。車両総重量には法律で上限があるので、
**車体が重くなった分、そのまま積載可能重量が減る**。

```
【車両総重量 25t の大型トラックで起きること（概念図）】

 ディーゼル車
 ├─ 車体・シャシ・架装 ────────────────┤├─── 積 載 ───────────────┤
 │             約 11〜12t              │        約 13〜14t         │

 BEV（電池式）※長距離を狙って大容量電池を積むと
 ├─ 車体・シャシ・架装 ───────────┤├─電池─┤├──── 積 載 ────┤
 │          約 11〜12t            │  数t   │     減った分だけ売上減   │
                                    ▲ ここが利益を直接削る
```

- 大型トラックが1日500〜800km走るには、乗用車の10倍以上のエネルギーが要る。
  電池容量を増やせば増やすほど **電池そのものが重く、高く**なる
- 電池は一般に **1kWhあたり5〜7kg程度**とされ（セル・パック構成により変動）、
  数百kWh積めば車両重量は数トン単位で増える
- 各国はゼロエミッション車の車両総重量上限を緩和する特例を設けているが、
  **緩和幅より電池重量のほうが大きい**ことが多く、積載減を完全には埋められない
- さらに充電時間の問題がある。給油なら10分の補給が、急速充電でも数十分〜数時間。
  **止まっている時間が売上を削る**商用車では、これが致命的に効く

> ポイント：乗用車のEV化は「不便を我慢できるか」の話。
> 商用車のEV化は **「その車で商売が成り立つか」** の計算。妥協の余地がない。

## 2. だから「小型・近距離」から順に進む

用途によって成立しやすさがはっきり分かれる。

| 用途 | 1日の走行 | 電動化の成立度 | 理由 |
| --- | --- | --- | --- |
| **構内・空港・港湾の車両** | 数十km | ◎ すでに実用 | 距離が短く、拠点で夜間充電できる |
| **小型配送（宅配・コンビニ）** | 50〜150km | ○ 導入が進む | ルートが決まっており、営業所に充電器を置ける |
| **ごみ収集・自治体車両** | 50〜100km | ○ 補助金と相性がよい | 公共調達で導入目標を立てやすい |
| **中型の地場配送** | 100〜250km | △ 条件次第 | 電池容量とコスト次第。補助金頼み |
| **大型の幹線輸送（長距離）** | 500〜1,000km | ✕ 現時点では困難 | 電池重量・充電時間・充電インフラのすべてが壁 |
| **ダンプ・ミキサー等の特装** | 変動 | △ | 架装の動力（PTO）にも電力が要り、電池消費が増える |

国内の実績値も、まだごく初期の段階にあることを示している。

| 指標 | 数値 | 時点・出典 |
| --- | --- | --- |
| EVトラックの普及率 | **1.06%** | 2025年3月末時点（報道・業界資料ベース） |
| EV・FCEVトラックの保有台数 | **計 4,582台** | 同上 |
| 政府の導入目標（大型・8t超） | 2020年代に **5,000台の先行導入**、2030年までに2040年の普及目標を設定 | 政府のグリーン成長戦略等 |
| 東京都の目標 | 2035年までに都内で **EVトラック7万台**、EVバス1,300台 | 東京都発表 |

※ 普及率の分母（貨物車全体か、8t以下か）で数値が変わる。**区分を確認して読むこと**。

## 3. 水素FCVの位置づけ：長距離の「本命」候補

**FCV（燃料電池車）** ＝ 水素と空気中の酸素を反応させて **車内で発電**し、モーターを回す車。
電池式（BEV）との決定的な違いは、エネルギーを「重い電池」ではなく「軽い気体」で持てること。

```
【BEV と FCV の違い（大型トラックで考える）】

 BEV：航続を伸ばす  ＝ 電池を増やす ＝ 重くなる ＝ 積載が減る
                      ▲ 航続と積載がトレードオフ

 FCV：航続を伸ばす  ＝ 水素タンクを増やす ＝ 発電装置（燃料電池）は増やさなくてよい
                      ▲ トレードオフが緩い。だから「長距離・大型ほどFCV有利」と言われる

 ただし：水素ステーションが無ければ走れない ＋ 水素の価格が高い
```

| 論点 | BEV（電池式） | FCV（燃料電池） |
| --- | --- | --- |
| 得意な領域 | 小型・近距離・定路線 | **大型・長距離・幹線** |
| 補給時間 | 数十分〜数時間 | 十数分（給油に近い） |
| 重量の効き方 | 航続に比例して重くなる | タンク増設が中心で、比較的軽い |
| インフラ | 充電器。電力網の増強が要る | 水素ステーション。**全国で数百か所規模にとどまる** |
| 燃料コスト | 電気代。深夜電力なら安い | 水素は現状で高い。量産と輸入で下がるかが鍵 |
| 現状 | 商品が出そろいつつある | 商品化が始まった段階 |

- 日本では2025年10月に日野が大型FCトラック **「プロフィア Z FCV」** を発売し、
  航続距離は **約650km** とされる。ホンダも燃料電池システムを大型トラックに載せる実証を進めている
- ただし **水素ステーションの数と水素価格**が普及の律速。
  運送会社は「自社の運行ルート上に水素が無ければ買えない」ので、拠点整備と車両導入が
  **にわとりと卵**の関係になる
- 政策的には港湾・幹線沿いに拠点を集中配置する「点から線へ」の整備方針が取られている
  （→ [水素・アンモニア](../../01_注目テーマ/06_水素・アンモニア/README.md)）

> 現実解としては当面 **「小型はBEV、大型はFCVと高効率ディーゼル／ハイブリッドの併存」**
> という見方が業界では一般的。どれか1つに収束する前提で読むと見誤る。

## 4. 排ガス規制と燃費基準：規制が買い替えを作る

商用車の需要カレンダーは、景気より **規制の施行日**で動く。
基準が変わる前に旧型を買う「駆け込み」と、その反動が繰り返される。

| 規制の種類 | 中身 | 産業への効き方 |
| --- | --- | --- |
| **排出ガス規制** | NOx（窒素酸化物）とPM（粒子状物質）の上限。日本ではポスト新長期規制以降、段階的に強化 | DPF・尿素SCRなど後処理装置が必須に。車両価格が上がり、整備需要も増える |
| **重量車燃費基準** | トップランナー方式（その時点で最も優れた車を基準にする方式）。**2025年度目標基準は2015年度基準比でトラック約13.4%、バス約14.3%の強化** | 未達だと出荷しづらくなる。電動車の扱いに特例が設けられている |
| **安全装備の義務化** | 衝突被害軽減ブレーキ、車線逸脱警報、側方衝突警報など | 標準装備化で価格が上がる。旧型を延命するより買い替え誘因が働く |
| **環境ゾーン規制** | 自治体による一定基準未満のディーゼル車の流入規制（東京都等） | 都市部で使う車の更新を前倒しさせる |
| **欧州のCO2規制** | 大型車にも企業平均のCO2削減義務。未達に罰金 | 欧州メーカーがゼロエミッション車を売らざるを得ない構造を作る |

**トップランナー方式** ＝ 市場に出ている最も優れた製品の性能を将来の基準にする仕組み。
達成できない車は事実上売れなくなるので、規制というより **開発競争の強制装置**として働く。

```
【規制が需要を波立たせる（イメージ）】

 販売台数
   ▲
   │        駆け込み
   │          ／＼
   │        ／    ＼ 反動減
   │──────        ＼────────
   │                ＼    ／
   └──────────────────────────▶ 時間
              新基準の施行日 ▲
   ▲ 「今年よく売れた」の中身が実需か駆け込みかを見分ける必要がある
```

## 5. 補助金：差額を埋めないと売れない

EVトラックはディーゼル車より **車両価格が2〜3倍**になることが多い。TCOで埋まらない差額を
公的補助で埋めるのが各国共通のやり方。

- 日本では環境省・経済産業省・国土交通省が連携する **「商用車等の電動化促進事業」** が中心。
  2025年度補正予算では **予算規模300億円**で公募が行われたと報じられる
- 仕組みは **ディーゼル車との価格差の一定割合（2/3など）を補助**する方式。
  車両と充電設備をセットで支援する枠もある
- 執行は環境優良車普及機構（LEVO）などが担い、トラック・バス・タクシーで窓口が分かれる
- 自治体の上乗せもある。東京都は2026年4月30日からEVバス・EVトラックの購入補助受付を開始した

> 注意点：補助金は **年度予算で切れる**。予算枠に達すると打ち切りや抽選になるため、
> 「補助が付く前提のTCO試算」は年度をまたぐと崩れる。
> 電動化の進捗を読むときは、車両性能より **補助金の継続性**を見るほうが当たる。

## 6. 2024年問題：需要の中身が変わった

**2024年問題** ＝ 2024年4月から、トラックドライバーの時間外労働に **年960時間の上限**が
適用されたこと。1人が走れる距離が減り、輸送能力が構造的に不足する。

| 論点 | 中身 |
| --- | --- |
| 試算 | 対策を取らない場合、営業用トラックの輸送能力が **2024年に14.2%、2030年に34.1%不足**する可能性（NX総合研究所などの推計として広く引用） |
| 起きたこと | 運賃の上昇、荷待ち時間の削減要求、中継輸送（ドライバーが途中で交代）の拡大、モーダルシフト（鉄道・船へ） |
| 2026年の続き | **2026年4月施行の改正物流効率化法**により、一定規模以上の荷主・物流事業者に効率化の取り組みが求められる（いわゆる「2026年問題」） |
| ドライバー側 | 全産業平均より労働時間が約2割長く、年収は1割程度低いという構造が続き、若手の入職が細い |

商用車メーカーから見た影響は、単なる「運送業界の話」ではない。

```
【2024年問題 → 商用車需要への波及】

 労働時間の上限
      │
      ├─▶ 運賃が上がる ──▶ 運送会社の収益改善 ──▶ 新車を買う余力が戻る ★販売増
      │                                          （2023〜2026年の販売増の背景）
      ├─▶ 1台あたりの稼ぎを最大化したい
      │        ├─▶ 大型化・トレーラ化（1回で多く運ぶ）
      │        ├─▶ 燃費・積載効率の重視 ──▶ 高付加価値車が売れる
      │        └─▶ 稼働率の追求 ──▶ ★テレマティクス・予知整備の価値が上がる
      │
      ├─▶ ドライバーが足りない ──▶ 自動運転・隊列走行への期待
      │        └─▶ 新東名で夜間のレベル4実証（メーカー4社が参画）
      │
      └─▶ 中継輸送・共同配送 ──▶ 拠点間の定路線化 ──▶ ★EVトラックと相性がよい
```

- 2026年上期の国内大・中型トラック販売が **4年連続で前年超え**となった背景には、
  運賃改善による更新需要と、規制対応の買い替えがある
- 一方、ドライバー不足そのものは解消していない。**車を売る相手（運送会社）の数が減る**
  という長期の逆風も同時に進んでいる
- 詳しくは [陸運・トラック](../../13_運輸・物流/06_陸運・トラック/README.md) と
  [宅配便](../../13_運輸・物流/07_宅配便/README.md) を参照

## 7. 自動運転：商用車のほうが先に実装される理由

- **走るルートが決まっている**（高速道路の幹線）、**夜間に走る**、**人件費削減の効果が大きい**。
  乗用車より条件がそろっている
- 日本では新東名高速道路の駿河湾沼津SA〜浜松SA間で、2025年3月から
  **夜間（22時〜5時）に第一通行帯を自動運転トラックの優先レーンとする実証**が始まった。
  いすゞ・日野・三菱ふそう・UDトラックスの4社が参画するプロジェクト（RoAD to the L4 テーマ3）
- 技術の総論は [自動運転](../../01_注目テーマ/15_自動運転/README.md) 側に置く

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **BEV** | 電池だけで走る電気自動車。商用では小型・近距離向き |
| **FCV／FCEV** | 水素で車内発電して走る燃料電池車。長距離・大型で有望とされる |
| **積載量と車両総重量の関係** | 総重量に上限があるため、車体が重くなるとその分だけ積める荷物が減る |
| **DPF** | ディーゼル微粒子捕集フィルタ。PM（すす）を捕らえて燃やす装置 |
| **尿素SCR** | 尿素水を噴いてNOx（窒素酸化物）を無害化する後処理装置 |
| **トップランナー方式** | 市場で最も優れた製品の性能を将来の基準にする規制手法 |
| **重量車燃費基準** | トラック・バス向けの燃費規制。2025年度目標は2015年度比でトラック約13.4%強化 |
| **2024年問題** | 2024年4月からのドライバー時間外労働年960時間上限による輸送力不足問題 |
| **2026年問題** | 2026年4月施行の改正物流効率化法により、荷主側にも効率化対応が求められること |
| **中継輸送** | 長距離を複数のドライバーで区間分担し、日帰り勤務を可能にする輸送方式 |
| **モーダルシフト** | トラック輸送を鉄道・船舶へ切り替えること |
