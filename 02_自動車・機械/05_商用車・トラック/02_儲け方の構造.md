# 商用車・トラック｜儲け方の構造

**このノートで分かること**：商用車メーカーは、新車を売って儲けているわけではない。
利益の柱は **売ったあとの部品・整備・サービス（アフター）** にある。
なぜそうなるのか、どういう仕掛けでその利益が守られているのかを分解する。

結論を先に書く。

```
【商用車ビジネスの利益構造（イメージ）】

           売上高                        利益への貢献
 新車販売    ■■■■■■■■■■■■■■■■■■■■■■■■   ■■■■        薄い
 部品・整備  ■■■■■■■■                       ■■■■■■■■■■  厚い
 金融・リース ■■■■                            ■■■■■       安定
 ※比率は各社・年で大きく異なる。ここは「売上の大きさと利益の厚さが逆転する」構図を示す図
```

> 押さえどころ：新車は **利益の源泉ではなく、10〜15年続くアフター収益の入場券**。
> 走っている自社の車が何台あるか（**保有台数＝パーク**）が、将来の利益をほぼ決める。

## 1. なぜ新車は薄利になるのか

商用車の新車販売が薄利になるのは、買い手が企業だから。

1. **相見積もりが標準**。運送会社の購買は4社（いすゞ／日野／三菱ふそう／UD）＋輸入車を並べる
2. **性能差が数値化される**。燃費、積載量、整備間隔は表で比較できる。感性で値段を取れない
3. **大口ほど値引きが深い**。数十台まとめ買いの単価は個別購入と大きく違う
4. **需要が景気と規制に左右される**。作りすぎても在庫を抱えられない（受注生産に近い）

一方で、原価は上がり続けている。

| 上昇要因 | 中身 |
| --- | --- |
| 部材・鋼材 | 鋼板、電子部品、樹脂の値上がり |
| 安全装備の義務化 | 衝突被害軽減ブレーキ、車線逸脱警報、側方衝突警報などの標準装備化 |
| 排ガス・燃費規制対応 | 後処理装置（DPF、尿素SCR）、電動補機の追加 |
| 人件費・エネルギー | 製造現場と販売現場の双方 |

結果として車両価格は上がる。大型トラックの新車価格は **1,500〜2,600万円**（2025〜2026年の業者相場・報道ベース、架装込み）まで来ており、
運送側では「償却が追いつかない」との声が報じられる。

## 2. アフターサービス：10年動き続ける車が生む収益

トラックは **10〜15年・50〜100万km** 使われる。走行距離が乗用車の5〜10倍なので、
消耗品の交換頻度も点検の回数も桁が違う。ここが利益の本丸になる。

```
【1台のトラックが生む収益の時間軸】

 0年           3年            6年            10年            15年
 ├─新車販売────┼──────────────┼──────────────┼───────────────┤
 │             │              │              │               │
 │ 薄利        │ 定期点検・車検（商用は毎年）                   │
 │             │ オイル・フィルタ・ブレーキ・タイヤ              │
 │             │ DPF・尿素SCR・クラッチ・バッテリー             │
 │             │ 事故修理・板金                                │
 │             │ 延長保証／メンテナンスパック                   │
 │             │              │              │ 中古車として二次流通（輸出含む）
 └─────────────┴──────────────┴──────────────┴───────────────┘
   ▲ 販売の利益      ▲───────── ここの累計が新車の利益を上回る ─────────▲
```

| 収益源 | 中身 | 特徴 |
| --- | --- | --- |
| **純正部品** | フィルタ、ブレーキ、クラッチ、電装品など | 利益率が高い。設計図と供給網を握るメーカーの独壇場 |
| **整備・車検** | 事業用トラックは**車検が毎年**（自家用貨物も初回2年・以降1年が基本） | 工賃収入。拠点が近いほど取り込める |
| **メンテナンスパック** | 定額で点検・消耗品交換を包括 | 収益が読める。ユーザーは予算が立つ |
| **延長保証** | 保証期間の上乗せ | ダウンタイム不安を金で解消する商品 |
| **リビルト部品** | 使用済み部品を再生して再販 | 安価な選択肢を純正側が用意し、社外流出を防ぐ |
| **中古車** | 下取り・買い取り・輸出 | 残価が高いほど新車の実質負担が下がる＝販売の武器 |

> なぜ車検が毎年なのか：事業用トラックは走行距離が長く、整備不良が重大事故に直結するため、
> 道路運送車両法の検査周期が自家用乗用車（初回3年・以降2年）より短く設定されている。
> **規制がそのまま整備需要を作っている**のが商用車の特徴。

## 3. 「止めない」ことを売る：テレマティクスと故障予知

運送会社にとって車が止まることは売上ゼロを意味する。
そこでメーカーは **「壊れる前に直す」** をサービス商品に仕立てた。

- **テレマティクス** ＝ 車両に通信機を積み、走行・エンジン・部品の状態を遠隔で集める仕組み
- いすゞは国内で販売するトラックに通信機能を標準装備し、
  **約44万台とつながっている**（同社発表、2026年3月30日時点）
- 集めたデータで故障の予兆を検知するのが **PREISM（プレイズム）** という高度純正整備サービス。
  2026年3月の機能強化では検知対象部品を拡大し、**突発故障を約7%低減**できるとしている（同社発表）

```
【データが利益に変わる流れ】

 車載通信機 ──▶ クラウドに蓄積 ──▶ 機械学習で予兆検知
                                        │
      ┌─────────────────────────────────┼─────────────────────────────┐
      ▼                                 ▼                             ▼
 ユーザー：突発故障が減る          販売店：入庫が計画的になる     メーカー：純正部品が売れる
 ＝稼働率が上がる                  ＝工場の稼働が平準化           ＝社外品に逃げない
      ▲ 三方が得をするので、値引き競争にならずに単価を取れる
```

- 副次効果として、**囲い込み**が効く。予兆診断は純正ネットワークでしか受けられないため、
  ユーザーは安い社外整備工場に流れにくくなる
- さらに運行データは荷主・物流のデジタル化（動態管理、配車最適化）にもつながり、
  メーカーが物流サービス側へ入り込む足がかりになる（→ [陸運・トラック](../../13_運輸・物流/06_陸運・トラック/README.md)）

## 4. ディーラー網＝参入障壁そのもの

商用車は **拠点の数と場所が競争力**。長距離幹線を走る車が故障したとき、
最寄りに自社のサービス拠点があるかどうかで購買が決まる。

| 論点 | 中身 |
| --- | --- |
| 立地 | 幹線道路沿い、インターチェンジ近く、物流団地の周辺 |
| 設備 | 大型車が入る整備ピット、部品倉庫、板金設備。**乗用車ディーラーとは施設が別物** |
| 人 | 大型車整備の資格者。人材確保が最大の制約 |
| 営業時間 | 夜間・早朝の入庫に対応（車は昼に走るため整備は夜） |
| 部品在庫 | 旧型を含む長期供給。倉庫の負担が重いが、これが乗り換え防止になる |

> 新規参入者（中国勢や新興EVメーカー）が日本市場で伸び悩む最大の理由はここ。
> **車を作れても、全国に整備網は作れない**。だから輸入商用車はまず
> 拠点の要らない用途（構内車両、定路線の小型配送）から入ってくる。

## 5. 金融：リース・レンタル・サブスクという「もう一つの本業」

| 形態 | 仕組み | ユーザー側の狙い | メーカー・金融側の狙い |
| --- | --- | --- | --- |
| **割賦・ローン** | 分割で購入 | 資産として保有 | 金利収入 |
| **ファイナンスリース** | 実質的に全額を分割で払う賃貸 | 資産計上を避け、初期負担を抑える | 与信を握って囲い込む |
| **メンテナンスリース** | リース料に整備・車検・税・保険を含む | **月額固定でTCOが読める**。管理の手間も外注 | 整備を自社網に固定できる |
| **レンタル** | 数日〜数か月の短期貸出 | 繁忙期・スポット需要、代車 | 高稼働で回収。中古市場へ出口 |
| **中古車販売・輸出** | 使用済み車両の二次流通 | 安価な調達手段 | **残価が高いほど新車リース料を下げられる** |

- 運送会社の多くは中小零細で、資金力に限りがある。**車を買うより借りる**ほうが合理的な場面が多い
- メンテナンスリースは、ユーザーには「予算が読める」、メーカーには「整備が自社に入る」という
  **利害が一致する商品**。商用車でリース比率が高いのはこのため
- 残価（数年後の中古価値）が高いことは競争力になる。日本製トラックは
  アジア・アフリカ向けの中古輸出需要が厚く、これが残価を支えている

詳細な金融側の論理は [リース](../../05_金融/10_リース/README.md)、
レンタル事業の経済性は [レンタカー・カーシェア](../../13_運輸・物流/12_レンタカー・カーシェア/README.md) も参照。

## 6. 数字で見る：メーカーの規模感（2026年時点）

| 指標 | 数値 | 時点・出典 |
| --- | --- | --- |
| いすゞ自動車 売上収益 | **3兆4,790億円**（前期比 +7.5%） | 2026年3月期、同社決算短信（IFRS） |
| いすゞ 営業利益 | **2,037億円**（同 -11.2%、利益率約5.9%） | 同上 |
| いすゞ 総販売台数 | **565,858台**（同 +8.1%）、うち国内 81,741台（+5.5%） | 同上。小型車エルフミオが国内を牽引 |
| ARCHION（日野＋三菱ふそう） 売上収益予想 | **2兆4,250億円**（増収減益予想） | 2027年3月期見通し、2026年5月14日発表 |
| 国内 普通トラック販売 | **75,689台**（前年比 +4.7%、3年連続増） | 2025暦年、日本自動車販売協会連合会ベース |
| 国内 大・中型トラック販売 | **37,374台**（前年同期比 +1.9%、4年連続増） | 2026年上期（1〜6月）、業界紙集計 |

- 営業利益率は **5〜8%あたりが標準的なレンジ**。乗用車大手ほど高くはならない
- 台数は乗用車より2桁小さいが、**単価が10倍前後**なので売上規模は数兆円になる
- 業績の振れは「国内の景気」より **海外（アジア・北米）の需要と為替、そして関税**で決まる。
  2026年3月期のいすゞは、米国関税・材料費高・中東情勢による生産混乱で減益になったと説明している

## 7. 収益の全体像（まとめ図）

```
【商用車メーカーの利益の作り方】

  ┌── 新車を売る（薄利・受注生産）
  │        │
  │        ▼ 保有台数（パーク）が積み上がる ← ここが経営指標の本体
  │        │
  ├────────┼── 純正部品・整備・車検 ……… 利益率が高い
  │        ├── メンテナンスパック／延長保証 … 収益が読める
  │        ├── テレマティクス・故障予知 …… 囲い込み＋単価維持
  │        ├── リース・割賦の金利 ………… 安定収益
  │        └── 中古・下取り・輸出 ………… 残価を作り、新車に還流
  │
  └── 拠点網（整備・部品倉庫）………… 上記すべての前提であり参入障壁

  利益 ＝ （保有台数 × 1台あたり年間アフター収益） ＋ 新車マージン ＋ 金融
```

- **KSF（成功の鍵）は保有台数の維持**。シェアを落とすと10年かけてアフター収益が細る
- 逆に言えば、いったん取った市場は簡単には崩れない。だから国内は
  いすゞ／UD陣営と日野／三菱ふそう（ARCHION）陣営の **二極構造が固定化**しやすい
  （→ [④ 直近トピック](04_直近トピック_2026.md)）

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **アフターマーケット** | 新車販売後の部品・整備・修理・用品の市場。商用車では利益の主柱 |
| **パーク（保有台数）** | 市場で稼働している自社車両の総数。将来のアフター収益の母数 |
| **ダウンタイム** | 故障・整備で車が止まっている時間。これを減らすことが商品価値 |
| **テレマティクス** | 車載通信で走行・車両状態データを遠隔収集する仕組み |
| **PREISM（プレイズム）** | いすゞの高度純正整備。データで故障の予兆を検知し、計画的に整備する |
| **メンテナンスリース** | 整備・税・保険込みの月額固定リース。TCOが読めるのでユーザーに好まれる |
| **リビルト部品** | 使用済み部品を分解・再生して再出荷する部品。純正が用意する低価格帯 |
| **残価** | 数年後の中古価値。高いほどリース料を下げられ、販売競争力になる |
| **DPF／尿素SCR** | ディーゼルの排ガス後処理装置（粒子状物質の捕集／窒素酸化物の還元）。消耗品として整備需要を生む |
