# モーターの原理と種類

モーターとは、**電気を「回す力」に変える装置**。原理はたった一つ、
「**磁界の中に置いた導線に電流を流すと力が生まれる**」という現象だけでできている。
逆に外から回してやれば発電機になる（同じ機械の使い方違い）。

このノートで分かること：なぜ回るのか、方式がなぜ何種類もあるのか、
そして **なぜモーター単体ではなく「インバータとセット」で性能が決まるのか**。
EVの駆動ユニット（eAxle）としての話は [EV・電動化 ①](../../01_注目テーマ/03_EV・電動化/01_クルマの構造がどう変わるか.md) に置いてある。

## 1. 前提：電流と磁界は力を生む

磁石のN極からS極へ向かう「磁界」の中に導線を置き、電流を流すと、
導線は**磁界にも電流にも垂直な向き**に押される（フレミング左手の法則）。力の大きさは

```
F = B × I × L
    B = 磁束密度（磁界の濃さ）  I = 電流  L = 磁界の中にある導線の長さ
```

ここから、モーター設計のほぼすべてが導かれる。

| 強くしたいもの | やること | 代償 |
| --- | --- | --- |
| B（磁界の濃さ） | 強い磁石を使う／鉄心で磁束を集める | 磁石が高い（レアアース）。鉄心は重い |
| I（電流） | 太い銅線を流す／電流を増やす | 銅が高い。発熱（銅損）が電流の2乗で増える |
| L（導線の長さ） | 巻数を増やす／モーターを長くする | 大きく重くなる。巻けるスペースには限りがある |

> つまりモーターとは「**銅と鉄と磁石をどう詰め込むか**」という材料の勝負でもある。
> 後のノートでコスト構造が材料費に強く支配される理由はここにある（→ [② 産業構造](02_産業構造とサプライチェーン.md)）。

## 2. 回り「続ける」ための工夫＝整流

導線は力を受けて半回転するが、そのまま電流を流し続けると、
今度は逆向きに押されて戻ってしまう。**回り続けるには、半回転ごとに電流の向きを切り替える**必要がある。
この切り替えを「整流（コミュテーション）」と呼び、**その方式の違いがモーターの種類そのもの**になる。

```
【ブラシ付きDC】機械で切り替える            【ブラシレスDC / 同期機】電子で切り替える

  電池 ─▶ ブラシ（炭素の接点）              電池 ─▶ インバータ（半導体スイッチ）
           │ こすれる                                │ 位置センサ or 推定
           ▼                                        ▼
        整流子（回転する接点）                    ステータ巻線に流す順番を制御
           │                                        │
           ▼                                        ▼
        巻線の電流が反転 ─▶ 回り続ける          回転磁界ができる ─▶ ロータが追いかける

  安い・簡単 / ブラシが摩耗し寿命が短い        高効率・長寿命 / 制御回路が必須
```

ここが決定的に重要で、**ブラシレス化とは「機械式スイッチを半導体に置き換えること」**にほかならない。
半導体が安くなったからブラシレスが普及した、という順番で理解するとよい
（半導体スイッチの中身は [トランジスタの原理](../../03_電機・電子部品/02_半導体（ロジック・メモリ）/04_トランジスタの原理.md) 参照）。

## 3. どんなモーターも部品構成は同じ

```
        ┌──────────── ハウジング（外枠・放熱） ────────────┐
        │  ┌────────── ステータ（固定子） ──────────┐  │
        │  │  電磁鋼板を何百枚も積んだ鉄心 ＋ 銅線の巻線   │  │
        │  │     ┌──────────────────┐        │  │
   軸受 ═╪══╪═════│  ロータ（回転子）      │════════╪══╪═ 軸受
（ベアリング）│     │  磁石 or かご型導体 or 鉄のみ │        │  （ベアリング）
        │  │     └──────────────────┘        │  │
        │  └──────────────────────────────┘  │
        └─────────────── シャフト（出力軸）──────────────┘
```

| 部位 | 役割 | 材料 |
| --- | --- | --- |
| **ステータ（固定子）** | 電流を流して回転磁界を作る側 | 電磁鋼板＋銅線＋絶縁材 |
| **ロータ（回転子）** | 磁界に引かれて回る側 | 永久磁石／アルミor銅のかご／鉄心のみ |
| **鉄心** | 磁束の通り道。渦電流を抑えるため**薄い鋼板を積層**する | 無方向性電磁鋼板 |
| **巻線** | 電流を流す導体。太く多く巻けるほど効率が上がる | 銅（一部アルミ） |
| **ベアリング** | 軸を支える。寿命と静粛性を左右する | → [ベアリング](../10_ベアリング/README.md) |
| **磁石** | 方式によっては使う。強さが出力密度を決める | ネオジム／フェライト |

## 4. 主な方式と使い分け

| 方式 | 回る仕組み | 強み | 弱み | 代表的な用途 |
| --- | --- | --- | --- | --- |
| **ブラシ付きDC** | ブラシと整流子で機械的に電流を反転 | 安い、電池直結で回る、制御が要らない | ブラシが摩耗、火花、効率が低い | 玩具、電動工具、旧来のパワーウィンドウ |
| **ブラシレスDC（BLDC）** | インバータで通電を切り替える | 高効率、長寿命、静か、小型 | 制御回路が必要でコスト増 | HDD、ファン、ドローン、家電 |
| **永久磁石同期（PMSM／IPM）** | 回転磁界にロータの磁石が同期して回る | **出力密度と効率が最高クラス** | ネオジム磁石が高価・供給リスク | EV駆動、エアコン、産業サーボ |
| **誘導（IM／かご型）** | 回転磁界がロータに電流を誘導し、その電流が力を生む | **磁石もセンサも不要で頑丈・安い** | 磁石機より効率がやや低い、すべりが必要 | 工場の汎用動力、ポンプ、送風機 |
| **同期リラクタンス（SynRM）** | 鉄が「磁束の通りやすい向き」に引かれる力だけで回る | 磁石ゼロ、高効率 | トルク脈動、力率が低い、要インバータ | 産業用ポンプ・ファン、脱レアアース用途 |
| **ステッピング** | 決まった角度ずつ刻んで回す | 位置センサなしで位置決めできる | 高速で脱調、効率が低い | プリンタ、複合機、半導体装置の搬送 |
| **ユニバーサル（整流子交流）** | ブラシ付きDCを交流でも回す | 極めて高回転が出せる、安い | 騒音、寿命が短い | 掃除機、電動工具、ミキサー |

用語の注意：「**BLDCとPMSMは物理的にはほぼ同じもの**」で、
電流波形を矩形波で流すか正弦波で流すか（＝制御の流儀）で呼び分けているだけ、という理解でよい。

### ブラシレスがなぜ勝ったのか

家電・OA・車載の小型分野は、この20年で**ブラシ付き → ブラシレス**へ大きく置き換わった。理由は3つ。

1. **効率**：ブラシの摩擦損と接触抵抗がなくなる。省エネ規制と直結する
2. **寿命**：摩耗部品がベアリングだけになる。24時間動く機器で決定的
3. **制御**：回転数を自由に変えられる。エアコンの「インバータ化」がまさにこれ

## 5. トルクには2つの生み方がある

| 種類 | 原理 | 使う方式 |
| --- | --- | --- |
| **マグネットトルク** | 磁石のN/Sが回転磁界に引かれる力 | 表面磁石型（SPM） |
| **リラクタンストルク** | 鉄が「磁束が通りやすい向き」に向こうとする力（磁気抵抗＝リラクタンスの差を利用） | SynRM |

EV駆動などに使う **IPM（磁石埋込型）** は、磁石をロータの内部に埋めることで
**両方のトルクを同時に使う**。これが「少ない磁石で高出力・広い回転域」を成立させている核心。
レアアースフリーモーターの研究は、この**リラクタンストルクの比率を上げ、磁石を減らす／弱い磁石で代替する**方向に進んでいる
（→ [④ 直近トピック](04_直近トピック_2026.md)）。

## 6. 性能を決めるのは「モーター＋インバータ」

現代のモーターは単体では性能が出ない。**電気を作って与える側（インバータ）とセットで一つの装置**である。

```
 電源 ──▶ 整流／DCリンク ──▶ インバータ ──▶ モーター ──▶ 減速機 ──▶ 負荷
 AC or 電池               パワー半導体で       回転磁界        必要なら      ポンプ／車輪／
                          任意の周波数の                      トルク増幅    ロボット関節
                          交流を合成
                              ▲
                              │ 位置・電流を読んで毎秒数千〜数万回の判断
                          制御ソフト（ベクトル制御）
```

| 制御方式 | 中身 | 使いどころ |
| --- | --- | --- |
| **V/f制御** | 電圧と周波数の比を一定に保つだけの簡易制御 | ファン、ポンプの汎用インバータ |
| **ベクトル制御** | 電流を「トルクを作る成分」と「磁束を作る成分」に分解して別々に操る | サーボ、EV駆動、高性能機 |
| **弱め界磁制御** | わざと磁石の磁束を打ち消し、高回転域まで回す | EV駆動（高速巡航時） |

押さえどころは、**同じ鉄と銅と磁石でも、制御ソフト次第で効率が数％変わる**こと。
モーターメーカーが「ソフト会社」化していく圧力はここから来る（→ [③ 市場の変化](03_市場の変化と競争構図.md)）。

## 7. 効率はどこで失われるか

投入した電気の100%が回転になるわけではない。損失は4か所に出る。

| 損失 | 正体 | 減らし方 | 代償 |
| --- | --- | --- | --- |
| **銅損** | 巻線の電気抵抗による発熱（電流の2乗に比例） | 銅線を太く・多く、占積率を上げる | 銅の使用量が増える＝高い |
| **鉄損** | 鉄心の中で磁界が反転するたびに生じる損（ヒステリシス損＋渦電流損） | 薄くて低損失な電磁鋼板を使う | 高級鋼板は高い、薄いと工数増 |
| **機械損** | ベアリングの摩擦、風損（回転体が空気をかき回す） | 低摩擦軸受、形状最適化 | 精度・コスト |
| **インバータ損** | 半導体のスイッチング損・導通損 | SiC等の高効率素子を使う | 素子が高い |

```
 入力電力 100
   ├─ 銅損     ─┐
   ├─ 鉄損      ├─ 全部「熱」になる → 冷却設計が必要
   ├─ 機械損   ─┘
   └─ 出力（軸の回転）  ← IE3級の汎用機でおおむね 90% 前後（出力帯で大きく変わる）
```

> 効率90%を92%にするために材料費が2割増える、といったことが普通に起きる。
> **効率は「買える」が、タダではない**。だから規制がないと市場は安い低効率品に流れる。次章につながる。

## 8. なぜ効率規制があるのか：モーターは電力の最大の消費者

ここがモーター産業を理解する最大の背景。

- **世界の電力消費のうち、モーター駆動システムが占める割合はおよそ45〜53%**
  （IEA の推計を各国の業界資料が引用。数字は集計範囲で幅がある）
- 日本では **産業部門の電力消費の約7割前後がモーター**とされる（JEMA 資料）
- つまり **モーター効率を1%上げることは、発電所を建てずに電力を生み出すのに等しい**

この算術が各国を規制に向かわせた。国際規格 **IEC 60034-30-1** が効率クラスを定義し、
各国がそれを自国法規に取り込む、という形で世界的にそろっている。

| クラス | 呼び名 | 位置づけ |
| --- | --- | --- |
| **IE1** | 標準効率 | 旧来の汎用誘導機。先進国では販売できないものが多い |
| **IE2** | 高効率 | 小出力・単相などに残る下限 |
| **IE3** | プレミアム効率 | 現在の世界標準。日本のトップランナー基準はほぼこの水準 |
| **IE4** | スーパープレミアム効率 | EUが一部出力帯で義務化。誘導機では到達が苦しく、PM機/SynRMが有利 |
| **IE5** | ウルトラプレミアム効率 | 次の目標。事実上インバータ＋磁石機/SynRM前提 |

| 地域 | 制度 | 内容（年） |
| --- | --- | --- |
| **EU** | 規則 (EU) 2019/1781 | 2021年7月から0.75〜1,000kWで**IE3**、2023年7月から75〜200kWで**IE4**。単相0.12kW以上はIE2。EU試算で2030年までに年100TWh超の節減 |
| **日本** | 省エネ法トップランナー制度 | 三相誘導電動機が2013年に対象機器化、**2015年4月から規制適用**。基準値はIEC 60034-30のIE3相当 |
| **米国・中国ほか** | DOE規制／GB規格 | 同様にIE3級を下限とする方向。規格番号は違うが水準は近い |

> **規制は「新品として売れるかどうか」を決める**。だから規制が一段上がるたびに、
> 設計変更と材料の入れ替え（＝誘導機から磁石機・SynRMへ）が業界規模で起きる。
> 日本のモーターは2015年度時点で約97%がIE1だったが、現在は年間出荷の約7割がIE3級に置き換わったとされる（JEMA資料）。

## 9. 用途から方式を選ぶ早見表

| 用途の要求 | 向く方式 | 理由 |
| --- | --- | --- |
| とにかく安く、たまにしか動かさない | ブラシ付きDC／ユニバーサル | 効率より初期コストが支配的 |
| 24時間回り続ける（ファン、ポンプ、冷蔵庫） | BLDC／PMSM＋インバータ | 電気代が初期コストを上回るので効率が効く |
| 大きな力を頑丈に、保守を減らしたい | 誘導機 | 磁石もセンサもなく壊れにくい。予備品も安い |
| 位置をきっちり止めたい | ステッピング／サーボ | 角度制御が本質。→ [FA・制御機器](../../03_電機・電子部品/14_FA・制御機器/README.md) |
| 小さく軽く高出力（車載、ロボット、ドローン） | IPM（PMSM） | 出力密度で他を圧倒。ただし磁石コストを飲む |
| 磁石の調達リスクを避けたい | SynRM／磁石補助SynRM／誘導機 | レアアースを使わない設計。→ [④ 直近トピック](04_直近トピック_2026.md) |

## まとめ

- モーターは「**磁界の中の電流が力を受ける**」だけの装置。種類の違いは **整流の仕方とロータの作り方**の違い
- **ブラシレス化＝機械式スイッチの半導体化**。半導体が安くなったことが普及の前提だった
- 性能は **モーター単体では決まらない**。インバータと制御ソフトまで含めて一つの商品
- 世界の電力の**半分近くをモーターが消費している**ため、効率は公共政策の対象になる。
  IEクラスの引き上げが、そのまま製品の世代交代と材料の入れ替えを起こす

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **ステータ／ロータ** | 固定子／回転子。電磁石側と回る側 |
| **整流（コミュテーション）** | 回り続けるために電流の向きを切り替えること。機械式＝ブラシ、電子式＝インバータ |
| **BLDC** | ブラシレスDCモーター。半導体で整流するDCモーター |
| **PMSM／IPM** | 永久磁石同期モーター／磁石をロータ内部に埋め込んだ型。EV駆動の主流 |
| **誘導モーター（IM）** | 回転磁界がロータに電流を誘導して回す方式。磁石不要で頑丈 |
| **SynRM** | 同期リラクタンスモーター。磁石を使わず鉄の磁気抵抗差だけで回す |
| **すべり** | 誘導機で回転磁界とロータの回転数の差。これがないとトルクが出ない |
| **リラクタンストルク** | 鉄が磁束の通りやすい向きに向こうとする力 |
| **弱め界磁** | 磁石の磁束を打ち消して高回転まで回す制御 |
| **ベクトル制御** | 電流をトルク成分と磁束成分に分けて制御する方式 |
| **銅損／鉄損** | 巻線抵抗による発熱／鉄心の磁化反転による損失 |
| **電磁鋼板** | 鉄心用の薄い鋼板。渦電流を抑えるため積層して使う → [鉄鋼](../../11_資源・エネルギー・鉄鋼金属/09_鉄鋼/README.md) |
| **IEクラス** | IEC 60034-30-1 による効率等級。IE1（標準）〜IE5（ウルトラプレミアム） |
| **トップランナー制度** | 省エネ法に基づき、市場で最も優れた機器の水準を将来の基準にする日本の制度 |
