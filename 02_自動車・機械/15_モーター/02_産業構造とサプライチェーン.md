# 産業構造とサプライチェーン

結論から言うと、**「モーター業界」という一つの市場は存在しない**。
手のひらに乗る数グラムのものから、製鉄所を動かす数万kWのものまで、
出力が6桁違う製品が同じ名前で呼ばれているだけで、**顧客も競争相手も収益構造もまるで別**である。

このノートで分かること：どの出力帯にどんな会社がいるのか、
何が原価を決めているのか、そして **なぜ磁石の話が経営課題になるのか**。

## 1. まず出力帯で切る

| 区分 | 出力の目安 | 主な用途 | 売り方 | 競争の軸 |
| --- | --- | --- | --- | --- |
| **精密小型** | 〜数十W | HDD、光ディスク、スマホの振動、カメラ、ファン、プリンタ | 機器メーカーへ**億単位の量産品**として納入 | 小型化・薄型化・単価。設計で決まり、量で勝つ |
| **小型（家電・OA）** | 数十W〜数百W | エアコン、冷蔵庫、洗濯機、掃除機、複合機、電動工具 | セットメーカーへ年次商談 | 効率・静粛性・コスト。モデルチェンジに追随 |
| **車載** | 数W〜数百kW | ミラー、シート、ワイパー、EPS、電動ポンプ、**駆動用** | Tier1として長期の型式単位供給 | 品質保証・信頼性・車両搭載性。**一度採用されると数年続く** |
| **産業用（汎用）** | 0.1kW〜数百kW | ポンプ、送風機、コンプレッサ、コンベヤ | 商社・代理店経由の**規格品在庫販売** | 価格・納期・規格適合（IEクラス）。交換需要が太い |
| **産業用（特注・大型）** | 数百kW〜数万kW | 製鉄圧延機、船舶推進、鉱山、発電所補機 | 個別設計の受注生産 | 設計力・実績・アフターサービス |
| **サーボ／制御系** | 数十W〜数十kW | 工作機械、ロボット、半導体製造装置 | 装置メーカーへ制御器とセット | 応答性・精度・ソフト。→ [FA・制御機器](../../03_電機・電子部品/14_FA・制御機器/README.md) |

> 同じ会社でもこの区分をまたぐと別事業。ニデックが「精密小型で世界一」なのと
> 「車載駆動で苦戦」しているのが同時に成立するのは、**両者が別の商売**だから。

## 2. バリューチェーン

```
【川上：材料】              【中流：部品】           【モーター製造】       【川下：機器】
                                                                        
 電磁鋼板（無方向性）──┐                                                エアコン／冷蔵庫
  日本製鉄/JFE/宝武   │    プレス・積層コア ──┐                        自動車（EPS/駆動）
                      ├──▶ 巻線・絶縁       ├──▶ 組立・着磁・検査 ──▶  ポンプ／送風機
 銅線（マグネットワイヤ）│    永久磁石（着磁前）│    ローター/ステータ       工作機械／ロボット
  古河電工/住友電工等 ─┤                     │    バランス取り            HDD／プリンタ
                      │    ベアリング ───────┤                        ドローン／DCファン
 レアアース（Nd/Dy/Tb）─┘     NSK/NTN/ミネベア │
  ★中国に集中★             ダイカスト筐体 ────┘        ＋ インバータ・制御ソフト
                                                        （別事業だがセットで売れる）
```

付加価値が集まるのは次の3か所。

1. **磁石**：ネオジム磁石は事実上の戦略物資。価格も供給も政治で動く（→ 第4章）
2. **設計（電磁界＋熱＋構造の同時最適化）**：同じ材料でどれだけ性能を出せるか
3. **インバータと制御ソフト**：モーター単体の差が縮んだ後の差別化要素（→ [③ 市場の変化](03_市場の変化と競争構図.md)）

逆に、**巻く・積む・組み立てる**という工程そのものの付加価値は薄く、人件費の安い地域へ移りやすい。

## 3. コスト構造：材料費が主役

汎用の産業用モーター1台の原価は、**おおむね6〜7割が材料費**という構造になりやすい（一般的な目安）。
磁石を使う小型高性能機では、磁石だけで原価の2〜3割を占めることもある。

| 費目 | 目安の比重 | 相場変動の要因 |
| --- | --- | --- |
| **電磁鋼板** | 材料費の3〜4割 | 鉄鋼市況。高級グレード（薄板・低鉄損）は供給元が限られる |
| **銅（巻線）** | 材料費の2〜3割 | **LME銅価格**に直結。値上がりが即、利益を削る |
| **永久磁石** | 磁石機では材料費の2〜4割 | レアアース価格と中国の輸出管理 |
| **ベアリング・軸・筐体** | 1〜2割 | → [ベアリング](../10_ベアリング/README.md)、アルミ・鋳物市況 |
| **加工・組立の労務** | 1〜2割 | 自動化の度合い。量産品ほど小さい |
| **開発・型・設備の償却** | 数％〜 | 車載・精密小型は初期投資が重く、量が出ないと回収できない |

```
【量産型モデル】精密小型・家電                【受注設計型モデル】大型・特注
 単価: 数百円〜数千円                          単価: 数百万〜数億円
 数量: 年間 数千万〜数億個                     数量: 年間 数十〜数百台
 利益: 1個あたりは極小、量で稼ぐ                利益: 1台の粗利は厚い
 リスク: 顧客のモデルチェンジで一気に消える     リスク: 設計ミス・納期遅延が致命傷
 → 工場稼働率がすべて。設備は自動化・専用機     → 技術者の頭数と実績がすべて。保守で長く稼ぐ
```

> 同じ「モーターメーカー」でも、前者は**装置産業（稼働率ビジネス）**、
> 後者は**エンジニアリング（人月とノウハウのビジネス）**。財務の読み方も変わる。

## 4. 磁石とレアアース：この業界最大の地政学リスク

高性能モーターの出力密度を支えているのは **ネオジム磁石（Nd-Fe-B）**。
現在の永久磁石で最も強く、これがなければEV駆動モーターは今のサイズに収まらない。

| 元素 | 役割 | 供給の状況 |
| --- | --- | --- |
| **ネオジム（Nd）／プラセオジム（Pr）** | 磁石の主成分。磁力そのもの | 軽希土。中国のシェアが高いが産地は比較的分散 |
| **ジスプロシウム（Dy）／テルビウム（Tb）** | **高温でも磁力が落ちないようにする添加元素**（保磁力の確保） | **重希土。中国依存が極端に高い**。車載用は高温で使うため必須級 |
| **鉄・ホウ素** | 母材 | 汎用 |

ここが急所で、EVや産業機器のモーターは **100〜180℃で使われる**ため、
重希土を減らすと磁石が熱で弱くなり、最悪は**不可逆的に減磁**する。
つまり「高温で使う高性能モーター」＝「中国の重希土に依存する」という構造になっている。

対策は3方向に分かれる。

1. **省Dy・脱Dy**：粒界拡散法などで、必要な場所にだけ重希土を効かせる
2. **リサイクル**：使用済みモーターから磁石を回収（→ [金属リサイクル](../../11_資源・エネルギー・鉄鋼金属/14_金属リサイクル/README.md)）
3. **脱レアアース設計**：フェライト磁石やSynRMで代替する（→ [④ 直近トピック](04_直近トピック_2026.md)）

資源側の詳しい構図は [レアメタル・レアアース](../../11_資源・エネルギー・鉄鋼金属/13_レアメタル・レアアース/README.md) にある。

## 6. 収益モデル：どこで儲けるか

| 稼ぎ方 | 中身 | 成立条件 |
| --- | --- | --- |
| **量産の規模効果** | 専用設備で作り込み、1個あたりの固定費を極小化 | 年間数千万個級の需要と、顧客の継続採用 |
| **カスタム設計の粗利** | 顧客の機器に合わせて最適設計し、他社が入れない状態にする | 設計工数を回収できる単価と、顧客の切り替えコスト |
| **システム販売** | モーター＋インバータ＋制御ソフト＋設計支援をまとめて売る | 制御・アプリ知識の蓄積 |
| **交換・保守（アフター）** | 産業用は故障・更新の交換需要が太い。規制更新も需要になる | 代理店網とサービス拠点、在庫 |
| **M&Aによる面の拡大** | 地域・用途ごとに強い中堅を買い集め、調達と販路を統合する | 買収後の統合能力（ここでつまずく例が多い） |

> **産業用モーターは「一度入れたら10年以上回る」**。
> だから新設需要より**更新需要（リプレース）**の方が読みやすく、
> 効率規制はその更新のきっかけを制度的に作り出している（→ [① 原理と種類](01_モーターの原理と種類.md) 第8章）。

## 7. 参入障壁とKSF（成功要因）

1. **量産設備と自動化**：巻線・積層・着磁・検査の専用ラインを作れるか。ここに数十億円規模が要る
2. **磁石・鋼板の調達力**：長期契約と複数ソース。材料が取れないと設計が成立しない
3. **設計の統合力**：電磁界・熱・振動騒音・構造を同時に解く。CAEと実測データの蓄積が効く
4. **品質保証**：車載は不良1件でリコール。工程能力の証明が取引の前提
5. **制御ソフトとアプリ知識**：「顧客の機械をどう動かしたいか」を理解している側が強い
6. **規格対応**：IEクラス、UL、CE、機能安全。規格ごとの認証取得が実質的な参入障壁

逆に言うと、**「回るモーターを作る」だけなら参入は難しくない**。
中国勢が短期間で存在感を持てたのは、量産設備と材料が国内で揃い、規格も追いついたから。

## まとめ

- 「モーター業界」は **出力帯ごとに別産業**。量産型と受注設計型では財務も競争も違う
- 原価の主役は **銅・電磁鋼板・磁石**。市況と地政学が直接に利益を削る
- **重希土（Dy/Tb）の中国依存**が、この業界最大の構造リスク
- 参入障壁は「回すこと」ではなく、**量産設備・調達力・品質保証・規格認証**の側にある

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **精密小型モーター** | 数十W以下の小型モーター。HDD、光学機器、ファン、振動用など |
| **ネオジム磁石（Nd-Fe-B）** | 現行最強の永久磁石。高性能モーターに不可欠 |
| **重希土（Dy／Tb）** | ジスプロシウム・テルビウム。高温での減磁を防ぐ添加元素。中国依存が極端 |
| **減磁** | 熱や逆向きの磁界で磁石の磁力が失われること。不可逆になると故障 |
| **粒界拡散法** | 磁石の結晶粒界にだけ重希土を拡散させ、使用量を減らす技術 |
| **積層コア** | 電磁鋼板を打ち抜いて重ねた鉄心 |
| **着磁** | 組み立て後に強い磁界をかけて磁石を磁化する工程 |
| **マグネットワイヤ** | 絶縁被膜つきの銅線。巻線用 → [電線・ケーブル](../../11_資源・エネルギー・鉄鋼金属/12_電線・ケーブル/README.md) |
| **Tier1** | 完成車メーカーへ直接納入する一次部品メーカー |
| **eAxle** | モーター＋インバータ＋減速機の一体ユニット → [EV・電動化 ①](../../01_注目テーマ/03_EV・電動化/01_クルマの構造がどう変わるか.md) |
| **更新需要（リプレース）** | 既設機器の入れ替え需要。産業用モーターの主要な需要源 |
