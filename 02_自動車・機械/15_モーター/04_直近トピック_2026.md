## 1. ニデックの会計・品質不正と第三者委員会（2025〜2026年）

業界最大の日本企業で起きているガバナンス問題。**モーター産業の技術トピックではないが、
日本のモーター産業の勢力図に直接効く話**なので最初に置く。

| 時期 | 出来事 |
| --- | --- |
| 2025年5月 | 品質に関する不適切行為の疑いが**1,000件超**発覚したと同社が公表（報道ベース） |
| 2025年内 | 会計不正の疑いで第三者委員会を設置。決算開示が遅延 |
| **2026年4月17日** | 第三者委員会の**調査報告書（最終報告）を受領**したと開示 |
| 2026年8月 | **2026年4〜6月期決算の開示が東証の期限に間に合わない**と発表。品質不正等の精査が継続中 |
| 現在 | 上場廃止リスク、株主（アクティビスト含む）との対話、旧経営陣の責任追及が論点と報じられる |

業績面では、**2026年3月期中間決算で売上高1兆3,023億円（前年同期比0.7%増）と過去最高の一方、
営業利益は211億円（同82.5%減）**。車載セグメントでの多額の引当金計上等が主因とされる。
通期予想は調査継続のため未定。

> 押さえどころ：**精密小型で世界一の会社が、車載（eAxle）で躓いている**という構図。
> ③で述べた「単価の大きい市場＝儲かる市場ではない」の実例になっている。

## 2. 中国のレアアース輸出管理と、日本向け供給の減少

モーター産業にとって2025〜2026年で最も重い外部環境。

| 時期 | 内容 |
| --- | --- |
| **2025年4月** | 中国が**サマリウム・ガドリニウム・テルビウム・ジスプロシウム・ルテチウム・スカンジウム・イットリウムの7元素**とその化合物・製品に輸出許可制を導入 |
| 2025年10月以降 | 管理対象・手続きの厳格化が進み、許可取得に時間を要する状態が続くと報じられる |
| **2026年1月** | 日本向けの**軍民両用（デュアルユース）品目の輸出禁止**措置が実施されたと報じられる |
| **2026年1〜6月** | 中国から日本へのレアアース輸出量が**前年同期比で約5割減**（日本経済新聞報道）。米国向けも約1割減 |

なぜモーターに効くのか：**テルビウム（Tb）とジスプロシウム（Dy）は、
ネオジム磁石が高温で磁力を失わないようにする添加元素**で、
EV駆動モーターや産業機器のように100℃超で使うモーターには事実上必須だから
（→ [② 第4章](02_産業構造とサプライチェーン.md)、[レアメタル・レアアース](../../11_資源・エネルギー・鉄鋼金属/13_レアメタル・レアアース/README.md)）。

```
 中国の輸出許可制
      ↓
 磁石メーカーの重希土調達が遅れる／割高になる
      ↓
 モーターメーカー：①在庫積み増し ②省Dy設計の前倒し ③脱レアアース方式の実用化を急ぐ
      ↓
 完成品メーカー：調達先の二重化、設計変更の検討
```

## 3. レアアースフリーモーターの開発が実装段階へ（2025〜2026年）

上の供給リスクを受けて、**磁石を使わない／弱い磁石で済ませる方式**の開発が加速している。
これまで研究段階だったものが、実用出力に届き始めたのが直近の変化。

| 主体 | 内容 | 時期 |
| --- | --- | --- |
| **日立Astemo** | レアアースフリーの**同期リラクタンスモーター**を開発。BEV主駆動向けには**フェライト磁石を補助的に埋め込んだ磁石補助同期リラクタンス方式**で、従来の永久磁石モーター比で**サイズ増加を30%に抑えつつ180kW**（135kW版も）を実現と発表 | 2025年10月 |
| **プロテリアル**（旧日立金属） | フェライト磁石を使ったEV駆動用モーターを試作、**最高出力約100kW**を確認。**2030年代前半の実用化**を目標 | 発表は2024〜2025年 |
| 大学・スタートアップ | SynRM の高トルク密度化、巻線界磁式（磁石を使わず電磁石で界磁を作る）などの研究が並行 | 継続中 |

技術的な壁は明確で、**フェライト磁石の磁力はネオジム磁石の約1/3**。
同じ力を出そうとすると単純には3倍の体積が要る。
そこを**リラクタンストルク（鉄が磁束の通りやすい向きに向こうとする力）の比率を上げる**ことで埋めている
（原理は [① 第5章](01_モーターの原理と種類.md)）。

> 注意点：発表された出力は**ベンチでの数字**であることが多い。
> 量産コスト・重量・効率・騒音まで含めて置き換えが成立するかは別問題で、
> 「レアアースフリーが明日から主流になる」という読み方はしない方がよい。

## 4. EV駆動用モーター／eAxleの価格競争と中国勢

| 論点 | 状況 |
| --- | --- |
| 市場規模 | NEV向け eAxle の世界市場は**2024年に約86.2億ドル、2031年に約196.6億ドル（年率12.9%）**との推計（QYResearch系。調査会社により幅がある） |
| 出力帯 | 2024年時点で**ピーク出力100〜200kW帯が市場の約71%**を占めるとの推計 |
| 中国勢 | **汇川技術（Inovance）**がEVパワートレインの主要供給者として台頭。BYD、NIO、XPeng、Li Auto などを顧客に持つと紹介されている。産業オートメーションでも世界上位入りを掲げる |
| 日本勢 | デンソー・アイシン・**BluE Nexus**（トヨタ系3社の合弁）の共同開発eAxleがトヨタ bZ4X、スズキ初のBEV「e VITARA」（2025年1月時点）などに採用。アイシンは**第2世代を2025年、超小型の第3世代を2027年**に投入する計画と報じられる |
| 技術トレンド | **800V高電圧化**、静粛性（低騒音eAxle）、モーター・インバータ・減速機のさらなる一体化 |

EV需要そのものの見通しは [EV・電動化 ⑤ 直近トピック](../../01_注目テーマ/03_EV・電動化/05_直近トピック_2026.md) を参照。
ここでの要点は、**台数が伸びても部品単価が下がるため、サプライヤーの採算は改善しにくい**こと。

## 5. AIデータセンターの冷却が新しい需要源に

2026年に入って最も勢いがある需要は、意外にも**EVではなくデータセンターの冷却**。

| 事実 | 内容 |
| --- | --- |
| 発熱量 | AI用GPUサーバーは**1台あたり10kW超**の消費電力・発熱。従来の空冷では処理しきれない |
| 技術の移行 | 空冷 → **水冷（液冷）**へ。サーバー内に冷却液を通し、CDU（冷却液分配ユニット）とポンプで循環させる |
| モーター産業への波及 | 高静圧ファン、**液冷モジュール用ポンプ**が新規需要に。ニデックはタイでのサーバー用水冷モジュールの生産能力を月産200台→2,000台規模へ拡大すると発表（報道ベース）、将来は月産3,000台以上も視野 |
| 競合 | ミネベアミツミ、山洋電気（日本電産系）、台湾ファンメーカー、米欧の熱管理企業が参入。**日本勢はファン・ベアリング・精密加工の蓄積で優位**とされる |

```
 AI投資 ─▶ GPUサーバー（1台10kW超）─▶ 発熱が空冷の限界を超える
                                          │
                                          ▼
                              サーバー内をコールドプレートで冷やす
                                          │
              ┌───────────────┴───────────────┐
              ▼                                               ▼
    冷却液を循環させるポンプ（モーター）        高静圧ファン（BLDC）
              │                                               │
              └────▶ CDU／熱交換器 ────▶ 外部へ排熱 ◀─────┘
```

> 構造として面白いのは、**AIブームがモーター産業に届く経路が「冷却」**だという点。
> 半導体が電気を食い、熱が出て、それを動かす流体を回すのはやはりモーターである。

## 6. 効率規制の次の段：IE4以降とインバータ必須化

| 地域 | 現在地 |
| --- | --- |
| **EU** | 規則 (EU) 2019/1781 により、2021年7月から0.75〜1,000kWで**IE3**、**2023年7月から75〜200kWでIE4**が義務。単相0.12kW以上はIE2。EU試算で2030年までに年**100TWh超**の電力節減効果 |
| **日本** | 三相誘導電動機は2013年にトップランナー対象機器となり**2015年4月から規制適用**、基準は**IE3相当**。JEMA資料では、2015年度時点で国内モーターの約97%がIE1だったのに対し、現在は年間出荷の約7割がIE3級へ切り替わったとされる |
| **今後** | IE5（ウルトラプレミアム）は実質的に**可変速（インバータ）＋磁石機/SynRM前提**。「モーター単体の効率」から「システム効率」へ評価軸が移りつつある |

この規制圧力の根拠が、**世界の電力消費の約45〜53%をモーター駆動システムが占める**という事実
（IEA推計を各国業界団体が引用。集計範囲により数値に幅がある）。
日本では産業部門の電力消費の約7割前後がモーターとされる。
**発電所を建てずに電力を捻出する最も安い手段**という位置づけなので、規制が緩む方向は考えにくい。

## 7. 全体の構図

- **需要は増えている**。EV駆動、省エネ規制による更新、AIデータセンターの冷却と、伸びる先が複数ある
- **しかし利益は自動的には付いてこない**。EV駆動はOEM内製と中国勢の価格競争、
  汎用産業用は規格品としての価格勝負になりやすい
- **最大の不確実性は磁石**。中国のレアアース輸出管理が2025年から段階的に強まり、
  2026年前半の対日輸出は前年同期比で半減と報じられる。設計思想そのものを動かし始めている
- **日本勢の当面の勝ち筋**は、精密小型・高信頼車載部品・サーボ・冷却という
  「制約が厳しくて量産ノウハウが効く」領域。量の勝負は取り返しにくい
- **ニデックの不正問題**は業界最大手のガバナンス問題であり、
  日本のモーター産業全体の信認と再編シナリオに影響し得る

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **第三者委員会** | 会計不正などの調査のため社外の弁護士・会計士で構成する独立委員会 |

| **磁石補助同期リラクタンスモーター（PMaSynRM）** | SynRM に弱い磁石（フェライト等）を補助的に埋め込んだ方式 |

| **CDU** | 液冷データセンターの冷却液分配ユニット |
| **800V化** | EVの駆動系電圧を高めて急速充電と効率を改善する潮流 |
| **IE4** | IEC 60034-30-1 のスーパープレミアム効率クラス |
