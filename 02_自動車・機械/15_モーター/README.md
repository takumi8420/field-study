## 1. 業界の定義・範囲

**モーター（電動機）業界＝電気エネルギーを回転運動に変える装置を作る産業**。
逆向きに使えば発電機だが、発電機は電力機器として別業界に分類されることが多い。

境界の引き方は次の通り。

| 含む | 含まない（隣接） |
| --- | --- |
| 精密小型モーター、家電・OA用小型モーター、車載モーター、産業用汎用・大型モーター、サーボモーター、ステッピングモーター | 発電機（電力機器）、変圧器、リニアアクチュエータの一部、エンジン（内燃機関） |
| モーターに付随するインバータ・ドライバ（一体で売られる場合） | 単体の汎用インバータ・PLC → [FA・制御機器](../../03_電機・電子部品/14_FA・制御機器/README.md) |
| 磁石を組み込んだアセンブリ | 磁石材料そのもの → [レアメタル・レアアース](../../11_資源・エネルギー・鉄鋼金属/13_レアメタル・レアアース/README.md) |

> **本フォルダの守備範囲**：モーターそのものの技術と産業。
> EVの需要見通し・政策・車両構造は [EV・電動化](../../01_注目テーマ/03_EV・電動化/README.md) に委ねる。

## 5. 収益モデル・コスト構造

| 論点 | 中身 |
| --- | --- |
| 原価構成 | **材料費が原価の6〜7割**になりやすい（目安）。内訳は電磁鋼板・銅・磁石が中心 |
| 相場リスク | 銅（LME）、鉄鋼市況、レアアース価格が直接に利益を削る。価格転嫁の速度が収益を左右する |
| 量産型 | 単価数百円〜数千円、年間数千万〜数億個。**工場稼働率がすべて**の装置産業型 |
| 受注設計型 | 単価数百万〜数億円、年間数十〜数百台。設計力と実績が価値。**保守で長く稼ぐ** |
| アフター | 産業用は交換・更新需要が太い。規制更新も需要のきっかけになる |
| 利益率の目安 | 汎用品は一桁台の営業利益率になりやすく、サーボ・精密小型・特注品は二桁も可能。**区分ごとに大きく違う** |

## 6. 競争要因（KSF）と参入障壁

1. **量産設備と自動化**：巻線・積層・着磁・検査の専用ライン投資
2. **材料調達力**：磁石・電磁鋼板の長期契約と複数ソース化
3. **統合設計力**：電磁界・熱・振動騒音・構造を同時に最適化するCAEと実測の蓄積
4. **品質保証**：車載は不良1件がリコール。工程能力の証明が取引の前提
5. **制御ソフトとアプリ知識**：顧客の機械をどう動かしたいかを理解している側が強い
6. **規格認証**：IEクラス、UL、CE、機能安全。地域ごとの認証が実質的な障壁

「回るモーターを作る」こと自体の障壁は低い。**障壁は量産・調達・品質・認証の側にある**。

## 7. 規制・法制度

| 地域 | 制度 | 内容 |
| --- | --- | --- |
| **国際規格** | IEC 60034-30-1 | 効率クラス IE1（標準）〜IE4（スーパープレミアム）を定義。IE5は次段 |
| **EU** | 規則 (EU) 2019/1781 | 2021年7月から0.75〜1,000kWで**IE3**、2023年7月から75〜200kWで**IE4**。単相0.12kW以上はIE2。EU試算で2030年までに年100TWh超の節減 |
| **日本** | 省エネ法トップランナー制度 | 三相誘導電動機が2013年に対象機器化、**2015年4月から規制適用**。基準はIE3相当 |
| **米国・中国ほか** | DOE規制／GB規格 | 同水準のIE3級を下限とする方向 |
| **輸出管理** | 中国のレアアース輸出許可制 | 2025年4月に7元素を許可制に。2026年1月に対日デュアルユース品目の輸出禁止措置と報じられる |

> なぜ規制するのか：**世界の電力の半分近くをモーターが消費している**から。
> 効率を1%上げることは、発電所を建てずに電力を生み出すことに等しい。
> 詳しくは [① 原理と種類 第8章](01_モーターの原理と種類.md)。

## 8. 最近のトピック

詳細と出典は [④ 直近トピック（2026年9月時点）](04_直近トピック_2026.md)。要点のみ:

- **ニデックの会計・品質不正**：第三者委員会の最終報告を2026年4月に受領、8月には26年4〜6月期決算の開示が遅延。2026年3月期中間は売上高1兆3,023億円（+0.7%）に対し営業利益211億円（−82.5%）
- **中国のレアアース輸出管理**：2025年4月に7元素を許可制、2026年1月に対日デュアルユース禁輸。**2026年1〜6月の対日輸出は前年同期比約5割減**と報じられる
- **レアアースフリーモーターが実装段階へ**：Astemoが2025年10月に磁石補助同期リラクタンス方式で180kWを発表、プロテリアルはフェライト磁石で約100kWを確認し2030年代前半の実用化を目標
- **EV駆動用は台数が伸びても採算が苦しい**：OEM内製化と中国勢（Inovance等）の価格競争。eAxle市場は2031年に約197億ドルとの推計
- **AIデータセンターの冷却が新需要**：GPUサーバーの発熱で液冷へ移行し、ファン・ポンプ・冷却モジュールの需要が急伸
