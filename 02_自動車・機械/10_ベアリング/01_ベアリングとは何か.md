# ベアリング｜ベアリングとは何か（構造と原理）

**このノートで分かること**：ベアリング（軸受）は「回る軸を支える部品」だが、
その正体は **すべり摩擦を転がり摩擦に置き換える装置** である。
なぜそれで摩擦が100分の1になるのか、どう作り分けられ、どう寿命が決まるのかを押さえる。

> ポイント：ベアリングの設計は「壊れないように作る」ではなく、
> **「いつ壊れるかを確率で決めておく」** という発想でできている。
> ここが他の機械部品と決定的に違う。

## 1. まず結論：回るものの下には必ず入っている

モーター、車輪、変速機、扇風機、ハードディスク、風力発電機の主軸、新幹線の車軸——
**軸が回る場所には例外なくベアリングが入っている**。乗用車1台におよそ100〜150個
（車種により幅がある。業界解説ベースの目安）、産業用ロボットには関節の数だけ精密軸受が入る。
それでいて1個の単価は数百円から数千円で、自動車1台に占める金額比率は1%に満たない。
一方で壊れたときの損害は大きく、風力発電機なら交換だけで数千万円級のクレーン費用がかかる。

> **安くて小さいが、止まると機械全体が止まる。**
> この非対称性が「ふだんは誰も気にしないが、壊れたときだけ最大の関心事」という購買行動を生み、
> **価格より信頼性で選ばれる**市場を作って、老舗メーカーの地位を守っている。

## 2. 転がり軸受の構造：4つの部品しかない

現在の主流である**転がり軸受**は、驚くほど単純な4部品でできている。

```
                    ＜深溝玉軸受の断面＞

        外輪（Outer Ring）＝ ハウジング側に固定され、止まっている
        ┌──────────────────────────────────┐
        │ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │
        │      ╲   ╭───╮        ╭───╮   ╱   │ ← 軌道面（レース）＝最も精度を要求される面
        │       ╲ │ ● │ ←玉→  │ ● │ ╱     │
        │  ╭────────────────────────────╮  │ ← 保持器（Cage）＝玉を等間隔に保つ
        │  ╰────────────────────────────╯  │
        │       ╱ │ ● │        │ ● │ ╲     │
        │ ▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒ │
        └──────────────────────────────────┘
        内輪（Inner Ring）＝ 軸に圧入され、軸と一緒に回る
```

| 部品            | 日本語     | 役割                                         | 材料                   |
| --------------- | ---------- | -------------------------------------------- | ---------------------- |
| Inner Ring      | **内輪**   | 軸に固定され、軸と一緒に回る                 | 軸受鋼（SUJ2など）     |
| Outer Ring      | **外輪**   | ハウジング（機械側）に固定され、止まっている | 同上                   |
| Rolling Element | **転動体** | 内輪と外輪の間を転がる。玉またはころ         | 同上、一部セラミックス |
| Cage            | **保持器** | 転動体を等間隔に保ち、ぶつからないようにする | 鋼板、樹脂、黄銅       |

このほかに、ゴム製の**シール**（異物侵入と潤滑剤漏れを防ぐ蓋）と**グリース／潤滑油**が入る。
実はこの潤滑剤が寿命の半分を決める（後述）。

> 「軌道面（きどうめん）」＝ 転動体が転がる溝（レースウェイ）。ベアリングの性能は、
> ほぼこの軌道面の**形の正確さと表面の滑らかさ**で決まる。

## 3. なぜ摩擦が劇的に減るのか

### すべりと転がりの違い

重い箱を床の上で**引きずる**のと、丸太を下に敷いて**転がす**のの違い。
ベアリングがやっているのは、後者を機械の内部でやることである。

```
【すべり軸受】軸が受け面を「こすりながら」回る
   │ ～～～～～～ │ ← 油膜（数μm）を挟んで面で支える
   │  (  軸  )   │    μ ≒ 0.001〜0.1（油膜次第で大きく変わる。起動時は跳ね上がる）

【転がり軸受】接触点が「転がって」移動する
   │  ●  ●  ●   │ ← 点または線で接触。接触点はすべらずに転がる
   │  ( 内輪 )   │    μ ≒ 0.001〜0.003（起動時もほぼ同じ）
```

摩擦係数の桁が変わるのは、次の2つが同時に効くから。
(1) **接触面積が極小になる**——面で当たるのをやめ、点（玉）または線（ころ）で当てる。
(2) **すべりが転がりに変わる**——摩擦の正体は接触面での凝着とせん断だが、
転がると接触点が次々に入れ替わるので、こすり合わせが起こらない。

ただし「狭い面積で支える」ということは、**そこに莫大な圧力がかかる**ということでもある。
玉と軌道面の接触面圧は、通常使用でも 2〜3 GPa（ギガパスカル）級に達する。
海の一番深いところの水圧のさらに数百倍という値である。

> ここが、この産業が材料の産業になる理由。
> **数GPaを何億回も受け続けて割れない鋼**を作れるかどうかが、すべての出発点になる。

### すべり軸受が消えない理由

**すべり軸受**（軸をメタルや樹脂の受けで面で支える方式）も現役で、用途で棲み分けている。

| 方式           | 得意                                                   | 苦手                                             | 代表用途                                                               |
| -------------- | ------------------------------------------------------ | ------------------------------------------------ | ---------------------------------------------------------------------- |
| **転がり軸受** | 低摩擦、起動トルクが小さい、規格品で買える             | 高荷重・低速で寿命が出ない、衝撃に弱い、音が出る | モーター、車輪、変速機、ほぼすべての回転機械                           |
| **すべり軸受** | 荷重容量が桁違いに大きい、静か、衝撃に強い、薄く作れる | 起動時に油膜が切れて摩耗、潤滑油の供給が必須     | エンジンのクランクシャフト軸受（メタル）、大型蒸気タービン、船の推進軸 |

自動車エンジンのクランク軸には今もすべり軸受（「メタル」）が使われる。
**燃焼圧という巨大な衝撃荷重**を、転がり軸受では受けきれないからである。

## 4. 玉ところの使い分け

転動体の形が、そのまま性能の性格を決める。

```
  【玉（ボール）】点接触          【ころ（ローラー）】線接触
        ○                              ▬▬▬▬▬▬
    ────●────                      ────████────
   接触＝小さな楕円               接触＝細長い帯
   → 摩擦小・高速回転向き          → 面圧が分散し高荷重に耐える
   → 荷重容量は小さい              → 摩擦大・高速には不利
```

| 型式                 | 転動体                 | 受けられる荷重                             | 得意                                                        | 代表用途                                             |
| -------------------- | ---------------------- | ------------------------------------------ | ----------------------------------------------------------- | ---------------------------------------------------- |
| **深溝玉軸受**       | 玉                     | ラジアル（横）＋少しのアキシアル（軸方向） | 最も汎用。安い・高速・低摩擦                                | モーター、家電、汎用機械。世界で最も多く作られる型式 |
| **アンギュラ玉軸受** | 玉                     | ラジアル＋アキシアル（斜めに接触）         | 高速回転しつつ軸方向も受ける。2個を組み合わせて予圧をかける | 工作機械の主軸、EVモーター                           |
| **円筒ころ軸受**     | 円筒ころ               | ラジアルに非常に強い                       | 高荷重・高速。軸方向は受けない                              | 発電機、大型モーター、鉄道車軸                       |
| **円すいころ軸受**   | テーパのついたころ     | ラジアル＋アキシアルの両方を大きく         | 荷重の向きが複合する場所の定番                              | 自動車のハブ、デファレンシャル、建設機械             |
| **自動調心ころ軸受** | 球面ころ               | 超高荷重＋軸の傾きを吸収                   | 据付誤差やたわみがある場所                                  | 製鉄圧延機、風力主軸、抄紙機                         |
| **針状ころ軸受**     | 細長いころ（ニードル） | ラジアル大。外径が小さくできる             | 場所がないところに押し込む                                  | 変速機、ユニバーサルジョイント、コンプレッサ         |

覚え方はひとつ。**速く回したいなら玉、重いものを支えたいならころ**。
その中間に、荷重の向きが複合する場所を担う円すいころがいる。（このほか軸方向専用のスラスト軸受もある）

## 5. 精度等級：ベアリングは「等級を買う」商品

同じ「内径20mm、外径47mm、幅14mm（6204という規格番号）」の深溝玉軸受でも、
**精度等級**が違えば値段が10倍以上変わる。形が同じでも別の商品である。
日本ではJIS B 1514（ISO 492に対応）で規定されている。

| 等級（JIS）       | ISO表記     | 内径寸法の許容差の目安    | 用途                                       |
| ----------------- | ----------- | ------------------------- | ------------------------------------------ |
| **0級（普通級）** | Normal / P0 | 内径20mm級で 0〜−10μm程度 | 一般機械、家電、汎用モーター。出荷量の大半 |
| 6級               | P6          | 0級より厳しい             | やや精度を要する機械                       |
| 5級               | P5          | さらに厳しい              | 高速モーター、計測機器                     |
| **4級**           | P4          | 内径20mm級で 0〜−5μm程度  | 工作機械の主軸、精密スピンドル             |
| **2級**           | P2          | 最も厳しい                | 超精密機械。ごく少量                       |

※具体値はサイズ区分ごとに規格で定められている。上表は桁感の目安。
等級が規定するのは寸法だけでなく、**回転精度**（回したときの振れ）が本質である。

> 工作機械の主軸に4級を使うのは、主軸が1μm振れると**加工品も1μmずれる**から。
> ベアリングの精度は、そのまま機械の精度の上限になる。
> → [工作機械](../07_工作機械/README.md)、[産業用ロボット](../09_産業用ロボット/README.md)

この「等級」という概念が、後発メーカーにとっての最初の壁になる。
普通級は作れても、**4級を歩留まりよく量産する**のは別次元の話だからである。
→ [作り方と品質](02_作り方と品質.md)

なお寸法自体は ISO 15 などで国際標準化されており、型番を言えば世界中で同じものが買える。

```
   6   2   04      例：6204 ＝ 内径20／外径47／幅14mm の深溝玉軸受
   │   │   └─ 内径番号（04 → 20mm。04〜96は番号×5がmm）
   │   └───── 寸法系列（2は軽荷重寄り、3は重荷重寄り）
   └───────── 形式（6＝深溝玉、7＝アンギュラ玉、N＝円筒ころ、3＝円すいころ）
```

互換性が高いので**メーカーを替えられる**が、中身の良し悪しは外から見えず、
「何年もつか」は買ったあとにしか分からない。
だから汎用の普通級は価格勝負になり、シビアな用途は実績品しか使われない——
この**二層構造**がこの市場の競争を決めている。 → [市場と儲け方](03_市場と儲け方.md)

## 6. 寿命計算：確率で設計するという考え方

### 基本定格寿命 L10

ベアリングは、異物も入らず潤滑も十分な理想的な状態でも、**いつかは必ず壊れる**。
転動体が軌道面を何億回も押し続けることで、金属の内部に微細な亀裂が生まれ、
やがて表面がうろこ状に剥がれ落ちる。これを**フレーキング（剥離）**といい、
転がり軸受の寿命はこの現象で定義されている。

そして、まったく同じロットの軸受を同じ条件で回しても、壊れる時期はばらつく。
だから業界は「平均寿命」ではなく、**確率で表す寿命**を使う。

```
  同じ軸受を100個、同じ条件で回し続ける
        ├─ 10個が壊れた時点の総回転数 ＝ 基本定格寿命 L10（信頼度90%の寿命）
        └─ 残り90個はまだ回っている
  → L10 は「10個に1個が壊れるまで」であって「そこで全部壊れる時間」ではない
```

計算式（ISO 281 / JIS B 1518）は次の形をしている。

```
    L10 = ( C / P )^p   ［単位：100万回転］

      C ＝ 基本動定格荷重（そのベアリングの体力。カタログに載っている）
      P ＝ 動等価荷重（実際にかかる荷重を換算したもの）
      p ＝ 3    （玉軸受）
          10/3 （ころ軸受）

    時間で欲しいときは
    L10h = ( 10^6 / (60 × n) ) × ( C / P )^p   ［単位：時間］
      n ＝ 回転速度（min⁻¹）
```

### この式から読み取るべきこと

指数が3（玉）や10/3（ころ）であることが、設計のすべてを支配する。

| 荷重の変化     | 玉軸受の寿命（指数3） |
| -------------- | --------------------- |
| 荷重が 0.8倍   | 約 1.95倍に延びる     |
| 荷重が **2倍** | **1/8 に縮む**        |
| 荷重が 3倍     | 約 1/27               |

> **荷重が2倍になると寿命は8分の1。** これがベアリング設計の最も重要な一行。
> 逆に言えば、荷重をわずかに下げる工夫（1サイズ大きい軸受に変える、荷重の偏りをなくす）が
> 寿命に劇的に効く。機械設計者がベアリング選定に神経を使うのはこのため。

### 実際の寿命は計算どおりにはならない

L10は理想条件の値である。現実には次の係数で補正する（修正定格寿命 Lnm）。

| 要因                           | 影響                                                                                                 |
| ------------------------------ | ---------------------------------------------------------------------------------------------------- |
| **潤滑**（油膜の厚さ）         | 油膜が転動体と軌道面を隔てられているか。粘度と回転速度で決まる。不足すると金属接触が起きて寿命は激減 |
| **異物**（コンタミネーション） | 潤滑剤に硬い粒子が混ざると軌道面にくぼみができ、そこが割れの起点になる。**現場の故障原因で最も多い** |
| **温度**                       | 高温でグリースが劣化し、鋼の硬さも落ちる                                                             |
| **取り付け**                   | 軸の傾き（ミスアライメント）、圧入の締めすぎ／緩すぎ                                                 |

現場の故障は材料疲労よりも**潤滑不良・異物混入・取り付け不良**が圧倒的に多い（各社の故障解析資料が共通して指摘する傾向）。
つまりメーカーの仕事の半分は「部品を売ること」ではなく**正しい使い方と故障原因の診断を提供すること**で、
これが補修・サービスビジネスの土台になる。 → [市場と儲け方](03_市場と儲け方.md)

## 7. 特殊な条件が要求するもの

汎用品と高付加価値品の分かれ目は「どんな過酷条件に耐えるか」にある。ここが老舗の主戦場になる。

| 条件                                     | 何が起きるか                                                                                                                               | 対策                                               |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------- |
| **高速回転**（EVモーター、工作機械主軸） | 遠心力で転動体が外輪を叩く、発熱                                                                                                           | セラミック（窒化ケイ素）製の玉で軽量化。樹脂保持器 |
| **軸電流**（EV・インバータ駆動モーター） | 内外輪の間に電位差が生じ、放電で軌道面が波状に荒れる（**電食**）                                                                           | 絶縁被膜付き軸受、セラミック玉で電気を通さなくする |
| **水素による早期剥離**                   | 潤滑油の分解などで生じた水素が鋼にしみ込み、通常より早く白い組織を伴う剥離が起きる（**白色組織剥離**）。風力や一部の自動車補機で報告される | 材料改良、表面処理、専用グリース                   |
| **超高荷重・低速**（風力主軸、圧延機）   | 油膜ができにくく金属接触。巨大サイズで材料欠陥に当たる確率も上がる                                                                         | 自動調心ころ、特殊熱処理、鋼の清浄度をさらに上げる |
| **高温・真空**（航空エンジン、半導体装置、宇宙）  | 硬さ低下、潤滑剤の劣化・蒸発                                                                                                               | 耐熱軸受鋼（M50など）、真空グリース、固体潤滑      |

[再生可能エネルギー](../../11_資源・エネルギー・鉄鋼金属/07_再生可能エネルギー/README.md)、

## 8. 用語メモ

| 用語                       | 意味                                                                           |
| -------------------------- | ------------------------------------------------------------------------------ |
| **転がり軸受**             | 内輪・外輪の間で転動体を転がして軸を支える方式。現在の主流                     |
| **すべり軸受**             | 面で油膜を介して支える方式。エンジンのクランク軸など高荷重・衝撃用途に残る     |
| **内輪／外輪**             | 軸側とハウジング側のリング。軌道面（転動体が転がる溝）を持つ                   |
| **転動体**                 | 玉（ボール）またはころ（ローラー）。点接触か線接触かで性格が変わる             |
| **軌道面（レースウェイ）** | 転動体が転がる面。ここの精度と表面品質が性能を決める                           |
| **精度等級**               | JIS B 1514 の 0級／6級／5級／4級／2級。数字が小さいほど高精度・高価            |
| **基本定格寿命 L10**       | 同一条件で回して10%が壊れるまでの回転数。信頼度90%の寿命                       |
| **フレーキング（剥離）**   | 転がり疲れで軌道面がうろこ状に剥がれる現象。軸受寿命の定義そのもの             |
| **電食**                   | 軸電流の放電で軌道面が荒れる損傷。インバータ駆動のEVモーターで問題になる       |
| **予圧**                   | 軸受にあらかじめ荷重をかけてガタをなくすこと。剛性と回転精度が上がるが発熱する |
