### 最初に押さえる一行

> **ベアリングは「すべり摩擦を転がり摩擦に置き換える装置」であり、
> その優劣は鋼の中の目に見えない不純物とミクロンの研削で決まる。**
> 単価は数百円。だが壊れると機械ごと止まる。安くて代替不能、という部品産業の典型。

## 1. 業界の定義・範囲

**回転する軸を支え、摩擦を減らす機械要素（軸受＝ベアリング）**を設計・製造する産業。
機械要素部品のなかでも、標準寸法がISOで国際的に決まっていて
「型番を言えば世界中で同じものが買える」という点に特徴がある。

| 隣接領域                                                                | 境界                                                                                                     |
| ----------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| [鉄鋼（特殊鋼）](../../11_資源・エネルギー・鉄鋼金属/09_鉄鋼/README.md) | **原料側**。軸受鋼を作って売る。鋼の清浄度がベアリングの寿命をほぼ決めるため、事実上の共同開発関係にある |
| [自動車部品](../02_自動車部品/README.md)                                | 最大の売り先。ただしベアリングメーカーは複数の完成車メーカーに横断的に売るため、系列への所属度は低い     |
| 直動部品（リニアガイド・ボールねじ）                                    | **直線運動**を支える案内。THK・IKO・NSKなどが手がけるが、回転軸受とは市場も競合も異なる                  |
| 歯車・減速機                                                            | 力を伝える側。ベアリングは支える側。ただし減速機の中にはベアリングが多数入る                             |
| シール・グリース                                                        | ベアリングの性能を左右する周辺部材。軸受メーカーがユニットとして一体化する傾向                           |
| すべり軸受（エンジンメタル）                                            | 同じ「軸受」だが、大同メタル工業などの専業がおり、技術体系も別                                           |

業界の中は、**製品で**（玉軸受／ころ軸受／ハブユニット／大型軸受）、
**売り先で**（自動車／産業機械／風力・エネルギー／鉄道・航空）、
**流通で**（OEM＝新品組付け／アフターマーケット＝補修）に分かれる。
この3軸の掛け算で考えると整理しやすい。

## 2. 市場規模と成長性

| 指標                     | 数値                                         | 出典・注記                                        |
| ------------------------ | -------------------------------------------- | ------------------------------------------------- |
| 日本の軸受完成品 販売額  | **8,202.71億円**（2025年、前年比+3.8%）      | 日本ベアリング工業会（JBIA）統計・報道ベース      |
| └ 玉軸受／ころ軸受       | 4,335.91億円（+4.4%）／3,611.63億円（+4.2%） | 同上                                              |
| 日本からの輸出額         | **4,226.54億円**（2025年、+3.9%）            | 同上。**販売額の半分超が輸出**                    |
| 世界の産業用軸受市場     | 約596億ドル（2026年）→ 約928億ドル（2031年） | Mordor Intelligence の推計                        |
| 世界のベアリング市場全体 | 2031年に約1,637億ドル                        | Astute Analytica の推計（2023年公表）。定義が広い |

- 成長率はGDP成長をやや上回る程度。**地味に伸びるが急成長はしない**
- 伸びるのは**用途**のほう。風力、ロボット、半導体装置、航空機
- **輸出比率が高い外需産業**。国内景気より海外設備投資と為替の影響が大きい
- 統計が伸びていても利益率は低いままで、**再編の動機は成長ではなく収益性**にある

      │ ★ここで鋼の清浄度が         │ ★ここでμmの精度が   │    ※利益率が高い
      │   決まる（酸素 5ppm以下）   │   決まる              │

## 5. 収益モデル・コスト構造

**この業界の利益は「どの産業に売ったか」でほぼ決まる。**

| 区分                   | 売り先         | 価格決定                             | 収益性       | 数量の性質                                       |
| ---------------------- | -------------- | ------------------------------------ | ------------ | ------------------------------------------------ |
| **自動車OEM**          | 完成車メーカー | 相見積り＋年次値下げ要求             | **低い**     | 新車生産に連動＝循環的。だが工場を埋める量が要る |
| **産業機械OEM**        | 機械メーカー   | 仕様と実績で決まる                   | 高い         | 設備投資サイクルで振れる                         |
| **風力・鉄道・航空**   | 各メーカー     | 認証と信頼性が前提。値引き圧力は弱い | 高い         | 台数は少ないが単価が巨大                         |
| **アフターマーケット** | 商社・保全部門 | 定価ベース                           | **最も高い** | 既存設備の保全需要＝安定的                       |

- 原価の**3〜4割程度が鋼材**とされ、鋼材価格の上昇が直接効く
- 残りは**減価償却・電力・人件費**という固定費。品種ごとにラインを立てるため、
  **稼働率が落ちた瞬間に利益が消える**（[タイヤ](../03_タイヤ/README.md)の加硫機と同じ構造）
- **品番数が数万点**あり、生産終了品も補修用に長く供給する。
  これが在庫と段取り替えのコストとして重く、「品番整理」が構造改革の定番テーマになる
- 日本3社の営業利益率は**おおむね4〜5%前後**。SKFの産業部門が二桁を出すのと対照的で、
  **自動車向け比率の高さが利益率の天井になっている**

→ 詳細は [市場と儲け方](03_市場と儲け方.md)

## 6. 競争要因（KSF）と参入障壁

**この業界の障壁は「金額」ではなく「年数」でできている。**

| 要因                     | 中身                                                                                                                            |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------- |
| **鋼の清浄度**           | 酸素5ppm以下の軸受鋼を安定供給できる特殊鋼メーカーが国内にいるか。寿命は鋼中の**最大の介在物1個**で決まる。後からは良くできない |
| **熱処理のノウハウ**     | 残留オーステナイト量、経年寸法変化、用途別の作り分け。正解は実機で年単位回さないと分からない                                    |
| **恒温工場と研削**       | 鋼は1℃で100mmあたり約1.17μm伸びる。4級（許容差数μm）を出すには**室温±1℃**の管理が要る                                           |
| **ばらつきの制御**       | 平均ではなく標準偏差。玉1個だけ0.5μm大きければそこから壊れる。**1億個を同じに作る**技術                                         |
| **検証に要する時間**     | 寿命は出荷前に全数検査できない。新材料の評価に数千時間                                                                          |
| **故障データベース**     | どの用途でどう壊れたかの蓄積。過去に売っていないと持ちようがない                                                                |
| **規格品ゆえのブランド** | 寸法互換があるので替えられるが、中身は外から見えない。だから実績あるブランドが選ばれ続ける                                      |

逆に**参入しやすい部分**もある。汎用の普通級は自動化ラインと標準的な鋼で作れるため、
すでに中国勢の主戦場になっている。障壁は絶対ではなく**下の層から順に削られる**。
→ [作り方と品質](02_作り方と品質.md#6-なぜ後発が追いつけないのかまとめ)

## 7. 規制・法制度

許認可で守られた産業ではない。効いてくるのは**規格・競争法・通商**の3つ。

| 制度                            | 内容                                                                                                                           |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **ISO 15／ISO 492／JIS B 1514** | 寸法系列と精度等級（0級・6級・5級・4級・2級）の国際規格。互換性を担保する一方、価格競争の土台にもなる                          |
| **ISO 281／JIS B 1518**         | 基本定格寿命（L10）の計算方法。カタログ値の根拠になる共通言語                                                                  |
| **JIS G 4805**                  | 高炭素クロム軸受鋼（SUJ2ほか）の規格                                                                                           |
| **独占禁止法（企業結合審査）**  | NSK・NTNの統合は国内トップ2の結合にあたり、**公取委の第2次審査は避けられない**との見方。事業売却が条件になる可能性が指摘される |
| **独占禁止法（カルテル）**      | 2013年に公取委がNTN・日本精工・不二越へ計約133.7億円の課徴金納付命令。EU・米・中でも制裁                                       |
| **通商（関税・原産地）**        | 米国の関税が調達・販売コストに影響。各社は売価転嫁で回収を図ると説明していると報じられる                                       |
| **航空・鉄道の認証**            | 型式認証や車両規格への適合。取得に年単位を要し、強い参入障壁になる                                                             |

## 9. 用語メモ

各ノート末尾にも用語メモがある。ここでは最重要の8語だけ。

| 用語                           | 意味                                                                                                                   |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------- |
| **転がり軸受／すべり軸受**     | 転動体を転がして支えるか、油膜を挟んで面で支えるか → [ベアリングとは何か](01_ベアリングとは何か.md)                    |
| **内輪・外輪・転動体・保持器** | 転がり軸受を構成する4部品 → [ベアリングとは何か](01_ベアリングとは何か.md)                                             |
| **精度等級**                   | JIS B 1514の0級／6級／5級／4級／2級。数字が小さいほど高精度・高価 → [ベアリングとは何か](01_ベアリングとは何か.md)     |
| **基本定格寿命 L10**           | 同条件で回して10%が壊れるまでの回転数。**荷重2倍で寿命1/8（玉軸受）** → [ベアリングとは何か](01_ベアリングとは何か.md) |
| **フレーキング（剥離）**       | 転がり疲れで軌道面がうろこ状に剥がれる現象。寿命の定義そのもの → [ベアリングとは何か](01_ベアリングとは何か.md)        |
| **非金属介在物／酸素量**       | 鋼中の微小な不純物。**最大の1個**が寿命を決める。5ppm以下が現在の高品質水準 → [作り方と品質](02_作り方と品質.md)       |
| **超仕上げ**                   | 研削痕を除き表面をRa 0.02μm級にする最終工程 → [作り方と品質](02_作り方と品質.md)                                       |
| **電食**                       | インバータ駆動モーターの軸電流で軌道面が荒れる損傷。EVで問題化 → [ベアリングとは何か](01_ベアリングとは何か.md)        |
