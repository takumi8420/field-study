# ベアリング｜市場と儲け方

**このノートで分かること**：ベアリングは誰に売られ、どこで利益が出るのか。
「自動車向けは数量が出るが儲からない、産業機械と補修が儲かる」という構図と、
**世界4強＋日本3社**という競争の形、そしてEV化で何が増え何が減るのかを押さえる。

> ポイント：ベアリングメーカーの利益は、**どの産業に売ったか**でほぼ決まる。
> 同じ部品を作っていても、自動車向けと産業機械向けでは利益率が数倍違う。
> だから「自動車依存度をどう下げるか」が全社共通の経営テーマになる。

## 1. 需要先：4つの顔を持つ

```
                  ┌──────────────────────┐
                  │  ベアリングメーカー  │
                  └──┬────┬────┬────┬───┘
      ┌──────────────┘    │    │    └──────────────┐
      ▼                   ▼    ▼                   ▼
 ┌──────────┐   ┌──────────────┐ ┌────────────┐ ┌────────────┐
 │  自動車  │   │  産業機械    │ │ 風力・発電 │ │ 鉄道・航空 │
 │ 数量が最大│  │ 利益率が高い │ │ 単価が巨大 │ │ 認証が壁   │
 │ 値引き圧力│  │ 品番が膨大   │ │ 中国勢参入 │ │ 補修が長期 │
 └──────────┘   └──────────────┘ └────────────┘ └────────────┘
  ハブ、変速機、   工作機械、ロボット、 主軸、増速機、  車軸、主電動機、
  モーター、補機   建機、鉄鋼、半導体   ヨー・ピッチ    ジェットエンジン
```

| 需要先               | 数量 | 単価       | 利益率   | 性格                                                                   |
| -------------------- | ---- | ---------- | -------- | ---------------------------------------------------------------------- |
| **自動車**           | 最大 | 低い       | **低い** | 完成車メーカーからの年次値下げ要求（コストダウン）が常態。量産品質が命 |
| **産業機械・FA**     | 中   | 中〜高     | **高い** | 品番が膨大で代替されにくい。設備投資サイクルで振れる                   |
| **風力・エネルギー** | 小   | 非常に高い | 中〜高   | 1個数百万〜数千万円級もある。交換コストが巨額なので信頼性が最優先      |
| **鉄道・航空**       | 小   | 高い       | 高い     | 認証取得に年単位。いったん入れば長く使われる                           |

→ [産業用ロボット](../09_産業用ロボット/README.md)、[工作機械](../07_工作機械/README.md)、
[建設機械](../06_建設機械/README.md)、[鉄道車両](../14_鉄道車両/README.md)、
[航空機・防衛](../13_航空機・防衛/README.md)、[再生可能エネルギー](../../11_資源・エネルギー・鉄鋼金属/07_再生可能エネルギー/README.md)

### なぜ自動車向けは儲からないのか

1. **買い手の力が強い**。完成車メーカーは年間数千万個を買う。相見積もりと年次値下げが前提
2. **仕様が標準化されている**。ハブや変速機の軸受は各社が作れるため差別化しにくい
3. **数量が読めるぶん、価格が詰められる**。長期契約で量を保証する代わりに単価を下げる

それでも自動車をやる理由は、**工場を埋める数量が要るから**。装置産業なので稼働率が落ちると
固定費を賄えない（→ [作り方と品質](02_作り方と品質.md)）。
この構図は [タイヤ](../03_タイヤ/README.md) の「OEは薄利、REPで稼ぐ」と似ているが、
ベアリングには**タイヤほど強い交換需要がない**（後述）。そこが決定的に違う。

## 2. 新品（OEM）と補修（アフターマーケット）

| 区分                           | 売り先                                     | 価格                       | 利益率   | 数量の性質                           |
| ------------------------------ | ------------------------------------------ | -------------------------- | -------- | ------------------------------------ |
| **OEM（新品組付け）**          | 機械メーカー・完成車メーカー               | 相見積り・年次値下げ       | 低い     | 新規生産に連動。景気で大きく振れる   |
| **アフターマーケット（補修）** | 商社・機械工具商・エンドユーザーの保全部門 | 定価ベース。値引きは小さい | **高い** | 既存設備の保全需要。景気に対して安定 |

補修市場は、ベアリングメーカーにとって**利益の安全弁**である。

```
   新車・新設備の生産 ──▶ OEMベアリング（薄利）──▶ 機械が10年、20年動く
                                                          │
                                       ┌──────────────────┴──────────────────┐
                                       ▼                                     ▼
                              定期交換・故障交換                    状態監視サービス
                              （アフター＝厚利）                （センサ内蔵軸受、診断）
```

ただし自動車では**補修比率がタイヤほど高くならない**。タイヤは3〜5年で必ず減って交換されるが、
**ベアリングは正しく使えばクルマの寿命まで持つよう設計されている**からである（消耗品ではない）。
その代わりに補修が効くのは**産業機械・鉄道・風力**の側。設備は20年、30年と使われ、
その間ベアリングは何度も交換される。**保全計画を握っているか**が商売の分かれ目になる。

### サービス化の方向

大手が伸ばそうとしているのは、部品販売の外側にある領域である。

| サービス                               | 中身                                               | なぜ効くか                                                           |
| -------------------------------------- | -------------------------------------------------- | -------------------------------------------------------------------- |
| 状態監視（CBM）                        | 振動センサで軸受の異常を早期検知し、壊れる前に交換 | 計画外停止のコストが部品代より桁違いに大きい                         |
| 軸受の再生（リマニュファクチャリング） | 大型軸受を分解・研磨・再組立して再使用             | 大型は新品が高く納期も長いため、再生に経済性がある                   |
| 故障解析・設計支援                     | 壊れた軸受を解析し、原因と対策を提示               | 現場故障の多くは潤滑・異物・取付けが原因。ここに入り込むと指名が続く |

> ベアリングメーカーが「部品屋」から抜け出そうとするとき、
> 必ず通るのが**保全（メンテナンス）への侵入**である。
> 部品単体の値段は下がるが、止めないことの価値は下がらない。

## 3. 市場規模

定義（転がり軸受のみか、直動やユニットを含むか）で大きく変わるため、幅を持って見る。

| 指標                     | 数値                                         | 出典・注記                                         |
| ------------------------ | -------------------------------------------- | -------------------------------------------------- |
| 日本の軸受完成品販売額   | **8,202.71億円**（2025年、前年比+3.8%）      | 日本ベアリング工業会（JBIA）統計。報道ベースで確認 |
| └ 玉軸受                 | 4,335.91億円（同 +4.4%）                     | 同上                                               |
| └ ころ軸受               | 3,611.63億円（同 +4.2%）                     | 同上                                               |
| 日本からの輸出額         | **4,226.54億円**（2025年、同 +3.9%）         | 同上。**販売額の半分以上が輸出**という外需産業     |
| 世界の産業用軸受市場     | 約596億ドル（2026年）→ 約928億ドル（2031年） | Mordor Intelligence の推計。定義は「産業用」       |
| 世界のベアリング市場全体 | 2031年に約1,637億ドル                        | Astute Analytica の推計（2023年公表）。定義が広い  |

> 日本の軸受産業は **売上の半分超を輸出している**。したがって為替と海外設備投資の影響を強く受け、
> 国内統計だけを見ていても業績は説明できない。

成長率そのものは世界のGDP成長を少し上回る程度の「地味な成長産業」で、
急成長するのは風力・ロボット・半導体装置といった**特定用途のニッチ**に限られる。

## 4. 世界4強＋日本3社という構図

**欧州2社（SKF・Schaeffler）＋日本3社（NSK・NTN・ジェイテクト）＋米Timken** が世界の上位を占め、
その下に中国勢と、ミネベアミツミのような特定分野特化型が広がる、という二層構造になっている。

| 企業                         | 立ち位置     | 特徴                                                                                                         |
| ---------------------------- | ------------ | ------------------------------------------------------------------------------------------------------------ |
| **SKF**（瑞）                | 世界最大手級 | 産業用が主力で高収益。自動車部門は売上の約3割を占めるが利益は約1割にとどまり、2026年に分離上場を目指すと発表 |
| **Schaeffler**（独）         | 同規模       | INA・FAG・LuKブランド。2024年にVitesco（パワートレイン電動化）を統合し自動車依存が高い複合体に               |
| **日本精工（NSK）**          | 世界上位     | 自動車・産業機械の両輪。精密機器（ボールねじ等）も。2026年5月にNTNとの経営統合で基本合意                     |
| **NTN**                      | 世界上位     | ハブベアリング（車輪軸受）で世界有数。等速ジョイント（ドライブシャフト）も主力                               |
| **ジェイテクト**             | 総合         | 軸受（KOYO）に加え電動パワーステアリングと工作機械。トヨタ系                                                 |
| **Timken**（米）             | 特化型       | 円すいころ軸受の草分け。産業用・鉄道・航空。M&Aで駆動部品にも展開                                            |
| **ミネベアミツミ**（日）     | ニッチ特化   | **ミニチュア・小径ボールベアリングで世界シェア上位**（同社開示で約6割水準とされる）。HDD・小型モーター向け   |
| **THK／日本トムソン（IKO）** | 隣接         | **直動（リニアガイド・ボールねじ）**が主戦場。回転ではなく直線運動を支える                                   |

### 日本勢が強い理由と、弱い理由

| 強い理由                                                                  | 弱い理由                                                     |
| ------------------------------------------------------------------------- | ------------------------------------------------------------ |
| 国内に高清浄度の軸受鋼メーカーがいる → [作り方と品質](02_作り方と品質.md) | **自動車向け比率が高い**。低収益事業に経営資源が縛られている |
| 自動車の量産品質で鍛えられ、ばらつきが小さい                              | 国内自動車生産の縮小が直撃する                               |
| 品番数が多く、補修まで面倒を見る商習慣                                    | 品番の多さが在庫・段取りコストとして重くのしかかる           |
| ハブ・等速ジョイントなどユニット化で付加価値を出せる                      | EV化でエンジン・変速機向けの需要が構造的に減る               |

**SKFが自動車を切り離し、日本勢が自動車で消耗している**——この差が2026年の再編を理解する補助線になる。

## 5. 収益性の実際

2026年3月期（2025年度）の日本3社の数字は、構造改革の効果が出始めた局面と読める。

| 企業            | 2026年3月期 売上高 | 同 営業利益 | 前期比 | 出典                                                         |
| --------------- | ------------------ | ----------- | ------ | ------------------------------------------------------------ |
| 日本精工（NSK） | 約9,116億円        | 約388億円   | +36.4% | 各社開示・報道ベース                                         |
| NTN             | 8,263億円          | 310億円     | +35.2% | NTN 決算短信（2026年5月14日）                                |
| ジェイテクト    | ─                  | 約248億円   | −35.4% | 報道ベース。軸受以外（ステアリング・工作機械）の比重が大きい |

営業利益率で見ると**おおむね4〜5%前後**で、製造業として決して高くない。
SKFの産業部門が二桁の利益率を出すのと対照的で、
**自動車向けの比率の高さが利益率の天井になっている**ことがよく表れている。

```
   ＜同じ部品を作っていても利益率が違う理由＞

   産業機械向け ── 品番が多く、代替しにくく、値引き圧力が弱い ──▶ 利益率 高
        ↑ ここを増やしたい、というのが各社共通の戦略
   自動車向け  ── 量は出るが、年次値下げと相見積もり ──────────▶ 利益率 低
```

### コストと価格転嫁

原価の3〜4割程度が鋼材とされるため**鋼材価格の上昇は直接効く**。転嫁のしやすさは売り先で非対称。

| 売り先                         | 転嫁のしやすさ                           |
| ------------------------------ | ---------------------------------------- |
| アフターマーケット（商社経由） | 比較的しやすい。定価改定で通る           |
| 産業機械メーカー               | 交渉次第。代替が難しい品番は通りやすい   |
| **完成車メーカー**             | **最も難しい**。契約期間中は動かしにくい |

近年は米国の関税負担も加わり、各社は売価転嫁で回収を図っていると報じられている。

## 6. カルテル事件という教訓

**2013年3月、公正取引委員会はベアリングの価格カルテルで、
NTN・日本精工・不二越の3社に排除措置命令と総額約133億6,587万円の課徴金納付命令を出した。**

| 項目         | 内容                                                                               |
| ------------ | ---------------------------------------------------------------------------------- |
| 対象         | 産業機械用軸受および自動車用軸受の販売価格                                         |
| 行為の時期   | 2010年5〜8月に会合を持ち、値上げを合意したとされる                                 |
| 合意内容     | 産業機械向けで8〜10%、自動車向けで鋼材1kgあたり20円の値上げ                        |
| 課徴金       | NTN 約72億3,100万円／日本精工 約56億2,500万円／不二越 約5億900万円                 |
| ジェイテクト | カルテルに関与したが、**課徴金減免制度（リーニエンシー）**により命令対象から外れた |

日本だけでは終わらず、EU・米国・中国でも自動車部品カルテルの一環として制裁が科され、
米国では民事訴訟（クラスアクション）も提起された。中国の国家発展改革委員会は2014年、
日系自動車部品メーカー各社に計12億3,540万元の制裁金を科している。

### 何が教訓なのか

この事件は「悪い会社があった」という話に留まらず、
**なぜこの業界でカルテルが起きやすかったのか**という構造の話として読むべきである。

| 構造要因                     | カルテルを誘発する理由                                           |
| ---------------------------- | ---------------------------------------------------------------- |
| 商品が標準化されている       | 差別化しにくく、価格でしか競えない                               |
| プレイヤーが少数             | 顔が見える。合意が成立しやすく、裏切りも検知しやすい             |
| 原材料（鋼材）が共通         | コスト増が全社に同時に来るため「一緒に上げよう」の動機が生まれる |
| 買い手が強い                 | 単独で値上げを言い出すと採用を外される恐怖がある                 |
| 業界団体・情報交換の場が多い | 接触の機会が制度的に存在する                                     |

つまり **「値上げしたいが単独では通らない」という構造的な苦しさ**が背景にある。
1970年代にも同種の事件があったと報じられており、繰り返された点が批判された。

> 教訓は、コンプライアンス研修を増やすことではなく **価格でしか競えない商売から抜け出すこと**。
> 各社がユニット化（ハブユニット、センサ内蔵軸受）、産業機械シフト、サービス化へ向かうのは、
> 企業戦略であると同時に**構造的な必然**でもある。

## 7. EV化で何が増え、何が減るか

最も誤解されやすいのがここ。「EVになればモーターが要るからベアリングは増える」は
**半分しか合っていない**。

```
   ＜内燃機関車 → EV でベアリング需要がどう動くか＞

   【消える・減る】                  【残る】             【増える・変わる】
   エンジン（クランク・カム・        ホイールハブ ×4      駆動モーター軸受
     タイミング系・ターボ）          ステアリング         （高速・電食対策）
   多段変速機（AT/MT/CVT）           サスペンション       減速機（1〜2段）軸受
   補機ベルト駆動の発電機・          ブレーキ周り         熱マネ用ウォーターポンプ
     エアコンコンプレッサ                                 eアクスル一体ユニット
        ▼                                                      ▼
   点数は減る方向                              1個あたりの単価は上がる方向
```

| 項目               | ICE車            | EV                  | 含意                                                     |
| ------------------ | ---------------- | ------------------- | -------------------------------------------------------- |
| エンジン関連の軸受 | 多数             | **ゼロ**            | ターボ・カム・クランク周りの需要は消滅する               |
| 変速機の軸受       | 多段変速機に多数 | 減速機は1〜2段      | **点数が大きく減る**                                     |
| 駆動モーターの軸受 | 補機モーターのみ | 主駆動モーター      | 高速回転（2万rpm級）・電食対策が必要で**高単価・高難度** |
| ホイールハブ       | 4個              | 4個（電池で車重増） | **大型化・高荷重化**し単価は上がる                       |
| 熱マネジメント系   | 少ない           | 電動ポンプが増える  | 小径軸受の需要増                                         |

したがって EV化は **「数量は減るが単価と技術要求は上がる」** 置き換えとして起きる。
数量減を単価と新規用途で埋められるかが各社の勝負で、NTN経営陣が
「EV化の中でシェアが低下する製品分野がある」と述べたのはこの文脈である。
→ [EV・電動化](../../01_注目テーマ/03_EV・電動化/README.md)、[モーター](../15_モーター/README.md)

### 新しい成長領域

| 領域                         | 何が要るか                                                      | 状況                                                                                      |
| ---------------------------- | --------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| **風力発電**                 | 主軸・増速機・ヨー／ピッチ用の大型軸受。1個で数百万〜数千万円級 | 洋上化で大型化。中国勢が国内シェアを固め、欧州メーカーにも供給し始めたと報じられる        |
| **ヒューマノイド／ロボット** | 薄肉軸受、クロスローラー、フレキシブル軸受（波動歯車用）        | 市場はまだ小さいが伸び率が大きい。QYResearchの推計で2025年約3,380万ドル→2032年約8.7億ドル |
| **半導体製造装置**           | 真空対応、超精密、クリーン                                      | 単価が高く、認定されると長く使われる                                                      |
| **航空機**                   | 耐熱軸受鋼、厳格な認証                                          | 参入障壁が極めて高い。長期の補修需要                                                      |

→ [産業用ロボット](../09_産業用ロボット/README.md)、[ロボット](../../01_注目テーマ/09_ロボット/README.md)

## 8. この産業の要点を5行で

1. **回るものには必ず入る代替不能な部品**。しかし単価は安く、ふだんは誰も気にしない
2. 利益は「どの産業に売ったか」でほぼ決まる。**自動車は薄利、産業機械と補修が厚利**
3. 参入障壁は材料（鋼の清浄度）と時間（寿命検証）。**金額より年数を要求する壁**
4. ただし壁は絶対ではなく、**汎用品から順に中国勢に削られている**
5. EV化は「数量減・単価増」の置き換え。**自動車依存を下げられるかが各社の生死を分ける**

## 9. 用語メモ

| 用語                                 | 意味                                                                                    |
| ------------------------------------ | --------------------------------------------------------------------------------------- |
| **OEM（新品組付け）**                | 機械・車両の新規生産に組み込まれる軸受。数量は出るが薄利                                |
| **アフターマーケット（補修）**       | 既存設備の交換需要。商社・機械工具商を経由し、利益率が高い                              |
| **ハブベアリング（車輪軸受）**       | 車輪を支える軸受。シールやセンサを組み込んだユニット化が進み単価が上がった              |
| **等速ジョイント（CVJ）**            | ドライブシャフトの自在継手。NTNなど軸受メーカーの主力製品でもある                       |
| **直動（リニアモーション）**         | 回転ではなく直線運動を支える案内。リニアガイド、ボールねじ。THK・IKO・NSKなどが手がける |
| **CBM（状態基準保全）**              | 振動などを監視して壊れる前に交換する保全方式。軸受メーカーのサービス化の中心            |
