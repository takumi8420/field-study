① 船はどう作られ、どう売れるか

自動車・機械造船・重機
あこのページの単語集用語に触れると意味を確認できます14語
船主（オーナー）用船（ようせん）ブロック搭載艤装（ぎそう）進水海上試運転厚板（あつばん）新造船価指数手持ち工事量バルカーPCTC二重船殻（ダブルハル）為替予約

このノートで分かること：1隻の船が契約から引渡しまで2〜3年かけてどう作られるか、
船の種類ごとに商売がどう違うか、そして受注時に価格が固定されることが
鋼材高と為替でどんな損益を生むか。

結論を先に：造船は「作ってから売る」産業ではなく、「売ってから作る」産業。
売値は契約したその日に確定し、原価はそのあと2〜3年かけて発生する。
この時間差こそが、造船が好況でも赤字になる理由であり、業界再編と国策支援の根本原因である。

1. 誰が誰に売るのか

船を発注するのは海運会社だけではない。日本では船主（オーナー）という層が厚い。

  造船所 ──建造──▶ 船主（船を保有する会社）──貸す（用船）──▶ 海運会社 ──運ぶ──▶ 荷主
                      ・愛媛など地方のオーナー群              ・日本郵船/商船三井/川崎汽船    ・メーカー
                      ・ギリシャ船主                          ・マースク/MSC/CMA CGM          ・商社
                      ・リース会社（中国系が急拡大）                                          ・資源会社
                            ▲
                            │ 建造代金の7〜8割を借りる
                      船舶金融（銀行・リース・輸出信用機関）
  • 船主は不動産オーナーに近い。船を持ち、海運会社に期間を決めて貸し（＝用船）、用船料を受け取る
  • 造船所の実際の顧客は、海運会社よりも船主・リース会社であることが多い
  • 近年は中国のリース会社が船主として台頭し、「中国の金融が中国の造船所に発注する」循環ができている。
    これが中国のシェアを押し上げる一因とされる
  • 海運側の事情は 海運 を参照

2. 建造工程：切って、積んで、組む

船は「巨大なプラモデル」に近い。ブロック（船体の部分）を地上で作ってから、ドックで積み上げる。

①基本設計・詳細設計   船主の要求（船型・速力・燃費・積載量）を図面にする
        │              3〜12か月。ここが詰まると着工できない
        ▼
②鋼材切断（マーキン）  厚板をNC切断機で部品に切り分ける
        │              ここで初めて鋼材を買う ＝ 契約から半年〜1年後
        ▼
③小組立・ブロック建造  部品を溶接して数十〜数百トンのブロックにする（工場内）
        │              床面積と門型クレーンの能力が生産能力を決める
        ▼
④搭載（ドック）        ブロックをドックで積み上げ、船の形にする
        │              大型クレーンで数百トンを吊る。ここがボトルネック
        ▼
⑤艤装（ぎそう）        配管・電線・機関・航海機器を据え付ける
        │              工数の山場。手戻りが出ると一気に赤字化する
        ▼
⑥進水                  ドックに注水して船を浮かべ、岸壁に移す
        │              ドックが空く ＝ 次の船の搭載が始められる
        ▼
⑦海上試運転・引渡し    速力・燃費・機器を実海域で確認し、船級の検査を受けて船主へ
                        契約から通常 2〜3年

なぜ工程を先に地上でやるのか：ドックは数が限られた最大の設備。
ドックを使う時間（搭載〜進水）を短くするほど、同じ設備で年に何隻作れるかが増える。
そのため各社は「ブロックを大きくして、艤装を地上で済ませてから積む」方向へ改善を重ねてきた。

協力会社（社外工）が現場の大半という点も重要。溶接・塗装・配管の多くは協力会社が担う。
つまり造船所の生産能力は自社の設備だけでなく、地域の協力会社が何人動員できるかで決まる。

3. 支払いと資金の流れ

契約時   着工時   ブロック   進水時          引渡し時
 10%  →  10%  →   10%   →   10%   ───────▶  60%
 ▲                                            ▲
 前受金は小さい                        代金の大半はここ
 （近年は前払い比率が上がる傾向）
      ← ── この間、造船所が原価を立て替える ── →
  • 分割払いだが、重心は引渡し時にある（「ヘビーテール」と呼ばれる）
  • したがって造船所は建造期間中、鋼材代と人件費を自腹で回す運転資金が要る
  • 船主側も同様で、建造代金の大半は銀行借入。金利が上がると発注が鈍る
  • 会計上は工事進行基準で売上を立てるが、見積総原価が上振れした期に一括して損失を計上する。
    これが「ある日突然の巨額損失」として表に出る

4. 船種：同じ「船」でも別の商売

船種 運ぶもの 特徴 商売としての性格
バルカー（ばら積み船）鉄鉱石、石炭、穀物構造が単純。箱に近い量産品。価格勝負で中国が最も強い。日本の中堅が得意としてきた領域
タンカー原油、石油製品、ケミカル二重船殻など安全規制が厚い中程度。韓国・中国が主力
コンテナ船雑貨（コンテナ）大型化競争。速力と燃費が命1隻が大きく金額も大きい。韓国・中国が主戦場
LNG船液化天然ガス（−162℃）極低温タンクが心臓部。技術と実績の壁が高い高付加価値。韓国が圧倒的。日本は再参入を狙う領域
自動車船（PCTC）完成車多層のデッキ、荷役ランプ日本勢が伝統的に強い。発注元が日本の海運会社
フェリー・客船人内装・電装が膨大工数が読めず赤字リスクが最大。日本の大手は撤退済み
艦艇（護衛艦・潜水艦）—防衛省・官公庁が発注市況と無関係。国内の安定財源 → 航空機・防衛

LNG船がなぜ特別か：−162℃の液体を運ぶタンクは、素材・断熱・溶接のすべてが別物。
事故時の損害が巨大なため、船主は建造実績のない造船所に発注しない。
結果、実績を持つ韓国3社に発注が集中し、後発は入れない。実績が参入障壁そのものになっている。
→ LNG

5. 船価はどう決まるか — 海運市況との連動

船の値段（船価）は、造船所の原価から積み上がるのではなく、需給で決まる市況価格である。

 荷動きが増える ──▶ 運賃が上がる ──▶ 海運会社・船主が儲かる
                                            │
                                            ▼
                                     「船を増やそう」＝ 発注
                                            │
                                            ▼
                     造船所のドックが埋まる ──▶ 船価が上がる
                                            │
                                            ▼（2〜3年後）
                     船が大量に竣工 ──▶ 船腹（船の供給）が増える
                                            │
                                            ▼
                     運賃が下がる ──▶ 発注が止まる ──▶ 船価が下がる
  • 遅れて効くフィードバックが周期的な過不足を生む。造船が「サイクル産業」と呼ばれる理由
  • 指標としてはClarksons社の新造船価指数（Newbuilding Price Index）が使われる。
    2026年5月末で185.01（前月比+1.6pt）。2024年第3四半期のピーク189.69からはやや軟化（報道ベース）
  • 2021年5月の136.14と比べると約36%高い水準で、船価そのものは高止まりしている（2026年時点）
  • 契約は米ドル建てが主流。日本の造船所にとっては、受注時と引渡し時の為替差がそのまま損益になる

6. ここが核心：受注時に価格が固定されるということ

契約書にサインした日に売上が確定し、原価はそのあと2〜3年かけて発生する。
値上げ交渉の余地は原則としてない（物価スライド条項が付くことは稀）。

       契約日                    鋼材調達                      引渡し
        │                          │                             │
売値：  ●━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━●  固定（ドル建て）
        │                          │                             │
原価：  │                    ┌─────┴─────┐                       │
        │                    │ 鋼材 約49%  │ ← ここが上がると即赤字
        │                    │ 機器 約23%  │ ← 輸入品は円安で上がる
        │                    │ 労務 約23%  │ ← 人手不足で単価上昇
        │                    └───────────┘                       │
        └───────────── 2〜3年 ───────────────────────────────────┘

鋼材が上がるとどうなるか

  • 造船用厚板は鉄鋼メーカーと半年ごとに価格交渉して決まる。2022年度上期調達分は
    2020年度比のほぼ2倍、過去最高額に達した（業界紙報道）
  • このとき問題になったのは、すでに受注済みの船。
    たとえば2020年に「1隻50億円」で受注した船を、2022年に高騰した鋼材で作ることになる
  • 鋼材費が船価の約49%を占めるなら、鋼材が2倍になると原価は約1.5倍。船価が変わらない以上、
    利益はもちろん、元本まで削られる
  • 業界からは「鋼材高を吸収するには船価を4割引き上げる必要がある」との声が出た（2022年頃、業界紙報道）。
    実際には船価はそこまで上がらず、多くの造船所が損失を計上した
  • 国交省はOECD造船部会で「鋼材等の価格を適切に新造船価格に転嫁することの重要性」を提起している

為替が動くとどうなるか

状況 効く向き 理由
受注後に円安プラス（大きい）ドル建て受注の円換算額が増える。人件費・国産鋼材は円建てなので原価は増えない
受注後に円安マイナス（一部）輸入エンジン・舶用機器の調達コストが上がる
受注後に円高マイナス（大きい）円換算の売上が目減りする。1990年代〜2010年代前半の円高局面で日本の造船が苦しんだ最大の理由
韓国側のウォン安日本にマイナスドル建て船価が同じでも、韓国の造船所の自国通貨建て採算が改善し、価格攻勢をかけられる
  • 対策は為替予約（将来のレートを契約時に確定させる）。ただし予約した分だけ円安の恩恵も逃す
  • つまり造船所の利益の相当部分は、「いつ・どれだけヘッジするか」という金融判断で決まる。
    ものづくりの巧拙だけでは説明できない

なぜ逃げられないのか：ドックを空けると固定費が丸ごと赤字になる。
だから先行きが不透明でも、造船所は「今の船価」で受注を埋めに行く誘因が働く。
設備の重さが、不利な条件での受注を強制する。これが造船業の構造的な弱点である。

7. 造船所の「体温計」を読む

指標 見方
手持ち工事量（受注残）何年分の仕事があるか。2年分を切ると値引き受注が始まり、4年分あると強気に出られる。今治造船グループは約4年分を確保（2026年3月期、NSY経由81隻・406万総トン）
新造船価指数市況の水準。上がっている局面で受注した船は、引渡し時に利益が出やすい
鋼材の期先価格受注済み船の原価見通し。半期交渉の結果が翌期の損益を決める
為替予約残高円安・円高どちらに効くかを規定する
ドック稼働計画空白期間があると、その期は固定費が直撃する
