# ② 日本の造船が負けた理由と現在地

このノートで分かること：世界シェア5割を持っていた日本の造船が、なぜ8%まで落ちたのか。
韓国・中国に何をやられたのか。そして2026年時点で**何が残り、国は何をしようとしているか**。

> **結論を先に**：日本が負けたのは技術ではなく、**為替・国策・投資判断**である。
> 円高が採算を削り、韓国と中国が国の支援で設備と価格を積み増し、
> 日本は「設備を増やさない」という合理的な経営判断を続けた結果、作れる量そのものが縮んだ。
> 2025年末、政府はこれを**安全保障の問題**と位置づけ、2035年に建造能力を倍増する方針へ転換した。

## 2. 負けた理由を分解する

### (1) 為替：同じ船でも採算が違う

造船の契約は**ドル建て**が主流。だから通貨が動くと、船価が同じでも自国通貨建ての採算が変わる。

| 局面                 | 日本                                                       | 韓国                                                                   |
| -------------------- | ---------------------------------------------------------- | ---------------------------------------------------------------------- |
| 1990年代後半〜2012年 | **円高**。ドル建て売上の円換算が目減りし、赤字受注が常態化 | **ウォン安**（通貨危機後）。同じ船価でも利益が出せ、値下げ余力があった |
| 2013年以降           | 円安で採算は改善                                           | ウォンも変動。以降は技術・船種の差が主戦場に                           |

- 造船は原価の約7割（鋼材49%＋労務23%）が**自国通貨建て**。売上がドル建てなので、
  **自国通貨が安いほど利益が出る**。これが構造的に効く
- しかも[①](01_船はどう作られどう売れるか.md) で見たとおり、**受注時に価格が固定される**。
  受注から引渡しまでの2〜3年で円高が進めば、その分はまるごと造船所の損失になる。
  円高局面では「受注するほど赤字が増える」状態が現実に起きた

### (2) 国策支援の差

| 国       | やったこと                                                                                                                                             |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **韓国** | 政策金融機関による建造融資・保証、経営危機時の公的資金による支援。**ドックを止めずに維持**できた                                                       |
| **中国** | 国有造船大手（CSSC＝中国船舶集団）への集約と大規模な設備投資。国有リース会社が船主となって自国造船所に発注する循環。**建造能力そのものを国費で積んだ** |
| **日本** | 1980年代以降、過剰設備の削減（設備処理）を繰り返した。**能力を減らす方向の政策**が長く続いた                                                           |

> **ここが決定的**：日本の各社は「市況が悪いのに設備を増やすのは不合理」という、
> 企業としては正しい判断をし続けた。だが相手は企業ではなく**国**だった。
> 相手が採算度外視で設備を積むなら、個社の合理的判断の積み上げでは負ける。
> 2025年の政策転換は、この非対称性をようやく認めたものと言える。

### (3) 人件費と人の数

- 韓国・中国に対する**人件費の差**は当初から不利だった
- さらに国内では就業者が減り続けた。造船業の就業者数は約9万2,000人から約**7万6,000人**へ減少（報道ベース）
- 受注が戻っても**作る人がいない**。2026年の業界イベントでは「受注は増えても作れません」という
  現場の声が報じられ、1万人超の人手不足が指摘された

### (4) 設計リソースの細り

船は一品一様で、船主ごとに仕様が違う。設計者が足りないと、**受注できても着工できない**。
2026年のSea Japanでは、造船各社トップが「設計リソースの共有」「仕様の標準化」を
協業テーマとして挙げている（業界紙報道）。負けの原因が現場の溶接技能ではなく、
**上流の設計と段取り**にあるという認識が共有されつつある。

## 3. 事業再編：3グループへの集約

日本の造船は2020年代を通じて統合が進み、2026年時点でおおむね次の形になった。

```
【第1グループ】今治造船 連合
  今治造船 ──60%取得(2026年1月)──▶ ジャパンマリンユナイテッド（JMU）
      │                                    ・艦艇（護衛艦）も建造
      ├──60%取得(2026年4月)──▶ 日立造船マリンエンジン（舶用エンジン）
      └── 販売会社 NSY（日本シップヤード）で受注を一本化
      グループ売上 約1兆円規模

【第2グループ】常石造船 連合
  常石造船 ──完全子会社化(2025年6月)──▶ 三井E&S造船
                                          → 常石ソリューションズ東京ベイ に改称
      ・中国、フィリピンにも建造拠点（海外生産で価格競争に対抗）
  ※ 三井E&S 本体は造船から撤退し、舶用エンジンと港湾クレーンに集中

【第3グループ／独立系】
  三菱重工  … 商船は縮小。艦艇・官公庁船に特化
  川崎重工  … 商船は中国合弁が主。国内は潜水艦と新燃料船
  名村造船所、大島造船所 … 中堅専業として独立を維持
```

| 企業                       | 2026年3月期の状況                                                                        |
| -------------------------- | ---------------------------------------------------------------------------------------- |
| **今治造船**               | 売上高 **6,005億円**（前期比約+29%）で初の6,000億円超。設備投資は10年で1,000億円超を計画 |
| **JMU**                    | 純利益 **321億円** と2年連続の過去最高益。単体で28隻・183万総トンを受注                  |
| **今治造船グループ受注残** | NSY経由で81隻・406万総トン。**約4年分の工事量**に相当                                    |

（出典：海事プレス、日本経済新聞、東洋経済ほか。報道ベース）

- 政府の造船業再生ロードマップは、業界を**1〜3グループ体制に集約**する方向を示している。
  複数事業者が一体で動くことで、設計・資機材調達・建造の能力を最大化する狙い
- 統合の実質的な意味は「設計と受注窓口の共通化」。**ドックを足し算するだけでは生産性は上がらない**

## 4. 国策：造船業再生ロードマップ（2025年12月）

| 項目                    | 内容                                                                                        |
| ----------------------- | ------------------------------------------------------------------------------------------- |
| 策定                    | 2025年12月26日、国土交通省・内閣府                                                          |
| 目標                    | 年間建造量を現状**約900万総トン → 2035年に1,800万総トン**（倍増）                           |
| フェーズ1（2026〜28年） | 自動化・省力化設備の導入が中心                                                              |
| フェーズ2（2029〜31年） | 施設の新設・拡大                                                                            |
| フェーズ3（2032〜34年） | 増強したドック・クレーンの稼働                                                              |
| 枠組み                  | 経済安全保障推進法に基づき「**船体**」を特定重要物資に指定                                  |
| 投資                    | 令和7年度補正予算で1,200億円を措置。10年間で合計約3,500億円の投資が見込まれる（報道ベース） |
| 見直し                  | 3年ごとに成果目標の達成状況を見て検討                                                       |

**なぜ今さら倍増なのか**。理由は3つ。

1. **安全保障**。有事に船を作れる・直せる能力（艦艇の維持整備を含む）が国内に要る
2. **中国依存のリスク**。世界の商船の6割以上を1国が作る状態は、経済安保上の脆弱性とみなされた
3. **米国の動き**。米国は通商法301条で中国建造船に入港料を課し、造船能力の再建を志向している。
   日本にとっては追い風にも、米国向け投資要求にもなりうる

> **ただし最大の制約は人**。ドックとクレーンは金で買えるが、
> 溶接工と設計者は10年かけないと増えない。ロードマップのフェーズ1が
> 「自動化・省力化設備」から始まるのは、**人を増やせない前提で能力を倍にする**という
> 極めて難しい条件を最初から織り込んでいるためである。

## 5. 残された領域：日本は何で戦うのか

| 領域                                   | 現状                                                   | 勝ち目                                                                                                                                       |
| -------------------------------------- | ------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------- |
| **自動車船（PCTC）**                   | 日本勢が伝統的に強い                                   | 発注元が日本の海運会社。多層デッキの設計ノウハウが効く。USTRの自動車船向け入港料引き上げ（2025年10月）で中国建造船が不利になり、相対的に有利 |
| **LNG船**                              | 韓国が圧倒的。日本は建造再開が課題                     | 極低温タンクの技術はあるが**実績の連続性が切れた**のが痛い。再参入には船主の信頼回復が要る                                                   |
| **艦艇・官公庁船**                     | 三菱重工、JMU、川崎重工                                | 市況と無関係の安定財源。防衛予算増が直接効く → [航空機・防衛](../13_航空機・防衛/README.md)                                                  |
| **新燃料船（メタノール・アンモニア）** | 今治造船が燃料タンクの生産能力を拡張中（2028年度まで） | IMO規制の行方次第。規制が固まれば代替需要が一気に立つ → [水素・アンモニア](../../01_注目テーマ/06_水素・アンモニア/README.md)                |
| **バルカー（ばら積み船）**             | 中堅専業の主力                                         | 価格勝負。中国が最も強い領域で、標準化と省人化でしか対抗できない                                                                             |
| **舶用エンジン・機器**                 | 三井E&S、川崎重工、ヤンマー、ダイハツディーゼル        | 船体を取られても**機器は売れる**。二元燃料エンジンは技術障壁が高い                                                                           |

## 6. 韓国・中国の現在地

| 国                                                     | 戦い方                                                    | 2026年の動き                                                                                                                          |
| ------------------------------------------------------ | --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| **韓国**（HD現代、ハンファオーシャン、サムスン重工業） | **高付加価値船に特化**。LNG船・大型コンテナ船・海洋構造物 | サムスン重工業は商船受注73億ドル（LNG船18隻含む）で前年実績71億ドルを超過。HD韓国造船海洋は20万m³級LNG船4隻を約1兆4,993億ウォンで受注 |
| **中国**（CSSC ほか）                                  | **量と価格**。国有リース会社が船主となる循環              | 2026年1〜3月の世界受注シェアが8割近く。手持ち工事量シェア約69.8%                                                                      |

- 韓国は「日本と同じ土俵で価格競争しない」方向へ早く移った。**日本が失った10年で、韓国は船種を上に動かした**
- 中国は米国の301条措置で一時受注が落ちたが、措置の運用変更を受けて2026年1〜3月に急回復したと報じられる
