# 造船・重機

- 大分類: 自動車・機械
- 状態: done
- 更新日: 2026-09-20

**この業界を一言で**：**受注した瞬間に売値が決まり、2〜3年かけて作って、作り終えてから代金の大半をもらう産業**。
だから鋼材が上がっても、円が動いても、**契約済みの船の値段は1円も変えられない**。
この「価格の固定」と「長い時間差」が、造船と重機（重工業）の損益・再編・国策のすべてを説明する。

もうひとつの軸は**担い手の二層構造**。船を大量に作る専業造船（今治造船・常石など）と、
船は事業の一部でしかない総合重工（三菱重工・IHI・川崎重工）は、同じ「重厚長大」でも経済構造が別物である。

## 1. 業界の定義・範囲

「造船・重機」は、**大型の鋼構造物を一品ごとに受注して作る産業**をまとめた区分。
具体的には次の2つが同居している。

| 層           | 中身                                                         | 代表企業                                        |
| ------------ | ------------------------------------------------------------ | ----------------------------------------------- |
| **専業造船** | 商船（貨物を運ぶ船）を量産する。売上のほぼ全部が船           | 今治造船、JMU、常石造船、名村造船所、大島造船所 |
| **総合重工** | エネルギー設備・航空宇宙・防衛・産業機械の複合体。船は一部門 | 三菱重工業、IHI、川崎重工業                     |

隣接業界との境界は次のとおり。

| 業界                                                                                          | 違い                                                                               |
| --------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| [海運](../../13_運輸・物流/04_海運/README.md)                                                 | 船を**買って使う**側。造船にとっては唯一の顧客であり、海運市況＝造船の需要そのもの |
| [鉄鋼](../../11_資源・エネルギー・鉄鋼金属/09_鉄鋼/README.md)                                 | 船体の材料（厚板＝あつばん、船の外板に使う厚い鋼板）の供給元。船価の約半分が鋼材費 |
| [航空機・防衛](../13_航空機・防衛/README.md)                                                  | 重工3社の主力事業と重なる。艦艇（護衛艦・潜水艦）は造船所で作るので境界は曖昧      |
| [プラントエンジニアリング](../../12_建設・住宅・不動産/03_プラントエンジニアリング/README.md) | 日揮・千代田化工など。重工のプラント事業と**同じ一括請負のリスク構造**を持つ       |
| [建設機械](../06_建設機械/README.md)                                                          | 同じ機械産業だが量産品。造船は一品一様で、売ったあとのサービス収入も薄い           |
| [鉄道車両](../14_鉄道車両/README.md)                                                          | 川崎重工が両方やる。受注生産・長納期という点は共通                                 |

> **ポイント**：建設機械は「売ったあとの部品・サービスで稼ぐ」が、造船は**引渡しで関係がほぼ終わる**。
> だから造船は「1隻ごとの受注採算」がすべてで、逃げ道がない。

## 2. 市場規模と成長性

| 区分                      | 数値                                                          | 年・出典                                    |
| ------------------------- | ------------------------------------------------------------- | ------------------------------------------- |
| 世界の新造船建造量        | **7,227万総トン**（回復継続）                                 | 2025年、海事プレス（Clarksons集計ベース）   |
| うち日本の建造量          | **1,000万総トン超**（4年ぶりに大台回復）                      | 2025年、同上                                |
| 中国の建造量シェア        | **60%超**。2位韓国・3位日本との差が拡大                       | 2025年、国交省「造船業の現況」（2026年1月） |
| 世界の新造船発注量        | 3,900隻・**1億2,200万総トン**                                 | 2025年、海事プレス                          |
| 2026年1〜3月の世界受注量  | 5,517万総トン（前年同期比約6割増）、**中国のシェアが8割近く** | 2026年、海事プレス／日本経済新聞            |
| 中国の手持ち工事量シェア  | **69.8%**                                                     | 2026年第1四半期、中国側発表（報道ベース）   |
| 新造船価指数（Clarksons） | 185.01（2026年5月末）。2024年Q3のピーク189.69からやや軟化     | 2026年、Clarksons（報道ベース）             |
| 日本の造船就業者数        | 約9万2,000人 → 約**7万6,000人**へ減少                         | 近年、国交省資料・報道ベース                |

- **需要は自分で決まらない**。船を買うのは海運会社で、海運会社は運賃市況が良いときにしか発注しない。
  したがって造船の受注はおおむね**海運市況に1〜2年遅れて動く**
- 総トン（GT）は容積の単位で、船の大きさを表す。重量ではない点に注意
- 単年の受注量は振れが大きいので、**手持ち工事量（受注残）が何年分あるか**で健康状態を見るのが実務

## 3. バリューチェーン（川上 → 川下）

```
【川上】                【設計・建造】              【川下】

 鋼材（厚板）──┐
  日本製鉄/JFE  │
                ├──▶  造 船 所  ──▶ 船主（船を持つ会社）──▶ 海運会社（運航）──▶ 荷主
 舶用エンジン ──┤     設計→切断→      ・オーナー系              （定期用船）      （メーカー・商社）
  三井E&S/川重  │     ブロック→搭載→   ・海運会社の自社船
  ヤンマー/ダイハツ    艤装→進水→試運転
                │           ▲
 舶用機器   ──┤           │                  ┌── 船級協会（ClassNK 等）＝ 設計・工事の検査
  ポンプ/バルブ │      協力会社（社外工）      ├── 船舶金融（銀行・リース）＝ 建造代金の資金繰り
  航海計器/塗料 │      ＝現場人員の大半         └── 商社（機器調達・船舶投資）
                │
 ガスタンク  ──┘
  （LNG船の心臓部）
```

- 付加価値が集まるのは**①設計（船型・燃費性能）②高付加価値船のコア部品（LNGタンク、二元燃料エンジン）③艤装の工数管理**。
  鋼板を切って溶接する工程そのものは、人件費の安い国に勝てない
- 船主と海運会社は別であることが多い。愛媛の**船主（オーナー）**が船を保有し、海運会社に貸す構図が日本の特徴
- 舶用機器メーカー（[ポンプ・バルブ](../17_ポンプ・バルブ/README.md) など）は造船所の下請けに見えるが、
  エンジンや推進装置は寡占で、実は造船所より交渉力が強い領域もある

| ------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------- |

## 5. 収益モデル・コスト構造

```
 受注（契約） ─────────────── 2〜3年 ─────────────── 引渡し
   ↑                                                      ↑
 船価がここで確定（ドル建てが多い）              ここで代金の大半を受領
   │                                                      │
   └── この間に動くもの：鋼材価格 ／ 為替 ／ 人件費 ／ 舶用機器価格
        ぜんぶ造船所の持ち出し（＝値上げ交渉の余地がほぼない）
```

日本の新造船のコスト構成は、おおむね次の比率とされる（国交省資料ベース）。

| 費目       | 比率の目安 | 性格                                                                   |
| ---------- | ---------- | ---------------------------------------------------------------------- |
| **鋼材費** | 約49%      | 半年ごとの鉄鋼メーカーとの価格交渉で決まる。**契約後に上がったら丸損** |
| 舶用機器等 | 約23%      | エンジン、発電機、航海機器。輸入品は円安で上がる                       |
| 労務費     | 約23%      | 自社工＋協力会社。人手不足で単価上昇                                   |
| 管理費     | 約5%       | —                                                                      |

- 造船用厚板は2022年度上期調達分で**2020年度比のほぼ2倍**、過去最高額に達した（業界紙報道）。
  このとき既に受注済みだった船は、**上がった鋼材を契約時の船価で作る**ことになり、各社が損失を計上した
- 逆に、円安は**ドル建て受注の円換算額を増やす**ため追い風になる。ただし輸入機器のコストも上げるので、
  効き方は「ドル建て受注比率 −（輸入部材比率）」の差で決まる
- 利益率は薄い。好況期でも営業利益率は一桁前半〜中盤が普通で、**1隻の見積り誤りが全社損益を飛ばす**

詳しい仕組みは [① 船はどう作られ、どう売れるか](01_船はどう作られどう売れるか.md)。

## 6. 競争要因（KSF）と参入障壁

```
┌───────────────────────────────────────┐
│ ①ドックと大型クレーンがあるか（物理的な設備）       │ ← 中国が国費で一気に積んだ層
├───────────────────────────────────────┤
│ ②見積りが当たるか（工数・鋼材・為替の読み）         │ ← ここを外すと赤字
├───────────────────────────────────────┤
│ ③設計リソースの速さ（船主ごとの仕様変更に応える）   │
├───────────────────────────────────────┤
│ ④難しい船が作れるか（LNGタンク、二元燃料、艦艇）     │ ← 日韓が残っている領域
└───────────────────────────────────────┘
```

| KSF                      | なぜ効くか                                                                                             |
| ------------------------ | ------------------------------------------------------------------------------------------------------ |
| **ドック容量と連続建造** | ドックが空くと固定費が丸々赤字になる。だから安値でも受注を埋める誘因が働き、業界全体で価格が崩れやすい |
| **見積り精度とヘッジ**   | 受注時に価格が固定されるため、**為替予約と鋼材の手当てをいつ・どれだけ打つか**が実質的な利益源         |
| **設計人員**             | 船主ごとに仕様が違う一品生産。設計が追いつかないと受注できても着工できない                             |
| **高付加価値船の実績**   | LNG船は事故時の損害が巨大なため、船主は**建造実績のない造船所に発注しない**。実績が実績を呼ぶ          |
| **国の支援**             | 中国・韓国では政策金融と公的支援が価格競争力を左右してきた                                             |

## 7. 規制・法制度

| 分野                        | 内容                                                                                                                                                                                                                               |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **造船業再生ロードマップ**  | 国交省・内閣府が2025年12月26日策定。年間建造量を現状約900万総トンから**2035年に1,800万総トン**へ倍増。フェーズ1（2026〜28年：自動化・省力化設備）／フェーズ2（2029〜31年：施設の新設・拡大）／フェーズ3（2032〜34年：稼働）の3段階 |
| **経済安全保障推進法**      | 「船体」を**特定重要物資**に指定。建造能力の確保を安全保障の問題として扱う                                                                                                                                                         |
| **投資支援**                | 令和7年度補正予算で1,200億円を措置。10年間で合計約3,500億円の投資が見込まれる（報道ベース）                                                                                                                                        |
| **IMO（国際海事機関）規制** | 船の燃費・GHG規制が船種と燃料の選択を決める。ネットゼロ枠組みの採択は2025年10月に1年延期され、2026年後半に再開予定                                                                                                                 |
| **船級（ClassNK 等）**      | 船の設計・工事を検査し証書を出す民間機関。保険と船舶金融の前提になる                                                                                                                                                               |
| **USTR 通商法301条措置**    | 中国建造船・中国運航船の米国入港に追加料金（2025年10月14日徴収開始）。海運を通じて造船の発注先選びに影響                                                                                                                           |
| **外国人材**                | 造船・舶用工業は特定技能の対象分野。育成就労制度は2027年4月運用開始予定                                                                                                                                                            |

## 8. 最近のトピック

詳細は [④ 直近トピック 2026](04_直近トピック_2026.md)。要点は次の5つ。

1. **中国の独走が加速**。2026年1〜3月の世界新造船受注で中国のシェアが8割近く、手持ち工事量シェアも約7割（2026年）
2. **日本は国策で倍増へ舵**。造船業再生ロードマップ（2025年12月）で2035年に建造能力1,800万総トン。ただし就業者は減っており、現場からは「受注は増えても作れない」の声
3. **再編が一段落**。今治造船がJMUを子会社化（2026年1月）しグループ1兆円規模へ。常石造船は三井E&S造船を完全子会社化（2025年）。政府は1〜3グループへの集約を想定
4. **重工3社は過去最高益**。三菱重工は2026年3月期に受注高7兆6,536億円・純利益3,321億円。防衛受注残は3社計6兆2,500億円（+15%）
5. **豪州次期フリゲート11隻**。もがみ型能力向上型を三菱重工が受注し、2026年4月に契約。戦後最大級の防衛装備輸出

## 9. 用語メモ

各ノート末尾にも用語メモがある。共通の基本用語は次のとおり。

| 用語                    | 意味                                                                                                                 |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------- |
| **総トン（GT）**        | 船の容積を表す単位。重さではない。建造量の統計はこれで数える                                                         |
| **載貨重量トン（DWT）** | 積める貨物の重さ。貨物船の能力を表すときに使う                                                                       |
| **厚板（あつばん）**    | 船体に使う厚い鋼板。船価の約半分を占める最大のコスト → [鉄鋼](../../11_資源・エネルギー・鉄鋼金属/09_鉄鋼/README.md) |
| **艤装（ぎそう）**      | 船体に配管・電線・機器を据え付ける工程。工数の山場 → [①](01_船はどう作られどう売れるか.md)                           |
| **手持ち工事量**        | 受注残。何年分の仕事を抱えているかを示す業界の体温計                                                                 |
| **船主（オーナー）**    | 船を保有して海運会社に貸す事業者。愛媛の船主群が有名                                                                 |
| **船級協会**            | 船の設計・工事を検査し証書を出す機関。日本はClassNK（日本海事協会）                                                  |
| **二元燃料エンジン**    | 重油とLNG（またはメタノール）を切り替えて使えるエンジン                                                              |
| **EPC**                 | 設計・調達・建設を一括で請け負う契約形態。重工のプラント事業の基本形 → [③](03_重機（重工業）の中身.md)               |
| **GTCC**                | ガスタービン・コンバインドサイクル。ガスタービンと蒸気タービンを組み合わせた高効率発電設備                           |
