③ スマート農業

自動車・機械農業機械

このノートで分かること：自動操舵・自動運転トラクタ・可変施肥・ドローン防除とは何か。
そして技術がとっくに完成しているのに なぜ日本で普及が遅いのか ——
答えは「ほ場1枚の面積」と「投資回収年数」という、極めて単純な算数にある。

結論：スマート農業の障壁は技術ではない。
1台の機械が年間に働ける面積が小さすぎて、投資額を回収できない。
北米で自動操舵が当たり前になったのは技術が優れているからではなく、
1台が年に数千ha働くので 2〜3年で元が取れる からである。
日本の平均的な水田経営では、同じ計算が10年〜回収不能になる。

1. スマート農業の技術を4つに分ける

「スマート農業」は曖昧な言葉なので、何を自動化しているか で分けて理解する。

層 技術 何が置き換わるか 導入コスト感 日本での普及度
① 測位RTK-GNSS（誤差数cmの高精度衛星測位）「まっすぐ走る」ための目印・勘基地局＋受信機で数十万〜数百万円基盤。これがないと上の層が動かない
② 操作支援自動操舵（オートステア）ハンドル操作。人は乗ったまま後付けキットで100万〜300万円程度最も普及が進んでいる層
③ 自動走行ロボットトラクタ（有人監視下の無人運転／将来は遠隔監視）運転者そのもの同クラス機＋数百万円の上乗せ台数はまだ限定的
④ 意思決定可変施肥（VRT）、生育センシング、営農管理システム、ドローン防除「どこにどれだけ撒くか」の判断ソフトは年数万円〜、ドローンは100万〜300万円部分導入が中心
【スマート農機の技術スタック】

 ┌────────────────────────────────────────┐
 │ ④ 意思決定：可変施肥・生育診断・営農管理（データ）      │ ← 効果は出るが効果が見えにくい
 ├────────────────────────────────────────┤
 │ ③ 自動走行：ロボットトラクタ（無人）                  │ ← 法規・安全・価格の壁
 ├────────────────────────────────────────┤
 │ ② 操作支援：自動操舵（人は乗る）                     │ ← ここが実務の主戦場
 ├────────────────────────────────────────┤
 │ ① 測位：RTK-GNSS 基地局＋受信機（誤差数cm）          │ ← 土台。自治体整備も進む
 └────────────────────────────────────────┘

RTK（Real Time Kinematic）とは：基準となる固定局と、機械側の受信機で衛星電波の誤差を
打ち消し合い、位置精度を数cmに上げる方式。普通のGPSは誤差数m あるので、
畝（うね）に沿って走る農作業には使えない。RTKがあって初めて「重複なく・隙間なく」走れる。

2. 自動操舵が最初に普及した理由

「無人化」よりも「ハンドルを握らなくていい」が先に売れた。理由が明快である。

効果 中身
重複走行が減る目分量だと安全側に重ねて走るため、実作業面積が5〜10%無駄になる。自動操舵はこれをほぼゼロにする
夜間・悪条件でも作業できる目印が見えなくても走れる。農繁期の作業可能時間が延びる
熟練でなくても同じ精度新人・パート・後継者がいきなり熟練者と同じ精度で走れる＝人手不足対策そのもの
疲労が激減する1日8時間ハンドルを握らなくてよい。高齢者の作業継続に直結する
後付けできる既存のトラクタにキットを付ければ使える。全買い替えが不要

ポイント：自動操舵の価値は「無人化」ではなく 「作業品質の標準化」。
ここが農家に一番刺さった。人が減っている業界で、
「誰がやっても同じ結果になる」ことは省力化より価値が高い場合がある。

3. ロボットトラクタは今どこにいるか

メーカー（クボタ）はロボット農機を3段階で定義している。

レベル 定義 状況
レベル1有人での自動化・操作支援（自動操舵など）実用段階。市販品として普及中
レベル2人が同じほ場内で監視した状態での無人自動走行市販済み。アグリロボトラクタ等。現在の主力
レベル3遠隔監視を前提とした完全無人。公道を通ってほ場まで自走クボタは2026年に遠隔監視型の無人農機を実用化すると発表

安全側の作り込みとして、レーザースキャナーと超音波ソナーで人や障害物を検知し停止する仕組みが
搭載されている。技術的には「できている」段階で、残っているのは 法規・責任・価格 である。

【レベル2とレベル3の決定的な差】

 レベル2（現在）                      レベル3（これから）
 ┌────────────────┐            ┌────────────────┐
 │  ほ場                │            │  ほ場                │
 │   ■無人トラクタ      │            │   ■無人トラクタ      │
 │                      │            │                      │
 │   👤 監視者（同じほ場内）│            └──────┬──────┘
 └────────────────┘                   │ 通信
   ▲ 人が1人拘束される                        ▼
     ＝省力化の効果は「2台同時に動かす」   👤 遠隔の監視者（家・事務所）
       ことでしか出ない                    ▲ 1人で複数ほ場・複数台を見られる
                                             ＝ここで初めて人件費が本当に浮く

つまり レベル3にならないと経済性が跳ねない。
レベル2は「人が1人張り付く」ので、実質は自動操舵の延長にとどまる。
2026年に語られている「無人農機の実用化」はこの壁を越えられるかという話である。

4. ドローン防除と可変施肥

技術 中身 経済効果 壁
ドローン防除（農薬・肥料の空中散布）10〜25L級の農業用ドローンで農薬を撒く。1haあたり10分程度背負い式散布機での重労働がなくなる。中山間地でも使える機体100万〜300万円、航空法の許可・飛行計画、オペレーター資格、バッテリー運用
可変施肥（VRT）ほ場内の生育ムラに合わせて肥料量をリアルタイムで変える肥料代の削減（数%〜十数%）と収量の平準化センサ／衛星画像／処方マップの準備が要る。効果が年によってぶれる
収量コンバイン収穫しながら収量と水分を記録し、次年の施肥設計に使うデータが翌年の意思決定に回る1年1サイクルしか回らないので改善が遅い
営農管理システム作業記録・ほ場管理・コスト分析をクラウドで法人化した経営体の管理コストを下げる個人農家には過剰。入力の手間が続かない

ドローンの詳細は ドローン、
データ活用の産業論は フードテック に整理している。

注意すべき非対称性：ドローン防除は投資回収が速い（機体が安く、年間の散布回数が多く、
委託すれば機体を持たなくてよい）。一方、可変施肥は効果が見えにくく回収が遅い。
「スマート農業が普及しない」と一括りにするのは誤りで、技術ごとに回収年数がまったく違う。

5. 本題：なぜ普及が遅いのか（面積と回収年数の算数）

農水省の資料や各種調査では、スマート農業の導入率は調査の定義次第で大きくぶれる
（「何らかのスマート技術を導入」なら約45%という民間調査もある）。しかし
未導入農家の理由は一貫している。

未導入の理由 割合（民間調査ベース）
コストが高い／投資に見合わない約5割
活用方法が分からない3割超
ほ場が狭い・条件に合わない（上記に含まれることが多い）
相談先・サポートがない—

ここを数字で分解する。回収年数 ＝ 投資額 ÷ 年間の削減額 であり、
年間の削減額は 面積に比例する。これが全てである。

【自動操舵キット200万円は何年で回収できるか】

  仮定：自動操舵で 1ha あたり年 2万円分のコストが浮く
       （重複走行の削減＋作業時間短縮＋燃料・肥料の節約の合算イメージ）

  経営面積     年間の削減額        回収年数
  ─────────────────────────────────────────
    2ha   →      4万円     →     50年    ← 回収不能
    5ha   →     10万円     →     20年    ← 機械寿命と同じ。実質不能
   20ha   →     40万円     →      5年    ← ようやく検討に乗る
   50ha   →    100万円     →      2年    ← 買わない理由がない
  500ha   →  1,000万円     →    0.2年    ← 北米はここ
  ─────────────────────────────────────────
   ※ 削減額の単価は説明用の仮置き。実際は作物・地域・機種で変わる
     が、「面積に比例する」という関係は変わらない

そして日本のほ場は狭い。

指標 数値 時点・出典
30a（0.3ha）以上に区画整備された水田157万ha ＝ 田全体の約64%農水省 農村振興局資料
うち 1ha以上の大区画に整備された水田23万ha ＝ わずか9%同上

【なぜ「1枚の面積」が効くのか】

  30a区画（日本の標準）             10ha区画（北米イメージ）

  │ →→→→ │                    │ →→→→→→→→→→→→→→→→→→→→→→→→→→ │
  │ ←←←← │  ← 20mで折り返す    │ ←←←←←←←←←←←←←←←←←←←←←←←←←← │

  └──────┘                    └────────────────────────────┘
   直進区間が短い                    直進区間が長い
   ＝旋回・段取りの割合が高い          ＝直進自動化の効果が最大化
   ＝自動操舵の恩恵が薄まる            ＝自動操舵だけで劇的に効く
   ＋ ほ場間の移動（公道）も多い        ＋ ほ場間移動がほぼない

ここが核心：自動操舵が効くのは「まっすぐ長く走る時間」である。
30a区画では走行時間に占める旋回・畦際処理・ほ場間移動の比率が高く、
自動化できる部分そのものが小さい。技術の性能ではなく、ほ場の形状が効果の上限を決めている。

普及を妨げる要因の整理

要因 中身 解けるか
ほ場が狭い・分散している1枚30a、しかも1経営体の農地が何十枚にも散らばるほ場整備・農地集積（時間もお金もかかる。国の基盤整備事業次第）
投資回収年数上記の算数。小規模では回収できない大規模化・受託化・シェアリングで面積を稼ぐしかない
経営者の年齢基幹的農業従事者の平均年齢67.7歳（2025年）。残り稼働年数 < 回収年数世代交代・法人化を待つしかない部分が大きい
通信・RTK基地局山間部でRTK補正情報が届かない地域がある自治体がRTK基地局を整備する動きが広がっている
サポート人材「使いこなせる人」が販売店側にもいないメーカー・JAの人材育成が追いついていない
データの囲い込みメーカーごとにデータ形式・クラウドが違い、機種混在だとつながらないWAGRI（農業データ連携基盤）など標準化の試み

6. 制度：国は何をしているか

制度 中身
スマート農業技術活用促進法2024年6月21日公布、同年10月1日施行。生産側（農業者）と開発側（メーカー・スタートアップ）の双方の計画を国が認定し、支援を集中させる枠組み
認定を受けた場合の支援補助事業の優先採択、日本政策金融公庫の長期低利融資、税制特例の一体適用
投資促進税制対象機械等の特別償却32%、建物等16%（令和9年3月末まで）
農地の基盤整備ほ場の大区画化・汎用化。スマート農業の効果を決める本丸はここ（→第5章の算数）
WAGRI農業データ連携基盤。メーカー・自治体・研究機関のデータをつなぐ公的プラットフォーム

制度の設計思想として重要なのは、国が 「機械を買う補助」から「面積を増やす支援と合わせ技」へ
舵を切っていること。回収年数の算数を変えるには、機械を安くするより
1台が働く面積を増やすほうが効く、という理解が政策側にもある。

7. これから何が起きるか

  1. レベル3（遠隔監視）の解禁が最大の分水嶺。ここで初めて「1人で複数台」が成立し、
    労働時間の削減が投資額に見合う
  2. 後付け・レトロフィットが主流になる。世界的にも自動化は新車購入より
    既存機への後付けキットで広がっている（AGCOのPTx Trimbleなどが典型）
  3. サービス化（機械を売らずに作業を売る）。コントラクタがスマート農機を持ち、
    小規模農家は「作業を買う」形。面積を稼げるので回収年数の問題が解ける
  4. データの標準化競争。ジョンディアが囲い込み型、欧州勢が開放型で分かれている。
    日本はWAGRIで中間を狙う
  5. 電動化は農機では遅い。小型機・草刈機から入るが、大型トラクタは
    稼働時間の長さと充電インフラの制約で当面ディーゼルが続く見通し
