1. 業界の定義・範囲

農業機械（農機） ＝ 農作業に使う動力機械。耕す・植える・撒く・刈る・乾かす、の各工程に専用機がある。

境界の引き方：

  • 建設機械 は別（建設機械）。ただしクボタは両方を手がけ、
    ミニショベルなど小型建機と農機で技術・販売網を共有している
  • 農業そのもの（作る側） は 農業・種苗・肥料
  • 防除ドローンの機体技術・航空法 は ドローン
  • 植物工場・代替食などの農業テック全般 は フードテック

この業界を一言でいうと「国内は構造的に縮み、海外は景気循環で振れる」二重構造。

一方、日本メーカーの利益は北米・欧州・アジアの市況と為替で動く。

5. 収益モデル・コスト構造

利益 ＝ 新車販売（薄利） ＋ 作業機 ＋ 補修部品（厚利） ＋ 整備工賃（厚利）
       ＋ 金融の利ざや ＋ 中古再販 － 固定費（開発費・多機種対応・販売網）
論点 中身
営業利益率国内農機専業は5%前後が一つの壁。井関の2027年目標が「5%以上」であることが実態を示す
利益率が低い理由①機種が多く量産効果が出にくい ②販売網（JA・販売店）の販管費が重い ③国内の台数減で固定費を吸収しにくい
クボタが例外な理由海外（北米小型トラクタ）と建設機械を持つため。2026年12月期は純利益2,890億円・3期ぶり最高益の見通し
需要の季節性年度末（1〜3月）と春の作業前に山。補助金の年度に強く連動する
需要のサイクル性穀物価格→農家所得→設備投資と数年遅れで連動。下降局面では各社が減産して在庫を抜く
アフター農機は10〜20年使う。売った後の部品・整備で回収する構造

詳細は ② 売り方と儲け方。

6. 競争要因（KSF）と参入障壁

KSF（成功の鍵）

  1. サービス拠点の密度：農繁期に「その日のうちに直せる」かがブランドそのもの。撤退が致命傷になる理由
  2. フルラインの機種構成：トラクタだけでは選ばれない。田植機・コンバイン・作業機まで揃うか
  3. 海外市場の持ち分：国内が構造的に縮むため、海外比率が収益力を決める
  4. 馬力帯のポジション：小型で世界の巨人と土俵を分けられるか（日本勢の生命線）
  5. 排ガス規制対応力：各国の段階規制に合わせてエンジンを開発し続ける資金力
  6. データと自動化：自動操舵→レベル3無人化。ここで遅れると大規模顧客を失う

参入障壁

障壁 強さ 理由
販売・整備網強農繁期の即応性が必要。新規に全国網は作れない
補修部品の供給責任強20年分の部品を持ち続ける体力が要る
多機種開発の固定費強少量多品種。1機種あたりの開発費を回収しにくい
排ガス規制対応中〜強国ごとの段階規制にエンジンを合わせ続ける必要
機械の製造技術中単体の製造は模倣可能。ここだけなら参入できる
ソフト・自動化中新興・IT系が後付けキットで入りやすい領域

7. 規制・法制度

分野 主な制度
排出ガス特殊自動車排出ガス規制（オフロード法）。段階が上がると旧型エンジン機は販売できなくなり、買い替え需要を生む
安全農業機械の安全性検査（安全鑑定）。転倒時保護構造（ROPS）、PTO軸カバーなど
公道走行道路運送車両法。作業機を付けたトラクタの公道走行には灯火・幅・免許（大型特殊等）の要件がある
スマート農業技術活用促進法2024年6月21日公布・10月1日施行。計画認定で補助事業の優先採択、日本政策金融公庫の長期低利融資、税制特例を一体適用
投資促進税制上記法に基づく特別償却（機械等32%、建物等16%）。令和9年3月末まで
補助事業強い農業づくり／産地生産基盤パワーアップ事業、経営体育成支援、自治体独自の上乗せ補助
航空法農業用ドローンの飛行許可・承認、機体登録、操縦者技能証明
農地制度農地法、農地中間管理機構（農地バンク）による集積・集約。ほ場の大区画化がスマート農業の前提

8. 最近のトピック

詳細と出典は ④ 直近トピック（2026年9月時点）。要点だけ挙げると:

  • 三菱マヒンドラ農機が2026年3月2日に農機事業撤退・会社解散を発表。2026年度上期で生産販売終了。
    112年の歴史に幕。国内はクボタ・ヤンマー・井関の3社体制へ。補修部品と製品保証は継続
  • 北米の農機不況が2026年も継続。Deere・CNH・AGCOが揃って慎重な見通しを示し、
    アンダープロダクション（需要以上の減産）で在庫を圧縮している
  • クボタは2026年12月期の通期純利益予想を2,100億円→2,890億円へ38%上方修正、3期ぶり最高益見通し。
    ただし主因は需要回復ではなく円安と米国関税の還付
  • 井関農機の構造改革「プロジェクトZ」が数字に。2026年12月期2Qで営業利益率5.5%。
    2027年に5%以上という目標が射程圏内
  • 無人農機はレベル3（遠隔監視）が分水嶺。クボタは2026年に遠隔監視型の無人農機実用化を掲げる。
    レベル2は監視者が拘束されるため省力効果が限定的
  • 中古農機が海外需要と円安で高値（報道ベース）。国内の新規就農者が安い中古を確保しにくいという副作用
