# ④ 直近トピック（2026年9月時点）

報道・IR ベースの整理。数値は発表時点のものなので、必ず一次情報で裏を取ること。
この年の農業機械業界は、**国内で112年続いたメーカーが消え、海外では北米の農機不況が続き、
それでもクボタは円安と関税還付で最高益を更新する**という、ねじれた1年になっている。

## 1. 三菱マヒンドラ農機が農機事業から撤退・会社解散（2026年3月）

国内農機の4番手が消えた。1914年（大正3年）創立、112年の歴史に幕という構図である。

| 項目 | 内容 |
| --- | --- |
| 発表日 | **2026年3月2日**（同社ニュースリリース） |
| 内容 | 農業用機械の研究開発・生産・国内外販売を終了。**会社は解散し通常清算手続き**へ |
| 終了時期 | **2026年度上期（2026年9月末を目標）** |
| 補修部品・保証 | **供給と製品保証は継続**すると発表 |
| 沿革 | 1914年創立。2015年にインドのマヒンドラ・アンド・マヒンドラとの資本提携で現社名に |
| 影響（報道ベース） | グループ全体で**約900名以上**が退職の見通し。島根県松江市周辺の**サプライヤー約70社以上**に影響と報じられる |
| 同時に | グループ2社も解散予定と報じられる（東京商工リサーチ） |

```
【国内農機メーカーの再編】

  〜2025年                      2026年度以降
 ┌──────────┐             ┌──────────┐
 │ クボタ      │             │ クボタ      │
 │ ヤンマー    │   ───▶      │ ヤンマー    │  ← 3社に集約
 │ 井関農機    │             │ 井関農機    │
 │ 三菱マヒンドラ│             └──────────┘
 └──────────┘                  ▲ 残存者利益 ＋ 既存ユーザーの受け皿競争
       ▲ 縮む国内市場に4社は多すぎた
```

**なぜ起きたか（構造としての読み方）**

- 国内の基幹的農業従事者は2025年に **103.6万人・平均年齢67.7歳**（農林業センサス）。
  5年で24%減という母数の縮小に、4社体制が耐えられなかった
- 農機はフルラインで機種を揃えないと農家に選ばれにくい。**規模が小さいほど機種数の負担が重い**
- 撤退で表面化したのは価格でも性能でもなく **「壊れたら部品は出るのか」という不安**。
  農機が売って終わりの商品ではないことの証明でもある（→[② 売り方と儲け方](02_売り方と儲け方.md)）

> 業界への意味：シェアの大半がクボタ・ヤンマー・井関の3社に流れる見通しと報じられる。
> ただし縮む市場での残存者利益であって、成長ではない。

## 2. 北米の農機不況が2026年も続く

世界大手3社（Deere、CNH、AGCO）が2026年の北米見通しを揃って慎重に置いている。

| 論点 | 内容 |
| --- | --- |
| 需要 | 穀物価格の低迷で農家所得が伸びず、大型機の買い替えが先送りされている |
| 供給側の対応 | 各社が**アンダープロダクション（需要以上に減産）**を継続し、ディーラー在庫を圧縮 |
| 関税 | 米国の関税政策でコストが変動し、値付けと計画が読みにくい |
| 期間 | 「長期化するダウンサイクル」との見方が業界メディアで共有されている |

```
【北米農機サイクルの現在地（2026年）】

  穀物高・所得好調   在庫積み上がり    減産・在庫圧縮      回復
      2021-22   ──▶   2023-24   ──▶   2025-26   ──▶   2027?
        ■■■■■        ■■■             ■               ?
        ▲最高潮        ▲需要鈍化        ▲ いまここ
```

> 日本メーカーへの影響は非対称。**クボタの北米は大型穀作機ではなく小型トラクタ**が主戦場で、
> 顧客も農家というより土地持ち・造園・ホビーファーマーが多い。
> 大型穀作の不況と完全には連動しないが、2025年にはその小型トラクタも失速した。

## 3. クボタは2026年に最高益見通しへ急回復

2025年に減益だったクボタが、2026年に入って急反発している。

| 指標 | 数値 | 時点 |
| --- | --- | --- |
| 2025年12月期 売上収益 | **3兆0,189億円**（前期比+0.1%） | 2026年2月12日 決算短信 |
| 同 海外売上比率 | **77.3%**（前期比△1.7pt） | 同上 |
| 同 国内／海外 | 国内 +8.3% ／ 海外 △2.1%（**北米の小型トラクタ低迷**） | 同上 |
| 2025年12月期 純利益 | 約1,960億円（前期比**△15%**） | 同上・報道 |
| 2026年12月期 2Q 売上 | **1兆6,903億円**（前年同期比+16.2%） | 2026年8月4日 決算短信 |
| 同 2Q 純利益 | **1,737億円**（前年同期比**+87.8%**） | 同上 |
| 2026年12月期 通期 純利益 予想 | 2,100億円 → **2,890億円** へ38%上方修正。**3期ぶり最高益**更新見通し | 2026年8月4日 |
| 上方修正の要因 | **円安** と **米国関税の還付** | 同上・報道 |

> 注意して読むべき点：この急回復は **農機が売れたからではない**。
> 円安と関税還付という為替・制度要因の寄与が大きいと説明されている。
> 需要そのもの（北米の農機市況）は第2章のとおり慎重なままである。
> **業績と市況がずれているときは、何で稼いだのかを必ず分解する**。

## 4. 井関農機の構造改革「プロジェクトZ」が数字に出てきた

国内3位の井関農機は、抜本的構造改革を進めており、利益率がはっきり改善している。

| 指標 | 数値 | 時点 |
| --- | --- | --- |
| 2026年12月期 1Q | 売上・営業利益・経常利益が**1Qとして過去最高**。営業利益率 **5.1%**（前年同期比+2.1pt） | 2026年5月 |
| 2026年12月期 2Q | 営業利益率 **5.5%**（前年同期比+1.2pt） | 2026年8月7日 |
| 目標 | 2027年に**営業利益率5%以上** — 射程圏内と会社側は説明 | プロジェクトZ |
| 営業CF目標 | 2024〜2027年度の4年で**500億円** | 同上 |
| 進捗 | 2024年度 88億円＋2025年度 234億円＝**計322億円** | IR |
| 施策の方向 | **大型機・先端機**（スマート農機）へ軸足を移す。ヤンマーとは小型農機を共同開発 | 報道・IR |

> 読み方：**国内農機メーカーの「営業利益率5%」は簡単な数字ではない**。
> 機種数が多く、販売網が重く、国内の台数が細っているため、
> 5%を安定的に出すこと自体が構造改革のゴールになる業界である（→[② 売り方と儲け方](02_売り方と儲け方.md) 第6章）。

## 5. 無人農機「レベル3」と、国内出荷の持ち直し

**ロボット農機の遠隔監視（レベル3）**

- クボタはロボット農機をレベル1（有人の操作支援）／レベル2（ほ場内で人が監視する無人走行）／
  レベル3（**遠隔監視**を前提とする完全無人、公道を通ってほ場まで自走）の3段階で定義している
- 同社は **2026年に遠隔監視できる無人農機を実用化する** と発表している
- 経済的な意味は大きい。レベル2は監視者が1人ほ場に拘束されるので省力効果が限定的だが、
  レベル3なら1人で複数台・複数ほ場を見られる。**ここで初めて人件費が本当に浮く**
  （詳しくは [③ スマート農業](03_スマート農業.md) 第3章）

**国内出荷の持ち直し（集計ベース）**

| 年 | 農機出荷額 | 前年比 |
| --- | --- | --- |
| 2024年 | **3,790.6億円**（国内向け2,229.7億円／輸出1,560.9億円） | △9.6%（国内△8.5%、輸出△11.1%） |
| 2025年 | **約4,679億円** | **+9.1%（4年ぶり増加）** |

（日農工＝日本農業機械工業会の統計をもとにした集計値。集計範囲によって数値が変わるため、
正確な数字は日農工の原統計で確認すること）

2025年の機種別構成は、トラクタ約2,156億円（46.1%）、コンバイン約854億円（18.2%）、
田植機約334億円（7.1%）と、**トラクタが約半分**という農機の基本構造は変わっていない。

## 6. 中古農機の高値と、新規就農への副作用

- 日本製の中古トラクタ・コンバインは東南アジア・アフリカ・欧米で需要が強く、
  **中古相場が上昇している**と業界紙・買取事業者が伝えている
- 背景は ①円安で海外から見て割安 ②新車価格が鋼材・電子部品・排ガス規制対応で上昇
  ③状態の良い中古が輸出に抜けて国内が品薄
- 副作用として、**新規就農者や小規模農家が安い中古機を確保しにくくなっている**
- なお、中古相場に公的統計はない。**報道・事業者発信ベースの話**として扱うのが妥当

```
【2026年の農機業界を一枚で】

  国内                              海外
 ┌──────────────────┐   ┌──────────────────┐
 │ 農家 103.6万人・67.7歳    │   │ 北米：穀物安で買い替え延期 │
 │ → 4社→3社に集約           │   │ → Deere/CNH/AGCO 減産継続│
 │ → 大型・法人向けへシフト    │   │ → クボタの小型トラクタも失速│
 │ → 出荷額は2025年に+9.1%    │   │ ただし円安＋関税還付で     │
 │   （4年ぶり増）            │   │ クボタは最高益見通しへ     │
 └──────────────────┘   └──────────────────┘
          ▲ 構造的縮小                    ▲ 景気循環＋為替
              └──────── 二重構造 ────────┘
```

## 7. 全体の構図（まとめ）

1. **国内は「需要が減る」ではなく「担い手が消える」局面**。基幹的農業従事者103.6万人・平均67.7歳という
   母数の縮小が、4社体制を3社に圧縮した。三菱マヒンドラ農機の撤退はその最初の目に見える帰結である
2. **海外は景気循環**。北米は穀物安と在庫調整でダウンサイクルが続き、大手3社が減産を続けている
3. **にもかかわらずクボタは2026年に最高益見通し**。ただし牽引役は需要回復ではなく円安と関税還付で、
   業績と市況のズレを分けて読む必要がある
4. **各社の出口戦略は共通**：大型・高付加価値、海外、そしてサービス（部品・整備・データ）。
   井関のプロジェクトZはその国内版の典型
5. **スマート農業はレベル3が分水嶺**。遠隔監視が実務で使えて初めて人件費が浮く。
   逆に言えば、それまでは「ほ場が狭く回収できない」という算数が変わらない（→[③ スマート農業](03_スマート農業.md)）

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **通常清算** | 債務超過でない会社が、資産を処分して債務を返し法人格を消す手続き。倒産（破産）とは別 |
| **アンダープロダクション** | 需要の減少以上に生産を絞ってディーラー在庫を減らす動き。農機・建機で使われる |
| **ダウンサイクル** | 需要と価格が落ちる局面。農機は穀物価格に数年遅れて連動する |
| **関税還付** | 支払った関税が制度上戻ること。2026年のクボタ上方修正の一因と説明されている |
| **日農工（日本農業機械工業会）** | 国内農機メーカーの業界団体。生産・出荷・輸出入統計を公表している |
| **農林業センサス** | 5年ごとの農林業の全数調査。農家数・従事者数・経営規模の基礎統計 |
| **レベル3（農機）** | 遠隔監視を前提とする完全無人走行。クボタの定義による段階区分 |
| **プロジェクトZ** | 井関農機の構造改革の名称。2024〜2027年度で収益体質を立て直す計画 |
