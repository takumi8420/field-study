# ② 売り方と儲け方

このノートで分かること：農機は誰を通して売られ、どこで利益が出ているのか。
新車販売はむしろ薄利で、**下取り・部品・整備・金融** が効いているという構造を分解する。

> 結論：農機ビジネスの本質は「機械を売る商売」ではなく **「稼働している機械の台数を抱える商売」**。
> 売った瞬間より、その後10〜20年の部品と整備で回収する。
> だから**サービス拠点の密度がシェアそのもの**になり、撤退したメーカーの機械は一気に価値を失う。

## 1. 商流：日本の農機はJAを通って売られる

日本の農機流通は、自動車のような「メーカー系ディーラー一本」ではなく、
**系統（JAグループ）ルートと商系（民間販売店）ルートの二本立て** になっている。

```
【日本の農機商流】

  メーカー（クボタ／ヤンマー／井関）
     │
     ├──【系統ルート】──────────────────────────┐
     │   全農（全国農業協同組合連合会）             │
     │       └─ 県本部／経済連                    │
     │            └─ 単位JA（地域の農協）──▶ 農家 │
     │                 ・購買窓口として注文を取る    │
     │                 ・JA農機センターが整備も担う  │
     │                 ・営農指導・資金（JAバンク）も │
     │                                            │
     └──【商系ルート】─ メーカー系販売会社 ────────┤
         （クボタ農機販売、ヤンマーアグリジャパン等）  │
          ＋ 独立系の農機具店 ───────────────────┘
                                                  ▼
                                               同じ農家
```

| ルート | 強み | 弱み | 向く顧客 |
| --- | --- | --- | --- |
| **系統（JA）** | 営農指導・資金・共済・肥料とセットで囲い込める。集落単位の信頼 | 価格交渉力が働きにくい。手数料分が乗る | 小〜中規模、兼業、高齢農家 |
| **商系（メーカー系販売会社・農機具店）** | 直接の技術説明、値引き、細かい整備対応 | 資金・営農指導は付かない | 大規模法人、相見積りを取る層 |

> 変化しているのはここ。**大規模法人化が進むほど、顧客は系統ルートから離れる**。
> 20ha超の法人は数千万円の投資を相見積りで決めるので、JAの「まとめて注文」の利点が薄れる。
> メーカーが自社販売会社（クボタ農機販売、ヤンマーアグリジャパンなど）を整備してきたのは、
> **大規模層に直接触るチャネルを持たないと価格も情報も握られる**という危機感からである。

## 2. 「新車を売る」だけでは儲からない

農機の損益を1台のトラクタのライフサイクルで見ると、メーカー／販売店の利益源がはっきりする。

| 段階 | 誰の売上か | 粗利の厚さ | 補足 |
| --- | --- | --- | --- |
| 新車販売 | メーカー＋販売店 | **薄い**（相見積り・値引き・下取り上乗せ） | 台数は稼げるが価格競争 |
| 作業機（インプルメント）追加 | メーカー＋販売店 | 中 | 本体購入後、数年かけて買い足される |
| **補修部品** | メーカーが主 | **厚い** | 純正部品は競合が少なく価格決定力がある |
| **定期整備・修理** | 販売店／JA農機センター | **厚い** | 農繁期の"止められない"需要。工賃と出張費 |
| 延長保証・点検パック | メーカー＋販売店 | 中〜厚 | 稼働情報とセットで囲い込み |
| 下取り・中古再販 | 販売店 | 中（相場次第） | 下取り査定が新車の実質値引きの調整弁になる |
| 割賦・リース | メーカー金融子会社／JAバンク／リース会社 | 中（金利） | 高額機ほど効く |

```
【トラクタ1台の生涯収益イメージ（金額感の概念図）】

  新車販売        ■■■■■■■■■■■■■■■■■■■■  （大きいが粗利は薄い）
  作業機追加      ■■■■■■
  補修部品        ■■■■■■■■■■              ← 粗利率は新車の2〜3倍と言われる
  整備・修理工賃  ■■■■■■■■
  金融の利ざや    ■■■
  下取り→中古再販 ■■■■
                 └─────────────────────────▶ 15〜20年
   ▲ 売った瞬間ではなく、稼働している15〜20年でじわじわ回収する
```

> ここが **「撤退が致命的」な理由**でもある。
> 2026年3月に事業終了を発表した三菱マヒンドラ農機のユーザーが真っ先に心配したのは
> 価格でも性能でもなく「**壊れたら部品は出るのか**」だった（同社は補修部品供給と製品保証は継続すると発表）。
> 農機は買った後のサービスが商品の一部である。→ [④ 直近トピック](04_直近トピック_2026.md)

## 3. 下取りと中古：新車価格の"裏側"

農機の商談は、ほぼ必ず **下取り込み** で進む。ここには2つの効果がある。

1. **実質値引きの調整弁**：本体価格は表向き崩さず、下取り査定を上げて成約させる
2. **中古在庫の獲得**：引き取った機械は整備して中古として再販できる。ここが販売店の利益源

そして近年、中古農機の相場が上がっている。理由は輸出である。

| 要因 | 中身 |
| --- | --- |
| 海外需要 | 日本製の中古トラクタ・コンバインが東南アジア、アフリカ、欧米で人気。新品より安く、耐久性が高い |
| 円安 | ドル建てで見ると日本の中古機が割安になり輸出が伸びる |
| 新車価格の上昇 | 鋼材・電子部品・排ガス規制対応でコスト増。新車が高く、中古に需要が向かう |
| 供給減 | 農家の減少で「引退に伴う放出」は増えるが、状態の良い中古は輸出に抜ける |

（中古相場の上昇は業界紙・買取業者の発信が中心で、**公的統計はない**。「報じられる」レベルの話として扱う）

```
【中古農機の流れ】

  引退農家・買い替え
        │ 下取り
        ▼
   販売店／JA ──▶ 整備・再販（国内）──▶ 小規模農家・新規就農者
        │
        └──▶ 中古農機商社 ──▶ 輸出 ──▶ 東南アジア・アフリカ・欧米
                                   ▲ ここが伸びて国内中古が品薄・高値に
```

> 副作用：**国内の新規就農者が「安い中古」を買いにくくなっている**。
> 新規参入のハードルが機械コストで上がるという、業界にとっては痛し痒しの現象。

## 4. リース・レンタル・作業受託という「買わない」選択肢

高額な農機をどう使うかには、所有以外の選択肢がある。日本ではまだ所有が主流だが、
大規模化とともに比重が移りつつある。

| 方式 | 中身 | 向く場面 | 経済的な意味 |
| --- | --- | --- | --- |
| **購入（自己所有）** | 補助金・融資を使って買う | 毎年必ず使う基幹機（トラクタ、田植機） | 稼働日数が多ければ最も安い |
| **割賦・リース** | 数年〜10年で分割。所有権はリース会社 | 高額機、法人の資金繰り重視 | 初期負担を平準化。経費処理しやすい |
| **レンタル** | 数日単位。JAや農機店が貸す | 年に数日しか使わない機械（畦塗機、播種機など） | 稼働日数が少ない機械ほど得 |
| **作業受託（コントラクタ）** | 機械ごと人に来てもらう | 収穫・防除など繁忙期だけ | 機械も労働力も外注。人手不足に効く |
| **シェアリング／共同利用** | 集落営農・農事組合法人で共有 | 小規模が集まる地域 | 1台あたり稼働日数を上げる |

**判断の軸はただ一つ、年間稼働日数**である。

```
【所有か、借りるか】

  年間コスト
    ▲
    │  購入（固定費が重い）
    │  ＼
    │    ＼____________________  ← 使えば使うほど1日あたりは安くなる
    │
    │        レンタル（1日いくら）
    │       ／
    │     ／
    │   ／
    └────┴──────────────────────▶ 年間稼働日数
         損益分岐点
      ▲ コンバインのように「年10日しか使わないのに1台1,000万円級」は
        本来レンタル・受託向き。しかし収穫適期が地域で一斉に来るため
        貸し借りが成立しにくい ＝ だから日本の農家は買ってしまう
```

> ここが日本の農機市場の歪みの核心。**適期が全員同じ**（稲刈りは地域で2週間に集中する）ため、
> 共同利用やレンタルが理屈ほど機能しない。結果、稼働率の低い高額機を各戸が抱える。
> この非効率が、逆に言えば農機メーカーの売上を支えてきた。

## 5. 補助金と買い替えサイクル

農機は「買いたいときに買う」のではなく、**補助金が出るときに買う** 財である。

| 制度 | 中身 | 注意点 |
| --- | --- | --- |
| **スマート農業技術活用促進法**（2024年6月公布・10月施行） | 計画認定を受けると補助事業の優先採択、日本政策金融公庫の長期低利融資、税制特例が一体で受けられる | 認定が前提。誰でも自動で使えるわけではない |
| **投資促進税制（同法）** | 対象機械等の**特別償却32%**、建物等16%（令和9年3月末まで） | 償却の前倒しであって、補助金のような現金給付ではない |
| **強い農業づくり／産地生産基盤パワーアップ事業など** | 産地単位の設備・機械導入支援 | 産地の計画に紐づく。個人単独では使いにくい |
| **経営体育成支援・担い手向け融資** | 認定農業者向けのスーパーL資金など | 認定農業者になることが実質的な入口 |
| 自治体独自の上乗せ | 都道府県・市町村の独自補助 | 年度予算枠で早い者勝ちになりやすい |

> 効果としてよく言われるのが「**補助金が出る年度末に需要が集中する**」こと。
> 農機の国内出荷は年度末（1〜3月）と春の作業前に山が来る、季節性の強いビジネスになっている。

**買い替えサイクルを決める要素**

1. **物理寿命ではなく経済寿命**：トラクタは20年動くが、修理費がかさむ10〜15年目が判断点
2. **排ガス規制**：特殊自動車排出ガス規制の段階（3次・4次）で旧型は更新圧力がかかる
3. **農家の所得**：米価・野菜価格が良かった翌年に注文が出る
4. **補助金の有無**：上記。制度の年度と直結する
5. **後継者の有無**：後継者がいなければ機械は買わない。これが最も強い

```
【国内の買い替え意思決定】

   機械が古い  ─┐
   修理費が増加 ─┤
   補助金がある ─┼──▶ 「買う」
   所得が良い   ─┤
   後継者がいる ─┘        ▲ どれか1つでも欠けると「あと1年使う」に倒れる
                            とくに後継者の有無は決定的
```

## 6. メーカー側の収益構造

| 項目 | 目安・実例 | 出典・時点 |
| --- | --- | --- |
| クボタ 売上収益 | 3兆0,189億円、海外比率77.3% | 2025年12月期、IR |
| クボタ 通期純利益 予想 | 2,890億円（38%上方修正、3期ぶり最高益見通し） | 2026年8月、IR・報道 |
| 井関農機 営業利益率 | 2026年12月期2Qで**5.5%**（前年同期比+1.2pt） | 2026年8月、IR |
| 井関 構造改革目標 | 「プロジェクトZ」で2027年に営業利益率5%以上、4年間で営業CF500億円 | 2024〜2027年度、IR |
| 井関 営業CF進捗 | 2024年度88億円＋2025年度234億円＝計322億円 | IR |

読み取れること：

- **農機専業メーカーの営業利益率は5%前後が一つの壁**。自動車部品や工作機械より低い
- 理由は ①販売店・JAへの販管費が重い ②機種が多すぎて量産効果が出にくい
  ③国内は台数が細り固定費を吸収しにくい
- クボタが例外的に厚い利益を出せるのは **海外（とくに北米小型トラクタ）と建設機械** があるから。
  農機専業で国内中心だと、この水準には届かない
- だから各社が向かう先は同じ：**大型・高付加価値化、海外、そしてサービス（部品・整備・データ）**

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **系統ルート** | JAグループ（単位JA→経済連→全農）を通る商流。農機だけでなく肥料・農薬も同じ経路 |
| **商系ルート** | JAを通さない民間販売店・メーカー系販売会社の商流 |
| **全農** | 全国農業協同組合連合会。JAグループの購買・販売を束ねる全国組織 |
| **JA農機センター** | JAが運営する農機の販売・整備拠点。地域の整備インフラでもある |
| **下取り** | 買い替え時に旧機を引き取ること。査定額が実質的な値引きの調整弁になる |
| **補修部品（純正部品）** | 修理用の部品。競合が少なく粗利が厚いため、メーカーの安定収益源 |
| **コントラクタ** | 農作業受託事業者。機械と人をセットで提供する |
| **集落営農** | 集落単位で農地と機械を共同利用する組織。法人化すると農事組合法人などになる |
| **認定農業者** | 市町村が認定した経営改善計画を持つ農業者。補助金・融資の入口になる |
| **特別償却** | 取得年度に通常より多く減価償却できる税制優遇。納税を後ろ倒しにする効果 |
| **特殊自動車排出ガス規制** | 建機・農機のエンジンに課される排ガス規制。段階が上がると旧型が販売できなくなる |
| **経済寿命** | 物理的に動くかではなく「修理費より買い替えが得になる」時点で決まる寿命 |
