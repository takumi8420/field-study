# ① 製品と市場の構造

このノートで分かること：農機にはどんな機械があり、なぜ「日本の水田向け」と「北米の大規模畑作向け」が
まったく別のビジネスになるのか。そして国内が縮み海外が伸びるという **二重構造** の正体。

> 結論：農業機械は「1つの市場」ではない。**作物 × ほ場（畑・田んぼ）の広さ** で機械も価格も売り方も
> 完全に分かれる。日本メーカーは「狭いほ場向けの小型機」で世界に居場所を作り、
> その稼ぎ頭はもはや国内ではなく **北米の小型トラクタ** になっている。

## 1. 農機の4大機種と、その他大勢

農機は台数でも金額でも **トラクタが圧倒的** で、あとは作物別の専用機がぶら下がる形になっている。

| 機種 | 何をする機械か | 2025年の出荷額（推定） | 構成比 | ひとこと |
| --- | --- | --- | --- | --- |
| **トラクタ** | 自走する動力源。後ろに作業機を付け替えて耕す・運ぶ・撒く | 約2,156億円 | 約46% | 農機の"基幹"。単体では畑を耕せない |
| **コンバイン** | 刈り取りと脱穀（穂から籾を外す）を1台でやる収穫機 | 約854億円 | 約18% | 年に数日しか使わないのに最も高い |
| **田植機** | 育てた苗を水田に等間隔で植える | 約334億円 | 約7% | 日本・アジア固有。欧米にはほぼ市場がない |
| 刈払機・防除機ほか | 草刈り、農薬散布、乾燥機、管理機など | 残り約29% | — | 単価は低いが台数が多い |

（機種別は日本農業機械工業会＝日農工の出荷統計をもとにした集計値。2024年の農機出荷額は
前年比9.6%減の **3,790億円**、うち国内向け2,230億円・輸出1,561億円。2025年は前年比9.1%増の
**約4,679億円** と4年ぶりに増加に転じた、と集計サイト・業界紙ベースで報じられている）

> ポイント：**トラクタは「作業機（インプルメント）」を付けて初めて仕事をする**。
> ロータリ（土を砕く）、プラウ（土を反転させる）、ブロードキャスタ（肥料を撒く）などを
> 後部の三点リンク（規格化された取付部）に差し替える。
> だから農機メーカーは「本体を売って、その後に作業機を売り続ける」構造を持てる。

```
【トラクタ = プラットフォーム】

            ┌──────────────┐
  エンジン → │  トラクタ本体   │ ← ここだけ買っても何もできない
            │ （PTO軸・油圧・  │
            │   三点リンク）   │
            └───────┬──────┘
                    │ 付け替える
      ┌─────────┼─────────┬──────────┐
   ロータリ     プラウ      ブロードキャスタ   ハローほか
   （耕す）    （反転）      （施肥）        （代かき）
      ▲ 1台のトラクタに対し、作業機は生涯で何台も売れる
```

## 2. 「水田」と「大規模畑作」は別の産業である

同じ「農業機械」でも、日本の水田と北米コーンベルトでは **物理的な前提が違う**。
ここを押さえないと「なぜクボタはジョンディアと正面衝突しないのか」が分からない。

| 論点 | 日本（水田中心） | 北米（大規模畑作） |
| --- | --- | --- |
| ほ場1枚の広さ | 30a（＝0.3ha）区画が標準。30a以上に整備された水田は157万ha＝田全体の**約64%**、1ha以上はわずか23万ha（9%）（農水省資料） | 1区画で数十〜数百ha。区画という概念が薄い |
| 地面の条件 | 水を張った**軟弱な泥**。沈まないことが最優先 | 乾いた硬い土。牽引力が最優先 |
| トラクタの馬力帯 | **20〜60馬力**が主戦場 | **200〜600馬力**。大型は1台5,000万円超も |
| 車体の作り | 小型・小回り・四輪駆動・湿田用の幅広タイヤ | 巨大・高速・GPS前提・履帯（クローラ）も多い |
| 買う人 | 兼業農家〜小規模法人。1〜数台 | 数千haの大規模農場、コントラクタ（作業受託業者） |
| 収穫機 | **自脱型コンバイン**（稲の穂だけをこく日本独自方式） | 普通型コンバイン（作物ごと刈り込む） |
| 主なメーカー | クボタ、ヤンマー、井関 | ジョンディア（Deere）、CNH、AGCO、CLAAS |

> ここが最大のポイント：日本メーカーが世界で戦えているのは、
> **「大型で勝った」からではなく「小型という別の土俵を持っていた」から**。
> 北米でクボタが強いのは農場ではなく、**芝地・造園・馬の飼育場・別荘地**などを持つ
> 「ホビーファーマー／ランドオーナー」向けの小型トラクタ市場である。
> これは日本の水田向け小型機の技術がそのまま横展開できた領域だった。

```
【馬力帯で見た世界の棲み分け（イメージ）】

  0hp        50hp       100hp        200hp              600hp
  ├──────────┼──────────┼───────────┼──────────────────┤
  │  クボタ／ヤンマー／井関  │           │                  │
  │  ■■■■■■■■■■■■■■■■■■■│■■■■■■     │                  │
  │                      │           │                  │
  │            マヒンドラ（印）■■■■■■■│                  │
  │                      │           │                  │
  │                      │  Deere / CNH / AGCO / CLAAS  │
  │                      │  ■■■■■■■■■■■■■■■■■■■■■■■■■■■■■│
  └──────────┴──────────┴───────────┴──────────────────┘
     ホビー・小規模        中規模        大規模穀作（コーン・大豆・小麦）
     日本の水田            欧州の混合農業
```

## 3. 国内は縮む：農家が減っているという単純な理由

農機の国内需要は、景気でも技術でもなく **「機械を買う人が何人いるか」** でほぼ決まる。
そしてその母数が急速に減っている。

| 指標 | 数値 | 時点・出典 |
| --- | --- | --- |
| 基幹的農業従事者（主な仕事が農業の人） | **103.6万人** | 2025年 農林業センサス |
| 同 平均年齢 | **67.7歳** | 2025年 同上 |
| 5年間の減少 | 32.7万人減（**△24.0%**） | 2020→2025年。1985年以降で最大の減少率 |
| 25年間の減少 | 2000年 約240万人 → **△約57%** | 農水省統計 |
| 65歳以上の割合 | **69.6%** | 2025年 |
| 農業経営体の10年間の変化 | 全体 **△39.9%**、うち法人経営体は **+22.2%** | 2015→2025年 センサス |
| 20ha以上の経営体 | 日本の農地の**約半分**を耕作 | 2025年センサス分析（民間まとめ） |
| 耕地面積 | 約432万ha（水田率54%前後） | 農水省 耕地面積統計 |

この数字の読み方が重要で、**「市場が単純に縮む」のではなく「客層が入れ替わる」** という話である。

```
【国内農機市場で起きている置き換え】

   2000年代                      2020年代後半
 ┌──────────────┐        ┌──────────────┐
 │ 兼業農家 数百万戸   │        │ 法人・大規模経営体   │
 │ 1戸1ha前後        │  ───▶  │ 20ha〜数百ha       │
 │ 20〜30馬力を1台    │        │ 50〜100馬力を複数台 │
 │ 15〜20年使う       │        │ 稼働率高く5〜8年で更新│
 │ JA経由でまとめ買い  │        │ 直販・相見積り・リース│
 └──────────────┘        └──────────────┘
      台数：激減                    台数：微減／1件単価：大幅増
      ▲ 結果、台数は落ちるが金額の落ち方はそこまでではない
        ＝「台数減 × 単価増」の綱引きが国内市場の正体
```

> つまり国内は **「小型を大量に売るビジネス」から「大型・高機能を少数に売るビジネス」へ**
> 移行している。井関農機が構造改革「プロジェクトZ」で大型機・先端機に軸足を移しているのも、
> クボタが国内で大型トラクタを強化しているのも、同じ地殻変動への対応である。

## 4. 海外は伸びる：二重構造の正体

一方、世界の農機市場は人口増と新興国の機械化で長期的には拡大基調にある。
農業用トラクタ市場は **2026年に約784億ドル、2031年に約1,031億ドル（年率5.6%）** との
調査会社推計がある（MarketsandMarkets／Mordor系レポート。機関により定義も数値も幅がある点に注意）。

日本メーカーで海外比率が最も高いのがクボタで、ここが「二重構造」を最も分かりやすく表している。

| 指標 | 数値 | 時点・出典 |
| --- | --- | --- |
| クボタ 売上収益 | **3兆0,189億円**（前期比+0.1%） | 2025年12月期、クボタIR |
| うち **海外売上比率** | **77.3%**（前期比△1.7pt） | 同上 |
| 国内売上 | +8.3% | 同上 |
| 海外売上 | △2.1%（北米の小型トラクタ低迷） | 同上 |
| 2025年12月期 純利益 | 約1,960億円（前期比△15%） | 同上・報道 |
| 2026年12月期 2Q 売上 | 1兆6,903億円（前年同期比+16.2%） | 2026年8月4日 決算短信 |
| 同 2Q 純利益 | 1,737億円（**+87.8%**） | 同上 |
| 2026年12月期 通期 純利益 予想 | 2,100億円 → **2,890億円** に上方修正 | 2026年8月、3期ぶり最高益見通し |

> 読み替えると：**クボタの業績は「日本の農家」ではなく「米ドル・米国金利・米国の関税」で動く**。
> 2025年に北米小型トラクタが失速して減益、2026年に円安と米関税還付で急回復、というのがその証拠。
> 国内農機事業は安定した基盤ではあるが、利益の振れ幅を決めているのは海外である。

「クボタ10.22%で2位、ヤンマー4.19%で5位」といった数値は **推計値** として扱うこと。

## 6. なぜ農機は「サイクル産業」なのか

農機は自動車より **需要の波が荒い**。理由は3つ。

1. **農家の所得に直結する**。穀物価格が上がった翌年に注文が集中し、下がると一斉に止まる。
   トラクタは「欲しい」ではなく「今年の利益で買えるか」で判断される投資財である。
2. **買い替えを1〜2年先送りできる**。壊れなければ20年使える。景気後退局面では真っ先に延期される。
3. **在庫がディーラーに滞留する**。売れ行きが鈍るとメーカーは「減産して在庫を減らす（underproduce）」
   ため、需要の落ち込み以上に生産が落ちる。2026年の北米はまさにこの局面にある（→[④](04_直近トピック_2026.md)）。

```
【農機需要のサイクル】

 穀物価格↑ ──▶ 農家所得↑ ──▶ 設備投資↑ ──▶ 農機受注↑ ──▶ 増産
     ▲                                                    │
     │                                                    ▼
  作付け増 ◀── 生産拡大 ◀── 新型機で生産性↑        ディーラー在庫↑
     │                                                    │
     ▼                                                    ▼
 穀物価格↓ ──▶ 農家所得↓ ──▶ 買い替え先送り ──▶ 減産（underproduction）
                                                  ▲ 2026年の北米はここ
```

> 対して **日本の国内市場はこのサイクルが効きにくい**。米価の変動はあるが、
> 需要を決めている主因が「農家の数そのものの減少」という構造要因だからである。
> ここでも「国内＝構造的縮小、海外＝景気循環」という二重構造が現れる。

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **ほ場（圃場）** | 農作物を作る畑・田んぼの一区画。農機の議論では「1枚の面積」が決定的に重要 |
| **作業機／インプルメント** | トラクタに取り付けて仕事をさせる装置の総称。ロータリ、プラウ、ブロードキャスタなど |
| **三点リンク** | トラクタ後部の標準化された作業機取付部。規格があるのでメーカーをまたいで付く |
| **PTO軸** | Power Take-Off。エンジン動力を作業機へ回転で渡す軸。作業機を"動かす"ための仕組み |
| **自脱型コンバイン** | 稲を株ごと掴んで穂の部分だけ脱穀する日本独自方式。狭い水田と稲作に最適化されている |
| **普通型コンバイン** | 作物をまとめて刈り込んで内部で選別する欧米型。麦・大豆・とうもろこし向け |
| **代かき** | 田植え前に水を張った田の土を砕いて平らにする作業。ハローという作業機を使う |
| **馬力（hp／PS）** | トラクタの格を示す指標。日本は20〜60hp、北米大規模は200hp超が主戦場 |
| **コントラクタ** | 農作業を受託する事業者。自分の農地を持たず機械の稼働率で稼ぐ |
| **基幹的農業従事者** | ふだん仕事として主に農業に従事している人。農機の"実需の母数" |
| **農業経営体** | 一定規模以上で農業を営む単位（個人・法人）。法人だけは増えている |
| **アンダープロダクション** | 需要減より深く減産してディーラー在庫を抜く動き。農機業界特有の言い回し |
