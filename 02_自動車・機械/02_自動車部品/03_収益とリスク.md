# 自動車部品｜収益とリスク

**このノートで分かること**：部品メーカーの利益は**どこから出て、どこで消えるのか**。
そして、なぜ売上7兆円の会社でも営業利益率が一桁前半〜中盤にとどまるのか。

結論を先に書くと、部品メーカーは **「固定費の塊を、他人が決めた台数で割る商売」**。
自分で需要をコントロールできないのに、工場と金型と開発費は先に払う。
だから **利益の振れ幅は売上の振れ幅の数倍** になる。これが最大の特徴。

---

## 1. 利益が出る場所と消える場所（全体像）

```
   売上100
    │
    ├─ 材料費 45〜60 ──────────▶ 鋼材・樹脂・銅・アルミ・電子部品。市況で毎年動く
    │                              （買値が上がっても売値は3年前に決まっている）
    ▼
  付加価値 40〜55  ← 部品メーカーの本当の「取り分」はここ
    │
    ├─ 労務費 12〜20 ─────────▶ 賃上げ分は簡単には転嫁できない
    ├─ 減価償却 5〜10 ────────▶ 稼働率が落ちても1円も減らない【固定費】
    ├─ 金型・治具償却 2〜4 ───▶ 予定台数が出ないと回収不能
    ├─ 開発費 4〜9 ───────────▶ 受注前の先行投資は全額自腹
    ├─ 物流・エネルギー 3〜6 ─▶ かさばる部品ほど重い
    ├─ 販管費 5〜8
    ├─ 品質費用（保証・リコール引当）0〜数% ▶ **平時ゼロ、有事に数百億円**
    ▼
  営業利益 3〜8   ← ここだけが残る
```

上の配分は各社IRから起こした**概算レンジ**で、電装系（材料費が低く開発費が高い）と
プレス・鋳造系（材料費が高く償却が重い）でまったく違う。

| 実例（公表決算） | 売上 | 営業利益 | 営業利益率 |
| --- | --- | --- | --- |
| デンソー（2026年3月期） | 7兆5,399億円（過去最高） | 5,525億円 | **約7.3%** |
| アイシン（2026年3月期・報道集計ベース） | 約4.9兆円 | — | 約4%台 |

※ デンソーは2027年3月期について純利益13.9%減の見通しを示したと報じられる（2026年4月）。
売上は最高でも、関税と投資増で利益は伸びない、という構図になっている。

## 2. 利益が「出る」4つの源泉

| 源泉 | 中身 | なぜ利益になるか |
| --- | --- | --- |
| **① 償却が終わった量産品** | モデル末期の部品 | 設備投資の回収が済んでいるので、限界利益がほぼそのまま営業利益になる |
| **② 補修部品（アフターマーケット）** | ブレーキパッド、フィルター、ワイパー、電装品 | 新車向けの数倍の単価で売れることがある。**年次値下げの対象外**。保有台数に連動するので景気に鈍感 |
| **③ 承認図・独自技術の部品** | センサー、ハーネス設計、制御ソフト、ブレーキ制御 | 代替が効かないので価格交渉力がある（→ [取引の構造](02_取引の構造.md)） |
| **④ 工程改善（原価低減）の差分** | 歩留まり向上、段取り短縮、内製化 | 年次値下げ率を上回って原価を下げられた分が、そのまま利益になる |

> 教科書的には ①＋② が利益の柱。
> **新車向けの量産品は「工場を埋めるための仕事」であり、そこで大儲けする商売ではない**。
> 稼働率を確保して固定費を回収し、補修と末期モデルで利益を積む、というのが伝統的な収益構造。

---

## 3. 利益が「消える」7つの穴

| 穴 | 起きること | 典型的なインパクト |
| --- | --- | --- |
| **① 稼働率の低下** | OEMの減産、リコール、半導体不足、認証不正などで台数が減る | 固定費は減らないので**減った売上がほぼそのまま利益減**になる |
| **② 年次値下げ（CR）** | 毎年1〜3%程度の値下げ（慣習的な目安） | 改善が追いつかないと利益率がじりじり削れる |
| **③ 立ち上げ（ランプアップ）の失敗** | 量産初期の不良、設計変更、追加工 | 新規受注案件が数年間赤字を垂れ流す |
| **④ 開発費の先行投資** | 受注前の提案・試作、EV/SDVへの投資 | 失注すれば全額が損失。当たっても回収は5年後 |
| **⑤ 品質費用・リコール** | 不具合が見つかると回収・交換費用をOEMから求償される | トヨタ紡織はシートのリコール関連費用約160億円を2026年3月期に計上。デンソーの品質問題では460億円規模の追加賠償が報じられた |
| **⑥ 為替と原材料** | 円安・銅高・樹脂高。売値は3年前に固定 | 転嫁交渉が通るまで1〜2四半期のタイムラグがある |
| **⑦ 関税・地政学** | 米国の自動車・部品関税（2025年発動） | 生産移転か価格転嫁かの二択を迫られる。中小Tier2は価格決定力が弱く逃げ場が少ない |

### ①がなぜ致命的か：損益分岐点の算数

```
  【前提】固定費 年40億円、限界利益率 30%、計画売上 200億円
       損益分岐点売上 ＝ 40億 ÷ 0.30 ＝ 約133億円

   売上200億 → 限界利益60億 − 固定費40億 ＝ 営業利益 20億（利益率10%）
   売上170億 → 限界利益51億 − 固定費40億 ＝ 営業利益 11億（利益率 6.5%）
   売上140億 → 限界利益42億 − 固定費40億 ＝ 営業利益  2億（利益率 1.4%）
   売上120億 → 限界利益36億 − 固定費40億 ＝ 営業損失 △4億

   売上が15%減ると利益は45%減り、30%減ると赤字に落ちる
   ＝ 【オペレーティングレバレッジ】が非常に高い
```

限界利益率（売上から材料費など変動費を引いた割合）が30%程度しかない一方、
固定費が大きいため、**売上の小さな変動が利益を大きく揺らす**。
自動車部品メーカーの決算が「上振れ・下振れ」しやすいのはこの構造のせい。

## 4. 案件1件のキャッシュフロー：Jカーブ

```
 キャッシュ
   ▲
   │                                     ┌───── 補修部品で長期回収
   │                            ┌────────┘
 0 ┼───────────────┬─────┬─────┘ ← 累計で黒字化するのは量産4〜5年目
   │        ╲      │     │
   │          ╲____│     │
   │   先行開発  ＼_金型・設備投資
   │   （自腹）      ＼__立ち上げ赤字
   ▼
   ├─────┬─────┬─────┬─────┬─────┬─────┬─────▶
   -3年  -2年  -1年  SOP   +1年  +3年  +5年   EOP
```

この形から出てくる経営上の帰結が3つある。

1. **受注を止めると数年後に売上が消える**。だから赤字でも受注を取りにいく力学が働く
2. **モデルチェンジが重なる年は投資が集中してキャッシュが薄くなる**
3. **途中で車種が販売不振になると、投資を回収できないまま終わる**（最大のリスク）

## 5. 事業別の利益率のクセ

| 領域 | 営業利益率の傾向 | 理由 |
| --- | --- | --- |
| 電装・電子・センサー | 高め（8〜12%） | 承認図が多く、材料費比率が低い。ソフト・制御で差がつく |
| ブレーキ・ステアリング等の保安部品 | 中〜高（6〜10%） | 認証と実績が壁になり、価格が崩れにくい |
| ベアリング・シール等の機能部品 | 中（5〜10%） | 市販品として複数顧客に売れる。自動車以外にも展開できる |
| 変速機・エンジン部品 | 中（3〜7%） | 設備が重く償却負担が大きい。加えてEVで先細り |
| シート・内装・プレス | 低（2〜5%） | かさばるため物流費が重く、材料費比率が高い。単価が大きいだけ |
| 電池パック・eAxle等の新領域 | **足元は赤字〜低収益** | 立ち上げ期で稼働率が低く、償却が先行する |

> ここが重要：**売上の大きい領域ほど利益率が低い**という逆転が起きている。
> シートは1台あたり数万円の売上になるが利益率は数%、センサーは1個数百円でも利益率は二桁。
> 「売上規模」で部品メーカーを評価すると必ず読み違える。

## 6. バランスシートに出るリスク

| 項目 | リスクの中身 |
| --- | --- |
| **有形固定資産** | 専用設備は他の仕事に転用できない。車種が終わると**簿価だけが残り、減損損失になる** |
| **棚卸資産** | 内示の狂いと、補修用の長期在庫。EOP後10年分の部品を持たされることがある |
| **売掛金** | OEM向けは焦げ付きにくいが、サプライヤーの破綻（マレリ等）ではTier2側に連鎖する |
| **品質関連引当金** | 保証費用の見積。不具合が判明した期に一括計上され、業績を直撃する |
| **のれん** | 電動化対応の買収で積み上がる。計画未達だと減損 |

---

## 7. リスクを外部化する仕組み

| 手段 | 中身 | 限界 |
| --- | --- | --- |
| 複数顧客化 | トヨタ系でもホンダ・海外OEMにも売る | 系列の壁と、顧客同士の情報遮断が必要 |
| 非自動車展開 | 産業機械、航空、家電、医療へ横展開 | 自動車の量産規模に慣れた工場は小ロットに向かない |
| 地産地消 | 需要地の近くで作り、為替と関税と物流費を同時に潰す | 投資が二重になる。稼働率が下がる |
| 生産の変動費化 | 派遣・期間工、外注比率の調整 | 技能の蓄積が失われる。労働法制の制約 |
| リコール保険 | 製品回収費用保険、PL保険 | 保険で埋まるのは一部。信用の毀損は埋まらない |
| 価格改定条項 | 原材料市況との連動、労務費の転嫁 | 取適法で後押しされたが、**電気代・償却費の転嫁は依然として難しい** |

## 8. まとめ：この業界の利益方程式

> **営業利益 ＝（承認図品と補修品の厚い粗利）＋（工程改善の差分）
> −（年次値下げ）−（稼働率割れによる固定費の空振り）−（先行開発費）−（品質費用）**

「稼働率」と「承認図比率」の2つの言葉で、この業界の決算の8割は説明できる。
そして電動化・SDVは、**この方程式の右辺のすべてを一度に悪化させる**方向に効いている
（→ [電動化・SDVで何が変わるか](04_電動化・SDVで何が変わるか.md)）。

## 用語メモ

- **限界利益**：売上から変動費（主に材料費）を引いた額。固定費を賄う原資
- **損益分岐点売上高**：固定費 ÷ 限界利益率。これを下回ると赤字
- **オペレーティングレバレッジ**：固定費比率の高さから生じる、売上変動に対する利益の増幅度
- **付加価値**：売上 − 材料費。有償支給の影響を除いて会社の実力を見るときの指標
- **ランプアップ**：量産立ち上げ。歩留まりと生産速度が計画値に届くまでの期間
- **求償**：リコール費用などを原因企業に請求すること。部品メーカー最大の一撃リスク
- **減損損失**：回収見込みが立たなくなった固定資産の簿価を一気に切り下げる会計処理
- **引当金**：将来発生する見込みの費用を、あらかじめ費用計上しておくもの
- **地産地消**：販売する地域で生産すること。為替・関税・物流リスクの同時対策
- **Jカーブ**：先に赤字、後から黒字になる投資回収の形
