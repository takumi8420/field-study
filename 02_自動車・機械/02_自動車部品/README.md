# 自動車部品

- 大分類: 自動車・機械
- 状態: done
- 更新日: 2026-09-20

**一言でいうと**：完成車メーカー（OEM）の設計に合わせて、クルマを構成する約3万点の部品を作り、
量産開始から生産終了まで7年前後、その後の補修まで含めて15年以上供給し続ける産業。
**儲けの源泉は「工場の稼働率」と「自分で図面を描けるかどうか」**の2つに集約される。

## 1. 業界の定義・範囲

- **自動車部品**＝完成車メーカーに納入される部品・ユニット、および市場に出た車の補修用部品を作る産業
- 自ら車両の型式認証を取って自社ブランドで売る会社は [自動車（完成車）](../01_自動車（完成車）/README.md) 側
- 隣接業界との線引き

| 隣 | 境界 |
| --- | --- |
| [タイヤ](../03_タイヤ/README.md) | ゴムから作る素材系装置産業で、補修比率が突出して高いため別扱い |
| [ベアリング](../10_ベアリング/README.md)／[モーター](../15_モーター/README.md) | 自動車以外（産業機械・家電）にも同じ製品を売るため独立業界として扱う |
| [電子部品](../../03_電機・電子部品/05_電子部品/README.md)／[半導体](../../03_電機・電子部品/02_半導体（ロジック・メモリ）/README.md) | 車載グレードは品質規格（AEC-Q）と長期供給義務が別物。電機側から自動車への流入が続いている |
| 整備・カー用品 | 部品を「作る」のではなく「取り付ける・売る」川下 |

## 2. 市場規模と成長性

| 指標 | 数値 | 出典・年 |
| --- | --- | --- |
| 国内の自動車部品出荷額 | **20兆7,070億円** | JAPIA「自動車部品出荷動向調査」2024年度（有効回答293社）／2026年3月公表 |
| 最大手の売上 | デンソー **7兆5,399億円**（過去最高） | デンソー 2026年3月期決算 |
| 乗用車1台の部品点数 | 約3万点（エンジン車）／約2万点（BEV） | 業界で広く使われる概数。数え方で幅がある |
| 供給責任の期間 | 量産7年前後＋補修10年前後 | 商慣習・契約ベース |

- 需要は**世界の新車生産台数**にほぼ連動する。したがって自社では需要を作れない
- 成長ドライバーは台数ではなく **1台あたり単価**。電動化と電子化で、1台に載る金額は増えている
- ただし増えた金額の多くは電池・半導体・ソフトへ移り、**従来の機構部品の取り分は増えない**

**付加価値が集まる場所**：自分で設計する部品（承認図品）と、償却が終わった量産品、
そして補修部品。逆に、図面を渡されて加工するだけの工程には利益が残らない。

| 企業 | 立ち位置 | 特徴 |
| --- | --- | --- |

## 5. 収益モデル・コスト構造

- **収益**：新車向け量産（薄利・大量・毎年値下げ）＋補修向け（厚利・少量・値下げなし）
- **コスト**：材料費45〜60%、労務費12〜20%、減価償却5〜10%、開発費4〜9%（概算レンジ、領域で大きく変動）
- **利益率**：営業利益率は一桁前半〜中盤が中心。デンソーで約7.3%（2026年3月期）
- **固定費が重く、限界利益率が30%前後**しかないため、売上が15%落ちると利益は半減する

> 利益方程式：**（承認図品と補修品の粗利）＋（工程改善の差分）−（年次値下げ）−（稼働率割れ）−（先行開発費）−（品質費用）**

詳細は [収益とリスク](03_収益とリスク.md)。

## 6. 競争要因（KSF）と参入障壁

| KSF | 中身 |
| --- | --- |
| **承認図比率** | 自社で設計し責任を持てる部品をどれだけ持つか。価格交渉力の源泉 |
| **稼働率** | 固定費を埋められる受注量。複数OEM・非自動車への展開で平準化する |
| **品質保証体制** | IATF 16949、工程変更承認、トレーサビリティ。無事故の実績そのものが資産 |
| **立地** | かさばる部品は組立工場の近くでしか作れない。地産地消は為替・関税対策でもある |
| **原価低減の筋力** | 年1〜3%の値下げを飲み続けても利益を残せる改善能力 |
| **電動・ソフトへの転換速度** | 内燃機関のキャッシュを、いつ・いくら新領域へ振り向けられるか |

**参入障壁**：量産品質の証明、長期供給義務、リコール時の賠償能力、そして
「工程を変えるにもOEMの承認が要る」という取引の粘着性。技術だけでは入れない。

## 7. 規制・法制度

| 制度 | 中身 |
| --- | --- |
| **取適法（中小受託取引適正化法）** | 改正下請法。**2026年1月1日施行**。価格転嫁の協議義務、従業員数基準の導入、手形規制の強化 |
| 道路運送車両法・保安基準 | 部品の性能要件。指定部品制度、リコール届出（国土交通省） |
| IATF 16949 | 自動車産業の品質マネジメント規格。事実上の取引条件 |
| ISO 26262 / UN-R155 / UN-R156 | 機能安全／サイバーセキュリティ／ソフトウェア更新の要求。SDV時代の必須要件 |
| 米国の自動車・部品関税 | 2025年発動の25%追加関税。生産移転か価格転嫁かの判断を迫る |
| 独占禁止法・優越的地位の濫用 | 型の無償保管、一方的な代金減額などが問題行為として整理されている |
| 補助金・政策 | 事業再構築・省エネ補助、グリーンイノベーション基金、地域の産業転換支援 |

## 9. 用語メモ

用語は各ノート末尾の「用語メモ」にまとめている。特に重要なのは次の5語。

| 用語 | 意味 |
| --- | --- |
| **承認図／貸与図** | 部品メーカーが設計しOEMが承認する／OEMの図面どおり作る。利益率を分ける最大の境界 → [取引の構造](02_取引の構造.md) |
| **CR（原価低減）** | 継続取引品に対する年次の値下げ要請。慣習的に年1〜3%程度とされる → [取引の構造](02_取引の構造.md) |
| **SOP／EOP** | 量産開始／生産終了。SOPの2〜3年前に価格が決まる → [取引の構造](02_取引の構造.md) |
| **限界利益と損益分岐点** | 固定費が重いため、売上変動が利益を数倍に増幅する → [収益とリスク](03_収益とリスク.md) |
| **カーブアウト** | 内燃機関事業などを切り出して売却すること → [電動化・SDVで何が変わるか](04_電動化・SDVで何が変わるか.md) |
