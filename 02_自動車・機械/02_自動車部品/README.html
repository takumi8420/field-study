1. 業界の定義・範囲

  • 自動車部品＝完成車メーカーに納入される部品・ユニット、および市場に出た車の補修用部品を作る産業
  • 自ら車両の型式認証を取って自社ブランドで売る会社は 自動車（完成車） 側
  • 隣接業界との線引き
隣 境界
タイヤゴムから作る素材系装置産業で、補修比率が突出して高いため別扱い
ベアリング／モーター自動車以外（産業機械・家電）にも同じ製品を売るため独立業界として扱う
電子部品／半導体車載グレードは品質規格（AEC-Q）と長期供給義務が別物。電機側から自動車への流入が続いている
整備・カー用品部品を「作る」のではなく「取り付ける・売る」川下

  • 需要は世界の新車生産台数にほぼ連動する。したがって自社では需要を作れない
  • 成長ドライバーは台数ではなく 1台あたり単価。電動化と電子化で、1台に載る金額は増えている
  • ただし増えた金額の多くは電池・半導体・ソフトへ移り、従来の機構部品の取り分は増えない

5. 収益モデル・コスト構造

  • 収益：新車向け量産（薄利・大量・毎年値下げ）＋補修向け（厚利・少量・値下げなし）
  • コスト：材料費45〜60%、労務費12〜20%、減価償却5〜10%、開発費4〜9%（概算レンジ、領域で大きく変動）
  • 利益率：営業利益率は一桁前半〜中盤が中心。デンソーで約7.3%（2026年3月期）
  • 固定費が重く、限界利益率が30%前後しかないため、売上が15%落ちると利益は半減する

利益方程式：（承認図品と補修品の粗利）＋（工程改善の差分）−（年次値下げ）−（稼働率割れ）−（先行開発費）−（品質費用）

詳細は 収益とリスク。

6. 競争要因（KSF）と参入障壁

KSF 中身
承認図比率自社で設計し責任を持てる部品をどれだけ持つか。価格交渉力の源泉
稼働率固定費を埋められる受注量。複数OEM・非自動車への展開で平準化する
品質保証体制IATF 16949、工程変更承認、トレーサビリティ。無事故の実績そのものが資産
立地かさばる部品は組立工場の近くでしか作れない。地産地消は為替・関税対策でもある
原価低減の筋力年1〜3%の値下げを飲み続けても利益を残せる改善能力
電動・ソフトへの転換速度内燃機関のキャッシュを、いつ・いくら新領域へ振り向けられるか

参入障壁：量産品質の証明、長期供給義務、リコール時の賠償能力、そして
「工程を変えるにもOEMの承認が要る」という取引の粘着性。技術だけでは入れない。

7. 規制・法制度

制度 中身
取適法（中小受託取引適正化法）改正下請法。2026年1月1日施行。価格転嫁の協議義務、従業員数基準の導入、手形規制の強化
道路運送車両法・保安基準部品の性能要件。指定部品制度、リコール届出（国土交通省）
IATF 16949自動車産業の品質マネジメント規格。事実上の取引条件
ISO 26262 / UN-R155 / UN-R156機能安全／サイバーセキュリティ／ソフトウェア更新の要求。SDV時代の必須要件
米国の自動車・部品関税2025年発動の25%追加関税。生産移転か価格転嫁かの判断を迫る
独占禁止法・優越的地位の濫用型の無償保管、一方的な代金減額などが問題行為として整理されている
補助金・政策事業再構築・省エネ補助、グリーンイノベーション基金、地域の産業転換支援

9. 用語メモ

用語は各ノート末尾の「用語メモ」にまとめている。特に重要なのは次の5語。

用語 意味
承認図／貸与図部品メーカーが設計しOEMが承認する／OEMの図面どおり作る。利益率を分ける最大の境界 → 取引の構造
CR（原価低減）継続取引品に対する年次の値下げ要請。慣習的に年1〜3%程度とされる → 取引の構造
SOP／EOP量産開始／生産終了。SOPの2〜3年前に価格が決まる → 取引の構造
限界利益と損益分岐点固定費が重いため、売上変動が利益を数倍に増幅する → 収益とリスク
カーブアウト内燃機関事業などを切り出して売却すること → 電動化・SDVで何が変わるか
