# 自動車部品｜電動化・SDVで何が変わるか

**このノートで分かること**：電動化とソフトウェア化が、**部品メーカーの損益計算書とバランスシートに何をするのか**。
「エンジン部品が減ってモーターが増える」という物の話は
[EV・電動化｜クルマの構造がどう変わるか](../../01_注目テーマ/03_EV・電動化/01_クルマの構造がどう変わるか.md) に譲り、
ここでは **経営としてどう詰むのか／どう逃げるのか** を扱う。

結論を先に書くと、電動化は部品メーカーにとって
**「一番儲かっている事業が縮み、一番投資が要る事業が赤字で立ち上がる」** という最悪の順番でやってくる。
そして、その入れ替えを終えた頃には **利益率の高い設計の仕事がOEMとソフト企業に持っていかれている**可能性がある。

---

## 1. 財務上、何が起きるのか（順番が残酷）

```
   利益
    ▲
    │ ━━━━━━━━━━━━━━━━━━━━━━━━  内燃機関事業（償却済み・高採算）
    │            ╲
    │              ╲＿＿＿          ← 台数減と値下げでじわじわ縮む
    │                    ╲＿＿＿＿＿
  0 ┼────────────────────────────────────────────▶ 時間
    │  ＼                          ＿＿＿━━━━━  電動・ソフト事業
    │    ＼＿＿＿＿＿＿＿＿＿＿＿＿／
    │      新規投資（工場・開発・人材）が先行 → 数年間は赤字
    ▼
     ↑ この「谷」を、縮んでいく内燃機関事業のキャッシュで埋める必要がある
```

- **内燃機関（ICE）部品は、実は今いちばん利益率が良い**。設備の償却が終わり、工程も練り上がっているから
- その稼ぎ頭が、台数ベースで年々細っていく（HEVが残るため消滅はしないが成長はしない）
- 一方、eAxle・電池関連・パワーエレクトロニクスは立ち上げ期で**稼働率が低く、償却が重く、赤字**
- しかも新規領域では **中国・韓国勢がすでに量産効果を持っている**ため、価格が最初から低い

> ポイント：問題は「エンジン部品が無くなること」ではなく、
> **無くなるまでに10〜15年かかること**。だらだら縮む事業のために設備と人を維持しながら、
> 同時に新規事業へ投資しなければならない。**二重負担の期間が長い**のがいちばんきつい。

## 2. 事業ポートフォリオの4つの出口

実際に日欧のサプライヤーが取っている手は、おおむね次の4つに分類できる。

| 出口 | やること | 実例（報道・公表ベース） | 効くための条件 |
| --- | --- | --- | --- |
| **① 売る（カーブアウト）** | 内燃機関事業を切り出し、ファンドや同業に売却 | デンソーが内燃機関関連事業の売却を進め、規模は総額1兆円超と報じられる（2024年〜）。三菱電機が車載機器事業の再編・出資受け入れ・売却も選択肢と報じられる（2026年2月） | 買い手がいること。黒字のうちに売ること |
| **② 集める（ロールアップ）** | 縮む市場の同業を買い集め、シェアを上げて最後まで稼ぐ | ピストンリング・排気系・燃料系などで統合が進む | 業界全体で供給能力を減らせること |
| **③ 組み替える（転換）** | 同じ工法・設備で別の製品を作る。産業機器・航空・エネルギーへ | 精密加工→燃料電池部品、鍛造→風力・建機部品 など | 量産規模の違いを吸収できること |
| **④ 上に行く（ソフト・システム化）** | 単品部品からシステム・ソフト供給者へ | ウーブン・バイ・トヨタ（トヨタ・デンソー・アイシン出資）が車載ソフト基盤「Arene」を開発 | ソフト人材と、OEMとの役割分担の合意 |

### 資本構造そのものの組み替え

2025〜2026年に日本で起きているもう一つの大きな動きが、**親子上場の解消**。

- トヨタ等による**豊田自動織機のTOBが2026年3月に成立**し、上場廃止へ。買収総額は**約5.9兆円**で
  日本企業同士のM&Aとして過去最大（報道）
- 狙いは、短期の業績期待から切り離して**長期の投資判断を速くする**こと。
  上場子会社のままでは、少数株主のために「今期の利益」を守らねばならず、
  10年かかる電動化投資と相性が悪い

```
  【従来】                          【再編後】
   OEM ──30%出資── 上場Tier1        OEM ──100%── 非上場Tier1
                    │                              │
              少数株主（短期の利益を要求）      少数株主なし
              → 減損も撤退も決断が遅れる       → 一気に事業を切れる
```

## 3. SDV化が部品メーカーの「取り分」を動かす

SDV（Software Defined Vehicle＝ソフトで機能が決まる車）が進むと、
車内の電子部品の作り方と売り方が変わる。技術的な中身は
[EV・電動化](../../01_注目テーマ/03_EV・電動化/01_クルマの構造がどう変わるか.md) と
[自動運転](../../01_注目テーマ/15_自動運転/README.md) を参照。ここでは商売の話に絞る。

| 項目 | 従来（分散ECU） | SDV（集約＋ソフト分離） | 部品メーカーへの影響 |
| --- | --- | --- | --- |
| 納品物 | ハード＋ソフトが一体のECU（中身はブラックボックス） | ハード（コンピューター）と、その上で動くソフトが分離 | **ソフトの値段を別建てで取りにくくなる** |
| 値付け | 「部品1個いくら」。ソフト開発費はハード単価に埋め込んで回収 | ハードは汎用化して価格競争。ソフトはOEM内製 or ライセンス | 利益の乗せどころが消える恐れ |
| 仕様変更 | 量産開始で凍結 | 出荷後もOTAで更新 | **量産終了後もソフト保守の責任が続く**（コストは誰が持つ？） |
| 差別化の源泉 | 機構設計、小型化、コスト | アルゴリズム、統合制御、更新の速さ | 評価軸が土俵ごと変わる |
| 人材 | 機械・電気の技術者 | ソフトウェアエンジニア、サイバーセキュリティ | 採用競争の相手がIT業界になる |

> 最大の論点は **「ソフトの代金を誰がどう払うか」**。
> 従来は「ECU 1個 8,000円」の中にソフト開発費が溶けていた。
> ハードが汎用化してソフトが分離されると、部品メーカーは
> **安いハードを売る会社**になりかねない。ここで踏みとどまれるかが分かれ目。

### ソフト人材の壁

- 車載ソフトは「動けばいい」では済まない。機能安全（ISO 26262）、サイバーセキュリティ（UN-R155）、
  OTA更新の法規（UN-R156）といった**認証の塊**で、一般的なWeb開発とは要求が違う
- つまり **IT業界から人を採っても、そのままでは戦力にならない**。教育に数年かかる
- 一方で待遇水準はIT業界に引っ張られる。**製造業の賃金体系のままでは採れない**
- 結果として、(a) 別会社を作って別の給与体系にする、(b) 海外（インド・ベトナム・中国）の開発拠点に頼る、
  (c) OEMと合弁で人材をプールする、という形が取られている

## 4. 供給側の地図がどう塗り替わるか

| プレイヤー | 電動化・SDVでの立ち位置 | 2024〜2026年に起きたこと |
| --- | --- | --- |
| 日系メガサプライヤー（デンソー、アイシン） | 熱・電動・センサーで戦えるが、内燃機関の後始末が重い | 内燃機関事業のカーブアウト、グループ内の事業交換 |
| 欧州メガサプライヤー（Bosch、ZF、Continental） | EV投資と欧州市場の失速が同時に来て資金繰りが悪化 | Boschが最大5,500人、ZFがドイツで2028年末までに最大14,000人の削減を公表。Continentalは自動車部門の分離を検討と報じられる |
| 系列Tier1（マレリ、河西工業ほか） | 特定OEMへの依存度が高く、その1社の不振を直撃で受ける | マレリが2026年6月にチャプター11を申請と報じられ、日産・ステランティスが資産取得を協議 |
| 電機・電子からの参入組 | パワー半導体、モーター、コネクタで自動車の比重を上げる | 一方で三菱電機のように**車載から退く**判断も出ている |
| 中国サプライヤー | 電池・電動ユニット・スマートコックピットで先行。開発サイクルが速い | 中国市場では中国ブランドが約7割のシェアを取り、日系OEMも中国部品の採用比率を上げている |

```
  価値の移動（ざっくりした方向）

   [消える／縮む]              [残る]                [伸びる]
   燃料噴射・点火 ─┐        プレス・シート        電池セル・パック
   排気・触媒     ─┤        ブレーキ・サス        eAxle（モーター＋INV）
   多段変速機     ─┤  ──▶  ベアリング     ──▶  パワー半導体（SiC）
   スターター等   ─┘        ハーネス(*)          熱マネジメント
                                                  高性能コンピューター
                                                  ソフト・OTA基盤
   (*) ハーネスは高電圧化で単価が上がる一方、
       ゾーンアーキテクチャで配線長が減る。増減が相殺されうる
```

## 5. HEVという「時間稼ぎ」をどう使うか

- ハイブリッド（HEV）は**エンジンも電動ユニットも両方要る**ため、部品点数と部品金額はむしろ多い
- 2024〜2026年にかけて世界のBEV需要の伸びが想定を下回り、HEVが伸びた。
  結果として**日系サプライヤーの延命につながった**
- ただしこれは需要の先送りであって、構造問題の解決ではない。
  **HEVで稼いだキャッシュを電動・ソフトへ投資に回せているか**が、企業ごとの明暗を分ける

| 姿勢 | 中身 | 5年後 |
| --- | --- | --- |
| HEVの利益を配当・自社株買いに回す | 目先の株主還元は良い | 電動領域で戦えない |
| HEVの利益を新領域へ投資 | 短期の利益率は下がる | 生き残る可能性 |
| 内燃機関を売って新領域へ集中 | 売上は減る。減損の可能性 | 身軽になる。ただし買い手が要る |

## 6. 誤解を潰しておく

| よくある誤解 | 実際 |
| --- | --- |
| 「EV化で部品メーカーは全滅する」 | 消えるのは主にパワートレイン系。車体・足回り・内装・電装は残る。むしろ**電装は伸びる** |
| 「部品が減るから部品メーカーの売上も減る」 | 1台あたりの**金額**は電池を含めると増える。問題は**その金額を誰が取るか**（電池メーカーと半導体に移る） |
| 「ソフトを作れば儲かる」 | ソフト単体で課金する商習慣がまだ確立していない。認証コストと長期保守義務が重い |
| 「系列に守られているから安泰」 | 親会社が減産・不振に陥ると逃げ場がない。マレリ・河西工業の例がそれ |
| 「日本は電動化で完全に出遅れた」 | 電池材料、パワー半導体、モーター用磁石・鋼板、精密加工では依然として強い領域がある |

## 用語メモ

- **ICE**：Internal Combustion Engine。内燃機関＝エンジン
- **カーブアウト**：事業の一部を切り出して別会社化し、売却または独立させること
- **ロールアップ**：同業を買い集めて規模を作る戦略
- **親子上場**：親会社と子会社の両方が上場している状態。少数株主との利益相反が問題視される
- **TOB**：株式公開買付け。市場外で株式をまとめて買い付ける手続き
- **SDV**：Software Defined Vehicle。ソフトウェアで機能が決まる車
- **OTA**：Over The Air。無線経由のソフトウェア更新
- **ゾーンアーキテクチャ**：機能別ではなく車体の場所別に電子系をまとめる配線設計
- **ISO 26262**：自動車の機能安全規格。故障しても危険側に倒れない設計を要求する
- **UN-R155／R156**：国連基準。車両のサイバーセキュリティ管理／ソフトウェア更新管理を義務づける
- **eAxle**：モーター＋インバーター＋減速機を一体化した駆動ユニット
- **SiC**：炭化ケイ素。電力損失の小さいパワー半導体材料
