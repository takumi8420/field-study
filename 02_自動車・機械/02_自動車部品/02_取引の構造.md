# 自動車部品｜取引の構造

**このノートで分かること**：部品メーカーは誰と、どういう契約で、何年の付き合いをするのか。
そして **なぜ「毎年値下げ」を受け入れながら会社が潰れずに回ってきたのか**。

結論を先に書くと、自動車部品の取引は **「一度取ったら7〜10年続くが、その間ずっと値段が下がり続ける」** という
特殊な形をしている。受注時点では赤字、量産3〜4年目で黒字、モデル末期で稼ぐ。
この時間のズレを理解しないと、部品メーカーの決算も設備投資も読めない。

---

## 1. 時間軸：受注から供給終了まで15年以上

```
 [-4年]  [-3年]   [-2年]   [-1年]   SOP   +1  +2  +3  +4  +5  +6  +7年  →  補修供給+10年
   │       │        │        │       │
 先行開発  RFQ／   設計確定  量産準備 量産  ─── モデルライフ（4〜7年）───┐
 提案     見積     試作     金型製作 開始                              │
   │       │        │        │       │                              ▼
   ▼       ▼        ▼        ▼       ▼                          生産終了（EOP）
 自腹で   価格を  仕様凍結  金型と   ここで                    その後も補修部品を
 技術を   ここで  （後の変更 設備に  初めて                    10年前後供給する義務
 仕込む   握る    は有償交渉）大金    入金が                    （法規ではなく商慣習
          ↑              が出る   始まる                      ＋契約による）
       ここで一生分の利益が決まる
```

> ポイント：**価格は量産が始まる2〜3年前に決まる**。
> その後に原材料が上がっても為替が動いても、決めた値段で7年売り続ける。
> だから部品メーカーの決算は「今期の原材料市況」ではなく「3年前の見積の精度」で決まる部分が大きい。

| 段階 | 部品メーカーの資金 | 何が起きているか |
| --- | --- | --- |
| 先行開発（受注前） | **出ていく一方** | 受注できる保証はない。落とせば全額が損失 |
| RFQ〜量産準備 | 出ていく | 試作品は少量生産なので原価も高い。金型・専用設備への投資が集中 |
| 量産初期（SOP〜1年） | まだ赤字のことが多い | 立ち上げ不良、歩留まり低下、生産台数が計画未達になりがち |
| 量産中期（2〜5年） | ここで回収 | 歩留まりが安定し、工程改善で原価が下がる。**値下げ幅より改善幅が大きければ利益が出る** |
| 量産末期・補修 | 高採算 | 設備の償却が終わっている。補修部品は単価も高い |

## 2. 誰が図面を描くか：承認図・貸与図・市販品

部品取引を理解する一番の鍵は **「その部品の設計責任を誰が持つか」**。ここで利益率がまったく変わる。

| 類型 | 図面を描く人 | 設計責任 | 価格交渉力 | 典型例 |
| --- | --- | --- | --- | --- |
| **貸与図**（たいよず） | 完成車メーカー。部品メーカーは図面を「貸与」されて作るだけ | OEM | **弱い**。作り方の差でしか勝負できず、相見積で叩かれる | プレス部品、切削加工品、樹脂成形品 |
| **承認図**（しょうにんず） | **部品メーカーが設計し、OEMが承認する** | 部品メーカー（不具合責任も負う） | **強い**。設計ノウハウが他社に真似できない | ブレーキ、ステアリング、ハーネス、シート、電装ユニット |
| **市販品（カタログ品）** | 部品メーカーが独自に商品化 | 部品メーカー | 最も強い。標準品として複数OEMに売れる | ベアリング、コネクタ、半導体、電子部品 |

> 日本のTier1が高い利益率を維持してきた最大の理由は、**承認図比率が高い**こと。
> 逆に、貸与図しか持たないTier2・Tier3は「言われた通りに作る加工賃商売」になり、
> 値下げ要請をそのまま飲むしかない。**承認図を持てるかどうかが、部品メーカーの生死を分ける**。

承認図を持つには、(1) 自社で設計・解析ができる技術者、(2) 不具合を自社負担で直す体力、
(3) 品質保証と実績（＝過去に事故を起こしていないこと）の3つが要る。だから新規参入が難しい。

## 3. 見積の中身：価格はどう積み上がるか

日本の自動車産業では、価格は「相場」ではなく **原価の積み上げ** で決まる。
OEMは部品メーカーに原価の内訳を開示させ、それを見て交渉する（原価企画）。

```
  部品1個の見積価格
  ┌─────────────────────────────────────────┐
  │ ① 材料費   鋼材・樹脂・銅・アルミ・電子部品   │ ← 市況で動く。転嫁交渉の対象
  ├─────────────────────────────────────────┤
  │ ② 加工費   ＝ チャージレート × 加工時間      │ ← 設備の償却＋人件費＋電気代を
  │            （1分いくら、で計算する）          │    1分あたりに割り戻した数字
  ├─────────────────────────────────────────┤
  │ ③ 金型・設備の償却  型費を予定台数で割る     │ ← 台数が減ると1個あたりが増える
  ├─────────────────────────────────────────┤
  │ ④ 物流費・梱包費                             │
  ├─────────────────────────────────────────┤
  │ ⑤ 販管費・開発費の配賦                       │
  ├─────────────────────────────────────────┤
  │ ⑥ 利益（数%）                                │ ← ここだけが自社のもの。最初に削られる
  └─────────────────────────────────────────┘
```

**チャージレート（加工賃率）** は「この設備を1分動かすといくらかかるか」を表す数字で、
設備投資額・稼働率・人員配置から計算する。稼働率の前提が崩れると
（＝台数が計画の7割しか出ないと）、見積時の採算は一発で壊れる。

## 4. 年次値下げ（コストダウン要請）という慣行

| 呼び方 | 意味 |
| --- | --- |
| **CR（コストリダクション）** | 継続取引の部品について、毎年一定率の値下げを求める慣行 |
| **原価低減要請** | 完成車メーカーが半期ごとに取引先へ出す、値下げの依頼 |
| **VA／VE提案** | 部品メーカー側から「設計や工法を変えて安くする」提案。浮いた分を分け合う |

- 値下げ率は品目と時期によるが、**年1〜3%程度**が慣習的な目安とされる（公表値ではない）
- 理屈は「量産が進めば習熟して原価が下がるはずだから、その分を分け合う」というもの
- 実際に工程改善が進めば部品メーカーの利益は減らない。**改善が値下げ率に追いつかなくなった瞬間に赤字化**する
- 2022〜2024年の資材・エネルギー・労務費高騰局面では要請を一時停止する動きが広がった。
  トヨタは約4年ぶりに原価低減要請を再開し、2026年度下半期も継続する一方、
  労務費・物流費の上昇分は引き続き価格に反映する方針と報じられる（2026年2月報道）

```
  部品1個の価格の推移（イメージ）
  価格 ▲
      │ ＼ 契約価格（毎年CRで下がる）
      │   ＼＿＿
      │      ＼＿＿
      │         ＼＿＿
      │  ╲            原価（工程改善で下げる）
      │    ╲＿＿
      │       ╲＿＿＿＿
      │            ╲＿＿＿
      └──────────────────────────▶ 年
        SOP   +1   +2   +3   +4   +5
      ↑赤字     ↑ 原価改善が価格低下を上回ると黒字化
```

### 2026年1月から法律が変わった

改正下請法が **「中小受託取引適正化法（取適法）」** として **2026年1月1日に施行**。
主な変更は次のとおり。

| 変更点 | 中身 |
| --- | --- |
| 協議義務 | 受託側からコスト上昇に伴う価格転嫁の要請があったとき、委託側は**協議に応じることが義務**。一方的な据え置きや形式的な回答は禁止 |
| 一方的な代金決定の禁止 | 協議なしに従来価格を押し付ける行為を明確に違法化 |
| 適用範囲の見直し | 資本金基準に加えて**従業員数基準**を導入。手形払いの規制も強化 |

自動車産業では日本自動車工業会（JAMA）とJAPIAが自主行動計画を改定して対応を進めている。
**これは「毎年値下げ」の慣行そのものを禁じるものではない**点に注意。
禁じられたのは「協議せずに押し付けること」であり、合理的な改善に基づく値下げ交渉は残る。

## 5. 金型（かながた）と設備の負担

金型は、プレス・鋳造・樹脂成形で形を作るための「型」。1セットで数百万円〜数億円する。
**誰が金型代を払い、誰が所有するのか**は、部品取引で最ももめる論点のひとつ。

| 方式 | 支払い | 所有権 | 部品メーカーへの影響 |
| --- | --- | --- | --- |
| **OEM支給（無償貸与）** | OEMが型代を払い、部品メーカーに貸す | OEM | 資金負担はないが、**取引を切られたら型を引き上げられる** |
| **型費を別途請求** | 量産前に型代をまとめて受け取る | 多くはOEM | 一番健全。ただし価格交渉で値切られやすい |
| **部品価格に織り込む（償却）** | 型代を予定台数で割り、部品単価に上乗せして回収 | 部品メーカー | **台数が計画未達だと回収できない**。最大のリスク |
| **部品メーカー全額負担** | 自腹 | 部品メーカー | 承認図・市販品ではこれが普通。その代わり他社にも売れる |

> 中小のTier2・Tier3で頻発するトラブルが、この**型代の未回収**と**型の保管費**。
> 量産終了後も補修用に型を10年以上保管させられるが、保管費は払われないことが多い。
> 取適法でも「型の無償保管」は問題行為として整理されている。

## 6. 日々の取引：内示・確定・かんばん

契約があっても、毎月いくつ買うかは確定していない。実務は次の三段構えで回る。

```
  3ヶ月前   ▶ 内示（フォーキャスト）   「だいたい月1万個」  ← 拘束力なし
  1ヶ月前   ▶ 確定内示                 「来月は9,200個」    ← 材料手配の根拠
  当日〜前日 ▶ かんばん／納入指示       「14時に240個」      ← これが発注
```

- 部品メーカーは**内示を信じて材料と人を用意する**。内示が外れると在庫と遊休人員が残る
- 逆に納入が1個でも遅れると完成車の組立ラインが止まる。
  ライン停止は1分あたり数百万円規模のコストになり、**損害賠償や取引停止に直結**する
- だから部品メーカーは、契約上は在庫を持たない建前でも、実際には**自腹で安全在庫を積む**。
  「かんばん方式で在庫ゼロ」は完成車側の話で、**在庫は下に押し付けられている**のが実態

### 有償支給と無償支給

| 方式 | 中身 | 部品メーカーの帳簿への影響 |
| --- | --- | --- |
| **有償支給** | OEM／Tier1が材料をまとめ買いし、部品メーカーに**売る**。加工後に買い戻す | 材料費が仕入に、材料代込みの金額が売上に立つ。**売上が膨らむが利益は増えない** |
| **無償支給** | 材料を無償で預け、加工賃だけ払う | 売上は加工賃のみ。利益率は高く見えるが金額は小さい |

同業他社と「売上高」を比べるとき、有償支給か無償支給かで見え方が変わる。
**部品メーカーの比較は売上高ではなく付加価値（売上−材料費）で見る**のが実務的。

## 7. 品質保証：取引の前提条件

| 仕組み | 中身 |
| --- | --- |
| **IATF 16949** | 自動車産業の品質マネジメント規格。取得していないとTier1になれない事実上の入場券 |
| **PPAP／量産移行承認** | 量産前に「この工程でこの品質が出る」ことを書類と現物で証明する手続き |
| **工程変更の事前承認** | 材料・設備・工場を変えるにはOEMの承認が要る。**勝手に安い材料に変えられない** |
| **トレーサビリティ** | どのロットの材料がどの車に付いたかを追えるようにする。リコール時の切り分けに必須 |
| **PL責任・求償** | 部品が原因のリコールでは、費用がOEMから部品メーカーへ求償される（→ [収益とリスク](03_収益とリスク.md)） |

「工程変更に承認が要る」ことは、**コストダウンの自由度を縛る**と同時に、
**新規参入者を締め出す壁**にもなっている。安い新興メーカーがいても、
承認を取り直すコストとリスクを考えると切り替えが起きにくい。これが取引の粘着性の正体。

## 用語メモ

- **SOP**：Start of Production。量産開始。**EOP** は生産終了
- **RFQ**：Request for Quotation。見積依頼。ここで競合と価格を競う
- **承認図／貸与図**：部品メーカーが設計しOEMが承認する／OEMが描いた図面を渡される
- **CR**：Cost Reduction。年次の値下げ要請
- **VA／VE**：Value Analysis／Value Engineering。設計・工法の見直しで原価を下げる活動
- **チャージレート**：設備を1分（または1時間）動かすのにかかる費用。加工費の単価
- **原価企画**：目標原価を先に決め、そこから逆算して設計する手法
- **内示**：拘束力のない生産計画の事前通知。部品メーカーはこれを頼りに材料を手配する
- **かんばん**：必要な部品を必要な分だけ引き取るための指示票。実質的な発注書
- **有償支給／無償支給**：材料を売って渡す／預けて加工賃だけ払う
- **IATF 16949**：自動車産業向けの品質マネジメントシステム規格
- **取適法**：中小受託取引適正化法。改正下請法の新名称。2026年1月1日施行
- **求償**：リコール費用などを、原因を作った部品メーカーに請求すること
