# 自動車部品｜部品の全体像

**このノートで分かること**：クルマ1台をバラすと何が出てくるのか、それを誰が作っているのか。
そして「自動車部品業界」と一口に言うとき、実は**経済的性格がまったく違う5つの商売が同居している**こと。

結論を先に書くと、自動車部品は **「重くてかさばるもの」「精密で危ないもの」「電気のもの」「見た目のもの」** で
儲け方がまるで違う。同じTier1でも、シート屋と半導体屋では原価率も利益率も工場の形も別物になる。
この違いを押さえないと、「部品メーカーの決算」は一生読めない。

## 1. まず桁感：1台3万点とはどういう意味か

| 項目 | 数値 | 出典・注記 |
| --- | --- | --- |
| 乗用車1台の部品点数 | 約3万点（エンジン車） | 業界で広く使われる概数。ネジ1本を1点と数えるか、締結部品一式を1点と数えるかで倍半分変わる |
| うちエンジン単体 | 1万点前後 | 同上。EVでは数百〜千点規模に減る |
| 国内の自動車部品出荷額 | **20兆7,070億円**（2024年度、有効回答293社） | 日本自動車部品工業会（JAPIA）「自動車部品出荷動向調査」2026年3月公表 |
| 世界のメガサプライヤー最大手の売上 | 約7.5兆円（デンソー、2026年3月期） | デンソー決算。売上収益7兆5,399億円 |

> 注意：「3万点」は**正確な統計値ではない**。桁感（数千ではなく数万）を掴むための数字として扱う。
> 重要なのは点数そのものではなく、**3万点を1台に狂いなく集めて同時に組み付ける**という
> ロジスティクスの難易度のほうにある（→ [取引の構造](02_取引の構造.md)）。

### 点数と金額は比例しない

```
  部品「点数」の分布              部品「金額」の分布
  ┌──────────────┐              ┌──────────────┐
  │ 締結・小物  40%│ ← 安い      │ パワートレイン  25〜30%│ ← 高い
  │ エンジン系  30%│              │ 車体・シャシー  20〜25%│
  │ 車体・内装  20%│              │ 内外装・シート  15%前後│
  │ 電装・電子  10%│              │ 電装・電子     15〜20%│ ← EVで急拡大
  └──────────────┘              └──────────────┘
```

上の金額配分は各社IR・業界解説から起こした**概算**で、車格（軽自動車か高級車か）と
パワートレイン（エンジン車かEVか）で大きく動く。「ネジは点数の主役だが金額の主役ではない」
という当たり前のことが、後述する**利益の出どころ**を決めている。

## 2. 5系統の分類：経済的性格がまるで違う

自動車部品は慣習的に次の5つに分けられる。**同じ業界と呼ぶのが乱暴なくらい商売が違う**。

| 系統 | 代表的な部品 | 物理的特徴 | 経済的性格 | 利益の出どころ |
| --- | --- | --- | --- | --- |
| **エンジン系（パワートレイン）** | シリンダーブロック、ピストン、バルブ、燃料噴射、ターボ、排気・触媒、変速機 | 重い・高温・高精度 | 鋳造/鍛造＋機械加工の装置産業。設備が専用化しやすい | 加工賃と量産効果。ただし**EVで需要そのものが消える** |
| **駆動・足回り（シャシー）** | ドライブシャフト、デフ、等速ジョイント、サスペンション、ステアリング、ブレーキ、ベアリング | 重い・安全に直結 | 保安部品。認証と実績が重い参入障壁 | 安全部品プレミアム＋補修需要。EVでも残る |
| **車体・内外装** | プレス部品、シート、内装トリム、バンパー、ガラス、ランプ | かさばる・運べない | **輸送費が効くので工場は組立工場の近くに置く**（地域密着） | 立地の優位。金額は大きいが利益率は低い |
| **電装・電子** | ワイヤーハーネス、ECU、センサー、モーター、インバーター、カーナビ、コネクタ | 軽い・付加価値が高い | 電機・電子産業の論理。ソフトが効く | 技術プレミアム。**ここに投資と利益が移りつつある** |
| **アフターマーケット（補修）** | オイルフィルター、ブレーキパッド、バッテリー、ワイパー、タイヤ | 消耗品 | 量産品より**単価が高く粗利が厚い** | 保有台数×交換頻度。景気に鈍感な安定収益 |

> ポイント：新車向け（OEM供給）は「大量・薄利・値下げあり」、補修向け（アフター）は「少量・厚利・値下げなし」。
> **多くの部品メーカーの営業利益は、実は補修部品が不釣り合いに大きく稼いでいる**。
> 新車部門が赤字でも補修で食っている、という会社は珍しくない（→ [収益とリスク](03_収益とリスク.md)）。

これは技術だけでなく、後述する**承認図／設計の作り込み**の構造から生まれる

## 4. 系列（ケイレツ）別の主要サプライヤー

日本の部品産業は完成車メーカーを軸にした**資本・人的関係のかたまり**でできている。
「系列」とは、出資・役員派遣・共同開発・長期取引がセットになった関係を指す。

| 系列 | 主なサプライヤー（得意領域） |
| --- | --- |
| **トヨタ系** | デンソー（電装・熱・電動）、アイシン（変速機・ブレーキ・車体）、豊田自動織機（エンジン・コンプレッサー・産業車両）、豊田合成（ゴム・樹脂・エアバッグ）、トヨタ紡織（シート・内装）、ジェイテクト（ステアリング・ベアリング）、愛知製鋼（特殊鋼）、東海理化（スイッチ）、フタバ産業（排気系）、アドヴィックス（ブレーキ） |
| **ホンダ系** | 日立Astemo（旧ケーヒン・ショーワ・日信工業＋日立オートモティブ）、TSテック（シート）、武蔵精密工業（ギア）、エフテック（シャシー）、ユタカ技研 |
| **日産系** | マレリ（旧カルソニックカンセイ＋マニエッティ・マレリ／コックピット・空調。2026年に再度チャプター11申請と報じられる）、ユニプレス（プレス）、河西工業（内装） |
| **独立系（国内）** | 住友電工（ハーネス・電線）、矢崎総業（ハーネス、非上場）、NOK（シール）、日本特殊陶業（点火プラグ・センサー）、ニデック（モーター・eAxle → [モーター](../15_モーター/README.md)）、ミツバ、TPR／リケン（ピストンリング）、NSK／NTN（ベアリング → [ベアリング](../10_ベアリング/README.md)） |
| **電機・電子からの参入** | パナソニック オートモーティブ、村田製作所、ローム、富士電機、三菱電機（2026年2月に車載事業の再編検討が報じられる） |
| **海外メガサプライヤー** | Bosch（独）、ZF（独）、Continental（独）、Magna（加）、Forvia（仏）、Valeo（仏）、Hyundai Mobis（韓）、Aptiv、BorgWarner、Lear、Adient（米）、CATL／BYDグループ（中） |

### 系列は何のためにあったのか

- **開発の同時進行**：完成車の企画段階から部品メーカーが入り、一緒に仕様を詰める（デザインイン）。
  これをやると開発期間が短くなり、部品側も自社の作りやすい構造を提案できる
- **かんばん方式の前提**：在庫を持たない生産には、近くに・確実に・毎日納める相手が要る
- **相互の人質**：部品側は専用設備に投資し、完成車側は他に代えがきかない。
  裏を返せば**どちらも逃げられない**。これが年次値下げを受け入れる土壌にもなった

### そして今、系列がほどけている

| 動き | 内容 | 時期 |
| --- | --- | --- |
| 親子上場の解消 | トヨタ等による豊田自動織機のTOBが成立、上場廃止へ。買収総額 **約5.9兆円**（日本企業同士のM&Aで過去最大） | 2026年3月 |
| 事業の切り出し | デンソーが内燃機関関連事業の売却を進め、規模は総額1兆円超と報じられる | 2024年〜 |
| 破綻と再編 | マレリがチャプター11を申請、日産とステランティスが資産取得を協議と報じられる | 2026年6月 |
| 欧州勢のリストラ | Boschが最大5,500人、ZFがドイツで2028年末までに最大14,000人の削減を公表 | 2024〜2025年 |

詳しくは [電動化・SDVで何が変わるか](04_電動化・SDVで何が変わるか.md) と
[直近トピック_2026](05_直近トピック_2026.md) を参照。

## 5. Tier（ティア）の実像

| 階層 | 納入先 | 納めるもの | 典型的な企業像 |
| --- | --- | --- | --- |
| **Tier1** | 完成車メーカー（OEM） | **ユニット・モジュール**（機能のかたまり。例：ブレーキ一式、シート一式） | 売上1,000億〜7兆円。設計能力と品質保証体制を持つ |
| **Tier2** | Tier1 | 単品部品（モーター、センサー、ギア、樹脂成形品） | 売上100億〜3,000億円。専業メーカーが多い |
| **Tier3** | Tier2 | 加工・素材（プレス、切削、メッキ、熱処理、鋳造） | 売上数億〜100億円。地場の中小企業。ここが日本の裾野 |

ただし実務では階層はきれいに割り切れない。**同じ会社がある車種ではTier1、別の車種ではTier2**ということが日常的に起きる。
また電池・半導体のように、Tier1を飛び越してOEMが直接買う品目も増えている。

```
     【教科書の図】                 【現実】
        OEM                           OEM ◀── 電池・半導体・ソフトは直取引
         │                             │  ╲
      Tier1（ユニット）              Tier1  ╲ ← 同じ会社が別ラインでTier2
         │                             │      ╲
      Tier2（単品）                  Tier2 ────╳ 相互に売り買いする
         │                             │
      Tier3（加工・素材）            Tier3（ここだけは下請けのまま）
```

## 6. 隣接業界との境界

| 隣 | 境界の引き方 |
| --- | --- |
| [自動車（完成車）](../01_自動車（完成車）/README.md) | 車両として型式認証を取り、自社ブランドで売るかどうか。部品メーカーは車を売らない |
| [タイヤ](../03_タイヤ/README.md) | 素材（ゴム）から作る装置産業で、補修比率が極端に高いため別業界扱い |
| [ベアリング](../10_ベアリング/README.md)／[モーター](../15_モーター/README.md) | 自動車以外（産業機械・家電）にも同じ製品を売るため、独立した業界として扱う |
| [電子部品](../../03_電機・電子部品/05_電子部品/README.md)・[半導体](../../03_電機・電子部品/02_半導体（ロジック・メモリ）/README.md) | 車載向けは品質基準（AEC-Q、長期供給義務）が別格。同じチップでも車載グレードは別物 |
| 整備・用品小売 | 部品を「作る」のではなく「取り付ける・売る」側。アフターマーケットの川下 |

## 用語メモ

- **Tier1／Tier2／Tier3**：完成車メーカーに直接納める一次取引先／その下／さらにその下
- **OEM**：自動車業界では「完成車メーカー」を指す（他業界の受託生産の意味とは逆なので注意）
- **系列（ケイレツ）**：出資・役員・共同開発・長期取引が束になった企業グループ関係
- **メガサプライヤー**：売上2〜3兆円超で複数領域をまたぐ巨大Tier1。Bosch、デンソー、ZF、Continental など
- **デザインイン**：完成車の企画・設計段階から部品メーカーが参加して仕様を一緒に作ること
- **モジュール化**：複数部品をまとめて1つのユニットとして納入すること。Tier1の付加価値の源泉
- **保安部品**：ブレーキ、ステアリング、エアバッグなど、壊れると人命に直結する部品。法規と認証が厳しい
- **アフターマーケット**：新車向けではなく、市場に出た車の補修・交換向けの市場
- **AEC-Q**：車載電子部品の信頼性試験規格。温度範囲や寿命の要求が民生品よりはるかに厳しい
- **JAPIA**：一般社団法人 日本自動車部品工業会。出荷動向調査などの統計を出している
