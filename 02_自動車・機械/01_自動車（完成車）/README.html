1. 業界の定義・範囲

完成車（OEM） ＝ 自動車を設計し、組み立て、自社ブランドで販売する事業者。
自動車産業という言葉はもっと広く、次の4層をまとめて指すことが多い。

【自動車産業の広がり】
 ┌──────────────────────────────────────────────┐
 │ 製造：完成車(このノート)／部品／素材／金型・工作機械            │
 │ 販売：ディーラー、中古車、輸出                              │
 │ 使用：ガソリンスタンド、整備・車検、板金、保険、駐車場、道路      │
 │ 輸送：物流、キャリアカー、船舶（自動車専用船）                 │
 └──────────────────────────────────────────────┘
      ▲ この裾野の広さが「製造業の王様」と言われる理由（→ 第2章）

境界の引き方：

  • 商用車（トラック・バス） は顧客も購買理由も違うので 商用車・トラック に分ける
  • 二輪車 も別（二輪車）
  • 部品メーカー は 自動車部品。完成車メーカーはここに発注する側
  • EVという技術・政策の話は EV・電動化 に集約

「王様」と呼ばれる理由を分解すると3つ。

  1. 裾野の広さ：1台3万点の部品が数万社に発注される。1社の生産計画が全国の中小企業の売上を動かす
  2. 雇用の厚み：直接・間接あわせて約559万人。地域経済（愛知、群馬、静岡、九州など）の基盤そのもの
  3. 外貨の稼ぎ手：輸出額の2割前後を占める。円安・関税・海運が国の貿易収支に直結する

だから 米国の関税15%は「自動車業界のニュース」ではなく「日本経済のニュース」 になる。

5. 収益モデル・コスト構造

利益 ＝ 台数 × 1台あたり単価と中身（車格ミックス） × 地域の稼ぎやすさ
       ＋ 販売金融の利ざや － 固定費（開発費・設備償却・人件費）
論点 中身
原価の内訳購入部品・材料が約7割。労務費・償却費・経費が各1割前後（目安）
固定費の重さ完成車工場1ラインで1,000億円〜数千億円。稼働率が落ちると即赤字（オペレーティングレバレッジ）
損益分岐通説として年20万台規模・稼働率7〜8割が目安。公表基準はない
1台あたり利益軽で数万〜十数万円、量販車で10〜20万円、北米の大型ピックアップで50〜150万円（推計レンジ）
営業利益率7〜10%で好調、5%割れで構造改革。2026年3月期のトヨタは7.4%（前期10.0%）
為替感応度日本メーカーは1円の円安で営業利益が数百億円動く水準を開示
販売金融ローン・リース・残価設定の利ざや。欧米勢では営業利益の2〜4割を占めることもあると言われる
アフター車検・整備・部品。日本の総整備売上高は約5兆9,072億円（令和5年度、日整連）

詳細は ③ 儲け方の構造 と ④ 販売とアフターマーケット。

6. 競争要因（KSF）と参入障壁

KSF（成功の鍵）

  1. 稼働率の維持：需要変動に対して混流生産と車種構成で工場を満杯に保てるか
  2. 原価力：プラットフォーム共通化、購買集約、設計段階での原価作り込み（原価企画）
  3. 車格ミックス：利益の厚い帯（SUV・ピックアップ・上位グレード）で売れているか
  4. 電池とパワー半導体の調達力：長期契約・合弁で量と価格を押さえられるか
  5. ソフトウェア開発力：車両OS、OTA、ADAS。既存OEMの最大の弱点
  6. 販売網とアフター：保有台数＝将来の収益権。整備・金融・保険で稼ぐ土台
  7. 地政学対応：関税・規制・原材料に応じて、どこで作るかを組み替えられるか

参入障壁

障壁 強さ 理由
組立技術弱受託生産も可能。ここだけなら参入できる
量産品質・型式認証・リコール責任強新興EVメーカーの多くがここで脱落した
電池調達強量を押さえられないと価格で負ける
資本の厚み強黒字化まで数千億〜兆円を燃やす
販売・整備網中〜強直販でも整備拠点は要る
ソフトウェア中新興のほうが有利。既存勢の弱点

7. 規制・法制度

分野 主な制度
安全・認証道路運送車両法の型式指定（量産車が基準に適合していることを国が認める制度）、保安基準、国連協定規則（WP.29）による国際調和
検査・維持車検（継続検査）：自家用乗用車は新車3年、以降2年ごと。2020年に「特定整備」制度が始まりADASの電子制御装置整備に認証が必要に
燃費・環境CAFE（企業別平均燃費基準）、排出ガス規制、欧州のCO2規制、米国のCAFE/ZEV規制、中国のNEVクレジット
電動化目標日本：2035年までに乗用車新車販売で電動車100%（HEVを含む）。CEV補助金
税制自動車税・軽自動車税（種別割・環境性能割）、自動車重量税、エコカー減税。2026年は環境性能割の廃止が販売押し上げ要因として期待される
通商米国の通商拡大法232条による自動車・部品関税（日本は15%）、EUの中国製BEVへの相殺関税、原産地規則（USMCA）
リサイクル自動車リサイクル法（シュレッダーダスト・エアバッグ・フロンの適正処理をユーザー負担で）
取引適正化下請法／独占禁止法。労務費・原材料費の価格転嫁を促す指針（公取委・中企庁）

8. 最近のトピック

詳細と出典は ⑥ 直近トピック（2026年9月時点）。要点だけ挙げると:

  • 米国の自動車関税は15%のまま継続。2026年2月に最高裁が相互関税（IEEPA）を無効としたが、
    自動車に効いている232条関税は判決の対象外
  • 2026年3月期はトヨタが営業収益50兆円で日本企業初、しかし営業利益は21.5%減の3兆7,662億円。
    関税影響は約1.4兆円。7社中4社が減益、ホンダと日産は赤字、スズキは過去最高
  • 2026年は中東情勢によるアルミ・石化原料の調達混乱が新たな逆風。
    トヨタは2027年3月期に6,700億円、ホンダは3,130億円の減益要因を織り込む
  • 国籍別では中国メーカーが日本を抜いて世界首位に（2025年）。中国からの輸出は709.8万台（+21.1%）。
    一方で中国国内は利益率3%台の消耗戦
  • 日産はRe:Nissanで7工場閉鎖・2万人削減を進行中。2026年度に6拠点の統廃合を予定
  • 競争軸はSDV（ソフトウェア定義車両）へ。トヨタは2026年以降に独自の車両OS、
    日産はAI定義車両（AIDV）を掲げる
