# 直近トピック（2026年9月時点）

報道・公表資料ベースの整理。数値は必ず一次情報（各社IR、JETRO、官庁統計）で裏を取ること。
確定した制度は「発効」「決定」、まだ動くものは「報じられる」「見通し」と書き分けている。

## 1. 米国の関税：15%は続き、相互関税だけが崩れた

いま日本の自動車産業にとって最大の外部要因。経緯を分けて理解する必要がある。

```
【2025年】
 4/3   米が通商拡大法232条で自動車・部品に 25% の追加関税を発動
 7月   日米合意：232条と相互関税を合わせて 15% とすることで決着
 9/4   合意履行の大統領令。9/16 から日本車は 15% 適用（JETRO）

【2026年】
 2/20  米連邦最高裁が「IEEPA（国際緊急経済権限法）に基づく相互関税は違法・無効」と判断
 2/24  相互関税の徴収を停止。代替手段（通商法122条など）へ切り替えと報じられる
       ★ ただし 232条の自動車・部品関税(15%)は判決の対象外で、そのまま継続 ★
```

| 論点 | 現状（2026年9月時点） |
| --- | --- |
| 自動車の232条関税 | **継続**。日本車は15%。判決の影響を受けない |
| 相互関税（IEEPA） | 最高裁が無効と判断。徴収停止、還付手続きが論点に |
| 業績影響 | 2026年3月期に**トヨタで約1兆3,800億〜1兆4,500億円の減益要因**と各社が開示 |
| 各社の対応 | 米国現地生産の拡大、価格転嫁、仕向地の組み替え |

> 押さえどころ：**「トランプ関税が違法になった＝自動車が楽になった」ではない**。
> 自動車に効いているのは232条であり、そこは判決の外にある。
> 報道を読むときは **IEEPA（相互関税）か232条（品目別関税）か**を必ず区別すること。

## 2. 中東情勢によるサプライチェーン混乱（2026年の新しい衝撃）

2026年に入って表面化した、関税とは別系統のリスク。

| 影響経路 | 内容（報道ベース） |
| --- | --- |
| **素材** | アルミの調達不安、ナフサ（樹脂・塗料の原料）のサプライチェーン断絶が指摘される |
| **物流** | ホルムズ海峡の通航リスク。中東向け輸出と原料輸入の両方が滞る |
| **生産** | 2026年2月に日系4社（トヨタ、ホンダ、日産、SUBARU）の世界生産が減少。中東向け車両の生産・輸出停止の動きも |
| **減産規模** | トヨタが中東向けに4万台規模の生産削減、日産が九州工場で1,200台規模の減産と報じられる |
| **業績** | 2027年3月期の減益要因として**トヨタ6,700億円、ホンダ3,130億円**を各社が織り込み |

> 構図としては [02_サプライチェーンと系列](02_サプライチェーンと系列.md) で整理した
> 「上流にさかのぼるほど代替が効かない」という弱点が、今度は **素材の段階**で出た形。
> 半導体不足はTier2〜3の問題だったが、今回はアルミ・石化原料という **もっと上流**。

## 3. 2026年3月期決算：売上は最高、利益は減

| 会社 | 2026年3月期の結果 | 2027年3月期の見通し |
| --- | --- | --- |
| **トヨタ** | 営業収益 **約50兆円**（日本企業初）、営業利益 **3兆7,662億円**（前期比21.5%減）、利益率 10.0%→**7.4%** | 営業利益 **3兆円**（20.3%減）、**3期連続の減益**見通し |
| ホンダ | 最終赤字 | 中東影響3,130億円を織り込み |
| 日産 | 最終赤字。再建計画を実行中 | 構造改革の途上 |
| マツダ・SUBARU・三菱自 | 減益 | 関税と資材高の影響が継続 |
| スズキ | **過去最高の増収増益** | インドの強さが効いている |

- トヨタは2026年3月期に **電動車（HEV含む）の販売が初めて500万台を超えた**と発表
- 「売上は過去最高なのに3期連続減益」という形は、**外部要因（関税・中東・資材高）で利益だけが削られている**ことを示す
- 内部要因（台数・原価改善）だけを見れば各社は健闘しているが、
  [③ 儲け方の構造](03_儲け方の構造.md) で見たとおり **固定費が重いので外部ショックが利益率に直撃する**

## 4. 中国勢が「国籍別」で世界首位に

```
2025年の世界新車販売 約9,900万台（前年比 +4.7%、過去最多）

  メーカー別          │  国籍別
  ① トヨタG 約1,128万台 │  ① 中国勢（BYD・奇瑞・吉利・上汽・長安…）合計で首位
  ② VW      約900万台級 │  ② 日本勢（20年以上首位だったが2位へ）
  ③ 現代G    約700万台超 │  ③ 欧州勢
                        │  ④ 米国勢
  ※「誰が1位か」は集計の単位で変わる。ここを混同した記事が多い
```

| 指標 | 数値（2025年） | 出典 |
| --- | --- | --- |
| 中国の自動車輸出 | **709万8,000台**（前年比21.1%増、初の700万台超） | JETRO（中国汽車工業協会ベース） |
| 輸出上位 | 奇瑞134.4万台、BYD105.4万台（前年比2.4倍）、上汽95万台 | 同上 |
| 2026年の輸出見通し | 740万台（4.3%増）と減速予想 | CAAM予測 |
| 中国国内市場 | 2026年1〜4月が前年同期比4.8%減。5年ぶりの前年割れ | 報道ベース |
| 中国の自動車製造業の利益率 | 2026年1〜3月期で **3.4%**（産業平均5.4%を下回る） | 報道ベース |

> 読み方：**中国メーカーは「国内で儲からないから輸出する」局面に入っている**。
> 輸出の伸び（+21%）と国内の失速（-4.8%）が同時に起きているのがその証拠。
> この圧力が欧州の相殺関税や新興国での摩擦を生む（→ [05_競争環境](05_競争環境と世界の勢力図.md)）。

## 5. 日産の再建と、ホンダとの距離

| 時点 | 出来事 |
| --- | --- |
| 2024年3月 | ホンダ・日産がEV・知能化での協業検討を開始 |
| 2024年12月 | 経営統合に向けた基本合意書を締結 |
| 2025年2月 | 統合交渉は破談と報じられる。ただし技術提携の枠組みは継続 |
| 2025年5月 | 日産が再建計画 **「Re:Nissan」** を公表。**7つの車両生産拠点の閉鎖、約2万人の人員削減** |
| 2025年 | 追浜工場・湘南工場（日産車体）の閉鎖／再編を決定 |
| 2026年5月 | 2026年度に **7拠点のうち6拠点の統廃合**を予定と説明（報道ベース） |

- 日産の問題は商品力だけでなく **生産能力の過剰**。中国では能力150万台に対し生産約78万台で、
  約72万台分の余剰があるとの指摘がある（報道ベース）
- [01_クルマはどう作られるか](01_クルマはどう作られるか.md) の損益分岐の算数に当てはめると、
  稼働率5割の工場を抱えたままでは黒字化しない。**閉じるしかない**という判断になる

## 6. SDV／AI定義車両へ：ソフトが競争軸に

| 動き | 内容 |
| --- | --- |
| 市場規模 | SDV市場は2025年 649億ドル → 2026年 765億ドル（年率17.8%成長）との調査会社推計 |

## 7. 国内市場：2025年は回復、2026年は税制が追い風

| 指標 | 数値 | 出典 |

| 2025年の国内新車販売 | **456万5,777台**（前年比3.3%増、2年ぶりプラス） | 自販連＋全軽自協 |
| 内訳 | 登録車0.6%増、軽自動車3.8%増 | 同上 |

## 8. 全体の構図（2026年9月時点のまとめ）

1. **外部ショックが利益だけを削る局面**。売上は過去最高でも、関税（232条15%）と中東由来の資材・物流混乱で
   国内主要7社の多くが減益・赤字。トヨタは3期連続の営業減益見通し
2. **関税は「相互関税が無効化されても自動車は15%のまま」**。判決の射程を混同しないこと
3. **中国勢が国籍別で世界首位**。ただし中国国内は利益率3%台の消耗戦で、輸出への圧力が増している
4. **日本勢はHEVの強さで台数と利益を支えている**が、SDV・ソフトでの遅れが次の勝負どころ
5. **国内は縮小均衡**。新車456万台に対し中古648万台、整備は約5.9兆円。
   産業の重心は「作って売る」から「保有に寄り添う」方向へ動き続けている

## 用語メモ

- **232条関税**：米通商拡大法232条に基づく、安全保障を理由とした品目別の追加関税。自動車・鉄鋼が対象
- **IEEPA（相互関税）**：国際緊急経済権限法を根拠にした一律の関税。2026年2月に最高裁が無効と判断
- **MFN税率**：最恵国税率。通常の関税率のこと
- **Re:Nissan**：日産が2025年5月に公表した再建計画。7工場閉鎖・約2万人削減を含む
- **AIDV（AI定義車両）**：SDVの次の段階として、AIを車両体験の中核に置く考え方
- **環境性能割**：燃費性能に応じて課される自動車取得時の税。廃止が販売押し上げ要因として期待されている
- **ホルムズ海峡**：中東の原油・石化原料の主要航路。封鎖リスクが素材調達に直結する
