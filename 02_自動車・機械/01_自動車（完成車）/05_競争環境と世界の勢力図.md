# 自動車（完成車）｜競争環境と世界の勢力図

**このノートで分かること**：世界で誰が何台売っているのか。
なぜ中国勢がこれほど急に伸びたのか。アライアンス（提携）は何のために結ばれるのか。
そして、EV／HEV／PHEVをめぐる各社の戦略の違いはどこから来るのか。

結論を先に書くと、いま起きているのは **「規模の競争」から「速さとコストの競争」への転換**である。
従来の勝ち筋は年1,000万台の規模で開発費を薄めることだった。
中国勢は **開発期間を半分にし、電池と半導体を垂直統合で内製する**ことで、別の勝ち筋を作った。

| --- | --- | --- |
| 世界の新車販売 | **約9,900万台**（前年比約4.7%増、過去最多） | 2025年、報道・調査会社集計。集計範囲により9,500万台台の推計もある |
| うち中国市場 | 世界の増加分の約3分の2を中国が占めた | 2025年、報道ベース |

## 3. なぜ中国勢が急に強くなったのか

```
【従来型OEMの新車開発】            【中国新興勢の開発】
 企画 ─▶ 設計 ─▶ 試作 ─▶ 検証 ─▶ 量産    企画 ─▶ 設計・検証を並行 ─▶ 量産
 ────────── 48〜60ヶ月 ──────────      ──────── 18〜24ヶ月 ────────
   ・過去の品質基準を全部満たす           ・シミュレーション中心、部品は標準品を大量流用
   ・世界中の規制に一度に対応             ・まず中国市場向けに出し、売りながら直す（OTA）
```

中国勢の強さは、単なる補助金や人件費では説明できない。効いているのは次の5点。

| 要因 | 中身 |
| --- | --- |
| **開発速度** | 24ヶ月前後で新型車を出す。モデルチェンジの回転が倍速 |
| **垂直統合** | BYDは電池セル・パワー半導体・モーターまで内製。部品のマージンが社内に残る |
| **電池コスト** | LFP（リン酸鉄リチウム）を量産し、パック価格は2025年に **108ドル/kWh**（BNEF、過去最低） |
| **サプライチェーンの集積** | 深セン・長江デルタに部品が密集し、試作が数日で回る |
| **内装・ソフトの訴求** | 大画面・音声AI・スマホ連携。**「車の価値＝走り」から「車内の体験」へ**顧客評価軸を動かした |

### ただし中国市場自体は消耗戦（内巻）

- 中国の自動車製造企業の利益率は **2026年1〜3月期で3.4%**、産業全体（5.4%）を下回る（報道ベース）
- 国内販売は2026年に入り前年割れに転じたと報じられ、各社は輸出に活路を求めている
- 「作りすぎ（過剰生産能力）」が構造問題。稼働率が上がらない工場を抱えたまま値下げ競争が続く
- 結果として **「中国で勝てないから海外へ」**という圧力が、世界中の市場に安いEVを押し出している
  → 欧州の相殺関税、新興国での摩擦につながる（→ [EV・電動化④](../../01_注目テーマ/03_EV・電動化/04_各地域の政策と市場.md)）

## 4. アライアンス（提携）は何のために結ぶのか

自動車の提携は「仲良くするため」ではなく、**固定費を割り勘にするため**に結ぶ。

```
提携で割り勘にしたい固定費
 ┌───────────────────────────────────────┐
 │ ①プラットフォーム開発  数百億〜千億円／世代            │
 │ ②パワートレイン（HEV/BEV/電池）  兆円規模の投資        │
 │ ③車載ソフト・車両OS   人材の奪い合い。単独では人が足りない │
 │ ④自動運転・ADAS      検証データ量が効くのでスケール必須  │
 │ ⑤地域の生産拠点・販売網 相手の得意地域に相乗り          │
 └───────────────────────────────────────┘
```

| 類型 | 中身 | 例 |
| --- | --- | --- |
| **資本提携・経営統合** | 出資や統合で意思決定を一体化 | ルノー・日産・三菱自のアライアンス、ステランティス（統合）、トヨタとスバル・マツダ・スズキ等の資本関係 |
| **技術・領域別提携** | 特定分野だけ組む | ホンダ・日産の知能化／電動化の協業（2024年開始、経営統合は2025年2月に破談と報道） |
| **OEM供給（相互供給）** | 相手の車に自社バッジを付けて売る | 空白セグメントを開発費ゼロで埋められる |
| **合弁（JV）** | 現地法人を共同設立 | 中国では長く外資50%制限があり合弁が必須だった（乗用車の出資規制は2022年に撤廃） |
| **異業種連携** | ソフト・半導体・通信と組む | ソニー・ホンダのアフィーラ、各社と半導体メーカーの直接契約 |

> 提携が壊れる理由もはっきりしている。**(a) どちらが主導するかの綱引き、(b) 自国の雇用と工場をどう扱うか、
> (c) 統合効果が出るまでの時間に業績が耐えられない**、の3つ。
> ホンダ・日産の統合交渉（2024年12月基本合意 → 2025年2月破談と報道）はこの典型例として語られる。

## 5. EV／HEV／PHEVの戦略差はどこから来るのか

各社の選択は「技術の好み」ではなく、**主戦場の市場と、既存資産のどちらを守るか**で決まっている。

| 陣営 | 主力 | なぜそう選ぶのか | リスク |
| --- | --- | --- | --- |
| **トヨタ型（マルチパスウェイ）** | HEV中心＋BEV・PHEV・FCEVも並走 | HEVの利益率が高く、北米・新興国で今すぐ売れる。電池が足りない状況ではHEVのほうが **同じ電池量で多くの台数のCO2を減らせる** | BEVで出遅れれば、中国・欧州で棚を失う |
| **欧州OEM型** | BEV＋PHEV | **CO2規制を満たさないと罰金**。売る必要がある | BEVの利益が出ず、規制緩和で計画が宙に浮く |
| **中国勢型** | BEV＋PHEV（レンジエクステンダー含む） | 国内政策と電池サプライチェーンが味方。PHEVは航続不安を消して数量が伸びる | 国内の消耗戦。海外での関税・規制 |
| **米ビッグ3型** | 大型ICE／HEVで稼ぎ、BEVは縮小方向 | 利益源がピックアップ。税額控除終了で需要が細った | 規制が戻ると一気に苦しくなる |
| **テスラ型** | BEV専業＋ソフト・充電網 | 台数より単価・ソフト・エネルギー事業 | 車種が少なく、競合の追い上げに弱い |

- 日本メーカーのHEV強化は結果的に当たった面がある。トヨタは2026年3月期に
  **電動車（HEV含む）の販売が初めて500万台を超えた**と発表している
- ただし「HEVが強い」は **BEVで負けてよい理由にはならない**。中国・欧州ではBEVがないと売り場に並べない
- 詳細な地域別政策は [EV・電動化④ 各地域の政策と市場](../../01_注目テーマ/03_EV・電動化/04_各地域の政策と市場.md) に譲る

## 6. 競争軸が何に変わったか

```
【2010年代までの競争軸】          【2020年代以降の競争軸】
 ・エンジンの熱効率                ・電池の調達力と原価
 ・生産効率（TPS）                 ・ソフトウェア開発力（車両OS・OTA）
 ・品質・耐久性                    ・開発スピード（24ヶ月で出せるか）
 ・販売網の広さ                    ・顧客データと直接接点
 ・グローバル規模（1,000万台）      ・地域ごとの作り分け（地政学対応）
          ↓                              ↓
 「よいクルマを効率よく作る」        「よい体験を速く更新し続ける」
```

- **SDV（ソフトウェア定義車両）**：ハードを作り切って売るのではなく、
  出荷後にソフト更新で機能が増える車。トヨタは2030年度までにソフト関連R&Dに2兆円規模を計上すると報じられる
- ここが従来型OEMの最大の弱点。**ソフト人材は自動車業界の外にいる**ため、採用も文化も組み替えが要る
- 一方で **安全認証・量産品質・リコール対応** という従来型OEMの資産は依然として巨大な障壁。
  2010年代に多数生まれた新興EVメーカーの大半が量産段階で脱落したのはこのため

## 7. 参入障壁はどこにあるか

| 障壁 | 強さ | 説明 |
| --- | --- | --- |
| 組み立て技術 | **弱** | 委託生産（受託製造）も可能。ここだけなら参入できる |
| **量産品質・安全認証** | 強 | 各国の型式認証、衝突安全、リコール責任。これが新興の墓場 |
| **電池の調達** | 強 | 長期契約と合弁を押さえられるか。量が取れないと価格で負ける |
| **販売・整備網** | 中〜強 | 直販でも整備は必要。ゼロから作ると時間がかかる |
| **資本の厚み** | 強 | 黒字化まで数千億〜兆円を燃やす覚悟が要る |
| ソフトウェア | 中 | 新興のほうが有利な領域。既存OEMの弱点 |

## 用語メモ

- **OEM**：自動車業界では完成車メーカーを指す
- **アライアンス**：資本・技術・生産で結ぶ提携の総称。目的は固定費の割り勘
- **OEM供給**：他社が作った車を自社ブランドで売ること
- **内巻（ネイジュアン）**：中国語で消耗戦・過当競争を指す語。値下げ合戦の状態
- **マルチパスウェイ**：HEV・PHEV・BEV・FCEVを並行して用意する考え方
- **SDV（ソフトウェア定義車両）**：出荷後のソフト更新で価値が変わる車
- **OTA**：無線でソフトを更新する仕組み
- **E-GMP／TNGA／MQB**：各社のプラットフォーム名
- **相殺関税**：補助金を受けた輸入品に対し、その分を打ち消すために課す関税
- **型式認証**：量産車が基準に適合していることを国が認める制度。取得に時間と費用がかかる
