# 自動車（完成車）｜サプライチェーンと系列

**このノートで分かること**：1台3万点の部品が、どういう階層をたどって完成車工場に届くのか。
日本の「ケイレツ」と欧米の調達方式は何が違うのか。そして、半導体不足がなぜあれほど効いたのか。

結論を先に書くと、自動車産業は **「完成車メーカーが頂点にいるピラミッド」** である。
完成車メーカー（OEM）が自分で作るのは車両価値の3割前後にすぎず、残りは何万社もの部品会社が担う。
この **「自分では作らないが、全部の責任を負う」** という立ち位置が、
自動車メーカーの強さ（調達交渉力）と弱さ（1社の欠品で全ラインが止まる）を同時に作っている。

## 0. 全体像：ピラミッドの断面

```
                    ┌────────────────┐
                    │  OEM（完成車メーカー）  │  トヨタ、VW、GM、BYD…
                    │  設計統括・組立・販売・ブランド │  世界で十数グループ
                    └───────┬────────┘
                            │ 直接取引（数百〜千社）
              ┌─────────────┴─────────────┐
              │ Tier1（一次サプライヤー）                    │ デンソー、アイシン、ボッシュ、
              │ ユニット／モジュール単位で納入               │ コンチネンタル、現代モービス
              └─────────────┬─────────────┘
                            │ 数千社
              ┌─────────────┴─────────────┐
              │ Tier2（二次）：機構部品・電子部品・加工品     │
              └─────────────┬─────────────┘
                            │ 数万社
              ┌─────────────┴─────────────┐
              │ Tier3以下：ねじ、ばね、鋳物、めっき、金型     │ 中小零細が大半
              └───────────────────────────┘
                            ▲
                 素材（鉄鋼・アルミ・樹脂・ガラス・ゴム・半導体）
```

- 日本の自動車関連企業は **約6万9,000社**、就業人口は **約559万人**（JAMA推計、2024年前後）
- この階層の厚さが「**裾野が広い**」と言われる実体。詳しくは [README](README.md) の第1章

## 1. 誰が何を納めているのか（Tierの実務）

| 階層 | 納めるもの | 具体例 | 経済的な性格 |
| --- | --- | --- | --- |
| **Tier1** | すぐ車に付けられる**ユニット／モジュール** | シート一式、インパネ一式、ブレーキシステム、eAxle、エアコンユニット、ADAS用カメラ | 開発費を自社負担することが多く、OEMと共同開発。規模がないと生き残れない |
| **Tier2** | Tier1に組み込まれる部品 | モーター、センサー、半導体、ハーネス、ばね、樹脂成形品 | 専門技術の深さで勝負。複数Tier1に横売りできると強い |
| **Tier3以下** | 素形材・加工 | 鋳造、鍛造、切削、プレス、めっき、熱処理、金型 | 労働集約・設備集約。価格転嫁が最も難しい層 |
| **素材** | 鋼板、アルミ、樹脂、ガラス、ゴム | 高炉メーカー、化学、ガラス、タイヤ | 市況の影響を受け、OEMと直接価格交渉する（**ひも付き取引**） |

補足：Tier1が全部を自社で作るわけではなく、**シートのフレームはTier2、表皮はTier3** というように、
1つのモジュールの中にさらにピラミッドが入れ子で存在している。

> ポイント：「Tier1／Tier2」は会社の格ではなく **取引上の位置**。
> 同じ会社がA社にはTier1、B社にはTier2として納めることは普通にある。

## 2. ケイレツ（系列）とは何だったのか

日本の完成車メーカーは、部品会社と **資本・人材・情報でつながった長期継続取引** を築いた。これが系列。

| 側面 | 系列（日本型） | 伝統的な欧米型（アームズレングス） |
| --- | --- | --- |
| 取引期間 | 車のモデルライフ（4〜6年）を通じて継続。次期型も基本的に継続 | 部品ごとに競争入札。安い方へ乗り換える |
| 図面 | **承認図・貸与図**。サプライヤーが設計に踏み込む | 発注側が仕様を決め、作らせる（貸与図中心） |
| 価格 | 毎年の**原価低減要請（数%）**を前提に、利益は残す | 都度入札。値決めの上下が大きい |
| 資本関係 | OEMが数%〜過半を出資。役員も派遣 | 原則なし |
| 品質保証 | OEMがサプライヤーの工程まで指導・監査 | 受入検査で判定 |
| 強み | すり合わせ品質、開発の速さ、改善の共有 | 調達コストの機動的な削減 |
| 弱み | **価格の透明性が低い／新規参入が難しい／共倒れリスク** | 品質作り込みが弱く、緊急時の協力を得にくい |

### 承認図・貸与図という言葉

- **貸与図（たいよず）**：OEMが図面を描き、サプライヤーはその通りに作る。付加価値は加工だけ
- **承認図（しょうにんず）**：サプライヤーが設計し、OEMが承認する。**設計の付加価値をサプライヤーが取る**
- 日本のTier1が強いのは承認図の領域を持ってきたから。逆にTier3の多くは貸与図＝価格勝負になりやすい

### 系列は今どうなっているか

- 1990年代の日産リバイバルプランなどを機に、**株式の持ち合いは大幅に整理**された
- 実態としては「資本の系列」は薄まり、**「取引と開発の継続性」だけが残っている**状態
- さらに2020年代、トヨタがデンソーとアイシンの一部株式を売却するなど、資本のほどけは続いている（報道ベース）
- 一方で電動化・ソフト化により、**従来の系列外（電機、半導体、IT）から新しいTier1が流入**している
  → [自動車部品](../02_自動車部品/README.md)、[EV・電動化](../../01_注目テーマ/03_EV・電動化/README.md)

## 3. ジャストインタイム（JIT）の実際

JIT＝**必要なものを、必要なときに、必要なだけ**。在庫を持たないのが原則。

```
【従来型（押し込み生産）】
 前工程 ──▶ 大量に作る ──▶ 倉庫にためる ──▶ 後工程が取りに来る
                            ↑ 在庫＝資金と場所を食う。不良も滞留する

【JIT（引っ張り生産）】
 後工程が使った分だけ ──「かんばん」で前工程に発注──▶ 前工程が同じ量だけ作る
                                                    ↑ 在庫は数時間分しかない
```

実務上の姿：

- Tier1は完成車工場の近くに拠点を置き、**1日に数便〜十数便、時刻指定で納入**する
- シートのように大きく在庫できない部品は、ラインに流れる車の順番に合わせて
  **「その車専用の1脚」を順番どおりに積んで届ける**（**順序納入 / シーケンス納入**）
- 工場の敷地内に部品倉庫がほとんどない。**トラックが走る道路が倉庫**という表現もされる

| 得られるもの | 失うもの |
| --- | --- |
| 在庫資金の圧縮（運転資本が軽い） | 供給が1本切れると即ライン停止 |
| 不良の早期発見（滞留がないのですぐ露見） | 輸送便数が増え、物流コストとCO2は増える |
| 置き場が要らず工場が小さくて済む | 災害・地政学リスクへの耐性が低い |

## 4. 半導体不足で露呈した弱点（2021〜2023年）

自動車の半導体不足は、JITとピラミッドの両方の弱点が同時に出た事例として教科書的である。

### 何が起きたか（時系列の要約）

```
2020年春  コロナで需要急減 → OEMが車載半導体の発注を削減
2020年後半 予想外の需要回復 → 慌てて発注を戻す
           しかし空いた生産枠は スマホ・PC・データセンター向けが埋めていた
2021年     車載マイコンの納期が半年〜1年超へ。世界で数百万台規模の減産
2021年3月  ルネサス那珂工場の火災、米テキサスの寒波で工場停止 → さらに悪化
2022〜23年 ロックダウン、部品の海上物流の混乱が重なり、納期長期化が常態化
```

### なぜ自動車だけ深刻だったのか

| 要因 | 中身 |
| --- | --- |
| **発注が階層の奥に隠れていた** | OEMは半導体メーカーと直接取引していない。Tier1→Tier2→半導体と辿るため、OEMが「自分の車に何のチップが何個入るか」を把握していなかった |
| **在庫がない** | JITで数日分しか持たない。上流が止まると即座に効く |
| **買い手として弱い** | 車載半導体は世界の半導体市場の1割前後。**スマホより優先度が低い**客だった |
| **代替が効かない** | 車載は認証（機能安全・車載温度規格）が重く、別のチップに差し替えるのに年単位かかる |
| **1個足りないだけで車が作れない** | 数百個のチップのうち1種でも欠ければ完成車にならない（最弱リンク問題） |

### 産業は何を変えたか

1. **OEMが半導体メーカーと直接契約・長期引取保証を結ぶ**ようになった（階層を飛ばす）
2. **部品表（BOM）を数段下まで可視化**する取り組み。「どのTier3がどこにいるか」を地図で管理
3. **戦略在庫**：重要部品だけJITをやめて数週間〜数ヶ月分を持つ（**ジャスト・イン・ケース**）
4. 設計側で **チップ種類の共通化・削減**。1車種のマイコン品種を絞る
5. 地域分散（中国＋1、ニアショアリング）

> 教訓：JITは「上流が正常であること」を前提にした最適化だった。
> 現在は **平常時はJIT、重要部品だけ在庫を持つ** というハイブリッドが主流になっている。

## 5. 供給が止まる典型パターン

自動車のライン停止は、実は半導体だけの話ではない。過去の事例が示す共通構造がある。

| 年 | 出来事 | 詰まった場所 | 構造的な教訓 |
| --- | --- | --- | --- |
| 2007 | 新潟県中越沖地震（リケンのピストンリング） | **Tier2の1工場** | 小さな部品でも独占供給なら全社が止まる |
| 2011 | 東日本大震災（ルネサス那珂、特殊顔料） | Tier2〜3、素材 | 「どこで作っているか」を誰も把握していなかった |
| 2011 | タイ洪水 | 海外Tier2 | 海外分散しても集中していれば意味がない |
| 2016 | 熊本地震（アイシン九州） | Tier1 | 代替生産の立ち上げに数週間かかる |
| 2021〜23 | 半導体不足 | Tier2〜3 | 買い手としての優先順位が低かった |
| 2022〜 | ワイヤーハーネス（ウクライナ情勢） | 労働集約のTier1〜2 | 人手のかかる部品ほど地理的に偏る |
| 2026 | 中東情勢によるアルミ・ナフサ等の調達混乱 | **素材** | 素材までさかのぼると代替に年単位かかる（報道ベース、→ [直近トピック](06_直近トピック_2026.md)） |

共通するのは **「上流に行くほど1社集中していて、代替に時間がかかる」** という点。
そして完成車メーカーは、その事実を **止まってから知る** ことが多い。

## 6. 調達の実務：原価はどう決まるか

- **原価企画**：車の企画段階で「目標売価 － 目標利益 ＝ 許容原価」を決め、そこから部品ごとに配分する。
  「かかった原価に利益を乗せる」のではなく、**先に上限を決めてから設計する**のが自動車流
- **VA/VE（バリューアナリシス／エンジニアリング）**：設計変更で機能を保ったまま安くする提案活動。
  サプライヤーが提案し、削減額をOEMと分け合う仕組みを持つ会社もある
- **年次の原価低減**：モデルライフを通じて年に数%の値下げを前提に価格を決める慣行（近年は資材高で緩和方向）
- **価格転嫁**：2022年以降の資材・エネルギー高で、公正取引委員会や中小企業庁が
  **労務費・原材料費の転嫁を促す指針**を出し、業界慣行に是正圧力がかかっている

## 用語メモ

- **OEM**：自動車業界では「完成車メーカー」を指す（他業界の用法とズレるので注意）
- **Tier1／Tier2／Tier3**：完成車メーカーから見た取引の階層。会社の格ではなく位置
- **ケイレツ（系列）**：資本・人材・長期取引で結ばれたOEMと部品会社の関係
- **承認図／貸与図**：設計の主導権がサプライヤー側かOEM側か
- **JIT（ジャストインタイム）**：必要な物を必要な時に必要なだけ流す方式
- **かんばん**：後工程が使った分を前工程に知らせる指示票
- **順序納入（シーケンス納入）**：ラインに流れる車の順番どおりに部品を届けること
- **BOM（部品表）**：どの部品が何個使われているかの一覧。多段BOMの可視化が供給網管理の基礎
- **原価企画**：売価と利益から逆算して許容原価を決める手法
- **ジャスト・イン・ケース**：重要部品だけ意図的に在庫を持つ考え方
- **ひも付き取引**：OEMが素材メーカーと直接価格を決め、部品メーカーがその価格で買う仕組み
