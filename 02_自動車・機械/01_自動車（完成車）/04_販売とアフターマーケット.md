# 自動車（完成車）｜販売とアフターマーケット

**このノートで分かること**：作ったクルマがどういう商流で顧客に届くのか。
ディーラー（販売店）は何で食べているのか。そして **新車を売ることより、売った後のほうが儲かる** という構造。

結論を先に書くと、日本の新車販売は **「メーカー → 販売会社（ディーラー）→ 顧客」** という
2段階の商流で動いており、ディーラーの新車粗利は薄い。
ディーラーの利益の柱は **車検・整備・板金・部品（アフターサービス）と、中古車、そして金融・保険の手数料** にある。
つまり **新車販売は「将来の整備顧客を獲得する行為」** という側面を強く持つ。

## 1. 新車の商流：誰が誰に売っているのか

```
【日本】
 メーカー ──(卸)──▶ ディーラー（販売会社） ──(小売)──▶ 顧客
   │                    ▲                         │
   │  販売金融子会社 ────┘ 在庫金融(フロアプラン)   │ ローン・リース・保険
   └───────────────────────────────────────────────┘
                     ※ディーラーが在庫を買い取り、自分の名義で売る（買取型）

【米国】
 メーカー ──▶ 独立系ディーラー（フランチャイズ法で保護）──▶ 顧客
              ※メーカーの直販が州法で制限されている州がある

【テスラ／一部の新興・中国勢】
 メーカー ──────── 直販（オンライン＋ショールーム）────────▶ 顧客
              ※在庫リスクと粗利を自社で持つ。価格は全国一律にしやすい
```

| 方式 | 誰が在庫を持つか | メーカーの利点 | 弱点 |
| --- | --- | --- | --- |
| **ディーラー買取型（日米欧の主流）** | ディーラー | 在庫リスクを外に出せる。資本を使わず販売網を広げられる | 値引き競争の管理が難しい。顧客データが手元に残りにくい |
| **エージェント（代理店）型** | メーカー | 価格を統制でき、顧客データを直接持てる | 在庫リスクと運転資本をメーカーが負う |
| **直販型** | メーカー | 価格・体験・データを完全に握る | 販売網と整備網をゼロから作る必要がある |

- 欧州では2020年代に **エージェント型への転換**を進めたメーカーがあるが、収益性や販売店の反発で揺り戻しもある（報道ベース）
- 日本ではトヨタが2020年に **全店で全車種を扱う「全車種併売」** に移行し、4系列チャネル制を実質的に終えた

## 2. ディーラーの経済性：何で食べているか

| 収益部門 | 売上構成の目安 | 粗利率の目安 | 性格 |
| --- | --- | --- | --- |
| 新車販売 | 5〜6割 | **数%（薄い）** | 台数を取るための入口。値引きで簡単に消える |
| 中古車販売 | 1.5〜2割 | 10%前後 | 下取り車の再販。仕入れ（下取り）の値決めが命 |
| **サービス（車検・点検・整備）** | 1割前後 | **30〜50%** | 工賃（人件費）が主。**利益の柱** |
| 部品・用品 | 数% | 20〜30% | 純正部品とオプション |
| 金融・保険の手数料 | 数% | ほぼ丸儲け | ローン・残クレ・自動車保険の代理店収入 |

※ 業態・規模で大きく変わる。桁感をつかむための目安。

```
【ディーラーの損益イメージ（粗利の出どころ）】

 売上  ■■■■■■■■■■■■■■■■  新車が6割
 粗利  ■■■■                    新車の粗利はここだけ
       ■■■■■■■■              サービス・部品
       ■■■                     中古車
       ■■                      金融・保険
       └─▶ 台数は新車、利益はサービス、という逆転が起きている
```

> 押さえどころ：新車1台の粗利が仮に10〜20万円でも、
> その顧客が **10年間、車検を5回・点検を10回・部品交換を重ねる**と、
> 生涯の粗利ははるかに大きくなる。**保有台数＝将来の収益権**という見方が業界の常識。

## 3. 車検という制度が作る収益

日本のアフターマーケットが安定している最大の理由は、**車検（自動車検査登録制度）** という法制度にある。

| 車種 | 初回車検 | 2回目以降 |
| --- | --- | --- |
| 自家用乗用車（登録車・軽） | **新車から3年** | **2年ごと** |
| 自家用貨物（軽以外の小型貨物） | 2年 | 1年 |
| 事業用乗用（タクシー等）・大型トラック・バス | 1年 | 1年 |

- 車検を受けないと公道を走れない ＝ **需要が法律で作られている**
- 車検時の支払いは (a) **法定費用**（自賠責保険料・自動車重量税・印紙代）と (b) **整備料金・工賃** に分かれる。
  事業者の売上になるのは (b) の部分
- 日本の総整備売上高は **約5兆9,072億円**（令和5年度、日本自動車整備振興会連合会の実態調査）
- 整備事業場は **約9万1,849事業場**（同、令和5年6月末時点）。ディーラー系は事業場数では約16%だが、
  **売上ではディーラー系が専業を上回る**（同調査）＝ 1事業場あたりの規模が大きい

### プレイヤーの類型

| 類型 | 特徴 | 強み／弱み |
| --- | --- | --- |
| **ディーラー整備工場** | メーカー系。新車購入者をそのまま囲い込む | 技術情報・専用機器・純正部品にアクセスできる／価格は高め |
| **専業工場（町の整備工場）** | 事業場数では最多。地域密着 | 価格と融通／後継者不足と設備投資負担が重い |
| **兼業（ガソリンスタンド等）** | 給油のついでに軽整備 | 接点の多さ／高度な整備はできない |
| **車検専門・カー用品店チェーン** | 短時間・低価格の車検 | 価格訴求／作業範囲が限られる |
| **自家整備（大口ユーザー）** | 運送会社などが自社工場を持つ | コスト管理／規模が要る |

### 構造的な逆風と追い風

- **逆風**：整備要員の高齢化と人手不足。EV化で油脂・排気系の交換需要が減る。
  回生ブレーキでブレーキパッドの摩耗も減る
- **追い風**：**保有車の平均車齢が上がっている**（日本の乗用車平均使用年数は14年前後まで伸長）。
  古い車ほど整備が要る。さらに **ADAS（先進運転支援）付き車のエーミング**
  （カメラ・レーダーの光軸調整。ガラス交換や板金のたびに必要）という新しい作業が増えた
- **制度**：2020年に「分解整備」が **「特定整備」** に拡張され、
  ADASの電子制御装置整備に認証が必要になった。設備・人材投資に耐えられない工場は淘汰される方向

## 4. 中古車と認定中古車

```
【1台のクルマの一生と、そのたびに立つ商売】

 新車販売 ─▶ 保有(平均14年前後) ─▶ 下取り ─▶ オークション ─▶ 中古車販売 ─▶ 輸出 or 解体
   OEM         車検・整備・部品      ディーラー   USS等のAA     中古車店     中古車輸出商
   ディーラー   保険・ローン         買取専門店   （業者間市場） 認定中古車   解体・リサイクル
```

- 日本の中古車の年間取引台数は **約648万台**（2025年、調査会社集計。前年比0.2%減）。
  新車販売（2025年 **約456万台**、自販連・全軽自協）の **1.4倍規模**
- **オートオークション（AA）**：業者間の中古車卸売市場。USSなどが運営し、価格の基準を作る。
  ここでの相場が **残価設定ローンの前提**にもなる（→ [③ 儲け方の構造](03_儲け方の構造.md)）
- **認定中古車（CPO）**：メーカー／ディーラーが点検・保証を付けて売る中古車。
  - メーカーの狙いは **中古相場の下支え**。相場が下がると残価損が出て、新車の月々も高くなる
  - つまり認定中古車は「中古を売る商売」であると同時に **新車の価格競争力を守る装置**
- **中古車輸出**：日本車は右ハンドル圏・耐久性重視の地域で人気が高く、年間100万台超が輸出される年もある。
  これが国内の下取り価格を支えている

## 5. サブスクとリース：所有から利用へ

| 形態 | 契約者 | 含まれるもの | 特徴 |
| --- | --- | --- | --- |
| 個人リース（残価設定型） | 個人 | 車両＋税金 | 月額が安いが走行距離・原状回復の制限あり |
| **カーサブスク** | 個人 | 車両＋税金＋保険＋メンテ＋車検 | 「月々いくら」で全部込み。若年層に届きやすい |
| 法人リース（ファイナンス／メンテナンス） | 企業 | 車両（＋整備） | 社用車の定番。資産を持たずに使う（→ [リース](../../05_金融/10_リース/README.md)） |
| カーシェア・レンタカー | 個人・法人 | 時間貸し | 保有そのものをやめる層の受け皿 |

- トヨタの **KINTO** は2025年3月期に **初の最終黒字（約8億円）**、累計契約 **14万件超**と報じられた
  （日経、マイナビ等の報道ベース）。サブスクが単体事業として成立し始めた節目とされる
- メーカーがサブスクを重視する理由は3つ：
  1. **若年層の入口**：初期費用ゼロで新車に乗せられる
  2. **顧客との直接接点**：ディーラー経由では得にくい利用データと継続関係を持てる
  3. **残価コントロール**：返却車を認定中古に回し、相場を自分で管理できる

## 6. これから何が変わるか

| 変化 | 販売・アフターへの影響 |
| --- | --- |
| **オンライン販売の浸透** | 見積・契約はネット、納車と整備はリアル。ディーラーの役割が「売る場所」から「触る・直す場所」へ |
| **EV化** | オイル交換・排気系・変速機の整備需要が消え、**整備売上が構造的に縮む**。高電圧作業の資格・設備が新たに要る |
| **OTA（無線ソフト更新）** | 不具合修正が入庫なしで済む。一方で **機能をあとから売る**（サブスク機能）という新収益が生まれる |
| **ADAS普及** | エーミング需要が増え、板金・ガラス交換の単価が上がる。事故件数自体は減る方向 |
| **保険の変質** | 事故が減れば保険料収入も減る。自動運転では責任がメーカー側に寄る（→ [自動運転](../../01_注目テーマ/15_自動運転/README.md)） |
| **人手不足** | 整備士の確保が最大の制約。待遇改善で工賃単価は上がりやすい |

> まとめると、**「売る回数は減り、1台と長く付き合う商売に寄る」** のがこの10年の方向。
> だから各社が「保有台数 × 1台あたり年間収益（ARPU的な発想）」でアフターを語るようになっている。

## 用語メモ

- **ディーラー（販売会社）**：メーカーと販売契約を結び、在庫を買い取って小売する会社
- **併売**：同一販売店で複数チャネル・全車種を扱うこと
- **フロアプラン**：ディーラーの在庫車を担保にした在庫金融
- **法定費用**：車検時の自賠責保険料・自動車重量税・印紙代。事業者の売上にはならない
- **特定整備**：2020年に分解整備から拡張された制度。ADASの電子制御装置整備を含む
- **エーミング**：ADASのカメラ・レーダーの取付角度を再調整する作業
- **オートオークション（AA）**：業者間の中古車卸売市場。中古相場の基準を作る
- **認定中古車（CPO）**：メーカー基準の点検・保証付き中古車
- **平均車齢／平均使用年数**：保有車の古さを示す指標。上がるほど整備需要は増える
- **カーサブスク**：税金・保険・メンテ込みの月額利用サービス
