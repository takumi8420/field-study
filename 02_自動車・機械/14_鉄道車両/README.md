## 1. 業界の定義・範囲

**鉄道車両産業** ＝ 鉄道の上を走る車両（電車・気動車・機関車・貨車・路面電車）を
設計・製造し、鉄道事業者に納入する産業。近年は**保守・改修まで含めて引き受ける**のが標準になった。

```
【鉄道という産業の全体像】

 ┌──────────────────────────────────────────────────────┐
 │ 作る側（このノート）                                         │
 │   車両メーカー：日立、川崎車両、総合車両製作所、日本車輌、近畿車輛 │
 │   電機メーカー：三菱電機、東芝、東洋電機製造（駆動系）           │
 │   信号メーカー：日本信号、京三製作所、大同信号                  │
 │   部品：ナブテスコ（ブレーキ）、NSK/NTN（軸受）、内装各社        │
 ├──────────────────────────────────────────────────────┤
 │ 建てる側：ゼネコン（高架・トンネル）、電設（架線・変電）          │
 ├──────────────────────────────────────────────────────┤
 │ 運ぶ側：JR各社、私鉄、公営交通、第三セクター → 13_運輸・物流/01_鉄道 │
 └──────────────────────────────────────────────────────┘
```

境界の引き方：

- **鉄道会社の経営（運賃・沿線開発・貨物）** は [鉄道](../../13_運輸・物流/01_鉄道/README.md) に置く
- **信号・保安システム**は本来は別産業だが、
  **競争軸がシステム一括に移った以上、車両産業を語るには不可欠**なのでここでも扱う
- **モータ・インバータ単体**の技術は [モーター](../15_モーター/README.md) に寄せる
- **レール・まくらぎ・架線**などの軌道・電化設備は建設・電設の領域

【成長性の見取り図】

## 5. 収益モデル・コスト構造

```
 売上 ＝ 受注残の取り崩し（2〜4年前に結んだ契約） ＋ 保守・部品（毎年）
 原価 ＝ 購入部品（電機品・内装で5〜6割） ＋ 材料（アルミ・鋼材） ＋ 直接工の人件費
 固定費 ＝ 工場・熟練工・設計部隊 ← 受注が途切れても減らせない
```

| 論点           | 中身                                                                                        |
| -------------- | ------------------------------------------------------------------------------------------- |
| 1両の価格      | 通勤電車 **1億円前後**、特急 2億円前後、新幹線 **2.7〜4.5億円**（いずれも推計・報道ベース） |
| 購入部品比率   | **5〜6割**。駆動系だけで原価の3割前後                                                       |
| 営業利益率     | **車両単体では数%**。近畿車輛は2.9%（2026年4〜6月、報道ベース）                             |
| 在庫リスク     | ほぼゼロ（受注してから作る）。代わりに**受注残が切れると工場が空く**                        |
| 最大のリスク   | **固定価格×長納期**。数年後の材料費・人件費を読み違えると一括で損失が出る                   |
| 利益が厚い領域 | 信号・保安（20〜25年更新）、**30年の保守契約**（毎年の安定収入）                            |
| 量産効果       | ほぼ効かない。**標準車体（sustina / A-train / efSET）で設計費を薄めるのが唯一の対策**       |

## 6. 競争要因（KSF）と参入障壁

**KSF（成功の鍵）**

1. **信号を持っているか** ── 持たないと「システム一括」を売れない。日立の買収はここへの回答
2. **現地に工場と保守拠点があるか** ── Buy America など制度要求と顧客要求の両方を満たす
3. **受注残を切らさないこと** ── 熟練の溶接工・艤装工は一度失うと戻らない
4. **見積もり精度** ── 固定価格で数年先の原価を約束する商売。外すと赤字が一括で出る
5. **標準車体による原価低減** ── 個別受注の重さを設計の使い回しで薄める
6. **レファレンス（納入実績）** ── 実績がないと入札に呼ばれない

**参入障壁**

| 障壁                       | 強さ     | 理由                                               |
| -------------------------- | -------- | -------------------------------------------------- |
| 製造設備                   | 中       | 工場と溶接設備は買える                             |
| **安全認証・納入実績**     | **強**   | 「どこかで無事故で走っている」実績が入札資格になる |
| **信号・保安システム**     | **最強** | 認証取得に年単位。買収でしか入れないほど           |
| **長期保守の実行力**       | 強       | 現地に人と拠点が要る                               |
| **運転資金**               | 強       | 納入まで2〜4年、代金回収が遅い                     |
| **制度（Buy America 等）** | 強       | 現地工場がないと入札資格すら得られない             |

## 7. 規制・法制度

| 分野               | 主な制度                                                                                                                            |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------- |
| **車両の安全基準** | 鉄道事業法、**鉄道に関する技術上の基準を定める省令**。車両設計・構造・ブレーキ性能の基準                                            |
| **確認・届出**     | 新形式車両の使用開始には国土交通省への**車両設計の確認・届出**が必要                                                                |
| **統計**           | **鉄道車両等生産動態統計調査**（国交省）。受注・生産・受注残を月次／四半期／年次で公表                                              |
| **輸出支援**       | **インフラシステム海外展開戦略2025**、国交省インフラシステム海外展開行動計画。JICA円借款・JBIC融資とセットで案件を組む              |
| **海外の調達規制** | 米 **Buy America**（国内調達比率＋国内最終組立の義務）、**連邦資金による中国製鉄道車両の調達制限**、EUの外国補助金規則              |
| **国際規格**       | 欧州の **TSI**（相互運用性技術仕様）と **EN 規格**、鉄道安全の **CENELEC 規格（EN 50126/50128/50129）**。欧州案件ではこの認証が前提 |
| **環境・省エネ**   | 省エネ法、各社のカーボンニュートラル目標。回生ブレーキ・SiC インバータ採用の後押しに                                                |
| **バリアフリー**   | バリアフリー法。車椅子スペース、情報提供設備などが車両仕様に反映される                                                              |

## 8. 最近のトピック

詳細と出典は [④ 直近トピック（2026年9月時点）](04_直近トピック_2026.md)。要点は次の5つ。

- **国内生産は減少**。2025年度は **1,161両**（前年度比93.7%）。JR 464両、公営・民鉄 619両、輸出 78両
- **受注は世界的に過去最高、しかし採算が苦しい**。アルストムは受注残1,040億ユーロ（2026年3月末、+10%）、
  Book-to-bill 1.4 を記録する一方、2025/26年度の調整後EBITマージンは約6%と計画未達
- **米国の関税がコストに効き始めた**。シーメンス・モビリティが2026年5月に売上見通しを引き下げたと報道。
  固定価格契約のため転嫁できない
- **日本勢の海外は二つの成功パターン**。日立＝英国現地生産＋タレス信号事業買収（約2,822億円）で
  「システムを売る会社」へ。川崎車両＝ニューヨーク市地下鉄で R211 総数1,175両に加え
  **R268 型378両（約2,200億円）を2025年11月に内示**
- **高速鉄道輸出は納入段階へ**。台湾高鐵向け N700S ベース車両（12編成144両・約1,240億円）が2026年から出荷、
  インド向けは E10 系と同形を2026年ごろ納入予定と報じられる
