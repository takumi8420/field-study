# ④ 直近トピック（2026年9月時点）

報道・各社発表ベースの整理。数値は必ず年月とセットで見ること。
推計・報道であるものはその旨を明示している。一次情報は末尾の参考リンクから確認できる。

> この1年の構図をひとことで言えば、
> **「受注は過去最高、でも作る現場は苦しい」**。
> 世界中で鉄道への投資が積み上がる一方、材料費・人件費・関税がメーカーの採算を削っている。

## 1. 国内生産は減少：2025年度は1,161両（前年度比93.7%）

日本鉄道車輌工業会（JARi）の集計では、2025年度の国内実生産は **1,161両**。
2024年度の1,239両に対して **93.7%** と、1割近く減った。

| 区分                     | 2025年度       | 内訳のポイント                         |
| ------------------------ | -------------- | -------------------------------------- |
| **実生産 総計**          | **1,161両**    | 2024年度 1,239両 → 93.7%               |
| JRグループ向け           | 464両          | 新幹線・在来線の更新が中心             |
| 公営・民鉄向け           | 619両          | 全体の半分超。**細かい案件の積み上げ** |
| 輸出                     | 78両           | 国内工場から船積みした分のみ           |
| 電車                     | 1,059両（91%） | 日本の車両工業は実質「電車工業」       |
| 気動車／電気機関車／貨車 | 39／34／28両   | 機関車・貨車は極小                     |

```
【国内生産の推移イメージ】

 2024年度  ■■■■■■■■■■■■■■■■■■■■■■■■■  1,239両
 2025年度  ■■■■■■■■■■■■■■■■■■■■■■■    1,161両（93.7%）
                                      ▲ 減少の主因は更新の端境期と見られる
 ※ この統計は「日本国内の工場で作った両数」。
   日立の英国工場、川崎車両の米国工場の分は含まれない。
   → 国内統計だけでは日本メーカーの実力は測れない
```

注意：この統計は生産の「谷」と「山」が案件のタイミングで大きく振れる。
単年の増減で長期トレンドを語るのは危険で、**5年の移動平均で見るのが実務的**。

## 2. アルストム：受注残1,040億ユーロの過去最高、しかし採算は計画未達

世界市場の温度感を最もよく示したのが、アルストム（仏）の2025/26年度決算（2026年5月発表）。

| 指標                 | 数値                                            | 時点            |
| -------------------- | ----------------------------------------------- | --------------- |
| 受注残（バックログ） | **1,040億ユーロ**（+10%、オーガニックでは+11%） | 2026年3月末     |
| 同（四半期時点）     | 1,003億ユーロ                                   | 2025年12月末    |
| Book-to-bill         | **1.4**                                         | 2025/26年度通期 |
| 第3四半期の受注      | 96億ユーロ（前年同期比で2倍超）                 | 2025年10〜12月  |
| 調整後EBITマージン   | **約6%**（計画未達）                            | 2025/26年度     |

同社は2026/27年度に向けて「全製品ラインで安定した実行を取り戻すこと」を最優先課題に掲げ、
**実行改善のアクションプラン**を打ち出したと発表している。
一部の車両契約で問題が出ていることも認めていると報じられる。

> **この1件がこの産業の本質を全部言っている。**
> 受注は取れる（鉄道投資は世界的に増えている）。
> しかし、数年前に固定価格で取った契約を、上がった材料費と人件費で作ると赤字になる。
> → 構造の説明は [③ 需要の構造と受注産業の宿命](03_需要の構造と受注産業の宿命.md) の第3章

## 3. 米国の関税がメーカーのコストに効き始めた

2026年5月、**シーメンス・モビリティが米国の関税によるコスト増を理由に売上見通しを引き下げた**と報じられた。
鉄道車両は部品点数が多く、国境をまたぐ部材調達が前提になっているため、関税の影響を受ける。

| 影響経路       | 中身                                                                                     |
| -------------- | ---------------------------------------------------------------------------------------- |
| 部材の輸入関税 | アルミ・鋼材・電機品の調達コストが上がる                                                 |
| 現地調達義務   | **Buy America** 規制により、米国案件では国内調達比率と国内最終組立が義務。逃げ場が少ない |
| 固定価格契約   | 契約済み案件は値上げできない。**コスト増はメーカーの持ち出し**                           |

一方、この制度は日本勢にとって参入障壁であると同時に**防波堤**でもある。
Buy America と安全保障上の理由により、**CRRC は米国の連邦補助鉄道車両調達から事実上締め出されている**。
川崎車両が米国に工場を持ち続けている理由もここにある。

## 4. 川崎車両：ニューヨーク地下鉄で連続受注（R211 → R268）

日本メーカーの海外案件で最大級のものが、川崎車両のニューヨーク市交通局（NYCT）向け地下鉄車両。

| 時期           | 内容                                          | 金額（報道・発表ベース）                                        |
| -------------- | --------------------------------------------- | --------------------------------------------------------------- |
| 2018年〜       | **R211** 型を受注。追加を重ね総数 **1,175両** | 約32億ドル（約4,674億円）。同社の鉄道案件で過去最大と報じられる |
| 2025年2月      | R211 を **435両** 追加受注                    | 約1,773億円と報道                                               |
| **2025年11月** | 新型 **R268** 型 **378両** の発注内示         | **約15億ドル（約2,200億円）**、2028〜2030年納入予定             |

```
【川崎車両のNY案件が意味すること】

  現地工場（米国内2拠点）
        │
        ├─ Buy America 規制をクリアできる ─────────┐
        ├─ 同一形式の大量生産で量産効果が出る ─────┤──▶ 受注残が数年分積み上がる
        └─ 実績（レファレンス）が次の入札で効く ───┘        ＝ 工場と熟練工を維持できる

  リスク：発注元が1つに集中している（NYCT の予算が止まると一気に空く）
```

## 5. 日立レール：英国で車両＋保守、信号で世界へ

日立は「車両を売る会社」から「**鉄道システムを売る会社**」への転換を最も進めている。

| 時期        | 出来事                                                                                                                                                                                                                       |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2024年6月   | 仏 **タレス社の鉄道信号事業（GTS）の買収を完了**。買収額 **16億6,000万ユーロ（約2,822億円）**。従業員約9,000人が加わり、日立レールは世界51か国・約24,000人体制に。**売上の半分超を利益率の高い信号事業が占める構造**になった |
| 2025年4月   | 英鉄道会社から**バッテリー走行対応のハイブリッド車45両**を受注。契約額 約3億ポンド（約580億円）、**10年保守込み**、2028年納入予定と報道                                                                                      |
| 2026年3月期 | 日立のモビリティセクター売上収益 **1兆3,215億円**（前年比 **+12.8%**）。**鉄道信号・制御事業の受注が寄与**と説明（※昇降機等を含むセクター数値）                                                                              |
| 中期計画    | 2030年度に鉄道事業の売上高を **最大2兆円**（2024年度比で6割強増）とする計画と報じられる                                                                                                                                      |

> 注目点：日立のモビリティ増収の説明が「車両が売れたから」ではなく
> **「信号・制御の受注が寄与した」**になっていること。
> これが競争軸の変化そのもの。

## 6. 高速鉄道の輸出：台湾は納入段階、インドは2026年ごろ

| 案件                                           | 状況（2026年時点）                                                                                                                                                                                 |
| ---------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **台湾高鐵 向け新型高速車両**                  | 日立・東芝の連合（Hitachi Toshiba Supreme Consortium）が2023年5月に **12編成144両・約1,240億円**で受注。**N700S ベース**で、一部を日本車輌製造が製造。2026年から出荷・納入段階に入ったと各社が公表 |
| **インド高速鉄道**（ムンバイ〜アーメダバード） | **JR東日本の E10 系と同形の車両**を、2026年ごろに納入する計画と報じられる。日本の新幹線方式を丸ごと移植する最大の案件                                                                              |
| **フィリピン等の都市鉄道**                     | 総合車両製作所が商社と組んで通勤電車を受注した例がある                                                                                                                                             |

日本の鉄道輸出は、国土交通省の
**「インフラシステム海外展開戦略2025」および同省のインフラシステム海外展開行動計画**に基づいて推進されている。
車両単体ではなく、**車両＋信号＋運営ノウハウ＋円借款**の4点セットで提案するのが基本形。

```
【日本の高速鉄道輸出の実像】

 「新幹線を売る」＝ 車両を売ることではない

  車両（日立・日本車輌・川崎車両）
  ＋ 信号・保安（日立・日本信号・京三）
  ＋ 運行ノウハウ・要員教育（JR東海・JR東日本）
  ＋ 資金（JICA 円借款 / JBIC）
  ＋ 現地の法制度整備・要員育成
  ──────────────────────────
  ＝ 国ぐるみのパッケージとして初めて成立する
       ▲ だから商談は年単位、下手をすると10年単位になる
```

## 8. CRRC：規模は拡大、しかし出口が限られる

| 指標                                       | 数値                                 | 時点                                   |
| ------------------------------------------ | ------------------------------------ | -------------------------------------- |
| 売上高                                     | **2,730.6億元（約5.6兆円）**         | 2025年、決算ベース                     |
| 前年比                                     | **+10.8%**（2024年 2,464.7億元）     | —                                      |
| 新規契約（車両販売・改修・保守以外を含む） | 516.4億元（2025年売上の約18.9%相当） | 風力発電・蓄電設備など非鉄道分野を含む |

CRRC は世界最大の鉄道車両メーカーだが、構図には2つのねじれがある。

1. **欧米市場にほぼ入れていない**。米国は Buy America と安全保障立法で排除、
   EU も外国補助金規則の審査を強めており、入札から撤退する事例が出ている
2. **国内の高速鉄道建設が一巡**し、中国国内の新造需要は頭打ちとされる。
   そのため**風力発電・蓄電池といった非鉄道分野への多角化**を進めている

> つまり CRRC は「圧倒的に大きいが、売り先が広がらない」状態にある。
> これが日本勢・欧州勢にとっての時間的な猶予になっている。
> ただし東南アジア・アフリカ・中東では価格と融資条件で依然として強い。

## 10. 全体の構図（まとめ）

```
【2026年時点の鉄道車両産業】

  世界の鉄道投資         ↑↑  都市化・脱炭素・老朽更新で増加
         │
         ├─ 受注残は過去最高（アルストム 1,040億ユーロ）
         │
  作る側のコスト         ↑↑  材料費・人件費・米関税
         │
         └─ 固定価格契約のため転嫁できず、採算は悪化
                │
                ▼
  各社の答え：「車両で薄く取り、信号と30年保守で厚く回収する」
                │
     ┌──────────┼──────────┐
     ▼           ▼            ▼
  日立         川崎車両      国内系列メーカー
  信号買収＋   現地生産＋    JR系列の安定発注＋
  30年保守     大量反復受注   標準車体で原価低減
```

1. **需要は世界的に強い**。都市化、脱炭素、老朽更新の3つが同時に来ており、受注残は各社で過去最高水準
2. **しかし儲からない**。固定価格の長期契約に、材料費・人件費・関税の上昇が直撃している
3. **だから競争軸が上に移った**。車両単体ではなく、信号・運行管理・30年保守まで含めた一括提供へ
4. **日本国内は縮小基調**。2025年度生産は1,161両で前年度比93.7%。更新需要中心の構造は変わらない
5. **日本勢の活路は海外の現地化**。日立の英国＋信号買収、川崎車両の米国工場が二つの成功パターン

## 11. 用語メモ

| 用語                             | 意味                                                                                       |
| -------------------------------- | ------------------------------------------------------------------------------------------ |
| **受注残（バックログ）**         | 契約済みでまだ引き渡していない仕事の金額。売上の何年分あるかで工場の先行きが読める         |
| **Book-to-bill**                 | 受注÷売上。1を超えていれば手持ち仕事が増えている                                           |
| **調整後EBITマージン**           | 一時費用を除いた営業利益率。アルストムなど欧州勢が採算指標として使う                       |
| **Buy America**                  | 米国の連邦補助鉄道調達で国内調達比率・国内最終組立を義務づける規制                         |
| **GTS**                          | タレス社の Ground Transportation Systems（地上輸送システム）部門。日立レールが2024年に買収 |
| **N700S／N700ST**                | JR東海の最新新幹線車両と、それをベースにした台湾高鐵向け輸出仕様                           |
| **E10系**                        | JR東日本の新形式新幹線車両。インド高速鉄道向けに同形が供給される計画と報じられる           |
| **インフラシステム海外展開戦略** | 日本政府のインフラ輸出の基本方針。鉄道は主要分野の一つ                                     |
| **量産先行車**                   | 本格量産の前に少数作って走行試験を行う車両。JR東海の385系がこれにあたる                    |
| **ハイブリッド車（鉄道）**       | エンジン発電＋蓄電池でモータを回す気動車。非電化区間の省エネ・脱炭素策                     |
