# ① 鉄道車両の作られ方と構成

このノートで分かること：**鉄道車両は何でできていて、どういう順番で作られるのか**。
そして「1両1億円」という値段と、**量産効果がほとんど効かない**という、この産業最大の特徴がどこから来るのか。

> ポイント：鉄道車両は自動車と同じ「乗り物の製造業」に見えて、**経済的には造船や建設に近い**。
> 1つの案件ごとに設計し直す**個別受注生産（オーダーメイド）**だからだ。

## 1. まず結論：これは「量産品」ではない

自動車は同じ車種を年に数十万〜数百万台作る。鉄道車両は、**1つの発注が20〜300両**で終わる。
しかも発注元の鉄道会社ごとに、線路幅も、ホームの高さも、電気の種類も、
運転台のレイアウトも、座席の生地の色すら違う。

| 比較軸           | 自動車（乗用車）                   | 鉄道車両                                         |
| ---------------- | ---------------------------------- | ------------------------------------------------ |
| 1車種の生産数    | 年10万〜100万台                    | 1形式あたり累計 数十〜数百両                     |
| 生産方式         | ベルトコンベアの流れ作業（ライン） | **定置式に近い**。台車に乗せて工程間を移動させる |
| 設計             | プラットフォーム共通化で使い回す   | 案件ごとに個別設計（仕様書が数百ページ）         |
| 1台（1両）の価格 | 100万〜1,000万円                   | **1億円前後**（通勤電車。後述）                  |
| 顧客の数         | 数百万人の個人                     | **国内で実質100社程度の鉄道事業者**              |
| 買い替え周期     | 10年前後                           | **30年前後**                                     |
| 償却・回収       | メーカーが在庫リスクを負う         | **受注してから作る。在庫リスクはほぼゼロ**       |

```
【自動車と鉄道車両の「儲け方の形」の違い】

 自動車：  開発費（巨額） ──▶ 量産（数十万台で割る） ──▶ 1台あたり開発費は小さい
                                   ▲ 量産効果が効く

 鉄道車両：開発費（案件ごと） ──▶ 生産（数十〜数百両で割る） ──▶ 1両あたり開発費が重い
                                   ▲ 量産効果がほぼ効かない
                                   ＝ だから「設計の使い回し」が最大のコスト削減策になる
```

だから各メーカーは **標準車体（プラットフォーム）** を持っている。
総合車両製作所の `sustina`（ステンレス標準車体）、日立製作所の `A-train`（アルミ標準車体）、
川崎車両の `efSET`／`efACE` などがそれで、
「骨格は共通、内装と艤装だけ客ごとに変える」ことで、個別受注の重さを少しでも薄める設計思想だ。

## 2. 車両は5つのかたまりでできている

鉄道車両を分解すると、ざっくり5つのブロックになる。
**メーカーが自分で作るのは車体と組立だけ**で、残りは専門メーカーから買う（＝購入部品比率が高い）。

```
        ┌──────────────── 車体（箱）────────────────┐
        │  アルミ or ステンレス。窓・ドア・屋根        │
        │  ┌── 内装 ──┐   ┌── 空調・照明 ──┐        │
        │  │座席・床材 │   │冷房装置・LED   │        │
        │  └──────────┘   └───────────────┘        │
        │  ┌─ 電気品（床下） ────────────────────┐  │
        │  │ パンタグラフ → 主変圧器 → VVVFインバータ│ │
        │  │ → 主電動機(モータ) → 歯車 → 車輪       │ │
        │  └──────────────────────────────────────┘ │
        └────────┬──────────────────┬────────────────┘
                 ▼                  ▼
            ┌─ 台車 ─┐        ┌─ 台車 ─┐   ← 1両に2台。車輪・軸・ばね・ブレーキ
            │ ○    ○ │        │ ○    ○ │      「乗り心地」と「安全」の心臓部
            └────────┘        └────────┘
```

| ブロック             | 中身                                                 | 誰が作るか                                           | コスト感（目安） |
| -------------------- | ---------------------------------------------------- | ---------------------------------------------------- | ---------------- |
| **車体（構体）**     | アルミ合金の押出形材、またはステンレス鋼板           | 車両メーカー本体（唯一の内製の主戦場）               | 2〜3割           |
| **台車**             | 枠、車輪、車軸、軸受、空気ばね                       | 車両メーカーが内製することが多い。軸受はNSK・NTNなど | 1〜2割           |
| **駆動系（電気品）** | パンタグラフ、主変圧器、**VVVFインバータ**、主電動機 | 三菱電機、東芝、日立、東洋電機製造、富士電機         | **3割前後**      |
| **ブレーキ・空気系** | 空気圧縮機、電空変換、ブレーキ制御                   | ナブテスコ、三菱電機                                 | 1割前後          |
| **内装・艤装**       | 座席、床、内張り、空調、ドア、案内表示、トイレ       | 内装専業・空調メーカー（三菱電機、東芝キヤリアなど） | 2割前後          |

> ポイント：**車両メーカーの粗利の源泉は「箱と台車」しかない**。
> 一番付加価値の高い駆動系は電機メーカーの領分で、
> 日立・東芝・三菱電機のような総合電機がここを押さえている。
> 「車両メーカー」と「電機メーカー」の力関係は、この図の通り。
> → [総合電機](../../03_電機・電子部品/01_総合電機/README.md)、[モーター](../15_モーター/README.md)

### 2-1. 車体材料：アルミかステンレスか

日本の通勤電車は、1980年代までは普通鋼（さびる鉄）だったが、いまはほぼ二択になっている。

| 材料                           | 長所                                                                                   | 短所                             | 主な採用                                 |
| ------------------------------ | -------------------------------------------------------------------------------------- | -------------------------------- | ---------------------------------------- |
| **アルミ合金**（押出形材）     | 軽い。大型の中空形材を押し出して溶接するので**部品点数が減る**。断面設計の自由度が高い | 材料単価が高い。溶接に熟練が要る | 日立 `A-train`、近畿車輛、新幹線の多く   |
| **ステンレス鋼**（レーザ溶接） | さびない＝**塗装が不要で保守費が安い**。材料が比較的安い                               | アルミより重い                   | 総合車両製作所 `sustina`、川崎車両の一部 |

「アルミは軽いから電気代が安い」「ステンレスは塗らなくていいから30年の保守が安い」──
どちらを選ぶかは**車両の値段ではなく、30年使ったときの総費用（ライフサイクルコスト）**で決まる。
→ 材料側の話は [アルミ](../../11_資源・エネルギー・鉄鋼金属/11_アルミ/README.md)、[鉄鋼](../../11_資源・エネルギー・鉄鋼金属/09_鉄鋼/README.md)

### 2-2. 駆動系：VVVFインバータが主役

**VVVF（可変電圧可変周波数）インバータ** ＝ 架線からもらった電気を、
モータを回すのにちょうどいい電圧と周波数に作り変える装置。ひとことで言えば「電車のアクセル」。

```
【電車が走る仕組み（直流1500V区間の例）】

 架線 1500V ──▶ パンタグラフ ──▶ 断流器 ──▶ VVVFインバータ ──▶ 主電動機 ──▶ 歯車 ──▶ 車輪
                (集電)                        (直流→三相交流に変換)   (誘導 or 同期)   (減速)

 ブレーキ時は逆向き：車輪 ──▶ モータ（発電機として働く）──▶ インバータ ──▶ 架線へ返す
                                               ▲ これが「回生ブレーキ」。省エネの核心
```

- 1990年代以降、**直流モータ → 交流誘導モータ + VVVF** への置換が進み、消費電力が大きく下がった
- 近年は **PMSM（永久磁石同期電動機）** の採用が増え、さらに効率が上がっている
- パワー半導体が Si（シリコン）から **SiC（炭化ケイ素）** に替わると装置が小さく軽くなり、
  電力消費もさらに下がる。JR東日本や東京メトロなどが採用を広げている
  → [半導体・先端半導体](../../01_注目テーマ/02_半導体・先端半導体/README.md)、[モーター](../15_モーター/README.md)

### 2-3. 台車：地味だが「安全」そのもの

台車＝車輪・車軸・軸受・ばね・ブレーキをひとまとめにした走り装置。1両に2台つく。

- **乗り心地**（空気ばねの設計）と **脱線しにくさ**（曲線での車輪とレールの当たり方）を決める
- 2017年の新幹線のぞみ台車き裂事案以降、台車枠の製造管理と検査は大幅に厳格化された
- 軸受は玉軸受・ころ軸受の世界 → [ベアリング](../10_ベアリング/README.md)

## 3. 作る順番（工程フロー）

```
【鉄道車両の製造フロー】

 ①仕様打合せ・設計      ②材料調達        ③構体組立        ④艤装
 鉄道会社と数百ページ     アルミ形材       溶接で「箱」を    配線・配管・空調・
 の仕様書を詰める  ──▶  ステンレス鋼板 ──▶ 作る          ──▶ 内装・座席を
 （6か月〜2年）          電気品を発注      （塗装 or 無塗装）   ひたすら取り付ける
                                                              ▲ 人手が最も要る工程
                              │
                              ▼
 ⑤台車製作・組み合わせ  ⑥各種試験        ⑦出荷・甲種輸送   ⑧現地試運転・引渡し
 台車の上に車体を       静止試験、        貨物列車や船で    実際の線路で走らせ、
 載せる（車体載せ） ──▶ 走行試験      ──▶ 現地へ運ぶ   ──▶ 鉄道会社が検査して受領
                        （構内試験線）    （深夜に走る）      ▲ ここで初めて売上計上
```

工程を見ると分かるのは、**「④艤装」が全体の時間と人手の半分近くを食う**ということ。
配線もパネルもドアも、案件ごとに寸法と仕様が違うので、ロボット化が効きにくい。
自動車のようにラインで流せず、**熟練工の手作業に依存する**のはこのためだ。
→ ロボット化の限界という意味では [産業用ロボット](../09_産業用ロボット/README.md) の対極にある

| 工程                   | 期間の目安           | 自動化のしやすさ        |
| ---------------------- | -------------------- | ----------------------- |
| 設計・仕様調整         | 6か月〜2年           | ✕（顧客との擦り合わせ） |
| 構体（溶接・接合）     | 数週間／両           | △（溶接ロボットは入る） |
| **艤装（配線・内装）** | **数週間〜／両**     | **✕（人手勝負）**       |
| 試験                   | 数週間〜数か月／編成 | △                       |
| 甲種輸送・現地試運転   | 数週間〜数か月       | ✕                       |

受注から引渡しまで、通常 **2〜4年**。新形式や海外案件なら5年以上かかることもある。
この「長い納期」が、次のノートで扱う受注残（バックログ）という経営指標を重要にする。
→ [③ 需要の構造](03_需要の構造と受注産業の宿命.md)

## 4. 値段の感覚：1両いくら、1編成いくら

公表資料が少ない世界なので、**鉄道会社の設備投資リリースや報道からの推計レンジ**として押さえる。

| 車両種別                      | 1両あたり                | 1編成あたり      | 備考                                     |
| ----------------------------- | ------------------------ | ---------------- | ---------------------------------------- |
| 通勤型電車（ステンレス4ドア） | **1億円前後**            | 10両で10億円前後 | 量産効果が出る帯。報道・推計ベース       |
| 特急型電車                    | 2億円前後                | 8両で15〜20億円  | 内装・座席が高い                         |
| 新幹線車両                    | **2.7〜4.5億円**（推計） | 16両で40〜60億円 | 台車・高速対応・防音で高い               |
| 気動車・ハイブリッド車        | 2〜3億円                 | —                | エンジン＋蓄電池を積む分高い             |
| 路面電車（LRV）               | 3〜4億円                 | —                | 低床化のため台車が特殊。両数が少なく割高 |

> なぜ通勤電車が「1両1億円」で止まるのか：
> **同一形式を100両単位で作れるから**。逆にLRVや事業用車が高いのは、
> 数両しか作らないのに設計費を全部そこに乗せるしかないから。
> 「両数が多い＝安い」という関係が、この産業ではほぼそのまま価格になる。

日本国内の生産規模は、日本鉄道車輌工業会（JARi）の集計で
**2025年度の実生産 1,161両**（2024年度 1,239両に対し 93.7%）。
内訳は JRグループ向け 464両、公営・民鉄向け 619両、輸出 78両。
車種別では電車 1,059両が圧倒的で、気動車39両、電気機関車34両、貨車28両。

```
【2025年度 国内生産 1,161両の内訳】（JARi 集計）

 需要先別   JR      ■■■■■■■■■■■■■■■■  464両
            公営・民鉄 ■■■■■■■■■■■■■■■■■■■■■  619両
            輸出     ■■■                  78両

 車種別     電車    ■■■■■■■■■■■■■■■■■■■■■■■■■■■■■  1,059両（91%）
            気動車  ■                      39両
            電機    ■                      34両
            貨車    ■                      28両
       ▲ 日本の「鉄道車両工業」＝実質「電車工業」
```

注意点：この数字は**日本国内の工場で作った両数**。
日立の英国工場や川崎車両の米国工場で作った分は入らない。
つまり **国内統計だけを見ると日本メーカーの実力を過小評価する**。
→ 海外の話は [② 市場と競争](02_市場と競争_世界3強とシステム輸出.md)

## 5. 日本の特殊事情：鉄道会社の子会社が作る

世界的に見て日本が特異なのは、**車両を買う側（鉄道会社）が車両メーカーを子会社に持っている**こと。

| メーカー                     | 資本の系列                           | 主な供給先                             | 性格                                     |
| ---------------------------- | ------------------------------------ | -------------------------------------- | ---------------------------------------- |
| **総合車両製作所（J-TREC）** | JR東日本の子会社（旧・東急車輛製造） | JR東日本、東急、私鉄、海外都市鉄道     | 横浜・新津の2拠点。`sustina`             |
| **日本車輌製造**             | JR東海が筆頭株主                     | JR東海（N700S）、私鉄、輸出            | 新幹線と鉄道以外（建設機械・橋梁）も持つ |
| **日立製作所**               | 独立（総合電機）                     | JR各社、海外（英国・イタリア・米国等） | 車両＋信号＋保守の総合。最大手           |
| **川崎車両**                 | 川崎重工業の分社                     | JR西日本、ニューヨーク市交通局ほか     | 海外都市鉄道に強い。`efSET`              |
| **近畿車輛**                 | 近鉄グループ                         | 近鉄、JR、米国LRV                      | LRV・輸出に特色                          |

なぜこうなったのか。理由は3つある。

1. **発注が読めないから**：鉄道会社の設備投資は年ごとに上下する。
   系列メーカーを持っていれば、自社の更新計画に合わせて工場の仕事量を平準化できる
2. **仕様を作り込みたいから**：日本の鉄道会社は車両の細部まで自社で設計思想を持つ。
   子会社なら擦り合わせのコストが低く、ノウハウが外に出ない
3. **内製で原価を下げたいから**：JR東日本は自社の新津車両製作所で E231 系などを大量生産し、
   1両あたりの価格を大きく下げた（後に J-TREC に統合）

```
【日本型】                          【欧米型】
 鉄道会社 ───（親会社）──▶ 車両メーカー    鉄道会社 ───（入札）──▶ 独立系メーカー
   JR東日本 ──▶ 総合車両製作所                発注者は仕様を決めて公開入札
   JR東海   ──▶ 日本車輌製造                  メーカーは価格と性能で競う
     ▲ 供給が安定／仕様の作り込みが深い          ▲ 価格競争が働く／メーカーは規模を追える
     ▼ 系列外メーカーは商機が限られる            ▼ 発注ロットが大きく、巨大企業が有利
```

この構造の帰結：
**日本メーカーは国内では「守られている」が、その分だけ規模が小さい。**
だから世界市場に出ると、CRRC・アルストム・シーメンスという桁違いの相手と戦うことになる。
→ [② 市場と競争](02_市場と競争_世界3強とシステム輸出.md)

## 6. 30年使うことを前提に作る

鉄道車両は買ったら **30年前後**使う（国内の目安。私鉄では40年超も珍しくない）。
これはメーカーの作り方に直接影響する。

- **部品の長期供給義務**：30年後もその電子基板を供給できるか。半導体の生産中止が現実的なリスク
- **中間更新（リニューアル）**：15年前後で内装・電気品を入れ替える工事が入る。これもメーカーの仕事
- **保守を売る**：車両を売って終わりではなく、**30年分の保守契約とセットで売る**のが今の標準
  （英国では「車両＋保守◯年」でまとめて契約するのが普通。日立の英国案件がまさにこれ）

```
【鉄道車両の一生（30年モデル）】

 0年      5年        15年              25年        30年
 ├────────┼──────────┼─────────────────┼───────────┤
 新造     初回の重要部検査  中間更新（リニューアル）  廃車前提の延命    廃車・解体
          ▲ 数年ごとの      ▲ 内装・電気品を交換     ▲ 部品取り        ▲ 一部は
            検査は鉄道会社     メーカーの仕事           共食い整備          地方私鉄へ譲渡
            の車両基地で                                                   海外へ売却
```

> ポイント：**「売って終わり」から「30年面倒を見る」へ**というのが、
> この20年で世界の鉄道車両ビジネスに起きた最大の変化。
> 保守は毎年安定した収入になるうえ、故障データが次の設計に効く。
> 詳しくは [② 市場と競争](02_市場と競争_世界3強とシステム輸出.md) の「システム輸出」の章へ。

## 7. 用語メモ

| 用語                            | 意味                                                                               |
| ------------------------------- | ---------------------------------------------------------------------------------- |
| **構体（こうたい）**            | 車両の「箱」の部分。床・側面・屋根・妻面を溶接で組んだもの                         |
| **艤装（ぎそう）**              | 構体に配線・配管・内装・機器を取り付ける工程。元は造船用語                         |
