# ③ 需要の構造と受注産業の宿命

このノートで分かること：**鉄道車両メーカーの売上は、自分では1円も作れない**。
すべては鉄道会社（と政府）が「今年いくら設備投資するか」で決まる。
その完全な受注産業としての構造と、国内需要が縮む中でどこに活路があるのかを見る。

> ポイント：自動車メーカーは値下げすれば台数を増やせる。
> **鉄道車両メーカーは値下げしても両数は増えない。**
> 必要な両数は、線路の長さと運行本数で物理的に決まっているから。

## 1. 需要はどこから来るのか

鉄道車両の需要は、大きく3つしかない。

```
【鉄道車両の需要の3つの源泉】

 ①更新需要（リプレース）        ②新線・輸送力増強         ③海外
 古くなった車両を置き換える      新しい路線を作る、          新興国の都市鉄道、
 ＝ 保有両数 ÷ 耐用年数         編成を長くする              欧米の老朽車更新
      │                           │                           │
      ▼                           ▼                           ▼
 日本のほぼ全部（8〜9割）      日本ではほぼ消滅          日本メーカーの成長領域
 「毎年◯両ずつ」の             （延伸は年に数件）         ただし制度の壁が厚い
  ほぼ一定の需要
```

日本国内では **①更新需要が圧倒的**。人口が減り、新線がほとんど作られないので、
「増える」需要はもうない。あるのは「古くなったから替える」需要だけだ。

| 需要の種類       | 日本での比重（目安）                      | 性格                                     |
| ---------------- | ----------------------------------------- | ---------------------------------------- |
| 更新（置き換え） | **8〜9割**                                | 保有両数と車齢で計算できる。予測しやすい |
| 新線・増備       | 1割前後                                   | 延伸開業や空港アクセスなど。案件が単発   |
| 輸出             | 生産両数の7%程度（2025年度78両／1,161両） | 国内工場ベース。海外現地生産は別         |

## 2. 更新需要の算数：「30年に1回」が全部を決める

鉄道車両の法定耐用年数は税法上13年だが、**実際の使用年数は30年前後**（国内の目安）。
私鉄では40年、50年使う例も珍しくない。ここから需要の総量が計算できる。

```
【更新需要のかんたんな算数】

 年間の更新需要（両） ≒ 全国の保有両数 ÷ 平均使用年数

 日本の鉄道車両の保有は概ね 5万両台（JR＋民鉄＋公営、推計）
   5万両 ÷ 30年 ＝ 年およそ 1,600〜1,700両

 実際の国内生産（2025年度）＝ 1,161両
   ▲ 計算値より少ない＝更新が先送りされている／使用年数が延びている
     もしくは改修（リニューアル）で延命して新造を減らしている
```

> ポイント：この式の分子（保有両数）は**輸送需要が減れば減る**。
> 人口減で運行本数が減れば、必要な車両数も減る。
> つまり日本の更新需要は、**緩やかだが確実に細っていく**。
> 一方で分母（使用年数）を鉄道会社が延ばせば、需要はさらに減る。
> **メーカーにとって最悪のシナリオは「鉄道会社が車両を長く使う」こと**。

### 2-1. 実際の生産両数の推移

| 年度         | 国内実生産  | 前年度比  | 備考                                  |
| ------------ | ----------- | --------- | ------------------------------------- |
| 2024年度     | 1,239両     | —         | JARi 集計                             |
| **2025年度** | **1,161両** | **93.7%** | JR 464両／公営・民鉄 619両／輸出 78両 |

内訳の特徴（2025年度）：

- **電車 1,059両（91%）** ── 日本の鉄道車両工業は実質「電車工業」
- 気動車39両、電気機関車34両、貨車28両。機関車・貨車はごく少ない
- 貨車が少ないのは、**日本の鉄道貨物が全輸送量のごく一部**だから。
  米国が機関車と貨車の国（Wabtec が強い理由）であるのとは対照的
  → [陸運・トラック](../../13_運輸・物流/06_陸運・トラック/README.md)

## 3. 受注産業であることの意味

### 3-1. 売上が「相手の予算」で決まる

鉄道会社の設備投資は、**運賃収入 → 経常利益 → 設備投資予算** という順番で決まる。
そして運賃は認可制で、簡単には上げられない。つまり──

```
【鉄道車両メーカーの売上が決まるまで】

 乗客数（人口・通勤需要）
    │
    ▼
 鉄道会社の運賃収入 ──（運賃は認可制。自由に上げられない）
    │
    ▼
 鉄道会社の利益
    │
    ▼
 設備投資予算（安全対策・駅改良・ホームドア・システム更新 と 車両新造 の取り合い）
    │                                  ▲ 車両は「後回しにできる」枠の筆頭
    ▼
 車両発注 ──▶ メーカーの受注残 ──（2〜4年後）──▶ メーカーの売上
                                    ▲ 数年遅れて効いてくる
```

ここに2つの怖さがある。

1. **車両新造は「削りやすい」枠**：ホームドア設置や耐震補強は法令・社会的要請で削れない。
   一方「車両はあと3年使えばいい」で先送りできる。**不況時に真っ先に削られる**
2. **タイムラグ**：今年の受注が売上になるのは2〜4年後。
   だから鉄道会社の設備投資が回復しても、メーカーの業績回復は数年遅れる（逆も同じ）

### 3-2. 受注残（バックログ）という生命線

受注残＝契約済みでまだ引き渡していない仕事。この産業では**最も重要な経営指標**。

| 指標             | 意味                   | 見方                                                         |
| ---------------- | ---------------------- | ------------------------------------------------------------ |
| **受注残高**     | 手持ち工事の総額       | 「売上の何年分か」で見る。2〜3年分あれば当面の工場稼働は安泰 |
| **Book-to-bill** | 受注 ÷ 売上            | 1超なら受注残が増えている。アルストムは2025/26年度に1.4      |
| **工場の稼働率** | ラインが埋まっているか | 空くと固定費（人件費・設備）が丸ごと赤字になる               |

> **受注残が切れると工場が止まる。** これが受注産業の宿命。
> 日立が英国工場の仕事の谷を埋めるために次の案件を必死で取りに行くのも、
> 川崎車両がニューヨーク案件を連続受注するのも、
> 「腕のいい溶接工と艤装工を手放すと二度と戻ってこない」という現実があるから。
> 一度失った熟練工は、数年では育たない。

### 3-3. 固定価格契約というリスク

長期契約の多くは**固定価格**（作る前に値段が決まる）。納入は2〜4年後。
その間に何が起きるか。

| 上がるもの         | 影響                                                     |
| ------------------ | -------------------------------------------------------- |
| アルミ・鋼材の価格 | 車体コストに直撃。数年で数割動くことがある               |
| 賃金・外注費       | 艤装は人手勝負なので人件費上昇がそのまま効く             |
| 電子部品・半導体   | 調達難で代替設計が必要になると、設計費が追加で発生       |
| 為替               | 海外案件では現地通貨建て。円高になれば円換算の利益が縮む |

一方で、値上げは基本的にできない。
**受注時の見積もりを外すと、数年後に一括で損失が出る**。
アルストムが2025/26年度に「受注は過去最高なのに採算が計画に届かなかった」のも、
日本車輌製造が過去に米国案件で大きな損失を計上したのも、この構造が原因。

```
【固定価格 × 長納期 のリスク構造】

  受注（価格確定）                      引渡し（売上計上）
     │                                      │
     ├──── 2〜4年 ────────────────┤
     │   材料費↑  人件費↑  為替変動  調達難   │
     │   ▲ これらは全部メーカー側の持ち出し   │
     ▼                                      ▼
  「安く取る」ほど後で苦しくなる      赤字案件が一気に表面化
```

## 4. 周辺市場：車両の外に稼ぎ場所がある

車両そのものの需要が細るなら、その周りを取る。これが各社の共通戦略。

| 周辺市場                     | 中身                                           | 需要の性格                         | 主なプレイヤー                                   |
| ---------------------------- | ---------------------------------------------- | ---------------------------------- | ------------------------------------------------ |
| **信号・保安**               | ATC、CBTC、連動装置、踏切                      | 20〜25年で更新。安全投資は削れない | 日立、京三製作所、大同信号、日本信号、シーメンス |
| **運行管理・旅客案内**       | ダイヤ作成、指令システム、案内表示             | ソフトの更新サイクルは短い         | 日立、東芝、日本信号                             |
| **保守・部品供給**           | 定期検査、部品、改修                           | **30年間ずっと**。安定収入         | 車両を納めたメーカー                             |
| **中間更新（リニューアル）** | 内装・電機品の入れ替え                         | 車齢15年前後                       | 車両メーカー、鉄道会社の自社工場                 |
| **軌道・架線・変電**         | レール、まくらぎ、電化設備                     | 土木・電気工事の世界               | 建設会社、電設会社                               |
| **蓄電池・脱炭素対応**       | 蓄電池車、水素燃料電池車、非電化区間の電化代替 | これからの成長領域                 | 日立、東芝、JR東日本                             |

```
【1本の路線でお金が落ちる場所】

 ┌──────────────────────────────────────────────────┐
 │ 土木（トンネル・高架）      ← 建設会社。金額は最大だが1回きり  │
 │ 軌道（レール・まくらぎ）     ← 数十年で更新                    │
 │ 電力（変電所・架線）        ← 20〜30年で更新                  │
 │ 信号・通信                 ← 20〜25年で更新。利益率が高い ★   │
 │ 運行管理システム            ← 10〜15年で更新 ★               │
 │ 車両                       ← 30年で更新。金額は大きいが薄利   │
 │ 保守・部品                 ← 毎年ずっと ★★                  │
 └──────────────────────────────────────────────────┘
   ★ ＝ 車両メーカーが取りに行っている領域
```

> ポイント：**車両は「30年に1回しか売れない商品」**。
> それだけで会社を回すのは無理がある。
> だから信号（20年更新）と保守（毎年）を押さえて、収入を平らにする。
> 日立が信号事業を買い、保守契約込みで売るのはこの理屈。
> → [② 市場と競争](02_市場と競争_世界3強とシステム輸出.md)

## 5. 海外の都市鉄道需要：唯一の「増える」市場

国内が更新需要だけなら、増える需要は海外にしかない。

| 地域                   | 需要の中身                                         | 日本勢の立ち位置                                                     |
| ---------------------- | -------------------------------------------------- | -------------------------------------------------------------------- |
| **東南アジア・インド** | 都市化に伴う地下鉄・モノレール新設、高速鉄道       | ODA（円借款）とセットで日本方式を売り込む。インド高速鉄道が象徴      |
| **北米**               | 老朽車両の更新（地下鉄・通勤鉄道）。新線は少ない   | 川崎車両（NY）、日立（メリーランド等）。Buy America 対応が必須       |
| **欧州**               | 老朽更新＋高速化。運行会社の民営化で発注主体が多様 | 日立が英国・イタリアで現地化。大陸欧州はアルストム・シーメンスの牙城 |
| **中東・アフリカ**     | 新設（サウジ、エジプト等）。国家プロジェクト型     | 欧州勢と中国勢が主戦。日本勢は限定的                                 |
| **中国**               | 世界最大だが、事実上 CRRC の独占                   | 実質、参入不可                                                       |

日本政府も **「インフラシステム海外展開戦略2025」** 等に基づいて後押ししているが、
鉄道輸出の難しさは「車両を売る話ではない」ところにある。

```
【鉄道システム輸出に必要な4点セット】

 ①技術（車両・信号）   ②資金（円借款・輸出信用）  ③運営ノウハウ  ④現地雇用
    メーカー              JICA／JBIC／商社           鉄道会社        現地工場
       ▲                     ▲                        ▲               ▲
       └── この4つを揃えた「チーム」でないと提案すらできない ──┘

 だから鉄道輸出は「メーカー vs メーカー」ではなく「国 vs 国」の競争になる
```

直近の案件（台湾高鐵、インド高速鉄道、フィリピン都市鉄道）は
[④ 直近トピック](04_直近トピック_2026.md) の第6章にまとめた。

> 教訓：**中国に高速鉄道案件で競り負けた過去（インドネシア）**が示すのは、
> 価格と融資条件で勝負されると日本は不利だということ。
> 日本の売り文句は「開業以来の無事故」「定時性」「保守の仕組みごと移植する」という
> **運行品質のパッケージ**であって、車両の値段ではない。

## 6. 国内市場：縮むが、ゼロにはならない

悲観だけではない。国内需要が完全には消えない理由が3つある。

| 支える要因                 | 中身                                                                                                                                                 |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **安全・バリアフリー投資** | ホームドア、踏切保安、耐震。法令・社会的要請で削れない。車両側も車椅子スペース等で改造需要                                                           |
| **省エネ・脱炭素**         | 旧型車を新型に替えると消費電力が数割下がる。カーボンニュートラル目標が更新の後押しになる → [脱炭素・GX](../../01_注目テーマ/05_脱炭素・GX/README.md) |
| **省人化**                 | 運転士・車掌の人手不足。ワンマン運転対応、自動運転（GoA2.5〜）対応の車両・地上設備への投資                                                           |

2026年度の鉄道各社の設備投資計画を見ても、車両新造は着実に続いている
（各社の具体的な計画は [④ 直近トピック](04_直近トピック_2026.md) の第7章に一覧した）。

> ポイント：**1社あたりの車両投資は数十億円**。
> これが100社弱分積み上がって、年1,000両強の市場になっている。
> 巨大な単一発注はほとんどなく、**細かい案件の積み上げ**という点でも、日本市場は特殊。

## 7. まとめ：この産業をひとことで

```
【鉄道車両メーカーの損益構造】

 売上 ＝ 受注残の取り崩し（2〜4年前の契約） ＋ 保守・部品（毎年）
 原価 ＝ 購入部品（電気品・内装で5〜6割） ＋ 材料（アルミ・鋼材） ＋ 直接工の人件費
 固定費 ＝ 工場・熟練工・設計部隊
        ▲ 受注が途切れても減らせない。減らしたら二度と戻らない

 → だから経営の本質は「受注残を切らさないこと」に尽きる
 → 利益の本質は「見積もりを外さないこと」に尽きる
```

この3点に集約される。**需要は外生的**（鉄道会社の設備投資がすべて）、
**量産効果が効かない**（個別受注。標準車体で設計費を薄めるのが唯一の対策）、
**稼ぐ場所が移った**（車両単体では薄利。信号・保守・システム一括でようやく利益が出る）。

## 8. 用語メモ

| 用語                             | 意味                                                                             |
| -------------------------------- | -------------------------------------------------------------------------------- |
| **更新需要（リプレース）**       | 古くなった車両を同数で置き換える需要。成長ではなく維持の需要                     |
| **耐用年数**                     | 税法上は13年だが、鉄道車両の実使用は30年前後（国内の目安）                       |
| **受注残（バックログ）**         | 契約済み・未引渡しの仕事の金額。売上の何年分あるかで工場の先行きが読める         |
| **固定価格契約**                 | 契約時に金額を確定する方式。材料費・人件費の上昇はメーカー負担になる             |
| **甲種輸送**                     | 完成車両を機関車が牽引して納入先まで運ぶこと                                     |
| **ワンマン運転**                 | 車掌を乗せず運転士1人で運行すること。ホームの監視カメラや車両側の設備が要る      |
| **GoA（自動化レベル）**          | 列車運転の自動化段階。GoA1（手動）〜GoA4（無人運転）。都市新交通は GoA4 が多い   |
| **ODA／円借款**                  | 政府開発援助。鉄道システム輸出では JICA の円借款が案件成立の前提になることが多い |
| **インフラシステム海外展開戦略** | 日本政府のインフラ輸出方針。鉄道はその主要分野の一つ                             |
| **ライフサイクルコスト（LCC）**  | 購入費＋運用費＋保守費＋更新費の総額。発注者が本当に見ている数字                 |
