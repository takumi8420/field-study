# 直近トピック（2026年9月時点）

報道・公表資料ベースの整理。数値は一次情報（防衛省・経産省・会計検査院・各社IR）で
裏を取ること。確定した制度は「閣議決定」「締結」、まだ動くものは「報じられる」
「見通し」と書き分けている。

2026年のこの業界は、**民需と防需の両方が同時に強気**という、めったに起きない局面にある。
ただし理由はまったく別で、民需は「積み上がった受注残をどう捌くか」、
防需は「増えた予算をどう使い切り、国内産業に落とすか」が論点になっている。

```
【2026年の見取り図】

  民需 ── 需要は史上最高水準（受注残10年分） ── 供給が追いつかない
                                              ▲ 生産レートがすべて

  防需 ── 予算がGDP比2%へ ── 輸出の壁も撤廃 ── 供給能力と財源が課題
                                              ▲ 撤退で痩せた基盤が戻るか
```

## 1. 防衛費：GDP比2%を2年前倒しで達成、2026年度予算は9兆円台へ

| 時点 | 内容 |
| --- | --- |
| 2022年12月 | 安保3文書。2027年度に GDP 比2%到達を目標、5年で総額43兆円程度 |
| 2025年度 | 当初＋補正で防衛費を積み、**GDP 比2%に到達。目標を2年前倒しで達成**と報じられる |
| 2026年度予算案 | 防衛関係費 **9兆353億円**。**初めて9兆円を突破**したと報じられる |
| 2026年4月 | 海上保安庁・公共インフラ等を含む防衛関連費は **約10兆6,000億円、GDP 比1.9%**と集計（報道） |

読むときの注意が2つある。

- **定義を確認する**。防衛省の予算（狭義の防衛関係費）か、NATO 基準に寄せた
  「防衛関連費」（海保・インフラ・研究開発を含む広義）かで数字が1兆円以上変わる
- **補正予算を含むか**。単年度の当初予算だけを見ると、2%到達の説明がつかない

財源は依然として論点で、**安定財源のめどが立っていないという慎重論**が報じられている。
増税・国債・歳出改革の配分が今後の政治日程に乗る。

## 2. 防衛装備移転三原則：5類型を撤廃（2026年4月21日 閣議決定）

**2026年4月21日、政府は防衛装備移転三原則の運用指針を改定する閣議決定を行った**と
報じられる。産業にとってこれが今年最大の制度変更である。

| 項目 | 改定前 | **改定後（2026年4月〜）** |
| --- | --- | --- |
| 完成品の移転 | **5類型に限定**（救難・輸送・警戒・監視・掃海） | **5類型を撤廃**。護衛艦・戦闘機・ミサイルを含む完成品全般が条件付きで移転可能 |
| 移転先 | 協定締結国 | 同じく **防衛装備品・技術移転協定の締結国に限定**（2026年4月時点で17か国とされる） |
| 対外投資規制 | 厳格に制限 | M&A・海外投資の制限を緩和する方向と報じられる |

```
【「量が出ない」という積年の病に対する処方箋】

  従来： 国内需要のみ ──▶ 少量 ──▶ 単価高い ──▶ 買える数が減る ──▶ 撤退
                                     ▲___________________________|

  改定後の狙い： 輸出が加わる ──▶ 数量増 ──▶ 量産効果で単価低下
                                 ──▶ 国内調達も楽になる ──▶ 基盤が維持される

  ※ ただし実際に売れるかは別問題。価格競争力・オフセット（相手国への生産移管等の
     見返り）・長期の維持整備支援で、日本企業は経験の薄い領域に出ることになる
```

制度が変わっただけで輸出が増えるわけではない。**受注してから納めるまでの維持整備を
何十年も引き受ける体制**を持てるかが、実際の勝負どころになる。

## 3. GCAP：約1兆円の開発契約が動き出した

日英伊の次期戦闘機計画（2035年配備目標）が、2026年に**実務フェーズへ**入った。

| 時点 | 動き |
| --- | --- |
| 2026年4月 | 政府間機関 **GIGO** と、日英伊3社の合弁 **Edgewing**（三菱重工＋BAEシステムズ＋レオナルド）の間で最初の契約が締結されたと報じられる |
| **2026年7月3日** | **約46億ポンド（約9,900億円）規模、2027年末までを対象とする複数年開発契約**を締結と報じられる |
| 2026年7月 | ファンボロー航空ショーで**大型ディスプレイを備えたコックピットの最新モックアップ**を公開。**カナダが初のオブザーバー国**として参加すると発表 |
| 継続中 | 英・伊は取得単価低減のため参加国拡大に前向き。**サウジアラビアなどが候補**と各種報道 |

> 押さえどころ：**参加国が増えると単価は下がるが、意思決定は遅くなる**。
> 日本は2035年という配備目標を動かせないため、「拡大による安さ」と「納期」の
> トレードオフが、今後2〜3年の最大の争点になる。

## 4. 重工3社の決算：防衛と民間エンジンで過去最高

**2026年3月期（2025年度）は、三菱重工・川崎重工・IHI の3社そろって最高益圏**と
報じられた。牽引したのは防衛と航空エンジン、そして原子力である。

| 会社 | 報じられた内容 |
| --- | --- |
| **三菱重工業** | 純利益・事業利益などが過去最高 |
| **川崎重工業** | 売上収益・純利益・受注高がそれぞれ過去最高 |
| **IHI** | **受注高が過去最高の約1兆8,500億円**。民間エンジン事業が想定以上に伸び、受注高・売上収益・営業利益・税引前利益・当期利益がすべて過去最高 |
| 3社合計（防衛） | **防衛関連事業の受注残高は2026年3月期末で計6兆2,500億円、前期末比15%増**。5類型撤廃でさらに積み増しの見方 |

```
【なぜIHIが目立つのか（事業ポートフォリオの差）】

  機体構造が主  ─────────────────────▶ エンジン部品が主
  （三菱重工・川崎重工・SUBARU）              （IHI）
   売上＝ボーイングの生産レートに連動          売上＝既に飛んでいる機数に連動
   レートが上がらないと伸びない                補用部品が積み上がる
   ▲ 増産の遅れがそのまま効く                  ▲ 需要が景気に対して粘り強い
```

これは [② 儲け方とアフターマーケット](02_儲け方とアフターマーケット.md) で書いた
「アフターマーケットが利益の本体」という構造が、決算の差として表面化した例である。

## 5. ボーイング：生産上限が外れ、月産47機の運転へ

民需側の最大のニュースは、**ボーイングの 737 増産が制度的な足かせを外した**こと。

| 時点 | 内容 |
| --- | --- |
| 2024年1月 | ドア部品脱落事案。FAA が 737 の月産を **38機**に制限 |
| 2025年10月 | FAA が上限を **42機**へ引き上げ |
| **2026年3月** | **一律の上限（キャップ）を撤廃**し、実績に応じた監視方式（performance-based oversight）へ移行したと報じられる |
| **2026年5〜6月** | FAA のキャップストーン審査を通過し、**月産47機の水準でラインを運転**と CEO が説明（報道） |
| 目標 | 経営陣は **52機**、将来的に **63機**を掲げる |
| 構造面 | **スピリット・エアロシステムズの買収が完了**。737 機体構造の約7割を作っていた会社を内製化 |

受注残は依然として過去最高水準にある。

| 指標 | 数値 | 時点・出典 |
| --- | --- | --- |
| ボーイング 会社全体の受注残 | **約6,950億ドル**（民間機は6,100機超・約5,760億ドル） | 2026年第1四半期、同社発表 |
| ボーイング 民間機受注残 | 6,758機（うち737が4,819機） | 2026年5月末、Forecast International 集計 |
| 第1四半期の納入 | 143機、純受注 140機 | 2026年第1四半期、同社発表 |

```
【受注残10年分の意味】

  2026年に発注した航空会社  ──────────────────▶ 納入は2030年代半ば
                              ▲ この間の資材高・為替・賃上げは
                                原則としてメーカー側が負う

  だから業界ニュースで見るべきは「何機受注したか」ではなく
  「月産を何機まで上げられたか」。受注は既に10年分ある
```

## 7. 日本の民需：生産額は過去最高、完成機は2035年に再挑戦

- **2024年度の航空機生産額は前年度比22%増の約2兆619億円**（速報ベース）となり、
  2019年度以来5年ぶりに過去最高を更新、**初めて2兆円を超えた**と報じられる。
  SJAC 会報では 2024年度実績を **1兆9,867億円（前年比31.7%増）**とする集計もあり、
  速報／確報・集計区分で数字が動く点に注意
- 2025年度は **約2.3兆円**を超える見通しとも報じられる
- 増加の主因は **民間エンジン（新製＋補用部品）の伸長**と、安保3文書に基づく**防衛需要**
- 完成機については、経産省が2024年3月の産業構造審議会で
  **2035年以降をめどに複数社参画型で次世代機に再挑戦し、今後10年で官民合わせて
  5兆円規模を投資する**方向性を提示。三菱スペースジェット（MSJ）の
  「1社単独・型式証明で行き詰まった」反省を踏まえ、海外メーカーと組んで
  認証ノウハウを取りに行く設計になっている

## 8. 全体の構図（まとめ）

1. **民需は「需要不足」ではなく「供給不足」の局面**。受注残は10年分あり、
   業績を決めるのは受注数ではなく月産レート。ボーイングは FAA の上限撤廃と
   スピリット内製化で、ようやく増産の入口に立った
2. **その増産の恩恵は、機体構造よりエンジン部品に早く効く**。IHI の過去最高受注は
   アフターマーケット型の収益構造が効いた結果で、重工3社の明暗はここで分かれた
3. **防需は予算・制度の両面で歴史的な転換期**。GDP 比2%を2年前倒しで達成し、
   2026年4月には完成品輸出の5類型が撤廃された。重工3社の防衛受注残は6兆円台に乗った
4. **ただし「予算増＝国内産業の増収」ではない**。FMS（米国からの調達）への支出、
   撤退で痩せたサプライチェーンの供給能力、安定財源の不在という3つの制約が残る
5. **GCAP は日本の防衛産業にとって試金石**。初の本格的な国際共同開発であり、
   初めて「輸出を前提に設計される装備」でもある。参加国拡大（単価低減）と
   2035年という納期のどちらを取るかが、今後の焦点になる

## 用語集

| 用語 | 意味 |
| --- | --- |
| 防衛関係費 | 防衛省予算を中心とする狭義の防衛支出。NATO基準の安全保障関連経費とは集計範囲が異なる |
| 防衛装備移転三原則 | 日本から海外へ防衛装備を移転する際の基本方針と条件 |
| GCAP | 日本・英国・イタリアが2035年の配備を目指す次期戦闘機の共同開発計画 |
| FMS | 米国政府を通じて装備品を購入する有償軍事援助。価格や納期を日本側だけでは決めにくい |
| 受注残 | 契約済みだが、まだ売上として計上していない注文の金額や数量 |
| 月産レート | 航空機を1か月に何機生産するかを示す指標 |
| 補用部品 | 稼働中の航空機を整備・修理するために交換する部品 |
| 型式証明 | 航空機の設計が安全基準を満たすことを当局が認める承認 |
