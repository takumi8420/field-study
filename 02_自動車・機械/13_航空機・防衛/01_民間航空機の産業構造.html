航空機・防衛｜民間航空機の産業構造

自動車・機械航空機・防衛
あこのページの単語集用語に触れると意味を確認できます12語
複占（デュオポリー）エアフレームTier1RSP（リスク・シェアリング・パートナー）型式証明（TC）製造証明（PC）／耐空証明（AC）バックログ（受注残）生産レートデファラル単通路機／双通路機JAEC（日本航空機エンジン協会）COMAC

このノートで分かること：世界に旅客機メーカーが実質2社しかないのはなぜか。
その2社の下に、エンジン・装備品・機体構造の会社がどう並び、日本メーカーは
どこに、どんな契約形態で入っているのか。そして「10年分の受注残があるのに
増産できない」という、この産業だけの奇妙な状態がなぜ起きるのか。

結論を先に書くと、民間航空機産業は次の3つで説明できる。

①【複占】 100席超のジェット旅客機はボーイングとエアバスの2社だけ
②【分業】 機体・エンジン・装備品は別々の会社が作り、別々に認証を取る
③【認証】 型式証明という国の許可が、参入も増産も律速する

1. なぜ2社しか残らなかったのか（複占の経済学）

100席を超えるジェット旅客機を新規開発できるメーカーは、実質 ボーイング（米）と
エアバス（欧）の2社 しかない。これは談合の結果ではなく、費用構造からくる必然に近い。

要因 中身 効き方
開発費の巨大さ新型機1機種の開発に 1〜2兆円規模（787は当初見積もりを大幅超過したと報じられる）失敗すると会社が傾く
学習曲線同じ型を作り続けるほど1機あたり工数が下がる。初号機と200号機で工数が数分の1になる後発は原価で勝てない
回収期間の長さ開発開始から黒字化まで 20〜30年。1機種の寿命は50年に及ぶ資本の忍耐力が要る
認証コスト各国当局の型式証明。新規メーカーは実績ゼロから信頼を積む必要時間で殴られる
顧客の保守性航空会社は整備・訓練・部品在庫を機種ごとに持つ。機種を増やしたくない新規参入を嫌う

ポイント：この産業の参入障壁は「技術」より「時間と資本の耐久力」。
技術的に作れる国は増えたが、20年赤字に耐えて認証を取り切れる事業体が少ない。

挑戦者はいる。中国の COMAC（C919 が国内線で就航、C929 を開発中）、ブラジルの
エンブラエルとカナダ発の エアバスA220（旧ボンバルディアCシリーズ）は
100席前後のリージョナル・小型機で存在感がある。ただし「単通路の量産帯」で2社に
挑めているとは言いがたい。

2. 三層分業：機体・エンジン・装備品は別の会社

飛行機は「機体メーカーが全部作る」のではない。大きく3つの産業が並走している。
しかも航空会社は、機体とエンジンを 別々に選んで別々に買うことが多い。

【民間航空機の三層分業】

  ┌─ 機体（エアフレーム）─────────────────────────┐
  │  ボーイング / エアバス                                │
  │   └─ 機体構造 Tier1：三菱重工(主翼)、川崎重工(胴体)、SUBARU(中央翼)、    │
  │                      スピリット・エアロシステムズ、レオナルド 等          │
  └─────────────────────────────────────────┘
            ▲ 航空会社はここと契約           ▲ そして「別途」こことも契約
  ┌─ エンジン ────────────────────────────┐
  │  GEエアロスペース / RTX(プラット&ホイットニー) / ロールス・ロイス        │
  │   └─ 共同事業体：CFM(GE+サフラン)、IAE(P&W+MTU+JAEC)                  │
  │   └─ 日本勢：IHI、川崎重工、三菱重工（JAEC としてRSP参画）              │
  └─────────────────────────────────────────┘
  ┌─ 装備品（システム）──────────────────────────┐
  │  降着装置・油圧・電源・空調・航法・座席・内装・タイヤ                    │
  │  ハネウェル、コリンズ(RTX)、サフラン、住友精密、ナブテスコ、ジャムコ 等  │
  └─────────────────────────────────────────┘

この構造から出てくる実務上の含意は3つ。

  • 同じ機体でもエンジンが複数選べる（例：A320neo は CFM の LEAP と P&W の GTF）。
    つまりエンジン各社は機体1機種の中でさらに競争している
  • 機体メーカーの手元に残る付加価値は薄い。設計・最終組立・統合・販売が主で、
    部品点数の大半は外から買う（→ ② 儲け方とアフターマーケット）
  • どこか1社が止まると全体が止まる。代替供給者が認証込みで存在しないため、
    自動車のような「別のサプライヤーに切り替える」が効きにくい

3. リスクシェアリングパートナー（RSP）という契約形態

航空機産業に固有の言葉が RSP（リスク・シェアリング・パートナー）。
ふつうの下請けは「図面どおり作って納めて代金をもらう」が、RSP はそうではない。

項目 ふつうの受注生産 RSP（リスク分担）
開発費発注元が負担自分の持ち出し（数百億〜数千億円）
設計責任発注元担当部位は自分で設計・認証まで
代金納入時に払われる売れた機数に応じて後から回収
売れなかったら損は小さい投資が回収できない
売れたら加工賃だけ長期の分け前＋補修部品の売上
【RSP のキャッシュフロー（イメージ）】

 資金
  +│                                    ┌──────── 量産＋補修部品で回収
   │                                ┌───┘
  0├────────────────────┬───────────────────────▶ 年
   │  \                   /    初号機納入
  -│   \_______________ /
   │     開発費の持ち出し（5〜10年、赤字が続く）
        ▲ ここで機種が中止・不振になると全損に近い

日本の重工3社（三菱重工・川崎重工・IHI）と SUBARU は、この RSP としてボーイングの
プログラムに深く入っているのが最大の特徴。単なる部品屋ではなく「共同事業者」に近い。
逆に言えば、ボーイングの生産レートが下がると日本勢の売上も直撃される。

エンジン側では、日本勢は JAEC（日本航空機エンジン協会） という枠組みで参画する。
V2500（IAE）で日本側の分担は約23%、その後継の PW1100G-JM でも同程度とされる。
IHI は GE9X（777X 用）や Trent 系にも参画しており、民間エンジン部品は近年の
日本の航空機生産額を押し上げている主因になっている。

押さえどころ：日本の航空機産業は 「完成機を売る産業」ではなく「他人の完成機の
一部を作る産業」。だから業績は自社の努力より、ボーイング／エアバス／エンジン3社の
生産計画に強く左右される。

日本全体の規模感としては、2024年度の航空機生産額が前年度比22%増の約2兆619億円となり
初めて2兆円を超えた（速報ベース、SJAC集計として報じられる）。
SJAC 会報では 2024年度実績を 1兆9,867億円（前年比31.7%増）とする集計もあり、
速報／確報や集計区分で差が出るので、引用時は出典と時点をそろえること。

5. 型式証明：この産業の律速段階

型式証明（Type Certificate, TC） ＝ 「その設計の飛行機は安全基準を満たしている」と
国の航空当局が認める許可。米国は FAA、欧州は EASA、日本は国土交通省航空局（JCAB）。

【機体が売れるまでに必要な3つの承認】

 ① 型式証明（TC）      設計そのものの承認    ←── 数年〜10年かかる
        ↓
 ② 製造証明（PC）      その設計どおり量産できる体制の承認
        ↓
 ③ 耐空証明（AC）      個々の機体1機ごとの検査
        ↓
      引き渡し・運航
なぜ重いのか 中身
試験飛行の量数千時間の飛行試験、実機破壊試験、疲労試験。数年単位
書類の量設計根拠・解析・試験結果を当局に示す文書が膨大
当局との対話力基準の解釈を当局と詰める経験値そのものが資産。新興勢の最大の壁
相互承認の壁FAA の TC を取れば各国が追認しやすい。逆にそこを通らないと世界で売れない

日本が痛感したのがこの壁だった。三菱スペースジェット（MSJ、旧 MRJ）は
2008年の事業化決定から型式証明を取り切れず、2023年2月に開発中止となった。
技術ができなかったというより、「当局に安全を証明する仕事」の設計・体制・人材が
足りなかったというのが広く語られる総括である。

経産省は2024年3月の産業構造審議会で、2035年以降をめどに複数社参画型で次世代機に
再挑戦し、今後10年で官民合わせて5兆円規模を投資する方向性を示した（同省資料・報道）。
単独完成機ではなく、海外メーカーと組みながら認証ノウハウを取りに行く設計になっている。

6. 受注残10年：時間軸の異常さ

この産業を一言で特徴づけるなら 「受注残（バックログ）が10年分ある」。

指標 ボーイング エアバス
民間機 受注残6,758機（2026年5月末、Forecast International 集計）9,247機（2026年5月末、同）
会社全体の受注残約6,950億ドル（2026年第1四半期、同社発表。民間機は6,100機超・約5,760億ドル）―
年間納入（目標・実績）2026年第1四半期に143機を納入2026年通期目標 約870機、上期実績 351機
受注残÷年産約10年分約10.6年分
【自動車と航空機の時間軸の違い】

 自動車：受注 ─▶ 納車           数週間〜数か月
 航空機：受注 ─────────────────────────▶ 納入   5〜10年
         ▲ 契約時に価格が決まる       ▲ この間のインフレ・為替・原価増は
                                        原則メーカー側のリスク

ここから導ける、投資家・就活生・取引先が誤解しやすい点：

  • 「受注が好調」は短期の業績とほぼ無関係。売上になるのは5〜10年先
  • 逆に 「不況で航空需要が落ちた」もすぐには効かない。既存受注残が緩衝材になる。
    ただし航空会社が納入を先送り（デファラル）すると効いてくる
  • 業績を動かすのは受注ではなく「生産レート（月産何機）」。ここを見るのが実務

7. なぜ増産できないのか

需要も受注残もあるのに納入が伸びない。理由は需要側ではなく 供給側の詰まりにある。

ボトルネック 中身
当局の監視ボーイングは2024年のドア脱落事案を受け FAA から 737 の月産上限を課された。38→42機へ緩和、2026年3月に一律の上限が撤廃され、実績に応じた監視方式へ移行したと報じられる
サプライヤーの体力コロナ期に人員・設備を落とした二次三次が戻り切らない。熟練工の再取得に年単位
素材・鍛造品チタン・特殊合金の大型鍛造品は世界に数社しか作れない
エンジンエンジン待ちで機体が駐機される事象が繰り返し起きている
認証済みの代替がない別のサプライヤーに切り替えるにも、その部品の認証取得に年単位

2026年時点の状況としては、ボーイングは 737 を月産47機の水準で運転していると
公表し（FAA のキャップストーン審査通過、2026年5〜6月の報道）、経営陣は 52機、
将来的に63機を目標として語っている。また 737 の機体構造の大半を作っていた
スピリット・エアロシステムズを買収して内製に戻したことで、工程の詰まりを
自社で潰せる体制に変えた。

ポイント：この産業の「成長」とは、需要が増えることではなく、月産を1機増やせること。
ニュースを読むときは受注数ではなく生産レートの数字を追うこと。

用語メモ

  • 複占（デュオポリー）：供給者が実質2社しかいない市場構造。100席超のジェット旅客機がこれ
  • エアフレーム：エンジンを除いた機体そのもの（胴体・主翼・尾翼・降着装置など）
  • Tier1：機体メーカーに直接納める一次サプライヤー。日本の重工各社はここ
  • RSP（リスク・シェアリング・パートナー）：開発費を自己負担し、売れた機数に応じて回収する共同事業型の契約。航空機産業に特有
  • 型式証明（TC）：設計が安全基準を満たすと当局が認める許可。FAA（米）・EASA（欧）・JCAB（日）
  • 製造証明（PC）／耐空証明（AC）：量産体制の承認／機体1機ごとの検査
  • バックログ（受注残）：契約済みでまだ納入していない機数・金額。航空機では10年分に達する
  • 生産レート：月産何機作るか。業績を実際に動かすのはこの数字
  • デファラル：航空会社が納入時期を先送りすること
  • 単通路機／双通路機：通路が1本の小型機（737・A320）／2本の中大型機（787・A350）
  • JAEC（日本航空機エンジン協会）：IHI・川崎重工・三菱重工が民間エンジン国際共同開発に参画するための組織
  • COMAC：中国商用飛機。C919（単通路）を国内就航させ、C929 を開発中
