# 航空機・防衛｜儲け方とアフターマーケット

**このノートで分かること**：飛行機は1機100億円以上するのに、なぜメーカーは
「機体では儲からない」と言うのか。エンジンメーカーが新品を赤字同然で売る理由。
そして、この産業の利益が **売った瞬間ではなく、その後30年の整備と部品で立つ**
仕組みを、数字の桁感つきで押さえる。

結論を先に書くと、航空機産業の収益は次の1行で説明できる。

```
利益 ＝ （機体・エンジンの新造販売：薄利、しばしば赤字）
        ＋（就航後 20〜30年の 補修部品・整備・オーバーホール：ここが本体）
```

この構造を **レーザーブレード（カミソリの刃）型**と呼ぶ。
髭剃りの本体を安く配り、替刃で回収するのと同じ発想である。

## 1. 機体は「売っても薄い」

| 論点 | 中身 |
| --- | --- |
| カタログ価格と実売の乖離 | 公表価格は目安にすぎず、**実際は数十%の値引きが常態**とされる。ローンチカスタマー（最初に発注した航空会社）ほど安い |
| 学習曲線 | 初号機の製造工数は量産機の数倍。**初期の数十機〜100機は1機ごとに赤字**になることがある |
| プログラム会計 | 米国メーカーは「そのプログラム全体で最終的にいくら儲かるか」を見積もり、各期に按分して原価計上する（**プログラム会計**）。見積もりが悪化すると、過去分もまとめて損失計上される |
| 長期固定価格のリスク | 5〜10年先の納入を今の価格で契約する。**その間の資材高・インフレ・為替はメーカー負担**が原則 |
| ボーイングの実績 | 2026年第1四半期時点の会社全体の受注残は約6,950億ドルと過去最高。しかし民間機部門は長く採算改善の途上と報じられる |

```
【1機種のプログラム全体のキャッシュフロー（イメージ）】

  +│                                        ┌──── 補修部品・整備で長く稼ぐ
   │                              ┌────────┘
   │                        ┌─────┘  量産が軌道に乗り機体でも黒字
  0├──────────┬────────┬─────────────────────────────▶ 年
   │  \        /   初号機   ▲ 損益分岐（ブレークイーブン）
  -│   \______/    納入        機種によっては 1,000機以上売らないと届かない
   │  開発費
        ◀── 5〜10年 ──▶ ◀────────── 20〜40年 ──────────▶
```

> ポイント：**機体販売は「装置を市場に置く行為」**。置いた機体の数が、
> その後30年の部品・整備の収益権になる。だから多少無理をしても受注を取りに行く。

## 2. エンジン：レーザーブレード型の教科書

エンジンはこの構造がさらに極端になる。

| 段階 | 経済性 |
| --- | --- |
| 新造エンジンの販売 | **大幅値引き。原価割れで売ることもある**と広く言われる |
| 初期のスペアエンジン | ここでいくらか回収 |
| **ショップビジット（分解整備）** | 数年〜十数年おきに工場に降ろして分解・部品交換。**1回で数億円規模**（機種による） |
| **補修部品（スペアパーツ）** | 高い利益率。タービンブレード等の高温部品は消耗品 |
| 長期整備契約 | 飛行時間あたりいくらで包括的に面倒を見る契約（後述） |

```
【エンジン1基あたりの収益の出方（イメージ）】

  新造販売    1回目SV      2回目SV      3回目SV      …
    ▼          ▼            ▼            ▼
  ──┬──────────┬────────────┬────────────┬──────▶ 運航年数
    │          │            │            │
  損失/トントン  利益      利益       利益
  ◀─ 数年 ─▶ ◀─ 5〜8年 ─▶ ◀─ 5〜8年 ─▶

  ※ SV＝ショップビジット（工場での分解整備）。回数と間隔は機種・運航条件で大きく違う
```

ここから出てくる、この産業だけの行動原理：

- **エンジンメーカーは「装着機数（インストールベース）」を何より重視する**。
  1機種に自社エンジンが載れば、20〜30年分の部品収益が確定に近づく
- だから **機体メーカーの新機種でエンジンの座を取る競争が異常に激しい**。
  A320neo で CFM（LEAP）と P&W（GTF）が併存しているのはこの綱引きの結果
- **新造エンジンが売れるほど、短期の利益は悪化することがある**。
  決算を読むときは「新造とアフターの構成比」を見ないと誤読する

### 長期整備契約（PBH／フライトアワー契約）

近年の主流は、**飛行時間（フライトアワー）あたり定額で整備一式を引き受ける契約**。
GE の OnPoint、ロールス・ロイスの TotalCare などが代表例で、**Power by the Hour（PBH）**
とも呼ばれる。

| 立場 | メリット | リスク |
| --- | --- | --- |
| 航空会社 | 整備費が飛行時間に比例する変動費になり、予算が読める。突発の大出費を避けられる | 自社で整備の裁量を失う |
| エンジンメーカー | **30年分の収益が契約として先に確定**。競合の整備業者を排除できる | 想定より部品が傷むと自社負担。運航が止まると収入も止まる |

> コロナ禍でこの弱点が露呈した。飛行機が飛ばない＝フライトアワーが発生しない＝
> **PBH 契約の収入がゼロに近づく**。エンジン各社の業績が一斉に沈んだのはこのためである。

## 3. アフターマーケットの全体像（MRO）

**MRO ＝ Maintenance（整備）・Repair（修理）・Overhaul（オーバーホール＝分解して
基準状態まで戻す大規模整備）** の総称。

| 市場 | 規模（推計） | 出典の性格 |
| --- | --- | --- |
| 航空 MRO 全体 | 2025年 約830億ドル → **2026年 約887億ドル**（年率6.8%） | 調査会社の推計 |
| うちエンジン MRO | **2026年 約471億ドル** → 2032年 約750億ドル（年率約8%） | 調査会社の推計 |
| 商用機 MRO | 2035年に約1,083億ドル（年率4.29%） | 調査会社の推計 |

**エンジンだけで MRO 全体の半分前後**を占める。これが「エンジン屋がこの産業で
いちばん強い」と言われる根拠である。

```
【MRO のプレイヤー4分類】

 ①OEM系            ②航空会社系          ③独立系            ④部品専業
 GE/RR/P&W         ルフトハンザ・テクニーク   ST Engineering      部品商社
 ボーイング/エアバス  エールフランスKLM E&M    HAECO 等            サープラス部品
 の整備部門         ANA/JAL のエンジニアリング                  PMA部品メーカー
    ▲               ▲                      ▲                  ▲
 技術データと        自社機で培った          コスト競争力        OEM純正より安い
 部品を握る          ノウハウを外販          （人件費の安い地域）  代替部品
   ↑ 一番強い                                                 ↑ OEMが最も嫌う存在
```

### なぜ OEM が強いのか

整備は「誰でもできる作業」ではない。**技術データ（整備マニュアル、修理限界値、
工程の許可）を持っているのは設計した OEM だけ**で、部品も純正が基本になる。
つまり **OEM はアフターマーケットのルールブックを握っている**。

これに対抗するのが **PMA（Parts Manufacturer Approval）** ＝ FAA が認めた
「純正以外の代替部品」を作る仕組みと、**DER 修理**（当局の指定技術者が承認した
独自修理法）。OEM はこれを強く牽制し、長期整備契約で囲い込む構図になっている。

## 4. 機体は誰が持っているのか：リース会社という主役

見落とされがちだが、**世界の商用機のかなりの部分（おおむね半分前後と言われる）は
航空会社ではなくリース会社が保有**している。

```
【お金と機体の流れ】

  メーカー ──機体──▶ リース会社（AerCap、Air Lease、SMBCアビエーションキャピタル 等）
     ▲                      │
     │ 代金                 │ 賃貸（オペレーティングリース）
     │                      ▼
  金融市場 ◀──資金調達──  航空会社（ANA、JAL、LCC 各社）
                              │
                              ▼ 整備の発注
                           MRO 各社 ─── 部品 ──▶ OEM
```

| 誰が得をするか | 理由 |
| --- | --- |
| メーカー | 新興・小規模な航空会社にも売れる。**リース会社が信用リスクを肩代わり**するため販路が広がる |
| 航空会社 | 数百億円の機体を買わずに済む。機材の入れ替えが柔軟になる |
| リース会社 | 賃料＋**残価（リース終了後の売却価値）**で稼ぐ。実質は長期の設備金融 |

日本勢では **SMBCアビエーションキャピタル、ORIX、三菱HCキャピタル** などが
世界上位の航空機リース事業を持つ。**リース会社の発注動向が機体メーカーの受注残を
左右する**ので、航空機産業のニュースでリース会社名が頻出するのはこのためである。
→ [リース](../../05_金融/10_リース/README.md)

## 5. 日本メーカーにとってのアフターマーケット

日本勢は完成機を持たないので、**アフターの取り分は「参画した部位・部品の補修需要」**
という形で入ってくる。ここが近年の業績を押し上げている。

| 会社 | 航空分野の稼ぎ方 | 2026年3月期の状況 |
| --- | --- | --- |
| **IHI** | 民間エンジン部品（V2500／PW1100G-JM／GE9X 等）。新製部品＋**補用部品** | 受注高が過去最高の約1兆8,500億円。**民間エンジンが想定以上に伸びた**と報じられる |
| **三菱重工** | 787主翼など機体構造、防衛、リージョナルジェット整備（CRJ の事業を2020年に取得） | 純利益・事業利益が過去最高と報じられる |
| **川崎重工** | 787前部胴体、防衛機（P-1・C-2）、エンジン部品 | 売上収益・純利益・受注高が過去最高と報じられる |
| **SUBARU** | 787中央翼、防衛ヘリ | 航空宇宙は同社の第2の柱 |

> 重工3社を並べると、**ボーイングの機体生産レートに引っ張られる機体構造事業より、
> エンジン補用部品を持つ事業のほうが景気変動に強い**という差が出る。
> 機体構造は「作った分しか売上にならない」が、補用部品は既に飛んでいる機数に比例するため。

## 6. コスト構造と収益性の目安

| 項目 | 目安 | コメント |
| --- | --- | --- |
| 機体メーカーの売上総利益率 | 機種・時期で大きく振れる | プログラム会計のため単年では読みにくい |
| エンジン OEM の営業利益率 | アフター比率が高いほど高い | 新造比率が上がると一時的に悪化 |
| 機体構造 Tier1 の利益率 | **数%台にとどまりやすい** | 為替・材料費・生産レートに直撃される |
| 補修部品 | **利益率が高い**（具体率は各社非開示） | 数量は少ないが単価と粗利が厚い |
| 固定費の性格 | 設備より **治工具・認証・人材** | 熟練工の育成に年単位。人を切ると戻せない |

この「人を切ると戻せない」性質は重要で、コロナ期に各国のサプライヤーが人員を
削減した結果、**需要が戻っても供給が戻らない**という 2020年代後半の生産制約に
つながっている（→ [① 民間航空機の産業構造](01_民間航空機の産業構造.md) 第7章）。

## 用語メモ

- **アフターマーケット**：製品を売った後の整備・修理・部品供給の市場。航空機産業の利益の本体
- **レーザーブレード型（カミソリの刃モデル）**：本体を安く売り、消耗品・サービスで回収する収益モデル
- **MRO**：Maintenance（整備）／Repair（修理）／Overhaul（分解大整備）の総称
- **ショップビジット（SV）**：エンジンを機体から降ろして工場で分解整備すること。1回で数億円規模
- **PBH（Power by the Hour）／フライトアワー契約**：飛行時間あたり定額で整備を包括契約する方式。TotalCare、OnPoint など
- **インストールベース（装着機数）**：既に世に出ている自社製品の数。将来の部品収益の母数
- **プログラム会計**：1機種全体の生涯損益を見積もり、各期に按分する会計。米航空機メーカーが採用
- **ローンチカスタマー**：新機種を最初に発注する航空会社。大幅な値引きを受ける代わりにリスクも負う
- **PMA部品**：FAA が認証した純正以外の代替部品。OEM の牙城を崩す存在
- **DER修理**：当局指定の技術者が承認した独自の修理方法
- **オペレーティングリース**：所有権を移さず賃貸する方式。残価を前提に賃料が決まる
- **残価（レジデュアルバリュー）**：リース終了時の機体価値。リース会社の損益を決める最重要変数
