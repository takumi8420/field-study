航空機・防衛｜防衛産業の特殊性

自動車・機械航空機・防衛
あこのページの単語集用語に触れると意味を確認できます14語
財源FMS（米国からの調達）への流出供給能力買い手独占（モノプソニー）中央調達原価計算方式随意契約国庫債務負担行為安保3文書FMS（有償援助）防衛装備移転三原則オフセットGCAP／GIGO／Edgewingデュアルユース

このノートで分かること：日本の防衛産業がなぜ長く「儲からない産業」だったのかを、
制度の側から理解する。顧客が政府1社だと価格はどう決まるのか。なぜ撤退が相次いだのか。
防衛費が GDP 比2%まで増えて何が変わったのか。そして FMS（米国からの調達）と
GCAP（日英伊の共同開発）という対照的な2つの潮流。
軍事技術そのものではなく、産業・調達制度・収益構造の話に絞る。

結論を先に書くと、日本の防衛産業の特殊性は次の3点に集約される。

①【買い手が1人】 顧客は防衛省ただ1社。値段も数量も相手が決める（買い手独占）
②【原価計算で価格が決まる】 かかった費用＋規定の利益率。がんばっても儲けが増えない
③【量が出ない】 長く輸出が禁じられ、国内需要だけ。量産効果が効かず単価が高止まり

1. 顧客が政府1社という意味（買い手独占）

ふつうの製造業は「顧客が複数いる」ことを前提に成り立つ。防衛はそうではない。

論点 民需（民間航空機など） 防需（国内防衛装備品）
顧客世界中の航空会社・リース会社防衛省（防衛装備庁）ただ1社
価格決定交渉・競争。売り手にも値付けの自由原価計算方式が中心。実費＋規定利益
数量市場が決める予算が決める。単年度主義で変動
仕様標準品を多数に売る1件ごとの特注。少量多品種の極致
需要の波景気・旅客需要政治と安全保障環境。企業は読めない
売り先の分散できるできない（長く輸出が禁じられた）

ポイント：買い手が1人だと、企業努力が利益に結びつかない。
原価を下げると、その下がった原価をもとに次の契約価格が下がる。
「安く作れる会社ほど売上が減る」という、民間企業の常識と逆の力が働く。

2. 価格はどう決まるか（原価計算方式と随意契約）

日本の中央調達（防衛装備庁がまとめて買う方式）では、競争が成立しにくい装備品は
随意契約＋原価計算方式で価格が決まる。

【契約価格の組み立て（原価計算方式のイメージ）】

  ┌─────────────────────────────────────────┐
  │ 材料費   ＋  労務費  ＋  製造経費  ＝ 製造原価             │
  ├─────────────────────────────────────────┤
  │ ＋ 一般管理費及び販売費                                   │
  ├─────────────────────────────────────────┤
  │ ＋ 利益（原価に一定率を掛ける）  ← ★ここが低いと嫌われた   │
  └─────────────────────────────────────────┘
                 ＝ 契約価格
論点 中身
従来の利益率見積もり上の企業利益率は 8%程度にとどまっていたとされる
2023年度からの改善防衛省は取り組みに応じて 最大15%まで引き上げる制度を導入（同省・報道）
原価監査企業の帳簿を国が確認する。過大請求は返還・指名停止の対象
単年度主義予算は原則1年。長期の設備投資・人材育成が計画しにくい（国庫債務負担行為で複数年契約も可能）
知財開発費を国が負担した分、技術データの権利関係が民需転用を難しくする場合がある

「がんばっても儲からない」構造が、次章の撤退につながった。

3. なぜ企業の撤退が相次いだのか

2010年代、日本では防衛事業から撤退する企業が続いた。この20年で100社超が撤退したとも
報じられる（報道ベース）。理由は単一ではなく、複数の要因が重なっている。

【撤退の悪循環】

  防衛費がGDP比1%枠 ──▶ 調達数量が少ない
        │                    │
        │                    ▼
        │              量産効果が効かない ──▶ 単価が高い
        │                    │                    │
        │                    ▼                    ▼
        │              予算内で買える数が減る ◀────┘
        │                    │
        │                    ▼
        └────────── サプライヤーの採算悪化 ──▶ 撤退
                              │
                              ▼
                     代替先がなく調達が困難に（国の防衛力にも影響）
撤退の理由 中身
利益率の低さ防衛事業の営業利益率は平均数%台、案件によっては赤字とも指摘された
量が出ない戦車・護衛艦・航空機はいずれも少量。専用の治工具・生産ラインが償却できない
輸出できない長く実質禁輸だったため国内需要だけ。海外市場に逃げられない
特殊仕様の負担民需と共用できない設備・人員・技能者を抱え続けることになる
見通しが立たない単年度予算で発注が読めず、設備投資の意思決定ができない
レピュテーション「武器を作る会社」と見られることを避けたい企業があったとされる

裾野は広い。報道・政府資料では 10式戦車の関連企業が約1,300社、護衛艦が約8,300社と
言われる。1社の撤退が部品1点の供給途絶になり、装備全体が作れなくなるのがこの産業の
怖さで、政府が「防衛生産・技術基盤」を政策対象にする理由でもある。

政府の対応が 防衛生産基盤強化法（2023年成立）。
サプライチェーン調査、製造工程の効率化・サイバー対策への財政支援、事業承継の支援、
そして 企業が撤退する場合に国が製造施設を取得して生産を継続する（事実上の国有化）
仕組みまで用意した点が特徴である。

4. 防衛費 GDP 比2%で何が起きているか

2022年12月のいわゆる 安保3文書（国家安全保障戦略・国家防衛戦略・防衛力整備計画）で、
2023〜2027年度の5年間の防衛力整備に 総額43兆円程度という枠が示された。
その後の動きは次のとおり。

時点 内容
2022年12月安保3文書。5年で総額43兆円程度、2027年度に GDP 比2%到達を目標
2025年度当初＋補正で防衛費を積み増し、関連経費込みで GDP 比2%に到達。目標を2年前倒しで達成したと報じられる
2026年度予算案防衛関係費 9兆353億円（初の9兆円台）と報じられる
2026年4月防衛関連費は インフラ・海上保安庁等を含めて約10兆6,000億円、GDP 比1.9%と集計（報道）
【「防衛費」と「防衛関連費」は別物】

  ┌─ 防衛関係費（狭義。防衛省の予算）───────────┐
  │  装備品調達・人件費・維持整備・研究開発          │  2026年度 約9.0兆円
  └─────────────────────────────────┘
  ＋ 海上保安庁、公共インフラ整備、サイバー、研究開発 等
  ＝ ┌─ 防衛関連費（NATO基準に寄せた広義）──────────┐
     │                                              │  約10.6兆円／GDP比1.9%
     └──────────────────────────────────┘
   ※ 「2%達成」という報道は、どちらの定義か・補正予算を含むかで数字が変わる。
      記事を読むときは必ず定義と年度を確認すること。

産業側への波及も数字で出ている。重工3社（三菱重工・川崎重工・IHI）の防衛関連事業の
受注残高は2026年3月期末で計6兆2,500億円、前期末比15%増と報じられ、各社は2026年3月期に
過去最高水準の業績を記録した。

ただし、増額がそのまま国内産業の利益になるわけではない。論点は3つ。

  1. 財源：増税・国債・歳出改革の組み合わせで議論が続く。安定財源のめどは立ち切っていない
  2. FMS（米国からの調達）への流出：次章。予算が増えても米国に支払われる分が大きい
  3. 供給能力：注文が急増しても、撤退で痩せたサプライチェーンがすぐには応えられない

5. FMS：米国から買うという特殊な調達

FMS（Foreign Military Sales、有償援助） ＝ 米国政府が売り手になって同盟国に装備を
売る仕組み。企業から買うのではなく、政府対政府の取引である点が決定的に違う。

項目 通常の輸入調達 FMS
売り手米企業米国政府（企業には米政府が発注する）
価格契約時に確定見積もりベース。後から変わり得る
納期契約で確定米側の都合で変わり得る
支払い納入後・出来高前払いが原則
精算都度納入後に精算。余剰金の返還が遅れる問題が長年指摘される
国内産業への波及代理店・整備で一部あり少ない。技術も原則開示されない
【FMS の金の流れ】

  日本（防衛省） ──前払い──▶ 米国政府 ──発注──▶ 米国防衛企業
        ▲                        │
        └──── 装備品 ◀───────────┘
        ※ 価格・納期の決定権は米国側。日本は「契約」ではなく
          米政府の手続きに乗る形になる

規模の推移が問題の大きさを示す。FMS の当初予算額は令和4年度が約3,800億円だったのに対し、
令和5年度は約1兆4,800億円へ急増した（国会資料・防衛白書ベース）。
会計検査院は2026年1月にも FMS 調達の状況に関する報告書を公表しており、
未納入・過大な前払金の未精算が繰り返し指摘課題となっている。

押さえどころ：防衛費が増えても、その一部は米国に流れ、国内の生産基盤には落ちない。
「防衛費2%＝国内防衛産業の売上2倍」ではない。ここが投資テーマとして語られるときに
最も誤解される点である。

6. 装備移転三原則：輸出の壁と、その解体

日本は長く 武器輸出三原則（1967年）で事実上の禁輸状態にあった。転換の流れは以下。

時点 内容
1967年武器輸出三原則。以後、運用で事実上の全面禁輸に
2014年4月防衛装備移転三原則へ改定。一定の条件下で移転を認める枠組みに
2023年12月運用指針改定。ライセンス生産品の完成品を、ライセンス元国へ輸出できるように（迎撃ミサイルの対米輸出が例）
2024年3月GCAP（次期戦闘機）の完成品輸出を、厳格な条件つきで容認
2026年4月21日運用指針を改定する閣議決定。「救難・輸送・警戒・監視・掃海」の5類型を撤廃し、護衛艦・戦闘機・ミサイルを含む完成品全般を、条件付きで移転可能に（政府発表・報道）

移転先は 防衛装備品・技術移転協定を結んだ国に限られる。2026年4月時点で
米国・英国・豪州・インド・フィリピン・フランス・ドイツ・マレーシア・イタリア・
インドネシア・ベトナム・タイ・スウェーデン・シンガポール・UAE・モンゴル・
バングラデシュの 17か国とされる（報道ベース）。

産業から見た意味は明快で、「量が出ない」という積年の病に対する処方箋である。
輸出で数量が増えれば量産効果が効き、単価が下がり、国内調達も楽になる。
ただし実際に売るには、価格競争力・オフセット（相手国への生産移管や技術移転の見返り）・
長期の維持整備支援という、日本企業が経験の薄い領域で戦う必要がある。

7. GCAP：国際共同開発という新しい形

GCAP（Global Combat Air Programme） ＝ 日英伊が共同で次期戦闘機を開発する計画。
2035年の配備を目標とする。産業構造として新しいのは、次の二層建てになっている点。

【GCAP の体制】

  ┌── 政府側 ───────────────────────────────┐
  │  GIGO（GCAP国際政府機関、本部は英国）                      │
  │   日本・英国・イタリアの3政府が設立。発注者の役割を一本化     │
  └─────────────────┬───────────────────┘
                        │ 契約
  ┌─────────────────▼───────────────────┐
  │  Edgewing（エッジウィング）＝ 3社の合弁企業                │
  │   三菱重工業（日） ＋ BAEシステムズ（英） ＋ レオナルド（伊） │
  └─────────────────┬───────────────────┘
                        │ 発注
     エンジン：IHI ＋ ロールス・ロイス ＋ アヴィオエアロ 等
     電子装備・センサー：三菱電機、レオナルド 等 ＋ 各国サプライヤー
時点 動き
2022年12月日英伊が GCAP に合意（日本の次期戦闘機＝F-2 後継）
2024年GIGO 設立条約。本部は英国、初代トップは日本から
2026年4月GIGO と Edgewing の間で最初の契約が結ばれたと報じられる
2026年7月3日約46億ポンド（約9,900億円）規模の複数年開発契約（2027年末まで対象）を締結と報じられる
2026年7月ファンボロー航空ショーで最新モックアップを公開。カナダが初のオブザーバー国として参加と発表

なぜ共同開発なのかは、産業の論理で説明できる。

  • 戦闘機1機種の開発費は兆円規模で、1国では償却できない
  • 参加国が増えるほど調達数量が増え 1機あたり単価が下がる（英・伊がサウジアラビア等の
    追加参加に前向きと報じられるのはこのため）
  • 反面、参加国が増えると仕様調整と意思決定が遅れる。欧州の過去の共同開発がたどった
    失敗を避けられるかが焦点で、日本は2035年という納期を動かせない事情がある

ポイント：GCAP は「日本が久しぶりに完成機を作る」話であると同時に、
日本の防衛産業が初めて「輸出を前提に設計される装備」を手がける話でもある。
前章の装備移転三原則の緩和と、この計画は同じ文脈にある。

用語メモ

  • 買い手独占（モノプソニー）：買い手が1人しかいない市場。防衛装備の国内調達がこれ
  • 中央調達：防衛装備庁がまとめて契約する方式（対して部隊・地方機関の小口契約が地方調達）
  • 原価計算方式：材料費・労務費・経費＋一般管理費＋規定利益率で契約価格を決める方式
  • 随意契約：競争入札によらず特定の相手と契約すること。代替のない装備で多用される
  • 国庫債務負担行為：単年度予算の例外として、複数年度にまたがる契約を認める仕組み
  • 安保3文書：2022年12月の国家安全保障戦略・国家防衛戦略・防衛力整備計画
  • 防衛生産基盤強化法（2023年）：サプライチェーン支援、事業承継支援、撤退時の製造施設の国による取得などを定めた法律
  • FMS（有償援助）：米国政府が売り手となる政府間取引。前払い・見積価格・納期変動が特徴。装備が届かない／前払金の余剰が返らない「未納入・未精算問題」を会計検査院が繰り返し指摘している
  • 防衛装備移転三原則：2014年に武器輸出三原則を置き換えた移転の枠組み。完成品の移転を救難・輸送・警戒・監視・掃海に限っていた「5類型」は2026年4月に撤廃
  • オフセット：装備を輸出する際、相手国に生産・技術・雇用を還元する見返り条件
  • GCAP／GIGO／Edgewing：日英伊の次期戦闘機計画／その政府間機関／三菱重工・BAE・レオナルドの合弁会社
  • デュアルユース：民生と防衛の両方に使える技術。撤退した企業を引き戻す鍵として語られる

  • ② 儲け方とアフターマーケット：民需はアフターで稼ぐ。防需はそれが制度上できない
  • ④ 直近トピック（2026年9月時点）：2026年の制度改正と受注の動き
