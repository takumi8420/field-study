## 1. 業界の定義・範囲

この業界は、性格のまったく違う **2つの事業が同じ会社の中に同居している**のが特徴。

```
【航空機・防衛という業界の中身】

 ┌─ 民需（民間航空機）─────────────────────────┐
 │  機体構造・エンジン部品・装備品を、ボーイング／エアバス／       │
 │  エンジン3社に納める。顧客は世界中。市場原理で動く             │
 └────────────────────────────────────┘
 ┌─ 防需（防衛装備品）─────────────────────────┐
 │  航空機・艦艇・車両・ミサイル・電子装備を防衛省に納める。       │
 │  顧客は1社。価格は原価計算方式。予算と政策で動く               │
 └────────────────────────────────────┘
        ▲ 同じ工場・同じ技能者が両方を担うことも多い。
          だから「民需が細ると防需の基盤も痩せる」という連動が起きる
```

境界の引き方：

- **飛行機を運航する事業**は [航空（運輸）](../../13_運輸・物流/02_航空/README.md)。ここは作る側
- **ロケット・衛星**は [宇宙・衛星](../../01_注目テーマ/07_宇宙・衛星/README.md) に集約（担い手は重なる）
- **護衛艦・潜水艦**は [造船・重機](../12_造船・重機/README.md) 側に置く
- 本フォルダは **航空機（民需・防需）と、防衛産業という制度の話**を中心に扱う

| --- | --- | --- |

| 同（別集計） | 1兆9,867億円（前年比31.7%増） | 2024年度実績、SJAC会報 第862号 |

| 日本の防衛関連費（広義） | 約10兆6,000億円、**GDP比1.9%** | 2026年度、報道ベース（海保・インフラ等を含む） |
| 重工3社の防衛受注残 | **6兆2,500億円**（前期末比15%増） | 2026年3月期末、報道ベース |
| 航空MRO市場（世界） | 2025年 約830億ドル → 2026年 約887億ドル | 調査会社推計 |
| うちエンジンMRO | 2026年 約471億ドル | 調査会社推計 |
| ボーイング 受注残 | 会社全体で約6,950億ドル（民間機6,100機超） | 2026年第1四半期、同社発表 |
| エアバス 民間機受注残 | 9,247機 | 2026年5月末、Forecast International集計 |

**成長性の性格**が他業種と違う点を押さえたい。

- 民需は **需要ではなく供給が律速**。受注残が10年分あるので、伸び率＝増産できた率
- 防需は **政策で不連続に増える**。市場の需要曲線ではなく予算が需要
- どちらも **リードタイムが極端に長い**。今年の意思決定が売上になるのは5〜10年後

## 3. バリューチェーン（川上 → 川下）

```
 素材 ──▶ 部品・部位 ──▶ 統合（OEM）──▶ 顧客 ──▶ 運用 ──▶ 整備・部品
 チタン     機体構造      ボーイング      航空会社   20〜30年  MRO・補用部品
 超合金     エンジン部品   エアバス        リース会社  飛ばす    オーバーホール
 炭素繊維   装備品        GE/RR/P&W      防衛省
   ▲            ▲              ▲             ▲                   ▲
 供給者が     RSPとして     設計・統合・    信用リスクを      ★利益の本体はここ★
 世界に数社   開発費を分担   販売・認証      負う主体
             利益率は数%台  絶対額は最大
```

- 付加価値が集まるのは **(a) エンジン、(b) アフターマーケット（整備・補用部品）、
  (c) 世界に数社しかない特殊素材・大型鍛造品**
- 機体メーカーは規模こそ最大だが、**新造販売そのものは薄利**。売った機体は
  「その後30年の部品・整備の収益権」として効いてくる（→ [②](02_儲け方とアフターマーケット.md)）
- 日本勢は **完成機を持たず、Tier1 として参画する立場**。したがって業績は
  ボーイング／エアバス／エンジン3社の生産計画に従属する（→ [①](01_民間航空機の産業構造.md)）

## 5. 収益モデル・コスト構造

```
民需の利益 ＝ （新造の販売：薄利、初期は赤字）
              ＋（就航後20〜30年の 補用部品・整備・オーバーホール：★本体★）

防需の利益 ＝ （材料費＋労務費＋経費）× 規定の利益率
              ＋（輸出が認められれば量産効果 ← 2026年に制度が変わった）
```

| 論点 | 中身 |
| --- | --- |
| 機体の新造 | カタログ価格から大幅値引き。学習曲線のため初期数十〜100機は1機ごとに赤字になり得る |
| プログラム会計 | 1機種の生涯損益を見積もって各期に按分。見積もり悪化時に過去分もまとめて損失計上される |
| エンジン | **本体を安く売り、ショップビジット（分解整備）と補用部品で20〜30年かけて回収**（レーザーブレード型） |
| 長期整備契約 | 飛行時間あたり定額のPBH契約。収益が先に確定する代わり、運航が止まると収入も止まる |
| 機体構造Tier1 | 利益率は **数%台**にとどまりやすい。為替・材料費・生産レートに直撃される |
| 防需 | 原価計算方式。見積利益率は従来8%程度、**2023年度から取り組みに応じ最大15%**へ（防衛省） |
| 固定費の性格 | 設備より **治工具・認証・熟練人材**。人を切ると戻すのに年単位かかる |

## 6. 競争要因（KSF）と参入障壁

**KSF（成功の鍵）**

1. **装着機数（インストールベース）を取ること**。1機種に採用されれば30年分の部品収益がつく
2. **認証を取り切る力**。当局と基準の解釈を詰める経験値そのものが資産
3. **生産レートを上げる力**。需要ではなく供給が制約なので、月産を1機増やせるかが成長
4. **アフターの比率**。新造依存の事業は景気と生産レートに振り回される
5. **防需では、輸出も含めた量の確保**。量産効果が単価を下げ、調達数量を増やす好循環をつくる
6. **サプライチェーンの維持**。二次三次が1社抜けると装備が作れなくなる

**参入障壁**

| 障壁 | 強さ | 理由 |
| --- | --- | --- |
| 加工技術そのもの | 中 | 難削材の加工ができる工場は日本にも多い |
| **型式証明（認証）** | **極めて強** | MSJが越えられなかった壁。時間と経験でしか買えない |
| **時間と資本の耐久力** | **極めて強** | 開発から黒字化まで20〜30年 |
| **実績（フライトヒストリー）** | 強 | 安全の実績がない部品は採用されない |
| **アフターの技術データ** | 強 | 整備マニュアルと修理限界値をOEMが握る |
| 防需の参入 | 中〜強 | 制度上は参入可能だが、採算と事業継続性が壁になる |

## 7. 規制・法制度

| 分野 | 主な制度 |
| --- | --- |
| **安全・認証** | 型式証明（TC）／製造証明（PC）／耐空証明（AC）。米FAA、欧EASA、日本は国土交通省航空局（JCAB） |
| **整備の資格** | 認定事業場制度、整備士資格。代替部品はPMA（FAA認証の非純正部品）、独自修理はDER修理 |
| **防衛調達** | 中央調達と地方調達、随意契約、**原価計算方式**、原価監査、国庫債務負担行為（複数年契約） |
| **防衛生産基盤** | **防衛生産基盤強化法**（2023年）。サプライチェーン調査、製造工程効率化・サイバー対策支援、事業承継支援、**撤退時に国が製造施設を取得する仕組み** |
| **輸出管理** | **防衛装備移転三原則**（2014年に武器輸出三原則から転換）。2023年12月にライセンス完成品の輸出を解禁、2024年3月にGCAP完成品を容認、**2026年4月21日の閣議決定で5類型を撤廃** |
| **外為法** | 安全保障貿易管理（リスト規制・キャッチオール規制）。技術の提供も規制対象 |
| **米国由来の規制** | ITAR／EAR。米国製部品・技術を含む装備は米国の輸出規制に従う |
| **政策の枠組み** | 安保3文書（2022年12月）、防衛力整備計画（5年で総額43兆円程度） |

## 8. 最近のトピック

詳細と出典は [④ 直近トピック（2026年9月時点）](04_直近トピック_2026.md)。要点は次の5つ。

- **防衛費はGDP比2%を2年前倒しで達成**。2026年度の防衛関係費は9兆353億円で初の9兆円台、
  広義の防衛関連費は約10兆6,000億円・GDP比1.9%と報じられる。安定財源は積み残し
- **2026年4月21日の閣議決定で防衛装備移転三原則の5類型が撤廃**。護衛艦・戦闘機を含む
  完成品全般が、協定締結国（17か国とされる）向けに条件付きで移転可能になった
- **GCAPが実務段階へ**。2026年7月3日にGIGOとEdgewing（三菱重工＋BAE＋レオナルド）が
  約46億ポンド（約9,900億円）の複数年開発契約を締結と報じられる。カナダがオブザーバー参加
- **重工3社は2026年3月期に最高益圏**。防衛受注残は3社計6兆2,500億円（+15%）、
  IHIの受注高は過去最高の約1兆8,500億円で民間エンジンが牽引
- **ボーイングは737の月産上限が外れ47機の運転へ**。FAAは2026年3月に一律キャップを撤廃し
  実績連動の監視方式へ。スピリット買収で機体構造を内製化した
