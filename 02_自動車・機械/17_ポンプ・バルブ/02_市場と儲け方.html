読み取るべきことは3つ。

  1. 重量は増えていないのに金額は過去最高（バルブ生産重量 +0.3% に対し金額 +7.3%）。
    価格改定と、高付加価値品への構成シフトで稼いでいる
  2. ポンプは内需 +2.5%、外需 +10%。国内は国土強靭化や老朽更新で底堅いが伸びない。
    伸びるのは北米データセンター、LNG、アジア・中東の石油化学（JSIM 2026年度見通し）
  3. 輸出額が生産額を上回って見えるのは統計の対象範囲が違う（貿易統計は継手・部品を広く含む）ため。
    単純比較はできないが、外需比率が高い産業であることは確か

2. 核心：用途で値段が10倍変わる

これがこの業界を理解する最大の鍵。同じ「口径50mmのボール弁」でも、どこに付くかで価格が桁違いになる。

キッツが半導体・データセンターを成長ドライバーに挙げ、
フジキンが半導体装置向けに特化しているのは、この構造を突いている。

4. 本当の儲けどころ：アフターマーケット

ポンプもバルブも寿命が20〜40年。設置された機械は動き続け、部品は摩耗する。

収益源 内容 粗利の目安 景気連動
①新規機器（OEM／新設）新しい設備に納める低〜中大きい（設備投資に連動）
②補修部品（スペアパーツ）羽根車、シール、軸受、弁座、ステム高い小さい
③オーバーホール（OH）分解・計測・補修・再組立・再試験高い小さい
④改造・リトロフィット羽根車を作り直して効率を上げる、インバータ化高い政策・電気代に連動
⑤長期保守契約（LTSA）数年分の点検・部品・緊急対応を包括契約中〜高・安定ほぼ無関係
⑥監視・診断サービス振動・電流を常時監視し故障を予知高い（ソフト）拡大中 → ③

なぜアフターが強いか。 理由は「他社に替えられない」から。

  • 羽根車もケーシングもそのメーカー固有の形状。図面を持っているのはメーカーだけ
  • 交換するには据付寸法（フランジ位置、軸心高さ）を合わせる必要があり、配管の作り直しは高くつく
  • プラントの停止時間（シャットダウン期間）は限られ、確実に直せる相手しか選べない

新品で薄く取り、20年かけて厚く回収する。
だから競合は「最初の1台」を赤字覚悟で取りにいくことがある。
プリンタとインクの関係に近いが、ロックインの期間が数十年という点が違う。

一方で、アフターには第三者の補修業者（サードパーティ）が入り込む。
とくに汎用ポンプでは、地場の整備業者が互換部品でオーバーホールする。
メーカーが純正部品と診断データでこれを締め出そうとするのが近年の競争軸。

5. 商流：誰が買うのかが3通りある

【ルートA：EPC経由（大型プラント）】── 最も金額が大きい

  石油会社・電力会社（エンドユーザー）
        │ 発注
        ▼

   ただし「エンドユーザー承認ベンダー」の指定があるため、
   実質の営業対象はエンドユーザー側の技術部門になる（＝スペックイン）。

【ルートC：装置メーカー直販（半導体・食品・医薬）】── 単価と利益率が高い

  半導体製造装置メーカー（東京エレクトロン、AMAT、Lam など）

  ★装置の設計図面に型番が載る＝スペックイン。

   → [半導体製造装置](../../03_電機・電子部品/03_半導体製造装置/README.md)

ルートによって必要な能力がまるで違う。
Aは規格適合と大型製作能力と英文書類、Bは在庫と価格と納期、Cは清浄度と装置メーカーとの共同開発。
1社で全部やろうとすると組織が破綻するので、事業部を分けるのが普通。

6. コスト構造

 売上100 に対するおおまかな内訳（規格品ベースの概念図）

  材料費（鋳物・鍛造・ステンレス・特殊合金）     35〜45
  加工・組立の労務と外注                        15〜25
  検査・試験（試験設備の償却含む）                3〜8
  販管費（技術営業・代理店手数料・保証引当）     15〜25
  ─────────────────────────────────
  営業利益                                       5〜15

  ★材料費比率が高い＝鋼材・銅・ステンレスの市況に利益が振られる。
   銅相場の上昇はキッツの「メタルソリューション事業」のように
   売上を押し上げる一方、バルブ側では原価増になる（2026年上期に顕在化）。
  • 鋳物（キャスティング）がボトルネック。バルブ・ポンプの本体は鋳物であり、
    国内の鋳造業は高齢化・廃業で供給力が細っている。作れる量が増えない構造的制約
  • 検査・書類のコストが馬鹿にならない。高グレード品では材質証明・非破壊検査・
    立会試験の記録作成に相当な工数がかかる。これが価格差の一部を説明する
  • 価格改定が通りやすくなった。2022年以降、材料費・エネルギー費の上昇を理由に
    各社が値上げを実施。バルブ生産額が重量横ばいで金額最高を更新しているのはこの効果が大きい

8. 収益性と競争の型

領域 営業利益率の目安 誰と競うか 決め手
上下水道・公共の汎用弁数%国内同業＋海外廉価品価格、認証、納期
ビル設備・一般産業5〜10%国内・アジア勢在庫、代理店網、品揃え
大型カスタムポンプ振れが大きい（赤字案件も出る）世界の数社実績、設計力、工期
石油化学・LNG向け重要弁10%超欧米勢と指名競争API適合、実績、アフター網
半導体向け超高純度弁・真空ポンプ15〜25%少数の専業清浄度、装置メーカーとの共同開発
アフターサービス20%超とされる純正 vs サードパーティ図面・部品・診断データの保有

結論：この業界で利益率を上げる道は2つしかない。
①より重要な用途に上がる（ビル設備 → プラント → 半導体）
②アフターの比率を上げる（売り切りから保守契約へ）。
荏原の「水・空気・エネルギー・半導体」という事業配置も、
キッツの「半導体・データセンター」重点も、どちらも①の話である。
