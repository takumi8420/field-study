地味に見えるが、同じ形・同じ口径の製品でも、どこに付けるかで値段が10倍以上変わるという
きわめて特異な価格構造を持つ。上下水道の1万円のバルブと、半導体装置の100万円のバルブは、
図面上はよく似ている。この「用途による値段の階段」を理解することが、この業界を読む鍵になる。

1. 業界の定義・範囲

流体そのものを運ぶ・制御するための機器を作る産業。業界統計では
「ポンプ」＝日本産業機械工業会（JSIM）、「バルブ」＝日本バルブ工業会が統計を出しており、
製品カテゴリとしては別だが、顧客も商流も技術もほぼ重なるため、1つの業界として扱われる。

扱う製品は大きく次のとおり。

  • ポンプ：遠心（渦巻）ポンプ、多段ポンプ、水中ポンプ、立軸ポンプ、
    往復動ポンプ、ダイヤフラムポンプ、ギヤポンプ、真空ポンプ
  • バルブ：ゲート（仕切）弁、ボール弁、バタフライ弁、グローブ（玉形）弁、
    チェック（逆止）弁、安全弁、制御弁（コントロールバルブ）、高純度ダイヤフラム弁
  • 周辺：メカニカルシール、継手、ストレーナ、フランジ、給水ユニット

隣接業界との境界は次のとおり。ここを混同すると話が通じなくなる。

業界 違い
油圧・空圧機器同じ「ポンプ」「バルブ」という言葉を使うが目的が違う。あちらは油や空気を使って力を伝える（流体はエネルギーの運び屋）。こちらは流体そのものを届けるのが目的
空調・冷凍機冷温水・冷媒を循環させる設備。ポンプ・バルブの大口需要先
モーターポンプの動力源。効率規制の強化がポンプの構成・価格に直結
水処理・上下水道水を処理・供給する事業の側。ポンプ・バルブはその設備の中身
プラントエンジニアリングプラントを設計・調達・建設するEPC。機器メーカーにとっての発注元
半導体製造装置高純度バルブ・ドライ真空ポンプの需要先。単価が別世界
FA・制御機器制御弁の上位にある計装・制御システム。アズビル・横河は両方を扱う
住宅設備機器水栓金具・給湯器。バルブ技術の延長線上にあり、キッツなどが重なる

6. 競争要因（KSF）と参入障壁

┌──────────────────────────────────────────────┐
│ ①作る（鋳造・加工・組立）                              │ ← 中国・インド勢が到達済み
├──────────────────────────────────────────────┤
│ ②証明する（JWWA・API・ASME・PED等の認証、材質証明）    │ ← 取得に数年。実質の入場券
├──────────────────────────────────────────────┤
│ ③実績（トラックレコード）                              │ ← 20年動いた記録は買えない
├──────────────────────────────────────────────┤
│ ④選定する力（系統計算・NPSH検討・Cv選定の技術営業）    │ ← 人に宿る。育成に10年
├──────────────────────────────────────────────┤
│ ⑤直し続ける（補修部品の図面・世界のサービス拠点）      │ ← 最後まで残る障壁
└──────────────────────────────────────────────┘
KSF なぜ効くか
認証と規格適合API 610／API 6D、JWWA、ASME、PED。適合していないと引合すら来ない。取得に時間と費用がかかる
ベンダーリスト（AVL）への登録エンドユーザーやEPCが認めた一覧に載ることが商談の前提。新規は実績がないと載れない
実績（トラックレコード）「20年間トラブルなく動いた」という記録は金で買えない。重要用途ほどここで決まる
技術営業の選定力ポンプ単体では性能を保証できず、現場の配管・水位・液温で成立可否が決まる。系統計算できる人がいないと売れない
アフターサービス網プラントの停止時間は限られる。現地に部品と技術者がいる会社しか選ばれない
鋳物の調達力作れる量の上限を決めてしまう。国内鋳造業の縮小が競争条件になっている
（半導体向け）清浄度と共同開発装置メーカーと一緒に開発するため、一度入ると装置の世代交代まで続く

逆に、参入障壁が低い領域もある。ビル設備用の汎用バタフライ弁や小型ポンプは
中国・韓国・インド勢と正面から価格競争になる。
この二極化（守れる領域と守れない領域）こそが、各社が用途を上へずらす動機になっている。

7. 規制・法制度

分野 内容
水道法／下水道法上下水道の基準。2026年5月26日に下水道法改正案が衆院可決。都道府県による広域連携推進計画、維持管理状況の公表制度を盛り込む
JWWA（日本水道協会）規格・認証上下水道向け機器の実質的な参入切符。取得していないと入札に参加できない
高圧ガス保安法／労働安全衛生法圧力容器・安全弁の構造規格と定期自主検査。安全弁の設置は法定義務
消防法消火ポンプ（スプリンクラー・屋内消火栓）は認定品が必要
電気事業法／原子炉等規制法発電所・原子力向け機器のクラス分けと品質保証要求。原子力クラス1機器は別格の管理体制が要る
省エネ法／トップランナー制度三相誘導電動機の効率規制（IE3以上）が事実上ポンプの構成を決めている → モーター
API規格（610／6D／609 など）／ASME／PED／CRN石油・ガス・輸出向けの必須規格。国ごとに別の認証が必要で、コストが参入障壁になる
NACE MR0175硫化水素を含む環境（サワーサービス）向けの材料規格
国土強靭化 新5か年計画（2026年度〜）老朽更新・防災の予算枠。公共向けポンプ需要の土台
ウォーターPPP（内閣府・国交省）コンセッション（レベル4）と管理・更新一体マネジメント（レベル3.5）。2031年度までに上下水道で200件が政府目標
2026年度 個別補助制度「重要水道管路更新事業」「重要下水道管路更新事業」等を創設、事業費320億円を計上と報じられる

8. 最近のトピック

詳細は ④ 直近トピック 2026。要点は次の5つ。

  1. バルブ生産額が2年連続で過去最高。2025年度は5,782億円（+7.3%）。
    ただし生産重量は+0.3%、個数は▲0.2%。量ではなく単価が伸びている（日本バルブ工業会）
  2. ポンプ受注は内需+2.5%／外需+10.0%。2026年度見通しは合計5,424億円。
    国内は国土強靭化と老朽更新で底堅いが、資材費高騰と施工能力不足で工事が後ろ倒し（JSIM、2026年3月）
  3. 荏原が長期ビジョン E-Vision2035 を発表（2026年2月13日）。2035年に売上2兆円超・営業利益率20%超。
    2026年12月期は6期連続最高益見込みで、利益の伸びは半導体（CMP装置・真空ポンプ）が牽引
  4. バルブ各社が半導体・データセンターへ重点シフト。キッツは中計で半導体・DC・インドを成長ドライバーに置き、
    タイ工場にDC向けバタフライ弁の増産投資。フジキンは55億円の半導体用バルブ新工場を2026年春稼働予定
  5. 八潮の陥没事故（2025年1月）を機に上下水道の政策が動いた。
    2026年度に320億円の個別補助制度を創設、下水道法改正、ウォーターPPPで2031年度までに200件目標。
    更新率0.65%（全量更新に約150年かかる計算）という現実に対する政策転換

9. 用語メモ

各ノート末尾にも用語メモを置いている。共通する基本用語は次のとおり。

用語 意味
揚程（ヘッド）ポンプが押し上げられる高さ（m）。圧力を高さに換算した値。10m ≒ 0.1MPa → ① 基礎
Q-H曲線／運転点流量と揚程の関係曲線と、配管抵抗曲線との交点。ポンプは必ずこの1点で運転される
相似則（アフィニティ則）回転数を変えたときの変化。動力は回転数の3乗に比例。省エネ制御の理屈の中核
キャビテーション吸込圧が下がりすぎて液が沸騰し、泡の圧壊で羽根車が壊食される現象。NPSHの管理が対策
容積式ポンプ一定体積を閉じ込めて押し出す方式。流量が正確で高粘度に強い。吐出を閉じると破裂する
メカニカルシール軸からの漏れを止める部品。消耗品として交換需要を生む
ゲート弁／ボール弁／バタフライ弁遮断弁の3大形式。順に「大口径で安い」「素早く確実」「薄く軽く大口径に強い」
制御弁（コントロールバルブ）外部信号で開度を連続的に変える弁。単価は一般弁の10〜100倍 → ① 基礎
Cv値バルブの流量能力を示す係数。制御弁選定の中心的な数字
ウォーターハンマー（水撃）弁の急閉やポンプ停止で圧力波が走り配管を叩く現象。破損事故の主因
API 610／API 6D石油・ガス向けの遠心ポンプ／バルブ規格。適合しないとプラントに納入できない
JWWA認証日本水道協会の規格認証。上下水道向けの実質的な参入切符
EPC／ベンダーリスト（AVL）プラントを一括受注する会社／その承認済み納入メーカー一覧。載らないと引合が来ない
エンジニアード品（特注品）現場条件に合わせて設計する一品もの。受注から出荷まで半年〜3年
アフターマーケット補修部品・オーバーホール・保守契約。新品より粗利が高く景気に左右されにくい → ② 市場と儲け方
ウォーターPPP上下水道の官民連携。長期契約・性能発注・維持管理と更新の一体化 → ③ 需要の構造と技術
ダイヤフラム弁／ガスボックス半導体向けの高純度弁と、それを集積したガス供給ユニット
ドライ真空ポンプ油を使わない真空ポンプ。半導体プロセスのチャンバ排気に使う
予知保全振動・電流から異常の兆候を掴み、故障前に手を打つ保全
