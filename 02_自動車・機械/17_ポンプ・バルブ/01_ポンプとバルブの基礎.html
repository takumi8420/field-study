このノートで分かること：ポンプが「何を作っている機械」なのか（答え：流量ではなく圧力＝揚程）、
遠心ポンプと容積式の決定的な違い、バルブ5種類の使い分け、

1. まず役割の整理：ポンプは押す、バルブは絞る

配管の中を水や薬液や石油が流れている。その系統には必ずこの2つが入っている。

  • ポンプ＝流体にエネルギーを与えて押し出す機械（能動部品）
  • バルブ＝流れを止める／絞る／向きを変える部品（受動部品）
 【もっとも単純な流体系統】

   貯水槽              ポンプ         制御弁          需要先
  ┌──────┐            ╭───╮      ┌──┐         ┌──────┐
  │      │──────▶ │ P │────▶│><│────────▶│ 配水管 │
  │  水  │  吸込配管  ╰───╯ 吐出 └──┘  仕切弁  └──────┘
  └──────┘            ▲             ▲              ▲
                       │             │              │
                エネルギーを与える  流量を調整する  完全に閉じる
                （揚程を作る）    （圧力を捨てる）  （遮断する）

  ★ポンプが作るのは「圧力」、バルブがやるのは「その圧力を捨てること」。
   この“捨てる”をやめて省エネにするのがインバータ可変速制御 → ノート③

ポイント：ポンプとバルブは別々の商品に見えるが、
顧客（プラント・ビル・上下水道）から見ると「流体をどう運ぶか」という1つの課題。
だから荏原・キッツ・Flowserve のような会社は両方を、あるいは周辺機器まで一緒に売る。

2. ポンプの2大方式：ターボ型（遠心）と容積式

ポンプは数十種類あるが、原理は2つしかない。

観点 ターボ型（遠心ポンプ・斜流・軸流） 容積式（往復式・回転式）
原理羽根車を高速で回し、遠心力で流体に速度を与え、それを圧力に変えるシリンダやギヤで一定体積を閉じ込めて押し出す
代表形式渦巻ポンプ、多段ポンプ、水中ポンプ、立軸ポンプピストン、プランジャ、ダイヤフラム、ギヤ、スクリュー、一軸ねじ
流量と圧力の関係圧力が上がると流量が減る（連続的な曲線）圧力によらず流量はほぼ一定（吐出側を締めると圧力が青天井に上がる）
向いている流体水のようにサラサラ（低粘度）、大量高粘度、スラリー（固形分混じり）、少量を正確に
流量の精度低い（系統の抵抗で変わる）高い（回転数に比例。計量に使える）
台数比全体の8割以上がこちらとされる残り。薬注・計量・高圧用途
安全上の注意締め切り運転しても壊れにくい吐出弁を閉じたまま回すと配管が破裂する（リリーフ弁が必須）

容積式は「ポンプ自体が流量計」になるのが最大の特徴。
浄水場で次亜塩素酸を1分間に何mLと正確に入れる薬注ポンプ（ダイヤフラム式）はこちら。
一方、上水を1日に10万トン送るような仕事は圧倒的にターボ型。

 【ポンプの分類ツリー】

  ポンプ
   ├─ ターボ型（羽根車で回す）
   │   ├─ 遠心（渦巻）ポンプ …… 高い圧力・中〜大流量。最も普及
   │   │    ├─ 単段    片側から吸って1枚の羽根車で押す。ビル給水など
   │   │    └─ 多段    羽根車を直列に並べる。ボイラ給水・高層ビル・油田圧入
   │   ├─ 斜流ポンプ   …… 中揚程・大流量。雨水排水
   │   └─ 軸流ポンプ   …… 低揚程・超大流量。排水機場（扇風機に近い）
   └─ 容積式
       ├─ 往復式  ピストン／プランジャ／ダイヤフラム …… 超高圧・計量
       └─ 回転式  ギヤ／ベーン／スクリュー／一軸ねじ …… 高粘度・定量搬送

3. 「揚程」と「流量」という2つの軸

ポンプのカタログはすべてこの2軸で書かれている。ここが分からないと業界の話が読めない。

  • 流量 Q：単位時間にどれだけ送れるか（m³/min、L/min）
  • 揚程 H：どれだけ高く押し上げられるか（m）。
    実は「圧力」を水の高さに読み替えた値で、扱う流体の比重によらず同じ数字になるので便利。
    10m の揚程 ≒ 0.1MPa ≒ 1気圧。

3-1. 性能曲線と抵抗曲線、そして「運転点」

 揚程 H(m)
   ▲
   │＼                       ← ポンプ性能曲線（Q-H曲線）
   │  ＼                        メーカーが試験で保証する固有の特性
   │    ＼      ／
   │      ●───      ← 運転点（この1点でしか運転されない）
   │    ／  ＼
   │  ／      ＼
   │／  ← 抵抗曲線（配管・バルブ・高低差で決まる。ほぼ Q の2乗）
   └───────────────────▶ 流量 Q(m³/min)

  ★ポンプは「カタログの最大流量」で動くのではない。
   配管系の抵抗曲線と交わった1点でしか動かない。
   バルブを絞る＝抵抗曲線を立てる＝運転点が左上に移動して流量が減る。

つまり：バルブで流量を絞るのは、ポンプが作ったエネルギーを熱として捨てているだけ。
「絞るのをやめて、回転数を落とす」のが可変速制御で、これが省エネの中核 → ③ 需要の構造と技術

3-2. 相似則（アフィニティ則）──省エネの理屈はここに集約される

回転数 N を変えたときの変化。ターボ型に成り立つ法則。

項目 回転数との関係 回転数を80%に落とすと
流量 QQ ∝ N（1乗）80%
揚程 HH ∝ N²（2乗）64%
軸動力 PP ∝ N³（3乗）51%

流量を2割減らすだけで消費電力が半分になる。これがインバータ制御のインパクト。
荏原はインバータ内蔵PMモータ搭載ポンプで循環用途の消費電力を平均35%削減したとしている
（同社アフターサービス資料、2020年代の実測値）。

3-3. 比速度：形が変わる理由

同じ「遠心ポンプ」でも、高揚程・小流量なら羽根車は細く大径に、
低揚程・大流量なら太く小径になる。この使い分けの指標が 比速度（Ns）。
比速度が小さい＝渦巻型、大きい＝軸流型。
メーカーが何百という型式を持つのは、この Ns の帯ごとに最適形状が違うから。

4. キャビテーション：ポンプ屋が一番気にする現象

ポンプの入口（吸込側）は圧力が下がる。下がりすぎてその温度での飽和蒸気圧を割り込むと、
常温の水が沸騰して泡になる。その泡が羽根車の高圧部で潰れるとき、
局所的に数百MPaの衝撃波が出て金属をえぐる。これがキャビテーション（空洞現象）。

 【キャビテーションの発生】

  吸込配管        羽根車入口         羽根車出口
  圧力 高  ──▶  圧力 最低  ──▶   圧力 高
                     │                  │
              水が沸騰して泡発生    泡が瞬時に潰れる（圧壊）
                     ▼                  ▼
                  性能低下         金属表面が侵食される
                （揚程が出ない）   （エロージョン＝壊食）
                                        ▼
                                  振動・騒音・短寿命

  ★対策は「吸込側の余裕圧力」を確保すること。
   この余裕を NPSHa（利用可能有効吸込ヘッド）、
   ポンプ側が要求する最低値を NPSHr（必要有効吸込ヘッド）と呼ぶ。
   設計の鉄則： NPSHa ＞ NPSHr（一般に1m以上の余裕を取る）

なぜこれが商売に効くか。ポンプは「ポンプ単体」では性能を保証できない。
吸込配管の引き回し、水槽の水位、液温、標高──現場の条件で成立するか決まる。
だから重要用途ほど、カタログから型番を選ぶのではなく、
メーカーの技術者が系統計算をして選定する。ここが特注品ビジネスの起点になる
→ ② 市場と儲け方

5. 軸封（シール）：ポンプの故障の主因

回っている軸がケーシング（外箱）を貫通する部分から、中の液が漏れる。ここを止めるのが軸封。

方式 仕組み 特徴
グランドパッキン編んだ紐を軸に巻いて押さえる安価。わざと少し漏らして冷却する。定期的な締め直しが必要
メカニカルシール2枚の平滑なリングを面で押し当て、ミクロの液膜で封じるほぼ無漏洩。現代の主流。消耗品として交換需要が出る
無軸封（キャンドモータ／マグネットポンプ）軸を外に出さない。磁力で回す漏れがゼロ。危険液・高純度液用。高価

半導体の薬液や石油化学の危険液では、漏れないこと自体が価値なので無軸封が選ばれる。
メカニカルシールは単体でも産業として成立している（日本ピラー工業、イーグル工業など）。

6. バルブの5種類：見分け方と使い分け

バルブは「開け閉めするだけ」に見えて、形ごとに目的がまったく違う。

種類 動き 得意なこと 苦手なこと 主な用途
ゲート（仕切）弁板を上下に差し込む全開時の抵抗が極小。大口径で安い中間開度で使えない（振動・摩耗）。開閉に時間がかかる上下水道の本管、プラントの遮断
ボール弁穴の開いた球を90°回す全開時の抵抗ゼロ、素早く確実に締まる、小型大口径だと球が高価配管の元栓、半導体の薬液・ガス、ビル設備
バタフライ弁円板を90°倒す薄くて軽くて安い。大口径に圧倒的に有利。流量調整もできる全開でも円板が流路に残り抵抗になる空調の冷温水、上下水道、大口径の一般配管
グローブ（玉形）弁円錐の栓を上下させる流量の微調整ができる流路がS字に曲がるので圧力損失が大きい手動の流量調整、蒸気
チェック（逆止）弁流れの力で勝手に開閉逆流を自動で止める（動力不要）急閉すると水撃（ウォーターハンマー）を起こすポンプ吐出側に必ず付く

これに加えて安全弁（リリーフ弁）（設定圧を超えると自動で吹く。法規で設置義務がある）と、
制御弁（コントロールバルブ）がある。

 【口径と単価のイメージ：なぜバタフライ弁が普及したか】

  単価
   ▲
   │                                   ／ ゲート弁（板と本体が巨大化）
   │                              ／
   │                        ／ ボール弁（球が重く高価に）
   │                  ／
   │            ／
   │      ────────────  バタフライ弁（円板は薄いまま）
   │ ──
   └────────────────────────▶ 口径
     25A    100A    300A    600A   1000A

  ★口径が大きくなるほどバタフライ弁のコスト優位が効く。
   上下水道・空調のような「大口径・低圧」の世界で主役になる理由。

6-1. 制御弁（コントロールバルブ）が別格な理由

温度や圧力を一定に保つため、外から信号を受けて開度を連続的に変えるバルブ。
グローブ弁の本体に、空気圧アクチュエータ＋ポジショナ（指令通りの開度に合わせる装置）を載せる。

  • Cv値：そのバルブがどれだけ流せるかの指標。バルブ選定の中心的な数字
  • レンジアビリティ：制御できる最大流量と最小流量の比。50:1 なら広い範囲で制御できる
  • 固有流量特性：開度と流量の関係。リニア／イコールパーセント／クイックオープンを使い分ける

制御弁は単価が普通のバルブの10〜100倍になる。理由は、バルブ本体ではなく
「プロセスを安定させる装置」として売られるから。ここが利益率の高い領域
→ ② 市場と儲け方

7. 材質と規格：ここで値段が決まる

材質 目安コスト 用途
鋳鉄（FC）／ダクタイル鋳鉄（FCD）1上水・空調・一般水。上下水道バルブの主力
青銅・黄銅（CAC）1〜2小口径の給水栓、住宅設備
ステンレス（SCS13／SUS316）3〜6食品、薬品、海水、半導体
特殊合金（ハステロイ、チタン、デュプレックス）10〜30強酸、海水淡水化、化学プラント
樹脂／ライニング（PFA、PTFE、ゴム）2〜10薬液、スラリー、半導体の超純水・フッ酸

規格も値段を左右する。

  • 圧力クラス：JIS の 5K/10K/16K/20K、ANSI の 150lb/300lb/600lb など。
    数字が大きいほど肉厚になり高価
  • API 6D / API 610：石油・ガス向けのバルブ／遠心ポンプ規格。これに適合しないとプラントに入れない
  • JWWA / 水道施設耐震工法指針：上下水道向け。日本水道協会の認証が実質の参入切符
  • ASME、PED（欧州）、CRN（カナダ）：輸出先ごとに別の認証が要る

これが参入障壁の正体：技術的に作れることと、
「その現場に納入できる資格を持っていること」は別。
認証取得と実績（トラックレコード）に数年かかるため、新規参入は簡単ではない。

8. 流体機械の設計思想：試験で保証する世界

ポンプ・バルブが半導体やソフトウェアと決定的に違うのは、理論だけでは性能が決まらないこと。

  1. 性能は実測で保証する。ポンプは工場の試験設備で Q-H 曲線を実測し、
    顧客立会いの試験（ウィットネステスト）で合格させてから出荷する
  2. 相似則でスケールする。小型の模型で試験し、相似則で実機性能を推定する。
    大型立軸ポンプ（排水機場用）などは実機試験ができないのでこの手法が要る
  3. CFD（数値流体解析）は設計期間を縮めたが、試験を置き換えていない。
    最後は実測というのが業界の常識
  4. 寿命が20〜40年。だから「今の性能」より「20年後も部品が手に入るか」で選ばれる

この「長寿命＋試験で保証」という性質が、
補修部品とオーバーホールという安定収益を生む → ② 市場と儲け方

9. 隣接分野との違い

分野 違い
油圧・空圧機器同じ「ポンプ」「バルブ」という言葉を使うが、目的は動力の伝達。油はエネルギーの運び屋であって、届けたい商品ではない。こちらは流体そのものを運ぶのが目的
空調・冷凍機冷温水を循環させる側。ポンプ・バルブの大口需要先
モーターポンプの動力源。プレミアム効率規制（IE3以上）はポンプの価格にも直結
水処理・上下水道水を「処理する」事業。ポンプ・バルブはその設備の中身
半導体製造装置薬液・ガス用の超高純度バルブ、ドライ真空ポンプの需要先。単価が別世界

10. 用語メモ

用語 意味
揚程（ヘッド）ポンプが流体を押し上げられる高さ（m）。圧力を高さに換算した値。10m ≒ 0.1MPa
Q-H曲線（性能曲線）流量と揚程の関係。ポンプ固有の特性で、メーカーが試験で保証する
運転点Q-H曲線と配管の抵抗曲線の交点。ポンプは必ずこの1点で運転される
相似則（アフィニティ則）回転数を変えたときの変化。動力は回転数の3乗に比例する
比速度（Ns）ポンプの形式を決める指標。小さいと渦巻型、大きいと軸流型
キャビテーション吸込圧力が下がりすぎて液が沸騰し、泡が潰れて羽根車を壊食する現象
NPSH正味吸込ヘッド。利用できる値 NPSHa がポンプの要求値 NPSHr を上回る必要がある
容積式ポンプ一定体積を閉じ込めて押し出す方式。流量が正確で高粘度に強い。吐出を閉じると破裂する
メカニカルシール2枚のリングを押し当てて軸からの漏れを止める部品。消耗品で交換需要が出る
ゲート弁／ボール弁／バタフライ弁遮断用バルブの3大形式。順に「大口径で安い」「素早く確実」「薄く軽く安い」
チェック弁（逆止弁）逆流を自動で止めるバルブ。ポンプ吐出側に必ず付く
制御弁（コントロールバルブ）外部信号で開度を連続的に変えるバルブ。単価は一般弁の10〜100倍
Cv値バルブの流量能力を示す係数。制御弁選定の中心的な数字
ポジショナ制御弁を指令どおりの開度に合わせる補助装置
