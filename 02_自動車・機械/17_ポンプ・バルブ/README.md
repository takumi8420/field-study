# ポンプ・バルブ

- 大分類: 自動車・機械
- 状態: done
- 更新日: 2026-09-20

**この業界を一言で**：水・薬液・石油・ガスといった**流体を「運ぶ」「止める」ための機械**を作る産業。
地味に見えるが、**同じ形・同じ口径の製品でも、どこに付けるかで値段が10倍以上変わる**という
きわめて特異な価格構造を持つ。上下水道の1万円のバルブと、半導体装置の100万円のバルブは、
図面上はよく似ている。この「用途による値段の階段」を理解することが、この業界を読む鍵になる。

## 1. 業界の定義・範囲

**流体そのものを運ぶ・制御するための機器**を作る産業。業界統計では
「ポンプ」＝日本産業機械工業会（JSIM）、「バルブ」＝日本バルブ工業会が統計を出しており、
**製品カテゴリとしては別だが、顧客も商流も技術もほぼ重なる**ため、1つの業界として扱われる。

扱う製品は大きく次のとおり。

- **ポンプ**：遠心（渦巻）ポンプ、多段ポンプ、水中ポンプ、立軸ポンプ、
  往復動ポンプ、ダイヤフラムポンプ、ギヤポンプ、真空ポンプ
- **バルブ**：ゲート（仕切）弁、ボール弁、バタフライ弁、グローブ（玉形）弁、
  チェック（逆止）弁、安全弁、制御弁（コントロールバルブ）、高純度ダイヤフラム弁
- **周辺**：メカニカルシール、継手、ストレーナ、フランジ、給水ユニット

隣接業界との境界は次のとおり。ここを混同すると話が通じなくなる。

| 業界 | 違い |
| --- | --- |
| [油圧・空圧機器](../11_油圧・空圧機器/README.md) | **同じ「ポンプ」「バルブ」という言葉を使うが目的が違う**。あちらは油や空気を使って**力を伝える**（流体はエネルギーの運び屋）。こちらは**流体そのものを届けるのが目的** |
| [空調・冷凍機](../16_空調・冷凍機/README.md) | 冷温水・冷媒を循環させる設備。ポンプ・バルブの大口需要先 |

| [水処理・上下水道](../../15_サービス・生活関連/24_水処理・上下水道/README.md) | 水を処理・供給する**事業**の側。ポンプ・バルブはその設備の中身 |

| [半導体製造装置](../../03_電機・電子部品/03_半導体製造装置/README.md) | 高純度バルブ・ドライ真空ポンプの需要先。単価が別世界 |

## 2. 市場規模と成長性

| 区分 | 数値 | 年・出典 |
| --- | --- | --- |
| 国内 バルブ生産額 | **5,782億円**（前年度比 +7.3%、過去最高） | 2025年度、日本バルブ工業会（経産省 生産動態統計ベース） |
| 同 生産重量／数量 | 134,239トン（+0.3%）／92,209千個（▲0.2%） | 2025年度、同上 |
| バルブ 輸出／輸入 | 6,576億円／3,967億円（輸出先1位は中国 1,890億円） | 2025年度、貿易統計ベース（同上） |
| 国内 ポンプ受注額 | **5,191億円**（内需3,805／外需1,385、+2.5%） | 2025年度見込、日本産業機械工業会 |
| 同 2026年度見通し | **5,424億円**（内需3,900 +2.5%／外需**1,524 +10.0%**） | 2026年3月27日公表、同上 |
| 世界 ポンプ市場 | 2026年 約778億ドル → 2034年 約1,140億ドル（CAGR 約4.9%） | 調査会社の推計（Fortune Business Insights） |
| 国内 バルブ製造の事業所数 | 約460事業所。自社ブランドで製造販売するのは**150社程度** | 2022年、日本バルブ工業会 |

**押さえるべき3点**。

1. **数量は横ばい、金額だけが伸びている**。バルブは生産個数▲0.2%・重量+0.3%に対し金額+7.3%。
   価格改定と高付加価値品へのシフトの結果であり、**数を売る商売ではなくなりつつある**
2. **国内は更新需要で「底堅いが伸びない」**。ポンプ内需は2026年度も+2.5%どまり。
   需要がないのではなく、**資材費高騰と施工能力不足で工事が先送りされている**（JSIM）
3. **伸びは外需と先端分野**。北米データセンター、LNG、アジア・中東の石油化学、そして半導体

## 3. バリューチェーン（川上 → 川下）

```
【川上】            【製造】                【流通】                 【川下】

 鋳物（鋳鉄・鋳鋼）┐                                              ┌─▶ 上下水道・排水機場（自治体）
 ステンレス・特殊合金┤                    ┌─ EPCコントラクタ ─────┼─▶ 石油・化学プラント
 銅合金・伸銅品     ├─▶ ポンプ・バルブ ─┤   （日揮・千代田化工等）  ├─▶ 発電所（火力・原子力）
 ゴム・樹脂（シール）┤    メーカー        │                          └─▶ LNG・海水淡水化
 モータ・アクチュエータ┘   荏原／キッツ    ├─ 設備工事会社・サブコン ──┬─▶ ビル空調・給水
 鍛造品・弁座材     ┘   フジキン／酉島   │   機械商社・代理店         └─▶ 工場ユーティリティ
                        Flowserve 等     │
   ▲                     │               └─ 装置メーカー直販 ────────▶ 半導体製造装置
   │                     │                                             食品・医薬プラント
   │                     ▼
   │              【アフターマーケット】
   │               補修部品・オーバーホール・改造・長期保守契約・遠隔診断
   │                     ▲
   └─ 鋳造業の供給力低下  └─ ここに最も厚い利益が乗る（粗利20%超とされる）
      が全体のボトルネック    第三者の補修業者との競合もここで起きる

  ★付加価値が集まるのは2か所。
   ①「設計段階で自社型番を仕様書に載せる」＝スペックイン
   ②「20〜40年の設備寿命のあいだ、部品と保守を売り続ける」＝アフター
```

- 材料費比率は35〜45%程度。鋼材・ステンレス・銅の市況に利益が振られる
- **鋳物がボトルネック**。国内鋳造業の高齢化・廃業で、注文しても枠が取れないことがある
- 新品は薄利、**20年かけてアフターで回収する**のが基本構造 → [② 市場と儲け方](02_市場と儲け方.md)

| **Flowserve**（米） | ポンプ・バルブ・シール | 石油・ガス向け世界大手。売上は約48億ドル規模とされる（2026年見込、報道ベース） |
| **Xylem**（米） | 水 | 上下水道特化。ポンプ＋計測＋サービスの統合 |
| **Grundfos**（デンマーク） | 循環ポンプ | 省エネ小型ポンプの世界最大手。非上場 |
| **KSB／Sulzer／ITT／Pentair／Weir** | 総合 | 欧米の総合勢。世界のアフターサービス網が武器 |
| **Emerson(Fisher)／IMI／Velan／Baker Hughes(Masoneilan)** | 制御弁・重要弁 | 制御弁・重要バルブの世界勢 |

**シェアの構図**：世界のポンプは Grundfos・Xylem・Flowserve・KSB・Sulzer・ITT・荏原などが
上位を分け合うが、**誰も支配的なシェアを持たない分散市場**。
理由は、用途ごとに要求が違いすぎて「全部を作れる会社」が存在しないため。
一方で**半導体装置用バルブのような極端なニッチでは1社が8割を取る**（フジキン）。
国内バルブ製造は約460事業所・自社ブランド150社程度と中小が多く、事業承継とM&Aが恒常的に起きている。

## 5. 収益モデル・コスト構造

```
 利益 ＝ ①新規機器（OEM・新設）     薄利。設備投資の波をかぶる
       ＋ ②補修部品（スペアパーツ）   厚利。図面を持つメーカーが独占しやすい
       ＋ ③オーバーホール            厚利。数年ごとに定期的に発生
       ＋ ④改造・省エネ改修          厚利。インバータ化・羽根車再設計
       ＋ ⑤長期保守契約・遠隔診断    安定。ウォーターPPPやLTSAで拡大
       －  材料費 35〜45%（鋳物・ステンレス・銅）
       －  加工・組立 15〜25%／検査・試験 3〜8%
       －  販管費 15〜25%（技術営業・代理店手数料・保証引当）
```

| 領域 | 営業利益率の目安 | 決め手 |
| --- | --- | --- |
| 上下水道・公共の汎用弁 | 数% | 価格、JWWA認証、納期 |
| ビル設備・一般産業 | 5〜10% | 在庫、代理店網、品揃え |
| 大型カスタムポンプ | 振れが大きい（赤字案件も出る） | 実績、設計力、工期管理 |
| 石油化学・LNG向け重要弁 | 10%超 | API適合、実績、アフター網 |
| 半導体向け高純度弁・真空ポンプ | **15〜25%** | 清浄度、装置メーカーとの共同開発 |
| アフターサービス | **20%超**とされる | 図面・純正部品・診断データの保有 |

> **利益率を上げる道は2つしかない**。
> ①**より重要な用途に上がる**（ビル設備 → プラント → 半導体）
> ②**アフターの比率を上げる**（売り切りから保守契約へ）。
> 荏原の半導体シフトもキッツの半導体・DC重点も、すべて①の話である。

## 6. 競争要因（KSF）と参入障壁

```
┌──────────────────────────────────────────────┐
│ ①作る（鋳造・加工・組立）                              │ ← 中国・インド勢が到達済み
├──────────────────────────────────────────────┤
│ ②証明する（JWWA・API・ASME・PED等の認証、材質証明）    │ ← 取得に数年。実質の入場券
├──────────────────────────────────────────────┤
│ ③実績（トラックレコード）                              │ ← 20年動いた記録は買えない
├──────────────────────────────────────────────┤
│ ④選定する力（系統計算・NPSH検討・Cv選定の技術営業）    │ ← 人に宿る。育成に10年
├──────────────────────────────────────────────┤
│ ⑤直し続ける（補修部品の図面・世界のサービス拠点）      │ ← 最後まで残る障壁
└──────────────────────────────────────────────┘
```

| KSF | なぜ効くか |
| --- | --- |
| **認証と規格適合** | API 610／API 6D、JWWA、ASME、PED。**適合していないと引合すら来ない**。取得に時間と費用がかかる |
| **ベンダーリスト（AVL）への登録** | エンドユーザーやEPCが認めた一覧に載ることが商談の前提。新規は実績がないと載れない |
| **実績（トラックレコード）** | 「20年間トラブルなく動いた」という記録は金で買えない。重要用途ほどここで決まる |
| **技術営業の選定力** | ポンプ単体では性能を保証できず、現場の配管・水位・液温で成立可否が決まる。系統計算できる人がいないと売れない |
| **アフターサービス網** | プラントの停止時間は限られる。**現地に部品と技術者がいる会社しか選ばれない** |
| **鋳物の調達力** | 作れる量の上限を決めてしまう。国内鋳造業の縮小が競争条件になっている |
| **（半導体向け）清浄度と共同開発** | 装置メーカーと一緒に開発するため、一度入ると装置の世代交代まで続く |

**逆に、参入障壁が低い領域もある**。ビル設備用の汎用バタフライ弁や小型ポンプは
中国・韓国・インド勢と正面から価格競争になる。
**この二極化（守れる領域と守れない領域）こそが、各社が用途を上へずらす動機**になっている。

## 7. 規制・法制度

| 分野 | 内容 |
| --- | --- |
| **水道法／下水道法** | 上下水道の基準。**2026年5月26日に下水道法改正案が衆院可決**。都道府県による広域連携推進計画、維持管理状況の公表制度を盛り込む |
| **JWWA（日本水道協会）規格・認証** | 上下水道向け機器の実質的な参入切符。取得していないと入札に参加できない |
| **高圧ガス保安法／労働安全衛生法** | 圧力容器・安全弁の構造規格と定期自主検査。**安全弁の設置は法定義務** |
| **消防法** | 消火ポンプ（スプリンクラー・屋内消火栓）は認定品が必要 |
| **電気事業法／原子炉等規制法** | 発電所・原子力向け機器のクラス分けと品質保証要求。**原子力クラス1機器は別格の管理体制が要る** |
| **省エネ法／トップランナー制度** | 三相誘導電動機の効率規制（IE3以上）が事実上ポンプの構成を決めている → [モーター](../15_モーター/README.md) |
| **API規格（610／6D／609 など）／ASME／PED／CRN** | 石油・ガス・輸出向けの必須規格。国ごとに別の認証が必要で、コストが参入障壁になる |
| **NACE MR0175** | 硫化水素を含む環境（サワーサービス）向けの材料規格 |
| **国土強靭化 新5か年計画（2026年度〜）** | 老朽更新・防災の予算枠。公共向けポンプ需要の土台 |
| **ウォーターPPP（内閣府・国交省）** | コンセッション（レベル4）と管理・更新一体マネジメント（レベル3.5）。**2031年度までに上下水道で200件**が政府目標 |
| **2026年度 個別補助制度** | 「重要水道管路更新事業」「重要下水道管路更新事業」等を創設、事業費320億円を計上と報じられる |

## 8. 最近のトピック

詳細は [④ 直近トピック 2026](04_直近トピック_2026.md)。要点は次の5つ。

1. **バルブ生産額が2年連続で過去最高**。2025年度は5,782億円（+7.3%）。
   ただし生産重量は+0.3%、個数は▲0.2%。**量ではなく単価が伸びている**（日本バルブ工業会）
2. **ポンプ受注は内需+2.5%／外需+10.0%**。2026年度見通しは合計5,424億円。
   国内は国土強靭化と老朽更新で底堅いが、資材費高騰と施工能力不足で工事が後ろ倒し（JSIM、2026年3月）
3. **荏原が長期ビジョン E-Vision2035 を発表**（2026年2月13日）。2035年に売上2兆円超・営業利益率20%超。
   2026年12月期は6期連続最高益見込みで、**利益の伸びは半導体（CMP装置・真空ポンプ）が牽引**
4. **バルブ各社が半導体・データセンターへ重点シフト**。キッツは中計で半導体・DC・インドを成長ドライバーに置き、
   タイ工場にDC向けバタフライ弁の増産投資。フジキンは55億円の半導体用バルブ新工場を2026年春稼働予定
5. **八潮の陥没事故（2025年1月）を機に上下水道の政策が動いた**。
   2026年度に320億円の個別補助制度を創設、下水道法改正、ウォーターPPPで2031年度までに200件目標。
   更新率0.65%（全量更新に約150年かかる計算）という現実に対する政策転換

## 9. 用語メモ

各ノート末尾にも用語メモを置いている。共通する基本用語は次のとおり。

| 用語 | 意味 |
| --- | --- |
| **揚程（ヘッド）** | ポンプが押し上げられる高さ（m）。圧力を高さに換算した値。10m ≒ 0.1MPa → [① 基礎](01_ポンプとバルブの基礎.md) |
| **Q-H曲線／運転点** | 流量と揚程の関係曲線と、配管抵抗曲線との交点。ポンプは必ずこの1点で運転される |
| **相似則（アフィニティ則）** | 回転数を変えたときの変化。**動力は回転数の3乗に比例**。省エネ制御の理屈の中核 |
| **キャビテーション** | 吸込圧が下がりすぎて液が沸騰し、泡の圧壊で羽根車が壊食される現象。NPSHの管理が対策 |
| **容積式ポンプ** | 一定体積を閉じ込めて押し出す方式。流量が正確で高粘度に強い。吐出を閉じると破裂する |
| **メカニカルシール** | 軸からの漏れを止める部品。消耗品として交換需要を生む |
| **ゲート弁／ボール弁／バタフライ弁** | 遮断弁の3大形式。順に「大口径で安い」「素早く確実」「薄く軽く大口径に強い」 |
| **制御弁（コントロールバルブ）** | 外部信号で開度を連続的に変える弁。単価は一般弁の10〜100倍 → [① 基礎](01_ポンプとバルブの基礎.md) |
| **Cv値** | バルブの流量能力を示す係数。制御弁選定の中心的な数字 |
| **ウォーターハンマー（水撃）** | 弁の急閉やポンプ停止で圧力波が走り配管を叩く現象。破損事故の主因 |
| **API 610／API 6D** | 石油・ガス向けの遠心ポンプ／バルブ規格。適合しないとプラントに納入できない |
| **JWWA認証** | 日本水道協会の規格認証。上下水道向けの実質的な参入切符 |
| **EPC／ベンダーリスト（AVL）** | プラントを一括受注する会社／その承認済み納入メーカー一覧。載らないと引合が来ない |
| **エンジニアード品（特注品）** | 現場条件に合わせて設計する一品もの。受注から出荷まで半年〜3年 |
| **アフターマーケット** | 補修部品・オーバーホール・保守契約。新品より粗利が高く景気に左右されにくい → [② 市場と儲け方](02_市場と儲け方.md) |
| **ウォーターPPP** | 上下水道の官民連携。長期契約・性能発注・維持管理と更新の一体化 → [③ 需要の構造と技術](03_需要の構造と技術.md) |
| **ダイヤフラム弁／ガスボックス** | 半導体向けの高純度弁と、それを集積したガス供給ユニット |
| **ドライ真空ポンプ** | 油を使わない真空ポンプ。半導体プロセスのチャンバ排気に使う |
| **予知保全** | 振動・電流から異常の兆候を掴み、故障前に手を打つ保全 |
