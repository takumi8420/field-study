# ③ 需要の構造と技術

このノートで分かること：この業界の需要が**「更新」「省エネ」「先端」の3層**に分かれていること。
国内の土台は老朽インフラの更新、成長の刃は半導体とデータセンター、
そして両者をつなぐのが**可変速制御と予知保全という“機械をサービスに変える”技術**である。

## 1. 需要の5本柱

| 需要分野 | 何が売れるか | 需要のドライバー | 景気連動 | 単価水準 |
| --- | --- | --- | --- | --- |

## 2. 土台①：インフラ更新需要は「危機」として顕在化した

日本の上下水道は高度成長期に一斉に作られ、いま一斉に寿命を迎えている。

| 指標 | 数値 | 年・出典 |
| --- | --- | --- |
| 法定耐用年数40年を超えた水道管 | 全体の約2割・**17.6万km** | 2025年6月時点、報道・自治体向け解説記事 |
| 水道管の年間更新率 | **約0.65%** | 同上 |
| 全部を入れ替えるのに必要な年数（単純計算） | 100 ÷ 0.65 ≒ **約150年** | 上記から算出（推計） |

更新率0.65%ということは、**寿命40年の設備を150年かけて更新している**という計算になる。
物理的に追いつかない。これが2025年1月の埼玉県八潮市の道路陥没事故（下水道管の破損が原因とされる）で
可視化され、政策が動いた。

| 動き | 内容 | 時期 |
| --- | --- | --- |
| 対策検討委員会の提言 | 下水道に起因する大規模陥没を受けた第2次提言 | 2025〜2026年、国交省 |
| **個別補助制度の創設** | 「重要水道管路更新事業」「重要下水道管路更新事業」等。事業費**320億円**を計上と報じられる | 2026年度予算 |
| **下水道法改正案** | 都道府県による広域連携推進計画の策定、維持管理状況の公表制度 | 2026年5月26日 衆院可決 |
| **国土強靭化 新5か年計画** | 2026年度から開始。老朽更新が継続テーマ | 2026年度〜 |
| **ウォーターPPP** | コンセッション（レベル4）と管理・更新一体マネジメント（レベル3.5）。**2031年度までに200件**（水道100・下水道100）を目標 | 内閣府・国交省 |

> **ポンプ・バルブ業界への意味**：管路の更新が進めば、その節目にある**ポンプ場・処理場の
> 機械設備も更新される**。さらにウォーターPPPは「管理と更新を10年以上の長期契約で一体化」する仕組みなので、
> 機器メーカーにとっては**売り切りから長期保守契約への転換**を後押しする。
> 詳しくは [水処理・上下水道](../../15_サービス・生活関連/24_水処理・上下水道/README.md)

ただし制約もある。資材費・人件費の高騰で**工事が後ろ倒しになる**動きが続いており、
JSIM も2026年度のポンプ内需の伸びを +2.5% と控えめに見ている。予算がついても、施工能力が足りない。

## 3. 伸びしろ②：半導体とデータセンターという別世界

同じ「バルブ」でも、半導体向けは要求が根本的に違う。

| 観点 | 一般産業用バルブ | 半導体製造装置用バルブ |
| --- | --- | --- |
| 最優先事項 | 漏れないこと・耐圧 | **汚さないこと**（パーティクル・金属溶出・アウトガス） |
| 内面 | 鋳肌のまま／簡単な仕上げ | 電解研磨、不動態化処理、Ra 0.2μm 以下など |
| 構造 | ボール・ゲート・バタフライ | **ダイヤフラム弁**（弁体と駆動部を金属膜で完全分離） |
| デッドボリューム（液が滞留する空間） | 気にしない | **極小化が至上命題**（残留ガスがウェハを汚す） |
| 作動回数 | 数千〜数万回 | **数百万〜1,000万回**（1枚のウェハ処理で何度も開閉する） |
| サイズ | 25A〜1000A | 1/4インチ級が中心。**集積化してユニットで納める** |
| 単価 | 数千円〜数万円 | **数万〜数十万円／個**。ガスボックス単位では数百万円 |
| 供給構造 | 多数のメーカーが競合 | **少数の専業に集中**。フジキンは装置向けで世界シェア8割とされる |

```
 【半導体装置1台の中での位置づけ：バルブは“部品”ではなく“ユニット”で売る】

   特殊ガスボンベ
        │
        ▼
   ┌──────────────────────────────────┐
   │  ガスボックス（ガス供給ユニット）        │
   │   ┌──┐ ┌────┐ ┌──┐ ┌──────┐      │
   │   │弁│─│MFC │─│弁│─│フィルタ│──┐   │  MFC＝マスフローコントローラ
   │   └──┘ └────┘ └──┘ └──────┘  │   │      （流量を精密に制御する装置）
   │   ↑ 数十〜数百個の高純度弁が集積       │   │
   └───────────────────────────────┼──┘
                                        ▼
                            プロセスチャンバ（ウェハ処理室）
                                        │
                                        ▼
                            ドライ真空ポンプ＋除害装置
                            （荏原・エドワーズなどの領域）

  ★半導体では「バルブを買う」のではなく「ガス供給ユニットを買う」。
   装置メーカーは中身の設計まで委ねるので、一度採用されると切り替えが極めて難しい。
   → [半導体製造装置](../../03_電機・電子部品/03_半導体製造装置/README.md)
```

**データセンターの液冷**も新しい市場になった。
生成AI用のGPUは発熱量が大きく、空冷では追いつかない。サーバーに冷却液を直接通す液冷では、
**静かで、漏れなくて、24時間365日止まらないポンプ**が要る。
パナソニックは2025年6月にデータセンター向け冷却水循環ポンプを発表し、
NVIDIAの次世代GPUに備えて流量を4倍にした製品を開発したと報じられている（日経クロステック、2026年1月）。
キッツもタイ工場にデータセンター向けバタフライ弁の増産投資（約8億円、2026年下期稼働予定）を決めている。
→ [データセンター](../../04_情報通信・IT・ネット/03_データセンター/README.md)

## 4. 技術①：省エネ＝「絞るのをやめる」

[① 基礎](01_ポンプとバルブの基礎.md) で見たとおり、動力は回転数の3乗に比例する（相似則）。
従来の流量調整は「バルブを絞る」だったが、これはポンプが作ったエネルギーを熱で捨てているだけ。

```
 【同じ流量70%を作る2つの方法】

  ■ 従来：バルブ絞り制御
    モータ100%回転 ─▶ ポンプ全力 ─▶ バルブで絞る ─▶ 流量70%
                        消費電力 約90%          ↑
                                          ここで20%を熱として捨てている

  ■ 現在：インバータ可変速制御
    モータ ~80%回転 ─▶ ポンプ ─▶ バルブ全開 ─▶ 流量70%
                        消費電力 約50%（相似則：0.8³≒0.51）

    差分 ≒ 40ポイント。ポンプは工場・ビルの電力消費の大きな割合を占めるため、
    投資回収は電気代だけで2〜5年になることが多い
```

- 荏原は**インバータ内蔵PMモータ搭載ポンプ**で、循環用途の消費電力を平均35%削減したとしている
  （同社アフターサービス資料）。PMモータ＝永久磁石同期モータ。誘導モータより効率が高い
  → [モーター](../15_モーター/README.md)
- **「ポンプ単体の効率」から「システム効率」へ**評価軸が移っている。
  高効率ポンプでも、過大な設計（オーバースペック）で常に絞って使えば意味がない。
  実際、既設ポンプの多くは安全を見て一回り大きく選定されており、**運転点が最高効率点から外れている**
- 省エネ改修は**インバータ追加、羽根車の外径カット、ポンプの入れ替え**の3段階で提案される。
  ここが補修サービスの高付加価値メニューになる → [② 市場と儲け方](02_市場と儲け方.md)

## 5. 技術②：予知保全＝「機械売り」から「稼働売り」へ

ポンプは壊れる前に必ず兆候を出す。その兆候を掴んで先回りするのが予知保全。

```
 【予知保全の4段構造】

  ┌─────────────────────────────────────────────┐
  │ ④ 運用の意思決定：次の定期修繕までもつか、いつ止めるか   │ ← 売り物はここ
  ├─────────────────────────────────────────────┤
  │ ③ 診断：正常時との差分、故障モードの推定               │ ← メーカーの知見
  │    （キャビテーション／アンバランス／軸受劣化／シール漏れ）│
  ├─────────────────────────────────────────────┤
  │ ② 収集・通信：エッジ機器 → クラウド                    │
  ├─────────────────────────────────────────────┤
  │ ① 計測：振動、温度、モータ電流、吐出圧、流量            │
  └─────────────────────────────────────────────┘

  ★③が決定的。振動波形を見て「これは軸受の外輪傷」と言えるのは、
   何万台の故障履歴を持つメーカーだけ。データそのものより
   “何と比べるか”の母集団が競争資源になる。
```

なぜメーカーがここに投資するのか。理由は防衛でもある。

- 補修市場には**第三者の整備業者**が入る。純正部品より安い互換部品で勝負される
- しかし「異常を先に検知して、止まる前に手を打つ」サービスは、
  設計データと故障履歴を持つメーカーにしか提供しにくい
- 結果として**保守契約に診断サービスを束ねて囲い込む**流れになる。
  ウォーターPPP（長期一括契約）やプラントのLTSAとも相性がいい

モータ電流だけで診断する方式（センサを追加せずに済む）や、
後付けの無線振動センサなど、**既設設備に安く載せる**ことが実用上の鍵になっている。
上下水道のポンプ場は無人が多く、人手不足も追い風になる。

## 6. 技術③：材料・製法まわりの地味だが効く変化

| テーマ | 内容 | 意味 |
| --- | --- | --- |
| **積層造形（3Dプリント）** | 複雑形状の羽根車、廃番になった旧型機の補修部品 | 型が不要。**少量・一品ものの補修**に効く。長寿命設備の弱点（部品の廃番）を埋める |
| **耐食・耐摩耗材** | デュプレックスステンレス、超高分子量ポリエチレン、セラミック溶射 | 海水淡水化・スラリー用途の寿命を延ばす。単価も上がる |
| **CFD（数値流体解析）** | 羽根車・弁体の形状最適化 | 試作回数を減らし設計期間を短縮。ただし**最終保証は実測試験**という原則は変わらない |
| **無軸封化** | キャンドモータ・マグネットカップリング | 漏れゼロ。危険液・高純度液で選ばれる。シール交換需要は減るが単価は上がる |
| **標準化・モジュール化** | ユニット化された給水装置、パッケージポンプ | 現場据付の工数を減らす。**施工の人手不足への回答** |
| **電動アクチュエータ化** | 空気式から電動へ | 圧縮空気配管が不要になり、開度のフィードバックが取りやすい → [FA・制御機器](../../03_電機・電子部品/14_FA・制御機器/README.md) |

## 7. 制約：作れる量が増えない

需要の話ばかりしたが、この業界の実際のボトルネックは**供給側**にある。

1. **鋳物が細っている**。バルブ・ポンプ本体は鋳造品。国内鋳造業は高齢化と廃業が進み、
   注文しても枠が取れない。海外調達に切り替えると品質保証の手間が増える
2. **溶接・機械加工の技能者が減っている**。大型ポンプの組立や高圧弁の肉盛り溶接は
   資格と経験が要る仕事で、短期に増やせない
3. **試験設備がボトルネック**。大型ポンプは実機試験設備がないと出荷できない。
   設備投資が重く、受注が増えても納期は簡単に縮まらない
4. **据付・施工の人手**。機器が届いても工事会社がいなければ設置できない。
   自治体の更新工事が後ろ倒しになる最大の理由がここ

> **だから「需要が増える＝売上が増える」とは限らない**。
> 2026年度の国内ポンプ受注見通しが +2.5% にとどまるのは、需要が弱いからではなく、
> 資材・人件費の高騰と施工能力の制約で**工事が先送りされている**ため（JSIM、2026年3月）。

## 8. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **国土強靭化 新5か年計画** | 2026年度から始まる国の防災・老朽更新の中期計画。公共向けポンプ需要の土台 |
| **ウォーターPPP** | 上下水道の官民連携の総称。コンセッション（レベル4）と管理・更新一体マネジメント（レベル3.5）。2031年度までに200件が目標 |
| **管更新率** | 1年間に更新された管路の比率。水道では約0.65%（2025年）で、全量更新に150年かかる計算 |
| **インバータ可変速制御** | モータの回転数を変えて流量を調整する方式。動力は回転数の3乗に比例するため省エネ効果が大きい |
| **PMモータ** | 永久磁石同期モータ。誘導モータより効率が高く、インバータと組んで使う |
| **システム効率** | ポンプ単体ではなく、配管・弁・制御を含めた系統全体の効率。過大設計だと単体効率が高くても無駄になる |
| **ダイヤフラム弁** | 金属膜で流路と駆動部を完全に分ける構造の弁。半導体の高純度ガス・薬液の標準形式 |
| **デッドボリューム** | 流路内で液やガスが滞留する空間。半導体用途では汚染源になるため極小化が求められる |
| **MFC（マスフローコントローラ）** | ガス流量を精密に制御する装置。ガスボックスの中核部品 |
| **ガスボックス** | 半導体製造装置のガス供給ユニット。高純度弁・MFC・フィルタを集積したもの |
| **ドライ真空ポンプ** | 油を使わない真空ポンプ。半導体プロセスのチャンバ排気に使う。荏原・エドワーズなどが供給 |
| **液冷（ダイレクト液冷）** | サーバーに冷却液を直接通す冷却方式。生成AI向けGPUの発熱増で採用が拡大 |
| **予知保全** | 振動・電流などから異常の兆候を掴み、故障前に手を打つ保全。事後保全・時間基準保全の次の段階 |
| **積層造形（3Dプリント）** | 粉末を積層して造形する製法。廃番部品の再現や複雑形状の羽根車に使われ始めている |
| **キャンドモータポンプ／マグネットポンプ** | 軸を外に出さない無漏洩ポンプ。危険液・高純度液用 |
