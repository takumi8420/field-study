# ② 市場と儲け方

このノートで分かること：**同じ口径のバルブが、用途を変えるだけで値段が10倍以上変わる**こと。
規格品と特注品で商売の型がまったく違うこと。
そして本当の利益は新品ではなく**補修部品とオーバーホール**から出ていること。

## 1. 市場規模：国内はほぼ横ばい、伸びているのは「外」と「半導体」

| 区分 | 数値 | 年・出典 |
| --- | --- | --- |
| 国内 バルブ生産額 | **5,782億円**（前年度比 +7.3%、**過去最高**） | 2025年度、日本バルブ工業会（経産省 生産動態統計ベース） |
| 同 前年度 | 5,736億円（+8.2%、当時の過去最高） | 2024年度、同上 |
| 同 生産重量 | 134,239トン（+0.3%）／生産数量 92,209千個（▲0.2%） | 2025年度、同上 |
| バルブ 輸出額 | 6,576億円（最大は中国 1,890億円、次いで米国 1,054億円） | 2025年度、貿易統計ベース（同上） |
| バルブ 輸入額 | 3,967億円（最大は中国 1,119億円） | 2025年度、同上 |
| ポンプ 受注額（見込） | **5,191億円**（内需 3,805／外需 1,385、+2.5%） | 2025年度、日本産業機械工業会 自主統計 |
| 同 2026年度見通し | **5,424億円**（内需 3,900 +2.5%／外需 **1,524 +10.0%**） | 2026年3月27日公表、同上 |
| 世界 ポンプ市場 | 2026年 約778億ドル → 2034年 約1,140億ドル（CAGR 約4.9%） | 調査会社の推計（Fortune Business Insights） |

**読み取るべきこと**は3つ。

1. **重量は増えていないのに金額は過去最高**（バルブ生産重量 +0.3% に対し金額 +7.3%）。
   価格改定と、**高付加価値品への構成シフト**で稼いでいる
2. **ポンプは内需 +2.5%、外需 +10%**。国内は国土強靭化や老朽更新で底堅いが伸びない。
   伸びるのは北米データセンター、LNG、アジア・中東の石油化学（JSIM 2026年度見通し）
3. **輸出額が生産額を上回って見える**のは統計の対象範囲が違う（貿易統計は継手・部品を広く含む）ため。
   単純比較はできないが、**外需比率が高い産業**であることは確か

## 2. 核心：用途で値段が10倍変わる

これがこの業界を理解する最大の鍵。**同じ「口径50mmのボール弁」でも、どこに付くかで価格が桁違いになる。**

```
 【同じ機能・同じ口径のバルブの単価イメージ（概念図。実売価格は案件次第）】

  単価（対数目盛）
   ▲
 1000万円 ┤                                            ■ 原子力（クラス1機器）
           │                                          安全審査・トレーサビリティ・
           │                                          模擬試験・記録の束
  100万円 ┤                              ■ 半導体（超高純度ダイヤフラム弁）
           │                            パーティクル管理・メタル溶出・
           │                            超高純度ガスに耐える内面処理
   10万円 ┤              ■ 石油化学プラント（API適合・耐圧・耐食）
           │            材質保証・NACE・検査成績書・第三者立会
    3万円 ┤      ■ ビル設備（空調冷温水）
           │    カタログ品。設備業者が数百個まとめ買い
    1万円 ┤ ■ 上下水道（一般用・大量調達）
           └──────────────────────────────────▶
             公共・大量     一般産業      重要プラント   超高純度   安全最重要

  ★値段の差は「金属の量」ではなく、
   ①要求される精度・純度 ②求められる証明書と試験の量 ③壊れたときの損害額 で決まる。
```

なぜこうなるのか。**バルブの値段は「壊れたときに失われるもの」の裏返し**だから。

| 用途 | 1個壊れると何が起きるか | それゆえ求められるもの | 値段の桁 |
| --- | --- | --- | --- |
| ビル設備 | 一部の階の空調が止まる。半日で交換 | カタログ性能、納期、安さ | 万円 |
| 上下水道 | 断水。ただし迂回系統がある場合も | 40年寿命、耐震、JWWA認証 | 万円〜十万円 |
| 石油化学プラント | **プラント全停止。1日あたり億円単位の損失** | API適合、材質証明、検査成績書 | 十万円〜百万円 |
| 半導体（薬液・ガス） | **ウェハ1ロット全損＋ライン汚染** | パーティクル・金属溶出・デッドボリュームの管理 | 百万円 |
| 原子力 | 安全に直結 | 規格クラス、耐震、全数記録、長期の品質保証体制 | 百万円〜 |

> **だから「値上げ交渉」ではなく「用途の入れ替え」で利益率が上がる**。
> キッツが半導体・データセンターを成長ドライバーに挙げ、
> フジキンが半導体装置向けに特化しているのは、この構造を突いている。

## 3. 規格品（カタログ品）と特注品（エンジニアード品）

ポンプ・バルブメーカーの中には、**まったく違う2つの商売が同居している**。

| 観点 | 規格品（スタンダード） | 特注品（エンジニアード／カスタム） |
| --- | --- | --- |
| 何を売るか | カタログの型番 | **その現場で成立する設計** |
| 受注の仕方 | 代理店・商社経由の在庫販売 | 引合 → 仕様検討 → 見積 → 設計 → 製造 → 立会試験 |
| リードタイム | 即納〜数週間 | **6か月〜3年**（大型は設計だけで数か月） |
| 1件の金額 | 数万〜数百万円 | 数千万〜数十億円 |
| 利益率 | 中（数量と生産効率で稼ぐ） | 高いが**振れる**（見積時の想定が外れると赤字） |
| 競争相手 | 中国・韓国・インド勢と価格競争 | 実績のある数社の指名競争 |
| 典型 | ビル給水ポンプ、汎用バタフライ弁、水栓 | 発電所ボイラ給水ポンプ、海水淡水化ポンプ、LNGポンプ、大型排水機場 |

```
 【2つの商売のキャッシュフローの形】

  規格品：            ■■■■■■■■■■■■■■■■  （毎月平らに入る）
                      在庫→出荷→請求。運転資本は在庫に寝る

  特注品：   受注 ─────設計・製造（6か月〜3年）──── 出荷 ─ 検収
             ▲前受金          ▲コストだけ出ていく        ▲残金
             │                                            │
             └─ 受注残（バックログ）として計上 ───────────┘

  ★特注品は「受注残」が業績の先行指標になる。
   だから決算で売上より受注高が注目される。
   一方で、受注から売上計上まで時間があるので
   その間の鋼材価格・為替・人件費の変動をかぶるリスクがある。
```

## 4. 本当の儲けどころ：アフターマーケット

ポンプもバルブも**寿命が20〜40年**。設置された機械は動き続け、部品は摩耗する。

| 収益源 | 内容 | 粗利の目安 | 景気連動 |
| --- | --- | --- | --- |
| ①新規機器（OEM／新設） | 新しい設備に納める | 低〜中 | **大きい**（設備投資に連動） |
| ②補修部品（スペアパーツ） | 羽根車、シール、軸受、弁座、ステム | **高い** | 小さい |
| ③オーバーホール（OH） | 分解・計測・補修・再組立・再試験 | 高い | 小さい |
| ④改造・リトロフィット | 羽根車を作り直して効率を上げる、インバータ化 | 高い | 政策・電気代に連動 |
| ⑤長期保守契約（LTSA） | 数年分の点検・部品・緊急対応を包括契約 | 中〜高・**安定** | ほぼ無関係 |
| ⑥監視・診断サービス | 振動・電流を常時監視し故障を予知 | 高い（ソフト） | 拡大中 → [③](03_需要の構造と技術.md) |

**なぜアフターが強いか。** 理由は「他社に替えられない」から。

- 羽根車もケーシングも**そのメーカー固有の形状**。図面を持っているのはメーカーだけ
- 交換するには据付寸法（フランジ位置、軸心高さ）を合わせる必要があり、配管の作り直しは高くつく
- プラントの停止時間（シャットダウン期間）は限られ、**確実に直せる相手**しか選べない

> **新品で薄く取り、20年かけて厚く回収する**。
> だから競合は「最初の1台」を赤字覚悟で取りにいくことがある。
> プリンタとインクの関係に近いが、ロックインの期間が数十年という点が違う。

一方で、アフターには**第三者の補修業者（サードパーティ）**が入り込む。
とくに汎用ポンプでは、地場の整備業者が互換部品でオーバーホールする。
メーカーが純正部品と診断データでこれを締め出そうとするのが近年の競争軸。

## 5. 商流：誰が買うのかが3通りある

```
【ルートA：EPC経由（大型プラント）】── 最も金額が大きい

  石油会社・電力会社（エンドユーザー）
        │ 発注
        ▼
  EPCコントラクタ（日揮・千代田化工・Bechtel・現代E&C など）
        │ 機器発注。ここで「ベンダーリスト」に載っていないと引合すら来ない
        ▼
  ポンプ・バルブメーカー ──▶ 鋳造・鍛造の協力工場

  ★ポイント：メーカーはエンドユーザーと直接交渉できない。
   ただし「エンドユーザー承認ベンダー」の指定があるため、
   実質の営業対象はエンドユーザー側の技術部門になる（＝スペックイン）。
   → [プラントエンジニアリング](../../12_建設・住宅・不動産/03_プラントエンジニアリング/README.md)

【ルートB：設備工事会社・代理店経由（ビル・工場・上下水道）】── 数が多い

  発注者（自治体・ビルオーナー・工場）
        │ 入札／発注
        ▼
  サブコン・設備工事会社・水道施設工事業者
        │ 機器調達
        ▼
  機械商社・代理店（在庫を持ち、与信も担う）
        │
        ▼
  ポンプ・バルブメーカー
   → [サブコン](../../12_建設・住宅・不動産/02_サブコン（電気・空調・設備）/README.md)／[機械商社](../../06_商社・卸売/04_機械商社/README.md)

【ルートC：装置メーカー直販（半導体・食品・医薬）】── 単価と利益率が高い

  半導体製造装置メーカー（東京エレクトロン、AMAT、Lam など）
        │ 装置に組み込む部品として発注
        ▼
  ポンプ・バルブメーカー（フジキン、CKD、荏原 など）

  ★装置の設計図面に型番が載る＝スペックイン。
   装置が量産される限り継続受注になるが、切り替えには装置の再認定が要る
   → [半導体製造装置](../../03_電機・電子部品/03_半導体製造装置/README.md)
```

**ルートによって必要な能力がまるで違う**。
Aは規格適合と大型製作能力と英文書類、Bは在庫と価格と納期、Cは清浄度と装置メーカーとの共同開発。
1社で全部やろうとすると組織が破綻するので、事業部を分けるのが普通。

## 6. コスト構造

```
 売上100 に対するおおまかな内訳（規格品ベースの概念図）

  材料費（鋳物・鍛造・ステンレス・特殊合金）     35〜45
  加工・組立の労務と外注                        15〜25
  検査・試験（試験設備の償却含む）                3〜8
  販管費（技術営業・代理店手数料・保証引当）     15〜25
  ─────────────────────────────────
  営業利益                                       5〜15

  ★材料費比率が高い＝鋼材・銅・ステンレスの市況に利益が振られる。
   銅相場の上昇はキッツの「メタルソリューション事業」のように
   売上を押し上げる一方、バルブ側では原価増になる（2026年上期に顕在化）。
```

- **鋳物（キャスティング）がボトルネック**。バルブ・ポンプの本体は鋳物であり、
  国内の鋳造業は高齢化・廃業で供給力が細っている。**作れる量が増えない**構造的制約
- **検査・書類のコスト**が馬鹿にならない。高グレード品では材質証明・非破壊検査・
  立会試験の記録作成に相当な工数がかかる。これが価格差の一部を説明する
- **価格改定が通りやすくなった**。2022年以降、材料費・エネルギー費の上昇を理由に
  各社が値上げを実施。バルブ生産額が重量横ばいで金額最高を更新しているのはこの効果が大きい

## 8. 収益性と競争の型

| 領域 | 営業利益率の目安 | 誰と競うか | 決め手 |
| --- | --- | --- | --- |
| 上下水道・公共の汎用弁 | 数% | 国内同業＋海外廉価品 | 価格、認証、納期 |
| ビル設備・一般産業 | 5〜10% | 国内・アジア勢 | 在庫、代理店網、品揃え |
| 大型カスタムポンプ | 振れが大きい（赤字案件も出る） | 世界の数社 | 実績、設計力、工期 |
| 石油化学・LNG向け重要弁 | 10%超 | 欧米勢と指名競争 | API適合、実績、アフター網 |
| 半導体向け超高純度弁・真空ポンプ | **15〜25%** | 少数の専業 | 清浄度、装置メーカーとの共同開発 |
| アフターサービス | **20%超**とされる | 純正 vs サードパーティ | 図面・部品・診断データの保有 |

> **結論**：この業界で利益率を上げる道は2つしかない。
> ①**より重要な用途に上がる**（ビル設備 → プラント → 半導体）
> ②**アフターの比率を上げる**（売り切りから保守契約へ）。
> 荏原の「水・空気・エネルギー・半導体」という事業配置も、
> キッツの「半導体・データセンター」重点も、どちらも①の話である。

## 9. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **エンジニアード品（特注品）** | 現場条件に合わせて設計する一品もの。受注から出荷まで半年〜3年 |
| **受注残（バックログ）** | 受注済みで未出荷の金額。特注品事業の先行指標 |
| **アフターマーケット** | 補修部品・オーバーホール・保守契約の総称。新品より粗利が高く景気に左右されにくい |
| **オーバーホール（OH）** | 分解・計測・補修・再組立・再試験の一連作業。数年に一度の定期作業として発生する |
| **LTSA（長期保守契約）** | 数年分の点検・部品供給・緊急対応を包括する契約。収益が平準化する |
| **サードパーティ補修** | メーカー以外の業者が互換部品で行う補修。純正品との競合になる |
| **EPC** | 設計（Engineering）・調達（Procurement）・建設（Construction）を一括受注する会社。プラント向け機器の実質の発注元 |
| **ベンダーリスト（AVL）** | エンドユーザーやEPCが認めた納入可能メーカーの一覧。ここに載ることが商談の前提 |
| **スペックイン** | 顧客の仕様書・設計図面に自社型番を載せてもらうこと。繰り返し受注の源泉 |
| **JWWA認証** | 日本水道協会の規格認証。上下水道向けの実質的な参入切符 |
| **NACE（MR0175）** | 硫化水素を含む環境（サワーサービス）向けの材料規格。石油・ガスで必須 |
| **立会試験（ウィットネステスト）** | 顧客が立ち会う性能・耐圧試験。重要機器では合格が出荷条件 |
| **鋳物（キャスティング）** | バルブ・ポンプ本体の製法。国内の鋳造業の供給力低下が業界全体の制約になっている |
