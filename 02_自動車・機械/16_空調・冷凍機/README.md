# 空調・冷凍機

- 大分類: 自動車・機械
- 状態: done
- 更新日: 2026-09-20

**この業界を一言で**：熱を作るのではなく、**熱をある場所から別の場所へ汲み上げて運ぶ機械（ヒートポンプ）**を作って売る産業。
ルームエアコンも、ビルのチラーも、スーパーの冷凍ショーケースも、原理は同じ冷凍サイクルである。
ただし商売は真っ二つに割れていて、**住宅用は量産品の価格競争、業務用は工事と保守で稼ぐサービス業**に近い。
このフォルダはその二重構造と、「規制が製品を決める」という業界の癖を軸に構成している。

## 1. 業界の定義・範囲

空調・冷凍機とは、**冷凍サイクル（ヒートポンプ）を使って熱を移動させる機械**を設計・製造・販売・保守する産業。
日本冷凍空調工業会（JRAIA）の区分では、家庭用エアコン、業務用パッケージエアコン、ビル用マルチ、
チラー・アプライド機器、冷凍冷蔵ショーケース、輸送用冷凍機、ヒートポンプ給湯機などが含まれる。

隣接業界との境界は次のとおり。

 パワー半導体・基板    ──┤   （ダイキン、三菱電機、 │  ┌─▶ 機材商社 ──▶ 設備工事店 ──▶ 店舗・中小ビル

- 冷媒はフッ素化学の製品。ダイキンのように**冷媒（化学）まで自社で持つ**企業は規制対応で有利に立つ
- 買い手側の事情は [ゼネコン](../../12_建設・住宅・不動産/01_ゼネコン/README.md)、

## 5. 収益モデル・コスト構造

```
利益 ＝ ①住宅用の機器販売（薄い・天候で振れる）
      ＋ ②業務用の機器販売（中）
      ＋ ③据付工事（中）
      ＋ ④保守・点検契約（厚い・安定）    ← 実質的な利益の柱
      ＋ ⑤部品・修理・更新（厚い）
      － 材料費（銅・アルミ・鋼板・半導体・冷媒）と物流費
```

| 収益源             | 性格                                   | 利益率のイメージ             |
| ------------------ | -------------------------------------- | ---------------------------- |
| 住宅用エアコン     | 量販店の店頭で比較される。季節商品     | 薄い。数量と材料相場で振れる |
| 業務用機器         | 相見積もり。設計段階で決まれば有利     | 中                           |
| 据付工事           | 人件費次第。工事会社が担うことが多い   | 中                           |
| **保守・点検契約** | 年次の定期収入。フロン点検が法律で義務 | **厚い**。景気の波が小さい   |
| 部品・修理         | 稼働台数に比例。緊急対応は単価が高い   | 厚い                         |
| 更新（リプレース） | 配管を流用できるため既設メーカーが有利 | 中〜厚い                     |

- 売上100に対して材料費が40〜55を占める部品集約型。**銅・アルミ相場が利益に直結**する
- **かさばる・重い・季節商品**の三重苦で物流費が効くため、消費地の近くで作るのが基本
- 業務用・サービス比率が高い企業ほど営業利益率が高い傾向 → [② 儲け方と競争](02_儲け方と競争.md)

## 6. 競争要因（KSF）と参入障壁

```
┌──────────────────────────────────────┐
│ ①作る（圧縮機・熱交換器・インバータ制御）          │ ← 中国勢が追いついた層
├──────────────────────────────────────┤
│ ②売る（量販店の棚／設計事務所・サブコンとの関係）   │
├──────────────────────────────────────┤
│ ③止めない（全国のサービス網・部品在庫・保守契約）   │ ← 最大の障壁
├──────────────────────────────────────┤
│ ④規制を味方にする（冷媒の標準化・省エネ基準の先取り）│ ← ダイキンが最も得意
└──────────────────────────────────────┘
```

| KSF                              | なぜ効くか                                                                               |
| -------------------------------- | ---------------------------------------------------------------------------------------- |
| **圧縮機の内製**                 | 原価・効率・静粛性の大半を決める。外部調達だと差別化できない                             |
| **サービス網**                   | 業務用・冷凍は止まると顧客の損害が直接発生する。「壊れた日に人が来る」ことに金が払われる |
| **設計事務所・サブコンとの関係** | 図面に機種が書き込まれた時点で勝負がつく                                                 |
| **地域ごとの製品開発**           | 気候・住宅構造・電源事情が違うため、輸出だけでは勝てない                                 |
| **規制対応と標準化**             | 使える冷媒と必要効率が法律で決まる。先に適合した側が土俵を取る                           |
| **量産規模（住宅用）**           | 部品集約型なので調達量がそのままコストになる                                             |

> **この業界の参入障壁は工場ではなく「人と網」にある。**
> 機械を作るだけなら追いつける。だが全国の工事店・サービス拠点・部品在庫と、
> 設計段階で仕様に入り込む関係は、10年単位でしか作れない。

## 7. 規制・法制度

| 分野                                 | 内容                                                                                                                                 |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------ |
| **モントリオール議定書／キガリ改正** | オゾン層破壊物質（CFC・HCFC）の全廃に続き、2016年のキガリ改正でHFC（代替フロン）を段階削減。日本は2029年▲70%、2034年▲80%、2036年▲85% |
| **オゾン層保護法／フロン排出抑制法** | 冷媒の製造・輸入の数量管理、業務用冷凍空調機器の**定期点検・漏えい報告・廃棄時回収**を義務付ける。保守ビジネスの法的な土台           |
| **省エネ法（トップランナー制度）**   | 家庭用エアコンの目標基準値を約15年ぶりに引き上げ。壁掛形は2027年度、それ以外は2029年度が目標年度（「エアコン2027年問題」）           |
| **建築物省エネ法**                   | 2025年4月から原則すべての新築建築物に適合義務。建物の断熱と設備効率の両面で空調に影響                                                |
| **米国の冷媒規制（AIM Act）**        | 2026年1月以降、新設の住宅・軽商業用HVACはGWP700以下が必須。R-454B・R-32への全面移行                                                  |
| **欧州 F-gas規則／暖房政策**         | HFC削減に加え、暖房の電化を補助金で誘導。補助の増減がそのまま需要に直結する                                                          |
| **補助金**                           | 国内では省エネ機器への各種補助、自治体では東京ゼロエミポイントなど。自然冷媒機器への補助（環境省）も継続                             |
| **高圧ガス保安法**                   | CO2・アンモニアなど高圧・毒性のある自然冷媒を扱う設備で適用                                                                          |

詳細は [③ 規制と技術トレンド](03_規制と技術トレンド.md)。

## 9. 用語メモ

各ノート末尾にも用語メモを置いている。共通する基本用語は次のとおり。

| 用語                         | 意味                                                                                                              |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| **ヒートポンプ**             | 熱を作らず低温側から高温側へ汲み上げる仕組み → [① 仕組みと製品分類](01_エアコンの仕組みと製品分類.md)             |
| **冷媒**                     | 熱を運ぶ流体。蒸発・凝縮を繰り返す。種類の選択が規制と直結する → [③ 規制と技術トレンド](03_規制と技術トレンド.md) |
| **圧縮機（コンプレッサー）** | 冷媒を高圧にする部品。エアコンの心臓部で原価・効率の要                                                            |
| **COP／APF**                 | 効率の指標。COPはある一点の条件、APFは通年の実使用に近い条件での値                                                |
| **PAC**                      | パッケージエアコン。店舗・事務所向けの業務用エアコン                                                              |
| **ビル用マルチ／VRF**        | 室外機1台に多数の室内機をつなぎ冷媒流量を可変制御する日本発の方式                                                 |
| **チラー**                   | 冷水（温水）を作る機械。大規模施設・データセンターの中央熱源                                                      |
| **GWP**                      | 地球温暖化係数。CO2の何倍の温室効果があるか。冷媒規制の中心指標                                                   |
| **キガリ改正**               | HFC（代替フロン）の生産・消費を段階削減する国際的な取り決め（2016年）                                             |
| **A2L**                      | わずかに燃える微燃性冷媒の分類。R-32、R-454Bが代表                                                                |
| **トップランナー制度**       | 市場最高効率の製品を基準に将来の省エネ目標値を定める日本の制度                                                    |
