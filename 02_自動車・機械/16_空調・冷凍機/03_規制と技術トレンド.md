# ③ 規制と技術トレンド

このノートで分かること：この業界の技術は、**規制が先に決まり、それに合わせて製品が作り替えられる**という順番で動く。
冷媒規制（オゾン層→温暖化）、省エネ基準、そしてインバータ化という3つの軸を押さえると、
いま起きているデータセンター液冷や欧州ヒートポンプ暖房の話まで一直線でつながる。

## 1. 結論：規制がロードマップを書いている

```
 1987 モントリオール議定書 ─── オゾン層を壊すガス（CFC/HCFC）を段階的に禁止
        ↓ 代替として HFC（R-410A など）が普及。オゾン層は守れた
 2016 キガリ改正 ─────────── その HFC が強力な温室効果ガスだったので今度は HFC を削減
        ↓ 先進国は生産・消費を段階的に削減（日本：2029年▲70%、2036年▲85%）
 2020年代 低GWP冷媒への移行 ── R-32、R-454B、CO2、プロパン、アンモニアへ
        ↓ 同時に、省エネ基準（トップランナー、SEER2 など）も引き上げ
 2027〜  日本のエアコン新省エネ基準 ／ 米国の A2L 全面移行
```

| 規制の軸                 | 何を縛るか                              | 企業への影響                                                 |
| ------------------------ | --------------------------------------- | ------------------------------------------------------------ |
| **冷媒規制**             | 使える冷媒の種類（オゾン破壊係数・GWP） | 製品の中身を作り替える。設計・安全対策・サービス体制まで波及 |
| **省エネ基準**           | 機器の効率（APF／SEER など）            | 達成できない機種は売れなくなる。低価格帯が消える             |
| **建物・エネルギー政策** | 建物の断熱・暖房方式・補助金            | 需要そのものを作る／消す（欧州ヒートポンプがその典型）       |
| **安全規格**             | 可燃性冷媒の充填量・施工方法            | 工事店の教育コスト。規格が普及速度を決める                   |

> ポイント：空調メーカーにとって規制は「守るコスト」であると同時に、
> **自社が先に対応した冷媒・技術を標準にできれば競争優位になる**という機会でもある。
> ダイキンがR-32の特許を開放したのは、この構図を狙った動きだった → [② 儲け方と競争](02_儲け方と競争.md)

## 2. 冷媒規制：オゾン層の次はGWP

冷媒の評価軸は2つある。**ODP（オゾン層破壊係数）**と **GWP（地球温暖化係数）**。

| 世代                | 代表的な冷媒                                             | ODP      | GWP（100年）   | 状況                                                         |
| ------------------- | -------------------------------------------------------- | -------- | -------------- | ------------------------------------------------------------ |
| 第1世代 CFC         | R-12                                                     | 高い     | 約10,900       | 1996年に先進国で生産全廃                                     |
| 第2世代 HCFC        | R-22                                                     | 中       | 約1,810        | 日本は2020年に生産全廃。既設機の補充が課題                   |
| 第3世代 HFC         | R-410A、R-134a                                           | **ゼロ** | 約2,090／1,430 | オゾン層は守れたがGWPが高く、削減対象に                      |
| 第3.5世代 低GWP HFC | **R-32**                                                 | ゼロ     | 約675          | ルームエアコンの主流。微燃性（A2L）                          |
| 第4世代 HFO混合     | R-454B、R-1234yf                                         | ゼロ     | 約466／4以下   | 北米の住宅用・車載で採用                                     |
| 自然冷媒            | **CO2（R-744）／アンモニア（R-717）／プロパン（R-290）** | ゼロ     | 1／0／3        | 冷凍冷蔵・給湯・産業用で拡大。可燃性・毒性・高圧の扱いが課題 |

- **GWP** とは「同じ重さのCO2の何倍、温室効果があるか」の数字。R-410Aは1kg漏らすとCO2約2トン分に相当する
- 日本はキガリ改正に基づき、2019年からHFCの削減を開始。**2029年▲70%、2034年▲80%、2036年▲85%**（基準年比）が義務
  （環境省・経産省資料）。2026年の基準限度は達成見込みとされる（経産省 産業構造審議会資料、2026年3月）
- 国の目標として、HFC冷媒の**加重平均GWPを2030年に450程度、2036年に10程度以下**という水準が示されている
- 米国では **2026年1月以降、新設の住宅・軽商業用HVACはGWP700以下の冷媒が必須**となり、
  R-410Aの新規機器は使えなくなった。Carrier、Trane、Lennox、ダイキンなどは主にR-454BやR-32へ移行した（報道・メーカー資料、2026年）

### 「微燃性（A2L）」という厄介な副作用

低GWP冷媒はたいてい**わずかに燃える**。これが業界全体のコストになっている。

```
 高GWP・不燃（R-410A）          低GWP・微燃（R-32 / R-454B）
   施工が簡単                     ・冷媒漏えい検知器が必要
   誰でも扱える                   ・部屋の広さに応じた充填量制限
   → 規制で使えなくなる            ・工事店の再教育、工具の更新
                                   ・筐体・コイル・制御の設計変更
                                   → 機器価格が上がる
```

- 2026年の米国では、A2L移行・SEER2（効率規制）対応・原材料高・関税が重なり、
  主要メーカーが相次いで値上げを実施したと報じられる
- 日本でも業務用はフロン排出抑制法により**定期点検・漏えい量報告・廃棄時回収**が義務付けられており、
  これが保守ビジネスの法的な土台になっている → [② 儲け方と競争](02_儲け方と競争.md)
- 自然冷媒（CO2・アンモニア）は規制の枠外に出られる利点があるが、高圧設計や毒性対策が必要で、
  いまのところ冷凍冷蔵・給湯・産業用が中心

## 3. 省エネ基準：2027年に日本のエアコンが変わる

日本の省エネ規制は **トップランナー制度**（市場で最も優れた製品の性能を基準に、将来の目標値を決める仕組み）で動く。

| 項目         | 内容                                                                                          |
| ------------ | --------------------------------------------------------------------------------------------- |
| 指標         | **APF**（通年エネルギー消費効率）。1年を通した実使用に近い条件での効率                        |
| 今回の改正   | 家庭用エアコンの目標基準値を**約15年ぶりに引き上げ**。消費電力を最大3割程度抑えることを求める |
| 目標年度     | 壁掛形は**2027年度以降**、壁掛形以外・マルチタイプは2029年度以降                              |
| 市場への影響 | 基準を満たさない低価格モデルの製造・出荷が事実上難しくなる。「エアコン2027年問題」と呼ばれる  |

（資源エネルギー庁「エネこれ」および報道ベース、2026年）

- 効率を上げる手段は主に **熱交換器を大きくする・インバータ制御を賢くする・圧縮機効率を上げる**の3つ。
  いずれも原価が上がるため、**規制強化＝製品単価の上昇**という関係になる
- 業務用エアコンにもトップランナー基準があり、こちらも段階的に強化されている
- 建物側では**建築物省エネ法**が2025年4月に原則全建築物へ適合義務を拡大。
  断熱が良くなると必要な空調能力は下がるが、換気・除湿・制御の要求は上がる
  → [ゼネコン](../../12_建設・住宅・不動産/01_ゼネコン/README.md)、[住宅設備機器](../../12_建設・住宅・不動産/12_住宅設備機器/README.md)

## 4. インバータ化：この業界最大の技術革新

「インバータ」とは、電源の周波数を作り替えてモーターの回転数を自由に変える技術のこと。
これが空調に入った瞬間、機械の性格が変わった。

```
【定速機（インバータなし）】            【インバータ機】

 能力 ┃■■■■    ■■■■               能力 ┃■■■■▂▂▂▂▂▂▂▂▂▂
      ┃    ON      ON                        ┃ 立上りは全力 → 以降は弱く連続運転
      ┃────────────                        ┃────────────────
      ┃  OFF    OFF                           時間                     時間

 ・ON/OFFでしか制御できない             ・必要な分だけ冷やす／暖める
 ・室温が上下に振れる                   ・室温が安定し、消費電力が下がる
 ・起動電流が大きい                     ・部分負荷の効率が劇的に良い
```

- エアコンは**定格出力で運転している時間のほうが短い**。実使用では部分負荷（能力の30〜60%程度）が大半を占める。
  だから「最大能力時の効率（COP）」より「通年の効率（APF）」が重視される
- インバータ化は日本メーカーが1980年代に商品化し、省エネ基準の強化とともに国内でほぼ100%普及した。
  新興国では定速機がまだ多く残っており、**インバータ化そのものが省エネ政策の主要メニュー**になっている
- 中身は可変速モーターとパワー半導体。ここは [モーター](../15_モーター/README.md) と
  [半導体（ロジック・メモリ）](../../03_電機・電子部品/02_半導体（ロジック・メモリ）/README.md) の領域と直結する

## 5. データセンター冷却：空調業界にできた新しい市場

生成AI向けサーバーの発熱が、空調業界に**これまでになかった規模の需要**を作った。

| 世代           | 冷却方式                         | ラック当たり発熱 | 空調側の中身                              |
| -------------- | -------------------------------- | ---------------- | ----------------------------------------- |
| 従来のIT       | 空冷（部屋ごと冷やす）           | 〜10kW程度       | CRAC／CRAH＋チラー                        |
| 高密度化       | 列間空調・封じ込め               | 10〜30kW         | 近接配置の空調機                          |
| **AIサーバー** | **液冷（直接チップ冷却／液浸）** | 50〜130kW超      | **CDU**（冷却液分配装置）＋チラー＋冷却塔 |

```
【空冷】                              【ダイレクトチップ液冷】

 冷たい空気 ──▶ サーバー ──▶ 熱い空気   冷却水 ──▶ コールドプレート（チップに直付け）
     ▲                        │                       │
     └── 空調機 ◀────────────┘                       ▼
                                                    CDU（熱交換）──▶ 冷水 ──▶ チラー ──▶ 冷却塔
 空気は熱を運ぶ能力が低い               水は空気の数千倍の熱容量。高密度でも冷やせる
 → 高発熱では物理的に追いつかない        → 空調メーカーは「チラーとCDUと制御」を丸ごと売れる
```

- ダイキンは北米データセンター冷却事業を2023年度 約230億円から **2025年度 約1,000億円**へ拡大する見通しを示し、
  2030年度に3,000億円超を目指すとしている（ダイキンIR資料、2025年11月）
- 同社は2025年11月に米チルダイン（負圧式液冷システム）を買収し、**空冷（チラー）と液冷（CDU）の両方**を持つ体制にした（報道ベース）
- 三菱重工は液冷スタートアップZutaCoreへの出資（2023年）など、重工系も参入している
- 大型チラーの磁気軸受ターボ圧縮機は、まさにこの用途で需要が伸びている → [① 仕組みと製品分類](01_エアコンの仕組みと製品分類.md)
- 需要側の事情は [データセンター](../../04_情報通信・IT・ネット/03_データセンター/README.md) と
  [生成AI](../../01_注目テーマ/01_生成AI/README.md)、電力制約は [電力](../../11_資源・エネルギー・鉄鋼金属/04_電力/README.md) を参照

> ポイント：データセンター冷却は**一品一様の大型機＋長期保守**という、業務用空調の中でも最も利益率の高い型。
> しかも顧客がクラウド事業者に集中しているため、一度採用されると数百MW単位でまとまって入る。

## 6. 欧州のヒートポンプ暖房：政策で需要が作られ、政策で冷えた

欧州は「暖房を電化する」という政策のもと、ガスボイラーからヒートポンプへの置き換えを進めてきた。
ここは日本メーカーにとって最大の成長市場と目されていたが、**補助金の増減にそのまま振り回されている**。

```
 2021〜22  エネルギー危機でガス価格高騰 ＋ 各国の手厚い補助金
              ↓ 販売が急増。日本勢が欧州に生産拠点を増設
 2024      補助金の打ち切り・縮小、ガス価格の低下、電気料金の高止まり
              ↓ 欧州の販売台数は平均▲23%（ベルギー▲52%、ドイツ▲48%）と報じられる
 2025〜26  各国が支援を再設計。フランスEDFは2026年4月に2.4億ユーロの電化促進策を発表
              （低所得8万世帯に1台1,000ユーロの定額補助）と報じられる
```

| 需要を左右する要因     | 中身                                                                               |
| ---------------------- | ---------------------------------------------------------------------------------- |
| **電気とガスの価格比** | 電気がガスより高いとヒートポンプの運転費メリットが消える。ここが最大の変数         |
| 補助金                 | 本体＋工事で数十万円かかるため、補助の有無で採算が反転する                         |
| 既存設備               | ラジエーターを活かすため**温水式**が必要。低温水で効く設計が求められる             |
| 施工人材               | 設置できる工事業者の数が普及のボトルネック。欧州で約17万人の直接雇用があるとされる |

- 日本勢（ダイキン、三菱電機、パナソニック）は欧州に現地生産を構え、**需要が落ちても投資を継続**している。
  暖房の電化は長期の政策方向として維持されるという読みによる（報道ベース、2024〜2026年）
- 三菱電機の2026年3月期は、欧州の需要回復もあってライフ部門が伸び、全社で4期連続の最高益となった（三菱電機IR、2026年4月）
- 脱炭素の政策全般は [脱炭素・GX](../../01_注目テーマ/05_脱炭素・GX/README.md) を参照

## 7. そのほかの技術トレンド

| トレンド                     | 中身                                                     | なぜ効くか                                                           |
| ---------------------------- | -------------------------------------------------------- | -------------------------------------------------------------------- |
| **遠隔監視・予知保全**       | 機器にIoT通信を載せ、稼働データから故障を予兆検知        | 保守契約の付加価値が上がり、サービス人員の稼働も効率化する           |
| **BEMS／デマンドレスポンス** | ビル全体のエネルギーを制御し、電力需給に応じて空調を調整 | 空調はビル電力の3〜5割。**調整力として電力市場に売れる**可能性がある |
| **換気・空気質（IAQ）**      | CO2濃度・湿度・粒子の制御                                | コロナ禍以降に評価軸として定着。空調と換気の統合商材になる           |
| **除湿・潜熱処理**           | 温度を下げずに湿気だけ取る（デシカント等）               | 日本・東南アジアの高湿度環境で差がつく                               |
| **ヒートポンプの高温化**     | 80〜150℃の熱を作る産業用ヒートポンプ                     | 工場のボイラー置き換え。脱炭素の次の主戦場                           |
| **蓄熱**                     | 夜間に氷や冷水を作って昼に使う                           | 電力ピークをずらせる。再エネ余剰の受け皿にもなる                     |

## 8. 用語メモ

| 用語                     | 意味                                                                                      |
| ------------------------ | ----------------------------------------------------------------------------------------- |
| **ODP**                  | オゾン層破壊係数。R-11を1とした相対値。HFC以降はゼロ                                      |
| **GWP**                  | 地球温暖化係数。CO2の何倍の温室効果があるかを示す。冷媒規制の中心指標                     |
| **モントリオール議定書** | オゾン層破壊物質を規制する国際条約（1987年）                                              |
| **キガリ改正**           | 2016年にモントリオール議定書へ追加された、HFC（代替フロン）の生産・消費を段階削減する改正 |
| **フロン排出抑制法**     | 日本の国内法。業務用冷凍空調機器の点検・漏えい報告・廃棄時回収を義務付ける                |
| **A2L（微燃性）**        | ASHRAE分類のひとつ。わずかに燃える冷媒。R-32、R-454Bなどが該当                            |
| **R-454B**               | 北米の住宅・軽商業用で主流になりつつある低GWP混合冷媒（GWP約466）                         |
| **トップランナー制度**   | 市場最高効率の製品を基準に将来の省エネ目標値を定める日本の制度                            |
| **SEER2**                | 米国の冷房期間エネルギー効率指標。2023年から試験条件が改定された                          |
| **CDU**                  | Coolant Distribution Unit。液冷で冷却液をサーバーへ分配・熱交換する装置                   |
| **ダイレクトチップ冷却** | 発熱するチップに冷却板を直付けして液で熱を奪う方式                                        |
| **BEMS**                 | ビルエネルギー管理システム。空調・照明を統合制御する                                      |
| **デシカント**           | 吸湿材で空気中の水分を取る除湿方式。温度を下げずに湿度だけ下げられる                      |
