# ① エアコンの仕組みと製品分類

このノートで分かること：エアコンは「冷たい空気を作る機械」ではなく、**熱を汲み出して別の場所に捨てる機械（ヒートポンプ）**である。
その一点を理解すると、ルームエアコンからビル用マルチ、チラー、冷凍冷蔵ショーケースまで、全部が同じ原理の親戚だと見えてくる。

## 1. 結論：エアコンは「熱を運ぶポンプ」

暖房で電気ストーブを使うと、電気1kWhは熱1kWh分にしかならない。効率は100%が上限である。
ところがエアコン（ヒートポンプ）は、**外気の中にある熱をかき集めて室内に放り込む**。
電気は「熱を作る」ためではなく「熱を運ぶ」ために使われるので、**投入電力の3〜6倍の熱**を室内に届けられる。

```
【電気ヒーター】                      【ヒートポンプ（エアコン暖房）】

 電気 1 ──▶[ 発熱 ]──▶ 熱 1          電気 1 ──▶[ 圧縮機 ]
                                                  │
 効率の上限 = 1                        外気の熱 3 ─┴──▶ 室内へ 熱 4
                                       （タダの熱を汲み上げる）
                                       効率（COP）= 4
```

- この「投入エネルギーに対して何倍の熱を動かせたか」の比を **COP**（成績係数）という
- 冷房も原理は同じで、**室内の熱を屋外に捨てている**。室外機から熱風が出るのはそのため
- 外気温が下がるほど汲み上げられる熱が減るので、寒冷地では効率が落ちる。
  寒冷地向け機種は圧縮機の能力と着霜対策で、**外気−15〜−25℃でも暖房できる**ように作られている

> ポイント：ヒートポンプは「省エネ家電」である以前に、**電気で熱を作らずに済ませる技術**。
> 各国が暖房の脱炭素化でヒートポンプに殺到する理由はここにある → [③ 規制と技術トレンド](03_規制と技術トレンド.md)

## 2. 冷媒サイクル：4つの部品でぐるぐる回す

熱を運ぶ役目を担うのが **冷媒**（れいばい）という液体・気体だ。
冷媒は「圧力を下げると低温で蒸発し、圧力を上げると高温で凝縮する」という性質を持ち、
蒸発するときに周りから熱を奪い（気化熱）、凝縮するときに熱を吐き出す。
この性質を、**圧力を人工的に上下させて**使い倒すのが冷凍サイクルである。

```
                  ┌──────── 高圧・高温のガス ────────┐
                  │                                    ▼
            ┌───────────┐                      ┌───────────┐
            │  圧縮機    │                      │  凝縮器    │ ← ここで熱を捨てる
            │ (心臓部)   │                      │（室外機の熱交換器）│    （冷房時）
            └───────────┘                      └───────────┘
                  ▲                                    │
                  │                                    ▼
            ┌───────────┐                      ┌───────────┐
            │  蒸発器    │ ← ここで熱を奪う      │  膨張弁    │
            │（室内機の熱交換器）│   （冷房時＝涼しい）  │（圧力を落とす）│
            └───────────┘                      └───────────┘
                  ▲                                    │
                  └──────── 低圧・低温の液 ◀──────────┘
```

| 部品 | 役割 | ひとことで言うと |
| --- | --- | --- |
| **圧縮機（コンプレッサー）** | 冷媒ガスを押し潰して高温高圧にする | 唯一エネルギーを食う部品。**ここが心臓部** |
| **凝縮器（コンデンサー）** | 高温のガスを冷やして液に戻す | 熱を外に捨てる場所 |
| **膨張弁** | 液を細い穴から吹き出させ圧力を一気に下げる | 冷媒を冷たくする場所 |
| **蒸発器（エバポレーター）** | 低温の液が蒸発して周囲から熱を奪う | 冷たくなる場所 |

- 暖房時は **四方弁** で冷媒の流れを逆にし、室内機を凝縮器（熱を吐く側）、室外機を蒸発器（熱を奪う側）に切り替える。
  だから1台で冷房と暖房の両方ができる
- 冬に室外機から湯気が出るのは、蒸発器側に付いた霜を溶かす **デフロスト運転**のため

## 3. 圧縮機が競争力を決める

エアコンの原価・効率・静粛性・信頼性は、圧縮機でほぼ決まる。
メーカーが圧縮機を内製するかどうかが、この業界の実力差を作ってきた。

| 型式 | 原理 | 主な用途 | 特徴 |
| --- | --- | --- | --- |
| **ロータリー** | 円筒の中でローラーが偏心回転 | ルームエアコン、小型 | 安価・小型。量産効果が効く |
| **スクロール** | 渦巻き形の部品をかみ合わせて圧縮 | パッケージ、ビル用マルチ、中型 | 振動が少なく高効率。業務用の主力 |
| **スクリュー** | 2本のねじ状ローターで押し込む | 中〜大型チラー、冷凍機 | 大能力で連続運転に強い |
| **遠心（ターボ）** | 羽根車で加速して圧力を得る | 大型チラー（数百〜数千kW） | 大容量で高効率。**磁気軸受**化で無給油・低損失に |
| **往復動（レシプロ）** | ピストンで圧縮 | 冷凍・冷蔵、低温用 | 低温域に強い。古典的だが現役 |

- **インバータ**（電源周波数を変えてモーター回転数を可変にする技術）で圧縮機の回転数を連続制御できるようになったことが、
  この業界最大の技術革新。詳しくは [③ 規制と技術トレンド](03_規制と技術トレンド.md)
- モーター・磁石の調達力も効いてくる → [モーター](../15_モーター/README.md)
- 大型チラー用の磁気軸受ターボ圧縮機は、いまデータセンター向けで需要が急増している分野でもある

## 4. 製品分類：同じ原理で、売り方がまったく違う

冷凍サイクルという点では全部同じだが、**誰が買い、誰が据え付け、いくらの商売になるか**は製品ごとに別世界である。

| 区分 | 製品 | 能力の目安 | 買う人 | 据付 | 商売の性格 |
| --- | --- | --- | --- | --- | --- |
| 住宅用 | **ルームエアコン**（壁掛け） | 2.2〜7.1kW | 個人 | 街の電気店・量販店の工事 | 量産品。価格競争 |
| 住宅用 | **ハウジングエアコン**（天井埋込・マルチ） | 同上 | 住宅会社・個人 | 住宅設備として同時施工 | 新築と結びつく |
| 業務用 | **パッケージエアコン（PAC）** | 4〜30kW（1.5〜10馬力） | 店舗・事務所 | 空調設備工事会社 | 工事込み。更新需要が太い |
| 業務用 | **ビル用マルチ（VRF）** | 室外機1台に室内機数十台 | ビルオーナー | サブコン・設備工事会社 | 設計段階で機種が決まる |
| 業務用 | **チラー／アプライド機器** | 数百kW〜数MW | 大規模施設・工場・DC | プラント的な設計施工 | 一品一様。保守込み |
| 冷凍・冷蔵 | **冷凍冷蔵ショーケース、業務用冷凍機** | — | スーパー・コンビニ・食品工場 | 専門業者 | 24時間稼働。止められない |
| 輸送 | **輸送用冷凍機**（トラック・コンテナ） | — | 運送・物流 | 車体架装 | 車両と一体 |

```
【個別分散方式】ルームエアコン／パッケージ     【中央熱源方式】チラー＋空調機

  室内機 ── 冷媒配管 ── 室外機              チラー（冷水を作る）
  室内機 ── 冷媒配管 ── 室外機                  │ 冷水7℃
  （部屋ごとに独立。1台壊れても他は動く）        ▼
                                              ポンプ ──▶ 空調機（AHU）──▶ ダクト ──▶ 各階
  ＝日本・アジアの主流                          │
                                            冷却塔（屋上で熱を捨てる）
                                              ＝大規模ビル・工場・データセンターの主流
```

- **ビル用マルチ（VRF＝Variable Refrigerant Flow）は日本メーカーが作り、世界に広げた方式**。
  冷媒を直接ビル内に循環させ、室内機ごとに流量を変える。中央熱源式より工事が軽く、個別課金がしやすい
- 一方、数MW級の熱を扱う大規模施設や [データセンター](../../04_情報通信・IT・ネット/03_データセンター/README.md) では水（冷水）で運ぶチラー方式が主流。
  ここは [ポンプ・バルブ](../17_ポンプ・バルブ/README.md) や配管工事と地続きの世界になる

## 5. 冷凍・冷蔵という、もうひとつの柱

「空調・冷凍機」という業界名の後半、**冷凍機**は快適さではなく **食品を腐らせない** ための機械である。
サイクルの原理は同じだが、要求が違う。

| 軸 | 空調（エアコン） | 冷凍・冷蔵 |
| --- | --- | --- |
| 温度帯 | 室温 20〜28℃前後 | 冷蔵 0〜5℃／冷凍 −20〜−50℃ |
| 稼働 | 季節変動が大きい（夏に集中） | **24時間365日連続** |
| 止まったときの損害 | 不快 | **商品が全損**。だから保守の価値が高い |
| 冷媒の選択 | R-32、R-410A など | CO2（R-744）やアンモニアの採用が進む |
| 買い手 | 個人・テナント | スーパー、コンビニ、食品工場、物流倉庫 |

- スーパー・コンビニの冷凍冷蔵ショーケースでは、**CO2冷媒（R-744）のノンフロン冷凍機**が2010年の商品化以降広がった。
  CO2はフロン排出抑制法の管理対象外になるため、点検・届出の事務負担が減るという実利もある（パナソニック、NEDO資料）
- 買い手側の事情は [食品スーパー](../../07_小売・流通/03_食品スーパー/README.md)・
  [コンビニエンスストア](../../07_小売・流通/01_コンビニエンスストア/README.md)、
  そして [物流施設](../../12_建設・住宅・不動産/16_物流施設/README.md) のコールドチェーン文脈で読むとつながる

## 8. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **ヒートポンプ** | 熱を作らず、低温側から高温側へ汲み上げる仕組み。エアコン・冷蔵庫・エコキュートは全部これ |
| **冷媒** | 熱を運ぶ流体。蒸発・凝縮を繰り返す。種類の選択が規制と直結する → [③](03_規制と技術トレンド.md) |
| **COP** | 成績係数。投入電力に対して何倍の熱を動かせたかの比。ある一点の条件での値 |
| **APF** | 通年エネルギー消費効率。1年を通した実使用に近い条件で測った効率。日本の省エネ基準はこれを使う |
| **圧縮機（コンプレッサー）** | 冷媒を高圧にする部品。エアコンの心臓部で原価・効率の要 |
| **四方弁** | 冷媒の流れを反転させ、冷房と暖房を切り替える弁 |
| **デフロスト** | 暖房時に室外機に付いた霜を溶かす運転。一時的に暖房が止まる |
| **PAC** | パッケージエアコン。店舗・事務所向けの業務用エアコン |
| **ビル用マルチ／VRF** | 室外機1台に多数の室内機をつなぎ、冷媒流量を可変制御する方式。日本発 |
| **チラー** | 冷水（または温水）を作る機械。ダクト・配管で建物中に熱を配る中央熱源方式の中核 |
| **AHU（空調機）** | エアハンドリングユニット。冷温水と空気を熱交換してダクトへ送る箱 |
| **冷却塔（クーリングタワー）** | 水を蒸発させて熱を大気へ捨てる屋上の装置 |
| **馬力（馬力表示）** | 業務用エアコンの能力表示の慣習。1馬力≒2.8kW程度 |
| **CO2冷媒（R-744）** | 自然冷媒のひとつ。GWPが1で規制対象外。冷凍冷蔵・給湯で普及 |
