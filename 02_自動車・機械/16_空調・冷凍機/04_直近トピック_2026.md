# ④ 直近トピック（2026年9月時点）

報道・IR ベースの整理。数値は発表時点のもので、一次情報での裏取りを前提に読むこと。
この1年の空調業界は、**「猛暑で家庭用が売れた日本」「規制で作り替えが起きた北米」「AIデータセンターという新しい柱」「政策次第で揺れる欧州暖房」「日立の撤退に象徴される事業の絞り込み」**の5つで整理できる。

## 1. ダイキン、売上初の5兆円超え。空調・冷凍機が牽引（2026年5月）

| 項目                          | 2026年3月期 実績              | 前期比 |
| ----------------------------- | ----------------------------- | ------ |
| 連結売上高                    | **5兆150億円**（初の5兆円超） | +5.5%  |
| 連結営業利益                  | 4,149億円                     | +3.3%  |
| うち空調・冷凍機事業 売上高   | **4兆6,211億円**              | +5.4%  |
| うち空調・冷凍機事業 営業利益 | **3,770億円**                 | +7.4%  |

- 全社の伸びを空調・冷凍機が牽引した一方、**化学事業（フッ素樹脂等）は苦戦**したと報じられる。
  期中に純利益見通しを下方修正した局面もあった
- 米国の関税影響について、**470億円分を吸収した**と報じられている（2025年5月時点の報道）
- 空調専業でこの規模に達したことが、この業界の「機器だけでなくサービスと地域網で稼ぐ」構造を端的に示す
  → [② 儲け方と競争](02_儲け方と競争.md)

## 2. 記録的猛暑と補助金で、国内ルームエアコンが1,000万台超（2026年4月）

- 2025年度の国内ルームエアコン出荷は **1,002.9万台（前年度比+6.5%）**。
  1,000万台を超えたのは **2020年度以来2度目**と報じられる
- 日本電機工業会（JEMA）によると、2025年度の白物家電の国内出荷額は**2兆6,813億円（+3.8%）**で2年連続のプラス。
  エアコンが全体を押し上げた
- 要因は **記録的猛暑** と、東京都の高効率家電買い替え支援「**東京ゼロエミポイント**」などの自治体補助金。
  同事業は2026年2月に延長・拡充が発表されている

> 読み方：国内の家庭用は**天候と補助金という外生要因で毎年数量が振れる市場**。
> 数量が伸びた年の業績を「構造的な成長」と読むと間違える。
> 見るべきは、単価（高効率機へのシフト）と、翌年の反動の大きさ。

| 振れの要因 | 2025年度の効き方                                                     |
| ---------- | -------------------------------------------------------------------- |
| 夏の気温   | 記録的猛暑で買い替え・新規設置が前倒しされた                         |
| 補助金     | 東京ゼロエミポイント等が実質価格を押し下げた                         |
| 工事能力   | 繁忙期の取付業者不足が供給側の制約になる                             |
| 省エネ規制 | 2027年度基準を控え、低価格帯の駆け込み／高効率機への移行が同時に進む |

## 3. データセンター冷却が「第二の柱」として立ち上がる（2025年11月〜2026年）

- ダイキンは2025年11月に**北米データセンター冷却戦略を説明**。
  同事業の売上を **2023年度 約230億円 → 2025年度 約1,000億円（見通し）→ 2030年度 3,000億円超（目標）**とする計画を示した
- 同時期に米 **チルダイン（Chilldyne）**（負圧式の液体冷却システム）を買収したと報じられ、
  **空冷（チラー）＋液冷（CDU）を一社で提供**する体制を整えた
- AIサーバー向けの大型チラーでは**磁気軸受ターボ圧縮機**が鍵になり、ダイキンは第4世代の開発を進めているとされる（2026年6月時点の同社発信）
- 三菱重工は液冷スタートアップ **ZutaCore** への出資（2023年）を通じてダイレクトチップ液冷に参入、
  液浸・空冷ハイブリッドのコンテナ型データセンターも展開している

```
 AIサーバーの発熱密度              空調メーカーにとっての意味

 従来IT   〜10kW/ラック  ──▶ 空冷で足りる（既存商売）
 AI       50〜130kW/ラック ─▶ 液冷が必須
                              ├─ CDU・冷却板（新規の商材）
                              ├─ 大型チラー（既存の強みが効く）
                              └─ 長期保守（止められない＝サービス単価が高い）
```

## 4. 北米：A2L冷媒への全面移行と値上げ（2026年1月〜）

- **2026年1月以降、米国では新設の住宅・軽商業用HVACに GWP700以下の冷媒が必須**となり、
  R-410A を使う新規機器は事実上販売できなくなった
- Carrier、Trane、Lennox、ダイキン、三菱電機、LG などの主要ブランドは、
  **R-454B** または **R-32** を中心に製品ラインを切り替えた
- 移行には筐体・コイル・制御・漏えい検知の再設計が必要で、**機器価格の上昇**につながった。
  2026年は A2L 対応・SEER2（効率規制）・銅や鋼材の原材料高・関税が重なり、主要メーカーが相次ぎ値上げしたと報じられる

| 影響を受ける側 | 中身                                                   |
| -------------- | ------------------------------------------------------ |
| メーカー       | 製品の全面刷新。在庫の入れ替えとリコールリスク管理     |
| 工事店         | 微燃性冷媒の取り扱い教育、工具・検知器の更新           |
| エンドユーザー | 機器価格の上昇。既設R-410A機の修理用冷媒も逼迫         |
| 部材メーカー   | 漏えい検知センサー、新冷媒対応の潤滑油・シール材に需要 |

- 日本では**フロン排出抑制法**のもとで段階的にGWP規制が進み、キガリ改正に基づく削減義務は2029年▲70%、2036年▲85%。
  2026年の基準限度は達成見込みとされる（経産省 資料、2026年3月）→ [③ 規制と技術トレンド](03_規制と技術トレンド.md)

## 5. 欧州ヒートポンプ暖房：底打ちと政策の再設計（2024年〜2026年）

- 欧州のヒートポンプ販売は2024年に**平均▲23%**（ベルギー▲52%、ドイツ▲48%）と大きく落ち込んだと報じられる。
  原因は**補助金の打ち切り・縮小**、ガス価格の低下、電気料金の高止まり
- 業界団体は欧州委員会に行動計画の早期公表を求め、雇用への影響（少なくとも4,000人が失職、6,000人以上が影響）も指摘された
- 2026年4月、フランスのEDFが **2.4億ユーロの電化促進パッケージ**を発表。
  低所得8万世帯に1台あたり1,000ユーロの定額補助を出し、ガス・石油ボイラーからの切り替えを促すと報じられる
- 日本勢（ダイキン、三菱電機、パナソニック）は需要減のなかでも**欧州の現地生産・開発投資を継続**。
  三菱電機の2026年3月期は欧州の需要回復もあってライフ部門が伸び、全社で**4期連続の最高益**（売上5兆8,947億円、営業利益4,330億円）となった

> 読み方：欧州のヒートポンプ需要は「技術の良し悪し」ではなく、
> **電気料金とガス料金の比率、そして補助金の有無**でほぼ決まる。
> 長期の政策方向（暖房の脱炭素）は維持されるため、各社は短期の落ち込みを織り込んだうえで投資を続けている。

## 6. 事業ポートフォリオの再編：日立が家庭用エアコンから撤退（2025年8月完了）

- 日立製作所は、米ジョンソンコントロールズとの合弁 **ジョンソンコントロールズ日立空調（JCH）** の持分（約4割）を
  **独ボッシュへ売却**。2025年8月に、家庭用エアコン事業の売却と業務用空調拠点の取得を完了した
- 日立の持分売却額は約1,250億円、ボッシュ側の取得総額は約1,950億円規模と報じられる。
  日立は2026年3月期に事業再編等利益として約1,540億円を計上する見込みとされた
- ボッシュ（暖房機器大手）にとっては、**暖房＋空調の世界的ポートフォリオを一気に得る**取引

| 動き                             | 意味                                                       |
| -------------------------------- | ---------------------------------------------------------- |
| 日立：家庭用を手放し業務用へ集中 | 量産品の価格競争から降り、**工事＋保守の商売に寄せる**判断 |
| ボッシュ：空調を取り込む         | 欧州の暖房需要電化に備え、ヒートポンプの製品群を厚くする   |
| 中国勢：台数シェアを維持         | 美的・格力が家庭用の量産を押さえる構図は変わらない         |

- 「住宅用は量産品、業務用は工事とサービス」という本フォルダの見立てを、この再編がそのまま裏書きしている
  → [② 儲け方と競争](02_儲け方と競争.md)

## 7. 2027年度の新省エネ基準（「エアコン2027年問題」）

- 経済産業省は家庭用エアコンのトップランナー目標基準値を**約15年ぶりに引き上げ**。
  壁掛形は**2027年度以降**、壁掛形以外・マルチタイプは2029年度以降が目標年度
- 消費電力を現行比で最大3割程度抑えることが求められ、**基準未達の低価格モデルは実質的に作れなくなる**と見られている
- 業界・流通では「2027年4月を境に安いモデルが消える」「価格が上がる」といった見方が広がり、
  賃貸オーナー向けの買い替え判断記事なども増えている（報道・業界メディアベース、2025〜2026年）

## 8. 全体の構図（まとめ）

1. **数量は天候と補助金、利益は業務用とサービス**。2025年度の国内1,000万台超は猛暑と補助金の産物で、構造的な成長とは別に読む
2. **規制が製品の作り替えを強制している**。北米は2026年1月にA2L全面移行、日本は2027年度から新省エネ基準。どちらも**単価上昇**につながる
3. **AIデータセンターが新しい利益の柱になった**。ダイキンは北米DC冷却を2030年度3,000億円超へ。空冷と液冷の両方を持つ勝負に入った
4. **欧州の暖房電化は政策次第で振れる**。2024年に急減した後、2026年のEDF支援策など再設計が進む。日本勢は投資を継続
5. **ポートフォリオの選別が進む**。日立は家庭用から撤退して業務用に集中、ボッシュは空調を取り込む。「量産品か、工事とサービスか」の線引きが鮮明になった

## 9. 用語メモ

| 用語                     | 意味                                                                                         |
| ------------------------ | -------------------------------------------------------------------------------------------- |
| **東京ゼロエミポイント** | 東京都の高効率家電買い替え支援事業。エアコン・冷蔵庫等の実質価格を下げ、国内需要を押し上げる |
| **A2L**                  | わずかに燃える（微燃性）冷媒の分類。R-32、R-454Bが代表                                       |
| **R-454B**               | 北米の住宅・軽商業用で主流になった低GWP混合冷媒（GWP約466）                                  |
| **SEER2**                | 米国の冷房期間エネルギー効率指標。2023年に試験条件が改定された                               |
| **CDU**                  | 液冷でサーバーへ冷却液を分配・熱交換する装置。データセンター冷却の中核部品                   |
| **磁気軸受ターボ圧縮機** | 磁力で軸を浮かせて無給油運転する大型チラー用の圧縮機。高効率で部分負荷に強い                 |
| **JCH**                  | ジョンソンコントロールズ日立空調。2025年にボッシュへ売却された                               |
| **エアコン2027年問題**   | 2027年度からの新トップランナー基準により、低価格・低効率モデルが市場から消えるとされる論点   |
