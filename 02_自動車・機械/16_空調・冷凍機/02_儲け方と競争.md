# ② 儲け方と競争

このノートで分かること：同じエアコンメーカーでも、**住宅用は「量産品を安く作って大量に売る商売」、業務用は「工事とサービスで稼ぐ商売」**という、まったく別の二つの事業が一社の中に同居している。
そして海外では「気候と住宅のつくりが違うから製品も違う」ため、グローバル展開＝現地化とほぼ同義になる。

## 1. 結論：ひとつの会社に二つの経済学がある

```
【住宅用（ルームエアコン）】              【業務用（PAC／ビル用マルチ／チラー）】

 設計 ─▶ 量産工場 ─▶ 卸／量販店 ─▶ 個人   設計 ─▶ 工場 ─▶ 設備工事会社 ─▶ 施主
                                                        （サブコン・専門工事店）
 勝負どころ                                勝負どころ
 ・原価（圧縮機・熱交換器・モーター）        ・設計段階で仕様に入り込めるか
 ・量販店の棚と販売台数                      ・据付・試運転の品質
 ・年1回のモデルチェンジ                      ・**保守契約の継続**（10〜15年）
                                            ・更新時の入れ替え（リプレース）
 利益率：薄い。季節と天候で数量が振れる     利益率：厚い。景気の波が住宅用より小さい
```

| 軸             | 住宅用                           | 業務用                                                 |
| -------------- | -------------------------------- | ------------------------------------------------------ |
| 買う人         | 個人（ほぼ一生に数回）           | 施主・ビルオーナー・チェーン本部（繰り返し買う）       |
| 決める人       | 買う本人                         | **設計事務所・設備工事会社**（施主ではない場合が多い） |
| 価格の決まり方 | 量販店の店頭価格。比較されやすい | 工事見積もりに紛れ込む。機器単体の比較になりにくい     |
| 利益の出どころ | 機器の粗利 × 台数                | 機器＋据付＋**保守＋更新**                             |
| 需要の波       | 夏の天候で大きく振れる           | 建設投資と更新周期で決まり、比較的なだらか             |
| 競合           | 中国勢・韓国勢を含む総力戦       | 施工力とサービス網を持つ者だけが土俵に乗る             |

> ポイント：**住宅用エアコンは「家電」、業務用エアコンは「設備」**。
> 家電の商売は棚と価格、設備の商売は図面と人（工事・保守）で決まる。
> 同じ冷凍サイクルなのに競争のルールが別物なのは、この違いによる。

## 2. 住宅用：量産品の経済学

ルームエアコンは、原価の大半が **圧縮機・熱交換器（銅・アルミ）・モーター・基板** で占められる部品集約型の製品である。
つまり **材料相場と量産規模がそのまま利益率になる**。

- 銅とアルミの価格が上がると熱交換器の原価が膨らみ、モデルチェンジのタイミングで価格に転嫁する
- 台数が出ないと圧縮機・モーターの内製ラインが遊ぶため、**稼働率の維持が最優先**になる
- 日本の需要は **夏の天候と補助金**で乱高下する。2025年度の国内出荷は1,002.9万台（前年度比+6.5%）で、
  1,000万台超えは2020年度以来2度目。記録的猛暑と東京都の「東京ゼロエミポイント」が効いたと報じられる
  （日本冷凍空調工業会統計・報道ベース、2026年4月）
- 量販店・ECの販路は白物家電と完全に共通 → [白物家電](../../03_電機・電子部品/09_白物家電/README.md)

### 「工事がついてくる家電」という特殊性

ルームエアコンは、買っても**工事しないと使えない**という点で他の白物家電と決定的に違う。

```
 購入（量販店・EC） ──▶ 工事の手配 ──▶ 取付工事（1〜2時間）──▶ 使用開始
                            │
                            └─ ここが夏のボトルネック。
                               猛暑で注文が集中すると「機械はあるが職人がいない」状態になる
```

- 工事費は本体価格の2〜4割に達することもあり、**実質価格は工事込みでしか語れない**
- 取付業者の人手不足は、猛暑年の供給制約として毎年のように報じられる
- この「工事が必要」という性質が、後述する業務用のサービス商売へとつながっていく

## 3. 業務用：工事とサービスが利益の本体

業務用空調は、機器を売った瞬間に商売が終わらない。

```
 ①設計段階          ②機器販売        ③据付工事        ④保守契約        ⑤更新（10〜15年後）
  ↓                  ↓                ↓                ↓                ↓
 設備設計者に       メーカー・        設備工事会社     年◯万円 × 台数   同じメーカーで
 自社方式を         商社が納入        （サブコン）     の継続収入        入れ替わりやすい
 書き込ませる                         が施工
  ↑                                                    ↑
  └──── ここで決まると②〜⑤まで丸ごと取れる ───────────┘
                                                        利益率はここが一番高い
```

| 収益源             | 性格                                               | 利益率のイメージ           |
| ------------------ | -------------------------------------------------- | -------------------------- |
| 機器販売           | 競合と相見積もり。値引き圧力あり                   | 中                         |
| 据付工事           | 工事会社が受け持つことが多い。メーカー直施工もある | 中（人件費次第）           |
| **保守・点検契約** | 年次の定期収入。フロン点検が法律で義務             | **厚い**。景気の波が小さい |
| 部品・修理         | 稼働台数に比例。緊急対応は単価が高い               | 厚い                       |
| 更新（リプレース） | 配管を再利用できるため既設メーカーが有利           | 中〜厚い                   |

- 空調・熱源関連の**保守・メンテナンス市場は国内4,625億円**、うち6割弱をメンテナンス専業会社が占めるとされる
  （富士経済の調査、2020年代の推計）。メーカーはここを取り返しにいっている
- 業務用冷凍空調機器は **フロン排出抑制法**で定期点検が義務。つまり**法律が保守契約の需要を作っている**
  → [③ 規制と技術トレンド](03_規制と技術トレンド.md)
- 冷凍・冷蔵は止まると商品が全損するので、**24時間対応のサービス網そのものが商品**になる

> ポイント：業務用空調の競争力は「良いエアコンを作れるか」ではなく、
> **全国どこでも、壊れた日に人が来るか**で決まる。だから後発が入りにくい。

## 4. 設備工事会社との関係：本当の顧客は誰か

業務用空調でメーカーが向き合う相手は、最終ユーザーではなく **設備工事会社（サブコン・専門工事店）** である。

```
 施主（ビルオーナー・チェーン本部）
   │ 発注
   ▼
 ゼネコン ──▶ サブコン（空調設備工事） ──▶ 専門工事店（配管・ダクト・電気）
                   │ 機器を購入
                   ▼
              空調メーカー／機材商社
```

| 関係者                                                                                        | 役割               | メーカーから見た意味                       |
| --------------------------------------------------------------------------------------------- | ------------------ | ------------------------------------------ |
| 設備設計事務所                                                                                | 仕様書・図面を書く | **ここで機種が決まる**。営業の主戦場       |
| [ゼネコン](../../12_建設・住宅・不動産/01_ゼネコン/README.md)                                 | 建物全体をまとめる | 工期とコストの締め付け役                   |
| [サブコン（空調設備）](../../12_建設・住宅・不動産/02_サブコン（電気・空調・設備）/README.md) | 空調設備一式を施工 | 直接の買い手。値引き交渉の相手             |
| 機材商社・販売店                                                                              | 在庫と与信を持つ   | 地場の小口案件の窓口                       |
| ビル管理会社                                                                                  | 運用と日常点検     | 保守契約の競合でもあり、パートナーでもある |

- メーカーが自前の販売会社・サービス会社を抱えるのは、**工事会社経由だと保守まで取れない**から
- 一方で工事会社を敵に回すと機器が売れない。**売ってもらう相手と保守を奪い合う**微妙な関係が常にある
- 日本の空調設備工事は、高砂熱学工業・新菱冷熱工業・ダイダンといった専業サブコンが担う。
  彼らの受注状況は空調機器需要の先行指標になる

## 5. 気候と住宅構造で、製品が地域ごとに違う

空調は「その土地の気候と建物」に合わせないと売れない、きわめてローカルな商品である。
グローバル展開が難しいのはこの点にある。

| 地域                               | 気候・住宅の特徴                                                   | 主流の製品                                                         |
| ---------------------------------- | ------------------------------------------------------------------ | ------------------------------------------------------------------ |
| **日本**                           | 高温多湿の夏、部屋ごとに暮らす                                     | 壁掛けルームエアコン（個別分散）。除湿性能が重視される             |
| **中国・東南アジア**               | 高温。集合住宅中心                                                 | 壁掛け＋窓用。価格最優先。現地メーカーが圧倒的                     |
| **北米**                           | 広い戸建て、地下室あり、**もともとダクトが通っている**             | ダクト式セントラル空調（ユニタリー）＋ガス炉。壁掛けは少数派       |
| **欧州**                           | 夏は短く冷房需要が小さい。**暖房はガスボイラー＋温水ラジエーター** | 温水式ヒートポンプ（ヒートポンプ暖房機）。冷房用エアコンは南欧中心 |
| **インド・中東**                   | 酷暑・ほこり・電圧不安定                                           | 高外気温でも止まらない設計、窓用・スプリット                       |
| **寒冷地（北海道・北欧・カナダ）** | 外気−20℃でも暖房が要る                                             | 寒冷地仕様。低外気温での能力確保と着霜対策                         |

```
【日本型】 部屋ごとに1台          【北米型】 家に1システム        【欧州型】 温水を循環

  □エアコン  □エアコン            ┌─ ダクト ─┬─ ダクト ─┐       ヒートポンプ
  □エアコン  □エアコン            │          │          │        （屋外）
   ↑ 個別に買い替えできる       [ 熱源1台（屋外＋屋内機）]        │ 温水
   ↑ 賃貸でも設置しやすい        ↑ 既設ダクトが参入障壁          ▼
                                  ↑ 冷暖房＋ガス炉の組合せ      ラジエーター／床暖房
                                                                 ↑ ボイラーの置き換えとして売る
```

- **北米に日本式の壁掛けが広がらなかったのは、家にすでにダクトがあったから**。
  技術の優劣ではなく、住宅ストックの構造が製品を決めている
- 欧州でヒートポンプが「暖房機器」として売られるのは、置き換える相手がガスボイラーだから。
  室内側の配管（ラジエーター）を活かすために温水式になる → [③ 規制と技術トレンド](03_規制と技術トレンド.md)
- つまり**製品を輸出するだけでは勝てない**。現地の商流・工事店・サービス網まで持つ必要がある

## 6. ダイキンのグローバル展開：現地化の教科書

空調専業でありながら世界首位級の売上を持つダイキン工業は、この「現地化」を戦略の中心に置いてきた。

| 手法                    | 具体例                                                                                                                         | 狙い                                                                              |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------- |
| **M&Aで販売網ごと買う** | 2012年 米グッドマン（ダクト式住宅空調の大手）を約3,000億円で買収                                                               | 北米のダクト式市場と流通網を一気に取得                                            |
| **地域ごとの製品開発**  | 各地域に開発・生産拠点を置き、現地仕様で設計                                                                                   | 気候・住宅・電源事情に合わせる                                                    |
| **規格づくりに関与**    | インドやブラジルで冷媒規格の整備に関与したと報じられる                                                                         | 自社が強い冷媒（R-32）が使える土俵を作る                                          |
| **特許の無償開放**      | 2011年に新興国、2015年に全世界へR-32基本特許を開放。2019年に権利不行使を宣言                                                   | 標準を取りにいく。R-32搭載機は他社含め累計2.3億台（2022年12月時点、ダイキン推計） |
| **成長領域への投資**    | 北米データセンター冷却事業を2023年度 約230億円→2025年度 約1,000億円見通し、2030年度3,000億円超を目標（ダイキンIR、2025年11月） | 新しい需要の柱を作る                                                              |

- 2026年3月期の空調・冷凍機事業は売上高 **4兆6,211億円**（前期比+5.4%）、営業利益 3,770億円（+7.4%）。
  全社売上は初の5兆円超（5兆150億円）となった（ダイキンIR、2026年5月）
- **特許を手放して市場を取る**という発想が象徴的。
  冷媒は規制で決まるため、「自社の冷媒が規制に適合する側に立つ」ことが最大の参入障壁になる

- **台数の王者（中国勢）と利益の王者（日米欧の業務用勢）は別**。
  台数で語るか金額で語るかで順位が入れ替わるので、数字を見るときは必ず単位を確認する
- 2025年、日立製作所は家庭用エアコン事業（ジョンソンコントロールズ日立空調の持分）を独ボッシュへ売却し、
  代わりに業務用空調拠点を取得して**業務用に集中する**再編を完了した（報道ベース、2025年8月）。
  「住宅用と業務用は別の商売」という本ノートの見立てを、再編がそのまま裏書きしている

## 8. コスト構造と利益率の目安

```
 売上 100
  ├─ 材料費（銅・アルミ・鋼板・電子部品・冷媒）   40〜55  ← 相場で動く
  ├─ 労務・製造経費                              10〜15
  ├─ 物流費（かさばる・重い）                      5〜10  ← 海上運賃の影響が大きい
  ├─ 販売費（販促・量販店対応・サービス網）        15〜25
  └─ 営業利益                                      5〜12
```

- **空調は「かさばる・重い・季節商品」**という三重苦で物流費が効く。だから消費地の近くで作る
- 業務用・サービス比率が高い会社ほど営業利益率が高くなる傾向がある
- 為替も効く。円安は輸出に有利だが、海外生産・海外販売が主体の企業では**換算の影響のほうが大きい**

## 9. 用語メモ

| 用語                             | 意味                                                                         |
| -------------------------------- | ---------------------------------------------------------------------------- |
| **リプレース（更新）**           | 既設機を新品に入れ替える工事。配管を流用できるため既設メーカーが有利         |
| **サブコン**                     | 設備工事を担う専門工事会社。空調設備はゼネコンの下でこの層が施工する         |
| **機材商社**                     | 空調機器・配管材を在庫し、工事店に与信付きで卸す流通                         |
| **保守契約（メンテナンス契約）** | 定期点検・清掃・部品交換を年契約で請け負う。業務用の安定収益源               |
| **フロン点検義務**               | フロン排出抑制法に基づく業務用冷凍空調機器の定期点検。保守需要の法的な裏付け |
| **ユニタリー**                   | 北米で主流のダクト式住宅用空調システムの総称                                 |
| **温水式ヒートポンプ**           | 空気の熱で温水を作り、ラジエーターや床暖房に流す欧州向けの暖房機             |
| **寒冷地仕様**                   | 低外気温でも暖房能力を保つよう圧縮機・制御を強化した機種                     |
| **R-32**                         | ダイキンが普及を主導した低GWP冷媒。特許を開放して標準化を図った              |
| **グッドマン**                   | ダイキンが2012年に買収した米国の住宅用ダクト式空調メーカー                   |
