# タイヤ｜市場と競争

**このノートで分かること**：世界のタイヤ市場が誰に握られているか、
中国・韓国・インド勢の台頭で何が変わったか、EV化がタイヤに何を要求するか、
そして乗用車以外（鉱山・航空機）とリトレッド（更生タイヤ）という儲かる周辺領域。

> ポイント：タイヤは**上位3社で世界の約4割**という寡占の顔を持ちながら、
> 下の価格帯では数十社が殴り合う**二層構造**の市場になっている。
> 上位勢の戦い方は「シェアを守る」ではなく「高価格帯へ逃げ続ける」に近い。

## 2. アジア勢の台頭

- 中国は**世界のタイヤ供給の4割超**を占めるとされる（業界誌推計、2025年時点）。TBR（トラック・バス用ラジアル）とPCR（乗用車用ラジアル）の両方
- 伸びた理由は単に人件費が安いからではない。**自動化された新設工場を一気に建てたため、1本あたり固定費が低い**
- 米国・EU・インド・ブラジルなどが中国産タイヤに反ダンピング税・相殺関税をかけたため、
  各社は**タイ・ベトナム・カンボジア・メキシコ・セルビアなどに工場を移して迂回**した
- 結果、「中国ブランド＝中国製」ではなくなっている。原産地で見ても実態がつかめない

> 上位勢が取る対抗策は正面からの値下げではなく、**逃げる**こと。
> 高インチ化、OE承認タイヤ、OHT、リトレッドやサービス契約といった、
> 価格表だけでは比較できない領域に軸足を移す。

### 地域ごとの事情

| 地域               | 特徴                                                                               |
| ------------------ | ---------------------------------------------------------------------------------- |
| 北米               | 世界最大のREP市場。ピックアップ・SUV比率が高く大口径が主流。関税政策の影響が大きい |
| 欧州               | 冬用タイヤの義務／推奨地域が広く季節需要が明確。ラベリング規制と Euro 7 の発信地   |
| 日本               | 保有台数が横ばい〜微減で、数量は伸びない成熟市場。スタッドレス需要が下支え         |
| 中国               | 世界最大の生産国かつ大きな内需。価格競争が厳しく、自国勢の海外展開が進む           |
| インド・東南アジア | 二輪・小型車が多く本数は伸びる。現地勢（MRF、アポロ等）が強い                      |

## 3. EV化でタイヤに何が起きるか

EVはタイヤにとって**追い風と逆風が同時に来る**変化になる。

| EVの特性                                                             | タイヤへの要求                             | 結果として起きること                                    |
| -------------------------------------------------------------------- | ------------------------------------------ | ------------------------------------------------------- |
| **電池で車重が重い**（同クラスのガソリン車比で2〜3割重いことが多い） | 高い荷重能力（ロードインデックス、HL規格） | 専用設計が必要。汎用品では持たない                      |
| **モーターは発進時から最大トルク**                                   | 耐摩耗性                                   | 摩耗が早い＝**交換サイクルが短くなる＝REP需要が増える** |
| **エンジン音がない**                                                 | 静粛性（ロードノイズ低減）                 | 吸音スポンジ内蔵などの高付加価値品が売れる              |
| **航続距離が電費に直結**                                             | 低転がり抵抗                               | 「減りにくく、転がり抵抗も低い」という難しい両立が要る  |
| **回生ブレーキ**                                                     | 制動時の挙動が異なる                       | 摩耗の出方が変わり、偏摩耗対策が要る                    |

```
  【逆風】               【追い風】
  重くて摩耗が早い       交換が早く来る → REP本数が増える
  設計要求が厳しい       専用タイヤは単価が高い → ミックス改善
  OEは相変わらず薄利     静粛性・電費が売り文句になり比較されやすい
       └──────────────┬──────────────┘
                       ▼
     開発力のある上位勢に有利に働きやすい構造変化
     （安い汎用品では要求を満たしにくいため）
```

技術的な打ち手は、高分散シリカや高弾性ポリマーによる配合の作り込み、
トレッドパターンの最適化、内側に吸音材を貼る静粛化（ダンロップの「サイレントコア」、
ピレリの「PNCS」など）に集約される。
→ [構造と作り方](01_タイヤの構造と作り方.md) の三すくみの話につながる。

あわせて、EV化そのものの動きは
[注目テーマ｜EV・電動化](../../01_注目テーマ/03_EV・電動化/README.md) を参照。

### 規制の逆風：タイヤ摩耗粉じん

EUの Euro 7 は、排気ガスだけでなく**ブレーキ粉じんとタイヤ摩耗粒子を初めて規制対象にする**。
新型式は2026年11月29日から、全新車は2027年11月29日から適用とされる（報道ベース）。
乗用車用（C1クラス）から摩耗量の測定法が定められ、基準を満たさないタイヤは売れなくなる。

- EVは重いため、摩耗量では不利になりやすい
- 「よく止まる（＝柔らかい）」と「減りにくい」が相反するため、安全性能との調整が論点になる
- 最新の適用時期・限度値は流動的。一次情報（欧州委員会・国交省）での確認が要る

## 4. 乗用車以外：儲かるのは「公道を走らないタイヤ」

| 種別                         | 用途                               | 経済的な特徴                                                                                                                                             |
| ---------------------------- | ---------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **OHT／OTR（鉱山・建機用）** | 露天掘り鉱山のダンプ、油圧ショベル | 直径3〜4mの超大型は1本が乗用車1台分以上の価格になることも。供給できる会社が少なく、鉱山が止まる損失が巨大なため価格交渉力が強い                          |
| **農機用**                   | トラクター、コンバイン             | 収穫期に合わせた供給責任。農機メーカーとの結び付きが強い → [農業機械](../08_農業機械/README.md)                                                          |
| **航空機用**                 | 旅客機の主脚・前脚                 | 型式認証の壁が高く実質数社の寡占。摩耗が速く**リトレッド前提**で運用される。着陸回数課金に近い契約もある → [航空](../../13_運輸・物流/02_航空/README.md) |
| **トラック・バス用（TB）**   | 運送事業者                         | 「走行1kmあたりコスト」で選ばれる。リトレッドとセットで売る                                                                                              |
| **二輪用**                   | オートバイ                         | 銘柄指向が強く、サーキット由来のブランド価値が効く → [二輪車](../04_二輪車/README.md)                                                                    |

```
  乗用車REP  ──────────── 競争が激しい。価格比較サイトで横並びにされる
  TB＋リトレッド ───────── 事業者は総コストで選ぶ。サービス契約にできる
  OHT／鉱山 ────────────── 供給責任に対価が付く。参入者が少ない
  航空機 ───────────────── 認証の壁。事実上の寡占
         ↑ 上に行くほど「値段だけで比較されない」＝利益率が高い
```

## 5. リトレッド（更生タイヤ）：使い切らずに、台枠を何度も使う

リトレッドとは、**摩耗したトレッド（接地面）だけを削り取り、新しいゴムを貼って加硫し直す**こと。
骨格（カーカス）はそのまま再利用する。

```
  使用済みタイヤ
      │
      ▼
  【1】検査（カーカスが再利用できるかX線・目視で判定）
      │      ← ここで落ちると再生できない。台枠の品質がすべて
      ▼
  【2】バフ研磨（古いトレッドを削る）
      │
      ▼
  【3】新しいトレッドゴムを貼る
      │    ・プレキュア方式：加硫済みトレッドを接着（低温・設備が軽い）
      │    ・リモールド方式：未加硫ゴムを貼って金型で加硫（新品に近い仕上がり）
      ▼
  【4】加硫 → 検査 → 出荷
```

| 観点           | 中身                                                                                                        |
| -------------- | ----------------------------------------------------------------------------------------------------------- |
| 誰が使うか     | トラック・バス、航空機、建機・鉱山。**乗用車ではほとんど使われない**                                        |
| なぜ成り立つか | 材料使用量が新品より大幅に少なく、価格は新品の6〜7割程度。事業者にとって走行1kmあたりコストが下がる         |
| メーカーの旨み | **自社の新品を売った顧客を囲い込める**。台枠が自社製であるほど再生しやすい。サービス収益として継続する      |
| 環境面         | 資源・CO2の削減になるため、脱炭素の文脈で追い風 → [脱炭素・GX](../../01_注目テーマ/05_脱炭素・GX/README.md) |
| 注意点         | 台枠の劣化管理が生命線。点検・空気圧管理サービスとセットで初めて回る                                        |

ブリヂストンが中期計画で「小売サービス、リトレッド、鉱山・航空ソリューション」を
成長事業と位置づけ、2026年に売上収益4.8兆円レベル・調整後営業利益率13%レベルを目標に
掲げているのは、この**サービス化＝価格競争から降りる**戦略の表れになる（同社IR）。

## 6. リサイクルと廃タイヤ

- 日本では廃タイヤの多くが**熱利用（セメント工場や製紙工場の燃料）**に回っており、素材としての再生は一部
- 近年は**ケミカルリサイクル**（熱分解で油やカーボンブラックを回収）や、
  タイヤからタイヤへ戻す取り組みが各社で進むが、コストが課題
- EUを中心に再生材・バイオ由来材料の使用比率を上げる目標が置かれ始めている
- → [金属リサイクル](../../11_資源・エネルギー・鉄鋼金属/14_金属リサイクル/README.md) と同様、
  「回収の物流をどう組むか」が事業化の壁になる

## 7. 競争の軸を一枚にまとめると

| 軸                                 | 効くところ                               | 上位勢の優位               |
| ---------------------------------- | ---------------------------------------- | -------------------------- |
| 配合・設計の技術力                 | 三すくみ（燃費・ウェット・摩耗）を広げる | ◎ 研究開発の蓄積が効く     |
| ブランド                           | REPの指名買い、値決め力                  | ◎ 百年単位の蓄積           |
| 販売網・小売                       | 価格コントロール、点検データ             | ◎ 直営・系列を持つ社が有利 |
| 生産コスト                         | 汎用サイズの価格勝負                     | △ 新興勢の新工場に分がある |
| OE採用                             | 将来のREPの種まき                        | ○ 高級車では上位勢が優位   |
| サービス化（リトレッド・車両管理） | 価格比較からの離脱                       | ◎ 事業者向けで差がつく     |

## 用語メモ

- **PCR**：Passenger Car Radial。乗用車用ラジアルタイヤ
- **TBR／TB**：Truck & Bus Radial。トラック・バス用ラジアルタイヤ
- **OTR／OHT**：Off-The-Road／Off-Highway Tire。鉱山・建機・農機など公道外の機械用
- **リトレッド（更生タイヤ）**：摩耗したトレッドを貼り替えて再生したタイヤ
- **台枠（ケーシング）**：リトレッドで再利用する骨格部分。使用済みタイヤの中身
- **プレキュア／リモールド**：リトレッドの2方式。前者は加硫済みトレッドを接着、後者は金型で加硫
- **HL規格**：High Load。EV等の重い車両向けに荷重能力を高めたタイヤ規格
- **反ダンピング税**：不当廉売とみなされた輸入品にかける追加関税。中国産タイヤに各国が発動
- **Euro 7**：EUの次期排出規制。タイヤ摩耗粒子とブレーキ粉じんを初めて対象にする
- **ラベリング**：転がり抵抗・ウェットグリップ等の等級表示制度。EUと日本で運用が異なる
