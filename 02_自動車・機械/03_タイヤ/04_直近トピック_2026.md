# タイヤ｜直近トピック（2026年9月時点）

報道・各社IR ベースの整理。一次情報（各社ニュースリリース、JATMA統計、欧州委員会）で必ず裏取りすること。
数値は公表時点のものを記載しており、以後の修正はありうる。

## 1. 国内市販用タイヤの値上げが常態化（2026年9月1日）

- ブリヂストンは**2026年9月1日出荷分から、国内市販用タイヤのメーカー出荷価格を平均5%改定**すると発表（同社ニュースリリース、2026年6月15日）。夏タイヤ・スタッドレスの双方が対象
- 同日付でダンロップ（住友ゴム）が約6%、横浜ゴムが約5%の改定を実施したと報じられている（流通各社・業界メディア報道ベース）
- 理由として各社が挙げるのは、**天然ゴムをはじめとする原材料価格、エネルギー、物流費の上昇**
- 構造的に見ると、これは [儲け方の構造](02_儲け方の構造.md) で述べた
  「**REPは値上げできるがOEは上げにくい**」という非対称性がそのまま現れた動き。
  値上げは市販用（REP）に対して行われ、新車装着用（OE）の価格は個別契約のまま動かない

> 販売現場では「値上げ実施日の直前に駆け込み需要が出て、直後に反動減が来る」という
> 需要の前倒しが毎回起きるため、四半期の数量比較を見るときは改定日との関係に注意が要る。

## 2. 原材料：天然ゴム相場の高止まり

- 汎用グレードの指標である **TSR20**（タイ産標準ゴムの規格）は、2026年時点で前年比+30%前後の水準にあると報じられている（Sunsirs等の商品市況情報）
- 上昇の背景は、産地（タイ・インドネシア・ベトナム）の天候不順、ゴム林の老齢化と植え替え遅れ、労働力不足といった**供給側の制約**とされる
- タイヤメーカーは通常数ヶ月分の在庫を持つため、**相場上昇が損益に出るのは1〜2四半期遅れる**。
  決算の「原材料要因」は当期ではなく前期の相場を反映していることが多い

```
  天然ゴム相場 ↑ ──（在庫消化 1〜2四半期）──▶ 売上原価 ↑
                                                    │
                       価格改定の発表 ──（流通在庫 1〜2ヶ月）──▶ 売価 ↑
                                                    │
                       ＝ コスト増が先、値上げ効果が後。その間の四半期は利益が凹む
```

## 3. 米国の関税がコストと収益を揺らしている

- グッドイヤーは2026年第1四半期に**関税コスト 5,800万ドル**を計上し、
  これを**推定 4,600万ドルの関税還付**で一部相殺したと開示している（同社 8-K／10-Q、2026年）
- 関税の対象は完成タイヤだけでなく、**天然ゴム・合成ゴム・カーボンブラック・スチールコード等の原材料**にも及ぶとされ、米国内生産であってもコストが上がる構図になっている
- 従来から中国産タイヤには反ダンピング税・相殺関税がかかっており、各社はタイ・ベトナム・カンボジア・メキシコ等へ生産を移してきた。追加関税はその迂回ルートにも影響しうる
- 北米は世界最大のREP市場であるため、ここでのコスト増は各社の利益率に直結する

## 4. EUDR（EU森林破壊防止規則）— 天然ゴムの調達が「証明できるか」勝負に

- EUDRは2023年6月に発効した規則で、対象7品目に**天然ゴム**が含まれる。
  ゴム製空気入りタイヤなどの**加工された派生品もEU域内で扱うには対象**になる
- 事業者は、その天然ゴムが**2020年12月31日以降に森林破壊された土地で生産されていないこと**を、
  産地の位置情報（ジオロケーション）付きで示すデュー・ディリジェンス申告が必要になる
- 適用時期は二度の延期を経て流動的。**大規模事業者は2026年12月30日から、小規模・零細事業者は2027年6月30日から**とする整理が報じられている（最新は欧州委員会・JETRO等の一次情報で要確認）
- 実務上の影響は既に出ており、天然ゴム市場が**EUDR対応品と非対応品に分かれ、対応品にプレミアムが付く**状況になっていると業界紙が伝えている
- 天然ゴムの多くは東南アジアの**小規模農家（スモールホルダー）**から集荷されるため、
  誰の畑から来たかを追跡すること自体が難しい。ここがコスト要因になる

```
  小規模農家（数百万戸）→ 集荷人 → 加工工場 → 商社 → タイヤメーカー → EU市場
       ▲                                                         ▲
       └── ここの位置情報を確定させる必要がある ──────────────────┘
           （従来は混ざってしまえば出所が分からなかった）
```

## 5. Euro 7：タイヤ摩耗が初めて規制される

- EUの次期規制 **Euro 7** は、排気ガスに加えて**ブレーキ粉じんとタイヤ摩耗粒子**を初めて規制対象にする
- 適用は**新型式が2026年11月29日から、全新車が2027年11月29日から**とされる（報道ベース）
- 乗用車用（C1クラス）タイヤについて、直径1.7m以上のドラム試験機を用いる国連（UNECE）の標準試験法が整備され、摩耗量を測ることになる
- **EVは車重が重く摩耗量で不利**になりやすいため、EV普及と摩耗規制が同時に来る点が各社の課題
- タイヤ側から見ると、これは「よく止まる＝柔らかい」と「減りにくい＝硬い」の
  トレードオフに、第三の制約が加わることを意味する（[構造と作り方](01_タイヤの構造と作り方.md) の三すくみ）

| 規制                 | 対象                           | いつから                                    | タイヤへの含意                             |
| -------------------- | ------------------------------ | ------------------------------------------- | ------------------------------------------ |
| EUDR                 | 天然ゴムの由来                 | 大規模2026年12月／小規模2027年6月（流動的） | 調達コスト増、トレーサビリティ投資         |
| Euro 7               | タイヤ摩耗粒子・ブレーキ粉じん | 新型式2026年11月／全新車2027年11月          | 摩耗性能が販売可否の条件に。配合設計の制約 |
| 各国の反ダンピング税 | 中国等からの輸入タイヤ         | 継続中                                      | 生産地の再配置が続く                       |

## 6. 国内需要は緩やかな縮小。JATMAの見通し

日本自動車タイヤ協会（JATMA）の**2026年 国内四輪車用タイヤ需要見通し**は次の通り。

| 区分          | 本数            | 前年比 |
| ------------- | --------------- | ------ |
| 新車用（OE）  | 約3,648万本     | 約1%減 |
| 市販用（REP） | 約6,397万本     | 約2%減 |
| **合計**      | **約1億46万本** | 微減   |

（2025年末公表の当初見通し。2026年の年央見直しでは総需要 約1億153万本＝前年比98%、
新車用 約3,705万本＝同100%、市販用 約6,448万本＝同98% と報じられている）

- 本数ベースで **OE:REP ≒ 36:64**。金額ベースではREPの比重がさらに高い
- 国内は保有台数が横ばい〜微減で、**数量では伸びない成熟市場**。各社の国内戦略は
  高インチ化・冬タイヤ・小売サービスによる**単価と粗利の引き上げ**に寄っている

## 8. 全体の構図（まとめ）

1. **コスト側**は、天然ゴム高・関税・物流費・規制対応（EUDR、Euro 7）の四重苦で上がり続けている
2. **転嫁側**は、REP（市販用）で年1〜2回の値上げを打てるが、OE（新車用）はほぼ動かせない。
   この非対称性ゆえに、**REP比率と高インチ比率が各社の利益の分かれ目**になっている
3. **需要側**は、日本を含む先進国の本数は横ばい〜微減。数量ではなく単価で伸ばす市場に変質した
4. **競争側**は、中国・韓国勢が数量で下から押し上げ、上位勢は高価格帯とサービスへ上へ逃げる
5. **EV化**は摩耗を早めてREP本数を増やす追い風であると同時に、Euro 7の摩耗規制という逆風も連れてくる。両立できる開発力を持つ企業が有利になりやすい

## 用語メモ

- **TSR20**：タイ産などの標準ゴム規格。天然ゴムの汎用グレードの価格指標。先物も上場している
- **EUDR**：EU森林破壊防止規則。天然ゴムを含む7品目とその派生品が対象
- **デュー・ディリジェンス申告**：EUDRで求められる、産地の位置情報を含む調達確認の申告
- **スモールホルダー**：天然ゴムを生産する小規模農家。追跡可能性の難所
- **Euro 7**：EUの次期排出規制。タイヤ摩耗粒子とブレーキ粉じんを初めて対象にする
- **反ダンピング税／相殺関税**：不当廉売・補助金付き輸入に課す追加関税
- **ミックス改善**：高インチ・高付加価値品の構成比を上げて利益率を高めること
- **年央見直し**：JATMAが年の途中で需要見通しを改訂すること
