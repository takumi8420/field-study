### 最初に押さえる一行

> **タイヤメーカーは自動車部品メーカーの顔をした消費財ブランド企業である。**
> 新車に付けるタイヤ（OE）はほとんど儲からず、その後の交換需要（REP）で稼ぐ。

## 1. 業界の定義・範囲

自動車・二輪車・航空機・建設機械・農業機械などが路面（滑走路・地面）と接する
**ゴム製の車輪外装**を作る産業。ゴム工業の一部だが、以下の点で他のゴム製品と性格が違う。

| 隣接領域                                                          | 境界                                                                                     |
| ----------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| [合成ゴム](../../10_素材・化学/14_合成ゴム/README.md)             | **原料側**。SBR・BRなどのポリマーを作って売る化学産業。タイヤメーカーの仕入先            |
| [炭素・カーボン](../../10_素材・化学/13_炭素・カーボン/README.md) | 補強充填剤（カーボンブラック）の供給側                                                   |
| [自動車部品](../02_自動車部品/README.md)                          | 一般の部品はOE中心だが、タイヤは**交換需要が主戦場**。系列に組み込まれにくく独立性が高い |
| ホイール                                                          | 金属部品で別産業。タイヤメーカーは通常作らない                                           |
| チューブ・ベルト等の工業用ゴム                                    | 同じゴム工業だが、ブランドと交換市場を持たない点で経済が異なる                           |

タイヤ業界の中は、需要側で **乗用車用（PCR）／トラック・バス用（TB）／
OHT（鉱山・建機・農機）／航空機用／二輪用** に分かれ、
売り先で **OE（新車装着）／REP（市販交換）** に分かれる。この2軸の掛け算で考えると整理しやすい。

## 2. 市場規模と成長性

- 世界のタイヤ市場は概ね2,000億ドル規模とされる（各種調査会社の推計。定義により幅がある）
- 上位企業の規模感は、2024年実績ベースでミシュラン 約257億ドル、ブリヂストンが同程度、グッドイヤー 174.7億ドル（業界誌 European Rubber Journal の推計および同社開示）
- **国内は成熟市場**。JATMAの2026年 国内四輪車用タイヤ需要見通しは
  総需要 約1億46万本（新車用 約3,648万本／市販用 約6,397万本）で微減
- 成長性は本数ではなく**単価**にある。高インチ化、EV向け、生産財（鉱山・農機）、リトレッドを含むサービス
- 中国が世界供給の4割超を占めるとされ、数量の重心はすでにアジアにある（業界誌推計、2025年時点）

## 3. バリューチェーン（川上 → 川下）

```
【川上：原材料】                【中流：製造】              【川下：流通・使用】
天然ゴム（タイ/インドネシア/ベトナム）
合成ゴム（石化メーカー）        練り → 押出・圧延        ┌─▶ 自動車メーカー（OE）
カーボンブラック／シリカ  ──▶  → 成形 → 加硫 → 検査 ──┤     ※薄利。だが将来のREPの種
スチールコード／繊維コード      （設備産業。金型と         │
配合薬品（硫黄・老化防止剤）      加硫機が能力を決める）    └─▶ 卸・専業店・量販店・通販
                                                               ディーラー・法人直販（REP）
                                                                    ※ここが利益の本命
                                        ┌──────────────────────────┘
                                        ▼
                             使用 → 摩耗 → 交換（3〜5年）
                                        │
                                        ├─▶ リトレッド（TB・航空機・鉱山）
                                        └─▶ 廃タイヤ → 熱利用・リサイクル
```

付加価値が集まるのは **(1) 配合設計などの技術、(2) ブランド、(3) 川下の販売・サービス網** の3点。
製造そのものは差がつきにくく、新興勢の自動化工場に価格で追われる領域になっている。

## 5. 収益モデル・コスト構造

**この業界の核心はここにある。→ 詳細は [儲け方の構造](02_儲け方の構造.md)**

| 区分                | 売り先                   | 価格決定                           | 収益性   | 数量の性質                 |
| ------------------- | ------------------------ | ---------------------------------- | -------- | -------------------------- |
| **OE（新車装着）**  | 自動車メーカー           | 相見積り＋年次値下げ要求           | **薄い** | 新車生産に完全連動＝循環的 |
| **REP（市販交換）** | 卸・店舗・消費者・事業者 | 希望価格＋店頭競争。ブランドが効く | **厚い** | 保有台数×走行距離＝安定的  |

- 1台のクルマは生涯で **OE 4本に対し REP 10〜20本** を消費する。日本の本数比でも **OE:REP ≒ 36:64**
- OEをやる理由は利益ではなく、**純正指名によるREPの種まき、ブランド証明、サイズの標準化、技術の実証**
- 原材料は売上原価の概ね3〜4割（各社IRからの目安）。天然ゴム・合成ゴム・カーボンブラック・スチールコード
- 残りは**減価償却・人件費・エネルギー・物流**という固定費。
  金型は原則1サイズ1型、加硫機は1本15分前後を占有するため、**稼働率が落ちた瞬間に利益が飛ぶ**
- 価格転嫁は非対称。原材料高はREPの値上げで取り返せるが、OEは契約期間中ほぼ動かせない

## 6. 競争要因（KSF）と参入障壁

| 要因                 | 中身                                                                               |
| -------------------- | ---------------------------------------------------------------------------------- |
| **ブランド**         | REPは指名買いが成立する数少ない自動車関連商材。百年単位の蓄積がそのまま参入障壁    |
| **配合・設計技術**   | 転がり抵抗・ウェットグリップ・耐摩耗の三すくみを広げる力。レシピは秘匿されている   |
| **販売・サービス網** | 直営小売、整備、リトレッド、車両管理。価格比較から離脱する唯一の道                 |
| **設備と稼働率**     | 金型と加硫機の物量が能力。需要地近接が原則で、輸送効率が悪いため各地に工場が要る   |
| **OE承認の実績**     | 完成車メーカーの評価を通ること自体が技術の証明になり、高級車では強い参入障壁になる |
| **規模の経済**       | 原材料の調達力、研究開発費の分散                                                   |

逆に**参入しやすい部分**もある。汎用サイズのREPは技術要求が相対的に低く、
自動化した新工場を建てられれば価格で戦える。ここを中国・インド勢が取った。

## 7. 規制・法制度

| 制度                     | 内容                                                                                                                                      |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------- |
| 保安基準（日本）         | 残溝1.6mm（スリップサイン）が使用限度。速度記号・荷重指数の表示義務                                                                       |
| ラベリング制度（日本）   | JATMAの自主基準。転がり抵抗 AAA〜C、ウェットグリップ a〜d。低燃費タイヤの定義                                                             |
| EUタイヤラベル           | 転がり抵抗・ウェットグリップ・騒音の等級表示が義務                                                                                        |
| **Euro 7**（EU）         | 排気に加え**タイヤ摩耗粒子・ブレーキ粉じん**を初めて規制。新型式2026年11月29日／全新車2027年11月29日（報道ベース）                        |
| **EUDR**（EU）           | 森林破壊防止規則。天然ゴムとその派生品（タイヤ）が対象。適用は延期を経て大規模事業者2026年12月30日、小規模2027年6月30日とされる（要確認） |
| TPMS義務化               | 空気圧監視システムの新車装着義務（米・EU等）                                                                                              |
| 反ダンピング税・相殺関税 | 中国等からの輸入タイヤに各国が発動。生産地の再配置を促す                                                                                  |
| 資源有効利用・廃タイヤ   | 日本では廃タイヤの多くが熱利用。再生材使用比率の目標設定がEUを中心に進む                                                                  |

## 8. 最近のトピック

詳細と出典は **[直近トピック_2026](04_直近トピック_2026.md)**。

1. **2026年9月1日に国内市販用タイヤの価格改定**。ブリヂストン平均5%、ダンロップ約6%、横浜ゴム約5%（各社リリース・報道）
2. **天然ゴム相場の高止まり**。TSR20は前年比+30%前後と報じられ、在庫期間の分だけ遅れて損益を圧迫
3. **米国の関税**。グッドイヤーは2026年Q1に関税コスト5,800万ドルを計上（同4,600万ドルの還付見込みで一部相殺）
4. **EUDRとEuro 7**。天然ゴムのトレーサビリティと、タイヤ摩耗の性能規制という二つの新しい制約
5. **各社はサービス化と生産財シフトへ**。ブリヂストンは小売・リトレッド・鉱山/航空を成長領域に、横浜ゴムは消費財:生産財を1:1へ
