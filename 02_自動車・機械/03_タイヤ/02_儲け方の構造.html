タイヤ｜儲け方の構造（OEとREPの二本立て）

自動車・機械タイヤ
あこのページの単語集用語に触れると意味を確認できます10語
OE（Original Equipment）REP（Replacement）／RE／アフターマーケット純正指名承認タイヤ（MO、N0、RO1など）高インチ化消費財／生産財OHT（Off-Highway Tire）ミックス改善価格改定廃タイヤ処理料

このノートで分かること：タイヤメーカーの利益がどこから出ているか。
結論から言うと、新車に付けるタイヤ（OE）はほとんど儲からず、
その後の交換需要（REP）で稼ぐ。この一点がタイヤ業界の理解の核心になる。

ポイント：タイヤメーカーは自動車部品メーカーの顔をしているが、
実態は消費財ブランド企業＋交換サービス業に近い。
新車に装着されることは「売上」ではなく「広告と種まき」だと考えると腑に落ちる。

1. OEとREPという二つの市場

区分 正式には 誰に売るか 誰が使うか 価格の決まり方
OE（オーイー）Original Equipment＝新車装着用自動車メーカー（完成車工場）新車を買った人（選べない）車種開発時の相見積り＋年次の値引き要求
REP（レップ）Replacement＝市販交換用卸・販売店・量販店・通販摩耗したタイヤを替える人（選べる）メーカー希望価格＋店頭競争。ブランドが効く

英語圏ではREPを RE（Replacement） や アフターマーケット とも呼ぶ。
日本の統計（JATMA）では「新車用」「市販用」と書かれる。同じものを指す。

2. 1台のクルマが生むタイヤ需要

   新車が1台できる                その後 10〜15年、保有され続ける
        │                                      │
        ▼                                      ▼
  ┌───────────┐            ┌──────┬──────┬──────┬──────┐
  │ OE 4本    │            │ REP  │ REP  │ REP  │ REP  │ ...
  │（＋スペア）│            │ 4本  │ 4本  │ 4本  │ 4本  │
  └───────────┘            └──────┴──────┴──────┴──────┘
   一度きり                   3〜5万km／3〜5年ごとに繰り返す
                              （冬用を履く地域はさらに+4本）

  ＝ 生涯で 1台あたり OE 4本 : REP 10〜20本 ほどの比率になる

日本の実数でも同じ形が確認できる。JATMA（日本自動車タイヤ協会）の
2026年 国内四輪車用タイヤ需要見通しは、総需要 約1億46万本、
内訳は新車用 約3,648万本／市販用 約6,397万本（2025年末公表時点。
2026年の年央見直しでは総需要 約1億153万本、新車用 約3,705万本、市販用 約6,448万本）。
本数ベースですでに OE:REP ≒ 4:6、金額ベースではさらに差が開く。

3. なぜOEは儲からないのか

理由は買い手の性質にある。

  1. 買い手が巨大で、価格の主導権を握っている
    完成車メーカーは1車種で年間数十万本を買う。相見積りで数社を競わせられる
  2. 年次値下げが慣行
    自動車部品と同じく「毎年◯%のコストダウン」を織り込む商習慣がある
    → 自動車部品 の系列・コストダウンの構造と同じ
  3. 仕様が指定される
    車種ごとに転がり抵抗・乗り心地・静粛性の目標値が与えられ、専用開発が必要。開発費はかかるのに単価は上げにくい
  4. 数量が完成車の生産台数に完全連動する
    減産されれば即座に数量が消える。景気と半導体不足などの影響をそのまま受ける

それでもOEを取りに行く4つの理由

理由 中身
REPへの種まき新車装着タイヤが減ったとき、同じ銘柄を買い直す人が一定数いる（純正指名）。装着シェアは数年後のREPシェアに効く
ブランドの証明「このクルマの標準装着はミシュラン」という事実そのものが広告になる。とくに高級車・スポーツカー
サイズの標準化自社が得意なサイズを新車に載せられれば、そのサイズの交換市場を先取りできる
技術の実証完成車メーカーの厳しい評価基準を通ること自体が開発力の鍛錬になる

高級車向けには、メーカー承認の刻印（ミシュランの「MO」「N0」、
ブリヂストンの「MOE」「RO1」など車種専用の識別記号）が付く。
これはOEを起点に高単価REPへ誘導する仕組みでもある。

4. REPが本命である理由

  • 買うのは個人・事業者で、比較検討の軸が価格だけではない（安心、静粛性、燃費、冬性能）
  • ブランドが指名買いを生む。「レグノ」「ミシュラン」のような銘柄指名が成立する
  • 販売店を通すため、値崩れがOEほど直接的でない
  • 需要が保有台数に紐づく。新車が売れない年でもタイヤは減り続けるので、景気耐性が高い
  • 冬用タイヤ、ランフラット、大口径など高付加価値品を出しやすい
   新車販売台数（毎年の増減が激しい）  ────▶ OE需要（振れ幅が大きい）
   自動車保有台数（ゆっくりしか動かない）──▶ REP需要（安定した土台）
                                              ＋走行距離（景気・燃料価格で増減）

つまりOEは循環的（シクリカル）、REPは構造的（ストック）。
決算説明で各社が「REP比率」「高インチ比率」を強調するのはこのため。

5. 儲けの階段：どこが厚いか

領域 収益性の目安 なぜそうなるか
OE 乗用車用（小径・量販車種）最も薄い完全な競争入札。数量は出るが単価が上がらない
REP 乗用車用（標準サイズ）中位中国・韓国勢を含む価格競争がある
REP 乗用車用（18インチ以上・高性能）厚い代替品が少なく、選ぶ人が価格より性能を見る
TB（トラック・バス用）＋リトレッド厚い運送事業者にとっては「走行1kmあたりコスト」勝負。サービス込みで売れる
OHT（鉱山・建機・農機）最も厚い参入者が少なく、止まると顧客の損失が巨大。供給責任に対価が付く
航空機用特殊認証の壁が高く、実質的に数社の寡占。リトレッド前提の運用

各社が中期計画で「消費財（乗用車用）と生産財（トラック・OHT）の比率を見直す」と言うのは、
この階段の上の方に資源を移す、という意味になる。横浜ゴムは中期計画「YX2026」で
4:1だったタイヤ消費財と生産財の売上構成比を1:1に近づける方針を掲げ、
2026年度に売上収益1兆1,500億円・事業利益1,300億円・事業利益率11%を目標としている（同社IR）。

6. 販売網：REPで勝つにはチャネルが要る

  タイヤメーカー
      ├─▶ 直営／系列小売（ブリヂストンのタイヤ館、ミシュランのユーロマスター等）
      │        → 最も利幅が取れる。整備・点検までセットで抱え込める
      ├─▶ タイヤ専業店・整備工場（卸経由）
      ├─▶ カー用品量販（オートバックス、イエローハット など）
      │        → [家電量販型の小売構造](../../07_小売・流通/06_家電量販/README.md) に近い価格競争
      ├─▶ 自動車ディーラー（純正交換需要）
      ├─▶ ネット通販＋取付店（持ち込み装着）
      │        → 価格透明化が進み、メーカー希望価格が効きにくくなった領域
      └─▶ 法人直販（運送会社・レンタカー・カーシェア・鉱山会社）
               → [陸運・トラック](../../13_運輸・物流/06_陸運・トラック/README.md) の車両管理と直結

小売を自社で持つかどうかが各社の性格を分ける。
小売網を持てば価格と在庫をコントロールでき、点検データも取れるが、店舗の固定費を背負う。
ブリヂストンが北米で小売・リトレッド網を重視するのは、
タイヤ単品の値段勝負から「使用期間あたりのサービス料金」へ軸をずらすためでもある。

7. コスト構造と、価格転嫁の効きかた

売上原価のうち原材料が占める割合は概ね3〜4割とされ（各社IR資料からの目安）、
残りが人件費・減価償却・エネルギー・物流になる。効いてくる変数は次の4つ。

変数 動くとどうなるか 転嫁までの時間差
天然ゴム価格商品市況。産地（タイ・インドネシア・ベトナム）の天候と作付けで動く在庫を数ヶ月持つため、損益に出るのは1〜2四半期遅れ
合成ゴム・カーボンブラック原油・ナフサ連動 → 石油化学同上
海上運賃・物流費タイヤは軽くて嵩張るので運賃感応度が高い比較的すぐ効く
為替海外生産・海外販売比率が高いため、円安は円建て利益を押し上げる即時

価格転嫁の非対称性

  原材料が上がる  ──▶ REPは値上げを発表できる（例：国内は年1〜2回の価格改定）
                  ──▶ OEは契約期間中は上げにくい。次のモデルサイクルまで我慢

  原材料が下がる  ──▶ REPの値上げはすぐには戻さない（＝利益が膨らむ局面）
                  ──▶ OEは値下げ要求が来る

つまりREP比率が高いほど、コスト変動局面で利益を守りやすい。
これもREPが本命と言われる理由のひとつ。
なお日本国内では2026年9月1日付でブリヂストンが市販用タイヤを平均5%改定するなど、
主要各社がほぼ同時期に価格改定を実施している（各社ニュースリリース・報道ベース。
詳細は 直近トピック_2026）。

8. 1本のタイヤの値段はどう積み上がるか（イメージ）

  店頭価格（乗用車用REP、税別）
  ┌──────────────────────────────────────────────┐
  │ 小売マージン＋取付工賃・廃タイヤ処理料         │ ← 消費者が払う額の2〜4割程度
  ├──────────────────────────────────────────────┤
  │ 卸・物流（倉庫、配送、季節在庫の金利）         │
  ├──────────────────────────────────────────────┤
  │ メーカー出荷価格                               │
  │   ├ 原材料（ゴム・充填剤・コード・薬品）       │ ← 相場で動く
  │   ├ 加工費（電力・人件費・金型償却・加硫）     │ ← 稼働率で1本あたりが変わる
  │   ├ 研究開発費・ブランド広告費                 │ ← REP価格を支える源泉
  │   └ 営業利益                                   │
  └──────────────────────────────────────────────┘

※比率は商品・地域で大きく変わるための概念図。実額は各社IRの原価率で確認する。

冬用タイヤはさらに季節在庫の負担が乗る。夏に作って冬に売るため、
売れ残りは翌年に持ち越され、暖冬は需要と在庫の両面で効く。

9. まとめ：この業界を読むときのチェック項目

  1. REP比率が上がっているか（数量ではなく金額で見る）
  2. 高インチ（18インチ以上）比率が上がっているか＝ミックス改善
  3. OHT・鉱山・航空機など生産財の比率
  4. 稼働率。固定費産業なので数量減はそのまま利益減になる
  5. 価格改定の実施時期と幅、そして原材料市況との時間差
  6. 小売・リトレッドのサービス収益をどれだけ抱えているか

用語メモ

  • OE（Original Equipment）：新車装着用タイヤ。自動車メーカーに納入する
  • REP（Replacement）／RE／アフターマーケット：市販交換用タイヤ。消費者・事業者が買い替える
  • 純正指名：新車装着と同じ銘柄を買い替え時にも選ぶ行動。OEがREPに効く経路
  • 承認タイヤ（MO、N0、RO1など）：自動車メーカーが車種専用に承認した刻印付きタイヤ
  • 高インチ化：18インチ以上の大口径タイヤ比率が上がること。単価と利益率が高い
  • 消費財／生産財：タイヤ業界では乗用車用＝消費財、トラック・建機・鉱山用＝生産財と呼び分ける
  • OHT（Off-Highway Tire）：公道を走らない機械用のタイヤ。建機・鉱山・農機向け
  • ミックス改善：数量ではなく、売れる商品の構成を高単価側にずらして利益率を上げること
  • 価格改定：値上げの業界的な言い方。日本では出荷価格ベースで発表される
  • 廃タイヤ処理料：交換時に消費者が払う処理費用。リサイクル・熱利用に回る
