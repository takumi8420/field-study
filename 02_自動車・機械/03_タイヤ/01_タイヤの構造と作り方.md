# タイヤ｜構造と作り方

**このノートで分かること**：タイヤが「ゴムの塊」ではなく、繊維と鋼線をゴムで固めた**複合構造体**であること。
そして、それを作る工程（練り → 成形 → 加硫）が、なぜ**稼働率で利益が決まる設備産業**になるのか。

> ポイント：タイヤの原価を決めるのは「ゴムの値段」だけではない。
> **金型の数 × 加硫機の台数**という物理的な制約が、そのまま生産能力と固定費になる。

## 1. まず結論：タイヤは4つの仕事を同時にやる部品

クルマの部品でタイヤだけが持つ特徴は、**路面と接している唯一の部品**だということ。
接地面積は1本あたり葉書1枚ほど（乗用車で概ね150〜200cm²とされる）。ここに以下が集中する。

| 役割                 | 中身                                                           | これを担う部位                 |
| -------------------- | -------------------------------------------------------------- | ------------------------------ |
| 荷重を支える         | 車重＋積載を空気圧で支える（ゴムではなく**空気**が支えている） | カーカス＋ビード（＝圧力容器） |
| 駆動・制動力を伝える | エンジン／モーターの力、ブレーキの力を路面に渡す               | トレッド＋ベルト               |
| 方向を変える         | 横力（コーナリングフォース）を発生させる                       | ベルト＋サイドウォール         |
| 衝撃を吸収する       | 路面の凹凸をいなす                                             | 空気室＋サイドウォール         |

「タイヤは空気を入れる容器であり、ゴムはその容器の皮にすぎない」と理解すると、後の話がつながる。

## 2. 断面図：どこに何が入っているか

```
             ← 接地面（トレッド） →
      ┌───────────────────────────────┐
      │  トレッドゴム（溝＝パターン）  │ ← 摩耗・グリップ・排水を担当
      ├───────────────────────────────┤
      │  ベルト（スチールコード2層）   │ ← タガの役割。トレッドを締めて形を保つ
      │  ＋ベルト補強層（ナイロン等）  │
   ┌──┴───────────────────────────────┴──┐
   │            カーカス（プライ）          │ ← 骨格。ポリエステル等のコードを
   │   ポリエステル／レーヨンのコード＋ゴム │    ゴムで挟んだ層。空気圧を受け止める
   │                                        │
サイド│                                    │サイド ← 曲げを繰り返す。ひび割れの出やすい場所
ウォール│          （空気室）              │ウォール
   │                                        │
   └──┬───────────────────────────────┬──┘
      │ インナーライナー（気密ゴム層）│ ← チューブレス化を支える「内側のゴム風船」
      └───┬───────────────────┬───────┘
       ビード（スチールワイヤの束）  ← ホイールのリムに食いつく“錨”。
       ＋ビードフィラー                 ここが緩むと空気が抜ける
```

### 部位ごとの役割と、効かせどころ

| 部位                 | 材料                                           | 何を決めるか                                                       |
| -------------------- | ---------------------------------------------- | ------------------------------------------------------------------ |
| **トレッド**         | ゴム配合（コンパウンド）＋パターン             | グリップ、摩耗寿命、燃費（転がり抵抗）、静粛性                     |
| **ベルト**           | スチールコード＋ゴム                           | 高速時の形状保持、直進安定性、摩耗の均一さ                         |
| **カーカス**         | ポリエステル／レーヨン／アラミドのコード＋ゴム | 荷重耐性、乗り心地、耐久性                                         |
| **サイドウォール**   | 耐候性ゴム                                     | 乗り心地、耐オゾン・耐屈曲。**性能より見た目と刻印の場所**でもある |
| **ビード**           | スチールワイヤ束＋硬いゴム                     | リムとの密着、ハンドル応答                                         |
| **インナーライナー** | ブチルゴム系                                   | 空気の抜けにくさ（内圧保持）                                       |

**ラジアル構造**（カーカスコードが進行方向に対して直角＝放射状）が現在の乗用車用の標準。
古いバイアス構造（斜めに何層も重ねる）に比べ、転がり抵抗が低く寿命が長い。
一部の建設機械用・農機用・旧車用にはバイアスも残る。

## 3. 材料：ゴムは半分。残り半分が性能を決める

乗用車用タイヤの重量構成は概ね次の目安（各社公開資料・業界解説からの概算。配合は企業秘密）。

| 材料                                                       | 重量比の目安 | 役割                                                             |
| ---------------------------------------------------------- | ------------ | ---------------------------------------------------------------- |
| 合成ゴム（SBR、BRなど）                                    | 20〜30%      | 乗用車用の主役。グリップと耐摩耗の設計自由度が高い               |
| 天然ゴム（NR）                                             | 15〜25%      | 発熱に強く引き裂きに強い。**トラック・バス用では主役に逆転する** |
| 補強充填剤（カーボンブラック／シリカ）                     | 20〜28%      | ゴムを「強くする」。ここが性能の分かれ目（後述）                 |
| 補強コード（スチール／ポリエステル／レーヨン等）           | 10〜15%      | 骨格。ゴムだけでは形が保てない                                   |
| 配合薬品（硫黄、酸化亜鉛、加硫促進剤、老化防止剤、オイル） | 5〜10%       | 架橋、劣化防止、加工性                                           |

### なぜ天然ゴムが消えないのか

合成ゴムは石油から作れるのに、天然ゴム（パラゴムノキの樹液）が使われ続ける理由は**発熱と引き裂き**。
天然ゴムは分子が揃っていて伸びると結晶化するため、大きな荷重がかかっても発熱しにくく裂けにくい。
トラック・バス用（TB）や鉱山用・航空機用のように**重くて熱を持つ用途ほど天然ゴム比率が上がる**。
逆に乗用車用は合成ゴムの比率が高く、配合設計で性能を作り込む。

→ 合成ゴム側の産業は [合成ゴム](../../10_素材・化学/14_合成ゴム/README.md)、
カーボンブラック側は [炭素・カーボン](../../10_素材・化学/13_炭素・カーボン/README.md) を参照。

### カーボンブラックとシリカ：タイヤが「黒い」理由と、燃費が良くなった理由

- **カーボンブラック**：石油系原料を不完全燃焼させて作る極微細な炭素粉。ゴムに混ぜると強度と耐摩耗性が数倍になる。タイヤが黒いのはこれが入っているから
- **シリカ（二酸化ケイ素）**：1990年代に実用化された代替充填剤。カーボンブラックより**転がり抵抗を下げつつウェットグリップを保てる**。低燃費タイヤ（いわゆるグリーンタイヤ）の中核技術
- ただしシリカはゴムとなじみにくく、**シランカップリング剤**という薬品で橋渡しをする必要がある。混練の手間とコストが増えるため、低燃費タイヤは高価になりやすい

> ポイント：「シリカをどれだけ均一に分散させられるか」が各社の腕の見せどころ。
> レシピ（配合）と混練条件がノウハウの塊で、特許と秘匿の対象になっている。

## 4. 性能の三すくみ（魔の三角形）

タイヤ開発が難しいのは、主要3性能が**互いに食い合う**から。

```
                 転がり抵抗の低さ（＝燃費・電費）
                        ／＼
                      ／    ＼
                    ／  トレード ＼
                  ／     オフ      ＼
                ／                    ＼
   ウェットグリップ ────────────── 耐摩耗（寿命）
   （安全＝止まる）                （経済性＝もつ）

  ・柔らかいゴム → よく止まるが、減りやすく、転がり抵抗も上がりがち
  ・硬いゴム     → 長持ちし転がり抵抗は低いが、濡れた路面で止まらない
  → 配合（シリカ・ポリマー設計）とパターンで三角形そのものを広げるのが技術競争
```

日本ではこの2軸が**ラベリング制度**として表示される（転がり抵抗 AAA〜C、ウェットグリップ a〜d）。
JATMA（日本自動車タイヤ協会）の自主基準で、両方が一定等級以上のものが「低燃費タイヤ」を名乗れる。

## 5. 作り方：練って、貼って、焼く

```
【1】材料           【2】練り（混練）        【3】部材づくり
天然ゴム            バンバリーミキサーで      押出機 → トレッド・サイドウォール
合成ゴム    ──▶    ゴム＋充填剤＋薬品を  ──▶ カレンダー → コード＋ゴムのシート
カーボン/シリカ     高温でこね回す              ビードワイヤ加工 → ビードリング
薬品                （コンパウンド完成）
                                                      │
                                                      ▼
【6】検査                 【5】加硫              【4】成形
外観・ユニフォミティ ◀── 金型に入れ、内側から ◀── 成形機で各部材を
バランス・X線             高温高圧で15分前後      円筒状に貼り合わせ
出荷                      （硫黄で架橋＋          ＝グリーンタイヤ（生タイヤ）
                           トレッド模様を刻む）      ※この時点ではまだ柔らかい
```

### 各工程で何が起きているか

| 工程                     | やること                                                                   | ここが効く                                                     |
| ------------------------ | -------------------------------------------------------------------------- | -------------------------------------------------------------- |
| **混練（練り）**         | ゴムに充填剤・薬品を練り込む。数段階に分けて行う                           | 分散の均一性＝性能のばらつき。ここで失敗すると後で取り返せない |
| **押出・圧延**           | トレッドやサイドウォールの断面形状を作る／コードにゴムを被せてシートにする | 厚みの精度。重量ばらつきはユニフォミティ不良に直結             |
| **成形**                 | 10〜20種類の部材をドラム上で順に貼り、膨らませてタイヤの形にする           | 貼り合わせ位置のズレ＝振動・偏摩耗の原因                       |
| **加硫（バルカナイズ）** | 金型に入れ、蒸気等で加熱加圧。硫黄がゴム分子をつなぐ（架橋）               | **1本ずつ15分前後を占有する**。ここが生産能力のボトルネック    |
| **検査**                 | 外観、真円度、重量バランス、X線で内部のコード乱れを見る                    | 不良の流出はリコール直結。全数検査が基本                       |

### 加硫がなぜ決定的か

生ゴムは温めると軟らかく、冷えると硬くなるだけの「粘土」にすぎない。
硫黄を加えて加熱すると、ゴム分子の鎖同士が硫黄で橋渡し（架橋）され、**弾性を持つ固体**になる。これが加硫。
同時に金型の彫り込みが転写され、トレッドパターンと側面の刻印が一度に出来上がる。

## 6. 設備産業としての性格

ここがタイヤ業界の経済を理解する要。

- **金型は原則1サイズ1型**。乗用車用だけでサイズ・パターン・銘柄の組み合わせは数千SKUに及ぶ。
  売れ筋を外した金型は減価償却だけ残る
- **加硫機の台数が生産能力の上限**。1本15分前後を占有するので、増産＝機械を買うしかない
- 結果として**固定費比率が高い**。稼働率が数%落ちるだけで利益が飛ぶ
- 品種切替（サイズ変更）には段取り替えが要る。**多品種少量ほど稼働率が落ちる**
- 工場は需要地の近くに置くのが原則。タイヤは**軽くて嵩張る**ため輸送効率が悪く、海上運賃の影響を強く受ける
- 立ち上げには数年かかる。需要が読みにくい局面で新工場を建てる判断が難しい

```
利益 ＝（売価 − 変動費[ゴム・充填剤・コード・電力]）× 本数 − 固定費[償却・人件費・金型]
                                                                   ↑
                                     ここが重いので「本数が落ちた瞬間に赤字」になる
```

> ポイント：だから各社は**稼働率を守るために安売りしてでも数量を取る**誘惑と常に戦っている。
> 収益性の高い大口径サイズ（18インチ以上）に生産を寄せる動きは、この構造への答えでもある。

## 7. 品質保証と表示

- 側面には **サイズ・ロードインデックス（負荷能力）・スピードレンジ・製造年週（4桁のDOTコード等）** が刻印される
- 日本では消費生活用製品ではなく道路運送車両法の保安基準の世界。スリップサインが出る残溝1.6mmが使用限度
- 空気圧管理が性能・寿命・安全の大半を決める。TPMS（空気圧監視システム）は米国では新車装着が義務、EUでも義務化済み

## 用語メモ

- **カーカス**：タイヤの骨格層。コード（繊維）をゴムで挟んだシートを重ねたもの
- **ベルト**：トレッドの下でタガのように締めているスチールコード層。ラジアルタイヤの要
- **ビード**：ホイールのリムに食いつく鋼線の輪。ここで空気を封じる
- **インナーライナー**：内側の気密ゴム層。チューブなしで空気を保持する
- **コンパウンド**：ゴム配合物。各社最大のノウハウ
- **加硫（バルカナイゼーション）**：硫黄でゴム分子を架橋し弾性体にする工程
- **グリーンタイヤ**：加硫前の生タイヤ。または低燃費タイヤの通称（文脈で意味が変わる要注意語）
- **ユニフォミティ**：1本の中の均一性（真円度・剛性のムラ）。振動の原因になる
- **ラジアル／バイアス**：カーカスコードの向きによる構造の違い。現在の乗用車用はほぼラジアル
- **ラベリング制度**：転がり抵抗とウェットグリップの等級表示。JATMAの自主基準
- **SKU**：在庫管理上の品目単位。タイヤはサイズ×銘柄で膨大になる
