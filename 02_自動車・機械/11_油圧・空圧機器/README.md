# 油圧・空圧機器

- 大分類: 自動車・機械
- 状態: done
- 更新日: 2026-09-20

**この業界を一言で**：機械に「力」を配るための部品を作って売る産業。
ただし名前が並んでいるだけで、**油圧と空圧は中身がまったく別の商売**である。
油圧は建機メーカーに設計込みで納める重い商売、
空圧は**無数の装置メーカーに膨大な品種を即納する在庫ビジネス**。
このフォルダはその違いを軸に構成している。

## 1. 業界の定義・範囲

油圧・空圧機器とは、**油または圧縮空気を使って動力を伝え、機械を動かす部品**の総称。
業界では **フルードパワー機器**と呼び、業界団体は日本フルードパワー工業会（JFPA）。

主な製品は **ポンプ／バルブ（制御弁）／シリンダ／油圧モータ**の4つと、
フィルタ・アキュムレータ・継手などの付属機器。
空圧側にはこれに加えてF.R.L.ユニット（フィルタ・減圧弁・給油器）や真空機器が入る。

隣接業界との境界は次のとおり。

| 業界 | 違い |
| --- | --- |
| [建設機械](../06_建設機械/README.md) | 建機の**中身**を供給する側。油圧市場の約45%が建機向け |
| [工作機械](../07_工作機械/README.md) | 金属を削る機械そのもの。油圧・空圧はその中のクランプや開閉に使われる |
| [産業用ロボット](../09_産業用ロボット/README.md) | ロボット本体は電動。ただし**手先のハンドは空圧チャック**が主流 |
| [ポンプ・バルブ](../17_ポンプ・バルブ/README.md) | 水・薬液など**流体そのものを送る**ための機器。動力伝達が目的ではない |
| [モーター](../15_モーター/README.md) | 電気で直接回す。油圧・空圧と代替関係にある |
| [FA・制御機器](../../03_電機・電子部品/14_FA・制御機器/README.md) | センサ・PLC・サーボなど電気側の自動化部品。空圧と同じ客に売る |
| [ベアリング](../10_ベアリング/README.md) | 同じ機械要素部品だが、動力を作らず回転を支える |

**「油圧」と「空圧」を1つの業界として語ると必ず間違える**。
市場規模も成長率も顧客も収益性も違う。→ [① 原理と使い分け](01_油圧と空圧の原理と使い分け.md)

## 2. 市場規模と成長性

| 区分 | 数値 | 年・出典 |
| --- | --- | --- |
| 国内 油圧機器 出荷額 | **3,541億円**（前年比 ▲0.6%） | 2025年（暦年、実績見込み）、JFPA需要見通し（2026年5月公表／報道ベース） |
| 同 2026年見通し | 3,656億円（+3.2%） | 同上 |
| 国内 空気圧機器 出荷額 | **5,467億円**（前年比 +5.3%） | 2025年（暦年、実績見込み）、同上 |
| 同 2026年見通し | 5,885億円（**+7.6%**） | 同上 |
| 世界 油圧市場 | 2025年 394億ドル → 2030年 443億ドル（CAGR 約2.4%） | 調査会社の推計（Mordor Intelligence 等） |
| 世界 空圧機器市場 | 2026年 374億ドル → 2031年 523億ドル（CAGR 約6.9%） | 同上（推計） |
| 油圧市場に占める建機向け | **約45%**（世界の建設分野比率は31.05%とされる） | 2025〜2026年、JFPA／調査会社推計 |

- **国内でも世界でも、空圧のほうが市場が大きく、成長も速い**
- 油圧の需要ドライバーは**建設投資と建機の販売台数**。自分では決まらない
- 空圧の需要ドライバーは**設備投資全般**、とくに半導体製造装置・工作機械・ロボット。
  JFPAは2026年について半導体・FPD製造装置関連 +12%、工作機械 +6%、産業用ロボット +3.2% を見込むとされる

## 3. バリューチェーン（川上 → 川下）

```
【川上】                【製造】                  【流通】              【川下】

 鋼材・鋳鍛造 ──┐
 アルミ押出材  ──┤
 ゴム（シール） ──┼──▶ 油空圧メーカー ──┬──▶ 直販営業 ──────┬──▶ 装置メーカー（OEM）
 樹脂・磁性材   ──┤   SMC / CKD / KYB     │                        │    設計時に型番が決まる
 電磁コイル     ──┘   川崎重工 / ダイキン  ├──▶ 機械商社・代理店 ──┤    ＝スペックイン
 作動油（石油）  ──▶   ボッシュ・レックスロス│    （在庫を前線配置）  │
                                            │                        └──▶ 工場（MRO・補修）
                                            └──▶ MRO通販（ミスミ等）      緊急性が高く利益率も高い

  ★付加価値は「設計図面に自社の型番を入れてもらう」段階に集まる。
   一度載れば、その装置が作られる限り発注が続く。切り替えには設計変更が要る
```

- 川上の材料費比率は35〜45%程度。鋼材・アルミ・ゴムの市況に利益が振られる
- 川下では、**新規装置向け（OEM）と補修（MRO）の二本立て**。
  MROは景気の波が小さく値引き圧力も弱い → [② 産業構造と儲け方](02_産業構造と儲け方.md)

## 4. 主要プレイヤーとシェア

| 企業 | 分野 | 立ち位置・特徴 |
| --- | --- | --- |
| **SMC**（日） | 空圧 | **世界首位**。シェア3割超とされる。品揃え（派生含め70万品目超）と厚い在庫による即納が競争力。2026年3月期 売上高 8,425億円、営業利益率22%台 |
| **フェスト（Festo）**（独） | 空圧 | 世界2位級・非上場。欧州の装置メーカーに強い |
| **CKD**（日） | 空圧・流体制御 | 国内2位。半導体製造装置向けが伸び、2027年3月期予想を上方修正（2026年8月） |
| **コガネイ**（日） | 空圧 | 小型空圧、静電気除去に特化 |
| **パーカー・ハネフィン**（米） | 油圧・空圧 | 総合大手。買収で拡大。航空・シールも持つ |
| **ボッシュ・レックスロス**（独） | 油圧 | 産業用・移動機械用の世界大手。電動化とソフトに投資 |
| **ダンフォス**（デンマーク） | 油圧 | イートンの油圧事業を買収し移動機械向けで大手に |
| **川崎重工**（日） | 油圧 | 建機用コントロールバルブで**世界シェア約3割**とされる |
| **カヤバ（KYB）**（日） | 油圧 | ショベルのアーム用シリンダで**世界シェア約4割**とされる。自動車用ショックアブソーバも主力 |
| **ダイキン工業 油機事業**（日） | 油圧 | インバータ制御の省エネ油圧ユニットに強み |
| **不二越**（日） | 油圧 | ロボット・ベアリングも持つ総合機械メーカー |
| **ナブテスコ**（日） | 油圧（撤退） | 走行ユニットで世界シェア約25%を持ちながら、**2026年1月に事業売却を完了** |
| **豊興工業／油研工業／東京計器** | 油圧 | 産業機械向けの中堅専業 |

- 世界の油圧は**パーカー・ボッシュ・レックスロス・ダンフォスの3社で約4分の1**を占めるとされる（推計）
- 空圧はSMCの一強で、上位に日本勢が2社（SMC・CKD）入る珍しい構図
- **日本勢は建機用の基幹油圧部品で高いシェアを持つ**が、そこが今まさに揺らいでいる

## 5. 収益モデル・コスト構造

```
利益 ＝ ①新規装置向け（OEM）  波が大きい。設備投資に連動
      ＋ ②補修・交換（MRO）    厚くて安定。稼働設備がある限り続く
      ＋ ③カスタム・ユニット化 設計工数を売る
      ＋ ④省エネ・診断サービス 拡大中
      － 材料費（35〜45%）－ 製造固定費 － 直販営業の人件費
```

| 指標 | 油圧 | 空圧 |
| --- | --- | --- |
| 営業利益率の目安 | 数%〜10%程度 | 10〜20%超（SMCは22%台、2026年3月期） |
| 価格決定力 | 弱い（顧客が数十社に集中） | 比較的強い（顧客が分散、単価が小さい） |
| 内製化リスク | **高い**（建機メーカーが自社生産） | 低い |
| 在庫の扱い | 受注生産中心。在庫は少なめ | **意図的に厚く持つ**。欠品の損害が在庫コストより大きい |

> **空圧の逆説**：普通の経営では在庫は悪だが、空圧では**在庫が競争力そのもの**。
> 客（装置メーカー）は部品が1点来ないと装置を出荷できず、
> その損害は部品代の数十〜数百倍になる。だから**値段より納期で選ばれる**。

## 6. 競争要因（KSF）と参入障壁

```
┌────────────────────────────────────────┐
│ ①作る（鋳造・加工・シール・組立）                        │ ← 中国勢が到達しつつある
├────────────────────────────────────────┤
│ ②揃える（品種数・カタログ・CADデータ・型番の標準化）      │ ← 数十年の蓄積
├────────────────────────────────────────┤
│ ③届ける（在庫・世界の物流拠点・当日出荷）                │ ← 空圧の最大の障壁
├────────────────────────────────────────┤
│ ④入り込む（設計段階でのスペックイン）                    │ ← いったん入れば長く効く
└────────────────────────────────────────┘
```

| KSF | なぜ効くか |
| --- | --- |
| **品種数** | 装置メーカーは「1社で全部揃う」ことを求める。足りないと丸ごと他社へ行く |
| **在庫と即納** | 欠品の損害は部品代の100倍。納期が価格に優先する |
| **スペックイン** | 図面に型番が載れば繰り返し発注される。切替には設計変更が必要 |
| **グローバル同一品番** | 客の工場が海外に移っても現地で同じ型番が買える |
| **信頼性の実績** | 数千万回の往復に耐える必要がある。実績のない会社は試されない |
| **（油圧）OEMとの共同開発** | 機種開発の初期から入る。決まれば型式の寿命まで続く |
| **（油圧）省エネ制御技術** | 電動建機ではエネルギー効率が直接の選定理由になる |

**油圧の弱さは、この②③④の障壁が空圧より低いこと**にある。
専用設計なので品種数の意味が薄く、受注生産中心で在庫が武器にならず、
顧客が内製化を選べばスペックインは崩れる。

## 7. 規制・法制度

| 分野 | 内容 |
| --- | --- |
| **高圧ガス保安法** | 圧縮空気は一定圧力以上で規制対象。一般的な工場用圧力（0.5〜0.7MPa）は対象外 |
| **労働安全衛生法** | 圧力容器（エアタンク・アキュムレータ）の構造規格と定期自主検査 |
| **PED／CE／UL等の海外認証** | 輸出時に必要。国ごとに異なり、取得コストが参入障壁になる |
| **機能安全（ISO 13849 等）** | 非常停止時に機械を安全に止める要求。安全弁・安全バルブの需要を生む |
| **省エネ法** | 工場のエネルギー使用量報告。圧縮空気は工場電力の大きな割合を占めるため対策対象になる |
| **GX建設機械認定制度／GX補助金** | 需要側（建機）の制度。電動建機の普及方針が油圧機器の開発方向を決める → [建設機械](../06_建設機械/README.md) |
| **環境規制（作動油）** | 森林・水辺など漏洩リスクの高い現場で生分解性作動油が要求される地域がある |
| **輸出管理・通商** | 航空機向けなど一部は輸出管理の対象。米国の関税措置もコストに影響すると報じられる |

## 8. 最近のトピック

詳細は [④ 直近トピック 2026](04_直近トピック_2026.md)。要点は次の5つ。

1. **空圧が油圧を規模でも伸びでも引き離した**。
   2026年見通しは空圧 5,885億円（+7.6%）に対し油圧 3,656億円（+3.2%）（JFPA、2026年5月）
2. **ナブテスコが油圧機器事業を売却**。世界シェア約25%の走行ユニット事業を
   イタリアのコマーへ142億円で譲渡し、2026年1月に完了。
   理由は中国勢の台頭と建機メーカーの内製化（日経報道）
3. **SMCが売上高1兆円を計画**。2026年3月期は売上高 8,425億円・営業利益 1,905億円、
   2027年3月期は1兆円（+18.7%）を目指す（会社発表）
4. **半導体設備投資が空圧を押し上げている**。CKDは2026年8月、半導体需要増で
   2027年3月期予想を売上高1,930億円・営業利益285億円へ上方修正
5. **建機の電動化は油圧の敵ではないが、要求を厳しくする**。
   電動建機でもアームを動かすのは油圧。ただし電池容量が有限なので、
   高効率ポンプ・回生・EHAが必須になる → [③ 技術トレンド](03_技術トレンド.md)

## 9. 用語メモ

各ノート末尾にも用語メモを置いている。共通する基本用語は次のとおり。

| 用語 | 意味 |
| --- | --- |
| **フルードパワー** | 流体（油・空気）で動力を伝える技術の総称 → [① 原理と使い分け](01_油圧と空圧の原理と使い分け.md) |
| **JFPA** | 日本フルードパワー工業会。出荷統計と年次の需要見通しを公表 |
| **パスカルの原理** | 密閉流体の圧力はどこでも等しく伝わる。小さな力を大きな力に変える原理 |
| **MPa（メガパスカル）** | 圧力の単位。1MPa ≒ 10気圧。油圧は20〜35MPa、空圧は0.5〜0.7MPaが標準 |
| **アクチュエータ** | 動力を実際の動き（直線・回転）に変える部品。シリンダ・モータの総称 |
| **電磁弁（ソレノイドバルブ）** | 電気信号で流路を切り替えるバルブ。空圧回路の基本部品 |
| **F.R.L.ユニット** | 空圧の三点セット（フィルタ・レギュレータ・ルブリケータ） |
| **走行ユニット** | 油圧ショベルのクローラを回す減速機＋油圧モータの一体品 |
| **スペックイン** | 顧客の設計図面に自社型番を入れてもらうこと。繰り返し受注の源泉 → [② 産業構造と儲け方](02_産業構造と儲け方.md) |
| **MRO** | 保守・補修用の部材需要。景気の波が小さく利益率が高い |
| **多品種少量・即納** | 空圧ビジネスの中核。品種を極端に増やし在庫を厚く持って当日出荷する |
| **EHA** | 電気油圧アクチュエータ。モーター・ポンプ・シリンダを一体化した部品 → [③ 技術トレンド](03_技術トレンド.md) |
| **ロードセンシング** | 負荷が必要とする圧力・流量だけを作る省エネ油圧制御 |
| **エア漏れ** | 圧縮空気の漏れ。工場の圧縮空気使用量の約20%を占めるとされ、省エネ提案の定番 |
