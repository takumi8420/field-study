油圧・空圧機器｜原理と使い分け

このノートで分かること：油圧と空圧が「何をする部品」なのか、
なぜ小さな装置から巨大な力が出せるのか、そして同じ「流体で動かす」技術なのに、
油と空気でまったく別の産業になっている理由。
最後に、近年これらを食いに来ている電動アクチュエータとの棲み分けを整理する。

1. 一言でいうと：力を配るための配管

油圧・空圧機器（業界用語では フルードパワー機器＝流体で動力を伝える機器）は、
「動力源から離れた場所に、必要な大きさの力を、必要なタイミングで届ける」ための部品群である。

電気なら電線で運ぶところを、油や空気という流体で運ぶ。それだけの話なのだが、
流体で運ぶと 電線ではできない芸当ができる。

【動力の運び方は3通りある】

  電気で運ぶ   モーター ──電線──▶ モーター・電動シリンダ
               → 制御が正確。だが「重い物を押す」には大きなモーターと減速機が要る

  油で運ぶ     モーター ──配管──▶ 油圧シリンダ／油圧モータ
               → 圧力を上げれば小さな筒で数十トン押せる。重い物担当

  空気で運ぶ   コンプレッサ ──配管──▶ 空圧シリンダ
               → 安い・速い・軽い・汚れない。軽い物を大量に動かす担当

ポイント：この3つは「どれが優れているか」ではなく、
力の大きさ・速さ・精度・清潔さ・コストのどれを優先するかで選ばれる。
業界の構造も、この使い分けの線に沿って分かれている。

2. なぜ小さな装置で大きな力が出るのか：パスカルの原理

密閉した液体に圧力をかけると、その圧力は容器のどこでも同じ大きさで伝わる。
これがパスカルの原理である。力は「圧力 × 受圧面積」で決まるので、
入口を細く、出口を太くすれば、小さな力が大きな力に化ける。

【パスカルの原理＝流体版のてこ】

   小さい力 100N                             大きい力 10,000N
        ↓                                           ↑
     ┌──┐                                    ┌──────────┐
     │  │ 面積 1cm2                          │          │ 面積 100cm2
     │  │                                    │          │
     └──┴────────────────────────────┴──────────┘
          ← 油（圧力はどこでも 100N/cm2 = 10MPa で一定）→

   入口の力を100倍にするかわりに、動く距離は1/100になる（仕事の量は同じ）
  • 実務で使う圧力は 油圧で 14〜35MPa（メガパスカル）程度が一般的。
    35MPa は約350気圧で、手のひら大（直径10cm）のシリンダで約27トンを押せる計算になる
  • 空圧は 0.5〜0.7MPa（5〜7気圧）が標準。油圧の 1/50 程度しかない
  • だから「掘る・潰す・持ち上げる」は油圧、「つまむ・押し出す・並べる」は空圧になる

3. 回路の基本構成：4つの役者

油圧も空圧も、回路の骨格は同じ 「作る→ためる→配る→動かす」 である。

【油圧回路の基本形】

  電動モーター ──▶ 油圧ポンプ ──▶ 制御バルブ ──┬──▶ 油圧シリンダ（直線に動く）
   （動力源）      （圧力を作る）  （方向・流量・  │
                                    圧力を決める） └──▶ 油圧モータ（回る）
        ▲                                │
        │                                ▼
      タンク ◀──── フィルタ・クーラ ◀──── 戻り油
      （作動油をためる・冷やす・ゴミを取る）

【空圧回路の基本形】

  コンプレッサ ──▶ エアタンク ──▶ F.R.L. ──▶ 電磁弁 ──▶ 空圧シリンダ
  （工場に1台、    （ためる）    （ゴミ取り・  （方向を   （動く）
   全体で共用）                    減圧・給油）  切替）          │
                                                                ▼
                                                        大気にそのまま放出
                                                       （戻り配管が要らない）

空圧に戻り配管が要らないことが、実は決定的な差になる。
配管が半分で済み、漏れても空気なので機械も製品も汚れない。
食品・医薬・半導体の工場で空圧が選ばれる理由の大半はここにある。

4. 主要機器の分類：何がいくらで売れているか

機器 役割 ざっくりした位置づけ
ポンプ油に圧力を与える。ピストン型・ギヤ型・ベーン型がある油圧の心臓。ピストンポンプは高圧・高効率だが高価
バルブ（制御弁）流れの向き・量・圧力を決める。回路の頭脳電磁弁・比例弁・サーボ弁。精度を出す部分で単価が高い
シリンダ（アクチュエータ）直線に押す・引く。最も台数が出る建機のアーム、プレス、自動機の押し出し
モータ（油圧モータ）回転力を出す。走行・旋回に使う建機のクローラ走行、ウインチ、旋回
付属機器フィルタ、クーラ、アキュムレータ（蓄圧器）、配管・継手地味だが交換需要が続く
空圧特有F.R.L.ユニット（フィルタ・レギュレータ・ルブリケータ）、真空機器（吸着パッド）、エアチャック半導体・電子部品の搬送は真空吸着が主役

日本フルードパワー工業会（JFPA）の需要見通しでは、
2025年（暦年）の国内出荷は 油圧機器 3,541億円（前年比0.6%減）、空気圧機器 5,467億円（同5.3%増）、
2026年見通しは 油圧 3,656億円（+3.2%）、空気圧 5,885億円（+7.6%）とされる
（JFPA 2026年需要見通し、2026年5月公表／産機通信報道ベース）。
空圧のほうが市場が大きく、伸びも速いのが現在の姿である。

5. 油圧と空圧の比較：同じ技術ではない

観点 油圧 空圧
使用圧力14〜35MPa（高圧）0.5〜0.7MPa（低圧）
出す力大きい。数トン〜数百トン小さい。数十kg〜数百kg
速さ遅め（油は粘い）速い。1秒に何往復も可能
位置決め精度高い（油はほぼ縮まない）苦手（空気がばねのように縮む）
清潔さ油漏れが宿命。食品・医薬では嫌われるきれい。漏れても空気
配管往復2本＋タンクが必要片道1本。戻りは大気放出
エネルギー効率高い（流体が非圧縮）悪い。圧縮と漏れで大半を捨てる
1台あたりの単価高い（数万〜数百万円）安い（数千〜数万円）
1顧客あたりの点数少ない非常に多い。1ラインに数百〜数千個
主な売り先建機、工作機械、プレス、船舶、航空機工場の自動化装置全般、半導体装置、食品、包装

この表の最後の2行が、産業構造の違いを決めている。
油圧は「少数の大口OEMに、設計込みで高単価品を納める」ビジネス。
空圧は「無数の装置メーカーに、安い部品を膨大な品種でさばく」ビジネスになる。
→ ② 産業構造と儲け方

6. 空気は縮む、油は縮まない：この一点がすべて

空圧の弱点はすべて「空気がばねである」ことから来ている。

【押し当てたときの挙動】

 油圧シリンダ          空圧シリンダ
    ▼                      ▼
  ┃███┃止まる            ┃░░░┃ぐにゃっと沈む
  ┗━━━┛                  ┗━━━┛
  油は数千気圧かけても      空気は圧力が上がると体積が減る
  1%も縮まない             = 荷重で位置がずれる
  → 途中停止・精密位置決めができる  → 「端から端まで動かす」用途に限られる
  • だから空圧シリンダは基本的に「出す／引っ込める」の2ポジションで使う。
    途中で正確に止めたければ、空圧では難しく、電動アクチュエータの出番になる
  • 逆に、この「ばね性」は押し付ける力を一定に保つ用途（研磨、圧入、ワークの保持）では利点になる
  • 油圧は非圧縮なので、重い物を空中で保持したまま微動させることができる。
    建機のアーム操作が成立するのはこのおかげ → 建設機械

7. 使い分けの地図

        大 ▲
           │                      【油圧】
   出す    │              建機・プレス・射出成形機
   力の    │              船舶舵取機・航空機の舵面
   大きさ  │
           │      【電動】
           │   ロボット・工作機械の送り
        中 │   搬送・位置決め・組立
           │
           │  【空圧】
           │  つかむ・押す・払う・吸着
        小 │  包装・食品・電子部品の搬送
           └──────────────────────────▶
             低い            位置決め精度            高い
  • 右上（大きな力＋高精度）は油圧の独壇場だったが、近年は電動（電気油圧アクチュエータ）が侵食しつつある
  • 左下（小さい力＋低精度）は空圧が圧倒的に安く、電動が入り込めない
  • 危ない領域は中央。電動化の波はここから広がっている → ③ 技術トレンド

8. 電動アクチュエータとの三つ巴

方式 強み 弱み 主戦場
油圧出力密度が圧倒的。過負荷に強い。屋外・粉塵に強い油漏れ、効率、油温管理、配管が重い建機、農機、プレス、船舶、航空機
空圧安い、速い、軽い、清潔、壊れにくい、防爆効率が悪い、位置決めできない、圧縮空気の電気代自動機、半導体装置、食品・包装
電動位置・速度・力を自在に制御、データが取れる、省エネ高価、重い物は苦手、過負荷で壊れる、熱がこもるロボット、工作機械、精密搬送

「電動が全部置き換える」という話にはならない。理由は3つ。

  1. 出力密度：同じ力を出す電動シリンダは、油圧シリンダより大きく重くなる。
    建機のアームの先端に付けるのは現実的でない
  2. 過負荷耐性：油圧はリリーフ弁（圧力の逃し弁）で逃がせば壊れない。
    電動はボールねじやモーターが物理的に壊れる
  3. コスト：空圧シリンダが数千円なのに対し、同等の電動シリンダは数万円。
    1ラインに数百個使う世界では置き換えが成立しない

一方で、中負荷・高精度・稼働頻度が高い領域では電動が確実に勝っている。
射出成形機の型締めや工作機械の送りは、この20年でほぼ電動に置き換わった。

9. どこで使われているか

用途 油圧／空圧 使われ方
建設機械油圧ポンプ・バルブ・シリンダ・走行モータ。市場の約45%を占める最大需要先
農業機械油圧作業機の昇降、HST（静油圧式無段変速）
工作機械両方クランプ（つかむ）は油圧、カバー開閉・切粉除去は空圧
産業用ロボット空圧ロボット本体は電動だが、手先のハンドは空圧チャックが主流
半導体製造装置空圧・真空ウェハの吸着搬送、薬液・ガスの流量制御
射出成形機・プレス油圧→電動電動化が最も進んだ領域。大型機は今も油圧
造船・重機油圧舵取機、甲板機械、ハッチカバー
航空機・防衛油圧操縦舵面、脚の上げ下げ。信頼性要求が別格
食品・医薬・包装空圧油が使えないので空圧か電動の二択

10. 用語メモ

用語 意味
フルードパワー流体（油・空気）で動力を伝える技術の総称。業界団体名（JFPA）にも使われる
パスカルの原理密閉流体の圧力はどこでも等しく伝わる。小さな力を大きな力に変える原理
MPa（メガパスカル）圧力の単位。1MPa ≒ 10気圧。油圧は20〜35MPa、空圧は0.5〜0.7MPaが標準
アクチュエータ動力を実際の動き（直線・回転）に変える部品の総称。シリンダやモータのこと
シリンダ筒とピストンで直線運動を出す部品。最も台数が出る
油圧モータ油の流れで回転力を出す部品。建機の走行・旋回に使う
電磁弁（ソレノイドバルブ）電気信号で流路を切り替えるバルブ。空圧回路の基本部品
比例弁・サーボ弁電気信号の大きさに比例して流量・圧力を連続制御する高級バルブ
F.R.L.ユニット空圧の三点セット。フィルタ（ゴミ取り）・レギュレータ（減圧）・ルブリケータ（給油）
アキュムレータ圧力をためておく蓄圧器。瞬間的な大流量や、停電時の非常動作に使う
リリーフ弁設定圧を超えた油を逃がす安全弁。油圧が過負荷で壊れない理由
HST静油圧式無段変速装置。油圧ポンプとモータの組み合わせで無段変速する
非圧縮性圧力をかけても体積がほぼ変わらない性質。油にあり、空気にない
JFPA日本フルードパワー工業会。油圧・空気圧機器の出荷統計と需要見通しを公表
