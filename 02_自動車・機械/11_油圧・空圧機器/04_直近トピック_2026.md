# 油圧・空圧機器｜直近トピック（2026年9月時点）

報道・会社発表ベースの整理。数値は原則として一次情報（会社IR・業界団体）を優先し、
確定していないものは「見通し」「推計」「報じられる」と明示する。

**この時点の一行まとめ**：**空圧は半導体・FA需要で絶好調、油圧は建機依存のまま足踏み**。
そして日本の油圧業界では、中国勢の台頭と建機メーカーの内製化を理由に
**事業そのものを手放す動き**が現実になった。

```
【2026年の油空圧業界を1枚で】

        ＋
        │      ● 空圧（2026年見通し +7.6%）
   成長  │        半導体製造装置・FA・輸出が牽引
   率    │
      0 ─┼──────────────────────────
        │   ● 油圧（2026年見通し +3.2%、2025年は▲0.6%）
        │     建機45%依存。中国勢の低価格品と内製化に挟まれる
        －
             国内市場の規模 →  油圧 約3,500億円 ＜ 空圧 約5,500億円
```

## 1. JFPA見通し：空圧が油圧を規模でも伸びでも引き離した

日本フルードパワー工業会（JFPA）が2026年5月に公表した需要見通し（産機通信の報道ベース）。

| 区分 | 2025年（実績・見込み） | 2026年（見通し） |
| --- | --- | --- |
| **油圧機器**（暦年） | 3,541億円（前年比 **▲0.6%**） | 3,656億円（**+3.2%**） |
| 油圧機器（年度） | 3,553億円（前年度比 ▲0.1%） | 3,706億円（+4.3%） |
| **空気圧機器**（暦年） | 5,467億円（前年比 **+5.3%**） | 5,885億円（**+7.6%**） |
| 空気圧機器（年度） | 5,563億円（前年度比 +5.1%） | 5,999億円（+7.8%） |

読みどころは3つ。

1. **規模がすでに逆転している**。空圧は油圧の1.5倍以上の市場になった
2. **油圧市場の約45%が土木建設機械向け**。国内は横ばい、
   輸出は先進国のインフラ投資が支える見込みとされる
3. **空圧の伸びを作っているのは設備投資の中身**。
   JFPAの見通しでは一般機械部門で**工作機械 +6%、産業用ロボット +3.2%、
   半導体・FPD製造装置関連 +12%**とされ、輸出（約6割）が成長を牽引する

> つまり、同じ「フルードパワー」でも、
> 油圧は[建設機械](../06_建設機械/README.md)の景気を、
> 空圧は[半導体製造装置](../../03_電機・電子部品/03_半導体製造装置/README.md)と
> [産業用ロボット](../09_産業用ロボット/README.md)の景気を見ている。
> **同じ業界統計に載っているだけで、実態は別の産業**である。

## 2. ナブテスコが油圧機器事業を売却：日本の油圧再編の象徴

2026年最大の構造ニュース。

| 項目 | 内容 |
| --- | --- |
| 発表 | 2025年7月31日（ナブテスコ 適時開示） |
| 完了 | **2026年1月5日**（売却完了を発表、日経報道） |
| 相手 | イタリア **コマー・インダストリーズ（Comer Industries）** |
| 金額 | **142億円**。新設分割した会社の株式70%を譲渡、30%はナブテスコが継続保有 |
| 対象 | 油圧ショベル用**走行ユニット**等の油圧機器の研究開発・製造・販売 |
| 立ち位置 | 走行ユニットは**世界シェア約25%**とされる主力事業 |
| 理由 | 中国ローカル油圧メーカーの台頭と、建機メーカーの内製化で収益力が回復しない（木村社長コメント、日経） |

```
【なぜシェア25%の事業を手放すのか】

  世界シェア25% ＝ 強い？
        │
        ├─ 顧客は建機メーカー数十社に集中
        │    └─ 内製化を決められたら、その分の需要が丸ごと消える
        │
        ├─ 中国の建機メーカーが中国製油圧を採用
        │    └─ 「そこそこの品質で半額」に価格が引きずられる
        │
        └─ 設備・開発の固定費は重い
             └─ 数量が落ちると一気に採算割れ

  ＝ シェアがあっても「価格決定力がない」。
     これが油圧ビジネスの弱点そのもの → 02_産業構造と儲け方.md
```

ナブテスコ本体はロボット用精密減速機など高収益事業に資源を集中する構え。
**日本の機械部品メーカーが「シェアはあるが儲からない事業」を切る**という点で、
この業界に限らない示唆がある。

## 3. SMC：2027年3月期に売上高1兆円計画

空圧の世界首位 SMC の 2026年3月期（2026年5月14日発表）。

| 項目 | 金額 | 前期比 |
| --- | --- | --- |
| 売上高 | **8,425億円** | +6.4% |
| 営業利益 | **1,905億円** | +0.2% |
| 経常利益 | 2,355億円 | +12.2% |
| 純利益 | 1,673億円 | +7.0% |
| 設備投資 | 1,502億円 | +39.4% |

- 地域別売上は**中国 2,349億円が最大**、次いで欧州 1,622億円、アジア（中国除く）1,589億円、日本 1,588億円。
  **日本が4番手**という点にこの会社の性格が出ている
- **2027年3月期は売上高 1兆円（+18.7%）、営業利益 2,190億円（+14.9%）を計画**
  （会社予想。automation-news / kikai-news 等の報道でも確認できる）
- 営業利益率は22%台で、機械セクターの中央値を大きく上回る。
  自己資本比率も9割台と、**実質無借金で在庫を厚く持てる財務**が競争力を支えている
- 設備投資を4割増やしているのは、**品種と在庫をさらに厚くする**という意思表示と読める

## 4. 半導体設備投資の波が空圧を押し上げている

CKDは**2026年8月7日**、2027年3月期の業績予想を上方修正したと発表（会社開示）。

| 項目 | 修正前 | 修正後 |
| --- | --- | --- |
| 売上高 | 1,800億円 | **1,930億円** |
| 営業利益 | 245億円 | **285億円** |

理由は「半導体関連市場の需要が当初想定を上回った」こと。
CKDは前工程（ウェットプロセス、高真空制御機器）から後工程（高精度空圧・電動アクチュエータ）まで
半導体製造装置に部材を供給しており、**装置メーカーの受注がそのまま業績に跳ね返る**。

```
【空圧メーカーにとっての半導体サイクル】

 半導体メーカーの設備投資判断 ──（数か月〜1年）──▶ 装置メーカーの受注
                                                        │（数か月）
                                                        ▼
                                      空圧・流体制御メーカーの受注（CKD・SMC 等）

 ★ 波は大きいが先行指標がはっきりしていて読みやすい。
   逆に装置メーカーが止まると、一気に在庫調整に入る
```

## 5. 油圧側：カヤバは好調、ただし理由は自動車と為替

| 会社 | 決算期 | 内容 |
| --- | --- | --- |
| カヤバ（KYB） | 2026年3月期 通期計画 | 売上高 **4,750億円**（+8.4%）、営業利益 **360億円**（+58.8%）、純利益 275億円（+84.6%） |
| 同 第3四半期まで | 2026年3月期 3Q累計 | 売上高 約3,540億円（+9.7%）、営業利益 約312億円（前年同期比 約2倍） |

- 増益の中身は**AC事業（自動車用ショックアブソーバ）とHC事業（産業用油圧）の両方が堅調**で、
  加えて**円安と、知多鋼業の完全子会社化**が寄与したと説明されている（会社発表）
- カヤバは**油圧ショベルのアーム用シリンダで世界シェア4割**とされ、
  川崎重工は**建機用コントロールバルブで世界シェア3割**とされる（業界メディアの推計）。
  日本勢は建機用の基幹油圧部品で依然として高いシェアを持つ
- ただしこれは「建機メーカーが日欧米勢である限り」の話。
  中国建機メーカーの比率が上がるほど、日本の油圧部品の出番は減る

## 6. 建機の電動化：油圧需要は消えないが、条件が厳しくなる

- コマツの電動化建機7機種が **GX建設機械の初回認定**を取得（2023年12月）。
  国交省・経産省が電動建機の普及制度を整えつつある
- ボルボCEはコンパクト電動ショベル ECR25 Electric、電動ホイールローダ L25 Electric を日本にも投入
- コベルコ建機は燃料電池式電動ショベルの試作機で稼働評価を開始、
  タダノは2026年度を最終年度とする中期経営計画で電動ラフテレーンクレーンの世界展開を表明
  （日本自動車会議所・業界報道ベース）
- 一方、**電池コストが重く車両価格が高い**点が課題で、
  普及は「様子見ムード」が拭えないとも報じられる。都市部の夜間工事（低騒音）など用途は限定的

```
【電動建機が油圧機器メーカーに突きつけるもの】

  ディーゼル建機                   電動（バッテリ）建機

  エンジン ──▶ 油圧ポンプ         電池 ──▶ モーター ──▶ 油圧ポンプ
   燃料を足せば1日動く              ★ 電池容量が有限
  「多少の油圧ロスは許容」        「1ジュールも無駄にできない」
        ▼                                ▼
  安価な油圧で十分               高効率ポンプ・ロードセンシング・
                                  エネルギー回生・EHA が必須に

  ＝ 油圧の"台数"は減らないが、"中身の要求"が一段上がる
     → 技術を持つ側に有利、価格だけの中国勢には不利になりうる
```

詳細は [③ 技術トレンド](03_技術トレンド.md)。

## 8. 全体の構図（3〜5行のまとめ）

1. **空圧は勝っている**。半導体・FA・輸出に支えられ、市場規模でも成長率でも油圧を上回った。
   SMCは売上1兆円が視野に入り、CKDは半導体需要で上方修正した
2. **油圧は構造問題を抱えている**。建機1業種に45%依存し、
   顧客の内製化と中国勢の低価格品に挟まれて価格決定力を失いつつある
3. **その帰結がナブテスコの事業売却**。世界シェア25%の事業でも儲からなければ手放す、という判断が現実に出た
4. **ただし油圧が消えるわけではない**。電動建機でも動かすのは油圧であり、
   むしろ省エネ要求が強まる分、技術を持つ側には追い風になりうる
5. **共通の答えは「単品売りをやめる」**。油圧はユニット化と省エネ制御、
   空圧は品揃え・在庫・省エア診断。どちらも顧客の電気代と停止時間で稼ぐ方向に動いている
