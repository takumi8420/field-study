油圧・空圧機器｜産業構造と儲け方

このノートで分かること：同じ「フルードパワー」でも、油圧と空圧では商売の形がまるで違う。
油圧は少数の大口メーカーに設計込みで納める重い商売、
空圧は在庫と物流で勝つ即納ビジネスである。
なぜ SMC が営業利益率20%超を出せて、油圧メーカーが苦戦するのか、その理由をここで説明する。

1. 結論：この業界は2つの別会社の集まりである

【油圧ビジネス】少数・大口・設計込み          【空圧ビジネス】多数・小口・カタログ即納

  建機メーカー（コマツ・日立建機 等）             装置メーカー（数万社）
  農機・プレス・船舶・航空機                      半導体装置・工作機械・食品機械・包装機
        ▲ 年間数万〜数十万台                            ▲ 1社あたり年数十万円〜数億円
        │                                                │
  ┌──────────────┐                    ┌──────────────┐
  │ 油圧メーカー          │                    │ 空圧メーカー          │
  │ KYB・川崎重工・ダイキン │                    │ SMC・CKD・コガネイ     │
  │ ボッシュレックスロス   │                    │ フェスト・パーカー     │
  └──────────────┘                    └──────────────┘
   ・顧客は数十社。1社失うと痛い                  ・顧客は数万社。1社失っても平気
   ・機種ごとに専用設計（型式が固定される）        ・カタログ品。品番で買える
   ・価格交渉は顧客が強い                          ・**在庫を持っている会社が勝つ**
   ・顧客の内製化が最大のリスク                    ・単価は安いが点数が膨大

この一枚で、油圧と空圧の収益性の差はほぼ説明がつく。
油圧は顧客の数が少なく、内製化されると逃げ場がない。
空圧は顧客が分散しており、価格ではなく「明日届くか」で選ばれる。

2. 油圧側の構造：建機メーカーに寄りかかった商売

JFPAの需要見通しによれば、油圧機器市場の約45%が土木建設機械向け
（JFPA 2026年需要見通し、2026年5月公表／産機通信報道ベース）。
つまり油圧機器メーカーの業績は、建設機械の販売台数でほぼ決まる。

【油圧機器メーカーが抱える3つの構造リスク】

 ①需要の集中        建機1業種で市場の45%。建機が止まれば一緒に止まる
        │
 ②顧客の内製化      建機メーカーは油圧を「差別化の中核」と見ており、
        │            ポンプ・バルブを自社で作りたがる（コマツは内製化を進めてきた）
        │
 ③中国勢の追い上げ  中国の建機メーカーが中国製油圧を採用。
                     「そこそこの品質で半額」に価格が引きずられる

この3つが同時に効いた結果が、2025〜2026年のナブテスコによる油圧機器事業の売却である。
油圧ショベル用走行ユニットで世界シェア約25%を持ちながら、
中国メーカーの台頭と建機メーカーの内製化で収益力が戻らず、
イタリアのコマー・インダストリーズへ 142億円で譲渡（2025年7月発表、2026年1月完了。日経報道）。
→ ④ 直近トピック 2026

一方で油圧には簡単には崩れない砦もある。

砦 中身
大出力・高圧領域数十トンを押す仕事に電動は物理的に届かない
過酷環境屋外・粉塵・振動・氷点下。電子部品より流体のほうが壊れにくい
安全認証が重い分野航空機の操縦系統、船舶の舵取機。実績のない部品は採用されない
補修（MRO）建機は20年使われる。稼働機がある限りシールとポンプの交換需要が続く

3. 空圧側の構造：在庫と物流が競争力そのもの

空圧機器の特徴は、1個あたりが安く、種類が膨大で、客が急いでいること。

  • シリンダ1本は数千円。電磁弁も数千円〜。1個の価格交渉に意味がない
  • 一方で1台の自動機に数十〜数百個、1つの工場ラインに数千個が入る
  • 客（装置メーカー）は納期に追われている。部品が1点来ないと装置が出荷できない

この結果、購買の判断基準が「安いか」ではなく「今すぐ手に入るか」になる。

【空圧が「即納ビジネス」になる理由】

  装置メーカーの都合                空圧メーカーの答え

  設計変更が頻繁            ─▶   品種を極端に増やす（SMCは7万点超の基本品目、
  （客の仕様が固まらない）           派生を含めると70万品目超とされる）

  1個足りないと出荷できない ─▶   **完成品在庫を厚く持つ**。
  （欠品の損害が部品代の100倍）      在庫回転率が悪くても、欠品を出さないほうが儲かる

  急に必要になる            ─▶   世界中に物流拠点。当日〜翌日出荷
                                    商社・代理店にも在庫を置かせる

  組合せが無限              ─▶   受注生産の仕組み（半製品在庫＋短時間の最終組立）

ここが空圧ビジネス最大の逆説：
教科書的な経営は「在庫を減らせ」と言うが、空圧では在庫を厚く持つほうが強い。
欠品による機会損失と信用失墜のほうが、在庫の金利負担よりはるかに高くつくからである。
SMCは部品不足が深刻だった時期にも「高在庫・短納期」で他社の欠品を奪い、
最高益を出したと報じられた（日本経済新聞、2021年11月）。

さらにSMCは代理店を「卸」ではなく自社営業の補完と位置づけ、ユーザー直販を基本にしてきた。
流通マージンが乗らない分、売上総利益率が同業を上回る構造になっている。

4. ビジネスモデルの比較

項目 油圧 空圧
顧客の数数十〜数百社（大口OEM中心）数万社（装置メーカー＋工場）
1件あたりの金額大きい（数十万〜数億円）小さい（数千円〜数百万円）
製品の性格機種ごとの専用設計・カスタムカタログ品・型番で買える標準品
勝負どころ設計力、耐久性、OEMとの共同開発品揃え・在庫・納期・販売網
価格決定力弱い（顧客が強い）比較的強い（代替が面倒、単価が小さい）
内製化リスク高い（建機メーカーが自社で作る）低い（装置メーカーが空圧部品を作る理由がない）
景気感応度建設投資・資源価格に連動設備投資全般。半導体設備の波が大きい
利益率の目安営業利益率 数%〜10%程度20%前後も可能（SMCは22%台）

5. 販路：誰を経由して届くか

【川上】              【製造】              【流通】                【川下】

 鋼材・鋳物 ──┐
 アルミ押出   ──┤
 ゴム（シール）──┼──▶ 油空圧メーカー ──┬──▶ 直販営業 ─────┬──▶ 装置メーカー（OEM）
 樹脂          ──┤                         │                        │   （設計時に型番が決まる）
 電磁コイル    ──┘                         ├──▶ 機械商社・代理店 ──┤
                                            │    （在庫を持つ）      └──▶ 工場（MRO・補修）
                                            │
                                            └──▶ MRO通販（モノタロウ、ミスミ等）
                                                  → 小口・緊急の受け皿

  ★ 付加価値が集まるのは「設計時に自社品番を入れてもらう」段階。
    いったん図面に型番が載れば、その装置が作られる限り繰り返し発注される（スペックイン）
  • 装置メーカーの設計者が図面に書いた型番は、そのまま何年も発注され続ける。
    だから空圧メーカーは営業を設計段階に張り付かせ、CADデータやカタログアプリを無料で配る
  • 補修（MRO）市場はエンドユーザーの工場が客。緊急性が高く、値引き圧力が弱い
  • 商社の役割は在庫の前線配置と与信 → 機械商社

7. 収益構造：どこで利益が出ているか

空圧メーカーの損益イメージ

  売上 100
   ├ 材料費・外注     35〜45   ← アルミ、鋼材、ゴム、電磁コイル
   ├ 製造固定費       15〜20   ← 多品種少量のため自動化投資が重い
   ├ 販管費（営業）   20〜25   ← 直販営業が多い＝人件費が重い
   └ 営業利益         15〜22   ← SMCは22%台（2026年3月期）

  在庫は重い（完成品＋半製品）。だがそれが競争力なので減らさない

サービス・省エネ提案エア漏れ診断、消費量の見える化拡大中。→ ③ 技術トレンド

8. KSF（競争要因）と参入障壁

┌────────────────────────────────────────┐
│ ①作る（鋳造・機械加工・シール・組立）                    │ ← 中国勢が到達しつつある層
├────────────────────────────────────────┤
│ ②揃える（品種数・カタログ・CADデータ・型番の標準化）      │ ← 数十年の蓄積
├────────────────────────────────────────┤
│ ③届ける（在庫・世界の物流拠点・当日出荷）                │ ← 空圧の最大の障壁
├────────────────────────────────────────┤
│ ④入り込む（設計段階でのスペックイン、営業の密着）        │ ← いったん入れば長期に効く
└────────────────────────────────────────┘
KSF なぜ効くか
品種数装置メーカーは「1社で全部揃う」ことを求める。品種が足りないと丸ごと他社に行く
在庫と即納欠品の損害は部品代の数十〜数百倍。納期が価格に優先する
スペックイン図面に型番が載れば、その装置が売れる限り発注が続く。切替には設計変更が必要
グローバル同一品番客の工場が海外に移っても同じ型番が現地で買える。日系装置メーカーの海外展開に追随
信頼性の実績空圧シリンダは数千万回の往復に耐える必要がある。実績のない会社は試されない
（油圧）OEMとの共同開発建機メーカーの機種開発に初期から入る。一度決まれば型式の寿命まで続く

逆に言えば、油圧は②③④の障壁が空圧より低い。
型式ごとの専用設計なので品種数の意味が薄く、在庫より受注生産が中心で、
顧客が内製化を選べばスペックインは崩れる。これが収益性の差として表れている。

9. 用語メモ

用語 意味
OEM向け装置・機械メーカーに部品として納める取引。新規設備の需要に連動する
MROMaintenance, Repair and Operations。工場の保守・補修用の部材需要。景気の波が小さく利益率が高い
スペックイン顧客の設計図面に自社の型番を入れてもらうこと。繰り返し受注の源泉
多品種少量品種が極端に多く、1品種あたりの数量が少ない生産形態。空圧機器の典型
即納受注から当日〜数日で出荷すること。空圧の競争力の中心
内製化顧客（建機メーカー等）が部品を自社で作るようになること。油圧メーカー最大のリスク
走行ユニット油圧ショベルのクローラを回す減速機＋油圧モータの一体品。ナブテスコが世界シェア約25%を持っていた
F.A.ファクトリーオートメーション。空圧機器の主戦場 → FA・制御機器
代理店／機械商社在庫の前線配置・与信・小口配送を担う流通。→ 機械商社
