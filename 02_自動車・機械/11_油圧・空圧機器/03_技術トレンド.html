このノートで分かること：「電動化で油圧はなくなるのか」という問いへの現実的な答えと、
省エネ・IoT・脱炭素という3つの波が、この地味な部品産業をどう作り変えつつあるか。
建機側の技術（ICT施工・自動化）は 建設機械｜テクノロジー にあるので、
ここでは機器メーカー側から見た技術に絞る。

1. 全体像：4つの潮流

┌──────────────────────────────────────────────┐
│ ④脱炭素と作動油（生分解性油、長寿命化、油量削減）            │ 始まったばかり
├──────────────────────────────────────────────┤
│ ③IoT・予知保全（センサ内蔵バルブ、エア消費の見える化）       │ 商品化が進む
├──────────────────────────────────────────────┤
│ ②省エネ制御（インバータ油圧、ロードセンシング、省エア）      │ すでに商売になっている
├──────────────────────────────────────────────┤
│ ①電動化（電動アクチュエータ、電気油圧アクチュエータ EHA）    │ 領域ごとに決着がつきつつある
└──────────────────────────────────────────────┘

共通するのは「流体を売る商売から、動きと省エネを売る商売へ」という方向。
部品単体の性能競争では中国勢に価格で追いつかれるため、
制御・ソフト・データを抱き合わせることで単価と粘着性を保とうとしている。

2. 電動化：どこが置き換わり、どこが残るのか

「電動化で油圧が消える」は言いすぎで、実際には領域ごとにきれいに決着がついている。

【この30年で起きた置き換えの順番】

 1990年代  射出成形機の型締め ──────▶ 電動サーボ化（ほぼ完了）
              理由：精度・省エネ・クリーン。中小型機は電動が標準に

 2000年代  工作機械の送り軸 ────────▶ ボールねじ＋サーボ（完了）
              理由：位置決め精度。油圧では0.001mm単位が出せない

 2010年代  自動機の中負荷シリンダ ──▶ 電動シリンダへ部分移行（進行中）
              理由：途中停止・多点位置決め・データ取得

 2020年代  建機の一部・小型機 ──────▶ 電動化（バッテリ化）は進むが
              **アクチュエータは依然として油圧**が主流（後述）
領域 置き換わったか 理由
射出成形機（中小型）ほぼ電動化精度・省エネ・油汚れなし。大型機は今も油圧
工作機械の送り電動化完了必要な精度に油圧が届かない。ただしクランプは今も油圧
産業ロボットの関節電動元から電動。ただし手先のハンドは空圧チャックが主流
自動機の位置決め軸移行中電動シリンダが単価低下。多点停止が必要な工程から置換
自動機の単純な押し引き空圧のまま電動シリンダは数万円、空圧は数千円。置き換える経済合理性がない
建機のアーム・走行油圧のまま出力密度と過負荷耐性で電動が届かない
プレス・鍛造一部サーボプレス化大トン数は油圧が有利
航空機の操縦系統一部EHAへ「More Electric Aircraft」の流れ。→ 航空機・防衛

重要な区別：建設機械の「電動化」とは、多くの場合
ディーゼルエンジンをバッテリ＋電動モーターに置き換えることであり、
アームを動かすのは相変わらず油圧ポンプとシリンダである。
つまり建機の電動化は、油圧機器メーカーにとって必ずしも需要の喪失ではない。
ただしエンジンがなくなると「限られた電池容量でいかに油を無駄にしないか」が問われ、
省エネ油圧の技術競争が一気に厳しくなる。

3. 電気油圧アクチュエータ（EHA）：油圧と電動の合体

業界で最も話題になっている折衷案が EHA（Electro-Hydraulic Actuator）。
モーター・ポンプ・シリンダ・油を1つの箱に閉じ込めた部品である。

【従来の中央集中型油圧】                【EHA：分散型】

  エンジン／電動モーター                  ┌────────────┐
        │                                  │ モーター＋ポンプ │
     油圧ポンプ                            │   ＋シリンダ     │  ← 各所に独立配置
        │                                  │   ＋油（密閉）   │
   ┌──┴──┐ 長い配管                    └────────────┘
   │        │ （漏れ・圧損・重量）              ▲ 電線だけで繋ぐ
 バルブ    バルブ                                │
   │        │                              電源・信号
 シリンダ  シリンダ                          （配管が要らない）

 利点：大出力を1台のポンプで賄える          利点：配管レス、漏れにくい、
 欠点：配管が重い・漏れる・常に油を回して          使うときだけ電力を消費（待機損失が小）
       圧損でエネルギーを捨てる                    位置・力をデジタル制御できる
                                              欠点：高価、放熱、1台あたりの出力に限界
  • 航空機（操縦舵面のバックアップ）、射出成形機、工作機械の一部で実用化が進む
  • 建機でも電動建機との相性がよいとして各社が開発中。ただしコストが課題
  • 調査会社・業界メディアでは「油圧と電子の融合（EHA）が最も議論される技術潮流」とされる
    （Power & Motion / Fluid Power World などの業界誌、2025〜2026年）

機器メーカーにとってのEHAの意味は、部品売りからユニット売りへの移行である。
ポンプ単体では中国勢と価格で戦うことになるが、
モーター・制御・ソフトを含むユニットなら選ばれる理由を作れる。

4. 省エネ制御：すでに金になっている領域

油圧側：捨てている油をやめる

従来の油圧ユニットは、必要でないときもポンプを回し続け、余った油をリリーフ弁で逃がしていた。
逃がした分のエネルギーは全部熱になって捨てられる（そのうえ油を冷やす電力も要る）。

技術 中身 効果
インバータ駆動油圧ユニット必要な流量だけモーター回転数を落として供給消費電力を大幅削減。ダイキン工業の油機事業が得意とする領域
ロードセンシング負荷が必要とする圧力だけを作る建機の標準技術。余剰圧の熱損失を抑える
可変容量ポンプ吐出量を機械的に可変古典的だが今も主力
エネルギー回生下降時・減速時の位置エネルギーを蓄圧器や電池に回収ハイブリッド建機、エレベータ、射出成形機
油量削減タンク容量を減らす設計作動油の使用量とCO2、廃油処理を減らす

空圧側：圧縮空気は「工場で最も高いエネルギー」

意外に知られていないが、圧縮空気は電気を大量に食う。
モーターで空気を押し込む過程で熱として大半が失われ、
投入電力のうち実際の仕事になるのは1〜2割程度とされる。

【圧縮空気のエネルギーの行方（イメージ）】

  電力 100
    │
  コンプレッサ ──▶ 圧縮熱として放出 ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ 約70〜80
    │
  配管 ──────▶ エア漏れ ▓▓▓▓▓ 工場全体の圧縮空気使用量の**約20%**が漏れとされる
    │           （IHI回転機械エンジニアリング、各社省エネ解説より）
    │
  機器で使う ▓▓▓ 残りわずか

だから空圧メーカーの省エネ提案は、次の3点に集約される。

手段 中身
エア漏れをなくす継手・チューブの更新、漏れ検知器での特定。休日の圧力低下量で漏れ量を推定できる
圧力を下げる必要な工程だけ高圧にし、他は減圧弁で落とす。供給圧0.1MPa低減で数%の省電力
使う量を減らす戻り工程を低圧にする省エアバルブ、吸着の間欠化、真空エジェクタの制御

この提案がそのまま商売になる。部品を売るのではなく、
工場のエア消費を測って「この改善で年間◯◯円」と示し、機器の入れ替えを取る。
→ ② 産業構造と儲け方

5. IoT・予知保全：部品にセンサを付けて売る

流体は目に見えないので、異常が起きるまで誰も気づかない。
ここにセンサとネットワークを入れる動きが進んでいる。

対象 測るもの 分かること
圧縮空気の流量計ラインごとのエア消費量漏れの発生、設備ごとの消費実態、改善効果の検証
センサ内蔵電磁弁通電回数、応答時間弁の寿命、コイル劣化の兆候
シリンダの位置センサストローク時間の変化シール劣化（動作が遅くなる）、エア圧不足
作動油の状態監視油温、粘度、水分、金属粉、汚染度ポンプの摩耗、フィルタ交換時期、故障の前兆
フィルタの差圧計前後の圧力差目詰まり。交換時期の自動通知
【予知保全が金になる理屈】

  従来：壊れてから直す                 予知：兆候で直す

  ライン停止（1時間で数十万〜数百万円）   計画停止（休日に交換）
        │                                     │
  緊急で部品を探す（在庫がなければ数日）   事前に部品を手配
        │                                     │
  復旧までの損失が部品代の100倍           部品代だけで済む

  ★ 客が払うのは「部品代」ではなく「止まらないことへの対価」。
    ここは建機のアフターサービスと同じ構図 → ../06_建設機械/02_儲け方の構造.md

業界大手（SMC、フェスト、パーカー、エマソンなど）は
センサ入りバルブとクラウドの可視化ダッシュボードに研究開発費を振り向けている
（Mordor Intelligence などの調査会社レポート、2026年）。

6. 脱炭素と作動油

論点 中身
作動油の環境影響建機の油漏れは土壌汚染になる。森林・水辺の作業では生分解性作動油が要求される地域がある
長寿命化油の交換頻度を下げれば、廃油とCO2と手間が減る。高性能フィルタと油温管理がセット
油量そのものの削減EHA化・小型化で必要な油量を減らす。ユニットあたり数十リットルが数リットルに
省エネ＝CO2削減油圧・空圧の消費電力削減がそのまま工場のスコープ2削減になる
難燃性作動油製鉄所など火気のある現場では水・グリコール系。→ 鉄鋼
GX建設機械認定制度日本では電動建機等を国が認定。需要側の制度が機器側の開発方向を決める → 建設機械

作動油そのものは石油会社の商品であり、機器メーカーは「油を選ばない機器」
「油を替えなくていい機器」の方向に動く。→ 石油元売り

7. まとめ：どの技術が、いつ金になるか

技術 現在地（2026年時点） 機器メーカーへの影響
電動アクチュエータ置換中負荷・高精度領域で進行中空圧の中〜上位品が侵食される。自社で電動も持つのが解
EHA（電気油圧）航空・成形機で実用、建機は開発段階部品売り → ユニット売りへの移行機会
省エネ油圧（インバータ等）商品として確立更新需要を取る営業ネタ。日本勢が得意
省エア・漏れ対策商品として確立診断サービス＋機器更新のセット販売
センサ内蔵・予知保全商品化が進む段階粘着性を上げる。データの蓄積が参入障壁になる
生分解性・難燃性作動油対応地域・用途限定規制が広がれば追加需要
中国勢の低価格品建機用油圧で顕在化価格では勝てない。制御・信頼性・在庫で戦う

全体の構図：単品の性能では差がつかなくなった。
油圧は「省エネとユニット化」、空圧は「品揃え・在庫・省エア診断」に活路を求めている。
どちらも 部品の値段ではなく、顧客の電気代と停止時間で勝負する方向に動いている。

8. 用語メモ

用語 意味
EHA（電気油圧アクチュエータ）モーター・ポンプ・シリンダ・油を1つの箱に収めた部品。配管が要らない
サーボ／サーボ化位置・速度・力をフィードバック制御すること。電動化の中身
インバータ制御モーターの回転数を必要な分だけに絞る制御。油圧ユニットの省エネの中心
ロードセンシング負荷が必要とする圧力・流量だけを作る油圧制御。建機の標準技術
エネルギー回生下降・減速時のエネルギーを蓄圧器や電池に回収して再利用すること
リリーフ損失余った油を安全弁から逃がすときに熱として捨てられるエネルギー
エア漏れ圧縮空気の配管・継手からの漏れ。工場の圧縮空気使用量の約20%を占めるとされる
省エアバルブ戻り行程の圧力を下げて空気消費を減らす電磁弁
真空エジェクタ圧縮空気で真空を作る部品。半導体・電子部品の吸着搬送に使う
作動油汚染度（NAS等級）油中の異物量の等級。汚れるとポンプとバルブが摩耗する
生分解性作動油漏れても微生物に分解される植物油系の作動油。環境規制地域で要求される
難燃性作動油火気のある現場向けの水・グリコール系作動油。製鉄所などで使用
スコープ2購入電力に由来するCO2排出。省エネ機器がここに効く → 脱炭素・GX
