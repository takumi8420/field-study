## 1. 業界の定義・範囲

**二輪車産業** ＝ オートバイ（原動機付自転車を含む）を設計・生産・販売する事業者と、
その部品・用品・整備・金融の周辺産業。

```
【二輪車産業の広がり】
 ┌────────────────────────────────────────────────┐
 │ 製造：完成車(このノート)／エンジン・車体部品／電装・電池            │
 │ 販売：正規ディーラー、量販店（レッドバロン等）、中古車、輸出         │
 │ 使用：用品・アパレル（ヘルメット、ウェア）、カスタムパーツ、保険、駐輪  │
 │ 整備：修理・車検（251cc以上）、タイヤ・オイル交換                  │
 │ 関連：レース（MotoGP、鈴鹿8耐）、レンタル、シェアリング、配達事業     │
 └────────────────────────────────────────────────┘
```

境界の引き方：

- **電動アシスト自転車・電動キックボード** は別扱い。ただし中国・東南アジアでは
  電動二輪との境目が曖昧で、統計上も混在することがある
- **ATV／SxS（レジャー用四輪バギー）・船外機・スノーモービル** は
  二輪メーカーの「パワースポーツ事業」として同じセグメントに入ることが多い
- **自動車（四輪）** は [自動車（完成車）](../01_自動車（完成車）/README.md)。
  同じ会社でも経済性がまったく違う

## 3. バリューチェーン（川上 → 川下）

```
 素材 ──▶ 部品 ──▶ 完成車メーカー ──▶ 販売店 ──▶ 使用 ──▶ 中古／輸出
 鋼材      エンジン部品   設計・組立     正規D/量販店  用品・整備   中古車
 アルミ    電装・FI       ブランド       与信・ローン   タイヤ・油脂  海外へ流出
 樹脂・ゴム 電池（電動）   現地生産網     試乗・コミュニティ 保険
   ▲ 利益率は中位   ▲ 中位          ▲ 事業全体で     ▲ 薄利      ▲ 利益率は高い
                                     18%台も（ホンダ二輪）
```

- 付加価値が集まるのは **(a) 完成車メーカー本体、(b) 補修部品・用品、(c) 新興国の販売金融**
- 二輪は四輪と違い **車検が250cc以下で不要** なため、整備収益は四輪ほど大きくない。
  代わりに **用品・カスタムパーツの社外品市場**が厚い
- 新興国では販売の半分以上がローン。**与信を押さえた者が販売台数を握る**

## 5. 収益モデル・コスト構造

```
利益 ＝ ①アジアの圧倒的台数 × ②現地生産・現地調達で作った薄い利ざや
       ＋ ③先進国の大型車の厚い利ざや
       ＋ ④補修部品・用品・金融という「売ったあと」の利益
       － 固定費（四輪に比べて桁がひとつ小さい）
```

| 論点             | 中身                                                                                              |
| ---------------- | ------------------------------------------------------------------------------------------------- |
| 部品点数         | 二輪は**1,500〜5,000点**。四輪の約3万点に対して1桁小さい                                          |
| 開発費           | 1車種 数億〜数十億円。四輪の数百億〜1,000億円に対して1〜2桁小さい                                 |
| 工場投資         | 数十億〜200億円規模。四輪の1ライン1,000億円〜に対して軽い                                         |
| 原価構成         | **部品・材料費が7割前後**。労務費・経費・償却が残り                                               |
| 1台あたり利益    | アジア125cc：1〜2.5万円／日本の250cc：5〜10万円／大型プレミアム：30〜80万円（いずれも推計レンジ） |
| 事業の利益率     | **ホンダ二輪は18.3%（2025年3月期）**。同社四輪やトヨタ（2026年3月期 7.4%）を大きく上回る          |
| 売ったあとの収益 | 補修部品・用品・アパレル・販売金融・保険。**保有台数に比例するので景気に強い**                    |
| 主なリスク       | 為替、新興国の金利と与信、排ガス規制対応コスト、米国関税、原材料市況                              |

> ポイント：**固定費が軽いから、台数が落ちても赤字になりにくい**。
> これが「四輪より二輪のほうが儲かる」という一見不思議な結果の正体。
> 詳細は [② 儲け方の構造](02_儲け方の構造.md)。

## 6. 競争要因（KSF）と参入障壁

**KSF（成功の鍵）**

1. **現地の販売網と整備網**：新興国で数千〜1万店規模。これがないと売っても直せない
2. **現地調達率**：部品を現地で作れないと価格が合わない。関税回避にも直結
3. **与信・販売金融**：販売の半分以上がローン。ローンを付けられるかが台数を決める
4. **耐久性と低燃費**：生活の足としては故障＝生活の停止。ブランドより信頼性
5. **ブランドとレース**：先進国の趣味層ではここが購買理由そのもの
6. **フルレンジの製品力**：50ccから1,800ccまで一貫して作れることが技術資産になる
7. **規制対応の速さ**：排ガス規制のたびに全車種を再設計できる開発体制

**参入障壁**

| 障壁               | 強さ   | 理由                                                         |
| ------------------ | ------ | ------------------------------------------------------------ |
| 車体の設計・組立   | 弱     | 四輪より簡単。中国の受託生産も使える                         |
| **現地部品網**     | **強** | 半世紀かけて作られたもの。後発が短期で作れない               |
| **販売・整備網**   | **強** | 電動スタートアップが最も苦しんだのがここ                     |
| **販売金融・与信** | 中〜強 | 現地金融機関との関係が要る                                   |
| ブランド（先進国） | 強     | 趣味市場ではブランドが購買理由。新規参入は極めて難しい       |
| 規制対応の開発力   | 中     | 排ガス・騒音・安全基準。小規模メーカーには重い               |
| 電動の技術         | 弱〜中 | 部品点数が減るので**参入は容易になる**。ここが日本勢のリスク |

## 7. 規制・法制度

| 分野               | 主な制度                                                                                                                                                   |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **車両区分・免許** | 道路交通法・道路運送車両法。原付一種／原付二種／軽二輪／小型二輪。**2025年4月1日から「新基準原付」（125cc以下かつ最高出力4.0kW以下）を原付一種として新設** |
| **排出ガス**       | 日本の**第4次排出ガス規制**（2025年11月1日から50cc以下にも適用、従来の50cc原付は生産終了）。欧州のEuro5+、インドのBS6                                      |
| **検査・整備**     | 251cc以上は車検（継続検査）が必要。**250cc以下は車検不要**で、この境目が日本独自の市場を作った                                                             |
| **安全**           | ヘルメット着用義務、ABS装着義務（新型車）、国連協定規則（WP.29）による国際調和                                                                             |
| **電動化支援**     | インドのFAME／PM E-DRIVE補助金、日本のCEV補助金、各国の購入補助                                                                                            |
| **都市規制**       | 中国の**禁摩**（主要都市でのガソリン二輪の乗り入れ規制）。ベトナムでもガソリン二輪規制の強化方針が示されている                                             |
| **通商**           | 米国の**通商拡大法232条**による関税。ハーレーは2026年1〜3月期に4,500万ドルの関税費用を計上                                                                 |
| **駐車**           | 日本では二輪の駐車場不足が長年の課題。自治体の駐輪・駐車政策が利用に影響する                                                                               |

## 8. 最近のトピック

詳細と出典は [④ 直近トピック（2026年9月時点）](04_直近トピック_2026.md)。要点だけ挙げると:

- **ホンダの二輪事業が過去最高**。2026年3月期に販売2,210万1,000台、営業利益7,319億円（+684億円）。
  四輪が電動化戦略の見直しで苦しむ中、**二輪が全社を支える構図**が鮮明になった
- **ヤマハ発動機も大幅上方修正**。2026年12月期の営業利益予想は2,600億円（前期比206%）。
  インド・ASEANの二輪需要と円安が押し上げた
- **日本の50cc原付が終了**。2025年11月から第4次排ガス規制が適用され、
  生産は2025年10月末で終了。125cc以下・4.0kW以下の「新基準原付」へ移行
- **米国関税が大型車ビジネスを直撃**。ハーレーは2026年1〜3月期に4,500万ドルの関税費用、
  通期の売上総利益率が約4ポイント低下した
- **KTMがバジャージ傘下へ**。2025年11月に約8億ユーロで支配権が移り、
  2026年1月に親会社がBajaj Mobility AGへ改称。2026年4〜6月期に再建後初のEBIT黒字
- **インドで順位が動いた**。電動二輪はTVS（24.9%）・バジャージ（22.9%）が上位に立ち、
  先行したOla Electricが後退。ホンダのスクーターシェアも41.5%→39%へ低下
- **交換式バッテリーのGachacoをホンダが連結子会社化**（2026年4月1日、出資比率34%→47%）
