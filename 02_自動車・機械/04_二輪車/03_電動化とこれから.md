# 二輪車｜電動化とこれから

**このノートで分かること**：二輪の電動化は、四輪より **早く進んでいる地域** と
**ほとんど進まない地域** にくっきり分かれる。その差はどこから来るのか。
そして、二輪だけに成立する「バッテリー交換方式」がなぜ重要なのか。

結論を先に書く。

```
【二輪の電動化を決めるのは「1回の走行距離」と「充電場所」】

  1日20km・自宅に駐輪場あり ──▶ 電動が成立する（中国、台湾、インドの都市）
  1日20km・集合住宅で充電不可 ──▶ バッテリー交換方式が要る（東南アジア、インド）
  週末に300km走る            ──▶ まだ電動では代替できない（日欧米の趣味層）
       ▲ 同じ「二輪車」でも、用途が違うので電動化の答えが3つに分かれる
```

四輪のEV化は「航続距離と充電時間」が壁になるが、
**二輪は1回の走行が短いので、その壁が最初から低い**。だから電動化が先に来た。

## 1. なぜ二輪のほうが電動化しやすいのか

| 論点                 | 四輪EV                    | 電動二輪                           | 差の理由                             |
| -------------------- | ------------------------- | ---------------------------------- | ------------------------------------ |
| 必要な電池容量       | 40〜100kWh                | **1.5〜4kWh**                      | 車重と走行距離が1桁違う              |
| 電池コストの絶対額   | 80〜200万円               | **5〜20万円**                      | 同上。値下げ余地も小さくて済む       |
| 1回の走行距離        | 20〜300km                 | **5〜30km**                        | 生活の足としては十分                 |
| 充電時間（普通充電） | 8〜12時間                 | **3〜6時間**、家庭用コンセントで可 | 容量が小さい                         |
| 電池の持ち運び       | 不可（車体に固定）        | **できる**（10〜15kg）             | ここが決定的                         |
| 車両価格への影響     | ガソリン車比 +50〜100万円 | ガソリン車比 **+3〜15万円**        | 補助金で埋めやすい                   |
| 部品点数の削減       | 大きい                    | 大きい                             | エンジン・変速機・排気系が丸ごと不要 |

> **最大の違いは「電池を外して持ち運べる」こと**。
> 四輪では非現実的なバッテリー交換方式が、二輪では実際に事業として成立している。
> これが二輪の電動化を四輪と別の道にしている。

## 2. 地域ごとに答えが違う

```
【電動二輪の普及度（イメージ、2025〜2026年）】

 中国      ■■■■■■■■■■■■■■■■■■■■■■■■■■■■■  新車の大半が電動（電動自転車含む）
 台湾      ■■■■■■■■■■■■■■■■                   交換式ステーション網が完成
 インド    ■■■■■■■                                スクーターの約13%が電動（FY2026）
 ベトナム  ■■■■■                                  規制でこれから急伸の見込み
 欧州      ■■■                                     都市スクーターから
 日本      ■                                        ほぼ進んでいない
 北米      ■                                        趣味層には受け入れられていない
```

| 地域                       | 進み方                                                                                                                                                      | 理由                                   |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------- |
| **中国**                   | 最も進んだ。都市の主要都市で **禁摩**（ガソリン二輪の乗り入れ規制）があり、そもそもガソリン二輪が締め出された。電動自転車・電動スクーターの一大市場になった | **規制が先に需要を作った**             |
| **台湾**                   | Gogoro が交換式バッテリーのステーションを全土に展開し、電動が実用的な選択肢になった                                                                         | **インフラを作り切った**               |
| **インド**                 | 2026年度のスクーター販売811万台のうち**約13%が電動**。補助金（FAME／PM E-DRIVE）が後押し                                                                    | 政府の補助金と大気汚染対策             |
| **ベトナム・インドネシア** | 大気汚染対策でガソリン二輪の規制強化方針が示され、電動化の圧力が高まっている                                                                                | 政策がこれから効く                     |
| **日本**                   | ほとんど進んでいない。市場が趣味中心で、電動の弱点（航続・音・重量）がそのまま欠点になる                                                                    | **需要側の動機がない**                 |
| **欧州**                   | 都市のシェアリング・デリバリー用スクーターから。大型は進んでいない                                                                                          | 都市規制は効くが趣味層は動かない       |
| **北米**                   | 電動は極めて限定的。ハーレーは電動事業をLiveWireとして分社したが苦戦と報じられる                                                                            | 趣味＝エンジンの音と鼓動、という価値観 |

> ポイント：**「電動化が進む＝環境意識が高い」ではない**。
> 進んでいるのは、(a) ガソリン二輪が規制で使えない、(b) 補助金が大きい、
> (c) 交換インフラがある、のいずれかが成立している地域。
> 逆に日本のように **二輪が趣味の乗り物である市場では、電動化の動機がそもそも存在しない**。

## 3. バッテリー交換方式（バッテリースワップ）

二輪の電動化を語るうえで避けて通れないのがこれ。

```
【充電式 vs 交換式】

 ■充電式（自宅・職場で充電）
   帰宅 ──▶ コンセントに挿す ──▶ 4時間待つ ──▶ 翌朝使える
     ✕ 集合住宅・路上駐車では挿す場所がない（アジアの都市の大問題）
     ✕ 電池が車両価格の3〜5割を占め、初期費用が重い

 ■交換式（ステーションで電池を入れ替える）
   走行 ──▶ 残量低下 ──▶ ステーションへ ──▶ 90秒で満充電の電池と交換 ──▶ 走行継続
     ○ 給油と同じ感覚。待ち時間ゼロ
     ○ 電池はサービス事業者の所有 → 車両価格から電池代を外せる
     ○ 電池の劣化リスクを個人が負わない
     ✕ 規格統一が必要。ステーション網の初期投資が重い
```

| 方式                     | 誰が使うか                       | 経済性                                                                     |
| ------------------------ | -------------------------------- | -------------------------------------------------------------------------- |
| **家庭充電（固定電池）** | 戸建て・駐輪場がある層           | 車両価格に電池代が乗る。最も安く始められるが充電場所が要る                 |
| **家庭充電（着脱電池）** | 集合住宅の住民                   | 電池を部屋に持ち込んで充電。日本・欧州の小型電動二輪の主流                 |
| **交換式（スワップ）**   | 都市部の高頻度利用者、デリバリー | 車両は安く買い、**電池はサブスクで月額課金**。事業者側は継続収入を得られる |

**交換式が二輪だけで成立する理由**：電池が1.5〜4kWh、重さ10〜15kgで、
**人が手で持ち運べるから**。四輪の数百kgの電池パックでは、ロボットと専用施設が必要になり
コストが合わない。二輪は自動販売機サイズの装置で済む。

### 日本の取り組み：Gachaco（ガチャコ）

| 項目         | 内容                                                                                                                                                    |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 設立         | 2022年4月。**ホンダ・ENEOSホールディングス・カワサキモータース・スズキ・ヤマハ発動機の5社**                                                             |
| 目的         | 電動二輪向けの**共通規格**交換式バッテリーのシェアリングと、そのインフラ整備                                                                            |
| 展開         | 2022年10月に東京でステーション稼働開始。2024年1月から個人向けサービス開始。東京・大阪を中心に拡大中                                                     |
| 2026年の動き | **2026年4月1日、ホンダがGachacoを連結子会社化**。第三者割当で34万株・3.4億円を引き受け、出資比率を34%→47%へ。ヤマハ発動機・スズキも追加出資（各社発表） |

> ここが重要：**日本4社が共通規格で協調している**。
> 通常なら競合同士だが、交換式は「ステーションがどこにでもある」ことが価値なので、
> 規格が割れるとどの陣営も成立しない。**インフラは競争領域ではなく協調領域**、という判断。

海外では **台湾のGogoro** が先行例で、自社規格のステーション網を全土に展開して
電動スクーターを普及させた。インドでもバジャージ・TVS・Ather らが独自またはパートナーと
交換／急速充電網を整備している。

## 4. インドの電動二輪：いま最も動いている市場

インドは **世界最大の二輪市場（2026年度 約2,170万台）** であると同時に、
電動化が最も速く進む大規模市場でもある。

| 指標                             | 数値                          | 時点・出典                         |
| -------------------------------- | ----------------------------- | ---------------------------------- |
| 二輪全体の販売                   | 約2,170万台（前年比+10.7%）   | 2026年度（FY2026）、SIAM出荷ベース |
| うちスクーター                   | 約811万台（+18.5%）で過去最高 | 同上                               |
| **スクーターに占める電動の比率** | **約13%**                     | 同上、報道ベース                   |
| 電動二輪の月次販売               | 月17万台規模                  | 2026年5月、登録ベースの報道        |

**プレイヤーの顔ぶれが数年で入れ替わった**のがこの市場の特徴。

| 企業                 | 立ち位置               | 2026年の状況                                                                       |
| -------------------- | ---------------------- | ---------------------------------------------------------------------------------- |
| **TVSモーター**      | 電動でトップ           | 2026年5月に42,376台・シェア**24.9%**（報道ベース）。既存の販売網とアフターが効いた |
| **バジャージオート** | 2位                    | 同月39,104台・シェア22.9%。Chetakブランド                                          |
| **Ather Energy**     | 専業スタートアップ     | 同月27,024台。自社充電網「Ather Grid」とファミリー向けRiztaで存在感                |
| **Ola Electric**     | 先行者だが失速         | 2024年には約3割のシェアを取ったが、2026年には順位を落としたと報じられる            |
| **ホンダ（HMSI）**   | ガソリンスクーター首位 | FY2026のスクーター販売316万台で首位維持だが、シェアは41.5%→**39%**へ低下           |

```
【インドの電動二輪でスタートアップが失速した理由（報道ベースの整理）】

  スタートアップ                     既存二輪メーカー
  ┌────────────────┐          ┌────────────────┐
  │ 製品開発は速い          │          │ 製品開発は遅い          │
  │ 補助金で価格を作れる    │          │ しかし…                │
  │ ✕ 販売網が薄い          │  ──▶    │ ○ 全国数千店の販売網    │
  │ ✕ 修理・部品が届かない  │          │ ○ 整備士と部品の供給    │
  │ ✕ 品質のばらつき        │          │ ○ 量産品質のノウハウ    │
  └────────────────┘          └────────────────┘
       先行しても、2〜3年で「売ったあとの面倒を見られる側」が勝ち始めた
```

> 教訓：**二輪の電動化は「作れるか」ではなく「売ってから直せるか」で決まる**。
> これは [② 儲け方の構造](02_儲け方の構造.md) で見た販売網の話と同じ結論に行き着く。

## 5. 中国勢と欧州プレミアム：もうひとつの競争軸

電動化と並行して、**ガソリン車の側でも勢力図が動いている**。

| 動き                     | 中身                                                                                                                                                                                              | 日本勢への影響                                                   |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| **中国勢の中大型シフト** | CFMOTO・QJMOTOR・宗申・隆鑫らが250cc超のレジャー車に進出。2025年1〜9月の中国の250cc超生産は約76.9万台で**前年同期比32%増**（中国二輪車商会ベース）。中国国内の中大型で中国ブランドのシェアは8割超 | **最も収益率が高い帯**に、価格が3〜5割安い競合が現れた           |
| **中国の輸出量**         | 2025年1〜9月の上位10社の輸出だけで約612万台、全輸出の61%（同上）。総輸出は年1,000万台規模                                                                                                         | 新興国の量販帯でも競合                                           |
| **インド勢の台頭**       | ロイヤルエンフィールドが350〜650ccで世界展開。バジャージは2025年11月に**約8億ユーロでKTMの経営権を取得**（間接保有約75%）、2026年1月に親会社がBajaj Mobility AGへ改称                             | 欧州プレミアムブランドがインド資本の傘下に入り、原価競争力を得る |
| **欧州プレミアムの再編** | KTMは2024年末に経営危機に陥り再建手続きへ。2026年第2四半期にはインド外販売が前年同期比**71%増の48,672台**、EBITDA率約8.7%まで回復し、再建後初のEBIT黒字（報道ベース）                             | ブランド×インドの原価という組み合わせが競合として立ち上がる      |

```
【日本4社が挟まれつつある構図】

                       高単価・高利益
                            ▲
      欧州プレミアム         │        ← BMW / ドゥカティ / KTM(バジャージ傘下)
      （ブランドで上を取る）  │
                            │
          ┌─────────────────────┐
          │       日本4社（全レンジ）       │  ← ここが伝統的な強み
          └─────────────────────┘
                            │
      中国勢                 │        ← CFMOTO / QJMOTOR / 宗申 / 隆鑫
      （価格で下から食う）    │           ＋ インド勢（ヒーロー / TVS / バジャージ）
                            ▼
                       低価格・大量
```

## 6. これから5〜10年で何が起きるか（見立て）

確定事実ではなく、業界の議論と政策方針から読める方向性として整理する。

| 論点           | 見立て                                                                                   | 根拠                                                                        |
| -------------- | ---------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| アジアの電動化 | **都市部から段階的に進む**。全面転換ではなく、都市＝電動／地方＝ガソリンの併存が長く続く | 充電・交換インフラは都市にしか作れない                                      |
| 交換式の規格   | **地域ごとに数規格に収れん**。日本4社＋ENEOS（Gachaco）、台湾Gogoro、インド各社          | 2026年4月のホンダによるGachaco子会社化はその布石                            |
| 先進国の大型車 | **電動化は当面進まない**。エンジンの音と鼓動が商品価値そのもの                           | LiveWire等の苦戦。カーボンニュートラル燃料の議論も                          |
| 合成燃料・水素 | 趣味の大型車を「エンジンのまま残す」選択肢として検討が続く                               | → [水素・アンモニア](../../01_注目テーマ/06_水素・アンモニア/README.md)     |
| 日本市場       | **原付一種は新基準原付（125cc・4kW以下）へ置き換わり、趣味市場だけが残る**               | 2025年11月からの第4次規制で50ccの生産が終了                                 |
| 競争           | 日本4社のシェアは **アジアの量販帯で削られる可能性**が高い                               | 中国・インド勢の販売網が成熟しつつある                                      |
| 収益           | 短期的にはむしろ良好。ホンダ二輪は2026年3月期に台数・利益とも過去最高                    | 新興国の所得上昇と上位機種化（→ [④ 直近トピック](04_直近トピック_2026.md)） |

## 7. このノートのまとめ

1. 二輪の電動化は四輪より **技術的な壁が低い**（電池が1.5〜4kWh、持ち運べる）
2. 進む地域は「規制でガソリン二輪が使えない」「補助金が大きい」「交換網がある」のいずれか
3. **バッテリー交換方式は二輪だけに成立する解**。電池を車両価格から外せるのが本質
4. 日本はGachacoで4社＋ENEOSが共通規格を組み、2026年4月にホンダが連結子会社化した
5. インドが最大の実験場。先行したスタートアップが失速し、**販売網を持つ既存勢が巻き返した**
6. 並行して中国勢が中大型に、インド勢がプレミアムブランド（KTM）に上がってきている

## 用語メモ

| ---------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| **バッテリースワップ（交換式）**         | 放電した電池をステーションで満充電のものと入れ替える方式。給油と同じ時間感覚で済む                                                |
| **Gachaco（ガチャコ）**                  | ホンダ・ENEOS HD・カワサキ・スズキ・ヤマハ発が2022年に設立した交換式バッテリーのシェアリング会社。2026年4月にホンダの連結子会社に |

| **禁摩（きんま）**                       | 中国の主要都市によるガソリン二輪の市街地乗り入れ規制。中国の電動化を決定づけた                                                    |
