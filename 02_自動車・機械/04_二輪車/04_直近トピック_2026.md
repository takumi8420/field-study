# 二輪車｜直近トピック（2026年9月時点）

報道・各社発表ベースの整理。数値は必ず年（または決算期）とセットで見ること。
確定した決算数値と、報道・推計は区別して書いている。一次情報での裏取りを前提とする。

```
【2026年の二輪業界を一言でいうと】

  四輪が関税と電動化投資で苦しむ中、二輪は
  「アジアの需要増 ＋ 円安 ＋ 上位機種化」で過去最高益が並んだ年

   ホンダ二輪 営業利益 7,319億円（過去最高）  ヤマハ発 通期予想を大幅上方修正
        ▲ ただし国内は2年連続の販売減、米国は関税、インドではシェア低下
```

## 1. ホンダ二輪が過去最高：「実は二輪の会社」

ホンダの2026年3月期（FY2026）決算では、二輪事業が全社を支える構図が鮮明になった。

| 指標                         | 2026年3月期          | 前期比                               |
| ---------------------------- | -------------------- | ------------------------------------ |
| 二輪販売台数                 | **2,210万1,000台**   | 増加（アジア・南米が牽引）。過去最高 |
| 二輪事業 営業利益            | **7,319億円**        | **+684億円**。過去最高               |
| （参考）前期の二輪営業利益率 | 18.3%（2025年3月期） | 同社の全事業で最高水準               |

- 増加の主因は **アジアと南米**。インド・ASEAN・ブラジルでの需要増と、
  110ccから125cc以上への**上位機種化（ミックス改善）**が効いたと説明されている
- 一方で四輪は電動化戦略の見直し（EV計画の縮小）に伴う損失計上などで大幅減益となり、
  第3四半期時点では「**二輪事業5,466億円が全社を1社で支えた**」という趣旨の分析が
  複数のメディアで報じられた
- ホンダは2025年のビジネスアップデートで **世界シェア50%・年3,000万台** を中長期の目標として掲げている

> 押さえどころ：日本の二輪メーカーにとって、二輪は「四輪のついで」ではない。
> **利益率でも安定性でも、二輪のほうが上**という状態が続いている。
> 構造的な理由は [② 儲け方の構造](02_儲け方の構造.md) 参照。

## 2. ヤマハ発動機も大幅な上方修正

| 指標       | 2026年12月期 通期予想（修正後）          | 前期比                     |
| ---------- | ---------------------------------------- | -------------------------- |
| 売上収益   | **2兆9,000億円**                         | 約114%                     |
| 営業利益   | **2,600億円**                            | 約206%                     |
| 連結純利益 | **1,700億円**（従来予想を700億円上回る） | 前期の約10.6倍と報じられる |

- 主力の **ランドモビリティ事業（二輪が中心）** が大幅増益。**インド・ASEANの需要が大きく伸長**
- 前期は米国での構造改革や在庫調整で利益が落ち込んでおり、その反動という面もある
- 円安も収益を押し上げている（同社発表・報道）

```
【2026年に日本の二輪勢が好調だった3つの理由】

  ①アジアの需要増          ②上位機種化              ③為替
   インド FY2026 +10.7%      110cc → 125cc以上へ      円安で海外利益の
   ASEAN も堅調              1台あたり単価と利益が上昇   円換算額が膨らむ
        │                       │                       │
        └───────────┴───────────┘
                             ▼
                  台数 × 単価 × 為替 が同時にプラス
                  （逆回転すると一気に落ちる構造でもある）
```

## 3. 国内市場：50cc原付の終了と「新基準原付」への移行

日本市場は2025〜2026年に制度の節目を迎えた。

| 時期          | 出来事                                                                                            |
| ------------- | ------------------------------------------------------------------------------------------------- |
| 2025年4月1日  | **「新基準原付」区分の新設**。総排気量125cc以下かつ最高出力4.0kW（5.4ps）以下を原付一種として扱う |
| 2025年10月末  | 従来の50cc原付の生産が事実上終了                                                                  |
| 2025年11月1日 | **第4次排出ガス規制が50cc以下にも適用**                                                           |

- 2025年の国内販売（登録・出荷）は **約36万1,990台、前年比1.6%減**。**2年連続の前年割れ**と報じられた
- 2026年は「原付は縮小するが趣味バイクは安定需要」という見立てが業界から出ている
- JAMAの2025年度二輪車市場動向調査では、**新車購入者の平均年齢が55.2歳**。
  高齢化が進み、若年層への訴求が業界課題として明示されている

> なぜ50ccが消えたのか：車両価格15万円のバイクに、
> 触媒・FI・OBDといった規制対応で1〜3万円（推計）のコストが乗ると採算が合わない。
> **規制は常に小排気量から先に殺す**（→ [② 儲け方の構造](02_儲け方の構造.md) 第6章）。

## 4. 米国関税：大型車ビジネスへの逆風

2026年も米国の関税が二輪に効いている。影響が最も見えやすいのがハーレーダビッドソン。

| 指標                      | 数値                                                            | 時点           |
| ------------------------- | --------------------------------------------------------------- | -------------- |
| 世界出荷台数              | 37,295台（前年同期比 **-3.4%**）                                | 2026年1〜3月期 |
| 世界出荷台数              | 39,209台（前年同期比 **+9.4%**）                                | 2026年4〜6月期 |
| **関税関連コスト**        | **4,500万ドル**                                                 | 2026年1〜3月期 |
| 通期の売上総利益率        | 前年比で約4ポイント低下、主因は関税                             | 会社説明       |
| 2026年通期 世界小売見通し | **13万3,500〜13万8,500台**（従来13万〜13万5,000台から引き上げ） | 2026年時点     |

- 北米の小売は2026年1〜3月期に23,803台（+14%）と伸びており、**需要が弱いというより収益性の問題**
- ハーレーは対応策として、北米向けRevolution Maxエンジンの生産を **米国内に戻す** と公表している
- 日本勢も北米で大型車・SxS（レジャー用四輪バギー）を売っているため、同じ逆風を受ける

> 四輪の関税問題（232条関税、日本は15%）と同じ構図。
> 詳細は [自動車（完成車）｜直近トピック](../01_自動車（完成車）/06_直近トピック_2026.md) を参照。

## 5. 欧州プレミアムの再編：KTMがバジャージ傘下へ

2024年末に経営危機に陥ったオーストリアのKTM（KTM・ハスクバーナ・GASGAS）は、
インドのバジャージオートの傘下で再建が進んでいる。

| 時期           | 出来事                                                                                                                                        |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| 2024年末       | KTM（親会社ピエラー・モビリティ）が経営危機、再建手続きへ                                                                                     |
| 2025年11月     | **バジャージオートが約8億ユーロでKTMの支配権を取得**。間接保有比率を約75%へ                                                                   |
| 2026年1月      | 親会社の社名が ピエラー・モビリティ → **Bajaj Mobility AG** に変更                                                                            |
| 2026年4〜6月期 | インド外でのKTM・ハスクバーナ・GASGAS販売が **48,672台（前年同期比+71%）**、EBITDA率約8.7%。再建手続き完了以来 **初のEBIT黒字**（報道ベース） |

```
【「欧州ブランド × インドの原価」という新しい組み合わせ】

  KTM（オーストリア）              バジャージ（インド）
  ┌──────────────┐            ┌──────────────┐
  │ ブランド            │            │ 低原価の量産技術    │
  │ レース実績          │  ＋       │ 新興国の販売網      │
  │ 設計・走行性能      │            │ 資本力              │
  └──────────────┘            └──────────────┘
             ▼
    300〜500ccの「入門プレミアム」を、日本勢より安く出せる体制
             ▲ 日本4社が最も利益を取ってきた帯への直撃
```

## 6. 中国勢の中大型シフト

もうひとつの構造変化。中国メーカーが **利益率の高い250cc超のレジャー車** に本格参入している。

| 指標                                     | 数値                                                          | 時点・出典                         |
| ---------------------------------------- | ------------------------------------------------------------- | ---------------------------------- |
| 中国の250cc超 生産／販売                 | 約30万4,800台／約29万7,800台（前年同期比 **+64.2%／+58.2%**） | 2025年1〜4月、中国二輪車商会ベース |
| 同上（通年ペース）                       | 約76万9,000台／約76万1,400台（前年同期比 **+32.1%／+32.9%**） | 2025年1〜9月、同上                 |
| 中国国内の中大型での中国ブランドのシェア | **80%超**（CFMOTO・QJMOTOR・宗申・隆鑫など）                  | 2025年、同上                       |
| 上位10社の輸出                           | 約611万5,500台（全輸出の **61.4%**）                          | 2025年1〜9月、同上                 |

- 中国の二輪輸出は年1,000万台規模で、量販帯ではすでに新興国で日本勢と競合している
- 2025年以降は **中大型の輸出比率が17%超へ上昇** したと報じられ、
  欧州・東南アジアのレジャー市場でも中国ブランドが並ぶようになった
- 四輪で起きた「中国勢の台頭」が、時間差で二輪にも来ているという見方ができる
  （四輪の状況は [自動車（完成車）｜競争環境と世界の勢力図](../01_自動車（完成車）/05_競争環境と世界の勢力図.md)）

## 8. 交換式バッテリー：ホンダがGachacoを連結子会社化

| 時期             | 出来事                                                                                                                                  |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| 2022年4月        | ホンダ・ENEOSホールディングス・カワサキモータース・スズキ・ヤマハ発動機の5社で **Gachaco** 設立                                         |
| 2022年10月       | 東京でバッテリー交換ステーションの稼働開始                                                                                              |
| 2024年1月        | 個人向けサービス開始                                                                                                                    |
| **2026年4月1日** | **ホンダが第三者割当で34万株・3.4億円を引き受け、出資比率34%→47%に。Gachacoを連結子会社化**。ヤマハ発動機・スズキも追加出資（各社発表） |

- ホンダは今後、電動建設機械・作業機械のユーザーへのシェアリング拡大や、
  多数の電動二輪を運用する法人向けのステーション貸与・保守にも広げる方針を示している
- **競合4社が共通規格で協調している**点がこの取り組みの本質。
  ステーション網は「どこにでもある」ことが価値なので、規格が割れると全員が負ける

## 9. 全体の構図

2026年の二輪業界は、**短期の好調と中期の不安が同居**している。

1. **短期は良い**。アジアの需要増・上位機種化・円安が重なり、ホンダ二輪は過去最高益、
   ヤマハ発は通期予想を大幅上方修正した。四輪が苦しむ中で二輪が全社を支える構図
2. **ただし好調の中身は「外部環境」に依存している**。需要・ミックス・為替の3つが同時にプラスに
   振れた結果であり、いずれかが逆回転すれば利益は速く落ちる
3. **中期のリスクは競争構造の変化**。中国勢が利益率の高い中大型へ、
   インド勢（バジャージ×KTM）がプレミアムブランドへ上がってきた。
   日本4社が最も稼いできた帯が両側から挟まれつつある
4. **電動化は地域で分岐**。インドと中国では実市場になり、日本・北米の趣味市場では進まない。
   カギはバッテリー交換インフラで、日本勢はGachacoで共同戦線を組んだ
5. **国内市場は制度的な転換点**。50cc原付が2025年で終わり新基準原付へ移行。市場は年36万台規模で2年連続減、購入者平均年齢55.2歳という構造的課題が残る

## 用語メモ

| 用語                            | 意味                                                                                                                                        |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| **FY2026**                      | 会計年度の呼び方。ホンダは2026年3月期、インドのSIAM統計は2025年4月〜2026年3月を指す。**ヤマハ発は12月決算**なので2026年12月期。混同しやすい |
