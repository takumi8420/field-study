# 二輪車｜儲け方の構造

**このノートで分かること**：二輪車メーカーは1台売っていくら儲かるのか。
なぜ「1台13万円のスクーター」を売る事業が、四輪より高い利益率を出せるのか。
そして、日本4社はなぜ世界でこれほど強いのか。

結論を先に書く。

```
二輪の利益 ＝ ①アジアの圧倒的台数 × ②現地生産・現地調達で作った薄い利ざや
             ＋ ③先進国の大型車で稼ぐ厚い利ざや
             ＋ ④補修部品・用品・金融という「売ったあと」の利益
             － 固定費（四輪に比べて桁がひとつ小さい）
```

四輪との決定的な違いは **固定費の軽さ** にある。
1台の値段は10分の1でも、工場も開発費も小さいので、**利益率はむしろ二輪のほうが高い**。

## 1. 四輪と二輪の経済性を並べて見る

| 項目                 | 四輪（完成車）             | 二輪（アジア量販）                  | 二輪（先進国大型） |
| -------------------- | -------------------------- | ----------------------------------- | ------------------ |
| 車両価格             | 200〜500万円               | **10〜25万円**                      | 80〜400万円        |
| 部品点数             | 約3万点                    | **1,500〜3,000点**                  | 3,000〜5,000点     |
| 完成車工場の投資額   | 1ライン1,000億円〜数千億円 | **数十億〜200億円規模**             | 同左               |
| 新車1車種の開発費    | 数百億〜1,000億円          | **数億〜数十億円**                  | 数十億円           |
| 損益分岐の目安       | 年20万台規模と言われる     | **年数万台**でも成立                | 年数千〜数万台     |
| 営業利益率の目安     | 5〜10%で好調               | —                                   | —                  |
| 事業全体の営業利益率 | トヨタ 7.4%（2026年3月期） | ホンダ二輪 **18.3%**（2025年3月期） | —                  |

> ポイント：**部品点数と開発費が1桁小さい**ことが、二輪の高収益の源泉。
> 四輪は「巨大な固定費を台数で割る」商売だが、二輪は固定費そのものが軽い。
> だから台数が少し落ちても赤字になりにくい。

ホンダの2026年3月期（FY2026）の二輪事業は、販売 **2,210万1,000台**、
営業利益 **7,319億円**（前期比684億円増）で、台数・利益とも過去最高（同社決算発表）。
前期の二輪営業利益率18.3%は、同社の全事業の中で最高だった。

## 2. 1台あたりの利益：桁感

```
【アジアのコミューター1台の内訳（価格15万円の例・推計）】

  小売価格 15.0万円
   ├─ 販売店の粗利          1.5〜2.5万円  ← ディーラーの取り分
   ├─ 輸送・広告・販促        0.5万円
   └─ メーカー出荷額        12.0〜13.0万円
        ├─ 部品・材料費       8.0〜9.0万円  ← 原価の7割前後
        ├─ 労務費・経費       1.5〜2.0万円
        ├─ 開発費・償却       0.5〜1.0万円
        └─ 営業利益     ★ 1.5〜2.5万円（率にして12〜18%）
```

| 区分                          | 車両価格     | 1台あたり営業利益の目安 | 備考                                                  |
| ----------------------------- | ------------ | ----------------------- | ----------------------------------------------------- |
| アジア110〜125ccコミューター  | 10〜18万円   | **1〜2.5万円**          | 薄いが年2,000万台で回る                               |
| アジア上位スクーター（PCX等） | 25〜45万円   | 3〜7万円                | 「ちょっといいバイク」帯。伸びている                  |
| 日本の軽二輪（250cc）         | 50〜80万円   | 5〜10万円               | 車検不要で売りやすい                                  |
| 先進国の中型（400〜800cc）    | 80〜150万円  | 10〜25万円              |                                                       |
| 大型・プレミアム（1,000cc超） | 200〜400万円 | **30〜80万円**          | 台数は小さいが利ざやは厚い                            |
| 電動二輪（現時点）            | 20〜60万円   | **しばしばマイナス**    | 電池コストと少量生産（→ [③](03_電動化とこれから.md)） |

※ 各社は車種別利益を公表しないため **業界で語られる推計レンジ**。桁感をつかむ用途に限る。

## 3. なぜ安く作れるのか：現地生産と現地調達

アジアで15万円のバイクを黒字で売るには、**日本から輸出していては絶対に成立しない**。
答えは「その国で作り、その国の部品で作る」こと。

```
【二輪メーカーの現地化の段階】

 ①完成車輸出        ②ノックダウン(KD)組立     ③現地生産＋現地調達     ④現地で開発まで
  日本で作って送る    部品で送って現地で組む     現地部品メーカーを育成   現地の嗜好に合わせ設計
   関税で価格が2倍に   関税を下げられる          原価が現地水準に        開発費も現地水準に
       ✕ 売れない         △ まだ高い               ○ 勝負できる           ◎ 勝ち続けられる
                                                   ▲ 日本4社はここ〜④にいる
```

- 多くの新興国は完成車輸入に **高い関税**（数十%〜100%超）をかけ、国内組立を誘導する。
  だから現地生産は「コスト戦略」であると同時に **市場に入るための条件**でもある
- 現地調達率（ローカルコンテント）を高めると、原価が現地の賃金・材料水準まで落ちる。
  主要国では9割超に達しているとされる
- **部品メーカーを一緒に連れて行く**（あるいは現地企業を育てる）のが日本勢の定石。
  ここは四輪の系列・ケイレツと同じ発想（→ [自動車部品](../02_自動車部品/README.md)）
- 為替が有利に働く年もある。ヤマハ発動機は2026年12月期の上方修正理由に
  インド・ASEANの需要増と円安を挙げている（同社発表・報道）

> ポイント：新規参入者にとっての本当の壁は、技術ではなく
> **「何十年もかけて作った現地の部品網と販売網」**。ここが二輪の参入障壁の中核。

## 5. 「売ったあと」の利益：補修部品・用品・金融

新車販売と同じくらい大事なのが、**保有台数から生まれる収益**。

```
【1台売ると、そのあと何度も稼げる】

  新車販売          補修部品・消耗品        用品・アパレル        金融・保険
  ┌────┐   5〜15年 ┌──────────┐  趣味層は ┌──────────┐  ┌──────────┐
  │利益  │ ───────▶│ タイヤ・チェーン │ ────────▶│ ヘルメット  │  │ ローン    │
  │2万円 │           │ ブレーキ・オイル │           │ ウェア      │  │ 残価設定  │
  └────┘           │ プラグ・バッテリー│           │ カスタム部品│  │ 盗難保険  │
                      └──────────┘           └──────────┘  └──────────┘
   1回きり             毎年 数千〜数万円         購入時に10〜30万円   毎月の利ざや
                       ▲ 世界の保有台数は数億台規模。ここが安定収益
```

| 収益源                   | 中身                                                 | なぜ効くか                                                             |
| ------------------------ | ---------------------------------------------------- | ---------------------------------------------------------------------- |
| **補修部品（純正部品）** | タイヤ、チェーン、ブレーキパッド、オイル、バッテリー | 新車より**利益率が高い**。保有台数に比例するので景気変動に強い         |
| **用品・アパレル**       | ヘルメット、ジャケット、グローブ、カスタムパーツ     | 趣味層は車両価格の1〜2割を用品に使う。ハーレーのアパレル事業が典型     |
| **販売金融**             | ローン、残価設定、リース                             | 新興国では**販売の半分以上がローン**。与信を押さえた者が販売台数を握る |
| **保険・サービス**       | 盗難保険、延長保証、ロードサービス                   | 継続課金。単体で薄くても台数で効く                                     |
| **レース・ブランド**     | MotoGP、鈴鹿8耐、ダカール                            | 直接の利益は出ないが、**ブランドの根拠**になる                         |

> 二輪は四輪と違い **車検（250cc以下は不要）や整備の縛りが緩い** ので、
> メーカー系ディーラーの整備収益は四輪ほど大きくない。
> その代わり **部品・用品・カスタム** の市場が大きく、社外品メーカーの層が厚い。

## 6. コスト構造とリスク

| 項目         | 性格                        | 効き方                                                                      |
| ------------ | --------------------------- | --------------------------------------------------------------------------- |
| 部品・材料費 | 変動費（原価の**7割前後**） | 鋼材・アルミ・樹脂・ゴムの市況。少量の車種ほど部品単価が高い                |
| 労務費       | 準固定費                    | 新興国工場では相対的に軽い。日本国内工場は重い                              |
| 開発費       | 固定費                      | 排ガス・騒音規制のたびに全車種の再設計が必要。**小排気量ほど負担が重い**    |
| 設備償却     | 固定費                      | 四輪より1桁小さい。稼働率の悪化に耐えやすい                                 |
| 販売網維持   | 固定費                      | 新興国では数千〜1万店規模の網。維持費が競争力そのもの                       |
| 為替         | —                           | 日本4社は輸出と海外利益の円換算で大きく振れる                               |
| **関税**     | —                           | 2026年は米国関税が重い。ハーレーは1〜3月期だけで4,500万ドルの関税費用を計上 |

**規制コストという固有のリスク**

```
【排ガス規制が小排気量を殺す仕組み】

  規制強化 ──▶ 触媒・O2センサー・燃料噴射(FI)・OBD が必須に
                 対策コスト：1台あたり 1〜3万円（推計）
                    │
        ┌───────────┴───────────┐
        ▼                                 ▼
  車両価格15万円の原付                車両価格150万円の大型車
  → 価格の10〜20%の負担 ＝ 致命的      → 価格の1〜2% ＝ 吸収できる
        │
        ▼
  日本の50cc原付は2025年10月末で生産終了（2025年11月から第4次規制適用）
```

規制は **常に小さく安いバイクから先に殺す**。これが世界的に見られる傾向で、
インドのBS6、欧州のEuro5+、日本の第4次規制のいずれでも同じことが起きた。

## 7. 日本4社はなぜ強いのか

日本勢（ホンダ・ヤマハ発動機・スズキ・カワサキモータース）は、
**世界の二輪市場で四輪よりはるかに高いシェア**を持つ。

| 企業                                    | 立ち位置                                                | 収益の柱                                                          |
| --------------------------------------- | ------------------------------------------------------- | ----------------------------------------------------------------- |
| **ホンダ**                              | 世界首位。販売2,210万台・世界シェア約4割（2026年3月期） | アジアのコミューター。二輪営業利益7,319億円は全社の支え           |
| **ヤマハ発動機**                        | 世界2位級                                               | 二輪＋マリン（船外機）。2026年12月期は営業利益2,600億円へ上方修正 |
| **スズキ**                              | インド・ASEANで存在感                                   | 二輪は四輪（インド）に次ぐ位置づけ                                |
| **カワサキモータース**                  | 大型・レジャー特化                                      | Ninja等の中大型とオフロード四輪車（SxS）。北米が主戦場            |
| **ヒーロー（印）**                      | 台数では世界最大級                                      | インド国内の低価格帯                                              |
| **TVS／バジャージ（印）**               | 急成長                                                  | TVSはインドのスクーターで28%（FY2026）。バジャージはKTMを傘下に   |
| **ハーレーダビッドソン（米）**          | 大型クルーザーの象徴                                    | 車両＋用品＋金融。2026年通期の小売見通しは13.35万〜13.85万台      |
| **BMW Motorrad／KTM／ドゥカティ（欧）** | プレミアム                                              | 高単価。KTMは経営破綻を経てバジャージ傘下で再建中                 |

強さの理由を分解すると4つ。

1. **1960〜70年代にアジアへ先に入り、現地の部品網と販売網を作り切った**。後発が追いつけない
2. **小排気量から大型まで一貫して作れる**。エンジン・車体の技術が全レンジで共有できる
3. **レースで作ったブランド**が、趣味層の購買理由として機能している
4. **四輪と違って中国勢の本格参入が遅れた**。ただしこの優位は崩れつつある（→ [③](03_電動化とこれから.md)）

> 押さえどころ：四輪で日本勢が中国勢に抜かれた（2025年、国籍別で中国が世界首位と報道）のに対し、
> **二輪ではまだ日本勢が首位を保っている**。ただし電動化がその前提を変えうる。

## 8. このノートのまとめ

1. 二輪の高収益は **固定費の軽さ** から来る。部品点数も開発費も四輪の1桁下
2. アジアの1台の利益は1〜2万円と薄いが、年2,000万台で回るので絶対額が大きい
3. 安く作れる理由は現地生産・現地調達。これは同時に **参入障壁** でもある
4. 補修部品・用品・金融という「売ったあと」の利益が、景気変動の緩衝材になる
5. 排ガス規制は常に **小排気量から先に殺す**。日本の50cc原付が消えたのがその典型
6. 日本4社の強さは、半世紀かけて作ったアジアの部品網・販売網とレースブランドにある

## 用語メモ

| 用語                                 | 意味                                                                                   |
| ------------------------------------ | -------------------------------------------------------------------------------------- |
| **現地調達率（ローカルコンテント）** | 現地で調達した部品が原価に占める割合。高いほど原価が現地水準に下がり、関税も回避できる |
| **ノックダウン生産（KD）**           | 部品の状態で輸出し、現地で組み立てる方式。完成車関税を避ける手段                       |
| **オペレーティングレバレッジ**       | 固定費が大きいほど、売上の増減が利益に増幅して効く性質。二輪は四輪より小さい           |
| **FI（フューエルインジェクション）** | 電子制御の燃料噴射装置。排ガス規制対応で小排気量にも必須になった                       |
| **OBD（車載式故障診断装置）**        | 排ガス関連の故障を車両自身が検知・記録する仕組み。規制対応コストの一部                 |
| **残価設定ローン**                   | 数年後の下取り価格をあらかじめ差し引いて分割払いする仕組み。高額な大型車で使われる     |
| **SxS（サイド・バイ・サイド）**      | 2人以上が横並びで乗るレジャー用四輪バギー。カワサキ・ホンダ等の北米の収益源            |
| **BS6／Euro5+**                      | インド／欧州の排出ガス規制の段階名。対応のたびに全車種の再設計が要る                   |
