# 建設機械｜機械と市場

**このノートで分かること**：建設機械とは具体的に何の機械の集まりなのか。
なぜ油圧ショベルだけが特別扱いされるのか。そして、
**同じ「建機メーカー」の看板の下に、建設向けと鉱山向けという別々の商売が同居している**こと。

結論を先に書くと、この業界は次の一文でほぼ説明できる。

```
建設機械の需要 ＝ ①建設投資（公共＋民間） ＋ ②資源価格（鉱山の設備投資）
                    ＋ ③更新需要（前の好況期に売った機械が寿命を迎える）
                  × ④金利（顧客はほぼ全員ローンかリースで買う）
```

需要が自分で決まらない。**客の客（発注者・資源メジャー）の懐具合で決まる**。
だから建設機械は、景気に敏感な産業の代表格として扱われる。

## 1. 建設機械とは何を指すか

「建設機械」は単一の製品ではなく、**現場で土や岩を動かす自走式の機械**の総称である。
日本建設機械工業会（CEMA）の出荷統計では、おおむね次のように分類される。

| 機種                                             | 何をする機械か                       | 位置づけ                                                            |
| ------------------------------------------------ | ------------------------------------ | ------------------------------------------------------------------- |
| **油圧ショベル**                                 | アームの先のバケットで土を掘る・積む | **業界の主力**。世界の建機市場の3〜4割を占めるとされる              |
| **ミニショベル**（6トン未満）                    | 狭い現場・住宅地向けの小型ショベル   | 欧州・日本で需要が厚い。レンタル比率が非常に高い                    |
| **ブルドーザ**                                   | 排土板（ブレード）で土を押して均す   | 造成の基本。ICT化の効果が最も分かりやすい機種                       |
| **ホイールローダ**                               | バケットで積み込む。除雪・骨材にも   | 建設以外（農業・除雪・リサイクル）の用途も広い                      |
| **クレーン（移動式）**                           | 吊り上げる                           | 別業界に近い。国内はタダノ・加藤製作所が強い                        |
| **道路機械**（ローラ、アスファルトフィニッシャ） | 舗装を敷く・締め固める               | → [道路・舗装](../../12_建設・住宅・不動産/04_道路・舗装/README.md) |
| **鉱山機械**（超大型ダンプ、大型ショベル）       | 鉱山で鉱石を掘って運ぶ               | **別の商売**。後述                                                  |
| **コンクリートポンプ車など**                     | 生コンを圧送する                     | 中国勢（SANY、Zoomlion）が強い領域                                  |

隣接業界との線引きを押さえておく。

```
【近いが違うもの】

 建設機械 ─── 農業機械         ：走る・掘るは似ているが客と販路が違う
   │                             （→ ../08_農業機械/README.md）
   ├──── 工作機械               ：金属を削る「工場の中の機械」。売り先が製造業
   │                             （→ ../07_工作機械/README.md）
   ├──── 商用車・トラック        ：公道を走る。車検・法規が中心
   │                             （→ ../05_商用車・トラック/README.md）
   ├──── 産業用ロボット          ：工場内の自動化。屋外の不確実性がない
   │                             （→ ../09_産業用ロボット/README.md）
   └──── 油圧機器               ：建機の中身。部品供給側
                                 （→ ../11_油圧・空圧機器/README.md）
```

> ポイント：建設機械は **「屋外・不整地・一品一様の現場」で動く**。
> 工場の中で決まった動きを繰り返す産業用ロボットとは、
> 求められる耐久性も、自動化の難易度も、桁が違う。

## 2. 油圧ショベルが主役になった理由

油圧ショベルは、1台で **掘る・積む・均す・壊す** を全部こなす。
アームの先の**アタッチメント**（バケット、ブレーカ、破砕機など）を差し替えるだけで、
解体現場にも、林業にも、災害復旧にも転用できる。

```
【1台の油圧ショベルが化ける】

           ┌── バケット      → 掘削・積込（標準）
           ├── ブレーカ      → コンクリート破砕
 本体 ─────┼── 圧砕機        → 解体
 （高い）   ├── グラップル    → 木材・スクラップの掴み
           └── 法面バケット  → 傾斜の仕上げ
              （安い。付け替えるだけ）
```

- 顧客から見ると、**本体は高いが汎用性が高いので稼働させやすい**＝投資回収しやすい
- メーカーから見ると、**同じ本体を世界中に売れる**＝量産効果が効く
- その結果、油圧ショベルは建機の中で最も競争が激しく、最も価格圧力が強い機種にもなった

なお油圧ショベルの心臓は**油圧ポンプ・バルブ・モーター**であり、
ここは川崎重工業やKYB、そして油圧機器の世界最大手である
ボッシュ・レックスロスや、日本では**油研工業・不二越**などの領域と重なる。
中国メーカーが長く苦戦した理由の一つが、この油圧部品の内製化の壁だった。

## 3. 「建設機械」と「鉱山機械」という2つの別世界

同じ会社が作っていても、建設向けと鉱山向けは**別の産業**だと思ったほうがいい。

| 比較軸         | 建設機械（土木・建築向け）             | 鉱山機械（マイニング向け）                         |
| -------------- | -------------------------------------- | -------------------------------------------------- |
| 客             | 中小の土木業者、レンタル会社、ゼネコン | 資源メジャー（BHP、Rio Tinto など）、大手鉱山会社  |
| 1台の価格      | 数百万円〜数千万円                     | **数億円〜十数億円**（超大型ダンプ）               |
| 台数           | 多い（世界で年間数十万台規模）         | 少ない（年間数百〜数千台規模）                     |
| 需要ドライバー | 建設投資、住宅着工、公共事業           | **資源価格と鉱山会社の設備投資計画**               |
| 稼働           | 1日8時間、現場ごとに移動               | **24時間365日、同じ鉱山で走り続ける**              |
| 部品・サービス | 販売店経由。競合部品（非純正）も入る   | **メーカーが保守契約で丸ごと抱える**。利益率が高い |
| 景気の波       | 建設サイクル（数年）                   | 資源サイクル（より長く、より激しい）               |

> ここが最大の押さえどころ：**鉱山機械は「稼働を売る商売」の先行事例**である。
> 24時間止められない現場だから、客は機械そのものよりも
> **「止まらないこと」に金を払う**。だからメーカーは保守をまるごと請け負い、
> 部品・サービスの継続収入を得る。建設向けもこの方向に寄っていく、というのが業界の大きな流れ。

数値で見ると、コマツでは鉱山機械の売上高が直近8年で2倍近くに伸び、
**2023年度には売上全体の半分近くを占める**に至ったと報じられている（ダイヤモンド・オンライン報道）。
「建機メーカー」と呼ばれながら、実態はかなりの部分が資源産業向け企業になっている。
→ [資源開発](../../11_資源・エネルギー・鉄鋼金属/02_資源開発/README.md)、
[非鉄金属](../../11_資源・エネルギー・鉄鋼金属/10_非鉄金属/README.md)

## 4. 市場規模：国内と世界

**国内（出荷ベース）**

日本建設機械工業会（CEMA）の需要予測（2025年8月公表分）では、

| 年度     | 出荷金額の予測               | 前年度比                |
| -------- | ---------------------------- | ----------------------- |
| 2024年度 | 約2兆9,400億円（実績ベース） | —                       |
| 2025年度 | **2兆8,488億円**             | 約3%減（2年連続の減少） |
| 2026年度 | **2兆8,457億円**             | ほぼ横ばい（±0%）       |

- 減少の理由として、CEMAは**金利上昇を見込んだ設備投資意欲の低下**を挙げている。
  顧客はローンやリースで買うので、金利が上がると買い控えが起きる
- この予測は年2回（2月・8月）改定される。直近の公表では2026年度・2027年度とも
  小幅増（2027年度 約3兆993億円、前年度比1%増）との予測も出ており、**最新値はCEMAのサイトで確認**
- 国内出荷のうち**輸出が半分以上**を占める年が多い。国内市場だけでは説明にならない

**世界（メーカー売上ベース）**

英KHL社が毎年公表する「Yellow Table」（世界の建機メーカー売上トップ50）が事実上の業界地図。

| 順位（2025年実績ベース、Yellow Table 2026版） | 企業                                                                                                 | 特徴                                             |
| --------------------------------------------- | ---------------------------------------------------------------------------------------------------- | ------------------------------------------------ |
| 1                                             | **キャタピラー**（米）                                                                               | 世界シェア約15%。建機部門売上 約375億ドル        |
| 2                                             | **コマツ**（日）                                                                                     | シェア約11%（2024年実績ベース）。鉱山とICTに強い |
| 3                                             | **XCMG 徐工**（中）                                                                                  | ジョンディアを抜いて3位に浮上                    |
| 4〜                                           | ジョンディア（米）、リープヘル（独）、SANY 三一（中）、ボルボCE（スウェーデン）、日立建機（日） ほか | —                                                |

- 上位10社で世界売上の**約6割**を占める寡占市場（2024年実績ベースで約61%）
- トップ50に**中国メーカーが13社**入り、うち7社が順位を上げた（2026版）。
  中国勢の台頭がこの数年の最大の構造変化

## 5. 需要は何で動くか：典型的な景気敏感産業

```
【建設機械の需要が動く経路】

 ①公共事業予算 ──┐
 ②民間建設投資 ──┼──▶ 建設会社の仕事量 ──▶ 機械の稼働時間 ──▶ 買替・増車
 ③住宅着工     ──┘                              │
                                                  ├──▶ レンタル会社の稼働率
 ④資源価格（銅・鉄鉱石・石炭・金）──▶ 鉱山会社の設備投資 ──▶ 鉱山機械受注
                                                  │
 ⑤金利 ───────────────────────────────────────┘（ローン・リースの負担）
 ⑥為替 ──▶ 輸出採算（円安は追い風）
 ⑦中古機の相場 ──▶ 下取り価格 ──▶ 新車の実質負担額
```

需要の性質を整理すると次のようになる。

| 需要の種類                 | 中身                     | 波の大きさ                                 |
| -------------------------- | ------------------------ | ------------------------------------------ |
| **新規需要**               | 事業拡大による増車       | 景気に最も敏感。好況期に集中する           |
| **更新需要**               | 寿命・保証切れによる買替 | **数年前の販売台数で読める**。業界の底支え |
| **レンタル会社の設備投資** | レンタル各社の保有機更新 | まとめ買いなので受注が塊で動く             |
| **災害復旧・インフラ補修** | 復旧工事、老朽化対策     | 政策次第。国内では重要な下支え             |

> なぜ波が大きいのか：建設機械は**買わなくても済ませられる**。
> 景気が悪ければ、客は「今ある機械をもう1年使う」「レンタルで凌ぐ」を選べる。
> だから需要は先送りされ、回復時に一気に戻る。**典型的な後ろ倒し型の設備投資財**である。

## 6. 地域別の需要：どこで売れているか

| 地域                         | 市場の性格                         | 最近の動き（2025〜2026年）                                                         |
| ---------------------------- | ---------------------------------- | ---------------------------------------------------------------------------------- |
| **北米**                     | 単価が高く利益も出やすい主戦場     | **データセンター建設**とインフラ工事で堅調。ただし米国の関税がコストを押し上げ     |
| **日本**                     | 成熟。更新需要とレンタル向けが中心 | 金利上昇と工事の人手不足で需要は弱含み                                             |
| **欧州**                     | ミニショベルと環境規制が特徴       | **電動建機が最初に育つ市場**。電気代が安く補助金もある                             |
| **中国**                     | かつて最大の成長市場               | 不動産不況で内需縮小。**現地勢が輸出に回り、世界で日欧米勢とぶつかる**             |
| **アジア（インドネシア等）** | 資源開発と連動                     | **石炭価格の停滞**でマイニング事業者の投資意欲が減退し、建機需要が低迷（2025年度） |
| **中南米・豪州・アフリカ**   | 鉱山機械の本場                     | 銅を中心に底堅い。**電化・データセンター需要で銅の増産投資**が続く                 |

- 日本メーカーにとって北米は利益の柱。ここが崩れると全社が崩れる構造は自動車と同じ
  （→ [自動車（完成車）｜儲け方の構造](../01_自動車（完成車）/03_儲け方の構造.md)）
- 逆に中国は「稼ぐ市場」から「競合が出てくる市場」へ変質した。
  中国国内で売れなくなった機械が**輸出**に回り、新興国市場での価格競争を激化させている

## 7. サプライチェーン：誰が何を作っているか

```
【川上】                    【組立】              【川下】

 鋼材・鋳鍛造 ──┐
 油圧機器      ──┤
 エンジン      ──┼──▶ 建機メーカー ──▶ 販売代理店 ──┬──▶ 建設会社（エンドユーザー）
 電装・センサー ──┤     （コマツ、        （ディーラー）  │
 電池・モーター ──┘      日立建機 等）                    ├──▶ レンタル会社 ──▶ 建設会社
                                                          │
                            ▲                             └──▶ 中古機流通 ──▶ 新興国へ輸出
                            │
                     部品・サービス（アフターマーケット）
                     ＝ここに利益が集まる（→ 02_儲け方の構造.md）
```

- **エンジン**：コマツは自社製、日立建機はいすゞなどから調達。排ガス規制対応の開発負担が重い
- **油圧機器**：内製化の度合いがコスト競争力を左右する。コマツは内製比率が高い
- **鋳鍛造・構造部材**：重量物のため輸送費が効き、需要地の近くで作る動機が働く
- **販売代理店**：**ここが参入障壁の本体**。詳しくは [儲け方の構造](02_儲け方の構造.md)

## 8. 「機械を売る商売」から「稼働を売る商売」へ

このフォルダ全体の軸をここで示しておく。

```
【従来】 機械を売る商売
  メーカー ──機械──▶ 客   「いい機械を安く、たくさん」
   売った瞬間に関係が薄くなる。次は買替のときまで会わない

【現在】 稼働を売る商売
  メーカー ══機械＋通信＋部品＋保守＋施工データ══▶ 客
   「この現場の土工事を、この工期・このコストで終わらせる」を売る
   売ったあとも毎月つながっている ＝ 継続収入と、次の販売機会
```

この移行が起きる理由は3つある。

1. **本体の値段では中国勢に勝てない**。同等スペックで大幅に安い機械が出てきた以上、
   本体だけで戦えば利益率は落ちる一方
2. **客が人手不足で困っている**。日本の建設業では技能者の高齢化と人手不足が深刻で、
   客の本当の課題は「機械が欲しい」ではなく「人が足りないまま工事を終わらせたい」に変わった
   （→ [ゼネコン](../../12_建設・住宅・不動産/01_ゼネコン/README.md)）
3. **機械がつながるようになった**。稼働データが取れるので、
   保守・部品・与信・中古相場まで**データで管理できる**（→ [テクノロジー](03_テクノロジー.md)）

## 用語メモ

- **CEMA（日本建設機械工業会）**：国内の建機メーカーの業界団体。出荷金額統計と需要予測（年2回）を公表する
- **油圧ショベル**：アームとバケットで掘削する機械。建機市場の中核機種。俗称「ユンボ」「バックホウ」
- **ミニショベル**：機体重量6トン未満クラスの小型ショベル。住宅地や狭い現場向け
- **アタッチメント**：アーム先端に付け替える作業装置（バケット、ブレーカ、圧砕機など）
- **マイニング（鉱山機械）**：鉱山向けの超大型機。単価が桁違いで、保守込みで販売されることが多い
- **Yellow Table**：英KHL社が毎年公表する世界の建機メーカー売上ランキング。事実上の業界地図
- **更新需要**：寿命を迎えた機械の買替需要。過去の販売台数から読めるため、業界の底を支える
- **アフターマーケット**：販売後の部品・整備・保守サービスの市場。→ [儲け方の構造](02_儲け方の構造.md)
