いま起きていることを一文でまとめると、次のようになる。

「売上は過去最高、利益は二桁減」
  ＝ 数量では稼げなくなり、値上げで売上を守り、
     関税とコスト増で利益を削られている局面。
     その裏で、部品・サービス・レンタル・鉱山の自動化という
     「稼働を売る商売」が着実に伸びている。

1. 売上は最高益更新、利益は二桁減（2025〜2026年）

日米の主要3社の直近決算は、揃って同じ形をしている。

会社 決算期 売上 利益
コマツ（連結）2026年3月期4兆1,328億円（前期比+0.7%、過去最高）営業利益 5,673億円（▲13.7%）、純利益 3,764億円（▲14.4%）
コマツ 建設機械・車両部門同3兆8,060億円（+0.2%）セグメント利益 4,911億円（▲18.0%）
キャタピラー Construction Industries2025年12月期—セグメント利益率 18.7%（2024年 24.2%）
キャタピラー Resource Industries同124.7億ドル（ほぼ横ばい）19.9億ドル（▲22%）、利益率 15.9%（2024年 20.4%）
日立建機2026年3月期過去最高収益を更新レンタル +13%増収、スペシャライズド・パーツ・サービス +8%増収
  • コマツは「一部地域での物量減を、継続的な販売価格改善でカバー」して売上高を過去最高に更新した、
    と説明している。つまり台数ではなく値上げで売上を守った
  • キャタピラーは建設・鉱山の両部門で利益率を大きく落としており、
    同社は主因として関税による製造コストの悪化を挙げている
  • 日立建機は新車販売の伸びが落ち着く一方、レンタルと部品・サービスが牽引した。
    ただし部品サービス（通常分）は豪州・アジアで顧客がメンテナンス投資を抑制した影響でほぼ前年並み

読み方：この業界の「良い決算」は、いま新車台数では作れない。
値上げが通るか、部品・サービス・レンタルが伸びるか、鉱山が堅いか。
決算説明資料でこの3点を確認すると、各社の立ち位置がすぐ分かる。
→ 儲け方の構造

2. 米国関税：2026年度が本当の正念場

米国の関税措置は、建機業界の2025〜2026年の最大の変数になっている。

【なぜ米国に工場があっても関税を食らうのか】

 米国工場 ◀── 部品・コンポーネント（日本・中国・欧州から輸入）
    │             ↑ ここに関税がかかる
    │
    └─▶ 完成機を米国で販売
        「現地生産しているから関税は関係ない」とはならない。
         鋼材・油圧・エンジン・電装の輸入分がコストに乗る
論点 状況（報道ベース）
影響額各社が四半期ごとに見通しを修正しており、金額は流動的。コマツ943億円・日立建機300億円程度という通期影響試算が報じられた時期もあれば、一部関税率の変更を受けてコマツ258億円・日立建機192億円へ縮小するとの報道もある
2026年度関税コストが通期で乗る最初の年にあたり、コマツ・日立建機にとって正念場とされる
対応値上げ（販売価格の改善）による転嫁が中心。相互関税が停止された局面でも「工事需要が高いため値上げは継続」と各社が説明したと報じられた
副作用円高と資源価格の下落が重なると、値上げだけでは吸収しきれない
  • キャタピラーは2025年第4四半期で、正味の追加関税影響を 6.5億〜8.0億ドル と見込み、
    そのうち約55%が建設部門、約20%が鉱山部門に発生すると説明している
  • つまり関税の負担は、単価の安い建設機械側に重く効く構造になっている

※ 関税率と影響額は制度変更と交渉で頻繁に動く。最新は各社の四半期決算で確認すること。

3. 需要の地域分化：北米と中南米が支え、アジアと国内が弱い

2025〜2026年の需要は、地域ごとに方向が割れている。

地域 方向 理由
北米強いデータセンター建設とインフラ工事。ただし関税でコストは重い
中南米・豪州底堅い鉱山向け。銅を中心とした資源需要
欧州やや回復コマツは欧州が伸長したと説明
アジア（インドネシア等）弱い石炭価格の停滞で現地マイニング事業者の投資意欲が減退
日本国内弱い金利上昇を見込んだ設備投資意欲の低下（CEMA）。工事の担い手不足も重い
中国縮小＋輸出増内需低迷。行き場を失った機械が輸出に回り、新興国で価格競争を招く

国内の出荷金額予測（日本建設機械工業会、2025年8月公表分）は次のとおり。

年度 出荷金額の予測 前年度比
2025年度2兆8,488億円約3%減（2年連続の減少）
2026年度2兆8,457億円ほぼ横ばい（±0%）
  • この予測は前回（2025年2月）から1,226億円・4.1%の下方修正だった
  • その後の公表分では2026年度・2027年度とも小幅増（2027年度 約3兆993億円、前年度比1%増）
    との予測も出ており、年2回の改定のたびに数字が動く。最新はCEMAのサイトで確認

4. 鉱山の自動化が「実証」から「商売」へ

建設現場の自動化がまだ年間数件〜数十件の試行段階なのに対し、
鉱山の無人化はすでに台数で語れる商売になった。

出来事 時期 内容
コマツ AHS 累計1,000台達成2026年4月無人ダンプ運行システム搭載車が世界で初めて累計1,000台に到達。1,000台目は積載290トンの「930E-5AT」、米Barrick MiningのNevada Gold Mines向け
コマツ AHS 累計1,016台2026年3月期決算決算資料で開示。同社は「コト価値ビジネス」の進展として説明
日立建機 AHS 本格事業化2024年〜鉱山用ダンプの自律走行システムを事業化。24時間対応のリモートサポートセンターを運用
日立建機 鉱山DX戦略2026年2月2050年に鉱山運営でネットゼロを掲げ、トロリー充電式フル電動ダンプとハイブリッドダンプを投入
コマツ 米国の鉱山機械保守拠点を3倍に2026年6月（報道）銅増産の特需に照準。保守体制の増強＝部品・サービス収入の取り込み
【なぜ保守拠点を増やすのが「戦略」なのか】

 鉱山会社の関心 ＝ 1時間止まるといくら損するか
   超大型ダンプが1台止まる → その日の搬出計画が崩れる → 数百万円〜の機会損失

 メーカーの打ち手 ＝ 部品倉庫とサービスマンを近くに置く
   → 「止まらない」を売れる → 保守契約と部品が継続収入になる
   → 機械そのものの値段競争から降りられる
  • 銅は電化とデータセンター需要で長期の増産が見込まれており、
    鉱山機械はその設備投資の直接の受け皿になる
    → 非鉄金属、
    資源開発

5. i-Construction 2.0：3年目は「試行から標準化へ」

国土交通省が2024年4月に策定した i-Construction 2.0（建設現場のオートメーション化）は、
2025年度で2年目を終えた。同省が公表した成果は次のとおり。

項目 2025年度 前年度 伸び
自動施工9件4件2倍超
遠隔施工41件21件約2倍
ICT施工 StageⅡ111件45件約2.5倍
  • ICT建設機械等認定制度は省人化建設機械へ対象を拡充された（2024年12月時点で84型式が認定済み）
  • 3年目（2026年度）は「i-Construction 2.0 躍動の年」と位置づけられ、
    AI活用／企業・工事の規模を問わない普及／試行から本格運用・標準化へがキーワードとされる
  • 数字を素直に読むと、倍々で伸びているが絶対数はまだ小さい。
    2026年の段階で「自動施工が普及した」と書くのは早い。
    実務で効いているのはマシンコントロールまでの層である
    → テクノロジー

6. 電動建機：市場はまだ立ち上がっていない

話題性に対して、実売はまだ小さい。ここは各社も率直に語っている。

論点 状況
市場現時点でほとんど存在しない。電気代が安く補助金もある欧州で先に育ちつつある
国内日立建機の電動建機の国内販売は「まだ1台」と報じられた（日経ビジネス）。理由は顧客の「買っても使えない」懸念＝現場に充電設備がないこと
制度GX建設機械認定制度（コマツの電動化建機7機種が初回認定、2023年12月）。経産省の研究会が「GX建機普及に向けたロードマップ」中間とりまとめを公表（2025年1月31日）。環境省の補正予算で商用車等の電動化促進事業（建設機械）の補助も実施
見通し脱炭素の流れは不可逆であり、今後電動化の促進や義務付けといった規制が出てくると各社は想定している

業界関係者の説明を要約すると、「市場がないから売れないのではなく、
充電インフラがないから使えない」というのが現在地。
規制（騒音・排気の制限、公共工事の要件化）と充電設備の補助が揃った地域から順に立ち上がる、
というのが共通の見立てである。
→ 脱炭素・GX

7. 中国勢の台頭：世界ランキングの順位が入れ替わった

英KHL社の「Yellow Table」（世界の建機メーカー売上ランキング）は、
この数年の構造変化をそのまま映している。

版 内容
Yellow Table 2025（2024年実績）1位キャタピラー（シェア15.9%）、2位コマツ（11.2%）、3位ジョンディア、4位XCMG（徐工）、5位リープヘル。上位10社で世界売上の約61%
Yellow Table 2026（2025年実績）1位キャタピラー（シェア約15.2%、建機部門売上 約375億ドル）、2位コマツ、3位にXCMGがジョンディアを抜いて浮上。トップ50に中国メーカー13社が入り、うち7社が順位上昇
  • 中国勢は内需の不動産不況を輸出で埋めており、新興国市場で日欧米勢と正面からぶつかる
  • 対抗軸は本体価格ではなく、部品供給網・サービス体制・稼働データという
    10年単位で積み上げた資産。ここが「稼働を売る商売」への移行を各社が急ぐ実務上の理由
  • ジェトロも貿易構造の変化から建設機械の供給網を分析しており、
    分断下でのサプライチェーン再編が論点になっている（2026年4月公表）

8. 国内レンタル：価格改定の動き

  • 国内の建機レンタル売上高は 約1兆2,397億円（2023年度、前年度比+4.9%、3年連続増）と報じられている
  • 最大手アクティオは連結売上高 約3,600億円・営業拠点444か所（2024年12月期）
  • 同社は 2026年4月ご請求分よりレンタル価格を改定すると告知した（2026年3月）。
    人件費・整備費・機械の取得価格の上昇を、レンタル料金へ転嫁する動きとみられる

レンタル料金が上がるということは、建設会社の原価が上がるということでもある。
建機メーカー → レンタル会社 → 建設会社 → 発注者、と値上げが順に転嫁されていく過程が、
いまの建設コスト上昇の一部を構成している。
→ ゼネコン

9. 全体の構図（まとめ）

【2026年の建設機械業界を1枚で】

  ＜逆風＞                              ＜追い風＞
  ・米国関税（2026年度が本番）          ・北米データセンター建設
  ・アジア／国内の需要低迷              ・銅を中心とした鉱山の設備投資
  ・金利上昇（顧客の買い控え）          ・値上げが通る市況
  ・中国勢の輸出攻勢                    ・部品・サービス、レンタルの伸び
  ・円高、資源価格の下落リスク          ・鉱山自動化（AHS 1,000台超）の商用化

        ↓                                     ↓
   新車を数量で売る商売は、もう伸びない
        ＝＝＝＝＝＝＝＝▶  稼働を売る商売へ重心を移す
   （部品・サービス／レンタル／保守契約／施工ソリューション／稼働データ）
  1. 決算の形が変わった。売上最高・利益二桁減は、値上げで数量減を埋めた結果である
  2. 関税は2026年度が本番。現地生産していても部品輸入分で効くため、逃げ切れない
  3. 需要は地域で割れている。北米と中南米の鉱山が支え、アジアと国内が沈む
  4. 自動化は鉱山で先に商売になった。建設現場はまだ試行の段階で、実務はマシンコントロールまで
  5. 電動化は制度待ち。充電インフラと規制が揃った地域から順に立ち上がる

用語メモ

  • 販売価格改善：値上げのこと。決算の要因分解でこの表現が使われる
  • コト価値ビジネス：コマツが使う用語。機械（モノ）ではなく、稼働・施工・保守（コト）で稼ぐ領域
  • AHS：鉱山向け無人ダンプトラック運行システム。コマツは累計1,000台超を導入
  • i-Construction 2.0：国交省の建設現場オートメーション化方針（2024年4月策定）
  • ICT施工 StageⅡ：施工をジャストインタイム化するなど、より進んだICT活用の段階
  • GX建設機械認定制度：電動建機等を国が認定し、補助等の対象とする日本の制度
  • Yellow Table：英KHL社が毎年公表する世界建機メーカー売上ランキング
  • トロリー充電式ダンプ：架線から給電して走る鉱山ダンプ。ルートが固定される鉱山向け
