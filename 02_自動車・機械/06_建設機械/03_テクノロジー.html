このノートで分かること：ICT施工・マシンコントロール・遠隔操作・自動化・電動化が、
それぞれ何をする技術で、どれがもう商売になっていて、どれがまだ実験段階なのか。
そして、稼働管理システムという地味な仕組みが、
なぜ与信・在庫調整・中古相場まで動かす「経営の中枢」になったのか。

この分野の技術は、すべて同じ方向を向いている。

【技術の目的はひとつ】

  機械を売る商売  ──────────────▶  稼働を売る商売
       ↑                                  ↑
  いい機械を作る技術                 現場の仕事を成立させる技術
  （エンジン、油圧、耐久性）        （測量、設計データ、自動制御、遠隔、通信）

1. 全体像：5つの技術レイヤー

┌──────────────────────────────────────────────┐
│ ⑤現場全体のデジタル化（施工管理・工程・出来形）              │ スマートコンストラクション等
├──────────────────────────────────────────────┤
│ ④自動化・遠隔操作（無人ダンプ、遠隔ショベル）                │ 鉱山では実用、建設では実証
├──────────────────────────────────────────────┤
│ ③マシンコントロール（設計データ通りに刃先が自動で動く）      │ 商用化済み・普及期
├──────────────────────────────────────────────┤
│ ②マシンガイダンス（今どこを掘っているか画面に出る）          │ 商用化済み・標準装備化
├──────────────────────────────────────────────┤
│ ①稼働管理（機械の位置・稼働時間・故障予兆を遠隔で見る）      │ 2001年〜。すでにインフラ
└──────────────────────────────────────────────┘

下の層ほど古く、確実に金になっている。上の層ほど新しく、まだ実証の色が濃い。
①②③はすでに商売になっており、④は鉱山のみ実用、⑤は育成中というのが現在地である。

2. ICT施工とは何か：測量から検査までを数字でつなぐ

従来の土工事は、「丁張り（ちょうはり）」という木の杭と板で掘る位置と深さを示し、
オペレーターが目視と経験で合わせていた。ICT施工はこれを3次元データに置き換える。

【従来の土工事】
 測量（人が歩く） → 図面（2D） → 丁張りを打つ（人） → 掘る（経験） → 検査（人が測る）
     数日              紙            数日               やり直し多い     数日

【ICT施工】
 ドローン・レーザー測量 → 3次元設計データ → 建機に読み込む → 自動制御で掘る → 出来形を機械が記録
     数時間                  3Dモデル          通信で配信       やり直しが減る   検査が同時に終わる

効果は3つに整理できる。

効果 中身
省人化丁張り作業と測量要員が要らなくなる。人手不足への直接の答え
未熟練者でも掘れる設計面より深く掘れないので、経験の浅いオペレーターでも仕上がる
やり直しが減る掘りすぎ（余掘り）が減り、その埋め戻しの手間と材料費も減る

ここが重要：ICT施工が売れる理由は「かっこいいから」ではない。
日本の建設業は技能者の高齢化と人手不足に直面しており、
客の課題が「機械が欲しい」から「人がいないまま工事を終わらせたい」に変わった。
技術がその答えになったから金を払う客が現れた、という順序である。
→ ゼネコン

国の政策が市場を作った

日本ではICT施工の普及を国土交通省が政策として押し上げている。

施策 内容
i-Construction（2016年〜）公共工事でICT施工を標準化。発注時にICT活用工事として発注する枠組み
i-Construction 2.0（2024年4月策定）「建設現場のオートメーション化」を掲げ、①施工②データ連携③施工管理の3本柱で自動化を推進
ICT建設機械等認定制度（2022年6月〜）必要な機能を備えた建機を国が認定。2024年12月時点で84型式が認定され、その後省人化建機へ対象を拡充

i-Construction 2.0 の2年目（2025年度）の成果として国交省が公表した数字は次のとおり。

項目 2025年度 前年度
自動施工の実施件数9件4件
遠隔施工の実施件数41件21件
ICT施工 StageⅡ の実施件数111件45件
  • 伸び率は大きいが、絶対数はまだ小さい。自動施工は全国で年間1桁台である
  • 3年目（2026年度）は「AI活用」「企業・工事の規模を問わない普及」「試行から本格運用・標準化へ」
    をキーワードに位置づけられている
  • つまり現状は、マシンコントロールまでは実用、完全自動化はこれからという段階

3. コマツのスマートコンストラクション：何を売っているのか

コマツが2015年に始めた「スマートコンストラクション」は、
建機メーカーが機械ではなく現場そのものを商品にした最初の大きな試みとして語られる。

【売っているもの】

 従来：  ICT建機を1台    ──▶ 顧客は自分で測量・設計・施工計画を組む

 SC： ┌ 測量（ドローン・3Dスキャン）
      ├ 3次元設計データの作成
      ├ 施工計画・土量計算
      ├ ICT建機（自社製とは限らない）
      ├ 日々の進捗の見える化（何㎥掘れたか）
      └ 出来形の記録と検査
       ↑ これを一式、サービスとして提供する
特徴 中身
対象コマツ製以外の機械や、人・材料も含めて現場全体をつなぐ思想
収益機械販売ではなく、サービス利用料・ソリューション提供料
顧客価値工期短縮と省人化。「何人・何日でこの土量を動かせるか」が可視化される
難しさ現場ごとに事情が違い、標準化しにくい。顧客側のITリテラシーにも左右される
  • コマツは決算説明でこうした領域を「コト価値ビジネス」と呼んで、モノ（機械）と区別している
  • 建機メーカーの技術説明を読むときは、「これは機械の性能の話か、現場の運用の話か」を
    区別して読むと、事業としての意味が見えやすい

4. 稼働管理システム：地味だが最も金を生んでいる仕組み

コマツのKOMTRAX（コムトラックス）は、機械に通信端末とGPSを載せ、
位置・稼働時間・燃料・エラーコードを遠隔で吸い上げる仕組みで、
2001年から標準装備化が進められた。日立建機の ConSite なども同種の仕組みである。

【稼働データが何に化けるか】

                 ┌──▶ ①サービス   ：故障予兆を検知して壊れる前に部品を届ける
                 │                     → 部品・サービス収入の獲得、客の稼働率向上
 機械 ──通信──▶ │
 （位置・稼働    ├──▶ ②与信       ：稼働していない＝支払能力が怪しい、が分かる
  時間・燃料・   │                     支払が滞れば遠隔でエンジンを始動できなくする
  エラー）       │                     → 新興国でローン販売を可能にした
                 │
                 ├──▶ ③生産・在庫 ：地域ごとの稼働時間の増減＝需要の先行指標
                 │                     → 需要が落ちる前に生産を絞れる
                 │
                 └──▶ ④中古相場   ：稼働時間と整備履歴が証明できる個体は高く売れる
                                       → 残価を強気に置ける＝新車の実質価格が下がる

この4つの使い道のうち、②と③は他業界ではあまり見ない、建機に特有の使い方である。

用途 なぜ建機で効くのか
与信顧客は中小業者が多く、信用情報が乏しい国もある。稼働実績が事実上の信用情報になる。コマツは中国市場で、KOMTRAXによる与信管理によって新規顧客にもローン販売を可能にしたとされる
在庫調整需要の波が激しい業界で、販売台数より数か月早く稼働時間が落ちる。これを見て生産と流通在庫を絞れば、値崩れと不良在庫を避けられる

押さえどころ：稼働管理は新しい技術ではなく、20年以上かけて台数を積み上げてきた資産である。
数十万台の稼働データがあるから故障予兆も需要予測も当たる。
後発が同じものを作っても、データが貯まるまでに10年かかる。
→ これが 儲け方の構造 で触れた参入障壁の正体のひとつ。

5. 遠隔操作と自動化：鉱山が先、建設が後

自動化は鉱山で先に実用化し、建設現場はまだ追いついていない。

比較軸 鉱山 建設現場
現場の環境閉鎖された私有地。一般人も一般車両も入らない公道に接し、人・通行車両・埋設物がある
作業内容決まったルートを往復して運ぶ（反復作業）毎回違う形を掘る（一品一様）
経済合理性24時間稼働・人件費・遠隔地の労務確保で効果が大きい現場が小さく、投資回収しにくい
現状商用運用中実証・限定運用

鉱山：無人ダンプ（AHS）はすでに商売になっている

  • コマツの無人ダンプトラック運行システム（AHS：Autonomous Haulage System）は
    2008年に世界で初めて商用導入され、チリ・豪州・カナダ・ブラジル・スウェーデン・米国の
    6か国で24時間365日稼働している
  • 2026年4月、AHS搭載車の累計導入台数が世界で初めて1,000台に到達したと発表された
    （1,000台目は積載290トンの「930E-5AT」、米Barrick MiningのNevada Gold Minesへ導入）。
    同社の2026年3月期決算では累計 1,016台 と開示されている
  • 日立建機も鉱山用ダンプの自律走行システムを本格事業化し、24時間対応のリモートサポートセンターを
    運用している

なぜ鉱山で先に成立したのか。

【鉱山で無人化が合う理由】

 ①同じルートを往復するだけ        → 自動運転の難易度が低い
 ②私有地で第三者がいない          → 安全要件を自社で設計できる
 ③24時間止めたくない              → 交代要員の確保より無人化のほうが安い
 ④遠隔地で人が集まらない          → そもそも人を置けない
 ⑤1台が数億円、燃料も巨額         → わずかな効率改善でも金額が大きい

→ 自動運転、
ロボット

建設：遠隔操作から入るのが現実解

建設現場では完全自動化より先に、遠隔操作が実用に近づいている。

  • 災害現場（土砂崩れ、火山、原発）では、人が入れないため昔から無人化施工が使われてきた
  • 近年は「事務所から1人が複数台を操作する」形が模索されている。実現すれば人手不足への答えになる
  • 課題は通信の遅延と体感の欠落。オペレーターは振動や音で土質を判断しており、それが伝わらないと品質が落ちる
  • 国交省の集計でも遠隔施工は2025年度で41件と、まだ試行の域

6. 電動建機：現在地はどこか

電動建機（バッテリー式の油圧ショベル等）は、話題性の割に市場がまだ小さい。
ここは正直に書いておく必要がある。

論点 現状
市場の大きさ現時点でほとんど立ち上がっていない。電気代が安く補助金もある欧州で先に育ちつつある
日本国内日立建機の電動建機の国内販売は「まだ1台」と報じられた（日経ビジネス）。理由は顧客側の「買っても使えない」懸念＝充電環境がない
最大の壁充電インフラ。建設現場には大容量の電源がない。仮設電源を引くコストが重い
稼働時間大型機ほど電力消費が大きく、1充電で1日持たせるのが難しい
制度日本では GX建設機械認定制度 があり、コマツの電動化建機7機種が初回認定を取得（2023年12月）。経産省の研究会が「GX建機普及に向けたロードマップ」の中間とりまとめを公表（2025年1月31日）。環境省の補正予算で商用車等の電動化促進事業（建設機械）の補助が実施されている
どこから普及するかミニショベル（消費電力が小さい・屋内や住宅地で騒音と排気が問題になる）から

客のメリットは排気ガスと騒音が出ないこと（屋内・トンネル・夜間・住宅地で効く）、
デメリットは車両価格・充電設備工事費・稼働時間・中古価格の読みにくさ。
補助金か、現場側の制約（騒音・排気の規制）がないと、経済合理性だけでは選ばれない。

  • 鉱山側では方向が少し違い、日立建機は2026年2月に2050年ネットゼロ戦略を発表し、
    トロリー充電式フル電動ダンプとハイブリッドダンプの投入を掲げている。
    鉱山は走るルートが決まっているので、架線（トロリー）方式が成立しやすい
  • 電動化は不可逆の流れと見られており、各社は規制が来る前提で開発を進めている
    → 脱炭素・GX、
    EV・電動化

7. 技術が収益モデルをどう変えるか

技術 「機械を売る商売」での位置づけ 「稼働を売る商売」での位置づけ
稼働管理おまけの付加機能収益の土台。売った後も客とつながり続ける回線
MG/MC高い機械を買わせるための装備未熟練者でも現場を回せるという価値の提供
自動化機械の性能自慢人を配置しないで済む＝人件費の代替
電動化コスト増現場の制約（騒音・排気）を外して仕事が取れるようにする手段

まとめると、建機の技術競争は「機械の性能」から「現場の成立」へ移った。
そして現場の成立を売るには、機械だけでなく、
通信・データ・部品供給・サービスマンの全部が要る。
これが日欧米の既存メーカーが中国勢に対して守ろうとしている陣地である。

用語メモ

  • ICT施工：測量・設計・施工・検査を3次元データでつなぐ土工事の方法。国交省が公共工事で推進
  • マシンガイダンス（MG）：設計面と刃先の位置関係を運転席のモニターに表示する機能。操作するのは人
  • マシンコントロール（MC）：設計面より深く掘れないよう、機械が自動で刃先を制御する機能
  • 丁張り：掘る位置と高さを示す木杭と板の仮設物。ICT施工が不要にした代表的な手間
  • i-Construction 2.0：国交省が2024年4月に策定した建設現場のオートメーション化方針。3本柱で構成
  • ICT建設機械等認定制度：必要な機能を備えた建機を国が認定する制度（2022年6月開始、その後拡充）
  • KOMTRAX／ConSite：コマツ／日立建機の稼働管理システム。位置・稼働時間・エラーを遠隔で収集
  • AHS（無人ダンプトラック運行システム）：鉱山で超大型ダンプを自動運転させる仕組み
  • スマートコンストラクション：コマツが提供する現場全体のデジタル化サービス。機械ではなく施工を売る
  • GX建設機械認定制度：電動建機等を国が認定し、補助金等の対象とする日本の制度
  • トロリー方式：架線から給電して走らせる方式。ルートが固定される鉱山で成立しやすい
