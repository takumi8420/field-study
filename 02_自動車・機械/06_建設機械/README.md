# 建設機械

- 大分類: 自動車・機械
- 状態: done
- 更新日: 2026-09-20

**この業界を一言で**：土や岩を動かす機械を作って売る産業。
ただし、**利益の本体は機械そのものではなく、売ったあとの部品・サービス・金融・レンタル**にある。
この10〜20年、業界全体が **「機械を売る商売」から「稼働を売る商売」へ**重心を移し続けている。
このフォルダはその一点を軸に構成している。

## 1. 業界の定義・範囲

建設機械とは、**現場で土や岩を掘る・運ぶ・均す・締め固める自走式の機械**の総称。
日本建設機械工業会（CEMA）の統計区分では、油圧ショベル、ミニショベル、ブルドーザ、
ホイールローダ、移動式クレーン、道路機械、鉱山機械などが含まれる。

隣接業界との境界は次のとおり。

| 業界                                                 | 違い                                                             |
| ---------------------------------------------------- | ---------------------------------------------------------------- |
| [農業機械](../08_農業機械/README.md)                 | 走る・掘るは似ているが、顧客（農家）と販路（農協・専門店）が別   |
| [工作機械](../07_工作機械/README.md)                 | 工場の中で金属を削る機械。売り先が製造業で、需要ドライバーが違う |
| [商用車・トラック](../05_商用車・トラック/README.md) | 公道を走る。車検・運送業の法規が中心                             |
| [産業用ロボット](../09_産業用ロボット/README.md)     | 屋内の定型作業。屋外・不整地・一品一様という難しさがない         |
| [油圧・空圧機器](../11_油圧・空圧機器/README.md)     | 建機の中身（ポンプ・バルブ・モーター）を供給する側               |
| [造船・重機](../12_造船・重機/README.md)             | 重工大手の一部が建機に隣接するが、製品も顧客も別系統             |

**同じ会社の中に2つの商売がある**点が最大の特徴。
建設向け（数百万〜数千万円の機械を多数）と、鉱山向け（数億〜十数億円の機械を少数、保守込み）は
顧客も需要ドライバーも収益構造も別物である。→ [① 機械と市場](01_機械と市場.md)

## 2. 市場規模と成長性

| 区分                     | 数値                                          | 年・出典                                               |
| ------------------------ | --------------------------------------------- | ------------------------------------------------------ |
| 国内出荷金額（予測）     | **2兆8,488億円**（前年度比約3%減、2年連続減） | 2025年度、日本建設機械工業会 需要予測（2025年8月公表） |
| 同 翌年度                | **2兆8,457億円**（ほぼ横ばい）                | 2026年度、同上                                         |
| 世界最大手の建機売上     | キャタピラー 約375億ドル、世界シェア約15%     | 2025年実績、KHL「Yellow Table 2026」                   |
| 上位10社の世界シェア合計 | 約61%                                         | 2024年実績、KHL「Yellow Table 2025」                   |
| 国内建機レンタル市場     | 約1兆2,397億円（前年度比+4.9%）               | 2023年度、業界統計（報道ベース）                       |

- 需要は自分で決まらない。**建設投資（公共＋民間）と資源価格（鉱山の設備投資）で決まる**
- そのうえ顧客はほぼ全員ローンかリースで買うため、**金利が上がると需要が落ちる**。
  CEMAは2025年度の減少要因として「金利上昇を見込んだ設備投資意欲の低下」を挙げている
- 国内メーカーの出荷は輸出比率が高く、国内市場だけでは業界を説明できない

【川上】                    【組立】                【川下】

 鋼材・鋳鍛造 ──┐
 油圧機器      ──┤
 エンジン      ──┼──▶ 建機メーカー ──▶ 販売代理店 ──┬──▶ 建設会社（エンドユーザー）
 電装・センサー ──┤   （コマツ、日立建機、  （ディーラー）│
 電池・モーター ──┘     キャタピラー 等）                  ├──▶ レンタル会社 ──▶ 建設会社
                                                            │
                            ▲                               └──▶ 中古機流通 ──▶ 新興国へ輸出
                            │                                      （20年以上使われる）
                     部品・サービス（アフターマーケット）
                     ＋ 販売金融 ＋ 稼働管理データ

- 中古機の国際流通が厚く、中古相場が下取り価格と残価を通じて**新車の実質価格を決めている**
- 客の側の事情は [ゼネコン](../../12_建設・住宅・不動産/01_ゼネコン/README.md)、

## 5. 収益モデル・コスト構造

```
利益 ＝ ①新車販売（薄い・波が大きい）
      ＋ ②部品・サービス（厚い・安定）  ← 実質的な利益の柱
      ＋ ③販売金融（ローン・リースの利ざや）
      ＋ ④レンタル・中古（保有資産の運用）
      － 固定費（開発費・工場・販売網）
```

| 収益源             | 性格                                   | 利益率のイメージ                                         |
| ------------------ | -------------------------------------- | -------------------------------------------------------- |
| 新車販売           | 景気敏感。値引き圧力が強い             | 薄い。特にミニショベル・標準ショベルは中国勢と競合       |
| **部品・サービス** | 稼働機が動く限り発生。景気の波が小さい | **厚い**（新車の2〜3倍とされる）。業界の実質的な利益の柱 |
| 鉱山機械＋保守契約 | 単価が大きく、24時間稼働で消耗も激しい | 厚い。メーカーが保守を丸ごと抱える                       |
| 販売金融           | 利ざや＋残価差益                       | 中。金利と貸倒れ、残価の読みに左右される                 |
| レンタル           | 保有資産の稼働率次第                   | 中。資産が重い                                           |

直近の実績（2025〜2026年）は「売上最高・利益二桁減」で揃っている。

| 会社                                 | 決算期       | 内容                                                                     |
| ------------------------------------ | ------------ | ------------------------------------------------------------------------ |
| コマツ（連結）                       | 2026年3月期  | 売上高 4兆1,328億円（+0.7%、過去最高）、営業利益 5,673億円（**▲13.7%**） |
| コマツ 建機・車両部門                | 同           | 売上高 3兆8,060億円、セグメント利益 4,911億円（▲18.0%）                  |
| キャタピラー Construction Industries | 2025年12月期 | 利益率 18.7%（2024年 24.2%）。関税による製造コスト増が主因               |
| キャタピラー Resource Industries     | 同           | 売上 124.7億ドル、利益 19.9億ドル（▲22%）、利益率 15.9%                  |
| 日立建機                             | 2026年3月期  | 過去最高収益。レンタル +13%、スペシャライズド・パーツ・サービス +8%      |

コスト側の要点は、**固定費（工場・開発・販売網）が重く、数量が落ちると一気に採算が悪化する**こと。
詳細は [② 儲け方の構造](02_儲け方の構造.md)。

## 6. 競争要因（KSF）と参入障壁

```
┌─────────────────────────────────┐
│ ①機械を作る（工場・油圧・エンジン・排ガス対応）   │ ← 中国勢が追いついた層
├─────────────────────────────────┤
│ ②売って貸す（代理店網・販売金融・中古の引取り）   │
├─────────────────────────────────┤
│ ③止めない（部品倉庫・サービスマン・稼働管理）     │ ← 最大の障壁。10年以上かかる
└─────────────────────────────────┘
```

| KSF                        | なぜ効くか                                                                      |
| -------------------------- | ------------------------------------------------------------------------------- |
| **販売・サービス代理店網** | 地域ごとの営業・整備・部品在庫。新規参入者は代理店を口説けない                  |
| **部品供給と即応体制**     | 現場が1日止まると顧客の損失は数十万〜数百万円。「止まらない」ことに金が払われる |
| **稼働データの蓄積**       | 数十万台分のデータがあるから故障予兆・需要予測・与信・中古査定が当たる          |
| **販売金融**               | 顧客はほぼ全員ローン・リース。貸せる会社が売れる会社になる                      |
| **ブランドと中古相場**     | 中古で高く売れる＝残価を強気に置ける＝実質価格が安くなる                        |
| **規制対応力**             | 排ガス・騒音・安全基準が国ごとに違い、認証に時間と金がかかる                    |

> **「稼働を売る商売」に移行するほど、参入障壁は高くなる。**
> 本体価格で戦えば中国勢に負けるが、「止まらないことへの対価」で戦えば、
> 代理店網とデータを持つ側が強い。日欧米勢がサービス・ソリューションへ舵を切る理由はここにある。

## 7. 規制・法制度

| 分野                      | 内容                                                                                                           |
| ------------------------- | -------------------------------------------------------------------------------------------------------------- |
| **排出ガス規制**          | 特定特殊自動車排出ガス規制法（オフロード法）。国ごとに段階規制があり、開発負担が重い                           |
| **公共工事の要件**        | 国交省の **i-Construction / i-Construction 2.0**。ICT活用工事としての発注が普及の原動力                        |
| **ICT建設機械等認定制度** | 必要な機能を備えた建機を国が認定（2022年6月開始、2024年12月時点84型式）。省人化建機へ拡充                      |
| **GX建設機械認定制度**    | 電動建機等を国が認定。コマツの電動化建機7機種が初回認定（2023年12月）                                          |
| **補助金**                | 環境省の商用車等の電動化促進事業（建設機械）、経産省のGX建機普及ロードマップ研究会（中間とりまとめ 2025年1月） |
| **安全・資格**            | 労働安全衛生法に基づく車両系建設機械運転技能講習など。オペレーターの資格制度が需要の裾野を規定する             |
| **通商・関税**            | 米国の関税措置がコスト構造を直撃。現地生産していても輸入部品分で影響を受ける                                   |

## 8. 最近のトピック

詳細は [④ 直近トピック 2026](04_直近トピック_2026.md)。要点は次の5つ。

1. **売上は過去最高、利益は二桁減**。数量減を値上げで埋め、関税とコスト増で利益が削られた（2025〜2026年）
2. **米国関税は2026年度が本番**。現地生産していても輸入部品分で効くため逃げ切れない
3. **需要は地域で割れた**。北米（データセンター建設）と中南米（鉱山・銅）が支え、
   アジア（インドネシアの石炭）と国内（金利上昇）が弱い
4. **鉱山の自動化が商売になった**。コマツのAHS搭載車は累計1,000台超（2026年4月）。
   一方で建設現場の自動施工は年間9件（2025年度、国交省）とまだ試行段階
5. **中国勢の台頭**。Yellow Table 2026でXCMGが3位に浮上、トップ50に中国13社
