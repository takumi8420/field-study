建設機械｜儲け方の構造

自動車・機械建設機械
あこのページの単語集用語に触れると意味を確認できます9語
アフターマーケット稼働機（フリート）純正部品ツース／履帯（クローラ）残価（レジデュアルバリュー）フロアプランアワーメーターオペレーティングリース／ファイナンスリース販売価格改善

このノートで分かること：建機メーカーは1台売っていくら儲かるのか。
なぜ「新車がよく売れた年」と「儲かった年」がずれるのか。
そして、利益の柱が新車ではなく部品・サービス（アフターマーケット）であるという、
この業界を理解する最大の鍵。

結論を先に書く。

建機メーカーの利益 ＝ ①新車販売（薄い・波が大きい）
                    ＋ ②部品・サービス（厚い・安定）  ← 実質的な利益の柱
                    ＋ ③販売金融（ローン・リースの利ざや）
                    ＋ ④レンタル・中古（保有資産の運用）
                    － 固定費（開発費・工場・販売網）

①は「機械を売る商売」、②〜④は「稼働を売る商売」。
この10〜20年、業界は重心を①から②〜④へ移し続けてきた。

1. 新車1台の利益：薄い

機種 価格帯の目安（新車） 粗利のイメージ コメント
ミニショベル300〜800万円薄い量産機種。中国勢との価格競争が最も激しい
標準油圧ショベル（20トン級）1,500〜3,000万円薄い〜中主力機種だが最も値引き圧力が強い
ブルドーザ・ホイールローダ2,000万円〜中ICT仕様は上乗せが取れる
移動式クレーン3,000万円〜数億円中法規・安全要件が厳しく参入者が少ない
鉱山用超大型ダンプ・ショベル数億円〜十数億円厚い保守契約とセットで売る。ここが稼ぎ頭

※ 各社は機種別の利益を公表しないため、これは業界で語られる相場感。桁感をつかむ用途に限る。

実際の決算で見ると、建機メーカーの利益率は次のような水準になる。

会社・区分 直近の実績 前年
コマツ 連結（2026年3月期）売上高 4兆1,328億円（+0.7%）、営業利益 5,673億円（▲13.7%）、純利益 3,764億円（▲14.4%）売上は過去最高を更新
コマツ 建設機械・車両部門売上高 3兆8,060億円（+0.2%）、セグメント利益 4,911億円（▲18.0%）利益率 約12.9%
キャタピラー Construction Industries（2025年12月期）セグメント利益率 18.7%2024年 24.2%
キャタピラー Resource Industries（同）売上 124.7億ドル（ほぼ横ばい）、利益 19.9億ドル、利益率 15.9%2024年 20.4%

読みどころ：売上は過去最高なのに営業利益は二桁減、というのが2025〜2026年の建機業界の姿。
値上げで売上を維持しつつ、関税とコスト増、そして販売数量の減少が利益を削った。
キャタピラーの建設部門の利益率が24.2%→18.7%へ落ちたのも、主因は関税による製造コスト増と説明されている。

2. 利益の柱：部品・サービス（アフターマーケット）

建機は壊れる前提で設計されている消耗品の塊である。
土や岩を掘るので、バケットの刃先（ツース）、走行装置（履帯＝クローラ）、
油圧ホース、フィルタ、シールは必ず摩耗する。

【1台の建機が寿命を迎えるまでに、客が払う金】

 購入時                 稼働中（10年）                    売却時
 ┌────────┐     ┌──────────────────────────┐   ┌──────┐
 │ 新車 2,000万円 │     │ 燃料・オイル                       │   │ 下取り│
 └────────┘     │ 定期整備・点検                     │   │ 300万 │
                        │ 摩耗部品（ツース、履帯、ホース）   │   └──────┘
                        │ オーバーホール                     │
                        │ 保守契約・稼働管理                 │
                        └──────────────────────────┘
                          この10年の累計は、しばしば新車価格に匹敵する

 メーカーの利益貢献：  新車＝薄い   　  部品・サービス＝厚い（利益率は新車の2〜3倍とされる）

なぜ部品・サービスの利益率が高いのか。理由は4つある。

  1. 純正部品はメーカーしか持っていない。互換部品はあるが、保証と寿命の差で純正が選ばれる
  2. 客は値段より止まらないことを優先する。現場が止まると1日数十万〜数百万円の損失が出る
  3. 競争入札にならない。新車は複数社を比べるが、壊れた機械の部品は今すぐ要る
  4. 景気の波が小さい。新車が売れない年でも、既に現場にある機械は動き続ける

日立建機の2026年3月期は、この構造がそのまま数字に出た。

事業 2026年3月期の動き
新車販売需要が落ち着き、伸びは限定的
レンタル13%の増収
スペシャライズド・パーツ・サービス8%の増収（M&A効果を含む）
部品サービス（通常）ほぼ前年並み（豪州・アジアで顧客のメンテナンス投資抑制の影響）

同社は過去最高収益を更新したと説明しており、新車ではない部分が牽引した格好になる。

だから各社は「稼働機台数（フリート）」を最重要指標として語る。
一度売った機械は、10年分の部品・サービス収入の入り口だからだ。
逆に言えば、シェアを一度失うと、そこから10年にわたって
アフターマーケットの収入も失う。だから各社は赤字覚悟でも新車のシェアを守ろうとする。

3. 販売金融：客はほぼ全員、現金で買っていない

建機の客は中小の土木業者が多く、数千万円の機械を現金一括では買えない。
そこでメーカーは金融子会社を持ち、自分で貸して自分の機械を売る。

商品 仕組み メーカーの収益源 リスク
割賦（ローン）機械代を分割で貸す調達金利と貸出金利の差（利ざや）貸倒れ
ファイナンスリース客は所有せず、実質的な分割購入利ざや＋手数料貸倒れ
オペレーティングリース数年後の残価を差し引いた分だけ払う利ざや＋残価差益残価の読み違い
在庫金融（フロアプラン）販売代理店の在庫機を担保に融資金利＋代理店の囲い込み代理店の経営悪化
保険・延長保証の取次代理店として仲介手数料—
【残価の読み違いが効く仕組み】

 新車 2,000万円、5年後の残価設定 700万円（35%）で貸す
   → 客が5年で払うのは 1,300万円 ＋ 金利。月々の負担が軽くなり、買える客が増える

 【5年後】中古相場が 800万円 → メーカーは +100万円の差益
          中古相場が 500万円 → メーカーは －200万円の残価損

 ＝＝ 中古相場を読み間違えると、新車が売れた年でも金融で損が出る ＝＝
  • 金利が上がると、客の月々の負担が増えて新車需要そのものが落ちる。
    CEMAが2025年度の需要減の理由に「金利上昇を見込んだ設備投資意欲の低下」を挙げたのはこの経路
  • 一方でメーカー金融は貸出金利も上げられるので、利ざやは必ずしも縮まない
  • 新興国では、稼働管理システムが与信そのものを可能にした。
    コマツはKOMTRAX（後述）を与信管理に使うことで、中国市場で
    信用情報のない新規顧客にもリテールファイナンスでの購入を可能にしたとされる
    → テクノロジー、リース

4. レンタル：所有から利用への移行

日本の建設現場では、機械を買わずに借りるのが主流になっている。

指標 数値 出典・年
国内の建機レンタル売上高約1兆2,397億円（前年度比+4.9%、3年連続増）2023年度、業界統計（報道ベース）
最大手アクティオの連結売上高約3,600億円、営業拠点 444か所2024年12月期
レンタル価格アクティオが2026年4月請求分より価格改定を実施同社告知（2026年3月）

レンタルが伸びる理由は、客の側の事情で説明できる。大きく5つ。①現場ごとに必要な機種が違う（全部買うと遊ぶ機械が出る）、
②工期が有限で終われば要らない、③整備・車検・保管をレンタル会社が持ってくれる、
④資産を持たずに帳簿を軽くしたい、⑤最新のICT仕様を試せる（買うと5年は古い仕様のまま）。

メーカーから見たレンタル会社は、巨大な一括購入顧客であると同時に、競合でもある。

見方 内容
顧客として数百台単位でまとめ買いしてくれる最重要顧客。値引き圧力は強い
競合としてレンタルが普及すると、エンドユーザーが新車を買わなくなる
戦略としてメーカー自身がレンタル事業を持つ（日立建機のレンタル事業が13%増収したのはこの流れ）

押さえどころ：レンタルは「機械を売る商売」から「稼働を売る商売」への移行を、
メーカーの外側で先に実現してしまったビジネスモデル。
だからメーカーはレンタルを取り込む方向（自社レンタル、サブスクリプション型の提供）に動いている。

5. 中古機：新車の値段を裏から決めている市場

建機は頑丈で、20年以上動く。だから中古機の国際市場が非常に厚い。

【建機の一生】

 日本・欧米で新車 ──10年使用──▶ 下取り ──▶ 中古市場（オークション）
                                               │
                                               ├──▶ 国内の中小業者
                                               └──▶ 東南アジア・アフリカ・中東へ輸出
                                                      さらに10〜20年使われる

中古相場が新車販売を左右する経路は3つある。

経路 仕組み
下取り価格中古が高い＝下取りが高い＝客の実質負担が軽い＝新車が売れる
残価中古が高い＝リースの残価を強気に置ける＝月額を安くできる
在庫調整中古相場が崩れると、メーカーは新車の生産を絞って市場の在庫を減らす
  • 中古相場は稼働時間（アワーメーター）と整備履歴で決まる。
    近年は稼働時間が少なく状態の良い中古機への需要が根強いとされる
  • 稼働データが記録されている機械は、履歴が証明できるぶん高く売れる。
    これも稼働管理システムが効く場面
  • 円安は中古機の輸出を後押しする。海外の買い手から見て日本の中古機が安くなるため

6. コスト構造と、利益を動かすレバー

項目 性格 動かし方
材料費・購入部品費（鋼材、油圧、エンジン）変動費。原価の大半設計での原価低減、購買集約、内製化
工場の減価償却・労務費固定費稼働率。需要が落ちると一気に採算が悪化する
研究開発費固定費だが削れない排ガス規制、電動化、自動化で増加圧力
販売代理店網の維持固定費統廃合。ただし切りすぎると顧客接点を失う
関税近年の新しい変動要因生産地の見直し、値上げでの転嫁
為替—日本勢は円安が追い風

損益改善の王道は自動車と同じで3つしかない。
(1) 値上げ、(2) 原価低減、(3) 数量を戻す（稼働率）。
2025〜2026年の建機各社は、(3) が効かない中で (1) の値上げで凌いだ。
コマツが「一部地域の需要減を継続的な販売価格改善でカバー」し売上高を過去最高にしたのはその典型。

7. 参入障壁：本当の壁は工場ではなく販売網

機械そのものは、中国メーカーが証明したとおり作れるようになる。
しかし建機で本当に難しいのは、売ったあとの面倒を全国・全世界で見る体制である。

【建機ビジネスに必要な3層】

 ┌─────────────────────────────────┐
 │ ①機械を作る                                      │ ← 中国勢が追いついた層
 │   工場、油圧、エンジン、排ガス対応                │
 ├─────────────────────────────────┤
 │ ②売って貸す                                      │ ← 金融・代理店・在庫
 │   販売代理店網、販売金融、中古の引き取り          │
 ├─────────────────────────────────┤
 │ ③止めない                                        │ ← ここが最大の障壁
 │   部品倉庫、サービスマン、24時間対応、稼働管理    │
 │   ＝10年以上かけないと作れない                    │
 └─────────────────────────────────┘
障壁 中身 なぜ効くか
販売・サービス代理店網地域ごとの代理店。営業・整備・部品在庫を持つ新規参入者は代理店を口説けない。既存メーカーとの関係が深い
部品供給網どの部品も翌日に届く倉庫と物流「止まらない」を保証する実体。真似に最も時間がかかる
サービスマン現地で修理できる技能者育成に年単位。人手不足で希少性が増している
稼働データ数十万台の稼働実績故障予兆・与信・中古相場の精度に直結。台数がないと貯まらない
規制対応排ガス、騒音、安全基準が国ごとに違う認証取得のコストと時間
ブランドと中古相場中古で高く売れるブランドは新車も売りやすい残価が強気に置ける＝実質価格が安くなる

この構造を一言でいうと、「稼働を売る商売」に移行するほど、参入障壁は高くなる。
機械の値段で戦えば中国勢に負けるが、
「止まらないことへの対価」で戦えば、代理店網とデータを持つ側が強い。
日欧米勢が揃ってサービス・ソリューションへ舵を切っているのは、この計算による。

8. 決算の読みどころ（建機特有）

見る場所 何が分かるか
建設機械・車両部門の利益率10%台前半なら平常、一桁に落ちたら警戒
部品・サービスの伸び率新車と分けて開示する会社が増えた。稼働機の健康状態が読める
レンタル収入保有資産の運用がうまくいっているか
地域別売上北米依存度、アジア（インドネシア＝石炭）の変調
鉱山機械（マイニング）の比率資源サイクルへの感応度
販売金融の債権残高と貸倒引当金新興国での与信リスク
流通在庫（ディーラー在庫）積み上がると翌期の生産調整＝減益の予兆
関税・為替の影響額各社が要因分解を開示する。実力を見るならここを除いて見る

用語メモ

  • アフターマーケット：販売後の部品・整備・保守の市場。新車より利益率が高く、景気の波が小さい
  • 稼働機（フリート）：市場で現に動いている自社製機械の総数。将来の部品・サービス収入の母数
  • 純正部品：メーカー供給の正規部品。互換品より高いが保証と寿命で選ばれる
  • ツース／履帯（クローラ）：バケットの刃先／走行用のキャタピラ。どちらも摩耗する代表的な消耗品
  • 残価（レジデュアルバリュー）：リース満了時の想定価値。読み違えると損失が出る
  • フロアプラン：販売代理店の在庫機を担保にした在庫金融
  • アワーメーター：機械の稼働時間計。中古査定の最重要指標。自動車の走行距離にあたる
  • オペレーティングリース／ファイナンスリース：前者は残価を差し引いた利用料、後者は実質的な分割購入
  • 販売価格改善：値上げのこと。決算の要因分解でこの表現が使われる
