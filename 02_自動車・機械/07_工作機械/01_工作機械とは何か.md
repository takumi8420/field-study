# 工作機械とは何か（マザーマシン）

**このノートで分かること**：工作機械が「何をする機械」で、旋盤・マシニングセンタ・研削盤がどう違い、
なぜ「精度」と「剛性」がそんなに難しいのか。そして NC（数値制御）という頭脳を誰が握っているのか。

結論を先に言うと、工作機械とは **金属の塊を削って部品の形にする機械** であり、
**その工作機械自身も工作機械で作られる**。だから「機械を作る機械＝マザーマシン（母なる機械）」と呼ばれる。
自動車も飛行機もスマホの金型も、元をたどれば必ずどこかの工作機械が削った部品でできている。

---

## 1. 定義：何をもって「工作機械」と呼ぶか

日本工作機械工業会（JMTBA）の整理では、工作機械とは
**「主として金属の工作物を、切削・研削などによって不要な部分を取り除き、必要な形状・寸法・精度に加工する機械」**。
ポイントは3つ。

| 条件 | 意味 | 外れる例 |
| --- | --- | --- |
| 対象が**金属**中心 | 木工機械・繊維機械は別カテゴリ | 木工旋盤、射出成形機（プラスチック） |
| **動力で駆動**される | 手工具は含まない | ヤスリ、ハンドドリル |
| **工具を保持して相対運動**させる | 素材を型で潰すだけの機械は「鍛圧機械」として区別されることが多い | プレス機、鍛造機 |

ただし実務上は、金属を **削る／曲げる／付ける** の3系統をまとめて「工作機械・鍛圧機械」と呼ぶことが多い。
この3つの違いが、業界の地図そのものになっている。

```
                  金属を「部品の形」にする3つの方法
  ┌──────────────┬──────────────┬──────────────┐
  │  除去加工     │  塑性加工     │  付加加工     │
  │（削る）       │（曲げる・潰す）│（積む）       │
  ├──────────────┼──────────────┼──────────────┤
  │ 旋盤          │ プレス機      │ 金属3Dプリンタ │
  │ マシニングセンタ│ ベンダー      │（AM＝Additive │
  │ 研削盤        │ 鍛造機        │  Manufacturing）│
  │ 放電加工機    │ 板金加工機    │               │
  ├──────────────┼──────────────┼──────────────┤
  │ 狭義の「工作機械」│「鍛圧機械」  │ 新領域・量産は  │
  │ ＝JMTBA統計の対象│ 別統計        │ まだ限定的     │
  └──────────────┴──────────────┴──────────────┘
      材料がムダになるが     材料ムダが少なく速い   複雑形状が一発で作れるが
      形の自由度と精度は最強  金型が要る（初期費用大） 遅く・高く・表面が粗い
```

> ポイント：**JMTBA の受注統計が扱うのは左の「削る」機械**。
> ニュースで「工作機械受注」と言えば、ほぼこの切削・研削の世界の話だと思ってよい。

## 2. 機種の違い：旋盤・マシニングセンタ・複合機・研削盤

一番の分かれ目は **「ワーク（加工物）が回るのか、工具が回るのか」**。ここだけ押さえれば機種名は迷わない。

| 機種 | 何が回るか | 得意な形 | 典型的な加工対象 |
| --- | --- | --- | --- |
| **旋盤（NC旋盤）** | ワークが回る。工具（バイト）は固定して押し当てる | **丸いもの**（円筒・円錐・ネジ） | シャフト、ボルト、ベアリング内外輪、油圧部品 |
| **マシニングセンタ（MC）** | 工具が回る。ワークはテーブルに固定 | **四角いもの・穴・溝・曲面** | エンジンブロック、金型、ロボットの関節部品 |
| **複合加工機** | 両方。旋削主軸＋回転工具を1台に | 丸と四角が混ざった部品 | 医療用インプラント、航空部品、圧縮機部品 |
| **研削盤** | 砥石（といし）が高速回転 | **仕上げ**。ミクロン単位の寸法出し・鏡面 | ベアリング軌道面、カムシャフト、金型の仕上げ |
| **放電加工機（EDM）** | 放電の火花で溶かす（力をかけない） | 超硬材、深く細い穴、鋭い角 | 金型、タービンブレードの冷却穴 |
| **歯車加工機（ホブ盤等）** | 専用工具で歯を刻む | 歯車 | 変速機、減速機、ロボット用減速機 |

### 「センタ」とは何か

MC の「センタ（center）」は **工具を自動で取り替えられる**という意味。
機械の横にマガジン（工具の倉庫）が付いていて、**ATC（自動工具交換装置）** がプログラム通りに
ドリル→エンドミル→タップ…と差し替える。人が付きっきりでなくてよいので、これが自動化の起点になった。

さらに **APC（自動パレット交換装置）** を足すと、加工中に次のワークを段取りできる。
パレットを何枚も並べた **FMS（フレキシブル生産システム）** まで行くと、夜間無人運転になる。

```
  単機 ──▶ ATC付き ──▶ APC付き ──▶ ロボット/AGV連携 ──▶ FMS（無人ライン）
  人が工具交換   工具は自動   ワークも自動    搬送も自動     計画も自動
    │            │            │              │              │
  価格 数百万〜  1千万〜     2千万〜        5千万〜        数億〜数十億
    └── 売る側の利益率は右にいくほど高い（＝ライン提案のうまみ）──▶
```

## 3. 頭脳＝NC（数値制御）。ここをファナックが握っている

**NC（Numerical Control＝数値制御）** とは、「工具をどこへ、どの速さで動かすか」を
数値プログラムで指示する仕組み。コンピュータを内蔵した現代のものは **CNC** と呼ぶ。
プログラムは今も **G コード**（`G01 X100. Y50. F200` ＝ 直線でX100,Y50へ送り速度200で動け）という
1950年代生まれの記法が基本で、実際には CAD/CAM ソフトが自動生成する。

```
  3D CAD（形を描く）
      ↓  形状データ
  CAM（工具の通り道を決める）
      ↓  NCプログラム（Gコード）
  CNC装置 ＝ 機械の頭脳   ← ここがファナック / ハイデンハイン / シーメンス
      ↓  指令パルス
  サーボモータ＋ボールネジ ＝ 機械の手足
      ↓
  主軸が回り、テーブルが動き、削れる
```

| 層 | 役割 | 主なプレイヤー | 備考 |
| --- | --- | --- | --- |
| CAD/CAM | 形状と工具経路 | Autodesk、Siemens、Dassault、CGTech | ソフト。ライセンス課金 |
| **CNC装置** | 頭脳。指令を出す | **ファナック**、シーメンス、ハイデンハイン、三菱電機 | ファナックは**NC装置で国内約7割・世界約5割**とされる（各種報道・同社説明、2025年時点） |
| サーボ／主軸モータ | 手足を動かす | ファナック、安川電機、三菱電機 | CNCとセットで売られることが多い |
| 機械本体（構造・主軸・送り） | 剛性と精度を担保 | DMG森精機、ヤマザキマザック、オークマ、牧野フライス ほか | ここが「工作機械メーカー」 |
| 周辺 | 工具、チャック、クーラント、計測 | 切削工具メーカー、工具ホルダ、ミツトヨ ほか | 消耗品ビジネス |

> ポイント：**多くの工作機械メーカーは、自社製品の「頭脳」を他社（ファナック）から買っている**。
> 例外が **オークマ**で、CNC・サーボ・モータまで自社開発する「完全内製」路線を取る。
> これは「制御まで握れば機械の性能を限界まで引き出せる」という思想で、
> 業界の中では珍しい垂直統合型。ファナック依存の是非は、この業界の古くからの論点。

ファナックは CNC を売る立場なので、**工作機械メーカーの競合ではなく供給者**。
同時に自社でも小型MC（ロボドリル）を作っており、部分的には競合する、というねじれた関係にある。
→ 関連：[FA・制御機器](../../03_電機・電子部品/14_FA・制御機器/README.md)、[産業用ロボット](../09_産業用ロボット/README.md)

## 4. なぜ精度と剛性が難しいのか

カタログには「位置決め精度 ±0.001mm」といった数字が並ぶ。1µm（マイクロメートル）＝ 1/1000mm。
髪の毛の太さが約 70µm なので、**髪の毛の 1/70 のズレを何時間も保ち続ける**という話になる。
これを難しくしている敵は4つ。

| 敵 | 何が起きるか | 対策 |
| --- | --- | --- |
| **熱** | モータ・主軸・切削点が発熱し、鋳鉄のベッドが伸びる。1m の鋳鉄は1℃で約11µm伸びる | 対称構造で熱を逃がす、主軸を冷却、温度センサで**熱変位補正**、工場ごと空調 |
| **振動（びびり）** | 工具とワークが共振し、面が波打つ。工具も欠ける | ベッドを重くする、**ダンピング（減衰）**の高い材料、切削条件の自動調整 |
| **たわみ** | 切削力で構造が弾性変形する。深い加工ほど不利 | 門型（ポータル）構造、リニアガイドの剛性配分、太い主軸 |
| **摩耗・経年** | ボールネジやガイドが減り、精度が落ちる | スケールで実位置を読む**フルクローズド制御**、定期オーバーホール |

ここで効いてくるのが **剛性（変形しにくさ）** と **質量**。
工作機械が今も「重くて鋳鉄の塊」なのは、軽くすると振動と熱で精度が出ないから。
中型のマシニングセンタで 5〜10トン、大型門型機なら数十トンになる。
輸送費も据付費もかかるが、**軽くするインセンティブがない**のがこの産業の面白いところ。

```
   切削力 F が加わったときの理想と現実
   ┌───────────┐            ┌───────────┐
   │  主軸      │            │  主軸  ＼  │ ← たわむ
   │   │        │  F→        │   │    ＼ │
   │  工具─■ワーク│            │  工具─■  │ ← 削り過ぎ／削り残し
   │  ベッド     │            │  ベッド ～～│ ← 振動
   └───────────┘            └───────────┘
      剛性が高い              剛性が足りない
   ＝寸法が出る・面がきれい    ＝寸法が狂う・びびり跡・工具が折れる
```

さらに、精度は **作る側の工場自体が高精度でないと作れない**という循環がある。
高精度な機械を作るには、高精度な機械（＝マザーマシン）と、
**キサゲ**（手作業で摺動面を微細に削り、面の当たりを作る職人技）のような手仕事が今も残る。
だから工作機械は「装置産業だが、人の腕が最後に効く」半分クラフトの世界になっている。

## 5. 加工の周辺：工具・切削条件・後工程

機械だけでは何も削れない。実際に金属に食い込むのは **切削工具**（インサート＝刃先チップ）で、
これは消耗品として継続的に売れる。工具メーカーと機械メーカーは別業界だが、密接に組む。

| 区分 | 何を売るか | 代表企業（日本） | 経済的性格 |
| --- | --- | --- | --- |
| 切削工具（超硬・CBN・ダイヤ） | 刃先チップ、エンドミル、ドリル | サンドビック（スウェーデン）、三菱マテリアル、住友電工ハードメタル、京セラ、タンガロイ、オーエスジー | **消耗品**。景気に遅行せず稼働に連動 |
| 工具ホルダ・チャック | 工具と主軸をつなぐ | BIG DAISHOWA、北川鉄工所、キトー | 機械1台に何十本 |
| 計測 | 加工後の寸法検査、機上計測 | ミツトヨ、レニショー（英） | 精度保証の最終ライン |

**日本機械工具工業会（JTA）** がこの切削工具の生産統計を毎月出しており、
**機械（設備投資）よりも「工場が今どれだけ動いているか（稼働）」を映す指標**として読まれる。
両方を並べると、「設備は買われているが実稼働はまだ」といったズレが見える。
→ 統計の読み方は [需要の性格と受注統計の読み方](02_需要の性格と受注統計の読み方.md) で詳述。

## 用語メモ

- **マザーマシン**：機械を作る機械。工作機械の別名。産業の土台という意味を込めた呼び方
- **NC / CNC**：数値制御。工具の動きを数値プログラムで指示する仕組み。C はコンピュータ
- **G コード**：NCプログラムの標準的な記法。`G00`早送り、`G01`直線切削 など
- **ATC / APC**：自動工具交換装置／自動パレット交換装置。無人化の第一歩
- **主軸（スピンドル）**：工具またはワークを回す軸。回転数と剛性が機械の性格を決める
- **ボールネジ**：回転を直線運動に変える送り機構。精度の要
- **リニアモータ駆動**：ボールネジを使わず直接直線駆動。高速・高精度だが高価
- **フルクローズド制御**：スケール（ものさし）で実際の位置を読んでフィードバックする方式
- **びびり（チャタリング）**：工具とワークの共振。加工面に波模様が出る不良
- **キサゲ**：摺動面を手作業で削り、面の当たりを作る仕上げ技能
- **インサート**：使い捨ての刃先チップ。摩耗したら回して／替えて使う
- **FMS**：Flexible Manufacturing System。複数機＋搬送＋制御で多品種を無人生産する構成
- **AM（付加製造）**：金属3Dプリンタ。削らず積む。現状は試作・補修・複雑形状が中心
