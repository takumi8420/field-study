# 競争と儲け方（日本・ドイツ・中国の構図）

**このノートで分かること**：工作機械メーカーは何で利益を出しているのか。
単品売りからライン提案へという流れ、保守・部品・リビルドという「景気に左右されない売上」、
そして日本・ドイツ・中国・台湾がどう住み分け、その均衡がいま何で崩れかけているのか。

結論を先に言うと、**機械そのものの粗利は思ったより薄く、儲けは「あと」から来る**。
納めた機械が20年動き続ける間に落ちる保守・部品・改造・再生の収入と、
1台売りではなく工程まるごとを提案したときの付加価値。ここが勝負どころになっている。

---

## 1. 世界の構図：3つの階層に分かれている

工作機械は「安いものと高いものが同じ土俵にいない」産業である。
生産額の1位は圧倒的に中国だが、それは主に中低級機の話で、
高精度・高難度の領域では日本とドイツがほぼ2強、という二層構造になっている。

| 階層 | 主な担い手 | 典型価格 | 競争軸 |
| --- | --- | --- | --- |
| **ハイエンド**（5軸・複合・超精密・大型） | ドイツ（DMG MORI、GROB、Heller、Chiron）、日本（DMG森精機、ヤマザキマザック、オークマ、牧野フライス、ジェイテクト、芝浦機械）、スイス（GF、Starrag） | 5,000万〜数億円 | 精度、難削材対応、無人化提案、サポート網 |
| **ミドル**（量産向けMC・NC旋盤） | 日本（ブラザー工業、オークマ、シチズン、スター精密、ツガミ）、台湾（TONGTAI、YCM、Hiwin系）、韓国（DN Solutions＝旧斗山） | 1,000万〜5,000万円 | 価格対性能、サイクルタイム、納期 |
| **ローエンド／汎用** | 中国（瀋陽機床、大連機床の系譜、科徳数控、海天精工、創世紀 ほか）、台湾 | 数百万〜1,500万円 | 価格。CNCも国産化が進む |

**世界生産額は中国が15年連続で首位**とされ、世界総額の約3割を占める（Gardner Intelligence 等の調査ベース、2024/2025年）。
一方で、**精密機・高位機種は日本とドイツが2位クラスとして並ぶ**というのが通説的な整理である。

```
      精度・難度
        ▲
   高   │  ドイツ ██████    日本 ██████      ← ここは値段で戦っていない
        │  （大型・5軸）    （複合・研削・量産精度）
        │
   中   │           日本 ████  台湾 ████  韓国 ███
        │
   低   │                        中国 ████████████  台湾 ████
        └──────────────────────────────────▶ 数量
                                        中国が数量で世界一
        └─ 中国の矢印は年々「上」へ伸びている ─▶
```

> ポイント：**中国勢は下から上がってくる**。ローエンドで数を作って学習し、
> CNC も国産（広州数控、華中数控など）が育ち、中位機種に届きつつある。
> 日本勢の防衛線は「まだ真似できない精度・信頼性・サポート」だが、その線は毎年少しずつ後退している。

## 3. 儲けの構造：機械を売った瞬間が利益のピークではない

工作機械1台の損益をざっくり分解すると、こうなる（業界の一般的な構造。企業により差は大きい）。

```
  受注価格 3,000万円の中型マシニングセンタ（イメージ）
  ┌──────────────────────────────────────────┐
  │ 部品・材料費（鋳物、ボールネジ、ガイド、主軸、CNC…）  約 55〜65% │
  │  └ うち CNC＋サーボ一式 …… 車で言えばエンジン相当の大物      │
  │ 組立・調整の人件費                                約 10% │
  │ 販売・サービス・据付                              約 10% │
  │ 開発費・本社費                                    約 10% │
  │ ─────────────────────────────────────  │
  │ 営業利益                                     約 5〜15% │
  └──────────────────────────────────────────┘

  納入後 15〜20年にわたって発生する売上
  ┌──────────────────────────────────────────┐
  │ 消耗部品・修理部品 / 定期点検 / 予防保全契約              │
  │ 改造・レトロフィット（CNC載せ替え、周辺自動化の後付け）      │
  │ オーバーホール・リビルド（再生機として再販）               │
  │ 中古機の下取り・再整備・再販                            │
  │  → 粗利率は新台より高いことが多く、景気の谷でも減りにくい      │
  └──────────────────────────────────────────┘
```

| 収益源 | 景気感応度 | 粗利率の傾向 | 狙い |
| --- | --- | --- | --- |
| 新台販売 | **極めて高い** | 低〜中 | 台数シェアと設置ベース（稼働台数）を増やす |
| 保守・部品 | 低い | 高い | 設置ベース×年数で積み上がる。**谷を埋める柱** |
| 改造・レトロフィット | 中 | 中〜高 | 買い替え予算がない不況期にむしろ売れる |
| リビルド・中古再販 | 中 | 中 | 下取りで新台を売り、再生して新興国へ回す循環 |
| ソフト・監視サービス | 低い | 高い | 稼働監視・予知保全のサブスク化。まだ発展途上 |

> ポイント：**設置ベース（世界で何台動いているか）こそが資産**。
> 新台を安く出してでもシェアを取り、20年分のアフターを取りに行く、という判断があり得る。
> 逆に、設置ベースが小さい新規参入者はアフター収益が作れず、値段でしか勝負できない。

## 4. 単品売りから「ライン提案」へ

近年の最大の変化は、**売るものが「機械」から「工程」に変わりつつある**こと。
顧客（特に中小の部品加工業者）が深刻な人手不足に直面しており、
「速い機械」より「人がいなくても回るしくみ」に金を払うようになった。

```
  【従来】機械を売る
     メーカー ──機械──▶ 顧客
                        顧客が自分で治具・工具・プログラム・段取りを整える

  【いま】工程を売る
     メーカー ──┬── 機械（複数台）
                ├── ロボット／ローダー／AGV（搬送）
                ├── 治具・工具・切削条件（加工技術そのもの）
                ├── NCプログラム・シミュレーション
                ├── 計測・品質保証（機上計測、トレーサビリティ）
                └── 稼働監視ソフト・遠隔保守
                          ──▶ 顧客は「夜間8時間の無人運転」を買う
```

| 段階 | 顧客が買うもの | 売り手の付加価値 | 価格帯 |
| --- | --- | --- | --- |
| 単機 | 機械 | 精度・速度 | 数百万〜数千万円 |
| 自動化セル | 機械＋ロボット＋周辺 | インテグレーション | 数千万〜1億円 |
| ライン／FMS | 工程まるごと | 生産計画・稼働保証 | 数億〜数十億円 |
| 稼働サービス | 成果（生産量・稼働率） | リスクの引受 | 契約次第 |

この方向は **産業用ロボットや FA との境界を溶かす**。
DMG森精機や各社が自社でロボットシステムを組み、
一方でファナックやロボットメーカーが工作機械と組んだパッケージを出す。
→ [産業用ロボット](../09_産業用ロボット/README.md)

ただし、ライン提案は **難しくて長い**。
仕様決めに数か月、立ち上げにさらに数か月かかり、途中で顧客の生産計画が変われば全部やり直しになる。
高収益だが、プロジェクト管理を誤ると赤字工事になる。ここが実力差の出るところ。

## 5. 切削工具メーカーとの関係

機械が「舞台」なら、実際に金属に食い込むのは **切削工具**。両者は補完関係にある。

| 観点 | 工作機械メーカー | 切削工具メーカー |
| --- | --- | --- |
| 売るもの | 設備（一度売れば10〜20年） | **消耗品**（毎月減る） |
| 景気との関係 | 設備投資に連動（先行・振幅大） | 稼働に連動（振幅小・安定） |
| 顧客との接点 | 数年に一度 | ほぼ毎月 |
| 利益率 | 景気次第で大きく振れる | 相対的に安定 |
| 代表企業 | DMG森精機、マザック、オークマ ほか | サンドビック、三菱マテリアル、住友電工ハードメタル、京セラ、タンガロイ、オーエスジー |

協業のポイントは **「切削条件」** にある。
新しい材料（チタン、CFRP、焼入れ鋼）を削るには、機械の剛性・回転数と工具の材種・形状を
セットで詰めないと成立しない。だから機械メーカーは自社のテクニカルセンタで
工具メーカーと共同で加工事例（アプリケーション）を作り、それをまとめて顧客に提案する。

**この加工ノウハウこそが、カタログスペックに現れない参入障壁**である。
中国勢が同等スペックの機械を安く出しても、「この材料をこの条件でこの精度で削れる」という
実証データの蓄積は短期間では真似できない。

## 6. 競争要因（KSF）と参入障壁

| 要因 | 中身 | 効き方 |
| --- | --- | --- |
| **精度と信頼性の実績** | 20年動き続ける証拠。壊れないこと自体が価値 | 新規参入が最も苦しむ点 |
| **加工アプリケーション** | 材料×形状×精度の組み合わせごとの実証データ | 蓄積型。時間でしか買えない |
| **世界のサービス網** | 止まった機械を24時間以内に直せるか | 顧客の稼働＝収益なので決定的 |
| **設置ベース** | 既設台数。買い替え時の第一候補になる | 累積優位 |
| **CNC の押さえ方** | 買うか、内製するか | 内製は開発費が重いが差別化できる |
| **資金力と在庫耐性** | 不況期を耐える体力 | 谷でシェアが動く |
| 参入障壁の弱い点 | 汎用機はモジュール調達で作れてしまう（CNC・ガイド・ボールネジは買える） | **下からの侵食を招く** |

> ポイント：この業界の障壁は「特許」ではなく **「実績と時間」**。
> 一方で、部品を買い集めれば汎用機は作れてしまうので、**下位機種の障壁は低い**。
> だから上へ上へと逃げ続けるしかない、というのが日本勢の構造的な宿命になっている。

## 7. いま構図を揺らしている3つの力

### (1) 中国市場の落ち込みと国産化

中国は長らく最大の輸出先だったが、不動産不況以降の投資減速と、
政府の産業政策（国産設備優先、研究開発減税など）で **日本勢の取り分が縮む方向**にある。
中位機種では中国メーカーが十分な品質に達しつつあり、
「安いから」ではなく「十分だから」選ばれ始めたのが本質的な変化。

### (2) 自動車の電動化による加工点の移動

エンジン1基は数百点の高精度加工部品の塊で、工作機械にとって最大の飯の種だった。
EV化でその需要が減る一方、モータのローター/ステーター、減速機のギヤ、
電池ケース、大型アルミ構造部品といった **新しい加工点**が生まれている。
差し引きがプラスかマイナスかはまだ定まっておらず、各社は両にらみで対応している。
→ [自動車（完成車）](../01_自動車（完成車）/README.md)、[自動車部品](../02_自動車部品/README.md)

### (3) AI・データセンター投資という新しい需要

半導体製造装置や電子部品、放熱部品、精密筐体の増産が、
2025〜2026年にかけて工作機械受注を押し上げていると報じられている。
ただしこれは **一つのテーマに需要が偏る**ということでもあり、
反動が来たときの落差は大きい。
→ [半導体製造装置](../../03_電機・電子部品/03_半導体製造装置/README.md)、
詳細は [直近トピック_2026](04_直近トピック_2026.md)

## 8. 経営指標の見どころ

| 指標 | 見方 |
| --- | --- |
| **受注高／受注残** | 売上より先に動く。決算短信で必ず確認 |
| 外需比率 | 7割前後が標準。高すぎると為替と関税に振られる |
| **売上高営業利益率** | 好況期で10〜15%、不況期でゼロ近辺まで落ちる会社が多い。ファナックのような部品側は20%前後 |
| サービス売上比率 | 高いほど谷に強い。開示している会社は限られる |
| 棚卸資産回転 | 好況の終盤に在庫が膨らみやすい |
| 為替感応度 | 輸出比率が高いので円安は追い風。ただし海外生産比率が高い企業は効果が薄い |

## 用語メモ

- **設置ベース（インストールドベース）**：世界で稼働中の自社機の累計台数。アフター収益の源泉
- **レトロフィット**：既存機のCNCや周辺装置を新しくして延命すること
- **リビルド（再生機）**：使用済み機を分解・整備し、新品同等に戻して再販すること
- **アプリケーション（加工事例）**：この材料をこの条件でこう削れる、という実証データ
- **テクニカルセンタ**：メーカーが顧客の実部品を試し削りする拠点。提案営業の中核
- **インテグレーション**：機械・ロボット・治具・ソフトを組み合わせて一つの生産設備にする仕事
- **5軸加工**：X/Y/Z の直線3軸＋回転2軸。工具の角度を変えられるので複雑形状を一度に削れる
- **自動旋盤（スイス型／主軸移動型）**：細長い棒材から小物部品を連続で削り出す旋盤。医療・電子部品向け
- **鍛圧機械**：プレス・板金曲げ・レーザ切断など、削らずに成形する機械。工作機械とは別統計
- **DN Solutions**：韓国の大手。旧・斗山工作機械。ミドル帯で日本勢の競合
