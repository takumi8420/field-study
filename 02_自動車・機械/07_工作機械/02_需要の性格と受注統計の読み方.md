# 需要の性格と受注統計の読み方

**このノートで分かること**：工作機械がなぜ「景気に最も敏感な業界」と言われるのか。
毎月ニュースになる **JMTBA（日本工作機械工業会）の受注統計** をどう読むのか。
そして自動車・半導体・航空機という需要先ごとに、波の形がどう違うのか。

結論から言うと、工作機械は **受注産業**であり、買われるのは
「企業が来年以降もっと作れると信じたとき」だけ。
つまり **設備投資の意思決定そのものが商品**なので、景気の山谷を増幅して映す。
これが「工作機械受注＝景気の先行指標」と呼ばれる理由である。

---

## 1. なぜ景気に最も敏感なのか

理由は3つに分解できる。

| 理由 | 中身 | 結果 |
| --- | --- | --- |
| **延期できる買い物** | 機械が1台壊れても、残業や外注で当面しのげる。買い替えを1年遅らせても即座には困らない | 不安になった瞬間、需要がゼロ近くまで落ちる |
| **金額が大きく回収が長い** | 1台数千万〜数億円。回収に5〜10年 | 金利・為替・政策の先行き次第で判断が止まる |
| **需要家の需要の「微分」を見る** | 客（自動車・半導体）の生産量ではなく、**生産量の増え方**に反応する | 客の生産が「増えているが増加ペースが鈍った」だけで受注は減る |

この3つ目が特に効く。経済学でいう **加速度原理**で、
最終需要が10%伸びるとき設備投資は30%伸び、最終需要の伸びが5%に鈍っただけで設備投資はマイナスに転じうる。

```
  最終需要（自動車の生産台数など）
   ▁▂▃▄▅▆▇█▇▆▅▄▃▂▁▂▃▄▅   ← なだらかな波

  工作機械の受注
   ▁▁▃▇█████▃▁　　▁▂▇██   ← 同じ波が増幅され、山も谷も鋭い
   └─ 立ち上がりは最終需要より早く、落ち込みも早い ─┘
      ＝「先行指標」と呼ばれる所以
```

> ポイント：工作機械メーカーの売上は、**客の好不調ではなく、客の「気分の変化率」**で動く。
> だから決算説明会では常に「引き合い（問い合わせ）は増えているか」が最初に問われる。

## 2. JMTBA 受注統計の構造

一般社団法人 日本工作機械工業会（JMTBA）が **毎月2回** 公表する。

| 種類 | 出るタイミング | 中身 |
| --- | --- | --- |
| **速報** | 翌月の第2営業日前後（＝経済統計の中でも極めて速い） | 総額・内需・外需の3つだけ |
| **確報** | 同月の中〜下旬 | 機種別、需要業種別、地域別（北米・欧州・アジア…）、受注残、販売額、生産額 |

**速さが価値**。景気指標としては内閣府「機械受注統計」より約1か月早く出るため、
市場関係者は「まず工作機械受注を見る」という順番で景況感を更新する。
→ 統計の公表は [日本工作機械工業会 統計情報](https://www.jmtba.or.jp/statistics/)。

### 統計の基本構造

```
  受注総額
   ├── 内需（日本国内向け）
   │     └── 需要業種別：一般機械 / 自動車 / 電気・精密 / 航空機・造船・輸送用機械 / 金属製品 …
   └── 外需（輸出向け）
         └── 地域別：アジア（うち中国）/ 北米（うち米国）/ 欧州 / その他

  ＋ 別建てで公表されるもの
   ├── 受注残高 ＝ 受けたがまだ納めていない金額（＝将来の売上の在庫）
   ├── 販売額   ＝ 実際に納品・計上した金額
   └── 生産額   ＝ 工場から出た金額
```

## 3. 読み方のコツ：5つの視点

### (1) 前年同月比より「金額の水準」を見る

工作機械受注は季節性（8月の夏季休業、12月の期末駆け込み）が強く、前月比はブレる。
前年同月比は分かりやすいが、**前年が異常に低ければ簡単に+50%になる**。
実務では「月間◯◯億円」という水準感で判断する。おおまかな目安は次の通り。

| 月間受注額 | 業界の体感 |
| --- | --- |
| 800億円台以下 | 不況。各社減産・雇用調整に入る水準 |
| 1,000〜1,200億円 | 損益分岐点付近。「底這い」と表現される |
| 1,300〜1,500億円 | 平常運転 |
| 1,600億円以上 | 好況。納期が延び始める |
| 2,000億円超 | 過熱。部品供給がボトルネックに |

（水準感は各社決算説明・業界紙の記述から筆者が整理した目安であり、公式な区分ではない）

### (2) 内需と外需を分けて見る

日本の工作機械産業は **外需が7割前後**の輸出産業。
2025年（暦年）の確報では **受注総額 1兆6,043億円（前年比+8.0%）、うち内需 4,409億円（−0.2%）、
外需 1兆1,635億円（+11.5%）、外需比率 72.5%** と報じられている
（JMTBA発表ベース、日刊工業新聞・日本産機新聞など）。
**外需は過去最高を更新した一方、内需は前年並み**という構図で、
「日本の景気」よりも「世界の設備投資」を映す統計になっている点に注意が要る。

### (3) 地域別で世界の設備投資地図を読む

外需の内訳は、そのまま「今どこの国が工場を建てているか」の地図になる。

| 地域 | 読み方 |
| --- | --- |
| **中国** | 長らく最大の単一市場。ただし現地メーカーの台頭と国産化政策で、日本勢の取り分は構造的に縮む方向 |
| **北米** | 製造業回帰・国内投資誘導策で拡大。ただし関税政策の変更に直撃される |
| **欧州** | ドイツ勢の地元。自動車の電動化転換で振れが大きい |
| **インド・ASEAN** | 中国の代替生産地として伸びる。単価は中国より低め |

### (4) 受注残（バックログ）＝将来の売上の在庫

受注してから納めるまで、標準機で3〜6か月、大型機・ライン案件では1〜2年かかる。
**受注残が積み上がっていれば、受注が今月落ちても売上はしばらく保つ**。逆に、

> 受注が減り始めても数か月は増収増益に見える。
> **「受注は落ちているのに決算が良い」局面こそ、株式市場が最も警戒するタイミング**。

受注残÷月平均販売額 ＝ **手持ち月数**。これが3か月を割ると工場の操業に穴が空き始める。

### (5) 機種別・業種別で「何のための投資か」を見る

| 見えるパターン | 意味するもの |
| --- | --- |
| 旋盤・小型MCが増える | 部品加工の中小企業（町工場）が動いている＝裾野の回復 |
| 大型門型機・複合機が増える | 航空機・エネルギー・金型など大物の長期投資 |
| 電気・精密向けが急増 | 半導体・電子部品の設備サイクルが立ち上がった |
| 自動車向けが急増 | 新型車の立ち上げ、またはライン更新 |

## 4. 需要先ごとの波の形

工作機械の需要は「業界を横断する」ので、複数の波が重なって見える。主要な3つ。

```
  時間 ──────────────────────────────▶

  自動車    ▁▃▅▇▅▃▁▃▅▇▅▃▁▃▅▇▅▃    周期 4〜6年（モデルチェンジ／設備更新）
            └ 量が大きい。台数×工程数で膨大な機械を使う

  半導体・電子 ▁▁▁▇███▁▁▁▁▁▇██▁▁▁    周期 3〜4年、振幅が極端（シリコンサイクル）
            └ 立ち上がると一気。止まるとピタリと止まる

  航空機     ▁▂▃▄▅▆▇▇▇▇▆▅▄▃▂▁      周期 10年超。ゆっくり大きい
            └ 難削材（チタン・インコネル）で単価が高い

  合計      ────  この3つが位相をずらして重なるのが実際の受注
```

| 需要先 | 買い方 | 使う機械 | 波の性格 |
| --- | --- | --- | --- |
| **自動車・自動車部品** | 車種立ち上げごとに**ライン単位**でまとめ買い | 専用機・トランスファマシン、量産向けMC・旋盤、研削盤 | 最大の需要先。EV化でエンジン部品（数百点の加工）が消え、代わりにモータ・ギヤ・筐体・電池ケースの加工が増える構造転換の途中 |
| **半導体・電子部品** | 装置メーカー・部品メーカーの増産投資に連動 | 高精度MC、複合機、超精密加工機 | 振幅が最も大きい。近年は**AI・データセンター向け**が牽引 |
| **航空機・防衛** | 機体の生産レート引き上げに数年がかりで対応 | 大型5軸MC、難削材対応機 | 長期。単価が高く利益率も良い |
| **金型** | 需要家の新製品開発サイクルに連動 | 高速MC、放電加工機、研削盤 | 中小企業が多く、景気に敏感 |
| **一般機械・建機・農機** | 更新投資中心 | 汎用MC、旋盤 | 内需の底堅い部分 |
| **医療・エネルギー** | 規制と需要の長期トレンド | 複合加工機、5軸 | 単価が高い成長領域 |

→ 需要家側は [自動車部品](../02_自動車部品/README.md)、[建設機械](../06_建設機械/README.md)、
[航空機・防衛](../13_航空機・防衛/README.md)、[半導体（ロジック・メモリ）](../../03_電機・電子部品/02_半導体（ロジック・メモリ）/README.md) を参照。

## 5. もう一つの統計：日本機械工具工業会（JTA）の生産統計

**日本機械工具工業会（JTA）** は、切削工具（超硬工具・特殊鋼工具・ダイヤ/CBN工具）の
**生産額**を毎月公表している。工作機械の受注統計と組み合わせると、景気の位相がより細かく見える。

| 統計 | 何を映すか | 位相 |
| --- | --- | --- |
| **JMTBA 受注統計** | これから据え付けられる**設備**の量 ＝ 企業の先行き期待 | **先行**（実際の生産活動の数四半期前） |
| **JTA 切削工具生産統計** | 今まさに削られている量 ＝ 工場の**実稼働** | **一致〜やや遅行** |
| 内閣府 機械受注統計 | 機械全般の受注（船舶・電力を除く民需） | 先行。ただし公表はJMTBAより約1か月遅い |
| 日銀短観 設備投資計画 | 企業の**意思**そのもの | 最も先行 |

読み方の例：

> **工具生産は堅調なのに工作機械受注が落ちる** → 今の生産は忙しいが、増産投資には踏み切らない。
> 「稼働はあるが確信がない」状態で、景気の天井が近いサイン。
>
> **工作機械受注が先に立ち上がり、工具生産が後から追う** → 典型的な回復入り。
> 設備が据え付けられ、半年〜1年遅れて実稼働が増える。

JTA の統計は 2025年12月分の切削工具生産額が約373億円（前年同月比108%）、
2026年1月分が約366億円（同105%）と報じられており、月400億円弱のスケール感で推移している。
工作機械受注（月1,500〜2,000億円）に対して桁が1つ小さいが、
**景気で消えない消耗品売上**であることが、この数字の安定性に表れている。

## 6. 実際の数字で追ってみる（2025〜2026年）

| 時点 | 数値 | 出所・性格 |
| --- | --- | --- |
| 2025年（暦年）受注総額 | **1兆6,043億円**、前年比+8.0%。過去4番目の高水準 | JMTBA確報（報道ベース） |
| うち内需 | 4,409億円（−0.2%） | 同上。国内投資は足踏み |
| うち外需 | 1兆1,635億円（+11.5%）、**過去最高**。外需比率72.5% | 同上。北米・アジアが過去最高 |
| 2026年 年間見通し | **1兆7,000億円**（JMTBA見通し、2026年1月公表と報じられる） | 見通し＝確定値ではない |
| 2026年3月 | 約1,934.7億円 | 月次速報（報道ベース） |
| 2026年6月 | 約2,035億円、前年同月比+52.8% | 月次速報（報道ベース） |
| 2026年7月 | 約1,931億円、前年同月比+50.4%、13か月連続増加 | 月次速報（報道ベース） |
| 2026年8月 | 約1,978億円、前年同月比+65% | 2026年9月9日公表の速報（報道ベース） |

読み取れること：

1. **月2,000億円前後という過熱圏**に入っている。2025年通年（月平均約1,337億円）から水準が一段上がった
2. 伸び率が+50〜65%と極端なのは、**前年が低かった反動**も含む。水準で見ることが重要
3. 牽引役は AI・データセンター関連と自動化投資と報じられており、**特定用途への依存の高さ**が懸念点として指摘されている
4. 内需が伸び悩む構図は続いており、日本の工場の更新投資は依然として重い課題

（詳細と一次資料は [直近トピック_2026](04_直近トピック_2026.md) を参照）

## 7. 受注産業ゆえの経営の難しさ

| 局面 | 起きること | 経営判断 |
| --- | --- | --- |
| 好況 | 受注残が膨らむ。納期が1年超に伸びる | 増産すべきか？ 設備と人を増やすと次の谷で重荷になる |
| ピーク | 受注が横ばいに転じる。だが受注残があるので売上は伸び続ける | ここで縮む決断ができるか |
| 後退 | 受注が急減。受注残を食いつぶしながら操業 | キャンセル・納期延期の申し出が増える |
| 底 | 受注残が尽き、稼働率が急落。固定費が重い | 資金繰りと雇用の維持。**サービス売上が支えになる** |

固定費（工場・開発・人）の比率が高いので、**売上が2割落ちると営業利益は簡単に消える**。
だから各社は「景気に左右されない収益源」を作ろうとする。それが保守・部品・リビルド（再生機）で、
この点は [競争と儲け方](03_競争と儲け方.md) で扱う。

## 用語メモ

- **受注産業**：見込み生産ではなく、注文を受けてから作る産業。売上の先行きが受注で決まる
- **受注残（バックログ）**：受注済みで未納品の金額。将来の売上の在庫
- **手持ち月数**：受注残 ÷ 月平均販売額。工場が何か月分の仕事を抱えているか
- **加速度原理**：最終需要の「増加率の変化」が設備投資を大きく振らせるという考え方
- **先行指標／一致指標／遅行指標**：景気の山谷に対して、先に動くか同時か後から動くか
- **速報／確報**：JMTBA受注統計の2段構え。速報は総額・内需・外需のみ、確報で内訳が出る
- **内需／外需**：国内向け受注／輸出向け受注。日本の工作機械は外需が7割前後
- **シリコンサイクル**：半導体の需給が数年周期で大きく振れる現象
- **難削材**：チタン合金、ニッケル基超合金（インコネル）など削りにくい材料。航空機で多用
- **トランスファマシン**：同じ部品を工程順に自動搬送しながら加工する専用ライン。量産専用で汎用性はない
