# 直近トピック（2026年9月時点）

報道ベースの整理。数値は各時点の公表値・報道値であり、確定値でないものは明示する。
一次情報（JMTBA統計、各社IR）で必ず裏取りすること。

**この時期の一言まとめ**：受注は月2,000億円前後という過熱圏にある。
ただし牽引役は AI・データセンター関連という**単一テーマへの偏り**で、
一方では米国の分野別関税調査、中国市場の構造的縮小、
そして牧野フライスをめぐる買収劇が外為法の介入で「安全保障案件」に変わるという、
需要・通商・資本の3方向から同時に揺さぶられている。

## 1. 受注が過去最高圏へ。2026年は1兆7,000億円見通し

### 数字の推移

| 時点 | 受注額 | 前年同月（年）比 | 備考 |
| --- | --- | --- | --- |
| 2025年（暦年）確報 | **1兆6,043億円** | +8.0% | 過去4番目の高水準 |
| └ 内需 | 4,409億円 | −0.2% | 国内投資は足踏み |
| └ 外需 | **1兆1,635億円** | +11.5% | **過去最高**。外需比率72.5%。北米・アジアが過去最高額 |
| 2026年 年間見通し | **1兆7,000億円** | 前年超え | JMTBA見通し（2026年1月公表と報じられる）。自動化需要が理由 |
| 2026年3月 | 約1,934.7億円 | ― | 月次速報 |
| 2026年6月 | 約2,035億円 | +52.8% | 内需・外需とも前年同月超え |
| 2026年7月 | 約1,931億円 | +50.4% | **13か月連続増加**。前月比は−5.1% |
| 2026年8月 | 約1,978億円 | **+65%** | 2026年9月9日公表の速報。夏季休業月にもかかわらず高水準 |

2026年の累計は前年同期比132%前後で推移していると報じられている。

### 読み方の注意

- **+50〜65%という伸び率は、前年の低水準の反動を含む**。伸び率ではなく「月2,000億円」という水準で見る
- 月2,000億円は [需要の性格と受注統計の読み方](02_需要の性格と受注統計の読み方.md) で整理した目安では**過熱圏**。
  実際、部品供給や据付人員がボトルネックになり、納期が延びているとされる
- 受注残が厚く積み上がるので、**仮に受注が落ちても売上は数四半期は保つ**。
  逆に言えば、決算が良い時期に受注のピークアウトが起きうる

## 2. 牽引役は AI・データセンター。その依存への懸念

2026年8月の受注が前年同月比65%増となった要因として、
**AI関連需要**が挙げられていると報じられている（日本経済新聞、2026年9月）。
同記事の見出しには「高い依存度に懸念も」という趣旨の指摘も含まれている。

推定される需要の中身：

| 需要の入口 | 工作機械で何を削るか |
| --- | --- |
| 半導体前工程・後工程の装置増産 | 装置の真空チャンバー、ステージ、精密構造部品（アルミ・ステンレスの大物高精度加工） |
| データセンターの冷却・電源 | ヒートシンク、液冷用の微細流路部品、電源筐体 |
| 光通信・高速基板 | コネクタ金型、微細部品 |
| 電力インフラ | 変圧器・発電設備の大型部品 |

→ 需要側の構造は [半導体製造装置](../../03_電機・電子部品/03_半導体製造装置/README.md)、
[半導体（ロジック・メモリ）](../../03_電機・電子部品/02_半導体（ロジック・メモリ）/README.md) を参照。

**リスクの見立て**：半導体・電子向けは [シリコンサイクル](02_需要の性格と受注統計の読み方.md) の通り
振幅が極端で、立ち上がりも速いが止まるのも速い。
自動車・一般機械という「厚い底」が同時に伸びているかどうかが、
今回の好況の持続性を判断する分かれ目になる。内需（＝国内の一般機械・自動車）が
2025年に前年並みだった点は、その意味で気になる材料。

## 3. 米国の「工作機械への分野別関税」調査

2025年9月、トランプ米政権が **工作機械や医療機器への分野別関税を視野に調査を始めた**と報じられた
（日本経済新聞）。工作機械は米国の輸入国・地域別シェアで**日本が最も高い**とされ、
実現すれば日本勢を直撃する。

その後の通商環境は大きく動いている。

| 時期 | 出来事 | 出所 |
| --- | --- | --- |
| 2025年9月 | 米商務省が工作機械・医療機器等の分野別関税を視野に調査開始と報道 | 日本経済新聞 |
| 2025年内 | 鉄鋼・アルミ関税の運用変更で、工作機械の輸出が「予想外の最高」になる局面も | 日本経済新聞 |
| **2026年2月20日** | 米連邦最高裁が、IEEPA（国際緊急経済権限法）を根拠とする相互関税を**違法・無効**と判断 | ジェトロ |
| 2026年2月24日 | 相互関税の徴収停止。同日から**通商法122条**に基づく関税を新たに適用 | ジェトロ |

**論点**：関税の法的根拠が差し替えられただけで、**保護主義そのものは続いている**。
分野別（232条型）の調査結果が出れば、工作機械が名指しで対象になる可能性が残る。
一方で、北米の設備投資自体は製造業回帰で強く、
日本勢にとっては「需要は good、コストは risk」という板挟みの構図になっている。

```
   北米ビジネスの二面性
   ┌──────────────────┐        ┌──────────────────┐
   │ 追い風              │        │ 向かい風            │
   ├──────────────────┤        ├──────────────────┤
   │ 製造業の国内回帰     │  ⇄     │ 分野別関税の調査     │
   │ 半導体・EV工場の新設  │        │ 関税制度の頻繁な変更  │
   │ 人手不足＝自動化需要  │        │ 為替・据付人員の不足  │
   └──────────────────┘        └──────────────────┘
        → 対応：現地生産・現地調達の拡大、価格転嫁、受注時点の条件見直し
```

## 4. 牧野フライス買収劇：外為法が初めて「中止勧告」を出す

この2年で最も業界を揺らした資本の話。経緯を整理する。

| 時期 | 出来事 |
| --- | --- |
| 2024年12月27日 | **ニデック**が牧野フライス製作所へ、事前交渉なしの「同意なきTOB」を提案・公表 |
| 2025年前半 | 牧野フライスが買収防衛策を導入。対抗策の発動で経済的損害が生じる恐れから、**ニデックは2025年5月8日にTOBを撤回** |
| 2025年6月3日 | 牧野フライスがアジア系投資ファンド **MBKパートナーズ**をホワイトナイトとして選定。MBKがTOBを発表（**1株11,751円**）。牧野フライスも賛同 |
| **2026年4月22日** | 政府が **外為法（外国為替及び外国貿易法）に基づき、MBKによる買収計画の中止を勧告**していたと報じられる。**2017年の法改正以降で初の適用事例** |
| 2026年半ば | MBKのTOBは断念。買収をめぐる局面は続いていると報じられる |

### なぜ外為法が出てきたのか

工作機械は **軍民両用（デュアルユース）技術**の典型で、
高精度な5軸加工機はミサイル・航空機・原子力部品の製造にも使える。
実際、輸出は外為法の**キャッチオール規制**と国際輸出管理枠組み（旧ココム／ワッセナー・アレンジメント）の
対象であり、1987年の東芝機械ココム違反事件はこの業界の記憶に残る事件でもある。

つまり **工作機械メーカーの経営権は、純粋な資本の論理だけでは決まらない**。
日本政府が「コア業種」として指定する産業の株式取得には事前届出が必要で、
今回はその制度が初めて「中止勧告」という最も強い形で使われた。

> ポイント：この一件は個社の話にとどまらず、
> **「日本の工作機械メーカーは海外ファンドに売れない資産なのか」**という問いを業界全体に残した。
> 事業承継や再編の選択肢が制度的に狭まる一方、技術流出への歯止めにもなる。両面がある。

## 5. 中国：最大市場でありながら、日本勢の取り分が縮む

| 論点 | 状況 |
| --- | --- |
| 市場規模 | 2025年時点でも **中国が世界最大市場**であることは変わらない |
| 生産額 | 中国は **15年連続で世界最大の生産国**とされ、世界総額の約3割（Gardner Intelligence 等の調査ベース） |
| 日本からの輸出 | 2023年度の中国向けは約2,740億円で外需の約28%・全体の約19%を占めたが、2022→2023年で約27%減少したとされる |
| 政策 | 研究開発税制優遇、ハイエンド機器の輸入依存低減を掲げた産業政策を継続 |
| 技術水準 | 精密工作機械・産業用ロボットの**上位機種は依然として日本・ドイツ依存**。ただし中位帯は国産で足りるようになってきた |

構造として起きているのは、単なる「安売り競争」ではなく **需要そのものの内製化**。
中国の顧客が「日本製でなくても十分」と判断する範囲が年々広がっており、
日本勢が守れる領域は上へ押し上げられている。

```
   中国市場における日本勢のポジション（イメージ）
   2015年   [超精密|高精度|中精度|汎用    ]
             ■■■■■■■■■■■■□□□□□□      ■＝日本勢が取れる領域
   2020年   [超精密|高精度|中精度|汎用    ]
             ■■■■■■■■□□□□□□□□□□
   2026年   [超精密|高精度|中精度|汎用    ]
             ■■■■■□□□□□□□□□□□□□
             └─ 上へ押し上げられている。金額は取れても台数は減る ─┘
```

**日本勢の対応**：中国依存を下げ、北米・インド・ASEAN・欧州へ販売を分散する動きが進む。
2025年に外需が過去最高になった一方で中国が牽引役でなかったのは、この分散が効いた結果とも読める。

## 6. JIMTOF2026：2年に一度の世界最大級の見本市

- **会期**：2026年10月26日（月）〜31日（土）の6日間
- **会場**：東京ビッグサイト全館（東4〜6ホールを除く）、会場規模 92,850m²
- **主催**：一般社団法人 日本工作機械工業会、株式会社東京ビッグサイト
- **想定来場者**：約13万人
- 1962年から2年に1度開催。第33回

工作機械は「現物を見て、試し削りのデータで買う」商材なので、
**JIMTOF は新製品発表と商談が集中する業界最大のイベント**。
2026年10月開催なので、本ノート作成時点（2026年9月）ではまさに直前。
好況下での開催となるため、各社の自動化・AI活用・5軸/複合の新機種発表が焦点になる。
受注統計にも「JIMTOF効果」で10〜12月に上乗せが出ることがある。

## 8. 全体の構図（まとめ）

1. **需要は過熱圏**。2026年の受注は月2,000億円前後で、年間1兆7,000億円見通し。
   ただし牽引は AI・データセンター関連という単一テーマで、内需（一般機械・自動車）はまだ厚くない。
2. **通商リスクが常在**。米国の分野別関税調査は続いており、関税の法的根拠が最高裁判決で
   差し替えられた後も保護主義の方向は変わっていない。北米は最大の成長市場であると同時に最大の不確実性。
3. **中国は「市場が消える」のではなく「取り分が上に追いやられる」**。
   台数では負け、金額と付加価値で戦う構図が定着しつつある。
4. **資本の論理に安全保障が割り込んだ**。牧野フライスをめぐる外為法の初適用は、
   工作機械が軍民両用技術であることを制度として可視化した。再編の自由度が下がる。
5. したがって各社の課題は共通で、**単品売りからライン・サービスへの転換をどれだけ進められるか**。
   谷が来たときに何で食うかを、好況の今のうちに作れるかが分かれ目になる。
   → [競争と儲け方](03_競争と儲け方.md)

## 用語メモ

- **分野別関税（232条型）**：特定品目を安全保障上の理由で調査し課税する米国の仕組み
- **IEEPA**：国際緊急経済権限法。2026年2月に米最高裁がこれを根拠とする相互関税を無効と判断
- **通商法122条**：国際収支の悪化に対処するための関税権限。2026年2月24日から適用開始
- **同意なき買収（同意なきTOB）**：対象企業の取締役会の賛同を得ずに行う株式公開買付け
- **ホワイトナイト**：敵対的買収を受けた企業が、味方として招く別の買い手
- **外為法（外国為替及び外国貿易法）**：対内直接投資を安全保障の観点から審査する法律。コア業種は事前届出制
- **デュアルユース**：民生にも軍事にも使える技術。高精度工作機械はその典型
- **キャッチオール規制**：リスト規制品でなくても、用途・需要者次第で輸出許可を要する制度
- **JIMTOF**：日本国際工作機械見本市。2年に1度、東京ビッグサイトで開催
