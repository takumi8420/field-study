# 工作機械

- 大分類: 自動車・機械
- 状態: done
- 更新日: 2026-09-20

金属を削って部品の形にする機械。**その工作機械自身も工作機械で作られる**ので
「機械を作る機械＝マザーマシン（母なる機械）」と呼ばれる。
自動車も航空機も半導体製造装置も、元をたどれば必ずどこかの工作機械が削った部品でできている。
産業の土台であると同時に、**設備投資そのものが商品**なので、景気の波を最も鋭く映す業界でもある。

## 1. 業界の定義・範囲

**工作機械とは**、動力で工具を保持・駆動し、主に金属の工作物から不要部分を取り除いて
必要な形状・寸法・精度に仕上げる機械。日本工作機械工業会（JMTBA）の統計が対象とするのは
この「削る（除去加工）」の領域である。

隣接領域との境界：

| 領域 | 含むか | 理由 |
| --- | --- | --- |
| 旋盤、マシニングセンタ、研削盤、放電加工機、歯車加工機 | ○ | 中核 |
| プレス機、板金曲げ機、レーザ切断機、鍛造機 | △ | **鍛圧機械**として別統計。広義には「工作機械・鍛圧機械」と併称 |
| 射出成形機、押出機 | ✕ | プラスチック加工機械 |
| 木工機械、繊維機械 | ✕ | 対象材料が違う |
| 半導体製造装置、産業用ロボット | ✕ | 別業界。ただし工程では隣接し、需要家でも供給者でもある |
| 切削工具、工具ホルダ、計測機器 | ✕ | 別業界（日本機械工具工業会など）だが不可分の関係 |

→ 詳細は [01_工作機械とは何か](01_工作機械とは何か.md)

## 2. 市場規模と成長性

| 指標 | 数値 | 年・出所 |
| --- | --- | --- |
| 日本の工作機械受注総額 | **1兆6,043億円**（前年比+8.0%）。過去4番目 | 2025年暦年、JMTBA確報（報道ベース） |
| └ 内需 | 4,409億円（−0.2%） | 同上 |
| └ 外需 | **1兆1,635億円**（+11.5%）、**過去最高**。外需比率 **72.5%** | 同上 |
| 2026年 年間見通し | **1兆7,000億円** | JMTBA見通し（2026年1月公表と報じられる） |
| 直近の月次受注 | 2026年8月 約1,978億円（前年同月比+65%） | 2026年9月9日速報（報道ベース） |
| 世界の生産額1位 | **中国**（15年連続、世界総額の約3割） | 2024/2025年、Gardner Intelligence 等の調査ベース |
| 日本の切削工具生産額 | 月350〜400億円規模（2025年12月 約373億円、前年同月比108%） | 日本機械工具工業会（JTA）統計（報道ベース） |

**成長性の見方**：長期の趨勢成長率は世界のGDP成長並みだが、
**短期の振幅が極端に大きい**。谷から山まで受注が2倍以上動くことは珍しくない。
「成長産業か」ではなく「今サイクルのどこにいるか」で語る業界。

## 3. バリューチェーン（川上 → 川下）

```
 【部材・要素部品】      【頭脳】           【機械メーカー】     【流通】      【需要家】
  鋳物（ベッド）         CNC装置            DMG森精機           商社        自動車・部品
  ボールネジ/リニアガイド サーボモータ        ヤマザキマザック     代理店      半導体・電子
  主軸ユニット（軸受）    ─ ファナック        オークマ            直販        航空機・防衛
  油空圧・クーラント        シーメンス        牧野フライス                     金型
  板金・配線               ハイデンハイン     ブラザー、シチズン他              一般機械・建機
      │                      │                  │                            │
      └── コスト55〜65% ──────┘        組立・調整・据付                       ▼
                                          テクニカルセンタで        納入後15〜20年の
                                          加工実証・提案            保守・部品・改造・再生
                                                                   ＝利益率の高い裏の柱
  【消耗品】切削工具・ホルダ（サンドビック、三菱マテリアル、住友電工、京セラ、オーエスジー…）
            → 機械の稼働に比例して毎月売れる。景気の谷でも減りにくい
```

付加価値が集まるのは3か所。
**(1) CNC・サーボ（ファナック等の寡占）**、
**(2) 精度・剛性を作り込む機械本体の設計と組立技能**、
**(3) 納入後20年のアフター**。単純な組立工程には価値が残らない。

| 海外 | DMG MORI（独）、GROB、Heller、Chiron（独）、GF/Starrag（瑞）、DN Solutions（韓）、瀋陽機床・科徳数控ほか（中）、TONGTAI・YCM（台） | 独＝高精度、韓台＝ミドル、中＝数量 |

**シェアの構図**：世界は「中国が数量、日独が高付加価値」の二層。
単一企業の世界シェアは高くても数%台で、**寡占ではない**。
寡占しているのはむしろ上流の CNC（ファナック）。

## 5. 収益モデル・コスト構造

| 項目 | 目安 | コメント |
| --- | --- | --- |
| 部品・材料費 | 売上の55〜65% | CNC＋サーボ一式が最大の買い物 |
| 組立・調整人件費 | 約10% | 熟練工の手仕事が残る |
| 販売・サービス・据付 | 約10% | 世界網の維持費。不況でも削りにくい |
| 開発・本社費 | 約10% | 固定費 |
| 営業利益率 | 好況期10〜15%、不況期はゼロ近辺 | **売上が2割落ちると利益が消える** |

**儲けの本体は納入後**。設置ベース（世界で稼働中の自社機）に対して、
保守・部品・レトロフィット（CNC載せ替え）・リビルド（再生機）が20年続く。
これらは粗利率が新台より高く、景気の谷でも減りにくい。
→ [03_競争と儲け方](03_競争と儲け方.md)

## 6. 競争要因（KSF）と参入障壁

1. **精度と信頼性の実績**：20年壊れずに1µmを保つ証拠。時間でしか買えない
2. **加工アプリケーション**：「この材料をこの条件でこの精度で削れる」という実証データの蓄積
3. **世界のサービス網**：止まった機械を即日直せるか。顧客の稼働＝収益なので決定的
4. **設置ベース**：既設台数が多いほど買い替えの第一候補になる（累積優位）
5. **CNCの押さえ方**：買うか内製するか。オークマの完全内製は差別化の一形態
6. **不況を耐える体力**：谷でシェアが動く産業なので、資金力が競争力そのもの

**障壁の弱点**：CNC・ボールネジ・リニアガイドは買えるので、
汎用機はモジュール調達で作れてしまう。**下位機種の障壁は低く、中国勢の侵食を招く**。
だから上へ逃げ続けるしかない、という構造的な宿命がある。

## 7. 規制・法制度

| 制度 | 内容 |
| --- | --- |
| **外為法（外国為替及び外国貿易法）／輸出管理** | 高精度工作機械は**軍民両用（デュアルユース）**。リスト規制＋キャッチオール規制の対象。5軸加工機などは輸出許可が要る場合がある |
| ワッセナー・アレンジメント | 通常兵器・関連汎用品の国際的な輸出管理枠組み（旧ココム）。工作機械の精度は代表的な管理項目 |
| **外為法 対内直接投資規制** | 安全保障上重要な「コア業種」の株式取得は事前届出制。2026年4月、**牧野フライス買収に対し2017年改正以降で初の中止勧告**が出たと報じられる |
| 米国の分野別関税 | 2025年9月、工作機械・医療機器等への分野別関税を視野に米政権が調査開始と報道。2026年2月に相互関税が最高裁で無効となり通商法122条へ切り替え（ジェトロ） |
| 中国の産業政策 | 国産設備優先、研究開発減税などでハイエンド機器の輸入依存低減を推進 |
| 国内支援 | ものづくり補助金、事業再構築系の設備投資補助が中小の設備更新を後押し |
| 安全規格 | 機械の包括的な安全基準、CEマーキング（EU）、労働安全衛生法 |

> 工作機械は「経済財」であると同時に「安全保障物資」。
> 輸出も、株式の売買までもが国家の審査対象になる、数少ない産業のひとつ。

| **速報／確報** | JMTBA受注統計の2段構え。速報は翌月第2営業日前後と極めて速い → [02](02_需要の性格と受注統計の読み方.md) |
| **外需比率** | 輸出向け受注の割合。日本は7割前後 → [02](02_需要の性格と受注統計の読み方.md) |
| **設置ベース** | 世界で稼働中の自社機の累計。アフター収益の源泉 → [03](03_競争と儲け方.md) |
| **レトロフィット／リビルド** | 既存機のCNC載せ替え／分解整備して再販すること → [03](03_競争と儲け方.md) |
| **デュアルユース** | 民生にも軍事にも使える技術。高精度工作機械はその典型 → [04](04_直近トピック_2026.md) |
