このノートで分かること：基礎調味料の数量がなぜ減り続けるのか、
その減った分がどこへ消えたのか、そして低単価・重量物という構造が
コスト上昇局面でどれだけ不利に働くか。

1. 結論：しょうゆは減り、みそは下げ止まり、メニュー用が伸びている

調味料市場は「縮んでいる」と一言で言われるが、実際には3つの違う動きが同時に起きている。

動き 何が起きているか 数値（年・出典）
① 基礎調味料の数量が減るしょうゆの出荷量は1973年の129万klをピークに、半減に近づいている2023年 68万3,340kl（前年比▲2.0%、しょうゆ情報センター）。2024年は前年並みの約68万klで下げ止まったとみられる（報道）
② みそは下げ止まった2016年以来9年ぶりに前年を上回った2025年 生産量 36万2,589t（+1.8%）、出荷量 36万2,356t（+1.8%）（全国味噌工業協同組合連合会、報道ベース）
③ メニュー専用・簡便調味料が伸びる「◯◯の素」が基礎調味料の出番を奪う形で伸長ハウス食品のメニュー専用シーズニングは2025年度4〜12月出荷ベースで前年比+4.3%、味の素「Cook Do」も好調に着地（報道）
④ 輸出が伸びる日本食ブームとインバウンド起点の関心拡大2025年 醤油輸出額 134.9億円（+10.7%）／輸出量 5万9,778t（+9.8%、過去最大）、味噌 71.4億円（+13.1%）、ソース混合調味料 721.5億円（+7.8%）（財務省貿易統計を基に農林水産省作成）

つまり、国内の基礎調味料は縮み、周辺と海外が伸びている。
食品メーカー一般の「国内数量は伸びない」という話は
総合食品④ にあるが、
調味料ではその減り方に固有の理由がある。それが次章の話。

2. 減った分はどこへ消えたのか ― 内食・中食シフト

しょうゆの消費が半減に近づいたと聞くと、「日本人が和食を食べなくなった」と思いがちだが、
実態はもっと単純である。しょうゆは姿を変えて消費されている。

【昔（1970年代）】
  家庭でしょうゆの瓶を買う
        │
        ├─▶ 煮物に使う
        ├─▶ そばつゆを自分で作る（しょうゆ＋みりん＋だし）
        ├─▶ 焼き肉のたれを自分で作る
        └─▶ 卵かけごはんにかける
                  → 全部「しょうゆの瓶」から出ていた

【いま（2020年代）】
  家庭でしょうゆの瓶を買う（量は減る）
        │
        └─▶ 卵かけごはん・刺身など「かける用途」だけが残る

  一方で ↓ しょうゆは別の入口から家に入ってくる

  食品メーカーが加工用しょうゆを買う
        │
        ├─▶ めんつゆ  ──────┐
        ├─▶ 焼き肉のたれ ────┤
        ├─▶ 鍋つゆ ─────────┼─▶ 家庭が買う
        ├─▶ ドレッシング ────┤
        └─▶ 惣菜・弁当・冷食 ─┘
                  ★しょうゆメーカーの名前は表に出ない
                  ★瓶のしょうゆより単価は高いが、
                   しょうゆメーカーの取り分は加工用の薄い粗利

  外食チェーンが業務用しょうゆを買う
        └─▶ 外食・持ち帰りとして消費される

しょうゆ情報センターも、家庭用の減少と業務用の増加、その背景として
「しょうゆ系調味料（つゆ・たれ）の普及」「外食の常態化」「中食の拡大」を挙げている。

ポイント：基礎調味料メーカーにとって最悪なのは、量が減ることではなく
「粗利の厚い家庭用が減り、粗利の薄い加工用・業務用に置き換わること」である。
同じ1klを売っても、家庭用の1kl と加工用の1kl では利益が全く違う。

食の3類型 定義 調味料メーカーへの影響
内食（ないしょく）家で材料から作って食べる基礎調味料が最も売れる形。ここが減っている
中食（なかしょく）弁当・惣菜を買って家で食べる加工用・業務用の需要になる。粗利は薄い → 中食・弁当
外食店で食べる業務用の需要になる。メニュー採用が勝負 → ファストフード

単身世帯の増加、共働きの増加、高齢化（少量しか作らない）が、
この内食→中食シフトを押し続けている。

3. メニュー専用調味料 ― 「基礎調味料の敵」ではなく「置き換え」

メニュー専用調味料（「麻婆豆腐の素」「回鍋肉の素」など）は、
基礎調味料メーカーにとって両義的な存在である。

【メニュー専用調味料が、基礎調味料から奪うもの】

  従来の麻婆豆腐               メニュー専用調味料を使う麻婆豆腐
  ┌────────────────┐        ┌────────────────┐
  │ しょうゆ  小さじ2 │        │ 「Cook Do 麻婆豆腐」│
  │ みそ      大さじ1 │   →    │  1袋              │
  │ 豆板醤    小さじ1 │        │                   │
  │ 酒・砂糖・片栗粉  │        │ ＋ 豆腐とひき肉     │
  │ 鶏がらスープ      │        └────────────────┘
  └────────────────┘
   基礎調味料5〜6種類が         基礎調味料の出番はゼロ
   少しずつ減る                （＝袋の中に加工用として入っている）

  → 消費者の支払額はむしろ増える。
    しかしその金は「メニュー用を作った会社」に行き、
    基礎調味料メーカーには「加工用の薄い粗利」しか残らない。
    ★同じ会社が両方作っていれば問題ないが、そうでなければ収益の移転が起きる。

だから各社は自分でメニュー用に出ていく。
味の素「Cook Do」、ハウスのメニュー専用シーズニング、エスビーのシーズニングミックス、
キッコーマンの「うちのごはん」、ミツカンの「〇〇の素」——
これらは基礎調味料の市場縮小に対する、同じ会社による自己カニバリ（共食い）戦略である。

なぜメニュー用が伸びるのか 中身
時短・簡便調味料を計量する手間、買い揃える手間、余らせる手間がゼロになる
失敗しない味が決まっている。料理の経験が浅くても同じ味が出る
少量世帯に合う1〜2人分が作れる。基礎調味料を買うと余る層と相性が良い
単価が高い1食あたりでは割高だが、消費者は「材料費の一部」として受け入れる
新規参入の余地がある基礎調味料と違い、棚が固定されていない。ここだけは新商品競争が成立する

日本食糧新聞の「メニュー用調味料特集2026」や業界報道では、
中華・和風に比べてメニューの少ない洋風メニュー用調味料が各社の注力領域になっており、
市場拡大が見込まれると整理されている。

ポイント：基礎調味料の棚は動かない（→①）が、
メニュー用の棚は動く。強さの源泉だった「棚が動かない」が、
新しい需要を取りに行くときには逆に足かせになる。

4. 減塩・健康志向 ― 単価は上がるが数量は減る

調味料は、健康志向がそのまま「使用量を減らせ」という圧力になる、珍しいカテゴリである。

論点 中身
食塩摂取量の目標厚生労働省「日本人の食事摂取基準」で、成人の食塩相当量の目標値は男性7.5g/日未満、女性6.5g/日未満（2020年版）。実際の摂取量はこれを上回る
しょうゆ・みその位置づけ日本人の食塩摂取源としてしょうゆ・みそ・漬物は上位。公衆衛生上の減塩施策の主な標的になる
減塩商品の売り方「塩分◯%カット」は通常品より高く売れる。数量は減るが単価は上がるので、メーカーにとって必ずしも悪い話ではない
技術的な難所塩はしょうゆ・みその保存性（腐らせない仕組み）そのものでもある。減塩すると日持ちが悪くなるため、密封ボトル・充填技術とセットで開発する必要がある
鮮度容器という発明空気に触れさせない二重構造ボトル（キッコーマン「いつでも新鮮」シリーズなど）。開封後の劣化を防ぐことで、少量でも「最後まで美味しい」を実現した。減塩と同じく「単価を上げる」方向の技術
うま味による減塩味の素などが推す方向。うま味を足すと、塩を減らしても満足感が保てるという考え方。減塩が「うま味調味料の追い風」になるという逆転
【調味料市場の「数量 ✕ 単価」の動き】

   単価
    ▲
    │        ● 鮮度容器・減塩・こだわり品
    │       ／   （高付加価値化。数量は小さいが利幅が厚い）
    │      ／
    │  ● 従来品
    │   ＼
    │    ＼
    │     ● PB・価格訴求品
    │      （数量は出るが利幅が薄い）
    └──────────────────────────▶ 数量

  → 市場は「二極化」する。中間の普通の商品が最も苦しい。
    繊研新聞の報道でも、醤油市場は単価上昇と輸出増で
    「二極化に対応しながら市場を維持している」と整理されている。

5. 原料と為替 ― 大豆・小麦・塩・糖・卵

調味料の原料は、ほぼすべてが輸入相場と為替に握られている。
相場商品の一般論は 製粉・製糖・製油 が詳しい。
ここでは調味料固有の効き方だけを書く。

原料 使うカテゴリ 調達の事情
脱脂加工大豆・丸大豆しょうゆ、みそ大半が輸入（米国・ブラジル・カナダ等）。シカゴ相場と為替に直撃される。製油業の副産物である脱脂加工大豆は、製油の稼働にも左右される
小麦しょうゆ政府が一括輸入して売り渡す制度の対象（→ 製粉・製糖・製油）。年2回の政府売渡価格改定が原価に効く
食塩しょうゆ、みそ、ほぼ全部国内生産と輸入（主にメキシコ・豪州の天日塩）。運賃と為替の影響
糖類・異性化糖つゆ、たれ、ドレッシング砂糖は調整金制度の対象で、国際相場より高い水準に置かれる
鶏卵マヨネーズ国内相場。鳥インフルエンザの発生で一気に跳ねる。他の調味料にはないリスク
油脂（菜種・大豆油）マヨネーズ、ドレッシング相場と為替。マヨネーズは重量の大半が油脂
香辛料（胡椒・唐辛子等）カレー、スパイス産地が限られ、天候・地政学リスクに弱い。エスビー・ハウスの調達力が効く

  シカゴ大豆相場 ──┐
  為替（円安）  ──┼──▶ 脱脂加工大豆の価格 ──┐
  海上運賃    ──┘                          │
                                            ├──▶ 原材料費
  政府売渡価格（小麦）─────────────────────┤     （原価の4〜5割）
  塩の輸入価格 ────────────────────────────┘
                                                  │
  原油 ──▶ 樹脂・フィルム ──▶ 包装資材費 ─────────┤

  2024年問題 ──▶ 運賃 ──▶ 物流費 ─────────────────┤

  最低賃金・春闘 ──▶ 人件費 ──────────────────────┘

帝国データバンクの「食品主要195社」価格改定動向調査（2025年11月時点）では、
値上げ要因として原材料高 99.7%、包装・資材 51.5%、物流費 36.1%、人件費 34.4% が挙がっている。
値上げ実務の一般論は 総合食品② を参照。

6. 低単価・重量物という構造問題 ― 物流費が利益を食う

① 第5章で触れた「安くて重い」という性質は、
コスト上昇局面で他の食品より深刻に効く。

【同じ「運賃10%上昇」が与える打撃の違い（イメージ）】

  売価1,000円／1kg の商品（菓子・冷凍食品など）
    物流費が売上の3% → 3円/個 → 10%上昇で +0.3円 → 売価の0.03%
    ほとんど気づかない

  売価200円／1.1kg の商品（1Lしょうゆ）
    物流費が売上の8〜10% → 16〜20円/本 → 10%上昇で +1.6〜2.0円 → 売価の約1%
    ★営業利益率が7〜12%の商売で、売価の1%は利益の1割前後に相当する

  → 「重さあたりの値段が安い」ほど、運賃上昇は利益を直撃する。
構造問題 中身 各社の対応
遠距離が合わない運賃が売価に対して重いため、遠方に売るほど利益が減る工場の地域分散。キッコーマン・ヤマサ・ミツカンはいずれも国内に複数工場
共同配送のしづらさ重量物と軽量物を混載すると効率が悪い業界横断の共同配送・モーダルシフト（鉄道・船）の試み
パレット・容器の標準化一斗缶・ペット・BIB・瓶と容器が多様で、積載効率が上がらない業務用のBIB化、軽量ペットボトル化
CLO（物流統括管理者）義務化改正物流効率化法で2026年4月から特定事業者に選任義務大手調味料メーカーは荷主として該当。物流が経営アジェンダに
小容量化の罠少人数世帯向けに小容量を出すと、1本あたりの包装費・物流費は減らない高付加価値（鮮度容器・減塩）とセットにして単価を上げる

海外展開が現地生産になる理由も、ここに帰着する。
日本から液体を運ぶ運賃では、現地の調味料と価格で戦えない。
キッコーマンが米国に3工場を持ち、ミツカンが北米・欧州で現地生産しているのは必然である
（→ ②）。

7. まとめ：市場の変化を理解する3つの鍵

鍵 中身
① 「減った」のではなく「姿を変えた」しょうゆは瓶からつゆ・たれ・惣菜へ移った。数量より、粗利の厚い家庭用から薄い加工用への移動が問題
② 伸びるのは棚が動く場所だけ基礎調味料の棚は動かないので伸びない。メニュー専用・高付加価値・輸出という「棚が動く場所」に各社が出ている
③ 低単価・重量物が全てのコストを増幅する物流費・包装費の上昇が、売価の小さい商品ほど利益を削る。工場配置と海外の現地生産はこの制約への答え

用語メモ

用語 意味
内食・中食・外食内食＝家で材料から作る／中食＝惣菜・弁当を買って家で食べる／外食＝店で食べる。調味料の売り先がこの3つでまったく違う
メニュー専用調味料（メニュー用調味料）特定の1メニューのために配合された調味料。「Cook Do」「麻婆豆腐の素」など。基礎調味料の使用機会を置き換える
簡便調味料メニュー専用より広く、「合わせ調味料」「シーズニング」「〇〇のたれ」など、調理の手間を減らす調味料の総称
鮮度容器開封後も空気に触れさせない二重構造の容器。しょうゆの酸化（黒ずみ・風味低下）を防ぐ。単価を上げる代表的な技術
異性化糖とうもろこし等のでんぷんから作る液状の糖。つゆ・たれ・ドレッシングに広く使われる。砂糖より安価だが、原料コーン相場と為替に左右される
調整金制度（砂糖）輸入糖から徴収した金を国内産糖に交付する制度。国内の砂糖価格が国際相場より高い水準に保たれる → 製粉・製糖・製油
CLO（物流統括管理者）改正物流効率化法により、一定規模以上の荷主企業に選任が義務づけられる役員級の物流責任者。2026年4月施行
モーダルシフトトラック輸送を鉄道・船舶に切り替えること。重量物である調味料では効果が出やすいが、リードタイムが延びる
二極化高付加価値品とPB・価格訴求品に需要が分かれ、中間の普通の商品が苦しくなる現象。調味料でも進行している
