# ① 調味料が強い商売である理由

このノートで分かること：**なぜ調味料は、食品の中でとくに利益率が高く、順位がひっくり返らないのか**。
そして、その強さの裏側にある「低単価・重量物」という構造的な弱点。

食品メーカー一般の損益・値決め・商品開発のルールは
[総合食品](../01_総合食品/README.md) に書いた。ここでは調味料固有の話だけを扱う。

## 1. 結論：買い替え頻度が低いのに、ブランド指名が極端に強い

調味料の異常さは、次の2つが**同時に**成り立っていることにある。

1. **買い替え頻度が低い** — しょうゆ1本は家庭で2〜3か月もつ。年に数回しか買わない。
2. **にもかかわらず、ブランド指名が極端に強い** — 「しょうゆ」ではなく「キッコーマン」、
   「マヨネーズ」ではなく「キユーピー」、「酢」ではなく「ミツカン」と指名して買われる。

普通の商売では、この2つは両立しない。
買う回数が少ない商品は、**買うたびに比較検討される**のが普通だからである（家電や車がそうだ）。
ところが調味料は違う。理由は、**味の記憶が家庭の味そのものだから**である。

> ポイント：調味料を変えるということは、**家庭の料理の味をすべて変える**ということ。
> 味噌汁の味、煮物の味、卵焼きの味が一斉に変わる。
> だから消費者は、数十円の価格差では乗り換えない。**「失敗したときの損失」が大きすぎる**。

この結果、何が起きるか。**棚が動かない**。

```
【棚が動かない、とはどういうことか】

  ◆ 菓子・飲料の棚（回転が速い・入れ替わる）
     春の棚替え          秋の棚替え
    ┌──────────┐      ┌──────────┐
    │ 新商品A  │  →   │ 新商品C  │   ← 1年で半分が入れ替わる
    │ 新商品B  │      │ 定番X    │
    │ 定番X    │      │ 新商品D  │
    └──────────┘      └──────────┘

  ◆ 基礎調味料の棚（ほとんど動かない）
     春の棚替え          秋の棚替え
    ┌──────────┐      ┌──────────┐
    │ キッコーマン │  →  │ キッコーマン │  ← 同じ商品が何十年も居座る
    │ ヤマサ     │      │ ヤマサ     │
    │ PB        │      │ PB        │
    │（地場銘柄）  │      │（地場銘柄）  │
    └──────────┘      └──────────┘

  → 小売から見ると「外すとクレームが来る商品」なので外せない。
    新規参入者は、空いている棚がないので入れない。
```

[総合食品③](../01_総合食品/03_商品開発とブランド.md) で見たとおり、
食品メーカーは新商品を大量に出して棚を守る。
しかし**基礎調味料のブランドは、新商品を出さなくても棚が守られる**。
これが利益率の差になって表れる。

| カテゴリ                               | 営業利益率の目安 | 新商品依存度   | なぜそうなるか                                                                          |
| -------------------------------------- | ---------------- | -------------- | --------------------------------------------------------------------------------------- |
| 製粉・製糖・製油（素材型）             | 2〜5%            | 低い           | 差別化できない。相場の転嫁が仕事 → [製粉・製糖・製油](../02_製粉・製糖・製油/README.md) |
| 菓子・冷凍食品                         | 4〜7%            | **非常に高い** | 新商品が出ないと棚が取れない。販促費が重い                                              |
| **基礎調味料（しょうゆ・酢・みそ等）** | **7〜12%**       | **低い**       | **ブランド指名が強く、棚が安定。販促費を抑えられる**                                    |
| メニュー専用調味料・つゆ               | 5〜9%            | 中〜高         | 新しい用途を作る商売なので提案が要る                                                    |
| 加工用うま味調味料（BtoB）             | 相場次第         | —              | 実質コモディティ。世界の需給で値が決まる                                                |

（各社IRおよび業界報道からの概数。年によって振れる）

## 2. 「調味料」はひとつの市場ではない ― 別市場の束

「調味料業界」という言い方は便利だが、**中身は互いにほとんど競合しない別市場の集合**である。
しょうゆメーカーとマヨネーズメーカーは、同じ棚に並んでいても競争していない。

```
【「調味料」という名前でひとくくりにされている7つの別市場】

  ┌─ 発酵でつくる（時間と菌が障壁）─────────────────┐
  │  しょうゆ   キッコーマン / ヤマサ / ヒゲタ / ヒガシマル    │
  │  みそ      マルコメ / ハナマルキ / ひかり味噌 / 地場多数  │
  │  食酢      ミツカン（圧倒的） / タマノイ                 │
  │  みりん     宝酒造 / タカラ / キッコーマン（本みりんは酒類扱い）│
  │  うま味調味料 味の素（発酵法。世界最大）                   │
  └──────────────────────────────────────────┘
  ┌─ 乳化・配合でつくる（設備と配合技術が障壁）──────────┐
  │  マヨネーズ   キユーピー（圧倒的） / 味の素               │
  │  ドレッシング  キユーピー / 理研ビタミン / ピエトロ         │
  └──────────────────────────────────────────┘
  ┌─ スパイス・調合（原料調達と配合が障壁）───────────┐
  │  カレー     ハウス食品 / エスビー食品 / 江崎グリコ         │
  │  スパイス    エスビー食品（国内圧倒的） / ハウス           │
  └──────────────────────────────────────────┘
  ┌─ 組み合わせて売る（用途提案が商売）───────────────┐
  │  つゆ・鍋つゆ  ヤマキ / ミツカン / キッコーマン / ヤマサ     │
  │  メニュー専用  味の素「Cook Do」 / ハウス / エスビー        │
  └──────────────────────────────────────────┘

  ※横のつながりは薄い。しょうゆ会社がマヨネーズで勝つことはほぼない。
    逆に、各市場の中では上位1〜2社がシェアの大半を取る「小さな寡占」が並んでいる。
```

この「**別市場の束**」という構造が、調味料を理解する最大の鍵である。

- **市場規模を語るときは必ずカテゴリを限定する**。「調味料市場◯兆円」はほぼ意味がない。
- **シェアも同様**。ミツカンは食酢で圧倒的だが、しょうゆでは存在感がない。
- **M&Aが起きにくい**。買っても技術も販路も流用できないことが多い。
  実際、大手調味料メーカーの国内再編はほとんど起きていない。

## 3. 発酵という参入障壁 ― 菌と時間は金で買えない

しょうゆ・みそ・酢・みりん・うま味調味料は、いずれも**微生物の働きで作る**。
ここが、調味料が他の加工食品と決定的に違うところである。

```
【しょうゆができるまで（本醸造方式）】

  大豆（脱脂加工大豆）＋ 小麦
        │  蒸す／炒る
        ▼
    製麹（せいきく）  ← 麹菌（こうじきん）を繁殖させる。2〜3日
        │            ★ここで使う菌株が各社の秘伝
        ▼
    仕込み（諸味＝もろみ）＋ 食塩水
        │
        ▼
    発酵・熟成  ◀────── ★6か月〜1年以上かかる
        │              乳酸菌 → 酵母 の順にバトンが渡る
        │              蔵に住み着いた菌が味を決める
        ▼
    圧搾 → 火入れ → ろ過 → 充填

  → 「レシピを教える」ことはできても、
    「蔵の菌と、1年分の在庫と、その間の運転資金」は渡せない。
```

これが意味すること。

| 障壁の中身         | なぜ効くか                                                                                 |
| ------------------ | ------------------------------------------------------------------------------------------ |
| **時間**           | 仕込んでから売れるまで半年〜1年以上。**原料を買った金が1年寝る**。運転資金の要る商売       |
| **菌**             | 各社が独自の菌株を持ち、蔵に棲む微生物相（フローラ）も味に影響する。買ってきて再現できない |
| **蔵・タンク**     | 発酵タンクは巨大で、増産するには数年先を読んで先に建てる必要がある                         |
| **失敗の不可逆性** | 発酵が狂った諸味は元に戻せない。1年分の在庫を失う                                          |
| **品質の一定性**   | 生き物が相手なのに「去年と同じ味」を毎年出さなければならない。これ自体がノウハウ           |

一方で、**発酵を使わない作り方もある**。
しょうゆには、大豆を塩酸で分解して短時間で作る「アミノ酸液混合方式（混合・混合醸造）」があり、
安価な業務用や海外の一部で使われる。
ただし日本のJAS規格では、本醸造・混合醸造・混合の別を表示する義務があり、
家庭用の主力は本醸造である。
**「発酵で作っているかどうか」が、そのまま価格帯と棚の位置を分けている**。

> ポイント：参入障壁は特許でも免許でもない。**時間と菌と運転資金**である。
> だからこそ、資本力のある異業種が入ってきても勝てない。
> 逆に言えば、**既存プレイヤーも急には増産できない**（→ キッコーマンの米国第3工場は
> 2024年4月着工、2026年5月仕込み開始、10月出荷予定。2年半かかっている）。

## 4. 家庭用と業務用 ― 見えないところで半分が動いている

調味料は、**スーパーの棚に並ばない分が非常に多い**。

```
【しょうゆの行き先（イメージ。実際の比率はメーカーにより大きく異なる）】

  生産 ───┬──▶ 家庭用（スーパー・ドラッグ・EC）
          │      ブランド勝負。粗利は厚い
          │
          ├──▶ 業務用（外食・中食・給食）
          │      一斗缶・20Lバッグインボックス。価格と安定供給の勝負
          │
          └──▶ 加工用（食品メーカーへの原料供給）
                 つゆ・たれ・惣菜・冷凍食品の「中身」になる
                 ★ここが最も見えない。表示上はメーカー名も出ない

  ※業界全体では、家庭用の消費は減り、業務用・加工用が相対的に増えている。
    「家庭でしょうゆを使わなくなった」のではなく、
    「めんつゆ・たれ・惣菜という形に姿を変えて消費されている」（しょうゆ情報センターの解説）
```

この二本立てが、調味料メーカーの損益を理解する上で重要になる。

|                    | 家庭用                                                                              | 業務用・加工用                                                          |
| ------------------ | ----------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| 売り方             | 小売の棚を取る。卸経由 → [食品卸](../../06_商社・卸売/06_食品卸/README.md)          | 外食チェーン・食品メーカーへ直販＋業務用卸                              |
| 価格の決まり方     | 建値＋リベート。特売に振り回される → [総合食品②](../01_総合食品/02_値決めと交渉.md) | 年間契約・相対（あいたい）交渉。数量が読める                            |
| 粗利               | 厚い（ブランドプレミアム）                                                          | 薄い                                                                    |
| 数量の安定性       | 人口減でじりじり減る                                                                | **チェーンのメニューに採用されると数年単位で安定**                      |
| 営業のやること     | 棚割り提案・販促                                                                    | **メニュー提案（食材提案）**。味の設計から入り込む                      |
| 切り替えられやすさ | 低い（消費者が指名する）                                                            | **高い（相見積もりで落とされる）** ただしメニュー開発から入ると粘着する |

> ポイント：業務用は粗利が薄いが、**工場の稼働率を支える**。
> 発酵設備は止められない（タンクは常に回す方が効率が良い）ので、
> **家庭用のブランド利益 ＋ 業務用の数量** という組み合わせが最も収益性が高い。
> ミツカンの2025年度（2026年2月期）国内実績でも、家庭用937億円に対し業務用223億円と、
> 業務用が無視できない規模で存在する（ミツカン発表）。

## 5. 単価が安く、重い ― 物流費が効きすぎる商品

調味料の弱点はここに集約される。

```
【1パレット（約1トン）あたりの商品価値のイメージ】

  医薬品        ████████████████████████████  数千万円
  菓子・化粧品   ████████                      数百万円
  即席麺        ███                            百万円前後
  ★しょうゆ     █                              十数万円  ← 安くて重い
  小麦粉・砂糖   ▌                              十万円未満

  → トラック1台で運べる「金額」が小さい。
    運賃が同じでも、売上に対する物流費の比率は桁で違う。
```

しょうゆ1Lは約1.1kg、みそ1kgは1kg、マヨネーズも液体に近い。
**水を運んでいるようなもの**で、売価に対する重量が大きい。

| 効いてくる場面 | 何が起きるか                                                                                                                                                 |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 運賃上昇       | 2024年問題（トラックドライバーの時間外労働規制）以降の運賃上昇が、低単価商品ほど直撃する → [陸運・トラック](../../13_運輸・物流/06_陸運・トラック/README.md) |
| 遠距離配送     | 関東の工場から九州へ運ぶと採算が合わない。**地場メーカーが生き残る理由**でもある                                                                             |
| 海外展開       | **日本から輸出するのでは運賃で勝てない**。だからキッコーマンは現地生産を選んだ → [②](02_各社の戦い方.md)                                                     |
| 値上げ         | 帝国データバンクの調査では、値上げ要因として物流費を挙げる企業が2025年末時点で36.1%。原材料高（99.7%）に次ぐ常連要因になっている                             |
| 小容量化       | 容量を減らすと1本あたりの単価は下がるが、**1本あたりの包装費・物流費は減らない**。利益率がかえって悪化することがある                                         |

この「安くて重い」性質が、**調味料メーカーの工場配置と海外戦略のすべてを決めている**。
しょうゆメーカーが全国に工場を分散して持ち、キッコーマンが米国・欧州・アジアに9か所の
しょうゆ工場を構えているのは、味のためだけでなく**運賃の問題**である。

## 6. なぜ順位がひっくり返らないのか ― 3つの鍵

| 鍵                               | 中身                                                                                   |
| -------------------------------- | -------------------------------------------------------------------------------------- |
| **① 味の記憶が乗り換えを止める** | 買い替え頻度が低いのに指名買いされる。価格差では動かない。棚が固定される               |
| **② 発酵が時間と菌で守っている** | レシピを知っても作れない。増産にも数年かかる。資本だけでは入れない                     |
| **③ 家庭用と業務用の二階建て**   | ブランドで粗利を取り、業務用・加工用で数量と稼働率を稼ぐ。どちらか一方では成り立たない |

裏を返せば、この3つは**弱点の裏返し**でもある。

- ①が効くということは、**新しい味を広めるのにも同じだけ時間がかかる**ということ。
- ②が効くということは、**需要が急に落ちてもタンクを止められない**ということ。
- ③が効くということは、**外食・中食の景気に半分が連動する**ということ。

各社がこの構造をどう使い分けているかは [② 各社の戦い方](02_各社の戦い方.md)、
需要側の変化は [③ 市場の変化](03_市場の変化.md) を参照。

## 用語メモ

| 用語                          | 意味                                                                                                                                                                                |
| ----------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **本醸造（ほんじょうぞう）**  | しょうゆの製法区分のひとつ。大豆・小麦に麹菌を働かせ、発酵・熟成させて作る伝統的な方式。JAS規格ではこのほかに「混合醸造」「混合」があり、表示が義務づけられる。家庭用の主力は本醸造 |
| **諸味（もろみ）**            | 仕込んだ原料と食塩水が発酵・熟成している途中の、どろっとした状態のもの。これを搾ったものがしょうゆ                                                                                  |
| **製麹（せいきく）**          | 蒸した原料に麹菌を繁殖させる工程。2〜3日かけて行う。ここで使う菌株が各社の味の根幹                                                                                                  |
| **脱脂加工大豆**              | 大豆から油を搾ったあとの粕を、しょうゆ用に加工したもの。丸大豆よりコストが低く、国内しょうゆの主原料。製油業との接点 → [製粉・製糖・製油](../02_製粉・製糖・製油/README.md)         |
| **うま味調味料**              | グルタミン酸ナトリウム（MSG）を主成分とする調味料。味の素が1908年の池田菊苗によるうま味発見を受けて事業化。現在はサトウキビ糖蜜などを原料に**発酵法**で作る（化学合成ではない）     |
| **バッグインボックス（BIB）** | 段ボール箱の中に樹脂の袋を入れた業務用容器。10〜20L。軽くて廃棄しやすく、業務用しょうゆ・つゆの主力容器                                                                             |
| **加工用（原料用）**          | 食品メーカーに原料として売る分。つゆ・たれ・惣菜・冷凍食品の中身になる。最終商品にメーカー名は出ない                                                                                |
| **相対（あいたい）取引**      | 相手と1対1で条件を決める取引。業務用調味料の価格は、建値ではなくこの相対交渉で決まることが多い                                                                                      |
| **メニュー専用調味料**        | 「麻婆豆腐の素」のように、特定の料理1品のために配合された調味料。基礎調味料の代替ではなく**使う場面を奪う**存在 → [③](03_市場の変化.md)                                             |
