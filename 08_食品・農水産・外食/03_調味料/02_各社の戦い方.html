このノートで分かること：調味料の主要各社が、どのカテゴリでどう棲み分けているか。
そして、海外で勝った会社が何をしたのか ―
「調味料」ではなく「用途」を売ったという、この業界で最も重要な発明について。

1. 結論：みんな「別の市場のチャンピオン」である

調味料大手7社は、一見同じ棚に並んでいるが、実際には別々の市場の1位を守っている
（→ ① 第2章）。
だから、正面から潰し合うことがほとんど起きない。

2. キッコーマンの発明 ― 「しょうゆ」ではなく「テリヤキ」を売った

キッコーマンは日本の食品メーカーで最も海外比率が高い会社のひとつで、
2026年3月期の海外売上収益は 5,802億円（前期5,521億円から+5.1%）、
売上収益7,455億円の大半を海外が占める（同社IR）。

なぜ勝てたのか。答えは技術でも資本でもなく、売り方の転換にある。

【失敗する売り方 vs キッコーマンの売り方】

 ✕ 普通のやり方（多くの日本食品メーカーが失敗した道）
   「これは日本の伝統的な調味料 SOY SAUCE です」
        │
        ▼
   スーパーの「エスニック食材コーナー」に置かれる
        │
        ▼
   アジア料理を作るときだけ買われる  → 年に1回売れるかどうか
        │
        ▼
   数量が伸びない。現地生産できるほどの規模に届かない

 ○ キッコーマンのやり方
   「肉を焼くときに、これをかけると美味しくなります」
        │  ★調味料ではなく「用途」を売る
        ▼
   店頭デモンストレーションで、実際に肉を焼いて食べさせる（1950〜60年代〜）
        │
        ▼
   TERIYAKI という「アメリカ料理のジャンル」を作ってしまう
        │  ★もはや日本食の話ではない
        ▼
   スーパーの「調味料コーナー（ケチャップ・マスタードの隣）」に置かれる
        │
        ▼
   日常的に使われる → 数量が出る → 1973年 米国ウィスコンシン工場
        │
        ▼
   現地生産で運賃・鮮度の問題が消える → さらに安く売れる → 定着

この「カテゴリを翻訳するのではなく、用途を発明する」というやり方が、
調味料の海外展開における教科書になっている。

何を変えたか 具体的に
置かれる棚を変えたエスニック棚 → 一般調味料棚。ここが最大の勝負どころ。売れる回数が桁で変わる
使う場面を作った「日本料理を作るとき」→「肉・魚を焼くとき」「サラダにかけるとき」。既存の食習慣に割り込んだ
味を変えた現地向けに甘み・とろみを調整した TERIYAKI SAUCE などを別商品として開発。本醸造しょうゆはそのまま残した
現地生産した1973年 米国ウィスコンシン、1998年 カリフォルニア、そして2026年に米国第3工場（ウィスコンシン州ジェファーソン）。安くて重い商品を輸出で戦わない（→① 第5章）
時間をかけた米国進出は1957年の販売会社設立から数えて70年近く。発酵と同じで、市場を育てるのにも時間がかかる

2026年の続報：キッコーマンは2026年9月18日、米国第3工場（ウィスコンシン州ジェファーソン）の
グランドオープニングを発表した。2024年4月着工、2026年5月に仕込み開始、10月出荷予定。
投資額は10年間で約800億円、2034年までに米国内の生産能力を現状から3〜4割拡大する計画と報じられている。
詳細は ④ 直近トピック。

ポイント：海外で売れているのは「日本のしょうゆ」ではなく「現地の調味料になったしょうゆ」である。
食品の海外展開一般の話は 総合食品④ にある。
調味料に固有なのは、「用途の発明」ができれば数量が桁で変わるという点。

3. 味の素 ― 調味料会社が半導体材料を作っている理由

味の素は調味料会社に見えて、発酵とアミノ酸の会社である。
これが、調味料業界で最も変わった立ち位置を生んでいる。

【味の素の事業の広がり ― すべて「アミノ酸」から派生している】

           1908年 池田菊苗が昆布から「うま味（グルタミン酸）」を発見
                        │
                     翌年 事業化
                        │
              ┌─────────┴─────────┐
              ▼                     ▼
      【アミノ酸をつくる技術】        【アミノ酸を味に使う】
       （発酵・精製・大量生産）        （調味料・食品）
              │                     │
      ┌───────┼───────┐            ├─ うま味調味料「味の素」
      ▼       ▼       ▼            ├─ 風味調味料「ほんだし」
   医薬用     動物栄養   ★電子材料     ├─ メニュー専用「Cook Do」
   アミノ酸   （飼料用    ABFフィルム   ├─ 冷凍食品（ギョーザ等）
   ・医薬     アミノ酸）  半導体パッケージ└─ 海外の調味料事業
    受託製造            の層間絶縁材    （東南アジア・南米に強い）
                        │
                        └─▶ 世界シェア極めて高いとされ、
                             利益率が食品より桁違いに高い

  → 2026年3月期の事業利益1,811億円（+13.7%）を牽引したのは
    ヘルスケア等セグメント（電子材料を含む）と調味料・食品（同社IR）。

調味料業界の中で味の素が特殊なのは、次の3点である。

特殊な点 中身
非食品の高収益事業を持つ半導体パッケージ用絶縁材（ABFフィルム）。食品の利益率では考えられない水準の収益を生む。食品事業の値上げ交渉の切迫度が他社と違う
BtoBのうま味調味料が相場商品加工用（食品メーカー向け）のグルタミン酸ナトリウムは、中国・東南アジアの増産で国際的な供給過多と値崩れに直面していると報じられる。家庭用の「味の素」とは全く別の商売
新興国で「調味料の入口」を押さえている東南アジア・南米で、1回使い切りの小袋（サシェ）を露店経由で売る流通を自前で作った。所得が上がると、そのまま「ほんだし」「Cook Do」にアップグレードできる

2026年の値上げ：味の素は家庭用製品37〜39品種を、EC向けは2026年11月1日納品分、
家庭用は12月1日納品分から約5〜15%値上げすると発表した（2026年9月、報道）。
業務用も2026年8月1日納品分から改定している。

4. キユーピー・ハウス・エスビー ― 「素材の会社」という別の顔

会社 表の顔 実は本業に近いもの
キユーピーマヨネーズ・ドレッシング卵の総合活用。マヨネーズに使うのは卵黄。残る卵白は食品素材・ファインケミカル（ヒアルロン酸等）に回す。卵1個を無駄なく使い切る構造が原価を支えている。近年はパッケージサラダ・サラダ惣菜という「食べ方」まで押さえに行っている
ハウス食品グループ本社バーモントカレー・シチュー香辛料と機能性素材。ウコン（ウコンの力）、大塚食品との協業など。海外は中国のカレー事業と、米国の豆腐事業（House Foods America）という一見無関係な二本柱
エスビー食品カレー・チューブ薬味スパイスの調達・調合。胡椒・唐辛子・ハーブを世界から買い付け、配合する会社。国内スパイス市場では圧倒的で、外食・食品メーカー向けの調合スパイス供給が見えない収益源。2026年3月期は売上1,290億円（+4.5%）、営業利益103億円（+9.3%）。レトルトカレーは低価格帯「あじわい」が前年比147.8%と伸びた（同社IR）

エスビー食品は2027年3月期から第4次中期経営計画に入り、
海外売上高を2026年3月期の136億円から2029年3月期に210億円、構成比10.6% → 14.8% へ
引き上げる計画を示している（同社IR・報道）。
北米で即席カレーの配荷を広げるという、キッコーマンのテリヤキと同じ「用途を売る」路線である。

5. 業務用と外食への「食材提案」 ― 見えない主戦場

家庭用の棚が動かない以上、成長の余地は業務用にある。
ただし業務用は「安く売る」商売ではない。メニューを一緒に作る商売である。

【業務用調味料の営業がやっていること】

  ✕ ただの価格勝負                 ○ メニュー提案（食材提案）
  ┌──────────────┐           ┌────────────────────────┐
  │ 「うちのしょうゆは │           │ チェーン本部の商品開発部と組む │
  │  1L あたり○円です」│           │        │                │
  └──────────────┘           │        ▼                │
         │                     │ 「新メニューの味、一緒に作ります」│
         ▼                     │        │                │
  相見積もりで毎年叩かれる          │        ▼                │
  切り替えコストがゼロ              │ 専用のたれ・つゆを共同開発      │
                                │        │                │
                                │        ▼                │
                                │ そのチェーンでしか出ない味になる  │
                                │        │                │
                                │        ▼                │

                                │  = 簡単には外せない            │

  → 業務用の粘着性は「価格」ではなく「メニューに組み込まれていること」で生まれる。
販売先 特徴 関連ノート
外食チェーンメニュー採用されると数年安定。ただしメニュー改廃で一気に消えるファストフード／ファミリーレストラン／焼肉・ラーメン
中食（惣菜・弁当・CVS）最も伸びている販売先。少量多品種で開発負荷は重い中食・弁当／コンビニエンスストア
給食（学校・病院・事業所）数量は安定。入札が多く価格は厳しい。減塩要求が強い給食・フードサービス
食品メーカー（加工用）つゆ・たれ・冷凍食品の中身。ブランドは表に出ない冷凍食品・惣菜／即席麺

6. PBとの競合 ― 「基礎調味料ほど危ない」という逆説

プライベートブランド（PB＝小売が自社ブランドで売る商品）は、調味料でも広がっている。
ただし、効き方がカテゴリで正反対である。

カテゴリ PBの脅威度 理由
しょうゆ・みそ・酢（基礎調味料）高い味の違いが分かりにくい価格帯が存在する。中堅・地場メーカーがPBを受託し、NB（ナショナルブランド）の下に安い選択肢が常設される
マヨネーズ中キユーピーの指名買いが強く、PBは価格訴求の第2候補にとどまりやすい
カレールウ低「バーモント」「ゴールデン」といった商品名自体が指名される。味の設計が複雑で真似しにくい
メニュー専用調味料低用途とレシピをセットで売る商売。PBは後追いになる
うま味調味料低発酵設備が要る。小規模には作れない

ここに逆説がある。
① で見たとおり基礎調味料はブランドが強いが、
強いブランドのすぐ下に「同じように見える安い商品」を置けるのも基礎調味料である。
容器も味も分かりやすく、差が説明しにくい。

一方、PBを受託する側から見ると、自社ブランドを持たない中堅メーカーにとっては
工場の稼働率を埋める貴重な仕事でもある。この判断の一般論は
総合食品② 第6章にある。

富士経済によれば、PB食品は「低価格な廉価品」から品質・健康価値を打ち出すPBへと
ポジションが変わってきており、価格一辺倒ではない競合になりつつある（同社レポート、2026年）。

7. まとめ：各社の戦い方を理解する3つの鍵

鍵 中身
① 正面衝突していない各社が別カテゴリの1位。国内でシェアを奪い合う戦いはほぼ起きない。だから順位が長期間動かない
② 海外は「用途の発明」で決まる翻訳して売ると売れない。現地の食習慣に割り込む用途を作れた会社だけが数量を得た。そこまでいけば現地生産が成立し、運賃の壁が消える
③ 成長の余地は業務用・加工用にある家庭用の棚は動かない。だから外食・中食のメニュー開発に入り込む。粗利は薄いが数量と稼働率がついてくる

用語メモ

用語 意味
NB（ナショナルブランド）メーカーが自社ブランドで全国に売る商品。キッコーマンしょうゆ、キユーピーマヨネーズなど
PB（プライベートブランド）小売が自社ブランドで企画し、メーカーに製造委託して売る商品。トップバリュ、みなさまのお墨付きなど
テリヤキソース日本の照り焼きのたれを、米国向けに甘み・とろみを調整して商品化したもの。キッコーマンが米国で「調味料カテゴリ」として定着させた。日本の伝統食品ではなく、米国市場向けの発明品である点が重要
ABFフィルム（味の素ビルドアップフィルム）半導体パッケージの層間絶縁材。味の素のアミノ酸製造の副産物技術から生まれた。食品会社の収益を大きく押し上げている非食品事業
サシェ1回使い切りの小袋包装。新興国では冷蔵庫・保管場所・可処分所得の制約から、大容量より小袋が売れる。味の素が東南アジア・南米で展開した流通の核
配荷（はいか）商品が実際に店頭に並んでいる店の割合。「配荷率」が上がらないと、どれだけ広告を打っても売れない。海外展開の実務上の最重要指標
相見積もり（あいみつ）複数社から見積もりを取って比較すること。業務用調味料が毎年価格を叩かれる仕組み
