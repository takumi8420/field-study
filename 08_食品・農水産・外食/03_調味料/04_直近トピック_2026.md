## 1. キッコーマンが米国第3工場をオープン（2026年9月18日）

調味料業界で2026年最大のニュースは、キッコーマンの米国生産能力の拡張である。

| 項目     | 内容                                                                                                                                 |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| 場所     | 米国ウィスコンシン州ジェファーソン                                                                                                   |
| 経緯     | 2024年1月に建設発表 → 2024年4月着工 → **2026年5月にしょうゆの仕込み開始** → 2026年9月18日グランドオープニング → **10月出荷開始予定** |
| 位置づけ | 米国内で3か所目、海外では**9か所目**のしょうゆ生産拠点                                                                               |
| 投資額   | **10年間で約800億円**（報道ベース）                                                                                                  |
| 生産能力 | 2034年までの10年間で、既存工場と合わせ米国内の生産能力を**現状から3〜4割拡大**する計画（報道ベース）                                 |
| 狙い     | 多品種生産も視野に入れるとされる（時事通信、2026年9月19日）                                                                          |

```
【なぜ「工場を建てる」ことがニュースになるのか】

  発酵は仕込みから出荷まで時間がかかる（→ ①第3章）
        │
        ▼
  タンクを増やす＝数年先の需要を読んで、先に金を払うこと
        │
        ▼
  2024年4月 着工 ──▶ 2026年5月 仕込み開始 ──▶ 2026年10月 出荷
     │                    │                       │
     └─ 2年で建屋・設備 ──┘   └─ 半年近い熟成 ────┘

  → 「いま建て始めた工場は、2年半後にしか売上にならない」。
    逆に言えば、キッコーマンは2034年までの北米需要に賭けている。
```

背景にあるのは、北米しょうゆ事業の継続的な伸びである。
2026年3月期の海外売上収益は **5,802億円**（前期5,521億円から+5.1%）で、
売上収益7,455億円（+5.2%）、事業利益795億円（+2.9%、過去最高）を牽引した（同社IR）。
日本経済新聞は「海外で価格支配力が高く」、連結営業キャッシュフローの
1,000億円超えが視野に入ってきたと報じている（2026年8月）。

> この構図の意味は [② 各社の戦い方](02_各社の戦い方.md) 第2章（テリヤキという発明）にある。
> **用途を発明して数量を作り、現地生産で運賃の壁を消す**という順番が完成した状態。

## 2. 調味料の値上げが2026年後半に集中している

食品全体の値上げ品目数は2026年に入って落ち着いてきたが、**調味料は例外的に多い**。

| 発表元                 | 内容                                                                                                                                                                                                                          | 時期                        |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------- |
| **キユーピー**         | 家庭用 **224品目**を約3〜25%値上げ。調味料（マヨネーズ・ドレッシング・タルタルソース等）113品目、調理食品30品目、素材食品32品目、介護食49品目。キユーピーマヨネーズ450gは税込559円→**611円**。14か月で2度目の改定と報じられる | **2026年11月1日出荷分**から |
| **味の素**             | 家庭用製品 **37品種**を約**5〜15%**値上げ（「味の素」「アジシオ」など）。EC商品は11月1日納品分から                                                                                                                            | **2026年12月1日納品分**から |
| **味の素（業務用）**   | 業務用調味料の出荷価格改定                                                                                                                                                                                                    | 2026年8月1日納品分から      |
| **ミツカン**           | 納豆商品の価格改定（原材料費・製造コスト高騰）                                                                                                                                                                                | 2026年6月1日から            |
| **キユーピー（前回）** | 家庭用調味料の一部改定                                                                                                                                                                                                        | 2026年6月1日出荷分から      |

帝国データバンクの調査（2025年11月時点）では、2026年の値上げ予定品目は当初1,044品目と
前年同時期の見通し（4,417品目）から大幅に減少していた。
しかし2026年に入ると**1〜4月に最も値上げ品目が多かったのは調味料（1,603品目）**で、
マヨネーズ・食用油・ドレッシングが中心だったと報じられている。

```
【なぜ調味料だけ値上げが続くのか】

  ① 原料が全部同時に上がった
     菜種・大豆油 ↑（マヨネーズ・ドレッシングの主成分）
     鶏卵 ↑        （マヨネーズ）
     大豆・小麦・塩 ↑（しょうゆ・みそ）
     香辛料 ↑       （カレー・スパイス）

  ② 低単価・重量物なので、物流費・包材費の上昇が利幅を直撃（→ ③第6章）
     値上げ要因（2025年11月・帝国データバンク）
       原材料高   99.7% ████████████████████
       包装・資材  51.5% ██████████
       物流費     36.1% ███████
       人件費     34.4% ███████

  ③ 買い替え頻度が低く、指名買いが強い（→ ①第1章）
     = 値上げしても離脱されにくい ＝ 値上げしやすいカテゴリでもある

  → 「上げざるを得ない」と「上げられる」が重なった結果、
    調味料が値上げの主役になっている。
```

## 3. 2025年決算は「値上げが利益に効いた年」だった

2025〜2026年に締めた各社の決算は、**数量は伸びないが利益は改善**という共通の形になっている。

| 会社             | 決算期          | 売上                                               | 利益                                                    | コメント                                         |
| ---------------- | --------------- | -------------------------------------------------- | ------------------------------------------------------- | ------------------------------------------------ |
| **キッコーマン** | 2026年3月期     | 売上収益 **7,455億円**（+5.2%）                    | 事業利益 **795億円**（+2.9%）**過去最高**               | 海外しょうゆ・食品卸が牽引                       |
| **味の素**       | 2026年3月期     | 売上高 **1兆5,837億円**（+3.5%）                   | 事業利益 **1,811億円**（+13.7%）                        | 調味料・食品とヘルスケア等（電子材料）が牽引     |
| **ミツカン**     | 2026年2月期     | 売上高 **3,131億円**（▲0.2%、為替影響除くと+0.5%） | 営業利益 **267億円**（+29.2%）**過去最高**、3期連続増益 | 北米の収益性重視戦略＋原料容器費・物流費の改善   |
| **エスビー食品** | 2026年3月期     | 売上高 **1,290億円**（+4.5%）                      | 営業利益 **103億円**（+9.3%）                           | 低価格帯レトルトカレー「あじわい」が前年比147.8% |
| **キユーピー**   | 2026年11月期 2Q | 売上高 **2,616億円**（+3.9%）                      | 営業利益 **200億円**（+23.9%）                          | 価格改定の浸透、高付加価値品、海外拡大           |

ミツカンの国内セグメントは、**家庭用937億円（+2.2%）に対し業務用223億円（+1.5%）**。
家庭用の内訳では**納豆308億円（+6.1%）、ぽん酢142億円（+6.0%）、つゆ・鍋つゆ197億円（+4.6%）**が伸び、
**食酢は219億円（▲4.6%）と減少**した（同社発表、2026年6月4日）。

> ポイント：**基礎調味料（食酢）が減り、用途がはっきりした商品（ぽん酢・つゆ・納豆）が伸びる**
> という、[③ 市場の変化](03_市場の変化.md) で整理した構図が、
> そのまま1社の決算の中で起きている。

## 4. 輸出は過去最大 ― 醤油の輸出量が初めて6万トンに迫る

2025年（1〜12月）の農林水産物・食品の輸出額は **1兆7,005億円**（前年比+12.8%）で過去最高。
このうち調味料関連は次のとおり（財務省「貿易統計」を基に農林水産省作成）。

| 品目                 | 2025年 輸出額      | 前年比     | 備考                                                                                                                 |
| -------------------- | ------------------ | ---------- | -------------------------------------------------------------------------------------------------------------------- |
| **ソース混合調味料** | **721億4,600万円** | **+7.8%**  | カレー調製品・マヨネーズ・ドレッシング・酢・ウスターソース類等の合計。**2025年から酢を含む定義に変更**された点に注意 |
| **醤油**             | **134億9,300万円** | **+10.7%** | 輸出量は **5万9,778t**（+9.8%）で過去最大と報じられる                                                                |
| **味噌**             | **71億4,200万円**  | **+13.1%** | 2023年は前年比▲6.9%だったが再び伸びに転じた                                                                          |
| （参考）加工食品計   | 5,724億8,800万円   | +7.2%      |                                                                                                                      |

伸びた理由として農林水産省は「様々な調味料の需要の高まり」、
報道では**米国・韓国での日本式カレーの人気**や、**インバウンド経験を起点とした日本食への関心**が
挙げられている。

```
【調味料輸出が伸びる2つのルート】

  ルートA：海外の日本食レストランが増える
     日本食レストラン数の増加
        │
        ▼
     業務用の醤油・みりん・みそが要る
        │
        ▼
     まず輸出で入り、量が増えると現地生産に切り替わる
        ★キッコーマンはこの段階を70年かけて通過済み

  ルートB：現地の家庭料理に入り込む
     インバウンドで日本の味を体験
        │
        ▼
     帰国後、現地スーパーで買う
        │
        ▼
     ★ここで「エスニック棚」ではなく「調味料棚」に置けるかが勝負
       （→ ②第2章 テリヤキという発明）
```

全国醤油工業協同組合連合会は2025年の輸出額目標131億円を掲げており、実績はこれを上回った形。
醤油の輸出は2023年に初めて100億円を超えており、**金額の伸びが数量の伸びを上回る＝単価が上がっている**
（＝付加価値化している）点が特徴である。

## 5. みそが9年ぶりに増加、しょうゆは下げ止まり

長く減少が続いていた基礎調味料の数量に、変化の兆しが出ている。

| 品目         | 直近の数値                                                                                                                                                 | 意味                                                    |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------- |
| **みそ**     | 2025年（1〜12月）生産量 **36万2,589t**（+1.8%）、出荷量 **36万2,356t**（+1.8%）。**2016年以来9年ぶりに前年超え**（全国味噌工業協同組合連合会、報道ベース） | 近年は年約2%ずつ減っていたダウントレンドが下げ止まった  |
| **しょうゆ** | 2023年 出荷量 **68万3,340kl**（▲2.0%、しょうゆ情報センター）。2024年は前年並みの約68万klで着地したとみられる（報道）                                       | 1973年の129万klから半減に近い水準だが、減少ペースが鈍化 |

下げ止まりの理由として業界で挙げられているのは、
**①値上げ後も離脱が起きにくかったこと、②中食・内食回帰の一部戻り、③輸出の押し上げ**。
ただし「人口 × 食事回数」という構造的な上限は変わっていない
（→ [総合食品④](../01_総合食品/04_国内成熟と海外展開.md)）ため、
**トレンド転換と見るのは早い**という慎重な見方も強い。

なお、しょうゆメーカーの数は **2024年で1,013社**（1955年の約6,000社、2000年の1,611社から減少）とされ、
数量の下げ止まりとは別に、**事業者数の減少は続いている**。

## 6. 加工用うま味調味料の世界的な供給過多

家庭用の「味の素」とは別に、食品メーカー向けの**加工用グルタミン酸ナトリウム（MSG）**は
国際的な供給過多と値崩れに直面していると報じられている。
中国・東南アジアの増産が背景とされる。

|                | 家庭用うま味調味料       | 加工用うま味調味料（BtoB）                             |
| -------------- | ------------------------ | ------------------------------------------------------ |
| 売り先         | 消費者（スーパー・EC）   | 食品メーカー・外食                                     |
| 価格の決まり方 | ブランド。建値＋リベート | **実質コモディティ。国際需給で決まる**                 |
| いまの状況     | 2026年12月に5〜15%値上げ | 供給過多で軟調                                         |
| 味の素の対応   | 値上げと用途拡大         | サプライチェーンを一元管理して再成長を図る方針（報道） |

これは**同じ商品名でも、売る相手が変わると全く別の商売になる**という、
調味料業界の構造をよく示す例である（→ [①](01_調味料が強い商売である理由.md) 第4章）。

## 7. 全体の構図

2026年9月時点の調味料業界は、次の4つの力が同時に働いている。

```
【4つの力】

  ① コスト圧力（原料・包材・物流・人件費）
       │
       ▼  値上げで対応 → 調味料は指名買いが強いので通しやすい
  ② 値上げの浸透 ──▶ 【利益は改善】 各社が過去最高益を更新
       │
       ▼
  ③ 国内数量の構造的減少（人口・内食減）
       │    ただし2025年は みそ+1.8%、しょうゆ下げ止まりと小休止
       ▼
  ④ 海外・輸出・業務用へのシフト
       醤油輸出 過去最大（5万9,778t）
       キッコーマン米国第3工場（10年800億円）
       エスビー 海外構成比 10.6%→14.8% 計画

  → 結論：「国内で数量を伸ばす」ことを、もう誰も主戦場にしていない。
    国内は値上げと高付加価値化で利益を守り、
    成長は海外と業務用・メニュー用に置く、という形が固まった年。
```

一方で、**2027年4月からの飲食料品消費税1%**（2026年9月15日閣議決定、法改正が必要）は
調味料にとっても大きな変数になる。
店頭価格が下がる余地に値上げをぶつけられる一方、
2029年4月の税率戻りに向けた需要変動が読みにくい。
制度の詳細は [総合食品⑤](../01_総合食品/05_直近トピック_2026.md) 第2章を参照。

| **ソース混合調味料**       | 農林水産省の輸出統計の品目区分。カレー調製品・マヨネーズ・ドレッシング・酢・ウスターソース類等の合計。**2025年から酢を含む定義に変わった**ため、前年比を見るときは注意               |
| **グランドオープニング**   | 工場の本格稼働を祝う式典。仕込み開始と出荷開始の間に行われることが多い                                                                                                               |
| **為替影響を除いた前年比** | 海外売上を現地通貨ベースで比較した数値。ミツカンのように海外比率6割の会社では、円換算の売上と実態が大きくずれるため必ず確認する                                                      |
| **配荷率**                 | 対象となる店舗のうち、実際にその商品を置いている店の割合。海外展開では売上より先にこれを見る                                                                                         |
| **飲食料品の消費税1%**     | 2026年9月15日の閣議決定による方針。2027年4月1日〜2029年3月31日の2年間、飲食料品の消費税率を8%→1%とする臨時措置（法改正が必要） → [総合食品⑤](../01_総合食品/05_直近トピック_2026.md) |
