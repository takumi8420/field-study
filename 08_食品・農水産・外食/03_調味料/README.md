- 大分類: 食品・農水産・外食

## このフォルダの読み方

調味料は、食品の中で**最も順位がひっくり返らないカテゴリ**である。
しょうゆといえばキッコーマン、マヨネーズといえばキユーピー、酢といえばミツカン。
この並びは数十年変わっていない。

理由は単純で、**買い替え頻度が低いのに、ブランド指名が極端に強い**から。
調味料を変えるとは、家庭の料理の味をすべて変えるということで、
消費者は数十円の差では乗り換えない。結果として**棚が動かない**。
だから新規参入が入れず、営業利益率も食品の中では高い7〜12%程度を保てる。

もうひとつ重要なのは、**「調味料業界」は単一市場ではない**ということ。
しょうゆ・みそ・酢・みりん・うま味調味料・マヨネーズ・カレー……は互いに競合しておらず、
**小さな寡占が7つ並んでいる**状態にある。だからシェアを語るときは必ずカテゴリを限定する。

このフォルダは [総合食品](../01_総合食品/README.md) の基礎（損益構造・値決め・商品開発・海外展開）を
**前提**にしている。ここでは調味料固有の話だけを書く。

## 1. 業界の定義・範囲

**調味料** ＝ 食材そのものではなく、**味を付けるために使われる食品**の総称。
本フォルダでは、家庭用・業務用として流通する加工調味料を扱う。

```
【「調味料」という言葉が指す範囲】

  ┌──────────── 本フォルダの対象 ────────────────┐
  │                                                        │
  │  ◆ 基礎調味料（さしすせそ＋α）                          │
  │     しょうゆ／みそ／食酢／みりん／うま味調味料            │
  │     ※砂糖・塩は素材型なので → 02_製粉・製糖・製油        │
  │                                                        │
  │  ◆ 乳化・配合系                                        │
  │     マヨネーズ／ドレッシング／ソース類                    │
  │                                                        │
  │  ◆ スパイス・香辛料                                     │
  │     カレールウ／スパイス／チューブ薬味                    │
  │                                                        │
  │  ◆ 二次加工調味料（基礎調味料を組み合わせたもの）          │
  │     めんつゆ／鍋つゆ／焼肉のたれ／ぽん酢                  │
  │     メニュー専用調味料（「◯◯の素」）／風味調味料（だし）  │
  └────────────────────────────────────────────────┘

  隣接するが別扱いのもの：
   ・砂糖・食塩・食用油の「素材そのもの」  → 02_製粉・製糖・製油
   ・本みりん                             → 酒税法上は酒類。08_ビール・酒類 も参照
   ・食品添加物（増粘剤・保存料など）       → 素材・化学の領域
   ・スープ・即席みそ汁                    → 加工食品寄り。01_総合食品
   ・ケチャップ・トマト加工品               → 農産加工。カゴメが代表
```

境界の引き方で押さえるべき点。

- **家庭用・業務用・加工用の3つの売り先がある**。同じ工場で作っていても商売が別物
  （→ [①](01_調味料が強い商売である理由.md) 第4章）。
- **「調味料業界」は単一市場ではない**。しょうゆとマヨネーズは競合しない。
  シェアを語るときは必ずカテゴリを限定する。
- **素材（砂糖・塩・油）と調味料の線引き**は、加工度とブランドの有無で引く。
  素材型の利益率は2〜5%だが、調味料は7〜12%になりうる。

（国内の「調味料市場◯兆円」という数字は、調査会社ごとに対象品目が異なり比較できない。
富士経済「食品マーケティング便覧」などの有料レポートで、**対象品目の定義を確認したうえで**使うこと）

成長性の読み方。

- **国内の数量は構造的に減る**。人口減に加え、内食→中食シフトで
  「家庭でしょうゆの瓶を使う機会」そのものが減っている（→ [③](03_市場の変化.md) 第2章）。
- **ただし金額は保たれている**。値上げと高付加価値化（鮮度容器・減塩・こだわり品）で単価が上がり、
  醤油市場は「単価上昇と輸出増で市場を維持」と報じられる。
- **伸びしろは3つに限られる** — ①海外（輸出＋現地生産）、②業務用・加工用、
  ③メニュー専用・簡便調味料。国内の基礎調味料で数量を伸ばす戦い方は、もう誰も取っていない。

## 3. バリューチェーン（川上 → 川下）

```
【モノ・カネ・情報の流れ】

 モノ
   大豆・小麦・塩 ──▶ 製油/製粉 ──▶ ★調味料メーカー★ ──┬─▶ 卸 ─▶ 小売 ─▶ 家庭
   （輸入が大半）      （脱脂加工大豆）    │              │
   菜種・鶏卵 ─────────────────────────┤              ├─▶ 業務用卸 ─▶ 外食・給食
   香辛料（輸入）──────────────────────┤              │
                                        │              └─▶ 食品メーカー（加工用）
                                        │                   └▶ つゆ・惣菜・冷食の中身になる
                                   ★発酵・熟成★
                                   6か月〜1年以上
                                   （在庫と運転資金が寝る）

 カネ
   家庭用  建値 ＋ リベート・特売協賛     → 総合食品② と同じ構造
   業務用  相対（あいたい）交渉・年間契約  → メニュー採用されると数年安定
   加工用  数量契約。粗利は最も薄い

 情報
   家庭用  POS・棚割り  ◀── 小売／卸
   業務用  メニュー開発の相談 ◀──▶ 外食チェーンの商品開発部
           ★ここが業務用の本体。価格ではなく味の設計で入り込む
```

付加価値がどこに集まるか。

| 段階                             | 営業利益率の目安 | なぜそうなるか                                                                  |
| -------------------------------- | ---------------- | ------------------------------------------------------------------------------- |
| 原料（大豆・小麦・塩・油）       | 2〜5%            | 相場商品。差別化できない → [製粉・製糖・製油](../02_製粉・製糖・製油/README.md) |
| **調味料メーカー（家庭用）**     | **7〜12%**       | **ブランド指名が強く棚が安定。販促費を抑えられる**                              |
| 調味料メーカー（業務用・加工用） | 薄い             | 相見積もりで叩かれる。ただし数量と工場稼働率を支える                            |
| 食品卸                           | 1%台             | 誰でも扱える → [食品卸](../../06_商社・卸売/06_食品卸/README.md)                |
| 小売                             | 2〜3%            | 立地と品揃えの勝負                                                              |

> ポイント：**調味料メーカーの利益は「家庭用のブランド」から出て、
> 数量と稼働率は「業務用・加工用」が支える**。どちらか一方では成り立たない二階建て構造。

**シェアの見方**：この業界に「調味料業界のシェア」という概念は存在しない。
しょうゆ・食酢・マヨネーズ・カレールウ……と**カテゴリごとに別の会社が1位**であり、
互いにほとんど競合していない（→ [①](01_調味料が強い商売である理由.md) 第2章）。

```
  │         ├─ 物流費      7〜11 ◀★食品平均より重い（低単価・重量物）
  │         ├─ 営業人件費  6〜8
  │         └─ 研究開発費  1〜2
  └─ 営業利益 7〜12  ← ★食品メーカー平均（5〜8%）より高い

  ★印が調味料の特徴。
   「販促費が軽く、物流費と償却が重い」が、他の加工食品との最大の違い。
```

| 収益・コストの論点       | 中身                                                                                                                                        |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------- |
| **販促費が軽い**         | 棚が動かず指名買いされるので、新商品を大量に出して棚を守る必要が薄い。**これが利益率の源泉**                                                |
| **物流費が重い**         | 1Lしょうゆは約1.1kg、売価は200円前後。**重さあたりの値段が安く、運賃上昇が利益を直撃**する（→ [①](01_調味料が強い商売である理由.md) 第5章） |
| **発酵設備の償却が重い** | タンクは巨大で、増設には数年かかる。稼働を落とせないので**業務用・加工用で数量を埋める必要がある**                                          |
| **在庫と運転資金**       | 仕込みから出荷まで半年〜1年以上。**原料を買った金がその間寝る**                                                                             |
| **原料は全部輸入相場**   | 大豆・小麦・塩・菜種油・香辛料。為替と相場で決まる。ヘッジは時間を買うだけ → [総合食品①](../01_総合食品/01_食品メーカーの損益構造.md)       |
| **値上げは通りやすい**   | 買い替え頻度が低く指名買いが強いため、離脱が起きにくい。2026年1〜4月の値上げ品目は調味料が最多（1,603品目）                                 |

## 6. 競争要因（KSF）と参入障壁

| KSF                          | 中身                                                                                                                       |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| **ブランド＝家庭の味の記憶** | 乗り換えのコストが「家庭の料理の味が全部変わる」こと。数十円の価格差では動かない。**数十年かけて蓄積された、買えない資産** |
| **発酵の技術と菌**           | 各社独自の麹菌株と蔵の微生物相。レシピを知っても再現できない                                                               |
| **生産能力の先行投資**       | タンクは数年先を読んで建てる。キッコーマン米国第3工場は着工から出荷まで2年半                                               |
| **全国・現地の工場網**       | 重量物なので輸送距離が競争範囲を決める。海外は現地生産に切り替えないと価格で勝てない                                       |
| **業務用のメニュー入り込み** | 価格ではなく、外食チェーンのメニュー開発に入って専用の味を作ること。切り替えるとメニューが変わるので粘着する               |
| **原料調達力**               | 大豆・小麦・塩・香辛料の相場を吸収する購買力。規模が効く                                                                   |

**参入障壁**は許認可ではない。実質的な障壁は
**①ブランドの蓄積（＝時間）、②発酵設備と菌（＝時間と資本）、③動かない棚**の3つ。
とくに③は他の食品カテゴリにない障壁で、
**棚が空かないので、良い商品を作っても置く場所がない**という形で効く。

逆に、**メニュー専用調味料・簡便調味料の棚は動く**。
新規参入や新商品競争が成立するのはこの領域に限られる（→ [③](03_市場の変化.md) 第3章）。

## 7. 規制・法制度

| 制度                                                         | 内容                                                                                                                                 | 調味料への影響                                                                                                                                      |
| ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| **しょうゆのJAS規格**                                        | 本醸造・混合醸造・混合という製法区分と、こいくち・うすくち・たまり・さいしこみ・しろという種類の表示。等級（特級・上級・標準）も規定 | **製法と等級が表示義務**になっているため、価格帯と棚の位置がそのまま製法で分かれる。安価な混合方式と本醸造が混同されない                            |
| **みそのJAS規格／公正競争規約**                              | 原料（米・麦・豆）、味（甘・辛）、色による区分                                                                                       | 地域ごとの多様性が制度上も保たれている                                                                                                              |
| **酒税法（本みりん）**                                       | アルコール分14%前後の本みりんは**酒類**。製造免許・酒類販売免許が必要                                                                | 「みりん風調味料」はアルコール1%未満に抑えて酒類を回避したもの。**同じ棚に法的に全く違う商品が並ぶ** → [ビール・酒類](../08_ビール・酒類/README.md) |
| **食品表示法**                                               | 原材料名、アレルゲン（小麦・大豆・卵など）、栄養成分、原料原産地の表示義務                                                           | しょうゆは小麦・大豆、マヨネーズは卵と、**主原料がそのままアレルゲン**。表示の誤りは自主回収に直結                                                  |
| **食品衛生法／HACCP**                                        | 2021年6月から原則すべての食品事業者に義務化                                                                                          | 地場の中小しょうゆ・みそメーカーに記録・管理の負担。**メーカー数減少（1,013社）の一因**                                                             |
| **健康増進法／食事摂取基準**                                 | 成人の食塩相当量の目標は男性7.5g/日未満、女性6.5g/日未満（2020年版）                                                                 | **調味料は食塩摂取の主要経路**。減塩が公衆衛生上の要請として継続的に効く → [③](03_市場の変化.md) 第4章                                              |
| **景品表示法**                                               | 「減塩」「◯%カット」などの表示根拠                                                                                                   | 減塩訴求には比較対象と根拠が要る                                                                                                                    |
| **改正物流効率化法**                                         | 2026年4月から特定事業者にCLO（物流統括管理者）選任義務                                                                               | **重量物を扱う調味料メーカーは荷主として該当しやすい**。物流が経営アジェンダに                                                                      |
| **軽減税率／飲食料品の消費税引下げ**                         | 2026年9月15日閣議決定により、**2027年4月1日〜2029年3月31日の2年間、飲食料品の消費税率を8%→1%**とする方針（法改正が必要）             | 店頭価格が下がる余地に値上げをぶつけられる → [総合食品⑤](../01_総合食品/05_直近トピック_2026.md)                                                    |
| **独占禁止法（優越的地位の濫用）／適正取引推進ガイドライン** | 公取委が毎年度「価格転嫁円滑化に関する調査」を実施。ガイドラインは2026年1月改定                                                      | 値上げ交渉の後ろ盾 → [総合食品②](../01_総合食品/02_値決めと交渉.md)                                                                                 |

## 9. 用語メモ

各ノートの末尾に詳しい用語メモがある。ここでは最重要の8つだけ。

| 用語                         | 意味                                                                                                                                                           |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **本醸造（ほんじょうぞう）** | しょうゆの製法区分。麹菌で発酵・熟成させる伝統的な方式。JAS規格で表示が義務。家庭用の主力 → [①](01_調味料が強い商売である理由.md)                              |
| **諸味（もろみ）**           | 発酵・熟成途中のどろっとした中間品。搾るとしょうゆになる。半年〜1年かけて熟成する → [①](01_調味料が強い商売である理由.md)                                      |
| **脱脂加工大豆**             | 大豆から油を搾ったあとの粕をしょうゆ用に加工したもの。国内しょうゆの主原料 → [製粉・製糖・製油](../02_製粉・製糖・製油/README.md)                              |
| **うま味調味料**             | グルタミン酸ナトリウム（MSG）が主成分。サトウキビ糖蜜などを原料に**発酵法**で作る（化学合成ではない）→ [②](02_各社の戦い方.md)                                 |
| **加工用（原料用）**         | 食品メーカーに原料として売る分。つゆ・たれ・惣菜・冷凍食品の中身になり、メーカー名は表に出ない → [①](01_調味料が強い商売である理由.md)                         |
| **メニュー専用調味料**       | 「麻婆豆腐の素」のように特定の1メニュー用に配合された調味料。基礎調味料の出番を置き換える → [③](03_市場の変化.md)                                              |
| **テリヤキソース**           | 日本の照り焼きのたれを米国向けに調整した商品。キッコーマンが「エスニック棚」ではなく「調味料棚」に置かせた、海外展開の教科書的な発明 → [②](02_各社の戦い方.md) |
| **鮮度容器**                 | 開封後も空気に触れさせない二重構造ボトル。酸化を防ぎ、単価を上げる代表的な高付加価値化技術 → [③](03_市場の変化.md)                                             |
