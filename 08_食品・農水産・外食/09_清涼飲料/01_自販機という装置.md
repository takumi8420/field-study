# ① 自販機という装置

このノートで分かること：日本の清涼飲料メーカーの利益が**どこから出ていたのか**、
そしてなぜ 2025〜2026 年に大手各社が自販機で**そろって巨額の減損**を出したのか。

## 1. 結論：自販機は「定価が通る唯一のチャネル」だった

清涼飲料を他の食品と分ける最大の特徴は、**メーカーが自分で小売店を持っている**ことにある。
それが自動販売機（以下、自販機）である。

> **自販機はメーカー直販なので、値引きも特売もリベートもない。
> 希望小売価格がそのまま売価になり、粗利が最も厚い。
> だから日本の飲料メーカーは、長いあいだ「自販機で稼いで、スーパーで数量を取る」という
> 二階建ての商売をしてきた。**

一般の食品メーカーは、卸と小売を通して売る。建値（メーカーが示す基準納入価格）を出しても、
特売協賛やリベートで実質価格は下がり、店頭価格は小売が決める
（→ [総合食品② 値決めと交渉](../01_総合食品/02_値決めと交渉.md)）。
ところが自販機だけは、**値段を決めるのも、置くのも、補充するのも、代金を回収するのもメーカー**である。
食品業界でこれができるのは清涼飲料とたばこくらいしかない。

この「厚い粗利の装置」が、いま急速に採算を失いつつある。
2025〜2026 年にかけて、コカ・コーラ ボトラーズジャパン、ダイドー、伊藤園が
相次いで自販機資産の減損（帳簿価額の切り下げ）を計上し、
ポッカサッポロは自販機事業そのものを売却した（第7章）。

```
【清涼飲料メーカーの「二階建て」構造】

  ┌──────────────────────────────────────────────┐
  │  2階：自販機チャネル（メーカー直販）             │
  │   ・売価 = 希望小売価格（定価が通る）            │
  │   ・粗利率 50〜60% 程度と言われる               │
  │   ・ただし 1台ごとに固定費が乗る                 │
  │      （機械の償却・電気代・ロケーション手数料・補充人件費）│
  │   → 数量は少ないが「利益」を稼ぐ場所             │
  ├──────────────────────────────────────────────┤
  │  1階：店頭チャネル（卸・小売経由）               │
  │   ・売価 = 小売が決める（88円・98円の特売）      │
  │   ・粗利率 20〜30% 程度                         │
  │   → 「数量」と工場稼働率を稼ぐ場所               │
  └──────────────────────────────────────────────┘

  2階が縮むと、1階の数量だけでは利益が出ない ← いま起きていること
```

## 2. 自販機は何台あるのか

| 指標                                       | 数値                                                    | 年・出典                                                                          |
| ------------------------------------------ | ------------------------------------------------------- | --------------------------------------------------------------------------------- |
| 自販機・自動サービス機の普及台数（全機種） | **約388万台**                                           | 2025年末。日本自動販売システム機械工業会（JVMA）。10年前比で2割以上減と報じられる |
| うち清涼飲料の自販機                       | **1,976,200台**（飲料自販機の50.2%）                    | 2024年12月末。全国清涼飲料連合会Q&A                                               |
| ピーク圏との比較                           | 2016年 約494万台 → 2022年 約397万台（6年で約100万台減） | ITmedia ビジネスオンライン（2026年7月）報道ベース                                 |
| コカ・コーラ ボトラーズジャパンの保有台数  | **約65万台**                                            | 2025年。報道ベース                                                                |
| ダイドーグループHDの保有台数               | **約27万台**（国内販売の約9割が自販機）                 | 2026年。報道ベース                                                                |
| 伊藤園の保有台数                           | **約7.5万台**（2015年は約16.5万台）                     | 2025年12月。日本経済新聞報道                                                      |

読み方のポイント。

- **「388万台」は飲料だけの数字ではない**。たばこ・食品・券売機・両替機・コインロッカーまで
  含む工業会統計の数字なので、飲料だけなら200万台前後と見るのが妥当。
- **減り方が一様ではない**。全体では年1%前後の減少だが、伊藤園のように
  10年で半分以下にした会社もある。**「採算の悪い台を捨てる」意思決定の差**が出ている。
- 世界的に見ても日本の台数密度は突出している。人口 1.2 億人に対して飲料自販機約200万台、
  つまり **国民60人に1台**という計算になる。これが「自販機大国」と呼ばれた根拠である。

## 3. 自販機1台の損益 ― どこで儲かり、どこで消えるか

自販機ビジネスは、**1台を1つの小さな店舗**と見ると理解しやすい。
以下は公開情報・事業者向け資料をもとにした**典型例の試算**であり、実際は立地で大きくぶれる。

```
【飲料自販機 1台の月次損益（標準的なロケーションの試算例）】

  販売本数        1,000本/月（1日あたり約33本）
  平均売価        160円/本（旧価格帯。2026年の値上げ後は175円前後）
  ───────────────────────────────────
  売上            160,000円
   − 商品原価      64,000円  (40%。工場出荷原価＋物流)
  ───────────────────────────────────
  粗利             96,000円  （粗利率 60%）
   − ロケーション手数料  16,000〜32,000円 （売上の10〜20%が目安）
   − 電気代         3,000〜8,000円   （原則オーナー負担だが実質的な設置条件になる）
   − 補充・集金人件費 25,000〜35,000円 （ルート営業1人が1日20〜30台を回る）
   − 機械の減価償却  8,000〜12,000円  （1台50〜80万円を5〜7年で償却）
   − 通信費・メンテ   2,000〜4,000円   （遠隔監視・キャッシュレス端末）
  ───────────────────────────────────
  営業利益         ざっくり 0〜25,000円 ← 損益分岐は月700〜800本あたり
```

> ポイント：**自販機の粗利率は60%と極めて高いが、その粗利の大半は
> 「1台あたりの固定費」で消える。** だから決定的に効くのは**販売本数**である。
> 月1,000本売れる台と月400本の台で、売上は2.5倍しか違わないのに、
> 利益は「黒字」と「明確な赤字」に分かれる。

なぜ固定費が重いのか。**自販機は無人販売に見えて、実は極めて人手がかかる**からである。

- 補充・集金は人が行く。ルート営業（ベンダー担当者）1人が1日に20〜30台を回る。
- 売れようが売れまいが、**1台あたりの訪問コストはほぼ同じ**。
  だから売れない台ほど1本あたりのコストが跳ね上がる。
- 近年は**キャッシュレス決済への対応改修**が加わった。
  交通系IC・QR決済に対応するには1台数万円の追加投資が要る。
  これが「古い台をそのまま使い続ける」ことを難しくした。

## 4. チャネル別の粗利 ― なぜ自販機が特別なのか

同じ 500ml のペットボトルでも、**売る場所によってメーカーの手取りが全く違う**。

| チャネル                             | 消費者の支払額（目安） | メーカーの手取り（目安） | メーカー側の追加コスト                   | 実質的な粗利の厚さ               |
| ------------------------------------ | ---------------------- | ------------------------ | ---------------------------------------- | -------------------------------- |
| **自販機（直販）**                   | 180〜220円             | **売価そのもの**         | ロケーション手数料、補充人件費、機械償却 | **最も厚い**。ただし固定費が重い |
| コンビニ                             | 160〜180円             | 100〜120円前後           | 少量多頻度配送、専用商品の開発           | 中。定番価格が守られやすい       |
| スーパー・食品スーパー               | 88〜128円（特売時）    | 70〜90円前後             | 特売協賛、チラシ協賛、センターフィー     | 薄い                             |
| ドラッグストア・ディスカウントストア | 78〜108円              | 65〜85円前後             | さらに強い値下げ圧力                     | **最も薄い**                     |
| EC（ケース買い）                     | 1本あたり70〜100円     | 60〜85円前後             | 送料負担、箱・梱包                       | 薄い。ただし数量は安定           |

（各社IR・報道・小売価格の実勢からの概算。為替や値上げ局面で毎年動くため、最新は各社の決算説明資料で確認）

この表がすべてを語っている。

- **自販機で1本売ると、スーパーで2〜3本売るのと同じ利益**になる。
  だから台数が2割減ると、店頭で数量を4〜6割増やさないと利益が埋まらない。
  現実にはそんな数量増は起きないので、**台数減はそのまま利益減になる**。
- 逆に言えば、**ドラッグストアとディスカウントストアの拡大は飲料メーカーにとって二重の打撃**だった。
  自販機の客を奪ったうえに、奪った先の粗利が最も薄い
  （→ [ドラッグストア](../../07_小売・流通/04_ドラッグストア/README.md)、
  [ディスカウントストア](../../07_小売・流通/09_ディスカウントストア/README.md)）。

## 5. ベンダー ― 自販機を運営するという事業

**ベンダー（vendor）＝自販機オペレーター**。自販機を設置して商品を補充し、
売上を回収する事業者のこと。清涼飲料の自販機には大きく3つの型がある。

| 型                                   | 誰が運営するか                           | 商品構成                           | メーカーにとっての意味                                           |
| ------------------------------------ | ---------------------------------------- | ---------------------------------- | ---------------------------------------------------------------- |
| **メーカー直営（フルサービス）**     | 飲料メーカー／その販社が自分で設置・補充 | 自社商品のみ（一部他社品）         | 粗利は最大。ただし人と機械を自社で抱える                         |
| **専業ベンダー（複数メーカー扱い）** | 独立系のオペレーター会社                 | 各社の商品を混載。安い価格設定も可 | メーカーは「卸売価格で納める」だけ。粗利は薄いが固定費は持たない |
| **ロケーションオーナー買取型**       | 設置場所の持ち主（企業・ビル・工場）     | オーナーが仕入れて自分で補充       | メーカーはケース販売と同じ。数量だけ取れる                       |

**ロケーションオーナー**＝自販機を置く場所（オフィスビル、工場、駐車場、病院、駅など）の持ち主。
メーカー直営・専業ベンダー型では、オーナーは「場所と電源」を出し、
見返りに**ロケーション手数料（販売手数料）**を受け取る。

```
【自販機をめぐるお金と役割の流れ】

  消費者 ──160〜220円──▶ 自販機
                            │
         ┌──────────────────┼──────────────────┐
         │                  │                  │
         ▼                  ▼                  ▼
  ロケーションオーナー    ベンダー（運営者）    飲料メーカー
  （場所＋電源を提供）    （補充・集金・保守）   （商品を供給）
         │                  │                  │
   手数料 売上の10〜20%   人件費・車両・機械償却   工場出荷原価
   （電気代は実質負担）     を回収して利ざや       ＋ブランド投資

  ※ メーカー直営の場合、真ん中のベンダー機能をメーカー自身が持つ。
    この「自前の販売網」こそが清涼飲料業界の粗利の源泉であり、
    同時にいま重荷になっている固定費でもある。
```

手数料の設計には2つの型がある。

- **売上連動型**：売れた金額の10〜20%をオーナーに支払う。売れない立地ではオーナー収入もゼロに近い。
- **固定型（定額）**：1台あたり月額いくらで支払う。オーナーには安定収入だが、
  ベンダー側は売れない台で確実に赤字になるため、**近年は連動型に寄っている**。

## 6. なぜ台数が減っているのか ― 6つの理由

単一の犯人はいない。**需要側・競合側・コスト側の三方向から同時に効いている**。

| 分類     | 要因                                             | 効き方                                                                                                                                          |
| -------- | ------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| 需要側   | **マイボトル（水筒）の定着**                     | 節約と環境意識の両方から。とくにオフィスと学校で効く                                                                                            |
| 需要側   | **人口減少と、職場・学校の人数減**               | 自販機の売上は「その場所に何人いるか」でほぼ決まる。在宅勤務の定着も直撃した                                                                    |
| 競合側   | **コンビニの拡大とカウンターコーヒー**           | 100〜180円で淹れたてが飲める。缶コーヒーの最大の競合になった（→ [コンビニエンスストア](../../07_小売・流通/01_コンビニエンスストア/README.md)） |
| 競合側   | **ドラッグストア・ディスカウントストアの安売り** | 同じ商品が自販機の半額前後で買える。価格差が可視化された                                                                                        |
| コスト側 | **キャッシュレス対応の改修費**                   | 1台あたり数万円。売れない台では投資回収できない                                                                                                 |
| コスト側 | **人手不足とルート人件費・燃料費の上昇**         | 補充の人が確保できない。2024年問題以降のドライバー不足も効く（→ [陸運・トラック](../../13_運輸・物流/06_陸運・トラック/README.md)）             |

> ポイント：**値上げが自販機にとっては「とどめ」になった。**
> 店頭は特売で88円のまま、自販機だけ160円→180円→2026年に220円へ上がると、
> **価格差が2.5倍**になる。価格差が見えるほど、自販機は「急ぎのとき・喉が渇いたときだけ」の
> 緊急用チャネルに退いてしまう。

## 7. 2025〜2026年に起きた「減損ラッシュ」

減損とは、**帳簿に載せている資産の価値を、将来稼げる見込みに合わせて切り下げる会計処理**のこと。
自販機は「機械」という固定資産なので、その資産群が将来キャッシュを生まないと判断されれば
一度に損失が出る。2025〜2026年に起きたのは、まさにこれである。

| 会社                                  | 内容                                                                                                                                                                          | 時期・出典                                                                  |
| ------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| **コカ・コーラ ボトラーズジャパンHD** | 自販機事業で **881億円の減損**。2025年12月期の連結最終損益は **507億円の赤字**                                                                                                | 2025年1〜6月期に計上／確報は2026年2月。日本経済新聞・東洋経済オンライン報道 |
| **ダイドーグループHD**                | 2025年度は売上高 **2,412億円**、経常利益41億円ながら、**298億円の減損**で最終損失 **303億円**。国内飲料事業は22億円の営業赤字。自販機27万台のうち **2万台を削減**する方針     | 2026年2月発表。報道ベース                                                   |
| **伊藤園**                            | 2026年4月期に自販機事業で **135.9億円の減損**。連結純利益は前期比93%減の10億円へ下方修正（従来予想から150億円の下振れ）。25年5〜10月の自販機飲料販売数量は前年同期比 **▲14%** | 2026年1月発表。日本経済新聞報道                                             |
| **ポッカサッポロ（サッポロHD）**      | 自販機 **約4万台**の事業をライフドリンクカンパニーへ売却（2026年10月めど）。対象社員は約300人                                                                                 | 2026年3月5日発表。日本経済新聞ほか                                          |
| **コカ・コーラ ボトラーズジャパン**   | 自販機の**運営・管理業務を外部化**。運営会社の過半株式をシンクランHDへ、企画・管理業務をジェンパクトへ譲渡                                                                    | 2024年8月公表                                                               |

ここから読み取るべきことは3つある。

- **「儲かっていないから減損した」のではない**。コカ・コーラBJHは事業利益ベースでは
  むしろ改善していたと説明している。減損は**「将来これだけの台数で稼げる前提を下げた」という
  経営判断の表明**であり、実質的には**縮小の宣言**である。
- **減損はキャッシュアウトを伴わない**。現金が出ていくわけではなく、
  **翌期以降の減価償却費が軽くなる**ので、損益は改善しやすくなる。
  「膿を出す」処理なので、翌期の数字だけを見ても実態は分からない。
- **事業売却という選択肢が現実になった**。サッポロHDの撤退は、
  「自販機は飲料メーカーの必須インフラ」という前提が崩れたことを示す。
  買い手のライフドリンクカンパニーは**低価格PBを得意とする会社**で、
  高価格の自販機を安価な商材で埋め直すという別の勝ち筋を狙っているとみられる。

## 8. これからの自販機 ― 「減らす」のではなく「置き直す」

台数を減らすのは目的ではない。実際に各社が進めているのは**立地の選別と置き直し**である。

```
【立地の選別ロジック】

   売上（本/月）
     高 ▲
        │  ┌──────────────┐   ┌──────────────┐
        │  │ 駅・病院・空港 │   │ 大規模工場   │
        │  │ 観光地・高速SA │   │ 大型オフィス │  ← 守る・機械を更新する
        │  └──────────────┘   └──────────────┘
        │
        │  ┌──────────────┐   ┌──────────────┐
        │  │ 中小オフィス   │   │ 屋外・路上   │  ← 手数料を下げて交渉
        │  │ マンション     │   │ 駐車場       │     ダメなら撤去
   低   │  └──────────────┘   └──────────────┘
        └──────────────────────────────────▶
          低                            高    電気代・手数料などの固定費

   ・右下（売れないのに固定費が高い）＝ 真っ先に撤去される象限
   ・撤去した台は廃棄せず「中古機」として優良立地に転用される
     → ダイドーは新品投資を減らすため、引き揚げた中古機を再活用する方針を示している
```

同時に、粗利の薄さを別の形で補う動きも出ている。

- **価格帯の再設計**：高立地は高価格（220円〜）、屋外・郊外は低価格機や100円系商材を置く二極化。
- **自販機を「メディア」として使う**：デジタルサイネージ搭載機による広告収入、
  地域の防災情報表示（災害時に無償提供するモードを持つ機種もある）。
- **飲料以外への拡張**：冷凍食品・日用品・土産物の自販機。
  こちらは台数が増加しており、工業会統計でも食品系は伸びている。
- **キャッシュレス由来のデータ**：誰がいつ何を買ったかのデータを商品企画に使う。
  ただしデータ単体で稼げるわけではなく、**あくまで補充効率の改善が本命**。

## 9. まとめ：この章を理解する3つの鍵

1. **自販機は「定価が通る自前の小売店」だった**。粗利率60%前後という他チャネルの2倍の
   厚みが、日本の飲料メーカーの利益の源泉だった。
2. **その粗利は1台あたりの固定費で食われる**。ロケーション手数料・電気代・補充人件費・
   機械償却は売れても売れなくてもかかるので、**販売本数が落ちた瞬間に赤字化する**。
   これが「稼働率で決まる装置産業」の典型である。
3. **2025〜2026年の減損ラッシュは、その装置が採算ラインを割ったことの会計上の追認**。
   各社は撤去・売却・外部委託で台数と固定費を落とし、
   **残す台は高価格・高回転の立地に集約する**方向へ動いている。

## 用語メモ

| 用語                                     | 意味                                                                                                                                                                   |
| ---------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **ベンダー（自販機オペレーター）**       | 自販機を設置し、商品の補充・集金・保守を行う事業者。メーカー直営と独立系専業がある。飲料業界で「ベンダー」と言えば自販機運営者を指し、IT業界の「供給者」の意味ではない |
| **ロケーションオーナー**                 | 自販機の設置場所を提供する人・企業。「場所と電源」を出す代わりに販売手数料を受け取る。電気代は原則オーナー負担                                                         |
| **ロケーション手数料（販売手数料）**     | ベンダーがオーナーに払う設置料。売上の10〜20%が目安の売上連動型と、月額固定型がある                                                                                    |
| **フルサービス（フルオペレーション）**   | ベンダー側が機械・商品・補充・保守をすべて負担する方式。オーナーは場所を出すだけ                                                                                       |
| **ルート営業**                           | 自販機を巡回して補充・集金・清掃を行う担当者。1人が1日20〜30台を回る。自販機コストの最大要素のひとつ                                                                   |
| **減損（減損損失）**                     | 固定資産が将来稼ぐ見込みのキャッシュに見合わなくなったとき、帳簿価額を切り下げて損失計上すること。**現金は出ていかない**が、翌期以降の減価償却費は軽くなる             |
| **希望小売価格（メーカー希望小売価格）** | メーカーが「この値段で売ってほしい」と示す価格。店頭では守られないことが多いが、**自販機では事実上そのまま売価になる**点が清涼飲料の特徴                               |
