# ③ 商品カテゴリと競争

このノートで分かること：清涼飲料を**カテゴリごとに分けて見ると、まったく別の商売**であること。
どのカテゴリが量を稼ぎ、どのカテゴリが金を稼いでいるのか。
そしてなぜ毎年1,000品も新商品が出るのか。

## 1. 結論：「清涼飲料業界」というひとつの市場は存在しない

清涼飲料をひとまとめに語ると、必ず判断を誤る。

> **お茶・コーヒー・水・炭酸・スポーツ飲料は、
> 原価構造も、単価も、ブランドの効き方も、競争相手も違う。
> 同じ工場で作り、同じトラックで運び、同じ棚に並ぶが、
> 経済的にはまったく別の5つの商売である。**

いちばん端的なのが**1リットルあたりの単価**である。
ミネラルウォーターは約102円、コーヒー飲料は約342円。**3.4倍の開きがある**。
つまり、水を1リットル売って得られる金額は、コーヒーの3分の1以下しかない。

だから「数量シェア」と「金額シェア」は一致しない。
**水は量の王者だが、金額ではコーヒーと茶に大きく負けている。**

```
【生産量シェアと販売金額シェアのねじれ（2025年）】

   生産量（数量）                    販売金額
   ─────────────                    ─────────────
   茶系飲料      24.3%   ◀────▶     コーヒー飲料等 21.0%
   ミネラルW     21.0%   ◀─┐  ┌─▶  茶系飲料      19.1%
   炭酸飲料      16.3%     │  │      炭酸飲料      18.3%
   コーヒー      13.2%   ──┘  │      ミネラルW      9.9%  ◀ 量21% → 金額10%
   果実飲料等     6.9%          │      果実飲料等     9.1%
   スポーツ等     5.8%          └──   スポーツ等     7.5%
   紅茶飲料       4.4%                 紅茶飲料       5.0%
   その他         8.0%                 その他        10.1%

   ★ 水は「量を運ばされるが金にならない」カテゴリ
   ★ コーヒーは「量は少ないが金を稼ぐ」カテゴリ
     → 自販機が減るとコーヒーが最も痛む（缶コーヒーの主戦場が自販機だから）
```

## 3. 5つのカテゴリ、5つの競争構造

| カテゴリ             | 競争の型                                           | 何で差がつくか                                   | 原料相場の効き                         | 主なチャネル                               |
| -------------------- | -------------------------------------------------- | ------------------------------------------------ | -------------------------------------- | ------------------------------------------ |
| **茶（無糖茶）**     | **寡占＋ブランド戦**。上位数ブランドで大半を占める | ブランドの記憶。味の差は小さく、指名買いがすべて | 小さい（茶葉は比較的安定）             | 全チャネル。最も分散                       |
| **コーヒー**         | **ブランド＋チャネル依存**。自販機依存度が最も高い | ブランドと容器（缶・ボトル缶・PET）              | **大きい**（生豆相場が直撃）           | 自販機・コンビニ中心                       |
| **水**               | **コモディティ競争**。ブランド力が最も効きにくい   | ほぼ価格と配荷。あとは水源のストーリー           | 中身はほぼゼロ。**容器と運賃がすべて** | スーパー・ドラッグ・EC。2Lが主戦場         |
| **炭酸**             | **強ブランドの寡占**。コーラ2社とサイダー系        | 100年単位のブランド。新規参入はほぼ不可能        | 砂糖・香料。無糖炭酸水は中身が安い     | 自販機・コンビニ・スーパー                 |
| **スポーツ／機能性** | **用途とエビデンス**。使う場面が指定されている     | 「熱中症対策」「経口補水」など**用途の指名**     | 砂糖・電解質。中程度                   | ドラッグ・コンビニ・自販機。夏に極端に集中 |

各カテゴリをもう少し分解する。

### 3.1 茶系飲料 ― 最大カテゴリ、しかし単価は低い

| 小分類         | 生産量（kl、2025年） | 前年比 | 1Lあたり単価 |
| -------------- | -------------------: | -----: | -----------: |
| 緑茶飲料       |            3,048,900 |  99.1% |      約172円 |
| むぎ茶飲料     |            1,443,200 | 100.5% |      約150円 |
| ブレンド茶飲料 |              480,000 |  97.3% |      約188円 |
| ウーロン茶飲料 |              382,300 |  97.4% |      約179円 |
| その他茶系     |              257,000 | 103.9% |      約195円 |

- **むぎ茶が伸びている**（唯一の前年超え）。ノンカフェインで家族全員が飲め、
  価格も安い。**家庭の「水がわり」需要**を取り込んでいる。
- 緑茶は微減だが依然として最大の小分類。「お〜いお茶」「綾鷹」「伊右衛門」「生茶」の4強構図で、
  **年間を通じてCMが途切れない唯一のカテゴリ**でもある。
- 単価が低い理由は明快で、**2Lの大容量が多いから**。
  家庭の常備飲料になったぶん、1Lあたりでは安くなる。

### 3.2 コーヒー飲料 ― 無糖ブラックが主役に変わった

| 小分類                             | 2023年（kl） | 2024年（kl） |  2025年（kl） | 前年比 |
| ---------------------------------- | -----------: | -----------: | ------------: | -----: |
| ミルク入り                         |    1,392,700 |    1,335,400 |     1,324,200 |  99.2% |
| **無糖ブラック**（甘味料入り含む） |    1,382,100 |    1,384,800 | **1,390,200** | 100.4% |
| コーヒー入り乳飲料                 |      113,300 |      119,600 |        90,900 |  76.0% |
| 希釈用（飲用時）                   |       19,900 |       18,100 |        37,100 | 205.0% |
| その他（微糖など）                 |      227,400 |      237,600 |       214,600 |  90.3% |

> ポイント：**2023年にはミルク入りが無糖を上回っていたが、2025年には逆転した。**
> かつての缶コーヒーは「甘い・ミルク入り・自販機で温かい」ものだった。
> いまは「無糖ブラック・PETボトル・コンビニで冷たい」に変わりつつある。
> **商品の姿が変わると、売る場所も変わる**。自販機の縮小はこの変化と連動している。

コーヒーは**原料相場の直撃を受ける唯一の大カテゴリ**でもある。
2025年は生産量が98.8%と微減なのに販売金額は113.1%と大幅増。
**生豆相場の高騰を値上げでまるごと転嫁した**結果であり、
これができたのは「コーヒーは高くても買う」という需要の硬さがあったからである。

### 3.3 ミネラルウォーター ― 量は伸びたが金にならない

- 2021年 4,154,300kl → 2024年 5,029,500kl と**3年で約2割拡大**したが、
  2025年は**4,861,900kl（96.7%）**と反落した。
  前年の猛暑・備蓄特需の反動と報じられる。
- 1Lあたり約102円。**全カテゴリで最も安い**。
  中身の原価がほぼゼロなのに利益が薄いのは、**容器と運賃しかコストがないのに価格も安いから**。
- **伸びの背景は3つ**。**①無糖・カロリーゼロ志向**（甘い飲料からの置き換え）、
  **②災害備蓄**（ローリングストック＝少し多めに買って古いものから使う備蓄法。
  2Lケースの定期購入がEC経由で定着した）、
  **③猛暑と熱中症対策**（職場での対策義務化で企業がケース単位で常備するようになった）。
- 競争構造は**最もコモディティ（均質商品）に近い**。
  PBの比率が高く、受託専業メーカー（→ [② 第6章](02_作り方と原価.md)）の主戦場でもある。

### 3.4 炭酸飲料 ― 2つの顔を持つ

| 小分類                             | 生産量（kl、2025年） |    前年比 | 販売金額（百万円） |     前年比 |
| ---------------------------------- | -------------------: | --------: | -----------------: | ---------: |
| 一般炭酸飲料（コーラ、サイダー等） |            1,639,300 |     99.0% |            376,262 | **108.1%** |
| 栄養ドリンク炭酸飲料               |              487,000 |     96.3% |            187,057 |     101.0% |
| 果汁入り炭酸飲料（果汁10%未満）    |              446,200 |    105.9% |            114,157 |     113.8% |
| プレーン炭酸水（無糖）             |              382,300 |     97.7% |             68,983 |     104.2% |
| 果汁/フレーバー入り炭酸水          |              221,000 |     89.5% |             43,229 |      98.5% |
| 果実フレーバー／着色炭酸飲料       |              224,700 | **78.6%** |             43,528 |      76.8% |

- **一般炭酸は世界的ブランドの寡占**。コーラ系は日本国内だけで戦っている商品ではなく、
  世界規模の広告投下とブランド資産がそのまま参入障壁になる。
- **プレーン炭酸水（無糖）**は、水と同じくコモディティ寄り。
  家庭用ハイボールの割り材としても伸びた（→ [ビール・酒類](../08_ビール・酒類/README.md)）。
- **栄養ドリンク炭酸**は「清涼飲料」に分類されるエナジードリンク類。
  1Lあたり約384円と、清涼飲料の中でも突出して単価が高い。
  医薬部外品のドリンク剤とは制度上まったく別物である点に注意（→ [④ 第4章](04_直近トピック_2026.md)）。

### 3.5 スポーツ飲料・機能性 ― 夏に賭けるカテゴリ

- 2025年は1,346,800kl（97.2%）。前年の猛暑特需の反動が出た。
- **需要の季節偏在が最も激しい**。7〜8月に年間需要が集中するため、
  夏の天候が外れると在庫と工場稼働の両方で損失が出る。
- 近年は「熱中症対策」という**用途の言葉**が定着し、
  職場での熱中症対策強化が2025年から義務化されたこともあって、
  **BtoB（企業が従業員用にケース購入）の比率が上がっている**。

## 4. 無糖化 ― 業界全体を貫くいちばん大きな流れ

**無糖化**は単なる流行ではなく、**カテゴリ間の資金移動**として統計に現れている。

| 事象                                 | 2023年 → 2025年の動き                                                                 |
| ------------------------------------ | ------------------------------------------------------------------------------------- |
| コーヒー：無糖ブラック vs ミルク入り | 無糖が逆転して首位に（1,382,100 → 1,390,200kl、ミルク入りは 1,392,700 → 1,324,200kl） |
| 紅茶：ストレート（無糖）             | 187,000 → **198,100kl（2025年は前年比113.7%）**。紅茶全体が減る中で唯一伸びた         |
| 紅茶：レモン／ストレート（有糖）     | レモン 235,200 → 194,900kl、有糖ストレート 109,100 → 94,400kl と明確に減少            |
| 果実飲料等                           | 2025年は前年比94.2%。**甘い飲料の代表格が最も落ちている**                             |
| ミネラルウォーター・無糖茶           | 中期的に拡大。2025年は反落したが、構成比では依然として高い                            |

```
【飲料の需要が移動した方向（過去10年の大きな流れ）】

   甘い・小容量・冷温両用          無糖・大容量・常温
   （自販機／コンビニ中心）        （スーパー・ドラッグ・EC中心）
   ┌────────────────┐            ┌────────────────┐
   │ 加糖缶コーヒー   │            │ 無糖ブラックPET  │
   │ 果汁飲料         │  ───────▶  │ ミネラルウォーター│
   │ 加糖紅茶         │            │ 無糖茶・むぎ茶   │
   │ 甘い炭酸         │            │ プレーン炭酸水   │
   └────────────────┘            └────────────────┘
        ↑ 粗利が厚い                    ↑ 粗利が薄い
        ↑ 自販機が強い                  ↑ 小売の価格競争

   ★ 需要の移動が、そのまま「粗利の厚いチャネルから薄いチャネルへの移動」
     になっている。これが業界の利益率が下がっている根本原因。
```

**特定保健用食品（トクホ）と機能性表示食品**の交代も、この流れの一部である。

| 制度                     |         2022年 |  2023年 |  2024年 |      2025年 |
| ------------------------ | -------------: | ------: | ------: | ----------: |
| 特定保健用食品（トクホ） | 48,256千ケース |  42,762 |  37,862 |  **35,744** |
| 機能性表示食品           | 80,350千ケース | 109,797 | 123,845 | **124,691** |

（全国清涼飲料連合会「清涼飲料水統計2026」）

- **トクホは国の個別審査が必要**で、費用と期間がかかる。表示できる内容は強いが重い。
- **機能性表示食品は届出制**で、事業者の責任で科学的根拠を示せば表示できる。速くて安い。
- その結果、**生産量は機能性表示食品がトクホの3.5倍**になった。
- ただし制度は厳格化の方向にあり、**2026年9月1日にGMP（適正製造規範）が完全義務化**された
  （→ [総合食品⑤](../01_総合食品/05_直近トピック_2026.md)）。飲料は錠剤・カプセルほど影響は大きくないが、
  届出情報の表示方法の改正には対応が必要になる。

## 5. ブランドの寿命と「新商品1,022品」の意味

清涼飲料は**毎年1,000品前後の新商品が出て、ほぼ同数が消えている**。

| 年         |  新商品数 |  総商品数 | 新商品比率 |
| ---------- | --------: | --------: | ---------: |
| 2021年     |     1,231 |     6,592 |      18.7% |
| 2022年     |     1,339 |     6,734 |      19.9% |
| 2023年     |     1,310 |     6,598 |      19.9% |
| 2024年     |     1,094 |     6,462 |      16.9% |
| **2025年** | **1,022** | **6,412** |  **15.9%** |

（全国清涼飲料連合会「清涼飲料水統計2026」）

総商品数がほぼ横ばいで新商品が1,000品出ているということは、
**毎年1,000品近くが棚から消えている**ということである。

なぜそんなに出すのか。理由は**棚と自販機の「面」を守るため**である。

```
【新商品を出し続ける理由 ― 面の取り合い】

  スーパーの飲料棚（イメージ）
  ┌──────────────────────────────────────┐
  │ 茶  │ 茶  │ 水  │ 水  │ 炭酸│ コーヒー│  ← 棚の総面積は増えない
  │ A社 │ B社 │ A社 │ PB  │ C社 │ A社     │
  └──────────────────────────────────────┘
        ▲
        └ 年2回の棚替えで、各社が「新商品」を持って面の取り合いをする

  自販機のコラム（1台あたり25〜40種）
  ┌───┬───┬───┬───┬───┬───┬───┬───┐
  │定番│定番│定番│新 │定番│新 │定番│定番│  ← 入る枠は固定
  └───┴───┴───┴───┴───┴───┴───┴───┘

  ・新商品を出さないと「提案する理由」がなくなり、面が削られる
  ・出した新商品の多くは1年以内に消えるが、その間に面を守れる
  ・利益を稼いでいるのは、実際には何十年も続く定番ブランド
```

これは総合食品と同じ論理だが（→ [総合食品③](../01_総合食品/03_商品開発とブランド.md)）、
清涼飲料には**固有の事情**が2つある。

1. **自販機という自社の棚がある**。自販機のコラム（商品を並べる列）は1台25〜40種ほど。
   ここに何を入れるかを**自社で決められる**ので、新商品を試す場として機能してきた。
   自販機が減ることは、**新商品のテスト場が減ること**でもある。
2. **味の差別化余地が小さい**。無糖茶や水では、中身で差をつけるのが難しい。
   結果として、**パッケージ・容量・キャンペーン・広告タレント**が競争の主戦場になる。
   伊藤園が「お〜いお茶」の広告に米大リーグの大谷翔平選手を起用して
   国内外の販売を伸ばしたのは、この構造を示す典型例である（報道ベース）。

## 7. 水市場と災害備蓄 ― 「飲料」から「備蓄物資」へ

ミネラルウォーターには、他のカテゴリにない性質がある。
**賞味期限が長く（2年前後）、災害時に必需品になる**ことである。

| 需要の種類                         | 中身                               | 経済的な特徴                                               |
| ---------------------------------- | ---------------------------------- | ---------------------------------------------------------- |
| 日常の飲用                         | 500ml・2Lの日常購入                | 価格競争が激しい。PB比率が高い                             |
| **ローリングストック（家庭備蓄）** | 多めに買って古いものから使う備蓄法 | **ケース単位・定期購入**になりやすく、ECと相性が良い       |
| 自治体・企業の備蓄                 | 防災備蓄、熱中症対策の常備         | **入札・法人契約**。数量が大きく安定するが、単価は最も安い |
| 災害発生時の緊急需要               | 断水地域への供給                   | 突発的で予測不能。工場が被災すれば供給側も止まる           |

- 2024年にミネラルウォーター類が5,029,500kl（前年比104.1%）まで伸びたのは、
  猛暑と備蓄需要の重なりが大きかったとされ、
  2025年はその反動で4,861,900kl（96.7%）に落ちた。
  **「備蓄需要は積み上がった翌年に反動が出る」**という周期性がある。
- 水は**輸送費が売価に占める比率が最も高い**ため、災害時には
  「作れるが運べない」という事態が起きやすい。
  各社が全国に採水地と工場を分散させているのは、備蓄需要への対応でもある。

## 8. まとめ：この章を理解する3つの鍵

1. **数量シェアと金額シェアがねじれている**。水は量の21%だが金額の10%、
   コーヒーは量の13%だが金額の21%（2025年）。
   **どのカテゴリが伸びるかで、業界全体の利益が変わる**。
2. **無糖化は「粗利の薄いほうへの移動」でもある**。
   甘い小容量（自販機・コンビニ）から、無糖の大容量（スーパー・ドラッグ・EC）へ需要が移り、
   それがそのまま利益率の低下につながっている。
3. **競争のルールがカテゴリごとに違う**。炭酸はブランドの寡占、
   茶はブランドと広告、水は価格と物流、コーヒーは相場と自販機、
   スポーツは用途と天候。**ひとつの戦略ですべては戦えない**。

## 用語メモ

| 用語                           | 意味                                                                                                                                   |
| ------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------- |
| **清涼飲料水**                 | アルコール分1%未満の飲料のうち、乳製品・乳酸菌飲料などを除いたもの。食品衛生法上の分類で、酒類・医薬部外品のドリンク剤とは別扱いになる |
| **コラム（自販機）**           | 自販機の中で商品を並べる列のこと。1台あたり25〜40種前後。ここに入る／入らないが売上を左右する                                          |
| **棚替え（たなかえ）**         | 小売が売場の商品構成を見直すこと。春・秋の年2回が一般的で、新商品の生死と棚の面積がここで決まる                                        |
| **特定保健用食品（トクホ）**   | 国が個別に審査・許可した保健機能食品。審査に費用と時間がかかる。清涼飲料での生産量は2022年以降減少が続く                               |
| **機能性表示食品**             | 事業者が科学的根拠を届け出れば機能を表示できる制度（2015年開始）。トクホより速く安いため急増した。2026年9月1日にGMP義務化が完全施行    |
| **ローリングストック**         | 備蓄品を少し多めに買い、古いものから使って買い足す備蓄法。ミネラルウォーターの定期購入需要の柱                                         |
| **PB（プライベートブランド）** | 小売が自社ブランドで売る商品。飲料では受託専業メーカーが製造する。水・無糖茶・炭酸水でとくに比率が高い                                 |
| **コモディティ（均質商品）**   | 中身で差がつきにくく、価格で選ばれる商品。飲料ではミネラルウォーターとプレーン炭酸水が代表                                             |
