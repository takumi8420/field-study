## このフォルダの読み方

清涼飲料は、食品業界の中で**ただ一つ「自前の小売店」を持っていた業界**である。
それが自動販売機で、メーカーが直接設置し、直接補充し、
**希望小売価格がそのまま売価になる**という、日本独自のチャネルだった。
粗利率は60%前後と店頭の2倍以上あり、ここで稼いだ利益が業界全体を支えてきた。

その装置がいま、採算ラインを割っている。
2025〜2026年にコカ・コーラ ボトラーズジャパン（881億円）、ダイドー（298億円）、
伊藤園（136億円）が自販機資産の減損を計上し、ポッカサッポロは事業そのものを売却した。
一方で商品そのものは、**中身より容器のほうが高い**という独特の原価構造を持ち、
**PET樹脂・段ボール・運賃**が値段を決めている。

このフォルダは、**基礎は [総合食品](../01_総合食品/README.md) に委譲**し、
清涼飲料に固有の3つの論点――**自販機・容器と原価・カテゴリ別の競争**――を掘り下げる。

## 1. 業界の定義・範囲

**清涼飲料**＝ **アルコール分1%未満の飲料**のうち、乳製品や乳酸菌飲料などを除いたもの。
食品衛生法上の「清涼飲料水」という分類が土台になっている。

```
【「飲みもの」の中での清涼飲料の位置】

  アルコール分 1% 以上 ──────▶ 酒類（酒税法）
                               ビール・チューハイ・ワイン
                               → [ビール・酒類](../08_ビール・酒類/README.md)

  アルコール分 1% 未満
   ├─ ★清涼飲料水★（本フォルダ）
   │    茶・コーヒー・炭酸・ミネラルウォーター・果実飲料
   │    スポーツ飲料・紅茶・野菜飲料・豆乳 など
   │
   ├─ 乳製品・乳飲料（乳等省令）
   │    牛乳、加工乳、乳酸菌飲料 → [乳業](../04_乳業/README.md)
   │
   └─ 医薬部外品のドリンク剤
        リポビタンD等の「栄養ドリンク」
        ※ 缶入りエナジードリンクは清涼飲料水、
          瓶入りドリンク剤は医薬部外品。見た目が似ていても制度がまったく違う
          （消費税率まで別になる → [④ 第4章](04_直近トピック_2026.md)）

  ※ 外食・カフェで淹れる飲料は「外食」であり本フォルダの対象外。
    ただし缶・PETコーヒーの最大の競合である
```

境界の引き方で押さえるべき点。

- **自販機は清涼飲料業界の一部として語られる**。
  台数の統計は日本自動販売システム機械工業会（JVMA）が出すが、
  経営上は飲料メーカーの販売チャネルそのものである。
- **ボトラーとメーカーは別会社のことがある**。
  日本コカ・コーラ（原液供給とブランド）とコカ・コーラ ボトラーズジャパン（製造・販売）は
  役割も損益の形も違う（→ [② 第6章](02_作り方と原価.md)）。
- **受託製造専業も業界の一員**。ブランドを持たずPBを作る会社が、
  国内生産の3割を担っている（委託製造比率30.1%、2025年）。

成長性の読み方。

- **数量はすでに頭打ち**。2021〜2024年は年1〜3%ずつ伸びていたが、
  2025年に**5年ぶりの前年割れ（▲2.1%）**となった。
  値上げによる買い控えと、前年の猛暑・備蓄特需の反動が重なった。
- **金額は過去最高**。値上げで単価が上がったため。
  **数量を落として単価を取る局面**に入っている。
- **構造的な上限は人口と「1日に飲む量」**。1人あたり年間187.5リットル＝1日514mlは、
  生活の中でこれ以上大きく増える余地が乏しい水準である。
- 伸びしろは **①海外（緑茶・日本ブランド）、②業務用・BtoB（熱中症対策の常備）、
  ③高単価カテゴリ（無糖ブラック、機能性）**の3方向に限られる。

## 3. バリューチェーン（川上 → 川下）

```
【モノ・カネの流れ ― 2つのルートが並走している】

  原料              製造                      販売
 ─────────────────────────────────────────────────────────▶

 茶葉・生豆   ┐                    ┌──▶ 自販機（メーカー直販）──▶ 消費者
 砂糖・果汁   ├─▶ 飲料メーカー ────┤     ★売価=希望小売価格。粗利60%前後
 水源         │   ボトラー          │
              │   受託工場(30.1%)   └──▶ 卸 ──▶ 小売 ──▶ 消費者
 PET樹脂      │                              スーパー/CVS/ドラッグ/EC
 キャップ     ┘                              ★売価は小売が決める。粗利20〜30%
 段ボール
   ▲
   └ 原価の最大費目。原油・紙パルプ・為替に連動

 ★ この「2本立て」が清涼飲料の最大の特徴。
   上のルートが縮むと、下のルートで数量を増やしても利益は戻らない
```

付加価値がどこに集まるか。

| 段階                                         | 粗利率の目安 | 特徴                                         |
| -------------------------------------------- | ------------ | -------------------------------------------- |
| 原液供給・ブランド保有（日本コカ・コーラ型） | 非常に高い   | 設備を持たず、原液とロイヤリティで稼ぐ       |
| ブランドメーカー（サントリー・伊藤園等）     | 30〜40%      | ブランドと商品開発で稼ぐが、広告・販促が重い |
| ボトラー・受託工場                           | 10〜20%      | 設備と物流を抱える。**稼働率がすべて**       |
| **自販機チャネル（メーカー直販）**           | **50〜60%**  | 定価が通る。ただし1台ごとの固定費が重い      |
| 店頭チャネル（卸・小売経由）                 | 20〜30%      | 特売・リベート・センターフィーで削られる     |

> ポイント：**粗利がいちばん厚いのは自販機。しかし固定費もいちばん重い。**
> 販売本数が損益分岐（月700〜800本前後が目安）を割ると、
> 粗利60%の装置が一気に赤字装置に変わる。これが2025〜2026年の減損ラッシュの正体である
> （→ [① 自販機という装置](01_自販機という装置.md)）。

**シェアの見方**：清涼飲料でも「業界全体のシェア」はあまり意味を持たない。
炭酸はコカ・コーラ系が圧倒的、紅茶はキリン、緑茶は伊藤園とコカ・コーラとサントリー、
水はPBを含む乱戦――と**カテゴリごとに勢力図が違う**。
シェアを語るときは必ずカテゴリを限定する（→ [③ 商品カテゴリと競争](03_商品カテゴリと競争.md)）。

## 5. 収益モデル・コスト構造

```
【500ml PET 飲料 1本の原価イメージ（無糖茶の目安）】

  メーカー出荷価格（店頭チャネル向け） おおむね 70〜90円
   ├─ 容器関連        20〜28円  ◀★最大。PET・キャップ・ラベル・段ボール
   ├─ 中身（原料）     4〜15円   ◀水なら1〜3円、コーヒーなら20〜35円
   ├─ 製造費          8〜15円
   ├─ 物流費          8〜15円   ◀重くて安いので比率が高い
   ├─ 販促・広告・営業 10〜20円
   └─ 利益            3〜8円

  ※ 同じ1本を自販機で売れば売価180〜220円。原価は同じなので粗利が2倍以上になる
```

| 収益・コストの論点           | 中身                                                                                                  |
| ---------------------------- | ----------------------------------------------------------------------------------------------------- |
| **チャネルで利益が2倍違う**  | 自販機（粗利50〜60%）と店頭（20〜30%）。**どこで売れたかで損益が変わる**のが清涼飲料の最大の特徴      |
| **中身より容器が高い**       | 水・無糖茶では容器関連が原価の最大費目。原油・樹脂・紙パルプ・為替に連動する                          |
| **重くて安い＝物流費が重い** | 500ml 1本が約0.52kg。採算が合うのは工場から200〜300km圏とされ、**全国の工場網が参入障壁**になる       |
| **自販機は固定費の塊**       | ロケーション手数料（売上の10〜20%）、電気代、ルート人件費、機械償却。**月700〜800本が損益分岐の目安** |
| **季節変動が極端**           | 7〜8月に需要が集中。ピークに合わせた設備は冬に遊ぶので、**委託製造（30.1%）で吸収する**               |
| **値上げの効き方が非対称**   | 自販機は定価が通るので値上げしやすいが、通すほど店頭との価格差が開いて客を失う                        |

詳しくは [① 自販機という装置](01_自販機という装置.md)、[② 作り方と原価](02_作り方と原価.md)。

## 6. 競争要因（KSF）と参入障壁

| KSF                          | 中身                                                                                     |
| ---------------------------- | ---------------------------------------------------------------------------------------- |
| **ブランド（指名買い）**     | 味の差が小さい無糖茶・水ほど、ブランドの記憶が勝敗を決める。数十年の広告投資が資産になる |
| **配荷力（どこに置けるか）** | 棚と自販機のコラムをいくつ取れるか。**新商品を毎年1,000品出すのは面を守るため**          |
| **全国の生産網**             | 重くて安いので、消費地の近くで作れないと運賃で負ける。工場配置がそのまま競争範囲になる   |
| **充填技術**                 | 無菌充填ラインを持つかどうかで、作れる商品と使えるボトルの軽さが変わる                   |
| **原料調達力**               | コーヒー生豆・濃縮果汁・茶葉。相場変動を吸収する購買体制                                 |
| **自販機網の運営力**         | かつては最大のKSFだったが、**いまは「どれだけ賢く減らせるか」に変わった**                |

**参入障壁**は免許ではない（清涼飲料の製造は営業許可とHACCP対応で足りる）。
実質的な障壁は **①全国の工場と物流網、②棚と自販機の面を取り続ける販促費、
③数十年かけたブランド**の3つ。
ただし**低価格PB専業という抜け道**は存在し、
ブランド投資も自販機も持たない会社が、容器と物流だけの原価で参入している。
これが水・無糖茶・炭酸水の価格を押し下げ続けている。

## 7. 規制・法制度

| 制度                                 | 内容                                                                                                                                        | 清涼飲料への影響                                                                              |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| **食品衛生法／清涼飲料水の規格基準** | 殺菌・製造基準。2021年6月からHACCPに沿った衛生管理が原則義務                                                                                | 充填ラインの無菌管理・記録が必須。小規模事業者には設備負担                                    |
| **食品表示法**                       | 原材料名、アレルゲン、栄養成分、原料原産地の表示                                                                                            | 表示誤りは自主回収に直結。ラベル変更のリードタイムが値上げ実務を縛る                          |
| **機能性表示食品制度**               | 2015年開始の届出制。2024年9月に健康被害の報告義務化、**2026年9月1日にGMP義務化が完全施行**、届出情報の表示方法も改正                        | 清涼飲料の機能性表示食品は生産量ベースでトクホの3.5倍（2025年）。制度運用の厳格化に対応が必要 |
| **特定保健用食品（トクホ）**         | 国の個別審査・許可制                                                                                                                        | 審査負担が重く、清涼飲料での生産量は2022年以降減少が続く                                      |
| **容器包装リサイクル法**             | 特定事業者に再商品化の義務                                                                                                                  | 再生材の落札価格高騰が**そのまま原価上昇**になる                                              |
| **プラスチック資源循環促進法**       | 使用の合理化と再資源化                                                                                                                      | 軽量化（リデュース率28.4%、2023年度）とボトルtoボトル（2030年50%以上目標）の推進              |
| **景品表示法**                       | 優良誤認・有利誤認の禁止                                                                                                                    | 「無糖」「ゼロ」「機能性」の表示の根拠                                                        |
| **軽減税率／飲食料品の消費税引下げ** | 2026年9月15日の閣議決定により、**2027年4月1日〜2029年3月31日の2年間、飲食料品の消費税率を8%→1%**とする方針（2026年9月時点で法改正は未成立） | 清涼飲料は対象。**医薬部外品のドリンク剤は10%のまま**で、似た商品で税率が9ポイント違う事態に  |
| **改正物流効率化法**                 | 2026年4月に特定事業者の指定・CLO選任義務が施行                                                                                              | 重量物を大量に動かす飲料メーカーは典型的な該当荷主                                            |
| **労働安全衛生規則（熱中症対策）**   | 職場での熱中症対策が義務化                                                                                                                  | 企業がケース単位で飲料を常備する**BtoB需要の追い風**になっている                              |

## 8. 最近のトピック

詳細は → [④ 直近トピック（2026年9月時点）](04_直近トピック_2026.md)

1. **2025年は生産量が5年ぶりに減少（▲2.1%）、販売金額は過去最高（4兆9,825億円、+5.3%）**。
   値上げで金額を作り、数量を失った典型的な年になった。
2. **自販機の減損ラッシュ**。コカ・コーラBJH 881億円、ダイドー 298億円、伊藤園 135.9億円。
   ポッカサッポロは約4万台の自販機事業をライフドリンクカンパニーへ売却した。
3. **500ml PETが税別220円へ**。コカ・コーラ ボトラーズジャパンが2026年9月1日出荷分から
   希望小売価格を3.2〜18.7%改定、サントリーも10〜11月出荷分から追随した。
4. **2027年4月から飲食料品の消費税が1%へ**（2026年9月15日閣議決定、法改正は未成立）。
   値上げの「窓」になるが、2029年4月の税率復帰時の反動という出口の問題も抱える。
5. **PET資源循環の第2段階**。リサイクル率85.1%（2024年度推計）は達成済みで、
   論点はボトルtoボトル比率（2023年33.7%、2030年50%以上目標）と
   **再生材の価格高騰**に移った。

## 9. 用語メモ

各ノート末尾に詳しい用語メモがある。ここでは最重要の7つだけ。

| 用語                                   | 意味                                                                                                                                       |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| **ベンダー（自販機オペレーター）**     | 自販機を設置し、補充・集金・保守を行う事業者。メーカー直営と独立系専業がある → [①](01_自販機という装置.md)                                 |
| **ロケーション手数料**                 | 自販機の設置場所の持ち主に払う販売手数料。売上の10〜20%が目安。電気代は原則オーナー負担 → [①](01_自販機という装置.md)                      |
| **減損（減損損失）**                   | 固定資産の帳簿価額を将来の稼ぐ力に合わせて切り下げる処理。**現金は出ていかない**が、翌期以降の償却は軽くなる → [①](01_自販機という装置.md) |
| **ボトラー**                           | ブランド元から原液（コンセントレート）の供給を受け、自社工場で製品化して担当地域で販売する会社 → [②](02_作り方と原価.md)                   |
| **無菌充填（アセプティック充填）**     | 中身を冷ましてから無菌環境で常温充填する方式。香味が残り、薄く軽いボトルが使えるが設備投資が重い → [②](02_作り方と原価.md)                 |
| **委託製造（受託・パッカー）**         | 他社ブランドや小売PBの飲料を作る専業工場。2025年の委託製造比率は30.1% → [②](02_作り方と原価.md)                                            |
| **ボトル to ボトル（水平リサイクル）** | 使用済みPETを再びPETボトルに戻すこと。2023年で33.7%、2030年に50%以上が業界目標 → [②](02_作り方と原価.md)                                   |
