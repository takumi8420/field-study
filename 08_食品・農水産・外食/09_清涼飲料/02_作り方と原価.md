# ② 作り方と原価

このノートで分かること：ペットボトル飲料1本の原価が**何でできているか**、
なぜ「中身より容器のほうが高い」という逆転が起きるのか、
そして誰がどこで作っているのか（自社工場・ボトラー・受託）。

## 1. 結論：清涼飲料は「水を詰める商売」ではなく「容器と物流の商売」である

清涼飲料の原価を分解すると、多くの人の直感とは逆の姿が出てくる。

> **ミネラルウォーターや無糖茶では、中身（水・茶葉抽出液）の原価より、
> 容器（PETボトル・キャップ・ラベル）の原価のほうが高い。
> さらに、出荷してから店に届くまでの物流費が、中身の原価を上回ることすらある。**

なぜそうなるのか。**飲料は重くてかさばるのに、単価が安い**からである。
**「単位重量あたりの売上」が極端に低い商品**なので、物流費の比率が高くなる。

```
【清涼飲料が他の食品と違う3つの物理的制約】

  ① 重い      500ml PET 1本 ≈ 0.52kg。中身の比重がほぼ水そのもの
  ② かさばる  段ボール1ケース(24本) ≈ 12.5kg・約0.03㎥
  ③ 安い      1本あたりのメーカー出荷額は数十円

  ⇒ 「重量あたり・容積あたりの売上」が食品の中でも最低クラス
  ⇒ 工場は消費地の近くに置かざるを得ない（遠くへ運ぶと赤字）
  ⇒ 全国に工場網を持てるかどうかが、そのまま参入障壁になる
```

この「重くて安い」という性質が、
工場配置・委託生産・容器の軽量化・値上げのタイミングまで、すべてを規定している。

## 2. 500ml PET 1本の原価イメージ

以下は公開情報と業界慣行からの**目安の試算**であり、カテゴリ・数量・年によって大きく動く。
断定的な数字ではなく「どの費目が大きいか」を掴むための図と考えてほしい。

```
【500ml PET 飲料 1本の原価構成（無糖茶を例にした目安）】

  メーカー出荷価格（店頭チャネル向け）  おおむね 70〜90円
  ┌──────────────────────────────────────────┐
  │ 容器関連          20〜28円                  │ ◀★ここが最大
  │   ・PETプリフォーム（ボトルのもと）12〜18円 │
  │   ・キャップ                 2〜3円        │
  │   ・ラベル                   1〜2円        │
  │   ・段ボール・仕切り          3〜5円        │
  ├──────────────────────────────────────────┤
  │ 中身（原料）       4〜15円                  │
  │   ・水・茶葉／果汁／コーヒー豆／砂糖         │
  │     ※ミネラルウォーターなら 1〜3円          │
  │     ※果汁100%・コーヒーなら 20〜35円に跳ねる │
  ├──────────────────────────────────────────┤
  │ 製造費            8〜15円                   │
  │   ・充填ラインの減価償却、電力、工場人件費   │
  ├──────────────────────────────────────────┤
  │ 物流費            8〜15円                   │
  │   ・工場→倉庫→卸センター→店舗             │
  ├──────────────────────────────────────────┤
  │ 販促・広告・営業   10〜20円                 │
  ├──────────────────────────────────────────┤
  │ 利益               3〜8円                   │
  └──────────────────────────────────────────┘

  ※ 自販機チャネルでは売価が180〜220円になるため、
    同じ原価で粗利が2倍以上になる → [① 自販機という装置](01_自販機という装置.md)
```

ここから読み取るべきこと。

- **水やお茶では、容器が原価の最大費目になる**。だから「中身より容器が高い」。
- **コーヒー・果汁100%では逆転する**。コーヒー生豆や濃縮果汁は相場商品で、
  高騰局面では中身が原価の半分近くを占める（→ 第5章）。
- **原油が上がるとPET樹脂が上がる**。PETはテレフタル酸とエチレングリコールから作られ、
  いずれも石油化学製品なので、原油と為替の両方に連動する
  （→ [石油化学](../../10_素材・化学/02_石油化学/README.md)）。
- **段ボールが意外に重い**。紙パルプ相場と連動し、値上げが直接効く
  （→ [紙・パルプ](../../10_素材・化学/09_紙・パルプ/README.md)）。

## 3. 容器 ― PETボトル・缶・紙のすみ分け

2025年の容器別生産量は次のとおり。**PETボトルが8割**という圧倒的な偏りがある。

| 容器                             | 生産量（kl）   | 構成比    | 主な用途                     | 経済的な特徴                                                 |
| -------------------------------- | -------------- | --------- | ---------------------------- | ------------------------------------------------------------ |
| **PETボトル**                    | 17,854,925     | **80.1%** | 茶・水・炭酸・スポーツ       | 軽い、再栓できる、透明。自社成形できるため内製化が進んだ     |
| 缶（スチール・アルミ）           | 2,017,071      | 9.0%      | コーヒー、炭酸、栄養ドリンク | 遮光性・耐圧性に優れる。自販機との相性が良いが、再栓できない |
| 紙容器                           | 1,570,251      | 7.0%      | 乳飲料、果汁、野菜飲料       | 冷蔵前提が多く、量販店中心                                   |
| その他（パウチ、チルドカップ等） | 689,269        | 3.1%      | ゼリー飲料、カップコーヒー   | コンビニの成長とともに伸びた                                 |
| びん                             | 171,753        | 0.8%      | 一部の炭酸・栄養ドリンク     | 重くて運賃がかかる。ほぼ業務用と一部ブランドのみ             |
| **計**                           | **22,303,270** | 100%      | —                            | ※シロップ類を除く                                            |

（2025年。全国清涼飲料連合会「清涼飲料水統計2026」）

PETボトルの中身をさらに分けると、**中型（400〜699ml）が圧倒的**であることが分かる。

| PETボトルの容量区分    | 生産量（kl）   | 位置づけ                                                                                       |
| ---------------------- | -------------- | ---------------------------------------------------------------------------------------------- |
| 小型（1〜399ml）       | 750,909        | コンビニ・自販機の少量ニーズ。単価は高いが量は小さい                                           |
| **中型（400〜699ml）** | **12,934,628** | いわゆる500ml。**清涼飲料の主戦場**。※ミネラルウォーターは容量別データがないため全量ここに計上 |
| 大型（700ml以上）      | 4,169,388      | 2L・1.5Lなど家庭用。1本あたり単価は最も安く、価格競争が最も激しい                              |

> ポイント：**容量が変わると商売が変わる。**
> 500mlは「その場で飲む」需要なので価格が通りやすく、自販機・コンビニが主戦場。
> 2Lは「家に置く」需要で、完全にスーパー・ドラッグの価格競争になる。
> **同じ会社の同じブランドでも、500mlと2Lでは利益率が2倍以上違う**ことがある。

### 軽量化 ― 静かに続いてきたコストダウン

PETボトルは長年、**薄く・軽く**され続けてきた。理由は3つで、
**①樹脂を減らせば原価が下がる**（最大の費目なので効きが大きい）、
**②軽くなれば運賃が下がる**（重量課金の物流では直接効く）、
**③プラスチック使用量の削減目標に応えられる**。

PETボトルリサイクル推進協議会によれば、**リデュース率（軽量化率）は2023年度で28.4%**。
2004年度を基準に、ボトル1本あたりの樹脂使用量が約3割減ったという意味である。
ただし軽量化には限界がある。薄くしすぎると輸送中に潰れ、炭酸には耐圧が要るため薄くできない。
**「炭酸のボトルは無糖茶のボトルより厚くて重い」**のはこのためで、
同じ500mlでも原価が違う。

## 4. 充填ライン ― ホットパックと無菌充填

飲料工場の中核は**充填（じゅうてん）ライン**、つまり「殺菌した中身を容器に詰める設備」である。
方式は大きく2つあり、**どちらを持っているかで作れる商品と原価が変わる**。

| 方式                               | やり方                                                                 | ボトル・キャップ                                         | 味への影響                                 | 設備投資                             |
| ---------------------------------- | ---------------------------------------------------------------------- | -------------------------------------------------------- | ------------------------------------------ | ------------------------------------ |
| **ホットパック（高温充填）**       | 中身を85〜90℃前後まで加熱殺菌し、**熱いまま詰めて**冷却する            | 熱に耐える必要があるため**厚く重いボトル**＋耐熱キャップ | 熱による香味・ビタミンの劣化が出やすい     | 比較的安い。古くからある方式         |
| **無菌充填（アセプティック充填）** | 中身を短時間で殺菌して**冷ましてから**、無菌環境で**常温のまま詰める** | 耐熱性が不要なので**薄く軽いボトル**が使える             | 加熱ダメージが小さく、**香りと風味が残る** | 高い。クリーンルームと無菌管理が必要 |

**無菌充填（アセプティック充填）**＝ ボトル・キャップ・中身・充填室のすべてを無菌状態にして、
常温で詰める方式。「後から加熱しない」ので、熱に弱い成分を守れる。

```
【2つの充填方式の流れ】

 ホットパック
  原料調合 ─▶ 加熱殺菌(90℃前後) ─▶ 熱いまま充填 ─▶ キャップ ─▶ 冷却
                                    ▲
                            耐熱ボトル（厚い＝樹脂が多い）が必須

 無菌充填（アセプティック）
  原料調合 ─▶ 超高温短時間殺菌 ─▶ 冷却 ─┐
                                        ├─▶ 無菌室で常温充填 ─▶ キャップ
  ボトル成形 ─▶ ボトル・キャップを殺菌 ─┘
                                    ▲
                   軽量ボトルが使える＝樹脂代と運賃が下がる
                   ただし工場側の無菌管理コストは重い
```

> ポイント：**無菌充填は「設備投資が重いが、ボトル代と味で勝てる」方式。**
> 緑茶・紅茶・ミルクコーヒーなど**熱に弱い商品ほど無菌充填が必要**になる。
> つまり **無糖茶が伸びるほど、無菌ラインを持つ会社が有利になる**という関係がある。
> 逆に炭酸飲料は常温・耐圧充填という別のラインが要るので、
> **カテゴリを増やすほど工場に必要なライン種類が増え、固定費が重くなる**。

もうひとつ知っておくべき事実がある。
**開栓前のペットボトルで液面の高さが違う**のは、この方式の違いによる。
ホットパックは冷却時に内部が減圧されてボトルがへこむため液面が高く見え、
無菌充填は充填時のままなのでキャップの下に液面が見える。

## 5. 中身の原料 ― 4つの相場

清涼飲料の原料は、価格の決まり方で大きく4群に分かれる。

| 原料                 | 主な使い道               | 価格の決まり方                                                       | 2025〜2026年の状況                                                                                  |
| -------------------- | ------------------------ | -------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| **コーヒー生豆**     | 缶・PETコーヒー          | ニューヨーク（アラビカ）・ロンドン（ロブスタ）の先物＋海上運賃＋為替 | 2025年2月に史上最高値圏（400セント/lb超）。2026年は需給緩和へ向かうが**高止まり見通し**と報じられる |
| **砂糖・異性化糖**   | 炭酸、スポーツ、果汁入り | 国際糖価＋国内の調整金制度（砂糖の価格調整制度）                     | 国内価格は制度で緩衝されるが、無糖化の進行で使用量自体が減少                                        |
| **果汁（濃縮果汁）** | 果実飲料                 | オレンジ・りんご等の産地作柄と為替。とくにオレンジは不作が長期化     | 果実飲料等の生産量は2025年に**前年比94.2%**と大きく減少。原価高で数量が落ちた典型                   |
| **茶葉**             | 緑茶・麦茶・烏龍茶       | 国内茶産地の入札（一番茶・二番茶）＋輸入茶葉                         | 相対的に安定。緑茶飲料は**1Lあたり172円**前後の単価で、水より高くコーヒーより安い                   |

（相場は報道ベース。数値は全国清涼飲料連合会「清涼飲料水統計2026」と各種報道から）

> ポイント：**原料相場の影響度はカテゴリで全く違う。**
> ミネラルウォーターは中身がほぼタダなので相場に強く、
> コーヒーは中身が原価の半分近くを占めるので相場に弱い。
> 2025年にコーヒー飲料等の**生産量は98.8%（微減）なのに販売金額は113.1%（大幅増）**
> になったのは、相場高を値上げで転嫁した結果である。
> （カテゴリ別の詳細 → [③ 商品カテゴリと競争](03_商品カテゴリと競争.md)）

## 6. 誰が作っているのか ― ボトラーと受託製造

清涼飲料は「ブランドを持つ会社」と「実際に作る会社」が分かれていることが多い。
これは他の食品カテゴリと比べても際立った特徴である。

### 6.1 ボトラー制度（コカ・コーラ方式）

**ボトラー**＝ ブランド元から**原液（コンセントレート）**の供給を受け、
自社の工場で水・糖類と混ぜて製造し、決められた地域で販売する会社のこと。

```
【コカ・コーラシステムの役割分担】

  ザ コカ・コーラ カンパニー（米国本社）
        │ 原液のレシピ・ブランドの所有
        ▼
  日本コカ・コーラ株式会社
        │ ・原液（コンセントレート）の製造・供給
        │ ・ブランド戦略、新商品開発、広告
        ▼ 原液を販売
  ボトラー（コカ・コーラ ボトラーズジャパン ほか）
        │ ・原液に水と糖類を加えて製品化
        │ ・容器の成形・充填・箱詰め
        │ ・担当エリアでの営業・自販機の運営・配送
        ▼
  自販機／コンビニ／スーパー／飲食店

  ※ 利益の取り方が違う：
     日本コカ・コーラ = 原液販売＋ロイヤリティ（設備を持たない高収益モデル）
     ボトラー         = 製造・物流・自販機を抱える（固定費の重い低利益率モデル）
     → 同じ「コカ・コーラ」でも、儲け方と決算の形が全く違う
```

日本ではかつて地域ごとに十数社のボトラーが存在したが、統合が進み、
現在は**コカ・コーラ ボトラーズジャパン**が国内の大半をカバーしている。
自販機の減損（→ [①](01_自販機という装置.md) 第7章）が
ボトラー側の決算に出たのも、**設備と販売網を持つのがボトラーだから**である。

### 6.2 受託製造（OEM・パッカー）

ボトラー制度とは別に、**受託製造（パッカー）**も大きな役割を果たしている。
ブランドを持たず、他社の商品や小売のPB（プライベートブランド）を作る専業の工場である。

全国清涼飲料連合会の統計によれば、**委託製造の比率は2025年で30.1%**。
つまり**清涼飲料の3本に1本は、ブランドを持つ会社以外の工場で作られている**。

| 年         | 自社（グループ）製造 | 委託製造  |
| ---------- | -------------------- | --------- |
| 2021年     | 71.0%                | 29.0%     |
| 2022年     | 70.3%                | 29.7%     |
| 2023年     | 71.5%                | 28.5%     |
| 2024年     | 71.9%                | 28.1%     |
| **2025年** | **69.9%**            | **30.1%** |

（全国清涼飲料連合会「清涼飲料水統計2026」）

委託が使われる理由は3つ。**①季節変動を吸収するため**（夏のピークに合わせて自社設備を作ると
冬は遊ぶので、ピーク分だけ外に出すほうが安い）、**②地域をカバーするため**（重くて運べないので、
遠隔地は現地工場に任せたほうが運賃が安い）、**③PBを作るため**（スーパー・ドラッグストア・
コンビニのPB飲料は、ほぼすべて受託専業メーカーが作っている
→ [総合食品② 第6章](../01_総合食品/02_値決めと交渉.md)）。

> ポイント：**受託専業の存在が、低価格PBを可能にしている。**
> ブランド投資も自販機網も持たない会社が作れば、原価は容器と中身と物流だけで済む。
> だから2Lの水が1本60〜80円で売れる。
> 2026年にポッカサッポロの自販機事業を買ったライフドリンクカンパニーは
> この低価格帯の代表格であり、**「安く作る側」が「高く売る装置」を買った**という構図になる。

## 7. 物流 ― 工場をどこに置くかがすべて

飲料は重いので、**工場から遠いほど赤字に近づく**。
一般に「陸送で採算が合うのは工場から200〜300km圏」と言われ、
これが各社が全国に複数工場を持つ理由になっている。

```
【物流の流れとコストの乗り方】

  工場 ──▶ メーカー倉庫 ──▶ 卸のセンター ──▶ 店舗 / 自販機
             保管費        センターフィー     ルート配送
            （夏在庫）     （小売に支払う）  （自販機は特に高い）

  ★ 夏のピークが最大の制約
     7〜8月の需要は冬の1.5〜2倍。ピークに合わせて工場を作ると冬は遊び、
     トラックを確保しようとすると運賃が高騰する
     → だから「委託製造」と「事前の在庫積み上げ」で吸収する
```

近年のコスト上昇要因は3つ。**2024年問題（ドライバーの時間外労働規制）**以降、
重量物である飲料は同じ運賃でも積める数量が少ないため影響が大きい
（→ [陸運・トラック](../../13_運輸・物流/06_陸運・トラック/README.md)）。
**改正物流効率化法**により2026年4月から大手荷主にCLO（物流統括管理者）選任が義務づけられ、
飲料メーカーは典型的な該当荷主になった。加えて**センターフィー**（小売の物流センター利用料）の
負担も続く（→ [食品卸② 物流という本体](../../06_商社・卸売/06_食品卸/02_物流という本体.md)）。

## 8. リサイクルPET ― コストと制約が同時に増える

日本のPETボトルは**回収率・リサイクル率とも世界的に高い**。
PETボトルリサイクル推進協議会によれば、**2024年度のリサイクル率は85.1%（推計）**、
2023年度は85.0%、リデュース率（軽量化率）は28.4%だった。

いま論点になっているのは「リサイクルするかどうか」ではなく、
**ボトル to ボトル（水平リサイクル）をどこまで増やせるか**である。

| 用語                                           | 意味                                                                       |
| ---------------------------------------------- | -------------------------------------------------------------------------- |
| **水平リサイクル（ボトル to ボトル、B to B）** | 使用済みPETボトルを、また**PETボトルに戻す**こと。何度でも循環できる       |
| カスケードリサイクル                           | 繊維・シート・卵パックなどに作り替えること。一度使うと次はボトルに戻せない |

全国清涼飲料連合会は**2030年にボトルtoボトル比率50%以上**を目標に掲げており、
2023年時点の実績は**33.7%**。主要ブランドオーナー各社は2025〜2026年度に
自社使用分のB to B化率50%到達を見込むとされる。

ただし、ここには**経済的な副作用**がある。
**再生PET（リサイクル樹脂）はバージン樹脂より高いことが多い**（回収・選別・洗浄・再重合の
工程が乗るため）うえ、使用済みPETのフレークが海外へ輸出されるようになり、
容器包装リサイクル制度における**落札価格が高騰**していると経産省の審議会資料でも指摘されている。
「ゴミだったもの」が値のつく資源になった結果、**調達コストが上がった**わけで、
今後は**収益性を見ながらB to B使用量を慎重に判断する**局面に入るとみられている。

> ポイント：**環境対応は「善意のコスト」ではなく「原価の一部」になった。**
> 容器が原価の最大費目である以上、再生材の価格はそのまま損益に出る。
> 清涼飲料が資源循環の議論の中心にいるのは、
> **業界の都合ではなく、原価構造上そうならざるを得ない**からである。
> （→ [廃棄物処理・環境リサイクル](../../15_サービス・生活関連/23_廃棄物処理・環境リサイクル/README.md)、
> [脱炭素・GX](../../01_注目テーマ/05_脱炭素・GX/README.md)）

## 9. まとめ：この章を理解する3つの鍵

1. **原価の主役は容器と物流**。水や無糖茶では中身より容器が高い。
   だから原油・樹脂・段ボール・運賃が上がると、中身の相場が動かなくても値上げが必要になる。
2. **作り方（充填方式）が商品を決める**。無菌充填ラインを持つかどうかで、
   作れる商品と使えるボトルの重さが変わる。無糖茶の時代は無菌充填の時代でもある。
3. **作る主体が分かれている**。ボトラー制度と受託製造（委託比率30.1%、2025年）が、
   ブランドと製造の分離を生み、**低価格PBの存在を可能にしている**。

## 用語メモ

| 用語                                   | 意味                                                                                                                                                           |
| -------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **ボトラー**                           | ブランド元から**原液（コンセントレート）**の供給を受け、自社工場で製品化して担当地域で販売する会社。コカ・コーラ方式の中核。設備と販売網を持つため固定費が重い |
| **コンセントレート（原液）**           | 製品の味を決める濃縮原液。ブランド元が独占的に供給する。レシピを握ることがブランド支配の源泉になる                                                             |
| **受託製造（パッカー／OEM）**          | 他社ブランドや小売PBの飲料を作る専業メーカー。2025年の委託製造比率は30.1%。低価格PBの供給元                                                                    |
| **無菌充填（アセプティック充填）**     | 中身を冷ましてから無菌環境で常温充填する方式。香味劣化が小さく、薄く軽いボトルが使えるが、設備投資と無菌管理の負担が重い                                       |
| **ホットパック（高温充填）**           | 加熱殺菌した中身を熱いまま詰める方式。耐熱ボトル・耐熱キャップが必要で容器が重くなる。開栓前の液面が高く見えるのはこの方式                                     |
| **プリフォーム**                       | ペットボトルになる前の試験管状の成形品。工場でこれを加熱・延伸してボトルに膨らませる（ブロー成形）。プリフォームの状態で運ぶと容積が小さく済む                 |
| **リデュース率**                       | PETボトル1本あたりの樹脂使用量をどれだけ減らせたかの率。2023年度で28.4%（PETボトルリサイクル推進協議会）                                                       |
| **ボトル to ボトル（水平リサイクル）** | 使用済みPETを再びPETボトルに戻すこと。2023年時点の比率は33.7%、業界目標は2030年に50%以上                                                                       |
| **センターフィー**                     | 小売の物流センターを通す際にメーカー・卸が負担する費用。実質的な値引きとして機能する                                                                           |
