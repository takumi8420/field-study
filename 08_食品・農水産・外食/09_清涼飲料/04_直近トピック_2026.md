# ④ 直近トピック（2026年9月時点）

報道ベースの整理。数値は一次情報（統計・IR）で裏取りしたものと、
報道・推計にとどまるものを区別して書いている。

このノートで分かること：2025〜2026年に清涼飲料業界で何が起きたのか。
一言でいえば、**「自販機という利益装置が採算を失い、値上げで金額をつくる局面に入った」**年である。

## 1. 2025年の生産量は5年ぶりの減少、しかし金額は過去最高

全国清涼飲料連合会「清涼飲料水統計2026」（2026年5月29日発刊）による確定値。

| 指標                |                            2025年 |                            前年比 |
| ------------------- | --------------------------------: | --------------------------------: |
| 清涼飲料水 生産量   |                 **23,110,200 kl** | **97.9%（▲2.1%）**＝5年ぶりの減少 |
| 生産者販売金額      |           **4兆9,824億8,800万円** |              **105.3%**＝過去最高 |
| 1人あたり年間消費量 | 187.5リットル（1日あたり約514ml） |                                 — |
| PETボトルの構成比   |                             80.1% |                                 — |
| 新商品数／総商品数  |                  1,022品／6,412品 |              いずれも前年より減少 |

（人口は総務省統計局2025年10月1日現在確定値 123,219千人を使用）

読み方はシンプルで、**「値上げで金額を作り、数量を失った」**ということに尽きる。

```
【2021→2025年の数量と金額のかい離】

  生産量(万kl)                     販売金額(兆円)
   2,360 ┤        ╭──╮             5.0 ┤              ╭─ 4.98(過去最高)
   2,320 ┤     ╭──╯  ╰─╮           4.7 ┤          ╭───╯
   2,270 ┤  ╭──╯        ╰─ 2,311   4.4 ┤      ╭───╯
   2,212 ┤──╯                      4.2 ┤  ╭───╯
         └──────────────────       3.9 ┤──╯
          21  22  23  24  25            └──────────────────
                                         21  22  23  24  25

  ★ 2025年は「本数は減ったのに売上は過去最高」という決算が並んだ年
  ★ 数量を落として単価を取る局面 = 利益は必ずしも増えない
    （値上げは原料・資材・物流・人件費の上昇を埋めるためのものだから）
```

## 2. 自販機の減損ラッシュと事業売却 ― 業界最大の構造変化

2025〜2026年のいちばん大きな出来事は、**自販機資産の一斉切り下げ**である。

| 時期                 | 会社                                  | 内容                                                                                                                                                               |
| -------------------- | ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 2025年1〜6月期に計上 | **コカ・コーラ ボトラーズジャパンHD** | 自販機事業で **881億円の減損**。2025年12月期の連結最終損益は **507億円の赤字**（2026年2月確報、報道ベース）                                                        |
| 2026年1月発表        | **伊藤園**                            | 2026年4月期に自販機事業で **135.9億円の減損**。連結純利益は従来予想から150億円下振れし、前期比93%減の10億円へ。25年5〜10月の自販機飲料販売数量は**前年同期比▲14%** |
| 2026年2月発表        | **ダイドーグループHD**                | **298億円の減損**で最終損失 **303億円**。国内飲料事業は22億円の営業赤字。保有する約27万台のうち **2万台を削減**する方針                                            |
| 2026年3月5日発表     | **ポッカサッポロ F&B（サッポロHD）**  | 自販機事業（**約4万台**、社員約300人）を**ライフドリンクカンパニーへ売却**（2026年10月めど）。酒類とレモン事業に集中                                               |

背景にある数字。

- 自販機・自動サービス機の普及台数は **2025年末で約388万台**（日本自動販売システム機械工業会）。
  10年前比で2割以上減ったと報じられる。
- 報道ベースでは **2016年 約494万台 → 2022年 約397万台** と、6年で約100万台減った。
- 伊藤園の自販機台数は **2015年 約16.5万台 → 2025年12月 約7.5万台**。**10年で半分以下**。

> ポイント：**減損は「赤字だから」ではなく「将来の前提を下げたから」出る。**
> コカ・コーラBJHは事業利益ベースではむしろ改善していたと説明している。
> それでも減損したのは、**台数をこれ以上増やさない（むしろ減らす）という前提に切り替えた**からである。
> 減損は現金が出ていく処理ではなく、翌期以降の償却負担を軽くするので、
> **2026年以降の各社の損益は見かけ上よくなる**。数字の改善を実力回復と読み違えないほうがよい。
> 詳しい仕組みは → [① 自販機という装置](01_自販機という装置.md)

## 3. 2026年の値上げ ― ペットボトル「220円時代」へ

2026年は、清涼飲料にとって5年連続の値上げ局面になった。
とくに象徴的なのが、**500ml PETの希望小売価格が税別200円から220円へ**上がったことである。

| 会社                                | 実施時期                                   | 内容                                                                                                                                                     |
| ----------------------------------- | ------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **コカ・コーラ ボトラーズジャパン** | **2026年9月1日 出荷分**                    | PET（小型・中型・大型）、缶、ボトル缶、パウチ、ハンディパック等の希望小売価格を **3.2〜18.7%** 改定。500ml PETは税別200円→220円。対象は165品と報じられる |
| **サントリービバレッジ＆フード**    | 2026年10月1日 出荷分／一部は11月1日 出荷分 | 小型・大型PET、ボトル缶を中心に **20円**程度の改定                                                                                                       |
| 他の大手各社                        | 2026年秋                                   | 同様の改定が続いた（報道ベース）                                                                                                                         |

値上げの理由として各社が挙げているのは、原材料費ではなく**それ以外**が中心になっている点が重要である。

- **資材（PET樹脂・段ボール）とエネルギー価格の高騰**
- **為替相場の変動と国際情勢の影響**
- **物流費・人件費の上昇**

これは [② 作り方と原価](02_作り方と原価.md) の構造そのままで、
**中身よりも容器と物流が原価の主役**である以上、
原料相場が落ち着いても値上げ圧力は消えないということを意味する。

```
【値上げが自販機に与える副作用】

  2020年ごろ            2026年
  ┌──────────┐        ┌──────────┐
  │ 自販機 140円│        │ 自販機 180〜220円│
  │ 店頭   98円 │        │ 店頭   108〜138円│（特売時は88円も残る）
  └──────────┘        └──────────┘
   価格差 約1.4倍          価格差 約1.6〜2.5倍

  ★ 値上げは自販機のほうが通りやすい（メーカーが価格を決められるから）
  ★ しかし通した結果、店頭との価格差が開き、自販機離れが加速する
  ★ 「値上げできるチャネルほど、値上げで客を失う」というジレンマ
```

## 4. 2027年4月からの「飲食料品 消費税1%」

2026年9月15日に閣議決定された大綱により、
**2027年4月1日から2029年3月31日までの2年間、飲食料品の消費税率を8%から1%へ引き下げる**方針が示された。
ただし**2026年9月時点で法改正は成立していない**。関連法案は2026年10月召集予定の
臨時国会に提出され、年内成立を目指すとされている。

清涼飲料にとっての論点は3つある。

| 論点                                       | 中身                                                                                                                                                                                              |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **清涼飲料は対象になる**                   | 軽減税率（8%）の対象である「飲食料品（酒類を除く）」に含まれるため、1%の対象になる見込み                                                                                                          |
| **エナジードリンクとドリンク剤で差がつく** | 清涼飲料水に分類されるエナジードリンク（例：レッドブル）は**1%**、医薬部外品のドリンク剤（例：リポビタンD）は**10%**のまま。**同じ棚の似た商品で税率が9ポイント違う**という事態になると報じられる |
| **値上げの「窓」になる**                   | 税率が下がるぶん店頭価格が下がる余地ができる。そこに値上げをぶつければ、**消費者の実感価格を上げずに建値を上げられる**。ただし小売がその余地を価格訴求に使う可能性もあり、綱引きになる            |

> ポイント：**2027年4月は、2026年秋の値上げの「効き方」を左右する。**
> 220円になった500mlが、税率引き下げで消費者の支払額としては据え置きに見える可能性がある。
> 逆に**2029年4月に税率が8%へ戻るとき**、今度は値上げなしで店頭価格が上がるので、
> 需要の反動が起きる。**2年間の臨時措置は、出口のほうが難しい**。
> 業界全体の整理は → [総合食品⑤ 直近トピック](../01_総合食品/05_直近トピック_2026.md) 第2章

## 5. PET資源循環 ― 「回収率85%」の次の壁

日本のPETボトルのリサイクル率は高い。PETボトルリサイクル推進協議会によれば
**2024年度のリサイクル率は85.1%（推計）**、リデュース率（軽量化率）は2023年度で28.4%。
論点は「リサイクルするか」ではなく、**ボトル to ボトル（水平リサイクル）をどこまで増やすか**に移っている。

| 指標                   | 数値                | 年・出典                                |
| ---------------------- | ------------------- | --------------------------------------- |
| PETボトル リサイクル率 | **85.1%**（推計）   | 2024年度。PETボトルリサイクル推進協議会 |
| ボトル to ボトル比率   | **33.7%**           | 2023年。全国清涼飲料連合会資料          |
| 業界目標               | **2030年に50%以上** | 全国清涼飲料連合会                      |

ここで2026年に表面化している問題が2つある。

1. **使用済みPETの争奪戦**。フレーク（粉砕した再生原料）の輸出が増え、
   容器包装リサイクル制度における**落札価格が高騰**していると経産省の審議会資料でも指摘されている。
   「ゴミだったもの」が値のつく資源になった結果、**再生材の調達コストが上がった**。
2. **再生材はバージン樹脂より高いことがある**。環境目標を追うほど原価が上がるため、
   主要ブランドオーナー各社が2025〜2026年度にB to B化率50%へ到達したあと、
   **2026年以降は収益性を見ながら慎重に判断する**局面に入るとみられている。

> ポイント：**容器が原価の最大費目である以上、再生材の価格はそのまま損益に出る。**
> 清涼飲料が資源循環の議論の中心にいるのは、業界の都合ではなく原価構造上そうなるからである。
> → [② 作り方と原価](02_作り方と原価.md) 第8章、
> [廃棄物処理・環境リサイクル](../../15_サービス・生活関連/23_廃棄物処理・環境リサイクル/README.md)

## 6. 原料相場 ― コーヒーの高止まりと、それ以外

- **コーヒー生豆**：2025年2月に史上最高値圏（アラビカで400セント/ポンド超）を記録。
  その後は下げに転じ、2026年は6年ぶりの需給緩和に向かうと報じられるが、
  **小売価格は高止まりが続く見通し**（日本経済新聞、2026年2月）。
  2025年のコーヒー飲料等は**生産量98.8%・販売金額113.1%**と、
  値上げで金額を作った典型的な姿になっている。
- **果汁**：オレンジを中心に不作が長期化し、果実飲料等の生産量は2025年に**前年比94.2%**と
  全カテゴリで最大の落ち込み。**原価が上がって数量が落ちた**分かりやすい例。
- **砂糖・茶葉**：相対的に安定。ただし無糖化の進行で砂糖の使用量自体が構造的に減っている。
- **資材・エネルギー**：PET樹脂・段ボール・電力・燃料が値上げ理由の中心に移った。

## 7. 猛暑と「熱中症対策」という新しい需要

- 気象庁は2026年4月に、最高気温40℃以上の日を**「酷暑日」**とする呼称を定めた。
- 職場の熱中症対策強化が義務化されて2年目に入り、
  **企業が従業員用に飲料をケース単位で常備する**動きが定着してきた。
  水・スポーツ飲料・塩分入り飲料にとっては、BtoBの安定需要になる。
- ただし**天候依存は諸刃の剣**でもある。
  2024年に猛暑と備蓄需要で伸びたミネラルウォーターは、
  2025年に**4,861,900kl（前年比96.7%）**と反落した。
  **特需の翌年には必ず反動が来る**ため、夏の在庫計画を誤ると廃棄と工場稼働の両方で損失が出る。
- 民間調査では、2026年の清涼飲料の国内市場を**6兆2,853億円（2025年比107.1%）**と見込む予測も出ている
  （富士経済の推計。小売ベースの市場規模であり、全国清涼飲料連合会の
  生産者販売金額4.98兆円とは集計基準が違う点に注意）。

## 9. 全体の構図

```
【2025〜2026年に起きていることの全体像】

   需要側                    コスト側                制度側
  ┌──────────────┐        ┌──────────────┐      ┌──────────────┐
  │ 無糖化・大容量化│        │ PET樹脂・段ボール│      │ 消費税1%へ    │
  │ マイボトル定着  │        │ 電力・燃料      │      │ (2027/4〜)    │
  │ 人口減・在宅勤務│        │ 物流費・人件費   │      │ 資源循環規制   │
  └──────┬───────┘        └──────┬───────┘      └──────┬───────┘
         │                       │                       │
         ▼                       ▼                       ▼
  ┌────────────────────────────────────────────────────────┐
  │  粗利の厚い自販機が縮み、粗利の薄い店頭・ECへ需要が移動   │
  │  → 数量は減り、値上げで金額だけが伸びる                  │
  │  → 自販機資産の将来価値が下がり、一斉に減損              │
  │  → 各社は「台数を減らし、残す台は高価格・高回転に集約」   │
  └────────────────────────────────────────────────────────┘
```

3〜5行でまとめると、こうなる。

- **2025年は数量が5年ぶりに減り、金額は過去最高**という、値上げ局面の典型的な年になった。
- **業界の利益装置だった自販機が採算ラインを割り**、コカ・コーラBJH（881億円）、
  ダイドー（298億円）、伊藤園（136億円）が減損、ポッカサッポロは事業売却に踏み切った。
- **2026年の値上げで500ml PETは税別220円へ**。値上げは自販機のほうが通りやすいが、
  通すほど店頭との価格差が開き、自販機離れが進むというジレンマを抱えている。
- **2027年4月の消費税1%**が最大の変数。値上げの「窓」になるが、
  2029年4月の税率復帰時の反動という出口の問題も同時に抱える。
- 中期的には、**容器・物流・再生材というコスト側の構造**が値上げ圧力を作り続ける。
  相場が落ち着いても値上げが止まらないのは、そのためである。

## 用語メモ

| 用語                                   | 意味                                                                                                                                                 |
| -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **減損（減損損失）**                   | 固定資産が将来生むキャッシュに見合わなくなったとき、帳簿価額を切り下げて損失計上すること。**現金の流出は伴わない**が、翌期以降の減価償却費は軽くなる |
| **希望小売価格**                       | メーカーが示す「この値段で売ってほしい」という価格。店頭では守られないことが多いが、**自販機では事実上そのまま売価になる**                           |
| **軽減税率**                           | 飲食料品（酒類・外食を除く）と定期購読新聞に適用される8%の税率。2027年4月からの2年間は1%へ引き下げる方針が示された（2026年9月時点で法改正は未成立）  |
| **ボトル to ボトル（水平リサイクル）** | 使用済みPETボトルを再びPETボトルに戻すこと。2023年時点の比率は33.7%、業界目標は2030年に50%以上                                                       |
| **フレーク**                           | 使用済みPETボトルを洗浄・粉砕した再生原料。輸出需要の増加で価格が上昇している                                                                        |
| **ローリングストック**                 | 備蓄品を少し多めに買い、古いものから使って買い足す備蓄法。ミネラルウォーターの定期購入需要の柱                                                       |
| **酷暑日**                             | 最高気温40℃以上の日。気象庁が2026年4月に呼称を定めた。飲料の夏季需要を語る際の新しい指標になる                                                       |
