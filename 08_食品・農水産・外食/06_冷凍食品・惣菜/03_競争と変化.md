# ③ 競争と変化

このノートで分かること：冷凍食品と惣菜のプレイヤーがどう並んでいるか。
そして **「冷凍食品の品質が上がるほど、中食と外食の領域を食っていく」** という
この分野で最も大きな構造変化が、どこでどう起きているか。

## 1. 結論：冷凍食品は「食べ方」ではなく「作り方」を置き換えている

> **冷凍食品の競争相手は、他社の冷凍食品ではない。**
> 家庭用の相手は「今日スーパーで惣菜を買う」という選択であり、
> 業務用の相手は「店の厨房で仕込む」という作業である。
> 品質が上がるたびに、この2つの領域から仕事を引き受けていく。

```
【食卓の1食を、誰が作るかの取り合い】

                    かつて                     いま
  ─────────────────────────────────────────────────────────
  平日の夕食     内食（自分で作る）    ──▶  惣菜／冷凍食品／宅配
  外食店のメニュー 店の厨房で仕込む     ──▶  業務用冷凍食品＋店で仕上げ
  弁当のおかず    朝に作る             ──▶  自然解凍タイプの冷凍惣菜
  給食・社食      調理員が全工程        ──▶  冷凍＋スチコンで再加熱
  ─────────────────────────────────────────────────────────
                      ▲                        ▲
                 人手が潤沢だった          人手が足りない／時間がない
                 （作るのが当たり前）      （作らない選択が普通に）

  ※ 冷凍食品の伸びは「冷凍食品が好きになった」からではなく、
     ほかの選択肢のコスト（時間・人件費）が上がったから、という順序で起きている。
```

## 2. プレイヤーの構図 ― 冷凍食品側

| 企業 | 立ち位置 | 特徴 |
| --- | --- | --- |
| **ニチレイ** | 冷凍食品と低温物流の両輪 | 2026年3月期は売上高 約**7,161億円**（前年比+2.0%）、純利益 **273億円**（+10.5%）と報じられる。**低温物流（ニチレイロジグループ）の売上が3,000億円を突破**し、加工食品の原材料高を物流が補う構図。2026年4月から加工食品事業と水産・畜産事業を「食品事業」に統合する中期計画を公表 |
| **味の素冷凍食品** | 家庭用のブランド力が最強クラス | 味の素グループ。**「ギョーザ」が象徴商品**。「水なし・油なし」で焼ける設計など、調理工程を削る商品開発が得意。業務用でも炒飯・から揚げが強い |
| **ニッスイ（日本水産）** | 水産原料からの一貫体制 | 冷凍食品に加えて練り製品・ちくわなどの常温／チルド加工品も持つ。**漁獲・養殖から加工までの垂直統合**が特徴。海外（欧米・アジア・南米）にも展開 |
| **マルハニチロ** | 水産最大手の加工部門 | 水産物の調達力が源泉。**原料調達から製造・販売までの一貫体制**。冷凍食品と水産事業が相互に効く（→ [水産](../11_水産/README.md)） |
| **テーブルマーク** | 主食系（麺・米飯・パン）に特化 | JTグループ。**1974年発売の冷凍「さぬきうどん」が冷凍うどんでトップシェア**とされる。冷凍食品の生産量1位品目が「うどん」であることを考えると、この一角の重みは大きい |
| 日清食品グループ／日本製粉（ニップン）／ケイエス冷凍食品ほか | 特定カテゴリで強い | 冷凍パスタ、冷凍米飯、肉だんごなど。カテゴリ単位の勝負になる |
| 業務用専業・中堅 | 給食・外食向けに特化 | ブランドを持たず、規格と価格と供給責任で勝負する。数量は大きいが粗利は薄い |

（各社IR・報道ベース。ニチレイの数値は2026年5月の決算発表報道による）

**シェアの見方**：冷凍食品も総合食品と同じで、「業界全体のシェア」はほとんど意味を持たない。
うどんはテーブルマーク、餃子は味の素冷凍食品、といった具合に**品目ごとに勝者が違う**。
シェアを語るなら必ず品目を限定する必要がある。

## 3. プレイヤーの構図 ― 惣菜・中食側

冷凍食品と違い、中食側は**「作る会社」と「売る会社」が分かれていない**ケースが多い。

| 類型 | 代表例 | 商売の性格 |
| --- | --- | --- |
| **弁当チェーン** | プレナス（ほっともっと）、オリジン東秀 | 店舗の経済性で動く。立地・家賃・アルバイト人件費が勝負 |
| **デリカ（惣菜）専門店** | ロック・フィールド、柿安本店 | 百貨店・駅ビルへの出店が中心。高単価・高品質。家賃と催事が効く |
| **CVSベンダー（専用工場）** | わらべや日洋ホールディングスなど | 特定チェーン向けに弁当・おにぎり・惣菜を製造。**取引先1社への依存度が極めて高い**のが構造的弱点 |
| **スーパー系デリカ** | カネ美食品ほか、各スーパーの子会社・テナント | スーパーの惣菜売場を受託運営。母体の店舗数がそのまま売上規模 |
| **小売自身（インストア）** | 食品スーパー各社、GMS | 自社の売場で自社が作る。惣菜は粗利と集客の両方を担う |

（業態と代表企業の整理。売上規模の順位は集計方法により変わる）

> ポイント：**ベンダーと専門店では、リスクの形が正反対**である。
> ベンダーは営業しなくても数量が来るが、取引先を失えば工場が丸ごと止まる。
> 専門店は自分で客を集めなければならないが、売り先が分散している。
> 「どちらが良い」ではなく、**誰に依存しているか**が経営の焦点になる。

## 4. 冷凍が中食・外食を侵食する ― この分野の最大の構造変化

```
【冷凍食品が入り込んでいく3つの経路】

 ① 家庭 ─── 惣菜を買う ──────────┐
            冷凍食品を買う ◀─────┘ 置き換え
            （まとめ買いできる・捨てなくていい・値引きを待たなくていい）

 ② 外食店 ── 店で仕込む ──────────┐
            業務用冷凍を使う ◀────┘ 置き換え
            （調理人が採用できない・技能の標準化・廃棄が減る）

 ③ 中食工場 ─ 一から作る ─────────┐
            冷凍の中間素材を使う ◀─┘ 置き換え
            （下処理済みの冷凍野菜・冷凍肉・半調理品を投入）

  ※ ①〜③はすべて「人件費が上がる／人が採れない」ことを共通の推進力にしている。
```

なぜ冷凍が有利になったのか。理由は3つある。

| 理由 | 中身 |
| --- | --- |
| **品質が実用水準を超えた** | 急速凍結と再加熱設計の進歩で、「冷凍だから落ちる」が当てはまらない商品が増えた（→ [①](01_冷凍食品という産業.md) 第3章） |
| **廃棄ロスの差が決定的になった** | 惣菜は売れ残れば廃棄。冷凍は売れ残っても在庫。原材料が高いほど、この差が損益に効く |
| **買い置き環境が整った** | 大容量冷凍庫・セカンド冷凍庫の普及と、冷凍宅配・ECの拡大 |

**数字にも表れている**。冷凍食品の家庭用は2025年に金額で **+9.6%**（数量 +2.8%）と伸び、
「ワンプレート」商品は2万トン・135億円規模が出荷されたと報じられる（日本冷凍食品協会統計に基づく報道、2026年4月）。
これは惣菜のワンプレート弁当と**同じ食事シーンを狙った商品**である。

> ポイント：**惣菜が冷凍に負けるとしたら、味ではなく「廃棄と値引き」で負ける**。
> 夕方に半額シールを貼って粗利を削る商売と、
> 1年間在庫として持てる商売では、原材料高の局面での耐久力が違う。
> ただし惣菜には冷凍が持てない武器がある ―― **できたての温度と匂い**である。
> 揚げ物を揚げている音と匂いは、冷凍ケースでは再現できない。
> 中食側の防衛線はここにあり、だからスーパーは店内厨房を残している。

## 5. 値上げと数量 ― 「金額は過去最高、数量は横ばい」の読み方

冷凍食品・惣菜ともに、2023年以降の市場拡大の相当部分は価格改定による。

| 年 | 冷凍食品 国内生産量 | 同 生産額 | 惣菜市場規模 |
| --- | --- | --- | --- |
| 2021年 | 1,587,091トン | 7,343億円 | ― |
| 2022年 | 1,598,808トン（100.7%） | 7,639億円（104.0%） | ― |
| 2023年 | 1,545,568トン（**96.7%**） | 7,799億円（102.1%） | 10兆9,827億円 |
| 2024年 | 1,537,854トン（**99.5%**） | 8,064億円（103.4%） | 11兆2,882億円（102.8%） |
| 2025年 | 1,574,172トン（102.4%） | **8,577億円**（106.4%） | **11兆7,075億円**（103.7%） |

（冷凍食品：日本冷凍食品協会。惣菜：日本惣菜協会）

**2023〜2024年は数量が減っているのに金額は増えている**。値上げで名目が膨らむ一方、
消費者は買う量を減らしていた。2025年になって数量もプラスに転じたが、
生産額の伸び（+6.4%）と数量の伸び（+2.4%）の差は依然として価格要因である。

2026年の値上げも続いている（報道ベース）。

| 時期 | 内容 |
| --- | --- |
| 2026年2〜4月 | ニチレイフーズ、マルハニチロ、ニッスイなどが家庭用・業務用を改定（第1波） |
| 2026年9月1日納品分 | **ニッスイ**：家庭用冷凍食品 約2〜17%、家庭用加工食品（練り製品等）全品 約5〜17%、業務用冷凍食品の一部。**テーブルマーク**：家庭用・業務用 約3〜20%。**日清食品グループ**も冷凍食品を改定 |
| 2026年10月1日納品分 | **味の素冷凍食品**：「やわらか若鶏から揚げボリュームパック」など**16品を5〜8%** |

値上げ理由として各社が共通して挙げるのが **包装資材費** である。
原材料相場が落ち着いても、包材・物流・人件費は下がらない。
だから冷凍食品の値上げは、総合食品全体と同じく**粘着質（一度上がったら戻らない）**な性格を持つ
（→ [総合食品⑤](../01_総合食品/05_直近トピック_2026.md)）。

## 6. 販路が増えた ― 冷食専門店、自販機、EC

冷凍食品は長く「スーパーの冷凍ケース」という一本の売り場に縛られていた。
ここ数年、その外側に販路が生まれている。

| 販路 | 中身 | 経済的な意味 |
| --- | --- | --- |
| **冷凍食品専門店** | 冷凍品だけを扱う業態。輸入冷凍食品の専門店や、外食チェーンの直売所型店舗 | 棚の取り合いから逃げられる。自社商品だけを並べられる |
| **冷凍自動販売機** | サンデン・リテールシステム「ど冷えもん」、富士電機「FROZEN STATION」など。24時間無人販売 | **小さな面積で売れる**。飲食店が空き時間に自社商品を売る副収入にもなる。リンガーハットは冷凍食品直売所を2022年から展開し、2026年に国内3店舗目を八王子に出店したと報じられる |
| **EC・冷凍宅配** | ネットスーパー、冷凍ミールキット、D2C冷凍惣菜 | 冷凍だから配送に耐える。**常温品より返品・品質クレームが少ない** |
| **業務用の小口化** | 飲食店向けのネット卸・少量配送 | 小さな店でも業務用品が買えるようになり、業務用市場の裾野が広がる |

> ポイント：**冷凍自販機が意味を持つのは「冷凍だから無人で置ける」から**である。
> 常温弁当や惣菜は無人販売すると消費期限の管理ができないが、
> 冷凍なら機械が−18℃を保つかぎり品質が落ちない。
> 温度という物理的な条件が、そのまま販売チャネルの自由度になっている。

## 7. 需要側の構造変化 ― 世帯が小さくなると中食と冷凍が伸びる

| 変化 | 中食・冷凍食品への影響 |
| --- | --- |
| **単身世帯の増加** | 1人分を作ると食材が余る。買ったほうが安く、捨てる量も減る |
| **共働き世帯の増加** | 平日夕方に調理時間がない。**時短が価格より優先される場面**が増える |
| **高齢化** | 少量・やわらかい・調理が負担。配食サービスと冷凍惣菜の市場が伸びる |
| **米・生鮮の値上がり** | 自炊のコストが上がり、中食・冷凍の相対的な割安感が増す |
| **家庭の冷凍庫容量の拡大** | 大容量冷凍庫・セカンド冷凍庫の普及が、家庭用冷凍食品の「買える上限」を引き上げた |

日本惣菜協会は、惣菜市場が2006年比で **149%** に拡大したことについて、
人口減少下の内需型市場としては例外的だとしたうえで、
消費者の生活スタイルと価値観の変化を捉えた結果だと説明している（2026年4月）。

## 8. 人手不足が業務用需要を押し上げる

この分野で最も見落とされやすい因果がこれである。

```
【人手不足 → 業務用冷凍食品の需要増 という連鎖】

  最低賃金の上昇          調理人が採用できない
       │                      │
       ▼                      ▼
   厨房の人件費が上がる ──────┘
       │
       ▼
  「自分で仕込む」コスト > 「冷凍品を買う」コスト  ← ここが逆転する
       │
       ▼
  外食・給食・中食工場が業務用冷凍食品に切り替える
       │
       ▼
  業務用の数量が伸びる（2025年 +1.9%、金額 +3.1%）
       │
       ▼
  冷凍食品メーカーは「安定した数量」を得る代わりに、薄い粗利で受ける
```

外食・給食の現場では、この切り替えが「品質の妥協」ではなく
**「品質の標準化」**として語られることが多い。
ベテランが辞めても味が変わらない、新人でも同じものが出せる、という価値である。
（→ [給食・フードサービス](../21_給食・フードサービス/README.md)、
[ファストフード](../14_ファストフード/README.md)）

一方で、冷凍食品メーカー自身も人手不足と無縁ではない。
冷凍食品の**工場数は404、企業数は326**（2025年、日本冷凍食品協会）で、
10年以上にわたって減少が続いている。
設備投資と省人化に耐えられる規模の会社に集約が進んでいる、と読める。

## 9. 競争要因（KSF）と参入障壁

| KSF | 家庭用 | 業務用 |
| --- | --- | --- |
| ブランド | ◎ 指名買いが起きる。棚の確保に直結 | △ 相手は法人。ブランドより規格と価格 |
| 凍結・再加熱の技術 | ◎ 「レンジで失敗しない」が商品力 | ◎ 歩留まり・作業時間に直結 |
| コールドチェーン（自社／共同） | ◎ 物流費が損益を左右する | ◎ 定時定量の供給責任 |
| 生産規模と稼働率 | ◎ 固定費が重い装置産業 | ◎ 大ロットで単価が決まる |
| 原料調達力 | ○ 相場変動の吸収 | ◎ 供給責任の前提 |
| 営業網（卸・小売／外食本部） | ◎ 棚を取る力 | ◎ 本部への提案力とメニュー開発の伴走 |

**参入障壁**は許認可ではない（食品製造業は営業許可とHACCP対応が要るが免許制ではない）。
実質的な壁は次の3つ。

1. **凍結設備への投資**。トンネルフリーザー1本でも数億円規模になり、
   稼働率が上がらなければ単位原価が跳ね上がる。
2. **コールドチェーンへのアクセス**。冷凍倉庫と冷凍車を確保できなければ、
   作れても届けられない。自社で持てば重く、外に払えば高い。
3. **棚（家庭用）／実績（業務用）**。冷凍ケースの面積は常温棚より限られ、
   業務用は供給を止めない実績がないと本部の採用リストに乗らない。

## 10. まとめ：この章を理解する3つの鍵

1. **冷凍食品の競争相手は惣菜と厨房**。品質が上がるほど、
   「今日買う惣菜」と「店で仕込む作業」を置き換えていく。推進力は人件費と時間である。
2. **金額の伸びと数量の伸びを分けて読む**。2023〜2024年は数量減・金額増。
   市場が拡大しているように見えても、買われた量が増えているとは限らない。
3. **惣菜側の防衛線は「できたて」**。廃棄と値引きという弱点を抱えつつ、
   冷凍が持てない温度と匂いで戦っている。だからスーパーは店内厨房を捨てない。

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **中間素材（半調理品）** | 下処理や一次加熱まで済ませた業務用の冷凍原料。カット野菜、から揚げの生地付け肉など。厨房の工程を部分的に置き換える |
| **スチコン（スチームコンベクションオーブン）** | 蒸気と熱風を組み合わせた業務用加熱機。冷凍品の再加熱を均一にでき、業務用冷凍食品の普及を支えた設備 |
| **自然解凍タイプ** | 加熱せず常温に置くだけで食べられる冷凍惣菜。弁当のおかず用。加熱しないぶん微生物管理の基準が厳しい |
| **ベンダー依存** | 特定チェーン向け専用工場が、その1社に売上の大半を依存している状態。数量は安定するが、契約解消で工場が丸ごと止まる |
| **建値／リベート** | メーカーが示す基準価格と、あとから払い戻す販売報奨金。実質価格は建値から各種負担を引いた正味で決まる → [総合食品②](../01_総合食品/02_値決めと交渉.md) |
| **ど冷えもん／FROZEN STATION** | 冷凍自動販売機の代表機種（サンデン・リテールシステム／富士電機）。24時間無人で冷凍品を売れる |
