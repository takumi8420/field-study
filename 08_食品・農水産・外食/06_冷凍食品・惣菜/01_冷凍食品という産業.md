# ① 冷凍食品という産業

このノートで分かること：冷凍食品が **「家庭用」と「業務用」でまったく別の商売** であること、
その品質を決めているのが「どれだけ速く凍らせたか」という物理現象であること、
そして長い賞味期限が在庫の自由と冷凍倉庫コストを同時に生むこと。

## 1. 結論：同じ工場で作っていても、家庭用と業務用は別の産業

> **家庭用冷凍食品は「スーパーの冷凍ケースの棚を取る」ブランド商売。
> 業務用冷凍食品は「外食・給食の厨房から調理工程を引き取る」設備代替の商売。**
> 売る相手も、値段の決まり方も、商品設計も違う。

数字で見ると、日本の冷凍食品は数量ではほぼ半々、金額では家庭用がやや上回る。

| 区分 | 生産数量（2025年） | 構成比 | 生産額（工場出荷額） | 構成比 | 単価の目安 |
| --- | --- | --- | --- | --- | --- |
| **業務用** | 813,787トン（前年比 101.9%） | 51.7% | 4,119億円（103.1%） | 48.0% | 約 **506円/kg** |
| **家庭用** | 760,385トン（102.8%） | 48.3% | 4,458億円（109.6%） | 52.0% | 約 **586円/kg** |
| 合計 | 1,574,172トン（102.4%） | 100% | **8,577億円**（106.4%、過去最高） | 100% | 約545円/kg |

（一般社団法人 日本冷凍食品協会「令和7年（1〜12月）冷凍食品の生産・消費について（速報）」2026年4月16日。単価は生産額÷生産量で筆者計算）

同じ1kgでも家庭用のほうが出荷単価が2割近く高い。
これは家庭用のほうが**小分け包装・トレー・電子レンジ対応の仕掛け**という手間が乗っているからで、
業務用は1kg・2kgのバルク（大袋）で、包装は最小限、その分安い。

```
【同じ「冷凍からあげ」でも別商品になる】

 業務用                          家庭用
 ─────────────────────────       ─────────────────────────
 1kg 大袋・段ボール入り            220g トレー＋袋・箸で取れる量
 味付けは控えめ（店で味変する）      味付け完成（そのまま食卓へ）
 フライヤー／スチコン前提          電子レンジ600W 3分30秒 前提
 価格は年1〜2回の相対取引で決定     建値＋リベート、店頭は特売で動く
 売り先＝外食本部・給食会社・卸     売り先＝スーパー／CVS の冷凍ケース
 勝負どころ＝歩留まり・作業時間     勝負どころ＝ブランドと棚の面積
```

## 2. そもそも「冷凍食品」とは何か

日本冷凍食品協会の定義では、冷凍食品は次の4条件を満たすものとされる。

| 条件 | 中身 | なぜ必要か |
| --- | --- | --- |
| ① 前処理してある | 洗う・切る・加熱するなど、食べる直前の手間を先に済ませてある | 「そのまま調理できる」が価値の中心 |
| ② **急速凍結**してある | 食品の中心温度を短時間で一気に下げる | 品質を決める最重要工程（→ 第3章） |
| ③ 適切に包装してある | 密封し、表示を付ける | 乾燥（冷凍焼け）と酸化を防ぐ |
| ④ **−18℃以下**で流通・保管する | 製造から店頭まで温度を切らさない | 微生物が増えず、品質劣化が止まる（→ 第4章） |

> **急速凍結（きゅうそくとうけつ）** ＝ 食品を「最大氷結晶生成帯」（おおむね −1℃〜−5℃）を
> 30分程度で通過させる凍らせ方。家庭の冷凍庫でゆっくり凍らせるのとは別物。

**−18℃という数字には理由がある**。この温度帯では微生物はほぼ増殖できず、
酵素反応も化学変化も実用上ほぼ止まる。だから冷凍食品には**保存料を使う必要がない**。
「冷凍食品は添加物だらけ」というイメージは実態と逆で、
むしろ温度という物理的手段で保存しているぶん、常温加工食品より保存料が要らない。

## 3. 急速凍結と氷結晶 ― 品質を決めているのは物理現象

冷凍食品のおいしさを決めているのは、レシピよりも先に**凍らせ方**である。

```
【ゆっくり凍らせた場合 vs 一気に凍らせた場合】

  ゆっくり凍結（家庭の冷凍庫）      急速凍結（工場のトンネルフリーザー）
  −1℃〜−5℃を数時間かけて通過       −1℃〜−5℃を30分以内で通過

   細胞  ┌───┐                      細胞  ┌───┐
        │ ●●●│ ← 大きな氷の粒            │∵∵∵│ ← 細かい氷の粒
        │ ●●●│    細胞膜を突き破る        │∵∵∵│    細胞膜を壊さない
        └───┘                            └───┘
           ↓ 解凍                            ↓ 解凍
      水分が流れ出る（ドリップ）        水分が戻る
      スカスカ・パサパサになる          食感と味が保たれる
```

水は凍ると体積が約9%増える。ゆっくり凍らせると、その膨張が**少数の大きな氷の結晶**に集中し、
細胞膜を内側から突き破る。解凍したとき、破れた細胞から水分と旨味成分が流れ出る。
これが**ドリップ**で、「冷凍するとまずくなる」の正体である。

急速凍結では氷結晶が微細に分散するので細胞が壊れにくい。
つまり **「速く凍らせる＝設備の性能」がそのまま品質になる**。

| 凍結方式 | 仕組み | 凍結の速さ | 主な用途 |
| --- | --- | --- | --- |
| エアブラスト（トンネルフリーザー） | −35℃前後の冷風を強く当てる | 標準 | 冷凍食品の主力。汎用性が高い |
| スパイラルフリーザー | 冷風式を螺旋状のコンベアで上下に通す | 標準〜速い | 設置面積あたりの処理量が大きい |
| 接触式（コンタクトフリーザー） | 冷却板で上下から挟む | 速い | 平たい形状（ミンチ、フィレ）向き |
| ブライン／液体凍結 | 低温の不凍液に浸ける | かなり速い | 魚介、寿司ネタ |
| 液化窒素（−196℃） | 液体窒素を噴霧 | 最速 | 高付加価値品。ランニングコストが高い |
| CAS・プロトン等の高付加価値凍結 | 磁場・電場などを併用すると称する方式 | 速いとされる | 導入例は限定的。効果の評価は分かれる |

> ポイント：**冷凍食品メーカーの技術力は「レシピ」ではなく「凍結条件の作り込み」に宿る**。
> どの温度帯を何分で抜けさせるか、どの工程で凍らせるか（加熱前か後か）、
> 解凍時にどう戻るか。これは設備と経験の蓄積であり、レシピを真似されても追随されにくい。
> 総合食品で言う「工業化」（→ [総合食品③](../01_総合食品/03_商品開発とブランド.md)）の冷凍版にあたる。

## 4. コールドチェーン ― 切れたら商品価値がゼロになる鎖

> **コールドチェーン** ＝ 生産から消費者の手元まで、
> 低温を一度も切らさずにつなぐ物流・保管の仕組み。「低温物流」とも言う。

冷凍食品は「作れば売れる」商品ではなく、**−18℃を維持できる設備が最後まで続いていて初めて商品になる**。
途中で一度でも温度が上がると、氷が溶けて再び凍る過程で氷結晶が粗大化し（再結晶化）、
見た目は無事でも食感が落ちる。しかも消費者にはその履歴が見えない。

```
【冷凍食品のコールドチェーン ― ひとつでも欠けると成立しない】

  工場          冷凍倉庫        幹線輸送       配送センター    店舗       家庭
 −35℃凍結  ──▶ −25〜−18℃ ──▶ 冷凍トラック ──▶ −18℃仕分け ──▶ 冷凍ケース ──▶ 冷凍庫
  （設備投資） （自動ラック）   （2024年問題）  （TC/DC）    （電気代）  （容量が制約）
      │            │               │             │            │
      └── どこか1か所でも −18℃を切ると、品質は戻らない ────────┘

  ※ 常温流通の加工食品なら、倉庫もトラックも棚も「ただの箱」で済む。
     冷凍はそのすべてが冷却設備であり、そのすべてに電気代と償却が乗る。
```

このため冷凍食品は、常温の加工食品にくらべて**物流・保管コストが構造的に高い**。
おおまかな相場観として、冷凍倉庫の保管料は常温倉庫の2〜3倍、
輸送も冷凍車が必要なぶん割高になる（事業者・地域により幅がある）。

さらに近年は次の圧力がかかっている。

| 論点 | 中身 |
| --- | --- |
| 電気代 | 冷凍倉庫は24時間冷やし続ける。電力料金の上昇がそのまま原価に乗る |
| 冷媒の規制 | フロン排出抑制法。老朽設備の自然冷媒（アンモニア／CO2）への更新投資が必要 |
| 倉庫の老朽化 | 国内の営業用冷蔵倉庫は築年数の古いものが多く、建て替えには数十億円規模の投資が要る |
| トラック運転者の時間外規制 | 2024年4月からの上限規制（いわゆる2024年問題）で長距離の輸送力が細った |
| 荷待ち・荷役時間 | 冷凍品は手荷役が残りやすく、パレット化が遅れている |

大手5社（味の素冷凍食品・テーブルマーク・ニチレイ・ニッスイ・マルハニチロ）が
**共同物流の枠組み拡大を協働で検討**すると発表したのは2024年6月。
競合同士が物流だけは組むのは、**冷凍の物流費が単独では支えきれない水準に来た**という認識の表れである
（→ [食品卸② 物流という本体](../../06_商社・卸売/06_食品卸/02_物流という本体.md)、
[倉庫・3PL](../../13_運輸・物流/08_倉庫・3PL/README.md)）。

## 5. 家庭用の経済学 ― 「電子レンジ600W◯分」は調理設計そのもの

家庭用冷凍食品の商品設計は、**消費者の調理器具に合わせて逆算される**。

| 加熱手段 | 設計上の制約 | 生まれた商品 |
| --- | --- | --- |
| 電子レンジ | 水分の多いところだけが先に熱くなる。ムラが出る | 蒸気が抜ける自立パウチ、トレー形状での熱制御、具材の配置設計 |
| フライパン | 油と水を足す必要がある | 「水なし・油なし」餃子（トレーに油脂と水分をあらかじめ仕込む） |
| トースター | 表面が焦げやすい | クロワッサン、ピザ |
| 自然解凍 | 加熱しない。菌数管理が厳しい | 弁当用の小分け惣菜カップ |

> ポイント：**「水なし油なしで焼ける餃子」は、味の改良ではなく調理工程の削減で勝った商品**である。
> 家庭用冷凍食品の競争軸は「おいしさ」だけでなく、
> **「その家庭が持っている器具で、失敗せずに、何分でできるか」**にある。
> だから開発は食品開発であると同時に、加熱工学の設計になる。

家庭用の売り場としての難しさも押さえておきたい。

- **冷凍ケースは面積が限られている**。スーパーの冷凍什器は常温棚より1台あたりの設置コストが高く、
  売場面積を増やしにくい。棚の取り合いは常温以上に厳しい。
- **買える量に上限がある**。消費者の家庭用冷凍庫の容量が物理的な天井になる。
  ここ10年で大容量冷凍庫・セカンド冷凍庫が普及したことが、家庭用市場の拡大を後押しした。
- **特売の振れが大きい**。「4割引」「半額」が日常化しており、建値と実売価格の乖離が大きい
  （→ [総合食品② 値決めと交渉](../01_総合食品/02_値決めと交渉.md)）。

## 6. 業務用の経済学 ― 厨房の人件費を買ってもらう商売

業務用冷凍食品の顧客は、外食チェーン、給食会社、病院・福祉施設、ホテル、コンビニのベンダーなど。
彼らが冷凍食品を買う理由は「安いから」ではなく、**厨房の作業を減らせるから**である。

```
【業務用冷凍食品が置き換えているもの】

  従来の店内調理                   冷凍食品を使った場合
  ───────────────                  ───────────────────
  仕入（生鮮）                      冷凍品を仕入れる
   ↓ 洗う・切る・下味               ↓
   ↓ 下処理の人1名×3時間            （工場で済み）
   ↓ 仕込みロス（歩留まり85%）       （歩留まり100%・可食部のみ）
   ↓ 調理（技能が要る）              加熱して盛るだけ（誰でも同じ味）
   ↓ 仕込み分の廃棄リスク            必要な分だけ出す（在庫は冷凍で持てる）
  ───────────────                  ───────────────────
  原材料費は安い／人件費は高い       原材料費は高い／人件費と廃棄が減る
```

つまり業務用の値決めは **「冷凍品の価格 vs 生鮮＋人件費＋廃棄ロス」の比較**で決まる。
最低賃金が上がり、調理人が採用できなくなるほど、冷凍食品が有利になる。
**人手不足は業務用冷凍食品にとって追い風**という関係がここで生まれる。

業務用の特徴を家庭用と並べると次のようになる。

| 項目 | 家庭用 | 業務用 |
| --- | --- | --- |
| 買い手 | 不特定多数の消費者（実際の交渉相手は小売） | 外食本部・給食会社・卸（法人） |
| 価格の決まり方 | 建値＋リベート、店頭は特売で変動 | 年1〜2回の相対交渉。数量コミットとセット |
| 求められること | 味・ブランド・簡便さ | 規格の安定、歩留まり、作業時間、トレーサビリティ |
| 1品あたり数量 | 少ない・SKUが多い | 多い・SKUは絞られる |
| 粗利率 | 高い | 低い |
| 数量の安定度 | 天候・特売・新商品で振れる | 安定（契約ベース） |
| 新規参入 | 棚が取れない | 品質と供給責任が問われる。実績がないと入れない |
| 2025年の実績 | 数量 +2.8% / 金額 +9.6% | 数量 +1.9% / 金額 +3.1% |

（2025年実績は日本冷凍食品協会・前掲速報）

2025年は**家庭用が金額で+9.6%と大きく伸びた**が、これは数量（+2.8%）以上に
値上げと高単価品（ワンプレート商品など）への移行が効いたためで、
「売れた量」以上に「1袋あたりの単価」が上がった年だった、と読むのが正確である。

## 7. 賞味期限が長いことの意味 ― 在庫は持てる。ただしタダではない

冷凍食品の賞味期限は一般に **製造から12〜18か月**（家庭用の目安）。
常温の加工食品（数か月）や、惣菜のような日配品（当日〜数日）とは桁が違う。
これが商売の形を大きく変える。

| 効果 | 中身 |
| --- | --- |
| **見込み生産ができる** | 需要期の前にまとめて作り置きできる。工場の稼働率を平準化できる |
| **欠品しにくい** | 安全在庫を厚く持てる。小売から見た供給責任のハードルを越えやすい |
| **廃棄ロスが小さい** | 惣菜のような「売れ残り＝即廃棄」がない。これが中食に対する最大の優位 |
| **返品が少ない** | 納品期限（1/3ルール等）の運用余地が大きい |
| **しかし保管料がかかる** | 在庫を持てば持つほど冷凍倉庫の保管料と電気代が積み上がる |
| **資金が寝る** | 長期在庫は運転資金を食う。回転が落ちれば財務が重くなる |

> ポイント：**冷凍食品の「在庫が持てる」は、廃棄ロスを冷凍倉庫代に付け替えているだけ**である。
> 惣菜が「売れ残りを捨てる」形で払うコストを、冷凍食品は「冷やし続ける」形で毎日払っている。
> だから冷凍食品メーカーの経営は、**需要予測の精度＝在庫日数の管理**が利益を左右する。
> ニチレイのように自社で低温物流事業（ニチレイロジグループ）を持つ会社が強いのは、
> このコストを外に払わず内側で回せるからでもある。

```
【大分類ごとの「業務用比率」（2025年・数量ベース）】

  水産物     ███████████████▌ 77.1%  ← ほぼ業務用（原料的な用途）
  農産物     ███████████████▎ 76.6%

  菓子類     █████████████▏   65.4%
  畜産物     ████████████▋    63.4%
  フライ類以外 ████████▌       42.6%  ← 麺・米飯・餃子。ここだけ家庭用が過半
  ───────────────────────────

  （日本冷凍食品協会 2025年速報 表-4 より作成）
```

この図が示しているのは、**「冷凍食品＝家庭のおかず」という実感は、
実は"フライ類以外の調理食品"というひとつのカテゴリの話**だということ。
それ以外の領域は、外食・給食の厨房に入っていく業務用が主戦場である。

## 9. まとめ：この産業を理解する3つの鍵

1. **家庭用と業務用は別の商売**。家庭用は棚とブランド、業務用は厨房の人件費との比較。
   数量では業務用が過半、金額では家庭用が過半、という「ねじれ」がそれを表している。
2. **品質は設備で決まる**。急速凍結で氷結晶を細かくできるか、−18℃を切らさず届けられるか。
   レシピではなく凍結条件と物流が参入障壁になる。
3. **賞味期限の長さは、廃棄ロスを冷凍倉庫代に付け替える仕組み**。
   在庫を持てる自由と、冷やし続ける固定費が同時に来る。

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **急速凍結** | −1℃〜−5℃の「最大氷結晶生成帯」を30分程度で通過させる凍らせ方。氷結晶が細かくなり、細胞が壊れにくい。冷凍食品の4条件のひとつ |
| **最大氷結晶生成帯** | 食品中の水分の大半が凍る温度帯（おおむね −1℃〜−5℃）。ここをゆっくり通ると大きな氷の粒ができる |
| **ドリップ** | 解凍時に食品から流れ出る水分。細胞が壊れている証拠で、旨味成分も一緒に失われる |
| **コールドチェーン** | 生産から消費まで低温を切らさずつなぐ物流・保管の仕組み。冷凍は −18℃以下、冷蔵は 0〜10℃が目安 |
| **−18℃** | 冷凍食品の流通・保管の基準温度。微生物の増殖と酵素反応が実用上止まるため、保存料が不要になる |
| **エアブラスト／スパイラルフリーザー** | 低温の冷風を当てて凍らせる装置。冷凍食品工場の主力設備 |
| **バルク（業務用大袋）** | 1kg・2kgなどの大容量包装。業務用の標準形で、家庭用のような個包装・トレーがない |
| **歩留まり（ぶどまり）** | 仕入れた原料のうち実際に商品になる割合。業務用冷凍食品は可食部だけを納品するので、厨房側の歩留まりが100%になる |
| **SKU** | Stock Keeping Unit。商品の管理単位。味・容量違いも別SKU。家庭用はSKUが多く、業務用は絞られる |
| **1/3ルール** | 製造日から賞味期限までを3等分し、最初の1/3以内に小売へ納品する商習慣 → [総合食品①](../01_総合食品/01_食品メーカーの損益構造.md) |
