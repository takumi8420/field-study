## 1. 冷凍食品の消費量が初めて300万トンを超えた（2026年4月発表）

日本冷凍食品協会が2026年4月16日に公表した「令和7年（1〜12月）冷凍食品の生産・消費について（速報）」で、
**2025年の国内消費量が3,029,325トン（前年比103.6%）となり、調査開始以来はじめて300万トンを超えた**。

| 指標 | 2025年 | 前年比 |
| --- | --- | --- |
| 国内消費量（国内生産＋冷凍野菜輸入＋調理冷凍食品輸入） | **3,029,325トン** | 103.6% |
| 国民1人あたり年間消費量 | **24.6kg**（+1.0kg） | ― |
| 消費額 | **1兆3,614億円** | 104.1% |
| 国内生産量 | 1,574,172トン | 102.4% |
| 国内生産額（工場出荷額） | **8,577億円**（過去最高を更新） | 106.4% |
| 冷凍野菜の輸入量 | **1,224,678トン**（統計開始以来最高） | 104.9% |

読み方のポイントは3つ。

- **家庭用が金額で大きく伸びた**（数量+2.8%／金額+9.6%）。値上げと、
  ワンプレート型など高単価商品への移行の両方が効いている。
  報道では「ワンプレート」商品が2万トン・135億円規模の出荷と伝えられている。
- **業務用は堅調だが伸びは緩やか**（数量+1.9%／金額+3.1%）。
  外食・給食の需要は底堅いが、価格転嫁は家庭用ほど進んでいない。
- **輸入冷凍野菜が過去最高**。1,224,678トンは国内生産量（157万トン）の約8割に相当する規模で、
  日本の冷凍食品市場が**輸入原料に大きく依存している**ことを示す。
  主な輸入先は中国（649,906トン、108.0%）、アメリカ（294,151トン、103.5%）。

> 注意：消費量の集計に使う「調理冷凍食品の輸入量」は**協会会員33社のみを対象とした調査**であり、
> 会員外の商社・流通業者の輸入は含まれない。協会自身も
> 「実際の消費量は303万トンを上回るものと考えられる」としている。

## 2. 惣菜市場も過去最高の11兆7,075億円 ― スーパーが牽引（2026年4月発表）

日本惣菜協会は2026年4月14日、**2025年の惣菜市場規模を11兆7,075億円（前年比103.7%）**と発表した。

| 業態 | 2025年（億円） | 構成比 | 前年比 |
| --- | --- | --- | --- |
| CVS | 36,044 | 30.8% | 102.3% |
| 食料品スーパー | 35,522 | 30.3% | **104.9%** |
| 惣菜専門店 | 32,020 | 27.4% | 104.2% |
| 総合スーパー | 10,113 | 8.6% | **104.7%** |
| 百貨店 | 3,375 | 2.9% | 99.3% |
| **合計** | **117,075** | 100% | 103.7% |

この発表で目を引くのは**業態の逆転傾向**である。

- 長く最大業態だった **CVSの伸びが+2.3%と最も低い**。店舗数が飽和し、
  客数が伸びないなかで単価だけが上がっている。
- 代わりに **食料品スーパー（+4.9%）と総合スーパー（+4.7%）が市場を牽引**した。
  米や生鮮三品の価格上昇で「作るより買うほうが無駄がない」と評価された、と協会は説明している。
- 協会は、惣菜市場が**2006年比149%**に拡大したことに触れ、
  人口減少下の内需型市場としては例外的な成長だとしている。

詳細は「2026年版惣菜白書」（2026年6月1日発刊）に掲載される。

## 3. 値上げの第2波 ― 理由は原料から「包装資材」へ（2026年9〜10月）

2026年の冷凍食品の価格改定は、報道ベースで**2つの波**に分かれた。

| 時期 | 主な発表 |
| --- | --- |
| **第1波：2〜4月** | ニチレイフーズ、マルハニチロ、ニッスイなどが家庭用・業務用を改定 |
| **第2波：9月1日納品分** | **ニッスイ** … 家庭用冷凍食品 約2〜17%、家庭用加工食品（練り製品等）全品 約5〜17%、業務用冷凍食品の一部。**テーブルマーク** … 家庭用・業務用 約3〜20%。**日清食品グループ** … 冷凍食品を改定 |
| **第2波：10月1日納品分** | **味の素冷凍食品** … 「やわらか若鶏から揚げボリュームパック」など**16品を5〜8%** |

```
【値上げ理由の重心が移っている】

  2022〜2023年             2025〜2026年
  ─────────────            ─────────────
  ■ 原材料相場（小麦・油脂）  ■ 包装資材費 ◀ 各社が共通して挙げる
  ■ 為替（円安）             ■ 人件費（最低賃金の上昇）
  □ 物流費                  ■ 物流費（2024年問題以降）
  □ 電気代                  ■ 電気代（冷凍倉庫は24時間稼働）
                            □ 原材料相場

  ※ 相場は下がることがあるが、包材・人件費・物流費は下がらない。
     だから今回の値上げは「粘着質」になる。
```

冷凍食品はとくに**電気代と物流費への感応度が高い**。
−18℃を維持する冷凍倉庫は24時間冷却を止められず、輸送も冷凍車が要る。
常温の加工食品より、エネルギー価格の上昇が直接原価に乗る構造にある
（→ [① 第4章](01_冷凍食品という産業.md)）。

## 4. 冷凍物流の協働 ― 競合5社が物流だけ組む

味の素冷凍食品・テーブルマーク・ニチレイ・ニッスイ・マルハニチロの**大手5社**は、
2024年6月、冷凍食品物流の持続的成長に向けた協働の検討を開始すると発表した。
既存の共同物流の枠組みを拡大し、**共同保管・共同配送による積載率の向上**、
物流ネットワークの安定化、物流現場の生産性向上を共同で進めるという内容である。

背景にあるのは次の圧力。

| 圧力 | 中身 |
| --- | --- |
| トラック運転者の時間外労働上限規制 | 2024年4月施行。長距離輸送の供給力が細った（いわゆる2024年問題） |
| 冷凍倉庫の老朽化と電気代 | 24時間冷却が前提。更新投資には数十億円規模がかかる |
| 手荷役の残存 | 冷凍品はパレット化が遅れており、荷待ち・荷役時間が長い |
| 改正物流効率化法 | 2026年4月に特定事業者の指定・CLO（物流統括管理者）選任義務が施行。大手食品メーカーは荷主として該当 |

> ポイント：**棚では殺し合う競合同士が、物流では手を組む**。
> これは冷凍物流のコストが「1社では支えきれない水準」に来たという認識の表れである。
> 冷凍食品の商品力は工場と冷凍倉庫と冷凍車の連鎖の上に成り立っており、
> その連鎖が切れれば商品が成立しない（→ [倉庫・3PL](../../13_運輸・物流/08_倉庫・3PL/README.md)、
> [食品卸② 物流という本体](../../06_商社・卸売/06_食品卸/02_物流という本体.md)）。

ニチレイが2026年3月期に**低温物流（ニチレイロジグループ）の売上3,000億円突破**を達成し、
加工食品の原材料高を物流事業の収益拡大で補ったと報じられているのも、同じ文脈で読める。
**冷凍食品メーカーにとって、低温物流は「コスト」でもあり「事業」でもある**。

## 5. 惣菜の自動化 ― 盛付ロボットが現場実装の段階へ

惣菜製造は食品産業のなかで最も自動化が遅れた領域とされてきた。
形が不揃い、やわらかい、彩りが商品価値、多品種少量 ―― 機械化を阻む条件が揃っているためである。

日本惣菜協会は経済産業省・農林水産省の支援のもとでロボット開発を進め、
**2024年に「惣菜盛付の全工程をロボット化し、現場実装に成功した」と報じられた**。
その後も麺惣菜の盛付工程を統合したロボットシステムなどが公表されている。
音声認識AIでロボットの動作プログラムを設定し、ティーチング（動作の教え込み）を不要にする
技術も登場している。

ただし普及には条件がある。

| 条件 | 中身 |
| --- | --- |
| 1品目あたりの生産量 | 多品種少量の現場では段取り替えが効果を打ち消す。**大ロットのベンダー工場から先に入る** |
| 投資回収年数 | 設備が高額。人件費削減額との比較で回収年数が決まる |
| 衛生設計 | 洗浄しやすい構造でないと食品工場には置けない |
| 店内厨房は最後 | スーパーのインストア厨房は品目が多く場所も狭い。導入は最も遅れる |

> ポイント：**自動化できない工程が残るかぎり、その工程は冷凍食品に外注される**。
> 盛り付けだけは人がやるとしても、揚げる・煮る・炒めるを冷凍品に置き換えれば人は減る。
> ロボット化と業務用冷凍食品は、どちらも**「人手不足への回答」という同じ需要を取り合っている**。

## 6. 販路の多様化 ― 冷凍自販機と直売所型の専門店

冷凍食品の売り場が「スーパーの冷凍ケース」の外へ広がっている。

- **冷凍自動販売機**：サンデン・リテールシステムの「ど冷えもん」、
  富士電機の「FROZEN STATION」（標準設定で70個収納）などが普及。
  屋外設置が可能で、24時間365日の無人販売ができる。
- **外食チェーンの直売所型店舗**：リンガーハットは長崎ちゃんぽんの冷凍食品を
  24時間購入できる自販機設置型店舗を2022年8月から展開しており、
  八王子に国内3店舗目を開設したと報じられている。
- **企業の福利厚生向け**：日清製粉ウェルナなどが、従業員向け食事提供として
  冷凍自販機の導入を提案している。社食を持てない企業の代替になる。

経済的な意味は明確である。**冷凍は「機械が温度を保つかぎり品質が落ちない」ため、
無人販売と相性がよい**。常温弁当や惣菜では消費期限の管理が難しく、同じことができない。
温度という物理条件が、そのまま販売チャネルの自由度になっている。

同時に、冷凍専門店・自販機・ECは**「棚の取り合いから逃げる」手段**でもある。
スーパーの冷凍ケースは面積が限られ、常温棚以上に競争が厳しい。
自社の売り場を持てば、そこは自社商品だけで埋められる。

## 7. 2027年4月からの飲食料品の消費税1% ― 中食と外食の線引きが焦点に

2026年9月15日の閣議決定により、**2027年4月1日から2029年3月31日までの2年間、
飲食料品の消費税率を8%から1%に引き下げる方針**が示された（実施には法改正が必要）。

この分野にとっての論点は、**「中食は対象、外食は対象外」という境界**である。

```
【軽減税率と同じ線引きが、そのまま効いてくる】

  対象になる（飲食料品）            対象外（外食）
  ──────────────────                ──────────────
  ・冷凍食品（スーパー・EC・自販機）   ・レストランでの飲食
  ・スーパー／CVSの惣菜・弁当         ・フードコートでの飲食
  （持ち帰り＝テイクアウト）          ・店内のイートインスペース利用

  → 同じ弁当でも「持ち帰り」と「店内で食べる」で税率が変わる
  → 中食・冷凍食品は 8% → 1% の恩恵を受ける側
  → 外食は据え置き。相対的な価格差が7ポイント開く
```

仮にこの方針どおり施行されれば、**中食・冷凍食品は外食に対して価格面でさらに有利になる**。
すでに人件費と時間という面で外食から需要を奪ってきた流れが、税制面からも後押しされる形になる。

ただし注意点も多い。

- 2026年9月時点では**大綱の閣議決定段階**であり、施行には法改正が要る。
  対象品目の細部（外食・テイクアウトの扱い、イートインの判定など）は今後の法案審議で固まる。
- 店頭価格が下がる余地が生まれるため、**小売がメーカーに値下げ（または値上げの見送り）を
  求める交渉材料**にもなりうる。値上げの「窓」が開くと同時に、綱引きの場も生まれる。
- 2029年4月の税率戻りに向けて、駆け込みと反動という需要変動が起きる可能性がある。

最新は財務省・国税庁の公表で確認すること。
（→ [総合食品⑤ 直近トピック](../01_総合食品/05_直近トピック_2026.md) 第2章に制度の全体像）

## 8. 全体の構図

2026年9月時点で、この分野は次のような姿にある。

1. **市場は金額で過去最高、数量は緩やかな回復**。冷凍食品の生産額8,577億円、
   惣菜市場11兆7,075億円はいずれも過去最高だが、伸びの相当部分は価格改定である。
   数量は2023〜2024年に落ち込み、2025年にようやくプラスへ戻った。
2. **値上げの理由が「原料」から「包材・人件費・物流・電気代」へ移った**。
   相場は戻ることがあるが、これらは戻らない。今回の価格水準は定着する可能性が高い。
3. **人手不足が需要と供給の両方に効いている**。需要側では業務用冷凍食品を押し上げ、
   供給側では冷凍食品の企業数（326社）・工場数（404工場）を減らし続けている。
4. **競合が物流で手を組む段階に入った**。大手5社の共同物流検討は、
   冷凍物流のコストが1社では支えきれなくなったことの表れである。
5. **2027年4月の飲食料品1%は、中食・冷凍食品に追い風になりうる**。
   外食が対象外なら、中食との価格差はさらに開く。ただし法改正待ちで、細部は未確定。

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **国内消費量（冷凍食品）** | 日本冷凍食品協会の定義で「国内生産量＋冷凍野菜輸入量＋調理冷凍食品輸入量」の合計。輸入は会員社分のみのため実際はこれを上回るとされる |
| **ワンプレート商品** | 主食・主菜・副菜が1つの容器で完結する商品。冷凍・惣菜の両方で伸びている |
| **2024年問題** | トラック運転者の時間外労働上限規制（2024年4月施行）による輸送力不足。冷凍物流はとくに影響が大きい |
| **CLO（物流統括管理者）** | 改正物流効率化法で、一定規模以上の荷主に選任が義務づけられた役員級の物流責任者。2026年4月施行 |
| **共同物流** | 複数社が保管・配送を共有し、積載率と安定性を高める取り組み。冷凍食品大手5社が検討を進める |
| **軽減税率の境界（中食と外食）** | 持ち帰りは飲食料品（軽減対象）、店内飲食は外食（対象外）という線引き。2027年4月からの1%措置でも同じ境界が焦点になる |
| **ティーチング** | 産業用ロボットに動作を教え込む作業。多品種少量の惣菜工場では、この手間が自動化の障壁になっていた |
