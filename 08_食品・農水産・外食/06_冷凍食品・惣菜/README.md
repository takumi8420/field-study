- 大分類: 食品・農水産・外食

## このフォルダの読み方

このフォルダは、**「家で食べる1食を、誰が作るか」という取り合い**を扱う。

冷凍食品と惣菜は、スーパーの中では隣り合った売場にある。
しかし商売としては**正反対の性格**を持つ。
冷凍食品は賞味期限12〜18か月で、売れ残っても在庫として持てる代わりに、
−18℃を維持する冷凍倉庫代と電気代を毎日払い続ける。
惣菜は消費期限が当日中で、夕方に売れ残れば値引きか廃棄しかない代わりに、
できたての温度と匂いという冷凍には出せない武器を持つ。

> **この分野を理解する最短の問いは「そのコストを、在庫で払うか、廃棄で払うか」である。**

さらに冷凍食品の内側にも、**家庭用と業務用というまったく別の商売**が同居している。
家庭用はスーパーの冷凍ケースの棚を取るブランド商売。
業務用は外食・給食の厨房から調理工程を引き取る設備代替の商売。
数量では業務用が過半（51.7%）、金額では家庭用が過半（52.0%）という「ねじれ」が、
この二重構造をよく表している（2025年、日本冷凍食品協会）。

本フォルダは [総合食品](../01_総合食品/README.md) の基礎
（損益構造・値決めとリベート・商品開発・海外展開）を前提にしている。
建値やリベート、1/3ルール、値上げの実務といった共通ルールはそちらを先に読んでほしい。

## 1. 業界の定義・範囲

- **冷凍食品** ＝ ①前処理してあり、②急速凍結し、③適切に包装し、④−18℃以下で流通・保管する食品
  （日本冷凍食品協会の定義）。家庭用と業務用に大きく分かれる。
- **惣菜・中食** ＝ 調理済みの食品を買って帰り、家や職場で食べるための食品と、その市場。
  弁当・おにぎり・惣菜・調理麺・調理パン・サラダなど。

```
【「1食」をめぐる3つの領域と、本フォルダの位置】

              調理する人    食べる場所    本フォルダとの関係
  ─────────────────────────────────────────────────────────
  内食         自分         家           冷凍食品（家庭用）はここを助ける
  ★中食★      事業者       家・職場      ★本フォルダの主戦場★
  外食         事業者       店           業務用冷凍食品の販売先／中食の競合
  ─────────────────────────────────────────────────────────

  冷凍食品はこの3領域すべてに入り込む「横断的な商品カテゴリ」であり、
  中食は「業態としての市場」。定義の軸が違うことに注意。

  境界の引き方：
   ・冷凍の原料（冷凍野菜・冷凍水産物）    → 素材寄り。11_水産、12_農業
   ・チルド（0〜10℃）の加工品             → 別の温度帯。日配品として扱う
   ・弁当チェーン・惣菜専門店の店舗経営     → 20_中食・弁当（小売型の見方）
   ・給食・社食の受託運営                  → 21_給食・フードサービス
```

## 2. 市場規模と成長性

| 指標 | 数値 | 年・出典 |
| --- | --- | --- |
| 冷凍食品 国内生産額（工場出荷額） | **8,577億円**（前年比 106.4%）。過去最高 | 2025年。日本冷凍食品協会（2026年4月16日 速報） |
| 冷凍食品 国内生産量 | **1,574,172トン**（102.4%） | 同上 |
| 冷凍食品 国内消費量 | **3,029,325トン**（103.6%）。**初の300万トン超** | 同上 |
| 同 消費金額 | **1兆3,614億円**（104.1%） | 同上 |
| 国民1人あたり年間消費量 | **24.6kg**（+1.0kg） | 同上 |
| 冷凍野菜の輸入量 | **1,224,678トン**（104.9%）／3,343億円。統計開始以来最高 | 2025年。財務省貿易統計ベース、同上 |
| 冷凍食品の工場数／企業数 | **404工場**（97.8%）／**326社**（95.6%） | 同上。10年以上減少が続く |
| 惣菜（中食）市場規模 | **11兆7,075億円**（103.7%）。過去最高 | 2025年。日本惣菜協会（2026年4月14日） |
| 同 20年間の拡大率 | **2006年比 149%** | 同上 |
| 外食・中食合計 | 約 **22.84兆円**（+3.3%、2019年比+8.3%） | 2025年見込み。サカーナ・ジャパン（Circana Japan）推計 |

成長性の読み方。

- **金額は過去最高、数量は緩やかな回復**。冷凍食品の生産量は2023年（96.7%）・2024年（99.5%）と
  2年続けて減り、2025年にようやくプラスへ戻った。金額の伸びの相当部分は価格改定である。
- **中食は人口減少下で伸びてきた例外的な内需市場**。2006年比149%。
  伸びの源泉は景気ではなく、単身世帯・共働き世帯・高齢世帯の増加という世帯構造の変化。
- **冷凍食品は輸入依存が大きい**。冷凍野菜の輸入量122万トンは国内生産量157万トンの約8割にあたる。
  中国・アメリカが主な調達先で、為替と現地コストの影響を受ける。
- **供給側は集約が進む**。冷凍食品の企業数は326社まで減り、前年比95.6%。
  設備投資と省人化に耐えられる規模の会社に寄っている。

## 3. バリューチェーン（川上 → 川下）

```
【冷凍食品と惣菜は、同じ売場で別の流れを持つ】

 ■ 冷凍食品
   原料（国産・輸入） ─▶ 工場（急速凍結） ─▶ 冷凍倉庫 ─▶ 冷凍配送 ─▶ 小売／自販機／EC
                          （設備投資）      （在庫で持つ）  （−18℃）       │
                                │                                        └▶ 家庭
                                └──────────▶ 卸・外食本部・給食会社（業務用）

 ■ 惣菜（インストア）
   原料 ─▶ 店の厨房（当日製造） ─▶ 店の売場 ─▶ 当日中に売り切る
                                       │
                                       └─ 売れ残り → 値引き → 廃棄（その日のうちに）

 ■ 惣菜（ベンダー製造：コンビニ型）
   原料 ─▶ 専用工場（1社専属） ─▶ 配送センター ─▶ 1日2〜3便 ─▶ 店の棚 ─▶ 期限切れ廃棄

 【付加価値がどこに集まるか】
   冷凍食品：工場（凍結技術）と冷凍倉庫（在庫を持てる力）
   惣菜　　：売場（作りたてと立地）と需要予測（廃棄を減らす力）
```

| 段階 | 粗利率の目安 | 経済的な特徴 |
| --- | --- | --- |
| 冷凍食品メーカー（家庭用） | 高め | ブランドと棚で決まる。ただし特売・リベートで削られる |
| 冷凍食品メーカー（業務用） | 低い | 相対交渉。数量は安定するが粗利は薄い |
| 冷凍倉庫・低温物流 | 中 | 装置産業。電気代と稼働率で決まる。ニチレイのように事業として切り出せる |
| 惣菜（インストア） | 高い（食品スーパー内では上位） | ただし人件費18〜25%、廃棄・値引き3〜8%が相殺する |
| 惣菜ベンダー | 低い | 1社依存。数量は安定するが価格決定力がない |

（構造理解のための概数。企業・業態により幅が大きい）

## 4. 主要プレイヤーとシェア

| 企業 | 立ち位置 | 特徴 |
| --- | --- | --- |
| **ニチレイ** | 冷凍食品＋低温物流の両輪 | 2026年3月期 売上高 約7,161億円（+2.0%）、純利益273億円（+10.5%）と報じられる。**低温物流（ニチレイロジグループ）が売上3,000億円突破**。2026年4月に加工食品と水産・畜産を「食品事業」へ統合 |
| **味の素冷凍食品** | 家庭用ブランドの筆頭 | 味の素グループ。「ギョーザ」が象徴商品。**「水なし・油なし」で焼ける**など調理工程を削る設計が得意 |
| **ニッスイ** | 水産原料からの一貫体制 | 冷凍食品＋練り製品。漁獲・養殖から加工まで垂直統合。欧米・アジア・南米に展開 |
| **マルハニチロ** | 水産最大手の加工部門 | 原料調達から製造・販売までの一貫体制。水産事業と冷凍食品が相互に効く |
| **テーブルマーク** | 主食系（麺・米飯・パン）特化 | JTグループ。1974年発売の冷凍「さぬきうどん」が**冷凍うどんでトップシェア**とされる |
| 日清食品グループ／ニップン／ケイエス冷凍食品ほか | カテゴリ特化 | 冷凍パスタ、冷凍米飯、肉だんごなど品目単位の勝負 |
| **プレナス／オリジン東秀** | 弁当チェーン | 店舗の経済性で動く。立地・家賃・人件費が勝負 |
| **ロック・フィールド／柿安本店** | デリカ専門店 | 百貨店・駅ビル中心。高単価・高品質 |
| **わらべや日洋ホールディングスほか** | CVSベンダー | 特定チェーン向け専用工場。数量は安定するが**1社依存**が構造的弱点 |
| **カネ美食品ほか** | スーパー系デリカ | 惣菜売場の受託運営。母体の店舗数が売上規模を決める |
| 食品スーパー各社（インストア） | 自社売場で自社製造 | 惣菜は粗利と集客の両方を担う。店内厨房を残す戦略的理由がある |

**シェアの見方**：冷凍食品も惣菜も、「業界全体のシェア」はほとんど意味を持たない。
冷凍食品は**品目ごとに勝者が違い**（うどんはテーブルマーク、餃子は味の素冷凍食品）、
惣菜は**業態ごとに市場が分かれている**（CVS 30.8%／食料品スーパー 30.3%／専門店 27.4%）。
シェアを語るなら品目または業態を必ず限定する。

## 5. 収益モデル・コスト構造

```
【冷凍食品メーカーと惣菜（インストア）の原価表の違い】

 ■ 冷凍食品メーカー（売上100のイメージ）   ■ 惣菜インストア（売上100のイメージ）
   原材料費      40〜50                     原材料費      40〜50
   包装資材費     5〜8  ◀値上げの主因        人件費       18〜25 ◀★最大の特徴
   工場人件費     5〜7                       廃棄・値引き   3〜8  ◀★惣菜固有
   償却・光熱     5〜8  ◀冷凍は電気代が重い   容器・包材     3〜5
   ────────────────                        光熱費         2〜4  ◀フライヤー・ケース
   粗利         30前後                      ────────────────
    └ 販促・リベート                         残り（店の貢献利益）
      物流費（冷凍車・冷凍倉庫） ◀★重い
   ────────────────
   営業利益      5〜8

 ※ 構造理解のための概数。統計値ではない。
```

| 論点 | 中身 |
| --- | --- |
| **冷凍は電気代と物流費への感応度が高い** | −18℃を24時間維持する。倉庫も車も棚も冷却設備で、そのすべてに電気代と償却が乗る |
| **在庫で払うか、廃棄で払うか** | 冷凍食品は賞味期限12〜18か月で在庫を持てるが保管料がかかる。惣菜は当日で売り切るが廃棄が出る |
| **惣菜は人件費が原価の柱** | 加工食品メーカーの工場人件費5〜7%に対し、惣菜は18〜25%。最低賃金の上昇が直撃する |
| **業務用は薄利・安定、家庭用は厚利・変動** | 業務用は契約ベースで数量が読めるが粗利が薄い。家庭用は粗利が厚いが特売と棚替えで振れる |
| **値上げは効くまで時間がかかる** | 事前通告 → 交渉 → 改定 → 効果まで半年〜1年。総合食品と同じ（→ [総合食品②](../01_総合食品/02_値決めと交渉.md)） |

## 6. 競争要因（KSF）と参入障壁

| KSF | 中身 |
| --- | --- |
| **凍結・再加熱の設計力** | 急速凍結で氷結晶を細かくし、電子レンジやスチコンで元に戻る商品を作る技術。レシピより真似されにくい |
| **コールドチェーンへのアクセス** | 冷凍倉庫と冷凍車を確保できなければ、作れても届けられない。自社で持てば重く、外に払えば高い |
| **生産規模と稼働率** | 凍結設備は高額な装置。稼働率が落ちれば単位原価が跳ねる |
| **棚（家庭用）／実績（業務用）** | 冷凍ケースは常温棚より面積が限られる。業務用は供給を止めない実績がないと採用されない |
| **需要予測の精度** | 冷凍は在庫日数、惣菜は廃棄ロス率。どちらも予測精度がそのまま利益になる |
| **人時生産性（惣菜）** | 惣菜の利益は粗利率ではなく「廃棄ロス率 × 人時生産性」で決まる |

**参入障壁**は許認可ではない（営業許可とHACCP対応は要るが免許制ではない）。
実質的な壁は **①凍結設備への投資、②コールドチェーンの確保、③棚または取引実績** の3つ。
とくに②は、冷凍食品を「作れるのに売れない」状態を生む最大の要因になる。

| 制度 | 内容 | この分野への影響 |
| --- | --- | --- |
| **食品衛生法／HACCP** | 2021年6月から原則すべての食品事業者にHACCPに沿った衛生管理を義務化 | 惣菜の店内厨房を含め記録・管理の負担。小規模事業者の設備投資要因 |
| **冷凍食品の自主的取扱基準** | 日本冷凍食品協会の認定制度。−18℃以下の保管・輸送、表示のルール | 「認定証マーク」として消費者向けの品質担保に使われる |
| **食品表示法** | 原材料、アレルゲン、栄養成分、調理方法（加熱の有無）の表示義務 | 冷凍食品は「加熱してあるか」「解凍方法」の表示が商品設計と直結 |
| **フロン排出抑制法** | 業務用冷凍冷蔵機器の点検義務、冷媒の転換 | 冷凍倉庫・冷凍ケースの更新投資。自然冷媒（アンモニア／CO2）への移行 |
| **改正物流効率化法** | 2026年4月に特定事業者の指定・CLO（物流統括管理者）選任義務が施行 | 大手冷凍食品メーカーは荷主として該当。共同物流の推進要因 |
| **トラック運転者の時間外労働上限規制** | 2024年4月施行（2024年問題） | 冷凍の長距離輸送力が細った。大手5社の共同物流検討の背景 |
| **食品ロス削減推進法／納品期限の緩和** | 1/3ルールの見直し（1/3 → 1/2）を農水省が業界に働きかけ | 冷凍は影響が小さいが、チルド・日配は返品・廃棄の負担が減る |
| **軽減税率／飲食料品の消費税引下げ** | 2026年9月15日閣議決定により、**2027年4月〜2029年3月の2年間、飲食料品を8%→1%**とする方針（法改正が必要） | **中食・冷凍食品は対象、外食は対象外**。中食と外食の価格差が開く（→ [④](04_直近トピック_2026.md) 第7章） |

## 8. 最近のトピック

詳細は → [④ 直近トピック（2026年9月時点）](04_直近トピック_2026.md)

1. **冷凍食品の消費量が初の300万トン超**（2025年、2026年4月発表）。生産額8,577億円も過去最高。
   ただし家庭用は数量+2.8%に対し金額+9.6%で、伸びの多くは価格と単価の上昇。
2. **惣菜市場は11兆7,075億円で過去最高**（2025年）。CVSの伸びが+2.3%と鈍る一方、
   食料品スーパー(+4.9%)と総合スーパー(+4.7%)が市場を牽引。米・生鮮の値上がりが追い風になった。
3. **値上げの理由が「原料」から「包装資材」へ**。2026年は2〜4月と9〜10月の2波。
   ニッスイ（家庭用冷食 約2〜17%）、テーブルマーク（約3〜20%）、味の素冷凍食品（16品を5〜8%）。
4. **競合5社が物流で協働**。味の素冷凍食品・テーブルマーク・ニチレイ・ニッスイ・マルハニチロが
   共同物流の枠組み拡大を検討。冷凍物流が1社で支えきれない水準に来たことの表れ。
5. **2027年4月の飲食料品消費税1%**は中食・冷凍食品に追い風になりうる。
   外食は対象外のため価格差が開く。ただし大綱の閣議決定段階で、法改正と細部の確定はこれから。

## 9. 用語メモ

各ノート末尾に詳しい用語メモがある。ここでは最重要の7つ。

| 用語 | 意味 |
| --- | --- |
| **急速凍結** | −1℃〜−5℃の「最大氷結晶生成帯」を30分程度で通過させる凍らせ方。氷結晶が細かくなり細胞が壊れにくい。冷凍食品の品質を決める最重要工程 → [①](01_冷凍食品という産業.md) |
| **コールドチェーン** | 生産から消費まで低温を切らさずつなぐ物流・保管の仕組み。冷凍は−18℃以下。どこか1か所でも切れると品質は戻らない → [①](01_冷凍食品という産業.md) |
| **中食（なかしょく）** | 調理済み食品を買って帰り、家や職場で食べること。内食と外食の中間。市場規模は11兆7,075億円（2025年） → [②](02_惣菜・中食の市場.md) |
| **日配品（にっぱいひん）** | 毎日・高頻度で配送される日持ちしない商品。惣菜・弁当・牛乳・豆腐・パンなど。当日製造・当日販売が前提 → [②](02_惣菜・中食の市場.md) |
| **インストア／アウトパック** | 店内厨房で作るか、工場で作って店では並べるだけか。作りたて感と単位原価がトレードオフになる → [②](02_惣菜・中食の市場.md) |
| **人時生産性（にんじせいさんせい）** | 従業員1人が1時間で生み出す粗利益。惣菜売場の最重要指標。惣菜の利益は「廃棄ロス率 × 人時生産性」で決まる → [②](02_惣菜・中食の市場.md) |
| **ワンプレート商品** | 主食・主菜・副菜が1つの容器で完結する商品。個食化とタイパ志向で伸び、冷凍と惣菜が正面から競合する領域 → [③](03_競争と変化.md) |
