# ② 惣菜・中食の市場

このノートで分かること：**11兆円を超えた中食市場**が、外食でも内食でもない場所で
どう伸びたのか。業態（スーパー／コンビニ／専門店／弁当店）でまるで違う商売であること。
そして惣菜が **「当日作って当日売り切る」** 日配ビジネスであるがゆえに抱える廃棄ロスと人件費の重さ。

## 1. 結論：中食は「内食から手間だけを取り出した市場」である

> **中食（なかしょく）** ＝ 調理済みの食品を買って帰り、家や職場で食べること。
> レストランで食べる「外食」と、材料から作る「内食（ないしょく）」の中間。
> 弁当・惣菜・おにぎり・調理パン・サラダ・サンドイッチなどが該当する。

```
【内食・中食・外食の三分法】

              調理する人     食べる場所     払っているもの
  内食        自分          家             材料費
   │
   │  ← 手間を外に出す（これが中食の正体）
   ▼
  中食        事業者        家・職場        材料費 ＋ 調理の手間
   │
   │  ← 場所とサービスも外に出す
   ▼
  外食        事業者        店             材料費 ＋ 手間 ＋ 場所 ＋ 接客

  ※ 中食は「外食が安くなったもの」ではない。
     内食から調理の手間だけを切り出した市場であり、比較対象は
     「自分で作る場合の時間と失敗と食材の余り」である。
```

だから中食の需要は、外食の景気ではなく**世帯のかたち**で決まる。
単身世帯と共働き世帯が増えるほど、「1人分を作ると食材が余る」「作る時間がない」という
内食の非効率が表に出て、中食に流れる。この流れは景気に左右されにくく、
**リーマンショックとコロナ期を除けばほぼ一貫して右肩上がり**だった。

## 2. 市場規模 ― 2025年に11兆7,075億円

| 指標 | 数値 | 年・出典 |
| --- | --- | --- |
| 惣菜（中食）市場規模 | **11兆7,075億円**（前年比 **103.7%**） | 2025年。日本惣菜協会（2026年4月14日発表） |
| 同（前年） | 11兆2,882億円（102.8%） | 2024年。同協会 |
| 同（2年前） | 10兆9,827億円 | 2023年。同協会 |
| 20年間の拡大率 | **2006年比 149%** | 同協会。日本の内需型市場としては例外的 |
| 外食・中食合計の市場規模 | 約 **22.84兆円**（前年比 +3.3%、2019年比 +8.3%） | 2025年見込み。サカーナ・ジャパン（Circana Japan）推計 |
| 料理品小売業（持ち帰り弁当店・惣菜店に限定した集計） | 約 **7.6兆円** | 2023年。日本フードサービス協会「外食産業市場規模推計」 |

> 注意：**「中食市場は何兆円か」は集計の切り方で倍近く変わる**。
> 日本惣菜協会の11.7兆円は、スーパーやコンビニの店内惣菜・弁当・おにぎり・調理パンまで含む広い定義。
> 日本フードサービス協会の「料理品小売業」約7.6兆円は、惣菜店・弁当店という業態に絞った集計。
> 数字を引用するときは、必ずどちらの定義かを添える必要がある。

成長の読み方も、冷凍食品と同じ注意がいる。2024→2025年の +3.7% は
**原材料高・人件費高を受けた価格改定（値上げ）がかなりの部分を占める**。
日本惣菜協会自身も、2025年は「価格の見直しが進み堅調に推移した」と説明している。
点数（買われた個数）が同じ比率で伸びているわけではない。

## 3. 業態別 ― 同じ「惣菜」でも商売がまったく違う

| 業態 | 2025年 市場規模 | 構成比 | 前年比 | 商売の性格 |
| --- | --- | --- | --- | --- |
| **CVS（コンビニ）** | 3兆6,044億円 | 30.8% | 102.3% | 最大だが伸びが鈍い。専用工場（ベンダー）に製造を委託し、1日3便で運ぶ |
| **食料品スーパー** | 3兆5,522億円 | 30.3% | **104.9%** | 市場を牽引。店内厨房（インストア）で作る。生鮮と一体運営 |
| **惣菜専門店** | 3兆2,020億円 | 27.4% | 104.2% | 弁当チェーン、デリカ専門店、駅ナカ。ブランドと立地で勝負 |
| **総合スーパー（GMS）** | 1兆113億円 | 8.6% | **104.7%** | 一度落ちたが再び伸びた。食品フロアの集客装置 |
| **百貨店** | 3,375億円 | 2.9% | 99.3% | デパ地下。高単価だが市場は縮小 |
| 合計 | **11兆7,075億円** | 100% | 103.7% | |

（日本惣菜協会「2025年惣菜市場規模」2026年4月14日発表）

```
【製造の場所が違う ＝ コスト構造が違う】

  ■ インストア（スーパー・GMS・百貨店・一部専門店）
    店の厨房 ──▶ 店の売場
    ・作った場所で売る。輸送なし
    ・作りたてを訴求できる／揚げたての匂いが集客になる
    ・店ごとに調理人が要る（労働集約）
    ・売れ残りは その店の廃棄ロス

  ■ アウトパック／ベンダー製造（コンビニ・一部スーパー）
    専用工場 ──▶ 配送センター ──▶ 店の棚
    ・1か所でまとめて作るので単位原価が下がる
    ・1日2〜3便の多頻度配送が必須（賞味期限が短いため）
    ・店側に調理人が要らない
    ・売れ残りは 店（加盟店）の負担になりやすい ← FC会計の論点

  ■ セントラルキッチン（弁当チェーン・給食）
    自社工場で下処理 ──▶ 店で最終調理
    ・技能を工場に集約し、店は誰でも回せる設計にする
```

業態ごとの勘所を1行ずつ。

- **コンビニ**：市場規模は最大だが、2025年は+2.3%と全業態で最も伸びが低い。
  店舗数が飽和し、客数が伸びない中で単価だけが上がっている構図
  （→ [コンビニエンスストア](../../07_小売・流通/01_コンビニエンスストア/README.md)）。
- **食料品スーパー**：惣菜は**粗利率が生鮮より高く、買い物客の滞在時間と客単価を押し上げる**ため、
  各社が最も投資している売場。米や生鮮の価格が上がるほど「作るより買うほうが安い」局面が生まれる
  （→ [食品スーパー① 生鮮が決める商売](../../07_小売・流通/03_食品スーパー/01_生鮮が決める商売.md)）。
- **惣菜専門店**：弁当チェーン（ほっともっと等）、デリカ（ロック・フィールド等）、
  駅ナカ・駅ビルのテナント。立地に払う家賃が重く、**外食に近い店舗の経済性**で動く。
- **百貨店**：デパ地下は単価も粗利も高いが、母体の百貨店そのものが縮んでいるため市場も微減が続く。

## 4. カテゴリ別 ― 惣菜の半分近くは「ごはんもの」

日本惣菜協会は惣菜を5つに分類している。

| カテゴリ | 中身 | 構成比（2023年） |
| --- | --- | --- |
| **米飯類** | 弁当、おにぎり、寿司、丼、チャーハン | **43.9%** |
| **一般惣菜** | 唐揚げ、コロッケ、サラダ、煮物、フライ | **34.9%** |
| 調理麺 | 冷し中華、焼そば、うどん、パスタ（容器入り） | 9.2% |
| 袋物惣菜 | 常温・チルドの袋入り惣菜（煮豆、きんぴら等） | 7.1% |
| 調理パン | サンドイッチ、惣菜パン | 5.0% |

（構成比は「2024年版惣菜白書」ダイジェスト版に基づく2023年の数値。最新は「2026年版惣菜白書」（2026年6月1日発刊）で確認）

> ポイント：**中食市場の本体は「弁当とおにぎり」である**。
> 惣菜というと揚げ物やサラダを思い浮かべるが、金額の4割以上は米飯類。
> つまり中食は「おかずを買い足す市場」ではなく、**1食まるごとを置き換える市場**として大きくなった。
> コンビニと食料品スーパーが二強になっているのも、
> 「1食分を買って帰る」場所として最も使われているからである。

## 5. 日配品の経済学 ― 「当日作って当日売り切る」という制約

> **日配品（にっぱいひん）** ＝ 毎日または高頻度で店に配送される、日持ちのしない商品。
> 惣菜・弁当のほか、牛乳、豆腐、パン、納豆などが該当する。

惣菜の消費期限は、インストア惣菜で当日中、コンビニ弁当でも製造から十数時間〜1日程度。
この短さが、冷凍食品とは正反対の経済構造を作る。

```
【1日の売れ方と、値引きのタイミング（スーパー惣菜の典型）】

 売上
  ▲
  │                                    ┌─┐  ← 夕方ピーク（17〜19時）
  │                          ┌─┐      │ │
  │        ┌─┐              │ │      │ │   ┌─┐ ← 20時以降
  │  ┌─┐  │ │  ┌─┐  ┌─┐  │ │      │ │   │ │   ここから
  │  │ │  │ │  │ │  │ │  │ │      │ │   │ │   3割引 → 半額
  └──┴─┴──┴─┴──┴─┴──┴─┴──┴─┴──────┴─┴───┴─┴──▶ 時刻
    10   11   12   13   14  15〜16    17〜19   20〜21    閉店

  作る量を決めるのは「開店前」。売れ方が分かるのは夕方。
  ズレた分は、値引き（粗利を削る）か廃棄（全額損）で処理するしかない。
```

| 論点 | 中身 | なぜそうなるか |
| --- | --- | --- |
| **廃棄ロス** | 売れ残りは原則その日に廃棄。スーパー惣菜で売価ベース数%、品目によっては10%近くになる場合もあるとされる | 消費期限が当日中。翌日に回せない |
| **値引き（見切り）** | 夕方以降の3割引・半額。粗利を削って廃棄をゼロに近づける | 廃棄（100%損）より値引き（一部回収）のほうがマシという計算 |
| **欠品ロス** | 夕方に品切れすると売上機会を失い、客の店離れも招く | 惣菜は「あると思って来る」商品。欠品の機会損失は数字に出ない |
| **製造は朝に集中** | 早朝から昼にかけて仕込み、夕方ピークに合わせて揚げる | 労働時間が偏り、パート採用が難しい時間帯に人が要る |
| **人件費率が高い** | 惣菜は食品製造の中でも屈指の労働集約型。手作業が多い | 形が不揃い・やわらかい・盛り付けが要る、という自動化困難な条件が揃う |
| **原価率は生鮮より低い** | 惣菜の粗利率は食品スーパーの中では高い部類 | 加工することで付加価値を乗せられる。ただし人件費と廃棄で相殺される |

> ポイント：**惣菜の利益は「粗利率」ではなく「廃棄ロス率 × 人時生産性」で決まる**。
> 粗利率が40%でも、廃棄が8%あって、人件費が売上の20%を食えば残らない。
> だから惣菜の現場改善は、味の改良よりも先に**「何を、何時に、何個作るか」の精度**に向かう。
> 需要予測AIや自動発注が惣菜売場から導入されるのは、効果が最も大きい領域だから
> （→ [フードテック③ 流通と消費のテクノロジー](../../01_注目テーマ/13_フードテック/03_流通と消費のテクノロジー.md)）。

## 6. 原料と人件費 ― 値上げが効きにくい理由

惣菜の原価は、加工食品メーカーとは構成が違う。

```
【惣菜（スーパーのインストア惣菜）売上100円のイメージ】

  売上高 100
   ├─ 原材料費 40〜50   ◀ 米・食用油・鶏肉・野菜。生鮮相場に直撃される
   ├─ 人件費   18〜25   ◀★ 加工食品メーカー（工場人件費5〜7）と桁が違う
   ├─ 廃棄・値引 3〜8    ◀★ 惣菜固有。売価で消える
   ├─ 容器・包材 3〜5    ◀ トレー・フィルム。原油連動
   ├─ 光熱費     2〜4    ◀ フライヤー・オーブン・冷蔵ケース
   └─ 残り（店の貢献利益）

  ※ 業態・企業により幅が大きい。構造の理解用の概数であり、統計値ではない。
```

ここから読み取れること。

1. **人件費が原価の柱**。最低賃金の上昇がそのまま原価上昇になる。
   加工食品メーカーが「労務費の転嫁率は30%」で苦しんでいる（→ [総合食品②](../01_総合食品/02_値決めと交渉.md)）のと同じ問題が、
   惣菜ではもっと直接的に効く。
2. **米と食用油の相場に弱い**。米飯類が金額の4割超を占めるため、**米価の上昇は惣菜の原価そのもの**。
   2024〜2026年の米価高騰局面では、弁当チェーンとコンビニが相次いで値上げに踏み切った。
3. **値上げの打ち手が限られる**。加工食品なら容量変更（実質値上げ）という手があるが、
   弁当の中身を減らすのは見た目に出るため使いにくい。結果として表示価格の改定に回りやすい。
4. **一方で、内食の値上がりが追い風にもなる**。
   日本惣菜協会は2025年について「コメや生鮮三品の価格上昇などから、特に少人数世帯では、
   作るよりも惣菜を買う方が無駄がないことも評価された」としている。
   **自炊のコストが上がると、中食の相対的な割安感が増す**という非対称がある。

## 7. ワンプレート化・個食化 ― 商品設計が変わりつつある

中食の商品トレンドは、世帯構造の変化をそのまま映している。

| 変化 | 中身 | 商品への影響 |
| --- | --- | --- |
| **個食化** | 家族がそろって同じものを食べない。1人分を買う | 少量パック、1人前の惣菜カップ、小容量の弁当 |
| **ワンプレート化** | 主食＋主菜＋副菜が1つの容器で完結 | 「これ1つで1食」商品。冷凍食品でも急速に増えている |
| **高齢者需要** | 少量・やわらかい・塩分控えめ | 高齢者向け弁当、配食サービス |
| **タイパ（時間対効果）志向** | 買う・作る・片づける時間を減らしたい | 容器のまま食べられる、洗い物が出ない設計 |
| **健康志向** | たんぱく質量、野菜量、カロリー表示 | サラダチキン、高たんぱく惣菜、栄養成分の前面表示 |

> ポイント：**ワンプレート化は中食と冷凍食品の主戦場が重なる場所**である。
> 「主食＋おかずが1つの容器で完結」という設計は、惣菜でも冷凍食品でも同じ要求から生まれた。
> 違いは、惣菜が「今日中に食べる」前提なのに対し、冷凍は「いつでも食べられる」前提であること。
> 冷凍食品協会の2025年統計では「ワンプレート」の出荷が2万トン・135億円と報じられており、
> 冷凍側からの侵食が数字に出始めている（→ [③ 競争と変化](03_競争と変化.md)）。

## 8. 惣菜製造の労働集約性 ― 自動化が最も遅れた食品分野

惣菜工場・店内厨房は、食品産業のなかでも自動化が難しい領域として知られる。

| 自動化を阻む条件 | 具体例 |
| --- | --- |
| **形が不揃い** | 唐揚げ、コロッケ、煮物。ひとつずつ大きさが違う |
| **やわらかい・崩れる** | ポテトサラダ、卵焼き、麺類 |
| **盛り付けに見栄えが要る** | 弁当は「彩り」が商品価値。位置と向きが決まっている |
| **多品種少量** | 1ラインで1日に何十品目も切り替える。段取り替えが頻繁 |
| **衛生制約** | 洗浄しやすい構造でないと設備を入れられない |

経済産業省・農林水産省の支援のもとで日本惣菜協会が進めてきた
**惣菜盛付ロボットの開発**は、2024年に「盛付の全工程をロボット化し現場実装に成功」と報じられた。
麺惣菜の盛付工程を統合したロボットシステムなど、
**人が手でつかんで容器に入れる**という工程そのものを置き換える方向に進んでいる。

ただし導入のハードルは高い。投資額に対して回収年数が長く、
多品種少量の現場では段取り替えがロボット化の効果を打ち消してしまう。
結果として、**自動化が進むのは「1品目を大量に作るベンダー工場」から**で、
多品種を少量ずつ作るスーパーの店内厨房はいちばん最後になる。

> ポイント：**惣菜業界の人手不足は、そのまま業務用冷凍食品の追い風になる**。
> 盛り付けだけは人がやるとしても、揚げる・煮る・炒めるという工程を
> 冷凍品に置き換えれば、厨房の人数は減る。
> 「自動化できないから冷凍品を使う」という選択が、
> 中食の現場で静かに広がっている（→ [③ 競争と変化](03_競争と変化.md)）。

## 9. まとめ：中食を理解する3つの鍵

1. **中食は内食から手間を切り出した市場**。だから伸びを決めるのは景気ではなく世帯構造。
   2006年比149%という拡大は、単身・共働き・高齢世帯の増加そのものである。
2. **業態で商売が違う**。コンビニ＝ベンダー製造と多頻度配送、スーパー＝インストアと生鮮一体、
   専門店＝立地と家賃。同じ「惣菜」でも原価表の形が違う。
3. **利益は廃棄ロスと人時生産性で決まる**。日配品であることが、
   在庫を持てる冷凍食品との最大の違いであり、最大の弱点でもある。

| **内食（ないしょく）** | 材料を買って自分で調理して家で食べること |
| **日配品（にっぱいひん）** | 毎日または高頻度で配送される日持ちしない商品。惣菜・弁当・牛乳・豆腐・パンなど |
| **インストア惣菜** | 店舗内の厨房で製造し、その店で売る惣菜。作りたてが訴求できるが、店ごとに人が要る |
| **アウトパック** | 工場やセンターで製造・包装し、店では並べるだけの惣菜。単位原価は下がるが作りたて感は出ない |
| **ベンダー** | コンビニ等の専用商品を製造する協力工場・メーカー。1社の商品を1日数便で供給する |
| **セントラルキッチン** | 複数店舗分の下処理・調理を集約する自社工場。店の作業を最小化する仕組み |
| **廃棄ロス（フードロス）** | 売れ残って廃棄する商品。売価ではなく原価で損失が出るが、その分の売上機会も失う |
| **見切り（値引き）** | 消費期限が近づいた商品を値下げして売り切ること。夕方以降の3割引・半額 |
| **人時生産性（にんじせいさんせい）** | 従業員1人が1時間働いて生み出す粗利益。惣菜売場の最重要指標 |
| **ワンプレート商品** | 主食・主菜・副菜が1つの容器で完結する商品。個食化とタイパ志向から伸びている |
