制度が価格を決める世界

食品・農水産・外食製粉・製糖・製油

このノートで分かること：製粉・製糖・製油の3業界は、原料の値段を自分で決められない。
しかもその決まり方が3業界でまったく違う。小麦は政府が価格を決め、砂糖は制度がお金を付け替え、
油だけが素の国際相場に晒されている。この違いが、3業界の収益の形を分けている。

1. 結論：この業界は「相場に晒されているようで、晒されていない」

製粉・製糖・製油は、原料を仕入れて、挽く・精製する・搾るだけの素材型産業である。
売上原価の6〜8割が原料費なので、常識的には「原料相場が動けば利益も激しく動く」はずだ。

ところが日本では、小麦と砂糖に国が価格に介入する仕組みが入っている。

品目 原料の入り方 価格を決めるもの 相場との距離
小麦国家貿易（政府が全量買って売る）政府売渡価格（年2回改定）遠い。6か月平均でならされ、半年遅れで来る
砂糖民間輸入だが調整金を徴収国際相場＋調整金＋国内需給中間。相場は生きているが上乗せが大きい
大豆・菜種（製油）ほぼ無関税で民間が自由に輸入シカゴ・ウィニペグ相場×為替近い。ほぼ素のまま直撃する

ポイント：同じ「原料を加工するだけの商売」なのに、小麦は制度に守られ、油は裸で相場に立っている。
この非対称が、製粉が安定高収益で、製油が薄利で振れ幅が大きい理由の大半を説明する。

3業界を同じフォルダに入れる理由は、「穀物・油糧種子を仕入れて一次加工する」という
バリューチェーン上の位置が同じだからであって、儲け方が同じだからではない。

2. 小麦：国家貿易という仕組み

2-1. 「国家貿易」とは何か

国家貿易（state trading）とは、特定の品目について国だけが輸入の窓口になる制度のこと。
日本では主要食糧（小麦・大麦）が「食糧法」（主要食糧の需給及び価格の安定に関する法律）に基づき、
農林水産省が輸入して国内の製粉会社に売り渡す形をとっている。

1995年のWTO農業協定で「輸入数量制限は禁止」となったあとも、
日本は関税化ではなく国家貿易を残した。量は制限しないが、窓口は国が握る、という形である。

2-2. 価格の決まり方

政府売渡価格は「直近6か月間の平均買付価格」＋マークアップ＋港湾諸経費で算定され、
年2回（4月期・10月期）改定される。ここに3つの仕掛けがある。

  1. 6か月平均でならす … 国際相場が1か月で急騰しても、その月の価格だけでは動かない
  2. 年2回しか変えない … 相場の変動が製粉会社に届くまで、最大で半年以上のタイムラグが出る
  3. 全社に同じ価格 … 銘柄ごとに1本の価格。大手も中堅も原料原価の出発点は同じ

マークアップとは、政府が買付価格に上乗せして取る差額のこと（かつての「輸入差益」）。
行き先は2つで、①政府の管理経費と、②国内産麦の生産振興（経営所得安定対策＝いわゆる「ゲタ」）である。

つまり、輸入小麦を使うパンや麺の消費者が、国産小麦の農家を間接的に支えている。
これが日本の小麦政策の基本構図で、砂糖の調整金制度（後述）とまったく同じ発想である。

2-3. 5つの銘柄と用途

政府が売り渡すのは5銘柄で、それぞれ用途が違う。「小麦粉」と一括りにできないのは、
たんぱく質（グルテン）の量が銘柄で違い、用途がほぼ決まってしまうからだ。

銘柄 産地 主な用途 性格
1CW（ウェスタン・レッド・スプリング）カナダパン用高たんぱく。強力粉の基幹
DNS（ダーク・ノーザン・スプリング）米国パン・中華麺用高たんぱく
HRW（ハード・レッド・ウィンター）米国パン・中華麺用中〜高たんぱく
ASW（スタンダード・ホワイト）豪州日本麺（うどん）用低たんぱく。うどん専用に近い
WW（ウェスタン・ホワイト）米国菓子用低たんぱく。薄力粉の基幹

（出典：農林水産省 輸入小麦の政府売渡価格 公表資料）

日本の小麦供給は輸入が約8割。供給先は米国 約43%、カナダ 約40%、豪州 約17%とされる
（2026年9月・農水省資料をもとにした報道ベース）。3か国にほぼ依存しているのが実情で、
この3か国のどこかで天候が崩れると、直ちに売渡価格に効いてくる。

2026年10月期の+12.0%は近年で最大級の改定である。
半年に1度しか動かないぶん、動くときは一気に動くのがこの制度の特徴でもある。

2-5. SBS方式という例外

国家貿易にも抜け道が用意されている。SBS（Simultaneous Buy and Sell＝売買同時入札）は、
実需者（製粉会社やパン会社）と輸入業者がペアで入札し、
政府は形式上の売り買いだけを通す仕組み。銘柄や品質を自分で指名して買いたいときに使う。

数量は全体からみれば限定的だが、
「デュラム小麦（パスタ用）」や特定産地の高付加価値小麦など、
画一的な5銘柄では足りない需要の受け皿になっている。

2-6. 製粉会社にとって、この制度は何を意味するか

論点 意味
原料原価が全社共通原料の仕入れ力で差がつかない。差がつくのは歩留まり・製品構成・物流
半年に1度の改定値上げ・値下げのタイミングが業界一斉。価格改定の交渉根拠が明確（「政府が上げたので」と言える）
タイムラグ相場が急騰しても半年は据え置き＝短期的には利益が守られる。逆に相場が下がっても半年は高原価
為替リスク政府が買い付けるので、製粉会社は直接の為替リスクをほぼ負わない（価格に織り込まれて来る）

製粉が食品業界の中で異例に安定した利益率を保てるのは、原料リスクの大半を制度が吸収しているから。
裏返すと、原料で勝つことができないので、競争は「製品の中身」と「装置の効率」に向かう。

3. 砂糖：糖価調整制度という所得移転

3-1. 何をしている制度か

糖価調整制度は、「砂糖及びでん粉の価格調整に関する法律」に基づき、
安い輸入糖から調整金を徴収し、それを財源に国内のてん菜・さとうきび農家と製造事業者へ交付金を出す仕組み。

国産の砂糖は、北海道のてん菜（ビート）と、沖縄・鹿児島南西諸島のさとうきびから作られる。
国際相場の粗糖より生産コストが圧倒的に高いため、放っておけば作れない。
そこで、輸入糖を使う消費者・食品メーカーから薄く広く取って、国内産地に回す。

【糖価調整制度のお金の流れ】

 海外の粗糖（原料糖）
      │  国際相場（ニューヨーク粗糖先物 など）
      ▼
 精製糖会社が輸入
      │
      ├──▶ 【独立行政法人 農畜産業振興機構（alic）】
      │      いったん売り渡し、すぐ買い戻す形をとり
      │      その差額として《調整金》を徴収
      │             │
      │             │  調整金
      │             ▼
      │      ┌────────────────────┐
      │      │  交付金として支出              │
      │      │   ・てん菜 / さとうきび生産者  │
      │      │   ・てん菜糖 / 甘しゃ糖の工場  │
      │      └────────────────────┘
      │             ▲
      ▼             │
 精製（製糖工場）   国内産糖（北海道・沖縄・鹿児島）
      │             │
      └──────┬──┘
                 ▼
          国内の砂糖市場（上白糖・グラニュー糖 …）

この「売り渡してすぐ買い戻す」という奇妙な形をとるのは、
関税ではなく国内の価格調整として制度を組んでいるためである（WTO上の整理）。

3-2. 制度の中身（2026砂糖年度＝令和8砂糖年度の数値）

指定糖調整率輸入糖から徴収する調整金の率38.14%39.32%
2次調整金一定の輸入糖にかかる追加の徴収25,613円/製品トン同額

てん菜糖への交付金単価が1年で約1.5倍に跳ねているのが目を引く。
コスト上昇と産地の経営悪化に制度が追随した形と読める。

3-3. 制度が抱える構造問題

砂糖の国内消費が減り続けているのに、支える対象は減らない。
調整金は「輸入量×率」で決まるので、消費が減れば財源そのものが細る。

  • 糖価調整制度の調整勘定は、2023砂糖年度の単年度収支が約74億円の赤字、
    累積の欠損は約640億円に達したとされる（農政審議会資料・報道ベース）
  • 2026砂糖年度（令和8砂糖年度）から、てん菜糖の交付対象数量を55万トンに設定するなど、
    支出側を絞る調整が入っている

もう一つの穴が加糖調製品である。
砂糖そのものではなく「砂糖＋ココア」「砂糖＋粉乳」のように混ぜた状態で輸入すれば、
調整金がかからない（または軽い）。この迂回が広がったため、
2018年のTPP11発効に合わせて、主要な加糖調製品にも調整金を課す措置が導入された。

制度は「守る」と同時に「抜け道を塞ぎ続ける」宿命を負う。
砂糖の制度史は、ほぼ加糖調製品との追いかけっこの歴史でもある。

3-4. 精製糖会社にとって、この制度は何を意味するか

  • 原料糖の国際相場は生きている（小麦と違い政府が価格を決めてくれるわけではない）
  • そこに調整金が固定的な上乗せとして乗る → 国内の砂糖価格が国際相場より高く保たれる
  • 国内価格が高い＝砂糖離れ・代替甘味料への流出を招き、市場が縮む
  • 市場が縮む＋コスト上昇 → 工場の統廃合と業界再編が不可避になる

制度が産地を守る代わりに、精製糖会社は縮む市場の中で規模を削り合うことになった。
2020年代に相次いだ経営統合（DM三井製糖、ウェルネオシュガー）は、この帰結である。

4. 大豆・菜種：制度がほとんどない世界

製油の原料である大豆・菜種は、ほぼ無関税で民間が自由に輸入できる。
小麦や砂糖のような国家貿易も調整金もない。

なぜか。答えは単純で、守るべき国内産地がほとんどないからである。

原料 国内生産の位置づけ 制度
小麦国内生産あり（供給の約2割）。産地保護の必要国家貿易＋マークアップ
砂糖（てん菜・さとうきび）北海道・南西諸島の基幹作物。地域経済そのもの糖価調整制度
大豆（搾油用）搾油用はほぼ全量輸入。国産大豆は豆腐・納豆・味噌向けで別市場実質なし
菜種ほぼ全量輸入（カナダ中心）実質なし

制度がないということは、シカゴ（大豆）やウィニペグ（菜種）の先物価格と為替が、
そのまま原価に直撃するということだ。しかも製油の原料費は売上原価の大半を占める。

製油は3業界の中で唯一、原料リスクを自分で背負っている。
だから値上げのニュースが製油だけ頻繁に出る。半年待ってくれる制度がないので、
コストが上がれば自分で顧客と交渉するしかない。

例外的に制度が絡むのは次の2つ。

  • こめ油（米油） … 原料は国産の米ぬか。国内原料で作れる唯一の植物油として、
    食料自給率の文脈で政策的に注目される
  • 国産大豆 … 畑作物の直接支払交付金（ゲタ）の対象。ただし搾油ではなく食品用

タイムラグの正体

シカゴ小麦が急騰してから、食卓のパンが値上がりするまでを分解すると、こうなる。

シカゴ小麦 急騰
   │  （0〜6か月）政府の買付価格に順次反映
   ▼
直近6か月の平均買付価格が上昇
   │  （最大6か月）次の改定期（4月期 or 10月期）を待つ
   ▼
政府売渡価格 改定
   │  （2〜3か月）製粉会社が小麦粉の価格改定を発表・実施
   ▼
小麦粉価格 改定
   │  （1〜数か月）製パン・製麺各社が製品価格に転嫁
   ▼
店頭のパン・麺が値上がり

  合計：早くて半年、遅ければ1年以上

実例として、2026年4月1日に政府売渡価格が+2.5%となったのを受け、
日清製粉は2026年6月20日納品分から業務用小麦粉を値上げすると2026年4月8日に発表している
（強力系 25kgあたり75円、中力系・薄力系 同100円、国内産小麦100% 同75円）。
制度改定から店頭反映まで、律儀に階段を降りてくるのがこの業界の作法である。

「小麦の値上がり」が報道されてから実際に効くまでに半年ある。
逆に言えば、いま店頭で起きている値上げは、半年前の世界の出来事の結果である。
