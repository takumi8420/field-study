# 直近トピック（2026年9月時点）

報道ベースの整理。数値は一次情報（農林水産省プレスリリース、各社IR）で裏取りすること。
2026年のこの業界は、**「制度が守り切れなくなった年」**として記憶されそうな局面にある。

## 1. 輸入小麦の政府売渡価格が+12.0%、3年半ぶりの7万円台

**2026年9月9日、農林水産省は2026年10月期の輸入小麦の政府売渡価格を
5銘柄加重平均で1トンあたり70,020円（前期比+12.0%）と決定した。**
引き上げは2期連続で、7万円台は2023年4〜9月期以来3年半ぶりとなる。

| 適用期           | 価格（円/トン） | 改定率                         |
| ---------------- | --------------- | ------------------------------ |
| 2025年10月期     | 61,010          | ―                              |
| 2026年4月期      | 62,520          | **+2.5%**（6期ぶりの引き上げ） |
| **2026年10月期** | **70,020**      | **+12.0%**                     |

（出典：農林水産省プレスリリース、日本経済新聞、JAcom ほか 2026年9月）

### なぜここまで上がったか

報道されている要因は4つで、**すべてが同じ方向に重なった**のが今回の特徴である。

```
【2026年10月期 +12.0% の内訳イメージ（要因の重なり）】

  ① 産地の作柄悪化
     米国の干ばつ、欧州の記録的高温による減産見通し
        │
  ② 供給不安の再燃
     ロシア・ウクライナ情勢の激化、黒海の物流混乱
        │      → シカゴ小麦先物が1年前比4割以上高い水準（2026年9月時点・報道）
        │
  ③ 円安
     ドル建ての買付価格が、円換算でさらに膨らむ
        │
  ④ 海上運賃・燃料の高騰
     イランによるホルムズ海峡封鎖の影響で運賃・燃料が世界的に上昇（報道ベース）
        │
        ▼
  直近6か月の平均買付価格が大幅上昇 → 売渡価格 +12.0%
```

**この4つのうち、制度が緩和できるのは「時間」だけ**である。
6か月平均と年2回改定でならしても、すべての要因が同時に効けば、
ならした後でも2桁の改定になる。**制度は振幅を小さくするが、水準は動かせない。**

→ 仕組みの詳細は [制度が価格を決める世界](01_制度が価格を決める世界.md)

### これから起きること（構造からの推測）

1. 製粉各社が**2026年末〜2027年初にかけて業務用小麦粉を値上げ**（過去のパターンでは改定から2〜3か月後）
2. 製パン・製麺・製菓が**2027年春に製品価格へ転嫁**
3. 店頭のパン・麺・菓子が値上がりするのは**2027年前半**
4. 一方で、**下がるときも同じだけ遅い**。相場が落ち着いても2027年10月期までは戻らない

2026年4月期（+2.5%）のときは、日清製粉が2026年4月8日に発表し、
**6月20日納品分**から値上げを実施している。今回も同様の時間差になる可能性が高い。

## 2. 食用油は年に2度の値上げ。制度の緩衝材がない世界

製油は政府売渡価格のような一斉改定の合図がないため、**各社が個別に、何度も**値上げを出す。
2026年は前半だけで大手2社が相次いで改定を発表した。

| 発表時期          | 企業                 | 内容                                                                            |
| ----------------- | -------------------- | ------------------------------------------------------------------------------- |
| 2026年3月         | 日清オイリオグループ | 食用油を最大14%値上げ                                                           |
| 2026年3月5日      | J-オイルミルズ       | 6月1日納品分から、**家庭用11〜16%／業務用・加工用17〜22%**                      |
| 2026年4月20日前後 | 日清オイリオグループ | キャノーラ油など家庭用を最大15%値上げ（6月から）                                |
| 2026年4月22日     | 日清オイリオグループ | 家庭用・業務用・加工用を6月1日納入分から改定（業務用を含め最大21%と報じられる） |

（出典：J-オイルミルズ プレスリリース、日本経済新聞、LNEWS、食品新聞 2026年3〜5月）

### 理由に共通して挙がるもの

- **バイオ燃料需要の拡大**（SAF・再生可能ディーゼル）による油糧種子の国際相場高
- 中東情勢を含む**物流費・エネルギー費の高騰**
- **円安**
- 包材・資材費、人手不足によるサプライチェーン全体のコスト上昇

> **食用油の値上げ理由に「航空燃料」が出てくる時代になった。**
> 食用油はもはや食品業界だけの商品ではなく、エネルギー政策の影響を直接受ける。
> → [市場と収益](03_市場と収益.md) の「バイオ燃料が油糧種子相場を変えた」

### 業績：2025年度（2026年3月期）は減益で着地

- **J-オイルミルズ**：売上高2,265億円（前期比2%減）、純利益47億円（同32%減）
- **大手2社とも2桁以上の減益**で着地したと報じられる
- 2027年3月期はJ-オイルミルズが**値上げ効果で純利益5%増**を見込む（日本経済新聞 2026年5月）

日本食糧新聞は2026年6月末、**「国内製油、試練の夏」**として、
汎用油とオリーブ油の価格適正化と需要回復が焦点になると報じている。

## 3. 製粉は増収増益。同じ原料高でも結果が反転する

**日清製粉グループ本社の2026年3月期連結決算は、売上高8,650億円（前期比1.6%増）、
営業利益466億円（同0.7%増）、経常利益513億円（同4.4%増）の増収増益**（決算短信）。
2027年3月期は売上高8,700億円、営業利益460億円、純利益410億円を見込む。

| 企業                 | 2026年3月期                    | 方向               |
| -------------------- | ------------------------------ | ------------------ |
| 日清製粉グループ本社 | 売上8,650億円、営業利益466億円 | **増収増益**       |
| J-オイルミルズ       | 売上2,265億円、純利益47億円    | **減収・大幅減益** |

> **同じ2025年度、同じ原料高・円安の環境で、製粉は増益、製油は32%減益。**
> 違いは経営努力ではなく、**原料価格の決まり方（制度の有無）**である。
> この対比が、この業界を理解する上で最も分かりやすい実例になっている。

増益の中身としては、**海外製粉事業の好調**と、**国内の値上げによる採算改善**、
パスタ・パスタソースなど**加工食品の伸長**が挙げられている。
つまり「粉だけの会社」ではなくなっていることが効いている。

## 4. 製糖：合併と工場閉鎖が同時に進む

砂糖は国内消費の漸減が続き、**2026年は再編と設備集約の節目の年**にあたる。

```
【2026年の製糖業界カレンダー】

  2026年 8月 ── DM三井製糖、砂糖を値上げ（燃料・資材費高騰）
  2026年 9月 ── DM三井製糖HD、子会社3社の生産終了
                  （関門製糖・鳳氷糖・日糖産業）
  2026年 9月 ── DM三井製糖、ニュートリション分野のM&A拡充を表明（報道）
  2026年10月 ── ウェルネオシュガー、東洋精糖を合併（予定）
                  ※2025年10月に第一糖業を合併済み
```

（出典：食品新聞、M&A Online、事業構想オンライン ほか 2025〜2026年）

### 2つの大手が選んだ道

| 企業                           | 戦略                                                                                                                                                                    |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **DM三井製糖ホールディングス** | 中期計画「2026 Diversify into Nutrition & Health」。**砂糖中心のポートフォリオを見直し、スポーツ栄養・シニア向け栄養をM&Aで拡充**。国内砂糖事業は工場を絞って「強靭化」 |
| **ウェルネオシュガー**         | 統合を重ねて**国内の精製糖事業そのものを集約**。第一糖業（2025年10月）、東洋精糖（2026年10月予定）                                                                      |

**「砂糖から出ていく」DM三井製糖と、「砂糖に集まる」ウェルネオシュガー**という
対照的な構図として読むと分かりやすい。ただし両者とも前提は同じで、
**国内砂糖市場は縮む**という認識である。

### 制度側も財源が細っている

糖価調整制度の調整勘定は、2023砂糖年度の単年度収支が約74億円の赤字、
累積欠損が約640億円に達したとされる（農政審議会資料・報道ベース）。
消費が減れば調整金の財源も減るという**制度の自己矛盾**が表面化している。

2026年9月10日に決定された令和8砂糖年度の指標では、
てん菜由来の国産糖への交付金単価が**18,559円→27,592円/製品トン**へ大きく引き上げられた一方、
てん菜糖の交付対象数量は55万トンに設定されている。
**単価を上げて産地を支えつつ、対象数量で総額を抑える**という調整が見て取れる。

→ 制度の仕組みは [制度が価格を決める世界](01_制度が価格を決める世界.md)

## 5. 国産回帰：期待は高いが、原料が付いてこない

### 米粉

輸入小麦の高騰で米粉への引き合いは強まり、**米粉用米の需要は2025年度で約6万2,000トン**まで伸びた。
農林水産省は2030年度に生産量13万トンという目標を掲げている。

ところが**生産は2023年度から減り続けている**。
主食用米の価格上昇で農家が主食用に回帰したためで、
2025年度は需要との乖離が目立つと日本農業新聞の論説（2026年）が指摘している。

> **「輸入小麦が高いから米粉へ」という話は、原料の米が確保できて初めて成立する。**
> 制度が支える米粉用米の交付金と、市場が付ける主食用米の価格が競合してしまい、
> **小麦の代替を国内で用意するのは簡単ではない**ことが2026年に露呈した形である。

### こめ油

国内原料で作れるほぼ唯一の植物油だが、
**原料の米ぬか発生量が減少**していることが課題として報じられている
（日本食糧新聞 2026年7月）。米の消費が減れば米ぬかも減るという構造的な天井がある。

需要は健康志向で伸びているのに、**原料の上限が米消費に縛られる**。
これも国産回帰の難しさを示す一例である。

## 6. 全体の構図

2026年のこの業界は、次のようにまとめられる。

1. **制度の緩衝材が効かないほど原料が上がった年**。輸入小麦の政府売渡価格は10月期に+12.0%と、
   6か月平均でならしてもなお2桁の改定になった。産地の天候、地政学、円安、運賃が同時に効いたため。
2. **制度の有無が業績の明暗を分けた**。2026年3月期は製粉が増収増益、製油が大幅減益。
   同じ環境でこれだけ結果が割れるのは、原料価格の決まり方が違うからである。
3. **製糖は制度に守られながら縮んでいる**。合併と工場閉鎖が同時進行し、
   大手は「砂糖以外」へ軸足を移し始めた。糖価調整制度自体も財源難に直面している。
4. **国産回帰は期待ほど進んでいない**。米粉もこめ油も、需要はあるのに原料が増やせない。
5. 結果として各社の戦略は、**下流（加工食品）か横（機能性素材）への多角化**に収斂している。
   「原料を挽く・精製する・搾るだけ」では、制度があってもなくても利益が細るからである。
