# 3つの製造業の中身

このノートで分かること：**製粉・製糖・製油は「工場の中で何をしているか」が全然違う**。
挽いて分ける（製粉）、溶かして不純物を取る（製糖）、搾って2つに分ける（製油）。
いずれも**副産物が収益を左右し、装置の稼働率が利益を決める**装置産業である。

## 1. 共通の骨格：原料を買って、分けて、売る

3業界に共通するのは、**原料を物理的・化学的に「分ける」だけ**という点だ。
新しい物質を合成するわけではない（その点で化学産業とは違う）。

```
【3業界に共通する形】

  原料（穀物・油糧種子・粗糖）
        │
        ▼
  ┌──────────────┐
  │   分ける工程        │  ← 大型装置。24時間連続運転が基本
  └──────────────┘
        │
        ├──▶ 主製品（小麦粉／砂糖／食用油）… 売上の大半
        │
        └──▶ 副産物（ふすま／糖蜜／ミール）… 利益に効く
```

ここから導かれる経済的な性質が3つある。

| 性質             | 理由                                   | 結果                                                     |
| ---------------- | -------------------------------------- | -------------------------------------------------------- |
| **装置産業**     | 大型設備に固定費が寝ている             | **稼働率が落ちた瞬間に赤字**。止められないので24時間運転 |
| **副産物で稼ぐ** | 原料の重量の2〜8割が副産物になる       | 副産物が売れないと採算が崩れる                           |
| **寡占**         | 設備投資が重く、規模でしか効率が出ない | 各分野2〜4社に集約                                       |

> ポイント：**この3業界を「食品メーカー」と思うと読み違える。実態は素材プラント産業に近い。**
> 利益の見方も、ブランド力より**歩留まり・稼働率・副産物価格**を見るのが正しい。

## 2. 製粉：小麦を挽いて等級別に分ける

### 2-1. 工程

小麦粒は、外側の**皮（ふすま＝bran）**、内側の**胚乳（endosperm）**、発芽する**胚芽（germ）**からなる。
製粉とは、**胚乳だけをきれいに取り出して粉にする**作業である。

```
【製粉の工程】

 原料小麦（政府から購入／国産）
   │
   ▼
 ① 精選（夾雑物・石・金属を除く）
   │
   ▼
 ② 調質（テンパリング）… 水を加えて一定時間置く
   │   皮を強く・胚乳をもろくして「分かれやすく」する
   ▼
 ③ ロール製粉（挽く）
   │   ┌── 粗砕ロール（ブレーキロール）で砕く
   │   ├── ふるい（シフター）で分ける
   │   ├── 純化機（ピュリファイヤー）で粒度を揃える
   │   └── 滑面ロール（スムースロール）で細かく
   │   ※ この「砕く→ふるう」を 20〜40 段以上繰り返す
   ▼
 ④ 分級・配合
   │
   ├──▶ 小麦粉（上級粉・中級粉・末粉 …）  歩留まり 約70〜78%
   └──▶ ふすま（麬）                      約20〜25%
```

**調質（テンパリング）**という地味な工程が製粉の肝である。
乾いたまま挽くと皮が砕けて粉に混ざり、色の悪い粉になる。
水を入れて皮を「しなやか」にしてから挽くことで、**皮を大きいまま剥がせる**。

### 2-2. 歩留まりと等級

**歩留まり（ぶどまり）**とは、投入した原料に対して製品が取れる割合のこと。

| 出てくるもの       | 重量比の目安   | 用途                                   | 価値           |
| ------------------ | -------------- | -------------------------------------- | -------------- |
| **小麦粉（全体）** | 約70〜78%      | パン、麺、菓子、プレミックス           | 主製品         |
| ├ 1等粉            | 粉の中で最上位 | 高級パン・菓子。白く灰分が少ない       | 最も高い       |
| ├ 2等粉・3等粉     | 順に下位       | 一般用途、加工用                       | 中〜低         |
| └ 末粉（すえこ）   | 少量           | 飼料・工業用                           | 低い           |
| **ふすま（麬）**   | 約20〜25%      | **配合飼料の原料**、一部は食物繊維素材 | 低いが量が出る |

等級を分けるのは**灰分（かいぶん）**という指標である。
灰分とは、粉を燃やして残るミネラル分の量。皮に多く含まれるので、
**灰分が低い＝皮の混入が少ない＝白くてきれいな粉**ということになる。

> **同じ小麦から、同じ装置で、価格の違う粉が何種類も出てくる。**
> どの等級を何%取るか（＝製品ミックス）の設計が、製粉会社の腕の見せどころである。
> 高級粉を欲張れば歩留まりが落ち、歩留まりを追えば等級が下がる。

### 2-3. ふすまの経済学

ふすまは小麦の重量の2割強を占める。これが**配合飼料の原料として売れる**かどうかで採算が動く。

- 飼料相場が高いとき … ふすま収入が増え、製粉の実質原価が下がる
- 飼料相場が安いとき … ふすまが捨て値になり、粉に負担が寄る

つまり**製粉の収益は、畜産・飼料市況と連動している**。
→ [畜産・飼料](../13_畜産・飼料/README.md)

**同じ「穀物を挽く・搾る」装置技術の延長線上にあるため、兼業が成立する**のがこの業界の特徴である。

## 3. 製糖：粗糖を溶かして不純物を取る

### 3-1. 2段階の構造

砂糖づくりは**産地でやる工程**と**消費地でやる工程**に分かれる。ここを混同すると業界地図を読み違える。

```
【砂糖の2段階】

 ■ 第1段階：原料糖（粗糖）をつくる ＝ 産地側
   さとうきび／てん菜
        │ 搾る・煮詰める・結晶化
        ▼
   粗糖（原料糖）… 茶色い。まだ不純物を含む
   ├ 海外産地（ブラジル、タイ、豪州 …）→ 輸入
   └ 国内産地（沖縄・鹿児島＝甘しゃ糖／北海道＝てん菜糖）

 ■ 第2段階：精製する ＝ 消費地側（＝精製糖会社の仕事）
   粗糖
        │ ① 洗糖（結晶の表面の蜜を洗う）
        │ ② 溶解（水に溶かす）
        │ ③ 清浄（石灰・炭酸ガス、活性炭・イオン交換樹脂で色と不純物を除く）
        │ ④ 濃縮・結晶化（真空釜で煮詰めて結晶を育てる）
        │ ⑤ 分蜜（遠心分離機で結晶と蜜を分ける）
        │ ⑥ 乾燥・篩別
        ▼
   ├──▶ 製品糖（グラニュー糖／上白糖／三温糖 …）
   └──▶ 糖蜜（廃糖蜜）… 発酵原料・飼料へ
```

**分蜜（ぶんみつ）**は遠心分離機で「結晶」と「まわりの蜜」を分ける工程。
これを繰り返すごとに純度が上がるが、回収できる糖の量は減っていく。
**純度と歩留まりのトレードオフ**がここにも出る。

### 3-2. 日本独特の「上白糖」

世界の砂糖はほぼグラニュー糖だが、日本では**上白糖**がよく使われる。
上白糖はグラニュー糖に**転化糖液（ビスコ）を噴霧**してしっとりさせたもので、
日本の家庭用・和菓子用に最適化された製品である。

> **同じ原料糖から、製品の作り分けで付加価値を変えられる**。
> グラニュー糖は完全なコモディティだが、液糖・和三盆・特殊糖・機能性糖質（オリゴ糖など）へ
> 進むほど価格交渉力が残る。製糖各社が「砂糖以外」に向かう理由はここにある。

### 3-3. 副産物：糖蜜

**糖蜜（廃糖蜜、モラセス）**は、これ以上結晶が取れなくなった残りの蜜。
アルコール発酵の原料、アミノ酸発酵（味の素などの発酵原料）、飼料に回る。
量は出るが単価は低く、**製糖の副産物収入は製粉のふすまほど大きくはない**。
→ [調味料](../03_調味料/README.md)

### 3-4. 主要プレイヤーと再編

国内の砂糖消費は漸減が続き、**工場の統廃合と経営統合が常態**になっている。

| 企業                             | 成り立ち                               | 動き                                                                                                                                                                   |
| -------------------------------- | -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **DM三井製糖ホールディングス**   | 2021年に三井製糖と大日本明治製糖が統合 | 国内最大手。中期計画「2026 Diversify into Nutrition & Health」で**砂糖以外（栄養・健康）へ軸足を移す**。2026年9月末に子会社3社（関門製糖・鳳氷糖・日糖産業）の生産終了 |
| **ウェルネオシュガー**           | 2023年1月に日新製糖と伊藤忠製糖が統合  | 2025年10月に第一糖業を合併、**2026年10月に東洋精糖を合併予定**                                                                                                         |
| **塩水港精糖**                   | 独立系                                 | オリゴ糖など機能性糖質に強み                                                                                                                                           |
| **フジ日本**（旧・フジ日本精糖） | 独立系                                 | イヌリンなど機能性素材                                                                                                                                                 |

（出典：各社発表および2025〜2026年の報道）

```
【精製糖業界の集約（主な流れ）】

 三井製糖 ─┬─▶ DM三井製糖HD（2021）
 大日本明治製糖 ┘        │
                          └─▶ 関門製糖ほか3社 生産終了（2026年9月末）

 日新製糖 ─┬─▶ ウェルネオシュガー（2023）
 伊藤忠製糖 ┘        │
                      ├─▶ 第一糖業 合併（2025年10月）
                      └─▶ 東洋精糖 合併（2026年10月 予定）
```

> **縮む市場では、装置産業は「工場を減らして1工場あたりの稼働率を上げる」しか手がない。**
> 製糖の再編はブランド獲得でもシナジー狙いでもなく、**純粋な設備集約**である。

## 4. 製油：搾って「油」と「粕」に分ける

### 4-1. 工程

製油は、大豆や菜種から**油**を取り出す産業。だが重量で見ると、**主役はむしろ粕（ミール）**である。

```
【製油の工程】

 原料（大豆・菜種・ごま・落花生 …）
   │
   ▼
 ① 前処理（精選・乾燥・圧扁＝フレーク状に潰す）
   │
   ▼
 ② 搾油
   │  ├ 圧搾（エクスペラーで物理的に搾る）… 菜種など油分の多い原料
   │  └ 抽出（ヘキサン等の溶剤で溶かし出す）… 大豆など油分の少ない原料
   │     ※ 大豆は油分が約20%しかないので、圧搾だけでは採算に合わない
   ▼
 ③ 原油（げんゆ）＋ ミール（油粕）に分離
   │
   ├──▶ ④ 精製 ─────────────────┐
   │      ・脱ガム（リン脂質を除く）            │
   │      ・脱酸（遊離脂肪酸を除く）            │
   │      ・脱色（白土・活性炭）                │
   │      ・脱臭（高温・減圧で匂いを飛ばす）    │
   │                                            ▼
   │                                    食用油（サラダ油・キャノーラ油 …）
   │
   └──▶ ミール（大豆ミール／菜種ミール）
            └─▶ 配合飼料の主原料へ
```

**脱臭**は230〜260℃の高温・高真空で行う。ここで大量の蒸気とエネルギーを使うため、
**製油は3業界の中で最もエネルギーコストの比重が高い**。燃料価格の影響を強く受ける。

### 4-2. 歩留まり：油とミールの比率

| 原料     | 油の取り分 | ミールの取り分 |
| -------- | ---------- | -------------- |
| **大豆** | 約18〜20%  | **約75〜77%**  |
| **菜種** | 約40%前後  | 約54〜56%      |

（出典：日本植物油協会）

> **大豆を搾る工場は、実は「飼料工場」である。**
> 重量の4分の3がミールとして出ていくので、
> 大豆搾油の採算は「大豆価格 vs（油価格×20% ＋ ミール価格×76%）」で決まる。
> この差額を**クラッシュ・スプレッド（搾油マージン）**と呼ぶ。

**ミール**とは、油を搾ったあとの粕のこと。たんぱく質を40%以上含み、
**配合飼料のたんぱく源として欠かせない**。鶏・豚・牛の飼料に大量に使われる。
したがって製油の収益は、**畜産の飼料需要と直結している**。
→ [畜産・飼料](../13_畜産・飼料/README.md)

### 4-3. 主要プレイヤー

| 企業                     | 立ち位置             | 特徴                                                                                                     |
| ------------------------ | -------------------- | -------------------------------------------------------------------------------------------------------- |
| **日清オイリオグループ** | 国内首位             | 家庭用の強いブランド（日清キャノーラ油など）。中鎖脂肪酸（MCT）など機能性油脂、化粧品原料油にも展開      |
| **J-オイルミルズ**       | 国内2位              | 2002年にホーネンコーポレーション・味の素製油・吉原製油が統合。業務用に強く、スターチ（でん粉）事業も持つ |
| **昭和産業**             | 3位級                | 製粉と併営。大豆・とうもろこしも扱う                                                                     |
| **かどや製油**           | ニッチ首位           | **ごま油に特化**。原料も市場も別世界で、市況の当たり方が違う                                             |
| **築野食品工業**         | こめ油の最大手クラス | 国産米ぬかを原料とする                                                                                   |

日本の植物油の総供給量は**2025年で258万トン**とされる（日本植物油協会）。
油種別では菜種油と大豆油が2本柱で、パーム油（主に加工用）が続く。

### 4-4. なぜ製油は薄利なのか

| 要因                 | 内容                                                                           |
| -------------------- | ------------------------------------------------------------------------------ |
| 原料が丸ごと市況     | 制度の緩衝材がない（→ [制度が価格を決める世界](01_制度が価格を決める世界.md)） |
| 為替が直撃           | 大豆・菜種はドル建て・カナダドル建て。円安がそのままコスト増                   |
| エネルギー多消費     | 抽出・脱臭に大量の熱。燃料高の影響が大きい                                     |
| 家庭用がPB化・特売化 | スーパーの目玉商品にされやすく、値上げが通りにくい                             |
| ミール価格が読めない | 副産物の収入が畜産市況任せ                                                     |

2026年3月期のJ-オイルミルズ連結決算は、売上高2,265億円（前期比2%減）、
純利益47億円（同32%減）と報じられ、**大手2社とも2桁以上の減益**となった（日本経済新聞ほか）。
その後、2026年に入って各社が大幅な値上げに踏み切っている。
→ [直近トピック 2026](04_直近トピック_2026.md)

## 5. 3業界を横に並べる

| 項目           | 製粉                       | 製糖                               | 製油                         |
| -------------- | -------------------------- | ---------------------------------- | ---------------------------- |
| 原料           | 小麦（政府売渡／国産）     | 粗糖（輸入／国産）                 | 大豆・菜種（輸入）           |
| 主工程         | 挽いて分ける（物理）       | 溶かして不純物を取る（化学＋物理） | 搾る＋精製（物理＋化学）     |
| 主製品         | 小麦粉（等級別）           | 砂糖（品種別）                     | 食用油                       |
| **副産物**     | **ふすま**（約20〜25%）    | **糖蜜**                           | **ミール**（大豆で約76%）    |
| 副産物の行き先 | 飼料                       | 発酵原料・飼料                     | 飼料                         |
| 歩留まりの意味 | 粉の取り分と等級のバランス | 純度と回収率のバランス             | 油とミールの配分（市況次第） |
| 原料リスク     | **制度が吸収**             | 調整金で水準が持ち上がる           | **丸ごと自社負担**           |
| 収益の安定度   | 高い                       | 中（市場縮小が重い）               | 低い（振れが大きい）         |
| 寡占度         | 上位4社で8割超             | 大手2グループ＋独立系              | 上位2社が中心                |
| 業界の主戦場   | 加工食品・海外への多角化   | 設備集約と「砂糖以外」への転換     | 値上げ交渉と高付加価値油     |
