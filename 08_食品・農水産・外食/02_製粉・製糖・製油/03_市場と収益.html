このノートで分かること：この3業界の客はほとんどが企業（B2B）である。
小麦粉も砂糖も食用油も、量の大半はパン屋・菓子メーカー・外食・中食に流れる。
だから値上げが通るかどうかは交渉次第で、そこに制度・原料相場・為替・健康志向が絡んでくる。

1. 誰に売っているのか

【製品の流れと、値決めの主戦場】

  製粉 ──▶ 小麦粉 ─┬──▶ 製パン（山崎製パン、敷島製パン …）
                    ├──▶ 製麺（うどん・そば・即席麺）
                    ├──▶ 製菓（菓子メーカー）
                    ├──▶ 外食・中食（ピザ、天ぷら、ベーカリー）
                    └──▶ 家庭用（薄力粉1kg袋、プレミックス）  ← 量は少ない

  製糖 ──▶ 砂糖 ───┬──▶ 飲料（清涼飲料、乳飲料）
                    ├──▶ 製菓・製パン
                    ├──▶ 調味料・加工食品
                    └──▶ 家庭用（上白糖1kg）                 ← 量は少ない

  製油 ──▶ 食用油 ─┬──▶ 外食・中食（フライヤー用が巨大）
                    ├──▶ 加工食品（スナック、即席麺の揚げ油）
                    ├──▶ 加工用（マヨネーズ、マーガリン、ドレッシング）
                    └──▶ 家庭用（キャノーラ油ボトル）         ← 量は少ない

              ┌──────────────────────────┐
              │ 量の8割前後は業務用・加工用（B2B）        │
              │ → 年1〜2回の価格改定交渉が最大の勝負所    │
              └──────────────────────────┘

業務用と家庭用の違い

項目 業務用・加工用 家庭用
量多い（全体の8割前後）少ない
包装25kg紙袋、フレコン、ローリー（バラ輸送）、一斗缶1kg袋、1,000gボトル
値決め個別交渉。年1〜2回の価格改定小売の店頭価格。特売の対象になりやすい
利益率薄いが量で稼ぐ単価は高いが、販促費・棚代がかかる
転嫁のしやすさ制度改定を根拠にできれば通りやすい小売の抵抗が強く、遅れる
客の乗り換えスペック（灰分・たんぱく量・酸価）が合えば乗り換えるブランド選好がある程度効く

意外だが、家庭用のほうが値上げが難しい。
業務用は「政府売渡価格が上がったので」という客観的な根拠を出せるが、
家庭用はスーパーの特売・PBとの比較に晒され、値上げがそのまま棚落ちのリスクになる。
製油が家庭用で苦しむのはこのためである。
→ 食品スーパー

2. 価格転嫁のメカニズム

2-1. 製粉：制度が「値上げの口実」をくれる

政府売渡価格の改定（年2回）が、業界一斉の値上げタイミングになる。
これは製粉会社にとって極めて有利な仕組みである。

  • 全社が同時に同じ理由で上がる → 1社だけ我慢して価格を据え置く動機がない
  • 公表された政府の数字が根拠 → 顧客も反論しにくい
  • 半年に1回で済む → 交渉コストが低い

実例：2026年4月1日の政府売渡価格+2.5%を受け、日清製粉は2026年4月8日に
2026年6月20日納品分からの業務用小麦粉値上げを発表した。

品目 値上げ幅（25kgあたり）
強力系小麦粉（パン用）+75円
中力系・薄力系小麦粉（うどん・菓子用）+100円
国内産小麦100%小麦粉+75円

（出典：日清製粉 ニュースリリース 2026年4月8日）

25kgで75〜100円＝1kgあたり3〜4円である。小麦粉の値上げは、額で見れば驚くほど小さい。
しかしパン1斤に使う小麦粉は200g程度なので、そこからさらに薄まる。
「小麦が○%上がった」という見出しと、食卓の値上がり幅は一致しないことは押さえておきたい。

2-2. 製油：制度の助けがないので、自力で何度も上げる

製油には政府売渡価格のような一斉改定の合図がない。
そのため各社が個別に、年に複数回、値上げを発表することになる。

2026年の例（いずれも報道・各社発表ベース）：

時期 企業 内容
2026年3月日清オイリオグループ食用油を最大14%値上げ
2026年3月5日J-オイルミルズ6月1日納品分から、家庭用11〜16%、業務用・加工用17〜22%
2026年4月日清オイリオグループ6月1日納入分から、家庭用・業務用・加工用を値上げ（家庭用のキャノーラ油等は最大15%、業務用・加工用を含めると最大21%と報じられる）

ここでも業務用の値上げ率のほうが家庭用より大きい。
家庭用は小売の抵抗で上げ幅を抑えざるを得ず、業務用に寄せて全体の採算を取るのが実務である。

製油の値上げが「年に何度も」ニュースになるのは、制度の緩衝材がないから。
製粉の値上げが「年2回」なのと対照的で、これは各社の姿勢の差ではなく制度の差である。

2-3. 製糖：値上げは通るが、市場が縮む

砂糖も同様に各社個別の改定で、2026年にはDM三井製糖が8月からの値上げを発表している
（燃料・資材費高騰を理由とする。食品新聞 2026年5月）。

ただし砂糖には特有の難しさがある。値上げが需要減を呼びやすいのだ。

  • 砂糖は代替品がある（異性化糖＝コーンシロップ、高甘味度甘味料、ステビアなど）
  • 飲料・加工食品メーカーは、価格差が開けば配合を切り替える
  • 健康志向による「減糖」トレンドが構造的に効いている

小麦粉や食用油には「代わりに使えるもの」がほぼないのに対し、
砂糖だけは甘味として置き換え可能である。これが製糖の立場を弱くしている。
→ 清涼飲料

3. 原料相場と為替

3-1. どの相場を見ればいいか

業界 見るべき指標 取引所・情報源
製粉シカゴ小麦先物（CBOT Wheat）ただし効くのは6か月遅れ
製糖ニューヨーク粗糖先物（No.11）ブラジル・タイ・インドの作柄と輸出政策
製油シカゴ大豆先物（CBOT Soybeans）、ICEカノーラ（菜種）大豆油・大豆ミールの先物も個別にある
全業界共通USD/JPY、CAD/JPY、海上運賃（バルク運賃指数）円安はそのままコスト増

3-2. 相場が効くまでの時間差

【同じ「国際相場の上昇」が、3業界に効くまで】

  国際相場 上昇
      │
      ├─ 製油 ──▶ 1〜3か月（在庫の回転分だけ遅れる）
      │            → すぐに値上げ交渉へ
      │
      ├─ 製糖 ──▶ 2〜4か月（原料糖の手当てと在庫）
      │            → 値上げするが需要減とセット
      │
      └─ 製粉 ──▶ 6〜12か月（6か月平均＋年2回改定）
                   → 一斉に、大きく、遅れて来る

この時間差は投資家・取引先にとって実務的な意味を持つ。
「いまシカゴ小麦が高い」というニュースは、製粉会社の来期以降の原価の話であって、
足元の決算にはまだ効いていない。逆に製油はすでに効いている。

3-3. バイオ燃料が油糧種子相場を変えた

2020年代に入って、植物油の相場を動かす最大の新要因がバイオ燃料需要である。

【食用油が燃料と競合するようになった】

  大豆油・菜種油・パーム油
       │
       ├──▶ 食用（従来の用途）
       │
       └──▶ 燃料用
              ├ バイオディーゼル（FAME）
              ├ 再生可能ディーゼル（HVO）
              └ SAF（持続可能な航空燃料）  ← 2020年代後半の最大の伸び代

  → 燃料は「食品より高い価格を払える」場面がある
  → 食用油メーカーは、燃料需要と原料を取り合うことになった

世界の植物油生産量は、2023/24年でパーム油 約8,006万トン、大豆油 約6,298万トンとされる
（日本植物油協会）。この巨大な市場に、航空業界のSAF義務化などが新規需要として乗ってくる。

日本でも資源エネルギー庁が次世代液体燃料政策としてSAF原料の確保を進めており、
非可食油脂（廃食用油など）の活用が政策の柱になっている
（資源エネルギー庁 資料、2026年4月）。裏を返せば、
可食油脂を燃料に回すと食品と競合するという認識が制度側にもある。

食用油はもう「食品の原料」だけではない。エネルギーの一部になった。
これが、製油の原料相場が構造的に高止まりしやすくなった理由である。

3-4. 為替のインパクト

原料がドル建て・カナダドル建てなので、円安はそのまま原価増になる。

業界 為替リスクの負い方
製粉政府が買い付けるため、直接は負わない。売渡価格に織り込まれて半年後に来る
製糖自社で輸入するため直接負う。為替予約でヘッジ
製油自社で輸入するため直接負う。原料費比率が高いぶん影響が最大

4. 国産回帰という別の潮流

輸入依存が極端に高いこの業界で、国産原料が注目されるのは自然な流れである。
ただし、期待と現実のギャップが大きい。

4-1. 米粉

小麦粉の代わりに米を粉にして使う。強みは3つ。

  • グルテンフリー（小麦アレルギーの人が食べられる）
  • 吸油率が低い（天ぷら・唐揚げがカラッと揚がる）
  • 国産原料（自給率向上に直結）

2022年以降の輸入小麦高騰で業務用価格の差が縮まり、引き合いが強まった。

指標 数値 時点・出典
米粉用米の需要約6万2,000トン2025年度・報道ベース
政府の生産量目標13万トン2030年度・農林水産省
生産（作付）の実態2023年度から減少が続き、需要と大きく乖離していると指摘される2025年度・日本農業新聞 論説

米粉は「需要はあるのに原料が作られない」という珍しい状態にある。
理由は単純で、主食用米の価格が上がったため、農家が主食用に戻したから。
米粉用米は交付金がつくとはいえ、主食用米が高いときは競争にならない。
制度が支える価格と市場が付ける価格のせめぎ合いという点で、この業界らしい話である。
→ 農業・種苗・肥料

4-2. こめ油（米油）

国内原料でつくれる、ほぼ唯一の植物油。原料は精米時に出る米ぬかで、
米を食べる限り必ず発生する副産物である。

  • γ-オリザノールなどの機能性成分を含むことが訴求点
  • 酸化しにくく、揚げ物の風味がよいとされる
  • 学校給食や米菓のかけ油が伝統的な用途

課題は原料の量が米の消費量に縛られること。
米の消費が減れば米ぬかも減る。2026年には「国産米ぬか発生量の減少」が
需要対応上の課題として報じられている（日本食糧新聞 2026年7月）。

需要が伸びても原料を増やせないという、副産物ビジネス特有の天井がある。

4-3. 国産小麦

国産小麦は供給の2割弱にとどまるが、「国産」という付加価値が明確に値段になる数少ない領域。
「ゆめちから」「きたほなみ」など、パン用に使える国産品種の開発が進んだ。

製粉各社も国内産小麦100%の粉をラインナップしており、
前述の日清製粉の値上げでも「国内産小麦100%小麦粉」が独立した品目として扱われている。

5. 需要側の逆風と追い風

5-1. 逆風：人口減少と健康志向

要因 効き方
人口減少3業界すべてに効く。パンも砂糖も油も、食べる人が減る
減糖・低糖質砂糖に最も強く効く。代替甘味料への流出
脂質への警戒油に効く。ただし「良い油」（MCT、オリーブ、こめ油）へのシフトという形も取る
糖質制限ブーム小麦粉にも一定の逆風。パン・麺の摂取減

ただし、「量は減るが単価は上がる」という形で吸収されている面もある。
砂糖なら希少糖・オリゴ糖、油ならMCTオイルや高付加価値油といった具合である。

5-2. 追い風：中食・外食の伸び

家庭で作らなくなるほど、原材料は業務用のルートを通る。

【調理の場所が移ると、需要の経路が変わる】

  昔： 家庭で調理
        小麦粉・砂糖・油 ──▶ 家庭用（小容量・小売経由）

  今： 中食（惣菜・弁当）・外食が伸びる
        小麦粉・砂糖・油 ──▶ 業務用・加工用（大容量・直販/商社経由）
                              │
                              └─▶ 製粉・製油各社は
                                   「粉を売る」から「加工食品も作る」へ

日清製粉グループやニップンが冷凍食品・中食・惣菜へ事業を広げているのは、
この流れに沿った当然の動きである。
粉のまま売るより、パスタや冷凍麺にして売るほうが付加価値が乗る。

→ 中食・弁当、給食・フードサービス、即席麺

6. 収益構造の比較

指標 製粉 製糖 製油
売上原価に占める原料費高い（6〜7割）高い（7割前後）最も高い（7〜8割）
営業利益率の目安数%（食品の中では安定）数%。市場縮小で厳しい低い。年による振れが大きい
利益の振れ要因政府売渡価格の改定期ずれ、ふすま価格調整金、砂糖需要、稼働率原料相場、為替、ミール価格、エネルギー
多角化の方向加工食品・中食・海外製粉（日清製粉Gは海外比重が大）栄養・健康（ニュートリション）、機能性糖質機能性油脂、化粧品原料、スターチ

主要各社の直近業績（いずれも決算短信・報道ベース）：

企業 決算期 売上高 利益
日清製粉グループ本社2026年3月期8,650億円（+1.6%）営業利益466億円（+0.7%）、経常利益513億円（+4.4%）
日清製粉グループ本社2027年3月期 予想8,700億円営業利益460億円、純利益410億円
J-オイルミルズ2026年3月期2,265億円（▲2%）純利益47億円（▲32%）

製粉が増収増益、製油が大幅減益という2026年3月期の対比が、
このノートの主張をそのまま示している。同じ原料高の局面でも、制度の有無で結果が反転する。

多角化の中身にも一貫した論理がある。
「原料を分けるだけ」の商売は必ずコモディティ化するので、
分けたものをさらに加工する（下流へ）か、分ける技術を別の素材に応用する（横へ）
の2方向にしか逃げ場がない。製粉は下流（加工食品）、製糖・製油は横（機能性素材）に出た。

用語メモ
