# 製粉・製糖・製油

- 大分類: 食品・農水産・外食
- 状態: done
- 更新日: 2026-09-20

**穀物・油糧種子を仕入れて、挽く・精製する・搾るだけの一次加工産業**。
食品メーカーに見えるが、実態は**原料費が売上原価の6〜8割を占める装置産業**である。
最大の特徴は、**小麦と砂糖には国が価格に介入する制度があり、油にはない**こと。
この非対称が、製粉の安定高収益と製油の薄利を分けている。

## 1. 業界の定義・範囲

**穀物や油糧種子を一次加工して、食品メーカー・外食に素材を供給する産業**を指す。

| 分野     | やること                                             | 主製品                                   | 副産物                   |
| -------- | ---------------------------------------------------- | ---------------------------------------- | ------------------------ |
| **製粉** | 小麦を挽いて胚乳と皮を分け、等級別の粉にする         | 小麦粉（強力・中力・薄力）、プレミックス | ふすま（飼料へ）         |
| **製糖** | 輸入した粗糖を溶かし、不純物と色を除いて結晶化する   | グラニュー糖、上白糖、液糖               | 糖蜜（発酵原料・飼料へ） |
| **製油** | 大豆・菜種を圧搾／溶剤抽出し、油と粕に分けて精製する | 食用油（キャノーラ、大豆、こめ油）       | ミール（飼料へ）         |

隣接分野との境界は次のとおり。

| 分野           | 違い                                                   | 参照                                                  |
| -------------- | ------------------------------------------------------ | ----------------------------------------------------- |
| **総合食品**   | 完成品（最終製品）のブランドで売る。こちらは素材を売る | [総合食品](../01_総合食品/README.md)                  |
| **農業・種苗** | 原料そのものを作る側。製粉・製糖・製油はその買い手     | [農業・種苗・肥料](../12_農業・種苗・肥料/README.md)  |
| **畜産・飼料** | 副産物（ふすま・ミール）の最大の行き先                 | [畜産・飼料](../13_畜産・飼料/README.md)              |
| **調味料**     | 糖蜜などを発酵原料として使う。川下側                   | [調味料](../03_調味料/README.md)                      |
| **総合商社**   | 原料の買付・輸送・在庫を担う。この業界の取引相手       | [総合商社](../../06_商社・卸売/01_総合商社/README.md) |

なお製粉大手は加工食品（パスタ、冷凍食品、中食）へ、
製糖・製油大手は機能性素材へ広がっており、**会社の輪郭は分野名より広い**。

## 2. 市場規模と成長性

| 指標                                   | 数値                                          | 時点・出典                         |
| -------------------------------------- | --------------------------------------------- | ---------------------------------- |
| 輸入小麦 政府売渡価格（5銘柄加重平均） | **70,020円/トン**（前期比+12.0%）             | 2026年10月期・農林水産省           |
| 同上（前期）                           | 62,520円/トン（+2.5%）                        | 2026年4月期・農林水産省            |
| 日本の小麦の輸入依存度                 | 約8割（米国 約43%、カナダ 約40%、豪州 約17%） | 2026年・農水省資料をもとにした報道 |
| 植物油の国内総供給量                   | **258万トン**                                 | 2025年・日本植物油協会             |
| 世界の植物油生産（パーム／大豆）       | 8,006万トン／6,298万トン                      | 2023/24年・日本植物油協会          |
| 砂糖調整基準価格                       | 155,500円/製品トン（前年度153,200円）         | 令和8砂糖年度・農林水産省          |
| 指定糖調整率                           | 38.14%（前年度39.32%）                        | 令和8砂糖年度・農林水産省          |
| 米粉用米の需要                         | 約6万2,000トン（生産は減少傾向）              | 2025年度・報道ベース               |

成長性の見方は分野で分かれる。

- **製粉**：国内は人口減で微減。伸びしろは**海外製粉と加工食品**（日清製粉Gは海外比重が大きい）
- **製糖**：**国内消費は漸減が確定路線**。減糖トレンドと代替甘味料が構造的な逆風
- **製油**：数量は横ばいでも、**バイオ燃料需要で原料相場が構造的に高止まり**

**付加価値が集まる場所**は明確で、この業界そのものではない。
原料は相場（または制度）で決まり、製品はコモディティに近い。
そのため各社は**下流（加工食品）か横（機能性素材）へ出ることで利益を作っている**。

## 5. 収益モデル・コスト構造

```
【典型的な損益の形】

  売上 100
   ├ 原料費（変動費）  60〜80   ← 相場と制度で決まる。自社で動かせない
   ├ 加工費（固定費中心）
   │   ├ 減価償却       止めても減らない
   │   ├ エネルギー     24時間連続運転なので大きい（特に製油の脱臭）
   │   └ 人件費         稼働率に比例しない
   ├ 物流費            バラ輸送・小口配送
   └ 営業利益            数%

  ＋ 副産物収入（ふすま・糖蜜・ミール）… ここが黒字/赤字を分けることがある
```

利益を左右する変数は4つ。

1. **原料価格**（制度か相場か。→ [01](01_制度が価格を決める世界.md)）
2. **歩留まりと製品ミックス**（上級粉をどれだけ取るか。→ [02](02_3つの製造業の中身.md)）
3. **稼働率**（固定費が重いので、落ちた瞬間に利益が消える）
4. **副産物価格**（飼料市況に連動する）

**製粉と製油の2026年3月期を並べると、この構造がそのまま見える。**

| 企業                 | 2026年3月期                                      | 結果     |
| -------------------- | ------------------------------------------------ | -------- |
| 日清製粉グループ本社 | 売上8,650億円（+1.6%）、営業利益466億円（+0.7%） | 増収増益 |
| J-オイルミルズ       | 売上2,265億円（▲2%）、純利益47億円（▲32%）       | 大幅減益 |

同じ原料高・円安の環境でこれだけ割れるのは、**原料価格の決まり方が違うから**である。

## 6. 競争要因（KSF）と参入障壁

| 要因                         | 中身                                                                           |
| ---------------------------- | ------------------------------------------------------------------------------ |
| **臨海の大型工場**           | 原料を船で直接受けられる立地。新規には作れず、最大の参入障壁                   |
| **歩留まりと品質の蓄積**     | 装置を買っても付いてこないノウハウ                                             |
| **顧客とのスペックの紐づき** | 製パン各社は特定の粉に製法を合わせている。乗り換えコストが高い                 |
| **物流網**                   | バラ輸送の拠点網と小口配送のカバー                                             |
| **副産物の販路**             | ふすま・ミールを安定消化できる飼料メーカーとの関係                             |
| **原料調達力**               | 製粉は制度で平準化されるが、**製糖・製油は商社との関係と為替ヘッジ能力が効く** |
| **多角化の巧拙**             | 素材だけでは利益が細る。下流か横へ出られるか                                   |

**製粉では「原料の仕入れで差がつかない」**という点が特異である（全社が同じ政府売渡価格）。
そのぶん競争は製品ミックスと装置効率、そして加工食品事業の巧拙に向かう。

## 7. 規制・法制度

| 制度                         | 根拠法                                             | 中身                                                                           |
| ---------------------------- | -------------------------------------------------- | ------------------------------------------------------------------------------ |
| **小麦の国家貿易**           | 食糧法（主要食糧の需給及び価格の安定に関する法律） | 政府が輸入小麦を全量買い取り、製粉会社に売り渡す。売渡価格は年2回改定          |
| **マークアップ**             | 同上                                               | 買付価格への上乗せ。国内産麦の生産振興（経営所得安定対策）と政府管理経費に充当 |
| **SBS（売買同時入札）**      | 同上                                               | 実需者が銘柄を指名して買える国家貿易の例外枠                                   |
| **糖価調整制度**             | 砂糖及びでん粉の価格調整に関する法律               | 輸入糖から調整金を徴収し、国産てん菜糖・甘しゃ糖へ交付金。alicが実施           |
| **加糖調製品への課税措置**   | 関税暫定措置法ほか                                 | 調整金を回避する迂回輸入を塞ぐため、2018年のTPP11発効に合わせて導入            |
| **経営所得安定対策（ゲタ）** | 農業の担い手経営安定法ほか                         | 国産麦・大豆などの生産者へ交付。マークアップが財源の一部                       |
| 食品表示・食品衛生           | 食品表示法、食品衛生法                             | アレルゲン表示（小麦）、原料原産地表示など                                     |

> 制度の要点は**「輸入品から取って、国産品に回す」**という一点に尽きる。
> 小麦のマークアップも砂糖の調整金も、発想はまったく同じである。
> 詳細は [制度が価格を決める世界](01_制度が価格を決める世界.md)。

## 8. 最近のトピック

→ [04 直近トピック 2026](04_直近トピック_2026.md)（出典URL付き）

1. **輸入小麦の政府売渡価格が2026年10月期に+12.0%、70,020円/トン**。3年半ぶりの7万円台。
   米国の干ばつ、欧州の高温、ロシア・ウクライナ情勢、円安、海上運賃高が同時に効いた。
2. **食用油は2026年前半だけで大手2社が相次いで値上げ**。業務用・加工用は最大22%前後。
   理由にバイオ燃料・SAF需要が挙がるようになった。
3. **2026年3月期は製粉が増収増益、製油が大幅減益**。同じ環境でも制度の有無で結果が反転した。
4. **製糖は合併と工場閉鎖が同時進行**。ウェルネオシュガーが東洋精糖を合併予定（2026年10月）、
   DM三井製糖は子会社3社の生産を2026年9月末で終了し、栄養・健康分野へ軸足を移す。
5. **国産回帰は原料がボトルネック**。米粉は需要が伸びたのに作付が減り、
   こめ油は米ぬかの発生量減少が課題になっている。
