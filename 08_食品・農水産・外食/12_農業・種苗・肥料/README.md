## 1. 業界の定義・範囲

このフォルダが扱うのは **「農産物を作る営み」と「そのために買う資材」** の2つ。

```
 【この業界の範囲】

  ┌─ 種苗（種・苗） ──┐
  ├─ 肥料 ───────────┤
  ├─ 農薬 ───────────┼──▶ 【農業経営体】──▶ 集荷・卸 ──▶ 食品メーカー
  ├─ 飼料 → 畜産へ ──┤       農家・法人              　　　  外食・小売
  └─ 農業機械 → 別ノート┘      集落営農
       ▲ここが「農業資材」     ▲ここが「農業」
         ＝本フォルダ            ＝本フォルダ
```

**境界の引き方**

- **農業機械**は [02_自動車・機械/08_農業機械](../../02_自動車・機械/08_農業機械/README.md) に委譲。

| サカタのタネ 売上高                  | **1,042.8億円**（前期比+12.2%）、営業利益131.2億円                   | 2026年5月期、同社決算                            |
| 食料自給率                           | カロリーベース **37%**／生産額ベース **66%**／摂取熱量ベース **45%** | 2025年度、農水省                                 |
| %PSE（農業者受取額に占める政策支持） | 日本 **約36%**（OECD平均19%、EU17%、米国11%）                        | 2022年、OECD**推計**。関税による価格上乗せを含む |

> **成長性の見方**：産出額は横ばい圏で推移する一方、**経営体だけが急減している**。
> つまりこの産業の成長ドライバーは「市場の拡大」ではなく **1経営体あたりの規模拡大（集約）**。
> 資材メーカー（種苗・肥料・農薬・農機）にとっては、
> **顧客数は減るが1顧客の購買額は増える**という、流通チャネルの作り直しを迫る変化になる。

## 3. バリューチェーン（川上 → 川下）

```
 川上（資材）                 生産                 集出荷・流通            消費

 種苗 ─────────┐                              ┌─ JA・全農（共販）─┐
  サカタ/タキイ  │                              │   ▲委託販売手数料  │
  農研機構/県    │                              │                    │
                 ├──▶ 農業経営体 ──── 出荷 ────┼─ 産直・直販 ───────┼──▶ 卸売市場
 肥料 ─────────┤      82.8万                  │   ▲価格決定力を     │     食品メーカー
  尿素/りん安/   │      基幹的従事者103.6万人    │     取りにいく形     │     外食・中食
  塩化加里       │      平均67.7歳               │                    │     スーパー
  ▲ほぼ全量輸入 │                              └─ 契約栽培 ─────────┘
                 │                                   ▲実需者と直結
 農薬 ─────────┤
  国内3,400億円  │
  ▲登録に10年    │
                 │
 農機 ─────────┘  → [農業機械](../../02_自動車・機械/08_農業機械/README.md)

  ▲付加価値が厚い    ▲最も薄い。価格決定力が    ▲手数料・マージン
    ＝知財と資源       乏しく、補助金で補う構造
```

**どこに付加価値が集まるか**

- **川上の資材（特に種苗と農薬）は知財に守られて利益率が高い**。開発費は重いが、
  権利期間中は代替が効かない
- **肥料は市況商品**。原料の国際価格と為替がそのまま乗るため、流通段階のマージンは薄い
- **生産（農業経営体）が最も薄い**。相手が市場価格であり、規模が小さく、価格転嫁の交渉力が乏しい。
  そこを補うのが交付金と国境措置（関税）という設計になっている
- **集出荷・流通は手数料ビジネス**。JAの共販は数量をまとめることで交渉力を作る仕組み

## 5. 収益モデル・コスト構造

```
 【生産側（農業経営体）】

  収入 ＝ 販売収入（面積 × 単収 × 価格）＋ 交付金・共済金
  費用 ＝ 労働費 ＋ 農機具費（償却・修理）＋ 肥料費 ＋ 農薬費
         ＋ 光熱動力費 ＋ 地代・賃借料 ＋ 種苗費

   ★ 労働費と農機具費が大きく、短期では動かせない（固定的）
   ★ 短期で動かせるのは 肥料・農薬・燃料 ＝ だから資材費の話題になりやすい
   ★ 価格は自分で決められない ＝ 収入側を能動的に動かせるのは「面積」だけ
      → 規模拡大しか所得増の道がない、という構造
```

| プレイヤー             | 何で儲けるか                                                   | 利益率の目安・特徴                                               |
| ---------------------- | -------------------------------------------------------------- | ---------------------------------------------------------------- |
| 農業経営体（水田作）   | 面積×単収。所得の相当部分を交付金が占めることが多い            | 米価の変動と交付金設計に業績が左右される                         |
| 農業経営体（施設園芸） | 単位面積あたりの売上が高い                                     | **暖房燃料と電気が原価の大きな部分**。エネルギー価格に直撃される |
| 種苗会社               | 品種という知財の使用権。**開発は長期・無収入、登録後に回収**   | 研究開発費が重い。営業利益率は1桁後半〜10%台のことが多い         |
| 農薬メーカー           | 新規有効成分の特許期間中に回収。特許切れ後はジェネリックと競合 | 開発10年・数十億〜100億円超と言われる。医薬品に近い              |
| 肥料メーカー・商社     | 原料を輸入して加工・配合。**市況と為替のスプレッド**           | 市況商品。在庫評価で損益が振れる                                 |
| JA（経済事業）         | 購買・販売の手数料                                             | **薄利〜赤字。信用・共済の収益で営農指導を支える総合事業モデル** |

## 6. 競争要因（KSF）と参入障壁

**生産側のKSF**

1. **面積を集められるか**（＝地域での信用。農地は「貸したい人が選ぶ」）
2. **通年の作業設計**（法人は雇用を抱えるため、冬場の仕事を作れるかが利益を決める）
3. **販路の確保**（共販に任せるか、契約栽培・直販で価格決定力を取りにいくか）
4. **補助金・交付金の制度理解**（制度を知っているかどうかで所得が数百万円変わりうる）
5. **資材の調達力**（銘柄集約・大型規格・商系との相見積り）

**資材側のKSF**

1. **育種・開発のパイプライン**（種苗・農薬とも、次の新品種／新規剤が途切れないこと）
2. **知財の国際的な取得**（属地主義。日本で登録しても海外では効かない）
3. **登録・規制対応の体力**（農薬登録、ゲノム編集の届出、各国承認）
4. **原料の調達網**（肥料は産地が地質で決まるため、外交・長期契約が武器になる）
5. **流通チャネル**（JA系統と商系の両にらみ。大規模法人への直販比率が上がっている）

| 参入障壁               | 強さ   | 理由                                                                |
| ---------------------- | ------ | ------------------------------------------------------------------- |
| **農地の取得・賃借**   | **強** | 農地法の許可制。よそ者が農地を集めるのは容易ではない                |
| **育種のリードタイム** | **強** | 交配から登録まで10年超。資金を寝かせられる体力が要る                |
| **農薬の登録**         | **強** | 10年・数十億〜100億円超。既存大手以外はジェネリックからしか入れない |
| 肥料原料の調達         | 中〜強 | 鉱山・ガス田という上流を押さえているのは海外大手                    |
| 肥料の製造・配合       | 中     | 配合・造粒自体の技術障壁は高くない                                  |
| 農産物の生産そのもの   | 弱〜中 | 技術習得は可能。ただし**採算に乗せる面積の確保**が実質的な壁        |

## 7. 規制・法制度

| 分野               | 主な制度                                                                                                                                                     |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **農政の基本**     | **食料・農業・農村基本法**（2024年6月改正・施行。食料安全保障を理念の柱に）／食料・農業・農村基本計画                                                        |
| **不測時対応**     | **食料供給困難事態対策法**（2026年4月1日施行）。3段階で要請・指示、生産計画の届出違反に20万円以下の罰金                                                      |
| **取引・価格転嫁** | **食料システム法**（2026年4月施行と報じられる）。生産コストの取引価格への反映を協議する枠組み                                                                |
| **農地**           | 農地法（売買・賃借・転用の許可）／農業経営基盤強化促進法（地域計画）／農地中間管理事業法（農地バンク）                                                       |
| **米**             | 食糧法。生産数量目標の配分は2018年産で廃止、現在は「生産の目安」＋水田活用の直接支払交付金による誘導                                                         |
| **経営安定**       | ナラシ（収入減少影響緩和交付金）／ゲタ（畑作物の直接支払交付金）／収入保険／農業共済                                                                         |
| **種苗**           | **種苗法**（品種登録・育成者権。2020年改正で自家増殖の許諾制・海外持出制限、2026年に期間35年化と仮保護の改正案）／種子法は2018年廃止・多くの道県が条例で代替 |
| **バイオ**         | カルタヘナ法（遺伝子組換え生物の環境影響）／食品衛生法（GM食品の安全性審査）／ゲノム編集は届出制                                                             |
| **農薬**           | **農薬取締法**（登録制。2018年改正で再評価制度を導入）／食品衛生法のポジティブリスト制度（残留基準）                                                         |
| **肥料**           | 肥料の品質の確保等に関する法律（旧・肥料取締法）／**経済安全保障推進法の特定重要物資**に肥料を指定（2022年12月）                                             |
| **環境**           | **みどりの食料システム戦略**（2021年）と**みどりの食料システム法**（2022年7月施行、みどり認定）                                                              |
| **組織**           | 農業協同組合法（2015年改正で中央会制度の見直し、准組合員の事業利用規制は継続的な論点）                                                                       |

> **この分野の読み方**：農政は **「制度が変わると経済が変わる」** 度合いが極めて高い。
> 米価も、種の価格も、肥料の負担も、直接に制度設計の関数になっている。
> 一方で **どの制度も評価が割れている**。制度の仕組みを正確に押さえたうえで、
> 賛否の論拠を両方知っておくのが、この業界の「常識レベル」の内容になる。

- **コメ政策が2年で反転**。2026年産主食用米の生産の目安は **711万トン（前年比約2%減）** とされ、
  前政権の「増産」方針は事実上撤回。**政府備蓄米の買い入れも2026年産から再開（21万トン）**と報じられる
- **米価は店頭も農家手取りも下落**。2026年8月下旬のスーパー5kg平均は **3,112円**。

- **食料供給困難事態対策法が2026年4月1日に施行**。3段階の要請・指示と罰則を備えた枠組みが動き出した。
  同時期に食料システム法（価格転嫁）も施行
- **種苗法の再改正**。**育成者権を25年→35年（樹木40年）に延長**し、**出願公表後の仮保護**で
  登録前の輸出差止を可能にする内容。農業団体からは自家増殖の制限強化として反対も
- **2026年秋肥は値上げ**。輸入尿素 **+14.5%**、塩化加里 +7.3%、高度化成 +5.0%（JA全農発表）。
  中東情勢と円安が主因。一方で尿素の中国依存は27%→3%に低下するなど**輸入先の多元化は進展**。
  ただし **りん安は中国依存72%が残る**
- **2025年農林業センサス確定値**：経営体 **82.8万**、基幹的農業従事者 **103.6万人・平均67.7歳**。
  **今いる人が一斉に引退する時期が10年以内に来る**ことが確認された
- **食料自給率（2025年度）はカロリーベース37%（△1pt）、生産額ベース66%（+2pt）**。
  米の消費減と在庫増が国産供給熱量を押し下げた
