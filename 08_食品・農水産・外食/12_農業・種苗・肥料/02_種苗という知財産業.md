# ② 種苗という知財産業

このノートで分かること：**なぜ農家は毎年「種を買う」のか、品種という知的財産はどう守られているのか、
日本の品種が海外に流出するとはどういうことか、そして世界の種子産業はなぜ数社に集中したのか**。

> **結論から**：種苗業は農業の川上にある **知財ビジネス** である。
> 売っているのは「袋に入った粒」ではなく、**10年かけて育てた遺伝情報の使用権**に近い。
> だから製薬業に構造がよく似ている（長い開発期間、高い研究費、権利期間で回収）。
> そして製薬と同じく、**世界では巨大な寡占**が成立し、**日本は野菜種子という特定領域だけで強い**。

---

## 1. なぜ種は「買うもの」になったのか：F1品種の仕組み

かつて農家は収穫物の一部を翌年の種に使っていた（**自家採種**）。
いま野菜の主流は **F1品種（エフワン、一代雑種）** で、これは毎年買い直すのが前提になっている。

```
 【F1品種のしくみ】

   親A（性質を固定した系統） × 親B（別の固定系統）
              │
              ▼
          F1（雑種第一代）      ← 農家が買うのはこれ
      ・形・大きさ・熟期が揃う（＝機械収穫・箱詰めに向く）
      ・親より強く育つ（雑種強勢／ヘテローシス）
      ・病害抵抗性など狙った性質を入れられる
              │
              ▼ この種を採って翌年まくと…
          F2（雑種第二代）
      ・性質がバラバラに分離する（大小・早晩が混ざる）
      → 出荷規格に合わない ＝ 商売にならない

   ★ 種苗会社は「親系統」を門外不出にして持つ。
     F1を買っても親は復元できない。これが実質的な技術防壁になる。
```

| 種類                                 | 性質                                                         | 使われ方                                                                           |
| ------------------------------------ | ------------------------------------------------------------ | ---------------------------------------------------------------------------------- |
| **F1品種**                           | 揃いが良い／強い。自家採種すると形質が分離する               | 野菜の主流。トマト・キャベツ・ブロッコリー等                                       |
| **固定種・在来種**                   | 自家採種しても同じ性質が出る（何代も選抜して固定済み）       | 伝統野菜、有機・自家採種志向の農家                                                 |
| **自殖性作物（イネ・ムギ・ダイズ）** | 自分の花粉で受精するためF1化が技術的に難しく、固定品種が主流 | **コメの種もみは自家採種や県の原種センター経由が多い**。ここがF1野菜と決定的に違う |

> **よくある誤解の整理**：「F1だから毎年買わされる」は半分正しく、半分は不正確。
> F1が広がったのは**規格が揃うから流通が回る**という出口側の要請が大きい。
> 一方で「種の自給を企業に握られた」という懸念も現に存在する。
> **技術的な理由と、産業支配への懸念は、別のレイヤーの話として分けて考える**のが整理のコツ。

## 2. 品種を守る制度：種苗法と育成者権

新しい品種を作った人（育成者）の権利を守る法律が **種苗法**。特許法の農業版と考えると早い。

| 項目               | 内容                                                                                                                 |
| ------------------ | -------------------------------------------------------------------------------------------------------------------- |
| **品種登録**       | 農水省に出願 → 審査（実際に栽培して特性を確認）→ 登録。審査には年単位かかる                                          |
| **登録の要件**     | 区別性（既存品種と違う）・均一性・安定性・未譲渡性（出願前に売っていない）                                           |
| **育成者権**       | 登録品種の種苗の生産・譲渡・輸出入などを独占できる権利                                                               |
| **存続期間**       | **25年**（樹木は30年）。※2026年の改正案で **35年（樹木40年）** への延長が審議された（→[④](04_直近トピック_2026.md)） |
| **権利の及ぶ範囲** | 種苗だけでなく、**収穫物**、さらに一定の加工品にも及ぶ場合がある                                                     |
| **登録品種の表示** | 種袋や苗に「登録品種」等の表示。買う側はこれで判別する                                                               |

```
 【品種開発の時間軸（イメージ）】

  交配 ─▶ 選抜（数年〜10年）─▶ 系統固定 ─▶ 出願 ─▶ 審査(数年) ─▶ 登録
   │                                            │              │
   └── ここは完全に自社負担・無収入 ────────────┘              └─ ここから25年
                                                                    （改正案では35年）
   ★ 出願〜登録の「数年の空白」に無断増殖されても止めにくい
     → これが2026年改正案の主眼（出願公表後の仮保護）
```

### 2020年の種苗法改正で何が変わったか

2020年12月成立、2021年4月・2022年4月に段階施行。争点になった改正なので、内容を正確に。

| 改正点             | 改正前                                                       | 改正後                                                                   |
| ------------------ | ------------------------------------------------------------ | ------------------------------------------------------------------------ |
| **自家増殖**       | 登録品種でも原則として農家の自家増殖は自由（一部作物を除く） | **登録品種の自家増殖には育成者の許諾が必要**                             |
| **海外持出制限**   | 品種登録時に制限をかけられない                               | 登録時に **「日本国内限定」「○○県内限定」** といった利用条件を付けられる |
| **栽培地域の指定** | なし                                                         | 産地限定のブランド品種を制度的に守れる                                   |
| **侵害立証**       | 育成者側の立証負担が重い                                     | 特性表を活用した推定規定等で立証しやすく                                 |

**注意すべき事実関係**

- 対象は **登録品種のみ**。一般品種（在来種・品種登録されていない品種・登録が切れた品種）は対象外。
  作付面積ベースでは **多くの品目で一般品種が主流**（米は8〜9割が一般品種とされる）
- 許諾は「禁止」ではなく「手続き」。都道府県や農研機構が育成した品種については、
  包括的に許諾したり無償にしたりする運用が広く行われている

**それでも割れている論点**

| 賛成側の論拠                                                           | 懸念側の論拠                                                               |
| ---------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| 海外流出を止めないと育成投資が回収できず、結局は新品種が生まれなくなる | 許諾手続きが農家の負担・コストになる。将来的に有償化が進む可能性           |
| ブランド産地（あまおう、シャインマスカット等）を守る手段が必要         | 公的機関の育種が縮小すれば、民間・多国籍企業への依存が強まる               |
| 登録品種に限った限定的な規制である                                     | 「登録品種が今後増えれば、実質的に自家採種は難しくなる」という時間軸の懸念 |

→ このノートは制度の構造と双方の論拠を並べるにとどめ、どちらが正しいかは評価しない。

## 3. 海外流出問題：なぜ止められなかったのか

シャインマスカット（農研機構が育成、2006年品種登録）は、中国・韓国で大規模に栽培されている。
**これは主に「違法」ではなく「権利が無かった」ために起きた**という点が重要。

```
 【流出の構造】

  日本で品種登録（国内の育成者権）
        │
        │  ★ 育成者権は「国ごと」に取る必要がある（属地主義）
        │     日本の登録は海外では効かない
        ▼
  誰かが枝・苗を持ち出す（当時は持出制限の制度が無い）
        │
        ▼
  現地で栽培・増殖 ─▶ 現地で別名で品種登録されることすらある
        │
        ▼
  第三国（東南アジア等）の店頭で日本産と競合
        → 日本からの輸出が伸びない ＝ 逸失利益
```

| 事実                       | 内容                                                                                        |
| -------------------------- | ------------------------------------------------------------------------------------------- |
| イチゴの流出による損失試算 | 農水省の試算で **5年間で約220億円**（韓国産イチゴの第三国輸出による逸失利益の推計）         |
| 主な流出品目               | ぶどう（シャインマスカット）、いちご、さくらんぼ、いぐさ 等                                 |
| 根本原因                   | ①海外での品種登録をしていなかった ②持出しを止める制度が無かった ③出願から登録までの空白期間 |

**対策として整理されてきたもの**

1. **海外での品種登録を先に取る**（各国で出願。費用と時間がかかるため農水省が支援事業を設けている）
2. **国内登録時に海外持出制限をかける**（2020年改正）
3. **出願中の期間も守る**（2026年改正案の仮保護。警告書を出せば輸出差止が可能に）
4. **DNA品種識別**：流出先の作物が当該品種かを遺伝子で判定する技術

> **ポイント**：種苗の知財は特許と同じで **「国ごとに取る」**。
> 日本の登録は中国では何の意味も持たない。
> 流出問題の本質は「盗まれた」ことより **「先に現地で権利を取っていなかった」** ことにある。

## 4. 日本の種苗プレイヤー：野菜種子という「勝っている領域」

| 企業・機関                      | 立ち位置                       | 特徴                                                                                                                                                          |
| ------------------------------- | ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **サカタのタネ**（上場）        | 世界の野菜種子で上位10社の一角 | 2026年5月期 売上高 **1,042.8億円**（前期比+12.2%）、営業利益 **131.2億円**（同+7.1%）。**ブロッコリーで高い世界シェア**を持つとされる。海外卸売が成長の牽引役 |
| **タキイ種苗**（非上場）        | 同じく世界上位クラス           | 京都本社。東南アジアのキャベツ等に強いとされる。非上場で開示は限定的                                                                                          |
| **カネコ種苗**（上場）          | 飼料作物・牧草・花きなどに強い | 種苗だけでなく農業資材・園芸の卸も手がける                                                                                                                    |
| **雪印種苗**                    | 牧草・飼料作物                 | 畜産と連動（→ [畜産・飼料](../13_畜産・飼料/README.md)）                                                                                                      |
| **みかど協和・ナント種苗 ほか** | 中堅専門種苗                   | 特定品目に特化して生き残る                                                                                                                                    |
| **農研機構・都道府県の試験場**  | **公的育種**                   | コメ・麦・果樹の主要品種は公的機関育成が多い。「コシヒカリ」「シャインマスカット」等。民間が採算を取りにくい領域を担ってきた                                  |

```
 【日本の種苗が強い領域・弱い領域】

   強い ────────────────────────▶ 弱い

  野菜のF1種子           花き種子      穀物（トウモロコシ・大豆）
  ブロッコリー/キャベツ/  パンジー等    ＝ バイエル・コルテバの主戦場
  トマト/ニンジン 等                    種子＋除草剤＋形質のパッケージ
   ▲ 育種の手間が重く、                  で圧倒的。日本勢はここに入れない
     品目ごとに職人的知見が要る
     → 規模より「品目の目利き」が効く
```

**なぜ日本勢が野菜で残れたか**：野菜は品目数が多く、地域ごとに求められる性質（耐病性・日長反応・食味）が
細かく違うため、**巨大企業の規模の経済が効きにくい**。一方、トウモロコシ・大豆のような大面積の単一作物では、
遺伝子組換え形質と除草剤をセットで売るモデルが成立し、そこは完全に欧米勢の領域になった。

## 5. 世界の種子産業：なぜ数社に集中したのか

```
 【2010年代後半の大再編】

  モンサント ──買収──▶ バイエル（2018年、約630億ドル規模と報じられた）
  デュポン＋ダウ ──統合──▶ 農業部門を分離 ──▶ コルテバ・アグリサイエンス（2019年）
  シンジェンタ ──買収──▶ 中国化工（ChemChina）→ シンジェンタ・グループ（2017年）
  BASF ──── バイエルの一部事業を取得して種子に本格参入

  → 種子 × 農薬 × デジタル農業 を1社で束ねる「4大グループ」体制へ
```

| 企業                               | 本拠         | 強み                                                                       |
| ---------------------------------- | ------------ | -------------------------------------------------------------------------- |
| **バイエル（Crop Science）**       | 独           | 旧モンサント。トウモロコシ・大豆の形質と除草剤（グリホサート）のパッケージ |
| **コルテバ・アグリサイエンス**     | 米           | 旧デュポン・パイオニア＋ダウ。種子と農薬の両輪                             |
| **シンジェンタ・グループ**         | 瑞／中国資本 | 農薬に強く、種子も上位。中国の農業政策と結びつく                           |
| **BASF（Agricultural Solutions）** | 独           | 農薬が主軸、種子は特定作物                                                 |
| **サカタのタネ／タキイ種苗**       | 日           | **野菜・花きの特化型**。上の4社とは土俵が違う                              |

**寡占が成立した経済的な理由**

1. **育種の固定費が上がり続けた**：ゲノム解析・マーカー選抜（DNAの目印で有望個体を選ぶ手法）の導入で、
   研究開発が装置産業化した
2. **種子と農薬のセット販売**：除草剤耐性の形質を持つ種子 ＋ その除草剤、という組み合わせで囲い込める
3. **規制対応コスト**：遺伝子組換え作物の各国承認には巨額の費用と時間がかかり、大手しか負担できない
4. **デジタル農業**：処方マップ・収量データを握ると、次に何を売るかが決まる（→ [スマート農業](../../02_自動車・機械/08_農業機械/03_スマート農業.md)）

> **農薬業界と同じ構図**。詳しくは [③ 肥料・農薬の経済](03_肥料・農薬の経済.md) の農薬の章を参照。
> 種子と農薬は「別の商品」ではなく、**同じ顧客に同じタイミングで売る一体の商品**になっている。

## 6. ゲノム編集と遺伝子組換え：規制の差が産業を決める

この2つは技術も規制も違う。混同すると話が噛み合わない。

| 軸             | 遺伝子組換え（GM / GMO）                                             | ゲノム編集（主にSDN-1型）                                                                 |
| -------------- | -------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| **やること**   | 他の生物の遺伝子を **外から入れる**                                  | 自分のゲノムの特定箇所を **切って壊す（外来遺伝子を残さない）**                           |
| **できる変化** | 自然には起きない性質（Bt毒素の産生など）                             | 自然突然変異や従来の放射線育種でも起こりうる変化の範囲                                    |
| **日本の規制** | カルタヘナ法による環境影響審査 ＋ 食品衛生法の安全性審査（**必須**） | 外来遺伝子が残らない場合は **届出（情報提供）で流通可能**                                 |
| **表示**       | 遺伝子組換え表示制度あり                                             | 届出制。義務表示は課されていない                                                          |
| **EU**         | 厳格なGMO規制。栽培はほぼ進まず                                      | **原則としてGMOと同じ扱い**（新ゲノム技術=NGTの規則案を検討中で、緩和の方向で議論が続く） |
| **米国**       | USDA・FDA・EPAの3機関体制                                            | 一定要件でGMO規制の対象外                                                                 |

```
 【日本の運用（ゲノム編集食品）】

   開発 ──▶ 厚労省/消費者庁 へ 届出（外来遺伝子が残っていないことを説明）
                  │
                  ├─ 残っていない（SDN-1）──▶ 従来品種と同等の扱い ──▶ 流通可
                  │
                  └─ 外来遺伝子が入った（SDN-2/3の一部）──▶ GMOとして安全性審査

   国内の届出例：
     ・GABA高蓄積トマト（サナテックシード、2020年12月に届出受理と発表）
     ・可食部を増やしたマダイ／成長の速いトラフグ（リージョナルフィッシュ、2021年）
```

**産業としての意味**

- ゲノム編集は **規制コストが劇的に低い**。GMOで数十億〜百億円規模かかった承認費用が桁違いに下がる
  → 大学発ベンチャーや中堅種苗会社でも品種を出せる可能性がある
- ただし **消費者受容** は別問題。流通・小売が扱うかどうかで実際の市場が決まる
- EUの扱いが緩和されれば世界の開発が一気に動く。**規制が産業構造を決める典型例**

論点としては、「表示がないと選べない」という消費者側の主張と、
「自然突然変異と区別できないものに表示は技術的に検証不能」という開発側の主張が対立している。
これも決着していない。

## 7. 種子法廃止（2018年）という別の論点

種苗法と混同されやすいが、**主要農作物種子法（種子法）は別の法律**。

|                        | 種子法                                                           | 種苗法                                   |
| ---------------------- | ---------------------------------------------------------------- | ---------------------------------------- |
| 目的                   | 都道府県に **米・麦・大豆の優良種子の生産・普及** を義務づける   | **品種の知的財産**（育成者権）を保護する |
| 動き                   | **2018年4月に廃止**                                              | 2020年に改正、2026年に再改正案           |
| 廃止の理由（政府説明） | 民間の参入を妨げている。都道府県の取組は予算措置等で継続できる   | —                                        |
| 懸念された点           | 公的な種子供給が細り、種子価格の上昇や民間依存が進むのではないか | —                                        |
| その後                 | 多くの道県が **独自の種子条例** を制定し、従来の体制を維持した   | —                                        |

> つまり結果として、**都道府県の種子供給は条例で続いている**。
> 廃止の影響を「大きかった／小さかった」と断定するには時間がまだ足りない、というのが実務的な見方。

| 用語                           | 意味                                                                                                                 |
| ------------------------------ | -------------------------------------------------------------------------------------------------------------------- |
| **F1品種（一代雑種）**         | 異なる固定系統を交配した雑種第一代。形質が揃い生育も旺盛。自家採種すると次代で性質が分離するため毎年買い直すのが前提 |
| **雑種強勢（ヘテローシス）**   | 雑種第一代が両親より旺盛に育つ現象。F1が使われる生物学的な理由                                                       |
| **固定種・在来種**             | 自家採種しても同じ性質が再現される品種。伝統野菜など                                                                 |
| **自家増殖／自家採種**         | 収穫物や株の一部から次作の種苗を得ること。登録品種は2020年改正後、育成者の許諾が必要                                 |
| **育成者権**                   | 品種登録によって発生する独占権。種苗法に基づく。存続期間は現行25年（樹木30年）                                       |
| **品種登録**                   | 農水省への出願・審査を経て育成者権を得る手続き。区別性・均一性・安定性等が要件                                       |
| **登録品種／一般品種**         | 育成者権が存続しているものが登録品種。在来種や権利切れ品種は一般品種で、自家増殖の制限を受けない                     |
| **属地主義**                   | 知的財産権は国ごとに取得・行使するという原則。海外流出問題の根本にある                                               |
| **海外持出制限**               | 2020年改正で導入。品種登録時に「日本国内限定」等の利用条件を付けられる                                               |
| **仮保護**                     | 出願公表後、登録前の期間にも一定の差止め等を可能にする仕組み。2026年改正案の柱                                       |
| **マーカー選抜（MAS）**        | DNAの目印を使って有望な個体を早期に選ぶ育種手法。育種の装置産業化を招いた技術                                        |
| **遺伝子組換え（GM）**         | 外来の遺伝子を導入する技術。カルタヘナ法と食品衛生法で審査が必須                                                     |
| **ゲノム編集（SDN-1）**        | 自らのゲノムの特定箇所を切断して変異を起こす技術。外来遺伝子が残らない場合、日本では届出で流通可能                   |
| **カルタヘナ法**               | 遺伝子組換え生物の環境への影響を規制する法律（生物多様性条約カルタヘナ議定書の国内担保法）                           |
| **種子法（主要農作物種子法）** | 都道府県に米・麦・大豆の優良種子供給を義務づけた法律。2018年廃止。多くの道県が条例で代替                             |
| **原種・原原種**               | 種子生産の元になる高純度の種子。都道府県の原種センター等が管理する                                                   |
