# ④ 直近トピック（2026年9月時点）

報道・公表資料ベースの整理。数値は発表時点のもので、**確定値・推計・報道を区別して書く**。
政策評価が割れる論点が多いため、ここでは **何が決まったか／何が争われているか** を並べ、
どちらが正しいかは書かない。

---

## 1. コメ政策が「増産」から「需要に応じた生産」へ反転（2026年）

2024〜2025年のコメ価格高騰を受けて、前政権期には **増産** に舵を切る方針が示されていた。
それが2026年産をめぐって **事実上撤回** された、というのが今年最大の農政ニュース。

| 項目                            | 内容                                                                                              | 時点・性質             |
| ------------------------------- | ------------------------------------------------------------------------------------------------- | ---------------------- |
| 2026年産 主食用米の生産量の目安 | **711万トン**（前年比 **約2%減**）                                                                | 農水省。報道ベース     |
| 位置づけ                        | 「増産」方針を撤回し、従来の **「需要に応じた生産」** に戻す                                      | 高市政権の方針とされる |
| 理由（報じられている説明）      | これ以上増やすとコメが余って価格が暴落するという農家の不安への配慮、価格の維持                    | 報道ベース             |
| 政府備蓄米                      | 2025年産で停止していた **買い入れを2026年産から再開**。**21万トン**を農家と事前契約で確保する方針 | 報道ベース             |
| 備蓄の目標水準                  | 約 **100万トン** への回復を目指すとされる                                                         | 報道ベース             |

```
 【この2年でコメ政策が振れた軌跡】

  2023年まで ── 「需要に応じた生産」＝実質的な生産調整の継続
        │
        ▼ 2024〜2025年：品薄と価格高騰、備蓄米の放出
  2025年   ── 「増産」へ転換（コメ不足への対応が最優先に）
        │
        ▼ 2026年：価格下落と農家の不安
  2026年産 ── 「増産」撤回、目安711万トン（前年比2%減）＋備蓄買入れ再開

   → わずか2年で「不足への対応」から「余りの管理」へ反転した。
     コメ政策は需給の振れに対して後追いになりやすい、という構造が露呈した形。
```

**割れている論点**

| 減産方向を支持する側                                                       | 慎重・批判する側                                                                 |
| -------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| 価格が生産費を割れば経営が続かない。現に概算金は前年から大きく下がっている | 2024〜25年の不足を招いたのは生産抑制の結果ではないか。再び絞れば同じことが起きる |
| 備蓄の積み増しは不測の事態への備えとして合理的                             | 政府買入れは実質的な価格支持であり、消費者と中食・外食の負担になる               |
| 「目安」は強制ではなく、判断は農家に委ねられている                         | 概算金と交付金を通じて実質的な誘導力は残っている                                 |

→ 制度の仕組み（生産調整の歴史と現在）は [① 日本の農業の構造](01_日本の農業の構造.md) の6章を参照。

## 2. 米価：店頭は下落、農家の手取り（概算金）も下落

| 指標                                       | 数値                                                                                        | 時点・出典                                                                     |
| ------------------------------------------ | ------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| スーパー店頭価格（全国約1,000店、5kg平均） | **3,112円**（前週比 **△44円**）                                                             | 2026年8月下旬、農水省公表を報じたもの                                          |
| 2026年産の概算金                           | 産地・銘柄により前年産から **大幅に低下**。早期米の一部は生産費の目安を下回る水準           | 2026年、報道ベース                                                             |
| 生産費の目安                               | **20,535円／60kg**                                                                          | 農水省の生産費統計が参照値として使われている                                   |
| 農家の受け止め                             | コメ農家の **85%** が2026年の概算金水準を「厳しい」と回答、**25%** が「経営継続に強い不安」 | 2026年、民間事業者（ビビッドガーデン）の調査。**アンケートであり統計ではない** |

> **同じ価格下落が、立場で正反対の意味を持つ**。消費者にとっては「安くなって良かった」、
> 農家にとっては「生産費を割った」。店頭価格と農家手取りは同時に下がりうるので、
> 「米価が適正かどうか」に共通の答えが出にくい。

新米が出回る9月以降も、民間在庫が厚く店頭価格には下押し圧力が続くとの見方が報じられている。
**最新の相対取引価格・店頭価格は農水省の月次公表で確認すること**。

## 3. 食料供給困難事態対策法が施行（2026年4月1日）

2024年の通常国会で成立していた **食料供給困難事態対策法** が、2026年4月1日に施行された。
2024年6月の **食料・農業・農村基本法** 改正（1999年の制定以来初の本格改正、2024年6月5日施行）で
**食料安全保障** が基本理念の柱に位置づけられたことを受けた、実行法にあたる。

```
 【3段階の対応スキーム】

  ① 食料供給困難 兆候 段階
       政府対策本部を設置 ──▶ 生産・出荷・販売の **要請**
             │
             ▼ 事態が深刻化
  ② 食料供給困難事態
       生産者・事業者に **出荷・販売の調整の指示**
             │
             ▼ さらに深刻（特定食料の大幅な不足）
  ③ 特定食料の増産等
       **生産計画の届出・変更の指示** ──▶ 従わない場合 **20万円以下の罰金**

   対象となる「特定食料」は米・小麦・大豆など、政令で定める。
```

| 賛成側の論拠                                                     | 懸念側の論拠                                                                   |
| ---------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| 有事に何も権限がない状態のほうが危険。枠組みを事前に作るのは当然 | 生産者に罰則付きで計画提出を求めるのは私権制限にあたる。発動要件が曖昧との指摘 |
| 発動は極めて限定的で、まず要請から段階的に進む設計               | 平時の生産基盤を細らせておいて有事に増産を命じるのは順序が逆ではないか         |
| 輸入途絶リスクは現実に存在する（肥料・飼料・小麦）               | 増産を命じても **種子・肥料・燃料が輸入依存** では実行できない                 |

関連して、**食品等の適正な取引に関する法律（いわゆる「食料システム法」）が2026年4月に施行**され、
農産物のコストを取引価格に反映させるための協議の枠組みが整えられた、と報じられている。
価格転嫁の実効性はこれから検証される段階。

## 4. 種苗法の再改正（2026年）：育成者権の期間延長と「出願中」の保護

2020年改正に続く、**2026年の種苗法改正**。2026年4月に閣議決定され、通常国会で審議された。

| 改正点                   | 内容                                                                                                           |
| ------------------------ | -------------------------------------------------------------------------------------------------------------- |
| **育成者権の存続期間**   | **25年 → 35年**（樹木は30年 → 40年）への延長                                                                   |
| **出願公表後の仮保護**   | 登録前でも、**書面で警告**すれば、出願品種の種苗の輸出や、最終消費以外を目的とした収穫物の輸出を差し止められる |
| 登録品種名称の推定規定   | 品種名称の使用に関する推定を整備し、侵害立証を容易に                                                           |
| 損害額の推定規定の見直し | 育成者の実施能力を超える数量についても一定の加算を認める方向                                                   |

```
 【なぜ「出願中」を守る必要があったか】

  出願 ──▶ 公表 ──▶ 審査（栽培試験に数年）──▶ 登録 ──▶ 育成者権
              │◀────── ★この数年間が「空白」 ──────▶│
              │
              └ シャインマスカットの流出は、まさにこの
                空白期間に起きたと指摘されてきた
                （品種登録2006年／海外での無断栽培はそれ以前から）
```

**争点**

- 反対する農業団体（農民連など）は「農家の自家増殖の自由をさらに狭める」として廃案を求めた
- 推進側は「育成投資を回収できなければ新品種が生まれず、結局は産地が弱る」と主張
- 同時期に **新たな育苗（種苗の生産・流通）に関する法案** も議論され、こちらも賛否が分かれた

制度の基礎（育成者権とは何か、2020年改正で何が変わったか）は
[② 種苗という知財産業](02_種苗という知財産業.md) を参照。

## 5. 肥料：2026年秋肥は値上げ。中東情勢と円安が効いた

JA全農が発表した **令和8肥料年度 秋肥（6〜10月）** の価格は、主要銘柄が揃って値上げとなった。

| 銘柄                 | 改定率（春肥対比） | 全農が挙げる主な理由                   |
| -------------------- | ------------------ | -------------------------------------- |
| 尿素（輸入・大粒）   | **+14.5%**         | **中東情勢の影響**で市況がいち早く上昇 |
| 塩化加里             | **+7.3%**          | 需要堅調＋円安                         |
| 高度化成（15-15-15） | **+5.0%**          | 原料市況と製造諸経費の上昇             |
| 過石                 | +4.9%              | 同上                                   |
| 硫安（粉）           | +1.4%              | 国内物流費                             |
| 尿素（国産・細粒）   | +0.2%              | 国内物流費                             |

全農は「窒素、りん酸、加里とも需要が堅調なことから昨年末より市況は上昇しており、
さらに **円安が一段と進んだ**」ことを値上げの背景として説明している。
報道では、中東情勢の悪化により **ホルムズ海峡での輸送が停滞した** ことが尿素高騰の要因とされているが、
その具体的な経緯は情報源によって記述が異なるため、**一次情報（全農の発表文）に当たるのが確実**。

**一方で、構造面では改善が進んでいる**（集計ベース、2024肥料年度）

| 原料     | 変化                                                                 |
| -------- | -------------------------------------------------------------------- |
| 尿素     | 中国依存 **27% → 3%**。マレーシア74%／ベトナム10%へ多元化            |
| 塩化加里 | ロシア・ベラルーシ依存 **37% → 0%**。カナダ78%／イスラエル7%へ       |
| りん安   | **中国依存72%が残る**（モロッコ21%）。ここだけ置き換えが進んでいない |

```
 【肥料リスクの現在地】

  尿素    ████░░░░░░  分散できた（ただし中東情勢の直撃は受ける）
  塩化加里 ███░░░░░░░  分散できた（カナダ偏重ではある）
  りん安  █████████░  ★未解決。中国が7割

  → 「肥料の脱中国は完了した」という要約は不正確。
    原料ごとに状況がまったく違う。
```

肥料は2022年12月に **経済安全保障推進法の特定重要物資** に指定されており、
輸入先の多元化、備蓄、下水汚泥資源の肥料利用などが政策的に進められている。
詳細は [③ 肥料・農薬の経済](03_肥料・農薬の経済.md)。

## 6. 2025年農林業センサス確定値：構造転換の速度が想定を超えた

2026年に確定値が出そろい、**5年前より減少ペースが速い**ことが確認された。

| 指標             | 2025年           | 比較                                                                        |
| ---------------- | ---------------- | --------------------------------------------------------------------------- |
| 農業経営体       | **82.8万経営体** | 2015年137.7万 → **10年で約4割減**                                           |
| 基幹的農業従事者 | **103.6万人**    | 2020年比 **△24.0%**（32.7万人減）。2000年の240.0万人からは25年で **△56.8%** |
| 平均年齢         | **67.7歳**       | 2000年は62.2歳                                                              |
| 65歳以上の比率   | **69.6%**        | —                                                                           |

> この数字が意味するのは「農業が衰退している」ことではなく、
> **「今いる人が一斉に引退する時期が10年以内に来る」** こと。
> 引退後の農地が担い手に渡るのか、荒廃するのかで、2030年代の姿が大きく変わる。
> これがスマート農業・農地集積・法人化のすべての政策を急がせている直接の理由になっている。

農機メーカー側から見た同じ現象は
[農業機械｜直近トピック](../../02_自動車・機械/08_農業機械/04_直近トピック_2026.md)（三菱マヒンドラ農機の撤退など）を参照。
**顧客が減るという現実が、供給側の再編として表面化している**。

## 7. 食料自給率：カロリーベース37%に低下、生産額ベースは66%に上昇

2025年度の食料自給率は、**カロリーベース37%（前年度△1pt）／生産額ベース66%（+2pt）／
摂取熱量ベース45%（△1pt）**。低下の主因として、**米の1人あたり消費量が53.3kg → 52.0kg へ約2%減り、
民間在庫が増えたこと**で国産供給熱量が押し下げられたと説明されている（農水省公表・報道ベース）。

> カロリーベースが下がりながら生産額ベースが上がったのは、
> 前者が「国産の供給熱量」で決まり、後者が「金額」で決まるため。
> 野菜・畜産物の価格が上がれば金額ベースは増える。
> **自給率は1つの数字ではない。どの指標で、なぜ動いたかまで見ないと意味を取り違える**。

品目別の弱点（小麦・大豆・油脂・飼料）の分解は
[フードテック｜日本の食産業の課題との接続](../../01_注目テーマ/13_フードテック/04_日本の食産業とフードテック.md)、
指標の定義は [① 日本の農業の構造](01_日本の農業の構造.md) の8章を参照。

## 8. 全体の構図（まとめ）

```
        世界のショック                国内の構造変化
   ┌──────────────┐        ┌──────────────┐
   │ 中東情勢・円安 ──▶ 肥料高 │        │ 経営体 10年で4割減 │
   │ 中国の輸出政策 ──▶ りん安 │        │ 平均年齢 67.7歳    │
   │ 品種の海外流出 ──▶ 知財   │        │ 農地集積は6割で停滞 │
   └──────┬───────┘        └────────┬─────┘
              │                                  │
              ▼                                  ▼
       ┌─────────────────────────────────┐
       │  政策の対応（2024〜2026年に集中）                │
       │  ・基本法改正（2024）＝食料安全保障を理念に      │
       │  ・食料供給困難事態対策法 施行（2026年4月）      │
       │  ・食料システム法 施行（2026年4月）＝価格転嫁    │
       │  ・種苗法 再改正（2026）＝育成者権35年・仮保護   │
       │  ・コメは「増産」撤回、目安711万トン＋備蓄再開   │
       └─────────────────────────────────┘
```

1. **2024〜2026年は、農政の法制度がまとめて書き換わった3年間**だった。
   基本法改正を頂点に、不測時対応・価格転嫁・知財保護の3本が実行法として下りてきた
2. 一方、**コメ政策だけは需給の振れに追随して2年で方向が反転**した。
   制度は整ったが、価格と生産量の調整という最も古い問題は解けていない
3. **資材（肥料・種苗）は「調達先の地政学」と「知財の国際化」という、農業の外側の論理で動いている**。
   国内の努力だけでは価格も流出も止まらない
4. そして最大の変数は **人**。2025年センサスが示した減少速度に対し、
   集積・法人化・スマート農業のどれもまだ追いついていない
5. 各論点で評価が真っ二つに割れているのがこの分野の常態。**どの指標で、誰の立場から語っているか**を
   毎回確認することが、ニュースを読むうえでの最低条件になる

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **生産の目安** | 国が示す主食用米の生産量の指標。2018年産で数量目標の配分を廃止して以降、強制力はない |
| **政府備蓄米** | 不作等に備えて政府が保有する米。買い入れと売り渡しで需給にも影響する |
| **概算金／相対取引価格** | 概算金＝JAが集荷時に農家へ先払いする仮渡金で、実質的にその年の米価の目安。相対取引価格＝出荷団体と卸売業者の間の取引価格（農水省が月次公表） |
| **食料・農業・農村基本法** | 農政の基本理念を定める法律。2024年6月に制定以来初の本格改正。食料安全保障を柱に据えた |
| **食料供給困難事態対策法／特定食料** | 2026年4月1日施行。3段階で要請・指示を行い、生産計画の届出に応じない場合は20万円以下の罰金。対象となる特定食料（米・小麦・大豆等）は政令で定める |
| **食料システム法** | 2026年4月施行と報じられる法律。生産コストを取引価格に反映させる協議の枠組みを定める |
| **仮保護（種苗法）** | 品種登録の出願公表後、登録前の期間にも警告により輸出差止等を可能にする仕組み |
| **肥料年度／特定重要物資** | 肥料年度は6月〜翌5月（秋肥・春肥に分けて価格改定を公表）。肥料は2022年12月に経済安全保障推進法の特定重要物資に指定 |
| **農林業センサス** | 5年ごとの農林業の全数調査。構造変化を把握する基礎統計 |
| **カロリーベース／生産額ベース／摂取熱量ベース自給率** | 順に、供給熱量で測るもの、金額で測るもの、実際に摂取した熱量（廃棄分を除く）で測るもの。動きが逆になることがある |
