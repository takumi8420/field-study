# ① 日本の農業の構造

このノートで分かること：**誰が農業をやっているのか（＝経営体と人）、農地はどうなっているのか、
コメと畑作・施設園芸は何が違うのか、JAとは何なのか、そして「補助金がいくら入っているのか」**。
日本農業の話は数字を押さえないと感情論になる。まず構造を数字で掴む。

> **結論から**：日本の農業は「**作る人が急速に減り、1人あたりの面積が増えている産業**」である。
> 産出額（約9〜10兆円）はさほど減っていないのに、経営体は10年で4割減った。
> つまり **縮小ではなく集約** が起きている。ただしその集約が農地の減少・荒廃に追いついていない、
> というのが政策論争のほぼすべての出発点になっている。

## 1. まず全体の縮尺を掴む

| 指標                 | 数値                                                                             | 時点・出典                              |
| -------------------- | -------------------------------------------------------------------------------- | --------------------------------------- |
| 農業総産出額         | おおむね **9〜10兆円台**                                                         | 2020年代、農水省 生産農業所得統計       |
| 産出額の構成比       | 畜産 **36.1%** ／ 野菜 **24.2%** ／ 米 **19.6%**（残りが果実・花き・工芸作物等） | 近年値、同上                            |
| 農業経営体           | **82.8万経営体**（2015年は137.7万 → **10年で約4割減**）                          | 2025年 農林業センサス（確定値）         |
| 基幹的農業従事者     | **103.6万人**、平均年齢 **67.7歳**、65歳以上が **69.6%**                         | 2025年 同上                             |
| 同 5年間の増減       | **△24.0%**（32.7万人減）                                                         | 2020→2025年                             |
| 耕地面積             | 約 **430万ha**（うち水田が54%前後）                                              | 農水省 耕地面積統計                     |
| 担い手への農地集積率 | **58.9%**（目標は8割）                                                           | 2021年度、農水省。近年も6割前後で頭打ち |
| 食料自給率           | カロリーベース **37%**（前年度△1pt）／生産額ベース **66%**（同+2pt）             | 2025年度、農水省                        |

```
 【日本の農業を1枚で】

   産出額 9〜10兆円          ←  トヨタ1社の売上の3分の1以下
     ├ 畜産  36%  ──▶ 実質は「輸入穀物の加工業」（→ 畜産・飼料ノート）
     ├ 野菜  24%  ──▶ 施設園芸。金額は大きいが労働集約
     ├ 米    20%  ──▶ 面積・政治的重みは最大、金額シェアは2割
     └ 果実・花き ほか

   作る人 103.6万人（平均67.7歳）
     │   ▼ 5年で△24%
   2030年代には「今の半分」が現実的な想定になっている
```

> **ポイント**：米は「金額では2割」しかない。
> にもかかわらず農政の議論がコメ中心になるのは、**面積（水田が耕地の過半）と、
> 生産調整という政策装置が米にだけ存在する**ため。金額の重みと政策の重みがずれている。

## 2. 経営体の激減と大規模化：同じコインの裏表

「農家が減った」は正しいが、それだけでは半分しか言っていない。**残った経営体は大きくなっている**。

```
 【経営体数と1経営体あたり面積の関係（イメージ）】

  2015年   経営体 137.7万  ─┐
  2020年   経営体 107.6万   │  耕地面積は 約450万ha → 約430万ha と
  2025年   経営体  82.8万  ─┘  「ゆるやかに」しか減っていない

   → 分母（経営体）が急減、分子（面積）は微減
   → 1経営体あたり面積は 必然的に増える
   → ただし「増えた面積」が丸ごと担い手に渡るわけではなく、
     一部は荒廃農地（耕作放棄地）に落ちる ←★ここが政策の焦点
```

### 3つの経営体タイプ

| 類型                         | 中身                                                       | 経済的な特徴                                                                                   |
| ---------------------------- | ---------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| **自給的農家・小規模副業**   | 年金＋兼業収入が主、農業は赤字でも継続                     | 撤退の意思決定が「経済合理性」で決まらない。だから統計上ゆっくりしか減らない                   |
| **認定農業者（個人の専業）** | 市町村が経営改善計画を認定した担い手。補助・融資の優先対象 | 面積拡大と機械投資が直結。→ [農業機械](../../02_自動車・機械/08_農業機械/README.md) の主要顧客 |
| **法人経営体・集落営農**     | 農事組合法人・株式会社。集落単位で機械と作業を共有する形も | 雇用を抱えるため **通年の仕事** が必要。冬場の作業をどう作るかが経営課題                       |

法人経営体は2025年センサスでも数を伸ばしており、**「経営体は減るが法人は増える」**という
二極化が10年単位で進んでいる。農機・肥料・種苗の各メーカーにとっては、
**顧客数は減るが1顧客あたりの単価は上がる**という商売の変化を意味する。

## 3. 農地：集積と耕作放棄という二つの流れ

農地は「増やす」ことがほぼ不可能なので、政策は**①担い手に集める（集積・集約）**と
**②荒れるのを止める（荒廃防止）**の2本立てになる。

| 制度                                    | 何をするか                                                                       | 現状の論点                                                                                                                 |
| --------------------------------------- | -------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| **農地法**                              | 農地の売買・貸借・転用に許可を要求。農業委員会が審査                             | 「農地を農地として守る」ための装置。一方で転用（宅地化）の抜け道が長年指摘されてきた                                       |
| **農地中間管理機構（農地バンク）**      | 2014年創設。出し手から農地を借り、担い手にまとめて貸す「中間の大家」             | 集積率は6割前後で頭打ち。目標8割との差が縮まらない                                                                         |
| **地域計画（人・農地プラン の法定化）** | 2023年の改正で、地域ごとに「10年後に誰がどの農地を耕すか」の目標地図を作る義務に | 2025年3月までに全国で策定。実効性はこれから                                                                                |
| **ほ場整備（大区画化）**                | 小さな田を1枚にまとめる公共事業                                                  | 大区画化がないと大型機械もスマート農業も効かない（→ [スマート農業](../../02_自動車・機械/08_農業機械/03_スマート農業.md)） |

```
 【農地の行き先は3つしかない】

        リタイアする農家の農地
                │
     ┌──────────┼──────────┐
     ▼          ▼          ▼
  ①担い手へ    ②転用      ③荒廃農地
   （集積）    （宅地・     （耕作放棄）
                太陽光）
   ▲政策が     ▲地価が     ▲ここが増えると
    望む方向     決める       元に戻すコストが
                            跳ね上がる
```

**なぜ集積が進まないのか**（複数の要因が同時に効いている）

1. **分散錯圃（ぶんさんさくほ）**：1経営体の田んぼが集落内に何十枚も散らばっている。
   面積を集めても移動時間が食う。「集積（面積を集める）」と「集約（1か所にまとめる）」は別物
2. **所有者不明農地・相続未登記**：貸し借りの相手が特定できない
3. **出し手の心理**：先祖の土地を手放す・貸すことへの抵抗。地代が安いと「貸すくらいなら荒らす」も起きる
4. **条件不利地**：中山間地域は集めても採算が合わない。集積率が上がるのは平場の水田に偏る

## 4. 水田農業（コメ）と畑作・施設園芸は「別の商売」

同じ「農業」でも、収益構造がまったく違う。これを混ぜて議論すると話が通じなくなる。

| 軸             | 水田農業（主にコメ）                                 | 畑作（麦・大豆・てん菜等）                           | 施設園芸（トマト・いちご等）                                                                                                |
| -------------- | ---------------------------------------------------- | ---------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| 儲け方         | 面積×単収×価格。**面積を増やさないと所得が増えない** | 同上。ただし輸入品との価格差が大きく交付金依存が強い | **単位面積あたりの売上が桁違い**。面積より設備と技術                                                                        |
| 労働           | 機械化が進み、**1人で数十haも可能**                  | 機械化が進む（北海道中心）                           | 極めて労働集約。人手が最大の制約                                                                                            |
| 初期投資       | 機械一式（数千万円）                                 | 大型機械（北海道は億単位も）                         | ハウス・空調・養液設備（10a あたり数千万円規模も）                                                                          |
| 変動費の主役   | 肥料・農薬・燃料・乾燥調製費                         | 肥料・種子・農薬                                     | **暖房用の燃料と電気**（→ [フードテック 生産のテクノロジー](../../01_注目テーマ/13_フードテック/02_生産のテクノロジー.md)） |
| 価格の決まり方 | 相対取引価格・概算金。**政策の影響が最大**           | ほぼ政策価格（交付金で採算を作る）                   | 市場（卸売市場）の需給。天候で乱高下                                                                                        |
| 政策との関係   | 生産調整・水田活用交付金・ナラシ                     | ゲタ（畑作物の直接支払交付金）                       | 直接の価格政策はほぼ無い                                                                                                    |

> **覚え方**：**水田は「政策の産業」、施設園芸は「エネルギーの産業」**。
> 同じ農家という言葉でも、前者は制度設計に、後者は燃料価格に業績を握られている。

## 5. JA（農協）：4事業を1つの組織でやる仕組み

JAを理解する鍵は「**農業団体である前に、地域の総合事業体である**」という点。

```
 【JAの4事業（＋営農指導）】

  ┌─ 信用事業（JAバンク）──── 貯金を集め、貸す。頂点は 農林中央金庫
  │   ▲ 収益の柱。農業以外の預金（准組合員）が原資の多くを占める
  │
  ├─ 共済事業（JA共済）────── 保険。長期共済（生命・建物）の手数料が大きい
  │   ▲ もう一つの柱
  │
  ├─ 購買事業 ──────────── 肥料・農薬・飼料・燃料・農機を農家に売る
  │   ▲ 全農が一括購買 → 県本部 → JA → 農家（→ 肥料・農薬ノート）
  │
  └─ 販売事業 ──────────── 農家の作物を集めて卸売市場・実需者へ売る
      ▲ 共同販売（共販）。委託販売の手数料が収入
         ＋ 営農指導事業（ほぼ赤字。信用・共済の収益で支える）
```

| 論点                     | 事実                                                                                           | 割れている評価                                                                                                                   |
| ------------------------ | ---------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| **准組合員のほうが多い** | 正組合員385万人に対し、准組合員636万人（2023年度、JAファクトブック）。2010年に逆転             | 「地域インフラとして当然」という見方と、「農業者の組織という建前が崩れている」という見方が対立。准組合員の事業利用規制は長く争点 |
| **信用・共済が収益の柱** | 経済事業（購買・販売）は薄利〜赤字の構造                                                       | 「金融の利益で営農指導を支える総合事業モデル」と評価する立場と、「だから農業に本気になれない」と批判する立場がある               |
| **購買の一者性**         | 全農経由の肥料・農薬は商系より高いと長年指摘され、全農は銘柄集約・大型規格で値下げを進めてきた | 「共同購買でスケールメリットが出る」対「競争がないから高止まりする」                                                             |
| **農林中金の運用**       | 2025年3月期に外国債券の含み損処理で **約1.8兆円の最終赤字** を計上したと発表                   | JAグループ全体の収益モデル（金融依存）の持続性が問われる契機になった                                                             |

**TAC（タック）**という言葉がJA関係者から出てきたら、
これは **「地域農業の担い手に出向く専任渉外担当」** のこと（Team for Agricultural Coordination の略とされる）。
大口の担い手がJA離れして商系に流れるのを防ぐために置かれた営業職、と理解すると分かりやすい。
※ 同じ「TAC」でも水産分野では **漁獲可能量（Total Allowable Catch）** を指す。
別物なので文脈で判断する（→ [水産](../11_水産/README.md)）。

## 6. コメの生産調整：歴史と、いまの姿

「減反（げんたん）」は正式名称ではないが、慣用的に生産調整を指す。
**米の作付面積を抑えて価格を支える仕組み**が、形を変えながら50年以上続いている。

| 時期         | 何が起きたか                                                                                  |
| ------------ | --------------------------------------------------------------------------------------------- |
| 1960年代後半 | 食管制度の下でコメ余りが顕在化。政府在庫が積み上がる                                          |
| **1971年**   | 生産調整の本格実施。作付けを減らした面積に奨励金                                              |
| 1995年       | 食糧管理法を廃止し **食糧法** へ。流通が段階的に自由化                                        |
| 2010年       | 戸別所得補償制度（販売価格と生産費の差を補填）を導入                                          |
| 2014年       | 同制度の単価を半減                                                                            |
| **2018年産** | **国による生産数量目標の配分を廃止**（いわゆる「減反廃止」）。以降は「需要に応じた生産」      |
| 現在         | 国は **生産の目安** を示すのみ。実質的な誘導は **水田活用の直接支払交付金**（転作助成）が担う |

```
 【「減反は廃止された」のに、なぜ生産調整が続いているのか】

  ① 国が「目安」を示す ──────┐
  ② 県・地域の協議会が配分     │  強制力はない
  ③ JAが概算金で誘導 ────────┤  しかし
  ④ 主食用米をやめて          │  ▼
     飼料用米・麦・大豆に      └─▶ 転作すると「交付金がもらえる」
     転作すると交付金              ＝ 実質的なインセンティブ設計

  → 直接の命令ではなく「お金で誘導する」方式に変わっただけ、
    という見方と、「配分廃止で農家の自由度は確かに増えた」という
    見方の両方がある。評価は割れている。
```

**現在の論点（立場によって結論が逆になる）**

- **価格を支えるべきか**：生産を抑えれば米価は上がり農家所得は守られるが、消費者と中食・外食（→ [ファストフード](../14_ファストフード/README.md)）はコストを負う
- **飼料用米の扱い**：主食用から転換すれば需給は締まり、飼料の国産化にもなる。一方「交付金がないと成立しない作物を作らせている」との批判もある
- **需要減の速度**：1人あたり年間消費量は50kg台まで落ちた（かつては100kg超）。調整の有無にかかわらず需要は縮む
- **緊急時の供給力**：作付けを抑えることは、不測の事態で増産する余地を残すことでもある（→ [直近トピック](04_直近トピック_2026.md) の食料供給困難事態対策法）

## 7. 所得の何割が補助金か：数字の読み方に注意

ここは**数字が独り歩きしやすい論点**なので、指標の定義を先に押さえる。

| 指標                               | 何を測っているか                                                                   | 日本の水準                                                                                                          |
| ---------------------------------- | ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| **%PSE（生産者支持推定量の比率）** | 農業者の受取額のうち、政策（財政支出＋**関税等による価格の上乗せ**）に由来する割合 | **約36%**（2022年、OECD推計）。OECD平均19%、EU17%、米国11%                                                          |
| **農業粗収益に占める交付金**       | 実際に振り込まれる補助金・交付金の割合                                             | 経営類型で大きく異なる。**水田作・畑作では所得の過半を交付金が占める事例も珍しくない**（農水省 営農類型別経営統計） |
| **国の農林水産予算**               | 一般会計ベース                                                                     | おおむね **2兆円台**で長年横ばい                                                                                    |

> **最重要の注意点**：%PSE の大部分は「財政支出」ではなく **国境措置（関税）による価格の上乗せ**。
> つまり「税金で払っている」のではなく「**消費者が高い価格で払っている**」部分が大きい。
> 「日本の農家は収入の4割が補助金」という要約は、この区別を落とすとミスリードになる。

**評価が割れる点**

- 「保護が手厚すぎて構造改革が遅れた」という批判（規制改革・経済学系の論者に多い）
- 「欧米も形を変えて手厚く支持している。日本だけ突出というのは指標の読み違い」という反論
- 「財政支出ベースで見れば日本の農業予算はむしろ少ない」という指摘
- いずれの立場も同じOECDデータを使って正反対の結論を出している。**どの指標で語っているかを毎回確認する**のが実務的な作法

## 8. 食料自給率という指標の読み方

| 指標                         | 2025年度の値                 | 何を測っているか                                     |
| ---------------------------- | ---------------------------- | ---------------------------------------------------- |
| カロリーベース総合食料自給率 | **37%**（前年度から1pt低下） | 供給熱量に占める国産の割合。**分母に廃棄も含む**     |
| 生産額ベース                 | **66%**（2pt上昇）           | 金額ベース。野菜・果実・畜産など単価の高い品目が効く |
| 摂取熱量ベース（新指標）     | **45%**                      | 実際に食べた熱量で計算。廃棄分を除く                 |

```
 【なぜカロリーベースだと低く出るのか】

  カロリーの重い品目 ＝ 穀物・油脂
     小麦 15%前後 ／ 大豆 6%前後 ／ 油脂 3%前後  ← ほぼ輸入
  ↓
  一方、日本が強いのは 野菜（80%前後）・米（ほぼ100%）
     しかし野菜は「カロリーが軽い」ので分子にあまり効かない
  ↓
  さらに 畜産は「国産」でも飼料が輸入なら国産扱いされない
     → 見かけ50%台 / 飼料考慮で10%前後
  ↓
  結果：カロリー37%、生産額66% という乖離が生まれる
```

品目別の詳細は [フードテック｜日本の食産業の課題との接続](../../01_注目テーマ/13_フードテック/04_日本の食産業とフードテック.md) の
自給率分解と、[畜産・飼料](../13_畜産・飼料/README.md) を参照。
**「37%」を単独で語らず、どの品目のどこが弱いかまで降りる**のが正しい使い方。

## 用語メモ

| 用語                                   | 意味                                                                                                 |
| -------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| **農業経営体**                         | 一定規模以上の農業を行う事業体。個人・法人・集落営農を含む統計上の単位                               |
| **基幹的農業従事者**                   | 普段の主な仕事が自家農業である人。「農業で食べている人」に最も近い指標                               |
| **農林業センサス**                     | 5年ごとの全数調査。農業の構造を知る一次統計の基礎                                                    |
| **認定農業者**                         | 市町村が経営改善計画を認定した担い手。補助金・融資で優遇される                                       |
| **集落営農**                           | 集落単位で機械・農地・作業をまとめて行う組織。法人化したものが農事組合法人                           |
| **分散錯圃（ぶんさんさくほ）**         | 1経営体の農地が地域内に散らばっている状態。集積の最大の障害                                          |
| **集積と集約**                         | 集積＝面積を集めること。集約＝1か所にまとめること。集積しても集約されないと効率は上がらない          |
| **荒廃農地（耕作放棄地）**             | 耕作されず、通常の農作業では作物を作れなくなった農地                                                 |
| **農地バンク（農地中間管理機構）**     | 農地を借り受けて担い手に転貸する都道府県単位の公的機関（2014年創設）                                 |
| **ほ場整備**                           | 小区画の田を大区画にまとめ、用排水路・道を整備する公共事業                                           |
| **生産調整（減反）**                   | 主食用米の作付けを抑えて需給と価格を調整する仕組み。1971年本格実施、2018年産で国の数量目標配分は廃止 |
| **水田活用の直接支払交付金**           | 水田で主食用米以外（麦・大豆・飼料用米等）を作った場合の交付金。現在の実質的な生産調整装置           |
| **ナラシ（収入減少影響緩和交付金）**   | 収入が過去平均を下回った分の一部を補填する制度                                                       |
| **ゲタ（畑作物の直接支払交付金）**     | 麦・大豆など輸入品と競合する畑作物の生産条件不利を補正する交付金                                     |
| **概算金**                             | JAが集荷時に農家へ先払いする仮渡金。実質的にその年の米価のアンカーになる                             |
| **相対取引価格**                       | 出荷団体と卸売業者の間で取引された米の価格。農水省が月次で公表                                       |
| **%PSE**                               | OECDの生産者支持推定量の比率。**関税による価格上乗せを含む**ため、財政補助の比率とは別物             |
| **正組合員／准組合員**                 | 正＝農業者でJAの議決権を持つ。准＝地域住民等で事業は利用できるが運営に関与しない                     |
| **TAC**                                | JAの担い手専任渉外担当。※水産分野のTAC（漁獲可能量）とは無関係                                       |
| **食糧法**                             | 1995年に食糧管理法を引き継いだ法律。米の流通を段階的に自由化した                                     |
| **カロリーベース／生産額ベース自給率** | 前者は供給熱量、後者は金額で計算。油脂・穀物の輸入依存が前者を押し下げる                             |
