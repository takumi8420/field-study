## このフォルダの読み方

製菓は「新商品が次々に出る華やかな業界」に見えるが、実態は逆である。
**利益を稼いでいるのは数十年〜100年前に発売された定番ブランド**で、
新商品の大半は1〜2年で消える。新商品を出す最大の目的は、売ることよりも
**棚のフェース（売場の面積）を確保し、ブランドを思い出させること**にある。

もうひとつの鍵は、**「菓子市場」という単一の市場が存在しない**ことだ。
チョコレート／スナック／ビスケット／米菓／飴・グミ／ガム／アイスは、
原料も設備も季節性も競合も違う**別々の商売**である。
だから「ガムだけが構造的に崩れ、グミだけが構造的に伸びる」という現象が同時に起きる。

なお、食品メーカー共通の基礎（損益構造・値決め・商品開発・海外展開）は
**[総合食品](../01_総合食品/README.md) に委譲**している。
このフォルダでは**製菓固有の事情**だけを扱う。

## 1. 業界の定義・範囲

**製菓（菓子製造業）** ＝ 砂糖・カカオ・穀物・油脂などを加工し、
**主食ではない嗜好品としての食品**を工業的に製造する産業。

```
【製菓の範囲と、隣接するものとの境界】

  川上                                               川下
  ───────────────────────────────────────────────▶

  原料産地      素材メーカー      ★製菓★        卸      小売     消費者
  カカオ農園 → 製糖・製粉・製油 →（本フォルダ）→ 食品卸 → CVS/SM →
  ばれいしょ畑   乳業・油脂                              DgS/100均
  茶園・米                │                             土産物店
                          └────────────────▶ 輸出・免税・越境EC

  ● 本フォルダが扱う範囲
     チョコレート／スナック菓子／ビスケット／米菓／飴・グミ／ガム
     和生菓子・洋生菓子／油菓子・豆菓子・玩具菓子／土産菓子

  ▲ 境界があいまいなもの
     アイスクリーム   … 統計上は菓子に含むが、冷凍流通という別の論理を持つ
     チルドデザート   … 乳業・デザートメーカーの領域と重なる（→ 04_乳業）
     パン             … 製パンは別業種。ただし菓子パンで境界が接する
     チョコ系飲料・茶飲料 … 飲料は別（→ 09_清涼飲料）

  ✕ 扱わないもの
     砂糖・小麦粉・油脂そのものの製造（→ 02_製粉・製糖・製油）
     外食のデザート提供（→ 14〜21）
```

境界の引き方で押さえる点。

- **「菓子メーカー」と「スイーツ店」は別の商売**。前者は工業生産・大量流通・ブランド勝負、
  後者は店舗の経済性（坪効率・人件費）で動く小売型である。
- **和菓子と洋菓子の区分は、統計上も実務上もあまり機能しない**。
  大手は両方を持ち、実際の競争はカテゴリ（チョコ、ビスケット等）ごとに起きている。
- **アイスクリームは統計上「菓子」に入る**が、冷凍物流・季節性・チャネルが独特で、
  本フォルダでは軽く触れるにとどめる。

成長性の読み方。

- **金額は過去最高、数量は前年割れ**。伸びの中身はほぼ価格改定で、工場の稼働は増えていない。
- **カテゴリ間で方向が逆**。チョコは原料高の転嫁で金額が膨らみ、グミは実需で伸び、
  ガムは縮み続けている。「菓子市場が伸びている」という一言で括ると誤読する。
- **成長は外にある**。インバウンド・輸出・海外事業が数少ない数量の伸びしろ
  （→ [③ 市場と海外](03_市場と海外.md)）。

       メーカー ────▶ 新商品提案・季節企画 ───▶ 卸／小売

付加価値がどこに溜まるか。

| 段階 | 付加価値 | 理由 |
| --- | --- | --- |
| 原料産地 | **薄い** | カカオは生産者価格が制度で決まり、相場高騰が農家に届きにくい |
| 素材加工（製糖・製粉・製油） | 薄い（営業利益率2〜5%） | 制度価格と相場の転嫁が仕事の大半 |
| **菓子メーカー** | **中程度（3〜9%）** | ブランドで単価を取れるが、販促費とリベートで削られる |
| 卸 | 薄い（1〜2%） | 物流と債権を引き受ける対価 |
| 小売（量販） | 薄い | 菓子は集客の目玉にされ、値引きの対象になりやすい |
| **土産・免税・催事** | **厚い** | **定価が通る**数少ない販路。輸送・催事コストを吸収しても残る |

> ポイント：菓子の付加価値は「どう作るか」より **「どこで売るか」** で決まる。
> 同じ商品でも、量販の特売棚と空港の土産棚では残る利益が全く違う。

## 5. 収益モデル・コスト構造

**儲け方の基本**：償却が終わった専用ラインで定番を大量に流し、
ブランド力で値引きを最小限に抑え、**販促費とリベートを削られすぎないよう守る**。

| 項目 | 目安 | 備考 |
| --- | --- | --- |
| 原材料費 | 売上の30〜45% | カカオ・砂糖・小麦・乳製品・油脂。カテゴリで大きく振れる |
| 包装資材費 | 5〜12% | 個包装が多いほど重い。小容量化で比率が上がる |
| 製造労務費・工場経費 | 10〜18% | **固定費**。稼働率が落ちると単位原価が跳ねる |
| 物流費 | 4〜8% | 軽くてかさばるため容積で運賃が決まる |
| 販促費・リベート | 8〜15% | 小売との交渉で決まる。粗利を削る最大要因 |
| 広告宣伝費 | 2〜6% | 定番は少なく、新商品は多い |
| **営業利益率** | **3〜9%** | 食品メーカー全体（5〜8%）とほぼ同じ帯。土産菓子専業はこれより高い |

固定費が効く構造が製菓の肝である。

```
【稼働率と利益の関係】

  稼働率 100%  ─────────────────────  単位原価 安い  → 黒字
  稼働率  80%  ───────────────░░░░░░  単位原価 上がる → 利益圧縮
  稼働率  60%  ──────────░░░░░░░░░░░  単位原価 高い  → 赤字に転落

  ★ 多品種化すると段取り替え（洗浄・調整）でラインが止まるため、
    見かけの稼働時間が長くても実生産量は増えない
  ★ 季節品専用の設備は、年の大半が遊ぶ
```

## 6. 競争要因（KSF）と参入障壁

| KSF | 中身 |
| --- | --- |
| **定番ブランドを持っていること** | 認知率が高い商品は広告費なしで売れ続ける。これがないと利益が出ない |
| **棚のフェースを確保する力** | 年2回の棚替え交渉で列数を維持できるか。新商品はそのためのカード |
| **専用ラインの生産効率** | 償却済みのラインで1品種を長く流せるか。切替が多いと原価が悪化する |
| **原料調達力** | カカオ・砂糖・油脂を安定して確保できるか。相場高騰局面では調達力が利益を分ける |
| **季節商戦の読み** | バレンタイン・クリスマスの数量を外すと、売れ残りがほぼ全損になる |
| **定価が通る販路の保有** | 土産・免税・催事・直販。ここを持つ会社は利益率が構造的に高い |

参入障壁。

| 障壁 | 高さ | 理由 |
| --- | --- | --- |
| 設備投資 | **高い** | 商品専用のライン・金型が必要。汎用設備では作れない |
| ブランド | **極めて高い** | 定番は数十年の蓄積。新規に作るのはほぼ不可能 |
| 棚の確保 | **高い** | 既存の定番が棚を埋めている。新規参入はエンド・催事から入るしかない |
| 許認可 | 低い | 食品衛生法の営業許可で足りる。制度的な参入規制はない |
| 小規模参入 | **低い** | ビーン・トゥ・バー、地域の土産菓子など**小さく高単価**なら成立する |

> ポイント：**全国流通の量販ブランドとしての参入は事実上不可能だが、
> 小規模・高単価・限定販路なら参入余地がある**。
> 業界の新陳代謝は主にこの「小さい側」で起きている。

## 7. 規制・法制度

| 制度 | 内容 |
| --- | --- |
| **食品衛生法／HACCP** | 2021年6月から原則すべての食品事業者にHACCPに沿った衛生管理が義務化 |
| **食品表示法** | 原材料名、添加物、栄養成分、**アレルゲン8品目の義務表示**（乳・小麦・落花生など菓子に関わるものが多い） |
| **チョコレート類の表示に関する公正競争規約** | チョコレート／準チョコレート／チョコレート菓子の区分とカカオ分の基準を定める。カカオ高で区分が動く |
| **景品表示法** | おまけ付き菓子（食玩）の景品価額の上限規制。菓子の歴史と直結する制度 |
| **砂糖の価格調整制度** | 輸入糖から調整金を徴収し国産糖を支える。国際相場がそのまま国内価格にならない（→ [製粉・製糖・製油](../02_製粉・製糖・製油/01_制度が価格を決める世界.md)） |
| **小麦の政府売渡価格** | 国が輸入小麦を製粉会社に売り渡す価格。年2回改定 |
| **機能性表示食品制度** | 健康訴求を載せる場合の届出制度。**2026年9月1日にGMP（製造管理基準）が完全施行**（→ [総合食品 ⑤](../01_総合食品/05_直近トピック_2026.md)） |
| **価格転嫁の政策支援** | 公正取引委員会・中小企業庁による転嫁円滑化の取組み。原料高局面で交渉の後ろ盾になる |
| **消費税（2027年4月〜）** | 飲食料品の税率を1%とする方針。菓子も対象。値付けと値札の全面的な見直しが必要 |
