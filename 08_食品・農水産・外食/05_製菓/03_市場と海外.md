# ③ 市場と海外

このノートで分かること：菓子の国内市場が「数量は増えないのに金額は最高を更新する」理由、
子ども向けから大人向けへの主顧客の移動、
そしてインバウンド・輸出・アジア展開という3つの外向きの出口。

## 1. 結論：国内は「食べる人が減り、単価が上がる」市場になった

```
【菓子の国内市場（2025年／令和7年、全日本菓子協会推定）】

  生産数量   196万8,100トン   前年比 ▲0.8%   ← 量は減っている
  生産金額   2兆9,403億円     前年比 +5.4%   ← 金額は伸びている
  小売金額   4兆 996億円      前年比 +5.7%   ← 初めて4兆円を突破、5年連続で過去最高

       数量 ─────────────────────────  横ばい〜微減
                    ×
       単価 ────────────────────▲▲▲▲▲  値上げで上昇
                    ‖
       金額 ────────────────▲▲▲▲▲▲▲  過去最高
```

つまり**「菓子が売れている」のではなく「同じ量が高く売れている」**。
2025年に過去最高を更新したのは、価格改定の効果が数量減を上回ったためである。
金額が伸びていても、工場の稼働（＝トン数）は伸びていない点が重要だ。

| カテゴリ（2025年） | 小売金額 | 前年比 | コメント |
| --- | --- | --- | --- |
| チョコレート | 約7,105億円 | +12.6% | カカオ高による価格改定がそのまま金額を押し上げた |
| スナック菓子 | 約6,042億円 | +3.9% | 初の6,000億円台。数量は横ばい |
| 飴菓子（キャンディ＋グミ） | 2024年に初の3,000億円台 | ― | **グミが成長の主役**（→ [①](01_菓子の商売の特徴.md) 第3章） |
| ビスケット／米菓／油菓子／その他 | ― | いずれも過去最高圏 | 価格改定効果が共通要因 |

（出典：全日本菓子協会「令和7年 菓子の生産数量・生産金額等（推定）」、および報道）

## 2. 少子化 ― 顧客の「原型」が縮んでいく

菓子は歴史的に**子どもを起点に設計されてきた商品**である。
おまけ、キャラクター、小遣いで買える価格、駄菓子屋。その基盤が数の上で細っている。

```
【15歳未満人口（総務省「人口推計」、各年4月1日現在）】

  2025年   1,366万人   44年連続の減少
  2026年   1,329万人   45年連続の減少（前年比 ▲35万人）
                       総人口に占める割合 10.8%（52年連続の低下）

  ＝ 毎年30万人規模で「将来の常連客」が消えていく計算
```

影響が直接出るのは以下のカテゴリ。

| 分野 | 起きていること |
| --- | --- |
| 駄菓子 | 単価が極端に低く（10〜50円）、値上げの余地がほとんどない。値上げできないまま原価だけ上がり、廃業・終売が続く |
| 玩具菓子（食玩） | 子ども向けからコレクター＝大人向けへ客層が移動。単価は上がったが数量は減った |
| キャラクター菓子 | 子ども向けIPだけでは数が取れず、大人が懐かしむIPの併用が増えた |
| ファミリーパック | 世帯人数の縮小で「大袋を家で分ける」機会が減少 |

> ポイント：菓子業界にとっての少子化は、**今日の売上ではなく「20年後のブランド認知」が削られる**問題。
> 子ども時代に覚えた味が一生続くという [①](01_菓子の商売の特徴.md) の構造の裏返しである。

## 3. 大人向けへの移動 ― 単価を上げられる唯一の方向

縮む子ども市場の代わりに、業界が総力を挙げて開拓してきたのが**大人の菓子**である。

| 軸 | 具体像 | 価格の効き方 |
| --- | --- | --- |
| **高カカオ** | カカオ70%以上の板チョコ、ポリフェノール訴求 | 同サイズで1.5〜2倍の単価が通る |
| **健康・機能** | 乳酸菌入りチョコ、難消化性デキストリン配合、GABA、たんぱく質バー | 機能性表示食品として届出すれば訴求が強くなる |
| **罪悪感の緩和** | 個包装・小容量・糖質オフ・「1日1枚」提案 | 容量を減らしても価格を保てる |
| **嗜好品化** | ビーン・トゥ・バー、産地別チョコ、高級ポテトチップス | 1,000円を超える菓子が成立する |
| **ひとり時間** | 自分へのご褒美、デスク菓子、晩酌のつまみ | 家族単位から個人単位への移行 |
| **シニア** | 米菓・和菓子・小分け。噛む力・塩分への配慮 | 数量は堅いが単価は上げにくい |

機能性表示食品の制度と、2026年9月に完全施行されたGMP義務化については
[総合食品 ⑤ 直近トピック](../01_総合食品/05_直近トピック_2026.md) 第6章を参照。
**菓子に「健康」を載せるハードルは制度面で上がっている**点は押さえておきたい。

## 4. インバウンド ― 菓子の位置づけを変えた最大の変化

訪日客の増加は、菓子業界にとって**「定価で売れる新しい棚」**の出現だった。

```
【菓子におけるインバウンド需要の位置】

  従来の国内販売                      インバウンド販売
  ──────────────                     ──────────────
  小売との価格交渉 → 特売 → 実売価↓    観光地・空港・ドラッグストアで
  リベート・協賛金で粗利減                 ほぼ定価で売れる
  棚のフェース争奪                        「日本限定」「日本製」が価値になる
        │                                      │
        ▼                                      ▼
    粗利 薄い                              粗利 厚い
                                          ＋ 帰国後の越境ECにつながる
```

| 指標 | 数値 | 年・出典 |
| --- | --- | --- |
| 訪日客の菓子購入額 | 約**2,900億円**（過去最高） | 2024年。報道（日本食糧新聞ほか） |
| 同 四半期 | **901.7億円**（前年同期比+33%、うち中国231億円・+71%） | 2025年1〜3月。四半期として初の900億円超。日刊経済通信社 |
| 土産菓子・ご当地菓子市場 | **3,963億円**見込み（2019年比 +13.8%） | 2025年。富士経済の推計 |

インバウンドが菓子に効きやすい理由は4つ。

1. **軽くて割れにくく、賞味期限が長い**。土産として最適な物性を持っている。
2. **個包装で配れる**。職場や親族に配る土産文化が海外にもある。
3. **日本製への信頼**。品質・衛生・パッケージの丁寧さが価格の理由になる。
4. **価格が手頃**。1,000〜2,000円で「日本らしいもの」が買える数少ないカテゴリ。

この波に最も素直に乗ったのが**土産菓子専業**である。
寿スピリッツ（銘菓の企画・製造・販売）のように、
**観光地・空港・駅という定価が通る販路に特化した会社**は、
大手NBメーカーより高い利益率を出せる構造を持つ。
関連は [旅行](../../15_サービス・生活関連/10_旅行/README.md)。

> 注意：インバウンドは**為替と外交に左右される需要**であり、恒常的な基盤とは言い切れない。
> 円安が反転すれば単価の魅力は落ち、渡航制限が出れば一夜で消える。
> 実際、中国向けの伸びは政治情勢で振れやすいと繰り返し報じられている。

## 5. 輸出 ― 抹茶・和菓子ブームという追い風

| 指標 | 数値 | 年・出典 |
| --- | --- | --- |
| 菓子類の輸出額 | **477億円**（前年比+10.7%、過去最高） | 2024年。報道・ジェトロ資料 |
| 農林水産物・食品の輸出額全体 | 1兆7,005億円（+12.8%）。2030年目標5兆円 | 2025年。農林水産省 |
| 鹿児島県茶市場のてん茶（抹茶原料）一番茶平均価格 | 6,013円/kg → **13,910円/kg** | 2026年。報道 |

輸出で起きていることを整理する。

```
【和の素材が「高く売れる」側に回った】

  かつて          抹茶・和菓子 ＝ 国内の伝統市場。単価は上がらない
                                （若年層の日本茶離れ、和菓子店の減少）
     │
     ▼ 2020年代
  いま            抹茶 ＝ 世界的な健康飲料／スイーツ素材
                  和菓子・和素材 ＝ 「日本らしさ」を象徴する輸出商品
     │
     ▼ 結果
  原料が足りない  てん茶の価格が前年の2倍超に。国内の菓子メーカーが原料を取り合う
                  → 抹茶を使った菓子・飲料の値上げが相次ぐ（2026年）
```

**ブームが原料高として跳ね返る**のが製菓らしい構図である。
抹茶菓子は「売れているのに原価が合わない」状態になりやすい。

## 6. アジア展開 ― 会社ごとに海外の重みが全く違う

| 企業 | 海外売上比率の目安 | 主戦場 | 型 |
| --- | --- | --- | --- |
| カルビー | **26.0%**（2026年3月期、海外売上886億円・+11.6%） | 北米（ハーベストスナップス）、中華圏、インドネシア、英国 | **スナックを現地の食習慣に合わせて作り替える** |
| 江崎グリコ | **約20%**（報道ベース） | 中国・東南アジア（ポッキー、プリッツ、ビスコ）、欧米 | **ポッキーという単一ブランドの世界展開** |
| 明治（明治HD食品セグメント） | 国内比率が高い。海外は中国・東南アジアの乳・菓子が中心 | 中国、インドネシア、タイ | **チョコと乳製品を軸に現地生産** |
| 森永製菓 | **約10%**（報道ベース） | 米国（ハイチュウ）、中華圏 | **単品ブランドの米国での定着**（ハイチュウのメジャーリーグ経由の浸透が有名） |
| ロッテ | 韓国・日本の二系統。グループとしてアジア広域 | 韓国・東南アジア | **グループ全体でのアジア基盤** |

（各社IR・報道による。決算期・セグメント定義が異なるため単純比較はできない）

海外展開が食品他社より難しい理由。

1. **チョコレートは温度帯の壁がある**。高温多湿の東南アジアでは、
   耐熱設計（ブルーム＝表面の白化を防ぐ処方）や冷蔵物流が必要になる。
2. **現地の「おやつ」の位置づけが違う**。屋台の食べ物や果物と競合する市場では、
   袋菓子の価格帯そのものを作り直す必要がある。
3. **味の現地化が避けられない**。甘さ・塩味・辛味・フレーバーは国ごとに正解が違う。
   ポテトチップスの味を現地開発するのはこのためである。
4. **ブランド認知をゼロから作る**。国内で100年かけて積んだ認知は海外では通用しない。

海外展開の一般的な成功・失敗パターンは
[総合食品 ④ 国内成熟と海外展開](../01_総合食品/04_国内成熟と海外展開.md) に整理されている。
**製菓は「単一ブランドを世界で通す」型（ポッキー、ハイチュウ）が効きやすい**点が特徴といえる。

## 7. PB・チャネル構造の変化 ― 競合は同業だけではない

```
【菓子の棚をめぐる三つ巴】

        NB（メーカーブランド）
          ／            ＼
         ／  価格比較     ＼  棚の取り合い
        ／                  ＼
   小売PB  ────────────  CVSオリジナル
   （安さと粗利）            （新規性と専用性）

  ・ドラッグストアと100円ショップが「菓子の安売り拠点」として存在感を増した
  ・コンビニは自社企画の菓子を増やし、NBの棚が相対的に減った
  ・ECは「まとめ買い」には強いが、かさばる菓子は送料が重く伸びにくい
```

| 相手 | 脅威の中身 | メーカーの対応 |
| --- | --- | --- |
| [小売PB](../../07_小売・流通/02_スーパー・GMS/README.md) | NBの3〜7割の価格。棚のフェースを奪う | 受託して稼働を埋めるか、差別化で棚を守るか |
| [コンビニ](../../07_小売・流通/01_コンビニエンスストア/README.md)オリジナル | 専用商品で棚を自社化 | 専用品の共同開発に入り込む |
| [ドラッグストア](../../07_小売・流通/04_ドラッグストア/README.md) | 食品を集客の目玉にして最安値を出す | 数量は出るが価格の基準点が下がる |
| [100円ショップ](../../07_小売・流通/08_100円ショップ/README.md) | 100円に収まる専用容量 | 専用規格の受託生産で対応 |
| [中食・弁当](../20_中食・弁当/README.md)／[カフェ](../19_カフェ/README.md) | 「間食の時間」そのものを奪う | 菓子の外側の競合。食シーン提案で対抗 |

## 8. まとめ：この章を理解する3つの鍵

1. **国内は数量が増えない市場**。2025年に小売4兆円を突破したのは値上げの結果で、
   生産数量は前年割れしている。
2. **顧客が子どもから大人・シニア・訪日客へ移った**。単価を上げられる方向にしか伸びしろがない。
3. **外向きの出口は3つ**。インバウンド（定価が通る棚）、輸出（抹茶・和素材の追い風）、
   アジア展開（単一ブランドの横展開）。いずれも為替と外交に左右される点は共通する。

直近の動きは → [④ 直近トピック（2026年9月時点）](04_直近トピック_2026.md)

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **小売金額／生産金額** | 生産金額はメーカー出荷ベース、小売金額は店頭販売ベース。全日本菓子協会は両方を推定で公表している |
| **飴菓子** | 統計上のカテゴリで、キャンディとグミを含む。近年の伸びはほぼグミによる |
| **食玩（玩具菓子）** | おまけの玩具が主役の菓子。子ども向けから大人のコレクター向けへ客層が移った |
| **高カカオチョコレート** | カカオ分70%以上などを訴求した商品。ポリフェノールと結びつけて大人向けに展開される |
| **ビーン・トゥ・バー** | カカオ豆の仕入れから板チョコまでを一貫して自社で行う作り方。小規模・高単価 |
| **ブルーム** | チョコ表面が白く粉を吹く現象。温度変化で脂肪や糖が析出する。高温地域での輸出の壁 |
| **てん茶（碾茶）** | 抹茶の原料になる茶葉。覆いをして育て、揉まずに乾燥させる。世界的な抹茶需要で価格が急騰した |
| **越境EC** | 海外の消費者が国境を越えてネットで買う取引。訪日で知った菓子のリピート購買の受け皿になる |
| **海外売上比率** | 連結売上に占める海外の割合。同じ菓子メーカーでも10%台から30%近くまで開きがある |
| **PB／NB** | PBは小売の自社ブランド、NBはメーカーブランド。菓子はPB化しやすく、価格比較にさらされやすい |
