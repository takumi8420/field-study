# ④ 直近トピック（2026年9月時点）

報道と公表統計をもとにした整理。**推計・報道ベースのものはその旨を明記**している。
数値は更新が早いので、最新は各出典で確認すること。

全体像を先に言うと、2026年の製菓業界は
**「カカオ相場は急落したのに、店頭価格は下がらない」**という状態にある。
そして相場が落ち着いたチョコレートの横で、**米・抹茶という別の原料が高騰している**。

## 1. カカオ相場 ― 歴史的高騰から急落へ。ただし店頭は下がらない

```
【カカオ豆の国際価格（USドル/kg、年平均。世界経済のネタ帳＝IMF一次産品価格ベース）】

 2020  2.37  ─┐
 2021  2.43   │ 平常時。2ドル台半ばで安定
 2022  2.39  ─┘
 2023  3.28      ← 西アフリカの不作が表面化
 2024  7.33      ← 約3倍。「カカオショック」と呼ばれる
 2025  7.80      ← 2025年1月に月次 10.75ドル/kg で最高水準
 2026  4.42      ← 年平均。ピークの約1/3〜半分まで調整
       （2026年8月の月次は 5.95ドル/kg）
```

- 2026年に入って下落した背景は、**エクアドル・西アフリカの作柄改善**と報じられている。
  コートジボワール・ガーナで降雨が安定し、カカオポッドの生育見通しが上向いた。
  先物は概ね**1トンあたり3,000〜5,000ドル台**まで戻したとされる（報道ベース）。
- ただし**店頭価格への反映は遅れる**。メーカーはすでに高値で先買いした原料と契約を抱えており、
  カカオ以外（包装資材・物流・人件費・エネルギー）は上がり続けている。
  価格反映は**早くても2026年後半〜2027年以降**との見方が多い（報道ベース）。

| 論点 | 現状 |
| --- | --- |
| 相場 | ピークの約1/3〜半分まで下落（2026年） |
| メーカー仕入 | 高値玉の消化が続く。恩恵は時間差で来る |
| 店頭価格 | 下がらない。むしろ2026年も値上げが続いている |
| 商品設計 | カカオ分を抑えた処方、ナッツ・ビスケットなど代替素材の活用が拡大 |

構造的な背景（産地の偏り、病害、樹の老齢化、生産者価格の固定制度）は
[② 原料と原価](02_原料と原価.md) 第3章に整理した。
**相場が戻っても、生産構造そのものが直ったわけではない**点は押さえておきたい。

## 2. バレンタイン価格は2年連続で過去最高（2026年2月）

帝国データバンクの調査（2026年）によると、

| 指標 | 2026年 | 前年 | 変化 |
| --- | --- | --- | --- |
| バレンタインチョコ 1粒あたり平均価格 | **436円** | 418円前後 | **+4.3%**（2年連続で過去最高） |
| 同一パッケージ（平均9個入）の価格 | **3,256円** | 3,037円 | **+7.2%** |

- 価格上昇の主因は**カカオ高の転嫁**。
- 同時に、**カカオ量を抑えて代替素材（ナッツ・ドライフルーツ・ビスケット）を使う商品**が拡大した。
  「チョコの粒を小さくする」「1箱の個数を減らす」といった調整も同時に進んでいる。
- イベント商材は**売れ残りがほぼ全損**になるため、価格を上げて数量を絞る方向に振れやすい
  （→ [① 菓子の商売の特徴](01_菓子の商売の特徴.md) 第5章）。

## 3. 2026年も値上げは続いている

| 時期 | 企業 | 内容 |
| --- | --- | --- |
| 2026年5月発表 | 亀田製菓 | 「ぽたぽた焼」など米菓を**4〜10%**値上げ（6月1日納品分から）。価格改定と内容量変更を併用 |
| 2026年8月発表 | 明治 | 「きのこの山」「たけのこの里」など計14品。チョコ・スナック計11品は**11月1日出荷分から約3〜8%**。飲料3品（「辻利お濃い抹茶ラテ」等）は10月1日から**約16〜21%** |
| 2026年8月発表 | ロッテ | 「キシリトール」などボトル入りガム等を値上げ |
| 2026年 | 森永製菓 | 価格改定ならびに内容量変更を公表 |

```
【2026年の値上げの「理由」が変わった】

  2022〜2024年   原材料（カカオ・小麦・油脂）＋ 円安
                  ＝ 輸入原料が主因

  2025〜2026年   原材料（カカオは下落、しかし米・抹茶は高騰）
                  ＋ 物流費（2024年問題の定着）
                  ＋ 人件費（最低賃金・処遇改善）
                  ＋ 包装資材・エネルギー
                  ＝ ★国内コストが主因に移った★

  → 相場が下がっても値上げが止まらないのは、原因が入れ替わったため
```

## 4. 菓子市場が初めて小売4兆円を突破（2025年実績、2026年4月公表）

全日本菓子協会の推定（2026年4月公表）によると、2025年（令和7年）の菓子は、

| 指標 | 2025年 | 前年比 |
| --- | --- | --- |
| 生産数量 | 196万8,100トン | **▲0.8%** |
| 生産金額 | 2兆9,403億円 | +5.4% |
| **小売金額** | **4兆996億円** | **+5.7%**（初の4兆円台、5年連続で過去最高） |
| チョコレート（小売） | 約7,105億円 | +12.6% |
| スナック菓子（小売） | 約6,042億円 | +3.9% |

- **数量は減り、金額だけが伸びた**。伸びの中身は価格改定効果である。
- チョコレートの+12.6%はカカオ高の転嫁がそのまま乗ったもので、
  「よく売れた」わけではない点に注意。
- 飴菓子（キャンディ＋グミ）は2024年に初めて小売3,000億円台に乗せており、
  **グミが数量ベースでも伸びている数少ないカテゴリ**である。

## 5. グミの拡大と、それを支える設備投資

```
【ガムとグミの交代（報道ベース、インテージ等の推計）】

  2017年   ガム 約823億円  >  グミ 約555億円
  2020年   ガム 約612億円      （コロナ期にガムが急落）
  2021年頃 ★金額が逆転★
  2022年   グミ 約781億円  >  ガム 約548億円
  2023年3月 明治がガム事業から撤退（「キシリッシュ」終売 → 同名でグミへ転用）
  2024年   UHA味覚糖がグミ売上1位（約189億円と報じられる）
  2026年   各社が増産投資を継続
```

- UHA味覚糖は福島工場の新棟を**2027年春に稼働**予定で、生産能力を約6割増やす計画。
- カンロも複数拠点でグミの生産能力を大幅に引き上げる方針を示している。
- グミは**機能（ビタミン、鉄、たんぱく質、コラーゲン）を載せやすい**ため、
  「おいしく健康に」を軸に新領域へ広がっていると報じられる（2026年）。
- 一方で、**設備投資が出そろった後に需要が鈍ると過剰能力になる**リスクは残る。
  グミは食感を売りにする商品であり、流行の変化が速い。

## 6. 抹茶ブームが原料高として跳ね返っている

| 指標 | 数値 | 年・出典 |
| --- | --- | --- |
| 鹿児島県茶市場 てん茶（抹茶原料）一番茶 平均価格 | 6,013円/kg → **13,910円/kg** | 2026年。報道ベース |
| 日本茶の輸出 | 大幅増。粉末茶の対米輸出が大きく伸びたと報じられる | 2026年。報道ベース |

- 世界的な抹茶需要の拡大で、**てん茶の需給が崩れ、煎茶用の茶葉までてん茶に転換**が進んでいる。
- その結果、**抹茶を使う菓子・飲料の原価が急騰**した。
  明治が2026年10月から「辻利お濃い抹茶ラテ」等を約16〜21%値上げしたのは、この流れの一例。
- **輸出が伸びるほど国内の原料が高くなる**という、和素材特有の構図が出ている
  （→ [③ 市場と海外](03_市場と海外.md) 第5章）。

## 7. インバウンドと輸出は引き続き過去最高圏

| 指標 | 数値 | 年・出典 |
| --- | --- | --- |
| 訪日客の菓子購入額 | 約2,900億円（過去最高） | 2024年。報道 |
| 同 四半期 | 901.7億円（+33%、うち中国231億円・+71%）。四半期として初の900億円超 | 2025年1〜3月。日刊経済通信社 |
| 菓子類の輸出額 | 477億円（+10.7%、過去最高） | 2024年。報道・ジェトロ |
| 土産菓子・ご当地菓子市場 | 3,963億円見込み（2019年比+13.8%） | 2025年。富士経済の推計 |

- 菓子は訪日客にとって**「軽い・割れにくい・日持ちする・配れる」**という土産の条件を満たす。
- 観光地・空港・ドラッグストアという**定価で売れる販路**が増えたことは、
  価格交渉に削られ続けてきた国内販売と対照的である。
- ただし**為替と外交情勢に振られる需要**であり、恒常的な基盤とみなすのは危うい。

## 8. 決算は「増収でも利益は明暗」

| 企業 | 直近決算 | 売上 | 営業利益 | コメント |
| --- | --- | --- | --- | --- |
| カルビー | 2026年3月期 | 3,401億円（+5.5%） | 261.7億円（**▲10%**、利益率7.7%） | 海外売上886億円（+11.6%）、**海外比率26.0%**。国内ポテトチップスは1,025億円（▲0.3%）でばれいしょ収量減の影響 |
| 江崎グリコ | 2025年12月期 | 3,613.9億円（+9.1%） | 87.4億円（**▲21%**、利益率2.4%） | 増収だが利益率が薄い |
| 森永製菓 | 2026年3月期 | 2,366.7億円（+3.4%） | 過去最高を更新と発表 | 価格改定とコストダウンで利益率を改善 |
| 明治HD | 2026年4〜6月 | 2,894億円 | 226億円（利益率7.8%） | 四半期。食品セグメントが中心 |

（各社IR・報道による。決算期とセグメント定義が異なるため単純比較はできない）

```
【同じ「増収」でも中身が違う】

  値上げが通った × コストダウンが効いた   → 増収増益（森永製菓）
  値上げが通った × 原料高が上回った       → 増収減益（江崎グリコ）
  値上げが通った × 数量が落ちた           → 増収減益（カルビー国内）
  海外が伸びた                            → 利益の下支え（カルビー海外 +11.6%）

  ＝ 差を作っているのは「売上が伸びたか」ではなく
     「値上げのスピードが原価上昇を追い越せたか」
```

食品メーカー全体の増収減益・二極化の構図は
[総合食品 ⑤ 直近トピック](../01_総合食品/05_直近トピック_2026.md) 第3章を参照。

## 9. 全体の構図（2026年9月時点）

1. **カカオはピークの1/3〜半分まで下がったが、店頭価格は下がらない**。
   高値玉の消化と、包装資材・物流・人件費という国内コストの上昇が残っているため。
2. **値上げの主因が輸入原料から国内コストへ移った**。
   だから相場が落ち着いても値上げは止まらず、2026年も各社が改定を発表している。
3. **カカオの横で、米と抹茶が高騰している**。米菓と抹茶菓子はいま最も原価が苦しい領域。
4. **市場は「数量横ばい・金額最高」が定着**。小売4兆円突破は値上げの結果であり、
   工場の稼働（トン数）は伸びていない。
5. **成長しているのはグミ、インバウンド、輸出の3つ**。
   いずれも既存の定番ブランドとは別の論理で動いており、
   ここに設備と人をどう配分するかが各社の分かれ目になっている。

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **カカオショック** | 2023〜2025年にカカオ国際価格が平常時の3〜4倍に跳ねた現象の通称。西アフリカの不作・病害が主因 |
| **先物（フューチャーズ）** | 将来の受渡しを約束して今の価格で売買する取引。カカオはニューヨークとロンドンの市場価格が世界の指標になる |
| **高値玉（たかねぎょく）** | 相場が高いときに買い付けた原料在庫・契約。相場が下がっても、これを消化するまではコストが下がらない |
| **内容量変更** | 価格を据え置いて量を減らす価格改定の方法。企業は「価格改定および内容量変更」と併記して公表することが多い |
| **てん茶（碾茶）** | 抹茶の原料になる茶葉。覆下栽培し、揉まずに乾燥させる。世界的な抹茶需要で価格が急騰した |
| **飴菓子** | 統計上のカテゴリで、キャンディとグミを含む。近年の伸びはほぼグミによる |
| **2024年問題** | トラックドライバーの時間外労働規制強化に伴う輸送力不足と運賃上昇。菓子はかさばるため影響が大きい |
| **増収減益** | 売上は伸びたが利益は減ること。値上げのスピードが原価上昇に追いつかないときに起きる |
