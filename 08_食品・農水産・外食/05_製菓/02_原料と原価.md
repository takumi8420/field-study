# ② 原料と原価

このノートで分かること：菓子の原価が何でできているか、
なぜカカオ相場が業界全体を揺らすのか、
そして「内容量を減らす」という値上げの逃げ道がどこで限界を迎えるか。

## 1. 結論：菓子の原価は「相場の塊」に薄い加工賃を足したもの

菓子は加工度が高いので付加価値が大きいと思われがちだが、
実際の製造原価は**そのほとんどが自分で決められない価格**でできている。

```
【菓子メーカーの売上100円の分解（家庭用・カテゴリ平均のイメージ）】

  売上 100
   ├─ 原材料費             30〜45  ◀ 相場と為替。カカオ・砂糖・小麦・乳製品・油脂
   ├─ 包装資材費            5〜12  ◀ 原油・紙パルプ。個包装が多いほど重い
   ├─ 製造労務費・工場経費  10〜18  ◀ 固定費。稼働率が落ちると単位原価が跳ねる
   ├─ 物流費                 4〜8   ◀ 2024年問題以降、上昇が止まらない
   ├─ 販促費・リベート       8〜15  ◀ 小売との交渉で決まる。粗利を削る最大要因
   ├─ 広告宣伝費             2〜6
   ├─ 販管費（人件費等）     10〜15
   └─ 営業利益               3〜9   ◀ 食品メーカー全体（5〜8%）とほぼ同じ帯

  ※各社IR・業界解説からの概算レンジ。カテゴリと販路で大きく振れる
```

**入口（原料）は相場と為替が決め、出口（店頭価格）は小売との交渉が決める**という
食品メーカー共通の構造は [総合食品 ① 食品メーカーの損益構造](../01_総合食品/01_食品メーカーの損益構造.md) に詳しい。
製菓が特殊なのは、**その相場のうち1品目（カカオ）の振れ幅が他業界より桁違いに大きい**ことである。

## 2. 5つの主原料と、それぞれの値動きの理由

| 原料 | 使うカテゴリ | 価格を決めるもの | 調達の性格 |
| --- | --- | --- | --- |
| **カカオ豆／カカオマス・ココアバター** | チョコレート、ココア | ニューヨーク・ロンドンの先物相場、西アフリカの作柄 | ほぼ全量輸入。産地が極端に偏る |
| **砂糖** | ほぼ全カテゴリ | 国際粗糖相場＋**日本独自の調整金制度**（→ [製粉・製糖・製油](../02_製粉・製糖・製油/01_制度が価格を決める世界.md)） | 制度価格のため国際相場がそのまま効かない |
| **小麦粉** | ビスケット、プレッツェル、和洋生菓子 | 政府売渡価格（年2回改定） | 国が輸入し製粉会社に売り渡す。価格は制度で決まる |
| **乳製品**（全粉乳・脱脂粉乳・バター・生クリーム） | ミルクチョコ、洋生菓子、アイス | 指定団体の取引価格、生乳生産量 | 国内酪農の生産量に左右（→ [乳業](../04_乳業/README.md)） |
| **油脂**（パーム油・なたね油・植物油脂） | スナック、ビスケット、チョコ用代替油脂 | パーム油相場、原油、為替 | インドネシア・マレーシア依存 |

副原料も軽視できない。

- **ゼラチン・ペクチン**：グミの食感を作る。需要急増で逼迫しやすい
- **ナッツ（アーモンド・カシュー）**：米国・ベトナムの作柄と為替
- **米**：米菓の主原料。近年の国内米価上昇が直撃した
- **抹茶（てん茶）**：世界的な抹茶ブームで原料が逼迫（→ [④ 直近トピック](04_直近トピック_2026.md) 第5章）
- **香料・着色料・糖アルコール**：少量だが代替が効きにくい

## 3. カカオ相場 ― 数十年に一度の異常事態

製菓を理解するうえで**2023〜2026年のカカオ相場は必ず押さえる**。

```
【カカオ豆の国際価格（USドル/kg、年平均）】

 11 ┤                                   ● 10.75（2025年1月・月次ピーク）
 10 ┤                                  ╱
  9 ┤                                 ╱
  8 ┤                          ●7.33 ●7.80
  7 ┤                         ╱      │
  6 ┤                        ╱       │   ●5.95（2026年8月）
  5 ┤                       ╱        │  ╱
  4 ┤                      ╱         ●4.42（2026年 年平均）
  3 ┤              ●3.28 ╱
  2 ┤ ●2.37 ●2.43 ●2.39
  1 ┤
    └──┴─────┴─────┴─────┴─────┴─────┴─────┴──▶
      2020  2021  2022  2023  2024  2025  2026

  出典：世界経済のネタ帳（IMF一次産品価格ベースの集計）
  ・2020〜22年は 2.4ドル/kg 前後で安定していた
  ・2024年に 約3倍、2025年1月には 10.75ドル/kg と過去最高水準
  ・2026年は 3,000〜5,000ドル/トン台まで調整したと報じられる（ピークの約1/3）
```

### 3.1 なぜここまで上がったのか

| 要因 | 内容 |
| --- | --- |
| **産地の極端な集中** | 世界生産の6割超がコートジボワールとガーナの2か国。ここが崩れると代わりがない |
| **黒莢病（ブラックポッド）・CSSVD** | カカオの病害が西アフリカで広がり、収量が大きく落ちた |
| **気候変動と天候** | 乾燥・豪雨の振れが大きくなり、開花・結実が安定しない |
| **樹の老齢化** | 植え替えが進まず、樹齢が高い園が多い。収量が構造的に落ちる |
| **生産者価格の固定制度** | 両国は政府が農家買取価格を決める。相場が上がっても農家に還元されにくく、増産インセンティブが働かなかった |
| **投機資金の流入** | 需給の逼迫に金融のポジションが乗り、振れ幅が増幅された |

### 3.2 相場が下がっても店頭価格が下がらない理由

2026年にカカオはピークの約3分の1まで下げた。
それでも菓子の店頭価格は下がらない。理由は3つある。

```
【相場と店頭価格の時間差】

  カカオ相場   ▲▲▲▲▲▲▲▲▲▲▲▲▼▼▼▼▼▼
               2023  2024  2025 │ 2026
                                │
  メーカー仕入  ─────高値で長期契約────┼──── まだ高値玉の在庫を消化中
                                │
  店頭価格      ──値上げ──値上げ──値上げ┼── 据え置き（下げない）
                                │
                               ここで「下がった」と報じられても
                               店頭に効くのは早くて2026年後半〜2027年以降
```

1. **先買い（フォワード契約）で数か月〜1年分を確保している**。
   相場が下がった時点では、すでに高値で買った原料の在庫と契約が残っている。
2. **上がったのはカカオだけではない**。包装資材・物流費・人件費・エネルギーが同時に上がり、
   カカオが下がってもトータルの原価は下がらない。
3. **値下げは実務的にほぼ不可能**。一度下げた建値（メーカーの公式卸価格）を
   再び上げるには数か月の交渉と実需の説明が要る。
   小売との関係上、**下げてすぐ上げる**のは最も避けたい動きになる。

> ポイント：**相場と店頭価格の間には、最短でも半年〜1年の時間差がある**。
> 「カカオが下がった＝チョコが安くなる」は、少なくともその年には起こらない。

## 4. カカオ高への実務的な逃げ道

| 手段 | 中身 | 副作用 |
| --- | --- | --- |
| 価格改定 | 出荷価格を3〜10%上げる | 売価の壁（100円／200円）を超えると数量が落ちる |
| **内容量変更** | 価格を据え置き、グラム・個数を減らす | 「実質値上げ」と報じられ、信頼を損ねやすい |
| **カカオ分の見直し** | ミルク比率を上げる、準チョコレートに寄せる | 表示区分が変わる（下記5参照）。味の変化が露骨に出る |
| 代替素材 | ナッツ・ビスケット・ウエハースの比率を上げる | チョコ量を減らしても満足感を保てる。実際に拡大している |
| SKU削減 | 売れ筋に絞り、ラインの切替を減らす | 棚のフェースを失うリスク |
| 産地分散 | 中南米・アジア産の比率を上げる | 品質・量ともに西アフリカの代替にはなりきらない |

**日本の表示区分**も知っておくと記事が読める。

| 区分 | カカオ分の目安 | 位置づけ |
| --- | --- | --- |
| チョコレート | カカオ分35%以上（公正競争規約の基準） | 一般的な板チョコ |
| 準チョコレート | カカオ分15%以上・植物油脂の使用が多い | 低価格帯や菓子の外側コーティングに多い |
| チョコレート菓子／準チョコレート菓子 | 上記を用いた複合菓子 | ビスケット・ウエハースとの組み合わせ品 |

カカオが高騰すると、**「チョコレート」から「準チョコレート」へ表示が移る商品**が増える。
価格を守るための判断だが、表示を見れば起きていることが分かる。

## 5. 内容量変更（実質値上げ）の限界

菓子は売価の心理的な壁が強いため、他の食品よりも**容量で調整する頻度が高い**。
しかしこれには物理的・心理的な限界がある。

```
【実質値上げが行き詰まるまで】

  第1段階  中身を少し減らす（例：12枚→11枚）
            → 気づかれにくい。パッケージは同じサイズのまま

  第2段階  さらに減らす
            → 袋の中の空間（ヘッドスペース）が明らかに増え、「上げ底」と言われる

  第3段階  パッケージ自体を小さくする
            → 新しい包装資材の版・金型が必要（数百万〜のコスト）
            → 棚での見え方が小さくなり、フェースの存在感が落ちる

  第4段階  これ以上減らせない
            → 1個あたりの満足感を割る。個包装の最小単位を下回る
            → ★価格を上げるしかない★

  ＝ 実質値上げは「時間を稼ぐ手段」であって、恒久的な解ではない
```

食品全般の実質値上げの実務は [総合食品 ② 値決めと交渉](../01_総合食品/02_値決めと交渉.md) 第5章に詳しい。
製菓固有の事情は、**枚数・個数が消費者から直接数えられる**点にある。
液体や粉と違い、「昨日まで12枚だった」は即座に気づかれ、SNSで拡散する。

## 6. 包装材と物流 ― 菓子は「軽くてかさばる」最悪の貨物

| コスト要因 | 菓子の事情 |
| --- | --- |
| **包装資材** | 個包装＋内袋＋外箱の三重構造が普通。フィルム（[機能性樹脂・フィルム](../../10_素材・化学/04_機能性樹脂・フィルム/README.md)）と紙器（[紙・パルプ](../../10_素材・化学/09_紙・パルプ/README.md)）の両方が原油・パルプ相場に連動 |
| **小容量化の逆効果** | 容量を減らすほど、内容量あたりの包装資材費は増える。実質値上げが包装コストを押し上げる |
| **重量が軽く体積が大きい** | スナック菓子はトラックの重量上限より先に容積が埋まる。**運賃は体積で決まるのに単価は軽い** |
| **温度帯** | チョコは夏に定温輸送が要る。常温より運賃が高い |
| **賞味期限** | 菓子は比較的長いが、季節品は「年号入りパッケージ」で実質の販売期限が短い |
| **2024年問題** | ドライバーの時間外規制で運賃が継続上昇（→ [陸運・トラック](../../13_運輸・物流/06_陸運・トラック/README.md)） |

> ポイント：**菓子の物流費率が高いのは「重い」からではなく「かさばる」から**。
> 同じ10トン車に積んでも、ポテトチップスは重量の上限に届く前に荷台が満杯になる。

## 7. 生産ラインの専用性 ― 多品種化が効率を殺す

製菓工場の最大の特徴は、**ラインが商品専用に作り込まれている**ことである。

```
【チョコレート工場とスナック工場の違い】

 ＜チョコレート＞
  カカオ豆 ──焙焼──▶ 磨砕 ──▶ カカオマス ──┬──▶ ココアバター
                                            └──▶ 配合（砂糖・粉乳）
                                                    │
                                              精練（コンチング：数時間〜数十時間）
                                                    │
                                              テンパリング（温度を段階制御）
                                                    │
                                    ┌───────────────┼───────────────┐
                                    ▼               ▼               ▼
                                 モールド成形    エンローバー     センター入り
                                 （板チョコ）   （コーティング）  （粒・スティック）
                                    │               │               │
                                    └──── 冷却トンネル ──── 包装 ───┘

  ＜スナック＞
   じゃがいも ──洗浄・皮むき──▶ スライス ──▶ フライヤー ──▶ 味付け ──▶ 包装
   とうもろこし ──▶ エクストルーダー ──▶ 焙焼／フライ ──▶ 味付け ──▶ 包装

  ★共通する経済性★
   ・切替（製品を変える段取り）に時間がかかる → 1品種を長く流すほど原価が下がる
   ・洗浄が必要（アレルゲン管理：乳・小麦・落花生・そば等）→ 切替のたびに停止時間
   ・型・金型は商品専用 → 新商品ごとに設備投資が発生する
```

ここから出てくる結論は3つ。

1. **定番の長期連続生産がいちばん儲かる**。段取り替えがなく、歩留まりが安定し、償却も済んでいる。
2. **多品種少量は原価を確実に悪化させる**。期間限定・地域限定・コンビニ専用品を増やすほど、
   稼働率は上がっても**単位あたり原価は上がる**。
3. **季節品はラインを遊ばせる**。バレンタイン向けの設備は年の大半が稼働しない。
   だからこそ外部委託（OEM）を使う合理性が生まれる。

## 8. OEM／PB受託という選択

**OEM（相手先ブランド製造）**＝他社ブランドの商品を自社工場で作ること。
**PB（プライベートブランド）**＝小売が自社名で売る商品。

| 立場 | 得られるもの | 失うもの |
| --- | --- | --- |
| 受託する側（中小・専業メーカー） | 工場の稼働率が埋まる。営業・広告費が不要 | 粗利は薄い。取引を切られると一気に稼働が空く |
| 受託する側（大手） | 余剰ラインの活用。小売との関係強化 | 自社NB（ナショナルブランド）とカニバる |
| 委託する側（小売） | NBより安い価格で棚を作れる。粗利率が高い | 品質・供給をメーカーに握られる |

菓子は**PBが作りやすいカテゴリ**である。味の差が分かりやすい調味料などと比べ、
「小袋のチョコ」「ビスケット」「スナック」はPBでも一定の満足が得られやすい。
その結果、**NBは価格でPBと比較され続ける**。
PB受託の判断の考え方は [総合食品 ② 値決めと交渉](../01_総合食品/02_値決めと交渉.md) 第6章を参照。

## 9. まとめ：この章を理解する3つの鍵

1. **原価の30〜45%は相場そのもの**。特にチョコレートはカカオ1品目の振れが決算を左右する。
2. **相場と店頭価格には半年〜1年の時間差がある**。下がった直後に安くなることはない。
3. **ラインが商品専用に作られているため、多品種化は原価を悪化させる**。
   だから定番が強く、期間限定は「棚のための費用」として割り切られる。

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **カカオマス** | カカオ豆を焙焼・磨砕したペースト。チョコの味の中核。ここからココアバターを搾る |
| **ココアバター** | カカオ豆の脂肪分。室温で固く体温で溶ける性質がチョコの口どけを作る。高価 |
| **コンチング（精練）** | チョコ生地を長時間練り、粒子を細かくして香りを整える工程。数時間〜数十時間かかる |
| **準チョコレート** | カカオ分が少なく植物油脂の比率が高い規格。低価格帯やコーティングに使われる |
| **調整金制度** | 輸入糖から徴収した金を国産糖の生産者に回す日本の砂糖制度。国際相場がそのまま国内価格にならない理由 |
| **政府売渡価格** | 国が輸入小麦を製粉会社に売る価格。年2回改定され、パン・菓子の原価に波及する |
| **フォワード契約（先買い）** | 将来の受渡しを前提に、今の価格で原料を買う契約。相場変動から数か月〜1年を守るが、下落局面では逆に不利になる |
| **実質値上げ** | 価格を据え置いたまま内容量を減らすこと。菓子は枚数・個数が数えられるため気づかれやすい |
| **ヘッドスペース** | 袋の中の商品が入っていない空間。減量が進むとここが目立ち「上げ底」と言われる |
| **段取り替え（切替）** | 生産する品種を変えるための洗浄・調整作業。その間はラインが止まるため、多品種化の直接コストになる |
| **OEM／PB** | OEMは他社ブランド品の受託製造。PBは小売の自社ブランド商品。菓子はPB化しやすいカテゴリ |
| **NB（ナショナルブランド）** | メーカー自身のブランド商品。PBとの価格比較にさらされ続ける |
