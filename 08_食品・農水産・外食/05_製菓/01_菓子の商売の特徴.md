# ① 菓子の商売の特徴

このノートで分かること：菓子メーカーの利益がどこから出ているのか、
なぜ「一つの菓子市場」という言い方が成り立たないのか、
そして棚・価格・季節という3つの外部条件がこの商売をどう縛っているか。

## 1. 結論：利益を稼ぐのは「数十年売れ続けている定番」である

菓子売場には毎年おびただしい数の新商品が並ぶ。
しかし**メーカーの利益の柱になっているのは、たいてい50年前・100年前に発売された商品**だ。

| 商品 | メーカー | 発売年 | 2026年時点の経過 |
| --- | --- | --- | --- |
| 森永ミルクキャラメル | 森永製菓 | 1913年 | 113年 |
| グリコ（キャラメル） | 江崎グリコ | 1922年 | 104年 |
| 明治ミルクチョコレート | 明治 | 1926年 | 100年 |
| ビスコ | 江崎グリコ | 1933年 | 93年 |
| ミルキー | 不二家 | 1951年 | 75年 |
| ベビースターラーメン | おやつカンパニー | 1959年 | 67年 |
| のり塩ポテトチップス | 湖池屋 | 1962年 | 64年 |
| かっぱえびせん | カルビー | 1964年 | 62年 |
| ガーナミルクチョコレート | ロッテ | 1964年 | 62年 |
| ポッキー | 江崎グリコ | 1966年 | 60年 |
| 亀田の柿の種 | 亀田製菓 | 1966年 | 60年 |
| ルマンド | ブルボン | 1974年 | 52年 |
| きのこの山 | 明治 | 1975年 | 51年 |
| ハッピーターン | 亀田製菓 | 1976年 | 50年 |

（発売年は各社公表の商品史による。ブランド名の継承・リニューアルを含む）

> ポイント：菓子は「新商品の業界」に見えて、実際には**ブランド寿命が異常に長い業界**。
> 新商品の大半は1〜2年で消え、利益は old brand が稼ぐ。
> 新商品は売るためというより、**棚の面積を確保し、ブランドの存在を思い出させるため**に出される。

なぜ寿命が長いのか。理由は4つある。

1. **味の記憶が子ども時代に刻まれる**。菓子は人生で最初に「自分で選んで買う」商品カテゴリで、
   そこで覚えた味は一生残る。親になると子に買い与え、ブランドが世代を越えて引き継がれる。
2. **設備が専用でつくられている**。ポッキーの細いプレッツェルもきのこの山の形も、
   **その商品のためだけの専用ラインと金型**で作られている（→ [② 原料と原価](02_原料と原価.md) 第8章）。
   すでに償却が終わったラインで作る定番は、原価が新商品より構造的に安い。
3. **小売が定番の棚を外さない**。回転が読める商品は小売にとってもリスクが低い。
   定番カットは客のクレームに直結するため、棚から落ちにくい。
4. **広告費がいらない**。認知率が100%に近い商品は、想起を維持する最低限の投資で売れ続ける。

食品全般の「定番が利益を稼ぐ」構造は [総合食品 ③ 商品開発とブランド](../01_総合食品/03_商品開発とブランド.md) に詳しい。
製菓はその中でも**極端に定番依存が強いカテゴリ**だと理解すればよい。

## 2. 「菓子市場」は存在しない ― 7つの別々の市場

製菓を一つの業界として語ると必ず間違える。
**原料・設備・競合・季節性・利益率がカテゴリごとに全く違う**ためだ。

```
【製菓の中のカテゴリ構造（2025年 小売金額ベース、全日本菓子協会推定）】

 小売金額 4兆996億円
 ├── チョコレート     約7,105億円 ── 原料＝カカオ。相場直撃。季節イベント依存が最大
 ├── スナック菓子     約6,042億円 ── 原料＝じゃがいも・とうもろこし・油。かさばる＝物流費が重い
 ├── ビスケット       ── 原料＝小麦・油脂・糖。多品種・焼成ライン
 ├── 米菓（せんべい・あられ） ── 原料＝国産米。相場は国内米価。高齢層が主顧客
 ├── 飴菓子（キャンディ＋グミ） ── 砂糖・水あめ・ゼラチン。**グミが成長ドライバー**
 ├── チューインガム   ── **唯一の構造的縮小カテゴリ**
 └── その他（和生菓子・洋生菓子・油菓子・豆菓子・玩具菓子・アイス等）

 ※生産数量は 196万8,100トン（前年比 ▲0.8%）＝ 数量は増えていない
 ※生産金額は 2兆9,403億円（同 +5.4%）＝ 伸びはほぼ値上げによる名目膨張
```

| カテゴリ | 主原料 | 設備の性格 | 需要の癖 | 競争構造 |
| --- | --- | --- | --- | --- |
| チョコレート | カカオ豆、砂糖、乳製品 | テンパリング（結晶を整える温度管理）とモールド（型） | バレンタイン・クリスマスに集中。夏は溶けて売れない | 明治・ロッテ・森永・グリコ・ブルボンの大手寡占＋輸入高級品 |
| スナック | じゃがいも、とうもろこし、植物油 | フライヤー／エクストルーダー（生地を押し出す機械） | 通年。夏・飲用機会に強い | カルビーが圧倒的。湖池屋・ジャパンフリトレーが追う |
| ビスケット | 小麦粉、砂糖、油脂 | 連続焼成トンネルオーブン | 通年。朝食・間食代替で底堅い | ブルボン・森永・グリコ・ヤマザキビスケットなど分散 |
| 米菓 | うるち米・もち米 | 生地成形＋焼成＋味付け | 通年。年末年始・贈答に山 | 亀田製菓が首位。三幸製菓・岩塚製菓・栗山米菓 |
| 飴・グミ | 砂糖、水あめ、ゼラチン、果汁 | 煮詰め＋型抜き（グミはスターチモールド） | 通年。のど飴は冬に集中 | グミはUHA味覚糖・カンロ・明治が激戦 |
| ガム | ガムベース、糖アルコール | 圧延・成形 | **市場が縮小し続けている** | ロッテのシェアが圧倒的。他社は撤退 |

このため「菓子メーカーの利益率」を一括りに語る意味は薄い。
**同じ会社の中でも、チョコ部門とスナック部門では原価の動く理由が全く違う**。

## 3. ガムの崩壊とグミの台頭 ― 業界史上いちばん分かりやすい交代劇

製菓で直近20年に起きた最大の構造変化は、**ガム市場の崩壊とグミ市場の膨張**である。

```
【ガムとグミの逆転（インテージSRI等の報道値、億円／年）】

 1,000 ┤
       │   ガム
   800 ┤ ●━━━●━━━●
       │  '17   '18   '19  ＼            ●━━━● グミ
   600 ┤                     ＼●━━━●━━━●
       │                      '20  '21  '22
   400 ┤             ●━━━━━●
       │            グミ
   200 ┤
       └──────────────────────────────────▶
        2017        2020        2022        2025

  ・ガム   2017年 約823億円 → 2020年 約612億円（報道値）
  ・グミ   2017年 約555億円 → 2022年 約781億円（同期のガムは約548億円）
  ・2021年ごろに金額が逆転。以後、差は開き続けている
  ・飴菓子全体（キャンディ＋グミ）は2024年に初めて小売3,000億円台に到達
```

ガムが崩れた理由は、味でも品質でもなく**「噛む場面」が社会から消えたこと**にある。

| 要因 | 内容 |
| --- | --- |
| 喫煙率低下 | ガムは「たばこの代わりに口を動かす」需要と結びついていた |
| 運転・外出機会の減少 | 眠気覚まし需要が縮小 |
| マスク着用の常態化 | 人前で口を動かしにくい。コロナ期に決定的に落ちた |
| 捨てる手間 | 食べ終わりに包み紙とごみが出る。グミ・タブレットには無い |
| 職場文化の変化 | オフィスでガムを噛む行為が忌避されやすくなった |

対してグミは、**「歯ごたえ」という体験そのものが商品価値**になり、
果汁・コラーゲン・ビタミンなど機能の訴求も乗せやすかった。
さらに**SNSで「硬さ」「食感」が話題になりやすい**ため、新商品が自走で広がる。

この結果、2023年3月に明治が「キシリッシュ」などのガムを終売してガム事業から撤退した。
同社のガム市場シェアは2022年時点で5%未満、ロッテが金額シェア6割超を握っていたと報じられる。
一方、明治は「キシリッシュ」の名前をそのままグミに転用した。
**ブランド名だけを残してカテゴリを移す**という判断で、定番ブランドの価値の使い方がよく分かる事例である。

グミ側の投資も急だ。UHA味覚糖は2024年のグミ売上で1位（約189億円と報じられる）となり、
福島工場の新棟を2027年春に稼働させて生産能力を約6割増やす計画。
カンロも複数拠点でグミの生産能力を大幅に増強する方針を示している。
**設備投資のタイミングを間違えると過剰能力になる**のが、この手のブームの怖いところでもある。

## 4. 衝動買い商材であること ― 棚と価格がすべてを決める

菓子は**「買うつもりがなかったのに買う」比率が高い商品**とされる。
この性質が、菓子メーカーの営業活動をほぼ規定している。

```
【衝動買い商材の売れ方】

  来店 ──▶ 目的の買物（牛乳・卵・肉）──▶ 菓子売場を通る ──▶ 目に入る ──▶ 買う
                                             ▲            ▲         ▲
                                             │            │         │
                                    棚のどこに置かれるか   パッケージ  価格の心理的上限
                                    （エンド・レジ前）    の目立ち方  （100円／200円の壁）

  ＝ メーカーが自分で決められるのは「パッケージ」だけ。
     棚の位置は小売との交渉、価格は最終的に小売が決める。
```

ここから3つの帰結が出る。

1. **売価の「壁」が強烈に効く**。菓子の主力価格帯は100円台・200円台に集中していて、
   税込で1つ上の桁に行った瞬間に数量が落ちる。
   そのため**値上げは価格ではなく内容量で行われがち**になる（→ [② 原料と原価](02_原料と原価.md) 第6章）。
2. **棚の取り合いが営業の本質**。年2回の棚替え（小売が売場構成を見直すタイミング）で
   フェース（棚の正面に並ぶ列数）をいくつ取れるかが、次の半年の売上をほぼ決める。
   新商品を出す最大の目的は、この**交渉のカード**を持つことである。
3. **エンド・レジ前の争奪**。通路の端の平台（エンド）やレジ前の置き場は販促費・協賛金の世界で、
   ここが取れると数量は跳ねるが粗利は削られる。
   食品全体の値決め・リベートの仕組みは [総合食品 ② 値決めと交渉](../01_総合食品/02_値決めと交渉.md) を参照。

## 5. 季節性とイベント ― 年間の山谷が極端

菓子は**カレンダーで需要が動く**数少ない食品カテゴリである。特にチョコレートは極端だ。

```
【チョコレートの年間需要イメージ（山の高さは概念図）】

  1月  2月   3月  4月  5月  6月  7月  8月  9月  10月  11月  12月
       ███                                         ██    ██   ███
       ███                                         ██    ██   ███
   █   ███   ██   █    █   ▁    ▁    ▁    █   ███   ███  ███  ███
  ─────┴─────┴────┴────┴────┴────┴────┴────┴────┴─────┴─────┴────
      ↑バレンタイン ↑ホワイトデー      ↑夏＝溶けるので谷  ↑ハロウィン ↑クリスマス・年末

  ・生産は需要の2〜4か月前に始まる。バレンタイン品は前年秋には作り終えている
  ・夏は常温流通で溶けるため、チョコは物理的に売りにくい（定温輸送＝コスト増）
  ・売れ残りは翌年に持ち越せない（パッケージに年号・意匠が入る）
```

イベント商戦の経済的な意味。

| イベント | 特徴 | メーカーにとっての意味 |
| --- | --- | --- |
| バレンタイン（2月） | 百貨店催事が高単価、量販が数量。輸入ブランドと国内大手が同じ売場に並ぶ | 年間で最も**単価を上げられる**機会。一方で**売れ残り＝ほぼ全損** |
| ホワイトデー（3月） | マシュマロ・クッキー・キャンディに需要が散る | 森永・不二家など非チョコ勢にも山が来る |
| ハロウィン（10月） | 小分け・配る菓子。2010年代に急拡大 | **個包装の詰め合わせ**という商品形態を定着させた |
| クリスマス・年末（12月） | 贈答・帰省土産・オードブル的な詰め合わせ | 米菓・洋生菓子まで含めて年間最大の数量 |
| 行楽・夏休み | 旅行土産、ファミリーパック | [土産菓子](03_市場と海外.md) の稼ぎ時 |

2026年のバレンタインでは、チョコレート1粒あたりの平均価格が**436円（前年比+4.3%）**と
2年連続で過去最高を更新した（帝国データバンク調査、2026年）。
同一パッケージ（平均9個入）でみると**3,256円と前年3,037円から+7.2%**。
**カカオ高がイベント価格にそのまま乗っている**ことが分かる。

## 6. 販路ごとに「別の商品」を作っている

同じブランドでも、売る先によって中身の設計が変わる。

| 販路 | 求められる形 | 価格の性格 | 備考 |
| --- | --- | --- | --- |
| [コンビニ](../../07_小売・流通/01_コンビニエンスストア/README.md) | 1人分・小容量・新規性。専用商品が多い | 定価に近い。値引きが少ない | 発売サイクルが速く、外れると即カット |
| [スーパー・食品スーパー](../../07_小売・流通/03_食品スーパー/README.md) | ファミリーパック・大袋 | 特売の主戦場。実売価が読めない | チラシ特売で数量が跳ねるが粗利は薄い |
| [ドラッグストア](../../07_小売・流通/04_ドラッグストア/README.md) | 大袋・箱買い | **最安値をつけてくる**存在 | 集客のための目玉商品にされやすい |
| [100円ショップ](../../07_小売・流通/08_100円ショップ/README.md) | 100円で収まる専用容量 | 完全な価格先決め | 専用規格のOEM生産になりがち |
| 土産・観光地 | 個包装の箱菓子、地域限定 | **定価が通る数少ない場所** | 粗利が厚い。→ [③ 市場と海外](03_市場と海外.md) |
| [百貨店](../../07_小売・流通/05_百貨店/README.md) | 高単価ギフト、ブランド菓子 | 定価。催事の集客力 | バレンタイン催事が象徴 |
| EC・サブスク | まとめ買い・詰め合わせ | 送料が原価に乗る | かさばる菓子は送料負けしやすい |

> ポイント：**同じ「ポテトチップス」でも、CVS用の小袋・SM用の大袋・DgS用の箱・
> 100均用の専用容量で、原価も粗利も全く違う**。
> 「どの棚に、いくらで、どの容量で置くか」の組み合わせ設計が製菓営業の中身である。

## 7. まとめ：この章を理解する3つの鍵

1. **利益は定番が稼ぎ、新商品は棚のために出す**。ブランド寿命が数十年～100年に及ぶのが製菓の特異点。
2. **「菓子市場」は7つの別市場の寄せ集め**。ガムだけが構造的に崩れ、グミだけが構造的に伸びている。
3. **棚・価格・季節という外部条件に縛られる**。価格帯の壁があるから値上げは容量変更に逃げ、
   季節イベントに山があるから売れ残りリスクを抱える。

次は原価の側から見る → [② 原料と原価](02_原料と原価.md)

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **定番（レギュラー品）** | 通年で棚に置かれる継続商品。対義語は期間限定・季節品。製菓では定番が利益の大半を稼ぐ |
| **フェース** | 棚の正面に商品が並ぶ列数。フェース数＝実質的な露出量で、売上にほぼ比例する |
| **棚替え（棚割り変更）** | 小売が売場の商品構成を見直すこと。多くは年2回（春・秋）。メーカーの最大の営業機会 |
| **エンド** | 陳列棚の通路側の端にある平台。回転が最も速い一等地で、獲得には販促費が伴う |
| **衝動買い（非計画購買）** | 来店前に買う予定がなかった購買。菓子はこの比率が高い商材とされる |
| **テンパリング** | チョコレートのカカオバターの結晶を安定型に揃える温度操作。艶と口どけを決める |
| **エクストルーダー** | 原料生地を加熱しながら押し出して成形する機械。コーンスナック等で使う |
| **スターチモールド** | でんぷんの粉床に型を押して窪みを作り、そこにグミ液を流し込む製法 |
| **ガムベース** | ガムの噛む部分を作る樹脂状の基材。消化されないため「噛んで吐き出す」商品になる |
| **個包装** | 一つずつ包む形態。配る・分ける需要に対応するが、包装資材費と包装工程の負担が増える |
