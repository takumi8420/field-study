# ④ 直近トピック（2026年9月時点）

報道・各社開示ベースの整理。一次情報（各社IR、官公庁発表、調査会社の原資料）で必ず裏取りすること。
数値は公表時点のものであり、以後の改定で変わりうる。

> この1年の構図：**「市場は過去最高、店は過去最多で潰れている」**。
> ラーメン店の市場規模は2025年度に8,855億円と過去最高を更新し、
> 早ければ2027年度内に1兆円へ届く見通しとされる。
> その一方で2026年上半期のラーメン店倒産は36件と過去最多、焼肉店も26件で2年連続の最多。
> 潰れているのは**負債5,000万円未満・従業員10人未満**の小さな店ばかりで、
> 同じ時期に焼肉きんぐ（物語コーポレーション）と町田商店（ギフトホールディングス）は
> 過去最高益を更新している。**淘汰ではなく、置き換えが進行している**。

## 1. ラーメン店の倒産が過去最多（2026年上半期）

| 指標 | 数値 | 出典 |
| --- | --- | --- |
| 2026年上半期の倒産 | **36件**（前年同期比 +44.4%）。2009年以降の**上半期で過去最多** | 東京商工リサーチ |
| うち物価高倒産 | **10件**（前年同期比 +66.6%）。上半期の過去最多 | 同上 |
| うち人手不足倒産 | **5件**（同 +25.0%）。上半期の過去最多 | 同上 |
| 負債総額 | 15億100万円（前年同期比 ▲9.4%） | 同上 |
| 1件あたり平均負債 | **4,100万円**（前年同期6,600万円、▲37.8%） | 同上 |
| 負債1億円未満 | 31件（構成比 86.1%） | 同上 |
| 倒産原因 | 販売不振 28件（約8割） | 同上 |

- 倒産**件数は増え、1件あたりの負債は縮んでいる**。これは
  **より小規模な店から順に力尽きている**ことを示す
- なお年間では、2025年のラーメン店倒産は59件で、過去最多だった2024年（79件）から
  25.3%減と4年ぶりに前年を下回った（帝国データバンク）。
  **2025年にいったん落ち着いた反動として、2026年上半期に再加速した**形
- 東京商工リサーチは「ラーメンの価格も1,000円を超えることが珍しくなくなった。
  だが、価格に見合った味、トッピング、接客サービス等で満足感を提供できない場合は
  客離れを引き起こしかねず、ラーメン店の生存競争は激化している」と総括している

## 3. 牛肉高騰 — 子牛が3割急騰、和牛生産は10年ぶり減へ

焼肉の原価を決めるのは牛肉相場であり、その先行指標は**子牛（もと牛）価格**である。

```
【2026年の牛肉コストの構図】

  ■ 和牛  物価高で消費が落ちる → 繁殖農家が母牛を減らす
           → 子牛の供給が細る → 子牛価格が半年で約3割急騰、最高値圏
           → 2026年度の和牛肉生産は10年ぶりに減少見込み（報道ベース）
           → 数年先の枝肉相場はさらに上がりやすい

  ■ 輸入牛 円安 ＋ 世界的な需要増 ＋ 海上運賃
           → 米国産・豪州産が数年前の水準を大きく上回る高値で推移と報じられる

  ■ 交雑種（F1）  和牛より手頃な選択肢として需要が流入 → 堅調に推移
           → 「逃げ場」として使われるぶん、ここも下がりにくい
```

- つまり **和牛・輸入牛・交雑種のどれに振っても安くならない**。
  これが「食べ放題コースの値上げ → 客数減 → 販売不振」という連鎖の起点になっている
- 子牛から出荷まで20〜30か月あるため、**今日の子牛高は2〜3年後の枝肉高として戻ってくる**。
  焼肉店の原価環境は短期では改善しにくい（→ [① 焼肉の経済](01_焼肉の経済.md) 3章）
- 生産側の構造は [畜産・飼料](../13_畜産・飼料/README.md) を参照。相場は
  農林水産省の畜産物日別情報、JA全農ミートフーズの相場情報で最新値を確認する

## 4. 「1,000円の壁」の崩壊と、価格の三極化

| 指標 | 数値 | 年・出典 |
| --- | --- | --- |
| ラーメン店の市場規模 | **8,855億円**（2015年度比 +63.4%、過去最高） | 2025年度見込・帝国データバンク |
| 純損益合計（判明分） | **171億円**（前年度356億円から約半減） | 同上 |
| 上位50社チェーンの店舗数 | **6,305店**（+3.0%、初の6,000店超） | 2025年度末・同上 |
| 増収／前年度並み／減収 | 38.8% ／ 47.2% ／ 14.0% | 同上 |
| 1兆円到達の見通し | 早ければ **2027年度内** | 同上の推計 |
| 全国平均価格 | 約 **729円** | 2026年1月時点・価格集計サイト |
| 中華そば（外食）の価格指数 | 2020年＝100 → **115.2** | 2025年・消費者物価指数ベースの集計 |

- 帝国データバンクは価格帯が **低価格500円前後／標準1,000円前後／高価格1,500円以上**の
  三極に分かれつつあると整理している
- 注目すべきは **市場規模は過去最高なのに、純損益合計は前年度比で約半減**している点。
  **売上は値上げで伸びたが、コスト上昇がそれを上回った**ことを意味する
- 消費者側は依然として抵抗が強く、「1,000円超のラーメンを高いと思う」が9割以上、
  「値上げしたら食べる頻度が減る」が約7割という調査結果が報じられている
- 一方で一風堂・一蘭のように1,000円超でも好調な店もある。報道では、
  **駅ビルやショッピングモールなど高単価な飲食店が並ぶ施設に出店することで相対的に安く見せる**
  手法が指摘されている（→ [② ラーメンの経済](02_ラーメンの経済.md) 4章）

## 5. 大手の独り勝ち — 焼肉きんぐ、町田商店、そして牛角の縮小

| 企業 | 直近の数値 | 出典 |
| --- | --- | --- |
| **物語コーポレーション**（焼肉きんぐ、丸源ラーメン、ゆず庵） | 2026年6月期 売上 **1,516億89百万円（+22.4%）**、営業利益 **121億45百万円（+31.4%）**。グループ総店舗数914店（2026年5月時点） | 同社決算発表・フードリンクニュース |
| 同 月次 | 2026年5月の既存店売上高 **+13.4%**、焼肉・ゆず庵がけん引 | 同社開示・財経新聞 |
| **ギフトホールディングス**（町田商店、豚山、元祖油堂） | 2026年10月期1Q（2025年11月〜2026年1月）売上 **106億4,200万円（+25.1%）**、営業利益 **14億3,400万円（+85.2%）**。同期の利益予想を上方修正し株価は最高値を更新 | 同社開示・日本経済新聞 |
| 同 出店計画 | 2027年10月期に国内1,000店突破を目標 | 同社開示・報道 |
| **牛角**（レインズ／コロワイドG） | かつて800店超だった国内店舗が2026年4月時点で**約480店**まで減少と報じられる。同年4月下旬にグランドメニューを刷新 | 報道ベース |
| **安楽亭** | 2026年9月17日から食べ放題コースを値下げ。プレミアムゴージャスコース **16,500円 → 10,780円** など。全コースにソフトドリンク飲み放題を追加料金なしで付与 | 同社発表・日本経済新聞／食品産業新聞社 |

```
【同じ「焼肉」で起きた分岐】

  焼肉きんぐ   ロードサイド・郊外SC中心、家族客、食べ放題を磨き込み
               → 出店継続、増収増益
       ▲
  ───┼──────────────────────────────▶
       ▼
  牛角         駅前の単品注文型。値上げで客数が離れ、店舗数が縮小
  安楽亭       値上げ後に客離れ → 2026年9月に大幅値下げで揺り戻しを狙う

  ※ 同じコスト上昇に対し「業態を磨く」か「価格を戻す」かで対応が割れた
```

- ギフトホールディングスが伸びている理由は、麺・タレ・スープ・餃子・チャーシューを
  **自社工場および委託工場でPBとして生産し店舗へ供給する**モデルにある。
  店舗側の仕込み作業を削ることで、ラーメンのボトルネック（属人的なスープ作り）を外している
- 物語コーポレーションは焼肉・ラーメン・和食を同時に持つ**複数業態の会社**で、
  食材や部位を業態間で融通できる点が原価管理上の強みになっている

## 6. 人手不足と特定技能の受入停止

| 事項 | 内容 | 時期・出典 |

| 特定技能1号「外食業」 | 分野別受入上限5万人に到達し、**新規受入が当面停止** | 2026年4月13日から・出入国在留管理庁の運用（報道ベース） |
| 最低賃金 | 2025年度の全国加重平均 **1,121円**（+66円） | 2025年度・厚生労働省 |
| 人手不足倒産（ラーメン店） | 2026年上半期 **5件**（前年同期比 +25.0%）で上半期最多 | 東京商工リサーチ |
| 育成就労制度 | 技能実習に代わる新制度。2027年4月移行予定 | 政府方針 |

- 外食の人手は**採用の蛇口が制度によって閉じられた**状態にある。
  賃金を上げて採るしかないが、それはそのままL（人件費率）の悪化になる
- 焼肉はホール人数が要る業態なので最低賃金の上昇が直撃し、
  ラーメンは「代わりのいない1人」が抜けると店が開かないという別種の脆さを持つ
  （→ [③ 個店とチェーンの二極化](03_個店とチェーンの二極化.md) 4章）
- 外食全体の構造は
  [ファストフード ④ 人手不足と省力化](../14_ファストフード/04_人手不足と省力化.md) を参照

> 読み方：国内で「1,000円の壁」に阻まれている企業が海外へ出るのは、
> 成長のためというより **壁のない市場を探しているから**。
> 冷凍・通販も同じ発想で、**席数という物理的な上限の外側に売上を作る試み**である。
> ただしインバウンドの恩恵は都心・観光地に集中し、
> 郊外や住宅地の店には届かない。**立地による格差をさらに広げる要因**として読むべき。

## 8. 全体の構図（3〜5行のまとめ）

- **コストが一斉に上がり、転嫁できる側とできない側で結果が真っ二つに割れた**。
  ラーメンは市場規模が過去最高でありながら純損益が約半減し、倒産は過去最多という状態にある
- 潰れているのは**負債5,000万円未満・従業員10人未満の個店**に強く偏っており、
  同じ時期に焼肉きんぐ・町田商店は過去最高益を更新している
- 焼肉の原価は**子牛価格の急騰**を通じて数年先まで高止まりしやすく、
  ラーメンの原価は小麦・豚肉・光熱費に加え**スープを炊くガス代**が重い
- 人手は**特定技能の受入停止**で供給側に天井がつき、賃金で採るしかない局面に入った
- 出口として各社が向かっているのは **海外・インバウンド・冷凍チャネル**、
  すなわち「国内の価格の壁と席数の制約が効かない場所」である

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **物価高倒産** | 原材料・エネルギー等の価格上昇が主因となった倒産。調査会社が原因分類として集計している |
| **人手不足倒産** | 従業員の確保難・人件費高騰・後継者不在などが主因となった倒産 |
| **子牛（もと牛）価格** | 肥育農家が買う子牛の取引価格。肥育期間20〜30か月を経て枝肉相場に反映されるため、**牛肉価格の先行指標**になる |
| **三極化** | ラーメンの価格帯が低価格（500円前後）・標準（1,000円前後）・高価格（1,500円以上）に分かれつつある状態 |
| **1,000円の壁** | ラーメン1杯が1,000円を超えると客の抵抗が急に強まる価格の心理的上限（→ [②](02_ラーメンの経済.md)） |
| **PB供給型チェーン** | 本部が自社・委託工場で麺やスープを作り加盟店に供給する形態。ラーメンのチェーン化の主流 |
| **特定技能1号「外食業」** | 外食現場で就労できる在留資格。分野別上限5万人に到達し、2026年4月13日から新規受入が当面停止 |
