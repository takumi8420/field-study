# 焼肉・ラーメン

- 大分類: 食品・農水産・外食
- 状態: done
- 更新日: 2026-09-20

## このフォルダの読み方

焼肉とラーメンは、外食のなかで**経済構造がほぼ正反対**の2業態である。

**焼肉は、客が自分で焼く**。だから店は「切って盛る」までで仕事が終わり、
調理人が要らない。L（人件費）が20〜25%と低いのに、客単価は4,000〜5,000円取れる。
外食では例外的に条件のよい業態で、だから参入が絶えない。
その代わり **F（食材費）が牛肉相場に直結して38〜42%まで上がり**、
排煙・ロースターという他業態にない重い初期投資を背負う。

**ラーメンは、店主が全部作る**。スープは属人的で、毎日数時間の仕込みが要る。
原価率は30%台と悪くないが、**客単価が1,000円前後しかない**ため1杯の粗利が小さく、
「1,000円の壁」という心理的な価格上限に押さえ込まれている。
チェーン化が難しく、いまも**個人店が圧倒的多数**を占める。

それでもこの2業態は、いま**まったく同じ現象**に直面している。
**市場規模は過去最高なのに、倒産は過去最多**。
仕入交渉力と価格転嫁力を持つチェーンが過去最高益を更新する一方で、
負債5,000万円未満・従業員10人未満の個店が次々に退出している。
**共通しているのは「個人経営が多い」「価格の上限が客の心理で決まっている」の2点**で、
だから構造の違う2業態が同じ形で淘汰される。

[ファストフード ① 外食1店舗の経済](../14_ファストフード/01_外食1店舗の経済.md) で定義済み。
本フォルダはそれを前提に、2業態の固有の仕組みだけを扱う。

## 1. 業界の定義・範囲

**焼肉店**＝ 客席の焼台で客自身が肉を加熱する形式の飲食店。
**ラーメン店**＝ 中華麺とスープを主商品とする飲食店。
日本標準産業分類ではどちらも「食堂、レストラン」「専門料理店」に含まれ、
倒産統計などでは**「中華・東洋料理店」に一括される**ことが多い（帝国データバンクの分類）。

この2つを1フォルダで扱うのは、**どちらも個人経営が主役の業態**であり、
チェーン化の度合いと淘汰の進み方を比べると理解が早いためである。

| 業態 | 客単価 | 回転率 | F（原価） | L（人件費） | 調理の熟練度 | チェーン化 |
| --- | --- | --- | --- | --- | --- | --- |
| **焼肉（中価格帯）** | 4,000〜5,000円 | 1.5〜2回転 | **38〜42%** | **20〜25%** | 低い | 中 |
| **焼肉（一人焼肉）** | 1,200〜2,000円 | 5〜8回転 | 35〜40% | 20〜25% | 低い | 高い |
| **ラーメン** | 900〜1,300円 | 6〜12回転 | 30〜35% | **30〜35%** | **高い** | **低い** |
| [居酒屋](../16_居酒屋/README.md) | 3,000〜4,000円 | 1〜2回転 | 30%前後 | 28〜32% | 中 | 高い |
| [回転寿司](../17_回転寿司/README.md) | 1,200〜1,800円 | 高い | 40%超 | 20%前後 | 低い（機械化） | 非常に高い |

（業界の一般的な水準をもとにした概算。立地・業態で大きく振れる）

隣接領域との境界。

- **[即席麺](../07_即席麺/README.md)**：同じ「ラーメン」でも、即席麺は食品メーカーの装置産業。
  1食100〜300円で、店のラーメン（1,000円前後）とは買う理由も産業構造も違う。**競合ではなく別市場**
- **[焼肉用の肉の供給側](../13_畜産・飼料/README.md)**：繁殖・肥育・食肉卸が川上。
  焼肉店の原価は実質的にここで決まる
- **[居酒屋](../16_居酒屋/README.md)**：ホルモン焼き・大衆焼肉は居酒屋と連続的。酒の比重で分かれる
- **[中食・弁当](../20_中食・弁当/README.md)・[冷凍食品](../06_冷凍食品・惣菜/README.md)**：
  冷凍ラーメン・宅麺は店の味を店外へ出すチャネルで、産業としては食品側に片足がある

## 2. 市場規模と成長性

| 指標 | 数値 | 年・出典 |
| --- | --- | --- |
| ラーメン店の市場規模 | **8,855億円**（2015年度比 +63.4%、過去最高） | 2025年度見込・帝国データバンク |
| ラーメン 1兆円到達の見通し | 早ければ **2027年度内** | 同上の推計 |
| ラーメン上位50社チェーンの店舗数 | **6,305店**（前年度比 +3.0%、初の6,000店超） | 2025年度末・同上 |
| ラーメン店の純損益合計（判明分） | **171億円**（前年度356億円から約半減） | 2025年度・同上 |
| ラーメン1杯の全国平均価格 | 約 **729円** | 2026年1月時点・価格集計サイト |
| 焼肉店の市場規模 | 店舗数 約2万2,000店、年商 約1兆2,000億円 | 2020年・日本フードサービス協会の推計（J-Net21掲載） |
| 外食産業市場規模（参考） | 約24兆1,512億円 | 2023年・日本フードサービス協会／食の安全・安心財団の共同推計 |

成長性の読み方は3点。

- **金額は伸びているが、数量は伸びていない**。押し上げているのは値上げとチェーンの出店で、
  食事回数そのものは人口減で増えない
- **利益は伸びていない**。ラーメン店の純損益合計は市場が最高値を更新した年に約半減した。
  **売上の伸びをコスト上昇が食い切っている**
- **成長余地は国外にある**。ラーメンの海外単価は日本の2〜3倍、
  焼肉ライクは海外店舗数が国内を上回る（2025年4月時点）

## 3. バリューチェーン（川上 → 川下）

```
【焼肉】
  繁殖農家 ─▶ 子牛せり ─▶ 肥育農家 ─▶ と畜・枝肉せり ─▶ 食肉卸／加工センター ─▶ 焼肉店 ─▶ 客が焼く
   └────── 畜産・飼料 ──────┘         └─ ここで部位に分解 ─┘      └ 付加価値＝立地・ブランド ┘
   ※原価の決定要因は2〜3年前の子牛価格。店側で動かせる余地は小さい

【ラーメン】
  製粉 ─▶ 製麺所／自社工場 ─▶┐
  畜産（豚骨・鶏ガラ）─────▶├─▶ ラーメン店 ─▶ 客
  調味料（醤油・味噌・タレ）─▶┘        │
                                        └─▶ 冷凍・通販（宅麺・小売）─▶ 家庭
   ※付加価値はスープとタレの設計に集中。そこだけは外注しにくい
```

付加価値がどこに集まるかは、2業態で対照的である。

- **焼肉**：付加価値は**肉の調達力と立地**にある。商品そのものは加工度が低く、
  店の腕で原価を薄める余地が小さい。だから**規模で安く買える側が強い**
- **ラーメン**：付加価値は**スープとタレの設計**にある。属人的で真似されにくいが、
  同時に**拡大もしにくい**。チェーンはこれを自社工場へ移すことで拡大を可能にしている

## 5. 収益モデル・コスト構造

```
【売上100とした比率の比較】

              焼肉（中価格帯）     ラーメン
  F 食材費        38〜42          30〜35   ← 焼肉は牛肉相場に直撃
  L 人件費        20〜25          30〜35   ← ラーメンは仕込み労働が重い
  ────────────────────────────
  FL             60前後           65前後   ← ラーメンはすでに天井ぎりぎり
  R 家賃          8〜12           8〜12
  水道光熱費       5〜8            6〜10   ← ラーメンは寸胴を長時間炊く
  その他          8〜12           8〜12
  ────────────────────────────
  営業利益         5〜10           0〜7    ← ラーメンは構造的に薄い
```

- **焼肉**：原価は高いが人件費が低い。**利益の源泉は肉ではなく、ライス・キムチ・スープ・
  ドリンクという原価率10〜25%の商品**。肉は集客装置として機能している
- **ラーメン**：原価率は良好でも**客単価が低いため粗利の絶対額が小さい**。
  損益分岐点は概ね1日100〜150杯とされ、行列は虚栄ではなく必須条件になる
- **初期投資**：焼肉は排煙・ロースターを含め4,000万〜7,000万円級、
  ラーメンは10〜15坪なら1,000万〜2,000万円級。**この差が参入者の顔ぶれを分けている**

## 6. 競争要因（KSF）と参入障壁

| 業態 | 勝つための条件（KSF） | 参入障壁 | 障壁の弱さが生む問題 |
| --- | --- | --- | --- |
| **焼肉** | ①仕入の規模（1頭買い・産地直契約）②部位を売り切るメニュー設計 ③立地 ④食べ放題の原価管理 | **設備投資が重い**（4,000万〜7,000万円） | **居抜きで設備が残る**ため、前の店が潰れた立地に次の店が入り、同じ理由でまた潰れる |
| **ラーメン** | ①味の個性 ②1日100〜150杯を出し続ける集客力 ③仕込み労働に耐える体力 or 工場化 ④サイドメニューでの客単価づくり | **ほぼ無い**（1,000万〜2,000万円で開業可能） | **参入が簡単で再現が難しい**ため、店が増え続けながらチェーンも独占できない |

> ポイント：両業態とも **参入障壁が実質的に低い**ことが最大の特徴。
> だから供給過剰が慢性化し、コストが上がった局面で一斉に退出が起きる。
> **「倒産が過去最多」は、業界が弱いのではなく、入口が広いことの裏返し**である。

## 7. 規制・法制度

| 分野 | 内容 |
| --- | --- |
| **営業許可** | 食品衛生法に基づく飲食店営業許可。2021年の制度改正で HACCP（危害要因分析に基づく衛生管理）に沿った管理が原則義務化 |
| **生食規制** | 2011年の集団食中毒を受け、**牛レバーの生食提供が2012年に禁止**。生食用食肉（ユッケ等）にも厳格な規格基準。焼肉店のメニュー構成を大きく変えた制度変更 |
| **消防・建築** | 客席で火を使うため、厨房設備等の位置・構造の基準、防炎・排煙、ダクトの防火措置が課される。ビルイン出店の可否を左右する |
| **排煙・臭気** | 悪臭防止法や自治体の条例、近隣との関係。排気経路が確保できない物件では焼肉店が成立しない |
| **労働** | 最低賃金（2025年度 全国加重平均 1,121円、+66円）。時間外労働の上限規制 |
| **在留資格** | 特定技能1号「外食業」は分野別上限5万人に到達し、**2026年4月13日から新規受入が当面停止**。育成就労制度は2027年4月移行予定 |
| **表示** | 食品表示法・景品表示法。「和牛」「国産牛」「交雑種」の表示ルール、加工肉（成形肉）の明示義務 |

## 8. 最近のトピック

詳細と出典URLは [④ 直近トピック（2026年9月時点）](04_直近トピック_2026.md) に。

- **ラーメン店の倒産が2026年上半期36件で過去最多**（前年同期比 +44.4%、東京商工リサーチ）。
  1件あたり平均負債は4,100万円へ縮小し、**より小さい店から順に消えている**
- **焼肉店の倒産も26件で2年連続の上半期最多**。26件すべてが負債5,000万円未満、
  従業員10人未満が96.1%と、**個人店にほぼ限定されている**
- **牛肉は子牛価格が半年で約3割急騰**し最高値圏。2026年度の和牛肉生産は10年ぶりに減少見込みと
  報じられ、輸入牛も円安と世界需要で高止まり。**逃げ場がない**
- **ラーメン市場は8,855億円で過去最高**（2025年度・帝国データバンク）。
  だが純損益合計は前年度比で約半減し、価格帯は500円／1,000円／1,500円以上に三極化
- **大手は過去最高益**。焼肉きんぐ（物語コーポレーション）は2026年6月期に営業利益+31.4%、
  町田商店（ギフトホールディングス）は2026年10月期1Qで営業利益+85.2%
