# ③ 個店とチェーンの二極化 — 両業態に共通して起きていること

このノートで分かること：焼肉とラーメンという、経済構造のまったく違う2業態で
**なぜ同じ現象が同時に起きているのか**。倒産が過去最多なのに大手が過去最高益を出す、
という構図の正体。

> 結論：2020年代後半の焼肉・ラーメンで起きているのは不況ではなく **置き換え**である。
> コストが一斉に上がったとき、**価格転嫁できる規模を持つ側だけが生き残り、
> 持たない側が退出して、その立地をチェーンが埋める**。
> 焼肉とラーメンは業態としては正反対（L低・F高 ／ L高・F低）だが、
> **「個人経営が多い」「価格の上限が客の心理で決まっている」**という2点が共通しており、
> だから同じ形で淘汰が進む。

---

## 1. 数字で見る二極化

| 指標 | 数値 | 年・出典 |
| --- | --- | --- |
| 飲食店の倒産（上半期） | **473件**（前年同期458件から +3.3%）。**4年連続増、上半期として過去最多** | 2026年上半期・帝国データバンク |
| 同 負債総額 | 約 **245億9,200万円** | 同上 |
| 業態別（上半期） | 酒場・ビヤホール **125件**（過去最多）／中華・東洋料理店 **91件**（過去最多）／日本料理店 48件 | 同上。中華・東洋料理店には町中華・**ラーメン店・焼肉店**・カレー店が含まれる |
| ラーメン店の倒産（上半期） | **36件**（+44.4%、過去最多）。平均負債 4,100万円 | 2026年上半期・東京商工リサーチ |
| 焼肉店の倒産（上半期） | **26件**（+8.3%、2年連続で最多）。全件が負債5,000万円未満 | 同上 |
| 一方で大手は | 物語コーポレーション 2026年6月期 売上 +22.4%／営業利益 +31.4%（過去最高） | 同社決算発表 |
| 同 | ギフトホールディングス 2026年10月期1Q 売上 +25.1%／営業利益 +85.2% | 同社開示・報道 |

```
【同じ市場のなかで起きている2つの動き】

   売上・利益
      ▲
      │                     ┌──── チェーン（焼肉きんぐ、町田商店 等）
      │                ┌────┘        規模で仕入を下げ、価格転嫁もできる
      │           ┌────┘             → 増収増益、出店を続ける
      │      ─────┘
  ────┼──────────────────────────────▶ 時間
      │      ─────┐
      │           └────┐             個人店・零細チェーン
      │                └────┐        仕入は言い値、値上げは客離れに直結
      │                     └──── → 販売不振で退出

     ※倒産件数が増えても店舗総数が急減しないのは、空いた立地に
       チェーンと新規開業が入り続けるため（特に焼肉は居抜きが回る）
```

> ポイント：**倒産件数は「市場の縮小」ではなく「主役の交代」を示す指標**として読む。
> 市場規模（ラーメンは2025年度8,855億円で過去最高、帝国データバンク）が伸びながら
> 倒産が最多になるのは矛盾ではなく、**同じ現象の表と裏**である。

## 2. なぜ個店だけが耐えられないのか — 3つの非対称

個店とチェーンの差は「経営努力」ではなく、**構造的に決まっている3つの非対称**から来る。

| 非対称 | チェーン | 個店 | 効き方 |
| --- | --- | --- | --- |
| **仕入** | 年間数千トン単位でまとめて買い、産地・工場と直接契約。為替ヘッジや長期契約もできる | 卸から言い値で買う。数量が小さく交渉力がない | 牛肉・豚肉・小麦が上がると**同じ商品を2割高く買う**ことになる |
| **価格転嫁** | 全店同時に改定し、広告で説明できる。客が「世の中の値上げ」と受け取る | 常連相手に値札を書き換える。**個別の裏切りに見えてしまう** | 転嫁が遅れ、コスト上昇をそのまま利益から払う |
| **人の採用** | 待遇・研修・キャリアを提示できる。本部が採用を代行 | 店主と家族＋アルバイト数名。**店主が倒れたら終わり** | 人手不足局面で採用競争に勝てない |

```
【コストが10%上がったときに何が起きるか（売上100の店）】

  ■ チェーン
     F 35 → 38.5（+3.5）  ← 仕入交渉で上昇幅を圧縮、実際は +2 程度
     価格を 3% 上げる（売上 100 → 103）
     → FL比率は元の水準に戻る。既存店はプラスを維持

  ■ 個店
     F 35 → 38.5（+3.5）  ← 圧縮できない。そのまま乗る
     値上げすると常連が減ると考え、据え置く
     → 営業利益 8 → 4.5 に半減
     → 翌年もう一度上がる → 赤字 → 販売不振で退出
```

- 帝国データバンク・東京商工リサーチの倒産データで **「販売不振」が原因の8〜9割**を占めるのは、
  売れなくなったというより **「売れているのに残らなくなった」**状態が
  最終的に販売不振として計上されるため
- 倒産1件あたりの平均負債が縮んでいる（ラーメン店で2026年上半期4,100万円、前年同期6,600万円）
  のは、**より小さい店から順に消えている**ことを意味する

## 3. 価格転嫁が難しい理由 — 外食固有の摩擦

値上げは「決めれば終わり」ではない。外食には転嫁を遅らせる物理的・心理的な摩擦がある。

| 摩擦 | 中身 | とくに効く業態 |
| --- | --- | --- |
| **券売機・メニュー・看板** | 価格を変えるたびにボタン・POP・卓上メニュー・店頭看板を作り直す。小さな店ほど手間と費用が重い | ラーメン |
| **価格が1点に集約されている** | 食べ放題は「コース価格」1つが価格そのもの。**部分的な値上げができない** | 焼肉（食べ放題） |
| **比較が容易** | 並カルビ、醤油ラーメンなど**どこでも同じ名前の商品**があり、隣の店と直接比較される | 両方 |
| **心理的な上限** | ラーメンの1,000円の壁（→ [②](02_ラーメンの経済.md)）、焼肉食べ放題の「3,000円台」意識 | 両方 |
| **常連との関係** | 毎週来る客に値上げを告げるのは、個店にとって心理的な負荷が大きい | 個店全般 |

実務での回避策は、価格そのものを上げずに**客単価を上げる**ことに集中する。

- **サイドメニューへの誘導**：ラーメンは据え置き、餃子・ライス・トッピングで稼ぐ
- **上位グレードの新設**：既存コースは残し、上に「プレミアム」を足す（下は値上げしていない）
- **量目の調整**：肉の枚数、麺量、スープの提供量を静かに見直す（いわゆるステルス値上げ）
- **逆張りの値下げ**：安楽亭は2026年9月17日から食べ放題コースを値下げし、
  プレミアムゴージャスコースを16,500円→10,780円とするなど大幅な価格改定を実施した（同社発表）。
  **値上げで離れた客を、値下げで取り戻しにいく**動き

> ポイント：外食の値上げは「客単価を上げると同時に客数を減らす」綱引き
> （→ [外食1店舗の経済](../14_ファストフード/01_外食1店舗の経済.md) の既存店3数値）。
> 個店はこの綱引きの片方（客数）を失うと即座に赤字になるため、
> **勝てないと分かっている綱引きを始められない**。これが転嫁の遅れの正体である。

## 4. 人手不足 — 焼肉とラーメンで効き方が逆

同じ人手不足でも、2業態では詰まる場所が違う。

```
【人手が足りなくなる場所】

  焼肉店                           ラーメン店
  ┌───────────────┐              ┌───────────────┐
  │ 肉のカット（熟練少々）  │              │ スープ・タレの仕込み★★★ │
  │ ホール・配膳 ★★     │              │ 麺上げ・盛り付け ★★    │
  │ 炭・ロースターの管理★ │              │ ホール（席数少なく1〜2人）│
  │ 洗い物（網・鉄板）★★ │              └───────────────┘
  └───────────────┘
  → 頭数（アルバイト）が要る         → 代わりのいない1人が要る
  → 最低賃金の上昇が直撃             → 店主が倒れたら即閉店
```

| 要因 | 内容 | 年・出典 |
| --- | --- | --- |
| **最低賃金の上昇** | 2025年度の全国加重平均 **1,121円**（+66円）。以後も引き上げ方針が続く | 2025年度・厚生労働省 |
| **特定技能「外食業」の受入停止** | 分野別受入上限5万人に到達し、**2026年4月13日から新規受入が当面停止** | 2026年・出入国在留管理庁の運用（報道ベース） |
| **人手不足倒産** | ラーメン店で5件（前年同期比 +25.0%、上半期最多） | 2026年上半期・東京商工リサーチ |

- 焼肉はホール人数で回す業態なので、**最低賃金が上がるとL（人件費率）が素直に悪化する**。
  卓上端末・配膳ロボット・注文アプリの導入が進んでいるのはこのため
- ラーメンは **「1人が抜けると店が開かない」**という別種のリスクを抱える。
  代替が効かないので、省力化の答えは人を増やすことではなく
  **仕込みを工場へ移すこと**になる（→ [②](02_ラーメンの経済.md) 5章）
- 外食全体の人手不足の構造は
  [ファストフード ④ 人手不足と省力化](../14_ファストフード/04_人手不足と省力化.md) に詳しい

## 5. フランチャイズ（FC）という増え方

両業態とも、チェーン化の主な手段はFC（加盟店が出資して店を運営し、本部にロイヤリティを払う方式）
である。資本を使わずに店数を増やせるためだが、**業態によって本部の売り物が違う**。

| 業態 | FC本部が実際に売っているもの | 加盟店の初期投資 | 本部の収益源 |
| --- | --- | --- | --- |
| **焼肉（食べ放題型）** | 集客ブランド、仕入ルート、オペレーション設計 | 大きい（設備が重い。4,000万〜7,000万円級） | ロイヤリティ＋食肉の供給マージン |
| **焼肉（一人焼肉型）** | 小型店フォーマット、無煙ロースター、都心出店ノウハウ | 中（小型のため抑えられる） | ロイヤリティ＋食材供給 |
| **ラーメン** | **ジャンルの認知＋工場製のスープ・麺・具材** | 小さい（1,000万〜2,000万円級） | **食材供給マージンが主**。ロイヤリティは副次 |

> ポイント：ラーメンのFCは **「味を売る商売」**である。
> 本部は工場で作ったスープ・タレ・麺・チャーシューを加盟店に売り、
> 加盟店は湯煎して盛るだけで「あの味」を出せる。
> つまり **ラーメンFCの本質はチェーン本部というより食品メーカー**であり、
> 店舗数が増えるほど工場の稼働率が上がって利益率が改善する構造になっている。
> FC一般の仕組みは
> [コンビニ ② フランチャイズという仕組み](../../07_小売・流通/01_コンビニエンスストア/02_フランチャイズという仕組み.md) を参照。

## 6. 冷凍・宅麺 — 店の外へ出るチャネル

ラーメンを中心に、**店に来なくても店の味が買える**チャネルが育っている。

| チャネル | 中身 | 店にとっての意味 |
| --- | --- | --- |
| **専門通販（宅麺.com 等）** | 有名店のスープ・麺・具材を冷凍で宅配。店と同じ構成で提供 | **席数の制約を外す**。行列店が行列以上に売れる |
| **小売店での冷凍販売** | イオンの冷凍食品専門店「＠FROZEN」等でプレミアム冷凍ラーメンの販売が拡大（2024〜2026年） | 認知の拡大。地方客への到達 |
| **店頭の土産・物販** | 一蘭のように店舗売上と物販の二本立てにする | **原価率が低く、席を使わない売上** |
| **カップ麺・袋麺とのコラボ** | 有名店監修商品を食品メーカーと共同開発 | ブランド使用料と広告効果 |

```
【店内飲食と冷凍チャネルの経済の違い】

  店内飲食                       冷凍・通販
  売上 ＝ 席数 × 回転率 × 単価    売上 ＝ 生産能力 × 販売チャネル数
  上限 ＝ 物理的な席数            上限 ＝ 工場のライン
  人件費 ＝ 接客・調理            人件費 ＝ 製造（＝規模で下がる）
  家賃 ＝ 一等地ほど高い          家賃 ＝ 郊外の工場（安い）
     ▲                              ▲
  「行列ができても、それ以上は売れない」  「行列の価値を、席数と無関係に換金できる」
```

- 冷凍チャネルは **[冷凍食品・惣菜](../06_冷凍食品・惣菜/README.md) 産業への片足の移動**である。
  必要なのは製造能力・冷凍物流・品質管理であり、飲食店の能力とは別物
- 焼肉でも通販は存在するが、**客が自分で焼くという体験そのものが商品**なので、
  ラーメンほど置き換わらない。むしろ焼肉の外部チャネルは**精肉小売・デリバリー**の形を取る
- 工業的に量産される[即席麺](../07_即席麺/README.md)とは、
  価格帯（1食1,000円前後 対 100〜300円）も買う理由も違う。**競合ではなく別市場**と見るのが正確

## 7. インバウンドが支える都心店

訪日客の増加は、焼肉・ラーメンの**都心店だけ**を強く押し上げている。

| 指標 | 数値 | 年・出典 |
| --- | --- | --- |
| 訪日外国人旅行者数 | 約4,268万人（前年比 +15.8%）で過去最高と報じられる | 2025年・観光庁／日本政府観光局ベースの報道 |
| ラーメンの客単価（外国人客） | 1回あたり平均 約1,260円。日本人客の約900円に対し **+40%** | 2025〜2026年・調査会社／メディア集計 |
| 外食全体（2025年） | 売上 107.3% ＝ 客単価 104.3% × 客数 102.9%。**客単価主導** | 2025年・業界団体集計ベース |

インバウンドが効く理由は3つ。

- **価格の基準が違う**。自国の外食価格と比べるため、日本の1,000円のラーメンは安く見える。
  日本人客にとっての「1,000円の壁」が、訪日客には存在しない
- **ラーメンと焼肉は説明が要らない**。何が出てくるか写真で伝わり、
  食べ方の作法も単純。言語の壁が低い業態ほど訪日客の比率が上がる
- **和牛は明確な目的商品**。高級焼肉は訪日客にとって「日本でしか食べられないもの」であり、
  国内の和牛高で日本人客が離れた分を、訪日客が埋めている面がある

> ただし恩恵は **立地にほぼ完全に依存する**。
> 都心・観光地・空港周辺の店は客単価が上がるが、郊外・住宅地の店には一切届かない。
> **同じ業態の中で、立地による格差を広げている**要因として読むべきである。

## 8. 全体の構図

```
  コスト上昇（牛肉・小麦・豚肉・光熱費・人件費）
        │
        ├──▶ チェーン：仕入で吸収 ＋ 全店同時に価格改定
        │              → 増収増益、出店継続、FCで加速
        │
        └──▶ 個店：仕入は言い値、転嫁は常連との関係で止まる
                       → 利益が消える → 販売不振 → 退出
                                              │
                          空いた立地 ◀────────┘
                                │
                  ┌─────────────┴─────────────┐
            チェーンが出店              新規の個人開業（また同じ道）
```

この循環が回り続けるかぎり、**倒産件数は減らないが市場規模は伸びる**。
焼肉では「居抜きで設備が残る」ことが、ラーメンでは「開業資金が小さい」ことが、
それぞれ新規参入を絶やさないため、**淘汰が完了しない**。
これが、両業態が何年も「過去最多の倒産」を更新し続けている理由である。

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **価格転嫁** | 仕入コストの上昇分を販売価格に反映すること。外食は券売機・看板の変更が要るため遅れやすい |
| **販売不振** | 倒産統計の原因分類。売上が伸びない場合だけでなく、売れても利益が残らない状態も最終的にここに計上される |
| **ステルス値上げ** | 価格を据え置いたまま量目や内容を減らすこと。実質的な値上げにあたる |
| **特定技能1号「外食業」** | 外食現場で就労できる在留資格。分野別上限5万人に到達し、2026年4月13日から新規受入が当面停止 |
| **ロイヤリティ** | FC加盟店が本部に払う対価。外食では売上に率をかける方式が主流 |
| **食材供給マージン** | FC本部が加盟店に食材を卸す際の利ざや。ラーメンFCではロイヤリティより重要な収益源 |
| **＠FROZEN** | イオンリテールが展開する冷凍食品専門店。プレミアム冷凍ラーメンの販売チャネルのひとつ |
| **既存店前年比** | 開店から一定期間経った店だけの前年同月比。売上・客数・客単価の3点で読む |
