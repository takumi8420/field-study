# JTの事業構造

このノートで分かること：JT（日本たばこ産業）の利益が**どこから来ているのか**、
なぜ「日本の会社なのに日本ではあまり稼いでいない」状態になったのか、
ロシア事業という地政学リスクの正体、葉たばこ農家との特殊な関係、
そして政府が株主であり続けることの意味。

> ※本ノートは企業戦略と制度の解説であり、喫煙を勧めるものではない。

---

## 1. まず結論：JTは「日本の国営企業」ではなく「海外で稼ぐ多国籍企業」

JTは1985年に日本専売公社を民営化して生まれた会社である。
だが2026年時点のJTを「日本のたばこ会社」と理解すると、業績がまったく読めない。
**利益の大半は、1999年以降にM&Aで買い集めた海外たばこ事業から来ている**。

| 指標 | 数値 | 年・出典 |
| --- | --- | --- |
| 売上収益 | **3兆4,677億円**（前年比＋13.4%） | 2025年12月期・決算短信 |
| 営業利益 | **8,670億円**（同＋175.9%） | 同 |
| 当期利益 | **5,102億円**（同＋184.6%） | 同 |
| 調整後営業利益（為替一定ベース） | 9,275億円（同＋24.9%） | 2025年度・JT開示 |
| 年間配当 | **234円**（中間104円＋期末130円） | 2025年度 |
| （参考）前年の営業利益 | 3,235億円（前年比▲51.9%） | 2024年12月期 |
| （参考）前年の売上収益 | 3兆1,498億円（同＋10.9%） | 2024年12月期 |

**2025年の営業利益が3倍近くに見える理由**：2024年12月期に、
**カナダ現地子会社の「喫煙と健康」に関する訴訟の和解費用（訴訟関連費用は約3,756億円と報じられる）**を
計上して営業利益が半減していた。2025年はその反動が大きい。
**「2025年が良すぎる」のではなく「2024年が特殊要因で悪かった」**と読むのが正しい。

> **数字の読み方の注意**：JTが社内の最重要指標として使うのは「**為替一定ベースの調整後営業利益**」である。
> 新興国通貨を多く扱うため、円建ての表面上の数字は為替で大きく振れる。
> 「本業がどれだけ伸びたか」を見るならこちらを使う。

## 2. 利益はどこから来るのか：4つの塊

```
  JTグループの事業の重み（2026年時点の理解・イメージ）

  ┌────────────────────────────────────────────────┐
  │ 海外たばこ事業（JTI／本社ジュネーブ）                 │
  │ ████████████████████████████████████  利益の大半    │
  │  ・M&Aで買った欧州・CIS・アジア・アフリカ・中東のブランド  │
  │  ・ウィンストン、キャメル、LD、メビウス（海外展開）など   │
  │  ・★ロシアが大きな塊（CIS+で営業利益の約2割との報道）    │
  ├────────────────────────────────────────────────┤
  │ 国内たばこ事業                                      │
  │ ████████  縮小市場。加熱式で3番手                    │
  ├────────────────────────────────────────────────┤
  │ 加工食品事業（テーブルマーク等）                      │
  │ ██  冷凍麺・パックごはん。規模は小さい                 │
  ├────────────────────────────────────────────────┤
  │ 医薬事業  ✕ 2025年に撤退（塩野義製薬へ譲渡）           │
  └────────────────────────────────────────────────┘
```

| 事業 | 中身 | 位置づけ |
| --- | --- | --- |
| **海外たばこ（JTI）** | 1999年以降のM&Aで築いた世界事業。本社はジュネーブ | **グループの心臓**。紙巻・加熱式の双方を世界展開 |
| **国内たばこ** | メビウス、セブンスター、Ploom | 縮小市場。加熱式では最下位。**守りの事業** |
| **加工食品** | 冷凍麺・パックごはん（テーブルマーク）等 | 多角化の残り。規模は小さい → [総合食品](../01_総合食品/README.md) |
| **医薬** | 鳥居薬品、創薬研究 | **2025年に撤退**。塩野義製薬へ総額約1,600億円で譲渡 |

> **押さえどころ**：JTの国内たばこ事業は、売上では無視できないが
> **成長の源泉ではまったくない**。JTのニュースを読むときは、
> 「日本の話か、海外の話か」を最初に切り分けること。

## 3. どうやって海外を買ったのか：M&Aの年表

JTは国内市場の頭打ちを前提に、**1990年代末から一貫して「海外を買う」戦略**を取ってきた。

| 年 | 案件 | 金額（報道ベース） | 意味 |
| --- | --- | --- | --- |
| 1999年 | **RJRナビスコの米国外たばこ事業**を買収、JTインターナショナル（JTI）を設立 | 約78億ドル／約9,400億円 | **輸出会社から多国籍企業への転換点**。キャメル、ウィンストン等を取得 |
| 2007年 | **ギャラハー（英）**を買収 | 約1.7兆〜2.2兆円と報じられる | 欧州・CIS（旧ソ連圏）での地位を確立。当時の日本企業として最大級の海外M&A |
| 2015年 | ナチュラル アメリカン スピリットの米国外事業を取得 | 約5,000億円超と報じられる | プレミアム帯の強化 |
| 2018年 | ドンスコイ・タバック（露）等を取得 | 約1,900億円と報じられる | **ロシアでの地位をさらに固める** |
| 2024年10月 | **Vector Group（米）**の買収完了 | 約3,780億円 | **米国本土への本格参入**。世界2位の市場での販売網を取得 |
| 2025年 | 医薬事業からの撤退（塩野義製薬へ譲渡） | 約1,600億円（売却） | **たばこへの集中** |

```
  JTの変遷を1行でたどる

  1985  日本専売公社 → JT（民営化。ただし製造独占と政府保有は残す）
   │
  1999  RJR国外事業を買収 ──▶ JTI誕生。海外の器ができる
   │
  2007  ギャラハー買収 ────▶ 欧州・CISが主戦場に。ロシアの比重が上がる
   │
  2015  NAS国外事業 ─────▶ プレミアム帯
   │
  2018  ドンスコイ・タバック ─▶ ロシア依存がさらに深まる
   │
  2024  Vector Group ────▶ 手薄だった米国へ
   │
  2025  医薬を売却 ──────▶ 「たばこに集中」を明示
```

> **一貫しているのは「買った成長」である**。JTは自前で海外に売り込んだのではなく、
> 既に現地で売れているブランドと販売網を買ってきた。
> これが利益率の高さの源であると同時に、**のれん（買収差額）の大きさ**と
> **カントリーリスクの集中**という弱点にもなっている。

## 4. ロシアという最大の論点

| 論点 | 内容 |
| --- | --- |
| 規模 | JTはロシアのたばこ市場で**約4割のシェア**を持つとされ、同国最大級の日用消費財企業。営業利益では**CIS＋地域がグループの約2割**を占め、その大半がロシアと報じられる |
| 納税 | ロシアの税収の1%台を納めているとの報道があり、**「戦争の財源を支えているのではないか」という批判**を受けてきた |
| 2022年以降 | ウクライナ侵攻後、JTは「グループ経営からの分離を含む選択肢の検討」を表明。新規投資やマーケティングを停止したと説明してきたが、**事業そのものは継続** |
| 制約 | ロシア側の規制により外国企業の資産売却は政府承認が必要で、**売るに売れない状態**が続く。買い手・価格・送金の問題も重なる |
| 業績への効き方 | 皮肉なことに、ロシアやトルコでの販売が想定を上回り、**2025年の好決算に寄与した**とされる |

```
  JTのロシア事業をめぐるジレンマ

        ┌──────────────┐
        │  残る          │  → 批判・レピュテーションリスク・制裁関連の実務負担
        └──────┬───────┘     だが利益は確保される
               │
   JTの立場 ───┤
               │
        ┌──────┴───────┐
        │  売る／分離する  │  → 営業利益の約2割を失う可能性
        └──────────────┘     しかもロシア政府の承認が要り、
                               買い手・価格・送金のすべてが難しい

  ★「進むも地獄、退くも地獄」と評される所以。2026年時点で結論は出ていない
```

> **投資家・就活生が見るべき点**：JTの利益の質を評価するとき、
> **「どれだけロシアに依存しているか」は必ず出てくる論点**である。
> 同時に、政府が3分の1超の株主であることから、この問題は
> **企業判断だけでなく政治の問題**としても扱われ、国会で質問主意書が出されてきた。

## 5. 国内側の特殊な義務：葉たばこ農家と全量買取

たばこ事業法は、JTに**国産葉たばこを契約どおり全量買い取る義務**を課している。
他の農産物にはほとんど例のない仕組みである。

```
  葉たばこの流れ（国内）

  ┌─────────────┐  ①作付けの前に【契約】（面積・品種を決める）
  │ 契約耕作者（農家）│
  └──────┬──────┘  ②収穫
         ▼
  ┌─────────────┐  ③★JTが【全量】買い取る（価格も事前に決定）
  │      JT       │     買えなかった・要らなかったでは済まない
  └──────┬──────┘
         ▼
     原料として使用      ④実際には国産葉は割高なため、
                          製造に使う葉の多くは輸入葉

  ★「作れば必ず売れる」農業は、制度がそう設計しているから成立している
```

| 論点 | 内容 |
| --- | --- |
| 耕作者数・面積 | 2020年度で耕作者4,340戸・耕作面積6,079ha。長期的に減少が続く |
| 大量廃作 | 2021年11月、JTは**全国の葉たばこ農家の約4割にあたる1,729戸**が2022年以降の生産をやめると発表。廃作には助成金が支払われた |
| 価格 | JTは2026年産の葉たばこ買取価格を**2年連続で引き上げ**ると報じられた（資材高・担い手確保が背景） |
| 制度的な意味 | 全量買取はJTにとって**コスト面では負担**だが、政府がJT株を保有し続ける根拠のひとつとしても語られる |

> **なぜここが重要か**：JTは「海外で稼ぐ多国籍企業」でありながら、
> 国内では**農家保護という政策目的を背負った公的な装置**でもある。
> この二面性が、完全民営化（政府保有株の全売却）が進まない理由の一つになっている。
> 川上の農業の視点は [農業・種苗・肥料](../12_農業・種苗・肥料/README.md) を参照。

## 6. 政府保有株と株主還元

| 項目 | 内容 |
| --- | --- |
| 根拠法 | **日本たばこ産業株式会社法（JT法）**。財務大臣に発行済株式総数の**3分の1超**の保有義務 |
| 変遷 | 当初は「2分の1以上」。2011年の改正で「3分の1超」に緩和 |
| 2013年の売出 | 東日本大震災の復興財源として、政府保有株の一部（約3.33億株）を1株2,949円で売却し**約9,734億円**を調達 |
| 国の関与 | 定款変更、取締役の選解任、事業計画等に主務大臣（財務大臣）の認可・届出が絡む |
| 株主還元 | 2025年度の年間配当は**234円**。JTは配当性向の目安を掲げる高配当銘柄として個人投資家の保有が多い |
| 論点 | 「健康リスクのある製品の製造会社の筆頭株主が国であること」「配当の約3分の1が国庫に入る構造」への賛否 |

```
  JTの株主構造が生む「ねじれ」

     国（財務大臣、3分の1超）
            │  配当を受け取る＝国庫収入
            ▼
        ┌───────┐
        │   JT   │◀── たばこ税を納める（国・地方に約2兆円／年）
        └───┬───┘
            │ 一方で
            ▼
     厚生労働省は喫煙率の低下を政策目標にしている

  ★同じ政府の中に「JTの株主・徴税者」と「喫煙率を下げたい側」が同居する
  ★これが日本のたばこ政策が「禁止」ではなく「課税と場所の限定」で進む構造的理由
```

規制の全体像は [01_税と規制が支配する商売](01_税と規制が支配する商売.md) を参照。

## 7. 競合とのポジション比較

| 企業 | 本拠 | 強い地域 | 加熱式 | 特徴 |
| --- | --- | --- | --- | --- |
| **JT** | 日本 | 日本、CIS（ロシア等）、欧州、アジア | Ploom | 政府が3分の1超を保有する特殊会社。**M&A主導の成長**。2024年に米国へ参入 |
| **PMI** | 米国（本社はスイス） | 米国外全般 | **IQOS（日本で約7割）** | 「煙のない未来」を掲げ加熱式に全振り。2003年にアルトリアから米国外事業を分離した経緯 |
| **BAT** | 英国 | 世界広域 | glo | 紙巻・加熱式・VAPE・パウチの全方位。日本では2番手 |
| **アルトリア** | 米国 | **米国内のみ** | 米国内での展開 | マールボロの米国内権利を持つ。PMIとは別会社 |
| **インペリアル・ブランズ** | 英国 | 欧州中心 | 限定的 | 世界5位級 |
| **中国煙草総公司** | 中国 | **中国国内のみ** | 限定的 | 国家専売。**世界シェア約23%（2024年推計）だが海外にはほぼ出てこない** |

> **JTの立ち位置の要約**：世界3位級だが、**PMIのように1つの加熱式ブランドで世界を取る戦略ではなく、
> 地域ごとに強いブランドを買い集める戦略**を取ってきた。その結果、
> 地域分散が効く一方で、**ロシアのような一国への依存が生まれた**。

## 8. この先の論点

1. **ロシアの出口**。分離するのか、続けるのか。続けるなら批判をどう扱うのか。
   利益の約2割に関わるため、どちらに転んでも業績への影響が大きい。
2. **米国での成果**。Vector Group買収で入った世界2位の市場で、実際に利益を出せるか。
   米国は訴訟リスク・規制リスクがともに高い市場でもある。
3. **国内加熱式の巻き返し**。Ploom AURA／EVOと3年6,500億円の投資
   → [02_加熱式たばこという転換](02_加熱式たばこという転換.md)。
4. **訴訟リスクの常態化**。2024年のカナダの和解費用のように、
   **喫煙と健康に関する訴訟が一時に巨額の費用として表面化する**。
   これは海外たばこ事業を持つ以上、構造的に抱え続けるリスクである。
5. **政府保有株の扱い**。財政制度等審議会のたばこ事業等分科会などで
   国の関与のあり方が繰り返し論点になってきたが、2026年時点で結論は出ていない。

## 9. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **JTI（JTインターナショナル）** | JTの海外たばこ事業会社。本社はスイス・ジュネーブ。1999年のRJR国外事業買収を機に設立 |
| **為替一定ベースの調整後営業利益** | 為替変動とM&A関連の一時的要因を除いた利益指標。JTが全社の業績管理に用いる最重要KPI |
| **CIS＋** | 独立国家共同体（旧ソ連圏）を中心とした地域区分。JTの事業区分ではロシアが大半を占めるとされる |
| **のれん** | 買収価格が買った会社の純資産を上回る差額。M&Aを重ねた企業のバランスシートに大きく積み上がり、業績悪化時に減損の対象になる |
| **非継続事業** | 売却が決まり本業から切り離して表示される事業。JTの医薬事業は2025年12月期第3四半期から該当 |
| **全量買取義務** | JTが契約した国産葉たばこを全量買い取る、たばこ事業法上の義務 |
| **廃作** | 葉たばこの生産をやめること。JTが募集し、助成金が支払われる仕組みがある |
| **JT法（日本たばこ産業株式会社法）** | 政府に3分の1超の株式保有義務を課し、国の関与を定める法律 |
| **特殊会社** | 特別の法律に基づいて設立され、国の関与を受ける株式会社。JTはその一つ |
| **Vector Group** | JTが2024年10月に買収を完了した米たばこ企業。買収額は約3,780億円と報じられる |
