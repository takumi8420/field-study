このノートで分かること：なぜ日本が世界で最も加熱式たばこが普及した市場になったのか、
IQOS・glo・Ploomの競争がどう決着しかけているのか、
「デバイス（ハード）＋スティック（消耗品）」という商売がなぜ成立するのか、
そして2026年の課税方式見直しが何を変えるのか。

※本ノートは市場と制度の解説であり、喫煙を勧めるものではない。加熱式たばこも
製造たばこであり、ニコチンを含む。「健康リスクがない」ことを意味しない。
20歳未満の喫煙は法律で禁止されている。

1. まず結論：日本は世界の「実験場」になった

加熱式たばこ（葉たばこを燃やさず加熱して使う製品）は、2014年に名古屋で
IQOSの試験販売が始まって以降、10年あまりで国内たばこ市場のほぼ半分を占めるまでになった。

年 出来事
2014年11月フィリップ モリスがIQOSを名古屋で試験導入（世界初の本格展開市場として日本を選ぶ）
2016年IQOSが全国展開、品切れが続く。JTがPloom TECHを福岡で、BATがgloを仙台で先行発売
2018年10月加熱式たばこ独自の課税方式が導入され、5年かけて段階的に税負担を引き上げる仕組みが始まる
2020年4月改正健康増進法が全面施行。屋内原則禁煙に
2021〜2023年JTがPloom X系へ刷新。高温加熱方式に軸足を移す
2023年度加熱式の販売本数が585億本に（日本たばこ協会）
2025年5月27日JTが新デバイスPloom AURAと新スティックEVOを先行発売
2025年6月加熱式のシェアが約46%、都市部では50%超に達したとされる（JT推計・報道）
2026年4月／10月課税方式の再見直しが2段階で実施され、紙巻との税負担差が実質解消へ
  国内たばこ需要の中身の入れ替わり（イメージ）

  2014年   ████████████████████████████████  紙巻 ほぼ100%
  2018年   ███████████████████████████░░░░░  加熱式 1割台
  2021年   ██████████████████████░░░░░░░░░░  加熱式 3割前後
  2025年   ███████████████░░░░░░░░░░░░░░░░░  加熱式 約46%（都市部は50%超）

  ＊総需要そのものは縮んでいる。上の棒は「構成比」であって、量ではない

ポイント：これは新しい需要が生まれた話ではなく、既存の需要が別の形に移った話である。
市場全体は縮み続けており、加熱式の伸びは紙巻の減少をそのまま受け取っているにすぎない。

2. なぜ日本だけこうなったのか：5つの理由

海外では同じ時期にVAPE（電子たばこ）が「紙巻の代替」の主役になった。
日本ではそうならず、加熱式が一人勝ちした。理由は制度と環境の組み合わせにある。

理由 中身 効き方
① ニコチン入りVAPEが事実上売れないニコチンを含むリキッドは医薬品医療機器等法の規制対象で、国内での販売は事実上できない代替品の選択肢が加熱式しかなかった。これが最大の理由とされる
② 屋内禁煙の進行改正健康増進法（2020年4月全面施行）と自治体条例で、屋内で吸える場所が急減煙とにおいが少ないとされる加熱式へ移る動機になった
③ 税率差2018年以降も加熱式の税負担は紙巻より軽い状態が続いた同じ銘柄帯でも加熱式のほうが割安に見えた
④ PMIの戦略的選択PMIが世界に先駆けて日本を本格展開の場に選んだ供給・広告（規制内）・販路の資源が集中投下された
⑤ 流通の密度コンビニが全国に張り巡らされ、デバイスもスティックも同じ棚で買える立ち上がりのスピードが他国と桁違いになった → コンビニエンスストア
  海外と日本の「代替の受け皿」の違い

  【欧米】 紙巻 ──┬──▶ VAPE（ニコチン入り、規制の下で流通） ← 主役
                  └──▶ 加熱式（一部の国で伸長）

  【日本】 紙巻 ──┬──✕ VAPE（ニコチン入りは薬機法で国内販売不可）
                  └──▶ 加熱式 ← 受け皿がここしかない

  ★「規制が1つの選択肢を閉じたことで、もう1つの選択肢に需要が集中した」

制度が市場構造を作った例として教科書的。健康規制の設計思想の違いが、
10年後の市場のかたちをここまで変えるという事実は、他業界を読むときにも使える視点になる。

3. ビジネスモデル：デバイスは撒き餌、スティックで回収する

加熱式は、本体（デバイス）と消耗品（スティック／カプセル）が分かれている。
これが紙巻との最大の商売上の違いである。

  ┌─────────────┐        ┌────────────────────┐
  │ デバイス（ハード）│──────▶│ 専用スティック（消耗品）│
  │ 数千円〜1万円程度 │  規格  │ 1箱 500〜620円台      │
  │ 値引き・キャンペーン│ ロック │ ★ここに【たばこ税】がかかる│
  │ が可能（＝製造たばこ│        │ ★ここは【定価制】で値引き不可│
  │ ではないため定価制外）│        └────────────────────┘
  └─────────────┘

  収益の実体：デバイスは安く（時に赤字で）行き渡らせ、
             専用スティックの反復購入で回収する。
             いわゆる「カミソリと替刃」モデル。
論点 紙巻たばこ 加熱式たばこ
売るもの単一商品ハード＋消耗品の2階建て
価格の自由度定価制（財務大臣認可）スティックは定価制、デバイスは対象外＝値引きできる
顧客の固定銘柄の好みのみデバイス規格で物理的にロックされる（他社スティックは使えない）
必要な能力葉の調達・加工・配荷それに加えて家電に近い設計・量産・品質保証・アフターサポート
初期投資小さい大きい（開発・金型・量産・デバイス回収）
粗利の出方出荷即利益デバイス先行投資 → スティックで長期回収

ここが効く：デバイスを買った瞬間、その人はそのブランドのスティックしか買えなくなる。
価格競争も広告もできない市場で、企業が顧客を囲い込める唯一の合法的な手段が
デバイス規格である。だから各社は数千億円規模をデバイス刷新に投じる。
JTは2025〜2027年の3年間でRRP（加熱式等）に6,500億円を投じると公表している。

4. 3社の競争：紙巻の順位がひっくり返った

ブランド 企業 方式 国内加熱式シェア（推計） 特徴
IQOSフィリップ モリス（PMJ）高温加熱（ブレード／誘導加熱）約7割2014年の先行が決定的。銘柄数・デバイス世代とも最多
gloBAT（BATJ）高温加熱約2割価格帯を抑えた展開で追随
PloomJT初期は低温（TECH）→現在は高温（X／AURA）約1割紙巻の王者が加熱式では最下位。AURA＋EVOで巻き返しを図る
  日本市場の「ねじれ」

  【紙巻たばこ】                  【加熱式たばこ】
   JT   ██████████ 約6割          PMI  ██████████████ 約7割
   PMJ  █████      約2割強         BAT  ████           約2割
   BATJ ███        約1割強         JT   ██             約1割

   ★市場が加熱式へ移るほど、JTの国内での地位は相対的に下がる
   ★逆に言えば、JTにとって加熱式の巻き返しは「守り」の投資である

JTが出遅れた理由（報道・分析ベース）：初代Ploom TECHは
「たばこ葉を直接加熱しない低温方式」で、煙やにおいの少なさを重視した設計だった。
これは紙巻に近い吸いごたえを求めた層の期待とずれ、高温加熱方式のIQOS・gloに差をつけられた。
JTは2021年以降、高温加熱のPloom Xへ方針転換し、2025年のPloom AURA／EVOで
第3世代とも言える全面刷新を行っている。

なぜここまでやるのか：国内で加熱式のシェアを取り戻せないと、
JTは「国内最大手なのに、伸びているカテゴリーでは3番手」という状態が固定される。
加えて、日本で確立したデバイスとスティックはそのまま海外へ展開できる。
日本市場は各社にとって実験場であり、同時にグローバル展開の前提でもある
（Ploom AURAも日本先行で発売され、その後グローバル展開の方針が示されている）。

5. 税：軽かったものが、紙巻と同じところへ寄せられていく

5-1. 2018年からの第1次見直し

2018年10月より前、加熱式はパイプたばことして重量で課税されており、
紙巻と比べて税負担が大幅に軽かった。2018年度税制改正で「加熱式たばこ」という
独自の区分が作られ、重量と小売価格を紙巻の本数に換算する方式へ移行。
急激な負担増を避けるため、2018年10月から5年かけて段階的に実施された。

5-2. 2026年の第2次見直し

それでも紙巻との差は残った。2024年12月の与党税制改正大綱を受け、
国税庁が示した令和8年（2026年）4月1日からの課税方式の見直しは、換算方法そのものを変える。

区分 新しい換算の考え方
スティック型1本の重量が0.35g以下であれば、スティック1本＝紙巻たばこ1本として換算する
スティック型以外（カプセル等）1個の重量が5g以下であれば、1個＝紙巻たばこ20本として換算する
実施時期2026年4月1日（第1段階）／2026年10月1日（第2段階で新方式を全面適用）
  加熱式の税負担の推移（イメージ・実額ではない）

  税負担
   │                                   ┌──── 紙巻と同水準へ
   │                        ┌──────────┘
   │           ┌────────────┘  2026/4 → 2026/10 の2段階
   │  ┌────────┘  2018〜2022の5年間の段階実施
   │──┘  パイプたばこ扱い（〜2018/9）
   └────────────────────────────────────▶ 時間

  ★「軽い税率が加熱式を育てた」→「育ったので税率を揃える」という順序

価格への出方（2026年の実例）

時期 内容
2026年4月1日JTがPloom用スティック・ウィズ用カプセル計37銘柄を20〜30円値上げ（例：EVO 550→580円、メビウス 520→550円、キャメル 500→530円、ウィズ用カプセル 600→620円）
2026年9月1日PMJが紙巻18銘柄を一律20円値上げ（パーラメント600円など）
2026年10月1日JTがPloom用スティック31銘柄を各40円値上げ（EVO 580→620円、メビウス 550→590円、キャメル 530→570円）。PMJ・BATも同日付で加熱式を値上げ

読み筋：これらは増税の転嫁であり、メーカーの取り分が増える値上げではない。
ただし、加熱式の価格優位が消えることで、「紙巻へ戻る／やめる／加熱式に留まる」の
選択が消費者側で起きる。税率差がなくなった後も加熱式が選ばれ続けるかどうかが、
2027年以降の最大の観察ポイントになる。

6. 産業構造として何が変わったか

観点 紙巻中心の時代 加熱式が半分の時代
必要な能力農産物の加工業農産物の加工業＋小型家電メーカー
設備投資巻上機・包装機それに加えてデバイス開発・電子部品調達・量産委託
サプライチェーン葉たばこ → 加工 → 巻上 → 配荷電子部品・バッテリー・半導体の調達が加わる
顧客接点小売店の棚のみ棚＋デバイス登録・会員サイト・保証サポート
競争の軸銘柄ブランドデバイスの性能と世代交代の速さ
リスク需要減・増税それに加えてデバイス不具合・リコール・在庫の陳腐化
  加熱式が加わったサプライチェーン

  【従来】葉たばこ ──▶ 加工 ──▶ 巻上・包装 ──▶ 卸 ──▶ 許可小売店

  【加熱式】
    葉たばこ ──▶ 加工 ──▶ スティック製造 ──┐
                                            ├──▶ 卸 ──▶ 許可小売店
    バッテリー・半導体・樹脂 ──▶ デバイス量産 ┘      （デバイスはEC・直営も可）
        ↑
     電機・電子部品業界と接続する

見落とされがちな点：デバイスは製造たばこではないため、定価制の外にある。
つまり「本体は自由に値引きできるが、スティックは1円も値引けない」という
二重構造になっている。キャンペーンやクーポンがデバイス側に集中するのはこのためである。

7. この先の論点

  1. 税率差が消えた後の選択。2026年10月以降、加熱式の割安感は実質的に消える。
    それでも加熱式が選ばれるなら、理由は税ではなく「においと場所」だったことになる。
  2. JTの巻き返しが成立するか。Ploom AURA／EVOと6,500億円の投資が、
    7割を握るIQOSからどれだけシェアを奪えるか。デバイス規格のロックがあるため、
    移行には「デバイスを買い替えさせる」という高いハードルがある。
  3. 日本モデルの輸出。日本で確立した製品・オペレーションを、加熱式がまだ小さい
    欧州・アジアへ展開できるか。各社にとって日本市場の意味はここにある。
  4. 健康影響をめぐる評価。加熱式は燃焼を伴わないが、ニコチンを含み、
    長期的な健康影響についての知見は蓄積の途上にある。
    規制当局・研究機関の評価が今後の規制設計を左右する。

8. 用語メモ

用語 意味
加熱式たばこ葉たばこを燃やさず加熱して使う製造たばこ。IQOS・glo・Ploomなど。たばこ事業法・たばこ税法の対象
VAPE（電子たばこ）リキッドを蒸気化する製品。ニコチンを含むリキッドは日本では医薬品医療機器等法の規制対象で、国内販売は事実上できない。ニコチンなしのものは製造たばこではなく、たばこ税もかからない
RRPReduced-Risk Products。JTが用いる事業区分で、加熱式等の紙巻以外の製品群を指す
スティック／カプセル加熱式の消耗品。デバイス専用で互換性がなく、ここにたばこ税がかかり定価制が適用される
デバイス（本体）加熱器具。製造たばこではないため定価制の対象外で、値引き・キャンペーンができる
高温加熱方式／低温加熱方式葉たばこを直接高温で加熱するか、低温の蒸気を葉に通すか。日本では高温方式が主流になった
課税方式の見直し（2026年）スティック型は1本≦0.35gで紙巻1本に、非スティック型は1個≦5gで紙巻20本に換算する方式。2026年4月・10月の2段階で実施
カミソリと替刃モデル本体を安く売り、専用消耗品の反復購入で利益を得る商売の型。加熱式はこの典型
デバイスロック専用スティックしか使えない規格設計により、顧客がブランドから離れにくくなること
