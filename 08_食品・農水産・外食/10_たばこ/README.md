# たばこ

- 大分類: 食品・農水産・外食
- 状態: done
- 更新日: 2026-09-20

たばこは、**商品ではなく制度を理解しないと一行も説明できない産業**である。
小売価格の**6割前後が税**で、値段はメーカーが決められず**財務大臣の認可**で決まる。
国内での製造は法律上**JT（日本たばこ産業）1社の独占**で、そのJTの株式の3分の1超を
**政府（財務大臣）が保有し続ける義務**が法律に書かれている。
一方で需要は30年減り続け、紙巻たばこの販売本数は**ピークの4分の1以下**になった。
その縮む国内市場の内側で、**加熱式たばこへの置き換わり**という世界でも例のない現象が起き、
JTの利益の大半は**M&Aで買った海外事業**から来るようになった。
この4つ（税・規制・加熱式・海外）が、この業界を読むための座標軸である。

## 1. 業界の定義・範囲

**たばこ業界＝たばこ事業法の対象となる「製造たばこ」を作り、流通させ、売る産業**。
ここでいう製造たばこは、葉たばこを原料として製造された紙巻たばこ・葉巻・パイプたばこ・
かみたばこ・かぎたばこ、および**加熱式たばこ**を指す。

| 隣接領域 | この業界との境界 |
| --- | --- |
| 電子たばこ（ニコチンなしのVAPE） | 葉たばこを使わずニコチンも含まないものは**製造たばこではない**。たばこ税もかからない。日本ではニコチン入りリキッドは医薬品医療機器等法の規制対象で、国内販売は事実上できない |
| ニコチンパウチ | 口に含む無煙製品。日本では製造たばこ／医薬品のどちらに当たるかで扱いが分かれ、国内流通は限定的 |
| [コンビニエンスストア](../../07_小売・流通/01_コンビニエンスストア/README.md) | 出口。たばこは**販売金額の1割前後を占める主力カテゴリーとされる**が、粗利率は低い |
| [農業・種苗・肥料](../12_農業・種苗・肥料/README.md) | 川上の葉たばこ農家。作付け・買取が法律で仕組み化されている点が他作物と決定的に違う |
| [医薬品（新薬）](../../09_医薬・医療・ヘルスケア/01_医薬品（新薬）/README.md) | 禁煙補助薬はこちら。またJTは2025年に医薬事業から撤退した |

> この業界を一言で：**「価格を自分で決められない寡占企業が、縮む需要と増える税の間で、
> 商品の物理形態を組み替えて利益を守っている産業」**。

## 2. 市場規模と成長性

| 指標 | 数値 | 年・出典 |
| --- | --- | --- |
| 紙巻たばこ販売本数（国内） | 約**782億本**（ピークは1996年度の3,483億本） | 2025年度・日本たばこ協会 |
| 紙巻たばこの前年比 | 四半期ベースで▲4〜5%台が続く | 2025年度・同 |
| 加熱式たばこ販売本数（国内） | 約585億本（2023年度）。直近四半期で約180億本・約4,892億円 | 2023年度／直近・同 |
| 加熱式のシェア（たばこ全体に占める） | 約**46%**（都市部では50%超） | 2025年6月時点・JT推計（報道） |
| たばこ税収（国＋地方＋特別税） | 約**2兆1,280億円** | 2024年度・財務省／総務省 |
| ├ 国たばこ税 | 9,505億円 | 2024年度 |
| ├ たばこ特別税 | 1,151億円 | 2024年度 |
| └ 地方たばこ税 | 1兆624億円（道府県1,491億円＋市町村9,132億円） | 2024年度 |
| 成人喫煙率 | **14.8%**（男性24.5%、女性6.5%） | 2024年・厚労省 国民健康・栄養調査 |
| 世界のたばこ市場 | 約9,472億ドル（2024年）→2031年 約9,630億ドルの予測 | 調査会社の推計 |

**成長性の見立て**：国内は**本数ベースで構造的に縮小、金額ベースは横ばい〜微減**という
ねじれた市場である。喫煙率が下がり本数が減っても、増税と値上げで1本あたり単価が上がるため、
税収も売上金額もすぐには落ちない。これが「需要が減っているのに業績は悪くない」という
一見不思議な状態を生んでいる。伸びているのは (1) 加熱式、(2) 新興国・海外市場の2つだけである。

```
  国内たばこ需要の見取り図（イメージ・2026年時点の理解）

   本数        金額・税収
    │           │
    │＼         │ ─────＼_____     ← 増税・値上げが数量減を打ち消す
    │  ＼       │
    │    ＼____ │
    └──────────┴────────────▶ 年
     1996年ピーク         2026年

   ＊「数量は減る／単価は上がる」＝価格弾力性の低さが、この産業の収益を支えている
```

## 3. バリューチェーン（川上 → 川下）

```
 ┌──────────────────┐
 │ 葉たばこ農家        │ 国内：契約耕作者のみ。作付面積・品種は事前契約
 │（国内＋輸入）        │ ★JTには国産葉の【全量買取義務】（たばこ事業法）
 └────────┬─────────┘  → [農業・種苗・肥料](../12_農業・種苗・肥料/README.md)
          ▼
 ┌──────────────────┐
 │ 原料加工（乾燥・熟成）│ 国産は割高なため、実際の原料の多くは輸入葉
 └────────┬─────────┘
          ▼
 ╔══════════════════╗  ★このフォルダの主役
 ║ 製造                ║  国内製造は【JT1社の独占】（たばこ事業法）
 ║ JT／輸入：PMJ・BATJ  ║  外国たばこは「特定販売業者」として輸入・卸売
 ╚════════┬═════════╝  ★ここで小売定価が【財務大臣の認可】を受ける
          ▼
 ┌──────────────────┐
 │ 卸（特約店・たばこ卸） │ 医薬品卸・食品卸系の専業が担う地域が多い
 └────────┬─────────┘
          ▼
 ┌──────────────────┐  ★小売は【財務大臣の許可】制（営業所ごと）
 │ 小売（許可店）       │  CVS・スーパー・たばこ店・自販機（taspo等の年齢確認）
 └────────┬─────────┘  値引き販売は定価制によりできない
          ▼
       消費者（20歳以上）
```

**付加価値がどこに集まるか**：**国（税）が最大の取り分**で、小売価格の6割前後を持っていく。
残りをメーカーと流通で分けるが、**流通のマージンは定価に対して約1割前後とされ、固定的**。
小売は値引きも値上げもできないので、たばこは「粗利率は低いが確実に人が来る集客商材」という
位置づけになる。だから [コンビニ](../../07_小売・流通/01_コンビニエンスストア/README.md) はたばこを置き続ける。

## 4. 主要プレイヤーとシェア

| 企業 | 立ち位置 | 特徴 |
| --- | --- | --- |
| **JT（日本たばこ産業）** | 国内製造の独占企業。国内シェア約6割とされる | 2025年12月期 売上収益 約3兆4,677億円。「メビウス」「セブンスター」。加熱式は「Ploom」。**利益の大半は海外たばこ事業**。政府が株式の3分の1超を保有 |
| **フィリップ モリス ジャパン（PMJ）** | 外資最大手。加熱式で国内首位 | 「マールボロ」「パーラメント」。**IQOS**で加熱式市場の約7割を握るとされる（推計）。親会社PMIは世界2位級 |
| **ブリティッシュ・アメリカン・タバコ・ジャパン（BATJ）** | 外資2番手 | 「ケント」「ラッキーストライク」。加熱式は**glo**。加熱式シェアは約2割（推計） |
| インペリアル・ブランズ | 国内では小規模 | 「ウエスト」等。世界5位級 |
| 中国煙草総公司（China National Tobacco） | 世界最大 | 中国国内の専売公社。**世界シェア約23%（2024年推計）だが日本市場にはほぼ不在** |
| アルトリア（Altria） | 米国内専業 | 「マールボロ」の米国内権利を持つ。PMIとは1社が2003年に分割した別会社 |

## 5. 収益モデル・コスト構造

紙巻たばこ1箱（20本）600円の内訳イメージ（2026年9月時点の税率での試算）。

```
   小売価格 600円（財務大臣の認可価格）
   ├─ たばこ税等        304.88円  ← 1,000本あたり15,244円の4本立て
   │   ├ 国たばこ税       136.04円
   │   ├ たばこ特別税      16.40円
   │   ├ 道府県たばこ税    21.40円
   │   └ 市町村たばこ税   131.04円
   ├─ 消費税(10%)        54.55円
   ├─ 小売マージン       約60円前後（定価の約10%とされる）
   ├─ 卸マージン         数%
   ├─ 原料（葉たばこ）    数十円
   ├─ 製造・物流・販促    数十円
   └─ メーカー利益        残り

   → 税の合計 359.43円 ＝ 小売価格の【約59.9%】
```

| 指標 | 目安・性質 | 読み方 |
| --- | --- | --- |
| **税負担率** | 約6割 | 値上げの大半は増税の転嫁。メーカーの取り分は思うほど増えない |
| **価格弾力性** | 低い | 値上げしても需要が比例して減らない。だから増税しても税収が保たれる |
| 販売数量 | 年▲4〜5% | 構造的減少。**単価上昇で金額を維持する**のが各社の基本戦略 |
| 広告宣伝費 | 極めて限定的 | 規制で広告が打てない。**他の消費財と違い、販促費が構造的に小さい** |
| 加熱式デバイス | 赤字覚悟の先行投資 | 本体を安く配り、スティックで回収する。→ [02](02_加熱式たばこという転換.md) |
| 海外売上比率（JT） | 圧倒的に高い | 国内だけ見てもJTの実力は分からない。→ [03](03_JTの事業構造.md) |

> **なぜ利益率が高いのか**：広告が打てない＝販促費が要らない、新規参入がない＝シェア争いの
> コストが小さい、需要が価格に鈍い＝値上げが通る。規制が厳しいことが、皮肉にも
> **既存プレイヤーの利益を守る堀**として機能している。

## 6. 競争要因（KSF）と参入障壁

| 要素 | 内容 | 障壁 |
| --- | --- | --- |
| **製造独占** | 国内での製造たばこの製造はJTのみ（たばこ事業法） | **絶対的**（法律上、新規参入が不可能） |
| **輸入・卸の登録** | 外国たばこは「特定販売業者」の登録が必要 | 高い |
| **小売許可** | 営業所ごとに財務大臣の許可。既存店との距離基準（25〜300mの範囲で設定） | 高い（**売り場が法律で希少化されている**） |
| **定価制** | 小売定価は財務大臣の認可。値引き販売ができない | 価格競争が起きない＝既存ブランドが守られる |
| 広告規制 | テレビ・ラジオ広告は不可。屋外・雑誌等も厳しい自主基準 | **新ブランドが知名度を作れない**＝既存ブランドが有利 |
| ブランドの慣性 | 銘柄変更が起きにくい嗜好品 | 高い |
| **加熱式のデバイス技術** | 温度制御・バッテリー・消耗品の設計と量産 | 中〜高（ここだけは技術競争がある） |
| 流通網・棚 | 全国の許可小売店に配荷する体制 | 高い |

> **競争が起きる唯一の場所**：価格も広告も封じられているので、競争は
> **(a) 加熱式デバイスの性能、(b) 新銘柄・フレーバーの投入速度、(c) 海外市場でのM&A**
> の3つにしか存在しない。国内の紙巻では、事実上シェアがほとんど動かない。

## 7. 規制・法制度

| 制度 | 中身 | 効き方 |
| --- | --- | --- |
| **たばこ事業法**（1984年、1985年施行） | 製造独占、小売定価の認可、小売販売業の許可、葉たばこの全量買取。所管は**財務省** | 業界の根本ルール。**監督官庁が税務・財政当局**であることが業界の性格を決めている |
| **日本たばこ産業株式会社法（JT法）** | 政府（財務大臣）が発行済株式の**3分の1超**を保有する義務。役員人事・事業計画等に国の関与 | JTは普通の上場企業ではなく**特殊会社**。2011年に「2分の1以上」から緩和 |
| **たばこ税法・地方税法・たばこ特別税** | 紙巻は1,000本あたり合計15,244円の4本立て | 価格の前提そのもの → [01](01_税と規制が支配する商売.md) |
| **加熱式の課税方式見直し** | 2026年4月1日・10月1日の2段階で、紙巻との税負担差を解消 | 加熱式の値上げが連続 → [02](02_加熱式たばこという転換.md) |
| **国たばこ税の3段階引き上げ** | 2027年4月・2028年4月・2029年4月に1本あたり0.5円ずつ（計30円／箱） | **防衛財源**としての増税 |
| **FCTC（たばこの規制に関する世界保健機関枠組条約）** | 2003年採択、日本は2004年批准、2005年発効。広告規制・警告表示・価格政策等を締約国に求める | 国内規制の上位にある国際的な枠組み |
| **健康増進法（2018年改正、2020年4月全面施行）** | 多数の者が利用する施設は**原則屋内禁煙**。喫煙専用室の基準、20歳未満の立入禁止 | 飲食店・オフィスの設備投資と運用に直結 → 外食各社に影響 |
| 警告表示 | パッケージ表面積の**50%以上**に健康警告（2020年強化） | パッケージデザインの制約 |
| 広告規制 | テレビ・ラジオ・インターネットの一般向け広告は不可。財務省指針＋業界自主規準 | 新規ブランドの参入余地を狭める |
| 年齢確認 | 20歳未満喫煙禁止法。自販機はtaspo等での成人識別 | 販売オペレーションのコスト |

> **重要な捻れ**：たばこの**産業振興と課税は財務省**、**健康対策は厚生労働省**が所管する。
> 同じ政府の中に「税収を守りたい側」と「喫煙率を下げたい側」が同居しているため、
> 規制は「禁止」ではなく「課税強化と場所の限定」という形で進む。

## 8. 最近のトピック

→ 詳細は [04_直近トピック_2026](04_直近トピック_2026.md)

1. **加熱式たばこの課税方式が2026年4月1日と10月1日の2段階で見直された**。重量を紙巻の本数に換算する方式に変わり、紙巻との税負担差が実質的に解消へ向かう。
2. その結果、**2026年は値上げが連続した年**になった。JTは4月にPloom用スティック等37銘柄を20〜30円、10月に31銘柄を各40円引き上げ。PMJは9月に紙巻18銘柄を一律20円引き上げ（パーラメント600円）。
3. **加熱式のシェアは2025年半ばに約46%（JT推計）**、都市部では50%を超えたとされる。日本は世界で最も加熱式への置き換えが進んだ市場になった。
4. **JTの2025年12月期は売上収益3兆4,677億円（＋13.4%）、当期利益5,102億円（＋184.6%）**。前年にカナダ子会社の訴訟和解費用を計上した反動が大きい。年間配当は234円。
5. **JTは2025年に医薬事業から撤退**（鳥居薬品等を塩野義製薬へ総額約1,600億円で譲渡）。2024年には米Vector Groupを約3,780億円で買収しており、**「たばこへの集中」**が鮮明になった。

## 9. 用語メモ

詳しい説明は各ノート末尾の用語メモにある。最小限の12語だけここに掲げる。

| 用語 | 意味 |
| --- | --- |
| **製造たばこ** | たばこ事業法上の定義。葉たばこを原料とする製品。加熱式たばこも含む。VAPE（ニコチンなし）は含まない |
| **製造独占** | 国内で製造たばこを製造できるのはJTだけ、という法律上の仕組み |
| **小売定価** | 製造たばこの価格。メーカーが申請し**財務大臣が認可**する。値引き販売はできない |
| **特定販売業者** | 外国たばこを輸入して国内で卸売する登録業者。PMJ・BATJなど |
| **たばこ特別税** | 1998年に旧国鉄の債務処理財源として導入された国税。1,000本あたり820円 |
| **たばこ税等** | 国たばこ税＋たばこ特別税＋道府県たばこ税＋市町村たばこ税の総称。紙巻で計15,244円／1,000本 |
| **加熱式たばこ** | 葉たばこを燃やさず加熱して使う製品。IQOS・glo・Ploomなど |
| **RRP** | Reduced-Risk Products。JTの呼称で、紙巻以外の加熱式等を指す事業区分 |
| **全量買取義務** | JTが国産葉たばこを契約どおり全量買い取る法律上の義務 |
| **FCTC** | たばこの規制に関する世界保健機関枠組条約。2005年発効 |
| **JT法** | 日本たばこ産業株式会社法。政府に3分の1超の株式保有義務を課す |
| **距離基準** | 小売販売業の許可にあたり、既存店との間に25〜300mの範囲で設定される距離要件 |
