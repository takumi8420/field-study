## 1. 加熱式たばこの課税方式見直しが2段階で実施された（2026年4月／10月）

2026年のたばこ業界を1行で言うと、**「加熱式の税優遇が終わった年」**である。

国税庁は、令和8年（2026年）4月1日からの**加熱式たばこに係る課税方式の見直し**を告知した。
従来は重量と価格から紙巻の本数へ換算していたが、新方式では次のように整理される。

| 区分 | 新しい換算 |
| --- | --- |
| **スティック型** | 1本の重量が0.35g以下であれば、**1本＝紙巻たばこ1本**に換算 |
| **スティック型以外**（カプセル等） | 1個の重量が5g以下であれば、**1個＝紙巻たばこ20本**に換算 |
| 実施 | **2026年4月1日**に第1段階、**2026年10月1日**に新換算方式を全面適用（2段階） |

背景は2024年12月の与党税制改正大綱で示された方針で、目的は
(a) 紙巻との税負担差の解消、(b) 防衛費増額に伴う財源確保の2つとされる。

```
  2026年の「値上げカレンダー」

   4/1  ──▶ JT：Ploom用スティック等 37銘柄を 20〜30円 値上げ
              （EVO 550→580円 / メビウス 520→550円 / キャメル 500→530円
                ウィズ用カプセル 600→620円）
              ※他社の加熱式も同時期に改定

   9/1  ──▶ PMJ：紙巻 18銘柄を一律 20円 値上げ（パーラメント 600円 など）

  10/1  ──▶ JT：Ploom用スティック 31銘柄を各 40円 値上げ
              （EVO 580→620円 / メビウス 550→590円 / キャメル 530→570円）
              PMJ・BAT も同日付で加熱式を値上げ

  ★いずれも小売定価は【財務大臣の認可】を経て変わる。発表＝即値上げではない
```

> **読み筋**：これらは**増税の転嫁**であり、メーカーの取り分が増える値上げではない。
> 半年で加熱式が2度値上げされたことで、**加熱式の割安感は実質的に消えた**。
> 2027年以降、それでも加熱式が選ばれ続けるかが最大の観察点になる。
> 制度の詳細は [02_加熱式たばこという転換](02_加熱式たばこという転換.md)、
> 税の全体像は [01_税と規制が支配する商売](01_税と規制が支配する商売.md)。

## 2. さらに2027〜2029年の3段階増税が決まっている

| 時期 | 内容 |
| --- | --- |
| 2027年4月1日 | 国たばこ税を1本あたり **＋0.5円** |
| 2028年4月1日 | 同 **＋0.5円** |
| 2029年4月1日 | 同 **＋0.5円** |

紙巻・加熱式の**双方**が対象で、3年で1本あたり計1.5円＝**1箱（20本）あたり約30円**の増税になる。
財務省は「予見可能性を確保する観点も踏まえて」3段階とすると説明している。
位置づけは**防衛財源**であり、健康政策としての増税ではない点に注意が要る。

> **押さえどころ**：1998年のたばこ特別税は旧国鉄債務、2027年以降は防衛費。
> **たばこ税はその時々の財政需要を埋める道具として使われてきた**という筋は今回も変わらない。

## 3. 厚生労働省が加熱式たばこの規制強化を見送った（2026年7月）

改正健康増進法（2020年4月全面施行）の**5年後見直し**が2026年の大きな論点だった。

| 論点 | 2026年7月時点の方向 |
| --- | --- |
| **加熱式たばこを紙巻と同水準に規制するか** | **見送り**。受動喫煙の健康影響を評価する科学的知見がまだ足りないとして、当面は現行の経過措置を続ける方針と報じられる |
| 現行の経過措置とは | 紙巻は飲食店・ホテル等の屋内で原則禁煙だが、**加熱式は専用喫煙室で飲食しながらの喫煙が認められている** |
| **喫煙目的施設** | シガーバーやスナックなどを想定する「喫煙目的施設」について、**届出制**を導入する方針。要件は「たばこの対面販売をしていること」「主食と認められる食事を提供しないこと」 |
| 残る課題 | 加熱式専用喫煙室で働く**従業員の受動喫煙からの保護**が焦点として指摘されている |

日本たばこ協会も2026年3月に厚労省の受動喫煙対策専門委員会へ
施行後の現状に関する資料を提出しており、制度見直しの議論は継続している。

```
  受動喫煙規制の現在地（2026年9月時点）

  紙巻たばこ  ──▶ 屋内は原則禁煙（喫煙専用室のみ。飲食不可）
  加熱式たばこ ──▶ ★経過措置：加熱式専用喫煙室では【飲食しながら】可
                    今回の見直しでも強化は見送り
  喫煙目的施設 ──▶ 新たに【届出制】へ（シガーバー・スナック等）

  ★税は「紙巻と揃える」方向、受動喫煙規制は「加熱式を緩いまま残す」方向
    → 制度の2つの軸が、同じ年に逆向きに動いた
```

> **ここが2026年の面白いところ**：財務省側（税）は加熱式の優遇を終わらせ、
> 厚労省側（受動喫煙規制）は加熱式の緩和措置を残した。
> **「税では同じ扱い、規制では違う扱い」**という状態が当面続く。

## 4. JTの業績：2025年12月期の反動増と、2026年の上方修正

### 4-1. 2025年12月期（2026年2月発表）

| 項目 | 数値 | 前年比 |
| --- | --- | --- |
| 売上収益 | 3兆4,677億円 | ＋13.4% |
| 営業利益 | 8,670億円 | ＋175.9% |
| 当期利益 | 5,102億円 | ＋184.6% |
| 調整後営業利益（為替一定ベース） | 9,275億円 | ＋24.9% |
| 年間配当 | 234円（中間104円＋期末130円） | 増配 |

**営業利益が3倍近くに見える理由**：2024年12月期に**カナダ現地子会社の
「喫煙と健康」に関する訴訟の和解費用**を計上して営業利益が3,235億円（▲51.9%）まで落ちており、
その反動が大きい。トルコ・ロシアなどで紙巻の需要が想定を上回ったことも寄与したとされる。

### 4-2. 2026年12月期 第2四半期（2026年7月30日発表）

報道ベースでは、上期は売上収益1兆9,860億円（＋17.7%）、営業利益6,449億円（＋29.0%）、
親会社帰属の当期利益4,318億円（＋35.0%）。通期見通しも上方修正され、
売上収益3兆8,850億円（＋12.0%）、営業利益1兆80億円（＋16.3%）、
当期利益6,440億円（＋26.2%）に引き上げられた。
年間配当予想も234円から**272円**へ増額された（中間配当136円）。

## 5. JTの「たばこへの集中」が完了した

| 年月 | 出来事 |
| --- | --- |
| 2024年10月 | **米Vector Groupの買収完了**（約3,780億円）。世界2位の市場である米国本土へ本格参入 |
| 2025年5月7日 | **医薬事業からの撤退を発表**。鳥居薬品を含む医薬事業を塩野義製薬へ譲渡（総額約1,600億円規模） |
| 2025年5月27日 | 新デバイス**Ploom AURA**と新スティック**EVO**を先行発売。RRP（加熱式等）に2025〜2027年で**6,500億円**を投資すると公表 |
| 2025年6月18日 | 鳥居薬品へのTOBが終了し、完全子会社化 |
| 2025年Q3以降 | 医薬事業を**非継続事業**に分類 |

1985年の民営化以来、JTは「たばこ市場の頭打ち」を前提に医薬・食品への多角化を進めてきた。
しかし新薬開発は1品目に十年超と数百億円を要し、研究開発費の負担が重かったと報じられる。
**約40年続いた医薬事業からの撤退**は、多角化の看板を下ろして
**たばこ（とくに加熱式と海外）に資源を集中させる**という意思表示にあたる。

> **残る多角化は加工食品（テーブルマーク等）のみ**。
> 冷凍麺・パックごはんの世界は [総合食品](../01_総合食品/README.md) を参照。
> 医薬側の視点は [医薬品（新薬）](../../09_医薬・医療・ヘルスケア/01_医薬品（新薬）/README.md)。

## 6. ロシア事業は2026年も未決着のまま

| 論点 | 2026年時点の状況 |
| --- | --- |
| 規模 | ロシアのたばこ市場で約4割のシェアを持つとされ、**CIS＋地域でグループ営業利益の約2割**（その大半がロシア）と報じられる |
| JTの説明 | 2022年4月に「グループ経営からの分離を含めた選択肢の検討」を表明。新規投資・マーケティングを停止したとするが、**事業は継続** |
| 障害 | ロシア側の規制で外国企業の資産売却には政府承認が必要。買い手・価格・送金のすべてに制約 |
| 批判 | ロシアでの納税額の大きさから「戦争を支えているのではないか」という批判が続き、国会でも質問主意書が出されてきた |
| 皮肉な点 | 2025年はロシア・トルコでの販売が想定を上回り、**好決算に寄与した**とされる |

**政府がJT株の3分の1超を保有する特殊会社**であることから、この問題は
企業判断であると同時に政治の問題としても扱われ続けている。
2026年9月時点で、分離・売却の具体策は公表されていない。

## 8. 全体の構図（まとめ）

2026年のたばこ業界は、**「加熱式の優遇が税の側で終わり、規制の側では残った」**年である。
4月・10月の課税方式見直しで加熱式の割安感は消え、2027〜2029年には
防衛財源としての3段階増税が控える。一方、厚労省は加熱式の受動喫煙規制の強化を見送り、
専用喫煙室で飲食できる経過措置を残した。企業側では、JTが医薬から撤退し、
米Vector Groupを取り込み、6,500億円をPloom AURAに投じて国内加熱式の巻き返しを図る一方、
利益の約2割を占めるロシアの扱いは未決着のままである。
需要は本数ベースで年4〜5%減り続けるが、**増税と値上げが金額を支える**という
30年続く構図は2026年も変わっていない。

## 9. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **課税方式の見直し（2026年）** | 加熱式たばこを重量から紙巻の本数へ換算する方法の変更。スティック型は1本≦0.35gで紙巻1本、非スティック型は1個≦5gで紙巻20本。2026年4月・10月の2段階 |
| **小売定価の認可** | 製造たばこの価格変更は財務大臣の認可事項。各社の「値上げ発表」は正確には認可申請の公表である |
| **喫煙目的施設** | 改正健康増進法上の区分。たばこの対面販売を行い、主食と認められる食事を提供しない施設（シガーバー等）。2026年に届出制導入の方針 |
| **経過措置（加熱式専用喫煙室）** | 加熱式に限り、専用室内での飲食を認める暫定的な取扱い。2026年の見直しでも継続の方針 |
| **非継続事業** | 売却が決まり本業と切り離して開示される事業。JTの医薬事業が該当 |
| **RRP** | Reduced-Risk Products。JTにおける加熱式等の事業区分 |
| **CIS＋** | 独立国家共同体を中心とした地域区分。JTの開示上、ロシアが大半を占めるとされる |
| **駆け込み需要と反動** | 増税・値上げ前に買いだめが起き、直後に販売が落ち込む現象。四半期の前年比を読むときの必須の視点 |
