② 宅配弁当と配食サービス — 売っているのは食事だけではない

食品・農水産・外食中食・弁当
あこのページの単語集用語に触れると意味を確認できます9語
配食サービス介護保険外サービス介護予防・日常生活支援総合事業（総合事業）基本チェックリストケアマネジャー（介護支援専門員）地域包括ケアシステムルート密度（契約密度）メディカル給食サブスク（定期購入）

このノートで分かること：家まで弁当を届ける商売が、店売りの弁当とはまったく別の経済で動いていること。
配送費が食材費に迫るほど重く、それでも成り立つのは「毎日同じ家に行く」こと自体に値段がつくからだ。
高齢者向け配食が介護保険の外側にある「保険外サービス」として位置づけられている理由もここにある。

前提：中食市場全体の規模や、スーパー・コンビニの惣菜製造の話は
冷凍食品・惣菜 ②惣菜・中食の市場 にある。
店頭の弁当チェーンは ①弁当チェーンの店舗経済。
学校給食・事業所給食（契約で施設に入る商売）は 給食・フードサービス の領域。

1. 結論：配食は「食事の販売」と「安否確認」の抱き合わせである

【なぜ1食700円の弁当を、わざわざ1軒ずつ手渡しに行くのか】

   利用者（多くは独居高齢者）が買っているもの
   ┌────────────────────────────────────────────┐
   │  ① 栄養バランスのとれた食事        ← 原価がかかる部分      │
   │  ② 買い物・調理・片付けをしなくてよいこと                  │
   │  ③ 毎日、誰かが玄関に来ること      ← ここが「値段のつく」部分 │
   │     ＝ 安否確認・見守り                                  │
   └────────────────────────────────────────────┘
                     │
                     ▼
   家族・自治体から見た価値
   「異変があればその日のうちに分かる」
   ＝ 救急搬送や孤立死の予防コストを肩代わりしている

   → だから自治体が費用の一部を出す。
     単なる弁当の宅配なら公費は出ない。「見守り」だから出る。

ポイント：配食サービスの本体は物流ではなく「定期訪問」である。
宅配便で送れば配送費は下がるのに、あえて自社スタッフが毎日手渡しする事業者があるのは、
手渡しでなければ ③ が成立しないからだ。
実際、多くの自治体が配食への補助を「見守り配食サービス」「配食型見守りサービス」という
名前で制度化している（静岡市・葛飾区・三郷市ほか）。事業の目的が食事ではなく見守りだと明示されている。

2. 配食を3つに分けて見る

同じ「宅配弁当」でも、誰が金を払うかとどう届くかで経済がまったく違う。

類型 代表例 温度帯・頻度 誰が払うか 1食の価格帯 事業の性格
① 自治体委託型（見守り配食）各市区町村の配食事業。地域の弁当業者・社会福祉法人が受託常温・チルド、毎日1〜2食利用者が食事代、自治体が見守り分を補助実質負担 300〜600円程度（自治体で差が大きい）公共サービスの一部。受託できるかがすべて
② 民間・日替わり宅配型ワタミの宅食、まごころ弁当、ライフデリ など常温・チルド、平日毎日利用者が全額500〜900円自社配達員のルート密度で採算が決まる
③ 冷凍宅配EC型nosh（ナッシュ）、三ツ星ファーム、各社の冷凍宅配冷凍、週1回まとめて宅配便利用者が全額（サブスク）600〜1,000円実質は食品ECの定期購入。見守り機能はない
【物流の形が3つある】

  ① 自治体委託型            ② 日替わり宅配型            ③ 冷凍宅配EC型
  ─────────────            ─────────────            ─────────────
   地域の調理施設             自社セントラルキッチン        自社/委託の冷凍工場
        │                          │                          │
        │ 毎朝                     │ 前日夜〜早朝               │ まとめて生産・在庫
        ▼                          ▼                          ▼
   委託業者の車                地域の営業所                  冷凍倉庫
        │                          │                          │
        │ 1日1〜2回                │ まごころスタッフ等が       │ クール宅配便
        │ 手渡し＋声かけ            │ 1コースを巡回・手渡し      │ （ヤマト・佐川）
        ▼                          ▼                          ▼
     利用者宅                    利用者宅                    利用者宅の冷凍庫
                                                            （週1回・10食まとめて）

  距離あたりコスト：  ①≒②（毎日行く）  ＞  ③（週1回・積載効率が高い）
  見守り機能：        ①◎  ②○（手渡し時に声かけ）  ③✕（置き配・不在でも成立）

①②と③の違いが、この分野の最大の分岐点である。
①②は「毎日行く」ことに価値があるので配送費が高くても成立する。
③は見守りを捨てる代わりに、冷凍にして週1回まとめて送り、配送費を10分の1近くまで圧縮した。
矢野経済研究所も、冷凍宅配食について
「冷凍にすることで事業運営の効率化が図れ、デリバリーコストも削減できる」
「安くまとめ買いをしてストックできる」という供給側・需要側双方の利点を指摘している（2025年調査）。

3. 市場規模 — どの箱で数えるかで桁が変わる

指標 数値 年・出典
メディカル給食・在宅配食サービス市場（病院給食＋高齢者施設給食＋在宅配食の合計）2兆4,096億円（前年度比 102.4%）2024年度。矢野経済研究所（2025年調査）
同・2029年度予測2兆5,122億円矢野経済研究所の予測。5年でほぼ横ばい
高齢者向け宅食サービス市場約2,160億円（2019年の約1,800億円比 1.2倍）2025年予測。調査会社・FC本部が引用する推計値

（注：前者は病院・施設給食を含む大きな箱。在宅配食だけを取り出すと数千億円規模にとどまる。
後者は推計であり、集計主体によって数字が動く。引用時は必ずどちらの定義かを添える必要がある）

読み方の注意が2つある。

  • 市場全体は伸びていない。矢野経済研究所は病院給食が病院数・病床数の減少で微減、
    高齢者施設給食は安定期、在宅配食は原材料高による値上げで成長が鈍化したとしている。
    「高齢化が進むから配食市場は伸びる」という直感は、少なくとも金額ベースでは当たっていない
  • 構成比は動いている。同研究所は今後、病院給食の比率が下がり、
    高齢者施設給食と在宅配食の比率が上がると見ている。
    つまり食事の提供場所が病院から自宅・施設へ移るという、地域包括ケアの方針そのものが数字に出ている

4. ワタミの宅食 — 数字で見る日替わり宅配型

この類型で最大手なのがワタミの宅食事業である。決算の数字は、業態の特徴をそのまま映している。

指標 2026年3月期 読み方
宅食事業 売上高410億1,400万円（前期比 +1.9%）伸びは微増。値上げで支えている
宅食事業 セグメント利益43億1,100万円（前期比 △8.7%）増収なのに減益。原材料高を吸収しきれていない
セグメント利益率約10.5%店頭弁当チェーン（営業利益率4%前後）よりはるかに高い
調理済み商品の累計配送数5,878万3,000食（前期比 +1.6%）食数はほぼ横ばい
1食あたり売上（逆算）約698円弁当チェーンの客単価より高い
1日あたりお届け食数約24万食（主力「まごころシリーズ」）同社公表値

（ワタミ 2026年3月期 決算。報道・同社公表ベース。累計販売食数9億食、
病者・高齢者食宅配市場で16年連続売上シェアNo.1は同社発表）

ポイント：なぜ利益率が店頭弁当の2倍以上あるのか。
①定期利用なので週5日分がまとめて売れる（客単価ではなく「週単価」で稼ぐ）、
②前日までに数量が確定するので廃棄ロスがほぼない、
③客席も店舗も要らないので家賃負担が軽い、が主な理由である。
代わりに背負うのが配送費で、これは店売りには存在しないコストだ。

1食700円の中身（試算）

実額は公表されていないが、上の利益率から逆算すると、おおむねこうなる。

  1食 約700円 の内訳（筆者の試算。ワタミ宅食の実績利益率に合わせた概算）

  ┌──────────────────────────────────────────┐
  │ 食材原価          約 240円  ███████████               (約35%)│
  │ 製造・容器・包装  約 100円  ████▌                     (約15%)│
  │ 配送（人件費・車） 約 175円  ████████                  (約25%)│ ◀ 店売りには無い
  │ 拠点・本部・販促  約 110円  █████                     (約15%)│
  │ 利益              約  75円  ███▌                      (約10%)│
  └──────────────────────────────────────────┘

  → 配送費が食材原価の7割に達する。
    「1コースで何軒回れるか」が、そのまま利益率になる。

だからこの事業のKSF（成功の鍵）は、味でもメニュー数でもなく地域内の契約密度である。

  • 1人の配達員が1日に回れる軒数は、住宅の密集度でほぼ決まる
  • 都市部の団地・集合住宅は密度が高く成立しやすい。郊外・中山間地は1軒あたりの移動時間が延びて赤字になる
  • 後から契約が1軒増えると、ほぼ追加コストなしで売上だけ増える（すでにその道を通っているから）
    → 逆に密度が閾値を割ると、撤退するしかない。エリア単位の勝負になる

5. 介護保険の「外側」にあるということ

配食でいちばん誤解されやすいのがここだ。

【介護保険のお金は、原則として食事代には出ない】

  介護保険の給付（要介護認定 → ケアプラン → サービス利用）
  ┌────────────────────────────────┐
  │ 訪問介護・通所介護・福祉用具・施設サービス …           │  ← 1〜3割負担
  │                                                  │
  │  ✕ 食材費・調理費は原則 給付の対象外                  │
  │    （施設に入っても食費は自己負担）                    │
  └────────────────────────────────┘
                    │
                    │ では配食は？
                    ▼
  ┌────────────────────────────────┐
  │ 介護予防・日常生活支援総合事業（総合事業）／市町村の任意事業 │
  │  ・市区町村が独自に設計する。全国一律ではない            │
  │  ・「見守り」を目的に、1食あたり数百円を補助する形が多い    │
  │  ・対象：要支援認定者、基本チェックリスト該当者、独居高齢者など│
  └────────────────────────────────┘
                    │
                    ▼
  それ以外の人は 100%自費 ＝ 「介護保険外サービス」の市場

つまり配食事業者から見ると、客は3つの財布に分かれている。

財布 誰が決めるか 事業者にとっての意味
自治体の補助つき利用者市区町村の要綱。受託事業者は入札・登録制単価は低いが需要が安定。自治体の予算と制度変更に左右される
ケアマネ経由の自費利用者ケアマネジャー（介護支援専門員）の紹介ケアプランに配食は載せられないが、生活支援として勧められる。紹介が営業チャネルになる
家族が契約する自費利用者遠方に住む子世代実際に食べる人と払う人が違う。訴求先は子世代（見守り・安心が売り文句になる）

この「食べる人と払う人が違う」構造は、商品設計に直結する。
配食各社が配達時の声かけ、不在時の家族への連絡、専用アプリでの報告を強化するのは、
子世代に向けた機能だからだ。自治体の要綱でも、異変を検知したら
事前登録の家族や関係機関へ連絡することが明記されているのが通例である（墨田区・渋谷区ほか）。

6. 冷凍宅配EC（③）が伸びた理由と限界

nosh（ナッシュ）に代表される冷凍宅配弁当は、①②とは客層も価値も違う。

比較軸 日替わり宅配（②） 冷凍宅配EC（③）
主な客層高齢者・要支援者20〜40代の単身・共働き
買う理由調理が困難・見守り時短、糖質・塩分・カロリー管理、外食より安い
解約のしやすさ電話一本だが、生活に組み込まれ継続しやすいワンクリックで停止。解約率が経営を左右する
商品の訴求栄養バランス、やわらかさ、減塩糖質30g以下・塩分2.5g以下（nosh）、350kcal以下・たんぱく質15g以上（三ツ星ファーム）など数値で規定
制約配送密度家庭用冷凍庫の容量。10食入ると他が入らない

（各社の栄養基準は各社公表値。市場シェアや累計食数は各社発表・報道ベース）

③の限界は物流でも味でもなく、冷凍庫の棚である。
家庭の冷凍庫に10食も入れれば他の冷凍食品が入らなくなるため、
各社が「冷凍庫プレゼント」を打つのはこの制約を外すためだ。
→ 家庭の冷凍ストック争奪戦という論点は
冷凍食品・惣菜 ③競争と変化 に詳しい。

7. まとめ：配食を理解する3つの鍵

  1. 売っているのは食事＋定期訪問。見守りに値段がつくから、自治体の公費が入り、家族が払う
  2. 配送費が食材費に迫る。だから契約密度がすべてで、エリア単位で成立/不成立が決まる。
    密度を諦めて冷凍＋週1配送に振ったのが nosh 型で、そこでは見守りが消える
  3. 市場は「高齢化だから伸びる」わけではない。金額はほぼ横ばい（2029年度予測 2兆5,122億円）で、
    伸びているのは構成比の移動（病院 → 自宅・施設）と冷凍宅配という新しい客層である

用語メモ

用語 意味
配食サービス調理済みの食事を自宅まで届けるサービス。高齢者向けは見守りとセットで制度化されていることが多い
介護保険外サービス介護保険の給付対象にならない生活支援（配食、掃除、買い物代行、外出同行など）。全額自費か自治体の独自補助で賄う
介護予防・日常生活支援総合事業（総合事業）市区町村が主体となって要支援者・事業対象者向けのサービスを設計する仕組み。配食への補助はここに置かれることが多い
基本チェックリスト要介護認定を受けなくても総合事業のサービスを使えるようにするための、25項目の簡易な確認票
ケアマネジャー（介護支援専門員）利用者のケアプランを作る専門職。配食はプランに載らないが、事実上の紹介チャネルになる
地域包括ケアシステム高齢者が住み慣れた地域で暮らし続けられるよう、医療・介護・予防・住まい・生活支援を一体で提供する構想。配食は「生活支援」に位置づけられる
ルート密度（契約密度）1つの配達コース上にある契約軒数。配食の採算を直接決める指標
メディカル給食病院給食・高齢者施設給食の総称。在宅配食と合わせて調査会社が1つの市場として集計する
サブスク（定期購入）継続課金型の販売。冷凍宅配ECの基本形。解約率（チャーン）が収益の生命線になる
