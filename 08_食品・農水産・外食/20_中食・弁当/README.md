## 1. 業界の定義・範囲

**中食（なかしょく）** ＝ 調理済みの食品を買って帰り、家や職場で食べること。
その中で、このフォルダが扱うのは**1食まるごとを提供する事業者**である。

```
【中食の中の「弁当・配食」の位置】

                 中食（11.7兆円 / 2025年）
                          │
      ┌───────────────┼───────────────┐
      │               │               │
  おかずを買い足す      1食まるごと買う      1食まるごと届く
  （惣菜・サラダ）    （弁当・おにぎり）     （宅配弁当・配食）
      │               │               │
      │        ┌──────┼──────┐        │
      │        │      │      │        │
  スーパー    コンビニ  スーパー  弁当     ワタミの宅食
  デパ地下    ベンダー  店内厨房  チェーン  自治体配食
  冷凍惣菜    製造      製造     ◀━━━━━┓  冷凍宅配EC
      │                              ┃        │
      └──── 冷凍食品・惣菜フォルダ ────┘        │
                                    ┗━ ここが本フォルダ ━┛

      ＋ 別商流：駅弁・空弁・仕出し・法人弁当・デリバリー
```

**隣接業界との境界**を3本引く。

| 境界            | 手前（本フォルダ）           | 向こう側                             | 線引きの基準                                                           |
| --------------- | ---------------------------- | ------------------------------------ | ---------------------------------------------------------------------- |
| 対 **外食**     | 持ち帰り弁当（客席なし）     | 定食屋・ファストフード（客席あり）   | **客席を持つか**。税制上も「持ち帰り＝飲食料品／店内＝外食」で分かれる |
| 対 **惣菜製造** | 弁当を作って直接売る事業者   | 惣菜メーカー・ベンダー（小売に卸す） | **最終消費者に直接売るか、小売に卸すか**                               |
| 対 **給食**     | 個人・法人が都度注文する弁当 | 学校・事業所・病院と年間契約する給食 | **契約か、都度購入か**。給食は「食数が保証される」                     |

## 2. 市場規模と成長性

中食市場そのものの数字は [冷凍食品・惣菜 ②](../06_冷凍食品・惣菜/02_惣菜・中食の市場.md) に詳しいので、
ここでは**弁当・配食の事業者側に直結する指標**だけを置く。

| 指標                                           | 数値                                                | 年・出典                            |
| ---------------------------------------------- | --------------------------------------------------- | ----------------------------------- |
| 惣菜専門店（弁当チェーン・デリカ等）の市場規模 | **3兆2,020億円**（構成比27.4%、前年比104.2%）       | 2025年。日本惣菜協会                |
| FF持ち帰り米飯／回転寿司 売上高前年比          | **102.9%**（客数 **96.0%**、客単価 107.2%）         | 2025年 年間。日本フードサービス協会 |
| 同・2026年月次                                 | 3月 98.7%、4月 99.6%                                | 2026年。同協会（報道ベース）        |
| メディカル給食・在宅配食サービス市場           | **2兆4,096億円**（前年度比102.4%）                  | 2024年度。矢野経済研究所            |
| 同・2029年度予測                               | 2兆5,122億円（**5年でほぼ横ばい**）                 | 矢野経済研究所の予測                |
| 「お弁当屋さん」の倒産件数                     | **2026年1〜8月で83件**（2年連続で過去最多の見込み） | 東京商工リサーチ（2026年9月19日）   |

> **成長性の読み方**：市場は金額で伸びているが、**数量（客数・食数）は伸びていない**。
> 2025年に客数が前年割れした外食業態は、持ち帰り米飯／回転寿司と焼き肉の2つだけだった。
> 弁当は「値上げで売上を保っている」段階にあり、事業者数では淘汰が進んでいる。

## 3. バリューチェーン（川上 → 川下）

```
  ■ 弁当チェーン（受注生産型）

  産地・商社 ─▶ 本部一括仕入 ─▶ 自社/委託の加工センター ─▶ 物流センター
     米・鶏肉                    下処理・カット・半調理        1日1便（チルド）
     容器・資材                         │
                                       ▼
                                    店舗の厨房 ──▶ 注文を受けて調理・盛付 ──▶ 客
                                    ここで初めて作る            5〜10分

     付加価値がたまる場所： ① 本部の一括仕入（ボリュームディスカウント）
                           ② 加工センターの半調理（店の技能要求を下げる）
                           ③ 立地（昼の分母＝工場・オフィス・現場）

  ■ 配食（定期契約型）

  食材調達 ─▶ セントラルキッチン ─▶ 地域の営業所 ─▶ 配達員が1軒ずつ手渡し ─▶ 利用者
                前日までに確定数量      早朝仕分け      声かけ・安否確認
                ＝廃棄ロスゼロ                          ＝これが公費の対象になる

     付加価値がたまる場所： ① ルート密度（1コースの契約軒数）
                           ② 自治体の受託実績・ケアマネの紹介網
                           ③ 継続率（一度入ると生活に組み込まれる）
```

川上（食材・容器）はコモディティで価格支配力がなく、
**付加価値は「立地」または「顧客との継続関係」に集まる**。
これが製造業型の食品メーカーとの決定的な違いである。

**シェアの特徴**：持ち帰り弁当はほっともっとが突出して大きいが、
市場全体で見れば**弁当チェーン3社を合わせても惣菜専門店3.2兆円の1割前後**にすぎない。
残りは無数の地域業者・デリカ専門店・駅ナカテナントである。
**集約が進んでいない、きわめて分散した業界**という点は押さえておきたい。

## 5. 収益モデル・コスト構造

| 事業形態                   | 売上のつくり方                             | コストの主役                                   | 営業利益率の目安                                 |
| -------------------------- | ------------------------------------------ | ---------------------------------------------- | ------------------------------------------------ |
| **弁当チェーン（直営）**   | 客数 × 客単価。店頭即売                    | 食材原価40〜47%＋人件費22〜27%（FL65〜70%）    | **3〜6%**（プレナス連結は4.3%／2026年2月期）     |
| **弁当チェーン（FC本部）** | 加盟店への食材・資材卸＋ロイヤリティ＋物流 | 仕入原価と物流費。**店の赤字は負わない**       | 店舗運営より安定するが、加盟店が減ると即座に効く |
| **配食（日替わり宅配）**   | 契約軒数 × 週あたり食数。定期課金に近い    | **配送人件費が売上の2割強**。食材原価は35%前後 | **10%前後**（ワタミ宅食は10.5%／2026年3月期）    |
| **冷凍宅配EC**             | サブスク。解約率が生命線                   | 冷凍物流費＋広告宣伝費（顧客獲得コスト）       | 各社非開示。獲得コストの回収期間が勝負           |
| **仕出し・法人弁当**       | 行事・会議単位の受注。数量は前日確定       | 食材＋配送。**廃棄ロスはゼロ**                 | 単価が高く、値上げも通りやすい                   |

> **この業界の利益の出どころを一行で**：
> 弁当チェーンは「**客席を持たない**」ことで、配食は「**廃棄ロスを持たない**」ことで利益を出している。
> どちらも原価率そのものは飲食店より高い。節約できる項目が違うだけである。

## 6. 競争要因（KSF）と参入障壁

| KSF                          | なぜ効くか                                                                           |
| ---------------------------- | ------------------------------------------------------------------------------------ |
| **昼の分母がある立地**       | 弁当店の商圏は「住宅」ではなく「職場」。工場・現場・オフィスの分布で採算が決まる     |
| **ピーク処理能力**           | 受注生産なので、昼の90分でさばける食数が売上の天井。事前注文・団体予約でこれをならす |
| **法人・団体需要の獲得**     | 数量確定・廃棄ゼロ・ピーク外調理・値上げが通る。最も条件のよい商流                   |
| **配食のルート密度**         | 1コースの契約軒数がそのまま利益率。密度が閾値を割るとエリアごと撤退になる            |
| **自治体の受託実績**         | 配食では入札・登録の実績が次の受託を呼ぶ。公費の安定需要にアクセスできる             |
| **衛生事故を起こさないこと** | 大量調理で食中毒を出せば事業が止まる。HACCP対応は小規模業者ほど重い                  |

**参入障壁は低い。だが退出も多い。**
弁当屋は保健所の営業許可と厨房設備があれば始められるため、開業は容易である。
一方で、原材料・人件費・容器の上昇を価格に転嫁できずに退出する業者が絶えない
（2026年1〜8月で83件、資本金1,000万円未満が67.4%）。
**参入障壁ではなく「生存障壁」が高い業界**と捉えるのが実態に近い。

## 7. 規制・法制度

| 制度                               | 内容                                                                                                                         | 弁当・配食への効き方                                                                                                             |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| **食品衛生法／営業許可**           | 飲食店営業・惣菜製造業などの許可が必要。保健所が所管                                                                         | 店舗ごとに取得。仕出しで大量調理する場合は施設基準が厳しくなる                                                                   |
| **HACCP に沿った衛生管理**         | 2021年6月に完全義務化。工程ごとの危害要因管理と記録                                                                          | 小規模事業者には簡略版があるが、**記録の手間が廃業の一因**にもなっている                                                         |
| **大量調理施設衛生管理マニュアル** | 1回300食以上または1日750食以上の施設が対象（厚生労働省）                                                                     | 仕出し・配食のセントラルキッチンが該当。検食の保存（2週間）などが義務                                                            |
| **食品表示法**                     | 原材料・アレルゲン・消費期限の表示                                                                                           | 対面販売の弁当は表示が一部免除されるが、宅配・ECは表示義務が重い                                                                 |
| **軽減税率／2027年の飲食料品1%**   | 2019年導入の軽減税率で「持ち帰り8%／店内10%」。2026年9月の閣議決定で2027年4月から2年間、飲食料品を1%とする方針（法改正待ち） | 持ち帰り弁当は**対象になる可能性が高く追い風**。ただしイートイン併設店は運用負担が増える（→ [④](04_直近トピック_2026.md) 第6章） |
| **介護保険法／総合事業**           | 配食は原則として介護保険給付の対象外。市区町村の総合事業・任意事業で補助                                                     | 自治体ごとに要綱が違うため、**配食事業者は自治体単位で営業する**ことになる                                                       |
| **食品ロス削減推進法**             | 2019年施行。事業者に削減の努力義務                                                                                           | 受注生産の弁当チェーンは元々ロスが小さく、規制面では有利                                                                         |

## 8. 最近のトピック

詳細は [④直近トピック_2026](04_直近トピック_2026.md)。要点は5行。

1. **弁当店の倒産が2年連続で過去最多へ**（2026年1〜8月で83件）。市場は伸びているのに事業者は消えている
2. **米価は下落に転じた**（スーパー5kg平均 2026年2月 4,204円 → 8月 3,220円）が、
   包装資材・人件費・物流費が上がり続けるため店頭価格は下がらない
3. **ほっともっとは既存店売上104.3%・客数94.2%**（2026年2月期）。値上げで売上を保つ構図が続く
4. **配食は増収減益**（ワタミ宅食のセグメント利益△8.7%）。市場規模も2029年度までほぼ横ばい予測
5. **2027年4月の飲食料品1%**は持ち帰り弁当に追い風だが、イートイン併設店の運用負担が論点になる
