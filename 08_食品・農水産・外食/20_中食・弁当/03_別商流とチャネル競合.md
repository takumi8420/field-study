# ③ 別商流とチャネル競合 — 駅弁・仕出し・デリバリーと、弁当が奪い合われる場所

このノートで分かること：弁当には「店に買いに行く」以外に、**まったく別の売られ方**が4つあること
（駅弁・空弁／仕出し・法人弁当／デリバリープラットフォーム／エキナカ・催事）。
そしてそれぞれが違う理由で成立し、違う理由で苦しんでいること。
最後に、中食の需要がコンビニ・スーパー・内食とどう奪い合われているかを整理する。

> 前提：中食市場の業態別構成（コンビニ30.8%、食料品スーパー30.3%、惣菜専門店27.4% ほか、2025年）は
> [冷凍食品・惣菜 ②惣菜・中食の市場](../06_冷凍食品・惣菜/02_惣菜・中食の市場.md) に整理済み。
> ここでは**そこに載っていない商流**と、**チャネル間の奪い合い**を扱う。

## 1. 結論：弁当は「誰が需要を作るか」で4つに分かれる

店頭の弁当チェーン（→ [①](01_弁当チェーンの店舗経済.md)）は「店の前を通る人」が需要だった。
だが弁当という商品は、需要の作られ方がまったく違う商流をいくつも持っている。

```
【弁当の4つの別商流 ― 需要を作っているものが違う】

  ① 駅弁・空弁         需要を作るのは「移動」
     ─────────────────────────────────────
     新幹線の発車時刻 ── 客は必ず「今ここで」買う ── 比較検討しない
     → 立地独占が効く。価格弾力性が低い。旅の高揚が単価を押し上げる
     → 移動が減ると需要が消える（コロナ期に壊滅、出張のオンライン化で戻り切らない）

  ② 仕出し・法人弁当    需要を作るのは「行事と会議」
     ─────────────────────────────────────
     葬儀・法事・会議・研修・ロケ・イベント ── 前日までに数量が確定
     → 廃棄ゼロ。ピーク外で仕込める。BtoBなので値上げが通りやすい
     → 幹事は味より「確実に時間通り届くか」で選ぶ ＝ 信頼が参入障壁

  ③ デリバリー          需要を作るのは「動きたくない気分」
     ─────────────────────────────────────
     アプリを開く ── プラットフォームが客を連れてくる ── 手数料を払う
     → 客は増える。利益は減る。低単価商品ほど不利になる

  ④ 催事・エキナカ・EC   需要を作るのは「イベント性」
     ─────────────────────────────────────
     百貨店の駅弁大会、冷凍駅弁の通販、駅ナカの弁当専門ゾーン
     → 「駅で売れないなら、駅の外に駅弁を持っていく」という脱・立地の動き
```

> ポイント：店頭の弁当チェーンが**立地に張りつく商売**なのに対し、
> ②は**顧客名簿に張りつく商売**、①は**インフラに張りつく商売**、③は**プラットフォームに借りる商売**である。
> 同じ「弁当を作って売る」でも、守るべき資産がまったく違う。

## 2. 駅弁 — インフラに寄生し、インフラとともに縮んだ

駅弁は日本独特の商流で、**駅構内で営業する許可（構内営業権）**を持つ地元業者が、
その駅でしか買えない弁当を作って売る、という形で100年以上続いてきた。

| 指標                                           | 数値                               | 年・出典                                       |
| ---------------------------------------------- | ---------------------------------- | ---------------------------------------------- |
| 日本鉄道構内営業中央会 加盟社数（ピーク）      | **400社超**                        | 昭和30年代。報道・業界資料ベース               |
| 国鉄分割民営化時の駅弁業者数                   | **349社**                          | 1987年。報道ベース                             |
| 直近の加盟社数                                 | **86〜96社**（調査時点で差がある） | 2021年前後の報道ベース。**ピークの4分の1以下** |
| 京王百貨店「元祖有名駅弁と全国うまいもの大会」 | 第61回、**約380種・41業者**が出品  | 2026年1月6〜21日。同店発表                     |

なぜここまで減ったのか。理由は駅弁が**鉄道インフラの寄生ビジネス**だったからだ。

```
【駅弁の需要を殺したもの】

  かつて                              いま
  ───────────────────            ───────────────────
  在来線の長距離移動が数時間          新幹線で2時間半 → 食べずに着く
  列車内に食事の手段がない            車内販売の縮小・廃止が相次ぐ
  駅の売店以外に買う場所がない        駅ナカにコンビニ・ベーカリー・惣菜店
  出張・旅行が移動の主流              出張のオンライン会議化

      ↓                                  ↓
  「駅で買うしかない」＝ 独占          「駅でも買える」＝ ただの競合の1つ
```

だから駅弁業者が取った道は、**駅から出ること**である。

- **催事（駅弁大会）**：百貨店の物産展に出す。輸送駅弁として全国に送るか、実演で現地調製する。
  京王百貨店の大会は毎年1月に約380種を集める規模で、**1年の売上の相当部分をここで稼ぐ業者もある**とされる
- **冷凍化・EC**：崎陽軒が「おうちで駅弁シリーズ」として冷凍商品を展開するなど、
  賞味期限の壁（常温の駅弁は当日限り）を冷凍で外して通販に乗せる動き
  → 冷凍化の技術的な背景は [冷凍食品 ①](../06_冷凍食品・惣菜/01_冷凍食品という産業.md)
- **駅以外の出店**：駅ビル・商業施設・空港への展開。崎陽軒は2026年5月、新大阪駅の駅弁大会に初出店

> ポイント：駅弁は「**立地の独占で高く売る**」商売だったが、その独占が消えた。
> 残ったのは**ブランドと製法**だけで、それを持って駅の外（催事・EC・冷凍）へ出ていくしかない。
> 崎陽軒のシウマイのように、**駅弁というより地域の名物食品として自立できた企業だけが生き残った**構図である。

## 3. 仕出し・法人弁当 — 中食でいちばん「値上げが通る」商流

仕出し（しだし）＝注文を受けて調理し、指定の場所・時間に届ける形態。
法事・会議・研修・イベント・撮影現場など、**行事につく弁当**がこれにあたる。

| 比較軸             | 店頭の持ち帰り弁当   | 仕出し・法人弁当                                     |
| ------------------ | -------------------- | ---------------------------------------------------- |
| 注文のタイミング   | その場（即時）       | **前日〜数日前に確定**                               |
| 数量のブレ         | 読めない             | **ゼロ**（確定数量で作る）                           |
| 廃棄ロス           | ほぼ無し（受注生産） | **完全にゼロ**                                       |
| 調理タイミング     | 昼・夕のピークに集中 | **ピークの外で仕込める**                             |
| 価格帯             | 400〜800円           | **800〜3,000円以上**                                 |
| 値上げの通りやすさ | 10円で客が逃げる     | **通りやすい**（経費で落ちる／幹事が比較検討しない） |
| 選ばれる基準       | 味・価格・近さ       | **時間通りに、数が揃って届くこと**                   |

だから弁当チェーン各社は法人需要の取り込みを強化する。
プレナスは2026年2月期の重点施策に
「**スポーツイベント等の団体需要獲得に向けた営業体制を強化**」を挙げており、
2026年3月の価格改定でも**特注弁当は＋100円、オードブルは＋200円**と、
個人向け（＋10〜30円）の数倍の幅で上げている
（プレナス「『ほっともっと』商品価格に関するお知らせ」2026年2月20日）。

**同じ会社が、同じ厨房で作った弁当なのに、売る相手によって値上げ幅が10倍違う**。
これが価格弾力性（値段を上げたときに客がどれだけ逃げるか）の差である。

参入障壁も独特で、品質より**事故を起こさないこと**が効く。
100人分の弁当が30分遅れれば行事そのものが壊れるため、
発注側は「過去に間に合った業者」から動かない。
その一方で、大量調理で食中毒を出せば事業が止まる。衛生管理（HACCP）の負担は
店頭弁当より重く、**小規模業者が受けきれずに撤退する要因**にもなっている。

## 4. デリバリー — 客は増えるが、低単価ほど食われる

Uber Eats・出前館などのプラットフォームは、中食の作り手にとって
「店の外から客を連れてくる装置」である。同時に、**弁当という低単価商品と相性が悪い**。

```
【店頭500円の弁当が、アプリでは1,100円になる理由】

  店頭で買う                          アプリで頼む
  ─────────────                      ──────────────────────
                                      商品価格を店頭より 40〜60% 高く設定
     500円                        ┌─ 約 770円  ← ここから手数料が引かれる
       │                          │     │
       │                          │     └─ プラットフォーム手数料 30%前後
       ▼                          │        ＝ 約 230円 がプラットフォームへ
   店の取り分 500円                │        店の取り分 ≒ 540円（店頭とほぼ同じ）
                                   │
                                   ├─ 配送手数料      200〜500円
                                   └─ サービス料      数%
                                        ─────────────────
                                        客の支払い    約 1,100円
```

（商品価格の上乗せ幅・配送手数料は比較サイト・各社案内ベース。
手数料率30%前後は [ファストフード ②](../14_ファストフード/02_ファストフード特有の仕組み.md) 参照）

この図から読めることは3つある。

1. **店の取り分は店頭とほぼ同じにしかならない**。手数料を価格に転嫁しているだけで、
   デリバリーが儲かっているわけではない。増分は「本来来なかった客」の分だけ
2. **低単価商品ほど不利**。500円の弁当に300円の配送料が乗ると価格は1.6倍になるが、
   3,000円のピザなら1.1倍にしかならない。**手数料は率だが、配送料は額**だからだ
3. **客側から見ると弁当チェーンの価格優位が消える**。店頭なら「コンビニ弁当より安い」だったものが、
   アプリの上では他の外食と同じ価格帯に並んでしまう

ほっともっとは自社デリバリーに加えて Uber Eats・menu・出前館に出しており、
全国で最も掲載店舗が多いのは Uber Eats とされる（各社案内・比較サイトベース、2026年時点）。
プラットフォーム側の事業経済（Uber Eatsは黒字、出前館は赤字が続くと報じられる）は
[フードテック ③流通と消費のテクノロジー](../../01_注目テーマ/13_フードテック/03_流通と消費のテクノロジー.md) に整理がある。

## 5. 誰が弁当需要を奪い合っているか

中食の需要は、業態の垣根を越えて同じ財布を取り合っている。

| チャネル               | 強み                                             | 弁当チェーンから見た脅威                                                                   |
| ---------------------- | ------------------------------------------------ | ------------------------------------------------------------------------------------------ |
| **コンビニ**           | 24時間、どこにでもある、温めてくれる             | **時間と立地では勝てない**。ただし1食あたりは弁当チェーンのほうが量が多く割安              |
| **食料品スーパー**     | 生鮮の買い物ついでに買える。**閉店前の値引き**   | 夕方の需要を値引き惣菜に持っていかれる。ロスを出す業態だからこそ**投げ売りできる**のが厄介 |
| **ドラッグストア**     | 食品を集客用に安く売る。弁当・惣菜の取扱いが拡大 | **原価を割ってでも集客したい**業態が参入してきた                                           |
| **冷凍宅配・冷凍食品** | 買い置きできる。1食あたり単価が読める            | 「今日何を食べるか」を決める前に、すでに冷凍庫にある状態を作られる                         |
| **内食（手作り弁当）** | 限界費用が安い。余り物を使える                   | 節約局面で最初に戻る先。**最大の競合は家庭の台所**                                         |

### 「作ったほうが安いか」の損益分岐

節約局面で中食が伸びるか内食が伸びるかは、**食材価格と弁当価格のどちらが先に上がるか**で決まる。
2024〜2026年の米価変動は、この綱引きをはっきり見せた。

```
【米価と弁当価格の追いかけっこ（2026年8月時点）】

  スーパーの米 5kg 平均価格
    2026年 2月上旬  4,204円  ─┐
                              │ 半年で 約984円（約23%）下落
    2026年 8月上旬  3,220円  ─┘ （前年同期比 △13.8%）

  → 弁当1食分の米（生米150g）の原価
       4,204円/5kg のとき 約126円
       3,220円/5kg のとき 約 97円     …… 1食あたり約30円の差

  一方、弁当チェーンの店頭価格は
       2025年1月 +20円 → 2025年4月 のり弁+40円 → 2025年6月 +50円 → 2026年3月 +10〜30円
       （ほっともっとの例。報道および同社発表の整理）

  ＝ 米が下がっても、店頭価格は下がらない（人件費・物流費・容器が上がり続けているため）
     → 家庭側から見ると「自分で炊いたほうが安い」差が再び開く
     → これが 2025〜2026年に弁当チェーンの客数が前年割れした一因とみられる
```

（米価：時事通信「スーパーでのコメの平均価格」ほか農林水産省公表データに基づく報道。
価格改定：プレナス発表および報道ベース。因果関係は**筆者の解釈**）

> ポイント：**中食は「外食の代わり」としては強いが、「内食の代わり」としては弱い**。
> 外食と比べれば中食は安いので、節約局面では外食 → 中食の移動が起きる。
> だが内食と比べると中食は高く、節約がさらに深まると中食 → 内食へ戻る。
> 中食全体（11.7兆円、2025年）が伸びているのに弁当チェーンの客数が減るのは、
> **前者の追い風をスーパー惣菜が取り、後者の逆風を弁当チェーンが受けている**からである。

## 6. まとめ：この章を理解する3つの鍵

1. **駅弁はインフラの独占で成立していた**。独占が消えた今、
   残ったブランドを持って駅の外（催事・冷凍・EC）に出た業者だけが生き残っている
2. **仕出し・法人弁当は中食で最も条件がよい**。数量確定・廃棄ゼロ・ピーク外調理・値上げが通る。
   だから各チェーンが取りに行く。障壁は味ではなく「事故を起こさない信頼」
3. **弁当の競合は弁当屋ではない**。コンビニ・スーパー・ドラッグストア・冷凍・家庭の台所が同じ需要を取り合う。
   節約が浅いと中食が伸び、深まると内食に戻る

## 用語メモ

| 用語                         | 意味                                                                                                               |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| **駅弁**                     | 鉄道駅・列車内で販売される弁当。日本鉄道構内営業中央会の基準を満たすと「駅弁マーク」を表示できる                   |
| **調製元（ちょうせいもと）** | 駅弁を実際に製造している業者。駅名ではなく調製元で味が決まる                                                       |
| **構内営業**                 | 鉄道事業者の許可を得て駅構内で物販・飲食を行うこと。駅弁業者の事業基盤だった                                       |
| **輸送駅弁**                 | 催事で販売するため、製造地から会場へ輸送される駅弁。現地で作る「実演駅弁」と区別される                             |
| **空弁（そらべん）**         | 空港で売られる弁当。駅弁の空港版として2000年代に定着した                                                           |
| **仕出し**                   | 注文に応じて調理し、指定の場所・時間に届ける形態。法事・会議・イベントの弁当が代表                                 |
| **価格弾力性**               | 値上げしたときに需要がどれだけ減るか。個人向け弁当は高く（すぐ逃げる）、法人向けは低い                             |
| **プラットフォーム手数料**   | デリバリー事業者に払う注文金額に対する手数料。30%前後とされる                                                      |
| **限界費用**                 | もう1食作るのに追加でかかる費用。家庭の手作り弁当は余り物を使えるため極めて低い                                    |
| **HACCP（ハサップ）**        | 危害要因分析・重要管理点。工程ごとに危険を管理する衛生管理手法で、日本では原則すべての食品事業者に義務化されている |
