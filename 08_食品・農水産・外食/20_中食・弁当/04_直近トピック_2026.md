# ④ 直近トピック（2026年9月時点）

報道・IR ベースの整理。一次情報で裏取りすること。
中食市場全体の数字（惣菜11兆7,075億円、冷凍食品の生産300万トン超など）や、
2027年4月の飲食料品1%課税は [冷凍食品・惣菜 ④直近トピック](../06_冷凍食品・惣菜/04_直近トピック_2026.md)
で扱っているので、ここでは**弁当・配食の事業者側で起きていること**に絞る。

## 1. 弁当店の倒産が2年連続で過去最多へ（2026年9月発表）

中食市場は過去最高を更新し続けているのに、**弁当屋はかつてないペースで潰れている**。
この乖離が2026年のいちばん重要なニュースである。

| 指標                       | 数値                                      | 出典                                  |
| -------------------------- | ----------------------------------------- | ------------------------------------- |
| 「お弁当屋さん」の倒産件数 | **2026年1〜8月で83件**                    | 東京商工リサーチ（2026年9月19日発表） |
| 2025年（通年）             | **89件**（当時の過去最多）                | 同上                                  |
| 2026年の見通し             | **2年連続で過去最多を更新する見込み**     | 同上                                  |
| 地区別（2026年1〜8月）     | 関東 **35件（42.1%）**、近畿・九州 各10件 | 同上                                  |
| 資本金規模                 | **1,000万円未満が67.4%**                  | 同上                                  |

帝国データバンクも同時期に「弁当店の倒産が2年連続で最多」「『安い弁当』限界に」と題した調査を出しており、
**値上げできないことが致命傷になっている**と指摘している。

```
【なぜ市場は最高なのに、店は潰れるのか】

  中食市場 11.7兆円（2025年、過去最高）
      │
      ├── スーパー惣菜   104.9%  ← 伸びている（生鮮の集客装置として投資）
      ├── コンビニ       102.3%  ← 伸びは鈍いが規模は最大
      ├── ドラッグストア         ← 集客目的で原価を割ってでも入ってくる
      │
      └── 独立系の町の弁当屋      ← ここだけが取り残されている
              │
              ├ 仕入は大手と同じだけ上がる（むしろ量が少ない分だけ不利）
              ├ 値上げすると常連の会社員が来なくなる（1食10円に敏感）
              ├ 値引き競争に付き合えない（スーパーのように他部門で埋められない）
              └ 後継者もいない
                    ↓
              倒産・廃業
```

> ポイント：これは**需要の消滅ではなく、需要の移動**である。
> 弁当は売れている。売っている主体が、町の弁当屋からスーパー・コンビニ・
> ドラッグストア・大手チェーンへ入れ替わっているだけだ。
> 惣菜市場の統計（日本惣菜協会）が過去最高を更新し続けることと、
> 倒産統計が過去最多を更新することは、まったく矛盾しない。

## 2. 米価が下落に転じた ― それでも弁当屋は楽にならない

2024〜2025年に弁当業界を直撃した米価高騰は、2026年に入って下落に転じた。

| 時点            | スーパーの米 平均販売価格（5kg・税込） | 前年同期比 |
| --------------- | -------------------------------------- | ---------- |
| 2026年2月2〜8日 | **4,204円**                            | —          |
| 2026年8月3〜9日 | **3,220円**                            | **△13.8%** |
| 半年間の変化    | **△984円（約23%の下落）**              | —          |

（時事通信・農林水産省公表データに基づく報道。
なお2025年産米の7月相対取引価格は全銘柄平均 32,486円/玄米60kg で前年同月比+21%と高いままだが、
農林水産省自身が「7月の取引は全体の約4%で影響は小さい」としている）

ところが、これで弁当屋が救われるわけではない。理由は3つある。

1. **米は弁当原価の一部にすぎない**。1食分の生米150gで見ると、
   5kg 4,204円のとき約126円、3,220円のとき約97円。**下がる幅は1食あたり30円程度**
2. **他のコストは下がっていない**。鶏肉・食用油・小麦粉、電気・ガス、
   そして**包装資材と人件費**は上がり続けている。冷食・惣菜側でも
   2026年の値上げの理由が「原料」から「包装資材」へ移ったことが指摘されている
   （→ [冷凍食品・惣菜 ④](../06_冷凍食品・惣菜/04_直近トピック_2026.md)）
3. **一度上げた店頭価格は下げられない**。米価が戻っても値下げはしない。
   その結果、**家庭から見ると「自分で炊いたほうが安い」差が再び開く**
   （→ [③別商流とチャネル競合](03_別商流とチャネル競合.md) 第5章）

東京商工リサーチが調査の副題を
「コメ価格下落と消費税引き下げもコスト高」としているのは、この構図を指している。

## 3. ほっともっと ― 客数94.2%、それでも増収増益（2026年4月発表）

業界最大手プレナスの2026年2月期決算は、この業態の現在地をそのまま示している。

| 指標                                    | 2026年2月期               | 前期比                                        |
| --------------------------------------- | ------------------------- | --------------------------------------------- |
| 連結営業収益                            | **1,804億9,600万円**      | **+5.7%**（4期連続増収）                      |
| 連結営業利益                            | **77億6,800万円**         | **+7.4%**（6期連続増益）／営業利益率 **4.3%** |
| 粗利率                                  | 52.4%                     | 前期と同水準（±0.0P）                         |
| 親会社株主に帰属する当期純利益          | 52億6,600万円             | +17.9%                                        |
| ほっともっと事業 営業収益               | **1,183億5,600万円**      | +4.2%                                         |
| ほっともっと 店舗数                     | **2,426店舗**             | **前期末比 ±0店**                             |
| ほっともっと 既存店売上高               | **104.3%**                | —                                             |
| **ほっともっと 既存店客数**             | **94.2%**                 | **△5.8%**                                     |
| やよい軒（定食・店内飲食） 既存店売上高 | **110.5%**（客数 102.4%） | 二桁成長                                      |

（プレナス「2026年2月期 決算説明資料」2026年4月22日）

> ポイント：**同じ会社の中で、持ち帰り弁当と店内飲食の明暗が分かれている**。
> ほっともっと（持ち帰り）は客数△5.8%を単価で埋めて+4.3%。
> やよい軒（店内飲食）は客数+2.4%で売上+10.5%。
> これは「外食が弱く中食が強い」という一般論とは**逆**である。
> 節約局面で削られているのは外食ではなく、**内食に最も近い持ち帰り弁当**のほうだ。

同社は続く2026年2月20日に価格改定を発表し、3月2日から
のり弁当など＋10円、主力弁当＋20円、とんかつ系＋30円、特注弁当＋100円、オードブル＋200円を実施した。
**個人向けは10円刻み、法人向けは100円単位**という対比が、そのまま価格弾力性の差を表している。

## 4. 持ち帰り米飯の客数が業界全体で前年割れ（2026年1月・月次も継続）

プレナス1社の話ではない。業界統計でも同じ形が出ている。

| 区分（2025年 年間・全店データ） | 売上高     | 店舗数    | 客数       | 客単価     |
| ------------------------------- | ---------- | --------- | ---------- | ---------- |
| 外食 **全体**                   | 107.3%     | 100.7%    | **102.9%** | 104.3%     |
| ファーストフード 合計           | 107.5%     | 101.4%    | 103.0%     | 104.4%     |
| **FF 持ち帰り米飯／回転寿司**   | **102.9%** | **99.7%** | **96.0%**  | **107.2%** |
| FR 焼き肉                       | 102.2%     | 99.9%     | 98.2%      | 104.1%     |

（日本フードサービス協会「外食産業市場動向調査 令和7年（2025年）年間結果報告」2026年1月26日。税抜比較）

2025年に**客数が前年を割ったのは、持ち帰り米飯／回転寿司と焼き肉の2業態だけ**だった。
協会自身も「コロナ禍からの回復が早かった『FF持ち帰り米飯・回転寿司』や
『FR焼き肉』などの業態は、客数が前年を下回った」と総括している。

2026年に入っても回復していない。月次調査では
**2026年3月 98.7%、4月 99.6%** と、この区分は前年割れが続いている（報道ベース）。
回転寿司と合算された数字なので弁当単独の姿ではないが、
回転寿司が「食べ放題の拡充などで集客」と好調に報じられていることを踏まえると、
**持ち帰り米飯側の落ち込みはこの数字より深い**と読むのが自然である。

## 5. 配食 ― 増収減益と「市場は横ばい」という現実

高齢化を背景に伸びると思われがちな配食も、2026年の数字は素直ではない。

| 指標                                 | 数値                           | 年・出典                               |
| ------------------------------------ | ------------------------------ | -------------------------------------- |
| ワタミ 宅食事業 売上高               | **410億1,400万円**（+1.9%）    | 2026年3月期。報道・同社公表            |
| ワタミ 宅食事業 セグメント利益       | **43億1,100万円**（**△8.7%**） | 同上。**増収減益**                     |
| ワタミ 調理済み商品 累計配送数       | 5,878万3,000食（+1.6%）        | 同上                                   |
| メディカル給食・在宅配食サービス市場 | 2兆4,096億円（前年度比102.4%） | 2024年度。矢野経済研究所（2025年調査） |
| 同・2029年度予測                     | **2兆5,122億円**               | **5年でほぼ横ばい**の予測              |

```
【「高齢化 → 配食は伸びる」が単純に成立しない理由】

   対象人口は増える ──────────┐
                                ├──▶ でも金額は伸びない
   1人あたり支出は増えない ─────┘
        │
        ├ 年金生活者は1食800円を毎日は払えない
        ├ 自治体の補助予算も増えない（財政制約）
        └ 配送コストが上がる分を値上げすると、利用者が食数を減らす
              （週5食 → 週3食、昼だけ、といった削り方をする）

   さらに供給側の制約
        └ 配達する人が確保できない
              ＝ 密度の薄いエリアから順に撤退する
```

矢野経済研究所は在宅配食について、原材料価格の高騰による値上げで
**成長が鈍化**したと整理している。一方で**冷凍宅配食は成長**しており、
「冷凍にすれば運営効率が上がり配送コストも下げられる」（供給側）、
「まとめ買いしてストックできる」（需要側）という双方の利点から新規参入も増えている。
**配食市場の伸びは、手渡しの日替わり弁当から冷凍のEC定期便へ移っている**というのが実像に近い
（→ [②宅配弁当と配食サービス](02_宅配弁当と配食サービス.md)）。

## 6. 2027年4月の飲食料品1% ― 弁当店にとっては「イートイン」が争点

2026年9月15日の閣議決定で、2027年4月1日から2年間、
飲食料品の消費税率を8%から1%に引き下げる方針が示された（実施には法改正が必要）。
制度の全体像は [冷凍食品・惣菜 ④](../06_冷凍食品・惣菜/04_直近トピック_2026.md) 第7章にあるので、
ここでは**弁当店に固有の論点**だけを挙げる。

- **持ち帰り弁当は原則「対象」になる可能性が高い**。軽減税率と同じ線引きなら、
  テイクアウトは飲食料品、店内飲食は外食という区分になる
- **弁当チェーンにとっては追い風だが、外食部門を持つ会社は分断される**。
  プレナスのように「ほっともっと（持ち帰り）」と「やよい軒（店内飲食）」を併営する会社は、
  **同じ会社の中で税率が7ポイント違う事業を並べる**ことになる
- **イートインスペースの扱いが重い**。イートインを備える弁当店・惣菜店では、
  客に「店内で食べるか」を確認する運用が再び必要になる。2019年の軽減税率導入時と同様に、
  レジ改修とオペレーションの負担が小規模店ほど重くのしかかる
- **価格表示をどうするか**が実務の焦点になる。税率が変わる商品と変わらない商品を
  同じメニューに並べるため、税込表示の作り替えが必要になる

2026年9月時点では大綱の閣議決定段階であり、対象品目の細部は法案審議待ちである。
最新は財務省・国税庁の公表で確認すること。

## 7. 全体の構図

2026年9月時点で、中食・弁当の事業者側は次のような姿にある。

1. **市場は伸び、事業者は淘汰されている**。中食市場は過去最高を更新し続けているが、
   弁当店の倒産は2年連続で過去最多。需要は消えていないが、
   売り手がスーパー・コンビニ・ドラッグストア・大手チェーンに入れ替わっている
2. **客数を単価で埋める構図が限界に近い**。ほっともっとの既存店客数は94.2%。
   業界統計でも持ち帰り米飯は客数96.0%。値上げは通っているが、**来店の回数が減っている**
3. **米価が下がっても店頭価格は下がらない**。包装資材・人件費・物流費が上がり続けるからだ。
   結果として内食との価格差が再び開き、節約志向の深い層は家庭の台所へ戻る
4. **勝ち筋は「個人客の外」にある**。法人・団体の予約弁当（値上げが通る、廃棄ゼロ、ピーク外調理）と、
   定期契約の配食（週単位でまとまる、ロスがない）。プレナスが団体需要の営業体制を
   強化しているのは偶然ではない
5. **配食は「手渡し」から「冷凍便」へ重心が移りつつある**。市場金額は横ばい予測だが、
   その中身は日替わり手渡しからEC定期便へ置き換わっている。
   置き換わると同時に、配食が担っていた見守り機能は失われる

## 用語メモ

| 用語                                       | 意味                                                                                            |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------- |
| **既存店客数**                             | 1年以上営業している店の来店客数。値上げの影響を最も素直に映す指標                               |
| **相対取引価格（あいたいとりひきかかく）** | JA など集荷業者と卸売業者の間で取引される米の価格。農林水産省が月次で公表する                   |
| **軽減税率**                               | 2019年10月導入。飲食料品と新聞を8%、それ以外を10%とする制度。中食と外食の線引きはここで作られた |
| **イートインスペース**                     | 惣菜店・コンビニに併設された飲食スペース。ここで食べると「外食」扱いになり税率が変わる          |
| **増収減益**                               | 売上は増えたのに利益が減ること。コスト上昇を価格転嫁しきれていないときに起きる                  |
| **淘汰（とうた）**                         | 需要はあるが、コストに耐えられない事業者から退出していくこと。市場縮小とは区別する              |
