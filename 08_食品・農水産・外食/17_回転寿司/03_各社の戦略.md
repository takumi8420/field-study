# ③ 各社の戦略 — 勝敗を分けたのは国内ではなく海外だった

このノートで分かること：スシロー・くら寿司・はま寿司・かっぱ寿司の4社が、
同じ「回転寿司」という業態で、なぜこれほど業績に差がついたのか。
100円均一からの脱却、価格帯の多層化、海外展開、迷惑行為対策という
4つの論点を各社がどう処理したか。

> 結論：2020年代後半の回転寿司の勝敗は、**国内の商品力ではなく「海外をやれたかどうか」**で
> ほぼ説明できる。国内市場は人口減と米価・魚価の上昇で利益が出にくくなっており、
> 大手の利益成長はアジアと北米から来ている。
> スシローは海外事業だけで**9か月に78店を出店**（2026年9月期第3四半期）、
> くら寿司は国内が減収減益で北米は赤字、はま寿司は海外込みで**年間127店増**、
> かっぱ寿司は海外を持たず**四半期営業赤字**に転落した。
> **国内だけで戦っている会社から順に苦しくなっている**というのが、この業界の現在地である。

## 2. スシロー（FOOD & LIFE COMPANIES） — 国内で稼ぎ、海外で伸ばす

**基本の型**：国内は成熟事業として安定運用し、成長資金を海外に集中投下する。

| 項目             | 2025年9月期                                                          | 2026年9月期 第3四半期累計                                               |
| ---------------- | -------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| 国内スシロー事業 | 売上2,659.03億円（+11.6%）／利益259.94億円（+21.7%）／659店          | 売上2,169.32億円（+10.7%）／利益171.68億円（+12.4%）／668店             |
| 海外スシロー事業 | 売上1,314.20億円（**+42.6%**）／利益203.40億円（**+105.1%**）／234店 | 売上1,506.38億円（**+61.8%**）／利益203.68億円（**+83.2%**）／**310店** |

**海外の店舗数が9か月で227→304店（スシローブランド）へ、78店の純増**。
一方、国内スシローの店舗数は667→668と横ばいである。
**出店余力を完全に海外へ振り向けている**ことが数字に表れている。

- **展開エリア**：韓国・台湾・香港・シンガポール・タイ・中国大陸・インドネシアの7エリア。
  中国大陸は2026年4月に**100店舗を達成**（同社発表）。広州・成都・紹興・温州など内陸・地方都市へも進出
- **海外の方が利益率が高い**。2025年9月期のセグメント利益率は
  国内スシロー9.8%に対し海外スシロー15.5%（いずれもロイヤリティ支払前）。
  日本の「安くて品質が高い回転寿司」は、**現地では中〜高価格帯の日本食として売れる**
- **国内は小型店で出店余地を広げる**。郊外型より一回り小さい店舗を駅前・駅近に出す
  （2025年の阪神野田駅店、中野坂上店など）。席数は郊外型の半分〜3分の2だが、
  メニュー数は同じ。**大箱ロードサイドに適地が残っていない**という現実への対応
- **デジロー**（レーンに寿司を流さず映像から注文する仕組み）は2025年9月末で123店舗
- **事業の整理も進む**。2026年8月7日、**子会社・株式会社京樽の全株式譲渡を決議**。
  第4四半期から京樽事業は非継続事業に分類される。回転寿司と杉玉に資源を集中する形

> ポイント：F&LCの戦略は単純で、**「稼げる場所に店を置く」**。
> 国内の既存店を磨きつつ、新規投資は海外。2026年9月期は通期営業利益505億円の予想まで
> 上方修正された（2026年8月7日発表、期初予想から100億円の上積み）。

## 3. くら寿司 — 技術で差別化するが、国内が伸びない

**基本の型**：全店直営、自社開発の設備と「四大添加物不使用」を掲げる品質訴求。

| セグメント | 2025年10月期                                               | 2026年10月期 第3四半期累計                                 |
| ---------- | ---------------------------------------------------------- | ---------------------------------------------------------- |
| 日本       | 売上1,764.07億円／経常50.30億円（▲23.4%）                  | 売上1,306.34億円（**▲1.2%**）／経常33.94億円（**▲40.8%**） |
| 北米       | 売上421.03億円（+17.4%）／経常1.14億円（前期は▲10.41億円） | 売上372.04億円（+22.2%）／**経常損失6.45億円**             |
| アジア     | 売上265.98億円（+5.9%）／経常11.59億円（+26.6%）           | 売上218.45億円（+15.1%）／経常7.92億円（+42.0%）           |

- **国内が減収減益**。2026年10月期第3四半期累計で日本事業は売上▲1.2%・経常▲40.8%。
  売上の落ち込みはわずかでも、固定費が重いので利益は大きく削れる
  （→ [① 100円寿司の工学](01_100円寿司の工学.md) 損益分岐点の客数）
- **北米（Kura Sushi USA）が黒字定着しない**。2025年10月期にいったん黒字化したものの、
  2026年10月期第3四半期累計は関税による原材料価格上昇もあり経常損失に戻った。
  それでも出店は続け、店舗数は79→91店へ。**先行投資段階が長い**
- **アジア（台湾・中国・タイ）は堅調**。2026年7月にタイ法人を設立
- **設備の内製が特徴**。皿の自動計数、卓上の皿回収口と水流搬送、スマホ注文など、
  「スマートくら寿司」として体系化している
- **回転レーンを維持する数少ない大手**。2023年3月に業界初の「新AIカメラシステム」を全店導入し、
  レーン上の抗菌寿司カバーの不審な開閉を検知して本部にアラートを出す仕組みを作った。
  同社は**「今後も寿司を流すことにこだわる」**という立場を公にしている

> ポイント：くら寿司の課題は商品ではなく**利益率**である。
> 営業利益率2.2%（2025年10月期）は、同業のF&LC 8.4%と比べて著しく低い。
> 全店直営で減価償却が重く、国内の客数が伸びないと構造的に苦しい。
> 北米が黒字で回り始めるかどうかが最大の分岐点になる。

## 4. はま寿司（ゼンショーHD） — 出店スピードで押し切る

**基本の型**：グループ全体の調達力・物流網に乗り、ひたすら店を増やす。

- 2026年3月期は**年間132店を出店・5店を退店し、店舗数は127店の純増**で862店（国内664／海外198）。
  スシローの国内659店を国内店舗数で追い抜く位置まで来ている
- 売上+28.9%、営業利益+25.4%と、**2期連続で20%超の増収**。
  伸びの主因は既存店ではなく**出店そのもの**である
- 親会社[ゼンショーHD](../14_ファストフード/03_各社の戦略.md)は、すき家・はま寿司・ココス等を束ね、
  食材調達・工場・物流を**グループ共通のインフラ**として持つ。
  はま寿司はこのインフラの上に乗ることで、単独チェーンより低いコストで出店できる
- ゼンショーHDは海外に大規模な出店計画を掲げており、はま寿司も中国で急拡大していると報じられる
- **価格では最後まで粘った側**。最低価格110円を長く維持し、
  2026年5月26日から**まぐろなど5商品を20〜40円引き上げ**（まぐろ 110円→132円）。
  同社にとって**まぐろの値上げは初めて**で、サーモンは据え置いた

> ポイント：はま寿司の強さは**単体の商品力ではなくグループの体力**である。
> すき家で確立した調達・物流・出店開発の仕組みを、そのまま寿司に流用している。
> 裏返すと、すき家の業績（値下げ・値上げ）に振られるグループ全体の資源配分が、
> はま寿司の出店ペースを左右する。

## 5. かっぱ寿司（カッパ・クリエイト） — 一人負けの構造

かつて業界首位だった。2026年時点では4大チェーンの最下位に沈んでいる。

```
【かっぱ寿司に起きたこと（報道・開示ベース）】

  2024年12月 ──┐
               │  既存店売上高・客数がともに前年割れ
  2025年11月 ──┘  12か月連続（2025年11月は売上95%、客数93%）

  2026年3月期    売上731.93億円（±0.0%）、営業利益5.32億円（▲62.9%）
                 最終損益 ▲3.94億円

  2027年3月期1Q  売上177.51億円（▲2.4%）、営業損失 ▲7.07億円
  （2026年4〜6月） 4年ぶりの第1四半期営業赤字
```

不振の理由として報じられているものを整理すると、**単独ではなく重なって効いている**。

| 要因               | 中身                                                                                                                                      |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------- |
| **規模の差**       | 店舗数・売上が上位3社の3分の1以下。[② 水産調達](02_水産調達という本業.md)で見たとおり**買い付け力は店数の関数**なので、原価で最初から不利 |
| **海外がない**     | 成長市場を持たない。国内の客数減がそのまま業績になる                                                                                      |
| **価格政策の迷走** | 「平日90円」などの集客施策を打つ一方で値上げも行い、値上げは「失敗」と経営側が認めたと報じられる                                          |
| **原材料高**       | 売上総利益率の低下を会社側が赤字要因に挙げている                                                                                          |
| **節約志向**       | 物価上昇局面で、外食の来店頻度そのものが落ちた                                                                                            |

> ポイント：**回転寿司は規模がそのまま原価率になる業態**なので、
> いったん規模で劣後すると、商品や販促では巻き返しにくい。
> コラボ企画や価格施策を打っても、**原価の土台が違う相手とは同じ土俵に立てない**。
> かっぱ寿司の苦戦は経営判断の問題である以上に、この業態の構造が生む帰結でもある。

## 7. 価格帯の多層化 — 「100円均一」の終わり方

2022年前後に、主要チェーンから100円皿は実質的に消えた。ただし各社の抜け方は違う。

| チェーン       | 最低価格帯（2026年時点） | 抜け方                                                                                                                                             |
| -------------- | ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **スシロー**   | 120円前後                | 2022年に100円均一を廃止し、**多段階価格制**へ。2026年7月22日から「厳選まぐろ赤身」を120円→150円に改定する一方、サーモン・いか・えびは120円据え置き |
| **くら寿司**   | 115円〜                  | 115円・150円・180円など。「フレキシブルな商品設計」で原価率を調整し、過度な値下げを避ける方針を明示                                                |
| **はま寿司**   | 110円〜                  | **最低110円を最後まで維持**。2026年5月にまぐろを132円へ（初のまぐろ値上げ）                                                                        |
| **かっぱ寿司** | 110円〜                  | 平日90円などの集客施策と値上げを併用し、方針が定まりにくかった                                                                                     |

```
【価格帯の多層化とは何をしたのか】

  〔100円均一時代〕            〔多層化後〕
   ┌──────────┐              ┌──────────┐ 300円〜（うに、大トロ、豪華盛り）
   │  全部100円  │              ├──────────┤ 180〜250円（希少ネタ、3貫盛り）
   │            │      ──▶    ├──────────┤ 150円（まぐろ赤身、えんがわ等）
   └──────────┘              ├──────────┤ 110〜120円（サーモン、えび、いか）
                                └──────────┘ ＋サイド・デザート（原価率10〜30%）

   客単価 約1,000円                客単価 約1,300円
   「安い」を価格で示す            「安い」は最低価格帯の存在で示し、
                                   実際の支払いは上位皿とサイドで作る
```

> ポイント：**多層化は値上げを隠す手法ではなく、値上げを「選べる」ようにする手法**である。
> 全皿を一律に上げれば客離れを招くが、上位の皿を足すだけなら
> 「安く食べたい人は安く食べられる」状態が維持される。
> [① 原価ミックス](01_100円寿司の工学.md) の考え方を、価格表の側から実装したものと言ってよい。

## 8. 海外展開の3つの型

| 型                     | 採る企業                 | 中身                                               | メリットとリスク                                       |
| ---------------------- | ------------------------ | -------------------------------------------------- | ------------------------------------------------------ |
| **直営で密度を作る**   | スシロー、くら寿司       | 自社で出店し、品質・人材育成まで管理する           | 利益を丸ごと取れるが、資本と撤退リスクを自社で負う     |
| **FCで面を取る**       | 元気寿司                 | 現地パートナーに任せ、ロイヤリティと食材供給で稼ぐ | 資本を使わず速く広がるが、1店あたりの利益は薄い        |
| **グループ網に乗せる** | はま寿司（ゼンショーHD） | グループの海外拠点・調達網を使う                   | 単独より低コストで出られるが、グループの方針に従属する |

海外が効く理由は、単に市場が大きいからではない。

- **現地では価格帯が上がる**。日本で120円の皿が、現地通貨で日本円換算200〜300円相当で売れる。
  同じ原価・同じオペレーションで**粗利率が上がる**
- **日本食というブランドが効く**。日本の回転寿司は「安い外食」ではなく
  「手頃な日本食レストラン」として位置づけられる
- **人件費と家賃の水準が違う**。エリアによっては日本より低コストで運営できる

一方のリスクも明確である。国ごとの規制、現地の食材調達、為替、
そして**日本の外食チェーンが海外で減損を出すことは珍しくない**
（→ [ファストフード ③ 各社の戦略](../14_ファストフード/03_各社の戦略.md)）。
くら寿司の北米が長く赤字だったのは、この難しさの実例である。

## 9. テイクアウト・デリバリーと、都心・小型店

**席数という上限を外す**手段は、回転寿司でも共通のテーマである。

| チャネル           | 中身                                         | 経済的な意味                                                                                                                      |
| ------------------ | -------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| **テイクアウト**   | 店頭受け取り、持ち帰り専門店                 | 手数料がかからず粗利がそのまま残る。**最も利益率が高い**。スシローは海外でもテイクアウト専門店を展開（2026年5月に台湾初のTOGO店） |
| **デリバリー**     | 自社配達＋プラットフォーム                   | プラットフォーム手数料は注文金額の30%前後とされ、**原価率40%超の回転寿司とは相性が悪い**。専用メニュー・価格で対応する            |
| **都心型・小型店** | 郊外型の半分〜3分の2の席数で駅前・駅近に出す | **大箱ロードサイドの適地が枯れた**ことへの対応。家賃は上がるが、坪売上で取り返す                                                  |

> ポイント：回転寿司はもともと**原価率が高い＝手数料を払う余地が小さい**業態である。
> だからデリバリー依存度は[ファストフード](../14_ファストフード/02_ファストフード特有の仕組み.md)ほど高くならず、
> テイクアウトと小型店による**席数の拡張**の方が主戦場になる。

## 10. 迷惑行為事件が業界に強いた対策コスト

2023年1月、レーン上の寿司や卓上の醤油差しに対する迷惑行為の動画がSNSで拡散し、
回転寿司業界全体が**「共用の食品に不特定多数が触れる」**という業態そのものの弱点を突かれた。

```
【事件が業界に強いたもの】

  信頼の毀損 ──▶ 客数の一時的な落ち込み、株価下落
        │
        ├─▶ 設備投資     抗菌寿司カバーの全面展開、AIカメラ、卓上備品の個別提供
        ├─▶ 運用の変更   レーンに流す量の削減／注文品のみ提供／レーン廃止
        ├─▶ 人の配置     フロアの目視確認、本部の監視体制
        └─▶ 法的対応     刑事告訴・損害賠償請求という方針の明示（抑止のため）
```

| 対応                               | 採った企業                                 | コストの性格                                         |
| ---------------------------------- | ------------------------------------------ | ---------------------------------------------------- |
| **抗菌寿司カバー＋AIカメラ**       | くら寿司（2023年3月2日、全店導入。業界初） | 設備投資。回転レーンを**残す**ための投資             |
| **注文品のみレーン提供／デジロー** | スシロー                                   | 設備投資＋オペレーション変更。レーンを**やめる**方向 |
| **回転レーン廃止**                 | すし銚子丸（方針と報じられる）             | 設備を撤去し、業態そのものを組み替える               |
| **卓上備品の個別提供**             | 各社                                       | 継続的なコスト増（個包装の醤油・ガリなど）           |

この事件が業界に残したものは、費用だけではない。
**「回転させること」が本当に必要なのかという問いを各社に突きつけた**という点が大きい。
注文レーン化・デジロー化は廃棄ロス削減という経済合理性とも合致するため、
**事件は「もともと進んでいた変化を一気に加速させた」**と整理できる。
一方でくら寿司のように「回す文化を残す」ことに賭ける選択もあり、
**ここが2026年時点でも各社の差別化点として残っている**。

| **既存店売上高前年比**       | 一定期間以上営業している店だけの前年同月比。売上・客数・客単価の3点で読む → [外食1店舗の経済](../14_ファストフード/01_外食1店舗の経済.md) |
| **減損**                     | 投資の回収が見込めなくなった資産の帳簿価額を引き下げる会計処理。海外出店で出やすい                                                        |
