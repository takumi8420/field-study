# ④ 直近トピック（2026年9月時点）

報道・各社開示ベースの整理。数値は必ず一次情報（決算短信・決算説明資料）で裏を取ること。
確定した開示値と、報道・推計は本文中で区別して書いている。

## 0. まず全体像

2026年の回転寿司業界は、**「海外で稼ぐ会社」と「国内だけの会社」の差が決算の形で表面化した年**である。

```
【2026年の回転寿司：3本の線が同時に走っている】

  ①成長の線   スシロー海外が9か月で78店純増、中国大陸100店達成
              はま寿司が年間127店純増。成長は完全に海外・出店主導
                    ▲
  ②コストの線  米価・魚価・人件費・関税が同時に上昇
              → 2026年5〜7月に「まぐろだけ値上げ」という第2波
                    ▲
  ③淘汰の線   くら寿司の国内が減収減益（営業益▲45.2%）
              かっぱ寿司が4年ぶり四半期営業赤字
              → 規模と海外を持たない側から順に耐えられなくなる
```

## 1. スシロー（F&LC）が海外主導で最高益圏、京樽を売却（2026年8月）

2026年8月7日発表の2026年9月期第3四半期（2025年10月〜2026年6月）は、
**売上収益3,904.21億円（前年同期比+24.7%）、営業利益420.22億円（同+43.9%）**。
通期予想は売上5,050億円（+17.6%）、営業利益**505億円（+39.9%）**へ上方修正された
（期初予想から約100億円の上積み）。

| セグメント       | 売上収益         | 前年同期比 | セグメント利益 | 前年同期比 |
| ---------------- | ---------------- | ---------- | -------------- | ---------- |
| 国内スシロー     | 2,169.32億円     | +10.7%     | 171.68億円     | +12.4%     |
| **海外スシロー** | **1,506.38億円** | **+61.8%** | **203.68億円** | **+83.2%** |
| 京樽             | 164.29億円       | ▲8.1%      | 4.41億円       | +137.9%    |
| 国内杉玉         | 65.74億円        | +8.9%      | 2.41億円       | +717.5%    |

**海外の利益が国内を上回った**のがこの四半期の最大のニュースである。
店舗数でも海外スシローは227店→304店と9か月で78店の純増、国内スシローは667店→668店で横ばい。
国内外合計は1,198店→1,263店。

同日、**子会社・株式会社京樽の全株式譲渡を決議**。第4四半期から京樽事業は非継続事業に分類される。
テイクアウト寿司という別業態を手放し、回転寿司（スシロー）と居酒屋（杉玉）に資源を集中する形になる。

なお同社は**2026年7月1日付で1株を2株に分割**している。株価・EPSの前年比較時は注意が要る。

## 2. くら寿司は国内が失速、営業利益が半減近い（2026年9月）

2026年9月11日発表の2026年10月期第3四半期（2025年11月〜2026年7月）は、
売上高1,896.84億円（+4.4%）に対し、**営業利益28.45億円（▲45.2%）**、
経常利益34.69億円（▲37.7%）、四半期純利益20.30億円（▲41.3%）。

| セグメント | 売上高       | 前年同期比 | 経常利益                                       |
| ---------- | ------------ | ---------- | ---------------------------------------------- |
| **日本**   | 1,306.34億円 | **▲1.2%**  | 33.94億円（**▲40.8%**）                        |
| 北米       | 372.04億円   | +22.2%     | **▲6.45億円**（経常損失。前年同期も▲5.96億円） |
| アジア     | 218.45億円   | +15.1%     | 7.92億円（+42.0%）                             |

読みどころは2つ。

- **売上が1.2%落ちただけで、利益が40.8%落ちた**。回転寿司は減価償却と家賃という固定費が厚く、
  損益分岐点の客数が高いため、わずかな客数減が利益を大きく削る
  （→ [① 100円寿司の工学](01_100円寿司の工学.md)）
- **北米（Kura Sushi USA）が黒字に定着しない**。2025年10月期に経常利益1.14億円といったん
  黒字化したが、**関税による原材料価格の上昇**もあり再び経常損失。
  それでも店舗数は79→91店へ拡大し、先行投資が続いている

店舗数は全て直営で712店（うち米国91、アジア63）。2026年7月にはタイ法人を設立している。

## 3. 値上げの第2波 — 「まぐろだけ上げる」という選択（2026年5〜7月）

2022年前後の「100円均一の廃止」が第1波だとすると、2026年は**ネタを選んで上げる第2波**だった。

| 時期              | 内容                                                                                                                              |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| **2026年5月26日** | **はま寿司**が、まぐろなど5商品を20〜40円引き上げ。まぐろ 110円→132円。**同社にとってまぐろの値上げは初めて**。サーモンは据え置き |
| **2026年7月22日** | **スシロー**が価格改定。「厳選まぐろ赤身」120円→150円など。**サーモン・いか・えびは120円据え置き**                                |

両社に共通するのが「**看板ネタ（サーモン）は据え置き、まぐろを上げる**」という判断である。
サーモンは注文数が最も多く、値上げが客数に直結する。まぐろは
「高いネタ」という認識が消費者側にもあるため、相対的に受け入れられやすい。

値上げ理由として各社・報道が挙げるのは次の4つで、**魚だけではない**点が重要である。

| 要因                             | 中身                                                                                                           |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| **国産米の仕入価格高騰**         | 2024〜2025年に国内の米価が急騰。業務用米も大幅に上昇したと報じられる。シャリは全皿共通コストなので逃げ場がない |
| **円安による輸入魚のコスト上昇** | サーモン・えびは輸入養殖依存。為替がそのまま原価になる（→ [② 水産調達という本業](02_水産調達という本業.md)）   |
| **燃料費**                       | 遠洋漁業・超低温冷凍船の運航費                                                                                 |
| **人件費・光熱費**               | 最低賃金の上昇が続く（→ [ファストフード ④ 人手不足と省力化](../14_ファストフード/04_人手不足と省力化.md)）     |

**100円皿は2026年時点で主要チェーンから消えている**。最低価格帯は110〜120円台で、
10皿食べたときの支払いは2020年の1,100円（税込）から1,300円前後へ上がっている
（各社価格表および報道ベースの整理）。

## 4. かっぱ寿司が4年ぶりの四半期営業赤字（2026年4〜6月）

カッパ・クリエイト（コロワイド傘下）の2027年3月期第1四半期は、
**売上高177.51億円（▲2.4%）、営業損失7.07億円、最終損失7.65億円**。
第1四半期としては4年ぶりの営業赤字と報じられる。

前期（2026年3月期）も売上731.93億円（±0.0%）、営業利益5.32億円（▲62.9%）、
最終損益▲3.94億円で、既存店は**2024年12月から12か月連続で売上高・客数がともに前年割れ**
（2025年11月は売上95%、客数93%）と報じられている。

会社側は赤字要因として**原材料価格高騰による売上総利益率の低下**を挙げ、
値上げについては「失敗」と経営側が認めたとも報じられる。

> 構造的に見ると、かっぱ寿司は**規模（＝買い付け力）でも海外でも上位3社に劣後**している。
> 回転寿司は店数がそのまま原価率になる業態なので、
> コラボ企画や価格施策では原価の差を埋めきれない（→ [③ 各社の戦略](03_各社の戦略.md)）。

| 2026年8月         | スシローが青島市に1号店を開業、山東省で出店を拡大（ジェトロ ビジネス短信）                                                                    |
| 通期              | ゼンショーHDの**はま寿司も中国で急拡大**していると報じられる。ゼンショーHDはグループとして海外の大規模な出店計画を掲げる                      |

F&LCは2026年9月期に海外事業で**300〜320店舗体制、売上構成比35%**を目標としていたが、
第3四半期末ですでに海外310店（スシローブランド304店）に到達している。

中国での位置づけは「安い外食」ではなく**「コストパフォーマンスの良い日本食レストラン」**で、
日本より高い価格帯で提供できる。これが海外セグメントの高い利益率
（2025年9月期の海外スシロー事業のセグメント利益率15.5%、国内9.8%、いずれもロイヤリティ支払前）
の源泉になっている。

一方、中国事業は**政治・外交情勢の影響を受ける**という構造的リスクを抱える。
日本産水産物の輸入規制が2023年以降に繰り返されている点（→ [水産 ④ 直近トピック](../11_水産/04_直近トピック_2026.md)）は、
調達面でも出店面でも無視できない。

## 7. レーンをめぐる分岐が固定化した

2023年1月の迷惑行為事件から3年が経ち、各社の立場は明確に分かれたまま定着している。

```
【回転レーンをどうするか：3つの答え】

  A「流さない」     スシロー（F&LC）
     注文品のみレーンで提供。大型ディスプレイの映像から注文する「デジロー」
     → 2025年9月末で123店舗。会社は「注文なしにすしが流れる形はなくなる」と説明

  B「流し続ける」   くら寿司
     抗菌寿司カバー＋AIカメラで不審な開閉を検知し本部にアラート（2023年3月、全店導入）
     → 「今後も寿司を流すことにこだわる」と公言。回転寿司文化の存続を掲げる

  C「やめる」       すし銚子丸
     回転レーンの廃止方針が報じられる
```

この分岐は倫理や文化の問題に見えるが、**実態は設備投資の判断**である。
レーンをやめれば廃棄ロスがゼロに近づき衛生リスクも減るが、
「見て選ぶ楽しさ」という来店理由を失う。残すならカバーと監視に投資が要る。
**どちらを選んでも費用が発生する**ところがこの論点の本質で、
2026年時点では「流さない側」が主流になりつつあるが、決着はついていない。

## 8. 全体の構図（まとめ）

- **利益の源泉が国内から海外へ移った**。スシローの海外セグメント利益は2026年9月期第3四半期累計で
  国内を上回り、店舗純増もほぼ全部が海外。はま寿司も年間127店増のうち相当数が海外。
  **国内市場は人口減と原価高で「守る場所」になった**
- **原価の上昇が魚だけでなく米・人件費・関税に広がった**。だから値上げは
  「全皿一律」ではなく「ネタを選んで上げる」形になり、サーモンなど看板ネタは据え置かれた
- **規模の差が決算の差にそのまま出た**。買い付け力が店数の関数である以上、
  上位3社と4位以下の原価の差は埋まらない。かっぱ寿司の四半期営業赤字はその帰結
- **くら寿司の国内失速は業界全体への警告**でもある。売上▲1.2%で利益▲40.8%という感応度の高さは、
  回転寿司という業態が客数にきわめて脆いことを示している
- **レーンの是非は決着していない**。ただし「流さない」方向は衛生・廃棄・品質の3点で
  経済合理性を持つため、時間とともに広がる可能性が高い

## 9. 用語メモ

| 用語                         | 意味                                                                                                             |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| **非継続事業**               | 売却・廃止が決まった事業を継続事業と分けて表示する会計上の区分。F&LCは京樽事業を2026年9月期第4四半期から分類予定 |
| **上方修正**                 | 期初に出した業績予想を期中に引き上げること。F&LCは2026年8月7日に通期営業利益を505億円へ修正                      |
| **株式分割**                 | 1株を複数株に分けること。F&LCは2026年7月1日付で1株→2株。1株当たり指標の前年比較には調整が要る                    |
| **セグメント利益**           | 事業単位の利益。F&LCはロイヤリティ支払前、くら寿司は経常利益ベースと定義が異なる                                 |
| **損益分岐点の客数**         | 固定費を賄うのに必要な客数。回転寿司は減価償却と家賃が厚く、この水準が高い → [①](01_100円寿司の工学.md)          |
| **デジロー**                 | スシローの、レーンに寿司を流さず映像から注文する仕組み                                                           |
| **抗菌寿司カバー／AIカメラ** | くら寿司がレーンを残すために導入した衛生・監視の組み合わせ                                                       |
| **フレキシブルな商品設計**   | 仕入値の変動に応じて皿の構成・貫数・シャリ量を組み替え、平均原価率を保つこと（くら寿司の表現）                   |
