回転寿司とは「原価率を捨てた外食」である。
外食の原価率が28〜32%であるのに対し、回転寿司は40〜43%。
それでも成立するのは、①客単価が高く1人あたりの粗利「額」はむしろ厚い、
②レーン・ロボット・タッチパネルで人件費率を外食標準より低く抑えている、
③郊外の大箱で年商4億円級を稼ぎ、家賃比率を4〜7%まで下げている——この3点による。

そして原価の4割超が水産物であるため、この業界は実質的に水産商社でもある。
産地の一船買い、契約養殖、海外の調達拠点まで自前で持ち、
買い付け力がそのまま原価率になり、原価率がそのまま価格競争力になる。
だから店数が多い会社ほど安く仕入れられ、上位と下位の差は年々開く。

2026年時点で最も重要な事実は、利益の源泉が国内から海外へ移ったこと。
スシローの海外セグメント利益は2026年9月期第3四半期累計で国内を上回り、
店舗の純増はほぼ全部が海外。一方で国内だけで戦うチェーンは赤字に沈んでいる。

1. 業界の定義・範囲

回転寿司とは、寿司を定価の「皿」単位で提供し、コンベア（レーン）を用いて
注文・配膳・会計の一部を機械化した外食業態である。
1958年に大阪で第1号店が開業したとされ、統計上は日本フードサービス協会の業態分類で
「ファーストフード」のうち「持ち帰り米飯／回転寿司」に含まれる。

隣接業態との境界は、価格の単位・職人の有無・調理場所で引くと分かりやすい。

業態 価格の単位 職人 ネタの加工場所 客単価の目安
回転寿司（大手チェーン）皿（110〜300円）不要（シャリロボット＋規格カット）工場・産地1,200〜1,800円
準大手・地域回転寿司（銚子丸、がってん寿司など）皿（150〜500円）一部で店内調理店内加工の比率が高い2,000〜3,000円
「回らない寿司」チェーン（寿司居酒屋、立ち食い寿司）品・コース半職人店内中心3,000〜5,000円
個人経営の寿司店おまかせ・時価職人店内10,000円〜
中食・弁当の持ち帰り寿司（京樽、スーパーの握り）パック不要工場・バックヤード800〜2,000円
ファストフード単品・セット不要工場＋店内500〜1,100円

とくに押さえるべき境界は2つ。

  • 「回っているか」は定義の本質ではない。スシローの「デジロー」のようにレーンに
    寿司を流さない店も回転寿司として扱われる。本質は皿単位の定価制と、機械化されたオペレーション
  • 持ち帰り寿司は別業態。調理が店外で完結し、席を持たない。統計上は
    中食に近い。F&LCが2026年8月に京樽の売却を決めたのは、
    この2業態が別の商売であることの裏返しでもある

  • 国内市場は「金額は伸びるが皿数は伸びない」。8,000億円台への拡大は

  • 上位集中が進む。スシロー・はま寿司・くら寿司の3社で市場の相当部分を占め、
    規模が原価率に直結する構造のため、下位ほど苦しくなる（→ ③）
  • 成長の主戦場は海外。2026年9月期第3四半期のF&LC海外スシロー事業は前年同期比+61.8%。
    中国大陸・台湾・香港・東南アジア・北米で、日本より高い価格帯で売れる

本部の収益源は3つ。①店舗売上（大手は直営中心。くら寿司は全店直営）、
②買い付け・加工の内製による原価差、③海外展開によるセグメント利益。
ファストフードと違い、FC（フランチャイズ）比率は低い。
高額な設備投資とネタの品質管理を加盟店に委ねにくいためで、
FCを使うのは海外展開（元気寿司の型）や派生業態が中心になる。

6. 競争要因（KSF）と参入障壁

KSF なぜ効くか
買い付け力（＝店数）一船買い・産地直送は「まとめて売り切れる規模」があって初めて成立する。店数がそのまま原価率になる
加工・冷凍のインフラ規格カットで原価を1円単位に固定し、超低温冷凍で漁期と需要期のズレを吸収する
自動化の完成度シャリロボット・注文レーン・皿の自動計数・皿回収。人件費率を下げた分だけ原価率を払える
立地（郊外の大箱）家賃比率4〜7%を成立させる用地。良い区画は有限で、先に押さえた側が強い
集客力（客数）固定費が厚く損益分岐点の客数が高いため、客数を維持できるかが利益を決める。IPコラボと季節フェアが主戦場
海外での展開力国内が成熟した以上、成長と高利益率はここにしかない

参入障壁は外食のなかでもとくに高い。

  1. 設備投資。1店2億〜3億円に加え、加工場・冷凍物流・システムが要る
  2. 規模の壁。数十店では買い付け力が効かず、原価率で上位に勝てない。
    「小さく始めて大きくする」経路が事実上塞がっている
  3. 調達網。産地との関係、海外の加工場、輸入のロットは一朝一夕に作れない
  4. オペレーションと設備のノウハウ。レーン・ロボット・廃棄制御は各社の蓄積

ポイント：かっぱ寿司がかつて首位から4位へ落ちたのは、一度スケールの差がつくと
原価で追いつけなくなるというこの業界の性質を示している。
商品や販促で挽回できる幅は、原価の土台の差より小さい。

7. 規制・法制度

分野 内容
食品衛生法飲食店営業許可（保健所）。2021年6月からHACCPに沿った衛生管理が全事業者に義務化。生鮮魚介を大量に扱うため温度管理の要求が重い
食品表示法／景品表示法原材料・アレルゲン・原産地表示。魚種の表示は特に厳しく見られる（ネタの名称と実際の魚種が一致しているか）
水産流通適正化法（2022年12月施行）IUU（違法・無報告・無規制）漁業対策。特定魚種に漁獲番号の伝達・記録を義務化。仕入先のトレーサビリティ整備が必要になった
漁業法／TAC制度魚種ごとの漁獲上限。枠が縮めば、その魚はメニューから消える（→ 水産 ①）
労働基準法／最低賃金法2025年度の最低賃金は全国加重平均1,121円（+66円）。人件費率の上昇圧力
入管法（特定技能）特定技能1号「外食業」は分野別上限に到達し2026年4月13日から新規受入を当面停止（→ ファストフード ④）
支援策中小企業省力化投資補助金（配膳ロボット等）。ただし大手チェーンは対象外のことが多い
海外の規制出店先国ごとの食品衛生・輸入規制。日本産水産物の輸入規制（中国など）は調達にも出店にも影響する

    同時に京樽の全株式譲渡を決議（2026年8月7日）
  2. くら寿司の国内が失速。2026年10月期3Q累計は日本事業が売上▲1.2%・経常利益▲40.8%、
    連結営業利益▲45.2%。北米は関税による原材料高もあり経常損失に戻った
  3. 値上げの第2波は「ネタを選んで上げる」形。2026年5月にはま寿司がまぐろを110→132円
    （同社初のまぐろ値上げ）、7月にスシローが「厳選まぐろ赤身」を120→150円。
    サーモンは各社とも据え置き。理由は魚価だけでなく国産米の高騰
  4. かっぱ寿司が4年ぶりの四半期営業赤字（2026年4〜6月、営業損失7.07億円）。
    既存店は2024年12月から12か月連続で前年割れと報じられる
  5. 中国大陸が主戦場。スシローが2026年4月に中国本土100店舗を達成、
    はま寿司も急拡大。回転レーンの是非（スシローのデジロー／くら寿司のAIカメラ／
    銚子丸の廃止方針）は2026年時点でも分岐したまま
