# ② 水産調達という本業 — 寿司チェーンは実質的に水産商社である

このノートで分かること：回転寿司チェーンが、外食企業でありながら
なぜ「買い付け部隊」を自社で持ち、産地と海外に人を置いているのか。
サーモン・まぐろ・えびという3大ネタがどこから来ていて、
円安と魚価がどう店の値札に伝わるのか。

> 結論：回転寿司チェーンにとって、**調達は仕入業務ではなく事業そのもの**である。
> 原価の4割超が水産物で、しかもその大半が**輸入・養殖・相場もの**。
> だから大手は産地買い付け・一船買い・契約養殖・海外調達拠点まで内製し、
> **実質的に水産商社としての機能を抱え込んでいる**。
> 逆に言えば、**買い付け力がそのまま原価率になり、原価率がそのまま価格競争力になる**。
> 「100円」という看板は、この買い付け力が支えきれる範囲でしか維持できない。

水産業そのものの構造（漁業／養殖／加工の3層、TAC、魚粉、円安）は
[水産 README](../11_水産/README.md) と各ノートで扱っている。
本ノートはそれを**「回転寿司の原価表」の側から見直す**。

## 1. 回転寿司から見た水産業の地図

```
【1皿のネタが店に届くまで：4つの調達ルート】

 ①国内の天然もの（産地買い付け）
   産地市場のセリ ─▶ 自社バイヤー／産地仲買 ─▶ 自社・協力工場 ─▶ 店
   例：さんま、いわし、あじ、いか、たこ、ほたて
   特徴：量が読めない。豊漁なら安く大量に、不漁なら棚から消える

 ②国内の養殖もの（契約養殖）
   養殖業者と事前契約（数量・価格・出荷時期）─▶ 加工 ─▶ 店
   例：ぶり・はまち、まだい、くろまぐろ（一部）
   特徴：数量と価格が読める。その代わり餌代の高騰リスクを共有する

 ③輸入（養殖）
   ノルウェー／チリのサーモン、ベトナム・インドのえび、インドネシアのまぐろ
   ─▶ 商社または自社の海外調達拠点 ─▶ 冷凍で日本へ ─▶ 店
   特徴：世界市場の価格と為替を丸かぶりする。最大のボリュームゾーン

 ④輸入（天然・加工）
   南米・アフリカ沖のまぐろ、ロシア・北米のたらこ・いくら、中国での加工
   特徴：資源規制と国際情勢（禁輸・関税）に左右される
```

| ルート          | 数量の読みやすさ   | 価格の読みやすさ                               | 主なリスク                         |
| --------------- | ------------------ | ---------------------------------------------- | ---------------------------------- |
| ①国内天然       | **低い**（漁次第） | 低い（セリ相場）                               | 不漁、TAC（漁獲可能量）の縮小      |
| ②国内養殖       | 高い               | 中（契約で固定できるが、餌代で改定を迫られる） | 魚粉価格、高水温・赤潮による斃死   |
| ③輸入養殖       | 高い               | **低い**（国際相場＋為替）                     | 円安、世界需要の増加による買い負け |
| ④輸入天然・加工 | 中                 | 低い                                           | 資源規制、禁輸・関税、産地国の政策 |

> ポイント：**回転寿司の原価の主役は③の輸入養殖**である。
> サーモンもえびも、国内でどれだけ魚が獲れるかとは無関係に、
> **ノルウェーの生産量と円相場**で値段が決まる。
> つまり回転寿司の原価率は、日本の漁業の問題である以前に**国際商品市況の問題**である。

## 2. 3大ネタ — サーモン・まぐろ・えびの供給構造

回転寿司の注文ランキングは、各社とも上位が **サーモン・まぐろ・えび（＋はまち、いか）** で
固まっている。この3つの供給構造を押さえれば、原価の動きの8割は説明できる。

| ネタ         | 主な産地・形態                                                                                               | 価格を動かす変数                                                             | 回転寿司にとっての意味                                                            |
| ------------ | ------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| **サーモン** | ノルウェー・チリの**海面養殖**（トラウトサーモン含む）。ほぼ全量が輸入                                       | 世界のサーモン養殖生産量、**餌（魚粉・魚油）価格**、円相場、欧米・中国の需要 | **注文数1位の常連**。切り身で歩留まりがよく、通年で量を確保できる。回転寿司の主食 |
| **まぐろ**   | インド洋・大西洋・太平洋の天然（めばち・きはだ・びんちょう）＋地中海・国内の**蓄養／完全養殖**（くろまぐろ） | 国際的な漁獲枠（RFMO＝地域漁業管理機関の交渉）、超低温冷凍船の燃料費、円相場 | **看板ネタ**。値上げしにくく、値上げすると必ず報道される                          |
| **えび**     | ベトナム・インド・インドネシアの**養殖**（バナメイ中心）                                                     | 産地の病害、養殖池の作付け、米国・EU向け需要、円相場                         | 原価が比較的安定し、子ども需要が厚い                                              |

（産地・形態は業界で一般的に知られる構造。各社は仕入先を公表していない）

**3つとも「日本の海で獲れるかどうか」がほとんど関係ない**点が重要である。
日本の海面漁業生産量は2025年に270万500トン（前年比3.1%減、7年連続減少。農林水産省
漁業・養殖業生産統計）まで縮んだが、回転寿司のネタが消えないのは、
主力が輸入養殖で構成されているからである。

```

  サーモン系   ████████████████  約20%   輸入養殖（ノルウェー・チリ）
  まぐろ系     ███████████       約15%   輸入天然＋蓄養
  えび系       ████████          約10%   輸入養殖（東南アジア・インド）
  はまち・ぶり ██████             約8%    国内養殖（契約）
  いか・たこ   █████              約7%    輸入＋国内天然

  たまご・軍艦 ████████           約12%   加工品（低原価）

  ※業界で一般に語られる構成をもとにした概算。各社の公表値ではない
```

## 3. 買い付けの4つの型 — なぜ自前でやるのか

一般の外食チェーンは食材を[食品卸](../../06_商社・卸売/06_食品卸/README.md)や
[総合商社](../../06_商社・卸売/01_総合商社/README.md)から買う。
回転寿司大手はそこに自社の買い付け機能を差し込んでいる。理由は**中間マージンの排除だけではない**。

| 買い付けの型                 | 何をするか                                                     | なぜ効くか                                                                       |
| ---------------------------- | -------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| **産地買い付け（直送）**     | 自社バイヤーが産地市場のセリに参加し、その日の水揚げを直接買う | ①中間流通を1〜2段飛ばせる ②**他社が買わない魚を安く大量に買える**（後述）        |
| **一船買い（いっせんがい）** | 船1隻分の水揚げを丸ごと買い取る                                | 選別せず全部買うので単価が下がる。産地は売れ残りリスクを回避できるので歓迎される |
| **契約養殖**                 | 養殖業者と、数量・サイズ・出荷時期・価格を事前に取り決める     | **数量と価格が読める**。メニュー計画と価格表を先に確定できる                     |
| **海外調達拠点**             | 産地国に駐在・現地法人を置き、加工場の品質管理まで関与する     | 買い負けを防ぎ、規格カット（1貫◯g）まで現地で完了させられる                      |

### 「他社が買わない魚を買える」が最大の武器

産地市場では、**量が多すぎる魚・サイズが揃わない魚・馴染みのない魚**は買い手がつかず安くなる。
回転寿司チェーンは、この魚を引き取れる数少ない買い手である。

```
【なぜ回転寿司は「売れ残る魚」を買えるのか】

  条件1：店数が多い     → 1日に数トン単位で消化できる
  条件2：メニューが可変 → 「本日の一貫」「期間限定フェア」として即座に商品化できる
  条件3：工場を持つ     → サイズが不揃いでも、切り方を変えて規格に落とし込める
  条件4：冷凍設備がある → 一度に買って、数か月かけて売れる

        ↓

  産地：「まとめて引き取ってくれるなら安くていい」
  チェーン：「安く仕入れられるうえに、珍しいネタが集客材料になる」
        → 双方が得をする。これが産直・一船買いが成立する理由
```

> ポイント：**この仕組みは店数がないと回らない**。
> 数店規模のチェーンが一船買いをしても、売り切る前に鮮度が落ちる。
> **買い付け力は店数の関数**であり、だから回転寿司は規模がそのまま原価率になる装置産業に近い。
> 出店競争が激しいのは、席を増やしたいからではなく**買い付けの単位を大きくしたいから**でもある。

## 4. 円安が原価率に効く仕組み

回転寿司のネタは輸入依存が高いため、為替は**そのまま原価**である。

```
【円安がネタ原価に伝わる経路】

  ノルウェーでの建値       円換算の仕入値       店の原価率
  （例：8ドル/kg で不変）
        │
        ├─ 1ドル=110円 → 880円/kg → 1貫20gなら17.6円 → 120円の皿で原価率14.7%
        ├─ 1ドル=140円 → 1,120円/kg → 22.4円        → 同        18.7%
        └─ 1ドル=155円 → 1,240円/kg → 24.8円        → 同        20.7%

  ※現地建値が1円も動かなくても、円安だけで原価率が6ポイント動く
  ※実際には世界需要の増加で建値そのものも上がっており、影響は重なる
```

これに加えて、**円安は「買い負け」を招く**。
日本の水産物輸入額は2025年で約1兆9,626億円（貿易統計ベースの集計）と、
輸出額4,231億円（2025年・農林水産省）の4倍以上ある。
日本は**買う側**であり、円が弱くなるほど、同じ魚を欧米・中国と競り合ったときに
高値を出せなくなる（→ [水産 ② 養殖と輸入](../11_水産/02_養殖と輸入.md)）。

| 為替以外の原価の押し上げ要因     | 2020年代の状況                                                                                                                         |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| **魚粉（フィッシュミール）価格** | 養殖の餌の主原料。2026年3月に飼料用魚粉1kg 291円との集計。**給餌養殖の原価の6〜7割が餌代**なので、サーモン・ぶりの生産コストを直撃する |
| **燃料費**                       | 遠洋まぐろ漁船・超低温冷凍船の運航費。原油高が直接効く                                                                                 |
| **世界の水産物需要**             | 中国・東南アジアの中間層が同じ魚を買い始めた。**需要側の競合が増えた**                                                                 |
| **国内の米価**                   | 後述。回転寿司だけが持つ、国内起因のコスト                                                                                             |

## 5. シャリという「全皿共通コスト」

魚の話に目が行きがちだが、回転寿司には**もう一つ、逃げ場のない原価**がある。米である。

| 特徴                           | なぜ厄介か                                                                                   |
| ------------------------------ | -------------------------------------------------------------------------------------------- |
| **全皿に乗っている**           | ネタは差し替えられるが、シャリは差し替えられない。米が上がると**全商品の原価が同時に上がる** |
| **国産米が前提**               | 主要チェーンは国産米使用を掲げており、海外産への切り替えが品質・訴求の両面で難しい           |
| **原価ミックスで吸収できない** | 低原価ネタに逃がしても、その皿にも同じシャリが乗っている                                     |

2024〜2025年にかけて国内の米価が急騰し、業務用米も前年比で大きく上昇したと報じられた。
はま寿司が2024年12月と2025年12月に価格改定を行った理由として
**「シャリに国産米を100%使用しており、米の価格高騰の影響を直接受けた」**ことが挙げられている
（同社告知・報道ベース）。

> ポイント：**魚は買い付けの工夫で逃げられるが、米は逃げられない**。
> だから2024年以降の回転寿司の値上げは、
> 「まぐろが高いから」ではなく**「米が高いから全体を上げざるを得ない」**という形をとった。
> 値上げの説明を読むときは、魚由来か米由来かを分けて読むと構造が見える。

## 6. サステナビリティ要請 — 理念ではなく取引条件

水産物の持続可能性への要請は、回転寿司にとって3つの形で現れる。

| 形                          | 内容                                                                                                                       | 経営への影響                                                                                              |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| **資源規制（TAC・国際枠）** | 魚種ごとの年間漁獲上限。太平洋クロマグロは2027年から大型魚（30kg以上）の枠が25%増で国際合意（2026年8月）だが、小型魚は6%減 | 使える魚の量そのものが決まる。**枠が縮めばメニューから消える**                                            |
| **IUU漁業対策**             | 違法・無報告・無規制漁業の排除。日本では**水産流通適正化法**（2022年12月施行）が特定魚種に漁獲番号の伝達・記録を義務化     | 仕入先のトレーサビリティ（追跡可能性）の整備コスト。書類のない魚は買えなくなる                            |
| **認証（MSC／ASC）**        | 天然漁業／養殖の国際的な持続可能性認証                                                                                     | 欧米では取引条件。**海外出店するチェーンには直接効く**（→ [水産 ③](../11_水産/03_大手水産企業の商売.md)） |

回転寿司は「魚を大量に安く使う業態」として、環境NGOや報道から資源問題の文脈で
名指しされやすい立場にある。同時に、**大量かつ安定的に買う買い手**でもあるため、
産地から見れば資源管理の協力者にもなり得る。
各社が完全養殖魚の採用や未利用魚（市場価値がつかない魚）の商品化に取り組むのは、
この両面性への対応でもある。

## 7. 価格転嫁の限界 — 「100円」という看板の呪縛

原価が上がったら値段を上げればよい。だが回転寿司はそれが構造的に難しい。理由は3つある。

```
【なぜ回転寿司は値上げしにくいのか】

  理由1：価格が「皿」に固定されている
     一皿◯円が商品そのもの。1円刻みの調整ができず、
     10円上げると「値上げ」として必ず報道される

  理由2：「安さ」が来店理由そのもの
     ファミリー層が「家族4人で6,000円以内」という予算で来る。
     客単価が1割上がると、来店頻度が下がって客数に跳ね返る

  理由3：比較が容易
     チェーン間でメニューがほぼ同じ。
     1社だけが上げると、隣の店に流れる（＝価格の横並び圧力）
```

そのため各社が実際に取った手は、正面からの値上げではなく**価格帯の多層化**だった。

| 手段                               | 中身                                                                                                                                                                                | 効果                                                                          |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| **最低価格帯の維持＋上位皿の新設** | 110〜120円の皿を残しつつ、150円・180円・300円の皿を増やす                                                                                                                           | 「安い店」の看板を守りながら客単価を上げる                                    |
| **ネタを選んで値上げ**             | 2026年5月、はま寿司がまぐろを110円→132円（まぐろの値上げは初）。サーモンは据え置き。同年7月、スシローが「厳選まぐろ赤身」を120円→150円に改定し、サーモン・いか・えびは120円据え置き | **値上げする商品を選べる**。全皿一律より客離れが小さい                        |
| **サイド・デザートの強化**         | ラーメン、揚げ物、パフェなど                                                                                                                                                        | 原価率を下げながら客単価を上げる（→ [①](01_100円寿司の工学.md) 原価ミックス） |
| **貫数・サイズの調整**             | 2貫→1貫、シャリ量の見直し                                                                                                                                                           | 価格表を変えずに原価率を守る。ただし発覚すると批判を受けやすい                |

**「100円皿」は2022年前後に主要チェーンから実質的に消えた**。
2026年時点の最低価格帯は110〜120円台で、10皿食べたときの支払いは
2020年の1,100円（税込）から1,300円前後まで上がっている（各社価格表・報道ベース）。

> ポイント：回転寿司の値上げは、**価格を上げる作業ではなく「安い店」というブランドを
> どこまで削らずに原価を通すかという設計作業**である。
> だからどの皿を上げ、どの皿を据え置くかが各社の戦略判断になる（→ [③](03_各社の戦略.md)）。

## 8. 水産業界から見ると、回転寿司は何者か

視点を逆にすると、この業界のもう一つの顔が見える。

| 水産側の立場           | 回転寿司はどう見えるか                                                                                                                                                                                                           |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **漁業者・産地市場**   | まとめて買ってくれる数少ない大口需要。鮮魚を扱える小売が減るなか、**出口として重要度が上がっている**                                                                                                                             |
| **養殖業者**           | 契約で数量を引き取ってくれる相手。ただし価格交渉力は強く、餌代高騰を全額は通せない                                                                                                                                               |
| **大手水産・水産商社** | 最大級の顧客であり、**同時に競合**。チェーンが産地直送を強めるほど、中間の口銭が細る。極洋は寿司ネタ・業務用に強く、2026年3月期の水産事業は売上1,950億円（+15.6%）ながら営業益は5.9%減＝**相場高が原価を押し上げた**（同社開示） |
| **輸出産地**           | 国内チェーンが買わない分は輸出へ。ホタテは2025年に輸出額906億円（+30.4%）と水産物の輸出トップ（農林水産省）                                                                                                                      |

> ポイント：**回転寿司は日本の水産物流通における「最大級の小売の出口」**である。
> [食品スーパー](../../07_小売・流通/03_食品スーパー/README.md)の鮮魚売場が
> 技術者不足で縮小するなか、魚を消費者に届ける経路として比重が高まっている。
> つまりこの業界を理解することは、**日本人が魚をどう食べているかを理解すること**でもある。

| 用語                         | 意味                                                                                                                 |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| **一船買い（いっせんがい）** | 漁船1隻分の水揚げを選別せずに丸ごと買い取ること。単価が下がる代わりに、売り切る規模と加工力が要る                    |
| **産地直送（産直）**         | 産地市場・生産者から中間流通を飛ばして直接仕入れること。回転寿司大手の原価優位の源泉                                 |
| **契約養殖**                 | 養殖業者と数量・サイズ・出荷時期・価格を事前に取り決める取引。数量と価格が読める代わりに餌代リスクを共有する         |
| **買い負け**                 | 国際市場で他国のバイヤーに価格で競り負け、必要な量を確保できないこと。円安で起きやすい                               |
| **蓄養（ちくよう）**         | 天然の幼魚・若魚を捕獲して生け簀で太らせる方式。クロマグロで広く行われる。完全養殖とは別物                           |
| **完全養殖**                 | 人工種苗から育てた親魚で採卵し、サイクルを回せる状態 → [水産 ②](../11_水産/02_養殖と輸入.md)                         |
| **魚粉（フィッシュミール）** | 小魚を煮て搾り乾燥した飼料原料。給餌養殖の原価の6〜7割を占める → [水産 ②](../11_水産/02_養殖と輸入.md)               |
| **TAC（漁獲可能量）**        | 魚種ごとに国が定める年間漁獲上限。枠が縮むと、その魚はメニューから消える → [水産 ①](../11_水産/01_水産業の全体像.md) |
| **RFMO（地域漁業管理機関）** | WCPFC・ICCATなど、まぐろ等の国際的な漁獲枠を決める機関                                                               |
| **水産流通適正化法**         | IUU（違法・無報告・無規制）漁業対策のため、特定魚種に漁獲番号の伝達・記録を義務づける法律。2022年12月施行            |
| **MSC／ASC認証**             | 天然漁業／養殖の国際的な持続可能性認証。欧米では実質的な取引条件                                                     |
| **未利用魚**                 | 量が少ない・サイズが不揃い・知名度が低いなどの理由で市場価値がつきにくい魚。回転寿司の商品化対象になる               |
| **価格帯の多層化**           | 最低価格帯を残したまま上位価格の皿を増やし、平均客単価を上げる手法                                                   |
