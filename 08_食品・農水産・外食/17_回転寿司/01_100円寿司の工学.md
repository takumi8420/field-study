# ① 100円寿司の工学 — 原価率40%超という外食の異常値を、どう成立させているか

このノートで分かること：外食の標準的な原価率が30%前後なのに、回転寿司はなぜ40%を超える
原価率で利益を出せるのか。レーン・ロボット・タッチパネルという「設備」が、
その高原価率を支えるためにどう働いているのか。

> 結論：回転寿司は **原価率40〜43%（外食標準より10ポイント以上高い）** という異常値を、
> ①**客単価が高いので1人あたりの粗利「額」はむしろ厚い**、
> ②**自動化とセルフ化で人件費率を外食標準より低く抑えている**、
> ③**1店の年商が4億円級で、固定費が売上に対して薄くなる**、
> という3点で成立させている。
> **原価率の高さは失敗ではなく、「安く見せるために意図的に払っているコスト」**である。

外食1店舗の共通の読み方（FL比率・回転率・坪売上・既存店前年比）は
[ファストフード ① 外食1店舗の経済](../14_ファストフード/01_外食1店舗の経済.md) で定義済み。
本ノートはその語彙を前提に、回転寿司に固有の部分だけを扱う。

---

## 1. まず数字：回転寿司の原価率は本当に高い

「回転寿司の原価率は50%前後」とよく語られる。実際の開示数値はもう少し低く、
**40〜43%** というのが2025〜2026年の実態である。ただし外食標準（28〜32%）と比べれば、
やはり**10ポイント以上高い**。

| 企業（決算期）                                 | 売上原価率                             | 人件費率                   | 営業利益率 | 出典                              |
| ---------------------------------------------- | -------------------------------------- | -------------------------- | ---------- | --------------------------------- |
| **FOOD & LIFE COMPANIES**（2025年9月期・IFRS） | **43.0%**（前期43.1%）                 | 従業員給付費用率 **26.6%** | **8.4%**   | 同社決算説明資料（2025年11月7日） |
| 　同 2026年9月期 会社予想                      | 42.9%                                  | 27.0%                      | 8.4%       | 同上                              |
| **くら寿司**（2025年10月期・日本基準）         | **40.8%**（999.34億円 ÷ 2,451.09億円） | （販管費に内包、非開示）   | **2.2%**   | 同社決算短信（2025年12月10日）    |
| 　同 2026年10月期 第3四半期累計                | **41.0%**（778.56億円 ÷ 1,896.84億円） | 同上                       | 1.5%       | 同社決算短信（2026年9月11日）     |
| （参考）外食の一般的な目安                     | 28〜32%                                | 28〜32%                    | 5〜8%      | 業界通念                          |

FOOD & LIFE COMPANIES（以下 F&LC、「スシロー」の運営会社）の費用構造は、
同社が開示している比率を並べるときれいに100%になる。

```
【F&LC 連結の費用構造（2025年9月期、売上収益＝100）】

   売上収益 …………………… 100.0
     ├─ 売上原価（食材費）… 43.0  ← 外食標準+13ポイント
     ├─ 従業員給付費用 …… 26.6  ← 外食標準よりやや低い
     ├─ その他販管費 …………21.9  ← 家賃・水道光熱・広告・物流など
     ├─ その他収益−費用 … ▲0.1
     ▼  営業利益 ……………… 8.4   ← 外食大手としてはかなり高い
```

> ポイント：**原価率が13ポイント高いのに営業利益率はむしろ高い**。
> ここが回転寿司という業態の設計そのもので、「高い原価率を他のどこで取り返したか」を
> 説明できれば、この業界は8割理解したことになる。

## 2. 原価「率」ではなく粗利「額」で見ると、話が逆転する

外食の原価率は、比率で見ると回転寿司が不利に見える。だが店にとって本当に必要なのは
**1人のお客さんが落としていく粗利の「金額」**である。ここを計算すると順序が入れ替わる。

```
【1人のお客が残す粗利額（概算）】

  ■ ファストフード（バーガー）        ■ 回転寿司
    客単価      800円                   客単価    1,300円
    × 粗利率 70%（原価率30%）           × 粗利率 57%（原価率43%）
    ───────────────                     ───────────────
    粗利       560円／人                 粗利      741円／人  ← 約1.3倍
```

（客単価はいずれも2020年代の業態別の一般的な水準をもとにした概算）

つまり **原価率の高さは、客単価の高さで打ち消されている**。
そのうえで回転寿司は、以下の2つで「1店あたりの粗利の総額」をさらに積み上げる。

| てこ                     | 中身                                | なぜ効くか                                                                                                      |
| ------------------------ | ----------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| **大箱 × 高回転**        | 客席150〜200席、1日の回転率5〜8回転 | 1店の客数が多い。ファストフードの席数の2〜3倍を、同等の回転率で回す                                             |
| **郊外ロードサイド中心** | 敷地200〜300坪、駐車場付き          | 坪単価の安い立地。家賃比率を低く抑えられる（→ [外食1店舗の経済 ④](../14_ファストフード/01_外食1店舗の経済.md)） |

**1店あたりの年商を単純計算**すると差が明確になる。国内スシローは2,659.03億円÷659店で
**年商 約4.0億円／店**（月商 約3,360万円）、くら寿司の日本事業は1,764.07億円÷国内約550店で
約3.2億円／店。ファストフードの標準店（年商1.2〜1.8億円）の2〜3倍である
（各社の直近本決算の開示値を店舗数で割った概算。業態の混在があり厳密な店別売上ではない）。

> ポイント：**回転寿司は「原価率の高い業態」ではなく「1店の売上が桁違いに大きい業態」**である。
> 年商4億円の店なら、固定費（家賃・減価償却・店長給与）は売上に対して自然と薄くなる。
> 逆に言えば、**客数が落ちた瞬間にこの構造は一気に崩れる**。回転寿司が集客キャンペーンと
> IPコラボに異常な熱量を注ぐのは、体裁ではなく損益の必然である。

## 3. ネタごとの原価差を「ミックス」で吸収する

回転寿司の原価管理の中心概念が **原価ミックス**。
1皿ごとに原価率を合わせるのではなく、**店全体の平均原価率を目標に収める**という考え方。

| ネタの類型             | 例                                           | 1皿の原価率の目安                     | 役割                                    |
| ---------------------- | -------------------------------------------- | ------------------------------------- | --------------------------------------- |
| **集客ネタ（目玉）**   | 大トロ、うに、いくら、まぐろ赤身             | **60〜80%**、キャンペーン時は100%超も | 来店理由を作る。単体では赤字でよい      |
| **主力ネタ**           | サーモン、はまち、えび、いか                 | 40〜50%                               | 注文量が多い。ここが平均を決める        |
| **低原価ネタ**         | 玉子、いなり、軍艦（コーン・ツナ）、かっぱ巻 | **15〜30%**                           | 平均原価率を引き下げる                  |
| **サイドメニュー**     | ラーメン、うどん、茶碗蒸し、揚げ物           | 25〜35%                               | 原価率を下げつつ客単価を上げる          |
| **デザート・ドリンク** | ケーキ、パフェ、ソフトドリンク               | **10〜25%**                           | 最も利益率が高い。締めの1品が利益を作る |

（ネタ別原価率は業界で一般に語られる水準。各社は開示していないため推計値として扱う）

```
【原価ミックスの考え方】

  お客さんが10皿食べたときの店側の内訳（イメージ）

   大トロ 1皿 70% ／ まぐろ 2皿 55% ／ サーモン 2皿 45%  ← ここだけ見ると赤字
   えび   1皿 40% ／ いか   1皿 35%
   玉子   1皿 20% ／ かっぱ巻 1皿 18% ／ 軍艦 1皿 25%      ← ここで引き戻す
   ＋ デザート 1品 15%                                     ← 締めの1品が利益を作る
   ────────────────────────────────────────────────
   店全体の平均原価率 ≒ 42%  ← これが目標帯に入っていればよい
```

ここから3つの実務が出てくる。

- **キャンペーンは原価率を上げてでも打つ**。まぐろ祭り・かに祭りは単体で赤字でも、
  客数と「ついで注文」が増えれば店全体の粗利額は増える
- **サイドメニューとデザートの強化は、味の話ではなく原価の話**。
  客単価を上げながら平均原価率を下げられる唯一の手段である
- **フレキシブルな商品設計**（くら寿司が2025〜2026年の決算資料で繰り返し使う表現）とは、
  ネタの仕入値が動いたら**皿の構成・貫数・シャリ量を組み替えて平均原価率を維持する**こと

## 4. レーンの進化 — 「回す装置」から「運ぶ装置」へ

回転寿司の象徴だったコンベアは、この20年で意味が3回変わっている。

```
【レーンの3世代】

 第1世代（1958〜2000年代前半）「回すレーン」
   握った寿司をひたすら流す → 注文を受ける人が要らなくなる
   弱点：売れ残りが全部廃棄。廃棄率10%超も珍しくなかった
         ▼
 第2世代（2000年代後半〜2010年代）「注文レーン」
   タッチパネルで注文 → 上段の特急レーンで席へ直送。下段は「見本」
   皿にICタグを付け、時間経過した皿を自動で廃棄・在庫管理
         ▼
 第3世代（2020年代）「レーンを流さない」
   注文品だけを運ぶ。流れる寿司は大型ディスプレイの映像で再現
   狙い：①衛生・迷惑行為対策 ②廃棄ロスゼロ化 ③できたて提供
   スシローのデジロー設置店は123店舗（2025年9月末、同社決算説明資料）
```

2026年時点で各社の立ち位置は割れており、スシローは「流さない」、くら寿司は「流し続ける」、
すし銚子丸は「やめる」と真っ二つに分かれている（→ [③ 各社の戦略](03_各社の戦略.md)）。

> ポイント：**レーンは「寿司を回す装置」ではなく「人を減らす装置」**だった。
> 第1世代は接客の人を、第2〜3世代は**注文を受ける人・運ぶ人・廃棄を判断する人**を減らした。
> だからレーンを捨てるかどうかの議論は、文化論ではなく
> **「代わりに何が人件費を下げるのか」**という設備投資の議論である。

## 5. 自動化の3層 — どこまで機械に置き換わったか

回転寿司は、外食のなかで**最も自動化が進んだ業態**と言ってよい。
人の作業を「受注」「調理」「運搬」「後片付け」の4層に分けると、そのほとんどに機械が入っている。

| 層                 | 人がやっていたこと     | 置き換えた仕組み                                                   | 削減されるもの           |
| ------------------ | ---------------------- | ------------------------------------------------------------------ | ------------------------ |
| **受注**           | 注文を聞く、伝票を書く | タッチパネル、スマホ注文、時間帯別の自動レコメンド                 | ホールの接客人員         |
| **調理（シャリ）** | 握る                   | **シャリロボット**（1台で1時間に数千貫。米を計量・成形まで自動化） | 職人。未経験者でも扱える |
| **調理（ネタ）**   | 魚を捌く、スライスする | **工場で1食分にカット済みのネタを冷凍で配送**（後述）              | 店内の包丁仕事           |
| **運搬**           | 席まで運ぶ             | 特急レーン（直線の高速レーン）、配膳ロボット                       | ホールの運搬人員         |
| **会計**           | 皿を数える             | **皿のICタグ**／レーン上のAIカメラによる自動計数、セルフレジ       | レジ打ちと数え間違い     |
| **後片付け**       | 皿を下げる、洗う       | **卓上の皿回収口＋水流搬送**（くら寿司「皿NAVI」など）、大型食洗機 | バッシング（下げ膳）作業 |

```
【回転寿司店の作業フロー（自動化後）】

  〔工場／物流センター〕          〔店舗〕                〔客席〕
   ネタを規格カット ─冷凍便─▶ 解凍・盛り付け ┐
   米 ────────────────────▶ シャリロボット ┴─▶ レーン ─▶ 席
                                                  ▲          │
                                         タッチパネル注文 ◀───┤
                                  皿ICタグ／AIカメラで自動計数 ◀┘
                                  皿回収口 → 水流搬送 → 食洗機

  ※「握る」「捌く」「運ぶ」「数える」「洗う」の5つが、すべて設備に移った
  ※店に残る人の仕事は「盛り付け」「フロアの目視確認」「清掃」「トラブル対応」
```

この自動化の結果、回転寿司の人件費率は外食標準（28〜32%）より低い水準に収まっている
（F&LC連結の従業員給付費用率は2025年9月期で26.6%、本部人件費を含む）。
**高い原価率を払える原資は、ここで作られている。**

### 廃棄ロスとの戦い — 自動化投資のもう半分

「回す」方式の最大の弱点は、**売れ残りが全部廃棄になる**ことだった。
1皿の原価が50円なら、廃棄1皿は50円の損失で、取り返すには原価率43%の皿を2皿以上売らねばならない。
**廃棄率が数ポイント動くだけで営業利益が吹き飛ぶ**。対策は4つ。

- **皿のICタグ（RFID）**：レーン投入時刻を記録し、一定時間（例：350m走行＝約30分）で自動廃棄。
  廃棄の判断を人から外し、鮮度の下限を保証する
- **需要予測**：曜日・時間帯・天候・来店客数から、何分後に何皿売れるかを予測して製造指示を出す
- **注文品のみ提供**：そもそも流さない（デジロー等）。理論上、レーン廃棄はゼロになる
- **少量多回製造**：1回の製造ロットを小さくし、読み違えたときの損失を抑える

> ポイント：廃棄削減は、**原価率を直接下げる数少ない手段**である。
> メニューの原価を下げれば味が落ちて客数が減るが、廃棄を減らしても客には何も起きない。
> **回転寿司の自動化投資の半分は、廃棄との戦い**だと考えてよい。

## 6. セントラルキッチンと店内加工の分担

回転寿司は「店で魚を捌いている」というイメージがあるが、チェーンの実態は違う。
**ネタの加工はほぼ工場と産地で完了し、店は解凍・盛り付け・シャリ付けだけを行う**。

```
【ネタが店に届くまで】

  産地／海外の加工場            国内の自社・協力工場            店舗
  ──────────────────────────────────────────────────────
  漁獲・水揚げ ─▶ 一次処理 ─┐
  養殖場 ─────▶ 活〆・フィレ ┴▶ スライス・規格カット ─▶ 解凍 ─▶ 盛り付け
                                （1貫＝◯g に規格化）              ＋
                                冷凍（−40℃級）で保管        シャリロボット
                                                            （パート作業／数日で習熟）

  ※「規格カット」がこの業態の核心。1貫あたりのグラム数が固定されるので、
    原価が1円単位で読め、誰が作っても同じ商品になる
```

| 工程                   | どこでやるか           | なぜそこか                                                                        |
| ---------------------- | ---------------------- | --------------------------------------------------------------------------------- |
| 魚の一次処理・フィレ化 | 産地／海外の加工場     | 人件費が安く、鮮度の落ちる前に処理できる                                          |
| 規格カット（1貫◯g）    | 自社・協力工場         | **原価の固定と品質の均一化**。店の技能差を消す                                    |
| 冷凍・保管             | 超低温冷凍庫（−40℃級） | 漁期と需要期のズレを在庫で吸収する（→ [水産 ①](../11_水産/01_水産業の全体像.md)） |
| 解凍・盛り付け         | **店舗**               | ここだけは店でやる。作り置きすると品質が落ちるため                                |
| 炊飯・シャリ成形       | **店舗（ロボット）**   | 米は炊きたての保持時間が短く、輸送できない                                        |
| サイド・デザート       | 工場中心               | 店の作業を増やさずに客単価を上げるため                                            |

一部には**店内でネタを捌く**ことを売りにする店もある（くら寿司の「くらおさかな市場」など、
鮮魚の店内加工を前面に出す派生業態）。これは原価や効率ではなく、
**「工場の寿司」という評価への対抗手段**として位置づけられる。

## 7. 回転寿司版の1店舗P/L

[外食1店舗の経済](../14_ファストフード/01_外食1店舗の経済.md) の型に、回転寿司の数字を当てはめる。

```
【回転寿司1店舗の損益（郊外ロードサイド標準店・売上100とした比率の概算）】

   売上高 100      （年商4億円級＝月商3,300万円前後）
     ├─ F：食材費 ………… 41〜43   ★外食標準より10ポイント以上高い
     ├─ L：人件費 ………… 23〜27   ★自動化とセルフ化で標準より低い
     │                            ……… FL = 64〜70（標準の「60%以内」は最初から守れない）
     ├─ R：家賃 ………………  4〜7   ★郊外・大箱なので売上比では軽い
     ├─ 水道光熱費 ………  4〜6
     ├─ 減価償却費 ………  5〜7   ★レーン・ロボット・厨房設備が重い
     ├─ 販促・その他 ……  8〜12
     ▼
   店舗営業利益 ……………  5〜10
```

（各社開示の連結比率と業界の一般的水準から組み立てた概算。立地・規模で大きく振れる）

読み取るべきことは3つ。**①FL比率60%という外食の目安は回転寿司では通用しない**——
この業態は最初からFL 65〜70%で設計され、外食の常識「FLR 70%以内」はFLではなく
**家賃比率4〜7%**で守られている。**②減価償却費が重い**——レーン・ロボット・冷凍設備で
1店の初期投資は**2億〜3億円規模**とされ、ファストフードの郊外店（1億〜1.5億円）の2倍近い。
**③だから客数が落ちると一気に赤字になる**——くら寿司の日本事業が2026年10月期第3四半期累計で
売上▲1.2%にとどまったのに経常利益は▲40.8%まで落ちたのは、この構造の表れである。

### この業態の急所は3つしかない

| 急所           | なぜ効くか                                                                   | どこで扱うか                                                             |
| -------------- | ---------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| **魚価と為替** | 原価の4割超が水産物。仕入値が1割上がると原価率が4ポイント動く                | [② 水産調達という本業](02_水産調達という本業.md)                         |

> まとめ：回転寿司とは、**「原価率を捨てて、人件費と家賃と客数で取り返す」**業態である。
> だから回転寿司チェーンの経営は、味の追求である以上に
> **買い付け（原価）と集客（客数）の2点勝負**になる。次のノートは前者を扱う。

---

## 用語メモ

| 用語                       | 意味                                                                                                                                                   |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **原価ミックス**           | 皿ごとに原価率を合わせるのではなく、店全体の平均原価率を目標帯に収める考え方。目玉ネタの赤字を低原価ネタとデザートで埋める                             |
| **集客ネタ（目玉ネタ）**   | 大トロ・うに・いくらなど、単体では原価率60〜80%になるが来店理由を作るネタ                                                                              |
| **フレキシブルな商品設計** | 仕入値の変動に合わせて、皿の構成・貫数・シャリ量を組み替えて平均原価率を維持すること（くら寿司の決算資料での表現）                                     |
| **特急レーン**             | 注文品を席まで直送する直線の高速レーン。回転レーンの上段に設けられることが多い                                                                         |
| **デジロー**               | スシローの、レーンに寿司を流さず大型ディスプレイの映像から注文する仕組み。2025年9月末で123店舗                                                         |
| **シャリロボット**         | 米の計量・成形を自動で行う機械。握る技能を不要にし、回転寿司の低価格を成立させた装置                                                                   |
| **ICタグ（RFID）**         | 皿に埋め込む無線タグ。レーン投入からの経過時間で自動廃棄を判断し、会計時の皿数も自動計数する                                                           |
| **抗菌寿司カバー**         | レーン上の皿にかぶせる透明カバー。衛生対策として導入され、2023年以降は迷惑行為検知の対象にもなっている                                                 |
| **規格カット**             | ネタを「1貫＝◯グラム」に工場で切り揃えること。原価を1円単位で管理でき、店の技能差を消せる                                                              |
| **損益分岐点の客数**       | 固定費を賄うのに必要な客数。減価償却と家賃が重い回転寿司は、この水準が高い                                                                             |
| **FL比率／FLR比率**        | 食材費＋人件費（＋家賃）の売上比。回転寿司はFLが65〜70%と高く、Rの低さで帳尻を合わせる → [外食1店舗の経済](../14_ファストフード/01_外食1店舗の経済.md) |
