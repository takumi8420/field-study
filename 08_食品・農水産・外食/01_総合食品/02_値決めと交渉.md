# ② 値決めと交渉

このノートで分かること：スーパーの棚に並ぶ食品の値段が、**誰と誰の、どんな交渉で決まっているか**。
そして「値上げします」という発表から実際に利益が増えるまでに、何が起きているか。

## 1. 結論：食品の値段は「定価」ではなく「交渉の結果」である

家電なら「メーカー希望小売価格」があり、実売はそこから何%引きという世界。
食品は違う。**そもそも希望小売価格を出さない商品が多い**（オープン価格）。
では何を基準に交渉するのかというと、メーカーが設定する **建値（たてね）** である。

> **建値** ＝ メーカーが卸・小売に示す基準の納入価格。定価ではなく「交渉の出発点」。
> 実際の取引価格は、この建値から**リベート（販売報奨金）・特売協賛金・センターフィー負担**などを
> 差し引いた「正味（ネット）価格」で決まる。

つまり食品業界には**表の価格（建値）と実質の価格（ネット価格）の二重構造**がある。
値上げのニュースは表の価格の話であり、実質の価格が同じだけ上がるとは限らない。
ここが食品業界の値決めを理解する最大の鍵になる。

```
【表の価格と実質の価格】

  メーカー建値      100円  ← ニュースで「◯%値上げ」と報じられるのはここ
     │
     ├─ リベート（数量・販促・物流・決済）      ▲6円
     ├─ 特売協賛金（チラシ・エンド陳列の負担）  ▲4円
     ├─ 新規導入協賛（新商品を棚に置く一時金）  ▲1円
     └─ センターフィー等の負担                  ▲2円
                                            ─────
  メーカーの実質手取り（ネット価格）        87円

  → 建値を5%上げても、リベート条件を2%積み増されれば
    実質の値上げは 3% にしかならない
```

## 2. 誰と誰が交渉しているのか

食品の価格交渉は一本道ではない。少なくとも3つの交渉が同時に走っている。

```
【3つの交渉が同時に動く】

 ① 原料の交渉        ② 卸との交渉          ③ 小売との交渉
 ───────────         ────────────          ─────────────
 商社・製粉・         建値改定、リベート     実勢価格、特売頻度、
 油脂・乳業 等        条件、物流条件         棚の面積、PB
      │                    │                      │
      ▼                    ▼                      ▼
  メーカー ─────────▶  食品卸  ─────────▶  スーパー／CVS ──▶ 消費者
      │                                            ▲
      └──────── 直接交渉（帳合は卸でも価格は直談判）─┘

 ※ 商品は卸を通るが、価格の実質的な決定は
   「メーカー ⇄ 大手小売」の直接交渉で決まることが多い。
   卸は物流と債権を引き受け、価格交渉の主戦場からは外れている。
```

これが日本の食品流通の独特な点。**モノの流れ（商流）と価格決定の流れが一致していない**。
卸側から見た同じ構図は [食品卸ノート③](../../06_商社・卸売/06_食品卸/03_業界構造と再編.md) にある。

| 交渉相手 | メーカーの立場 | 主な論点 |
| --- | --- | --- |
| 原料サプライヤー（商社・素材メーカー） | 買い手。比較的強い | 年間数量、複数購買、スペック変更 |
| 食品卸 | 売り手。帳合を握られている | 建値改定の適用日、リベート料率、返品条件 |
| **大手小売（GMS・食品スーパー・CVS・ドラッグ）** | **売り手。圧倒的に弱い** | 納入価格、特売協賛、棚割り、PB受託 |
| 外食・中食・給食（業務用） | 売り手。比較的対等 | 年間契約価格、規格、安定供給 |

> ポイント：**小売との交渉でメーカーが弱いのは「棚」が有限だから**。
> スーパーの醤油売場に並べられるのは10〜20アイテム。
> そこから外されると、どれだけ良い商品でも売上がゼロになる。
> この「棚を人質にとられている」構造が、価格交渉の力関係を決めている。

## 3. 特売という制度 ― 日本の食品価格が読めない理由

日本のスーパーは **Hi-Low（ハイ・ロー）型** の価格政策を取る店が多い。
通常は高め、チラシの目玉商品として週に数日だけ大きく下げる、というやり方である。

| 方式 | 内容 | メーカーへの影響 |
| --- | --- | --- |
| **Hi-Low（特売型）** | 通常価格は高く、週次のチラシで一部商品を大幅値引き | 特売協賛金の負担が発生。特売週に需要が集中し、**生産計画が振り回される** |
| **EDLP（エブリデー・ロープライス）** | 常に一定の安値。特売をやらない | 協賛金は減るが、納入価格そのものを下げるよう求められる |

特売はメーカーにとって両刃の剣である。

- **良い面**：一時的に数量が跳ねる。新規のお客が試してくれる。
- **悪い面**：協賛金を負担するので利益が出ない。特売時しか売れない商品になる（特売慣れ）。
  さらに**特売週だけ生産を増やす必要があり、工場の稼働が平準化しない**。

```
【特売が生産を歪める】

 出荷量
  ▲
  │        ■特売週
  │        ███
  │        ███
  │  ▁▁▁  ███  ▁▁▁  ▁▁▁          ← 通常週は工場が余る
  │  ███  ███  ███  ███
  └──┴────┴────┴────┴──▶ 週
     1週  2週  3週  4週

  → ピークに合わせて設備と人を持つ必要がある
  → 平常週の稼働率が下がり、1個あたり固定費が上がる（→ ①第5章）
```

## 4. 値上げの実務 ― 「発表」の前に何が起きているか

値上げは記者発表で始まるのではない。実務は次の順番で進む。

```
【値上げの標準的な段取り（加工食品の例）】

 ─6か月  原価シミュレーション
          「このままだとQ3に粗利が◯pt落ちる」を社内で確定
            │
 ─5か月  値上げ幅と対象SKUの決定、社内決裁
          全品一律ではなく、主力は抑え、周辺品を大きく上げる等の設計
            │
 ─4か月  ★主要取引先への事前通告（口頭 → 文書）
          ここが最重要。改定日の3〜4か月前が慣行
            │
 ─3か月  ★プレスリリース（対外発表）
          「◯月◯日出荷分より、◯品目を平均◯%改定」
            │
 ─3〜1か月 卸・小売との個別交渉
          ・原価上昇の「証拠」提示（原料価格指数、仕入伝票、為替推移）
          ・小売からの逆提案（実施時期の延期、幅の圧縮、リベート増額要求）
          ・駆け込み需要（改定前の大量発注）への対応
            │
   0か月  出荷価格の改定日
          ただし店頭には旧価格の在庫が残り、実際の棚価格は1〜2か月遅れる
            │
 ＋3か月  数量の落ち込みが見える（買い控え・PBへの流出）
 ＋6か月  値上げ効果が損益に乗り切る
```

### 4.1 「原価上昇の証明」という仕事

値上げ交渉でメーカーが求められるのは、**「なぜ上げるのか」の客観的な説明**である。
感覚的な「コストが上がったので」では通らない。実務で持っていくのは次のような資料になる。

| 証拠の種類 | 具体例 | 説得力 |
| --- | --- | --- |
| 公的な指数・公表価格 | 輸入小麦の政府売渡価格、企業物価指数、原油価格、為替レート | 高い。第三者の数字なので反論しにくい |
| 国際相場のチャート | カカオ・コーヒー・大豆の先物価格推移 | 高い。ただし「ヘッジで回避できたのでは」と突かれる |
| 自社の原価内訳 | 原材料費・包装資材費・物流費の前年比 | 中程度。企業秘密との兼ね合いで開示範囲が難しい |
| 業界横並びの動き | 同カテゴリ他社の値上げ発表 | 実務上は最も効く。ただし**談合と誤解されない配慮が必要**（独禁法） |

> ポイント：**同業他社が先に値上げを発表しているかどうかで、交渉の通りやすさが全く変わる。**
> だから食品の値上げは「波」になる。ただし**事前に示し合わせれば価格カルテル（独禁法違反）**なので、
> あくまで各社が独立に判断した結果として同時期に重なる、という建て付けになる。

### 4.2 通らなかったときに起きること

交渉が決裂した場合、次のいずれかになる。

- **実施時期の延期**（3か月後ろ倒しなど）。最も多い着地。
- **幅の圧縮**（10%要求 → 6%で妥結）。
- **リベート・協賛金の積み増しとの抱き合わせ**（建値は上げるが実質は据え置き）。
- **特定小売への出荷停止**（極めて稀。関係が壊れるため最終手段）。
- **その小売のPBに置き換えられる**（＝帳合を失うのと同じ結果）。

## 5. 実質値上げ（容量変更）という選択

価格を据え置いたまま**内容量を減らす**ことで、単位あたりの価格を上げるやり方。
報道では「ステルス値上げ」「シュリンクフレーション」とも呼ばれる。

| 手法 | 例 | メリット | デメリット |
| --- | --- | --- | --- |
| **容量減（実質値上げ）** | 内容量を10%減らして価格据え置き | 店頭の「価格の見た目」が変わらないので買い控えが起きにくい。小売の棚札も変えずに済む | 消費者に気づかれると信頼を失う。包装・金型の変更コストがかかる |
| **価格改定（表示価格の変更）** | 198円 → 218円 | 説明しやすく誠実。一度上げれば継続的に効く | 買い控えとPBへの流出が起きる。小売との交渉が重い |
| **規格・仕様の変更** | 原料グレードの見直し、包装の簡素化 | 価格も容量も変えずにコストを下げられる | 品質劣化と受け取られると致命的 |
| **ミックス改善** | 高価格帯・高付加価値品の構成比を上げる | 平均単価が上がり、値上げ感を伴わない | 時間がかかる。販売数量は伸びない |

日本では価格表示のルール上、内容量の表示義務はあるが、
**「内容量を減らした」ことを目立たせる義務はない**。このため実質値上げは合法である。
ただし消費者庁は不当表示にならないよう注意を促しており、
近年は各社とも**自主的に「内容量を変更しました」と告知する**ケースが増えている。

> ポイント：実質値上げは**値上げの「第一波」でよく使われ、コスト上昇が続くと通用しなくなる**。
> 容量を減らし続けると、いずれ商品として成立しなくなるため。
> 2022年以降の長期のコスト上昇局面で各社が表示価格の改定に踏み切ったのは、
> 実質値上げの余地を使い切ったからでもある。

## 6. PB受託という選択

**PB（プライベートブランド）** ＝ 小売が自社ブランドで売る商品。
中身を作るのは多くの場合、食品メーカーである（＝受託製造）。

| 立場 | PBを受けるメリット | PBを受けるデメリット |
| --- | --- | --- |
| メーカー（受託する側） | 工場の空き能力が埋まり、**稼働率が上がる**。広告費・営業費がかからない | 利幅が薄い。自社NB（ナショナルブランド）の売上を食う。価格決定権がない |
| 小売（委託する側） | 粗利率が高い（NBの25〜30%に対しPBは30〜40%とされる）。値上げ局面で「安い選択肢」を持てる | 品質責任を負う。開発・在庫リスクを自社で持つ |

メーカーにとってPBは**「工場を遊ばせるよりマシ」という空き能力の消化策**であり、
同時に**「自社ブランドを自分で殺す」リスク**でもある。
とくに値上げ局面では、NBを値上げした結果、消費者が同じ工場で作られたPBに流れるという
皮肉な事態が起こる。

だから各社の方針は大きく分かれる。

- **PBを一切受けない**（ブランド価値を守る。大手NBメーカーに多い）
- **子会社・別工場で受ける**（本体ブランドと切り離す）
- **積極的に受ける**（中堅メーカー、空き能力の大きい工場）

PBが流通側からどう見えているかは
[食品卸ノート③](../../06_商社・卸売/06_食品卸/03_業界構造と再編.md) と
[食品スーパー](../../07_小売・流通/03_食品スーパー/README.md) を参照。

## 7. 価格転嫁を政策が後押しするようになった

2022年以降のコスト上昇を受けて、**国が「価格転嫁は正当である」と明示的に後押しする**
という、これまでになかった環境ができている。

| 制度・取り組み | 内容 | メーカーにとっての意味 |
| --- | --- | --- |
| **公正取引委員会「価格転嫁円滑化に関する調査」** | 取引先の多い発注者を毎年調査し、**協議を経ない取引価格の据置き**が疑われる事案に立入調査・注意喚起文書を送付。令和7年度（2025年度）調査では発注者4,334名に注意喚起文書。令和8年度（2026年度）調査は2026年6月17日に開始が公表された | 「交渉に応じない」こと自体が独禁法上の**優越的地位の濫用**に問われうる。値上げ交渉のテーブルに着かせる力になる |
| **優越的地位の濫用に係る事業者名の公表** | 2024年3月、公取委が転嫁交渉に応じなかった事業者名を公表 | 公表リスクが交渉圧力として働く |
| **労務費の適切な転嫁のための価格交渉に関する指針**（内閣官房・公取委、2023年11月） | 労務費上昇分の転嫁について発注者・受注者それぞれの行動指針を提示 | 原材料以外（人件費）の転嫁の根拠になる |
| **食品製造業者・小売業者間における適正取引推進ガイドライン**（農水省・中小企業庁） | 令和3年12月策定、令和8年（2026年）1月改定。センターフィーやリベートの算定根拠を示さない要請を問題行為として整理 | **リベート・センターフィーの根拠開示を求める材料**になる |

ただし現実の転嫁率には大きな偏りがある。公取委の特別調査（令和7年度／2025年度）によれば、
転嫁率の中央値は **原材料価格 80.0% / エネルギーコスト 50.0% / 労務費 30.0%**。

> **原材料の値上がりは比較的通るが、人件費の上昇はほとんど通っていない。**
> 「原料が上がった」は伝票で証明できるが、「賃上げした」は証明しにくく、
> 「それはあなたの会社の事情でしょう」と返されやすいため。
> 賃上げが続く局面では、これが食品メーカーの利益を静かに削っていく。

## 8. 2026年の新しい変数 ― 飲食料品の消費税1%

2026年9月15日の臨時閣議で「飲食料品消費税率の臨時的な引下げ及び就業者負担軽減支援金の導入に関する大綱」が決定され、
**軽減税率対象の飲食料品の消費税率を2027年4月1日から2029年3月31日までの2年間、8%から1%に引き下げる**方針が固まった
（報道および政府公表ベース。詳細は [⑤ 直近トピック](05_直近トピック_2026.md) で扱う）。

値決めの観点で何が変わるか。

- **店頭価格が7%分下がる余地が生まれる**。ここに値上げをぶつければ、
  消費者から見た支払額はほぼ変わらない。**値上げの「窓」が2027年4月に開く**。
- 逆に小売からは「減税分は消費者に還元すべきで、メーカーの値上げに充てるのはおかしい」
  という反論が想定される。交渉は激しくなる。
- **2029年4月の税率戻り**は事実上の7%値上げとして消費者に効く。
  そこに向けた駆け込み需要と反動減という、新しい波も生まれる。

## 9. まとめ：値決めを理解する3つの鍵

1. **表の価格（建値）と実質の価格（ネット価格）の二重構造**。
   値上げ発表の%がそのまま利益にならないのは、リベートと協賛金が間に挟まるから。
2. **交渉の力関係を決めているのは「棚」**。
   棚から落ちれば売上がゼロになるので、メーカーは大手小売に対して構造的に弱い。
   その弱さをPBがさらに増幅する。
3. **2022年以降、国が転嫁を後押しする側に回った**。
   原材料の転嫁率は8割まで来たが、労務費は3割にとどまる。次の争点はここ。

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **建値（たてね）** | メーカーが卸・小売に示す基準の納入価格。定価ではなく交渉の出発点。値上げ発表はこの建値の改定を指す |
| **オープン価格** | メーカーが希望小売価格を設定せず、店頭価格を小売の判断に委ねる方式。食品・家電で一般的 |
| **ネット価格（正味価格）** | 建値からリベート・協賛金・各種負担を差し引いた、メーカーの実質的な手取り価格 |
| **リベート（販売報奨金）** | 取引数量や販促実績に応じてメーカーが卸・小売へあとから払い戻す金銭。数量・販促・物流・決済の4類型が一般的 |
| **特売協賛金** | チラシ特売やエンド陳列の際、値引き原資の一部をメーカーが負担する金銭 |
| **Hi-Low（ハイ・ロー）／EDLP** | 通常高め＋週次特売で売る方式／常に一定の安値で売る方式。日本のスーパーはHi-Lowが主流 |
| **実質値上げ（シュリンクフレーション）** | 価格を据え置いたまま内容量を減らすこと。単位あたり価格は上がる。合法だが信頼リスクがある |
| **PB（プライベートブランド）／NB（ナショナルブランド）** | 小売が自社ブランドで売る商品／メーカーが自社ブランドで売る商品。PBの中身は多くの場合メーカーの受託製造 |
| **優越的地位の濫用** | 取引上強い立場の者が、相手に不当な不利益を与える行為。独占禁止法で禁止。**協議に応じない一方的な価格据置き**もこれに当たりうる |
| **センターフィー** | 小売が自社物流センターの運営費として納入業者から徴収する手数料。納品額の数%規模とされる → [食品卸①](../../06_商社・卸売/06_食品卸/01_食品卸は何をしているか.md) |
