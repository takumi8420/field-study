# ④ 国内成熟と海外展開

このノートで分かること：食品メーカーの成長がなぜ**構造的に頭打ち**なのか、
そしてその中で「海外で勝った会社」と「国内に留まった会社」で何が決定的に違ったのか。

## 1. 結論：国内の「数量」は二度と伸びない

食品の国内市場規模は、乱暴に言えば次の掛け算で決まる。

```
【国内食品市場の分解】

  市場規模 ＝ 人口 × 1人あたり食事回数 × 1食あたり支出

              ▼                ▼                   ▼
          減っていく        ほぼ一定           唯一動かせる
        （2008年を         （1日3食は        （値上げ・高付加価値化）
         ピークに減少）      増えない）

  さらに：高齢化により「1人あたり摂取量」も減る
         （高齢者は若年層より食べる量が少ない）

  → 数量（トン・食数）は構造的に縮小する
  → 名目金額を伸ばせるのは「単価」だけ
```

これが食品メーカーの経営が「値上げ」と「海外」の2語に集約される理由である。
国内で数量を伸ばそうとすれば、**他社からシェアを奪うしかない**。
だが第③ノートで見たとおり、主要カテゴリはすでに寡占化していて、
シェアを奪うには販促費を積むしかなく、それは自分の利益を削る行為になる。

> **国内市場での数量競争は、業界全体で見れば必ずマイナスサム（縮小する取り分の奪い合い）になる。**
> だから成長を求める会社は、国内から出るか、買うか、単価を上げるかの3択になる。

## 2. 3つの出口

| 出口 | 中身 | 得意な会社 | 限界 |
| --- | --- | --- | --- |
| **① 単価を上げる** | 値上げ、高付加価値品へのシフト、機能性訴求 | ブランド指名の強い会社（調味料、うま味調味料） | 数量が落ちる。買い控えとPBへの流出。国内では一巡しやすい |
| **② M&Aで買う** | 同業・隣接カテゴリの買収、業界内統合 | 資金力のある大手 | 国内M&Aは「縮む市場のシェアを買う」だけになりがち。のれん減損リスク |
| **③ 海外へ出る** | 輸出、現地生産、現地企業の買収 | 保存性が高い／現地の食習慣に入り込める商品を持つ会社 | 時間がかかる。現地の嗜好・宗教・規制の壁。為替と地政学リスク |

現実には各社ともこの3つを併用しているが、**どこに重心を置いたかで20年後の姿が大きく変わった**。
それが次章の海外売上比率の差として表れている。

## 3. M&Aによる規模拡大

食品業界のM&Aは、目的で4つに分類できる。

| 類型 | 狙い | 典型例のパターン |
| --- | --- | --- |
| **水平統合（同業の統合）** | 生産・物流・営業の重複を削り、シェアと交渉力を高める | 同カテゴリの中堅同士の統合、大手による中堅の吸収 |
| **カテゴリ拡張** | 隣のカテゴリを買って、小売への提案力（棚の面積）を広げる | 調味料メーカーが冷凍食品を買う、乳業が菓子を買う など |
| **川上統合（原料・農業へ）** | 原料の安定確保と価格変動の吸収。近年増えている | 原料商社・加工工場・農業法人の取得、六次産業化 |
| **海外買収（クロスボーダー）** | 販路・ブランド・生産拠点をまとめて買う。最も時間を買える | 現地の食品メーカーの買収 |

近年の特徴として、次の2点が指摘されている（M&A仲介各社のレポート、2025〜2026年）。

- **中小食品メーカーの事業承継案件が増えている**。後継者不在に加え、
  原材料・エネルギー・人件費の上昇と価格転嫁の遅れで**倒産が増加傾向**にあるため
  （食品業の倒産は2025年度168件、前年度比+13.5%。東京商工リサーチ）。
- **川上M&A（農業参入）と内製化が注目されている**。
  原材料高騰への対抗として、原料そのものを押さえにいく動き。

> ポイント：**国内M&Aは「成長」ではなく「守り」の色が濃い**。
> 縮む市場でシェアを買っても、市場全体が縮めば売上は伸びない。
> 国内M&Aの本当の狙いは、**工場の統廃合によるコスト削減**と、
> **小売に対する交渉力（棚の確保）**にある。
> 逆に「成長のためのM&A」と言えるのは、クロスボーダー案件だけに近い。

## 4. 海外売上比率の差 ― 同じ食品メーカーでこれだけ違う

| 企業 | 直近の売上規模 | 海外の位置づけ | 年・出典 |
| --- | --- | --- | --- |
| **キッコーマン** | 売上収益 **7,455億円** | **海外売上収益 約78%／事業利益の約90%が海外**。海外事業の約7割が北米 | 2026年3月期。同社IR・報道ベース |
| **味の素** | 売上高 **1兆5,837億円**（+3.5%）、事業利益 **1,811億円** | 海外比率は**6割前後**（集計定義により58〜68%と幅がある。海外売上高は1兆円を超えたと報じられる） | 2026年3月期（比率は各種報道・IR資料ベース） |
| **日清食品HD** | 売上収益 **7,920億円**（+2%）、営業利益 **605億円**（▲18.6%） | 海外のコア営業利益は**351億円**を見込み（前期比15%減）。**利益の約半分を海外が稼ぐ**構造 | 2026年3月期。海外利益は2025年11月の下方修正時点の見込み |
| **明治HD** | 売上 **1兆1,736億円**（+1.7%）、営業利益 **933億円**（+10.2%） | 国内（乳製品・菓子・医薬）が中心。海外は成長投資段階 | 2026年3月期。同社決算短信 |
| **山崎製パン** | 国内パン最大手 | 国内内需型。海外は一部地域に限定 | 12月期決算 |

この差は偶然ではない。**海外で伸びた会社には共通の条件がある**。

## 5. なぜキッコーマンは海外で勝てたのか

しょうゆという、いかにも日本的な商品で海外売上8割近くに到達した経緯は、
食品の海外展開の教科書になっている。

```
【キッコーマン型の海外展開（3段階モデル）】

 第1段階：輸出（1950〜60年代）
   日本から日系人・日本食レストラン向けに輸出
   → 市場は小さい。「在留邦人向け」で止まる
        │
        │ ★ここで方向転換したのが決定的
        ▼
 第2段階：用途の翻訳（1960〜70年代）
   「しょうゆ＝日本料理の調味料」ではなく
   「しょうゆ＝肉をおいしくする万能調味料」として再定義
   ・スーパーの店頭でステーキの試食デモを繰り返す
   ・テリヤキソースという"現地料理"を作り出す
   → 日本食を食べない人が買う商品になった
        │
        ▼
 第3段階：現地生産（1973年 米ウィスコンシン州〜）
   ・輸送費と関税を回避
   ・「アメリカ製のしょうゆ」として現地に根付く
   ・現地の雇用・原料調達で地域に組み込まれる
   → 2024年4月着工、2026年秋出荷開始予定の
     ウィスコンシン州ジェファーソンの米国第3工場に
     10年間で約800億円を投じる計画（報道ベース）
```

> **成功の本質は「日本の食文化を輸出した」ことではなく、「現地の食文化に自社製品の居場所を作った」こと。**
> テリヤキは日本料理ではない。現地で発明された用途である。
> 日本食レストラン向けに売り続けていたら、今の規模にはなっていない。

### 味の素と日清食品の場合

| 企業 | 海外で効いた要因 |
| --- | --- |
| **味の素** | ①**うま味調味料が各国の家庭料理に溶け込んだ**（東南アジア・南米）。②小分け（1回分の小袋）で低所得層にも届く価格設計にした。③発酵技術を医薬中間体・電子材料（ABF＝半導体パッケージ用絶縁フィルム）へ横展開し、食品以外の高収益事業を作った |
| **日清食品HD** | ①**即席麺は保存性が高く輸送コストに強い**という商品特性。②カップ麺という「容器＋調理法」ごと輸出できる。③各国の嗜好に合わせて味を全面的に作り替えた（現地では日本と全く違う味） |

逆に、海外展開が難しい商品もある。

- **日持ちしない**（牛乳、パン、豆腐、生菓子）→ 現地生産しかないが、初期投資が重い
- **重くてかさばる**（飲料、調味料の大型サイズ）→ 輸送費が売価を上回る
- **文化的に代替がある**（米飯、味噌汁）→ 現地に既存の主食があると入り込めない
- **宗教的制約**（豚由来原料、アルコール）→ ハラール等の対応が必須

## 6. 和食ブームと食材輸出

企業単位の海外展開とは別に、**日本から食材そのものを輸出する**流れが政策として推進されている。

| 指標 | 数値 | 年・出典 |
| --- | --- | --- |
| 農林水産物・食品の輸出額 | **1兆7,005億円**（前年比 **+12.8%**） | 2025年。農林水産省「2025年の農林水産物・食品の輸出実績」 |
| 政府目標 | **2030年に5兆円** | 農林水産省「農林水産物・食品の輸出拡大実行戦略」 |

輸出が伸びている背景。

- **和食のユネスコ無形文化遺産登録（2013年）以降の世界的な和食人気**。
  海外の日本食レストラン数は増加が続いている。
- **インバウンドが「試食の場」になっている**。訪日客が日本で食べた味を帰国後に買う、という循環。
- **円安で日本産品の海外価格が相対的に下がった**。
- 品目では、**ホタテ等の水産物、日本産ウイスキー・日本酒、牛肉、菓子、ソース類**などが伸びている。

一方で注意点もある。

- **輸出の主力は加工食品よりも一次産品・嗜好品**。食品メーカーの加工食品が主役とは限らない。
- **相手国の規制リスクが大きい**。放射性物質を理由とする輸入規制、
  各国の食品添加物・表示ルールの違い、突発的な輸入停止など。
  特定国への依存度が高い品目は、政治情勢で一夜にして販路を失いうる。

詳しくは [水産](../11_水産/README.md)、[農業・種苗・肥料](../12_農業・種苗・肥料/README.md)、
[ビール・酒類](../08_ビール・酒類/README.md) も参照。

## 7. 現地生産と「現地嗜好への適応」

海外展開の最後の壁が、**味をどこまで変えるか**である。

```
【海外展開の4象限：何を変え、何を守るか】

              現地の味に合わせる
                    ▲
                    │
  日清の海外カップ麺 │  現地メーカーの買収
  （味は全面的に別物）│  （ブランドごと現地のもの）
  ──────────────────┼──────────────────▶
  自社ブランドを      │              現地ブランドを
  そのまま使う        │              使う
                    │
  キッコーマンしょうゆ│  OEM・原料供給
  （味は変えず用途を │  （黒子に徹する）
   翻訳）            │
                    ▼
              日本の味を守る

  → どの象限が正解かは商品による。
    「味そのものが価値」なら左下、
    「カテゴリに入ること」が目的なら左上か右上。
```

現地化で実際に調整されるのは味だけではない。

| 調整項目 | 内容 |
| --- | --- |
| **味・辛さ・甘さ** | 同じブランドでも国ごとにレシピが違うのが普通 |
| **価格と容量** | 1回使い切りの小袋。1日の所得で買える価格帯に設計する（味の素の東南アジア展開が典型） |
| **宗教・食制限** | ハラール認証（イスラム圏）、ベジタリアン対応（インド）、コーシャ（ユダヤ教） |
| **表示・規制** | 現地語表示、添加物のポジティブリスト、栄養表示基準 |
| **流通チャネル** | 伝統的小売（パパママストア、露天）が主流の国では、少量・高頻度の配送網を自前で作る必要がある |

> ポイント：**海外展開のコストの大半は「工場」ではなく「販路」にある**。
> 工場は金を出せば建つ。しかし現地の小売網に商品を並べ、
> 消費者に習慣として定着させるには10年単位の時間がかかる。
> だからM&Aで現地企業を買うという選択（＝時間を買う）が合理的になる場面が多い。

## 8. 失敗のパターン

海外展開には典型的な失敗の型がある。

| 失敗の型 | 内容 |
| --- | --- |
| **日系向けで止まる** | 現地の日本食レストラン・日系スーパーだけで売れて満足してしまう。市場が小さく成長しない |
| **日本の味を押し付ける** | 「本物の味を教えてやる」という発想。現地の食習慣に居場所がないまま撤退 |
| **高すぎる価格設定** | 日本と同じ価格帯で売ろうとする。現地の所得水準に合わず、富裕層のニッチ商品で終わる |
| **販路を持たずに工場を建てる** | 生産能力が余り、固定費だけがのしかかる（→ [① 損益構造](01_食品メーカーの損益構造.md) 第5章の稼働率問題が海外で再現される） |
| **買収後の統合失敗** | 現地経営陣が離職、ブランドが毀損、のれん減損 |
| **地政学リスクの過小評価** | 特定国への集中。政変・規制強化・輸入停止で一気に失う |

近年の具体例として、日清食品HDは2026年3月期に**米国の一部地域で即席麺の販売が低迷**し、
インフレによる消費減速と**韓国製品の台頭による競争激化**を理由に海外利益の見通しを引き下げた
（2025年11月の下方修正時点。報道ベース）。
**「海外に出れば安泰」ではなく、海外でも現地競合との競争は激しい**ことを示す例といえる。

## 9. まとめ：この章を理解する3つの鍵

1. **国内の数量は構造的に縮む**。人口×食事回数×単価のうち、動かせるのは単価だけ。
   だから成長戦略は「単価・M&A・海外」の3択になり、真の成長は海外にしかない。
2. **海外で勝った会社は、日本食を輸出したのではなく現地の食文化に居場所を作った**。
   キッコーマンのテリヤキ、味の素の小袋、日清の現地味。いずれも日本の味そのものではない。
3. **輸出 → 現地生産 → 現地商品化の3段階には各10年かかる**。
   だからM&Aで時間を買う選択が合理的になる。ただし統合の失敗リスクは高い。

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **海外売上比率** | 連結売上に占める海外の割合。ただし「所在地別」「顧客の所在地別」「海外セグメント」で定義が異なり、会社間の単純比較には注意が必要 |
| **クロスボーダーM&A** | 国境をまたぐ企業買収。販路・ブランド・生産拠点をまとめて取得でき、時間を買える |
| **のれん（減損）** | 買収額が買われた会社の純資産を上回る部分。買収後に期待した収益が出ないと減損（一括で損失計上）になる |
| **六次産業化** | 一次産業（生産）×二次産業（加工）×三次産業（流通・販売）を一体でやること。原料確保と付加価値取り込みが狙い |
| **ハラール** | イスラム法で許される食品であることの認証。豚由来原料・アルコールの排除、製造ラインの分離などが求められる |
| **伝統的小売（TT）／近代的小売（MT）** | 個人商店・露天など従来型の小売／スーパー・コンビニなどチェーン型の小売。新興国ではTTの比率が高く、専用の配送網が必要になる |
| **ABF（味の素ビルドアップフィルム）** | 味の素が展開する半導体パッケージ用の層間絶縁フィルム。食品会社が発酵・化学技術を電子材料に横展開した代表例 |
| **マイナスサム** | 参加者全体の取り分が縮んでいく競争。縮小市場でのシェア争いはこれになりやすい |
