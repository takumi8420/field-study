# ① 食品メーカーの損益構造

このノートで分かること：食品メーカーの決算書が**どういう形をしているか**、
そしてなぜ「売上は過去最高なのに利益は減った」という決算が毎年のように出るのか。

## 1. 結論：食品メーカーは「相場と為替の下請け」である

食品メーカーの損益を一言でまとめると、こうなる。

> **売上の6〜7割が原材料費と製造費でまるごと消える。残りの大半を販促費が持っていく。
> だから営業利益率は5〜8%に落ち着く。そして最大の費目である原材料費は、自分では決められない。**

自動車や機械なら、部品メーカーに「来期は3%下げてくれ」と言える。
食品メーカーの相手は小麦・大豆・カカオ・原油・原乳であり、**交渉相手が市場である**。
小麦はシカゴ相場と政府売渡価格、カカオはロンドン・ニューヨーク相場、
原油は包装資材（プラスチックフィルム）と物流費に効いてくる。
しかも輸入原料が多いので、**相場が動かなくても円安になれば円建ての仕入は上がる**。

この「コストの入口が他人任せ、出口（店頭価格）も小売任せ」という挟み撃ちが、
食品メーカーの損益構造を理解する出発点になる。

```
【食品メーカーが挟まれている構図】

   相場・為替              自社                小売
  ┌──────────┐        ┌──────────┐      ┌──────────┐
  │ 小麦・大豆 │        │ 工場     │      │ スーパー │
  │ カカオ     │ ─────▶│ 研究開発 │─────▶│ コンビニ │──▶ 消費者
  │ 原乳・原油 │  仕入  │ ブランド │ 出荷 │ ドラッグ │
  │ 円安       │        └──────────┘      └──────────┘
  └──────────┘             ▲                    │
       ▲                    │                    │
       │                    └──── 値上げ交渉 ────┘
   コントロール不能            数か月〜半年かかる
                              （この時間差が赤字を生む）
```

## 2. 売上100円の分解

上場食品メーカー数社の決算を平均的にならすと、おおよそ次の姿になる
（各社IRの2025〜2026年3月期をもとにした概算。カテゴリで大きくぶれる点は第7章で扱う）。

```
【売上 100円の行き先（加工食品メーカーの標準的な姿）】

 売上高 100.0
  │
  ├─ 売上原価  62〜70  ────────────────────────────┐
  │    ├─ 原材料費       40〜50 ◀ここが最大。相場と為替に直撃
  │    ├─ 包装資材費      5〜8  ◀原油・紙パルプ連動
  │    ├─ 工場人件費      5〜7  ◀固定費。減らせない
  │    └─ 減価償却・光熱   4〜6  ◀固定費。稼働率が落ちると単価が跳ねる
  │
  ├─ 売上総利益（粗利） 30〜38
  │    │
  │    └─ 販売費及び一般管理費 24〜31
  │         ├─ 販売促進費・広告宣伝費  8〜14 ◀リベート・特売負担・CM
  │         ├─ 物流費（保管・配送）    5〜8  ◀2024年以降じわじわ増
  │         ├─ 営業人件費              5〜7
  │         └─ 研究開発費              1〜2  ◀製薬と比べ桁違いに小さい
  │
  └─ 営業利益  5〜8  ← ★この水準が食品メーカーの相場観
```

ここから読み取るべきことは3つある。

- **粗利率は意外と高い（30%台）**。食品卸の粗利6〜9%と比べれば5倍近い。
  ブランドと製法が模倣しにくいので、そこまでは取れる。
- **しかし販管費でほとんど食われる**。とくに販促費が重い（→ 第4章）。
- **研究開発費が売上の1〜2%しかない**。医薬品（15〜20%）と比べると極端に小さい。
  食品の「開発」は新薬開発ではなく、**味の設計と製造ラインへの落とし込み**なので、
  費用は人件費と試作費が中心になる。

## 3. 原材料費 ― なぜ「相場と為替に直撃される」のか

### 3.1 原料の三層構造

食品メーカーが買う原料は、価格の決まり方で3つに分かれる。

| 層 | 例 | 価格の決まり方 | メーカーが打てる手 |
| --- | --- | --- | --- |
| **国際商品（コモディティ）** | 小麦、大豆、とうもろこし、砂糖、カカオ、コーヒー豆、パーム油 | シカゴ・ロンドン・NYの先物相場＋海上運賃＋為替 | 先物・為替の**ヘッジ**（数か月〜1年先まで買い付けて価格を固定）。時間を買うだけで、水準は変えられない |
| **国内の制度価格** | 輸入小麦（政府売渡価格）、原乳（指定団体との年次交渉）、砂糖（調整金制度） | 政府・生産者団体との**年1〜2回の改定** | 改定のタイミングが読めるので、値上げ発表を合わせやすい |
| **加工中間品** | 食用油、糖化製品（異性化糖）、乳原料、調味料ベース、包装フィルム | 上流メーカーとの個別交渉 | 複数購買、スペック変更、規格見直し |

> ポイント：**「原料の値上がり」と「メーカーの決算悪化」の間には必ずヘッジ期間分のズレがある。**
> 相場が上がった瞬間に決算が悪くなるのではなく、**ヘッジしていた在庫が切れた四半期に一気に来る**。
> 「なぜ今ごろ？」という決算悪化の多くはこれが原因。

### 3.2 為替の効き方

輸入依存度が高い品目（小麦は約9割、大豆は約9割超、カカオ・コーヒーはほぼ全量が輸入）では、
**円安はそのまま原価上昇になる**。しかも二重に効く。

```
【円安が食品メーカーの損益に効く2つの経路】

  ① 直接経路（原料の円建て価格が上がる）
     小麦が同じ1ドルでも、140円/ドル → 160円/ドル なら +14%

  ② 間接経路（エネルギー・物流・包装が上がる）
     原油の円建て価格 ↑ → 燃料費 ↑ → 配送運賃 ↑
                        → 樹脂・フィルム ↑ → 包装資材費 ↑

  ※ 海外売上比率が高い会社（キッコーマン、味の素等）は
    ③ 換算経路（海外子会社の利益を円に直すと膨らむ）で + に働き、相殺される
```

だから同じ「円安」でも、**国内内需型メーカーには逆風、海外比率の高いメーカーには追い風**になる。
この非対称が、決算の明暗を分ける大きな要因になっている（→ [④ 国内成熟と海外展開](04_国内成熟と海外展開.md)）。

## 4. 販促費とリベート ― 粗利を削る最大の犯人

食品メーカーの販管費でいちばん重いのが販売促進費である。中身は大きく次の4つ。

| 費目 | 何にいくら払うか | 性格 |
| --- | --- | --- |
| **リベート（販売報奨金）** | 卸・小売に対して、取引数量や販促実績に応じて**あとから払い戻す**金銭 | 表向きの価格（建値）を崩さずに実質価格を調整する日本独特の商習慣。期末に条件が動く |
| **特売協賛金・チラシ協賛** | 「298円セール」をやるときに、値引き分の一部をメーカーが負担する | 販売数量と引き換え。断ると棚から落ちるリスク |
| **広告宣伝費（CM・デジタル）** | テレビCM、Web広告 | ブランド投資。削ると3年後に効いてくるので削りにくい |
| **新商品の導入費用（新規導入協賛）** | 新商品を棚に置いてもらうための一時金・サンプル | 新商品を出すほど増える固定的な出費 |

リベートと特売協賛は**会計上「売上から控除」される場合と「販管費」に計上される場合があり、
会社によって見え方が違う**。だから他社と粗利率を単純比較すると誤読する。
「A社の粗利は38%、B社は28%」の差の一部は、**販促費をどこに置いているかの違い**でしかないことがある。

> ポイント：食品メーカーの「実質的な販売価格」は、建値ではなく
> **建値 − リベート − 特売協賛 − センターフィー等の負担** で決まる。
> 表の価格を上げても、リベート条件を積み増されれば実入りは増えない。
> 値上げ交渉の本番はここにある（→ [② 値決めと交渉](02_値決めと交渉.md)）。

リベートやセンターフィー（小売の物流センター利用料）が卸・小売との間でどう流れているかは、
[食品卸ノート①](../../06_商社・卸売/06_食品卸/01_食品卸は何をしているか.md) に詳しい。
本ノートは**払う側＝メーカーの目線**で扱っている。

## 5. 工場の稼働率と固定費 ― 数量が減ると利益が急に消える

食品工場は**装置産業**である。充填ライン、殺菌設備、冷凍設備、クリーンルーム。
一度建てると、動かそうが止めようが減価償却費と保全人員の費用は発生する。

```
【稼働率と1個あたり製造原価（固定費20円/月・生産能力100万個の工場のイメージ）】

 稼働率   生産量      固定費÷生産量    変動費    製造原価/個
 100%    100万個  →      20.0円      + 60円  =  80.0円
  80%     80万個  →      25.0円      + 60円  =  85.0円   ← +6%
  60%     60万個  →      33.3円      + 60円  =  93.3円   ← +17%
  50%     50万個  →      40.0円      + 60円  = 100.0円   ← +25% 赤字圏

 → 売価が変わらなくても、数量が2割落ちるだけで粗利が吹き飛ぶ
```

ここに食品固有の事情が2つ重なる。

- **季節性が大きい**。アイス・清涼飲料は夏、鍋つゆ・おでんは冬。
  年間の山と谷の差が2倍以上になる品目があり、**谷の時期の稼働率が損益を決める**。
- **多品種少量化が進んだ**。SKU（商品の種類）が増えると段取り替え（品種切替時の洗浄・調整）が増え、
  同じ稼働時間でも実質の生産量が落ちる。だから各社は近年**アイテム数の削減**に動いている。

だから食品メーカーの構造改革は、ほぼ必ず「**工場の統廃合と生産ラインの集約**」という形を取る。
これは製造業共通の論理で、[製粉・製糖・製油](../02_製粉・製糖・製油/README.md) のような
素材型ではさらに極端に効く。

## 6. 賞味期限と在庫 ― 「作りすぎ」が直接損失になる

食品は時間が経つと売れなくなる。この当たり前の性質が、損益に3つの形で効く。

| 仕組み | 内容 | 損益への効き方 |
| --- | --- | --- |
| **1/3ルール** | 製造日から賞味期限までを3等分し、最初の1/3以内に小売へ納品する商習慣。超えると納品できない | 出荷できなかった在庫は値引き販売か廃棄。**メーカーの負担**になる |
| **返品** | 小売・卸から戻ってくる商品。リニューアルやパッケージ変更時に大量発生 | 返品分は売上のマイナス＋廃棄費用の二重負担 |
| **需要予測の外れ** | 天候・話題性で需要が読みにくい。品切れを恐れて多めに作りがち | 過剰生産 → 廃棄。逆に不足 → 欠品ペナルティと機会損失 |

近年は農林水産省が納品期限の緩和（1/3 → 1/2）を業界に働きかけており、
在庫廃棄の削減が進みつつある。とはいえ**「欠品は許されないが余らせたら自腹」**という
非対称な力関係は、そう簡単には変わらない。

この「1/3ルール」がどこで誰の負担になっているかは
[食品卸ノート①](../../06_商社・卸売/06_食品卸/01_食品卸は何をしているか.md) と合わせて読むと立体的になる。

## 7. カテゴリ別に利益率はこれだけ違う

「食品メーカーの営業利益率は5〜8%」は平均の話で、実際はカテゴリで大きく違う。

| カテゴリ | 営業利益率の目安 | なぜそうなるか | 例 |
| --- | --- | --- | --- |
| 調味料・ソース | 8〜13% | 少量で高頻度に買われ、ブランド指名が強い。単価に対して原料が軽い | [調味料](../03_調味料/README.md) |
| 製菓（チョコ・ビスケット） | 5〜10% | ブランド力は高いが、カカオ・乳・砂糖の相場直撃度が最も高い | [製菓](../05_製菓/README.md) |
| 即席麺 | 7〜12% | 保存性が高く物流が楽。海外展開しやすい | [即席麺](../07_即席麺/README.md) |
| 乳業（牛乳・ヨーグルト） | 3〜6% | 原乳価格が制度で決まり、日持ちしないので在庫調整が効かない | [乳業](../04_乳業/README.md) |
| 製粉・製糖・製油 | 2〜5% | 差別化しにくい素材型。相場の転嫁が価格の大半 | [製粉・製糖・製油](../02_製粉・製糖・製油/README.md) |
| 冷凍食品・惣菜 | 3〜7% | 冷凍物流コストが重い。業務用は価格競争が激しい | [冷凍食品・惣菜](../06_冷凍食品・惣菜/README.md) |
| 飲料 | 3〜8% | 自販機・容器コストが重く、物流比率が高い（重くてかさばる） | [清涼飲料](../09_清涼飲料/README.md) |

> ポイント：**「原料費が売価に占める割合」と「ブランド指名の強さ」の2軸で利益率はほぼ説明できる。**
> 醤油1本の原料費は数十円、店頭は数百円。だから調味料は利益率が高い。
> 小麦粉1kgの原料費は売価の大半を占める。だから製粉は薄い。

## 9. 値上げが利益に効くまでの時間差

食品メーカーの決算を読むうえで最も大事な感覚が、この**タイムラグ**である。

```
【原料が上がってから利益が戻るまで（典型例）】

 0か月   原料相場が上昇／円安が進行
   │     （ヘッジ在庫があるので損益にはまだ出ない）
   ▼
 2〜4か月 ヘッジ在庫が切れ、仕入単価が上がり始める
   │     ★ここから粗利率が落ちる＝決算悪化が表面化
   ▼
 3〜5か月 値上げを対外発表（多くは3〜4か月前に事前通告）
   │     小売・卸と交渉。証拠資料（原料伝票・指数）を示す
   ▼
 6〜9か月 実際の出荷価格が改定される
   │     ただし初月は特売・在庫処分で旧価格の商品が店頭に残る
   ▼
 9〜12か月 値上げ効果が損益に完全に乗る
         ただし数量は数%落ちている（買い控え・PBへの流出）

 → 原料上昇から利益回復まで、実質的に 半年〜1年 かかる
   この間に次の原料上昇が来ると、永久に追いつかない（＝2022年以降の状況）
```

この図が、冒頭の問い「なぜ売上最高なのに利益が減るのか」の答えになっている。
**値上げは効くが、遅れて効く。** そして遅れている間に次のコスト上昇が来る。
値上げの実務そのものは [② 値決めと交渉](02_値決めと交渉.md) で詳しく扱う。

## 10. まとめ：この損益構造を理解する3つの鍵

1. **原材料費が原価の大半**。相場と為替に直撃され、自分では決められない。
   ヘッジは「時間を買う」だけで、水準は変えられない。
2. **粗利30%台を販促費が削り、営業利益率5〜8%に落ち着く**。
   リベート・特売協賛という日本独特の商習慣が、表の値上げを実質化させない。
3. **固定費（工場）と賞味期限（在庫）が数量減に弱い**。
   値上げで数量が落ちると、稼働率低下と在庫廃棄で二重に効く。だから値上げは怖い。

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **建値（たてね）** | メーカーが公式に定める卸・小売向けの基準価格。実際の取引価格はここからリベートや値引きを引いた額になるため、建値は「表向きの定価」に近い → [②](02_値決めと交渉.md) |
| **リベート（販売報奨金）** | 取引数量や販促実績に応じて、メーカーが卸・小売へ**あとから払い戻す**金銭。建値を崩さずに相手ごとの実質価格を変えるための仕組み |
| **ヘッジ** | 先物や為替予約で将来の仕入価格をあらかじめ固定すること。価格変動の「時間差」を作れるが、水準そのものは変えられない |
| **1/3ルール** | 製造日から賞味期限までを3等分し、最初の1/3以内に小売へ納品する商習慣。超過分はメーカー・卸の負担になりやすい |
| **SKU（エスケーユー）** | Stock Keeping Unit。味・容量・パッケージ違いまで数えた商品の最小管理単位。SKUが増えるほど工場の段取り替えと在庫が増える |
| **段取り替え** | 生産ラインで作る品種を切り替える作業（洗浄・設定変更）。この間ラインは止まるので、多品種化は実質的な稼働率を下げる |
| **売上原価率／粗利率** | 売上に対する原価の割合／その裏返し。食品メーカーの粗利率は30〜38%が目安だが、販促費の計上場所で会社ごとにぶれる |
| **装置産業** | 設備投資が大きく固定費比率が高い産業。稼働率が下がると1個あたり原価が跳ね上がる |
