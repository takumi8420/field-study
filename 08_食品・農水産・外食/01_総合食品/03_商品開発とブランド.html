このノートで分かること：食品メーカーがなぜ毎年何百もの新商品を出しては消えていくのか、
それでも各社の売上の大半を何十年も前に出た商品が稼いでいるのはなぜか。

1. 結論：新商品は「消える前提」で作られ、利益は「定番」が稼ぐ

食品業界の商品開発には、他の産業から見ると奇妙に映る構造がある。

新商品の大半は1年以内に店頭から消える。それを知りながら、各社は大量に新商品を投入し続ける。
そして売上と利益の大半は、数十年前に発売されたロングセラーが稼いでいる。

一見すると壮大な無駄に見える。だがこれは合理的な行動である。理由は次章で見る「棚の論理」にある。

【食品メーカーの売上を支える構造（イメージ）】

  売上
   ▲
   │  ┌──────────────────────────────┐
   │  │                              │
   │  │  ロングセラー（定番）        │  売上の 60〜80%
   │  │  発売10年以上、毎年ほぼ一定  │  利益貢献はさらに高い
   │  │                              │  （広告も開発も償却済み）
   │  ├──────────────────────────────┤
   │  │  準定番（発売3〜10年）       │  売上の 15〜25%
   │  ├──────────────────────────────┤
   │  │ 新商品（1年以内）▲▽▲▽▲▽   │  売上の 5〜15%
   │  └──────────────────────────────┘  大半は翌年には無い
   └────────────────────────────────────▶ 時間

2. なぜ「消える前提」で大量に出すのか ― 棚の論理

答えは、新商品を出さないと棚（＝売場の陳列スペース）を失うからである。

スーパーやコンビニは、年に2回（春・秋）の棚替えで商品構成を見直す。
このとき小売のバイヤーは「売れていない商品を落とし、新しい提案を入れる」判断をする。
ここで新商品を提案できないメーカーは、棚の面積を削られる。

【棚替えのサイクルと新商品の役割】

  春の棚替え（3月頃）            秋の棚替え（9月頃）
        │                              │
        ▼                              ▼
  ┌─────────────┐              ┌─────────────┐
  │ A社 定番 3枠│              │ A社 定番 3枠│
  │ A社 新商品 1│─ 売れず撤去 ─▶│ A社 新商品 1│← 別の新商品
  │ B社 定番 2枠│              │ B社 定番 2枠│
  │ C社 新商品 1│              │ C社 定番 2枠│← 提案なしのD社の枠を奪取
  │ D社 定番 2枠│              │             │
  └─────────────┘              └─────────────┘

  → 新商品は「売るため」だけでなく
    「棚の面積を守り、他社の枠を奪うため」の手段でもある

新商品にはもうひとつ役割がある。定番の値上げを通すための材料である。
「新商品Xを一緒に出しますので、既存品の改定もお願いします」という交渉は、
食品業界では日常的に行われている（→ ② 値決めと交渉）。

ただしこの構造にも変化が出ている。
2024年12月の報道によれば、食品の新商品数は5年前（2019年）比で約2割減。
物価高で生産・物流コストが上がったため、各社が新商品を絞り、
定番品に経営資源を集中する方向へ転換しているとされる（日本経済新聞、2024年12月）。

新商品を出す理由 新商品を絞る理由（近年）
棚の面積を確保・拡大する新規導入協賛金（棚に置いてもらう一時金）が重い
値上げ交渉の材料になるSKU（商品の種類）増加で工場の段取り替えが増え、稼働率が落ちる
消費者の飽きを防ぎ、カテゴリ全体を活性化する在庫・廃棄のリスクが増える
流行を捉えて次の定番を育てる定番のほうが利益率が高い（開発費・広告費が償却済み）

3. ロングセラーはなぜ強いのか

各社の主力は、驚くほど古い。以下は代表例（発売年は各社公表ベース）。

商品 メーカー 発売年 なぜ生き残ったか
味の素（うま味調味料）味の素1909年家庭の調理習慣そのものに組み込まれた
カルピスアサヒ飲料1919年「希釈して飲む」という独自の体験。贈答需要
キユーピー マヨネーズキユーピー1925年味の基準そのものになった。代替品が「マヨネーズ風」に見える
明治ミルクチョコレート明治1926年パッケージと味の一貫性。世代を超えた記憶
チキンラーメン日清食品1958年即席麺というカテゴリ自体の創出者
かっぱえびせんカルビー1964年「やめられない、とまらない」で食べ方を定義
ポッキー江崎グリコ1966年手が汚れない構造。派生商品を無限に作れる
ボンカレー大塚食品1968年世界初の市販レトルトカレー。温めるだけという新習慣
カップヌードル日清食品1971年容器・調理・喫食を一体で発明。世界展開の基盤

ロングセラーが強い理由は、味が優れているからだけではない。

  • 習慣に組み込まれている — 「マヨネーズを買う」ではなく「キユーピーを買う」。
    指名買いされる商品は、小売も棚から外せない。外すと客が怒るから。
  • 広告費と開発費が償却済み — 新商品は初年度に大量の広告を打つが、
    定番は「思い出してもらう」程度の広告で足りる。だから利益率が構造的に高い。
  • 製造ラインが最適化されている — 数十年作り続けているので歩留まりが高く、原価が安い。
  • リニューアルで延命できる — 中身を少しずつ改良し、パッケージを更新する。
    「変わらない味」を守りながら実は少しずつ変わっている、というのが実態。

ポイント：食品メーカーのブランドは、記憶と習慣という形で消費者の側に蓄積された資産である。
広告をやめても数年は売れ続けるが、10年やめれば世代交代で忘れられる。
だからロングセラーほど広告を止められないという逆説がある。

4. 商品開発のプロセス

食品の商品開発は、研究所だけの仕事ではない。工場と営業が最初から関わるのが特徴。

【新商品ができるまで（加工食品の標準的な流れ：12〜18か月）】

 ① 企画（コンセプト）        2〜3か月
    「誰が、どんな場面で、なぜ買うか」を定義
    市場調査、競合分析、価格帯の設定
        │
 ② 試作（レシピ開発）        3〜6か月
    研究所で小ロット試作 → 社内官能評価（味の採点）
    消費者調査（ブラインドテストで既存品と比較）
        │
 ③ 工業化（ここが難所）      3〜6か月
    ★研究所の鍋で作れた味を、1時間に数万個作る設備で再現できるか
    ・加熱時間、殺菌条件、充填速度の設定
    ・賞味期限の設定（保存試験を実際の期間ぶん走らせる必要がある）
    ・原料の安定調達（同じ品質の原料を年間通じて確保できるか）
        │
 ④ 包装・表示設計            2〜3か月
    パッケージデザイン、原材料表示、栄養成分表示、アレルゲン表示
    （食品表示法の適合確認。誤りがあれば回収になる）
        │
 ⑤ 営業提案・商談            3〜4か月（③④と並行）
    ★小売バイヤーへの提案 → 採用の可否がここで決まる
    採用されなければ、ここまでの投資はすべて無駄になる
        │
 ⑥ 発売・初回投入
    初回受注量に合わせて生産。売れ行きを2〜3か月で判定
        │
 ⑦ 次の棚替えで生死が決まる（発売6〜12か月後）

ポイント：工業化（③）が食品開発の最大の壁。
「試作品は美味しいのに量産すると別物になる」というのは日常茶飯事で、
加熱・殺菌・充填の条件が味と食感を変えてしまう。
だから食品メーカーの研究職は「味を作る人」であると同時に「設備で再現できる味を設計する人」である。
この工業化ノウハウこそが、レシピを真似されても簡単に追随されない参入障壁になっている。

5. カテゴリ別の競争構造 ― 寡占の分野と乱戦の分野

「食品業界」とひとくくりにされるが、カテゴリごとに競争の激しさは全く違う。

カテゴリ 競争構造 主なプレイヤー なぜそうなるか
しょうゆ寡占（首位が3割超）キッコーマン、ヤマサ、ヒゲタ、正田全国ブランドの信頼と製造設備。地方の小規模蔵は多数あるが全国流通しない
マヨネーズ寡占（上位2社で大半）キユーピー、味の素味が基準化され、指名買いが極端に強い
即席麺寡占（上位4社で大半）日清食品、東洋水産、サンヨー食品、エースコックブランドと販促投資の規模がものを言う
ビール類寡占（上位4社でほぼ全量）アサヒ、キリン、サントリー、サッポロ酒税・免許・全国の物流と営業網
うま味調味料実質独占に近い味の素発酵技術と生産規模
チョコレート数社の競合明治、ロッテ、森永製菓、江崎グリコブランドは強いが参入は可能。カカオ相場が共通の逆風
パン首位が突出＋地域勢山崎製パン、敷島製パン、フジパン＋地場日配品（毎日配送）なので物流圏が競争範囲を決める

惣菜・中食極端な乱戦中小多数＋小売のインストア地域性が強く、規模の経済が効きにくい
米飯・パックご飯数社サトウ食品、テーブルマーク他設備投資が重く新規参入しにくい

6. 健康志向と機能性表示食品

国内の数量が伸びない中で、各社が単価を上げる手段として力を入れてきたのが健康訴求である。
日本の「健康にいいと言える食品」の制度は3階建てになっている。

制度 誰が認めるか ハードル 例
特定保健用食品（トクホ）消費者庁が製品ごとに個別許可高い。ヒト試験が必要で、許可まで数年・数億円かかることも「血圧が高めの方に」など
栄養機能食品国の規格基準に適合すれば届出不要低い。表現できる内容は決められた栄養素の定型文のみ「カルシウムは骨や歯の形成に必要な栄養素です」
機能性表示食品事業者が科学的根拠を消費者庁に届出（許可制ではない）中程度。既存の論文レビューでも可「本品には◯◯が含まれます。◯◯には△△を助ける機能があることが報告されています」

2015年に始まった機能性表示食品は、届出制で費用と時間が抑えられるため急速に広がった。
一方で2024年の健康被害事案を受けて制度が厳格化されている。

  • 2024年9月1日：改正が施行。健康被害情報の報告義務化などが実施された。
  • 2026年9月1日：GMP（適正製造規範）に基づく製造管理が義務化（2年間の猶予期間を経て完全施行）。
    対象は「天然抽出物等を原材料とする錠剤、カプセル剤等食品」。
    錠剤・カプセルを作る工場と一次包装工場が管理対象で、二次包装工場は対象外。
  • 2026年9月1日：届出情報の表示方法の改正も実施。
    容器包装の主要面の上部に「機能性表示食品」の文字を枠で囲んで表示し、
    届出番号を近接した箇所に表示することが必要になる。
  • 届出者には年1回、製造・品質管理等の遵守状況を自己点検して消費者庁へ報告する義務が課された。

ポイント：機能性表示食品は「規制が緩いから広がった」市場だったが、
2024〜2026年の制度厳格化で体力のある企業しか続けられない領域に変わりつつある。
錠剤・カプセル型サプリメントの小規模事業者には重い負担で、淘汰が進むとみられる。

7. 少子高齢化と食のトレンド

国内市場の中身は、人口構成の変化でゆっくり、しかし確実に変わっている。

変化 中身 メーカーの対応
世帯人数の縮小単身・2人世帯が多数派に。大容量が売れない小容量・個包装への切替。ただし包装費比率が上がり原価は悪化する
高齢化咀嚼・嚥下しやすい食品、減塩、たんぱく質摂取のニーズ介護食・スマイルケア食、高たんぱく商品
共働きと時短調理時間を短くしたい。中食の利用増冷凍食品、レンジ調理、合わせ調味料、ミールキット
タイパ・個食化家族が別々のものを食べる1人前パック、多品種少量
健康と減塩・減糖生活習慣病予防への関心減塩しょうゆ、糖質オフ、機能性表示食品
インバウンドと和食ブーム訪日客の食体験が輸出需要につながる海外向け商品開発 → ④ 国内成熟と海外展開

ポイント：少子高齢化は「量が減る」だけでなく「1個あたりが小さくなる」ことが問題である。
同じ100gを売るのに、500g×1袋から100g×5袋になると、包装資材費と充填工数が5倍になる。
人口減少による数量減と、小容量化による原価上昇が同時に来るのが国内市場の厳しさの正体。

8. まとめ：この章を理解する3つの鍵

  1. 新商品は棚を守るための手段でもある。大半は1年で消えるが、出さなければ面積を削られる。
    ただし近年はコスト高で新商品数が絞られ、定番集中へ揺り戻しが起きている。
  2. 利益はロングセラーが稼ぐ。広告・開発が償却済みで、習慣として指名買いされるから。
    一方でブランドは記憶の資産なので、広告を止めると世代交代で消える。
  3. カテゴリで競争構造が全く違う。ブランド指名の強さ×参入障壁の高さで、寡占か乱戦かが決まる。
    この2軸が各社の利益率をほぼ説明する。

用語メモ

用語 意味
棚替え（たなかえ）／棚割り小売が売場の商品構成と陳列位置を見直すこと。年2回（春・秋）が一般的。ここで採否が決まる
定番（じょうばん）常時棚に置かれる商品。対義は特売品・季節品。「定番落ち」＝棚から外されること
新規導入協賛（導入費）新商品を棚に置いてもらう際にメーカーが小売へ支払う一時金
工業化研究所で作った試作品を、量産設備で同じ品質で作れるようにする工程。食品開発の最大の難所
官能評価訓練された評価者が味・香り・食感を点数化する手法。食品開発の中核となる検査
日配品（にっぱいひん）パン・牛乳・惣菜など毎日配送が必要な短期日配商品。物流圏が競争範囲を決める
トクホ（特定保健用食品）消費者庁が製品ごとに個別許可する健康強調表示制度。ヒト試験が必要でハードルが高い
機能性表示食品事業者が科学的根拠を消費者庁に届け出ることで機能性を表示できる制度（2015年開始）。許可制ではない
GMP（適正製造規範）Good Manufacturing Practice。製造・品質管理の基準。機能性表示食品では2026年9月1日から錠剤・カプセル等で義務化
SKUStock Keeping Unit。味・容量・パッケージ違いまで数えた商品の最小管理単位
