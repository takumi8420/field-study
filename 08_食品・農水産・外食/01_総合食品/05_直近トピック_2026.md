# ⑤ 直近トピック（2026年9月時点）

報道・公表資料ベースの整理。数値は必ず年月とセットで読むこと。
確定した制度と、まだ「方針」「見込み」の段階のものを区別して書いている。

## 1. 食品値上げは5年目へ ― 2026年も年2万品目超が確実

2022年に始まった食品の値上げは、2026年になっても止まっていない。

| 時点 | 値上げ品目数 | 補足 |
| --- | --- | --- |
| 2025年 通年 | **20,609品目** | 帝国データバンク「食品主要195社」価格改定動向調査 |
| 2026年 1〜11月 判明分 | **19,083品目** | 年間2万品目超は確実とされる |
| 2026年4月 | **2,798品目** | 分野別ではマヨネーズ・ドレッシング等の「調味料」が**1,514品目**で最多 |
| 2026年8月 | **2,311品目** | 前年同月比で約8割増。「中東発」の資材・エネルギー高が本格化 |
| 2026年9月 | **4,531品目** | **2026年内で最多**。単月4,000品目超は**2023年10月（4,758品目）以来、約3年ぶり** |
| 2026年10月 | **2,720品目**（判明分） | 秋にかけて継続の見通し |

（いずれも帝国データバンクの集計。同社は毎月末に翌月以降の判明分を公表している）

```
【値上げの「波」の推移（品目数・年ベース／帝国データバンク集計）】

 2022年  ████████████████████████    約 2.5万品目  第1波：原料高＋急激な円安
 2023年  ███████████████████████████ 約 3.2万品目  第2波：過去最大。エネルギー・物流も
 2024年  ██████████                  約 1.2万品目  いったん沈静化
 2025年  ████████████████████        20,609品目    第3波：再加速（コメ・カカオ・コーヒー）
 2026年  ████████████████████〜      2万品目超が確実 第4波：資材・人件費が主因に

 ※2022〜2024年の数値は各年の同社公表の概数。
   波ごとに「何が上がったか」が違う点が重要。
```

**2026年の値上げは、これまでと理由が変わってきている。**

- 2022〜2023年は**原材料相場と円安**が主因だった。
- 2025年は**コメ・カカオ・コーヒーといった特定品目の不作**が加わった。
- 2026年は、原材料高に加えて**包装資材・物流費・人件費（賃上げ）**という
  「構造的なコスト」が前面に出ている。中東情勢を背景とした
  樹脂・フィルムなど包装資材の値上げも報じられている。

> **原材料由来の値上げは「相場が下がれば止まる」が、人件費・物流費由来の値上げは戻らない。**
> だから2026年以降の値上げは、これまでより**粘着質（一度上がったら下がらない）**になる。
> [② 値決めと交渉](02_値決めと交渉.md) で見た「労務費の転嫁率30%」という数字が、この局面の焦点になる。

## 2. 最大の変数 ― 飲食料品の消費税を2027年4月から1%へ

2026年の食品業界にとって最も大きな出来事は、値上げそのものより**税制**かもしれない。

**2026年9月15日の臨時閣議**で「飲食料品消費税率の臨時的な引下げ及び
就業者負担軽減支援金の導入に関する大綱」が決定された（政府公表・報道ベース）。

| 項目 | 内容 |
| --- | --- |
| 対象 | 軽減税率の対象となっている飲食料品 |
| 税率 | **8% → 1%** |
| 期間 | **2027年4月1日 〜 2029年3月31日**（2年間の臨時措置） |
| 経緯 | 2026年8月5日に基本方針、同年9月15日に大綱を閣議決定 |
| なぜ0%でなく1%か | 0%にするとレジ・会計システムの改修が大規模になり、2027年4月の開始に間に合わないため（報道ベース） |
| 併設される措置 | 1%相当分（年約6,000億円規模とされる）の範囲内で、中低所得の就業者に「就業者負担軽減支援金」を支給し実質ゼロ化を図る |

食品メーカーにとっての意味を整理する。

```
【消費税1%が食品メーカーに与える3つの効果】

 ① 値上げの「窓」が開く（2027年4月）
    店頭税込価格が約7%下がる余地 → そこに値上げをぶつければ
    消費者の支払額はほぼ変わらない
    → ただし小売は「減税分は消費者に還元すべき」と主張する見込み。交渉は激化

 ② 駆け込みと反動が二度来る
    2027年3月  減税前なので買い控え → 4月に反動増
    2029年3月  税率が戻る前の駆け込み → 4月以降に大きな反動減
    → 生産計画・在庫計画が2回振り回される

 ③ 実務コストが発生する
    レジ・受発注・請求システムの税率改修、価格表示の切替
    → 中小食品メーカー・小売ほど負担が重い
```

> 注意：2026年9月時点では**大綱の閣議決定段階**であり、
> 実際の施行には法改正が必要。対象品目の細部（外食・テイクアウトの扱いなど）は
> 今後の法案審議で固まる。最新は財務省・国税庁の公表で確認すること。

## 3. 決算は「二極化」がはっきりした

値上げが続いているのに、食品メーカーの利益は改善していない。

| 指標 | 数値 | 年・出典 |
| --- | --- | --- |
| 食品メーカーの売上高合計 | **24兆2,824億円**（前年比 **+3.4%**） | 2025年（1〜12月期決算）。東京商工リサーチ、4,994社集計 |
| 同 利益合計 | **8,806億円**（前年比 **▲9.5%**） | 同上 |
| 黒字企業の割合 | **78.0%**（3,898社）／**減益企業は約46.1%** | 同上 |
| 利益の集中度 | 売上1,000億円以上の**41社**が利益合計の**55.5%**を稼ぐ | 同上 |
| 食品業の倒産件数 | **168件**（前年度比 **+13.5%**） | 2025年度。東京商工リサーチ |

```
【なぜ「増収減益」になるのか】

  売上          ↑ +3.4%   値上げで名目は伸びた
   ├ 原材料費   ↑↑        相場高＋円安
   ├ 包装資材費 ↑↑        原油・中東情勢
   ├ 物流費     ↑↑        2024年問題以降の運賃上昇
   ├ 人件費     ↑↑        賃上げ（転嫁率は中央値30%にとどまる）
   └ 販促費     →↑        値上げ後の数量維持のため削れない
                          ────────────────
   利益         ↓ ▲9.5%

  さらに：値上げで数量が落ちる → 工場の稼働率低下 → 1個あたり固定費が上昇
         （→ ① 損益構造 第5章）
```

主要各社の2026年3月期（一部は見込み）を並べると、明暗がはっきり分かれる。

| 企業 | 売上 | 利益 | コメント |
| --- | --- | --- | --- |
| 味の素 | 売上高 **1兆5,837億円**（+3.5%） | 事業利益 **1,811億円**（前期比+218億円） | ヘルスケア等・調味料食品が牽引。電子材料も寄与 |
| 明治HD | 売上 **1兆1,736億円**（+1.7%） | 営業利益 **933億円**（+10.2%） | カカオ・原乳高に対し、**値上げ・内容量変更・原料変更**で対応 |
| 日清食品HD | 売上収益 **7,920億円**（+2%） | 営業利益 **605億円**（**▲18.6%**） | 米国の一部地域で即席麺が低迷。**韓国製品の台頭**による競争激化 |
| キッコーマン | 売上収益 **7,455億円** | ― | 海外売上比率 **約78%**、事業利益の約**90%**が海外 |

（各社決算短信・決算説明資料および報道ベース。日清食品HDの海外コア営業利益見込み351億円は2025年11月の下方修正時点）

> **同じ「値上げの年」でも、海外比率の高い会社は円安が追い風になり、
> 国内内需型の会社は原料高がそのまま逆風になる。** この非対称が二極化の正体
> （→ [④ 国内成熟と海外展開](04_国内成熟と海外展開.md)）。

## 4. 原材料相場 ― カカオ・コーヒーの高騰と、その先

2025〜2026年の値上げの主役は、相場が特殊な動きをした特定品目だった。

| 原料 | 動き | 影響を受ける分野 |
| --- | --- | --- |
| **カカオ** | 西アフリカの不作・病害を背景に高騰。2022年比で一時**約4倍**まで上昇したと報じられる。2026年に入り高値からの反落もみられるが、依然高水準 | チョコレート、菓子、アイス。市販チョコの平均販売単価は前年比+4.3%で推移（報道ベース） |
| **コーヒー豆** | 産地の天候不順で高騰 | レギュラーコーヒー、缶・ペットボトルコーヒー |
| **コメ** | 2024年の「令和のコメ騒動」以降の価格上昇。2026年は在庫の逆ザヤ局面も | パックご飯、米菓、外食 |
| **小麦・大豆** | 国際価格は高水準で推移。輸入小麦は政府売渡価格を通じて年2回改定 | パン、麺、油脂、調味料 |
| **包装資材（樹脂・フィルム・紙）** | 中東情勢とエネルギー価格を背景に値上げが継続 | 全カテゴリ。とくに小容量化が進む商品ほど比率が高い |

> ポイント：**カカオのように「代替が効かない単一原料」に依存する商品ほど打撃が大きい**。
> 小麦なら配合を変える余地があるが、チョコレートからカカオは抜けない。
> 各社は**容量変更・原料グレードの見直し・高カカオ路線への転換**で凌いでいるが、
> 相場が高止まりすれば、いずれ表示価格の改定に回らざるを得ない。

## 5. 価格転嫁を国が後押しする体制が定着した

| 時期 | 動き |
| --- | --- |
| 2023年11月 | 内閣官房・公取委「労務費の適切な転嫁のための価格交渉に関する指針」公表 |
| 2024年3月 | 公取委が、転嫁協議に応じなかった**事業者名を公表** |
| 2025年12月 | 「令和7年度価格転嫁円滑化の取組に関する特別調査」結果公表。独禁法上問題となりうる行為が認められた発注者**4,334名**に注意喚起文書 |
| 2026年1月 | 農水省・中小企業庁「食品製造業者・小売業者間における適正取引推進ガイドライン」**改定** |
| **2026年6月17日** | 公取委が「**令和8年度 価格転嫁円滑化・支払の適正化に関する調査**」の開始を公表。協議を経ない取引価格の据置き等が疑われる事案に**立入調査**を実施予定 |

転嫁率の実態（公取委 特別調査、令和7年度／2025年度、中央値）。

```
【コスト項目別の転嫁率（中央値）】

 原材料価格     ████████████████  80.0%   ← 伝票で証明できるので通りやすい
 エネルギー     ██████████        50.0%
 労務費         ██████            30.0%   ← 「御社の事情でしょう」と返されやすい

 → 賃上げが続く局面で、ここが食品メーカーの利益を静かに削る
```

## 6. 機能性表示食品のGMP義務化が2026年9月1日に完全施行

2024年の健康被害事案を受けた制度改正が、2026年9月にひと区切りを迎えた。

| 施行日 | 内容 |
| --- | --- |
| 2024年9月1日 | 改正施行。**健康被害情報の報告義務化**など |
| **2026年9月1日** | **GMP（適正製造規範）に基づく製造管理の義務化が完全施行**。2年間の猶予期間が終了。対象は「天然抽出物等を原材料とする錠剤、カプセル剤等食品」。錠剤・カプセルの製造工場と**一次包装工場**が対象（二次包装工場は対象外） |
| **2026年9月1日** | **届出情報の表示方法の改正**も実施。容器包装の主要面の上部に「機能性表示食品」の文字を枠で囲んで表示し、届出番号を近接した箇所に表示する |
| 継続的義務 | 届出者は製造・品質管理等の遵守状況を自ら点検し、**年1回消費者庁へ報告** |

> ポイント：機能性表示食品は「届出制で費用と時間が抑えられる」ことで広がった市場だった。
> 制度厳格化により、**GMP対応の設備・品質管理体制を持てる企業しか続けられない領域**に変わる。
> 錠剤・カプセル型サプリの小規模事業者には重い負担で、淘汰と受託製造（OEM）への集約が進むとみられる。
> なお**加工食品（飲料・ヨーグルト等）の機能性表示**はGMP義務化の直接対象外だが、
> 表示方法の改正は同じく適用される。

## 7. 輸出は過去最高を更新 ― 2025年 1兆7,005億円

| 指標 | 数値 | 年・出典 |
| --- | --- | --- |
| 農林水産物・食品の輸出額 | **1兆7,005億円**（前年比 **+12.8%**） | 2025年。農林水産省「2025年の農林水産物・食品の輸出実績」 |
| 政府目標 | 2030年に **5兆円** | 農林水産省「農林水産物・食品の輸出拡大実行戦略」 |

円安、和食人気、インバウンドを通じた認知拡大が重なり、過去最高を更新している。
ただし目標の5兆円に対しては現状の3倍超が必要で、達成にはハードルがある。
また**相手国の輸入規制が突発的に変わるリスク**は依然として大きい。

## 8. 全体の構図

2026年9月時点の食品メーカーを一枚でまとめると、こうなる。

```
【2026年の食品メーカーが置かれた位置】

  ▼ 入口（コスト）              ▼ 出口（価格）
  ┌────────────────┐          ┌────────────────┐
  │ カカオ・コーヒー│          │ 値上げ第4波     │
  │ 包装資材（中東）│ ──────▶ │ 2026年 2万品目超│──▶ 消費者の買い控え
  │ 物流費（24年〜）│  挟撃    │ 9月は年内最多   │     PBへの流出
  │ 賃上げ（転嫁30%）│          └────────────────┘
  └────────────────┘                  ▲
                                        │
                              ┌─────────────────┐
                              │ 政策の後押し     │
                              │ ・公取委の転嫁調査│
                              │ ・適正取引GL改定 │
                              │ ・消費税1%(27年4月)│← 新しい「窓」
                              └─────────────────┘

  結果： 売上 +3.4% / 利益 ▲9.5%（2025年、TSR）
        利益の55.5%を大手41社が占める＝二極化
        中小は倒産増（2025年度168件、+13.5%）
```

1. **値上げは5年目に入り、理由が「原料」から「人件費・資材」へ移った**。
   後者は相場が下がっても戻らないため、値上げは粘着的になる。
2. **値上げしても利益は出ていない**。2025年は増収減益で、利益は大手41社に集中。
   規模がコスト吸収力を決める構造が鮮明になった。
3. **国は価格転嫁を後押しする側に回ったが、労務費の転嫁率は30%にとどまる**。
   次の交渉の焦点はここ。
4. **2027年4月の消費税1%が最大の変数**。店頭価格が下がる余地に値上げをぶつけられるが、
   小売との綱引きになる。2029年4月の税率戻りまで含めて、2回の需要の山と谷が来る。
5. **海外比率の高低が決算の明暗を分けている**。円安は国内型に逆風、海外型に追い風。
   ただし海外でも現地競合との競争は激しく、「出れば安泰」ではない。

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **軽減税率** | 消費税率10%の例外として、飲食料品と定期購読新聞に8%を適用する制度（2019年10月導入）。2027年4月からこの8%を1%に下げる方針が2026年9月に閣議決定された |
| **価格転嫁** | 原材料・エネルギー・人件費の上昇分を取引価格に反映させること。転嫁率は「上昇分のうち何%を価格に乗せられたか」を示す |
| **優越的地位の濫用** | 取引上強い立場の者が相手に不当な不利益を与える行為。独禁法違反。協議に応じない一方的な価格据置きも該当しうる |
| **GMP（適正製造規範）** | Good Manufacturing Practice。原材料の受入から出荷までの製造・品質管理の基準。機能性表示食品では2026年9月1日に義務化が完全施行 |
| **一次包装／二次包装** | 中身に直接触れる包装（ボトル・ブリスター等）／それを外側でまとめる包装（化粧箱・外装）。GMPの管理対象は一次包装まで |
| **逆ザヤ** | 仕入価格が販売価格を上回る状態。相場が急落したあと、高値で仕入れた在庫を抱えると発生する |
| **粘着的な値上げ** | 原因が相場ではなく人件費・物流費など構造的コストにあるため、原因が解消しても価格が戻らないタイプの値上げ |
