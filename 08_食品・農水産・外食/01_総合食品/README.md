## このフォルダの読み方

食品メーカーは **「原料を仕入れて、加工して、ブランドを付けて売る」** という単純な商売に見える。
しかし実際の損益は、**自分で決められない2つの価格に挟まれて**決まっている。
入口の原材料価格は相場と為替が決め、出口の店頭価格は小売との交渉が決める。
その結果、営業利益率は **5〜8%** という狭いレンジに収まり、
「売上は過去最高なのに利益は減った」という決算が繰り返される。

このフォルダは**食品分類の入口**にあたる。
製粉・調味料・乳業・製菓といった個別カテゴリのノートは、**ここで扱う損益構造・値決め・商品開発の
基本ルールを前提**にして、そのカテゴリ固有の事情だけを書く。

## 1. 業界の定義・範囲

**総合食品（食品メーカー）** ＝ 農水産物や加工原料を仕入れ、
**工業的に加工して商品化し、ブランドを付けて販売する製造業**。
本フォルダではとくに、**複数カテゴリにまたがる大手食品メーカー**と、
食品メーカー全般に共通する基礎を扱う。

```
【食品・農水産・外食の中での「総合食品」の位置】

  川上                                                   川下
  ───────────────────────────────────────────────▶

  農業・漁業    素材メーカー    ★総合食品★     食品卸      小売      消費者
  畜産・飼料 → 製粉・製糖 →  （本フォルダ）→（中間流通）→ スーパー →
               製油・乳原料    味の素・明治                  CVS
                              日清・キッコーマン            ドラッグ
                                   │
                                   └──────────▶ 外食・中食・給食
                                     （業務用ルート）

  隣接するが別扱いのもの：
   ・素材型（製粉・製糖・製油）  → 相場の転嫁が価格の大半。02_製粉・製糖・製油
   ・酒類・飲料                  → 酒税・免許・自販機という別の論理。08/09
   ・たばこ                      → 専売の名残と規制。10_たばこ
   ・外食・中食                  → 店舗の経済性で決まる小売型。14〜21
   ・生鮮（青果・鮮魚・精肉）    → 卸売市場という別制度。11_水産、12_農業
```

境界の引き方で押さえるべき点。

- **「加工食品メーカー」が中心**。原料をそのまま売る素材型（製粉・製糖・製油）とは
  利益率も競争構造も違う。素材型は相場の転嫁が仕事の大半で、利益率は2〜5%と薄い。
- **家庭用と業務用は別の商売**。同じ工場で作っていても、規格・容量・価格・営業が全く違う。
  家庭用はブランド勝負、業務用は品質と安定供給と価格の勝負になる。
- **「総合食品」という会社は実在しない**。味の素も明治も、複数カテゴリを持つ会社を
  便宜上こう呼んでいるだけ。実際の競争はカテゴリごとに起きている（→ [③](03_商品開発とブランド.md) 第5章）。

## 2. 市場規模と成長性

| 指標 | 数値 | 年・出典 |
| --- | --- | --- |
| 食料品製造業の製造品出荷額 | 約 **33.0兆円**（製造業全体の **8.8%**） | 2024年。経済産業省「2024年経済構造実態調査（製造業事業所調査）」 |
| 食品メーカーの売上高合計 | **24兆2,824億円**（前年比 **+3.4%**） | 2025年（1〜12月期決算）。東京商工リサーチ、4,994社集計 |
| 同 利益合計 | **8,806億円**（前年比 **▲9.5%**） | 同上 |
| 利益の集中度 | 売上1,000億円以上の **41社** が利益合計の **55.5%** | 同上 |
| 食品業の倒産件数 | **168件**（前年度比 **+13.5%**） | 2025年度。東京商工リサーチ |
| 飲食料品の値上げ品目数 | 2025年 **20,609品目**／2026年は1〜11月判明分で **19,083品目** | 帝国データバンク「食品主要195社」価格改定動向調査 |
| 農林水産物・食品の輸出額 | **1兆7,005億円**（前年比 **+12.8%**）。2030年目標は5兆円 | 2025年。農林水産省 |

成長性の読み方。

- **名目は伸びているが、実質（数量）は伸びていない**。売上増の大半は値上げによる名目膨張で、
  トン・食数ベースでは横ばい〜微減。
- **利益は伸びていない**。2025年は増収減益。原材料・包装資材・物流費・人件費の上昇が
  値上げのペースを上回った。
- **規模による二極化が鮮明**。利益の55.5%を大手41社が稼ぎ、中小は倒産が増えている。
- **構造的な上限は人口**。国内の食品消費総量は「人口 × 食事回数 × 1食あたり支出」で決まるため、
  数量は構造的に縮む（→ [④](04_国内成熟と海外展開.md) 第1章）。

## 3. バリューチェーン（川上 → 川下）

```
【モノ・カネ・情報の流れ】

 モノ  原料産地 ──▶ 素材メーカー ──▶ 食品メーカー ──▶ 卸 ──▶ 小売 ──▶ 消費者
      （海外・国内） （製粉・製油）   （本フォルダ）

 カネ  食品メーカー ──── 建値で請求 ────▶ 卸／小売
       食品メーカー ──── リベート・協賛金 ──▶ 卸／小売   ← 実質価格を下げる逆流
       食品メーカー ──── センターフィー負担 ──▶ 小売

 情報  食品メーカー ◀── POS・売れ筋・棚割り ── 卸／小売
       食品メーカー ──── 新商品提案・販促企画 ──▶ 卸／小売
                          （年2回の棚替えが勝負どころ）
```

付加価値がどこに集まるか。

| 段階 | 粗利率の目安 | 営業利益率の目安 | なぜそうなるか |
| --- | --- | --- | --- |
| 素材メーカー（製粉・製糖・製油） | 10〜20% | 2〜5% | 製品が均質で差別化しにくい。相場の転嫁が仕事 |
| **食品メーカー（加工食品）** | **30〜38%** | **5〜8%** | ブランドと製法で差がつく。ただし販促費で削られる |
| 食品卸 | 6〜9% | 1%台 | 同じ商品を誰でも扱える。差別化が物流しかない |
| 食品スーパー | 25〜30% | 2〜3% | 立地と品揃えで差がつくが、人件費と家賃が重い |

> ポイント：**粗利率で見れば食品メーカーが最も高い。しかし営業利益率では大差がない。**
> ブランドで取った粗利を、リベート・特売協賛・広告という形で
> 流通側に戻している構造だから（→ [②](02_値決めと交渉.md) 第1章）。

**シェアの見方**：食品業界には「業界全体のシェア」という概念がほとんど意味を持たない。
しょうゆ、マヨネーズ、即席麺、チョコレート……と**カテゴリごとにプレイヤーも寡占度も全く違う**ためである。
シェアを語るなら必ずカテゴリを限定する（→ [③](03_商品開発とブランド.md) 第5章に一覧）。

## 5. 収益モデル・コスト構造

```
【売上 100円の行き先（加工食品メーカーの標準的な姿）】

 売上高 100.0
  ├─ 売上原価 62〜70
  │    ├─ 原材料費   40〜50  ◀★最大。相場と為替に直撃される
  │    ├─ 包装資材費  5〜8   ◀原油・紙パルプ連動
  │    ├─ 工場人件費  5〜7   ◀固定費
  │    └─ 償却・光熱   4〜6   ◀固定費。稼働率低下で単価が跳ねる
  ├─ 粗利 30〜38
  │    └─ 販管費 24〜31
  │         ├─ 販促・広告  8〜14 ◀リベート・特売協賛・CM
  │         ├─ 物流費      5〜8
  │         ├─ 営業人件費  5〜7
  │         └─ 研究開発費  1〜2  ◀医薬品(15〜20%)と桁違いに小さい
  └─ 営業利益 5〜8  ← ★食品メーカーの相場観
```

| 収益・コストの論点 | 中身 |
| --- | --- |
| **原材料費が原価の大半** | 小麦・大豆・カカオ・原乳・油脂。相場と為替で決まり、自社では決められない。ヘッジは「時間を買う」だけで水準は変えられない |
| **販促費が粗利を削る** | リベート（販売報奨金）、特売協賛金、新規導入協賛。表の値上げが実質化しない最大の理由 |
| **工場は装置産業** | 固定費比率が高く、数量が2割落ちると1個あたり原価が6%上がる。季節性とSKU増加が稼働率をさらに下げる |
| **賞味期限が在庫リスク** | 1/3ルール、返品、需要予測の外れ。「欠品は許されないが余らせたら自腹」という非対称 |
| **値上げには時間差がある** | 原料上昇 → 決算悪化 → 事前通告 → 交渉 → 改定 → 効果が乗るまで半年〜1年 |

詳しくは [① 食品メーカーの損益構造](01_食品メーカーの損益構造.md)。

## 6. 競争要因（KSF）と参入障壁

| KSF | 中身 |
| --- | --- |
| **ブランド（＝指名買い）** | 「マヨネーズ」ではなく「キユーピー」と指名される状態。小売が棚から外せなくなる。数十年かけて蓄積した記憶の資産 |
| **棚の確保** | 年2回の棚替えで面積を守り、増やすこと。新商品提案はそのための手段でもある |
| **工業化ノウハウ** | 試作の味を量産設備で再現する技術。レシピを真似されても追随されにくい本当の参入障壁 |
| **原料調達力** | 相場変動を吸収する購買・ヘッジ体制。規模が効く |
| **全国の生産・物流網** | 日配品ほど決定的。パン・牛乳・惣菜は物流圏が競争範囲そのもの |
| **規模によるコスト吸収力** | 2025年の利益の55.5%を大手41社が占める。コスト上昇局面では規模がそのまま生存条件になる |

**参入障壁**は許認可ではない（食品製造業は営業許可・HACCP対応は要るが、免許制ではない）。
実質的な障壁は **①ブランドの蓄積、②工場への設備投資、③棚を取るための販促費**の3つ。
とくに③は、新規参入者が大手と同じ土俵に立つために毎年払い続ける必要があり、
**資本がある企業でも「棚に置き続ける費用」で息切れする**ことが多い。

## 7. 規制・法制度

| 制度 | 内容 | 食品メーカーへの影響 |
| --- | --- | --- |
| **食品衛生法／HACCP** | 2021年6月から原則すべての食品事業者にHACCPに沿った衛生管理が義務化 | 小規模事業者にも記録・管理の負担。設備投資の要因 |
| **食品表示法** | 原材料名、アレルゲン、栄養成分、原料原産地表示の義務 | 表示の誤りは**自主回収**につながる。パッケージ変更のコストとリードタイムに直結 |
| **機能性表示食品制度** | 2015年開始の届出制。2024年9月に健康被害の報告義務化、**2026年9月1日にGMP義務化が完全施行**、届出情報の表示方法も改正 | 錠剤・カプセル型は体制整備が必須に。小規模事業者の淘汰要因 |
| **JAS法・景品表示法** | 品質表示、不当表示（優良誤認・有利誤認）の禁止 | 実質値上げ（容量変更）の告知の仕方にも関わる |
| **独占禁止法（優越的地位の濫用）／下請法** | 協議を経ない一方的な価格据置きなどを規制。公取委が毎年度「価格転嫁円滑化に関する調査」を実施し、2026年度調査は2026年6月17日に開始を公表 | **メーカーは小売に対しては保護される側、下請の原料・包材業者に対しては規制される側**の両面を持つ |
| **適正取引推進ガイドライン**（農水省・中小企業庁） | 令和3年12月策定、**令和8年（2026年）1月改定**。センターフィーやリベートの算定根拠を示さない要請を問題行為として整理 | リベート・センターフィーの根拠開示を求める交渉材料 |
| **軽減税率／飲食料品の消費税引下げ** | 2026年9月15日の閣議決定により、**2027年4月1日〜2029年3月31日の2年間、飲食料品の消費税率を8%→1%**とする方針（法改正が必要） | 店頭価格が下がる余地に値上げをぶつけられる。一方で2029年4月の税率戻りに向けた需要変動も生じる |
| **食品ロス削減推進法／納品期限の緩和** | 1/3ルールの見直し（1/3 → 1/2）を農水省が業界に働きかけ | 緩和が進むほど返品・廃棄の負担が減る |
| **改正物流効率化法** | 2026年4月に特定事業者の指定・CLO（物流統括管理者）選任義務が施行 | 大手食品メーカーは荷主として該当。物流が経営アジェンダに格上げ → [食品卸②](../../06_商社・卸売/06_食品卸/02_物流という本体.md) |

## 8. 最近のトピック

詳細は → [⑤ 直近トピック（2026年9月時点）](05_直近トピック_2026.md)

1. **値上げは第4波へ** — 2026年は1〜11月判明分で19,083品目、年間2万品目超が確実。
   9月単月は4,531品目で年内最多、単月4,000品目超は2023年10月以来約3年ぶり（帝国データバンク）。
2. **2027年4月から飲食料品の消費税が1%へ** — 2026年9月15日に大綱を閣議決定。
   2029年3月末までの2年間の臨時措置。**値上げの「窓」が開く**が、小売との綱引きになる。
3. **増収減益と二極化** — 2025年の食品メーカーは売上+3.4%／利益▲9.5%。
   利益の55.5%を大手41社が占め、食品業の倒産は2025年度168件（+13.5%）（東京商工リサーチ）。
4. **値上げの理由が「原料」から「人件費・資材」へ** — 公取委調査（2025年度）の転嫁率中央値は
   原材料80.0%に対し**労務費は30.0%**。賃上げ分が通らず利益を削っている。
5. **機能性表示食品のGMP義務化が2026年9月1日に完全施行** — 届出情報の表示方法の改正も同日実施。
   錠剤・カプセル型サプリでは体制を持てない事業者の淘汰が進むとみられる。

## 9. 用語メモ

各ノートの末尾に詳しい用語メモがある。ここでは最重要の6つだけ。

| 用語 | 意味 |
| --- | --- |
| **建値（たてね）** | メーカーが卸・小売に示す基準の納入価格。定価ではなく交渉の出発点。値上げ発表はこの建値の改定を指す → [②](02_値決めと交渉.md) |
| **リベート（販売報奨金）** | 取引数量や販促実績に応じてメーカーが卸・小売へ**あとから払い戻す**金銭。建値を崩さずに相手ごとの実質価格を変える日本独特の商習慣 → [②](02_値決めと交渉.md) |
| **実質値上げ（シュリンクフレーション）** | 価格を据え置いたまま内容量を減らすこと。単位あたり価格は上がる。合法だが、気づかれると信頼を失う → [②](02_値決めと交渉.md) |
| **棚替え（たなかえ）** | 小売が売場の商品構成を見直すこと。年2回（春・秋）が一般的。新商品の生死と棚の面積がここで決まる → [③](03_商品開発とブランド.md) |
| **工業化** | 研究所で作った試作品を量産設備で同じ品質で作れるようにする工程。食品開発の最大の難所であり、真の参入障壁 → [③](03_商品開発とブランド.md) |
| **1/3ルール** | 製造日から賞味期限までを3等分し、最初の1/3以内に小売へ納品する商習慣。超過分はメーカー・卸の負担になりやすい → [①](01_食品メーカーの損益構造.md) |
