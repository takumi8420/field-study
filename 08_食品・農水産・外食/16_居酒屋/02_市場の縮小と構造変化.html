② 市場の縮小と構造変化 — 外食で唯一、コロナ前に戻っていない

食品・農水産・外食居酒屋
あこのページの単語集用語に触れると意味を確認できます9語
2019年比（コロナ前比）総合居酒屋大箱／小箱単品特化ソバーキュリアスノンアルコール飲料二次会需要酒場・ビヤホール価格転嫁

このノートで分かること：居酒屋という業態に何が起きたのかを数字で確認し、
それが一時的な落ち込みではなく需要そのものの構造変化である理由を押さえる。
そして、大手チェーンが店を減らし続ける一方で、なぜ専門店・個店が増えているのかを見る。

結論：居酒屋は外食の主要業態の中で唯一、2019年の水準に戻っていない。
日本フードサービス協会（JF）の会員社データから各年の前年比を連鎖させると、
パブレストラン／居酒屋の2025年の売上は2019年の約78%、客数は約66%、
店舗数は約68%にとどまる。同じ計算でファストフードは約140%、
ファミリーレストランは約116%、外食全体は約126%である。
落ちたのは「来店の回数」であり、それを支えていた団体宴会・二次会・接待という
3つの需要が戻らなかった。市場は縮んだのではなく、形が変わった。

※本ノートは産業構造の解説であり、飲酒を勧めるものではない。
20歳未満の飲酒は法律で禁止されている。飲酒には健康上のリスクがある。

各年の前年比を掛け合わせると、2019年を100としたときの水準が分かる。

居酒屋についてさらに4指標を同じ方法で並べると、何が起きたかが見える。

【パブレストラン／居酒屋 2019年を100としたときの2025年（筆者の連鎖計算）】

  売上   ████████████████                 約 78
  客数   █████████████                    約 66
  店舗数 █████████████▌                   約 68
  客単価 ███████████████████████▌         約 117

  → 客数が3分の1失われ、店も3分の1が消えた。
     その穴を「1人あたり単価 +17%」で7割方まで埋め戻したのが現在地。

ポイント：売上78に対して客数66という差が、この業態の現状のすべてを表している。
来ている人は減ったまま、1人あたりの支払いが増えた。
これは「値上げが通った」という良い面と、
「頭数で稼ぐモデルが壊れた」という悪い面を同時に意味する。
頭数で稼ぐモデル＝宴会である。

2. 失われた3つの需要

居酒屋の売上は、性格の異なる需要の積み上げでできていた。
2020年代に消えたのは、そのうち金額が大きく、単価が確定していた層だった。

【居酒屋の需要の4層と、その後】

  ┌────────────────────────────────────┐
  │ ④ 接待・取引先との会食              │ 大きく減った
  │    （企業の交際費。単価が高い）       │ ・オンライン商談の定着
  ├────────────────────────────────────┤ ・交際費管理の厳格化
  │ ③ 二次会                            │ ほぼ消えた
  │    （一次会のあとに続く2軒目）        │ ・「一次会で解散」が標準に
  ├────────────────────────────────────┤
  │ ② 大口の団体宴会                    │ 大きく減った
  │    （忘年会・歓送迎会・部署単位）     │ ・強制参加の忌避
  ├────────────────────────────────────┤ ・部署単位→有志少人数へ
  │ ① 少人数の日常利用                  │ 残った／むしろ増えた
  │    （2〜4人、仕事帰り、週末）         │ ・専門店・個店が受け皿に
  └────────────────────────────────────┘

帝国データバンクは2026年上半期の飲食店倒産動向のなかで、
「大口宴会の減少や二次会需要の低迷など、アフターコロナの新しい生活様式が定着した」ことを、
若者のアルコール離れと並ぶ背景として挙げている（2026年7月）。

この3層の喪失が痛いのは、単に売上が減るからではない。
① 居酒屋の経済で見たとおり、宴会は
「人数・単価・仕込み量・シフトを事前に確定できる」という利益率そのものを底上げする需要だった。

失ったもの 売上への影響 利益への影響（こちらが本質）
大口宴会1件5万〜30万円が消える仕込みロス増、シフト読み違い増、満席率低下
二次会21時以降の客数が消える深夜人件費だけが残る。閉店前倒しの直接要因
接待高単価客が消える高価格帯メニュー・個室の稼働が落ち、投資が回収できない
大箱の前提—200席の大箱が構造的に不要になった

最後の行が、大手チェーンの店舗数激減に直結する。
大箱は宴会を受けるための設備であり、宴会がなければ家賃だけが重い空席になる。

3. 飲酒習慣の変化 — 一時的ではない理由

宴会文化の変化に加えて、飲酒そのものの量が長期的に減っている。
これが「景気が戻れば戻る」話ではないことの根拠になる。

指標 数値 年・出典
成人1人あたりアルコール消費量101.8L（1992年度）→ 74.3L（2021年度）国税庁
酒類の販売（消費）数量約773万kL2024年度・国税庁「酒のしおり」
酒税収入約1.18兆円（ピークは1994年度の約2.12兆円）2024年度・同
20〜30代の飲酒習慣「ほとんど飲まない（飲めない）」が男性で4〜5割、女性で6割2017年・厚生労働省「国民健康・栄養調査」をもとにした民間分析
「ソバーキュリアス」20代の約4分の1があえて飲まないとされる民間シンクタンクの調査・分析

（詳細は ビール・酒類 ③ 国内縮小と海外展開 を参照）

【需要の減り方が「三重」になっている】

  居酒屋の総需要 ＝ ① 成人人口 × ② 1人あたり飲酒量 × ③ 外で飲む割合
                      ↓減          ↓減                ↓減
   ①人口動態      20歳以上人口は長期的に減少（社人研推計）
   ②飲酒量        健康志向、飲酒ガイドライン、運転規制、若年層の非飲酒
   ③外飲み比率    家飲みの定着、配信サービスでの在宅時間の増加、
                  物価高による外食の選別

  → メーカー側（②が効く）よりも、居酒屋側（①②③すべてが効く）のほうが厳しい

ポイント：酒類メーカーと居酒屋では、同じ「飲酒離れ」でも効き方が違う。
メーカーは家飲み需要が残れば缶で売れる（ビール・酒類）。
居酒屋は「外で」「集まって」飲むという行為そのものが商品なので、
家飲みへの移行は売上の純減になる。
業務用（樽・瓶）の出口としての居酒屋が細ることは、
酒類卸の業務用チャネルにも直接効く。

4. 大手チェーンの店舗数激減 — 誰が減らし、誰が増やしたか

需要の形が変わったことは、店舗数の動きにそのまま現れた。
流通系メディアの集計によると、大手居酒屋チェーン16社の店舗数は
2019年12月末 6,661店 → 2022年9月末 5,387店、3年弱で1,274店（19.1%）減した
（2022年11月・流通ニュース集計）。

チムニー（はなの舞ほか）738店488店▲250店

（出典：流通ニュース「大手居酒屋チェーン16社／3年で1274店を閉店」2022年11月）

モンテローザ（白木屋、魚民、笑笑ほか）は非上場だが、コロナ禍前に1,000億円を超えていた
売上高が500億円台まで縮み、店舗数も大きく絞り込んだと報じられている（2026年1月・東洋経済オンライン）。
かつて空き物件に素早く出店する「後出しジャンケン」と呼ばれた拡大戦略を、
多店舗展開そのものの前提が変わったため転換したとされる。

ワタミは、居酒屋一本足から「宅食（弁当宅配）＋外食＋焼肉」への転換を進めた企業である。
2026年3月期は連結売上932.7億円（前年比+5.1%）、営業利益48.4億円（+5.9%）。
国内外食事業は売上376.7億円（+9.5%）、セグメント利益22.6億円（+40.5%）で、
居酒屋業態・焼肉業態・テイクアウト業態などの複合として運営されている
（同社決算発表・2026年5月／流通ニュース）。

4-1. 増えた側に共通するもの

減らした企業と増やした企業の差は、規模でも資本力でもない。店の設計思想である。

軸 減らした大箱チェーン 増やした専門店チェーン
想定客数20〜50名の宴会2〜4名
席数150〜250席40〜80席
メニュー100品超の総合居酒屋看板1品＋派生（串カツ、餃子、焼き鳥、唐揚げ）
来店理由「とりあえず場所を押さえる」「あれを食べに行く」
家賃大面積＝絶対額が重い小面積＝撤退も出店も軽い
原価管理品数が多く難しい単品特化で仕入も仕込みも単純
人の習熟多品目でオペレーションが重い少品目で未経験者が戦力になる

ポイント：総合居酒屋は「何でもある」ことが価値だった。
幹事が20人分の希望をまとめる必要があるとき、何でもある店が選ばれる。
ところが2〜4人で来るなら、全員の希望を聞く必要がない。
「今日は餃子」「今日は串カツ」で決まる。
幹事という役割が消えたことが、総合居酒屋の存在理由を消した。
単品特化は同時に、原価管理・仕込み・教育のすべてを単純にする
（焼肉・ラーメンの単品特化と同じ論理）。

5. 個店と専門店の強さ、そして倒産の増加

「大手が減って個店が増えた」というのは半分だけ正しい。正確には
強い個店が増え、弱い個店が倒れている。この2つが同時に起きている。

指標 数値 年・出典
飲食店の倒産（上半期）473件（前年同期458件から+3.3%、上半期として過去最多・4年連続増）2026年上半期・帝国データバンク
うち酒場・ビヤホール（居酒屋主体）125件（前年同期105件から+19.0%、過去最多）同
酒場・ビヤホールが全体に占める比率26.4%（最多業態）同
飲食店の倒産（通年）894件（過去最多を更新。うち居酒屋が最多の212件）2024年・帝国データバンク

帝国データバンクは背景として、大口宴会・二次会需要の低迷と若者のアルコール離れに加え、
食材・光熱費の高騰、賃上げによる利益圧迫、さらに
2026年4月13日以降の外国人労働者（特定技能「外食業」）の新規受入停止を挙げ、
価格転嫁できる大手と、できない中小零細の格差が鮮明になっていると指摘している。

【同じ「居酒屋」でも、二極化している】

     強い                                          弱い
  ┌──────────────┐                  ┌──────────────┐
  │ 専門店・単品特化       │                  │ 総合居酒屋（大箱）    │
  │ 常連中心の個店         │                  │ 宴会依存の郊外店      │
  │ 立ち飲み・小箱         │                  │ 深夜依存の繁華街店    │
  │ 横丁・屋台村           │                  │ 値上げできない低価格店 │
  └──────────────┘                  └──────────────┘
    ・来店理由が明確                          ・来店理由が「場所」だけ
    ・客単価を上げられる                      ・値上げすると客が消える
    ・少人数でも成立                          ・満席にならないと赤字
    ・小面積＝家賃が軽い                      ・大面積＝空席が家賃を食う

ポイント：この業態で生き残る条件は「規模」ではなく「来店理由」になった。
宴会が消えたあとに残ったのは、少人数で「その店だから行く」という需要だけ。
大手が減り個店が増えたように見えるのは、
来店理由を作れる店の平均サイズが小さいからであって、
チェーンであること自体が不利になったわけではない
（串カツ田中や餃子チェーンは、単品特化のチェーンとして増やしている）。

6. 需要の受け皿はどこへ行ったか

居酒屋から抜けた需要は、消滅したわけではなく移った。

移り先 何を代替したか 関連ノート
家飲み（缶・瓶の購入）外で飲む行為そのものビール・酒類
コンビニ・食品スーパーつまみ＋酒の調達—
中食・弁当・惣菜「料理を作らずに食べる」需要冷凍食品・惣菜
焼肉・回転寿司家族・少人数の「ごちそう外食」—
単品特化の専門店少人数の「飲みながら食べる」需要本ノート4章
カフェ・昼の打ち上げ「集まって話す」需要のうち酒を伴わない部分—

注目すべきは、「集まって話す」需要そのものは消えていないこと。
消えたのは「集まるなら酒場」という結びつきである。
だから居酒屋側の打ち手は「酒を飲ませる」ではなく
「酒を飲まない人も満足できる場にする」方向に向かう。

  • ノンアルコール・低アルコール飲料の拡充。酒税法上、アルコール1%未満は酒類ではなく、
    清涼飲料と同じ土俵にある。原価率はアルコール同様に低く、
    飲まない客のドリンク単価をゼロにしないための最重要施策になっている
  • 料理で選ばれる店になる。単品特化・名物化の流れはここにもつながる
  • 昼営業への進出。夜だけの設備稼働を昼にも広げる（→ ③）

7. 構図のまとめ

【2020年代の居酒屋に起きたこと】

   需要の形が変わった              供給が追いつけなかった
   ─────────────              ──────────────
   団体宴会 → 少人数              大箱（200席）が余った
   二次会  → 一次会で解散          深夜帯の人件費だけ残った
   接待   → オンライン商談         個室・高価格帯が空いた
   飲酒   → 非飲酒・ノンアル       ドリンクの粗利が細った
        ↓                              ↓
   来店理由が「場所」から「料理」へ    大箱・総合型の閉店ラッシュ
        ↓                              ↓
   ┌──────────────────────────────────┐
   │ 単品特化・小箱・専門店が増え、                     │
   │ 総合居酒屋チェーンは業態転換か縮小を選んだ           │
   │ 同時に、価格転嫁できない中小店の倒産は過去最多に      │
   └──────────────────────────────────┘

市場は「縮んだ」のではなく「需要の単位が小さくなった」。
20人で1回来ていた客が、4人で2回来るようになった。
売上は落ちるが、それに合わせて店の形を小さく作り直せた側だけが残っている。
その作り直しの中身を、次のノートで見る。
