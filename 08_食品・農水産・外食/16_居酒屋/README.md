# 居酒屋

- 大分類: 食品・農水産・外食
- 状態: done
- 更新日: 2026-09-20

## このフォルダの読み方

居酒屋は **「食事で客を呼び、ドリンクで利益を作る業態」**である。
アルコール飲料の原価率は食事より圧倒的に低く（フード35〜40%に対しドリンク15〜25%）、
注ぐだけなので人手もほとんど使わない。
だから**売上に占めるドリンク比率が10ポイント上がると、店全体の原価率が約2ポイント下がる**。
営業利益率が5〜8%しかない世界で原価率2ポイントは利益の3割前後に相当する。
**ドリンク比率こそが、この業態の損益の主変数**である。
宴会も、飲み放題も、2時間制も、金曜への集中も、すべてこの一点から説明できる。

そして、その主力商品が売れなくなった。
JF（日本フードサービス協会）会員社データの各年前年比を連鎖させると、
パブレストラン／居酒屋の2025年売上は**2019年の約78%**にとどまる。
ファストフード約140%、ファミレス約116%、外食全体約126%に対して、
**居酒屋は外食の主要業態で唯一、コロナ前に戻っていない**。
失われたのは団体宴会・二次会・接待という「人数と単価が確定していた需要」で、
それは景気ではなく生活様式が変わった結果なので、待っていても戻らない。

外食の共通言語（FL比率、回転率、坪売上、既存店前年比）は
[ファストフード ① 外食1店舗の経済](../14_ファストフード/01_外食1店舗の経済.md) で定義済み。
本フォルダはそれを前提に、**居酒屋だけが持つ経済の癖**から書き起こす。

## 1. 業界の定義・範囲

**居酒屋＝酒類の提供を主目的としつつ、食事も本格的に出す外食業態**。
JFの業態分類では「パブレストラン／居酒屋」として集計され、
内訳は「パブ・ビアホール」と「居酒屋」に分かれる。
政府統計・倒産統計では「酒場・ビヤホール」という分類名が使われる。

隣接業態との境界は、**売上に占めるドリンク比率・客単価・滞在時間**で引く。

| 業態                                                         | ドリンク比率の目安 | 客単価             | 滞在時間  | 性格                                 |
| ------------------------------------------------------------ | ------------------ | ------------------ | --------- | ------------------------------------ |
| **居酒屋**                                                   | **30〜40%**        | 3,000〜4,000円     | 120分前後 | 食事も酒も。**両方が本命**           |
| バー・スナック                                               | 60〜90%            | 3,000〜8,000円     | 60〜150分 | 酒と場が本命。料理は付随             |
| [ファミリーレストラン](../15_ファミリーレストラン/README.md) | 10〜20%            | 1,000〜1,500円     | 50〜70分  | 食事が本命                           |
| [焼肉・ラーメン](../18_焼肉・ラーメン/README.md)             | 焼肉で20〜30%      | 焼肉3,000〜5,000円 | 60〜90分  | 食事が本命。焼肉は居酒屋需要と重なる |
| [回転寿司](../17_回転寿司/README.md)                         | 5〜10%             | 1,200〜1,800円     | 40〜60分  | 食事が本命。家族利用中心             |
| [カフェ](../19_カフェ/README.md)                             | 70%超              | 500〜900円         | 30〜60分  | ドリンク主体だが**単価が一桁違う**   |
| [ファストフード](../14_ファストフード/README.md)             | 10〜20%            | 500〜1,100円       | 10〜25分  | 低単価・超高回転                     |

（業界で一般に語られる水準をもとにした概算）

境界が曖昧なのは次の3つ。

- **焼肉**：宴会・飲酒需要の相当部分を取り込んでおり、居酒屋の直接の競合。
  コロワイド傘下のレインズ（牛角）のように、両業態を同じ企業が運営する例も多い
- **ネオ大衆酒場・立ち飲み**：滞在が短く単価も低いが、統計上は居酒屋
- **バル・イタリアン居酒屋**：料理の系統が違うだけで経済構造は居酒屋と同じ

> この業界を一言で：**「低原価のドリンクで利益を作る、高単価・低回転の外食」**。

## 2. 市場規模と成長性

| 指標                                    | 数値                                                | 年・出典                                                     |
| --------------------------------------- | --------------------------------------------------- | ------------------------------------------------------------ |
| 外食産業市場規模（日本）                | 約24兆1,512億円（前年比+20.2%）                     | 2023年・日本フードサービス協会／食の安全・安心財団の共同推計 |
| うち**料飲主体部門**                    | 約3兆8,719億円（前年比+31%）                        | 同                                                           |
| うち**居酒屋・ビヤホール等**            | **約9,152億円**                                     | 2023年・同（二次資料経由で確認）                             |
| パブレストラン／居酒屋 売上（2019=100） | **約78**                                            | 2025年・JF各年前年比からの筆者計算                           |
| 同 客数（2019=100）                     | 約66                                                | 同                                                           |
| 同 店舗数（2019=100）                   | 約68                                                | 同                                                           |
| 同 客単価（2019=100）                   | 約117                                               | 同                                                           |
| 2026年7月の売上前年比                   | **105.2%**（店舗数99.5%、客数103.7%、客単価101.5%） | 2026年7月・JF市場動向調査                                    |
| 飲食店の倒産（うち酒場・ビヤホール）    | **125件**（上半期として過去最多、前年同期比+19.0%） | 2026年上半期・帝国データバンク                               |

成長性の読み方は3点。

- **市場は縮小から横ばいへの途中**。売上の前年比は100%を超えているが、
  **店舗数は依然100%を割っている**。業態としてはまだ縮んでいる
- **伸びているのは客単価であって客数ではない**。2019年比で売上78・客数66という差が、
  値上げと単価設計で穴を埋めてきたことを示す
- **需要の単位が小さくなった**。20人で1回ではなく4人で2回。
  この形に店を作り替えられたかどうかが、増収と倒産最多の同時進行を生んでいる

詳細は [② 市場の縮小と構造変化](02_市場の縮小と構造変化.md)。

## 3. バリューチェーン（川上 → 川下）

```
【居酒屋のバリューチェーン ― 2本の流れが店で合流する】

 ■ 酒の流れ（利益を作る側）
   酒類メーカー ──▶ 酒類卸（一次・免許制）──▶ 業務用酒販店（二次卸）──┐
   ビール・焼酎・日本酒・RTD   与信と物流    樽・瓶の配送、サーバー洗浄  │
                                                                      ▼
 ■ 食材の流れ（客を呼ぶ側）                                      ┌──────┐
   水産・畜産・農業・青果 ──▶ 食品メーカー ──▶ 食品卸 ─────────▶│ 居酒屋 │──▶ 客
                              冷凍・惣菜      業務用食材         └──────┘
                                                                      ▲
 ■ 集客の流れ  グルメサイト・予約サイト・地図アプリ・SNS ──────────────┘
               （掲載料＋送客手数料。目的来店型なので依存度が高い）

 ※付加価値はメーカー（ブランド）と店（立地・来店理由）の両端に集まり、
   中間の卸は物流・与信・多頻度配送という機能で対価を得る
```

| ---------------- | ------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| 酒の川上         | ビール・焼酎・日本酒・RTDの製造。酒税が商品設計を規定する    | [ビール・酒類](../08_ビール・酒類/README.md)                                                                                 |
| 酒の流通         | 免許制。料飲店への与信、樽の配送・回収、サーバー管理まで担う | [酒類卸](../../06_商社・卸売/08_酒類卸/README.md)                                                                            |
| 食材の川上       | 鮮魚・精肉・青果。相場変動が原価率に直撃する                 | [水産](../11_水産/README.md)／[畜産・飼料](../13_畜産・飼料/README.md)／[農業・種苗・肥料](../12_農業・種苗・肥料/README.md) |

| **店舗**         | 立地、来店理由、ドリンク比率の設計                           | [① 居酒屋の経済](01_居酒屋の経済.md)                                                                                         |
| 集客             | 予約サイト、地図アプリ、SNS。掲載料と送客手数料              | [プラットフォーム・SNS](../../04_情報通信・IT・ネット/09_プラットフォーム・SNS/README.md)                                    |

> ポイント：居酒屋は**「酒の出口」でもある**。
> 業務用（樽生・瓶）の最大の販路であり、ここが細ることは
> [ビール・酒類](../08_ビール・酒類/README.md)メーカーと
> [酒類卸](../../06_商社・卸売/08_酒類卸/README.md)の業務用チャネルにそのまま伝わる。
> 家飲みへの移行は、メーカーにとっては「チャネルの移動」だが、
> **居酒屋にとっては売上の純減**になる。

## 4. 主要プレイヤーとシェア

居酒屋は**シェアの概念が薄い業界**である。
市場規模約9,000億円規模（2023年推計）に対し最大手でも数百億円規模で、
**個人店の比率がきわめて高い**。上位企業の合計でも市場の1割台にとどまるとみられる。

| 企業（主なブランド）                                           | 立ち位置             | 特徴・直近数値（出典：各社決算発表・報道）                                                                                                                                                            |
| -------------------------------------------------------------- | -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **ワタミ**（ミライザカ、三代目鳥メロ、焼肉の和民ほか）         | 複合業態化の代表     | 2026年3月期 連結売上 932.7億円（+5.1%）、営業利益 48.4億円（+5.9%）。国内外食は売上376.7億円（+9.5%）、セグメント利益22.6億円（+40.5%）、期末517店。**宅食・外食・焼肉の3本立てで居酒屋の変動を相殺** |
| **エターナルホスピタリティグループ**（鳥貴族）                 | 単品特化・均一価格   | 2026年7月期 売上 512.5億円（+10.6%）だが**営業減益**。2Qの国内鳥貴族既存店は売上+9.8%（客数+5.5%・客単価+4.0%）。焼き鳥特化で**値上げ後も客数が増えている稀な例**                                     |
| **モンテローザ**（白木屋、魚民、笑笑ほか／非上場）             | かつての最大手       | コロナ前1,000億円超だった売上高が500億円台まで縮小し、店舗も大きく絞ったと報じられる（2026年1月・東洋経済）                                                                                           |
| **コロワイド／レインズインターナショナル**（牛角、甘太郎ほか） | 外食コングロマリット | 2019年12月末1,839店→2022年9月末1,594店（245店減）。**焼肉（牛角）を軸に居酒屋需要を取り込む**                                                                                                         |
| **チムニー**（はなの舞、さかなや道場ほか）                     | 大衆居酒屋           | 2019年12月末738店→2022年9月末488店（250店減）                                                                                                                                                         |
| **大庄**（庄や、日本海庄やほか）                               | 老舗総合居酒屋       | 2019年12月末487店→2022年9月末290店（197店減）。鮮魚の内製に強み                                                                                                                                       |

| **NATTY SWANKY HD**（肉汁餃子のダンダダン）                    | 単品特化の成長組     | 2019年12月末86店→2022年9月末124店（**+38店**）                                                                                                                                                        |
| **一家HD**（屋台屋 博多劇場ほか）                              | 接客・ブランド重視   | 2019年12月末69店→2022年9月末74店（+5店）                                                                                                                                                              |

（店舗数は流通ニュース集計、業績は各社開示・報道ベース。詳細は [④](04_直近トピック_2026.md)）

> ポイント：**この業界で勝ち負けを分けたのは規模ではなく「来店理由」**だった。
> 総合居酒屋は「何でもある」ことが価値だったが、それは幹事が20人分の希望を
> まとめる必要があった時代の価値である。2〜4人で来るなら全員の希望を聞く必要はなく、
> 「今日は焼き鳥」「今日は串カツ」で決まる。
> **幹事という役割が消えたことが、総合居酒屋の存在理由を消した**。

## 5. 収益モデル・コスト構造

**店舗の損益**（売上100とした比率。共通の読み方は
[外食1店舗の経済](../14_ファストフード/01_外食1店舗の経済.md)）

| 項目                | 比率          | 居酒屋特有の事情                                      |
| ------------------- | ------------- | ----------------------------------------------------- |
| F：食材費・飲料原価 | **28〜33%**   | **ドリンク比率で上下する**。D比率10pt＝原価率約2pt    |
| L：人件費           | 28〜33%       | **金曜19〜21時**で必要人数が決まる。22時以降は25%割増 |
| **FL合計**          | 60%以内が目安 | —                                                     |
| R：家賃             | 8〜12%        | 駅前の**2階・地下**を選ぶことで成立させる             |
| 水道光熱費          | 5〜8%         | —                                                     |
| 販促・送客手数料    | 3〜6%         | 目的来店型のため**予約サイト依存度が高い**            |
| 減価償却・その他    | 8〜12%        | 内装・厨房。撤退時の原状回復費も重い                  |
| **営業利益**        | **5〜8%**     | —                                                     |

```
【居酒屋の利益がどこから出ているか（月商1,000万円の店・モデル計算）】

  フード売上 600万円 × 粗利62%  = 372万円
  ドリンク売上 400万円 × 粗利82% = 328万円   ← 売上は4割なのに粗利は47%
  ────────────────────────────────
  粗利合計 700万円
   − 人件費 300万 − 家賃 100万 − 水光熱 70万 − その他 120万
  ＝ 営業利益 110万円（営業利益率 11%）

  ※フード38%・ドリンク18%の原価率を置いた筆者のモデル計算
  ※ドリンク比率が40% → 20% に落ちると原価率が4pt悪化し、利益は40万円減る
```

**企業レベルの収益**は、多くが直営中心。
[ファストフード](../14_ファストフード/README.md)のようなFC（フランチャイズ）主体の企業は少ない。
理由は、居酒屋が**立地・人・雰囲気に依存しており標準化しにくい**ため。
串カツ田中のように単品特化でオペレーションを単純にした企業はFCを併用している。

## 6. 競争要因（KSF）と参入障壁

| KSF                          | なぜ効くか                                                                           |
| ---------------------------- | ------------------------------------------------------------------------------------ |
| **来店理由（名物・専門性）** | 「場所」で選ばれる時代が終わった。**その店でなければならない理由**がないと選ばれない |
| **ドリンク比率の設計**       | 損益の主変数。メニュー構成、飲み放題、ノンアル品揃えのすべてがここに効く             |
| **立地（駅前・繁華街）**     | 目的来店型だが、**駅から歩ける範囲**という制約は外せない                             |
| **予約の獲得力**             | 人数・単価・仕込み量を事前に確定でき、利益率そのものを底上げする                     |
| **人の確保**                 | 夜・土日・立ち仕事という条件で人を集められるか。最大の調達課題                       |
| **小さく作る力**             | 需要の単位が小さくなった以上、小面積で成立する設計ができるか                         |

**参入障壁は低い。それが最大の問題**でもある。

- 数百万〜2,000万円あれば1店は開業できる（居抜き物件ならさらに安い）。必要な免許も
  保健所の**飲食店営業許可**が中心で、店内で飲ませるだけなら酒類販売業免許は要らない
  （持ち帰り販売には別途免許が必要）。**だから常に新規参入があり、常に退出がある**
- 一方、**チェーンとして成立させるのは難しい**。標準化しにくく、
  店数が増えても[ファストフード](../14_ファストフード/README.md)ほどの購買力・広告効率が効かない
- **退出コストは高い**。原状回復費と解約予告期間があるため、赤字でも畳めずに続く店が残る

## 7. 規制・法制度

| 分野                             | 内容                                                                                                                                              |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| **食品衛生法**                   | 飲食店営業許可（保健所）。2021年6月からHACCPに沿った衛生管理が全事業者に義務                                                                      |
| **酒税法**                       | **2026年10月1日にビール系飲料の税率を1kL＝155,000円（350ml換算54.25円）へ一本化**。ビールは350ml換算で9.10円の減税、発泡酒・新ジャンルとRTDは増税 |
| **未成年者飲酒禁止法**           | **20歳未満への酒類提供を禁止**。年齢確認が店側の義務                                                                                              |
| **風俗営業等適正化法（風営法）** | 深夜（0時以降）に酒類を提供する店は「深夜酒類提供飲食店営業」の届出が必要。接待を伴う営業は許可制                                                 |
| **労働基準法**                   | 22時〜翌5時の深夜割増（25%以上）、時間外労働の上限規制                                                                                            |
| **最低賃金法**                   | 2026年度の答申ベース全国加重平均**1,177円**（前年度1,121円から+56円）。2026年10月以降順次発効                                                     |
| **入管法（特定技能）**           | 特定技能1号「外食業」が分野別上限に到達し、**2026年4月13日から新規受入を当面停止**。技能実習は2027年4月に育成就労へ移行予定                       |
| **健康増進法**                   | 2020年4月全面施行の受動喫煙対策。原則屋内禁煙（既存小規模店には経過措置）。**喫煙可否が客層を分ける要素になった**                                 |
| **アルコール健康障害対策基本法** | 2013年制定。2024年に厚生労働省が「健康に配慮した飲酒に関するガイドライン」を公表                                                                  |
| **食品表示法／景品表示法**       | アレルゲン表示、原産地表示、優良誤認・有利誤認                                                                                                    |

> 注：**20歳未満の飲酒は法律で禁止されている**。年齢確認は事業者の義務であり、
> 違反した場合は営業許可に関わる。本フォルダはこの前提で業界構造を記述している。

## 8. 最近のトピック

詳細は [④ 直近トピック（2026年9月時点）](04_直近トピック_2026.md)。要点は5つ。

- **倒産が過去最多**。2026年上半期の飲食店倒産473件のうち、居酒屋主体の
  「酒場・ビヤホール」が125件（+19.0%）で最多業態。いずれも過去最多（帝国データバンク）
- **月次は前年超えでも店舗数は減り続ける**。2026年7月のパブ／居酒屋は売上105.2%だが
  店舗数99.5%。外食全体（店舗数101.1%）と逆方向（JF）
- **2026年10月1日に酒税が一本化**。業務用ビールは中ジョッキ1杯あたり約11円の減税と試算される
  一方、缶チューハイ等（RTD）は増税
- **人のコストと供給に同時の圧力**。最低賃金は全国加重平均1,177円（2026年度答申）へ。
  特定技能「外食業」は2026年4月13日から新規受入停止
- **明暗が鮮明**。鳥貴族は既存店客数+5.5%（2026年7月期2Q）と値上げ後も客が増える一方、
  総合居酒屋大手は縮小を続け、中小零細の倒産は過去最多

## 9. 用語メモ

本フォルダは各ノート末尾に用語メモを置いている（独立した用語集は作っていない）。

| 用語                              | 意味                                                                                          |
| --------------------------------- | --------------------------------------------------------------------------------------------- |
| **ドリンク比率（D比率）／FD比率** | 売上に占めるドリンクとフードの構成比。居酒屋の損益の主変数 → [①](01_居酒屋の経済.md)          |
| **席あたり売上**                  | 客単価 × 回転率。席という固定資産の生産性 → [①](01_居酒屋の経済.md)                           |
| **2時間制（120分制）**            | 利用時間の上限。追加注文を切るかわりに回転を作る装置 → [①](01_居酒屋の経済.md)                |
| **深夜割増**                      | 22時〜翌5時の25%以上の割増賃金 → [①](01_居酒屋の経済.md)                                      |
| **目的来店型**                    | あらかじめ決めて来る客層。居酒屋が1階でなくても成立する理由 → [①](01_居酒屋の経済.md)         |
| **総合居酒屋／大箱**              | 100品超を揃え団体宴会を主力とした業態と、その大型店舗 → [②](02_市場の縮小と構造変化.md)       |
| **単品特化**                      | 串カツ、餃子、焼き鳥など看板1品に絞る設計 → [②](02_市場の縮小と構造変化.md)                   |
| **ソバーキュリアス**              | 飲めるがあえて飲まない志向 → [②](02_市場の縮小と構造変化.md)                                  |
| **飲み放題**                      | 値引きではなく、原価と人件費を事前に確定させる装置 → [③](03_収益構造の立て直し.md)            |
| **送客手数料**                    | 予約サイト経由の来店1人あたりに払う費用 → [③](03_収益構造の立て直し.md)                       |
| **横丁型／屋台村型**              | 小店舗を集積させ客席・水回りを共用する形式 → [③](03_収益構造の立て直し.md)                    |
| **酒税一本化**                    | 2026年10月1日のビール系税率統一 → [③](03_収益構造の立て直し.md)、[④](04_直近トピック_2026.md) |
| **酒場・ビヤホール**              | 倒産統計などの業種分類名。居酒屋を主体とする区分 → [④](04_直近トピック_2026.md)               |
