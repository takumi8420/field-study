# ④ 直近トピック（2026年9月時点）

報道・公表資料ベースの整理。数値は原則として一次情報（協会統計・調査会社レポート・企業開示）に当たり、
報道ベースのものはその旨を明記した。最新は各出典で確認すること。

このノートで分かること：2026年の居酒屋業界で**何が同時に起きているか**。
月次の売上は前年を上回り続けているのに、なぜ倒産が過去最多なのか。

> ※本ノートは産業構造の解説であり、飲酒を勧めるものではない。
> 20歳未満の飲酒は法律で禁止されている。飲酒には健康上のリスクがある。

---

## 1. 飲食店の倒産が過去最多、最多業態は「酒場・ビヤホール」

帝国データバンクによると、**2026年上半期の飲食店の倒産は473件**で、
前年同期（458件）から3.3%増え、**上半期として過去最多**を更新した（4年連続の増加）。
業態別では**居酒屋を主体とする「酒場・ビヤホール」が125件**で最多。
前年同期（105件）から19.0%増え、こちらも過去最多となった
（全体に占める比率26.4%。2026年7月22日公表）。

| 指標                     | 2026年上半期                      | 前年同期 | 増減        |
| ------------------------ | --------------------------------- | -------- | ----------- |
| 飲食店の倒産（全体）     | **473件**（上半期として過去最多） | 458件    | ＋3.3%      |
| うち酒場・ビヤホール     | **125件**（過去最多）             | 105件    | **＋19.0%** |
| 酒場・ビヤホールの構成比 | 26.4%（最多業態）                 | —        | —           |

通年ベースでは2024年に飲食店倒産が894件と過去最多を更新し、
そのうち**居酒屋が最多の212件**だった（帝国データバンク・2025年1月公表）。

同社が挙げる背景は4つに整理できる。

- **需要側**：大口宴会の減少、二次会需要の低迷という「アフターコロナの新しい生活様式の定着」、
  そして若者のアルコール離れ（→ [②](02_市場の縮小と構造変化.md)）
- **コスト側**：食材・光熱費の高騰と賃上げによる利益圧迫
- **人の供給側**：2026年4月13日以降の外国人労働者の新規受入停止（→ 本ノート4章）
- **格差**：価格転嫁できる大手と、できない中小・零細の差が鮮明に

> 構図：**「業界の数字は良く、個々の店は苦しい」**という状態が続いている。
> 平均値（月次の前年比）は上向きなのに、分布の下側が切れ落ちている。

## 2. 月次は前年超え。ただし店舗数は減り続けている

日本フードサービス協会（JF）の会員社データ（新規店を含む全店ベース・税抜比較）。

| 期間                                      | 売上高     | 店舗数    | 客数   | 客単価 |
| ----------------------------------------- | ---------- | --------- | ------ | ------ |
| **2025年 年間**（パブレストラン／居酒屋） | 104.0%     | 100.3%    | 101.3% | 102.6% |
| うち「居酒屋」内訳                        | 104.4%     | 99.8%     | 101.9% | 102.4% |
| うち「パブ・ビアホール」内訳              | 103.0%     | 102.3%    | 100.2% | 102.7% |
| **2026年7月**（パブ／居酒屋 合計）        | **105.2%** | **99.5%** | 103.7% | 101.5% |
| うち「居酒屋」内訳（2026年7月）           | 105.1%     | 99.6%     | 103.7% | 101.3% |
| （参考）外食全体 2026年7月                | 106.8%     | 101.1%    | 103.2% | 103.5% |

（出典：JF「外食産業市場動向調査」2025年年間結果報告／2026年7月度結果報告）

読みどころは3つ。

- **売上は伸びているが、外食全体には届かない**。2026年7月は業態別で最も低い部類
- **店舗数だけが1を下回り続けている**。外食全体が101.1%なのに、パブ／居酒屋は99.5%。
  **業態としてはまだ縮小局面にある**
- **2019年比では依然として届いていない**。各年の前年比を連鎖させると2025年の売上は
  2019年の約78%（筆者計算。外食全体は約126%）→ 計算の詳細は [②](02_市場の縮小と構造変化.md)

JFは2026年7月について、天候が安定したこと、スポーツ観戦のできるパブレストランが好調だったこと、
**「地域コミュニティの宴会の受け皿として集客に成功したところも見られ」**たことを挙げている。
大口の企業宴会ではなく、**地域単位の小さな集まり**が戻ってきている、という読み方ができる。

## 3. 2026年10月1日、酒税が一本化される

酒税法改正により、**2026年10月1日からビール系飲料（ビール・発泡酒・新ジャンル）の税率が
1kLあたり155,000円（350ml換算54.25円）に一本化**される。

| 品目                | 改正前（350ml換算） | 改正後  | 差                  |
| ------------------- | ------------------- | ------- | ------------------- |
| **ビール**          | 63.35円             | 54.25円 | **▲9.10円（減税）** |
| 発泡酒・新ジャンル  | 46.99円             | 54.25円 | ＋7.26円（増税）    |
| チューハイ等（RTD） | 28円                | 35円    | ＋7.00円（増税）    |

居酒屋にとっては**業務用ビールの減税**が直接の関心事になる。
報道・解説記事の試算では、**生ビール中ジョッキ（約435ml換算）1杯あたり約11円、
業務用19L樽1本あたり約494円の減税**にあたるとされる。
ただし仕入価格がそのまま同額下がるとは限らず、メーカー・卸の値決めに依存する。

一方で**RTD（缶チューハイ等）は増税**となる。
[①](01_居酒屋の経済.md)で見たとおり、サワー・ハイボール類は原価率10〜20%という
**居酒屋の利益の源泉**なので、既製缶を使う店ほど影響を受ける。
店で焼酎・スピリッツから作る場合は影響の出方が異なる。

→ 制度の背景と30年の経緯は
[ビール・酒類 ① 酒税が商品を作った](../08_ビール・酒類/01_酒税が商品を作った.md)、
流通側の動きは [酒類卸](../../06_商社・卸売/08_酒類卸/README.md) を参照。

## 4. 人のコストと供給の天井 — 最低賃金1,177円、特定技能は受入停止

```
【2026年、人にまつわる2つの変化が同時に来た】

  ① 価格が上がる                    ② 量が増えない
  ─────────────                ──────────────
  最低賃金 全国加重平均              特定技能1号「外食業」
  1,121円（2025年度）                分野別上限に到達
        ↓ ＋56円                     ↓
  1,177円（2026年度・答申ベース）     2026年4月13日から新規受入を当面停止
  2026年10月以降 順次発効
        ↓                              ↓
   深夜割増25%が乗る居酒屋は         採用チャネルの一つが止まる
   影響がさらに大きい
```

| 項目               | 内容                                                                                                                      | 年・出典                                           |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| 2026年度 最低賃金  | 答申ベースの全国加重平均 **1,177円**（前年度比+56円）。最高は東京1,280円、最低は宮崎1,085円。引き上げ額最大は佐賀県の65円 | 2026年7〜9月・中央最低賃金審議会／厚生労働省・報道 |
| 目安額             | Aランク54円、B・Cランク56円（2026年7月28日の目安提示）                                                                    | 同                                                 |
| 特定技能「外食業」 | 分野別受入上限に到達し、**2026年4月13日から新規受入を当面停止**                                                           | 2026年・農林水産省ほか                             |
| 技能実習           | 2027年4月に「育成就労」へ移行予定                                                                                         | —                                                  |

居酒屋は売上の一部が22時以降に入るため、**深夜割増（25%以上）**の対象時間が長い。
最低賃金の上昇は、この割増分ごと乗ってくる。
また、夜・土日・立ち仕事という条件から最低賃金より上の時給を提示せざるを得ない店も多く、
**最低賃金1円の上昇が、居酒屋では1円以上のコスト増になる**（→ [③](03_収益構造の立て直し.md)）。

## 5. 各社決算の明暗 — 専門店と複合業態が強い

| 企業                                           | 直近の業績                                                                                                                                                                                                                               | 出典・時期                            |
| ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------- |
| **ワタミ**                                     | 2026年3月期 連結売上 932.7億円（+5.1%）、営業利益 48.4億円（+5.9%）。**国内外食事業は売上376.7億円（+9.5%）、セグメント利益22.6億円（+40.5%）**。新規42店・撤退17店で期末517店                                                           | 2026年5月・同社決算発表／流通ニュース |
| **エターナルホスピタリティグループ**（鳥貴族） | 2026年7月期 売上 512.5億円（+10.6%）。**増収だが営業減益**（販管費増と第4四半期偏重の出店費用）。純利益は前期比23%減と、増益予想から一転したと報じられる。2026年7月期第2四半期は国内「鳥貴族」既存店 売上+9.8%（客数+5.5%、客単価+4.0%） | 2026年9月・同社決算短信／日本経済新聞 |
| **串カツ田中HD**                               | 2026年11月期は会社予想で売上 361.4億円（前期比+71.3%）と大幅増収の一方、**営業利益10億円（▲15.7%）・経常利益9.6億円（▲22.3%）・純利益4.2億円（▲43.6%）と減益見通し**。増収減益予想を嫌気して株価が続落したと報じられる                   | 2026年1月・同社開示／日本経済新聞     |
| **モンテローザ**（非上場／白木屋・魚民ほか）   | コロナ禍前に1,000億円超だった売上高が500億円台まで縮小し、店舗数も大幅に絞り込んだと報じられる。空き物件への素早い出店（「後出しジャンケン」戦略）も転換                                                                                 | 2026年1月・東洋経済オンライン         |

読み取れることは3つ。

- **売上は伸びている。利益は伸びていない**。鳥貴族も串カツ田中も増収減益。
  原材料・人件費・出店費用の上昇が利益を食っている
- **単品特化ブランドは客数が取れている**。鳥貴族の既存店は客数+5.5%（2026年7月期2Q）で、
  **値上げしても客が増えている**という外食では稀な状態
- **複合業態化が効いている**。ワタミは宅食・外食・焼肉・SUBWAYを持ち、
  居酒屋の変動を他事業で相殺できる構造になっている

## 6. インバウンドと需要の平準化

JFは2025年の年間総括で、大阪・関西万博（2025年4〜10月）と
**訪日外客数の過去最高**を外食売上のプラス要因として挙げている。
2026年7月度では逆に「大阪エリアでは昨年の万博の反動で振るわないところもあった」と、
**反動減**にも言及している（ディナーレストラン業態に関する記述）。

居酒屋・横丁・屋台村は訪日客に人気の高いカテゴリーとされ、
訪日ラボなどの集計でも渋谷など繁華街の居酒屋がランキング上位に入る（2026年8月）。

| 効果                 | 中身                                                                                  |
| -------------------- | ------------------------------------------------------------------------------------- |
| 客数の補填           | 国内の客数減を部分的に埋める                                                          |
| **曜日波動の平準化** | 旅行者は曜日を選ばない。金曜集中という最大の弱点を薄める（→ [①](01_居酒屋の経済.md)） |
| 客単価               | 注文点数が積み上がりやすい                                                            |
| 偏り                 | **繁華街・観光地の店に恩恵が集中**。郊外の大箱には届かない                            |
| 対応コスト           | 多言語メニュー、アレルギー・宗教上の制約の明示、海外カード・QR決済対応                |

## 7. 全体の構図

```
【2026年の居酒屋をひとことで】

   月次売上 105%前後 ── 前年は超える
        ×
   店舗数  99.5%    ── まだ減っている
        ×
   2019年比 約78%   ── 外食で唯一、戻っていない
        ×
   倒産    過去最多  ── 酒場・ビヤホールが最多業態
        ＝
   「業態全体は縮小の途中、個々の店は二極化の途中」
```

- **数字が良いのは平均であって、分布ではない**。値上げが通る店（専門店・ブランドのある店）と、
  通らない店（総合居酒屋・低価格帯）の差が、増収と倒産最多を同時に生んでいる
- **コストは3方向から同時に上がっている**。食材、光熱費、人件費（最低賃金1,177円）。
  さらに人の供給側には特定技能の受入停止という制度的な天井ができた
- **追い風は小さい**。2026年10月の酒税一本化による業務用ビールの減税は
  中ジョッキ1杯あたり約11円で、損益を変えるほどの規模ではない
- **需要の単位は小さいまま**。企業の大口宴会ではなく、地域・少人数の集まりが戻っている。
  これに合わせて店の形を作り替えられた側だけが残る（→ [③](03_収益構造の立て直し.md)）

## 用語メモ

| 用語                       | 意味                                                                                     |
| -------------------------- | ---------------------------------------------------------------------------------------- |
| **酒場・ビヤホール**       | 倒産統計などで使われる業種分類。居酒屋を主体とする区分                                   |
| **パブレストラン／居酒屋** | JFの業態分類。内訳として「パブ・ビアホール」と「居酒屋」に分かれる                       |
| **全店ベース**             | 新規店を含む集計。既存店のみの集計（既存店前年比）とは別物                               |
| **酒税一本化**             | 2026年10月1日にビール系飲料の税率を1kL＝155,000円へ統一する改正                          |
| **答申ベースの最低賃金**   | 地方最低賃金審議会の答申額。発効は都道府県ごとに10月以降順次                             |
| **特定技能1号「外食業」**  | 外食現場で就労できる在留資格。2026年4月13日から新規受入を当面停止                        |
| **増収減益**               | 売上は増えたが利益は減った状態。2026年の外食で頻出。原材料・人件費・出店費用の上昇が原因 |
