# ③ 収益構造の立て直し — 単価・稼働時間・人手の3方向

このノートで分かること：客数が2019年の3分の2しか戻っていない業態が、
**どうやって損益を成立させ直しているか**。
飲み放題という仕組みの経済的な意味、人手不足と最低賃金への対処、
モバイルオーダーと予約のDX、インバウンド、そして業態そのものの作り替え。

> 結論：居酒屋の立て直しは、**打ち手が3方向しかない**。
> ①**客単価を上げる**（コース化、専門店化、ノンアル拡充）
> ②**稼働していない時間・面積を使う**（昼営業、小箱化、横丁・フードコート型）
> ③**人にかかる費用を減らす**（モバイルオーダー、セルフ、外国人材）。
> どれも「客数が戻る」ことを前提にしていないのが特徴で、
> **客数が戻らないまま成立する店の形を作り直す作業**だと言い換えられる。

前提となる1店舗の損益の読み方は [① 居酒屋の経済](01_居酒屋の経済.md)、
なぜ客数が戻らないのかは [② 市場の縮小と構造変化](02_市場の縮小と構造変化.md) を参照。

> ※本ノートは産業構造の解説であり、飲酒を勧めるものではない。
> 20歳未満の飲酒は法律で禁止されている。飲酒には健康上のリスクがある。

## 1. 打ち手の全体図

```
【客数が戻らない前提で、損益をどう作り直すか】

   売上 ＝ 客数 × 客単価              費用 ＝ F（原価）＋ L（人件費）＋ R（家賃）
           ↑戻らない  ↑ここを上げる              ↑           ↑上がり続ける ↑固定

  ① 単価を上げる      コース化／セット化、専門店化、飲み放題の設計、ノンアル拡充
  ② 稼働を広げる      昼営業、小箱化、横丁・フードコート型、インバウンドの取り込み
  ③ 人の費用を下げる   モバイルオーダー、セルフ／配膳ロボット、外国人材、営業時間短縮
```

| 方向   | 効くところ       | 限界・副作用                               |
| ------ | ---------------- | ------------------------------------------ |
| ① 単価 | 売上・粗利       | 上げすぎると客数がさらに減る（値上げ疲れ） |
| ② 稼働 | 売上・家賃の吸収 | 昼と夜で商品も人も別に用意が必要           |
| ③ 人   | 人件費率         | 接客品質の低下、初期投資が必要             |

## 2. 単価の引き上げとコース化

[②](02_市場の縮小と構造変化.md)で見たとおり、パブレストラン／居酒屋の客単価は
2019年比で約17%上昇している（JFデータからの筆者計算）。
2025年の年間では客単価102.6%、2026年7月は101.5%と、上昇は続いている（JF公表値）。

問題は、**値上げだけでは限界がある**こと。
外食の値上げは必ず客数減とセットになる（→ [外食1店舗の経済](../14_ファストフード/01_外食1店舗の経済.md) 7章）。
そこで各社が選んだのが、単品の値上げではなく**「売り方を変えて単価を上げる」**方法だった。

| 手法                       | 何をしているか                                   | 単価への効き方                               |
| -------------------------- | ------------------------------------------------ | -------------------------------------------- |
| **コース化**               | 個別注文をやめ、3,000〜5,000円の組み合わせで売る | 注文点数の下振れを防ぎ、**単価を下限で固定** |
| **セット化**               | 「刺身3種＋日本酒」のような組み合わせ販売        | 単品では頼まれない品を抱き合わせる           |
| **名物の高単価化**         | 看板商品だけ価格帯を上げる                       | ブランド価値のある1品に価格決定力を持たせる  |
| **ノンアル・低アルの拡充** | 飲まない客にもドリンクを売る                     | **単価ゼロの客を作らない**                   |
| **少量多品種**             | 小皿・ハーフサイズを増やす                       | 注文点数を増やして単価を積む                 |

> ポイント：居酒屋の客単価は **「1品単価 × 注文点数」**でできている。
> 値上げは前者を動かすが客数を削る。**コース化は後者を確定させる**ので、
> 客数を削らずに単価の下振れを止められる。
> だから宴会需要が減った今も、コース販売そのものはむしろ強化されている。

## 3. 食べ放題・飲み放題の経済

「飲み放題」は居酒屋を象徴する仕組みだが、**値引きではなく原価の確定装置**である。

```
【2時間飲み放題 1,800円（1杯あたり原価70円と仮定）の経済】

  軽く飲む客   3杯 → 原価 210円 → 原価率 11.7%   店にとって有利
  平均的な客   5杯 → 原価 350円 → 原価率 19.4%   設計の中心
  多く飲む客   8杯 → 原価 560円 → 原価率 31.1%   フード並みに悪化
  極端な客    12杯 → 原価 840円 → 原価率 46.7%   赤字ラインに接近
         ↑
  客ごとにはブレるが、40人の宴会で平均すればブレは小さくなる
  ＝ 人数が多いほど「平均に収束する」ので読みが当たる
```

（原価70円は割りもの中心の一般的な水準を置いたモデル計算。品揃えで大きく変わる）

| 店にとっての効果         | 中身                                                                            |
| ------------------------ | ------------------------------------------------------------------------------- |
| **原価が事前に確定する** | 注文内容にかかわらず1人1,800円の売上。平均杯数が読めれば原価も読める            |
| **人件費が下がる**       | 注文を都度受けず、まとめて出せる。**ホールの動きが単純になる**                  |
| **客単価の下限が上がる** | 「1杯だけ」で帰る客がいなくなる                                                 |
| **提供品目を絞れる**     | 飲み放題対象を限定すれば仕入も在庫も単純化できる                                |
| リスク                   | 想定以上に飲む集団が来ると原価率が崩れる。だから**90分・120分の時間制限**が付く |

時間制限は「飲み放題の損失の上限を決める」装置であり、
[①](01_居酒屋の経済.md)で見た2時間制と**同じ理由から来ている**。
食べ放題も構造は同じだが、こちらは**原価率が読みにくい**という違いがある。

|                | 飲み放題                   | 食べ放題                                                         |
| -------------- | -------------------------- | ---------------------------------------------------------------- |
| 1回あたり原価  | 小さく、揃っている         | 品目によって数倍の差（肉と野菜）                                 |
| 消費の上限     | 体調・時間で自然に止まる   | 上限が読みにくい                                                 |
| 人手           | ほぼ不要（注いで運ぶだけ） | **調理が発生し続ける**                                           |
| 向いている業態 | 居酒屋全般                 | [焼肉](../18_焼肉・ラーメン/README.md)など客が自分で調理する業態 |

> ポイント：**飲み放題が居酒屋にこれほど広く定着したのは、ドリンクが「原価が低く・人手を使わず・
> 消費量が自然に頭打ちになる」商品だからである。**
> 食べ放題を同じ気軽さで導入できないのは、この3条件のどれも満たさないため。

近年は**「ノンアル飲み放題」「ソフトドリンク飲み放題」の価格を別建てにする**店が増えている。
飲まない人の参加ハードルを下げつつ、単価をゼロにしない設計である。

## 4. 人手不足と外国人材 — 制度に天井ができた

居酒屋の人件費は、2つの方向から同時に押し上げられている。

| 要因                                 | 内容                                                                                                                                   | 年・出典                                           |
| ------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| **最低賃金の上昇**                   | 2026年度の答申ベース全国加重平均 **1,177円**（前年度1,121円から+56円）。最高は東京1,280円、最低は宮崎1,085円。発効は2026年10月以降順次 | 2026年8〜9月・厚生労働省／中央最低賃金審議会・報道 |
| **深夜割増**                         | 22時〜翌5時は25%以上の割増（労働基準法）。居酒屋は売上の一部がこの帯に入る                                                             | —                                                  |
| **特定技能「外食業」の新規受入停止** | 分野別の受入上限に到達し、**2026年4月13日から新規受入を当面停止**。技能実習は2027年4月に育成就労へ移行予定                             | 2026年・農林水産省ほか                             |
| 採用難                               | 夜間・土日勤務という条件が、学生・主婦層の応募と構造的に合いにくい                                                                     | —                                                  |

```
【居酒屋の人件費が下がらない三重の理由】

  ① ピークが「金曜19〜21時」に一点集中 → 必要人数はそこで決まるのに月曜にも払う
  ② 売上の一部が22時以降にある         → 深夜割増で同じ1時間の単価が25%高い
  ③ 働き手にとって条件が悪い（夜・土日）→ 最低賃金より上を出さないと採れない

  ＝ 最低賃金が1円上がると、居酒屋は「1円以上」のコスト増を受ける
```

**特定技能「外食業」の新規受入停止**は、この業界にとって単なる制度変更ではない。
[ファストフード ④ 人手不足と省力化](../14_ファストフード/04_人手不足と省力化.md)でも扱ったとおり、
外食は外国人材の比率が高い業種であり、**人の供給側に制度的な天井ができた**ことを意味する。
帝国データバンクも2026年上半期の倒産動向で、この受入停止を
「急速に進む環境変化に対応できない飲食店の淘汰」の一因として挙げている。

→ 採用チャネルそのものについては
[人材派遣](../../15_サービス・生活関連/01_人材派遣/README.md)・
[人材紹介・求人メディア](../../15_サービス・生活関連/02_人材紹介・求人メディア/README.md) を参照。

## 5. DX — モバイルオーダー、予約、決済

居酒屋のDXは「便利にする」話ではなく、**人を減らすための投資**である。
どこで人を使っているかを分解すると、投資先がはっきりする。

| 店内の作業           | 誰が担うか（従来）         | DXによる置き換え                 | 経済的な効果                                                   |
| -------------------- | -------------------------- | -------------------------------- | -------------------------------------------------------------- |
| 注文を受ける         | ホール（呼ばれて卓へ行く） | **卓上QR・モバイルオーダー**     | ホール人数を削減。同時に**追加注文が増える**（呼ばなくてよい） |
| 料理・ドリンクを運ぶ | ホール                     | 配膳ロボット、セルフドリンクバー | 往復距離を削減                                                 |
| 会計                 | レジ担当                   | **卓上決済・キャッシュレス**     | ピーク終わりの行列を解消                                       |
| 予約を受ける         | 電話対応                   | **予約サイト・ネット予約**       | 営業中の電話対応が消える                                       |
| 仕込み量を決める     | 店長の経験                 | 予約データからの発注             | **食材ロスの削減＝原価率改善**                                 |

> ポイント：モバイルオーダーの効果は**人件費だけではない**。
> 「店員を呼ぶ」という行為が消えるので、**追加注文の回数が増える**。
> [①](01_居酒屋の経済.md)で見たとおり、居酒屋の利益はドリンクの杯数に比例する。
> **注文の摩擦を減らすことは、そのままドリンク比率を上げる施策**でもある。

予約については別の論点がある。**予約サイトへの手数料**である。

```
【集客チャネルごとのコスト構造（概念図）】

  自店の予約（電話・自社サイト・常連）  手数料ゼロ。ただし集客力は自力
  地図アプリ・SNSからの直接来店        実質無料。ただしコントロールしにくい
  グルメサイト・予約サイト経由          月額掲載料＋予約1人あたり課金
                                       ＝ 売上が増えるほど費用も増える
  デリバリープラットフォーム            注文金額の30%前後（居酒屋では限定的）
```

居酒屋は[①](01_居酒屋の経済.md)7章で見たとおり**目的来店型**で、
2階・地下という「探さないと見つからない」区画に入っていることが多い。
つまり**見つけてもらう手段を外部に握られやすい**。
掲載料と送客手数料をどこまで払うかは、家賃に次ぐ固定費の判断になる
（→ [プラットフォーム・SNS](../../04_情報通信・IT・ネット/09_プラットフォーム・SNS/README.md)、
[フィンテック・キャッシュレス](../../04_情報通信・IT・ネット/13_フィンテック・キャッシュレス/README.md)）。

## 6. インバウンド — 客数の穴を埋める新しい層

訪日外国人の増加は、居酒屋にとって**失われた客数を部分的に埋める要因**になっている。
JFも2025年の年間総括で、大阪・関西万博と訪日外客数の過去最高を
外食売上のプラス要因として挙げている。

| 居酒屋がインバウンドに向く理由 | 中身                                                                       |
| ------------------------------ | -------------------------------------------------------------------------- |
| **体験そのものが商品**         | 料理だけでなく「日本の酒場の空気」が目的になる。横丁・屋台村が人気を集める |
| **少人数・短時間**             | 2〜4人の来店が中心で、宴会を前提としない現在の店の形と合う                 |
| **客単価が高くなりやすい**     | 品数を多く頼む傾向があり、注文点数が積み上がる                             |
| **曜日波動を平らにする**       | 旅行者は月曜でも来る。**金曜集中という最大の弱点を薄める**                 |

一方で対応コストもかかる。**多言語メニュー**（写真付き）とアレルギー・宗教上の制約の明示、
**海外カード・QR決済**への対応、注文の摩擦を減らすモバイルオーダー（5章と同じ投資が効く）。
さらに立地依存が強く、**繁華街・観光地の店に恩恵が偏る**という限界もある。

→ 訪日需要の全体像は [ホテル](../../15_サービス・生活関連/09_ホテル/README.md)、
[旅行](../../15_サービス・生活関連/10_旅行/README.md) を参照。

## 7. 業態そのものを作り替える — 小箱化・横丁・昼営業

もっとも根本的な打ち手は、**店の形を需要の単位に合わせて作り直す**ことである。

| 型                   | 中身                                       | 経済的な狙い                                                                    |
| -------------------- | ------------------------------------------ | ------------------------------------------------------------------------------- |
| **小箱化・立ち飲み** | 20〜50席、立ち飲み中心、滞在短め           | 家賃の絶対額を下げ、**回転率を上げる**。撤退も軽い                              |
| **単品特化の専門店** | 串カツ、餃子、焼き鳥、唐揚げなど           | 来店理由を作る。仕入・仕込み・教育が単純化（→ [②](02_市場の縮小と構造変化.md)） |
| **横丁・屋台村型**   | 1区画に小店舗を集積させる                  | 1店あたりの投資を小さくし、**集積そのものが集客装置**になる。ハシゴ需要を内部化 |
| **フードコート型**   | 共用の客席に複数の専門店が面する           | **客席と洗い場を共有**して1店あたりの面積負担を下げる                           |
| **昼営業への進出**   | 夜の設備で昼定食・ランチを出す             | **家賃と設備の稼働時間を伸ばす**。1日の売上の底上げ                             |
| **複合業態化**       | 居酒屋＋焼肉＋テイクアウトを同一企業で持つ | 需要変動を業態間で相殺する（ワタミが典型）                                      |

```
【横丁・フードコート型が効く理由】

  ■ 単独の居酒屋        客席・トイレ・洗い場・厨房を1店で全部持つ
                         50坪のうち客席30坪・厨房20坪。家賃は50坪分

  ■ 横丁・フードコート型  客席・トイレ・洗い場を共用し、各店は厨房＋カウンターだけ
                         1店あたり8〜15坪で成立 → 家賃負担が数分の1に
                         ＋ 隣の店の客が流れる（集積の効果）
                         ＋ 1店が撤退しても区画全体は生き残る
```

**昼営業**は理屈としては正しいが、簡単ではない。
昼の客単価は1,000円前後と**夜の3〜4分の1**しかなく、昼の人手を別に確保する必要があり
（夜のスタッフは出勤できない）、仕込みと仕入が二重になってロス管理も複雑になる。
それでも**家賃と設備は昼も夜も同じだけかかっている**ので、
昼の粗利が固定費を少しでも吸収するなら意味がある。

> ポイント：昼営業は「儲かるから」ではなく
> **「家賃という払い済みの費用を、何かで回収するため」**に行われる。
> [ファストフード](../14_ファストフード/README.md)のアイドルタイム対策（夜マック等）と
> まったく同じ論理が、居酒屋では**昼という時間帯まるごと**に対して働いている。

## 8. 追い風になる制度 — 2026年10月の酒税一本化

2026年10月1日、ビール系飲料（ビール・発泡酒・新ジャンル）の酒税率が
**1kLあたり155,000円（350ml換算54.25円）に一本化**される（酒税法改正）。
350ml換算でビールは9.10円の減税、発泡酒・新ジャンルは7.26円、
チューハイ等（RTD）は7.00円の増税になる（税額の一覧は [④](04_直近トピック_2026.md) 3章。
制度の背景は [ビール・酒類 ① 酒税が商品を作った](../08_ビール・酒類/01_酒税が商品を作った.md)）。

居酒屋にとっての意味は、**業務用ビールが安くなる**ことである。

```
【業務用19L樽（生ビール）への効き方・試算】

  19,000ml ÷ 350ml ≒ 54.3 単位 × 9.10円 ≒ 約494円／樽の減税
  中ジョッキ（約435ml換算）1杯あたり 約11円の減税

  ※ 仕入価格がそのまま同額下がるとは限らない（メーカー・卸の値決め次第）
  ※ 一方で缶チューハイ等は増税。店で使う焼酎・スピリッツ類の扱いは品目による
```

[①](01_居酒屋の経済.md)で見たとおり、**生ビールは原価率25〜35%とドリンクの中では高い商品**である。
その原価が下がることは、ドリンク全体の粗利を押し上げる。
ただし1杯あたり11円程度なので、**それだけで損益が変わるほどの規模ではない**。
むしろ重要なのは、メーカー各社がビールカテゴリーへ商品・販促を集中させることで、
**業務用ビールの選択肢と販促支援が厚くなる**という間接的な効果のほうだとされる。

一方で、RTD（缶チューハイ等）の増税は、
[①](01_居酒屋の経済.md)で見た**低原価ドリンクの主力であるサワー系の原価**に影響し得る。
店で焼酎とソーダから作る場合と、既製の缶を使う場合で効き方が異なるため、
**どこまで自店で作るか**という判断に跳ね返る。

---

## 9. まとめ — どの打ち手も「客数が戻る」ことを前提にしていない

| 打ち手             | 効く指標               | 前提としているもの         |
| ------------------ | ---------------------- | -------------------------- |
| コース化・セット化 | 客単価                 | 来た客が確実に一定額を使う |
| 飲み放題の設計     | 原価率・人件費率       | 平均に収束する人数が来る   |
| ノンアル拡充       | ドリンク比率           | 飲まない客も来る           |
| モバイルオーダー   | 人件費率・ドリンク比率 | 初期投資を回収できる店数   |
| 小箱化・横丁型     | 家賃比率               | 需要の単位が小さいまま続く |
| 昼営業             | 家賃の吸収             | 昼にも人を確保できる       |
| インバウンド       | 客数・曜日波動         | 訪日需要が続く             |
| 酒税一本化         | 原価率（小幅）         | 仕入価格に反映されること   |

> ポイント：2020年代の居酒屋の立て直しは、
> **「宴会が戻ってくる日を待つ」ことを完全にやめたところから始まっている**。
> 大箱を畳み、席数を減らし、看板商品を作り、昼にも開け、
> 注文の摩擦を減らし、飲まない客にも売る。
> これらはすべて「20人で1回」ではなく「4人で2回」という需要に合わせた再設計であり、
> **そこへ作り替えられた店と、作り替えられなかった店の差**が、
> 大手の増収と中小の倒産最多という同時進行を生んでいる（→ [④](04_直近トピック_2026.md)）。

## 用語メモ

| 用語                         | 意味                                                                                                                       |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| **コース化**                 | 個別注文ではなく、決まった品数・価格の組み合わせで売ること。客単価の下限を確定させる                                       |
| **飲み放題**                 | 定額でドリンクを提供する仕組み。値引きではなく**原価と人件費を事前に確定させる装置**。損失の上限を切るために時間制限が付く |
| **モバイルオーダー／卓上QR** | 客自身の端末や卓上端末から注文する仕組み。ホール人員を減らすと同時に、追加注文の回数を増やす                               |
| **送客手数料**               | 予約サイト経由の来店1人ごとに支払う費用。掲載料と合わせ、家賃に次ぐ固定費になり得る                                        |
| **特定技能1号「外食業」**    | 外食現場で就労できる在留資格。分野別上限に達し2026年4月13日から新規受入を当面停止                                          |
| **育成就労**                 | 技能実習に代わる新制度。2027年4月に移行予定とされる                                                                        |
| **小箱化**                   | 席数・面積を小さくした店づくり。家賃の絶対額と撤退リスクを下げる                                                           |
| **横丁型／屋台村型**         | 小規模店舗を1区画に集積させる形式。客席・水回りを共用し、集積自体が集客装置になる                                          |
| **酒税一本化**               | 2026年10月1日にビール系飲料の税率を1kL＝155,000円へ統一する改正。ビールは減税、発泡酒・新ジャンル・RTDは増税               |
| **アイドルタイム**           | 客が少なく人件費と家賃だけがかかる時間帯。居酒屋では昼の時間帯がまるごとこれに当たる                                       |
