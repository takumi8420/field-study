# ③ 原料と市場 — 生豆相場は歴史的高値、日本の消費は頭打ち

このノートで分かること：コーヒー豆がどこから来てどう値段が決まるのか。
2024年以降の歴史的高騰が何によって起き、日本のカフェにどう効いたのか。
そして日本のコーヒー消費が伸びないなかで、
カフェが紅茶・抹茶へ広がっている理由。

> 結論：**コーヒーは農作物であり、生産地はブラジルとベトナムにほぼ集中している**。
> だから両国の天候が、そのまま世界の価格になる。
> 日本の生豆輸入単価は **2020年の289円/kgから2025年には1,010円/kg** へ
> 5年で約3.5倍になった（財務省貿易統計、全日本コーヒー協会まとめ）。
> 円安が重なり、ここに**輸入国側の追加負担**が乗った。
> 一方で日本のコーヒー消費量は **2025年で39.7万トン、前年比99.3%** と頭打ちで、
> 1人あたり消費量もむしろ減っている。
> **原料は上がり、需要は増えない**。これが日本のカフェが直面している基本構図である。

## 1. コーヒーが1杯になるまで（川上 → 川下）

```
【コーヒーのバリューチェーン】

 栽培・収穫      精製・脱穀      輸出          輸入・保管      焙煎        卸・小売
 ──────────   ──────────   ──────────   ──────────   ──────────  ──────────
 コーヒー農家 ─▶ 精製業者 ─▶ 現地輸出業者 ─▶ 商社（日本） ─▶ ロースター ─▶ カフェ
 （小規模が大半）  果肉を除き                  ＋保税倉庫    UCC、キーコーヒー  コンビニ
                  生豆にする                                各社自社焙煎     スーパー・EC
                                                            個人焙煎所          │
                                                                                ▼
                                                                             ☕ 1杯

  ※ 付加価値は「焙煎より後」に集まる。生豆1kg＝約1,000円が、
    カフェで1杯300円 × 約80杯 ＝ 24,000円の売上になる（→ ①）
```

- **生産者の取り分は小さい**。生豆1kgが約1,000円（2025年の日本の輸入単価）で、
  そのうち農家の手取りは数百円。ここがフェアトレード論の出発点になる
- **焙煎（ロースト）が日本側の最初の工程**。生豆のままでは商品にならず、
  焙煎で約**2割の重量が水分として失われる**。だから焙煎豆1kgには生豆1.2kgが要る
- 焙煎から先は国内産業。ここが値上げの実行主体になる

## 2. アラビカとロブスタ — 2つの品種でまったく別の相場

コーヒーの商業品種は実質2つ。**この違いを押さえないと相場のニュースが読めない**。

| 項目                 | **アラビカ種**                                   | **ロブスタ種（カネフォラ）**                                               |
| -------------------- | ------------------------------------------------ | -------------------------------------------------------------------------- |
| 世界生産に占める比率 | 約6割                                            | 約4割                                                                      |
| 主産地               | ブラジル、コロンビア、中米、エチオピア           | **ベトナム**、インドネシア、ブラジル、ウガンダ                             |
| 栽培条件             | 標高が高く冷涼な土地。**病害・霜・干ばつに弱い** | 低地でも育つ。**病害に強く収量が多い**                                     |
| 味                   | 酸味と香りがある。レギュラーコーヒー向き         | 苦味が強く香りが弱い。**インスタント・缶コーヒー・エスプレッソの増量**向き |
| 取引所               | ニューヨーク（ICE）                              | ロンドン（ICE）                                                            |
| 価格                 | 高い                                             | 安い（アラビカの半分前後）                                                 |

2026年7月のICO（国際コーヒー機関）の平均価格は次のとおり（全日本コーヒー協会訳、2026年8月）。

| 品目グループ                 | 2026年7月平均       | 前月比     |
| ---------------------------- | ------------------- | ---------- |
| **ICO複合指標価格（I-CIP）** | **287.26セント/lb** | **+15.4%** |
| コロンビア・マイルド         | 383.39セント/lb     | +18.1%     |
| アザー・マイルド             | 358.65セント/lb     | +16.5%     |
| ブラジル・ナチュラル         | 320.69セント/lb     | +17.9%     |
| ロブスタ                     | 184.78セント/lb     | +9.1%      |
| ニューヨーク（アラビカ先物） | 310.34セント/lb     | +20.9%     |
| ロンドン（ロブスタ先物）     | 172.73セント/lb     | +10.8%     |

> ポイント：「コーヒーが上がった」という報道は、
> **たいていアラビカの話**である。
> 缶コーヒーやインスタントに効くのはロブスタで、動き方が違う。
> カフェのドリップコーヒーはアラビカ主体なので、
> **カフェの原価に効くのはニューヨーク市場のほう**と覚える。

## 3. 相場はどう決まるのか

コーヒー相場を動かす要因は、大きく4つに整理できる。

| 要因                   | 中身                                               | なぜ効くか                                    |
| ---------------------- | -------------------------------------------------- | --------------------------------------------- |
| **① 生産国の天候**     | ブラジルの霜・干ばつ、ベトナムの降雨、エルニーニョ | 生産が2か国に集中しており、代替が利かない     |
| **② 在庫水準**         | 取引所の認証在庫（受渡し可能な在庫）               | 在庫が薄いと少しの供給不安で価格が跳ねる      |
| **③ 投機資金**         | ファンドの買い越し・売り越し、証拠金の変更         | 先物市場なので、実需と無関係に値が動く        |
| **④ 為替・物流・政策** | ドル円、海上運賃、輸出国の政策、輸入関税           | 日本の仕入値は**ドル建て相場 × 為替**で決まる |

```
【2026年7月に起きたこと（ICOレポートより）】

  ブラジルの天候懸念／エルニーニョ見通し／米国の認証在庫 ▲30.0%
  （2024年1月以来の最低）  ──▶ 「来年の玉が足りないかも」という予想
                               ▼
  I-CIP が1か月で +15.4%。7月6日・9日には日次で +8.2%、+9.3% の異常な上昇
                               ▼
  ICEの証拠金（取引に必要な担保）引き上げも重なり、値動きがさらに荒くなった
```

> ポイント：**相場が高いことより、乱高下していることのほうが実務では厄介**。
> ロースターは数か月先の豆を先に買う（先物買い付け）ため、
> 高値づかみのリスクを避けようとすると仕入を細切れにせざるを得ず、
> 結果として**仕入単価が読めなくなる**。
> 「値上げを何度も小刻みにやる」のは、この読めなさの裏返しである。

## 4. 歴史的高騰の経緯 — 日本の輸入単価で見る

国際相場は現地通貨とドルの話なので、日本の実感に直結しない。
**日本にいくらで入ってきたか**を財務省貿易統計で追うのが最も確実。

| 年                   | 生豆輸入量      | **輸入単価**   | 備考                     |
| -------------------- | --------------- | -------------- | ------------------------ |
| 2010年               | 410,530トン     | **283円/kg**   | 長く200〜300円台が続いた |
| 2020年               | 391,611トン     | **289円/kg**   | 10年間ほぼ横ばい         |
| 2023年               | 355,652トン     | **571円/kg**   | 2倍に                    |
| 2024年               | 360,287トン     | **677円/kg**   | さらに上昇               |
| **2025年（確々報）** | **359,382トン** | **1,010円/kg** | **2020年の約3.5倍**      |

（出典：財務省「貿易統計」、全日本コーヒー協会「日本のコーヒー生豆の国別輸入量・単価」）

```
【日本の生豆輸入単価の推移（円/kg）】

  2010年   283 ██
  2020年   289 ██
  2023年   571 ████
  2024年   677 █████
  2025年 1,010 ████████

  ▲ 2020→2025 の5年で 約3.5倍。ここに円安が重なっている
```

- 輸入**量**は減っているのに、輸入**額**は急増した。
  つまり日本は「同じ量を高く買っている」状態
- 主要3か国（ブラジル・ベトナム・コロンビア）で**2025年は輸入量の76.4%**。
  調達先の集中がそのままリスクになる

| 国         | 2020年単価 | 2025年単価 | 倍率        |
| ---------- | ---------- | ---------- | ----------- |
| ブラジル   | 278円/kg   | 981円/kg   | 約3.5倍     |
| ベトナム   | 175円/kg   | 821円/kg   | **約4.7倍** |
| コロンビア | 374円/kg   | 1,206円/kg | 約3.2倍     |
| ケニア     | 847円/kg   | 1,360円/kg | 約1.6倍     |

> ポイント：**安いロブスタ（ベトナム）の上がり方が一番激しい**。
> インスタント・缶コーヒー・業務用の増量に使われる安価な豆が高くなったため、
> 「安いコーヒー」ほど値上げ率が大きくなった。
> コンビニコーヒーや[清涼飲料の缶コーヒー](../09_清涼飲料/03_商品カテゴリと競争.md)の
> 値上げが相次いだのはこの経路による。

## 5. 2025〜2026年の値上げラッシュ

原料高は、**まず家庭用・業務用のレギュラーコーヒーに出て、あとから店頭価格に出た**。
ここでは川上側（ロースター）の動きだけを扱い、
カフェチェーンとコンビニの店頭価格は [④ 直近トピック](04_直近トピック_2026.md) にまとめる。

| 時期           | 主体         | 内容                                                                                  | 出典         |
| -------------- | ------------ | ------------------------------------------------------------------------------------- | ------------ |
| 2025年3月      | AGF          | ブレンディ等172品を15〜30%値上げ                                                      | 報道ベース   |
| 2025年7月      | AGF          | コーヒーほぼ全品176品種を**25〜55%**値上げ                                            | 報道ベース   |
| 2025年12月     | キーコーヒー | 2026年3月1日納品分から家庭用の一部を10〜30%値上げ発表                                 | 報道ベース   |
| 2025年12月22日 | UCC上島珈琲  | 2026年3月1日出荷分から業務用・家庭用レギュラーコーヒーを改定、店頭は10〜18%上昇見込み | 同社リリース |
| 2026年7月9日   | UCC上島珈琲  | 2026年11月1日出荷分から家庭用飲料を改定、店頭は5〜10%上昇見込み                       | 同社リリース |

UCCは値上げの理由として、**「コーヒー生豆国際相場が過去最高値を記録」**したことに加え、
包装資材・物流費・エネルギー価格の高騰、および急激な円安を挙げている（同社リリース）。
店頭では、ドトールが2026年7月23日にブレンドコーヒーSを280円→300円へ、
スターバックスが2026年10月9日から定番ビバレッジを4〜35円引き上げるなど、
**2026年に「店で飲む1杯」の値段が動いた**。

> ポイント：[① カフェの経済](01_カフェの経済.md) で見たとおり、
> 生豆が倍になっても**1杯あたりの豆代は十数円しか増えない**。
> それでも各社が20〜30円単位で値上げするのは、
> **豆代だけでなく人件費・家賃・資材・エネルギーが同時に上がっている**から。
> 「コーヒー豆が上がったから値上げ」という説明は、
> 消費者に伝わりやすい**説明の便法**という側面もある。

## 6. サステナビリティ — 「2050年問題」と認証

コーヒー業界には、相場とは別の長期リスクがある。

- **コーヒーの2050年問題** ＝ 気候変動により、2050年までに
  **アラビカ種の栽培適地が現在の約半分に減る**とする研究がたびたび引用される。
  アラビカは標高が高く冷涼な土地でしか育たないため、温暖化に弱い
- **生産者の高齢化と離農**。相場が安い年に赤字になる農家が多く、
  他作物（果樹など）へ転換すると供給は元に戻らない
- **森林破壊**。増産のために森林を切り開くと、規制と環境の両面で問題になる

| 枠組み                                 | 中身                                                                                                                                                                                      | 位置づけ                                                         |
| -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| **フェアトレード認証**                 | 生産者に最低価格とプレミアムを保証する第三者認証                                                                                                                                          | 価格の下支えが目的                                               |
| **レインフォレスト・アライアンス認証** | 環境保全と労働条件の基準を満たした農園を認証                                                                                                                                              | 環境・労働が目的                                                 |
| **各社の独自調達基準**                 | 大手ロースター・チェーンが自前で基準を設け、農園を直接支援                                                                                                                                | サプライ確保が本音の目的でもある                                 |
| **EUDR（EU森林破壊防止規則）**         | 2020年末以降に森林破壊を伴っていないことの証明を輸入業者に義務づける。コーヒーも対象。適用は延期が重なり、**EUの大企業は2026年12月30日、小規模事業者は2027年6月30日まで猶予**と報じられる | **トレーサビリティ（産地の追跡可能性）のコスト**が業界全体に乗る |

```
【認証が「値段」として現れる仕組み】

  認証を取る ─▶ 産地の記録・監査・区分管理が必要
       ├─▶ 生産者にプレミアム
       └─▶ ロースター・商社にトレーサビリティ実務コスト
                  ▼
  「認証つきの豆は高い」＝ 小売価格に上乗せ
                  ▼
  カフェは「高くても選ぶ理由」を客に説明する必要が出る
  → スペシャルティ店やサードプレイス型が有利（→ ②）
```

**日本は世界4位のコーヒー消費国**（全日本コーヒー協会）。

- 市場の成長を量に求められない以上、**単価を上げるしかない**。
  これが値上げが続く構造的な理由でもある

## 8. 紅茶・抹茶・スムージーへの広がり

コーヒーの相場が荒れ、消費も伸びないなかで、
カフェのメニューは**コーヒー以外**へ広がっている。

| カテゴリ                         | 位置づけ                                          | 経済的な意味                                                    |
| -------------------------------- | ------------------------------------------------- | --------------------------------------------------------------- |
| **紅茶**                         | 相場が比較的安定。ティーカフェ業態への転換も      | コーヒー相場から切り離せる                                      |
| **抹茶**                         | インバウンドとSNSで需要急増。**原料は逆に高騰中** | 客単価は取れるが原料確保が難しい                                |
| **スムージー・フラペチーノ系**   | 氷・果実・乳製品ベース                            | 原価が安く**単価を1.5〜2倍**にできる（→ [②](02_業態の違い.md)） |
| **ノンカフェイン・ハーブティー** | 夕方以降の需要を作る                              | アイドルタイム対策                                              |

抹茶については、状況が逆転している点に注意が必要。

- 海外の抹茶ブームで需要が急増し、**世界的な品薄**になったと報じられる
- 2026年上期の粉末状緑茶は、**輸出量が前年同期比+19.6%に対し、輸出額は+99.1%**。
  つまり**単価がおおむね倍**になった（貿易統計ベースの報道）
- 2026年の鹿児島県茶市場では、てん茶（抹茶の原料）の一番茶平均価格が
  前年6,013円/kgから**13,910円/kg**へ上昇したと報じられる
- 帝国データバンクは2026年6月の調査で、喫茶店の生き残り策として
  **「紅茶や緑茶、訪日客を中心に根強い人気がある抹茶などティーカフェ業態」**への
  シフトを挙げている

> ポイント：**コーヒーから逃げた先の抹茶も、いま高い**。
> 「原料を変えれば解決する」わけではなく、
> 結局は[① カフェの経済](01_カフェの経済.md) の
> 席時間単価をどう上げるかという問題に戻ってくる。

## 用語メモ

| 用語                         | 意味                                                                                         |
| ---------------------------- | -------------------------------------------------------------------------------------------- |
| **生豆（なままめ／きまめ）** | 焙煎前のコーヒー豆。国際商品として取引されるのはこの状態                                     |
| **焙煎（ロースト）**         | 生豆を加熱して香味を出す工程。重量が約2割減る                                                |
| **ロースター**               | 焙煎業者。カフェの仕入原価はここの卸値で決まる                                               |
| **アラビカ種**               | 世界生産の約6割。標高の高い土地で育ち、病害・霜に弱い。ニューヨーク市場で取引                |
| **ロブスタ種（カネフォラ）** | 低地でも育ち収量が多い。苦味が強く、インスタント・缶コーヒー向け。ロンドン市場で取引         |
| **I-CIP（ICO複合指標価格）** | 国際コーヒー機関が公表する総合指標価格。単位はセント/ポンド                                  |
| **認証在庫**                 | 取引所が受渡しに使えると認定した在庫。薄くなると価格が跳ねやすい                             |
| **ディファレンシャル**       | 先物価格に対する現物の上乗せ（または割引）幅。実際の仕入値は先物＋ディファレンシャル         |
| **フェアトレード**           | 生産者に最低価格とプレミアムを保証する仕組み。第三者認証がある                               |
| **EUDR**                     | EU森林破壊防止規則。2020年末以降の森林破壊に由来しないことの証明を義務づける。コーヒーも対象 |
| **コーヒーの2050年問題**     | 気候変動でアラビカ種の栽培適地が2050年までに大幅に減るとされる問題                           |
| **てん茶**                   | 抹茶の原料となる茶葉。碾茶。2026年に価格が急騰したと報じられる                               |
