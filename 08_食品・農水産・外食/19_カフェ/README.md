# カフェ

- 大分類: 食品・農水産・外食
- 状態: done
- 更新日: 2026-09-20

## このフォルダの読み方

カフェは **「コーヒーを売る店」ではなく「席の時間を売る店」**である。
コーヒー1杯の原価率は10〜20%と外食で最も低い。
それなのに経営が楽にならないのは、**客が1杯の代金で席を30分から2時間占有する**からだ。
つまりカフェの在庫は飲み物ではなく **「席 × 時間」** であり、
その在庫は1日に数回しか売れない。

だからカフェを読む中心指標は原価率ではなく
**席時間単価（客単価 ÷ 滞在時間）**になる。
値上げも、フードの追加も、モーニングサービスも、電源とWi-Fiも、
テイクアウトもモバイルオーダーも、
すべては**席時間単価か席在庫の使われ方を動かすための手段**にすぎない。

そしてもう一つ。「カフェ業界」という単一の業界は実質的に存在しない。
**スターバックス（居場所を売る）／ドトール（短時間高回転）／
コメダ珈琲店（喫茶店の看板を掲げた卸売業）／コンビニコーヒー（価格の下限を作った破壊者）**
は、客単価も滞在時間も、**誰からお金をもらうか**さえ違う。
同じ「コーヒー豆高騰」というニュースでも、各社に起きることは別々になる。

外食共通の指標（FL比率、回転率、坪売上、既存店前年比）は
[ファストフード ① 外食1店舗の経済](../14_ファストフード/01_外食1店舗の経済.md) で定義済み。
本フォルダはそれを前提に、**カフェ特有のゆがみ**だけを扱う。

## 1. 業界の定義・範囲

**カフェ・喫茶＝ コーヒー・紅茶などの飲料と軽食を、その場で飲食させる業態**。
総務省の産業分類では「喫茶店」（飲食店の小分類）にあたり、
日本フードサービス協会の業態分類でも「喫茶」として独立集計される。

隣接業態との線引きは、**滞在時間・客単価・アルコールの有無**で引く。

| 業態                                                         | 主力商品             | 客単価         | 滞在時間      | 境界の考え方                                                                            |
| ------------------------------------------------------------ | -------------------- | -------------- | ------------- | --------------------------------------------------------------------------------------- |
| **カフェ・喫茶**                                             | コーヒー・紅茶＋軽食 | 400〜1,000円   | **20〜120分** | 飲料が主。滞在が商品                                                                    |
| [ファストフード](../14_ファストフード/README.md)             | 食事                 | 500〜1,100円   | 10〜25分      | 食事が主。滞在を短くする設計                                                            |
| [ファミリーレストラン](../15_ファミリーレストラン/README.md) | 食事                 | 1,000〜1,500円 | 50〜70分      | テーブルサービスの食事                                                                  |
| [居酒屋](../16_居酒屋/README.md)                             | 酒                   | 3,000〜4,000円 | 120分前後     | アルコールが主                                                                          |
| コンビニのカウンターコーヒー                                 | コーヒー             | 140〜300円     | **0分**       | 席を持たない。[コンビニ](../../07_小売・流通/01_コンビニエンスストア/README.md)の一商品 |
| [清涼飲料](../09_清涼飲料/README.md)の缶・ペットコーヒー     | コーヒー             | 130〜200円     | 0分           | 製造業。自販機・小売で売る                                                              |

実務上は次の2つが境界線になりやすい。

- **フルサービスかセルフか**（配膳・下げ膳を店がやるか）。人件費率が10ポイント近く変わる
- **朝営業があるか**。カフェは外食で唯一、朝に山を作れる業態

| 喫茶店・カフェの市場規模     | 約1兆〜1.2兆円                 | 各種推計。2023年を1兆1,892億円とする調査会社推計あり |
| 喫茶店の民営事業所数         | **58,669事業所**               | 2021年、総務省「経済センサス-活動調査」              |

| 同・客単価／客数             | **108.6% / 101.1%**            | 同上                                                 |

```
【喫茶店の事業所数（総務省統計、個所）】

  1981年  154,630  ████████████████████████  ← ピーク
  1991年  126,260  ███████████████████

  ▲ 40年で約6割減。減ったのは主に個人経営の「喫茶店」。

```

> **成長性の読み方**：コーヒーの消費量は増えない（むしろ1人あたりは減少）。
> 一方で売上は伸びている。つまりこの市場の成長は
> **量ではなく単価（値上げと高付加価値化）で作られている**。
> だから「値上げが通らなくなった瞬間」が成長の終わりになる。
> その兆候は2026年に入って客数の前年割れとして現れ始めた
> （→ [④ 直近トピック](04_直近トピック_2026.md)）。

## 3. バリューチェーン（川上 → 川下）

```
 栽培・収穫       精製・輸出       輸入・商社      焙煎（ロースト）     店
 ──────────    ──────────    ──────────    ──────────────   ──────────
 コーヒー農家 ─▶ 現地輸出業者 ─▶ 商社・問屋 ─▶ ロースター ─────▶ カフェ
 ブラジル                        （保税倉庫）   UCC、キーコーヒー、    コンビニ
 ベトナム                                      各社自社焙煎、        スーパー
 コロンビア                                    個人焙煎所            EC

   生豆 約1,010円/kg（2025年の日本の輸入単価）
        │
        ├─ 焙煎で重量が約2割減る → 焙煎豆1kg＝生豆1.2kg
        │
        └─ 焙煎豆1kg ≒ 80〜100杯 ≒ カフェの売上 24,000〜30,000円

   ▲ 付加価値は「焙煎より後」、とくに「店の席」に集まる
```

- 川上（農園〜輸出）の取り分は小さく、価格変動を最も強く受ける。
  フェアトレードなどの議論はここから出てくる
- **日本側の付加価値は焙煎と店舗**。生豆1kg約1,000円が、店では2万円超の売上になる
- ただし店の側は**家賃と人件費**という重い固定費を負うので、
  倍率ほどには儲からない（→ [① カフェの経済](01_カフェの経済.md)）

> **収益構造で見ると各社はまったく別の商売**をしている。

> ドトール・日レスHD（売上1,591億円・同6.4%）を並べても意味がない。
> 片方はFC本部の卸売業、もう片方は店舗運営業である

## 5. 収益モデル・コスト構造

```
【カフェ1店舗のお金の流れ（売上100とした比率の目安）】

   売上高 100
     ├─ F：原価 ………… 15〜30   ← ドリンクは10〜20%と極端に低い。フードが上げる
     ├─ L：人件費 …… 30〜38   ← 営業時間が長く客単価が低いので下がらない
     │                        ……………… FL = 50〜68
     ├─ R：家賃 ……… 10〜15   ← 駅前立地では15%を超えて苦しむ店が多い
     ├─ 水道光熱費 …… 5〜8
     ├─ 販促・その他 … 8〜12
     ▼
   店舗営業利益 ……… 5〜10
```

| 指標              | カフェの目安     | 外食一般との違い                                 |
| ----------------- | ---------------- | ------------------------------------------------ |
| **F（原価率）**   | **15〜30%**      | ドリンク比率が高いほど低い。**外食で最も低い**   |
| **L（人件費率）** | 30〜38%          | 長時間営業・低客単価のため**外食で最も高い部類** |
| FL比率            | 50〜68%          | Fが低い分をLが食う                               |
| **席時間単価**    | **400〜1,300円** | **カフェ固有の中心指標**（客単価 ÷ 滞在時間）    |
| 満席率            | 40〜60%          | 席が余る時間が長い                               |
| 客単価            | 400〜1,000円     | フード比率でほぼ決まる                           |

儲け方は3つしかない。

- **回転で稼ぐ**（ドトール型）：滞在を短くし、席時間単価を上げる
- **単価で稼ぐ**（スターバックス・コメダ型）：長い滞在を高単価とフードで埋める
- **席を使わずに稼ぐ**（テイクアウト・豆の物販・卸）：席在庫を消費しない売上を作る

FC本部（コメダHDなど）は**4つ目のモデル**で、
店舗のFL・家賃を負わずに**加盟店への卸売とロイヤリティ**で稼ぐ。
だから営業利益率が15%超と、店舗運営業とは一桁違う水準になる。

## 6. 競争要因（KSF）と参入障壁

| 要因                   | 中身                             | 効き方                                             |
| ---------------------- | -------------------------------- | -------------------------------------------------- |
| **立地**               | 坪家賃と席時間単価の釣り合い     | 出店契約の時点で損益がほぼ決まる。最大のKSF        |
| **滞在価値の設計**     | 席間、照明、音、電源、Wi-Fi      | 「行く理由」を作る。コンビニに奪われない唯一の領域 |
| **客単価を作るフード** | モーニング、軽食、スイーツ       | 席効率の低さを埋める唯一の手段                     |
| **ブランドと指名度**   | 「あの店に行く」という動機       | 価格競争から降りるための条件                       |
| **調達（豆）**         | ロースターとの関係、自家焙煎     | 相場変動への耐性。差別化の源泉にもなる             |
| **FCの仕組み**         | 加盟店を集めて資本を使わず増やす | 店数の拡大速度を決める                             |

**参入障壁は低い**。小規模なカフェは数百万〜1,500万円程度で開業でき、
特別な許認可も飲食店営業許可で足りる。
だからこそ**新規開業も多く、退出も多い**。

```
【参入は易しく、継続が難しい構造】

  開業しやすい  ──▶  店が増える  ──▶  過当競争
       ▲                                 │
       │                                 ▼
       │                        家賃・人件費・原料が上がる
       │                                 │
       └───── 退出（倒産・廃業） ◀────────┘

  ▲ 帝国データバンクの調査でも、喫茶店の倒産は
    2023年の年間72件をピークに3年連続で高水準が続く
```

## 7. 規制・法制度

- **飲食店営業許可**（食品衛生法）：保健所の許可。設備基準（手洗い、シンクの数など）
- **食品衛生責任者**の設置義務
- **改正健康増進法（2020年4月全面施行）**：原則屋内禁煙。
  喫煙専用室の設置には要件があり、**古い喫茶店の喫煙文化が大きく制約された**
- **深夜酒類提供飲食店営業の届出**：夜にアルコールを出す場合
- **景品表示法・食品表示法**：産地表示、「スペシャルティ」等の表示
- **最低賃金**：人件費率の高いカフェは引き上げの影響を強く受ける
- **EUDR（EU森林破壊防止規則）**：日本の輸入に直接は適用されないが、
  産地側のトレーサビリティ対応コストが世界の豆価格に乗る（→ [③](03_原料と市場.md)）

## 8. 最近のトピック

詳細は [④ 直近トピック（2026年9月時点）](04_直近トピック_2026.md)。要点は5つ。

- **生豆相場は高値圏で乱高下**。2025年2月に過去最高値。2026年2月には「6年ぶり需給緩和」と報じられた一方、2026年7月にI-CIPが前月比+15.4%と急騰し、9月は2カ月半ぶり安値
- **値上げが店頭に到達**。ドトールがブレンドS 280→300円（2026年7月23日、約1,200店）、スターバックスが2026年10月9日から4〜35円、セブンカフェは2025年7月にRが税込140円へ
- **喫茶業態は売上増だが中身は客単価主導**。2025年は売上109.8%＝客単価108.6%×客数101.1%。**2026年6月は客数97.7%と前年割れ**（日本フードサービス協会）
- **倒産は高水準ながら2年ぶり減少**。2026年1〜5月で24件。増益企業は35.7%まで回復し、**価格で戦う店から空間で戦う店への入れ替わり**が進む（帝国データバンク）
- **抹茶・ティーカフェへのシフト**。ただし抹茶自身が高騰。2026年上期の粉末状緑茶は輸出量+19.6%に対し輸出額+99.1%
