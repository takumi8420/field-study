# ④ 直近トピック（2026年9月時点）

報道・各社開示・公的統計ベースの整理。一次情報（各社IR、官公庁・業界団体の発表）で
必ず裏取りすること。数値は公表時点のものであり、以後の改定で変わりうる。

> この1年の構図：**「生豆は高いまま荒れ、値上げは店頭に到達し、客数が止まった」**。
> コーヒー生豆の国際相場は2025年2月に過去最高値を付けたあと下げに転じたが、
> 2026年7月に再び1か月で15.4%跳ね上がり、9月には2か月半ぶりの安値と、
> **高値圏での乱高下**が続いている。
> 日本の生豆輸入単価は2025年に1,010円/kgと2020年の約3.5倍になり、
> 2026年は店頭価格への転嫁が一巡した。
> 結果、喫茶業態の売上は前年を上回っているが、
> **2026年6月には客数が97.7%と前年割れ**した。
> 一方で倒産件数は2年ぶりに減少し、
> **「価格で戦う店」から「空間で戦う店」への入れ替わり**が進んでいる。

## 1. コーヒー生豆相場 — 「需給緩和」と「高値ボラティリティ」の綱引き

2026年のコーヒー相場は、**下がる材料と上がる材料が同時に存在する**特異な年になった。

| 時期          | 出来事                                                                                                                                                     | 方向          |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------- |
| 2025年2月     | ICOアラビカ系指標が **9.05ドル/kg** と過去最高を記録                                                                                                       | ▲高値のピーク |
| 2026年2月     | 日本経済新聞が **「6年ぶり需給緩和へ」**と報道。ブラジル2026/27年産が記録的豊作見通し（民間予想で7,590万袋、前年比+15.5%）、米国のブラジル向け高関税も撤廃 | ▼下げ材料     |
| 2026年6月     | ICO複合指標価格（I-CIP）は月平均248.90セント/lb、前月比▲2.8%                                                                                               | ▼             |
| **2026年7月** | **I-CIPが287.26セント/lbへ前月比+15.4%**。ブラジルの天候懸念、エルニーニョ見通し、米国の認証在庫▲30.0%（2024年1月以来の最低）                              | ▲急騰         |
| 2026年9月     | 日本経済新聞が **「アラビカ豆、2カ月半ぶり安値」**と報道。ブラジルの降雨で来期収穫増の思惑                                                                 | ▼             |

```
【2026年の相場を一言で言うと】

   過去最高値 ─┐
  （2025年2月）│
               ▼  ブラジル豊作見通し・関税撤廃 → 下げ
               ▼
             高値圏 ←──┐
               ▲        │ 在庫の薄さ・天候懸念・投機・証拠金引き上げ
               └────────┘ → 少しの材料で跳ねる

  ＝「水準は高いまま、振れ幅だけが大きい」
     仕入担当にとって最も扱いにくい相場
```

- ICOは2026年7月に **7月6日 +8.2%、7月9日 +9.3%** という日次の異常な上昇を記録したと報告。
  ICE（取引所）の証拠金引き上げが売買の偏りを生んだ可能性にも触れている
- 日本の生豆輸入量は2025年で**359,382トン**、単価**1,010円/kg**（財務省貿易統計）。
  ブラジル・ベトナム・コロンビアの上位3か国で**76.4%**を占める
- 需給が緩んでも**1杯の値段はすぐには下がらない**。
  ロースターは数か月先の豆を先買いしており、高値で仕入れた在庫を売り切る必要があるため
  （日本経済新聞も「1杯の値段は高止まり続く見通し」と報じている）

詳しい相場の仕組みは [③ 原料と市場](03_原料と市場.md) を参照。

## 2. 値上げが店頭に到達した（2026年2月〜10月）

2025年は原料・製品（レギュラーコーヒー、インスタント）の値上げが中心だった。
**2026年は「店で飲む1杯」の値段が動いた年**である。

| 実施時期            | 主体                           | 内容                                                                    |
| ------------------- | ------------------------------ | ----------------------------------------------------------------------- |
| 2026年2月18日       | スターバックス                 | 価格改定。報道では約7割の店舗が対象、5〜30円程度                        |
| 2026年3月1日        | UCC上島珈琲                    | 業務用・家庭用レギュラーコーヒーを改定（店頭10〜18%上昇見込み）         |
| 2026年3月1日        | キーコーヒー                   | 家庭用の一部を改定（店頭10〜30%上昇見込み）                             |
| 2026年6月26日       | コメダ珈琲店                   | 多くの店舗でメニュー価格改定（同社決算短信）                            |
| 2026年7月14日       | ファミリーマート               | ファミマカフェを平均110%へ改定                                          |
| **2026年7月23日**   | **ドトール／エクセルシオール** | **約1,200店で改定。ブレンドコーヒーS 280円→300円**                      |
| 2026年10月9日       | スターバックス                 | 定番ビバレッジ4〜35円、フード10〜30円。ブリュードコーヒーShortは420円へ |
| 2026年11月1日出荷分 | UCC上島珈琲                    | 家庭用飲料製品を改定（店頭5〜10%上昇見込み）                            |

```
【ブレンドコーヒー1杯（Sサイズ相当）の価格の変化】

  ドトール        280円 ───────────▶ 300円（2026年7月23日〜）
  スターバックス   400円前後 ────────▶ 420円（2026年10月9日〜、Short）
  セブンカフェ     税込120円 ────────▶ 税込140円（2025年7月7日〜、R）

  ▲「ドトール280円」「コンビニ100円台」という
    長く固定されていた価格の目印が、この2年で軒並み動いた
```

> 読み方：[① カフェの経済](01_カフェの経済.md) のとおり、
> 生豆が2倍になっても1杯の豆代は十数円しか増えない。
> それでも20〜30円単位で値上げするのは、
> **豆代に加えて人件費・家賃・包装資材・エネルギーが同時に上がっている**から。
> 「コーヒー豆高騰」は消費者に説明しやすい**代表的な理由**であって、
> 値上げ幅の全部を説明するものではない。

## 3. 喫茶店の倒産は高水準ながら2年ぶりに減少

帝国データバンクの調査（2026年6月5日公表）によると、
**2026年1〜5月の「喫茶店」の倒産は24件**（負債1,000万円以上、法的整理）。

| 期間       | 倒産件数（1〜5月） | 備考                                             |
| ---------- | ------------------ | ------------------------------------------------ |
| 2023年     | 33件               | 年間72件で過去最多                               |
| 2025年     | 25件               |                                                  |
| **2026年** | **24件**           | **2年ぶりの減少。ただし3年連続で20件超の高水準** |

- 倒産の要因として挙げられているのは、
  **コーヒー豆の高騰、人件費、テナント料、パン・牛乳・卵などサイドメニュー原料の上昇**、
  加えて**経営者の高齢化**と電気・ガス代
- 競合として、大手カフェチェーン、**低価格で高品質なドリップコーヒーを出すコンビニ**、
  **Wi-Fi環境の整った安価なファストフード店**が挙げられている
- 一方で**2025年度に増益だった企業は35.7%**。2023年度の29.1%からは大きく改善しており、
  「全体が沈んでいる」のではなく**二極化**が進んでいる
- 収益改善の方向として、**スペシャルティコーヒー・高級業態への転換**、
  **SNS映えを狙ったフードの拡充**、
  **紅茶・緑茶・抹茶のティーカフェ業態**が挙げられている。
  同社はこれを「**空間・体験価値の提供へのシフト**」と表現している

> 読み方：**価格で戦う店が退出し、空間で戦う店が残る**という入れ替わりが起きている。
> これは [② 業態の違い](02_業態の違い.md) で見た
> 「コンビニコーヒーが飲み物だけを抜き取った」ことの必然的な帰結である。

## 4. 喫茶業態は売上増、しかし客数が止まった

日本フードサービス協会（JF）の「外食産業市場動向調査」で
**「喫茶」業態**の数値を追うと、局面の変化がはっきり見える。

| 期間           | 売上       | 店舗数 | **客数**  | **客単価** |
| -------------- | ---------- | ------ | --------- | ---------- |
| 2025年（年間） | **109.8%** | 100.6% | 101.1%    | **108.6%** |
| 2026年3月      | 105.3%     | 100.7% | 101.5%    | 103.7%     |
| 2026年4月      | 104.2%     | 100.9% | 100.6%    | 103.6%     |
| 2026年5月      | 109.3%     | 101.1% | 103.5%    | 105.6%     |
| **2026年6月**  | **100.6%** | 101.4% | **97.7%** | 103.0%     |
| 2026年7月      | 104.4%     | 100.8% | 101.0%    | 103.4%     |

（出典：日本フードサービス協会、全店・前年同期比、税抜）

```
【喫茶業態の「売上の作られ方」が変わってきている】

  2025年     売上 +9.8%  ＝  客数 +1.1%  ×  客単価 +8.6%
                              └ ほぼ横ばい     └ ここが全部

  2026年6月  売上 +0.6%  ＝  客数 ▲2.3%  ×  客単価 +3.0%
                              └ 前年割れ       └ 支えきれない

  ▲ 値上げ幅が縮み、客数がマイナスに触れた。
    [外食1店舗の経済] の「B → C」への移行局面にあたる
```

- JFは2026年6月について「台風以外でも雨天日の多い天候が客足に影響したが、
  夏の期間限定メニューなどによる客単価上昇で売上は100.6%」と説明している。
  天候要因は大きいが、**客単価の伸びが+3%台まで縮んでいる**点が重要
- **店舗数は一貫して前年超え**（100.6〜101.4%）。
  チェーンは出店を続けており、1店あたりの客数が薄まっている面もある
- 既存店3数値（売上・客数・客単価）の読み方は
  [外食1店舗の経済](../14_ファストフード/01_外食1店舗の経済.md) 第7章を参照

## 5. 各社決算 — FC卸売型と直営型で明暗が分かれない年

2026年は、**どちらのモデルも増収増益**という珍しい年だった。

| 企業                       | 決算期      | 売上                   | 営業利益         | 営業利益率 |
| -------------------------- | ----------- | ---------------------- | ---------------- | ---------- |
| **コメダホールディングス** | 2026年2月期 | **572億円（+21.6%）**  | 94億円（+6.8%）  | **16.5%**  |
| **ドトール・日レスHD**     | 2026年2月期 | **1,591億円（+6.9%）** | 101億円（+5.8%） | 6.4%       |

（各社決算短信。コメダはIFRS、ドトール・日レスは日本基準）

- **コメダ**：売上+21.6%の大半は、2025年3月のシンガポール子会社（30店舗）連結化による。
  国内は**加盟店向け卸売の既存店売上高が前年比109.5%**、全店113.4%と堅調。
  国内コメダ珈琲店は**1,030店（うち直営22店）**で、**FC比率は約98%**
- ただし**営業利益率は前期18.7%→16.5%へ低下**。
  原材料高とエネルギーコストを加盟店に全額転嫁しきれていないことを示唆する
- **ドトール・日レス**：インバウンド好調を背景に増収増益。
  経常利益は106億円（+10.4%）、年間配当を1株57円（前期比+7円）に引き上げた
- **スターバックスコーヒージャパン**：2026年3月31日現在で**2,116店（ライセンス店201含む）、
  従業員5,382名**（同社会社概要）。日本のカフェチェーンで最大規模を維持

```
【同じ原料高でも、負う人が違う】

  直営中心（ドトール・スタバ）   原料高 → 自社のP/Lを直撃 → 値上げで対応
  FC卸売型（コメダ）             原料高 → 卸値に転嫁 → 加盟店のP/Lを直撃
                                        └ 本部は利益率の低下として少しだけ被る

  ▲ FC本部は「安全」ではなく「遅れて効く」。
    加盟店が疲弊すれば出店が止まり、次は本部の成長が止まる
```

## 6. 抹茶・ティーカフェへのシフトと、抹茶自身の高騰

コーヒー相場から逃げる先として注目されたのが紅茶・抹茶だが、
**抹茶はコーヒー以上に値上がりしている**。

| 指標                                     | 数値                         | 時点・出典                       |
| ---------------------------------------- | ---------------------------- | -------------------------------- |
| 粉末状緑茶の輸出量                       | 前年同期比 **+19.6%**        | 2026年上期、貿易統計ベースの報道 |
| 粉末状緑茶の輸出額                       | 前年同期比 **+99.1%**        | 同上                             |
| 鹿児島県茶市場のてん茶（一番茶）平均価格 | 6,013円/kg → **13,910円/kg** | 2025年→2026年、報道ベース        |

- 背景は**海外（特に米国）の抹茶ブーム**。SNS起点で需要が急増し、
  ジェトロも2025年10月に「米国のカフェ経営者は抹茶の確保が課題」と報じている
- 日本国内でもインバウンド需要が重なり、**仕入価格の上昇と原料確保の難しさ**が
  飲食店の課題になっていると報じられる
- それでも喫茶店がティーカフェ業態へ動くのは、
  **コーヒー相場という単一リスクへの集中を避ける**意味と、
  **抹茶ドリンク・抹茶スイーツが高客単価を取れる**意味の両方がある
  （→ [① カフェの経済](01_カフェの経済.md) の客単価の節）

## 7. 制度面 — EUDRの再延期

**EUDR（EU森林破壊防止規則）**＝ EUに輸入される対象産品について、
2020年12月31日以降の森林破壊に由来しないことの証明を義務づける規則。**コーヒーも対象**。

- 適用開始が繰り返し延期され、**EUの大企業は2026年12月30日、
  小規模事業者は2027年6月30日**まで猶予されたと報じられる
- 違反時の制裁はEU域内売上高の最大4%の制裁金と物品の没収とされる
- **日本の輸入には直接適用されない**が、
  EUは世界のコーヒー消費の約3分の1を占めるため、
  **産地側のトレーサビリティ対応コストが世界の豆価格に乗る**経路で影響する
- 日本のロースター・商社も、産地証明の要求が強まる流れ自体からは逃れられない

## 8. 全体の構図（まとめ）

```
【2026年のカフェ業界を1枚で】

  生豆：高値圏で乱高下（2025年2月ピーク → 2026年は上下に振れる）
    │      ＋ 円安 ＋ 包装資材 ＋ エネルギー ＋ 最低賃金
    ▼
  値上げが店頭に到達（ドトール280→300円、スタバ、コンビニ）
    │
    ├──▶ 売上は前年超え（喫茶業態 2025年 +9.8%）
    │        └ ただし中身の +8.6% は客単価
    │
    └──▶ 2026年6月、ついに客数が前年割れ（97.7%）
             │
             ▼
  店の入れ替わりが進む
    ・価格で戦う個人店 …… 倒産は高水準（ただし2年ぶり減）
    ・空間で戦う店 ……… スペシャルティ、ティーカフェ、郊外滞在型が残る
    ・FC卸売型 …………… 利益率は高いが、加盟店の疲弊が次のリスク
```

要点を3行でまとめると次のようになる。

- **原料高は「1杯の原価」より「値上げの空気」として効いた**。
  豆代の増加は十数円だが、値上げ幅は20〜30円。差は人件費・家賃・資材・エネルギー
- **値上げは通ったが、2026年に入って客数が止まった**。
  売上の伸びが客単価だけに依存する局面は長くは続かない
- **生き残りの軸は価格から空間へ移った**。
  コンビニが飲み物を持ち去った以上、カフェは席・時間・体験でしか差を作れない
  （→ [① カフェの経済](01_カフェの経済.md)、[② 業態の違い](02_業態の違い.md)）

## 用語メモ

| 用語                         | 意味                                                                                                                                    |
| ---------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| **I-CIP（ICO複合指標価格）** | 国際コーヒー機関が公表するコーヒーの総合指標価格。単位はセント/ポンド                                                                   |
| **認証在庫**                 | 取引所が受渡しに使えると認定した在庫。薄いほど価格が跳ねやすい                                                                          |
| **証拠金（マージン）**       | 先物取引に必要な担保。引き上げられると資金の乏しい参加者が退出し、値動きが荒くなる                                                      |
| **需給緩和**                 | 供給が需要に追いつき、価格が下がりやすくなる状態。2026年2月に「6年ぶり」と報じられた                                                    |
| **客単価主導の増収**         | 客数がほぼ横ばいのまま、値上げだけで売上が伸びている状態。持続しない（→ [外食1店舗の経済](../14_ファストフード/01_外食1店舗の経済.md)） |
| **加盟店向け卸売**           | FC本部が加盟店へ原材料を販売する売上。コメダHDでは売上の約7割（2026年2月期）                                                            |
| **てん茶**                   | 抹茶の原料となる茶葉。2026年に価格が急騰したと報じられる                                                                                |
| **EUDR**                     | EU森林破壊防止規則。コーヒーも対象。大企業の適用は2026年12月30日まで延期されたと報じられる                                              |
