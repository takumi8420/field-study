# ② 業態の違い — 「カフェ」という1つの業界は存在しない

このノートで分かること：スターバックス、ドトール、コメダ珈琲店、コンビニコーヒー、
個人経営のスペシャルティ店が、**同じコーヒーを売りながらまったく別の商売**である理由。
どこで儲け、何を捨てているのか。電源とWi-Fiがなぜコストなのか。

> 結論：カフェは「コーヒーを売る店」という括りでは理解できない。
> **スターバックス＝居場所（サードプレイス）を売る小売業**、
> **ドトール＝短時間・高回転の立ち寄り装置**、
> **コメダ珈琲店＝喫茶店の看板を掲げた卸売業（FC本部）**、
> **コンビニコーヒー＝「淹れたてを140円で」という価格の下限を作った破壊者**。
> 4つは客単価も滞在時間も、そもそも**誰からお金をもらうか**が違う。
> だから同じ「コーヒー豆高騰」というニュースでも、各社に起きることは別々になる。

指標の定義（客単価、滞在時間、席時間単価、FL比率）は
[① カフェの経済](01_カフェの経済.md) を前提にする。

## 1. まず4類型のマップを置く

| 類型                   | 代表                                     | 客単価       | 滞在      | 誰から金を取るか                 | 捨てたもの       |
| ---------------------- | ---------------------------------------- | ------------ | --------- | -------------------------------- | ---------------- |
| **サードプレイス型**   | スターバックス、タリーズ                 | 600〜800円   | 40〜60分  | 直営店の来店客                   | 低価格、回転率   |
| **セルフ高回転型**     | ドトール、ベローチェ、エクセルシオール   | 400〜600円   | 20〜30分  | 直営・FCの来店客                 | 居心地、滞在価値 |
| **郊外フルサービス型** | コメダ珈琲店、星乃珈琲店、さかい珈琲     | 800〜1,000円 | 60〜90分  | **加盟店（卸売とロイヤリティ）** | 都心立地、回転率 |
| **ついで買い型**       | セブンカフェ、ファミマカフェ、マチカフェ | 140〜300円   | **0分**   | コンビニ来店客の「ついで」       | 座る場所、体験   |
| **スペシャルティ型**   | 個人経営、ブルーボトル等                 | 700〜1,200円 | 60〜120分 | 少数の来店客                     | 規模、標準化     |

```
【カフェ業態の位置取り（横軸＝滞在時間、縦軸＝客単価）】

 客単価
  高 │                              ● スペシャルティ（個人）
     │        ● スタバ              ● コメダ・星乃
     │
     │  ● ドトール
     │
  低 │ ● コンビニコーヒー
     └──────────────────────────────────────▶ 滞在時間
        0分        30分       60分        120分

  ※ 右上（高単価・長滞在）と左下（低単価・短滞在）は両方成立する。
    危ないのは「左上」＝低単価なのに長滞在。個人経営が陥りやすい位置。
```

## 2. スターバックス — 「サードプレイス」は空間を売る戦略

スターバックスコーヒージャパンは **2,116店（うちライセンス店201店）、従業員5,382名**
（同社会社概要、2026年3月31日現在）。日本のカフェチェーンで最大。

**サードプレイス（third place）＝ 家（第1）でも職場（第2）でもない第3の居場所**。
1990年代に米国本社が打ち出した概念で、日本でも同社の中核コンセプトになっている。

この戦略が経済的に何を意味するか。

| 要素            | 具体策                           | コストへの影響                            | 売上への影響               |
| --------------- | -------------------------------- | ----------------------------------------- | -------------------------- |
| 居心地          | ソファ席、間接照明、広い席間     | **1席あたり面積が増える＝坪効率が落ちる** | 滞在・再来店が伸びる       |
| 無料Wi-Fi・電源 | 時間制限なしの提供が一般的       | 長滞在を招き、席時間単価が下がる          | 「行く理由」になる         |
| 人による接客    | 名前の呼びかけ、カスタマイズ対応 | 人件費が上がる                            | 単価と指名度が上がる       |
| 全席禁煙        | 2020年以前から実施               | 喫煙者を捨てる                            | 非喫煙層・女性・学生を取る |

> ポイント：サードプレイス戦略は **「席効率を犠牲にして客単価とブランドを取る」**という
> 明確なトレードオフの選択である。だから同社は
> **高単価商品で席効率の低さを埋める**必要が構造的にある。

### フラペチーノ的な高単価商品の意味

フラペチーノ（氷とミルクをブレンドした冷たい甘い飲料）は、
単なる人気商品ではなく**席効率の低さを埋めるための装置**として読むとよい。

```
【なぜ高単価ドリンクが必要か（席時間単価の計算）】

  ブリュードコーヒー Short 420円 × 滞在45分 → 席時間単価 560円
  フラペチーノ Grande 700円前後 × 滞在45分 → 席時間単価 933円
  同じ45分座られても売上は1.7倍。席という在庫を変えずに席時間単価を上げられる
```

- 季節限定フラペチーノが毎年繰り返されるのは、**話題性**だけでなく
  **原価の安い氷・シロップ・ミルクで単価を1.5〜2倍にできる**から
- カスタマイズ課金（ミルク変更、ショット追加）も同じ構造。
  **席も人手も増やさずに客単価だけを積む**
- 2026年10月9日から定番ビバレッジを4〜35円、フードを10〜30円値上げすると発表
  （同社リリース、2026年9月18日）。ブリュードコーヒー Shortは420円になる

## 3. ドトール — 席時間単価を最大化する装置

ドトールコーヒーショップは全国**約1,078店**（2026年時点の集計サイト調べ）。
駅前・駅ナカ・オフィス街に集中し、ブレンドコーヒー（S）は長く280円だった。

ドトールの設計はスターバックスの**ほぼ正反対**である。

| 項目       | ドトール型                   | スターバックス型               |
| ---------- | ---------------------------- | ------------------------------ |
| 席間       | 狭い。カウンター席が多い     | 広い。ソファ席あり             |
| 提供       | レジで受け取り、自分で運ぶ   | 同左だが、受け渡しに会話が入る |
| 滞在の想定 | **20〜30分**                 | 40〜60分                       |
| 単価       | 400〜600円                   | 600〜800円                     |
| 喫煙       | 分煙ブースを持つ店舗があった | 全席禁煙                       |
| 立地       | 駅前・駅ナカ・オフィス街     | 商業施設・路面・郊外も広く     |

> ポイント：**単価が低いのに席時間単価は最も高い**のがドトール型。
> 滞在が短いからである。駅前の高い家賃を払えるのは、この効率があるから。
> 「安いカフェ」ではなく「**効率が極端に高いカフェ**」と読むのが正しい。

運営するドトール・日レスホールディングスの2026年2月期は
**売上高1,591億円（前期比+6.9%）、営業利益101億円（同+5.8%）、
純利益72億円（同+5.1%）**（同社決算短信、2026年4月14日）。
同社はドトール事業のほか日本レストランシステム（星乃珈琲店など）を抱える複合体で、
**「セルフ高回転型」と「フルサービス滞在型」の両方を社内に持っている**のが特徴。

2026年7月1日には、2026年7月23日から約1,200店で価格改定すると発表し、
**ブレンドコーヒー（S）を280円→300円**、カフェ・ラテ（S）を380円→400円とした（報道ベース）。
280円という価格帯の象徴が崩れた点で、業界内では節目として受け止められた。

## 4. コメダ珈琲店 — 喫茶店の看板を掲げた「卸売業」

コメダ珈琲店を理解する鍵は、**運営会社の売上の中身**にある。

コメダホールディングスの2026年2月期（連結、IFRS）は次のとおり（同社決算短信、2026年4月8日）。

| 項目                   | 2026年2月期                 | 前期比    |
| ---------------------- | --------------------------- | --------- |
| 売上収益               | **572億円**                 | +21.6%    |
| 営業利益               | **94億円**                  | +6.8%     |
| **売上収益営業利益率** | **16.5%**                   | 前期18.7% |
| 当期利益（親会社帰属） | 65億円                      | +11.1%    |
| グループ総店舗数       | 1,150店                     | —         |
| 国内コメダ珈琲店       | **1,030店（うち直営22店）** | —         |

**営業利益率16.5%は外食としては異常に高い**。
[外食1店舗の経済](../14_ファストフード/01_外食1店舗の経済.md) で見たとおり、
店舗を自分で運営する外食企業の営業利益率は5〜10%が普通である。
なぜこうなるのか。売上の内訳を見ると分かる。

```
【コメダHD 2026年2月期の売上内訳（単位：億円）】

  卸売（加盟店への豆・パン・食材の販売） … 393  ← 売上の約69%
  直営店売上 ………………………………………… 110  ← 海外子会社の連結が大半
  店舗開発収入（出店支援） ………………………  13
  その他 …………………………………………………  39
  リースに係る収益（不動産の転貸） ……………  17
  ───────────────────────────────────
  合計 …………………………………………………… 572
```

- **国内1,030店のうち直営はわずか22店（約2%）**。残りはすべてFC（加盟店）
- つまりコメダHDの本業は「喫茶店経営」ではなく
  **「加盟店に原材料を卸し、出店を支援し、ロイヤリティを受け取る」B2Bビジネス**
- FC本部は**店舗のFLコストも家賃も負担しない**。だから利益率が高く、
  売上が景気で大きく振れない
- 2026年2月期の**加盟店向け卸売の既存店売上高は前年比109.5%、全店は113.4%**（同社開示）。
  加盟店が売れば本部の卸売が伸びる、という連動構造

| 比較軸             | コメダHD（FC卸売型） | ドトール・日レスHD（直営中心型） |
| ------------------ | -------------------- | -------------------------------- |
| 売上規模（直近期） | 572億円              | 1,591億円                        |
| 営業利益率         | **16.5%**            | 6.4%                             |
| 売上の中身         | 卸売が約7割          | 店舗売上が中心                   |
| 景気・天候の影響   | 間接的（加盟店経由） | **直接的**                       |
| 出店の資本負担     | 加盟店が負担         | 自社が負担                       |

> ポイント：**FC本部の利益率と店舗の利益率を混同してはいけない**。
> コメダHDの16.5%は「コメダの店が儲かっている」ではなく
> 「**本部の取り分が構造的に安定している**」という意味である。
> FCの一般論は [コンビニ ② フランチャイズという仕組み](../../07_小売・流通/01_コンビニエンスストア/02_フランチャイズという仕組み.md) を参照。

### 郊外・モーニング・滞在という3点セット

コメダ型の店舗設計は [① カフェの経済](01_カフェの経済.md) の計算と整合的である。

- **郊外ロードサイド** → 坪家賃が安いので、席時間単価が低くても成立する
- **モーニングサービス**（開店〜11時ごろ、ドリンク代でトーストとゆで卵が付く）
  → カフェ最大のアイドルタイムである朝に客を作り、固定費を回収する
- **長居を許容する内装**（ボックス席、新聞・雑誌）
  → 回転を捨てる代わりに、フードで客単価800〜1,000円を作って埋める

```
【コメダ型の1日】

   7時      9時      11時     13時     15時     17時     19時
   ██████████████  ▅▅▅▅  ███████  ▅▅▅▅▅▅▅▅▅▅▅▅  ▅▅▅▅▅▅  ▂▂▂
   └─ モーニング ─┘        └昼食┘  └─ 午後の長居 ─┘

   ・朝に山を作れるのがカフェの特権（他の外食業態には朝の需要がない）
   ・午後の「アイドルタイム」が、カフェでは逆に稼働している
   → 外食の弱点であるアイドルタイムを、カフェは構造的に埋められる
```

## 5. コンビニコーヒーという破壊者

2013年前後にセブン-イレブンが「セブンカフェ」を本格展開して以降、
**淹れたてコーヒーの価格の下限が100円台前半に固定された**。
これはカフェ業界にとって最大の外部ショックだった。

| チェーン         | 商品                    | 価格の推移                                                                    | 出典         |
| ---------------- | ----------------------- | ----------------------------------------------------------------------------- | ------------ |
| セブン-イレブン  | ホット／アイスコーヒーR | 税抜112円 → **130円**（税込140円）、2025年7月7日から                          | 同社リリース |
| セブン-イレブン  | ホットコーヒーL         | 税抜167円 → 204円、同上                                                       | 同社リリース |
| ファミリーマート | アイスコーヒーS ほか    | 2026年7月14日から平均110%の価格改定。アイスカフェラテMは250→290円と報じられる | 報道ベース   |
| ローソン         | マチカフェ              | 160円程度（2026年前半時点の比較記事）                                         | 報道ベース   |

なぜコンビニコーヒーがこれほど強いのか。**カフェと戦っていないから**である。

```
【コンビニコーヒーの経済（カフェと何が違うか）】

  カフェ                      ／  コンビニ
  家賃を「席」が消費する        ／  家賃はすでに物販が負担している
  接客・下げ膳の人件費が要る    ／  レジ横で客が自分で淹れる
  客はコーヒーのために来る      ／  客は弁当や雑誌のために来る（＝集客コスト0）
  1杯300〜450円で採算          ／  1杯140円でも「ついで買い」として成立

  → コンビニの追加コストは「豆＋カップ＋機械の償却」だけ。140円でも粗利が残る。
```

- コンビニにとってコーヒーは**それ自体の利益より、来店頻度を上げる集客商品**
  （[コンビニ ① 1店舗の経済学](../../07_小売・流通/01_コンビニエンスストア/01_1店舗の経済学.md)）
- 影響を最も受けたのは**個人経営の喫茶店と低価格セルフ型**。
  「安くてそこそこ美味い」の領域が丸ごと奪われた
- 生き残ったカフェは、価格ではなく**席・空間・体験**に軸足を移した。
  帝国データバンクも、収益改善の方向として
  「空間・体験価値の提供」へのシフトを挙げている（2026年6月調査）

> ポイント：コンビニコーヒーは「安いカフェ」ではなく
> **「カフェから飲み物だけを抜き取った商品」**である。
> だからカフェの側は、抜き取られなかったもの＝**席・時間・空間**で勝負するしかなくなった。
> [① カフェの経済](01_カフェの経済.md) で「売っているのは席の時間」と書いたのは、この文脈による。

## 6. 個人経営とスペシャルティコーヒー

**スペシャルティコーヒー ＝ 産地・農園・精製方法まで特定でき、
カップの品質評価（カッピング）が一定点数以上の高品質豆**を指す呼び方。
1990年代以降の米国発の潮流で、日本では2000年代後半から広がった。

| 世代    | 呼び名             | 中身                                             | 価格帯   |
| ------- | ------------------ | ------------------------------------------------ | -------- |
| 第1の波 | ファーストウェーブ | インスタント・大量流通。家庭に普及               | 安い     |
| 第2の波 | セカンドウェーブ   | シアトル系。エスプレッソとラテ、店舗チェーン化   | 中       |
| 第3の波 | **サードウェーブ** | 豆の産地と焙煎度を語る。浅煎り・シングルオリジン | **高い** |

個人経営のスペシャルティ店の経済は厳しい。理由は[①](01_カフェの経済.md)の計算どおり。

- 客単価700〜1,200円でも滞在60〜120分 → **席時間単価は400〜700円**にしかならない
- 高品質な豆の仕入は通常の1.5〜3倍。原価率は20〜30%に上がる
- 焙煎を自前でやる（ロースター併設）と設備投資と技術が要る一方、
  **豆の小売（100g単位の物販）という席を使わない売上**を持てる

```
【個人スペシャルティ店の生き筋】

  ① 豆の物販を伸ばす … 席在庫を使わない売上。EC・サブスクも同じ
  ② 卸に回る ……… 他店・ホテル・オフィスへ焙煎豆を卸す（B2B）
  ③ 家賃を極限まで下げる … 2階、路地裏、郊外、自宅併設
  ④ 客単価を上げる … フード、アルコール、夜営業への拡張
  ▲ ①②は「カフェをやめて焙煎業になる」方向。実際そう進む店が多い
```

帝国データバンクの2026年6月の調査でも、収益性向上の施策として
**スペシャルティコーヒーや高級コーヒー業態への転換**、
**SNS映えを狙ったフードメニューの拡充**、
**紅茶・緑茶・抹茶などティーカフェ業態**への展開が挙げられている。

## 7. コワーキング的利用 — 電源とWi-Fiは「無料のコスト」

無料Wi-Fiと電源は、カフェにとって**客寄せであると同時に席時間単価を壊す装置**でもある。

```
【電源席が席時間単価に与える影響（試算）】

  電源なし席   客単価 600円 ÷ 滞在 45分  = 席時間単価 800円
  電源あり席   客単価 700円 ÷ 滞在 120分 = 席時間単価 350円
                     ▲ 単価は+100円しか増えないのに、滞在は2.7倍
  → 電源席は「1席あたりの稼ぎが半分以下になる席」。
    それでも置くのは、①集客、②平日昼の空席を埋める、という別の理由がある
```

| 立場                     | 電源・Wi-Fiの扱い              | 理由                                     |
| ------------------------ | ------------------------------ | ---------------------------------------- |
| サードプレイス型         | 原則提供（時間制限なしが多い） | ブランドの約束そのもの。滞在は単価で回収 |
| セルフ高回転型           | 会員登録制など条件付きが多い   | 回転を落としたくない                     |
| 郊外フルサービス型       | 提供するが、そもそも長居前提   | 客単価が高いので許容できる               |
| **ワークスペース併設型** | **時間課金で売る**             | 滞在時間そのものを商品化した解           |

- リモートワーク定着後、**カフェの一部は事実上のコワーキングスペース**になった
- これに対する最も合理的な解が「**時間を課金対象にする**」こと。
  ドリンク1杯＋席の時間料金という形なら、長滞在が売上に変換される
- 逆に言えば、**時間を課金しないまま電源を開放した店は、
  自分の在庫（席時間）を無料で配っている**ことになる

## 8. まとめ — 同じニュースが各社に別々に効く

| 出来事                 | サードプレイス型                 | セルフ高回転型                     | FC卸売型                             | コンビニ                   |
| ---------------------- | -------------------------------- | ---------------------------------- | ------------------------------------ | -------------------------- |
| **生豆相場の高騰**     | 影響小（原価率が低く単価が高い） | 影響中（低単価なので吸収しにくい） | **卸値に転嫁できる**（加盟店が負担） | 影響中（値上げで対応）     |
| **最低賃金の上昇**     | 影響大（人による接客が売り）     | 影響大（長時間営業）               | **限定的**（本部は店を持たない）     | 影響小（既存人員で淹れる） |
| **家賃の上昇**         | 影響大（都心・商業施設）         | **影響大（駅前が主戦場）**         | 小（郊外・加盟店負担）               | —                          |
| **リモートワーク定着** | 長滞在が増え席効率が悪化         | 影響小（そもそも短時間）           | 影響小                               | 影響小                     |
| **インバウンド増加**   | **恩恵大**（観光地立地）         | 中                                 | 中                                   | 中                         |

> ポイント：「カフェ業界が苦しい」という言い方は雑すぎる。
> **店を持つ者（コスト直撃）と、店を持たず卸す者（相対的に安全）**で
> 同じ相場高騰の意味が正反対になる。
> どの類型の話をしているのかを常に確認すること。

## 用語メモ

| 用語                       | 意味                                                                               |
| -------------------------- | ---------------------------------------------------------------------------------- |
| **サードプレイス**         | 家（第1）でも職場（第2）でもない第3の居場所。スターバックスの中核コンセプト        |
| **スペシャルティコーヒー** | 産地・農園まで特定でき、カッピング（味覚評価）が一定点数以上の高品質豆             |
| **シングルオリジン**       | 単一の産地・農園の豆だけを使ったコーヒー。ブレンドの対義語                         |
| **サードウェーブ**         | 豆の産地と焙煎度を語る2000年代以降の潮流。浅煎り・シングルオリジンが象徴           |
| **セルフサービス型**       | 注文・受け取り・下げ膳を客が行う方式。人件費を下げる代わりに滞在価値を下げる       |
| **フルサービス型**         | 席まで配膳し、下げ膳も店が行う方式。人件費は上がるが客単価と滞在が取れる           |
| **卸売（FC本部の）**       | 本部が加盟店に原材料を販売すること。コメダHDでは売上の約7割を占める（2026年2月期） |
| **店舗開発収入**           | FC本部が加盟店の出店支援（物件・設計・施工の仲介）で得る収入                       |
| **モーニングサービス**     | 朝の時間帯にドリンク代で軽食が付く仕組み。名古屋圏発祥とされ、郊外型の集客装置     |
| **カッピング**             | コーヒーの品質を専門家が採点する評価手法。スペシャルティの定義に使われる           |
