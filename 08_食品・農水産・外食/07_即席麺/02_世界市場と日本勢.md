# ② 世界市場と日本勢

このノートで分かること：**即席麺は日本で発明され、日本が世界の20分の1しか食べていない商品**である。
年1,242億食という巨大な需要はアジアにあり、そこで日本企業がどう戦い、
いま韓国勢にどこを取られつつあるのかを整理する。

---

## 1. 結論：市場は海外にしかない

2025年の即席麺の世界総需要は **1,242億1,000万食**（前年比 +0.7%）で、過去最高を更新した
（世界ラーメン協会＝WINA、2026年8月発表）。

一方、日本国内の需要は 59億5,000万食。**世界の約4.8%**にすぎない。
しかも国内は人口減少で構造的に伸びない（→ [総合食品④](../01_総合食品/04_国内成熟と海外展開.md) 第1章）。

> **ポイント：即席麺メーカーにとって「海外」は選択肢ではなく、成長の唯一の場所である。**
> そしてそれが可能なのは、即席麺が**保存が効き、軽く、調理設備がほとんど要らない**という、
> 加工食品の中でも例外的に輸出・現地生産に向いた商品特性を持つからである。

```
【他の食品と比べた「海外に出しやすさ」】

                 日持ち  輸送耐性  現地嗜好への改変  必要な調理設備
  即席麺           ◎       ◎           ◎（味を総取替え可）    お湯だけ
  しょうゆ         ◎       △（重い）    ○                     不要
  スナック菓子     ○       △（かさばる）○                     不要
  牛乳・パン       ✕       ✕           ―                     ―
  冷凍食品         ◎       ✕（冷凍鎖）  ○                     冷凍庫＋レンジ

  → 即席麺は「輸出で試し、売れたら現地生産に切り替える」という
     段階的な海外展開がやりやすい数少ない食品カテゴリ。
```

## 2. どこで食べられているか ― 国別需要

| 順位 | 国・地域         | 2025年        | 2024年 | 2021年 | 傾向                                         |
| ---- | ---------------- | ------------- | ------ | ------ | -------------------------------------------- |
| 1    | **中国／香港**   | **432.7億食** | 438.0  | 439.9  | 世界の約35%。微減が続く                      |
| 2    | **インドネシア** | **145.4億食** | 146.8  | 132.7  | 人口2.8億人。1人あたり消費が非常に高い       |
| 3    | **インド**       | **96.0億食**  | 88.2   | 75.6   | **4年で約27%増。最大の成長市場**             |
| 4    | ベトナム         | 82.3億食      | 81.4   | 85.6   | 1人あたり消費で世界トップ級                  |
| 5    | **日本**         | **59.5億食**  | 59.0   | 58.5   | 横ばい。成熟市場                             |
| 6    | 米国             | 52.3億食      | 51.5   | 49.8   | 微増。**韓国勢の主戦場になった**             |
| 7    | フィリピン       | 43.4億食      | 44.9   | 44.4   | ―                                            |
| 8    | タイ             | 41.9億食      | 40.8   | 36.3   | 着実に成長                                   |
| 9    | 韓国             | 40.6億食      | 41.0   | 37.9   | 人口5,100万人での40億食＝1人あたり世界最多級 |
| 10   | ナイジェリア     | 31.1億食      | 30.0   | 26.2   | アフリカの成長市場                           |

（世界ラーメン協会〈WINA〉「世界総需要データ」。単位は億食）

2025年の特徴として、WINAは**欧州を除く全エリアで成長**し、アジアが牽引、
中南米・中東アフリカも高い成長率を示したと整理している。
同時に、米国の通商政策や中東情勢によって原材料・製品コストへの影響が意識された年でもあったとしている。

```
【世界需要1,242億食の内訳（2025年、概算の構成比）】

  中国/香港     ████████████████████████████████████  約35%
  インドネシア  ████████████                          約12%
  インド        ████████                              約 8%
  ベトナム      ███████                               約 7%
  日本          █████                                 約 5%  ◀ここ
  米国          ████                                  約 4%
  その他        ██████████████████████████            約29%

  → 日本市場は「発祥の地」だが、量的には世界の20分の1。
     ここだけ見ていると業界の姿を見誤る。
```

需要の読み方で外してはいけない点が2つある。

- **人口の多い国が上位に来るのは当然**。見るべきは**1人あたり消費**である。
  ベトナム・韓国・インドネシアは1人あたり年70〜100食前後とされ、即席麺が主食に近い扱いを受けている。
  日本は年約48食（59.5億食 ÷ 約1.23億人で筆者が計算）で、実は「そこそこ」にすぎない。
- **単価は国によって桁が違う**。インドやナイジェリアの1食は日本円で数十円以下。
  **食数が伸びても売上・利益がそのまま伸びるわけではない**。

## 3. 日本発の商品が世界標準になった経緯

即席麺は「日本の食文化が広まった」例ではない。
**日本で発明された技術と商品フォーマットが、各国の食文化の中に別々に根付いた**例である。

```
【世界標準になるまでの流れ】

 1958  チキンラーメン発売（日清食品）
        └ 瞬間油熱乾燥法＝揚げて水分を飛ばす製法を確立
           ★この製法が業界の共通技術になった

 1960年代  日本国内で袋麺が普及。各社が参入
        └ 同時に台湾・韓国・東南アジアへ技術が伝播

 1971  カップヌードル発売（日清食品）
        └ 「容器＋フォーク＋お湯だけ」という完成形
           ★丼も箸も要らない ＝ 食文化を問わない

 1970年代〜 米国進出
        └ 1972年 米国で販売開始、1973年 現地生産へ
           米国名は "Cup Noodles"。スープではなく
           「片手で食べるスナック／軽食」として定着

 1980年代〜 中国・東南アジアで現地生産が本格化
        └ 現地企業も続々参入。技術は事実上オープンに

 2000年代〜 韓国勢が「辛い麺」で差別化し世界へ
        └ 農心「辛ラーメン」、三養「ブルダック炒め麺」

 → 日本企業は「製法と商品形態を発明した」が、
    「その市場を独占した」わけではない。
```

カップ麺が世界に広がった決定的な理由は、**食器を要求しないこと**にある。
箸の文化にもフォークの文化にも、丼のない家庭にも入っていける。
即席麺が「日本料理」ではなく「各国のローカルフード」として定着したのはこのためである。

## 4. 日清食品の海外 ― 利益の約半分を稼ぐが、いま逆風

日清食品ホールディングスは、日本の食品メーカーの中で**海外比率の高さで上位**に入る会社である。

| 指標                      | 数値                                                   |
| ------------------------- | ------------------------------------------------------ |
| 2026年3月期 売上収益      | **7,920億円**（前年比 +2%）                            |
| 同 既存事業コア営業利益   | **685億円**（▲18%）                                    |
| 同 連結純利益             | **430億円**（▲22%）                                    |
| 同 海外事業のコア営業利益 | **351億円**（前期比 ▲15%、期初予想から76億円下方修正） |

（日清食品HDの業績予想および日本経済新聞の報道ベース。2026年3月期より本部費用の配賦基準と海外ロイヤリティ料率を変更）

主な進出先と戦い方は次のとおり。

| 地域         | 戦い方                                                                                                                                     | 現状                                                                                            |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------- |
| **米国**     | 1970年代から現地生産。"Cup Noodles" として軽食ポジションを確立。近年は高価格帯の "Cup Noodles Stir Fry" や日本品質の商品で単価を上げる戦略 | **インフレによる消費減速と韓国製品の台頭で、一部地域の販売が低迷**。2026年3月期の下方修正の主因 |
| **中国**     | 香港を拠点に「合味道」ブランドで展開。都市部の若年層向け                                                                                   | 中国全体の需要が微減傾向にある中での競争                                                        |
| **ブラジル** | 1970年代から進出。**「Nissin Lámen」が国民的ブランド**に。現地の味（ガーリック、ストロガノフ風など）に全面適応                             | 南米は成長エリア。日清の海外の中でも成功例として挙げられる                                      |
| **欧州**     | 「Soba」ブランドの焼そば系が定着                                                                                                           | 欧州は2025年に唯一マイナス成長のエリア                                                          |

> **ポイント：日清の海外での強さは「日本の味を持っていった」ことではなく、
> 「現地で売れる味に全部作り替えた」ことにある。**
> ブラジルの日清の麺は日本人の想像するラーメンではない。
> これは [総合食品④](../01_総合食品/04_国内成熟と海外展開.md) 第7章のキッコーマンと同じ構造である。

## 5. 東洋水産 ― 北米・メキシコで稼ぐ

国内2番手の東洋水産は、いま**利益の稼ぎ方が日清と対照的**になっている。

| 指標（2026年3月期） | 数値                              |
| ------------------- | --------------------------------- |
| 売上高              | **5,366億円**（前年比 +4.8%）     |
| 営業利益            | **858億円**（+12.1%）**過去最高** |
| 経常利益            | 941億円（+10.4%）                 |
| 当期純利益          | 702億円（+9.9%）                  |

（東洋水産 決算短信・決算説明会資料、2026年5月）

牽引役は**海外即席麺事業**である。米国での価格改定効果と、メキシコでのカップ麺・袋麺の好調が効いた。

とくにメキシコは特徴的で、「Maruchan」は**ライム汁とチリソースをかけて食べる現地流の食べ方**とともに
定着している。スープを飲む文化に、即席麺が違和感なく入り込んだ形である。
米国でも "Maruchan Ramen Noodle Soup" は1食あたり数十セントの超低価格帯を押さえ、
**学生・単身世帯の常備食**という揺るがないポジションを持つ。

| 観点         | 日清食品HD                   | 東洋水産                             |
| ------------ | ---------------------------- | ------------------------------------ |
| 海外の主戦場 | 米国、中国、ブラジル、欧州   | **米国、メキシコ**                   |
| 価格帯の狙い | 高付加価値化（単価を上げる） | **低価格帯を押さえる（数量で稼ぐ）** |
| 2026年3月期  | 減益。米国苦戦が主因         | **増収増益・過去最高益**             |
| リスク       | 高単価戦略が消費減速に弱い   | 低価格帯は原材料高・関税に弱い       |

同じ即席麺の海外事業でも、**価格帯の置き方が違うだけで景色が逆になる**。
これが2026年の即席麺業界を見るうえで最も分かりやすい対比である。

## 6. 現地嗜好への適応 ― 何を変え、何を変えないか

海外展開の実務は、「どこまで作り替えるか」の判断の連続になる。

```
【変えるもの / 変えないもの】

  ＜変えない＞                    ＜全部変える＞
  ─────────────              ─────────────
  ・麺の製法（揚げる／乾かす）     ・味（スープの方向性）
  ・3〜5分で戻るという体験         ・辛さのレベル
  ・容器のフォーマット             ・具材（宗教・食習慣に対応）
  ・品質管理の基準                 ・1食あたりの量
                                   ・価格帯とパッケージ枚数
                                   ・ブランド名すら変えることがある
```

| 適応の軸         | 具体例                                                                                                                         |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **味**           | ブラジルはガーリック・肉系、メキシコはライムとチリ、インドはマサラ（香辛料）、東南アジアは甘辛・酸味                           |
| **宗教**         | イスラム圏ではハラール認証が必須。豚由来原料・アルコールを排除した製造ラインが要る                                             |
| **価格**         | 低所得層向けには小容量・低価格の単品売り。味の素が調味料で使った手法と同じ発想                                                 |
| **調理環境**     | お湯が常に手に入るとは限らない国では、水で戻せる／そのまま砕いて食べる用途も設計に入る                                         |
| **主食との関係** | 米・パン・トルティーヤなど既存の主食がある国では、**主食を置き換えるのではなく「おかず」や「軽食」の枠を狙う**ほうが入りやすい |

失敗パターンも定型化している。
**日本の味のまま持っていく／日系スーパーだけで売る／現地の価格帯を無視する**の3つで、
これは食品全般の海外展開に共通する（→ [総合食品④](../01_総合食品/04_国内成熟と海外展開.md) 第8章）。

## 7. 韓国勢の台頭 ― いちばん大きな構造変化

2020年代に入って、世界の即席麺市場で最も勢いがあるのは**韓国のメーカー**である。

| 企業                     | 主力ブランド         | 現状                                                                                                                                                                                 |
| ------------------------ | -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **農心（ノンシム）**     | **辛ラーメン**       | 米国で販売を伸ばし、海外比率が3割に迫る（報道ベース）。**初の輸出専用工場**を建設する方針と報じられる                                                                                |
| **三養（サムヤン）食品** | **ブルダック炒め麺** | SNS（YouTube・TikTok）の「激辛チャレンジ」で世界の10〜20代に浸透。**2024年の米国法人売上高は3,829億ウォン（前年比+138%）**と報じられる。ハラール認証を早期に取得しイスラム圏にも展開 |
| オットゥギ など          | 진ラーメン ほか      | 国内中心だが輸出も拡大                                                                                                                                                               |

数字で見ると規模感が分かる。

- 2025年の韓国の「K-FOOD+」輸出額は **136億2,000万ドル**で過去最高。
  このうち**ラーメンが15億2,000万ドル（前年比+21.9%）**で、単一品目として初めて15億ドルを突破した。
  米国向けは **+18.2%**（韓国政府発表、報道ベース）。

> **ポイント：韓国勢の武器は「辛さ」と「SNS」である。**
> 日本勢が長年かけて作ったのは「安心して食べられる定番」という信頼だった。
> 韓国勢が作ったのは「試したくなる刺激」であり、それは**SNSで爆発的に拡散する**。
> 商品開発のスピードとマーケティングの回し方が、そもそも違う土俵にある。

ただし韓国勢にも逆風はある。米国向け比率が高いため、
**2025年4月に米国が課した10%の基本関税、8月から適用された15%の相互関税**の影響で
業績が鈍化しているとも報じられる。農心が輸出専用工場を作る背景にはこの事情もある。

日本勢から見た論点は次の3つ。

1. **米国の棚を奪われている**。日清食品の2026年3月期下方修正の理由に
   「韓国製品の台頭による競争激化」が明示されている。
2. **辛さの軸を持っていなかった**。日本の即席麺は和風・豚骨・しょうゆが中心で、
   「激辛」という世界共通で分かりやすい軸で先行を許した。
3. **現地生産という強みは依然ある**。日清も東洋水産も主要市場に工場を持つため、
   関税局面ではむしろ有利に働く。

## 8. 非常食・備蓄という第二の需要

即席麺には、平時の食事とは別に **「備蓄される」需要**がある。
賞味期限が長く（カップ麺で約6か月、長期保存タイプはさらに長い）、常温で保管でき、
調理にお湯しか要らないためである。

| 需要の形                             | 内容                                                                                                                                                                               |
| ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **家庭の備蓄（ローリングストック）** | 日常的に食べながら買い足して、常に一定量の備蓄を保つ方法。日清食品は「カップヌードル ローリングストック」として、**3か月ごとに賞味期限内の商品を届ける定期サービス**を提供している |
| **自治体・企業の防災備蓄**           | 避難所用の備蓄。入札で大口の需要が動く                                                                                                                                             |
| **災害時の支援物資**                 | 発災後にメーカーが供給する。物流網が試される場面でもある                                                                                                                           |
| **高齢者・単身世帯の常備食**         | 買い物に行けない日の備え。国内で数量を支える地味だが重要な層                                                                                                                       |

関連して、日清食品の栄養バランス訴求ブランド「**完全メシ**」は
**2025年度に売上高100億円規模**に達する見込みと報じられ、シリーズ累計6,500万食を突破している。
即席麺の「安いが栄養が偏る」という弱点を正面から潰しにいく商品で、
**備蓄用途とも相性がよい**（栄養が確保できる非常食という位置づけ）。

---

## 9. まとめ ― この章を理解する3つの鍵

1. **市場は海外にしかない**。世界1,242億食に対し日本は59.5億食（約5%）。
   即席麺が保存・輸送・味の作り替えに強い商品だから、海外展開が現実的な選択肢になる。
2. **同じ海外でも価格帯の置き方で結果が逆になる**。2026年3月期、
   高付加価値を狙う日清食品HDは米国苦戦で減益、低価格帯を押さえる東洋水産は過去最高益。
3. **韓国勢の台頭が最大の構造変化**。辛さとSNSという日本勢が持たなかった軸で米国の棚を取った。
   ただし関税リスクを抱えており、現地生産を持つ日本勢には巻き返しの余地が残る。

## 用語メモ

| 用語                         | 意味                                                                                                                                        |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| **WINA（世界ラーメン協会）** | World Instant Noodles Association。1997年設立。**世界の即席麺需要の公式統計を毎年公表する唯一の機関**。この業界の数値はほぼここが出典になる |
| **1人あたり消費食数**        | その国の年間需要 ÷ 人口。市場の「成熟度」を見る指標。ベトナム・韓国が世界トップ級、日本は年約48食                                           |
| **ローリングストック**       | 備蓄品を日常的に消費しながら買い足し、常に一定量の新しい備蓄を保つ方法。賞味期限切れの廃棄を防げる                                          |
| **ハラール認証**             | イスラム法で許された食品であることの第三者認証。豚由来原料・アルコールの排除と、製造ラインの分離が必要                                      |
| **相互関税**                 | 相手国の関税率に合わせて自国の関税を課す方式。2025年に米国が導入し、韓国からの輸出品にも適用された（報道ベース）                            |
| **K-FOOD+**                  | 韓国政府が使う輸出統計の区分で、農水産食品に関連産業（資機材など）を加えたもの                                                              |
| **コア営業利益**             | 日清食品HDが使う利益指標。一時的な損益を除いた実力ベースの営業利益                                                                          |
| **完全メシ**                 | 日清食品の、栄養バランスを設計した食品ブランド。即席麺の「栄養が偏る」という弱点に対応する商品群                                            |
