報道および各社IR・業界団体統計をもとにした整理。

## 1. 2026年の値上げ ― 日清は4月、東洋水産は7月。対応が分かれた

即席麺は2023年以来、約3年ぶりの本格的な価格改定局面に入った。

| 企業         | 発表          | 実施                   | 内容                                                                                                                                                                                                                    |
| ------------ | ------------- | ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **日清食品** | 2025年12月3日 | **2026年4月1日出荷分** | 即席袋麺・カップ麺・カップスープなど**約170品**を希望小売価格ベースで **5〜11%** 引き上げ。カップヌードル（レギュラー）236円→**248円**、ビッグ271円→**298円**。一部の袋麺とカップライスは**価格据え置きで内容量を減量** |
| **東洋水産** | 2026年3月     | **2026年7月1日納品分** | カップ麺・ワンタンを希望小売価格ベースで **4〜11%**、オープン価格品は出荷価格 **10%** 引き上げ。赤いきつねうどん（レギュラー）236円→**248円**、でか盛271円→**298円**。**袋麺などは価格据え置き**                        |

（各社ニュースリリース、食品新聞・日本経済新聞の報道ベース）

読みどころは3点ある。

```
【2026年の値上げで起きたこと】

  カップ麺レギュラー
   日清 カップヌードル   236円 ──▶ 248円（4月）
   東洋水産 赤いきつね   236円 ──▶ 248円（7月）
     └ 定番同士が同じ価格に着地 ＝ 事実上の横並び

  袋麺
   日清     一部品目を「据え置き＋減量」
   東洋水産 据え置き
     └ 袋麺は特売の武器。表の価格を上げるとチラシから外される
        → カップと袋で打ち手が分かれた（→ ①第1章・第8章）

  ★ただし、希望小売価格が上がっても店頭の実勢売価が上がるとは限らない。
     売価を決めるのは小売。値上げが利益に乗るかは3〜6か月見ないと分からない。
```

食品新聞（2026年3月27日）は、この局面で**メーカーの対応が分かれ、同型品でも価格差が生じた**こと、
焦点が「実勢売価の行方」に移ったことを指摘している。
値上げの実務そのものの流れは [総合食品②](../01_総合食品/02_値決めと交渉.md) 第4章に詳しい。

## 2. 国内需要は2025年度に1.3%減 ― ただし「歴代4位」で高止まり

日本即席食品工業協会によると、2025年度（2025年4月〜2026年3月）の即席麺総需要は次のとおり。

| 区分     | 食数            | 前年度比  | 小売金額（推計） | 前年度比 |
| -------- | --------------- | --------- | ---------------- | -------- |
| カップ麺 | 39億4,386万食   | **▲0.3%** | 6,249億円        | ▲0.7%    |
| 袋麺     | 19億6,119万食   | **▲3.3%** | 1,614億円        | ▲3.6%    |
| **合計** | **59億506万食** | **▲1.3%** | **7,864億円**    | ▲1.3%    |

（日本即席食品工業協会調べ。食品新聞 2026年5月11日報道）

参考までに、前年の2024年度は59億8,347万食（+4.1%）、金額は**7,967億円で過去最高**だった。
つまり2025年度は**過去最高の翌年に小幅に落ちたが、歴代4位の水準で高止まり**している。

最も重要なのは内訳である。

| 区分                            | 2025年度 前年度比 |
| ------------------------------- | ----------------- |
| **JAS品**（定番ブランドが多い） | **+3.9%**         |
| **非JAS品**                     | **▲15.8%**        |

> **ポイント：全体は微減でも、定番は伸びて非定番が大きく落ちた。**
> 物価高で消費者が「失敗したくない」という選別消費に向かい、
> **知っている味・信頼しているブランドに回帰した**結果とみられる。
> 実際、2025年度は日清食品「カップヌードル」ブランドが過去最高売上を達成し、
> 東洋水産「赤いきつね・緑のたぬき」も販売食数が前年を上回っている（食品新聞 2026年6月8日）。

これは即席麺に限らず、コスト高局面で強いのはロングセラーだという食品全般の法則の現れでもある
（→ [総合食品③](../01_総合食品/03_商品開発とブランド.md) 第3章）。

なお2026年に入ってからは、**コメの不足・高騰による代替需要**で麺類全体が主食として再評価され、
乾麺・冷凍麺を含む全カテゴリが伸びているとも報じられている（日本食糧新聞「全国麺類特集2026」）。

## 3. 世界需要は2025年に1,242億食で過去最高 ― インドが牽引

世界ラーメン協会（WINA）が2026年8月に発表した2025年の世界総需要は **1,242億1,000万食**（前年比 **+0.7%**）で、
過去最高を更新した。

| 順位 | 国・地域     | 2025年       | 2024年    | 動き               |
| ---- | ------------ | ------------ | --------- | ------------------ |
| 1    | 中国／香港   | 432.7億食    | 438.0億食 | **微減**           |
| 2    | インドネシア | 145.4億食    | 146.8億食 | 微減               |
| 3    | **インド**   | **96.0億食** | 88.2億食  | **+8.8% で大幅増** |
| 4    | ベトナム     | 82.3億食     | 81.4億食  | 増加               |
| 5    | 日本         | 59.5億食     | 59.0億食  | 微増               |
| 6    | 米国         | 52.3億食     | 51.5億食  | 微増               |

（WINA「世界総需要データ」。※ WINAの日本の数値は暦年ベースで、第2章の協会の年度ベース統計とは集計期間が異なる）

WINAは2025年について、**欧州を除く全エリアが成長**し、アジアが牽引、
中南米・中東アフリカも高い成長率を示したと整理している。
一方で、**米国の通商政策や中東情勢の緊張により、原材料・製品コストへの影響がより意識された年**だったとも述べている。

```
【世界需要の構図（2025年）】

  中国       ▼ 微減（数量の3分の1を占める巨大市場が成熟局面へ）
  インド     ▲ 急増（4年で75.6億食 → 96.0億食）
  東南アジア ▲ 底堅い（ベトナム・タイが増加）
  中南米     ▲ 高成長（ブラジル・メキシコ）
  中東アフリカ ▲ 高成長（ナイジェリアなど）
  欧州       ▼ 唯一のマイナス

  → 「中国の成熟をインド・中南米・アフリカが埋める」構図。
     成長は続くが、単価の低い市場での食数増なので
     金額・利益の伸びは食数ほどではない点に注意。
```

## 4. 決算で明暗 ― 日清食品HDは下方修正、東洋水産は過去最高益

2026年3月期は、国内2強の結果がはっきり分かれた年になった。

| 項目                | **日清食品ホールディングス**                                                                                                                                      | **東洋水産**                                                                           |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| 売上（2026年3月期） | 売上収益 **7,920億円**（+2%）                                                                                                                                     | 売上高 **5,366億円**（+4.8%）                                                          |
| 利益                | 既存事業コア営業利益 **685億円（▲18%）**、純利益 **430億円（▲22%）**                                                                                              | 営業利益 **858億円（+12.1%）**、純利益 **702億円（+9.9%）**                            |
| 評価                | **下方修正。国内外で即席麺が苦戦**                                                                                                                                | **全利益指標で過去最高を更新**                                                         |
| 主因                | **米国の一部地域で販売が低迷**。インフレによる消費減速と**韓国製品の台頭による競争激化**。海外コア営業利益は期初予想から76億円引き下げ、前期比▲15%の351億円見込み | **海外即席麺事業が好調**。米国での価格改定効果と、メキシコでのカップ麺・袋麺の販売好調 |
| 株主還元            | 自社株買い200億円                                                                                                                                                 | 自社株買い最大235億円                                                                  |

（各社決算短信・決算説明会資料および日本経済新聞・日本食糧新聞の報道ベース。日清食品HDは2026年3月期より本部費用の配賦基準と海外ロイヤリティ料率を変更）

> **ポイント：同じ米国市場で、日清は苦戦し東洋水産は稼いでいる。**
> 違いは**価格帯**である。日清は高付加価値化で単価を上げる戦略を取り、
> 東洋水産は超低価格帯（学生・単身世帯の常備食）を押さえている。
> インフレで消費者が節約に向かうと、**高単価戦略が先に効かなくなる**。

詳しくは [② 世界市場と日本勢](02_世界市場と日本勢.md) 第4〜5章。

## 5. 原材料 ― 小麦は+2.5%、パーム油は4か月連続上昇

値上げの根拠となっているコスト側の動きも押さえておく。

| 原料                         | 2026年の動き                                                                                                                                    | 出典                            |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------- |
| **輸入小麦（政府売渡価格）** | 令和8年（2026年）4月期に5銘柄加重平均で **62,520円/トン、+2.5%** に改定。**円安水準の長期化**が背景                                             | 農林水産省（2026年3月11日公表） |
| **パーム油**                 | 2026年5月の国内卸価格は1kg **333〜343円**（中心値で前月比+5円、+1.5%）。**4か月連続の上昇**。海外のバイオ燃料（バイオディーゼル）需要が押し上げ | 日本経済新聞（2026年5月）       |
| **包装資材・物流費・人件費** | 各社が価格改定理由として「自助努力だけでは吸収できない」と明記                                                                                  | 各社ニュースリリース            |

即席麺は**小麦とパーム油という2つの国際相場商品に同時に挟まれる**カテゴリである。
揚げ麺では麺重量の約2割が油になるため、パーム油の上昇は小麦より速く原価に効くことがある
（→ [① 即席麺の商売](01_即席麺の商売.md) 第4章）。

なお、パーム油は2025年前半には半年で27%下落した局面もあり（日本経済新聞、2025年5月）、
**上下の振れが大きい**。「いま上がっている」ことを構造的な高止まりと決めつけないほうがよい。

## 6. 韓国勢の攻勢とその逆風

2026年時点で即席麺業界の最大の構造変化は、**韓国メーカーの世界展開**である。

- 2025年の韓国「K-FOOD+」輸出額は **136億2,000万ドル**で過去最高。
  このうち**ラーメンが15億2,000万ドル（前年比 +21.9%）**と、単一品目で初めて15億ドルを突破した。
  最大の輸出先は米国で、米国向けラーメンは **+18.2%**（韓国政府発表の報道ベース）。
- 三養食品「ブルダック炒め麺」は、SNSでの拡散により世界の10〜20代に浸透。
  **2024年の米国法人売上高は3,829億ウォン（前年比+138%）**と報じられる。
  早期のハラール認証取得でイスラム圏にも展開している。
- 農心は**初の輸出専用工場**を建設する方針と報じられ、米国での販売増により海外比率が3割に迫る。

一方で逆風もある。米国向け比率が高い農心は、
**2025年4月に米国が課した10%の基本関税、8月から適用された15%の相互関税**の影響で
業績が鈍化していると報じられる。
輸出依存のモデルは関税に弱く、**現地工場を持つ日本勢のほうが関税局面では有利**という側面もある。

## 7. 2027年4月からの飲食料品の消費税1%という変数

2026年9月15日の閣議決定により、**2027年4月1日〜2029年3月31日の2年間、
飲食料品の消費税率を8%→1%**とする方針が示された（法改正が必要）。

即席麺にとっての意味は次のとおり。

| 論点                                    | 中身                                                                                         |
| --------------------------------------- | -------------------------------------------------------------------------------------------- |
| **店頭価格が下がる余地ができる**        | 248円のカップ麺の税込価格が下がる。**その余地に値上げをぶつけられる**かが交渉の焦点になる    |
| **袋麺の特売価格が一段と安く見える**    | 5食パックの心理的な価格帯（298円など）を割り込みやすくなり、**袋麺の価格競争が激化する**恐れ |
| **2029年4月の税率戻りで駆け込みと反動** | 賞味期限が長く備蓄しやすい商品なので、**駆け込み需要が出やすいカテゴリ**にあたる             |

制度の全体像と食品業界への影響は [総合食品⑤](../01_総合食品/05_直近トピック_2026.md) 第2章にまとめられている。

## 9. 全体の構図

```
【2026年9月時点の即席麺業界】

  ＜国内＞
   需要 59.0億食（▲1.3%）で高止まり。しかし定番＋3.9% / 非定番▲15.8%
        └ 選別消費 ＝ ロングセラーに集中
   価格 カップ麺レギュラーが248円に横並び（日清4月・東洋水産7月）
        └ 袋麺は据え置きが基本 ＝ 特売の武器を守る
   コスト 小麦+2.5%（2026年4月期）、パーム油4か月連続上昇
        └ 値上げの根拠は揃っているが、実勢売価に乗るかは別問題

  ＜海外＞
   世界需要 1,242億食（+0.7%）で過去最高。インドが牽引、中国は微減
   日清食品HD ── 米国苦戦・減益（高単価戦略 × 消費減速 × 韓国勢）
   東洋水産  ── 北米・メキシコ好調で過去最高益（低価格帯を確保）
   韓国勢    ── ラーメン輸出15.2億ドル(+21.9%)。ただし米関税が逆風

  ＜2027年の変数＞
   飲食料品の消費税 8% → 1%（2027年4月〜2029年3月）
```

3〜5行でまとめると次のようになる。

1. **国内は「数量は横ばい、中身は定番一極集中」**。物価高が続くほど、ロングセラーを持つ会社が有利になる。
2. **値上げは通ったが、利益に乗るかは実勢売価次第**。袋麺は特売の武器なので値上げしにくく、
   カップと袋で打ち手が分かれる構造がはっきり出た。
3. **勝敗を決めているのは海外の価格帯の置き方**。同じ米国で、高単価を狙う日清が苦戦し、
   低価格帯を押さえる東洋水産が最高益を出した。
4. **韓国勢の台頭は続くが、関税という弱点がある**。現地工場を持つ日本勢には巻き返しの余地がある。
5. **2027年4月の消費税1%が次の大きな変数**。店頭価格が下がる余地を値上げに使えるかどうかが焦点。

## 用語メモ

| 用語                   | 意味                                                                                                                          |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| **希望小売価格**       | メーカーが「この値段で売ってほしい」と示す価格。拘束力はなく、実際の店頭価格（実勢売価）は小売が決める                        |
| **実勢売価**           | 店頭で実際に付いている価格。特売で大きく下がる。値上げが利益に乗るかはここを見る必要がある                                    |
| **オープン価格**       | メーカーが希望小売価格を設定しない方式。値上げは「出荷価格の改定」として発表される                                            |
| **JAS品／非JAS品**     | 日本農林規格の格付を受けた即席麺かどうかの区分。定番ブランドはJAS品に多く、2025年度の明暗を分けた                             |
| **選別消費**           | 物価高のもとで、消費者が支出先を絞り込み、失敗しにくい商品に集中する行動                                                      |
| **コア営業利益**       | 日清食品HDが使う、一時的な損益を除いた実力ベースの営業利益指標                                                                |
| **相互関税**           | 相手国の関税率に合わせて自国の関税を課す方式。2025年に米国が導入したと報じられる                                              |
| **政府売渡価格**       | 国が輸入小麦を製粉会社に売り渡す価格。年2回（4月期・10月期）改定される → [製粉・製糖・製油](../02_製粉・製糖・製油/README.md) |
| **ローリングストック** | 備蓄品を日常的に消費しながら買い足し、常に一定量の新しい備蓄を保つ方法                                                        |
