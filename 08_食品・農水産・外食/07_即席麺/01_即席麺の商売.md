# ① 即席麺の商売

このノートで分かること：**即席麺は「袋麺」と「カップ麺」という、名前が似ているだけの全く違う2つの商売**でできている。
その違いがどこから生まれ、誰が勝ち、どこでコストが決まるのかを、工場・原料・物流・値決めの順に分解する。

---

## 1. 結論：袋麺とカップ麺は「別の業界」だと思ったほうがいい

即席麺は、麺を揚げる（または乾かす）ことで長期保存できるようにし、
お湯で戻して食べる加工食品である。日本で発明され、いまや世界で年1,242億食が消費されている。

ただし国内の商売を見るときは、次の一点を最初に押さえる必要がある。

> **ポイント：カップ麺は袋麺より1食あたり約1.9倍の値段で売れる。**
> そして粗利率もカップのほうが高い。同じ「即席麺」でも、儲けの出方が全く違う。

2025年度（2025年4月〜2026年3月）の国内実績を割り算すると、これがはっきり見える。

| 区分         | 需要（食数）                   | 構成比 | 小売金額（推計）       | **1食あたり単価** |
| ------------ | ------------------------------ | ------ | ---------------------- | ----------------- |
| **カップ麺** | 39億4,386万食（前年度比▲0.3%） | 67%    | 6,249億円（▲0.7%）     | **約158円**       |
| **袋麺**     | 19億6,119万食（▲3.3%）         | 33%    | 1,614億円（▲3.6%）     | **約82円**        |
| 合計         | **59億506万食**（▲1.3%）       | 100%   | **7,864億円**（▲1.3%） | 約133円           |

（日本即席食品工業協会調べ。金額は同協会の小売金額推計値。1食あたり単価は金額÷食数で筆者が計算したもの）

なぜ単価が2倍近く違うのか。理由は3つある。

1. **容器が付いている**。紙カップ・フタ・外装フィルムのコストが乗るが、乗る分以上に売価が上げられる。
2. **調理の手間を肩代わりしている**。袋麺は鍋と丼が要るが、カップ麺はお湯だけで完結する。
   消費者が払っているのは麺ではなく「鍋を洗わなくていい」という便利さである。
3. **具（かやく）が入っている**。フリーズドライのエビ・肉・卵・ネギが商品の「顔」になり、値段の差を正当化する。

逆に袋麺は、**5食パックでスーパーの特売の目玉にされる**宿命がある。
「サッポロ一番5食 298円」のような値札が新聞折込チラシの一等地に載る。
つまり袋麺は**価格で客を呼ぶ商品**であり、メーカーから見れば
「数量は出るが1食あたりの利益は薄い」カテゴリになる。

## 2. 商品ができるまで ― 工程フロー

即席麺の作り方は、100年続く伝統製法ではなく**完全な工業プロセス**である。

```
【揚げ麺（フライ麺）の製造フロー】

 小麦粉・かんすい・塩水
   │
   ▼ ① ミキシング ── 粉と水を混ぜて生地にする
   ▼ ② 圧延（あつえん）── ロールで薄い帯状に伸ばす
   ▼ ③ 切り出し・ウェーブ ── 細く切り、波打たせる
   │      ※波＝湯が通る隙間。戻り時間3分の正体
   ▼ ④ 蒸し ── 蒸気でα化（でんぷんを消化できる状態にする）
   ▼ ⑤ 型入れ・カット ── 1食分ずつリテーナ（型）に入れる
   ▼ ⑥ フライ ── 150℃前後のパーム油で1〜2分。水分を12%→3%以下へ
   │      ★ここで麺重量の約2割が油になる ＝ パーム油相場が原価に直撃
   ▼ ⑦ 冷却 → ⑧ 容器詰め（カップ）／包装（袋）
   │      かやく・粉末スープ・液体スープを同時に投入
   ▼ ⑨ 金属検出・重量検査・シール検査 → 箱詰め → 出荷

 【ノンフライ麺】は ⑥ を「熱風乾燥」に置き換える。油を使わないので
   カロリーが低く生麺に近い食感になるが、乾燥に時間がかかり原価は上がる
   （「マルちゃん正麺」「ラ王」など高単価帯の商品）。
```

ここから読めることが2つある。

- **④の蒸しと⑥のフライは装置で決まる**。レシピを真似しても、同じ装置と条件がなければ同じ麺にならない。
  これが [総合食品③](../01_総合食品/03_商品開発とブランド.md) でいう「工業化」の壁そのものである。
- **⑥で油を食わせている**。揚げ麺は麺の重量の2割前後が油であり、
  パーム油の相場が上がると、小麦より先に原価に効くことがある。

## 3. 工場の経済性 ― 1ライン当たりの重さ

即席麺は典型的な**装置産業**である。1本の生産ラインが巨大で、止めると固定費だけが残る。

日清食品の関西工場（滋賀県栗東市、2018年10月操業）が分かりやすい実例になる。

| 項目           | 数値                                                  |
| -------------- | ----------------------------------------------------- |
| 投資額         | 約 **575億円**                                        |
| 生産ライン数   | **10本**                                              |
| 生産能力       | 日産 **約400万食**                                    |
| 敷地面積       | 約10万㎡（横300m × 奥行150m）                         |
| 品質管理カメラ | 約 **700台**、15か所をチェック                        |
| 主な生産品目   | カップヌードル、どん兵衛、U.F.O.、チキンラーメン ほか |

（日清食品の公表資料および報道ベース。2018年時点）

> **ポイント：1工場に575億円。これが即席麺の参入障壁の実体である。**
> 味が真似できるかどうかではなく、**全国に安定供給できる生産能力を持てるか**が問題になる。

工場の経済性で効いてくるのは次の3つ。

| 論点             | 中身                                                 | なぜ効くか                                                          |
| ---------------- | ---------------------------------------------------- | ------------------------------------------------------------------- |
| **稼働率**       | ラインを止めた時間は、そのまま償却費の垂れ流しになる | 固定費比率が高い。数量が2割落ちると1食あたり原価が数%跳ねる         |
| **切り替えロス** | 味を変えるたびに洗浄・段取り替えが要る               | 新商品を増やすほど稼働率が下がる。SKU（品目数）の増加は正義ではない |
| **自動化**       | 資材・容器の搬送をロボット化して人を減らす           | 人手不足と最低賃金上昇への唯一の答え。ただし初期投資が重い          |

即席麺メーカーが「新商品を年に何百品も出すのに、工場は定番を作り続けている」のは矛盾ではない。
**定番でラインを埋めて稼働率を確保し、その余力で新商品を回す**のが基本設計だからである。

## 4. 原料 ― 小麦・パーム油・かやくの三点セット

即席麺の原価は、ほぼ次の4つで説明がつく。

```
【カップ麺1食の原価イメージ（構成のイメージ。金額比率は概念図）】

  小麦粉        ███████          ← 政府売渡価格に連動。輸入小麦は国が売り渡す
  パーム油      █████            ← 揚げ麺なら麺重量の約2割。国際相場と為替
  かやく・スープ ████████         ← エビ・肉・野菜のFD（フリーズドライ）。最も高い部品
  容器・包装    ██████           ← 紙カップ、フィルム、段ボール。原油・パルプ連動
  工場人件費・償却 ████
  ＋ 物流費 ＋ 販促費（リベート・特売協賛）
```

| 原料               | 2026年時点の状況                                                                                                | 効き方                                                                                                                                             |
| ------------------ | --------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **小麦粉**         | 輸入小麦の政府売渡価格は令和8年（2026年）4月期に5銘柄加重平均 **62,520円/トン**、**+2.5%** に改定（農林水産省） | 国が半年ごとに改定する。**メーカーはこの改定日を見て値上げの段取りを組む**                                                                         |
| **パーム油**       | 2026年5月の国内卸価格は1kg **333〜343円** で4か月連続上昇。海外のバイオ燃料需要が押し上げ（日本経済新聞）       | 揚げ麺の原価に直結。インドネシア・マレーシアの政策と為替で動く                                                                                     |
| **かやく（具材）** | エビ、豚肉、鶏肉、卵、ネギ、キャベツをフリーズドライ加工                                                        | **1食の原価で最も高い部品になりやすい**。水産相場・畜産相場の影響を受ける → [水産](../11_水産/README.md)／[畜産・飼料](../13_畜産・飼料/README.md) |
| **容器・包装**     | 紙カップ、発泡素材、フィルム、段ボール                                                                          | 原油・パルプ連動。カップ麺は袋麺よりここが重い → [紙・パルプ](../../10_素材・化学/09_紙・パルプ/README.md)                                         |

小麦の政府売渡価格という制度そのものは [製粉・製糖・製油](../02_製粉・製糖・製油/README.md) に詳しい。
即席麺メーカーにとっては、**「原価上昇の証明」を小売に示すときの最強の材料**でもある
（→ [総合食品②](../01_総合食品/02_値決めと交渉.md) 第4章）。

## 5. 物流 ― 「軽いのに運べない」という固有の問題

即席麺、とくにカップ麺は、食品の中でもきわめて**輸送効率が悪い**。

```
【トラック1台の積み方（イメージ）】

   ＜缶詰・調味料＞          ＜カップ麺＞
  ┌──────────────┐       ┌──────────────┐
  │ ■■■■■■■■■■ │       │ ░░░░░░░░░░ │
  │ ■■■■■■■■■■ │       │ ░░░░░░░░░░ │
  │ ■■■■■■■■■■ │       │ ░░░░░░░░░░ │
  └──────────────┘       └──────────────┘
   重量制限が先に来る        荷台が一杯でも重量はスカスカ
   → 荷台に隙間が残る        → 体積で先に上限に達する

  カップ麺は「容積勝負（かさもの）」。1台で運べる金額が小さい
  ＝ 売上に対する物流費の比率が構造的に高くなる
```

カップ麺は中身がほぼ空気で、**荷台の重量上限より先に容積上限に達する**ため、
売上100円あたりの輸送コストが他の加工食品より高くつく。
ここに2024年4月からのトラック運転手の時間外労働上限規制（**物流2024年問題**）が重なった。
業界全体でトラックの積載率は4割程度まで落ちているとされ（国土交通省・日本ロジスティクスシステム協会の資料）、
即席麺メーカーは打ち手を迫られている。

| 打ち手                     | 内容                                                     | 例                                                                                                  |
| -------------------------- | -------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| **共同輸送**               | 重いものと軽いものを混載して、重量と容積の両方を使い切る | 日清食品とサッポログループ物流が即席麺とビールを共同輸送し、トラック約20%削減（2022年、報道ベース） |
| **パレット・外装の標準化** | 箱のサイズを揃えて積載効率を上げる                       | 業界共通パレットの導入                                                                              |
| **納品リードタイムの延長** | 翌日納品を翌々日にして、積み合わせの余裕を作る           | 小売との交渉事項                                                                                    |

物流の全体像は [食品卸②](../../06_商社・卸売/06_食品卸/02_物流という本体.md)、
[陸運・トラック](../../13_運輸・物流/06_陸運・トラック/README.md) を参照。

## 6. プレイヤーの構図 ― 5社でほぼ決まる

国内の即席麺は、**上位5社でほぼすべて**という寡占市場である。

| 企業                       | 主力ブランド                                             | 立ち位置                                                                                                                                            |
| -------------------------- | -------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| **日清食品（日清食品HD）** | カップヌードル、どん兵衛、U.F.O.、チキンラーメン、ラ王   | 業界の創業者かつ最大手。2026年3月期の日清食品HD連結売上収益は **7,920億円**（+2%）。**利益の約半分を海外が稼ぐ**点が他社と違う                      |
| **東洋水産（マルちゃん）** | 赤いきつね／緑のたぬき、マルちゃん正麺、マルちゃん焼そば | 国内2番手。2026年3月期は売上高 **5,366億円**（+4.8%）、営業利益 **858億円**（+12.1%）と**全利益指標で過去最高**。稼ぎ頭は北米・メキシコの海外即席麺 |
| **サンヨー食品**           | サッポロ一番（袋麺）、カップスター                       | 非上場。**袋麺で圧倒的な定番**を持つ。「サッポロ一番みそラーメン」は特売の常連                                                                      |
| **エースコック**           | スーパーカップ、わかめラーメン、はるさめ                 | 大盛り・ボリューム訴求が強い。**ベトナムで圧倒的シェア**を持つ海外の成功例                                                                          |
| **明星食品**               | チャルメラ、一平ちゃん                                   | 2006年から**日清食品グループ傘下**。グループ内で別ブランドとして棚を取る役割                                                                        |

（各社の売上高は決算短信ベース。ブランド構成は各社公表情報）

シェアの数値は各社が公表していないため、報道・調査会社の推計に頼るしかない。
おおまかな相場観としては、**日清食品グループ（明星を含む）が4割前後、東洋水産が2割前後、
サンヨー食品・エースコックが続く**構図とされるが、
**袋麺とカップ麺で順位が変わる**点に注意が必要である（袋麺ではサンヨー食品が強い）。

> **ポイント：即席麺は日本の加工食品の中でも寡占度が高いカテゴリの一つ。**
> しょうゆやマヨネーズと同じく、「カテゴリ名ではなくブランド名で買われる」状態にある
> （→ [総合食品③](../01_総合食品/03_商品開発とブランド.md) 第5章のカテゴリ別寡占度）。

## 7. 定番が異常に強い ― ロングセラーの経済学

即席麺は新商品の投入数がきわめて多いカテゴリである。コンビニの棚は毎週入れ替わる。
それにもかかわらず、**売上の中心は数十年前からほとんど変わらない**。

| ブランド                   | 発売年 | いまの位置づけ                                             |
| -------------------------- | ------ | ---------------------------------------------------------- |
| チキンラーメン             | 1958年 | 世界初の即席麺。ブランドの象徴                             |
| **カップヌードル**         | 1971年 | 世界初のカップ麺。2025年度に過去最高売上を更新（日清食品） |
| **赤いきつね／緑のたぬき** | 1978年 | 和風カップ麺の定番。東洋水産の看板                         |
| **サッポロ一番**           | 1966年 | 袋麺の定番。特売の主役                                     |

なぜここまで定番が強いのか。

1. **失敗したくない商品だから**。即席麺は「とりあえずお腹を満たす」用途で買われる。
   新しい味に賭けて外したときの落胆が大きく、消費者は知っている味に戻る。
2. **物価高で「選別消費」が進んだ**。2025年度はJAS品（定番品が多い）が **+3.9%**、
   非JAS品は **▲15.8%**（食品新聞、2026年6月）。
3. **棚を守る力になる**。定番は小売が外せない。外すと客が「あの店には置いていない」と学習する。
   メーカーは定番で棚の面積を確保し、その横に新商品を置く。

新商品の役割は「当てること」より、**棚の面積を守り、売場に動きを作ること**にある。
この考え方は食品全般に共通する（→ [総合食品③](../01_総合食品/03_商品開発とブランド.md) 第2章）。

## 8. 値決め ― 2026年の値上げで対応が分かれた

即席麺は希望小売価格（メーカー希望価格）とオープン価格が混在するカテゴリで、
**値上げの「発表の仕方」が各社で異なる**。2026年の改定はその違いがよく出た例である。

| 企業         | 実施時期           | 内容                                                                                                                                                                                                            |
| ------------ | ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **日清食品** | 2026年4月1日出荷分 | 即席袋麺・カップ麺・カップスープ約170品を希望小売価格ベースで **5〜11%** 引き上げ。カップヌードル（レギュラー）236円→**248円**、ビッグ271円→**298円**。一部の袋麺とカップライスは**価格据え置きで内容量を減量** |
| **東洋水産** | 2026年7月1日納品分 | カップ麺・ワンタンを希望小売価格ベースで **4〜11%**（オープン価格品は出荷価格10%）引き上げ。赤いきつねうどん（レギュラー）236円→**248円**、でか盛271円→**298円**。**袋麺などは価格据え置き**                    |

（各社ニュースリリースおよび食品新聞・日本経済新聞の報道ベース）

読み取れることは3つ。

- **カップ麺の主力レギュラー品は248円に横並びした**。定番同士は事実上の価格連動になっている。
- **袋麺の扱いが分かれた**。東洋水産は袋麺を据え置いた。**袋麺は特売の武器なので、値上げすると
  スーパーのチラシから外される**リスクがある。ここが袋とカップで経済が違うことの帰結である。
- **減量（実質値上げ）が併用された**。価格を据え置いて内容量を減らす手法は
  [総合食品②](../01_総合食品/02_値決めと交渉.md) 第5章のとおり合法だが、気づかれたときの反発が大きい。

さらに、**希望小売価格を上げても店頭の実勢売価が上がるとは限らない**。
特売でいくらにするかを決めるのは小売である。値上げが利益に乗るかどうかは、
発表後3〜6か月の実勢売価の推移を見ないと分からない。

## 9. 販路 ― 誰に売っているか

```
【販路ごとの経済（同じカップヌードルでも手取りが違う）】

  コンビニ        ──▶ 定価に近い248円で売れる。最も粗利が取れる
                       代わりにPB・限定品の開発を求められる
  スーパー／GMS   ──▶ 袋麺5食パックが特売の目玉。数量は出るが
  ドラッグストア       特売協賛とチラシ協賛で粗利が削られる
  EC・通販        ──▶ ケース買い。物流費は重いが特売圧力が弱い
  業務用・備蓄    ──▶ 官公庁・企業の防災備蓄。大口で価格が安定
```

PB（プライベートブランド）の受託も無視できない。コンビニのPBカップ麺は売場上位を占めることも多く
（セブン-イレブンの人気カップ麺上位10商品のうち7商品がPBという調査もある）、
メーカーにとっては**自社ブランドの棚を削る相手でありながら、工場の稼働率を埋めてくれる客**でもある
（→ [総合食品②](../01_総合食品/02_値決めと交渉.md) 第6章、

## 10. まとめ ― この章を理解する3つの鍵

1. **カップと袋は別の商売**。1食あたり単価は約158円と約82円で約1.9倍の差。
   カップは便利さを売り、袋は価格で客を呼ぶ。値上げの打ち手も分かれる。
2. **工場が参入障壁**。1工場575億円、10ライン、日産400万食という規模が、味の模倣を無意味にする。
   だから定番でラインを埋め、稼働率を守ることが利益の源泉になる。
3. **原料はパーム油と小麦、コストの隠れた山は物流**。カップ麺は「かさもの」で
   荷台が容積で先に埋まるため、売上に対する物流費が構造的に高い。

## 用語メモ

| 用語                    | 意味                                                                                                                                                   |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **フライ麺（揚げ麺）**  | 蒸した麺を150℃前後の油で揚げて水分を飛ばした麺。麺重量の約2割が油になる。3分で戻るのはこの製法ゆえ                                                     |
| **ノンフライ麺**        | 揚げずに熱風で乾燥させた麺。生麺に近い食感でカロリーが低いが、乾燥に時間がかかり原価が高い。「マルちゃん正麺」「ラ王」など                             |
| **α化（アルファか）**   | でんぷんに水と熱を加えて、人が消化できる状態に変えること。工程④の蒸しがこれにあたる                                                                    |
| **かやく**              | 麺に添えられる乾燥具材（エビ・肉・卵・野菜）。フリーズドライ加工され、1食の原価で最も高い部品になりやすい                                              |
| **リテーナ**            | 麺を1食分ずつ入れて形を整える型。カップにぴったり収まる円柱形はこれで作られる                                                                          |
| **JAS品／非JAS品**      | 日本農林規格（JAS）の格付を受けた即席麺かどうかの区分。統計上、定番ブランドはJAS品に多い                                                               |
| **SKU（エスケーユー）** | Stock Keeping Unit。味・サイズごとに数える商品の最小単位。増やすほど工場の切り替えロスが増える                                                         |
| **かさもの**            | 重量に比べて体積が大きい商品。カップ麺が典型。トラックが容積で先に満載になる                                                                           |
| **物流2024年問題**      | 2024年4月からトラック運転手の時間外労働が年960時間に制限されたことによる輸送力不足 → [陸運・トラック](../../13_運輸・物流/06_陸運・トラック/README.md) |
| **オープン価格**        | メーカーが希望小売価格を設定せず、売価を小売に委ねる方式。値上げは「出荷価格の改定」として発表される                                                   |
