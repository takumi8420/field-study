日本で発明され、いまや世界で年1,242億食（2025年、世界ラーメン協会）が消費される加工食品。
国内需要は59.0億食・7,864億円（2025年度、日本即席食品工業協会）で、世界の約5%にすぎない。

この業界を理解する最短の道は、「袋麺」と「カップ麺」を別の商売として分けて見ることである。
1食あたり単価はカップ約158円、袋約82円で約1.9倍の差があり、粗利率も、値上げの打ち手も、
売っている販路も違う。同じ工場で作っていても、経済が別物になっている。

1. 業界の定義・範囲

即席麺 ＝ 麺をあらかじめ調理・乾燥させ、お湯を注ぐか短時間煮るだけで食べられる状態にした加工食品。
日本即席食品工業協会の統計では、次の2つに大別される。

区分 中身 特徴
袋麺（即席袋めん）麺とスープを袋に入れたもの。鍋で調理する5食パックが主流。特売の目玉商品
カップ麺（即席カップめん）容器に麺・スープ・かやくを入れ、お湯を注ぐだけ調理器具が不要。単価が高い

さらに麺の作り方で フライ麺（揚げ麺） と ノンフライ麺 に分かれる。
この製法の違いが原価と食感を決める（→ ① 第2章）。

【隣接カテゴリとの境界】

  ＜即席麺＞                      ＜隣のカテゴリ＞
  ─────────────────────      ─────────────────────
  常温で長期保存できる           生麺・チルド麺 → 要冷蔵。日持ちしない
  お湯だけで完成                 冷凍麺         → 冷凍庫とレンジが要る
  工場で大量生産                 乾麺（そば・うどん・パスタ）
                                                 → スープが付かない素材型
  スープ・かやく込みの完成品      店のラーメン   → 外食。店舗の経済性で決まる
                                                 → 18_焼肉・ラーメン

  ★「カップライス」「即席スープ」は隣接商品として
    同じ工場・同じ営業ルートで扱われることが多く、
    各社の価格改定でも即席麺と一緒に発表される。

境界の引き方で押さえる点。

  • 常温・長期保存が定義の核。ここが冷凍麺・チルド麺と決定的に違い、
    輸出と備蓄に向くという性質を生んでいる。
  • 「ラーメン」は外食の話。麺の種類ではなく、店舗ビジネスかメーカービジネスかで分ける。
  • カップライス・カップスープは同じ商売の一部。工場・販路・値決めの単位が同じため、
    業界統計では別でも、経営上は一体で扱われる。

成長性の読み方。

  • 国内の食数は構造的に伸びない。人口減少が効くうえ、すでに1人あたり年約48食と普及しきっている。
    金額が伸びた年は、ほぼ値上げによる名目の膨張である。
  • それでも需要は崩れない。2025年度は微減だが歴代4位の水準。
    即席麺は不況に強い（外食から家庭内食への流れを受ける）ため、下方硬直性がある。
  • 中身は定番に集中している。2025年度はJAS品+3.9%に対し非JAS品▲15.8%。
    物価高の選別消費で、ロングセラーを持つ会社ほど有利になっている。
  • 成長は海外にしかない。世界需要は過去最高を更新し、インドが4年で約27%増。
    ただし単価の低い市場での食数増なので、金額・利益は食数ほど伸びない。

段階 経済的な特徴
原料（小麦・パーム油）国際相場と為替で決まる。メーカーは価格決定力を持たない
製粉・製油素材型。営業利益率2〜5%。小麦は政府売渡価格に連動 → 製粉・製糖・製油

ポイント：即席麺メーカーの利益は「どの販路でどれだけ売るか」で大きく変わる。
同じカップヌードルでも、コンビニで248円で売れるのとスーパーの特売で158円になるのとでは、
メーカーが最終的に手にする利益（特売協賛を引いた後）が全く違う。

5. 収益モデル・コスト構造

【カップ麺 vs 袋麺（1食あたりの経済。金額はイメージ）】

  ＜カップ麺＞ 売価 約158円        ＜袋麺＞ 売価 約82円
   ├ 麺（小麦・油）  ██             ├ 麺（小麦・油）  ██
   ├ かやく・スープ  ███            ├ スープ          █
   ├ 容器・包装      ██   ◀カップ   ├ 包装            ▌
   ├ 工場人件費・償却 █             ├ 工場人件費・償却 █
   ├ 物流費          ██   ◀かさもの ├ 物流費          █
   ├ 販促・特売協賛  █              ├ 販促・特売協賛  ██  ◀5食パックは特売の目玉
   └ 粗利            ████           └ 粗利            █

   → カップは容器と物流のコストを負うが、
      それを上回る売価が取れる。粗利額はカップが圧倒的に大きい。
   → 袋麺は売価が低いうえ特売協賛が重く、1食あたりの利益が薄い。
論点 中身
カップと袋で経済が違う1食単価は約158円と約82円。カップは便利さを売り、袋は価格で客を呼ぶ。値上げの打ち手も分かれる
装置産業である日清食品の関西工場は投資額 約575億円、10ライン、日産約400万食。固定費が重く、稼働率が利益を決める
原料は小麦とパーム油揚げ麺では麺重量の約2割が油。パーム油の上昇は小麦より速く効くことがある
かやくが最も高い部品フリーズドライのエビ・肉・野菜。商品の「顔」であり、原価の中心
物流費が構造的に高いカップ麺は「かさもの」。トラックの重量上限より先に容積上限に達し、1台で運べる金額が小さい
定番が利益を稼ぐ新商品は棚の面積を守るための手段。利益は数十年もののロングセラーが生む

詳しくは ① 即席麺の商売。

6. 競争要因（KSF）と参入障壁

KSF 中身
定番ブランドの保有カップヌードル（1971年）、赤いきつね（1978年）、サッポロ一番（1966年）。小売が棚から外せない状態を作ることが全て。2025年度のJAS品+3.9%／非JAS品▲15.8%という差がそれを裏づける
生産能力と自動化1工場575億円という規模。全国に安定供給できるかどうかが土俵に立つ条件
味の開発力と工業化試作の味を毎秒数個のラインで再現する技術。レシピが漏れても真似できない本当の障壁
販路ごとの提案力コンビニには週次の新商品・限定品、スーパーには特売企画。同じ商品を同じ売り方では通らない
原料調達力小麦・パーム油の相場変動を吸収する購買体制。規模が効く
海外の現地生産拠点輸出だけでは関税と輸送費に勝てない。現地工場を持つことが長期の競争力になる（→ ②）

参入障壁は許認可ではない（食品製造業は営業許可とHACCP対応が要るが免許制ではない）。
実質的な障壁は ①数十年かけた定番ブランド、②数百億円規模の生産設備、③棚を取り続けるための販促費 の3つ。
実際、国内で意味のある規模を持つのは5社程度にとどまっており、
加工食品の中でも寡占度の高いカテゴリになっている。

7. 規制・法制度

制度 内容 即席麺への影響
食品衛生法／HACCP2021年6月から原則すべての食品事業者に義務化大手はすでに対応済み。自動化投資と一体で進む
食品表示法原材料名、アレルゲン（小麦・えび・卵など）、栄養成分、原料原産地の表示義務アレルゲン表示ミスは即回収。かやくの原料変更のたびに表示を見直す必要がある
JAS（日本農林規格）即席めんのJAS規格がある。格付を受けた商品はJASマークを表示できる業界統計がJAS品／非JAS品で区分されるため、需要動向の読み方にも関わる
輸入小麦の政府売渡制度国が輸入小麦を買い付け、製粉会社に売り渡す。年2回（4月期・10月期）改定2026年4月期は5銘柄加重平均62,520円/トン、+2.5%（農水省）。値上げの根拠として使われる → 製粉・製糖・製油
景品表示法優良誤認・有利誤認の禁止「大盛り」「特盛」などの表示や、実質値上げ（減量）の告知の仕方に関わる
独占禁止法（優越的地位の濫用）／適正取引推進ガイドライン一方的な価格据置き要請や、根拠のないセンターフィー・リベート要請を規制。ガイドラインは2026年1月に改定小売との価格交渉の材料になる → 総合食品②
改正物流効率化法2026年4月に特定事業者の指定・CLO（物流統括管理者）選任義務が施行かさもの＝積載効率の悪い即席麺はこの論点の当事者。共同輸送の推進要因
飲食料品の消費税引下げ2026年9月15日閣議決定。2027年4月〜2029年3月の2年間、8%→1%とする方針（法改正が必要）店頭価格が下がる余地に値上げをぶつけられるか。袋麺の価格競争が激化する恐れ
食品ロス削減推進法／納品期限の緩和1/3ルールの見直し即席麺は賞味期限が長く、緩和の恩恵を受けやすいカテゴリ

    現地工場を持つ日本勢には巻き返しの余地。
