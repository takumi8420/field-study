# 即席麺

- 大分類: 食品・農水産・外食
- 状態: done
- 更新日: 2026-09-20

日本で発明され、いまや**世界で年1,242億食**（2025年、世界ラーメン協会）が消費される加工食品。
国内需要は**59.0億食・7,864億円**（2025年度、日本即席食品工業協会）で、世界の約5%にすぎない。

この業界を理解する最短の道は、**「袋麺」と「カップ麺」を別の商売として分けて見る**ことである。
1食あたり単価はカップ約158円、袋約82円で**約1.9倍の差**があり、粗利率も、値上げの打ち手も、
売っている販路も違う。同じ工場で作っていても、経済が別物になっている。

## 1. 業界の定義・範囲

**即席麺** ＝ 麺をあらかじめ調理・乾燥させ、**お湯を注ぐか短時間煮るだけで食べられる状態にした加工食品**。
日本即席食品工業協会の統計では、次の2つに大別される。

| 区分                           | 中身                                           | 特徴                            |
| ------------------------------ | ---------------------------------------------- | ------------------------------- |
| **袋麺（即席袋めん）**         | 麺とスープを袋に入れたもの。鍋で調理する       | 5食パックが主流。特売の目玉商品 |
| **カップ麺（即席カップめん）** | 容器に麺・スープ・かやくを入れ、お湯を注ぐだけ | 調理器具が不要。単価が高い      |

さらに麺の作り方で **フライ麺（揚げ麺）** と **ノンフライ麺** に分かれる。
この製法の違いが原価と食感を決める（→ [①](01_即席麺の商売.md) 第2章）。

```
【隣接カテゴリとの境界】

  ＜即席麺＞                      ＜隣のカテゴリ＞
  ─────────────────────      ─────────────────────
  常温で長期保存できる           生麺・チルド麺 → 要冷蔵。日持ちしない
  お湯だけで完成                 冷凍麺         → 冷凍庫とレンジが要る
  工場で大量生産                 乾麺（そば・うどん・パスタ）
                                                 → スープが付かない素材型
  スープ・かやく込みの完成品      店のラーメン   → 外食。店舗の経済性で決まる
                                                 → 18_焼肉・ラーメン

  ★「カップライス」「即席スープ」は隣接商品として
    同じ工場・同じ営業ルートで扱われることが多く、
    各社の価格改定でも即席麺と一緒に発表される。
```

境界の引き方で押さえる点。

- **常温・長期保存が定義の核**。ここが冷凍麺・チルド麺と決定的に違い、
  **輸出と備蓄に向く**という性質を生んでいる。
- **「ラーメン」は外食の話**。麺の種類ではなく、店舗ビジネスかメーカービジネスかで分ける。
- **カップライス・カップスープは同じ商売の一部**。工場・販路・値決めの単位が同じため、
  業界統計では別でも、経営上は一体で扱われる。

## 2. 市場規模と成長性

| 指標                     | 数値                                                  | 年・出典                         |
| ------------------------ | ----------------------------------------------------- | -------------------------------- |
| **国内総需要（食数）**   | **59億506万食**（前年度比 **▲1.3%**）。歴代4位        | 2025年度。日本即席食品工業協会   |
| うちカップ麺             | 39億4,386万食（▲0.3%）、構成比 **67%**                | 同上                             |
| うち袋麺                 | 19億6,119万食（▲3.3%）、構成比 **33%**                | 同上                             |
| **国内小売金額（推計）** | **7,864億円**（▲1.3%）。カップ6,249億円／袋1,614億円  | 同上                             |
| 前年度（参考）           | 59億8,347万食（+4.1%）、金額 **7,967億円で過去最高**  | 2024年度。同協会                 |
| 定番と非定番の差         | **JAS品 +3.9% / 非JAS品 ▲15.8%**                      | 2025年度。同協会                 |
| **世界総需要**           | **1,242億1,000万食**（+0.7%）。**過去最高**           | 2025年。世界ラーメン協会（WINA） |
| 日本の世界シェア         | 59.5億食 ＝ **世界の約4.8%**                          | 2025年。WINA                     |
| 1食あたり単価            | カップ **約158円** / 袋 **約82円**（金額÷食数で算出） | 2025年度。協会統計から計算       |

成長性の読み方。

- **国内の食数は構造的に伸びない**。人口減少が効くうえ、すでに1人あたり年約48食と普及しきっている。
  金額が伸びた年は、ほぼ値上げによる名目の膨張である。
- **それでも需要は崩れない**。2025年度は微減だが歴代4位の水準。
  即席麺は**不況に強い**（外食から家庭内食への流れを受ける）ため、下方硬直性がある。
- **中身は定番に集中している**。2025年度はJAS品+3.9%に対し非JAS品▲15.8%。
  物価高の選別消費で、ロングセラーを持つ会社ほど有利になっている。
- **成長は海外にしかない**。世界需要は過去最高を更新し、インドが4年で約27%増。
  ただし**単価の低い市場での食数増**なので、金額・利益は食数ほど伸びない。

## 3. バリューチェーン（川上 → 川下）

```
【モノとカネの流れ】

 モノ
   小麦（輸入）──▶ 製粉会社 ──┐
   パーム油（輸入）─────────┤
   かやく原料（エビ・肉・野菜）┼──▶ 即席麺メーカー ──▶ 卸 ──▶ 小売 ──▶ 消費者
   容器・包装資材 ───────────┘      （本フォルダ）      │
                                                          └──▶ EC・備蓄・業務用

 カネ
   即席麺メーカー ──── 建値で請求 ────▶ 卸／小売
   即席麺メーカー ──── 特売協賛・リベート ──▶ 小売   ← 袋麺でとくに重い
   小売 ──────────── PB受託の発注 ─────▶ メーカー   ← 自社ブランドの棚を削る相手

 情報
   メーカー ◀── POS・棚割り ── 小売
   メーカー ──── 新商品提案（週次の入れ替え）──▶ コンビニ本部
```

付加価値がどこに集まるか。

| 段階                   | 経済的な特徴                                                                                             |
| ---------------------- | -------------------------------------------------------------------------------------------------------- |
| 原料（小麦・パーム油） | 国際相場と為替で決まる。**メーカーは価格決定力を持たない**                                               |
| 製粉・製油             | 素材型。営業利益率2〜5%。小麦は政府売渡価格に連動 → [製粉・製糖・製油](../02_製粉・製糖・製油/README.md) |
| **即席麺メーカー**     | **ブランドと生産能力で差がつく段階**。カップ麺で高い粗利を取り、袋麺は数量で稼ぐ                         |
| 食品卸                 | 営業利益率1%台。物流が差別化要因 → [食品卸](../../06_商社・卸売/06_食品卸/README.md)                     |
| 小売                   | 販路によって即席麺の扱いが正反対（コンビニ＝定価に近い／スーパー・ドラッグ＝特売の目玉）                 |

> ポイント：**即席麺メーカーの利益は「どの販路でどれだけ売るか」で大きく変わる。**
> 同じカップヌードルでも、コンビニで248円で売れるのとスーパーの特売で158円になるのとでは、
> メーカーが最終的に手にする利益（特売協賛を引いた後）が全く違う。

## 4. 主要プレイヤーとシェア

| 企業                         | 立ち位置                   | 特徴                                                                                                                                                                                                              |
| ---------------------------- | -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **日清食品（日清食品HD）**   | 業界の創業者かつ最大手     | カップヌードル、どん兵衛、U.F.O.、チキンラーメン、ラ王。2026年3月期の連結売上収益 **7,920億円**（+2%）。**利益の柱の一つが海外**だが、同期は米国苦戦で純利益▲22%と下方修正。明星食品を傘下に持つ                  |

| **明星食品**                 | 日清グループ内の別ブランド | チャルメラ、一平ちゃん。2006年から日清食品グループ。グループとして棚の面積を増やす役割                                                                                                                            |
| 小売PB（セブンプレミアム等） | 委託生産される競合         | コンビニPBのカップ麺が売場上位を占めることも多い。メーカーにとっては受託先であり競合でもある                                                                                                                      |
| 海外勢（農心・三養など）     | 輸入品として国内にも流入   | 辛ラーメン、ブルダック炒め麺。世界市場では最大の競合                                                                                                                                                              |

（各社決算短信・公表資料および報道ベース）

**シェアの見方**：各社はカテゴリ別シェアを公表していないため、精緻な数値は存在しない。
報道・調査会社の推計ベースでは **日清食品グループ（明星含む）が4割前後、東洋水産が2割前後**、
サンヨー食品・エースコックが続く構図とされる。
ただし **袋麺とカップ麺で順位が入れ替わる**（袋麺はサンヨー食品が強い）点に注意。

## 5. 収益モデル・コスト構造

```
【カップ麺 vs 袋麺（1食あたりの経済。金額はイメージ）】

  ＜カップ麺＞ 売価 約158円        ＜袋麺＞ 売価 約82円
   ├ 麺（小麦・油）  ██             ├ 麺（小麦・油）  ██
   ├ かやく・スープ  ███            ├ スープ          █
   ├ 容器・包装      ██   ◀カップ   ├ 包装            ▌
   ├ 工場人件費・償却 █             ├ 工場人件費・償却 █
   ├ 物流費          ██   ◀かさもの ├ 物流費          █
   ├ 販促・特売協賛  █              ├ 販促・特売協賛  ██  ◀5食パックは特売の目玉
   └ 粗利            ████           └ 粗利            █

   → カップは容器と物流のコストを負うが、
      それを上回る売価が取れる。粗利額はカップが圧倒的に大きい。
   → 袋麺は売価が低いうえ特売協賛が重く、1食あたりの利益が薄い。
```

| 論点                       | 中身                                                                                                      |
| -------------------------- | --------------------------------------------------------------------------------------------------------- |
| **カップと袋で経済が違う** | 1食単価は約158円と約82円。カップは便利さを売り、袋は価格で客を呼ぶ。値上げの打ち手も分かれる              |
| **装置産業である**         | 日清食品の関西工場は投資額 **約575億円**、10ライン、**日産約400万食**。固定費が重く、稼働率が利益を決める |
| **原料は小麦とパーム油**   | 揚げ麺では麺重量の約2割が油。**パーム油の上昇は小麦より速く効く**ことがある                               |
| **かやくが最も高い部品**   | フリーズドライのエビ・肉・野菜。商品の「顔」であり、原価の中心                                            |
| **物流費が構造的に高い**   | カップ麺は「かさもの」。トラックの重量上限より先に容積上限に達し、1台で運べる金額が小さい                 |
| **定番が利益を稼ぐ**       | 新商品は棚の面積を守るための手段。利益は数十年もののロングセラーが生む                                    |

詳しくは [① 即席麺の商売](01_即席麺の商売.md)。

## 6. 競争要因（KSF）と参入障壁

| KSF                    | 中身                                                                                                                                                                              |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **定番ブランドの保有** | カップヌードル（1971年）、赤いきつね（1978年）、サッポロ一番（1966年）。**小売が棚から外せない状態**を作ることが全て。2025年度のJAS品+3.9%／非JAS品▲15.8%という差がそれを裏づける |
| **生産能力と自動化**   | 1工場575億円という規模。全国に安定供給できるかどうかが土俵に立つ条件                                                                                                              |
| **味の開発力と工業化** | 試作の味を毎秒数個のラインで再現する技術。レシピが漏れても真似できない本当の障壁                                                                                                  |
| **販路ごとの提案力**   | コンビニには週次の新商品・限定品、スーパーには特売企画。**同じ商品を同じ売り方では通らない**                                                                                      |
| **原料調達力**         | 小麦・パーム油の相場変動を吸収する購買体制。規模が効く                                                                                                                            |
| **海外の現地生産拠点** | 輸出だけでは関税と輸送費に勝てない。現地工場を持つことが長期の競争力になる（→ [②](02_世界市場と日本勢.md)）                                                                       |

**参入障壁**は許認可ではない（食品製造業は営業許可とHACCP対応が要るが免許制ではない）。
実質的な障壁は **①数十年かけた定番ブランド、②数百億円規模の生産設備、③棚を取り続けるための販促費** の3つ。
実際、国内で意味のある規模を持つのは**5社程度**にとどまっており、
加工食品の中でも寡占度の高いカテゴリになっている。

## 7. 規制・法制度

| 制度                                                         | 内容                                                                                                  | 即席麺への影響                                                                                                                                  |
| ------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **食品衛生法／HACCP**                                        | 2021年6月から原則すべての食品事業者に義務化                                                           | 大手はすでに対応済み。自動化投資と一体で進む                                                                                                    |
| **食品表示法**                                               | 原材料名、アレルゲン（小麦・えび・卵など）、栄養成分、原料原産地の表示義務                            | **アレルゲン表示ミスは即回収**。かやくの原料変更のたびに表示を見直す必要がある                                                                  |
| **JAS（日本農林規格）**                                      | 即席めんのJAS規格がある。格付を受けた商品はJASマークを表示できる                                      | 業界統計がJAS品／非JAS品で区分されるため、**需要動向の読み方にも関わる**                                                                        |
| **輸入小麦の政府売渡制度**                                   | 国が輸入小麦を買い付け、製粉会社に売り渡す。年2回（4月期・10月期）改定                                | **2026年4月期は5銘柄加重平均62,520円/トン、+2.5%**（農水省）。値上げの根拠として使われる → [製粉・製糖・製油](../02_製粉・製糖・製油/README.md) |
| **景品表示法**                                               | 優良誤認・有利誤認の禁止                                                                              | 「大盛り」「特盛」などの表示や、**実質値上げ（減量）の告知の仕方**に関わる                                                                       |
| **独占禁止法（優越的地位の濫用）／適正取引推進ガイドライン** | 一方的な価格据置き要請や、根拠のないセンターフィー・リベート要請を規制。ガイドラインは2026年1月に改定 | 小売との価格交渉の材料になる → [総合食品②](../01_総合食品/02_値決めと交渉.md)                                                                   |
| **改正物流効率化法**                                         | 2026年4月に特定事業者の指定・CLO（物流統括管理者）選任義務が施行                                      | **かさもの＝積載効率の悪い即席麺はこの論点の当事者**。共同輸送の推進要因                                                                        |
| **飲食料品の消費税引下げ**                                   | 2026年9月15日閣議決定。**2027年4月〜2029年3月の2年間、8%→1%**とする方針（法改正が必要）               | 店頭価格が下がる余地に値上げをぶつけられるか。袋麺の価格競争が激化する恐れ                                                                      |
| **食品ロス削減推進法／納品期限の緩和**                       | 1/3ルールの見直し                                                                                     | 即席麺は賞味期限が長く、**緩和の恩恵を受けやすいカテゴリ**                                                                                      |

1. **約3年ぶりの値上げで、カップ麺レギュラーが248円に横並び** — 日清食品は2026年4月出荷分から
   約170品を5〜11%引き上げ（カップヌードル236→248円）。東洋水産は2026年7月納品分から4〜11%
   （赤いきつね236→248円）。**袋麺は据え置きが基本**で、カップと袋で打ち手が分かれた。
2. **国内需要は▲1.3%だが、中身は定番一極集中** — 2025年度は59億506万食で歴代4位。
   **JAS品+3.9%に対し非JAS品▲15.8%**。物価高の選別消費でロングセラーに需要が集まった。
3. **世界需要は2025年に1,242億食で過去最高** — インドが96.0億食（+8.8%）と牽引、中国は微減。
   欧州を除く全エリアが成長（世界ラーメン協会）。
4. **日清食品HDと東洋水産で明暗** — 2026年3月期、日清HDは米国苦戦で純利益▲22%と下方修正。
   東洋水産は北米・メキシコ好調で営業利益858億円（+12.1%）と**過去最高**。
   **違いは価格帯の置き方**（高付加価値 vs 低価格帯）。
5. **韓国勢の攻勢と関税という逆風** — 2025年の韓国のラーメン輸出は15.2億ドル（+21.9%）で
   単一品目初の15億ドル超。一方、米国の関税で農心の業績は鈍化と報じられる。
   現地工場を持つ日本勢には巻き返しの余地。

## 9. 用語メモ

各ノート末尾に詳しい用語メモがある。ここでは最重要の7つ。

| 用語                         | 意味                                                                                                                         |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| **フライ麺（揚げ麺）**       | 蒸した麺を150℃前後の油で揚げて水分を飛ばした麺。麺重量の約2割が油になる。3分で戻るのはこの製法ゆえ → [①](01_即席麺の商売.md) |
| **ノンフライ麺**             | 熱風で乾燥させた麺。生麺に近い食感でカロリーが低いが原価が高い。「マルちゃん正麺」「ラ王」など → [①](01_即席麺の商売.md)     |
| **かやく**                   | 麺に添えられる乾燥具材。フリーズドライ加工され、**1食の原価で最も高い部品**になりやすい → [①](01_即席麺の商売.md)            |
| **かさもの**                 | 重量に比べて体積が大きい商品。カップ麺が典型で、トラックが容積で先に満載になる → [①](01_即席麺の商売.md)                     |
| **JAS品／非JAS品**           | 日本農林規格の格付を受けた即席麺かどうか。定番ブランドはJAS品に多く、2025年度の明暗を分けた → [③](03_直近トピック_2026.md)   |
| **WINA（世界ラーメン協会）** | 世界の即席麺需要の公式統計を毎年公表する唯一の機関。この業界の世界数値はほぼここが出典 → [②](02_世界市場と日本勢.md)         |
| **ローリングストック**       | 備蓄品を日常的に消費しながら買い足し、常に一定量の新しい備蓄を保つ方法 → [②](02_世界市場と日本勢.md)                         |
