# ③ 収益改善の打ち手 — 値上げが効きにくい業態が、人件費を機械で削った

このノートで分かること：ファミレスが利益を出すために実際に打っている手
（配膳ロボット・タッチパネル・セルフレジ・時間帯別メニュー・アプリ会員）が、
**それぞれどの費用項目に、いくら効くのか**。
そして、なぜファミレスでは「値上げ」が最後の手段になるのか。

> 結論：ファミレスは **価格弾力性が高い**（値上げすると客が他へ逃げやすい）業態である。
> 代替が多すぎるからで、客はコンビニ・中食・回転寿司・他ファミレスへ簡単に移る。
> だから各社は値上げより先に、**L（人件費）を機械で削る**方を選んだ。
> 配膳ロボットとタッチパネルがファミレスから普及したのは偶然ではない。
> **床面積が広く（＝歩行距離が長く）、滞在が長く（＝注文回数が多い）という
> ファミレス固有の弱点が、そのまま機械の投資対効果を最大にした**からである。

店舗経済の前提は [① ファミレスの経済](01_ファミレスの経済.md)、
外食共通の指標は [外食1店舗の経済](../14_ファストフード/01_外食1店舗の経済.md) を参照。

---

## 1. まず「値上げが効きにくい」とはどういうことか

**価格弾力性＝価格を1%上げたとき、客数が何%減るか**。
これが大きい（弾力性が高い）ほど、値上げが売上につながりにくい。

```
【値上げ後の売上変化（客単価1,200円・客数400人/日の店）】

  ケースA：弾力性が低い（高級店・専門店）
    価格 +5% → 客数 ▲1%
    売上 = 1,260円 × 396人 = 498,960円（+3.9%） ★値上げが効く

  ケースB：弾力性が高い（ファミレス）
    価格 +5% → 客数 ▲6%
    売上 = 1,260円 × 376人 = 473,760円（▲1.3%） ★値上げしたのに売上が減る

  → ファミレスはBに近い。さらに悪いことに、
    客数が減ると★人件費はすぐには減らない★（ホールは最低人数が決まっている）ので、
    利益はもっと大きく落ちる。
```

なぜファミレスの弾力性が高いのか。理由は「代替の多さ」に尽きる。

| 客が逃げる先                                                                                                | なぜ移れるか                                               |
| ----------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| [コンビニ](../../07_小売・流通/01_コンビニエンスストア/README.md)・[中食・弁当](../20_中食・弁当/README.md) | 同じ1,000円で家で食べられる。家族の食事は代替が効きやすい  |
| [回転寿司](../17_回転寿司/README.md)                                                                        | 同じ郊外ロードサイドで、同じ家族連れを取り合っている       |
| 他のファミレス                                                                                              | 幹線道路沿いには複数チェーンが並んでいる。切替コストがゼロ |
| [ファストフード](../14_ファストフード/README.md)                                                            | 客単価が半分。値上げ局面では下に落ちる                     |
| 内食（自炊）                                                                                                | 「今日は外食やめる」という選択がそのまま需要の消滅になる   |

> ポイント：ファミレスの客は **「この店に行きたい」より「今日は外で食べたい」**
> という動機で来ることが多い。店ではなく**シーン**を買っている。
> だから店を替える心理的コストが低く、価格に敏感になる。
> これが業態としての最大の弱点であり、**省力化に賭ける理由**でもある。

## 2. 配膳ロボット — ファミレスで最も効いた投資

**配膳ロボット＝料理を厨房から客席まで運ぶ自律走行の台車**。
すかいらーくグループは2021年8月に導入を開始し、
**2022年12月時点で全国約2,100店に約3,000台**の導入を完了した（同社発表）。

なぜファミレスで効果が大きいのか。3つの理由がある。

```
【ホールスタッフの1日の作業時間の内訳（イメージ）】

  注文を取る  ▓▓▓▓            15%
  料理を運ぶ  ▓▓▓▓▓▓▓▓▓▓▓▓    35%   ← ★ここが最大★
  下げる      ▓▓▓▓▓▓▓▓        25%
  レジ会計    ▓▓▓▓▓            15%
  清掃・補充  ▓▓▓              10%

  ・ファミレスは客席が100〜140席と広く、厨房から最遠席まで20〜30m
  ・1日400人の来店なら、料理を運ぶ往復は数百回に及ぶ
  ・★「運ぶ」は熟練が要らない＝真っ先に機械化できる作業★
```

| 効果                   | 中身                                                                                                                                                               |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **歩行距離の削減**     | 運搬をロボットが肩代わりし、人は注文・接客・下げに集中できる                                                                                                       |
| **ピーク人員の削減**   | 必要人数がピーク時で決まる（→[外食1店舗の経済5章](../14_ファストフード/01_外食1店舗の経済.md)）ため、ピークの1人減がそのまま人件費に効く                           |
| **採用の裾野が広がる** | 重い皿を長距離運ぶ作業が減り、**高齢者や体力に制約のある人も働ける**。導入した運営会社も「採用が増えた」という効果を挙げている（東洋経済オンラインほかの取材記事） |
| **離職の抑制**         | 身体負荷が下がることで定着率が上がる                                                                                                                               |

```
【配膳ロボット1台の投資回収（概算モデル）】

  導入費用    本体＋設置＋通信：1台あたり 200万〜300万円（リースなら月5万〜8万円）
  削減効果    ピーク帯のホール 0.5〜1.0人分
              → 1日4時間 × 1,200円 × 0.75人 × 30日 = 約 108,000円/月
  ────────────────────────────────────────────
  リース月額 6万円と比べると 月4.8万円のプラス
  購入（250万円）なら 250万 ÷ 10.8万 ≒ 23か月 ＝ 約2年で回収

  ※中小企業省力化投資補助金（配膳ロボット等が対象。上限1億円・補助率最大2/3）を
    使えば回収はさらに短くなる（→ [ファストフード④](../14_ファストフード/04_人手不足と省力化.md)）
```

すかいらーくHDは2026年8月、2026年12月期の連結純利益予想を195億円→**205億円**へ
上方修正し、**10期ぶりの最高益**を見込むと発表した。
報道では、配膳ロボットと卓上タブレット注文による省人化が
人件費上昇を吸収した点が要因として挙げられている。

## 3. タッチパネル注文とセルフレジ — 「注文」と「会計」を客に移す

配膳ロボットが「運ぶ」を削るのに対し、タッチパネルは「注文を取る」、
セルフレジは「会計する」を削る。3つ合わせて**ホール作業の6割前後**に手が入る。

| 施策                             | 削る作業                    | 投資額の目安                           | 副次的な効果                                                               |
| -------------------------------- | --------------------------- | -------------------------------------- | -------------------------------------------------------------------------- |
| **卓上タッチパネル／QRオーダー** | 注文を取る（作業の15%前後） | 1店 100万〜300万円（QRなら大幅に安い） | **追加注文が増える**。呼ぶ手間がないためデザート・ドリンクの追加率が上がる |
| **配膳ロボット**                 | 運ぶ（35%前後）             | 1台 200万〜300万円                     | 採用の裾野拡大、離職抑制                                                   |
| **セルフレジ／テーブル決済**     | 会計（15%前後）             | 1店 100万〜200万円                     | **ピーク時のレジ待ち行列が消える**＝回転率が上がる                         |
| **下げ膳のセルフ化**             | 下げる（25%前後）           | ほぼゼロ（導線設計のみ）               | 抵抗感が強く、ファミレスでは限定的                                         |

> ポイント：**タッチパネルは人件費を削るだけでなく、客単価を上げる**。
> 店員を呼ぶという心理的ハードルがなくなるため、
> 「もう1品」「ドリンクのおかわり」が注文されやすくなる。
> **コストを下げる施策と売上を上げる施策が同じ装置で両立する**のは珍しく、
> だからファミレスでは真っ先に全店導入が進んだ。

```
【3つの省力化を入れた店の人件費（120席・1日400人のモデル）】

■ 従来
   ピーク帯 ホール5名 ＋ キッチン4名 = 9名
   1日の総労働時間 約 70人時 × 1,200円 = 84,000円/日 → 月 252万円
   売上 1,440万円に対する L = 17.5%（社員給与・法定福利費を加えて実質 30%前後）

■ 省力化後（タッチパネル＋ロボット＋セルフレジ）
   ピーク帯 ホール3名 ＋ キッチン4名 = 7名
   1日の総労働時間 約 56人時 × 1,200円 = 67,200円/日 → 月 202万円
   ────────────────────────────────────────
   削減 月 50万円（年 600万円）
   → ★L（人件費率）を 3ポイント前後下げられる。
     FLが62〜68%に振れやすいファミレスにとって、これは利益の有無を分ける大きさ★
```

## 4. 時間帯別の採算改善 — 空いている時間に「別の商売」を置く

ファミレスは1日10〜17時間営業する（→[①6章](01_ファミレスの経済.md)）。
その長さは、**時間帯ごとに違う商売を1つの箱で回せる**という強みでもある。

| 時間帯                    | 置く商売                       | 狙い                                            | 実例                                                               |
| ------------------------- | ------------------------------ | ----------------------------------------------- | ------------------------------------------------------------------ |
| **モーニング**（7〜10時） | 低原価の朝定食・ドリンクセット | 開店時の固定費回収。高齢者の常連化              | 各社のモーニングセット                                             |
| **ランチ**（11〜14時）    | セットメニュー・日替わり       | 最大の稼ぎ時。**待たせない**ことが全て          | 平日限定ランチ                                                     |
| **アイドル**（14〜17時）  | **カフェ需要＋デザート**       | 人件費だけが流れる時間を粗利で埋める            | ドリンクバー＋パンケーキ、むさしの森珈琲業態                       |
| **ディナー**（17〜21時）  | 家族向けコース・アルコール     | 客単価が最も高い                                | 宴会・誕生日需要                                                   |
| **深夜**（22時〜）        | 少人数・長時間滞在             | **深夜割増25%を上回る客数が立つ立地だけ**開ける | すかいらーくは2020年に24時間全廃、2023年以降に立地を絞って一部復活 |

ガストが導入した平日限定の**「ガストフィットメニュー」**（小皿料理3品にドリンクバー・
スープバーを付けて約1,000円）は、この考え方の典型例といえる。
2025年12月期の同社決算では、このメニューが客数増に寄与したと説明されている。

```
【アイドルタイムを埋める施策の経済（14〜17時・3時間）】

  ■ 施策なし
     客数 15人 × 客単価 700円 = 10,500円
     人件費 2名 × 3時間 × 1,200円 = ▲7,200円
     F(30%) ▲3,150円 → ★限界利益 +150円（ほぼゼロ）★

  ■ ドリンクバー＋デザート訴求
     客数 35人 × 客単価 750円 = 26,250円
     人件費 2名 × 3時間 × 1,200円 = ▲7,200円（★人は増やさない★）
     F(22%／ドリンク比率が高いので低い) ▲5,775円
     → 限界利益 +13,275円/日 → 月 約40万円

  ※ポイントは「客単価を上げる」ことではなく
    ★すでに払っている人件費の下で客数だけを増やす★こと。
```

## 5. テイクアウトとデリバリー — 席数の上限を外す

ファミレスの売上上限は **席数 × 回転率** で決まる。
テイクアウトとデリバリーは、この上限そのものを外す手段になる。

| チャネル                                 | 経済的な意味                                                  | 注意点                                                                                                                                           |
| ---------------------------------------- | ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| **テイクアウト（持ち帰り）**             | 席を使わずに売れる。**F・容器代のみで、家賃も席も消費しない** | 容器代が乗る（2026年は容器・包装資材の高騰が続く）。軽減税率8%適用                                                                               |
| **デリバリー（プラットフォーム経由）**   | 商圏を店の前から半径2〜3kmへ広げる                            | **手数料が注文金額の30%前後**。原価率と合わせるとほぼ利益が残らない（→[ファストフード②](../14_ファストフード/02_ファストフード特有の仕組み.md)） |
| **自社配達**                             | 手数料を払わずに済む                                          | 配達員の確保と管理が必要。配達1件あたりの人件費が重い                                                                                            |
| **宅配専業ブランド（ゴーストキッチン）** | 既存店の厨房の空き時間で別ブランドを売る                      | 厨房のピークが重なると本業を圧迫する                                                                                                             |

```
【デリバリー1件（注文金額2,000円）の店側の手取り】

  注文金額            2,000円
  プラットフォーム手数料 ▲600円（30%）
  食材費 F(30%)        ▲600円
  容器・包装           ▲100円
  ピッキング人件費      ▲100円
  ──────────────────────
  店の手取り            600円（粗利率30%）
  → 店内飲食なら同じ2,000円で粗利1,400円（70%）残る。
    ★デリバリーは「売上は立つが利益は薄い」。
     アイドルタイムなど★余っている人手で回す限りにおいて意味がある★
```

## 6. 会員アプリとクーポン — 頻度を動かせる唯一の変数

売上＝客数×客単価だが、客単価には天井がある（家族の1食に払える額は決まっている）。
**頻度（同じ客が月に何回来るか）には天井がない**。ここを動かすのが会員アプリである。

| 手段                         | 何が変わるか                                                         | 副作用                                                     |
| ---------------------------- | -------------------------------------------------------------------- | ---------------------------------------------------------- |
| **アプリ会員＋クーポン配信** | 来店頻度を直接動かせる。「今週末使える」という期限で来店を作れる     | **クーポン依存**。定価で来なくなり、実質値下げが常態化する |
| **来店データの蓄積**         | 誰が、いつ、何を食べたかが分かる。メニュー改廃と出店判断の材料になる | 個人情報の管理コスト                                       |
| **モバイルオーダー／席予約** | ピークの待ち行列を平準化し、回転率を上げる                           | システム投資と運用                                         |
| **サブスク（定額）**         | 頻度を強制的に上げる。ドリンクバー定額などの事例がある               | 使い倒す客ばかりが残ると赤字化する                         |

> ポイント：**クーポンは「値上げの逆」である**。
> 値上げが客数を減らすのと同じ強さで、クーポンは利益を減らす。
> ロイヤルホストが基本的にクーポンを使わないのは、
> **一度下げた価格の記憶は客から消えない**という判断による。
> 一方でガストのようなボリュームゾーンは、
> クーポンなしでは客数を保てないという現実もある。**どちらが正解かは客層で決まる**。

## 7. 打ち手の優先順位 — 効果と投資の一覧

| 打ち手                       | 効く項目                | 投資額（1店）          | 回収期間 | 効果の大きさ                        |
| ---------------------------- | ----------------------- | ---------------------- | -------- | ----------------------------------- |
| **タッチパネル／QRオーダー** | L↓・客単価↑             | 100万〜300万円         | 1〜2年   | ★★★（売上とコストの両方）           |
| **配膳ロボット**             | L↓                      | 200万〜300万円/台      | 約2年    | ★★★                                 |
| **セルフレジ／テーブル決済** | L↓・回転率↑             | 100万〜200万円         | 1〜2年   | ★★                                  |
| **アイドルタイム施策**       | 売上↑（人件費は据置）   | ほぼゼロ（販促費のみ） | 即時     | ★★★                                 |
| **深夜営業の見直し**         | L↓（深夜割増）          | ゼロ                   | 即時     | ★★（立地次第で逆効果）              |
| **業態転換**                 | 売上↑・立地資産の再活用 | 3,000万〜8,000万円     | 3〜5年   | ★★★（→[②](02_業態の分化と再編.md)） |
| **テイクアウト／デリバリー** | 売上↑（利益は薄い）     | 数十万円               | —        | ★                                   |
| **会員アプリ／クーポン**     | 客数↑（利益は削れる）   | 本部投資               | —        | ★★（諸刃）                          |
| **値上げ**                   | 客単価↑・**客数↓**      | ゼロ                   | 即時     | ★（弾力性が高く、最後の手段）       |

```
【ファミレスの収益改善の打ち手マップ】

                    売上を増やす
                         ▲
      アイドル施策 ●     │     ● 業態転換
      テイクアウト ●     │     ● タッチパネル（両取り）
                         │
  ────────────── ● 値上げ ──────────────▶ コストを下げる
                         │     ● 配膳ロボット
      クーポン ●         │     ● セルフレジ
      （売上は増えるが    │     ● 深夜営業の見直し
        利益は減る）      ▼

  ★右上（タッチパネル・業態転換）が最優先。
    値上げは中央＝効果が読めず、弾力性の高いこの業態では副作用が大きい★
```

## 用語メモ

| 用語                             | 意味                                                                                                                       |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| **価格弾力性**                   | 価格を1%上げたときに需要（客数）が何%減るか。ファミレスは代替が多く弾力性が高い                                            |
| **配膳ロボット**                 | 料理を客席まで運ぶ自律走行台車。すかいらーくは2022年12月時点で約2,100店に約3,000台導入                                     |
| **卓上タッチパネル／QRオーダー** | 客が自分で注文する仕組み。人件費を削ると同時に追加注文を増やす                                                             |
| **限界利益**                     | 売上から変動費だけを引いた利益。「その時間帯を開けるべきか」を判断する指標                                                 |
| **人時（にんじ）**               | 1人が1時間働く労働量の単位。外食のシフト計算の基本単位                                                                     |
| **人時売上高**                   | 売上 ÷ 総労働時間。省力化投資の効果を測る代表指標                                                                          |
| **プラットフォーム手数料**       | デリバリー事業者に払う手数料。注文金額の30%前後 → [ファストフード②](../14_ファストフード/02_ファストフード特有の仕組み.md) |
| **ゴーストキッチン**             | 客席を持たず宅配専用に調理するブランド。既存店の厨房の空き時間で運用することもある                                         |
| **中小企業省力化投資補助金**     | 配膳ロボットなどの省力化設備に対する国の補助（上限1億円・補助率最大2/3）                                                   |
| **クーポン依存**                 | 割引がないと客が来なくなる状態。実質的な恒常値下げになる                                                                   |
