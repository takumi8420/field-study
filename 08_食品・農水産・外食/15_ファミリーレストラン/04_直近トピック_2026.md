# ④ 直近トピック（2026年9月時点）

報道および各社IR資料ベースの整理。数値は発表時点のもので、
確定値・会社予想・推計・報道を区別して書いている。最新は各社IRで確認すること。

> 全体を一言で：**ファミレス大手は好業績だが、中身は「省力化でコスト増を吸収し、
> 業態転換で低価格帯を取り戻した」結果**である。
> ファミレスという業態そのものは店舗数が減り続けており、
> 各社の成長は**ファミレス以外の業態（うどん・定食・焼肉・カフェ）**が担っている。
> 2026年最大のニュースは、**「値上げしない」サイゼリヤが値上げ検討に転じた**こと。
> 垂直統合という最強の防御でも原料高・賃料高を吸収しきれなくなった、という象徴になる。

前提となる仕組みは [① ファミレスの経済](01_ファミレスの経済.md)、
[② 業態の分化と再編](02_業態の分化と再編.md)、
[③ 収益改善の打ち手](03_収益改善の打ち手.md) を参照。

## 1. すかいらーくHDが10期ぶり最高益へ（2026年8月・上方修正）

すかいらーくホールディングスは2026年8月、2026年12月期の連結業績予想を上方修正した。

| 項目       | 修正後予想（2026年12月期）               | 備考                                      |
| ---------- | ---------------------------------------- | ----------------------------------------- |
| 売上収益   | **5,000億円**                            | 資さんうどん・しんぱち食堂のM&A効果を含む |
| 営業利益   | **350億円**                              | —                                         |
| 当期純利益 | **205億円**（従来195億円から5.1%上振れ） | **10期ぶりの過去最高益**見込み            |

前期（2025年12月期）の実績は次のとおり（同社決算短信・流通系メディア報道）。

| 項目         | 2025年12月期         | 前期比                                          |
| ------------ | -------------------- | ----------------------------------------------- |
| 売上収益     | 4,577.9億円          | +14.1%                                          |
| 営業利益     | 299.6億円            | +23.9%                                          |
| 既存店売上高 | —                    | **+8%（客数+2%、客単価+6%）**                   |
| 新規出店     | 77店（うち国内59店） | しゃぶ葉19店、ガスト14店、資さんうどん9店が中心 |
| **業態転換** | **36店**             | 既存店を別ブランドへ衣替え                      |

読みどころは3点。

- **客単価+6%に対し客数+2%**。値上げ主導だが、客数もプラスを保った。
  [③1章](03_収益改善の打ち手.md)の弾力性の議論でいえば、
  **値上げ分を上回る価値提供（メニュー刷新・省力化による待ち時間短縮）で客離れを抑えた**形
- **新規77店に対し業態転換36店**という比率。出店の3分の1相当を「衣替え」で作っている
- 報道では、**配膳ロボットと卓上タブレットによる省人化DXが人件費上昇を吸収**したことが
  最高益の要因として挙げられている（→[③2章](03_収益改善の打ち手.md)）

## 2. サイゼリヤが約6年ぶりの値上げ検討へ（2026年7月報道）

**2026年で最も構造的な意味を持つニュース**。「値上げしない」を看板にしてきた
サイゼリヤが、価格改定を検討する方針に転じたと報じられた（日本経済新聞ほか）。

| 項目     | 内容                                                                                                                                                               |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 報道時期 | 2026年7月                                                                                                                                                          |
| 発言     | 松谷秀治社長が「2027年8月期は消費者物価指数（CPI）の動向を見ながら、**アフォーダブルプライス（手ごろな価格）の範囲内での価格改定も視野に入れる**」と述べたとされる |
| 背景     | 原材料価格と店舗賃料の高騰を、客数増と販管費圧縮で補いきれなくなった                                                                                               |
| 試算     | 報道では**客単価を10円上げれば約20億円の増益**になるとされる                                                                                                       |
| 現状     | 2026年9月時点で正式決定ではなく、立地別価格の導入も検討対象と報じられる段階                                                                                        |

2026年8月期の業績自体は好調である。

| 項目     | 2026年8月期（会社予想） | 前期比 |
| -------- | ----------------------- | ------ |
| 売上高   | **2,970億円**           | +15.7% |
| 営業利益 | **182億円**             | +17.4% |

| 項目                   | 2026年8月期3Q累計（9月〜5月） | 前年同期比                      |
| ---------------------- | ----------------------------- | ------------------------------- |
| 売上高                 | 2,213.3億円                   | +17.5%                          |
| 営業利益               | 133.3億円                     | +25.6%                          |
| 日本セグメント営業利益 | 55.9億円                      | **+120.7%**                     |
| 連結客数               | 1億6,427万人                  | **+15.5%**（前年 1億4,168万人） |
| 連結客単価             | 870円                         | +12円（前年 858円）             |

> ポイント：**売上増の主役は客数（+15.5%）であって値上げではない**。
> 値上げなしで客数を2,259万人増やした結果が、日本セグメント営業利益+120.7%。
> [③1章](03_収益改善の打ち手.md)で見た「値上げすると客が逃げる」の逆を走ってきた。
> その企業が値上げに傾いたという事実が、**2026年のコスト環境の厳しさを示している**。

## 3. 業態転換とM&A — ファミレスを「うどん」と「定食」に替える動き

すかいらーくHDの低価格帯強化が、2026年に一段と加速した。

| 案件             | 時期                                                                   | 内容                                                                                 |
| ---------------- | ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| **資さんうどん** | 2024年に買収（約240億円と報じられる）                                  | 2030年をめどに**約4倍の400店**へ。2024年以降の出店約30店の大半が**ガストからの転換** |
| **しんぱち食堂** | **2026年4月に株式取得**（投資ファンドのJ-STARなどから、**約110億円**） | 炭火焼き干物定食チェーン（約108店）。2030年に**約300店**へ拡大する計画               |

なぜこの2つなのか。[②5章](02_業態の分化と再編.md)の立地の議論と直結している。

```
【すかいらーくの2つの買収が埋めている穴】

  資さんうどん  → 郊外ロードサイドの「低価格帯」の穴
                 ガストが値上げで失った低価格層を、
                 ★同じ建物のまま★うどん店に替えて取り戻す

  しんぱち食堂  → 都心・狭小立地の「坪効率」の穴
                 ガストの設計（広い席・長い滞在）では
                 坪家賃3万円の駅前に入れない。
                 ★都市型の坪効率を持つ業態そのものを買った★

  共通点：どちらも「新しいブランドが欲しかった」のではなく
         ★自社の弱点をピンポイントで埋める器★として買われている
```

## 4. ファミレス業態そのものは縮小が続く

大手の好決算の裏で、**ファミレスというカテゴリーの店舗数は減り続けている**。

| 調査                                               | 内容                                                                                                                                                                       |
| -------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 帝国データバンク（2022年8月発表）                  | ファミレス運営主要16社の店舗数が2022年6月期で**8,420店**。コロナ前（2019年12月期）比で**約810店・約9%減**。当該年度末にはコロナ前比で累計1,000店超の減少を見込むとしていた |
| 同調査（業態構成比、ファミレス非専業8社）          | **ファストフード+1.2pt、カフェ+0.9pt、焼肉+0.4pt**が増加、居酒屋▲1.1pt                                                                                                     |
| 日本ソフト販売「2026年版チェーン店舗数ランキング」 | ガスト▲11店（▲0.9%）、デニーズ▲3店（▲0.9%）、**ジョナサン▲9店（▲5.4%）**、ステーキガスト▲4店（▲4.8%）。**力強い増加傾向を示すファミレスチェーンがない**と指摘される        |

（pt＝ポイント。構成比の増減を表す単位）

- 減り方が「急減」ではなく**年1%前後のじわじわ減**に変わったのが2020年代の特徴。
  一気に閉めるフェーズが終わり、**業態転換で処理するフェーズ**に入ったことを示す
- 一方で **しゃぶ葉・資さんうどん・むさしの森珈琲**といった非ファミレス業態は増えている。
  つまり企業は成長しているが、**ファミレスという看板は減っている**

## 5. コスト環境 — コメ高・チキンショック・容器高騰が重なる

2026年の外食は、原材料の複数項目が同時に上がる局面にある。

| コスト項目                 | 2026年の状況                                                                                                                                                       |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **コメ**                   | 価格高騰が継続。ファミレスは米飯メニューの比率が高く、直撃を受ける。ロイヤルHDは2025年12月期に**国産米を中心とした原材料費高騰の影響額が23億円**に達したとしている |
| **鶏肉（チキンショック）** | 国際的な鶏肉需給の逼迫で価格上昇                                                                                                                                   |
| **容器・包装資材**         | 中東情勢などの影響で高騰。テイクアウト比率の高い店ほど効く                                                                                                         |
| **人件費**                 | 最低賃金が2025年度に全国加重平均**1,121円（+66円）**。外食最大のコスト変数                                                                                         |
| **賃料**                   | 都市部を中心に上昇。サイゼリヤが値上げ検討に転じた理由の一つとして挙げられている                                                                                   |

日本経済新聞の調査報道（2026年6月）では、**外食企業の約6割が2026年度に値上げを実施・予定**
としている。ファミレス・ファストフードチェーンでは一部メニューが10〜50円値上げされた。

一方、市場全体は名目では伸びている。
日本フードサービス協会の月次調査では、2025年12月の外食売上が前年同月比**6.0%増**、
低価格業態であるファストフードとファミリーレストランが売上を下支えしたとされる。
ただし[ファストフードREADME](../14_ファストフード/README.md)でも触れたとおり、
**この伸びは値上げによる単価上昇が主因で、食事回数そのものは伸びていない**点に注意。

## 7. 省力化の定着と、人の供給の制度的な天井

- すかいらーくグループの配膳ロボットは**2022年12月時点で約2,100店・約3,000台**で導入完了。
  2026年時点では「導入フェーズ」ではなく**「入っているのが前提」**の段階に入っている
- 副次効果として、**重い配膳作業が減ったことで高齢者など採用できる人の幅が広がった**ことが
  運営側から報告されている（東洋経済オンラインほか取材記事）
- 一方で人の供給には制度的な上限がついた。**特定技能1号「外食業」は分野別上限5万人に到達し、
  2026年4月13日から新規受入が当面停止**されている
  （→ [ファストフード④ 人手不足と省力化](../14_ファストフード/04_人手不足と省力化.md)）
- **深夜営業は立地を絞って選択的に運用**する形が定着した。
  すかいらーくは2020年に24時間営業を全廃したが、2023年以降、
  客数の立つ立地に限って深夜営業を戻している

```
        │
        └─▶ 業態転換 … ファミレスの箱を、うどん・定食・焼肉・カフェに替える
                     （資さんうどん400店計画、しんぱち食堂110億円買収）

  ★結論：企業は成長しているが、「ファミレス」という看板は減り続けている。
    2026年の主役は【省力化で守り、業態転換で攻める】という組み合わせ。
    そして「値上げしない」サイゼリヤの方針転換が、
    その防御にも限界が来つつあることを示している★
```

## 用語メモ

| 用語                           | 意味                                                                                                                                           |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| **上方修正**                   | 期中に会社が業績予想を引き上げること。逆は下方修正                                                                                             |
| **既存店売上高**               | 開店から一定期間経った店だけの前年比。売上・客数・客単価の3点で読む → [外食1店舗の経済](../14_ファストフード/01_外食1店舗の経済.md)            |
| **業態転換（コンバージョン）** | 建物を残したまま別ブランドに衣替えすること → [②](02_業態の分化と再編.md)                                                                       |
| **アフォーダブルプライス**     | 手ごろで払える価格帯。サイゼリヤが値上げ検討時に用いた表現                                                                                     |
| **消費者物価指数（CPI）**      | 物価の変動を示す指数。外食各社が価格改定の判断材料にする                                                                                       |
| **チキンショック**             | 国際的な鶏肉需給の逼迫による価格高騰                                                                                                           |
| **特定技能1号「外食業」**      | 外食現場で就労できる在留資格。分野別上限に到達し2026年4月13日から新規受入停止 → [ファストフード④](../14_ファストフード/04_人手不足と省力化.md) |
| **pt（ポイント）**             | 比率の差を表す単位。「構成比が+1.2pt」は構成比そのものが1.2%分増えたという意味                                                                 |
| **IFRS**                       | 国際会計基準。すかいらーくHDはこの基準で「売上収益」「営業利益」を開示する                                                                     |
