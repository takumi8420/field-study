# ② 業態の分化と再編 — 「総合型ファミレス」は解体され、ブランドの束になった

このノートで分かること：かつて1店であらゆる料理を出していたファミレスが、
なぜ **ガスト／バーミヤン／しゃぶ葉** のように専門ブランドへ割れたのか。
すかいらーく・ゼンショー・サイゼリヤ・ロイヤルHD・王将という5社が、
同じ「ファミレス」という枠の中で**まったく違う稼ぎ方**をしている理由。

> 結論：ファミレス各社の主戦場は、**「どのブランドを出すか」ではなく
> 「同じ建物・同じ物流・同じ人で、どのブランドに衣替えするか」**に移った。
> 郊外ロードサイドの建物は20年契約で、駐車場も厨房も転用が効く。
> だから不振店は**閉めるのではなく、需要のある業態へ転換（コンバージョン）する**。
> すかいらーくが2025年12月期に新規出店77店に対し**業態転換を36店**行ったのは、
> これが安価で速い「出店」だからである。

前提となる店舗経済（坪効率・CK・FL）は [① ファミレスの経済](01_ファミレスの経済.md) を参照。
外食共通の指標は [外食1店舗の経済](../14_ファストフード/01_外食1店舗の経済.md) で定義済み。

## 1. 総合型から専門型へ — なぜ分化したのか

1970〜80年代のファミレスは、**1つのブランドで洋食・和食・中華・デザートを全部出す
「総合型」**だった（初期のすかいらーく、デニーズ、ロイヤルホストなど）。
これが分化した理由は3つある。

| 分化の理由               | 中身                                                                                                               |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------ |
| **メニュー数の限界**     | 全ジャンルを載せると200品を超え、食材SKUとロスが手に負えなくなる（→[①3章](01_ファミレスの経済.md)）                |
| **選ばれる理由が薄れる** | 「何でもある店」は「何かが特別に美味い店」に負ける。専門チェーンの台頭で総合型の優位が消えた                       |
| **同じ商圏に複数出せる** | 1ブランドでは商圏に1店しか出せないが、業態が違えば**同じ商圏に3〜4店**置ける（カニバリを避けつつ店舗数を増やせる） |

```
【総合型 → ブランド分割のイメージ（すかいらーくの場合）】

  1970〜80年代            1990年代〜                        2020年代
  ┌──────────┐      ┌───────┬───────┐        ┌──────┬──────┬──────┐
  │ すかいらーく │ ──▶ │ ガスト  │バーミヤン│ ──▶ │ガスト │しゃぶ葉│資さん │
  │ （洋・和・中）│      │（洋食） │ （中華） │        │むさしの森│ジョナサン│しんぱち│
  └──────────┘      └───────┴───────┘        └──────┴──────┴──────┘
     1店で全部          ジャンル別に分割             価格帯・シーン別に細分化
                                                    ＋M&Aで外から業態を買う

  ※分割しても【CK・物流・購買・人材】は共通のまま。
    ここが「分けても効率が落ちない」理由であり、この業態の最大の仕掛け。
```

> ポイント：**ブランドは分けるが、裏側（工場・トラック・購買・システム・人事）は分けない**。
> 表で差別化し、裏で規模の効果を取る。これが外食のマルチブランド戦略の型。

## 2. 業態転換（コンバージョン）の経済 — なぜ閉店より得か

ファミレスの建物は、**厨房の位置・給排水・電気容量・駐車場**という骨格が共通している。
だから中身を入れ替えるだけで別業態の店になる。

```
【新規出店 vs 業態転換 の投資比較（概算）】

■ 新規出店（郊外ロードサイド 120坪）
   土地保証金 + 建物 + 内装 + 厨房 + 外構 = 2.0億〜3.0億円
   開業までのリードタイム = 用地交渉から 12〜24か月

■ 業態転換（既存のファミレスを、うどん店や焼肉店に衣替え）
   内装改修 + 看板 + 一部厨房機器 + 販促  = 3,000万〜8,000万円
   リードタイム = 閉店から 1〜3か月
   ────────────────────────────────────
   → 投資は 1/4〜1/8、期間は 1/8 前後。
     しかも★立地評価はすでに済んでいる（客が来ることが分かっている場所）★
```

| 比較軸           | 新規出店       | **業態転換**                 | 閉店                           |
| ---------------- | -------------- | ---------------------------- | ------------------------------ |
| 投資額           | 2.0〜3.0億円   | **3,000万〜8,000万円**       | 原状回復費が出ていく           |
| 期間             | 12〜24か月     | **1〜3か月**                 | 即時                           |
| 立地リスク       | 未知           | **既知（実績データがある）** | —                              |
| 賃貸借契約       | 新規に20年拘束 | **残存契約をそのまま使える** | 中途解約違約金が発生しうる     |
| CK・物流の稼働率 | 上がる         | **維持できる**               | **下がる（固定費が重くなる）** |

**最後の行が効いている**。[①4章](01_ファミレスの経済.md) で見たとおり、
セントラルキッチンと自社物流は固定費なので、**店舗数が減ると1食あたり製造原価が上がる**。
つまり閉店は、その店の赤字を消す代わりに**残る全店のコストを上げる**。
だから大手ほど「閉めずに替える」方向に強く傾く。

すかいらーくは2024年に資さんうどん（福岡発のうどんチェーン）を約240億円で買収し、
以後出店した約30店の大半をガストからの転換で賄ったと報じられている。
2030年をめどに資さんうどんを**約4倍の400店**へ増やす計画（日本経済新聞、2026年3月）。
さらに2026年4月には定食チェーン「しんぱち食堂」（炭火焼き干物定食、約108店）を
**約110億円で買収**し、2030年に約300店へ増やす計画とされる（同社発表・報道ベース）。

> ポイント：**M&Aは「新しいブランドを買う」のではなく「転換先の受け皿を買う」**。
> 買ったブランドは、自社の既存店を入れ替えるための器として使われる。

## 4. 低価格路線と品質路線 — 2つの道の中身

### 低価格路線（サイゼリヤ型）：原価を「作る側」から下げる

サイゼリヤは「値上げしない」ことを最大の差別化にしてきた。
それを可能にしているのが**垂直統合**（原料生産から製造・物流・店舗まで自社で持つこと）。

- オーストラリアの自社農場、国内外の自社工場、自社物流を持ち、
  **仕入価格の交渉ではなく、製造原価そのものを作りにいく**
- 店舗側でも「ミリ単位で無駄な動きを削る」作業設計で人件費を抑える
- 結果として、原材料高の局面でも**値上げせずに客数を伸ばす**ことができた。
  2026年8月期3Qまでの客数は前年同期比+15.5%、客単価は858円→870円（+12円）

ただし2026年7月、同社は**約6年ぶりの値上げ検討**へ方針を転換したと報じられた
（日本経済新聞ほか）。松谷秀治社長は2027年8月期について
「消費者物価指数の動向を見ながら、アフォーダブルプライス（手ごろな価格）の
範囲内での価格改定も視野に入れる」と述べたとされる。
**垂直統合でも吸収しきれない水準まで原材料と賃料が上がった**ということになる。

### 品質路線（ロイヤルホスト型）：値引きしないことで客を選ぶ

ロイヤルホストは「ファミレスの中の高価格帯」に位置し、
**クーポンによる集客を基本的に行わない**ことで知られる。

- 既存店売上高は2025年12月期に**108.0%**（前年比+8.0%）と好調
- ただし同社の主戦場は外食だけではない。**機内食・ホテル・食品**を併せ持つ複合企業で、
  外食単体の変動をグループで吸収する構造になっている
- 2025年12月期は国産米を中心とした原材料費高騰の影響額が**23億円**に達したとされ、
  高価格帯であっても原料高の直撃は避けられていない

| 比較軸         | 低価格路線（サイゼリヤ）                   | 品質路線（ロイヤルホスト）         |
| -------------- | ------------------------------------------ | ---------------------------------- |
| 客を呼ぶ手段   | **価格そのもの**（クーポン不要）           | 料理・接客・空間の体験価値         |
| 原価率         | 高め（安く売るため）                       | 高め（良い食材のため）※理由が逆    |
| 人件費         | 作業設計で徹底的に削る                     | サービスに人を使う（削れない）     |
| 値上げ耐性     | **弱い**（安さが存在理由なので上げにくい） | **強い**（客層が価格に敏感でない） |
| 原料高への強さ | 垂直統合で吸収                             | 価格転嫁で吸収                     |
| 客数の伸び     | 伸ばせる（2026年8月期+15.5%）              | 伸びは緩やか。単価で稼ぐ           |

## 5. 立地の3類型 — 郊外・駅前・モール

| 類型                 | 坪家賃の目安           | 客層・利用シーン           | 向くブランド                               | 難所                                                           |
| -------------------- | ---------------------- | -------------------------- | ------------------------------------------ | -------------------------------------------------------------- |
| **郊外ロードサイド** | 0.5〜1.2万円           | 車で来る家族、地域の常連   | ガスト、バーミヤン、ココス、資さんうどん   | 商圏人口の減少と高齢化。20年契約の重さ                         |
| **駅前ビルイン**     | 2.0〜4.0万円           | 単身、学生、ビジネス、深夜 | サイゼリヤ、しんぱち食堂、餃子の王将       | **坪売上15万円以上が必須**。ファミレス標準型では入れない       |
| **モールイン**       | 1.0〜2.0万円＋売上歩合 | 買い物ついでの家族         | しゃぶ葉、むさしの森珈琲、フードコート業態 | 施設の営業時間・休業日に縛られる。施設の集客力に運命を握られる |

**すかいらーくが都市部を取りにいくのに、ガストではなく
「しんぱち食堂」を110億円で買った理由**がここにある。
しんぱちは都心の狭小立地で高い坪効率を出す業態であり、
**ガストの設計（広い席・長い滞在）では都心の坪家賃を払えない**。
つまり都市部への進出は「既存ブランドの出店」ではなく
**「都市型の坪効率を持つ業態の獲得」**として実行された。

```
【立地別に、必要な坪売上がどう変わるか】

  坪家賃 0.8万円（郊外）  → 必要月坪売上  8万円 → ファミレス標準型で足りる ○
  坪家賃 1.5万円（モール）→ 必要月坪売上 15万円 → 小型・高回転業態が要る   △
  坪家賃 3.0万円（駅前）  → 必要月坪売上 30万円 → 専門・高回転業態のみ     ✗→○
                                                （しんぱち食堂・餃子の王将など）

  ※必要月坪売上 = 坪家賃 ÷ 家賃比率10%
```

## 6. 業態の縮小と、転換先としての焼肉・回転寿司・うどん

ファミレスというカテゴリー自体は縮小している。

- 帝国データバンクの調査（2022年8月発表）では、ファミレス運営主要16社の店舗数が
  2022年6月期時点で**8,420店**、コロナ前（2019年12月期）比で**約810店・約9%減**。
  同調査は当該年度末に**コロナ前比で累計1,000店超の減少**を見込むとしていた
- 同調査では、ファミレス非専業8社の業態構成比で
  **ファストフード+1.2ポイント、カフェ+0.9ポイント、焼肉+0.4ポイント**が増え、
  居酒屋が▲1.1ポイント減っていた
- 2026年時点の店舗数ランキング（日本ソフト販売の集計）でも、ガスト▲11店（▲0.9%）、
  デニーズ▲3店（▲0.9%）、ジョナサン▲9店（**▲5.4%**）と、
  **総合型ファミレスに増えているブランドがない**状況が続いていると報じられる

| 転換先                                     | なぜ選ばれるか                                                                           | 代表例                           |
| ------------------------------------------ | ---------------------------------------------------------------------------------------- | -------------------------------- |
| **うどん・定食**                           | 客単価は低いが**回転が速く、深夜人員が要らない**。原価率も安定                           | 資さんうどん、しんぱち食堂       |
| **[焼肉](../18_焼肉・ラーメン/README.md)** | 客単価が高く**ドリンク併売率が高い**。無煙ロースター設置で厨房人員を減らせる（客が焼く） | 焼肉ライク、牛角、各社の焼肉業態 |
| **[回転寿司](../17_回転寿司/README.md)**   | レーンとタッチパネルで**L（人件費）が最も削られた業態**。家族需要をそのまま受け継げる    | はま寿司、スシロー、くら寿司     |
| **[カフェ](../19_カフェ/README.md)**       | アイドルタイムに強く、**調理が軽い**。小型で出せる                                       | むさしの森珈琲、各社のカフェ業態 |

> ポイント：**転換先に共通するのは「客が作業を肩代わりする」か「調理が軽い」か**。
> 焼肉は客が焼き、回転寿司はレーンが運び、うどんはセルフで受け取る。
> ファミレスの弱点だったL（人件費）を、業態そのもので下げにいっている。
