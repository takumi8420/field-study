## このフォルダの読み方

ファミリーレストラン（ファミレス）は **「家族4人の食事を1店で完結させる」ために設計された外食業態**である。
そのために席を広く取り（1席1.5〜2.0㎡）、長く座らせ（滞在50〜70分）、
好みのばらつきを吸収するためメニューを100〜200品まで増やした。
この3つの選択の結果、**面積あたりの売上（坪効率）が外食の中でも構造的に低くなる**。

それでも成立してきたのは、**坪家賃の安い郊外ロードサイドに出て家賃比率を6〜10%に抑え、
セントラルキッチンで店の人件費を工場に付け替えてきた**から。
つまりファミレスは「坪効率が低い業態」ではなく
**「坪効率が低いことを前提に、安い土地と自社工場で成り立たせた業態」**である。

そしていま、その前提（安い土地・安い人手・安い原材料）がすべて崩れている。
各社の答えは**省力化（配膳ロボット・タッチパネル）で守り、業態転換で攻める**こと。
すかいらーくが2025年12月期に新規出店77店に対して**業態転換を36店**行ったのは、
建物と駐車場を残したまま看板を替える方が、新しく建てるより速くて安いからである。

**FLコスト・回転率・坪売上・既存店前年比といった外食の共通言語は、
[外食1店舗の経済（ファストフード①）](../14_ファストフード/01_外食1店舗の経済.md) で定義済み。
本フォルダは重複を避け、ファミレス固有の事情だけを扱う。**

## 1. 業界の定義・範囲

**ファミリーレストラン＝家族連れを主対象とし、テーブルサービスで幅広いメニューを
中価格帯で提供する外食業態**。日本フードサービス協会の業態分類では
「ファミリーレストラン」として集計され、洋風・和風・中華・焼肉に細分される。

隣接業態との境界は、**滞在時間・客単価・サービス方式・メニュー幅**で引く。

| 業態                                             | 客単価                     | 滞在時間     | サービス方式         | メニュー品目数      |
| ------------------------------------------------ | -------------------------- | ------------ | -------------------- | ------------------- |
| **ファミリーレストラン**                         | 1,000〜1,500円             | **50〜70分** | **テーブルサービス** | **100〜200品**      |
| [ファストフード](../14_ファストフード/README.md) | 500〜1,100円               | 10〜25分     | カウンター／セルフ   | 20〜40品            |
| [回転寿司](../17_回転寿司/README.md)             | 1,200〜1,800円             | 40〜60分     | レーン／タッチパネル | 100品前後           |
| [居酒屋](../16_居酒屋/README.md)                 | 3,000〜4,000円             | 120分前後    | テーブルサービス     | 100品前後（酒が主） |
| [カフェ](../19_カフェ/README.md)                 | 500〜900円                 | 30〜60分     | カウンター           | 30〜60品            |
| [焼肉・ラーメン](../18_焼肉・ラーメン/README.md) | 焼肉3,000円／ラーメン900円 | 60分／20分   | テーブル／カウンター | 単品特化            |

境界が曖昧なのは次の3つ。

- **サイゼリヤ**：統計上はファミレスだが、客単価870円（2026年8月期3Q累計・連結）は
  ファストフード級。本フォルダでは[②](02_業態の分化と再編.md)で主要プレイヤーとして扱う
- **餃子の王将**：中華単品特化でファミレス統計に入らないこともあるが、
  ロードサイドの家族需要では完全な競合
- **しゃぶ葉・資さんうどん・しんぱち食堂**：ファミレス企業が運営する非ファミレス業態。
  **統計上はファミレスから抜けるが、経営としては同じ箱の運用**である（→[②](02_業態の分化と再編.md)）

## 2. 市場規模と成長性

| 指標                             | 数値                                                                                                      | 年・出典                                                     |
| -------------------------------- | --------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| 外食産業市場規模（日本・全業態） | 約24兆1,512億円（前年比+20.2%）                                                                           | 2023年・日本フードサービス協会／食の安全・安心財団の共同推計 |
| 外食売上（全業態・全店ベース）   | 2025年12月に前年同月比**+6.0%**。低価格業態であるFFとファミレスが下支え                                   | 2026年1月・日本フードサービス協会 月次調査                   |
| ファミレス運営主要16社の店舗数   | 2022年6月期 **8,420店**（2019年12月期比で約810店・**約9%減**）                                            | 2022年8月・帝国データバンク                                  |
| ファミレス主要ブランドの増減     | ガスト▲11店（▲0.9%）、デニーズ▲3店、**ジョナサン▲9店（▲5.4%）**。力強く増えているファミレスチェーンがない | 2026年・日本ソフト販売の集計（民間調査）                     |

成長性の読み方は3点。

- **名目の売上は伸びているが、伸びているのは単価であって回数ではない**。
  人口減で食事回数は増えない。市場統計のプラスの多くは値上げの反映
- **カテゴリーとしては縮小、企業としては成長**という分裂が起きている。
  ファミレスの看板は減り、しゃぶ葉・うどん・定食・カフェが増えている
- **成長の出口は業態転換とM&A**。すかいらーくは資さんうどんを2030年に400店、
  しんぱち食堂を2030年に300店へ拡大する計画を示している（報道ベース）

## 5. 収益モデル・コスト構造

**店舗の損益**（売上100とした比率。指標の定義は
[外食1店舗の経済](../14_ファストフード/01_外食1店舗の経済.md)、詳細は[①](01_ファミレスの経済.md)）

| 項目         | ファミレスの水準        | ファストフードとの差 | 理由                                                          |
| ------------ | ----------------------- | -------------------- | ------------------------------------------------------------- |
| F：食材費    | **30〜35%**             | +2〜3pt              | 品目数100〜200でロスが出やすい。ドリンクバーが下押し          |
| L：人件費    | **30〜35%**             | +2〜3pt              | テーブルサービス（注文・配膳・下げ・清掃）                    |
| **FL合計**   | **62〜68%に振れやすい** | **重い**             | 60%の目安を超えやすく、**省力化投資が最も進んだ業態**になった |
| R：家賃      | **6〜10%**              | ▲3〜4pt              | 郊外の安い土地。**ここだけが有利**                            |
| 水道光熱費   | 6〜9%                   | +1〜2pt              | 面積が広く空調負荷が大きい。長時間営業                        |
| 減価償却費   | 4〜6%                   | +1pt                 | 建物ごと建てるため投資額が大きい                              |
| **営業利益** | **3〜7%**               | 薄い                 | —                                                             |

```
【ファミレスの利益がどこで消えるか（売上100とした比率）】

  売上 100
   ├─ F 食材費 …… 30〜35  ← 品目100〜200でロスが出る／ドリンクバーが下押し
   ├─ L 人件費 …… 30〜35  ← テーブルサービス。省力化の主戦場
   │                 …………… FL = 62〜68（★60%の目安を超えやすい★）
   ├─ R 家賃 ……… 6〜10   ← 郊外の安い土地。ここだけが有利
   ├─ 水道光熱 …… 6〜9    ← 広い面積＋長時間営業
   ├─ 減価償却 …… 4〜6    ← 建物ごと建てるため重い
   ├─ 販促・その他 8〜12
   ▼
  営業利益 …… 3〜7

  → ★家賃で得た3〜4ポイントの余裕を、FとLで使い果たす★のがこの業態。
```

- **月坪売上は10万〜18万円**。牛丼チェーン（20万〜30万円）の半分程度
- **初期投資は郊外ロードサイド1店で2.0億〜3.0億円**、賃貸借契約は20年が一般的。
  ファストフードの「3〜5年で回収」より長期の設計になる
- **本部側にはセントラルキッチンと自社物流という固定費がある**。
  店舗数が減ると1食あたり製造原価が上がるため、**閉店より業態転換が選ばれる**

## 6. 競争要因（KSF）と参入障壁

| KSF                                    | なぜ効くか                                                                      |
| -------------------------------------- | ------------------------------------------------------------------------------- |
| **郊外の好立地を先に押さえること**     | 月坪売上12万円の業態は坪家賃1.2万円までしか払えない。幹線道路沿いの好区画は有限 |
| **セントラルキッチンと自社物流の規模** | ここが効率化の本体。数百店規模がないと工場が回らない                            |
| **業態のポートフォリオ**               | 需要が落ちたブランドを、需要のある業態へ衣替えできるか。**箱の運用力**          |
| **省力化の実装度**                     | FLが構造的に重い業態なので、配膳ロボット・タッチパネルの効果が最も大きい        |
| **価格帯の設計**                       | 価格弾力性が高く、値上げが客数を直撃する。値上げと価値提供のバランス            |
| **ブランドの信頼（ファミリー層）**     | 家族で行く店は「失敗したくない」需要。安心が選ばれる理由になる                  |

**参入障壁**は外食の中でも高い部類。

- **1店だけでは成立しない**。CK・物流・購買力が効くのは数百店規模から
- **2〜3億円の初期投資と20年契約**が、1店あたりの失敗コストを大きくする
- **既存大手が好立地を押さえ済み**。新規参入は残り物の立地から始めることになる
- 逆に言えば、**大手自身も新規出店より業態転換を選ぶ**ため、市場の入替えは内部で起きる

## 7. 規制・法制度

| 分野                                   | 内容                                                                                                                                 |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| **食品衛生法**                         | 飲食店営業許可（保健所）。2021年6月からHACCPに沿った衛生管理が全事業者に義務化。**セントラルキッチンは食品製造業としての許可も必要** |
| **食品表示法／景品表示法**             | アレルゲン表示、原産地表示、優良誤認・有利誤認。メニュー数が多いほど管理負荷が大きい                                                 |
| **労働基準法**                         | **深夜割増（22時〜翌5時に25%以上）**。深夜営業の採算を直接決める                                                                     |
| **最低賃金法**                         | 2025年度は全国加重平均 **1,121円（+66円）**。外食最大のコスト変数                                                                    |
| **入管法（特定技能）**                 | 特定技能1号「外食業」は分野別上限5万人に到達し**2026年4月13日から新規受入を当面停止**。技能実習は2027年4月に育成就労へ移行予定       |
| **消費税（軽減税率）**                 | 店内飲食10%／テイクアウト8%。同一商品で税率が分かれるため価格表示の設計が必要                                                        |
| **都市計画法・建築基準法・駐車場条例** | 郊外ロードサイド店は用途地域と駐車場台数の規制を受ける。**出店可否を法規が決める**                                                   |
| **支援策**                             | 中小企業省力化投資補助金（配膳ロボット等、上限1億円・補助率最大2/3）、農水省・厚労省「省力化投資促進プラン（飲食業）」（2025年6月）  |

  配膳ロボットと卓上タブレットによる省人化が人件費上昇を吸収したと報じられる

  垂直統合でも原材料高と賃料高を吸収しきれなくなったという象徴的な出来事
- **業態転換とM&Aが成長の柱に**。資さんうどんを2030年に約400店（約4倍）、
  しんぱち食堂を約110億円で買収し2030年に約300店へ
- **コスト三重苦**。コメ高・チキンショック・容器高が重なり、外食企業の約6割が2026年度に値上げ
- **カテゴリーは縮小継続**。ガスト▲0.9%、ジョナサン▲5.4%など、増えているファミレスチェーンがない

## 9. 用語メモ

本フォルダは各ノート末尾に用語メモを置いている（独立した用語集は作っていない）。
外食共通の用語（FL比率、回転率、坪売上、既存店前年比、直営／FC）は
[外食1店舗の経済](../14_ファストフード/01_外食1店舗の経済.md) を参照。

| 用語                           | 意味                                                                                                            |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------- |
| **坪効率（月坪売上）**         | 月商 ÷ 店舗面積（坪）。ファミレスは10万〜18万円と低い → [①](01_ファミレスの経済.md)                             |
| **ドリンクバー**               | 定額飲み放題のセルフ式ドリンク。原価率10〜20%で粗利を厚くするが、滞在時間を延ばす → [①](01_ファミレスの経済.md) |
| **セントラルキッチン（CK）**   | 複数店舗分の仕込みを行う自社工場。店のLを本部の固定費に付け替える → [①](01_ファミレスの経済.md)                 |
| **業態転換（コンバージョン）** | 建物を残したまま看板と内装を替えること。投資は新規出店の1/4〜1/8 → [②](02_業態の分化と再編.md)                  |
| **マルチブランド戦略**         | 表のブランドは分け、裏の工場・物流・購買は共通にする戦い方 → [②](02_業態の分化と再編.md)                        |
| **垂直統合**                   | 原料生産から製造・物流・店舗までを自社で持つこと。サイゼリヤの低価格の源泉 → [②](02_業態の分化と再編.md)        |
| **価格弾力性**                 | 値上げしたときに客数がどれだけ減るか。ファミレスは代替が多く高い → [③](03_収益改善の打ち手.md)                  |
| **配膳ロボット**               | 料理を客席へ運ぶ自律走行台車。すかいらーくは2022年12月時点で約2,100店・約3,000台 → [③](03_収益改善の打ち手.md)  |
| **人時売上高**                 | 売上 ÷ 総労働時間。省力化投資の効果を測る指標 → [③](03_収益改善の打ち手.md)                                     |
| **深夜割増**                   | 22時〜翌5時の労働への25%以上の割増賃金。深夜営業の損益分岐を決める → [①](01_ファミレスの経済.md)                |
