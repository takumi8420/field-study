# 水産業の全体像 ― 獲る・育てる・売るは別の商売

このノートで分かること：**「水産業」とひとことで言うが、獲る（漁業）・育てる（養殖）・売る（加工/流通）は
経済の仕組みがまったく違う3つの産業**である。その違いと、日本の漁獲量がなぜ40年で3分の1以下になったのか、
そして獲る量を国が決める TAC・IQ という仕組みを押さえる。

## 1. 水産業は3層に分かれている

まず頭に入れるべきは、この3層が**別々の損益構造を持つ**ことである。
同じ「魚」を扱っていても、儲け方も、リスクの種類も、必要な資本もまったく違う。

```
 【1層目】獲る              【2層目】育てる            【3層目】売る・加工する
 ─────────────────────────────────────────────────────────────
  漁業（天然）               養殖業                    加工・流通
   ・元手 = 船と漁業権         ・元手 = 生け簀と稚魚      ・元手 = 工場と在庫
   ・変動費 = 燃料・人件費     ・変動費 = 餌（原価の6〜7割）・変動費 = 原料魚
   ・売上 = 獲れた量 × 相場    ・売上 = 出荷量 × 相場      ・売上 = 製品値決め
   ・最大リスク = 資源と天候   ・最大リスク = 餌代と斃死    ・最大リスク = 原料確保
   ・在庫は持てない            ・在庫＝生きた魚（売り急げない）・在庫は冷凍で持てる
       │                           │                          │
       └──── 産地市場 ─────────────┴──── 消費地市場 ──────────┘
                                                               │
                                                        小売・外食・輸出
```

> ポイント：**漁業は「相場ビジネス」、養殖は「飼育コストのビジネス」、加工・流通は「値決めと在庫のビジネス」**。
> 大手水産企業（Umios＝旧マルハニチロ、ニッスイ、極洋）の利益の大半が3層目から出ているのは、
> 1層目・2層目の利益が天候と餌代に振り回されるからである → [大手水産企業の商売](03_大手水産企業の商売.md)

| 層 | 誰がやっているか | 経営体の規模感 | 利益の源泉 | 効く外部要因 |
| --- | --- | --- | --- | --- |
| 漁業 | 個人・家族経営が大多数。沖合・遠洋は企業 | 沿岸は1〜数隻。遠洋は1隻数十億円 | 相場が高い魚を量獲ること | 資源量、海水温、燃料価格、漁獲枠 |
| 養殖 | 個人経営＋近年は企業・異業種参入 | 1経営体で年数億円規模が多い | 出荷単価 − 餌代 | 魚粉価格、水温、需要（輸出含む） |
| 加工・流通 | 中小加工場から大手食品会社まで | 幅が極端に広い | 加工賃＋ブランド＋在庫益 | 原料価格、為替、人手 |

## 2. 日本の漁獲量はなぜ3分の1以下になったのか

日本の漁業・養殖業生産量は**1984年の1,282万トンがピークで、2022年には392万トン**と、
ピーク比で3分の1以下になった（水産庁 水産白書）。
直近も下げ止まっていない。2025年の**海面漁業は270万500トン（前年比3.1%減）で、2019年から7年連続の減少**。
一方で**海面養殖業は83万1,900トン（同3.6%増）と5年ぶりに増加**した
（農林水産省「2025年漁業・養殖業生産統計」、2026年5月29日公表）。

減少の原因は1つではなく、時期によって主役が入れ替わっている。

```
 1970年代後半 ─── 200海里体制の確立
   └ 各国が沿岸200海里を排他的経済水域（EEZ）に。日本の遠洋漁業が他国の海から締め出される
      ▼ 遠洋漁業が激減（ピーク約400万トン → 現在30万トン台）

 1990年前後 ───── マイワシ資源の自然崩壊
   └ 1980年代に年400万トン超獲れたマイワシが数十万トンへ。海洋環境の数十年周期の変動が主因とされる
      ▼ 沖合漁業が半減

 2000年代〜 ───── 沿岸資源の減少＋担い手の減少
   └ 獲りすぎと環境変化の複合。加えて漁業者が高齢化して辞めていく
      ▼ 沿岸漁業がじわじわ縮小

 2010年代後半〜 ─ 海洋環境の急変
   └ サンマ・スルメイカ・サケの記録的不漁。海水温上昇で魚の分布が北・沖へ移動
      ▼ 特定魚種の壊滅的不漁が常態化
```

つまり**「資源が減った」と「獲る人が減った」が同時に進んだ**。
注意すべきは、この2つは原因と結果が絡んでいることである。
資源が減る → 獲れない → 儲からない → 辞める → 船が減る、という順番もあれば、
魚価が安い → たくさん獲らないと食べていけない → 小さい魚まで獲る → 資源が減る、という逆回りもある。
日本の資源管理改革は、この**後者の悪循環を制度で断ち切ろうとする試み**である。

### 担い手の数字

| 指標 | 数値 | 時点・出典 |
| --- | --- | --- |
| 漁業就業者数 | **12万1千人** | 2023年・農林水産省 漁業構造動態調査 |
| 同（20年前） | 23万8千人 | 2003年・同上 |
| 40歳未満の割合 | 17.8% | 2023年・同上 |
| 平均年齢 | 57.1歳 | 2023年・同上 |
| 新規漁業就業者数 | 1,691人（前年度比3%減） | 2022年度・水産庁 |

**20年で半減**している。しかも平均年齢57歳ということは、今後10〜15年でもう一段減る。
「魚が減った」以上に、**「魚を獲る人がいなくなる」ほうが先に効いてくる**という見方が業界では強い。

## 3. 漁業は「どこで獲るか」で3つに分かれる

漁業は操業する海域と航海日数で、遠洋・沖合・沿岸に分類される。
**これは単なる分類ではなく、必要な資本も規制も経営体の性格も違う**。

| 区分 | 操業海域 | 船の規模 | 航海日数 | 主な魚種 | 経営の性格 |
| --- | --- | --- | --- | --- | --- |
| **遠洋漁業** | 他国のEEZや公海。太平洋・大西洋・インド洋 | 数百〜数千トン級 | 数か月〜1年 | カツオ・マグロ、海外まき網、イカ | 大型設備投資。企業経営。国際交渉が生命線 |
| **沖合漁業** | 日本のEEZ内の沖合 | 数十〜数百トン級 | 数日〜数週間 | サバ、イワシ、サンマ、スケトウダラ、イカ | 大臣許可漁業が中心。中堅企業〜協業体 |
| **沿岸漁業** | 岸から見える範囲〜数十km | 10トン未満が大半 | 日帰り | 多魚種（イカ、タイ、ヒラメ、貝、海藻） | 個人・家族経営。漁業権に依存 |

生産量で見ると、現在は**沖合漁業が最大、次いで沿岸、遠洋は最小**という順序になっている。
遠洋漁業は1970年代の200海里体制で構造的に縮小しており、もはや主役ではない。

```
     1970年代                          現在（2020年代）
  ┌──────────────┐                 ┌──────────────┐
  │ 遠洋  ████████ │ 約400万t        │ 遠洋  █        │ 30万t台
  │ 沖合  ███████  │                 │ 沖合  ████     │ 最大だが半減以下
  │ 沿岸  ████     │                 │ 沿岸  ███      │ 微減が続く
  │ 養殖  ██       │                 │ 養殖  ██       │ ほぼ横ばい 83万t（2025年）
  └──────────────┘                 └──────────────┘
   合計 1,000万t超                    合計 約390万t
```

## 4. 誰がどこで獲っていいかは「許可」と「権利」で決まる

海は誰のものでもないが、**日本では漁業は許可制・権利制**であり、自由に参入できない。
ここが「参入障壁は制度そのもの」という水産業の特徴である。

| 制度 | 誰が与えるか | 対象 | 内容 |
| --- | --- | --- | --- |
| **大臣許可漁業** | 農林水産大臣 | 沖合・遠洋の大型漁業（沖合底びき網、大中型まき網、遠洋かつお・まぐろなど） | 船ごとに許可。隻数・トン数に上限 |
| **知事許可漁業** | 都道府県知事 | 中小規模の漁業 | 都道府県ごとに運用 |
| **漁業権** | 都道府県知事が免許 | 定置網、区画（養殖）、共同（沿岸の採貝採藻など） | 特定の海面を排他的に使う権利 |
| **自由漁業** | 不要 | 一部の釣りなど | 限定的 |

**漁業権のうち「共同漁業権」は原則として漁業協同組合（漁協）に免許される**。
漁協は組合員に行使を割り振るので、**実務上、地元の漁協に入らないと沿岸で漁ができない**。
これが「水産業は新規参入が難しい」と言われる最大の理由である。

2018年成立・2020年12月施行の**改正漁業法（70年ぶりの大改正）**では、
養殖用の区画漁業権について「地元漁協優先」の原則が見直され、
**適切に活用されていない水面には企業などが参入しやすくなった**。
企業の養殖参入が2020年代に増えた制度的な背景がこれである → [養殖と輸入](02_養殖と輸入.md)

## 5. 資源管理：TAC と IQ

### TAC（漁獲可能量）とは

**TAC＝Total Allowable Catch。「この魚は今年、日本全体で◯万トンまでしか獲ってはいけない」という上限**。
科学者が資源量を推定し、「これだけ獲っても資源が持続する」水準から逆算して国が決める。
日本では1997年のTAC法で導入された。

TACを決める土台になるのが **MSY（最大持続生産量）** という考え方である。
**資源を減らさずに毎年獲り続けられる最大の量**を意味し、改正漁業法でこのMSYベースの管理が法律上の原則になった。
それ以前は「過去にこれくらい獲れていたから」という実績ベースの色が濃かった。

### IQ（個別割当）とは

TACだけだと**「早い者勝ち」**になる。全体の枠が決まっているので、他の船に獲られる前に
急いで獲りに行くほうが得になり、結果として**漁期が短くなり、小さい魚まで獲り、単価の安い時期に集中出荷**される。
これを「オリンピック方式」と呼ぶ。

**IQ＝Individual Quota。TACを船ごと・経営体ごとにあらかじめ配分する仕組み**。
自分の枠が確保されているので、急ぐ必要がない。

```
 【オリンピック方式（TACのみ）】        【IQ方式】
  解禁！ → 全船が一斉出漁               各船に「あなたは◯トン」と配分
    │                                     │
    ├ 小さい魚でも獲る（獲らないと損）    ├ 大きくなるまで待てる
    ├ 短期間に大量入荷 → 魚価暴落        ├ 高い時期に出せる → 単価が上がる
    ├ 枠に達すると突然禁漁 → 稼働ムラ    ├ 年間の操業計画が立つ
    └ 危険な天候でも出漁しがち            └ 無理をしない
                                            ↓
                                          燃料費も人件費も下がり、
                                          同じ漁獲量でも利益が増える
```

> ポイント：**IQの効果は「資源が守られる」だけではない。単価が上がりコストが下がるので、漁業者が儲かる**。
> ノルウェーやアイスランドが少ない漁獲量で高い漁業所得を実現しているのは、この個別割当を徹底しているからだとされる。

改正漁業法は**TAC対象魚種の拡大**を進めており、2024年からマダラ、2025年からカタクチイワシとブリが追加された。
**漁獲量ベースで8割をTAC管理下に置く**ことが政策目標とされている（水産庁 資源管理ロードマップ）。
2026年3月には新たなロードマップが示されている。
ただし現場では「枠が実態に合わない」「沿岸の小規模漁業者に配分が回らない」という反発も根強く、
**制度としては前進しているが、合意形成のコストが極めて高い**というのが実情である。

## 6. 魚の値段はどこで決まるか ― 二段階の市場

野菜や肉と比べたときの水産物の最大の特徴は、**価格が2回決まる**ことである。

```
 漁船 ──▶【産地市場】──▶ 産地仲買・加工業者 ──▶【消費地市場】──▶ 仲卸 ──▶ 小売/外食
          (港のセリ)                              (豊洲など)       (小分け・目利き)
            ①                                        ②               ③
   生産者手取     産地市場価格            消費地市場価格   仲卸価格    小売価格
   ①─────────②────────────────────────③─────────④──────────⑤
                    ※市場流通では計5回の価格形成が行われるとされる（水産庁資料）

 【別ルート】産地直送・商社買付・輸入
   漁協/養殖業者 ──────────────────▶ 量販店・外食チェーン・輸出
                （市場を通さない相対取引。数量と価格を事前に決める）
```

**セリ**は買い手が競り上げて最高値の人が買う方式、**相対（あいたい）取引**は売り手と買い手が
事前に交渉して価格と数量を決める方式である。かつては市場＝セリだったが、
**量販店が大量・安定・定価での仕入れを求めるようになった結果、相対取引の比率が上がっている**。

この構造が水産物の価格に2つの性質を与える。

1. **振れが大きい**。天候・漁獲の増減がそのままセリ値に出る。豊漁だと暴落する
2. **中間が多く、生産者の手取りが薄くなりやすい**。段階ごとに手数料と経費が乗る

だから養殖業者や産地は**市場を飛ばして量販店・外食と直接契約したがる**し、
量販店も**産直で安定調達したがる**。市場流通の比率は長期的に下がっている。
→ [食品スーパー](../../07_小売・流通/03_食品スーパー/README.md)、[食品卸](../../06_商社・卸売/06_食品卸/README.md)

## 7. 日本人は魚を食べなくなった

供給側だけでなく、需要側も縮んでいる。

| 指標 | 数値 | 時点・出典 |
| --- | --- | --- |
| 食用魚介類の1人1年当たり消費量 | **21.4kg**（概算値） | 2023年度・農水省 食料需給表 |
| 同（ピーク時） | 40.2kg | 2001年度・同上 |
| 肉類との逆転 | 2011年度以降、魚介類が肉類を下回る | 水産庁 水産白書 |
| 1世帯当たり生鮮魚介類の年間購入量 | 18.1kg（前年比2%減） | 2024年・総務省 家計調査 |
| 同 年間支出金額 | 4.06万円（前年比1%減） | 2024年・同上 |

**20年強で消費量がほぼ半減**している。理由としてよく挙げられるのは、
調理の手間（骨・内臓・におい）、価格の上昇、肉の相対的な安さと簡便さ、
そして**「売場に魚を扱える人がいない」という供給側の事情**である。

魚価が上がると購入量が減る傾向が肉や野菜より強く、
2024年調査では「購入頻度や量が減った」と答えた人が魚で約18%（肉13%、野菜8%）だった（水産庁）。
**国内市場は数量ベースで縮み続ける前提**で、業界は輸出と加工に活路を求めている。

## 8. この業界を読むときの3つの視点

1. **どの層の話をしているか常に確認する**。「水産大手が最高益」は加工・海外の話であって、
   「漁業が好調」ではない。3層は連動しない
2. **量ではなく単価で見る**。漁獲量は減り続けているが、生産額は単価上昇でそこまで落ちていない。
   輸出も「量は減ったが額は増えた」という現象が起きる
3. **制度が経済を決める**。漁業権・許可・TAC・IQ・輸出施設登録。
   この業界は**規制が参入障壁であり、同時に収益性の決定要因**でもある

## 9. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **TAC（漁獲可能量）** | Total Allowable Catch。魚種ごとに「日本全体で年間◯トンまで」と国が決める漁獲上限。1997年のTAC法で導入 |
| **IQ（個別割当）** | Individual Quota。TACを船・経営体ごとに事前配分する仕組み。早獲り競争をなくし、単価上昇とコスト低下をもたらす |
| **ITQ** | Individual Transferable Quota。IQの枠を他者に譲渡・売買できるようにしたもの。日本は未導入 |
| **MSY（最大持続生産量）** | 資源を減らさずに毎年獲り続けられる最大量。改正漁業法でTAC算定の原則になった |
| **EEZ（排他的経済水域）** | 沿岸から200海里（約370km）の範囲で、沿岸国が水産資源を管理する権利を持つ海域 |
| **漁業権** | 特定の海面を排他的に利用する権利。都道府県知事が免許。定置・区画（養殖）・共同の3種 |
| **共同漁業権** | 沿岸の採貝採藻などの漁業権。原則として漁協に免許され、組合員が行使する |
| **漁協（漁業協同組合）** | 漁業者の協同組合。漁業権の管理、産地市場の開設、燃料・資材の供給、販売、金融まで担う |
| **産地市場／消費地市場** | 水揚げ港にある市場／豊洲など大消費地にある市場。水産物は両方で価格が決まる「二段階価格形成」 |
| **セリ／相対取引** | 競り上げて最高値が落札する方式／売買当事者が交渉で価格・数量を決める方式。量販店の増加で相対が拡大 |
| **仲卸** | 消費地市場で卸売業者から買い、小売・外食向けに小分け・目利きして売る業者 |
| **オリンピック方式** | TACだけがあってIQがない状態。枠の取り合いになり早獲り競争が起きる |
| **遠洋／沖合／沿岸漁業** | 他国EEZ・公海／日本のEEZ内の沖合／岸近く。資本規模も規制も経営体の性格も異なる |
| **改正漁業法** | 2018年成立・2020年12月施行。70年ぶりの大改正。MSYベースの資源管理、TAC・IQ拡大、養殖への企業参入促進 |
