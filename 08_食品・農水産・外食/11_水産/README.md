# 水産

- 大分類: 食品・農水産・外食
- 状態: done
- 更新日: 2026-09-20

**「水産業」はひとつの業界ではなく、獲る（漁業）・育てる（養殖）・売る（加工と流通）という
経済の仕組みがまったく違う3層の集合体**である。日本の生産量は1984年の1,282万トンをピークに
2025年には海面漁業270万トン＋海面養殖83万トンまで縮み、国内消費も20年強でほぼ半減した。
一方で輸出額は過去最高、そして大手3社は食品会社として最高益圏にある。
**この「縮む現場」と「伸びる数字」の同居を説明できることが、この業界を理解したということ**になる。

## 1. 業界の定義・範囲

水産業とは、**水生生物（魚・貝・甲殻類・海藻など）を獲り、育て、加工し、流通させる産業の総称**である。
統計上は次のように分かれ、それぞれ別の産業として扱われる。

| 区分 | 中身 | 経済の性格 |
| --- | --- | --- |
| **漁業（海面・内水面）** | 天然の水産物を獲る | 相場ビジネス。在庫を持てない |
| **養殖業（海面・内水面）** | 稚魚・稚貝から育てて出荷する | 飼育コストのビジネス。餌代が利益を決める |
| **水産加工業** | すり身、冷凍食品、缶詰、干物、練り製品 | 値決めビジネス。相場から半歩離れられる |
| **水産流通** | 産地市場、消費地市場、仲卸、水産商社 | 口銭・在庫・為替リスクの引受 |

隣接業界との境界は次の通り。

| 業界 | 違い | 参照 |
| --- | --- | --- |
| **農業** | 土地に紐づく。日本では水産と農業で法体系が別（漁業法／農地法） | [農業・種苗・肥料](../12_農業・種苗・肥料/README.md) |
| **畜産・飼料** | 陸上の動物を育てる。**魚粉という飼料原料を水産と共有する** | [畜産・飼料](../13_畜産・飼料/README.md) |
| **冷凍食品・惣菜** | 水産大手の主力製品が置かれる市場そのもの | [冷凍食品・惣菜](../06_冷凍食品・惣菜/README.md) |
| **食品卸・総合商社** | 水産商事と機能が重なる。競合でもあり協業先でもある | [食品卸](../../06_商社・卸売/06_食品卸/README.md) |
| **回転寿司・外食** | 水産物の最大の出口のひとつ | [回転寿司](../17_回転寿司/README.md) |
| **海運・港湾** | 漁船は海運ではない。ただし冷凍物流では重なる | [海運](../../13_運輸・物流/04_海運/README.md) |

**成長性は「金額は伸びるが数量は伸びない」**と読むのが正確である。
輸出額も輸入額も過去最高圏にあるが、それは単価上昇と円安の結果であって、
量は国内生産・国内消費ともに減り続けている。
**国内市場は数量ベースで縮む前提**で、業界は輸出・加工・養殖に活路を求めている。

## 3. バリューチェーン（川上 → 川下）

```
 【川上】生産                【中間】流通・加工                 【川下】出口
 ──────────────────────────────────────────────────────────────────
  漁船（遠洋/沖合/沿岸）─┬─▶【産地市場】─┬─▶ 産地仲買・産地加工 ─┐
        ↑ 漁業権・許可    │   （港のセリ） │                        │
        ↑ TAC・IQ         │                └─▶ 冷凍・保管 ─────────┤
                          │                                         ▼
  養殖業者 ───────────────┤                              【消費地市場】（豊洲等）
        ↑ 区画漁業権      │                                 卸売業者 → 仲卸
        ↑ 種苗・配合飼料  │                                         │
        ↑ 魚粉（輸入）    │                                         ▼
                          │                                   小売・外食・給食
  海外の漁業/養殖 ────────┴─▶ 水産商社・大手水産（買付/在庫/為替）─┤
        （輸入＝金額で国内生産を上回る）                             │
                                                                     ├─▶ 食品スーパー
  水産加工メーカー ──────────▶ 冷凍食品・缶詰・すり身製品 ─────────┤   回転寿司・外食
                                                                     └─▶ 輸出（米・香港・台湾）

  ※市場流通では ①生産者手取 ②産地市場価格 ③消費地市場価格 ④仲卸価格 ⑤小売価格 と
    計5回の価格形成が行われる（水産庁資料）。近年は市場を通さない相対・産直が増えている
```

付加価値がどこに残るかを見ると、業界の性格が分かる。

| 工程 | 付加価値 | 誰が取るか |
| --- | --- | --- |
| 漁業（獲る） | **低〜中** | 漁業者。相場に完全に従属し、価格決定力がない |
| 養殖（育てる） | 中 | 養殖業者。ただし餌代（原価の6〜7割）に利益を削られる |
| 産地加工 | 中 | 地場の加工業者。人手不足で稼働率が上がらない例が多い |
| 商社機能（買付・在庫・為替） | 中 | 水産大手・商社。利益率は低いが規模で稼ぐ |
| **加工食品（すり身・冷食・缶詰）** | **高** | **食品メーカー**。相場を値決めに変換できる唯一の工程 |
| 小売・外食 | 中〜高 | 量販店・外食。ただし鮮魚は技術者不足で縮小傾向 |

> ポイント：**この業界で最も価格決定力がないのは、魚を獲る人**である。
> 大手水産企業が加工と海外に重心を移したのは、企業文化の変化ではなく**利益が安定する場所へ動いた結果**である。

## 4. 主要プレイヤーとシェア

水産物の「シェア」は魚種・海域・チャネルごとに分かれ、全国シェアという概念が成立しにくい。
ここでは上場している大手3社の2026年3月期の数字を並べる。

| 企業 | 売上高（2026年3月期） | 営業利益 | 立ち位置・特徴 |
| --- | --- | --- | --- |
| **Umios（旧マルハニチロ）** | 1兆800億円（会社計画） | 300億円（同） | 業界最大手。**2026年3月1日付で社名を「Umios株式会社」に変更**。水産資源／水産商事／食品／畜産／保管物流。第3四半期累計の営業利益293.77億円は同期間で過去最高。欧州の寿司用ホタテ、オランダの加工会社買収、タイのペットフードが寄与 |
| **ニッスイ** | **9,312.65億円**（前期比5.1%増） | **404.30億円**（同27.2%増） | **売上・各段階利益とも過去最高、営業利益は初の400億円超**。水産／食品／ファインケミカル／物流。魚油由来のEPA原薬など高収益事業を持つ |
| **極洋** | **3,346.12億円**（同10.5%増） | 107.31億円（同3.1%減） | 寿司ネタ・業務用に強い。水産事業1,950億円（同15.6%増）だが営業益は5.9%減＝**相場高が原価を押し上げた**。新中計で3年で売上5割増、「海外」「食品」拡大を掲げる |

このほか、水産物の流通・調達では**総合商社**（→[総合商社](../../06_商社・卸売/01_総合商社/README.md)）、
生産の現場では**漁業協同組合（漁協）**と**個人・家族経営の漁業者／養殖業者**が圧倒的多数を占める。
陸上養殖には**電力・通信・不動産などの異業種**が参入している。

> 注意：**水産セグメントの売上増は好調を意味しない**。
> 相場が上がれば売上も原価も同時に膨らむため、必ず営業利益率で見る。→ [03](03_大手水産企業の商売.md)

## 5. 収益モデル・コスト構造

3層でまったく違うので、層ごとにモデルを持つ必要がある。

```
 【漁業】1航海あたり                【養殖】出荷1kgあたり        【加工】製品1個あたり
  売上 = 漁獲量 × セリ値             売上 = 出荷量 × 相場         売上 = メーカー値決め
   − 燃料費（油価に直撃）             − 餌代 ★原価の6〜7割         − 原料魚（相場・為替）
   − 乗組員の歩合給                   − 種苗（稚魚）代              − 加工賃（人件費）
   − 漁具・修繕・保険                 − 人件費・電気・資材          − 包材・エネルギー
   − 漁協手数料・市場手数料           − 減価償却（生け簀・設備）    − 物流費
   = 残り                             = 残り                        = 残り
   ↑ 売上側がまったく読めない         ↑ 原価側が外国の相場で動く    ↑ 両側をある程度コントロールできる
```

| 層 | 利益を決める変数 | 最大のリスク |
| --- | --- | --- |
| 漁業 | 漁獲量 × 魚価 − 燃料費 | 資源の減少、海洋環境の変化、燃料高。**売上がまったく読めない** |
| 養殖 | 出荷単価 − 餌代 | **魚粉価格**（2026年3月に1kg 291円と最高値圏）、赤潮・高水温による斃死 |
| 加工・流通 | 加工賃＋ブランド＋在庫益 | 原料確保（買い負け）、人手不足、在庫の評価損 |

**給餌養殖は餌代が原価の6〜7割**なので、**餌が2割上がると利益がほぼ消える**。
だから養殖業者は毎日ペルーの漁模様と魚粉相場を見ている → [02](02_養殖と輸入.md)

## 6. 競争要因（KSF）と参入障壁

### 勝つための条件（KSF）

| KSF | なぜ効くか |
| --- | --- |
| **原料へのアクセス** | 良い魚は量が限られる。漁業権・漁獲枠・産地との関係が事実上の資産 |
| **加工能力と技術** | 相場商売を値決め商売に変える唯一の手段。すり身・フィレ加工の技術蓄積が効く |
| **冷凍在庫と物流** | 漁期は短く、需要は通年。在庫を持てる者だけが安定供給できる |
| **輸出ルートと衛生認証** | 輸出先ごとに施設登録・衛生基準が違う。取得済みであることが参入障壁になる |
| **サステナビリティ認証** | MSC/ASCがないと欧米の大手小売・外食の棚に置けない。**理念ではなく取引条件** |
| **人の確保** | 漁業就業者は20年で半減、加工現場も人手不足。**原料があっても人がいなければ回らない** |

### 参入障壁

1. **制度そのもの**。漁業は大臣・知事の許可制、沿岸は漁業権（多くは漁協に免許）。
   **新規に船を出して魚を獲ることは、原則としてできない**
2. **漁獲枠**。TACとその配分は過去実績を基礎にするため、新規参入者に枠が回りにくい
3. **資本**。陸上養殖は大型施設で数百億円規模、遠洋漁船は1隻数十億円
4. **販路と信用**。量販店・外食は「事故らないこと」を最重視するため、実績のない事業者は採用されにくい

一方で、**2020年12月施行の改正漁業法により、養殖の区画漁業権については企業参入の余地が広がった**。
2020年代に異業種の養殖参入が相次いでいるのは、この制度変更が背景にある。

## 7. 規制・法制度

| 法令・制度 | 効き方 |
| --- | --- |
| **漁業法**（2018年成立、2020年12月施行の改正が70年ぶりの大改正） | 漁業権、許可漁業、資源管理の基本法。改正で**MSY（最大持続生産量）ベースの資源管理**、TAC・IQの拡大、養殖への企業参入促進が導入された |
| **TAC制度（海洋生物資源の保存及び管理に関する法律 → 改正漁業法に統合）** | 魚種ごとの年間漁獲上限。2024年にマダラ、2025年にカタクチイワシ・ブリを追加。**漁獲量の8割をTAC管理下に置く**のが政策目標 |
| **IQ（個別割当）** | TACを船・経営体に事前配分。早獲り競争をなくし、単価上昇とコスト低下をもたらす |
| **水産業協同組合法** | 漁協の設立・運営。共同漁業権の管理主体としての根拠法 |
| **水産流通適正化法**（2022年12月施行） | IUU漁業対策。国内産はナマコ・アワビ・**シラスウナギ（2025年12月1日〜）**、輸入はサバ・サンマ・マイワシ・イカが対象。漁獲番号の伝達と記録を義務化 |
| **食品衛生法／HACCP** | 加工場の衛生管理。2021年6月から原則すべての食品事業者に義務化 |
| **食品表示法** | 原産地・原材料・アレルゲン・消費期限。水産物は原料原産地表示が論点になりやすい |
| **輸出先国の施設認定制度** | 対米（HACCP）、対EU、対中国など、輸出先ごとに施設登録・認定が必要。**中国は2023年8月の全面禁輸以降、再登録手続きが継続中** |
| **国際的な地域漁業管理機関（RFMO）** | WCPFC、IATTC、ICCATなど。クロマグロ等の漁獲枠は国際交渉で決まる |
| **ワシントン条約（CITES）** | 2025年12月のCoP20でウナギ属全種の附属書II掲載提案が**否決**（賛成35・反対100） |
| **みどりの食料システム戦略／水産業の成長産業化政策** | 養殖の成長産業化、輸出目標、スマート水産業。令和7年度 水産白書（2026年6月）の特集が「養殖業の成長産業化」 |

> ポイント：**この業界は規制が参入障壁であり、同時に収益性の決定要因でもある**。
> TACの配分、漁業権の免許、輸出先国の施設登録──どれも経営の根幹に直結する。

## 8. 最近のトピック

詳細と出典URLは [直近トピック 2026](04_直近トピック_2026.md) に。要点は5つ。

1. **中国が日本産水産物の輸入を再停止**。2025年6月に10都県を除き条件付き再開 → 11月5日に北海道産冷凍ホタテ約6トンが出荷 →
   **11月19日に事実上の再停止**。ただし産地は販路を米国・ベトナム・タイに付け替え済みで、卸値はむしろ最高値圏
2. **2025年生産統計**。海面漁業270万500トン（7年連続減）、海面養殖83万1,900トン（5年ぶり増）。
   ホタテは26万3,000トンと17%減だが、輸出額は906億円で30.4%増＝**量は減り単価が上がった**
3. **太平洋クロマグロの大型魚（30kg以上）の漁獲枠を2027年から25%増で国際合意**（2026年8月）。小型魚は6%減。
   **資源管理が効いた数少ない成功例**。配分をめぐる国内調整が次の焦点
4. **サンマは2026年秋に調査開始（2003年）以来の最少見通し**（推定分布量は前年の40%）。
   一方スルメイカは2026年漁期の枠を6万8,400トンと前年当初枠の約3.6倍に拡大
5. **魚粉が最高値圏**。ペルーのアンチョビ第2漁期の暫定枠が50万トン（前年同期比79%減、2025年11月）。
   2026年3月には飼料用魚粉1kg 291円との集計。**養殖の採算を直撃**

## 9. 用語メモ

各ノートの末尾に詳しい用語メモがある。最低限押さえるべき12語。

| 用語 | 意味 |
| --- | --- |
| **TAC（漁獲可能量）** | Total Allowable Catch。「この魚は日本全体で年間◯トンまで」という国が決める漁獲上限 → [01](01_水産業の全体像.md) |
| **IQ（個別割当）** | Individual Quota。TACを船・経営体ごとに事前配分する仕組み。早獲り競争をなくし単価を上げる → [01](01_水産業の全体像.md) |
| **MSY（最大持続生産量）** | 資源を減らさずに毎年獲り続けられる最大量。改正漁業法でTAC算定の原則に |
| **漁業権** | 特定の海面を排他的に使う権利。定置・区画（養殖）・共同の3種。知事が免許 → [01](01_水産業の全体像.md) |
| **漁協** | 漁業協同組合。共同漁業権の管理、産地市場の開設、資材供給、販売、金融まで担う |
| **産地市場／消費地市場** | 港のセリ／豊洲などの大消費地市場。水産物は**二段階で価格が決まる** → [01](01_水産業の全体像.md) |
| **魚粉（フィッシュミール）** | 小魚を煮て搾り乾燥した飼料原料。**給餌養殖の原価の6〜7割**。ペルー産依存 → [02](02_養殖と輸入.md) |
| **完全養殖** | 人工種苗から育てた親魚で採卵し、サイクルを回せる状態。クロマグロは2002年に近大が世界初成功 → [02](02_養殖と輸入.md) |
| **陸上養殖／RAS** | 陸のタンクで育てる方式／水をろ過して再利用する閉鎖循環式。**装置産業の損益構造** → [02](02_養殖と輸入.md) |
| **すり身（surimi）** | 白身魚を洗って脂と臭みを除いた半製品。かまぼこ・カニカマの原料。**安い魚を工業原料に変える技術** → [03](03_大手水産企業の商売.md) |
| **IUU漁業** | 違法（Illegal）・無報告（Unreported）・無規制（Unregulated）漁業。水産流通適正化法が国内対策 → [03](03_大手水産企業の商売.md) |
| **MSC／ASC認証** | 天然漁業／養殖の国際的な持続可能性認証。欧米の大手小売では**実質的な取引条件** → [03](03_大手水産企業の商売.md) |
