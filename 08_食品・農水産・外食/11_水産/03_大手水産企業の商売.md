# 大手水産企業の商売 ― 彼らは漁業会社ではない

このノートで分かること：**Umios（旧マルハニチロ）・ニッスイ・極洋の水産大手3社は、いま漁業会社ではなく食品会社である**。
利益の主力は加工食品と海外事業であり、自社で獲る魚の比率は小さい。
なぜそうなったのか、何で稼いでいるのか、そして輸出と中国リスク、サステナビリティ認証がどう効くのかを押さえる。

## 1. まず結論：売上の大半は「獲った魚」ではない

水産大手3社のルーツは、いずれも戦前〜戦後の遠洋漁業である。
捕鯨、北洋のトロール、遠洋まぐろ延縄──自分の船団で世界中の海から魚を獲ってくる会社だった。
それが変わったのは**1970年代の200海里体制**である。
各国が沿岸200海里を排他的経済水域（EEZ）として囲い込んだ結果、
**日本の遠洋漁業は漁場を失い、3社は「獲る会社」であり続けることができなくなった**。

```
 【1960〜70年代】               【200海里体制】           【現在】
  自社船団で世界の海から獲る  ──▶ 漁場を喪失         ──▶ 獲るのは一部だけ
   漁業 = 本業                     船団を縮小・売却         買う（トレーディング）
   加工 = 獲った魚の処理場          ↓                       育てる（養殖）
                                 残ったのは               作る（加工食品）
                                 ・全国の加工工場          売る（海外・量販・外食）
                                 ・販売網と商権
                                 ・海外の人脈と拠点
```

> ポイント：**水産大手は「海から陸へ」事業の重心を移すことで生き延びた会社**である。
> だから決算を読むときは、水産セグメントの数字より、**食品（加工）セグメントと海外の数字**を先に見る。

### セグメントの形は各社で違う

3社ともセグメント区分と名称を頻繁に見直しており、単純比較はできない。
おおまかには**「水産（漁業・養殖・トレーディング）」「食品（加工・冷食・常温）」「その他（物流、ファインケミカル、畜産、ペットフードなど）」**の3系統である。

| 会社 | 主な事業の柱 | 特徴的な非水産事業 |
| --- | --- | --- |
| Umios（旧マルハニチロ） | 水産資源（漁業・養殖）／水産商事（トレーディング）／食品（加工）／畜産／保管物流 | **畜産**と**ペットフード**。タイのペットフード事業が好調と報じられる |
| ニッスイ | 水産事業／食品事業／ファインケミカル／物流 | **ファインケミカル**。魚油由来のEPA原薬など。利益率が高い |
| 極洋 | 水産（水産商事・かつお/まぐろ）／食品（冷凍食品・常温食品）／生鮮／物流サービス | 3社のなかでは水産の比重が相対的に高く、寿司ネタ・業務用に強い |

極洋の2026年3月期は、**水産事業の売上1,950億39百万円（前期比15.6%増）に対して営業利益57億50百万円（同5.9%減）**、
**生鮮事業の売上717億25百万円（同8.9%増）に対して営業利益38億56百万円（同6.7%増）**と開示されている。
**売上は伸びているのに水産の利益が減る**のは、相場高で仕入原価が上がり、売価転嫁が追いつかないためである。

> ポイント：**水産セグメントは「相場に乗る商売」なので、売上が増えても利益が増えるとは限らない**。
> 相場が上がれば売上は自動的に膨らむが、それは原価も同時に膨らむという意味でもある。

## 3. 商社機能 ― 「水産商事」とは何をしているのか

3社の売上で大きな比率を占める「水産商事」「水産事業」は、実は**商社業務**である。

```
 【水産商事の商流】
  世界の漁業者・養殖業者・輸出業者
        │  買付（ドル建てが多い）
        ▼
   ★水産大手（買付・在庫・為替・品質管理・与信）
        │  国内の量販店・外食チェーン・加工メーカーへ販売
        ▼
   小売／外食／自社の加工工場
```

彼らが担っているのは次の4つで、**これは総合商社の機能そのもの**である
→ [総合商社](../../06_商社・卸売/01_総合商社/README.md)、[食品卸](../../06_商社・卸売/06_食品卸/README.md)

| 機能 | 中身 | なぜ価値があるか |
| --- | --- | --- |
| **調達ネットワーク** | 世界中の産地に買付拠点と人脈を持つ | 良い原料は量が限られ、先に押さえた者が勝つ |
| **在庫（冷蔵倉庫）** | 大量の冷凍在庫を持ち、供給を平準化する | 漁期は短いが、需要は通年。持てる者だけが応えられる |
| **為替・相場リスクの引受** | ドル建て仕入を円建てで販売し、価格変動を吸収する | 量販店や外食は変動リスクを負いたくない |
| **品質・衛生の保証** | 産地の工場管理、トレーサビリティ、輸出入手続き | 小売にとって「事故らない」ことが最大の価値 |

**この商売の利益率は低い（数%）が、回転と規模で稼ぐ**。
在庫を抱えるので相場が下がると評価損を食らう一方、相場が上がれば在庫益が出る。
**「水産の利益は在庫と相場で毎年ぶれる」**のはこのためである。

## 4. 加工 ― すり身・缶詰・冷凍食品

3社が安定して稼いでいるのは加工である。**原料相場の変動を製品の値決めで吸収でき、ブランドが効く**からである。

| 加工の型 | 中身 | 経済的な意味 |
| --- | --- | --- |
| **すり身（surimi）** | スケトウダラなどの白身魚を洗って脂と臭みを抜き、たんぱくだけを残した半製品。かまぼこ・ちくわ・カニカマの原料 | **魚を「素材」から「工業原料」に変えた発明**。安い魚を安定品質の製品に変換できる。カニカマは世界に輸出される日本発の加工食品 |
| **缶詰** | サバ缶、ツナ缶、サケ缶など | 常温流通・長期保存。災害備蓄需要。国産サバ缶ブームのように需要が急変する |
| **冷凍食品** | 魚フライ、フィッシュスティック、寿司ネタ、業務用の切身 | **最大の成長領域**。量販店・外食・給食が顧客 → [冷凍食品・惣菜](../06_冷凍食品・惣菜/README.md) |
| **チルド・惣菜** | 焼き魚、煮魚、味付け切身 | 「家で魚を焼きたくない」という需要の受け皿 |
| **ファインケミカル** | 魚油から精製したEPA・DHAの原薬、サプリ原料 | 食品より利益率が高い。ニッスイの柱のひとつ |

```
 【原料から製品への価値の階段】
  水揚げされた魚（相場で決まる）
     │  ＋選別・下処理
     ▼
  フィレ・切身（加工賃が乗る）
     │  ＋すり身化・調味・フライ・冷凍
     ▼
  加工食品（メーカー値決め・ブランドが効く）
     │  ＋家庭用ブランド／業務用スペック対応
     ▼
  店頭・外食のメニュー
  ─────────────────────────────────
  下に行くほど相場から切り離され、利益が安定する
```

> ポイント：**加工とは「相場商売を値決め商売に変換する装置」**である。
> 水産大手が食品会社になったのは企業文化の変化ではなく、**そのほうが利益が安定するという経済的な必然**だった。

## 5. 漁業と養殖 ― 小さいが戦略的

いまも3社は漁業と養殖をやっているが、**規模より「原料を押さえる」意味が大きい**。

| 事業 | 中身 | 戦略的な意味 |
| --- | --- | --- |
| 漁業（自社船・出資船） | 北洋トロール、海外まき網、かつお・まぐろなど | 原料の一部を自前で確保。国際的な漁獲枠が資産になる |
| 養殖（ブリ、マダイ、クロマグロ、サーモンなど） | 自社・グループ、または契約養殖 | **完全養殖クロマグロ**などはブランド価値が高い。生産から販売まで一気通貫で利益を取れる |
| 種苗・飼料 | 人工種苗の生産、配合飼料事業 | 養殖のコスト構造を内側から押さえる |

養殖への企業参入が2020年代に増えた背景には、**2020年12月施行の改正漁業法**がある。
養殖に使う区画漁業権について、従来の地元漁協優先の原則が見直され、
**活用されていない水面に企業が入りやすくなった** → [水産業の全体像](01_水産業の全体像.md)

ただし養殖は**餌代が原価の6〜7割**で、魚粉相場に利益が直結する。
大手といえども、**養殖単体で安定して稼ぐのは難しい** → [養殖と輸入](02_養殖と輸入.md)

## 6. 海外 ― いま利益を作っているのはここ

国内市場が数量ベースで縮むなか、3社とも**海外での加工・販売**に重心を移している。

| 動き | 内容 | 時点 |
| --- | --- | --- |
| Umios（旧マルハニチロ） | 欧州で寿司用ホタテの販売が好調。オランダの水産加工会社を買収し、2025年7〜9月期から寄与。タイのペットフード事業も好調と報じられる | 2025〜2026年 |
| ニッスイ | 欧州・北米に加工・販売拠点。2026年3月期は売上・利益とも過去最高 | 2026年3月期 |
| 極洋 | 新中期経営計画で3年で売上高5割増を掲げ、「海外」「食品」の拡大を打ち出したと報じられる | 2025年 |

海外が効く理由は3つある。

1. **世界の水産物需要は伸びている**。特に寿司・刺身の世界的な普及で、日本式の加工技術に需要がある
2. **現地で加工すれば為替と関税の影響を抑えられる**。日本から輸出するより現地生産が有利な場面が多い
3. **人口が増える市場にいられる**。国内の1人当たり魚介消費量は2001年度の40.2kgから2023年度21.4kgへほぼ半減している

## 7. 輸出と中国リスク ― ホタテで何が起きたか

日本の水産物輸出は伸びている。
**2025年の農林水産物・食品の輸出額は1兆7,005億円（前年比12.8%増）で、うち水産物は4,231億円（同17.2%増）**。
品目別では**ホタテ貝（生鮮など）906億円（同30.4%増）、ブリ528億円（同27.4%増）**。
輸出先は1位アメリカ、2位香港、3位台湾である（農林水産省、2026年2月公表）。

だが、ここに至るまでは激震があった。

```
 2022年     対中ホタテ輸出 10.3万トン／467億円
            = 日本のホタテ輸出の51%が中国向け（1国依存）
                │
 2023年8月   中国が日本産水産物を全面禁輸（ALPS処理水の海洋放出に反発）
                │  ホタテの主要用途は「中国で殻むき加工 → 米国等へ再輸出」だった
                │  → 加工機能ごと失われ、産地に在庫が滞留
                ▼
 2023〜25年  販路の付け替え：米国・ベトナム・タイ向けが急増
            国内でも殻むき加工能力を増強（補助金）
            → 輸出量は回復し、卸値はむしろ最高値圏へ
                │
 2025年6月29日 中国が10都県（福島・群馬・栃木・茨城・宮城・新潟・長野・埼玉・東京・千葉）
                を除き、条件付きで輸入を再開すると発表
 2025年11月5日 北海道産冷凍ホタテ 約6トンが全面禁輸後はじめて中国へ出荷
 2025年11月19日 中国が日本産水産物の輸入を事実上再停止（首相答弁への反発とみられると報じられる）
```

この経験から業界が学んだのは3点である。

| 教訓 | 中身 |
| --- | --- |
| **1国依存は経営リスクそのもの** | 品質でも価格でもなく、外交で売上の半分が消える |
| **加工工程の海外依存も同じリスク** | 「中国で殻をむく」という工程依存が、禁輸時に最も効いた |
| **分散すれば単価は上がりうる** | 実際、販路分散後に輸出量は伸び、卸値は上昇した。中国依存が価格を抑えていた面もある |

産地からは「外交カードに使われるのはうんざり」という声が出ていると報じられる。
**2026年時点でも中国向けは実質的に止まった状態**であり、最新状況は農林水産省の輸出再開手続きページで確認するのが確実である。
→ [直近トピック 2026](04_直近トピック_2026.md)

## 8. サステナビリティ ― 認証とIUU対策は「取引条件」になった

水産業のサステナビリティは、いまや理念ではなく**取引の前提条件**である。
欧米の大手小売・外食が調達基準として認証を求めるため、**認証がないと棚に置けない**。

| 制度 | 対象 | 中身 |
| --- | --- | --- |
| **MSC認証（海のエコラベル）** | **天然（漁業）** | Marine Stewardship Council。資源の状態、生態系への影響、管理体制の3原則で漁業を審査 |
| **ASC認証** | **養殖** | Aquaculture Stewardship Council。環境負荷、水質、飼料の持続可能性、労働環境などを審査 |
| **CoC認証** | 流通・加工 | Chain of Custody。認証品が非認証品と混ざらないよう、加工・流通段階を管理する認証 |
| **MEL** | 日・天然/養殖 | Marine Eco-Label Japan。日本発の水産エコラベル。GSSI（世界水産物持続可能性イニシアチブ）承認済み |

日本国内でもESG投資やSDGs対応を背景に認証品の調達が広がり、
**輸入サーモンなどを中心に、ASCラベル付き商品の流通量がこの3年で大きく増加したとされる**（報道ベース）。
一方、**日本の漁業はMSC認証の取得が少ない**。
資源評価データの整備と、漁業管理体制（TAC・IQ）の未成熟がネックだとされる。

### IUU漁業とその対策

**IUU漁業＝Illegal（違法）, Unreported（無報告）, Unregulated（無規制）漁業**。
許可なく獲る、獲った量を報告しない、どの国の規制も及ばない海域や船籍で獲る、といった漁業の総称である。
資源を壊すだけでなく、**強制労働などの人権問題とも結びつく**ため、欧米の規制は年々厳しくなっている。

日本の対策が**水産流通適正化法（特定水産動植物等の国内流通の適正化等に関する法律、2022年12月施行）**である。

| 区分 | 対象 | 内容 |
| --- | --- | --- |
| **第一種（国内産）** | ナマコ、アワビ、**シラスウナギ（2025年12月1日から適用）** | 漁獲番号の伝達、届出、取引記録の作成・保存を義務化 |
| **第二種（輸入）** | **サバ、サンマ、マイワシ、イカ** | 輸入時に外国政府の漁獲証明書の添付を求める |

**対象魚種が限定的**（EUは全魚種、米国も拡大の方向）という指摘があり、
「抜け穴が残る」とのNGOからの批判もある。**今後の対象拡大が規制リスクとして残っている**と見ておくべきである。

## 9. この3社を読むときの注意

1. **水産セグメントの売上増＝好調ではない**。相場高は売上も原価も押し上げる。**営業利益率で見る**
2. **社名と事業の実態がずれている**。Umios、ニッスイ、極洋──どれも社名は水産だが、実態は食品会社である
3. **為替は両刃**。円安は輸入原料のコストを上げるが、輸出と海外子会社の円換算利益は押し上げる。**どちらが大きいかは会社ごとに違う**
4. **地政学が損益項目になる**。中国の禁輸、ロシア産原料、ワシントン条約。**規制・外交が営業利益に直接効く業界**である

## 10. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **200海里体制** | 1970年代に各国がEEZを設定し、外国漁船を締め出した国際的な流れ。日本の遠洋漁業が壊滅的に縮小した転機 |
| **水産商事** | 世界から水産物を買い付けて国内外に販売する商社業務。低利益率・大量回転。在庫と為替のリスクを引き受ける |
| **すり身（surimi）** | 白身魚を洗って脂と臭みを除き、たんぱく質だけを残した半製品。かまぼこ・カニカマの原料。日本発の工業的加工技術 |
| **ファインケミカル** | 魚油由来のEPA原薬など、高付加価値の化学品事業。食品より利益率が高い |
| **MSC認証** | 天然漁業を対象とする国際的な持続可能性認証。「海のエコラベル」 |
| **ASC認証** | 養殖を対象とする国際的な持続可能性認証。飼料の持続可能性や労働環境も審査対象 |
| **CoC認証** | 認証品が非認証品と混ざらないことを保証する、加工・流通段階の管理認証 |
| **MEL** | Marine Eco-Label Japan。日本発の水産エコラベル。GSSI承認を取得 |
| **IUU漁業** | 違法・無報告・無規制漁業。資源破壊に加え、強制労働などの人権問題とも結びつく |
| **水産流通適正化法** | 2022年12月施行。IUU由来の水産物の国内流通を防ぐ法律。国内産（ナマコ・アワビ・シラスウナギ）と輸入（サバ・サンマ・マイワシ・イカ）が対象 |
| **トレーサビリティ** | いつ・どこで・誰が獲った魚かを追跡できる状態。輸出と認証の前提条件 |
