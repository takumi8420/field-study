# 養殖と輸入 ― 足りない魚をどう埋めているか

このノートで分かること：**世界の水産物供給はすでに養殖が半分を超えたのに、日本は養殖化に乗り遅れた**。
その結果、日本は「獲れない分を輸入で埋める国」になっている。
養殖の採算を左右する餌（魚粉）の問題、完全養殖と陸上養殖の実態、そして円安が輸入に効く構造を押さえる。

## 1. 世界はもう「獲る」より「育てる」が多い

2024年、**世界の漁業・養殖業生産は過去最高の2億3,500万トン**に達した。
このうち水生動物（魚・甲殻類・貝など。海藻を除く）が1億9,500万トンで、内訳は次の通りである
（FAO『世界漁業・養殖業白書 SOFIA 2026』、2026年6月公表）。

| 区分 | 生産量（2024年） | 特徴 |
| --- | --- | --- |
| **養殖（水生動物）** | **1億トン超**（史上初めて1億トンを突破） | 1950年代以降、年平均3.2%で成長し続けている |
| **漁船漁業（天然）** | 約9,200万トン | ここ30年ほぼ横ばい。**生態系の限界に達している** |
| 合計（水生動物） | 約1億9,500万トン | FAOは2034年に2億1,400万トンになると予測 |

> ポイント：**天然の漁獲量は「もう増えない」**。世界人口が増え、健康志向で魚の需要が増えても、
> 海から獲れる量には上限がある。**だから増分はすべて養殖が担う**。これが世界の共通認識である。

```
 世界の水生動物生産（イメージ）
                              養殖が漁船漁業を追い抜いた
  1990年  漁船 ████████████████  養殖 ███
  2000年  漁船 ████████████████  養殖 ███████
  2010年  漁船 ███████████████   養殖 ████████████
  2024年  漁船 ███████████████   養殖 ████████████████  ← 初の1億トン超
          └── 30年横ばい ──┘    └─ 年3.2%成長 ─┘
```

対する日本は、2025年の海面養殖業生産量が**83万1,900トン（前年比3.6%増、5年ぶりの増加）**
（農林水産省「2025年漁業・養殖業生産統計」）。海面漁業の270万500トンに対して養殖は2割強にすぎず、
**世界の潮流とは逆の構成**になっている。「日本は養殖化が遅れた」と言われるのはこの点である。

### なぜ日本は養殖に振り切れなかったのか

| 理由 | 中身 |
| --- | --- |
| **天然資源が豊かだった** | 四方を海に囲まれ、魚種が多い。わざわざ育てなくても獲れた |
| **漁業権制度** | 養殖に使う区画漁業権は地元漁協優先で、企業が入りにくかった（2020年の改正漁業法で緩和） |
| **消費者が天然を好んだ** | 「天然物のほうが上」という価値観が長く根強かった |
| **適地が限られる** | 静穏な内湾が必要だが、日本は湾が小さく、養殖密度がすでに高い |
| **餌の輸入依存** | 魚粉をほぼ輸入に頼るため、原価を自国でコントロールできない |

2026年6月に公表された**令和7年度 水産白書の特集テーマが「養殖業の成長産業化に向けた対応」**だったのは、
政策側もこの遅れを最重要課題と認識していることを示している。

## 2. 日本の養殖は何を育てているか

日本の海面養殖は、**魚（ブリ・マダイ・サーモン・クロマグロ）と、貝・藻類（ホタテ・カキ・ノリ・ワカメ）**の
2系統に分かれる。この2つは経済がまったく違う。

| 対象 | 代表 | 餌 | 育成期間の目安 | 経済の性格 |
| --- | --- | --- | --- | --- |
| **給餌養殖（魚）** | ブリ類、マダイ、サーモン、クロマグロ | 必要（原価の6〜7割） | ブリ約2年、マダイ約2年、クロマグロ3年以上 | 餌代が利益を決める。魚粉相場に直撃される |
| **無給餌養殖（貝・藻類）** | ホタテ、カキ、ノリ、ワカメ | 不要（プランクトンを食べる／光合成） | ホタテ2〜4年、ノリは数か月 | 餌代ゼロ。海況と労働力が勝負。輸出で伸びた |

日本の養殖魚の代表はブリ類とマダイである。
ブリは輸出でも伸びており、**2025年のブリ輸出額は528億円（前年比27.4%増）**（農林水産省）。
ホタテは**2025年の輸出額906億円（生鮮など、前年比30.4%増）で水産物の輸出品目トップ**だが、
生産量は2025年に26万3,000トンと前年比17%減で、価格上昇が額を押し上げた側面が大きい。

```
 【給餌養殖の損益イメージ：ブリ1kgあたり】
  売上（出荷単価）  ████████████████████ 100
   ├ 餌代          ██████████████        60〜70  ★ここが魚粉相場で動く
   ├ 稚魚（種苗）代 ███                    10前後
   ├ 人件費・燃料   ███                    10前後
   ├ 減価償却・資材 ██                      5前後
   └ 残り（利益）   █                      数%〜十数%

  → 餌代が2割上がると、利益はほぼ消える
```

> ポイント：**給餌養殖は「飼料相場に対するレバレッジ商売」**である。
> 出荷単価が固定なら、餌代が10%動くだけで利益が数倍ぶれる。だから養殖業者は魚粉相場を毎日見ている。

## 3. 餌の問題 ― 魚粉（フィッシュミール）とは何か

**魚粉＝フィッシュミール。カタクチイワシなどの小魚を煮て、搾って、乾燥・粉砕した粉末の飼料原料**。
タンパク質含有量が高く、養殖魚の成長効率がよいため、給餌養殖の配合飼料の主原料として使われてきた。
養殖魚だけでなく、養豚・養鶏の飼料にも使われる → [畜産・飼料](../13_畜産・飼料/README.md)

問題は、**世界の魚粉の大きな部分がペルー沖のカタクチイワシ（アンチョベータ）1魚種に依存している**ことである。
ペルー沖は**エルニーニョ（海水温が上がる現象）**が起きると極端な不漁になる。
つまり、**日本の養殖業の原価が、地球の裏側の1魚種の漁模様と、ペルー政府が決める漁獲枠で決まる**。

| 出来事 | 内容 | 時点 |
| --- | --- | --- |
| エルニーニョによる不漁 | ペルー沖のアンチョビが不漁となり、魚粉価格が高騰 | 2023年前後 |
| ペルー増産で一服 | 魚粉価格は約2割下落。ただし米中関税などで高値圏は継続と報じられる | 2025年2月・報道 |
| **第2漁期の枠が激減** | ペルー政府が北中部海域の暫定漁獲枠を**50万トン（前年同期比79%減）**に設定。事前予想の200〜250万トンを大きく下回る | 2025年11月1日 |
| **国内魚粉価格が最高値圏** | 飼料用魚粉1kgあたり**291円**を記録。コロナ禍前比で平均+184%との集計 | 2026年3月・民間価格集計 |

※価格集計は民間サイトの推計値。契約条件や品位で実勢は異なるため、目安として読む。

### 代替飼料という解

魚粉を減らす方向の研究・実用化が進んでいる。狙いは**原価の安定化と、資源保全（小魚を獲って魚を育てる矛盾の緩和）**である。

| 代替原料 | 中身 | 状況 |
| --- | --- | --- |
| 植物性タンパク（大豆、菜種、コーンなど） | 最も普及。ただし必須アミノ酸が不足しがちで配合設計が難しい | 実用段階 |
| 昆虫（アメリカミズアブなど） | 食品残渣で育てた幼虫を粉末化。循環型で環境負荷が低い | 実証〜一部商用 |
| 微細藻類 | 魚油に含まれるDHA・EPAを藻類から直接とる | 実証段階、コストが課題 |
| 単細胞タンパク／培養タンパク | メタンや水素を使い微生物にタンパクを作らせる | 研究〜実証 |
| 食品副産物・未利用魚 | 加工残渣や規格外魚を飼料化 | 一部実用 |

→ 技術の全体像は [フードテック](../../01_注目テーマ/13_フードテック/README.md)

ただし、**代替飼料は「魚粉が高いとき」しか経済合理性が立たない**。
魚粉が安くなると代替原料は割高になって採用が止まる。**普及ペースは魚粉相場に振り回される**というのが実態である。

## 4. 完全養殖 ― 卵から卵まで人の手で回す

**「完全養殖」とは、人工的に孵化させて育てた魚から卵を採り、その卵からまた魚を育てるサイクルを確立すること**。
これに対し、天然の稚魚（種苗）を捕まえてきて育てるのは「蓄養」や「不完全養殖」と呼ばれる。

なぜ重要か。**天然稚魚に頼る限り、養殖は天然資源を消費している**からである。
ブリの養殖はモジャコ（天然のブリ稚魚）を採捕して始めるのが伝統的な方式で、
これでは資源保護の観点から「養殖だから持続可能」とは言えない。

| 魚種 | 完全養殖の状況 | 論点 |
| --- | --- | --- |
| **クロマグロ** | 2002年に近畿大学が世界初の完全養殖に成功。人工種苗の供給が商業化 | 成長に3年以上、餌効率が悪い。生残率の改善が課題 |
| **マダイ** | 早くから確立。人工種苗が主流 | ほぼ解決済み |
| **ブリ** | 人工種苗化が進行中。天然モジャコ依存からの脱却が課題 | 種苗コストが天然より高い |
| **ウナギ** | 完全養殖の技術自体は2010年に成功。**商業化はまだ** | 仔魚の餌と飼育期間がネック。シラスウナギは依然として天然採捕頼み |
| **サーモン（トラウト等）** | 淡水での種苗生産は確立 | 海面・陸上どちらで育てるかの選択の問題 |

令和7年度 水産白書でも**ウナギの完全養殖の取組**が特集で取り上げられている。
ウナギは2025年11〜12月のワシントン条約締約国会議で国際取引規制の対象になりかけた経緯もあり
（→ [直近トピック 2026](04_直近トピック_2026.md)）、**完全養殖の商業化は資源問題であると同時に貿易リスク対策**でもある。

## 5. 陸上養殖 ― 採算が成立するかがすべて

**陸上養殖＝海ではなく陸のタンクで魚を育てる方式**。
水をろ過して再利用する **RAS（Recirculating Aquaculture System＝閉鎖循環式養殖）** が代表的である。

```
 【海面養殖】                       【陸上養殖（RAS）】
  海に生け簀を浮かべる               陸のタンク＋ろ過装置＋ポンプ
   ＋ 初期投資が小さい                ＋ 消費地の近くに作れる（輸送費・鮮度で有利）
   ＋ 海水の交換は自然任せ（電気代ゼロ） ＋ 水温・水質を一定に保てる → 通年で計画生産
   − 台風・赤潮・高水温のリスク直撃    ＋ 薬剤・寄生虫リスクが低い、排水を管理できる
   − 適地が限られ、新規区画が取れない  − 初期投資が巨額（大型施設で数百億円規模）
   − 水温が制御できない               − 電気代（ポンプ・冷却・ろ過）が常時かかる
                                      − 設備トラブル＝全滅リスク
```

> ポイント：**陸上養殖は「魚の養殖」というより「装置産業」**である。
> 減価償却と電気代という固定費が大きいので、**稼働率と歩留まりが落ちた瞬間に赤字**になる。
> 半導体工場やデータセンターと同じ損益の形をしている。

だから陸上養殖が成り立つのは、**高く売れる魚**（アトランティックサーモンなど）で、
**生鮮・高鮮度というプレミアムが取れる**場合に限られやすい。国内でも投資は加速している。

| 案件 | 内容 | 時点 |
| --- | --- | --- |
| 三重県の大型施設 | 世界最大級のアトランティックサーモン陸上養殖施設。総事業費約700億円とも報じられ、2027年末頃からの出荷を目指す | 2026年・報道 |
| FRDジャパン（千葉県富津市） | 富津ファームの部分引き渡しが完了し、本格生産を開始 | 2026年2月 |
| ピュアサーモンジャパン | 1億8,000万米ドル超の優先ノートによる資金調達を完了 | 2026年・発表 |
| 国内サーモン生産 | 2026年の国内生産量は過去最多だった前年からさらに1割増える見込みと報じられる | 2026年・報道 |

異業種（商社、電力、通信、不動産など）の参入が目立つのも陸上養殖の特徴である。
**必要なのは漁業のノウハウより、設備投資と運転管理の能力**だからである。
逆に言えば、**魚価が下がるか電気代が上がれば、装置産業の宿命として一気に苦しくなる**。

## 6. 日本は水産物の輸入大国である

国内生産が減り、消費も減ったが、**それでも国内生産だけでは足りない**。
2025年の水産物輸入額は**約1兆9,626億円**と報じられており、
同年の水産物輸出額4,231億円の4倍を超える。**日本は水産物の大幅な輸入超過国**である。

| 主要輸入品目 | 主な調達先 | 使われ方 |
| --- | --- | --- |
| **サケ・マス類** | ノルウェー、チリ | 刺身・寿司、切身。回転寿司の看板ネタ |
| **エビ** | ベトナム、インド、インドネシアなど | 外食、冷凍食品、惣菜 |
| **カツオ・マグロ類** | 台湾、中国、韓国、太平洋島嶼国など | 刺身、寿司、ツナ缶原料 |
| **カニ・イカ・タコ・ウナギ** | ロシア、中国、ペルー、モロッコなど | 加工原料、外食 |

サケ・マスの輸入単価は**2016年の1kgあたり約780円から、2024年に約1,279円、2025年には約1,370円**へ上昇した一方、
**輸入数量は約22万トンでほぼ横ばい**と集計されている（民間データ集計）。
エビの2025年輸入量は22.2万トンと報じられる。

### 円安が効く仕組み

```
  1ドル=110円の時代                1ドル=155円の時代
  ────────────────              ────────────────
  ノルウェー産サーモン              同じサーモン
  10ドル/kg                        10ドル/kg
     ↓                                ↓
  仕入れ 1,100円/kg                 仕入れ 1,550円/kg  ← 現地価格が同じでも+41%
     ↓                                ↓
  回転寿司の原価に乗る               原価を吸収できず、値上げ or ネタを変える
                                       ↓
                                   「サーモンを国産に置き換える」動機が生まれる
                                       ↓
                                   国内サーモン養殖ブームの経済的な背景
```

> ポイント：**国内サーモン養殖の投資ラッシュは、技術革新というより為替の産物**という面が大きい。
> 円安で輸入サーモンが高くなり、国産の採算ラインが相対的に下がった。
> したがって**円高に振れると、この投資の前提が崩れる**リスクを常に抱えている。

さらに、世界の水産物需要は中国をはじめ新興国で伸びており、**「買い負け」**が起きる。
円安と需要増が重なると、日本の買い手が価格で他国に競り負けて、そもそも原料が取れなくなる。
加工業者にとってはこれが最も深刻な問題で、**「工場を作っても原料が確保できず稼働率が上がらない」**
という事態が各地で報告されている。

## 7. 養殖と輸入は「同じ問題の裏表」

まとめると構図はこうである。

```
  天然が獲れない ──┬──▶ 養殖を増やす ──▶ 餌（魚粉）が要る ──▶ 魚粉は輸入 ──▶ 円安と相場に直撃
                   │                        └ 陸上養殖なら電気代と巨額投資
                   │
                   └──▶ 輸入で埋める ────▶ 円安で高い＋買い負け ──▶ 国産回帰の動機
                                                                        ↓
                                                            養殖投資が増える（最初に戻る）
```

**「国産か輸入か」という二択ではなく、養殖を増やすこと自体が輸入（餌・稚魚・設備）に依存している**。
ここを理解しないと、「国産化で自給率が上がる」という単純な話に見えてしまう。

## 8. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **魚粉（フィッシュミール）** | カタクチイワシなどの小魚を煮て搾り乾燥・粉砕した飼料原料。給餌養殖の原価の中核。ペルー産への依存が高い |
| **魚油（フィッシュオイル）** | 魚粉の製造過程で出る油。DHA・EPAを含み飼料・サプリに使われる |
| **給餌養殖／無給餌養殖** | 餌を与えて育てる養殖（ブリ、マダイ、サーモン）／餌が不要な養殖（ホタテ、カキ、ノリ） |
| **種苗（しゅびょう）** | 養殖を始めるための稚魚・稚貝。天然採捕か人工生産かで持続可能性の評価が変わる |
| **モジャコ** | 流れ藻に付く天然のブリ稚魚。ブリ養殖の伝統的な種苗 |
| **シラスウナギ** | ウナギの稚魚。ウナギ養殖の出発点で、いまも天然採捕に依存している |
| **完全養殖** | 人工種苗から育てた親魚から採卵し、そのサイクルを回せる状態。クロマグロは2002年に近大が世界初成功 |
| **蓄養（ちくよう）** | 天然で獲った魚を一定期間生け簀で肥らせて出荷すること。養殖とは区別される |
| **陸上養殖** | 陸のタンクで育てる方式。装置産業的な損益構造になる |
| **RAS（閉鎖循環式養殖）** | Recirculating Aquaculture System。水をろ過して再利用する陸上養殖方式。水を捨てないが電力を食う |
| **エルニーニョ** | 太平洋赤道域の海水温が上がる現象。ペルー沖のアンチョビ不漁 → 魚粉高騰を引き起こす |
| **飼料効率（FCR）** | 1kgの魚を育てるのに要する餌の量。小さいほど効率がよい。養殖の採算を測る基本指標 |
| **買い負け** | 国際市場で他国の買い手より高値を出せず、原料を確保できないこと。円安局面で顕在化する |
