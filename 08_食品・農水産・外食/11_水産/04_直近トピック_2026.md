# 直近トピック（2026年9月時点）

報道・公表ベースの整理。数値は年月とセットで示し、推計・報道は明示している。
一次情報の所在は末尾の [参考リンク](#8-参考リンク) にまとめた。

## 0. まず全体像

2026年の水産業を動かしているのは、**「制度」「気候」「外交」の3つ**である。
資源管理は前進し（クロマグロ増枠、TAC拡大）、養殖は政策の主役になり（水産白書の特集）、
その一方で海の環境は悪化し（サンマの記録的不漁）、外交は水産物を人質に取り続けている（中国の再停止）。

```
 【追い風】                        【逆風】
  ・輸出額が過去最高（水産4,231億円） ・中国が日本産水産物を再び事実上停止（2025年11月）
  ・クロマグロ大型魚の枠25%増         ・サンマは調査開始以来の最少見通し（2026年秋）
  ・養殖が5年ぶりに増加（2025年）     ・魚粉が最高値圏（2026年3月 1kg 291円）
  ・陸上養殖に巨額投資が続く          ・海面漁業は7年連続減（2025年 270万トン）
  ・ウナギのCITES規制案は否決         ・漁業就業者は20年で半減（12.1万人）
```

## 1. 中国の輸入停止が「再開 → 再停止」で元に戻った（2025年11月）

**最大のトピックはこれである。** 時系列を押さえる。

| 時点 | 出来事 |
| --- | --- |
| 2023年8月 | ALPS処理水の海洋放出に反発し、中国が日本産水産物を**全面禁輸** |
| 2025年6月29日 | 中国税関総署が、**10都県（福島・群馬・栃木・茨城・宮城・新潟・長野・埼玉・東京・千葉）を除き条件付きで輸入再開**すると発表 |
| 2025年11月5日 | 北海道産の冷凍ホタテ**約6トン**が、全面禁輸後はじめて中国向けに出荷される |
| **2025年11月19日** | **中国が日本産水産物の輸入を事実上再停止**。首相答弁への反発とみられると報じられる |
| 2026年〜 | 農林水産省が輸出施設の再登録手続き（原則毎月20日までの資料提出、翌月までに中国政府へ再登録要請）を継続 |

再開からわずか2週間での再停止だった。産地からは**「外交カードにされるのはうんざり」**という声が出ていると報じられる。

### ただし、産地はもう中国を待っていない

2022年の対中ホタテ輸出は10.3万トン・467億円で、**日本のホタテ輸出の51%**を占めていた。
禁輸で失った販路を、この2年で米国・ベトナム・タイなどに付け替えた結果、
**輸出量は回復し、卸値はむしろ最高値圏になった**と報じられている。

```
 禁輸前（〜2023年7月）                禁輸後（2023年8月〜）
  日本 ──▶ 中国（殻むき加工）──▶ 米国等   日本 ──▶ 米国・ベトナム・タイ へ直接
        （輸出の51%が中国向け）                 ＋国内の殻むき加工能力を増強（補助）
                                                     ↓
   ・価格の主導権は中国の買い手            ・1国依存が解消、単価は上昇
   ・加工工程まで海外依存                  ・加工付加価値が国内に残る
   ・外交リスクが直撃                      ・ただし人手不足がボトルネックに
```

> 構図：**禁輸は打撃だったが、結果として「中国依存＋加工の海外依存」という構造的な脆さを是正した**。
> 中国が再開しても「元には戻らない」という産地の声はこの意味である。

→ 詳しくは [大手水産企業の商売](03_大手水産企業の商売.md)

## 2. 2025年の生産統計 ― 漁業7年連続減、養殖は5年ぶり増（2026年5月公表）

農林水産省「2025年漁業・養殖業生産統計」（2026年5月29日公表）の要点。

| 区分 | 2025年の生産量 | 前年比 | 備考 |
| --- | --- | --- | --- |
| **海面漁業** | **270万500トン** | **3.1%減** | 2019年から**7年連続の減少** |
| **海面養殖業** | **83万1,900トン** | **3.6%増** | **5年ぶりの増加** |

魚種別（海面漁業）では次の通り。

| 魚種 | 2025年生産量 | 前年比 | コメント |
| --- | --- | --- | --- |
| マイワシ | 70万7,600トン | 6.2%増 | 日本の漁獲の柱。多くは養殖飼料・加工向け |
| サバ類 | 28万3,800トン | 10.9%増 | 缶詰・輸出・飼料に回る |
| **ホタテガイ** | 26万3,000トン | **17%減** | 輸出額は増えたが**量は減った**＝単価上昇 |
| カツオ | 19万4,300トン | 19.6%減 | 資源と海洋環境の影響 |

長期で見ると、日本の生産量は**1984年の1,282万トンがピークで、2022年には392万トン**とピーク比3分の1以下。
下げ止まりの兆しはまだ見えない。→ [水産業の全体像](01_水産業の全体像.md)

## 3. 太平洋クロマグロ ― 大型魚の枠を25%増で国際合意（2026年8月）

**2026年8月18日**、中西部太平洋まぐろ類委員会（WCPFC）と全米熱帯まぐろ類委員会（IATTC）の
クロマグロ管理合同作業部会（第11回会合 第2次会議）で、**2027年から30kg以上の大型魚の漁獲割当量を25%引き上げ、
小型魚は6%減とする新たな管理枠組みに全参加国・地域が合意した**と報じられている。

これに先行して、日本の枠は小型魚4,725トン → 5,125トン（1.1倍を基礎）、
大型魚7,609トン → 11,869トン（1.5倍を基礎）へ増枠されてきた経緯がある。

```
 【太平洋クロマグロの親魚量（産卵親魚量）のイメージ】
  1961年  ████████████████  約16万トン（ピーク）
  2010年  █                 約1万トン（史上最低）→ 2014年に絶滅危惧II類に指定
   ↓ 国際的な厳格な漁獲規制（特に小型魚＝未成魚の削減）
  2020年代 ██████            回復傾向 → 増枠の根拠に
```

> ポイント：**これは「資源管理が効いた」という数少ない成功例**である。
> 小型魚を獲るのを我慢すれば、親魚が増えて将来の漁獲が増える──という教科書通りの結果が出た。
> 一方で「大型魚を獲れる大型漁船が優遇され、小型魚が主体の沿岸漁民にしわ寄せが行く」という批判もある。
> **増枠の配分をめぐる国内調整が、2026〜2027年の焦点**になる。

## 4. サンマは調査開始以来の最少見通し、スルメイカは枠を3.6倍に（2026年）

海洋環境の変化が、魚種ごとに正反対の結果を生んでいる。

| 魚種 | 2026年の状況 | 出典の性格 |
| --- | --- | --- |
| **サンマ** | 2026年秋の来遊量は2025年を下回り、**調査を開始した2003年以降で最少**の可能性。事前調査の推定分布量は前年の**40%** | 水産研究・教育機構の長期漁海況予報・報道 |
| **スルメイカ** | 2026年漁期（2026年4月〜2027年3月）の漁獲枠を**6万8,400トン**と正式決定。前年の当初枠の**約3.6倍** | 水産庁の決定・報道 |

サンマの不漁については、海水温上昇で分布が北・東へ移動したこと、暖水塊が回遊を妨げること、
外国漁船による公海での漁獲などが理由に挙げられてきた。
ただし**「日本のEEZ内では実質的に獲り放題の状態が長く続いた」という管理側の問題を指摘する見方**もある。

スルメイカの増枠は資源の回復を示すものだが、
**長期的には漁獲が低迷しており、乱獲による資源悪化を懸念する声がある**と報じられている。
枠が増えても、それを獲る船と人がいるかは別問題である。

## 5. 魚粉が最高値圏 ― ペルーの漁獲枠79%減が効いた（2025年11月〜2026年）

養殖の原価を決める**魚粉（フィッシュミール＝小魚を煮て搾り乾燥した飼料原料）**が高値圏にある。

| 時点 | 出来事 |
| --- | --- |
| 2025年2月 | ペルーの増産で魚粉価格は約2割下落。ただし米中関税などでなお高値との報道 |
| **2025年11月1日** | ペルー政府が北中部海域のアンチョビ第2漁期の暫定漁獲枠を**50万トン（前年同期比79%減）**に設定。事前予想の200〜250万トンを大きく下回り、業界に衝撃 |
| **2026年3月** | 飼料用魚粉の価格が**1kgあたり291円**を記録。コロナ禍前比で平均+184%との集計（民間価格集計サイト） |

```
 ペルー沖の漁模様 ──▶ 世界の魚粉需給 ──▶ 配合飼料価格 ──▶ 養殖の原価（6〜7割が餌）
       │                                                            │
   エルニーニョ                                              出荷単価に転嫁できなければ
   漁獲枠の政治的決定                                          養殖業者の利益がゼロに
       │
  日本の養殖業者にはコントロール不能
```

> 構図：**日本の養殖業の採算は、地球の裏側の1魚種の漁模様とペルー政府の枠設定で決まる**。
> 代替飼料（昆虫、微細藻類、植物性タンパク）の開発が進むのは、この依存を切りたいからである。
> ただし代替原料は魚粉が高いときしか採算が合わず、**普及ペース自体が魚粉相場に左右される**。

→ [養殖と輸入](02_養殖と輸入.md)、[フードテック](../../01_注目テーマ/13_フードテック/README.md)

## 6. ウナギのワシントン条約規制案は否決（2025年12月）

**2025年11月24日〜12月5日**、ウズベキスタン・サマルカンドで開かれた
**ワシントン条約（CITES）第20回締約国会議（CoP20）**で、
EUが提案した**ウナギ属全種の附属書II掲載**（国際取引に輸出国の許可を要する規制）が採決され、
**賛成35・反対100で否決**された（水産庁・環境省発表）。

日本は、ニホンウナギについて2012年から日中台（2014年以降は韓国も加えた4者）で
資源管理に取り組んでおり、**資源の保全と持続可能な利用が行われている**と主張し、これが受け入れられた形である。

| 論点 | 賛成側（EU等）の主張 | 反対側（日本等）の主張 |
| --- | --- | --- |
| 資源状態 | ウナギ属全体で個体数が減少 | 種ごとに状況が異なり、一括規制は過剰 |
| 管理体制 | 密漁・違法取引が横行している | 日中台韓の枠組みで池入れ量を管理している |
| 規制の効果 | 取引規制で違法流通を抑えられる | 正規の取引を止めるだけで、密漁は止まらない |

**業界にとっては当座のリスクが回避された**が、構造的な問題（シラスウナギが天然採捕に依存し、
密漁・違法流通が絶えない）は残る。だからこそ**ウナギの完全養殖の商業化**が急がれており、
令和7年度 水産白書でも特集の一項目として取り上げられている。

なお国内では、**シラスウナギが2025年12月1日から水産流通適正化法の第一種対象**に加わり、
漁獲番号の伝達・記録が義務づけられた。**国内の流通管理を固めることで、国際規制の必要性を否定する**
という日本の戦略と整合している。

## 7. 政策の軸は「養殖の成長産業化」（2026年6月）

**2026年6月5日**、水産庁が**令和7年度 水産白書**を公表した。
特集テーマは**「養殖業の成長産業化に向けた対応」**で、次の内容が扱われている。

- 養殖技術立国の確立に向けた**育種**（品種改良）や**輸出拡大**の取組
- **ウナギの完全養殖**に関する取組
- ワシントン条約をめぐる国際的な情勢
- 養殖業の今後の可能性（**陸上養殖**など）

トピックスとして、漁業共済の機能強化、近代捕鯨の歴史、**IUU漁業撲滅**、**水産業の担い手確保**が並ぶ。

### 陸上養殖への投資は続いている

| 案件 | 内容 | 時点 |
| --- | --- | --- |
| 三重県の大型施設 | 世界最大級のアトランティックサーモン陸上養殖施設。総事業費約700億円とも報じられ、2027年末頃からの出荷を目指して建設中 | 2026年5月・報道 |
| FRDジャパン（千葉県富津市） | 富津ファームの部分引き渡しが完了し、本格生産を開始 | 2026年2月 |
| ピュアサーモンジャパン | 1億8,000万米ドル超の優先ノートによる資金調達を完了 | 2026年・発表 |
| 国内サーモン全体 | 2026年の国内生産量は、過去最多だった前年からさらに1割増える見込みと報じられる | 2026年・報道 |

陸上養殖は**固定費（減価償却＋電気代）が重い装置産業**である。
**魚価が下がるか電力価格が上がると一気に採算が崩れる**構造を抱えたまま、投資が先行している。
2027〜2028年にこれらの施設が一斉に出荷を始めたとき、**国内サーモン相場がどうなるか**が次の論点になる。

## 8. 水産物輸出は過去最高、ただし円安と輸入超過は変わらず（2026年2月公表）

| 指標 | 2025年 | 前年比 |
| --- | --- | --- |
| 農林水産物・食品の輸出額 | **1兆7,005億円** | 12.8%増 |
| うち農産物 | 1兆1,008億円 | 12.1%増 |
| うち**水産物** | **4,231億円** | **17.2%増** |
| うち林産物 | 735億円 | 10.1%増 |
| ホタテ貝（生鮮など） | 906億円 | 30.4%増 |
| ブリ | 528億円 | 27.4%増 |

輸出先は1位アメリカ、2位香港、3位台湾。
一方で**2025年の水産物輸入額は約1兆9,626億円**と報じられており、
**輸出の4倍以上を輸入している**構造は変わっていない。
サケ・マスの輸入単価は2016年の1kgあたり約780円から2025年には約1,370円に上昇した一方、
**数量は約22万トンでほぼ横ばい**（民間データ集計）。つまり**円安と国際価格上昇で金額だけが膨らんでいる**。

## 9. 全体の構図（まとめ）

1. **資源管理は確実に前進した**。クロマグロの増枠合意は、規制を我慢すれば資源が戻るという実例を示した。
   TAC対象魚種も拡大が続く（2024年マダラ、2025年カタクチイワシ・ブリ）
2. **それでも国内生産は減り続ける**。海面漁業は7年連続減。理由は資源だけでなく、
   漁業就業者が20年で半減（2023年 12.1万人、平均年齢57.1歳）したことにある。**人の問題が資源の問題を追い越しつつある**
3. **政策の主役は養殖に移った**。2026年の水産白書の特集が養殖であること、陸上養殖に巨額の民間投資が入っていることがその証拠。
   ただし養殖は餌（魚粉）と電力という**輸入・相場に依存する原価構造**を抱えており、自給率の話とは単純につながらない
4. **外交が損益項目になった**。中国の禁輸と再停止、ワシントン条約のウナギ提案。
   **「良い魚を安く作る」だけでは経営が守れない**産業になっている
5. **金額は伸びるが数量は伸びない**。輸出額も輸入額も過去最高圏だが、量はむしろ減っている。
   **単価上昇で膨らんだ数字を「成長」と読み違えない**ことが、この業界の数字を読む最大のコツである

## 10. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **ALPS処理水** | 福島第一原発の汚染水を多核種除去設備で処理した水。2023年8月の海洋放出が中国の禁輸の引き金になった |
| **WCPFC / IATTC** | 中西部太平洋まぐろ類委員会／全米熱帯まぐろ類委員会。太平洋のマグロ資源を管理する国際機関 |
| **産卵親魚量** | 卵を産める成熟した魚の総量。資源の健康状態を測る基本指標。クロマグロは1961年約16万トン → 2010年約1万トン |
| **暖水塊（だんすいかい）** | 周囲より水温の高い海水の塊。サンマなどの回遊経路を妨げ、不漁の一因とされる |
| **魚粉（フィッシュミール）** | 小魚を煮て搾り乾燥・粉砕した飼料原料。養殖の原価の6〜7割を占める餌の主原料 |
| **アンチョベータ** | ペルー沖のカタクチイワシ。世界の魚粉原料の中心。エルニーニョで極端な不漁になる |
| **CITES（ワシントン条約）** | 絶滅のおそれのある野生動植物の国際取引を規制する条約。附属書IIに載ると輸出国の許可が必要になる |
| **シラスウナギ** | ウナギの稚魚。ウナギ養殖の出発点で、いまも天然採捕に依存する。2025年12月から水産流通適正化法の対象 |
| **水産流通適正化法** | IUU漁業由来の水産物の国内流通を防ぐ法律（2022年12月施行）。漁獲番号の伝達・記録を義務づける |
| **TAC（漁獲可能量）** | 魚種ごとの年間漁獲上限。2024年からマダラ、2025年からカタクチイワシ・ブリが対象に追加 |
| **長期漁海況予報** | 水産研究・教育機構が発表する、漁期前の資源分布・来遊量の見通し。サンマ・スルメイカなどで注目される |
