# ③ 構造問題

このノートで分かること：**乳業と酪農がいま直面している、簡単には解けない5つの問題**。
酪農家の減少、飼料高、数年おきに逆転する「牛乳余り」と「牛乳不足」、
チーズの輸入依存、そして代替ミルクと人手不足。

---

## 1. 結論：供給も需要も同時に縮んでいて、しかもタイミングが合わない

乳業の構造問題は、次の一文に集約できる。

> **生乳の供給能力は年単位でしか動かせないのに、需要は月単位で動く。
> そのズレが、数年おきに「牛乳が足りない」と「牛乳が余る」を交互に発生させる。
> そしてその調整コストは、最も立場の弱い酪農家に集中する。**

```
【なぜ需給が振れ続けるのか（増産・減産サイクル）】

  ① 牛乳が足りない ──▶ 国が増産を呼びかける／乳価が上がる
                              │
                              ▼
  ② 酪農家が増産投資（牛を増やす・牛舎を建てる）
                              │   ※牛が乳を出すまで約2年かかる
                              ▼
  ③ 2年後、生乳が増える ──▶ ところが人口減・値上げで需要は減っている
                              │
                              ▼
  ④ 生乳が余る ──▶ 脱脂粉乳の在庫が積み上がる／減産を要請される
                              │
                              ▼
  ⑤ 酪農家が牛を処分・離農 ──▶ 数年後にまた供給不足へ ──▶ ①へ戻る

  このサイクルの周期はおおむね5〜8年。一巡するたびに酪農家の戸数が減っていく。
```

生乳の増産には牛を増やす必要があり、**子牛が生まれて搾れるようになるまで約2年**かかる。
一方、値上げによる買い控えは**翌月から起きる**。この時間差が埋まらないのが乳業の宿命である。

---

## 2. 酪農家の減少と生乳生産量の長期減少

### 2.1 数字で見る縮小

| 指標                         | 数値                                            | 時点・出典                                                                           |
| ---------------------------- | ----------------------------------------------- | ------------------------------------------------------------------------------------ |
| 酪農家戸数                   | **9,251戸**（前年度比 **▲500戸**）              | 2025年度末。中央酪農会議まとめ、日本農業新聞報道                                     |
| 1万戸割れ                    | 2024年に1万戸を下回った                         | 中央酪農会議                                                                         |
| 生乳生産量（2026年度見通し） | **731万トン**（2025年度比 **▲1.2%**）へ上方修正 | 2026年6月。日本経済新聞報道。当初のJミルク見通しは約725万トンで**3年ぶりの減産**予想 |
| うち北海道                   | **427万トン**（▲0.6%）                          | 2026年度見通し                                                                       |
| うち都府県                   | **303万トン**（▲1.9%）                          | 2026年度見通し                                                                       |
| 生乳生産量（月次）           | 2026年6月は前年同月比 **▲1.3%**                 | 日本経済新聞報道                                                                     |

読み方のポイント。

- **戸数の減り方（年5%前後）に比べ、生産量の減り方（年1%前後）は緩い。**
  残った経営体が規模を拡大して補っているから。つまり **「少数の大規模経営への集約」** が進んでいる。
- ただし**集約には限界がある**。1戸が100頭から200頭に増えるには牛舎・搾乳ロボット・
  人手が必要で、そこに投資できる経営はもう多くない。
- **都府県の減り方が北海道より速い**。都府県は飲用向けが中心で規模が小さく、
  後継者不在と住宅地化（臭気・環境への苦情）で廃業しやすい。
  都府県の生産が細るほど、飲用乳の供給を北海道からの長距離輸送に頼ることになり、
  物流コストが増える（→ [①](01_生乳という原料の特殊性.md) 集送乳調整金）。

```
【酪農経営が減っていく道筋】

  飼料・燃料・資材の高騰 ─┐
  乳価は交渉で後追い     ─┼─▶ 手取りが減る ─┬─▶ 借入返済が苦しい ─▶ 離農
  金利・建設費の上昇     ─┘                   │
                                               ├─▶ 後継者が継がない ─▶ 廃業
  ＋ 365日休めない労働                         │
  ＋ 家族経営で代替要員がいない                └─▶ 牛を減らす（早期淘汰）
                                                        │
                                                        ▼
                                             数年後、生乳が足りなくなる
```

### 2.2 飼料高騰という直撃弾

酪農の生産費のうち**飼料費が最大の項目**で、畜種の中でも酪農は飼料費比率が最も高い。
そして日本の配合飼料の原料（とうもろこし、大豆かすなど）はほぼ輸入なので、
**国際相場と為替に完全に握られている**。

| 指標                                      | 数値                                                                         | 時点・出典                                    |
| ----------------------------------------- | ---------------------------------------------------------------------------- | --------------------------------------------- |
| JA全農 配合飼料供給価格（2026年1〜3月期） | 全畜種平均で1トンあたり **+4,200円（+5.1%）**、新価格は平均 **約8万6,050円** | JA全農発表・報道ベース。4四半期ぶりの引き上げ |
| 酪農への負担                              | 畜種別で酪農が最も重く、**+10.6%** と報じられる                              | 2026年。報道ベース                            |

**配合飼料価格安定制度**（国と生産者が積み立てた基金で値上がり分の一部を補塡する仕組み）が
あるため全額が経営を直撃するわけではないが、**補塡は値上がり分の一部にとどまり、
基金が枯渇すれば機能しない**。2022年以降の高騰局面では基金の積み増しが繰り返された。

→ 飼料そのものの仕組みは [畜産・飼料](../13_畜産・飼料/README.md)

## 3. 「牛乳余り」と「牛乳不足」が数年で入れ替わる

日本の乳業を外から見て最も理解しにくいのがこれである。
**2014年前後はバター不足で店頭から消え、2022〜2023年は生乳が余って廃棄が議論され、
2026年は再び脱脂粉乳の在庫過剰が最大の課題になっている。**

| 時期         | 状況                               | 何が起きたか                                                                                                                                    |
| ------------ | ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| 2014年前後   | **バター不足**                     | 猛暑と高齢化で生乳生産が落ち、店頭からバターが消えた。国が輸入枠を追加                                                                          |
| 2015〜2019年 | 増産局面                           | 国と業界が「生産基盤の回復」を掲げ、酪農家が増産投資（牛舎・牛の導入）                                                                          |
| 2020〜2021年 | **コロナで需要が消える**           | 学校給食の休止、外食・インバウンドの消滅。生乳が行き場を失い、脱脂粉乳の在庫が急増                                                              |
| 2022〜2023年 | **牛乳余り＋コスト急騰の同時発生** | 「余っているのに乳価は上げざるを得ない」という最悪の組み合わせ。減産要請と乳用牛の早期淘汰支援が行われた                                        |
| 2024〜2025年 | 需給がやや締まる                   | 生産減少と飲用需要の下げ止まり。2025年8月に飲用乳価 +4円                                                                                        |
| **2026年**   | **再び余剰へ**                     | 値上げで牛乳消費が落ち込み、脱脂粉乳在庫が2026年2月末で **75,961トン（前年同期比+41%）**。2026年度は3年ぶりの減産見通しだが、在庫は高水準が続く |

> ポイント：**「牛乳が余っている」と「牛乳が足りない」は、どちらも同じ原因から出る。**
> 生乳の供給は2年遅れで反応し、需要は即座に反応する。
> 供給が需要に追いつく頃には、需要はもう別の水準に移っている。

### 対策の限界

Jミルクは乳業と酪農の双方が拠出する基金で **酪農乳業需給変動対策特別事業** を発動し、
過剰在庫の脱脂粉乳を**飼料向けなどに値引きして転用**している。
ただしこれは在庫を減らすだけで、需要を増やしてはいない。
報道では、この基金は初年度に大半を使い切り、拠出金が倍増されたとされる。

## 4. 学校給食という需要 ― 数量の下支えであり、弱点でもある

**学校給食用牛乳供給事業**により、全国の小中学校に牛乳が毎日供給されている。
これは乳業にとって、**価格は安いが、数量が確実に読める貴重な需要**である。

| 学校給食牛乳の性質     | 意味                                                                   |
| ---------------------- | ---------------------------------------------------------------------- |
| **入札で決まる**       | 都道府県単位の入札。価格競争が厳しく、利幅は極めて薄い                 |
| **数量が安定**         | 児童生徒数 × 授業日数で計算でき、需要予測が要らない                    |
| **地域乳業の生命線**   | 中小・地域乳業にとって売上の柱。ここを失うと工場の稼働率が維持できない |
| **長期休暇に消える**   | 夏休み・冬休みに需要がゼロになる。この期間は生乳が余りやすい           |
| **少子化で確実に減る** | 児童生徒数に完全比例するため、構造的に縮小する                         |

2020年のコロナ休校で「給食が止まると生乳が余る」ことが全国に可視化された。
近年はさらに、**給食費の高騰で「牛乳を外すべきでは」という議論**も出ている。
報道によれば和歌山市では牛乳1本が70円となり、給食費（自校調理で1人1食282円）の
**約25%を牛乳が占める**状況が議論の背景になったとされる。

> 学校給食は「守られた需要」に見えて、実際は**少子化・給食費・献立論争という3方向から削られる需要**である。
> 地域乳業ほどここへの依存が高く、縮小の影響を強く受ける。

→ [給食・フードサービス](../21_給食・フードサービス/README.md)

## 5. チーズの輸入依存とEPA

日本のチーズ消費は伸びているが、**その伸びの多くを輸入が取っている**。理由は単純で、
**国産の原料乳（チーズ向け乳価）でも、輸入チーズより高くなってしまう**からである。

```
【チーズだけが国産化しにくい理由】

  牛乳・ヨーグルト        チーズ
  ─────────        ────
  液体・要冷蔵          → 固体・長期保存可能
  海を越えられない      → 船で世界中から運べる
  ＝ 国産しか選べない    → ＝ EU・オセアニア産と直接競合
                            （放牧中心で生産コストが日本より格段に安い）
  ↓                        ↓
  国内需給で乳価が決まる  国際相場に合わせないと売れない
                          ＝ チーズ向け乳価を安くするしかない
                          ＝ 安い乳価では酪農家が作りたがらない
                          → 国産ナチュラルチーズが増えない
```

**日EU・EPA（2019年2月発効）** の内容。

| 品目                                             | 扱い                                                                                                   |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------ |
| ゴーダ・チェダーなど**ハード系ナチュラルチーズ** | 発効前は最大 **29.8%** の関税。**16年目までに段階的に撤廃**（＝2034年前後に無税）                      |
| カマンベール等の**ソフト系チーズ**               | 完全撤廃せず、**関税割当（低関税で入れられる数量枠）**を設定。枠は国産の生産拡大と両立する範囲に抑えた |
| プロセスチーズ                                   | 段階的な関税削減                                                                                       |

（農林水産省「日EU・EPAにおける農林水産物の交渉結果概要」）

つまり、**ハード系チーズの関税は時間をかけて消えていく**。
国産チーズは「関税に守られている間に競争力をつける」という宿題を負っており、
その猶予は残り10年を切っている。
国産の活路は、**ブランド化した高付加価値チーズ**と、
輸入では代替しにくい**フレッシュチーズ（モッツァレラ等）・業務用の鮮度品**にあるとされる。

なお、CPTPP（TPP11）でも同様にチーズの段階的な関税削減が進んでおり、
**チーズは日本の乳製品で最も国際競争にさらされている分野**である。

## 6. 代替ミルク（植物性飲料）の台頭

**代替ミルク（植物性ミルク）** とは、豆乳・アーモンドミルク・オーツミルクなど、
植物原料から作った乳白色の飲料のこと。牛乳の直接の競合である。

| 指標                                   | 数値                                                                  | 時点・出典                                       |
| -------------------------------------- | --------------------------------------------------------------------- | ------------------------------------------------ |
| 豆乳類の生産量（2026年1〜6月）         | **229,648kL**（前年同期比 **+10.6%**）。上期として過去最高            | 2026年。日本食糧新聞報道                         |
| 植物性ミルク市場（日本の乳製品代替品） | 2026年 **約15.6億ドル**（2025年 約14.8億ドル）、2031年 約20.5億ドルへ | 調査会社の推計（Mordor Intelligence 系レポート） |
| オーツミルク                           | 急成長の後、**2026年上期は前年割れ**。一巡感が指摘される              | 2026年。日本食糧新聞報道                         |

構図の読み方。

- **脅威の本体は「量」ではなく「棚」**。植物性ミルクの数量は牛乳類（2025年度見通しで約436万kL）
  に比べればまだ小さい。しかし**チルド飲料の棚を奪う**ため、牛乳の露出が減る影響は数量以上に大きい。
- **豆乳とアーモンドが2強**で、オーツミルクは成長が一巡。
  「第3のミルク」として一気に伸びたが、定着には価格と用途の再定義が要るとされる。
- **乳業自身が植物性に出ている**。明治・森永乳業・雪印メグミルクとも
  アーモンド飲料やオーツ系飲料を手がけており、「敵に回る」よりも「自社で取り込む」戦略を取っている。
- 植物性ミルクは**常温保存できる製品が作りやすい**ため、
  牛乳の弱点であるコールドチェーンの制約を受けにくい。これが構造的な強みになっている。

→ [フードテック](../../01_注目テーマ/13_フードテック/README.md)／[清涼飲料](../09_清涼飲料/README.md)

## 7. 人手不足と工場再編

### 7.1 現場が人を集められない

| 場所           | 人手不足の形                                                                             |
| -------------- | ---------------------------------------------------------------------------------------- |
| **酪農現場**   | 365日休みがない。搾乳は朝晩2回。外国人材（特定技能）への依存が進むが、住環境の整備が要る |
| **乳業工場**   | 夜間作業が前提。衛生管理も厳しく、人を集めにくい                                         |
| **集乳・配送** | 大型免許を持つドライバーの不足。2024年問題で拘束時間の上限も厳しくなった                 |
| **宅配**       | 乳業の伝統チャネルだが、配達員の高齢化で縮小                                             |

### 7.2 大手の設備投資は「北海道への集約」に向かっている

生乳の供給が北海道に偏り、都府県の生産が細っていることを受け、
大手は**北海道東部（根釧地域）に大型工場を集中投資**している。報道ベースの主な案件。

| 企業                       | 投資           | 内容                                                                          |
| -------------------------- | -------------- | ----------------------------------------------------------------------------- |
| **明治**                   | 約 **480億円** | 北海道中標津町に新工場（根釧工場）。**2027年3月稼働予定**                     |
| **雪印メグミルク**         | 約 **475億円** | 中標津工場の拡張に着手                                                        |
| **森永乳業**               | 約 **147億円** | 北海道恵庭市に「北海道えにわ工場」を建設                                      |
| **雪印メグミルク（関東）** | —              | 川越工場（埼玉県）の生産を **2028年度上期めど**に終了し、関東の生産体制を再編 |

（日本経済新聞・酪農乳業速報などの報道ベース。金額・時期は変更されうる）

> ここに乳業の将来像が出ている。
> **「北海道で大量に作って乳製品にし、都府県では工場を減らして飲用に特化する」**という再配置。
> 一方でこれは、**都府県の生乳が減ったとき飲用の供給を北海道に頼る度合いが上がる**ことも意味し、
> 輸送コストと災害時のリスク（北海道の一工場が止まると全国に響く）が高まる。

---

## 8. まとめ：この章を理解する3つの鍵

1. **供給は2年遅れ、需要は即時。** この時間差が増産・減産サイクルを生み、
   一巡するたびに酪農家が減る。構造問題の根はすべてここにある。
2. **輸入と競合するかどうかで運命が分かれる。** 飲用は守られるが人口減で縮む。
   チーズは関税撤廃が進み、守りが外れていく。代替ミルクは常温流通という強みで棚を取りにきている。
3. **投資は北海道に集約されつつある。** 効率化である一方、
   飲用を長距離輸送に頼る構造への転換であり、新しいリスクも作っている。

## 用語メモ

| 用語                           | 意味                                                                                                                     |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------ |
| **増産・減産サイクル**         | 不足→増産要請→2年後に供給増→需要減で余剰→減産・淘汰→数年後に再び不足、という周期。生乳が搾れるまで約2年かかることが原因  |
| **配合飼料価格安定制度**       | 国と生産者が積み立てた基金で、配合飼料の値上がり分の一部を補塡する仕組み。全額は埋まらず、基金が尽きれば機能しない       |
| **早期淘汰**                   | 生乳が余る局面で、乳用牛を通常より早く処分すること。国が支援金を出した年もある。供給を減らせるが、数年後の不足要因になる |
| **学校給食用牛乳供給事業**     | 学校給食に牛乳を供給する制度。都道府県単位の入札で供給者が決まる。地域乳業の売上の柱                                     |
| **日EU・EPA**                  | 2019年2月発効の経済連携協定。ゴーダ・チェダー等のハード系チーズは16年目までに関税撤廃、ソフト系は関税割当                |
| **関税割当**                   | 一定数量までは低い関税で輸入でき、それを超えると高い関税がかかる仕組み。国内生産と輸入の折り合いをつける手段             |
| **代替ミルク（植物性ミルク）** | 豆乳・アーモンドミルク・オーツミルクなど植物原料の乳白色飲料。常温流通できるのが牛乳に対する構造的な強み                 |
| **根釧（こんせん）地域**       | 北海道東部の根室・釧路地方。日本最大の酪農地帯で、大手乳業の大型工場投資が集中している                                   |
| **特定技能**                   | 一定の技能を持つ外国人材の在留資格。農業分野に酪農も含まれ、酪農現場の労働力として比重が高まっている                     |
