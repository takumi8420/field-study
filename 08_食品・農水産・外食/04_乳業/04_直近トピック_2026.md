# ④ 直近トピック（2026年9月時点）

報道ベースの整理。数値は一次情報で裏取りすること。
「〜と報じられる」「推計」と書いたものは確定事実と区別して読む。

このノートで分かること：**2026年の乳業は「乳価を上げたら牛乳が売れなくなった」という
一点に収斂している**。据え置きに転じた乳価、積み上がる脱脂粉乳、北海道への大型投資、
そして酪農家の減少が同時に進んでいる。

---

## 1. 2026年度の飲用乳価は「据え置き」で決着 ― 2年ぶり

**2026年1月23日**、関東生乳販連は、明治・森永乳業・雪印メグミルクなど乳業大手と協議し、
**2026年度（2026年4月〜）の飲用向け・発酵乳向け生乳価格を据え置き**で合意したと明らかにした。
据え置きは**2年ぶり**である。北海道の **ホクレン** も、加工用・集団向けを除く飲用乳価を
2026年度は据え置くことで決着した。

### なぜ上げられなかったのか

| 要因                 | 中身                                                                               |
| -------------------- | ---------------------------------------------------------------------------------- |
| **前回値上げの反動** | 2025年8月に飲用向けを **+4円/kg** 引き上げた結果、**牛乳の消費が落ち込んだ**       |
| **需給の悪化懸念**   | さらに上げれば消費がもう一段落ち、生乳が余る。**脱脂粉乳の在庫が増えるだけ**になる |
| **乳業側の余力**     | 値上げを店頭に転嫁しきれず、メーカーも量を減らしたくない                           |

**飲用乳価の推移（関東生乳販連の例）**

| 時期         | 改定                                                   |
| ------------ | ------------------------------------------------------ |
| 2022年11月   | +10円/kg                                               |
| 2023年8月    | +10円/kg                                               |
| 2024年度     | 据え置き                                               |
| 2025年8月    | **+4円/kg**（2年ぶりの引き上げ。ホクレンも同月・同額） |
| **2026年度** | **据え置き**（2026年1月23日合意）                      |

```
【2026年の袋小路】

  飼料・燃料・資材が高い ──▶ 酪農家は乳価を上げてほしい
                                    │
                                    ▼
                          乳価を上げる（2025年8月 +4円）
                                    │
                                    ▼
                          店頭の牛乳が値上がりする
                                    │
                                    ▼
                          消費者が買う量を減らす
                                    │
                                    ▼
                          生乳が余る／脱脂粉乳の在庫が増える
                                    │
                                    ▼
                          「これ以上は上げられない」＝2026年度は据え置き
                                    │
                                    ▼
                          酪農家の手取りは改善しないまま
                          コストだけ上がり続ける ──▶ 離農が続く
```

> ここが2026年の乳業を理解する出発点。
> **「値上げできない理由」は小売の反対ではなく、消費者が実際に買わなくなったことにある。**
> 加工食品全般が値上げを重ねるなか（→ [総合食品⑤](../01_総合食品/05_直近トピック_2026.md)）、
> 牛乳は**代替品（水・お茶・植物性ミルク）に逃げられやすい**ため、価格弾力性が高い。

## 2. 脱脂粉乳の在庫が再び膨らんだ ― 2026年2月末で前年比+41%

生乳が余った分は保存のきく**脱脂粉乳**になる。その在庫が2026年に再び高水準に戻った。

| 指標                   | 数値                                  | 時点・出典                    |
| ---------------------- | ------------------------------------- | ----------------------------- |
| 脱脂粉乳在庫           | **75,961トン**（前年同期比 **+41%**） | 2026年2月末。日本経済新聞報道 |
| 2026年度末の在庫見通し | **83,300トン**（前年比 **+19.8%**）   | Jミルク需給見通し・報道ベース |
| 対策を織り込んでも     | **8万トン超**が残る見込みと報じられる | 2026年。酪農乳業速報          |

構図は [①](01_生乳という原料の特殊性.md) と [③](03_構造問題.md) のとおりで、
**バターやクリームの需要は堅調なのに、脱脂粉乳だけが余る**。
1つの生乳からバターと脱脂粉乳が同時にできてしまうため、
バター需要に合わせて生乳を回すと脱粉が必ず積み上がる。

**対策**：Jミルクは乳業・酪農の双方が拠出する基金による **酪農乳業需給変動対策特別事業** を
発動し、過剰な脱脂粉乳を**値引きして飼料向けなどに転用**している。
ただし報道では、この基金は初年度に大半を使い切り、拠出金が倍増されたとされる。
在庫は減っても**需要が増えたわけではない**点に注意。

日本経済新聞は、需要創出の試みとして脱脂粉乳を原料にした「ミルク繊維」などの
新用途開発が模索されていると報じている。

## 3. 生乳生産は3年ぶりの減産へ ― 2026年度 731万トン（▲1.2%）

| 指標                              | 数値                                                    | 時点・出典                                        |
| --------------------------------- | ------------------------------------------------------- | ------------------------------------------------- |
| 2026年度 生乳生産量見通し（当初） | 約 **725万トン**。**3年ぶりの減産**転換                 | 2026年1月30日公表。Jミルク／農林水産省 需給見通し |
| 同（上方修正後）                  | **731万トン**（2025年度比 **▲1.2%**）                   | 2026年6月。日本経済新聞報道                       |
| うち北海道                        | **427万トン**（▲0.6%）                                  | 2026年度見通し                                    |
| うち都府県                        | **303万トン**（▲1.9%）                                  | 2026年度見通し                                    |
| 月次実績                          | 2026年6月は前年同月比 **▲1.3%**                         | 日本経済新聞報道                                  |
| 酪農家戸数                        | **9,251戸**（前年度末比 **▲500戸**）。9,000戸割れが目前 | 2025年度末。中央酪農会議まとめ                    |

読み方。

- **上方修正の理由は「酪農家の生産意欲が強かった」**と報じられた。
  2025年8月の乳価引き上げが、少なくとも一時的には増産インセンティブになった。
- ところが**牛乳消費が減っているため、生乳には余剰感**が残る。
  つまり「生産は減っているのに余っている」という状態で、
  減産のスピードが需要の落ち方に追いついていない。
- **都府県の減り方（▲1.9%）が北海道（▲0.6%）の3倍**。飲用向けの供給基盤が
  都府県から失われつつあり、長期的には飲用乳の長距離輸送依存が強まる。

## 4. 飼料価格は2026年も高止まり ― 1〜3月期は4四半期ぶりの値上げ

| 指標                                      | 数値                                                                      | 時点・出典                                        |
| ----------------------------------------- | ------------------------------------------------------------------------- | ------------------------------------------------- |
| JA全農 配合飼料供給価格（2026年1〜3月期） | 全畜種平均 **+4,200円/トン（+5.1%）**、新価格は平均 **約8万6,050円/トン** | JA全農発表・報道ベース。**4四半期ぶりの引き上げ** |
| 値上げ要因                                | 穀物相場に加え、**円安による輸入コスト上昇**                              | 2026年。報道ベース                                |
| 畜種別の負担                              | **酪農が最も重く +10.6%** と報じられる                                    | 2026年。報道ベース                                |

酪農は畜種の中で**最も飼料費比率が高い**。そこに乳価据え置きが重なるため、
2026年度の酪農経営は「収入は横ばい、費用は増加」という形になる。

**配合飼料価格安定制度**による補塡はあるが、値上がり分の全額を埋めるものではない。
「補塡があるから大丈夫」と読むのは誤りで、**生産者の負担は確実に増えている**。

> 2026年の酪農の姿を一行で言えば、
> **「乳価は据え置き、飼料は値上げ、戸数は年500戸ペースで減少」**。
> これが乳価改定と酪農経営の動向の核心である。

**読み取れること。**

> 2026年には熊本地震による乳業工場への影響も業界紙で報じられており、拠点集中のリスクは現実の論点になっている。

## 6. 需要側の変化 ― 機能性は「特化型」へ、植物性ミルクは過去最高

### 6.1 機能性ヨーグルト

- 訴求が **「万能型」から「特化型」へ**移行。「免疫」「脂肪」「血糖値」など
  特定の領域を前面に出す商品設計が増えたと報じられる（食品産業新聞社ニュースWEB）。
- **ドリンクタイプは2026年4〜7月の販売が前年同期を上回った**。
  値上げ局面でも、1回で飲み切れる容量と価格のバランスが支持されたと分析されている。
- 明治は **LG21** を2026年4月上旬から順次リニューアル（風味改良・賞味期限延長）し、
  砂糖・甘味料不使用の「LG21無添加」を4月14日に新発売した（2026年3月23日プレスリリース）。
  **賞味期限の延長**は、物流負担と廃棄の削減にも効く施策である。

### 6.2 植物性ミルク

| 指標                           | 数値                                                                  | 時点・出典       |
| ------------------------------ | --------------------------------------------------------------------- | ---------------- |
| 豆乳類の生産量（2026年1〜6月） | **229,648kL**（前年同期比 **+10.6%**）。**上期として過去最高**        | 日本食糧新聞報道 |
| 構図                           | **豆乳・アーモンドの2強**。オーツミルクは2026年上期に前年割れで一巡感 | 同上             |
| 日本の乳製品代替品市場         | 2026年 約 **15.6億ドル**（2025年 約14.8億ドル）→2031年 約20.5億ドル   | 調査会社の推計   |

牛乳が値上げで数量を落とす一方、**植物性ミルクは上期過去最高**という対照が2026年の特徴である。
数量規模ではまだ牛乳に遠く及ばないが、**チルド飲料の棚を奪う**という意味で
乳業への影響は数量以上に大きい。乳業各社自身も植物性飲料を手がけており、
「奪われる」のではなく「自社で取り込む」構えを見せている。

## 7. 学校給食という論点が再燃している

給食費の高騰を背景に、**「学校給食の牛乳は必要か」という議論**が一部自治体で表面化した。
報道によれば、和歌山市では牛乳1本が **70円** となり、
給食費（自校調理で1人1食 **282円**、共同調理で **275円**）の **約25%** を牛乳が占める状況が
議論の背景になったとされる。「和食に合わない」という献立論も併せて語られている。

乳業側から見ると、学校給食は**価格は安いが数量が確実に読める需要**であり、
とくに地域乳業にとっては工場稼働率を支える生命線である
（→ [③ 構造問題](03_構造問題.md) 第4章）。
少子化で構造的に減っていく需要に、**給食費という新しい削減圧力**が加わった形になる。

## 8. 全体の構図

```
【2025年8月〜2026年9月に何が起きたか】

  2025/ 8月  飲用乳価 +4円/kg（2年ぶりの引き上げ。関東・ホクレン）
      │        ▼
      │      店頭の牛乳が値上がり ──▶ 消費が落ち込む
      ▼
  2026/ 1/23 2026年度の飲用・発酵乳向け乳価は「据え置き」で合意（2年ぶり）
      │  1/30 Jミルクが需給見通しを公表：26年度は3年ぶり減産（当初約725万トン）
      │  1〜3月 JA全農の配合飼料価格 +5.1%（4四半期ぶりの引き上げ）
      │  2月末  脱脂粉乳在庫 75,961トン（前年同期比 +41%）
      ▼
  2026/ 5月  大手3社の26年3月期決算：飲用依存度で明暗が分かれる
      │  6月  26年度生乳生産を731万トン（▲1.2%）へ上方修正
      │  6月  月次生産は前年同月比 ▲1.3%（生産抑制が進む）
      │  8月  乳業大手が北海道東部に工場を増設・集約と報じられる
      ▼
  2026/ 9月  「乳価は据え置き、飼料は値上げ、戸数は年▲500戸」が続く
```

2026年9月時点の乳業を、5行でまとめるとこうなる。

1. **乳価は据え置きに転じた。** 2025年8月の+4円で牛乳消費が落ち、
   2026年度は2年ぶりの据え置き。「上げたいが上げると売れない」という袋小路に入った。
2. **余剰は脱脂粉乳に溜まっている。** 2026年2月末の在庫は前年比+41%の約7.6万トン。
   基金で飼料向けに転用しているが、需要が増えたわけではない。
3. **酪農は縮小が続く。** 戸数は2025年度末で9,251戸（年▲500戸）、
   生乳生産は2026年度に3年ぶりの減産（▲1.2%、731万トン）。飼料は2026年も値上げ。
4. **メーカーの明暗は「飲用依存度」で分かれた。** 飲用比率の高い雪印メグミルクが減益、
   海外と機能性素材を持つ森永乳業が大幅増益、明治HDは機能性ヨーグルトで堅調。
5. **投資は北海道に集約されている。** 明治480億円・雪メグ475億円・森永147億円。
   効率化と引き換えに、飲用乳の長距離輸送依存と拠点集中リスクが高まる。

> 一言でいえば、**2026年の乳業は「需要を作れていない」ことが最大の問題**である。
> 制度（補給金・指定団体）と基金は余剰を受け止められるが、
> 牛乳を飲む人を増やすことはできない。ここが構造問題の中心にある。

## 用語メモ

| 用語                             | 意味                                                                                                                 |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| **飲用乳価**                     | 牛乳など飲用に回す生乳の取引単価。輸入品と競合しないため用途別乳価の中で最も高い → [①](01_生乳という原料の特殊性.md) |
| **据え置き**                     | 乳価交渉で前年度と同じ単価にすること。2026年度の飲用・発酵乳向けがこれにあたる                                       |
| **脱脂粉乳（脱粉）**             | 生乳から脂肪を除いて乾燥させた粉。保存がきくため余剰生乳の受け皿になり、在庫量が需給の指標になる                     |
| **酪農乳業需給変動対策特別事業** | Jミルクが運営する、乳業と酪農の拠出金による基金事業。過剰な脱脂粉乳を飼料向けなどへ値引き転用して在庫を減らす        |
| **配合飼料価格安定制度**         | 配合飼料の値上がり分の一部を、国と生産者の積立基金から補塡する制度。全額は埋まらない                                 |
| **中央酪農会議（中酪）**         | 全国の指定団体などで構成する酪農の全国団体。酪農家戸数などの実態調査を公表している                                   |
| **根釧（こんせん）地域**         | 北海道東部の根室・釧路地方。日本最大の酪農地帯で、大手乳業の大型工場投資が集中する                                   |
