## このフォルダの読み方

乳業は、食品カテゴリの中で**唯一「制度」を理解しないと何も分からない**業界である。
理由はひとつで、**生乳（牛から搾ったままの乳）が他のどの食品原料とも違う性質を持つ**から。

> **毎日搾れて止められない。腐りやすくて在庫にできない。重くて遠くへ運べない。**

小麦や砂糖なら「相場が高いから買い控える」「需要が減ったから作付けを減らす」ができる。
生乳はできない。牛は毎日乳を出し、それは数日で腐り、海を越えて運ぶこともできない。
だから日本は、**指定生乳生産者団体・用途別乳価・加工原料乳生産者補給金**という
一式の制度でこの原料を受け止めてきた。乳業を理解するとは、この制度を理解することとほぼ同義である。

もうひとつの顔が、**商売としての乳業**。
牛乳は原料費比率が高く、差別化できず、毎日冷蔵で運ばなければならないため、ほとんど利益が残らない。
稼いでいるのは**ヨーグルト・チーズ・アイス・デザート**、とりわけ**機能性ヨーグルト**である。

食品メーカー共通の基礎（損益構造、値決め、商品開発、海外展開）は
[総合食品](../01_総合食品/README.md)に委ねる。ここでは**乳業に固有の話だけ**を書く。

## 1. 業界の定義・範囲

**乳業** ＝ 酪農家が生産した**生乳**を集め、殺菌・加工して
**牛乳・乳飲料・ヨーグルト・チーズ・バター・脱脂粉乳・アイスクリーム・粉ミルク**などに
して販売する産業。

本フォルダでは、**生乳を扱う川上（酪農と集乳の制度）から、乳業メーカーの商売まで**を範囲とする。

```
【乳業の位置と、隣との境界線】

  川上                                                          川下
  ──────────────────────────────────────────▶

  飼料（輸入穀物）      酪農家           ★乳業★              卸・小売
  粗飼料（牧草）   ──▶ 約9,251戸  ──▶ （本フォルダ）  ──▶  スーパー ──▶ 消費者
       │                  │          明治・森永乳業        CVS
       │                  │          雪印メグミルク        ドラッグ
  13_畜産・飼料      指定団体が        ＋中堅・地域乳業          │
                     集乳・販売                                  └──▶ 外食・給食
                     （ホクレン等）                                    （業務用）

  境界の引き方：
   ・乳牛の飼養・飼料・繁殖             → 13_畜産・飼料（酪農経営の中身）
   ・アイス、チョコ用乳原料の使い手     → 05_製菓、06_冷凍食品・惣菜
   ・乳酸菌飲料・植物性ミルクの飲料棚   → 09_清涼飲料（競合として重なる）
   ・食品メーカー共通の損益・値決め     → 01_総合食品（基礎はそちら）
```

注意すべき境界。

- **「酪農」と「乳業」は別の産業**。酪農は牛を飼って生乳を作る農業、
  乳業はそれを加工する製造業。両者は指定団体を挟んで取引関係にある。
  ただし経営の浮沈は完全に連動しているため、実務でも報道でも「酪農乳業」と一括りに語られる。
- **牛乳・加工乳・乳飲料は法令上まったく別の商品**。乳等省令（乳及び乳製品の成分規格等に関する省令）で
  成分規格が決まっており、「牛乳」と名乗れるのは生乳100%で成分無調整のものだけ。
- **チーズは半分が輸入**。国産と輸入が同じ棚で競合する、乳製品で唯一の分野
  （→ [③](03_構造問題.md) 第5章）。

成長性の読み方。

- **数量は構造的に縮む**。飲用乳の需要は人口と学校給食に比例し、どちらも減る。
  生乳生産も2026年度は3年ぶりの減産見通し。
- **金額は値上げで支えられてきたが、それも限界が見えた**。2025年8月の飲用乳価+4円で
  消費が落ち込み、2026年度は据え置きになった。
- **伸びているのは「加工の深い商品」と「輸出できる乾いた製品」**。
  機能性ヨーグルト、チルドデザート、海外向けの粉ミルク・機能性素材。
- **競合は他の乳業だけではない**。植物性ミルクが上期過去最高を更新しており、
  チルド飲料の棚をめぐる競争が激化している。

## 3. バリューチェーン（川上 → 川下）

```
【モノ・カネ・情報の流れ】

 モノ  飼料 ──▶ 酪農家 ──▶ 指定団体 ──▶ 乳業メーカー ──▶ 卸 ──▶ 小売 ──▶ 消費者
      （輸入）   （搾乳）   （集乳・配分）  （殺菌・加工）  （冷蔵）  （日配）
                                              │
                                              └──▶ 業務用（外食・製菓・給食）

 カネ  乳業 ──── 用途別乳価で支払い ────▶ 指定団体
       指定団体 ── プール乳価（平均単価）──▶ 酪農家
       国 ────── 加工原料乳生産者補給金 ──▶ 酪農家（指定団体等経由）
       Jミルク基金 ── 需給変動対策（脱粉の飼料転用等）

 情報  乳業 ◀── 用途別の必要量の提示 ── 指定団体
       指定団体 ──── 日々の需給調整（飲用が余れば加工へ）────▶ 各工場
       Jミルク ──── 需給見通しの公表（年数回）────▶ 業界全体
```

付加価値がどこに集まるか。

| 段階                                         | 経済的な特徴                                               | なぜそうなるか                                                       |
| -------------------------------------------- | ---------------------------------------------------------- | -------------------------------------------------------------------- |
| **酪農家**                                   | 売値を自分で決められない。コスト（飼料）は国際相場で決まる | 価格決定権が指定団体にあり、しかも生産量を機動的に調整できない       |
| **指定団体**                                 | 手数料ビジネス。交渉力が存在価値そのもの                   | 集約して初めて大手乳業と対等になる。需給調整という公共的な機能も担う |
| **乳業メーカー（飲用乳）**                   | 原料費が出荷価格の6割前後。営業利益はほぼ残らない          | 成分規格が同じで差別化できず、毎日冷蔵で運ぶ必要がある               |
| **乳業メーカー（発酵乳・チーズ・デザート）** | **ここが利益の源泉**。菌株・製法・ブランドで差がつく       | 加工が深いほど原料費の比率が下がり、機能性なら特許で守れる           |
| **小売**                                     | 牛乳は集客商品（目玉商品）。安く売られやすい               | 「毎日買う商品」なので価格が記憶され、値上げに敏感                   |

> ポイント：**牛乳は、バリューチェーンのどの段階でも儲からないように出来ている。**
> 酪農家は価格を決められず、メーカーは差別化できず、小売は集客のために安く売る。
> それでも作り続けるのは、生乳を毎日引き取らなければならないからである。

バターは雪印メグミルク・よつ葉が強い、チーズは輸入が半分**、という構図で捉える。

## 5. 収益モデル・コスト構造

```
【牛乳1,000mL（店頭250円前後）のコスト構造イメージ】

  店頭価格         250円
   └ 小売マージン    45〜60円
  ────────────────────
  メーカー出荷価格  190〜205円
   ├ 生乳代        110〜130円  ◀★出荷価格の6割前後。用途別乳価で決まり交渉余地が小さい
   ├ 容器（紙パック） 15〜20円
   ├ 殺菌・充填加工費 15〜20円  ◀工場の固定費。稼働率で単価が動く
   ├ 物流費（冷蔵）   20〜30円  ◀★重い・低温・毎日配送。近年最も上がっている
   ├ 販管費          15〜20円
   └ 営業利益         0〜10円   ◀★ほぼ残らない
  ※構造を示すための概算。実際は企業・チャネル・容量で大きく異なる
```

| 論点                                   | 中身                                                                                                       |
| -------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| **原料費比率が食品の中で突出して高い** | 飲用乳では出荷価格の6割前後。しかも用途別乳価は指定団体との年1回の交渉で決まり、月次で下げることはできない |
| **物流が固定的に重い**                 | 冷蔵・多頻度・重量物。工場の商圏＝運べる距離になるため、全国に工場を分散して持つ必要がある                 |
| **利益は「加工の深さ」に比例する**     | 牛乳＜プレーンヨーグルト＜機能性ヨーグルト／チーズ／デザートの順に利益率が上がる                           |
| **在庫にできない**                     | 賞味期限が短く、1/3ルールの制約も厳しい。売れ残りは廃棄が原則                                              |
| **原料は止められない**                 | 小売の発注が減っても生乳は毎日届く。余剰は自社で脱脂粉乳等に加工して抱える                                 |

詳しくは [② 乳業メーカーの商売](02_乳業メーカーの商売.md)。

## 6. 競争要因（KSF）と参入障壁

| KSF                            | 中身                                                                                   |
| ------------------------------ | -------------------------------------------------------------------------------------- |
| **コールドチェーンと工場配置** | 冷蔵で毎日運べる範囲が商圏。全国網は巨額の固定費だが、同時に**最大の参入障壁**でもある |
| **生乳の安定確保**             | 指定団体との関係。生乳が足りない局面では調達力がそのまま生産量を決める                 |
| **独自菌株と臨床エビデンス**   | 機能性ヨーグルトの本体。特許と届出で守れる、数少ない「まねできない差別化」             |
| **ブランドと習慣化**           | 「毎朝1本」という行動を作れるか。乳製品は購買頻度が高く、習慣になれば極めて強い        |
| **品質管理・安全性**           | 食中毒は一度で会社が傾く（2000年の事例）。粉ミルクではさらに要求水準が高い             |
| **業務用の規格対応力**         | 外食・製菓・給食向けの規格品と安定供給。数量は大きいが利幅は薄い                       |

**参入障壁**は免許制ではない（乳処理業・乳製品製造業は食品衛生法上の営業許可）。
実質的な障壁は **①冷蔵物流と工場への巨額投資、②指定団体から生乳を安定的に引き取る関係、
③菌株・エビデンスという研究の蓄積**の3つ。
逆に言えば、**この3つを必要としない植物性ミルク（常温流通・植物原料）は、
乳業の障壁を迂回して棚に入ってくる**。これが代替ミルクを構造的な脅威にしている理由である。

## 7. 規制・法制度

| 制度                                                 | 内容                                                                                                                                                    | 乳業への影響                                                                                          |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| **畜安法（畜産経営の安定に関する法律）**             | 加工原料乳生産者補給金制度の根拠法。2018年4月施行の改正で旧・指定団体制度（不足払い法）を廃止し、**アウトサイダーや部分委託にも補給金の交付対象を拡大** | 酪農家が売り先を選べるようになった。ただし実態は2022年時点で**94.2%が指定団体経由**（Jミルク）        |
| **加工原料乳生産者補給金**                           | 乳製品向けに出荷された生乳への国の上乗せ支払い。**2026年度は補給金 9.11円/kg、集送乳調整金 2.83円/kg、総交付対象数量 325万トン**                        | 北海道の酪農経営を成立させている前提。総交付対象数量は事実上の生産の目安になる                        |
| **乳等省令**（乳及び乳製品の成分規格等に関する省令） | 牛乳・加工乳・乳飲料・発酵乳などの成分規格、殺菌条件、容器包装、表示を規定                                                                              | 「牛乳」と名乗れる条件を決めている＝**飲用乳で中身の差別化ができない法的な理由**                      |
| **食品衛生法／HACCP**                                | 2021年6月から原則すべての食品事業者にHACCPに沿った衛生管理が義務                                                                                        | 小規模な地域乳業には設備・記録の負担が重く、廃業や委託生産の要因                                      |
| **食品表示法／機能性表示食品制度**                   | 機能性の表示は消費者庁への届出制。**2026年9月1日にGMP義務化が完全施行**                                                                                 | 機能性ヨーグルトは制度の主要な使い手。体制整備のコストが上がる → [総合食品](../01_総合食品/README.md) |
| **日EU・EPA（2019年2月発効）／CPTPP**                | ゴーダ・チェダー等ハード系ナチュラルチーズは**16年目までに段階的に関税撤廃**（発効前は最大29.8%）。ソフト系は**関税割当**で管理                         | 国産チーズの保護が時間とともに外れていく。**猶予は10年を切った** → [③](03_構造問題.md)                |
| **学校給食用牛乳供給事業**                           | 都道府県単位の入札で供給者を決め、学校へ牛乳を供給                                                                                                      | 地域乳業の売上の柱。少子化と給食費高騰で構造的に縮小                                                  |
| **配合飼料価格安定制度**                             | 国と生産者の積立基金で飼料の値上がり分の一部を補塡                                                                                                      | 酪農経営を支えるが全額は埋まらず、基金が尽きれば機能しない                                            |
| **改正物流効率化法**                                 | 2026年4月に特定事業者の指定・CLO（物流統括管理者）選任義務が施行                                                                                        | 日配品を大量に動かす乳業は荷主として該当。共同配送・納品頻度見直しが加速                              |

## 9. 用語メモ

各ノートの末尾に詳しい用語メモがある。ここでは最重要の8つ。

| 用語                               | 意味                                                                                                                                                                                               |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **生乳（せいにゅう）**             | 牛から搾ったままの乳。加熱殺菌も成分調整もしていない状態。これを殺菌したものが「牛乳」 → [①](01_生乳という原料の特殊性.md)                                                                         |
| **指定生乳生産者団体（指定団体）** | 酪農家から生乳販売を委託され、地域の生乳をまとめて集荷し、乳業メーカーと価格交渉する農協連合会。北海道はホクレン、関東は関東生乳販連 → [①](01_生乳という原料の特殊性.md)                           |
| **一元集荷多元販売**               | 地域の生乳を1か所にまとめ（一元集荷）、複数の乳業メーカーに配分して売る（多元販売）仕組み → [①](01_生乳という原料の特殊性.md)                                                                      |
| **用途別乳価**                     | 同じ生乳でも、飲用・発酵乳・チーズ・乳製品と用途ごとに取引単価を変える仕組み。**輸入品と競合しない飲用が最も高く、国際相場品のバター・脱脂粉乳向けが最も安い** → [①](01_生乳という原料の特殊性.md) |
| **プール乳価**                     | 用途別の販売代金を合計し、総生乳量で割って全酪農家に共通の単価として支払う方式。用途の当たり外れをならす → [①](01_生乳という原料の特殊性.md)                                                       |
| **加工原料乳生産者補給金**         | バター・脱脂粉乳・チーズ等の乳製品向けに出荷された生乳に国が上乗せ支払いする制度。2026年度 9.11円/kg、総交付対象数量325万トン → [①](01_生乳という原料の特殊性.md)                                  |
| **日配品（にっぱいひん）**         | 日持ちせず毎日または高頻度で店舗へ配送される商品。牛乳・ヨーグルトが代表。**物流圏がそのまま商圏になる** → [②](02_乳業メーカーの商売.md)                                                           |
| **脱脂粉乳（脱粉）**               | 生乳から脂肪を除いて乾燥させた粉。保存がきくため余剰生乳の受け皿になり、**在庫量が「牛乳が売れているか」の指標**になる → [①](01_生乳という原料の特殊性.md)／[③](03_構造問題.md)                    |
