# ② 乳業メーカーの商売

このノートで分かること：**乳業メーカーは牛乳では稼げていない**。
どこで利益を取り、なぜ物流が重荷になり、なぜ「免疫」「腸内環境」と書いたヨーグルトを
必死に売っているのか。

---

## 1. 結論：牛乳は「赤字ギリギリの義務」、稼ぎ頭はヨーグルトとチーズとデザート

乳業メーカーの損益を一言で言うと、こうなる。

> **牛乳（飲用乳）は、原料費の比率が極端に高く、差別化しにくく、毎日運ばなければならない、
> 三重苦の商品である。それでも作り続けるのは、生乳を引き取る責任と、棚と物流網を守るため。
> 利益はヨーグルト・チーズ・アイス・デザートといった「加工の度合いが深い商品」で取る。**

なぜ牛乳が儲からないのか、1本の分解で見る。

```
【牛乳1,000mL（店頭250円前後）のコスト構造イメージ】

  店頭価格         250円
   └ 小売マージン    45〜60円
  ────────────────────
  メーカー出荷価格  190〜205円
   ├ 生乳代        110〜130円  ◀★ 出荷価格の6割前後。用途別乳価で決まり交渉余地が小さい
   ├ 容器（紙パック） 15〜20円   ◀ 紙パルプ・印刷。原油と紙の相場連動
   ├ 殺菌・充填の加工費 15〜20円 ◀ 工場の固定費。稼働率で単価が動く
   ├ 物流費（冷蔵）   20〜30円  ◀★ 重い・低温・毎日配送。近年最も上がっている
   ├ 販管費          15〜20円
   └ 営業利益         0〜10円   ◀★ ほぼ残らない
  ※ 構造を示すための概算。実際の数値は企業・チャネル・容量で大きく異なる
```

対してヨーグルトやチーズは、**同じ生乳から作っても「加工賃」と「ブランド」の取り分が大きい**。
機能性をうたったヨーグルトなら、さらに研究開発費を価格に乗せられる。

| 製品                       | 原料費の重さ           | 差別化の余地                       | 利益率の目安（相対）     |
| -------------------------- | ---------------------- | ---------------------------------- | ------------------------ |
| **牛乳・乳飲料**           | 極めて重い             | 小さい（成分規格がほぼ同じ）       | 最も低い。赤字の年もある |
| **発酵乳（ヨーグルト）**   | 中                     | **大きい**（菌株・機能性・食感）   | 高い                     |
| **機能性ヨーグルト**       | 中                     | **最も大きい**（特許・臨床データ） | 最も高い                 |
| **チーズ**                 | 重い（輸入原料も使う） | 中（製法・熟成・業務用規格）       | 中〜高                   |
| **アイス・チルドデザート** | 中                     | 大きい（ブランド・季節商品）       | 高い                     |
| **育児用粉ミルク**         | 中                     | 大きい（処方・安全性・信頼）       | 高いが国内市場は縮小     |

農林水産省の乳業メーカー経営実態調査でも、**牛乳中心の中小メーカーは仕入れた生乳価格を
販売価格に十分転嫁できず利益率が低位**である一方、**大手3社はヨーグルト・チーズなど
付加価値の高い製品で相対的に高い利益率**という整理がされている。

## 3. コールドチェーンと日配品 ― 乳業の物流はなぜ重いのか

### 3.1 「日配品」であるということ

**日配品（にっぱいひん）** とは、**日持ちがせず、店舗へ毎日または高頻度で配送される商品**のこと。
牛乳・ヨーグルト・豆腐・惣菜・パンなどが該当する。乳業の主力はほぼ全部これである。

```
【日配品の物流（牛乳の一日）】

  夜〜早朝     早朝            午前            午前〜昼      翌朝
  ────     ───            ───            ──────    ───
  搾乳・集乳 ▶ 工場で殺菌・充填 ▶ 冷蔵配送センター ▶ 店舗へ納品 ▶ 売場
  （タンク      （数時間で       （5℃以下を維持）   （多頻度・     （賞味期限
    ローリー）    処理しないと                        小口配送）      〜2週間程度）
                  品質が落ちる）
                                       ↑
                            ここ全部が「冷やしたまま」＝コールドチェーン
                            温度が切れた瞬間に商品は廃棄になる
```

- **運べる距離が工場の商圏を決める。** 常温品なら1つの工場で全国に出せるが、
  牛乳は冷蔵で日々運べる範囲しかカバーできない。だから乳業は**全国に工場を分散して持つ**必要があり、
  それ自体が巨額の固定費であり、同時に**新規参入者にはまねできない参入障壁**にもなっている。
- **積載効率が悪い。** 牛乳は約88%が水で、重量あたりの価値が低い。
  同じトラック1台で運ぶ価値が、菓子や調味料に比べて小さい。
- **返品・廃棄が直撃する。** 賞味期限が短いので、売れ残りは基本的に廃棄。
  常温品のように「来月売る」ができない。

### 3.2 2024年問題以降のコスト上昇

トラックドライバーの時間外労働規制（いわゆる**2024年問題**）と人手不足で、
運賃と夜間作業の人件費が上がり続けている。乳業は
**「夜間に作って早朝に運ぶ」**という最も人を確保しにくい時間帯に依存しているため、
影響が食品の中でもとくに大きい。

その結果、大手は次のような手を打っている。

| 対応                   | 中身                                                                               |
| ---------------------- | ---------------------------------------------------------------------------------- |
| **共同配送**           | 競合同士で同じトラックに載せる。乳業3社や地域乳業との共配が広がった                |
| **賞味期限の延長**     | 殺菌・充填技術（ESL＝Extended Shelf Life）で日持ちを延ばし、配送頻度と廃棄を減らす |
| **工場の集約と大型化** | 小さい工場を閉じて大型ラインに集約。ただし商圏が広がるぶん輸送距離は伸びる         |
| **容器の軽量化**       | 紙パックの薄肉化、キャップ形状の変更                                               |

詳しくは → [陸運・トラック](../../13_運輸・物流/06_陸運・トラック/README.md)／[倉庫・3PL](../../13_運輸・物流/08_倉庫・3PL/README.md)

## 4. 賞味期限と返品 ― 「作りすぎ」がそのまま損になる

乳業は、[総合食品①](../01_総合食品/01_食品メーカーの損益構造.md) で扱った在庫リスクが
**最も過酷な形で出るカテゴリ**である。

| 論点                   | 乳業での現れ方                                                                                                                                                          |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1/3ルール**          | 製造日から賞味期限までを3等分し、最初の1/3以内に小売へ納品する商習慣。賞味期限が2週間の牛乳では**1/3＝5日程度**しかなく、実務上は「作ったらすぐ出す」以外の選択肢がない |
| **欠品ペナルティ**     | 棚を空けると小売から強く咎められる。結果として**わざと多めに作る**動機が働き、余りが発生する                                                                            |
| **需要の天気依存**     | 牛乳・ヨーグルト・アイスは気温で売れ行きが大きく振れる。予測を外すと即廃棄                                                                                              |
| **生乳側は止まらない** | 小売の発注が減っても、酪農家からの生乳は届き続ける（→ [①](01_生乳という原料の特殊性.md)）。メーカーは余った生乳を**脱脂粉乳などに回して自社で抱える**                   |

> ポイント：一般の食品メーカーは「売れなければ作らない」ができる。
> **乳業は、売れなくても原料が毎日届く。** この非対称が、乳業の在庫リスクを他業種と違うものにしている。

## 5. 機能性ヨーグルトという高付加価値化

### 5.1 なぜヨーグルトに機能性を付けるのか

牛乳は、成分規格が法令で定められているため、**中身で差別化できない**。
ヨーグルトは違う。**どの乳酸菌を使うかで効能も味も変えられ、しかも菌株は特許で守れる**。

```
【価値の積み上げ方】

  生乳 ─────────────────────────────▶ 価格
   │
   ├ 殺菌・充填しただけ          ＝ 牛乳          ：差別化ほぼ不可
   │
   ├ ＋ 発酵（一般的な乳酸菌）    ＝ プレーンヨーグルト：やや差別化
   │
   ├ ＋ 独自菌株 ＋ 臨床データ    ＝ 機能性ヨーグルト  ：★特許と表示で守れる
   │    ＋ 機能性表示食品の届出                        単価は牛乳の数倍/100mL
   │
   └ ＋ ブランド ＋ 習慣化（毎日飲む）＝ 継続購買       ：★最も強い
```

- **R-1**（1073R-1乳酸菌）＝「免疫」を軸に訴求。下期（秋冬）に需要が伸びる
- **LG21**（ラクトバチルス・ガセリOLL2716株）＝胃の健康を軸に訴求。2000年3月発売のロングセラーで、
  2026年4月に風味改良・賞味期限延長のリニューアルを実施し、砂糖・甘味料不使用タイプも追加
- 森永乳業は**ビフィズス菌（BB536など）**を自社製品に使うだけでなく、
  **素材として他社に販売するBtoBビジネス**に育てている

2026年の市場動向としては、訴求が**「万能型」から「特化型」へ**移っている（免疫、脂肪、血糖値、
睡眠など特定領域を前面に出す）と報じられる。またドリンクタイプは
**2026年4〜7月の販売が前年同期を上回った**とされ、1回で飲み切れる容量と価格のバランスが
値上げ局面で支持されたと分析されている（食品産業新聞社ニュースWEB／日本食糧新聞）。

### 5.2 機能性表示食品制度との関係

**機能性表示食品**とは、事業者が科学的根拠を消費者庁に届け出れば、
国の審査を経ずに機能性を表示できる制度（2015年開始）。
乳業はこの制度の最大の活用者のひとつである。一方で、
**2026年9月1日に施行されたGMP（適正製造規範）義務化**など規制は強化方向にある
（→ [総合食品③](../01_総合食品/03_商品開発とブランド.md)）。

> 注意点：機能性は**科学の話であると同時に、毎日の習慣を作る話**でもある。
> R-1が強いのは効能そのものより、「毎朝1本飲む」という行動が定着したから。
> 乳業の高付加価値化は、**定期購買される日用品に変えられるか**にかかっている。

## 6. 粉ミルクと海外展開 ― 国内で縮み、海外で戦う

**育児用粉ミルク（調製粉乳）** は、乳業の伝統的な高付加価値商品である。
安全性への要求が極めて高く、参入障壁も高い。日本では明治・森永乳業・雪印メグミルク・
和光堂（アサヒグループ食品）などが担ってきた。

問題は、**市場が出生数に完全に比例する**こと。日本の出生数は減り続けており、
国内の粉ミルク市場は構造的に縮小する。だから各社は海外へ出る。

| 展開の型                             | 中身                                                 | 例                                                              |
| ------------------------------------ | ---------------------------------------------------- | --------------------------------------------------------------- |
| **輸出（日本ブランドの信頼を売る）** | 日本製の安全性を武器にアジア中間層へ                 | 粉ミルク・液体ミルクのアジア向け輸出                            |
| **現地企業の買収**                   | 現地の販路と工場を丸ごと取る                         | 森永乳業の欧州事業（ドイツ子会社中心）が2026年3月期に過去最高益 |
| **素材のBtoB販売**                   | 最終製品ではなく菌・たんぱく質・乳糖などを他社に売る | 森永乳業のビフィズス菌素材、明治の機能性素材                    |
| **技術・ブランドのライセンス**       | 現地企業に製法とブランドを貸す                       | アジア各国での提携生産                                          |

**なぜ乳業の海外展開は難しいか。** 牛乳・ヨーグルトはチルド流通なので輸出しにくく、
現地に工場と冷蔵物流を持たなければならない。つまり**進出には必ず重い設備投資が伴う**。
これが、常温品を輸出できる調味料や即席麺（→ [総合食品④](../01_総合食品/04_国内成熟と海外展開.md)）
との決定的な違いで、乳業の海外比率が相対的に低い理由でもある。
逆に、**粉ミルク・粉末素材・チーズといった「乾いた製品」は輸出できる**ため、
海外展開はこの領域に集中する。

## 7. まとめ：この章を理解する3つの鍵

1. **牛乳は利益を出す商品ではなく、生乳を引き取り、棚と物流網を維持するための商品。**
   儲けはヨーグルト・チーズ・アイス・デザート・機能性で取る。
2. **物流が競争力そのもの。** 冷蔵・毎日・重量物という条件が、工場配置を決め、商圏を決め、
   新規参入を止めている。2024年問題以降はここがコスト増の最前線。
3. **成長の出口は「加工の深さ」と「乾いた製品」。** 中身で差別化できる発酵乳・機能性素材と、
   輸出できる粉ミルク・粉末素材・チーズ。液体のまま海を越えることはできない。

## 用語メモ

| 用語                           | 意味                                                                                                                           |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| **日配品（にっぱいひん）**     | 日持ちせず、毎日または高頻度で店舗へ配送される商品。牛乳・ヨーグルト・豆腐・パンなど。物流圏がそのまま商圏になる               |
| **コールドチェーン**           | 生産から店頭まで一度も温度を上げずに保つ低温物流網。切れた時点で商品は廃棄になる                                               |
| **飲用乳**                     | 牛乳・加工乳・成分調整牛乳・乳飲料など、そのまま飲む製品の総称。乳業の数量の柱だが利益は薄い                                   |
| **発酵乳**                     | 生乳を乳酸菌などで発酵させたもの。ヨーグルトが代表。乳等省令上の分類名でもある                                                 |
| **機能性表示食品**             | 事業者が科学的根拠を消費者庁に届け出ることで機能性を表示できる制度（2015年開始）。機能性ヨーグルトの多くがこれに該当する       |
| **ESL（Extended Shelf Life）** | 殺菌・充填の無菌度を高めて賞味期限を延ばす技術。配送頻度と廃棄を減らす                                                         |
| **1/3ルール**                  | 製造日から賞味期限までを3等分し、最初の1/3以内に納品する商習慣。賞味期限の短い乳製品では特に厳しい                             |
| **調製粉乳（育児用粉ミルク）** | 母乳に近い組成に調整した乳児用の粉ミルク。安全性要求が高く参入障壁も高いが、市場は出生数に比例する                             |
| **BtoB素材ビジネス**           | 最終製品ではなく、乳酸菌・ビフィズス菌・たんぱく質・乳糖などを他社に原料として売る事業。設備を持たずに機能性の知見を換金できる |
