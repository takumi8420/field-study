# ① 生乳という原料の特殊性

このノートで分かること：**なぜ乳業だけが「指定団体」「用途別乳価」「補給金」という
他の食品カテゴリに存在しない制度を抱えているのか**。その答えはすべて、
生乳（牛から搾ったままの牛の乳）という原料の物理的な性質から出てくる。

---

## 1. 結論：生乳は「止められない・腐る・遠くへ運べない」

食品原料の大半は、小麦でも大豆でもカカオでも、**乾いていて、保存でき、船で運べる**。
だから相場が下がれば買い控えられるし、需要が減れば産地が作付けを減らせばよい。

生乳はそのどれもが当てはまらない。

| 生乳の性質                     | 何が起きるか                                                                                                         |
| ------------------------------ | -------------------------------------------------------------------------------------------------------------------- |
| **毎日搾れて、止められない**   | 乳牛は搾らないと乳房炎になる。需要が減っても生産は止まらない。「今日は作らない」という選択肢が物理的に存在しない     |
| **腐りやすい（貯蔵性がない）** | 搾った生乳は冷却しても数日しかもたない。在庫として置いておけないので、**毎日必ず誰かが買って処理しなければならない** |
| **重くて水分が多い**           | 生乳は約88%が水。トンあたりの価値に対して輸送費が重く、**経済的に運べる距離が限られる**（実務上の目安は数百km圏）    |
| **品質がばらつく**             | 乳脂肪率・無脂乳固形分は季節と飼料で変わる。取引は成分に応じた精算になる                                             |

> ポイント：**「毎日出てきて、置いておけず、遠くへ運べない」**という3点セットが、
> 乳業を他の食品と決定的に違う業界にしている。
> 売れ残りを在庫にできないから、**余った分は必ず何かに変えなければならない**。
> この「必ず変えなければならない」という強制が、後述するバター・脱脂粉乳の在庫問題の正体である。

```
【生乳が他の食品原料と違うところ】

  小麦・大豆・砂糖              生乳
  ────────────              ────
  収穫は年1〜2回          →   搾乳は毎日2回、365日
  年単位で作付けを調整     →   減らすには牛を減らすしかない（＝数年かかる）
  常温で1年以上保存        →   冷蔵で数日
  船で地球の裏から運べる   →   運べるのは数百km（＝輸入できない）
  相場で売り手を選べる     →   その日のうちに引き取り手が必要

  ↓ 結果

  「需要が減っても供給が減らない」期間が必ず発生する
  → 市場に任せると価格が暴落し、酪農家が一斉に廃業する
  → だから制度で受け止める仕組みが必要になった
```

## 2. 生乳はどう流れているか

```
【生乳の流れ（モノとカネ）】

  酪農家          指定団体             乳業メーカー          小売・外食
 （約9,251戸）   （ホクレン、       （明治・森永乳業・        （消費者）
                  関東生乳販連など）    雪印メグミルクなど）

  搾乳 ──毎日──▶ 集乳（クーラー
   │              ステーション/          飲用向け ──▶ 牛乳・乳飲料 ──▶ スーパー
   │              タンクローリー）  ───┼ 発酵乳・生クリーム等向け ──▶ ヨーグルト
   │                   │                └ 乳製品（加工原料乳）向け ──▶ バター・脱脂粉乳
   │                   │                                                 チーズ
   │  ◀── プール乳価 ──┘  ◀── 用途別乳価で代金 ──┘
   │      （用途を平均した
   │        1本の単価）
   │
   └─◀── 加工原料乳生産者補給金（国） 2026年度 9.11円/kg ＋集送乳調整金 2.83円/kg

  ※ 酪農家は「どの乳業メーカーに売るか」を自分で選ばない。指定団体に委託して配分される。
```

- **酪農家（生産者）** — 2025年度末で全国 **9,251戸**（前年度比 **▲500戸**、中央酪農会議まとめ、
  日本農業新聞報道）。2024年に1万戸を割り込んだ後も減少が続いている。
- **指定団体（指定生乳生産者団体）** — 酪農家から生乳の販売を委託され、まとめて集荷し、
  乳業メーカーと価格交渉する農協連合会。北海道は **ホクレン**、関東は **関東生乳販連** など、
  ブロックごとに置かれている。
- **乳業メーカー** — 生乳を受け入れて牛乳・乳製品に加工する。大手3社（明治・森永乳業・
  雪印メグミルク）と、地域の中小乳業（数百社）に分かれる → [② 乳業メーカーの商売](02_乳業メーカーの商売.md)

## 3. 指定団体と「一元集荷多元販売」

### 3.1 何をしている組織か

**指定団体**とは、酪農家から生乳の販売を委託され、**地域の生乳をいったん全部まとめてから、
複数の乳業メーカーへ配分して売る組織**のこと。この仕組みを **一元集荷多元販売**
（いちげんしゅうか・たげんはんばい）と呼ぶ。
「集めるのは1か所（一元）、売り先は複数（多元）」という意味である。

なぜこうするのか。理由は3つある。

| 理由                    | 中身                                                                                                                           |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **①交渉力の確保**       | 1戸の酪農家が大手乳業と価格交渉しても勝負にならない。地域の生乳を束ねて初めて対等な交渉になる                                  |
| **②集送乳コストの削減** | 1戸ずつ別々のメーカーへ運ぶと輸送が非効率。地域でまとめてルートを組めば運賃が下がる                                            |
| **③需給調整**           | 飲用が余った日は加工向けへ回す、といった**日々の振り分け**を誰かがやらないと生乳が捨てられる。指定団体がその調整弁になっている |

2022年の生乳処理量に対する指定団体の販売実績比率は **94.2%**（Jミルク）。
制度が変わった今でも、実態としてはほぼ全量がこのルートを通っている。

### 3.2 2018年の制度改正 ― 「全量委託」でなくてもよくなった

かつては「指定団体に**全量**を委託した酪農家だけが補給金をもらえる」という縛りがあった。
2018年4月施行の**改正畜産経営安定法（畜安法）**で、旧・不足払い法に基づく指定団体制度は廃止され、
次のように変わった。

- 指定団体に出さない酪農家（**アウトサイダー**）や、乳業者に直接売る酪農家にも
  **補給金が交付される**ようになった（年間販売計画の提出などが条件）
- 生乳の一部だけを指定団体に委託する **部分委託** が可能になった
- 指定団体は制度上「**指定事業者**」という呼び名になったが、実務では今も指定団体と呼ばれる

> 改正の狙いは「酪農家が売り先を選べるようにして所得を増やす」こと。
> 一方で懸念されたのが **「いいとこ取り」** である。値段のよい飲用向けだけを自分で売り、
> 余った分の処理は指定団体に任せる酪農家が増えると、指定団体の需給調整機能と交渉力が弱くなる。
> 現実には94%超が指定団体経由で、構造は大きくは変わっていない。

## 4. 用途別乳価 ― なぜ飲用が高く、加工向けが安いのか

**用途別乳価**とは、**同じ生乳でも「何に使うか」によって取引価格を変える仕組み**のこと。
乳業を理解する上で最重要の概念である。

```
【用途別乳価の階段（イメージ。実際の単価は年度・地域で異なる）】

  高  ┌─────────────────┐
   │  │ 飲用向け（牛乳・乳飲料）      │ ← 輸入品と競合しない。国内需給で決まる
   │  ├─────────────────┤
   │  │ 発酵乳・生クリーム等向け      │ ← ヨーグルト、デザート、業務用クリーム
   │  ├─────────────────┤
   │  │ チーズ向け                    │ ← 輸入チーズと競合。安くないと国産が作れない
   │  ├─────────────────┤
   │  │ 乳製品向け（加工原料乳）      │ ← バター・脱脂粉乳。国際相場に引っ張られる
  安  └─────────────────┘        ＝ここが余剰の受け皿。だから最安
```

なぜこの順番になるのか。理由は **「その製品が輸入品と競争しているかどうか」** で決まる。

| 用途                 | 輸入との関係                                               | 価格が高い/安い理由                                          |
| -------------------- | ---------------------------------------------------------- | ------------------------------------------------------------ |
| **飲用（牛乳）**     | **輸入できない**。生乳は鮮度が命で、海を越えて運べない     | 国内の需給だけで価格が決まる。競合がいないので高く売れる     |
| **発酵乳・クリーム** | ほぼ国産。チルド流通が必要                                 | 飲用に次いで高い                                             |
| **チーズ**           | **輸入と真正面から競合**。EUやオセアニアの安いチーズが入る | 高い原料では国産チーズが作れない。安い乳価でないと成立しない |
| **バター・脱脂粉乳** | 国際相場品。保存がきくので世界中から運べる                 | 国際相場を超える原料費では作れない。**最も安い**             |

> ポイント：**乳価は「原価＋利益」で決まっていない。「その製品が輸入品といくらで戦えるか」で決まっている。**
> だから同じ牧場の同じタンクの生乳が、どこに運ばれるかで価値が変わる。

### プール乳価 ― 酪農家の手取りは「平均」になる

用途によって単価が違うと、たまたま加工向けに回された酪農家だけが損をしてしまう。
そこで指定団体は、**地域全体の販売代金を合計し、生乳量で割った単価を全戸に支払う**。
これを **プール乳価** と呼ぶ。

```
【プール乳価の考え方】

  飲用向け 40% × 高い単価  ┐
  発酵乳等 20% × 中の単価  ├─ 合計金額 ÷ 総生乳量 ＝ プール乳価（全戸共通）
  乳製品   40% × 安い単価  ┘
  → 飲用比率の高い都府県ほど高く、乳製品比率の高い北海道ほど低い
  → だから北海道の酪農家ほど補給金の重みが大きい
```

北海道は生乳生産量の約6割を占めるが、人口が少なく飲用需要が小さいため、
その多くがバター・脱脂粉乳・チーズに回る。**北海道＝加工、都府県＝飲用**という分業が、
地域ごとの乳価差と、次章の補給金制度の理由になっている。

## 5. 加工原料乳生産者補給金 ― 「安い用途」を国が埋める

**加工原料乳生産者補給金**とは、**バター・脱脂粉乳・チーズなどの乳製品向けに出荷された生乳に対し、
国が1kgあたりいくら、と上乗せして支払うお金**のこと。

目的は単純で、**加工向けの乳価が安すぎて、そのままでは北海道で酪農が続かない**からである。
飲用需要の少ない地域の生産を維持しないと、飲用が足りなくなったときに全国へ回す余力がなくなる。

| 項目                 | 2026年度（令和8年度）                      |
| -------------------- | ------------------------------------------ |
| 補給金単価           | **9.11円/kg**（前年度比 **13銭引き上げ**） |
| 集送乳調整金単価     | **2.83円/kg**                              |
| 合計（実質の上乗せ） | **約11.94円/kg**                           |
| 総交付対象数量       | **325万トン**（前年度比 **7万トン増**）    |

（農林水産省「令和8年度の加工原料乳生産者補給金単価等」。前年度比は日本農業新聞報道ベース）

読み方のポイント。**集送乳調整金**は遠隔地から集乳する輸送費を補うお金で、
「生乳は遠くへ運べない」という制約を税金で部分的に緩めている。
**総交付対象数量**には上限があり、超えた分に補給金は出ないため、事実上の生産数量の目安になる。
補給金は酪農家に直接ではなく指定団体等を経由して支払われ、プール乳価に反映される。

## 6. 需給調整のしわ寄せ ― バターと脱脂粉乳の在庫

### 6.1 なぜバターと脱脂粉乳は必ずセットで語られるのか

生乳を遠心分離すると、脂肪分と、脂肪を抜いた残り（脱脂乳）に分かれる。
脂肪分から **バター**、脱脂乳を乾燥させて **脱脂粉乳（脱粉）** ができる。
**1つの生乳から必ず両方が同時にできる**ので、片方だけ作ることができない。

```
【生乳1トンを分けると】

                ┌─ クリーム ──▶ バター     （需要：堅調。菓子・パン・業務用）
  生乳 1トン ───┤
                └─ 脱脂乳 ────▶ 脱脂粉乳   （需要：低調。加工乳・飲料・製菓原料）

  → バターが足りないから生乳を回す → 脱脂粉乳も同じだけできてしまう
  → バターは売れる、脱脂粉乳は余る ＝ 構造的な需給ギャップ
```

この非対称が、日本の乳業で何十年も繰り返されている「バター不足なのに脱脂粉乳は在庫過剰」
という一見矛盾した現象の正体である。

### 6.2 直近の在庫の状況（2026年）

脱脂粉乳の在庫は **2026年2月末で 75,961トン（前年同期比 +41%）**（日本経済新聞報道）。
2026年度末は 83,300トン（前年比+19.8%）に達する見通しと報じられる
（詳細は → [④ 直近トピック](04_直近トピック_2026.md) 第2章）。

Jミルク（一般社団法人Jミルク＝酪農乳業の全国団体）は、乳業と酪農の双方が拠出した基金による
**酪農乳業需給変動対策特別事業**を発動し、**過剰な脱脂粉乳を安く飼料向けなどに転用**している。
つまり、**人間の食べ物として作ったものを、値引きして牛の餌に回して在庫を減らしている**。

> 覚えておくべき構図：**脱脂粉乳の在庫は「生乳が余っていることの計量器」である。**
> 牛乳が売れなくなると、行き場を失った生乳が加工に回り、脱粉として積み上がる。
> ニュースで「脱粉在庫が○万トン」と出たら、それは酪農と乳業の経営が苦しいという意味だと読む。

## 7. 乳価交渉はどう行われるか

### 7.1 交渉の当事者と時期

```
【年間のスケジュール（典型例）】

  秋〜12月    国が翌年度の補給金単価・総交付対象数量を決定（畜産物価格決定）
     │        ※与党の畜産・酪農対策の議論とセットで決まる
     ▼
  1月〜3月    指定団体 ── 乳業メーカー大手 との用途別乳価交渉
     │        ・飲用向け／発酵乳向けを中心に、翌年度4月からの単価を決める
     │        ・関東生乳販連が先行して決め、他地域が続く年が多い
     ▼
  4月        新年度の乳価が適用（引き上げは8月からなど、期中実施の年もある）
     │
     ▼
  乳業メーカー ── 卸・小売 との製品価格交渉（＝店頭の牛乳が値上がりする段階）
                  ※原料が上がってから店頭に乗るまで数か月かかる
```

### 7.2 直近の飲用乳価の動き

関東生乳販連の例で、2022年11月に +10円/kg、2023年8月に +10円/kg、2024年度は据え置き、
2025年8月に +4円/kg、そして **2026年度は据え置き**（2026年1月23日合意）。
推移の一覧と背景は → [④ 直近トピック](04_直近トピック_2026.md) 第1章

> ここが乳業の難しさ。**乳価を上げると酪農家は助かるが、牛乳が売れなくなって生乳が余る。**
> 2025年8月の+4円のあと消費が落ち、2026年度は据え置きになった。
> 「コストは上がっているのに値上げできない」という、生産者も乳業も出口のない状態になっている
> → [③ 構造問題](03_構造問題.md)

## 8. まとめ：この章を理解する3つの鍵

1. **制度はすべて「生乳が止められず、腐り、運べない」ことへの対処である。**
   指定団体も、用途別乳価も、補給金も、この物理的制約を社会的に受け止めるための装置。
2. **乳価は原価で決まらず、「輸入品と戦えるか」で決まる。**
   輸入できない飲用は高く、国際相場品のバター・脱脂粉乳は安い。その差をプール乳価と補給金で埋めている。
3. **余った生乳は必ず脱脂粉乳になる。** 在庫が積み上がるのは「牛乳が売れていない」ことの裏返しであり、
   バター不足と脱粉過剰は同じ現象の表と裏である。

## 用語メモ

| 用語                                     | 意味                                                                                                                                                                       |
| ---------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **生乳（せいにゅう）**                   | 牛から搾ったままで、加熱殺菌も成分調整もしていない乳。これを加熱殺菌したものが「牛乳」                                                                                     |
| **指定生乳生産者団体（指定団体）**       | 酪農家から生乳販売を委託され、まとめて集荷し乳業メーカーと交渉する農協連合会。北海道はホクレン、関東は関東生乳販連など。2018年の畜安法改正で制度上は「指定事業者」となった |
| **一元集荷多元販売**                     | 地域の生乳をいったん1か所にまとめ（一元集荷）、複数の乳業メーカーに配分して売る（多元販売）仕組み                                                                          |
| **用途別乳価**                           | 同じ生乳でも、飲用・発酵乳・チーズ・乳製品など用途ごとに取引単価を変える仕組み。飲用が最も高く、バター・脱脂粉乳向けが最も安い                                             |
| **プール乳価**                           | 用途別の販売代金を合計して総生乳量で割り、全酪農家に共通の単価として支払う方式。用途の当たり外れをならす                                                                   |
| **加工原料乳生産者補給金**               | バター・脱脂粉乳・チーズ等の乳製品向けに出荷された生乳に国が上乗せ支払いする制度。2026年度は9.11円/kg、総交付対象数量325万トン                                             |
| **集送乳調整金**                         | 遠隔地からの集乳・輸送コストを補うために補給金と併せて交付される金額。2026年度は2.83円/kg                                                                                  |
| **アウトサイダー**                       | 指定団体に委託せず、自ら乳業者へ生乳を販売する酪農家。2018年改正で補給金の対象になった                                                                                     |
| **部分委託**                             | 生乳の一部だけを指定団体に委託し、残りは自分で販売する方式。2018年改正で可能になった                                                                                       |
| **脱脂粉乳（脱粉）**                     | 生乳から脂肪分を除いた脱脂乳を乾燥させた粉。保存がきくため需給調整の受け皿になり、余剰在庫の指標になる                                                                     |
| **Jミルク**                              | 酪農・乳業・関連団体でつくる一般社団法人。需給見通しの公表や需給変動対策事業を担う                                                                                         |
| **畜安法（畜産経営の安定に関する法律）** | 補給金制度の根拠法。2018年4月施行の改正で旧・不足払い法に基づく指定団体制度が廃止され、補給金の交付対象が拡大した                                                          |
