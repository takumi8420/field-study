このノートで分かること：主要チェーンが何を選び、何を捨てたのか。
ファストフードの戦略が 「安くして回す」か「高くして価値で取る」かの2本道に
収束する理由と、時間帯・アプリ・為替という3つの勝負どころ。

結論：ファストフードの戦略は、① 外食1店舗の経済 の
「売上 ＝ 客数 × 客単価」のどちらを取りにいくかで2つに割れる。
① 低価格×高回転（牛丼、うどん、サイゼリヤ）＝ 客数で取り、原価率の高さを回転で飲む
② 付加価値×高単価（モスバーガー、ケンタッキー、マクドナルドの上位商品）＝
単価で取り、客数の少なさを粗利の厚さで飲む
どちらの道も成立するが、中途半端な位置は成立しない。
これは価格帯が近い店同士で客の奪い合いが起き、規模の小さい側が先に潰れるため。

1. 2本の道を1枚の図で

【外食の戦略ポジショニング（客単価 × 回転率）】

  客単価
   高 │
      │                      ● モスバーガー（注文後調理・高単価）
 1200 │        ● ケンタッキー（クリスマス等ハレの日需要）
      │
 1000 │  ● マクドナルド（セット・上位商品で単価を作る）
      │
  800 │              ● 丸亀製麺（出来たてを見せる・天ぷら追加で単価）
      │   ● サイゼリヤ（低単価×注文点数）
  600 │      ● 牛丼3社（単品完結・超高回転）
      │
   低 └──────────────────────────────────────▶ 回転率 高
        低                                      高

  ・左下（低単価×低回転）は成立しない ＝ 個人店の廃業ゾーン
  ・右上（高単価×高回転）が理想だが、両立は難しい
    → ドライブスルーとテイクアウトは、この「右上」に近づく数少ない手段

ポイント：どこに立つかを決めた瞬間に、使う武器が全部決まる。
低価格×高回転を選べば、標準化・セントラルキッチン・立地（交通量）が武器になる。
付加価値×高単価を選べば、店内調理・食材の産地・接客が武器になる。
この2つは同じ会社の中でも同居しにくい。だから外食大手は
1社1業態ではなく、複数業態を持つグループ経営へ向かう。

3. 低価格×高回転の代表 — 牛丼3社の「同じ商売、違う判断」

牛丼はファストフードの経済がもっとも純粋に出る業態である。
単品完結・滞在10分・回転10回転超。だから価格の判断が業績に直結する。

                     └─▶ 客数の伸びは小さいが、利益率は守られた

ポイント：値下げは客数を確実に増やすが、利益は確実に減る。
増えた客数が、下げた単価を人件費・家賃の固定費吸収で取り返せるかどうかが賭けになる。
すき家の2026年3月期の数字は「客数は取れたが利益は取り返せなかった」ことを示しており、
その判断が2026年7月の値上げ（480円への回帰）につながったと読める。

4. 付加価値×高単価の代表 — モスバーガーと丸亀製麺

モスバーガー：作り置きしないことをコストではなく商品にする

モスバーガーは注文を受けてから作る。これは② 特有の仕組みで
見た「提供時間を短くする」という原則の逆をいく選択である。

  • 提供に時間がかかる → 回転率が落ちる → 同じ席数で売れる量が減る
  • それでも成立するのは、客単価がマクドナルドより高いから
  • 国産野菜の使用などを打ち出し、「安さ以外の理由で選ばれる」位置を取っている

2026年3月期の既存店は+9.0%（客数+6.3%、客単価+2.5%）で、
客数と単価の両方が伸びた。値上げ局面で客数も伸びるのは、
価格で選ばれていない証拠であり、付加価値型の狙いが効いている状態といえる。

丸亀製麺：手間を「見せる」ことで付加価値に変える

丸亀製麺は全店に製麺機を置き、店内で麺を打つ。
セントラルキッチンに寄せればL（人件費）は下がるのに、あえてやらない。

【店内製麺の損得】

  −  製麺の人員と場所が要る（L と 厨房面積が増える）
  −  技術の習熟が要る（標準化の難易度が上がる）
  ─────────────────────────────
  ＋  「打ちたて・茹でたて」が目に見える → 低単価でも価値を感じさせる
  ＋  天ぷら・おむすびを客が自分で取る → 注文点数が増え客単価が上がる
  ＋  セルフサービスなので、ホール人員は少なくて済む

  → L を製麺に使い、ホールから削る。トータルのL は抑えたまま付加価値を作る

2026年3月期の丸亀製麺セグメントは売上1,371.9億円（+7.1%）、
セグメント利益率は約16%と報じられており、外食としてはきわめて高い水準にある。
一方で同社は海外事業で114億円の減損を計上しており、
国内で確立した型がそのまま海外で通用するとは限らないことも示している。

5. 時間帯戦略 — 朝食と深夜という2つの空白

① 外食1店舗の経済で見たとおり、外食の人件費はピークで決まる。
だからすでに人がいる時間の売上を増やすのがもっとも利益率が高い。

時間帯 経済的な意味 各社の打ち手
朝（6〜10時）開店準備で人はすでにいる。追加人件費がほぼゼロ朝マック、すき家・松屋の朝定食、ケンタッキーの朝メニュー
昼（11〜14時）最大のピーク。ここで人員が決まる回転率を上げる（提供時間短縮、モバイルオーダー）
アイドル（14〜17時）人件費だけが出ていく時間午後限定のドリンク・デザート、勉強や仕事での滞在を許容
夜（17〜21時）第2のピーク。単価は昼より高い夜マックのような増量・高単価メニュー
深夜（22〜5時）人件費が割増（深夜手当）。客数は少ない24時間営業の縮小が進む（→ ④ 人手不足と省力化）
【朝食が「利益率の高い売上」である理由】

  昼に新規で1,000円売る      朝に新規で1,000円売る
   → 追加の人員が必要           → 開店準備の人員で対応できる
   → 追加人件費 200〜300円      → 追加人件費 ほぼ 0円
   → 残る利益 …… 小さい         → 残る利益 …… 大きい

  同じ1,000円でも、どの時間帯で作った売上かで利益が変わる

深夜については逆方向に動いている。深夜手当（労働基準法で22時〜5時は25%以上の割増）が
効くうえ人が採れないため、24時間営業を維持できる店が減っている。
これは同じ24時間問題を抱えるコンビニと
共通の構図だが、外食のほうが深夜の売上が薄く、撤退の判断が早い。

6. モバイルオーダーとアプリ会員 — 何が経済的に変わるのか

各社が自社アプリに投資するのは、クーポンを配るためではない。
支払う相手を変え、客の行動データを取るためである。

効果 何が起きるか
手数料を払わなくて済むデリバリー事業者への30%前後の手数料を回避できる（→ ②）
ピークの処理能力が上がる事前注文・事前決済でレジ滞留が減る。同じ人員で多くさばける
注文ミスが減る口頭注文がなくなり、クレーム対応の時間コストが減る
客単価が上がる画面上で「ご一緒にいかがですか」を全員に出せる（人は言い忘れる）
個人が特定できる誰が・いつ・何を・どのチャネルで買ったかが1つのIDに紐づく
来店頻度を動かせる「最後の来店から2週間」の人だけにクーポンを出す、が可能になる

日本マクドナルドは2026年3月、ポイントプログラム「Myマクドナルドリワード」を
モバイルオーダー・デリバリー・セルフオーダー端末・カウンター・ドライブスルーの
全チャネルに統合したと報じられている。
これは「どのチャネルで買っても同じIDに紐づく」ことを意味し、
チャネル別の最適化から、個客別の最適化へという転換にあたる。

ポイント：ファストフードの競争は「今日の1杯を売る」から
「その人の年間来店回数を1回増やす」へ移っている。
客単価には上限があるが、来店頻度には上限がない。
そしてこれは、データを持っている会社しかできない競争である。

7. 原材料と為替 — 外食は「買う側」である

ファストフードの原価は、自社ではまったく決められない要素に大きく左右される。

【FFの主要原材料と、価格を動かす要因】

  牛肉  … 米国・豪州産に依存 → 為替（円安）＋ 米国の牛の頭数 ＋ 中国の需要
  鶏肉  … 国産約65% / 輸入約35%（輸入の約7割がブラジル産とされる）
          → 鳥インフルエンザ ＋ 為替 ＋ 世界的な需要増
  小麦  … 政府売渡価格（年2回改定）に連動 → 国際相場 ＋ 為替
  コメ  … 国内相場。2024〜2026年にかけて高値が続いたと報じられる
  食用油 … 原油・大豆相場 ＋ 為替
  包装資材 … 原油由来のナフサ価格 → 2026年は中東情勢で高騰したと報じられる
  ─────────────────────────────────────────
  共通項：ほぼすべてに「為替」が乗る。円安は外食の原価を一律に押し上げる
  • 外食は価格転嫁が遅い。メニュー表・券売機・看板・アプリをすべて変える必要があり、
    原材料が上がってから値上げまで数か月のタイムラグが出る。この間は利益が圧縮される
  • 転嫁の順番が業態で違う。高単価業態は「100円上げても比率は小さい」ので転嫁しやすい。
    低単価業態は数十円の値上げでも比率が大きく、客数の反応が激しい
  • 帝国データバンクの2026年4月調査では、値上げ要因として
    原材料高 99.9%、包装・資材コスト 81.3%、人件費 66.0%、物流費 61.8%、エネルギー費 60.0%
    が挙がった（同社調査）。単一要因ではなく複数が同時に来ているのが2020年代の特徴

原料の川上については畜産・飼料、
水産、製粉・製糖・製油、
物流面は食品卸も参照。

8. まとめ — 各社の選択を1行で

会社 何を選び、何を捨てたか
マクドナルドチャネルの多さを取り、単一店舗の特別感を捨てた
モスバーガー出来たての価値を取り、提供速度と回転率を捨てた
ケンタッキーチキン特化を取り、メニューの幅を捨てた（その分ハレの日需要が強い）
すき家客数を取り、短期の利益率を捨てた（2026年に方針を戻した）
吉野家ブランドと利益率を取り、価格競争での客数を捨てた
松屋メニューの幅を取り、単品特化の効率を捨てた
丸亀製麺見える手間を取り、セントラルキッチンの効率を捨てた
サイゼリヤ値上げしないことを取り、短期の利益率を捨てた（垂直統合で耐える）

用語メモ

用語 意味
低価格×高回転単価を抑えて客数と回転率で稼ぐ型。牛丼・うどん・サイゼリヤ。立地の交通量と標準化が武器
付加価値×高単価単価を上げて少ない客数で稼ぐ型。モスバーガー等。食材・調理法・接客が武器
ハレの日需要クリスマスや誕生日など、非日常の日に集中する需要。ケンタッキーの強みだが日常使いの開拓が課題になる
時間帯戦略朝・昼・アイドル・夜・深夜のどこに商品を投入するかの設計。すでに人がいる時間の売上は利益率が高い
深夜割増労働基準法で22時〜翌5時の労働に25%以上の割増賃金が必要。深夜営業の採算を悪くする最大要因
アプリ会員／リワード自社アプリで会員を囲い込み、購買履歴をIDに紐づける仕組み。手数料回避と来店頻度の操作が目的
