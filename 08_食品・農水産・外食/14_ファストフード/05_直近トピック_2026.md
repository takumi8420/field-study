# ⑤ 直近トピック（2026年9月時点）

報道・各社開示ベースの整理。一次情報（各社IR、官公庁発表）で必ず裏取りすること。
数値は公表時点のものであり、以後の改定で変わりうる。

> この1年の構図：**「値上げは通ったが、客数はもう伸びない」**。
> 原材料・資材・人件費が同時に上がり、外食企業の約6割が2026年度の値上げに動いた。
> 大手チェーンの既存店はプラスを保っているが、その中身は客単価主導に傾いている。
> 一方で中小・零細の飲食店は倒産が過去最多を更新し、
> 特定技能の新規受入停止が人手の供給に天井をつけた。
> **需要が増えたのではなく、供給側が減っている**局面と読むのが正確である。

## 1. コスト三重苦 — 「チキンショック」と容器高騰（2026年前半）

2026年の外食のコスト圧力は、**原材料・包装資材・人件費が同時に来た**点に特徴がある。

| 要因 | 中身 | 時期 |
| --- | --- | --- |
| **チキンショック** | 鶏肉相場が過去最高水準に。鳥インフルエンザによる供給不安、円安、世界的な需要増、輸送費上昇が重なったと報じられる。日本の鶏肉は国産約65%・輸入約35%で、輸入の約7割がブラジル産とされる | 2025年後半〜2026年 |
| **容器・包装資材の高騰** | 中東情勢の緊迫化で原油・ナフサの調達が不安定化し、容器・包装資材が急騰したと報じられる（いわゆる「ホルムズショック」） | 2026年前半 |
| **コメ・食用油等** | コメの高値が継続したと報じられる。食用油・小麦も為替の影響を受ける | 2024年〜2026年 |
| **人件費** | 最低賃金の継続的な引き上げ（2025年度は全国加重平均1,121円、+66円） | 継続 |

- 日本経済新聞は2026年6月、**外食企業の約6割が2026年度に値上げする**と報じた。
  背景としてチキンショックと容器不足を挙げている
- 帝国データバンクの2026年4月調査では、値上げ要因として
  **原材料高 99.9%／包装・資材コスト 81.3%／人件費 66.0%／物流費 61.8%／エネルギー費 60.0%**
  が挙がった。**4年連続で9割以上の企業が「原材料高」を挙げている**
- 食品全体でも値上げは止まらず、2026年6月は1,078品目の価格改定があり、
  年間では1万品目を超える見通しと報じられた
- 影響はメニューにも及び、サイゼリヤがチキンステーキ等の一部メニューを休売したと報じられた

> 読み方：これまでの値上げは「原材料高」という単一要因だった。
> 2026年は**資材・物流・エネルギー・人件費が同時に効いている**ため、
> 1品の値上げ幅では吸収しきれず、メニュー構成そのものの見直し（休売・差し替え）に及んでいる。
> コスト構造の詳細は [① 外食1店舗の経済](01_外食1店舗の経済.md) と
> [③ 各社の戦略](03_各社の戦略.md) の原材料の節を参照。

## 2. 牛丼の価格戦争が一巡（2025年9月 → 2026年7月）

すき家（ゼンショーHD）が2025年9月に牛丼並盛を**480円 → 450円**へ値下げし、
2026年7月8日に**30円値上げして480円に戻した**（同社告知・報道ベース）。

| 指標 | 数値 | 出典 |
| --- | --- | --- |
| すき家 2026年3月期 国内既存店 | 売上 103.5%、**客数 96.6%**、客単価 107.2% | ゼンショーHD決算発表 |
| グローバルすき家セグメント | 売上 3,144億円（+6.3%）、営業利益 **93億円（前期比 ▲62.0%）** | 同上 |
| ゼンショーHD 連結（2026年3月期） | 売上 **1兆2,640億円（+11.2%）**、営業利益 814億円（+8.4%）、純利益 458億円（+16.6%） | 同上 |
| グローバルはま寿司 | 売上 3,202億円（+28.9%）、営業利益 267億円（+25.4%） | 同上 |

```
【この1年で起きたこと】

  2025年9月  すき家 値下げ（480→450円）
       │      → 月次の既存店客数は2026年5月に +17.8% まで伸びた
       │      → しかし通期の国内既存店客数は 96.6%（＝前年割れ）
       │         月次と通期で逆の数字が出るのは、値下げ前の期間を含むため
       ▼
  2026年3月  ゼンショーHD 2026年3月期決算
              すき家セグメント営業利益 ▲62.0%
              清掃強化・店舗改装のコストも重なった
       ▼
  2026年7月  すき家 30円値上げで480円へ回帰
              → 価格競争は一巡。次は「値上げしても客が残るか」の局面
```

吉野家・松屋は値下げに深追いせず、2026年6月以降の既存店は
**吉野家 +0.4%（6月）／+0.7%（8月、客数▲1.3%）、松屋フーズ ▲4.8%（6月）／+2.1%（8月）**
と伸び悩んだ（各社月次開示・流通系メディア報道）。
利益率は守ったが、客数では差をつけられた形になる。

## 3. 大手チェーンは好調 — ただし中身は客単価主導

2025年度〜2026年度の主要チェーンの決算は、**そろって増収増益**だった。

| 会社 | 決算期 | 売上 | 利益 | 既存店 |
| --- | --- | --- | --- | --- |
| 日本マクドナルドHD | 2025年12月期 | 全店売上高 **8,886億円（+7.2%）** | 営業利益 532億円（+10.9%） | **+5.7%**（41四半期連続増）。期末3,025店、年間120店出店 |
| モスフードサービス | 2026年3月期 | 1,027.7億円（+6.8%） | 営業利益 65.6億円（+25.6%）、純利益 45.9億円（+45.6%） | **+9.0%**（客数+6.3%、客単価+2.5%） |
| トリドールHD | 2026年3月期 | 売上収益 2,787億円（+3.9%） | 営業利益 105.8億円（+21.9%）※海外で減損114億円 | 丸亀製麺 **+4.5%**（客単価+2%、客数+2.5%） |
| サイゼリヤ | 2026年8月期（会社予想） | 2,763億円（+8%） | 営業利益 190億円（+23%）、純利益 124億円（+11%）で3年連続最高益 | 国内 +7%、海外 ▲4% |

一方、マクドナルドは2026年2月25日に**約6割の商品を10〜50円値上げ**したと報じられ、
2026年5月の既存店は売上+5.7%に対し**客数は+0.6%**にとどまった。
2026年1〜6月期は43四半期連続の既存店増収となったが、
**伸びの大半は客単価が作っている**。

> 読み方：[① 外食1店舗の経済](01_外食1店舗の経済.md) の「既存店3数値の読み方」でいう
> **ケースB（客単価主導）**に近づいている。
> 値上げ余地がどこまで残るかが、2026年後半〜2027年の最大の論点。
> なお日本マクドナルドHDは2026年12月期について減収予想を示しており（会社予想）、
> 前期の反動と既存店投資の影響をどう見るかで評価が割れている。

## 4. 特定技能「外食業」の新規受入停止（2026年4月13日）

農林水産省と出入国在留管理庁は2026年3月27日、
**特定技能1号「外食業」分野の新規受入を2026年4月13日から当面停止する**と発表した。

| 項目 | 内容 |
| --- | --- |
| 理由 | 分野別の受入上限 **5万人**に在留者数が到達する見込みとなったため |
| 在留者数 | 2026年2月末時点で **約4万6,000人** |
| 例外 | 技能実習からの移行など一部を除き、新規の在留資格認定証明書交付を停止 |
| 今後 | 技能実習制度は**2027年4月に育成就労制度へ移行**予定。外食分野の育成ルートが再設計される見込み |

```
【外食の人の入り口が、上から順に細くなっている】

  国内の学生・主婦層 ── 人口減と他業種との時給競争で縮小
  留学生アルバイト   ── 週28時間の上限があり穴埋めに限界
  特定技能1号        ── 2026年4月に上限到達で新規停止  ←★ 今回
  育成就労（2027年〜）── 制度設計はこれから

  → 残る手段は「省力化」と「1人あたり生産性の向上」しかない
```

詳細は [④ 人手不足と省力化](04_人手不足と省力化.md) を参照。

## 5. 飲食店の倒産が過去最多（2026年上半期）

帝国データバンクによると、2026年上半期（1〜6月）の飲食店倒産は **473件** で、
前年同期（458件）を上回り**上半期として過去最多**、4年連続の増加となった
（2026年7月公表）。

| 業態 | 件数 | 備考 |
| --- | --- | --- |
| 酒場・ビヤホール（[居酒屋](../16_居酒屋/README.md)主体） | **125件**（前年同期比 +19.0%） | 2023年以降、上半期4年連続で100件超 |
| 中華・東洋料理店 | **91件** | 過去最多 |

同社は要因として、食材・光熱費の高騰と賃上げによる利益圧迫に加え、
**特定技能の受入停止など急速な環境変化に対応できない飲食店の淘汰**が進むとの見方を示している。

> 読み方：大手チェーンの既存店がプラスを続けるなかで倒産が過去最多という、
> 一見矛盾する2つの事実が並んでいる。これは
> **同じ環境変化が、規模によって正反対に作用している**ということ。
> 仕入単価・省力化投資・採用力・ブランドの4点で差がつき、
> 中小の需要がチェーンと[中食・弁当](../20_中食・弁当/README.md)・
> [コンビニ](../../07_小売・流通/01_コンビニエンスストア/README.md)へ流れている。

## 6. デリバリー市場の淘汰と、自社チャネルへの回帰

フードデリバリーは事業者の撤退が続き、市場が絞られた。

- **Wolt** が2026年3月4日に日本でのサービスを終了したと報じられる
- **menu** が2026年9月30日でデリバリー・テイクアウトサービスを終了予定と報じられる
- 残るプラットフォームは価格競争へ。出前館が送料無料を全国に拡大、
  Uber Eats はサブスク「Uber One」で手数料を実質0円にする施策を展開

一方、チェーン側は**手数料30%前後を払わずに済む自社チャネル**を強化している。
日本マクドナルドは2026年3月、ポイント制度「Myマクドナルドリワード」を
モバイルオーダー・デリバリー・セルフオーダー端末・カウンター・ドライブスルーの
**全チャネルに統合した**と報じられた。購買行動が1つの顧客IDに紐づく形になる。

```
【デリバリーの位置づけの変化】

  2020〜2022年  コロナ下で「売上を作る手段」として急拡大
        ▼
  2023〜2025年  手数料30%の重さが表面化。利益が出ないことが認識される
        ▼
  2026年        プラットフォーム側が淘汰・価格競争へ
                チェーン側は自社アプリ・自社配達へ回帰
                → デリバリーは「売上の柱」から「チャネルの1つ」に戻った
```

## 7. AIと省力化の実装フェーズ入り

| 動き | 内容 | 時期・出典 |
| --- | --- | --- |
| **AIドライブスルー** | 日本マクドナルドがGoogle Cloudと連携し、音声認識AIによる注文受付を進める方針と報じられる。狙いは注文ミスの削減、従業員負担の軽減、提供時間の短縮 | 2026年1月・報道ベース |
| **AI重量計測** | 商品を渡す前に袋の重量をAIで測り、入れ忘れ・渡し間違いを検知する仕組みの導入が報じられる | 同上 |
| **政策・補助金** | 農水省・厚労省が「省力化投資促進プラン（飲食業）」を2025年6月に取りまとめ。中小企業省力化投資補助金は配膳ロボット等を対象に補助上限1億円・補助率最大3分の2 | 政府文書・制度 |
| **業界の認識変化** | 人手不足を「解決する問題」ではなく「前提として管理する条件」と捉え、採用投資から設備投資へ配分を移す動きが広がっているとされる | 業界メディア |

> 読み方：AI・ロボットの導入は**人件費を減らすため**というより、
> **最低賃金上昇で毎年増えていく人件費を吸収するため**の防衛投資である
> （→ [④ 人手不足と省力化](04_人手不足と省力化.md)）。
> 投資判断も「削減額」ではなく「投資しなかった場合の増加額」との比較になる。

## 8. 全体の構図（まとめ）

- **コストは複合化した**。原材料単独ではなく、資材・物流・エネルギー・人件費が同時に上がり、
  値上げ幅では吸収しきれずメニュー構成の見直しに及んでいる
- **価格競争は一巡した**。すき家の値下げ→値上げ回帰は、
  「客数は買えるが利益は買えない」ことを数字で示した
- **大手の既存店は好調だが、中身は客単価主導**。客数の伸びは細く、値上げ余地が焦点
- **人の供給に制度的な天井がついた**。特定技能の新規受入停止で、省力化が唯一の解になった
- **業界内の格差が開いている**。倒産は過去最多だが大手は最高益。
  同じ環境が規模によって正反対に作用しており、中小の需要が大手と中食へ移っている

| **ホルムズショック** | 中東情勢の緊迫化で原油・ナフサの調達が不安定化し、容器・包装資材が高騰した現象を指す報道上の呼称 |
| **既存店売上高前年同月比** | 開店から一定期間経った店だけを集計した前年同月比。売上・客数・客単価の3点で読む（→ [①](01_外食1店舗の経済.md)） |
| **価格転嫁** | コスト上昇分を販売価格に反映すること。外食はメニュー・券売機・看板の変更が要るため転嫁が遅れやすい |
| **特定技能1号「外食業」** | 外食現場で就労できる在留資格。分野別上限5万人に到達し、2026年4月13日から新規受入が当面停止された |
| **育成就労制度** | 技能実習制度に代わる新制度。2027年4月移行予定 |
