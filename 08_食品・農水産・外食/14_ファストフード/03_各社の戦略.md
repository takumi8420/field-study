# ③ 各社の戦略 — 低価格×高回転か、付加価値×高単価か

このノートで分かること：主要チェーンが何を選び、何を捨てたのか。
ファストフードの戦略が **「安くして回す」か「高くして価値で取る」かの2本道**に
収束する理由と、時間帯・アプリ・為替という3つの勝負どころ。

> 結論：ファストフードの戦略は、[① 外食1店舗の経済](01_外食1店舗の経済.md) の
> **「売上 ＝ 客数 × 客単価」のどちらを取りにいくか**で2つに割れる。
> ① **低価格×高回転**（牛丼、うどん、サイゼリヤ）＝ 客数で取り、原価率の高さを回転で飲む
> ② **付加価値×高単価**（モスバーガー、ケンタッキー、マクドナルドの上位商品）＝
> 単価で取り、客数の少なさを粗利の厚さで飲む
> **どちらの道も成立するが、中途半端な位置は成立しない**。
> これは価格帯が近い店同士で客の奪い合いが起き、規模の小さい側が先に潰れるため。

## 1. 2本の道を1枚の図で

```
【外食の戦略ポジショニング（客単価 × 回転率）】

  客単価
   高 │
      │                      ● モスバーガー（注文後調理・高単価）
 1200 │        ● ケンタッキー（クリスマス等ハレの日需要）
      │
 1000 │  ● マクドナルド（セット・上位商品で単価を作る）
      │
  800 │              ● 丸亀製麺（出来たてを見せる・天ぷら追加で単価）
      │   ● サイゼリヤ（低単価×注文点数）
  600 │      ● 牛丼3社（単品完結・超高回転）
      │
   低 └──────────────────────────────────────▶ 回転率 高
        低                                      高

  ・左下（低単価×低回転）は成立しない ＝ 個人店の廃業ゾーン
  ・右上（高単価×高回転）が理想だが、両立は難しい
    → ドライブスルーとテイクアウトは、この「右上」に近づく数少ない手段
```

> ポイント：**どこに立つかを決めた瞬間に、使う武器が全部決まる**。
> 低価格×高回転を選べば、標準化・セントラルキッチン・立地（交通量）が武器になる。
> 付加価値×高単価を選べば、店内調理・食材の産地・接客が武器になる。
> この2つは同じ会社の中でも同居しにくい。だから外食大手は
> **1社1業態ではなく、複数業態を持つグループ経営**へ向かう。

## 3. 低価格×高回転の代表 — 牛丼3社の「同じ商売、違う判断」

牛丼は**ファストフードの経済がもっとも純粋に出る業態**である。
単品完結・滞在10分・回転10回転超。だから価格の判断が業績に直結する。

```
【2025〜2026年の牛丼3社の分岐】

  2025年9月  すき家：牛丼並盛 480円 → 450円 へ値下げ
                     │
                     ├─▶ 客数は大きく伸びた（2026年5月の既存店客数 +17.8%）
                     └─▶ だが利益は落ちた
                          グローバルすき家セグメント営業利益
                          2026年3月期 93億円（前期比 ▲62.0%）

  2026年7月8日 すき家：30円値上げして 480円 に戻す
                     │
                     └─▶ 値下げは「客数を取り戻す一時的な投資」だったと読める

  同じ期間、吉野家・松屋は深追いせず
                     └─▶ 客数の伸びは小さいが、利益率は守られた
```

| 会社 | 2026年の既存店（4月／5月／6月／8月） | 読み方 |
| --- | --- | --- |
| すき家 | +17.8% ／ +15.9% ／ +12.5% ／ +11.1% | 値下げ効果で客数主導。ただし伸び率は月を追って縮小 |
| 吉野家 | +10.4% ／ +9.7% ／ +0.4% ／ +0.7% | 6月以降に失速。客数は8月で▲1.3%とマイナス |
| 松屋フーズ | +8.0% ／ +5.3% ／ ▲4.8% ／ +2.1% | 月次のブレが大きい。販促の有無で振れる |

（各社月次開示・流通系メディア報道ベース。前年同月の反動も含むため単月では判断できない）

> ポイント：**値下げは客数を確実に増やすが、利益は確実に減る**。
> 増えた客数が、下げた単価を人件費・家賃の固定費吸収で取り返せるかどうかが賭けになる。
> すき家の2026年3月期の数字は「客数は取れたが利益は取り返せなかった」ことを示しており、
> その判断が2026年7月の値上げ（480円への回帰）につながったと読める。

## 4. 付加価値×高単価の代表 — モスバーガーと丸亀製麺

### モスバーガー：作り置きしないことをコストではなく商品にする

モスバーガーは**注文を受けてから作る**。これは[② 特有の仕組み](02_ファストフード特有の仕組み.md)で
見た「提供時間を短くする」という原則の**逆**をいく選択である。

- 提供に時間がかかる → 回転率が落ちる → 同じ席数で売れる量が減る
- それでも成立するのは、**客単価がマクドナルドより高い**から
- 国産野菜の使用などを打ち出し、「安さ以外の理由で選ばれる」位置を取っている

2026年3月期の既存店は**+9.0%（客数+6.3%、客単価+2.5%）**で、
客数と単価の両方が伸びた。値上げ局面で客数も伸びるのは、
**価格で選ばれていない証拠**であり、付加価値型の狙いが効いている状態といえる。

### 丸亀製麺：手間を「見せる」ことで付加価値に変える

丸亀製麺は全店に製麺機を置き、店内で麺を打つ。
セントラルキッチンに寄せればL（人件費）は下がるのに、あえてやらない。

```
【店内製麺の損得】

  −  製麺の人員と場所が要る（L と 厨房面積が増える）
  −  技術の習熟が要る（標準化の難易度が上がる）
  ─────────────────────────────
  ＋  「打ちたて・茹でたて」が目に見える → 低単価でも価値を感じさせる
  ＋  天ぷら・おむすびを客が自分で取る → 注文点数が増え客単価が上がる
  ＋  セルフサービスなので、ホール人員は少なくて済む

  → L を製麺に使い、ホールから削る。トータルのL は抑えたまま付加価値を作る
```

2026年3月期の丸亀製麺セグメントは売上1,371.9億円（+7.1%）、
セグメント利益率は約16%と報じられており、外食としてはきわめて高い水準にある。
一方で同社は海外事業で114億円の減損を計上しており、
**国内で確立した型がそのまま海外で通用するとは限らない**ことも示している。

## 5. 時間帯戦略 — 朝食と深夜という2つの空白

[① 外食1店舗の経済](01_外食1店舗の経済.md)で見たとおり、外食の人件費はピークで決まる。
だから**すでに人がいる時間の売上を増やす**のがもっとも利益率が高い。

| 時間帯 | 経済的な意味 | 各社の打ち手 |
| --- | --- | --- |
| **朝（6〜10時）** | 開店準備で人はすでにいる。追加人件費がほぼゼロ | 朝マック、すき家・松屋の朝定食、ケンタッキーの朝メニュー |
| 昼（11〜14時） | 最大のピーク。ここで人員が決まる | 回転率を上げる（提供時間短縮、モバイルオーダー） |
| **アイドル（14〜17時）** | 人件費だけが出ていく時間 | 午後限定のドリンク・デザート、勉強や仕事での滞在を許容 |
| 夜（17〜21時） | 第2のピーク。単価は昼より高い | 夜マックのような増量・高単価メニュー |
| **深夜（22〜5時）** | 人件費が割増（深夜手当）。客数は少ない | 24時間営業の縮小が進む（→ [④ 人手不足と省力化](04_人手不足と省力化.md)） |

```
【朝食が「利益率の高い売上」である理由】

  昼に新規で1,000円売る      朝に新規で1,000円売る
   → 追加の人員が必要           → 開店準備の人員で対応できる
   → 追加人件費 200〜300円      → 追加人件費 ほぼ 0円
   → 残る利益 …… 小さい         → 残る利益 …… 大きい

  同じ1,000円でも、どの時間帯で作った売上かで利益が変わる
```

深夜については逆方向に動いている。深夜手当（労働基準法で22時〜5時は25%以上の割増）が
効くうえ人が採れないため、**24時間営業を維持できる店が減っている**。
これは同じ24時間問題を抱える[コンビニ](../../07_小売・流通/01_コンビニエンスストア/01_1店舗の経済学.md)と
共通の構図だが、外食のほうが深夜の売上が薄く、撤退の判断が早い。

## 6. モバイルオーダーとアプリ会員 — 何が経済的に変わるのか

各社が自社アプリに投資するのは、クーポンを配るためではない。
**支払う相手を変え、客の行動データを取るため**である。

| 効果 | 何が起きるか |
| --- | --- |
| **手数料を払わなくて済む** | デリバリー事業者への30%前後の手数料を回避できる（→ [②](02_ファストフード特有の仕組み.md)） |
| **ピークの処理能力が上がる** | 事前注文・事前決済でレジ滞留が減る。同じ人員で多くさばける |
| **注文ミスが減る** | 口頭注文がなくなり、クレーム対応の時間コストが減る |
| **客単価が上がる** | 画面上で「ご一緒にいかがですか」を全員に出せる（人は言い忘れる） |
| **個人が特定できる** | 誰が・いつ・何を・どのチャネルで買ったかが1つのIDに紐づく |
| **来店頻度を動かせる** | 「最後の来店から2週間」の人だけにクーポンを出す、が可能になる |

日本マクドナルドは2026年3月、ポイントプログラム「Myマクドナルドリワード」を
モバイルオーダー・デリバリー・セルフオーダー端末・カウンター・ドライブスルーの
**全チャネルに統合した**と報じられている。
これは「どのチャネルで買っても同じIDに紐づく」ことを意味し、
**チャネル別の最適化から、個客別の最適化へ**という転換にあたる。

> ポイント：ファストフードの競争は「今日の1杯を売る」から
> **「その人の年間来店回数を1回増やす」**へ移っている。
> 客単価には上限があるが、来店頻度には上限がない。
> そしてこれは、データを持っている会社しかできない競争である。

## 7. 原材料と為替 — 外食は「買う側」である

ファストフードの原価は、**自社ではまったく決められない**要素に大きく左右される。

```
【FFの主要原材料と、価格を動かす要因】

  牛肉  … 米国・豪州産に依存 → 為替（円安）＋ 米国の牛の頭数 ＋ 中国の需要
  鶏肉  … 国産約65% / 輸入約35%（輸入の約7割がブラジル産とされる）
          → 鳥インフルエンザ ＋ 為替 ＋ 世界的な需要増
  小麦  … 政府売渡価格（年2回改定）に連動 → 国際相場 ＋ 為替
  コメ  … 国内相場。2024〜2026年にかけて高値が続いたと報じられる
  食用油 … 原油・大豆相場 ＋ 為替
  包装資材 … 原油由来のナフサ価格 → 2026年は中東情勢で高騰したと報じられる
  ─────────────────────────────────────────
  共通項：ほぼすべてに「為替」が乗る。円安は外食の原価を一律に押し上げる
```

- **外食は価格転嫁が遅い**。メニュー表・券売機・看板・アプリをすべて変える必要があり、
  原材料が上がってから値上げまで数か月のタイムラグが出る。この間は利益が圧縮される
- **転嫁の順番が業態で違う**。高単価業態は「100円上げても比率は小さい」ので転嫁しやすい。
  低単価業態は数十円の値上げでも比率が大きく、客数の反応が激しい
- 帝国データバンクの2026年4月調査では、値上げ要因として
  **原材料高 99.9%、包装・資材コスト 81.3%、人件費 66.0%、物流費 61.8%、エネルギー費 60.0%**
  が挙がった（同社調査）。**単一要因ではなく複数が同時に来ている**のが2020年代の特徴

原料の川上については[畜産・飼料](../13_畜産・飼料/README.md)、
[水産](../11_水産/README.md)、[製粉・製糖・製油](../02_製粉・製糖・製油/README.md)、
物流面は[食品卸](../../06_商社・卸売/06_食品卸/README.md)も参照。

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **低価格×高回転** | 単価を抑えて客数と回転率で稼ぐ型。牛丼・うどん・サイゼリヤ。立地の交通量と標準化が武器 |
| **付加価値×高単価** | 単価を上げて少ない客数で稼ぐ型。モスバーガー等。食材・調理法・接客が武器 |
| **ハレの日需要** | クリスマスや誕生日など、非日常の日に集中する需要。ケンタッキーの強みだが日常使いの開拓が課題になる |
| **時間帯戦略** | 朝・昼・アイドル・夜・深夜のどこに商品を投入するかの設計。すでに人がいる時間の売上は利益率が高い |
| **深夜割増** | 労働基準法で22時〜翌5時の労働に25%以上の割増賃金が必要。深夜営業の採算を悪くする最大要因 |
| **アプリ会員／リワード** | 自社アプリで会員を囲い込み、購買履歴をIDに紐づける仕組み。手数料回避と来店頻度の操作が目的 |
| **価格転嫁** | 原材料等のコスト上昇を販売価格に反映すること。外食はメニュー変更の手間からタイムラグが出やすい |
| **垂直統合** | 原料の生産・加工・物流まで自社で持つこと。サイゼリヤの自社農場・自社工場が代表例。原価を安定させられる |
| **減損** | 投資した資産の回収見込みが下がったときに、帳簿価額を切り下げて損失計上すること。トリドールHDが2026年3月期に海外事業で114億円計上 |
