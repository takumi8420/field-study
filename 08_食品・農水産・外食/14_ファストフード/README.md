# ファストフード

- 大分類: 食品・農水産・外食
- 状態: done
- 更新日: 2026-09-20

## このフォルダの読み方

ファストフードは **「料理を作る仕事を、手順を実行する仕事に置き換えた業態」**である。
食材の規格・厨房機器・作業手順・店内配置・品質基準をすべて固定することで、
調理経験のない人が数日で同じ商品を同じ時間で出せるようにした。
これにより人件費を下げ、回転率を上げ、店を短期間に大量に複製できるようになった。
**標準化こそがこの業態の商品**である。

経済の読み方は単純で、**FLコスト（F＝食材費＋L＝人件費）が売上の60%以内に収まるか**。
残り40%のうち家賃が10%、水道光熱費とその他が20%を食い、営業利益は良くて10%。
売上100万円の店に残るのは10万円しかない。だから外食は
「売上を上げる」よりも「FLを1ポイント下げる」ことに全力を注ぐ。

**本フォルダは外食分類の最初のノート**なので、①で「外食1店舗の経済性」を
業態を問わず使える形で丁寧に扱った。
[ファミリーレストラン](../15_ファミリーレストラン/README.md)・[居酒屋](../16_居酒屋/README.md)・
[回転寿司](../17_回転寿司/README.md)・[カフェ](../19_カフェ/README.md)など後続の外食ノートは、
ここで定義した指標（FL比率、回転率、坪売上、既存店前年比）をそのまま使う。

## 1. 業界の定義・範囲

**ファストフード（FF）＝ 注文から提供までが短く、価格が低く、テイクアウトが前提に
組み込まれた外食業態**。日本フードサービス協会の業態分類では
「ファーストフード」として集計され、洋風（ハンバーガー等）・和風（牛丼等）・麺類・
持ち帰り米飯／回転寿司・その他に細分される。

隣接業態との境界は、**提供時間・客単価・滞在時間・サービス方式**の4点で引く。

| 業態 | 提供時間 | 客単価 | 滞在時間 | サービス方式 |
| --- | --- | --- | --- | --- |
| **ファストフード** | 1〜3分 | 500〜1,100円 | 10〜25分 | **カウンター／セルフ** |
| [ファミリーレストラン](../15_ファミリーレストラン/README.md) | 10〜20分 | 1,000〜1,500円 | 50〜70分 | テーブルサービス |
| [居酒屋](../16_居酒屋/README.md) | 都度提供 | 3,000〜4,000円 | 120分前後 | テーブルサービス |
| [回転寿司](../17_回転寿司/README.md) | 都度提供 | 1,200〜1,800円 | 40〜60分 | レーン／タッチパネル |
| [カフェ](../19_カフェ/README.md) | 1〜3分 | 500〜900円 | 30〜60分 | カウンター |
| [中食・弁当](../20_中食・弁当/README.md) | 即時 | 500〜900円 | 0分（持ち帰り） | 販売のみ（調理は工場） |

境界がとくに曖昧なのは次の3つ。

- **サイゼリヤ**：統計上は[ファミレス](../15_ファミリーレストラン/README.md)だが、
  価格帯と客単価はFF級。本フォルダでは戦略の比較対象として[③](03_各社の戦略.md)で扱う
- **[コンビニ](../../07_小売・流通/01_コンビニエンスストア/README.md)のカウンターFF**：
  揚げ物・コーヒーはFFと同じ需要を奪い合う。統計上は小売だが、競合としては外食
- **[中食・弁当](../20_中食・弁当/README.md)**：調理が店外（工場）で完結する点でFFと分かれるが、
  昼食需要では完全な競合

## 2. 市場規模と成長性

| 指標 | 数値 | 年・出典 |
| --- | --- | --- |
| 外食産業市場規模（日本） | **約24兆1,512億円**（前年比+20.2%） | 2023年・日本フードサービス協会／食の安全・安心財団の共同推計 |
| コロナ前のピーク | 約26兆円規模 | 2019年・同推計 |
| 市場動向調査（会員企業の全店ベース） | 月次で公表。2022年以降は前年比プラスが継続 | 日本フードサービス協会 |
| 飲食店の倒産件数 | 2026年上半期 **473件**（上半期として過去最多、4年連続増） | 2026年7月・帝国データバンク |

成長性の読み方は3点。

- **市場全体は横ばい〜微増**。人口減で食事回数そのものは増えない。
  数字の伸びは**値上げによる単価上昇**が主因で、数量（食事回数）は伸びていない
- **業態間のシェア移動が本番**。個人店が減り、チェーンと[中食](../20_中食・弁当/README.md)・
  [コンビニ](../../07_小売・流通/01_コンビニエンスストア/README.md)に需要が移っている
- **成長の主戦場は海外**。トリドールHD、ゼンショーHD、サイゼリヤはいずれも海外比率を
  高めているが、トリドールHDが2026年3月期に海外で114億円の減損を計上したように、
  **国内で確立した型がそのまま通用するとは限らない**

## 3. バリューチェーン（川上 → 川下）

```
【ファストフードのバリューチェーン】

  生産               加工・製造            流通              店舗            顧客
  ────────────────────────────────────────────────────────────────────
  畜産・飼料 ─┐
  水産       ─┤
  農業       ─┼─▶ 食品メーカー ──▶ 食品卸 ──▶ 本部 ──▶ 直営店 ──▶ 消費者
  製粉・製油 ─┘     セントラル        専用      ↑        FC店
                    キッチン          物流      │         ▲
                                              商品開発     │
                                              価格決定  ロイヤリティ
                                              ブランド     │
                                              購買交渉 ────┘

  ※為替・国際相場が川上を直撃し、そのまま店の原価率（F）に乗る
  ※付加価値が集まるのは「本部」。商品開発・購買力・ブランド・立地情報を握る
```

| 段階 | 誰が何をするか | 付加価値の所在 |
| --- | --- | --- |
| 川上（原料） | [畜産・飼料](../13_畜産・飼料/README.md)、[水産](../11_水産/README.md)、[製粉・製糖・製油](../02_製粉・製糖・製油/README.md) | 市況商品。価格決定力は弱い |
| 加工 | [総合食品](../01_総合食品/README.md)、[冷凍食品・惣菜](../06_冷凍食品・惣菜/README.md)メーカー、本部のセントラルキッチン | 規格化のノウハウ |
| 流通 | [食品卸](../../06_商社・卸売/06_食品卸/README.md)、専用物流センター、[陸運・トラック](../../13_運輸・物流/06_陸運・トラック/README.md) | 多頻度・定温配送の運営力 |
| **本部** | 商品開発、価格決定、購買交渉、立地開発、ブランド、FC管理 | **ここに集中する** |
| 店舗 | 調理・接客・清掃 | 標準化により、個店の裁量は小さい |

> ポイント：ファストフードは**意図的に「店」から付加価値を抜いた業態**である。
> 店が特別でなくなるほど、複製が容易になり、店数が増え、購買力とブランドが強くなる。
> だから本部が強く、店（とくにFC加盟店）は薄い利益で運営することになる。

## 5. 収益モデル・コスト構造

**店舗の損益**（売上100とした比率。詳細は [①](01_外食1店舗の経済.md)）

| 項目 | 比率 | 性格 |
| --- | --- | --- |
| F：食材費 | 28〜32% | 変動費。メニュー構成と仕入で決まる |
| L：人件費 | 28〜32% | 準固定費。**ピーク時の必要人数**で決まる |
| **FL合計** | **60%以内が目安**（65%超で赤字圏） | 外食の共通言語 |
| R：家賃 | 10%以内 | **完全な固定費**。出店契約時に確定 |
| 水道光熱費 | 5〜7% | 厨房のガス・電気 |
| 販促・減価償却・その他 | 10〜17% | — |
| **営業利益** | **目標10%、実際は5〜8%** | — |

**本部の収益**は、直営とFCで性格が変わる。

- **直営**：店舗売上をまるごと計上。利益は厚いが、初期投資（1店4,000万〜1.5億円）を自社で負う
- **FC**：①ロイヤリティ（売上の3〜7%が主流）②食材・資材の卸売マージン ③加盟金。
  1店あたりの利益は薄いが、**資本を使わず店数を増やせる**

## 6. 競争要因（KSF）と参入障壁

| KSF | なぜ効くか |
| --- | --- |
| **立地** | 家賃比率10%を切れるかで出店可否が決まる。良い区画は有限で、先に押さえた側が強い |
| **標準化の完成度** | 未経験者が即戦力になるほど、L（人件費）が下がり離職にも耐えられる |
| **購買力（店数）** | 店数が多いほど食材が安く買え、F（原価率）が数ポイント下がる |
| **ブランド** | 値上げしても客が戻るかどうかを決める。個人店との最大の差 |
| **チャネルの数** | 店内・テイクアウト・ドライブスルー・デリバリー・アプリ。席数という上限を外せる |
| **顧客ID（アプリ会員）** | 来店頻度を直接動かせる。客単価には上限があるが頻度にはない |

**参入障壁**は、一見低く（1店なら数千万円で開業できる）、実は高い。

- 1店だけなら誰でも始められるが、**チェーンとして成立させるには数十〜百店規模が必要**。
  そこに届かないとセントラルキッチンも購買力も広告効率も効かない
- **立地の先行者優位**が強い。主要幹線・駅前の好区画はすでに埋まっている
- **人が採れない**。2026年時点では、出店できても人員を確保できずに開店できないケースがある

## 7. 規制・法制度

| 分野 | 内容 |
| --- | --- |
| **食品衛生法** | 飲食店営業許可（保健所）。2021年6月から**HACCPに沿った衛生管理が全事業者に義務化** |
| **食品表示法／景品表示法** | アレルゲン表示、原産地表示、優良誤認・有利誤認（産地偽装や「実質〇〇円」表示の規制） |
| **労働基準法** | 深夜割増（22時〜5時に25%以上）、時間外労働の上限規制。深夜営業の採算を直撃 |
| **最低賃金法** | 都道府県ごとに毎年改定。2025年度は全国加重平均1,121円（+66円）。外食最大のコスト変数 |
| **入管法（特定技能）** | 特定技能1号「外食業」。分野別上限5万人に到達し**2026年4月13日から新規受入を当面停止**。技能実習は2027年4月に育成就労へ移行予定 |
| **フランチャイズ関連** | 中小小売商業振興法の法定開示書面、独占禁止法（フランチャイズ・ガイドライン） |
| **支援策** | 中小企業省力化投資補助金（配膳ロボット等、上限1億円・補助率最大2/3）、農水省・厚労省「省力化投資促進プラン（飲食業）」（2025年6月） |

## 8. 最近のトピック

詳細は [⑤ 直近トピック（2026年9月時点）](05_直近トピック_2026.md)。要点は5つ。

- **コストが複合化した**。チキンショック（鶏肉高騰）と中東情勢による容器・包装資材高騰が重なり、
  日経報道では外食企業の約6割が2026年度に値上げ
- **牛丼の価格戦争が一巡**。すき家が2025年9月の値下げ（480→450円）を
  2026年7月に元に戻した。値下げで客数は取れたがセグメント営業利益は▲62.0%
- **大手は増収増益、ただし客単価主導**。マクドナルドは既存店43四半期連続増収だが
  2026年5月の客数は+0.6%にとどまる
- **人の供給に制度的な天井**。特定技能「外食業」が2026年4月13日から新規受入停止
- **倒産は過去最多**。2026年上半期の飲食店倒産473件。大手は最高益という格差が鮮明
