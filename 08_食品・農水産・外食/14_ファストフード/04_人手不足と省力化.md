# ④ 人手不足と省力化 — 最低賃金が上がるたびに店が1軒消える

このノートで分かること：なぜ外食で人が採れないのか。
**最低賃金の上昇がなぜ外食にだけ致命傷になるのか**。
セルフレジ・配膳ロボット・調理自動化がどこまで効き、どこで効かないのか。

> 結論：外食のL（人件費）は、**そのほとんどが最低賃金近傍の時給で構成されている**。
> だから最低賃金が3%上がれば人件費もほぼ3%上がる。他産業のように
> 「賃上げは上位層だけ」という逃げ方ができない。
> [① 外食1店舗の経済](01_外食1店舗の経済.md)で見たとおり人件費率は売上の約30%なので、
> **最低賃金+3%は、営業利益率10%の店から利益の1割弱を一撃で奪う**。
> 省力化投資は、この目減りを埋めるための防衛であって、成長投資ではない。

---

## 1. 最低賃金が「最大のコスト圧力」である理由

外食のアルバイト時給は、多くの地域で**最低賃金＋数十円**の水準にある。
つまり最低賃金は、外食にとって**業界全体の人件費を一斉に動かす政策変数**である。

```
【最低賃金上昇のインパクト（月商1,200万円の店）】

  人件費率 30% → 月の人件費 360万円
  うちアルバイト分が 7割 → 252万円

  最低賃金が 3% 上がると …… 252万 × 3% = 約 7.6万円／月
                              = 年 約 91万円

  この店の営業利益率が 8%（＝月96万円、年1,152万円）だとすると
  年91万円は 営業利益の約8% に相当する

  ※さらに、最低賃金近辺の人が上がると「その少し上の人」も上げざるを得ない
    （賃金圧縮＝ペイコンプレッション）ので、実際の負担はこれより大きい
```

| 項目 | 内容 |
| --- | --- |
| 2025年度の最低賃金 | 全国加重平均 **1,121円**（前年度比 +66円、約+6.3%）に改定（厚生労働省） |
| 2026年度 | 中央最低賃金審議会の目安を経て各都道府県で改定。**最新は厚労省の公表で確認すること** |
| 外食業の平均賃金 | 月額 **約26万円**で、全産業のなかで最低水準とされる（政府統計にもとづく報道） |
| 特徴 | 年齢・勤続による賃金の上がり方が小さく、**長く働いても賃金が伸びにくい** |

> ポイント：**外食の賃金が低いのは、外食が儲かっていないから**である。
> [① 外食1店舗の経済](01_外食1店舗の経済.md)の通り、外食の営業利益率は良くて10%。
> ここから賃金を上げる原資は出てこない。だから
> **「人手不足 → 賃上げ → 利益減 → 値上げ → 客数減」**というループに入る。
> このループを止める手は、値上げが通る商品力を作るか、省力化で人数そのものを減らすかの2つしかない。

## 2. なぜ外食で人が採れないのか — 4つの構造要因

| 要因 | 中身 | なぜ外食で深刻か |
| --- | --- | --- |
| **① 労働人口の減少** | 15〜64歳人口が減り続けている | 外食の主戦力である学生・主婦層のパイそのものが縮小 |
| **② 他業種との時給競争** | 物流倉庫・小売・介護などが同じ層を奪い合う | **外食は立ち仕事・ピークの忙しさ・クレーム対応**があり、同じ時給なら選ばれにくい |
| **③ 時間帯のミスマッチ** | 人が欲しいのは昼ピークと夜・深夜 | 学生は昼に学校、主婦は夜に家庭。**欲しい時間に人がいない** |
| **④ 離職率の高さ** | 短期間で辞める人が多い | 採用・教育コストが繰り返し発生し、実質的な人件費を押し上げる |

```
【離職率が効く仕組み — 見えない人件費】

  1人採用するコスト  … 求人広告 3万〜10万円 ＋ 面接・手続きの時間
  1人育てるコスト    … 教育担当の時給 × 20〜40時間 ＋ 本人の未熟練期間

  → 1人あたり 10万〜20万円 と言われる

  年間の離職者が 20人／店 なら、年 200万〜400万円が
  「売上を1円も生まない人件費」として消える

  ※標準化されたファストフードは教育が短くて済むぶん、この損失が小さい。
    標準化は、離職前提の労働市場に対する適応でもある
```

## 3. 外国人材 — 支え手が、制度の上限にぶつかった

外食は外国人材への依存度が高い。とくに都市部の店舗では、留学生アルバイトと
在留資格「特定技能」で働く人がいなければシフトが組めない状況が広がっている。

| 制度 | 内容 | 2026年の状況 |
| --- | --- | --- |
| **留学生のアルバイト** | 資格外活動許可で**週28時間まで** | 時間の上限があり、フルタイムの穴埋めにはならない |
| **特定技能1号「外食業」** | 外食の現場で即戦力として就労できる在留資格。分野別の**受入上限5万人** | 2026年2月末で在留者が**約4.6万人**に達し、**2026年4月13日から新規受入を当面停止**すると農林水産省・出入国在留管理庁が発表（2026年3月27日） |
| **技能実習 → 育成就労** | 技能実習制度は**2027年4月に育成就労制度へ移行**予定 | 外食分野の人材育成ルートが再設計される見込み |

```
【特定技能「外食業」の受入停止が意味すること】

  2019年  制度開始、分野別上限 5万人（5年間の想定）
     │
     ▼
  2026年2月末  在留者 約4.6万人 …… 想定より速いペースで上限に接近
     │
     ▼
  2026年4月13日  新規の在留資格認定証明書交付を当面停止
                 （技能実習からの移行など一部例外を除く）
     │
     ▼
  影響：・新規採用の前提が崩れた店舗が出る
        ・すでに在留している人材の獲得競争（＝賃金競争）が激化
        ・上限の引き上げか、育成就労での再設計かが今後の論点
```

> ポイント：**外国人材は「安い労働力」ではなく「そもそも人がいない穴を埋める手段」**だった。
> その手段に制度上の天井がついた以上、残る道は**省力化しかない**。
> 2026年に外食各社の省力化投資が加速しているのは、この制度変更と無関係ではない。

## 4. 省力化の3層 — どこを削っているのか

省力化と一口に言うが、**削っている作業はまったく違う**。3つの層に分けて見る。

| 層 | 対象作業 | 主な手段 | 削減できる人時の目安 | 難易度 |
| --- | --- | --- | --- | --- |
| **① 受注・会計** | 注文を聞く、金を受け取る | セルフオーダー端末、券売機、モバイルオーダー、セルフレジ、キャッシュレス | **大きい**（レジ係を減らせる） | **低い**（すでに普及） |
| **② 運搬・片付け** | 料理を運ぶ、食器を下げる | 配膳ロボット、下げ膳ロボット、セルフ返却口 | 中程度 | 中（導線設計が要る） |
| **③ 調理** | 焼く、揚げる、盛る | 自動フライヤー、自動炊飯、調理ロボット、盛付機 | 小〜中（工程による） | **高い**（衛生・品質・設備投資） |

```
【なぜ①から先に進んだのか】

  ①受注・会計  … 作業が定型。機械が失敗しても軽微。客も慣れている
                  → 投資回収が速い（券売機1台 数十万〜百万円で人1人分の一部を置換）
        ▼
  ②運搬        … 経路が決まっていれば機械化できるが、店の通路幅に制約される
                  → 配膳ロボットは席数の多い[ファミレス](../15_ファミリーレストラン/README.md)・
                    [回転寿司](../17_回転寿司/README.md)で先行。
                    カウンター中心のファストフードでは効果が薄い
        ▼
  ③調理        … 品目ごとに専用機が要る。汎用ロボットは高価で回収が合わない
                  → 「ロボットを入れる」より「調理をセントラルキッチンへ移す」ほうが
                    安上がりなことが多い（→ [② 特有の仕組み](02_ファストフード特有の仕組み.md)）
```

**ファストフードは①がすでに終わっている業態**である。
券売機・セルフオーダー端末・モバイルオーダーはほぼ行き渡った。
だから次の一手は②③、あるいは**そもそも作業を店から追い出す**方向に向かう。

## 5. 2026年の具体的な動き

| 領域 | 動き | 出典の性格 |
| --- | --- | --- |
| **AIドライブスルー** | 日本マクドナルドがGoogle Cloudと組み、音声認識AIによる注文受付や、袋の重量をAIで計測して渡し間違いを検知する仕組みを導入する方針と報じられる | 報道ベース（2026年1月） |
| **アプリ／ID統合** | 同社が2026年3月、ポイント制度をモバイルオーダー・デリバリー・セルフレジ・カウンター・ドライブスルーの全チャネルに統合したと報じられる | 報道ベース |
| **配膳ロボット** | 席数の多い業態を中心に導入が続く。人手不足を「解決する問題」ではなく「前提として設計する条件」と捉える動きが広がる | 業界メディア |
| **政策** | 農林水産省・厚生労働省が「省力化投資促進プラン（飲食業）」を2025年6月に取りまとめ | 政府文書 |
| **補助金** | 中小企業省力化投資補助金が配膳ロボット等を対象に、補助上限**1億円**・補助率最大**3分の2**で支援 | 政府制度 |

> ポイント：**省力化投資は「人件費の削減」ではなく「人件費の増加を吸収する」ための投資**である。
> 最低賃金が年3〜6%上がる環境では、何もしなければ利益は毎年削られていく。
> だから投資回収の計算も、「削減できた人件費」ではなく
> **「投資しなかった場合に増えていたはずの人件費」**と比べることになる。

## 6. 24時間営業の見直し — 撤退の経済

深夜営業は、**深夜割増（22時〜翌5時は25%以上の割増賃金）**が効くうえ、
そもそも人が集まらない。2020年代を通じて、外食の24時間営業は縮小してきた。

```
【深夜帯を閉めるかどうかの計算】

  深夜（22〜5時）の売上 …………… 月 60万円
  深夜の変動費（食材30%）………… 18万円
  深夜の人件費（割増込み 2名）…… 月 45万円
  ────────────────────────────
  深夜の貢献利益 …………………… ▲3万円 → 閉めたほうがよい

  ただし、閉めると次が起きる
   − 「いつでも開いている」という信頼が落ち、昼の客数も落ちる可能性
   − 深夜に来ていた配送・清掃・仕込みの段取りを組み直す必要
   − 深夜シフトで生活していた従業員の離脱

  → 「深夜だけの損益」では決められない。これはコンビニの時短問題と同じ構図
```

コンビニでは本部と加盟店で損益分岐がズレるという固有の問題があったが
（→ [コンビニ ① 1店舗の経済学](../../07_小売・流通/01_コンビニエンスストア/01_1店舗の経済学.md)）、
外食は**直営比率が高い会社が多く、判断が早い**。
実際、牛丼チェーンでも深夜の閉店や無人時間帯の設定が進んでいる。

## 7. 人手不足に耐えられなかった店はどうなったか

2026年上半期（1〜6月）の飲食店倒産は **473件** で、前年同期の458件を上回り
**上半期として過去最多**、4年連続の増加となった（帝国データバンク調査、2026年7月公表）。

| 業態 | 2026年上半期の件数 | 特徴 |
| --- | --- | --- |
| 酒場・ビヤホール（[居酒屋](../16_居酒屋/README.md)主体） | **125件**（前年同期比 +19.0%） | 2023年以降4年連続で上半期100件超 |
| 中華・東洋料理店 | **91件** | 過去最多 |
| その他 | — | 食材・光熱費高騰、賃上げ、特定技能の受入停止など環境変化への対応力差が出た |

倒産の中心は**中小・零細の個人店**であり、大手チェーンではない。
理由は[① 外食1店舗の経済](01_外食1店舗の経済.md)から説明できる。

- **仕入価格が違う**。チェーンは購買量でF（原価率）を数ポイント下げられる
- **省力化投資ができる**。1店舗の個人店には券売機1台の投資回収も重い
- **値上げの通り方が違う**。ブランドのあるチェーンは客が戻るが、個人店は戻らないことがある
- **採用力が違う**。知名度と教育体制がある側に人が集まる

> ポイント：人手不足とコスト高は、**業界全体を縮ませるのではなく、業界内の格差を広げる**。
> 淘汰された個人店の需要は消えるのではなく、チェーンと
> [中食・弁当](../20_中食・弁当/README.md)・[コンビニ](../../07_小売・流通/01_コンビニエンスストア/README.md)へ流れる。
> 2026年の外食市場でチェーン各社の既存店がプラスを続けているのは、
> 需要が増えたからというより、**受け皿が減ったから**という側面がある。

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **最低賃金** | 使用者が支払わなければならない賃金の下限。都道府県ごとに毎年改定。2025年度は全国加重平均1,121円（+66円） |
| **ペイコンプレッション（賃金圧縮）** | 最低賃金が上がると、その少し上の層との差が縮まり、結果的に上の層も上げざるを得なくなる現象 |
| **深夜割増** | 22時〜翌5時の労働に25%以上の割増賃金が必要（労働基準法）。深夜営業の採算を悪くする最大要因 |
| **人時（にんじ）／人時売上高** | 1人が1時間働く量。売上 ÷ 総労働時間 ＝ 人時売上高。外食の労働生産性を測る基本指標 |
| **特定技能1号「外食業」** | 外食の現場で就労できる在留資格。分野別上限5万人。2026年4月13日から新規受入が当面停止された |
| **資格外活動許可** | 留学生がアルバイトをするための許可。原則**週28時間まで**の上限がある |
| **育成就労制度** | 技能実習制度に代わる新制度。2027年4月に移行予定 |
| **セルフオーダー端末** | 客が自分で注文を入力する端末。受注・会計の人員を削減できる省力化の第一段階 |
| **配膳ロボット** | 料理を席まで運ぶ自走ロボット。席数が多く通路の広い業態で効果が出やすい |
| **中小企業省力化投資補助金** | 省力化設備の導入を支援する国の補助金。補助上限1億円、補助率最大3分の2 |
| **貢献利益** | 売上から変動費を引いた額。「この時間帯／この店を続けるべきか」を判断するときに使う |
