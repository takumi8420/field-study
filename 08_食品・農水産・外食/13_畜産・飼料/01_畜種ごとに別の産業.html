① 畜種ごとに別の産業 ― 牛・豚・鶏

このノートで分かること。
「畜産業」という一つの産業は存在しない。牛・豚・鶏は、資金の寝かせ方も、
経営形態も、価格の決まり方も、まったく違う3つの産業である。
その違いを、肥育期間・資金負担・工業化の度合いという3つの軸で分解する。

酪農（乳を搾る牛）は 乳業 側で扱っている。
このノートは 肉を取る畜産＝肉用牛・豚・鶏 に軸足を置く。

1. 結論：違いは「お金が何か月寝るか」で決まる

同じ家畜でも、生まれてから出荷できるまでの期間がまるで違う。
これが経営のかたちをほぼ全部決めてしまう。

  • 牛：子牛を買ってから出荷まで 約20か月。1頭100万円超の資産が2年近く寝る
    → 資金負担が重く、借入が要る。買った時の子牛価格と、売る時の枝肉相場が2年ずれる
  • 豚：種付けから出荷まで 約10か月（肥育だけなら約6か月）。
    繁殖から出荷までを1つの農場でやる一貫経営が主流。ずれが小さい代わりに病気が全部止める
  • 鶏（ブロイラー）：ヒナから出荷まで 約50日。
    回転が速いので工場のように回せる。だから最も工業化＝インテグレーションが進んだ
【お金が寝る時間の比較 ― これが業界構造を決める】

 牛（肥育）  ■■■■■■■■■■■■■■■■■■■■  約20か月／1頭 100万円超
             └ 子牛を買う ────────────────▶ 枝肉で売る
                （ここで価格が決まる）      （2年後の相場は誰にも分からない）

 豚         ■■■■■■■■■■  約10か月（種付→出荷）／1頭 数万円
             └ 自分の農場で子豚を作る ──▶ 売る
                （買値リスクがない代わりに、病気が出たら全滅）

             └ ヒナを入れる ─▶ 出荷 ─▶ 鶏舎を洗って次のヒナ（年6〜7回転）
                （契約で飼うだけ。相場リスクはインテグレーターが持つ）

ポイント：牛は金融業に近く、鶏は製造業に近い。豚はその中間で、衛生管理が生命線。

3. 牛 ― 肥育期間が長く、資金負担が重い

3.1 「繁殖」と「肥育」は別の農家がやっている

日本の肉用牛は、牛を産ませる人と牛を太らせる人が分かれている。

【牛肉ができるまで ― 2人の農家と1つの市場】

 ① 繁殖農家              ② 家畜市場（子牛せり）        ③ 肥育農家
  母牛を飼い、            生後8〜10か月の子牛を        子牛を買って
  毎年1頭 子牛を産ませる ──▶ せりで売買            ──▶ 約20か月 肥育  ──▶ 食肉処理場
  （山間地・中小規模）     ★ここで子牛価格が決まる      （大規模・資金力）    （枝肉になる）
       │                                                    │
       │                                              ★ここで枝肉価格が決まる
       └ 収入＝子牛の売値                                    └ 収入＝枝肉の売値 −子牛代 −飼料代

  この「①の売値」と「③の仕入値」は同じもの。
  つまり、子牛が高いと繁殖農家は儲かり、肥育農家は苦しむ（利害が正反対）。

子牛価格が上がれば繁殖農家が潤い、肥育農家が痛む。
この綱引きが牛の業界ニュースの大半を占める。

3.2 和牛・交雑種・乳用種 ― 同じ「国産牛」でも中身が違う

店頭で「国産牛」と書かれているものは、実は3系統に分かれる。

区分 中身 出どころ 価格帯（枝肉・目安）
和牛黒毛和種・褐毛和種など日本固有の肉用品種。霜降り（脂肪交雑）が特徴繁殖農家が専用の母牛から生産最も高い。2026年3月の東京市場A5去勢は 2,640円/kg（前年同月比+2.4%、日本農業新聞）
交雑種（F1）乳用牛（ホルスタイン）の母に和牛の種を付けた子。和牛と乳用種の中間酪農家の副産物。酪農の経営判断で数が決まる中間
乳用種（ホルスタイン去勢など）乳の出ない雄の乳用牛を肉用に育てたもの酪農家の副産物。乳用牛は雌しか搾れないので雄は肉になる最も安い

ここが重要：交雑種と乳用種の供給量は、肉の需要ではなく酪農の都合で決まる。
酪農家が減り、乳価が厳しくなって和牛の種付けを減らせば、数年後に交雑種の肉が減る。
牛肉と牛乳が同じ問題を共有しているのはこのため（→ 乳業 ③構造問題）。

3.3 子牛価格と枝肉相場の連動 ― 2年のズレが赤字を作る

肥育農家の損益はきわめて単純で、「売った枝肉代 −（20か月前に買った子牛代＋飼料代）」。
問題は、子牛を買う時点で、2年後の枝肉相場が分からないこと。

時期 数値 出典
和牛子牛 全国平均取引価格（2026年3月）1頭 847,245円（前月比+3.8%、前年同月比+32.6%）日本農業新聞
東京食肉市場 枝肉加重平均（A5去勢、2026年3月）2,640円/kg（前年同月比+2.4%）日本農業新聞
肥育経営の試算1頭あたり15万円程度の赤字の恐れ日本農業新聞の試算（報道ベース）
2026年度の和牛肉生産10年ぶりの減少見込み日本経済新聞報道（2026年5月）

なぜこうなるか。

  1. 牛肉の消費が値上げで落ち、繁殖農家が母牛を減らした
  2. 数年遅れて子牛の頭数が減る → 子牛価格が急騰（前年比3割高）
  3. しかし枝肉相場は消費低迷でそこまで上がらない
  4. 結果、高い子牛を買って、上がりきらない枝肉で売る＝赤字

   │                          ╱

   │                    ╱

       この「開いた口」の幅が、肥育農家1頭あたりの赤字。

3.4 牛マルキン ― 赤字の9割を埋める制度

マルキン＝「肉用牛肥育経営安定交付金」の通称（「◯の中に金」の字から）。
畜産経営の安定に関する法律（畜安法）に基づく制度で、仕組みはこうなっている。

【マルキンの計算】

  標準的販売価格（その四半期に実際に売れた平均価格）
      │
      │  ← この差が「赤字」
      ▼
  標準的生産費（子牛代＋飼料代などの平均的なコスト）

      交付金 ＝ （標準的生産費 − 標準的販売価格）× 90%

      原資：生産者の積立 1/4 ＋ 国の補助 3/4
      単位：都道府県別・品種区分別（肉専用種／交雑種／乳用種）に毎月算定
論点 中身
対象肉用牛肥育経営（牛マルキン）と肉豚経営（豚マルキン）。あらかじめ加入して積み立てておく必要がある
補塡率差額の 90%。残り10%は自己負担
契約期間現行は 2025年4月1日〜2028年3月31日（農畜産業振興機構=alic）
発動の実際自動では出ない。2026年3月販売分は、導入時（約2年前）の子牛価格が低かったため肉専用種で発動なしと報じられた（日本農業新聞）

注意すべき点：マルキンの「標準的生産費」は、2年前に買った子牛の価格をベースに計算される。
つまり、今まさに高い子牛を買っている農家の痛みは、2年後にしか制度に反映されない。
制度があっても足元の資金繰りは助からない、というのが現場の不満の中心にある。

4. 豚 ― 一貫経営と衛生管理

豚は牛と違い、繁殖から出荷までを1つの経営体でやる「一貫経営」が主流。
母豚に種を付け、生まれた子豚をそのまま自分の農場で肥育して出荷する。

特徴 なぜそうなるか
子豚を買わない母豚1頭から年間20頭以上の子豚が取れる。外から買うより自分で作るほうが安く、病気の持ち込みも防げる
だから相場リスクが牛より小さい「高値で仕入れた資産を抱える」という状態が生じにくい。変動するのは飼料代と枝肉相場の2つだけ
代わりに疾病リスクが致命的農場内で繁殖まで完結しているぶん、病気が入ると繁殖の土台ごと失う。再建に1年以上かかる
規模拡大が進んだ戸数は減り続けているが1戸あたりの頭数は増加。設備投資（換気・糞尿処理・防疫）が重く、中小は続けられない

衛生（バイオセキュリティ）が経営そのもの

養豚で「衛生」というのは掃除の話ではなく、ウイルスを農場に入れない設計のこと。

【養豚農場のバイオセキュリティ（考え方）】

  外部（野生イノシシ・車両・人・飼料・ネズミ）
        │
   ─────┼───── 防護柵・消毒槽・車両消毒            ← ①入口で止める
        │
   ─────┼───── シャワーイン／専用長靴・作業着       ← ②人に付けて持ち込ませない
        │
   ─────┼───── 農場内を清浄区域／汚染区域に分ける   ← ③中で広げない
        │
      豚舎（母豚・子豚・肥育豚）

  ★ 豚熱（CSF）は発症すればほぼ100%死ぬ。だから「治す」のではなく「入れない」が唯一の戦略。
  • 豚熱（CSF）：2018年9月に国内で26年ぶりに発生し、以後、野生イノシシを介して各地に拡大。
    2019年から対象地域でワクチン接種が行われている（農林水産省）。
    ワクチンを打っていても発生した農場は全頭殺処分が原則で、経営は一度止まる。
  • アフリカ豚熱（ASF）：ワクチンがない。アジアで流行しており、国内に入れば養豚は壊滅的打撃を受ける。
    空港の水際検疫が強化されているのはこのため。

5. 鶏 ― インテグレーションで最も工業化された

5.1 インテグレーション＝ヒナから精肉まで1社で通す

インテグレーション（垂直統合）とは、
種鶏 → ふ化（ヒナ）→ 飼料 → 飼育 → 食鳥処理 → 加工 → 販売という
本来バラバラの工程を、1つの企業グループがまとめて運営するやり方のこと。
その運営主体をインテグレーターと呼ぶ。

【ブロイラーのインテグレーション】

  ┌──────────────────── インテグレーター（1社または1グループ） ─────────────────┐
  │                                                                             │
  │  種鶏場 ──▶ ふ化場 ──▶ ［ヒナ・飼料・薬を支給］──▶ 食鳥処理場 ──▶ 加工・販売 │
  │                              │         ▲                                    │
  └──────────────────────────────┼─────────┼────────────────────────────────────┘
                                 ▼         │
                            契約生産農家（鶏舎で50日育てる）
                            ・ヒナと飼料は「買わない」（支給される）
                            ・出荷しても「売らない」（引き取られる）
                            ・受け取るのは【飼育料（手数料）】

  → 農家は相場リスクを負わない代わりに、価格決定権も持たない。
     相場も在庫も、すべてインテグレーターが引き受ける。
指標 数値 出典
インテグレーション化の比率9割超農林水産省資料
上位9グループのシェア年間処理羽数の 6割強農林水産省資料
ブロイラー経営費に占める飼料代64%農林水産省資料
同・ヒナ代16%（飼料と合わせて約8割が輸入資源に依存）農林水産省資料

なぜ鶏だけここまで統合が進んだのか。理由は3つ。

  1. 回転が速い（約50日）ので、工程を計画的に同期させる価値が大きい
  2. 飼料とヒナで経営費の8割を占める。ここを企業がまとめて調達すればコストが下がる
  3. 1羽あたりの単価が小さく、規模でしか利益が出ない

牛の業界ニュースが「子牛が高い／安い」なのに対し、
鶏の業界ニュースが「◯◯社が処理場を新設」になるのは、この構造の違いによる。

5.2 鶏卵と鶏肉は、まったく別の商売

同じ「鶏」でも、採卵鶏とブロイラーは品種からして別であり、産業としても別物。

軸 鶏卵（採卵鶏） 鶏肉（ブロイラー）
品種採卵用（白色レグホーン系など）。産卵に特化肉用（チャンキー等）。成長速度に特化
商品の性質毎日産まれ続ける。止められない（生乳に似ている）出荷日を決められる。計画生産しやすい
価格日々の建値（相場）で動く。JA全農たまごの基準価格が指標部位別に卸売。契約取引の比重が高い
需給の性格供給が急には増やせない（ヒナを入れて産み始めるまで約5か月）50日サイクルで増減できる
直近の価格2026年7月の卸売月平均 303円/kg、2026年8月上旬の小売全国平均 10個305円（報道ベース）―

鶏卵の価格が跳ねやすい理由がここにある。
鳥インフルエンザで採卵鶏が殺処分されると、代わりのヒナを入れても産み始めるのに約5か月かかる。
だから供給の穴はすぐには埋まらず、価格が数か月単位で高止まりする。
「物価の優等生」と呼ばれた卵が2023年以降たびたび高騰しているのは、この時間差のためである。

6. まとめ：この章を理解する3つの鍵

  1. 牛は「2年ずれ」の産業。子牛を買う判断と枝肉を売る結果が20か月離れているので、
    構造的に「高値で買って安値で売る」局面が周期的にやってくる。マルキンはその9割を埋めるが、
    計算の基準が2年前なので足元の痛みには遅れる。
  2. 豚は「入れない」ことがすべて。一貫経営で相場リスクは小さいが、
    豚熱・ASFが農場に入れば繁殖の土台ごと失う。設備投資の主目的が防疫になっている。
  3. 鶏は最も工業化された。飼料代64%＋ヒナ代16%という原価構造が規模の競争を生み、
    インテグレーションが9割超に達した。農家は相場リスクを負わない代わりに価格決定権もない。
    そして鶏卵と鶏肉は別産業で、卵は「約5か月の再生産の時間差」ゆえに価格が跳ねる。

枝肉（えだにく）食肉処理場で家畜から皮・頭・内臓・四肢の先を取り除いた、骨付きの胴体部分。食肉取引の基本単位で、「枝肉相場」＝この状態の1kgあたり価格。ここから部位ごとに切り分けたものが精肉
肥育（ひいく）子牛・子豚を、出荷できる体重・肉質まで太らせる工程。牛で約20か月、豚で約6か月
繁殖（はんしょく）母牛（母豚）を飼い、子を産ませる工程。牛では肥育と別の農家が担うことが多い
交雑種（F1）乳用牛（ホルスタイン）の母に和牛の種を付けて生まれた牛。和牛と乳用種の中間の肉質・価格
マルキン肉用牛肥育経営安定交付金（牛マルキン）・肉豚経営安定交付金（豚マルキン）の通称。標準的販売価格が標準的生産費を下回ったとき、差額の90%を交付する制度。原資は生産者積立1/4＋国3/4
インテグレーション（垂直統合）ヒナ・飼料の供給から飼育、食鳥処理、加工、販売までを1つの企業グループが一貫して行う仕組み。運営主体をインテグレーターと呼ぶ。ブロイラーでは9割超がこの形
ブロイラー食肉用に品種改良された若鶏。約50日で出荷される
採卵鶏（さいらんけい）卵を産ませるための鶏。ブロイラーとは別品種。ヒナを入れてから産卵開始まで約5か月
豚熱（CSF）豚・イノシシのウイルス性伝染病。発症すればほぼ100%死亡。人には感染しない。2018年に国内で26年ぶりに発生し、2019年からワクチン接種
アフリカ豚熱（ASF）豚熱とは別のウイルス。ワクチンがないため、水際で止める以外に手段がない
バイオセキュリティ病原体を農場に入れない・広げないための衛生管理の設計全般
