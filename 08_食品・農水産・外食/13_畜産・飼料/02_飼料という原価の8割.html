② 飼料という原価の8割

食品・農水産・外食畜産・飼料

利点限界限界その2配合飼料濃厚飼料粗飼料（そしりょう）大豆粕（だいずかす）配合飼料価格安定制度通常補塡異常補塡もと畜費（もとちくひ）エコフィードTDN（可消化養分総量）飼料用米パナマックス型

このノートで分かること。
日本の畜産経営は、シカゴの穀物相場と為替と海上運賃で損益が決まる。
自分では1円も動かせないコストが原価の6〜8割を占める、という構造を分解する。
そのうえで、それを和らげる配合飼料価格安定制度と、
逃れようとする国産化（飼料用米・エコフィード）を見る。

1. 結論：畜産は「輸入穀物を肉に変える加工業」である

日本の畜産農家が何をしているか、経済的に言い換えるとこうなる。

ドル建てで買った輸入穀物を、円建てで売る肉・卵に変換している。
つまり畜産経営は、実態として為替と穀物相場のリスクを取る商売になっている。

  • 配合飼料の主原料はトウモロコシと大豆粕。そのほとんどが輸入
  • 日本の濃厚飼料の自給率は約13%（＝約87%が輸入）。飼料全体でも約26%（農林水産省資料）
  • ブロイラー経営では飼料代が経営費の64%、ヒナ代16%と合わせて約8割が輸入資源（農林水産省資料）
  • 酪農・肉用牛でも飼料費は生産費の最大項目
【畜産経営のコスト構造（考え方）】

  売上（枝肉・卵・生乳）
   │
   ├─ 飼料費 ───────────────────  50〜65%  ◀★ほぼ輸入。自分では決められない
   │   └ トウモロコシ／大豆粕／麦類／ぬか類／ビタミン・ミネラル
   ├─ もと畜費（子牛代・子豚代・ヒナ代）  10〜30%  ◀牛で特に大きい
   ├─ 労働費                                  ◀家族労働が多く、実質は「残り」
   ├─ 減価償却（畜舎・機械）                 ◀糞尿処理・換気設備が近年重い
   ├─ 光熱動力・診療衛生・敷料 など
   └─ 残り＝所得

  ※畜種・規模で比率は大きく変わる。ここは構造を示すための概算。

  → 費用のトップ2（飼料・もと畜）がどちらも「相場」で、
    農家に価格交渉力がない。ここが畜産経営の根本的な弱さ。

2. 配合飼料とは何か

配合飼料とは、家畜が必要とする栄養（エネルギー・たんぱく質・ビタミン・ミネラル）を
畜種や成長段階ごとに計算して、複数の原料を混ぜて作った工業製品のこと。
農家が原料を自分で買って混ぜるのではなく、飼料メーカーから完成品として買う。

原料 役割 調達先 配合の目安
トウモロコシエネルギー源。配合飼料の主役米国・ブラジル・アルゼンチンなど。ほぼ全量輸入約5〜6割
大豆粕（だいずかす）たんぱく源。大豆から油を搾った残り輸入（または国内製油の副産物）約1〜2割
麦類・こうりゃん（ソルガム）エネルギー源の代替輸入数%
ぬか類・ふすま繊維・副産物国内製粉・精米の副産物が使える数%
動物性たんぱく・油脂・添加物栄養調整国内外少量

粗飼料（そしりょう）は別物で、牧草・稲わら・デントコーン（飼料用トウモロコシの茎葉）など
繊維を取るための飼料。牛（反芻動物）には必須で、豚・鶏にはほぼ不要。
粗飼料は国産の比率が比較的高いが、輸入乾草も相当量使われている。

覚え方：濃厚飼料＝カロリーとたんぱく（穀物）＝ほぼ輸入。
粗飼料＝繊維（牧草）＝牛だけが必要で、国産余地がある。

3. 価格はどう決まるか ― 3つの外部要因

配合飼料の値段は、農家にもメーカーにも決められない。次の3つの掛け算で決まる。

                   畜産農家

  ★ 改定は「四半期ごと」。つまり、相場が動いてから農家に届くまで

2026年7〜9月期の改定理由を、JA全農はこう説明している（2026年公表）。

ポイント：4つの要因が同時に悪化することがある。
穀物高・運賃高・円安は独立ではなく、原油高や地政学リスクで一緒に動きやすい。
だから飼料価格は「じわじわ上がる」のではなく「段差で跳ねる」。

4. 配合飼料価格安定制度 ― 上がった分の一部を埋める仕組み

飼料が跳ねるたびに畜産が全滅しないよう、あらかじめ積み立てておいた基金から補塡する
仕組みがある。これが配合飼料価格安定制度で、2階建てになっている。

【配合飼料価格安定制度の2階建て構造】

  飼料価格
    ▲
    │                      ┌─────────────┐
    │                      │ 異常補塡     │ ← 【2階】異常補塡基金
    │   ･･･････････････････└─────────────┘    直近1年平均の115%を超えた分
    │                                          原資：国 ＋ 飼料メーカー
    │                      ┌─────────────┐
    │                      │ 通常補塡     │ ← 【1階】通常補塡基金
    │   ─────────────────  └─────────────┘    直近1年平均を超えた分
    │   （直近1年の平均価格）                   原資：生産者の積立 ＋ 飼料メーカー
    │
    │   ■■■■■■■■■■■■■■■■■■  農家が負担する部分
    └──────────────────────────────▶ 時間

  ★ 補塡されるのは「上がった分の一部」であって、飼料代そのものではない。
  ★ 基金は積立でできている。長期の高騰が続くと枯渇し、国が積み増さないと機能しなくなる。
階層 発動条件（考え方） 原資 性格
通常補塡当期の価格が直近1年の平均を超えたとき、その差額を補塡生産者の積立金＋飼料メーカーの拠出生産者が自分で積んだお金の払い戻しに近い
異常補塡輸入原料価格が直近1年平均の115%を超えるような異常高騰のとき、通常補塡の上に上乗せ国（補助）＋飼料メーカー制度の名のとおり「異常時」の追加セーフティネット

この制度を誤解しないための3点。

  1. 全額は埋まらない。補塡は値上がり分の一部であり、飼料代の水準そのものは下がらない
  2. 高値が続くと効かなくなる。基準が「直近1年の平均」なので、
    高値が1年続けば、その高値が新しい基準になる。高止まりには構造的に無力
  3. 基金が尽きる。2022年以降の高騰局面では、国による基金の積み増しが繰り返された

ここが制度の本質：配合飼料価格安定制度は「急変を均す」制度であって、
「高い飼料を安くする」制度ではない。 2022年以降の局面が苦しいのは、
急変ではなく高値の常態化だからである。

5. 飼料高騰は、どうやって経営を潰すか

「飼料が上がると苦しい」では説明になっていない。潰れ方には順番がある。

【飼料高騰 → 廃業までの連鎖】

 ① 飼料価格が上がる
      ▼
 ② 1頭（1羽）あたりの利益が薄くなる／マイナスになる
      ▼
 ③ 短期の資金繰りが回らなくなる ← ★ここが実際の破綻点
      （飼料代は毎月払う。売上は出荷時にしか入らない）
      ▼
 ④ 頭数を減らす／更新をやめる（母牛・母豚を売る、ヒナを入れない）
      ▼
 ⑤ 数か月〜2年遅れて、子牛・子豚・食肉の供給が減る
      ▼
 ⑥ 相場が上がる ← しかしその時、辞めた農家はもう戻ってこない

破綻するのは「損益」ではなく「資金繰り」、というのが実務上の要点。
飼料代は毎月必ず出ていくが、肉用牛なら収入は20か月後にしか入らない。
だから赤字が出た瞬間ではなく、運転資金が尽きた瞬間に経営が止まる。

そして⑥が重要で、供給が減って相場が回復したときには生産基盤が失われている。
これが畜産の縮小が一方通行になる理由で、
和牛子牛の高騰（2026年、前年比3割高）も、繁殖農家が減った結果として起きている
（→ ① 畜種ごとに別の産業 第3章）。

畜種 飼料高騰が最初に出る場所 供給が減るまでの時間差
酪農毎月の乳代と飼料代の差。最も飼料費比率が高い経産牛を淘汰すれば数か月で生乳が減る
肉用牛（繁殖）母牛の更新をやめる・減らす2〜3年（子牛が減り、その後 枝肉が減る）
肉用牛（肥育）子牛の導入を絞る約20か月
養豚母豚の更新・増頭をやめる約1年
ブロイラーインテグレーターが飼育料に転嫁して吸収する数か月（ヒナの導入羽数で即調整できる）

6. 国産化という出口 ― 飼料用米とエコフィード

輸入依存から逃れるための国内の手段は、大きく3つある。いずれも「万能薬ではない」。

6.1 飼料用米

主食用でなく家畜のエサ用に作る米。水田を維持したまま転作でき、
トウモロコシの一部を置き換えられる。交付金（水田活用の直接支払交付金など）で支えられている。

  • 利点：水田を維持できる（水田は一度やめると戻すのが難しい）。国産で為替の影響を受けない
  • 限界：交付金がなければ経済的に成り立たない。交付金の見直し議論が起きるたびに作付が揺れる
  • 限界その2：トウモロコシと栄養特性が完全には同じではなく、置き換えられる比率に上限がある

6.2 エコフィード

食品残さ（食品工場の副産物、売れ残り、調理残さなど）を飼料化したもの。
「エコロジー」と「エコノミー」から作られた造語。

指標 数値 出典
エコフィード製造数量（令和4年度＝2022年度）108万TDNトン（概算）農林水産省
濃厚飼料全体に占める比率約5%農林水産省
うち国産原料由来30万TDNトン（概算）農林水産省
国産原料由来の拡大目標50万TDNトンまで拡大が必要とされる農林水産省
  • 利点：食品ロス削減と飼料自給率向上を同時に達成できる。原料コストが低い
  • 限界：成分が毎回ばらつくため、栄養設計が難しい。配合飼料の置き換えには量にも限界がある
  • 限界その2：収集・乾燥・殺菌の物流コストがかかる。近隣に食品工場がないと成立しない

6.3 粗飼料（牧草・デントコーン）の国内生産

牛にしか効かないが、面積さえあれば国産で回せる唯一の飼料。
北海道や中山間地の草地をどう維持するかという、農地・担い手の問題と直結する
（→ 農業・種苗・肥料）。

飼料自給率の目標

区分 現状（近年の農水省資料） 目標
飼料全体約 26%34%（令和12年度＝2030年度）
濃厚飼料（穀物中心）約 13%（＝87%が輸入）向上をめざす
粗飼料（牧草中心）濃厚飼料より大幅に高い草地の生産性向上で引き上げ

数字の読み方：飼料全体の自給率を26%→34%に上げるというのは、
実質的には「粗飼料をもっと国産化し、濃厚飼料の一部を飼料用米とエコフィードで置き換える」
という意味。濃厚飼料の輸入依存そのものは当面変わらない、というのが正直な現状である。

7. まとめ：この章を理解する3つの鍵

  1. 畜産は輸入穀物を肉に変える加工業。費用の6〜8割が飼料と もと畜で、どちらも相場。
    シカゴのトウモロコシ・大豆粕、海上運賃、ドル/円の4つが動くと損益が決まる。
  2. 配合飼料価格安定制度は「急変を均す」制度であって、「高値を安くする」制度ではない。
    通常補塡（直近1年平均を超えた分・生産者積立が原資）と
    異常補塡（1年平均の115%超・国が原資）の2階建てだが、高値が続けば基準そのものが上がる。
  3. 潰れるのは損益ではなく資金繰り。飼料代は毎月出るが収入は出荷時にしか入らない。
    そして一度やめた繁殖農家は、相場が回復しても戻ってこない。
