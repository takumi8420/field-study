**2026年の畜産・飼料を一行で言えば、**

> **飼料は4四半期連続で上がり、子牛は前年比3割高、牛肉消費は5年連続で減り、

## 1. 配合飼料は4四半期連続の値上げ ― 2022年以来4年ぶりの高値

JA全農の配合飼料供給価格（全国全畜種総平均・トンあたり）は、2026年に入って**4期連続で上昇**した。

| 四半期           | 改定幅                  | 備考                                                           | 出典                            |
| ---------------- | ----------------------- | -------------------------------------------------------------- | ------------------------------- |
| 2026年1〜3月期   | **+約4,200円（+5.1%）** | 4四半期ぶりの値上げ。新価格は平均約8万6,050円/トン             | JA全農発表・JAcom／日本農業新聞 |
| 2026年4〜6月期   | **+約1,250円**          | **2年ぶり高値**と報じられる                                    | JA全農発表・日本経済新聞        |
| 2026年7〜9月期   | **+約3,700円**          | 穀物高・運賃高・円安が同時進行                                 | JA全農プレスリリース（2026年）  |
| 2026年10〜12月期 | **+約3,200円（+3.5%）** | **4四半期連続の値上げ**。**2022年10〜12月期以来4年ぶりの高値** | 日本経済新聞（2026年9月）       |

### なぜ上がり続けているのか

JA全農が7〜9月期改定で挙げた4要因が、そのまま構造を示している。

| 要因                                       | 動き（2026年）                                              |
| ------------------------------------------ | ----------------------------------------------------------- |
| トウモロコシ（シカゴ定期）                 | 2月 430セント/ブッシェル → 5月上旬 **480セント/ブッシェル** |
| 大豆粕（シカゴ定期）                       | 2月 340ドル/トン → 4月 **360ドル/トン台**                   |
| 海上運賃（パナマックス型・米ガルフ〜日本） | 50ドル/トン台 → **70ドル/トン台**                           |
| 為替                                       | 155円前後 → **160円前後**の円安                             |

```
【2026年に起きていること】

   穀物高  ──┐
   運賃高  ──┼──▶ 輸入CIF（円建て）上昇 ──▶ 配合飼料 4期連続値上げ
   円 安   ──┘                                     │
                                                    ▼
                          配合飼料価格安定制度の「通常補塡」は
                          直近1年平均を基準にするため、
                          高値が続くと基準そのものが切り上がって効かなくなる
                                                    │
                                                    ▼
                                    畜産経営の負担は実質的に増え続ける
```

> 読み方の注意：**「補塡があるから大丈夫」は誤り**。
> 配合飼料価格安定制度は**急変を均す制度**であって、高止まりには構造的に弱い
> （→ [② 飼料という原価の8割](02_飼料という原価の8割.md) 第4章）。

## 2. 和牛子牛が前年比3割高 ― 肥育農家は1頭15万円の赤字試算

2026年の肉用牛でいちばん大きな話は、**子牛価格の急騰と、肥育経営の逆ざや**。

| 指標                                | 数値                                                     | 時点・出典                       |
| ----------------------------------- | -------------------------------------------------------- | -------------------------------- |
| 和牛子牛 全国平均取引価格           | **1頭 847,245円**（前月比 +3.8%、**前年同月比 +32.6%**） | 2026年3月。日本農業新聞          |
| 東京食肉市場 枝肉加重平均（A5去勢） | **2,640円/kg**（前年同月比 +2.4%）                       | 2026年3月。日本農業新聞          |
| 肥育経営の収支                      | **1頭あたり15万円程度の赤字**となる恐れ                  | 日本農業新聞の試算（報道ベース） |
| 2026年度の和牛肉生産                | **10年ぶりの減少**見込み                                 | 日本経済新聞報道（2026年5月）    |

### 何が起きたのか（時間の順序で読む）

```
 2022〜2025年
   飼料高 ＋ 牛肉消費の低迷
        ▼
   繁殖農家が母牛（繁殖雌牛）を減らす・離農する
        ▼
 2026年
   子牛の出回り頭数が減る ──▶ 子牛価格が前年比 +32.6%（2026年3月）
        │
        │  一方で 枝肉相場は消費低迷で +2.4% しか上がらない
        ▼
   肥育農家：高い子牛 × 高い飼料 ÷ 上がらない枝肉 ＝ 1頭15万円の赤字試算
        ▼
 2026年度
   肥育農家も導入を絞る ──▶ 和牛肉生産が10年ぶりに減少見込み
        ▼
 2027年以降
   供給減で相場は上がるが、その時には生産基盤が失われている
```

**繁殖農家は潤い、肥育農家が痛む**という、利害が正反対になる典型的な局面。
制度面では**牛マルキン**があるが、「標準的生産費」の計算基準が**約2年前に導入した子牛の価格**に
基づくため、**2026年3月販売分は肉専用種で発動なし**と報じられた（日本農業新聞）。
制度はあるが足元の痛みには届いていない。

## 3. 牛肉消費は5年連続で減少 ― 「輸入が高い」という逆転

消費側でも構造変化が起きている。

| 論点             | 中身                                                                             | 出典                                         |
| ---------------- | -------------------------------------------------------------------------------- | -------------------------------------------- |
| 牛肉消費         | **5年連続で減少**。コメや野菜の高騰で牛肉の購入が後回しにされていると報じられる  | 日本経済新聞（2026年2月）                    |
| 輸入牛肉         | 仕入価格の高騰が継続。米国の飼養頭数減と円安が重なる                             | 報道ベース                                   |
| 国産枝肉の値動き | 和牛・交雑種・乳用去勢とも高い状況が続き、**低い格付等級ほど相場の上昇率が高い** | 2026年、日本食肉流通センター資料・報道ベース |
| 米国（参考）     | 2026年の牛肉生産量は **1,156万2,000トン**、前年比 **約▲1.3%** の見通し           | alic／Bloomberg報道                          |

> 起きている逆転：**かつては「安い輸入牛／高い国産牛」だったが、
> 輸入牛が高騰して価格差が縮み、
> その結果「輸入の代わりに安い国産（低位等級）が買われる」という流れが生じている。**
> 国産にとっては追い風に見えるが、**牛肉全体の消費量そのものが減っている**ため、
> 「パイが縮むなかでの相対的なシェア移動」でしかない。

## 4. 鳥インフルエンザ ― 2025-2026シーズンは24事例・約576万羽

| 指標                                     | 数値                                                                                    | 時点・出典                            |
| ---------------------------------------- | --------------------------------------------------------------------------------------- | ------------------------------------- |
| 2025-2026シーズン（令和7年度）の国内発生 | **24事例**、**約576万羽**が殺処分対象                                                   | 農林水産省（2026年7月14日時点の整理） |
| 鶏卵の卸売価格                           | 2026年4月時点で前年同期比 **約3%安**。JA全農たまご基準価格（東京M）は **320円/kg** 前後 | 2026年。日本経済新聞報道              |
| 同（夏）                                 | 2026年7月の月平均卸売価格 **303円/kg**、2026年8月上旬の小売全国平均は **10個305円**     | 2026年。報道ベース                    |

### 読み方

- **殺処分規模は過去最大級の年（2022-2023シーズンの約1,771万羽）に比べれば小さい**。
  2026年に入って**卵の供給難は緩和し、卸値の高騰には一服感**が出たと報じられている
- ただし**店頭価格はなお高い**。卸値が下がっても小売価格の下げは遅れる
- 構造的な理由は変わらない。**採卵鶏はヒナを入れてから産卵開始まで約5か月**かかるため、
  殺処分で空いた穴はすぐには埋まらない（→ [③ 流通と市場](03_流通と市場.md) 第7章）
- **毎年10〜11月に渡り鳥とともに新シーズンが始まる**。
  2026年秋以降の発生状況次第で、卵価は再び跳ねうる

## 5. 和牛輸出は過去最高を更新 ― ただし米国の通商政策が影

国内が縮むなかで、**輸出は数少ない明確な成長分野**。

| 指標                   | 数値                                                        | 年・出典                                    |
| ---------------------- | ----------------------------------------------------------- | ------------------------------------------- |
| 牛肉輸出額             | **635.8億円**（前年比 +11.6%）。**過去最高**                | 2024年（令和6年）。農畜産業振興機構（alic） |
| 牛肉輸出量             | **10,113トン**（前年比 +20.1%）。**過去最高**               | 2024年。alic                                |
| 最大の輸出先           | **米国 2,139トン（+87.2%）**、全体の21.1%。台湾を抜いて首位 | 2024年。alic                                |
| 2026年上半期の輸出実績 | 牛肉は米・緑茶などとともに**過去最高額**を更新              | 2026年上半期。JAcom 農業協同組合新聞        |

**同時に不安材料もある。** 最大の輸出先になった米国向けは、
米国の通商政策（関税）の影響を直接受ける立場になった。
「和牛離れの日本／輸出は過去最高、しかし米国向けにトランプ関税の影」という論調の報道が
2026年も続いている（日経ビジネス等）。
**国内消費が縮むぶんを輸出で埋める構造は、外国の政策リスクを内部化することでもある。**

## 6. 食肉大手は過去最高益 ― 「相場」より「加工」が効いた

| 企業                             | 2026年3月期                                                                                  | 出典                           |
| -------------------------------- | -------------------------------------------------------------------------------------------- | ------------------------------ |
| **日本ハム**                     | 売上高 **1兆4,574億円**（+6.3%）、事業利益 **683億円**（+60.7%）で**いずれも過去最高**       | 決算発表・酪農乳業速報ほか報道 |
| **伊藤ハム米久ホールディングス** | **純利益が前期比34%増**。配当は2.2倍と報じられる                                             | 日本経済新聞（報道ベース）     |
| **プリマハム**                   | 決算短信は公表されているが、本ノートでは数値を確認できていない。**最新はIR資料で確認のこと** | ―                              |

### なぜ生産者が苦しいのに大手は最高益なのか

矛盾ではなく、**立ち位置の違い**で説明できる。

```
【同じ「食肉」でも、儲かる場所が違う】

  生産者（繁殖・肥育・養豚）
     売値：相場で決まる ／ 買値（子牛・飼料）：相場で決まる
     → 両側から挟まれる。価格転嫁の手段がない          ◀★ 赤字
            │
            ▼
  食肉処理・卸
     手数料と回転で稼ぐ。相場が上がれば取扱高も増える   ◀ 中立〜やや追い風
            │
            ▼
  食肉加工大手（ハム・ソーセージ・調理加工品）
     ブランドがあるので【値上げを通せる】
     原料高は2024〜2025年の値上げで転嫁済み
     → 値上げ効果が原料高を上回った                     ◀★ 最高益
```

> ここが2026年の食肉業界の構図：**値上げを通せる人が勝ち、通せない人が負けた。**
> 生産者は相場に価格を握られているため、コスト上昇をどこにも渡せない。
> 一方、加工大手はブランドと棚を持っているので、小売に転嫁できた。
> **同じ業界で、上流が赤字・下流が最高益という状態が同時に成立している。**

## 8. 全体の構図

2026年の畜産・飼料を、5行でまとめる。

1. **コスト側は悪化が続いている。** 配合飼料は4四半期連続の値上げで4年ぶり高値。
   穀物高・運賃高・円安が同時に効いており、配合飼料価格安定制度は高止まりには効きにくい。
2. **上流の生産基盤が静かに削れている。** 繁殖農家の減少で和牛子牛は前年比3割高、
   肥育は1頭15万円の赤字試算、和牛肉生産は2026年度に10年ぶりの減少見込み。
   **辞めた繁殖農家は相場が戻っても帰ってこない。**
3. **需要側も縮んでいる。** 牛肉消費は5年連続減少。
   ただし輸入牛肉が高騰したため、**低位等級の国産が輸入の代替として買われる**という逆転が起きている。
4. **利益は下流に偏っている。** 日本ハムは過去最高益、伊藤ハム米久も増益。
   **値上げを通せる加工大手が勝ち、相場に価格を握られた生産者が負けた**年だった。
5. **出口は輸出、リスクは疾病と外国の政策。** 和牛輸出は過去最高を更新したが、
   最大の輸出先が米国になったことで通商政策の影響を内部化した。
   鳥インフルエンザは2025-2026シーズンで24事例・約576万羽。秋以降の新シーズンが常に控えている。

```
【2026年の力の向き】

                  ▲ 値上げを転嫁できた
     食肉加工大手  ■■■■■■■■  過去最高益（日本ハム 事業利益+60.7%）
                  │
     食肉卸・処理  ■■■        取扱高は増加
                  │
     ───────────┼──────────  ここから上と下で符号が逆転
                  │
     肥育農家      ▼▼▼▼        子牛+32.6%／枝肉+2.4% → 1頭15万円赤字試算
     繁殖農家      ▲▲          子牛高で収入増。ただし母牛はすでに減っている
     養豚・養鶏    ▼▼          飼料4期連続値上げ＋疾病リスク
                  ▼ コスト上昇を誰にも渡せない
```

## 用語メモ

| 用語                                 | 意味                                                                                                                                                                   |
| ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **配合飼料供給価格**                 | JA全農が四半期ごとに改定する配合飼料の販売価格。全国全畜種総平均で公表されるが、実際は地域別・畜種別・銘柄別に異なる                                                   |
| **通常補塡／異常補塡**               | 配合飼料価格安定制度の2階建て。通常補塡は直近1年平均を超えた分（原資は生産者積立）、異常補塡は1年平均の115%超の異常高騰分（原資は国） → [②](02_飼料という原価の8割.md) |
| **牛マルキン**                       | 肉用牛肥育経営安定交付金。標準的販売価格が標準的生産費を下回った分の90%を交付。**生産費の計算が約2年前の子牛価格に基づくため、足元の痛みに遅れる**                     |
| **繁殖雌牛（はんしょくめすうし）**   | 子牛を産ませるための母牛。これが減ると2〜3年遅れて子牛と牛肉の供給が減る                                                                                               |
| **枝肉加重平均価格**                 | 食肉卸売市場で取引された枝肉の、取引重量で加重した平均単価。相場の代表値として使われる                                                                                 |
| **格付等級（A5など）**               | 歩留等級（A/B/C）×肉質等級（5〜1）。A5は「歩留まりが良く霜降りが多い」の意味で、味の等級ではない → [③](03_流通と市場.md)                                               |
| **高病原性鳥インフルエンザ（HPAI）** | 渡り鳥が持ち込む鶏の伝染病。発生農場は全羽殺処分。2025-2026シーズンは24事例・約576万羽                                                                                 |
| **ケージフリー**                     | 採卵鶏をバタリーケージで飼わず、平飼い・放牧などで飼う方式。EUは2021年で55%、米国は2020年で26.2%                                                                       |
