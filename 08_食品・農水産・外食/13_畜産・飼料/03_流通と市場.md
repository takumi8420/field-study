# ③ 流通と市場 ― 枝肉相場・食肉加工・疾病・アニマルウェルフェア

このノートで分かること。
生きた家畜が**枝肉**になり、格付けされ、相場がつき、ハム・ソーセージになって
食卓に届くまでの流れ。そこに乗る**輸入牛肉とセーフガード**、**和牛輸出**という外との接点。
そして、この産業が抱える2つの特殊なリスク
――**疾病（鳥インフルエンザ・豚熱）が供給を一瞬で消すこと**と、
**アニマルウェルフェアという新しい要求**を扱う。

---

## 1. 結論：畜産物の価格は「せりで決まる相場」と「契約で決まる値段」の二重構造

同じ食肉でも、値段の決まり方が2通りある。ここを混同すると業界ニュースが読めない。

| 方式                               | 決まり方                                                      | 主な対象                                     | 性格                                             |
| ---------------------------------- | ------------------------------------------------------------- | -------------------------------------------- | ------------------------------------------------ |
| **市場取引（せり）**               | 食肉卸売市場で毎日せりにかけ、**枝肉1kgあたりの価格**が決まる | 和牛・交雑種など**格付けで値段が変わるもの** | 公開され、これが**全国の指標相場**になる         |
| **相対（あいたい）取引・契約取引** | 買い手と売り手が事前に数量と価格を決める                      | 豚肉・鶏肉・輸入肉・量販店向けの大口         | 安定供給が目的。相場が動いても即座には変わらない |

> ポイント：**牛は「相場の産業」、鶏は「契約の産業」、豚はその中間。**
> だから牛肉のニュースは「枝肉が◯◯円」、鶏肉のニュースは「◯◯社が工場を新設」になる。

## 2. 生体から枝肉へ ― 食肉処理と格付

```
【家畜が肉になるまで】

  農場（肥育農家）
      │  生体（生きた家畜）をトラックで輸送
      ▼
  食肉センター／食肉処理場（と畜場）
      │  ・と畜検査（獣医師である「と畜検査員」が1頭ごとに検査）
      │  ・解体：皮・頭・内臓・四肢の先を外す
      ▼
  ★ 枝肉（骨付きの胴体）＝ 食肉取引の基本単位
      │
      │  ・冷却（数日）
      │  ・★格付（日本食肉格付協会の格付員が等級を判定）
      ▼
  ┌──────────────┬────────────────┐
  │ 食肉卸売市場   │ 相対取引（契約）│
  │ （せり）       │                 │
  └───────┬──────┴────────┬────────┘
          ▼                   ▼
    食肉卸・食肉加工メーカー（部分肉・精肉に分割）
          │
          ├──▶ 量販店・精肉店（精肉として販売）
          ├──▶ 外食・中食（焼肉・ファストフード・弁当）
          └──▶ ハム・ソーセージなどの加工品原料
```

### 格付 ― 「A5」の意味

牛肉の**格付**は、日本食肉格付協会が **歩留等級（A・B・C）× 肉質等級（5〜1）** の
組み合わせで判定する。よく聞く「A5」はこの2つの掛け合わせ。

| 記号                              | 何を見ているか                                                                                                    |
| --------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| **A / B / C**（歩留等級）         | 枝肉から**取れる肉の割合**。Aが最も歩留まりが良い。**味の話ではない**                                             |
| **5 / 4 / 3 / 2 / 1**（肉質等級） | **脂肪交雑（霜降り）**・肉の色沢・締まりときめ・脂肪の色沢と質の4項目で判定。最も低い項目の等級が全体の等級になる |

> 誤解されやすい点：**A5＝一番おいしい、ではない**。
> A5は「歩留まりが良く、霜降りが多い」という意味であって、
> 赤身の味や食べやすさを評価する指標ではない。
> それでも**A5は市場で最も高く売れる**ため、生産側は霜降りを付ける肥育をする。
> 「和牛は脂が多すぎる」という消費者の声と、格付制度が求めるものにはズレがある。

## 3. 食肉卸売市場と枝肉相場

**食肉卸売市場**は、東京（芝浦）・大阪・名古屋など主要都市にある、
枝肉を せり で売買する公設の市場。ここでついた価格が**枝肉相場**として公表され、
市場を通らない相対取引の値段も、この相場を参照して決まる。

| 指標                                    | 数値                                   | 時点・出典                    |
| --------------------------------------- | -------------------------------------- | ----------------------------- |
| 東京食肉市場 枝肉加重平均（和牛A5去勢） | **2,640円/kg**（前年同月比 +2.4%）     | 2026年3月。日本農業新聞       |
| 和牛子牛 全国平均取引価格               | **1頭 847,245円**（前年同月比 +32.6%） | 2026年3月。日本農業新聞       |
| 2026年度の和牛肉生産                    | **10年ぶりの減少**見込み               | 日本経済新聞報道（2026年5月） |

相場の読み方。

- **枝肉相場は「等級ごと」に見る**。全体平均は意味が薄い。
  2026年は**低位の格付等級ほど上昇率が高い**と報じられており、
  これは「輸入牛肉が高くて、その代わりに安い国産が買われている」ことを示す
- **年末に跳ねる**。12月は贈答・外食需要で和牛の相場が上がる季節性がある
- **相場が上がっても農家が儲かるとは限らない**。
  子牛代と飼料代が同時に上がっていれば差し引きはマイナス（→ [①](01_畜種ごとに別の産業.md) 第3章）

## 4. 食肉加工 ― ハム・ソーセージ大手の構造

日本の食肉加工大手は、単なる「ハムを作る会社」ではない。
**生産（農場）・食肉処理・食肉卸売・加工品製造**を垂直に持つ**総合食肉企業**である。

```
【食肉大手の事業構造（典型）】

  ┌──────────── 食肉事業（売上の大半・利幅は薄い） ────────────┐
  │  自社農場 ──▶ 自社/提携の食肉処理 ──▶ 部分肉・精肉の卸売      │
  │  ＋ 輸入食肉のトレーディング（商社機能）                        │
  └────────────────────────────────────────────────────────────┘
                              │ 原料を自前で確保できる
                              ▼
  ┌──────── 加工事業（売上は小さいが利幅が厚い） ────────────────┐
  │  ハム・ソーセージ・ベーコン ／ 調理加工品（ハンバーグ・唐揚げ等）│
  │  ＋ ブランド（シャウエッセン、アルトバイエルン 等）              │
  └────────────────────────────────────────────────────────────┘

  ★ 食肉事業は「相場の商売」＝数量は大きいが利益率が低い。
  ★ 加工事業は「ブランドの商売」＝相場の影響を受けにくく、利益率が高い。
  → 大手の決算は、この2つの綱引きで説明できる。
```

| 企業                                     | 立ち位置                                       | 特徴                                                                                                                                                                                                  |
| ---------------------------------------- | ---------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **日本ハム**                             | 国内最大手                                     | 食肉事業（生産〜処理〜卸）と加工事業の両輪。プロ野球球団の保有でブランド認知が高い。**2026年3月期は売上 1兆4,574億円（+6.3%）、事業利益 683億円（+60.7%）でいずれも過去最高**（決算発表・報道ベース） |
| **伊藤ハム米久ホールディングス**         | 2016年に伊藤ハムと米久が経営統合。伊藤忠商事系 | 伊藤忠の調達網を背景に輸入食肉に強い。**2026年3月期は純利益が前期比34%増と報じられる**（報道ベース）                                                                                                  |
| **プリマハム**                           | 3番手。三井物産が主要株主                      | ソーセージ・加工品に比重。相対的に食肉トレーディングの比率が低い                                                                                                                                      |
| **スターゼン／伊藤忠食品ほか食肉卸**     | 食肉卸売の専業大手                             | 加工品ブランドを持たず、**食肉の調達と販売に特化**。利幅は薄いが物量で稼ぐ                                                                                                                            |
| **JA全農ミートフーズ／全農チキンフーズ** | JAグループ                                     | 国産畜産物の販売機能。相場情報の発信源でもある                                                                                                                                                        |
| **各地のインテグレーター**               | 鶏肉の生産主体                                 | ヒナ〜処理〜加工を一貫。上位9グループで年間処理羽数の**6割強**（農水省資料）                                                                                                                          |

> 大手の稼ぎ方を一行で言えば、**「相場商売（食肉）で数量を押さえ、ブランド商売（加工品）で利益を出す」**。
> 食肉事業の規模が大きいのは儲かるからではなく、
> **加工品の原料を安定して確保するため**という側面が強い。

## 5. 輸入牛肉とセーフガード

日本の牛肉消費のうち**過半は輸入**。主に米国・豪州から入る。
国産と輸入は同じ棚で直接競合するが、**部位と用途で棲み分けている**面もある。

| 区分                       | 主な用途                               | 価格                                                |
| -------------------------- | -------------------------------------- | --------------------------------------------------- |
| **和牛**                   | 焼肉・すき焼き・贈答・外食の高単価帯   | 最も高い                                            |
| **交雑種・乳用種**         | 量販店の国産牛、外食の中価格帯         | 中位                                                |
| **輸入牛肉（米国・豪州）** | 牛丼・ハンバーグ・惣菜・量販の低価格帯 | 最も安い…はずだったが、近年は高騰して差が縮んでいる |

### セーフガード（緊急輸入制限）

**セーフガード**とは、**輸入が急増して国内産業に大きな損害が出そうなとき、
一時的に関税を引き上げて輸入を抑える仕組み**のこと。

日米貿易協定に基づく牛肉セーフガードは、2022年に発動条件が改正された。

| 論点                               | 中身                                                                                                                                                                           |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 改正の内容（2022年11月、国会承認） | 米国からの輸入量が基準を超えても、**TPP加盟国からの輸入量との合算がTPPの枠内に収まれば発動しない**。さらに**2027年度までは「前年度の輸入実績を超えること」も発動条件に加わる** |
| 2026年度の発動水準                 | **68.4万トン**（報道・政府資料ベース）                                                                                                                                         |
| 改正の経緯                         | 2021年3月に実際に発動し、米国側が強く反発した。協定の安定運用のために条件を緩めたのが経緯                                                                                      |
| 意味合い                           | 発動のハードルが上がった。**米国産牛肉は実務上ほぼセーフガードの心配なく入ってくる**状態に近く、**国内生産者から見れば保護の水準が下がった**                                   |

### 近年の逆転現象

2024年前後から、**輸入牛肉の仕入価格が過去最高圏**という状況が続いている。
米国の牛の飼養頭数が歴史的低水準にあること、円安、海上運賃が重なったためで、
**「輸入が安くて国産が高い」という前提が崩れている**。
その結果、量販店では**低位等級の国産牛が輸入の代替として買われ、
格付が低いものほど相場の上昇率が高い**という現象が起きている（2026年、報道ベース）。

## 6. 和牛輸出 ― 数少ない成長分野

国内の牛肉消費が縮むなか、**和牛の輸出は明確に伸びている**。

| 指標         | 数値                                                                | 年・出典                                    |
| ------------ | ------------------------------------------------------------------- | ------------------------------------------- |
| 牛肉の輸出額 | **635.8億円**（前年比 **+11.6%**）。**過去最高**                    | 2024年（令和6年）。農畜産業振興機構（alic） |
| 牛肉の輸出量 | **10,113トン**（前年比 **+20.1%**）。**過去最高**                   | 2024年。alic                                |
| 最大の輸出先 | **米国 2,139トン（+87.2%）**。全体の21.1%を占め、台湾を抜いて首位に | 2024年。alic                                |
| 2026年上半期 | 牛肉は米・緑茶などとともに**過去最高額**を更新                      | 2026年上半期。JAcom 農業協同組合新聞        |

なぜ輸出が伸びるのか。

1. **和牛は世界的に「Wagyu」というブランドとして通用する**数少ない日本の農産物
2. **国内消費が縮むぶん、A5の高価格帯が国内だけでは売り切れない**
3. 輸出先の**検疫条件（施設認定）が順次緩和**され、出せる国と施設が増えた

一方でリスクもある。

- **関税政策に左右される**。米国向けは米国の通商政策の影響を受ける（2026年も報道が続く）
- **輸出用に認定された食肉処理施設が限られる**。増産したくても処理能力がボトルネック
- **和牛遺伝資源の流出**。精液・受精卵の海外流出は法規制（家畜改良増殖法等の改正）で対応が進んだが、
  海外で「Wagyu」を名乗る牛が生産されている状況は変わらない

## 7. 疾病リスク ― 供給が一瞬で消える

畜産が他の製造業と決定的に違うのは、**在庫ではなく生き物を抱えている**こと。
病気が出れば、その農場の資産は**法律に基づいて殺処分され、ゼロになる**。

```
【家畜伝染病が発生したときの流れ（高病原性鳥インフルエンザの例）】

  異常の発見（死亡羽数の増加など）
      │  ★農場主には通報義務がある（家畜伝染病予防法）
      ▼
  都道府県の家畜保健衛生所が検査 → 遺伝子検査で確定
      ▼
  ┌──── 防疫措置（24時間以内の開始が目標） ────┐
  │ ・当該農場の【全羽殺処分】＋焼却・埋却        │
  │ ・移動制限区域（半径3km）／搬出制限区域（10km）│
  │ ・消毒ポイントの設置                          │
  └──────────────────────────────────────────┘
      ▼
  制限解除まで数週間〜。その間、周辺農場も出荷できない
      ▼
  ★ 経営再開には、洗浄・消毒・空舎期間＋ヒナの再導入が必要
    採卵鶏はヒナを入れてから【産卵開始まで約5か月】
    → 供給の穴はすぐには埋まらない ＝ 卵価が数か月高止まりする
```

| 疾病                                 | 対象             | 特徴                                                    | 直近の状況                                                                                               |
| ------------------------------------ | ---------------- | ------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| **高病原性鳥インフルエンザ（HPAI）** | 鶏・アヒルなど   | 渡り鳥が持ち込む。**1事例で数十万羽規模**の殺処分になる | **2025-2026シーズン（令和7年度）で24事例、約576万羽が殺処分対象**（農林水産省、2026年7月14日時点の整理） |
| **豚熱（CSF）**                      | 豚・イノシシ     | 発症すればほぼ100%死亡。人には感染しない                | 2018年9月に国内で26年ぶりに発生。2019年から対象地域でワクチン接種。**流行は継続中**                      |
| **アフリカ豚熱（ASF）**              | 豚・イノシシ     | **ワクチンがない**。アジアで流行                        | 国内未発生。水際検疫が最重要                                                                             |
| **口蹄疫**                           | 牛・豚など偶蹄類 | 2010年に宮崎県で約29万頭を殺処分した前例                | 国内は2010年以降発生なし                                                                                 |

**経営者から見た疾病リスクの本質**は次の3点。

1. **自分が悪くなくても被害を受ける**。渡り鳥や野生イノシシは防ぎようがなく、
   また**近隣で発生すれば移動制限で自分の農場も出荷できない**
2. **補償はあるが、全部は埋まらない**。手当金（評価額に基づく）や経営支援はあるが、
   **失われた時間**（ヒナを入れ直して産卵・出荷に至るまでの数か月〜1年）は戻らない
3. **だから防疫設備が固定費になる**。ネット・防鳥対策・消毒・車両動線の設計が
   経営の必須投資になり、**小規模農家ほど負担しきれず退出する**

> 制度の側から見ると、家畜伝染病は**「個人の損失」ではなく「国の食料供給の問題」**として扱われる。
> 家畜伝染病予防法が通報義務と強制的な殺処分を定めているのは、
> 1農場の損失を受け入れてでも**全国への拡大を止めるほうが安い**という判断に基づく。

## 8. アニマルウェルフェア ― 新しい要求

**アニマルウェルフェア（動物福祉）**とは、
**家畜を、健康で快適な環境で飼養することをめざす考え方**。
「かわいそうだから」という情緒の話ではなく、**国際的な取引条件・調達基準**になりつつある。

### 5つの自由（国際的な基本原則）

1. 飢え・渇きからの自由
2. 不快からの自由（適切な環境）
3. 痛み・傷害・疾病からの自由
4. 恐怖・苦悩からの自由
5. **正常な行動を表現する自由**（＝ 動き回れる、巣作りできる、など）

5番目が最も厳しく、**バタリーケージ（採卵鶏を狭いケージで飼う方式）や
妊娠ストール（母豚を身動きできない柵に入れる方式）**が問題にされるのはここに当たる。

### 日本と海外の距離

| 地域     | 状況                                                                                                                                                                                                                                                                                                                                                                                                                 |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **日本** | 2023年7月、農林水産省が国際基準（WOAHコード）を踏まえた**「アニマルウェルフェアに関する飼養管理指針」**を策定。畜種ごとに「実施が推奨される事項」と「将来的に実施が推奨される事項」を区分。**2026年3月に「達成目標の検討報告書（中間とりまとめ）」**が公表された。ただし**バタリーケージ飼養が主流**で、飼養システムの変更を伴う規制の導入は現時点で検討されていない（国立国会図書館 調査と情報 No.1344、2026年2月） |
| **EU**   | **2012年にバタリーケージを禁止**。2021年時点で採卵鶏の**55%がケージフリー**                                                                                                                                                                                                                                                                                                                                          |
| **米国** | 州法と企業の調達方針が牽引。2020年時点で**26.2%がケージフリー**                                                                                                                                                                                                                                                                                                                                                      |

### なぜ日本の畜産にとって経営問題なのか

- **切り替えに巨額の投資がいる**。ケージフリーにすると同じ鶏舎で飼える羽数が減り、
  1個あたりの生産コストが上がる。**卵価が今の水準のままでは回収できない**
- **買い手側から来る**。規制ではなく、**外食チェーン・ホテル・食品メーカーの調達方針**として
  「◯年までにケージフリー卵に切り替える」という宣言が広がる形で要求される
- **輸出の条件にもなる**。和牛輸出を伸ばそうとすれば、輸出先の基準を無視できない
- **人手不足とは逆方向に働くこともある**。平飼いは管理の手間が増え、疾病リスクも上がりうる

> 構図としては、**「国内の制度は緩いが、取引先と輸出先から要求される」**というかたち。
> 日本の畜産にとっては、法規制の話ではなく**取引条件の話として静かに効いてくる**論点である。

---

## 9. まとめ：この章を理解する3つの鍵

1. **価格は二重構造**。牛は市場のせりで決まる「相場の産業」、鶏は企業が抱える「契約の産業」。
   格付（A5＝歩留まりA×肉質5）が相場を決めるが、**A5は味の等級ではない**。
2. **食肉大手は「相場商売＋ブランド商売」の二層**。食肉事業で数量と原料を押さえ、
   ハム・ソーセージなどの加工事業で利益を出す。輸入牛肉が高騰し、
   **国産の低位等級が代替として買われる**という逆転も起きている。
3. **疾病は供給を一瞬で消し、戻るのに数か月〜1年かかる**。
   2025-2026シーズンのHPAIは24事例・約576万羽。採卵鶏は再導入から産卵まで約5か月。
   **そこに、アニマルウェルフェアという「取引条件としての新しいコスト」が乗ってくる。**

## 用語メモ

| 用語                                 | 意味                                                                                                                                                                         |
| ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **枝肉（えだにく）**                 | と畜・解体後の、骨付きの胴体部分。食肉取引の基本単位。**枝肉相場＝この1kgあたりの価格**                                                                                      |
| **部分肉**                           | 枝肉を部位ごと（ロース、バラ、モモ等）に大分割したもの。ここから精肉に加工される                                                                                             |
| **格付（かくづけ）**                 | 日本食肉格付協会が行う枝肉の等級判定。牛は**歩留等級A/B/C × 肉質等級5〜1**。「A5」はその組み合わせ                                                                           |
| **歩留等級（ぶどまりとうきゅう）**   | 枝肉から取れる肉の割合の評価（A・B・C）。味の評価ではない                                                                                                                    |
| **肉質等級**                         | 脂肪交雑（霜降り）・肉の色沢・締まりときめ・脂肪の質の4項目で判定。**最も低い項目の等級が全体の等級になる**                                                                  |
| **脂肪交雑（しぼうこうざつ）**       | 筋肉の中に細かく入った脂肪＝霜降り。和牛の価値を決める最大要素                                                                                                               |
| **食肉卸売市場**                     | 枝肉をせりで売買する公設市場（東京・大阪など）。ここでついた価格が全国の指標相場になる                                                                                       |
| **相対（あいたい）取引**             | 買い手と売り手が個別に数量・価格を決める取引。豚肉・鶏肉・輸入肉で主流                                                                                                       |
| **セーフガード（緊急輸入制限）**     | 輸入急増で国内産業に損害が出そうなとき、一時的に関税を上げて輸入を抑える措置。日米貿易協定の牛肉セーフガードは2022年に発動条件が緩和され、**2026年度の発動水準は68.4万トン** |
| **家畜伝染病予防法**                 | 家畜の伝染病発生時の通報義務・移動制限・殺処分などを定める法律。1農場の損失を受け入れて全国への拡大を止める設計                                                              |
| **移動制限区域／搬出制限区域**       | 発生農場を中心に半径3km／10km程度で設定され、区域内の家畜・畜産物の移動が制限される。**発生していない周辺農場も出荷できなくなる**                                            |
| **アニマルウェルフェア（動物福祉）** | 家畜を健康で快適な環境で飼養する考え方。「5つの自由」が国際的な原則。日本は2023年7月に農水省の飼養管理指針を策定                                                             |
| **バタリーケージ／ケージフリー**     | 採卵鶏を狭いケージで多段飼育する方式／それをやめて平飼い・放牧にする方式。EUは2012年にバタリーケージを禁止                                                                   |
