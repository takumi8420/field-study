## このフォルダの読み方

畜産を理解するときに、最初に捨てなければいけない思い込みが2つある。

> **①「畜産業」という一つの産業は存在しない。牛・豚・鶏は別の産業である。**
> **②「農業」だと思って見ると読み違える。実態は輸入穀物を肉に変える加工業である。**

①は、**お金が何か月寝るか**で説明できる。
牛は子牛を買ってから出荷まで約20か月、豚は約10か月、鶏（ブロイラー）は約50日。
この差が経営形態をほぼ全部決める。牛は**繁殖と肥育が別の農家**に分かれて子牛市場を挟み、
豚は**一貫経営**で衛生管理が生命線になり、鶏は回転の速さを生かして
**インテグレーション（垂直統合）が9割超**という、最も工業化された姿になった。

②は、コスト構造の話。配合飼料の主原料はトウモロコシと大豆粕で、
**濃厚飼料の自給率は約13%（＝約87%が輸入）**。
ブロイラーでは飼料代が経営費の64%、ヒナ代16%と合わせて約8割が輸入資源に依存している。
つまり畜産経営の損益は、**シカゴの穀物相場・海上運賃・ドル円**という、
農家が1円も動かせない3つの変数で決まる。

そしてこの産業には、他の製造業にない特殊なリスクがある。
**在庫ではなく生き物を抱えている**こと。鳥インフルエンザや豚熱が出れば、
その農場の資産は法律に基づいて殺処分されてゼロになり、
採卵鶏なら再導入から産卵開始まで約5か月、供給の穴は埋まらない。

なお、**酪農（乳を搾る牛）は [乳業](../04_乳業/README.md) 側で扱っている**。
生乳の制度（指定団体・用途別乳価・補給金）はすべてそちらにある。
ここでは**肉を取る畜産＝肉用牛・豚・鶏**と、全畜種に共通する**飼料**に軸足を置く。

## 1. 業界の定義・範囲

**畜産・飼料** ＝ 家畜（牛・豚・鶏など）を飼養して**食肉・卵**を生産する産業と、
それを支える**飼料（配合飼料・粗飼料）の製造・供給**の産業をあわせた領域。

本フォルダでは、**肉用畜産（肉用牛・養豚・養鶏）と飼料**を範囲とし、
**酪農・生乳は [乳業](../04_乳業/README.md) に委ねる**。

```
【畜産・飼料の位置と、隣との境界線】

  川上                                                             川下
  ────────────────────────────────────────────────▶

  穀物（輸入）        飼料メーカー        畜産農家          食肉処理・加工       小売・外食
  トウモロコシ  ──▶  配合飼料      ──▶  肉用牛      ──▶  食肉センター  ──▶  スーパー
  大豆粕              （JA全農ほか）      養豚              食肉卸売市場       量販精肉
       │                    │             ブロイラー        ハム・ソーセージ   焼肉・牛丼
       │                    │             採卵鶏            日本ハムほか       弁当・惣菜
  海運・商社          ★このフォルダ★    ★このフォルダ★                      └▶ 輸出（和牛）

  境界の引き方：
   ・乳用牛の飼養、生乳、乳価、指定団体        → 04_乳業
   ・牧草・飼料用米の作付け、水田政策、JA      → 12_農業・種苗・肥料
   ・大豆粕・ふすまを生む製油・製粉            → 02_製粉・製糖・製油
   ・ハム・ソーセージの「食品メーカーとしての」 → 01_総合食品（損益・値決めの基礎）
   ・牛丼・焼肉・弁当という需要側              → 14_ファストフード、18_焼肉・ラーメン、20_中食・弁当
```

注意すべき境界。

- **「畜産」と「酪農」は別**。酪農は乳を搾る産業で、制度も経営も別物。
  ただし**交雑種（F1）と乳用種の肉は酪農の副産物**なので、肉の供給は酪農と連動する。
- **飼料メーカーと畜産農家は別の産業だが、実質は一体**。
  農家のコストの6〜8割が飼料なので、飼料価格の改定が畜産のニュースそのものになる。
- **鶏肉と鶏卵は別産業**。品種も違えば、価格の決まり方（契約 vs 日々の建値）も違う。
- **食肉大手（日本ハム等）は食品メーカーであると同時に商社的なトレーダー**でもある。
  輸入食肉の扱いが大きく、相場の影響を受ける。

成長性の読み方。

- **国内の数量は縮む**。人口減と、値上げによる牛肉離れ。牛肉消費は5年連続減少。
- **生産基盤はもっと速く縮む**。飼料高と子牛高で繁殖農家が離農しており、
  2026年度の和牛肉生産は10年ぶりの減少見込み。**やめた農家は相場が戻っても帰ってこない。**
- **単価は上がっている**。数量減と輸入高騰で相場は高い。ただし
  **相場高＝農家の利益ではない**（子牛と飼料が同時に上がっているため）。
- **伸びているのは輸出と加工品**。和牛輸出は過去最高更新、
  食肉大手の加工事業は値上げを通して過去最高益。**利益は下流に偏っている。**

## 3. バリューチェーン（川上 → 川下）

```
【モノ・カネ・情報の流れ】

 モノ  輸入穀物 ──▶ 飼料メーカー ──▶ 畜産農家 ──▶ 食肉処理場 ──▶ 卸／市場 ──▶ 小売・外食
      （シカゴ）     （配合飼料）     （肥育・養豚      （枝肉）    （部分肉）   （精肉・加工品）
                                      養鶏・採卵）        │
                          ▲                               └──▶ 輸出（和牛・認定施設のみ）
                          │
                    繁殖農家 ──▶ 家畜市場（子牛せり）──▶ 肥育農家   ※牛だけの二段構え

 カネ  農家 ──── 飼料代（毎月出る）────▶ 飼料メーカー
       農家 ◀─── 枝肉・卵の代金（出荷時にしか入らない）──── 卸・市場
       国 ───── 牛マルキン／豚マルキン（差額の90%）────▶ 農家
       基金 ─── 配合飼料価格安定制度（通常補塡・異常補塡）──▶ 農家
       ★ 出ていくのは毎月、入ってくるのは出荷時。だから【資金繰りで潰れる】

 情報  シカゴ相場・為替・海上運賃 ──▶ JA全農が四半期ごとに配合飼料価格を改定
       食肉卸売市場のせり ─────▶ 枝肉相場として公表 ──▶ 相対取引の参照値になる
       家畜保健衛生所 ────────▶ 発生確認 ──▶ 移動制限区域の設定（周辺農場も出荷停止）
```

付加価値がどこに集まるか。

| 段階                       | 経済的な特徴                                                                 | なぜそうなるか                                                       |
| -------------------------- | ---------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| **飼料メーカー**           | 原料は相場、売価は四半期改定。自分の利幅は薄い**装置産業**                   | 相場をそのまま転嫁する立場で、儲けは製造・物流のマージン             |
| **繁殖農家（牛）**         | 子牛価格が上がれば潤う。ただし**規模が小さく高齢化**していて供給を増やせない | 母牛から年1頭しか取れず、増頭に3年かかる                             |
| **肥育農家（牛）**         | **最も苦しい**。買値も売値も相場で、間に20か月の時間差がある                 | 価格決定権がどちらにもない。マルキンは2年遅れで効く                  |
| **養豚・養鶏**             | 規模でしか利益が出ない。疾病が出れば資産がゼロになる                         | 1頭・1羽の単価が小さく、防疫設備が固定費として重い                   |
| **インテグレーター（鶏）** | 相場リスクを引き受ける代わりに、**工程全体の利益を取る**                     | ヒナ・飼料・処理・販売を握ることで、どこで儲けるかを自分で選べる     |
| **食肉処理・卸**           | 手数料と回転で稼ぐ。相場上昇は取扱高の増加として効く                         | 在庫リスクは短い。物量のビジネス                                     |
| **食肉加工大手**           | **ここに利益が集まる**。ブランドがあるので値上げを通せる                     | ハム・ソーセージ・調理加工品は原料費比率が下がり、棚での交渉力がある |
| **小売**                   | 精肉は**集客商品**。安く売られやすい                                         | 毎週買う商品なので価格が記憶され、値上げに敏感                       |

> ポイント：**この産業は、価格を「決められる人」と「受け入れるしかない人」に
> きれいに二分されている。** 生産者は両側（飼料と枝肉）を相場に握られ、
> 加工大手はブランドで値上げを通せる。2026年に上流が赤字で下流が最高益という
> 一見矛盾した決算が並んだのは、この構造がそのまま表に出たため。

| **JA全農（畜産生産部・飼料畜産中央研究所ほか）**       | **配合飼料の最大の供給者**                     | 四半期ごとの**配合飼料供給価格**が業界の基準値になる。JA全農ミートフーズが国産畜産物を販売                                                                                                                          |
| **日清丸紅飼料／中部飼料／フィード・ワン／協同飼料系** | 配合飼料メーカー                               | 商社系・独立系。港湾に工場を置き、輸入原料を受けて配合する装置産業                                                                                                                                                  |
| **鶏肉インテグレーター各社**                           | ブロイラーの生産主体                           | ヒナ〜飼料〜飼育〜食鳥処理〜加工を一貫。**上位9グループで年間処理羽数の6割強**（農林水産省資料）                                                                                                                    |
| **総合商社（伊藤忠・三井物産・丸紅・三菱商事ほか）**   | 飼料原料と輸入食肉の調達                       | 穀物のオリジネーション（産地での集荷）から船、国内配合まで握る。**畜産の上流と下流の両方に資本で入っている**                                                                                                        |
| **農畜産業振興機構（alic）**                           | 独立行政法人                                   | **マルキン等の交付金の実施主体**。統計・調査の発信源でもある                                                                                                                                                        |
| **家畜改良センター／日本食肉格付協会／家畜保健衛生所** | 公的機関                                       | 品種改良、枝肉格付、防疫の実務を担う                                                                                                                                                                                |

**シェアの見方**：「畜産業界のシェア」という数字は意味を持たない。
畜種ごとに主役が違い、生産段階（農家）は零細分散、
加工・流通段階（食肉大手）は寡占、というように**段階によって集中度がまったく違う**。
おおまかには、**生産は分散、鶏だけインテグレーターに集約、
加工は日本ハム・伊藤ハム米久・プリマハムの3強、飼料はJA全農が最大**、という構図で捉える。

## 5. 収益モデル・コスト構造

```
【肉用牛（肥育）1頭あたりの収支イメージ ― 2026年の局面】

  売上：枝肉 約500kg × 相場 ≒ 130万円前後（和牛A5、2026年3月相場で概算）
   │
   ├ もと畜費（子牛代）   85万円   ◀★2026年3月の和牛子牛は1頭 847,245円（前年比+32.6%）
   ├ 飼料費              40〜50万円 ◀★20か月分。配合飼料は4四半期連続値上げ
   ├ 労働費・減価償却・診療衛生・敷料・金利 など
   └ 差引 ＝ ★赤字（1頭あたり15万円程度の赤字の恐れ、日本農業新聞の試算）

  ※構造を示すための概算。品種・地域・出荷月齢・経営規模で大きく異なる。
  ※マルキン（差額の90%補塡）が乗るが、標準的生産費の計算は約2年前の子牛価格に基づくため
    2026年3月販売分は肉専用種で発動なしと報じられた。
```

| 論点                                     | 中身                                                                                                                    |
| ---------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| **費用のトップ2がどちらも相場**          | 飼料費（輸入穀物）と もと畜費（子牛せり）。**農家に価格交渉力がない**。これが畜産経営の根本的な弱さ                     |
| **収入と支出のタイミングがずれる**       | 飼料代は毎月出るが、収入は出荷時にしか入らない。牛なら20か月後。**赤字ではなく資金繰りで破綻する**                      |
| **固定費の主役が防疫と環境対策に移った** | 畜舎・換気・糞尿処理・消毒動線。**売上を増やさない投資**だが、やらないと経営できない                                    |
| **利益率は畜種と段階で全く違う**         | 生産段階は薄利かつ赤字局面あり。鶏のインテグレーターは工程全体で、加工大手はブランドで利益を確保                        |
| **在庫調整ができない**                   | 家畜は生きているので「作るのを止めて待つ」ができない。餌は毎日要る。出荷を遅らせれば飼料代だけ増える                    |
| **資産が法律でゼロになりうる**           | 家畜伝染病が発生すれば全頭・全羽殺処分。手当金はあるが、**失われた時間（再導入〜出荷までの数か月〜1年）は補償されない** |

詳しくは [② 飼料という原価の8割](02_飼料という原価の8割.md)、[③ 流通と市場](03_流通と市場.md)。

## 6. 競争要因（KSF）と参入障壁

| KSF                            | 中身                                                                                     |
| ------------------------------ | ---------------------------------------------------------------------------------------- |
| **規模**                       | 1頭・1羽あたりの利幅が薄いので、頭数でしか利益が出ない。畜舎・設備の固定費も規模で割る   |
| **飼料の調達力**               | 配合飼料をどれだけ安く安定的に引けるか。インテグレーターや商社系が強いのはここ           |
| **バイオセキュリティ（防疫）** | 病気を入れない設計。**1回の発生で経営が止まる**ため、実質的に最優先の経営課題            |
| **もと畜の確保**               | 牛なら子牛、鶏ならヒナ。2026年のように子牛が枯渇すると、**カネがあっても増やせない**     |
| **販路（契約）**               | 量販店・外食との継続契約があれば相場変動を平準化できる。インテグレーションの本質でもある |
| **糞尿処理と地域との関係**     | 臭気・水質のトラブルは立地の死活問題。堆肥化・バイオガスの設備が要る                     |
| **ブランド（銘柄畜産物）**     | 「◯◯牛」「◯◯豚」。相場から一段上の価格を取るための数少ない手段                           |

**参入障壁**は免許制ではない（と畜場・食鳥処理場には許可が必要だが、飼養そのものは届出・基準遵守）。
実質的な障壁は **①畜舎・防疫・糞尿処理への巨額の初期投資、②もと畜と飼料を安定的に引ける関係、
③立地（臭気・用地・防疫距離）** の3つ。
ただし最大の障壁は、**そもそも儲からないので誰も入ってこない**ことにある。
新規参入より**既存農家の離農と大規模化**が構造変化の主役になっている。

## 7. 規制・法制度

| 制度                                                           | 内容                                                                                                                              | 畜産への影響                                                                                                                                              |
| -------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **畜安法（畜産経営の安定に関する法律）**                       | **牛マルキン・豚マルキン**の根拠法。標準的販売価格が標準的生産費を下回った場合、差額の**90%**を交付。原資は生産者積立1/4＋国3/4   | 赤字の9割を埋める最大のセーフティネット。ただし**標準的生産費が約2年前の子牛価格に基づく**ため、足元の急変に遅れる（2026年3月販売分は肉専用種で発動なし） |
| **配合飼料価格安定制度**                                       | 通常補塡（直近1年平均を超えた分・生産者積立＋メーカー拠出）と異常補塡（輸入原料が1年平均の**115%**超・国＋メーカー）の**2階建て** | 急変は均せるが、**高止まりには構造的に弱い**（基準が直近1年平均なので、高値が続けば基準が上がる）。基金が枯渇すれば機能しない                             |
| **家畜伝染病予防法**                                           | 通報義務、移動制限区域（半径3km）・搬出制限区域（10km）、**発生農場の全頭・全羽殺処分**、手当金                                   | **発生していない周辺農場も出荷できなくなる**。1農場の損失を受け入れて全国への拡大を止める設計                                                             |
| **飼養衛生管理基準**                                           | 畜種ごとに定められた衛生管理の遵守義務（防鳥ネット、消毒、記録等）                                                                | 小規模農家ほど設備・記録の負担が重く、離農の要因になる                                                                                                    |
| **と畜場法／食鳥処理法**                                       | と畜場・食鳥処理場の許可、と畜検査員（獣医師）による1頭ごとの検査                                                                 | 処理能力が実質的なボトルネック。**輸出には別途の施設認定**が要る                                                                                          |
| **牛トレーサビリティ法**                                       | 国内で生まれたすべての牛に**個体識別番号**を付け、出生から流通まで追跡                                                            | BSE対策として2003年に導入。和牛ブランドの信頼の基盤でもある                                                                                               |
| **日米貿易協定の牛肉セーフガード**                             | 2022年11月の改正でTPP枠との合算判定になり、**2027年度までは前年度実績超も発動条件**に。**2026年度の発動水準は68.4万トン**         | 発動のハードルが上がり、**国内生産者から見れば保護水準が下がった**                                                                                        |
| **家畜改良増殖法（和牛遺伝資源の保護）**                       | 精液・受精卵の不正な流通・輸出への規制                                                                                            | 和牛という遺伝資源の流出防止。輸出振興の前提条件                                                                                                          |
| **アニマルウェルフェアに関する飼養管理指針**（2023年7月）      | WOAHコードを踏まえ、畜種ごとに「実施が推奨される事項」「将来的に推奨される事項」を提示。**2026年3月に達成目標の中間とりまとめ**   | 現時点で**飼養システムの変更を伴う規制は未導入**。実際の圧力は**取引先の調達方針と輸出先の要求**として来る                                                |
| **家畜排せつ物法**                                             | 家畜排せつ物の管理施設の構造基準                                                                                                  | 糞尿処理設備が必須投資。地域との関係にも直結                                                                                                              |
| **飼料安全法（飼料の安全性の確保及び品質の改善に関する法律）** | 飼料・飼料添加物の成分規格、有害物質の基準。エコフィードの安全確保もここ                                                          | 飼料メーカーの製造基準。BSE後は肉骨粉の利用規制が続く                                                                                                     |

## 8. 最近のトピック

詳細は → [④ 直近トピック（2026年9月時点）](04_直近トピック_2026.md)

1. **配合飼料は4四半期連続の値上げ、4年ぶり高値** — 2026年10〜12月期は **+3,200円（+3.5%）**。
   シカゴのトウモロコシ高、パナマックス運賃の上昇（50→70ドル/トン台）、
   円安（155→160円）が同時に効いた。
2. **和牛子牛が前年比+32.6%、肥育は1頭15万円の赤字試算** — 2026年3月の子牛は **847,245円**。
   一方で枝肉は **2,640円/kg（+2.4%）** しか上がらず、
   **子牛高・枝肉安のはさみ状価格差**が肥育経営を直撃している。
3. **和牛肉生産が10年ぶりの減少見込み** — 繁殖農家が母牛を減らした結果。
   **一度失った繁殖基盤は相場が戻っても回復しない**という、畜産縮小の一方通行性が表に出た。
4. **牛肉消費は5年連続減少、しかし輸入が高い** — 米国の飼養頭数減と円安で輸入牛肉が高騰し、
   **低位等級の国産が輸入の代替として買われる**という逆転が起きている。
5. **上流が赤字、下流が過去最高益** — 日本ハムは2026年3月期に売上・事業利益とも過去最高
   （事業利益 +60.7%）。**値上げを通せる加工大手が勝ち、相場に価格を握られた生産者が負けた。**
   同時に、和牛輸出は過去最高を更新し、鳥インフルエンザは2025-2026シーズンで
   **24事例・約576万羽**が殺処分対象となった。

## 9. 用語メモ

各ノートの末尾に詳しい用語メモがある。ここでは最重要の10。

| 用語                                   | 意味                                                                                                                                                                                            |
| -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **枝肉（えだにく）**                   | と畜・解体後の、骨付きの胴体部分。**食肉取引の基本単位**で、「枝肉相場」はこの1kgあたりの価格 → [③](03_流通と市場.md)                                                                           |
| **格付（A5など）**                     | 日本食肉格付協会による枝肉の等級。**歩留等級（A/B/C＝取れる肉の割合）× 肉質等級（5〜1＝霜降り等）**。**A5は味の等級ではない** → [③](03_流通と市場.md)                                           |
| **肥育（ひいく）／繁殖（はんしょく）** | 子牛を太らせる工程／母牛に子を産ませる工程。**牛では別の農家が担い、間に子牛せりが入る** → [①](01_畜種ごとに別の産業.md)                                                                        |
| **交雑種（F1）**                       | ホルスタインの母に和牛の種を付けた牛。**酪農の副産物**なので、供給量は酪農の都合で決まる → [①](01_畜種ごとに別の産業.md)／[乳業](../04_乳業/README.md)                                          |
| **マルキン**                           | 肉用牛肥育経営安定交付金（牛マルキン）・肉豚経営安定交付金（豚マルキン）。**標準的販売価格が標準的生産費を下回った差額の90%を交付**。原資は生産者積立1/4＋国3/4 → [①](01_畜種ごとに別の産業.md) |
| **インテグレーション（垂直統合）**     | ヒナ・飼料の供給から飼育・食鳥処理・加工・販売までを1企業グループが一貫して行う仕組み。**ブロイラーでは9割超**。農家は飼育料を受け取る契約生産者になる → [①](01_畜種ごとに別の産業.md)          |
| **配合飼料**                           | 畜種・成長段階に応じて複数原料を混ぜた完成品の飼料。**主原料はトウモロコシと大豆粕で、ほぼ輸入** → [②](02_飼料という原価の8割.md)                                                               |
| **配合飼料価格安定制度**               | 飼料値上がり分の一部を基金から補塡する**2階建て**の仕組み（通常補塡＋異常補塡）。**急変は均せるが高止まりには効かない** → [②](02_飼料という原価の8割.md)                                        |
| **エコフィード**                       | 食品残さ・副産物を原料にした飼料。令和4年度で**108万TDNトン、濃厚飼料の約5%** → [②](02_飼料という原価の8割.md)                                                                                  |
| **アニマルウェルフェア（動物福祉）**   | 家畜を健康で快適な環境で飼養する考え方。「5つの自由」が国際原則。日本は2023年7月に農水省の飼養管理指針を策定、2026年3月に達成目標の中間とりまとめ → [③](03_流通と市場.md)                       |
