# 国内縮小と海外展開 ― 人口が減る国のビール会社

このノートで分かること：日本のビール・酒類メーカーが**なぜ国内では勝っても増えないのか**、
そして**兆円単位の海外M&Aに踏み切った理由と、その成否**。

国内市場は「人口が減る × 1人あたりの飲酒量も減る」という二重の縮小に入っている。
装置産業で固定費が重い以上（[02_メーカーの商売](02_メーカーの商売.md)）、縮む市場に留まることは緩やかな自滅に等しい。
だから各社は**海外を買う**か**酒以外へ広げる**か、その両方を選んだ。

---

## 1. 結論：国内は「守る市場」、成長は外にある

```
  【国内】                              【海外】
   成人人口が減る                       人口が増え、所得も伸びる
   ×                                    ×
   1人あたり飲酒量も減る                 ビールが「これから普及する」地域がある
   ＝                                    ＝
   数量は構造的に縮む                    数量で伸びる余地がある
   ↓                                     ↓
   稼働率を守りながら                    M&Aで既存ブランドと販売網ごと買う
   単価を上げる（プレミアム化）          （自前でゼロから作る時間はない）
   ＋ ノンアル・低アルで客層を広げる      ＋ ウイスキー・日本酒の輸出
```

- 国内は**ゼロサム**。他社からシェアを奪っても市場は増えない。
- 海外は**時間との勝負**。ビールは装置とブランドの商売なので、現地企業を買うのが最短で、
  結果として**兆円規模のM&A**になった。
- ただし、買えば必ず成功するわけではない。**キリンのブラジルとミャンマーは失敗**、
  **サントリーの米国ウイスキーは2025年に減損**と、明暗が分かれている。

## 2. 国内が縮む ― 数字で確認する

| 指標                          | 数値                                       | 年・出典                       |
| ----------------------------- | ------------------------------------------ | ------------------------------ |
| 酒類の課税数量                | 約812万kL                                  | 2024年度・国税庁「酒のしおり」 |
| 酒類の販売（消費）数量        | 約773万kL                                  | 2024年度・同                   |
| 酒税収入                      | 約1.18兆円（ピークは1994年度の約2.12兆円） | 2024年度・同                   |
| 成人1人当たりアルコール消費量 | 101.8L（1992年度）→ 74.3L（2021年度）      | 国税庁                         |
| 清酒の課税数量                | 177万kL（1973年度）→ 39万kL（2023年度）    | 国税庁                         |
| 酒類の消費数量                | 10年前比 約9%減                            | 2023年度・同                   |

### 2-1. 減り方が「二重」であること

```
  国内の総需要 ＝ ① 成人人口  ×  ② 1人あたり飲酒量
                    ↓減             ↓減

  ① 人口動態：20歳以上人口は今後数十年にわたり減少が続く（国立社会保障・人口問題研究所の推計）
  ② 1人あたり：若年層の飲酒離れ、健康志向、飲み会文化の縮小、在宅化、
                運転規制の厳格化、可処分所得の伸び悩み

  → どちらか片方なら「景気が戻れば戻る」。両方が同時に効いているので構造的な縮小。
```

### 2-2. 中身の入れ替わり

数量は減るが、中身は動いている。**単価を上げられるカテゴリーに移れるか**が国内戦略の焦点になる。

| カテゴリー             | 方向                                                                       | 背景                                                             |
| ---------------------- | -------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| ビール（本来のビール） | 長期減 → **回帰の兆し**                                                    | 2020・2023・2026年の段階的減税。2026年10月の一本化でさらに追い風 |
| 発泡酒・新ジャンル     | **縮小へ**                                                                 | 増税で価格優位が消える。主力はビールへ製法変更                   |
| RTD（缶チューハイ等）  | 伸びてきたが2026年10月に増税                                               | 低価格の受け皿だった前提が変わる                                 |
| 清酒                   | 国内は減。ただし**純米・純米吟醸は増**（2013年度9.2万kL→2023年度10.4万kL） | 「安く多く」から「少なく良いものを」へ                           |
| ウイスキー             | 好調が継続                                                                 | ハイボールの定着。原酒の在庫制約が供給を縛る                     |
| ノンアル・低アル       | **成長**                                                                   | 健康志向、飲酒ガイドライン、スマートドリンキング                 |
| クラフトビール         | **成長**（絶対額は小さい）                                                 | 醸造所が約950〜970か所に増加（2026年、民間集計）                 |

### 3-1. アサヒ ― 「買って、海外比率を作った」

```
  2015年ごろ                  2020年以降
  ┌────────────┐            ┌──────────────────────┐
  │ 国内ビール中心  │  ──買収──▶ │ 欧州（中東欧・西欧）   │
  │ 海外比率は小さい │            │ ＋ 豪州（CUB）        │
  └────────────┘            │ ＋ 国内               │
                               │ 海外が売上の過半      │
                               └──────────────────────┘
   資金は借入でまかない、のれんと有利子負債が膨らんだ
   → 買収後は「稼いだキャッシュで借金を返す」局面が続いた
```

- 狙いは明快で、**国内の稼ぎを、成長する地域のブランドに置き換える**こと。
- 買ったのは**プレミアム帯のブランド**が中心。数量ではなく単価で稼ぐ設計になっている。
- リスクは財務。大型買収を借入で行ったため、**のれんの減損と金利負担**が長く経営課題として残った。

### 3-2. キリン ― 2つの失敗から学んだこと

| 案件                                    | 何が起きたか                                                                                                                                | 教訓                                                                                 |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| ブラジル（2011年取得→2017年売却）       | 買収後にブラジル経済が悪化し競争も激化。想定した収益を上げられず、巨額の減損を計上したうえで売却                                            | **成長市場だから儲かる、とは限らない**。現地の競合構造を読み違えると装置が重荷になる |
| ミャンマー（2015年取得→2023年売却完了） | 合弁相手が**国軍系企業**。2021年2月のクーデター後、人権上の批判が高まり事業継続が困難に。合弁解消交渉は難航し、最終的に保有株を合弁先へ売却 | **誰と組むかが事業の存続条件になる**。カントリーリスクは経済指標では測れない         |

> キリンのミャンマー撤退は、**「地政学リスクと人権配慮が、企業の撤退判断を直接動かした」**という点で
> 日本企業にとって象徴的な事例になった。現地の収益性そのものは悪くなかったと報じられており、
> **儲かっていても続けられない事業がある**ことを示している。

その後のキリンは、海外ビール（豪ライオン）を保持しつつ、**医薬（協和キリン）とヘルスサイエンス**へ重心を移している。
2025年12月期は純利益1,475億円と過去最高水準で、海外売上比率は56.0%。

### 3-3. サントリー ― ウイスキーで世界へ、そして逆風

- 2014年、米ビーム社を**約1.6兆円**で買収。ジムビーム等のバーボンと、山崎・響・白州などの日本ウイスキーを
  同じ販売網に載せる構想だった。非上場企業としては異例の規模である。
- 2020年代前半は北米の需要が強く、ビームサントリーは業績を牽引した。
- しかし**2025年12月期は逆風**。米国の物価高で中間所得層の蒸留酒需要が落ち、
  **米バーボンブランドの商標権について424億円の減損**を計上。営業利益は前期比33%減の2,211億円、
  純利益は51%減の865億円となった（2026年2月13日発表）。中国のワイン子会社売却で60億円の売却損も出ている。

> 学べる点：**スピリッツは景気感応度が高い**。ビールより単価が高く、嗜好品性が強いぶん、
> 消費者の財布が締まると真っ先に落ちる。「海外＝安定成長」ではない。

## 4. 輸出 ― 日本から「持ち出す」ルート

M&Aと並ぶもう一つの海外戦略が、**日本で作って海外に売る**輸出である。

| 品目                   | 2025年の輸出額   | 前年比              |
| ---------------------- | ---------------- | ------------------- |
| **合計（日本産酒類）** | **1,494.77億円** | **＋11.8%**         |
| ウイスキー             | 489.79億円       | ＋12.2%             |
| 清酒（日本酒）         | 458.79億円       | ＋5.6%              |
| ビール                 | 262.65億円       | ＋24.8%（過去最高） |
| リキュール             | 144.71億円       | ＋2.0%（過去最高）  |

出典：国税庁「最近の日本産酒類の輸出動向について」（財務省貿易統計ベース）。
2024年は1,337億円で前年比▲0.5%と踊り場だったが、**2025年に過去最高を更新した**。

```
  【輸出が伸びる理由】
   ① 円安 ── 現地通貨ベースで割安になり、価格競争力が上がる
   ② 和食の世界的普及 ── 日本酒・焼酎の飲用シーンが増える
   ③ ジャパニーズウイスキーの評価 ── 国際的な品評会での受賞が積み重なった
   ④ 2024年12月「伝統的酒造り」のユネスコ無形文化遺産登録 ── 物語としての訴求力
   ⑤ 政府の輸出促進 ── 農林水産物・食品の輸出額目標5兆円、国税庁の輸出支援

  【伸びない理由・制約】
   ① 世界の酒類市場に占める清酒のシェアは0.1%未満（2023年・IWSR）＝認知度がまだ低い
   ② 蔵元の多くが小規模で、輸出実務（規制・ラベル・物流）を自前で持てない
   ③ ウイスキーは原酒の在庫制約。今すぐ増産しても出荷できるのは数年〜十数年後
   ④ 各国の酒類規制・関税・宗教上の制約
```

輸出の実務は、**輸出入酒類卸売業免許を持つ卸・商社**が担うことが多い。
この免許には需給調整の枠がないため新規参入しやすく、小さな専門商社が次々に生まれている。
→ [酒類卸](../../06_商社・卸売/08_酒類卸/02_市場の縮小と各社の戦略.md)

### 4-1. 「ジャパニーズウイスキー」の定義問題

日本のウイスキーには長らく法的な原産地定義がなく、**海外産の原酒を輸入して瓶詰めしただけのものが
「Japanese Whisky」として売られる**事例が問題視された。
2021年に日本洋酒酒造組合が業界の自主基準（国内での糖化・発酵・蒸留・貯蔵3年以上・国内瓶詰め等）を定め、
表示の整理が進んでいる。**ブランド価値を守るためのルール整備**であり、輸出拡大の前提条件でもある。

## 5. 健康志向とどう向き合うか

海外展開と並んで、各社が避けて通れないのが**「飲酒は健康リスクを伴う」という前提の強まり**である。

| 動き                                                     | 内容                                                                                                    | 年                   |
| -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- | -------------------- |
| アルコール健康障害対策基本法                             | 不適切な飲酒による健康障害の防止を国の施策に位置づけ                                                    | 2013年（2014年施行） |
| アサヒビール「スマートドリンキング」提唱                 | 飲む／飲まないを個人が選べる社会を目指す考え方                                                          | 2020年12月           |
| **厚生労働省「健康に配慮した飲酒に関するガイドライン」** | **純アルコール量（g）**での把握を推奨。生活習慣病リスクを高める量の目安を男性40g／日、女性20g／日と提示 | 2024年2月            |
| 缶への純アルコール量表示                                 | 各社が段階的に表示を導入。商品マスタの改訂が流通側にも波及                                              | 2024年〜             |
| 高アルコールRTDの見直し                                  | 大手各社がアルコール分8%以上の缶チューハイの新商品を出さない方針を示したと報じられる                    | 2025〜2026年         |

> メーカーにとっての意味：**「たくさん飲んでもらう」ことを前提にした成長は描けなくなった**。
> 代わりに、(a) 単価を上げる（プレミアム化）、(b) 飲まない人を客にする（ノンアル・低アル）、
> (c) 人口の多い海外へ出る、という3つしか残らない。
> このノートの主題である「海外展開」は、健康志向という制約の裏返しでもある。

※20歳未満の飲酒・妊娠中の飲酒は法律・医学の両面で禁じられている。
本ノートは産業構造の解説であり、飲酒を勧める趣旨はない。

## 6. 酒以外への多角化

国内の酒が縮むなら、**酒以外の事業で稼ぐ**という選択もある。4社の姿勢は大きく違う。

| 社           | 酒以外の柱                                                         | 方向性                                                                                                                      |
| ------------ | ------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| アサヒ       | 飲料（アサヒ飲料）、食品（カルピス、和光堂等）                     | 国内は飲料・食品、成長は海外酒類                                                                                            |
| **キリン**   | 医薬（協和キリン）、ヘルスサイエンス（ファンケル、ブラックモアズ） | **「酒の会社」から「健康の会社」へ**の比重移動が最も鮮明                                                                    |
| サントリー   | 清涼飲料（サントリー食品インターナショナル）、健康食品             | 飲料が規模では本体級。酒類はスピリッツで世界展開                                                                            |
| **サッポロ** | 食品飲料（ポッカサッポロ）、外食、**不動産**                       | 2025年12月に不動産事業（恵比寿ガーデンプレイス等）を米KKR・PAG陣営へ**4,770億円**で譲渡すると発表。酒類・食品飲料への集中へ |

サッポロの不動産売却は、**「本業で稼げる会社に戻る」ための資産整理**という位置づけで、
株式の51%を2026年6月1日に譲渡し、残りを2028年・2029年に段階譲渡する契約と報じられている。

## 7. この章のまとめ

1. 国内は**成人人口減 × 1人あたり飲酒量減**の二重の縮小。景気循環ではなく構造的なもの。
2. だから各社は**海外を買った**。アサヒは欧州・豪州で海外比率を過半に、サントリーはビームでスピリッツ世界大手に。
3. ただし**買えば勝てるわけではない**。キリンはブラジルで減損・売却、ミャンマーでは地政学リスクにより撤退。
   サントリーも2025年に米ウイスキーで424億円の減損を計上した。
4. 輸出は2025年に**1,494.77億円と過去最高**。ウイスキー・清酒が牽引し、ビール・リキュールも最高額。
5. 健康志向（2024年の飲酒ガイドライン）は制約であると同時に、**ノンアル・低アルという新市場**を生んだ。
6. 酒以外への多角化の度合いは各社で大きく異なり、**キリン＝健康、サッポロ＝資産整理**と方向が分かれている。

## 8. 用語メモ

| 用語                                   | 意味                                                                                                            |
| -------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| **のれん**                             | M&Aで買収額が対象企業の純資産を上回る部分。収益が計画に届かないと減損（費用計上）になる                         |
| **減損**                               | 資産の価値が回収見込みを下回ったときに帳簿価額を切り下げる会計処理。利益を大きく押し下げる                      |
| **海外売上比率**                       | 連結売上のうち海外事業が占める割合。キリンHDは56.0%（2025年12月期）                                             |
| **カントリーリスク**                   | 進出先の政変・規制・為替・送金制限などのリスク。ミャンマーの事例はその典型                                      |
| **プレミアム化**                       | 単価の高い商品構成へ移すこと。数量が減る市場で売上を守る代表的な手段                                            |
| **RTD**                                | Ready To Drink。缶チューハイ・缶ハイボールなど開けてすぐ飲める製品                                              |
| **IWSR**                               | 酒類市場の国際的な調査会社。世界市場規模やシェアの出典としてよく使われる                                        |
| **ジャパニーズウイスキー（自主基準）** | 2021年に日本洋酒酒造組合が定めた表示基準。国内での糖化・発酵・蒸留、3年以上の国内貯蔵、国内瓶詰め等を要件とする |
| **純アルコール量**                     | 飲料量(ml)×度数(%)÷100×0.8 で求めるアルコールのグラム数。2024年の厚労省ガイドライン以降、表示が進む             |
| **伝統的酒造り**                       | こうじ菌を用いた日本の酒造りの技術。2024年12月にユネスコ無形文化遺産に登録された                                |
| **輸出入酒類卸売業免許**               | 自社が輸出入する酒類を卸売できる免許。需給調整の枠がなく、輸出参入の入口になる                                  |
