## 1. 2026年10月1日、ビール系の酒税が一本化される（最大の論点）

2017年に成立した改正酒税法の**最終段階**が、いよいよ2026年10月1日に施行される。

| 区分                               | 〜2026年9月 | 2026年10月〜                 | 差                   |
| ---------------------------------- | ----------- | ---------------------------- | -------------------- |
| ビール                             | 63.35円     | **54.25円**（1kL 155,000円） | **▲9.10円（減税）**  |
| 発泡酒（麦芽比率25%未満）          | 46.99円     | **54.25円**                  | **＋7.26円（増税）** |
| 新ジャンル（法令上は発泡酒）       | 46.99円     | **54.25円**                  | **＋7.26円（増税）** |
| その他の発泡性酒類（チューハイ等） | 28円        | **35円**（1kL 100,000円）    | **＋7円（増税）**    |

※350ml換算。出典：財務省「酒税に関する資料」、国税庁。

```
  段階的一本化の全体像（350ml換算・円）

   77 ┤●ビール
   70 ┤ ╲●
   63 ┤   ╲●
   54 ┤     ╲●━━━━ 54.25 に一本化 ●━━━━
   47 ┤   ●━━╱                    ╱
   38 ┤ ●━╱ 新ジャンル           ╱
   35 ┤                    ●━━━━╱ チューハイ等 35
   28 ┤ ●━━━━━━━━━━━━━━●
      └──────────────────────────────────
       2020/10   2023/10          2026/10
```

**なぜ一本化するのか**：財務省は「酒類間の税負担の公平性の回復」を理由に挙げている。
似た飲み物なのに税率が違えば、**税の設計が商品開発をゆがめる**。その歪みを正す、という整理である。
同時に、増税される発泡酒・新ジャンル・RTDは数量が多いため、**縮み続ける酒税収を下支えする**意味も持つ。

## 2. 主力ブランドの「ビール化」が相次ぐ

税差が消えれば、麦芽を減らす理由がなくなる。各社は主力の新ジャンルを**ビールへ製法変更**すると発表した。

| ブランド                  | メーカー       | 内容                                              | 時期           |
| ------------------------- | -------------- | ------------------------------------------------- | -------------- |
| **金麦**                  | サントリー     | 麦芽比率を50%以上に高めてビール化                 | 2026年10月以降 |
| **本麒麟**                | キリンビール   | 新ジャンル→ビールへ製法変更。全国リニューアル発売 | 2026年11月4日  |
| **GOLD STAR／麦とホップ** | サッポロビール | 新ジャンル（発泡酒②）からビールへ品目変更         | 2026年下期     |

（各社発表および日本経済新聞・ITmedia・日本ビアジャーナリスト協会などの報道、2026年1〜5月）

```
  【2026年9月までの棚】            【2026年10月以降の棚】
  ┌──────────┐                  ┌──────────┐
  │ ビール棚  │ 高い              │           │
  ├──────────┤                  │ ビール棚  │ 発泡酒・新ジャンルの
  │ 発泡酒棚  │ 中間              │ に統合    │ 主力が流れ込む
  ├──────────┤                  │           │
  │ 新ジャンル棚│ 安い            │           │
  └──────────┘                  ├──────────┤
                                  │ RTD棚     │ 相対的に割高に
                                  └──────────┘
   価格で分かれていた3段の棚が、
   「中身と価格帯」で分かれる棚に組み替わる
```

**起きうること**（2026年9月時点では確定していない）

- 9月に増税品目（発泡酒・新ジャンル・RTD）の**駆け込み需要**、10月に**反動減**。
- 「安いから買う」という理由が消えるため、**ブランド力の差がそのまま数量差**になる。
- ビールは減税だが、原材料費・物流費・人件費の上昇分を吸収するため、**店頭価格が素直に下がるとは限らない**。
- 業務用の樽生も減税対象。飲食店の原価は下がるが、値下げに回すか利益に回すかは店ごとの判断になる。
  → [居酒屋](../16_居酒屋/README.md)

## 3. アサヒグループのサイバー攻撃と、その後の業績インパクト

2025年9月29日、アサヒグループホールディングスがランサムウェア攻撃を受け、
**受注・出荷システムが停止**。国内の生産・物流が広範に止まった。

| 項目                   | 内容                                                                                 | 出典・時点         |
| ---------------------- | ------------------------------------------------------------------------------------ | ------------------ |
| 発生                   | 2025年9月29日。ランサムウェアグループ「Qilin」による攻撃と報じられる                 | 報道ベース         |
| 供給影響               | 受注・出荷システムが停止し、国内の商品供給が滞る。手作業での受注対応に切り替え       | 同社公表           |
| 受注・出荷システム復旧 | 2025年12月初旬                                                                       | 報道ベース         |
| 物流網の正常化         | 2026年2月                                                                            | 同                 |
| 復旧完了               | 2026年4月                                                                            | 同                 |
| 業績影響               | 2025年12月期の売上収益が**想定を約600億円（▲2.0%）下回る見込み**                     | 同社開示（2026年） |
| 情報流出               | 2026年2月18日時点で**11万5,513件**の流出を確認（従業員5,117件、取引先関係11万396件） | 同社公表           |

**業界への波及**

- アサヒの供給停止期間に、**キリン・サッポロが代替需要を取り込んだ**。
  2025年12月期はキリンHDの純利益1,475億円、サッポロHDの純利益194億円といずれも前期比約2.5倍に拡大し、
  「アサヒの障害が利益を押し上げた」と報じられている（2026年2月）。
- アサヒビールの2025年10〜12月の売上高は概算で前年同期比2割減と報じられ、年末需要を取り逃した。
- **教訓**：ビールは需要予測に基づく計画生産・在庫型の商売で、**受注と出荷は完全にシステム依存**している。
  工場が無傷でも、基幹システムが止まれば商品は動かない。食品・飲料業界全体のBCP見直しの契機になった。

## 4. 2025〜2026年の市場動向 ― 「ビール回帰」は本物か

| 指標                                         | 内容                                                                                 | 年・出典         |
| -------------------------------------------- | ------------------------------------------------------------------------------------ | ---------------- |
| 大手3社（アサヒ除く）のビール類販売数量      | 前年比▲3%                                                                            | 2025年・各社発表 |
| 同・ビールカテゴリー                         | 前年比＋2%                                                                           | 2025年           |
| 同・エコノミージャンル（発泡酒＋新ジャンル） | 前年比▲7%                                                                            | 2025年           |
| サッポロビールのビールカテゴリー             | 前年比103%                                                                           | 2025年・同社     |
| 開示方針                                     | **アサヒ・キリンは数量開示を取りやめ**。2025年以降はサントリーとサッポロのみ数量開示 | 2024年12月〜     |

```
  ビール系の内訳イメージ（数量ベースの方向感、2025年）

   ビール          ▲▲▲▲▲▲▲▲▲▲▲▲ ＋2%     ← 減税が効いている
   発泡酒・新ジャンル ▼▼▼▼▼▼▼      ▲7%     ← 増税で縮む
   ────────────────────────────
   ビール類 合計                    ▲3%     ← 全体では減少が続く

   ※「ビール回帰」は確かに起きているが、
     それはビール類全体の縮小を止めるほどではない、というのが2025年の実像。
```

> 読み方の注意：**大手2社が数量を開示しなくなったため、業界全体のシェアや数量は公式には分からなくなった**。
> 2026年以降の「シェア争い」の報道は、POSデータや推計に基づくものが増える。
> 「アサヒが首位、キリンが2番手」という序列だけが安定した事実で、
> 酒税一本化を機に**サントリーが2位に浮上する可能性**を指摘する見方もある（ダイヤモンド・オンライン、2026年）。

## 5. RTD（缶チューハイ）― 増税でも成長を狙う

- 2026年10月に350ml換算28円→35円へ増税。ビールとの税差は約35円→約19円に縮む。
- それでも各社は成長カテゴリーとして扱っており、打ち手は**味の幅**に向かっている。

| 動き                 | 内容                                                                                         |
| -------------------- | -------------------------------------------------------------------------------------------- |
| 無糖・無炭酸の拡大   | お茶割り、レモンサワー系など「炭酸でない」RTDが新潮流として注目される（食品新聞、2026年4月） |
| ビールとの中間領域   | ビールほど重くなく、従来のチューハイより飲みごたえのある帯を狙う商品設計                     |
| 高アルコールの見直し | 大手各社が**アルコール分8%以上の缶チューハイの新商品を出さない方針**を示したと報じられる     |
| サッポロの目標       | 2026年に前年比5.1%増の1,230万ケースを目標とし、3月に「飲みごたえ〈超無糖〉」2種を投入        |
| 年間着地の不透明さ   | 増税を控え、駆け込みと反動のどちらが大きいか読みにくい情勢と業界紙は伝える                   |

> 背景にあるのは**健康配慮の潮流**。2024年2月の厚労省「健康に配慮した飲酒に関するガイドライン」以降、
> 純アルコール量（g）での把握が推奨され、**高アルコール商品を出しにくい空気**ができた。
> 増税と健康志向が同じ方向（低アル化）に働いている点が、RTDの2026年の特徴である。

## 7. クラフトビールは1,000か所目前

| 指標                         | 数値                                             | 年・出典               |
| ---------------------------- | ------------------------------------------------ | ---------------------- |
| 国内の醸造所（ブルワリー）数 | 約950〜970か所。1,000か所超えが目前              | 2026年3〜4月・民間集計 |
| 2019年度                     | 約420社                                          | 民間集計               |
| 市場規模                     | 出荷43,745kL／売上約360億円、ビール市場の約0.95% | 2022年度・民間調査     |

- 増加を支えるのは制度。**最低製造数量基準の引き下げ（1994年、ビール2,000kL→60kL）**、
  **年3,000kL以下への酒税軽減**（租税特別措置）、**2018年のビール定義拡大**（麦芽比率50%以上、副原料に果実・香草等）。
- 2026年10月の一本化は、**クラフトにとっては追い風**。もともと麦芽比率が高く「ビール」区分にいるため、
  減税の恩恵を受ける側にいる。
- 2024年12月の「伝統的酒造り」ユネスコ無形文化遺産登録は日本酒・焼酎の話だが、
  **「地域の酒」全体への関心**という形でクラフトにも波及している。

## 8. 企業の構造改革 ― サッポロの不動産売却

2025年12月24日、サッポロホールディングスが**不動産事業を米KKRとアジア系PAGの陣営へ4,770億円で譲渡する**と発表した。

| 項目         | 内容                                                                                                                                             |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| 対象         | サッポロ不動産開発（恵比寿ガーデンプレイス、オフィス等）                                                                                         |
| 譲渡額       | 4,770億円                                                                                                                                        |
| スケジュール | 2026年6月1日に株式51%、2028年6月に20%、2029年6月に29%を段階譲渡                                                                                  |
| 入札経緯     | 2025年8月の2次入札にベインキャピタル、KKR、ローンスターの3陣営。最終的にKKR・PAG陣営が取得。**国内デベロッパーは価格で及ばなかった**と報じられる |
| 会計上の扱い | 2025年12月期決算で不動産事業を非継続事業に分類                                                                                                   |

> 意味：サッポロにとって恵比寿の土地は**旧ビール工場跡地**であり、長く安定収益源だった。
> それを手放すのは、**「酒類・食品飲料で稼げる会社に戻る」という宣言**である。
> 一方で、縮む国内市場で本業だけに絞ることのリスクも同時に負うことになる。

## 9. 全体の構図（まとめ）

1. **2026年10月1日の酒税一本化が、この年の中心にある**。30年続いた「税率の低い区分を発明する競争」が終わり、
   ビール・発泡酒・新ジャンルが同じ54.25円になる。競争軸は「税」から「中身とブランド」に戻る。
2. その結果、**金麦・本麒麟・GOLD STARなど主力の新ジャンルが次々とビールへ製法変更**される。
   カテゴリーとしての「第三のビール」は事実上終わる。
3. RTDは増税される側。ただし各社は無糖・無炭酸など味の幅で成長を狙う。健康配慮の流れも重なり、
   **業界全体が低アルコール方向へ寄っている**。
4. **2025年はアサヒのサイバー攻撃が業界の勢力図を一時的に動かした**。
   キリン・サッポロが代替需要で大幅増益。基幹システムが止まれば商品は動かないという事実が可視化された。
5. 国内は縮み続ける一方、**輸出は2025年に1,494.77億円と過去最高**。ウイスキー・清酒が牽引し、
   ビール・リキュールも最高額を更新した。成長は海外にある、という構図は変わらない。

## 10. 用語メモ

| 用語                     | 意味                                                                                       |
| ------------------------ | ------------------------------------------------------------------------------------------ |
| **酒税の一本化**         | ビール・発泡酒・新ジャンルの税率を350ml換算54.25円に統一すること。2026年10月1日実施        |
| **エコノミージャンル**   | 発泡酒と新ジャンルを合わせた低価格帯の業界呼称                                             |
| **ビール化**             | 新ジャンル・発泡酒の麦芽比率を50%以上に引き上げ、酒税法上の品目を「ビール」に変更すること  |
| **駆け込み需要／反動減** | 増税前に買いだめが起き、増税後に売れなくなる現象。在庫を積みすぎると評価損になる           |
| **ランサムウェア**       | データを暗号化して身代金を要求するマルウェア。アサヒの事例では受注・出荷システムが停止した |
| **非継続事業**           | 売却・撤退が決まった事業を、会計上ほかの事業と区分して表示する扱い                         |
| **PI値**                 | Purchase Index。POSデータで来店客1,000人あたりの販売金額・数量を示す指標                   |
| **純アルコール量**       | 飲料量(ml)×度数(%)÷100×0.8 のグラム数。2024年の厚労省ガイドラインが把握を推奨              |
| **ビアテイスト飲料**     | ビール風の味わいを持つ飲料の総称。アルコール分1%未満のノンアルを含む                       |

※本ノートは産業動向の解説であり、飲酒を勧めるものではない。
20歳未満の飲酒は法律で禁止されている。飲酒には健康上のリスクがあり、
厚生労働省は2024年2月の「健康に配慮した飲酒に関するガイドライン」で純アルコール量での把握を推奨している。
