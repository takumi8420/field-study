# ビール・酒類

- 大分類: 食品・農水産・外食
- 状態: done
- 更新日: 2026-09-20

酒類メーカーは、**酒税という制度の上に商品を設計する産業**である。
ビール・発泡酒・新ジャンルという区分は味の違いではなく税率の違いから生まれ、
30年にわたって「税の安い区分を発明する競争」が続いてきた。
その競争が**2026年10月1日の税率一本化で終わる**。
加えて、ビール工場は転用できない大型装置の塊であり、**稼働率が利益を決める**。
縮む国内市場・巨額の海外M&A・健康志向という3つの圧力の下で、各社が何をしているかを見ていく。

## 1. 業界の定義・範囲

**ビール・酒類（メーカー）＝酒類製造免許を持ち、酒類を製造して出荷する事業者**。
酒税法上の「酒類」は**アルコール分1度（1%）以上の飲料**であり、1%未満は酒類ではない。

| 隣接領域                                                                                                               | この業界との境界                                                                                   |
| ---------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| [酒類卸](../../06_商社・卸売/08_酒類卸/README.md)                                                                      | 製造免許と卸売免許は別。**メーカーは消費者に直接売れない**（別途免許が必要）                       |
| [清涼飲料](../09_清涼飲料/README.md)                                                                                   | アルコール1%未満のノンアルは酒税法上「酒類」でなく、酒税も免許も不要。**事実上この両業界の重なり** |
| [居酒屋](../16_居酒屋/README.md)                                                                                       | 業務用（樽生・瓶）の最大の出口。メーカーはサーバー設置まで面倒を見る                               |
| [総合食品](../01_総合食品/README.md)                                                                                   | 大手酒類メーカーは飲料・食品も持つ複合企業（アサヒ飲料、ポッカサッポロ、サントリー食品等）         |
| [農業・種苗](../12_農業・種苗・肥料/README.md)                                                                         | 麦芽・ホップ・酒米・果実の川上。麦芽とホップは輸入が中心                                           |
| [アルミ](../../11_資源・エネルギー・鉄鋼金属/11_アルミ/README.md) ／ [ガラス](../../10_素材・化学/11_ガラス/README.md) | 容器。**中身の原料費より容器費のほうが重いとされる**                                               |

品目としては、ビール系（ビール・発泡酒・新ジャンル）、RTD（缶チューハイ等）、
清酒、焼酎、ウイスキー・スピリッツ、ワイン、リキュール、ノンアルコール飲料までを含む。

> この業界を一言で：**「税率が商品設計を決め、稼働率が利益を決める装置産業」**。

**成長性の見立て**：国内数量は**成人人口の減少 × 1人あたり飲酒量の減少**という二重要因で構造的に縮小。

大手各社は売上の過半を海外や酒以外で稼ぐ構造に移りつつある。

```
 ┌──────────────┐

 └──────┬───────┘
        ▼
 ┌──────────────┐  容器メーカー：アルミ缶・ガラス瓶・ステンレス樽・段ボール

 └──────┬───────┘
        ▼
 ╔══════════════╗  ★このフォルダの主役
 ║ 酒類メーカー   ║  仕込み→発酵→貯酒→ろ過→充填。リードタイム約1か月
 ║（製造免許4,070場）║  ★出荷した瞬間に酒税の納税義務が発生（課税移出）
 ╚══════┬═══════╝  固定費（償却・人件費・広告）が重い＝稼働率がすべて

 │ 酒類卸        │  全国系卸・総合食品卸の酒類部門。営業利益率0.5〜1%台
 └──┬────────┬──┘
    │家庭用   │業務用
    ▼         ▼
 ┌────────┐ ┌──────────────┐
 │量販・CVS│ │業務用酒販店（二次卸）│ 早朝配送・与信・樽生サーバー
 │ DS・EC  │ └────────┬─────┘
 └───┬────┘              ▼
```

メーカーが利益を取れるのは、(a) 全国ブランドの指名買い、(b) 規模による製造コスト優位、
(c) 業務用でのサーバー設置による囲い込み、の3点である。

## 5. 収益モデル・コスト構造

350ml缶1本のメーカー出荷価格（税抜）を約140円とした場合の内訳イメージ（2026年9月時点の税率での試算。実額は非開示）。

```
   ├─ 酒税                    63.35円  ← 2026年10月からは 54.25円（出荷価格の約45%）
   ├─ 容器（アルミ缶・蓋）      約15〜20円 ← 中身の原料費より高いとされる
   ├─ 原料（麦芽・ホップ・副原料）約 8〜12円
   ├─ 製造変動費（用役・水・CO2）約 3〜5円
   ├─ 製造固定費（償却・工場人件費）約10〜15円 ← 稼働率で1本あたりが動く
   ├─ 物流費                   約 5〜8円
   ├─ 広告宣伝・販促費          約10〜15円  ← ブランド維持の固定費
   └─ 営業利益                 残り
```

| 指標             | 目安・性質             | 読み方                                                                   |
| ---------------- | ---------------------- | ------------------------------------------------------------------------ |
| **稼働率**       | 最重要指標             | 固定費が重く、損益分岐点を超えると利益が急に伸びる。逆に落ちると即赤字圏 |
| 限界利益率       | 高い                   | 追加1本の変動費は原料・容器・酒税程度。だから数量が命                    |
| 広告宣伝費       | 年数百億円規模とされる | 減らせば短期の利益は出るが、ブランドが痩せる構造的固定費                 |
| 生産リードタイム | 約1か月                | 「売れてから作る」ができない。需要予測の精度が在庫と欠品を決める         |
| 海外売上比率     | 各社で大きく違う       | キリンHDは56.0%（2025年12月期）。国内だけを見ても各社の実力は分からない  |

> **なぜ寡占になるのか**：1工場が年数十万kL規模で、これを埋める販売力がないと固定費を割れない。
> さらに全国で名前を覚えてもらう広告費も要る。**装置とブランドの二重の壁**が大手4社の寡占を支えてきた。

## 6. 競争要因（KSF）と参入障壁

| 要素                 | 内容                                                                       | 障壁                             |
| -------------------- | -------------------------------------------------------------------------- | -------------------------------- |
| **ブランド**         | 味の差を説明しにくい商品なので「知っている名前」が買われる。広告で維持する | **高い**                         |
| **規模（稼働率）**   | 大型工場の固定費を割るだけの数量が要る                                     | **高い**                         |
| 販売網・卸の口座     | 全国の帳合と棚を取るには既存卸との関係が要る                               | 高い                             |
| 業務用のサーバー設置 | 飲食店のタップ（注ぎ口）は台数が限られ、一度入ると動きにくい               | 高い                             |
| 製造免許             | 酒税法の製造免許。ビールは年60kL、発泡酒は6kLの最低製造数量基準            | 中（**規模を求めなければ低い**） |
| 技術・原酒在庫       | ウイスキーは熟成年数がそのまま参入障壁になる                               | 高い（ウイスキー）               |
| ノンアル             | アルコール1%未満は酒税も免許も不要                                         | **低い**（＝競合が入りやすい）   |

> **参入の穴**：1994年の最低製造数量基準の引き下げ（ビール2,000kL→60kL）、
> 年3,000kL以下への酒税軽減、2018年のビール定義拡大により、
> **小規模で高単価・狭商圏のクラフト領域は開いている**。逆に「全国流通のナショナルブランド」は事実上閉じている。

## 7. 規制・法制度

| 制度                                                            | 中身                                                                                                | 効き方                                                                                          |
| --------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| **酒税法**                                                      | 製造・卸売・小売をすべて免許制に。所管は**国税庁**（酒税課）                                        | 業界の根本ルール。監督官庁が税務当局であることが業界の性格を決めている                          |
| **酒税の税率**                                                  | ビール系は2020年10月・2023年10月・**2026年10月**の3段階で一本化（350ml換算54.25円）。RTDは28円→35円 | 商品設計と価格の前提そのもの → [01_酒税が商品を作った](01_酒税が商品を作った.md)                |
| ビールの定義                                                    | 麦芽比率50%以上（2018年4月に67%以上から緩和）、副原料の範囲を政令で規定                             | クラフトの商品設計の幅が広がった                                                                |
| 最低製造数量基準                                                | ビール60kL、発泡酒6kL、清酒60kL、果実酒6kL                                                          | 1994年の引き下げが地ビール・クラフトを生んだ                                                    |
| 租税特別措置（酒税軽減）                                        | 前年度の総課税移出数量3,000kL以下の承認酒類製造者に1.25〜20%の軽減                                  | 小規模醸造所・蔵元の生命線                                                                      |
| **酒類の公正な取引に関する基準**（2017年告示）                  | 総販売原価を下回る継続販売を禁止                                                                    | 過度な安売りを抑制。主に流通側 → [酒類卸](../../06_商社・卸売/08_酒類卸/01_酒類流通の特殊性.md) |
| 20歳未満の飲酒禁止                                              | 年齢確認、広告の自主基準                                                                            | 販売・広告の運営コスト                                                                          |
| アルコール健康障害対策基本法（2013年）                          | 不適切な飲酒による健康障害の防止を国の施策に                                                        | 業界の自主規制の土台                                                                            |
| **健康に配慮した飲酒に関するガイドライン**（2024年2月、厚労省） | 純アルコール量（g）での把握を推奨                                                                   | 缶への純アルコール量表示、高アルコール商品の抑制へ                                              |
| 輸出関連（輸出促進法、輸出拡大実行戦略）                        | 国税庁が輸出コンソーシアム・補助金で支援                                                            | 輸出参入の後押し                                                                                |
| ジャパニーズウイスキーの表示基準（2021年、業界自主）            | 国内での糖化・発酵・蒸留、3年以上の国内貯蔵、国内瓶詰め等                                           | ブランド価値の保全                                                                              |

| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| **酒類**                       | 酒税法上、アルコール分1度（1%）以上の飲料。1%未満は酒類ではなく、酒税も免許も不要                                                                |
| **麦芽比率**                   | 原料に占める麦芽の重量比。50%以上（かつ副原料が規定内）なら酒税法上「ビール」。**税区分を決める最大のスイッチ** → [01](01_酒税が商品を作った.md) |
| **発泡酒**                     | 麦芽を原料の一部に使う発泡性酒類でビールに該当しないもの。税率は麦芽比率で3段階                                                                  |
| **新ジャンル（第三のビール）** | 麦芽を使わない、または発泡酒に麦由来スピリッツを加えて税率を下げたビール風飲料。2023年10月に法令上は発泡酒へ統合                                 |
| **RTD**                        | Ready To Drink。缶チューハイ・缶ハイボールなど、開ければそのまま飲める製品                                                                       |
| **課税移出**                   | 製造場から酒類を出荷すること。この時点で酒税の納税義務が発生する。需要指標「課税移出数量」の語源                                                 |
| **稼働率**                     | 設備能力に対する実生産量の比率。固定費の重いビール工場では利益を直接左右する → [02](02_メーカーの商売.md)                                        |
| **樽生（ケグ）**               | 樽詰め生ビール。サーバー設置・炭酸ガス・洗浄・空樽回収までが一体の業務用インフラ                                                                 |
| **業務用／家庭用**             | 料飲店向け＝業務用、量販店・CVS向け＝家庭用。価格も営業手法も別事業                                                                              |
| **エコノミージャンル**         | 発泡酒と新ジャンルを合わせた低価格帯の業界呼称                                                                                                   |
| **純アルコール量**             | 飲料量(ml)×度数(%)÷100×0.8 のグラム数。2024年の厚労省ガイドラインが把握を推奨                                                                    |
| **のれん／減損**               | M&Aで純資産を超えて払った部分と、その価値切り下げ。海外買収の成否がここに表れる → [03](03_国内縮小と海外展開.md)                                 |
