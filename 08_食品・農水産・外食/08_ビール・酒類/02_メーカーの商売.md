# メーカーの商売 ― 装置産業とブランドの二階建て

このノートで分かること：ビール会社は何にお金を使い、何で儲けているのか。
答えは2つ、**ビール工場は巨大な装置産業で稼働率が利益を決める**、そして**売価を守るのはブランドと広告**である。

税制の話（ビール・発泡酒・新ジャンルの区分）は [01_酒税が商品を作った](01_酒税が商品を作った.md) を先に読むと理解が早い。
卸・小売側の話は [酒類卸](../../06_商社・卸売/08_酒類卸/README.md) に譲る。

---

## 1. 結論：固定費の塊を、ブランドで埋める商売

```
  【コストの正体】                    【売上の正体】
   巨大な醸造設備・充填ライン          全国どこでも同じ味・同じ価格で
   ＝減価償却・人件費・光熱費          買えるナショナルブランド
   ＝作っても作らなくてもかかる固定費   ＝広告で維持する指名買い
            │                                  │
            └────────── 稼働率 ──────────────┘
              工場を埋められるだけの需要を
              ブランドで作り出せるかどうかが利益を決める
```

- ビール工場は、仕込み釜・発酵タンク・貯酒タンク・ろ過・充填ラインが一体になった**連続装置**である。
  一度建てれば、**中身が何であろうと固定費は同じだけかかる**。
- だから**「たくさん作って、たくさん売る」以外に利益を出す方法がない**。
  これが、日本のビール市場が大手4社の寡占になった最大の理由である。
- 一方、酒は**味の違いを言葉で説明しにくい商品**である。だから消費者は「知っている名前」を買う。
  ブランド＋広告が売価を支える二階部分になる。

> 押さえる構図：**下の階が装置（規模で戦う）、上の階がブランド（指名買いで戦う）**。
> どちらか一方だけでは成り立たない。クラフトが小さく成立できるのは、この二階建てを降りて
> 「小さい装置＋狭い商圏」という別の経済に乗っているからである（後述）。

## 3. ビール工場の経済性 ― 稼働率がすべて

### 3-1. 工程と設備

```
 麦芽 ─┐
 ホップ ├─▶ ①仕込み ─▶ ②発酵 ─▶ ③貯酒（熟成）─▶ ④ろ過 ─▶ ⑤充填・包装 ─▶ 出荷
 水   ─┘   （糖化）    1週間前後    数週間          （非加熱)   缶・瓶・樽
            釜・ろ過槽   発酵タンク   貯酒タンク      フィルタ    高速充填ライン
            ↑───────────── すべて専用の大型設備。転用できない ─────────────↑

  リードタイム：仕込みから出荷まで概ね1か月前後
  → 「売れてから作る」ができない。需要予測が外れると在庫か欠品になる
```

- 工場の中身は**タンクと配管**である。1基あたり数百kLの発酵・貯酒タンクが林立し、建屋・用役（蒸気・冷却・排水処理）が付く。
- 主要な固定費は **減価償却費・人件費・光熱費・排水処理**。生産量が半分になっても、これらはほとんど減らない。
- 逆に**限界利益率は高い**。追加で1本作るときに増えるのは原料・容器・酒税くらいなので、
  **稼働率が損益分岐点を超えた瞬間から利益が急に伸びる**。

### 3-2. だから何が起きるか

| 現象                       | 理由                                                                                   |
| -------------------------- | -------------------------------------------------------------------------------------- |
| 大手4社への集中            | 1工場が年数十万kL規模。この規模を埋められる販売力がないと成立しない                    |
| 工場の閉鎖・集約が続く     | 国内需要が減れば稼働率が落ちる。**工場を減らして残りの稼働率を上げる**のが唯一の処方箋 |
| 委託生産・相互OEM          | 自社工場が空くくらいなら他社品を受託する。逆に遠隔地は他社に委託して輸送費を削る       |
| 値下げに踏み切りにくい     | 固定費が重いので、単価を落として数量を稼ぐ戦略は失敗すると一気に赤字になる             |
| 生産拠点の地理的配置が重要 | 中身の大半は水で**重い**。遠くへ運ぶほど物流費が効く。需要地の近くに工場を置く         |

アサヒビールは2026年時点で北海道・福島・茨城・名古屋・吹田・博多の6工場を稼働させている（同社公表）。
2000年代以降、各社とも国内のビール工場を閉鎖・集約してきており、**「工場閉鎖ドミノ」と報じられる局面**もあった。

> 一言でいうと：**ビール会社の設備投資判断は「増やす」より「どこを畳むか」の判断になっている**。
> 国内が構造的に縮む市場である以上、これは今後も続く。

## 4. コスト構造 ― 350ml缶を分解する

メーカー出荷ベースでの大まかな内訳（2026年9月時点の税率で試算。実額は各社非開示のため推計）。

```
  350ml缶 1本のメーカー出荷価格（税抜）を 約140円 とすると

   ├─ 酒税                63.35円  ← 2026年10月からは 54.25円
   ├─ 容器（アルミ缶・蓋）  約 15〜20円  ← 中身の原料費より高いとされる
   ├─ 原料（麦芽・ホップ・副原料）約 8〜12円
   ├─ 製造変動費（用役・水・CO2） 約 3〜5円
   ├─ 製造固定費（償却・工場人件費） 約 10〜15円  ← 稼働率で1本あたりが動く
   ├─ 物流費                約 5〜8円
   ├─ 広告宣伝・販促費       約 10〜15円  ← ブランド維持の費用
   └─ 営業利益              残り

   ※ 出荷価格の約45%が酒税。原料費より「税」と「容器」が重いのが
     ビールというプロダクトの特徴。
```

読み取るべき点は3つ。

1. **原料費が主役ではない**。麦芽やホップの相場変動より、税・容器・稼働率のほうが効く。
2. **容器が重い**。アルミ地金の相場と円安が直撃する。→ [アルミ](../../11_資源・エネルギー・鉄鋼金属/11_アルミ/README.md)
3. **広告宣伝費が構造的な固定費**になっている。減らせば短期の利益は出るが、ブランドが痩せる。

原料調達の面では、**麦芽の大半は豪州・カナダ・欧州からの輸入**、ホップはドイツ・チェコ・米国産が中心で、
国内産（岩手・秋田・山梨など）は限られる。つまり**為替と海上運賃がそのまま原価に効く**。

## 5. 容器とチャネル ― 缶・瓶・樽で商売が変わる

### 5-1. 3つの容器

| 容器                   | 主な用途           | メーカーから見た性質                                                                             |
| ---------------------- | ------------------ | ------------------------------------------------------------------------------------------------ |
| **缶**                 | 家庭用の主力       | 軽く、割れず、積める。物流効率が最もよい。アルミ地金価格の影響を受ける                           |
| **瓶（リターナブル）** | 飲食店・一部家庭用 | 洗って繰り返し使う。**空瓶を回収する静脈物流**が必要。重く割れる                                 |
| **樽（ケグ）**         | 業務用の生ビール   | サーバー設置・炭酸ガス・配管洗浄・空樽回収までが一体のインフラ。**飲食店を囲い込む装置**でもある |

### 5-2. 業務用と家庭用は別の事業

```
  ┌─────────────── メーカー ───────────────┐
  │                                          │
  【業務用】樽・瓶                    【家庭用】缶
  │                                          │
  ▼                                          ▼
 業務用酒販店（二次卸）              量販店・CVS・DS・ドラッグ
 ・早朝配送、少量多頻度                ・大量ロット、センター納品
 ・サーバー貸与と洗浄                  ・チラシ特売、PB圧力
 ・飲食店への与信                      ・棚割りが勝負
  ▼                                          ▼
 居酒屋・レストラン・ホテル            家庭
 → [居酒屋](../16_居酒屋/README.md)    → [食品スーパー](../../07_小売・流通/03_食品スーパー/README.md)
                                        [コンビニ](../../07_小売・流通/01_コンビニエンスストア/README.md)

  価格：業務用のほうが1L単価は高く取れる  価格：家庭用は価格競争が激しい
  営業：店舗ごとの個別営業（人海戦術）    営業：チェーン本部との年間商談
```

| 論点           | 業務用                                     | 家庭用                             |
| -------------- | ------------------------------------------ | ---------------------------------- |
| 単価・利幅     | 高い                                       | 低い（特売の常連商材）             |
| 需要の安定性   | 天候・景気・感染症・宴会文化に左右される   | 相対的に安定                       |
| 販売の手間     | 店舗単位。サーバー設置・洗浄まで面倒を見る | チェーン本部との商談に集約         |
| 回収・静脈物流 | 空樽・空瓶の回収が必須                     | 缶は基本的に使い捨て（自治体回収） |
| ブランド露出   | **店で飲む＝体験がブランドを作る**         | 棚とCMがブランドを作る             |

> 業務用が利益率以上に重要な理由：**飲食店で飲んだ味が家庭用の指名買いにつながる**から。
> 樽生のサーバーを置いてもらうことは、単なる販売ではなく**ブランド体験の設置**である。
> コロナ禍で業務用が止まったとき、各社が強い危機感を持ったのはこのためでもある。

## 6. ブランドと広告宣伝費 ― なぜ重いのか

- ビールは**ブラインドで銘柄を当てるのが難しい**商品とされる。差が分かりにくいほど、選択はブランドに依存する。
- 加えて、ビールは**「人前で飲む」商品**である。何を注文するか、何を持ち寄るかには社会的な意味が乗る。
  ここに広告が効く余地が生まれる。
- 結果として、大手各社の**広告宣伝費・販売促進費は販管費の中で大きな比重**を占める（各社有価証券報告書）。
  金額の水準は非開示・区分もまちまちだが、**年数百億円規模**とされる。

| 打ち手                          | 中身                   | 効果の出方                                                                                   |
| ------------------------------- | ---------------------- | -------------------------------------------------------------------------------------------- |
| テレビCM・大型タレント起用      | 認知の底上げ           | 効果測定が難しいが、やめると棚が細る                                                         |
| スポーツ・イベント協賛          | 飲用シーンとの結びつけ | 長期のブランド資産 → [広告代理店](../../14_メディア・広告・エンタメ/01_広告代理店/README.md) |
| 店頭販促（POP・什器・値引原資） | 棚の確保               | 短期の数量に直結。リベートとして卸・小売に流れる                                             |
| 飲食店への樽生サーバー設置      | 体験の設置             | 中長期。設置台数がそのままシェアに効く                                                       |
| ブランドのリニューアル          | 中身・パッケージの刷新 | **2026年の「ビール化」はこの最大版**                                                         |

> ブランドが参入障壁になる仕組み：新規参入者は**工場を建てる資金**だけでなく、
> **全国で名前を覚えてもらう広告費**も用意しなければならない。装置とブランドの二重の壁が、
> 大手4社の寡占を30年以上維持してきた。

## 7. クラフトビール ― 別の経済に乗る

### 7-1. 規模感

| 指標                   | 数値                                                 | 年・出典               |
| ---------------------- | ---------------------------------------------------- | ---------------------- |
| 国内のクラフト醸造所数 | 約950〜970か所（1,000か所が目前）                    | 2026年3〜4月・民間集計 |
| 同・2019年度           | 約420社                                              | 民間集計               |
| クラフトビール市場規模 | 出荷43,745kL／売上約360億円、ビール市場全体の約0.95% | 2022年度・民間調査     |

### 7-2. なぜ小さくても成立するのか

```
  【大手の経済】                    【クラフトの経済】
   年数十万kLの工場                  年数十〜数百kLの醸造所
   全国流通・全国広告                 醸造所併設のタップルーム／地域の飲食店
   固定費を数量で割る                 固定費が小さく、単価が高い
   1本あたりの利益は薄い              1杯あたりの利益は厚い
   ↑                                 ↑
   規模の経済                         差別化と体験の経済
```

- 1994年の**最低製造数量基準の引き下げ**（ビール2,000kL→60kL）、
  発泡酒免許（6kL）の活用、**3,000kL以下への酒税軽減**（租税特別措置）、
  2018年の**ビールの定義拡大**（麦芽比率50%以上、副原料に果実・香草等）という制度変更が積み重なって、
  小さな醸造所が成り立つ条件が整った。
- クラフトは**物流圏が狭い**。冷蔵・短期間で飲みきる前提なので、遠くに運ばない。
  それが逆に「その土地でしか飲めない」という価値になる。

### 7-3. 大手との関係

| 関係                   | 例                                                                                |
| ---------------------- | --------------------------------------------------------------------------------- |
| 出資・資本提携         | キリンが2014年にヤッホーブルーイングへ出資（約33%）。販路と生産を大手が支える     |
| 大手自身のクラフト事業 | キリンの「SPRING VALLEY」（2015年に醸造所併設の店舗、2021年にブランドを全国展開） |
| 設備の受託醸造         | 小規模ブランドが他社設備を借りて作る（ファブレス型）                              |
| 競合として             | 業務用のタップ（注ぎ口）を大手の樽生と奪い合う                                    |

> 大手にとってクラフトは、**脅威というより「高単価帯の学習装置」**である。
> 数量では脅威にならないが、「ビールにお金を払う理由」を作り直しているのはクラフト側であり、
> 2026年の税一本化後にビールが品質競争へ戻るとき、この蓄積が効いてくる。

## 8. ノンアル・低アル ― 免許のいらない新市場

| 指標                                 | 数値                                   | 年・出典               |
| ------------------------------------ | -------------------------------------- | ---------------------- |
| ビールテイスト飲料（ノンアル）販売額 | 1,020億円／35.4万kL                    | 2025年・民間調査の推計 |
| 同・見通し                           | 1,050億円／36.1万kL                    | 2026年・同上           |
| 2026年1〜6月のビアテイスト飲料       | 金額PI 前年同期比＋6.8%、数量PI ＋6.9% | 2026年・POS集計        |
| 「アサヒゼロ」の販売数量             | 172万箱（当初目標の2.8倍超）           | 2024年・アサヒビール   |

- **アルコール分1%未満は酒税法上の「酒類」ではない**。酒税がかからず、製造・販売の免許も不要。
  つまり**税負担ゼロで、清涼飲料と同じ土俵**に立つ。→ [清涼飲料](../09_清涼飲料/README.md)
- メーカーにとっての意味は2つ。
  1. **酒税が乗らないぶん、利益率を取りやすい**（原価構造が清涼飲料に近い）。
  2. **「飲まない人」「飲めない場面」を客にできる**。運転前、昼、妊娠中、休肝日など需要の時間帯が違う。
- アサヒビールは2020年12月に「**スマートドリンキング**」（飲む・飲まないを自分で選べる社会）を提唱。
  厚生労働省が2024年2月に「健康に配慮した飲酒に関するガイドライン」で**純アルコール量（g）**での把握を推奨したことも、
  低アル・ノンアルへの重心移動を後押ししている。
- 一方、**免許の壁がない＝誰でも参入できる**領域でもある。飲料メーカー・新興ブランドとの競争になる。

## 9. この章のまとめ

1. ビール工場は**転用できない大型装置の塊**で、固定費が重い。**稼働率が利益を決める**。
2. 国内需要が縮むなかで、各社の設備判断は「増やす」ではなく「**どこを畳むか**」になっている。
3. コストの主役は原料ではなく**酒税・容器・固定費・広告**。
4. 業務用（樽・瓶）と家庭用（缶）は**別の事業**。業務用は利益以上に「ブランド体験の設置」として重要。
5. クラフトは**制度変更（最低製造数量・軽減税率・定義拡大）が作った別の経済**に乗っている。
6. ノンアル・低アルは**酒税も免許もかからない**ため、利益率が取りやすい反面、競合が入りやすい。

## 10. 用語メモ

| 用語                         | 意味                                                                                     |
| ---------------------------- | ---------------------------------------------------------------------------------------- |
| **稼働率**                   | 設備の能力に対する実際の生産量の比率。固定費が重い装置産業では、これが損益を直接左右する |
| **限界利益**                 | 売上から変動費（原料・容器・酒税など）を引いた額。固定費を回収する原資                   |
| **貯酒（ちょしゅ）**         | 発酵後のビールを低温で寝かせる工程。タンクが長期間ふさがるため設備計画上の制約になる     |
| **ケグ（樽）**               | 業務用の金属製容器。サーバーにつないで生ビールを注ぐ。回収・洗浄して再利用する           |
| **リターナブル瓶**           | 回収・洗浄して繰り返し使う瓶。静脈物流（戻りの物流）が必要                               |
| **静脈物流**                 | 商品を届けた帰りに空容器・廃材を回収する物流。酒類では空瓶・空樽で発生する               |
| **業務用／家庭用**           | 飲食店向け＝業務用、量販店・CVS向け＝家庭用。チャネルの呼び分け                          |
| **OEM／受託醸造**            | 他社ブランドの製品を自社設備で製造すること。空いた設備を埋める手段                       |
| **タップルーム**             | 醸造所に併設された飲食スペース。クラフトの主要な販路かつブランド体験の場                 |
| **スマートドリンキング**     | アサヒビールが2020年に提唱した考え方。飲む／飲まないを個人が選べるようにする             |
| **PI値**                     | Purchase Index。POSデータで来店客1,000人あたりの販売金額・数量を示す指標                 |
| **ナショナルブランド（NB）** | メーカーが全国展開する自社ブランド。小売のPB（プライベートブランド）と対比される         |

※本ノートは産業構造の解説であり、飲酒を勧めるものではない。20歳未満の飲酒は法律で禁止されている。
飲酒には健康上のリスクがあり、量と頻度には個人差への配慮が必要とされる。
