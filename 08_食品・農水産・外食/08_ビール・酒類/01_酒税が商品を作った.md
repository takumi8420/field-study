# 酒税が商品を作った ― 税率が決めた商品設計の30年

このノートで分かること：**ビール・発泡酒・新ジャンルという区分は、味の違いではなく税率の違いから生まれた**。
その仕掛けと、30年続いた「税とのいたちごっこ」、そして2026年10月に何が終わるのか。

酒を「飲みもの」としてではなく「税金が乗った工業製品」として見ると、この業界の商品ラインナップは一気に読める。
流通側（免許・卸・小売）の話は [酒類卸](../../06_商社・卸売/08_酒類卸/README.md) に譲り、ここでは**作る側の商品設計**に絞る。

---

## 1. 結論：日本のビール会社は「安い税率の器」を発明し続けてきた

```
  1994年               2003年頃            2020〜2026年
  ┌──────┐           ┌──────────┐        ┌──────────────┐
  │ビール │ 高い税率  │ 発泡酒   │ 中くらい│ 3つを同じ税率に│
  │63〜77円│ ──逃避──▶ │ 46.99円  │──逃避──▶│  54.25円      │
  └──────┘           └──────────┘  新ジャンル└──────────────┘
                                    （同 46.99円）      ↑
                                                  2026年10月で
   ※350ml換算の酒税額                             「逃げ場」が消える
```

- 酒税は**中身1kLあたりいくら**で決まる。だから**同じ350ml缶でも、どの区分に分類されるかで原価が20円近く変わる**。
- 20円の差は、店頭価格200円前後の商品では決定的である。だから各社は「税率の低い区分に入る作り方」を発明した。
- その結果生まれたのが**発泡酒**（麦芽を減らす）と**新ジャンル**（麦芽を使わない／別の酒を混ぜる）である。
- 2026年10月1日、この3つの税率が **350ml換算54.25円**に統一される。**逃げる先がなくなる**。

> ポイント：日本のビール系商品の歴史は「おいしさの競争」であると同時に、
> **「税法の条文の隙間をどう通すかの競争」**だった。ここを外すと商品名の意味が分からない。

## 2. 税率の基本 ― どこで、いくら、誰が払うのか

### 2-1. 課税のタイミング

```
  原料調達 ──▶ 仕込み・発酵・貯酒 ──▶ 充填 ──▶ 【製造場から出荷】──▶ 卸 ──▶ 小売 ──▶ 消費者
                                                    ▲
                                          ここで酒税の納税義務が発生
                                          （これを「課税移出」という）
                                          納めるのはメーカー（製造者）
```

- 酒税を納めるのは**メーカー**。消費者ではない。ただし税額は出荷価格に乗るので、**実質的な負担は消費者**に転嫁される。
- 出荷した時点で納税義務が生じるので、**売れ残っても税は戻ってこない**（返品・廃棄には別途手続きが要る）。
  在庫を積みすぎることが、メーカーにとって直接の資金負担になる理由である。
- 統計上の需要指標が「課税移出数量」と呼ばれるのは、この課税の仕組みに由来する。

**読み方のコツ**：

- **ビール系は「量あたり」課税**、蒸留酒は「度数が上がるほど増える」課税。設計思想が違う。
- **ビールが突出して高い**。1kLあたり181,000円は、清酒（100,000円）の1.8倍、チューハイ（80,000円）の2.3倍。
- **発泡酒には3段階の麦芽比率区分がある**点に注意。麦芽比率25%以上50%未満はすでに155,000円＝54.25円で、
  一本化後のビール税率と同じ。だから**税で得をしようとする商品は「麦芽比率25%未満」に集中した**。

## 3. 「麦芽比率」という一本の線

### 3-1. 定義

- **麦芽**：大麦を発芽させて乾燥させたもの。ビールの糖分（＝アルコールのもと）と香味の源。
- **麦芽比率**：原料のうち麦芽が占める重量比。**これが酒税法の分類を決める最大のスイッチ**。

| 麦芽比率                       | 酒税法上の品目                    | イメージ                                                            |
| ------------------------------ | --------------------------------- | ------------------------------------------------------------------- |
| 50%以上 ＋ 副原料が規定内      | **ビール**                        | 本来のビール。2018年3月までは67%以上が要件だった                    |
| 50%未満（25%以上）             | 発泡酒①                           | 税率は155,000円/kL。実は一本化後のビールと同額                      |
| 25%未満                        | **発泡酒②**                       | 税率134,250円/kL。「発泡酒」として売られた主力はここ                |
| 麦芽を使わない／別の酒を混ぜる | **新ジャンル**（法令上も発泡酒②） | エンドウ豆・とうもろこし等を使う型と、麦由来スピリッツを足す型の2つ |

### 3-2. 新ジャンルの正体（条文ベース）

国税庁の定義を噛み砕くと、新ジャンルは次の**2つの作り方**のどちらかである。

```
 【型A】麦芽をまったく使わない
   糖類 ＋ ホップ ＋ 水 ＋ 一定の物品（大豆やえんどうのたんぱく分解物、
   とうもろこし、酵母エキス、食物繊維 など）を発酵させる
   → 「その他の醸造酒（発泡性）」として低い税率に入った

 【型B】発泡酒に「別の酒」を足す
   麦芽比率50%未満の発泡酒 ＋ 大麦・小麦由来のスピリッツ（蒸留酒）
   → 「リキュール（発泡性）」として低い税率に入った
   ※ 主力ブランドの多くはこちら
```

> なぜこんな作り方をするのか：**条文の定義に当てはまらなければ「ビール」ではない**から。
> 「ビールに似ているが法律上はビールでないもの」を作れば、税が安くなる。
> 味をよくするためではなく、**分類を外すために原料を変えた**。これが新ジャンルの本質である。

2023年10月の改正で、**新ジャンルは法令上「発泡酒」に統合された**（税率も発泡酒②と同じ134,250円/kL）。
つまり2026年9月時点では、区分として残っているのは「ビール／発泡酒／その他の発泡性酒類」の3つだけで、
「新ジャンル」は**商品カテゴリーの通称として生き残っている**にすぎない。

## 5. 2026年10月に何が終わるのか

### 5-1. 税額の動き

| 区分                               | 〜2026年9月 | 2026年10月〜 | 差                   |
| ---------------------------------- | ----------- | ------------ | -------------------- |
| ビール                             | 63.35円     | **54.25円**  | **▲9.10円（減税）**  |
| 発泡酒（25%未満）・新ジャンル      | 46.99円     | **54.25円**  | **＋7.26円（増税）** |
| 発泡酒（25%以上50%未満）           | 54.25円     | 54.25円      | 変わらず             |
| チューハイ等「その他の発泡性酒類」 | 28円        | **35円**     | **＋7円（増税）**    |

### 5-2. 終わるもの・始まるもの

```
  【終わるもの】
   ・「ビールより安いから選ぶ」という購買理由
   ・麦芽を減らして税を逃れる商品設計（＝発泡酒・新ジャンルの存在理由）
   ・カテゴリー別の棚割り（ビール棚／発泡酒棚／新ジャンル棚の三段構え）

  【始まるもの】
   ・中身（麦芽比率・製法・味）での正面勝負
   ・既存ブランドの「ビール化」＝麦芽比率を50%以上に上げて品目を変更
   ・相対的に割高になるRTD（チューハイ）からビールへの需要シフト（の可能性）
```

実際に、主力の新ジャンルブランドが**ビールへ製法変更**すると各社が発表している。

| ブランド              | メーカー       | 発表内容                                                         |
| --------------------- | -------------- | ---------------------------------------------------------------- |
| 金麦                  | サントリー     | 麦芽比率を50%以上に高め、2026年10月以降ビールとして販売          |
| 本麒麟                | キリンビール   | 2026年11月4日に全国リニューアル発売、新ジャンル→ビールへ製法変更 |
| GOLD STAR／麦とホップ | サッポロビール | 新ジャンル（発泡酒②）からビールへ品目変更                        |

（2026年1〜5月の各社発表・報道ベース。詳細は [04_直近トピック_2026](04_直近トピック_2026.md)）

> **なぜ「ビール化」するのか**：増税で税率が同じになる以上、
> 「税が安い代わりに麦芽が少ない」という商品は**安くもないのに味で劣る**という最悪の位置に落ちる。
> ならば麦芽を増やして「ビール」と名乗ったほうが売れる。**税差が消えた瞬間、品質競争に戻る**という当たり前のことが起きる。

## 6. チューハイ（RTD）― 増税される側

- **RTD**＝Ready To Drink。缶を開ければそのまま飲める製品の総称。缶チューハイ、缶ハイボール、缶カクテルなど。
- 酒税法上は多くが「**リキュール（発泡性）**」や「スピリッツ（発泡性）」で、アルコール分10度未満なら
  「その他の発泡性酒類」として**28円／350ml**という最も低い税率が適用されてきた。
- ビール系より約20〜35円安い税率が、**2000年代以降のRTD急成長を下支えした**。

2026年10月にこれが35円へ上がる（＋7円）。ビールは▲9.10円なので、**両者の税差は約35円→約19円に縮む**。

| 論点                     | 内容                                                                                           |
| ------------------------ | ---------------------------------------------------------------------------------------------- |
| 価格差の縮小             | ビールとRTDの店頭価格差が縮む。「安いから缶チューハイ」という選択理由が弱まる                  |
| 各社の打ち手             | 無糖・無炭酸（お茶割り、レモンサワー系）など**味の幅**で差をつける方向へ（2026年・食品業界紙） |
| 高アルコール商品の見直し | 大手各社は**アルコール分8%以上の缶チューハイの新商品を出さない方針**を示していると報じられる   |
| 健康配慮との接続         | 低アルコール（3〜5%）帯への重心移動が進む                                                      |

なお、**アルコール分9度以上13度未満で発泡性のない**焼酎・ウイスキー・スピリッツ・リキュールには、
租税特別措置法により**80,000円/kL＋8度超1度ごと10,000円**という軽い税率が用意されている。
低アルコール化には税制上のインセンティブも存在する、という点は押さえておきたい。

## 7. ビール以外の酒 ― 税制の作りが違う

### 7-1. 日本酒（清酒）

- 税率は**100,000円/kL**（2023年10月に果実酒と統一）。1.8L（一升瓶）で180円、720mlで72円。
- ビール系に比べれば**量あたりの税は軽い**。つまり日本酒の価格の大半は税ではなく、**米・手間・ブランド**である。
- だから日本酒業界の課題は税ではなく、**需要そのものの縮小**にある。課税数量は1973年度の177万kLから
  2023年度は39万kL（ピークの3割以下、国税庁）。一方で純米酒・純米吟醸酒は増加しており、
  「安く多く」から「少なく良いものを」への転換が進んでいる。
- 2024年12月、**「伝統的酒造り」がユネスコ無形文化遺産に登録**され、輸出の追い風になっている。

### 7-2. 焼酎

- 蒸留酒類。**21度未満は200,000円/kL、21度以上は20度を超える1度ごとに10,000円加算**。
  25度の焼酎なら250,000円/kL＝1.8Lで450円。
- 度数課税なので、**度数を下げれば税が下がる**。焼酎の主力が20度・25度に集中しているのはこのためでもある。

### 7-3. ウイスキー

- 同じ蒸留酒類だが、**370,000円/kL（37度未満）**と焼酎より大幅に高い。37度以上は1度ごとに＋10,000円。
  40度なら400,000円/kL、700mlボトルで280円。
- 税が高くても成り立つのは、**単価そのものが高いから**。原酒を数年〜数十年寝かせる商売なので、
  税負担より**在庫（貯蔵原酒）の資金負担と需要予測の難しさ**のほうが経営課題として大きい。
- ハイボールとして薄めて飲む文化が定着し、業務用・家庭用の両方で需要が広がった。

### 7-4. 小規模事業者への軽減措置

租税特別措置法により、**前年度の総課税移出数量が3,000kL以下**の承認酒類製造者は、
酒税額の一定割合（規模に応じ1.25〜20%）が軽減される。
クラフトビールや小規模の蔵元が成り立つのは、**最低製造数量基準の引き下げ（1994年）とこの軽減措置**が支えているからである。

> 似た飲み物なのに税が違うのはおかしい、という整理である。
> 同時に、**減る一方だった酒税収を安定させたい**という財政側の事情も背景にある（ビールは減税だが、
> 数量の多い発泡酒・新ジャンル・RTDは増税されるため）。

## 9. この章のまとめ

1. ビール・発泡酒・新ジャンルという区分は**味の区分ではなく税の区分**。麦芽比率という一本の線が分けている。
2. 30年にわたり、メーカーは**税率の低い区分に入る作り方**を発明し、国は追いかけて税率を上げてきた。
3. 2026年10月、ビール系3区分が54.25円に一本化され、**この逃げ場が消える**。
4. 各社は主力の新ジャンルを**ビールへ製法変更**して対応する。競争軸は「税」から「中身」に戻る。
5. RTDは増税され、ビールとの価格差が縮む。日本酒・焼酎・ウイスキーは**別の税体系**で動いている。

次は、その税制の上でメーカーがどう儲けているかを [02_メーカーの商売](02_メーカーの商売.md) で見る。

| 用語                           | 意味                                                                                                                                                   |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **酒類**                       | 酒税法上、アルコール分1度（1%）以上の飲料。1%未満は酒類ではなく、酒税も製造・販売免許も不要                                                            |
| **麦芽**                       | 大麦を発芽・乾燥させたもの。ビールの糖分と香味の源                                                                                                     |
| **麦芽比率**                   | 原料に占める麦芽の重量比。50%以上（かつ副原料が規定内）なら酒税法上「ビール」。2018年3月までは67%以上が要件だった                                      |
| **発泡酒**                     | 麦芽を原料の一部に使う発泡性酒類でビールに該当しないもの。税率は麦芽比率で3段階に分かれる                                                              |
| **新ジャンル（第三のビール）** | 麦芽を使わない、または発泡酒に麦由来スピリッツを加えて税率を下げたビール風飲料。2023年10月に法令上は発泡酒へ統合され、2026年10月にビールと同税率になる |
| **RTD**                        | Ready To Drink。缶チューハイ・缶ハイボールなど、開ければそのまま飲める製品                                                                             |
| **その他の発泡性酒類**         | ビール・発泡酒以外で、アルコール分10度未満の発泡性酒類。RTDの多くがここに入る                                                                          |
| **課税移出**                   | 製造場から酒類を出荷すること。この時点で酒税の納税義務が発生する                                                                                       |
| **課税移出数量**               | 出荷され酒税が課された量。国内需要を見る代表指標                                                                                                       |
| **最低製造数量基準**           | 製造免許を受けるために必要な年間最低製造量。ビールは1994年に2,000kL→60kLへ引き下げられた                                                               |
| **租税特別措置（酒税軽減）**   | 前年度の総課税移出数量が3,000kL以下の承認酒類製造者への酒税軽減。小規模醸造所を支える制度                                                              |
| **エコノミージャンル**         | 業界で使われる呼称。発泡酒と新ジャンルを合わせた低価格帯のこと                                                                                         |

※本ノートは制度と産業構造の解説であり、飲酒を勧めるものではない。20歳未満の飲酒は法律で禁止されている。
アルコールには健康上のリスクがあり、厚生労働省は2024年2月の「健康に配慮した飲酒に関するガイドライン」で
純アルコール量（g）での把握を推奨している。
