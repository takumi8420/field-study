# 生成AI｜バリューチェーンと業界構造

**このノートで分かること**：生成AIの「誰が何を作り、誰に売っているか」。
GPUを作る会社からChatGPTを使う会社まで、5つの層が縦に積み上がった産業だということ。

## 0. まず押さえる全体像

生成AIは、**半導体 → データセンター／クラウド → 基盤モデル → アプリ → ユーザー**という
一方通行の縦積み構造になっている。石油産業が「油田 → 精製 → ガソリンスタンド」で理解できるのと同じで、
**どの層にお金と利益が溜まっているか**を見れば、ニュースの意味がほぼ読める。

```
                        ┌──────────────────────────────┐
  ユーザー（企業・個人）  │ 月額課金・API利用料を払う側        │
                        └──────────────▲───────────────┘
  ④ アプリ層             ChatGPT / Copilot / Claude Code / 各社SaaSのAI機能
   （UI・業務への組込み）  OpenAI, Microsoft, Salesforce, Adobe, 国内SIer・SaaS
                                     ▲  モデルをAPIで呼ぶ
  ③ 基盤モデル層          GPT / Claude / Gemini / Llama / Qwen / DeepSeek
   （モデルを学習・提供）   OpenAI, Anthropic, Google DeepMind, Meta, xAI, Mistral, 中国勢
                                     ▲  学習と推論の計算を借りる
  ② クラウド／DC層        AWS, Microsoft Azure, Google Cloud, Oracle, CoreWeave
   （計算資源を貸す）       ＋ データセンター事業者・電力・冷却
                                     ▲  GPUサーバを買う
  ① 半導体層              NVIDIA(GPU), AMD, Google TPU, Broadcom(カスタムASIC)
   （計算する石を作る）     ＋ TSMC(製造), SK hynix/Micron/Samsung(HBM)
```

> ポイント：**この矢印は「お金が下に流れる」向きでもある**。
> ユーザーが払った料金がアプリ→モデル→クラウド→半導体へと降りていく。
> 2020年代半ばの時点では、一番下（半導体）の利益率が一番高いという逆転が起きている。

## 1. 各層の役割と経済的な性格

| 層             | やること                                                          | 代表プレイヤー                                           | 経済的な性格                                             |
| -------------- | ----------------------------------------------------------------- | -------------------------------------------------------- | -------------------------------------------------------- |
| ① 半導体       | AIの計算をする専用チップ（GPU/TPU/ASIC）と高速メモリ（HBM）を作る | NVIDIA、AMD、Broadcom、TSMC、SK hynix                    | 供給が需要に追いつかず**売り手優位**。粗利率が極めて高い |
| ② クラウド／DC | チップを大量に並べ、電力・冷却・ネットワークとセットで貸す        | AWS、Azure、Google Cloud、Oracle、CoreWeave              | **装置産業**。巨額の設備投資を数年で償却する。稼働率が命 |
| ③ 基盤モデル   | 大量のデータで巨大モデルを学習し、APIとして提供する               | OpenAI、Anthropic、Google、Meta、xAI、中国勢             | 学習費が先払いの**赤字先行型**。差別化が効く期間が短い   |
| ④ アプリ       | モデルを業務・製品に組み込み、使える形にする                      | Microsoft、Salesforce、Adobe、無数のスタートアップ、SIer | 粗利はモデル利用料に食われる。**顧客接点とデータ**が武器 |
| ⑤ ユーザー     | 実際に業務で使い、人件費や時間を減らす                            | 全産業                                                   | 価値が最終的に落ちる先。ただし効果測定が難しい           |

**なぜ半導体が一番儲かるのか**：①〜④のどの層が勝っても、計算は必ず必要になる。
つまり①は「誰が勝つか分からない競争で、全員に道具を売る」立場にいる。
ゴールドラッシュでスコップを売る構図そのもの。
→ チップ側の詳細は [AI半導体とHBM](../02_半導体・先端半導体/02_AI半導体とHBM.md) に分けて書いている。

## 2. 基盤モデル層の3類型

生成AIの中核である③は、さらに3つのタイプに分かれる。ここの区別が付くと業界ニュースが読めるようになる。

| 類型                      | 中身                                                       | 代表                                              | 収益の取り方                                                     |
| ------------------------- | ---------------------------------------------------------- | ------------------------------------------------- | ---------------------------------------------------------------- |
| **クローズド（API提供）** | モデルの中身（重み）は非公開。APIかアプリ経由でのみ使える  | OpenAI、Anthropic、Google                         | API従量課金＋サブスク。値付けの自由度が高い                      |
| **オープンウェイト**      | モデルの重みを公開し、誰でもダウンロードして自前で動かせる | Meta（Llama）、Alibaba（Qwen）、DeepSeek、Mistral | モデル自体は無料。周辺（クラウド、サポート、エコシステム）で回収 |
| **垂直特化・自社専用**    | 特定業務や特定言語に絞って学習する                         | 各国のソブリンAI、金融・医療特化モデル            | 受託・ライセンス。規模より「使える領域」で勝負                   |

**「オープンウェイト」は「オープンソース」と厳密には違う**。
公開されるのは学習済みの数値（重み）であって、学習データや学習コードまで全部公開されることは少ない。
それでも「手元で動かせる」ことの意味は大きく、機密データを外に出せない企業や、
コストを下げたい事業者がここに流れる。

> 2026年時点では、モデルルーター（複数モデルを束ねて中継するサービス）OpenRouter において、
> 中国系オープンウェイトモデルの利用トークンが全体の6割前後を占めたと報じられる。
> 「最高性能はクローズド、実務の量はオープンウェイト」という二層化が進んでいる。

## 3. 縦に統合しようとする力と、水平分業の力

半導体が「設計と製造の水平分業」で説明できる（→ [半導体のサプライチェーン](../../03_電機・電子部品/02_半導体（ロジック・メモリ）/01_サプライチェーンと業界構造.md)）のに対し、
生成AIでは**各層が上下に手を伸ばす動き**が同時進行している。

```
 NVIDIA  ─────▶ クラウド事業者へ出資・DC構築にも関与（①→②へ）
 Google  ─────▶ 自社TPUを設計し、モデルもアプリも自社（①〜④を全部）
 OpenAI  ─────▶ 自社向けチップ開発・DC建設に参画（③→②①へ）
 Microsoft ───▶ Azureで計算を売り、Copilotでアプリも売る（②＋④）
 Meta    ─────▶ モデルを無料公開して③をコモディティ化し、自社サービスを守る
```

**なぜ統合したがるのか**：

1. **計算資源の確保**。GPUが買えなければモデルは作れないので、上流を押さえたい
2. **利益の取りこぼし防止**。中間業者に粗利を持っていかれたくない
3. **囲い込み**。モデルとクラウドをセットにすると顧客が移りにくくなる

逆に**分業が残る理由**は、各層の必要能力がまるで違うから。
半導体の製造は物理と装置の世界、モデル学習は研究者とデータの世界、
アプリは業務知識と営業の世界で、同じ会社が全部を最高水準でやるのは難しい。

## 4. 「どこがボトルネックか」を毎年追う

どの産業にも「実際に詰まっている場所」がある。生成AIでは、それが年々下へ移動してきた。

| 時期             | 実際のボトルネック      | 起きたこと                                               |
| ---------------- | ----------------------- | -------------------------------------------------------- |
| 2023年頃         | **GPUの供給**           | AI GPUの入手待ちが長期化。確保した企業が先行             |
| 2024〜2025年頃   | **先端パッケージとHBM** | チップは作れても、積層・実装の能力が足りない             |
| 2025〜2026年頃   | **電力と用地**          | データセンターを建てても電気が引けない。受電待ちが年単位 |
| （先行きの論点） | **需要そのもの**        | 積み上げた設備を埋めるだけの支払意思があるか             |

> 2026年時点で、国内データセンターの消費電力は日本全体の電力の約3%に近づき、
> 2021年の約1.5%からおよそ倍増したと報じられる。
> NVIDIAのBlackwell世代以降のGPUサーバは1ラックあたり100〜120kW級とされ、
> 従来の空冷（1ラック5〜10kW）では冷やしきれず、液冷が前提になりつつある。
> → [データセンター](../../04_情報通信・IT・ネット/03_データセンター/README.md)、[電力](../../11_資源・エネルギー・鉄鋼金属/04_電力/README.md)

## 5. 日本のポジション

日本勢は③（基盤モデル）でフロンティアを取るのは難しいが、他の層に居場所がある。

| 層             | 日本の位置                                                                                      |
| -------------- | ----------------------------------------------------------------------------------------------- |
| ① 半導体       | **装置と材料で世界上位**。HBM・先端パッケージ向けの装置・材料で恩恵。量産のロジックは弱い       |
| ② クラウド／DC | 国内DC建設ラッシュ。ただしIaaSの器は米国勢が押さえる。電力と用地の制約が重い                    |
| ③ 基盤モデル   | 国産LLM（ソブリンAI）を政策で後押し。規模でフロンティアを追うのは困難で、日本語・特定領域で勝負 |
| ④ アプリ       | **最も現実的な主戦場**。業務知識・既存顧客・現場データを持つSIerと業務SaaSが有利                |
| ⑤ ユーザー     | 利用率は急伸中だが欧米・中国より低水準。伸びしろ＝そのまま生産性改善の余地                      |

> 2024年度調査で、日本の個人の生成AI利用経験率は26.7%（前年度9.1%）。
> 米国68.8%、中国81.2%、ドイツ59.2%との差は大きい（総務省 令和7年版 情報通信白書）。
> 「日本は遅れている」と同時に「1年で約3倍」という立ち上がりも同じ数字が示している。

## 6. この業界を見るときの指標

- **ハイパースケーラー4〜5社の設備投資（CapEx）**：②の投資意欲＝業界全体の体温計
- **NVIDIAの四半期売上とデータセンター部門比率**：①の需給
- **主要モデル事業者の年換算売上（ARR／run rate）**：③に本当にお金が入っているか
- **100万トークンあたりの単価**：④の原価であり、値下がりスピードの指標（→ [ビジネスモデルと経済性](03_ビジネスモデルと経済性.md)）
- **企業の生成AI導入率・本番運用率**：⑤の実需（PoC止まりか、業務に載ったか）

## 用語メモ

- **基盤モデル（Foundation Model）**：大量データで汎用的に学習し、さまざまな用途に転用できる大規模モデルの総称。LLMはその一種
- **ハイパースケーラー**：自社で超大規模データセンターを運営する巨大クラウド事業者（AWS、Azure、Google Cloud など）
- **オープンウェイト**：学習済みモデルの数値（重み）が公開され、手元で動かせる状態。学習データまで公開とは限らない
- **推論（Inference）**：学習済みモデルを使って答えを出す処理。利用者が増えるほど積み上がる継続コスト
- **ソブリンAI**：自国の言語・データ・インフラで完結させるAIを国家として持とうとする動き
- **モデルルーター**：複数のモデルを束ね、用途やコストに応じて振り分けて中継するサービス
