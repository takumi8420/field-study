# 生成AI｜ビジネスモデルと経済性

**このノートで分かること**：生成AIが「誰からどうやってお金を取っているか」と、
なぜ巨大な売上が立ちながら赤字が続くのか。
鍵は **「学習費は先払いの固定費、推論費は使うほど増える変動費」** という二重構造にある。

## 1. 課金モデルの4類型

| 類型                             | 課金の仕方                            | 代表例                       | 事業者から見た性格                                               |
| -------------------------------- | ------------------------------------- | ---------------------------- | ---------------------------------------------------------------- |
| **API従量課金**                  | 入力・出力のトークン数に応じて課金    | モデル事業者のAPI            | 使われるほど原価も増える。**粗利率が読みやすいが低め**           |
| **サブスク（定額）**             | 1ユーザー月額◯◯円で使い放題に近い     | ChatGPT Plus、各種Copilot    | ヘビーユーザーで赤字になる。**原価は利用量に比例するのに売上は定額** |
| **シート課金（業務SaaS組込み）** | 既存SaaSのアドオンとして1席あたり月額 | 業務ソフトのAI機能           | 既存顧客に乗せやすい。値上げの名目になる                         |
| **成果連動・タスク課金**         | 処理した件数や成果に応じて            | 一部のエージェント型サービス | 顧客のROIと直結するが、原価変動リスクを事業者が負う              |

> **ここがSaaSと決定的に違う点**：従来のソフトウェアは「複製コストほぼゼロ」だった。
> 生成AIは**利用のたびにGPUと電気を消費する**ので、売上原価が利用量に比例して増える。
> 「定額使い放題」を出すと、使われるほど赤字が膨らむ。
> → [ソフトウェア・SaaS](../../04_情報通信・IT・ネット/06_ソフトウェア・SaaS/README.md) との比較で見ると差が際立つ。

## 2. コスト構造：固定費と変動費の二重構造

```
【モデル事業者のP/L（イメージ）】

  売上（API＋サブスク＋ライセンス）
   ├── 売上原価
   │    ├── 推論コスト（GPU時間・電力）………… 利用量に比例する変動費
   │    └── クラウド利用料（自社DCでなければ）
   ├── 研究開発費
   │    ├── 学習コスト（次世代モデルの事前学習）… 巨額の先払い固定費
   │    ├── 研究者の人件費 …………………………… 極端な高単価。獲得競争
   │    └── 学習データの調達・ライセンス料
   └── 販管費（営業・安全性対応・法務）

  → 売上が伸びても、次世代モデルの学習費が先に立つため営業赤字が続きやすい
```

**「作りながら走る」構造**：
現行モデルで稼いでいる間に、次世代モデルの学習に稼ぎ以上を突っ込む。
売上が数倍に伸びても赤字が縮まらないのはこのため。
半導体の装置償却（→ [前工程](../../03_電機・電子部品/02_半導体（ロジック・メモリ）/02_前工程.md)）と似ているが、
生成AIの場合は**償却前に技術世代が変わってしまう**ぶんさらに厳しい。

## 3. トークン単価の急落と、それが意味すること

生成AIの経済性を語るうえで最も大きい事実は、**同じ性能あたりの単価が猛烈に下がり続けている**こと。

| 時期                        | 単価の水準（100万トークンあたり、報道・指数ベース） |
| --------------------------- | --------------------------------------------------- |
| 2020年6月（GPT-3）          | 約60ドル                                            |
| 2025年2月（軽量モデル）     | 約0.10ドル                                          |
| 2026年5月末（市場平均指数） | 約2.04ドル                                          |
| 2026年9月初（市場平均指数） | **約0.97ドル**（過去最低圏）                        |

※ 2026年の数値は Silicon Data の「LLM Token Expenditure Index」ベースと報じられるもの。
モデルの性能帯が混在するため単純比較はできないが、**下げ止まっていない**ことは共通している。
「GPT-3からの5年で600分の1」「3年で1,000分の1」といった推計も示されている。

**下がる理由は4つ**：

1. フロンティア各社の激しい価格競争
2. 中国勢を中心とした高性能オープンウェイトモデルの台頭（無料で置き換えられる圧力）
3. ハード・ソフト両面の効率化（新世代GPU、量子化、MoE、推論最適化）
4. 用途別に小さいモデルを使い分ける運用の定着

**誰にとって何を意味するか**：

| 立場                | 意味                                                                                               |
| ------------------- | -------------------------------------------------------------------------------------------------- |
| アプリ事業者（④層） | 原価が毎年下がる＝**時間が味方**。同じ価格でも粗利が改善する                                       |
| モデル事業者（③層） | 値下げ圧力が常時かかる。**性能で差を付け続けないと単価を守れない**                                 |
| ユーザー企業        | 「今は高いから見送る」判断が古くなりやすい。去年不可能だった用途が今年は採算に乗る                 |
| 半導体・DC（①②層）  | 単価が下がるほど使用量が増えるので、**総需要としては増える**（ジェヴォンズのパラドックス的な構図） |

> 逆説：単価が下がっているのに業界全体の支出は増える。
> 安くなったぶんエージェントが大量にトークンを消費するようになるため。

## 4. ユニットエコノミクス：1リクエストあたりで考える

アプリ事業者の目線で、1回の利用にいくらかかるかを分解する。

```
 1リクエストの原価
  = (入力トークン数 × 入力単価) + (出力トークン数 × 出力単価)
  + 埋め込み・検索コスト（RAGの場合）
  + ログ保存・監視・ガードレール判定のコスト

  ※ 出力単価は入力単価の3〜5倍程度に設定されることが多い（出力は1トークンずつ逐次生成するため）
  ※ 推論（reasoning）モデルは内部の思考も出力トークンとして課金され、数倍に膨らむ
```

| 論点                     | 効いてくる場所                                                     |
| ------------------------ | ------------------------------------------------------------------ |
| **入力を短くする**       | RAGで渡す文書を絞る、会話履歴を要約して持つ                        |
| **モデルを使い分ける**   | 簡単な判定は小型モデル、難問だけ大型モデルに回す（ルーティング）   |
| **キャッシュを効かせる** | 同じ前置き（システムプロンプト）を再利用する仕組みで入力課金を削る |
| **バッチ処理に回す**     | 即時性が要らない処理は割安なバッチ枠を使う                         |

**LTV/CAC の考え方は従来SaaSと同じだが、粗利率の前提が違う**。
従来のSaaSが粗利率70〜80%を前提にできたのに対し、
AI機能の比重が高いサービスは原価が利用量に連動するため、粗利率が下がりやすい。
価格設定を「席数」ではなく「利用量」に寄せる動きが出ているのはこのため。

## 5. なぜ巨額投資が続くのか：設備側の算数

```
 ユーザーの支払い（アプリ・API）
        │
        ▼
  モデル事業者 ──長期契約──▶ クラウド事業者 ──GPU購入──▶ 半導体メーカー
        │                       │                          │
        │                       ▼                          ▼
        │                  DC建設・電力契約              製造委託（TSMC等）
        │
        └── 次世代モデルの学習に再投資（回収前に次の世代へ）
```

- 2026年、主要ハイパースケーラー数社の設備投資合計は**6,000億〜7,000億ドル規模**に達する見通しと報じられる
  （前年比3割超の増加。集計対象企業により数値が異なる）
- 設備投資は数年かけて償却されるので、**需要が想定を下回った瞬間に減損リスク**になる
- 投資の正当化には「将来これだけ使われる」という前提が要る。この前提の当否が「AIバブル論争」の核心

> ある試算では、現在のインフラ支出を正当化するには2030年時点でAI関連の年間売上が
> 2兆ドル規模必要で、現状の延長では約8,000億ドル足りない、という指摘も報じられている（推計）。
> 数字の前提はまちまちなので鵜呑みにはできないが、**「投資が先、収益が後」という時間差**は事実。

## 6. 各層の利益率のイメージ

| 層                 | 粗利率の目安                             | 理由                                                               |
| ------------------ | ---------------------------------------- | ------------------------------------------------------------------ |
| ① 半導体（AI GPU） | **非常に高い**                           | 供給制約と技術的な参入障壁。価格決定力がある                       |
| ② クラウド／DC     | 中程度                                   | 償却負担が重い。稼働率と長期契約の確保が生命線                     |
| ③ 基盤モデル       | 売上総利益は出ても**営業赤字**になりがち | 次世代学習費と人件費が重い                                         |
| ④ アプリ           | ピンキリ                                 | モデル利用料を粗利から払う。**顧客データと業務接点があれば守れる** |

**「AIで儲かっているのは誰か」への答え**：
2026年時点では、①の半導体と②の一部（長期契約を取れた事業者）。
③は売上こそ急拡大しているが利益にはなっていない。④は選別が進んでいる段階。

## 7. 投資判断・事業判断で見るべき数字

- モデル事業者の **年換算売上（ARR／run rate）** と、その伸び率の変化
- ハイパースケーラーの **CapEx／営業CFの比率**（借入依存が高まっていないか）
- **トークン単価指数**（原価トレンド）と **自社のトークン消費量**（需要トレンド）
- 企業側の **PoCから本番運用への移行率**：ここが動かないと売上は続かない
- DCの **受電確保状況**（契約済み容量）。建屋より電気がボトルネック

## 用語メモ

- **ARR／run rate**：直近の売上を年換算した数値。急成長企業の規模感を示すのに使われる。実績の年間売上とは違う
- **トークン単価**：100万トークンあたりの価格。入力と出力で別建て。出力のほうが高い
- **プロンプトキャッシュ**：繰り返し使う前置き部分をキャッシュして入力課金を下げる仕組み
- **ルーティング**：問い合わせの難易度に応じて安いモデルと高いモデルを振り分けること
- **CapEx（設備投資）**：データセンター・GPUなどへの投資額。AI業界の体温計
- **減損**：投資した資産の回収見込みが下がったとき、帳簿価額を切り下げる会計処理
- **ジェヴォンズのパラドックス**：効率化で単価が下がると、かえって総使用量が増える現象
