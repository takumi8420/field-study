# 生成AI

- 大分類: 注目テーマ
- 状態: done

文章・画像・コードなどを「作る」AIと、それを支える産業の総称。
**半導体 → クラウド → 基盤モデル → アプリ → ユーザー**という5層の縦積み構造で理解するのが最短ルート。
技術としてはLLM（大規模言語モデル）が中心で、その正体は「次に来る単語を確率で当てる装置」にすぎない。

## 1. 業界の定義・範囲

**生成AI（Generative AI）**＝学習した内容をもとに、新しいテキスト・画像・音声・動画・コードを
**生成する**AIの総称。分類や予測をする従来型AI（判別AI）と対になる概念。

| 区別すべき言葉 | 中身                                                             |
| -------------- | ---------------------------------------------------------------- |
| AI             | 人間の知的作業を機械にやらせる技術全般（1950年代からの言葉）     |
| 機械学習       | データからパターンを学ぶ手法。AIの一部                           |
| 深層学習       | ニューラルネットワークを多層にした機械学習。2010年代の主役       |
| **生成AI**     | 深層学習を使って**新しいコンテンツを作る**もの。2022年以降の主役 |
| **LLM**        | 生成AIのうち、言語を扱う大規模モデル。生成AIの中核               |

**隣接領域との境界**：

- 半導体側（GPU、HBM、先端パッケージ）は [半導体・先端半導体](../02_半導体・先端半導体/README.md) に分けて整理
- 計算資源の供給は [クラウド・IaaS](../../04_情報通信・IT・ネット/04_クラウド・IaaS/README.md) と [データセンター](../../04_情報通信・IT・ネット/03_データセンター/README.md)
- 業務ソフトへの組込みは [ソフトウェア・SaaS](../../04_情報通信・IT・ネット/06_ソフトウェア・SaaS/README.md)

## 3. バリューチェーン（川上 → 川下）

```
① 半導体 ──▶ ② クラウド／DC ──▶ ③ 基盤モデル ──▶ ④ アプリ ──▶ ⑤ ユーザー
 GPU/HBM      計算資源を貸す      モデルを学習・API提供   業務に組み込む   実務で使う
 NVIDIA他     AWS/Azure/GCP他    OpenAI/Anthropic他     SaaS/SIer      全産業

  ◀────────────── お金はこの向きに流れる（ユーザー → 半導体） ──────────────
```

- **付加価値は現状①に最も集中**。誰が勝っても計算は必要なので、チップ供給者が安定して稼ぐ
- ③は売上急拡大中だが、次世代モデルの学習費が重く**営業赤字になりやすい**
- ④は粗利をモデル利用料に食われる一方、**顧客接点と業務データ**という守りの資産を持つ
- 詳しくは [01_バリューチェーンと業界構造](01_バリューチェーンと業界構造.md)

**シェアの見方**：「生成AIのシェア」は層ごとにまったく別物。
①はNVIDIAの寡占、②は米大手3社＋新興GPUクラウド、③はクローズド2社＋オープンウェイト勢、
④は無数のプレイヤーの選別段階、という構図で捉える。

## 5. 収益モデル・コスト構造

| 収益モデル       | 内容                                                                          |
| ---------------- | ----------------------------------------------------------------------------- |
| API従量課金      | 入出力のトークン数で課金。出力単価は入力の3〜5倍程度が一般的                  |
| サブスク         | 1ユーザー月額。使われるほど原価が増えるため、ヘビーユーザーで逆ざやになりうる |
| シート課金       | 既存SaaSのAIアドオンとして1席あたり月額                                       |
| 成果・タスク課金 | 処理件数や成果に連動。エージェント型で採用が増えつつある                      |

**コスト構造の核心**：

- **学習費＝先払いの固定費**（1モデルあたり数十億〜数千億円規模と推計）
- **推論費＝使うほど増える変動費**（GPU時間と電力）
- 従来のソフトウェアと違い**複製コストがゼロではない**ため、粗利率が構造的に下がる
- 一方でトークン単価は激しく下落中（2026年9月に100万トークンあたり約0.97ドルと報じられる）
- 詳しくは [03_ビジネスモデルと経済性](03_ビジネスモデルと経済性.md)

## 6. 競争要因（KSF）と参入障壁

| 層             | KSF（成功の鍵）                                  | 参入障壁                                         |
| -------------- | ------------------------------------------------ | ------------------------------------------------ |
| ① 半導体       | 性能と開発ツールのエコシステム                   | 極めて高い（設計・製造・ソフト資産）             |
| ② クラウド／DC | 電力・用地・長期契約の確保、資金調達力           | 高い（兆円規模の投資と受電権）                   |
| ③ 基盤モデル   | 計算資源の確保、研究者、データ、安全性の作り込み | 高い。ただしオープンウェイトが障壁を下から削る   |
| ④ アプリ       | 業務知識、顧客データ、ワークフローへの食い込み   | 低い。**だから差別化はAIの外側で作る必要がある** |

> ④の参入障壁が低いことが最大の注意点。
> 「LLMを呼ぶだけ」のサービスはモデル側の機能追加で消える。
> 生き残るのは、**顧客の業務データと承認フローに埋め込まれたもの**。

## 7. 規制・法制度

| 地域 | 性格                                 | 主な枠組み                                                                                            |
| ---- | ------------------------------------ | ----------------------------------------------------------------------------------------------------- |
| EU   | リスクベースの厳格規制。域外適用あり | EU AI Act（2024年8月発効、2026年8月本格適用。高リスク規定は最長2027年12月まで延期の方針と報じられる） |
| 日本 | 推進が基本。罰則なし                 | AI推進法（2025年成立）、AI基本計画（2025年12月閣議決定、5年で1兆円超の国産AI投資方針と報じられる）    |
| 米国 | 連邦包括法なし。州法・分野別         | 大統領令＋州規制                                                                                      |
| 中国 | 事前審査・登録を伴う個別規制         | 生成AIサービス管理暫定弁法 など                                                                       |

日本の著作権法第30条の4により、情報解析目的の学習は一定条件で許容されるとされる一方、
**生成・利用段階は通常の著作権判断に服する**。詳細は [04_企業導入とAIエージェント・規制](04_企業導入とAIエージェント・規制.md)。
