# 蓄電池

- 大分類: 注目テーマ
- 状態: done
- 更新日: 2026-09-19

**一言でいうと**：蓄電池は「**電気を時間的にずらす装置**」を作る産業である。
電気は作った瞬間に使わないと消えてしまうという制約を外すのが役割で、
だからEV（走る時間にずらす）にも再生可能エネルギー（昼の電気を夕方にずらす）にも要る。

## 1. 業界の定義・範囲

**蓄電池産業＝繰り返し充放電できる電池（二次電池）と、それを組み込んだシステムを作る産業**。
使い切りの乾電池（一次電池）は含まない。

範囲は「セル」だけではなく、次の4層すべてに広がる。

```
[素材・資源]    リチウム、ニッケル、コバルト、黒鉛、銅・アルミ箔
    ↓
[電池材料]      正極材／負極材／電解液／セパレータ
    ↓
[セル・モジュール・パック]   電池メーカー（CATL、パナソニック等）
    ↓
[システム・用途]  EV、系統用蓄電池、家庭用、データセンターBBU
```

隣接業界との境界は次のとおり。

## 2. 市場規模と成長性

| 指標                     | 数値                             | 年・出典                                             |
| ------------------------ | -------------------------------- | ---------------------------------------------------- |
| リチウムイオン電池市場   | 約1,418億ドル                    | 2026年予測（IDTechExの推計）                         |
| 世界需要（車載＋定置用） | **約1,600〜約2,900GWh**          | 2030年予測。調査機関で幅が大きい（経産省資料で紹介） |
| 世界需要（長期）         | 5.456TWh                         | 2036年予測（IDTechExの推計）                         |
| 日本の国内製造基盤目標   | **150GWh/年**                    | 2030年〜2030年代半ば（経産省 蓄電池産業戦略）        |
| 定置用（ESS）の成長率    | 2026年に30%近く                  | 報道・調査会社ベース                                 |
| 車載電池の上位2社シェア  | CATL 39.2%＋BYD 16.4%＝**55.6%** | 2025年生産量ベースの集計                             |

**成長の確度は高いが、予測の幅が極端に大きい**のがこの産業の特徴。
2030年需要で1,600〜2,900GWhと**2倍近い開き**があるため、
「どのシナリオを前提に工場を建てるか」が各社の最大の経営判断になっている。

## 3. バリューチェーン（川上 → 川下）

```
鉱山・塩湖 ──▶ 精錬（化学品化） ──▶ 電池材料 ──▶ セル ──▶ パック ──▶ 用途
  豪州          中国が集中          正極/負極    中国・韓国  OEM/合弁   EV・系統・DC
  チリ                              電解液
  コンゴ                            セパレータ
  インドネシア                             ▲
                                     装置メーカー（塗工・捲回・化成）
       ▲
   リサイクル（ブラックマス）◀───── 使用済み電池・工程くず
```

**付加価値がどこに集まるか**：

| 工程             | 付加価値               | 理由                                                 |
| ---------------- | ---------------------- | ---------------------------------------------------- |
| 鉱山             | 市況次第で大きく振れる | 価格変動をまともに受ける                             |
| **精錬・材料**   | 安定して高い           | 参入に時間と環境許認可が要る。中国集中＝実質的な関所 |
| セル製造         | **薄い**               | 材料費が6〜7割。歩留まりが立つまでは赤字             |
| パック・システム | 中程度                 | 設計と制御（BMS）で差がつく                          |
| 系統用の運用     | 制度次第               | 電力市場の価格差と容量収入で決まる                   |

> ポイント：**セル製造は意外と儲からない**。材料費比率が高く、価格競争が激しい。
> 収益が集まるのは「上流の精錬・材料」と「下流の運用・制度収入」の両端である。

## 5. 収益モデル・コスト構造

### セルメーカー

```
セル製造コスト 100 の内訳（おおよその構図）
├─ 材料費  60〜70   ← 正極材が最大。化学の選択が効く
└─ 加工費  20〜30   ← 人件費・電力・減価償却・歩留まりロス
```

- **材料費の産業**（半導体＝装置償却の産業と対照的）。歩留まりが悪いと材料がそのまま捨てられる
- 立ち上げ期は歩留まりが低く、安定までに1〜2年。ここで赤字が続く
- 需要が計画を下回ると、稼働率割れ＋長いリードタイムの仕掛品が評価損になる

### 系統用蓄電池事業者

| 収益源                               | 中身                                                       |
| ------------------------------------ | ---------------------------------------------------------- |
| 卸電力市場の裁定                     | 安い時間に充電、高い時間に放電。**価格の変動幅**が利益の源 |
| 容量市場・長期脱炭素電源オークション | 「必要なとき供給できる能力」への固定収入。落札で原則20年   |
| 需給調整市場                         | 周波数調整などの調整力の対価                               |

**蓄電池は電気を作らないので、価格がフラットな市場では儲からない**。
再エネが増えて価格が乱高下するほど事業性が上がる、という関係になっている。

### 価格水準（2025年・BNEF調査）

| セグメント       | 価格                                       |
| ---------------- | ------------------------------------------ |
| パック世界平均   | 108ドル/kWh（前年比▲8%、過去最低）         |
| 定置用           | 70ドル/kWh（▲45%）＝**最も安いセグメント** |
| LFP／NMC         | 81／128ドル/kWh                            |
| 中国／北米／欧州 | 84ドル/kWh／＋44%／＋56%                   |
| 2026年予測       | 約105ドル/kWh（▲3%）                       |

## 6. 競争要因（KSF）と参入障壁

| KSF                                    | なぜ効くか                                                 |
| -------------------------------------- | ---------------------------------------------------------- |
| **量産歩留まりの立ち上げ速度**         | 材料費比率が高く、歩留まりがそのまま原価になる。暗黙知の塊 |
| **材料の長期調達力**                   | 精錬・材料が中国集中。契約と在庫の巧拙が原価と供給を左右   |
| **顧客との長期関係**                   | 車載は認証に年単位。いったん採用されると乗り換えにくい     |
| **資本力**                             | 1工場で数千億円。需要が下振れしても耐えられるか            |
| **安全・品質の実績**                   | 事故はリコールとブランド毀損に直結する                     |
| **（系統用）用地と系統接続枠、制度枠** | 電池は買えるが接続枠は買えない。実務上の最大のボトルネック |
| **トレーサビリティ対応**               | EU電池規則下では「証明できないと売れない」                 |

参入障壁は「技術」より**「量産ノウハウ」と「サプライチェーンの押さえ」**にある。
設備は買えるが、歩留まりと調達網は買えない。

## 7. 規制・法制度

| 制度                                 | 中身                                                                                                                                        |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------- |
| 日本：蓄電池産業戦略                 | 2030年〜2030年代半ばに**国内製造基盤150GWh/年**の目標。推進会議で継続議論                                                                   |
| 日本：経済安全保障推進法             | 蓄電池を**特定重要物資**に指定し、設備投資・材料生産を支援                                                                                  |
| 日本：**長期脱炭素電源オークション** | 2023年度創設。落札で原則20年の固定収入。系統用蓄電池導入の実質的な引き金                                                                    |
| 日本：GX関連予算・各種補助金         | 家庭用・産業用・系統用の導入支援。市場規模を左右する                                                                                        |
| EU：**EU電池規則**                   | デューデリジェンス（2025年8月〜）、ラベル義務（**2026年8月18日**全面施行）、バッテリーパスポート（2027年）、リサイクル材比率（2027年7月〜） |
| 米国：IRA等                          | 国内生産・調達要件に紐づく税額控除。北米投資の誘因（政権により運用が変動）                                                                  |
| 中国：輸出管理                       | 黒鉛（2023年）に続き、2025年10月に**電池・正極材・人造黒鉛負極材・製造設備／技術**を許可制へ                                                |
| 輸送・保安規制                       | リチウム電池の航空輸送規制、消防法上の設置基準など                                                                                          |

**この産業は制度で需要が作られ、制度で供給が止まる**。技術動向と同じ比重で政策を追う必要がある。

## 8. 最近のトピック

詳細は [05_直近トピック_2026](05_直近トピック_2026.md)。要点は以下の5行。

1. パック価格は2025年に**108ドル/kWh**と過去最低、2026年も約105ドル/kWhへ低下予測（BNEF）。
   **材料は上がったのに製品は下がった**という逆転が起きた。
2. 需要の主役が**車載から定置用・データセンター（BBU）へ一時シフト**。
   パナソニックは国内の車載セル設備をBBU向けに転換すると報じられる。
3. **ナトリウムイオン電池が量産段階へ**。CATLの「Naxtra」が2026年に出荷開始と報じられ、
   リチウム依存からの部分的脱却が現実味を帯びた。
4. 中国が2025年10月に**電池・正極材・人造黒鉛負極材と製造設備／技術**まで輸出許可制に拡大。
   競争軸が「作れるか」から「調達できるか」へ移った。
5. **全固体電池は「量産」の言葉に注意**。トヨタ・出光は2027〜2028年にEV年5〜6万台分規模、
   日産は2028年度の量産投入を目指すとされ、実体はパイロット〜初期量産の段階。
