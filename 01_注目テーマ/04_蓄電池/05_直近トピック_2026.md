# 蓄電池｜直近トピック（2026年9月時点）

報道・公表資料ベースの整理。数値は出典の年月とセットで読むこと。
確定事実と、計画・推計・報道を区別して書いている。一次情報での裏取りを前提とする。

**この1年の構図を1行で**：
EV向けの伸びが踊り場に入る一方、**定置用とデータセンター向けが主役に躍り出て**、
同時に**中国が電池材料そのものを輸出管理の対象**にしたことで、産業の重心が動いた年。

## 1. 電池価格：材料が上がっても製品は下がった

BloombergNEF（BNEF）の年次調査（2025年12月公表）によると、

| 指標                             | 2025年                               | 備考                                       |
| -------------------------------- | ------------------------------------ | ------------------------------------------ |
| リチウムイオンパック世界平均     | **108ドル/kWh**                      | 前年比▲8%、過去最低を更新                  |
| 定置用（蓄電システム）セグメント | **70ドル/kWh**                       | 前年比▲45%。**最も安いセグメントになった** |
| BEV（乗用EV）向けパック          | 99ドル/kWh                           | —                                          |
| LFPパック／NMCパック             | 81ドル/kWh ／ 128ドル/kWh            | 化学による差が約1.6倍                      |
| 中国／北米／欧州                 | 中国84ドル/kWh、北米＋44%、欧州＋56% | 地域差が縮まらない                         |
| **2026年予測**                   | **約105ドル/kWh**（▲3%）             | 中国の能力過剰と競争激化が要因             |

注目点は、**2025年はリチウム・コバルト価格が上昇したのにパック価格が下がった**こと。
中国の製造能力が需要を上回り、LFPシフトが進んだためとされる。
ただしBNEFは、安値で仕入れた在庫が払底すれば材料高がコストに効いてくると指摘している。

## 2. リチウム価格の反転と「タイトバランス」

- 2026年初のリチウム価格は、前年同期の**2倍超**まで戻した。ただし**2022年ピーク比では約7割安**の水準
- 電池グレード炭酸リチウムは、2026年を通じて**8万〜15万元/トン**の幅で変動するとの市場見方がある
- 調査会社BMIは2026年4月、供給逼迫を理由にリチウム価格見通しを上方修正したと報じられる
- 業界の一般的な見方は「**タイトバランス**」。需要（特に蓄電池）が伸びる一方、
  価格低迷期に設備投資が絞られたため、**供給の弾力性が落ちている**

```
リチウム価格のイメージ（2022→2026）

 高 │ ●2022 ピーク
    │  ╲
    │   ╲
    │    ╲___●2023-24 急落（増産＋需要鈍化）
    │        ╲_____●2025 底打ち
 安 │              ╱‾‾● 2026 反発（ピーク比▲約7割の水準）
    └──────────────────────────
```

> 教訓：**リチウム価格と電池価格は同じ方向に動くとは限らない**。
> 間に「セルメーカーの競争」「在庫」「化学の選択」が挟まっているため。

## 3. 定置用（ESS）が「今年の主役」に

- 2026年の蓄電システム（ESS）は成長率が**30%近く**に達するとされ、
  BESS（電池式蓄電システム）向けリチウム需要は**2026年に55%増**との見通しが報じられる
- リチウムイオン電池市場全体は2026年に**約1,418億ドル**規模、
  2036年には需要**5.456TWh**に達するとの予測（IDTechExの推計）
- 背景は2つ。**再エネの増加による時間シフト需要**と、**AIデータセンターの電力需要**

### データセンター向け（BBU）の台頭

- **BBU（Battery Backup Unit）**＝サーバーラックに組み込む小型バックアップ電源が急伸
- パナソニックは、北米の車載電池販売が計画を下回るなか、
  **国内工場の車載セル生産設備をBBU向けに転換**し、2026年度第1四半期から国産BBUの販売開始を計画と報じられる
- データセンター向けモジュールのメキシコ新工場建設も報じられている

- 一方、パナソニックHDは2026年3月期の純利益予想を下方修正（前期比29%減）し、

> 日系にとっての当面の解は「車載一本足からの脱却（＝定置用・DC向けへの振り向け）」になりつつある。

## 5. ナトリウムイオン電池が量産段階へ

リチウムを使わない**ナトリウムイオン電池**が、2026年に初めて商業量産の段階に入った。

- CATLは新型ナトリウムイオン電池 **「Naxtra」** を投入。
  エネルギー密度**175Wh/kg**、**−40℃**での動作を掲げ、LFPの代替可能性を示したとされる
- 2026年中にGWh規模の出荷、最初の顧客への出荷は**2026年9月から**と報じられる
- 乗用車・商用車・バッテリー交換網・電力インフラ向けの製品展開を予定し、
  **60GWh規模の供給契約**を獲得したと報じられている
- 日本では、国土交通省がナトリウムイオン電池の航空機持ち込みを制限する動きも報じられており、
  **新しい化学には新しい規制が追いかけてくる**ことの例になっている

意味するところ：ナトリウムは海水由来で資源制約がほぼない。
**リチウム依存からの部分的な脱却**が現実の選択肢になり始めた、というのが2026年の変化である。
ただし密度はLFPと同等〜やや下で、**当面の主戦場は定置用と低価格帯・寒冷地**とみられる。

## 6. 中国の輸出管理が電池そのものに及んだ

| 時期              | 内容                                                                                                                                                        |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2023年10月        | 一部の黒鉛および関連品目を輸出許可制に（同年12月1日施行）                                                                                                   |
| **2025年10月9日** | 商務部・税関総署が公告2025年第58号を発出。**リチウム電池・正極材・人造黒鉛負極材および関連設備・技術**を輸出許可対象に追加（2025年11月8日施行）と報じられる |

これまでは「原料（黒鉛・レアアース）」が対象だったが、
**完成品である電池と、製造設備・技術まで対象が広がった**点が転換点。
中国は天然黒鉛の精製で**9割超**のシェアを持つとされ、
EV用負極の大半が黒鉛であることを考えると、影響範囲は広い。

| トヨタ・出光興産  | 2027〜2028年に**EV年5〜6万台分**の規模で製造開始を計画。2030年までに年9GWhの生産能力を計画と報じられる |

> **普及の主役はあくまでLFPとその改良型**であり、全固体はプレミアム帯から入る、と読むのが妥当。

## 8. 日本：制度で作る需要と、150GWhの目標

- 経済産業省の**蓄電池産業戦略推進会議**は2026年に入っても継続して開催され、
  2026年4月17日、6月2日に資料が公表されている
- 目標として、**2030年から2030年代半ばに国内製造基盤150GWh/年**の確立が掲げられている
- 2030年時点の世界需要（車載＋定置用）は調査機関により**約1,600〜約2,900GWh**と、予測の幅が大きい
- **長期脱炭素電源オークション**は3回の入札を終え、脱炭素電源が計1,330万kW、LNG火力が計1,010万kW落札。
  次回は2027年1月予定
  - 初回は蓄電池が**1,092MW**落札（応札量の約4分の1）
  - 2024年度分は3〜6時間が96.1万kW、6時間以上が76.9万kW
  - 蓄電池への応札集中を受け、**募集上限は1GW→0.8GW**、リチウムイオンは0.4GWへ縮小する方針と報じられる
- 自動車メーカーがエネルギーマネジメント領域へ進出し、
  トヨタ・ホンダ等が**自社EV＋蓄電池＋太陽光**のエコシステム構築を模索していると報じられている

| 時期              | 内容                                                                           |

| 2025年8月18日     | サプライチェーン・デューデリジェンス義務が開始                                 |

**「どこから来た材料か」を証明できない電池はEUで売れなくなる**という方向が、
2026年に実務レベルで効き始めた。トレーサビリティ対応が非関税障壁として機能する構図。

## 10. 全体の構図（まとめ）

1. **価格は下がり続けているが、理由が変わった**。以前は材料安、いまは中国の供給過剰とLFPシフト。
   2026年は材料高がコストに乗ってくるかが焦点。
2. **需要の主役が車載から定置用へ一時的にシフト**した。EVは踊り場、ESSとデータセンターが伸びる。
   日系メーカーはここへ生産設備を振り向けて凌いでいる。
3. **競争の重心は「作れるか」から「調達できるか」へ**移った。中国の輸出管理とEU電池規則が、
   技術ではなく**サプライチェーンの証明能力**を競争軸に変えつつある。
4. **化学の分岐が進んだ**。LFP／LMFP／ナトリウムイオン／全固体が用途ごとに棲み分け始め、
   「次世代電池が全部を置き換える」という図式ではなくなった。
5. 日本の系統用蓄電池は**制度枠（長期脱炭素電源オークション）が実質的な上限**。
   募集上限の縮小がそのまま導入ペースに効く。

## 用語メモ

- **BNEF**：BloombergNEF。エネルギー分野の調査部門。電池パック価格の年次調査が業界標準
- **タイトバランス**：需給が均衡ぎりぎりで、少しの変動で価格が動きやすい状態
- **BESS**：Battery Energy Storage System。電池式の蓄電システム
- **BBU**：Battery Backup Unit。サーバーラック搭載の小型バックアップ電源
- **Naxtra**：CATLのナトリウムイオン電池ブランド。175Wh/kg、−40℃動作を掲げる
- **公告2025年第58号**：中国がリチウム電池・正極材・人造黒鉛負極材等を輸出許可制にした通達
- **バッテリーパスポート**：EU電池規則で求められる、電池個体の電子的な履歴情報
- **長期脱炭素電源オークション**：脱炭素電源に長期固定収入を与える日本の制度。2023年度創設
