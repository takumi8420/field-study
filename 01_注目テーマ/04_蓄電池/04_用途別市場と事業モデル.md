# 蓄電池｜用途別市場と事業モデル

**このノートで分かること**：蓄電池が「誰に、何のために」売れているのか。
車載・定置用・民生でビジネスの性格がまったく違うこと、そして
定置用蓄電池が「機器の販売」ではなく「**電力市場で稼ぐ資産**」になっている理由。

まず結論を3行で。

> 車載は**自動車部品**のビジネス（長期契約・品質保証・量産能力が勝負）。
> 定置用は**発電所に近いインフラ投資**のビジネス（電力価格差と制度収入で回収する）。
> 民生は**成熟した部品**のビジネスだが、2020年代半ばからデータセンター向けという新市場が立った。

## 1. 用途の3分類

| 区分               | 何に載るか                                  | 求められる性能                               | ビジネスの性格                   |
| ------------------ | ------------------------------------------- | -------------------------------------------- | -------------------------------- |
| **車載（xEV）**    | EV、PHEV、HV、商用車、バス                  | エネルギー密度、急速充電、安全、10年級の耐久 | 自動車部品。契約は数年〜10年単位 |
| **定置用（ESS）**  | 系統用、産業用、家庭用、データセンター      | 毎日充放電する寿命、コスト、設置面積         | インフラ投資／制度ビジネス       |
| **民生・産業機器** | スマホ、PC、電動工具、掃除機、ドローン、UPS | 小型軽量、形状自由度、品質                   | 成熟した部品ビジネス             |

需要量としては**車載が圧倒的に最大**で、次いで定置用が急成長中。
2030年時点の世界需要（車載＋定置用）の予測は調査機関により**約1,600〜約2,900GWh**と幅があり、
経済産業省の資料でもこの幅が紹介されている（2026年時点）。
**「予測の幅そのものが大きい」ことが、この産業の投資判断を難しくしている**。

```
世界の電池需要（イメージ／構成比）

  車載        ████████████████████████████████  最大。EV販売台数に連動
  定置用      ██████████                        成長率が最も高い（再エネとDC）
  民生・機器  ███                               成熟。数量は安定
```

## 2. 車載電池のビジネス

### 誰が誰に売るか

```
セルメーカー ──▶ モジュール/パック ──▶ 自動車メーカー ──▶ 消費者
  CATL等          セル側 or OEM側        トヨタ、VW等
     │
     └─ OEMとの合弁（JV）／内製化が進行中
```

車載電池の調達には3つの形がある。

| 形態           | 中身                                | 例                                   |
| -------------- | ----------------------------------- | ------------------------------------ |
| **外部調達**   | セルメーカーから買う                | 多くのOEMの基本形                    |
| **合弁（JV）** | OEMと電池メーカーが共同で工場を持つ | 欧米で一般的。投資と需要リスクを分担 |
| **内製**       | OEM自身が作る                       | BYD（元が電池会社）、テスラの一部    |

### 経済的な特徴

- **電池はEV原価の3〜4割**を占めるとされる最大部品。ここが下がらないとEVは安くならない
- 契約は**数年先の数量コミット**を伴う。だからEV販売が計画を下回ると、
  電池メーカーの工場が即座に稼働率割れを起こす
- 品質保証が重い。**8年/16万km級の保証**が一般的で、不具合は大規模リコールに直結する
- 認証・監査に時間がかかるため、**いったん採用されると乗り換えが起きにくい**（＝参入障壁）

> ポイント：車載電池は「作れば売れる」商品ではなく、**特定の車種の特定の年式に紐づいた受注生産**。
> 半導体でいえば汎用メモリではなくカスタムASICに近い。だから需要変動の直撃を受ける。

→ [EV・電動化](../03_EV・電動化/README.md)、[自動車（完成車）](../../02_自動車・機械/01_自動車（完成車）/README.md)

## 3. 定置用蓄電池：3つの層

定置用（ESS：Energy Storage System）は、設置される場所で性格が分かれる。

| 層                     | 規模の目安     | 誰が持つか                             | 目的                                          |
| ---------------------- | -------------- | -------------------------------------- | --------------------------------------------- |
| **系統用（グリッド）** | 数MWh〜数百MWh | 発電事業者、専業事業者、商社、ファンド | 電力市場で売買して稼ぐ／系統の安定化          |
| **産業用・業務用**     | 数十kWh〜数MWh | 工場、商業施設、データセンター         | ピークカット、BCP（停電対策）、自家消費最大化 |
| **家庭用**             | 5〜15kWh程度   | 一般家庭                               | 太陽光の自家消費、停電対策、電気代削減        |

### 3-1. 系統用蓄電池は「発電所」として扱われる

太陽光が増えると、昼間に電気が余り、夕方に足りなくなる。
この**時間のズレを埋める装置**が系統用蓄電池である。

```
発電量
  │        ☀ 太陽光（昼に大量）
  │       ╱‾‾‾╲
  │      ╱     ╲            ← 昼：余る → 蓄電池が充電（安く買う）
  │─────╱───────╲──── 需要
  │              ╲___       ← 夕方：足りない → 蓄電池が放電（高く売る）
  └──────────────────── 時刻
       6   12   18   24
```

**収益源は1つではなく、複数市場の組み合わせ**になる。

| 収益源                                 | 中身                                                         |
| -------------------------------------- | ------------------------------------------------------------ |
| **卸電力市場の裁定（アービトラージ）** | 安い時間に買い、高い時間に売る。値差が利益                   |
| **容量市場**                           | 「必要なときに発電できる能力」に対して支払われる固定収入     |
| **需給調整市場**                       | 周波数調整など、秒〜分単位の調整力を提供して得る対価         |
| **出力制御の回避**                     | 再エネの捨て電（カーテイルメント）を減らし、売電機会を増やす |

> ポイント：**蓄電池は電気を作らない。時間をずらすだけ**。
> したがって収益は「電力価格の**変動幅**」に比例する。価格が一日中フラットな市場では儲からない。
> 再エネが増えて価格変動が大きくなるほど、蓄電池の事業性が上がるという関係になっている。

### 3-2. 日本では制度が事業性を作っている

日本の系統用蓄電池は、市場収入だけでは投資回収が読みにくいため、
**長期脱炭素電源オークション**という制度が実質的な引き金になっている。

- 2023年度に創設された、容量市場の一部。**落札すると原則20年間の固定収入**が得られる
- 初回オークションでは、応札量の約4分の1にあたる**計1,092MWの蓄電池が落札**された
- 2024年度分では、運転継続時間3時間以上6時間未満が96.1万kW、6時間以上が76.9万kW落札
- 蓄電池の応札が想定を超えたため、**募集上限は初回・第2回の1GWから0.8GWへ縮小**、
  うちリチウムイオン電池は0.4GWとされる（2026年時点で報じられている方針）
- これまで3回の入札で、脱炭素電源が計1,330万kW、LNG火力が計1,010万kW落札。次回は2027年1月の予定

> 意味：**「儲かるから建つ」のではなく「制度枠を取れたから建つ」**のが現在の日本の系統用蓄電池。
> 枠が縮めば計画も縮む。ニュースを読むときは、募集上限と落札結果をセットで見る必要がある。

### 3-3. 家庭用蓄電池

- 容量は5〜15kWh程度、価格は工事費込みで**100万〜200万円台**が一般的な相場とされる
- 導入動機は3つ：①FIT買取期間終了後（卒FIT）の自家消費、②電気代高騰対策、③停電対策
- 補助金（国・自治体）の有無が販売台数を大きく動かす。**制度依存度が高い市場**
- 販売は住宅設備の流通に乗る。訪問販売型が多く、**価格の不透明さが業界課題**として指摘される

## 4. データセンター向けという新市場

2020年代半ばから、AI向けデータセンターの電力需要増を背景に、
**BBU（Battery Backup Unit）**＝サーバーラックに組み込む小型バックアップ電源の需要が急伸した。

- 従来の大型UPS（無停電電源装置）を、ラック単位のリチウムイオン電池で置き換える発想
- パナソニックは、車載電池需要の減速を受けて**国内工場の車載セル生産設備をBBU向けに転換**し、
  2026年度第1四半期から国産BBUの販売を始める計画と報じられている
- メキシコにデータセンター向けモジュールの新工場を建設する計画も報じられる

> ここが2026年の重要な構図。**車載の踊り場と、定置用・データセンターの成長が同時に起きている**。
> 電池メーカーにとっては「同じセルをどの市場に振り向けるか」という転換の巧拙が業績を分ける。

## 5. 価格：どこまで下がったか

| 年         | 指標                    | 数値                                     | 出典                 |
| ---------- | ----------------------- | ---------------------------------------- | -------------------- |
| 2024年     | LIBパック世界平均       | 約117ドル/kWh                            | BNEF調査（前年調査） |
| **2025年** | LIBパック世界平均       | **108ドル/kWh**（前年比▲8%、過去最低）   | BNEF調査             |
| 2025年     | 定置用セグメント        | **70ドル/kWh**（前年比▲45%）             | BNEF調査             |
| 2025年     | BEV（乗用EV）向けパック | 99ドル/kWh                               | BNEF調査             |
| 2025年     | LFPパック／NMCパック    | 81ドル/kWh ／ 128ドル/kWh                | BNEF調査             |
| 2025年     | 中国／北米／欧州        | 中国84ドル/kWh、北米は＋44%、欧州は＋56% | BNEF調査             |
| 2026年     | パック平均（予測）      | **約105ドル/kWh**（前年比▲3%）           | BNEF予測             |

読み取れることは3つ。

1. **定置用が最も安いセグメントになった**（2025年に70ドル/kWh）。LFPの大量生産と、
   重量・体積制約が緩いことが効いている
2. **地域差が大きい**。北米・欧州のパックは中国より4〜6割高く、
   これは関税・人件費・立ち上げ途上の歩留まりを反映している
3. 2025年は**材料価格が上がったのに製品価格は下がった**。中国の能力過剰と競争激化が主因とされる

## 6. 事業モデルの比較

| 観点       | 車載電池                    | 系統用蓄電池                   | 家庭用蓄電池               |
| ---------- | --------------------------- | ------------------------------ | -------------------------- |
| 顧客       | 自動車メーカー              | 電力市場／事業者               | 個人                       |
| 売り物     | セル・パック（モノ）        | 時間をずらす機能（サービス）   | システム＋工事             |
| 収益       | 単価×数量                   | 市場収入＋容量収入             | 販売粗利＋施工             |
| 主なリスク | EV販売計画の下振れ、稼働率  | 電力価格の変動幅、制度変更     | 補助金の有無、販売チャネル |
| 投資回収   | 工場の稼働率次第            | 10〜20年                       | 10年前後（電気料金次第）   |
| 勝ち筋     | 量産能力と品質、OEMとの関係 | 用地・系統接続枠・制度枠の確保 | 販売網とアフター           |

> 特に系統用で見落とされがちなのが、**系統接続枠と用地**。
> 電池そのものは買えば手に入るが、「ここに繋いでよい」という権利は簡単には手に入らない。
> **ボトルネックは電池ではなく接続枠**、という状況が各国で起きている。

## 7. この市場を見るときの指標

- 世界のEV販売台数と電池搭載量（GWh）：車載の需要そのもの
- **炭酸リチウム価格**：材料コストの体温計。ただし製品価格とは連動しない年もある
- BNEF等の**パック価格調査（年次）**：コスト低減の進み具合
- 日本：**長期脱炭素電源オークションの募集上限と落札量**、系統用蓄電池の運開容量
- 各社の**稼働率**と在庫：需要ギャップが最初に出る場所
- 経済産業省 蓄電池産業戦略推進会議の資料：国内政策と目標の最新値

## 用語メモ

- **xEV**：EV・PHEV・HVなど電動車の総称
- **ESS**：定置用蓄電システム。Energy Storage System
- **系統用蓄電池**：送配電網に直接つないで電力市場で運用する大型蓄電池
- **アービトラージ**：価格差を利用した売買。蓄電池では安い時間に充電し高い時間に放電すること
- **容量市場**：「必要なときに供給できる能力」に対価を払う市場
- **需給調整市場**：周波数維持などの調整力を売買する市場
- **長期脱炭素電源オークション**：脱炭素電源に長期の固定収入を与える日本の制度。2023年度創設
- **出力制御（カーテイルメント）**：発電し過ぎたときに再エネの出力を絞ること
- **卒FIT**：固定価格買取制度の買取期間が終了した太陽光。自家消費の必要が生まれる
- **BBU**：Battery Backup Unit。サーバーラック搭載の小型バックアップ電源
- **UPS**：無停電電源装置。停電時に機器へ電力を供給する
- **系統接続枠**：送電網に接続する権利。実務上の最大のボトルネック
- **ピークカット**：需要のピークを蓄電池で削り、契約電力・料金を下げること
