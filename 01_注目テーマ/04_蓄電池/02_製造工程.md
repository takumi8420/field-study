# 蓄電池｜製造工程（電極製造 → 組立 → 化成・エージング）

**このノートで分かること**：リチウムイオン電池がどうやって作られるか、
なぜ工場が数千億円規模になるのか、そして「歩留まり」がこの産業の利益を決める理由。

まず結論を2行で。

> 電池工場は「**金属箔に材料を塗って、乾かして、切って、巻いて、液を入れて、初回充電する**」という
> 連続ラインである。半導体と違い工程数は少ないが、**塗りムラと異物混入が即不良**になるため、
> 立ち上げに時間がかかり、**歩留まりが利益を丸ごと左右する**。

## 1. 全体の流れ

```
【1. 電極製造（前工程）】
  正極材/負極材 ─▶ 混練 ─▶ 塗工 ─▶ 乾燥 ─▶ プレス ─▶ スリット ─▶ 真空乾燥
   (粉＋バインダ    (スラリー   (箔に塗る) (溶媒を飛ばす)(密度を上げる)(幅に切る) (水分除去)
    ＋溶媒)          を作る)
                                   │
                                   ▼
【2. 組立（中工程）】
  電極を切り出す ─▶ 積層 or 捲回 ─▶ 溶接（タブ付け）─▶ 缶/パウチに封入
                                            ─▶ 注液（電解液を入れる）─▶ 封口
                                   │
                                   ▼
【3. 化成・検査（後工程）】
  初回充電（化成）─▶ ガス抜き ─▶ エージング（数日〜数週間の放置）─▶ 選別・出荷
                                   │
                                   ▼
【4. モジュール・パック組立】
  セルを束ねる ─▶ BMS・冷却・筐体を付ける ─▶ 車やコンテナに載せる
```

工程の性格が段階ごとに大きく違う。ここが理解の勘所。

| 段階             | 性格                             | 律速になるもの           | 所要時間の目安     |
| ---------------- | -------------------------------- | ------------------------ | ------------------ |
| 電極製造         | **化学＋塗工**。連続ライン       | 塗工速度と乾燥炉の長さ   | 数時間（連続）     |
| 組立             | **精密機械**。高速な巻き・積み   | 装置のタクトと溶接品質   | 数秒〜数十秒／セル |
| 化成・エージング | **時間を買う工程**。ひたすら待つ | 充放電装置の台数と置き場 | **数日〜3週間**    |
| パック組立       | **組立・配線**。人と自動化の混在 | 設計・検査               | 数十分／パック     |

> ポイント：**エージングだけで数週間かかる**のが電池工場の最大の特徴。
> 仕掛品（作りかけの在庫）が膨大になり、「作り始めてから売上になるまで」が長い。
> 需要が急に落ちると、この仕掛品がまるごと評価損になる。

## 2. 電極製造：塗って乾かす工程が品質を決める

### 2-1. 混練（スラリー作製）

正極材・導電助剤・バインダ（つなぎ）を溶媒に分散させ、**スラリー**（どろっとした塗料）にする。

- 正極側の溶媒は伝統的に**NMP**という有機溶媒。回収設備が要る（＝コストと環境負荷）
- 負極側は**水系**が主流で扱いやすい
- 分散が不均一だと、そのまま塗りムラ＝容量ばらつきになる。地味だが決定的な工程

### 2-2. 塗工（コーティング）

アルミ箔（正極）・銅箔（負極）に、スラリーを**両面に均一な厚みで**塗る。
厚みの狙いは数十マイクロメートル。数%ずれれば不良になる世界。

- 装置の代表：東レエンジニアリング、ヒラノテクシード、東芝三菱電機産業システム、中国のWuxi Lead など
- **塗工速度がラインの生産能力そのもの**。「毎分◯m」がそのままGWhに換算される

### 2-3. 乾燥

溶媒を飛ばす。ここが**エネルギー消費と設備長の主役**で、
乾燥炉が数十メートルに及ぶため、工場が横に長くなる。

> 近年注目されているのが**ドライ電極（乾式）プロセス**。溶媒を使わず粉のまま成膜する方式で、
> 乾燥炉と溶媒回収設備をまるごと不要にできる可能性がある。実用化できればコストと投資額を
> 大きく下げられるため、各社が開発中。ただし量産実績はまだ限定的。

### 2-4. プレス（ロールプレス）と裁断

ローラーで押し固めて**電極密度**を上げ、必要な幅にスリットする。
密度を上げるほど容量は増えるが、上げすぎると電解液が染み込まず出力が落ちる。**トレードオフの調整点**。

## 3. 組立：巻くか、積むか

| 方式                       | やり方                                     | 向く形状           | 特徴                               |
| -------------------------- | ------------------------------------------ | ------------------ | ---------------------------------- |
| **捲回（ワインディング）** | 正極・セパレータ・負極を重ねてぐるぐる巻く | 円筒形、角形       | 速い。量産性が高い                 |
| **積層（スタッキング）**   | 短冊状に切って交互に積む                   | ラミネート型、角形 | 内部抵抗が低く高出力。タクトが遅い |

いずれも共通する敵は**異物混入**。金属片が1個でも混ざると、そのセルは内部短絡＝発火リスクになる。
そのため工場はクリーンルームであると同時に、**ドライルーム**（露点−40℃級の超低湿度）である必要がある。
リチウム化合物と電解液は水分と反応してしまうためで、**この除湿設備が工場コストの大きな部分を占める**。

### 注液と封口

真空環境で電解液を注入し、密封する。注液量が少なければ容量不足、多ければ膨れる。
ここも「見えないのに効く」工程の代表格。

## 4. 化成とエージング：この産業特有の「待ち時間」

**化成（フォーメーション）＝作ったセルを初めて充放電する工程**。
このとき負極の表面に **SEI（固体電解質界面）被膜** という薄い膜ができる。
SEIは、電解液と負極がそれ以上反応しないよう仕切る保護膜で、
**この膜の質が電池の寿命をほぼ決めてしまう**。だからゆっくり丁寧に充電する。

続く**エージング**は、温度をかけて一定期間放置し、電圧降下の大きいセル＝
微小な内部短絡を抱えたセルをあぶり出す工程。**不良品をここで落とす**ための時間である。

```
化成（数時間〜数日）──▶ ガス抜き ──▶ 高温エージング ──▶ 常温エージング（数日〜数週間）
   SEI被膜を形成         副生ガス除去      不良の顕在化        電圧の安定を確認
                                                │
                                          電圧降下が大きい ─▶ 不良として除外
```

経済的な意味は3つ。

1. **充放電装置（フォーメーション設備）が大量に要る**。設備投資の主要項目のひとつ
2. **広大な置き場（エージング棟）が要る**。工場面積が膨らむ
3. **リードタイムが長い**＝運転資金が寝る。需要変動に弱い構造の原因

## 5. 設備投資と工場の経済性

| 項目                 | 目安                                                                   | 備考                                 |
| -------------------- | ---------------------------------------------------------------------- | ------------------------------------ |
| 工場規模の単位       | **GWh/年**                                                             | 1GWh＝60kWhのEV約1.7万台分           |
| 建設費               | おおむね **1GWhあたり数十億〜100億円規模**（報道・各社発表からの推計） | 立地・自動化度・化学で大きく変動     |
| 代表的な新工場       | 20〜50GWh/年                                                           | 建設費は数千億円規模になる           |
| 立ち上げ期間         | 着工から量産まで **2〜3年**、歩留まり安定までさらに1年以上             | ここが計画のリスク                   |
| コストに占める材料費 | **6〜7割**（一般的な整理）                                             | 正極材が最大。だから化学の選択が効く |

半導体との違いを一言でいうと、**半導体は装置償却の産業、電池は材料費の産業**。
ただし立ち上げ局面は例外で、歩留まりが低いうちは償却と廃棄ロスが重くのしかかる。

### コスト構造のイメージ

```
セル製造コスト 100 のうち（おおよその一般的な内訳）
├─ 正極材                  約 35〜45
├─ 負極材（黒鉛）           約 8〜12
├─ 電解液                   約 5〜8
├─ セパレータ               約 5〜8
├─ 箔・その他部材           約 5〜10
└─ 加工費（人件費・電力・償却・歩留まりロス） 約 20〜30
```

※ 化学・時期・地域で大きく変わるため、あくまで構図を掴むための概算。
正確な数値は各社IRや調査会社レポートで確認すること。

## 6. 歩留まりの算数

**歩留まり（Yield）＝ 良品セル数 ÷ 投入セル数**。

電池は材料費比率が高いので、歩留まりが悪いと**材料費がそのまま捨てられる**。
半導体のように「小さいチップなら被害が小さい」という逃げ道がない。

- 新工場の立ち上げ直後は歩留まりが低く、**数十%台からスタートすることも珍しくない**とされる
- 量産が安定すると90%台後半まで上がる
- 歩留まり80% → 95% の改善は、単位あたり材料費を約16%下げるのと同じ効果
  （1÷0.80＝1.25、1÷0.95＝1.053。1.25→1.053 は約16%減）

> ポイント：**「工場を建てた＝供給できる」ではない**。歩留まりが立つまでの1〜2年が本当の勝負で、
> ここで躓いた新規参入は世界中にある。量産ノウハウ（暗黙知）が参入障壁そのもの。

| 混練・塗工・乾燥 | 東レエンジニアリング、ヒラノテクシード、浅田鉄工、Wuxi Lead（中国）、Yinghe（中国） |
| プレス・スリット | 日立造船（現カナデビア系）、西村製作所、中国勢                                      |
| 捲回・積層・組立 | CKD、皆藤製作所、Wuxi Lead、Hangke（中国）                                          |
| 注液・封口       | 中国勢が強い                                                                        |
| 化成・検査       | 東洋システム、日置電機（計測）、Hangke（中国）                                      |

装置は日本・韓国勢に技術的な蓄積がある一方、**中国装置メーカーが価格と納期で急速にシェアを取った**。
中国の電池コスト優位は、材料だけでなく**装置の内製化・低価格化**にも支えられている。

## 8. 製造から見たLFPと三元系の違い

| 観点           | LFP                                          | 三元系                             |
| -------------- | -------------------------------------------- | ---------------------------------- |
| スラリーの扱い | 導電性が低く導電助剤が多め。分散の難度が高い | 比較的扱いやすい                   |
| 乾燥・水分管理 | 吸湿しやすく水分管理が重要                   | 同様に厳格                         |
| 化成の時間     | 長めになりやすい                             | 相対的に短い                       |
| 安全設計の負担 | 軽い（熱暴走しにくい）                       | 重い（冷却・断熱・検査が厚くなる） |
| 材料費         | 低い                                         | 高い                               |

同じラインで作り分けられるわけではなく、**化学が変われば工程条件も装置も変わる**。
「LFPに切り替える」という発表が、実際には数年の設備改造を伴うのはこのため。

## 用語メモ

- **スラリー**：電極材料を溶媒に分散させた塗料状の液体
- **バインダ**：材料を箔に接着させるつなぎ。PVDF（正極）、SBR/CMC（負極）など
- **導電助剤**：電気を通りやすくする添加材。カーボンブラックなど
- **NMP**：正極スラリーで使われる有機溶媒。回収設備が必要
- **塗工（コーティング）**：箔にスラリーを塗る工程。ラインの生産能力を決める
- **ドライ電極**：溶媒を使わずに成膜する次世代プロセス。乾燥炉が不要になる
- **捲回／積層**：電極を巻く方式／短冊状に積む方式
- **注液**：電解液をセルに入れる工程。真空下で行う
- **化成（フォーメーション）**：初回充放電。SEI被膜を作る工程
- **SEI被膜**：負極表面にできる保護膜。寿命を左右する
- **エージング**：一定期間放置して不良を顕在化させる工程
- **ドライルーム**：露点−40℃級の超低湿度室。電池工場に必須
- **歩留まり**：良品率。材料費比率が高い電池では利益に直結する
- **GWh/年**：電池工場の能力を表す単位。1GWh＝100万kWh
