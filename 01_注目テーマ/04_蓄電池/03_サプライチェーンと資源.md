# 蓄電池｜サプライチェーンと資源

**このノートで分かること**：電池の原料がどこの国から来て、どこで加工され、誰が組み立てるのか。
なぜ「中国依存」という言葉が繰り返し出てくるのか。そしてリサイクルが制度化されつつある理由。

まず結論を3行で。

> 電池のサプライチェーンの本当のボトルネックは**鉱山ではなく精錬・材料加工**にある。
> リチウムやコバルトの産地はバラけているのに、**それを電池用の材料に変える工程は中国に集中**している。
> だから各国の政策は「鉱山を取りに行く」より「精錬と材料を自国／同盟国に戻す」方向に向かう。

## 1. 川上から川下までの全体像

```
【資源】        【精錬・化学品】      【電池材料】        【セル】        【パック・搭載】
鉱山・塩湖  ──▶ 炭酸/水酸化リチウム ──▶ 正極材      ──▶ セルメーカー ──▶ 自動車/系統/機器
  豪州          中国・チリ            中国・韓国・日本    中国・韓国・日本
  チリ                                                  ・欧米新興
  コンゴ    ──▶ 硫酸コバルト     ──▶ 負極材(黒鉛)
  インドネシア ─▶ 硫酸ニッケル/MHP   中国がほぼ独占
  中国      ──▶ 球状化黒鉛       ──▶ 電解液・セパレータ
                                        中国・日本
       ▲                                        ▲
   リサイクル（ブラックマス）◀────── 使用済み電池・工程くず ◀───┘
```

**チョークポイント（詰まりやすい箇所）は左から2番目と3番目**、つまり精錬と材料工程にある。

## 2. 4つの主要資源

| 資源                     | 何に使うか                       | 主な産地（2020年代半ば）                                                     | 精錬・加工の集中先                   |
| ------------------------ | -------------------------------- | ---------------------------------------------------------------------------- | ------------------------------------ |
| **リチウム**             | 正極材と電解液の塩。全化学で必須 | 豪州（硬岩スポジュメン）、チリ・アルゼンチン（塩湖かん水）、中国、ジンバブエ | 中国が化学品転換の過半を握るとされる |
| **コバルト**             | 三元系正極の安定材               | **コンゴ民主共和国が世界産出の7割前後**、インドネシアが急伸                  | 中国が精錬の大半                     |
| **ニッケル**             | 三元系正極の主役。密度を上げる   | インドネシアが圧倒的首位、フィリピン、ロシア                                 | インドネシア（中国資本主導）＋中国   |
| **黒鉛（グラファイト）** | 負極材。天然と人造がある         | 天然は中国、モザンビーク、マダガスカル                                       | **中国が精製で9割超**との指摘がある  |

> ポイント：**リチウムは「偏在」より「精錬集中」が問題**。原料は豪州・南米に十分あるが、
> それを電池グレードの炭酸リチウム／水酸化リチウムにする工程が中国に寄っている。
> 一方**コバルトは産地そのものが偏在**（コンゴ）で、性格が違う。

### リチウムの2つの採り方

| 方式                   | 原料       | 場所                         | 特徴                                             |
| ---------------------- | ---------- | ---------------------------- | ------------------------------------------------ |
| 硬岩（スポジュメン）   | 鉱石       | 豪州、ジンバブエ、中国       | 立ち上げが速い。コストは塩湖より高い傾向         |
| 塩湖かん水（ブライン） | 地下の塩水 | チリ、アルゼンチン、ボリビア | 蒸発池で濃縮するため**1〜2年かかる**。安いが遅い |
| DLE（直接抽出）        | かん水     | 開発中                       | 蒸発池を使わず短時間で抽出。商業化が焦点         |

供給が急には増えない理由がここにある。塩湖は時間がかかり、新規鉱山は探査から生産まで5〜10年。
**需要が跳ねると価格が急騰し、増産が追いついた頃には価格が崩れる**という循環を繰り返してきた。

### 価格サイクル（2022〜2026年）

- 2022年：EV需要急拡大でリチウム価格が史上最高値圏へ
- 2023〜2024年：増産と需要鈍化で急落。**ピーク比で数分の1**まで下落
- 2025年：底打ち。BNEF調査ではパック価格が**平均108ドル/kWh**と過去最低を更新（前年比8%減）
- 2026年初：リチウム価格は前年同期の2倍超まで戻すも、**2022年ピーク比では約7割安**の水準と報じられる
- 2026年：BNEFはパック価格がさらに3%下がり**約105ドル/kWh**になると予測

> 材料が上がってもパック価格が下がったのは、**LFPシフト・中国の過剰能力・競争激化**が効いたため。
> 「材料価格＝電池価格」ではない、というのがこの数年の教訓。

## 3. なぜ中国に集中したのか

理由は単一ではなく、3つが重なった。

| 要因                                 | 中身                                                                      |
| ------------------------------------ | ------------------------------------------------------------------------- |
| 政策の連続性                         | 2010年代から新エネ車（NEV）補助金と国内電池優遇を長期継続し、需要を作った |
| 精錬という「嫌われ工程」を引き受けた | 精錬は環境負荷・電力消費が大きく、先進国では許認可が通りにくい            |
| 材料・装置・セルの**垂直統合**       | 正極材から装置まで国内で完結し、改善サイクルが速い                        |

結果として、**セル生産だけを他国に移しても、材料と精錬が中国依存のまま残る**という構造ができた。
欧米・日本の政策が「材料・精錬の国内回帰」を狙うのは、この一段上流を押さえないと意味がないため。

## 4. 輸出管理という新しい変数

資源は「量がない」だけでなく「**出してもらえない**」リスクを持つようになった。

| 時期       | 出来事                                                                                                                                    |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| 2023年10月 | 中国商務部が一部の黒鉛および関連品目を輸出許可制に（同年12月1日施行）                                                                     |
| 2025年10月 | 中国がリチウム電池・正極材・**人造黒鉛負極材**および関連設備・技術を輸出許可対象に追加（公告2025年第58号、2025年11月8日施行）と報じられる |
| 継続       | レアアース・ガリウム等を含む重要鉱物の輸出管理が段階的に拡大                                                                              |

「許可制」は禁輸ではない。ただし**許可が出るまでの時間が読めない**ことが、
調達側にとっては実質的な供給リスクになる。在庫積み増し、代替調達、長期契約への回帰が進んだ。

## 6. リサイクル：制度が需要を作る段階に入った

電池リサイクルは「環境のため」から「**資源調達手段かつ法的義務**」へ性格が変わりつつある。

### 工程の流れ

```
使用済み電池・工程くず ─▶ 放電・解体 ─▶ 破砕・選別 ─▶ ブラックマス
                                                         │
                     ┌───────────────────────────────────┤
                     ▼                                   ▼
             【乾式（熱処理）】                    【湿式（酸で溶かす）】
        設備が単純／リチウムを回収しにくい    回収率が高い／薬品処理が必要
                     └──────────▶ Li / Ni / Co / Mn を再び正極材へ
```

**ブラックマス**＝正極材と負極材の粉が混ざった黒い粉。これが事実上の「都市鉱山の鉱石」で、
国際的に売買されるようになった。有害物・越境移動規制の対象になりやすい点も論点。

### EU電池規則（Battery Regulation）が効いている

EUで電池を売るなら守らねばならないルールが段階的に発効している（いずれも報道・解説ベースの整理）。

| 時期              | 内容                                                                                         |
| ----------------- | -------------------------------------------------------------------------------------------- |
| 2025年8月18日     | サプライチェーン・**デューデリジェンス**義務開始（コバルト等の責任ある調達の体制構築と報告） |
| **2026年8月18日** | 電池の**ラベル表示義務**が全面施行。対象電池に所定項目の表示が必要                           |
| 2027年            | **バッテリーパスポート**（電池ごとの電子的な履歴情報）の運用開始が予定される                 |
| 2027年7月1日〜    | 大型電池で**コバルト・鉛・リチウム・ニッケルのリサイクル材使用比率**に最低基準が設定される   |

意味するところは単純で、**「どこの鉱山から来た材料か」「何%が再生材か」を証明できない電池はEUで売れなくなる**。
これは環境規制であると同時に、**トレーサビリティを持つ企業への実質的な参入障壁**でもある。

→ [金属リサイクル](../../11_資源・エネルギー・鉄鋼金属/14_金属リサイクル/README.md)

### リユース（再利用）という中間段階

車載電池は容量が7〜8割に落ちるとEVには不向きになるが、
**定置用なら十分使える**。そこで「EV → 定置用 → リサイクル」という多段活用（カスケード利用）が模索されている。
課題は、SOH（健全度）の診断コストと、メーカーをまたいだ規格・保証の不在。

## 7. 日本の政策

| 施策                                           | 内容                                                                                |
| ---------------------------------------------- | ----------------------------------------------------------------------------------- |
| 蓄電池産業戦略                                 | 2022年策定、その後改訂。**2030年代半ばに国内製造基盤150GWh/年**の確立を目標に掲げる |

## 用語メモ

- **スポジュメン**：リチウムを含む硬岩鉱石。豪州が主産地
- **かん水（ブライン）**：リチウムを含む地下塩水。蒸発池で濃縮する
- **DLE（直接リチウム抽出）**：蒸発池を使わずかん水からリチウムを取り出す新技術
- **炭酸リチウム／水酸化リチウム**：電池用リチウム化合物。LFPは炭酸、高ニッケル三元系は水酸化を使う
- **MHP**：ニッケル中間製品（混合水酸化物沈殿物）。インドネシアで大量生産される
- **球状化黒鉛**：負極用に丸く加工した天然黒鉛。加工は中国に集中
- **人造黒鉛**：石油コークス等から作る黒鉛。急速充電性と寿命で有利
- **チョークポイント**：供給網で代替が効かない狭隘部。電池では精錬と材料加工
- **ブラックマス**：使用済み電池を破砕・選別して得られる金属含有粉
- **乾式／湿式リサイクル**：熱処理で回収する方式／酸で溶かして回収する方式
- **バッテリーパスポート**：電池個体の材料由来・カーボンフットプリント等を記録する電子情報
- **カスケード利用**：性能が落ちた電池を要求水準の低い用途へ順に回すこと
- **特定重要物資**：経済安全保障推進法で指定された、供給確保を国が支援する物資
