フードテック｜代替タンパク（植物肉・培養肉・昆虫・精密発酵）

注目テーマフードテック
あこのページの単語集用語に触れると意味を確認できます16語
飼料ペットフード発酵槽は既存インフラB2Bで売れる既存の相場と勝負できる代替タンパク（オルタナティブプロテイン）押出成形（エクストルージョン）HMMA（高水分押出成形）培地成長因子細胞性食品新規食品（Novel Food）NOVA分類／超加工食品（UPF）精密発酵ハイブリッド肉魚粉（フィッシュミール）

このノートで分かること：代替タンパクの4系統がそれぞれ別の産業であること。
そして、なぜ植物肉ブームが失速し、培養肉がまだ売られていないのかを、価格の算数と規制の両面から。

結論から書くと、代替タンパクの勝敗は「既存の肉・乳と同じ値段で、同じくらい美味しいか」のほぼ一点で決まった。
2020〜2022年はESG資金がその価格差を補填していたが、金利が上がって資金が引いた瞬間、価格差を埋められない事業が順に消えた。

1. まず4系統を分けて覚える

「代替肉」と一括りにすると必ず混乱する。作り方も、コスト構造も、規制も全部違う。

系統 作り方（ひとことで） 今どこにいるか コストの中心 規制のハードル
植物肉大豆・えんどうのタンパクを押出成形で繊維状にするすでに店頭にある。伸び悩み原料タンパク＋加工（押出成形）費低い（普通の加工食品）
培養肉（細胞性食品）動物の細胞を培養槽で増やす米国・シンガポールで承認済みだが商業規模は未達培地（細胞の餌）と培養設備非常に高い（新規食品審査）
昆虫コオロギ等を養殖して粉末化食用は縮小、飼料・ペットフードに転換飼育設備と餌中（飼料は比較的通りやすい）
精密発酵微生物に特定のタンパク質を作らせるB2B原料として立ち上がり中。伸びている発酵槽の稼働率と基質（糖）中〜高（新規食品だが前例が増えた）
                 【動物を使わずにタンパク質を得る4つの道】

 植物から取り出す ──▶ 大豆・えんどう ──▶ 分離タンパク ──▶ 押出成形 ──▶ 植物肉
                                                          （繊維状にする）

 動物の細胞を増やす ▶ 細胞株 ──▶ 培地で培養 ──▶ 収穫 ──▶ 成形 ──▶ 培養肉
                              ↑ここのコストが千倍単位で高かった

 昆虫を育てる ──────▶ コオロギ・アメミズアブ ──▶ 乾燥・粉末 ──▶ 飼料／食品

 微生物に作らせる ──▶ 酵母・菌に遺伝子を入れる ──▶ 発酵槽 ──▶ 精製 ──▶ 乳タンパク・油脂
                                                            （精密発酵）

ポイント：精密発酵だけは「消費者に代替品と意識させずに売れる」。
乳タンパクや油脂として食品メーカーに原料で納めるので、
「代替品だから安くないと買わない」という消費者心理の壁を迂回できる。ここが他の3系統との決定的な差。

2. なぜ植物肉ブームは失速したのか

2019年のBeyond Meat上場からおよそ3年で、米国の植物肉小売売上は2022年をピークに減少に転じた。
理由は3つあり、どれか1つではなく3つ同時に効いたのが厳しかった。

(1) 価格：安くならなかった

植物肉の原価は、原料の分離大豆タンパク／えんどうタンパクよりも、それを肉らしい繊維にする加工工程にかかる。
高水分押出成形（HMMA）という装置に通す工程で、装置の減価償却と電力が効く。
畜産は数千年かけて規模と流通を最適化しており、新参が量産効果で追い抜くには桁違いの生産量が要る。

  ひき肉100gあたりの店頭価格イメージ（2026年時点の日本の感覚値）
  ┌──────────────────────────────────────┐
  │ 鶏ひき肉      ██████            安い   │
  │ 豚ひき肉      ████████                 │
  │ 牛ひき肉      ███████████              │
  │ 大豆ミート    ███████████████  高い    │  ← 「環境にいい」だけでは埋まらない差
  └──────────────────────────────────────┘
  ※小売価格は商品・時期で大きく変動する。傾向の図であり実測値ではない

「多少高くても買う層」は最初に買い終わる（＝トライアルは伸びる）。
問題はリピートで、価格差がそのまま継続率を削った。

(2) 味と食感：期待値を超えられなかった

植物肉は「肉の代わり」として売られたため、比較対象が本物の肉になった。
ハンバーガーのパティのように味付けと油脂で覆える形態では健闘したが、
ステーキ・鶏むね肉のような素材の食感がそのまま評価される形態では差が埋まらなかった。

(3) 超加工食品（UPF）批判：健康というイメージが逆転した

これが最も予想外の逆風だった。
植物肉は原料を分離・再構成し、結着剤・着色料・香料を使う。
NOVA分類（ブラジルの研究者が提唱した加工度の分類）でいう第4群＝超加工食品にそのまま当てはまる。

  • 米国では2025年に健康行政のトップがUPFを強く問題視する発言を繰り返し、FDA・USDAがUPFの統一定義づくりに着手
  • フランスでは2026年5月に国会でUPFのシンポジウムが開かれ、規制法案の準備が進むと報じられる
  • 日本の食品業界は「減塩・減糖・低糖質」といった製品改良で実務的に対応する動きが中心

皮肉な構図：植物肉は「健康・環境にいい食品」として売り出されたのに、
加工度の高さゆえに健康フレームの側から攻撃される立場になった。
「肉を似せるために加工する」という設計思想そのものが、UPF批判と正面衝突している。

撤退しても会社が潰れない。不二製油のような大豆タンパク素材メーカーはむしろ原料供給側として安定している。

3. 培養肉：コストの壁はどこにあるのか

培養肉は「動物の細胞を取り出し、培養液（培地）の中で増やして食用にする」技術。
2013年に初のバーガーが発表されたときの原価は1個あたり約33万ドルと報じられた。そこから大幅に下がったが、まだ壁がある。

コストの正体は「培地」

  培養肉1kgを作るのに必要なもの
  ┌────────────────────────────────────────────────┐
  │ ①細胞株         一度作れば増やせる。コストは小さい  │
  │ ②培地（細胞の餌）████████████████████  最大の費用  │
  │    アミノ酸、糖、ビタミン、そして成長因子            │
  │    ※成長因子は医薬グレードだとg単位で数十万円級      │
  │ ③培養槽の設備償却 ██████                           │
  │ ④無菌管理・人件費 ████                             │
  └────────────────────────────────────────────────┘
        ↑ 「培地を食品グレードで、桁違いに安く作る」ことが業界共通の課題

医薬品のバイオ生産（抗体医薬など）と同じ装置・同じ無菌管理を使うのに、
売る先は1kg数千円の食肉市場。ここが構造的なミスマッチで、
「医薬品の原価で食品の値段のものを作る」ことを求められている。
→ 装置と管理の考え方は 創薬ベンチャー・バイオ と共通

現実解は「ハイブリッド」

コストが下がりきらないため、培養した細胞や脂肪を数%だけ植物肉に混ぜるアプローチが主流になりつつある。
Mosa Meat（蘭）が培養牛脂の単体承認を英国・EUに申請しているのは、
「脂（＝風味の源）だけを培養で作り、残りは植物性で組む」ほうが早く商業化できるからである。

各国の承認状況（2026年時点）

国・地域 状況
シンガポール2020年に世界初の販売承認。食料自給率が極端に低く、国策として推進
米国FDAの上市前相談＋USDA検査を経て販売可能に（Upside Foods、GOOD Meat）。ただし州レベルの禁止法がフロリダ・アラバマに続き2025年7月にミシシッピで成立

イスラエル・カタール等個別に承認例が出ている

押さえどころ：技術ではなく規制と価格で地域差がついた。
「培養肉が実現するか」ではなく「どの国で、いくらで売れるようになるか」を追うのが実務的な見方。

4. 昆虫：食用から飼料へピボットした

昆虫食は2020年前後に大きく報じられたが、日本では消費者の忌避感と炎上リスクが強く、食用は縮小した。
生き残ったのは用途を変えた側で、

  • 飼料：養殖魚・鶏・豚の餌。魚粉（フィッシュミール）が高騰しているため、代替として経済合理性がある
  • ペットフード：アレルギー対応の新規タンパク源としての需要
  当初の狙い            実際に伸びた場所
  人が食べる    ──✕──▶ 忌避感・価格・規模の3重苦
  家畜/魚が食べる ──○──▶ 魚粉高騰の代替として採算が見える
                        → [畜産・飼料](../../08_食品・農水産・外食/13_畜産・飼料/README.md)
                        → [水産](../../08_食品・農水産・外食/11_水産/README.md)

教訓として一般化できる：代替タンパクは、消費者が「選ぶ」市場より、原価で判断される「B2B原料」市場のほうが早く立ち上がる。

5. 精密発酵：いま最も現実味がある系統

精密発酵は、酵母や菌に遺伝子を入れて狙った1種類のタンパク質を作らせる技術。
ビール酵母やチーズの凝乳酵素（レンネット）は昔から同じ原理で作られており、新技術というより既存技術の応用範囲拡大にあたる。

作れるもの 用途 状況
乳タンパク（ホエイ、カゼイン、β-ラクトグロブリン）プロテイン飲料、アイス、チーズPerfect Day（米）が先行。Vivici（蘭）が2025年3月に「Vivitein BLG」を発売
卵白タンパク製菓、製パン開発中
油脂パーム油代替、培養肉のハイブリッド用開発中
香料・色素（ヘム鉄など）植物肉の「肉らしさ」Impossible Foodsが利用

市場推計では2025年の約32億ドルから2026年に約45億ドル（TBRC推計）といった数字が出るが、
年率40%超という前提は強気であり、推計であることを前提に扱うべき。

なぜ現実味があるのか。理由は3つ。

  1. 発酵槽は既存インフラ：製薬・アミノ酸・酵素の既存工場を転用できる。ゼロから建てなくてよい
  2. B2Bで売れる：消費者の受容性の壁を通らない。食品メーカーの調達判断＝価格と機能で決まる
  3. 既存の相場と勝負できる：乳タンパクの市況が高いときは十分に採算ラインに入る

ただし弱点も明確：遺伝子組換え微生物を使うため、表示規制と消費者団体の反応が国ごとに違う。
また発酵槽の稼働率が落ちればすぐ赤字になる装置産業なので、量を売る先の確保が前提になる。
発酵の採算構造は 02_生産のテクノロジー で扱う。

6. 採算が合う条件を明示すると

4系統をまたいで、「これを満たさないと事業として続かない」という線を書いておく。

系統 採算ラインの目安 満たせている？
植物肉畜肉と同価格以下。それが無理なら「肉の代替」ではなく独自カテゴリ（大豆の惣菜）として売る✕（多くが1.5〜2倍）→ 用途変更で生き残る形
培養肉培地コストを現状から1〜2桁下げる＋主要市場の承認取得✕（未達。ハイブリッドで部分商業化を狙う段階）
昆虫（飼料）魚粉相場を下回ること△（相場次第で成立）
精密発酵既存の乳タンパク・油脂の相場を下回るか、機能で上回ること○（品目によっては成立し始めている）

成功例と失敗例を並べると構図が見える。

  • 失敗：Beyond Meat（価格差を埋められず売上減）、スプレッド（植物工場。別ノートで扱うが同じ構図）、食用昆虫の多く
  • 成功：Perfect Day／Vivici などのB2B原料型、既存食品メーカーの大豆ミート（本業の1ラインとして赤字を吸収できる）、昆虫の飼料転換
  • 共通点：「消費者に新しい選択を迫った側」が負け、「既存の調達に静かに入り込んだ側」が残った

7. この分野のニュースの読み方

  1. 「承認された」＝「売れる」ではない。承認は必要条件にすぎず、価格と販路が別に要る
  2. 資金調達額のニュースは進捗ではない。売上高と生産量（トン／年）を見る
  3. 「市場規模○兆円予測」は使わない。定義がばらばらで、調査会社間で数倍の開きがある
  4. 原料相場と電力単価を見る。この分野の損益は、技術進歩より外部相場に振られることが多い

用語メモ

  • 代替タンパク（オルタナティブプロテイン）：家畜・魚由来でないタンパク源の総称
  • 押出成形（エクストルージョン）：原料を加熱・加圧しながら細い口から押し出す加工。植物タンパクを繊維状にして肉の食感を作る中核技術
  • HMMA（高水分押出成形）：水分を多く含んだ状態で押出成形する方式。よりジューシーな食感が出るが装置が高価
  • 培地：細胞を育てる液体。アミノ酸・糖・ビタミン・成長因子を含む。培養肉の原価の大半
  • 成長因子：細胞分裂を促すタンパク質。医薬グレードだと極めて高価で、食品グレードでの量産が課題
  • 細胞性食品：培養肉の日本での行政用語。「培養肉」は通称
  • 新規食品（Novel Food）：EU・英国の制度上、1997年以前に十分な食経験のない食品。個別に安全性審査が必要
  • NOVA分類／超加工食品（UPF）：食品を加工度で4群に分ける分類。第4群がUPF。植物肉の多くが該当する
  • 精密発酵：微生物に狙った特定のタンパク質を作らせる発酵。従来の発酵（醸造）が「混合物を作る」のに対し「単一分子を作る」
  • ハイブリッド肉：植物タンパクに培養細胞・培養脂肪を数%混ぜた製品。培養肉の早期商業化ルート
  • 魚粉（フィッシュミール）：養殖飼料の主原料。価格高騰が昆虫・微生物タンパクの追い風になっている
