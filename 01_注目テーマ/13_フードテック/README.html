フードテック

学習済み更新 2026-09-19注目テーマ
あこのページの単語集用語に触れると意味を確認できます10語
投資は横ばいだが中身が変わった植物肉は「終わった」のではなく「リセット」培養肉は規制で地域差が鮮明植物工場は淘汰期省人化とデリバリーは実利フェーズ代替タンパク（オルタナティブプロテイン）精密発酵植物工場（人工光型）テイクレート超加工食品（UPF）

フードテックを一言でいえば、「食べものを作る・運ぶ・食べるの各段階に、技術でコストか制約を1つ外そうとする試みの総称」。
ひとつの産業ではなく、代替タンパク・生産技術・流通技術・消費技術という性格の違う4つの塊の寄せ集めである。

この分野を読むときの最大の注意点は、期待が先に立ちすぎて、撤退と破綻が普通に起きること。
植物肉は2022年をピークに売上が落ち、国内の植物工場は約4割が赤字（2025年、日経報道）、
国内最大級のレタス工場を運営していたスプレッドは2024年8月に民事再生を申請した（負債37.4億円）。
一方で、陸上養殖やフードデリバリー、外食の省人化のように採算が合い始めた領域も確実にある。

このノート群の狙い：「すごい技術」の紹介ではなく、どういう条件なら採算が合い、どこで合わなかったのかを算数で押さえること。

1. 業界の定義・範囲

フードテックは、食のバリューチェーン（生産→加工→流通→消費）のいずれかを、技術で置き換え・効率化しようとする事業領域を指す。
業種分類ではなく「切り口」なので、含む／含まないの線を先に引いておかないと話が発散する。

含む 含まない（隣接）
代替タンパク（植物肉・培養肉・昆虫・精密発酵）従来型の食肉・加工食品 → 畜産・飼料、総合食品
植物工場・陸上養殖・スマート農業通常の露地農業・海面養殖 → 農業・種苗・肥料、水産
フードデリバリー・受発注SaaS・需要予測一般の物流網 → 宅配便、食品卸
外食の省人化（調理・配膳・オーダー）外食チェーンの運営そのもの → ファストフード
パーソナライズ栄養、完全栄養食医薬品・特定保健用途の治療 → 健康食品・サプリメント

4つの塊は、収益構造がまったく違う。同じ「フードテック」という言葉で括ると必ず誤読する。

 ①代替タンパク     ②生産テクノロジー    ③流通テクノロジー   ④消費テクノロジー
 植物肉/培養肉      植物工場/陸上養殖     デリバリー/ロス削減   省人化/栄養
 ───────────      ───────────        ───────────       ───────────
 研究開発型         設備産業型            プラットフォーム型    店舗設備／SaaS型

 承認と単価が壁     電力単価と稼働率が壁    テイクレートが壁     人件費との比較が壁

付加価値が集まるのは、「既存プレイヤーのコストを実際に下げた場所」だけ。
消費者に新しい体験を提案するタイプ（植物肉、パーソナライズ栄養）は、
既存品との価格差を消費者が負担してくれるかという一点で生死が決まり、多くが負けた。

4. 主要プレイヤーとシェア

分野がバラバラなので、企業一覧より「どの類型か」で整理したほうが役に立つ。

類型 代表例 立ち位置・特徴
植物肉（海外）Beyond Meat、Impossible Foods（米）ブームの主役。Beyond Meatは2026年1〜3月期に売上が前年同期比▲15%、営業利益率▲70.6%と報じられ、再建途上
植物肉（国内）大豆ミート各社（不二製油、大塚食品、伊藤ハム米久 ほか）既存の食品会社が本業の一製品ラインとして手掛ける形が主流。専業ベンチャーは少ない

スマート農業クボタ、ヤンマー、井関（自動運転農機）、各種営農SaaS既存の農機メーカーが本命。→ 農業機械

外食の省人化配膳ロボット（Pudu、Keenon 等）、モバイルオーダー各社すかいらーくの大量導入以降、普及が加速。導入済み省人化設備では配膳ロボットが最多

5. 収益モデル・コスト構造

領域 何で儲けるか コストの中心 採算が合う条件
植物肉加工食品として1パックいくら原料（分離大豆タンパク等）と押出成形の加工費畜肉と同価格かそれ以下になること。現状は多くが1.5〜2倍
培養肉まだ商業規模の売上がほぼない培地（細胞の餌）と培養槽の設備償却培地コストを数桁下げること＋各国の販売承認
精密発酵B2Bの原料販売（kgいくら）発酵槽の稼働、糖などの基質既存の乳タンパク・油脂の相場を下回るか、機能で差別化できるか
植物工場野菜1株いくら（契約栽培中心）電力（ランニングの25〜30%）と人件費、設備償却一般野菜の1.3倍以内に価格を収め、かつ通年契約の販路を持つこと
陸上養殖魚1kgいくら餌代（6〜7割）＋ポンプ・水温管理の電力＋設備償却高単価魚種（サーモン・エビ等）＋輸送コストの削減分で海面養殖に勝つこと
デリバリー飲食店からの手数料（テイクレート）＋配送料＋広告配達員への報酬（変動費）、獲得販促費1注文あたりの粗利 > 配達コスト。注文密度が上がるほど配達1件の距離が縮み黒字化する
外食の省人化設備販売／月額リース機体・保守削減できた人件費 > 機体コスト。配膳ロボは本体150〜300万円、レンタル月7〜10万円が目安（2026年時点の相場）

分野をまたぐ共通の教訓：「環境にいい」「健康にいい」は価格プレミアムをほとんど生まない。
2020〜2022年はESGマネーがその差額を埋めていたが、金利上昇で資金が引いた瞬間、
価格で勝てない事業から順に消えた。採算は理念ではなく算数で決まる。

6. 競争要因（KSF）と参入障壁

KSF

  1. 既存品との価格差をゼロに近づけられるか。これが最大かつほぼ唯一の関門
  2. 原料・エネルギーの調達力。植物工場なら電力契約、陸上養殖なら餌、培養肉なら培地
  3. 販路（アンカー顧客）。コンビニ・スーパー・外食チェーンとの通年契約があるかどうかで稼働率が変わる
  4. 規制の通過。培養肉・新規食品は各国の承認が必要で、通過そのものが資産になる
  5. 稼働率。設備型（植物工場・陸上養殖・発酵槽）はすべて、止まった瞬間に赤字になる装置産業

参入障壁

  • 設備型：初期投資（植物工場で数億〜数十億円、大型陸上養殖で数百億円規模）と、回収に10年級かかる時間
  • 代替タンパク：食品安全の承認、特許、そして味と食感を作る加工技術のノウハウ
  • プラットフォーム型：両面市場（店舗と利用者）の鶏卵問題。先行者の注文密度に後発は勝ちにくい
  • 逆に障壁が低いのは植物肉。既存の食品メーカーが同等品を短期間で出せてしまい、専業の優位が保てなかった

7. 規制・法制度

制度・領域 内容
食品衛生法（日本）新しい食品は食品衛生基準審議会で安全性を審議。培養肉（細胞性食品）は2026年時点で販売承認の枠組みが整備途上で、試食にも制約がある
新規食品（Novel Food）規制EU・英国は新規食品として個別審査。Mosa Meat等が申請中（2026年時点）
米国FDAの上市前相談＋USDAの検査で販売可能に。ただし州レベルで禁止する動き（フロリダ、アラバマ、2025年7月にミシシッピ）があり国内で割れている
シンガポール2020年に世界で初めて培養肉の販売を承認。食料自給率の低さを背景に国策として推進
表示規制「肉」「ミルク」などの名称を代替品に使えるかで各国が争点化。日本では大豆ミートのJAS規格が2022年に制定
食品ロス削減推進法（日本、2019年施行）2030年度までに食品ロスを2000年度比で半減させる目標。事業系は先行して達成
超加工食品（UPF）をめぐる動き米FDA・USDAが定義策定に着手、フランスでは規制法案の準備が進むと報じられる（2026年）。植物肉にとっては逆風
補助金日本は「フードテック官民協議会」（農水省）、みどりの食料システム戦略、スマート農業技術活用促進法（2024年施行）など

8. 最近のトピック

詳細は 05_直近トピック_2026 を参照。要点だけ5行で。

  1. 投資は横ばいだが中身が変わった：2025年の世界アグリフードテック投資は約162億ドルで前年並み。件数は減り、実売上のある川上側に資金が寄った
  2. 植物肉は「終わった」のではなく「リセット」：Beyond Meatの苦境が続く一方、既存食品メーカーの製品ラインとしては残った。争点は価格と超加工食品批判
  3. 培養肉は規制で地域差が鮮明：米・シンガポールは承認済み、欧英は審査中、米国内では州単位の禁止法という逆流も
  4. 植物工場は淘汰期：スプレッドの民事再生（2024年）後、工場が他社へ譲渡され再編が進む。電気代がそのまま損益になる構造は変わらない
  5. 省人化とデリバリーは実利フェーズ：人手不足という具体的な痛みに直結しており、採算が読める数少ない領域

9. 用語メモ

各ノート末尾の「用語メモ」に分散して置いている。最初に押さえるべき5語だけここに。

  • 代替タンパク（オルタナティブプロテイン）：家畜・魚由来でないタンパク源の総称。植物・培養・昆虫・微生物の4系統 → 01_代替タンパク
  • 精密発酵：微生物に特定のタンパク質（乳タンパクなど）を作らせる技術。ビールの発酵と違い狙った1種類の分子を作らせるのが肝 → 01_代替タンパク
  • 植物工場（人工光型）：閉鎖空間でLED照明と空調により通年栽培する施設。電気代が損益を直撃する → 02_生産のテクノロジー
  • テイクレート：プラットフォームが取引額から受け取る手数料の比率。デリバリーでは飲食店から3割前後 → 03_流通と消費のテクノロジー
  • 超加工食品（UPF）：工業的に高度加工された食品を指す分類（NOVA分類の第4群）。植物肉の多くがここに分類され、健康イメージの前提が揺らいだ → 01_代替タンパク
