## 1. 投資：金額は横ばい、中身が「実業寄り」に変わった

- AgFunder の「Global AgriFoodTech Investment Report 2026」によると、
  **2025年の世界のアグリフードテック投資は約162億ドルで前年比ほぼ横ばい**
- 内訳が変わった。**川上（農場・生産技術・バイオ）が約90億ドルで前年比＋7%**と伸びた一方、
  **案件数は▲12%**。つまり**1件あたりが大きくなり、選別が進んだ**
- 川下（デリバリー・ネットスーパー）の「成長優先」型の資金は明確に退いた。
  2025年の最大メガディールは、この分野のピーク（2021年）の案件と比べ**約8割小さい**と報じられる
- 投資家が見る軸は「実証できる科学」「成立するユニットエコノミクス」「収益化の道筋」に移ったとされる

```
  2021年（ゼロ金利・ESGブーム）  ████████████████████████  ピーク
  2022年                        ███████████
  2023年                        ████████
  2024年                        ██████
  2025年 約162億ドル             ██████ ← 横ばい。ただし川上に7%シフト、件数は12%減
                                        「薄く広く」から「厚く少なく」へ
```

> 読み方：**この分野の冬は終わっていないが、底は打った**という見立てが業界メディアの共通認識。
> ただし2026年も「大きな回復の年にはならない」との観測が示されている。

## 2. 植物肉：Beyond Meat の苦境が続き、業界は「リセット」局面

- **Beyond Meat は2026年1〜3月期に売上が前年同期比▲15%**、**営業利益率は▲70.6%**と報じられる。
  減少は外食向け（フードサービス）に集中し、米国内・海外の双方で落ちた
- 同社は「植物タンパクの会社」への位置づけ直しを進め、2026年夏にドリンク製品を投入する計画とされる
- 業界メディア（FoodNavigator, 2026年2月）は、植物肉は**「死んだのではなくリセット中」**で、
  課題は**純粋に価格**だと整理している。金利上昇で消費者の可処分所得が締まり、割高な代替品が真っ先に落ちた
- 米国の小売売上は2022年のピーク以降、減少が続いている

**日本での見え方は少し違う**。専業ベンチャーではなく既存の食品メーカーが製品ラインとして持つため、
売れ行きが落ちても会社が傾かない。原料の分離大豆タンパクを供給する側（不二製油など）はむしろ安定している。

## 3. 培養肉：規制で地域差が鮮明に。国内は「枠組み整備の途中」

| 地域 | 2026年時点の状況 |
| --- | --- |
| シンガポール | 2020年に世界初承認。培養脂肪向けのガイドライン改定や、細胞培養プロセスの自動化に関する基準づくりが進むとされる |
| 米国 | FDAの上市前相談＋USDA検査で販売可能。ただし**州単位の禁止法**が拡大し、フロリダ・アラバマに続き**2025年7月にミシシッピ**が3例目 |
| EU・英国・スイス | 新規食品として審査中。**Mosa Meat（蘭）**が培養牛脂で英国・EFSA・スイスに申請。英国市場投入は2027年頃との見方。2026年7月にはオランダの政府系投資機関から約87.5万ユーロを調達したと報じられる |
| 日本 | 消費者庁・食品衛生基準審議会の**新開発食品調査部会**で細胞性食品の取扱いを審議中。**2026年3月30日に（一社）細胞農業研究機構（JACA）が意見書を提出**。販売の枠組みはまだ整っていない |

```
  【培養肉をめぐる2026年の構図】

  技術：  培地コストは下がったが、まだ食肉価格には届かない
    ↓
  戦略：  「丸ごと肉」をあきらめ、培養脂肪を数%混ぜるハイブリッドへ  ← Mosa Meat の申請がこれ
    ↓
  規制：  承認する国（シンガポール・米）／審査中（EU・英）／禁止する州（米国内）／整備中（日本）
    ↓
  結果：  同じ製品が、国境どころか州境をまたぐだけで合法性が変わる状態
```

> ポイント：**技術より規制のほうが速く動いており、しかも逆方向にも動いている**。
> 米国で連邦は認め、州が禁じるという分裂は、この産業のリスクを象徴している。

## 4. 植物工場：スプレッド破綻後の再編と、消えない電気代問題

- 日経新聞は2025年、**国内の植物工場のおよそ4割が赤字**で、工場産レタスが一般品の2倍の価格になる例もあると報じた
- 人工光型ではランニングコストの**25〜30%が電気代**とされ、
  電力調達（高圧契約への切替、新電力の活用など）の見直しで**10〜15%程度の改善余地**があると業界メディアは指摘する
- **国内最大級のレタス工場を運営していたスプレッド（京都）は2024年8月26日に民事再生法の適用を申請**（負債約37億4,300万円）。
  同年9月に再生手続開始決定。設備投資の先行と光熱費高騰で資金が尽きた形で、
  主要工場はその後、他社に譲渡された
- 業界の総括は一貫している。**市場拡大を優先し採算を後回しにした経営は続かない**

| 赤字工場に共通すること | 黒字工場に共通すること |
| --- | --- |
| 販路を決めずに建てた | 通年・定量の契約を先に取った |
| 一般野菜と同じ土俵で価格競争した | 低カリウム野菜など**比較されない商品**に逃げた |
| 電力契約を見直していない | 契約形態・調達先を定期的に見直している |
| 収穫・包装が手作業のまま | 工程の自動化で人件費を圧縮した |

## 5. 陸上養殖：大型投資が続く。ただし「餌代6〜7割」は変わらない

- **2026年の国内サーモン生産量は、過去最多だった前年からさらに1割程度増える見込み**と報じられる
- **三重県津市で建設中の世界最大級のアトランティックサーモン陸上養殖施設**は、
  **総事業費約700億円とも報じられ、2027年末頃からの出荷開始を目指す**（2026年5月の地元報道）
- 静岡県富士宮市ではノルウェー系の事業者が既に出荷を開始している
- ただしコスト構造は水産業の原則どおりで、**養殖原価の6〜7割は餌代**。
  これに加えてRAS（閉鎖循環式）ではポンプ・冷却・酸素供給の電力が常時かかる

> 見立て：陸上養殖は代替タンパクより現実的だが、**「高単価魚種×消費地近接」以外では成立しにくい**。
> 大型案件ほど立ち上げ期の技術トラブルが資金繰りを直撃するため、
> 出荷開始から3年程度の実績を見るまで成否は判断できない。

## 6. 食品ロス：日本は2030年目標を前倒し達成

- **2024年度の食品ロスは461万トン**（家庭系224万トン、事業系237万トン）。前年度から3万トン減少。
  **2026年6月30日に農水省・環境省が公表**
- **経済損失は前年度の4兆円から約3.8兆円に減少**
- 2000年度の980万トンと比べると半減しており、**SDGs目標12.3（2030年までに半減）を達成した**とされる
- 削減の主因は、返品・廃棄を生んでいた**商慣行（3分の1ルール）の緩和**と、賞味期限の年月表示化、AI需要予測の普及

> 珍しく明確な成功事例。**技術より商慣行の変更が効いた**という点が、この分野全体への教訓になる。

## 7. 超加工食品（UPF）：植物肉にとっての新しい逆風

- 米国では2025年以降、健康行政のトップがUPFを強く問題視する発言を重ね、
  **FDAとUSDAがUPFの統一定義づくりに着手**した。定義の確定は将来の表示義務化への第一歩とみられる
- **フランスでは2026年5月28日に国会でUPFのシンポジウムが開かれ**、規制法案の提出準備が進むと報じられる
- 日本の食品業界は規制論争より**製品改良（減塩・減糖・低糖質）で実務的に対応**する動きが中心
- 学術的には「加工度そのものが問題なのか、栄養組成が問題なのか」で論争が続いている

```
  植物肉にとっての意味

  2019年の売り文句： 「環境にいい・健康にいい・動物を殺さない」
                              ↓
  2026年の現実：     環境 → 消費者は価格差を払わない
                     健康 → UPF分類の第4群に当てはまり、むしろ攻撃される側
                     倫理 → 一定の支持はあるが市場を作るには小さい
                              ↓
  残った訴求軸は「美味しくて同じ値段」。つまり普通の食品と同じ土俵になった
```

## 8. フードデリバリー：寡占なのに儲からない構図が続く

- 日本のフードデリバリー市場は**2024年 約7,967億円 → 2025年 約8,240億円**（推計）
- 利用率では**Uber Eats が約57%、出前館が約36%**で、2社で9割超という寡占（調査ベース）
- しかし収益は割れている。**Uber Eats は3年連続の黒字で2026年1月に過去最高**と報じられる一方、
  **出前館は約79億円の赤字**が見込まれるとされる。新規参入の Rocket Now も急成長と報じられ、価格競争が続く
- 構造的には、送料無料・同一価格の競争が続く限り**資金力の差が生存期間を決める消耗戦**になる

## 9. 外食の省人化：導入設備の最多は配膳ロボット

- 外食各社は2026年に向け、省人化投資とDXで**「限られた人数で店舗を回す運営モデル」**への移行を加速させている
- 導入済みのロボット・省人化設備では**配膳ロボットが58.6%で最多**（業界調査）
- 相場は**本体150万〜300万円、レンタルで月7万〜10万円**程度
- 判断は単純で、**削減できる人件費が月7〜10万円を超えるか**。座席数が多く配膳距離が長い大型店ほど有利

## 10. 全体の構図

1. **フードテックは「期待の分野」から「採算で選別される分野」に移った**。2025年の投資が横ばいでも川上に7%シフトし、件数が12%減ったのがその証拠
2. **勝ち残っているのは、消費者に新しい選択を迫らず、既存プレイヤーのコストを直接削るもの**。省人化、ロス削減、B2B原料型の精密発酵がそれにあたる
3. **負けているのは、既存品より高い代替品を消費者に買ってもらう前提のもの**。植物肉と、販路なしで建てた植物工場が典型
4. **規制が事業の生死を直接決める領域がある**。培養肉は技術より承認の地図を見るべきで、しかも米国では州単位の禁止という逆流も起きている
5. **日本固有の軸は「人手不足」と「輸入依存」**。前者は今すぐ金になり、後者は10年単位の話。この2つを混ぜて論じると必ず噛み合わなくなる

## 用語メモ

- **アグリフードテック（AgriFoodTech）**：農業・食品領域のテクノロジー投資全般を指す投資用語。川上（農場側）と川下（流通・消費側）に分けて集計されることが多い
- **メガディール**：1件で数億ドル規模の大型資金調達。件数より金額で市場の熱量を見るときに使われる
- **細胞性食品**：培養肉の日本での行政用語
- **新開発食品調査部会**：消費者庁の食品衛生基準審議会に置かれる部会。新しい食品の安全性を審議する
- **Novel Food（新規食品）**：EU・英国で個別の安全性審査を要する新しい食品のカテゴリ
- **NOVA分類／UPF**：食品を加工度で4群に分ける分類。第4群が超加工食品（UPF）
- **RAS**：閉鎖循環式陸上養殖。水を濾過して再利用する方式
- **3分の1ルール**：賞味期限までの期間を3等分し最初の1/3以内に納品する日本の商慣行。食品ロスの主因とされ緩和が進んだ
