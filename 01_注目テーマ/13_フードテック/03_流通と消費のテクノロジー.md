# フードテック｜流通と消費のテクノロジー（デリバリー・フードロス・栄養・省人化）

このノートで分かること：食べものを**届ける／捨てない／選ぶ／出す**の4領域で、技術が実際に金を生んでいる場所。
代替タンパクや植物工場と違い、この領域は**既に大きな売上が立っている**。ただし儲かっているとは限らない。

結論：この4領域は、**「人手不足という具体的な痛み」に直結しているものほど採算が読める**。
逆に、消費者に新しい行動を求めるもの（パーソナライズ栄養）は立ち上がりが遅い。

## 1. フードデリバリー：規模がすべての消耗戦

### 三者をつなぐ両面市場

```
        【フードデリバリーの三角形】

              飲食店（加盟店）
             ／           ＼
   手数料30%前後          注文が増える
           ／               ＼
   プラットフォーム ────────── 消費者
           ＼      配送料・サブスク  ／
      配達報酬 ＼               ／ 早く届く
              配達員（ギグワーカー）

  プラットフォームの取り分 ＝ 店舗手数料 ＋ 配送料 ＋ 広告料
  プラットフォームの費用   ＝ 配達員への報酬 ＋ 販促 ＋ システム
```

### ユニットエコノミクス（1注文あたりの算数）

デリバリーが黒字化するかどうかは、**1注文あたりの粗利が配達コストを上回るか**だけで決まる。

| 項目 | 目安（2026年時点の一般的な水準） | 備考 |
| --- | --- | --- |
| 注文金額 | 2,000〜3,000円 | 客単価が低いと全部が壊れる |
| 店舗からの手数料（テイクレート） | 注文金額の**30%前後** | 飲食店にとっては重い。「デリバリー専用価格」で転嫁される |
| 消費者からの配送料 | 0〜500円 | 無料競争に走ると収支が壊れる |
| 配達員への報酬 | 1件あたり数百円 | 距離と時間で変動。ここが最大の変動費 |
| 販促・クーポン | 変動 | シェア争いの局面で膨らむ |

**決定的に効くのが「注文密度」**。同じエリアで注文が増えるほど、
①配達員の待機時間が減り、②1回の移動で複数件を運べ（バッチ配達）、③1件あたりの配達コストが下がる。

```
  注文密度と1件あたり配達コスト

  注文が少ない ──▶ 配達員は空で走る時間が長い ──▶ コスト高 ──▶ 赤字
       │                                                      │
       └──── 販促で注文を増やす（費用が増える）────────────────┘
                     ↓ ここを抜けられるか
  注文が多い ──▶ 1回の移動で2〜3件 ──▶ コスト低 ──▶ 黒字
                     ↑「都市部だけ黒字、地方は赤字」が起きる理由
```

これが**「都市部は黒字だが地方は構造的に赤字」**という現象の正体で、
撤退ニュースが出る地域は、たいてい注文密度が閾値に届かなかった場所である。

### 日本市場の構図（2026年時点）

| | 状況 |
| --- | --- |
| 市場規模 | 2024年 約7,967億円 → 2025年 約8,240億円（各種推計） |
| シェア | Uber Eats 約57%、出前館 約36%（利用率ベースの調査。2社で9割超） |
| 収益 | **Uber Eatsは3年連続黒字**と報じられる一方、**出前館は約79億円の赤字見込み**とされる |
| 新規参入 | Rocket Now などが急成長と報じられ、価格競争が続く |

> 構図：**寡占なのに儲からない**という珍しい市場。
> 理由は、①乗り換えコストがほぼゼロ（消費者はアプリを2つ入れて安いほうを使う）、
> ②飲食店も複数に登録する、③差別化要素が「速さ」と「価格」しかないこと。
> 結果として**資金力の差がそのまま生存期間になる消耗戦**になっている。

### 飲食店側から見ると

手数料30%は、外食の営業利益率（数%〜10%程度）を軽く吹き飛ばす。
だから飲食店は**デリバリー価格を店内価格より高く設定**するか、
**デリバリー専用の低原価メニュー**を出すか、**ゴーストキッチン**（客席を持たない調理拠点）に切り替える。
→ [ファストフード](../../08_食品・農水産・外食/14_ファストフード/README.md)、[中食・弁当](../../08_食品・農水産・外食/20_中食・弁当/README.md)

## 2. フードロス：日本は「削減が進んだ」珍しい国

### 数字を押さえる

| 指標 | 数値 | 年・出典 |
| --- | --- | --- |
| 日本の食品ロス発生量 | **461万トン**（前年度比▲3万トン） | 2024年度、農水省・環境省（2026年6月30日公表） |
| うち家庭系 | 224万トン | 同上 |
| うち事業系 | 237万トン | 同上 |
| 経済損失 | 約3.8兆円（前年度4兆円から減少） | 同上 |
| 2000年度比 | 980万トン → 461万トン。**SDGs目標12.3（2030年に半減）を達成済み**とされる | 同上 |

> これは日本の数少ない明確な成功事例。「もったいない」の文化だけでなく、
> **商慣行の見直しという地味な制度改革**が効いた。

### どこで発生するかを図で

```
  【食品ロスの発生場所】

  生産   ─▶ 製造 ─▶ 卸 ─▶ 小売 ─▶ 外食 ─▶ 家庭
  規格外     製造ロス  返品   売れ残り  食べ残し  食べ残し・
  （統計外）  ████    ███    ██████   ██████   期限切れ ████████
                     ↑                          （家庭系224万トン）
                 3分の1ルール
                （製造日から賞味期限までを3分割し、
                  最初の1/3以内に小売へ納品する商慣行）
                  → 緩和が進み、納品期限の見直しが削減の主因になった
```

### 何が効いたのか

| 施策 | 効き方 |
| --- | --- |
| **3分の1ルールの緩和** | 納品期限を「2分の1」に緩めると、返品・廃棄が大幅に減る。最も効果が大きかった |
| 賞味期限の年月表示化 | 日付単位の管理をやめると、物流と在庫の無駄が減る |
| AI需要予測 | 発注精度が上がれば発注過多が減る。コンビニ・スーパーで実装が進む → [コンビニエンスストア](../../07_小売・流通/01_コンビニエンスストア/README.md) |
| ダイナミックプライシング（値引き自動化） | 電子棚札と連動し、期限が近い商品を自動値引き |
| フードシェアリング（TABETE等） | 売れ残りを消費者に安く直販。**規模は小さいが店舗の廃棄費用を減らす** |
| フードバンク・こども食堂 | 寄付ルート。税制と免責の整備が課題 |

**採算が合う条件**は明快で、**削減できた廃棄原価 ＋ 廃棄処理費 > システム費用**。
廃棄は原価だけでなく**処理費も払っている**（事業系一般廃棄物の処理費）ので、
削減の経済効果は原価だけで見るより大きい。
→ [廃棄物処理・環境リサイクル](../../15_サービス・生活関連/23_廃棄物処理・環境リサイクル/README.md)

## 3. パーソナライズ栄養：期待が先行し続けている領域

「遺伝子・腸内細菌・血糖値を測って、その人に合った食事を提案する」という構想。
2020年前後に多くのサービスが立ち上がったが、**日本ではほぼ立ち上がっていない**。

| アプローチ | 中身 | 現状 |
| --- | --- | --- |
| 遺伝子検査ベース | SNPを調べて体質を推定 | 科学的根拠が弱い項目が多く、信頼性に批判 |
| 腸内細菌叢（マイクロバイオーム） | 便検査で菌叢を解析 | 研究は進むが、食事提案への落とし込みが難しい |
| CGM（持続血糖測定） | 血糖の上がり方を実測して食事を調整 | **最も実感が得やすい**。医療機器規制との境界が論点 |
| 食事記録AI | 写真から栄養素を推定 | 精度は上がったが、記録し続ける動機が続かない |
| 完全栄養食 | 1食で必要栄養素を満たす主食（パン・麺など） | 日本では比較的定着。BASE FOOD、日清食品などが展開 |

**立ち上がらない理由は3つ**。
1. **継続コストが高い**：測定に金がかかり、結果が出るまで時間がかかる
2. **行動変容が起きない**：提案されても食事は変わらない。人は「知っているのにやらない」
3. **規制の壁**：効果を言い切ると医薬品・医療機器の領域に入る。表現が曖昧になり訴求力が落ちる

> 逆に**完全栄養食は伸びた**。理由は「選ばせない」から。
> パーソナライズは消費者に判断を求めるが、完全栄養食は**いつもの主食を置き換えるだけ**で済む。
> **消費者の行動変容を最小にした設計が勝つ**という、この分野の普遍則がここにも出ている。
> → [健康食品・サプリメント](../../09_医薬・医療・ヘルスケア/13_健康食品・サプリメント/README.md)

## 4. 外食の省人化：最も採算が読める領域

外食は人手不足がそのまま売上機会の損失になる。だから省人化投資は**効果の計算が簡単**で、導入が進んだ。

```
  【外食店舗の作業と、省人化技術の対応】

  集客 ─▶ 受付 ─▶ 注文 ─▶ 調理 ─▶ 配膳 ─▶ 下膳 ─▶ 会計 ─▶ 洗浄
          ↓       ↓       ↓       ↓       ↓       ↓       ↓
       予約SaaS  モバイル  調理    配膳    配膳    セルフ   食洗
       順番待ち  オーダー  ロボ    ロボ    ロボ    レジ     自動化
       システム  セルフ   （揚げ物 （すかい （回収  券売機
                 オーダー  ・炒め）  らーく   モード）
                           △まだ    等で
                           限定的    大量導入）
                                     ◎最も普及
```

### 投資回収の算数（配膳ロボットの例）

| 項目 | 目安（2026年時点の相場） |
| --- | --- |
| 本体価格 | 150万〜300万円 |
| レンタル／リース | 月7万〜10万円 |
| 削減できる人件費 | ホール1名分の一部。仮に月20万円の0.5人分＝月10万円 |
| 判断 | **月10万円の削減 vs 月7〜10万円のリース料** → ぎりぎり成立。**繁忙店ほど有利** |

だから**導入は大型店・郊外ファミレス・回転寿司から進んだ**。
座席数が多く配膳距離が長い店ほど、1台あたりの削減効果が大きいからである。
逆に**小さな個人店では回収できない**。ここが普及率の差になっている。
→ [ファミリーレストラン](../../08_食品・農水産・外食/15_ファミリーレストラン/README.md)、[回転寿司](../../08_食品・農水産・外食/17_回転寿司/README.md)、[ロボット](../09_ロボット/README.md)

### 調理ロボットが配膳より遅れている理由

- 調理は**メニューごとに動きが違う**。汎用化が難しく、単品特化（フライヤー、ラーメン、炒飯）に留まる
- 衛生管理と清掃の手間が増え、**省人化した分を清掃で取り返される**ことがある
- 厨房は狭く、既存店に後付けできない

> 一般化すると、省人化が進む順は
> **「動きが単純」×「削減できる人件費が大きい」**の掛け算で決まる。
> 配膳（単純・距離が長い）が一番、調理（複雑）が後、というのはこの式そのもの。

## 5. 4領域の採算を並べる

| 領域 | 何を減らすか／増やすか | 採算が合う条件 | 現状 |
| --- | --- | --- | --- |
| デリバリー | 客の移動時間を消す | 注文密度が閾値を超える都市部であること | 寡占だが消耗戦。勝者1社だけ黒字 |
| フードロス削減 | 廃棄原価＋処理費 | システム費用 < 削減額。**商慣行の変更が最も効く** | 日本は成功事例。制度が効いた |
| パーソナライズ栄養 | 消費者の健康 | 消費者が測定コストと手間を継続負担すること | 未成立。完全栄養食だけ定着 |
| 外食の省人化 | 人件費 | 削減人件費 > 機器コスト。**大型店ほど有利** | 最も現実的。導入が進行中 |

**共通の教訓**：
この4領域を並べると、**「既存プレイヤーのコストを直接削るもの」だけが確実に生き残っている**ことが分かる。
デリバリーは店舗に30%のコストを乗せる側なので苦戦し、省人化とロス削減は店舗のコストを削る側なので定着した。

## 用語メモ

- **テイクレート**：プラットフォームが取引額から取る手数料率。デリバリーでは飲食店から30%前後
- **ユニットエコノミクス**：取引1件あたりの収支。プラットフォーム事業の健全性を測る基本指標
- **注文密度**：一定エリア・時間あたりの注文数。デリバリーの配達効率を決める最重要変数
- **バッチ配達**：1人の配達員が複数注文をまとめて運ぶこと。密度が上がると可能になる
- **ゴーストキッチン（クラウドキッチン）**：客席を持たず配達専用に調理する拠点。家賃と人件費を圧縮できる
- **3分の1ルール**：製造日から賞味期限までを3等分し、最初の1/3以内に小売へ納品する日本の商慣行。食品ロスの主因とされ緩和が進んだ
- **納品期限・販売期限**：小売が卸に求める期限と、店頭から下げる期限。ここを緩めると廃棄が減る
- **フードシェアリング**：売れ残りを割安で消費者に直販する仕組み
- **フードバンク**：まだ食べられる食品を福祉団体等に無償提供する仕組み
- **CGM（持続血糖測定）**：皮下センサーで血糖値を連続測定する装置。パーソナライズ栄養で最も実感が得やすい手法
- **完全栄養食**：1食で1日に必要な栄養素の1/3程度を満たすよう設計された食品
- **モバイルオーダー**：客のスマホから注文・決済する仕組み。レジ・ホールの人手を減らす
- **セルフオーダー端末**：卓上のタブレット等。外食の省人化で最も早く普及した
