# フードテック｜日本の食産業の課題との接続

このノートで分かること：**日本でフードテックが必要とされる理由は、世界の文脈（環境・人口増）とは違う**ということ。
世界は「増える人口をどう養うか」だが、日本は**「減る作り手でどう供給を保つか」**が課題である。

結論：日本におけるフードテックの本命は、代替タンパクや培養肉ではなく、
**人手不足の穴埋め（省人化）と、輸入依存リスクの軽減**である。
補助金や政策もそちらに寄っており、投資判断もその順で見るのが正しい。

## 1. 日本の食産業が抱える4つの構造問題

```
  ①人口減・高齢化          ②作り手の消滅              ③自給率の低さ
  国内の食の総需要が縮む     基幹的農業従事者            カロリーベース37%
  ↓                        2000年 240万人              （2025年度）
  「市場が伸びない中で      → 2025年 103.6万人          ↓
   コストだけ上がる」       平均年齢67.7歳              輸入が止まると
                           65歳以上が69.6%              代替手段がない
         ＼                      ／                         ／
          ＼                    ／                         ／
           ▼                  ▼                         ▼
        ④供給網の脆弱性：円安・資源高・地政学リスクが
          そのまま食品価格と調達可否に跳ね返る
```

### 数字で押さえる

| 指標 | 数値 | 年・出典 |
| --- | --- | --- |
| 食料自給率（カロリーベース） | **37%**（前年度から1ポイント低下） | 2025年度、農水省（2026年8月7日公表） |
| 食料自給率（生産額ベース） | **66%**（前年度から2ポイント上昇） | 同上 |
| 基幹的農業従事者 | **103.6万人**（2000年比 ▲56.8%） | 2025年、農水省 |
| 同 平均年齢 | **67.7歳**。65歳以上が69.6%、49歳以下は12.6% | 同上 |
| 飼料自給率 | 25%前後 | 近年の農水省公表値。**畜産の「国産」は輸入飼料に支えられている** |
| 食品ロス | 461万トン／経済損失 約3.8兆円 | 2024年度、農水省・環境省（2026年6月30日公表） |

> **カロリーベースと生産額ベースが逆方向に動く**のは、覚えておくと効く。
> カロリーベースは米・小麦・油脂など「重いカロリー源」の国産割合を見るので、
> 小麦・大豆・油糧作物・飼料を輸入に頼る日本では上がりにくい。
> 一方、野菜・果実・畜産物といった**高単価品は国産比率が高い**ので生産額ベースは高く出る。
> 「どちらが正しい」ではなく、**質問が違う指標**として使い分ける。

## 2. 自給率37%の中身を分解する

「37%」という数字だけでは何も分からない。品目ごとに見ると、どこが弱点かがはっきりする。

| 品目 | 自給率のおおよその水準（近年の農水省公表値） | 何が起きているか |
| --- | --- | --- |
| 米 | ほぼ100% | 唯一の自給品目。ただし消費量は長期的に減少 |
| 野菜 | 80%前後 | 加工・業務用は中国等からの輸入が多い |
| 果実 | 40%前後 | 輸入果実が定着 |
| 肉類 | 見かけ50%台／飼料を考慮すると10%前後 | **飼料の大半が輸入**。国産畜産＝輸入穀物の加工業という側面 |
| 魚介類 | 50%台 | 漁獲量の長期減少。→ [水産](../../08_食品・農水産・外食/11_水産/README.md) |
| 小麦 | 15%前後 | 米・カナダ・豪に依存 |
| 大豆 | 6%前後 | 食用は一部国産、油糧用はほぼ輸入 |
| 油脂類 | 3%前後 | **最も脆弱**。菜種・大豆・パーム由来 |

```
  【日本の食卓が輸入に依存している場所】

  ごはん   ██████████ 国産            ← ここだけ強い
  パン     █░░░░░░░░░ 小麦は輸入
  肉       ████░░░░░░ 見かけは国産でも飼料は輸入 ██░░░░░░░░
  油       █░░░░░░░░░ ほぼ輸入
  大豆製品 █░░░░░░░░░ 豆腐・納豆の原料も多くが輸入
  魚       █████░░░░░ 漁獲減で輸入依存が進む

  → 「自給率を上げる」＝実質的に「飼料・小麦・油糧作物をどうするか」の問題
```

**ここがフードテックとの接続点**。
代替タンパク・精密発酵・植物工場は、いずれも**「輸入に頼っている品目を国内で作る」候補**になりうる。
ただし現状のコストでは置き換わらないので、**当面は補完であって代替ではない**。

## 3. 人手不足：食の全工程で同時に起きている

食産業の人手不足は農業だけの話ではない。**川上から川下まで全部が同時に足りない**のが日本の特徴。

| 工程 | 何が起きているか | 効くフードテック |
| --- | --- | --- |
| 農業・漁業 | 従事者の高齢化と引退。新規就農が追いつかない | 自動操舵農機、ドローン防除、収穫ロボット、陸上養殖（少人数で回る） |
| 食品工場 | 現場作業者の確保難。外国人材への依存 | 検査自動化、ピッキングロボット、AI外観検査 |
| 物流 | 2024年問題（トラック運転手の時間外労働上限規制） | 共同配送、庫内自動化、需要予測による配車最適化 → [陸運・トラック](../../13_運輸・物流/06_陸運・トラック/README.md) |
| 小売 | レジ・品出しの人手 | セルフレジ、電子棚札、AI発注 → [食品スーパー](../../07_小売・流通/03_食品スーパー/README.md) |
| 外食 | 最も深刻。採用できず営業時間短縮 | 配膳ロボット、モバイルオーダー、セルフレジ、セントラルキッチン化 |

```
  【人手不足が価格に変わる経路】

  人が採れない ─▶ 賃金を上げる ─▶ 原価が上がる ─▶ 値上げ
       │                                            │
       └─▶ 採れないまま ─▶ 生産量／営業時間を減らす ─┘（供給が減っても値上げ）

  どちらの経路でも食品価格は上がる。
  → 省人化投資は「効率化」ではなく「事業を続けるための必須投資」になった
```

> これが**日本の省人化フードテックが確実に伸びる理由**。
> 「導入すると得」ではなく「導入しないと店を開けられない」という水準に来ている。
> だから配膳ロボットやモバイルオーダーは、代替タンパクと違って**採算が読める**。
> → [03_流通と消費のテクノロジー](03_流通と消費のテクノロジー.md)

## 4. 政策：日本は何に金を出しているか

| 施策 | 内容 | どこに効くか |
| --- | --- | --- |
| **みどりの食料システム戦略**（2021年策定） | 2050年までに化学農薬50%減、化学肥料30%減、有機農業25%（100万ha）などの目標。2022年にみどりの食料システム法 | スマート農業、バイオ農薬、代替肥料 |
| **スマート農業技術活用促進法**（2024年施行） | 技術の開発・供給と生産方式の転換を一体で認定・支援 | 農機・サービス事業者と農業者の橋渡し |
| **フードテック官民協議会**（農水省、2020年設立） | 代替タンパク、細胞性食品、フードロス等のルール整備と事業化支援 | 制度づくりとマッチング |
| **食料・農業・農村基本法の改正**（2024年） | 「食料安全保障」を法目的の中心に据える大きな転換 | 輸入依存の見直し、備蓄・生産基盤 |
| **食品ロス削減推進法**（2019年施行） | 2030年度までに2000年度比半減。事業系は先行達成 | 商慣行の見直し、フードバンク |
| **細胞性食品のルール整備** | 食品衛生基準審議会の新開発食品調査部会で審議中（2026年時点） | 培養肉の販売可否そのもの |

> 政策の重心が、2020年頃の「環境・持続可能性」から、
> 2024年以降は**「食料安全保障」と「担い手不足」**へ明確に移った。
> これは補助金の出どころが変わったということであり、**事業者の訴求ポイントも変わる**。
> 「環境にいい」より「国産化できる」「人が要らない」のほうが通る時代になった。

## 5. 日本で「効くフードテック」と「効かないフードテック」

課題との対応表にすると、投資判断の順序がはっきりする。

| 日本の課題 | 効くフードテック | 効き方 | 現実性 |
| --- | --- | --- | --- |
| 農業・漁業の担い手消滅 | 自動操舵農機、ドローン防除、陸上養殖、環境制御 | 1人あたり生産量を上げる | ◎ 進行中 |
| 外食・小売の人手不足 | 配膳ロボ、モバイルオーダー、AI発注 | 直接的な人件費削減 | ◎ 最も採算が読める |
| 物流の制約（2024年問題） | 共同配送、需要予測、庫内自動化 | 積載率と実車率を上げる | ○ |
| 食品ロス3.8兆円 | 商慣行見直し、AI需要予測、値引き自動化 | 廃棄原価＋処理費を削る | ○ 制度が先に効いた |
| 飼料の輸入依存 | 昆虫飼料、微生物タンパク飼料、飼料用米 | 魚粉・穀物の一部を置換 | △ 相場次第 |
| 油脂・小麦の輸入依存 | 精密発酵による油脂、国産小麦の品種改良 | 長期の話 | △ |
| 食肉の輸入依存 | 植物肉、培養肉 | コストが合えば | ✕ 現状は価格で負ける |
| 国内市場の縮小 | 輸出（日本食・和牛・水産物） | 需要側を海外に広げる | ○ 政策の重点 |

**この表の読み方**：
上の3行（人手不足系）は**今すぐ金になる**。下の3行（自給率系）は**10年単位の話**。
同じ「フードテック」でも時間軸がまったく違うので、混ぜて議論すると必ず噛み合わなくなる。

## 6. 日本固有の制約：なぜ海外のモデルがそのまま来ないか

| 制約 | 内容 | 帰結 |
| --- | --- | --- |
| **農地が細かい** | 圃場が分散し1枚が小さい。大型機械の稼働効率が上がらない | スマート農業の回収年数が長くなる。農地集積とセットでないと成立しない |
| **食への要求水準が高い** | 鮮度・見た目・味への基準が厳しい | 規格外品の発生が多い一方、品質で差別化した高付加価値化は成立しやすい |
| **新奇な食品への警戒** | 昆虫食の炎上に代表される忌避感。遺伝子組換えへの抵抗も強い | B2C型の代替タンパクは立ち上がりにくく、**B2B原料型のほうが現実的** |
| **規制の慎重さ** | 培養肉は承認枠組みが整備途上。海外が先行 | 国内企業が海外で先に上市する動きが出る |
| **エネルギー価格が高い** | 電力単価が欧米・アジアの一部より高い | 植物工場・陸上養殖・発酵の採算がその分厳しい → [電力](../../11_資源・エネルギー・鉄鋼金属/04_電力/README.md) |
| **人口減で市場が伸びない** | 国内需要そのものが縮む | 量を前提にしたコストダウンが効きにくい。輸出か高付加価値かの二択になる |

> まとめると、日本は**「フードテックが必要な理由は世界一はっきりしているのに、
> フードテックが儲かる条件（安い電力・大きい市場・新奇性への寛容さ）が揃っていない」**という国。
> だから、**人手不足という痛みが明確な領域から順に**実装されていく。

## 7. 結局どう見ればいいか

1. **「日本の食料安全保障のためにフードテック」という話は、飼料・小麦・油脂の話である**。肉の代替の話ではない
2. **短期に確実なのは省人化**。人件費との比較で計算できるものは必ず入る
3. **設備型（植物工場・陸上養殖・発酵）は電力単価に効かれる**。日本の電力価格の推移が採算の前提になる
4. **B2Cで新奇な食品を売るのは日本では難しい**。B2B原料か、既存商品の置き換えのほうが通る
5. **政策の重心は「環境」から「安全保障と担い手」へ移った**。補助金の建て付けを見ると事業機会の場所が分かる

## 用語メモ

- **食料自給率（カロリーベース）**：国民1人1日あたり供給熱量に占める国産の割合。飼料が輸入なら畜産物は国産と数えない
- **食料自給率（生産額ベース）**：食料の国内生産額が国内消費仕向額に占める割合。高単価な野菜・畜産が効くので高く出る
- **食料国産率**：飼料の国産・輸入を問わず国内生産を評価する指標。畜産の実態を見るときに併用する
- **飼料自給率**：家畜が食べる飼料のうち国産の割合。日本は25%前後
- **基幹的農業従事者**：普段の仕事として主に自営農業に従事する人。2025年で103.6万人、平均年齢67.7歳
- **農地の集積・集約化**：分散した農地を担い手にまとめる政策。スマート農業の採算の前提条件
- **みどりの食料システム戦略**：2021年策定。2050年までの環境負荷低減目標を掲げた農水省の長期戦略
- **食料・農業・農村基本法**：農政の基本法。2024年改正で「食料安全保障」が中心に据えられた
- **2024年問題**：トラック運転手の時間外労働上限規制により輸送力が不足する問題。食品物流を直撃する
- **セントラルキッチン**：複数店舗分の下処理・調理を集中して行う拠点。外食の省人化の基本形
- **規格外品**：形・大きさが基準を外れた農産物。味は同じでも流通しにくく、ロスの一因
