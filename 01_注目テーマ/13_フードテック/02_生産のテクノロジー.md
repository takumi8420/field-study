# フードテック｜生産のテクノロジー（植物工場・陸上養殖・スマート農業・精密発酵）

このノートで分かること：食べものを「屋内で作る」試みの**採算構造**。
どれも装置産業であり、**電力・餌・人件費のどれが効くか**で成否が分かれる。

結論を先に書くと、屋内生産は共通して次の式で決まる。

```
  利益 = （販売単価 － 変動費）× 生産量 － 固定費（設備償却＋人件費＋基本料金）
                ↑                    ↑              ↑
        一般品より高く売れるか    稼働率が命     一度建てたら逃げられない
```

**稼働率が落ちた瞬間に赤字**という点で、半導体工場と同じ性格を持つ。
→ 同じ構造の解説は [半導体｜前工程](../../03_電機・電子部品/02_半導体（ロジック・メモリ）/02_前工程.md) が分かりやすい

## 1. 植物工場：電気代がそのまま損益になる

### 2つの型を先に分ける

| 型 | 光源 | 建物 | 作れるもの | コスト特性 |
| --- | --- | --- | --- | --- |
| **人工光型（完全閉鎖型）** | LEDのみ | 断熱された建屋・多段棚 | 葉物（レタス・ハーブ）中心 | 電力が最大の変動費。天候に一切左右されない |
| **太陽光利用型（高度化温室）** | 太陽光＋補光 | ガラス・フィルム温室 | トマト・パプリカ・きゅうり等の果菜 | 暖房用の燃料費が効く。オランダ型が代表 |

日本で「植物工場」と言うときは前者を指すことが多い。以降は人工光型を中心に書く。

### コストの内訳（人工光型のイメージ）

```
  人工光型植物工場のランニングコスト構成（2026年時点の一般的な内訳イメージ）
  ┌───────────────────────────────────────────────────┐
  │ 電力（LED照明＋空調）  ████████████       25〜30%   │ ← 相場に直撃される
  │ 人件費（播種・収穫・包装）█████████████    30〜40%   │ ← 意外と自動化できていない
  │ 設備の減価償却          ████████          15〜25%   │ ← 逃げられない固定費
  │ 培養液・種苗・資材      ████               5〜10%   │
  │ 物流・包装              ███                5%前後   │
  └───────────────────────────────────────────────────┘
  ※業界メディア・事業者公表の複数情報からの目安。施設規模と作目で大きく変わる
```

意外に思われるのは、**人件費が電力と同等かそれ以上に重い**こと。
「工場」と名がつくが、実際には**収穫と包装が手作業**の施設が多い。
LEDの効率改善で電力は下がってきたが、人件費は最低賃金の上昇でむしろ増えている。

### なぜ4割が赤字なのか

日経新聞は2025年、**国内の植物工場のおよそ4割が赤字**で、工場産レタスが一般品の2倍の値段になるケースがあると報じた。
理由を分解すると、

1. **単価が上がらない**：レタスは代替が効く。一般品が安い時期には売れ残り、値引きを迫られる
2. **電気代は上がった**：燃料費調整額の上昇で、2021年頃と比べ電力単価が大きく上振れした
3. **稼働率を上げられない**：作った分を売る通年契約がないと、栽培棚を空ける＝固定費が丸ごと損になる
4. **設備投資が先行する**：建てた後に販路を探すと、償却だけが先に走る

> 教訓：植物工場は「技術で野菜を作る事業」ではなく、**「通年の定量契約を取って、その分だけ作る事業」**。
> 販路が先、設備が後。逆にやると必ず詰む。

### 失敗例：スプレッド（2024年）

- 2006年設立。京都府亀岡市などに人工光型の大規模レタス工場を持ち、業界の旗手とされた
- 一時黒字化したが赤字が常態化。**設備投資の先行と光熱費高騰**で資金が尽き、
  **2024年8月26日に民事再生法の適用を申請（負債約37億4,300万円）**。同年9月に再生手続開始決定
- その後、主要工場は他社へ譲渡され、事業自体は続いている

破綻の教訓として業界メディアが挙げるのは、**「市場拡大を優先し採算を二の次にした」**という一点に尽きる。

### 成功している側の条件

赤字と黒字を分けているのは、技術の優劣ではなく次の3つ。

| 条件 | 中身 |
| --- | --- |
| **販路の固定** | コンビニ・カット野菜メーカー・外食チェーンとの**通年・定量・定価**契約。天候で相場が動かない点こそが工場野菜の価値 |
| **電力調達の最適化** | 高圧契約への切替、新電力の活用、深夜電力の利用（照明時間を夜に寄せる）。電力調達の見直しで10〜15%改善の余地があるとされる |
| **高付加価値作目** | 低カリウムレタス（腎臓病患者向け）、機能性成分を強化したハーブ、医薬・化粧品原料の植物など。**一般野菜と価格比較されない場所へ逃げる** |

→ 電力契約の考え方は [電力](../../11_資源・エネルギー・鉄鋼金属/04_電力/README.md)／[新電力](../../11_資源・エネルギー・鉄鋼金属/05_新電力/README.md) を参照

## 2. 陸上養殖：餌代が原価の6〜7割という現実

陸上養殖は、海ではなく陸上のタンクで魚を育てる方式。主流は**RAS（閉鎖循環式陸上養殖）**で、
水を濾過・殺菌して循環させ、使う水を大幅に減らす。

```
  【RAS（閉鎖循環式）の水の流れ】

   飼育槽 ──▶ 固形物除去 ──▶ 生物濾過 ──▶ 脱気・殺菌 ──▶ 酸素供給 ──▶ 飼育槽
    ↑          （フン・残餌）  （アンモニア  （CO2抜き・  （純酸素）      │
    └───────────────────────────  を硝酸へ）   UV/オゾン）  ─────────────┘
                              ↑ここが止まると数時間で全滅する
                              → 電力の二重化・警報・自家発電が必須
```

### コスト構造

| 項目 | 目安 | 性格 |
| --- | --- | --- |
| 餌（飼料） | **原価の6〜7割** | 変動費。魚粉・魚油の国際相場に直撃される |
| 電力 | 10〜20% | ポンプ・冷却・酸素供給。**24時間止められない** |
| 設備の減価償却 | 大きい | 大型案件では初期投資数百億円規模 |
| 人件費 | 相対的に小さい | 海面養殖より少人数で回せる |
| 種苗（稚魚） | 変動 | サーモンは発眼卵の輸入に依存する例が多い |

**海面養殖に対する陸上養殖の強み**は、
①赤潮・台風・高水温の影響を受けない、②消費地の近くに作れて輸送コストと鮮度で勝てる、③薬剤使用を抑えられる。
**弱み**は、①初期投資が桁違い、②電力が止まれば全滅、③海が「タダで提供してくれていた水の循環と酸素供給」を電気で買うことになる。

> 要するに陸上養殖は、**「海が無料でやっていた仕事を、電気代を払って自前でやる」**事業。
> だから**輸送費の削減分と鮮度プレミアムが電気代を上回る魚種・立地でしか成立しない**。
> サーモン・エビ・ウナギのような高単価魚種に集中しているのはこのため。

### 日本の状況（2026年時点）

- 2026年の国内サーモン生産量は、過去最多だった前年からさらに1割程度増える見込みと報じられる
- 静岡県富士宮市ではノルウェー系のProximar Seafoodが出荷を開始
- 三重県津市では**世界最大級のアトランティックサーモン陸上養殖施設**が建設中。
  **総事業費約700億円とも報じられ、2027年末頃からの出荷開始を目指す**
- 2023年の改正漁業法関連で**陸上養殖が届出制の対象**となり、生産実態の把握が進んだ

**注意点**：世界では大型RAS案件の失敗も多い（生育不良、水質管理の失敗、稼働遅延）。
「大きく建てる」ほど、立ち上げ期の技術的トラブルが資金繰りを直撃する。
→ 海面養殖・漁業側の構造は [水産](../../08_食品・農水産・外食/11_水産/README.md)

## 3. スマート農業：ロボットではなく「人を減らす」ための道具

スマート農業は派手なロボットの話に見えがちだが、日本での実需は明確で、
**基幹的農業従事者が2000年の240万人から2025年に103.6万人へ、25年で約57%減った**（農水省）という
人手の消滅に対する対症療法である。

| 技術 | 何を減らすか | 普及度（2026年時点の体感） |
| --- | --- | --- |
| GPS自動操舵・自動運転トラクタ | 運転の熟練と労働時間 | ○ 大規模水田・北海道で実装が進む |
| ドローン防除 | 農薬散布の重労働 | ○ かなり普及。受託散布のサービス業も成立 → [ドローン](../08_ドローン/README.md) |
| 収穫ロボット | 収穫の人手（作業時間の3〜5割） | △ 品目限定。トマト・アスパラ等で実証段階 |
| 環境制御（温室のCO2・温度・かん水） | 経験と勘 | ○ オランダ型の高度環境制御が定着 |
| 営農管理SaaS・生育予測AI | 記録と計画の手間 | ○ 導入は進むが解約率が課題 |
| 収量予測・需給マッチング | 出荷ロスと価格変動 | △ データ量が足りない |

```
  スマート農業が刺さる順番（＝投資回収が早い順）

  1. 労働時間が長く単純な作業の代替   ← 自動操舵、ドローン防除    ◎ すぐ回収できる
  2. 経験の置き換え                   ← 環境制御、生育予測        ○ 数年で回収
  3. 器用さが要る作業の代替           ← 収穫ロボット              △ まだ人のほうが安い
  4. 経営全体の最適化                 ← 営農SaaS、需給予測        △ 効果が測りにくい
```

**採算が合う条件**は単純で、**削減できた労働時間×賃金 > 機械のリース料**。
農地が細かく分かれている日本では、1台あたりの稼働面積が稼げず回収年数が伸びる。
だから**農地の集積（規模拡大）とセットでないと、スマート農業は経済的に成立しにくい**。
2024年施行のスマート農業技術活用促進法も、技術導入と経営改善を一体で支援する建て付けになっている。
→ [農業・種苗・肥料](../../08_食品・農水産・外食/12_農業・種苗・肥料/README.md)、[農業機械](../../02_自動車・機械/08_農業機械/README.md)

## 4. 精密発酵：発酵槽の稼働率がすべて

精密発酵の生産現場は、**製薬のバイオ工場とほぼ同じ**。
タンク（発酵槽）に微生物と糖などの基質を入れ、温度・pH・酸素を管理して目的タンパク質を作らせ、精製する。

```
  【精密発酵の工程】

  遺伝子設計 ─▶ 菌株構築 ─▶ 種培養 ─▶ 本培養（発酵槽） ─▶ 分離・精製 ─▶ 乾燥・粉末
   （何を作らせるか）（酵母/菌）  （少量で増やす）   ↑              ↑
                                            ここの容量と      精製コストが
                                            稼働率が原価を    意外に重い
                                            決める           （食品用でも高純度が要る）
```

| コスト項目 | 性格 | 効かせ方 |
| --- | --- | --- |
| 発酵槽の減価償却 | 固定費 | **既存の製薬・アミノ酸工場を借りる（受託生産）**ことで初期投資を避けられる |
| 基質（糖など） | 変動費 | 砂糖・でんぷん糖の相場に依存。安価な糖源の確保が競争力 |
| 精製 | 変動費＋設備 | 目的タンパクを他の菌体成分から分けるコスト。**収率（力価）**が効く |
| 電力・用役 | 変動費 | 撹拌・温調・滅菌 |

**採算が合う条件**は、
①目的タンパクの**力価（培養液1Lあたり何g取れるか）**を十分に上げること、
②発酵槽を**遊ばせないだけの受注**があること、
③**既存原料の相場を下回る**こと。

逆にいえば、力価が低い段階で自社工場を建てると、**償却が乗った高原価の原料を売ることになり勝てない**。
初期は受託生産（CMO）を使う判断が合理的で、ここは医薬品のCDMOと同じ発想。
→ [CRO・CDMO](../../09_医薬・医療・ヘルスケア/03_CRO・CDMO/README.md)、[総合化学](../../10_素材・化学/01_総合化学/README.md)

## 5. 4手法を横並びで比較する

| | 植物工場（人工光） | 陸上養殖（RAS） | スマート農業 | 精密発酵 |
| --- | --- | --- | --- | --- |
| 初期投資 | 数億〜数十億円 | 数十億〜数百億円 | 1台数百万〜数千万円 | 自社建設なら数十億円／受託なら小 |
| 最大の変動費 | 電力 | 餌 | 燃料・保守 | 基質（糖） |
| 止まると | 数日で収穫ゼロ | **数時間で全滅** | 作業が遅れる | バッチが廃棄 |
| 競合相手 | 露地野菜の相場 | 海面養殖・輸入品 | 人の労働 | 既存原料の市況 |
| 勝ち筋 | 通年定量契約＋高付加価値作目 | 高単価魚種＋消費地近接 | 規模拡大とセット | 受託生産＋力価向上 |
| 典型的な負け方 | 販路なしで建てて償却倒れ | 立ち上げトラブルで資金ショート | 稼働面積が足りず回収できない | 力価が低いまま自社工場を持つ |

> 全部に共通する一文：**「作れる」ことと「採算が合う」ことの間には、稼働率という深い溝がある**。
> フードテックの生産技術のニュースを読むときは、必ず**「その設備は何%回るのか」**を問う。

## 用語メモ

- **人工光型植物工場（完全閉鎖型）**：外光を遮り、LEDだけで栽培する施設。天候の影響を受けないが電力が重い
- **太陽光利用型植物工場**：太陽光を主とし補光・環境制御を加える高度温室。オランダ型が代表
- **多段栽培**：棚を何段も積んで面積あたりの収量を上げる方式。植物工場の基本
- **RAS（Recirculating Aquaculture System）**：閉鎖循環式陸上養殖。水を濾過して再利用する
- **かけ流し式**：地下水や海水を汲み上げて使い捨てる陸上養殖。設備は安いが水源に依存
- **生物濾過**：微生物にアンモニアを硝酸へ変換させる工程。RASの心臓部
- **FCR（飼料要求率）**：魚を1kg太らせるのに必要な餌のkg数。低いほど効率が良い。養殖の収益性を決める最重要指標
- **魚粉・魚油**：養殖飼料の主原料。国際相場が原価を直撃する
- **基幹的農業従事者**：普段仕事として主に自営農業に従事している人。2025年で103.6万人、平均年齢67.7歳（農水省）
- **可変施肥（VRT）**：圃場内の場所ごとに施肥量を変える技術。センシングとセットで使う
- **発酵槽（ファーメンター／バイオリアクター）**：微生物を培養するタンク。容量と稼働率が原価を決める
- **力価（タイター）**：培養液1Lあたりに得られる目的物の量。精密発酵の原価を左右する
- **基質**：微生物の餌になる原料。糖が一般的
- **CMO／CDMO**：受託製造（＋開発）を請け負う事業者。自社工場を持たずに量産できる
