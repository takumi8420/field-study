# フードテック

- 大分類: 注目テーマ
- 状態: done
- 更新日: 2026-09-19

フードテックを一言でいえば、**「食べものを作る・運ぶ・食べるの各段階に、技術でコストか制約を1つ外そうとする試みの総称」**。
ひとつの産業ではなく、**代替タンパク・生産技術・流通技術・消費技術**という性格の違う4つの塊の寄せ集めである。

この分野を読むときの最大の注意点は、**期待が先に立ちすぎて、撤退と破綻が普通に起きる**こと。
植物肉は2022年をピークに売上が落ち、国内の植物工場は約4割が赤字（2025年、日経報道）、
国内最大級のレタス工場を運営していたスプレッドは2024年8月に民事再生を申請した（負債37.4億円）。
一方で、陸上養殖やフードデリバリー、外食の省人化のように**採算が合い始めた領域も確実にある**。

> このノート群の狙い：「すごい技術」の紹介ではなく、**どういう条件なら採算が合い、どこで合わなかったのか**を算数で押さえること。

## 1. 業界の定義・範囲

フードテックは、**食のバリューチェーン（生産→加工→流通→消費）のいずれかを、技術で置き換え・効率化しようとする事業領域**を指す。
業種分類ではなく「切り口」なので、含む／含まないの線を先に引いておかないと話が発散する。

| 含む | 含まない（隣接） |
| --- | --- |
| 代替タンパク（植物肉・培養肉・昆虫・精密発酵） | 従来型の食肉・加工食品 → [畜産・飼料](../../08_食品・農水産・外食/13_畜産・飼料/README.md)、[総合食品](../../08_食品・農水産・外食/01_総合食品/README.md) |
| 植物工場・陸上養殖・スマート農業 | 通常の露地農業・海面養殖 → [農業・種苗・肥料](../../08_食品・農水産・外食/12_農業・種苗・肥料/README.md)、[水産](../../08_食品・農水産・外食/11_水産/README.md) |
| フードデリバリー・受発注SaaS・需要予測 | 一般の物流網 → [宅配便](../../13_運輸・物流/07_宅配便/README.md)、[食品卸](../../06_商社・卸売/06_食品卸/README.md) |
| 外食の省人化（調理・配膳・オーダー） | 外食チェーンの運営そのもの → [ファストフード](../../08_食品・農水産・外食/14_ファストフード/README.md) |
| パーソナライズ栄養、完全栄養食 | 医薬品・特定保健用途の治療 → [健康食品・サプリメント](../../09_医薬・医療・ヘルスケア/13_健康食品・サプリメント/README.md) |

4つの塊は、**収益構造がまったく違う**。同じ「フードテック」という言葉で括ると必ず誤読する。

```
 ①代替タンパク     ②生産テクノロジー    ③流通テクノロジー   ④消費テクノロジー
 植物肉/培養肉      植物工場/陸上養殖     デリバリー/ロス削減   省人化/栄養
 ───────────      ───────────        ───────────       ───────────
 研究開発型         設備産業型            プラットフォーム型    店舗設備／SaaS型
 = 医薬品に近い     = 電力多消費の装置産業  = 両面市場、規模が命  = 投資回収年数で判断
 承認と単価が壁     電力単価と稼働率が壁    テイクレートが壁     人件費との比較が壁
```

## 2. 市場規模と成長性

| 指標 | 数値 | 年・出典 |
| --- | --- | --- |
| 世界のアグリフードテック投資額 | 約162億ドル（前年比ほぼ横ばい） | 2025年、AgFunder「Global AgriFoodTech Investment Report 2026」 |
| うち川上（農場・生産技術側） | 約90億ドル（前年比＋7%、件数は▲12%） | 2025年、同上。**金額は増えたが件数は減る＝選別が進んだ** |
| 世界の精密発酵乳製品 | 2025年 約32億ドル → 2026年 約45億ドル | TBRC（調査会社）の推計。年率40%超という高い前提に注意 |
| 日本のフードデリバリー | 約8,240億円 | 2025年、各社集計・推計ベース |
| 日本の食品ロス | 461万トン／経済損失 約3.8兆円 | 2024年度、農水省・環境省（2026年6月30日公表） |

## 3. バリューチェーン（川上 → 川下）

```
【川上：原料をつくる】          【中流：加工する】        【川下：届けて食べる】
 種苗・肥料・飼料 ─┐
 露地農業・畜産 ───┼─▶ 食品メーカー ─▶ 卸 ─▶ 小売／外食 ─▶ 消費者
 漁業・養殖 ──────┘        ↑                      ↑           ↑
                           │                      │           │
 [フードテックが入る場所]    │                      │           │
 ・植物工場 ────────────────┘（規格化された原料を安定供給）    │
 ・陸上養殖 ────────────────┘                                │
 ・スマート農業（人を減らす）                                   │
 ・代替タンパク ────────────▶ 原料として食品メーカーに売る       │
 ・精密発酵 ────────────────▶ 乳タンパク・油脂・香料を売る       │
 ・受発注SaaS／需要予測 ──────────────────▶ 卸・小売の在庫を減らす│
 ・デリバリー／ゴーストキッチン ───────────────────────────────┘
 ・省人化ロボット／モバイルオーダー ───────────────────────────┘
 ・パーソナライズ栄養 ─────────────────────────────────────▶ 消費者に直接
```

付加価値が集まるのは、**「既存プレイヤーのコストを実際に下げた場所」**だけ。
消費者に新しい体験を提案するタイプ（植物肉、パーソナライズ栄養）は、
**既存品との価格差を消費者が負担してくれるか**という一点で生死が決まり、多くが負けた。

## 4. 主要プレイヤーとシェア

分野がバラバラなので、企業一覧より**「どの類型か」**で整理したほうが役に立つ。

| 類型 | 代表例 | 立ち位置・特徴 |
| --- | --- | --- |
| 植物肉（海外） | Beyond Meat、Impossible Foods（米） | ブームの主役。Beyond Meatは2026年1〜3月期に売上が前年同期比▲15%、営業利益率▲70.6%と報じられ、再建途上 |
| 植物肉（国内） | 大豆ミート各社（不二製油、大塚食品、伊藤ハム米久 ほか） | 既存の食品会社が**本業の一製品ライン**として手掛ける形が主流。専業ベンチャーは少ない |
| 培養肉 | Upside Foods、GOOD Meat（米）、Mosa Meat、Meatable（欧）、インテグリカルチャー（日） | 承認済みは米・シンガポールのみ。欧州・英国は審査中（2026年時点）。**量産コストが最大の壁** |
| 精密発酵 | Perfect Day、Vivici（欧米） | 微生物に乳タンパク等を作らせる。**B2B原料**として売るので消費者の抵抗を受けにくい |
| 昆虫 | Ynsect（仏）、グリラス（日） | 食用より**飼料・ペットフード用途**に軸足が移った |
| 植物工場 | スプレッド（2024年に民事再生）、プランツラボラトリー、キーストーンテクノロジー ほか | 国内約4割が赤字（2025年報道）。生き残りは**電力契約と販路**を握れた事業者 |
| 陸上養殖 | Proximar Seafood（静岡）、三重県津市の大型案件（2027年末出荷目標、総事業費約700億円と報じられる） | 大型投資が相次ぐ段階。**餌代が原価の6〜7割**という水産の常識は変わらない |
| スマート農業 | クボタ、ヤンマー、井関（自動運転農機）、各種営農SaaS | 既存の農機メーカーが本命。→ [農業機械](../../02_自動車・機械/08_農業機械/README.md) |
| デリバリー | Uber Eats、出前館、Wolt、Rocket Now | 日本ではUber Eatsと出前館で利用率の9割超（2026年、各種調査）。**Uber Eatsは黒字、出前館は赤字継続** |
| 外食の省人化 | 配膳ロボット（Pudu、Keenon 等）、モバイルオーダー各社 | すかいらーくの大量導入以降、普及が加速。導入済み省人化設備では配膳ロボットが最多 |

## 5. 収益モデル・コスト構造

| 領域 | 何で儲けるか | コストの中心 | 採算が合う条件 |
| --- | --- | --- | --- |
| 植物肉 | 加工食品として1パックいくら | 原料（分離大豆タンパク等）と**押出成形の加工費** | **畜肉と同価格かそれ以下**になること。現状は多くが1.5〜2倍 |
| 培養肉 | まだ商業規模の売上がほぼない | **培地（細胞の餌）**と培養槽の設備償却 | 培地コストを数桁下げること＋各国の販売承認 |
| 精密発酵 | B2Bの原料販売（kgいくら） | 発酵槽の稼働、糖などの基質 | 既存の乳タンパク・油脂の相場を下回るか、機能で差別化できるか |
| 植物工場 | 野菜1株いくら（契約栽培中心） | **電力（ランニングの25〜30%）と人件費**、設備償却 | 一般野菜の1.3倍以内に価格を収め、かつ**通年契約の販路**を持つこと |
| 陸上養殖 | 魚1kgいくら | **餌代（6〜7割）**＋ポンプ・水温管理の電力＋設備償却 | 高単価魚種（サーモン・エビ等）＋輸送コストの削減分で海面養殖に勝つこと |
| デリバリー | 飲食店からの手数料（テイクレート）＋配送料＋広告 | 配達員への報酬（変動費）、獲得販促費 | **1注文あたりの粗利 > 配達コスト**。注文密度が上がるほど配達1件の距離が縮み黒字化する |
| 外食の省人化 | 設備販売／月額リース | 機体・保守 | **削減できた人件費 > 機体コスト**。配膳ロボは本体150〜300万円、レンタル月7〜10万円が目安（2026年時点の相場） |

> 分野をまたぐ共通の教訓：**「環境にいい」「健康にいい」は価格プレミアムをほとんど生まない**。
> 2020〜2022年はESGマネーがその差額を埋めていたが、金利上昇で資金が引いた瞬間、
> 価格で勝てない事業から順に消えた。**採算は理念ではなく算数で決まる**。

## 6. 競争要因（KSF）と参入障壁

**KSF**
1. **既存品との価格差をゼロに近づけられるか**。これが最大かつほぼ唯一の関門
2. **原料・エネルギーの調達力**。植物工場なら電力契約、陸上養殖なら餌、培養肉なら培地
3. **販路（アンカー顧客）**。コンビニ・スーパー・外食チェーンとの通年契約があるかどうかで稼働率が変わる
4. **規制の通過**。培養肉・新規食品は各国の承認が必要で、通過そのものが資産になる
5. **稼働率**。設備型（植物工場・陸上養殖・発酵槽）はすべて、**止まった瞬間に赤字**になる装置産業

**参入障壁**
- 設備型：初期投資（植物工場で数億〜数十億円、大型陸上養殖で数百億円規模）と、回収に10年級かかる時間
- 代替タンパク：食品安全の承認、特許、そして**味と食感を作る加工技術のノウハウ**
- プラットフォーム型：両面市場（店舗と利用者）の鶏卵問題。先行者の注文密度に後発は勝ちにくい
- 逆に**障壁が低いのは植物肉**。既存の食品メーカーが同等品を短期間で出せてしまい、専業の優位が保てなかった

## 7. 規制・法制度

| 制度・領域 | 内容 |
| --- | --- |
| 食品衛生法（日本） | 新しい食品は食品衛生基準審議会で安全性を審議。**培養肉（細胞性食品）は2026年時点で販売承認の枠組みが整備途上**で、試食にも制約がある |
| 新規食品（Novel Food）規制 | EU・英国は新規食品として個別審査。Mosa Meat等が申請中（2026年時点） |
| 米国 | FDAの上市前相談＋USDAの検査で販売可能に。ただし**州レベルで禁止する動き**（フロリダ、アラバマ、2025年7月にミシシッピ）があり国内で割れている |
| シンガポール | 2020年に世界で初めて培養肉の販売を承認。食料自給率の低さを背景に国策として推進 |
| 表示規制 | 「肉」「ミルク」などの名称を代替品に使えるかで各国が争点化。日本では大豆ミートのJAS規格が2022年に制定 |
| 食品ロス削減推進法（日本、2019年施行） | 2030年度までに食品ロスを2000年度比で半減させる目標。事業系は先行して達成 |
| 超加工食品（UPF）をめぐる動き | 米FDA・USDAが定義策定に着手、フランスでは規制法案の準備が進むと報じられる（2026年）。**植物肉にとっては逆風** |
| 補助金 | 日本は「フードテック官民協議会」（農水省）、みどりの食料システム戦略、スマート農業技術活用促進法（2024年施行）など |

## 8. 最近のトピック

詳細は [05_直近トピック_2026](05_直近トピック_2026.md) を参照。要点だけ5行で。

1. **投資は横ばいだが中身が変わった**：2025年の世界アグリフードテック投資は約162億ドルで前年並み。件数は減り、実売上のある川上側に資金が寄った
2. **植物肉は「終わった」のではなく「リセット」**：Beyond Meatの苦境が続く一方、既存食品メーカーの製品ラインとしては残った。争点は価格と超加工食品批判
3. **培養肉は規制で地域差が鮮明**：米・シンガポールは承認済み、欧英は審査中、米国内では州単位の禁止法という逆流も
4. **植物工場は淘汰期**：スプレッドの民事再生（2024年）後、工場が他社へ譲渡され再編が進む。電気代がそのまま損益になる構造は変わらない
5. **省人化とデリバリーは実利フェーズ**：人手不足という具体的な痛みに直結しており、採算が読める数少ない領域

## 9. 用語メモ

各ノート末尾の「用語メモ」に分散して置いている。最初に押さえるべき5語だけここに。

- **代替タンパク（オルタナティブプロテイン）**：家畜・魚由来でないタンパク源の総称。植物・培養・昆虫・微生物の4系統 → [01_代替タンパク](01_代替タンパク.md)
- **精密発酵**：微生物に特定のタンパク質（乳タンパクなど）を作らせる技術。ビールの発酵と違い**狙った1種類の分子を作らせる**のが肝 → [01_代替タンパク](01_代替タンパク.md)
- **植物工場（人工光型）**：閉鎖空間でLED照明と空調により通年栽培する施設。電気代が損益を直撃する → [02_生産のテクノロジー](02_生産のテクノロジー.md)
- **テイクレート**：プラットフォームが取引額から受け取る手数料の比率。デリバリーでは飲食店から3割前後 → [03_流通と消費のテクノロジー](03_流通と消費のテクノロジー.md)
- **超加工食品（UPF）**：工業的に高度加工された食品を指す分類（NOVA分類の第4群）。植物肉の多くがここに分類され、健康イメージの前提が揺らいだ → [01_代替タンパク](01_代替タンパク.md)
