# 自動運転｜事業としての自動運転（採算・展開・用途）

**このノートで分かること**：自動運転は誰が・どこで・どうやって稼ぐのか。
ロボタクシー1台の損益の中身、遠隔監視という「消えていない人件費」、
そして**一番早く商売になったのはロボタクシーではなく鉱山と農地だった**という事実。

結論を先に言う。自動運転の事業性は**「ドライバーの人件費を、車両の減価償却と遠隔監視の人件費に置き換える取引」**である。
置き換えが割に合うかは、**①車両がいくらか ②オペレータ1人で何台見られるか ③1台を1日何時間動かせるか**の3つで決まる。
この3つが揃うのは、いまのところ**稼働率を極端に上げられる用途（タクシー・幹線トラック）か、ODDが閉じた用途（鉱山・農地・工場）**だけである。

## 1. ロボタクシー1台の損益を分解する

まず比較対象として、人が運転するタクシーの構造を置く。

```
【人が運転するタクシー】             【ロボタクシー】

 売上 100                             売上 100
  ├ 乗務員人件費（歩合）  55〜60        ├ 車両の減価償却        20〜35
  ├ 燃料・電気             8〜12        ├ 遠隔監視の人件費       5〜15
  ├ 車両償却・整備         8〜12        ├ デポ運営（清掃・充電・  10〜20
  ├ 保険・車庫・管理費     8〜12        │  整備・待機場所の地代）
  └ 営業利益            数%〜10%        ├ 電気代                 5〜8
                                        ├ 保険                   ?（実績不足で高止まり）
 ★人件費が過半。台数を増やすには        ├ 地図維持・通信・クラウド 数%
   乗務員を増やすしかない               └ 営業利益           理論上は厚いが
                                                            現状は都市単位で赤字

 ★構造の違い：人件費（変動費）が、車両とデポ（固定費）に置き換わる
   → **稼働率が落ちた瞬間に赤字**になる装置産業型の損益に変わる
```

> ここが最大のポイント。**タクシーは人件費が変動費なので、暇なら乗務員を帰せば損は止まる。
> ロボタクシーは車両の減価償却が固定費なので、暇でも金が出ていく。**
> よって「深夜も雨の日も走らせられる」ことが、事業として決定的に効く。

### 実際の数字（2026年時点、報道・企業発表ベース）

| 指標                      | 数値                                                                                   | 出どころ              |
| ------------------------- | -------------------------------------------------------------------------------------- | --------------------- |
| Waymoの年換算売上（ARR）  | 約3億5,500万ドル（2026年2月時点。2025年末は約2億8,400万ドル）                          | 調査会社Sacraの集計   |
| 同・稼働車両数            | 約3,000台（2026年2月時点）→ 約4,000台（2026年9月時点）                                 | 報道ベース            |
| 1台あたり年間売上（逆算） | **約1,100〜1,200万円／台・年**（1ドル150円換算の粗い推計）                             | 上2行からの筆者推計   |
| 1回あたり平均運賃         | 約15〜17ドル                                                                           | 調査会社推計          |
| 遠隔支援オペレータの比率  | **約1:43**（オペレータ約70人で約3,000台、2026年2月時点）                               | Waymo公表値を引く報道 |
| 同・中国勢                | Pony.aiが1:20を開示、2025年末に1:30を目標と報じられる。中国の規制は長く1:3を求めていた | 報道ベース            |

**1台あたり年商1,100万円**という水準は、日本の法人タクシー1台（乗務員2〜3人で回して年間2,000万円前後）と比べると
まだ低い。**24時間動かせる利点を、都市の広さと需要密度がまだ埋められていない**段階と読める。

### 遠隔監視比率が事業の生死を決める理由

```
 オペレータ1人あたりの人件費を年800万円（3交代前提で1席あたり約2,400万円／年）とすると

   1:3  の場合 → 1台あたり年 800万円の人件費 ＝ **人を乗せているのと同じ**。事業にならない
   1:20 の場合 → 1台あたり年 120万円
   1:43 の場合 → 1台あたり年  56万円 ← 年商1,100万円に対して約5%。ようやく無視できる水準
   1:100 の場合→ 1台あたり年  24万円 ← 目指す先
```

> **「無人運転」は人件費をゼロにしない。1/40 くらいにする技術である。**
> 中国勢が当局から1:3を求められていた時期に赤字が膨らんだのは、この算数のため。
> ニュースで「無人化に成功」と読んだら、**次に探すべき数字は台数ではなく遠隔監視の比率**。

## 2. 車両コストという重し

| 項目                     | 実情（2026年時点）                                                                                                                            |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------- |
| ロボタクシー用車両の単価 | 量産乗用車＋センサ・演算・冗長化で、**1台1,000万円超**とされてきた（推計）。Waymoは第5世代でJaguar I-PACEを使用                               |
| 低価格化の動き           | Waymoは中国Zeekr車体の採用や、新型「Ojai」の投入を進め、**年5,000台規模の導入ペース**へ移行すると報じられる。センサの自社内製化も価格低減の柱 |
| LiDARの値下がり          | 中国Hesaiは約200ドル（約3万円）のADAS向けLiDAR「ATX」を投入。2026年上半期のLiDAR出荷は約110万台（前年同期比＋100.8%）                         |
| 冗長化のコスト           | レベル4は操舵・制動・電源・演算をすべて二重化する必要があり、**ここが量産乗用車との価格差の主因**                                             |
| 償却年数                 | 車体は5〜7年でも、**センサ・演算ユニットは技術更新が速く3〜4年で陳腐化**する。実質的な償却は短い                                              |

車両コストは**技術の問題ではなく量の問題**である。年5,000台と年50万台では部品単価が桁で違う。
だから各社は「ロボタクシー専用車を量産する」方向（TeslaのCybercab構想、中国勢の専用車）へ向かっている。
一方で**専用車は量産に乗るまで赤字を垂れ流す**ので、既存量産車の改造から入るのが現実解になっている。

## 3. 地域展開は「面」ではなく「都市単位の積み上げ」

ソフトウェアなのに展開が遅いのは、**1都市の立ち上げが土木工事に近い**から。

```
【新しい都市に入るまでにやること】

 ① 当局・警察・消防と協議         数か月〜1年（事故時の対応手順、緊急車両への譲り方）
 ② 高精度地図の作成               専用計測車で全道路を走る
 ③ 現地データでの学習・評価       その街固有の運転作法（合流の荒さ、二重駐車の多さ）
 ④ 安全監視員つきで試験走行       数か月〜1年
 ⑤ 従業員限定の無人走行           数か月
 ⑥ 一般客の無人商用運行           ← ここでようやく売上が立つ
 ⑦ デポ（車庫）の確保             充電設備・清掃・整備・待機スペース。都心の地代が効く

  ┌────────────────────────────────────────────────┐
  │ Waymo：フェニックス（2020年）→ SF → LA → ...     │
  │  → 2026年9月に14都市／約4,000台と報じられる      │
  │  1都市目に10年。14都市目は数か月。**逓減はする** │
  └────────────────────────────────────────────────┘
```

> 「立ち上げコストは都市ごとにかかるが、回を追うごとに安くなる」——
> この**学習曲線がどこまで下がるか**が、ロボタクシー企業の企業価値の中身そのものである。
> 逆にいえば、**1都市目のコストで企業価値を評価してはいけない**し、
> **14都市目の速度で「もうどこでも走れる」と考えてもいけない**。

## 4. 用途別の事業性：早い順に並べる

自動運転が商売になった順番は、**ODDが閉じている順**であって、技術の高度な順ではない。

| 用途                               | ODDの閉じ具合                                      | 事業の現在地                                                                                                                          | 経済的な理由                                                                                         |
| ---------------------------------- | -------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| **鉱山（無人ダンプ）**             | 完全に閉じる（私有地・一般車なし・決まったルート） | **20年以上前から商用**。コマツのAHS（無人ダンプ運行システム）は世界の鉱山で稼働                                                       | 24時間無休で動かせて、人件費（僻地手当込み）が極端に高い。投資回収が明快                             |
| **工場・倉庫内（AGV/AMR）**        | 完全に閉じる                                       | 商用として確立                                                                                                                        | 詳細は [ロボット](../09_ロボット/README.md)・[倉庫・3PL](../../13_運輸・物流/08_倉庫・3PL/README.md) |
| **農機（自動操舵・無人トラクタ）** | ほぼ閉じる（自分の圃場）                           | **商用。クボタ・ヤンマー・John Deereが販売中**                                                                                        | 作業精度が上がって収量が増える＝**安全と関係なく金になる**。RTK測位で数cm精度                        |
| **港湾・空港の構内車両**           | 閉じる                                             | 中国・欧州の自動化ターミナルで実装                                                                                                    | 同上。決まったルートの反復                                                                           |
| **高速道路の幹線トラック**         | 半分閉じる（歩行者・自転車がいない）               | **2026年に米国で無人商用が始動**。Auroraがダラス〜ヒューストン間で週7日の完全無人輸送（荷主はMcLane）。Kodiakは2026年Q1で顧客所有28台 | 長距離運転は労働時間規制で1人あたりの稼働に上限がある。**車が休まないだけで経済性が出る**            |
| **ロボタクシー（都市）**           | 開いている（歩行者・自転車・工事・雨）             | 米・中で商用。**都市単位ではまだ赤字**とみられる                                                                                      | 需要密度が高く運賃が取れる。ただし難易度が最も高い                                                   |
| **地域路線バス・コミュニティ交通** | 半分閉じる（決まったルート）                       | **日本の主戦場。だがほぼ補助金事業**                                                                                                  | 赤字路線を無人化するので、**元から運賃で成り立っていない**。自治体予算が原資                         |
| **ラストワンマイル配送**           | 開いている（歩道・私道）                           | 米中で実証〜小規模商用                                                                                                                | 1件あたり単価が低く、車両代を割りにくい                                                              |

```
【縦軸：技術の難しさ／横軸：事業として成立した時期】

 難しい ▲
        │                                      ロボタクシー（都市）●
        │                                    ／
        │                      幹線トラック●
        │              地域バス●（補助金）
        │        港湾・空港●
        │   農機●
        │ 鉱山●
 易しい └──────────────────────────────────────────────▶
        2000年代        2020年代前半        2020年代後半

 ★「ODDが閉じているほど早く商売になる」という一本の線に、きれいに乗る
```

## 5. 日本固有の事情：人手不足が需要をつくる

日本で自動運転が政策的に推されるのは、**需要が「便利さ」ではなく「担い手不在」から来ている**から。

| 分野               | 何が起きているか                                                                                                                 |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------- |
| **バス・タクシー** | 乗務員の高齢化と減少で、**路線の減便・廃止が全国で進行**。運転できる人がいないから走れない、という状態                           |
| **トラック**       | いわゆる2024年問題（時間外労働の上限規制）で輸送力不足。詳細は [陸運・トラック](../../13_運輸・物流/06_陸運・トラック/README.md) |
| **地方の移動**     | 高齢者の免許返納と公共交通の撤退が同時に起きる                                                                                   |
| **政策目標**       | 政府は地域限定型の無人自動運転移動サービスを**2025年度目処に50か所程度、2027年度までに100か所以上**とする目標を掲げてきた        |

> だから日本のレベル4は**都市のロボタクシーではなく、地方の低速バス・カートから始まった**。
> 永平寺町（2023年、国内初の特定自動運行許可）、ひたちBRT、柏の葉の中型バス（2026年1月運行開始）はいずれもこの系譜。
> **採算ではなく「運転手がいない路線をどう維持するか」が事業目的**なので、
> 民間のロボタクシーとは評価軸が違う。ここを混ぜて読むと話が通らなくなる。

一方で**都市部のロボタクシーも2026〜2027年に動き出す**。
Waymo・GO・日本交通が2026年9月に提携合意し、**2027年中に完全無人の商用運行**を目指す（段階的に100台規模）と報じられる。
日産はティアフォーと共同開発したシステムで横浜の実証（最大20台規模、2025〜2026年度）を経て2027年度のサービス開始を目標とする。

## 6. 誰が儲けるのか：レイヤー別の取り分

```
 【レイヤー】            【誰がいる】                  【付加価値】

 ① 半導体・センサ    NVIDIA、Hesai、ソニー（CMOS）     高い。だが値下げ圧力も強い
      ↓
 ② Tier1 部品        ボッシュ、デンソー、コンチネンタル 中。冗長ブレーキ・操舵で不可欠
      ↓
 ③ 自動運転ソフト    Waymo、ティアフォー、Momenta、     **ここが価値の源泉だが
                     Wayve、Pony.ai、Mobileye           まだ誰も黒字化していない**
      ↓
 ④ 車両製造          完成車メーカー、Zeekr等            低い。「箱を作る側」に回ると薄利
      ↓
 ⑤ 運行（フリート）  Waymo、GO・日本交通、newmo         デポ・整備・保険・オペレータ
      ↓
 ⑥ 配車プラット      Uber、Lyft、GO、DiDi               需要側を握る。**自前の車を持たずに
    フォーム                                              手数料を取れる強い位置**
      ↓
    乗客
```

構図として重要なのは、**③（ソフト）と⑥（配車アプリ）のどちらが主導権を取るか**という争い。

- Waymoは③④⑤を垂直統合し、⑥は自社アプリ＋提携（東京ではGOアプリ経由）で確保しようとしている
- Uberは③を持たず、**複数のAV事業者を載せる場**になることで⑥の位置を守ろうとしている
- 日本では**GO・日本交通のようなタクシー配車側が、AV事業者を呼び込む側**に立っている

> 覚えておくとよい対比：**自動運転は「車の産業」ではなく「稼働率の産業」に変わる。**
> 車を作って売る商売（一発の粗利）から、車を持って動かす商売（日々の稼働率）へ移る。
> だから既存の完成車メーカーにとっては、得意な工程が増えるのではなく**別の商売を始めろと言われている**に等しい。
> 詳細は [自動車（完成車）](../../02_自動車・機械/01_自動車（完成車）/README.md) と [EV・電動化](../03_EV・電動化/README.md) にも通じる。

## 用語メモ

- **ユニットエコノミクス**：1単位（ここでは1台、または1回の乗車）あたりの収支。事業全体の黒字より先にここが合うかを見る
- **ARR（年換算売上）**：直近の月次売上を12倍した年間換算値。成長企業の規模感を示すのに使われる
- **稼働率**：車両が実際に売上を生んでいる時間の割合。固定費型の事業では利益に直結する
- **実車率**：タクシー業界の指標で、走行距離のうち客を乗せていた割合。ロボタクシーでも同じ問題（空車回送）が起きる
- **デポ**：ロボタクシーの拠点。充電・清掃・整備・待機を行う。**都心の地代がコストとして効く**
- **遠隔支援（Remote Assistance）**：センターから車両に助言・許可を出す運用。完全な遠隔運転とは区別される
- **オペレータ比率**：遠隔オペレータ1人が同時に受け持つ車両数。1:43など。**事業性の最重要KPI**
- **AHS（Autonomous Haulage System）**：鉱山の無人ダンプ運行システム。コマツなどが供給。自動運転の商用化第1号
- **AGV / AMR**：工場・倉庫内の無人搬送車（AGVは決まった経路、AMRは自律的に経路を決める）
- **RTK測位**：基準局の補正情報で衛星測位の誤差をcm級に縮める方式。農機の自動操舵の基盤
- **隊列走行**：先頭を有人トラックが走り、後続が電子的に追従する運用。後続の無人化を狙う
- **2024年問題**：トラック運転者の時間外労働に上限規制が入り、輸送力が不足する問題
