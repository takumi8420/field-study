自動運転

学習済み更新 2026-09-20注目テーマ
あこのページの単語集用語に触れると意味を確認できます9語
ロングテールを潰す速度遠隔監視比率都市立ち上げの学習曲線当局・地元との関係需要側の接点車両を安く大量に確保できるか極めて高いやや低い低い

一言でいえば、「運転という労働を、車両の減価償却と遠隔監視の人件費に置き換える産業」。
技術の話に見えて、実態は人件費の付け替えが割に合うかどうかという算数であり、
だから稼働率を極端に上げられる用途（タクシー・幹線トラック）と、走る条件が閉じた用途（鉱山・農地）からしか成立しない。

もう1つ、この業界を読むうえで絶対に外せない区別がある。デモと商用運行はまったく別物だということ。
「自動運転が走った」というニュースは、①期間限定の実証、②安全監視員が同乗する営業運行、
③車内無人＋遠隔監視の商用運行、のどれかを指しているが、この3つは難易度が桁で違う。
台数・地域・監視者の有無を確認せずに読むと、業界の現在地を必ず読み違える。

そして最後に、レベル2とレベル3のあいだには技術ではなく法律の断層がある。
レベル3を名乗った瞬間、事故の責任がメーカー側へ移る。だが売価はほとんど上がらない。
この非対称が、「センサはどんどん良くなるのに、車はレベル2のまま」という2026年の風景を作っている。

1. 業界の定義・範囲

「自動運転」とは、運転操作（認知・判断・操作）の一部または全部を機械が代替する技術と、それを使ったサービスの総称。
ただし業界として語られるときは、運転支援（ADAS）を売る部品産業と、運転者なしで運行するサービス産業という、
経済構造がまったく違う2つが同じ名前で呼ばれている。

含む 含まない（隣接）
自動運転ソフトウェア（認識・予測・計画）車体そのものの製造 → 自動車（完成車）
車載センサ（カメラ、LiDAR、ミリ波レーダー）動力系の電動化 → EV・電動化
車載演算ユニット・ADAS用ECU半導体の製造そのもの → 半導体・先端半導体
高精度地図・測位インフラカーナビ用の一般地図
ロボタクシー・自動運転バスの運行事業人間が運転するタクシー・バス → タクシー・バス
自動運転トラック・隊列走行倉庫内の搬送ロボット → ロボット
鉱山・農地・港湾の無人車両空の自律機 → ドローン・空飛ぶクルマ

境界が曖昧な2か所がある。
①ADASと自動運転（技術は連続しているが、責任の所在が違うので制度上は断絶している）、
②配車プラットフォーム（Uber・GOなどは車も技術も持たないが、需要側を握るので取り分が大きい）。
とくに②は、「自動運転の勝者＝AI企業」とは限らないという意味で重要。

2. 市場規模と成長性

自動運転は市場規模の数字が最も当てにならない分野である。定義次第で2桁ぶれる。

Waymoの稼働台数約3,000台 → 約4,000台2026年2月 → 2026年9月、報道ベース

総額の予測より、実物の量で見るほうが正確。
ロボタクシーは台数・都市数・累計走行距離・遠隔監視比率、ADASはセンサ出荷台数と単価で追う。
「2030年に◯兆円市場」という数字はほぼすべて調査会社の推計であり、ADASを含むか、車両価格を含むかで別物になる。

規模で見れば、2026年時点のロボタクシー産業は世界全体で年商1,000億円に届くかどうかという段階。
日本のタクシー業界（年間1兆円超）と比べても、まだ桁が2つ小さい。
巨額の期待と、極小の実売の落差が、この産業の現在地である。

構図の要点は2つ。

この産業の最大のクセ：「無人化」は人件費をゼロにしない。1/40くらいにする技術である。
遠隔オペレータ1人が何台見られるかで採算が決まり、1:3では人を乗せるのと変わらない。
だから遠隔監視比率は、台数よりも重要な事業KPIである。詳細は 03_事業としての自動運転。

6. 競争要因（KSF）と参入障壁

KSF

  1. ロングテールを潰す速度：珍しい場面のデータをどれだけ集め、どれだけ速く学習に反映できるか。走行距離がそのまま資産になる
  2. 遠隔監視比率：1:3か1:43かで損益が反転する。介入が必要な場面をどれだけ減らせるかの勝負
  3. 都市立ち上げの学習曲線：1都市目のコストをどこまで下げられるか。ここが企業価値の中身そのもの
  4. 当局・地元との関係：警察・消防・道路管理者・住民。1件の事故で許可が消える構造なので、信頼の蓄積が資産になる
  5. 需要側の接点：配車アプリを持つか、持つ相手と組めるか。技術があっても客が呼べなければ稼働率が上がらない
  6. 車両を安く大量に確保できるか：センサ込みで1台1,000万円級（推計）の車両を、どれだけ安く積み増せるか

参入障壁

  • 極めて高い：ロボタクシーは、数千億円規模の累積投資と10年単位の走行実績がないと商用に届かない。新規参入はほぼ不可能
  • やや低い：ADAS向けセンサ・ソフトは、量産車に採用されれば一気に数が出る。中国勢の台頭はここから起きた
  • 低い：限定区間の低速サービス（構内カート、地域バス）は既存システムを買って運用できる。ただしそこに大きな利益はない

結果として業界は二極化している。都市ロボタクシーは数社の寡占、
限定区間サービスは多数の小規模事業者＋補助金という構造になる。

7. 規制・法制度

制度 内容
道路運送車両法（国交省）クルマ（モノ）の基準。2019年改正（2020年4月施行）で自動運行装置を法律上定義し、作動状態記録装置の搭載を義務化、ソフト改変（OTA更新）を許可制にした
道路交通法（警察庁）走らせ方の規律。2019年改正でレベル3を解禁（作動中のスマホ注視等を条件付きで容認）。2022年改正・2023年4月施行で「特定自動運行」の許可制度を新設
特定自動運行の許可運転者なしの運行には都道府県公安委員会の許可が必要。ルート・時間帯・ODD、特定自動運行主任者による遠隔監視、事故時の対応体制、関係機関との調整、住民周知が審査される
自賠法（自動車損害賠償保障法）事故の賠償は運行供用者責任が原則。まず所有者・事業者側の保険で被害者を救済し、欠陥があれば保険会社がメーカーへ求償する
製造物責任法（PL法）ソフトの欠陥による責任の根拠。プログラム単体は「製造物」に当たらないとされるが、組み込まれた車両は対象
UN-R157（ALKS）／WP.29国連の自動車基準。レベル3の高速道路走行の国際基準。2022年改訂で上限130km/hまで拡張。日本も国内基準に取り込む
米国車両基準は連邦（NHTSA／FMVSS）、運行と免許は州の管轄。カリフォルニアは許可制＋ディスエンゲージメント報告の公開義務、テキサス・アリゾナは緩やか
中国都市ごとの試験区（パイロットゾーン）で段階的に緩和。都市間競争として推進される一方、事故時は一斉停止のリスク
政府目標（日本）無人自動運転移動サービスを2025年度目処に50か所程度、2027年度までに100か所以上

米国で先に無人運行が広がったのは技術差ではなく制度差という見方が有力。
州によっては禁止条文がない状態から走り始められた。日本は先に許可制を作ったので安全だが、走り出すまでが遅い。
詳細は 04_規制と責任。
