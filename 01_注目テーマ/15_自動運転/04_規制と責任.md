# 自動運転｜規制と責任（法制度・事故・保険・社会受容）

**このノートで分かること**：日本で自動運転車を走らせるのに何の許可が要るのか、
事故ったとき誰が払うのか、そして**なぜ「技術ができても走れない」という状態が起きるのか**。

結論を先に言う。日本の自動車の法律は**「クルマ（モノ）の基準」と「走らせ方（ヒトの行為）」の2本立て**で、
自動運転はその両方を書き換える必要があった。さらに難しいのは**責任**で、
現行制度は**被害者救済を最優先して、まず車の持ち主側の保険で払い、あとでメーカーに請求する**という
順番を維持している。つまり**「メーカーが悪いのかソフトが悪いのか」を先に決めない**ことで制度を動かしている。

そして最後に、法律より強い制約がある。**社会受容**である。
2023年に米GM傘下Cruiseが1件の事故で事業ごと止まった事例が示すとおり、
**この産業は「技術的な安全性」ではなく「1件の事故に耐えられるか」で動いている**。

## 1. 日本の法律は2本立て

```
 ┌─────────────────────────────┐   ┌─────────────────────────────┐
 │   道路運送車両法（国土交通省）  │   │    道路交通法（警察庁）        │
 │   ── クルマ（モノ）の基準 ──   │   │  ── 走らせ方（行為）の規律 ── │
 │                             │   │                             │
 │ ・保安基準（ブレーキ、灯火…） │   │ ・運転者の義務（前方注視、    │
 │ ・型式指定（量産車の一括認可） │   │   携帯電話禁止、酒気帯び…）  │
 │ ・車検                      │   │ ・事故時の措置義務            │
 │ ・**自動運行装置**（2019年改正）│   │ ・**特定自動運行**の許可      │
 │ ・**作動状態記録装置**の義務   │   │   （2022年改正／2023年4月施行）│
 │ ・**プログラム改変の許可制**   │   │ ・公安委員会が許可を出す       │
 │   （OTA更新も国の管理下）     │   │                             │
 └─────────────────────────────┘   └─────────────────────────────┘
          「その車は走ってよいか」            「その走らせ方は許されるか」
                    └──────────┬──────────┘
                      両方をクリアして初めて公道を走れる
```

この2本立ては**自動運転に固有の話ではなく、もともとの日本の自動車法制の形**である。
ただし自動運転では、**「運転者」という概念が両方の法律の中心にある**ため、
どちらも同時に改正しないと1歩も動けなかった。

## 2. 主要な法改正の流れ

| 時期                                      | 法律                             | 内容                                                                                                                                                              |
| ----------------------------------------- | -------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2019年5月成立<br>（2020年4月施行）        | **道路運送車両法** 改正          | **自動運行装置**を法律上の「装置」として定義し、保安基準の対象に追加。**作動状態記録装置**の搭載を義務化。ソフトウェアの改変（OTA更新含む）を**国の許可制**にした |
| 2019年5月成立<br>（2020年4月施行）        | **道路交通法** 改正              | **レベル3を解禁**。自動運行装置の作動中は、直ちに引き継げる状態であればスマートフォンの画面注視等を認める（＝アイズオフの法的根拠）                               |
| 2022年4月成立<br>（**2023年4月1日施行**） | **道路交通法** 改正              | **特定自動運行**の許可制度を新設。**運転者のいないレベル4相当の走行**を、都道府県公安委員会の許可のもとで可能にした                                               |
| 2023年5月                                 | 運用第1号                        | 産業技術総合研究所が**国内初の特定自動運行許可**を取得（福井県永平寺町）                                                                                          |
| 2021年〜                                  | 国連（WP.29）**UN-R157（ALKS）** | 高速道路の自動車線維持システムに関する国際基準。当初60km/h上限、2022年の改訂で最大130km/hまで拡張。日本もこれを国内基準に取り込む                                 |

### 「特定自動運行」の許可は何を求めるか

レベル4を走らせたい事業者が公安委員会に出す申請では、おおむね次が問われる。

| 要件                   | 中身                                                                                                             |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------- |
| **走行の計画**         | どのルートを、何時から何時まで、どの速度で、どの天候条件で走るか（＝ODDの申告）                                  |
| **特定自動運行主任者** | 遠隔監視をする人を置き、車両の状況を常時把握する体制を作る。**車内の運転者の代わりに、この人が法的な役割を担う** |
| **事故時の措置**       | 事故が起きたら直ちに現場に人を派遣し、負傷者の救護と警察への報告を行う体制                                       |
| **関係機関との調整**   | 警察・消防・道路管理者との事前協議                                                                               |
| **住民への周知**       | 沿線住民への説明                                                                                                 |

> 制度の設計思想がここに表れている。**「運転者がいなくなる」のではなく、
> 「運転者の義務を、遠隔監視者と事業者に割り振り直す」**という考え方。
> だから日本のレベル4は、**個人の車の機能ではなく、事業者が許可を取って行う運行**として作られている。
> 個人所有のレベル4乗用車は、現行制度の想定外である。

## 3. 事故が起きたら誰が払うのか

### 民事（損害賠償）：自賠法の運行供用者責任がそのまま使われる

```
     事故発生
        │
        ▼
 【第1段階】自動車損害賠償保障法（自賠法）
   ┌────────────────────────────────────────────┐
   │ 「運行供用者」＝車を運行の用に供している者     │
   │  （所有者・事業者。**運転していた人とは限らない**）│
   │  が、原則として賠償責任を負う                 │
   │  → 自賠責保険＋任意保険から被害者へ支払い     │
   └────────────────────────────────────────────┘
        │  ★被害者は「ソフトのバグか運転ミスか」を
        │    証明しなくても救済される（ここが肝）
        ▼
 【第2段階】保険会社 → メーカーへの求償
   ┌────────────────────────────────────────────┐
   │ システムに欠陥があった場合、保険会社が        │
   │ メーカー等に求償する                          │
   │  ・製造物責任法（PL法）                       │
   │  ・作動状態記録装置のデータが証拠になる        │
   └────────────────────────────────────────────┘
```

国交省の「自動運転における損害賠償責任に関する研究会」報告書（2018年）は、
**当面は現行の運行供用者責任の枠組みを維持し、保険会社からメーカーへの求償を円滑にする仕組みを整える**
という方向で整理した。**制度を作り直すのではなく、既存の枠に載せる**という判断である。

レベル3車両については、**メーカーが保険会社に記録装置のデータを提供するスキーム**が用意され、
事故原因の切り分けができるようにしている。

### 刑事責任：ここが最も未整理

| レベル                  | 誰が刑事責任を問われうるか                                                                                               |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| レベル2                 | **運転者**。システムを使っていても前方監視義務があるため、過失運転致死傷罪の対象                                         |
| レベル3                 | 作動中は監視義務が免除されるが、**引き継ぎ要請に応じなかった場合**は運転者の責任が問われうる                             |
| レベル4（特定自動運行） | 車内に運転者がいない。**特定自動運行主任者や事業者の管理責任**、および製造者の責任が論点になる。**判例の蓄積がまだない** |

> 民事（お金）は現行法で回せるが、**刑事（誰を罰するか）は事実上未解決**。
> これは日本に限らず各国共通で、「誰も逮捕できない事故」が起きたときに社会がどう反応するかが、
> この産業の次の関門になると考えられている。

### 事故調査の仕組み

- **自動運転車事故調査委員会**が交通事故総合分析センター（ITARDA）内に設置され、
  事故の原因分析と再発防止の知見蓄積を行っている
- 米国では**NHTSA（運輸省道路交通安全局）への事故報告が義務**で、
  報告されたデータが公開されるため、Waymo等の事故件数が外部から集計できる
  （例：2021年7月〜2025年末にWaymoがNHTSAへ報告した事故は1,429件、負傷117件、死亡2件と集計されている。
  ただし**大半は他車からの追突など、相手方に起因するもの**とされる）

## 4. 保険という「まだ値段のついていないコスト」

| 論点         | 現状（2026年時点）                                                                                                                                                                                                        |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 料率の根拠   | 自動車保険の料率は**事故統計の蓄積**で決まる。ロボタクシーは走行距離が足りず、**統計的に料率を出せない**。結果として高めの個別引受になりやすい                                                                            |
| 誰が入るか   | 運行事業者が入る。だが**事故の原因がソフトにある場合の求償先がメーカー**なので、実質的にメーカーのリスクでもある                                                                                                          |
| データの扱い | 作動状態記録装置のログをどこまで保険会社に開示するか。**メーカーの営業秘密と事故原因究明の衝突**が起きる                                                                                                                  |
| 安全性の主張 | Waymoは自社公表で「あらゆる負傷報告事故の発生率は100万マイルあたり0.6件、人間ベンチマークの2.80件に対し**約80%減**」としている（同社および査読論文ベース）。**ただし自社データであること、ODDが限定されていることに注意** |
| 逆の効果     | 自動運転が普及して事故が減ると、**自動車保険の市場そのものが縮む**。損保業界にとっては長期の構造問題                                                                                                                      |

> 保険の観点は [損害保険](../../05_金融/08_損害保険/README.md) と裏表になっている。
> 「事故が減って保険料収入が減る」構造は、損保にとって自動運転が
> **顧客の技術革新であると同時に、自分の商売の縮小要因**であることを意味する。

## 5. 各国の制度の違い

| 国・地域 | 仕組み                                                                 | 特徴                                                                                                                                                                              |
| -------- | ---------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **日本** | 車両＝国交省（型式指定）、運行＝都道府県公安委員会（特定自動運行許可） | **事業者への許可制**。ルート・時間帯・体制まで審査するので、立ち上げに時間がかかるが、走り出せば当局と足並みが揃う                                                                |
| **米国** | 車両の安全基準は連邦（NHTSA／FMVSS）、運転者の免許と運行は**州の管轄** | **州ごとにバラバラ**。カリフォルニアはDMVの許可制＋ディスエンゲージメント報告の公開義務、アリゾナ・テキサスは緩やか。だから**Waymoはフェニックス、Teslaはオースティンから始めた** |
| **中国** | 都市ごとに試験区（パイロットゾーン）を指定し、段階的に条件を緩める     | **都市間競争**として推進。展開が速い一方、事故が起きると当局が一斉に止める（規制リスクが大きい）                                                                                  |
| **欧州** | UN-R157など**国連基準（WP.29）を型式認証に取り込む**                   | 基準調和が進んでおり、ドイツはレベル4の法整備で先行。日本も同じ国連基準を採用する                                                                                                 |

> **米国で先に無人運行が広がった理由は、技術差ではなく制度差**という見方が有力。
> 州によっては「自動運転を明示的に禁じる条文がない」状態から始められたため、
> 事業者が**まず走らせて実績を作る**アプローチを取れた。
> 日本は先に許可制を作ったので安全だが、**走り出すまでが遅い**。一長一短である。

## 6. 社会受容：法律より強い制約

技術が基準を満たしても、**住民と行政が嫌がれば事業は止まる**。実例で見るのが早い。

| 出来事                                         | 何が起きたか                                                                                                                                                                                                        | 教訓                                                                                               |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| **GM Cruise の事故と事業縮小**（2023年10月〜） | サンフランシスコで、他車にはねられた歩行者をCruise車両が巻き込み引きずる事故。**当局への報告が不十分だったと問題視され**、カリフォルニアDMVが許可を停止。その後GMはロボタクシー事業への出資を打ち切ったと報じられる | **事故そのものより、当局への情報開示の姿勢が致命傷になった**。安全性の議論は信頼の議論である       |
| **緊急車両・工事現場との干渉**                 | 消防・救急の進路を塞ぐ、工事の誘導員の手信号が理解できず立ち往生する、といった事例が各地で問題化                                                                                                                    | 相手は「事故」ではなく「業務妨害」として苦情を出す。**行政の現場職員が味方でないと運行は続かない** |
| **車両への破壊行為**                           | 米国の一部都市でロボタクシーが放火・破壊される事件が発生したと報じられる                                                                                                                                            | 雇用不安や監視への反発が、直接行動として出る場合がある                                             |
| **慎重すぎることの副作用**                     | 安全側に振ると、交差点で譲り続けて渋滞を作る、路駐を避けられず立ち往生する                                                                                                                                          | **「危険すぎる」より「邪魔である」という苦情のほうが多い**のが実情                                 |

```
【この産業の非対称性】

  100万回の安全な走行  ──▶  ニュースにならない
       1回の重大事故   ──▶  サービス全停止・当局の許可取消・事業撤退

  ★だから各社は、統計的には人間より安全でも、
    「1件も起こさない」ことを求められる。
    この非対称性が、展開速度を技術以上に縛っている。
```

もうひとつ、日本固有の受容問題がある。**雇用**である。
タクシー・バス・トラックの運転職は日本で数十万人規模の雇用であり、
自動運転は「人手不足の解消策」として歓迎される一方、業界団体からは慎重論も出る。
ただし日本の場合、**すでに人が足りていない路線から先に無人化が進む**ため、
米中に比べると雇用との正面衝突は起きにくい構図にある。

## 7. これから決まっていくこと

| 論点                          | 現状                                                                                                         |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------ |
| レベル4の刑事責任の所在       | 判例がない。重大事故が起きて初めて輪郭が出ると見られる                                                       |
| ソフトウェア更新（OTA）の扱い | 日本は許可制。**頻繁に学習モデルを更新する事業とどう折り合うか**が実務上の課題                               |
| 学習モデルの認証方法          | 「なぜそう動いたか説明できない」モデルをどう型式認証するか。シミュレーション試験の基準づくりが国際的に進行中 |
| 高速道路トラックの無人化      | 日本では新東名などで実証中。**ドライバー不在での長距離走行は制度・体制ともこれから**                         |
| データの越境                  | 走行データ（地図・映像）の国外移転を制限する国が増えている。**中国製車両・センサの安全保障上の扱い**とも絡む |

## 用語メモ

- **道路運送車両法**：クルマという「モノ」の安全基準・型式指定・車検を定める法律。所管は国土交通省
- **道路交通法**：道路での「行為」を規律する法律。運転者の義務、許可制度を定める。所管は警察庁
- **自動運行装置**：2019年の道路運送車両法改正で法律上定義された、運転操作を代替する装置
- **作動状態記録装置**：自動運行装置がいつ作動・解除されたかを記録する装置。レベル3以上で搭載義務。事故時の責任判断の根拠になる
- **特定自動運行**：2023年4月施行の改正道交法で新設された、運転者なしの自動運行を行う制度。都道府県公安委員会の許可が必要
- **特定自動運行主任者**：特定自動運行の実施主体が置く、遠隔監視と事故対応を担う者
- **自賠法（自動車損害賠償保障法）**：交通事故の被害者救済のための法律。自賠責保険の根拠
- **運行供用者責任**：車を自分のために運行させている者が負う責任。ほぼ無過失責任に近く、**運転していたかどうかを問わない**
- **PL法（製造物責任法）**：製造物の欠陥による損害の責任を製造業者に負わせる法律。プログラム単体は「製造物」に当たらないとされるが、組み込まれた車両は対象
- **UN-R157（ALKS）**：国連WP.29が定める自動車線維持システムの国際基準。レベル3の高速道路走行の土台
- **WP.29**：国連の自動車基準調和世界フォーラム。日本・欧州が主導し、型式認証の国際基準を作る
- **NHTSA**：米国運輸省道路交通安全局。連邦の自動車安全基準（FMVSS）と事故報告制度を所管
- **ディスエンゲージメント報告**：カリフォルニア州が試験許可事業者に義務づける、自動運転解除の年次報告。外部から進捗を比較できる数少ない公開データ
- **ITARDA（交通事故総合分析センター）**：日本の事故分析機関。自動運転車事故調査委員会が置かれている
