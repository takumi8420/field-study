自動運転｜レベル0〜5とODDの実際

注目テーマ自動運転
あこのページの単語集用語に触れると意味を確認できます11語
SAE J3016ハンズオフアイズオフODD（運行設計領域）ジオフェンステイクオーバー（引き継ぎ）MRM（ミニマルリスクマヌーバ）特定自動運行安全監視員（セーフティドライバー／セーフティオペレータ）遠隔監視／遠隔支援作動状態記録装置

このノートで分かること：自動運転レベルが車の賢さの順位ではないこと、
そしてレベル2とレベル3のあいだに制度上の断層が走っていること。
さらに「レベル4を達成」という見出しを読むときに必ず確認すべき条件（ODD）の話。

結論を先に言う。自動運転レベルとは「事故ったとき、誰が運転者だったか」を決める分類である。
性能の等級ではないので、レベル2の車がレベル3の車より上手に走ることは普通にある。
そしてレベル2→3の1段だけが、責任者が人からシステムへ移る唯一の段差であり、
ここを越えるコストが高すぎるため、多くのメーカーはレベル2のまま性能だけ上げる道を選んでいる。

1. SAE J3016 のレベル定義

国際標準SAE J3016（日本ではJASO/官民ITS構想がこれを採用）の6段階。

レベル 呼び名 誰が操作するか 誰が周囲を監視するか 運転者は誰か 市販の実例
0運転支援なし人人人警報のみの車。AEB（自動ブレーキ）もここ
1運転支援人＋システム（前後か左右のどちらか）人人ACC（車間制御）単独、LKA（車線維持）単独
2部分運転自動化人＋システム（前後と左右の両方）人人各社の「ハンズオフ」機能。Tesla Autopilot/FSD（監視付き）、日産プロパイロット2.0、GM Super Cruise
3条件付運転自動化システムシステム（ただし人は引き継ぎ要請に応じる義務）システム（作動中）Honda レジェンド（2021年、100台リース限定）、Mercedes Drive Pilot
4高度運転自動化システムシステムシステム（人は引き継がなくてよい）Waymo、中国Apollo Go/Pony.ai/WeRide、日本の永平寺町など限定区間サービス
5完全運転自動化システムシステムシステム存在しない。開発目標としても事実上棚上げ

最重要の見分け方：「人が前を見ていなくてよいか」＝アイズオフ（eyes-off）かどうかが、レベル2と3の境目。
手を離してよい（ハンズオフ）だけならレベル2のまま。手より目のほうが重い。

2. レベル2とレベル3のあいだの断絶

この1段が、技術の1段ではなく法的な1段であることが、この業界を理解する最大の鍵。

 ┌──────────── レベル2まで ────────────┐ ║ ┌──────── レベル3から ────────┐
 │                                      │ ║ │                              │
 │  運転者＝人間                        │ ║ │  運転者＝システム             │
 │  常時前方監視の義務あり              │ ║ │  作動中は前方監視の義務なし    │
 │  事故の一次責任＝運転者              │ ║ │  事故の責任＝運行供用者／      │
 │  車は「便利な道具」                  │ ║ │   メーカーの責任が問われうる   │
 │                                      │ ║ │                              │
 │  型式指定は既存の延長                │ ║ │  国交省の**特別な認可**が必要   │
 │  メーカーの追加負担：小              │ ║ │  作動状態記録装置の搭載義務    │
 │                                      │ ║ │  保険・PL・当局説明の負担：大   │
 └──────────────────────────────────────┘ ║ └──────────────────────────────┘
                                          ║
                              ここが断層（責任の所在が移る）
                              性能ではなく**引き受けるリスク**が変わる

なぜ各社がレベル3に行きたがらないかは、この図で説明がつく。
レベル3を名乗った瞬間、作動中の事故についてメーカーが説明責任と賠償リスクを負う。
一方でユーザーが払ってくれる金額はレベル2の「ハンズオフ」とたいして変わらない。
つまり収入は同じでリスクだけ跳ね上がる。だからレベル2の性能を上げ続けるのが合理的になる。

レベル3のもうひとつの難題：引き継ぎ（テイクオーバー）

レベル3は「システムが走るが、限界が来たら人に返す」設計である。ここに構造的な問題がある。

  • 人はスマホを見ていてよい。だが10秒後には運転を再開できていなければならない
  • 人間は注意を切った状態から状況を把握し直すのに十数秒かかる（研究ベースの知見）
  • 返すのは「システムが困った場面」＝いちばん難しい場面。初心者に難問だけ渡す構図になる

このため、レベル3は
「システムが自力で安全に止まれる（MRM＝ミニマルリスクマヌーバ）」ことを前提に、
返すまでの猶予を十分取れる場面（渋滞中の高速道路など）に限定するという形で実装されている。

3. ODD：どこでなら走れるかという「但し書き」

ODD（Operational Design Domain＝運行設計領域）とは、
そのシステムが正常に働くと設計者が保証した条件のこと。レベル3・4の車は必ずODDを持つ。

ODDの軸 具体例
道路高速道路の本線のみ／中央分離帯のある片側2車線以上／特定の市道◯◯線のみ
速度60km/h以下（渋滞時）／95km/h以下
天候降雨・降雪・濃霧では作動しない。逆光でも解除される場合がある
時間帯日中のみ／夜間も可
地理高精度地図が整備された区域内のみ（ジオフェンス）
交通前走車がいること（渋滞追従型）／歩行者が少ない区域
車両状態センサ面が汚れていない、乗員がシートベルト着用、など
        ┌─────────────────────────────────────────┐
        │              ODD（走ってよい条件）        │
        │   ┌───────────────────────────────┐     │
        │   │  通常走行                      │     │
        │   └───────────────────────────────┘     │
        └─────────────────────────────────────────┘
                     ▲                    │
          ODDに戻る  │                    │ ODDから出る（雨が降る／
                     │                    ▼  地図外へ／センサ汚損）
        ┌────────────┴───────────────────────────────┐
        │  レベル3 → 人へ引き継ぎ要請（10秒程度の猶予） │
        │           応じなければ MRM（自動で減速・停車） │
        │  レベル4 → 人には返さない。MRMで路肩に停車し、 │
        │           遠隔オペレータ／回収要員を呼ぶ      │
        └────────────────────────────────────────────┘

「レベル4を実現」という見出しは、ODDを見ないと意味がない。
「時速12km・全長2kmの決まったルート・晴天の日中のみ・遠隔監視あり」もレベル4だし、
「サンフランシスコ全域・24時間・雨天可・客を乗せて」もレベル4である。
同じ「レベル4」で難易度が3桁違う。

4. デモと商用運行を分けて読む

この業界のニュースは、次の4段階が全部「自動運転が走った」と報じられる。区別して読む必要がある。

段階 実態 見分けるポイント
①公道実証（デモ）期間限定・招待客・関係者同乗。台数1〜数台「実証実験」「試乗会」「〇月〇日〜〇月〇日」と期間が書いてある
②有人監視の営業運行運転席または助手席に安全監視員が乗る。客は一般人「セーフティドライバー同乗」「保安要員」。無人ではない
③遠隔監視の無人運行車内に人はいないが、遠隔センターが監視・支援する「無人」「ドライバーレス」。オペレータ1人が何台見ているかが要点
④完全無監視遠隔監視すらない2026年時点で商用ではほぼ存在しない。どの事業者も遠隔支援は残している

現実のロボタクシー事業者はすべて③である。「無人運転」という言葉は
「車内に人がいない」という意味であって、「誰も見ていない」という意味ではない。
遠隔監視の人員比率は事業の採算に直結する。詳細は 03_事業としての自動運転。

「リスクは上がるが売価は上がらない」という経済の帰結である。

6. レベル4の現在地（2026年時点）

レベル4は乗用車の機能としてではなく、サービス（ロボタクシー・バス・トラック）として実装されている。
理由は単純で、車両1台あたりのコストが高いので、稼働率を上げて回収するしかないから。

地域 事業者 規模・条件（2026年時点、報道・企業発表ベース）
米国Waymo2026年9月にデンバー・サンディエゴ・タンパを追加し、稼働14都市・約4,000台規模と報じられる。一般客向け商用、車内無人、遠隔支援あり
米国Tesla Robotaxi2026年8月末時点で無監視（車内監視員なし）は約85台／7都市と集計される。2026年1月にオースティンで車内安全監視員なしの運行を開始したと報じられる。遠隔監視は継続
中国Baidu Apollo Go2025年に世界1,000台超、24都市。2026年に5,000台・40都市への拡大計画と報じられる。武漢では車両単位の黒字化に到達との報道

7. レベル5が語られなくなった理由

2016年ごろは「2020年にレベル5」と言われていた。今それを言う事業者はいない。

  • レベル5はODDがないことを意味する。世界中のあらゆる道・天候・国で走れること
  • 雪国の除雪されていない道、標示のない途上国の道、警察官の手信号、これらすべてを含む
  • ODDを限定することで商売になると業界が学んだ。限定はごまかしではなく、安全を保証できる範囲を宣言する行為
  • よって現在の目標は「レベル5」ではなく「レベル4のODDを、経済的に見合う範囲まで広げること」に置き換わった

業界内で広く共有されている理解：レベル5は製品仕様ではなく、思考実験である。

用語メモ

  • SAE J3016：自動運転レベルを定めた国際標準。日本の制度・報道もこれに準拠する
  • ハンズオフ：ハンドルから手を離してよい状態。レベル2でも可能
  • アイズオフ：前方から目を離してよい状態。レベル3以上でのみ可能。レベル2と3の実質的な境目
  • ODD（運行設計領域）：システムが正常に働くと設計者が保証した条件の集合。道路・速度・天候・地理・時間帯など
  • ジオフェンス：地図上で「ここから外へは出ない」と設定した仮想の境界線
  • テイクオーバー（引き継ぎ）：レベル3でシステムから人へ運転を戻すこと。要請から実際に戻るまでの時間が安全上の要点
  • MRM（ミニマルリスクマヌーバ）：引き継がれなかった場合に、システムが自力で安全な状態（減速・路肩停車）へ移る動作
  • 特定自動運行：2023年4月施行の改正道交法で新設された、日本でレベル4相当を公道で行うための許可制度。都道府県公安委員会の許可が要る
  • 安全監視員（セーフティドライバー／セーフティオペレータ）：試験・初期運行で車内に乗り、いつでも介入できる人。乗っている時点で「無人」ではない
  • 遠隔監視／遠隔支援：センターから車両の状況を見て、必要時に助言・許可・遠隔操作を行う運用。無人運行でも通常は残る
  • 作動状態記録装置：レベル3以上で搭載が義務づけられる、システムの作動状況を記録する装置。事故時の責任判断に使う
