# 自動運転

- 大分類: 注目テーマ
- 状態: done
- 更新日: 2026-09-20

一言でいえば、**「運転という労働を、車両の減価償却と遠隔監視の人件費に置き換える産業」**。
技術の話に見えて、実態は**人件費の付け替えが割に合うかどうか**という算数であり、
だから**稼働率を極端に上げられる用途（タクシー・幹線トラック）と、走る条件が閉じた用途（鉱山・農地）からしか成立しない**。

もう1つ、この業界を読むうえで絶対に外せない区別がある。**デモと商用運行はまったく別物**だということ。
「自動運転が走った」というニュースは、①期間限定の実証、②安全監視員が同乗する営業運行、
③車内無人＋遠隔監視の商用運行、のどれかを指しているが、この3つは難易度が桁で違う。
**台数・地域・監視者の有無**を確認せずに読むと、業界の現在地を必ず読み違える。

そして最後に、**レベル2とレベル3のあいだには技術ではなく法律の断層がある**。
レベル3を名乗った瞬間、事故の責任がメーカー側へ移る。だが売価はほとんど上がらない。
この非対称が、**「センサはどんどん良くなるのに、車はレベル2のまま」**という2026年の風景を作っている。

## 1. 業界の定義・範囲

「自動運転」とは、**運転操作（認知・判断・操作）の一部または全部を機械が代替する技術と、それを使ったサービス**の総称。
ただし業界として語られるときは、**運転支援（ADAS）を売る部品産業**と、**運転者なしで運行するサービス産業**という、
経済構造がまったく違う2つが同じ名前で呼ばれている。

| 含む                                        | 含まない（隣接）                                                                                 |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| 自動運転ソフトウェア（認識・予測・計画）    | 車体そのものの製造 → [自動車（完成車）](../../02_自動車・機械/01_自動車（完成車）/README.md)     |
| 車載センサ（カメラ、LiDAR、ミリ波レーダー） | 動力系の電動化 → [EV・電動化](../03_EV・電動化/README.md)                                        |
| 車載演算ユニット・ADAS用ECU                 | 半導体の製造そのもの → [半導体・先端半導体](../02_半導体・先端半導体/README.md)                  |
| 高精度地図・測位インフラ                    | カーナビ用の一般地図                                                                             |
| ロボタクシー・自動運転バスの運行事業        | 人間が運転するタクシー・バス → [タクシー・バス](../../13_運輸・物流/11_タクシー・バス/README.md) |
| 自動運転トラック・隊列走行                  | 倉庫内の搬送ロボット → [ロボット](../09_ロボット/README.md)                                      |
| 鉱山・農地・港湾の無人車両                  | 空の自律機 → [ドローン](../08_ドローン/README.md)・[空飛ぶクルマ](../16_空飛ぶクルマ/README.md)  |

**境界が曖昧な2か所**がある。
①**ADASと自動運転**（技術は連続しているが、責任の所在が違うので制度上は断絶している）、
②**配車プラットフォーム**（Uber・GOなどは車も技術も持たないが、需要側を握るので取り分が大きい）。
とくに②は、**「自動運転の勝者＝AI企業」とは限らない**という意味で重要。

## 2. 市場規模と成長性

自動運転は**市場規模の数字が最も当てにならない分野**である。定義次第で2桁ぶれる。

| 指標                      | 数値                                                                          | 年・出どころ                           |
| ------------------------- | ----------------------------------------------------------------------------- | -------------------------------------- |
| Waymoの年換算売上（ARR）  | 約3億5,500万ドル（2025年末は約2億8,400万ドル）                                | 2026年2月、調査会社Sacraの集計         |
| Waymoの稼働台数           | 約3,000台 → 約4,000台                                                         | 2026年2月 → 2026年9月、報道ベース      |
| Waymoの運転者なし累計走行 | 約2億2,060万マイル                                                            | 2026年3月まで、同社公表                |
| Hesai（中国）のLiDAR出荷  | 約110万台（前年同期比＋100.8%）、売上15.41億元                                | 2026年上半期、同社発表                 |
| ADAS向けLiDARの価格       | 新型「ATX」で約200ドル（約3万円）                                             | 2026年、報道ベース                     |
| 日本の政府目標            | 無人自動運転移動サービスを2025年度目処に50か所程度、2027年度までに100か所以上 | 政府のデジタル田園都市／モビリティ政策 |

> **総額の予測より、実物の量で見るほうが正確**。
> ロボタクシーは**台数・都市数・累計走行距離・遠隔監視比率**、ADASは**センサ出荷台数と単価**で追う。
> 「2030年に◯兆円市場」という数字はほぼすべて調査会社の推計であり、ADASを含むか、車両価格を含むかで別物になる。

規模で見れば、**2026年時点のロボタクシー産業は世界全体で年商1,000億円に届くかどうか**という段階。
日本のタクシー業界（年間1兆円超）と比べても、まだ桁が2つ小さい。
**巨額の期待と、極小の実売の落差**が、この産業の現在地である。

```
                     アイシン（操舵）   Mobileye                          遠隔監視

 付加価値： 高い（寡占）   中（不可欠）     **最も高いが          低い          中            高い
            ただし値下げ                   まだ誰も黒字化        「箱を作る側」 オペレーション（需要を握る）
            圧力も強い                     していない**          は薄利         の巧拙が効く
```

構図の要点は2つ。

1. **価値はソフト（③）に集まるはずだが、2026年時点で黒字化した事業者はいない**。研究開発費を先食いしている段階
2. **需要側（配車アプリ）が強い**。車を持たずに手数料を取れる位置で、Uberは自前の自動運転技術を捨ててこの位置に移った

完成車メーカーにとって残酷なのは、**この鎖の中で「車両製造」が最も薄利な位置に置かれている**こと。
「車を作って売る」商売から「車を持って動かす」商売への転換を迫られている。

## 5. 収益モデル・コスト構造

| 事業                             | 何で儲けるか                                  | コストの中心                                                 | 利益の出方                                                                       |
| -------------------------------- | --------------------------------------------- | ------------------------------------------------------------ | -------------------------------------------------------------------------------- |
| **ADAS部品・チップ**             | 車1台あたりの部品代                           | 開発費（固定費）と半導体の製造原価                           | **搭載台数がすべて**。量産車に載れば固定費を薄く配れる。載れなければゼロ         |
| **LiDAR**                        | 1個あたりの物販                               | 部材と量産設備                                               | 価格競争が激しく**赤字覚悟のシェア争い**。淘汰が続いている                       |
| **自動運転ソフト（ライセンス）** | メーカーへのライセンス料、または開発受託      | エンジニアの人件費                                           | 採用車種が決まるまで数年赤字。**採用されれば限界費用は小さい**                   |
| **ロボタクシー運行**             | 1乗車あたりの運賃（平均15〜17ドル）           | **車両の減価償却＋遠隔監視の人件費＋デポ運営＋電気代＋保険** | 固定費型。**稼働率が落ちた瞬間に赤字**。1台年商は約1,100万円と逆算される（推計） |
| **自動運転トラック**             | 輸送1便あたりの運賃、または車両＋サービス販売 | 車両、遠隔監視、整備拠点                                     | **人が休む時間も走れる**ぶんが利益の源。長距離ほど効く                           |
| **地域バス・コミュニティ交通**   | 運賃＋**自治体からの委託費・補助金**          | 車両、遠隔監視、地上要員                                     | **元から運賃で成り立っていない路線**が対象なので、実質は行政予算事業             |
| **鉱山・農機**                   | 車両・システムの販売＋保守                    | 開発費と車両原価                                             | **すでに黒字**。ODDが閉じているので追加コストが小さい                            |

> **この産業の最大のクセ**：「無人化」は人件費をゼロにしない。**1/40くらいにする**技術である。
> 遠隔オペレータ1人が何台見られるかで採算が決まり、1:3では人を乗せるのと変わらない。
> だから**遠隔監視比率は、台数よりも重要な事業KPI**である。詳細は [03_事業としての自動運転](03_事業としての自動運転.md)。

## 6. 競争要因（KSF）と参入障壁

**KSF**

1. **ロングテールを潰す速度**：珍しい場面のデータをどれだけ集め、どれだけ速く学習に反映できるか。走行距離がそのまま資産になる
2. **遠隔監視比率**：1:3か1:43かで損益が反転する。介入が必要な場面をどれだけ減らせるかの勝負
3. **都市立ち上げの学習曲線**：1都市目のコストをどこまで下げられるか。ここが企業価値の中身そのもの
4. **当局・地元との関係**：警察・消防・道路管理者・住民。**1件の事故で許可が消える**構造なので、信頼の蓄積が資産になる
5. **需要側の接点**：配車アプリを持つか、持つ相手と組めるか。技術があっても客が呼べなければ稼働率が上がらない
6. **車両を安く大量に確保できるか**：センサ込みで1台1,000万円級（推計）の車両を、どれだけ安く積み増せるか

**参入障壁**

- **極めて高い**：ロボタクシーは、数千億円規模の累積投資と10年単位の走行実績がないと商用に届かない。**新規参入はほぼ不可能**
- **やや低い**：ADAS向けセンサ・ソフトは、量産車に採用されれば一気に数が出る。中国勢の台頭はここから起きた
- **低い**：限定区間の低速サービス（構内カート、地域バス）は既存システムを買って運用できる。ただし**そこに大きな利益はない**

結果として業界は二極化している。**都市ロボタクシーは数社の寡占**、
**限定区間サービスは多数の小規模事業者＋補助金**という構造になる。

## 7. 規制・法制度

| 制度                               | 内容                                                                                                                                                                        |
| ---------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **道路運送車両法**（国交省）       | クルマ（モノ）の基準。2019年改正（2020年4月施行）で**自動運行装置**を法律上定義し、**作動状態記録装置**の搭載を義務化、**ソフト改変（OTA更新）を許可制**にした              |
| **道路交通法**（警察庁）           | 走らせ方の規律。2019年改正でレベル3を解禁（作動中のスマホ注視等を条件付きで容認）。**2022年改正・2023年4月施行で「特定自動運行」の許可制度**を新設                          |
| **特定自動運行の許可**             | 運転者なしの運行には**都道府県公安委員会の許可**が必要。ルート・時間帯・ODD、**特定自動運行主任者**による遠隔監視、事故時の対応体制、関係機関との調整、住民周知が審査される |
| **自賠法（自動車損害賠償保障法）** | 事故の賠償は**運行供用者責任**が原則。まず所有者・事業者側の保険で被害者を救済し、**欠陥があれば保険会社がメーカーへ求償**する                                              |
| **製造物責任法（PL法）**           | ソフトの欠陥による責任の根拠。**プログラム単体は「製造物」に当たらない**とされるが、組み込まれた車両は対象                                                                  |
| **UN-R157（ALKS）／WP.29**         | 国連の自動車基準。レベル3の高速道路走行の国際基準。2022年改訂で上限130km/hまで拡張。日本も国内基準に取り込む                                                                |
| **米国**                           | 車両基準は連邦（NHTSA／FMVSS）、運行と免許は**州の管轄**。カリフォルニアは許可制＋ディスエンゲージメント報告の公開義務、テキサス・アリゾナは緩やか                          |
| **中国**                           | 都市ごとの試験区（パイロットゾーン）で段階的に緩和。**都市間競争として推進**される一方、事故時は一斉停止のリスク                                                            |
| **政府目標（日本）**               | 無人自動運転移動サービスを2025年度目処に50か所程度、2027年度までに100か所以上                                                                                               |

> **米国で先に無人運行が広がったのは技術差ではなく制度差**という見方が有力。
> 州によっては禁止条文がない状態から走り始められた。日本は先に許可制を作ったので安全だが、走り出すまでが遅い。
> 詳細は [04_規制と責任](04_規制と責任.md)。

4. **無人トラックが定期便になった**。2026年5月からAuroraがダラス〜ヒューストン間で**完全無人・週7日**の商業輸送を実施（荷主はMcLane）。難易度が低く経済効果が明快なため、**ロボタクシーより先に定着する可能性**
5. **量産車はレベル2のまま、センサだけ豪華になる**。中国HesaiのLiDAR出荷は2026年上半期で約110万台（＋100.8%）、価格は約200ドル級まで低下。**レベル3の責任を引き受けずに性能だけ上げる**選択が続いている
