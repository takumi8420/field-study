注目テーマ水素・アンモニア

このノートで分かること：なぜ水素・アンモニアの話は必ず「政策」の話になるのか。
そして日本が2024年に作った「値差支援」という仕組みが、具体的に何をどう埋めるのか。

結論を先に：低炭素水素は、放っておけば誰も買わない。
既存燃料より確実に高く、買っても品質は同じだからである。
だから世界中の政府が「高い分の差額を税金で埋める」仕組みを作った。
つまりこの業界の需要は、制度設計が作り出している人工的な需要である。ここを外すと何も読めない。

1. なぜ補助金なしでは成立しないのか

低炭素水素の問題は「性能が悪い」ことではない。性能は既存の水素とまったく同じである。

              グレー水素        低炭素水素
  性能          同じ      =       同じ
  使い勝手      同じ      =       同じ
  価格        1〜2$/kg    <     4〜8$/kg     ← 3〜5倍
  CO2         9kg出る     >     ほぼゼロ      ← 買う側に金銭的メリットがない

  → 企業が自発的に買う理由は「CO2削減を評価する制度」が無ければ存在しない

これは経済学でいう外部性そのもので、CO2を出しても誰も罰金を払わない世界では、安いグレー水素が必ず勝つ。
選択肢は2つしかない。

手段 中身 採っている地域
ムチ（炭素に値段をつける）排出量取引、炭素税。CO2を出す側のコストを上げるEU（EU-ETS、CBAM）が最も強力
アメ（差額を補填する）補助金、税額控除、差額契約日本（値差支援）、米国（45V）、EU（水素銀行）

日本は炭素価格がまだ弱いため、アメ側で押している。これが日本の制度の特徴である。

2. 日本の枠組み：水素基本戦略と水素社会推進法

2-1. 水素基本戦略（2017年策定、2023年6月改定）

項目 内容
導入目標2030年 300万トン/年 → 2040年 1,200万トン/年 → 2050年 2,000万トン/年
価格目標2030年に 30円/Nm³（≒334円/kg）、2050年に 20円/Nm³（≒223円/kg）。現状は約100円/Nm³
投資官民で今後15年間に15兆円を投資
重点水電解装置・燃料電池・液化水素・水素還元製鉄など9分野の戦略技術

2040年の1,200万トンは現在の日本の水素利用量（主に産業用で約200万トン）の約6倍に相当する。
「本当に届くのか」が常に問われる、野心的な目標である。

2-2. 水素社会推進法（2024年成立・同年10月23日施行）

正式名称は長い（脱炭素成長型経済構造への円滑な移行のための低炭素水素等の供給及び利用の促進に関する法律）。
中身は極めてシンプルで、「計画を国が認定し、認定された事業に2種類の支援を出す」という制度である。

3. 「値差支援」の仕組みを図で理解する

日本の制度の中核。英国の洋上風力で使われた差額決済契約（CfD）の考え方を水素に応用したもの。

  円/kg
   ↑
   │  ┌──────────────────────────────┐
   │  │        基準価格（Strike Price）           │  ← 低炭素水素の実際の製造・輸送コスト
   │  │        ＝ 事業者が生き残れる価格            │     （申請時に事業者が提示し、国が査定）
   │  └──────────────────────────────┘
   │             ▲
   │             │  ◀━━━ この差額を国が15年間補填する（＝値差支援）
   │             ▼
   │  ┌──────────────────────────────┐
   │  │        参照価格（Reference Price）         │  ← 置き換えられる既存燃料の価格
   │  │        ＝ 利用者が払ってもよい価格           │     （LNG価格・アンモニア市況等に連動）
   │  └──────────────────────────────┘
   └────────────────────────────────▶ 時間（15年）

  ポイント①：参照価格は市況に連動するので、LNGが高騰すると差額は縮み、国の負担が減る
  ポイント②：支援は15年。さらに支援終了後10年の事業継続が条件 → 実質25年のコミットメント
  ポイント③：供給側と利用側の【共同申請】が必須 → 「作ったけど買い手がいない」を制度的に防ぐ

ここが巧いところ：共同申請の義務づけ。
世界中の水素プロジェクトが潰れる最大の理由は「オフテイク（引取契約）が取れない」ことなので、
制度の入口でそれを要求している。裏を返せば、買い手が見つからない案件は最初から申請できない。

拠点整備支援

こちらは「みんなで使う設備」の建設費を補助する仕組み。
受入タンク、共用パイプライン、桟橋など、1社では投資回収できないが無ければ誰も始められない設備が対象。

  • 支援は FS（事業性調査）→ FEED（基本設計）→ インフラ整備 の3段階で、段階ごとに継続可否を判断する
  • 令和7年度当初予算でFEED事業に57億円、令和8〜12年度の5年間で総額2,196億円を計上（経産省資料、2026年3月）
  • 大規模拠点は3カ所程度に絞る方針（報道）。「薄く広く」ではなく「厚く狭く」

ここに、日本の戦略が「まず海外のブルーアンモニアを大量に持ってくる」方向であることがはっきり表れている。

モニタリング体制

制度が興味深いのは、認定後の監視の仕組みまで作り込んでいる点。

  • 認定案件は2030年度までに供給開始し、支援15年＋終了後10年の継続が前提
  • 経産省とJOGMECが、EPCや運転計画の進捗、炭素集約度の実績、価格転嫁の状況を継続的に確認
  • 水素・アンモニア小委員会に定期報告し、審議会が確認・助言する
  • 市場の不確実性が高いことを制度側も認めており、「自立した事業として成立しうるか」を検証し続ける建て付け

5. 各国の戦略を並べる

国・地域 主な手段 狙い 2026年時点の状況
日本値差支援＋拠点整備（水素社会推進法）、GX経済移行債海外から低炭素水素・アンモニアを調達し、既存火力と製鉄を延命しながら脱炭素認定が始まったばかり。規模はまだ小さい
EUEU-ETS（炭素価格）、欧州水素銀行のオークション、RED III の義務比率、CBAM域内でグリーン水素を作り、炭素価格で需要を強制的に作る第3回オークションで9件に10.9億ユーロを配分（2026年5月）。落札補助単価 0.57〜3.49ユーロ/kg。応札は予算の6倍超

EUオークション方式と日本の値差支援の違い

EU 欧州水素銀行 日本 値差支援
決め方競争入札。「補助はいくら要るか」を安い順に採択個別審査。事業計画を国が査定して基準価格を決める
支援期間最大10年15年（＋終了後10年の継続義務）
長所競争が働き、補助単価が下がる大型・長期の案件に踏み込める。買い手を制度的に確保できる
短所小規模案件に偏りやすい。落札後の脱落もある競争が働きにくく、基準価格の査定が甘いと過大補助になる

EUの第3回オークションが予算の6倍超の応札を集めた事実は、
「補助さえあれば作りたい事業者は山ほどいる」ことと、
「補助なしで成立する案件は依然ほぼ無い」ことを同時に示している。

6. 制度を見るときのチェックポイント

ニュースを読むときに確認すべき項目を並べておく。

  1. 炭素集約度（CI）の基準値は何か。「グリーン」と書いてあっても制度基準を満たすとは限らない
  2. 支援期間は何年か。10年と15年では事業の成立性がまったく違う
  3. オフテイク（引取契約）はあるか。「覚書（MOU）」と「拘束力ある契約」は別物
  4. FID（最終投資決定）を取ったか。発表とFIDの間には巨大な谷がある
  5. 補助の原資は何か。日本はGX経済移行債＝将来の炭素賦課金で返す借金。返済原資の議論が別途ある
  6. 支援終了後に自立できる見込みがあるか。15年後に価格が下がっていなければ、制度が切れた瞬間に事業が止まる

7. できていること／できていないこと（2026年時点）

✅ できていること ❌ できていないこと
日本は法律・予算・執行機関（JOGMEC）まで制度を作り切った認定はまだ価格差6件・拠点2件。2030年300万トンへの道筋は見えていない
共同申請義務やモニタリング体制など、失敗を織り込んだ制度設計になっている認定案件の規模が小さい（水電解案件は年1,000トン台）
EUは炭素価格＋オークションで需要を制度的に作ったそれでも補助が 0.57〜3.49ユーロ/kg 必要。自立には遠い
米国は45Vで世界最大の税額控除を用意した2025年のOBBBAで2027年末着工までに縮小。政権交代で制度が反転するリスクが現実化した
拠点整備で「大規模3カ所程度」と選択と集中の方針が出た選ばれなかった地域の構想が宙に浮く。地方の水素構想の多くは再検討が要る

用語メモ

  • 水素社会推進法：2024年成立。低炭素水素の供給・利用計画を国が認定し、値差支援と拠点整備支援を出す法律
  • 値差支援（価格差に着目した支援）：低炭素水素の実コスト（基準価格）と既存燃料価格（参照価格）の差額を国が補填する制度
  • 基準価格（ストライクプライス）：事業者が事業を継続できる価格。申請時に提示し、国が査定して決める
  • 参照価格：置き換え対象の既存燃料の価格。市況に連動するので、補填額は年によって変わる
  • CfD（差額決済契約）：基準価格と市場価格の差を決済する契約。英国の洋上風力で確立し、水素に応用された
  • 拠点整備支援：共用タンク・共用パイプラインなど、複数事業者が使うインフラの整備費補助
  • FEED（Front End Engineering Design）：本格建設前の基本設計。ここで工費とスケジュールが固まる
  • FID（最終投資決定）：企業が「本当にカネを出す」と決めること。報道の「発表」とは重みが全く違う
  • オフテイク契約：製品の引取契約。これが無いとプロジェクトファイナンスが組めない
  • GX経済移行債：日本政府が脱炭素投資の原資として発行する国債。将来の炭素賦課金・排出量取引の収入で償還する建て付け
  • JOGMEC：エネルギー・金属鉱物資源機構。水素分野では補助金の交付・執行とモニタリングを担う
  • 45V：米IRAのクリーン水素製造税額控除。CIに応じ最大3ドル/kg。2025年のOBBBAで期限が短縮された
  • CBAM（炭素国境調整措置）：EUが域外からの輸入品にEU-ETS相当の炭素コストを課す制度。鉄鋼などが対象
