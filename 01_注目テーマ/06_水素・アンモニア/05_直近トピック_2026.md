# 直近トピック（2026年9月時点）

報道・公表資料ベースの整理。数値は必ず一次情報で裏取りすること。
出典の性格（公式／統計／報道／推計）を各項目に明示した。

> **この1年の総括**：2026年は「**期待の縮小と、制度の始動が同時に起きた年**」である。
> 世界では大型プロジェクトの中止・延期が続き、最終投資決定（FID）は前年割れした。
> 一方で日本の水素社会推進法は初めて認定案件を出し、EUは第3回オークションで10億ユーロ超を配分した。
> 「盛り上がりは終わったが、制度に裏打ちされた案件だけが残り始めた」——これが2026年の実像。

## 1. IEAの2026年レビュー：量は増えたが、投資判断は減った

（出典：IEA *Global Hydrogen Review 2026*。国際機関の統計・分析）

| 指標 | 2025年実績 | 前年からの変化 |
| --- | --- | --- |
| 低排出水素の生産量 | **約1 Mt（100万トン）** | 前年比 +20% |
| 世界の水素生産に占める比率 | 1%未満 → **2026年に初めて1%超の見込み** | — |
| 水電解装置の導入容量（累計） | **4 GW 超**（前年から倍増） | 中国が新規設置の**約75%** |
| 建設中の電解装置 | 2.5 GW 超（2026年稼働目標） | 欧州で2GWだが少数の大型案件に集中 |
| 新規FID（最終投資決定） | 約 **300 ktpa** | **初めて減少**。2年連続で約1Mtpaだったものが 0.8Mtpa を下回る |
| 2030年までにFID済みの生産量 | **6 Mt 超** | 前回レビューの10Mtから**低下** |
| 2030年目標のプロジェクトパイプライン | **27 Mt** に縮小 | 約300ktpaが延期・中止 |
| オフテイク（引取）契約量 | 約 **1.7 Mt** でほぼ横ばい | 新規契約のうち**確定は約20%のみ** |

> **読み方**：生産量と設備は増えているのに、将来を決める指標（FID、パイプライン、オフテイク）が
> そろって縮んでいる。これは「今動いている案件は完成に向かうが、**次の波が来ていない**」ことを意味する。
> IEAは、発表済みの電解装置容量のうち **100GW超が、2027年末までにFIDを取らなければ2030年稼働の可能性を失う** と警告している。

出典：https://www.iea.org/reports/global-hydrogen-review-2026 ／ https://www.iea.org/reports/global-hydrogen-review-2026/executive-summary

## 2. 大型プロジェクトの中止・撤退が相次ぐ

（出典：各社発表および報道。報道ベースであることに留意）

| 時期 | 案件 | 内容 |
| --- | --- | --- |
| 2024年10月 | 豪 Origin Energy | 水素事業を停止と報じられる（日経） |
| 2025年 | bp「HyGreen Teesside」 | 英国初の大型グリーン水素案件を中止。再エネ投資縮小の戦略見直しの一環 |
| 2025年6月 | 豪 **CQ-H2**（豪州最大級のグリーン水素計画） | 計画中止。**丸紅、関西電力、岩谷産業**が撤退と報じられる（日経） |
| 2025年11月 | ExxonMobil「Baytown」ブルー水素・アンモニア | **無期限の一時停止**と報じられる。三菱商事・丸紅が引取を検討していた案件 |
| 2026年5月 | **AGC** | グリーン水素製造用イオン交換膜の生産設備（北九州）の建設を延期し、投資を中断と報じられる（日経） |

日経の報道（2025年1月）によれば、2030年までの稼働を掲げる世界のグリーン水素製造能力 **560GW** のうち、
**実現が見込まれるのは約14%（1割強）** にとどまるという。

### なぜ止まるのか（共通する4つの理由）

```
  ① 資材費・人件費の高騰       → 建設費が計画時の1.5〜2倍に
  ② 政策支援の後退             → 米45Vの縮小、欧州の脱炭素ペース鈍化
  ③ 需要（オフテイク）が付かない → MOUは結べても拘束力ある契約に進まない
  ④ 高金利                     → 20年回収の資本集約型事業に最も効く
        ↓
  「作れるが、売れる価格で作れない」── 技術ではなく経済性で止まっている
```

> **重要な区別**：これらは技術的失敗ではない。
> 水電解も液化水素もアンモニア混焼も、技術としては動いている。止まっているのは**カネの計算**である。
> 逆に言えば、電力価格か炭素価格が動けば、同じ案件が再び動きうる。

## 4. EU水素銀行 第3回オークション：需要は旺盛、しかし補助なしでは無理

（出典：欧州委員会／Hydrogen Europe。**公式**）

| 項目 | 内容 |
| --- | --- |
| 応札締切 | 2026年2月19日 |
| 応札 | **11カ国から58件**、予算13億ユーロに対し**6倍超の応札** |
| 結果公表 | 2026年5月 |
| 落札 | **9件、総額10.9億ユーロ** |
| 落札価格レンジ | **0.57〜3.49ユーロ/kg**（補助単価） |
| 規模 | 電解装置 約1.1GW。稼働後10年間で RFNBO・低炭素電解水素 130万トンを生産 |
| 今後 | CINEAと助成契約をQ4 2026に締結。署名後2.5年でファイナンシャルクローズ、5年で稼働が条件 |

欧州委員会は第4回オークションに**5億ユーロ**を配分する方針とされる。

> **読み方が分かれる結果**：
> - ポジティブ：応札6倍超＝作りたい事業者は多い。最低落札は0.57ユーロ/kgまで下がった
> - ネガティブ：**最低でも0.57ユーロ/kgの補助が要る**。グリーン水素はなおグレー水素の**2〜4倍**の価格圏
>
> 「補助があれば作る」が「補助がなければ作らない」——この構図は2026年も変わっていない。

## 5. 米国：45Vの縮小で、投資判断のカレンダーが前倒しに

（出典：法律事務所のクライアントアラート等。制度解説）

2025年7月4日に成立した **One Big Beautiful Bill Act（OBBBA）** により、
IRAのクリーン水素製造税額控除 **45V** の期限が大幅に前倒しされた。

| | 従来（IRA） | OBBBA後 |
| --- | --- | --- |
| 適用終了 | 2032年末までに着工した設備 | **2027年末までに着工**した設備 |
| 当初の下院案 | — | 2025年末着工まで（＝事実上の廃止）だったが、上院で2年の猶予 |

- 結果として、米国の水素事業者は**2027年末までに着工判断を下さなければならない**という時限に追われている
- これがIEAの言う「2027年末までにFIDを取らないと2030年に間に合わない100GW」と時期的に重なる
- **政策が政権交代で反転しうる**というリスクが、水素業界で初めて現実の数字として表れた事例

出典：https://www.kirkland.com/publications/kirkland-alert/2025/08/one-big-beautiful-bill-act-brings-big-changes-to-green-energy-tax-credits

## 7. 全体の構図（まとめ）

```
    期待                                             現実
  ┌─────────────────┐            ┌─────────────────┐
  │ 2030年までに 560GW の      │            │ 実現見込みは約14%（日経, 2025年）│
  │ グリーン水素製造能力        │  ──────▶  │ FIDは2025年に前年割れ（IEA）    │
  │ 日本は2030年 300万トン      │            │ 国内認定案件は年1,000トン台      │
  └─────────────────┘            └─────────────────┘
                                              │
                                              ▼
                              残ったのは「制度が支える案件」だけ
                       ┌──────────────┬──────────────┐
                       ▼                              ▼
          【量が出るルート】                   【技術で差が出るルート】
          海外ブルーアンモニアの輸入            水電解装置・電解質膜・液化水素船
          （JERA碧南 77万t/年 など）           （東レ、旭化成、川崎重工、千代田化工）
          → 2029〜2030年に発電で実装           → 部材・装置の外販で稼ぐ
```

2026年時点の要点を5行で整理する。

1. **技術は止まっていない**。混焼、水素還元、液化輸送、いずれも実証を通過している
2. **止まっているのは経済性**。資材高・高金利・需要不足で、世界の大型案件が次々に中止・延期された
3. **制度は動き出した**。日本の値差支援は初の認定を出し、EUは10.9億ユーロを配分した
4. しかし**規模がまったく足りない**。低排出水素は世界の水素生産の1%、日本の認定案件は目標の0.01%台
5. **2027年末が業界の分水嶺**。米45Vの着工期限、IEAが警告する100GWのFID期限が同じ時期に重なる

> 最後に一言でまとめるなら：**「水素は失敗したのではなく、想定より20年遅い」**。
> 技術ではなく、価格と制度と時間の問題として見るのが、この業界の正しい見方である。

## 用語メモ

- **FID（最終投資決定）**：企業が実際に資金を投じると決めること。発表・MOUとは重みが全く違う
- **Mt / ktpa**：Mt＝100万トン、ktpa＝千トン/年。水素業界は単位が混在するので注意
- **オフテイク契約**：製品の長期引取契約。これが無いとプロジェクトファイナンスが組めない
- **RFNBO**：EU制度上の「再生可能燃料（非生物由来）」。EUでグリーン水素と認められる要件
- **45V**：米IRAのクリーン水素製造税額控除。最大3ドル/kg。OBBBAで期限が2027年末着工までに短縮
- **OBBBA**：One Big Beautiful Bill Act（2025年7月4日成立）。米国の再エネ・水素税額控除を大幅に見直した法律
- **CINEA**：EUの気候・インフラ・環境執行機関。水素銀行の助成契約を締結する主体
- **FH2R**：福島水素エネルギー研究フィールド（浪江町）。10MW級の水電解設備を持つ国内最大級の実証拠点
- **GX経済移行債**：日本政府の脱炭素投資向け国債。将来の炭素賦課金・排出量取引収入で償還する建て付け
