## 1. 業界の定義・範囲

「水素・アンモニア」は独立した業界名というより、**複数の既存業界にまたがるテーマ**である。
境界を押さえておかないと、どの会社の話をしているのか分からなくなる。

```
【作る】────────【運ぶ・貯める】────────【使う】
 ・産業ガス         ・海運／造船           ・電力（混焼）
 ・石油元売り       ・石油元売り（基地）    ・鉄鋼（水素還元）
 ・総合化学         ・プラントエンジ        ・化学（原料）
 ・電機（水電解装置）・都市ガス（配管）      ・自動車（FCV）
 ・商社（権益・調達）                       ・肥料・製油所（既存需要）
```

- **隣接テーマとの境界**：[脱炭素・GX](../05_脱炭素・GX/README.md) が全体戦略、本テーマはその中の「燃料・原料の置き換え」を担う部分。
  [蓄電池](../04_蓄電池/README.md)・[EV・電動化](../03_EV・電動化/README.md) とは**競合関係**にある（乗用車・短時間の電力調整では電池が優位）
- **アンモニアを含む理由**：アンモニアは「水素の運び屋」であると同時に「それ自体が燃料」でもあるため。
  日本の政策が「水素**・アンモニア**」と並記するのはこの二重性ゆえ（→[02_運ぶ・貯める](02_運ぶ・貯める.md)）
- **含まれないもの**：既存の肥料用アンモニア製造、石油精製で使う従来型の水素は「既存需要」として区別する

## 2. 市場規模と成長性

| 指標 | 数値 | 年・出典の性格 |
| --- | --- | --- |
| 世界の水素需要（全体） | 約1億トン/年 | 2020年代半ば。IEA等の推計 |
| うち**低排出水素**の生産 | **約1 Mt**（全体の1%未満） | 2025年。IEA *Global Hydrogen Review 2026* |
| 水電解装置の世界導入容量 | **4 GW 超**（前年から倍増、うち新規の約75%が中国） | 2025年。IEA |
| 世界のアンモニア生産 | 約1.8〜2億トン/年（約8割が肥料用途） | 2020年代。業界統計 |
| 日本の導入目標 | 2030年 **300万t/年** → 2040年 **1,200万t/年** → 2050年 **2,000万t/年** | 水素基本戦略（2023年6月改定） |
| 日本の価格目標 | 2030年 **30円/Nm³**（≒334円/kg）、2050年 20円/Nm³ | 同上。現状は約100円/Nm³ |
| 官民投資 | 今後15年間で **15兆円** | 同上 |

> **成長性の読み方**：市場規模の予測値は各社バラバラで、あてにならない。
> 代わりに見るべきは **FID（最終投資決定）の件数と量**。2025年の新規FIDは約300ktpaで**初めて前年割れ**した（IEA）。
> 「発表された計画」ではなく「カネが出た案件」を数えるのが、この業界の正しい規模把握である。

## 3. バリューチェーン（川上 → 川下）

```
【原料】        【製造】           【転換・輸送】        【受入】         【利用】
天然ガス ──▶ 水蒸気改質＋CCS ──┐
石炭     ──▶ ガス化＋CCS      ├─▶ 液化(−253℃) ──▶ LH2船 ──┐
再エネ電力─▶ 水電解           ┘   MCH化         ──▶ ケミカル船┼─▶ 受入基地 ──▶ 発電（混焼）
                                  NH3合成        ──▶ NH3船  ┘   共用タンク     製鉄（還元）
                                  （ハーバー・ボッシュ法）          共用パイプ     化学原料
                                                                              FCV・FC
  ┌────────┐  ┌────────┐  ┌────────┐  ┌───────┐
  │装置メーカー │  │エンジ会社   │  │海運・造船   │  │商社（権益・  │
  │旭化成/東レ  │  │千代田化工   │  │川崎重工     │  │トレーディング）│
  │/東芝/IHI  │  │/日揮/東洋  │  │/商船三井    │  │三菱商事/三井 │
  └────────┘  └────────┘  └────────┘  └───────┘

  付加価値が集まる場所 ──▶ ① 装置・材料（電解質膜、触媒、極低温機器）
                        ② 権益・長期契約（安い海外電力・ガスを押さえた者）
                        ③ 川下の設備（混焼ボイラー、水素バーナー）
```

> **どこで稼げるか**：現時点で利益が出ているのは、**水素を売る事業ではなく、水素の設備を売る事業**である。
> 燃料としての水素はまだ補助金頼みだが、電解質膜（東レ）、混焼ボイラー（IHI）、極低温機器（川崎重工）は
> 世界の実証案件に売れている。「売る側」と「使う側」を混ぜて評価しないのがコツ。

## 5. 収益モデル・コスト構造

現時点で「水素を売って儲かる」事業はほぼ存在しない。収益の形は3つに分かれる。

| モデル | 稼ぎ方 | 経済的な特徴 |
| --- | --- | --- |
| **設備・材料を売る** | 水電解装置、電解質膜、混焼ボイラー、極低温機器 | 普通の製造業。**今いちばん現金が入る**。景気ではなく各国の補助金予算に連動 |
| **燃料を供給する** | 低炭素水素・アンモニアの長期供給契約 | 設備投資が重く回収20年級。**値差支援（補助金）が前提**。制度リスクが事業リスクそのもの |
| **権益・トレーディング** | 海外の安い電力・ガスを押さえて転売 | 商社型。初期の出資と撤退の判断速度が勝負 |

### グリーン水素のコスト分解

```
  グリーン水素コスト ＝ ①電力費（60〜70%） ＋ ②設備費の回収（25〜35%） ＋ ③運転維持費（〜5%）

  ①電力費 ＝ 電力単価 × 50〜55 kWh/kg      ← 水素1kgに必要な電力
  ②設備費 ＝ 装置価格 ÷ 生涯生産量          ← ここで効くのが【稼働率】

  ★この業界最大の矛盾★
     安い電気（太陽光の余剰）＝ 稼働率15〜20% → 装置費が回収できない
     高い稼働率（系統電力24h）＝ 電気代が高い → 電力費が跳ねる＋CO2が付く
     → 「安い電力」と「高い稼働率」は普通は両立しない
```

| 種別 | 価格レンジ | 年・性格 |
| --- | --- | --- |
| グレー水素（安い産ガス国） | 約1〜2ドル/kg | 2020年代。推計 |
| ブルー水素 | 約1.5〜3ドル/kg | 同上。CO2価格次第 |
| グリーン水素 | 約4〜8ドル/kg | 同上。地域差が大きい |
| EU水素銀行 第3回落札の補助単価 | **0.57〜3.49ユーロ/kg** | 2026年5月。欧州委員会（公式） |

## 6. 競争要因（KSF）と参入障壁

| KSF | 中身 | なぜ効くか |
| --- | --- | --- |
| **安い電力・ガスへのアクセス** | 中東・北米・豪州の権益 | コストの6〜7割が電力費。立地で勝負が決まる |
| **需要（オフテイク）の確保** | 拘束力ある長期引取契約 | 世界の案件が潰れる最大の理由がここ。日本の値差支援が共同申請を義務づけたのもこのため |
| **制度を読み切る力** | CI基準、補助の期限、税制 | 米45Vのように**政権交代で制度が反転する**。制度リスクが事業の生死を決める |
| **要素技術の独自性** | 電解質膜、触媒、極低温機器、燃焼制御 | 装置を売る側はここで差がつく。日本勢の強みが集中する領域 |
| **撤退判断の速さ** | 損切りの意思決定 | 2025〜26年は「早く降りた企業が傷が浅い」局面だった |

**参入障壁**：大規模案件は数千億円規模で、20年級の回収期間。プロジェクトファイナンスが組めるかどうかが実質的な障壁であり、
そのためには①長期オフテイク、②政府支援、③信用力のある出資者、の3点セットが要る。
逆に小規模な水電解装置の製造には障壁が低く、**中国勢の低価格攻勢**が起きている。

## 7. 規制・法制度

| 制度 | 内容 |
| --- | --- |
| **水素社会推進法**（2024年成立・10月施行） | 低炭素水素等の供給等事業計画を国が認定し、**①価格差に着目した支援（値差支援、15年）**、**②拠点整備支援**を実施。執行はJOGMEC |
| **水素基本戦略**（2017年策定、2023年6月改定） | 2030年300万t、2040年1,200万t、2050年2,000万tの導入目標と価格目標 |
| **GX推進法／GX経済移行債** | 支援の原資。将来の炭素賦課金・排出量取引収入で償還する建て付け |
| **高圧ガス保安法** | 水素の貯蔵・充填・輸送の安全規制。ステーション建設コストに直結 |
| **EU：EU-ETS、RED III、CBAM、欧州水素銀行** | 炭素価格で需要を強制し、オークションで補助を配分 |
| **米国：IRA 45V**（OBBBAで改正） | クリーン水素製造税額控除。最大3ドル/kg。**2027年末までに着工した設備に限定**へ短縮（2025年7月成立） |

詳細は [04_政策と価格差支援](04_政策と価格差支援.md)。

## 8. 最近のトピック

→ [05_直近トピック_2026](05_直近トピック_2026.md)（出典URL付き）

1. **IEAレビュー（2026年）**：低排出水素の生産は2025年に約1Mtへ（+20%）、電解装置は4GW超に倍増。一方で**新規FIDは初めて前年割れ**し、2030年パイプラインは27Mtに縮小
2. **世界で撤退が相次ぐ**：bp HyGreen Teesside中止、豪CQ-H2中止（丸紅・関電・岩谷が撤退）、ExxonMobil Baytown無期限停止、AGCのイオン交換膜投資中断。**技術ではなく経済性で止まっている**
3. **日本の制度が始動**：2026年3月、水素社会推進法で価格差支援6件・拠点整備2件が認定。ただし国内水電解案件は年1,607t／1,177tと小規模。量を担うのは**米ルイジアナ産の低炭素アンモニア（約77万t/年）**
4. **EU水素銀行 第3回**：応札は予算の6倍超、9件に10.9億ユーロを配分。落札補助単価は**0.57〜3.49ユーロ/kg**で、自立にはなお遠い
5. **国内の実装は明暗**：碧南の20%アンモニア混焼は2029年度商用化へ前進、水素還元製鉄は試験炉でCO2削減45%。一方**FCVは2025年に国内431台**（2021年比8割減）で、乗用車の水素は趨勢が決した

> **全体の構図**：2026年は「期待の縮小」と「制度の始動」が同時に起きた年。
> 残ったのは制度に支えられた案件だけで、量は海外ブルーアンモニアの輸入、技術差は装置・材料の外販、という二層構造になりつつある。
> 次の分水嶺は**2027年末**（米45Vの着工期限、IEAが警告する100GWのFID期限）。

## 9. 用語メモ

用語は各ノートの末尾「用語メモ」に分散して置いている。最頻出だけここに再掲する。

| 用語 | 意味 |
| --- | --- |
| **グレー／ブルー／グリーン水素** | 化石由来／化石＋CCS／再エネ電力＋水電解。→ [01](01_水素の作り方と色分類.md) |
| **炭素集約度（CI）** | 水素1kgを作るのに出たCO2の量。制度上の「低炭素」判定は色ではなくこの数値で行う |
| **水電解** | 水に電気を流して水素と酸素に分けること。ALK / PEM / AEM / SOEC の4方式 |
| **水素キャリア** | 水素を運びやすい別物質に変えたもの。液化水素・MCH・アンモニアが三大候補。→ [02](02_運ぶ・貯める.md) |
| **MCH** | メチルシクロヘキサン。常温常圧の液体で水素を運べる有機ハイドライド |
| **混焼／専焼** | 既存燃料に混ぜて燃やす／100%その燃料で燃やす。混焼率は通常「熱量比」 |
| **水素還元製鉄** | 鉄鉱石から酸素を取る還元剤に、炭素ではなく水素を使う製鉄法。→ [03](03_使い道とコスト競争力.md) |
| **値差支援** | 低炭素水素の実コストと既存燃料価格の差額を国が補填する制度。→ [04](04_政策と価格差支援.md) |
| **FID（最終投資決定）** | 企業が実際に資金を投じると決めること。「発表」「MOU」とは重みが違う |
| **オフテイク契約** | 製品の長期引取契約。これが無いとプロジェクトファイナンスが組めない |
| **Nm³** | 0℃・1気圧換算の体積。水素は 1kg ≒ 11.2Nm³。日本の政策目標はこの単位 |
