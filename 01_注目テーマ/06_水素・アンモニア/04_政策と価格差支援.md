# 政策と価格差支援（値差支援・拠点整備・各国戦略）

**このノートで分かること**：なぜ水素・アンモニアの話は必ず「政策」の話になるのか。
そして日本が2024年に作った「**値差支援**」という仕組みが、具体的に何をどう埋めるのか。

> 結論を先に：低炭素水素は、**放っておけば誰も買わない**。
> 既存燃料より確実に高く、買っても品質は同じだからである。
> だから世界中の政府が「高い分の差額を税金で埋める」仕組みを作った。
> つまりこの業界の需要は、**制度設計が作り出している人工的な需要**である。ここを外すと何も読めない。

---

## 1. なぜ補助金なしでは成立しないのか

低炭素水素の問題は「性能が悪い」ことではない。性能は既存の水素とまったく同じである。

```
              グレー水素        低炭素水素
  性能          同じ      =       同じ
  使い勝手      同じ      =       同じ
  価格        1〜2$/kg    <     4〜8$/kg     ← 3〜5倍
  CO2         9kg出る     >     ほぼゼロ      ← 買う側に金銭的メリットがない

  → 企業が自発的に買う理由は「CO2削減を評価する制度」が無ければ存在しない
```

これは経済学でいう**外部性**そのもので、CO2を出しても誰も罰金を払わない世界では、安いグレー水素が必ず勝つ。
選択肢は2つしかない。

| 手段 | 中身 | 採っている地域 |
| --- | --- | --- |
| **ムチ（炭素に値段をつける）** | 排出量取引、炭素税。CO2を出す側のコストを上げる | EU（EU-ETS、CBAM）が最も強力 |
| **アメ（差額を補填する）** | 補助金、税額控除、差額契約 | 日本（値差支援）、米国（45V）、EU（水素銀行） |

日本は炭素価格がまだ弱いため、**アメ側で押している**。これが日本の制度の特徴である。

## 2. 日本の枠組み：水素基本戦略と水素社会推進法

### 2-1. 水素基本戦略（2017年策定、2023年6月改定）

| 項目 | 内容 |
| --- | --- |
| 導入目標 | 2030年 **300万トン/年** → 2040年 **1,200万トン/年** → 2050年 **2,000万トン/年** |
| 価格目標 | 2030年に **30円/Nm³**（≒334円/kg）、2050年に **20円/Nm³**（≒223円/kg）。現状は約100円/Nm³ |
| 投資 | 官民で**今後15年間に15兆円**を投資 |
| 重点 | 水電解装置・燃料電池・液化水素・水素還元製鉄など9分野の戦略技術 |

2040年の1,200万トンは現在の日本の水素利用量（主に産業用で約200万トン）の**約6倍**に相当する。
「本当に届くのか」が常に問われる、野心的な目標である。

### 2-2. 水素社会推進法（2024年成立・同年10月23日施行）

正式名称は長い（脱炭素成長型経済構造への円滑な移行のための低炭素水素等の供給及び利用の促進に関する法律）。
中身は極めてシンプルで、**「計画を国が認定し、認定された事業に2種類の支援を出す」**という制度である。

```
        事業者（供給側 ＋ 利用側 が共同で申請）
                      │
                      ▼
        ┌───────────────────────┐
        │  低炭素水素等供給等事業計画       │
        │  ・炭素集約度が基準以下か          │
        │  ・2030年度までに供給開始するか    │
        │  ・利用側が新規設備投資をするか     │
        └───────────────────────┘
                      │ 主務大臣が認定
        ┌─────────────┴─────────────┐
        ▼                              ▼
  ① 価格差に着目した支援          ② 拠点整備支援
    （＝値差支援）                  （共用タンク・共用パイプライン等）
    15年間、基準価格と               FS → FEED → インフラ整備 の3段階で
    参照価格の差額を補填              設備費の一部を補助
        │                              │
        └────── 執行は JOGMEC ──────────┘
```

## 3. 「値差支援」の仕組みを図で理解する

日本の制度の中核。**英国の洋上風力で使われた差額決済契約（CfD）の考え方**を水素に応用したもの。

```
  円/kg
   ↑
   │  ┌──────────────────────────────┐
   │  │        基準価格（Strike Price）           │  ← 低炭素水素の実際の製造・輸送コスト
   │  │        ＝ 事業者が生き残れる価格            │     （申請時に事業者が提示し、国が査定）
   │  └──────────────────────────────┘
   │             ▲
   │             │  ◀━━━ この差額を国が15年間補填する（＝値差支援）
   │             ▼
   │  ┌──────────────────────────────┐
   │  │        参照価格（Reference Price）         │  ← 置き換えられる既存燃料の価格
   │  │        ＝ 利用者が払ってもよい価格           │     （LNG価格・アンモニア市況等に連動）
   │  └──────────────────────────────┘
   └────────────────────────────────▶ 時間（15年）

  ポイント①：参照価格は市況に連動するので、LNGが高騰すると差額は縮み、国の負担が減る
  ポイント②：支援は15年。さらに支援終了後10年の事業継続が条件 → 実質25年のコミットメント
  ポイント③：供給側と利用側の【共同申請】が必須 → 「作ったけど買い手がいない」を制度的に防ぐ
```

> ここが巧いところ：**共同申請の義務づけ**。
> 世界中の水素プロジェクトが潰れる最大の理由は「オフテイク（引取契約）が取れない」ことなので、
> 制度の入口でそれを要求している。裏を返せば、**買い手が見つからない案件は最初から申請できない**。

### 拠点整備支援

こちらは「みんなで使う設備」の建設費を補助する仕組み。
受入タンク、共用パイプライン、桟橋など、**1社では投資回収できないが無ければ誰も始められない設備**が対象。

- 支援は FS（事業性調査）→ FEED（基本設計）→ インフラ整備 の3段階で、段階ごとに継続可否を判断する
- 令和7年度当初予算でFEED事業に**57億円**、令和8〜12年度の5年間で総額**2,196億円**を計上（経産省資料、2026年3月）
- 大規模拠点は**3カ所程度**に絞る方針（報道）。「薄く広く」ではなく「厚く狭く」

## 4. 認定はどこまで進んだか（2026年3月時点）

ここが一番具体的で、かつ一次情報が取れる部分。

### 価格差支援（値差支援）の認定案件

2025年3月末時点で**27件の申請**があり、2026年3月時点で**6件が認定**されている。
うち2026年3月27日に認定された国内案件2件の詳細（経産省 水素・アンモニア小委員会 資料6、2026年3月27日）：

| | 山梨案件 | 福島案件 |
| --- | --- | --- |
| 場所 | 山梨県北杜市 | 福島県田村市、双葉郡浪江町 |
| 供給事業者 | 水素製造SPC（やまなしハイドロジェンカンパニー、サントリー） | 水素製造SPC（やまなしハイドロジェンカンパニー、ヒメジ理化） |
| 利用事業者 | サントリー 等 | ヒメジ理化 等 |
| 供給量 | **1,607 t-H2/年** | **1,177 t-H2/年** |
| 用途 | サントリー天然水 南アルプス白州工場の**殺菌工程の熱源** | 石英ガラスの**加工工程の熱源** |
| 技術 | 東レの電解質膜を用いた水電解装置 | 同左 |

JERAも価格差支援の認定を受けており、米ルイジアナ州「Blue Point」で製造する低炭素アンモニアを
碧南火力の燃料転換に使う計画（2025年12月報道）。

> 注目すべき点：**山梨・福島案件の供給量は年1,607トンと1,177トン**。
> 2040年目標の1,200万トンに対して、**0.01%台**である。
> 制度は動き出したが、規模はまだ「実証の延長」に近い。冷静に桁を見ておきたい。

### 拠点整備支援の認定案件

2025年6月30日の締切までに**12件の申請**。2026年3月27日付で**2件を認定**（同資料）。

| | ① JERA 案件 | ② 北海道案件 |
| --- | --- | --- |
| 拠点整備・運営 | JERA | 北海道電力、三井物産、IHI、苫小牧埠頭 |
| 主な利用事業者 | JERA、豊田自動織機 等 | 北海道電力、UBE三菱セメント、東ソー 等 |
| 生産地 | 米国ルイジアナ州（**約77万トン/年**） | 同左 |
| 利用地 | 愛知県碧南など | 北海道苫小牧など |
| 狙い | 碧南火力のクリーン化。IHIの混焼ボイラーの商用利用 | 苫東厚真発電所のクリーン化。中京・苫小牧地区のサプライチェーン形成 |

**約77万トン/年**という規模は、先の水電解案件（年1,000トン台）の**700倍**。
ここに、日本の戦略が「まず海外のブルーアンモニアを大量に持ってくる」方向であることがはっきり表れている。

### モニタリング体制

制度が興味深いのは、**認定後の監視の仕組みまで作り込んでいる**点。

- 認定案件は2030年度までに供給開始し、支援15年＋終了後10年の継続が前提
- 経産省とJOGMECが、EPCや運転計画の進捗、**炭素集約度の実績**、価格転嫁の状況を継続的に確認
- 水素・アンモニア小委員会に定期報告し、審議会が確認・助言する
- 市場の不確実性が高いことを制度側も認めており、「自立した事業として成立しうるか」を検証し続ける建て付け

## 5. 各国の戦略を並べる

| 国・地域 | 主な手段 | 狙い | 2026年時点の状況 |
| --- | --- | --- | --- |
| **日本** | 値差支援＋拠点整備（水素社会推進法）、GX経済移行債 | 海外から低炭素水素・アンモニアを調達し、既存火力と製鉄を延命しながら脱炭素 | 認定が始まったばかり。規模はまだ小さい |
| **EU** | EU-ETS（炭素価格）、**欧州水素銀行**のオークション、RED III の義務比率、CBAM | 域内でグリーン水素を作り、炭素価格で需要を強制的に作る | 第3回オークションで**9件に10.9億ユーロ**を配分（2026年5月）。落札補助単価 **0.57〜3.49ユーロ/kg**。応札は予算の6倍超 |
| **米国** | IRAの **45V** 税額控除（最大3ドル/kg）、水素ハブ（H2Hubs） | 安い天然ガス・再エネを武器に世界最安の水素を作る | 2025年7月成立の **OBBBA** で 45V は**2027年末までに着工した設備に限定**。当初の2032年末から大幅前倒しで縮小 |
| **中国** | 国有企業主導の大規模投資、電解装置の国産量産 | 装置産業としての覇権。国内の再エネ余剰の受け皿 | 世界の電解装置新規設置の**約75%**を占める（IEA, 2026年） |
| **中東（UAE・サウジ・オマーン）** | 国営企業による輸出プロジェクト | 石油後の輸出商品としての水素・アンモニア | NEOM等の大型案件。ADNOCが米Baytown案件に出資 |
| **豪州** | 産出ポテンシャルを武器に輸出拠点化を志向 | 日韓向け輸出 | **大型案件の中止が相次ぐ**。CQ-H2からは丸紅・関西電力・岩谷が撤退と報じられる |

### EUオークション方式と日本の値差支援の違い

| | EU 欧州水素銀行 | 日本 値差支援 |
| --- | --- | --- |
| 決め方 | **競争入札**。「補助はいくら要るか」を安い順に採択 | **個別審査**。事業計画を国が査定して基準価格を決める |
| 支援期間 | 最大10年 | **15年**（＋終了後10年の継続義務） |
| 長所 | 競争が働き、補助単価が下がる | 大型・長期の案件に踏み込める。買い手を制度的に確保できる |
| 短所 | 小規模案件に偏りやすい。落札後の脱落もある | 競争が働きにくく、基準価格の査定が甘いと過大補助になる |

> EUの第3回オークションが**予算の6倍超の応札**を集めた事実は、
> 「補助さえあれば作りたい事業者は山ほどいる」ことと、
> 「**補助なしで成立する案件は依然ほぼ無い**」ことを同時に示している。

## 6. 制度を見るときのチェックポイント

ニュースを読むときに確認すべき項目を並べておく。

1. **炭素集約度（CI）の基準値は何か**。「グリーン」と書いてあっても制度基準を満たすとは限らない
2. **支援期間は何年か**。10年と15年では事業の成立性がまったく違う
3. **オフテイク（引取契約）はあるか**。「覚書（MOU）」と「拘束力ある契約」は別物
4. **FID（最終投資決定）を取ったか**。発表とFIDの間には巨大な谷がある
5. **補助の原資は何か**。日本はGX経済移行債＝将来の炭素賦課金で返す借金。返済原資の議論が別途ある
6. **支援終了後に自立できる見込みがあるか**。15年後に価格が下がっていなければ、制度が切れた瞬間に事業が止まる

## 7. できていること／できていないこと（2026年時点）

| ✅ できていること | ❌ できていないこと |
| --- | --- |
| 日本は法律・予算・執行機関（JOGMEC）まで制度を作り切った | 認定はまだ価格差6件・拠点2件。2030年300万トンへの道筋は見えていない |
| 共同申請義務やモニタリング体制など、失敗を織り込んだ制度設計になっている | 認定案件の規模が小さい（水電解案件は年1,000トン台） |
| EUは炭素価格＋オークションで需要を制度的に作った | それでも補助が 0.57〜3.49ユーロ/kg 必要。自立には遠い |
| 米国は45Vで世界最大の税額控除を用意した | 2025年のOBBBAで2027年末着工までに縮小。**政権交代で制度が反転するリスク**が現実化した |
| 拠点整備で「大規模3カ所程度」と選択と集中の方針が出た | 選ばれなかった地域の構想が宙に浮く。地方の水素構想の多くは再検討が要る |

## 用語メモ

- **水素社会推進法**：2024年成立。低炭素水素の供給・利用計画を国が認定し、値差支援と拠点整備支援を出す法律
- **値差支援（価格差に着目した支援）**：低炭素水素の実コスト（基準価格）と既存燃料価格（参照価格）の差額を国が補填する制度
- **基準価格（ストライクプライス）**：事業者が事業を継続できる価格。申請時に提示し、国が査定して決める
- **参照価格**：置き換え対象の既存燃料の価格。市況に連動するので、補填額は年によって変わる
- **CfD（差額決済契約）**：基準価格と市場価格の差を決済する契約。英国の洋上風力で確立し、水素に応用された
- **拠点整備支援**：共用タンク・共用パイプラインなど、複数事業者が使うインフラの整備費補助
- **FEED（Front End Engineering Design）**：本格建設前の基本設計。ここで工費とスケジュールが固まる
- **FID（最終投資決定）**：企業が「本当にカネを出す」と決めること。報道の「発表」とは重みが全く違う
- **オフテイク契約**：製品の引取契約。これが無いとプロジェクトファイナンスが組めない
- **GX経済移行債**：日本政府が脱炭素投資の原資として発行する国債。将来の炭素賦課金・排出量取引の収入で償還する建て付け
- **JOGMEC**：エネルギー・金属鉱物資源機構。水素分野では補助金の交付・執行とモニタリングを担う
- **45V**：米IRAのクリーン水素製造税額控除。CIに応じ最大3ドル/kg。2025年のOBBBAで期限が短縮された
- **CBAM（炭素国境調整措置）**：EUが域外からの輸入品にEU-ETS相当の炭素コストを課す制度。鉄鋼などが対象
