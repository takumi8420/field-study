# ドローン

- 大分類: 注目テーマ
- 状態: done
- 更新日: 2026-09-19

一言でいえば、**「空にセンサーを持ち上げる道具」と「空を運ぶ乗り物」が、同じ「ドローン」という名前で呼ばれている産業**。
この2つは技術も経済性もまったく別物で、**前者（撮る・測る）はすでに商売になっており、後者（運ぶ）はまだ補助金の世界にいる**。
ニュースが噛み合わないのはここが混ざっているからで、この区別を先に入れておくと業界の話は一気に読みやすくなる。

もう1つ、この業界を理解する鍵は**バッテリーの物理**。電池のエネルギー密度が航空燃料より2桁低いため、
マルチコプターは「30分・数kg」という枠から出られない。制度が緩和されても、この枠は動かない。

## 1. 業界の定義・範囲

「ドローン」は正式には**無人航空機（UAV / UAS）**。日本の航空法では**機体重量100g以上の遠隔操作または自動操縦の航空機**が規制対象になる。
100g未満は「模型航空機」扱いで、航空法の無人航空機の規制からは外れる（ただし他の法律は別途かかる）。

| 含む | 含まない（隣接） |
| --- | --- |
| マルチコプター（回転翼が複数） | 人が乗る電動垂直離着陸機 → [空飛ぶクルマ](../16_空飛ぶクルマ/README.md) |
| 産業用固定翼UAV・VTOL機 | 有人の航空機・ヘリ → [航空機・防衛](../../02_自動車・機械/13_航空機・防衛/README.md) |
| 軍事用UAV・徘徊型兵器 | 人工衛星による上空観測 → [宇宙・衛星](../07_宇宙・衛星/README.md) |
| 地上のオペレーション（運航管理・データ解析） | 地上走行型の配送ロボット → [ロボット](../09_ロボット/README.md) |
| 機体部品（モーター、電池、フライトコントローラ） | 水中ドローン（ROV／AUV。航空法の対象外） |

**境界がはっきりしない2か所**がある。
①**空飛ぶクルマ**（人が乗るかどうかだけの違いで、技術系譜は地続き）、
②**データ解析事業**（機体は道具にすぎず、実態は測量業・画像解析業）。
とくに②は重要で、**国内市場の過半はサービス事業であって、機体メーカーの売上ではない**。

## 2. 市場規模と成長性

| 指標 | 数値 | 年・出典 |
| --- | --- | --- |
| 国内ドローンビジネス市場 | 約4,973億円（前年度比＋13.8%） | 2025年度、インプレス総合研究所 推計 |
| 同（見込み） | 約5,501億円（＋10.6%） | 2026年度見込み、同 推計 |
| 同（予測） | 約9,544億円 | 2030年度、同 予測（2025〜2030年度の年平均＋13.9%） |
| 世界のドローン市場（軍事含む広義） | 約838億ドル → 約964億ドル | 2025年→2026年、Grand View Research 推計 |
| 世界の商用ドローン市場（狭義） | 約244億ドル → 約280億ドル | 2025年→2026年、同 推計 |
| 日本国内流通機体の国産比率 | 約3%（中国製が約91%） | 2026年1月、政党資料を引く報道ベース |

> 注意：**世界市場の数字は定義次第で3〜4倍ぶれる**。軍事用を含むか、サービスや解析まで含むかで別物になる。
> 総額を比べるより、「**国内は点検・測量が中心で、サービス事業が過半**」という構成比のほうが安定して使える。

国内市場を3区分で見ると、傾向は次のとおり（インプレス総合研究所の区分。金額は推計）。

```
【機体】          【サービス】                    【周辺サービス】
 ドローン本体      点検・測量・農業・空撮の受託     スクール、保険、機体整備、
 ペイロード        データ解析・3D化                 ソフトウェア、運航管理
 ──────────       ─────────────────────────       ─────────────────────
 比率は縮小傾向    最大の塊（過半）・成長の主役      伸びるが規模は小さい
 中国製が大半      日本企業の主戦場                  免許制度化で一度伸びた
```

**機体で稼ぐのは難しく、機体を使ったサービスで稼ぐ**。これが日本のドローン産業の現在地。

## 3. バリューチェーン（川上 → 川下）

```
【部品】        【機体製造】      【運航】            【データ】         【出口】
電池セル  ──▶  DJI（中国）  ──▶  サービス事業者 ──▶ 3D点群／画像解析 ──▶ 発注者
モーター        ACSL（日）        測量会社            SfM・AI判定        ゼネコン
FC・ESC         Parrot（仏）      電力子会社          クラウド           電力・ガス
イメージセンサ   Skydio（米）     ドローン専業         レポート生成        自治体
プロペラ        Anzu/Autel 等     農業サービス業                          農家・防衛省
 ├── 中国の深圳周辺に集中 ──┤  ├──── ここが日本の事業者の居場所 ────┤

  付加価値：  低い（部品は汎用化）  →  低い（機体は買ってくる）  →  高い（現場知識＋解析）
```

**付加価値は右側に寄っている**。機体は「買ってくる道具」であり、儲けは
「誰も行きたくない場所のデータを、安全に・安く・繰り返し取ってくる」オペレーションと、
その**データを発注者の判断材料に変換する工程**に出る。
逆にいえば、**機体を作るだけの会社は、防衛・安全保障需要がなければ厳しい**。

## 4. 主要プレイヤーとシェア

| 企業 | 立ち位置 | 特徴 |
| --- | --- | --- |
| DJI（中国） | 民生・産業用機体の圧倒的首位 | 世界シェア**70%超**（推計）。垂直統合と深圳の部品網で価格・機能とも他を寄せつけない。米国では新規機種の型式認証が事実上止まった |
| Autel Robotics／EHang（中国） | DJIの次手 | Autelは産業用、EHangは自律飛行の乗用機に軸足 |
| Skydio（米） | 自律飛行に特化 | 障害物回避とAI追尾。米政府・警察・インフラ向け。消費者向けからは撤退 |
| Anduril／AeroVironment（米） | 防衛UAV | 偵察・徘徊型兵器。ウクライナ以降に評価が一変した領域 |
| Parrot（仏） | 欧州の数少ない量産メーカー | 安全保障要件を満たす機体として欧米官需を取る |
| ACSL（日） | 国産機の代表格 | 国産部品率を売りに官公庁・防衛省へ。2026年に防衛省から相次いで受注と報じられる |
| Terra Drone（日） | サービス＋運航管理 | 点検・測量の受託と、UTM（運航管理）事業。迎撃ドローンにも進出 |
| ヤマハ発動機（日） | 農業用の老舗 | 1990年代から産業用無人ヘリ。散布分野の原型を作った |
| 日本郵便／ANA／セイノー（日） | 物流ドローンの実装側 | レベル4飛行の実証・実装の先頭。ただし採算は自治体の補助に依存 |
| Zipline／Wing（米） | 配送専業 | Ziplineは累計200万便超（2026年1月）。医療物資中心で、日本の宅配とは前提が違う |

※**正確なシェア統計が存在しない業界**（非上場が多く、定義も揺れる）。
機体の出荷台数、受注額、飛行実績（便数・km）といった**物量で比較する**ほうが実務的。

## 5. 収益モデル・コスト構造

| 事業 | 何で儲けるか | コストの中心 | 利益の出方 |
| --- | --- | --- | --- |
| 機体販売 | 1台いくらの物販 | 部品（電池・モーター・センサー）と開発費 | **量産台数がすべて**。年数千台では固定費を割れない。DJIとまともに価格で戦えない |
| 点検・測量の受託 | 1現場いくらの役務 | **人件費（パイロット＋解析者）が6〜7割**、機体は償却で数% | 人が乗らない足場・高所作業車の代替。**現場あたり単価×年間稼働日数**で決まる |
| 農業散布 | 面積あたりの請負、または機体販売＋保守 | 機体、オペレーター、農薬 | 季節集中型。**繁忙期に何ha回せるか**が利益を決める |
| 物流配送 | 1便あたり運賃 | 運航要員、機体償却、離着陸拠点 | **1便あたりのコストが宅配便の単価を大きく上回る**。補助金なしでは黒字化していない |
| ソフト・運航管理 | ライセンス、SaaS | 開発人件費 | 導入社数が積み上がれば限界費用は小さい。ただし市場が小さい |
| スクール | 受講料 | 講師、教習用機体、施設 | 2022年の国家資格化で急増したが、**需要の先食いが終われば頭打ち**になる構造 |

> 業界に共通するクセ：**ドローンは「機体の値段」ではなく「1回飛ばすのにかかる人件費」で経済性が決まる**。
> 1人で安全に飛ばせる回数（＝目視外や自動航行が許されるか）が、そのまま収益性に直結する。
> 規制緩和が経済ニュースになるのは、それが**人件費の削減そのもの**だからである。

## 6. 競争要因（KSF）と参入障壁

**KSF**
1. **現場知識**：橋梁の劣化の見方、圃場の作付、送電線の設備台帳。ここが受託の参入障壁になる
2. **飛ばす資格と実績**：一等ライセンスと第一種機体認証、そして無事故の実績。発注者は事故を最も恐れる
3. **解析まで一気通貫**：画像を納品するだけでは値段が下がる。点群・図面・診断結果まで出せるかが単価を決める
4. **安全保障要件への適合**：官公庁・防衛では「中国製でないこと」が要求される場面が増えた。これが国産勢の唯一の追い風
5. **量産規模**（機体メーカーの場合）：DJI級の量を作れないなら、価格ではなく要件で勝負するしかない

**参入障壁**
- **低い**：機体を買って飛ばすだけなら誰でも始められる。だから空撮・簡易点検は価格競争になりやすい
- **高い**：レベル3.5／4の飛行、インフラ事業者の年間契約、防衛調達。ここは資格・実績・調達要件の壁が厚い
- 結果として**業界は二極化**する。前者は単価下落、後者は数が少ないが利幅が厚い

## 7. 規制・法制度

| 制度 | 内容 |
| --- | --- |
| **航空法**（無人航空機の章） | 100g以上が対象。飛行禁止空域（空港周辺・人口集中地区・150m以上）と飛行方法（目視内・日中・30m確保ほか）を定める。詳細は [02_規制と飛行レベル](02_規制と飛行レベル.md) |
| **機体登録制度**（2022年6月〜） | 100g以上は登録必須。**リモートID**（機体が識別信号を電波で発信）の搭載義務 |
| **機体認証**（第一種・第二種） | 機体の安全性の国の証明。レベル4には第一種が必要 |
| **操縦ライセンス**（一等・二等、2022年12月〜） | 国家資格。一等でレベル4が可能。2026年4月時点で一等4,592名、二等40,066名と報じられる |
| **飛行レベル1〜4（＋3.5）** | 目視内／目視外、無人地帯／有人地帯の組合せ。**3.5が実務の主力**になっている |
| **電波法** | 技適が必要。5.7GHz帯や長距離映像伝送は無線局免許・資格が要る |
| **小型無人機等飛行禁止法** | 国会・官邸・原子力事業所・防衛関係施設などの周辺を禁止 |
| **経済安全保障推進法** | 2026年にドローンを**特定重要物資**へ追加指定。国産化支援（費用の最大50%助成、2030年に年8万台体制）と報じられる |
| **米国 NDAA／FCC Covered List** | 米国で中国製機体の新規型式認証が事実上停止。日本企業の輸出・調達にも波及 |

## 8. 最近のトピック

詳細は [05_直近トピック_2026](05_直近トピック_2026.md) に出典URL付きでまとめた。要点は5つ。

1. **国内市場は2025年度4,973億円、2026年度5,501億円見込み**（推計）。牽引役は物流ではなく**インフラ・設備点検と土木・建築**
2. **米国がDJIを事実上締め出した**。2025年末にFCCのCovered Listへ追加され、新機種の型式認証が止まった（既存機の使用は継続可能）
3. **日本もドローンを特定重要物資に指定**。2030年に年8万台の国産体制を目標とする助成が始まると報じられる。現状の国産比率は約3%
4. **防衛需要が国産メーカーの収益源に**。ACSLが2026年に防衛省から相次ぎ受注し、業績見通しを大きく引き上げたと報じられる
5. **物流ドローンは期待と実態の差が大きい**。レベル4解禁から3年半が経っても、日本の商用配送は離島・山間部の補助事業が中心。
   一方で米Ziplineは累計200万便を超え、**「医療物資・道路が悪い地域」という条件がそろえば成立する**ことも示された
