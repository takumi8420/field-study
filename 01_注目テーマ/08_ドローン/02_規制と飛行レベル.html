ドローン｜規制と飛行レベル（何が許されていて、何がまだ難しいのか）

注目テーマドローン
あこのページの単語集用語に触れると意味を確認できます14語
型式認証限定変更特定飛行DID（人口集中地区）目視外飛行（BVLOS）リモートID機体認証（第一種／第二種）UTMFISSSORA緊急用務空域関連：01_機体の構造と技術03_用途別の事業性制度の考え方が近い 自動運転・空飛ぶクルマ

このノートで分かること：日本のドローン規制は「どこを飛ぶか（空域）」と「どう飛ぶか（方法）」の
2つの禁止リストでできており、その組合せを整理したものが飛行レベル1〜4である。
ニュースで語られる「レベル4解禁」が何を変え、実務では何がまだ使われていないのかを分解する。

結論から：2022年12月にレベル4（有人地帯の目視外飛行）が制度上解禁されたが、
実務の主力は2023年12月に新設された「レベル3.5」である。
レベル4は第一種機体認証と一等ライセンスという重い要件がかかり、件数が伸びない。
一方レベル3.5は「二等ライセンス＋保険＋機上カメラでの確認」で補助者と看板の配置を免除でき、
現場の人件費を直接削る。制度緩和が経済効果を持ったのは、レベル4ではなくレベル3.5のほうだった。

1. まず土台：航空法は「2つの禁止リスト」でできている

日本では機体重量100g以上（機体本体＋バッテリー。ペイロードは含めない）が無人航空機として航空法の対象になる。
100g未満は模型航空機として別扱いだが、飛行禁止法や条例は別途かかる。

 ┌─ 禁止リストA：飛んではいけない「空域」 ─────────────────┐
 │  ① 空港等の周辺                                          │
 │  ② 緊急用務空域（災害時に消防・警察のヘリが飛ぶ空域）      │
 │  ③ 地表・水面から 150m 以上の高さ                        │
 │  ④ 人口集中地区（DID）の上空  ← 都市部はほぼ全部これ      │
 └──────────────────────────────────────────────────────┘
 ┌─ 禁止リストB：やってはいけない「飛ばし方」 ───────────────┐
 │  ⑤ 夜間飛行     ⑥ 目視外飛行                             │
 │  ⑦ 人・物件から30m未満    ⑧ 催し場所の上空               │
 │  ⑨ 危険物の輸送  ⑩ 物件の投下                            │
 └──────────────────────────────────────────────────────┘
      A または B に1つでも当たる飛行 ＝ 「特定飛行」
      → 国交省の許可・承認が必要（または資格＋機体認証で不要にできる）

「特定飛行」という言葉が制度の中心。これに当たらない飛行（郊外の昼間・目視内・人から30m以上）なら、
登録さえしていれば許可は要らない。逆に、仕事で使う飛行のほとんどは特定飛行に該当する。

2. 飛行レベル1〜4（＋3.5）：2軸のマトリクス

レベルは「目視内か目視外か」×「人がいる場所か無人地帯か」の組合せに名前を付けたもの。

レベル 目視 地上の状況 補助者 必要なもの 実務での位置づけ
レベル1目視内問わない不要操縦者が手で飛ばす空撮、簡易点検。最も多い
レベル2目視内問わない不要自動操縦（ウェイポイント）測量、農薬散布の主流
レベル3目視外無人地帯必要（補助者・看板）許可・承認補助者を置く人件費が重く、伸び悩んだ
レベル3.5目視外無人地帯不要二等以上のライセンス＋保険＋機上カメラで確認2023年12月新設。実務の主力。道路・鉄道の横断が容易に
レベル4目視外有人地帯不要一等ライセンス＋第一種機体認証＋運航許可2022年12月解禁。要件が重く件数は限定的
        目視内                          目視外
      ┌─────────────┐              ┌──────────────────────┐
無人  │  Lv1 手動   │              │ Lv3   補助者アリ      │
地帯  │  Lv2 自動   │              │ Lv3.5 補助者ナシ ★主力 │
      └─────────────┘              └──────────────────────┘
      ┌─────────────┐              ┌──────────────────────┐
有人  │  Lv1 / Lv2  │              │ Lv4  一等＋第一種認証   │
地帯  │ （30m確保） │              │      ★制度はあるが件数少 │
      └─────────────┘              └──────────────────────┘

ポイント：レベル3.5が効いた理由は「補助者を置かなくてよい」の一点。
レベル3では、道路や線路を横切るたびに人を配置し、看板を立てる必要があった。
山間部を10km飛ばすのに現場要員が5〜6人必要になり、ドローンを使うほうが高くつくという本末転倒が起きていた。
3.5はここを「機上カメラで歩行者の有無を確認する」に置き換え、1〜2人で運航できるようにした。

3. 3つの資格・認証の関係を整理する

しばしば混同されるが、別々の制度である。

制度 何を証明するか 対象 種別
機体登録（2022年6月〜）「この機体は誰のものか」100g以上すべて登録記号の表示＋リモートID発信が義務
機体認証（2022年12月〜）「この機体は安全基準を満たすか」特定飛行に使う機体（任意だがレベル4では必須）第一種（レベル4可）／第二種（レベル3.5等）
操縦ライセンス（2022年12月〜）「この人は飛ばす技能があるか」操縦者一等（レベル4可）／二等
     機体登録          機体認証          操縦ライセンス
   （誰のものか）    （機体は安全か）    （人は飛ばせるか）
        │                 │                   │
        └────────┬────────┴─────────┬────────┘
                 │                   │
            第二種＋二等        第一種＋一等
                 ↓                   ↓
            レベル3.5            レベル4
  • 型式認証：メーカーが機体のモデル単位で取得する認証。これがあると1機ずつの検査が省ける。
    第二種型式認証を取得した機種は2026年時点でも十数機種にとどまり、選択肢が少ないことが普及の制約になっている
  • 限定変更：ライセンスには初期状態で「目視内・昼間・25kg未満」の限定がかかる。
    夜間飛行や25kg以上の機体を扱うには、追加の限定変更が必要
  • 取得者数は2026年4月時点で一等4,592名、二等40,066名と報じられる。
    二等が圧倒的に多く、現場はレベル3.5までで回していることがこの比率からも読み取れる

4. リモートID：空の「ナンバープレート」

2022年6月から、登録した機体はリモートID（機体の登録記号・位置・時刻を電波で発信する装置）の搭載が義務化された。
Bluetooth等で1秒間隔程度で発信し、地上の受信機やスマートフォンで誰の機体かが分かる。

  • 目的は匿名飛行の排除。事故や不審飛行が起きたときに所有者を特定できるようにする
  • 2022年6月20日までに事前登録した機体は免除（経過措置）。中古機を買うときの確認事項になる
  • 米国でも同様の制度（Remote ID）が施行されており、国際的にほぼ共通の方向

リモートIDは単なる規制ではなく、運航管理（UTM）の前提インフラでもある。
「誰がどこを飛んでいるか」が分かって初めて、複数機の同時運航や有人機との空域共用ができる。

5. 航空法以外にかかる法律

ドローンの許可を取っても飛ばせるとは限らない。別の法律が並列でかかるのがこの分野の厄介なところ。

法律 何を規制するか 実務上のポイント
電波法機体・送信機の電波技適マークのない機体は原則使えない。5.7GHz帯の映像伝送には無線局免許と第三級陸上特殊無線技士等が必要
小型無人機等飛行禁止法国会・官邸・原発・防衛関係施設・空港等の周辺航空法とは別建ての禁止。対象施設の管理者と都道府県公安委員会への通報が要る
民法207条（土地所有権）土地の上空も所有権が及ぶ他人の敷地上空の低空飛行はトラブルの元。私有地上空の飛行は地権者の了解が実務上の前提
道路交通法道路の使用道路上で離着陸したり、機材を置いて交通に影響を与える場合は道路使用許可
個人情報保護法・プライバシー映り込み総務省の「ドローンによる撮影映像の取扱いガイドライン」に沿う。住宅の窓が映るような撮影は要注意
自治体の条例公園・河川敷等都立公園、国営公園などは条例で一律禁止のことが多い。「航空法上OK＝飛ばせる」ではない
文化財保護法・自然公園法史跡・国立公園個別の許可が要る場合がある

現場での確認順序は ①航空法（空域・方法）→ ②電波法（技適・免許）→ ③土地の管理者 → ④条例 の4段。
このうち事故が起きやすいのは③で、法的には飛べても地権者・近隣住民の同意がなくて中止という例が多い。

6. 運航管理（UTM）とドローン航路

機体の数が増えると、「1機ずつ許可を出す」方式が破綻する。そこで整備が進んでいるのが2つの仕組み。

仕組み 内容 状況（2026年時点）
UTM（運航管理システム）飛行計画を事前に共有し、機体同士の衝突を防ぐ。有人機との調整も行う国交省の飛行情報共有システム（FISS）が土台。本格的な自動調整はこれから
ドローン航路河川上空・送電線上空など人がいない線状の空間を「道」として整備する経産省「デジタルライフライン全国総合整備計画」。2025年3月に浜松市・秩父市で開通式。一級河川1万km、送電網4万kmの整備を目指す
  従来：1飛行ごとに許可申請          航路方式：先に「道」を整備しておく

   事業者A ──▶ 個別申請 ──▶ 審査      ┌─── 送電線上空の航路（人がいない） ───┐
   事業者B ──▶ 個別申請 ──▶ 審査      │   事業者A ──▶                      │
   事業者C ──▶ 個別申請 ──▶ 審査      │   事業者B ──▶  航路の利用登録だけ   │
        審査が積み上がって詰まる       │   事業者C ──▶                      │
                                       └────────────────────────────────────┘

河川と送電線が選ばれた理由は明快で、①人がほぼいない、②細長く連続している、③管理者が限られている（国・電力会社）から。
都市部の空を開くより、すでに人がいない線を先に開くというのが現実的な順序になっている。

7. 海外制度との比較

国・地域 目視外飛行の扱い 特徴
日本レベル3.5／4として個別に制度化機体認証と操縦ライセンスを国が直接運用する。制度は精緻だが手続きが重い
米国Part 107（商用の基本ルール）＋ 目視外飛行の新ルール整備が進行従来は個別の免除（waiver）頼み。ルール化で一気に件数が伸びる可能性がある
EUOpen／Specific／Certified の3カテゴリーリスクの大きさで分類する方式。SORA（リスク評価手法）で個別に審査
中国実名登録と空域管理が厳格。産業利用は広範に普及機体メーカーが集中しており、実装と規制が同時に進む

日本の制度は「レベル」という分かりやすい階段を作った点で独特だが、
階段が細かいぶん、どの段にいるかの判定と書類が増えるという副作用もある。
EU方式（リスクで測る）との違いは、実務者がよく議論する論点。

8. 期待と実態の差

よく語られる期待 2026年時点の実態
レベル4が解禁されて都市部を自由に飛べる第一種機体認証を取った機体が極めて少なく、実施例は限定的。実務はレベル3.5
国家資格を取れば何でも飛ばせる資格は「許可・承認の一部を省略できる」だけ。空域と機体認証は別。二等だけではレベル4は不可
許可さえ取れば飛ばせる土地所有者・条例・住民合意が残る。航空法は4つある関門の1つ
制度が整えば物流が一気に広がる制度の次に来るのは採算。詳しくは 03_用途別の事業性
免許制度でスクールが儲かり続ける資格化直後に需要が集中し、その後は更新と新規参入の分だけ。先食いの構造

用語メモ

  • 特定飛行：禁止空域または禁止された飛行方法に当たる飛行。許可・承認の対象になる
  • DID（人口集中地区）：国勢調査で定義された人口密集エリア。都市部はほぼ該当し、上空は飛行禁止空域
  • 目視外飛行（BVLOS）：操縦者が機体を直接目で見ないで飛ばすこと。双眼鏡やモニター越しは「目視」に含まれない
  • リモートID：機体が登録記号・位置を電波で発信する装置。空のナンバープレートに相当
  • 機体認証（第一種／第二種）：機体の安全基準適合を国が証明する制度。第一種はレベル4用
  • 型式認証：モデル単位で取る認証。取得済み機種であれば個別検査が省ける
  • 限定変更：ライセンスの初期限定（目視内・昼間・25kg未満）を外す追加審査
  • UTM：無人機の運航管理システム。飛行計画の共有と衝突回避を担う
  • FISS：国交省の飛行情報共有システム。飛行計画を登録・参照する仕組み
  • SORA：欧州で使われる運航リスク評価手法。リスクの大きさで要求水準を決める
  • 緊急用務空域：災害・事故時に消防・警察の航空機が活動する空域。ドローンは原則飛行禁止
