学習済み更新 2026-09-19注目テーマ

一言でいえば、「空にセンサーを持ち上げる道具」と「空を運ぶ乗り物」が、同じ「ドローン」という名前で呼ばれている産業。
この2つは技術も経済性もまったく別物で、前者（撮る・測る）はすでに商売になっており、後者（運ぶ）はまだ補助金の世界にいる。
ニュースが噛み合わないのはここが混ざっているからで、この区別を先に入れておくと業界の話は一気に読みやすくなる。

もう1つ、この業界を理解する鍵はバッテリーの物理。電池のエネルギー密度が航空燃料より2桁低いため、
マルチコプターは「30分・数kg」という枠から出られない。制度が緩和されても、この枠は動かない。

1. 業界の定義・範囲

「ドローン」は正式には無人航空機（UAV / UAS）。日本の航空法では機体重量100g以上の遠隔操作または自動操縦の航空機が規制対象になる。
100g未満は「模型航空機」扱いで、航空法の無人航空機の規制からは外れる（ただし他の法律は別途かかる）。

含む 含まない（隣接）
マルチコプター（回転翼が複数）人が乗る電動垂直離着陸機 → 空飛ぶクルマ
産業用固定翼UAV・VTOL機有人の航空機・ヘリ → 航空機・防衛
軍事用UAV・徘徊型兵器人工衛星による上空観測 → 宇宙・衛星
地上のオペレーション（運航管理・データ解析）地上走行型の配送ロボット → ロボット
機体部品（モーター、電池、フライトコントローラ）水中ドローン（ROV／AUV。航空法の対象外）

境界がはっきりしない2か所がある。
①空飛ぶクルマ（人が乗るかどうかだけの違いで、技術系譜は地続き）、
②データ解析事業（機体は道具にすぎず、実態は測量業・画像解析業）。
とくに②は重要で、国内市場の過半はサービス事業であって、機体メーカーの売上ではない。

付加価値は右側に寄っている。機体は「買ってくる道具」であり、儲けは
「誰も行きたくない場所のデータを、安全に・安く・繰り返し取ってくる」オペレーションと、
そのデータを発注者の判断材料に変換する工程に出る。
逆にいえば、機体を作るだけの会社は、防衛・安全保障需要がなければ厳しい。

業界に共通するクセ：ドローンは「機体の値段」ではなく「1回飛ばすのにかかる人件費」で経済性が決まる。
1人で安全に飛ばせる回数（＝目視外や自動航行が許されるか）が、そのまま収益性に直結する。
規制緩和が経済ニュースになるのは、それが人件費の削減そのものだからである。

6. 競争要因（KSF）と参入障壁

KSF

  1. 現場知識：橋梁の劣化の見方、圃場の作付、送電線の設備台帳。ここが受託の参入障壁になる
  2. 飛ばす資格と実績：一等ライセンスと第一種機体認証、そして無事故の実績。発注者は事故を最も恐れる
  3. 解析まで一気通貫：画像を納品するだけでは値段が下がる。点群・図面・診断結果まで出せるかが単価を決める
  4. 安全保障要件への適合：官公庁・防衛では「中国製でないこと」が要求される場面が増えた。これが国産勢の唯一の追い風
  5. 量産規模（機体メーカーの場合）：DJI級の量を作れないなら、価格ではなく要件で勝負するしかない

参入障壁

  • 低い：機体を買って飛ばすだけなら誰でも始められる。だから空撮・簡易点検は価格競争になりやすい
  • 高い：レベル3.5／4の飛行、インフラ事業者の年間契約、防衛調達。ここは資格・実績・調達要件の壁が厚い
  • 結果として業界は二極化する。前者は単価下落、後者は数が少ないが利幅が厚い

7. 規制・法制度

制度 内容
航空法（無人航空機の章）100g以上が対象。飛行禁止空域（空港周辺・人口集中地区・150m以上）と飛行方法（目視内・日中・30m確保ほか）を定める。詳細は 02_規制と飛行レベル
機体登録制度（2022年6月〜）100g以上は登録必須。リモートID（機体が識別信号を電波で発信）の搭載義務
機体認証（第一種・第二種）機体の安全性の国の証明。レベル4には第一種が必要
操縦ライセンス（一等・二等、2022年12月〜）国家資格。一等でレベル4が可能。2026年4月時点で一等4,592名、二等40,066名と報じられる
飛行レベル1〜4（＋3.5）目視内／目視外、無人地帯／有人地帯の組合せ。3.5が実務の主力になっている
電波法技適が必要。5.7GHz帯や長距離映像伝送は無線局免許・資格が要る
小型無人機等飛行禁止法国会・官邸・原子力事業所・防衛関係施設などの周辺を禁止
経済安全保障推進法2026年にドローンを特定重要物資へ追加指定。国産化支援（費用の最大50%助成、2030年に年8万台体制）と報じられる
米国 NDAA／FCC Covered List米国で中国製機体の新規型式認証が事実上停止。日本企業の輸出・調達にも波及

8. 最近のトピック

詳細は 05_直近トピック_2026 に出典URL付きでまとめた。要点は5つ。

  1. 国内市場は2025年度4,973億円、2026年度5,501億円見込み（推計）。牽引役は物流ではなくインフラ・設備点検と土木・建築
  2. 米国がDJIを事実上締め出した。2025年末にFCCのCovered Listへ追加され、新機種の型式認証が止まった（既存機の使用は継続可能）
  3. 日本もドローンを特定重要物資に指定。2030年に年8万台の国産体制を目標とする助成が始まると報じられる。現状の国産比率は約3%
  4. 防衛需要が国産メーカーの収益源に。ACSLが2026年に防衛省から相次ぎ受注し、業績見通しを大きく引き上げたと報じられる
  5. 物流ドローンは期待と実態の差が大きい。レベル4解禁から3年半が経っても、日本の商用配送は離島・山間部の補助事業が中心。
    一方で米Ziplineは累計200万便を超え、「医療物資・道路が悪い地域」という条件がそろえば成立することも示された
