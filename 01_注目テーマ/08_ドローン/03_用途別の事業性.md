# ドローン｜用途別の事業性（どこが儲かり、どこがPoC止まりか）

このノートで分かること：ドローンの用途は「点検・測量・農業・物流・警備・防衛」に大別されるが、
**黒字で回っているのは上3つ、補助金頼みなのが物流**という偏りがある。
その分かれ目を、「**何と比べて安いのか**」という1つの問いで整理する。

**結論から**：ドローンが商売になるのは、
**①代替される手段が極端に高い（足場・高所作業車・ヘリ・人手）**、
**②人が行くと危ない、または行けない**、
**③同じ作業を何度も繰り返す**、
の3条件がそろう場所だけ。**物流はこの3つのどれも十分に満たしていない**（地上の宅配便が安すぎる）。
逆に**インフラ点検は3つすべてを満たす**ので、国内市場の最大の塊になっている。

## 1. 事業性を測る唯一の物差し：代替コストとの差

ドローン単体の費用ではなく、**「それをやめられる従来手段の費用」との差額**が事業の源泉になる。

```
  従来手段のコスト  ───────────────────────────▶  (A)
  ドローン運航のコスト ──────▶ (B)
                      ├────── 差額 = 事業の取り分 ──────┤
                      (A) − (B)

  (B)の中身：パイロット人件費 + 解析者人件費 + 機体償却 + 保険 + 移動・準備
             └─── 6〜7割は人件費。機体代は意外に小さい ───┘
```

だから**制度緩和（補助者が不要になる等）は、そのまま (B) を下げて差額を広げる**。
レベル3.5が業界にとって大きかったのは、この式で見れば当然の話になる。

## 2. 用途ごとの経済性（一覧）

| 用途 | 何を代替するか | 代替手段のコスト感 | ドローンで置き換わるか | 事業としての現在地 |
| --- | --- | --- | --- | --- |
| **インフラ点検** | 足場、高所作業車、橋梁点検車、ロープアクセス | 橋1件で足場だけで数百万円規模になることも | ○ 外観の一次スクリーニングは置き換わった | **黒字。国内最大の用途** |
| **測量（土木）** | トータルステーション、有人機測量、人手の実測 | 現場数日〜十数日の人工 | ◎ 数時間で広域の3Dが取れる | **黒字。i-Constructionで制度的に後押し** |
| **農業散布** | 背負い式散布、無人ヘリ、人力 | 人力は10a数十分。重労働で高齢化が深刻 | ◎ 10aを数分 | **黒字。国内で最も台数が出た用途** |
| **警備・巡回** | 警備員の巡回、固定カメラ | 人の常駐が高い | △ 補助的。天候と夜間に弱い | 導入は進むが、人の完全代替には至らず |
| **災害・消防** | ヘリ、人の立入り | ヘリは1時間数十万円 | ◎ 状況把握は完全に定着 | **黒字ではないが公共調達として定着** |
| **物流配送** | 軽トラック＋ドライバー、宅配便 | **1個あたり数百円** | ✕ 現状はコストで勝てない | **PoC・補助事業が中心** |
| **防衛・安全保障** | 有人偵察機、砲兵観測、人的偵察 | 極めて高い（人命を含む） | ◎ 費用対効果が破格 | **急拡大。国産メーカーの主収益源に** |

> 一番読み取ってほしいのは**物流の行**。他の用途は「代替手段が高い」から成立しているのに対し、
> 物流の代替手段である日本の宅配便は**1個数百円という世界最安水準**。
> ここに勝つのは、技術ではなく算数の問題として非常に難しい。

## 3. インフラ点検：国内市場の主役

日本のドローン市場を押し上げているのは物流でも空撮でもなく、**橋・トンネル・プラント・送電線・太陽光の点検**である。

**なぜ成立するか**
1. **足場・高所作業車を組まなくてよい**。橋梁の近接目視は足場だけで数百万円かかることがあり、桁が違う
2. **交通規制が要らない／短くて済む**。道路を止める社会的コストが大きい
3. **道路橋は5年に1度の近接目視点検が法定**。**繰り返し発生する需要**である（→ [土木・インフラ維持](../../12_建設・住宅・不動産/05_土木・インフラ維持/README.md)）
4. 日本の橋梁・トンネルの多くが高度成長期に作られ、**一斉に更新期を迎えている**

```
【従来】                                    【ドローン】
 足場設置（数日〜数週）                      機体で撮影（数時間）
    ↓                                           ↓
 技術者が登って打音・目視                    AI画像解析でひび割れ抽出
    ↓                                           ↓
 所見をスケッチ・報告書                      3Dモデル上に損傷をマッピング
    ↓                                           ↓
 足場解体（数日）                            疑わしい箇所だけ人が近接確認
 ───────────────────────                  ───────────────────────
 費用：高い／期間：長い／危険                費用：数分の1／期間：短い／安全
```

**ただし完全代替ではない**。打音検査（叩いて内部の浮きを判定する）は接触が要るため、
ドローンは「**全部を撮って、危ない箇所を絞り込む一次スクリーニング**」の役割が中心。
最終判断は人が行う。ここを誤解すると「点検が全自動になる」という過大な期待になる。

**儲けどころ**は撮影ではなく**解析と報告書**。写真の納品は価格競争になるが、
損傷図・数量・劣化度判定まで出せると単価が数倍になる。

## 4. 測量：制度が需要を作った例

- **i-Construction**（国交省が2016年から推進する建設現場の生産性向上施策）で、
  公共工事の起工測量・出来形管理に**3次元データの活用が標準化**された
- 「公共測量におけるUAVの使用に関するマニュアル」が整備され、**発注者側が成果物として3D点群を求める**ようになった
- つまり**顧客が3Dデータを要求する制度になった**ため、測量会社はドローンを使わざるを得ない

| 手法 | 取れるもの | 得意 | 不得意 |
| --- | --- | --- | --- |
| **写真測量（SfM）** | 写真から復元した点群・オルソ画像 | 安い、高解像度、広域 | 樹木の下、暗所、無地の面 |
| **UAV LiDAR** | 距離を直接測った点群 | **草木の隙間から地面を拾える**、暗所 | 機材が高価、機体が重くなる |
| **地上型（TS・地上レーザー）** | 高精度の点 | 精度が最も高い | 時間がかかる、広域は非現実的 |

**RTK-GNSS（数cm精度の測位）**が実用化したことで、地上に標定点（対空標識）を大量に置く作業が減り、
現場の人工がさらに落ちた。測位技術が事業性に直結する典型例（→ [01_機体の構造と技術](01_機体の構造と技術.md)）。

## 5. 農業：国内で最も普及した用途

- 農業用ドローンは**2019年の約4,000台から2024年には約4万台**へと、5年で約10倍に増えた（農林水産省の調査ベース）
- 市場規模は2025年時点で**約141億円**規模との推計もある
- 水稲の防除（農薬散布）が入口で、肥料散布、播種、生育診断（リモートセンシング）、受託サービスへ広がった

**なぜ普及したか**
1. **人力散布が重労働で、担い手が高齢化している**。代替の切迫度が他用途より高い
2. **圃場は無人地帯**。制度上のハードルが低く、レベル2（目視内自動）で回る
3. **面積あたりで課金できる**ため、成果と料金が対応しやすい
4. 有人の産業用無人ヘリ（ヤマハ発動機などが1990年代から展開）で**下地ができていた**

```
【散布の進化】
 人力（背負い式）  ─▶  産業用無人ヘリ  ─▶  マルチコプター  ─▶  変量散布
  10aに数十分         高価・要免許        安価・普及         AIで必要な所だけ
  重労働・高齢化       農協中心           個人農家にも       薬剤コストを削減
```

最近は**マルチスペクトルカメラで生育のムラを測り、必要な場所にだけ散布する変量散布**が広がり始めた。
散布の作業単価ではなく**農薬・肥料のコスト削減**で価値を出す方向で、
これは農業機械・種苗側の産業と重なる（→ [農業・種苗・肥料](../../08_食品・農水産・外食/12_農業・種苗・肥料/README.md)、
[農業機械](../../02_自動車・機械/08_農業機械/README.md)）。

## 6. 物流：期待と実態の差が最も大きい領域

**事実関係**
- 2022年12月にレベル4が解禁され、2023年3月に国内初のレベル4飛行（日本郵便による配送）が実施された
- しかし2026年時点でも、日本の商用ドローン配送は**離島・山間部・過疎地の自治体補助事業が中心**
- 都市部の日常的な配送は、限定的な試験段階にとどまる

**なぜ採算に乗らないのか**

| 項目 | 宅配便（軽トラック） | 物流ドローン |
| --- | --- | --- |
| 1回の輸送量 | 100個以上 | **1〜数個** |
| 1個あたりコスト | 数百円 | 運航要員の人件費を便数で割ると**桁が大きい** |
| 悪天候 | ほぼ影響なし | **風速・降雨で欠航**。年間の稼働率が読めない |
| 発着場 | 玄関先 | 安全な離着陸場所の確保が必要 |
| 距離 | 数十km以上 | 実用片道**数km**（→ [01_機体の構造と技術](01_機体の構造と技術.md) の算数） |

> 核心：**日本の宅配便が安く、密度が高すぎる**。1台の軽トラックが100個以上をまとめて運ぶのに対し、
> ドローンは1〜数個を1便で運ぶ。**まとめ運びができない乗り物が、まとめ運びに勝つのは構造的に難しい**。
> ドローン配送が成立するのは、**まとめ運びができない条件**——離島、山間部、道路が崩れた災害時、
> あるいは「今すぐ1個だけ」が極めて価値を持つ**医療物資**——に限られる。

**海外で成立している例が示すもの**
- 米Ziplineは**累計200万便を突破**（2026年1月、同社発表）。2026年半ばには累計250万便を超えたと報じられる
- 出発点はルワンダ・ガーナでの**輸血用血液の配送**。道路インフラが弱く、**地上輸送の代替コストが高い**場所だった
- つまり「ドローン配送は成立しない」のではなく、**成立する条件が日本の都市部とは違う**というのが正確な読み方

**日本でありうる筋**
1. **過疎地の買い物・医薬品配送**（自治体の生活支援としての位置づけ。純民間採算ではない）
2. **災害時の緊急輸送**（平時の採算ではなく、備えとしての価値）
3. **建設現場・プラント内の場内輸送**（公道を通らず、距離が短く、人件費が高い）
4. **離島・海上**（船便との比較なら勝てる場面がある）

## 7. 警備・災害・防衛

| 領域 | 使われ方 | 経済性 |
| --- | --- | --- |
| **警備** | 大規模施設の巡回、イベント上空の俯瞰、侵入検知の初動確認 | 警備員の完全代替ではなく**補助**。夜間・悪天候に弱く、常時運用の壁が残る（→ [警備](../../15_サービス・生活関連/21_警備/README.md)） |
| **消防・災害** | 火災の俯瞰、土砂災害の被災状況把握、行方不明者捜索（赤外線） | ヘリの代替として費用対効果が明確。**公共調達として定着**した |
| **防衛** | 偵察、着弾観測、徘徊型兵器（自爆型）、対ドローン（迎撃） | **費用対効果が破格**。数万円の機体で数億円の装備を脅かせる非対称性が本質 |

防衛領域は2022年以降に評価が一変した。ウクライナでの戦闘を通じて、
**安価な機体を大量に消費する運用**が有効だと示され、各国が調達を急いでいる。
ウクライナの年間生産は2025年に約450万機（うちFPV型が200万機超）、
2026年の目標は700万〜1,000万機とされ、大統領自身が「年1,000万機を製造している」と述べたと報じられる。

この結果、日本でも**防衛省の調達が国産メーカーの主収益源**になりつつある
（詳細は [04_産業構造とサプライチェーン](04_産業構造とサプライチェーン.md)）。
民生用途で価格競争にさらされていた国産勢にとって、**安全保障要件は数少ない価格以外の競争軸**になっている。

## 8. まとめ：用途の地図

```
            代替コストが高い
                  ↑
   防衛 ●         │         ● インフラ点検
                  │         ● 測量
   災害 ●         │         ● 農業散布
  ────────────────┼────────────────▶ 繰り返し発生する
                  │                    （＝需要が安定する）
   空撮（一品) ●  │  ● 警備（補助的）
                  │
   物流（都市部）●│
                  ↓
            代替コストが低い

   右上ほど事業になりやすい。物流は「左下」に置かれてしまうのが問題の本質。
```

## 用語メモ

- **SfM（Structure from Motion）**：多数の写真から立体形状を復元する手法。写真測量の中核
- **点群**：3次元座標を持つ点の集合。測量・点検の成果物の基本形式
- **オルソ画像**：ゆがみを補正し、真上から見た正しい縮尺の画像にしたもの。図面と重ねられる
- **i-Construction**：国交省が進める建設現場のICT活用施策。3次元データの活用を標準化した
- **近接目視点検**：道路橋・トンネル等に法定されている、手の届く距離での目視点検（5年に1度）
- **変量散布**：圃場内の生育のムラに応じて散布量を変える方式。薬剤・肥料コストを削減する
- **NDVI**：近赤外と赤の反射率から植生の活性を示す指標。マルチスペクトルカメラで取得する
- **FPV**：機体のカメラ映像をゴーグルで見ながら操縦する方式。軍事用の自爆型機体で多用される
- **徘徊型兵器**：目標上空で滞空し、発見次第突入する自爆型の無人機
- **対ドローン（C-UAS）**：探知・妨害・迎撃によって敵ドローンを無力化する技術・装備の総称
