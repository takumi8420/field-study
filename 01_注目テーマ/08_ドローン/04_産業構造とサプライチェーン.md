# ドローン｜産業構造とサプライチェーン（DJI寡占と、その崩し方）

このノートで分かること：ドローンの機体産業は**1社（DJI）が世界シェア7割超を握る極端な寡占**で、
その供給網は中国・深圳に集中している。この構造がなぜできたのか、
そして**2025〜2026年に各国が「安全保障」を理由にそれを崩しにかかっている**現在地を整理する。

**結論から**：DJIの強さは製品の出来ではなく、**「民生カメラ市場の量」→「部品単価の低下」→「機能の高度化」→「さらに量」**
という回転にある。この回転に技術で勝つのは難しい。だから各国が使ったのは**規制という別の軸**だった。
米国は2025年末にDJIをFCCのCovered Listへ加え、新機種の型式認証を事実上止めた。
日本は2026年にドローンを**特定重要物資**に指定し、国産化に助成を始めたと報じられる。
ただし日本国内で流通する機体の国産比率は**約3%**と報じられており、**構造の転換は始まったばかり**である。

## 1. 全体の地図：4つのレイヤー

```
┌─ レイヤー4：発注者 ─────────────────────────────────────────────┐
│  ゼネコン／電力・ガス／自治体／農家／防衛省／保険会社              │
│  「データが欲しい」「危ない作業をやめたい」                        │
└──────────────────────────▲──────────────────────────────────┘
┌─ レイヤー3：サービス事業者 ─┴───────────────────────────────────┐
│  測量会社、点検専業、電力子会社、Terra Drone、農業サービス業       │
│  機体を買ってきて、飛ばし、解析して納品する ← 日本企業の主戦場     │
└──────────────────────────▲──────────────────────────────────┘
┌─ レイヤー2：機体メーカー ───┴───────────────────────────────────┐
│  DJI（中国）が7割超。Autel、Skydio、Parrot、ACSL、Anduril …       │
│  価格競争が激しく、安全保障要件だけが別の競争軸                    │
└──────────────────────────▲──────────────────────────────────┘
┌─ レイヤー1：部品 ───────────┴───────────────────────────────────┐
│  電池セル／ブラシレスモーター／ESC／フライトコントローラ           │
│  イメージセンサ／ジンバル／プロペラ／通信チップ／磁石              │
│  → 中国・深圳周辺に集中。日本勢はセンサー・電池・素材で存在感      │
└────────────────────────────────────────────────────────────────┘
```

**金額の多くはレイヤー3で発生し、技術の依存はレイヤー1・2にある**。
この「稼ぐ場所」と「握られている場所」のズレが、日本の政策議論の出発点になっている。

## 2. なぜDJIが7割を取れたのか

| 要因 | 中身 | なぜ他社が真似できないか |
| --- | --- | --- |
| **深圳の部品網** | モーター、基板、樹脂部品、電池を数日で試作・量産できる集積 | 地理的な集積は資本では買えない |
| **垂直統合** | フライト制御、ジンバル、カメラ、映像伝送、アプリまで自社 | 各要素を別会社から買うと、統合品質と価格で負ける |
| **民生カメラ市場の量** | 消費者向けが数百万台規模。部品単価が桁で下がる | 産業用専業は年数千〜数万台。**部品を同じ値段で買えない** |
| **ソフトの完成度** | 誰でも飛ばせる操作性、自動航行アプリ、解析クラウド | ソフトは量産数に比例して磨かれる（不具合報告の数が違う） |
| **価格** | 同等機能で他社の数分の1 | 上記4つの結果 |

```
    販売台数が多い ──▶ 部品を安く大量に買える ──▶ 製品が安く高機能
          ▲                                              │
          └──────────────── さらに売れる ◀───────────────┘

    この輪に入れない専業メーカーは、同じ土俵では永久に追いつけない。
    → だから勝負する軸を「価格」から「調達要件（どこ製か）」へ移す必要があった。
```

> ポイント：**ドローンはスマートフォン産業の副産物**である。
> IMU、イメージセンサ、無線チップ、リチウム電池、そして小型カメラ——
> 主要部品のほとんどがスマートフォン向けに量産されたものの転用で、
> 深圳はその供給網の中心地だった。**DJIが中国から出たのは偶然ではない**
> （→ [PC・スマートフォン](../../03_電機・電子部品/11_PC・スマートフォン/README.md)、
> [電子部品](../../03_電機・電子部品/05_電子部品/README.md)）。

## 3. 部品はどこから来ているか

| 部品 | 主な供給 | 日本勢の位置 |
| --- | --- | --- |
| **リチウムイオン電池セル** | 中国（CATL、EVE等）、韓国 | 素材（電解液、セパレータ、正極材）で存在感（→ [二次電池](../../03_電機・電子部品/08_二次電池/README.md)） |
| **ブラシレスモーター** | 中国が大半 | 日本電産系など高性能品の供給はあるが、価格で不利 |
| **ネオジム磁石** | 中国が圧倒的（レアアース精製を含む） | 素材メーカーは強いが、原料は中国依存（→ [レアメタル・レアアース](../../11_資源・エネルギー・鉄鋼金属/13_レアメタル・レアアース/README.md)） |
| **イメージセンサ** | **ソニーが世界首位級** | **日本の数少ないチョークポイント**。DJI機にも広く使われる |
| **フライトコントローラ／SoC** | 中国・台湾・米国 | 汎用マイコンは調達可能 |
| **通信チップ** | Qualcomm等、中国メーカー | 日本勢は限定的 |
| **LiDAR** | 中国（Hesai、Livox）が急速に安価化、米国勢 | 一部に国産あり。車載用と共通の流れ |

**皮肉な構図**として、DJI機の中核部品であるイメージセンサは日本製であることが多い。
つまり**「中国依存」は一方向ではなく、相互に噛み合っている**。
安全保障の議論では、機体の国籍だけでなく**この部品レベルの相互依存**を見ないと実態を誤る。

## 4. 安全保障規制：軸が「価格」から「どこ製か」へ

なぜドローンが安全保障の対象になるのか。理由は3つある。

1. **データ**：飛行経路、撮影画像、インフラの構造情報がメーカーのクラウドに渡りうる
2. **供給途絶**：有事に部品・機体の供給が止まれば、点検も災害対応も止まる
3. **軍民両用**：民生機がそのまま偵察・攻撃に転用できることが実戦で示された

### 米国の動き

| 時期 | 内容 |
| --- | --- |
| 2020年頃〜 | 国防総省が中国製機体の使用を制限。**Blue UAS**（政府調達可能な機体リスト）を整備 |
| 2025年国防権限法（NDAA） | DJI等について**1年以内に安全保障上の審査を行う**ことを要求。**審査が行われなければ自動的にFCCのCovered Listに追加**という仕掛け |
| 2025年12月 | 審査期限が到来し、行政側の判断を受けて**FCCがDJI等をCovered Listへ追加**。新規の機器認証が事実上停止したと報じられる |
| 2026年時点 | **既存機の所有・使用は引き続き可能**だが、新機種の正規輸入・販売は止まる。連邦・州レベルで政府調達からの排除も進行 |

> 誤解されやすい点：**「DJI禁止」＝「今持っている機体が飛ばせなくなる」ではない**。
> 止まったのは**新しい機種がFCCの認証を取れなくなったこと**で、
> 効いてくるのは「買い替え・増機のタイミング」。じわじわと市場が入れ替わる設計になっている。

### 日本の動き

- 2026年、政府は**経済安全保障推進法の「特定重要物資」にドローンを追加指定**したと報じられる
- 研究開発・設備投資の費用の**最大50%を助成**し、**2030年時点で年8万台の生産体制**の整備を目指す方針
- 対象は機体だけでなく、**モーター・電池といった主要部品の生産設備も含める**とされる
- 背景にあるのが**国内流通機体の国産比率約3%（中国製約91%）**という数字（2026年1月、政党資料を引く報道ベース）
- 防衛省側も国産機の大量調達に動いており、**需要と供給の両面から国産化を組む**構図

```
  【需要側】防衛省・官公庁の調達要件      【供給側】特定重要物資としての助成
        「中国製でないこと」                  「設備投資の最大50%」
              ↓                                      ↓
        ───────────── 国産メーカーへ需要と資金を同時に流す ─────────────
                              ↓
            ただし量が足りない。年8万台でも DJI の出荷量には遠く及ばず、
            「コストでは勝てない前提で、要件で守られた市場を作る」という設計。
```

> 冷静に見るべき点：この政策は**国産機をDJIと同じ価格にする政策ではない**。
> 「高くても買う客（政府・重要インフラ）を確保して、その範囲で産業を維持する」という設計である。
> 民生市場でDJIに勝つ絵は、少なくとも2026年時点では描かれていない。

## 5. 国産メーカーの現在地

| 企業 | 立ち位置 | 2026年時点の状況 |
| --- | --- | --- |
| **ACSL** | 国産機体の代表格。国産部品率を売りに官公庁・防衛へ | 2026年に防衛省から小型空撮機の受注が相次ぎ、**累計十数億円規模**と報じられる。日本防衛装備工業会の正会員にドローンメーカーとして初承認されたとされる。売上高は2025年12月期 約26億円 → 2026年12月期 約40億円の見通しと報じられる |
| **Terra Drone** | サービス＋運航管理（UTM）。海外展開も | 点検・測量の受託と運航管理システム。迎撃ドローンをウクライナで実運用開始と発表 |
| **ヤマハ発動機** | 産業用無人ヘリの老舗（1990年代〜） | 農業散布の原型を作った。現在も農業・物流で展開 |
| **クボタ／ヤンマー等** | 農機メーカーとしての農業ドローン | 既存の販売網と保守網が強み（→ [農業機械](../../02_自動車・機械/08_農業機械/README.md)） |
| **日本郵便／ANA／セイノー等** | 物流の実装側 | レベル4・3.5の実証と社会実装。採算は補助に依存 |
| **各電力会社の子会社** | 送電線・鉄塔の点検 | 自社設備という**確実な内需**を持つ。事業性が最も安定している層 |

**国産メーカーの共通課題は「量」**。年数千〜数万台では、部品を安く買えず、
ソフトの磨き込みも進まない。だから政策が狙っているのは**量の確保そのもの**（年8万台という目標の意味）。

## 6. 防衛ドローンという別の産業

民生とは経済性がまったく違う領域が、2022年以降に急拡大した。

| 論点 | 内容 |
| --- | --- |
| **非対称性** | 数万円のFPV機が、数億円の戦車・装甲車を無力化しうる。費用対効果が桁違い |
| **消耗品化** | 「壊れないこと」より「安く大量に作れること」が要求される。従来の防衛装備の思想と逆 |
| **生産規模** | ウクライナは2025年に約450万機を国内生産（うちFPV型200万機超）、2026年目標は700万〜1,000万機とされる |
| **対ドローン（C-UAS）** | 迎撃側も安価な機体が主役に。AI迎撃ドローンは1機1,000〜3,000ドル級とされ、対空ミサイルより桁違いに安い |
| **産業への影響** | 「少量を高品質で」の防衛産業に、「大量を安価で」の民生型の生産思想が持ち込まれた |

> この変化が民生側に与える影響：**部品需要の急増**と、**各国での国産化圧力の高まり**。
> 防衛需要が国産メーカーの体力を支え、その体力が民生用の量産につながるか——
> 日本の政策はこの順序に賭けている構図になっている（→ [航空機・防衛](../../02_自動車・機械/13_航空機・防衛/README.md)）。

## 7. 期待と実態の差

| よく語られる期待 | 2026年時点の実態 |
| --- | --- |
| 規制でDJIが排除され、国産勢に一気に需要が移る | 移るのは**官公庁・重要インフラの調達**が中心。民生・一般業務用は価格差が残る |
| 国産化すればサプライチェーンが安全になる | **部品（電池・磁石・モーター）は依然として中国依存**。機体の組立を国内に移しても解決しない |
| 年8万台で国内需要をまかなえる | DJIの出荷量とは桁が違う。**「守られた市場ぶんの供給力」**という位置づけ |
| 防衛需要は一時的なブーム | 各国の調達計画は複数年にわたる。ただし**価格競争が激しい消耗品市場**であり、利幅は自動的には守られない |
| 日本は部品で弱い | **イメージセンサ（ソニー）と電池素材は世界的な強み**。弱いのは完成機の量産 |

## 用語メモ

- **DJI**：中国・深圳の民生／産業用ドローン最大手。世界シェア7割超と推計される
- **Covered List（FCC）**：米国の安全保障上の懸念機器リスト。掲載されると新規の機器認証が受けられない
- **NDAA（国防権限法）**：米国の年度国防予算法。中国製ドローンの調達規制の根拠になっている
- **Blue UAS**：米国防総省が定める、政府調達可能な機体のリスト。事実上の「安全な機体」認定
- **NDAA準拠機**：米国の調達規制に適合した機体。輸出を狙う日本メーカーも意識する要件
- **特定重要物資**：日本の経済安全保障推進法で、安定供給の確保が必要と指定された物資。2026年にドローンが追加指定と報じられる
- **ESC**：モーターの回転数を制御する電子基板。機体のコストと信頼性に効く主要部品
- **FPV**：カメラ映像をゴーグルで見ながら飛ばす方式。軍事用の自爆型で多用される
- **C-UAS**：対無人機システム。探知・電波妨害・物理的迎撃で敵機を無力化する
- **軍民両用（デュアルユース）**：民生品がそのまま軍事転用できる性質。ドローンは典型例
- **深圳**：中国広東省の都市。電子部品・試作・量産の集積地で、DJI本社の所在地
