脱炭素・GX｜技術の選択肢とコスト

注目テーマ脱炭素・GX
あこのページの単語集用語に触れると意味を確認できます12語
LCOE（均等化発電原価）COP（成績係数）出力制御（出力抑制）調整力DR（デマンドレスポンス）CCS／CCU／CCUSDAC（直接空気回収）SAF（持続可能航空燃料）グリーン水素／ブルー水素／グレー水素Nm3（ノルマル立方メートル）スプリット・インセンティブ省エネ法

このノートで分かること：CO2を減らす手段は結局いくつあるのか、
それぞれ1トン減らすのにいくらかかるのか、どういう順番で使うのが合理的なのか。

結論を先に言うと、選択肢は 「減らす／電気に替える／電気をきれいにする／燃料を替える／出たものを埋める」の5つ
しかない。そしてこの並び順がそのままコストの安い順になっている。
ニュースで話題になる水素やCCUSは、安い手段を使い切った後に残る難所のための最後の手段であって、
最初に来るものではない。

1. 5つの武器と、その使う順番

        ┌─────────────────────────────┐
        │ ⑤ 除去・オフセット            │  高い（数千〜数万円/t）
        │   CCS・DAC・森林吸収・クレジット │  最後の手段。難所の残り分に使う
        ├─────────────────────────────┤
        │ ④ 燃料を替える                │
        │   水素・アンモニア・バイオ・SAF  │  高温・長距離など電化できない所
        ├─────────────────────────────┤
        │ ③ 電気をきれいにする           │
        │   再エネ・原子力・系統・蓄電池   │  ②の効果はここで決まる
        ├─────────────────────────────┤
        │ ② 電気に替える（電化）         │
        │   EV・ヒートポンプ・電炉        │  効率が上がるので大抵は得
        ├─────────────────────────────┤
        │ ① そもそも減らす（省エネ）      │  安い。一部はコストがマイナス
        └─────────────────────────────┘

ポイント：②の電化は、③が進んでいないと排出が減らない。
石炭火力の多い系統でEVに乗り換えても削減幅は小さい。
「EVは本当にエコか」という論争の正体は、電源構成の話をEVの話にすり替えていることにある。

2. 手段ごとのコスト感（1トン減らすのにいくらか）

以下は桁感をつかむための目安。立地・規模・電源・燃料価格で大きく動くので、
個別案件では必ず最新の一次情報（資源エネルギー庁の各種WG資料、IEA、IRENA）で確認する。

手段 削減コストの目安（円/t-CO2） 備考
建物断熱・高効率モーター・運用改善マイナス〜数千円投資回収できるものが多い。まずここ
ヒートポンプ（給湯・低温熱）マイナス〜数千円効率が3〜5倍あるので燃焼より得になりやすい
事業用太陽光（適地）数千円適地が減り、日本は世界水準より高い
陸上風力数千〜1万円系統制約と地元合意がボトルネック
洋上風力1万円前後2020年代後半にコスト上昇（資材・金利）
電炉転換（鉄鋼）1万円前後スクラップ供給量と電力コストに依存
CCUS（高濃度のCO2源）数千〜1万円台化学プラント・製鉄所の一部など、濃いCO2は安い
CCUS（火力発電など低濃度）1万〜2万円台薄いCO2を集めるのは高い
水素還元製鉄数万円水素価格に直結
SAF（持続可能航空燃料）数万円従来ジェット燃料の2〜4倍の価格とされる
DAC（大気からの直接回収）数万〜十数万円大気中CO2は0.04%しかないので原理的に高い

比較の基準として：日本のGX-ETSの参考上限取引価格は約4,300円/t-CO2（2025年12月時点の政府資料）、
EU-ETSは70ユーロ台＝1万2,000円前後（2026年、1ユーロ170円換算）。
この線より左にある手段しか、制度だけでは動かない。残りは補助金か規制が要る。

3. 再生可能エネルギー ― 主戦場だが、コスト以外の壁がある

電源 強み 弱み・制約
太陽光設置が速く、分散できる昼しか出ない。日本は適地が減り、単価が世界より高い
陸上風力夜も出る。太陽光と補完的適地が北海道・東北に偏り、送電線が足りない
洋上風力（着床式）大規模化できる2020年代後半に資材高・金利高で採算が悪化し、撤退・見直しが相次いだ
洋上風力（浮体式）日本の深い海に合う商用化はこれから。コストは着床式より高い
バイオマス出力を調整できる燃料（木質ペレット等）の輸入依存とライフサイクル排出が論点
地熱設備利用率が高く安定開発に10年超。温泉事業者との調整、国立公園規制
水力既存設備が安定稼働大規模な新規適地がほぼない

日本固有のボトルネックは「コスト」より「系統」と「調整力」

 発電できる場所（北海道・東北・九州）
        │
        │  ◀── 送電線の容量が足りない（増強に10年・兆円単位）
        ▼
 電気を使う場所（首都圏・中京・関西）

 さらに：太陽光は昼に余り、夕方に足りない
   → 出力制御（作った電気を捨てる）が九州・東北で常態化
   → 解決策 ＝ 蓄電池・揚水・連系線増強・需要側の時間シフト（DR）
  • 出力制御（せっかく発電した再エネを止めること）は、再エネが増えるほど増える。
    つまり「太陽光をもっと建てる」だけでは削減が積み上がらない段階に入っている。
  • ここが 蓄電池 と 電力 の話に直結する。

4. 電化 ― もっとも効率の良い一手

用途 置き換え先 効率の目安
乗用車・小型商用車EV内燃機関の熱効率 30〜40% に対し、EVは電気→動力で80%超
給湯・暖房ヒートポンプ（エコキュート等）投入1に対し熱3〜5を取り出せる（COP 3〜5）
産業用の低・中温熱（〜200℃）産業用ヒートポンプ、電気ボイラー既に実用段階。導入の遅れの主因は初期投資と電気料金
製鉄電炉高炉の 1/3〜1/4 の排出（電源しだい）
高温熱（800℃超の分解炉、セメントキルン）電化が難しい電気式クラッカーは実証段階

ポイント：ヒートポンプは「熱を作る」のではなく「熱を運ぶ」装置。
だから投入したエネルギーより多い熱が出る（エネルギー保存則に反していない）。
脱炭素で最もコスト効率が良い技術の一つだが、地味なので話題になりにくい。

5. 水素・アンモニア ― 難所専用の高級品

  • 現在の水素の大半は化石燃料から作られている（グレー水素）。CO2を出しながら作るので、
    そのままでは脱炭素にならない。
  • 日本政府の価格目標：現在 約100円/Nm3 → 2030年 30円/Nm3 → 2050年 20円/Nm3
    （水素基本戦略。Nm3＝標準状態の立方メートル）。この目標が達成できるかが全ての前提。
  • 用途の優先順位は「電化できないところから」。乗用車に水素を使うのは、
    同じ電気でEVを走らせる方が効率が良いため、一般に筋が悪いとされる。
色の呼び名 作り方 CO2
グレー水素天然ガス・石炭の改質出る
ブルー水素同上＋CCSでCO2を回収大部分を抑制
グリーン水素再エネ電力で水を電気分解出ない（電源が再エネなら）
ピンク／イエロー水素原子力の電力で電気分解出ない

→ 詳細は 水素・アンモニア

6. CCUS ― 「消せないCO2」の受け皿

CCUS = Carbon dioxide Capture, Utilization and Storage（回収・利用・貯留）

 排ガス ──▶ ① 分離・回収 ──▶ ② 輸送 ──▶ ③-a 貯留（CCS）：地下1,000m以深の帯水層へ圧入
            （アミン吸収等）    （船・パイプライン） ③-b 利用（CCU）：化学品・燃料・コンクリートへ
  • コストの大半は ①の分離・回収。CO2濃度が高いほど安い。
    化学プラントや水素製造の副生CO2（ほぼ純CO2）は安く、火力発電の排ガス（CO2 10%台）は高い。
  • 日本は貯留適地が限られるため、海外（マレーシア、豪州等）へ運んで埋める
    「CCSバリューチェーン」構想が進む。JOGMECが支援する先進的CCS事業がその枠組み。
  • 政府は2030年までにCCS事業開始、年間600万〜1,200万t-CO2の貯留を目標としている（CCS長期ロードマップ）。
  • 批判：「CCSがあるから化石燃料を使い続けてよい」という言い訳（ムーンショット的な先送り）に
    なりうる、という指摘は根強い。セメントのプロセス排出のように本当に他に手がない用途に
    限れば正当性が高い。

7. 省エネ ― 地味だが最大の削減源

  • IEAは、2050年ネットゼロ経路での削減寄与のうちエネルギー効率改善が最大級の割合を占めると
    繰り返し指摘している。「使わなかった1kWh」が最も安い。
  • 日本には省エネ法（エネルギーの使用の合理化及び非化石エネルギーへの転換等に関する法律）があり、
    一定規模以上の事業者に定期報告と中長期計画の提出を課す。2023年施行の改正で
    非化石エネルギーへの転換と電気需要の最適化（DR）が義務の対象に加わった。
  • 実務上の障壁は技術ではなく「誰が投資するか」。賃貸ビルの断熱は
    大家が投資し、便益は光熱費として店子が受ける（スプリット・インセンティブ）ため進みにくい。

8. 技術を評価するときの4つの問い

  1. どの排出を狙っているか（Scope 1か、電力か、プロセス排出か）
  2. 1トンいくらか（MACカーブのどこに乗るか）
  3. 今ある制度の炭素価格で成立するか。しないなら補助金か規制が要る
  4. スケールするか（バイオ燃料は原料の土地、電炉はスクラップ量、CCSは貯留適地が上限になる）

用語メモ

  • LCOE（均等化発電原価）：建設費・燃料費・運転費を発電量で割った、1kWhあたりの生涯コスト
  • COP（成績係数）：ヒートポンプが投入エネルギー1に対して取り出せる熱の倍率
  • 出力制御（出力抑制）：需給バランスのため、発電できる再エネを止めること
  • 調整力：需要の変動に合わせて出力を上下できる電源・蓄電池・需要側の能力
  • DR（デマンドレスポンス）：需要家側が使用時間をずらして需給を調整すること
  • CCS／CCU／CCUS：CO2の回収＋貯留／回収＋利用／その両方
  • DAC（直接空気回収）：大気からCO2を直接取り出す技術。濃度が薄く高コスト
  • SAF（持続可能航空燃料）：廃食油・バイオマス等から作るジェット燃料。従来品の2〜4倍の価格
  • グリーン水素／ブルー水素／グレー水素：作り方で分けた水素の呼称
  • Nm3（ノルマル立方メートル）：0℃・1気圧に換算した気体の体積。水素の価格単位
  • スプリット・インセンティブ：投資する人と便益を受ける人が違うために投資が進まない現象
  • 省エネ法：一定規模以上の事業者にエネルギー使用の報告と改善を課す日本の法律
