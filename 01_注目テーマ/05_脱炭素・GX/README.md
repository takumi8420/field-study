# 脱炭素・GX

- 大分類: 注目テーマ
- 状態: done
- 更新日: 2026-09-19

**一言でいうと**：温室効果ガスの排出をゼロに近づけるために、
エネルギー・素材・輸送・金融のルールを丸ごと書き換える動き。
「GX（グリーントランスフォーメーション）」は日本政府の呼び名で、
**脱炭素を制約ではなく産業政策・成長戦略として扱う**という立場を示している。

この分野の勘所は3つだけ。
**①排出は誰がどこから出しているのか（構造）／②CO2にいくら値段が付くのか（制度）／
③1トン減らすのにいくらかかるのか（技術コスト）**。
この3つが噛み合ったところだけが実際に動く。

## 1. 業界の定義・範囲

**「脱炭素・GX」は単一の業界ではなく、全産業にかかる横断テーマ**。
だから「市場規模」を語るときは、必ず何を数えているのかを確認する必要がある。

範囲を3層に分けると整理しやすい。

```
 ┌──────────────────────────────────────────────────┐
 │ ③ ルールの層：制度・金融・開示                      │
 │    カーボンプライシング、ESG投資、開示基準、認証     │ ← 本フォルダの中心
 ├──────────────────────────────────────────────────┤
 │ ② 解決策の層：エネルギー・技術を供給する産業         │
 │    再エネ、原子力、水素、蓄電池、CCUS、省エネ機器     │ ← 各業界フォルダへ
 ├──────────────────────────────────────────────────┤
 │ ① 排出の層：CO2を出している当事者                   │
 │    電力、鉄鋼、セメント、化学、運輸、建物            │ ← 各業界フォルダへ
 └──────────────────────────────────────────────────┘
```

- 隣接テーマとの境界：
  **[水素・アンモニア](../06_水素・アンモニア/README.md)** は燃料そのものの話、
  **[蓄電池](../04_蓄電池/README.md)** と **[EV・電動化](../03_EV・電動化/README.md)** は需要側の技術、
  **[再生可能エネルギー](../../11_資源・エネルギー・鉄鋼金属/07_再生可能エネルギー/README.md)** は発電事業。
  本フォルダは**それらを束ねる制度とお金の流れ**を扱う。
- 「脱炭素」は技術・エネルギーの話、「GX」は**そこに投資と産業競争力を重ねた政策用語**。
  日本で「GX」と言う場合は、たいてい GX推進法とGX経済移行債20兆円の枠組みを指している。

## 2. 市場規模と成長性

| 指標 | 数値 | 時点・出典 |
| --- | --- | --- |
| 世界のクリーンエネルギー投資 | 年 **約2兆ドル超** | 2024〜2025年、IEA「World Energy Investment」の推計 |
| 日本のGX投資目標（官民） | 今後10年で **150兆円超** | 2023年、GX実現に向けた基本方針（政府） |
| うち政府の呼び水 | **GX経済移行債 20兆円**（2023〜2032年度） | GX推進法 |
| 世界のカーボンプライシング収入 | 年 約1,000億ドル規模 | 2023〜2024年、世界銀行「State and Trends of Carbon Pricing」の集計 |
| 日本のGHG排出（吸収源控除後） | 約 **9億9,400万 t-CO2e** | 2024年度速報、環境省（2026年4月公表） |
| 日本の2035年度目標 | 2013年度比 **−60%**（2040年度 −73%） | 2025年2月閣議決定のNDC |

- 成長性の源泉は**需要ではなく制度**。脱炭素の投資は、
  「安いから買う」ではなく「規制と補助金があるから動く」性格が強い。
  そのため**政権交代や景気で需要が一気に萎む**リスクを常に抱える（2026年の米国がその実例）。
- 逆に、いったん設備投資が着工すれば10〜30年動くため、**後戻りしにくい**という性質もある。

## 3. バリューチェーン（川上 → 川下）

```
【お金の流れ】
 国（GX経済移行債20兆円）──補助金・基金──▶ 事業会社の設備投資
        ▲                                        │
        │ 償還原資                                │ 削減実績
 化石燃料賦課金（2028年度〜）                      │
 排出枠オークション（2033年度〜）                   ▼
        ▲                                   排出量の算定・報告・検証
        │                                        │
 GX-ETS（2026年度〜義務）◀──排出枠の売買──────────┘
                                                 │ 足りない分
                                                 ▼
                                        J-クレジット／JCMの購入

【モノ・サービスの流れ】
 技術開発 ─▶ 機器・設備 ─▶ EPC（設計・調達・建設）─▶ 運用 ─▶ 算定・開示 ─▶ 検証
 大学/国研   電機・重工      エンジニアリング/ゼネコン   事業会社   SaaS/コンサル  審査機関
```

付加価値が集まる場所は2か所。
**①エネルギーを実際に作って売るところ**（発電、燃料）と、
**②制度が義務を生んだところ**（算定SaaS、検証、クレジット取引）。
中間の機器・工事は競争が激しく、利幅は取りにくい。

## 4. 主要プレイヤーとシェア

「脱炭素業界」という企業群があるわけではないので、**役割別**に見るのが実際的。

| 役割 | 主なプレイヤー | 立ち位置 |
| --- | --- | --- |
| 制度設計・資金供給 | 経済産業省・環境省、**GX推進機構**、JOGMEC、NEDO | 移行債の配分と制度運用。実質的にこの分野の需要を作っている |
| 排出の当事者（難削減） | 日本製鉄、JFE、太平洋セメント、三菱ケミカル、電力各社 | GX-ETSの主要対象。投資額が桁違いに大きい |
| 再エネ事業者 | JERA、電源開発、レノバ、ユーラスエナジー、外資（Ørsted等） | 発電して売る。系統制約と入札価格が収益を左右 |
| 設備・エンジニアリング | 三菱重工、IHI、日立、東芝、日揮、千代田化工、荏原 | CCUS・水素・アンモニア混焼のプラント側 |
| 商社 | 三菱商事、三井物産、住友商事、丸紅、伊藤忠 | 燃料・クレジット・権益をまとめる。事業投資で川上に入る |
| 排出量算定SaaS | ゼロボード、アスエネ、booost technologies、ウェイストボックス等 | 制度が生んだ新市場。GX-ETSとSSBJで需要拡大 |
| 検証・認証 | 日本品質保証機構（JQA）、SGS、DNV、LRQA、監査法人系 | 第三者保証の義務化で需要が急増する領域 |
| クレジット取引 | 東証「カーボン・クレジット市場」、商社、専業事業者 | J-クレジットの流通。2026年に価格が上昇 |
| 金融・評価 | メガバンク、GPIFなど機関投資家、CDP、MSCI／Sustainalytics | 資金供給とスコアリングで圧力をかける側 |

> ポイント：**この分野で最も確実に儲かるのは「制度対応を代行する仕事」**。
> 削減そのものはコストだが、**算定・検証・開示は義務なので支払われる**。
> 2026年のGX-ETS義務化とSSBJ法定化は、この層を一気に拡大させる。

## 5. 収益モデル・コスト構造

| プレイヤー | 何で儲けるか | コストの中心 |
| --- | --- | --- |
| 再エネ発電事業者 | 売電収入（FIT/FIP、PPA、市場売り） | 初期投資の減価償却と金利。**燃料費がほぼゼロで固定費産業** |
| 難削減産業（鉄鋼等） | 本業の製品販売＋**グリーン製品のプレミアム** | 排出枠の購入費、設備転換投資 |
| 算定SaaS | サブスクリプション（ARR） | 開発と営業。**制度改正のたびに再開発が必要** |
| 検証機関 | 検証1件あたりのフィー | 有資格者の人件費。**人の稼働で稼ぐ構造** |
| クレジット事業者 | 売買スプレッド、組成手数料 | 在庫リスク（価格変動）と認証コスト |
| 商社 | 権益の持分利益＋トレーディング | 投資の毀損リスク |

- 再エネ事業は **LCOE（1kWhあたり生涯コスト）で評価される典型的な装置産業**。
  金利が上がると採算が一気に悪化するため、2020年代後半の洋上風力は各国で見直しが相次いだ。
- **グリーン製品のプレミアムが成立するか**が、鉄鋼・化学の脱炭素投資の生死を分ける。
  作れても高く売れなければ、単なる原価増で終わる。

## 6. 競争要因（KSF）と参入障壁

1. **制度を読む力**。この分野の需要は制度が作る。審議会の議論を追えるかどうかが先行者利益に直結する
2. **長期の資金調達力**。回収に10〜20年かかる投資が中心。資本コストの低い企業が勝つ
3. **データを持っていること**。排出量の一次データは、後から買えない。早く集めた企業が精度で勝つ
4. **立地と系統接続**（再エネ）。良い適地と送電容量は早い者勝ちで、あとから増やせない
5. **検証に耐える手続き**。算定の正しさは属人的なノウハウに依存し、参入障壁になる

逆に**参入障壁が低い**のは、コンサルと算定ツールの層。ここは既に競争が激しい。

## 7. 規制・法制度

| 制度 | 内容 | 時期 |
| --- | --- | --- |
| **GX推進法**（2023年成立、2025年改正） | GX経済移行債、化石燃料賦課金、GX-ETSの根拠法 | 改正法は2026年4月施行 |
| **GX-ETS** | 年10万t-CO2以上の事業所を持つ法人が対象の排出量取引 | **2026年度から義務参加** |
| **化石燃料賦課金** | 化石燃料の輸入事業者等に、CO2量に応じて賦課 | 2028年度〜 |
| **排出枠の有償オークション** | 発電事業者向け | 2033年度〜 |
| 地球温暖化対策税 | 289円/t-CO2 の既存の炭素税 | 2012年〜 |
| **温対法**（地球温暖化対策推進法） | 一定規模以上の事業者に排出量の算定・報告・公表を義務付け（SHK制度） | 継続 |
| **省エネ法** | エネルギー使用の合理化と非化石転換、電気需要最適化 | 2023年改正施行 |
| **SSBJ基準／内閣府令** | 有価証券報告書でのサステナビリティ開示を義務化 | 2027年3月期から段階適用 |
| **CBAM（EU）** | 鉄鋼・アルミ・セメント等の輸入に炭素コストを課す | 2026年から本格課金 |
| エネルギー供給構造高度化法 | 小売電気事業者に非化石電源比率を義務付け | 継続 |

詳細は → [制度とカーボンプライシング](02_制度とカーボンプライシング.md)

## 8. 最近のトピック

詳細は → [直近トピック_2026](05_直近トピック_2026.md)

1. **2026年4月、GX-ETSが義務参加フェーズへ**。約300〜400社、国内排出の約6割が対象に
2. **J-クレジット価格が上昇**（再エネ電力由来で2026年に5,000円/t前後）。義務化を見越した先回り調達が主因と報じられる
3. **EUのCBAMが本格課金に**。2026年のCBAM証書価格は 75ユーロ台/t、EU-ETSは70ユーロ台で推移
4. **政策の割れ**。米国は2026年1月にパリ協定を再離脱、一方EUは2026年3月に「2040年90%減」を法制化
5. **開示が法定義務に**。2026年2月の内閣府令改正で、2027年3月期から時価総額の大きい順にSSBJ基準適用
