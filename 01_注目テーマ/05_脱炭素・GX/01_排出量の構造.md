# 脱炭素・GX｜排出量の構造（Scope1/2/3 と「削減の難所」）

**このノートで分かること**：温室効果ガス（GHG）は「誰が」「どこから」出しているのか、
企業単位でそれをどう切り分けるのか（Scope 1/2/3）、そして
なぜ鉄鋼・セメント・化学・運輸だけが「どうしても減らせない」と言われるのか。

結論を先に言うと、脱炭素の議論は**「電気を作るときに出るCO2」と「電気以外の理由で出るCO2」の
二つに分けた瞬間に見通しがよくなる**。前者は再エネ・原子力で置き換えられるが、
後者には燃やす以外の理由（化学反応そのもの）でCO2が出るものが混ざっていて、
そこが最後まで残る。

---

## 1. まず「温室効果ガス」とは何を数えているのか

- 対象は CO2（二酸化炭素）だけではない。京都議定書以来、次の7種類を数える。
  CO2 / CH4（メタン）/ N2O（一酸化二窒素）/ HFCs・PFCs・SF6・NF3（フロン類など）
- 種類ごとに温める力が違うので、**CO2換算（t-CO2e）** に揃えて足す。
  換算係数が **GWP（地球温暖化係数）**。100年で見るとメタンはCO2の約28倍、
  SF6は約23,500倍（IPCC第5次評価報告書の値。報告書の版で数値が変わる点に注意）
- 日本の排出の 92.3% は CO2（2024年度、環境省）。つまり実務上はほぼCO2の話になる。

> ポイント：「t-CO2」と「t-CO2e」は別物。前者はCO2そのもの、後者は他のガスを換算して足した合計。
> ニュースの数字を比べるときは、どちらかを必ず確認する。

## 2. 世界と日本の規模感

| 区分 | 量 | 時点・出典 |
| --- | --- | --- |
| 世界のGHG排出（全ガス） | 約55〜57 GtCO2e／年 | 2023〜2024年、UNEP Emissions Gap Report の推計 |
| うちエネルギー起源CO2 | 約37〜38 Gt／年 | 2023〜2024年、IEA の推計 |
| 日本のGHG排出・吸収（吸収源控除後） | **約9億9,400万 t-CO2e** | 2024年度速報、環境省（2026年4月公表） |
| 日本：前年度比 | −1.9%（約1,880万 t減） | 同上 |
| 日本：2013年度比 | **−28.7%**（約3億9,950万 t減） | 同上 |
| 日本：森林等の吸収量 | 約5,230万 t（うちブルーカーボン約32万 t） | 同上 |

- 日本は2024年度に**初めて10億トンを下回った**（吸収源を加えた純排出）。
  減少理由は環境省によれば「製造業の生産量減少」と「電源の脱炭素化」（再エネ＋原子力が電源構成の3割超）。
  つまり**景気要因と構造要因が混ざっている**ので、減ったこと自体を素直に成果と読むのは早い。
- 日本の世界シェアは約3%。単独で世界を動かす規模ではないが、
  G7の一角として制度・技術の先行事例を出す立場に置かれている。

## 3. 部門別の排出（日本・2024年度）と「直接／間接」の落とし穴

環境省の統計には**2通りの数え方**があり、これを混同すると議論が噛み合わない。

```
【排出源別（直接排出）】             【電気・熱配分後（間接排出）】
 発電所で燃やした分は発電所の排出      発電所の排出を、電気を使った側に配り直す

  エネルギー転換 40.4% ──────────┐
  （発電所・製油所）               │ 配り直す
  産業（工場）    24.4%  ←────────┤
  運輸（自動車等）18.6%  ←────────┤
  業務その他       5.2%  ←────────┤
  家庭             4.7%  ←────────┘
  工業プロセス等   残り

 ※ 数値は2024年度・CO2ベース、環境省／JCCCA
```

- **直接排出で見ると「発電所が最大の排出源」**。だから電源の脱炭素化が最優先になる。
- **間接排出で見ると産業（工場）が最大**になり、次に運輸・業務。
  「どの産業が悪いのか」という議論は、どちらの数え方かで答えが変わる。
- この「直接か、電気経由か」の区別が、そのまま企業会計での **Scope 1 と Scope 2** に対応する。

## 4. Scope 1 / 2 / 3 — 企業が自分の排出をどう切るか

国際的な計算ルールが **GHGプロトコル**（WRI と WBCSD が作った民間標準）。
ほぼ全ての制度（GX-ETS、SBT、ISSB/SSBJ）がこれを土台にしている。

| 区分 | 何を数えるか | 具体例 | 減らし方 |
| --- | --- | --- | --- |
| **Scope 1** | 自社が**直接**燃やして出した分 | 工場のボイラー、自社トラックの軽油、自家発電 | 燃料転換、電化、省エネ、CCUS |
| **Scope 2** | 自社が**買った電気・熱**を作るときに出た分 | 購入電力、地域冷暖房 | 再エネ電力への切替、証書・PPA購入 |
| **Scope 3** | それ以外の**バリューチェーン全体** | 仕入れた部品、輸送、出張、売った製品を客が使うとき、投融資先 | 調達先への要請、製品設計、投資判断 |

Scope 3 はさらに**15カテゴリ**に分かれる（購入した製品・サービス、資本財、輸送、出張、
販売した製品の使用、廃棄、投融資 など）。実務上はこの15個のうち
**自社にとって大きい2〜3個だけが支配的**になる。

```
        ┌──────── Scope 3（上流）────────┐   ┌─ Scope 1/2 ─┐   ┌── Scope 3（下流）──┐
原材料 ─▶ 部品メーカー ─▶ 物流 ──────────▶  自社の工場・オフィス  ─▶ 物流 ─▶ 販売 ─▶ 顧客の使用 ─▶ 廃棄
  ↑                                          ↑        ↑
  カテゴリ1（購入した製品）                Scope1   Scope2
                                          自社で燃焼  買った電気
```

### 業種でScope 3の重心がまったく違う

| 業種 | 支配的なカテゴリ | ざっくりした比率感 |
| --- | --- | --- |
| 銀行・保険・運用 | カテゴリ15（投融資先の排出） | Scope 3 が全体の **99%超**になるのが普通 |
| 自動車 | カテゴリ11（販売した製品の使用＝走行時の燃料） | 使用段階が 7〜8割 |
| 食品・アパレル・小売 | カテゴリ1（購入した原材料・商品） | 上流が大半 |
| 鉄鋼・セメント・化学 | Scope 1 が主役 | 自社の炉・キルンで出る |
| データセンター・IT | Scope 2（電力）＋カテゴリ1（サーバー等の資本財） | 電力が主役 |

> ポイント：**Scope 3 は足し算すると二重計上になる**。A社のScope 3はB社のScope 1でもある。
> だから「世界の合計」を出す道具ではなく、**「誰が誰に働きかければ減るか」を見つける道具**として使う。
> 金融機関が企業に脱炭素を迫るのは、金融にとって投融資先の排出こそが自分の排出だから。

## 5. 削減の難所（hard-to-abate）— なぜここだけ残るのか

電力と乗用車は「電気にすれば減る」。しかし次の4分野は、原理的に電化で解けない部分を抱える。

| 分野 | 世界のCO2に占める目安 | なぜ難しいのか | 有力な手段 |
| --- | --- | --- | --- |
| **鉄鋼** | 約7〜8% | 高炉法では炭素（コークス）が**燃料ではなく還元剤**。酸化鉄から酸素を奪う化学反応そのものにCが要る | 電炉（スクラップ）、水素還元、CCUS |
| **セメント** | 約7〜8% | 石灰石 CaCO3 → CaO + **CO2**。原料が分解して出る「プロセス排出」が全体の約6割。燃料を何に替えても消えない | 混合セメント（クリンカー比率低減）、CCUS、CO2吸収コンクリート |
| **化学** | 約5〜6% | 原料のナフサ自体が化石由来で、**炭素が製品の中に入っている**。さらに分解炉が800℃超の高温を要する | バイオ／リサイクル原料、電気式クラッカー、CCU |
| **運輸（航空・海運・長距離トラック）** | 航空約2%、海運約2% | エネルギー密度。同じ航続距離を電池で得ようとすると重すぎて積荷が載らない | SAF（持続可能航空燃料）、アンモニア・メタノール燃料、水素 |

### 鉄鋼の化学反応を1行で

```
高炉法：  Fe2O3 + 3CO → 2Fe + 3CO2     ← 鉄1トンあたり約1.8〜2.0 t-CO2
水素還元：Fe2O3 + 3H2 → 2Fe + 3H2O     ← 出るのは水。ただしH2が必要で吸熱反応
電炉：    鉄スクラップを電気で溶かす     ← 鉄1トンあたり約0.4〜0.6 t-CO2（電源しだい）
```

- 電炉は**今すぐできる最大の手段**だが、原料がスクラップなので**国内のスクラップ発生量が上限**になる。
  また不純物（銅など）が混ざるため高級鋼を作りにくい、という技術課題がある。
- 水素還元は原理的にゼロにできるが、**安い水素が大量に要る**。
  → [水素・アンモニア](../06_水素・アンモニア/README.md)

### セメントの「プロセス排出」が特殊な理由

燃料を再エネ電力やバイオマスに替えても、**石灰石を焼く限りCO2は出続ける**。
だから CCUS（回収・貯留）か、クリンカー（セメントの主成分）そのものを減らす設計しかない。
セメントは「CCUSがどうしても要る産業」の代表例とされる。
→ [セメント・生コン](../../10_素材・化学/10_セメント・生コン/README.md)

## 6. 限界削減費用（MAC）という考え方

脱炭素の優先順位は、**「1トン減らすのにいくらかかるか」**で並べると理解しやすい。

```
費用（円/t-CO2）
  ↑
  │                                        ┌──── CCUS・水素還元製鉄
  │                              ┌─────────┘     （数万円〜／t）
  │                   ┌──────────┘  SAF・合成燃料
  │        ┌──────────┘  洋上風力・EV
  │ ───────┘  太陽光（適地）
  │
0 ┼────────────────────────────────────────────────▶ 削減量
  │ ┌───┐
  │ │省エネ（断熱・高効率モーター）はマイナス＝やると得
  └─┘
```

- **省エネの一部はコストがマイナス**（投資を回収してお釣りが来る）。だから真っ先に取る。
- 右に行くほど高くつく。カーボンプライシング（炭素に値段を付ける制度）は、
  この曲線の**どこまでを経済的に成立させるかを決めるダイヤル**として働く。
  → [制度とカーボンプライシング](02_制度とカーボンプライシング.md)
- 具体的なコスト比較は → [技術の選択肢とコスト](03_技術の選択肢とコスト.md)

## 7. この分野を見るときの指標

- 環境省「温室効果ガス排出・吸収量」（毎年4月ごろに前々年度の速報）
- 電源構成に占める非化石比率（資源エネルギー庁）→ Scope 2 の全国平均を左右する
- **電力の排出係数（kg-CO2/kWh）**：企業のScope 2はこれに人質を取られている。
  全国平均は2024年度で概ね0.4台（小売事業者ごとに大きく異なる。最新は環境省の公表値で確認）
- 鉄鋼・セメント・化学の生産量（景気で排出が動くため、政策効果と切り分ける必要がある）

## 用語メモ

- **GHG（温室効果ガス）**：熱を閉じ込める気体。CO2、メタン、N2O、フロン類の7種類が対象
- **CO2e（CO2換算）**：ガスごとの温める力（GWP）を掛けて、CO2の重さに揃えた単位
- **GWP（地球温暖化係数）**：CO2を1としたときの温暖化能力。メタンは約28（100年基準、IPCC AR5）
- **GHGプロトコル**：排出量の数え方の国際的なデファクト標準。Scope 1/2/3 はここの定義
- **Scope 2 マーケット基準／ロケーション基準**：前者は買った電力メニューの係数、後者は地域の平均係数で計算する方法。再エネ契約の効果はマーケット基準にしか出ない
- **プロセス排出**：燃焼ではなく、化学反応そのものから出るCO2。セメントの石灰石分解が代表
- **hard-to-abate（難削減分野）**：鉄鋼・セメント・化学・長距離輸送など、電化だけでは減らせない産業
- **MACカーブ（限界削減費用曲線）**：削減手段を1トンあたり費用の安い順に並べたグラフ
- **排出係数**：エネルギー1単位あたりのCO2排出量。電力なら kg-CO2/kWh
- **カーボンバジェット**：気温上昇を一定に抑えるために、人類が今後出せるCO2の総量
