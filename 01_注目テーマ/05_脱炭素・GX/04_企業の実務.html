脱炭素・GX｜企業の実務（開示・目標・サプライチェーン要請）

注目テーマ脱炭素・GX
あこのページの単語集用語に触れると意味を確認できます17語
移行リスク物理リスク内部炭素価格（ICP）TCFDISSBSSBJシナリオ分析移行リスク／物理リスクSBT・SBTiRE100CDPCFP（カーボンフットプリント）コーポレートPPA非化石証書追加性グリーンウォッシュ／グリーンハッシング第三者保証

このノートで分かること：普通の事業会社にとって脱炭素が「何の仕事として降ってくるのか」。
排出量を数えて、目標を立て、有価証券報告書に書き、取引先から質問状が届く——
この一連の実務が、どの制度に根拠を持っていて、いつから義務になるのか。

結論を先に言うと、企業を動かしている力は 規制・投資家・顧客の3つで、
2020年代前半に最も強かったのは顧客（取引先）からの要請だった。
それが2026〜2027年にかけて、規制（GX-ETS）と開示義務（SSBJ）という
逃げられない形に変わりつつある、というのが現在地。

1. なぜ企業は脱炭素をやるのか — 3つの圧力

        ┌───────────────┐
        │ ① 規制（国）    │  GX-ETS、省エネ法、温対法、CBAM
        │  守らないと罰則  │  → 2026年度から義務の段階へ
        └───────┬───────┘
                │
   ┌────────────▼────────────┐
   │        事 業 会 社        │
   └────────────▲────────────┘
                │
   ┌────────────┴────────────┐──────────────────────┐
   │ ② 投資家・銀行            │ ③ 顧客・取引先        │
   │  開示しないと評価が下がる   │  データを出さないと     │
   │  SSBJ／ISSB、株主提案      │  取引から外される       │
   │  → 資金調達コストに響く     │  → 売上に直結する       │
   └──────────────────────────┴──────────────────────┘

ポイント：中堅・中小企業にとって、最も切実なのは③。
法律で義務化されていなくても、大手顧客が「Scope 3の算定に協力してほしい」と言ってきた瞬間に、
事実上の取引条件になる。規制は大企業から始まるが、要請は取引網を通じて下まで降りる。

2. 開示 — TCFD から ISSB、そして日本のSSBJへ

系譜を1本の線で

2015 TCFD設立（金融安定理事会の作業部会）
   │  気候リスクを財務情報として開示せよ、という枠組みを提示
   ▼
2021 東証プライム市場で TCFD またはそれと同等の開示が実質的に求められる
   │
   ▼
2023 ISSB が IFRS S1（サステナビリティ全般）／S2（気候）を公表
   │  TCFDの枠組みを取り込み、世界共通の「会計基準」の形に
   ▼
2025 SSBJ（サステナビリティ基準委員会）が日本版基準を確定
   │
   ▼
2026年2月 内閣府令改正 → 有価証券報告書での開示を**法的義務**に
   │
   ▼
2027年3月期から、時価総額の大きい順に段階適用

日本の適用スケジュール（2026年2月の内閣府令改正による）

適用開始 対象
2027年3月期プライム上場のうち、平均時価総額 3兆円以上
2028年3月期同 1兆円以上3兆円未満
2029年3月期同 5,000億円以上1兆円未満
未定同 5,000億円未満
  • 第三者保証（監査に相当する検証）も、開示適用の翌年から義務化される。
    つまり「とりあえず数字を出す」では済まず、監査に耐える算定プロセスが要る。
  • 初年度から2年間は「二段階開示」の経過措置があり、有価証券報告書と
    サステナビリティ情報を別のタイミングで公表できる。
  • 数値・時期は制度改正で動くため、最新は金融庁とSSBJの公表資料で確認すること。

TCFD／IFRS S2 が求める4本柱

柱 何を書くか つまずきやすい点
ガバナンス取締役会が気候をどう監督しているか「担当役員を置いた」だけでは弱い。議題に何回かけたかを書く
戦略気候変動が事業にどう効くか。シナリオ分析（1.5℃／4℃など複数の将来像で試算）定性的な作文で終わりがち。財務インパクトの金額化を求められる
リスク管理気候リスクを全社のリスク管理にどう組み込んでいるか環境部門だけで閉じていると指摘される
指標と目標Scope 1/2/3 の実績、削減目標、進捗Scope 3の算定精度が最大の難所

リスクは2種類に分けて考える。

  • 移行リスク：脱炭素へ移る過程で生じる損失。炭素価格、規制強化、需要の消滅（例：内燃機関部品）、評判
  • 物理リスク：気候そのものによる損失。急性（台風・洪水で工場停止）と慢性（平均気温上昇、海面上昇）

3. 目標 — SBT、ネットゼロ、RE100

枠組み 中身 難易度
SBT（Science Based Targets）パリ協定と整合する削減目標を、SBTi（民間イニシアチブ）が科学的に認定1.5℃水準だと Scope 1+2 で年4.2%程度の削減が目安。Scope 3の目標も必要
中小企業版SBTScope 1+2 のみで簡易に認定取引先要請への対応として普及
RE100事業の使用電力を100%再エネにすると宣言する国際イニシアチブScope 2 を消す取組。達成手段は自家発電・PPA・証書購入
カーボンニュートラル宣言自社の目標宣言。第三者認定は伴わない宣言だけなら容易。中身が問われる
ネットゼロ残余排出を除去（CCS・森林等）で相殺し、実質ゼロオフセットの質が問われる

注意：「カーボンニュートラル」と「ネットゼロ」は厳密には違う。
前者はクレジット購入による相殺を広く認める運用が多く、後者（SBTiのNet-Zero基準）は
原則90%以上を自社で実際に削減し、残りだけを恒久的な除去で相殺せよ、と求める。
企業の宣言を読むときは、どちらの定義かを必ず確認する。

再エネ調達の4つの手段（Scope 2 を減らす方法）

手段 中身 特徴
自家消費型太陽光（オンサイト）自社の屋根・敷地に設置追加性が明確。電気代も下がる。設置面積が上限
コーポレートPPA発電事業者と長期（15〜20年）の相対契約価格を固定でき、追加性も高い。契約が複雑
再エネメニューの購入小売電気事業者の再エネプランに切替手軽。上乗せ価格がかかる
証書の購入（非化石証書、グリーン電力証書）電気と環境価値を切り離して価値だけ買う最も手軽だが「追加性が薄い」と批判されやすい

4. サプライチェーン要請 — 大手の目標が下請けの仕事になる仕組み

 【大手メーカーのScope 3（カテゴリ1）】＝【部品メーカーのScope 1+2】

  完成品メーカー ──「製品ごとのCFPを出してください」──▶ Tier1 部品メーカー
      （2030年目標を掲げた）                              │
                                                         │ 同じ質問を転送
                                                         ▼
                                                    Tier2 加工業者
                                                         │
                                                         ▼
                                                    Tier3 素材・表面処理
  • Apple の「2030年までにサプライチェーン全体でカーボンニュートラル」や、
    自動車・電機大手の同様の方針が、そのまま取引先への要求事項として降りてくる。
  • 実務上の要求は主に3つ。
    1. 自社の Scope 1+2 排出量の報告（CDPのサプライチェーンプログラム経由が多い）
    2. 製品単位の CFP（カーボンフットプリント）の算定
    3. 削減目標の設定（中小企業版SBTの取得を求められることもある）
  • 特に欧州向けの製品では、CBAMや電池規則（バッテリーパスポート）のように
    製品ごとの炭素データがないと輸出できない方向に動いている。
    → EV・電動化 ／ 蓄電池

5. 社内で実際に回る業務フロー

 ① 算定        ② 計画        ③ 実行         ④ 開示        ⑤ 検証
 排出量を数える ─▶ 削減シナリオ ─▶ 設備投資・  ─▶ 有報・CDP ─▶ 第三者保証
 (Scope1/2/3)     と目標設定     再エネ調達     統合報告書     (2028年3月期〜順次義務)
     │                                              ▲
     └──── 一次データが足りない ────────────────────┘
            → 業種平均の原単位（排出原単位データベース）で代替
              → 精度が低く、保証で問題になる ← 現在の最大の実務課題
  • Scope 3 の算定は最初は「金額×原単位」で推計する（例：鋼材を1億円買ったから◯t）。
    これは簡便だが、安く買うほど排出が減るという馬鹿げた結果になるため、
    一次データ（取引先の実測値）への置き換えが求められていく。
  • 内部炭素価格（ICP）：社内の投資判断で、CO2に仮の値段を付けて評価する手法。
    「今は炭素に値段がなくても、10年後にはある」という前提で設備投資を選ぶための道具。
    国内では1t数千円〜1万円台で設定する例が多いとされる。
  • 体制面では、サステナビリティ推進部と経理・調達・工場が分断されているのが典型的な失敗形。
    開示が有価証券報告書に入る＝経理部門の仕事になることで、この分断は強制的に解消へ向かう。

6. グリーンウォッシュという逆リスク

  • グリーンウォッシュ＝実態を伴わない環境配慮アピール。
    2020年代半ばから、欧米では過大な宣伝に対する当局の摘発・訴訟が増えた。
  • その結果、企業が萎縮して発信を控える「グリーンハッシング（黙る）」も観察されている。
  • 実務的な教訓は単純で、「言えることしか言わない」「根拠データを残す」。
    開示が法定化され保証が入ることは、裏返せば言い逃れができなくなることでもある。

用語メモ

  • TCFD：気候関連財務情報開示タスクフォース。ガバナンス／戦略／リスク管理／指標と目標の4本柱
  • ISSB：国際サステナビリティ基準審議会。IFRS財団の下部組織。IFRS S1／S2 を公表
  • SSBJ：サステナビリティ基準委員会。日本版のサステナビリティ開示基準を作る組織
  • シナリオ分析：複数の将来（1.5℃上昇の世界／4℃上昇の世界など）を想定して事業への影響を試算すること
  • 移行リスク／物理リスク：脱炭素への移行で生じる損失／気候そのものによる損失
  • SBT・SBTi：科学的根拠に基づく削減目標と、その認定を行う国際イニシアチブ
  • RE100：使用電力を100%再エネにすることを宣言する企業連合
  • CDP：企業の環境情報を質問状で集め、スコアリングする国際NGO。投資家と大手顧客が参照する
  • CFP（カーボンフットプリント）：製品やサービス1単位あたりのライフサイクル排出量
  • コーポレートPPA：企業と発電事業者が結ぶ長期の電力購入契約
  • 非化石証書：電気の「非化石である」という環境価値だけを切り出した証書
  • 追加性：その取組があったからこそ新たな再エネ・削減が生まれたと言えるか
  • 内部炭素価格（ICP）：社内の投資判断用に自主的に設定するCO2の価格
  • グリーンウォッシュ／グリーンハッシング：実態を伴わない環境アピール／逆に発信を控えること
  • 第三者保証：開示したサステナビリティ情報を外部が検証すること。監査の一種
