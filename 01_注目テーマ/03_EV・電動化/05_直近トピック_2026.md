# 直近トピック（2026年9月時点）

報道・調査会社ベースの整理。**数値は集計主体によって定義も値も違う**ので、
一次情報（各社IR、IEA、政府発表）で必ず裏取りすること。

## 1. 「EV減速」の実態：伸びは続いているが、伸び率が鈍った

まず数字の整理から。ここが最も誤解されている。

| 指標 | 数値 | 備考 |
| --- | --- | --- |
| 2025年 世界EV・PHEV販売 | **2,000万台超**（前年比約20%増） | 新車の約4台に1台 |
| 2025年 世界シェア | **約25%** | 集計によっては16〜20%（BEV単独か、PHEV込みかで変わる） |
| 2026年 見通し | **前年比約12%増、シェア約3割** との予測 | 日経の報道ベース。米国は減少、中国・欧州・東南アジアが牽引 |
| 別推計 | 2026年 **2,270万台**、新車の19.8%（2025年16.5%） | EV Volumes系の推計。定義が違うため上の数字とは直接比較できない |

```
 世界EV・PHEV販売（概数／報道・調査会社ベース）
  台数
  2,300万 ┤                              ■  2026年(見通し)
  2,000万 ┤                        ■        2025年 実績
  1,700万 ┤                  ■              2024年
  1,400万 ┤            ■                    2023年
          └──────────────────────────────▶
   伸び率:      +35%   +21%   +20%   +12%   ← 台数は増え、伸び率は下がる
```

> **読み方**：販売台数は過去最高を更新し続けている。
> 減速しているのは**成長率**であり、市場そのものは縮んでいない。
> 「EVが失速した」という言説の実体は、(a)米国の政策転換による反動減、
> (b)欧州の規制緩和論、(c)メーカーの投資計画の下方修正、この3つが同時に起きたこと。

一方で、揺り戻しも明確に出ている。2026年に入り、
EU では2035年のエンジン車販売禁止目標の緩和案が出され、
中国では自動車取得税の全額免税が終了して国内販売に急ブレーキがかかった、と報じられている。
PHEVの成長率も前年比+20%程度に鈍化し、**PHEVですら勢いが落ちている**という指摘がある。

## 2. 米国：連邦税額控除の終了が効いた

- 2025年7月成立の **One Big Beautiful Bill Act** により、
  連邦のEV税額控除（新車30D＝最大7,500ドル、中古25E＝最大4,000ドル、商用・リース45W）は
  **2025年9月30日取得分をもって終了**
- 代替として、新車ローンの利息を年最大1万ドルまで所得控除できる制度（2025〜2028年）が導入された。
  EV専用ではなく**全ての新車が対象**であり、EV優遇ではない
- 結果として2025年9月に駆け込み需要、その後に反動減という波が生じたと報じられる。
  2026年の米EV販売は前年割れとの見方が優勢
- 含意：米国市場は **「補助金がないと成立する価格帯なのか」を初めて試されている**。
  ここでの実需の水準が、各社の北米投資計画の前提になる

## 3. 欧州：2035年の「エンジン車ゼロ」が事実上見直された

- 2025年12月、欧州委員会が2035年目標の見直し案を提示。
  **「排出ゼロ」から「90%削減」へ緩め**、プラグインハイブリッド、レンジエクステンダー、
  マイルドハイブリッド、e-fuel等の継続余地を残す内容と報じられた
- 小型で手頃なEUで生産されたEVには「スーパークレジット」を与える案も含まれ、
  **気候政策と域内産業保護が明確にセットになっている**
- 2026年1月から政治交渉に入り、**2026年中にさらに見直される可能性**も指摘されている
- 注意点：緩和されたのは「100%削減」という部分であり、CO2規制の枠組み自体は継続する。
  「EVをやめてよい」という話ではない

## 4. 日本勢：計画の下方修正とHEVへの傾斜

| メーカー | 2026年前後の動き（報道ベース） |
| --- | --- |
| **ホンダ** | 2030年度までのEV関連投資を **10兆円 → 7兆円**に引き下げ、2030年度のEV販売目標も **200万台 → 75万台程度**へ修正。米国生産予定だったEV3車種の開発・発売を中止。2026年3月期に上場来初の最終赤字（約4,000億円）を計上し、「2040年全車EV/FCEV化」目標は事実上撤回と報じられる |
| **トヨタ** | EV販売計画を再度下方修正する一方、中国では現地開発で攻勢。2026年5月にレクサスの次世代EV「LF-ZC」の量産開発を中止と報じられる。稼ぐエンジン車・HEVの利益を全固体電池と車載OS「Arene」に再投資する構え |
| **日産** | 全固体電池の自社開発を戦略の中核に据え、2028年度の量産投入を目標。ホンダ・三菱自との提携で次世代EVプラットフォームやソフト開発の負担分散を図る |

> **構図**：日本勢の修正は「EVをやめる」ではなく
> **「EV専用の巨額先行投資をやめ、HEV・PHEVで稼ぎながら次世代電池とソフトに絞って投資する」**
> という戦い方への切り替え。HEVが強い日本勢にとって、EV減速局面は相対的に有利に働いている。
> ただしこれは**時間を買っているだけ**で、中国勢のコスト水準に追いつく課題は残る。

## 5. 中国：「内巻」への当局介入と、それでも続く消耗戦

- 生産能力が国内需要を大きく上回る状態が続く。JETROの整理によれば、
  政府・業界団体は2025年から過当競争（内巻）の解消に本格的に取り組み始めた
- 2025年6月、工業情報化部と国家市場監督管理総局がメーカーへのヒアリングを実施し、
  価格法や低価格ダンピング禁止規定の遵守、価格コンプライアンスと品質管理の強化を求めた
- それでも値引きは止まらず、**BYDの2026年3月の平均値引き率は約10%で過去最高を更新**と報じられる
- 2026年も各社が軒並み二桁増の販売目標を掲げ、新興EVは最大7割増を狙うなど、競争は継続
- 副作用として、**サプライヤーへの支払いサイトの長期化**など供給網の持続性が問題視されている

## 6. 電池：価格は過去最低、全固体は「2027〜2028年」が焦点

### 価格

- BloombergNEF（2025年12月発表）によれば、2025年の **リチウムイオン電池パック価格は
  世界平均 108ドル/kWh**（前年比約8%減）で過去最低を更新
- 要因は **セルの供給過剰、激しい価格競争、LFPへのシフト**。
  リチウム・コバルトの金属価格は2025年に上昇したが、セル価格には転嫁されなかった
- 用途別では定置用蓄電池が **約70ドル/kWh**（前年比約45%減）と最も安いセグメントに。
  LFPパックの全セグメント平均は約81ドル/kWh
- BNEFは2026年もさらなる低下を見込むとされる

### 全固体電池

| 主体 | 状況（2026年時点の報道ベース） |
| --- | --- |
| トヨタ | 2026年度版BEVロードマップで **2027〜2028年に全固体電池搭載EVを投入**と明記。出光興産とのJV「LHバッテリー」で硫化物系固体電解質の量産体制を構築中 |
| 日産 | 2026年4月、**実車サイズの全固体電池セルで目標性能を達成**と公表。2028年度の量産投入を目指す |
| 中国・国軒高科 | 正式量産は2027年だが、一部を2026年中に製造する見込みと報じられる |
| 台湾・ProLogium | 第2世代セル（準固体系）の量産を2024年から開始、出荷累計240万個規模とされる |

> **注意**：全固体電池は資源制約を解決しない（正極・負極の材料系は基本的に同じ）。
> 論点は「できるか」ではなく **「量産価格でLFPに勝てるか」**。
> 詳しくは [バッテリーとコスト構造](02_バッテリーとコスト構造.md)。

## 7. 充電インフラ：日本は目標の約2割、規格はNACSへ動く

- 日本政府の目標は **2030年までに30万口（うち急速3万口）**。
  2024年度末時点の整備済みは **約6.8万口**（急速約1.2万口／普通約5.6万口）で、
  前年度から約2.8万口増加したと報じられる。増加ペースは上がっているが目標には距離がある
- 2026年度は **戸建住宅の充電用コンセント設置も補助対象**に加わり、
  令和7年度補正予算の関連措置のうち365億円規模が充電インフラ補助に配分されると報じられる
- 規格面では北米で **NACS**（テスラ方式）への収斂が進み、
  **日産リーフも2026年モデルでNACSを採用**。日本国内でもNACS対応の急速充電器投入が発表され、
  CHAdeMOとの併存が続く見通し
- 日本の新車販売に占めるEV比率は **2〜3%台**で推移（2025年）。
  普及の制約は価格だけでなく、**集合住宅で基礎充電を持てない**という構造にある

```
 政策の潮目（2025→2026）
  米国  ─ 税額控除あり ──┤2025/9/30で終了├── 補助なしの実需を試す局面
  欧州  ─ 2035年ゼロ ───┤90%削減へ緩和案├── PHEV・e-fuelの余地
  中国  ─ 取得税免税 ───┤2025年末で終了├── 反動減＋当局の内巻是正
  日本  ─ CEV補助継続 ──────────────────── HEV優位は変わらず
```

## 8. 全体の構図（2026年9月時点のまとめ）

1. **EVは減っていない。伸び率が鈍っただけ**。2025年に世界2,000万台超、2026年も増加見通し
2. ただし地域差が極端で、**米国は政策転換で減速、中国・欧州・東南アジアが牽引**する構図
3. 欧州の2035年目標は緩和方向、米国の税額控除は終了。**「政策が作った市場」の潮が一度引いた**
4. 日本勢は投資計画を下方修正し、**HEVで稼ぎつつ全固体電池とソフトに絞る**戦い方へ切り替え
5. 電池価格は108ドル/kWhと過去最低。**安さの主因はLFPと供給過剰**で、中国勢の優位が続く
6. 全固体電池の焦点は2027〜2028年。**技術の可否ではなく量産コスト**が勝負どころ

## 用語メモ

- **NEV**：中国の新エネルギー車（BEV＋PHEV＋FCEV）。HEVは含まない
- **OBBBA**：One Big Beautiful Bill Act。2025年7月成立の米法律。EV税額控除を2025年9月末で終了させた
- **30D／25E／45W**：米国の新車／中古／商用・リース向けEV税額控除の条文番号
- **スーパークレジット**：特定の車（小型・域内生産EV等）を規制上、複数台分としてカウントする優遇
- **内巻（ネイジュアン）**：中国で使われる、消耗的な過当競争を指す語
- **LFP**：リン酸鉄リチウム電池。安価・長寿命だがエネルギー密度は低い
- **NACS**：North American Charging Standard。テスラ由来の北米充電規格
- **CEV補助金**：日本のクリーンエネルギー自動車導入促進補助金
