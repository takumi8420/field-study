# EV・電動化｜バッテリーとコスト構造

**このノートで分かること**：EVの値段はほぼ電池で決まる。その電池が何でできていて、
なぜ値段が下がってきたのか、そして航続距離・充電時間という体感性能が何で決まるのか。

結論から言うと、EVの原価の **3〜4割が電池パック**。
電池パックの原価の **6〜8割が材料費**。つまり EVの価格競争は、実体としては **鉱物と化学の競争** である。

## 0. 電池の階層：セル → モジュール → パック

```
 ┌── セル(Cell) ───────────────┐   電池の最小単位。1個あたり3〜4V程度
 │  正極 / セパレータ / 負極 / 電解液  │   形状は 円筒形・角形・パウチ の3種
 └─────────────────────────────┘
            ↓ 数十個を束ねて配線・冷却板・監視回路を付ける
 ┌── モジュール(Module) ──┐            取り扱いと交換の単位
 └────────────────────────┘
            ↓ 数個〜十数個を筐体に収め、BMS・冷却・高電圧回路を付ける
 ┌── パック(Pack) ──────────────────┐  車に載る最終形。数百kg、容量40〜100kWh級
 │  車体の床下いっぱいに敷き詰める              │  衝突時の保護構造も兼ねる
 └──────────────────────────────────┘
```

近年は中間のモジュールを省く **CTP（セル・トゥ・パック）**、
さらにパック筐体を車体構造と一体化する **CTB／CTC（セル・トゥ・ボディ／シャシー）** が広がった。
狙いは単純で、**無駄な箱と金具を減らせば、同じ体積により多くのセルが入る**＝航続距離が伸びてコストが下がる。

## 1. セルの中身と、材料が決める性格

| 部材 | 役割 | 主な材料 | 噛み砕くと |
| --- | --- | --- | --- |
| 正極（カソード） | リチウムイオンの出し入れ先。容量と電圧を決める | NCM（ニッケル・コバルト・マンガン）、NCA、LFP（リン酸鉄リチウム） | **一番高く、性格を決める部材**。原価の3〜4割 |
| 負極（アノード） | 充電時にリチウムイオンを蓄える | 黒鉛（人造・天然）、一部シリコン添加 | 黒鉛の加工は中国に極端に集中 |
| セパレータ | 正極と負極の接触（＝ショート）を防ぐ薄膜 | ポリオレフィン微多孔膜 | 破れると発火。日本勢（旭化成・東レ）が強い |
| 電解液 | イオンの通り道 | 有機溶媒＋リチウム塩（LiPF6） | 可燃性。これを固体に置き換えるのが全固体電池 |

### 化学系（ケミストリー）の比較

| 方式 | エネルギー密度 | コスト | 安全性・寿命 | 主な用途 |
| --- | --- | --- | --- | --- |
| **NCM／NCA（三元系）** | 高い（軽く遠くまで走る） | 高い（ニッケル・コバルトを使う） | 熱暴走リスクが相対的に高い | 高級・長距離EV、日韓勢が得意 |
| **LFP（リン酸鉄）** | 低め（同じ航続には多く積む） | **安い**（コバルト・ニッケル不要） | 熱的に安定、サイクル寿命が長い | 普及価格帯EV、定置用蓄電池。中国勢が主導 |
| **LMFP／高電圧LFP** | LFPより改善 | 安い | 良好 | LFPの弱点を補う改良系 |
| **ナトリウムイオン** | さらに低い | リチウム不要で潜在的に安い | 低温に強いとされる | 量産は始まったばかり。小型車・定置向け |
| **全固体** | 高い（狙いは大幅改善） | 現時点では高い | 電解液が不燃固体になる | 2027〜2030年の実用化を各社が目標 |

> **ここが読みどころ**：2020年前後は「エネルギー密度＝正義」だったが、
> EVが補助金頼みから実需へ移った結果、**「安くて壊れないLFP」の比重が世界的に上がった**。
> 性能競争から価格競争へ軸が移ったことが、そのまま中国勢の優位につながっている。

## 2. 電池の価格はどう下がってきたか

| 年 | リチウムイオン電池パック価格（世界平均） | 出典・備考 |
| --- | --- | --- |
| 2010年 | 約1,200ドル/kWh | BloombergNEF（BNEF）の年次調査 |
| 2023年 | 約139ドル/kWh | BNEF |
| 2024年 | 約115ドル/kWh | BNEF。2017年以降で最大の下落幅と発表 |
| 2025年 | **約108ドル/kWh**（前年比 約8%減） | BNEF（2025年12月発表）。過去最低 |

- 2025年の下落理由は、BNEFによれば **セルの供給過剰・激しい価格競争・LFPへのシフト**。
  リチウムやコバルトの金属価格は2025年に上昇したのに、セル価格には転嫁されなかった
- 用途別では **定置用蓄電池が約70ドル/kWh** まで下がり、最も安いセグメントになったとされる
- BNEFは2026年もさらなる低下を見込む、と報じられている

### この数字を車の値段に翻訳すると

```
 60kWh の電池パック（航続400km級の目安）
   × 108ドル/kWh ＝ 約6,480ドル（2025年の世界平均価格で単純計算）
   ※ 1ドル150円換算なら約97万円

 実際の車両では、パック以外に eAxle・高電圧部品・熱管理が乗る。
 同クラスのエンジン車より車両原価が高くなりやすい構図は、まだ完全には解消していない。
```

**注意**：上記は世界平均の単純計算。実際の調達価格は数量・化学系・地域で大きく違い、
中国国内のLFPセルはこれよりかなり安いとされる。金額は毎年動くので **最新はBNEF等で確認すること**。

## 3. 航続距離は何で決まるのか（簡単な算数）

```
 航続距離(km) ＝ 電池容量(kWh) ÷ 電費(kWh/km)

 例）容量 60kWh、電費 0.15kWh/km（＝1kWhで約6.7km走る）
      → 60 ÷ 0.15 ＝ 400km
```

つまり航続距離を伸ばす手は2つしかない。**容量を増やす（＝高く重くなる）** か、
**電費を良くする（＝空力・軽量化・モーター効率・タイヤ転がり抵抗）** か。

| 航続を削る要因 | 理由 |
| --- | --- |
| 冬の低温 | 電池自体の性能低下に加え、**暖房に電力を使う**。エンジン車は排熱で暖房できるがEVはできない。ヒートポンプ搭載車は影響が小さい |
| 高速走行 | 空気抵抗は速度の2乗で効く。EVは高速道路で電費が悪化しやすい |
| 重い積載・勾配 | 位置エネルギー分の消費。ただし下りでは回生で一部戻る |
| 電池の劣化 | 使用年数とサイクル数で容量が漸減する |

カタログ値は測定モード（日本はWLTC、中国はCLTC、米国はEPA）で大きく違う。
**CLTC値は実走行より甘めに出やすい**ため、国をまたいだ比較では基準を揃える必要がある。

## 4. 充電速度の制約：なぜ「5分で満充電」にならないか

- 充電電力(kW) ＝ 電圧(V) × 電流(A)。速くするには電圧を上げるか電流を増やすしかない
- 電流を増やすとケーブルと電池が発熱する → 冷却設備が要る。だから **800Vアーキテクチャ**（電圧を上げて電流を抑える）が増えた
- 電池には **C レート** という上限がある。1C＝1時間で満充電になる電流。3Cなら約20分
- リチウムイオンは満充電に近づくと受け入れ速度を落とす（過充電で劣化・発火するため）。
  このため急速充電は **概ね80%までが実用域**で、カタログの「◯分で80%」はここを指す

```
 充電カーブ（イメージ）
 出力kW
  ▲
  │■■■■■■■■■■■□□
  │                 □□□□□□  ← 80%超で急激に絞られる
  └────────────────────────▶ 充電率(SOC)
   10%      50%     80%    100%
```

## 5. 電池のサプライチェーン：どこが詰まるか

```
 資源採掘 ──▶ 精錬・化合物化 ──▶ 部材(正極/負極/電解液/セパレータ) ──▶ セル ──▶ パック ──▶ 車
 リチウム:豪・チリ    ★中国に集中★        中国・日本・韓国        CATL/BYD/LG/     OEM内製
 コバルト:コンゴ                                              パナソニック/SK/Samsung
 ニッケル:インドネシア
 黒鉛:中国
```

- ボトルネックは採掘そのものより **精錬・化合物化の工程**。ここは中国のシェアが圧倒的に高い
- 米国のIRA（インフレ抑制法）や欧州の規制は、この集中を崩すために
  「どこで採り、どこで加工したか」を優遇条件に組み込んできた
- コンゴのコバルト輸出割当、中国のレアアース・黒鉛の輸出管理など、
  **資源が政策の道具として使われる**構図が定着している（→ [レアメタル・レアアース](../../11_資源・エネルギー・鉄鋼金属/13_レアメタル・レアアース/README.md)）

## 6. 使い終わった後：リユースとリサイクル

| 段階 | 内容 | 経済性 |
| --- | --- | --- |
| リユース（二次利用） | 車載として劣化した電池を定置用蓄電池へ転用 | 検査・選別コストが高く、新品LFPが安いと成立しにくい |
| リサイクル | 破砕して「ブラックマス」にし、ニッケル・コバルト・リチウムを回収 | **NCM系は回収価値が高いがLFP系は低い**。LFP普及はリサイクル経済性を悪化させる皮肉がある |
| 規制 | 欧州の電池規則（バッテリーパスポート、再生材使用率の義務化） | 回収網を持つことが事業要件になりつつある |

## 7. 全固体電池：何が変わって、何が変わらないか

- **変わる**：電解液（可燃性の液体）を固体電解質に置き換える。発火リスクの低減、
  高温耐性、理論上のエネルギー密度向上、急速充電性能の改善が期待される
- **変わらない**：正極・負極の材料は基本的に同じ系統を使うため、**資源制約は解決しない**
- **課題**：固体同士の界面をどう密着させ続けるか（充放電で電極が膨らむ）、大面積セルの量産技術、コスト
- 2026年時点の状況：トヨタが2027〜2028年の搭載を掲げ、日産は2026年4月に実車サイズセルで
  目標性能を達成したと公表（2028年度量産を目標）と報じられる。中国勢・台湾勢も量産を宣言しており、
  **「いつ・どの容量で・いくらで」出るかが焦点**（→ [直近トピック（2026年）](05_直近トピック_2026.md)）

> 注意：全固体電池は「明日すべてを置き換える技術」ではない。
> 当面は高価格帯からの限定投入で、**量産価格でLFPに勝てるかは別問題**。

## 用語メモ

- **kWh（キロワットアワー）**：電気の量の単位。電池の「タンクの大きさ」
- **kW（キロワット）**：電力＝速さの単位。充電器の出力や、モーターの出力に使う
- **セル／モジュール／パック**：電池の3階層。最小単位／中間の束／車載の最終形
- **CTP／CTB**：モジュールを省いてセルを直接パックや車体に組み込む構造
- **NCM・NCA**：ニッケル系の三元正極。高エネルギー密度・高コスト
- **LFP**：リン酸鉄リチウム。安価・長寿命・低エネルギー密度
- **エネルギー密度**：単位重量（Wh/kg）や体積（Wh/L）あたりに蓄えられる電気の量
- **C レート**：電池を何時間で充放電するかを示す指標。1C＝1時間
- **SOC**：State of Charge。充電率（%）
- **熱暴走**：内部短絡等で温度が上がり、連鎖的に発熱・発火する現象
- **電費**：1kWhで何km走れるか（またはkm走るのに何kWh使うか）
- **WLTC／CLTC／EPA**：日本・中国・米国の燃費／電費の測定モード
- **ブラックマス**：使用済み電池を破砕・選別して得られる金属濃縮粉
