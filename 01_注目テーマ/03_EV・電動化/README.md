## 1. テーマの定義・範囲

**電動化（Electrification）** とは、自動車の動力源を内燃機関（ガソリン・ディーゼルのエンジン）から
電気モーターへ置き換えていく流れの総称。「EV」という言葉は文脈により指す範囲が違うので、まずここを分ける。

| 略称 | 正式名 | 動力 | 外部充電 | エンジン |
| --- | --- | --- | --- | --- |
| **BEV** | 電気自動車 | モーターのみ | する | なし |
| **PHEV** | プラグインハイブリッド車 | エンジン＋モーター | する | あり |
| **HEV** | ハイブリッド車 | エンジン＋モーター | しない | あり |
| **FCEV** | 燃料電池車 | モーター（水素で発電） | 水素を充填 | なし |
| **MHEV** | マイルドハイブリッド | エンジン主体＋補助モーター | しない | あり |

- 狭義の「EV」＝ BEV。欧米の統計は **BEV＋PHEV** をまとめることが多い
- 中国の「NEV」＝ BEV＋PHEV＋FCEV（HEVは含まない）
- **日本の政策で言う「電動車」はHEVを含む**。ここが海外との議論のズレの元になる

隣接領域との境界：電池そのものの産業は [蓄電池](../04_蓄電池/README.md)／[二次電池](../../03_電機・電子部品/08_二次電池/README.md)、
車載ソフトと自動運転は [自動運転](../15_自動運転/README.md)、
水素・燃料電池は [水素・アンモニア](../06_水素・アンモニア/README.md) に分けてある。

## 2. 市場規模と成長性

| 指標 | 数値 | 時点・出典 |
| --- | --- | --- |
| 世界のEV・PHEV販売 | **2,000万台超**（前年比約20%増）、新車の約25% | 2025年、報道・調査会社ベース |
| 2026年見通し | 前年比 **約12%増**、シェア約3割 | 報道ベースの予測。米国は減少、中国・欧州・東南アジアが牽引 |
| 別推計 | 2026年 2,270万台、新車の19.8% | EV Volumes系推計。**BEV単独かPHEV込みかで数字が変わる**点に注意 |
| 日本の新車EV比率 | **2〜3%台**（EV単独） | 2025年。登録車ベースでは1%台という集計もある |
| 電池パック価格 | **108ドル/kWh**（前年比約8%減、過去最低） | 2025年、BloombergNEF |

> **押さえどころ**：「EVが失速した」と語られるが、販売台数は増え続けている。
> 鈍ったのは**成長率**。詳細は [⑤ 直近トピック](05_直近トピック_2026.md)。

## 4. 主要プレイヤーとシェア

| 区分 | 主なプレイヤー | 立ち位置・特徴 |
| --- | --- | --- |
| EV専業・新興 | テスラ、リビアン、中国新興各社 | ソフトと垂直統合が強み。量産品質が課題になりやすい |
| 中国大手 | BYD、Geely、上汽、長安 | **BYDは電池から半導体まで垂直統合**。2025年のBEV販売でテスラを通年で上回ったとされる |
| 欧州OEM | VW、ステランティス、BMW、メルセデス、ルノー | CO2規制対応でEVを売る必要がある側。収益性との板挟み |
| 米OEM | GM、フォード | 税額控除終了で計画を修正中 |
| 日本OEM | トヨタ、ホンダ、日産、三菱、スズキ | **HEVで稼ぎながらBEVは慎重**。2026年に投資計画の下方修正が相次いだ |
| 電池 | CATL、BYD、LGエナジー、パナソニックエナジー、SK on、Samsung SDI | 上位は中国・韓国勢。LFPで中国勢が先行 |

## 5. 収益モデル・コスト構造

| 論点 | 中身 |
| --- | --- |
| 原価構成 | 車両原価の **3〜4割が電池パック**。電池パック原価の6〜8割が材料費 |
| なぜEVは儲かりにくいか | 電池が高く、量産規模が小さく、開発費（新プラットフォーム＋ソフト）が重い。**規模が出るまで赤字**という装置産業的な構造 |
| 誰が儲けているか | 電池メーカー（特にLFPで量産規模を持つ中国勢）、パワー半導体、垂直統合できるOEM |
| 新しい収益源 | OTAによる機能販売、充電ネットワーク、エネルギーサービス（V2G）、残価保証つきリース |
| リスク | 電池の残存価値が読めず **中古価格が下がりやすい** → リース・残価設定ローンの与信リスクになる |

> EVの損益は「1台あたりいくら儲かるか」ではなく、
> **「その車種で何十万台作れるか」**で決まる。少量多品種はEVと相性が悪い。

## 6. 競争要因（KSF）と参入障壁

1. **電池の調達力**：長期契約・合弁で量と価格を押さえられるか。ここが最大の差
2. **量産規模**：プラットフォームを共通化し、1車種で数十万台規模を作れるか
3. **ソフトウェア開発力**：車載OS、OTA、ADAS。内製できる人材を抱えられるか
4. **熱管理と安全設計**：発火事故は致命傷。リコール1回で信頼が飛ぶ
5. **販売とサービス網**：充電の不安を解消する体験設計（残価保証、充電契約の抱き合わせ）
6. **地域ごとの適合**：規格・税制・ユーザー要求が地域で違う（→ [④ 各地域の政策と市場](04_各地域の政策と市場.md)）

参入障壁は「組み立て」ではなく **安全認証・品質保証・電池調達** の側にある。
2010年代に多数生まれた新興EVメーカーの多くが量産段階で脱落したのは、ここを甘く見たため。

## 7. 規制・法制度

| 地域 | 主な制度 |
| --- | --- |
| EU | 乗用車CO2排出規制。2035年の「実質ゼロ」目標は2025年末に **90%削減へ緩和する案**が提示され、2026年に立法手続きが継続中と報じられる。中国製BEVへの相殺関税 |
| 米国 | IRAのEV税額控除は **2025年9月30日取得分で終了**（OBBBA）。燃費・排ガス規制、州のZEV規制の扱いが争点 |
| 中国 | NEVクレジット（ダブルクレジット）規制、購入税減免の段階的縮小、過当競争（内巻）への当局の是正指導 |
| 日本 | 2035年までに乗用車新車販売で **電動車100%**（HEVを含む）。CEV補助金、充電・充てん設備の導入補助（2026年度は戸建住宅も対象に） |

## 8. 最近のトピック

詳細と出典は [⑤ 直近トピック（2026年9月時点）](05_直近トピック_2026.md)。要点だけ挙げると:

- **「EV減速」の実体は成長率の鈍化**。2025年に世界2,000万台超で過去最高、2026年も増加見通し
- **米国は連邦EV税額控除が2025年9月末で終了**し、駆け込みと反動減が発生
- **EUは2035年のエンジン車ゼロ目標を90%削減へ緩和する方向**。PHEV・e-fuelの余地を残す
- **日本勢は計画を下方修正**。ホンダはEV投資10兆円→7兆円、販売目標200万台→75万台程度へ
- **電池パックは108ドル/kWhで過去最低**（2025年、BNEF）。安さの主因はLFPと供給過剰
- **全固体電池の焦点は2027〜2028年**。トヨタ2027〜2028年投入、日産2028年度量産を目標
