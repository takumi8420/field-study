EV・電動化｜クルマの構造がどう変わるか

注目テーマEV・電動化
あこのページの単語集用語に触れると意味を確認できます14語
セル・トゥ・パック / セル・トゥ・ボディBEVHEVPHEVFCEVeAxleインバーターBMS回生ブレーキギガキャストSDVOTATier1／Tier2LCA

このノートで分かること：エンジン車（内燃機関車）とEVでは、車の中身と作り方がどう違うのか。
そして、その違いがなぜ「部品メーカーの再編」「系列の崩れ」という産業の話に直結するのか。

結論を先に書くと、EV化とは 「熱と回転を作る装置（エンジン）を、電気を貯めて回す装置（電池＋モーター）に入れ替える」 こと。
入れ替わるのは動力部分だけだが、そこが車両原価の3〜4割を占め、しかも 日本の部品産業が最も得意にしてきた領域 だったため、影響が大きい。

0. 全体像：何が何に置き換わるか

【エンジン車】
 燃料タンク ─▶ エンジン ─▶ トランスミッション ─▶ ドライブシャフト ─▶ 車輪
                 ▲  ▲                (多段変速が必要)
            吸排気系 冷却系
            燃料系  点火系    ← ここに数千〜1万点の部品が付く

【EV（BEV）】
 充電口 ─▶ 電池パック ─▶ インバーター ─▶ モーター ─▶ 減速機(1段) ─▶ 車輪
            (床下に敷く)   (直流→交流)            └─ eAxle として3点を一体化
                 ▲
            BMS・冷却・高電圧ハーネス・DC-DCコンバーター

エンジン車は「燃やして回す」ため、吸気・排気・燃料・点火・冷却・潤滑・変速という
補助系統が芋づる式に必要になる。EVはこれがまるごと消える代わりに、
電池・電力変換（パワーエレクトロニクス）・熱管理 が新たに主役になる。

1. 部品点数はどれだけ違うのか

区分 エンジン車 EV（BEV） 備考
車1台の部品点数約3万点約2万点一般に流通する概数。数え方の定義で幅がある
うちエンジン・駆動系約1万点数百〜千点規模エンジン単体で1万点近いとされる
変速機6〜10速の多段AT/CVT1段減速機が基本モーターは低回転から最大トルクが出るため多段が不要

注意：「約3万点→約2万点」は経産省の委託調査や業界解説で広く使われる概数であり、
車格・カウント方法で変わる。正確な統計値ではなく、桁感を掴むための数字として扱う。

そして重要なのは、減るのは点数であってコストではないこと。
消えた1万点の部品代よりも、追加される電池パックの方が高い。ここがEVが安くならない最大の理由。

2. 消える部品・残る部品・増える部品

分類 代表例 産業への影響
消えるエンジン本体（シリンダーブロック、ピストン、クランク、動弁系）、燃料噴射装置、点火プラグ、マフラー・触媒、多段変速機、スターター、オルタネーターピストンリング・バルブ・排気系の専業メーカーが事業転換を迫られる
残る（EVでも必要）ボディ・プレス部品、シャシー、サスペンション、ブレーキ、タイヤ、シート、内装、ガラス、ランプ、ベアリング売上規模は維持。ただし完成車の値引き圧力は受ける
増える・大きくなる電池セル／モジュール／パック、モーター、インバーター、DC-DCコンバーター、車載充電器（OBC）、高電圧ハーネス、電動コンプレッサー、ヒートポンプ、BMS、パワー半導体ここに投資が集中。電機・電子部品業界が自動車に流入してくる
性格が変わるブレーキ（回生協調）、ステアリング（電動化・ステアバイワイヤ）、空調（エンジン排熱が使えず電力で暖房）ソフトと制御の比重が上がる

回生ブレーキ（減速時にモーターを発電機として使い、運動エネルギーを電気に戻す仕組み）が入ると、
機械ブレーキの使用頻度が下がる。ブレーキパッドの交換需要が落ちるなど、補修部品の市場にも波及する。

3. 駆動系の主役：eAxle（イーアクスル）

EVの駆動ユニットは、モーター＋インバーター＋減速機を一体化した「eAxle」に集約されつつある。

構成要素 役割 噛み砕くと
モーター電気で回転を生む多くは永久磁石同期モーター（PMSM）。ネオジム磁石を使う
インバーター電池の直流をモーター用の交流に変換し、回転数とトルクを制御「アクセルの開度をモーターの回し方に翻訳する装置」。中身はパワー半導体
減速機モーターの高回転を車輪の回転数まで落とすギアは1段で足りる

一体化する理由は、配線と筐体を減らして軽く安くできるから。
逆に一体化が進むほど「モーターだけ」「インバーターだけ」を売る部品メーカーの居場所が狭くなる。

パワー半導体の材料が Si（シリコン）→ SiC（炭化ケイ素） に移ると、
電力の損失が減って同じ電池容量でも航続距離が伸びる。
つまり 半導体の進化が車の性能に直結する 構造になった（→ 半導体・先端半導体）。

4. 作り方（工程）はどう変わるか

【エンジン車の工場】
 鋳造 ─▶ 機械加工 ─▶ エンジン組立 ─▶ ┐
 プレス ─▶ 溶接 ─▶ 塗装 ─▶ 組立 ─▶ 検査（排ガス測定あり）

【EVの工場】
 （鋳造・機械加工の比重が激減。代わりに）
 セル生産 ─▶ モジュール組立 ─▶ パック組立 ─▶ ┐
 プレス／ギガキャスト ─▶ 溶接 ─▶ 塗装 ─▶ 組立 ─▶ 検査（絶縁・気密・高電圧安全）
  • エンジン工場の機械加工ラインが不要になる。ここは熟練と設備投資の塊で、雇用も多い
  • 代わりに必要なのは 電池工場（化学プラントに近い） と 高電圧の取り扱い技能
  • ギガキャスト（車体後部などを一体アルミダイカストで鋳造し、数十点の部品を1点にまとめる手法）が広がると、
    プレス・溶接工程そのものが減る。ただし事故時の修理が難しくなる等の課題も指摘される
  • セル・トゥ・パック / セル・トゥ・ボディ：モジュールを省いてセルを直接パックや車体に組み込み、
    体積効率を上げる手法（→ バッテリーとコスト構造）

ポイント：EVは「部品が少ないから簡単に作れる」のではない。
高電圧（400〜800V）を扱うため 感電・発火・絶縁の安全設計 が重く、
電池の熱管理を外すと発火事故に直結する。参入障壁は「組み立て」ではなく 安全・認証・品質保証 の側にある。

5. 内製／外注の線引きはどこに引かれるか

完成車メーカー（OEM）が何を自社で持つかは、EV時代の最大の経営判断になっている。

領域 内製に寄せる動機 外注に寄せる動機 実際の傾向
電池セル原価の3〜4割。押さえないと車の競争力を握れない投資額が兆円単位。化学産業のノウハウが要る合弁（JV）が主流。OEMと電池メーカーで折半
電池パック車体設計と不可分。安全責任もOEM—OEM内製が多い
モーター／eAxle走りの味を作る中核汎用化すれば買った方が安い大手は内製、量産効果を狙う新興は外部調達
インバーター／パワー半導体性能を左右する半導体は専業が圧倒的に強い半導体は外部調達が基本、制御ソフトは内製
車載OS・ソフト差別化の主戦場。OTA更新で収益化開発人材が足りない内製化を宣言するOEMが増加
シャシー・内外装—従来どおり系列・専業が強い外注継続

要するに 「電池・ソフトはOEMが取りに行き、機構部品は外に出す」 方向。
この線引きの変化が、次の系列の話につながる。

6. 系列（ティア構造）はどう揺れるか

日本の自動車産業は、完成車メーカーを頂点に
Tier1（直接納入）→ Tier2 → Tier3 という ピラミッド型の系列 で回ってきた。

【従来】                          【EV時代】
   OEM                               OEM ◀──── 電池メーカー（CATL, LG, パナソニック）
    │                                 │  ◀──── 半導体メーカー（パワー半導体・SoC）
  Tier1（ユニット単位で納入）           │  ◀──── ソフト／半導体設計（新規プレイヤー）
    │                                Tier1（機構部品は従来どおり）
  Tier2（部品単位）                     │
    │                                Tier2・Tier3 ← エンジン部品は需要そのものが縮む
  Tier3（加工・素材）
  • Tier1の頭越し取引が増える。電池と半導体はOEMが直接、大手サプライヤーと交渉する
  • 電機・電子部品メーカー（モーター、コネクタ、電子部品）が 自動車のTier1に昇格 してくる
  • エンジン部品を主力にしてきたTier2・Tier3は、
    (a) 電動部品へ転換、(b) 航空・産業機器など他分野へ展開、(c) 統合・廃業 のいずれかを迫られる
  • 一方で HEV（ハイブリッド）はエンジンも電動部品も両方要るため、
    HEVが売れている間は既存サプライヤーの延命になる。これが日本勢にとって時間稼ぎになっている

詳しくは 自動車部品 と
自動車（完成車） を参照。

7. 電気系アーキテクチャ（E/E）とソフトウェア

EV化と同時に進んでいるのが、車内の電子系の作り直し。

段階 構造 特徴
従来型機能ごとにECU（小型コンピューター）を分散。1台に50〜100個部品メーカーが「ECU込み」で納入。OEMは中身を知らなくても成立した
ドメイン集約走行系・車体系・情報系など領域ごとに1個の高性能ECUへ集約配線が減り、ソフト更新がしやすくなる
ゾーン／セントラル車体の場所ごとに中継し、中央の高性能コンピューターが統括車がスマホに近づく。OTA（無線ソフト更新）で機能追加・販売後の収益化が可能に

この流れを SDV（Software Defined Vehicle） と呼ぶ。
EVでなくても成立する話だが、EVは電力配分・電池制御・熱管理をソフトで統合的に最適化する必要があり、
EV化とSDV化は実務上セットで進む。自動運転の議論とも地続き（→ 自動運転）。

8. よくある誤解を潰す

誤解 実際
「部品が3分の2になるから誰でもEVを作れる」安全認証・衝突試験・電池の熱暴走対策・品質保証の壁は変わらず高い。新興EVメーカーの多くが量産と品質で躓いた
「EVは電池を積むだけ」電池は重い（数百kg）。重量増に合わせてサスペンション・ブレーキ・ボディ剛性を作り直す必要がある
「エンジンが無いから整備需要が消える」オイル交換等は消えるが、タイヤ摩耗は重量増で早まる。整備の中身が入れ替わる
「EV＝ゼロエミッション」走行中の排出はゼロだが、製造時（特に電池）と充電する電気の発電方法を含めた LCA（ライフサイクルアセスメント） で見る必要がある
「電動化＝BEV」電動車にはHEV・PHEV・BEV・FCEVが含まれる。日本の政策で言う「電動車100%」はHEVを含む（→ 各地域の政策と市場）

用語メモ

  • BEV：電池のみで走る純電気自動車。狭義の「EV」
  • HEV：エンジンとモーターを併用。外部充電しない
  • PHEV：外部充電できるハイブリッド。短距離はEV、長距離はエンジン
  • FCEV：燃料電池車。水素で発電して走る（→ 水素・アンモニア）
  • eAxle：モーター＋インバーター＋減速機の一体ユニット
  • インバーター：直流を交流に変換し、モーターの回転を制御する装置
  • BMS：Battery Management System。各セルの電圧・温度を監視し、充放電を管理する
  • 回生ブレーキ：減速時にモーターを発電機として使い、運動エネルギーを電気として回収する仕組み
  • ギガキャスト：大型アルミダイカストで車体の一部を一体成形する手法
  • SDV：Software Defined Vehicle。ソフトで機能が決まる車
  • OTA：Over The Air。無線経由でのソフトウェア更新
  • Tier1／Tier2：完成車メーカーに直接納入する一次下請け／その下の二次下請け
  • LCA：原料採掘から廃棄まで通算でCO2を評価する手法
