# AIとロボットの結合（基盤モデル・模倣学習・ヒューマノイド）

**このノートで分かること**：ロボットの「脳」がプログラムから学習モデルに置き換わりつつある話の中身と、
**デモ動画と実運用の間に何段の壁があるか**。

結論を先に書く。**動きの生成は確かに変わった。しかし2026年時点で、
基盤モデルで動くロボットが人の代わりに稼いでいる現場はまだ極めて限られる**。
ヒューマノイドは誇張報道が最も多い領域なので、このノートは一貫して「デモ」と「実運用」を分けて書く。

## 1. 何が変わったのか：手書きの手順から、学習した動作へ

```
【従来型（〜2020年代前半）】
 人が座標を教える ─▶ 決まった順に再生 ─▶ 想定外が来たら止まる
 ├ 強み：速い、正確、再現性100%、責任の所在が明確
 └ 弱み：教えていないことは一切できない。段取り替えのたびに再教示

【基盤モデル型（2023年〜）】
 カメラ画像＋言葉の指示 ─▶ 学習済みモデル ─▶ 関節の動きを直接出力
 ├ 強み：見たことのない物・位置でもそれなりに動く。言葉で指示できる
 └ 弱み：遅い、確率的、失敗の理由が説明できない、同じ結果を保証できない
```

この2つは対立ではなく**役割分担**になりつつある。
精度と安全が要る動きは従来の制御、状況判断と柔軟性が要る部分がAI、という組み合わせが実装の主流。

## 2. VLA（Vision-Language-Action）とは

**VLA**＝画像（Vision）と言葉（Language）を入力に、ロボットの動作（Action）を出力する
単一のニューラルネットワーク。言語モデルの仕組みを、出力が文章ではなく関節角になるよう作り変えたもの。

```
  カメラ画像 ──┐
               ├──▶ [ 大規模モデル ] ──▶ 関節の目標値の列（数十Hz）
  「赤い缶を取って」┘        ↑
                        ネット上の画像・言語で事前学習
                        ＋ ロボットの操作データで追加学習
```

| モデル | 開発元 | 位置づけ（2026年時点） |
| --- | --- | --- |
| **π0 / π0.5 系** | Physical Intelligence（米） | 汎用操作の代表格。複数の機体で同じモデルを動かす方向 |
| **Helix** | Figure AI（米） | 自社ヒューマノイド向け。上半身の器用な操作が売り |
| **Gemini Robotics 系** | Google DeepMind | 2026年7月に次世代版を公開。ロボット上でローカル実行でき、数時間のデータで別形状の機体に適応できると発表 |
| **GR00T 系** | NVIDIA | ヒューマノイド向けの共通基盤＋シミュレータ（Isaac）をセットで提供 |
| **RT-2 / OpenVLA ほか** | Google／研究コミュニティ | 研究の共通ベースライン |

> 注意：ここに並ぶ性能は**論文とデモ動画の数字**であり、工場の稼働率や不良率で検証されたものではない。
> 「成功率85%」は研究では良い数字だが、**産業では7台に1台が失敗する不良設備**を意味する。
> このギャップが、実装が進まない一番の理由になっている。

## 3. どうやって学習させるか：3つのルート

| 手法 | やり方 | 長所 | 短所 | 2026年の位置 |
| --- | --- | --- | --- | --- |
| **模倣学習** | 人が遠隔操作（テレオペ）した動きを大量に記録し、真似させる | 現実のデータなので実機で動きやすい | **データ収集に人手と時間がかかる**。1タスク数百〜数千回 | VLAの主流。π・Helix・Gemini・GR00T はいずれもここが土台 |
| **シミュレーション学習** | 物理シミュレータ上で数億回試行させる | 安く速く大量に試せる | **sim2realギャップ**（摩擦・変形・光の違いで実機では動かない） | 移動・歩行・全身制御で有効。接触の多い手作業は苦手 |
| **強化学習** | 報酬を与えて試行錯誤で覚えさせる | 人が教えられない動きも獲得できる | 報酬設計が難しく、実機では危険・低速 | 2026年に模倣学習の後段として組み合わせる流れが強まる |

実務では **「シミュレーションで大枠 → 模倣学習で現実に寄せる → 強化学習で仕上げる」** の3段構えが定石化しつつある。

## 4. 本当のボトルネックはデータ

言語モデルにはインターネットという既製のデータがあった。**ロボットには、それが無い**。

```
  言語モデル ： 人類が書いたテキスト 数兆トークン   → 無料で既にある
  画像モデル ： ネット上の画像 数十億枚             → 無料で既にある
  ロボット   ： 「掴んだ」「置いた」の身体データ    → ★誰も持っていない★
                                                     人が1回ずつ操作して作るしかない
```

このため各社が採る手段は次の4つに集約される。

1. **テレオペ工場**：人がVRコントローラで操作し、ひたすらデータを取る（人件費がそのままデータ原価になる）
2. **実運用からの回収**：すでに現場で動いているロボットからログを集める（先に配備した側が有利）
3. **シミュレーション生成**：合成データで水増しする
4. **共同でデータを持ち寄る**：日本では2025年に**AIロボット協会**が設立され、
   トヨタ自動車、Telexistence などが参画して、ロボットのデータ基盤とVLAの共同構築を進めている

> ここが日本の勝負どころ。基盤モデルそのもので米中に勝つのは難しいが、
> **製造・物流・小売の現場という「データの井戸」は日本にある**。
> [生成AI](../01_生成AI/README.md) の構図と同じで、モデルではなくデータとアプリ側に勝ち筋が寄る。

## 5. ヒューマノイドの現在地：デモと実運用を分ける

報道で最も混同されるのがここ。成熟度を5段階に分けて読むと誤解が減る。

```
  ⑤ 量産・外販         ： 第三者が買って現場で使い、採算が合っている
     ▲                    → 2026年時点で、汎用ヒューマノイドではほぼ存在しない
  ④ 限定タスクの実運用  ： 特定作業に絞って、社外の現場で日常稼働
     ▲                    → 一部（倉庫の搬送、コンビニの陳列など）で到達
  ③ 社内・パイロット稼働 ： 自社工場や協力先で試験稼働。人の監視付き
     ▲                    → Tesla、BMW×Figure などがここ
  ② 制御されたデモ      ： 展示会・動画。環境と手順を整えた一発撮り
     ▲                    → 報道の大半はここ
  ① 研究・論文
```

| 主体 | 公表されている内容 | どの段階か（筆者整理） |
| --- | --- | --- |
| Unitree（中国） | 2025年に約5,500台出荷、2026年は約2万台の出荷目標。累計1.8万台超の二足歩行機を製造と報じられる | 出荷台数は多いが、買い手の多くは**研究機関・開発者・デモ用途**。⑤とは言い難い |
| Figure AI（米） | BMW工場での稼働実績を公表。評価額390億ドル規模と報じられる | ③〜④。作業範囲は限定的 |
| Tesla（Optimus） | 2026年に社内展開1,000〜1,200台規模と報じられる。外部販売は2026年後半以降を目標 | ③。2025年Q4決算説明会で経営陣自身が「まだ有用な作業をしているロボットはない」と述べたと報じられる |
| Agility Robotics（米） | GXOの物流拠点でトート搬送の実運用実績 | ④。**タスクを1つに絞ったから成立した**典型 |
| 中国全体 | 2025年に世界のヒューマノイド出荷の約9割、2026年上期に世界で2.2万台超（中国のみで3万台超との主張もある） | 統計の定義が揺れており、**「ヒューマノイド」に車輪型や上半身のみを含む場合がある** |
| 川崎重工（日） | Kaleido シリーズを開発、イベントで公開 | ②〜③ |
| トヨタ自動車（日） | 産業用ヒューマノイドに注力を表明、自社工場からの実用化を志向 | ②〜③ |
| Telexistence（日） | コンビニの飲料補充ロボットをファミリーマート300店舗規模で実稼働と発表 | ④。**人型ではなく単腕＋昇降**という割り切りで成立させた例 |

> 読み方のコツ：**「何台作ったか」ではなく「誰が何の業務に使い、いくら払っているか」を見る**。
> 出荷台数が伸びていても、買い手が研究室と同業他社なら、それは市場ではなく開発投資である。

## 6. なぜ人型なのか、そして人型でなくてよい理由

**人型を推す論理**
- 世界（階段、ドアノブ、什器、工具）が人間の寸法で作られている。**環境を変えずに入れる**
- 1台で複数の仕事をさせられれば、稼働時間が伸びて回収年数が短くなる（[02_なぜ普及しないのか](02_なぜロボットは普及しないのか.md) の算数）
- 学習データを人の動作から取りやすい

**人型を疑う論理**
- 脚は高価で壊れやすく、転倒リスクがある。**床が平らなら車輪のほうが安く速い**
- 五指ハンドは高価で壊れやすい。**吸着パッド1個で済む作業が現場の大半**
- 汎用性は「どの仕事も70点」を意味しがちで、専用機の100点に採算で負ける
- 人と同じ空間で動く以上、安全規格（ISO 10218、ISO/TS 15066 など）の壁が重い

実際に④段階へ到達した事例（Agility、Telexistence）は、いずれも**人型を諦めて形をタスクに合わせた**ものである。
汎用ヒューマノイドが勝つとすれば、それは「1台が10種類の仕事をこなし、
専用機10台より安くなった」瞬間だが、2026年時点でその損益分岐は誰も示せていない。

## 7. 報道を読むときのチェックリスト

| 見るポイント | 誇張報道にありがちな書き方 | 実運用を示す書き方 |
| --- | --- | --- |
| 環境 | 「工場で稼働」 | 「◯◯社の△△工程で、×時間/日、□ヶ月連続稼働」 |
| 速度 | 速度に触れない／早送り動画 | 「人の◯%の速度」「タクトタイム◯秒」 |
| 成功率 | 「できるようになった」 | 「成功率◯%、失敗時は人が介入」 |
| 自律性 | 「自律的に」 | 遠隔操作の有無、監視者の人数を明記 |
| 台数 | 「◯万台出荷」 | 誰に、どの用途で、リピート受注はあるか |
| 経済性 | 価格に触れない | 導入総額と回収年数を示している |

> 特に注意すべきは**遠隔操作の有無**。テレオペ（人が遠隔で操作）を挟んだ映像が
> 「自律動作」として流通することがあり、これは技術的には全く別の段階である。

## 8. 産業構造としてどう見るか

AIの参入で、ロボット業界の付加価値の置き場所が動き始めている。

```
【従来】 本体メーカーが垂直統合（機構＋制御＋ソフト＋サービス）
         ファナック・安川・ABB・KUKA が一括で提供し、ここに利益が乗っていた

【これから？】 レイヤーが割れる可能性
   基盤モデル層 ： Google／PI／NVIDIA／中国勢     ← 新しい利益プール
   ───────────────────────────────────
   本体・制御層 ： ファナック・安川・UR・中国勢    ← コモディティ化の圧力
   ───────────────────────────────────
   部品層       ： ナブテスコ・ハーモニック       ← 需要は増えるが価格圧力も来る
```

半導体で起きた「設計と製造の分離」に似た分解が起きるのか、
それともロボットは**現場ごとのすり合わせが重すぎて垂直統合が残る**のか。
2026年時点では決着していない。これがこの業界の最大の論点である。

## 用語メモ

- **フィジカルAI／具身智能（Embodied AI）**：身体を持ち、物理世界で行動するAIの総称。中国では「具身智能」と呼ばれ国策用語になっている
- **VLA（Vision-Language-Action）**：画像と言語から直接ロボットの動作を出力するモデル
- **模倣学習（Imitation Learning）**：人の実演データを教師に動作を学ぶ方法。行動クローニングとも
- **テレオペレーション**：人が遠隔で操作すること。データ収集手段であり、実運用時の「介入」手段でもある
- **sim2real ギャップ**：シミュレータで学んだ動作が実機で通用しない現象
- **Isaac Sim / MuJoCo**：ロボット学習で広く使われる物理シミュレータ
- **エンボディメント転移**：ある機体で学んだモデルを別形状の機体に移すこと。基盤モデル化の核心
- **ISO 10218 / ISO/TS 15066**：産業用ロボットと協働運転の安全規格。人型が現場に入る際の法的な関門
