なぜロボットは普及しないのか（導入の経済学）

注目テーマロボット
あこのページの単語集用語に触れると意味を確認できます7語
ティーチングティーチングペンダント段取り替えSIer（システムインテグレータ）リスクアセスメントロボットフレンドリー回収年数（ペイバック）

このノートで分かること：ロボットが「技術的にできる」のに現場に入らない理由を、
本体価格ではなく総コストと投資回収年数の算数で説明する。

結論を先に書く。ロボットが普及しないのではなく、採算が合う現場から順に入っているだけ。
そして採算を壊している最大の要因は本体価格ではなく、ティーチング（動きを教える作業）と段取り替えである。

1. まず事実：日本はロボット大国だが、偏っている

指標 数値 年・出典
日本の産業用ロボット年間導入44,500台（前年比▲4%）、世界2位2024年、IFR World Robotics 2025
日本の稼働台数（ストック）450,500台（＋3%）2024年、IFR
日本のロボット密度従業員1万人あたり446台（世界4位）2024年、IFR
日本のサービスロボット市場2025年 約2.6兆円 → 2035年 約5.0兆円経済産業省の見通し
うち「現場作業」分野2025年 約2.0兆円（前年比＋12.4%）、市場の約7割富士経済の推計（2025年公表）

つまり自動車と電機の大量生産ラインには入り切っている一方で、
中小製造業・サービス業・農業といった領域はほぼ手つかず、という二極化した状態にある。

2. ロボット導入費の正体：本体は氷山の一角

見積もりを取ったことがない人が最も誤解するのがここ。本体価格は総額の3〜4割しかない。

       見えている部分
    ┌────────────────┐
    │  ロボット本体   │  300万〜800万円   ← ここしか比較されない
════╪════════════════╪══════════════════════════════════
    │  ハンド・治具   │  100万〜400万円   （掴む物ごとに作る）
    │  周辺装置       │  100万〜500万円   （供給機、コンベア、架台）
    │  安全対策       │   50万〜200万円   （柵、ライトカーテン、リスクアセスメント）
    │  システム設計    │  200万〜600万円   （SIerの設計・工事・立ち上げ）
    │  ティーチング    │   50万〜300万円   （動きを教える。段取り替えのたびに再発生）
    │  保守・教育      │  年10〜20万円     （予備品、年次点検、社内教育）
    └────────────────┘
       見えない部分（ここが効く）

1台のロボットを本当に動かすまでに、本体価格の2.5〜3倍が相場とされる。
300万円のアームを入れるつもりが総額900万円になる、という話が普通に起きる。

3. ティーチングという最大のコスト

ティーチング＝ロボットに「どの座標にどの姿勢で、どの速度で行くか」を1点ずつ教える作業。

方式 やり方 所要時間の目安 弱点
オンラインティーチング実機を手元のペンダント（操作器）で動かし、位置を1点ずつ記録単純作業で1〜3日、複雑なら1〜2週間その間ラインを止める。熟練者が要る
オフラインティーチングPC上の3Dモデルで動作を作り、実機に流し込む設計は数日。ただし現物との誤差合わせ（キャリブレーション）が必要3D CADデータが揃っていないと使えない
ダイレクトティーチング人が腕を掴んで動かして覚えさせる数時間精度が出ない。協働ロボット向け
AIによる自動生成画像や指示から動作を作る研究〜一部実用精度と再現性の保証がまだ難しい（03_AIとロボットの結合）

なぜここが致命的か：ティーチングは一度で終わらない。
製品が変わるたび、治具がずれるたび、ワークの置き方が変わるたびにやり直しになる。
導入費用ではなく運用費用として毎年のしかかるのが、他の設備投資と決定的に違う点。

さらに、この作業ができる人材（ロボットSIer＝システムインテグレータ）が全国的に不足している。
中小企業が独力でロボットを導入するのは困難、というのが経済産業省の資料でも繰り返される認識である。

4. 多品種少量という壁

ロボットは「同じことを、同じ場所で、何度も」が得意な機械である。
逆に言えば、品種が多い・数量が少ない現場では、ティーチングのコストを回収できない。

    多 ┤ ┌────────────┬────────────┐
 品  │ │  ここが本丸  │  自動車ライン │
 種  │ │ （まだ空白） │  一番ロボが  │
 数  │ │ AI・汎用ハンド│  入っている  │
    │ │  待ちの領域  │              │
    ┼─┼────────────┼────────────┤
    │ │  人のほうが  │  専用機のほう │
    │ │  安い領域    │  が安い領域   │
    少 ┤ └────────────┴────────────┘
       └──少──────生産数量──────多──┘
  • 右上（多品種×大量）：自動車のボディ溶接など。車種違いを1台のロボットで吸収できるからロボットが勝つ
  • 右下（少品種×大量）：専用機（カムやリンクで動く機械）のほうが速くて安い。ロボットは負ける
  • 左下（少品種×少量）：段取りする人件費のほうが安い。ロボットは入らない
  • 左上（多品種×少量）：中小製造業の大半がここ。ティーチングが重すぎて入らない ＝ 最大の未開拓市場

5. 投資回収年数の算数

現場で実際に使われる判断式は驚くほど単純である。

  回収年数 ＝ 総投資額 ÷ （年間の人件費削減額 ＋ 品質・稼働改善額 − 年間保守費）

  例）総投資 900万円、夜勤1名（年間約450万円）を置き換え、保守 年20万円
      900 ÷ （450 − 20） ≒ 2.1年   → 多くの企業の社内基準（3年以内）を満たす

  例）総投資 900万円、パート0.5名分（年間約110万円）の削減、保守 年20万円
      900 ÷ （110 − 20） ＝ 10年    → 設備の寿命と同じ。誰も稟議を通さない

ここから導かれる実務的な結論は3つ。

  1. 1台で何人分を置き換えられるかが全て。0.5人分の削減では絶対に通らない
  2. 稼働時間が長いほど有利。24時間動く物流倉庫や工場が先に自動化されるのは必然
  3. 人件費が高い国ほど有利。日本の賃金が伸び悩んだ2010年代に導入が鈍ったのは、
    技術の問題ではなく分母が小さくならず分子が大きくならなかったから
分野 年間稼働時間の目安 置き換え人数 回収年数の実感値
自動車溶接ライン4,000〜6,000時間1〜2名／台1〜3年
物流倉庫の棚搬送AMR3,000〜6,000時間群で3〜10名分2.5〜4年（各社導入事例、2026年）
飲食の配膳2,000〜3,000時間0.3〜0.7名分3〜5年（人件費高騰で改善中）
介護の移乗支援数百〜1,000時間0.2名分程度補助金なしでは成立しにくい
農業の収穫年30〜60日（季節限定）繁忙期のみ稼働日数が足りず最も厳しい

重要：農業ロボットが伸び悩む本質は技術ではなく稼働日数。
年間2ヶ月しか使わない機械は、どれだけ優秀でも減価償却を吸収できない。

6. 人件費との比較は「国ごと」に違う

国・地域 製造業の人件費水準 ロボット密度（2024年、IFR） 構図
韓国高い1,000台超／万人（世界1位）高賃金＋電機・半導体の大量生産で合いやすい
中国上昇中500台超／万人（日本を上回った、2023年以降）賃金上昇と国産ロボットの低価格化が同時に進行
日本中位446台／万人（世界4位）既存ラインは飽和、中小は未導入
米国高い300台前後／万人人手不足と高賃金で物流の自動化が先行

中国が急速にロボット密度を上げたのは、国産メーカーが価格を半分近くに落としたことが大きい。
つまり「ロボットが普及するか」は技術の完成度よりも価格と賃金の相対関係で決まる。

7. 解き方1：ロボットを変えず、環境を変える

日本の政策が採った方向がこれ。ロボットを賢くするより、現場をロボットに合わせるほうが安いという発想。

  • 経済産業省の「ロボットフレンドリーな環境」施策（ロボフレ事業）。
    施設管理・食品・小売・物流の4分野を中心に、ロボットが通れる通路幅、
    エレベーターとの通信仕様、什器の形状、商品の包装形態などを標準化する
  • 具体例：ロボットが自分でエレベーターを呼べる通信規格、
    掴みやすい形状のトレー、段差のない搬送経路、バーコードの貼付位置の統一
  【従来の発想】                    【ロボフレの発想】
  現場はそのまま                    現場を少し変える
        ↓                                 ↓
  ロボットを超高性能に              普通のロボットで足りる
        ↓                                 ↓
  1台3,000万円、開発3年             1台300万円、導入3ヶ月

8. 解き方2：補助金で分子を小さくする

制度 内容 補助率の目安
中小企業省力化投資補助金「カタログ注文型」（登録済み汎用製品から選ぶ）と「一般型」（個別のシステム構築）の2本立て。清掃ロボットではビルメンテナンス業・警備業などが対象業種に追加された1/2 前後
介護テクノロジー導入支援事業（厚労省・都道府県実施）介護ロボット・ICTの導入費を補助。重点分野は9分野16項目（2025年4月改訂運用）1/2〜3/4
ものづくり補助金設備投資全般。SIer費用も対象になりうる1/2〜2/3
各都道府県の独自制度導入診断、実証支援、専門家派遣制度による

補助金の本質は「回収年数を社内基準の内側に押し込む」こと。
3/4補助なら、回収10年の案件が2.5年になる。介護分野がほぼ補助金で動いているのはこのためである。

9. まとめ：普及の条件は4つ

ロボットが入るのは、次の4つが同時に成立した現場だけ。
① 作業が繰り返しである ② 稼働時間が長い ③ 1台で1人分以上を置き換える ④ 環境を変える権限が現場にある。
④が意外な盲点で、テナントビルや他社の倉庫では床も什器も動かせず、それだけで導入が止まる。

裏を返すと、AIが解こうとしているのは①（繰り返しでなくても動ける）であり、
ロボフレ政策が解こうとしているのは④である。分野別の実際の成否は
04_分野別の実装状況 にまとめた。

用語メモ

  • ティーチング：ロボットに動作を教える作業。教示。オンライン／オフライン／ダイレクトの3方式
  • ティーチングペンダント：ロボットを手動で動かし位置を記録する操作器
  • 段取り替え：生産品種を切り替える作業。ロボットでは治具交換＋プログラム切替を伴う
  • SIer（システムインテグレータ）：ロボット本体・周辺機器・安全対策を組み合わせて動く設備に仕立てる事業者。日本ロボットシステムインテグレータ協会（JARSIA）がある
  • リスクアセスメント：導入前に危険源を洗い出し安全方策を決める法定手順。労働安全衛生規則で産業用ロボットには柵などの隔離が原則求められる（80W以下等の例外あり）
  • ロボットフレンドリー：ロボットに合わせて施設・什器・業務フローを作り替える考え方。経産省の政策用語
  • 回収年数（ペイバック）：投資額を年間の削減額で割った年数。3年以内が製造業の一般的な社内基準
