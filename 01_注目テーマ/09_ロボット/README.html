ロボット

学習済み更新 2026-09-19注目テーマ
あこのページの単語集用語に触れると意味を確認できます5語
基幹部品の内製または安定調達導入を成立させる力（SIer網）稼働時間を積める用途を選ぶ力データの蓄積保守網

ロボット産業を一言でいえば、「作業を変えられる汎用機械を売る産業」。
専用機より遅くて高いのに使われるのは、作り直さずに別の仕事をさせられるからに尽きる。
そして普及の可否を決めているのは技術の完成度ではなく、稼働時間 × 置き換え人数で決まる投資回収年数である。

このフォルダは注目テーマとしてのロボット全般（サービスロボット、ヒューマノイド、AIとの結合、
物流・飲食・介護・清掃・農業への実装）を扱う。
工場の中で使う産業用ロボット（FA）の市場・企業・収益構造は
産業用ロボット に委ねる。

1. 業界の定義・範囲

ISO 8373（JIS B 0134）の定義をかみ砕くと、ロボットは「2軸以上の関節を持ち、プログラムで動きを書き換えられ、自動で動く機械」。
「作業を変えられる」ことが定義の核で、動きが固定された専用機は含まない。

含む 含まない（隣接）
産業用ロボット（詳細は別フォルダへ委譲）サーボ・PLC等の制御機器単体 → FA・制御機器
協働ロボット、サービスロボット動きが固定された専用自動機 → 工作機械
物流・清掃・配膳・警備・介護・農業ロボット空を飛ぶ無人機 → ドローン
ヒューマノイド、四足歩行ロボット公道を走る車両の自動化 → 自動運転
ロボット向け基盤モデル（VLA）身体を持たないAI全般 → 生成AI
減速機・アクチュエータ等の基幹部品ベアリング単体 → ベアリング

境界が曖昧になっている場所が2つある。
①AIとの境界（ロボットの価値がハードからモデルへ移りつつある）、
②自動運転との境界（屋外配送ロボットは両方の技術と規制にまたがる）。

5. 収益モデル・コスト構造

事業 何で儲けるか コストの中心 利益の出方
本体メーカー本体販売＋保守部品＋サービス部品調達（減速機・モータ）、開発費保守と部品が安定収益。本体は景気循環で振れる
部品（減速機）部品販売設備投資と歩留まり。装置産業寡占なので利益率は高いが、稼働率が落ちると固定費で赤字化
SIer設計・据付・教示の受託人件費（ほぼ全部）人月商売。規模の経済が効きにくく利益率は低め
サービスロボット販売・RaaS販売またはサブスク（月額）本体原価、保守・駆けつけ対応RaaS（月額）は導入の心理的障壁を下げるが、回収が長期化する
基盤モデルライセンス／API学習計算コストとデータ収集まだ収益化の前段階

全体に共通するクセ：設備投資財なので景気と設備投資サイクルに強く連動する。
かつ顧客の判断基準が回収年数に固定されているため、値下げより「人件費上昇」のほうが需要を動かす。

6. 競争要因（KSF）と参入障壁

KSF

  1. 基幹部品の内製または安定調達：減速機とモータの確保が量産のボトルネック
  2. 導入を成立させる力（SIer網）：本体が良くても、現場で動かせなければ売れない
  3. 稼働時間を積める用途を選ぶ力：技術より用途選定が成否を決める（04_分野別の実装状況）
  4. データの蓄積：基盤モデル時代は、現場で動いている台数がそのまま学習データになる
  5. 保守網：止まった瞬間に顧客の生産が止まるため、駆けつけ体制が乗り換え障壁になる

参入障壁

  • 部品（減速機は設計図があっても作れず、材料と加工の蓄積が要る）、安全規格と認証、
    実績（止まらない証明がないと産業ユーザーは買わない）、保守網の全国展開。
  • 逆にサービスロボットは障壁が低い。中国メーカーが日本の飲食・施設で多数を占めているのはこのため。

8. 最近のトピック

詳細は 05_直近トピック_2026 に出典URL付きでまとめた。要点は5つ。

  1. 産業用の主戦場は中国に移った。日本の年間導入は44,500台（2024年、IFR）で微減、一方ファナックは中国向けが牽引して増益
  2. ヒューマノイドは台数だけが先行。Unitreeは2026年に2万台出荷目標、Teslaは社内1,000台級で外販ゼロ。
    経営陣自身が「まだ有用な作業をしているロボットはない」と述べたと報じられる（2025年Q4）
  3. VLA基盤モデルが実装段階へ。Gemini Robotics 2（2026年7月）はロボット上でローカル実行し、数時間のデータで別機体に適応すると発表
  4. 日本の政策はロボットフレンドリー化（現場を標準化する方向）で固まり、補助金で回収年数を圧縮する設計になっている
  5. 実運用に到達したのは「運ぶ」仕事だけ。物流AMRは回収2.5〜4年、配膳は2,100店舗・3,000台規模。
    掴む・調理する・人に触れる仕事はまだ経済的に成立していない
