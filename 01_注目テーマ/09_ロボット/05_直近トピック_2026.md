## 1. 産業用ロボットは中国主導で回復、ただし国内は弱い

| 指標 | 数値 | 年・出典 |
| --- | --- | --- |
| 世界の産業用ロボット年間導入 | 過去10年で約2倍に拡大 | IFR World Robotics 2025 |
| 日本の年間導入 | 44,500台（前年比▲4%）、世界2位 | 2024年、IFR |
| 日本の稼働ストック | 450,500台（＋3%） | 2024年、IFR |
| 日本のロボット密度 | 446台／従業員1万人（世界4位） | 2024年、IFR |
| 密度の上位 | 韓国・シンガポール・ドイツが上位 | 2024年、IFR |

- 中国は既に日本・ドイツを密度で上回っており、**世界最大の市場かつ最大の生産国**という二重の立場を固めた
- ファナックの2026年3月期は**中国向けロボット売上が前年同期比で大きく伸びた**一方、欧州・日本は低調と報じられる。
  通期の連結純利益は前期比で増益、営業利益率は20%台を維持
- 安川電機は2026年2月期で売上約5,400億円・営業利益率は1桁台後半と報じられ、**同じロボット比率でも収益性に差**が出た
- 構図：需要の中心が日本国内から中国・米国へ移り、
  **日本メーカーは中国市場での価格競争と、中国メーカーの海外進出の両方に晒されている**

## 2. ヒューマノイドは「出荷台数」が急増、しかし用途はまだ薄い

- Unitree（中国）は2025年に約5,500台を出荷し、**2026年の出荷目標を約2万台**に設定したと報じられる。
  累計で1.8万台超の二足歩行機を製造したとの発表もある
- 2026年上期の世界出荷は2.2万台超、中国のみで3万台超という主張もあり、**集計の定義が揃っていない**
- 中国は2025年に世界のヒューマノイド出荷の約9割を占めたとされる
- Tesla の Optimus は2026年に社内展開1,000〜1,200台規模と報じられ、**外部販売はまだゼロ**。
  経営陣自身が2025年Q4の決算説明会で「まだ有用な作業をしているロボットはない」と述べたと報じられている
- Figure AI は BMW 工場での稼働実績を公表し、評価額390億ドル規模と報じられる

> **読み方の注意**：出荷台数の大半は研究機関・開発者・デモ用途への販売とみられ、
> 「工場で人の代わりに働いて稼いでいる台数」とは意味が違う。
> デモ（②）、社内パイロット（③）、限定実運用（④）、量産外販（⑤）の段階区分は
> [03_AIとロボットの結合](03_AIとロボットの結合.md) を参照。

## 3. ロボット基盤モデル（VLA）が実装フェーズに入った

- Google DeepMind は2026年7月に **Gemini Robotics 2** を公開。
  ロボット上でローカル実行できる効率的なVLAで、**数時間のデータで異なる形状の機体に適応**でき、
  ヒューマノイドの全身制御まで扱えるとされる
- Physical Intelligence の π 系、Figure の Helix、NVIDIA の GR00T 系はいずれも**模倣学習が土台**
- 2026年の変化は、模倣学習に**強化学習を本格的に組み合わせる**流れが定着したこと
- 日本では2025年に **AIロボット協会** が設立され、トヨタ自動車、Telexistence などが参画。
  VLAモデルとロボットデータのエコシステム構築を進めている

```
  【2023】画像→動作の研究モデル
     ↓
  【2024-25】VLAとして製品化開始。1機体1モデル
     ↓
  【2026】・ロボット上でローカル実行（通信なしで動く）
          ・数時間のデータで別機体へ転移
          ・模倣学習＋強化学習の併用が定番化
     ↓
  【残る課題】成功率の保証、失敗の説明可能性、データの量
```

## 4. 日本の政策は「環境をロボットに合わせる」方向で固まった

- 経済産業省は2026年5月に**AIロボティクスの社会実装に向けた政府の方向性を改訂**
- 中核は変わらず「**ロボットフレンドリーな環境**」。
  ロボットに合わせて施設・什器・業務フローを変え、普通のロボットで足りる状態を作る
- 施設管理・食品分野などでロボフレ事業（革新的ロボット研究開発等基盤構築事業）の成果が取りまとめられた
- **中小企業省力化投資補助金**は「カタログ注文型」と「一般型」の2本立てで運用。
  清掃ロボットの対象業種にビルメンテナンス業・警備業などが追加された
- 介護分野では、厚労省の**重点分野が9分野16項目**に拡大（2025年4月から運用）。
  介護テクノロジー導入支援事業の補助率は**1/2〜3/4**、都道府県が実施主体

| 政策 | 狙い | 効くところ |
| --- | --- | --- |
| ロボットフレンドリー化 | 現場側を標準化する | 導入設計費とティーチング費の削減 |
| 省力化投資補助金（カタログ型） | 選ぶ手間をなくす | 中小企業の意思決定の速さ |
| 介護テクノロジー導入支援 | 回収年数の圧縮 | 補助なしでは成立しない分野の下支え |
| SIer育成・連携促進 | 人材ボトルネックの解消 | 地域の中小製造業 |

## 5. 現場側：物流と飲食は普及期、介護と農業は補助金・実証段階

- **物流**：棚搬送型AMRで歩行時間80〜90%削減、人件費30〜40%減、**投資回収2.5〜4年**という導入事例が
  複数報じられている（2026年）。食品メーカーで年920万円の経費削減事例も
- **飲食**：すかいらーくグループは2022年に約2,100店舗・約3,000台を展開済み。
  ガストでランチピーク回転率＋約7.5%、片付け時間▲約35%、歩行数▲約42%
- **小売**：Telexistence の飲料補充ロボットがファミリーマート300店舗規模で実稼働（同社発表）
- **農業**：クボタが2024年に無人自動運転コンバインを投入。遠隔監視による完全無人運転農機の実用化を
  2026年をめどに目指すとされる。ただし**収穫ロボットは稼働日数の短さが依然ネック**
- **サービスロボット市場**：経産省の見通しで2025年約2.6兆円→2035年約5.0兆円。
  富士経済の推計では現場作業分野が2025年に約2.0兆円（＋12.4%）で市場の約7割

## 6. 部品：減速機メーカーがヒューマノイドに賭け始めた

- 精密減速機はハーモニック・ドライブ・システムズとナブテスコで**世界シェア約95%**とされる
- ナブテスコは2024〜26年度の設備投資計画275億円のうち、**約100億円をヒューマノイド向けに配分**すると報じられる
- 論点：ヒューマノイド1台は関節20〜40個で、6軸アームの数倍の減速機を使う。
  **需要が本当に来れば部品メーカーが最大の勝者**になるが、
  中国勢が性能を落とした安価な関節モジュールを内製し始めており、**単価下落と国産化の両面の圧力**がある

## 7. 全体の構図

1. **産業用ロボットの主戦場は中国に移った**。日本メーカーは中国での成長と、中国メーカーの逆進出に同時に直面している
2. **ヒューマノイドは台数だけが先行している**。2026年時点で汎用人型の量産外販・採算稼働はほぼ存在せず、
   実運用に到達したのは「人型を諦めてタスクに形を合わせた」ロボット（倉庫の搬送、コンビニの陳列）である
3. **AI側は転移可能性で前進した**。1機体1モデルから、数時間のデータで別機体に移せる段階へ。残る壁はデータ量と成功率の保証
4. **日本の政策はロボットを賢くする方向ではなく、現場を標準化する方向**に張っている。合理的だが成果が出るのに時間がかかる
5. **経済的な結論は変わっていない**。導入の可否は稼働時間×置き換え人数で決まり、
   AIが解こうとしているのは「繰り返しでなくても動ける」という1条件だけである

## 用語メモ

- **IFR（国際ロボット連盟）**：産業用ロボットの世界統計 World Robotics を毎年刊行する業界団体。この分野の基準統計
- **ロボット密度**：従業員1万人あたりの稼働ロボット台数。国際比較の標準指標
- **AIロボット協会**：2025年設立の日本の業界団体。ロボットデータ基盤とVLAの共同構築を掲げる
- **カタログ注文型**：中小企業省力化投資補助金の類型。登録済みの汎用製品から選ぶだけで申請できる簡易型
- **具身智能**：中国での「Embodied AI（身体を持つAI）」の呼称。国策キーワードになっている
