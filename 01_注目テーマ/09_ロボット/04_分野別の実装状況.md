# 分野別の実装状況（物流・飲食・介護・清掃・農業・小売）

**このノートで分かること**：工場の外でロボットが実際に使われている6分野について、
**どこで採算が合い、どこで合わなかったか**を分野ごとに分解する。

結論を先に書く。**採算が合ったのは「運ぶ」仕事だけ**である。
掴む・調理する・人に触れる、といった仕事はまだ経済的に成立していない。
運搬は距離と時間が測れるため削減効果が計算でき、環境の制約も床と通路だけで済むからだ。

## 1. 採算が合う条件を一般化する

```
   ┌───────────────────────────────────────────┐
   │ ① 作業が「運ぶ・回る・繰り返す」に分解できる      │ → 物流・清掃・配膳は◎
   │ ② 対象物が定型（形・重さ・置き方が揃う）         │ → 農業・介護は×
   │ ③ 年間稼働時間が長い                            │ → 農業は季節限定で×
   │ ④ 環境を改造する権限が自社にある                │ → テナント・他社倉庫は×
   │ ⑤ 失敗しても人が死なない                        │ → 介護・医療は規制が重い
   └───────────────────────────────────────────┘
        5つ全部〇 → 実運用済み    3つ以下 → 実証止まり
```

この5条件を各分野に当てはめたのが、次の一覧である（詳細は以降の各章）。

| 分野 | ①分解 | ②定型 | ③稼働 | ④環境 | ⑤安全 | 実装段階（2026年） |
| --- | --- | --- | --- | --- | --- | --- |
| 物流（搬送） | ◎ | ○ | ◎ | ○ | ○ | **量産・普及期** |
| 物流（ピッキング） | ○ | △ | ◎ | ○ | ○ | 導入拡大中 |
| 飲食（配膳） | ◎ | ○ | ○ | ○ | ○ | **普及期（チェーンに限る）** |
| 飲食（調理） | △ | △ | ○ | △ | ○ | 一部業態のみ |
| 清掃 | ◎ | ◎ | ○ | △ | ○ | 普及期 |
| 警備 | ○ | ◎ | ◎ | △ | ○ | 導入拡大中 |
| 小売（陳列） | ○ | ○ | ○ | ○ | ○ | 限定実運用 |

## 2. 物流：最も早く採算が合った領域

**なぜ成立したか**：倉庫は①自社の建物で②床が平らで③24時間動き④歩行距離が長く、
⑤人が歩き回る時間が全体作業時間の5〜6割を占めていた。削減余地が数字で見えた。

| 方式 | 仕組み | 効果 | 回収年数 |
| --- | --- | --- | --- |
| **棚搬送型（GTP）** | ロボットが棚ごと作業者の前まで運ぶ（Amazon Kiva方式） | 歩行時間 80〜90%削減、人件費30〜40%減とされる | 2.5〜4年（2026年の導入事例ベース） |
| **AMR（自律走行搬送）** | 地図を持って自分で経路を決めて走る。人と混在可 | 工程間搬送の人手を置き換え。例：食品工場で年920万円削減の報道事例 | 3〜4年 |
| **AGV（無人搬送車）** | 床の磁気テープやQRを辿る。経路固定 | 安価だがレイアウト変更に弱い | 2〜3年 |
| **ピッキングロボット** | 3Dカメラで対象を認識し掴む | 品目が揃えば有効。柔包装・不定形はまだ苦手 | 4年〜 |

- 「2024年問題」（トラック運転者の時間外労働上限規制）が需要を一段押し上げた
- ボトルネックは**掴む工程**。運ぶのは解けたが、**多品種の商品を掴み分けるのは未解決**
- 関連：[倉庫・3PL](../../13_運輸・物流/08_倉庫・3PL/README.md)、[陸運・トラック](../../13_運輸・物流/06_陸運・トラック/README.md)

```
  倉庫作業の時間内訳（一般的な目安）
  歩行・移動 ████████████████████ 50〜60%  ← ロボットが解いた部分
  ピッキング ████████ 20〜25%              ← いま挑戦中
  梱包・検品 ██████ 15〜20%                ← 一部自動化
  その他     ███ 5〜10%
```

## 3. 飲食：配膳だけが解けた理由

すかいらーくグループは2021年から猫型配膳ロボットを導入し、2022年には**全国約2,100店舗に約3,000台**を展開した。
公表されている効果は、ガストでランチピークの回転率が約7.5%向上、片付け時間が約35%削減、
従業員の歩行数が約42%削減（同社および取材記事より）。

**なぜ配膳だけが成立したか**を分解すると明快である。

| 飲食店の作業 | ロボット化の難易度 | 理由 |
| --- | --- | --- |
| **運ぶ（配膳・下げ膳）** | 低 | 経路が決まっており、対象はトレー1種類。床は自社の床 |
| 注文を取る | 低（ただしタブレットで足りる） | ロボットである必要がない |
| 洗う | 中 | 食洗機という既存の専用機が既に最適解 |
| **調理** | 高 | 食材が不定形。温度・水・油。ハンドが壊れる |
| 盛り付け | 高 | 見た目の評価が定量化できない |
| 片付け・清掃 | 高 | 対象がその都度違う |

> つまり飲食で起きたのは「調理ロボットの登場」ではなく、**運搬だけの切り出し**だった。
> ロボット導入の定石は、職務をまるごと置き換えるのではなく、**最も定型的な1動作だけ剥がす**ことにある。

- 採算の目安：1台200万〜300万円、1台あたり0.3〜0.7人分の削減。人件費上昇で成立圏に入った
- 制約：テーブル間の通路幅（およそ80cm以上）が必要で、**狭い個人店には物理的に入らない**
- 主要メーカーは中国勢（Pudu Robotics、KEENON、OrionStar）が中心。国内は販売・保守を担う代理店型
- 関連：[ファミリーレストラン](../../08_食品・農水産・外食/15_ファミリーレストラン/README.md)、[回転寿司](../../08_食品・農水産・外食/17_回転寿司/README.md)

## 4. 介護：最も必要とされ、最も進まない

**必要性は最大**（人手不足が最も深刻）なのに、実装が最も遅れている。理由は経済性と責任の2つ。

| 重点分野（厚労省、2025年4月から9分野16項目で運用） | 代表機器 | 実装の壁 |
| --- | --- | --- |
| 移乗支援（装着／非装着） | パワーアシストスーツ、移乗リフト | 装着に時間がかかり、忙しい現場で使われなくなる |
| 移動支援 | 歩行アシスト、自動ブレーキ付き歩行車 | 比較的進んでいる |
| 排泄支援 | 自動排泄処理装置 | 個別性が高く、清掃負担が別途発生 |
| 見守り・コミュニケーション | センサ付きベッド、見守りシステム | **最も普及した領域**。夜勤の巡回を減らせる |
| 入浴支援 | 入浴介助機器 | 設備工事を伴い費用が重い |
| 介護業務支援 | 記録の自動化、ICT | ロボットより先にこちらが効く |

**なぜ進まないか**

1. **1対1の仕事**：1台のロボットが同時に複数人を介助できないため、削減できるのは最大でも1人分未満
2. **利用者ごとの個別性**：体格・拘縮・認知の状態が全員違う。定型化できない
3. **事故時の責任**：人に直接触れるため、事故が起きたときの責任の所在が曖昧
4. **導入後の運用負荷**：準備・装着・清掃・充電にかかる時間が、節約した時間を食い潰す例が多い

そのため制度は**補助金で回収年数を押し込む**方向に振れている。
介護テクノロジー導入支援事業では補助率が1/2〜3/4に設定され、都道府県が実施主体となる。
逆に言えば、**補助金なしで自走している介護ロボットはほとんどない**。
関連：[介護](../../09_医薬・医療・ヘルスケア/09_介護/README.md)

## 5. 清掃・警備：地味だが最も堅い

**清掃ロボット**
- 対象は主に**床**。床は平らで、汚れの位置は選ばない。②定型条件を最も満たす
- 商業施設・空港・病院の大面積フロアで採算が合う。狭小・段差の多い建物では合わない
- 2026年時点で「中小企業省力化投資補助金」の清掃ロボット対象業種に
  ビルメンテナンス業・警備業・ペストコントロール業などが追加され、導入の後押しが強まっている
- 現場の実態は**完全自動化ではなく分担**。「ロボットが広い直線部分、人が隅・トイレ・階段」という協働運用が定着

**警備ロボット**
- 巡回・監視・受付の3用途。夜間の巡回で人員半減の事例が報じられている
- 警備業法上、ロボットは**人の警備員の代替として法的に位置づけられていない**ため、
  「人を減らす」というより「巡回頻度を上げる／人を重要ポイントに集約する」使い方になる
- 関連：[ビルメンテナンス・清掃](../../15_サービス・生活関連/22_ビルメンテナンス・清掃/README.md)、[警備](../../15_サービス・生活関連/21_警備/README.md)

## 6. 農業：機械は完成したが、稼働日数が足りない

| 領域 | 到達点（2026年） | 壁 |
| --- | --- | --- |
| **ロボットトラクタ／自動運転農機** | クボタ、ヤンマー、井関が製品化済み。有人機と無人機を並走させる「協調作業」で1人が2倍の面積を処理できる | 価格が通常機の1.5〜2倍。**大規模経営体でないと回収できない** |
| 無人コンバイン | クボタが2024年に無人自動運転コンバインを市場投入 | 同上 |
| **収穫ロボット** | ピーマン、トマト、アスパラなどで実証・一部製品化（AGRIST、inaho ほか） | **年30〜60日しか稼働しない**。作物ごとに機械が別 |
| ドローン防除 | 最も普及。[ドローン](../08_ドローン/README.md) 参照 | 規制対応が必要だが採算は合いやすい |
| 除草ロボット | 実証〜初期導入 | 圃場条件のばらつき |

**農業の核心的な壁は稼働日数**である。
物流ロボットが年5,000時間動くのに対し、収穫ロボットは年に数百時間しか動かない。
同じ投資額でも、**回収に必要な年数が10倍になる**。

```
  年間稼働時間と回収年数の関係（投資1,000万円、1時間あたり2,000円の人件費を代替と仮定）
  5,000時間 → 年1,000万円削減 → 回収 約1年   （物流）
  2,000時間 → 年  400万円削減 → 回収 約2.5年 （清掃）
    500時間 → 年  100万円削減 → 回収 約10年  （収穫ロボット）
```

対策は「複数作物・複数作業に使い回す」か「共同利用・レンタル化」で稼働を積むしかない。
関連：[農業・種苗・肥料](../../08_食品・農水産・外食/12_農業・種苗・肥料/README.md)、[農業機械](../../02_自動車・機械/08_農業機械/README.md)

## 7. 小売：定型商品の陳列から

- Telexistence は**コンビニの飲料補充**に絞ったロボットを開発し、
  ファミリーマートの300店舗規模で実稼働していると発表している（同社発表）
- 飲料は形が揃い、置く場所も決まっており、バックヤードから冷蔵ケースへという経路も固定。
  **①〜⑤の条件をほぼ満たす、小売で最も解きやすい作業**だった
- 逆に、弁当・パン・不定形の商品や、フェイスアップ（商品を前に出して整える作業）はまだ難しい
- 関連：[コンビニエンスストア](../../07_小売・流通/01_コンビニエンスストア/README.md)

## 8. 分野を横断して見える3つの教訓

> **教訓1：職務ではなく動作を切り出す。**
> 「飲食店を自動化する」ではなく「配膳だけ剥がす」。成功例は全てこの形をとっている。

> **教訓2：ロボットを賢くするより環境を変えるほうが安い。**
> 通路幅・什器・包装・エレベーター連携を先に直す（ロボットフレンドリー化）。
> 詳細は [02_なぜロボットは普及しないのか](02_なぜロボットは普及しないのか.md) の第7章。

> **教訓3：稼働時間が全てを決める。**
> 技術的な難易度が同じでも、24時間動く現場と年2ヶ月の現場では、成立条件が一桁違う。

そして、これら全ての制約を一気に外そうとしているのが汎用ヒューマノイドと基盤モデルであり、
その現在地は [03_AIとロボットの結合](03_AIとロボットの結合.md) に書いた通り、まだ証明されていない。

## 用語メモ

- **AMR（Autonomous Mobile Robot）**：地図とセンサで自律走行する搬送ロボット。経路が固定されない
- **AGV（Automated Guided Vehicle）**：磁気テープやQRコードを辿る無人搬送車。安いが柔軟性が低い
- **GTP（Goods to Person）**：人が棚へ歩くのではなく、棚を人の所へ運ぶ方式
- **タクトタイム**：1個を処理するのにかかる時間。ロボットと人の速度比較の基準
- **フェイスアップ**：小売店で商品を棚の前面に揃える作業。定型化が難しい代表例
- **協調作業（農機）**：有人機と無人機を並走させ、1人で2台分の面積を処理する運用
- **重点分野（介護）**：厚労省が定める介護テクノロジーの支援対象領域。2025年4月から9分野16項目
