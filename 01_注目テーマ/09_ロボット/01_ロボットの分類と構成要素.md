# ロボットの分類と構成要素

**このノートで分かること**：ロボットという言葉が指す範囲の整理と、1台のロボットが
「骨・筋肉・感覚・脊髄・脳」の5層でできているという見方。そして、**日本がどの層で強く、どの層で弱いのか**。

結論を先に書く。**日本が強いのは下3層（機構・アクチュエータ・センサ）、弱いのは上2層（知能ソフト・アプリ）**。
この非対称が、ロボット業界のニュースをほぼすべて説明する。

## 1. そもそもロボットとは何か

国際規格 ISO 8373（JIS B 0134）の定義をかみ砕くと、ロボットは次の3条件を満たす機械を指す。

1. **2軸以上**の動く関節を持つ（1軸だけの装置は「単軸アクチュエータ」であってロボットではない）
2. **プログラムで動きを書き換えられる**（カムや機械式リンクで動きが固定された専用機は含まない）
3. **自動で動く**（人が常時操作するだけのものはマニピュレータ／遠隔操作機）

> ポイント：「作業を変えられる汎用機械」であることがロボットの定義の核。
> 専用機より高くて遅いのに使われるのは、**作り直さずに別の仕事をさせられる**からに尽きる。

この定義からすると、自動販売機や全自動洗濯機はロボットではない。
一方、床を勝手に走る掃除機や、倉庫で棚を運ぶ台車はロボットに入る。

## 2. 2つの軸で分類する

分類は「**どこで使うか（産業用／サービス）**」と「**どんな形か（腕型／移動型／人型）**」の2軸で見ると整理できる。

```
                  腕型（固定）        移動型（走る）      人型（腕＋脚）
              ┌──────────────┬──────────────┬──────────────┐
 産業用       │ 多関節ロボット │  AGV / AMR    │ 産業用ヒューマ │
 （工場の中） │ スカラ・直交   │ （工場内搬送）│ ノイド（試験中）│
              │ 協働ロボット   │               │               │
              ├──────────────┼──────────────┼──────────────┤
 サービス     │ 調理ロボット   │ 配膳・清掃    │ 接客・介護    │
 （工場の外） │ 陳列ロボット   │ 警備・配送    │ （大半が実証）│
              │ 手術支援       │ 農業ロボット  │               │
              └──────────────┴──────────────┴──────────────┘
      ← 既に量産・量販されている                 まだ実証が中心 →
```

- **産業用ロボット**：安全柵の中、決められた場所で、決められた動きを繰り返す。
  市場・プレイヤー・収益構造は [産業用ロボット](../../02_自動車・機械/09_産業用ロボット/README.md) に委ねる
- **サービスロボット**：工場の外で、人がいる環境で働く。このフォルダの主戦場
- **協働ロボット（コボット）**：柵なしで人の隣に置けるように出力を抑えた腕型。
  産業用とサービスの中間に立つカテゴリ

| 区分 | 台数規模 | 価格帯の目安 | 何が難しいか |
| --- | --- | --- | --- |
| 産業用（腕型） | 世界で年40万台超、稼働ストック400万台超（2024年、IFR） | 300万〜1,500万円／台（本体） | 導入設計。本体は成熟済み |
| 協働ロボット | 産業用出荷の1割強（2024年、IFR推計） | 200万〜600万円／台 | 出力制限と速度のトレードオフ |
| サービス（移動型） | 配膳・清掃で国内数万台規模 | 100万〜400万円／台 | 環境の多様性、床・段差・人 |
| ヒューマノイド | 世界で2026年上期に2.2万台超と報じられる | 数百万〜数千万円／台 | 汎用性の証明。実運用の実績がまだ薄い |

## 3. 1台のロボットは5層でできている

ロボットを分解すると、人間の体に対応する5つの層になる。

```
 ┌─ ⑤ 知能ソフト（脳）   ： 何をするか決める。認識・計画・学習（VLA、ROS 2）
 │        ↓ 目標位置・目標力
 ├─ ④ 制御（脊髄）       ： 毎秒1,000回、関節角を指令値に合わせ込む（サーボ制御）
 │        ↓ 電流指令
 ├─ ③ センサ（感覚）     ： エンコーダ、力覚、カメラ、LiDAR、触覚
 │        ↑ 実際の角度・力・画像
 ├─ ② アクチュエータ（筋肉）： モータ＋減速機＋ドライバ。力とトルクを生む
 │        ↓ 回転・直動
 └─ ① 機構（骨）         ： アーム、ハンド、車輪・脚、フレーム
                              ↓
                          【 対象物・環境 】
```

「AIロボット」という言葉で語られているのは基本的に⑤の話であり、
**①〜④は別々の産業（機械部品・電機・電子部品）として既に成立している**。
ここを分けて考えないと、ニュースの意味が取れない。

| 層 | 主な中身 | 代表プレイヤー | 日本の位置 |
| --- | --- | --- | --- |
| ⑤ 知能ソフト | 認識・動作計画・基盤モデル・アプリ | Google DeepMind、Physical Intelligence、NVIDIA、中国勢 | **弱い**。基盤モデルの主戦場から外れている |
| ④ 制御 | サーボアンプ、コントローラ、リアルタイムOS | ファナック、安川電機、三菱電機、オムロン、KUKA、ABB | **強い**。[FA・制御機器](../../03_電機・電子部品/14_FA・制御機器/README.md) 参照 |
| ③ センサ | エンコーダ、力覚センサ、3Dカメラ、LiDAR | キーエンス、オムロン、ニデック（旧日本電産）、SICK、Luminar | 中〜強。触覚は世界的に未成熟 |
| ② アクチュエータ | サーボモータ、**精密減速機**、ドライバ | ハーモニック・ドライブ・システムズ、ナブテスコ、安川、ニデック | **極めて強い**（後述） |
| ① 機構 | アーム構造、ハンド、脚、軽量フレーム | 各ロボットメーカー、シュンク、THK | 中。ハンドは群雄割拠 |

## 4. 日本の牙城：精密減速機

ロボットの関節は、モータの「速く弱い回転」を「遅く強い回転」に変換しないと使い物にならない。
その変換器が**減速機**で、ここが日本の独壇場になっている。

| 方式 | 仕組み | 得意な場所 | 主なメーカー |
| --- | --- | --- | --- |
| **波動歯車（ハーモニックドライブ）** | 楕円状にたわむ薄い歯車を使い、1段で50〜160分の1に減速 | 手首・手指・肘など小型関節 | ハーモニック・ドライブ・システムズ（世界シェア約5割とされる） |
| **RV減速機（偏心揺動型）** | 偏心運動を使い、大きな力に耐える | 肩・腰など根元の大関節 | ナブテスコ（産業用ロボット関節用で世界シェア約6割とされる） |
| サイクロイド／遊星 | 汎用。安価 | 低負荷・低精度用途 | 多数 |

この2社で精密減速機の世界シェアは約95%を占めるとされる（各種業界推計、2025〜2026年）。

### なぜ他社が追いつけないのか

減速機に求められる性能は、カタログ上は単純だが、同時に満たすのが極端に難しい。

- **バックラッシュがほぼゼロ**（歯車のガタ。ここが0.1度あると、1m先のハンドは2mmずれる）
- **高い剛性**（力を掛けてもたわまない）
- **長寿命**（産業用途で数万時間）
- **上を全部満たしたまま量産**（材料・熱処理・研削の作り込みの世界）

つまり**設計図があっても作れない類の部品**であり、材料と加工の蓄積が壁になっている。
[ベアリング](../../02_自動車・機械/10_ベアリング/README.md) や [工作機械](../../02_自動車・機械/07_工作機械/README.md) と同じ構図。

> 2026年の論点：ヒューマノイド1台には20〜40個の関節があり、産業用アーム（6軸）の数倍の減速機を食う。
> ナブテスコは2024〜26年度の設備投資計画275億円のうち約100億円をヒューマノイド向けに配分すると報じられる。
> ただし**人型が本当に量産されるかはまだ証明されていない**ので、需要は期待先行の部分が大きい。

## 5. センサ：進んだところと遅れたところ

| センサ | 何を測るか | 成熟度 | 備考 |
| --- | --- | --- | --- |
| エンコーダ | 関節の角度 | 成熟 | 全ロボットの基礎。精度がそのまま位置精度になる |
| 力覚／トルクセンサ | 押し付けている力 | 実用段階 | 協働ロボットと嵌合作業に必須 |
| 3Dカメラ（ステレオ、ToF） | 物体の形と位置 | 実用段階 | ばら積みピッキングの要 |
| LiDAR | 周囲の距離地図 | 実用段階 | 移動ロボットの自己位置推定。[自動運転](../15_自動運転/README.md) と共通 |
| **触覚（指先の圧力・すべり）** | 掴んだ感触 | **未成熟** | 人間の指先に相当する素子がまだ無い。柔らかい物の扱いが苦手な最大の原因 |

「ロボットは豆腐を掴めない」と言われるのは、指の機構よりも**滑りを検知して力を微調整する感覚がない**ことが効いている。

## 6. 制御とソフト：位置で動かすか、力で動かすか

- **位置制御**：関節角度の目標値に合わせ込む。速く正確だが、当たると壊す。産業用の基本
- **力制御／インピーダンス制御**：押し付ける力を目標にする。
  「はめ込む」「なでる」「人とぶつかっても止まる」といった仕事に必要
- **サーボ制御の周期**は1kHz（毎秒1,000回）前後。AIの推論は速くても数十Hzなので、
  **上位のAIは「どこへ行くか」を決め、下位の制御が「どう追従するか」を担う**という分業になる

```
 AIモデル（10〜50Hz）    サーボ制御（1,000Hz）      モータ
   「缶を掴め」  ──▶  目標関節角の連続値 ──▶  電流 ──▶ 動く
      遅いが賢い            速いが馬鹿              物理
```

ソフトの世界標準は **ROS / ROS 2**（オープンソースのロボット用ミドルウェア）。
研究から実装まで事実上の共通言語になっている一方、日本企業は自社の閉じたコントローラを主力にしてきたため、
**外部の開発者が入ってくる入口が狭い**という構造的な弱点を抱えている。

## 7. 1台のコストはどう割れているか

ヒューマノイドを例に、報道と各社言及からの**推計**を置く（幅がある数字として読むこと）。

| 部位 | コスト比率（推計） | 備考 |
| --- | --- | --- |
| アクチュエータ一式（モータ＋減速機＋ドライバ） | 40〜55% | 関節数に比例する。**ここを削れるかが量産の鍵** |
| センサ（カメラ、力覚、IMU） | 10〜15% | 半導体の量産効果が効く |
| 計算機（GPU／SoC） | 5〜10% | [AI半導体](../02_半導体・先端半導体/02_AI半導体とHBM.md) の需要先 |
| 電池・電源 | 5〜10% | 稼働時間の制約要因 |
| 構造体・外装・組立 | 15〜25% | 中国勢が最も安く作れる部分 |

中国メーカーが人型を100万円前後で出せると言われるのは、**関節をまとめて内製し、汎用部品に置き換えた**から。
逆に言えば、日本の減速機メーカーの強さは「高精度が必要な用途」に限られ、
**性能を落としてでも安くする競争が始まると、シェアは守れるとは限らない**。

## 用語メモ

- **ISO 8373 / JIS B 0134**：ロボットの用語規格。定義の出発点
- **自由度（DOF）**：独立に動かせる軸の数。人間の腕は7自由度、産業用アームは6が標準
- **協働ロボット（コボット）**：ISO/TS 15066 に沿って出力・速度を制限し、柵なしで人と同じ空間に置ける腕型ロボット
- **バックラッシュ**：歯車のかみ合いの遊び。位置決め誤差の直接原因
- **サーボ**：指令値と実測値の差をゼロに追い込む閉ループ制御。ロボットの基本動作原理
- **エンドエフェクタ（ハンド）**：腕の先端に付ける道具。吸着、平行チャック、多指ハンドなど
- **ROS 2**：ロボット用のオープンソース・ミドルウェア。通信・座標変換・シミュレータの共通基盤
- **IMU**：加速度と角速度のセンサ。人型の姿勢維持に必須
