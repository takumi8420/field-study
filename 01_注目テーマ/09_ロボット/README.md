# ロボット

- 大分類: 注目テーマ
- 状態: done
- 更新日: 2026-09-19

ロボット産業を一言でいえば、**「作業を変えられる汎用機械を売る産業」**。
専用機より遅くて高いのに使われるのは、作り直さずに別の仕事をさせられるからに尽きる。
そして普及の可否を決めているのは技術の完成度ではなく、**稼働時間 × 置き換え人数で決まる投資回収年数**である。

このフォルダは**注目テーマとしてのロボット全般**（サービスロボット、ヒューマノイド、AIとの結合、
物流・飲食・介護・清掃・農業への実装）を扱う。
工場の中で使う**産業用ロボット（FA）の市場・企業・収益構造**は
[産業用ロボット](../../02_自動車・機械/09_産業用ロボット/README.md) に委ねる。

## 1. 業界の定義・範囲

ISO 8373（JIS B 0134）の定義をかみ砕くと、ロボットは「**2軸以上の関節を持ち、プログラムで動きを書き換えられ、自動で動く機械**」。
「作業を変えられる」ことが定義の核で、動きが固定された専用機は含まない。

| 含む | 含まない（隣接） |
| --- | --- |
| 産業用ロボット（詳細は別フォルダへ委譲） | サーボ・PLC等の制御機器単体 → [FA・制御機器](../../03_電機・電子部品/14_FA・制御機器/README.md) |
| 協働ロボット、サービスロボット | 動きが固定された専用自動機 → [工作機械](../../02_自動車・機械/07_工作機械/README.md) |
| 物流・清掃・配膳・警備・介護・農業ロボット | 空を飛ぶ無人機 → [ドローン](../08_ドローン/README.md) |
| ヒューマノイド、四足歩行ロボット | 公道を走る車両の自動化 → [自動運転](../15_自動運転/README.md) |
| ロボット向け基盤モデル（VLA） | 身体を持たないAI全般 → [生成AI](../01_生成AI/README.md) |
| 減速機・アクチュエータ等の基幹部品 | ベアリング単体 → [ベアリング](../../02_自動車・機械/10_ベアリング/README.md) |

境界が曖昧になっている場所が2つある。
**①AIとの境界**（ロボットの価値がハードからモデルへ移りつつある）、
**②自動運転との境界**（屋外配送ロボットは両方の技術と規制にまたがる）。

## 2. 市場規模と成長性

| 指標 | 数値 | 年・出典 |
| --- | --- | --- |
| 世界の産業用ロボット導入 | 過去10年で約2倍 | 2024年、IFR World Robotics 2025 |
| 日本の産業用ロボット導入 | 44,500台（前年比▲4%）、世界2位 | 2024年、IFR |
| 日本の稼働ストック | 450,500台（＋3%） | 2024年、IFR |
| 日本のロボット密度 | 446台／従業員1万人（世界4位） | 2024年、IFR |
| 日本のサービスロボット市場 | 2025年 約2.6兆円 → 2035年 約5.0兆円 | 経済産業省の見通し |
| うち現場作業分野 | 2025年 約2.0兆円（＋12.4%）、市場の約7割 | 富士経済の推計（2025年公表） |
| 世界のヒューマノイド出荷 | 2026年上期に2.2万台超と報じられる | 2026年、報道・調査会社（定義に幅あり） |

> 注意：**産業用は台数統計（IFR）が整備されているが、サービスロボットとヒューマノイドは定義が揺れる**。
> ヒューマノイドの出荷台数は、車輪型や上半身のみを含むかで数倍の差が出る。総額の比較より段階の見極めが有効。

## 3. バリューチェーン（川上 → 川下）

```
【部品】           【本体】          【組み上げ】       【使う側】
減速機 ─┐
モータ ─┤─▶ ロボットメーカー ─▶ SIer（設計・据付） ─▶ ユーザー企業
センサ ─┤     ファナック          ハンド・治具・        工場／倉庫／店舗
制御IC ─┘     安川・ABB・KUKA      安全柵・教示         病院／介護／農場
              Unitree・UR                  ▲
                    ▲                      │
              基盤モデル（VLA）─────────────┘
              Google / PI / NVIDIA   ← 2020年代後半に現れた新しい層

  本体は総額の3〜4割。残りはハンド・周辺装置・安全対策・SI費・ティーチング
```

付加価値の在り処が**移動しつつある**のがこの業界の現在地。
従来は本体メーカーの垂直統合に利益が乗っていたが、
上（基盤モデル）と下（減速機）の両端に利益が寄る可能性が議論されている。

## 5. 収益モデル・コスト構造

| 事業 | 何で儲けるか | コストの中心 | 利益の出方 |
| --- | --- | --- | --- |
| 本体メーカー | 本体販売＋保守部品＋サービス | 部品調達（減速機・モータ）、開発費 | **保守と部品が安定収益**。本体は景気循環で振れる |
| 部品（減速機） | 部品販売 | 設備投資と歩留まり。装置産業 | 寡占なので利益率は高いが、**稼働率が落ちると固定費で赤字化** |
| SIer | 設計・据付・教示の受託 | 人件費（ほぼ全部） | 人月商売。規模の経済が効きにくく利益率は低め |
| サービスロボット販売・RaaS | 販売またはサブスク（月額） | 本体原価、保守・駆けつけ対応 | **RaaS（月額）は導入の心理的障壁を下げるが、回収が長期化する** |
| 基盤モデル | ライセンス／API | 学習計算コストとデータ収集 | まだ収益化の前段階 |

> 全体に共通するクセ：**設備投資財なので景気と設備投資サイクルに強く連動する**。
> かつ顧客の判断基準が回収年数に固定されているため、**値下げより「人件費上昇」のほうが需要を動かす**。

## 6. 競争要因（KSF）と参入障壁

**KSF**
1. **基幹部品の内製または安定調達**：減速機とモータの確保が量産のボトルネック
2. **導入を成立させる力（SIer網）**：本体が良くても、現場で動かせなければ売れない
3. **稼働時間を積める用途を選ぶ力**：技術より用途選定が成否を決める（[04_分野別の実装状況](04_分野別の実装状況.md)）
4. **データの蓄積**：基盤モデル時代は、現場で動いている台数がそのまま学習データになる
5. **保守網**：止まった瞬間に顧客の生産が止まるため、駆けつけ体制が乗り換え障壁になる

**参入障壁**
- 部品（減速機は設計図があっても作れず、材料と加工の蓄積が要る）、安全規格と認証、
  実績（止まらない証明がないと産業ユーザーは買わない）、保守網の全国展開。
- 逆に**サービスロボットは障壁が低い**。中国メーカーが日本の飲食・施設で多数を占めているのはこのため。

## 7. 規制・法制度

| 制度 | 内容 |
| --- | --- |
| **労働安全衛生規則**（日本） | 産業用ロボットは運転中の柵・囲いによる隔離が原則。定格出力80W以下等の例外規定が協働ロボット普及の起点になった |
| **ISO 10218 / JIS B 8433** | 産業用ロボットの安全要求。設計と統合の両面を規定 |
| **ISO/TS 15066** | 協働運転の技術仕様。人が接触したときの許容力を定める |
| **介護テクノロジー導入支援事業**（厚労省・都道府県） | 重点分野9分野16項目（2025年4月運用開始）、補助率1/2〜3/4 |
| **中小企業省力化投資補助金**（経産省・中小機構） | カタログ注文型と一般型。清掃ロボットの対象業種にビルメンテナンス業・警備業等を追加 |
| **ロボットフレンドリー施策**（経産省） | 施設・什器・業務フロー側をロボットに合わせて標準化する政策。2026年5月に政府方針を改訂 |
| **警備業法** | 警備ロボットは人の警備員の代替として法的に位置づけられていない |
| 屋外配送ロボット | 道路交通法上の遠隔操作型小型車として制度整備済み。[自動運転](../15_自動運転/README.md) と地続き |

## 8. 最近のトピック

詳細は [05_直近トピック_2026](05_直近トピック_2026.md) に出典URL付きでまとめた。要点は5つ。

1. **産業用の主戦場は中国に移った**。日本の年間導入は44,500台（2024年、IFR）で微減、一方ファナックは中国向けが牽引して増益
2. **ヒューマノイドは台数だけが先行**。Unitreeは2026年に2万台出荷目標、Teslaは社内1,000台級で外販ゼロ。
   経営陣自身が「まだ有用な作業をしているロボットはない」と述べたと報じられる（2025年Q4）
3. **VLA基盤モデルが実装段階へ**。Gemini Robotics 2（2026年7月）はロボット上でローカル実行し、数時間のデータで別機体に適応すると発表
4. **日本の政策はロボットフレンドリー化**（現場を標準化する方向）で固まり、補助金で回収年数を圧縮する設計になっている
5. **実運用に到達したのは「運ぶ」仕事だけ**。物流AMRは回収2.5〜4年、配膳は2,100店舗・3,000台規模。
   掴む・調理する・人に触れる仕事はまだ経済的に成立していない
