# サイバーセキュリティ

- 大分類: 注目テーマ
- 状態: done
- 更新日: 2026-09-19

サイバーセキュリティを一言でいえば、**「攻撃が産業として分業化した結果、
防御も産業として買わざるを得なくなった領域」**。
攻撃側はツールの開発・侵入口の卸売・実行・換金が別々の事業者に分かれ、
侵入口は1件数百ドルで売買される。だから「小さいから狙われない」は成立しない。
そして論点は、この数年で**「情報が漏れるか」から「事業が何日止まるか」へ移った**。

## 1. 業界の定義・範囲

「サイバーセキュリティ」は、**情報システムとそこに載るデータを、
意図的な攻撃から守るための技術・運用・制度の総体**を指す。
対象は「機密性（漏らさない）・完全性（改ざんさせない）・可用性（止めない）」の3つで、
この3つを**CIA**と呼ぶ。近年の被害の重心は、3つめの**可用性**（＝業務が止まる）にある。

| 含む | 含まない（隣接） |
| --- | --- |
| 攻撃の構造と経済（ランサムウェア、APT） | 単純な機器故障・災害対策 → BCP一般の領域 |
| 防御の技術と運用（EDR、SOC、ゼロトラスト） | 製品カテゴリ別の市場・ベンダー競争 → [情報セキュリティ](../../04_情報通信・IT・ネット/14_情報セキュリティ/README.md) |
| 組織・サプライチェーンの実務 | 物理警備・入退室管理（一部重なる） |
| 規制・制度（国内外） | 個人のプライバシー論一般 |
| AIをめぐる新しい攻守 | AIモデルの性能・産業構造 → [生成AI](../01_生成AI/README.md) |

境界が曖昧になっている場所が3つある。
**①事業継続（BCP）との融合**（止まった日数が被害の本体になったため）、
**②経済安全保障との融合**（技術流出対策がセキュリティの主題になったため）、
**③AIとの融合**（AIが攻撃手段でもあり、守るべき対象でもあるため）。

```
  【攻撃側】産業化した分業                    【防御側】産業化した市場
  ────────────────────                ────────────────────
  開発(RaaS) ─▶ 卸(IAB) ─▶ 実行 ─▶ 換金     製品ベンダー ─▶ 販売代理 ─▶ 導入
       │                                          │         (SIer/商社)   │
       └────────── 狙う ──────────▶ 【組織】◀──── 守る ────────────┘
                                          │
                                   規制・取引先要求が
                                   投資を強制する
```

## 2. 市場規模と成長性

| 指標 | 数値 | 年・出典 |
| --- | --- | --- |
| 世界の情報セキュリティ支出 | 約2,489億ドル（前年比＋12.7%） | 2026年、Gartner（2026年6月公表の予測） |
| 同・2025年実績見込み | 約2,130億ドル | 2025年、Gartner |
| 同・2030年見通し | 約3,726億ドル | Gartner予測 |
| 国内セキュリティソフトウェア市場 | 約4,637億円 | 2026年、IDC Japan予測 |
| 国内セキュリティサービス市場 | 約3,446億円 | 2026年、IDC Japan予測 |
| 世界の身代金支払総額 | 約8.2億ドル（前年比 約▲8%） | 2025年、Chainalysis |
| 国内ランサムウェア被害報告件数 | 226件（過去2番目） | 2025年、警察庁 |

> 注意：**「セキュリティ市場」の定義は機関ごとに違う**（ソフトのみ／サービス込み／
> 人件費込み）。総額の比較より、**2桁成長が続いていること**と、
> **国内はサービス（監視・運用の委託）の比率が上がっていること**のほうが安定して使える。

成長理由は3つ同時に効いている。①実際に事故が起き経営の議題になった、
②規制と取引先要求が増えた、③AIという新しい守備対象が増えた。

## 3. バリューチェーン（川上 → 川下）

```
【川上：作る】                    【中流：届ける】              【川下：使う・運用する】
製品ベンダー ─────────▶ 販売代理店・SIer ─────▶ ユーザー企業
 CrowdStrike, Palo Alto        大塚商会, SCSK           情シス / CSIRT
 Microsoft, Cisco, Google      ネットワンシステムズ      ↑ ここで人が足りない
 トレンドマイクロ, FFRI          商社系ディストリビュータ    │
      │                                                    ▼
      │                        【運用を代行する】      MSSP / MDR / SOC事業者
      │                          ラック, NRIセキュア, 富士通, NEC, SBT
      ▼
【脅威情報の供給】                【第三者の目】
 脅威インテリジェンス事業者         監査法人, ペネトレーションテスト事業者, 認証機関
 各国CERT/CSIRT, JPCERT/CC        ISMS審査機関

     利幅が薄い ◀───────────────────────────────▶ 利幅が厚い
     （ハード転売・単純導入）                （継続監視・インシデント対応・コンサル）
```

付加価値が集まるのは**右側の「運用」**である。製品は買えば終わるが、
**運用は毎月お金が落ちる**うえ、一度任せると切り替えコストが高い。
だから製品ベンダーもSIerも、サブスクリプションと運用サービスへ寄っている。

## 5. 収益モデル・コスト構造

| 事業 | 何で儲けるか | コストの中心 | 利益の出方 |
| --- | --- | --- | --- |
| セキュリティ製品（ソフト） | 年額サブスクリプション（端末数・ユーザー数課金） | 研究開発、脅威情報の収集 | **ソフトウェアなので粗利が高い**（7〜8割規模）。解約率が業績を左右 |
| セキュリティ機器（ハード） | 機器＋保守契約 | 製造原価、保守要員 | 機器は薄利、**保守で回収**する構造 |
| SOC／MDR（監視代行） | 月額。監視対象の数・ログ量課金 | **人件費（24時間365日の交代制）** | 労働集約。1人が何社見られるかで利益率が決まる。自動化が命綱 |
| SIer・導入 | 案件ごとの請負 | 技術者の人件費 | 人月ビジネス。スポットなので継続性が弱い |
| 脆弱性診断・ペネトレーションテスト | 案件ごと | 高スキル人材の人件費 | 単価は高いが**人数が増やせない**ので規模が出にくい |
| インシデント対応（フォレンジック） | 緊急対応。時間単価 | 同上 | 単価は最も高い。**事故がなければ売上が立たない**ので平時は顧問契約で埋める |
| コンサル・認証支援 | 案件ごと | 人件費 | 規制強化が直接の需要になる |

> 全体に共通するクセ：**製品は高粗利、運用は労働集約**。
> だから製品ベンダーは運用まで取り込みたがり（プラットフォーム化）、
> 運用事業者は自動化とAIで1人あたりの担当社数を増やしたがる。
> M&Aが止まらない理由も、突き詰めればここにある。

## 6. 競争要因（KSF）と参入障壁

**KSF**
1. **脅威情報の量**：守っている顧客が多いほど、攻撃の兆候を早く広く見つけられる。
   **ネットワーク効果が効く数少ない領域**（顧客が増えるほど製品が強くなる）
2. **誤検知の少なさ**：警報が多すぎると現場が見なくなる。精度は運用の継続性そのもの
3. **統合の幅**：ツールが多すぎて回らない「ツール疲弊」への回答としてプラットフォーム化が進む
4. **運用できる人**：製品を売っても運用できなければ効果が出ず、更新もされない
5. **実績と信頼**：事故対応の実績は、そのまま次の受注につながる

**参入障壁**
- **脅威情報の蓄積**（後発は同じ精度を出せない）、
  **24時間体制を組める人員**、**認証・実績**（政府調達や金融取引に必要）、
  そして**既存導入の粘着性**（入れ替えは業務停止リスクを伴うので動きにくい）

一方で参入自体は容易な部分もある。特定分野に絞った新興企業（クラウド設定、ID、AI）は
次々に生まれ、**成長すると大手に買われる**。これが市場の新陳代謝の基本形になっている。

## 7. 規制・法制度

詳細は [04_規制と制度](04_規制と制度.md)。骨格は次のとおり。

| 制度 | 内容 | 時点 |
| --- | --- | --- |
| **改正個人情報保護法**（日） | **課徴金制度を導入**。一方で漏えい時の本人通知は合理化 | 2026年7月10日成立、7月17日公布 |
| **サイバー対処能力強化法／能動的サイバー防御**（日） | 官民の情報共有、通信情報の利用、無害化措置、体制整備の4本柱。基幹インフラ事業者に報告義務 | 2025年5月成立、**2026年10月1日施行** |
| **経済安全保障推進法**（日） | 基幹インフラの設備導入の事前審査、重要物資の確保 | 2022年成立 |
| **サイバーセキュリティ基本法**（日） | NISC設置など全体の枠組み | 2014年 |
| **NIS2指令**（EU） | **組織**を規制。リスク管理措置、経営陣の責任、24時間以内の早期警告 | 2023年発効、2026年に改正提案 |
| **サイバーレジリエンス法（CRA）**（EU） | **製品**を規制。機械可読SBOM、出荷後の更新提供。悪用中脆弱性の24時間報告は2026年9月11日から | 主要要件は2027年12月11日から |
| **SEC開示規則**（米） | 上場企業に重大インシデントの4営業日以内の開示を義務化 | 2023年施行 |
| **CMMC**（米） | 国防総省サプライチェーン向けの成熟度認証 | 段階適用中 |

> ポイント：**自社が規制対象でなくても、取引先経由で同じ要求が降りてくる**。
> 規制対象かどうかで判断すると読み違える。詳しくは
> [03_サプライチェーンと組織の実務](03_サプライチェーンと組織の実務.md)。

## 8. 最近のトピック

詳細は [05_直近トピック_2026](05_直近トピック_2026.md) に出典URL付きでまとめた。要点は5つ。

1. **身代金は「払う社が減り、要求額が上がった」**。2025年の世界の支払総額は約8.2億ドル（▲8%）、
   支払率は約28%と過去最低、一方で要求の中央値は12,738ドル→59,556ドルへ（Chainalysis）
2. **日本の被害は高止まり**。2025年の報告件数226件（警察庁）。支払率は43.8%まで低下したが、
   払わず復旧できなかった割合も28.4%へ上昇（JIPDEC、2026年1月調査）＝方針と能力のギャップ
3. **論点が「漏えい」から「事業停止」へ移った**。アサヒGHD（2025年9月）は受注・出荷が約2ヶ月麻痺、
   アスクル（2025年10月）は約74万件の個人情報流出に加え、他社ECまで巻き込んだ
4. **AIが攻守両側に**。IPA「10大脅威 2026」で「AIの利用をめぐるサイバーリスク」が初の3位。
   AI活用攻撃は2025年に前年比89%増（CrowdStrike）。守る側の新課題はAIエージェントの権限管理（NHI）
5. **ベンダー再編が加速**。2026年3月にGoogle×Wiz（約320億ドル）とPalo Alto×CyberArk（約250億ドル）が
   相次いで完了。2026年上半期のM&Aは219件で半期として過去最速
