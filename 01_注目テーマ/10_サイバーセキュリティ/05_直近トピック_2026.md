# 直近トピック（2026年9月時点）

報道・調査レポートベースの整理。一次情報で裏取りすること。
数値は公表元によって定義が違うため、**機関名をセットで読む**こと。

## 1. 身代金は「払う社が減り、要求額が上がった」

2025年の世界のランサムウェア支払総額は**約8.2億ドル**（Chainalysis集計）。
2024年の約8.92億ドルから**約8%減**。一方で件数は減っていない。

| 指標 | 2024年 | 2025年 | 出典 |
| --- | --- | --- | --- |
| 支払総額（オンチェーン） | 約8.92億ドル | **約8.2億ドル**（▲約8%） | Chainalysis |
| 支払率（払った被害者の割合） | 約3〜4割 | **約28%（過去最低）** | Chainalysis |
| 身代金要求の中央値 | 12,738ドル | **59,556ドル（約3.7倍）** | Chainalysis |
| IAB（初期アクセスブローカー）への支払 | ― | 少なくとも約1,400万ドル | Chainalysis |
| ネットワークアクセスの平均価格 | ― | 約439ドル（2026年Q1。2023年Q1は約1,427ドル） | 業界レポート |

**読み方**：支払率が下がったのは、バックアップ整備と「払わない」方針の浸透の成果。
だが攻撃側は**単価を上げて総額を維持**しようとしており、
狙われる側の負担（停止日数・復旧コスト）はむしろ増えている。
初期アクセスの価格が3年で3分の1に落ちたことは、**攻撃の裾野が広がった**ことを意味する。

→ 背景の構造は [01_攻撃側の経済学](01_攻撃側の経済学.md)

## 2. 日本：被害件数は高止まり、支払率は3年連続で低下

| 指標 | 数値 | 出典・時点 |
| --- | --- | --- |
| 国内ランサムウェア被害報告件数 | **226件**（過去最多2022年の230件に次ぐ2番目） | 警察庁「令和7年におけるサイバー空間をめぐる脅威の情勢等について」（2025年分） |
| サイバー犯罪検挙件数 | 15,108件（過去最多） | 警察庁「令和8年警察白書」 |
| 都内のランサムウェア被害 | 68件（過去最多） | 警察庁（2025年） |
| 復旧費用「1,000万円以上」の割合 | 5割超 | 警察庁サイバー警察局（2025年分） |
| 日本企業の身代金支払率 | **43.8%**（2024年調査57.0%から3年連続低下） | JIPDEC「企業IT利活用動向調査2026」（2026年1月調査） |
| 払わず復旧できなかった割合 | **28.4%**（2024年調査21.8%から上昇） | 同上 |

**読み方**：日本企業は「払わない」方向へ確実に動いている。
ただし同じ調査で**復旧できなかった割合が上昇**しており、
方針だけ変えて**復旧能力（バックアップと訓練）が追いついていない**組織が一定数いる。

```
  支払率      57.0% ────▶ 43.8%     払わない企業が増えた
  復旧失敗    21.8% ────▶ 28.4%     しかし戻せない企業も増えた
                                     ＝ 方針と能力のギャップ
```

## 3. 2025年の国内大型事例：業務停止が2ヶ月に及んだ

**アサヒグループホールディングス**（2025年9月29日発生）
- 受注・出荷システムが停止し、ビール・飲料・食品の供給が広範囲に影響
- 新商品12種の発売延期を2025年10月1日に発表
- 復旧完了は2026年に入ってから。**約2ヶ月にわたり受注・出荷が麻痺**したと報じられる
- 事業利益への影響は約1%規模と報告されている

**アスクル**（2025年10月発生、報告書は2025年12月12日公表）
- 在庫・出荷を担うWMS（倉庫管理システム）が停止し、ASKUL／ソロエルアリーナ／LOHACOの受注が停止
- **約74万件**の個人情報が流出したと公表
- 全面停止期間の売上機会損失は1日あたり約10〜13億円規模との推計が報じられる
- 自社だけでなく、同社が物流を受託していた**他社のECも巻き込まれた**（サプライチェーン影響）

**読み方**：この2件が国内の議論を変えた。論点が
「情報が漏れるか」から「**事業が何日止まるか**」へ移り、
セキュリティ投資が情報システム部門の話から**BCP（事業継続）と経営の話**になった。

→ 事故対応の流れは [02_防御の全体像](02_防御の全体像.md)

## 4. AIが攻守の両側に入った：IPA「10大脅威 2026」で初のランクイン

IPA「情報セキュリティ10大脅威 2026」（組織編、2026年公表）の上位は次の通り。

| 順位 | 脅威 | 前年から |
| --- | --- | --- |
| 1位 | ランサム攻撃による被害 | 変わらず |
| 2位 | サプライチェーンや委託先を狙った攻撃 | 変わらず |
| 3位 | **AIの利用をめぐるサイバーリスク** | **初ランクイン** |

解説書の副題は「当たり前を確実に、基本の徹底と継続的な見直しで被害の最小化を」。
新しい脅威が入った年に、**基本の徹底を掲げている**点が示唆的である。

AI周りで2026年に報告された動きを整理する。

| 観点 | 内容 | 出典 |
| --- | --- | --- |
| 攻撃へのAI活用の増加 | AIを活用した攻撃が2025年に前年比**89%増** | CrowdStrike「2026 Global Threat Report」 |
| 正規AIツールの乗っ取り | 90以上の組織で、自社の正規AIツールやAIエージェントが情報窃取に使われた | 同上 |
| 悪意あるAIスキルの流通 | 主要リポジトリのAIスキル約90万件を分析し、約2.5万件が不審、**3,000超が悪意あるもの**と判定。自己改変型や決済権限の悪用も確認 | ESET「2026年上半期脅威レポート」 |
| AIエージェントによる自律攻撃の予測 | 偵察から初期侵入・感染までを自律実行するAIエージェントの登場を警戒 | トレンドマイクロ「2026年脅威予測」 |
| NHI（非人間ID）の管理 | AIエージェントやAPIキーなど「人でない主体」のアクセスが急増し、ID管理の前提が崩れている | Gartner ほか |

**読み方**：注目すべきは「AIが新しい攻撃を発明した」ことではなく、
**既存の攻撃の量・速度・言語の壁が下がった**こと。
守る側の新しい宿題は、**自社が使うAIエージェントの権限管理**（NHI）である。
AIエージェントは人と違い、退職も異動もせず、**権限を持ったまま放置されやすい**。

→ [生成AI](../01_生成AI/README.md) / [02_防御の全体像](02_防御の全体像.md)

## 5. ベンダー業界の地殻変動：2026年前半に大型再編が集中

| 時期 | 案件 | 金額 | 意味 |
| --- | --- | --- | --- |
| 2026年3月11日 | **Google が Wiz の買収を完了** | **約320億ドル** | Alphabet史上最大の買収。約12ヶ月の規制審査を経て成立。Wizはマルチクラウド（AWS/Azure含む）製品として維持 |
| 2026年3月（Wizの翌日と報じられる） | **Palo Alto Networks が CyberArk の買収を完了** | **約250億ドル** | ID・特権管理をプラットフォームの中核に据える |
| 2026年上半期 | セキュリティM&A **219件**、開示済み金額91億ドル（メガディール除く） | ― | 半期として過去最速ペース（Momentum Cyber 集計） |

```
  【〜2023年頃】専門ベンダー並立        【2026年】プラットフォームへ集約

   EDR   SIEM  ID   クラウド  メール        ┌──────────────────────┐
   ●     ●    ●     ●       ●            │ 統合プラットフォーム   │
   │     │    │     │       │            │ Microsoft / Palo Alto │
   └──┬──┴──┬─┴──┬──┴───┬───┘            │ Google / CrowdStrike  │
      個別に導入・個別に運用               └───────────┬──────────┘
      ＝「ツール疲弊」                                  │
                                              周辺に新興の専門ベンダー
                                              （育つと買われる）
```

**読み方**：買収が集中している理由は3つと整理されている。
① 企業が**数十の製品を個別に運用する疲れ**（ツール疲弊）でプラットフォームへ寄せたい、
② AIによる検知は**データが1ヶ所に集まっているほど効く**、
③ 買い手がカテゴリ首位に**高い倍率を払う意思**を持っている。

結果として、5年前の「多数の専門ベンダーが並立する市場」から、
**少数の統合プラットフォーム＋その周辺**という構造に移りつつある。
買う側（ユーザー企業）から見ると、選択肢は減るが運用は楽になる、というトレードオフになる。

→ 製品市場の詳細は [情報セキュリティ](../../04_情報通信・IT・ネット/14_情報セキュリティ/README.md)

## 6. 市場規模：2026年に世界2,400〜2,500億ドル規模

| 指標 | 数値 | 年・出典 |
| --- | --- | --- |
| 世界の情報セキュリティ支出 | **約2,489億ドル**（前年比＋12.7%） | 2026年、Gartner（2026年6月公表の2Q26予測） |
| 同・別時点の予測 | 約2,442億ドル／約2,400億ドル | 2026年、Gartner（公表時期により幅） |
| 同・2025年実績見込み | 約2,130億ドル | 2025年、Gartner（2025年7月公表） |
| 2030年見通し | 約3,726億ドル | Gartner予測 |
| 国内セキュリティソフトウェア市場 | 約4,637億円 | 2026年、IDC Japan予測 |
| 国内セキュリティサービス市場 | 約3,446億円 | 2026年、IDC Japan予測 |

**読み方**：**2桁成長が続いている数少ないIT分野**である。
理由は需要側にあり、①事故が現実に起きて経営の議題になった、
②規制・取引先要求が増えた（[04_規制と制度](04_規制と制度.md)）、
③AIという新しい守備対象が増えた、の3つが同時に効いている。
Gartnerは一方で「**企業はAIツールへの支出がAIを守るための支出の17倍**」とも指摘しており、
守備が追いついていない構図も示されている。

## 7. 制度：日本で2つの法律が同時に動いた年

| 制度 | 動き | 時点 |
| --- | --- | --- |
| **サイバー対処能力強化法**（能動的サイバー防御） | 2025年5月16日成立 → **2026年10月1日施行**が確認 | 2026年施行 |
| **改正個人情報保護法** | 衆院通過（2026年5月26日）→ 参院で成立（7月10日）→ 公布（7月17日）。**課徴金を導入**し、漏えい時の本人通知は合理化 | 2026年成立 |
| EU **CRA**（サイバーレジリエンス法） | 悪用中の脆弱性の**24時間以内報告が2026年9月11日から適用**。主要要件は2027年12月11日から | 2026〜2027年 |
| EU **NIS2** | 2026年1月20日、欧州委員会が明確化・簡素化のための改正を提案 | 2026年 |

**読み方**：日本企業にとって2026年は、
**国内で報告義務が増え、EUで製品規制の期限が来る**という二正面の年になった。
特にCRAは「EUで製品を売るメーカー」が直接対象になるため、
**ソフトを積んだ日本の製造業**が初めて本格的にセキュリティ規制の当事者になる。

## 8. 全体の構図

1. **攻撃は産業化し、価格が下がった**。初期アクセスが1件数百ドルで買える以上、
   「うちは小さいから狙われない」という前提は成立しない。
2. **払う企業は減ったが、被害は減っていない**。攻撃側は要求額を上げて適応し、
   防御側は「払わない」ための復旧能力を問われている。
3. **論点が情報漏えいから事業停止へ移った**。2025年の国内大型事例が示したのは、
   被害の主因が「漏れた件数」ではなく「**止まった日数×日商**」だということ。
4. **AIは攻守両方に入り、新しい守備対象（AIエージェントの権限）も生んだ**。
   ただしIPAが基本の徹底を掲げるとおり、被害の大半は依然として
   MFA・更新・バックアップという地味な3点で防げる。
5. **規制と取引先要求が投資を動かす主動力になった**。自社が規制対象でなくても、
   顧客経由で同じ要求が降りてくる。**規制対象かどうかで判断すると読み違える**。

## 用語集

| 用語 | 意味 |
| --- | --- |
| ランサムウェア | データを暗号化したり盗んだりして、復旧や非公開と引き換えに金銭を要求する攻撃 |
| 初期アクセス | 攻撃者が企業ネットワークへ最初に侵入するための認証情報や侵入口 |
| MFA | パスワードに加え、端末や生体情報など複数の要素で本人確認する多要素認証 |
| バックアップ | 障害や攻撃に備えて、復元できる形でデータの複製を保管すること |
| AIエージェント | 目標に沿ってツールやデータへアクセスし、複数の処理を自律的に進めるAI |
| CRA | EUのサイバーレジリエンス法。デジタル要素を持つ製品にセキュリティ要件を課す |
| インシデント | 情報漏えい、侵入、サービス停止など、セキュリティ上の事故やその兆候 |
| 事業継続 | 障害や攻撃が起きても重要業務を続け、早期に復旧するための考え方と仕組み |
