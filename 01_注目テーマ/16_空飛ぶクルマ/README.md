# 空飛ぶクルマ

- 大分類: 注目テーマ
- 状態: done
- 更新日: 2026-09-20

**最初に押さえること：「空飛ぶクルマ」は道路を走らない。実体は電動の小型航空機である。**
正式名称は **eVTOL**（electric Vertical Take-Off and Landing＝電動垂直離着陸機）、
制度上は **Powered-Lift（動力揚力機）**、政策文書では **AAM**（次世代空モビリティ）と呼ばれる。
「空飛ぶクルマ」は日本の経産省・国交省が使い始めた通称であって、技術用語ではない。
頭の中でこれを「**小型の電動ヘリコプター／飛行機**」に置き換えると、業界のニュースは一気に読みやすくなる。

そして、**期待と実態の差が最も大きい分野のひとつ**である。2026年9月時点の事実を先に並べておく。

| 問い | 2026年9月時点の答え |
| --- | --- |
| 型式証明を取った機体は何機あるか | **有人操縦機は世界で0機**。取得済みは中国EHangの**無人機**EH216-S（2023年10月、中国CAAC）のみ |
| 有償で人を運んでいるか | 中国（広州・深圳）で無人機による**遊覧中心の運航**のみ。欧米日は未開業 |
| 大阪・関西万博（2025年）で商用運航したか | **していない**。有人デモ飛行にとどまった |
| 資金繰りで脱落した企業は | 独 **Lilium**（2024年10月に自主管理→支払不能、2026年に試作機解体）、独 **Volocopter**（2024年12月に破産申請） |
| 日本で商用運航はいつか | 政府ロードマップで**2027〜28年**（2026年3月改訂）。ただし最初に来るのは**遊覧飛行** |

## 1. 業界の定義・範囲

**人が乗る電動の垂直離着陸機（eVTOL）と、その運航・離着陸場・部品**を指す。

| 含む | 含まない（隣接） |
| --- | --- |
| 有人eVTOL（1〜6人乗り級）の開発・製造 | 人が乗らない無人機 → [ドローン](../08_ドローン/README.md) |
| その運航事業（遊覧・空港アクセス・救急） | 既存のヘリコプター・小型機の製造 → [航空機・防衛](../../02_自動車・機械/13_航空機・防衛/README.md) |
| バーティポート（離着陸場）の整備・運営 | 定期航空運送事業 → [航空](../../13_運輸・物流/02_航空/README.md) |
| 機体向けの電池・モータ・CFRP・制御ソフト | 地上を走る自動車 → [自動車（完成車）](../../02_自動車・機械/01_自動車（完成車）/README.md) |
| 運航管理・空域管理のシステム | 大型の電動航空機（リージョナル機の電動化） |

```
             機体の重さ →
  ┌──────────────────────────────────────────────────────────────┐
  │ 100g      25kg      150kg   │   600kg      2t        5t以上    │
  │ ────────────────────────────┼─────────────────────────────── │
  │   ドローン（無人航空機）     │   eVTOL（人が乗る）  ヘリ・小型機 │
  │   航空法「無人航空機」の章   │   航空法の「航空機」             │
  │   機体認証＋操縦ライセンス   │   型式証明＋耐空証明＋型式限定   │
  │   費用：数十万円規模         │   費用：数百億〜数千億円         │
  │   期間：数か月               │   期間：5〜10年                  │
  └──────────────────────────────────────────────────────────────┘
      ↑ 技術（電動推進・飛行制御・電池）は完全に地続き
                                ↑ ここで制度が断絶している

  「ドローンが飛べているのだから空飛ぶクルマもすぐ飛ぶ」という直感が外れるのは、
  この壁が技術ではなく制度でできているから。
```

**境界が曖昧な2か所**がある。
① **ドローンとの境界**：技術（分散電動推進、飛行制御、電池）は完全に地続きだが、**制度は「人が乗るか」で断絶している**。
無人機の実績は、そのままでは有人機の認証に使えない。
② **航空機産業との境界**：eVTOLは航空機なので、部品も認証も既存の航空産業のルールで動く。
「新しいモビリティ産業」という顔と「古い航空産業の末端」という顔の両方を持つ。

道路も走れる「ロードアブル機」も一部に存在するが、**自動車基準と航空機基準の両方を満たすためどちらも中途半端になり**、産業の主流ではない。

## 2. 市場規模と成長性

**この業界の市場規模予測は、定義次第で3桁ぶれる**。鵜呑みにしない。

| 指標 | 数値 | 年・出典 |
| --- | --- | --- |
| 世界の空飛ぶクルマ市場 | 1.43億ドル（2024年）→ 10.3億ドル（2030年）、年平均+39% | Stratistics MRI **推計** |
| 世界市場（長期） | **2050年に約185兆円** | 2024年、日本経済新聞が投資銀行等の**推計**を引用 |
| 中国「低空経済」 | 10兆元規模 | 中国報道ベース。ドローン・物流・観光を含む**広義**の定義 |
| 型式証明を持つ有人操縦機 | **0機** | 2026年9月時点 |
| 有償運航している機体 | 中国 EHang EH216-S（無人）のみ | 2026年9月時点 |

> なぜこんなに数字がぶれるのか：**基準年の実売がほぼゼロ**だから。
> ゼロに近い数字から年+39%と置けば、前提を少し動かすだけで将来値が桁で変わる。
> 「2050年に185兆円」と「2030年に10億ドル」は、同じ産業を語りながら5桁違う。
>
> **総額の予測ではなく物量で見る**のが実務的。すなわち「型式証明を持つ機体が何機あるか」
> 「有償で何人運んだか」「年間何便飛んだか」。これなら誰も水増しできない。

  付加価値：   普通（既存産業）   巨額の先行投資    薄利・人件費勝負    用地が命     価格に敏感
  現在の損益：   黒字              全社が大赤字        未開業           未開業       未体験

**いま確実に現金が動いているのは左端の部材だけ**。機体メーカーは売上ゼロのまま開発費を燃やし続け、
運航とインフラは本格開業していない。**市場が立ち上がる前に上場だけが先行した産業**という見方が実態に近い。

付加価値の行方は将来的にも読みにくい。機体は「認証という参入障壁」で守られる一方、
運航は人件費勝負の薄利になりやすく、**バーティポートの用地を押さえた者が最も強い**可能性がある（空港ビジネスと同じ構造）。

## 5. 収益モデル・コスト構造

| レイヤー | 何で儲けるか | コストの中心 | 利益の出方 |
| --- | --- | --- | --- |
| 機体製造 | 1機いくらの物販＋保守部品 | **開発費（5億〜50億ドル規模）が固定費**。認証が終わるまで売上ゼロ | 量産台数がすべて。年数百機に届かないと固定費を割れない |
| 運航 | 1便あたりの運賃 | **機体償却・電池交換・パイロット人件費** | 稼働時間と搭乗率。パイロットを外せるまで構造的に苦しい |
| バーティポート | 着陸料・駐機料・充電料・テナント | **用地と建設**。すべて固定費 | 発着回数がすべて。空港ビジネスと同じ |
| 整備・部品 | 定期整備、電池パック交換 | 人件費、部品在庫 | 機体数が積み上がってから |

**1フライトのコストを積むと、初期は1席あたり8万円級**（50km・15分、4席、搭乗率70%の概算）。
各社が語る1万〜2万円/席に届くには、量産・稼働率・電池寿命・**自律運航**の4つが全部必要になる。
詳しい積み上げは [02_事業として成立するのか](02_事業として成立するのか.md)。

> **最大のコスト項目は、機体でもパイロットでもなく「電池パックの消耗」になる可能性が高い**。
> eVTOLは離陸のたびに数百kWを高レートで絞り出すので、EVより遥かに早く劣化する。
> 各社が電池寿命を公表したがらないのは、ここが事業計画の急所だから → [蓄電池](../04_蓄電池/README.md)

## 6. 競争要因（KSF）と参入障壁

**KSF**
1. **型式証明を取り切る資金体力**。10年間、売上ゼロで数百億円/年を払い続けられるか。Lilium・Volocopterはここで落ちた
2. **認証しやすい設計を選ぶ判断**。性能を欲張るほど認証が重くなる。EHangが最初にゴールしたのはここを割り切ったから
3. **量産パートナー**。Joby＝トヨタ、Archer＝Stellantis、SkyDrive＝スズキ。**自動車メーカーの量産力を借りるのが定石**
4. **バーティポートの用地**。都心の一等地に降りられるかが、時短効果＝商品価値を決める
5. **運航事業者との結合**。作るだけでは商売にならない。Jobyが Blade を買ったのはこの理由

**参入障壁**
- **極めて高い**。型式証明という国の関門があり、資金・時間・審査体制のすべてが要る
- ただし障壁の中身は技術ではなく**制度と資金**。だから「技術で勝てる」だけの企業は落ちる
- 一方で**防衛用途は型式証明が不要**（軍用機は別体系）なため、そこだけ障壁が低い。各社が防衛に寄る理由

## 7. 規制・法制度

| 制度 | 内容 |
| --- | --- |
| **型式証明（TC）** | 設計が安全基準に適合していることの国の証明。**この業界の唯一の関門** → [03_型式証明と制度](03_型式証明と制度.md) |
| **耐空証明／生産承認／運航許可** | 機体個体／量産体制／事業者への証明。TCの後に続く |
| **FAA Part 21.17(b)（特殊クラス）** | 米国。既存分類に収まらないeVTOLを審査する枠組み。5段階のステージで進む |
| **Powered-Lift SFAR**（2024年10月） | 米国。動力揚力機の運航・訓練の特別規則 |
| **EASA SC-VTOL**（2019年） | 欧州。VTOL専用の特別基準。世界のeVTOL基準の事実上の下敷き。安全目標は**10⁻⁹/飛行時間** |
| **日本 航空法／型式証明** | JCAB（国交省航空局）が審査。SkyDriveには2025年2月に適用基準、2026年3月に全般計画書 |
| **ADO（航空機設計検査認定事業場）** | 設計検査を自社で実施してよいという日本の認定。**型式証明ではない**。2026年4月にSkyDriveが国内初取得 |
| **空の移動革命に向けたロードマップ**（2026年3月改訂） | 経産省・国交省。**2027〜28年に商用運航開始**、2030年代前半に遠隔操縦とAAMコリドー、2030年代後半に自律運航の一部実現 |
| **eIPP**（米、2026年） | FAA・運輸省の実証プログラム。全米26州・8件を選定。**型式証明前でも実証運航ができる** |
| **バーティポートの基準** | ICAOで検討中。ドバイVDXが2026年7月に世界初の商用認証 |

## 8. 最近のトピック

詳細は [04_直近トピック_2026](04_直近トピック_2026.md) に出典URL付きでまとめた。要点は5つ。

1. **日本は2027〜28年に仕切り直し**（2026年3月ロードマップ改訂）。万博での商用運航は実現せずデモにとどまり、最初に来るのは遊覧飛行
2. **米Joby・ArcherはFAA審査の最終段階**だが、「2026年中に型式証明は出ない」という業界分析も根強い。目標時期は5年連続で後ろ倒しされてきた
3. **欧州は主要2社を失った**。Lilium・Volocopterが破綻し、知的財産は国外へ。基準づくりで先行したのに使う企業がいなくなった
4. **中国と中東が先に運び始めた**。EHangが広州・深圳で有償運航、タイ・カタールにも展開。ドバイは2026年7月に世界初の商用バーティポートを認証
5. **各社が防衛に傾斜**。型式証明が不要で開発費を政府が負担してくれるため、資金繰りの現実解になっている

とくに混同しやすい3語を先に挙げておく。

- **型式証明（TC）** ＝ 設計の合格証。**これがないと有償で人を運べない**
- **ADO** ＝ 設計検査を自社でしてよいという認定。**合格証ではない**
- **実験許可** ＝ 試験飛行のための許可。**デモ飛行はこれで飛んでいる**ので、商用化の進捗を意味しない

### このページの単語集
