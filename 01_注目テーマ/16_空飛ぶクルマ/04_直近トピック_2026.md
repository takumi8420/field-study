**一行でいえば**：2026年は「**デモから商用の一歩手前まで来たが、まだ誰も越えていない**」年。
中国と中東が先に運び始め、米国は認証の最終段階で足踏みし、欧州は主要2社を失い、日本は目標を2年後ろ倒しした。

## 1. 日本：ロードマップが「2027〜28年」に仕切り直された

- **2026年3月27日**、経産省と国交省が「空の移動革命に向けたロードマップ」を改訂。
  **商用運航の開始時期を「2027〜28年」と初めて明記**した（国交省 報道発表）
- 3段階の絵：**2027〜28年に一部地域で商用運航（限定的な2地点間飛行と遊覧飛行）**、
  **2030年代前半に遠隔操縦とAAMコリドー等の新交通管理**、**2030年代後半に自律運航の一部実現**
- これは事実上の**仕切り直し**。当初は2025年の大阪・関西万博で商用運航を実現する計画だったが、
  型式証明が間に合わず、万博では**有人デモ飛行にとどまった**（SkyDriveが高度約4m、約3分、前後約50mの飛行を披露）
- 大阪では**2026年5月8日**、大阪府・市、丸紅、SkyDrive、Soracle（JAL×住友商事のJV）、大阪メトロなど6者が
  商用化コンソーシアムを設立。**大阪港バーティポート**を軸に、
  2026〜27年度にルート再検証とポート候補地選定、**2028年度に型式証明取得と遊覧飛行・一部商用運航**を目指すと報じられる

> 読み方：**「2027〜28年」は機体の目標時期ではなく、制度と拠点の準備が整う時期**。
> SkyDriveの型式証明取得目標が2028年以降である以上、2027年に日本国内で有償の旅客飛行が始まる可能性は低い。
> 最初に来るのは**遊覧飛行**であって、空港アクセスではない。

## 2. 日本：SkyDriveが「ADO」を取得。ただし型式証明ではない

| 年月 | 出来事 |
| --- | --- |
| 2025年2月 | 国交省が SkyDrive 機「SKYDRIVE」に**型式証明の適用基準を発行** |
| 2025年（万博期間） | 大阪・関西万博で有人デモ飛行 |
| 2026年3月 | 国交省と**全般計画書**で合意（審査の進め方が固まった） |
| **2026年4月20日** | **国内初の ADO（航空機設計検査認定事業場）を取得**。設計適合性の検査の一部を自社で実施可能に |
| 2026年7月30日 | スズキ・Air India と提携。インドの医療インフラ向けの活用を目指すと発表 |
| 2026年8月20日 | 第三者割当増資を実施（調達額非公開） |

**ADOはEASAの設計組織承認（DOA）、FAAの組織指定認可（ODA）に相当する認定であって、機体の合格証ではない**。
「国内初の設計承認」という見出しは誤読を招きやすい。型式証明そのものは2028年以降が目標。

機体はスズキグループの静岡県磐田市の工場で製造されている。
プレオーダーは**7カ国380機超**と発表されているが、この業界の受注は多くが拘束力の弱い意向表明である点に注意。

## 3. 米国：認証の最終段階と、「今年は取れない」という懐疑論

| 企業 | 認証の位置 | 目標 |
| --- | --- | --- |
| **Joby Aviation** | FAA 5段階のうち **Stage 4を完了、Stage 5のTIA飛行試験**へ。2026年3月に量産適合機が初飛行 | 2026年内のTC取得と商用運航開始 |
| **Archer Aviation** | FAA 4フェーズ区分の**フェーズ3を完了**、適合方法（MoC）の100%受理を達成と発表 | 2026年後半のTC取得、2026年内の米国運航開始 |
| **BETA Technologies** | 貨物・充電インフラから入る。2026年7月10日にeIPPで初飛行 | 段階的 |

```
  各社が公表してきた「商用運航開始」の目標時期（Jobyの例。報道・IR発表ベース）

   発表時点     目標       2023  2024  2025  2026  2027  2028
   ─────────────────────   ──────────────────────────────────
   2021年頃 → 2024年           ●────✗
   2023年頃 → 2025年                 ●────✗
   2024年頃 → 2025年末                     ●──✗
   2025年頃 → 2026年                          ●───?
                                                   ↑ 2026年9月時点はここ

   ✗ ＝ 達成されずに後ろ倒し。5年連続で「来年こそ」が繰り返されてきた。
   だから「目標時期の発表」は進捗ではない。見るべきは TIA が始まったかどうか。
```

一方で、**「2026年中に米国eVTOLが型式証明を取得することはない」**とする業界分析も報じられており、
Jobyの2027年半ば取得の確率を20〜30%、Archerを2028年以降と見る向きもある。

- **Jobyの財務**：2025年通期の純損失 約9.3億ドル（2024年の約6.1億ドル から拡大）、2026年上期の純損失 約3.55億ドル。
  手元現金・短期投資は約23億ドル。トヨタが出資と量産で関与
- Jobyは2025年にヘリ旅客事業の **Blade** を買収し、運航・顧客基盤を先に確保した。
  2026年4月にはマンハッタン〜JFK間を飛行してみせた（デモ）
- **eIPP（eVTOL Integration Pilot Program）**：FAAと米運輸省が**全米26州・8件**を選定。
  2026年夏にも運航開始の見込みと報じられる。**型式証明前でも実証運航ができる枠組み**である点が重要

> 読み方：**目標時期の発表を実績と読み替えないこと**。Jobyの商用化目標は当初2024年、次に2025年、そして2026年と
> 繰り返し後ろ倒しされてきた。見るべきは「**TIAが始まったか**」「**量産適合機で何時間飛んだか**」の2つ。

## 4. 中国と中東：先に「運んでいる」のはこちら

### 中国

- **EHang EH216-S** が唯一、型式証明・生産証明・運航証明を揃え、**広州・深圳で有償の旅客飛行を実施**している。
  ただし**無人（自律）・最大2名・航続30km級**で、内容は遊覧飛行が中心
- **2025年11月**、タイ民間航空局（CAAT）のサンドボックスの下で、中国国外初の都市旅客飛行を実施。
  同月、**カタール**でも中東初の無人旅客eVTOL飛行
- 2026年、**深圳・羅湖区に世界初の全自動バーティポート**を開設
- 自動車大手の**広汽集団**が自社初の空飛ぶクルマのラインオフを発表（JETRO報道）。
  中国では「低空経済」が国家戦略として位置づけられ、地方政府の補助が厚い

### ドバイ

- **2026年7月6日**、ドバイが**世界初の商用バーティポート「VDX」を認証**（Aviation Week報道）。
  Skyports Infrastructure とドバイ道路交通庁（RTA）が、さらに3か所を整備中
- Joby の運航拠点となり、**2026年内の商用運航開始**を目標としている

```
  2026年9月時点の世界地図（有償で人を運んでいるか）

   中国   ━━━━━━━━━━━━━━●  有償運航あり（無人・遊覧中心、EH216-S）
   中東   ━━━━━━━━━━━━━○  バーティポート認証済み、運航は年内目標
   米国   ━━━━━━━━━━━○      認証 最終段階（TIA）、実証運航はeIPPで開始
   日本   ━━━━━━━━○          基準・設計組織まで。商用は2027〜28年目標
   欧州   ━━━━━●──────✗       基準は最先行、しかし主要2社が破綻

          基準づくり → 設計審査 → 飛行試験 → 型式証明 → 有償運航
          ◀───────────────────────────────────────▶
```

> 構図：**性能を割り切って先に飛ばす中国／インフラと規制を先に整える中東／認証の厳密さを守る欧米**。
> 3つのアプローチのどれが「正解」かは、最初の重大事故が起きたときに初めて分かる。

## 5. 欧州：主要2社の破綻と、その後

| 企業 | 経緯 |
| --- | --- |
| **Lilium**（独） | 2024年10月に中核子会社の現金が尽き、自主管理手続きへ。その後支払不能。**2026年4月までに試作機が解体された**と報じられる。ダクテッドファン30基という野心的方式が認証・資金の両面で重荷に |
| **Volocopter**（独） | 2024年12月に破産申請。中国系資本を経て、**Diamond Aircraft のポートフォリオ下**でEASA認証を目指すと報じられる |

両社とも**受注を積み、試作機は飛んでいた**。それでも**認証が終わる前に現金が尽きた**。
業界分析では、**認証可能な機体を1機開発するには5億〜50億ドル（およそ750億〜7,500億円）**が必要とされる。

この2社の知的財産が国外（主に中国系）へ渡ったことは、欧州にとって**産業政策上の失点**と受け止められている。
EASAは2019年のSC-VTOLで**世界で最も早く基準を整えた**のに、その基準で認証を取る自国企業を失った。

## 6. 防衛への傾斜という静かな地殻変動

2026年に目立ってきたのが、**eVTOL各社の防衛シフト**。

- 型式証明が不要（軍用機は民間とは別の体系）なので、**認証を待たずに売上が立つ**
- 開発費を政府が負担してくれる。しかも**自律飛行・ハイブリッド動力**という、民間側でも欲しい技術の実証になる
- 日経xTECHは「次世代eVTOL、防衛需要が開発後押し 自律飛行型ハイブリッドに熱視線」（2026年7月）と報じている

**「都市の空を変える」という当初の物語からは遠いが、資金繰りの現実解**になっている。
同じ構図はドローン業界でも起きた → [ドローン](../08_ドローン/README.md)

## 7. 市場規模の数字は、ほぼ信用に値しない

| 出典 | 数値 | 注意点 |
| --- | --- | --- |
| Stratistics MRI（推計） | 世界市場 1.43億ドル（2024年）→ 10.3億ドル（2030年）、年平均+39% | **現時点の実売がほぼゼロ**なので、基準年の数字自体が不安定 |
| 日本経済新聞（2024年、Morgan Stanley等の推計を引用） | 世界市場は**2050年に185兆円** | 25年以上先の推計。前提が変われば桁が動く |
| 中国の各種報道 | 「低空経済」で10兆元規模 | ドローン・物流・観光を全部含む広義の定義 |

> **この業界の市場規模予測は、定義次第で3桁ぶれる**。
> 「2050年に185兆円」と「2030年に10億ドル」は、同じ産業について語りながら5桁違う。
> 総額の予測を比べるより、**「型式証明を持つ機体が何機あるか」「有償の旅客を何人運んだか」という物量**で見るほうが、
> はるかに実態に近い。2026年9月時点の答えは、**型式証明を持つ有人操縦機は0機**、有償運航は中国の無人機のみ。

## 8. 全体の構図（まとめ）

1. **有人操縦のeVTOLで型式証明を取った機体は、2026年9月時点で世界に1機もない**。取得済みは中国EHangの無人機のみ
2. 米Joby・Archerは認証の最終段階にいるが、**目標時期は5年連続で後ろ倒しされてきた**。2026年内取得を疑う声も強い
3. **欧州は主要2社（Lilium・Volocopter）を失った**。基準づくりでは先行したのに、それを使う企業がいなくなった
4. **日本は2027〜28年に仕切り直し**。万博での商用運航は実現せずデモにとどまり、最初に来るのは遊覧飛行になる見込み
5. 一方で**中国・中東では実際に人を運び始めた**。性能を割り切る／インフラを先に作る、という別の解き方が機能している
6. そして各社は**防衛需要に活路を求めている**。「都市交通の革命」ではなく「政府予算で開発を続ける」段階にある

**期待と実態の差が最も大きい分野のひとつ**であることは、数字が示している。
ただし「絶対に実現しない」でもない。**電池・認証・降りる場所の3つが解けたところから、局所的に成立していく**。
その最初の場所が東京や大阪ではなく、ドバイや深圳や離島である、というのが2026年時点の景色。

## 用語メモ

- **eIPP（eVTOL Integration Pilot Program）**：米FAA・運輸省の実証プログラム。**型式証明前でも実証運航ができる**枠組み
- **ADO（航空機設計検査認定事業場）**：設計検査を自社で実施してよいという日本の認定。型式証明ではない
- **低空経済**：中国が国家戦略として掲げる、低空域（概ね1,000m以下）の産業化。ドローン・eVTOL・物流・観光を含む広義の概念
- **サンドボックス**：新技術を限定条件下で試すために既存規制を一時的に緩める制度。タイのeVTOL旅客飛行はこの枠組み
- **量産適合機（conforming aircraft）**：量産する仕様と同一の機体。試作機での飛行実績とは意味が違う
- **VDX**：ドバイの空港近くに整備された世界初の商用認証バーティポート
