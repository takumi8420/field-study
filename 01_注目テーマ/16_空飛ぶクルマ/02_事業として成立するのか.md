# 空飛ぶクルマ｜事業として成立するのか（1席あたりいくらになるか）

このノートで分かること：**機体が飛ぶことと、商売になることは別問題**である。
1席あたりのコストを実際に積み上げ、既存の交通手段と並べて、どこなら成立してどこなら成立しないかを見る。

**結論から**：2026年9月時点で、**空飛ぶクルマで営業黒字を出している企業は世界に1社もない**。
コストを積むと、**1席あたり1万〜3万円級**（15分・50km程度のフライト）になり、
これは「タクシーと同程度の値段でヘリに乗れる」水準。**通勤の乗り物にはならず、空港アクセスと観光が現実解**になる。
そして黒字化の鍵は機体価格ではなく、**パイロットを1機につき1人乗せなくてよくなるか**にある。

## 2. 1フライトのコストを積んでみる

**前提**：大阪駅周辺 → 関西国際空港（直線約50km）を想定。巡航15分、地上作業を含むブロックタイム30分。
機体は4席（パイロット1＋乗客4）。数字は**公表情報とヘリコプター運航の実績からの筆者による概算**であり、
各社の公式予測ではない。桁の感覚をつかむためのもの。

| 費目 | 前提 | 1飛行時間あたり |
| --- | --- | --- |
| **機体の償却** | 機体価格 5億円、耐用10年、年間飛行時間 500時間 | **10.0万円** |
| **電池パックの交換** | パック6,000万円、800サイクル、1サイクル≒0.5飛行時間 | **15.0万円** |
| **パイロット人件費** | 年収＋社会保険＋訓練で年1,500万円、年間乗務600時間、1機に1.5人必要 | **3.8万円** |
| 整備（機体・モータ） | ヘリの半分と仮定 | 3.0万円 |
| 保険 | 機体価格の3〜5%/年 | 4.0万円 |
| 電力代 | 100kWh／30分、30円/kWh | 0.6万円 |
| バーティポート利用料・地上要員 | 1便5,000円×2便/時間 | 1.0万円 |
| 運航管理・本社間接費 | 上記の20% | 7.5万円 |
| **合計** | | **約 45万円/時間** |

```
  1飛行時間 45万円
        ↓  ブロック30分（実飛行15分＋地上15分）＝ 0.5時間
  1便あたり 約 22.5万円
        ↓  4席、搭乗率70% ＝ 2.8席
  1席あたり 約 8万円   ← 初期の実力（採算ライン）
```

この数字が示すのは、**最初は8万円/席でしか飛ばせない**ということ。
各社が語る「1万〜2万円/席」に下げるには、次の3つが全部必要になる。

| 削減レバー | 効果 | 実現時期の目安 |
| --- | --- | --- |
| **量産で機体価格を下げる**（5億円 → 1.5億円） | 償却 10万 → 3万円/時間 | 年数百機の量産が前提。2030年代 |
| **稼働時間を伸ばす**（年500時間 → 1,500時間） | 固定費が1/3に薄まる | 需要と航空管制の受け入れ次第 |
| **電池を長寿命化／安価化** | 交換費 15万 → 4万円/時間 | 蓄電池産業の進歩に依存 → [蓄電池](../04_蓄電池/README.md) |
| **パイロットを外す（自律運航）** | 人件費 3.8万 → ほぼゼロ、かつ1席増える | 日本のロードマップでは**2030年代後半** |

これを全部織り込むと **1時間あたり15万円前後 → 1席あたり2.5万円前後**。
さらに座席を4→6に増やし搭乗率を上げて、ようやく**1万円台**が見えてくる。

> ポイント：**最大のコストは機体でもパイロットでもなく、「電池パックの消耗」になる可能性が高い**。
> eVTOLは離陸のたびに電池を高レートで叩くので、EVより遥かに早く劣化する。
> 各社が電池寿命を公表したがらないのは、ここが事業計画の急所だから。

## 3. 既存の交通手段と並べる

大阪駅周辺 → 関西国際空港（約50km）の比較。**これが最も語られている想定路線**。

| 手段 | 所要時間（ドアtoドア） | 1人あたり料金 | 実態 |
| --- | --- | --- | --- |
| 特急はるか（鉄道） | 約 75分 | 約 2,900円 | **圧倒的に安い**。定時性も高い |
| リムジンバス | 約 70分 | 約 1,800円 | 最安。荷物が楽 |
| タクシー | 約 60〜90分（渋滞次第） | 約 20,000円（1台） | 4人で割れば5,000円/人 |
| ハイヤー・定額タクシー | 同上 | 約 25,000円（1台） | ビジネス利用の標準 |
| **ヘリコプター（チャーター）** | 約 25分＋前後移動20分 | 15万〜25万円（1機） | ヘリポートが限られ、騒音で発着枠が少ない |
| **eVTOL（初期）** | 約 15分＋前後移動20分 | **推計 3万〜8万円/人** | まだ存在しない |
| **eVTOL（成熟後の目標）** | 同上 | **目標 1万〜2万円/人** | 各社の長期目標 |

```
   料金 ▲
  20万円│  ●ヘリチャーター
        │
   5万円│        ●eVTOL（初期）
        │
   2万円│              ○eVTOL（目標）   ●タクシー（1台）
        │
   3千円│ ●鉄道 ●バス
        └──────────────────────────────▶ 所要時間
          75分      60分       35分     短い

  eVTOLが狙うのは「タクシーの値段で、鉄道の半分の時間」という空白地帯。
  ただし ▲ 前後の地上移動20分を足すと、時間差は思ったほど開かない。
```

> **ここが事業性の最大の弱点**：eVTOLの速さは「ドアtoドア」では大きく目減りする。
> バーティポートまで行く時間、保安検査、搭乗手続きを足すと、50km程度では鉄道との差が30〜40分しかつかない。
> **距離が短いと空の優位が出ず、距離が長いと電池が足りない**。この挟み撃ちが構造的な難しさ。

成立しやすいのは、**地上の移動が極端に不便な区間**。
瀬戸内・離島、渋滞が慢性化した新興国の都市（サンパウロ、ムンバイ）、砂漠の観光地（ドバイ、サウジ）、
そして**救急・医療搬送**（価格弾力性が低く、時間の価値が桁違いに高い）。

## 4. バーティポート：土地の問題であって技術の問題ではない

バーティポート＝eVTOLの離着陸場。**ここが実は最大のボトルネック**になる。

| 必要なもの | 中身 | なぜ難しいか |
| --- | --- | --- |
| **FATO / TLOF** | 最終進入・離陸区域／接地区域。機体の全長の1.5倍程度の広さ | 都心にまとまった平地がない |
| **進入表面の確保** | 離着陸の進入経路上に高い建物があってはならない | **周囲のビルが後から建つと使えなくなる**。都市計画との調整が要る |
| **充電設備** | 1機あたり数百kW級の急速充電。複数機なら1MW超 | 受電設備の増設が必要 → [電力](../../11_資源・エネルギー・鉄鋼金属/04_電力/README.md) |
| **待合・保安** | 搭乗手続き、手荷物、消防設備 | 空港に準じた設備が要り、小さくできない |
| **騒音の受忍** | 周辺住民の同意 | **技術ではなく合意形成の問題**。ヘリポートが都心で増えない理由と同じ |

現実解は **①既存のヘリポート（ビル屋上・空港）を転用する、②港湾・埋立地など反対の少ない場所に作る** の2つ。
日本で大阪湾岸（大阪港）が拠点に選ばれたのは、**用地が取れて騒音の苦情が出にくいから**であって、
そこに需要があるからではない。

```
  【理想】都心のビル屋上 → 空港           【現実】湾岸の埋立地 → 空港
   ▓▓▓                                      ░░░
   ▓▓▓[H]  ～～～～▶ ✈                      ░░░ [H] ～～～～▶ ✈
   ▓▓▓                                      ░░░
   オフィス直結・時短効果 大                 港まで地上移動30分・時短効果 小
   用地なし／騒音苦情／進入表面の確保が困難  用地あり／苦情少／需要が薄い
                ↑ ここを解けるかが勝負どころ
```

> 「空飛ぶクルマが普及しない理由」を1つ挙げるなら、機体でも規制でもなく**降りる場所がないこと**。
> これはドローン物流が伸び悩んでいる理由とも共通する → [ドローン](../08_ドローン/README.md)

## 5. パイロットという固定費

初期の商用運航は**パイロットが必ず1人乗る**。ここが事業性を大きく縛る。

- 操縦するには、事業用操縦士の資格に加えて、**その機種の型式限定**が要る。eVTOLはこれから作る資格
- Powered-Lift は飛行機でもヘリでもないため、**訓練課程も審査基準も新設**。米FAAは2024年10月に Powered-Lift SFAR で枠組みを作った
- **乗務時間の上限**があるため、1機を毎日飛ばすには1.5〜2人のパイロットが要る
- 4席の機体でパイロットが1席使うと、**売れる席は3席**。ここも効く

したがって業界のシナリオは必ず「**遠隔操縦 → 自律運航**」へ向かう。

| 段階 | 誰が操縦するか | 席の使い方 | コスト構造 | 日本の想定時期 |
| --- | --- | --- | --- | --- |
| 第1段階 | 機上のパイロット | 4席中3席が商品 | 人件費が乗る | 2027〜28年（商用運航開始） |
| 第2段階 | 地上からの遠隔操縦 | 4席すべて商品 | 1人が1機を見る。人件費は残る | 2030年代前半 |
| 第3段階 | 自律運航（1人で複数機を監視） | 4席すべて商品 | **人件費が1/3〜1/5に** | 2030年代後半 |

（出典：経産省・国交省「空の移動革命に向けたロードマップ」2026年3月改訂）

**第3段階に到達しないと、大衆価格にはならない**。一方、自律運航は型式証明よりさらに難しい制度課題なので、
「2030年代後半」という表現は**実質的に「当面は高価な乗り物である」と言っている**に等しい。

なお中国のEHang EH216-S は**最初から無人（自律）**で型式証明を取った。
航続30km級・2人乗りと性能を割り切ったうえで、**先に自律運航のコスト構造を手に入れた**ことになる。
ここが欧米日と中国の戦略の根本的な違い。

## 6. 収益の出口はどこにあるか（用途別の見立て）

| 用途 | 単価の許容度 | 必要な航続 | 成立しやすさ | 理由 |
| --- | --- | --- | --- | --- |
| **観光・遊覧飛行** | 高い（体験型消費） | 短くてよい（周回） | **◎ 最初に来る** | 移動効率を問われない。万博デモも実質これ |
| **空港アクセス** | 中（タクシー比較） | 30〜60km | ○ | 各社の本命。ただし地上移動時間で優位が削られる |
| **救急・医療搬送** | 非常に高い | 中 | ○ | ドクターヘリの補完。ただし**夜間・悪天候で飛べない**のが致命的 |
| **離島・中山間地の移動** | 中（代替手段が乏しい） | 30〜80km | ○ | 公共補助が入りやすい。日本で最も社会的意義がある領域 |
| **都市内通勤** | 低い（毎日は払えない） | 20〜40km | **× 当面ない** | 1席1万円でも月20万円。需要が薄い |
| **物流（無人・大型）** | 中 | 100km超 | △ | 有人より規制が軽い。中国AutoFlightなどが狙う |
| **防衛・人員輸送** | 高い（性能要求優先） | 長い | ○ 伸びている | **型式証明が不要（軍用機は別体系）**。開発費を稼ぐ受け皿になっている |

> 2026年に起きている静かな地殻変動：**eVTOL各社が防衛に寄り始めた**。
> 型式証明を待たずに売上が立ち、しかも開発費を政府が負担してくれるから。
> 「都市の空を変える」という当初の物語からは遠いが、**資金繰りの現実解**になっている。

## 7. 資金繰り：脱落した企業と、残っている企業

認証可能な機体を1機開発するには **5億〜50億ドル（およそ750億〜7,500億円）** が必要とされる（2026年、業界分析の推計）。
売上ゼロのまま10年これを払い続けられる企業だけが残る。

| 企業 | 国 | 2026年9月時点の状況 |
| --- | --- | --- |
| **Lilium** | 独 | **破綻**。2024年10月に自主管理手続き、その後支払不能に。2026年4月までに試作機が解体されたと報じられる。ダクテッドファン30基という野心的方式が認証と資金の両面で重荷になった |
| **Volocopter** | 独 | **破綻**。2024年12月に破産申請。中国系資本を経て Diamond Aircraft のポートフォリオ下で再建中と報じられる。知的財産は国外へ流出 |
| Joby Aviation | 米 | 存続。手元現金・短期投資 約23億ドル（2026年、同社開示）。トヨタが出資・量産で関与。Blade（ヘリ旅客事業）を買収して運航の足場を確保 |
| Archer Aviation | 米 | 存続。Stellantisが量産で関与。2026年内の米国運航開始を目標と発表 |
| BETA Technologies | 米 | 存続。貨物・充電網から入る戦略。2026年7月にFAAのeIPPで初飛行 |
| EHang | 中 | **唯一の有償商用運航**。型式証明・生産証明・運航証明を取得済み |
| SkyDrive | 日 | 存続。2026年8月に第三者割当増資。2028年の商用化を目標 |

**Lilium と Volocopter の破綻は、この業界の性格を露わにした**。
どちらも技術的には飛んでいたし、受注も積んでいた。それでも**認証が終わる前に現金が尽きた**。

```
   現金 ▲
        │╲
        │ ╲ 開発費（毎年数百億円）
        │  ╲
        │   ╲        ← ここで増資できないと終わる
        │    ╲         Lilium / Volocopter が落ちた場所
        │     ╲___
        │         ╲___ 型式証明 ← 売上が立ち始めるのはここから
        └────────────────────────────▶ 時間（10年以上）
                                  ↑
     受注残（プレオーダー）は積み上がるが、多くは拘束力の弱い意向表明で、
     現金にならない。「◯◯機の受注」という報道は、売上の裏付けにならない。
```

> **プレオーダーの読み方**：この業界の「◯◯機を受注」は、ほとんどが
> **拘束力のない意向表明（LOI／MOU）か、少額の内金のみ**。SkyDriveの「7カ国380機超」も同じ性格。
> キャンセル自由なので、**受注残の数字では企業の健全性は測れない**。見るべきは**手元現金÷年間の現金流出**。

## 8. まとめ：成立条件を3つに畳む

1. **電池が長寿命・高密度になること**。時間あたりコストの最大項目であり、航続の天井でもある → [01_機体の技術と物理的制約](01_機体の技術と物理的制約.md)
2. **降りる場所が都心に確保できること**。用地と騒音の合意形成であり、技術で解けない
3. **パイロットを外せること**。これが達成されるまで、1席1万円台には届かない → 日本の想定は2030年代後半

この3つが揃うまでは、**観光・空港アクセス・医療搬送・離島といった「値段が高くても成立する用途」で細く回す**のが現実的な姿になる。
「マイカーのように空を飛ぶ」という当初の物語は、少なくとも2030年代の間は実現しない。

## 用語メモ

- **バーティポート**：eVTOLの離着陸場。ヘリポートより充電設備と旅客設備が必要で、規模が大きい
- **FATO / TLOF**：Final Approach and Take-Off area／Touchdown and Lift-Off area。離着陸場の中核区域
- **ブロックタイム**：出発地で動き出してから到着地で止まるまでの時間。実飛行時間より長い
- **搭乗率（ロードファクター）**：座席の埋まり具合。運航業の採算を決める最重要指標 → [航空](../../13_運輸・物流/02_航空/README.md)
- **LOI / MOU**：Letter of Intent／Memorandum of Understanding。拘束力の弱い意向表明。受注と混同されやすい
- **キャッシュランウェイ**：手元現金÷年間の現金流出額。「あと何年もつか」。売上ゼロの業界ではこれが企業評価の中心
- **型式限定**：操縦士免許に付く、特定機種を操縦してよいという資格。機種ごとに訓練と審査が要る
- **Powered-Lift SFAR**：米FAAが2024年に定めた動力揚力機の運航・訓練の特別規則
- **ドクターヘリ**：救急医療用ヘリコプター。eVTOLが置き換えを狙う数少ない「高単価が正当化される」用途
