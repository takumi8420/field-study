# 産業構造と日本勢の位置

**このノートで分かること**：XRデバイスとメタバースサービスが、誰から誰へ流れて出来上がっているのか。
どこに利益が集まり、どこが薄利なのか。そして日本企業はその中のどこにいるのか。

先に要点を書くと、**日本勢は「部材とコンテンツでは強く、端末とプラットフォームでは不在」**。
これは半導体やスマートフォンで見た構図とほぼ同じで、XRでも繰り返されている。

## 1. バリューチェーンの全体像

```
【川上：部材】                【中流：端末】        【川下：ソフトとサービス】
                                                  │
半導体（SoC）─┐                                  │
 Qualcomm     │                                  │
              ├─▶ ODM/EMS ─▶ ブランド ─▶ 販売 ─▶│─▶ OS/ストア ─▶ コンテンツ ─▶ 利用者
ディスプレイ ─┤   Goertek     Meta               │   Horizon OS    ゲーム
 ソニー,BOE   │   Luxshare    Apple              │   visionOS      訓練SaaS
              │   Pegatron    Samsung            │   Android XR    設計ツール
光学部品 ────┤              EssilorLuxottica     │   SteamVR
 導光板,レンズ │              XREAL, RayNeo       │
              │                                  │
センサ/電池 ──┘                                  │
 ソニー(CIS)                                      │
                                                  │
  ← 利益率は高いが数量に依存 →  ← 赤字が続いた →  ← 取り分が集まる ─▶
```

**端末ブランドが最も苦しい層**というのがXRの特徴。
Metaは端末を原価割れ近くで売り、ソフトで回収する戦略を取ったが、台数が伸びず回収に至らなかった
（[02_ブームと失速の総括](02_ブームと失速の総括.md)）。
一方で部材メーカーは、売れた分だけ確実に儲かる。

## 2. 各層で誰が何を持っているか

| 層 | 主なプレイヤー | 集中度 | 日本勢の位置 |
| --- | --- | --- | --- |
| **SoC（頭脳のチップ）** | Qualcomm（Snapdragon XRが事実上の標準）、Apple（自社Mシリーズ） | 極めて高い | 不在 |
| **ディスプレイ** | ソニーセミコン（マイクロOLED）、BOE・SeeYA・Visionox（中）、Samsung Display | 中〜高 | **強い（マイクロOLED）** |
| **イメージセンサ** | ソニーセミコン、OmniVision | 高い | **強い** |
| **光学（レンズ・導光板）** | 大立光電（台）、Lumus（イスラエル）、Schott（独）、水晶光電（中） | 分散 | 一部（ニコン、キヤノン、HOYAなどが素材・加工で参画） |
| **組立（ODM/EMS）** | Goertek、Luxshare、Pegatron（いずれも中・台） | 高い | 不在 |
| **端末ブランド** | Meta、Apple、Samsung、Sony、XREAL、RayNeo、Pico | 中 | **ソニー（PSVR2）のみ** |
| **OS／ストア** | Meta Horizon OS、visionOS、Android XR、SteamVR | 極めて高い | 不在 |
| **コンテンツ・IP** | ゲーム各社、アニメ・VTuber関連、産業SaaS | 分散 | **強い（IPとアバター文化）** |

> 半導体と同じ構図。**「川上の部材」と「川下のコンテンツ」に日本の強みがあり、真ん中の端末とOSにいない**。
> 真ん中を取れないと、需要の主導権を握れず、部材も相手の設計変更に振り回される。

## 3. コストはどこに乗っているか

XRヘッドセットの原価構成は、機種の性格でまったく違う。おおまかな傾向は次のとおり。

| 部材 | VR/MRゴーグルでの比重 | ARグラスでの比重 | 備考 |
| --- | --- | --- | --- |
| ディスプレイ | 大（20〜35%） | 大 | マイクロOLED採用機は跳ね上がる |
| 光学系（レンズ／導光板） | 中 | **最大（30〜50%）** | 導光板は歩留まりが悪く高コスト |
| SoC・メモリ | 大 | 中 | Snapdragon系が標準 |
| センサ・カメラ | 中 | 中 | 台数が多い（4〜12個） |
| 電池・筐体・その他 | 中 | 小 | ARは電池を小さくして軽さを取る |

- **推計値であり、機種により大きく変わる**。分解調査（ティアダウン）記事ごとに数字が食い違う点に注意
- ARグラスで導光板の比率が突出するのが構造的な特徴。
  ここのコストが下がらない限り、**表示付きARグラスは安くならない**

```
  同じ「XRデバイス」でも経済が違う
  ────────────────────────────────────────────────
  VR/MRゴーグル : 部材も設計もスマホの延長 → 量産効果が効く
  ARグラス      : 光学が特殊で歩留まりが低い → 量産効果が効きにくい
  AIグラス      : ディスプレイも光学も要らない → 一気に安くなった
                   ↑ 2025〜26年に数量が伸びた理由はここ
```

## 4. プラットフォーム層：3陣営に整理された

| 陣営 | OS | 端末 | 戦略 |
| --- | --- | --- | --- |
| **Meta** | Horizon OS | Quest、Ray-Ban Meta、Ray-Ban Display | 台数を優先して安く売る。AIグラスへ軸足を移した |
| **Apple** | visionOS | Vision Pro | 高価格・高品質。法人用途へ寄せている |
| **Google／Samsung** | Android XR | Galaxy XR、各社グラス | スマホと同じ「OSを配って端末は各社に作らせる」型 |

もうひとつ**Steam（Valve）**がPC接続VRの流通を握っている。台数は小さいが、
PC VRゲームの販売チャネルとしては依然中心。

> プラットフォーム層の取り分は、アプリ売上の3割前後（ストア手数料）が基本。
> ただし**インストールベースが小さいと手数料の絶対額も小さい**ため、
> XRではこのモデルがまだ自立していない。ゲーム業界の構造と比べると分かりやすい
> （[ゲーム](../../04_情報通信・IT・ネット/10_ゲーム/README.md)）。

## 5. 日本勢の実像

### 強い場所

| 企業 | 領域 | 内容 |
| --- | --- | --- |
| **ソニーセミコンダクタソリューションズ** | マイクロOLED、イメージセンサ | XR向けマイクロOLEDの主要供給者。0.44型フルHDで最大10,000cd/m²を2024年に商品化 |
| **ソニー（PSVR2）** | 端末・コンテンツ | 家庭用ゲーム機と組む唯一の日本製VR。有機EL＋アイトラッキング |
| **ニコン、キヤノン、HOYA、AGC** | 光学・ガラス | レンズ設計、ガラス素材、加工。導光板向け高屈折率ガラスは素材勝負 |
| **セイコーエプソン** | シースルーグラス | MOVERIOで長年ARグラスを製品化。産業用途に強い |
| **村田製作所、TDK、日本電産ほか** | 電子部品 | センサ、アクチュエータ、電池周辺。XR特需というより汎用部材として |
| **バンダイナムコ、スクウェア・エニックス、カプコンほか** | コンテンツ | IPの強さ。VR専用よりもマルチ展開で参画 |
| **VTuber／アバター関連（カバー、ANYCOLOR等）** | 文化・経済圏 | アバターを介した活動で世界的に先行。VRChatの日本ユーザー比率も高い |

### 弱い／不在の場所

- **SoC**：Qualcomm一強。日本企業の参入余地は実質ない
- **OS・ストア**：米国3陣営で決着しつつある
- **端末の量産（EMS/ODM）**：中国・台湾勢が担う
- **プラットフォーム型サービス**：国内メタバースサービスは多数生まれたが、規模で海外に届いていない

## 6. 中国勢の台頭

見落とされがちだが、2025〜2026年のXRハードで最も動いているのは中国勢。

- **XREAL、RayNeo（TCL傘下）、Rokid、Viture**：ディスプレイ付きグラスで世界の出荷数量を伸ばした
- **Goertek、Luxshare**：組立の中心。設計能力も持ち始めている
- **BOE、SeeYA、Visionox**：マイクロOLEDでソニーを追う。価格で攻める
- **Pico（ByteDance傘下）**：VRゴーグルで中国内シェアを持つ

**部材から組立まで国内で完結できる**のが中国勢の強みで、ここはスマートフォンで起きた展開の再現に近い。
日本の部材メーカーにとっては、顧客が中国勢に置き換わるリスクと商機の両方がある。

## 7. 収益モデルの整理

| プレイヤー | 何で儲けるか | コストの中心 | 利益の出方 |
| --- | --- | --- | --- |
| 部材メーカー | 部品単価×数量 | 設備投資、歩留まり | **端末が売れた分だけ確実に出る**。設計変更リスクあり |
| 端末ブランド（普及型） | 本体は薄利、ストア手数料で回収 | 開発費、販売促進、赤字補填 | インストールベースが閾値を超えるまで赤字 |
| 端末ブランド（高価格型） | 本体の粗利 | 高価な部材 | 台数が出ないため事業規模が小さい |
| プラットフォーマー | アプリ売上の3割前後 | OS開発、開発者支援 | 台数依存。XRではまだ小さい |
| 産業XRベンダー | SaaS月額＋開発受託 | エンジニア人件費、3D制作 | **受託比率が高いと利益率が伸びない**のが共通課題 |
| コンテンツ | 販売・アイテム課金 | 制作費 | VR専用は回収が難しく、マルチ展開が前提に |

産業XRベンダーの課題は、**顧客ごとに作り込みが要るため受託業になりやすい**こと。
3D生成AIがこの制作コストを下げられるかが、この層が製品会社になれるかの分かれ目になる。

## 用語メモ

- **SoC**：System on a Chip。CPU・GPU・通信などを1つに載せたチップ。XRではSnapdragon XRシリーズが標準
- **ODM／EMS**：他社ブランド製品の設計込み受託／製造受託。XRはGoertek・Luxshareが中心
- **マイクロOLED（OLEDoS）**：シリコン基板上に有機EL層を作った超高精細ディスプレイ
- **導光板（ウェーブガイド）**：ARグラスで映像を目の前まで運ぶ薄板。原価と歩留まりの最大の壁
- **インストールベース**：市場に出回って実際に使われている端末の総数。プラットフォームの価値を決める
- **ティアダウン**：製品を分解して部材と原価を推定する調査。数字は推計で幅がある
- **テイクレート**：プラットフォームが取引額から取る手数料率。アプリストアでは3割前後が基準
