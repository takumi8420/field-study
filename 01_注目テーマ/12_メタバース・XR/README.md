# メタバース・XR

- 大分類: 注目テーマ
- 状態: done
- 更新日: 2026-09-19

一言でいえば、**「頭や目に機器を付けて、現実の上にCGを重ねたり、CGの中に入ったりする技術と、その上の経済圏」**。
2021〜22年に「次のインターネット」として過熱し、2023年以降に急速に冷えた。
2026年時点の実像は、**消費者向けVRは縮小、産業用途は定着、数量はAIスマートグラスが牽引**という三層構造にある。
関心と資金の多くは生成AIへ移ったが、近年は**AIがXRのコストを下げる補完関係**へ変わり始めている。

## 1. 業界の定義・範囲

XR（Extended Reality）は VR・AR・MR の総称。メタバースは「3D仮想空間で複数人が同時に活動する環境」を指すが、
**定義が論者によって大きく揺れる**ため、数字を読むときは必ず何を数えているか確認する必要がある。

| 含む | 含まない（隣接） |
| --- | --- |
| VR/MRヘッドセット、ARグラス、AIスマートグラス | スマホ単体のARアプリ → [PC・スマートフォン](../../03_電機・電子部品/11_PC・スマートフォン/README.md) |
| XR向けディスプレイ・光学部品・センサ | ディスプレイ産業一般 → [ディスプレイ](../../03_電機・電子部品/07_ディスプレイ/README.md) |
| 仮想空間プラットフォーム（VRChat等） | オンラインゲーム一般 → [ゲーム](../../04_情報通信・IT・ネット/10_ゲーム/README.md) |
| 産業XR（訓練・遠隔支援・設計レビュー） | 産業用ロボットの遠隔操作 → [ロボット](../09_ロボット/README.md) |
| アバター文化・バーチャルイベント | NFT・暗号資産そのもの → [フィンテック・キャッシュレス](../../04_情報通信・IT・ネット/13_フィンテック・キャッシュレス/README.md) |

デバイスは4類型で捉えると混乱しない。ここだけ先に押さえるとニュースが読める。

```
 ① VR/MRゴーグル      Quest 3, PSVR2       500〜700g  3〜8万円   ゲーム・訓練
 ② 空間コンピュータ    Vision Pro, Galaxy XR 550〜800g 25〜55万円 作業・法人検証
 ③ 表示付きグラス      Ray-Ban Display       50〜130g  5〜12万円  通知・字幕
 ④ 表示なしAIグラス    Ray-Ban Meta          50g前後   4〜5万円   撮影・音声AI
                                              └─ 2025〜26年に数量が伸びたのはここ
```

**④は映像を出さない**ため、厳密にはXRデバイスではない。統計上XRに算入されるので数字は伸びるが、
中身が入れ替わっている点が、この分野の数値を読むときの最大の注意点になる。

## 2. 市場規模と成長性

| 指標 | 数値 | 年・出典 |
| --- | --- | --- |
| AR/VR＋スマートグラス 世界出荷 | 約1,360万台、売上 約51億ドル | 2026年通年見通し、IDC推計 |
| 同 2030年 | 約2,730万台（年平均成長率18.9%） | IDC推計 |
| スマートグラス出荷（表示なし中心） | 約225万台、前年同期比 ＋167% | 2026年Q1、IDC推計 |
| Ray-Ban Meta（AIグラス）販売 | 2025年に700万本超（2023〜24年合計は200万本） | EssilorLuxottica公表、2026年2月 |
| 国内メタバース市場 | 2024年度 約2,750億円（前年度比＋47.6%） | 民間調査会社の推計 |
| Meta Reality Labs 累計営業損失 | 800億ドル超（2026年4月時点） | 同社決算に基づく報道 |

> **数値の読み方に注意が要る分野**。「メタバース市場◯兆円」という予測の多くは、
> メタバース経由で動く経済全体（小売・広告・エンタメを含む）を数えたもの。
> ブーム期には「2026年度に国内1兆円超」という予測もあったが、実績はそこに届いていない。
> **端末出荷台数のように定義が固い指標**で見るほうが実態に近い。

## 3. バリューチェーン（川上 → 川下）

```
【部材】                    【端末】              【ソフト・サービス】
SoC ─ Qualcomm ─┐
ディスプレイ ─ ソニー,BOE ─┤
光学（導光板・レンズ）─────┼─▶ ODM/EMS ─▶ ブランド ─▶│─▶ OS/ストア ─▶ コンテンツ ─▶ 利用者
センサ ─ ソニー ───────────┤   Goertek     Meta        │  Horizon OS   ゲーム
電池・筐体 ────────────────┘   Luxshare    Apple      │  visionOS     訓練SaaS
                                              Samsung   │  Android XR   設計ツール

  売れた分だけ確実に儲かる      赤字を出し続けた層       台数が出れば取り分が集まる
```

**端末ブランドが最も苦しい層**というのがXRの特徴。Metaは端末を薄利で売りソフトで回収する戦略を取ったが、
台数が伸びず回収に至らなかった。逆に部材メーカーは数量に比例して儲かる。詳細は
[04_産業構造と日本勢](04_産業構造と日本勢.md)。

## 4. 主要プレイヤーとシェア

| 企業 | 立ち位置 | 特徴 |
| --- | --- | --- |
| Meta（米） | 端末＋OS＋コンテンツの垂直統合 | スマートグラス世界シェア69.2%（2026年Q1、IDC推計）。VRは大幅縮小 |
| EssilorLuxottica（仏伊） | 眼鏡ブランドと製造 | Ray-Banブランドと量産を担う。AIグラスの成功の半分はここ |
| Apple（米） | 高価格の空間コンピュータ | Vision Pro。2026年は法人向けに軸足を寄せる |
| Google／Samsung（米韓） | Android XR陣営 | Galaxy XR（1,799ドル）が第1号機。「OSを配る」スマホ型の戦略 |
| Qualcomm（米） | XR向けSoC | Snapdragon XRが事実上の業界標準。参入余地がない層 |
| ソニー（日） | 部材＋端末＋コンテンツ | マイクロOLEDとイメージセンサで川上に強い。PSVR2は唯一の日本製VR機 |
| XREAL／RayNeo／Rokid／Viture（中） | 表示付きグラス | 2026年Q1で各2〜3%台のシェア。価格で攻める |
| Goertek／Luxshare（中） | 組立（ODM/EMS） | XR端末の製造を担う |
| Roblox／Epic Games（米） | プラットフォーム | UGC経済圏として最大規模。VR機は必須にしていない |
| VRChat（米） | VRネイティブのソーシャル | 2026年元旦に同時接続 約14.9万人。日本ユーザー比率が約27% |
| Microsoft（米） | 産業用MRから後退 | HoloLens 2生産終了、後継ロードマップ未提示（報道ベース） |

※XR市場は非上場企業が多く、シェアの厳密な統計は存在しない。**出荷台数で比較する**のが実務的。

## 5. 収益モデル・コスト構造

| プレイヤー | 何で儲けるか | コストの中心 | 利益の出方 |
| --- | --- | --- | --- |
| 部材メーカー | 部品単価×数量 | 設備投資、歩留まり | 端末が売れた分だけ確実に出る |
| 端末ブランド（普及型） | 本体は薄利、ストア手数料で回収 | 開発費、販促、赤字補填 | 台数が閾値を超えるまで赤字。Metaは超えられなかった |
| 端末ブランド（高価格型） | 本体の粗利 | 高価な部材（マイクロOLED等） | 台数が出ず事業規模が小さい |
| プラットフォーマー | アプリ売上の3割前後 | OS開発、開発者支援 | インストールベース依存。XRではまだ自立せず |
| 産業XRベンダー | SaaS月額＋開発受託 | エンジニア人件費、3D制作費 | 受託比率が高く利益率が伸びにくい |
| コンテンツ | 販売・アイテム課金 | 制作費 | VR専用は回収困難。マルチ展開が前提に |

> この分野を貫くクセ：**先行投資が巨額で、回収がインストールベース（普及台数）に依存する**。
> 台数が出ないと開発者が来ず、コンテンツが薄いと台数が出ない。
> このニワトリと卵を、Metaは5年・800億ドル超を投じても解けなかった。

## 6. 競争要因（KSF）と参入障壁

**KSF**
1. **重さと電池の解**：物理的制約を解いた設計ができるか。ここが体験時間を決める
2. **普及台数（インストールベース）**：開発者とコンテンツを引き寄せる唯一の資産
3. **光学部品の調達力**：導光板はARグラスの原価の3〜5割を占め、歩留まりが悪い
4. **既存の顔の上のブランド**：メガネは工業製品である前にファッション。Ray-Banの成功はここ
5. **B2Bでは費用対効果の説明力**：既存の出張費・事故損失と比較できるか

**参入障壁**
- SoCはQualcommに実質依存し、OSは米系3陣営で固まりつつある
- マイクロOLEDと導光板は量産のハードルが高く、供給者が限られる
- 端末は赤字を数年吸収できる資本がないと続かない（実際に多くの企業が撤退した）

## 7. 規制・法制度

XRに専用の業法はない。既存の制度が用途ごとに適用される形になっている。

| 領域 | 適用される制度・論点 |
| --- | --- |
| 医療での利用 | 診断・治療に使うなら**医療機器としての承認・届出**が必要。参照・教育目的なら対象外 |
| 撮影機能 | カメラ付きグラスは**肖像権・プライバシー**の論点。撮影中のLED表示などが業界慣行に |
| 青少年保護 | 仮想空間内のハラスメント・年齢確認。総務省の研究会で論点整理が進む |
| アバターの権利 | 肖像・著作権の扱いが未整備。文化庁・総務省で検討 |
| 決済・資産 | 仮想通貨や仮想土地を扱う場合は資金決済法等の対象になり得る |
| 労働安全 | 装着作業中の安全確保、VR酔いへの配慮 |
| 電波・技適 | 無線を使う端末は各国の認証が必要（日本は技術基準適合証明） |

日本では**産業政策として大型の基金が付いている分野ではない**。
総務省が『情報通信白書』と研究会で利用者保護とルール整備を進めるのが主な関与の形になっている。

## 8. 最近のトピック

詳細は [05_直近トピック_2026](05_直近トピック_2026.md) に出典URL付きでまとめた。要点は5つ。

1. **Meta Reality Labsが大幅縮小**。2026年にVRスタジオ3社閉鎖、法人向けQuest販売終了、Horizon Worldsのヘッドセット版終了。累計損失は800億ドル超（同社決算に基づく報道）
2. **数量の牽引役はスマートグラス**。2026年Q1で前年比＋167%、約225万台。Metaがシェア69.2%（IDC推計）。ただし**映像を出さないAIグラス**が主体
3. **端末は3陣営に収束**。Meta（Horizon OS）、Apple（visionOS、法人へ軸足）、Google/Samsung（Android XR）
4. **産業用MRのハード供給に空白**。HoloLens 2生産終了で後継がなく、現場要件を満たす機器が買いにくい
5. **AIとの関係が競合から補完へ**。GoogleのProject Genie（2026年1月）など、3D空間の生成がXR最大のコスト要因を下げる可能性
