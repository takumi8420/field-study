# 直近トピック（2026年9月時点）

報道ベースの整理。数値は出典と年月をセットで示し、確定事実と推計・報道を区別している。
一次情報（各社決算・公式発表）で裏取りできるものはその旨を記した。

**この1年の一言まとめ**：XRの主役が**ゴーグルからメガネへ、そしてVRからAIへ**入れ替わった年だった。

## 1. Meta Reality Labs が大規模に縮小した

2026年に入り、MetaのXR部門で撤退・縮小が連続した。

| 時期 | 内容 | 情報の性質 |
| --- | --- | --- |
| 2026年1月 | Reality Labs で約1,500人を削減。VRゲームスタジオ3社（Sanzaru Games、Twisted Pixel、Armature Studio）を閉鎖 | 報道ベース |
| 2026年2月 | 法人向けQuest販売を2月20日で終了、VR会議「Horizon Workrooms」を2月16日で終了 | 報道ベース |
| 2026年3月 | 主力ソーシャル空間「Horizon Worlds」をヘッドセットから削除し、スマホ版へ集約 | 報道ベース |
| 2026年4月 | 第1四半期のReality Labs営業損失 約40億ドル。2020年末以降の累計は800億ドル超 | 同社決算に基づく報道 |
| 2026年 | 第2四半期も約46億ドルの損失。累計880億ドル規模へ | 報道ベース |
| 2026年 | Reality Labs 予算を最大30%削減する方針と報じられる | 報道ベース |

同社CTOは「VRは死んでいない」と述べており、完全撤退ではない。
ただし優先順位は明確に**AIスマートグラス側**に移っている。
同社は2026年にAI関連へ1,090億ドル規模を投じる見通しとも報じられ、**資金の行き先が置き換わった**形。

> 読み方：これはメタバースという構想の断念というより、
> 「**2026年に金を生むのはVRではなくAIグラス**」という経営判断。
> 構想としてのメタバースは長期ビジョンとして残されている。

## 2. スマートグラスが市場を牽引した

XR市場の数量を押し上げたのは、ゴーグルではなく**ディスプレイを持たないAIグラス**だった。

| 指標 | 数値 | 年・出典 |
| --- | --- | --- |
| スマートグラス世界出荷（Q1） | 約225万台、前年同期比 **＋167%** | 2026年Q1、IDC推計 |
| Metaのスマートグラス世界シェア（Q1） | **69.2%** | 2026年Q1、IDC推計 |
| AR/VR＋スマートグラス通年出荷見通し | 約1,360万台、売上51億ドル | 2026年、IDC推計 |
| 同 2030年見通し | 2,730万台（年平均成長率18.9%） | IDC推計 |
| Ray-Ban Meta（AIグラス）販売 | 2025年に**700万本超**。2023〜24年の合計200万本から3倍超 | EssilorLuxottica公表（2026年2月） |
| 生産能力目標 | 2026年末までに年2,000万台、需要次第で3,000万台超も | 報道ベース |

シェア2位以下はRayNeo（3.4%）、Xiaomi（3.1%）、Viture（2.5%）、XREAL（2.0%）と、
**中国勢が並ぶ**（2026年Q1、IDC推計）。

```
  XR市場の「中身の入れ替わり」
  ───────────────────────────────────────────
  2022年   VRゴーグル ████████████  AR/グラス ██
  2026年   VRゴーグル ████          AR/グラス ████████████
                 ↓                        ↓
            台数が伸びない          表示なしAIグラスが急増
```

注意点：**この数字の伸びは「XRの復活」ではない**。
数量の大半を占めるAIグラスは映像を表示せず、厳密にはXR（拡張現実）体験を提供していない。
統計の定義上XRに算入されているだけで、中身は「カメラと音声AIを積んだメガネ」に近い
（[01_デバイスの技術](01_デバイスの技術.md) の類型④）。

## 3. 3陣営の端末競争：Apple は法人へ、Google/Samsung が参入

- **Apple Vision Pro**：2026年はM5チップ搭載版。visionOSのアップデートでMDM（端末管理）強化など
  法人向け機能を厚くしており、**訴求を消費者から企業へ寄せている**と分析されている（報道ベース）。
  重量と視野角という課題は未解決のまま
- **Samsung Galaxy XR**：1,799ドル。GoogleのAndroid XRを載せた第1号機。
  Vision Proのほぼ半額で同等クラスのハードという位置づけ。2025年の販売は約4万台との推計もあり、
  **どちらも数量はまだ極小**
- **Meta Ray-Ban Display**：2025年発売、799ドル。片眼に小型ディスプレイを載せ、
  手首の筋電センサ（神経信号を読むリストバンド）で操作する。
  ディスプレイ付きグラスを一般向け価格帯に下ろした点が転換点

> 3陣営が揃ったことで、**XRのOS競争はスマートフォンと同じ構図（iOS／Android／独自）**に収束した。
> ただし台数が桁違いに小さいため、開発者がどこに集まるかはまだ決していない。

## 4. HoloLens 後継の空白と、産業用MRの供給不安

- Microsoft は **HoloLens 2 の生産を終了**し、2026年時点で後継機のロードマップを示していない（報道ベース）
- 国内で扱っていたNTTドコモも2026年1月に取扱終了を告知したと報じられる
- 産業・医療の現場では、代替としてMeta Quest 3やApple Vision Proが使われるが、
  **防塵・ヘルメット併用・長時間装着といった現場要件を満たさない**という指摘が続いている
- 空白を埋める動きとして、日本のHMS社が産業用MRデバイス「SiNGRAY G2」を2026年に公開

> 産業XRの最大のリスクが「良いユースケースがないこと」から
> 「**要件を満たすハードを買えないこと**」へ移った、というのがこの1年の変化。

## 5. 生成AIとの接続が本格化した

XRとAIの関係は、**投資を奪い合う関係から、AIがXRのコストを下げる関係**へ変わり始めた。

| 動き | 内容 | 時期 |
| --- | --- | --- |
| **Google Project Genie** | 世界モデル「Genie 3」をもとに、文章から操作可能な3D空間をリアルタイム生成。720p/24fps、1セッション約60秒 | 2026年1月提供開始（米国、Google AI Ultra加入者向け） |
| **Waymo World Model** | Genie 3を自動運転シミュレーションに転用 | 2026年2月 |
| **AIグラス** | 音声AIを常時使える端末として、XRハードで唯一数量が伸びた | 2025〜2026年 |

XRの最大のコストは長く**3Dコンテンツの制作費**だった。訓練用の工場も、仮想空間の街も、人が作っていた。
世界モデルがここを肩代わりできれば、産業XRベンダーが受託業から製品会社に移る道が開ける
（[04_産業構造と日本勢](04_産業構造と日本勢.md) の6節）。

ただし2026年9月時点の生成品質は**数十秒・低解像度**の段階で、業務利用には遠い。
「方向性が見えた」段階であり、実装が進んだ段階ではない。

## 6. プラットフォームは静かに堅調

派手な話題がない一方、実際に人が集まっている場は数字を伸ばしている。

| サービス | 状況 | 出典の性質 |
| --- | --- | --- |
| **VRChat** | 2026年元旦に同時接続 約14万8,886人の過去最高。前年比＋9%。日本ユーザー比率が約27% | コミュニティによる集計・報告 |
| **Roblox** | 日次利用者1億人規模。UGC経済圏として最大級 | 同社IR |
| **Fortnite** | クリエイター向け機能を拡張し、「体験を配信するインフラ」へ性格を広げる | 報道・同社発表 |
| **Horizon Worlds** | ヘッドセット版終了、スマホ版へ集約 | 報道ベース |

VRChatが伸びている点は見落とされやすい。**ブームの後も文化として定着した**例で、
日本語圏の比率が高いことも含め、国内の強みが表れている領域といえる。

## 7. 日本の市場と政策

- **国内メタバース市場**：2024年度に約2,750億円（前年度比＋47.6%）という民間調査の推計がある。
  2028年度に1兆円超という予測も併記されるが、**調査会社ごとに定義と数値の幅が大きい**
- ブーム期には「2026年度に1兆円超」という予測もあったが、実績はそこに届いていない。
  **予測の下方修正が繰り返された**ことは、この分野の数字を読むときの前提として重要
- **総務省**は「Web3時代に向けたメタバース等の利活用に関する研究会」で、
  アバターの権利、青少年保護、相互運用性などの論点整理を進めてきた
- 『情報通信白書』は令和5年版以降、継続してメタバースの節を設けている

> 政策面では、メタバースを産業政策として大きく推すというより、
> **利用者保護とルール整備に軸足がある**のが日本の特徴。
> 宇宙やGXのような大型の基金は付いていない。

## 8. 全体の構図

2026年時点のXR・メタバース産業は、次の4行でほぼ説明できる。

1. **消費者向けVRは縮小局面**。最大の投資家だったMetaが自社スタジオを閉じ、法人VRからも撤退した
2. **数量はAIグラスが牽引**。ただしそれは映像を出さない端末で、XR体験の普及とは意味が違う
3. **産業用途は着実に残った**。訓練・遠隔支援・設計・医療で費用対効果が説明できる案件は継続している
4. **AIとの関係が競合から補完へ**。3D生成と世界モデルが、XR最大のコスト要因を下げる可能性が出てきた

```
  2026年のXR・メタバース産業（4つの箱）
  ────────────────────────────────────────────────────────
  消費者向けVR   ▼縮小   Metaが自社スタジオ閉鎖・法人VR撤退
  AIスマートグラス ▲急増  +167%（26年Q1、IDC推計）※映像は出さない
  産業XR         →横ばい 訓練・遠隔支援・設計・医療は継続。ハード供給に空白
  仮想空間SNS    →堅調   VRChat 同時接続14.9万人、Roblox/Fortniteは別格
  ────────────────────────────────────────────────────────
        ▲                                      ▲
        │ 資金と人材は2023年に生成AIへ流出      │ 2026年はAIが3D制作費を下げる側へ
        └───────── 競合関係 ──────▶ 補完関係 ──┘
```

一言でいえば、**「メタバース」という言葉は退場し、XRは部品と業務用途として生き残った**年だった。

## 用語メモ

- **Reality Labs**：MetaのXR・ウェアラブル部門。決算で独立開示されるため業界の体温計になる
- **Android XR**：GoogleのXR向けOS。Samsung Galaxy XRが第1号機
- **世界モデル（world model）**：環境の構造をAIが内部に持ち、次に起きることを予測する仕組み
- **筋電センサ（sEMG）**：皮膚表面から筋肉の電気信号を読む。Ray-Ban Displayの操作手段
- **MDM**：Mobile Device Management。企業が端末を一括管理する仕組み。法人導入の前提条件
