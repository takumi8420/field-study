再生医療・ゲノム

学習済み更新 2026-09-20注目テーマ

一言でいえば、「細胞や遺伝子そのものを"薬"として使う産業」と、
「遺伝情報を読んで治療を選ぶ医療」の2本立てである。
前者は製造（＝細胞を培養すること）が最大の難所、後者は読んだ後のデータと制度が争点になる。

この分野は期待が先行しやすい。本フォルダは次の3点を方針とする。

  1. 承認済み／治験中／研究段階を毎章はっきり分ける。「できる」と「できるかもしれない」を混ぜない
  2. iPS細胞の現在地は冷静に書く。2026年3月の国内初承認は画期的だが、本承認ではなく仮免許であり、
    対象患者も極めて限定的である
  3. 医学的アドバイスはしない。産業構造・制度・経済の観点に徹する

1. 業界の定義・範囲

「再生医療・ゲノム」は、狭い意味では再生医療等製品（細胞加工製品＋遺伝子治療用製品）という
薬機法上のカテゴリと、ゲノム医療（遺伝情報を読んで診断・治療選択に使う医療）を指す。

含む 含まない（隣接）
幹細胞由来の細胞・組織製品（iPS、ES、体性幹細胞）一般の医薬品開発 → 医薬品（新薬）
細胞治療（CAR-T などの免疫細胞治療）抗体医薬・低分子薬
遺伝子治療（AAV・レンチウイルスなどのベクター使用）核酸医薬（隣接だが遺伝情報は書き換えない）
ゲノム編集（CRISPR 等）の医療応用農業・工業のゲノム編集（食品分野） → フードテック
受託製造（細胞・遺伝子治療CDMO）一般の医薬品CDMO → CRO・CDMO
がん遺伝子パネル検査・全ゲノム解析一般の臨床検査 → 臨床検査・検査受託
培養装置・シングルユース資材・シーケンサー医療機器一般 → 医療機器
（周辺）自由診療の幹細胞治療・PRP療法承認された医療とは制度上まったく別枠（後述）
【「再生医療」という言葉の中身（混同されやすい3つ）】

 ① 再生医療等製品として承認されたもの … 国が品質・有効性・安全性を審査。保険が効きうる
 ② 臨床研究・治験                      … まだ効果は確認中。研究の枠組みで実施
 ③ 再安法に基づく自由診療              … 医療機関が届出て提供。**国は有効性を認めていない**。全額自費

  ニュースやクリニックの広告が①②③のどれを指しているかで、意味が180度変わる

桁感を押さえる。世界市場全体で200〜400億ドル台であり、大手製薬1社の売上規模に近い。
しかも売上の相当部分はCAR-Tと一部の希少疾患向け遺伝子治療に集中しており、
「再生医療」のイメージにある臓器再生や老化治療は、まだ市場を作っていない。
調査会社の予測は定義が揃っていないため、単一の数字を引かず幅で読むこと。

5. 収益モデル・コスト構造

収益源 中身 経済的な特徴
製品販売（保険収載品）1回数千万〜数億円患者数が少ないため単価が高い。「治すと売上が消える」自己終息型
受託製造（CDMO）GMP施設の稼働を売る稼働率がすべて。顧客1社依存が致命傷になる
資材・装置培地、シングルユース、培養装置、シーケンサー試薬消耗品で継続課金。最も安定
検査（ゲノム）保険点数または自費公定価格に守られるか、価格競争に飲まれるかの二択
自由診療幹細胞治療・PRPなど医療機関が価格を自由に設定。制度上、承認医療とは別枠
提携・マイルストン製薬企業からの一時金・開発協力金ベンチャーの主要な資金源。売上とは別

コスト構造は「固定費の塊」。無菌製造区域の維持、訓練された人員、品質試験がほぼ固定的に発生し、
自家製品は1バッチ＝1人なのでスケールメリットが原理的に効かない。
稼働率がそのまま採算になる点で、装置産業（半導体の前工程など）と同じ構造をしている。
→ 02_作り方と値段

6. 競争要因（KSF）と参入障壁

KSF

  1. CMC（製法・品質）を確立できるか。この分野で開発が止まる最大の理由は科学ではなく製造
  2. 他家（アロ）にできるか。作り置きができるかどうかで経済性が桁で変わる
  3. in vivo にできるか。体外に細胞を出さずに済めば、製造・物流・施設要件が丸ごと消える
  4. 投与できる施設を増やせるか。承認しても病院が対応できなければ売上にならない
  5. 適応疾患の選び方。患者数が少なすぎると採算が合わず、多すぎると保険財政が拒む

参入障壁

  • GMP施設と薬事対応（数十億〜数百億円規模の投資と、査察に耐える品質保証体制）
  • ベクター供給（AAVなどは製造能力が限られ、外注枠の確保自体が競争になる）
  • 人材（細胞培養の熟練者、CMC担当、レギュラトリー人材が世界的に不足）
  • 臨床ネットワーク（希少疾患では患者を集めること自体が難しい）
  • 開発資金の長期耐久力（承認まで10〜20年。iPS細胞は樹立から初承認まで約19年かかった）

7. 規制・法制度

制度 内容
医薬品医療機器等法（薬機法）2014年11月施行の改正で「再生医療等製品」を独立カテゴリとして新設。世界に先駆けた制度
条件及び期限付承認安全性を確認し有効性が「推定」できた段階で、販売先限定などの条件と原則7年以内の期限を付けて承認する「仮免許」
再生医療等安全性確保法（再安法）医療機関が行う再生医療の提供をリスクに応じ第1〜3種に分類し、認定委員会審査＋届出を求める。臨床研究にも自由診療にも適用
再安法・臨床研究法の改正（2024年6月14日公布）細胞加工物を用いないin vivo遺伝子治療も法の対象に。認定委員会の立入検査・欠格事由を整備
ゲノム医療法（2023年6月成立）遺伝情報の適切な管理と不当な差別の防止を掲げる理念法。罰則付きの禁止規定はない
次世代医療基盤法（2018年施行、2023年改正）医療情報を匿名加工・仮名加工して研究利用する枠組み
全ゲノム解析等実行計画がん・難病患者の全ゲノム解析と、その解析基盤・利活用体制の整備
2026年度 薬価制度改革条件及び期限付承認品の営業利益率係数0.5倍、有用性系加算は算定時に判断せず、費用対効果評価は本承認後
米FDARMAT指定、Accelerated Approval に加え、2026年2月に超希少疾患向け「plausible mechanism」枠組みの案を公表と報じられる
EU（EMA）ATMP（先端医療医薬品）として中央審査。償還は加盟国ごとで普及が進みにくい

規制の重心は2つ。①どこまで早く承認するか（有効性の証拠をどこまで求めるか）と、
②高額品を保険財政がどう受け止めるか。日本は①で先行し、いま②で締めにかかっている。
→ 03_制度と承認

8. 最近のトピック

詳細は 05_直近トピック_2026 に出典URL付きでまとめた。要点は5つ。

  1. 2026年3月、iPS細胞由来製品が国内で初めて承認された（クオリプス「リハート」、住友ファーマ「アムシェプリ」）。
    世界初と報じられるが、条件及び期限付＝仮免許であり、原則7年以内に有効性の検証が要る
  2. その制度の第1号ハートシート（テルモ）は2024年に有効性を示せず失効、コラテジェン（アンジェス）も申請取り下げ。
    「早く承認する」制度は作れたが、「市販しながら検証する」ことの難しさが露呈した
  3. 世界の遺伝子治療は逆風。Sarepta のElevidysで死亡例と枠組み警告、約36%の人員削減。
    bluebird bio は承認3製品で治療開始が57人にとどまったと報じられ、「承認≠普及」が業界の総括になった
  4. 制度は日米で逆向きに動いた。日本は仮承認品の価格を抑える方向（財政重視）、
    米FDAは超希少疾患向けにプラットフォーム承認という証拠水準を下げる方向（アクセス重視）
  5. 技術の焦点は in vivo（体内で完結）へ。in vivo CAR-Tが成功すれば製造ラインが丸ごと不要になるが、
    2026年時点では臨床初期段階。承認品はない
