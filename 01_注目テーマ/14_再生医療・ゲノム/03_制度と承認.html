制度と承認｜日本の「仮免許」制度は何を変え、何を突きつけたか

注目テーマ再生医療・ゲノム
あこのページの単語集用語に触れると意味を確認できます13語
薬機法再生医療等製品再生医療等安全性確保法（再安法）PMDA条件及び期限付承認使用成績調査（市販後調査）中医協薬価収載費用対効果評価高額療養費制度RMATATMP自由診療

このノートで分かること：日本は2014年に世界に先駆けて再生医療専用の法体系を作った。
その中核が「条件及び期限付承認」＝有効性が"推定"できた段階で仮に承認する制度である。
この制度が何を可能にし、どこで躓いたのか。そして保険財政との関係を整理する。

大原則：この分野では「承認された」だけでは何も言っていない。
①どの法律に基づくのか、②本承認か仮承認か、③保険が効くのか。この3点を確認しないと意味を取り違える。

1. 日本の制度は「二階建て」になっている

2014年11月に施行された2つの法律が、この分野の骨格である。

【同じ「細胞を使う治療」でも、通る道が2本ある】

  ┌─ 道A：製品として売る ────────────────────────┐
  │  医薬品医療機器等法（薬機法）                     │
  │  「再生医療等製品」という独立カテゴリ             │
  │  → PMDAが審査 → 厚生労働大臣が承認 → 保険収載     │
  │  → 全国どこでも（条件内で）同じ製品が使える       │
  └───────────────────────────────────────────────┘

  ┌─ 道B：医療機関が自分で行う ──────────────────┐
  │  再生医療等安全性確保法（再安法）                 │
  │  リスクに応じ第1〜3種に分類 → 認定委員会の審査     │
  │  → 厚生労働大臣へ「提供計画」を届出               │
  │  → その医療機関だけで実施。**有効性は国が保証しない** │
  │  → 臨床研究にも、自由診療にも、この道が使われる    │
  └───────────────────────────────────────────────┘
観点 道A：再生医療等製品（薬機法） 道B：再生医療等安全性確保法
何を審査するか製品の品質・有効性・安全性提供計画（体制と手順）
有効性の担保国が審査して承認国は有効性を認めていない
誰が使えるか承認条件を満たす医療機関届け出たその医療機関のみ
保険収載されれば保険適用臨床研究か自由診療（全額自己負担）
価格公定薬価医療機関が自由に設定

ここが一般報道で最も混乱する点。「幹細胞治療を受けられるクリニック」の広告は道Bであり、
「iPS細胞由来製品が承認された」は道A。同じ「再生医療」という語で全く別の話をしている。

再安法の分類（リスクベース）

種別 リスク 例 審査するのは
第1種高いiPS/ES細胞由来、他家の細胞、遺伝子導入した細胞特定認定再生医療等委員会＋厚生科学審議会
第2種中自家の幹細胞を培養して使う（脂肪由来幹細胞など）特定認定再生医療等委員会
第3種低いPRP療法など、加工が軽微なもの認定再生医療等委員会
  • 2024年6月14日に再安法と臨床研究法の改正法が公布された。主な改正点は
    ①細胞加工物を使わない遺伝子治療（in vivo 遺伝子治療）も法の対象に加える、
    ②認定委員会への立入検査や欠格事由の整備、である。
    従来は「細胞を加工する」ことが法の入口だったため、体内に直接ベクターを投与する治療が法の外にあった。そこを塞いだ

2. 条件及び期限付承認＝「仮免許」

再生医療等製品は、原材料が生体由来で製品にばらつきがあり、対象が希少疾患に偏るため、
通常の治験で有効性を統計的に証明するのに非常に時間がかかる。そこで導入されたのがこの制度。

【通常の承認との違い】

 通常の医薬品：
   治験で【有効性を検証】 ──▶ 承認 ──▶ 市販

 再生医療等製品（条件及び期限付）：
   治験で【安全性を確認】＋【有効性を"推定"】 ──▶ 仮承認 ──▶ 市販しながら検証
                                                    │
                                            原則7年以内に再申請
                                                    │
                          ┌─────────────────────────┴──────────────────┐
                          ▼                                            ▼
                   有効性を示せた                              示せなかった
                   → 本承認                                    → 承認失効・取消し

付く条件の典型

  • 販売先を、専門的な医師と設備を備えた医療機関に限定する
  • 全例を対象とした使用成績調査（市販後調査）を行う
  • 患者への十分な説明と同意の取得
  • 2025年5月時点で、国内で承認された再生医療等製品は20を超えるとされる。
    2020年以降に承認数が明確に増えた
  • ただし「承認数が増えた＝実用化が進んだ」ではない。次節の2つの失敗例がそれを示している

3. 制度が突きつけた現実：ハートシートとコラテジェン

この制度を理解するうえで、成功例より失敗例のほうが情報量が多い。

製品 内容 仮承認 結末
ハートシート（テルモ）ヒト（自己）骨格筋由来細胞シート。重症心不全2015年9月。制度の第1号市販後調査49例の解析で有効性を示せず、2024年7月に部会が「承認は適切でない」と結論。承認失効・販売終了
コラテジェン（アンジェス）HGF遺伝子治療薬。重症の閉塞性動脈硬化症2019年3月市販後調査で治験結果を再現できず、2024年6月に本承認申請を取り下げ、販売終了

この2件が同じ2024年に終わったことの意味：
「早く承認する」制度は作れたが、「市販後にきちんと検証する」ほうが難しかった。
市販しながらのデータ収集では、対照群が置けず、症例をコントロールできない。
テルモは市販後調査で「症例を制御する難しさを実感した」と述べたと報じられる。
制度の批判として言われる「仮免許のまま7年売れてしまう」だけでなく、
「仮免許で売ったせいで、本免許を取るためのデータが取れなくなる」という逆説がある。

このため制度の見直し論が続いており、条件・期限付承認の運用（どういう場合に認めるか、
市販後にどう検証させるか）を明確化するガイドラインの整備が議論されている。

4. 2026年3月：iPS細胞由来製品の初承認

製品 企業 対象 中身
リハートクオリプス虚血性心筋症による重症心不全（標準治療で効果不十分）ヒト（同種）iPS細胞由来心筋細胞シート
アムシェプリ（一般名 raguneprocel）住友ファーマパーキンソン病他家iPS細胞由来ドパミン神経前駆細胞
  • 2026年2月19日に薬事審議会の再生医療等製品・生物由来技術部会が了承、3月6日に条件及び期限付承認。
    iPS細胞由来製品の承認は世界初と報じられる
  • 国内販売は2026年秋頃を計画と報じられる

冷静に読むための注意点を4つ挙げる。

  1. これは本承認ではなく「条件及び期限付」＝仮免許。原則7年以内に有効性を検証して再申請が要る。
    先のハートシート・コラテジェンと同じ土俵に立ったということでもある
  2. 対象患者は非常に限定的。リハートは標準治療で効果不十分な虚血性心筋症の重症心不全、
    アムシェプリはパーキンソン病であり、いずれも「病気が治る」という話ではない
  3. 投与できる施設が限られる。条件として販売先が限定され、加えてシート状製品は物流面の制約もある
    → 02_作り方と値段
  4. 山中伸弥氏のiPS細胞樹立（2006/2007年）から約20年。「すぐ実用化される」という2010年代の期待は、
    実際には20年かかった。この時間感覚が、次の技術を見るときの基準になる

一方で、iPS細胞の臨床応用は他にも進んでおり、加齢黄斑変性（理研ほか）、1型糖尿病（京都大学）、
再生不良性貧血（同）、外傷性脊髄損傷（慶應義塾大学）、角膜上皮幹細胞疲弊症（大阪大学ほか）などで
治験・臨床研究の段階にある。これらはまだ承認されていない。

5. 保険収載と医療財政

承認されても保険が効かなければ、日本では事実上使われない。
保険適用（薬価・材料価格の収載）は中央社会保険医療協議会（中医協）で決まる。

【日本での「患者に届くまで」の4段】

 ①治験 ──▶ ②承認（PMDA審査／厚労大臣） ──▶ ③保険収載（中医協で価格決定） ──▶ ④病院が体制を整える
                                                                                      │
   ここまでが企業とアカデミアの仕事                                 ここが最後の関門 ──┘
                                                          （施設要件・人材・設備がなければ使えない）

2026年度の薬価制度改革で、条件及び期限付承認品の扱いが変わったと報じられる。

論点 改革の方向 狙い
価格算定原価計算方式の営業利益率の係数を0.5倍にする有効性が"推定"段階の製品に満額の利益を認めない
加算有用性系加算は算定時に判断しない検証前に「優れている」と評価しない
費用対効果評価本承認後に判断する効果が不確かな段階で費用対効果を測っても意味がない

考え方は一貫している。「仮免許の製品には、仮の価格を付ける」。
企業側（日米欧の製薬3団体や再生医療イノベーションフォーラム）は、これが開発投資の予見性を損なうとして
意見を出しており、「早く届ける」と「財政を守る」の綱引きが制度設計の中心にある。

財政インパクトの現実的な見方

  • キムリアの薬価が3,349万円と決まった2019年当時、「保険財政が破綻する」との論調があったが、
    実際には対象患者数が少ないため、総額としてのインパクトは限定的だった
  • 警戒すべきは「単価×患者数」の積。単価が高くても患者が年間数十人なら総額は数十億円で済む。
    逆に、高額薬が患者数の多い疾患（アルツハイマー病、心不全など）に広がると、桁が変わる
  • 日本の国民医療費は2023年度で約48兆円（厚労省）。この分母に対し、どこまでが許容範囲かという議論になる
  • 費用対効果評価制度（2019年度に本格導入）は、価格を決める仕組みではなく、
    いったん付いた価格を調整する仕組みである点に注意

6. 米国・欧州との比較

国・地域 枠組み 特徴
日本薬機法の「再生医療等製品」＋条件及び期限付承認専用カテゴリを世界で最初に作った。早期承認に振った設計
米国FDAの生物製剤（BLA）。RMAT指定、Accelerated Approval、優先審査バウチャー承認数・投資額とも世界最大。ただし市販後の安全性で揺り戻し（Elevidysの例）
欧州（EU）EMAの ATMP（先端医療医薬品）。Hospital Exemption 制度中央審査。一方で承認後の償還が加盟国ごとに分かれ、普及が進みにくい

2026年のFDAの動きが重要。
2026年2月、FDAは超希少疾患を対象とした個別化ゲノム治療について、
「plausible mechanism（妥当な作用機序）」に基づく新たな承認経路の案を示したと報じられる。

【何が変わるのか】

 従来：患者ごとに変異が違う → 変異ごとに別の申請 → 1人のために数億円の申請費 → 成立しない

 案 ：Cas9と送達系は共通（＝プラットフォーム）
      ガイドRNAだけ患者ごとに差し替える
      → 1つの治験枠で複数の変異をカバー、5〜10例程度の結果で承認を支える案も報じられる
      → 「N=1の治療」を制度として成り立たせる試み
  • これは規制緩和であると同時に、証拠水準を下げる判断でもある。Elevidysの死亡例のように
    安全性問題が起きたときに、どう責任を取るかという論点と表裏になっている
  • 日本の条件及び期限付承認が「日本版の早期承認」として2014年に先行し、
    2026年に米国が別の角度から早期化に踏み込んだ、という構図で読むと位置づけが分かる

7. 制度を読むときのチェックリスト

ニュースで「承認」「実用化」と聞いたら、次の5つを確認する。

確認事項 なぜ効くか
① 道Aか道Bか（再生医療等製品か、再安法下の提供か）道Bなら国は有効性を認めていない
② 本承認か、条件及び期限付承認か仮免許なら7年後に失効しうる
③ 対象患者はどこまで限定されているか「パーキンソン病に承認」と「重症で標準治療が効かない患者に限る」は別物
④ 保険収載されているか、価格はいくらか承認と保険は別のプロセス
⑤ 何例のデータに基づくか、対照群はあるか希少疾患では単群試験（比較対象なし）が多い

用語メモ

  • 薬機法：医薬品医療機器等法。医薬品・医療機器・再生医療等製品の承認を規律する法律
  • 再生医療等製品：薬機法上の独立カテゴリ（2014年新設）。細胞加工製品と遺伝子治療用製品を含む
  • 再生医療等安全性確保法（再安法）：医療機関が行う再生医療の提供を規律する法律。第1〜3種に分類
  • PMDA：医薬品医療機器総合機構。承認審査と安全対策を担う独立行政法人
  • 条件及び期限付承認：有効性を推定できた段階で条件と期限（原則7年以内）を付けて与える承認
  • 使用成績調査（市販後調査）：市販後に全例などを追跡して有効性・安全性を確かめる調査
  • 中医協：中央社会保険医療協議会。保険適用と価格を議論する厚労大臣の諮問機関
  • 薬価収載：保険が使える価格表に載せること。承認とは別の手続き
  • 費用対効果評価：ICER（1年の健康を延ばすのにいくらかかるか）で価格を調整する仕組み
  • 高額療養費制度：自己負担に月額上限を設ける制度。高額薬でも患者負担は頭打ちになる
  • RMAT：米FDAの再生医療先端治療指定。開発を加速する枠組み
  • ATMP：EUの先端医療医薬品。細胞・遺伝子・組織工学製品の総称
  • 自由診療：保険を使わず全額自己負担で行う診療。再安法の届出があっても有効性の公的評価とは無関係
