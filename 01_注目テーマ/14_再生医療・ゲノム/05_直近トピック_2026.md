報道ベースの整理。一次情報で必ず裏取りすること。
数値の性格（公式／推計／報道）を各項目に明記した。

> この1年の構図を一言でいえば、**「日本で最大の朗報が出た年であり、同時に世界で最大の逆風が吹いた年」**。
> iPS細胞由来製品が国内で初めて承認された一方、米国では遺伝子治療の事業性と安全性が同時に揺らいだ。

## 1. iPS細胞由来製品、国内初の承認（2026年3月）

**何が起きたか**

- 2026年2月19日、厚生労働省の薬事審議会 再生医療等製品・生物由来技術部会が2製品の
  **条件及び期限付承認**を了承。**3月6日に承認**（厚労省／企業の適時開示）

| 製品                             | 企業                            | 対象                                               | 内容                                  |
| -------------------------------- | ------------------------------- | -------------------------------------------------- | ------------------------------------- |
| **リハート**                     | クオリプス（東証グロース 4894） | 標準治療で効果不十分な虚血性心筋症による重症心不全 | ヒト（同種）iPS細胞由来心筋細胞シート |
| **アムシェプリ**（raguneprocel） | 住友ファーマ                    | パーキンソン病                                     | 他家iPS細胞由来ドパミン神経前駆細胞   |

- iPS細胞由来製品の承認は**世界初**と報じられる。国内販売は**2026年秋頃**を計画と報じられる

**冷静に読むための注記**

- **本承認ではなく「仮免許」**。原則7年以内に有効性を検証して再申請が必要。
  制度第1号のハートシート（テルモ）は2024年7月に有効性を示せず承認失効、
  コラテジェン（アンジェス）も2024年6月に申請取り下げとなった経緯がある
  → [03_制度と承認](03_制度と承認.md)
- **対象は極めて限定的**。「心不全が治る」「パーキンソン病が治る」ではない
- 山中伸弥氏によるヒトiPS細胞樹立（2007年）から**約19年**。「数年で実用化」という当時の期待との差が、
  この分野の時間感覚を示している
- 他のiPS応用（加齢黄斑変性、1型糖尿病、再生不良性貧血、脊髄損傷、角膜上皮幹細胞疲弊症など）は
  **治験・臨床研究の段階**にとどまる

## 2. 2026年度の薬価・費用対効果評価の制度改革（2025年末〜2026年度）

条件及び期限付承認を受けた再生医療等製品の**保険上の扱いが見直された**と報じられる。

| 論点           | 見直しの方向                                               |
| -------------- | ---------------------------------------------------------- |
| 価格算定       | 原価計算方式の**営業利益率の係数を0.5倍**                  |
| 加算           | **有用性系加算は算定時に判断しない**（本承認後に判断）     |
| 費用対効果評価 | **本承認後に判断**する                                     |
| 市場拡大再算定 | 類似品の「共連れ」廃止など、新規モダリティに合わせた見直し |

- 考え方は「**仮免許の製品には仮の価格を付ける**」。財政側の論理として一貫している
- 一方、日米欧の製薬3団体（2025年12月に共同声明）や再生医療イノベーションフォーラム（FIRM）は
  **開発投資の予見性が損なわれる**として意見を出しており、綱引きが続く
- 2026年度診療報酬改定では、**がんゲノム医療の要件も見直され**、
  「より迅速に最適な抗がん剤にアクセスできる」環境整備が図られたと報じられる
  → [04_ゲノム医療の実装](04_ゲノム医療の実装.md)

## 3. 米国：遺伝子治療の逆風（2025〜2026年）

**Sarepta / Elevidys（デュシェンヌ型筋ジストロフィーのAAV遺伝子治療）**

- 2025年に Elevidys 投与後の**急性肝不全による死亡例が2件**開示されたと報じられる
- FDAが**枠組み警告（black box warning）**を要求。追加の安全性データと試験要件を課したと報じられる
- Sarepta は**約500人（従業員の約36%）の人員削減**とパイプライン再編を発表。
  年間4億ドル超のコスト削減を見込むと報じられる
- 受託側にも波及し、Catalent のメリーランド拠点で大規模な人員削減が起きたと報じられる

**商業面の苦戦**

- bluebird bio（Lyfgenia、Zynteglo、Skysona）は経営難で従業員の約25%を削減したと報じられ、
  **2024年後半時点で市販3製品を合わせて治療を開始した患者は57人**にとどまったと報じられる
- Roche の Luxturna、Pfizer の Beqvez（撤退）など、**承認されても売れない**事例が積み上がった

> **この分野の本当の難所は、承認ではなく「承認後」にある**。
> 薬価が高く、投与できる施設が限られ、患者数が少なく、投与までの手続きが重い。
> 「科学は素晴らしいが、商業化は遅く高価で運用が複雑」という総括が業界メディアで繰り返されている。
> → [02_作り方と値段](02_作り方と値段.md)

## 4. FDA：超希少疾患向けの新しい承認経路（2026年2月）

- 2026年2月、FDAが**「plausible mechanism（妥当な作用機序）」の枠組み**に関するドラフトガイダンスを公表したと報じられる
- 対象は**超希少疾患向けの個別化ゲノム治療**（ゲノム編集とRNAを用いる手法が当面の中心）
- 核心は**プラットフォーム承認**の考え方：Cas9と送達系を共通に保ち、患者ごとに変えるのは
  ガイドRNAの配列だけ、という構成であれば、**変異ごとに別申請を求めない**
- 5〜10例程度の結果で幅広いプラットフォーム承認を支えうる、という報道もある

```
【なぜこれが産業的に大きいのか】

 従来：患者1人の変異 → 1申請 → 数億円の開発・申請費 → 経済的に不可能
 新案：1つのプラットフォーム → 複数変異をまとめて → 「N=1の治療」が制度に乗る

 ただし裏返すと、**承認に必要な証拠の水準を下げる**判断でもある。
 Elevidysの死亡例と同じ年に出てきた、という点は押さえておきたい。
```

## 5. 技術の焦点：in vivo CAR-T（体内でCAR-Tを作る）

- **細胞を体外に取り出さず、脂質ナノ粒子（LNP）や標的化レンチウイルスでCAR遺伝子を体内のT細胞に届ける**発想
- 2026年のASGCT（米国遺伝子細胞治療学会）年次総会では、LNPメーカーのAcuitas Therapeuticsが
  非ヒト霊長類で**体内のCD8陽性T細胞を特異的に改変しB細胞を完全に枯渇させた**と発表したと報じられる
- 学術誌でも「in vivo CAR-Tの革命」を論じるレビューが相次いでいる（2026年）

> **成功すれば、[02_作り方と値段](02_作り方と値段.md) で述べた3〜6週間の製造ラインが丸ごと不要になる**。
> 製造・物流・施設要件というこの産業最大のコスト要因が消え、価格も下がる。
> ただし2026年時点では**臨床の初期段階**であり、承認された製品は存在しない。
> この分野で「将来の構造変化」として最も注視すべきテーマ。

## 6. データとプライバシー：23andMe破綻の後始末（2025〜2026年）

- 2025年3月、23andMe が米ミズーリ州東部地区で連邦破産法の適用を申請。
  **1,500万人超の遺伝データ**の扱いが焦点になったと報じられる
- 2025年6月、創業者 Anne Wojcicki 氏が設立した非営利 **TTAM Research Institute** が
  **約3億500万ドル**で落札し、裁判所が売却を承認（Regeneron の約2億5,600万ドルを上回る入札）
- **28州の司法長官**が、本人の明示的同意なしの遺伝データ移転を阻止すべく提訴したと報じられる
- 米破産法は個人識別情報に一定の保護を置くが、**遺伝データを明示的に対象としていない**と指摘され、
  2026年時点で法改正を求める議論が続いている

> 産業への含意：**遺伝データを溜めるビジネスには「溜めた側が消えたとき」の出口ルールがない**。
> 日本ではゲノム医療法（2023年）が差別防止を理念として掲げたが**罰則付きの禁止規定はなく**、
> 次世代医療基盤法が研究利用の道を作っているにとどまる。
> → [04_ゲノム医療の実装](04_ゲノム医療の実装.md)

## 9. 全体の構図（まとめ）

```
【2024〜2026年の出来事を時系列で並べる】

 2024/06  再安法・臨床研究法の改正が公布（in vivo遺伝子治療も法の対象へ）      日本｜制度
 2024/06  コラテジェン（アンジェス）本承認申請を取り下げ、販売終了             日本｜失敗
 2024/07  ハートシート（テルモ）「承認は適切でない」と結論、承認失効            日本｜失敗
    │
 2025/03  23andMe が連邦破産法適用を申請（遺伝データ1,500万人分）              米国｜データ
 2025/04  経産省が再生医療等製品CDMO企業リストを公表                          日本｜基盤
 2025/06  TTAM Research Institute が約3.05億ドルで23andMeを取得（裁判所承認）  米国｜データ
 2025 年内 Sarepta：Elevidys死亡例2件、枠組み警告、約36%の人員削減              米国｜逆風
    │
 2026/02  FDA「plausible mechanism」枠組みのドラフトガイダンス公表と報じられる  米国｜緩和
 2026/02  薬事審議会部会がiPS由来2製品の条件及び期限付承認を了承               日本｜前進
 2026/03  リハート／アムシェプリ 条件及び期限付承認（iPS由来で世界初と報道）    日本｜前進
 2026年度 薬価制度改革：仮承認品の営業利益率係数0.5倍、費用対効果は本承認後     日本｜財政
 2026/秋  上記2製品の国内販売開始を計画と報じられる                            日本｜これから

  ── 日本＝制度で前へ／財政で締める、米国＝安全性で後退／承認経路で前へ ──
```

1. **日本は「早く承認する」制度を先に作り、2026年3月にiPS由来製品の初承認という象徴的成果を得た**。
   ただしそれは仮免許であり、過去に2件が本承認に届かず失効した制度の上に立っている
2. **世界の遺伝子治療は「承認後」で躓いている**。安全性（Elevidysの死亡例）と商業性（bluebird の57人）の両方。
   この分野の難所が科学から実装へ移ったことを示す
3. **制度は両方向に動いた**。日本は仮承認品の価格を抑える方向（財政重視）、
   米国はプラットフォーム承認で証拠水準を下げる方向（アクセス重視）。逆向きに見えるが、
   どちらも「高額・少数・不確実」という共通の構造への対処である
4. **技術の本命は in vivo（体内で完結させる）への移行**。製造と物流というコストの正体を消しにいく方向で、
   in vivo CAR-Tと非ウイルス送達がその中心。ただし承認品はまだない
5. **ゲノム側の争点はデータのガバナンスに移った**。23andMeの破綻は、遺伝データの権利と同意の
   持続性という未整備の問題を露出させた。日本にも罰則付きの差別禁止法はまだない

## 用語メモ

- **条件及び期限付承認**：有効性が推定できた段階で条件と原則7年以内の期限を付けて与える日本独自の承認
- **枠組み警告（black box warning）**：米国で最も強い安全性警告。添付文書の冒頭に枠で囲んで表示する
- **plausible mechanism framework**：FDAが2026年に示した、超希少疾患向け個別化治療の新承認経路の考え方
- **プラットフォーム承認**：共通部分を固定し可変部分だけ差し替える製品群を、まとめて承認する発想
- **in vivo CAR-T**：体外で細胞を加工せず、体内でCAR-T細胞を作らせる手法。臨床初期段階
- **ASGCT**：American Society of Gene & Cell Therapy。米国遺伝子細胞治療学会
- **モダリティ**：治療手段の種類（低分子、抗体、核酸、細胞、遺伝子など）
- **市場拡大再算定**：予想を超えて売れた薬の価格を引き下げる日本の薬価ルール
