# ゲノム医療の実装｜「読む」ビジネスはどこで成り立っているか

**このノートで分かること**：ゲノム医療の大半は、遺伝子を**治す**のではなく**読む**話である。
解読コストが劇的に下がった結果、「読むこと」自体はもう商売にならず、
**どう読むかを設計し、結果をどう使い、データをどう蓄えるか**に価値が移った。その構造を追う。

> 大原則：**シーケンサー（解読装置）は儲かるが、解読受託は儲かりにくい**。
> 検査で稼ぐには、①保険点数が付くか、②データが溜まって別の価値になるか、のどちらかが要る。

## 1. コストの崩壊が産業を作り替えた

```
【ヒト1人分のゲノム解読費用（概算・報道および NHGRI 公表の推移ベース）】

 2003年 ヒトゲノム計画完了     数億ドル規模（13年がかりの国際プロジェクト）
   │
 2007年頃                      約1,000万ドル
   │      ← 次世代シーケンサー（NGS）の登場で「ムーアの法則より速い」下落
 2015年頃                      約1,000ドル
   │
 2022年〜                      **100ドル台**が視野に（装置メーカー発表ベース）
   ▼
 結論：読むこと自体はコモディティ。価値は「読んだ後」に移った
```

| 時代     | 何が希少だったか                       | 誰が稼いだか                           |
| -------- | -------------------------------------- | -------------------------------------- |
| 2000年代 | 解読能力そのもの                       | 装置メーカー、大型解読センター         |
| 2010年代 | 解読結果を臨床に翻訳する力             | 検査会社、パネル開発企業               |
| 2020年代 | **データの量と、それに紐づく臨床情報** | データベースを持つ側（公的機関を含む） |

- **NGS（次世代シーケンサー）**＝ DNAを短い断片に切って並列で大量に読み、計算で再構成する装置。
  装置市場は Illumina（米）が長く支配的で、近年は Thermo Fisher、中国のMGI/Complete Genomicsなどが競合
- 日本には有力な装置メーカーがおらず、**川上（装置・試薬）は輸入依存**。
  国内勢が立つのは検査受託と解析・データの層になる
  → [臨床検査・検査受託](../../09_医薬・医療・ヘルスケア/06_臨床検査・検査受託/README.md)

## 2. ゲノム医療の4つの出口

「ゲノムを読む」と一口に言っても、**目的が4つに分かれ、それぞれ経済モデルが違う**。

| 出口                              | 何を読むか                    | 誰が払うか     | 日本での状況                                                 |
| --------------------------------- | ----------------------------- | -------------- | ------------------------------------------------------------ |
| **① がんゲノム医療**              | がん組織・血液（腫瘍由来DNA） | 公的保険       | 保険適用済み。中核・拠点・連携病院で実施                     |
| **② 希少疾患・難病の診断**        | 患者と家族の生殖細胞系列      | 保険＋研究費   | 全ゲノム解析等実行計画で推進中                               |
| **③ 新生児スクリーニング**        | 新生児の血液                  | 公費・自治体   | 従来型は全国実施。**遺伝子を使う拡大版は研究・任意検査段階** |
| **④ 消費者向け遺伝子検査（DTC）** | 唾液など                      | **本人の自費** | 規制が緩く、医療との境界が曖昧                               |

```
【同じ「遺伝子検査」でも別世界】

  ①②③ 医療の中             ④ 医療の外
   ├ 医師が指示             ├ 消費者が自分で買う
   ├ 結果に責任が伴う       ├ 「傾向」を返すだけ
   ├ 保険 or 公費           ├ 全額自費（数千〜数万円）
   └ 遺伝カウンセリング付き └ 説明は原則なし
```

## 3. ① がんゲノム医療（保険で回っている唯一の柱）

**がん遺伝子パネル検査**＝ がんに関係する100〜300程度の遺伝子をまとめて調べ、
効きそうな薬（分子標的薬）を探す検査。

```
【患者から見た流れ】

 ①標準治療がない／終わる見込み
      ↓
 ②がんゲノム医療 中核拠点／拠点／連携病院を受診
      ↓
 ③検体（がん組織 または 血液）を提出
      ↓
 ④パネル検査（数週間）
      ↓
 ⑤エキスパートパネル（多職種の専門家会議）で解釈 ← ★ここが日本の制度の特徴
      ↓
 ⑥結果説明。使える薬が見つかれば治療へ（治験・適応外を含む）
      ↓
 ⑦データは C-CAT（がんゲノム情報管理センター）へ集約 ← ★国が持つ資産になる
```

| 論点                     | 現状                                                                       |
| ------------------------ | -------------------------------------------------------------------------- |
| 保険適用の対象           | ①標準治療がない・終了見込みの**固形がん**、②造血器腫瘍または類縁疾患       |
| 実施施設                 | 厚労省が指定する中核拠点／拠点／連携病院。2024年時点で全国200施設超        |
| 実際に治療に到達する割合 | **1〜2割程度**とされることが多い（施設・時期により幅がある）               |
| 2026年度の診療報酬改定   | 「より迅速に最適な抗がん剤にアクセスできる」よう要件を見直したと報じられる |

> **「到達率」が最大の論点**。検査をしても、多くの患者で「使える薬がない」「あっても保険が効かない」
> 「治験の枠が遠方にしかない」「体力的に治療できる状態にない」で止まる。
> 検査のタイミングを早める（標準治療が尽きてからでは遅い）方向に制度が動いているのはこのため。
> **技術ではなく、薬へのアクセスと実施体制がボトルネック**になっている典型例。

- **C-CAT**（国立がん研究センター がんゲノム情報管理センター）は、検査結果と臨床情報を集約する。
  保険適用の要件としてデータ提出が組み込まれているため、**制度が自動的にデータベースを育てる設計**になっている。
  これは国際的にも珍しく、日本の数少ない構造的な強み

## 4. ② 希少疾患・難病と全ゲノム解析

- **診断の旅（diagnostic odyssey）**：希少疾患の患者は診断が付くまで平均で数年〜十数年かかるとされる。
  全ゲノム／全エクソーム解析はこの期間を大幅に短縮しうる
- 日本では厚生労働省の**「全ゲノム解析等実行計画」**（2019年に第一版、2022年に改定版）が
  がんと難病の患者の全ゲノム解析を進め、解析基盤と実施組織の整備を図っている
- **エクソーム（全遺伝子の"たんぱく質をコードする部分"だけ、全体の約1〜2%）**か
  **全ゲノム（全部）**かは、コストと解釈可能性のトレードオフ。読む量が増えるほど
  「意味の分からない変異（**VUS**）」が増え、**解釈のコストが上がる**

```
【読む範囲と「分からなさ」の関係】

 パネル（100〜300遺伝子） ： 解釈しやすい / 見落としがある
 エクソーム（約2万遺伝子） ： 中間
 全ゲノム（約30億塩基）   ： 見落としが少ない / **VUSの山**ができる
                              ↑
                     ここを減らすのがデータベースの仕事。
                     「日本人に多い変異」の情報が足りないと解釈できない
                     ＝ **人種・集団固有のデータが戦略資産になる理由**
```

## 5. ③ 新生児スクリーニング

- 日本では従来から**タンデムマス法**による新生児マススクリーニング（先天性代謝異常症など約20疾患）が
  全国で公費により実施されており、実質的に全新生児が受けている
- 近年は **SMA（脊髄性筋萎縮症）や SCID（重症複合免疫不全症）** を対象とする
  **拡大新生児スクリーニング**が自治体・研究事業ベースで広がっている。
  これは**遺伝子治療の登場と直結している**：SMAはゾルゲンスマなど早期治療の効果が症状発現前に最も大きいため、
  「治療法ができたから、検査する意味が生まれた」という順番になっている

> **検査と治療は独立ではない**。「治す手段がない病気を早期に見つける」ことの是非は長く議論されてきた。
> 遺伝子治療の実用化が、スクリーニング対象の拡大を正当化する側に働いている。
> 一方で**費用は誰が負担するのか**（公費か任意の自費か）が未整理で、自治体ごとに差が出ている

## 6. ④ 消費者向け遺伝子検査（DTC）と、23andMeの教訓

**DTC**（Direct-to-Consumer）遺伝子検査は、体質・祖先・疾患リスクの「傾向」を返すサービス。
日本では数千〜数万円で購入でき、**医療行為ではないため薬機法の規制がほぼかからない**。

| 論点       | 状況                                                                         |
| ---------- | ---------------------------------------------------------------------------- |
| 精度・意味 | 多因子疾患のリスクは**相対リスクの提示にとどまり、個人の将来は予測できない** |
| 規制       | 日本では業界団体の自主基準が中心。医療との線引きが曖昧                       |
| 収益モデル | 検査キット販売は一度きり。**継続課金が作れない**のが構造的弱点               |
| 本当の資産 | 集まった遺伝データ。製薬企業との共同研究に使われてきた                       |

**23andMe の破綻が示したもの（2025〜2026年）**

```
【何が起きたか】

 2006年〜  1,500万人超の遺伝データを集める（報道ベース）
    │      キット販売は一度きり → リピートが作れない → 赤字が続く
    │      データの創薬活用（GSKとの提携など）も、収益化に時間がかかる
    ▼
 2025年3月  米ミズーリ州東部地区で連邦破産法の適用を申請
    │
    │  ここで問題が噴出：**遺伝データは破産財団の"資産"として売れるのか？**
    │  28州の司法長官が、本人の明示的同意なしの移転を阻止すべく提訴したと報じられる
    ▼
 2025年6月  創業者が設立した非営利 TTAM Research Institute が約3.05億ドルで取得（裁判所が承認）
    ▼
 教訓：**「規約に同意した」ことが、事業が破綻した後まで有効な同意と言えるのか**
       米国の破産法は個人識別情報に一定の保護を置くが、**遺伝データを明示していない**と指摘されている
```

> **産業的な含意は2つ。**
> ① **遺伝データを溜めるビジネスは、溜めた側が潰れたときの出口が制度化されていない**。
> ② **「検査を売る」モデルは成立しにくい**。医療の中（保険・公費）に入るか、
> データを研究・創薬に接続して初めて事業になる。DTC単体で黒字を保つのは難しい。

## 7. データ利活用と倫理：日本のルール

| 制度・枠組み                                   | 中身                                                                                                                                                                                               |
| ---------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **ゲノム医療法**（2023年6月成立）              | 正式名は「良質かつ適切なゲノム医療を国民が安心して受けられるようにするための施策の総合的かつ計画的な推進に関する法律」。**遺伝情報による不当な差別の防止**と適切な管理を国の責務として掲げる理念法 |
| **個人情報保護法**                             | 遺伝情報は要配慮個人情報に該当しうる。取得には原則同意が必要                                                                                                                                       |
| **次世代医療基盤法**（2018年施行、2023年改正） | 認定事業者が医療情報を**匿名加工・仮名加工**して研究に使える枠組み。オプトアウト方式                                                                                                               |
| **全ゲノム解析等実行計画**                     | 解析データの利活用を前提に、事業実施組織を通じて研究・産業利用へ橋渡し                                                                                                                             |

**倫理で必ず問われる4点**

| 論点               | 中身                                                                                                                                                      |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **差別の禁止**     | 保険加入や就職で遺伝情報を使わせない。米国には GINA（2008年）という専用法があるが、**日本にはまだ罰則付きの禁止規定がない**。ゲノム医療法は理念にとどまる |
| **二次的所見**     | 目的外で見つかる重大な情報（例：がん検査中に見つかった遺伝性疾患のリスク）。「知らせるべきか」「知りたくない権利」の扱い                                  |
| **血縁者への波及** | 生殖細胞系列の変異は**家族全員の情報**になる。本人の同意だけで完結しない                                                                                  |
| **同意の持続性**   | 20年後の研究にまで同意は及ぶのか。23andMe の破産が突きつけた問題                                                                                          |

> **この分野で医学的な判断は医師の領域**。ここで扱えるのは、
> 「誰が費用を払い、誰がデータを持ち、どの制度が抜けているか」という産業・制度の構造だけである。

## 8. ビジネスとしてどこで稼げるか

| 層                           | プレイヤー像                                      | 収益性                                     |
| ---------------------------- | ------------------------------------------------- | ------------------------------------------ |
| 装置・試薬                   | Illumina、Thermo Fisher ほか。**海外勢が中心**    | 高い。消耗品で継続課金が効く               |
| 検査受託（ラボ）             | 大手臨床検査会社、専門ラボ                        | **点数次第**。装置と試薬の原価を引くと薄い |
| パネル・アッセイ開発         | 検査キットを設計・薬事承認まで通す企業            | 承認が取れれば強いが開発投資が重い         |
| 解析・解釈（バイオインフォ） | 変異の意味づけ、レポート生成                      | **人材依存。自動化が進むと単価が落ちる**   |
| データベース                 | C-CAT、バイオバンク、次世代医療基盤法の認定事業者 | 直接の収益は小さいが**戦略資産**           |
| 創薬への接続                 | 製薬企業、創薬ベンチャー                          | 最も大きいが最も遠い                       |

> **「読む」だけの層は、下から順に価格競争に飲まれる**。
> 生き残るのは、①保険点数という公定価格に守られた層、②装置・試薬という消耗品で稼ぐ層、
> ③データを創薬という高付加価値に接続できた層の3つ。
> → [創薬ベンチャー・バイオ](../../09_医薬・医療・ヘルスケア/04_創薬ベンチャー・バイオ/README.md)

## 用語メモ

- **ゲノム**：その生物が持つ遺伝情報の全体。ヒトでは約30億塩基対
- **NGS（次世代シーケンサー）**：DNAを大量並列に読む装置。解読コスト崩壊の主因
- **パネル検査**：あらかじめ決めた遺伝子群だけを読む検査。がんゲノム医療の主力
- **エクソーム**：ゲノムのうちタンパク質をコードする領域（全体の約1〜2%）
- **生殖細胞系列／体細胞**：生まれつき持つ変異／後天的に生じた変異。前者は家族に共有される
- **VUS**：Variant of Uncertain Significance。意味が確定していない変異。読む量が増えるほど増える
- **エキスパートパネル**：がんゲノム医療で結果を多職種で解釈する専門家会議
- **C-CAT**：国立がん研究センター がんゲノム情報管理センター。検査データを集約する国の基盤
- **二次的所見**：検査の主目的とは別に判明する、健康上重要な所見
- **遺伝カウンセリング**：遺伝情報の意味と選択肢を専門職が説明する支援
- **DTC遺伝子検査**：医療機関を介さず消費者に直接販売される遺伝子検査
- **次世代医療基盤法**：医療情報を匿名加工して研究利用可能にする日本の法制度
- **GINA**：米国の遺伝情報差別禁止法（2008年）。保険・雇用での遺伝情報利用を禁じる
- **タンデムマス法**：質量分析で複数の代謝異常症を一度に調べる新生児スクリーニングの手法
