# 暗号への影響と産業構造

このノートで分かること：**量子コンピュータが暗号に何をするのか（何をしないのか）**、
**いつまでに何をすべきか**、そして**この産業が誰の金で回っているのか**。

結論を先に書く。**量子コンピュータで暗号が破られるのはまだ先だが、対策は今やらないと間に合わない**。
理由は **Harvest now, decrypt later（今盗んで、後で解読する）** ―
今日盗まれた暗号通信は、10年後に解読されうる。したがって
**「10年後も秘密であってほしいデータ」を扱う組織にとって、期限はすでに過ぎている**。
この「まだ先なのに今やる」というねじれが、量子分野で唯一、**確実に金が動いている領域**を作っている。

前提は [量子ビットと計算の原理](01_量子ビットと計算の原理.md)、ハードの現状は [方式と現在地](02_方式と現在地.md)。
セキュリティ全般は [サイバーセキュリティ](../10_サイバーセキュリティ/README.md)、[情報セキュリティ](../../04_情報通信・IT・ネット/14_情報セキュリティ/README.md)。

## 1. Shorのアルゴリズムが壊すもの・壊さないもの

現代の暗号は大きく2種類ある。**壊れるのは片方だけ**である。

| 種類 | 何に使うか | 安全性の根拠 | 量子の影響 |
| --- | --- | --- | --- |
| **公開鍵暗号**（RSA、楕円曲線暗号=ECC、Diffie-Hellman） | 鍵交換、電子署名、TLS/HTTPS、証明書、ブロックチェーンの署名 | 素因数分解・離散対数の困難さ | **Shorのアルゴリズムで実質的に無力化**。ここが本丸 |
| **共通鍵暗号**（AES）、**ハッシュ**（SHA-2/3） | データ本体の暗号化、改ざん検知 | 総当たりの手間 | **Groverで探索が平方根に短縮されるだけ**。AES-128の強度がAES-64相当に落ちる |

対応の重さがまったく違う。

```
【公開鍵】RSA-2048 / ECC-256
   Shor のアルゴリズム ＝ 素因数分解を指数的に高速化
   → 「時間をかければ解ける」ではなく「実用的な時間で解ける」に変わる
   → **アルゴリズムそのものを別物に入れ替えるしかない**（＝PQCへの移行）

【共通鍵】AES-128
   Grover のアルゴリズム ＝ 総当たり 2^128 回 → 2^64 回（平方根）
   → **鍵長を2倍にすれば元の強度に戻る**（AES-128 → AES-256）
   → 設定変更で済む。深刻ではない
```

> よくある誤解：「量子コンピュータが来たら暗号が全部壊れる」。
> 正しくは **「公開鍵だけが壊れ、共通鍵は鍵長を伸ばせば済む」**。
> ただし公開鍵は**ネット上のあらゆる通信の入口**（TLSハンドシェイク、証明書、コード署名、
> 暗号資産の署名）に使われているため、影響範囲は広い（→ [暗号資産](../../05_金融/14_暗号資産/README.md)）。

## 2. いつ破られるのか（Q-Day）

RSA-2048 を破るのに必要な資源の見積もりは、**ハードが進歩したからではなく、
アルゴリズムと符号が改良されたことで、年々小さくなっている**。ここは重要な論点。

| 年 | 見積もり | 出典の性格 |
| --- | --- | --- |
| 2012年頃 | 論理量子ビット 数千個／物理量子ビット 10億個級 | 初期の学術的見積もり |
| 2019年 | 物理量子ビット **約2,000万個**／約8時間 | Gidney & Ekerå（学術論文） |
| 2025年5月 | 物理量子ビット **100万個未満**／1週間未満 | Gidney（Google研究者、学術論文）。**6年で20分の1** |
| 2026年2月 | 物理量子ビット **10万個未満** と主張 | Iceberg Quantum（qLDPC符号を用いた企業発表。査読状況に注意） |

一方、2026年時点の実機は**物理量子ビットで1,000個級**。まだ2〜3桁足りない。

```
【時間軸の見立て（2026年時点。幅で読むこと）】

 2026 ─────── 2030 ─────── 2035 ─────── 2040
  │             │             │
  │             │             └─ 悲観的見立て：ここでもまだ無理という専門家も多い
  │             └─ 各社ロードマップの「大規模FTQC」目標（IBM 2029、PsiQuantum 2029 など）
  └─ 現在：物理1,000量子ビット級、論理数十個

  ★ 政府の規制側は「2030〜2035年までに移行完了」を前提に制度設計している。
    つまり **技術の見通しではなく、制度の期限が実務のデッドラインを決めている**。
```

**「専門家の見立てには10年以上の幅がある」ことを、幅のまま持っておく**のが正しい理解である。
確定的な年号を語る資料は、その時点で疑ってよい。

## 3. Harvest now, decrypt later（HNDL）

これが「今やる」理由のすべてである。

```
  2026年   攻撃者が暗号化された通信をそのまま保存する（解読はしない）
    │       ← 通信は暗号化されているので、盗まれても現時点では読めない
    │       ← **受動的で、検知できない**
    ▼
  20XX年   量子コンピュータが実用化される
    │
    ▼        保存しておいた2026年の通信を、まとめて解読する
           → 政府の外交電文、医療記録、企業の知財、長期契約、個人の遺伝情報…
             **「その時点でまだ秘密であるべき情報」がすべて露出する**
```

したがって判断基準はこうなる。

> **「そのデータの秘密保持期間」＋「移行にかかる年数」＞「Q-Dayまでの年数」なら、もう手遅れ。**
> （Mosca の不等式として知られる考え方）

| データ種別 | 秘密であるべき年数 | 緊急度 |
| --- | --- | --- |
| 国家機密、外交、防衛 | 30〜75年 | **最優先**。各国が先頭で動いている理由 |
| 医療記録、遺伝情報 | 生涯（数十年） | 高 |
| 企業の研究データ、設計図 | 10〜20年 | 高 |
| 金融取引記録、契約 | 7〜10年 | 中 |
| 一時的なセッション、日常のWeb閲覧 | 数日 | 低 |

## 4. 耐量子暗号（PQC）への移行

対策は「量子で守る」ことではなく、**古典コンピュータ上で動く、量子でも解けない数学に乗り換える**こと。
これが **PQC（Post-Quantum Cryptography、耐量子計算機暗号）**。
**量子コンピュータは一切使わない、普通のソフトウェアである**点が重要。

| 標準 | 用途 | 数学的な土台 | 制定 |
| --- | --- | --- | --- |
| **FIPS 203（ML-KEM、旧Kyber）** | 鍵交換（TLSなど） | 格子問題 | 2024年8月、米NIST |
| **FIPS 204（ML-DSA、旧Dilithium）** | 電子署名 | 格子問題 | 2024年8月、米NIST |
| **FIPS 205（SLH-DSA、旧SPHINCS+）** | 電子署名（保険用の別方式） | ハッシュ関数 | 2024年8月、米NIST |

**制度側の期限**（ここが実務のデッドラインを決めている）。

| 期限 | 内容 | 主体 |
| --- | --- | --- |
| 2026年9月 | FIPS 140-2 認証の「Historical」移行 | 米NIST |
| 2026年12月 | EU加盟国の PQC 移行国家戦略の策定期限 | EU NIS協力グループ |
| **2027年1月** | 国家安全保障システムの**新規調達は耐量子対応が必須** | 米NSA（CNSA 2.0） |
| 2030年 | ソフト・ファーム署名の耐量子化 | 米NSA（CNSA 2.0） |
| 2033年 | Web・クラウド・OSで耐量子暗号が唯一の標準に | 米NSA（CNSA 2.0） |
| 2035年 | 連邦システム全体の移行完了 | 米NSM-10 |

> 注意点：PQCは**万全ではない**。SIKEという候補は標準化の最終選考中に**古典計算機で破られた**（2022年）。
> そのため実務では **ハイブリッド方式**（従来の楕円曲線暗号とPQCを併用し、どちらかが破れても安全）が
> 当面の標準となっている。主要ブラウザ・クラウドはすでにTLSでハイブリッド鍵交換を実装している。

## 5. 移行の実務（何から手を付けるか）

```
 ① 暗号の棚卸し（Cryptographic Bill of Materials）
    どのシステムが、どこで、どの暗号を使っているか棚卸しする
    → **ここでほぼ全ての組織が止まる**。自社が何を使っているか誰も把握していない
 ② 優先順位付け
    「長期秘密データ」×「外部と通信する」ものから
 ③ 暗号アジリティ（crypto-agility）の確保
    暗号方式を後から差し替えられる作りにする。**次に何が破れても耐えられる体質**
 ④ ハイブリッド方式で段階移行
 ⑤ 証明書・HSM・IoT機器など「寿命の長いもの」を計画的に更新
    → 20年動く産業機器・車載・スマートメーターが最大の難所
```

**量子暗号（QKD）との混同に注意**。QKD（量子鍵配送）は**専用の光ファイバや衛星が要るハードウェア**で、
既存インターネットには適用できない。米NSAは国家安全保障システムでのQKD採用を推奨しておらず、
**主流の答えはPQC（ソフト）である**。日本・中国・EUは通信インフラ側でQKDにも投資しており、
ここは国ごとに方針が割れている論点。

## 7. 国策としての量子（金の出どころ）

この産業の売上の主たる源泉は**政府予算**である。投資の理由は、経済性より**安全保障**にある。

| 国・地域 | 施策 | 規模 |
| --- | --- | --- |
| 米国 | 国家量子イニシアチブ法（2018年） | 2019〜2024年で50億ドル超（JETRO整理）。2026年5月に約20億ドルを9社前後へ拠出と報じられる |
| EU | Quantum Flagship（2018年〜） | 10年で10億ユーロ |
| ドイツ | 国家プログラム | 2023〜2026年で30億ユーロ規模 |
| フランス | 量子技術国家戦略（2021年〜） | 5年で10億ユーロ |
| 英国 | 調達プログラム ProQure（2026年3月発表） | 10億ポンド規模と報じられる |
| 中国 | 国家プロジェクト（詳細非公開） | 数兆円規模との推計もあるが**公表値がなく検証できない** |
| 日本 | 量子技術イノベーション戦略（2020年）、量子未来社会ビジョン（2022年）、経産省の産業化支援事業 | 各年度の予算措置。2030年に国内利用者1,000万人などの目標を掲げる |

> 構図：**「使えるかどうか分からないが、他国に先を越されたら安全保障上まずい」**という論理で予算が付く。
> 民需で回っていないため、**政策の方向が変わると産業が一気に冷える構造リスク**がある。
> 2021年前後の上場ブームで株価が乱高下したのはこの性質の表れで、投資テーマとしては
> 「実需の裏付けが薄い」ことを前提に見る必要がある。

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **Shorのアルゴリズム** | 素因数分解・離散対数を指数的に高速化。RSAとECCを無力化する |
| **Groverのアルゴリズム** | 総当たり探索を平方根に短縮。共通鍵は鍵長2倍で対応できる |
| **公開鍵暗号（RSA / ECC）** | 鍵交換・電子署名に使う。量子に破られる側 |
| **共通鍵暗号（AES）** | データ本体の暗号化。鍵長を伸ばせば残る |
| **Q-Day** | 暗号が実用的に破られる日。2030年代という見方が多いが幅が大きい |
| **CRQC** | 暗号学的に意味のある量子コンピュータ。Q-Dayを起こす規模の機械 |
| **HNDL（Harvest now, decrypt later）** | 今のうちに暗号文を保存し、将来解読する攻撃。検知できない |
| **Moscaの不等式** | 「秘密保持年数＋移行年数 > Q-Dayまでの年数」なら手遅れ、という判断式 |
| **PQC（耐量子暗号）** | 量子でも解けない数学に基づく**古典**暗号。ML-KEM、ML-DSAなど |
| **ML-KEM / ML-DSA / SLH-DSA** | NISTが2024年8月に標準化した3方式（FIPS 203/204/205） |
| **CNSA 2.0** | 米NSAの暗号要件。2027年1月から新規調達に耐量子対応を要求 |
| **ハイブリッド方式** | 従来暗号とPQCを併用し、どちらかが破れても安全にする実装 |
| **暗号アジリティ** | 暗号方式を後から差し替えられる設計にしておくこと |
| **CBOM** | 暗号の棚卸し表。移行の最初の一歩 |
| **QKD（量子鍵配送）** | 専用ハードで鍵を配る技術。PQCとは別物で、既存ネットには適用しにくい |
