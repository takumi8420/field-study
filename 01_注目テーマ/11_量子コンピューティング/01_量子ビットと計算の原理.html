量子ビットと計算の原理

注目テーマ量子コンピューティング

このノートで分かること：量子コンピュータがなぜ速いのか、そしてなぜ「何でも速い」わけではないのか。
この分野は誇張が多いので、原理のところで「できること」と「できないこと」の線を先に引いておく。

結論を先に書く。量子コンピュータは「すべての組合せを同時に試す並列マシン」ではない。
正しくは、答えの候補に波のような重みを付け、間違った候補どうしを打ち消し合わせて（干渉させて）、
正解だけを残す装置である。この「打ち消し方」を設計できる問題でしか速くならない。

ハードの方式や現在の到達点は 方式と現在地、
用途の切り分けは 何に使えるのか を参照。

1. 古典ビットと量子ビットは何が違うのか

古典コンピュータのビットは 0 か 1 のどちらか。半導体のトランジスタで電流の通り道を作る／消すことで表す
（→ トランジスタの原理）。

量子ビット（qubit） は、0 と 1 の中間の状態を取れる。これを 重ね合わせ（superposition） という。
ただし「0でもあり1でもある」という曖昧な言い方は誤解のもとで、正確には
「0の重み」と「1の重み」を持った1本のベクトルである。重みは実数ではなく複素数（振幅）で、
プラスとマイナス（正確には位相）を持つ。このマイナスが取れることが、量子計算の全力の源になる。

古典ビット             量子ビット（ブロッホ球で表す）
                                 |0⟩
  ┌───┐  ┌───┐                    ●
  │ 0 │  │ 1 │                 ／ │ ＼      ← 球面上のどこでも取れる
  └───┘  └───┘               ／   ●  ＼    ← この1点が「状態」
   2択のどちらか              ｜   状態  ｜
                              ＼       ／
                                 ＼   ／
                                    ●
                                 |1⟩

取りうる状態0 または 10と1の重ね合わせ（振幅は複素数）
物理的な実体トランジスタの電荷、磁化超伝導回路のエネルギー準位、イオンの電子状態、原子、光子の偏光 など
読み出し何度読んでも同じ読んだ瞬間に0か1に確定し、重ね合わせは壊れる
コピー自由にできるできない（複製不可能定理）
放っておくと状態を保つ勝手に壊れる（デコヒーレンス。マイクロ秒〜秒のオーダー）

2. 最大の誤解：「2^n 通りを同時に計算している」

n個の量子ビットは 2^n 個の振幅を持つ。300量子ビットあれば 2^300（宇宙の原子数より多い）個の振幅がある。
ここから「2^300通りを同時に計算できる」という説明がよく出るが、これは間違いである。

理由は測定にある。計算が終わって読み出すと、得られるのは n ビットの答えが1個だけ。
どの答えが出るかは、その候補の振幅の絶対値の2乗の確率で決まる。
つまり、内部にいくら情報があっても、取り出せるのは1回につき n ビットだけ。

【誤ったイメージ】                 【実際の姿】
全候補を同時計算 → 全部の答えが出る   全候補に振幅を配る
                                        ↓
 A → 結果A                         干渉させて、間違った候補の振幅を
 B → 結果B  ぜんぶ手に入る            打ち消し合わせる（+と−が相殺）
 C → 結果C                              ↓
 …                                  正解の候補だけ振幅が大きく残る
                                        ↓
                                    測定 → 高い確率で正解が1個出る

ポイント：量子コンピュータの本体は「並列計算」ではなく 「干渉の設計」。
正解以外を打ち消す配線を思いつけた問題しか速くならない。これが、速くなる問題が限られる根本理由。

3. もつれ（エンタングルメント）

2つ以上の量子ビットが、個別の状態としては書けない一体の状態になることを
もつれ（entanglement） という。

例：2量子ビットが「00 と 11 が半々」という状態にあるとき、
片方を測って 0 が出れば、もう片方は必ず 0（離れていても）。
「1つ目が0で、2つ目が…」という形に分解して書くことができない。

誤解 実際
もつれで情報を瞬時に送れる送れない。測定結果はランダムで、相手に意図した値を届けられない（無信号定理）
もつれは特別な現象量子回路ではごく普通に発生する。2量子ビットゲートを1回かければ作れる
もつれがあれば速いもつれだけでは足りない。干渉と組み合わせて初めて加速になる

もつれが効くのは、n量子ビットの状態空間が 2^n 次元まで広がるのが、もつれのおかげだから。
もつれがなければ、n個の量子ビットは n 個の独立したコマにすぎず、古典計算で簡単に真似できてしまう。

4. 量子ゲートと量子回路

計算はゲート（状態への操作）を順に当てることで進む。古典のAND/ORに当たるものだが、
すべての操作は可逆（入力に戻せる）でなければならない。情報を捨てる操作は熱を出し、状態を壊すからである。

ゲート 何をするか 役割
H（アダマール）0 を「0と1が半々」にする重ね合わせを作る入口
X0↔1 を入れ替える古典のNOTに相当
Z、T、位相ゲート振幅の符号・位相だけを変える干渉を設計する道具。ここが古典にない部分
CNOT（制御NOT）片方が1のときだけ、もう片方を反転もつれを作る。2量子ビットゲート
測定0か1に確定させる出口。ここで重ね合わせは失われる

実装上いちばん難しいのは 2量子ビットゲート（CNOTなど）で、
ハードウェアの良し悪しはほぼ 2量子ビットゲートの忠実度（fidelity） で語られる。
2026年時点の最高水準はイオントラップ方式の 99.9〜99.99% 台（各社公表値）。
一見すると十分に見えるが、1万回ゲートをかければ誤りはほぼ確実に入る。

【2量子ビット忠実度と、誤りなく回せるゲート数のざっくりした目安】

 忠実度 99%     → 約  100 回で誤りが期待値1
 忠実度 99.9%   → 約 1,000 回
 忠実度 99.99%  → 約10,000 回
 実用的な化学計算に必要なゲート数 → 10億〜1兆回
 ────────────────────────────────────
 桁が7〜8つ足りない。だから誤り訂正が要る（→ 02_方式と現在地.md）

5. 速くなる問題／ならない問題

加速の型は大きく3つ。「どれに当たるか」で話の重みがまったく違うので、ここは必ず分けて読む。

型 速さの差 代表アルゴリズム 実用上の意味
指数的加速古典で宇宙年齢 → 量子で数時間Shor（素因数分解）、量子位相推定（化学・材料のエネルギー計算）ここだけが「ゲームチェンジ」。ただし該当する問題は少ない
二次（平方根）加速1兆回 → 100万回Grover（非構造化探索）、振幅増幅（モンテカルロ）理論上は有利でも、1ゲートが古典より圧倒的に遅いため、実利が出るのは問題が巨大な場合だけ
ヒューリスティック証明なし。速いかもしれないQAOA、VQE、量子アニーリング加速の保証がない。誇大広告が最も集中する領域

そもそも速くならない代表例も押さえておく。

  • データが大量にある処理（検索、集計、データベース）：データを量子状態に読み込む時間がボトルネックになり、加速が消える
  • 四則演算・一般的なプログラム：古典より遅い。量子ビットは高価で、古典CPUの方が圧倒的に安く速い
  • AIの学習：現状、量子機械学習で古典を上回った実用例は確認されていない（2026年時点）

覚え方：量子コンピュータは「万能な速いパソコン」ではなく、「特定の数学構造に効く加速器」。
GPUやFPGAと同じ「アクセラレータ」の一種だと考えると、産業的な位置づけを間違えにくい。

6. なぜ難しいのか：デコヒーレンス

量子状態は極端に壊れやすい。周囲の熱、電磁ノイズ、宇宙線、装置自身の振動――
外の世界とわずかでも相互作用すると、重ね合わせの位相がバラけてただの確率的な古典状態に落ちる。
これが デコヒーレンス。

方式 コヒーレンス時間（状態が保つ時間、2026年時点の代表値） ゲート時間
超伝導100マイクロ秒〜1ミリ秒数十ナノ秒（速い）
イオントラップ数秒〜数分数十〜数百マイクロ秒（遅い）
中性原子数秒数マイクロ秒

「コヒーレンス時間 ÷ ゲート時間」が誤りなく回せる回数の上限の目安になる。
超伝導は保持が短いがゲートが速い、イオンは保持が長いがゲートが遅い、というトレードオフになっている。
どちらも「時間内に回せる回数」では桁違いに足りず、そこを埋めるのが誤り訂正である。

7. 古典コンピュータとの役割分担

量子コンピュータが古典コンピュータを置き換えることは、当面もその先も想定されていない。
実際の使い方はハイブリッドで、量子は「古典が苦手な芯の部分だけ」を担当する。

       ユーザーの問題（例：新しい触媒を設計したい）
                    │
        ┌───────────┴───────────┐
        │  古典（CPU / GPU / HPC）  │  ← 前処理、問題の切り出し、近似、
        │                          │     パラメータ調整、結果の後処理
        └───────────┬───────────┘
                    │ 小さく切り出した「本質的に量子的な部分」だけ投げる
                    ▼
        ┌──────────────────────┐
        │  量子プロセッサ（QPU）      │  ← 分子のエネルギー計算など
        │  クラウド経由で数秒〜数分   │
        └───────────┬───────────┘
                    │ 測定結果（確率分布）を返す
                    ▼
              古典側で集計・判断 → 必要なら再投入（ループ）

この構図から、産業側の含意が2つ出る。

  1. 量子は「クラウドの一機能」として売られる（→ クラウド・IaaS）。
    1台数十億円の装置を各社が買うモデルにはなりにくい
  2. 古典側のHPC・GPUと競合する。量子が勝つには、古典の最良手法を上回る必要がある。
    古典アルゴリズムも毎年改良されるため、「量子優位」の基準線は上がり続ける（後述の「脱量子化」）

8. よくある誤解のまとめ

よく言われること 実際
すべての計算が速くなる特定の数学構造に効くだけ。多くの処理はむしろ遅い
2^n 通りを同時に計算する取り出せる答えは1回に1個。干渉で正解を浮かび上がらせている
量子ビット数が多いほど高性能忠実度と接続性を無視した比較は無意味（→ 02_方式と現在地）
もつれで瞬時通信ができるできない。無信号定理
もう暗号は破られている2026年時点でRSA-2048を破った例はない（→ 04_暗号と産業構造）
AIが量子で劇的に速くなる実証されていない。むしろAIが量子の制御・誤り訂正に使われている
古典コンピュータを置き換える置き換えない。アクセラレータとして併用する

まとめ

量子コンピュータとは、複素数の振幅を持つ状態を操作し、干渉によって間違った答えを打ち消して、
正解の確率だけを高める装置である。並列マシンではない。
そして状態は放っておくと壊れるので、誤り訂正なしには実用的な長さの計算ができない。
このノートの結論は次の1本に直結する ― 方式と現在地。
