# 量子コンピューティング

- 大分類: 注目テーマ
- 状態: done
- 更新日: 2026-09-19

量子コンピューティングを一言でいえば、**「重ね合わせと干渉を使って、特定の種類の計算だけを劇的に速くする加速器」**。
汎用コンピュータの置き換えではなく、GPUと同じ**アクセラレータ**の一種である。
そして2026年時点で、**商用価値のある計算で古典コンピュータに勝った実例はまだない**。

この分野は**誇張が極端に多い**。本フォルダの方針は次の3つ。

1. **「できていること」と「できていないこと」を毎章はっきり分ける**
2. **実用化の時期は幅で書く**（各社ロードマップは2029〜2030年、懐疑的な見立ては2030年代後半）
3. **数値には年と出典の性格（学術／企業発表／推計／報道）を必ず添える**

## 1. 業界の定義・範囲

「量子コンピューティング」は、**量子力学の性質（重ね合わせ・もつれ・干渉）を計算資源として使う情報処理**と、
その周辺の装置・ソフト・サービスを指す。「量子技術」全体の一部分にすぎない点に注意。

| 含む | 含まない（隣接） |
| --- | --- |
| ゲート型量子コンピュータ（ハード・ソフト・クラウド） | 半導体・古典HPC → [半導体・先端半導体](../02_半導体・先端半導体/README.md)、[データセンター](../../04_情報通信・IT・ネット/03_データセンター/README.md) |
| 量子アニーリング（最適化特化の別方式） | 古典の「量子インスパイアード」アルゴリズム（**量子ハードを使わない**） |
| 量子誤り訂正、制御エレキ、希釈冷凍機などの部材 | 一般の低温機器・計測機器 → [計測・分析機器](../../03_電機・電子部品/13_計測・分析機器/README.md) |
| 量子アルゴリズム、量子ソフトウェア | 古典AI → [生成AI](../01_生成AI/README.md) |
| （関連）耐量子暗号 PQC ※量子ハードは使わない古典暗号 | 暗号運用全般 → [サイバーセキュリティ](../10_サイバーセキュリティ/README.md) |
| （関連）量子暗号通信 QKD、量子センシング | 通信インフラ → [通信キャリア](../../04_情報通信・IT・ネット/01_通信キャリア/README.md) |

```
【量子技術という言葉の中身（混同されやすい3つ）】

 ① 量子コンピューティング … 計算する。本フォルダの主題
 ② 量子通信・量子暗号(QKD) … 盗聴を検知できる鍵配送。専用の光ファイバ・衛星が要る
 ③ 量子センシング          … 磁場・重力・時間を超高精度に測る。医療・資源探査・測位で実用化が最も近い

 ＋ 耐量子暗号(PQC) … ①への「守り」。**普通のソフトウェアで、量子ハードは不要**
```

## 2. 市場規模と成長性

| 指標 | 数値 | 年・出典 |

| 世界の量子コンピューティング市場 | 約10.8億ドル | 2024年、QED-C調査（JETRO整理） |
| 同 | 約22.1億ドル（年平均成長率 約27%） | 2027年予測、QED-C調査 |
| 同（別推計） | 約25億ドル → 2031年に約99億ドル（CAGR約32%） | 2026→2031年、調査会社推計 |
| 日本市場 | 約1.97億ドル → 2032年に約28.8億ドル | 2023→2032年、調査会社推計 |
| 純粋量子企業で最大（IonQ）の売上 | 約1.3億ドル | 2025年実績、同社公表 |

> **桁感を間違えないことが最重要**。世界市場の全体が**20億ドル台**で、大手半導体1社の四半期売上にも届かない。
> しかも売上の大半は**政府・大企業の研究開発予算**であり、業務課題を解いた対価ではない。
> 調査会社の2030年代予測は「実用化が計画通り進んだ場合」の仮定に乗っているため、**幅で読む**こと。

## 3. バリューチェーン（川上 → 川下）

```
【川上：部材・装置】        【中核：計算機】          【川下：使う側】
希釈冷凍機（Bluefors 等） ─┐
極低温同軸ケーブル         ├─▶ QPU（量子プロセッサ） ─▶ クラウド提供 ─▶ 応用・コンサル ─▶ ユーザー
レーザー・光学部品         │   IBM/Google/Quantinuum    AWS Braket      SIer・各社の      製薬・化学
制御エレキ（AWG/FPGA）    │   IonQ/QuEra/PsiQuantum    Azure Quantum   量子チーム        金融・自動車
超伝導材料・パラ増幅器     ┘   富士通・理研/D-Wave       IBM Quantum                      政府・防衛

   実需があり利益が出ている  │  政府調達が売上の柱      │  従量課金だが額は小さい │ PoC（実証）止まり
   ＝「ツルハシ」を売る層    │  自力では黒字化できない  │                        │
```

付加価値の集まり方が、他産業と逆になっているのが特徴。
**川下（応用）でまだ価値が出ていないため、川上（部材・装置）だけが確実に売れている**。
これは産業が未成熟であることの直接の表れであり、
「どこで稼げるか」を問われたら、**当面は装置・部材と、政府案件を取れるハードベンダー**が答えになる。

## 5. 収益モデル・コスト構造

| 収益源 | 中身 | 経済的な特徴 |
| --- | --- | --- |
| **政府調達・補助金** | 国研・大学・防衛向けの装置納入、開発助成 | **最大の柱**。政策変更が直撃する構造リスク |
| 共同研究（PoC） | 製薬・化学・金融・自動車との実証 | 1件数千万〜数億円。継続案件になりにくい |
| クラウド従量課金 | QPU利用時間 | 額は小さい。実験用途が中心 |
| ソフト・ツール | SDK、誤り訂正ミドル、制御ソフト | 市場形成はこれから |
| 部材・装置 | 冷凍機、極低温部品、レーザー、制御エレキ | **実需あり。確実に利益が出る層** |

コスト側は**研究開発費と設備がほぼすべて**。希釈冷凍機1台で数億円、
量子ビット1個あたり数本の制御配線が要るため、**規模を増やすほど制御系のコストが線形以上に増える**。
主要プレイヤーは**構造的に赤字**で、資金調達と政府予算でつないでいる。

## 6. 競争要因（KSF）と参入障壁

**KSF**
1. **2量子ビットゲートの忠実度**。量子ビット数より先に、まずここ
2. **誤り訂正のオーバーヘッドの小ささ**（表面符号 → qLDPC符号への移行競争）
3. **制御系のスケーラビリティ**（配線・冷凍能力・クライオCMOS）
4. **政府案件を取る力**。売上の主柱がここにあるため、安全保障との接続が事業条件になる
5. **開発者エコシステム**。SDKとクラウドの入口を押さえた側に利用が集まる

**参入障壁**
- 資金（1社あたり年数百億円規模の研究開発を10年続ける必要がある）
- 人材（量子物理と極低温工学と制御工学の交差点。世界的に希少）
- **サプライチェーン**（希釈冷凍機・極低温部品は供給元が数社に限られ、納期が長い）
- 輸出管理（量子技術は米国・日本ともに輸出規制の対象に追加されている）

## 7. 規制・法制度

| 制度・方針 | 内容 |
| --- | --- |
| **NIST PQC標準（FIPS 203/204/205）** | 2024年8月制定。ML-KEM／ML-DSA／SLH-DSA。**移行の技術的な基準** |
| **米NSA CNSA 2.0** | 2027年1月から国家安全保障システムの新規調達に耐量子対応を要求。2033年にWeb/クラウド/OS、2035年に全体移行 |
| **EU NIS協力グループ** | 加盟国に2026年12月末までのPQC移行国家戦略策定を要請 |
| **輸出管理** | 量子コンピュータ・関連部材が輸出規制品目に追加（日本は2023年に外為法の規制対象へ追加） |
| **米 国家量子イニシアチブ法**（2018年） | 米国の量子政策の土台。2019〜2024年で50億ドル超 |
| **日本 量子技術イノベーション戦略**（2020年）／**量子未来社会ビジョン**（2022年） | 国内の司令塔。2030年に国内利用者1,000万人などの目標 |
| **経産省 量子コンピュータ産業化事業** | 2026年7月に今後の方向性を審議会へ提示。供給網整備に軸足 |

> 規制の重心は「量子コンピュータの規制」ではなく、**①輸出管理（他国に渡さない）と
> ②暗号移行の義務付け（守りを固める）**の2つにある。前者が産業政策、後者が実務の締切を作っている。

## 8. 最近のトピック

詳細は [05_直近トピック_2026](05_直近トピック_2026.md) に出典URL付きでまとめた。要点は5つ。

1. **競争軸が「物理量子ビット数」から「論理量子ビット数」へ移った**。2024年末のGoogle Willowによる
   しきい値突破が分水嶺。2026年時点の論理量子ビットは数十個で、実用（数百〜数千）にはまだ1〜2桁足りない
2. **方式は決着していない**。Googleが中性原子部門を新設、IonQが半導体ファウンドリを買収と、分散と垂直統合が同時進行
3. **金は政府から出ている**。2026年5月に米国が約20億ドルを9社前後へ、英国はProQureに10億ポンド規模。
   支援先が研究から**製造基盤（量子ファウンドリ）**へ移った
4. **日本は2026年度の1,000量子ビット機（富士通・理研）が節目**。強みは装置・部材と基礎研究、弱みはソフト層
5. **唯一いま実務になるのは暗号移行**。2026年後半〜2027年初頭に制度の期限が集中し、
   RSA-2048解読の必要資源見積もりは**理論改良によって**下がり続けている

### このページの単語集

| 用語 | 意味 |
| --- | --- |
| 物理量子ビット | 実際の素子で作る量子ビット。ノイズや誤りがあるため、多数を束ねて論理量子ビットを作る |
| 論理量子ビット | 複数の物理量子ビットと誤り訂正を組み合わせ、計算に使える信頼性を持たせた量子ビット |
| NISQ | 誤り訂正が十分でない、現在のノイズを含む中小規模量子コンピュータ |
| FTQC | 誤り訂正によって長い計算を正確に実行できる、耐故障型量子コンピュータ |
| ゲート型 | 量子ゲートを順番に適用し、汎用的な計算を行う方式 |
| 量子アニーリング | 組合せ最適化問題の解を、エネルギーが低い状態を探索することで求める専用方式 |
| PQC | 量子コンピュータでも解読しにくい数学問題を使う耐量子暗号。通常のコンピュータで動く |
| QKD | 量子状態を利用して盗聴を検知しながら暗号鍵を共有する量子鍵配送 |
| 希釈冷凍機 | 超伝導量子ビットなどを絶対零度近くまで冷却する装置 |
| 量子ファウンドリ | 量子チップの試作・製造を複数の企業や研究機関から受託する製造基盤 |
