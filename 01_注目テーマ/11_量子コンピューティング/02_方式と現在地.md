# 方式と現在地（ハードウェアと誤り訂正）

このノートで分かること：**量子ビットを何で作っているか（5方式）**と、
**2026年時点でどこまで来ていて、何ができていないか**。

結論を先に書く。2026年時点で、**商用価値のある計算を古典より速く解いた実例はまだない**。
業界の競争軸は2024〜2025年を境に「量子ビットを何個並べたか」から
**「誤りを訂正した論理量子ビットを何個作れたか」**へ移った。
実用的な誤り耐性マシン（FTQC）の登場時期は、各社ロードマップでは**2029〜2030年前後**、
懐疑的な専門家の見立てでは**2030年代半ば〜後半**と、**5〜15年の幅**がある。

原理は [量子ビットと計算の原理](01_量子ビットと計算の原理.md)、用途は [何に使えるのか](03_何に使えるのか.md)。

## 1. 方式の一覧（2026年時点）

「どの方式が勝つか」はまだ決着していない。**5方式が並走中**である。

| 方式 | 量子ビットの正体 | 動作環境 | 強み | 弱み | 主なプレイヤー |
| --- | --- | --- | --- | --- | --- |
| **超伝導** | 超伝導回路（ジョセフソン接合）のエネルギー準位 | **約10ミリケルビン**（絶対零度近傍）の希釈冷凍機 | ゲートが速い（数十ns）。**半導体の製造技術が流用できる** | 配線が物理的に増え続ける。コヒーレンス時間が短い | IBM、Google、Rigetti、富士通・理研、IQM |
| **イオントラップ** | 真空中に電磁場で浮かせたイオンの電子状態 | 室温筐体＋超高真空（レーザー多数） | **忠実度が最高**（2量子ビット99.9〜99.99%台）。全ビットが互いに繋がる | ゲートが遅い（数十〜数百μs）。スケール（多数の同時制御）が難題 | Quantinuum、IonQ |
| **中性原子** | レーザーで並べた中性原子（リュードベリ状態を利用） | 真空＋光ピンセット | **物理ビットを並べやすい**（1,000個超を実証）。配置の自由度が高い | ゲート忠実度と原子の抜け落ちが課題 | QuEra、Pasqal、Atom Computing、Infleqtion |
| **光（フォトニック）** | 光子の状態（偏光、スクイーズド光） | **常温動作が可能**（検出部は冷却） | 常温・低消費電力。**光ファイバでモジュール接続でき、量子通信と親和** | 光子の損失、確率的なゲート。大規模化はこれから | PsiQuantum、Xanadu、NTT・理研（光量子） |
| **半導体スピン** | シリコン中の電子1個のスピン | 数百mK〜1K | **既存の半導体ラインで量産できる可能性** | 実証規模がまだ小さい | Intel、Diraq、imec、日立 |
| （参考）**トポロジカル** | 準粒子（マヨラナ）で情報を符号化 | 極低温 | 原理的に誤りに強い | **存在の実証段階**。実用は遠い | Microsoft |

> 補足：**量子アニーリング（D-Wave）はゲート型とは別物**。詳細は本ノート 6 章。

## 2. 超伝導方式の中身（いちばん主流なので詳しく）

超伝導量子ビットは、**超伝導の回路にできる「振り子」の最下段と2段目を、0と1に見立てた**もの。
通常のLC共振回路だとエネルギー準位が等間隔に並んでしまい、0と1だけを狙って操作できない。
そこで**ジョセフソン接合**（超伝導体を極薄の絶縁膜で挟んだ素子）を入れて準位の間隔を不均等にし、
「0→1だけを励起するマイクロ波」を撃てるようにする。

```
【超伝導量子コンピュータの物理的な姿】

   室温                ┌──────────────────┐
   （制御エレキ）       │ マイクロ波発生器・AWG・FPGA │  ← 量子ビット1個あたり
                       └──────────┬───────┘     数本の同軸ケーブル
   ─ 4K ─────────────────────┼─────────  ← 低雑音増幅器（HEMT）
   ─ 800mK ──────────────────┼─────────
   ─ 100mK ──────────────────┼─────────  ← 減衰器で熱ノイズを落とす
   ─ 10mK ───────────────────▼─────────
                     ┌─────────────────┐
                     │  量子チップ（数cm角）  │  ← ここだけが「量子」
                     └─────────────────┘
        希釈冷凍機（高さ2m級・1台で数億円規模）

   配線が量子ビット数に比例して増える ＝ 冷凍機の冷却能力が物理的な上限になる
```

ここから2つの産業的な含意が出る。

1. **ボトルネックはチップではなく「配線と冷凍機」**。だから各社は
   **制御電子回路の極低温での集積化**（クライオCMOS）と**多チップ接続**に投資している。
   2025年に富士通・理研が256量子ビットを実現したときも、要点は素子そのものより
   **高密度実装技術**だった（2025年4月、理研・富士通発表）
2. **半導体産業とサプライチェーンが重なる**。希釈冷凍機、極低温同軸ケーブル、
   超伝導材料、パラメトリック増幅器 ― 装置・部材側に日本企業が多く関わる
   （→ [半導体製造装置](../../03_電機・電子部品/03_半導体製造装置/README.md)、[半導体・先端半導体](../02_半導体・先端半導体/README.md)）

## 3. イオントラップと中性原子

**イオントラップ**は、荷電した原子（イオン）を真空中に電磁場で浮かせ、レーザーで操作する。
原子は**自然が作った完全に同一な部品**なので、製造ばらつきがなく、忠実度で一貫して先行している。
2026年3月にQuantinuumが **94個の誤り保護された論理量子ビット**を使った計算を報告し、
IonQは2025年10月に2量子ビットゲート忠実度 **99.99%** を公表している（いずれも各社発表）。
弱点は速度と規模で、イオンを増やすほど同時制御が難しくなるため、
**小さなトラップを多数つないで大きくする**（QCCD、フォトニック接続）方向へ進んでいる。

**中性原子**は、電荷を持たない原子を「光ピンセット」で格子状に並べる。
電荷がないので相互干渉が小さく、**1,000個超の物理量子ビットを並べること自体は既に実証済み**。
QuEraは2025年11月に448個の物理原子で **96個の論理量子ビット**を検証したと発表した。
2026年3月にはGoogleが超伝導と並行して**中性原子の研究部門を新設**したと報じられており、
「超伝導一本足」ではなくなりつつあることの象徴として注目された。

## 4. 誤り訂正：この分野の本丸

量子ビットは壊れやすい。したがって**多数の質の悪い物理量子ビットを束ねて、
1個の頑丈な「論理量子ビット」を作る**。これが **量子誤り訂正（QEC）** である。

古典のパリティやRAIDと似ているが、量子では **(1) 状態をコピーできない、
(2) 測定すると壊れる、(3) ビット反転だけでなく位相反転の誤りもある** という3つの制約があり、
「壊さずに誤りの情報だけを抜き出す」巧妙な符号が必要になる。代表格が **表面符号（surface code）**。

```
【物理量子ビット → 論理量子ビット】

  ● ● ● ● ●      物理量子ビット（誤り率 0.1〜1%）
  ● ● ● ● ●   ┐
  ● ● ● ● ●   ├─▶  論理量子ビット 1個（誤り率 0.0001% 以下を目指す）
  ● ● ● ● ●   │
  ● ● ● ● ●   ┘
  表面符号：数百〜1,000個の物理ビットで1個の論理ビット

  重要なしきい値：物理誤り率が「ある値」より良くなると、
  符号を大きくするほど論理誤り率が下がる（＝ below threshold）。
  逆に、しきい値より悪いと、増やすほど誤りが増える。
```

このしきい値を実機で初めて超えたのが、2024年末に公表された Google の **Willow** チップである
（符号距離を3→5→7と大きくするほど論理誤り率が下がることを実証）。
**「量子コンピュータは原理的に作れる」と「作れるかどうか分からない」の境目**がここで越えた、
と業界が評価している転換点である。

| 世代 | 呼び方 | 何ができるか | 時期 |
| --- | --- | --- | --- |
| 現在 | **NISQ**（Noisy Intermediate-Scale Quantum） | 数十〜数千の物理ビット。誤り訂正なし。**深い計算ができない** | 〜2020年代後半 |
| 移行期 | 早期誤り耐性（early FTQC） | 数十〜数百の論理ビット。限定的な有用計算 | 2027〜2030年前後（各社ロードマップ） |
| 本命 | **FTQC**（誤り耐性量子計算） | 数千〜数百万の論理ビット。Shorや本格的な化学計算 | **2030年代**（見通しの幅が大きい） |

NISQの限界は明確で、**誤り緩和（error mitigation）** という
「同じ計算を何度も回してノイズの影響を統計的に差し引く」手法で凌いでいるが、
回数が問題サイズに対して指数的に増えるため、**規模を大きくすると破綻する**。
つまり **NISQのまま実用に到達する道は、現在ほぼ否定されている**。

## 5. 「量子ビット数」の正しい読み方

ニュースに出る「◯◯量子ビット」は、**3種類がごちゃまぜに使われている**。ここが最大の誤解ポイント。

| 呼び方 | 意味 | 2026年時点の代表値 |
| --- | --- | --- |
| **物理量子ビット** | 実際の素子の数。誤り率はそのまま | 超伝導で1,000超級、中性原子で1,200超 |
| **論理量子ビット** | 誤り訂正で束ねた頑丈な単位 | 数十個（Quantinuum 94、QuEra 96 などの検証例） |
| **アルゴリズミック量子ビット（#AQ）** | 「実際に意味のある計算に使える数」としてIonQが提唱した指標 | 64程度 |

> 注意：**物理量子ビット数どうしを方式をまたいで比べても意味がない**。
> 「量子ビット数 × 2量子ビットゲート忠実度 × 接続性 × 実行できる回路の深さ」で見る。
> 量子ボリューム（QV）やCLOPSといった複合指標もあるが、**各社が自社に有利な指標を出す**傾向があり、
> どの指標も業界標準にはなっていない。ベンチマークの出典と定義を必ず確認する。

## 6. 量子アニーリングは別枠

**量子アニーリング**（D-Wave が商用化）は、ゲート型とは目的も仕組みも異なる。

| | ゲート型量子コンピュータ | 量子アニーリング |
| --- | --- | --- |
| できること | 原理的に何でも（汎用） | **組合せ最適化の近似解**に特化 |
| 動かし方 | ゲートを順に当てる | エネルギーが最低の状態へ「冷やして落とす」 |
| 誤り訂正 | 必須。研究の中心 | 定式化が違い、同じ枠組みでは扱わない |
| 規模 | 数百〜数千物理ビット | 5,000超（D-Wave Advantage、同社公表） |
| Shorで暗号を破れるか | 将来は可能 | **できない** |
| 実用状況 | 実証段階 | **商用稼働しているが、古典ソルバーに対する明確な優位は確立していない** |

```
   ゲート型：  |0⟩─H─●─────── 回路を組み立てて答えを干渉で作る
                     │
              |0⟩────⊕─M

   アニーリング： エネルギーの地形を作り、ボールを転がして谷底を探す
                  ＼      ／＼      ／
                    ＼  ／    ＼  ／     ← 谷底＝最適解
                      ＼／        ＼／
                   量子トンネル効果で山を「抜けて」隣の谷へ行けるのが売り
```

「量子ビット数5,000超」という数字が単独で流れると、ゲート型の1,000と比べて
「D-Waveのほうが進んでいる」と誤読されやすいが、**比較できる数字ではない**。

## 7. 2026年時点の現在地まとめ

- **できている**：しきい値を下回る誤り訂正の実証、論理量子ビット数十個の作成、
  物理量子ビット1,000個級の集積、クラウド経由での商用提供
- **できていない**：商用価値のある計算での古典超え、論理量子ビット数百個以上の安定運用、
  暗号解読、汎用的なビジネス課題での投資回収
- **争点**：方式の決着（未定）、誤り訂正のオーバーヘッドをどこまで減らせるか（qLDPC符号が有望視）、
  制御エレキの集積、そして**古典アルゴリズムの改良による「脱量子化」**（→ [03](03_何に使えるのか.md)）

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **NISQ** | 誤り訂正のない中規模ノイズあり量子計算。現在の段階。深い計算ができない |
| **FTQC** | 誤り耐性量子計算。誤り訂正を効かせて任意の長さの計算ができる状態。本命 |
| **量子誤り訂正（QEC）** | 多数の物理量子ビットで1個の論理量子ビットを作る技術 |
| **論理量子ビット** | 誤り訂正済みの頑丈な量子ビット。**ニュースの数字はこれか物理かを必ず確認** |
| **表面符号（surface code）** | 最も研究が進んだ誤り訂正符号。格子状に並べる。オーバーヘッドが大きい |
| **qLDPC符号** | 表面符号より少ない物理ビットで済む新しい符号。2025〜2026年の主戦場 |
| **しきい値（threshold）** | この物理誤り率より良くなると誤り訂正が機能し始める境界 |
| **below threshold** | しきい値を下回った状態。Googleが2024年末にWillowで実証 |
| **誤り緩和（error mitigation）** | 誤り訂正の代用。統計処理でノイズを差し引く。規模が大きいと破綻する |
| **ジョセフソン接合** | 超伝導体を極薄絶縁膜で挟んだ素子。超伝導量子ビットの心臓部 |
| **希釈冷凍機** | 約10ミリケルビンまで冷やす装置。超伝導方式に必須。1台数億円規模 |
| **クライオCMOS** | 極低温で動く制御回路。配線ボトルネックの解決策として開発中 |
| **リュードベリ状態** | 中性原子方式でゲートに使う、電子が大きく広がった励起状態 |
| **QCCD** | イオンを区画間で移動させて拡張するアーキテクチャ |
| **量子アニーリング** | 組合せ最適化に特化した別方式。ゲート型と混同されやすい |
| **量子ボリューム（QV）／CLOPS** | 量子ビット数以外の複合性能指標。業界標準ではない |
