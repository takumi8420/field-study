# 何に使えるのか（用途と、誇大広告の切り分け）

このノートで分かること：**量子コンピュータが実際に効く領域はどこか**、
そして**「効く」と言われているが根拠が薄い領域はどこか**。

結論を先に書く。**本命は量子化学・材料シミュレーション**である。
理由は単純で、**自然そのものが量子力学で動いているから**。量子的な対象を量子的な装置で真似るのが、
唯一「古典では原理的に指数的に高くつく」ことがはっきりしている用途である。
一方、**宣伝でいちばん多く使われる「最適化」と「機械学習」は、加速の理論的保証がない**。
物流の配送計画や金融ポートフォリオが「量子で劇的に速くなる」という話は、
2026年時点で**古典の最良手法に勝った実証がない**。

原理は [量子ビットと計算の原理](01_量子ビットと計算の原理.md)、ハードの現状は [方式と現在地](02_方式と現在地.md)。

## 1. 加速の「型」でふるいにかける

用途の話は、必ず [01](01_量子ビットと計算の原理.md) の3つの型に当てはめてから読む。

| 型 | 保証 | 該当する用途 | 判定 |
| --- | --- | --- | --- |
| **指数的加速（証明あり）** | 数学的な裏付けあり | 素因数分解・離散対数（Shor）、量子系のシミュレーション（化学・材料）、一部の線形代数 | **本命**。ただし大規模FTQCが要る |
| **二次加速（証明あり）** | 平方根までは確実 | 総当たり探索（Grover）、モンテカルロ積分の高速化（金融リスク） | **条件付き**。1ゲートが古典より桁違いに遅く、実利は問題が巨大な場合のみ |
| **ヒューリスティック（証明なし）** | なし | QAOA・VQE による組合せ最適化、量子機械学習、量子アニーリング | **要注意**。宣伝の大半がここ |

> 読み方のコツ：プレスリリースに「最適化」「AI」「金融」と書いてあり、
> **どのアルゴリズムで、古典の何と比べたのか**が書かれていなければ、3段目のヒューリスティックだと考えてよい。

## 2. 本命：量子化学・材料シミュレーション

分子や結晶の中で電子がどう振る舞うかを解くのが量子化学。
電子はお互いに影響し合うため、**電子の数が増えると、考慮すべき状態の数が指数的に増える**。
古典計算では近似（DFTなど）でしのいでいるが、**遷移金属を含む触媒や超伝導体など、
近似が効かない系では精度が足りない**。ここが量子の出番になる。

```
【古典の限界】
 電子 20個 の厳密計算 → 現代のスパコンで可能
 電子 50個 の厳密計算 → 状態数が約2^100。**宇宙の年齢でも終わらない**
                          ↓
 古典は近似（DFT・CCSD(T)）でしのぐ → 触媒・磁性体・超伝導体では精度不足

【量子の主張】
 分子の電子系  ──マッピング──▶  量子ビット系
 （自然の量子系）              （人工の量子系）
   同じ物理法則に従うので、電子1個 ≒ 量子ビット数個で「そのまま」表現できる
   → 必要な量子ビット数が**指数ではなく比例**で済む ＝ 指数的加速
```

具体的な出口は次の通り。

| 分野 | 解きたいこと | 産業的な意味 | 関連ノート |
| --- | --- | --- | --- |
| 触媒 | 窒素固定（アンモニア合成）の反応経路、CO2還元 | 世界のエネルギーの数%を使うハーバー・ボッシュ法の改良 | [総合化学](../../10_素材・化学/01_総合化学/README.md)、[水素・アンモニア](../06_水素・アンモニア/README.md) |
| 電池材料 | 電解質・正極材の中のイオンの動き | 全固体電池などの材料探索の短縮 | [蓄電池](../04_蓄電池/README.md) |
| 創薬 | タンパク質と薬剤の結合エネルギーの精密計算 | 候補絞り込みの精度向上（**構造予測はAIの領分で、別物**） | [医薬品（新薬）](../../09_医薬・医療・ヘルスケア/01_医薬品（新薬）/README.md) |
| 超伝導・磁性 | 強相関電子系の基底状態 | 常温超伝導など基礎材料の探索 | [電子材料](../../10_素材・化学/03_電子材料/README.md) |

**ただし時期は近くない**。2026年に公表された複数の資源見積もり研究は、
**化学で量子優位が出始めるのは論理量子ビット200個前後から**、
経済的な優位が出るのは**2030年代半ば**という見通しを示している（arXiv等の推計。幅が大きい）。
論理量子ビットは2026年時点で数十個なので、**まだ1桁足りない**。

## 3. 最適化：いちばん宣伝され、いちばん根拠が薄い

「配送ルート」「シフト表」「ポートフォリオ」といった**組合せ最適化**は、
説明しやすいため営業資料の定番になっている。実態は次の通り。

| 論点 | 実態 |
| --- | --- |
| 理論的な加速 | **ない**。QAOAもアニーリングも、古典に勝つ保証は証明されていない |
| 実証の状況 | 小規模な問題で「古典と同等」か「古典がやや速い」という結果が多い |
| 古典側の強さ | 商用ソルバー（Gurobi、CPLEX等）と近年のGPU実装が非常に強い。**基準線が毎年上がる** |
| それでも進む理由 | **定式化（QUBO化）の過程で問題が整理され、古典ソルバーで解決してしまう**という副産物が実際にある |

> ここで押さえたい概念が **「脱量子化（dequantization）」**。
> 量子アルゴリズムの発表をきっかけに古典アルゴリズムが改良され、
> **量子の優位が後から消える**という現象が繰り返し起きている。
> 「今日の時点で量子が古典に勝っている」と主張するには、**古典側の最新手法と比較した結果が必須**。

## 4. 金融・リスク計算

| 用途 | アルゴリズム | 現実的な評価 |
| --- | --- | --- |
| デリバティブ価格評価、VaR（リスク量）計算 | 振幅推定（モンテカルロの二次加速） | **理論保証はある**。ただし桁違いの回路深さが必要で、FTQC待ち |
| ポートフォリオ最適化 | QAOA / アニーリング | ヒューリスティック。優位は未証明 |
| 不正検知・信用スコア | 量子機械学習 | 根拠が最も薄い |
| **暗号の作り替え** | （量子とは別技術のPQC） | **今すぐ着手すべき唯一の実務**（→ [04](04_暗号と産業構造.md)） |

金融機関が量子に取り組む本当の理由は、計算そのものよりも
**「Q-Day（暗号が破られる日）への備え」と「人材・知見の先行確保」**にある。
（→ [メガバンク](../../05_金融/01_メガバンク/README.md)、[資産運用](../../05_金融/06_資産運用/README.md)）

## 5. 機械学習・AI：最も慎重に扱う領域

「量子AI」は最も誇張されやすい。理由は3つ。

1. **データを入れる入口が詰まる**。N個のデータを量子状態に載せるのにN回の操作が要るなら、
   その時点で加速が消える（**入出力ボトルネック**）
2. **量子機械学習の多くは、古典で効率的に模倣できる**ことが示されている（脱量子化の典型例）
3. **古典のAIが強すぎる**。GPUクラスタの実力は年々伸びており、基準線が高い
   （→ [生成AI](../01_生成AI/README.md)）

逆に、**AIが量子を助ける方向は実際に機能している**。誤り訂正のデコード（どこで誤りが起きたかの推定）や
パルス制御の最適化に機械学習が使われ、成果が出ている。**「量子でAI」より「AIで量子」のほうが現実的**。

## 6. そもそも向かない領域

| 用途 | なぜ向かないか |
| --- | --- |
| データベース検索、ビッグデータ集計 | データの読み込みがボトルネック。Groverの二次加速では埋まらない |
| Webアプリ、業務システム、一般の演算 | 古典CPUが圧倒的に安く速い。量子は高価・低速・確率的 |
| 動画処理、レンダリング | 並列性は古典GPUの土俵 |
| AIモデルの学習 | 上記の通り。実証なし |
| 乱数生成 | 量子で作れるが、**量子コンピュータは不要**（量子乱数発生器という別の安価な装置で足りる） |

## 7. 「使えるか」を判定するチェックリスト

発表やベンダー提案を見たとき、次の5点を確認すると誇大広告をほぼふるい落とせる。

```
 ① 物理量子ビットか、論理量子ビットか？      → 混同した比較は無効
 ② 比較対象は「古典の最良手法」か？          → 総当たりや旧手法と比べていないか
 ③ 実機で解いたのか、シミュレータか？        → 「量子コンピュータで実証」の多くは古典シミュレータ
 ④ 問題サイズは実務レベルか？                → 都市10個の巡回セールスマンは古典で一瞬
 ⑤ アルゴリズムに加速の証明はあるか？        → QAOA/VQE/アニーリングは「なし」
```

| 表現 | 読み替え |
| --- | --- |
| 「量子コンピュータで◯◯に成功」 | 多くは**小規模な原理実証**。実務規模ではない |
| 「従来の1億倍高速」 | **何と比べたか**が書かれていなければ無意味 |
| 「量子優位を達成」 | 実用価値のないランダム回路サンプリングのことが多い。**実用タスクではない** |
| 「量子インスパイアード」 | **量子コンピュータは使っていない**。古典アルゴリズムの商品名 |
| 「2025年に実用化」 | 「クラウドで試せる」の意味であることが多い |

## 8. では今、産業側は何をしているのか

2026年時点で、量子関連企業の売上の実体は**大半が政府・大企業の研究開発予算**である。
業務課題を解いた対価としての売上ではない。

| 収益源 | 内容 | 規模感 |
| --- | --- | --- |
| 政府調達・補助金 | 国立研究所・防衛・大学向けのハードウェア納入 | **売上の最大の柱**。米国は2026年5月に約20億ドルを複数社へ拠出と報じられる |
| クラウド利用料 | AWS Braket、Azure Quantum、IBM Quantum 等の従量課金 | 小さい。実験用途が中心 |
| 共同研究契約 | 化学・製薬・金融・自動車との実証（PoC） | 数千万〜数億円／件 |
| ソフト・ツール | SDK、コンパイラ、誤り訂正ミドルウェア | 市場はまだ小さい |
| 部材・装置 | 希釈冷凍機、極低温部品、レーザー、制御エレキ | **実需がある層。地味だが確実に売れる** |

> 投資家向けの言い方をすれば、**量子産業で今いちばん堅いのは「ツルハシ（装置・部材）」**。
> 掘る側（アルゴリズムで価値を出す）はまだ鉱脈に届いていない。
> 純粋量子企業で最大のIonQでも2025年売上は約1.3億ドル（同社公表、前年比約3倍）で、
> 産業としては**半導体1社の四半期にも届かない規模**である。

## まとめ

- **本命は量子化学・材料**。理由は「量子を量子で真似る」が唯一の証明された指数加速だから。時期は2030年代
- **最適化と機械学習は保証がない**。宣伝の大半はここに集中している
- **今すぐ実務になるのは暗号の移行だけ**（→ [暗号と産業構造](04_暗号と産業構造.md)）
- 判定の軸は「論理か物理か」「古典の最良手法と比べたか」「実機か」の3つ

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **量子化学計算** | 分子・材料中の電子の振る舞いを解くこと。量子計算の本命用途 |
| **VQE（変分量子固有値ソルバー）** | 古典と量子を往復して分子の基底エネルギーを求める手法。NISQ向けだが加速の保証はない |
| **QPE（量子位相推定）** | 厳密にエネルギーを求める手法。指数加速の本命だがFTQCが要る |
| **QAOA** | 組合せ最適化向けの量子アルゴリズム。加速の証明はない |
| **QUBO** | 最適化問題を「0/1変数の2次式」に書き直した形式。アニーリングに投げる際の標準形 |
| **Grover探索** | 総当たり探索を平方根に短縮。二次加速どまり |
| **振幅推定** | モンテカルロ法を二次加速する。金融リスク計算の本命 |
| **脱量子化（dequantization）** | 量子の優位が古典アルゴリズムの改良で消える現象。頻繁に起きている |
| **入出力ボトルネック** | 大量データを量子状態に読み書きする時間で加速が消える問題 |
| **量子優位／量子超越** | 古典を上回ったという主張。**実用価値のないタスクでの主張が多い**点に注意 |
| **量子インスパイアード** | 量子の発想を借りた**古典**アルゴリズム。量子ハードは使わない |
| **PoC（実証実験）** | 本番導入前の試行。量子業界の案件の大半はこの段階 |
