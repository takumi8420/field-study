# 直近トピック（2026年9月時点）

報道・企業発表ベースの整理。数値は必ず年月と出典の種類を添えた。
**企業発表の性能値は第三者による査読・再現を経ていないものが多い**ため、
「◯◯社発表」と書いたものは、そのまま事実として扱わないこと。

構造的な背景は [方式と現在地](02_方式と現在地.md)、[何に使えるのか](03_何に使えるのか.md)、
[暗号と産業構造](04_暗号と産業構造.md) を参照。

## 1. 競争軸が「量」から「質」へ完全に移った

2026年の最大の変化は、**話題の中心が物理量子ビット数から論理量子ビット数に移ったこと**。

| 時期 | 発表 | 内容 |
| --- | --- | --- |
| 2024年12月 | Google **Willow** | 符号距離を大きくするほど論理誤り率が下がる（**below threshold**）ことを実機で実証。この分野の転換点とされる |
| 2025年11月 | QuEra（中性原子） | 448個の物理原子で **96個の論理量子ビット**を検証したと発表 |
| 2026年3月 | Quantinuum（イオントラップ） | **94個の誤り保護された論理量子ビット**での計算を報告。損益分岐（break-even）超えと主張 |
| 2026年3月 | Microsoft ＋ Quantinuum | H2システムで **12論理量子ビット**、論理誤り率 約 2/1,000 を実証と報道 |
| 2026年4月 | QuEra | 物理2個で論理1個を作る **qLDPC符号**の実装を発表。表面符号よりオーバーヘッドが小さい |

```
【この2年で起きたこと】

 2024年まで： 「そもそも誤り訂正は機能するのか？」が未解決
                        ↓ Willow（2024年12月）
 2025〜26年： 「機能する。あとはどれだけ安く積めるか」の勝負へ
                        ↓
 現在の主戦場： 表面符号（物理1,000個で論理1個）
                 → qLDPC符号（物理数個〜数十個で論理1個）へのオーバーヘッド削減競争
```

> 意味：**「原理的に作れるか」の議論は終わり、「工学的にいくらで作れるか」の議論に移った**。
> これは半導体が研究から産業になった瞬間と似た構造変化だが、
> **論理量子ビットは数十個**にすぎず、実用（数百〜数千個）まではまだ遠い。

## 2. 方式の勝者はまだ決まっていない（むしろ分散した）

2026年に象徴的だったのは、**先行者が「二股」をかけ始めた**こと。

- **Google が中性原子の専門研究部門を新設**（2026年3月、米コロラド州ボルダー）と報じられた。
  超伝導で先頭を走る企業が、並行して別方式に投資したことになる
- **IonQ が半導体ファウンドリ SkyWater Technology を約18億ドルで買収**（2026年、報道ベース）。
  イオントラップのチップ製造を垂直統合する狙い
- **PsiQuantum**（光方式）はブリスベンとシカゴの計算センターを2026年に着工。
  GlobalFoundries の量産ラインでチップを作る戦略を継続

| 方式 | 2026年時点の状況 |
| --- | --- |
| 超伝導 | 物理ビット数と資金で先行。配線と冷凍能力が壁 |
| イオントラップ | 忠実度・論理ビット数で先行。速度とスケールが壁 |
| 中性原子 | 物理ビットの並べやすさで台頭。忠実度が追いつきつつある |
| 光 | 常温動作・製造流用が強み。大規模化はこれから |
| 半導体スピン | 量産適性が強み。規模はまだ小さい |

## 3. 国家マネーが本格的に流れ込んだ

**この産業は依然として政府予算で回っている**。2026年はその規模が一段上がった年になった。

| 時期 | 国・主体 | 内容 |
| --- | --- | --- |
| 2026年5月 | 米国政府 | 約**20億ドル**を9社前後に拠出と報じられる。IBMに約10億ドル、D-Wave・Rigetti・Infleqtionに各約1億ドル、GlobalFoundriesに3.75億ドル |
| 2026年5月 | 米商務省（CHIPS法） | Quantinuum に**1億ドル**。誤り耐性イオントラップ機の製造ボトルネック解消向け |
| 2026年3月 | 英国 | 量子コンピュータ調達プログラム **ProQure** に **10億ポンド**（約2,140億円）規模の投資を発表と報じられる |
| 2026年7月 | 日本・経済産業省 | 産業構造審議会で「量子コンピュータ政策の今後の方向性」を提示（産業化・供給網整備の方向） |

> 構図：**米国の資金が「量子ファウンドリ」（製造基盤）に向かい始めた**のが2026年の特徴。
> 個別企業の研究支援から、**半導体と同じく製造インフラを国内に抱える**発想へ移っている
> （→ [半導体・先端半導体](../02_半導体・先端半導体/README.md) の地政学の章と同じ論理）。

## 5. 「暗号移行の期限」が現実の締切になった

技術の見通しが不確かなまま、**制度の期限だけが確定している**というねじれが鮮明になった年でもある。

```
  2026年 9月21日  FIPS 140-2 認証が「Historical」へ（米NIST）
  2026年12月31日  EU加盟国のPQC移行 国家戦略の策定期限（EU NIS協力グループ）
  2027年 1月 1日  米国家安全保障システムの新規調達は耐量子対応が必須（NSA CNSA 2.0）
  ───────────────────────────────────────────────
  → 2026年後半〜2027年初頭は、**3つの期限が重なる山場**
  2030年 ソフト・ファーム署名、2033年 Web/クラウド/OS、2035年 連邦システム全体
```

同時に、**RSA-2048 解読に必要な資源の見積もりが下がり続けている**点も注意。
2019年に物理2,000万量子ビットとされたものが、2025年5月のGidney論文で**100万量子ビット未満**へ、
2026年2月には Iceberg Quantum が qLDPC符号で **10万量子ビット未満**と主張した（企業発表）。
**ハードが進んだのではなく、アルゴリズムと符号が改良されている**のが本質で、
**Q-Dayは技術進歩だけでなく「理論の改良」で前倒しされうる**ことを意味する。
（詳細は [暗号と産業構造](04_暗号と産業構造.md)）

## 6. 「量子優位」の主張に対する反証も強まった

2026年は、期待だけでなく**冷静な再評価**も目立った年だった。

- 2026年8月、量子アルゴリズムのベンチマークを**より現実的な条件で測り直す**研究が公表され、
  従来の優位主張の多くが**古典の最良手法と比較していない**ことが指摘された
- 化学分野の資源見積もり研究は、**量子優位が見え始めるのは論理量子ビット200個前後**、
  経済的優位は**2030年代半ば**という水準を示している（学術論文ベース。推計の幅は大きい）
- 実務上の現実解として、**量子＋古典＋AIのハイブリッド**が定着しつつある

| 主張 | 2026年時点の実態 |
| --- | --- |
| 「量子で創薬が変わる」 | 論理量子ビット200個級が要る。現在は数十個 |
| 「量子で物流最適化」 | 加速の理論保証なし。古典ソルバーが強い |
| 「量子AIが来る」 | 実証なし。逆に**AIが誤り訂正のデコードに使われている**のが実態 |
| 「暗号がもう破られる」 | 実機は物理1,000量子ビット級。2〜3桁足りない |

## 7. 市場と企業の実態：規模はまだ小さい

| 指標 | 数値 | 年・出典 |
| --- | --- | --- |
| 世界の量子コンピューティング市場 | 約10.8億ドル | 2024年、QED-C調査（JETRO整理） |
| 同 | 約22億ドル | 2026年（予測）、複数調査の整理 |
| 同 | 約25億ドル → 2031年に約99億ドル（CAGR約32%） | 2026→2031年、調査会社推計 |
| 日本市場 | 約1.97億ドル（2023年）→ 2032年に約28.8億ドル | 調査会社推計 |
| IonQ（純粋量子企業で最大）の売上 | 約1.3億ドル（前年比約3倍）、2026年見通し 2.25〜2.45億ドル | 2025年実績・同社公表 |

> 桁感の確認：**世界市場の全体が約20億ドル台**。これは大手半導体1社の四半期売上にも届かない。
> 株式市場の関心の大きさに対して、**実体経済の規模は極端に小さい**。
> しかも売上の大半は政府・大企業の研究開発予算であり、**業務課題を解いた対価ではない**
> （→ [03_何に使えるのか](03_何に使えるのか.md) の8章）。

## 8. 全体の構図（まとめ）

1. **誤り訂正は「できるか」から「いくらで積めるか」へ移った**。2024年末のWillowが分水嶺で、
   2025〜26年は論理量子ビットを数十個まで積み上げた段階。実用（数百〜数千）にはまだ1〜2桁足りない
2. **方式は決着していない**。むしろGoogleが中性原子へ、IonQが製造の垂直統合へと、**分散と囲い込みが進んだ**
3. **金は政府から出ている**。2026年は米20億ドル、英10億ポンド級の国費が動き、
   支援先が研究から**製造基盤（量子ファウンドリ）**へ移った
4. **日本は2026年度の1,000量子ビット機が節目**。強みは装置・部材と基礎研究、弱みはソフト層と資金
5. **唯一、今すぐ動くべき実務は暗号移行**。2026年後半〜2027年初頭に制度期限が集中し、
   RSA解読の見積もりは理論改良で下がり続けている。技術の到来時期は不確かでも、**締切は確定している**

## 用語メモ

このノートで初めて出た、あるいは特に誤読されやすい用語だけを置く。
基礎用語は [01](01_量子ビットと計算の原理.md)〜[04](04_暗号と産業構造.md) の各用語メモを参照。

| 用語 | 意味 |
| --- | --- |
| **below threshold** | 誤り訂正の「しきい値」を下回った状態。符号を大きくするほど論理誤り率が下がる。2024年末にGoogle Willowが実機で初実証 |
| **符号距離** | 誤り訂正符号の頑丈さの指標。大きいほど多くの誤りを訂正できるが、必要な物理量子ビットが増える |
| **qLDPC符号** | 表面符号より少ない物理量子ビットで論理量子ビットを作れる符号。2025〜2026年の主戦場 |
| **break-even（損益分岐）** | 誤り訂正した論理量子ビットの誤り率が、元の物理量子ビットより良くなった状態。QECが「割に合った」境界 |
| **量子ファウンドリ** | 量子チップの受託製造基盤。2026年に米国の公的資金が向かい始めた領域 |
| **ProQure** | 英国の量子コンピュータ調達プログラム（2026年3月発表、10億ポンド規模と報道） |
| **Kookaburra / Nighthawk** | IBMが2026年に計画する誤り訂正モジュール／120量子ビットプロセッサの名称 |
| **CHIPS法（CHIPS and Science Act）** | 米国の半導体・科学技術支援法。量子企業への支援にも使われている |
