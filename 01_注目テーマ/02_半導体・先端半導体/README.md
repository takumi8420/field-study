## 1. テーマの定義・範囲

「先端半導体」とは一般に、**微細化の最前線にあるロジック（およびHBM等の先端メモリ）**を指す。
AI・データセンター、経済安全保障、日本の産業政策という3つの文脈が同時に交差しているのが、
このテーマが注目される理由。

## 2. いま押さえるべき論点（5つ）

1. **微細化は減速し、勝負は「束ね方」へ移った** — チップレットと先端パッケージ
2. **ボトルネックは前工程ではなく後工程とHBM** — CoWoS能力が世界のAI供給量を決める
3. **買い手が少数のクラウド大手に集中している** — 彼らの設備投資が需給そのもの
4. **産業政策と輸出管理が需給を直接動かす** — 市場原理だけでは読めない
5. **制約条件は最終的に電力** — チップが作れても電気と用地がなければ動かない

## 3. バリューチェーンのどこに利益があるか

```
EDA/IP  →  設計(ファブレス)  →  前工程(ファウンドリ)  →  HBM  →  先端パッケージ  →  クラウド/サービス
  寡占        高利益率            TSMCの寡占          3社寡占      能力が不足        巨額投資の主体
```

利益は**寡占または能力不足が起きている場所**に集中する。
現在は 設計（NVIDIA）／製造（TSMC）／HBM（SK hynix）／装置（ASML）に偏在している。

## 5. 収益モデル・コスト構造

- ファブレスは固定費が軽く高利益率。ただし**ソフト資産（CUDA等）が参入障壁の本体**
- ファウンドリは装置償却が主コスト。**稼働率が落ちた瞬間に赤字**
- メモリは市況商品だが、**HBMだけは高付加価値**という二重構造
- 先端品は「作れる量」が価格を決めるため、**能力増強の発表が最重要ニュース**になる

## 6. 競争要因（KSF）と参入障壁

投資継続力／歩留まりノウハウ／大口顧客との共同開発／ソフトウェアエコシステム／
装置・材料の確保枠。新規参入は事実上、国策の支援なしには成立しない。

## 7. 規制・法制度

米国の対中輸出管理（性能しきい値ベース、域外適用あり）、日本・オランダの装置輸出管理、
CHIPS法・欧州チップス法・日本の経済安保予算・中国の大基金。詳細は ③。

## 8. 最近のトピック

詳細と出典は [⑥ 直近トピック（2026年9月時点）](06_直近トピック_2026.md)。要点だけ挙げると:

- **2nm世代（GAA＋裏面電源）が量産段階へ** — TSMC N2、Intel 18A（Panther Lake）
- **ボトルネックはHBM4と先端パッケージ** — Rubinの生産計画がHBM4検証で下振れ
- **DRAM価格の歴史的高騰** — データセンターが供給の大半を吸収し、PC・スマホに波及
- **輸出規制が同盟国の装置企業にも拡大する方向** — 中国は装置の国産化で応じる
- **Rapidus は量産前の最終段階** — 2027年度後半の量産開始を目標
