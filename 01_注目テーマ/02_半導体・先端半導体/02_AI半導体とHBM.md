# AI半導体とHBM

いま半導体業界の利益が最も集中している領域。
「計算する石（GPU）」「記憶する石（HBM）」「それを束ねる技術（先端パッケージ）」の三点セットで理解する。

## 1. AIの計算は何をしているか

生成AIの学習・推論は、実質的に**巨大な行列演算の繰り返し**。
逐次処理が得意なCPUより、単純な演算を大量に並列実行できるGPU系のほうが桁違いに速い。

| 用途 | 特徴 | 効く性能 |
| --- | --- | --- |
| **学習（Training）** | 巨大モデルを数千〜数万チップで数週間回す | 演算性能、**チップ間通信**、メモリ容量 |
| **推論（Inference）** | 学習済みモデルを大量のユーザーに提供 | メモリ帯域、電力効率、コスト |

近年は市場の重心が学習から**推論**へ移りつつある。推論はユーザー数に比例して伸び続けるため、
「1回作って終わり」の学習より長期的な需要が大きいと見られている。

## 2. なぜHBMが必要か（メモリの壁）

演算器の性能は伸びたのに、**メモリからデータを運ぶ速度**が追いつかない。これが「メモリの壁」。
AIの推論では演算器が待たされる時間が支配的になるため、**帯域（Bandwidth）**が最重要になる。

**HBM（High Bandwidth Memory）** はその回答：

- DRAMチップを**垂直に積層**（8段、12段、16段）し、**TSV**（貫通電極）で上下を直結
- GPUのすぐ隣にインターポーザ経由で置き、**極太のデータ経路**をつくる
- 通常のDRAMより単価も利幅も高く、メモリ各社の収益源になった

| 世代 | 位置づけ |
| --- | --- |
| HBM2E / HBM3 | 前世代のAIアクセラレータ向け |
| **HBM3E** | 現行AI GPUの主力。8段/12段 |
| **HBM4** | 次世代。ベースダイをロジックファウンドリが作る方向で、**メモリとロジックの境界が溶けつつある** |

プレイヤーは **SK hynix（エスケー・ハイニックス）、Micron（マイクロン）、Samsung（サムスン）** の3社。
HBMは歩留まりが難しく、先行したSK hynixが強い立場を取っている。
HBM生産に能力を割く分、汎用DRAMの供給が絞られて市況が上がる、という波及も起きる。

## 3. 先端パッケージ＝本当のボトルネック

AI向けGPUは「大きなロジックダイ＋複数のHBM」を1つのパッケージに収める必要がある。
これを担うのが **2.5D実装（TSMC〈ティーエスエムシー〉のCoWoSなど）**。

```
        ┌───────── パッケージ基板（FC-BGA） ─────────┐
        │   ┌──── シリコンインターポーザ ────┐        │
        │   │ [HBM] [HBM] [ GPUダイ ] [HBM] │        │
        │   └───────────────────────────────┘        │
        └────────────────────────────────────────────┘
```

- GPUの前工程が空いていても、**CoWoS能力とHBM供給がなければ出荷できない**
- このため増産ニュースは「ウェハー」ではなく「**CoWoS能力を何倍にする**」という形で語られる
- OSAT企業のASE（エーエスイー）やAmkor（アムコー）、TSMCが後工程能力へ大型投資を続けている

## 4. 競争構図

| 立場 | プレイヤー | ポイント |
| --- | --- | --- |
| GPU | **NVIDIA（エヌビディア）** | 圧倒的シェア。強さの本質はチップ単体でなく **CUDA というソフト資産**と、ラック単位で売る形態 |
| 対抗GPU | AMD（エーエムディー、Instinct）、Intel（インテル、Gaudi等） | 性能は接近しても、ソフトの移行コストが壁 |
| 自社開発チップ | Google（グーグル、TPU）、Amazon（アマゾン、Trainium/Inferentia）、Microsoft（マイクロソフト）、Meta（メタ） | 自社需要が巨大なので内製が成り立つ。NVIDIA依存とコストの低減が狙い |
| スタートアップ | Cerebras（セレブラス）、Groq（グロック）等 | 推論特化・独自アーキテクチャで差別化 |
| 製造 | **TSMC（ティーエスエムシー）** | 上記のほぼ全員がTSMCで作る。誰が勝ってもTSMCが儲かる構造 |
| メモリ | SK hynix（エスケー・ハイニックス）、Micron（マイクロン）、Samsung（サムスン） | HBMの供給枠が事実上の参入チケット |

商流の理解として重要なのは、**買い手がハイパースケーラー（クラウド大手）に集中している**こと。
少数の巨大顧客の設備投資計画が、そのまま業界の需給を決める。

## 5. 制約条件は「電力」と「熱」

- AIデータセンターは1施設で数十〜数百MW級。**電力系統の空きと送電網が立地を決める**
- 発熱密度が上がり、空冷では追いつかず**液冷**が標準化しつつある
- 半導体の話が、電力・発電・冷却・不動産（データセンター）の話と直結する
  → [データセンター](../../04_情報通信・IT・ネット/03_データセンター/README.md)、[電力](../../11_資源・エネルギー・鉄鋼金属/04_電力/README.md) と合わせて見る

## 6. 注意して見るべきリスク

- **需要の持続性**：学習需要の一巡、投資回収（ROI）への懐疑が出ると設備投資は急減しうる
- **在庫の二重計上**：供給不足局面では顧客が重複発注しやすく、実需以上の受注に見えることがある
- **集中リスク**：TSMC・SK hynix・ASML（エーエスエムエル）・NVIDIA のどこか1つが止まると連鎖する
- **電力制約**：チップがあっても電気と用地がなければ設置できない

## 用語メモ

- **CoWoS**：Chip on Wafer on Substrate。TSMCの2.5D実装技術
- **TSV**：シリコン貫通電極。積層チップの縦方向配線
- **NVLink / InfiniBand / イーサネット**：チップ間・サーバー間の高速接続
- **ラックスケール**：チップ単体でなくラック丸ごとを1つの計算機として売る形態
- **トークン**：生成AIの処理単位。推論コストはトークン当たりで語られる
