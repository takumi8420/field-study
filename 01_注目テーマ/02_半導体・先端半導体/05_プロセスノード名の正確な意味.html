「2nm」「3nm」の正確な意味

注目テーマ半導体・先端半導体
あこのページの単語集用語に触れると意味を確認できます8語
ゲート長ハーフピッチデナード則ムーアの法則CPP / MMPトラック（T）MTr/mm²Å（オングストローム）

結論から言うと、いまの「2nm」はチップ上のどの寸法も指していない。
世代を表すブランド名であり、長さではない。以下、なぜそうなったかを順に押さえる。

1. 昔は本当に長さだった（〜2000年代前半）

初期の「◯µm / ◯nm」は実在する寸法を指していた。

  • ゲート長：トランジスタのスイッチ部分の長さ
  • ハーフピッチ：配線の「線幅＋間隔」の半分

半導体は「1世代ごとに寸法を約0.7倍」というリズムで進んできた。
0.7倍にすると面積は 0.7 × 0.7 ≒ 0.5倍、つまり同じ面積に2倍のトランジスタが載る。

1000 → 700 → 500 → 350 → 250 → 180 → 130 → 90 → 65 → 45 → 32 → 22 → 14 → 10 → 7 → 5 → 3 → 2
        （各段はおおむね ×0.7。この数列そのものが「世代の番号」になった）

この時代は デナード則（寸法を縮めると電圧も下げられ、速く・省電力になる）が効いていたので、
「小さくする＝全部良くなる」が成り立っていた。

2. 物理とノード名が切れた（2000年代半ば〜）

寸法を縮めるとリーク電流（漏れ電流）が無視できなくなり、電圧を下げられなくなった。
その結果、ゲート長は20〜25nm前後で縮まなくなった。

しかし業界は0.7倍の数列を名乗り続けた。つまり：

世代名 実際のゲート長（目安）
65nm約35nm
32nm約30nm
22nm（FinFET登場）約25nm
7nm / 5nm / 3nm / 2nmいずれも十数〜20nm台で頭打ち

2011年のFinFET以降は、平面構造ですらないので「ゲート長◯nm」という比較自体が意味を失った。
ノード名は、寸法ではなく「前世代からこれだけ良くなった新世代」というラベルになった。

3. では「2nm世代」は何を約束しているのか

各社が新ノードで示すのは、だいたい次のパッケージ（前世代比の目安）。

指標 典型的な改善幅
トランジスタ密度1.1〜1.3倍程度（かつては2倍だった）
同じ電力での性能+10〜15%
同じ性能での消費電力−25〜30%

つまり「2nm」＝「3nm世代の次に来る、性能・電力・密度をこれだけ改善した製造プロセス」という意味。
数字の 2 と物理量の対応は、もう無い。

4. 本当に比べるべき3つの数字

ノード名でなく、以下で比較するのが正しい読み方。

指標 意味 先端での目安
CPP（Contacted Poly Pitch＝ゲートピッチ）隣り合うトランジスタの間隔45〜50nm前後
MMP（Minimum Metal Pitch＝最小配線ピッチ）最も細かい配線層の間隔20〜30nm前後
トラック数（セル高さ）標準セルの背の高さ。6T→5Tと低くすると面積が縮む5〜6T

論理回路の密度はおおむね 1 ÷（CPP × MMP × トラック数） に比例する。
ここに「2」も「3」も出てこない、というのがこの話の要点。

総合的な物差しとしては MTr/mm²（1mm²あたり百万トランジスタ数） が使われる。
ただしSRAMとロジックで密度が違うため、同じ条件での比較でないと意味がない。

5. メーカー間で同じ数字でも中身が違う

これが実害のある誤解ポイント。

  • 歴史的に Intelの「10nm」はTSMCの「7nm」と同程度の密度だった。
    Intelは名前で損をしていると考え、2021年に 10nm→「Intel 7」 と改名した（中身は変えずに名前を他社基準に合わせた）。
  • 現在の各社の呼称：
    • TSMC：N5 → N3 → N2 → A16 → A14
    • Intel：Intel 7 → Intel 4 → Intel 3 → 18A → 14A
    • Samsung：SF4 → SF3 → SF2
  • A16 / A14 の「A」はオングストローム（1Å = 0.1nm）。A14 は「1.4nm世代」という意味で、
    ナノメートル表記では小数になって見栄えが悪いので単位を変えただけ。中身の考え方は同じ。

「TSMCの2nmとIntelの18Aはどちらが上か」という問いは、名前では決まらない。
密度・性能・電力・歩留まり・供給量で見るしかない。

6. 数字が止まっても進歩は続く（等価スケーリング）

寸法で稼げなくなった分、別の方法で世代を進めている。

手法 内容
構造の変更プレーナ → FinFET → GAA（ナノシート）。2nm世代の主役はこれ
裏面電源供給（BSPDN）電源配線をウェハー裏面に移し、表面は信号専用に。Intelは PowerVia、TSMCは Super Power Rail と呼ぶ
DTCO設計と製造を一体で最適化し、セル高さを詰める
チップレット＋先端パッケージ1チップを小分けにして束ね、実効的な集積度を上げる

だから最近のノード更新は「どれだけ小さくしたか」より
「GAAを入れたか／裏面電源を入れたか」で語られることが多い。

7. ニュースを読むときのチェックリスト

「2nm量産開始」と見たら、次の5点を確認する。

  1. どこの2nmか（TSMC N2 / Intel 18A / Samsung SF2 / Rapidus 2nm）
  2. どの段階か（試作／リスク生産／量産開始／歩留まり安定）
  3. GAAか、裏面電源はあるか（世代の実体はここ）
  4. 改善幅はいくつか（性能+◯%、電力−◯%、密度×◯）
  5. 誰向けに作るのか（スマホSoC／AI GPU／車載）— 用途で意味が変わる

用語メモ

  • デナード則：寸法縮小に伴って電圧も下げられるという経験則。2000年代に崩れた
  • ムーアの法則：集積度が約2年で2倍になるという経験則。鈍化したが「等価スケーリング」で延命中
  • CPP / MMP：ゲートピッチ／最小配線ピッチ。ノードの実体を示す数値
  • トラック（T）：標準セルの高さの単位。6T→5Tで面積が縮む
  • MTr/mm²：面積あたりのトランジスタ数
  • Å（オングストローム）：0.1nm。A16＝1.6nm世代の意味
