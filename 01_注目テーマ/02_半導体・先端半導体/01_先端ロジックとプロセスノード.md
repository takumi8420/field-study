# 先端ロジックとプロセスノード

「◯nm」という数字の意味と、なぜ最先端を追える企業が3社しか残らなかったのかを押さえる。

> 本フォルダの数値・時期は2026年前半までの公表情報ベース。最新は各社IR・WSTS等で確認すること。

## 1. 「◯nm」はもう寸法ではない

- 昔はゲート長などの実寸を指していたが、**現在のノード名は世代を示すブランド名**。
  同じ「3nm」でもメーカーが違えばトランジスタ密度は違う。
- 比較したいときは、トランジスタ密度（MTr/mm²）・性能・消費電力・コスト（PPAC）で見る。
- **なぜ数字と実寸が切れたのか、では何を比べるべきかは
  [⑤ プロセスノード名の正確な意味](05_プロセスノード名の正確な意味.md) で詳しく扱う。**
- 呼び方も各社バラバラ：TSMC は N5 / N3 / N2、Intel は Intel 4 / Intel 3 / **18A** / 14A（A＝オングストローム、18A＝1.8nm相当）、Samsung は SF4 / SF3 / SF2。

## 2. トランジスタ構造の変遷

| 世代 | 構造 | 要点 |
| --- | --- | --- |
| 〜28nm | **プレーナ（平面）** | 平らなゲート。微細化すると電流の漏れが止められなくなった |
| 22/16nm〜3nm | **FinFET** | チャネルを「ヒレ」状に立てて3面から制御。漏れを大幅に抑えた |
| 2nm世代〜 | **GAA / ナノシート** | チャネルを板状にして**全周をゲートで囲む**。制御力がさらに向上 |
| その先 | CFET など | nMOSとpMOSを積み重ねる構想。研究段階 |

あわせて **裏面電源供給（BSPDN：PowerVia等）** が導入されつつある。
配線層の表側を信号だけにして、電源をウェハー裏面から供給する。配線混雑と電圧降下を同時に緩和する手法。

## 3. 露光装置：EUV と High-NA

| 方式 | 波長 | 位置づけ |
| --- | --- | --- |
| ArF液浸 | 193nm（実効134nm相当） | 7nm以前の主力。今も成熟ノードの主戦力 |
| **EUV（NA0.33）** | 13.5nm | 7nm/5nm/3nm世代の中核。ASMLの独占 |
| **High-NA EUV（NA0.55）** | 13.5nm | 解像度を上げる次世代機。1台400億円級。露光面積が半分になる副作用（フィールドステッチング）がある |

- EUVを使わない場合は**マルチパターニング**で1層を複数回に分けて描くため、工程数・コスト・歩留まりリスクが増える。
- 装置が高いだけでなく、**マスク（レチクル）1セットも先端ノードでは数億〜十数億円**。少量生産では割に合わない。

## 4. なぜ最先端は3社に絞られたのか

- **投資額の壁**：先端ロジックの新工場は1〜2兆円規模。世代ごとに増える
- **歩留まりの壁**：立ち上げ初期は良品率が低く、改善ノウハウの蓄積が要る
- **需要の壁**：高い開発費を回収できる大口顧客（Apple、NVIDIA等）を掴めないと成立しない

結果として最先端ロジックを量産できるのは実質 **TSMC・Samsung・Intel** の3社。
そのうち**外販の最先端はTSMCがほぼ独占**という状態が続いている。

GlobalFoundriesとUMCは早い段階で「最先端を追わない」と決め、
成熟ノード（車載・アナログ・RF等）で稼ぐ路線に転換した。これはこれで合理的な戦略。

## 5. 微細化の減速と「横に広げる」発想

トランジスタを小さくするコスト効率が悪化したため、性能向上の主戦場が移った。

1. **チップレット**：大きな1枚のチップを機能別の小チップに分割し、1パッケージに統合
   - 小さいダイのほうが歩留まりが良い、機能ごとに最適なノードを選べる（I/Oは成熟ノードで十分）
   - 接続規格が **UCIe**
2. **先端パッケージ**：2.5D（シリコンインターポーザ）／3D積層（TSV、ハイブリッドボンディング）
3. **DSA（専用回路）**：汎用CPUではなく用途特化のアクセラレータで性能を稼ぐ

つまり「**微細化（前工程）だけの競争から、束ね方（後工程）とアーキテクチャの競争へ**」が現在地。
製造フローの詳細は [半導体（ロジック・メモリ）](../../03_電機・電子部品/02_半導体（ロジック・メモリ）/README.md) を参照。

## 6. 成熟ノードも重要

- 車載マイコン、パワー半導体、アナログ、センサーは **28nm以上で十分**なものが多い
- 部品点数では成熟ノードのほうが圧倒的に多く、2021〜22年の「半導体不足」の主役もこちら
- 中国は輸出規制で先端を封じられた分、**成熟ノードへの大規模投資**に向かった。
  将来の供給過剰と価格下落のリスク要因として注視されている

## 用語メモ

- **PPAC**：Performance / Power / Area / Cost。ノード比較の物差し
- **リスク生産（Risk Production）**：量産直前の試作段階
- **テープアウト**：設計を確定してマスク製造に回すこと
- **IP**：設計の部品（Armコア、SerDes等）。ライセンス商売
- **BSPDN**：裏面電源供給
