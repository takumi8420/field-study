# 宇宙・衛星

- 大分類: 注目テーマ
- 状態: done
- 更新日: 2026-09-19

宇宙産業を一言でいえば、**「ロケットで軌道にモノを置き、置いたモノで回線・位置・画像を売る産業」**。
金額の大半は打ち上げやロケットではなく、**置いた後のサービス（通信・測位・地球観測）と地上機器**にある。
この10年の変化の震源は、技術の発明ではなく**再使用による打ち上げ単価の低下**だった。

## 1. 業界の定義・範囲

「宇宙・衛星」は、**地球の軌道またはそれ以遠にモノを送り、運用し、そこから得られる価値を売る産業**を指す。

| 含む | 含まない（隣接） |
| --- | --- |
| ロケット・打ち上げサービス | 航空機（大気圏内）→ [航空機・防衛](../../02_自動車・機械/13_航空機・防衛/README.md) |
| 衛星の製造・部品 | 地上の通信設備一般 → [通信機器](../../04_情報通信・IT・ネット/02_通信機器/README.md) |
| 衛星通信・測位・地球観測サービス | 地上ネットワークの運営 → [通信キャリア](../../04_情報通信・IT・ネット/01_通信キャリア/README.md) |
| 地上局・受信端末 | 高高度の無人機 → [ドローン](../08_ドローン/README.md) |
| 月・惑星探査、軌道上サービス | 天文学（学術。産業ではない） |

衛星は「どの高さを回るか」で商売の形が決まる。この3階建てだけは先に覚えておくとニュースが読める。

```
  GEO 高度36,000km ●        地上から止まって見える。1機で広域。放送・気象。遅延 往復0.5秒
  MEO 高度20,000km ●●●      測位（GPS・みちびき・Galileo・北斗）
  LEO 高度   550km ●●●●●●●● 遅延が小さく数千機でリレー。ブロードバンド・地球観測
  ───────────────────────── 地表
```

境界が曖昧になっている場所が2つある。
**①携帯直接通信**（衛星と通信キャリアの融合）、**②衛星画像の解析**（宇宙企業というよりデータ分析業）。

## 2. 市場規模と成長性

| 指標 | 数値 | 年・出典 |
| --- | --- | --- |
| 世界の宇宙経済 | 約6,860億ドル（前年比＋12%） | 2025年実績、Space Foundation 推計（2026年7月公表） |
| 同（別推計） | 約6,264億ドル | 2025年、Novaspace 推計 |
| 世界の政府宇宙予算 | 約1,410億ドル（＋7.4%） | 2025年、Space Foundation 推計 |
| 日本の宇宙産業市場 | 約4兆円 | 政府資料。2030年代早期に約8兆円へ倍増が政府目標 |
| 長期見通し | 2030年代前半に1兆ドル | 各調査会社の推計。幅がある |

> 注意：**機関ごとに「宇宙経済」の定義が違い、推計に2割前後の幅が出る**。
> 総額の比較より、「衛星サービス＋地上機器で全体の7〜8割」という**構成比**のほうが安定して使える。

## 3. バリューチェーン（川上 → 川下）

```
【アップストリーム】                        【ダウンストリーム】
部品・素材 ─▶ 衛星製造 ─▶ 打ち上げ ─▶ │ ─▶ 衛星運用 ─▶ 地上設備・端末 ─▶ サービス／データ
 電子部品      三菱電機     SpaceX      │     Starlink      アンテナ・受信チップ    通信/測位/画像解析
 推進系        NEC, Airbus  MHI, Ariane │     スカパーJSAT                        防衛・農業・保険・金融
 太陽電池                               │
       受注型の製造業（官需が多い）      │      インフラ／サブスク型（民需が多い）
          金額シェアは1〜2割            │         金額シェアは7〜8割
```

付加価値が集まるのは**右側**。ただし右側に入るには左側（衛星を上げる能力）が要るため、
**垂直統合できた事業者が強い**（自社ロケットで自社衛星を上げるSpaceXが典型）。

## 5. 収益モデル・コスト構造

| 事業 | 何で儲けるか | コストの中心 | 利益の出方 |
| --- | --- | --- | --- |
| 打ち上げ | 1回いくらの役務 | 機体製造費（第1段が5〜6割）、射場運用 | **再飛行回数と年間打ち上げ数**で単価が決まる。燃料代は誤差 |
| 衛星製造 | 受注生産 | 設計・試験の人件費、長納期部品 | 官需の一品ものは低回転・低利益率。量産型は別物 |
| 衛星通信 | 月額サブスク、帯域卸 | 配備前は**衛星と打ち上げの巨額投資**。配備後は限界費用が小さい | 加入者数が損益分岐を越えるまで赤字が続く典型的な先行投資型 |
| 測位 | 信号は無料。受信機・補正で課金 | 衛星の運用費は国が負担 | 民間の利益は**受信チップと補正サービス側**に出る |
| 地球観測 | 1シーン課金、年間契約、解析SaaS | 衛星の配備費、解析の人件費 | 画像単価は下落傾向。**解析まで踏み込めるかが利益の分かれ目** |

> 全体に共通するクセ：**初期投資が巨大で回収が長く、失敗コストが非対称**（打ち上げ失敗1回で数百億円と数年）。
> 衛星は上げたら回収できないため、**先に配備した側が構造的に有利**になる。

## 6. 競争要因（KSF）と参入障壁

**KSF**
1. **打ち上げ手段の確保**：自前で持てれば配備スピードで圧倒できる。持てなければ他社の枠待ちになる
2. **衛星の量産能力**：一品ものから量産へ移れたか。自動車・電子機器の量産技術が効く
3. **アンカー顧客（多くは政府）**：初期の需要を保証してくれる存在があるか
4. **データを答えに変える力**：地球観測では画像そのものではなく解析結果が売り物
5. **周波数と軌道の権利**：ITU調整・各国免許。先に押さえた側が有利

**参入障壁**
- 資本（コンステレーション1つで数千億〜数兆円）、免許（宇宙活動法・ITU・FCC等）、
  技術の実証実績（打ち上げ実績がないと保険もつかず顧客もつかない）、
  そして**輸出管理**（ロケット・衛星技術はミサイル技術と地続きで、国際的な規制対象）

## 7. 規制・法制度

| 制度 | 内容 |
| --- | --- |
| **宇宙条約**（1967年） | 天体の領有禁止、打ち上げ国の国際責任。すべての土台 |
| **宇宙活動法**（日本・2016年） | 民間のロケット打ち上げ・衛星管理を許可制に。民間参入の法的土台 |
| **衛星リモセン法**（日本） | 高分解能の衛星画像を扱う事業者を許可制に |
| **ITU による周波数・軌道位置の調整** | 事実上の希少資源の割当。実質的な参入障壁 |
| **輸出管理（MTCRなど）** | ロケット技術はミサイル技術と地続きのため厳しく規制される |
| **デブリ低減ガイドライン** | 運用終了後の軌道離脱（LEOでは5年以内が国際的な目安として広がる） |
| **宇宙戦略基金**（日本・2024年〜） | JAXAに置かれた最大10年・総額1兆円規模の技術開発支援 |

## 8. 最近のトピック

詳細は [05_直近トピック_2026](05_直近トピック_2026.md) に出典URL付きでまとめた。要点は5つ。

1. **世界の宇宙経済は2025年で6,264〜6,860億ドル**（推計機関により幅）。伸びを牽引しているのは衛星通信サービス
2. **打ち上げは十分に安くなった**。相乗り便で約2,700ドル/kg（2026年）。ボトルネックは費用から「衛星の量産」と「売り先」へ移った
3. **Starlinkの独走**（軌道上1万機超、加入者約1,200万件と報じられる）に対し、**Amazon Leoは約400機**で遅れ。差の原因は打ち上げ枠
4. **日本は防衛需要が土台になった**。防衛省の衛星コンステ事業は約2,831億円・5年（2026年2月公表）
5. **H3が立ち直り、みちびき7号機の打ち上げに成功**（2026年8月）。NASAのArtemis IIは2026年4月に有人月周回を実施
