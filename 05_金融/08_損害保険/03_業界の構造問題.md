# 業界の構造問題

このノートで分かること：日本の損保がなぜ**3グループの寡占**になり、その寡占が
2023年以降に**どんな制度改正を呼び込んだのか**。そして自然災害の増加と代理店の集約が、
業界の姿をどう変えつつあるのか。

> 断り書き：本ノートは**公表された事実と制度対応の観点**から整理する。
> 個別企業・個人の責任を断定的に評価することは目的としない。
> 数値・経緯には出典と時点を付し、報道ベースのものはその旨を明記する。

## 1. なぜ3グループになったのか

戦後の日本には20社超の損保があった。それが2010年前後の再編で3グループに集約された。

```
【3メガ損保への集約（概略）】

 東京海上火災＋日動火災 ──▶ **東京海上日動**（2004年）──▶ 東京海上HD
                                              ＋日新火災、海外買収（Philadelphia, HCC, Pure ほか）

 三井海上＋住友海上 ──▶ 三井住友海上 ─────┐
 大東京火災＋千代田火災 ─▶ あいおい損保 ─┐  ├─▶ **MS&AD**（2010年）
 ＋ニッセイ同和損保 ──▶ あいおいニッセイ同和 ┘  ＋三井ダイレクト損保

 安田火災＋日産火災＋大成火災 ─▶ 損害保険ジャパン ┐
 日本興亜損保 ───────────────────┴─▶ **損保ジャパン**（2014年）
                                              ──▶ SOMPOホールディングス
                                              ＋介護、海外（Sompo International、2026年Aspen買収）

  再編を促した3つの力
   ① **1996年の保険業法改正と1998年の料率自由化** … 横並び料率が崩れ、価格競争が始まった
   ② **自然災害の巨大化** … 1回1兆円級の支払いに耐える資本規模が要る
   ③ **システム投資の重さ** … 契約管理・損害サービスの基幹システムは規模で回収する
```

| 項目           | 銀行との比較                                                                                                  |
| -------------- | ------------------------------------------------------------------------------------------------------------- |
| プレイヤー数   | [メガバンク](../01_メガバンク/README.md)は3グループ＋地銀約100行。損保は**3グループ＋中堅・ダイレクト十数社** |
| 寡占度         | 損保のほうが高い。3メガで国内正味収入保険料の**8〜9割**を占めるとされる                                       |
| 商品差         | 銀行の融資条件より、損保の約款のほうが標準化されている（GIROJの参考純率が共通の土台）                         |
| 顧客の乗り換え | 個人は比較的容易。**企業向けは幹事会社が固定化しやすい**                                                      |

この「商品が似ていて、プレイヤーが3つで、企業向けは共同保険で同席する」という条件が、
次章の問題の土壌になったと有識者会議で指摘された。

## 2. 企業向け保険の保険料調整行為 ―― 何が起き、何が変わったか

### 経緯（公表ベース）

| 時点           | 出来事                                                                                                                               |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| 2023年12月19日 | 公正取引委員会が、企業向け保険の見積もりをめぐる独占禁止法違反（不当な取引制限）の疑いで大手4社などに立入検査                        |
| 2023年12月26日 | **金融庁が大手4社（東京海上日動・三井住友海上・損保ジャパン・あいおいニッセイ同和損保）に業務改善命令**                              |
| 2024年6月25日  | 金融庁「損害保険業の構造的課題と競争のあり方に関する有識者会議」報告書                                                               |
| 2024年10月31日 | **公正取引委員会が排除措置命令**。9件のカルテル・談合を認定、課徴金総額20億円超と報じられる                                          |
| 2024年11月     | 経済産業省が4社への補助金交付を一定期間停止すると報じられる                                                                          |
| 2024年12月25日 | 金融審議会「損害保険業等に関する制度等ワーキング・グループ」報告書                                                                   |
| 2025年5月30日  | **改正保険業法が成立**（6月6日公布）                                                                                                 |
| 2026年1月      | 日本損害保険協会「損害保険会社の独占禁止法遵守のための指針」を整備                                                                   |
| 2026年6月1日   | **改正保険業法 施行**                                                                                                                |
| 2026年9月11日  | 金融庁が監督指針の改正案を公表（企業内代理店規制の再構築、独禁法遵守態勢、企業向け保険モニタリングの高度化）。意見募集は10月13日まで |

### なぜ起きやすい構造だったのか（有識者会議の論点整理）

```
【企業向け保険で価格競争が働きにくかった構造】

  ①**共同保険**  1件が数百億〜数千億円規模 → 1社では引き受けきれない
     → 幹事会社＋非幹事会社が同じ案件のテーブルに並ぶ
     → 引受条件・料率の情報が自然に共有される場ができる

  ②**政策保有株の持ち合い**  保険会社 ⇄ 契約者企業が互いの株を持つ
     → 「株を持っているから保険も」→ 価格以外の理由で幹事が決まる

  ③**企業内代理店**  契約者企業のグループ内代理店が自社グループの保険を扱う
     → 手数料がグループに落ちる → 実質的な値引き／囲い込みに近い機能

  ④**営業目標（増収）の重視**  シェア維持が優先され、採算割れでも受ける誘因

    ①〜④が重なると、**価格で競う動機が弱くなる**
```

### 制度として何が変わったか

**改正保険業法（2026年6月1日施行）**で、特定大規模乗合損害保険代理店への体制整備義務、
兼業代理店の業務管理体制の強化、禁止行為の範囲拡大、保険仲立人の届出義務追加が入った。
**監督指針の改正案（2026年9月11日公表）**では、企業内代理店規制の再構築・独禁法遵守態勢・
企業向け保険のモニタリング高度化が柱になっている（条文レベルの一覧は [README](README.md) 第7章）。
あわせて各社が**政策保有株のゼロ化方針**を表明した（第4章）。

> ポイント：一連の対応の本質は**「価格が価格として機能する市場に戻す」**こと。
> 罰則より、①持ち合いを解く ②代理店の役割を明確にする ③引受の意思決定を独立させる、
> という構造側の手当てに重心が置かれている。

## 3. ビッグモーター問題が業界にもたらしたもの

### 経緯（公表ベース）

中古車販売大手のビッグモーター社（現社名：株式会社BALM）による自動車保険金の不適切請求が
2023年に問題となった。同社は複数の損保の**保険代理店**でもあり、
**修理工場であると同時に保険を売る立場**にあった点が構造的な論点となった。

| 時点          | 出来事                                                                          |
| ------------- | ------------------------------------------------------------------------------- |
| 2023年        | 不適切な保険金請求が問題化。各社が調査を実施                                    |
| 2024年1月25日 | **金融庁が損害保険ジャパンおよびSOMPOホールディングスに業務改善命令**           |
| 2024年3月15日 | 損保ジャパンが金融庁へ業務改善計画を提出                                        |
| 2024年3月末   | SOMPOホールディングスのグループCEOが退任                                        |
| 2024年11月    | 金融庁がSOMPOホールディングス・損保ジャパンに追加の改善命令を出したと報じられる |

### 構造として何が論点になったか

```
【「修理工場が代理店でもある」という利益相反の構図】

   保険会社 ──手数料──▶ ディーラー／整備工場（＝代理店）
       ▲                          │ 顧客紹介の見返りに入庫（修理）を回す関係
       │ 保険金                    ▼
     契約者 ◀──修理──────── 修理部門
                                 ▲ **保険金の請求者**と**保険を売る人**が同居する

   さらに ①保険会社から代理店への**出向者** ②**入庫紹介**（事故車を特定工場へ回す実務）
   ③販売実績に連動する**手数料ポイント** が重なると、
   保険会社側が是正しにくい関係ができうる、と指摘された
```

### 何が変わったか

1. **出向・入庫紹介の見直し**：大規模代理店への出向や、販売実績と入庫紹介を結び付ける運用の適正化
2. **代理店手数料ポイント制度の見直し**（第5章）／**大規模代理店の体制整備義務**（2026年6月施行）
3. **保険金支払いの適正性チェック**：請求内容の点検プロセスの強化

> ポイント：カルテル問題が**企業向け・価格の問題**だったのに対し、
> ビッグモーター問題は**個人向け・チャネルの問題**だった。
> 二つが同時期に表面化したことで、金融庁は「損害保険業の構造的課題」として
> **商品・価格・販売チャネルを一体で見直す**方向に進んだ。

## 4. 政策保有株の売却 ―― 持ち合いを解く

政策保有株式とは、**純粋な投資目的ではなく、取引関係の維持を目的に保有する他社株式**のこと。
損保はこれを大量に抱えてきた。

| グループ                        | ゼロ化の目標時期（報道ベース） |
| ------------------------------- | ------------------------------ |
| 東京海上ホールディングス        | 2029年度末をめど               |
| MS&ADインシュアランスグループHD | 2030年3月末                    |
| SOMPOホールディングス           | 2031年3月末                    |

- 3社合計で**年1.5兆円規模**の売却が進んでいると報じられる
- 持ち合い解消で生じる原資は**2.5兆円規模**との報道もある
- SOMPOは2025年度に政策保有株を2,924億円削減したと報じられる
- 東京海上HDは売却資金の約6割を成長投資、約2割を株主還元に充てる方針と報じられる

```
【政策保有株を売ると何が起きるか】

  ＜短期＞                            ＜中長期＞
   売却益が有価証券売却益として計上     ①持ち合いを理由とした取引慣行が弱まる → 価格競争が働く
   2025年度の業界の有価証券売却益       ②ソルベンシー・マージン比率の**株価連動が薄まる**
   **1兆5,171億円**（協会加盟31社）     ③資本を海外M&Aと株主還元へ振り向けられる
        ↓
   **ただし在庫を売り切れば終わる一過性の利益**
   → 本業の実力は**コンバインドレシオ**で見る（→ [①](01_損保の収益構造.md)）
```

## 5. 代理店手数料ポイント制度 ―― 何を評価するかを変える

代理店手数料は、一律の率ではなく**ポイント制度**で決まる。
保険会社が代理店を評価項目ごとに採点し、その合計点で手数料率が変わる仕組みである。

| 従来の主な評価項目 | 何が起きたか |
| --- | --- |
| **規模**（収入保険料の大きさ） | 大きい代理店ほど手数料率が上がる → 保険会社が大型代理店に強く言いにくい |
| **増収率** | 売る量を増やす誘因が強く働く。質（損害率・継続率）の配点は相対的に小さかった |

2024年以降、この設計の見直しが進んだ。報道ベースでは次のような方向が伝えられている。

- **規模・増収率の配点を引き下げる**
- **「自己完結度」を新指標に加える**
  — 保険会社の社員が代理店業務を肩代わりしていないか（いわゆる二重構造）を測る
- **顧客本位でない評価項目を除外**（損保ジャパンは2026年7月実施と報じられる）
- 新規契約よりも**顧客評価・品質**に重点を移す

```
【評価軸の移動】

  〈従来〉                     〈見直し後の方向〉
   規模  ████████             規模  ███
   増収率 ██████              増収率 ██
   品質  ██                   **品質・顧客評価** ██████ ／ **自己完結度** █████

  → 「たくさん売る代理店」から「きちんと完結できる代理店」へ
  → 2025年度末の代理店数 **124,024店**（△11.5%、統計上で過去最大の減少幅）
```

なお、この制度をめぐっては2024年に一部の損保代理店が公正取引委員会へ申告したと報じられており、
評価項目の設計そのものが論点になっている。

## 6. 自然災害の増加と保険料

損保にとって自然災害は「たまに起きる事故」ではなく、**構造的なコスト要因**になった。

全種目の損害率は、災害が集中した2011年度に83.4%、2018年度に69.1%まで上がり、
災害の少なかった2025年度は61.0%だった（日本損害保険協会「保険種目別損害率」）。
種目別の推移は [②](02_商品と市場.md) 第3章にまとめた。対応は3つの層で行われている。

1. **料率**：参考純率の引き上げと水災料率の細分化（→ [②](02_商品と市場.md)）
2. **契約設計**：火災保険の契約期間を最長5年に短縮、免責金額の設定
3. **資本・再保険**：異常危険準備金の積み増し要望、再保険手当ての厚みの確保（→ [①](01_損保の収益構造.md)）

> ポイント：**保険料は「過去の実績」から作られるが、気候リスクは過去の延長ではない**。
> ここに損保の料率算出の根本的な難しさがある。
> 気候変動シナリオ分析や、行政のハザードマップとの接続が進むのはこのため
> （→ [脱炭素・GX](../../01_注目テーマ/05_脱炭素・GX/README.md)）。

## 7. 損害調査という仕事 ―― アジャスター

契約を売るのが営業なら、**払うべき額を決めるのが損害調査**である。
保険会社の損益を最後に決めるのはこちらで、2025年度の損害調査費は**6,198億円**（前年度比+8.7%）。

| 職種                         | 何をするか                                                                                                   |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------ |
| **技術アジャスター**         | 自動車の損傷を見て、修理方法と修理費の妥当性を判定する。日本損害保険協会の資格試験（初級・上級・特級）がある |
| 医療アジャスター／医療専門職 | 人身事故の後遺障害等級や治療の相当性を判断する                                                               |
| 火災・新種の鑑定人           | 建物・設備の損害額を査定する。損害保険登録鑑定人の資格がある                                                 |
| 賠償責任の担当者             | 過失割合や法的責任を交渉・調整する                                                                           |

```
【事故発生から支払いまで】

  事故発生 ──▶ 事故受付（コールセンター）
                   ├──▶ 保険金請求の受理・約款上の支払対象かの確認
                   ├──▶ **損害調査**（アジャスター／鑑定人）
                   │        ・修理見積の妥当性を工場と協定する
                   │        ・水増し・不正請求がないか確認する
                   │        ・過失割合を相手方保険会社と交渉する
                   ├──▶ **支払備金の計上**（確定するまで負債として積む → [①](01_損保の収益構造.md)）
                   └──▶ 保険金の支払い

  ■ 甘く払えば → 損害率が上がり、翌年の保険料に跳ね返る
  ■ 厳しすぎれば → 顧客の信頼を失い、契約が続かない
  → **適正に払う**ことが損害調査の目的であり、単なるコスト削減部門ではない
```

損害調査は人手に強く依存するため、近年は**AIによる画像からの損傷判定**や
**修理費見積の自動算出**の導入が進んでいる。一方で、
「誰が最終的に判断責任を負うか」という論点は残る。

## 8. これからの論点

- **国内市場の頭打ち**：保有台数も住宅着工も伸びない。成長は料率改定と海外に依存する
- **海外事業への依存**：東京海上HDは海外の正味収入保険料が国内本体を上回る。**為替と海外の災害**が損益を左右する
- **代理店の集約**：12.4万店からさらに減る見通し。大型乗合代理店の影響力が増す
- **自動運転**：事故責任がドライバーからメーカー・システムへ移ると、自動車保険の設計が変わる
- **サイバー・気候関連の新リスク**：過去データが乏しく料率算出が難しい。**引受能力そのものが競争力**になる
- **経済価値ベースのソルベンシー規制と人材**：時価評価の健全性規制への移行、アジャスター・アクチュアリーの確保

## 9. 用語メモ

| 用語                                 | 意味                                                                                     |
| ------------------------------------ | ---------------------------------------------------------------------------------------- |
| **保険料調整行為**                   | 複数の保険会社が事前に保険料水準を調整する行為。独占禁止法上の不当な取引制限に当たりうる |
| **排除措置命令／課徴金**             | 公取委が違反行為の排除を命じる処分／国庫に納付させる金銭（2024年10月の4社合計20億円超と報じられる） |
| **業務改善命令**                     | 保険業法に基づき金融庁が経営改善を命じる行政処分                                         |
| **特定大規模乗合損害保険代理店**     | 改正保険業法で体制整備義務を課される規模の大きい乗合代理店                               |
| **企業内代理店**                     | 契約者である企業がグループ内に設置する保険代理店                                         |
| **共同保険**                         | 大型契約を複数社で分担して引き受ける仕組み                                               |
| **政策保有株式**                     | 取引関係の維持を目的に保有する他社株式                                                   |
| **代理店手数料ポイント制度**         | 評価項目の点数で代理店手数料率を決める仕組み                                             |
| **自己完結度**                       | 代理店が保険会社の支援なしに自力で業務を完結できている度合い                             |
| **アジャスター**                     | 自動車事故の損害額・修理方法を判定する損害調査の専門職                                   |
| **損害保険登録鑑定人**               | 火災・新種保険の損害額を鑑定する資格者                                                   |
| **アクチュアリー**                   | 確率・統計を用いて保険料率や準備金を算定する保険数理の専門職                             |
| **経済価値ベースのソルベンシー規制** | 資産・負債を時価評価して支払余力を測る健全性規制                                         |
