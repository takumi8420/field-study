# 直近トピック（2026年9月時点）

報道ベースの整理。数値は一次情報（日本損害保険協会・金融庁・損害保険料率算出機構・各社IR）で
裏取りすること。**このノートは「今どうなっているか」だけを扱う**。仕組みの説明は
[①](01_損保の収益構造.md)〜[③](03_業界の構造問題.md) にある。

> 2026年の損害保険を一言でいえば、**「値上げが効いて本業が戻り、稼いだ資本を海外へ振り向ける年」**。
> コンバインドレシオは92.2%まで改善した。問題は**その改善が自然災害の少なさにどれだけ助けられたか**と、
> **2026年6月に施行された新しいルールの下で、販売チャネルをどう作り直すか**に移っている。

## 2. 自動車保険の参考純率が+14.4% ―― 2002年以降で最大の改定幅

2026年6月、**損害保険料率算出機構（GIROJ）が自動車保険の参考純率を全国平均+14.4%
引き上げる届出を金融庁に提出した**と報じられる。2002年以降で最大の改定幅とされる。

| 項目                   | 内容                                                                            | 時点                  |
| ---------------------- | ------------------------------------------------------------------------------- | --------------------- |
| 参考純率の改定         | 全国平均 **+14.4%** の引き上げを届出                                            | 2026年6月、GIROJ      |
| 大手3社の保険料改定    | 損保ジャパン・三井住友海上・あいおいニッセイ同和損保が平均 **6〜7.5%** 引き上げ | 2026年1月実施（報道） |
| 自動車の損害率         | 2020年度55.8% → 2024年度68.1% → **2025年度67.5%**（期末）                       | 損保協会              |
| 自動車の正味支払保険金 | 2兆7,461億円（+2.7%）、全体の50.3%                                              | 2025年度、損保協会    |

値上げの理由は、事故件数ではなく**1件あたりの単価**にある。

```
【修理費が上がる3つの経路】

  ①**先進安全装備（ADAS）の普及**
     バンパーにミリ波レーダー、フロントガラスにカメラ
     → 軽微な衝突でも部品交換 ＋ **エーミング（センサー再調整）** が必要
     → 以前なら数万円で済んだ修理が十数万円に

  ②**部品・素材の値上がり**
     樹脂・鋼材・電子部品の価格上昇、輸入部品は円安も効く

  ③**板金塗装の人件費上昇**
     整備士不足と賃上げ。工賃（レバーレート）の引き上げ

     ①②③ → **事故件数が減っても保険金総額は減らない**
            → 料率を上げるしか収支を合わせる方法がない
```

> 注意：**参考純率は保険料そのものではない**。各社が事業費を上乗せして自社料率を決めるため、
> +14.4%がそのまま保険料に反映されるわけではない。実際の改定率・時期は会社と契約条件で異なる。
> 本ノートは業界動向の整理であり、個別の保険加入に関する助言は行わない。

## 3. 改正保険業法が2026年6月1日に施行 ―― 代理店規制の作り直し

2025年5月30日に成立（6月6日公布）した改正保険業法が、**2026年6月1日に施行**された。
2023〜2024年に表面化した一連の問題を受けた制度対応である（経緯は [③](03_業界の構造問題.md)）。

| 改正項目                                       | 内容                                                               |
| ---------------------------------------------- | ------------------------------------------------------------------ |
| **特定大規模乗合損害保険代理店の体制整備義務** | 規模の大きい乗合代理店にコンプライアンス責任者の設置などを義務付け |
| **兼業代理店の業務管理体制**                   | 保険以外の本業を持つ代理店の管理体制整備義務を強化                 |
| **禁止行為の範囲拡大**                         | 保険契約の締結・募集に関する禁止行為を拡大                         |
| **保険仲立人**                                 | 変更等の届出義務の対象を追加                                       |

さらに金融庁は**2026年9月11日**、「保険会社向けの総合的な監督指針」の一部改正案を公表した。
意見募集は2026年10月13日まで。柱は3つ。

1. **企業内代理店に関する規制の再構築**
2. **独占禁止法遵守態勢の構築**
3. **企業向け保険商品のモニタリングの高度化**

これは2024年6月25日の「損害保険業の構造的課題と競争のあり方に関する有識者会議」報告書と、
2024年12月25日の金融審議会ワーキング・グループ報告書の提言に基づくもので、
**一連の制度対応の総仕上げ**に当たる。

## 5. 海外へ向かう資本 ―― バークシャー出資とAspen買収

国内市場が料率改定でしか伸びないなか、政策保有株の売却で得た資本は海外へ向かっている。

| 時点          | 出来事                                                                                                                                                                         |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 2026年2月24日 | **SOMPOホールディングスが米Aspen Insurance Holdingsの買収を完了**。買収額は約35億ドルと報じられる（2025年8月27日に契約を公表）                                                 |
| 2026年3月23日 | **バークシャー・ハサウェイの再保険子会社ナショナル・インデムニティが東京海上HDに約2,874億円を出資**。保険会社を対象とした共同M&Aと再保険分野での連携を含む戦略提携と報じられる |
| 2026年5月     | MS&ADとSOMPOが2027年3月期の減益予想を公表。**海外保険事業の競争激化**が理由と報じられる                                                                                        |

政策保有株の売却は各社が期限付きの方針を示している（報道ベース）。

| グループ                        | ゼロ化の目標時期 |
| ------------------------------- | ---------------- |
| 東京海上ホールディングス        | 2029年度末をめど |
| MS&ADインシュアランスグループHD | 2030年3月末      |
| SOMPOホールディングス           | 2031年3月末      |

3社合計で年1.5兆円規模の売却が進み、持ち合い解消による原資は2.5兆円規模との報道もある。
東京海上HDは売却資金の約6割を成長投資、約2割を株主還元に充てる方針と報じられる。

> 留意点：**海外比率が上がるほど、損益は為替と海外の自然災害に振られる**。
> 東京海上HDでは海外保険子会社の正味収入保険料（2兆7,754億円）が
> 東京海上日動単体（2兆5,964億円）を上回っており、
> 北米のハリケーンや訴訟環境（ソーシャル・インフレーション）の影響を直接受ける構造になっている。

## 6. 再保険市況は軟化の見通し ―― コストが下がる方向

世界の再保険市場では、キャパシティ（引受余力）が需要を上回る状態が続いており、
**2027年の更改に向けて料率が軟化（ソフト化）する**との見方が報じられている
（Insurance Journal、2026年9月8日）。

```
【再保険サイクルと元受の損益】

  大災害が連続 → 再保険会社の損失 → キャパシティ減 → **料率上昇（ハード化）**
      ▲                                                        │
      │                                                        ▼
  資本が流入 ◀── 高収益 ◀── 災害の少ない年が続く ◀── 元受の再保険コスト増
      │
      ▼
  キャパシティ過剰 → **料率低下（ソフト化）** → 元受の出再コストが下がる
                                                → コンバインドレシオの改善要因

  2026年9月時点：**ソフト化局面**にあるとの見方
   ・元受にとっては出再コストの低下 → 引受利益にプラス
   ・ただし「安く再保険が買える」ことは「リスクを多く抱えてもよい」ことを意味しない
```

2025年度の出再正味保険料は2兆3,301億円（協会加盟31社）で、元受正味保険料の約22%に当たる。
火災に限れば元受2兆1,811億円に対し出再9,872億円と、**約45%を外へ出している**（→ [①](01_損保の収益構造.md)）。

## 7. 異常危険準備金の税制要望 ―― 大災害への備えを厚くする

日本損害保険協会は2025年7月24日の理事会で、令和8年度税制改正要望を決定した。
柱の一つが**火災保険等に係る異常危険準備金制度の充実**である。

| 項目                                     | 現行                | 要望              |
| ---------------------------------------- | ------------------- | ----------------- |
| 積立率（火災・風水害区分）               | 正味収入保険料の10% | 維持              |
| **洗替保証率（本則積立率となる残高率）** | **30%**             | **40%へ引き上げ** |

背景は、2018年・2019年に2年続けて自然災害の保険金支払いが1兆円を超えたことで
残高が大きく減ったこと。2025年度は災害が少なく積み増しの機会になったが、
**制度上の上限が低いと次の当たり年に備えきれない**という主張である。

## 8. 全体の構図

2026年9月時点の損害保険業界は、次の4つの力が同時に働いている。

1. **値上げサイクルの途中にある**。火災は2023年6月届出の参考純率+13.0%が2024年10月以降に反映され、
   自動車は2026年6月届出の+14.4%がこれから効く。**収入保険料の増加は当面続く**
2. **2025年度の好決算は自然災害の少なさに助けられている**。コンバインドレシオ92.2%は
   実力値というより「当たらなかった年の数字」であり、火災の損害率44.9%は平時の水準ではない
3. **制度改正が販売チャネルを作り直している**。2026年6月施行の改正保険業法と
   同年9月の監督指針改正案により、代理店は「数」から「質と自己完結度」へ評価軸が移った。
   代理店数の11.5%減はその最初の結果である
4. **稼いだ資本は海外へ向かっている**。政策保有株の売却益という一過性の原資を、
   海外保険事業という恒久的な収益源へ入れ替える作業が進行中。
   その分、損益は為替と海外リスクに左右されやすくなる

> まとめ：**本業は確かに戻った。ただし、戻り方の半分は天候と一過性の益である。**
> 実力を見るなら、災害が平年並みに戻った年のコンバインドレシオと、
> 海外事業の引受採算を確認する必要がある。
