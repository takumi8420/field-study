# 損害保険

- 大分類: 金融
- 状態: done
- 更新日: 2026-09-20

**一言でいうと**：事故・災害という「めったに起きないが起きると高くつく損失」を、
大勢から少しずつ集めた保険料でまとめて肩代わりする装置。日本では**3メガ損保グループ
（東京海上HD／MS&AD／SOMPO）**にほぼ集約されている。業界全体の正味収入保険料は
**9兆9,726億円**（2025年度、日本損害保険協会 加盟31社）で、その**約47%が自動車保険**。

儲かっているかどうかは、たった一つの指標で判定できる。

> **コンバインドレシオ ＝ 損害率 ＋ 事業費率。100%を超えたら保険引受は赤字。**
> 2025年度の業界平均は **92.2%**（損害率61.0% ＋ 事業費率31.2%、損保協会）。
> 前年度の96.0%から3.8ポイント改善した。理由は値上げが効いたことと、自然災害が少なかったこと。

## 1. 業界の定義・範囲

損害保険とは、**偶然の事故によって生じた「実際の損害額」を補填する保険**である。
ここが [生命保険](../07_生命保険/README.md) との最大の違いで、生保は「死亡したら1,000万円」と
あらかじめ決めた金額を払う（定額給付）のに対し、損保は「修理費が63万円かかったから63万円」と
実損を払う（**実損てん補**）。だから損保には「いくら払うことになるか事前に分からない」という
性質がつきまとう。

隣接業態との境界は次のとおり。

| 区別する相手                                 | 境界                                                                                                            |
| -------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| [生命保険](../07_生命保険/README.md)         | 人の生死・健康が対象。契約は数十年単位で、保険料を後から変えられない。損保は**1年契約が基本で毎年値決めできる** |
| [少額短期保険](../09_少額短期保険/README.md) | 保険金額と期間に上限を設けた登録制の業態（ミニ保険）。免許制の損保会社とは規制の重さが違う                      |
| 共済（JA共済・全労済・県民共済など）         | 根拠法が保険業法ではなく農協法・消費生活協同組合法。保険業界の統計には原則入らない                              |
| 第三分野（医療・がん・傷害）                 | 生保・損保**どちらも売れる**領域。損保側では「傷害」として計上される                                            |
| 再保険会社（トーア再保険、スイス再保険など） | 保険会社から保険を引き受ける「保険会社のための保険会社」。→ [①](01_損保の収益構造.md)                           |
| 保険代理店・保険仲立人（ブローカー）         | 保険を引き受けず、募集（販売）だけを行う。→ [②](02_商品と市場.md)                                               |
| 損害保険料率算出機構（GIROJ）                | 保険会社ではなく、参考純率・基準料率を算出する法定の中立機関。→ [②](02_商品と市場.md)                           |

**含める範囲**：保険業法上の損害保険会社（元受・再保険）と、その販売を担う代理店チャネルまで。
持株会社傘下の生保子会社・海外保険子会社は、グループ損益を理解するうえで外せないので触れる。

## 2. 市場規模と成長性

| 指標                                 | 数値                               | 時点・出典                          |
| ------------------------------------ | ---------------------------------- | ----------------------------------- |
| 正味収入保険料                       | **9兆9,726億円**（前年度比 +4.1%） | 2025年度、日本損害保険協会 加盟31社 |
| 元受正味保険料（含む収入積立保険料） | **10兆7,401億円**（+3.8%）         | 同上                                |
| 正味支払保険金                       | **5兆4,597億円**（△2.0%）          | 同上                                |
| コンバインドレシオ                   | **92.2%**（前年度96.0%）           | 同上                                |
| 保険引受利益                         | **3,601億円**（+185.1%）           | 同上                                |
| 当期純利益                           | **1兆7,673億円**（△2.8%）          | 同上                                |
| 総資産                               | **33兆7,912億円**                  | 2025年度末、同上                    |

成長性の見方は独特で、**「契約件数が増えるか」ではなく「料率を上げられるか」**で決まる。

- 自動車の保有台数も住宅着工戸数も伸びない。件数は横ばいか減少が前提
- それでも収入保険料が4%増えたのは、**火災・自動車の料率改定**が効いたから（→ [②](02_商品と市場.md)）
- 損保は1年契約が基本なので、**毎年の更改で値段を付け直せる**。これがインフレ局面での強み
- 一方、国内が伸びない分の成長は**海外保険事業**が担う。3メガとも連結収益の半分前後が海外（→ [③](03_業界の構造問題.md)）

## 3. バリューチェーン（お金とリスクの流れ）

損保のバリューチェーンは、**保険料が入ってくる流れ**と**リスクが出ていく流れ**の二層でできている。

```
【損害保険の資金とリスクの流れ】

 ＜集める＞              ＜引き受ける＞            ＜逃がす＞           ＜払う＞
  契約者                  損害保険会社             再保険会社           事故・災害
  （個人・企業）
     │ 保険料              ┌──────────┐
     └───▶ 代理店 ─────▶│ 元受（もとうけ）│──出再保険料──▶ 国内外の
            手数料 ◀──────│              │              再保険会社
            （事業費の約半分）│  責任準備金   │◀─回収再保険金──（リスクの転売）
                            │  支払備金     │
            直販（ダイレクト）│  異常危険準備金 │
     └──────────────▶└──────────┘
                                    │ 保険金＋損害調査費
                                    ▼
                              損害調査（アジャスター）
                                    │
                                    ▼
                                 契約者へ支払

  ＋ 集めた保険料は払うまで手元に残る（フロート）→ 有価証券で運用 → 資産運用粗利益

  付加価値が集まるのは
    ①**リスクを正しく値付けできる者**（料率＝データの勝負）
    ②**顧客への接点を持つ者**（代理店網／ディーラー／直販）
    ③**大災害を吸収できる資本と再保険手当てを持つ者**
```

詳しくは [① 損保の収益構造](01_損保の収益構造.md)。

## 5. 収益モデル・コスト構造

損保の利益は**2階建て**である。ここを分けて見ないと業績を読み違える。

```
【損保の損益の組み立て（2025年度・協会加盟31社）】

 ①保険引受（本業）
     正味収入保険料             9兆9,726億円  …… 売上に当たるもの
   − 正味支払保険金＋損害調査費   6兆 795億円  …… 損害率 **61.0%**
   − 諸手数料及び集金費          1兆6,894億円  …┐
   − 保険引受に係る営業費等      1兆4,207億円  …┴ 事業費率 **31.2%**
   ────────────────────────────────
   ＝ **コンバインドレシオ 92.2%** →  保険引受利益 **3,601億円**
                                     （100%を超えていたら赤字）

 ②資産運用
     資産運用収益 2兆4,216億円 − 資産運用費用 2,824億円
   ＝ 資産運用粗利益 **2兆1,391億円**  …… 引受利益の約6倍

 ①＋② → 経常利益 2兆3,816億円 → 当期純利益 1兆7,673億円
```

> ポイント：**日本の損保は長らく「引受でトントン、運用で稼ぐ」構造**だった。
> 2025年度に引受利益が前年の2.9倍になったのは、値上げの効果と自然災害の少なさが重なった一過性の面もある。

| 指標                   | 意味                                                       | 2025年度                 |
| ---------------------- | ---------------------------------------------------------- | ------------------------ |
| **損害率**             | （正味支払保険金＋損害調査費）÷ 正味収入保険料             | **61.0%**（前年度64.1%） |
| **事業費率**           | （諸手数料及び集金費＋引受に係る営業費等）÷ 正味収入保険料 | **31.2%**（前年度31.9%） |
| **コンバインドレシオ** | 損害率＋事業費率。**100%超＝引受赤字**                     | **92.2%**（前年度96.0%） |
| 運用利回り（インカム） | 利息配当金ベース                                           | 3.75%（前年度4.11%）     |
| 支払備金残高           | 発生済みで未払いの保険金の見積額                           | 4兆6,851億円             |
| 責任準備金残高         | 未経過期間分の保険料＋異常危険準備金など                   | 14兆8,392億円            |

コスト構造の要点は、**事業費の半分以上が代理店手数料**だということ。
人件費や店舗費ではなく「売ってもらうための費用」が最大のコスト項目であり、
ダイレクト型が参入できた理由もここにある（→ [②](02_商品と市場.md)）。

## 6. 競争要因（KSF）と参入障壁

| 優位の源泉                     | 中身                                                                                           | 真似しにくさ |
| ------------------------------ | ---------------------------------------------------------------------------------------------- | ------------ |
| **事故データの量**             | 料率は過去の事故実績から作る。契約が多いほど値付けが正確になる（大数の法則）                   | ★★★          |
| **代理店網**                   | 全国12.4万店の代理店（2025年度末）との関係。自動車ディーラーとの結び付きは資本関係を伴うことも | ★★★          |
| **再保険の手当て力**           | 巨大災害を海外再保険市場に転売できる交渉力と信用力                                             | ★★★          |
| **資本の厚さ**                 | 1回の巨大台風で1兆円級の支払いが出ても倒れない体力                                             | ★★★          |
| **損害調査網（アジャスター）** | 事故現場で損害額を確定する人的ネットワーク。品質が顧客満足を決める                             | ★★           |
| **海外プラットフォーム**       | 買収済みの海外保険会社。時間では買えない                                                       | ★★★          |
| 価格                           | 商品性が似るため、ダイレクト型は価格で攻める                                                   | ★            |

参入障壁は**保険業法の免許（内閣総理大臣＝金融庁の免許制）**と、
**ソルベンシー・マージン比率**などの健全性規制。ダイレクト型・[少額短期保険](../09_少額短期保険/README.md)は
参入できたが、彼らが取ったのは主に個人向けの標準的な商品であり、
**巨大リスクの引受**と**企業向けの総合的な保険プログラム**には届いていない。

## 7. 規制・法制度

| 制度                                          | 中身                                                                                   | 損保への効き方                                                                                                                            |
| --------------------------------------------- | -------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| **保険業法**                                  | 免許制、業務範囲、募集規制、健全性規制                                                 | 業界の土台。2025年5月30日に改正法が成立し、**2026年6月1日施行**                                                                           |
| **改正保険業法（2026年6月施行）**             | 特定大規模乗合損害保険代理店への体制整備義務、兼業代理店の業務管理体制、禁止行為の拡大 | 大規模代理店にコンプライアンス責任者の設置などを義務付け → [③](03_業界の構造問題.md)                                                      |
| **保険会社向けの総合的な監督指針**            | 金融庁の監督実務の基準                                                                 | 2026年9月11日に改正案を公表（企業内代理店規制の再構築、独占禁止法遵守態勢、企業向け保険モニタリングの高度化）。意見募集は同年10月13日まで |
| **ソルベンシー・マージン比率**                | 通常の予測を超えるリスクへの支払余力。200%が早期是正措置の目安                         | 大災害と株価下落の双方に効く。**経済価値ベース（ESR）**の新しい規制枠組みが国際的に導入進行中                                                    |
| **自賠責保険（自動車損害賠償保障法）**        | すべての自動車に加入義務。**ノーロス・ノープロフィット原則**（損も得もしない）         | 保険会社の利益源にならない別枠 → [②](02_商品と市場.md)                                                                                    |
| **地震保険（地震保険に関する法律）**          | 政府が再保険で最終的な支払いを引き受ける官民共同制度                                   | 民間だけでは引き受けられないリスクの処理の仕方 → [①](01_損保の収益構造.md)                                                                |
| **損害保険料率算出団体に関する法律**          | GIROJ が参考純率（火災・自動車・傷害など）と基準料率（自賠責・地震）を算出             | 各社はこれを参考に自社料率を作る。**強制ではない** → [②](02_商品と市場.md)                                                                |
| **独占禁止法**                                | 不当な取引制限（カルテル）の禁止                                                       | 2024年10月31日、公正取引委員会が大手4社に排除措置命令。課徴金総額20億円超と報じられる → [③](03_業界の構造問題.md)                         |
| **異常危険準備金（租税特別措置法第57条の5）** | 火災・風水害区分で正味収入保険料の10%を損金算入して積み立て                            | 自然災害の当たり年に取り崩す。損保協会は2025年7月に洗替保証率30%→40%への引き上げを要望                                                    |

## 8. 最近のトピック

詳細は [④ 直近トピック（2026年9月時点）](04_直近トピック_2026.md)。要点は5つ。

1. **2026年6月1日に改正保険業法が施行**。大規模な乗合代理店に体制整備義務が課され、
   代理店の「数を減らして質を上げる」方向が制度として固まった
2. **自動車保険の参考純率が全国平均+14.4%**（2026年6月、GIROJ が金融庁へ届出）。
   2002年以降で最大の改定幅と報じられる。修理費と人件費の上昇が背景
3. **代理店数が2025年度末に12万4,024店へ**（△16,114店、△11.5%）。統計上で過去最大の減少幅
4. **バークシャー・ハサウェイが東京海上HDに約2,874億円を出資**（2026年3月）。
   SOMPOは米Aspen買収を完了（2026年2月、約35億ドル）。国内が伸びない分を海外で埋める動きが加速
5. **金融庁が2026年9月11日に監督指針の改正案を公表**。企業内代理店規制の再構築と
   独占禁止法遵守態勢の整備が柱。一連の不祥事を受けた制度対応の総仕上げに当たる
