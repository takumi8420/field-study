# 損保の収益構造

このノートで分かること：損害保険会社の儲けは**たった一つの式**で判定できる。
**コンバインドレシオ＝損害率＋事業費率**。これが100%を超えたら、保険を引き受ける本業は赤字である。
そして日本の損保が「1年契約」であることが、[生命保険](../07_生命保険/README.md) との決定的な違いを生む。

> 損保を理解する切り口は3つ。**①保険料はどう認識されるか ②損失はいつ確定するか ③手に負えないリスクをどこへ逃がすか**。
> 順に「正味収入保険料」「支払備金」「再保険」が対応する。

## 1. まずコンバインドレシオ ―― 100%が損益分岐点

損保の本業の成績表は、売上高利益率でもROEでもなく**コンバインドレシオ（Combined Ratio）**である。

```
【コンバインドレシオの構造】

  保険料 100 を受け取ったとき、何にいくら出ていくか

  ┌────────────────────────────────────────┐
  │ 正味収入保険料                                    100.0 │
  ├──────────────────────┬─────────────────┤
  │ 損害率  61.0                    │ 事業費率  31.2      │ 残り 7.8
  │ （保険金＋損害調査費）             │ （代理店手数料＋営業費）│  ＝引受利益
  └──────────────────────┴─────────────────┘
      ◀──────── コンバインドレシオ 92.2% ────────▶

  ■ 92.2% → 100−92.2 ＝ **7.8ポイントが引受のマージン**
  ■ もし 103% なら → 保険料100に対し103出ていく ＝ **引受は赤字**
    それでも会社全体が黒字になりうるのは、資産運用があるから（第8章）
  ※ 決算上の「保険引受利益」は満期返戻金や責任準備金の繰入も差し引くため、
    2025年度は3,601億円（対正味収入保険料3.6%）と、7.8ポイントより小さくなる
```

数値は2025年度（令和7年度）、日本損害保険協会 加盟31社ベース。

| 指標                   | 定義                                                                   | 2024年度  | 2025年度      |
| ---------------------- | ---------------------------------------------------------------------- | --------- | ------------- |
| **損害率**             | （正味支払保険金＋損害調査費）÷ 正味収入保険料                         | 64.1%     | **61.0%**     |
| **事業費率**           | （諸手数料及び集金費＋引受に係る営業費及び一般管理費）÷ 正味収入保険料 | 31.9%     | **31.2%**     |
| **コンバインドレシオ** | 損害率＋事業費率                                                       | 96.0%     | **92.2%**     |
| 保険引受利益           | 引受収益−引受費用−引受に係る営業費等±その他（満期返戻金・準備金繰入を含む） | 1,263億円 | **3,601億円** |

3.8ポイントの改善で引受利益が2.9倍になった。**分母が10兆円あるので、1ポイントが約1,000億円**に相当する。
コンバインドレシオが「わずか数ポイント動いただけ」に見えても、利益は倍半分に振れる。これが損保の怖さであり面白さである。

なぜ2025年度に改善したのか。理由は2つに分解できる。

1. **値上げが効いた**：火災保険・自動車保険の料率改定で正味収入保険料が4.1%増（→ [②](02_商品と市場.md)）
2. **自然災害が少なかった**：火災保険の正味支払保険金が16.0%減。
   加えて2024年1月の能登半島地震に係る地震保険の支払いの反動減もあった（損保協会）

つまり**「分母を上げ、分子が偶然小さかった」**年である。分子は天災次第で毎年振れる。

## 2. 正味収入保険料 ―― 「売上」の定義がややこしい

損保の売上に当たるものは **正味収入保険料**。ただし定義に再保険が組み込まれている。

```
【正味収入保険料の定義】

   元受正味保険料        …… 契約者から直接受け取った保険料
 ＋ 受再正味保険料        …… 他の保険会社から引き受けた分の保険料
 − 出再正味保険料        …… 他の保険会社へリスクを渡すために払った保険料
 ───────────────
 ＝ **正味収入保険料**     …… 自社が最終的に抱えたリスクに対応する保険料

  2025年度（協会加盟31社）
   元受 10兆5,976億円 ＋ 受再 1兆7,051億円 − 出再 2兆3,301億円 ＝ 9兆9,726億円
   （元受は収入積立保険料1,425億円を除いたベース）
                                       ▲
                     元受の約22%を再保険へ渡している（第6章）
```

| 用語               | 中身                     | 覚え方                     |
| ------------------ | ------------------------ | -------------------------- |
| 元受（もとうけ）   | 契約者と直接結んだ契約   | 自分がお客さんから取った分 |
| 受再（じゅさい）   | 他社から引き受けた再保険 | よそのリスクを買った分     |
| 出再（しゅっさい） | 他社へ渡した再保険       | 自分のリスクを売った分     |
| 正味（ネット）     | 元受＋受再−出再          | **最後に自分が背負った分** |

ここが重要な理由は、**「売上が大きい＝リスクを多く抱えている」わけではない**から。
火災保険は元受2兆1,811億円に対し出再9,872億円（2025年度）で、**元受のおよそ45%を外へ出している**。
自然災害リスクをそのまま抱えたら債務超過になりうるので、意図的に手放している。

## 3. 保険料はすぐ利益にならない ―― 責任準備金

契約者から4月に1年分の保険料を受け取っても、それは**まだ稼いだお金ではない**。
3月までの補償を約束しているので、期末時点で残り期間に対応する分は**負債**として積む。
これが**責任準備金**（うち未経過期間分を「未経過保険料」という）。

```
【1年契約の保険料が収益になっていく流れ】

  4/1 保険料12を受け取る（現金は全額入る）
   ├──────────────────────────────┤
   4月   5月   6月 …………………………………  翌3月
   ■1   ■1   ■1  … 毎月1ずつ「経過した」分だけ収益になる

  期末（9月末）時点：
     経過分 6 ＝ 収益
     未経過分 6 ＝ **責任準備金（負債）** ← まだ会社のものではない

  2025年度末の責任準備金残高 ＝ **14兆8,392億円**（協会加盟31社）
      ≒ 年間保険料（9兆9,726億円）の約1.5年分
```

## 4. 支払保険金も確定しない ―― 支払備金

損保の損益をゆがめる最大の要因は、**事故が起きても支払額がすぐ決まらない**ことである。

- 自動車事故の対物なら数週間で決まる
- 対人（後遺障害）や賠償責任訴訟なら、確定まで**数年**かかる
- その間、会社は「いくら払うことになりそうか」を見積もって負債に計上する

これが**支払備金**。2025年度末の残高は **4兆6,851億円**（協会加盟31社）。

| 備金の種類   | 中身                                                                                | 難しさ                   |
| ------------ | ----------------------------------------------------------------------------------- | ------------------------ |
| 普通支払備金 | 報告済みで未払いの案件ごとの見積額                                                  | 個別に積む               |
| **IBNR備金** | 既に発生しているが**まだ報告されていない**事故の見積額（Incurred But Not Reported） | 統計的にしか推計できない |

> ポイント：支払備金の見積もりが甘いと、後から不足が判明して**準備金の積み増し（リザーブ強化）**が必要になり、
> 後年度の損益を直撃する。逆に厚く積んでいれば戻し益が出る。
> **損保の決算は「見積もりの巧拙」で数百億円動く**。

## 5. 生保との決定的な違い ―― 短期契約だから毎年値決めできる

| 論点             | 損害保険                                       | [生命保険](../07_生命保険/README.md)   |
| ---------------- | ---------------------------------------------- | -------------------------------------- |
| 契約期間         | **1年が基本**（火災は最長5年）                 | 10年〜終身                             |
| 保険料の見直し   | **毎年の更改で変えられる**                     | 契約時に固定（予定利率も固定）         |
| 支払額の決まり方 | **実損てん補**（実際の損害額）                 | **定額給付**（あらかじめ決めた金額）   |
| 主なリスク       | 自然災害・事故の頻度と単価                     | 長生き／死亡率、金利（予定利率との差） |
| 負債の期間       | 短い（1〜数年）                                | 非常に長い（数十年）                   |
| インフレへの耐性 | **強い**（値上げできる）                       | 弱い（既契約は変えられない）           |
| 中核の健全性指標 | コンバインドレシオ、ソルベンシー・マージン比率 | 基礎利益、逆ざや、ESR                  |

```
【「1年契約で毎年値決めできる」の意味】

 〈損保〉                          〈生保〉
  2023年 契約 → 赤字だった            2003年 契約（予定利率1.5%で固定）
     ↓ 翌年の更改で料率を上げる            ↓
  2024年 契約 → 料率+13%                ……20年後も契約はそのまま
     ↓                                  ↓
  2025年 契約 → 黒字化                 金利が動いても保険料は変えられない

  → 損保は**間違えても翌年やり直せる**
  → その代わり、値上げすれば顧客は他社へ移れる（毎年が勝負）
```

これが日本の損保が2023〜2026年のインフレ局面で利益を戻せた根本理由である。
火災保険は2019年から2024年までの複数回の参考純率改定で全国平均が累計40%超上がったと報じられており、
自動車保険も2026年1月に大手3社が平均6〜7.5%の引き上げを実施したと報じられる（→ [②](02_商品と市場.md)）。

## 6. 自然災害と再保険 ―― リスクの転売

損保の最大の敵は**巨大自然災害**である。1回の台風で数千億円の支払いが出る。
これを自社だけで抱えたら資本が飛ぶので、**再保険（Reinsurance）＝保険会社のための保険**を使う。

```
【再保険の仕組み：リスクの転売】

  契約者 ──保険料──▶ 元受損保 ──出再保険料──▶ 再保険会社
                          │                    （トーア再保険、
                          │                     スイス再、ミュンヘン再など）
   事故発生 ◀─保険金──── │ ◀──回収再保険金────┘
                          │
                  自社で持つ部分（保有）は限定

  ■ 比例再保険：保険金額の◯%をそのまま分け合う
  ■ **超過損害額再保険（XOL）**：
       「1事故で1,000億円を超えた部分のうち3,000億円まで」を再保険会社が持つ
       → 元受は**巨大災害の上限を買っている**のと同じ

  2025年度（協会加盟31社）
   出再正味保険料 2兆3,301億円  … 保険料の一部を「保険をかける費用」として払う
   うち火災だけで   9,872億円  … 元受火災保険料 2兆1,811億円の約45%
```

再保険には**市況（サイクル）**がある。大災害が続くと再保険料率が上がり（ハード化）、
逆に災害が少なくキャパシティが余ると下がる（ソフト化／軟化）。
2026年9月時点では、世界の再保険市場はキャパシティが需要を上回り、
2027年更改に向けて料率が軟化するとの見方が報じられている。
**再保険料が下がれば元受のコストが下がる**ので、コンバインドレシオにも効く。

## 7. 異常危険準備金 ―― 「当たり年」に備える貯金

自然災害は毎年同じ量は来ない。来ない年に貯めて、来た年に取り崩す仕組みが**異常危険準備金**である。

| 論点                   | 内容                                                                           |
| ---------------------- | ------------------------------------------------------------------------------ |
| 根拠                   | 租税特別措置法第57条の5                                                        |
| 仕組み                 | 火災・風水害区分で正味収入保険料の**10%**を損金算入して積み立て                |
| 無税で積める残高の上限 | 正味収入保険料の**30%**（洗替保証率も30%）                                     |
| 取り崩し               | 損害率が一定水準（火災は50%）を超えた分を取り崩す                              |
| 現状の課題             | 2018年・2019年の連年1兆円超の災害支払いで残高が大きく減ったとされる            |
| 業界の要望             | 損保協会は2025年7月24日、**洗替保証率を30%→40%へ引き上げる**税制改正要望を決定 |

> ポイント：異常危険準備金は**損益の平準化装置**。積むと利益が減り、取り崩すと利益が増える。
> だから損保の「純利益」を年度間で単純比較すると実力を見誤る。各社が**修正利益／修正純利益**という
> 独自指標を併用するのはこのためである（→ [③](03_業界の構造問題.md)）。

地震リスクはさらに特殊で、家計向けの**地震保険**は政府が再保険で最終的な支払いを引き受ける官民共同制度になっている。
民間の引受能力だけでは、首都直下級の地震を支えられないからである。

## 8. 2階建ての損益 ―― 引受と運用

保険料は事故が起きるまで手元に残る。この滞留資金を**フロート**と呼び、有価証券で運用する。

```
【損保の損益は2階建て（2025年度・協会加盟31社）】

 ①保険引受                              ②資産運用
   正味収入保険料      9兆9,726億円        資産運用収益   2兆4,216億円
  −保険金＋損害調査費   6兆  795億円       −資産運用費用      2,824億円
  −事業費            3兆1,101億円       ───────────────
  ─────────────────         = 資産運用粗利益 **2兆1,391億円**
  = 保険引受利益      **3,601億円**            うち利息配当金 9,048億円
    （CR 92.2%）                              うち有価証券売却益 1兆5,171億円

         ①＋②＋その他 → 経常利益 2兆3,816億円 → 当期純利益 1兆7,673億円

  ■ 引受利益は運用粗利益の**6分の1以下**
  ■ 有価証券売却益1兆5,171億円の多くは**政策保有株の売却**とみられる（→ [③](03_業界の構造問題.md)）
    これは在庫を売り切ると終わる一過性の利益
```

だからこそ、**コンバインドレシオで本業を見る**必要がある。
純利益は運用と準備金の増減で膨らんだり縮んだりするが、コンバインドレシオはごまかしが効きにくい。

## 9. 健全性 ―― ソルベンシー・マージン比率

銀行の自己資本比率に当たるものが**ソルベンシー・マージン比率**である。

- 分子：資本＋価格変動準備金＋異常危険準備金＋有価証券含み益など（＝支払余力）
- 分母：保険引受リスク＋巨大災害リスク＋資産運用リスクなどを統合した額の1/2
- **200%を下回ると金融庁の早期是正措置の対象**

大手損保は数百%の水準を維持しているが、この指標は**株価下落に弱い**。
含み益が資本に効くため、政策保有株を多く持っていた時代は株式市場と健全性が連動していた。
政策保有株の売却は、還元原資の確保と同時に**この連動を切る**意味も持つ（→ [③](03_業界の構造問題.md)）。

## 10. 用語メモ

| 用語                           | 意味                                                                     |
| ------------------------------ | ------------------------------------------------------------------------ |
| **コンバインドレシオ**         | 損害率＋事業費率。**100%超で保険引受は赤字**                             |
| **損害率**                     | （正味支払保険金＋損害調査費）÷正味収入保険料。2025年度61.0%             |
| **事業費率**                   | （諸手数料及び集金費＋引受に係る営業費等）÷正味収入保険料。2025年度31.2% |
| **正味収入保険料**             | 元受＋受再−出再。最終的に自社が抱えたリスクに対応する保険料              |
| **元受／受再／出再**           | 契約者から直接／他社から引き受け／他社へ渡す                             |
| **責任準備金**                 | 未経過期間に対応する保険料などの負債。2025年度末14兆8,392億円            |
| **支払備金**                   | 発生済みで未払いの保険金の見積額。2025年度末4兆6,851億円                 |
| **IBNR備金**                   | 発生したがまだ報告されていない事故に備える備金                           |
| **再保険（出再・受再）**       | 保険会社が自らのリスクにかける保険。リスクの転売                         |
| **超過損害額再保険（XOL）**    | 1事故の損害が一定額を超えた部分を引き受ける再保険                        |
| **ハード化／ソフト化**         | 再保険料率が上がる局面／下がる局面                                       |
| **異常危険準備金**             | 大災害に備える税制優遇付きの準備金。積立率10%、無税残高上限30%           |
| **フロート**                   | 保険料を受け取ってから保険金を払うまで手元に滞留する資金                 |
| **ソルベンシー・マージン比率** | 通常の予測を超える損失への支払余力。200%が早期是正措置の目安             |
| **修正利益／修正純利益**       | 準備金の増減などを調整した各社独自の実力利益指標                         |
