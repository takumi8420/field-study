# リスクと健全性

このノートで分かること：**銀行が抱える4つのリスク（信用・金利・市場・流動性）が、
決算のどこに、どういう形で現れるか**。そして「健全性」を測る物差し
（不良債権比率、与信費用、CET1比率、ストレステスト）の読み方。

> 銀行は「リスクを引き受けて対価をもらう商売」である。
> リスクを取らない銀行は利ざやも稼げない。問題は**取り方と備え方**。
> 基礎用語は [① 銀行のビジネスの基本](01_銀行のビジネスの基本.md) を参照。

## 1. 銀行が抱える4つのリスク

```
【リスクの見取り図：BSのどこに潜むか】

  ＜資産＞                              ＜負債＞
 ┌────────────────┐        ┌────────────────┐
 │ 貸出金                  │        │ 預金                    │
 │  ← ①**信用リスク**       │        │  ← ④**流動性リスク**     │
 │    借り手が返せない       │        │    預金が一斉に逃げる     │
 ├────────────────┤        │                        │
 │ 有価証券（国債・外債）    │        ├────────────────┤
 │  ← ②**金利リスク**       │        │ 市場調達                │
 │    金利上昇で価格が下がる  │        │  ← ④調達が止まる        │
 │ 有価証券（株式）          │        ├────────────────┤
 │  ← ③**価格変動リスク**    │        │ 自己資本                │
 └────────────────┘        │  ← ①〜③の損失をここで吸収 │
                                      └────────────────┘
  ＋ ⑤オペレーショナルリスク（システム障害・不正・マネロン・サイバー）
     …BSには出ないが、行政処分と信用失墜という形で効く
```

| リスク                     | 何が起きるか                             | 決算に出る場所                           | 主な備え                                      |
| -------------------------- | ---------------------------------------- | ---------------------------------------- | --------------------------------------------- |
| **信用リスク**             | 融資先が倒産・延滞                       | **与信費用**（引当金繰入・貸倒償却）     | 引当金、担保・保証、分散                      |
| **金利リスク**             | 金利上昇で債券価格が下落／調達コスト上昇 | 有価証券の評価損益、資金利益             | ALM（期間の管理）、デュレーション短縮、ヘッジ |
| **価格変動リスク**         | 株式・外貨資産の評価が動く               | 株式等関係損益、その他有価証券評価差額金 | 政策保有株の縮減                              |
| **流動性リスク**           | 預金流出・市場調達停止で支払えない       | 表には出ず、出たら破綻                   | LCR／NSFR、日銀当座預金、中央銀行借入         |
| **オペレーショナルリスク** | システム障害、不正送金、マネロン見逃し   | 経費・特別損失、業務改善命令             | 内部統制、システム投資、監視                  |

## 2. 与信費用 ―― 銀行の利益を最も大きく動かすもの

**与信費用**（＝与信関係費用、クレジットコスト）とは、
貸し倒れに備えて積む**貸倒引当金の繰入額**と、実際に回収を諦めた**貸倒償却**の合計。
回収が進んで引当を取り崩せば「戻り益（マイナスの与信費用）」になる。

```
【債務者区分と引当の関係（金融検査マニュアル以来の実務）】

  区分            状態                        引当の考え方        貸出の扱い
 ─────────────────────────────────────────
  正常先        問題なし                      過去の倒産確率で      ─
                                              少額を一括引当
  要注意先      業績不振・延滞気味             やや厚く引当        （うち**要管理先**は
                                                                  不良債権に含む）
  **破綻懸念先**  経営破綻の可能性が大きい       担保でカバーされ    **不良債権**
                                              ない部分に厚く
  **実質破綻先**  法的には未破綻だが実態は破綻   ほぼ全額           **不良債権**
  **破綻先**      法的整理・取引停止処分         全額               **不良債権**

  → **開示債権（金融再生法ベース）** ＝ 破産更生債権等 ＋ 危険債権 ＋ 要管理債権
     **不良債権比率** ＝ 開示債権 ÷ 総与信残高
```

主な数値（2026年3月期、全国の銀行103行を集計した東京商工リサーチ調査）。

| 指標                   | 金額・比率               | 前年比                               |
| ---------------------- | ------------------------ | ------------------------------------ |
| **不良債権比率**       | **1.07%**（中央値1.58%） | 0.07ポイント低下                     |
| 不良債権額（開示債権） | 8兆3,186億円             | +0.1%                                |
| 貸倒引当金             | 3兆9,029億円             | −3.1%（2年連続減、5年ぶりの3兆円台） |

> 読み方：**比率1%台は歴史的に見て極めて低い**（不良債権問題のピークだった2002年3月期は
> 主要行で8%台に達したとされる）。ただし「引当金を取り崩してきた」ということは、
> **次に景気が悪化したときに積み直す余地が大きい＝将来の減益要因**という意味でもある。

### フォワードルッキング引当

近年は、個社の延滞実績だけでなく、**将来のシナリオ（景気後退、特定業種の悪化、地政学リスク）を
先回りして積む**方式が広がっている。2026年3月期は、中東情勢への備えとして
フォワードルッキング引当を計上した銀行があり、前年比で与信費用が増えたと報じられる。

```
【従来型引当 vs フォワードルッキング引当】

 従来型：  倒産が起きてから → 積む       （後追い。危機時にまとめて損失が出る）
          実績 ●──────────▶ 引当 ●

 FL型：   兆候の段階で → 先に積む        （利益は平準化されるが、
          シナリオ ●─▶ 引当 ●            「なぜ積んだか」の説明責任が重い）
                        ⋮
                     実際に悪化したら追加引当は不要／戻し入れも
```

## 3. 金利リスク ―― 「金利上昇は銀行にプラス」の但し書き

金利が上がると利ざやは広がる（→ [④ 金利のある世界への転換](04_金利のある世界への転換.md)）。
しかし同時に、**すでに保有している低利回りの債券は値下がりする**。
債券価格と金利は逆に動くからだ。

```
【同じ金利上昇が、利益と資産に逆向きに効く】

  金利 ↑
   ├─▶ 新規の貸出金利 ↑ ／ 日銀当預の付利 ↑ ────▶ **資金利益 ↑（フロー）**
   │
   └─▶ 保有する固定利付国債の時価 ↓ ────────▶ **含み損 ↑（ストック）**
                                                      ▲
        残存期間が長いほど（デュレーションが長いほど）打撃が大きい
        例：残存20年の超長期国債は、金利1%上昇でおおむね15〜20%程度値下がりする
```

含み損そのものは、満期まで持てば額面で償還されるので実現しない。
問題は次の2点。

1. **売れなくなる**：損切りしないと資金を動かせず、高い利回りの資産に入れ替えられない（**塩漬け**）
2. **預金が逃げたときに売らざるを得ない**：流動性リスクと結びつくと破綻要因になる（2023年の米SVB）

2025〜2026年に報じられた含み損の状況（いずれも報道ベース）。

| 主体               | 含み損                                        | 時点                      |
| ------------------ | --------------------------------------------- | ------------------------- |
| 日本銀行の保有国債 | 約32兆8,000億円（過去最大）                   | 2025年9月末、日銀中間決算 |
| 地方銀行の国内債   | 約3兆円（前年の約2倍）                        | 2025年11月時点の報道      |
| 信用金庫           | 約2.5兆円弱（1年で約3倍）、金融庁が集中点検へ | 2025年10月時点の報道      |

> **メガバンクは相対的にこの問題に強い**。理由は
> ①運用が国債偏重ではなく外債・貸出に分散している
> ②デュレーションを短く保つALM（資産負債管理）を早くから実施
> ③損切りしても稼ぐ力（業務純益）で埋められる。
> 逆に、国債で運用せざるを得なかった[地方銀行](../02_地方銀行/README.md)・信金の方が構造的に厳しい。

## 4. 規制資本 ―― CET1比率とバッファ

自己資本比率の計算式と用語は [①](01_銀行のビジネスの基本.md) に譲り、ここでは**運用**を見る。

```
【CET1比率の「目標レンジ」経営】

  規制上の最低ライン（G-SIBsの場合、資本バッファ込みでおおむね 8〜9%台）
        │
        │ ← ここを割ると**配当・賞与の支払いが制限される**（資本保全バッファ）
        ▼
  ─────────────────────────────────────
   実務上の目標レンジ   例：MUFGは **9.5〜10.5%**（完全実施ベース）
  ─────────────────────────────────────
        ▲                    ▲
   下回ると：自己株買いを     上回ると：自己株買い・増配・
   絞り、利益蓄積で回復       成長投資（買収・貸出増）に回す

  2026年の実例：MUFGは完全実施ベースCET1比率が **9.2%** に低下し、
  自己株買いを1,000億円にとどめ、年内に資本水準を回復させる方針と報じられる
```

| 用語                       | 意味                                                                                                                                                 |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **資本バッファ**           | 最低比率の上に積む上乗せ。資本保全バッファ、G-SIBsサーチャージ、カウンターシクリカルバッファ（景気過熱時に上積み）                                   |
| **資本フロア**             | 内部モデルで計算したRWAが、標準的手法で計算したRWAの一定割合を下回らないようにする措置。**2026年は70%、2027年に最終の72.5%**（金融庁資料、段階導入） |
| **完全実施ベース（フル）** | 経過措置を使わず、最終規制がフル適用された前提での比率。実力値として使われる                                                                         |
| **TLAC**                   | Total Loss-Absorbing Capacity。破綻処理時に損失吸収・資本再構築に使える負債（TLAC債など）を一定量持つ義務。G-SIBsに適用                              |

> ここが実務の肝：**CET1比率は「高ければよい」ではない**。
> 高すぎればROEが下がって株主から資本効率を問われ、低ければ規制と格付けに引っかかる。
> **目標レンジの中で運転する**のが銀行経営の基本動作になっている。→ [②](02_メガバンクの稼ぎ方.md) 第7章

## 5. ストレステスト ―― 「最悪を想定して耐えられるか」

ストレステストとは、**景気後退・金利急変・株価急落といった厳しいシナリオを当てはめて、
損失額と自己資本比率がどこまで落ちるかを試算する**こと。

| 種類                         | 実施主体                     | 中身                                                           |
| ---------------------------- | ---------------------------- | -------------------------------------------------------------- |
| **監督上のストレステスト**   | 金融庁・日銀（共通シナリオ） | 複数行に同じシナリオを当てて比較。結果は監督に使われる         |
| **自社管理のストレステスト** | 各銀行                       | 自社固有のリスク（特定業種集中、特定国エクスポージャー）を検証 |
| **リバースストレステスト**   | 各銀行                       | 「どこまで悪化したら自社は耐えられなくなるか」から逆算する     |

金融庁は日銀と共同で `金融システムレポート` 等を通じて分析を公表しており、
2026事務年度の金融行政方針（2026年9月15日公表）では、
長期金利が30年ぶりに3%台を付けるなかで、
**不動産業向け融資、超長期の住宅ローン、預金などの流動性リスク**を重点的に点検すると報じられている。

```
【今なぜ「不動産融資」と「超長期住宅ローン」が点検対象か】

  金利 ↑ ──┬─▶ 不動産の利回り要求 ↑ → **不動産価格 ↓** → 担保価値の低下
            │      ＋ 開発案件の資金コスト ↑ → 採算悪化
            │           → [不動産金融・REIT](../13_不動産金融・REIT/README.md)、
            │             [不動産デベロッパー](../../12_建設・住宅・不動産/08_不動産デベロッパー/README.md)へ波及
            │
            └─▶ 変動金利の住宅ローン返済額 ↑ → 家計の返済余力 ↓
                   ※日本は変動金利型の比率が高い。35年・超長期ローンは
                     金利が1%動くだけで総返済額が大きく変わる
```

## 6. 不良債権処理の歴史 ―― なぜ日本の銀行はこうなったか

今の規制・保守的な経営姿勢・メガバンクという形そのものが、
**1990年代〜2000年代の金融危機の産物**である。ここを知らないと業界の常識が読めない。

```
【日本の不良債権問題 30年の流れ】

 1985-90  プラザ合意後の金融緩和 → **不動産バブル**
          「土地は値下がりしない」前提で担保融資が膨張（土地本位制）
              │
 1990-91  総量規制・金融引き締め → **地価暴落**
              │  担保価値が消え、融資が不良化
 1992-96  **先送り**の時代
          「いずれ地価は戻る」と信じ、追い貸し・飛ばし・損失の繰り延べ
              │
 1997-98  **金融危機**：三洋証券、**北海道拓殖銀行**、山一證券が相次ぎ破綻
          日本長期信用銀行・日本債券信用銀行が一時国有化
          → 貸し渋り・貸しはがきで実体経済が収縮（**信用収縮**）
              │
 1998-99  金融再生法・早期健全化法 → **公的資金による資本注入**
              │
 2002-05  **金融再生プログラム（竹中プラン）**
          厳格な資産査定（DCF的手法、繰延税金資産の算入制限）、
          主要行の不良債権比率を半減させる数値目標
          → りそなへの実質公的管理（2003年）、足利銀行の一時国有化
          → **大手行の不良債権比率は2002年3月期の8%台から
             2005年3月期には2%台へ低下**（金融庁公表ベース）
              │
 2000-06  この過程で都市銀行13行が **3メガ＋りそな** に集約（→ [②](02_メガバンクの稼ぎ方.md) 第1章）
              │
 2010年代 **ゼロ金利・マイナス金利** → 利ざや壊滅、店舗・人員削減へ
              │
 2024年〜  **金利のある世界へ**（→ [④](04_金利のある世界への転換.md)）
```

この歴史が今も効いている点を3つ。

1. **引当と査定に極端に保守的**：先送りで傷を広げた反省から、早く認識して早く積む文化になった
2. **担保・保証への依存を減らす動き**：土地担保一本足への反省。事業性評価融資や
   2024年施行の**企業価値担保権**（事業全体を担保にする新制度）はその延長にある
3. **公的資金への強い忌避感**：資本を厚く保ち、還元より健全性を優先しがちな保守性の源泉

> 若手が「なぜこんなに手続きが重いのか」と感じる審査・与信のプロセスは、
> **この30年で一度壊れた業界が積み上げた安全装置**である。

## 7. オペレーショナルリスク ―― BSに出ないリスク

| 類型                       | 具体例                                             | 効き方                                               |
| -------------------------- | -------------------------------------------------- | ---------------------------------------------------- |
| **システム障害**           | 勘定系の停止でATM・振込が止まる                    | 業務改善命令、信用失墜、顧客流出                     |
| **マネロン・テロ資金供与** | 不審取引の見逃し、制裁対象との取引                 | 海外当局からの巨額制裁金、ドル決済網からの排除リスク |
| **サイバー攻撃**           | ランサムウェア、不正送金、サプライチェーン攻撃     | 業務停止と情報漏えい                                 |
| **内部不正**               | 貸金庫からの窃取、顧客情報の不正利用、インサイダー | 行政処分と経営責任                                   |

**マネロン対策（AML/CFT）**は近年の最大の規制コスト項目のひとつ。
金融庁は、FATF（金融活動作業部会）の**第5次対日相互審査**も見据え、
関係省庁・業界団体と連携して態勢の高度化を促す方針を示している（2026事務年度金融行政方針、報道ベース）。
また、マネロンやサイバーのような高度な専門性が要る領域について、
**複数の金融機関が共同で対処する**枠組みの検討にも言及がある。

> 規制コストは**固定費**である。だから規模の小さい銀行ほど相対的に重い。
> 規制強化が結果として**業界再編の圧力**になる、という因果は押さえておく。

## 用語メモ

| 用語                               | 意味                                                                       |
| ---------------------------------- | -------------------------------------------------------------------------- |
| **与信費用（クレジットコスト）**   | 貸倒引当金繰入＋貸倒償却。回収が進むと戻り益になる                         |
| **貸倒引当金**                     | 将来の貸し倒れに備えて費用計上し、資産から控除する準備金                   |
| **一般貸倒引当金／個別貸倒引当金** | 正常先等にまとめて積むのが一般、個別に査定して積むのが個別                 |
| **債務者区分**                     | 正常先／要注意先（うち要管理先）／破綻懸念先／実質破綻先／破綻先           |
| **不良債権比率**                   | 開示債権 ÷ 総与信。2026年3月期は103行平均で1.07%（東京商工リサーチ）       |
| **フォワードルッキング引当**       | 将来シナリオを先取りして積む引当                                           |
| **デュレーション**                 | 債券の価格が金利変動にどれだけ反応するかを示す平均回収期間                 |
| **ALM**                            | Asset Liability Management。資産と負債の金利・期間構造を一体で管理すること |
| **その他有価証券評価差額金**       | 時価評価した有価証券の含み損益。純資産に計上され、自己資本に影響する       |
| **CET1比率／目標レンジ**           | 中核資本比率と、各行が自ら設定する運営目標の幅                             |
| **資本フロア**                     | 内部モデルRWAの下限。2026年70%→2027年72.5%（金融庁）                       |
| **TLAC**                           | 破綻時に損失吸収できる負債を一定量持つ規制                                 |
| **ストレステスト**                 | 厳しいシナリオ下の損失と自己資本比率を試算する健全性検証                   |
| **企業価値担保権**                 | 不動産等の個別資産でなく事業全体を担保にする新しい担保制度（2024年施行）   |
