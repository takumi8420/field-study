銀行のビジネスの基本

金融メガバンク

このノートで分かること：銀行は「他人のお金（預金）で他人に貸す」装置であり、
その儲けは「調達金利と運用金利の差（利ざや）」「手数料」「市場運用」の3本柱でできている。
そして銀行だけが自己資本比率規制という特殊な足かせをはめられている理由も分かる。

金融業を理解する切り口は3つだけ。①お金はどこから来てどこへ行くか ②何で稼ぐか ③リスクを誰が背負うか。
銀行はこの3つが「預金 → 貸出」「利ざや＋手数料」「銀行自身が貸し倒れを背負う」という形で組み合わさった業態。

1. 銀行は「お金の流れの真ん中」にいる

世の中には、お金が余っている人（家計・一部の企業）と、足りない人（企業・住宅を買う個人・国）がいる。
この二者を直接つなぐのが直接金融（株式・社債＝証券 の領域）、
あいだに入って自分の帳簿を通すのが間接金融＝銀行である。

【直接金融と間接金融の違い】

〈直接金融〉                        〈間接金融（銀行）〉
 資金の出し手                        資金の出し手
   個人・機関投資家                    預金者（個人・企業）
      │ 株・債券を買う                    │ 預金する（元本は返ってくる約束）
      ▼                                  ▼
   ─────────                    ┌───────────┐
    発行体（企業・国）                │   銀 行   │ ← ここが自分の帳簿で受ける
   ─────────                    └───────────┘
      ▲                                  │ 貸す（返ってこないリスクは銀行が負う）
      │ 値下がり・デフォルトは                ▼
      │ 買った人が直接かぶる              借り手（企業・個人・地方公共団体）

 リスクの行き先：投資家                リスクの行き先：**銀行**（預金は原則守られる）

ここが決定的な違い。預金者は貸し倒れのリスクを負わない（1,000万円とその利息までは預金保険で保護）。
その代わり、借り手が飛んだときの損は銀行の自己資本が吸収する。
だから銀行には「資本を厚く持て」という規制がかかる（→ 第8章）。

2. すべてはバランスシート（貸借対照表）で考える

銀行を理解する最短ルートは、損益計算書ではなくバランスシート（BS）を見ること。
製造業は「工場と在庫」がBSの中身だが、銀行はBSそのものが商品である。

【銀行のバランスシート（イメージ／比率は都市銀行のおおよその感覚）】

  ＜資産＝運用＞                        ＜負債＝調達＞
 ┌──────────────┐        ┌──────────────┐
 │ 貸出金        40〜50% │        │ 預金          70〜80% │ ← 調達コストが低い
 │  法人・住宅ローン       │        │  個人・法人の普通/定期  │    これが銀行の強み
 ├──────────────┤        ├──────────────┤
 │ 有価証券      15〜25% │        │ 市場調達      10%前後 │ ← 社債・CD・コールなど
 │  国債・外債・株式       │        ├──────────────┤
 ├──────────────┤        │ その他負債            │
 │ 日銀当座預金  10〜20% │        ├──────────────┤
 │  （余った資金の置き場）  │        │ **自己資本   5%前後** │ ← 損を吸収する層
 ├──────────────┤        │  （資本金・利益剰余金）  │
 │ 現金・その他          │        └──────────────┘
 └──────────────┘

  → 資産の「利回り」ー 負債の「利回り」＝ **利ざや**（第4章）
  → 資産が5%目減りしただけで自己資本が消える ＝ **レバレッジが効いた商売**

銀行の規模感（一次統計）。

項目 金額 前年同月比 時点・出典
全国銀行（107行）の総預金971兆8,836億円+2.6%2026年3月末、全国銀行協会 速報
全国銀行の貸出金636兆2,102億円+4.6%同上
都市銀行5行の預金495兆6,740億円+2.6%同上（みずほ・三菱UFJ・三井住友・りそな・埼玉りそな）
都市銀行5行の貸出金252兆3,331億円+4.9%同上

※「都市銀行5行」にはりそな・埼玉りそなが入るため、3メガ＝都銀ではない。
ただし預金・貸出の大半は3メガが占める。個社別は ② メガバンクの稼ぎ方。

ここから2つ読める。

  1. 預金 971兆円に対し貸出は 636兆円。差の約335兆円は国債などの有価証券と日銀当座預金に回っている。
    つまり日本の銀行は「集めた預金を貸し切れていない」状態が続いている（預貸率＝貸出÷預金、全国銀行で約65%）
  2. 都市銀行は預貸率が約51%とさらに低い。大企業は社債や内部留保で資金を賄えるため、
    メガバンクは国内貸出だけでは資金を使い切れない。だから海外貸出と有価証券運用が要る（→ ②）

3. 信用創造 ―― 銀行だけが「お金を増やせる」理由

銀行の独特さは、貸出を実行した瞬間に預金が生まれる点にある。
現金を数えて貸しているのではなく、借り手の口座に数字を書き込んでいる。

【信用創造の最小モデル】

 ① A社が銀行から1億円借りる
    銀行BS：  資産 +貸出金 1億円   /  負債 +預金（A社口座） 1億円
              ↑ 手元の現金は1円も減っていない。**預金＝お金が新しく生まれた**

 ② A社が仕入先B社へ1億円支払う
    → B社の口座（同じ銀行 or 他行）へ預金が移るだけ。世の中の預金総額は減らない

 ③ B社の銀行がその預金を元手にまた貸す
    → さらに預金が生まれる ……（以下くり返し）

 ブレーキになるもの：
   ・**自己資本比率規制**（資本が足りないと貸せない）← 現代の主な制約
   ・預金準備率（日銀に積む義務）
   ・**借りたい人がいるかどうか**（実はこれが最大の制約。日本の30年はここで詰まった）

ポイント：教科書的な「預金準備率による乗数」より、実務上のブレーキは
資本の量と資金需要の有無。日本で長く貸出が伸びなかったのは
銀行に金がなかったからではなく、借り手が借りなかったから。

4. 利ざや ―― 銀行の「粗利率」

利ざやとは、運用（貸出・有価証券）で受け取る利回りと、調達（預金・市場調達）で払う利回りの差。
よく使われる指標は次の3つ。

指標 定義 何を見る数字か
預貸金利回り差貸出金利回り − 預金等利回り貸すビジネスの粗利率。銀行の本丸
資金利益率（NIM）資金利益 ÷ 資金運用資産有価証券・日銀当預も含めた運用全体の利ざや
総資金利ざや資金運用利回り −（資金調達原価率＝調達利回り＋経費率）経費まで引いた後。ここがマイナスだと本業赤字

日本の銀行の預貸金利回り差は、ゼロ金利・マイナス金利期に1%を切る水準まで潰れた。
理由は単純で、預金金利は0%より下げられない（ゼロ金利制約）のに、
貸出金利だけが競争と政策金利低下で下がり続けたから。

【利ざやが潰れる／戻るメカニズム】

〈マイナス金利期（〜2024年3月）〉        〈金利のある世界（2024年〜）〉

 貸出金利  ▂▂▂ 0.8%                   貸出金利  ▅▅▅ 1.6%
                ↕ 利ざや 約0.75%                        ↕ 利ざや 拡大
 預金金利  ▁ 0.001%〜0.02%            預金金利  ▂ 0.4%（2026年8月、メガ普通預金）
           ─── ゼロの床 ───
   ↑ 預金金利はこれ以上下げられない          ↑ 預金金利の上げ幅 ＜ 貸出金利の上げ幅
     → 貸出金利が下がるほど利ざやが消える       → **差が開く＝増益**

※ 数値は水準感の例示。金利は 2026年9月18日の日銀会合で政策金利が 1.25%程度へ引き上げられたと報じられる。
金利局面の詳細は ④ 金利のある世界への転換。

5. 収益の3本柱 ―― 業務粗利益の分解

銀行の売上に当たるのが業務粗利益。これは必ず3つに分解して見る。

柱 正式名称 中身 特徴
① 利ざや資金利益貸出金利息＋有価証券利息 − 預金利息等金利水準に直結。残高×利ざやの掛け算
② 手数料役務取引等利益送金・為替、投信/保険の販売、M&Aアドバイザリー、シンジケートローン組成、カード、信託報酬金利に左右されにくい。非金利収入の本命
③ 市場・その他その他業務利益国債等債券売買損益（債券5勘定尻）、外国為替売買益、デリバティブブレが大きい。損切りで赤字にもなる
【業務粗利益 → 最終利益までの流れ】

  業務粗利益（＝①資金利益 ＋ ②役務取引等利益 ＋ ③その他業務利益）
      −  経費（人件費・物件費＝店舗・システム・減価償却）
      ───────────────────────────
   ＝ **業務純益**（本業の儲け）
      −  **与信費用**（貸し倒れに備えた引当・損失）  ← 第7章
      ±  株式等関係損益（政策保有株の売却益など）
      ±  持分法投資損益（海外出資先の取り分）
      −  税金
      ───────────────────────────
   ＝ 親会社株主に帰属する当期純利益

ここで押さえるべき癖：銀行の利益は「与信費用」で大きく上下する。
本業（業務純益）が横ばいでも、引当を積めば減益、戻し入れれば増益になる。
だから決算を見るときは「業務純益」と「与信費用」を分けて読む。→ ③ リスクと健全性

6. 資産サイドの中身 ―― 貸す・買う・預ける

集めた預金の使い道は3つしかない。

使い道 利回り リスク 補足
貸出金高い信用リスク（貸し倒れ）法人融資、住宅ローン、カードローン、プロジェクトファイナンス
有価証券中金利リスク・価格変動国債、地方債、社債、外債、投資信託、政策保有株式
日銀当座預金政策金利に連動ほぼ無し余資の置き場。金利のある世界ではここ自体が収益源になった

7. コスト構造 ―― 固定費の塊であること

銀行のコストは人件費と物件費（店舗・システム）が大半で、ほぼ固定費。
貸出が増えても比例して費用は増えない。だから残高が増えるほど利益率が跳ねる（オペレーティングレバレッジ）。

指標 意味 目安
OHR（経費率）経費 ÷ 業務粗利益。低いほど効率的日本のメガで50〜60%台。欧米大手は50%台が優良とされる
与信費用率与信費用 ÷ 貸出残高平時は年0.1〜0.3%程度。危機時は1%超へ跳ねる
ROE純利益 ÷ 自己資本長く5%前後だったが、2026年3月期はMUFGで11.3%（東証定義）に達したと報じられる

だから銀行の構造改革は、必ず店舗削減・人員削減・システム統合に向かう。
粗利が伸びない時代には、固定費を削る以外に利益を作る手がなかった。→ ④

8. 自己資本比率規制（BIS規制）―― 銀行だけの足かせ

銀行はレバレッジが高い（自己資本は資産の5%前後）。
そこで国際的な取り決めとして、リスクの大きさに応じた資本を持てという規制がかかる。
バーゼル銀行監督委員会が決めるのでバーゼル規制／BIS規制と呼ぶ。

【自己資本比率の計算式】

                    自己資本（CET1など）
  自己資本比率 ＝ ────────────────────
                  **リスクアセット（RWA）**

  RWA＝資産額 × リスクウェイト
     日本国債            → 0%      （いくら持っても分母が増えない）
     住宅ローン          → 20〜35%  （担保があるので軽い）
     優良大企業向け融資  → 20〜50%
     中小企業向け融資    → 75〜100%
     株式（政策保有株）  → 100〜250%以上（重い。売却圧力の理由）

  → 同じ1兆円を貸しても、**誰に貸すかで必要な資本が変わる**
  → だから銀行は「RWA効率（＝RWA1単位あたりの利益）」で案件を選ぶ

用語を整理する。

用語 読み・意味
RWARisk-Weighted Assets＝リスクアセット。リスクの重みを掛けて数え直した資産額。規制上の分母
CET1Common Equity Tier1＝普通株式等Tier1資本。資本のうち最も損失吸収力が高い中核部分（普通株＋内部留保）。規制上の分子の本命
Tier1 / Tier2CET1にその他Tier1（AT1債など）を足したのがTier1、劣後債等を足したのが総自己資本
国際統一基準行 / 国内基準行海外拠点を持つ銀行は総自己資本比率8%以上（＋資本バッファ）、国内のみの銀行は4%以上。メガは前者
G-SIBs世界的にシステム上重要な銀行。MUFG・SMFG・みずほの3社とも指定され、追加の資本上乗せが課される
バーゼルIII最終化内部モデルの使い過ぎを抑える改定。国際統一基準行には2024年3月末から適用。資本フロア（内部モデル算出RWAが標準的手法の一定割合を下回らないようにする措置）は段階導入で2026年に70%、2027年に最終の72.5%（金融庁資料）

なぜこんな規制があるか。銀行が潰れると預金と決済が止まり、経済全体が止まるから。
自動車メーカーが1社潰れても車は他社から買える。銀行は決済インフラなので代替が効かない。
この「公共性」が、免許制・検査・規制資本・公的資金という一連の仕組みの根拠になっている。

9. 銀行が壊れる2つの壊れ方

壊れ方 メカニズム 対処する規制
ソルベンシー（資産の毀損）貸し倒れや有価証券の評価損で自己資本が食い潰される自己資本比率規制、ストレステスト
流動性（取り付け）資産は無事でも、預金が一斉に逃げて支払いが回らない。資産は貸出＝すぐ現金化できない（満期のミスマッチ）流動性カバレッジ比率（LCR）、安定調達比率（NSFR）、日銀の「最後の貸し手」機能

2023年の米シリコンバレー銀行（SVB）は典型で、金利上昇で保有債券に含み損 →
不安になった預金者がスマホで一斉に資金移動 → 数日で破綻という流動性の壊れ方だった。
デジタル時代は取り付けの速度が桁違いに速い。金融庁も2026事務年度の行政方針で
預金などの流動性リスク管理を重点点検に挙げている（2026年9月15日公表、報道ベース）。
