# 金利のある世界への転換

このノートで分かること：**2024年3月のマイナス金利解除で、銀行の何が「元に戻った」のか**。要点は一つ、
**預金がふたたび価値のある原材料になった**こと。そして、金利が消えていた10年間に銀行が身につけた体質
（店舗削減・システム投資・手数料シフト）が、金利が戻った今どう効いているかを整理する。

> 仕組みの基礎は [①](01_銀行のビジネスの基本.md)、個社の数字は [②](02_メガバンクの稼ぎ方.md)、副作用（含み損）は
> [③](03_リスクと健全性.md)。ここでは**「金利がどこを通って銀行の損益に届くか」という伝達の配線**を見る。

## 1. 何が起きたのか ―― 3行で

1. 日銀は2016年2月から**マイナス金利政策**（日銀当座預金の一部に −0.1% を課す）を採っていたが、
   **2024年3月19日の決定会合で解除**し、無担保コール翌日物を 0〜0.1% 程度に誘導する枠組みへ戻した
2. そこから段階的な利上げが続き、**2026年9月18日の会合で政策金利は1.25%程度**へ引き上げられたと報じられる
3. 結果、3メガの2026年3月期の連結純利益は合計**5兆2,588億円**（前期比+33.9%、3社とも3期連続で最高益）。
   増益の主因は**資金利益＝利ざや**の改善だった（各社決算、報道ベース）

> ポイント：これは銀行が急に賢くなったからではない。**同じ商売をしていて、価格（金利）だけが戻った**。
> だから「実力か、環境か」を分けて読むことが、この局面の銀行を見るときの基本姿勢になる。

## 2. マイナス金利期に銀行で起きていたこと

マイナス金利は「預金者からお金を取る政策」ではなく、
**銀行が日銀に置いている当座預金の一部にマイナスの利息を課す**政策だった。

```
【マイナス金利期（2016-2024年）の銀行の詰み方】

  ① 貸出金利 ── 政策金利に引っ張られて低下 ──▶ ▼ 下がる
  ② 預金金利 ── 0%より下げられない（ゼロ金利制約）▶ ─ 動かない（0.001%）
                          → **利ざや ＝ ① − ② が一方的に潰れる**
  ③ 貸出に回らない資金 → 日銀当座預金へ。うち「政策金利残高」は **−0.1%**
     ＝ 置くだけで費用。国債を買っても利回りゼロ、超長期なら金利リスク
  ④ 打てた手は3つだけ
     (a) 手数料を増やす（投信・保険販売、M&A、信託）  → [②](02_メガバンクの稼ぎ方.md) 第6章
     (b) 海外で稼ぐ（利ざやの厚い国へ）              → [②](02_メガバンクの稼ぎ方.md) 第4章
     (c) **経費を削る**（店舗・人員・システム）       → 本ノート 第6・7章
```

（c）が本ノートの主題である。**粗利が伸びない以上、利益は経費側からしか作れなかった**。
この10年、銀行が「縮む産業」に見えていたのはそういう構造による。

## 3. 政策金利の推移 ―― どこまで来たか

| 時点          | 政策金利（無担保コール翌日物）      | 出来事                                                |
| ------------- | ----------------------------------- | ----------------------------------------------------- |
| 2016年2月     | **−0.1%**（当座預金の政策金利残高） | マイナス金利政策の導入                                |
| 2024年3月19日 | **0〜0.1%程度**                     | **マイナス金利解除**。17年ぶり利上げ、YCCも撤廃       |
| 2024年7月     | 0.25%程度                           | 追加利上げ                                            |
| 2025年1月     | 0.5%程度                            | 追加利上げ                                            |
| 2026年6月     | **1.00%程度**                       | 段階的な引き上げを経て到達（日銀公表、報道ベース）    |
| 2026年9月18日 | **1.25%程度**                       | 3カ月ぶりの追加利上げ。物価上振れリスクへの対応と報道 |

長期金利も上昇し、**30年債利回りは3%台**を付けたと報じられる（2026年9月）。
この「金利3%時代」を前提に、金融庁は2026事務年度の金融行政方針で不動産業向け融資・超長期の住宅ローン・
流動性リスクを重点点検に挙げた（2026年9月15日公表）。最新は日銀「金融市場調節方針」で確認する。

## 4. 金利はどの配線を通って銀行の損益に届くか

「政策金利が上がる＝銀行が儲かる」は結論としては正しいが、**途中の配線を知らないと決算が読めない**。

```
【政策金利 → 銀行収益の伝達経路（4本の配線）】

   日銀の政策金利 ↑
     ├─▶ ①**日銀当座預金の付利** ↑ … 余資を置くだけで利息。**即日・確実に効く**
     │      メガは当預残高が巨額で、ここだけで数千億円規模の増収要因
     ├─▶ ②**短期プライムレート（短プラ）** ↑ … 優良企業向け短期貸出と住宅ローン変動金利の基準
     │      長く1.475%で固定 → 2024年以降に段階引き上げ、2026年は**2.125%程度**の行が多い
     │      ただし**約定の更改・返済日まで反映されず、半年〜1年遅れて効く**
     ├─▶ ③**TIBOR／市場連動（スプレッド貸出）** ↑ … 大企業向けに多く、**改定が速い**
     └─▶ ④**預金金利** ↑（＝費用。普通預金は横並びで改定、定期は期日まで旧金利）

   差し引き ＝ **資金利益の増加** ＋ 副作用：含み損拡大（→ [③](03_リスクと健全性.md) 第3章）
```

実務の癖が2つ。**効き方に時間差がある**（付利は即日、市場連動は数カ月、短プラ連動と住宅ローンは半年〜1年）ため
利上げの恩恵は数期にわたり出続ける。一方**預金は改定日に一斉に上がる**ので、直後の四半期は費用が先に出ることもある。

## 5. 預金の価値の復活 ―― 「ただの負債」から「最強の資産」へ

マイナス金利期、預金は**持て余すもの**だった。集めても貸せず、日銀に置けば費用が出るため、各行は法人の
大口預金を断りさえした。金利のある世界では、この評価が180度ひっくり返る。

```
【同じ100兆円の預金が、金利局面でいくらを生むか（概念計算）】

  〈マイナス金利期〉                    〈2026年9月時点〉
   調達コスト 0.001%                     調達コスト 0.4%（普通預金）
   運用先 日銀当預 −0.1% ／ 国債 0.0%    運用先 日銀当預 1.25%前後
   ─────────────            ─────────────
   取り分 ほぼゼロ（むしろ費用）           取り分 **約0.85%**
   100兆円 × ほぼ0 ＝ **ほぼ0円**         100兆円 × 0.85% ＝ **約8,500億円**

   ※「貸さずに日銀に置いただけ」の概算。貸せばさらに厚い。**預金を持つこと自体が収益源に戻った**
```

だから競争軸は**「預金をどれだけ安く、どれだけ多く維持できるか」**に戻る。ここで効くのが**預金ベータ**。

| 用語                         | 定義                                           | 2024〜2026年の日本（概算）                                                               |
| ---------------------------- | ---------------------------------------------- | ---------------------------------------------------------------------------------------- |
| **預金ベータ**               | 政策金利の上昇幅のうち預金金利に転嫁された割合 | 政策金利 −0.1%→1.25%（+1.35pt）に対し普通預金は 0.001%→0.4%（+0.4pt）。**ベータは約30%** |
| **粘着性（スティッキネス）** | 金利が上がっても預金が逃げない度合い           | 給与振込・口座振替・決済口座は動きにくい。**メガの強みの正体**                           |

> ポイント：**銀行の増益は「預金ベータが低い」ことの裏返し**である。利上げ分の3割しか返していないから、
> 7割が粗利になる。日本の銀行が特別ずるいのではなく、**口座を動かさない預金者が多い**という市場構造の結果。
> 逆に言えば、預金者が動き出した瞬間にこの構図は縮む（→ 第8章）。

| 時点                          | 円普通預金金利 | 備考                                                     |
| ----------------------------- | -------------- | -------------------------------------------------------- |
| マイナス金利期（〜2024年3月） | **0.001%**     | 100万円を1年預けて利息10円                               |
| 2026年2月2日                  | 0.3%           | 三菱UFJは旧行時代を含め33年ぶり水準と報じられる          |
| **2026年8月3日**              | **0.4%**       | 3メガ横並びで改定。**1992年8月以来およそ34年ぶり**の水準 |
| 定期預金1年もの（2026年9月）  | 年0.5%程度     | 3メガ横並び。ネット銀行はこれを上回る商品を出している    |

## 6. 預貸金利回り差の戻り方と、コスト構造改革の到達点

**預貸金利回り差**＝貸出金利回り − 預金等利回り（→ [①](01_銀行のビジネスの基本.md) 第4章）。
戻り方は**左右非対称**で、貸出は約定更改を待ちながらじりじり上がり、預金は上げ幅が3割程度にとどまる。
この非対称性が2025〜2026年の増益の正体だが、**永遠には続かない**。理由は3つ。

1. **貸出の金利改定はいずれ一巡する**。入れ替わり切れば、利上げが止まった瞬間に伸びも止まる
2. **預金ベータは時間とともに上がる**。競争と預金者の学習で、転嫁率は後から効いてくる
3. **与信費用が戻る**。不良債権比率1.07%（2026年3月期、東京商工リサーチ）は歴史的低水準で、**上げ余地の方が大きい**

もう一つの増益要因が、金利ゼロの10年に削り続けた経費である。

| 領域           | 何をしたか                                             | 規模感（公表・報道ベース）                                            |
| -------------- | ------------------------------------------------------ | --------------------------------------------------------------------- |
| **店舗**       | 近隣店舗の統廃合、支店の出張所化、共同店舗             | 3メガの国内店舗は30年で約6割減ったとされる（東洋経済、2023年）        |
| **店舗の中身** | フルバンク店 → **軽量店**（相談特化、現金を扱わない）  | みずほ銀行は店舗の約4割をコンサル特化型へ転換する方針と報じられる     |
| **人員**       | 新卒採用の抑制、自然減、業務量ベースの削減目標         | 2017〜2018年に各行が公表した構造改革計画（数千〜1万人超の業務量削減） |
| **事務**       | 印鑑レス、タブレット受付、後方事務の集中処理センター化 | 店頭事務の削減が軽量店化の前提条件                                    |
| **ATM**        | 他行・コンビニとの共同化                               | 自社網を持つコストを下げる                                            |

```
【店舗戦略の3段階】

 第1段階（2017-2021） **統廃合**：近くの店を閉じてまとめる
                       → 閉めるほど次に閉める店がなくなり、限界が来る
 第2段階（2021-2024） **軽量化**：現金・事務を引き上げ、相談業務に特化した店を残す
 第3段階（2024年〜）   **再配置**：金利のある世界で「預金と相談」の価値が戻り、
                       閉じ続けるのではなく**どこに置くか**の問題へ（増やすのはリモートとアプリ）

  なぜ閉じられたのか ＝ **取引の大半がアプリとATMに移ったから**
```

> 押さえどころ：**銀行の経費はほぼ固定費**（→ [①](01_銀行のビジネスの基本.md) 第7章）。
> だから粗利が戻った今、削った固定費はそのまま利益に落ちる（**オペレーティングレバレッジ**）。
> 2026年3月期の最高益は「利ざや回復 × 10年削り続けた経費」の掛け算である。

## 7. システム投資とDX ―― 削れないコスト

経費のうち、**システム費だけは削れない**。むしろ増えている。ここが銀行のコスト構造の特殊な点。

| 投資領域                   | 中身                                         | なぜ必要か                                                                                    |
| -------------------------- | -------------------------------------------- | --------------------------------------------------------------------------------------------- |
| **勘定系（基幹システム）** | 預金・為替・融資の元帳。止められない         | 止まると決済が止まり、行政処分と社会的影響に直結                                              |
| **チャネル**               | アプリ、オンラインバンキング、API連携        | 店舗を閉じた分の接点をここで賄う                                                              |
| **規制対応**               | マネロン監視、本人確認、レポーティング       | 規制は増える一方で削減対象にできない（→ [③](03_リスクと健全性.md) 第7章）                     |
| **セキュリティ**           | 不正送金・ランサムウェア対策                 | [情報セキュリティ](../../04_情報通信・IT・ネット/14_情報セキュリティ/README.md)の供給側と直結 |
| **AI**                     | 書類作成・照会応答・審査支援・コールセンター | 人員削減の次の打ち手                                                                          |

```
【勘定系が重い理由 ―― なぜ「作り直せない」のか】

 1970-80年代 各行が自前でメインフレーム上に構築（COBOL資産）
      │       合併のたびに**片寄せ or 併存**の判断が発生
      ▼
 みずほの例  3行統合時に統合を先送り → 2002年・2011年に大規模障害
      │       → **MINORI** を約4,500億円かけて構築、2019年に移行完了
      ▼
 現在  ・止めれば社会が止まる ・仕様を知る技術者が高齢化（**レガシー人材の枯渇**）
       ・投資しても売上は増えない（**守りの投資**）
       → それでも刷新に向かうのは、**維持費とリスクが刷新費を上回る**ところまで来たから
       → 三井住友銀行は次期勘定系でメガ初の24時間無停止オンラインを目指すと報じられる

 発注先は [SIer・ITサービス](../../04_情報通信・IT・ネット/05_SIer・ITサービス/README.md) の主要顧客
```

生成AIの実装も2025〜2026年に「実験」から「業務組み込み」へ移った（いずれも報道ベース）。三井住友銀行の
営業店向けAIアシスタントは2026年3月時点で約28,000名が利用し、音声認識AIと大規模言語モデルによる
コールセンターでは人手の対応件数を1日あたり約50%削減したとされる。次の焦点は**エージェント型**の利用。

> ここでの見方：AIは「人を減らす道具」であると同時に、**店舗を閉じて失った顧客接点を安く取り戻す道具**でもある。
> 銀行のDXは効率化の話に見えて、実質は**チャネル戦略**の話である。

## 8. フィンテックとの競合 ―― 金利が戻っても消えない脅威

金利のある世界は銀行に追い風だが、**同時に「預金が動く世界」でもある**。
金利が0%ならどこに置いても同じだから誰も動かない。金利が付いた瞬間、比較が始まる。

| 競合の軸               | 相手                                                                  | 何を取られるか                                                                         |
| ---------------------- | --------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| **預金金利**           | [ネット銀行](../04_ネット銀行/README.md)、証券口座のMRF、個人向け国債 | 最も安い調達原資。店舗を持たない分、相手は高い金利を出せる                             |
| **決済**               | コード決済、送金アプリ、給与デジタル払い                              | 日常の決済接点と購買データ。接点を失えば商品販売機会も消える                           |
| **住宅ローン**         | ネット銀行                                                            | 量の大きい資産。2026年はメガの変動1.25%に対しネット銀行1.29%と**逆転現象**も報じられる |
| **資産運用**           | ネット証券、[資産運用](../06_資産運用/README.md)会社の直販            | 新NISA以降の投信残高。手数料収入の柱                                                   |
| **法人決済・資金管理** | クラウド会計・BaaS事業者                                              | 中小企業の入出金データという与信情報                                                   |

```
【銀行機能のアンバンドリング（分解）と再統合】

 かつて  ひとつの銀行が全部を束ねていた
         ［口座／決済／送金／融資／運用／保険／外貨］

 2010年代 機能ごとに専業が切り出した（アンバンドリング）
         口座・決済 → コード決済／プリペイド   融資 → オンラインレンディング
         送金     → 送金アプリ・海外送金      運用 → ネット証券・ロボアド

 2020年代 銀行側の反撃＝**再統合**
         ・アプリを「金融のハブ」にする（残高・カード・投資・保険を1画面に）
         ・[証券](../05_証券/README.md)・信託・カードのグループ連携（→ [②](02_メガバンクの稼ぎ方.md) 第5章）
         ・**銀行自身がデジタル通貨側に出る**：3メガは信託型ステーブルコインの共同発行で合意し、
           2026年度中の実取引開始を目指すと報じられる（→ [⑤](05_直近トピック_2026.md)）

 銀行が最後まで手放せない中核 ＝ **口座（本人確認済みの受け皿）**・**与信**・**決済の最終決済**
```

> まとめ方：フィンテックは銀行の**利ざやを奪う**より、**接点と手数料を削る**形で効いてきた。金利が戻って
> 収益は回復したが、**接点の奪い合いは終わっていない**。むしろ預金金利が意味を持つ分、乗り換えは容易になった。

## 9. この局面で何を見ればよいか

決算を読むときは5点。**①預貸金利回り差の前年同期比**（利上げが粗利に届いたか）、
**②預金残高と普通／定期の構成比**（調達コストが上がっていないか）、**③与信費用と不良債権比率**、
**④有価証券の含み損益とデュレーション**（→ [③](03_リスクと健全性.md)）、
**⑤OHRとシステム投資額**（削った固定費が利益に落ちているか）。

| **TIBOR**                        | 東京銀行間取引金利。大企業向けスプレッド貸出の基準に使われ、金利改定が速い               |
| **預金ベータ**                   | 政策金利の上昇幅のうち預金金利に転嫁された割合。低いほど銀行の粗利が厚い                 |
| **軽量店**                       | 現金・事務機能を持たず、相談業務に特化した小型店舗                                       |
| **オペレーティングレバレッジ**   | 固定費比率が高い事業で、売上増が利益に増幅して効く性質                                   |
| **勘定系システム／レガシー**     | 預金・為替・融資の元帳を処理する基幹システム／保守人材が減った既存システム資産           |
| **アンバンドリング**             | 銀行が束ねていた機能を専業事業者が個別に切り出すこと。その逆が再統合（リバンドリング）   |
