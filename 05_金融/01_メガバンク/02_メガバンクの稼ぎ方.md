# メガバンクの稼ぎ方

このノートで分かること：**3メガ（MUFG／SMFG／みずほ）が、誰から預かり、誰に貸し、どこで稼いでいるか**。
地方銀行との決定的な違いは、**海外**と**グループ会社（信託・証券・カード・リース）**という2本の追加エンジンを持っていること。

> 前提知識は [① 銀行のビジネスの基本](01_銀行のビジネスの基本.md)。
> 利ざや・資金利益・RWA・CET1 といった語はそちらで説明している。

## 1. 「メガバンク」とは何を指すか

制度上「メガバンク」という業態区分はない。実務では、
**バブル崩壊後の再編で生き残った3つの巨大金融グループ**を指す。

| グループ                                     | 銀行本体     | 主な前身（都市銀行の統廃合） | 特徴のひとことまとめ                                                        |
| -------------------------------------------- | ------------ | ---------------------------- | --------------------------------------------------------------------------- |
| **三菱UFJフィナンシャル・グループ（MUFG）**  | 三菱UFJ銀行  | 三菱＋東京＋三和＋東海       | 規模で首位。**米モルガン・スタンレー約2割出資**とアジア商業銀行の買収が武器 |
| **三井住友フィナンシャルグループ（SMFG）**   | 三井住友銀行 | 三井＋住友＋さくら           | 効率経営（低OHR）。**米ジェフリーズ提携＋アジアのマルチフランチャイズ戦略** |
| **みずほフィナンシャルグループ（みずほFG）** | みずほ銀行   | 第一勧業＋富士＋日本興業     | 大企業取引と証券（旧興銀由来）が強み。楽天グループとの提携でリテール補強    |

りそなホールディングスは都市銀行（りそな・埼玉りそな）を持つが、
海外拠点をほぼ持たず国内リテール・信託に特化しているため、通常メガには数えない。

```
【日本の銀行再編の大きな流れ】

 1990年代初頭：都市銀行13行 ＋ 長信銀3行 ＋ 信託7行
        │ バブル崩壊 → 不良債権の山（→ [③](03_リスクと健全性.md)）
        │ 1997-98年：北海道拓殖銀行破綻、長銀・日債銀の国有化
        ▼
 1999-2006年：金融危機と公的資金を経て大合併
        ├─ 第一勧業＋富士＋日本興業 ─────▶ **みずほ**（2000年持株会社、2002年銀行統合）
        ├─ 住友＋さくら（三井＋太陽神戸）──▶ **三井住友**（2001年）
        ├─ 三和＋東海 ─▶ UFJ ┐
        └─ 三菱＋東京 ────── ┴──────▶ **三菱UFJ**（2005-06年）
        ▼
 現在：3メガ ＋ りそな ＋ [地方銀行](../02_地方銀行/README.md)群 ＋ [ネット銀行](../04_ネット銀行/README.md)
```

> ポイント：**メガバンクは「勝った銀行」ではなく「生き残るために合併した銀行」**。
> 巨大な店舗網・重複システム・複数の企業文化という統合コストを、20年以上かけて処理してきた。
> みずほの度重なるシステム障害も、この統合の後遺症という文脈で語られることが多い。

## 3. 収益の4部門 ―― どこで稼いでいるか

3メガは社内を「部門（セグメント）」で切って管理している。名称は各社で違うが、実質は次の4〜5分類。

| 部門                             | 顧客                 | 主な収益                                                                       | 性格                                                                                   |
| -------------------------------- | -------------------- | ------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------- |
| **法人（国内）**                 | 大企業・中堅中小     | 貸出の利ざや、為替・送金、M&Aアドバイザリー、シンジケートローン組成手数料      | 金利上昇の恩恵が最も大きい                                                             |
| **個人（リテール）**             | 個人・富裕層         | 住宅ローン、預金（調達）、投信・保険の販売手数料、カード                       | **預金という原材料の供給源**。単体では儲けにくい                                       |
| **海外（グローバル）**           | 海外の企業・現地個人 | 海外貸出の利ざや（国内より厚い）、プロジェクトファイナンス、現地銀行の持分利益 | 3メガの利益の**3〜4割**を生むエンジン                                                  |
| **市場（グローバルマーケッツ）** | ―                    | 債券・為替・デリバティブのトレーディング、ALM（資産負債の金利ポジション管理）  | 振れが大きい。金利観の勝負                                                             |
| **受託・アセット**               | 年金・機関投資家     | 信託報酬、運用報酬                                                             | [信託銀行](../03_信託銀行/README.md)・[資産運用](../06_資産運用/README.md)と重なる領域 |

```
【メガバンクの利益ポートフォリオ（概念図／構成比は各社・年で変動）】

  国内法人  ■■■■■■■■■■■■         ← 金利上昇で急回復中
  海外      ■■■■■■■■■■■■■■     ← 利ざやが厚い。ただし与信費用と地政学リスク
  市場      ■■■■■■                 ← ブレ大
  個人      ■■■■■                   ← 預金の供給源。手数料は新NISAで底上げ
  受託・その他■■■■

   ※ 個人部門は「利益が薄いから縮小」ではない。**預金（最も安い調達）を
     生み出す工場**であり、これを失うと法人・海外の貸出原資が消える。
     ここが [ネット銀行](../04_ネット銀行/README.md)や
     [フィンテック](../../04_情報通信・IT・ネット/13_フィンテック・キャッシュレス/README.md)との競合が効いてくる点。
```

## 4. 海外部門 ―― メガバンクの本当の差別化

地方銀行にはできず、メガにだけできること。それが**海外**である。理由は3つ。

1. **国内では資金が余っている**。都市銀行の預貸率は約51%（2026年3月末、全銀協速報から算出）。
   国内で貸し切れない資金の行き先が要る
2. **海外の貸出利ざやのほうが厚い**。日本の大企業向けが0.3〜0.6%なのに対し、
   アジアのノンバンクや新興国リテールは数%単位
3. **円建て資産だけでは成長が取れない**。人口が減る国の銀行が成長するには、人口が増える国に資産を持つしかない

```
【3メガの海外の攻め方の違い（報道・各社開示ベース）】

 MUFG  ：買って「現地の銀行になる」型
         タイ・アユタヤ銀行（Krungsri）、インドネシア・バンクダナモン、
         フィリピン・セキュリティバンク出資 ＋ **米モルガン・スタンレー約2割出資**
         → 現地ブランドを残し、持分利益と現地リテールで稼ぐ

 SMFG  ：「第2・第3のSMBCグループ」を作る **マルチフランチャイズ戦略**
         インドネシア（BTPN）、インド（SMFG India Credit＝旧フラトン、子会社化）、
         ベトナム（FE Credit出資）、フィリピン ＋ 米ジェフリーズと提携（IB領域）

 みずほ ：法人・投資銀行ルート中心
         米グリーンヒル買収（M&Aアドバイザリー）、インドの投資銀行買収、
         アジアでは大企業取引と証券ビジネスを軸に

 共通  ：**インドへの集中**。3メガ合計で1兆円超を出資・買収に投じたと報じられる（日経、2025年12月）
```

海外は「うまみ」と同時に「痛み」も大きい。東洋経済（2026年）は、
**米モルガン・スタンレー出資が巨額の持分利益を生む一方、東南アジアの出資先では減損・巨額損失が続いた**と報じている。
新興国のリテール・消費者金融は利ざやが厚い代わりに、景気悪化で一気に貸し倒れが出る。

> 教訓として押さえる構図：**海外の利ざやの厚さは、そのまま信用リスクの厚さである**。
> 高い利回りはリスクの対価であって、無料のボーナスではない。

## 5. グループ会社の束ね方 ―― 「銀行」だけではない

メガバンクは持株会社（フィナンシャル・グループ）の下に、業態別の子会社をぶら下げている。
これは**業態ごとに免許が違う**という日本の制度設計に由来する。

```
【メガバンクグループの標準的な構成】

            ┌──────────────────────────┐
            │   ○○フィナンシャル・グループ（持株会社）    │ ← 上場しているのはここ
            └──────────────────────────┘
                 │
   ┌────┬────┬────┬────┬────┬────┐
   ▼        ▼        ▼        ▼        ▼        ▼
  銀行     信託銀行   証券      カード    リース    資産運用
  預貸・決済 年金・不動産 引受・仲介  与信・加盟店  設備の所有  投信の組成
   │         │         │         │         │         │
   └─ [本ノート]  [信託](../03_信託銀行/README.md)  [証券](../05_証券/README.md)  [カード・決済](../11_クレジットカード・決済/README.md)  [リース](../10_リース/README.md)  [資産運用](../06_資産運用/README.md)

  なぜ束ねるのか＝**同じ顧客に複数の商品を売れる（クロスセル）**
   例：企業の資金需要 → 銀行が融資 → 社債発行なら証券 → 設備なら リース
       → 従業員の年金は信託 → 決済はカード会社 → 余資は資産運用
  規制上の注意：**銀証ファイアウォール規制**（融資で得た非公開情報を
  証券部門に流すことの制限）。2022年に法人向けは大幅緩和された
```

| グループ会社         | 稼ぎ方                                | メガにとっての意味                                            |
| -------------------- | ------------------------------------- | ------------------------------------------------------------- |
| **証券**             | 引受手数料、M&A手数料、ブローカレッジ | 大企業の資金調達が「融資→社債・株式」に動いても取り逃がさない |
| **信託**             | 信託報酬、不動産仲介、証券代行        | 年金・事業承継・不動産という**手数料の塊**                    |
| **カード・決済**     | 加盟店手数料、リボ・分割の金利、会費  | 個人の日常決済データと安定収益                                |
| **リース**           | 賃料と物件の残価                      | 融資では取れない設備投資需要。海外リースは大型ビジネス        |
| **消費者金融・保証** | 高い利ざや                            | 銀行本体では取りにくいリスク層を子会社で引き受ける            |

## 6. 非金利収入（手数料）へのシフト

長いゼロ金利時代、日本の銀行は「利ざやで稼げないなら手数料で稼ぐ」方向に舵を切った。
これは**日本特有の戦略ではなく、欧米大手銀行が先に到達した形**でもある。

| 手数料の種類           | 中身                                                          | 最近の動き                                                           |
| ---------------------- | ------------------------------------------------------------- | -------------------------------------------------------------------- |
| **投資商品の販売**     | 投資信託・保険の販売手数料、残高連動のフィー                  | 2024年開始の**新NISA**で口座と残高が拡大。株高も追い風（報道ベース） |
| **法人ソリューション** | M&Aアドバイザリー、ストラクチャードファイナンス組成、事業承継 | 国内M&Aの増加とPEファンドの活発化で伸長                              |
| **決済・為替**         | 送金手数料、外国為替、トランザクションバンキング              | 無料化の圧力あり。海外送金はフィンテックと競合                       |
| **信託・受託**         | 年金・証券代行・不動産                                        | 安定的なストック収入                                                 |

```
【収益構造のシフト（イメージ）】

  〈2000年代〉         〈ゼロ金利期〉        〈金利のある世界／2024年〜〉
  資金利益 ■■■■■■■■  資金利益 ■■■■■     資金利益 ■■■■■■■■  ← 復活
  手数料   ■■           手数料   ■■■■■     手数料   ■■■■■■     ← 積み上げた分は残る
  その他   ■            その他   ■■          その他   ■■

  → 目指しているのは「利ざやが戻ったから手数料はいらない」ではなく、
    **両輪にして金利サイクルに左右されない収益構造を作る**こと
```

## 7. 株主還元と資本政策 ―― 「稼いだ資本をどう使うか」

銀行は利益を出すと自己資本（CET1）が厚くなる。資本が余れば規制上は健全だが、
分母ばかり増えて**ROEが下がる**。だから余剰資本は「貸出・投資に回す」か「株主に返す」かの二択になる。

| 使い道         | 具体例                                                                         |
| -------------- | ------------------------------------------------------------------------------ |
| 成長投資       | 海外銀行の買収・出資、RWAを使う貸出の積み増し、システム投資                    |
| 株主還元       | 増配（累進配当＝減配しない方針）、自己株式取得（買った株は消却することが多い） |
| 資本の質の改善 | 政策保有株式の売却（RWAが重く、価格変動リスクもあるため縮減が求められている）  |

2026年の実例（報道ベース）。

- みずほFG：2026年5月と7月に各1,000億円、**合計2,000億円を上限とする自己株式取得**を決議、取得株は消却予定。
  2026年度の年間配当予想は150円（6期連続増配）
- 三井住友FG：1,800億円規模の自己株式取得枠
- MUFG：完全実施ベースのCET1比率が目標レンジ（9.5〜10.5%）を下回る**9.2%**に低下したため、
  自己株買いは1,000億円にとどめ、利益の蓄積で資本水準を回復させる方針と報じられる

> ここが銀行の資本政策の面白いところ。**「資本が厚いから買い戻す／薄いから我慢する」**という
> 規制起点の意思決定になる。事業会社のように「手元キャッシュがあるから還元」とはならない。
> CET1と目標レンジの関係は [③ リスクと健全性](03_リスクと健全性.md) で詳しく扱う。

## 8. メガバンクの競争優位（KSF）はどこにあるか

| 優位の源泉               | 中身                                                                         | 真似しにくさ                               |
| ------------------------ | ---------------------------------------------------------------------------- | ------------------------------------------ |
| **低コストの預金基盤**   | 個人・法人の決済性預金。ほぼ無利息で巨額に集まる                             | ★★★ 口座と給与振込・決済の慣性が極めて強い |
| **信用力（格付け）**     | 自身が低コストで市場調達できる。外貨調達も可能                               | ★★★ 規模と国の信用に紐づく                 |
| **大企業との歴史的関係** | メインバンクとしての情報優位、役員派遣、政策保有株                           | ★★ 縮小方向だが残っている                  |
| **海外ネットワーク**     | 現地免許・現地行の買収済み基盤                                               | ★★★ 免許と時間が要る                       |
| **グループのフルライン** | 銀行・信託・証券・カード・リース                                             | ★★ 他グループも持つ                        |
| **規制対応力**           | バーゼル、マネロン対策、サイバー。**コストを払える規模があること自体が障壁** | ★★★ 規制コストが小さい銀行を淘汰する       |

参入障壁の裏返しとして、**免許（銀行業の免許は金融庁の認可制）**と**規制対応コスト**がある。
[ネット銀行](../04_ネット銀行/README.md)や事業会社系の銀行は参入できたが、
彼らが取ったのは主に個人の決済・住宅ローンであり、**大企業向け与信と海外という中核**には届いていない。

## 9. 弱点 ―― 何がメガの利益を壊しうるか

1. **預金の流出**：金利のある世界では、預金者が「金利の高いところ」へ動く。
   ネット銀行・証券口座（MRF）・国債へ資金が移ると、最も安い調達原資が細る
2. **決済の脱銀行化**：コード決済・送金アプリ・給与デジタル払い。
   決済データと接点を握られると、金融商品の販売機会も失う（→ [フィンテック・キャッシュレス](../../04_情報通信・IT・ネット/13_フィンテック・キャッシュレス/README.md)）
3. **海外の与信コスト**：新興国リテールと米国のレバレッジドローンは景気逆回転に弱い
4. **金利リスクの裏目**：金利上昇は利ざやにプラスだが、保有債券には含み損を生む（→ [③](03_リスクと健全性.md)）
5. **レガシーシステム**：勘定系の刷新は数千億円規模。止めると社会が止まるため、更新が難しい（→ [④](04_金利のある世界への転換.md)）

| **銀証ファイアウォール規制**     | 銀行と証券の間の非公開情報の共有制限。2022年に法人分野で大幅緩和                                  |
| **マルチフランチャイズ戦略**     | SMFGの海外戦略。重点国ごとに銀行・ノンバンク・決済を揃え、現地で「もう一つのグループ」を作る      |
| **シンジケートローン**           | 複数の銀行が協調して行う大型融資。取りまとめ役（アレンジャー）が組成手数料を得る                  |
| **ストラクチャードファイナンス** | プロジェクトや資産のキャッシュフローを裏付けにする融資。不動産・インフラ・船舶・航空機など        |
| **累進配当**                     | 減配せず、維持か増配のみとする配当方針                                                            |
| **自己株式取得（自社株買い）**   | 自社の株を市場から買い戻すこと。消却すれば株式数が減りEPS・ROEが上がる                            |
| **ROE**                          | 純利益 ÷ 自己資本。銀行の経営目標として最も重視される                                             |
| **持分法投資損益**               | 出資先（20〜50%程度保有）の利益のうち自社取り分。MUFGのモルガン・スタンレー出資が代表例           |
