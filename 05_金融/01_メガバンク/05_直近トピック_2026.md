# 直近トピック（2026年9月時点）

報道ベースの整理。数値は必ず一次情報（日銀・金融庁・各社IR）で裏取りすること。**このノートは「今どう
なっているか」だけを扱う**。仕組みの説明は [①](01_銀行のビジネスの基本.md)〜[④](04_金利のある世界への転換.md) にある。

> 2026年のメガバンクを一言でいえば、**「利上げの果実を受け取り終えた局面から、次の一手へ移る年」**。
> 過去最高益は出た。株主還元も過去最大になった。問題は**稼いだ資本を何に使うか（海外・デジタル通貨）**と、
> **上がった金利がいつ借り手の負担として跳ね返ってくるか**に移っている。

## 1. 日銀が政策金利1.25%へ ―― 利上げペースが加速

2026年9月18日までの金融政策決定会合で、日銀は政策金利（無担保コール翌日物）を**1.25%程度へ引き上げた**と
報じられる。6月会合（1.00%程度）以来3カ月ぶりで、2024年3月の解除以降では**最短の利上げ間隔**にあたる。

| 項目           | 内容                                                                        | 時点                 |
| -------------- | --------------------------------------------------------------------------- | -------------------- |
| 政策金利       | **1.25%程度**（1995年以来およそ31年ぶりの水準と報じられる）                 | 2026年9月18日        |
| 直前の水準     | 1.00%程度                                                                   | 2026年6月            |
| 引き上げの理由 | 原油高・円安による**物価の上振れリスク**の抑制                              | 日経・NHK報道        |
| 長期金利       | 30年債利回りが3%台に到達したと報じられる                                    | 2026年9月            |
| 先行き         | 年内にもう1回、2027年も複数回の見方があり、着地は2%前後との予想が報じられる | 各社エコノミスト予想 |

> 銀行への意味：利上げは**当座預金の付利 → 市場連動貸出 → 短プラ連動貸出**の順に時間差で効く（→ [④](04_金利のある世界への転換.md) 第4章）。
> つまり**2026年9月の利上げ分は2027年3月期以降に効く**。「利上げが止まってもしばらく増益が続く」構造である。

```
【なぜ増えたのか ―― 増益要因の分解（概念図）】

  前期の純利益
     ＋ **資金利益の増加**       ■■■■■■■■■■  ← 最大の要因。利ざや拡大（[④](04_金利のある世界への転換.md)）

     − 与信費用                 ▼             ← 低水準だが、フォワードルッキング引当は増
     − 経費（システム投資・人件費）▼▼
  ───────────────────────────────
  ＝ 過去最高益

   ※ **「政策保有株の売却益」は一過性**。本業の実力は資金利益と役務取引等利益で見る
     （→ [②](02_メガバンクの稼ぎ方.md) 第2章）
```

> 上がる**という二重の効果があるため、資本政策として合理的に進む。

3メガは**インドに合計1兆円超**を投じたと報じられる。2026年はその実行・統合の年になった。

| グループ     | 案件                                                                      | 規模・時期（報道ベース）                                                         |
| ------------ | ------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| **MUFG**     | インドのノンバンク大手**シュリラム・ファイナンス**へ出資（株式約20%取得） | 約44億ドル（約6,700〜6,800億円）。2025年12月契約、2026年3〜5月ごろ出資完了見込み |
| **SMFG**     | 民間銀行大手**イエス銀行**へ出資（25%弱、持分法適用会社化）               | 約2,800億円。**商業銀行そのものへの参入**                                        |

```
【3メガのインド攻略の「入り口」が違う】

  MUFG   ─▶ **ノンバンク**（中小企業・個人向け）

   共通のリスク：新興国リテールの与信コストと、現地規制・為替（→ [②](02_メガバンクの稼ぎ方.md) 第4章）
```

## 6. 金融庁「2026事務年度 金融行政方針」――監督の重心が動いた

金融庁は**2026年9月15日**に2026事務年度（2027年夏ごろまで）の金融行政方針を公表した。要点は3つ。

| 重点                                                             | 中身                                   | 背景                                                             |
| ---------------------------------------------------------------- | -------------------------------------- | ---------------------------------------------------------------- |
| **大手金融機関の海外事業の監視強化**                             | 海外拠点・出資先のリスク把握を深める   | 3メガの海外・インド投資の拡大（第5章）                           |
| **不動産業向け融資／超長期の住宅ローン／流動性リスクの重点点検** | 金利3%時代に耐えるか                   | 金利上昇で不動産価格・家計の返済余力・預金の粘着性が同時に揺らぐ |
| **地域金融機関への目配り**                                       | 地銀・信金を地域経済の「要」と位置づけ | 含み損と人口減の直撃（→ [地方銀行](../02_地方銀行/README.md)）   |

そのほか、保険販売の適切な業務運営、資産運用立国の推進、マネロン対策の高度化が柱として並ぶ。

> **監督の関心は「儲かっているか」ではなく「上がった金利の副作用がどこに出るか」**に移った。銀行の決算が
> 良いときほど、当局は次の局面を見ている。

## 7. 預金・住宅ローンの金利競争が本格化

| 商品                           | 2026年9月時点の水準 | 備考                                                                                       |
| ------------------------------ | ------------------- | ------------------------------------------------------------------------------------------ |
| メガの円普通預金               | **年0.4%**          | 2026年8月3日改定。1992年8月以来およそ34年ぶり水準（2026年2月に0.3%へ引き上げた後の再改定） |
| メガの定期預金1年もの          | **年0.5%程度**      | 3メガ横並び。ネット銀行はこれを上回る商品を提示                                            |
| メガの住宅ローン変動金利       | **1.25%程度**       | 短期プライムレート（2.125%程度）に連動                                                     |
| ネット銀行の住宅ローン変動金利 | 1.29%程度           | **メガ・地銀より高いという逆転現象**が報じられる（モゲチェック、2026年9月）                |

```
【住宅ローンの「逆転現象」はなぜ起きたか（報道からの整理）】

  かつて：ネット銀行 ＜ メガ・地銀     （店舗を持たない低コストで価格勝負）
  2026年：ネット銀行 ＞ 地銀 ・ メガ    （1.29% ＞ 1.25% ＞ 1.23%）

   考えられる要因
     ① ネット銀行は**調達側（預金金利）でも競争している**ため、貸出で薄利にしにくい
     ② メガは**低い預金ベータ**（→ [④](04_金利のある世界への転換.md) 第5章）で調達コストが上がりにくく、
        金利のある世界では**価格競争力が逆に強くなる**
     ③ 住宅ローンは取引の入口。メガは他商品とのクロスセルで採算を取れる

   → 金利のある世界では、**「安い預金を持っている側」が有利**という原理に戻る
```

## 8. 生成AI ―― 「効率化」から「実行」へ

2026年に入り、メガバンクの生成AI活用は実験段階を抜けたと報じられる。三井住友銀行の営業店向け
AIアシスタントは**2026年3月時点で約28,000名**が利用し、音声認識AIと大規模言語モデルによる
コールセンターでは人手の対応件数を**1日あたり約50%削減**したとされる。2026年の焦点は、照会応答に
とどまらず**手続きの実行まで担うエージェント型**の利用。いずれもベンダー・メディアの記事に基づく
数値であり、各社の公式開示での確認が要る。

## 9. 全体の構図

1. **増益は金利という「価格」が戻った結果**。10年削り続けた経費の上に利ざやが乗り、利益が増幅して出ている
2. その果実はまず**株主還元と政策保有株の削減**に回り、次に**海外（特にインド）とデジタル通貨**へ向かう
3. 一方、**金利上昇の副作用はこれから出る**。不動産融資の担保価値、変動金利の住宅ローン、有価証券の
   含み損、預金の粘着性。金融庁の2026事務年度方針はそこを狙って点検する
4. 競争軸は「貸出金利」から**「どれだけ安い預金を維持できるか（預金ベータ）」**へ移った。
   ステーブルコインもネット銀行も、突き詰めればこの調達基盤への挑戦である
5. 2027年以降の論点は、**利上げが止まったあとも利益を維持できるか**＝非金利収入と海外の持分利益が
   どこまで積み上がっているか

> 本ノートは学習用の整理であり、投資判断の材料ではない。個別銘柄・金融商品の売買の助言は含まない。

## 用語メモ

| 用語                         | 意味                                                                                                   |
| ---------------------------- | ------------------------------------------------------------------------------------------------------ |
| **信託型ステーブルコイン**   | 信託の仕組みで発行するデジタル通貨。裏付け資産が信託財産として分別管理され、発行体の倒産から隔離される |
| **共同委託者**               | 同一の信託契約に複数の委託者が並ぶ形態。3メガ共同発行スキームで採られるとされる                        |
| **持分法適用会社**           | 議決権のおおむね20〜50%を保有する出資先。利益の持分相当が連結損益に反映される（SMFGのイエス銀行など）  |
| **ノンバンク**               | 預金を受け入れず融資を行う金融会社。銀行免許が要らないため新興国では参入手段になる                     |
| **政策保有株**               | 取引関係維持のために持つ取引先株式。売却益が出るうえRWAも軽くなる（→ [③](03_リスクと健全性.md)）       |
| **株式分割**                 | 1株を複数株に分けること。株価が下がり少額から買いやすくなる（SMFGの1対2など）                          |
| **フォワードルッキング引当** | 将来シナリオを先取りして積む貸倒引当（→ [③](03_リスクと健全性.md) 第2章）                              |
| **短期プライムレート**       | 優良企業向け短期貸出の最優遇金利。住宅ローン変動金利の基準（→ [④](04_金利のある世界への転換.md)）      |
| **預金ベータ**               | 政策金利の上昇分のうち預金金利に転嫁された割合（→ [④](04_金利のある世界への転換.md) 第5章）            |
| **金融行政方針**             | 金融庁が事務年度ごとに公表する監督の重点方針。当局が何を見るかの予告編にあたる                         |
