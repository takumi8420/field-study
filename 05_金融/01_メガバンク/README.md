# メガバンク

- 大分類: 金融
- 状態: done
- 更新日: 2026-09-20

**一言でいうと**：家計と企業から集めた巨額の預金を、国内外の企業・個人に貸し、
その利ざやと手数料で稼ぐ装置。日本では再編を経て**3グループ（MUFG／SMFG／みずほFG）**に集約された。
2024年のマイナス金利解除で「金利のある世界」に戻り、2026年3月期は3社合計で純利益5兆円を超えた。

## 1. 業界の定義・範囲

「メガバンク」は制度上の業態区分ではない。実務では、**バブル崩壊後の再編で生き残った
3つの巨大金融グループ**（三菱UFJフィナンシャル・グループ、三井住友フィナンシャルグループ、
みずほフィナンシャルグループ）を指す。

隣接業態との境界は次のとおり。

| 区別する相手                                                                                                                     | 境界                                                                             |
| -------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| [地方銀行](../02_地方銀行/README.md)                                                                                             | 営業地盤が地域に限られ、海外拠点をほぼ持たない。収益は地元の預貸金利ざや頼み     |
| りそなホールディングス                                                                                                           | 都市銀行（りそな・埼玉りそな）を持つが海外拠点をほぼ持たず、通常メガには数えない |
| [信託銀行](../03_信託銀行/README.md)                                                                                             | 預貸ではなく信託報酬・受託資産で稼ぐ。3メガはグループ内に信託銀行を持つ          |
| [ネット銀行](../04_ネット銀行/README.md)                                                                                         | 店舗を持たず低コスト。個人の決済と住宅ローンが主戦場                             |
| [証券](../05_証券/README.md)・[リース](../10_リース/README.md)・[クレジットカード・決済](../11_クレジットカード・決済/README.md) | 免許が別なので子会社として保有する。銀行本体の業務ではない                       |
| [政府系金融](../15_政府系金融/README.md)                                                                                         | 政策目的の資金供給。民業補完であり利益最大化が目的ではない                       |

**含める範囲**：銀行本体（預金・貸出・為替＝決済）＋持株会社傘下の信託・証券・カード・リース・
資産運用まで。メガバンクの損益は**グループ連結でしか意味をなさない**ため。

## 2. 市場規模と成長性

| 指標                      | 数値                                  | 時点・出典                                            |
| ------------------------- | ------------------------------------- | ----------------------------------------------------- |
| 全国銀行（107行）の総預金 | **971兆8,836億円**（前年同月比+2.6%） | 2026年3月末、全国銀行協会 速報                        |
| 全国銀行の貸出金          | **636兆2,102億円**（+4.6%）           | 同上                                                  |
| 都市銀行5行の預金         | **495兆6,740億円**（+2.6%）           | 同上（みずほ・三菱UFJ・三井住友・りそな・埼玉りそな） |
| 都市銀行5行の貸出金       | **252兆3,331億円**（+4.9%）           | 同上                                                  |
| 3メガの連結純利益合計     | **5兆2,588億円**（前期比+33.9%）      | 2026年3月期、各社決算・報道ベース                     |

成長性の見方は独特で、**「市場が伸びるか」ではなく「金利水準がどこにあるか」**で決まる。

- 国内の預金・貸出残高は数%成長にとどまり、人口減で国内の資金需要は構造的に伸びにくい
- 一方、**政策金利が −0.1%（2016〜2024年）から1.25%（2026年9月）へ動いただけ**で、
  同じ残高から生まれる利益が数割増えた（→ [④](04_金利のある世界への転換.md)）
- したがって成長ドライバーは ①金利水準 ②海外資産の積み増し ③非金利収入（手数料）の3つ

## 3. バリューチェーン（資金の流れ）

銀行業のバリューチェーンは物ではなく**お金の流れ**である。

```
【メガバンクの資金の流れ：集める → 回す → 稼ぐ】

 ＜調達＞                    ＜運用＞                      ＜収益＞
  家計の預金 ─┐
  企業の預金 ─┼─▶ 銀行のBS ─┬─▶ 国内法人向け貸出 ──▶ 利ざや（薄い）
  市場調達   ─┘   （信用創造）├─▶ 住宅ローン ─────▶ 利ざや＋量
  （社債・CD）                ├─▶ **海外貸出** ─────▶ 利ざや（厚い）＋与信リスク
                              ├─▶ 有価証券（国債・外債）▶ 利息＋価格変動リスク
                              └─▶ 日銀当座預金 ─────▶ 付利（金利のある世界で復活）

  ＋ お金を動かさない収益（非金利収入）
      決済・為替 ／ 投信・保険の販売 ／ M&Aアドバイザリー ／ 信託報酬 ／ カード加盟店手数料

  付加価値が集まるのは
    ①**最も安い調達（決済性預金）を握っている者**
    ②**信用リスクを正しく値付けできる者**
    ③**グループで同じ顧客に何度も売れる者**（クロスセル）
```

詳細は [① 銀行のビジネスの基本](01_銀行のビジネスの基本.md) と
[② メガバンクの稼ぎ方](02_メガバンクの稼ぎ方.md)。

| グループ                | 2026年3月期 連結純利益     | 立ち位置               | 特徴                                                                                |
| ----------------------- | -------------------------- | ---------------------- | ----------------------------------------------------------------------------------- |

| **みずほ FG**           | **1兆2,486億円**（+41.0%） | 大企業取引・証券に強み | 旧興銀由来の法人基盤。楽天グループ提携でリテール補強。インドは投資銀行を買収        |

そのうち大半が3メガに集まる。「シェア」より**預金という原材料の集中度**で見るのが実態に近い。

## 5. 収益モデル・コスト構造

```
【業務粗利益 → 最終利益】

  業務粗利益 ＝ ①資金利益（利ざや） ＋ ②役務取引等利益（手数料） ＋ ③その他業務利益（市場）
     − 経費（人件費・物件費＝店舗とシステム。**ほぼ固定費**）
   ＝ 業務純益
     − **与信費用**（貸倒引当と損失。利益を最も大きく振らす）
     ± 株式等関係損益（政策保有株の売却益など＝一過性）
   ＝ 純利益
```

| 指標              | 意味                | 目安                                                               |
| ----------------- | ------------------- | ------------------------------------------------------------------ |
| **OHR（経費率）** | 経費 ÷ 業務粗利益   | 日本のメガで50〜60%台。低いほど効率的                              |
| **与信費用率**    | 与信費用 ÷ 貸出残高 | 平時は年0.1〜0.3%程度、危機時は1%超へ                              |
| **不良債権比率**  | 開示債権 ÷ 総与信   | 103行平均**1.07%**（2026年3月期、東京商工リサーチ）                |
| **ROE**           | 純利益 ÷ 自己資本   | 長く5%前後だったが、MUFGは11.3%（東証定義）に到達と報じられる      |
| **CET1比率**      | 中核資本 ÷ RWA      | MUFGは目標レンジ9.5〜10.5%に対し9.2%（完全実施ベース、報道ベース） |

コスト構造の要点は**固定費の塊であること**。貸出が増えても費用は比例しないため、
粗利が戻った局面では利益が増幅して出る（オペレーティングレバレッジ）。
逆に粗利が潰れた10年間は、**店舗・人員を削る以外に利益を作る手がなかった**（→ [④](04_金利のある世界への転換.md)）。

## 6. 競争要因（KSF）と参入障壁

| 優位の源泉               | 中身                                                                         | 真似しにくさ   |
| ------------------------ | ---------------------------------------------------------------------------- | -------------- |
| **低コストの預金基盤**   | 決済性預金がほぼ無利息で巨額に集まる。**利上げ局面でこれが最強の武器になる** | ★★★            |
| **信用力（格付け）**     | 自身が低コストで円・外貨を調達できる                                         | ★★★            |
| **海外ネットワーク**     | 現地免許・買収済みの現地行。時間で買えない                                   | ★★★            |
| **規制対応力**           | バーゼル、マネロン、サイバー。**コストを払える規模自体が障壁**               | ★★★            |
| **大企業との歴史的関係** | メインバンクとしての情報優位                                                 | ★★（縮小方向） |
| **グループのフルライン** | 銀行・信託・証券・カード・リース                                             | ★★             |

参入障壁は**銀行業の免許（金融庁の認可制）**と**規制対応コスト**。
[ネット銀行](../04_ネット銀行/README.md)や事業会社系銀行は参入できたが、彼らが取ったのは
主に個人の決済と住宅ローンであり、**大企業向け与信と海外という中核**には届いていない。

## 7. 規制・法制度

| 制度                              | 中身                                                           | メガへの効き方                                                          |
| --------------------------------- | -------------------------------------------------------------- | ----------------------------------------------------------------------- |
| **銀行法**                        | 免許制、業務範囲規制、他業禁止、5%ルール（他社株式の保有制限） | 業態別に子会社を持つグループ構造の根拠                                  |
| **バーゼルIII／自己資本比率規制** | 国際統一基準行は総自己資本8%以上＋バッファ                     | 資本フロアは2026年70%→2027年72.5%（金融庁、段階導入）                   |
| **G-SIBs規制**                    | 世界的にシステム上重要な銀行への資本上乗せ                     | **3メガとも指定**。TLAC（損失吸収可能な負債の保有）も適用               |
| **流動性規制（LCR／NSFR）**       | 30日ストレス下の現金確保、長期資産の安定調達                   | 2023年のSVB破綻以降、監督の関心が高い                                   |
| **預金保険**                      | 1金融機関あたり元本1,000万円と利息を保護                       | 預金者がリスクを負わない前提を支える                                    |
| **AML/CFT**                       | マネロン・テロ資金供与対策。FATFの国際基準                     | 最大級の規制コスト項目。海外当局の制裁金リスク                          |
| **銀証ファイアウォール規制**      | 銀行・証券間の非公開情報共有の制限                             | 2022年に法人分野で大幅緩和                                              |
| **企業価値担保権**                | 事業全体を担保にする新制度（2024年施行）                       | 不動産担保一辺倒からの転換                                              |
| **金融行政方針**                  | 金融庁が事務年度ごとに公表する監督の重点                       | 2026事務年度（2026年9月15日公表）は海外事業監視・不動産融資・流動性が柱 |

## 8. 最近のトピック

詳細は [⑤ 直近トピック（2026年9月時点）](05_直近トピック_2026.md)。要点は5つ。

1. **日銀が政策金利を1.25%程度へ**（2026年9月18日、報道ベース）。30年国債利回りは3%台に到達
2. **3メガの2026年3月期純利益は合計5兆2,588億円**（+33.9%、3社とも3期連続で最高益）。主因は利ざや拡大
3. **株主還元が過去最大**。年間配当は3社合計2兆円規模へ。政策保有株は2029年3月末までに1兆円超を削減する方針
4. **3メガが信託型ステーブルコインを共同発行**することで合意。2026年度中の実取引開始を目指すと報じられる
5. **金融庁2026事務年度金融行政方針**（2026年9月15日）は、大手の海外事業監視、不動産業向け融資・
   超長期住宅ローン・流動性リスクの点検を柱に据えた
