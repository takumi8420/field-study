# ④ 直近トピック（2026年9月時点）

報道・公表資料ベースの整理。数値は公表時点のものであり、最新は各一次情報で確認すること。
特定のファンドや商品を推奨する意図はなく、**産業構造がどう動いているか**を追う。

> **この時点の要約**：新NISA3年目に入り、家計の資金流入は続いている。
> 公募投信の残高は**2026年8月末で364兆円**と過去最高圏にあるが、
> 増えた分の多くは**株高による時価上昇**である。
> 政策は「家計に投資させる」段階から「**受け皿の質を上げる**」段階に移り、
> 2026年は**業界団体の統合（4月）**と**金融戦略の改訂（7月）**という2つの節目があった。

## 1. NISAの残高動向 ── 金額目標は達成、残る課題は「口座数」と「未稼働」

新NISAは2024年1月に始まり、2026年で3年目に入った。まず数字を押さえる。

| 時点                     | NISA口座数        | 累計買付額   | 備考                                                   |
| ------------------------ | ----------------- | ------------ | ------------------------------------------------------ |
| 2023年12月末             | 1,801万口座       | 約35兆円     | 旧NISA（一般・つみたて・ジュニア）                     |
| 2024年12月末             | 2,559万口座       | 約53兆円     | 新NISA開始1年目                                        |
| 2025年 6月末             | 2,696万口座       | 約63兆円     | 金融庁、2025年9月公表                                  |
| **2025年12月末**         | **約2,826万口座** | **約71兆円** | 前年比 口座数+10%、買付額+36%（金融庁、2026年7月確報） |
| 政府目標（2027年12月末） | 3,400万口座       | 56兆円       | **金額目標は2025年3月末時点で前倒し達成**              |

（出典：金融庁「NISA口座の利用状況に関する調査結果」各回。2025年12月末は速報値2,821万口座から確報で上方修正）

```
【NISAの目標達成状況 ── 金額は超過、口座数は8割】

  累計買付額   目標 56兆円  ████████████████████ 100%
               実績 71兆円  ██████████████████████████ 127%  ← 達成済み

  口座数       目標 3,400万 ████████████████████ 100%
               実績 2,826万 ████████████████ 83%             ← 2025年12月末

  ＝ お金は入った。だが「投資している人の数」はまだ届いていない。
    しかも口座を開いただけで買付額がゼロの「未稼働口座」が相当数ある。
```

**未稼働口座**（口座はあるが買付額ゼロ）の存在は、政策上の重要論点になっている。
金融機関がキャンペーンで口座開設だけを進めた結果、
**口座数の増加が実際の資産形成につながっていない**部分がある、という指摘である
（大和アセットマネジメント「投資信託白書2026」第3章、金融庁公表データを分析）。

### 2026年度税制改正で決まったこと・見送られたこと

| 項目                                                   | 結果       | 中身                                                         |
| ------------------------------------------------------ | ---------- | ------------------------------------------------------------ |
| **プラチナNISA**（65歳以上向け別枠、毎月分配型の解禁） | **見送り** | 金融庁が2025年8月に要望。自民党議連も提言したが大綱に入らず  |
| つみたて投資枠への**債券中心の投資信託**追加           | 決定       | 株式以外の選択肢を広げる                                     |
| **定期売却サービス**の手数料徴収容認                   | 決定       | 資産を取り崩す局面（デキュムレーション）の支援               |
| **こどもNISA**（未成年向け）                           | 検討段階   | 2026年度税制改正大綱に向けて政府・与党が検討したと報じられる |

（出典：金融庁「令和8年度税制改正について」2025年12月、および報道）

> ポイント：政策の関心が**「積み立てる人」から「取り崩す人」へ広がった**。
> 高齢者が資産を使いながら運用を続ける局面（毎月分配型・定期売却）をどう制度化するかが、
> 2025〜2026年の最大の論点になった。ただしプラチナNISAは、
> **毎月分配型が元本を取り崩して分配する可能性がある**という懸念もあり、決着していない。

## 2. 公募投信の残高は過去最高圏 ── ただし中身は「時価上昇」

| 時点        | 公募投信の純資産総額 | 動き                      |
| ----------- | -------------------- | ------------------------- |
| 2026年2月末 | 329兆8,023億円       | 9カ月連続で過去最高更新   |
| 2026年5月末 | 334兆円前後          | 過去最高を更新            |
| 2026年7月末 | 352〜360兆円台       | 連続で過去最高を更新      |
| 2026年8月末 | **364兆2,855億円**   | 5,840本。ETF135兆円を含む |

（出典：資産運用業協会「数字で見る投資信託」各月。月次の動きはFinasee等の集計報道）

資金の流れも続いている。公募投信は**22年連続の純資金流入**（2004〜2025年）で、
2025年の年間純資金流入額は**15兆5,004億円**。
ETFを除く株式投信は**36カ月（3年）連続の流入超**となった。

流入先は明確に偏っている。2026年8月の月間純流入額では
**全世界株式インデックス型（通称「オルカン」）に約3,961億円**が入り、
米国株指数連動型を上回った。7月時点では全世界株式型が米国株指数型の約2倍の流入で、
全世界株式型の保有者数は2026年6月末で**約686万人**（2023年12月末の約255万人から約2.7倍）と報じられる。

```
【残高が増えた理由の分解（考え方）】

   公募投信の残高増  ＝  資金流入（新しく入ったお金）
                      ＋  時価変動（持っている資産の値上がり）

   2026年の局面：
     資金流入   ██████         年15兆円規模で継続（実需）
     時価変動   ████████████   株高により大きく寄与

   ＝ 残高が過去最高でも、それは「相場が上がった」結果でもある。
     相場が下げれば残高は簡単に減る。
     業界の実力は残高ではなく、フロー（純資金流入）の継続性で見る。
```

> ポイント：**インデックス型が株式投信の65.1%**（2026年8月末）。
> 日本の個人マネーも、すでに指数連動が主役である。
> 運用会社から見れば「残高は増えるが手数料率は下がる」局面が続いている
> → [① 運用会社のビジネスモデル](01_運用会社のビジネスモデル.md)

## 3. 政策：「資産運用立国のアップグレード」（2026年7月）

2026年7月21日、内閣官房（日本成長戦略本部事務局）が
**「成長投資を促進するための金融戦略 ── 資産運用立国のアップグレード ──」** を公表した。
2023年12月の「資産運用立国実現プラン」の後継にあたる政府方針である。

| 柱                                        | 資産運用業に直接効く部分                                                     |
| ----------------------------------------- | ---------------------------------------------------------------------------- |
| ①金融機関・市場の機能強化                 | 17の戦略分野への成長資金供給、厚みのある金融市場、地域金融力の強化           |
| ②企業の成長投資促進のためのガバナンス改革 | 投資先企業側の資本効率改善                                                   |
| **③国民が成長の成果を享受する環境整備**   | **アセットオーナーの機能向上／資産運用サービスの高度化／家計の資産形成促進** |
| ④金融システムを支えるインフラ投資         | AI時代を見据えたオンチェーン金融、金融システムへの信頼確保                   |

同じ時期（2026年7月24日）に金融庁が
**「資産運用サービスの高度化に向けたプログレスレポート2026」** を公表。
大手運用会社のAUM・収益構造・顧客別の手数料率を分析したもので、
本フォルダの数値の多くはここを出典としている。

主な指摘として、
**アセットオーナー・プリンシプルの受入れ表明は2026年6月末で369主体**に達した一方、
**iDeCoの加入者は約400万人とNISA口座数（2,820万口座）の7分の1以下**にとどまり、
DC（確定拠出年金）の多段構造とコストの見直しが課題として挙げられている
→ [② 誰のお金を運用しているか](02_誰のお金を運用しているか.md)

> ポイント：「アップグレード」の要点は、**家計向け施策から供給側（運用業・アセットオーナー）の
> 質の向上へ重心を移したこと**にある。NISAの枠は広げ切ったので、次は中身、という順番である。

## 4. 業界団体の統合 ── 資産運用業協会が発足（2026年4月1日）

**投資信託協会**と**日本投資顧問業協会**が合併し、
2026年4月1日に **一般社団法人 資産運用業協会** が発足した。

| 項目               | 内容                                                                            |
| ------------------ | ------------------------------------------------------------------------------- |
| 発足日             | 2026年4月1日                                                                    |
| 会員数             | 正会員941社、賛助会員23社（発足時）                                             |
| 会員の区分         | 投資運用会員（投資運用業者・信託業者等）／投資助言・代理会員（投資助言、IFA等） |
| カバーする運用資産 | 約1,000兆円規模と報じられる                                                     |

これまで日本では、**投資信託は投信協会、投資一任（年金向け）は投資顧問業協会**と
自主規制団体が分かれていた。同じ運用会社が両方に加入し、
似た報告を二重に出す非効率があった。統合の狙いは、
政策対応能力の向上と、海外の業界団体との連携強化にある。

```
【業界団体の統合が意味すること】

   〜2026年3月                        2026年4月〜

   投資信託協会                       ┌──────────────┐
     └ 投信（個人向け中心）    ──▶  │  資産運用業協会  │
   日本投資顧問業協会                 │  正会員941社     │
     └ 投資一任（年金向け）    ──▶  │  約1,000兆円     │
   （運用会社は両方に加入）           └──────────────┘

   ＝ 制度・統計・海外対応の窓口が一本化された。
     政策側（金融庁）から見ても、対話相手が1つになる。
```

## 5. スチュワードシップ改訂の実務反映と、議決権行使基準の厳格化

2025年6月26日に**日本版スチュワードシップ・コードが5年ぶりに改訂**された。
主な狙いは、**協働エンゲージメント（複数の運用会社が共同で企業と対話すること）の推進**、
投資先企業への株式保有状況の説明、そしてコードの**スリム化・プリンシプル化**である。

2026年に入り、各運用会社は改訂を自社の実務に落とし込む段階に入った。

- 国内上場株の**議決権行使基準の見直し**（2025年11月28日付など）を公表する会社が相次いだ
- **議決権行使の考え方**の改訂（2026年2月27日付など）も公表されている
- 多くの機関投資家が改訂コードへの対応を表明済み

背景には、パッシブ運用の比率上昇がある。売却という手段を持たない株主が増えるほど、
議決権行使と対話の質が企業統治の生命線になる
→ [③ 日本の資産運用業の課題と政策](03_日本の資産運用業の課題と政策.md)

> ポイント：基準の厳格化は「反対票を増やす」こと自体が目的ではない。
> **なぜ賛成・反対したかを説明できるようにする**方向に実務が動いている、と読むのが正確。

## 6. 再編とプライベートアセットへの傾斜

運用会社の組織再編も続いている。代表例として、
**ゆうちょ銀行が投資子会社を再編し、新たな資産運用子会社を設立する方針**を
2026年1月に示したと報じられる。投信運用会社と機関投資家向け運用会社を統合し、
PE（プライベート・エクイティ）や不動産の投資機能を集約する内容で、
狙いは手数料収益の拡大にある。

こうした動きの背景は共通している。

| 動機                               | 中身                                                                     |
| ---------------------------------- | ------------------------------------------------------------------------ |
| **手数料率の低下**                 | インデックス競争で伝統資産の収益性が落ちた                               |
| **プライベートアセットの高収益性** | PE・プライベートデット・インフラは手数料率が高く、値下げ競争が効きにくい |
| **規模の経済**                     | 統合でAUMを積み上げれば固定費を分散できる                                |
| **個人への開放**                   | 個人が非上場資産に投資できる「クロスオーバー型」商品の検討が進む         |

一方でプライベート市場側にも調整局面がある。世界のPE業界では、
ファンドが長期保有したまま売却できない投資先が積み上がっており、
競争激化と信用面の懸念から**業界の淘汰が進むとの見方**も報じられている。
プライベートアセットは**換金しにくい（流動性が低い）**という性格があり、
個人向けに広げる際にはこの点の説明が課題になる。

## 7. 全体の構図（まとめ）

```
【2026年9月時点の見取り図】

  家計  ──── NISA3年目。お金は入り続けている（22年連続の純流入）
   │         だが残高増の多くは株高。口座数目標は未達、未稼働口座も残る
   ▼
  販売  ──── ネット証券が主戦場。低コストのインデックス型に資金が集中
   │         銀行窓販のシェアは後退（公募株式投信で19.3%）
   ▼
  運用  ──── 残高は増えるが手数料率は下がる。収益源をオルタナティブへ移す
   │         系列構造・運用力・人材が積年の課題。業界団体は2026年4月に統合
   ▼
  企業  ──── パッシブ化で「売れない株主」が増え、対話と議決権の質が問われる
             スチュワードシップ・コードは2025年6月に5年ぶり改訂
   ▲
  政策  ──── 2026年7月「資産運用立国のアップグレード」。
             家計向け施策から供給側の質の向上へ重心が移った
```

要するに、**2026年は「量は達成、質はこれから」の年**である。
NISAの金額目標は前倒しで達成された一方、口座数と未稼働口座という宿題が残り、
運用会社側は手数料低下を前提に収益構造を作り替えている最中にある。
政策の関心も、非課税枠の拡大からアセットオーナーと運用会社の能力向上へ移った。
2027年に向けては、**NISA口座数3,400万という目標に届くか**、
**プライベートアセットの個人開放をどう設計するか**、
**協働エンゲージメントが実例として定着するか**の3点が焦点になる。

## 用語メモ

| 用語                           | 意味                                                                                     |
| ------------------------------ | ---------------------------------------------------------------------------------------- |
| **未稼働口座**                 | NISA口座を開設したものの買付額がゼロの口座。口座数目標と実態の乖離を生む                 |
| **プラチナNISA**               | 65歳以上を対象に毎月分配型などを解禁する構想。2026年度税制改正では見送られた             |
| **こどもNISA**                 | 未成年を対象とした非課税制度の構想。2026年時点で検討段階                                 |
| **定期売却サービス**           | 保有する投信を毎月など定期的に一定額・一定率で売却する仕組み。取り崩し局面を支える       |
| **デキュムレーション**         | 資産を積み上げる局面（アキュムレーション）の反対。取り崩して使う局面                     |
| **純資金流入（ネットフロー）** | 資金流入から流出を引いた額。相場変動の影響を除いた実需を示す                             |
| **プライベートアセット**       | 非上場の資産全般。PE、プライベートデット、不動産、インフラなど。流動性が低い             |
| **クロスオーバー投信**         | 上場資産と非上場資産を組み合わせ、個人でもプライベートアセットに投資できるようにした商品 |
| **協働エンゲージメント**       | 複数の運用会社が共同で投資先企業と対話すること。2025年のコード改訂で推進された           |
| **資産運用業協会**             | 投資信託協会と日本投資顧問業協会が統合し、2026年4月1日に発足した業界団体                 |
