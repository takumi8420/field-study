# 資産運用

- 大分類: 金融
- 状態: done
- 更新日: 2026-09-20

**一言でいうと**：他人のお金を預かって増やす仕事。売上は
**AUM（預かり資産残高）× 手数料率**という1本の式でほぼ決まり、
コストは固定費なので**規模がそのまま利益になる**業界。
お金の保管も販売も他社がやるため、運用会社が売っているのは「判断と指図」だけである。

> このフォルダは投資判断の材料ではなく、**産業構造の説明**である。
> 特定の運用会社・ファンド・商品を推奨する意図はない。

## 1. 業界の定義・範囲

**資産運用業（アセットマネジメント）** とは、顧客から資金を預かり、
**運用の判断と売買の指図を行う**ことを業とする産業を指す。
金融商品取引法上は**投資運用業**（投資信託委託業＋投資一任業）が中核にあたる。

隣接業界との境界は、**「誰のバランスシートにお金が載るか」** で切ると分かりやすい。

| 業界                                 | お金の置き場所                       | 収益源                                       |
| ------------------------------------ | ------------------------------------ | -------------------------------------------- |
| **資産運用**（本フォルダ）           | **顧客のもの。自社のBSに載せない**   | 残高に対する手数料（信託報酬・投資一任報酬） |
| [銀行](../01_メガバンク/README.md)   | 自社のBSに預金として載る             | 利ざや（貸出金利−預金金利）                  |
| [証券](../05_証券/README.md)         | 顧客資産を預かるが運用はしない       | 売買委託手数料、販売手数料、引受             |
| [信託銀行](../03_信託銀行/README.md) | 信託財産として分別管理（保管・計理） | 信託報酬のうち受託者部分                     |
| [生命保険](../07_生命保険/README.md) | 一般勘定として自社のBSに載る         | 保険料と支払いの差、運用収益                 |

隣接して見えるが**別物**なのは次の3つ。
**投資助言業**（助言だけで運用はしない）、**販売会社**（売るだけで運用しない）、
**ヘッジファンド／PEファンド**（運用するが私募中心で規制の枠が違う）。

成長の性格は2つに分けて見る必要がある。
**①資金流入（実需）**は年15兆円規模で安定して続く一方、
**②時価変動（相場）**の寄与が大きく、残高の過去最高更新は株高の結果でもある。
金融庁の調査では、日系大手11社の国内機関投資家向けAUM増加分(2022→2025年、+55兆円)のうち
**資金流入は+9兆円、時価変動等が+45兆円**だった（プログレスレポート2026）。

## 3. バリューチェーン（川上 → 川下）

```
【資金の流れと、各段の取り分】

  家計・企業 ──▶ アセットオーナー ──▶ 運用会社 ──▶ 受託銀行 ──▶ 市場
   (資金の源)     GPIF/企業年金/保険     判断と指図     保管・計理     株式/債券/不動産
                       │                   ▲
                       │                   │ 商品供給
                       │            ┌──────┴──────┐
   個人 ──────────────┴───────▶│   販売会社     │
                                     │ 証券・銀行・ネット証券 │
                                     └───────────────┘

  取り分（バランス型アクティブ投信の例、信託報酬 年1.5%のうち）
    販売会社 約0.70%  ＞  運用会社 約0.73%  ≫  受託銀行 約0.07%
  ＝ 付加価値は「顧客との接点（販売）」と「運用の判断」に集まる。保管は薄利。
```

低コストのインデックス型では全体が年0.05〜0.10%程度まで下がるが、
**3者で分ける構造は変わらない**。だから残高が桁違いに大きくないと誰も食べていけない
→ 詳細は [①](01_運用会社のビジネスモデル.md)

## 5. 収益モデル・コスト構造

- **売上＝AUM × 手数料率**。他の収入はほぼない
- **コストはほぼ全部が固定費**（人件費・システム・データ/指数ライセンス）
- したがって**損益分岐点を超えた後の増収はほぼ丸ごと利益**。大手の営業利益率は30〜40%程度が目安
- 手数料率は顧客と商品で10倍以上違う：公的年金 **年0.02%** ／ 企業年金 **年0.27%** ／
  金融法人等 **年0.12%**（金融庁調査、2025年3月期）／ 個人向け投信は年0.05〜1.5%
- **AUMと収益はねじれる**。大手20社の国内機関投資家向けでは、パッシブが残高の6割を占めるのに
  収益ではアクティブが約7割。オルタナティブは残高7%で収益の26%

## 6. 競争要因（KSF）と参入障壁

| KSF                        | 中身                                                               |
| -------------------------- | ------------------------------------------------------------------ |
| **規模（AUM）**            | 固定費型なので規模が利益率を決める。値下げ余力にも直結             |
| **販売チャネル**           | 個人向けは「販売会社の棚に載るか」が全て。日本では系列が効いてきた |
| **運用実績の再現性**       | 機関投資家向けでは5年以上の実績と「なぜ勝てたかの説明」が要る      |
| **人材**                   | アクティブ・オルタナは人的資本産業。担当者が抜ければ商品が死ぬ     |
| **オルタナティブの組成力** | 値下げ競争が効かない唯一の高収益領域。案件獲得力が参入障壁になる   |

参入障壁は**資本ではなく規模と信用**。投資運用業の登録に必要な資本金は原則5,000万円で、
元手の壁は低い。しかし**損益分岐点に達する残高を集められるか**が実質的な壁になる。

## 7. 規制・法制度

| 制度                                           | 内容                                                                                       |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------ |
| **金融商品取引法**                             | 投資運用業（投資信託委託業・投資一任業）の登録制。分別管理、忠実義務・善管注意義務         |
| **投資信託及び投資法人に関する法律（投信法）** | 投信の仕組み（委託者・受託者・受益者）を定める                                             |
| **金融サービス提供法**                         | 2024年11月施行の**最善利益義務**（顧客等の最善の利益を勘案して誠実公正に業務を行う義務）   |
| **顧客本位の業務運営に関する原則**             | 2017年策定、2024年9月改訂で**プロダクトガバナンス**を追加。ソフトロー                      |
| **スチュワードシップ・コード**                 | 2014年策定、2025年6月に5年ぶり改訂。運用会社の株主としての責任                             |
| **アセットオーナー・プリンシプル**             | 2024年8月策定。2026年6月末で369主体が受入れを表明                                          |
| **NISA・iDeCo（税制）**                        | 非課税制度。2026年度税制改正ではつみたて投資枠への債券型追加等が決定、プラチナNISAは見送り |
| **参入促進策**                                 | 海外投資家等特例業務（2021年11月施行）、拠点開設サポートオフィス、金融・資産運用特区       |

政府方針は**「資産運用立国」**の系譜で理解する。
2023年12月「資産運用立国実現プラン」→ 2026年7月
「成長投資を促進するための金融戦略（＝資産運用立国のアップグレード）」
→ 詳細は [③](03_日本の資産運用業の課題と政策.md)

## 8. 最近のトピック

詳細は [④ 直近トピック（2026年9月時点）](04_直近トピック_2026.md)。要点は5つ。

1. **NISAは金額目標を前倒し達成**（2025年12月末で累計買付額71兆円、目標56兆円）。
   一方で口座数は2,826万と目標3,400万の8割にとどまり、**未稼働口座**が課題として残る
2. **公募投信は364兆円と過去最高圏**（2026年8月末）。全世界株式インデックス型への流入が突出し、
   インデックス型が株式投信の65.1%を占める。ただし残高増の多くは株高の寄与
3. **政策の重心が供給側へ**。2026年7月「成長投資を促進するための金融戦略」で
   アセットオーナー機能の向上・資産運用サービスの高度化が柱に据えられた
4. **業界団体が統合**。投資信託協会と日本投資顧問業協会が合併し、
   2026年4月1日に**資産運用業協会**が発足（正会員941社）
5. **収益源はプライベートアセットへ**。手数料低下を受け、PE・不動産・インフラの強化と
   運用子会社の再編が続く。個人向けクロスオーバー商品の設計が論点
