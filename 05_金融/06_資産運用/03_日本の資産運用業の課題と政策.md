# ③ 日本の資産運用業の課題と政策 ── 系列・運用力・スチュワードシップ

このノートで分かること：**なぜ日本の運用業界は「政策の対象」になっているのか**。
系列（親会社が銀行・証券）という日本固有の構造が何を生み、
政府がそれをどう変えようとしているか。そして、運用会社が
株主として企業に物を言う「スチュワードシップ」の仕組みと、その限界。

> **結論を先に**：日本の大手運用会社はほぼ全社が**金融グループの子会社**である。
> 親が銀行・証券（＝販売会社）であるため、**「売る側の都合」が商品に影響しやすい**。
> 政府はこれを2023年以降「資産運用立国」という旗のもとで是正しようとしており、
> 論点は3つ ──**①系列の利益相反、②運用力そのもの、③株主としての責任（スチュワードシップ）**。
> このノートはこの3つを順に扱う。

---

## 1. 政策の系譜 ── 「貯蓄から投資へ」から「資産運用立国」へ

日本の資産運用に関する政策は、2022年以降に一気に密度が上がった。
それまでの「貯蓄から投資へ」が家計向けの掛け声だったのに対し、
2023年以降は**運用会社そのものを改革対象にした**点が新しい。

```
【資産運用まわりの政策の流れ】

  2014年 2月  日本版スチュワードシップ・コード策定     ← 運用会社の責任を定義
  2015年 6月  コーポレートガバナンス・コード適用開始   ← 企業側の責任を定義
  2017年 3月  顧客本位の業務運営に関する原則（FD原則） ← 販売会社の責任を定義
        │
        │  ＝ ここまでは「原則（プリンシプル）を示して自主的にやらせる」段階
        ▼
  2022年11月  資産所得倍増プラン                       ← NISA拡充の原型
  2023年12月  資産運用立国実現プラン                   ← 運用業界そのものを改革対象に
  2024年 1月  新NISA開始
  2024年 8月  アセットオーナー・プリンシプル           ← お金の出し手にも規律を
  2024年 9月  FD原則を改訂（プロダクトガバナンス追加） ← 商品の作り手の責任を明文化
  2024年11月  最善利益義務が法律上の義務に             ← 原則から「義務」へ格上げ
  2025年 6月  スチュワードシップ・コード改訂（5年ぶり）
  2026年 4月  資産運用業協会が発足（業界団体の統合）
  2026年 7月  成長投資を促進するための金融戦略
              ＝「資産運用立国のアップグレード」
```

2026年7月21日に内閣官房（日本成長戦略本部事務局）が出した最新の戦略は、
柱立てが4つある（金融庁「成長投資を促進するための金融戦略」ページ、2026年）。

| 柱                                        | 主な中身                                                                 |
| ----------------------------------------- | ------------------------------------------------------------------------ |
| ①金融機関・市場の機能強化                 | 17の戦略分野への成長資金供給、銀行の資金供給機能、地域金融力             |
| ②企業の成長投資促進のためのガバナンス改革 | 企業側の資本効率・投資行動を促す                                         |
| ③国民が成長の成果を享受する環境整備       | **アセットオーナーの機能向上／資産運用サービスの高度化／家計の資産形成** |
| ④金融システムを支えるインフラ投資         | AI時代を見据えたオンチェーン金融、金融システムへの信頼確保               |

> ポイント：政策の重心が**「家計に投資させる」から「受け皿の質を上げる」へ移った**。
> 非課税枠を広げても、受け取る側の運用業界が弱ければお金は増えない、という認識である。

## 2. 系列構造 ── 日本の運用会社は「グループの一部門」

日本の大手運用会社は、独立した会社としてではなく、
**銀行・証券・保険グループの子会社**として作られてきた。

```
【日本型の系列構造 ── 親が売り、子が作る】

        ┌──────────────────────────────┐
        │      金融グループ（持株会社）          │
        └───┬──────────┬──────────┬──┘
            │            │            │
        ┌──▼──┐    ┌──▼──┐    ┌──▼───────┐
        │ 銀行  │    │ 証券  │    │ 運用会社      │
        │(販売) │    │(販売) │    │（商品の作り手）│
        └──┬──┘    └──┬──┘    └──┬───────┘
           │             │             │
           └─────┬─────┘             │ 商品（投信）を供給
                   │                     │
                   ◀─────────────────┘
                   │
              ┌───▼────┐
              │  個人顧客  │
              └───────┘

  ＝ 商品を作る会社と売る会社が同じグループ。
    グループ全体の収益を最大化しようとすると、
    「顧客に一番良い商品」より「グループが儲かる商品」に寄る誘因が生まれる。
```

この構造そのものは違法でもなんでもない。問題は**誘因（インセンティブ）の向き**にある。
金融庁が繰り返し指摘してきた利益相反は、大きく3つの型に整理できる。

| 利益相反の型                      | 何が起きるか                                                                 | 誰が損をするか                       |
| --------------------------------- | ---------------------------------------------------------------------------- | ------------------------------------ |
| **①棚（商品ラインナップ）の偏り** | 販売会社が系列運用会社の商品を優先的に並べる。他社の優れた商品が棚に載らない | 顧客（選択肢が狭まる）               |
| **②手数料設計の歪み**             | 信託報酬のうち販売会社の取り分を厚くした商品が作られやすい                   | 顧客（コストが高くなる）             |
| **③運用会社の従属**               | 子会社である運用会社が、親の販売方針に「ノー」と言いにくい                   | 顧客（不利な商品が組成・維持される） |

構造的な背景として、銀行はグループ証券への**仲介・紹介販売**に大きく依存してきた。
金融庁のモニタリングでは、グループ内に証券会社を持つ銀行のチャネル別販売動向は
**主要行等で57%、地域銀行で36%**が証券への仲介・紹介経由だった
（金融庁「投資信託等の販売会社による顧客本位の業務運営のモニタリング結果」2022年6月公表）。

> ポイント：**日本の投信は長く「作る競争」ではなく「棚を取る競争」だった**。
> 系列という近道があるので、運用の腕を磨かなくても残高が積み上がる。
> これが次節の「運用力が伸びない」問題に直結している。

### 制度側の答え ── 3段階で締め上げてきた

| 年         | 打ち手                                       | 性格                                                         |
| ---------- | -------------------------------------------- | ------------------------------------------------------------ |
| 2017年     | 顧客本位の業務運営に関する原則（FD原則）     | 任意。採択と自己評価を公表させる                             |
| 2024年9月  | 同原則を改訂し**プロダクトガバナンス**を追加 | 商品の**作り手**に、想定顧客の明確化・商品の継続検証を求める |
| 2024年11月 | **顧客等の最善の利益を勘案する義務**が法定   | 原則から**法律上の義務**へ。金融サービス提供法               |

**プロダクトガバナンス**とは、噛み砕けば「商品を出して終わりにするな」という考え方である。
誰向けの商品かをあらかじめ定め、コストに見合う価値があるかを定期的に検証し、
販売会社とも情報をやり取りして、想定と違う売られ方をしていないか確認する。
売り手側の規律だけでは不十分で、**作り手側の規律**が要る、という発想の転換だった。

大手金融グループには、専門性向上や運用人材の育成・確保を含む
**「運用力向上・ガバナンス改善のためのプラン」の策定と公表**が求められ、
金融庁がその進捗をモニタリングしている（資産運用立国実現プラン、2023年12月以降）。

## 3. 運用力をどう測るか ── 「うまい運用会社」の定義

系列で売れてしまう構造の裏返しとして、日本では
**「運用が上手いかどうか」で会社が選ばれる圧力が弱かった**。
では運用力はどう測られるのか。機関投資家の世界では、見る指標は決まっている。

| 指標                           | 何を見るか                               | 噛み砕くと                                                     |
| ------------------------------ | ---------------------------------------- | -------------------------------------------------------------- |
| **超過収益（アルファ）**       | ベンチマーク（指数）をどれだけ上回ったか | 「市場平均に勝てたか」                                         |
| **シャープレシオ**             | リスク1単位あたりのリターン              | 「どれだけ荒っぽい運用で稼いだか」を割り引いた成績             |
| **インフォメーション・レシオ** | 超過収益 ÷ そのブレ                      | 「勝ち方が安定していたか」                                     |
| **トラッキングエラー**         | 指数との乖離の大きさ                     | パッシブでは小さいほど良い／アクティブでは大きいほど攻めている |
| **運用体制の継続性**           | 運用担当者の在籍年数、離職率             | 「この成績を出した人はまだ居るのか」                           |

重要なのは、**1〜2年の成績では判断されない**こと。
年金の運用機関選定では通常5年以上の実績と、成績の**再現性の説明**が求められる。
「なぜ勝てたのか」を言語化できない運用会社は、たまたま勝っただけと見なされる。

```
【日本のアクティブ運用が抱える構造問題】

  ① ファンドの本数が多すぎる
     公募投信は5,840本（2026年8月末、資産運用業協会）
        │  → 1本あたりの残高が小さい
        ▼
  ② 小さいファンドは固定費を回収できない
        │  → 繰上償還される／運用に人手をかけられない
        ▼
  ③ 運用体制に投資できない
        │  → 成績が安定しない
        ▼
  ④ 系列販売で新商品を売る方が早い
        │  → 新しいテーマの商品を次々に作る
        └──────── ①に戻る（本数がさらに増える）

  ＝「多産多死」のループ。運用力に投資が向かわない構造になっていた。
```

金融庁が挙げる運用力の課題は、突き詰めると**人**の問題である。

- **人材市場の薄さ**：運用の専門人材が社内育成中心で、外部から採りにくい
- **報酬体系**：グループの給与体系に縛られ、成果に応じた報酬を出しにくい
- **ジョブローテーション**：数年で他部門へ異動するため、運用の専門性が蓄積しない

大手各社が海外ビジネスを強化点に挙げるのは、収益機会というだけでなく、
**海外の厳しいアセットオーナーに選ばれる過程で運用力が鍛えられる**からでもある
（金融庁の調査における各社の説明、プログレスレポート各年）。

参考までに、公募投信の純資産ベースで見た国内運用会社の上位は
**野村アセットマネジメント、三菱UFJアセットマネジメント、大和アセットマネジメント、
アモーヴァ・アセットマネジメント（旧・日興アセットマネジメント）、アセットマネジメントOne**
の順とされ、上位5社で約7割を占める（民間集計、2026年5月時点）。
ただし**野村の首位はETF（日銀が金融緩和で買い入れた分を含む）の寄与が大きい**ため、
この順位をそのまま「運用力の順位」と読むことはできない。

> ポイント：**残高ランキングは運用力ランキングではない**。
> 日本の残高上位は「系列の販売力」と「ETFという特殊要因」で説明できる部分が大きい。

## 4. 外資系運用会社の存在感 ── 強い領域と弱い領域

日本市場には外資系運用会社が多数参入しているが、**強い場所がはっきり分かれている**。

| 領域                                   | 強いのは                     | なぜそうなるか                                         |
| -------------------------------------- | ---------------------------- | ------------------------------------------------------ |
| 個人向けインデックス投信               | **日系（系列）**             | 販売網と超低コスト競争。ブランドと棚を押さえている     |
| 個人向けテーマ型アクティブ             | 日系＋外資（商品供給で参加） | 外資が運用し、日系が販売する組み合わせも多い           |
| 年金向け外国株式・外国債券             | **外資**                     | 現地の調査網と運用実績。日系は海外運用を外部委託しがち |
| オルタナティブ（PE・不動産・インフラ） | **外資が圧倒的**             | 案件の獲得力とファンド組成の経験値が段違い             |
| ETF                                    | 世界では外資が寡占           | 規模の経済がそのまま効く領域                           |

日本政府は外資の誘致を明確な政策にしている。

- **拠点開設サポートオフィス**（2021年1月開設）：登録の事前相談から監督まで**英語でワンストップ**対応
- **海外投資家等特例業務**（2021年11月施行）：一定の条件下で、登録ではなく**届出**で投資運用業ができる特例
- **金融・資産運用特区**（2024年〜）：行政手続きの英語対応や規制緩和を地域単位で進める
- **Japan Weeks**：海外投資家を東京に集める官民のイベント（2023年〜毎年秋）

> ポイント：外資誘致のねらいは**「外から競争を持ち込むこと」**にある。
> 系列で守られた市場に、実績だけで選ばれる会社を入れれば、
> 日系も運用力で勝負せざるを得なくなる、という設計である。
> 他方で、**個人向けの低コスト・インデックスという主戦場は日系が押さえている**ため、
> 家計マネーの入口での外資の存在感は、機関投資家分野に比べれば限定的である。

## 5. スチュワードシップ・コード ── 運用会社は「物言う責任」を負う

**スチュワードシップ（stewardship）** とは、他人の財産を預かる者の責任のこと。
運用会社は顧客のお金で株を持っているので、**株主としての権利を顧客のために使う義務**がある。
これを行動原則としてまとめたのが**日本版スチュワードシップ・コード**（2014年2月策定）。

法律ではなく**ソフトロー**（従うか、従わないなら理由を説明する＝comply or explain）である。

| 改訂      | 主な追加点                                                                                                        |
| --------- | ----------------------------------------------------------------------------------------------------------------- |
| 2014年2月 | 策定。投資先との「目的を持った対話（エンゲージメント）」を求める                                                  |
| 2017年5月 | **議決権行使結果の個別開示**を求める。パッシブ運用にも対話を求める                                                |
| 2020年3月 | ESG（環境・社会・ガバナンス）を含むサステナビリティの考慮。運用対象を債券等にも拡大                               |
| 2025年6月 | 5年ぶりの改訂。**協働エンゲージメントの推進**、投資先への株式保有状況の説明、コードの**スリム化・プリンシプル化** |

```
【議決権行使はどう決まるか ── 運用会社の中の流れ】

  ①議決権行使基準を作る（年1回見直し）
     例：「社外取締役が3分の1未満なら取締役選任に反対」
     「ROEが5年連続で基準未満なら経営トップの選任に反対」
        │
        ▼
  ②株主総会の招集通知が届く（集中日前後に数千社分が一気に来る）
        │   ├─ 議決権行使助言会社（ISS、グラス・ルイス）の推奨も参考にする
        │   └─ 重要議案は社内の議決権行使委員会にかける
        ▼
  ③賛否を決めて行使する
        │
        ▼
  ④結果を個別議案ごとに公表する（2017年の改訂以降、事実上の標準）
     反対した場合は理由も説明する

  ＝ 日本の株主総会は6月下旬に集中するため、
    数千社分を短期間でさばく必要がある。だから基準の機械的な適用に頼りやすい。
```

**協働エンゲージメント**とは、複数の運用会社が一緒に企業と対話すること。
1社では発言力が弱いため有効だが、日本では**大量保有報告制度の「共同保有者」に
あたるのではないか**という懸念から敬遠されてきた経緯がある。
2025年の改訂はここを後押しする趣旨を含む。

なお **GPIF は自ら個別企業の議決権を行使しない**。
巨大な公的機関が直接企業に影響を及ぼすこと（官製の企業支配）を避けるため、
議決権の行使は**運用を委託している運用会社に委ねている**。
その代わりGPIFは、運用会社のスチュワードシップ活動の質を評価する立場に立つ
→ [② 誰のお金を運用しているか](02_誰のお金を運用しているか.md)

## 6. パッシブ化が企業統治に与える影響 ── 「売れない株主」の誕生

パッシブ運用の拡大は、企業統治に構造的な問題をもたらす。理由は単純で、
**インデックス運用者は、その企業が指数に入っている限り株を売れない**からである。

```
【株主が経営に不満を持ったときの2つの手段】

  ■ アクティブ運用者
      「この経営はダメだ」
        ├─ Exit（売却）    → 売って去る。株価下落が経営へのメッセージになる
        └─ Voice（対話・議決権） → 物を言う
      ＝ 2つの手段を持つ。Exitの脅しがあるからVoiceも効く

  ■ パッシブ運用者
      「この経営はダメだ」
        ├─ Exit（売却）    → ✕ できない。指数に入っている限り持ち続ける
        └─ Voice（対話・議決権） → これしかない
      ＝ 退出できない株主。だからVoiceの質が企業統治の生命線になる

  ＝ 日本の株式市場ではパッシブ比率が高まり続けており、
    「売らない（売れない）株主」が大株主として居並ぶ構図になっている。
    インデックス型投信は株式投信の65.1%を占める（2026年8月末、資産運用業協会）。
```

ここに経済的なジレンマが重なる。

| ジレンマ                     | 中身                                                                                                                 |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| **コストの非対称**           | エンゲージメントには人件費がかかるが、信託報酬は年0.1%を切る。**調査・対話に費用をかけるほど採算が悪化する**         |
| **ただ乗り（フリーライド）** | A社が対話して企業価値が上がると、同じ指数を持つ**他の全ファンドも等しく得をする**。自社だけが負担する動機が弱い      |
| **時間とカバー範囲**         | 数千社を保有し、招集通知から行使までの期間は短い。1社ごとに深く踏み込めない                                          |
| **議決権の集中**             | 世界的には大手インデックス運用会社に議決権が集中し、**選ばれていない少数の会社が企業統治を左右する**という批判がある |

この批判に対する運用会社側の動きが、**ボーティング・チョイス（議決権行使のパススルー）**である。
ファンドの受益者（最終的な投資家）が議決権行使の方針を選べるようにする仕組みで、
ブラックロックなど大手が導入している。ただし個人投資家の利用率は高くないと報じられる。

日本では逆に、**パッシブにこそ対話を求める**方向で制度が作られてきた。
2017年のスチュワードシップ・コード改訂で
「パッシブ運用であっても中長期的視点に立った対話と議決権行使をすべき」と明文化されており、
2020年の改訂ではESG要素の考慮も求められている。

> ポイント：**パッシブ化は「安さ」と「統治の質」のトレードオフを生む**。
> 手数料を下げるほど対話に割ける資源は減るのに、
> 売れない株主として統治への責任だけは重くなる。
> この矛盾が、いまの日本の運用業界と政策の最大の未解決問題である。

---

## 7. 残る論点 ── これからどこを見ればよいか

- **系列の利益相反は減ったか** → 販売会社の棚に占める他社商品の比率、プロダクトガバナンスの開示内容
- **運用力は上がったか** → 「運用力向上プラン」の進捗、海外アセットオーナーからの受託実績
- **多産多死は止まるか** → 公募投信の本数（2026年8月末で5,840本）と1本あたり平均残高
- **外資は根付くか** → 特例業務・拠点開設の件数、オルタナティブ分野の受託拡大
- **スチュワードシップは機能するか** → 協働エンゲージメントの実例、議決権行使の反対率、開示の具体性
- **DC・iDeCoの改革** → 制度のシンプル化、運営管理機関のコスト構造

直近の動きは [④ 直近トピック（2026年9月時点）](04_直近トピック_2026.md) を参照。

## 用語メモ

| 用語                               | 意味                                                                                                   |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------ |
| **資産運用立国**                   | 2023年12月の「資産運用立国実現プラン」以降の政府方針の総称。家計の資産形成と運用業の高度化を両輪とする |
| **顧客本位の業務運営（FD原則）**   | Fiduciary Duty。2017年策定の金融庁の原則。2024年9月にプロダクトガバナンスを追加                        |
| **プロダクトガバナンス**           | 商品の作り手が、想定顧客の明確化・コストに見合う価値の検証・販売後の継続的な点検まで責任を負う考え方   |
| **最善利益義務**                   | 顧客等の最善の利益を勘案して誠実公正に業務を行う義務。2024年11月施行の金融サービス提供法で法定化       |
| **利益相反**                       | 顧客の利益と自社（グループ）の利益がぶつかる状態。系列構造では商品選定・手数料設計で起きやすい         |
| **スチュワードシップ・コード**     | 2014年策定。運用会社が株主として顧客のために責任を果たすための行動原則。ソフトロー                     |
| **コーポレートガバナンス・コード** | 2015年適用開始。企業側の統治の行動原則。スチュワードシップ・コードと「車の両輪」とされる               |
| **comply or explain**              | 原則に従うか、従わないなら理由を説明する、というソフトローの仕組み                                     |
| **エンゲージメント**               | 運用会社が投資先企業と行う「目的を持った建設的な対話」                                                 |
| **協働エンゲージメント**           | 複数の運用会社が共同で企業と対話すること。2025年のコード改訂で推進が打ち出された                       |
| **議決権行使助言会社**             | 株主総会議案への賛否を機関投資家に助言する会社。ISS、グラス・ルイスが代表                              |
| **ボーティング・チョイス**         | ファンドの受益者が議決権行使の方針を選べる仕組み。大手インデックス運用会社が導入                       |
| **Exit と Voice**                  | 株主の2つの手段。売却（Exit）と、対話・議決権（Voice）。パッシブはVoiceしか使えない                    |
| **海外投資家等特例業務**           | 2021年11月施行。一定条件の下で、登録ではなく届出により投資運用業を行える特例                           |
| **金融・資産運用特区**             | 2024年〜。行政手続の英語対応や規制緩和を地域単位で進める国の制度                                       |
| **インフォメーション・レシオ**     | 超過収益をその変動の大きさで割った指標。アクティブ運用の「勝ち方の安定性」を測る                       |
| **資産運用業協会**                 | 投資信託協会と日本投資顧問業協会が統合し2026年4月1日に発足した業界団体                                 |
