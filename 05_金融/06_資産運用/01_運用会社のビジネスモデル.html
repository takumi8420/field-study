① 運用会社のビジネスモデル ── AUM × 手数料率がほぼ全て

金融資産運用
あこのページの単語集用語に触れると意味を確認できます20語
AUM信託報酬（運用管理費用）販売手数料（申込手数料）受託銀行（受託者）基準価額パッシブ運用（インデックス運用）アクティブ運用アルファ／ベータトラッキングエラーネットフロー（純資金流入）投資一任契約ノーロード繰上償還ETF実効手数料率関連ノート：② 誰のお金を運用しているか③ 日本の資産運用業の課題と政策④ 直近トピック（2026年9月時点）証券信託銀行

このノートで分かること：資産運用会社（アセットマネジメント会社）は何を売っていて、
どこからいくら受け取り、なぜ「規模がそのまま利益」になるのか。
そして、なぜインデックスファンドの手数料が毎年のように下がり続けるのか。

結論を先に：運用会社の売上は、たった1本の式で決まる。
売上 ＝ AUM（預かり資産残高）× 手数料率。それ以外の収入はほとんどない。
一方でコストは人件費・システム費という固定費なので、
AUM が増えた分はほぼそのまま利益になる。この非対称性がこの業界の全てを規定している。

1. まず押さえる：運用会社は「お金を預かって、運用の指図をするだけ」の会社

銀行は預金を集めて貸し、利ざやを取る。証券会社は売買を取り次いで手数料を取る。
では運用会社は何をしているのか。

運用会社は、顧客のお金を自分のバランスシート（貸借対照表）に載せない。
お金の保管は信託銀行（受託銀行）がやり、売るのは証券会社や銀行（販売会社）がやる。
運用会社がやるのは「どの銘柄をいくら買え／売れ」と指図（さしず）することだけである。

【投資信託の3者分離構造 ── 日本の投信は必ずこの形】

   個人・年金                  販売会社                 運用会社                 受託銀行
  （受益者）              （証券・銀行・ネット証券）     （アセマネ会社）         （信託銀行）
      │                        │                       │                       │
      │ ①お金を出す            │                       │                       │
      ├───────────────▶│  ②お金を信託             │                       │
      │                        ├──────────────────────────────────────────▶│
      │                        │                       │  ③「A株を買え」と指図  │
      │                        │                       ├──────────────▶│
      │                        │                       │                       │ ④実際に売買・保管
      │                        │                       │                       ├──▶ 市場
      │ ⑤基準価額で評価される  │                       │                       │
      ◀───────────────────────────────────────────────────────────────┤

  ポイント：お金（信託財産）は受託銀行が分別管理している。
  だから運用会社が倒産しても、投資家の資産は基本的に守られる（＝倒産隔離）。
  運用会社は「判断と指図」という無形の役務だけを売っている身軽な商売。

ポイント：運用会社はお金を預かるが、自分のお金にはしない。
だから自己資本比率規制（銀行のBIS規制のような資本の縛り）も軽く、
参入に必要な自己資本は投資運用業で原則5,000万円で済む。
元手がほとんど要らない代わりに、規模がなければ食えない商売である。

2. 売上の式 ── AUM × 手数料率

運用会社の損益計算書は驚くほど単純である。

【運用会社の損益の骨格】

  売上（営業収益）＝  AUM  ×  手数料率
                     ↑         ↑
              預かり資産残高   年率 0.02% 〜 2% 程度
              （兆円単位）     （商品と顧客で10倍以上違う）

  ─ 費用 ────────────────────────────
    人件費（ファンドマネージャー、アナリスト、事務）
    システム費（運用システム、データ、指数のライセンス料）
    委託調査費・外部委託費
    ＝ ほぼ全部が固定費。AUM が2倍になっても費用は2倍にならない
  ────────────────────────────────
  ＝ 営業利益

AUM（Assets Under Management ＝ 運用資産残高、預かり資産残高）は2つの理由で増える。

AUM が増える理由 中身 運用会社から見た意味
資金流入（ネットフロー）新しくお金が入ってくる本当の営業成果。持続する
時価変動持っている株や債券の値段が上がる相場任せ。下がれば消える

金融庁の調査では、日系大手金融グループ11社の「国内」機関投資家向けAUMは
2022年3月末の280兆円から2025年3月末の335兆円へ +55兆円 増えたが、
その内訳は資金流入が+9兆円、時価変動等が+45兆円だった
（金融庁「資産運用サービスの高度化に向けたプログレスレポート2026」2026年7月）。

ポイント：運用会社の増収の大半は株高のおかげであることが多い。
決算が良いときに「実力なのか相場なのか」を分けて見るのが、この業界を読むコツ。

3. なぜ「規模がそのまま利益」なのか ── 固定費型の事業

ファンドを1本運用するコストは、そのファンドが10億円でも1兆円でもほとんど変わらない。
日経平均に連動するインデックスファンドを運用する手間は、
残高が10倍になっても10倍にはならない。株を買う枚数が増えるだけである。

【残高と利益の関係（イメージ・単純化した試算）】

  手数料率を年0.1%、運用の固定費を年5億円とすると──

   AUM      売上       固定費     営業利益      利益率
  ──────────────────────────────────────
  1,000億円   1.0億円    5.0億円   ▲4.0億円      赤字
  5,000億円   5.0億円    5.0億円      0億円      トントン
   1兆円     10.0億円    5.0億円    +5.0億円      50%
   5兆円     50.0億円    5.0億円   +45.0億円      90%
  ──────────────────────────────────────

  ＝ 損益分岐点を超えた瞬間から、増えた売上がほぼ丸ごと利益になる。
    低コストのインデックスファンドが「巨大でなければ成立しない」理由。

これが業界の性格を決めている。

  • ファンドは大きくならないと黒字化しない → 残高が伸びないファンドは繰上償還される
  • 規模の大きい会社ほど手数料を下げられる → 下げるとさらに残高が集まる → 勝者総取りに向かう
  • 買収が効く → 会社を買えばAUMが一気に乗る。運用業界のM&Aが多いのはこのため

ポイント：この業界の競争は「安さの自己強化ループ」である。
大きい会社が下げる → 小さい会社は追随すると赤字 → 残高が偏る → さらに大きくなる。
インデックス運用の世界が数社に集中していくのは必然といえる。

4. 信託報酬は誰がいくら取るのか ── 手数料の分かれ方

投資信託を持ち続けているあいだ、毎日少しずつ差し引かれるのが信託報酬（運用管理費用）。
これは1社が総取りするのではなく、3者で山分けする。

【信託報酬の分配（バランス型・アクティブ投信の典型例、年率）】

   投資家が払う信託報酬  年1.50%（税抜）
        │
        ├──▶ 販売会社（証券・銀行）    約 0.70%  ← 売った会社が持ち続ける限り毎年もらう
        │                                          （＝「代行手数料」。口座管理・報告の対価）
        ├──▶ 運用会社（アセマネ）      約 0.73%  ← 運用の判断と指図の対価
        │
        └──▶ 受託銀行（信託銀行）      約 0.07%  ← 保管・計理・決済の対価


【低コストのインデックス投信では全く景色が変わる（年率）】

   投資家が払う信託報酬  年0.05〜0.10% 程度
        │
        ├──▶ 販売会社   約 0.02〜0.04%   ← ネット証券は売って終わりではなく細く長く
        ├──▶ 運用会社   約 0.02〜0.04%
        └──▶ 受託銀行   約 0.01%

  ＝ 全体が20分の1以下になっても、3者で分ける構造は同じ。
    だから残高が桁違いに大きくならないと誰も食べていけない。

加えて、買うときに一度だけ取られる販売手数料（申込手数料、上限3%程度）がある。
これは全額が販売会社の取り分で、運用会社には1円も入らない。

手数料の種類 いつ払う 誰が受け取る 近年の動き
販売手数料（申込手数料）買うとき1回販売会社のみノーロード（無料）化が急速に進行。NISA つみたて投資枠は制度上ゼロ
信託報酬（運用管理費用）保有中、毎日販売会社・運用会社・受託銀行で分配インデックス型で年0.1%割れが常態化
信託財産留保額解約時ファンドに残る（誰の収入でもない）設定しないファンドが増加
成功報酬目標超過時運用会社機関投資家向けやヘッジファンドで一般的。公的年金でも導入が増加

ポイント：販売手数料がゼロになると、販売会社の収入は「信託報酬の取り分」だけになる。
つまり 「売った瞬間に稼ぐ」から「持ち続けてもらって稼ぐ」へ、
販売会社のビジネスモデル自体が変わった。これが回転売買批判への構造的な答えでもある。

5. アクティブとパッシブ ── 同じAUMでも収益がまるで違う

運用には大きく2つの流儀がある。

パッシブ（インデックス）運用 アクティブ運用
やること日経平均・TOPIX・S&P500 などの指数（インデックス）にそっくり連動させる指数を上回ることを狙って銘柄を選ぶ
必要な人員少ない。システムと数人で数兆円を回せる多い。アナリスト・ファンドマネージャーが要る
手数料率極めて低い（年0.02〜0.1%程度）高い（年0.5〜1.5%程度）
勝負の軸コストと運用の正確さ（トラッキングエラーの小ささ）銘柄選択の腕（超過収益＝アルファ）
経済的な性格装置産業。規模が全て人的資本産業。人が抜けると商品が死ぬ

同じ1兆円を預かっていても、パッシブなら年2億円、アクティブなら年100億円の売上になる。
この差は実際の統計にはっきり出ている。

【大手20社の国内機関投資家向け ── AUMと営業収益のねじれ】
（金融庁プログレスレポート2026。AUMは2025年3月末、営業収益は2025年3月期）

               AUM                         営業収益
  パッシブ  ████████████████████ 301兆円   ███ 552億円
  アクティブ ███████████ 168兆円            ████████████████████ 2,675億円

  ＝ 残高では パッシブが6割を占めるのに、
    収益では アクティブが7割近くを稼いでいる。

ポイント：「AUMが大きい会社＝儲かっている会社」ではない。
パッシブだらけのAUMは、規模のわりに収益を生まない。
決算を読むときは、AUMの絶対額ではなく中身の構成と実効手数料率（営業収益÷AUM）を見る。

6. 手数料引き下げ競争はなぜ止まらないのか

インデックスファンドは、極論すればどの会社が作っても中身が同じである。
「S&P500に連動する」という商品に、味の違いはほとんどない。
残るのはコストと残高規模だけで、これは典型的なコモディティ（差のない商品）である。

さらに日本では、「業界最低水準の運用コストを将来にわたってめざし続ける」という
自動追随型の宣言をするシリーズ（三菱UFJアセットマネジメントの eMAXIS Slim が代表例）が現れた。
他社が下げたら自動的に自分も下げる、という約束である。

【なぜ下げ止まらないのか ── 価格競争のループ】

  A社が信託報酬を下げる
        │
        ▼
  自動追随を宣言している B社も下げざるを得ない
        │
        ▼
  投資家は「一番安い1本」に集中する（商品に差がないから）
        │
        ▼
  残高がさらに寡占化する → 規模が出るのでまた下げられる
        │
        └──────────── 最初に戻る（下限は「運用の実費」）

  実際、米国株指数（S&P500）連動の代表的な低コスト投信の信託報酬は
  年0.1%を割り込み、2026年時点では年0.08%台の水準にある（各社公表資料）。
  ＝ 1,000万円を預けても年間8,000円程度。ここから3者で山分けする。

では運用会社はなぜそれでもやるのか。理由は3つある。

  1. 残高を握ること自体が資産。将来ほかの商品（オルタナティブ、ラップ、iDeCo）へ横展開できる
  2. NISAの受け皿になれるかどうかが、家計マネーの入口を押さえる勝負になっている
  3. 貸株（保有株を貸して手数料を得る）などの副収入で実質的なコストを埋められる

ポイント：インデックスの手数料競争は、ほぼ「赤字覚悟の入口争い」になっている。
だから各社の収益の柱は、値下げ競争の外側にある
アクティブ運用・オルタナティブ運用・機関投資家向けサービスに移りつつある。

7. 投資信託と投資一任（投資顧問）── 商売の作りが違う2本立て

運用会社の顧客は個人だけではない。契約の形が2種類ある。

投資信託（ファンド） 投資一任契約（投資顧問）
仕組み多数の投資家のお金をひとつの器（信託）にまとめる顧客1人ごとに専用の口座・運用方針を作る
主な顧客個人、DC（確定拠出年金）、一部の法人年金基金、保険会社、事業法人、大学ファンド
商品設計あらかじめ決めた方針で誰にでも売る（＝大量生産）顧客ごとにオーダーメイド（＝受注生産）
手数料信託報酬（目論見書で公開）個別交渉。規模が大きいほど値引きされる
規制上の分類投資信託委託会社（金商法の投資運用業）投資一任業者（同じく投資運用業）
営業の型販売会社への商品提供（BtoBtoC）年金基金・コンサルへの直接営業（BtoB）

同じ運用会社が両方やっているのが普通だが、求められる能力が違う。
投信は「販売会社の棚を取る力」、投資一任は「年金コンサルの選定を通る運用実績」が勝負になる。

ポイント：日本では長く投信＝系列の銀行・証券に売ってもらう商売、
投資一任＝実績で選ばれる商売という二重構造だった。
このうち前者がネット証券とNISAで崩れ始めたのが、いまの局面である
→ ③ 日本の資産運用業の課題と政策

8. 運用会社の決算の読み方 ── 見るべき4つの数字

指標 意味 見るポイント
AUM（運用資産残高）預かっている総額前年比の増減を「資金流入」と「時価変動」に分解する
ネットフロー（純資金流入）流入 − 流出ここがプラスかどうかが営業の実力。マイナスなら相場頼み
実効手数料率（営業収益 ÷ AUM）平均して何%取れているか下がり続けるのが常態。下落のスピードを見る
営業利益率固定費を吸収できているか大手で30〜40%程度が一つの目安。高い利益率が出やすい業種

参考までに、金融庁調査による国内顧客からの手数料率（営業収益÷AUM、2025年3月期）は、
公的年金などの公的アセットオーナーが0.02%、企業年金が0.27%、金融法人等が0.12%。
同じ「機関投資家」でも10倍以上の差がある。

ETF証券取引所に上場した投資信託。市場でいつでも売買でき、信託報酬は総じて低い
