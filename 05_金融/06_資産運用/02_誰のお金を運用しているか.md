# ② 誰のお金を運用しているか ── 年金・保険・個人で全く違う商売

このノートで分かること：**運用会社が預かっているお金は誰のものか**。
そして、同じ「資産運用」と呼ばれていても、**年金相手と個人相手では
売り方・値段・必要な能力がまるで違う**こと。

> **結論を先に**：日本の運用資金の最大の出し手は、長らく **年金（GPIF・企業年金）と保険会社**だった。
> ここは「入札とコンサルで選ばれる BtoB の世界」で、値段は安く、規模は巨大。
> そこに2024年以降、**新NISAで個人のお金**が本格的に流れ込み始めた。
> こちらは「販売会社の棚を取る BtoBtoC の世界」で、値段は（相対的に）高い。
> **この2つは同じ会社の中にあっても、別の商売である。**

---

## 1. お金の出し手を上から見る ── インベストメント・チェーン

家計のお金が最終的に企業の株式・債券に届くまでの道筋を、
金融庁や政府は **インベストメント・チェーン（投資の連鎖）** と呼ぶ。

```
【お金の流れの全体像】

  ┌──────────┐
  │  家計（個人） │  日本の家計金融資産 2,519兆円（2026年6月末、日銀資金循環統計）
  └─────┬────┘
        │
        ├─── ①自分で買う ──────────────────────────┐
        │     投信・NISA・iDeCo                                        │
        │     （販売会社＝証券・銀行・ネット証券を経由）                │
        │                                                               │
        ├─── ②勤め先を通じて ────────────────┐      │
        │     企業年金（DB・企業型DC）                        │      │
        │                                                      │      │
        ├─── ③保険料として ──────────────┐  │      │
        │     生命保険・損害保険                            │  │      │
        │                                                    │  │      │
        └─── ④社会保険料として ────────┐        │  │      │
              公的年金（厚生年金・国民年金）      │        │  │      │
                                                   ▼        ▼  ▼      ▼
                                          ┌──────────────────────────┐
                                          │  アセットオーナー（AO）       │
                                          │  GPIF・企業年金・保険会社・    │
                                          │  共済・大学ファンド 等         │
                                          └────────────┬─────────┘
                                                        │ 運用を委託
                                                        ▼
                                          ┌──────────────────────────┐
                                          │  運用会社（アセットマネジャー） │
                                          └────────────┬─────────┘
                                                        │ 指図
                                                        ▼
                                          ┌──────────────────────────┐
                                          │  上場企業の株式・債券／        │
                                          │  非上場株・不動産・インフラ    │
                                          └──────────────────────────┘
```

**アセットオーナー（AO）** とは、「最終的にそのお金の責任を負う主体」のこと。
GPIF、企業年金基金、保険会社、大学ファンドなどがこれにあたる。
運用会社は AO から「運用させてもらう」立場であり、**AO の目が厳しいほど運用会社は鍛えられる**。
政府が2024年に「アセットオーナー・プリンシプル」を作ったのはそのためで、
2026年6月末時点で **369の主体**が受け入れを表明している（金融庁プログレスレポート2026）。

## 2. 日本の家計金融資産 ── 2,519兆円の中身

まず出発点となる家計の資産を見る。

| 項目                 | 2026年6月末残高 | 構成比   | 前年比     |
| -------------------- | --------------- | -------- | ---------- |
| **金融資産合計**     | **2,519兆円**   | 100.0%   | +11.0%     |
| 現金・預金           | 1,132兆円       | 44.9%    | +0.5%      |
| 保険・年金・定型保証 | 586兆円         | 23.3%    | +3.2%      |
| 株式等               | 486兆円         | 19.3%    | +47.0%     |
| **投資信託**         | **193兆円**     | **7.7%** | **+36.8%** |
| 債務証券             | 38兆円          | 1.5%     | +15.5%     |

（出典：日本銀行「資金循環統計（速報）2026年第2四半期」2026年9月17日公表）

長らく「現預金が5割」と言われてきたが、2026年に入って**44.9%まで低下**した。
ただし注意すべき点がある。**減ったのは比率であって、金額ではない**。
現金・預金は+0.5%と微増で、比率が下がったのは**株式と投信の時価が急騰したから**である。

> ポイント：「貯蓄から投資へ」が進んだように見える数字の多くは、**相場が上がった結果**でもある。
> 本当に資金が動いたかは、残高ではなく**フロー（資金の出入り）**で見る必要がある。

## 3. 4つの顧客セグメント ── 全く違う4つの商売

運用会社から見ると、顧客は大きく4種類に分かれる。同じ会社の中にあっても別事業である。

| 顧客                           | 規模感                | 手数料率の目安         | 決め方                       | 運用会社に求められるもの             |
| ------------------------------ | --------------------- | ---------------------- | ---------------------------- | ------------------------------------ |
| **公的年金（GPIF等）**         | 超巨大（1件で数兆円） | **年0.02%**            | 公募・入札。厳格な定量評価   | 巨額を正確に回す執行力。パッシブ中心 |
| **企業年金（DB）**             | 中〜大                | **年0.27%**            | 年金コンサルの選定リスト経由 | 中長期の運用実績。説明責任           |
| **金融法人等（保険・銀行等）** | 大                    | **年0.12%**            | 相対交渉                     | 専門性。特に外国債券・オルタナティブ |
| **個人（投信・NISA・iDeCo）**  | 1件は小さいが数が多い | 商品により年0.05〜1.5% | 販売会社の棚に載るかどうか   | 商品ブランド、低コスト、販売支援     |

（手数料率は金融庁プログレスレポート2026の大手20社調査、2025年3月期。個人向けは各社公表の信託報酬水準）

この表が示す非対称性が、この業界の最大の特徴である。

```
【AUMと収益のねじれ ── 大手20社の国内機関投資家向け】
（金融庁プログレスレポート2026。AUMは2025年3月末、営業収益は2025年3月期）

            AUM（504兆円）                営業収益（3,995億円）
  公的AO   ████████████ 303兆円 (60%)    ███ 603億円 (15%)
  企業年金  ██ 65兆円 (13%)               ████████ 1,783億円 (45%)
  金融法人  █████ 136兆円 (27%)           ███████ 1,609億円 (40%)

  ＝ 公的年金は残高の6割を占めるのに、収益では15%しか生まない。
    企業年金は残高13%で収益の45%を稼ぐ「一番おいしい顧客」。
```

> ポイント：運用会社が **GPIF の運用を受託したがるのは、儲かるからではない**。
> 手数料率は0.02%とほぼタダ働きに近い。それでも取りに行くのは、
> **「GPIFに選ばれた運用会社」という看板（プレゼンス）が、他の営業に効く**から。
> 実際、金融庁の調査でも各社からそうした声が確認されている。

## 4. 公的年金（GPIF）── 世界最大級のアセットオーナー

**GPIF（年金積立金管理運用独立行政法人）** は、厚生年金・国民年金の積立金を運用する組織。

| 項目                         | 数値               | 時点                 |
| ---------------------------- | ------------------ | -------------------- |
| 運用資産額                   | **317兆7,596億円** | 2026年6月末          |
| 2026年度第1四半期の収益率    | +8.20%             | 2026年4〜6月         |
| 同 収益額                    | +24兆895億円       | 同上                 |
| 市場運用開始以降の累積収益額 | +221兆201億円      | 2001年度〜2026年度1Q |
| 同 年率収益率                | +4.95%             | 同上                 |

（出典：GPIF「2026年度第1四半期運用状況（速報）」2026年8月7日）

GPIFの基本ポートフォリオは、国内債券・国内株式・外国債券・外国株式を**各25%**という単純な形。
ほとんどを外部の運用会社に委託しており、そのうち大半が**パッシブ運用**である。

- パッシブ中心なので手数料が極端に低い
- ただし近年は**成功報酬型の契約**（目標を上回ったら追加で払う）も導入が進む
  （金融庁調査では大手20社のうち14社が公的AOから成功報酬型のアクティブ運用を受託）
- **オルタナティブ資産**は第5期中期計画（2025〜2029年度）で資産全体の**上限5%**。
  2026年3月末の時価総額は**5兆2,067億円（全体の1.74%）**にとどまる
  （GPIF資料、2026年4月・内閣官房提出）

> ポイント：GPIFは**巨大すぎて身動きが取りにくい**。
> 数兆円単位で銘柄を買えば市場価格を動かしてしまうため、原理的にパッシブに寄らざるを得ない。
> この「巨大なパッシブ投資家」の存在が、日本の企業統治に独特の影響を与えている
> → [③ 日本の資産運用業の課題と政策](03_日本の資産運用業の課題と政策.md)

## 5. 企業年金 ── DB と DC は全く違う

企業年金には2つの形があり、**誰が運用リスクを負うか**が根本的に違う。

```
【DB と DC の違い ── リスクの持ち主が入れ替わる】

  ■ DB（確定給付企業年金 / Defined Benefit）
    会社「退職後に毎月◯円払うと約束します」
      │
      ├─ 運用がうまくいかなかったら？ → 会社が穴を埋める（掛金を追加）
      │
      └─ 運用の判断者 ＝ 年金基金（＝プロ）
         → 運用会社は「年金コンサルの選定を通る実績」を競う
         → 手数料率 年0.27% 前後。運用会社にとって最重要の収益源

  ■ DC（確定拠出年金 / Defined Contribution）
    会社「毎月◯円を積み立てます。運用はご自身で」
      │
      ├─ 運用がうまくいかなかったら？ → 従業員本人の年金が減る
      │
      └─ 運用の判断者 ＝ 加入者本人（＝素人）
         → 運用会社は「運営管理機関の商品ラインナップに載るか」を競う
         → 実質的に個人向け投信と同じ土俵

  ＝ 日本全体としては DB から DC への移行が続いている。
    つまり「運用リスクが会社から個人へ移っている」。
```

DCには、会社が導入する**企業型DC**と、個人が自分で入る **iDeCo（個人型確定拠出年金）** がある。
iDeCo の加入者数は約400万人で、**NISA口座数（2,820万口座）の7分の1以下**にとどまり、
その差は年々広がっている（金融庁プログレスレポート2026）。
加入者の約20%前後が元本確保型商品のみで運用しており、
インフレ下では実質的に目減りするリスクを抱えていると金融庁は指摘している。

|                    | 企業型DC                                           | iDeCo                                          | NISA                           |
| ------------------ | -------------------------------------------------- | ---------------------------------------------- | ------------------------------ |
| 誰が掛金を出すか   | 会社（＋本人の追加拠出可）                         | 本人                                           | 本人                           |
| 税制メリット       | 掛金が全額非課税、運用益非課税                     | 掛金が所得控除、運用益非課税                   | 運用益非課税                   |
| 引き出し           | 原則60歳まで不可                                   | 原則60歳まで不可                               | いつでも可                     |
| 関与するプレイヤー | 会社・運営管理機関・レコードキーパー・運用会社     | 国民年金基金連合会・運営管理機関・RK・運用会社 | 販売会社・運用会社             |
| 課題               | 多数の主体が絡み高コスト。多くの運営管理機関で赤字 | 制度が複雑で伸びない                           | 未稼働（買付額ゼロ）口座の存在 |

> ポイント：**iDeCoが伸びない最大の理由は、制度の複雑さとコスト構造**にある。
> DCは会社→運営管理機関（銀行・証券・保険）→レコードキーパー（記録管理の専門会社、国内4社）
> という多段構造で、各段が手数料を取る。政府は2026年時点で「効率化・シンプル化に向けた
> 大胆な改革」を検討する方針を示している（金融庁プログレスレポート2026）。

## 6. 個人のお金 ── 投信とNISAの世界

個人向けは「販売会社を通じて売る」のが基本で、運用会社から見ると**間接販売（BtoBtoC）**である。

| 項目                                     | 数値                                    | 時点        |
| ---------------------------------------- | --------------------------------------- | ----------- |
| 公募投信の純資産総額                     | **364兆2,855億円（5,840本）** ※過去最高 | 2026年8月末 |
| うち株式投信                             | 348兆125億円                            | 同上        |
| うちETF                                  | 135兆3,290億円（419本）                 | 同上        |
| **インデックス型ファンド**               | **226兆4,146億円（株式投信の65.1%）**   | 同上        |
| 私募投信（機関投資家向け）               | 117兆6,669億円（7,476本）               | 同上        |
| 公募株式投信のうち銀行等の販売残高シェア | 19.3%（ETF除くと31.6%）                 | 同上        |
| 2025年の公募投信 年間純資金流入額        | 15兆5,004億円（22年連続の純流入）       | 2025年暦年  |

（出典：資産運用業協会「数字で見る投資信託」2026年9月11日公表）

## 7. 保険会社 ── 「自分でも運用するアセットオーナー」

生命保険会社は、集めた保険料を自分で運用する**一般勘定**を持っており、
それ自体が巨大な機関投資家である。同時に、系列の運用会社を持ち、
外部の運用会社にも一部を委託する。つまり **AOでありプレイヤーでもある**。

| 立場                           | やっていること                                                               |
| ------------------------------ | ---------------------------------------------------------------------------- |
| **アセットオーナーとして**     | 保険料を自社で運用（一般勘定）。国債・外債が中心。近年はオルタナティブを拡大 |
| **委託者として**               | 専門性の高い分野を外部運用会社に委託                                         |
| **グループ運用会社の親として** | 傘下の運用会社を通じて投信・投資一任も提供                                   |

生保は**長期の負債（保険金支払い義務）を抱えている**ため、
それに合わせた長期・安定の運用（ALM＝資産負債の総合管理）が求められる。
詳しくは [生命保険](../07_生命保険/README.md) を参照。

## 8. オルタナティブの台頭 ── PE・不動産・インフラ

**オルタナティブ（代替）資産**とは、上場株式・債券という「伝統資産」以外への投資の総称。

| 種類                               | 中身                                     | 特徴                                                                          |
| ---------------------------------- | ---------------------------------------- | ----------------------------------------------------------------------------- |
| **PE（プライベート・エクイティ）** | 未上場企業の株式。バイアウトファンド、VC | 数年〜10年資金を拘束。高いリターンを狙う                                      |
| **プライベートデット**             | 非上場企業への直接融資                   | 銀行融資の代替。利回りが相対的に高い                                          |
| **不動産**                         | オフィス・物流施設・住宅など             | インフレに強いとされる → [不動産金融・REIT](../13_不動産金融・REIT/README.md) |
| **インフラ**                       | 発電所、空港、道路、通信設備             | 超長期で安定した収入。年金の負債と相性が良い                                  |
| **ヘッジファンド**                 | 相場の方向によらない収益を狙う運用       | 成功報酬型が一般的                                                            |

なぜ機関投資家がオルタナティブに向かうのか。理由は2つある。

1. **伝統資産だけでは目標利回りに届かない**（特に低金利が長く続いた時期の年金）
2. **上場株式と値動きが違う**ので、ポートフォリオ全体のブレを抑えられる（分散効果）

運用会社にとってオルタナティブは**極めて重要な収益源**である。
手数料率が伝統資産より桁違いに高く、成功報酬も乗るためだ。

```
【大手20社の国内機関投資家向け ── オルタナティブの収益貢献】
（金融庁プログレスレポート2026。AUMは2025年3月末、営業収益は2025年3月期）

                     AUM           営業収益
  国内オルタナ    4兆円 (1%)      169億円 ( 4%)
  外国オルタナ   32兆円 (6%)      860億円 (22%)
  ─────────────────────────────────
  合計          36兆円 (7%)    1,029億円 (26%)

  ＝ 残高では7%にすぎないのに、収益の4分の1を稼ぐ。
    運用会社が総力を挙げてオルタナティブ強化に走る理由がここにある。
```

大手20社が「今後最も強化したいアセットクラス」として挙げた回答でも、
**国内オルタナ・外国オルタナが上位**に入っている（金融庁調査、32社回答）。

> ポイント：**オルタナティブは「値下げ競争が効かない領域」**である。
> インデックス運用と違って中身が各社で全く違うため、コモディティ化しない。
> パッシブ化で収益を削られた運用会社にとって、ここが最後の高収益フロンティアになっている。

## 用語メモ

| 用語                               | 意味                                                                                       |
| ---------------------------------- | ------------------------------------------------------------------------------------------ |
| **アセットオーナー（AO）**         | そのお金の最終的な責任を負う主体。GPIF、企業年金基金、保険会社、大学ファンドなど           |
| **インベストメント・チェーン**     | 家計 → アセットオーナー → 運用会社 → 企業 とお金が連なる流れ                               |
| **GPIF**                           | 年金積立金管理運用独立行政法人。厚生年金・国民年金の積立金を運用する世界最大級のAO         |
| **DB（確定給付企業年金）**         | 給付額を約束する企業年金。運用リスクは会社が負う                                           |
| **DC（確定拠出年金）**             | 掛金額を約束する企業年金。運用リスクは加入者本人が負う。企業型とiDeCoがある                |
| **運営管理機関**                   | DCで商品ラインナップの選定や加入者記録の管理を行う銀行・証券・保険会社                     |
| **レコードキーパー（RK）**         | DCの記録管理業務を専門に行う会社。国内に4社                                                |
| **元本確保型商品**                 | 定期預金・保険など、元本が減らない代わりに増えにくい商品。DCでの選択率の高さが課題視される |
| **一般勘定**                       | 保険会社が自社のリスクで運用する勘定。保険金支払いを約束する                               |
| **ALM**                            | Asset Liability Management。負債（将来の支払い）に合わせて資産を組む考え方                 |
| **オルタナティブ資産**             | 上場株式・債券以外への投資。PE、プライベートデット、不動産、インフラ、ヘッジファンド等     |
| **PE（プライベート・エクイティ）** | 未上場企業の株式に投資する運用。バイアウトファンドとVCが代表                               |
| **基本ポートフォリオ**             | アセットオーナーが定める長期の資産配分方針。GPIFは国内外の株式・債券を各25%                |
| **公募投信／私募投信**             | 不特定多数に募集するのが公募、適格機関投資家など限られた相手に出すのが私募                 |
| **アセットオーナー・プリンシプル** | 2024年8月に内閣官房が策定したAOの行動原則。2026年6月末で369主体が受入れを表明              |
