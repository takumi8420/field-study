制度の基礎は ① 少額短期保険という制度、市場の姿は ② 何が売れているか・誰がやっているか を先に読むと分かりやすい。

1. 制度創設20年 — 122社・1,665億円で頭打ちに近づく

金融庁が2026年8月6日に公表した「2026年 保険モニタリングレポート」は、少額短期保険業者について独立の章（第Ⅷ章）を立て、次のように整理した。

  • 少額短期保険制度の創設から20年が経過（2006年4月施行 → 2026年で20年）
  • 2026年3月末の少短業者は 122業者、収入保険料1,665億円
  • 「規模・特性や取扱商品も多様化」「市場規模も一貫して拡大傾向」
  • 一方で「ガバナンスが脆弱な少短業者も多く、それに起因した問題が継続的に発生」
  • 「赤字経営から脱却できず、財務面に課題を抱える少短業者が一定程度存在」

業者数は2023年度末123社 → 2025年度末122社と 初めて減少に転じた（協会統計）。
保険料は年7〜8％で伸び続けているのに、社数が増えなくなった。
業界全体の拡大局面から、勝ち負けの選別局面に入ったと読める節目である。

年度末 業者数 収入保険料
2021年度115社1,277億円
2022年度120社1,346億円
2023年度122社1,435億円
2024年度123社1,536億円
2025年度122社（▲1）1,665億円（+8％）

（出典：日本少額短期保険協会「2025年度の業界の決算概況について」2026年7月9日）

2. 2026年6月1日、改正保険業法と少短向け監督指針改正が同時施行

2025年5月30日に成立（同年6月6日公布）した「保険業法の一部を改正する法律」が、2026年6月1日に施行された。
もともとは損害保険業界の保険料調整行為・情報漏えい問題を受けた改正だが、少短にも波及した。

金融庁は2026年3月19日に「少額短期保険業者向けの監督指針」の改正案を公表し、
パブリックコメントを経て 2026年5月29日に結果を公表、同年6月1日から適用している。

【2026年6月1日施行のパッケージ（少短に関係する部分）】

  改正保険業法（2025年5月30日成立 / 2026年6月1日施行）
    ├─ 保険会社等の体制整備義務の強化
    ├─ 保険契約者等への過度な便宜供与の禁止
    ├─ 乗合代理店における比較推奨販売の適正化
    └─ 保険仲立人（ブローカー）の活用促進

  少額短期保険業者向けの監督指針 改正（2026年5月29日公表 / 6月1日適用）
    ├─ 上記法改正に対応した所要の改正
    ├─ 保険金等支払管理態勢・営業推進態勢に関する着眼点
    ├─ **少短業者の規模・特性に応じた態勢整備**を求める着眼点
    └─ **共同保険契約の取扱いに関する当局の基本的な考え方**を明示 ★

★の共同保険は、少短にとって実務上の要点である。
年間収受保険料50億円という上限があるため、グループ内の複数の少短で1つの契約を分担して引き受ける手法が使われてきた
（例：東京海上ミレア少額短期保険は2023年9月から東京海上ウエスト少額短期保険・Tokio Marine X少額短期保険との3社共同引受を開始）。
当局が「基本的な考え方」を着眼点として示したことで、この手法が黙認から監督対象へ移ったと位置づけられる。
上限の仕組みは ①の第5章 を参照。

「規模・特性に応じた態勢整備」という表現は、大手少短には保険会社並みの管理を求め、小規模事業者には見合った水準を求めるという二段構えの宣言と読める。

3. ガバナンス問題 — 経費の不正取得、親会社による資金の無断流用

同じ保険モニタリングレポートは、2025事務年度（2025年7月〜2026年6月）に認められた不適切事案を具体的に挙げている。
これは業界にとって最も重い指摘である。

指摘された事案 内容（レポートの記述に基づく）
金銭に関する不適切事案2024事務年度に発覚した 代表取締役による長期・多額の経費の不正取得
同上親会社による少短業者資金の無断流用
情報発信取扱商品について 顧客の誤認を招く内容の情報発信
商品開発保険商品に係る 検討・確認が十分でないまま開発が行われた事案

当局の対応も具体的で、
「少短業者の 主要株主に対して 適切な業務運営に向けた態勢整備の必要性を説明」
「少短業者が、保険業法に定められた金融機関であることを認識させた上で、必要な態勢整備やビジネスモデルのあり方等に係る対話を行った」としている。

この「金融機関であることを認識させた上で」という一文が、業界の現状をよく表している。
事業会社が本業の延長で作った子会社が多いため、金融機関としての自覚と体制が追いついていないケースがある、という趣旨に読める。
類型別の背景は ②の第7章 を参照。

【少短のガバナンスが緩みやすい構造】

   事業会社（不動産・小売・IT） ─── 100%子会社 ───▶ 少額短期保険業者
        │                                              │
        │ 本業の一部門のつもり                          │ 実は保険業法上の金融機関
        │ 役員は本業から出向                            │ 監督は財務局
        └─ 資金も人も本業と一体運用しがち ────────┘ ← ここで事故が起きる

4. 火災保険の参考純率が2026年10月に改定 — 賃貸家財にも波及

損害保険料率算出機構（GIROJ）が算出する 火災保険参考純率（各社が保険料を決めるときの基礎となる、保険金支払いに充てる部分の標準値）は、
2023年6月届出分で全国平均 +13.0％ と当時過去最大の引き上げとなり、2024年10月以降の契約に順次反映されてきた。
さらに 2026年10月に改定が予定され、上げ幅は10〜15％と過去最大級になる見込みと報じられている（複数メディア、いずれも報道・解説ベース）。

少短の賃貸家財保険はGIROJの参考純率を直接使うわけではないが、影響は2経路で及ぶ。

【値上げの波及ルート】

  自然災害の増加 ＋ 修理費・資材費のインフレ
        │
        ├─▶ 再保険料の上昇 ──▶ 大手損保へ出再している少短の採算を直撃
        │                       （出再比率が高いほど再保険料の値上げが効く）
        │
        └─▶ 損保の火災保険の値上げ ──▶ 賃貸家財の相場も切り上がりやすくなる
                                      ただし競合は**不動産会社への手数料**なので
                                      保険料の上昇分が手数料に回る可能性もある

賃貸家財の元受損害率は20％台と低い（②の第3章）ため、
損害率の悪化そのものよりも、再保険条件の悪化のほうが先に効く点が少短固有の論点になる。

5. 成長の中心が家財から周辺へ移った

2025年度の種目別の伸びが、この移行をはっきり示している。

種目 保険料の前年度比 件数の前年度比 位置づけ
家財104％103％規模の主力だが成熟。賃貸市場の頭打ち
生保・医療107％104％葬儀保険・引受基準緩和型が中心
ペット118％112％単価も件数も伸びる。扱いは10社のみ
費用・その他121％124％スマホ修理費用・キャンセル費用が牽引（協会説明）

周辺分野の具体的な動きとして、2026年には次のような報道・発表がある。

  • リトルファミリー少額短期保険（あいおいニッセイ同和損保系）が、動物病院での 窓口精算システムを2026年度末までに1,000病院へ拡大する方針を示した（同社発表）
  • ソニー損害保険が 2026年6月にペット保険の提供を開始。ペット保険は少短の主戦場だったが、免許を持つ損保の参入が続く
  • 孤独死関連の保険金支払いが 2024年度までの10年で約4倍 に増えたと報じられた（日本経済新聞、2026年3月）

ペット分野は「少短で育てて損保が刈り取る」構図が強まりつつある、というのが2026年の見取り図になる。
アニコム損保・アイペット損保が少短・共済から損保免許へ移行した過去の経緯とあわせて読むと分かりやすい。
→ ペット関連

6. 募集人は増え続けている — 36.3万人

地味だが構造を示す数字。少額短期保険募集人の資格取得者数は次のように増えている。

年度末 募集人資格取得者数
2021年度28.3万人
2022年度30.1万人
2023年度32.0万人
2024年度33.6万人
2025年度36.3万人

（出典：日本少額短期保険協会、2026年7月9日公表）

業者数が減っているのに募集人は増え続けている。
これは、募集人の実体が 不動産会社・携帯ショップ・ペットショップの従業員であり、
本業側の店舗網が資格を取っているためと考えられる。
少短業界の雇用は少短業界の中にはほとんどないという、この業界の性格をよく表す数字である。

7. 全体の構図

  1. 市場は伸びているが、事業者は増えなくなった。2025年度は収入保険料1,665億円（+8％）に対し業者数は122社（▲1社）。拡大期から選別期へ移った
  2. 成長の中心が家財（+4％）から、ペット（+18％）と費用・その他（+21％）へ移った。ただし家財が依然として保険料の59％を占める重さは変わらない
  3. 当局の姿勢が「育成」から「規律」へ振れた。2026年6月施行の改正保険業法と監督指針改正で、規模・特性に応じた態勢整備と共同保険の取扱いが明文化された
  4. 指摘されている問題は保険の中身ではなくガバナンス。経費の不正取得、親会社による資金の無断流用、誤認を招く情報発信。「保険業法上の金融機関である」という当たり前を当局が言葉にする段階にある
  5. コスト側では再保険条件の悪化が最大の変数。2026年10月の火災保険参考純率改定に象徴されるように、自然災害と修理費インフレが上流から効いてくる。資産運用で埋められない少短にとって逃げ場が少ない

8. 用語メモ

用語 意味
保険モニタリングレポート金融庁が毎年公表する、保険会社・少短業者の監督結果と課題の総括。2026年版は2026年8月6日公表
事務年度金融庁の行政の年度区分。7月〜翌年6月。「2025事務年度」は2025年7月〜2026年6月
監督指針法令ではないが、当局が何を見るかを示した文書。実務上は法令に準じる重みを持つ
参考純率損害保険料率算出機構が算出する、保険料のうち保険金支払いに充てる部分の標準値。各社はこれに自社の経費を上乗せして保険料を決める
共同保険契約1つの保険契約を複数の保険者が割合を決めて分担して引き受けること。少短では50億円上限への対応として使われる
主要株主保険業法上、一定割合以上の議決権を持つ株主。当局の監督・指導の対象になりうる
少額短期保険募集人少短商品の販売資格。協会が試験を実施。2025年度末で36.3万人
