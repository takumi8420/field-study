# 何が売れているか・誰がやっているか

このノートで分かること：少額短期保険の1,665億円（2025年度）が **どの商品に偏っていて、誰が売っているのか**。
結論を先に言うと、**この業界の本体は「賃貸住宅の入居者向け家財保険」であり、実態は不動産業界の付帯商品**である。

## 1. 結論：保険業界というより「本業の付帯商品」市場

| 見方                     | 内容                                                                                                                   |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------- |
| 保険として見ると         | 収入保険料1,665億円。[損害保険](../08_損害保険/README.md)の正味収入保険料9兆9,726億円（2025年度）の**約1.7％**しかない |
| 販売チャネルとして見ると | 賃貸契約・携帯契約・ペット購入・旅行予約といった **本業の手続きの途中に差し込まれる**。顧客が保険を探しに来ていない    |
| 経済構造として見ると     | 損害率が低く事業費率が高い。**保険料の多くが代理店（＝本業側）の手数料に回る**                                         |

```
【少短の典型的な売れ方】

  消費者は「保険を買いに来ていない」

   賃貸の入居申込 ──▶ 重要事項説明 ──▶ 契約時に家財保険をセット ──▶ 2年後に自動更新案内
   スマホの機種変更 ─▶ 店頭でオプション ─▶ 月額数百円で加入
   子犬・子猫の購入 ─▶ ペットショップ店頭 ─▶ その場で申込
   旅行の予約 ──────▶ 予約画面のチェック ─▶ キャンセル費用保険

  ＝ 保険会社の営業ではなく、**本業の接点そのものが販売力**
```

この構造を掴むと、「なぜ不動産会社・携帯会社・小売が少短子会社を作るのか」が一直線に説明できる。

| 2022年度     | 1,087万件                      | 1,346億円                | 120社               |

読みどころは3つ。

1. **家財が過半（保険料59％・件数73％）**。この業界は家財保険の業界である
2. **家財の伸びは104％**と業界平均（108％）より低い。賃貸市場が成熟しているため
3. **伸びているのはペット（118％）と費用・その他（121％）**。協会は費用分野について「スマホ修理費用保険やキャンセル費用保険の販売が好調」と説明している

> ポイント：**規模は家財が、成長率は周辺が担う**という二層構造。
> 家財の1社あたり契約件数は平均18万件超（977万件÷53社）で、上位に集中している。

## 3. 家財保険 — 賃貸契約に埋め込まれた保険

### 何を補償しているか

賃貸入居者向けの「家財保険」は、名前に反して家財だけの保険ではない。実務上は3点セットになっている。

| 補償               | 何のため                                                  | 保険金額の目安         |
| ------------------ | --------------------------------------------------------- | ---------------------- |
| **家財**           | 火災・水濡れ・盗難などで自分の家具家電が壊れた            | 100万〜500万円程度     |
| **借家人賠償責任** | 火事や水漏れで **部屋（大家の所有物）を壊した**ときの賠償 | 1,000万〜2,000万円程度 |
| **個人賠償責任**   | 階下への水漏れなど、他人への賠償                          | 1,000万円〜1億円       |

大家・管理会社にとって決定的に重要なのは真ん中の **借家人賠償責任** である。
入居者が無保険だと、部屋の原状回復費用を回収できないリスクを大家が直接負う。
だから **賃貸借契約の条件として保険加入を求める** 実務が定着した。

### なぜ少短が強いのか

```
【賃貸契約とセットになる流れ】

  入居希望者
     │ ①部屋探し
     ▼
  仲介会社（宅建業者）──── 同じ会社／グループが ────┐
     │ ②賃貸借契約                                 │ 保険の募集代理店を兼ねる
     ▼                                            │
  管理会社 ─────────────────────────────┘
     │ ③重要事項説明と同時に家財保険を案内
     │   → 入居者は「言われたものに入る」。比較検討がほとんど発生しない
     ▼
  少額短期保険業者（元受）
     │ ④保険料の相当部分を代理店手数料として仲介・管理会社へ
     │ ⑤2年後の更新案内も管理会社経由
     ▼
  （大手グループの場合）親会社の損保へ再保険を出して上限をかわす
```

ここで効くのが制度上の2つの偶然である。

- **保険期間の上限が2年**（損害保険分野）→ 賃貸借契約の更新サイクル2年と完全に一致する
- **保険金額の上限が1,000万円** → 借家人賠償の実務水準とぎりぎり整合する

つまり **少短の器のサイズが、たまたま賃貸家財保険にぴったり合っていた**。
制度の詳細は [① 少額短期保険という制度](01_少額短期保険という制度.md) を参照。

関連する業界側は [賃貸管理](../../12_建設・住宅・不動産/10_賃貸管理/README.md) と
[不動産仲介・流通](../../12_建設・住宅・不動産/09_不動産仲介・流通/README.md)。

### 経済構造 — 損害率は低く、事業費率が異常に高い

東京海上ミレア少額短期保険の2025年度ディスクロージャー資料（開示値）が分かりやすい。

| 指標                                 | 2024年度      | 2025年度      |
| ------------------------------------ | ------------- | ------------- |
| 元受正味保険料                       | 55億6,954万円 | 57億4,737万円 |
| **元受損害率**（保険金÷保険料）      | 23.8％        | **21.0％**    |
| **元受事業費率**（事業費÷保険料）    | 77.7％        | **71.3％**    |
| **元受合算率**（コンバインドレシオ） | 101.5％       | **92.3％**    |
| 保有契約件数（期末）                 | —             | 154万126件    |
| 当期純利益                           | —             | 30百万円      |

比較すると異様さが際立つ。[損害保険](../08_損害保険/README.md)業界平均（2025年度・損保協会加盟31社）は
損害率61.0％／事業費率31.2％。**損害率と事業費率が、ほぼ逆転している。**

|              | 大手損保（業界平均・2025年度） | 賃貸家財の少短（上記1社の例） |
| ------------ | ------------------------------ | ----------------------------- |
| 損害率       | 61.0％                         | 21.0％                        |
| 事業費率     | 31.2％                         | 71.3％                        |
| コンバインド | 92.2％                         | 92.3％                        |

**合計はほぼ同じ92％台なのに、中身が正反対**。これが意味することは次のとおり。

- 賃貸家財は **事故がめったに起きない**（部屋を全焼させる入居者は稀）。だから損害率が低い
- その代わり、保険料の大半が **募集代理店＝不動産会社への手数料**に回っていると見られる
- したがってこの商品の競争は「保険の中身」ではなく、**不動産会社にどれだけ払えるか／どれだけ食い込めるか**で決まる

> ポイント：賃貸家財の少短は、リスクを引き受ける事業というより、
> **不動産会社の収益源を保険の形で作っている事業**に近い。
> 保険料を下げる競争が起きにくいのも、比較する主体（入居者）が選んでいないからである。

なお同社は元受57億4,737万円のうち正味収入保険料が5,744万円で、**99％を出再している**。
50億円の壁をかわす仕組みは [①の第5章](01_少額短期保険という制度.md) を参照。

## 4. ペット保険 — 唯一「卒業」が起きた分野

保険料シェア17％、前年度比118％と最も伸びている。しかし扱うのは **わずか10社**。

| 特徴         | 内容                                                                                                                                      |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------- |
| 販売チャネル | ペットショップ店頭（生体販売と同時）、動物病院、ネット比較                                                                                |
| 保険の性質   | 通院・手術の **実費補償型**（50％・70％など補償割合を選ぶ）。損害率が高く、家財とは真逆の商品                                             |
| 制度上の難点 | 医療の上限80万円が効く。高額治療や長期の補償設計に天井がある                                                                              |
| 「卒業」     | アニコム損害保険・アイペット損害保険は、いずれも少短や共済から **損害保険会社の免許取得へ移行した**とされる（2000年代後半〜2010年代前半） |

少短の枠で規模が出てきたら免許を取って出ていく、という経路が実際に働いた唯一の分野である。
一方で現在も、SBIペット少額短期保険、日本ペット少額短期保険、リトルファミリー少額短期保険（あいおいニッセイ同和損保系）などが少短のまま営業している。

## 5. 費用・その他 — 尖ったニッチの実験場

件数203万件（前年度比124％）、保険料188億円（同121％）と最速で伸びている領域。
商品認可が届出中心で軽いので、**保険会社が採算を読みきれずに作らない小さな補償**がここに集まる。

| 類型             | 中身                                                                                           | 典型的なチャネル                                                             |
| ---------------- | ---------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| スマホ修理費用   | 画面割れ・水没の修理費を実費補償                                                               | 携帯ショップ、中古端末販売、通信契約に付帯                                   |
| キャンセル費用   | 旅行・ホテル・イベントの取消料を補償                                                           | 予約サイトの決済画面 → [旅行](../../15_サービス・生活関連/10_旅行/README.md) |
| 自転車・賠償     | 自転車事故の賠償（自治体の加入義務化が追い風）                                                 | 自治体、自転車販売店                                                         |
| 弁護士費用       | 痴漢冤罪・ネット誹謗中傷などの弁護士費用                                                       | ネット直販、SNS広告                                                          |
| 地震費用         | 地震で被災した際の当座の費用（火災保険の地震保険とは別枠の「低発生率保険」）                   | ネット、提携先                                                               |
| 孤独死・原状回復 | 賃貸室内で入居者が亡くなった際の原状回復・遺品整理費用。**大家向け**と**入居者向け**の両タイプ | 管理会社・大家                                                               |

孤独死関連は単身高齢者の増加を背景に伸びており、支払実績が **2024年度までの10年で約4倍** になったと報じられている（日本経済新聞、2026年3月）。
賃貸家財と同じ不動産チャネルに乗せられるため、家財の成熟を補う商品として位置づけられている。

## 6. 生保・医療 — 少額でも意味がある領域

保険料213億円（シェア13％）。上限（死亡300万円・医療80万円）があるため、
**「大きな保障」ではなく「入りやすさ」「用途の明確さ」で成立する商品**に寄る。

| 類型                            | なぜ少短で成立するか                                                                                                                                |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| 葬儀保険（死亡数十万〜300万円） | 葬儀費用という **金額の決まった支出**に狙いを絞る。高齢でも申し込みやすい設計が多い → [冠婚葬祭](../../15_サービス・生活関連/20_冠婚葬祭/README.md) |
| 引受基準緩和型の医療            | 持病がある人向け。1年更新なので引受判断を毎年やり直せる                                                                                             |
| 妊娠中でも入れる医療            | [生命保険](../07_生命保険/README.md)では引受が難しい時期に、期間を区切って提供                                                                      |
| 特定の職域・団体向け            | 会員組織に紐づけて販売する                                                                                                                          |

保険期間が1年で更新のたびに条件を見直せるため、**長期の予定を立てなくてよい**のが引受上の強みになる。
半面、保険料控除の対象外で、契約者保護機構もない（→ [①](01_少額短期保険という制度.md)）。

## 7. 誰がやっているか — 4類型

2026年6月10日時点の登録業者は121社（日本少額短期保険協会の登録一覧）。
社名を並べても意味がないので、**親会社と本業チャネルの組み合わせ**で分類する。

| 類型                           | 何が狙いか                                                                                           | 例（社名は登録一覧・各社公表による）                                                                                                                                                                                                                                |
| ------------------------------ | ---------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **① 不動産・賃貸系**           | 自社の管理物件・仲介網に家財保険を乗せ、手数料を取り込む                                             | スターツ少額短期保険（スターツグループ）、セキスイハイム不動産少額短期保険、全管協少額短期保険（賃貸管理業界団体系）、東急少額短期保険                                                                                                                              |
| **② 大手保険グループの子会社** | 本体では採算に乗らない小口を受け、**リスクは親へ再保険で戻す**。チャネル（不動産・ペット）を押さえる | 東京海上ミレア／東京海上ウエスト／Tokio Marine X（東京海上）、アイアル少額短期保険（住友生命グループ、2019年8月に子会社化）、リトルファミリー少額短期保険（あいおいニッセイ同和損保）、第一スマート少額短期保険（第一生命）、ニッセイプラス少額短期保険（日本生命） |
| **③ 事業会社・異業種の参入**   | **自社の顧客接点**に保険を付ける。保険単体では儲けず、本業のLTVを上げる                              | 楽天少額短期保険、au少額短期保険（KDDI）、イオン少額短期保険、ソニー少額短期保険、USEN少額短期保険、SBIリスタ少額短期保険                                                                                                                                           |
| **④ 独立系・専業**             | ニッチ特化。比較サイトやネット直販に依存                                                             | ペット専業各社、葬儀保険専業、弁護士費用保険の専業など                                                                                                                                                                                                              |

```
【類型ごとの「強さの源」】

  ①不動産系   ── 強さ＝物件と入居者への独占的な接点。弱さ＝管理戸数の頭打ち
  ②大手子会社 ── 強さ＝親の資本と再保険、50億円の壁を回避できる
                 弱さ＝親のガバナンス基準で動くので身軽さは失う
  ③事業会社系 ── 強さ＝既存顧客基盤。弱さ＝保険の専門人材が社内にいない
  ④独立系     ── 強さ＝商品の尖り。弱さ＝チャネルがなく、50億円どころか黒字化が壁
```

金融庁は2026年8月の保険モニタリングレポートで、
「ガバナンスが脆弱な少短業者も多く」「赤字経営から脱却できず、財務面に課題を抱える少短業者が一定程度存在している」と指摘している。
**④の層に課題が集中している**と読める。

### 参入の経済性 — なぜ1年で作れるのか

最低資本金1,000万円（実際には運転資金を含め数億円規模を用意するのが通例とされる）、登録制、
商品は届出中心。**新規設立**と**既存少短のM&A**の2ルートがあり、いずれも1年程度で開業可能と解説される。
M&Aが選ばれるのは **登録と体制をまとめて買える**から。賃貸家財分野では、成熟市場でシェアを取る手段として
M&Aが使われた例が報じられている（全国賃貸住宅新聞、東京海上グループによる少短2社の買収）。
なお登録審査では、保険計理人を含む**人的構成**が重点的に見られる。

## 8. この業界の天井と弱点

```
【少短ビジネスの3つの天井】

  ① 規模の天井：年間収受保険料50億円
       → 出再か共同保険でかわすには「親」が要る。独立系には本当の天井

  ② チャネルの天井：本業の接点の数
       → 管理戸数・携帯契約数・ペット販売頭数が増えなければ契約も増えない
       → 家財の伸びが104％にとどまるのはこれ

  ③ 信用の天井：契約者保護機構がない・保険料控除もない
       → 「保険会社と同じ」とは言えない。大きな保障の競争には出られない
```

さらに、収益源が保険引受だけ（資産運用は安全資産に限定）なので、
**損害率が跳ねた年を運用益で埋めることができない**。
自然災害の増加や修理費インフレは、少短にとって大手損保よりも直撃になりやすい。

## 9. 用語メモ

| 用語                             | 意味                                                                                                   |
| -------------------------------- | ------------------------------------------------------------------------------------------------------ |
| **家財保険（賃貸入居者向け）**   | 家財の損害＋借家人賠償責任＋個人賠償責任の3点セット。少短の収入保険料の59％（2025年度）                |
| **借家人賠償責任**               | 火災・水漏れなどで借りている部屋（大家の所有物）を壊したときの賠償責任。大家側が加入を求める最大の理由 |
| **募集代理店**                   | 保険の販売を行う者。少短では不動産会社・携帯ショップなど**本業の事業者**が兼ねることが多い             |
| **損害率**                       | 支払保険金÷収入保険料。賃貸家財は20％前後と極端に低い                                                  |
| **事業費率**                     | 事業費÷収入保険料。代理店手数料が中心。賃貸家財は70％前後と極端に高い                                  |
| **コンバインドレシオ（合算率）** | 損害率＋事業費率。100％超で保険引受は赤字                                                              |
| **低発生率保険**                 | 地震費用保険など、発生頻度が低い事象を対象とする区分。上限1,000万円                                    |
| **キャンセル費用保険**           | 旅行・宿泊・イベントの取消料を補償する保険。費用分野の成長ドライバー                                   |
| **孤独死保険**                   | 賃貸室内での死亡に伴う原状回復・遺品整理費用等を補償。大家向けと入居者向けがある                       |
| **引受基準緩和型**               | 告知項目を絞り、持病がある人でも加入しやすくした商品設計                                               |
