# 論点（民業補完と民業圧迫）

このノートで分かること：政府系金融をめぐって何が争われているのか。
民業圧迫、完全民営化、政策目的と収益性、モラルハザード、経済安全保障という5つの論点について、
**どちらの立場にも成り立つ理屈がある**ことを整理する。

> 前提：ここで扱う論点は、政治的な評価が割れるテーマである。
> このノートは**どちらが正しいかを結論づけない**。それぞれの主張がどんな前提に立っているかを示し、
> 数字や制度のどこを見れば議論を追えるかを書く。

## 1. 論点マップ

| 論点 | 「縮めるべき」側の主張 | 「必要だ」側の主張 | 争点の核 |
| --- | --- | --- | --- |
| **民業圧迫** | 民間が貸せる先まで低利で奪っている | 民間が貸さない先を拾っているだけ | 境界線を誰がどう測るか |
| **完全民営化** | 株式会社化した以上、政府出資は引き揚げるべき | 危機に備える主体を市場に委ねられない | 危機の頻度をどう見るか |
| **収益性** | 赤字を垂れ流す組織は規律を欠く | 赤字は政策コストであり成果指標ではない | 何を成功と定義するか |
| **モラルハザード** | 保証と低利が借り手・貸し手の規律を緩める | 規律を優先すると救えるはずの企業が潰れる | 選別の精度をどこまで求めるか |
| **経済安全保障** | 産業政策の名で歯止めなく膨らむ | 民間だけでは供給網を守れない | 「安全保障」の範囲の広さ |

## 2. 民業圧迫という批判

### 何が問題とされてきたか

民間金融機関側（とくに地銀・信金と全国銀行協会）から繰り返し指摘されてきたのは、
おおむね次のような具体的な場面である。

| 指摘されるパターン | 中身 |
| --- | --- |
| 優良先への横取り | 民間が育てた業績の良い取引先に、政府系が低利で提案して乗り換えさせる |
| 利子補給による実質ゼロ金利 | 自治体等の利子補給と組み合わせ、民間が出せない金利水準を提示する |
| 危機対応の長期化 | 危機の認定が続き、緊急のはずの制度融資が平時にも残り続ける |
| 長期・固定の条件競争 | 民間が資金調達の制約で出せない20年超・固定の条件を提示する |

会計検査院が政府系金融の「民業圧迫」について異例の調査に乗り出したと報じられたのは2018年で、
論争としては**20年以上続いている古い争点**である。
近年でも日本総研などのシンクタンクが、中小企業向け政策金融について
逆選択（悪い借り手ばかり集まる状態）と民業圧迫を同時に避ける枠組みの必要性を提言している。

### 反論の側の理屈

一方で、政策金融側および中小企業団体の側からは次のような反論が置かれる。

- **民間が貸すようになったのは、政府系が先に貸して実績を作ったからだ**という順序の主張。
  創業直後に公庫が貸し、数年後に地銀が入る、という流れは実際に多い
- **低利は結果であって狙いではない**。調達コストが低いのは資金源が財投だからで、
  同じ条件を出せない民間の側の制約でもある
- **危機時に「貸すな」とは言えない**。緊急時の蛇口の閉め方が遅いという批判は成り立つが、
  閉めるのが早すぎたときの批判はもっと強くなる
- 日本公庫の側からは、民間金融機関との**協調融資**や情報連携の枠組みを広げることで
  対応する、という方向が示されてきた

### 議論を追うときの見どころ

「圧迫かどうか」は感覚では決まらない。次のような指標を見れば、議論の土俵が具体的になる。

```
   境界線をどこで測るか

   ①【貸出先の重複度】      政府系と民間の両方から借りている企業の割合は？
   ②【協調か単独か】        協調融資の比率が上がっているか、単独案件が増えているか
   ③【金利差】              同じ信用力の借り手に対する金利の開き
   ④【期間】                民間が出せない年限に集中しているか
   ⑤【局面】                危機認定の期間と、平時に戻ってからの残高の落ち方
       │
       └─ ①〜⑤のどれを重視するかで、同じ数字が「補完」にも「圧迫」にも見える
```

> ポイント：この論争が決着しないのは、**「民間が貸せない」の定義が状況依存だから**である。
> 金利が上がれば民間が貸せる範囲は広がるし、景気が悪化すれば狭まる。
> 境界線そのものが動くので、固定的な線引きは原理的に難しい。

## 3. 完全民営化の議論と、その揺り戻し

2000年代の政策金融改革では、DBJと商工中金を**完全民営化する**方針が決まっていた。
しかし実際の歩みは、危機のたびに止まってきた。

| 年 | 出来事 | 民営化への影響 |
| --- | --- | --- |
| 2008年 | DBJ・商工中金が株式会社化。完全民営化の方針が法律に書かれる | 前進 |
| 2008〜2009年 | リーマン・ショック。危機対応業務が大規模発動 | 民営化時期が先送りに |
| 2011年 | 東日本大震災 | さらに先送り |
| 2015年 | 改正法施行。完全民営化の方針は維持しつつ、**当分の間**DBJに危機対応業務を義務づけ | 条件付きで維持 |
| 2016〜2017年 | 商工中金の危機対応融資で不正（制度要件を満たさない案件の実行）が発覚 | 民営化論が再燃 |
| 2020〜2022年 | コロナ禍 | 実質的に停止 |
| **2025年6月** | **商工中金が完全民営化**。政府保有株の処分が完了し、改正法が施行 | 実現（ただし条件付き） |
| 2026年9月 | 商工中金が約5.5億株・約912億円の自社株を中小企業組合等へ売り出すと発表 | 民営化後の資本再構築 |

### 「完全民営化」でも残るもの

商工中金の例が分かりやすい。**出資関係としては民営化されたが、性格は完全には民間化していない**。

| 項目 | 民営化後の扱い |
| --- | --- |
| 政府出資 | なくなった（2025年6月） |
| 危機対応業務 | **法律上の責務として残る** |
| 株主資格 | 中小企業組合等に限定する制限が残る |
| 特別準備金 | 維持 |

これをどう評価するかが分かれる。
「危機対応の担い手を確保したまま出資を引き揚げた現実解」と見る立場と、
「実質は政策金融のままで、名前だけ民営化した」と見る立場が併存する。

DBJについては、完全民営化の方針は法律上維持されているものの、
危機対応業務の義務づけが「当分の間」続き、**特定投資業務**（産業投資を原資に成長資金を
時限的・集中的に供給する業務）の投資決定期限も2031年3月末まで、
業務完了期限も2041年3月末まで延長された。期限の延長が繰り返されている状態である。

```
   完全民営化のジレンマ

        危機対応の担い手が必要 ──▶ 政府の関与を残す ──▶ 民営化できない
                ▲                                              │
                │                                              ▼
                └──── 危機は周期的に来る ◀──── 民間だけでは足りない局面が再来
                                     │
        「危機の間隔」＜「民営化に必要な年数」 である限り、この輪は閉じない
```

## 4. 政策目的と収益性の両立

政府系金融の決算を「黒字か赤字か」だけで評価すると、議論が噛み合わなくなる。
**赤字であることが目的に沿っている場合がある**からである。

| 見方 | 主張 | 弱点 |
| --- | --- | --- |
| 収益重視 | 赤字を続ける組織は非効率で、規律が働かない。市場からの調達コストに見合う運営をすべき | 民間が貸せる先を取りにいく動機が生まれ、民業圧迫に近づく |
| 政策効果重視 | 赤字は政策の値段。救えた雇用や事業の数で測るべき | 効果の測定が難しく、失敗が隠れやすい |

実際の数字で見ると、日本公庫の2026年3月期は2,925億円の最終赤字で、
与信関係費用は3,344億円と前期比28%増えた（日経報道ベース）。
小規模事業者でコロナ後の経営改善に時間がかかっていることが理由とされる。

```
   同じ数字の2通りの読み方

   与信関係費用 3,344億円（+28%）
        │
        ├─▶【A】危機時に十分な審査なく貸した結果。政策金融の規律が甘かった証拠
        │
        └─▶【B】民間が貸さない先に貸したのだから、損失が出るのは設計どおり。
               むしろ損失が出ていないなら民間と同じことをしている疑いがある

   A・Bのどちらが妥当かは、「損失が出た先が、そもそも救うべき先だったか」による。
   そしてそれは事後的にも判定が難しい。
```

> ポイント：政策金融の評価指標は、民間銀行と同じROEや不良債権比率では足りない。
> かといって「救った企業数」だけでは、救うべきでなかった企業を救った分も成果に数えられてしまう。
> **評価指標の設計そのものが論点である**、というのが実務・学術双方での共通認識に近い。

## 5. モラルハザード

モラルハザードとは、**保険や保証があることで、当事者の注意が緩むこと**をいう。
政策金融では、3つの層すべてで起きうる。

| 誰の | どんな緩みか | 表面化するとき |
| --- | --- | --- |
| **借り手** | 無利子・無担保なら借りられるだけ借りる。事業改善の先送り | 返済開始後に返せず、リスケや倒産に |
| **貸し手（民間）** | 100%保証なら焦げ付いても損しないので、審査が形式化する | 代位弁済の急増として表れる |
| **制度の設計者** | 短期の景気対策として使いやすいため、出口を決めずに始めてしまう | 危機の認定が長期化し、平時に戻せなくなる |

責任共有制度（保証協会80%・金融機関20%）は、2番目の層に手を打つ仕組みだった。
ただし危機時には100%保証が復活し、規律は再び緩む。
**危機対応の速さと規律の維持は、原理的にトレードオフ**になっている。

反対側の理屈も明確である。
危機の最中に「規律のために選別する」と言えば、選別の誤りで潰れる企業が必ず出る。
スピードを優先すれば筋の悪い先も通るが、遅らせれば救えた先が消える。
**どちらの誤りをより嫌うか**という価値判断が入るため、この論点も技術的には決着しない。

## 6. 経済安全保障による役割の再拡大

2020年代後半、政策金融が再び拡大する理由として前面に出ているのが**経済安全保障**である。

| 領域 | 何を政策金融がやるか | 民間だけでは難しい理由 |
| --- | --- | --- |
| 重要鉱物・鉱山権益 | JBICによる権益取得・開発への出融資 | 資源国の政治リスクと20年超の回収期間 |
| 半導体・サプライチェーン | 大型設備投資への長期資金、出資 | 投資額が巨大で、市況の振れが大きい |
| エネルギー安全保障 | LNG・発電案件への出融資 | 中東情勢など地政学リスクの引受先がない |
| 日米戦略投融資 | JBICが2026年に日米戦略投融資部門を新設（2025年9月の日米覚書に基づく） | 政府間合意を前提とする案件の実行主体が必要 |
| スタートアップ | DBJの特定投資業務、公庫の資本性ローン | 成長資金の供給が民間だけでは細い |

ここでも評価は割れる。

- **肯定的な見方**：供給網の寸断や資源の囲い込みは市場の失敗そのものであり、
  民業補完の原則にむしろ忠実である。民間銀行が単独で20年のカントリーリスクを取れない以上、
  政策金融がなければ案件自体が成立しない
- **懐疑的な見方**：「経済安全保障」は定義が広く、産業政策の別名として使えば、
  何でも民業補完の理屈が立ってしまう。かつての護送船団や産業育成金融への回帰にならないか

```
   政策金融の「守備範囲」はどう動いてきたか

   1990年代  [────────── 広い（産業育成金融）──────────]
   2000年代  [──── 縮める（改革・民営化）────]
   2010年代  [──── 危機対応で戻る ────────────]
   2020年代前半 [──────── コロナで最大化 ────────────────]
   2020年代後半 [──── 経済安全保障で再拡大 ──────────]
                 ▲
                 └─ 縮小の理屈（民業補完）と拡大の理屈（市場の失敗）は
                    同じ言葉で説明できてしまう。だから振れ幅が大きい
```

## 7. 論点を読むときの心得

- **「民業圧迫か補完か」は、金利水準と景気局面で答えが変わる**。金利のある世界に戻った
  2020年代後半は、民間が貸せる範囲が広がるため、境界線は民間側に有利に動きやすい
- **決算の赤字は、それ自体では良し悪しを決めない**。どの局面の貸出から出た損失かを見る
- **制度名の変更が多い**。同じ制度が数年で名前を変えるので、古い記事の制度名で判断しない
- **危機対応は「開ける」議論より「閉じる」議論のほうが難しい**。出口の設計が論点の中心にある

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **民業圧迫** | 政府系金融機関が、民間金融機関が対応できる領域にまで踏み込み、民間の取引を奪っているとする批判 |
| **逆選択** | 良い借り手が離れ、リスクの高い借り手ばかりが集まってしまう状態。情報の非対称性から生じる |
| **モラルハザード** | 保証や保険があることで、借り手・貸し手の注意や規律が緩むこと |
| **完全民営化** | 政府出資をなくし、通常の株式会社とすること。商工中金は2025年6月に実現したが、危機対応義務と株主資格制限は残る |
| **特定投資業務** | DBJが産業投資を原資に成長資金を時限的・集中的に供給する業務。投資決定期限は2031年3月末、業務完了期限は2041年3月末まで延長された |
| **利子補給** | 国や自治体が借入金利の一部を肩代わりし、借り手の実質負担を下げる措置 |
| **協調融資** | 政府系金融機関と民間金融機関が同一案件に一緒に融資すること。民業圧迫批判への実務的な答えとされる |
| **責任共有制度** | 信用保証協会と金融機関がリスクを80対20で分担する仕組み。2007年導入 |
| **経済安全保障** | 重要物資の供給網や技術の確保を安全保障の観点から進める政策領域。政策金融の新しい拡大根拠になっている |
