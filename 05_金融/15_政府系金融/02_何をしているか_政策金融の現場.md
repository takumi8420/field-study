# 何をしているか（政策金融の現場）

このノートで分かること：政府系金融機関が平時と危機時でどう働き方を変えるのか。
創業融資・マル経融資・信用補完・輸出金融・フラット35という代表的な5つの業務が、
それぞれどういう理屈で成立しているのか。

> 結論：政策金融の仕事は、**平時は「細く長い補完」、危機時は「太く短い注入」**の二本立てである。
> 平時の残高は地味だが、危機のたびに桁が変わる。この振れ幅の大きさが、
> 収益や不良債権の数字を歪め、民営化議論をこじらせる原因にもなっている。

## 1. 平時と危機時、二つの顔

```
   融資実行額
      ▲
      │                    ┏━━━━━━┓                    ┏━━━━━━━━━━┓
      │                    ┃リーマン ┃                    ┃  コロナ禍   ┃
      │                    ┃2008-09 ┃   ┏━━━┓        ┃ 2020-2022  ┃
      │                    ┗━━━━━━┛   ┃震災 ┃        ┗━━━━━━━━━━┛
      │                                  ┃2011┃              │
      │  ～～～～～～～～～～～～～～～～┗━━━┛～～～～～～～┴～～～～～～▶
      │   平時：創業融資・設備資金・マル経                 平時に戻る（が残高は残る）
      └────────────────────────────────────────────▶ 時間

      平時＝民間が拾わない小口・長期を細く出す
      危機＝民間が一斉に引くので、政府系が数年分を一気に出す
      危機の後＝ふくらんだ貸出が数年かけて不良債権として顕在化する ← 今ここ（2020年代後半）
```

政府系金融機関の決算を読むときは、**「どの局面の残高を見ているか」**を意識しないと誤読する。
たとえば日本公庫の2026年3月期は2,925億円の最終赤字（前期も2,008億円の赤字、日経報道ベース）で、
与信関係費用は3,344億円と前期比28%増えた。これは新規の失敗ではなく、
**コロナ期に膨らんだ貸出の後始末が今出ている**と読むのが自然である。

## 2. 危機対応という法定業務

「危機対応業務」は、**内外の金融秩序の混乱や大規模災害が起きたとき、
主務大臣が危機を認定し、指定金融機関が資金を供給する**という法律上の枠組みである。
指定金融機関はDBJと商工中金で、日本公庫がその**ツーステップローン**（日本公庫が
指定金融機関に資金を貸し、指定金融機関が企業に貸す二段構えの融資）や損害担保で裏側を支える。

| 危機 | 時期 | 政策金融が出したもの | 後に残った問題 |
| --- | --- | --- | --- |
| リーマン・ショック | 2008〜2009年 | 危機対応融資、CP買取、大企業向け劣後ローン | 民営化方針の事実上の凍結 |
| 東日本大震災 | 2011年〜 | 復興緊急保証、二重債務対策、災害復興住宅融資 | 債権買取機構の後始末 |
| コロナ禍 | 2020〜2022年 | 実質無利子・無担保融資（ゼロゼロ融資）、資本性劣後ローン | 返済開始後の倒産増、与信費用の膨張 |

この構造には、**危機の認定を政府が行う**という特徴がある。
つまり「いつ蛇口を開け、いつ閉めるか」は政治判断であり、
閉めるタイミングが遅れると民業圧迫批判に直結する（→[03 論点](03_論点_民業補完と民業圧迫.md)）。

## 3. ゼロゼロ融資とその後始末

コロナ禍で実行された「実質無利子・無担保」融資は、**2つのルートで流れた**。
この2ルートの違いが、後始末の姿の違いを生んでいる。

```
   【政府系ルート】                        【民間ルート】

   中小企業                                中小企業
      │ 申込                                  │ 申込
      ▼                                       ▼
   日本公庫・商工中金                      地銀・信金・メガバンク
      │ 直接融資（無担保・利子補給）           │ 融資
      │                                       ▼
      │                               信用保証協会が100%保証
      │                                       │ 都道府県が利子補給
      ▼                                       ▼
   リスクは公庫が直接抱える            リスクは保証協会→日本公庫の信用保険へ
      │                                       │
      ▼                                       ▼
   決算上の与信関係費用として表面化     代位弁済として表面化（銀行の損失にはなりにくい）
```

**どちらのルートでも、最終的なリスクの多くは国に戻ってくる**のが要点である。
民間ルートは一見「銀行が貸した」ように見えるが、100%保証が付いていれば
焦げ付きは保証協会が肩代わりし、その大半をさらに日本公庫の信用保険が受ける。

後始末の足元は、次のような状況である（いずれも東京商工リサーチ集計・報道ベース）。

| 時点 | ゼロゼロ融資利用後倒産 |
| --- | --- |
| 2025年通年 | 433件（東京商工リサーチ）／636件（帝国データバンク）。集計母数が異なる |
| 2026年1月 | 28件。9か月ぶりの20件台 |
| 2026年2月 | 27件 |
| 2026年4月 | 21件。4か月連続で前年同月を下回る |
| 累計（2020年7月〜2026年4月） | 約2,333件 |

件数だけ見れば小康状態だが、**利益で返せず返済猶予（リスケジュール）に逃げている企業**が
どれだけ潜んでいるかは統計に出ない。倒産件数の落ち着きを「終わった」と読むのは早い、
というのが実務側の一般的な見方である。

## 4. 創業融資とマル経融資

平時の日本公庫の看板商品が、**創業融資**と**マル経融資**である。
どちらも「民間が貸しにくい理由」がはっきりしているところが、民業補完の教科書的な例といえる。

| 制度 | 相手 | 民間が貸しにくい理由 | 制度の作り |
| --- | --- | --- | --- |
| **新規開業・スタートアップ支援資金** | これから創業する人・創業後おおむね7年以内 | 決算書がない、担保がない、事業の継続性が読めない | 2026年時点で上限7,200万円（うち運転資金4,800万円）、無担保・無保証が中心。自己資金要件は撤廃済み |
| **マル経融資（小規模事業者経営改善資金）** | 商工会議所・商工会の経営指導を受けた小規模事業者 | 1件あたりが小さすぎて銀行の採算に乗らない | 無担保・無保証人。**商工会議所の推薦が前提**で、指導とセットになっている |
| **資本性ローン** | 創業期・再生期の企業 | 債務超過に見える企業に追加で貸しにくい | 期中は利息のみ、元本は期限一括返済。金融機関の審査上は資本とみなされやすい |

> ポイント：マル経融資の本質は「**お金より前に指導が付いてくる**」ことにある。
> 商工会議所の経営指導員が帳簿を見て推薦するので、審査コストの一部を公的インフラが肩代わりしている。
> これは民間銀行の融資では再現しにくい仕組みである。

創業融資は、2024年に「新創業融資制度」が廃止され「新規開業資金」に統合、
2025年3月に「新規開業・スタートアップ支援資金」へ名称変更という経緯をたどっている。
制度名が頻繁に変わるので、**古い記事の制度名をそのまま信じない**のが読み方のコツである。

## 5. 信用補完＝表に出ない最大の仕事

日本公庫の中小企業事業が担う**信用保険**は、金額の規模でいえば直接融資より大きな影響を持つ。
これは「貸す」のではなく「貸せるようにする」仕事である。

```
   平時のリスク分担

   企業が1,000万円借りて返せなくなった場合（責任共有制度・保証割合80%のケース）

   ┌──────────────────────────────────────────┐
   │ 損失 1,000万円                                             │
   ├──────────────────────┬───────────────────┤
   │ 信用保証協会が代位弁済 800万円 │ 銀行が自ら負担 200万円 │
   ├──────────────────────┤                       │
   │   うち日本公庫の信用保険が     │  ← 銀行に審査の動機を   │
   │   協会へ保険金（7〜8割）        │    残すための設計       │
   └──────────────────────┴───────────────────┘

   危機時（コロナのゼロゼロ融資等）は保証割合100%になり、銀行の負担はゼロに近づく
        ↓
   審査をしなくても損しない ＝ モラルハザードの温床（→03 論点）
```

**責任共有制度**とは、原則として保証協会80%・金融機関20%でリスクを分け合う仕組みで、
2007年に導入された。それ以前の100%保証では、銀行が中身を見ずに貸す誘因が強すぎたためである。
ところが危機時には再び100%保証が復活する。危機対応の必要性と規律の維持は、
構造的にトレードオフの関係にある。

## 6. 輸出金融と資源確保

国内向けが日本公庫・商工中金の仕事だとすれば、**海外向けはJBICとNEXIの仕事**である。
二つはよく混同されるが、**片方は貸し、片方は保険をかける**という分担になっている。

| | JBIC（国際協力銀行） | NEXI（日本貿易保険） |
| --- | --- | --- |
| 機能 | 融資・出資・保証 | 保険の引受 |
| 典型案件 | 海外発電所、LNG、鉱山権益取得、半導体工場 | 輸出代金の回収不能、海外投資の接収リスク |
| リスクの取り方 | 自らが債権者になる | 民間銀行や輸出企業の損失を補償する |
| 相手 | 相手国政府・プロジェクト会社・日本企業の海外子会社 | 輸出企業・融資する銀行 |
| 拠り所 | 民間だけでは組成できない長期・大型案件 | カントリーリスク（戦争・送金制限・為替制限）は民間保険が引き受けにくい |

JBICの案件は、**相手国政府との交渉力を含めて「日本国の信用を貸す」**という性格がある。
資源国の巨大プロジェクトで日本企業が権益を取るとき、
民間銀行だけでは20年の融資も政治リスクの引受もできない。そこにJBICが入る。

NEXIが引き受ける「非常危険」（戦争・革命・為替制限など、取引先の経営とは関係なく
代金が回収できなくなるリスク）は、損害保険会社が商業ベースで引き受けにくい典型例である
（保険の一般的な成立条件は [損害保険](../08_損害保険/README.md) を参照）。

2026年6月に公表されたJBICの事業運営計画では、
**鉱山権益取得・半導体関連といった資源獲得とサプライチェーン強靱化**、
中東情勢を背景としたエネルギー安全保障、スタートアップ支援が重点として挙げられている。
2025年9月の日米間の覚書を受けて**日米戦略投融資部門**も新設された。
経済安全保障が政策金融の新しい拡大理由になっている、という流れである
（→[04 直近トピック 2026](04_直近トピック_2026.md)）。

## 7. フラット35＝貸さずに支える住宅ローン

住宅金融支援機構は、**自分では住宅ローンを貸さない**（災害復興融資などの例外はある）。
かつての住宅金融公庫は直接融資の主力だったが、2007年の改組で
「**証券化支援**」というまったく違うモデルに転換した。

```
   【買取型フラット35の流れ】

   ① 個人が民間金融機関で住宅ローンを借りる
        個人 ──────▶ 銀行・モーゲージバンク
                           │
   ② 機構がそのローン債権を買い取る
                           ▼
                    住宅金融支援機構
                           │
   ③ 買い取った債権をまとめて担保に債券（MBS）を発行
                           ▼
                    機関投資家（生保・年金・銀行）
                           │
   ④ 個人の返済 ─────────┘ が債券の利払い原資になる

   結果：銀行は35年の金利リスクを抱えずに長期固定ローンを出せる
         個人は35年固定という商品を選べる
         金利リスクは投資家が負う
```

**この仕組みがなぜ要るのか**が要点である。
銀行の資金調達は預金（短期）なので、35年固定で貸すと金利上昇時に逆ざやになる。
だから民間だけでは長期固定住宅ローンが供給されにくい。
機構が債権を買い取って投資家に流すことで、**金利リスクの引受先を作っている**わけである。

| 型 | 仕組み | 誰がリスクを持つか |
| --- | --- | --- |
| **買取型** | 機構がローン債権を買い取り、MBSを発行 | 信用リスクは機構、金利リスクは投資家 |
| **保証型** | 民間が保有したまま、機構が保険を付け、民間が債券を発行 | 民間が主体。機構は保険で支える |

2026年には制度が拡充され、融資限度額が8,000万円から**1億2,000万円**へ引き上げられた
（住宅価格上昇への対応、報道ベース）。床面積要件の緩和や借換規定の拡充も併せて行われている。
住宅ローン市場全体で見れば変動金利が主流であり、フラット35のシェアは大きくないが、
**長期固定という選択肢を市場に残すための装置**として位置づけられている。

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **危機対応業務** | 主務大臣が危機を認定したときに、指定金融機関（DBJ・商工中金）が資金を供給する法定業務 |
| **ツーステップローン** | 日本公庫が指定金融機関に資金を貸し、指定金融機関が企業に貸す二段構えの融資 |
| **ゼロゼロ融資** | コロナ禍の実質無利子・無担保融資。政府系の直接融資と、信用保証協会100%保証＋自治体の利子補給による民間ルートの2系統があった |
| **責任共有制度** | 信用保証協会80%・金融機関20%でリスクを分担する仕組み。2007年導入。銀行に審査の動機を残す狙い |
| **代位弁済** | 借り手が返せないとき、信用保証協会が金融機関へ残債を肩代わりして支払うこと |
| **マル経融資** | 小規模事業者経営改善資金。商工会議所・商工会の経営指導と推薦を前提とする無担保・無保証人の融資 |
| **資本性ローン** | 期中は元本返済がなく期限に一括返済する融資。審査上は資本とみなされやすい |
| **証券化支援** | 住宅ローン債権を買い取り、まとめて債券（MBS）として投資家に売る仕組み。金利リスクを投資家に移す |
| **MBS** | Mortgage-Backed Securities。住宅ローン債権を裏付けとする証券 |
| **非常危険** | 戦争・革命・送金制限など、取引先の信用とは無関係に代金が回収できなくなるリスク。貿易保険の中核 |
| **リスケジュール（リスケ）** | 返済条件の変更。元本返済の猶予など。倒産統計には現れない |
