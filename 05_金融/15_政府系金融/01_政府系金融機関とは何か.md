# 政府系金融機関とは何か

このノートで分かること：政府系金融機関が何を建前に存在しているのか、6つの機関がどう役割を
分けているのか、そしてそのお金がどこから来ているのか（財政投融資という仕組み）。

> 結論：政府系金融機関とは、**「民間が貸せないところに貸す」ことを法律で義務づけられた金融機関**である。
> だから、民間銀行と同じことをすれば「民業圧迫」と批判され、
> 民間が逃げる局面では「もっと貸せ」と求められる。この非対称性が業界のすべてを規定している。

## 1. 民業補完という建前

政府系金融機関を理解する鍵は「**民業補完**（みんぎょうほかん）」という4文字である。
民間金融機関の業務を補う、という意味で、各機関の根拠法に明記されている考え方だ。

なぜこんな建前が要るのか。理屈はこうである。

- 銀行はリスクに見合う金利を取れなければ貸さない。当たり前の商売の判断である
- ところが世の中には、「社会的には価値があるのに、民間の採算では貸せない」案件がある
  - 創業したての会社（実績も担保もない）
  - 数十年単位で回収する巨大インフラ（民間の融資期間より長い）
  - 政情不安な国での資源開発（カントリーリスクが読めない）
  - 金融危機の最中の資金繰り（民間が一斉に貸し渋る）
- そこに政府の信用を使って資金を流すのが政策金融、というのが建前

裏返すと、**民間が普通に貸せる案件に政府系が食い込めば、存在理由が崩れる**。
これが後述の「民業圧迫」論争（→[03 論点](03_論点_民業補完と民業圧迫.md)）の出発点になる。

```
        【民間が貸せる領域】              【民間が貸せない領域】
   ┌──────────────────────┐  ┌──────────────────────┐
   │ 担保がある／実績がある／   │  │ 創業直後／超長期／      │
   │ 回収期間が5〜10年／国内    │  │ カントリーリスク／危機時 │
   │                          │  │                        │
   │   メガバンク・地銀・信金   │  │   政 府 系 金 融 機 関   │
   └──────────────────────┘  └──────────────────────┘
              ▲                              ▲
              │                              │
        利ざやで稼ぐ                  政策目的で貸す（赤字も許容）
              │                              │
              └──── この境界線が動くたびに論争になる ────┘
```

## 2. 6つの機関の役割分担

日本で「政府系金融機関」と呼ばれるのは、おおむね次の6つである。
それぞれ**対象とする借り手**と**根拠法**が違う。

| 機関 | 略称 | 主な相手 | やっていること | 政府の関与 |
| --- | --- | --- | --- | --- |
| **日本政策金融公庫** | 日本公庫／JFC | 小規模事業者、中小企業、農林漁業者 | 小口の事業資金、創業融資、農林漁業融資、信用保険 | 政府全額出資の株式会社 |
| **日本政策投資銀行** | DBJ | 大企業、インフラ事業 | 長期の設備資金、メザニン（劣後ローン等）、投資 | 政府全額出資。完全民営化は先送り中 |
| **国際協力銀行** | JBIC | 海外展開する日本企業、資源案件 | 輸出金融、投資金融、資源ファイナンス | 政府全額出資 |
| **商工組合中央金庫** | 商工中金 | 中小企業の協同組合とその構成員 | 中小企業向け融資、危機対応 | **2025年6月に完全民営化**。危機対応義務は残る |
| **住宅金融支援機構** | JHF | 住宅ローンを借りる個人（間接的に） | フラット35の証券化支援、災害復興融資、住宅ローン保険 | 独立行政法人 |
| **日本貿易保険** | NEXI | 輸出・海外投資をする企業 | 貿易保険（代金回収不能・非常危険の引受） | 政府全額出資の株式会社 |

補足として、このほかに**沖縄振興開発金融公庫**（沖縄限定の総合政策金融）があり、
日本公庫との統合が長く議論されている。また地方公共団体向けには
**地方公共団体金融機構**（JFM）が資金を供給しており、広義の政策金融に含めて語られることがある。

### 日本公庫の「3事業」だけは押さえる

日本公庫は6機関のなかで最も裾野が広く、内部が3つの事業に分かれている。
名前が紛らわしいので、この区分だけは覚えておくと読み間違えない。

| 事業 | 旧組織 | 相手 | 融資の典型的な大きさ |
| --- | --- | --- | --- |
| **国民生活事業** | 国民生活金融公庫 | 個人事業主・小規模事業者 | 数百万〜数千万円。1件あたりは小さく件数が膨大 |
| **中小企業事業** | 中小企業金融公庫 | 中堅・中小企業 | 数千万〜数億円。設備資金が中心 |
| **農林水産事業** | 農林漁業金融公庫 | 農業法人・食品産業 | 長期・低利。担い手育成や6次産業化 |

このほか、中小企業事業のなかに**信用保険業務**（信用保証協会の保証を再保険する裏方の機能）が
置かれている。これは融資ではないが、中小企業金融の土台を支える重要な機能である
（→[02 何をしているか](02_何をしているか_政策金融の現場.md) の第5章）。

## 3. お金の出どころ＝財政投融資

政府系金融機関は預金を集めない（商工中金だけは例外的に預金を扱える）。
では原資はどこから来るのか。答えが「**財政投融資**（ざいせいとうゆうし、略して財投）」である。

財投とは、**国が債券を発行して市場から長期資金を借り、それを政策目的の機関に貸す仕組み**のこと。
税金を配る「予算」とは別建てで、あくまで**貸して返してもらう**のが原則である。

```
   ① 市場からお金を借りる              ② 政策機関に回す           ③ 現場に出る

   機関投資家・銀行・個人
        │
        │ 財投債（国債の一種）を買う
        ▼
   ┌──────────────┐    財政融資      ┌──────────────┐   融資   ┌────────┐
   │  国（財政融資資金）  │ ───────────▶ │ 日本公庫／JBIC   │ ──────▶ │ 中小企業 │
   │                    │                │ DBJ／JHF ほか    │          │ 海外案件 │
   └──────────────┘                └──────────────┘          │ 住宅ローン│
        ▲         ▲                          ▲                      └────────┘
        │         │                          │
   産業投資 │    政府保証 │              財投機関債（各機関が自力で発行）
  （NTT株等の配当を原資）  （機関の債券に国が保証）        ↑ 政府保証なし＝市場が機関を評価する
```

財投の資金は3つの経路に分かれる。**この3分類は財投を読むときの基本語彙**である。

| 経路 | 中身 | 性質 |
| --- | --- | --- |
| **財政融資** | 国が財投債で集めた資金を機関に貸す | 有償。金利を付けて返す。財投の主力 |
| **産業投資** | NTT株・JT株の配当等を原資に、機関に出資する | 返済不要の資本。リスクの高い分野に使う |
| **政府保証** | 機関が自分で発行する債券に国が保証を付ける | 国の直接の資金は出ないが、調達金利が下がる |

2001年の財投改革以前は、郵便貯金と年金積立金が自動的に旧大蔵省資金運用部へ預け入れられ、
そこから各機関に流れていた。「**入口で自動的に集まる巨額の資金を、出口で配る**」構造だったため、
非効率な事業に資金が流れ続けると批判された。改革後は、
**市場で財投債を発行して必要額だけ調達する**方式に変わっている。

> ポイント：財投改革の意味は「集まってしまったお金の使い道を探す」から
> 「必要な額だけ市場から借りる」への転換である。市場で借りる以上、
> 事業の採算は市場に見られる。これが政策金融に規律を与える設計になっている。

## 4. 財投債と財投機関債の違い

名前が1文字違いでややこしいが、**信用の出どころがまったく違う**ので区別が要る。

| | 財投債 | 財投機関債 |
| --- | --- | --- |
| 発行体 | 国 | 各政策機関（日本公庫、JHF など） |
| 法的性格 | 国債（普通国債とは区分経理） | 一般の社債に近い |
| 政府保証 | 国そのものの債務 | **なし**（別枠で「政府保証債」がある） |
| 返済原資 | 機関からの貸付回収金 | その機関の事業収益 |
| 市場の見方 | 国債金利で消化 | 機関ごとの信用力で金利が変わる |

財投機関債は、**「政府に頼らず自力で市場から借りてみろ」という規律付けの道具**として導入された。
市場が買わない＝その事業の採算が疑われている、というシグナルになる設計である。
とはいえ実務上は、住宅金融支援機構の発行する住宅ローン担保証券（MBS）のように
財投機関債が主力調達になっている機関もあり、規律の手段というより
資金調達の一形態として定着している面もある。

## 5. 民間銀行とどこが違うのか

同じ「貸す」商売でも、制約条件が根本的に違う。

| | 民間銀行 | 政府系金融機関 |
| --- | --- | --- |
| 資金の出どころ | 預金（短期・低コスト） | 財投・債券発行（長期） |
| 何を最大化するか | 株主への利益 | 法律に書かれた政策目的 |
| 赤字の意味 | 経営の失敗 | 政策コストとして許容されうる |
| 貸出期間 | 多くは5〜10年 | 20〜40年の超長期も可能 |
| 危機時の行動 | 貸出を絞る（合理的） | **貸出を増やす**（義務づけられる） |
| 監督 | 金融庁（銀行法） | 所管官庁＋財務省（各機関の設置法） |
| 自己資本比率規制 | バーゼル規制が直接適用 | 機関により扱いが異なる |

**「危機時に逆方向に動く」**という点が決定的に重要である。
民間銀行が貸出を絞るのは、貸倒れが増えて自己資本が痛むからで、個々の銀行としては正しい判断だ。
しかし全員が同時にそれをやると経済全体が資金不足で止まる（合成の誤謬）。
そこを政府系が埋める、というのが危機対応業務の理屈である
（→[02 何をしているか](02_何をしているか_政策金融の現場.md) の第2章）。

## 6. 歴史：統廃合と民営化の30年

現在の6機関体制は、2000年代の政策金融改革の結果である。
「大きすぎる政策金融を縮める」という方向で進んだが、**危機のたびに揺り戻しがあった**。

| 時期 | 出来事 | 方向 |
| --- | --- | --- |
| 1990年代まで | 郵貯・年金資金を原資に財投が肥大。住宅金融公庫が住宅ローンの主力 | 拡大 |
| 2001年 | 財投改革。郵貯・年金の預託を廃止し、財投債による市場調達へ | 縮小・規律付け |
| 2007年 | 住宅金融公庫を廃止し、住宅金融支援機構へ。直接融資から証券化支援へ転換 | 縮小 |
| 2008年10月 | 国民生活金融公庫・中小企業金融公庫・農林漁業金融公庫・国際協力銀行の一部を統合し **日本政策金融公庫** が発足。DBJ・商工中金は株式会社化し、完全民営化の方針 | 縮小 |
| 2008年〜2009年 | リーマン・ショック。危機対応業務が大規模に発動され、**民営化方針は事実上凍結** | 揺り戻し |
| 2011年 | 東日本大震災。復興向け融資・二重債務対策 | 揺り戻し |
| 2012年 | JBICが日本公庫から再分離し、単独の株式会社に | 再編 |
| 2020年〜2022年 | コロナ禍。実質無利子・無担保融資（ゼロゼロ融資）が空前の規模に | 大幅な揺り戻し |
| 2025年6月 | **商工中金が完全民営化**。ただし危機対応義務・株主資格制限は残る | 縮小 |
| 2020年代後半 | 経済安全保障・サプライチェーン強靱化でJBIC等の役割が再拡大 | 揺り戻し |

> ポイント：**「平時には縮小、危機には拡大」を繰り返してきた**のが日本の政策金融である。
> 完全民営化がなかなか実現しないのは、危機の周期が民営化の工程表より短いから、という見方ができる。

## 7. 信用補完という「貸さない支援」

政府系金融のもう一つの顔は、自分で貸すのではなく**民間が貸せるようにする**仕組みである。
中小企業金融では、この二層構造こそが実態に近い。

```
                  ① 保証を申し込む
   中小企業 ──────────────────▶ 信用保証協会（都道府県等に設置）
      │                                    │
      │ ② 融資                             │ ③ 保証債務を再保険
      ▼                                    ▼
   民間金融機関 ◀────────────── 日本政策金融公庫（信用保険）
   （地銀・信金）   ⑤ 代位弁済               │
                                            │ ④ 保険金（原則7〜8割）
                    ↑ 企業が返せない場合      ▼
                                       最終的なリスクは国（一般会計・保険準備金）へ
```

つまり、地銀や信金が中小企業に貸せているのは、**背後に保証協会と日本公庫の信用保険がある**からで、
政府系金融は「表に出ない土台」としても機能している。
民間側から見た同じ仕組みは
[地方銀行 03 地域経済との関係](../02_地方銀行/03_地域経済との関係.md) に詳しい。

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **民業補完** | 民間金融機関が対応できない分野に限って政策金融が資金を出すという原則。各機関の根拠法に書かれている |
| **財政投融資（財投）** | 国が債券発行等で集めた資金を、政策目的の機関に貸したり出資したりする仕組み。税金を配る予算とは別建てで、返済を前提とする |
| **財投債** | 財政投融資の原資を集めるために国が発行する国債。普通国債とは経理を分けて管理される |
| **財投機関債** | 各政策機関が政府保証なしで自ら発行する債券。市場の評価にさらすことで規律を働かせる狙いがある |
| **政府保証債** | 機関が発行する債券に国が保証を付けたもの。調達金利は下がるが、国の偶発債務になる |
| **産業投資** | NTT株・JT株の配当等を原資とする出資。返済不要の資本としてリスクの高い分野に充てる |
| **危機対応業務** | 金融秩序の混乱や大規模災害時に、政府が指定した金融機関（DBJ・商工中金）が資金を供給する法定の業務 |
| **信用保険** | 信用保証協会の保証債務を日本公庫が再保険する仕組み。中小企業金融の最終的なリスクの受け皿 |
| **資本性ローン** | 期中は元本を返さず期限に一括返済する融資。会計・審査上は資本とみなされやすく、創業期の企業が使う |
| **沖縄振興開発金融公庫** | 沖縄県だけを対象とする総合政策金融機関。日本公庫との統合が長く議論されている |
