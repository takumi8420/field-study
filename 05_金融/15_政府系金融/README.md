# 政府系金融

- 大分類: 金融
- 状態: done
- 更新日: 2026-09-20

政府が全額または一部を出資し、**民間金融機関が貸せない領域に資金を流すことを法律で定められた**
金融機関群。日本政策金融公庫、日本政策投資銀行、国際協力銀行（JBIC）、商工中金、
住宅金融支援機構、日本貿易保険（NEXI）の6機関が中核を成す。
建前は「民業補完」だが、危機のたびに役割が膨らみ、平時には縮小を迫られる。
**この振れ幅の大きさが、この業界のすべてを説明する。**

## 1. 業界の定義・範囲

「政府系金融機関」は法律上の統一された呼び名ではなく、
**政府出資と政策目的の根拠法を持つ金融機関の総称**として使われる慣行上の言葉である。

| 機関 | 形態 | 主な相手 | 所管 |
| --- | --- | --- | --- |
| 日本政策金融公庫（日本公庫） | 政府全額出資の株式会社 | 小規模事業者・中小企業・農林漁業者 | 財務省・経産省・農水省 |
| 日本政策投資銀行（DBJ） | 政府全額出資の株式会社 | 大企業・インフラ | 財務省 |
| 国際協力銀行（JBIC） | 政府全額出資の株式会社 | 海外展開企業・資源案件 | 財務省 |
| 商工組合中央金庫（商工中金） | **2025年6月に完全民営化** | 中小企業組合とその構成員 | 経産省・財務省・金融庁 |
| 住宅金融支援機構（JHF） | 独立行政法人 | 住宅ローンを借りる個人（間接） | 国交省・財務省 |
| 日本貿易保険（NEXI） | 政府全額出資の株式会社 | 輸出・海外投資をする企業 | 経産省 |

隣接領域との境界は次のとおり。

- [地方銀行](../02_地方銀行/README.md)・[メガバンク](../01_メガバンク/README.md)：
  貸す相手が重なる。協調融資のパートナーであり、民業圧迫論争の相手でもある
- **信用保証協会**：47都道府県等に置かれた公的保証機関。政府系金融機関ではないが、
  日本公庫の信用保険と一体で中小企業金融を支える
- **地方公共団体金融機構（JFM）**：地方自治体向けの資金供給。広義の政策金融
- **沖縄振興開発金融公庫**：沖縄限定の総合政策金融。日本公庫との統合が長く議論されている
- [損害保険](../08_損害保険/README.md)：NEXIの貿易保険は、民間損保が引き受けにくい
  非常危険（戦争・送金制限等）を対象とする点で役割が分かれる

## 2. 市場規模と成長性

政策金融の「規模」は、民間の市場規模とは意味が違う。
**毎年の財政投融資計画がその年の上限を示す**ので、ここを見るのが基本である。

| 指標 | 数値 | 時点・出典 |
| --- | --- | --- |
| 令和8年度 財政投融資計画 総額 | 19兆180億円 | 2026年度当初計画・財務省 |
| うち財政融資 | 12兆7,162億円 | 同上 |
| うち産業投資 | 5,003億円 | 同上 |
| うち政府保証 | 5兆8,015億円 | 同上 |
| 経産省関係の財政融資 | 1兆1,870億円（前年度1兆1,491億円） | 2026年度・経済産業省 |
| 日本公庫 最終損益 | ▲2,925億円（前期▲2,008億円） | 2026年3月期・日経報道ベース |
| 日本公庫 与信関係費用 | 3,344億円（前期比＋28%） | 2026年3月期・日経報道ベース |
| ゼロゼロ融資利用後倒産の累計 | 約2,333件 | 2020年7月〜2026年4月・東京商工リサーチ集計 |

成長性という概念はなじまない。**景気が悪いほど仕事が増え、景気が良いほど縮小を迫られる**
逆相関の構造にあるからである。ただし2020年代後半は、
経済安全保障という新しい拡大理由が加わっている点が従来と違う。

※財投計画は年度当初ベース。補正予算で追加されるため、最新は財務省の公表資料で確認する。

## 3. バリューチェーン（お金の流れ）

```
  【集める】                  【回す】                      【出る先】

   機関投資家・銀行・個人
        │ 財投債を買う
        ▼
   国（財政融資資金）─財政融資─┐
                              │
   NTT株等の配当 ─産業投資──┼──▶ 政 府 系 金 融 機 関 ──▶ 小規模事業者・中小企業
                              │      ┌────────────┐      （創業・設備・運転）
   市場（財投機関債）──────┤      │ 審査・政策判断  │ ──▶ 大企業・インフラ
                              │      │ 危機対応       │      （長期・大型）
   政府保証債 ───────────┘      └────────────┘ ──▶ 海外案件・資源
                                          │                    （JBIC・NEXI）
                                          │              ──▶ 住宅ローン
                                          │                    （フラット35）
                            回収・保険料・配当
                                          │
                                          ▼
                            国庫へ戻る／損失は政策コストとして残る
```

民間銀行と違い、**付加価値は「利ざや」ではなく「民間が取れないリスクを取ったこと」に置かれる**。
だから黒字の大きさが成果の指標にならず、評価指標の設計自体が論点になる
（→[03 論点](03_論点_民業補完と民業圧迫.md)）。

## 4. 主要プレイヤーとシェア

| 機関 | 立ち位置 | 特徴 |
| --- | --- | --- |
| **日本政策金融公庫** | 裾野の広さで群を抜く | 国民生活・中小企業・農林水産の3事業＋信用保険。創業融資とマル経融資が看板 |
| **日本政策投資銀行** | 大企業・インフラの長期資金 | 完全民営化の方針は法律上維持。危機対応業務と特定投資業務が期限延長を重ねている |
| **国際協力銀行** | 海外・資源・経済安全保障 | 2026年に日米戦略投融資部門を新設。案件の根拠が政府間合意に寄っている |
| **商工組合中央金庫** | 中小企業組合向け。唯一預金を扱える | 2025年6月に完全民営化。危機対応義務・株主資格制限・特別準備金は残る |
| **住宅金融支援機構** | 自分では貸さない | フラット35の証券化支援でMBSを発行。2026年に融資限度額を1.2億円へ拡充 |
| **日本貿易保険** | 貸さずに保険で支える | 戦争・送金制限など民間損保が引き受けにくい非常危険を担う |

「シェア」という概念は成り立ちにくい。**相手も目的も法律で分けられている**ためで、
競合するのはむしろ民間金融機関との境界線上である。

## 5. 収益モデル・コスト構造

| 項目 | 内容 |
| --- | --- |
| 収益 | 貸出利息、保証料・保険料、投資の配当・キャピタルゲイン |
| 調達コスト | 財政融資の金利、債券の利払い。国債金利に連動するため民間より低い |
| 最大の変動要因 | **与信関係費用**（貸倒引当金の繰入）。危機の数年後に一気に膨らむ |
| 利益率の目安 | 意味をなさない。政策コストとして赤字が許容される設計 |
| 経費 | 店舗網と審査人員。小口を多数さばくため国民生活事業は件数あたりコストが重い |

**危機対応で貸した融資は、数年後に与信関係費用として決算に現れる**。
2026年3月期の日本公庫の赤字はまさにその局面にある
（→[04 直近トピック](04_直近トピック_2026.md)）。

## 6. 競争要因（KSF）と参入障壁

参入障壁は**法律そのもの**である。個別の設置法がなければ存在できない。
そのうえで、各機関が機能するための条件は次の4つに整理できる。

| KSF | 中身 |
| --- | --- |
| **低コストの長期資金** | 財投・政府保証により、民間が出せない期間と金利で貸せる |
| **審査の蓄積** | 小規模事業者の審査ノウハウ、プロジェクトファイナンスの組成力 |
| **政府の信用** | JBICが相手国政府と交渉できるのは国の信用を背負っているため |
| **民間との協調** | 単独で取りにいけば民業圧迫批判を招く。協調融資の設計が実務上の要 |

## 7. 規制・法制度

| 制度 | 内容 |
| --- | --- |
| 各機関の設置法 | 株式会社日本政策金融公庫法、株式会社日本政策投資銀行法など。業務範囲を法律で限定 |
| 財政投融資 | 財政融資資金法等。毎年度の財投計画が国会に提出される |
| 危機対応業務 | 主務大臣が危機を認定し、指定金融機関（DBJ・商工中金）が資金を供給 |
| 信用補完制度 | 中小企業信用保険法。信用保証協会の保証を日本公庫が再保険する |
| 責任共有制度 | 原則として保証協会80%・金融機関20%のリスク分担（2007年導入） |
| 完全民営化の方針 | DBJ・商工中金について法定。商工中金は2025年6月に実現、DBJは期限延長が継続 |
| 貿易保険法 | NEXIの引受範囲と国の再保険の枠組みを定める |

## 8. 最近のトピック

詳細は [04 直近トピック 2026](04_直近トピック_2026.md) にまとめた。要点は次の5つ。

1. **日本公庫が2期連続の最終赤字**。2026年3月期は▲2,925億円、与信関係費用は3,344億円（＋28%）。
   コロナ期に膨らんだ貸出の後始末が決算に出ている（日経報道ベース）
2. **商工中金が2026年9月、約912億円の自社株売出しを発表**。2025年6月の完全民営化時に
   政府株の約9割を自社で落札しており、自己資本の再構築に動いた
3. **令和8年度の財政投融資計画は19兆180億円**（財務省）。経産省関係の財政融資は前年度から増加
4. **JBICが日米戦略投融資部門を新設**（2025年9月の日米覚書に基づく）。
   鉱山権益・半導体・エネルギー安全保障が2026年度の重点分野
5. **ゼロゼロ融資後の倒産は小康状態**（2026年4月は21件、累計約2,333件／東京商工リサーチ集計）。
   ただし借換保証の返済開始ピークが残り、リスケ企業は統計に出ない
