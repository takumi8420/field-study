# 直近トピック（2026年9月時点）

報道・各社IR・業界統計ベースの整理。数値は原則として一次情報（リース事業協会、各社決算開示）を
参照しているが、**報道ベースのものはその旨を明記**した。数値は時点とセットで読むこと。

> この1年のリース業界を一言でいうと：
> **①2027年度の新リース会計基準というカウントダウン、②金利のある世界での調達コスト上昇、
> ③航空機・不動産・再エネという非リース領域での最高益ラッシュ**、の3つが同時に進行している。

## 1. 2027年4月適用の新リース会計基準──業界最大の論点

### 何が決まっているか

企業会計基準委員会（ASBJ）が2024年9月に公表した**企業会計基準第34号「リースに関する会計基準」**が、
**2027年4月1日以後開始する事業年度から強制適用**される。3月決算の会社なら2028年3月期からとなる。
2025年4月1日以後開始する事業年度からの**早期適用**も認められている。

| 論点                 | 内容                                                                                                             |
| -------------------- | ---------------------------------------------------------------------------------------------------------------- |
| 中核の変更           | **借手のファイナンス／オペレーティングの区分を廃止**し、原則すべてのリースで使用権資産とリース負債をオンバランス |
| 例外                 | 短期リース（12か月以内）・少額リースは簡便処理でオフバランス可                                                   |
| 貸手（リース会社）側 | 現行の会計処理が基本的に維持される。**リース会社自身のPLが激変するわけではない**                                 |
| 中小企業             | 中小企業の会計に関する指針・要領を使う会社は当面対象外とされる                                                   |
| 背景                 | IFRS第16号（2019年適用）・米国基準ASC 842に日本基準を寄せるもの                                                  |

### 2026年時点で何が起きているか

- 3月決算の上場企業では、2026年3月期の有価証券報告書・決算短信で
  **「未適用の会計基準等に関する注記」**として影響の記載が求められる段階に入っている
- 実務の論点は**①リースの識別（どの契約がリースか）②リース期間の判定（更新オプションをどう見るか）
  ③割引率の算定 ④経過措置の選択**の4点に集約されると、監査法人各社が解説している
- 影響が大きいのは「リースを使っている会社」より、むしろ**店舗・オフィス・倉庫の賃借が多い会社**。
  多店舗展開する小売・外食、車両を多数持つ会社ほど使用権資産の計上額が膨らむ
- 指標面では、総資産が増えるため**自己資本比率とROAが低下**し、費用の内訳が
  「支払賃借料」から「減価償却費＋支払利息」へ組み替わるため**EBITDAは見かけ上増える**

### リース会社にとっての意味

- **マイナス**：オペレーティングリースの「オフバランスにできる」という訴求が消える
- **プラス**：借手側に契約台帳・割引率管理・システム対応という新しい手間が生まれ、
  **管理サービス・アドバイザリー・システム提供の商機**になる。会計ソフト各社やリース会社が
  対応ソリューションの発信を強めている
- **設計の変化**：短期・少額の簡便処理が残るため、**短期契約やサービス型（XaaS・サブスク型）**
  への商品設計シフトが議論されている

> 押さえどころ：**変わるのは借手の決算書であり、リース会社の決算書ではない。**
> だからこの改正は「会計の話」ではなく**営業トークと商品設計の話**として効いてくる。

## 3. 金利のある世界と調達コスト──「増益だが利ざやは苦しい」

2024年のマイナス金利解除以降、日本の金利水準は上がり続けている
（→ [メガバンク④](../01_メガバンク/04_金利のある世界への転換.md)）。
預金を持たないリース会社にとって、これは**まず費用として効く**。

- ある大手の開示では、**資金原価が860億円から1,150億円へ、調整後の調達利回りが1.33%→1.70%**へ
  上昇したとされ、「運用利回りの改善は進むが、足もとは調達コストの上昇が先行する」と説明されている
- 格付会社のレポート（2026年5月、格付投資情報センター）では、リース各社は
  **円金利上昇による調達コスト増をリース料率への転嫁と取扱高拡大で吸収する計画**であり、
  多くの社が2026年度も増益を見込むと整理されている
- ポイントは**タイムラグ**。既存契約は固定料率で数年動かないため、
  調達が先に上がり、料率転嫁が後から追いつく。この間だけ利ざやが縮む
- したがって注目すべきは「純利益が増えたか」ではなく、**新規契約の料率が上がっているか**である

## 4. 2026年3月期決算──最高益が相次ぐが、中身は一過性が混じる

各社の開示・報道ベース。**会計基準とセグメント定義が各社で異なる**ため単純比較はできない。

| 会社                             | 2026年3月期 親会社株主帰属純利益 | 前期比                      | 主因（開示・報道ベース）                                                                                                                           |
| -------------------------------- | -------------------------------- | --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **オリックス**                   | **4,473億円**                    | +27.2%                      | 環境エネルギー（セグメント利益1,222億円）、事業投資・コンセッション（939億円）、投資売却益                                                         |
| **三菱HCキャピタル**             | **1,622億円**                    | +20.0%（**4期連続最高益**） | 不動産の大口アセット売却益、航空セグメントの伸長、米州の貸倒関連費用減。子会社決算期変更の影響（航空89億円・ロジスティクス62億円の増益効果）を含む |
| **東京センチュリー**             | **1,113億円**                    | +30.5%                      | 売上高1兆4,577億円（+6.5%）。国際事業（Aviation Capital Group）が牽引。国内リースのセグメント利益は228億円で微減                                   |
| **三井住友ファイナンス＆リース** | **1,050億円**                    | −12.6%                      | 前期に計上したロシア関連保険和解金の剥落などによる反動減                                                                                           |

読み方のコツは2つ。

1. **増益の源泉を「経常的な利ざや」と「一過性の売却益・和解金」に分ける**。
   不動産の大口売却や投資の出口、ロシア関連保険金の受取は、翌期には繰り返されない
2. **国内リース単体の利益は伸びていない**。東京センチュリーの国内リースが微減であるように、
   最高益の主役は航空機・不動産・環境エネルギーといった非リース領域である

なお、主要リース各社の通期見通しでは9社中5社が最高益を見込むと報じられた（日刊工業新聞系媒体）。

## 5. 航空機リースの大型再編──住友商事によるAir Lease買収完了

2026年4月8日（米国東部時間）、**住友商事はSMBC Aviation Capital、Apollo、Brookfieldと共同で
米Air Lease Corporationの買収を完了した**と発表した。新社名は
**Sumisho Air Lease Corporation**で、保有・管理機数において世界トップクラスの規模になるとしている。

- 背景には、航空需要の回復（2024年の航空旅客数が過去最多の約50億人に達したとされる）と、
  **機体メーカーの生産遅延で新造機が不足し、既存機・中古機の価値が上がっている**構図がある
- 航空機リース市場の調査レポートでは、ナローボディ機が過半のシェアを占め、
  **ドライリース（機体のみの貸与）が6割弱**を占めると予測されている（調査会社の推計）
- 日本勢は SMBC Aviation Capital（SMFL）、Aviation Capital Group（東京センチュリー）、
  三菱HCキャピタル、オリックスと有力プレイヤーが並ぶ。そこに**商社が直接大型案件を取りにきた**
- リスク面は2022年以降のロシア関連機材の損失が示したとおり、**地政学リスクが直撃する領域**でもある

## 6. 資産の取り合い──再エネ・蓄電池・データセンター

各社の中期経営計画と業界レポートに共通するのは、**大型・長期のアセットへ資金を張る**方向性である。

| 領域                     | なぜリース会社が向くか                                             | 論点                                                             |
| ------------------------ | ------------------------------------------------------------------ | ---------------------------------------------------------------- |
| 再エネ・蓄電池           | 初期投資が巨額で回収が長期。資金調達力と資産管理能力がそのまま効く | FIT/FIP制度の変化、PPAの条件、**金利上昇で採算計算が厳しくなる** |
| データセンター           | AI需要で設備投資が急拡大。電力確保とセットの巨大案件               | 電力・用地の制約、陳腐化スピード                                 |
| 不動産                   | 開発・保有・売却で完結する。1件の規模が大きい                      | 市況依存、金利上昇時の評価                                       |
| インフラ・コンセッション | 長期の固定的な収入。運営ノウハウが参入障壁になる                   | 契約期間が20〜30年と長く、途中の制度変更リスク                   |

2026年の再エネ市場に関する解説では、**利上げ環境で自己所有・リース・PPAの採算比較の答えが変わる**
と指摘されている。金利が上がると「初期投資を自分で抱える」選択肢の不利が増すため、
**リース・PPAの相対的な魅力が高まる**という見方である一方、
リース会社側の調達コストも上がるため、料率へどこまで転嫁できるかが分かれ目になる。

## 7. 全体の構図

```
【2026年のリース業界を1枚で】

   【国内の本業】                     【非リース領域】
   リース取扱高 5兆2,120億円(+3.0%)    航空機・不動産・再エネ・投資
   リース比率 4.34% で横ばい      ×    → **最高益の主役はこちら**
   産業機械・建機は減少、IT・車両は増    → ただし一過性の売却益が混じる
        │                                      │
        │  調達コスト上昇（調達利回り1.33→1.70%の例）│
        └──────────┬───────────┘
                          ▼
              利ざやはタイムラグで一時的に縮むが、
              料率転嫁と取扱高拡大で吸収する計画
                          │
                          ▼
              2027年4月〜 **借手のオンバランス化**
              「オフバランス」の売り文句が消え、
              事務代行・陳腐化リスク移転・管理サービスで
              勝負し直す局面に入る
```

まとめると5行。

1. **2027年度の新リース会計基準**が最大の論点。変わるのは借手の決算書で、
   リース会社は営業トークと商品設計の作り直しを迫られる
2. 国内リース市場は3年連続で増加しているが、**リース比率4.34%と存在感は戻っていない**
3. 金利上昇は**調達が先、料率転嫁が後**。増益でも利ざやは苦しいという二面性がある
4. 2026年3月期は最高益が相次いだが、主役は航空機・不動産・環境エネルギーで、
   **国内リース単体の利益は伸びていない**
5. 住友商事のAir Lease買収に象徴されるように、**商社・ファンドと同じ土俵で
   大型アセットを取り合う**段階に入った

## 8. 用語メモ

| 用語                               | 意味                                                                           |
| ---------------------------------- | ------------------------------------------------------------------------------ |
| **企業会計基準第34号**             | 2024年9月公表の新リース会計基準。2027年4月1日以後開始事業年度から強制適用      |
| **使用権資産／リース負債**         | 新基準で借手のBSに載る「借りて使う権利」と、その支払義務                       |
| **未適用の会計基準等に関する注記** | まだ適用していない新基準について、適用時期と影響を開示する注記                 |
| **経過措置**                       | 新基準の適用開始時に、過去分をどう処理するかの選択肢（遡及適用か、期首調整か） |
| **リース比率**                     | 民間設備投資額に占めるリース設備投資額の割合。日本は4%台                       |
| **調達利回り**                     | 支払利息 ÷ 有利子負債。金利上昇局面で先に上がる                                |
| **ドライリース**                   | 機体のみを貸し、乗員・整備・保険は航空会社が負担する形態                       |
| **PPA（電力購入契約）**            | 発電事業者と需要家の長期売買契約。再エネ投資の回収の土台                       |
| **FIT／FIP**                       | 固定価格買取制度／市場価格に補助を上乗せする制度。再エネ採算の前提             |
