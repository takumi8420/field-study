# リース

- 大分類: 金融
- 状態: done
- 更新日: 2026-09-20

**一言でいうと**：企業が欲しがる設備をリース会社が代わりに買い、貸して、
毎月のリース料で回収する**金融**。所有権が担保の代わりになる。
ただし現在の日本の大手は**リースだけの会社ではなく**、航空機・不動産・再エネ・投資を束ねた
総合金融グループに姿を変えている。2027年度からの**新リース会計基準**で、
借手の決算書からオペレーティングリースのオフバランスが消える。

## 1. 業界の定義・範囲

リース業は、**ユーザーが指定した物件をリース会社が購入し、一定期間貸して
リース料で回収する事業**を指す。所有権はリース会社に残り、それが担保の役割を果たす。
物件はメーカーからユーザーへ直接納品され、リース会社は代金を一括で立て替える。
つまり**実態は設備資金の立替払いであり、金融業に分類される**。

隣接業態との境界は次のとおり。

| 区別する相手                                                                                                                                       | 境界                                                                                                             |
| -------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| [メガバンク](../01_メガバンク/README.md)・[地方銀行](../02_地方銀行/README.md)                                                                     | 預金を集められるかどうか。リース会社は預金がなく、調達は借入・社債・CPに依存する。機能（設備資金の供給）は重なる |
| レンタル（[建設機械](../../02_自動車・機械/06_建設機械/README.md)レンタル、[レンタカー](../../13_運輸・物流/12_レンタカー・カーシェア/README.md)） | **在庫を持つか**。レンタルは汎用品を在庫して短期で回す。リースは契約が決まってから物件を買う                     |
| 割賦（分割払い）                                                                                                                                   | **所有権が完済で移転するか**。割賦は最初からユーザーの資産、リースは貸手の資産                                   |
| [消費者金融](../12_消費者金融/README.md)・信販                                                                                                     | 対象が個人か法人設備か。信販会社はリースも割賦も扱い、境界は曖昧                                                 |
| [総合商社](../../06_商社・卸売/01_総合商社/README.md)・投資ファンド                                                                                | 事業投資の領域では**ほぼ同業**。大手リース会社は商社・ファンドと同じ案件を取り合う                               |
| [不動産金融・REIT](../13_不動産金融・REIT/README.md)                                                                                               | 不動産の保有・開発という点で重なる。大手リース各社は不動産を主要セグメントに持つ                                 |

**含める範囲**：従来型リース・割賦だけでなく、オートリース、航空機・コンテナ・船舶などの
オペレーティングリース、不動産・再エネ・PE投資・海外事業まで。
大手の損益は**セグメント別にしか意味をなさない**ため（→ [③](03_総合金融業への進化.md)）。

## 2. 市場規模と成長性

| 指標                                       | 数値                              | 時点・出典                       |
| ------------------------------------------ | --------------------------------- | -------------------------------- |
| リース取扱高                               | **5兆2,120億円**（前年度比+3.0%） | 2025年度（速報）、リース事業協会 |
| リース取扱高                               | 5兆847億円（+9.8%、3年連続増）    | 2024年度、リース事業協会         |
| リース設備投資額                           | 4兆6,710億円（+8.0%）             | 2024年度、同上                   |
| **リース比率**（民間設備投資に占める割合） | **4.34%**                         | 2024年度、同上                   |
| 2025年度上期 取扱高                        | 2兆3,761億円（+1.1%）             | 2025年度上期、同上               |

成長性の見方には注意が要る。**取扱高は3年連続で増えたが、リース比率は4%台で横ばい**であり、
1990年前後の1割超から半減以下の水準にとどまる。企業が手元現金で設備を買うようになったためで、
**「国内リース市場が構造的に伸びる」という絵は描きにくい**。
だから大手の成長は①海外 ②アセット（航空機・不動産・再エネ）③投資、の3方向に向かっている。

## 3. バリューチェーン（お金と物件の流れ）

```
【リース業のバリューチェーン：カネとモノが別経路を通る】

 ＜調達＞                  ＜与信・組成＞           ＜保有・回収＞        ＜出口＞
  銀行借入 ─┐
  社債     ─┤                                                 ┌─▶ 再リース
  CP       ─┼─▶ リース会社 ─▶ 審査・料率設定 ─▶ 物件を保有 ─┼─▶ ユーザーが買取
  証券化   ─┤     のBS         （与信＋残価）    リース料回収  └─▶ **中古市場で売却**
  出資     ─┘                       │                                    │
                                     │                                    ▼
   ▲ 調達コスト                      │                            **残価の当たり外れが
   │ 格付けが生命線                   │                              そのまま損益になる**
   └─────────────────┴──────────────────┘
                       差 ＝ 利ざや（スプレッド）＋売却損益

  付加価値が集まるのは
    ①**安く長く資金を調達できる者**（格付け・親会社の信用）
    ②**与信を正しく値付けできる者**（小口を大量にさばく仕組み）
    ③**中古資産の価値を読める者**（航空機・車両・建機の目利き）
```

物件そのものはメーカーからユーザーへ直行し、リース会社は触らないことも多い。
**リース会社が付加価値を出しているのは、資金・与信・資産価値の3か所**である。

## 4. 主要プレイヤーとシェア

2026年3月期の開示・報道ベース。**オリックスは米国基準、他は日本基準**で
セグメント定義も異なるため、単純比較はできない。

| 企業                                                                        | 2026年3月期 純利益                     | 系列                                 | 立ち位置・特徴                                                                                            |
| --------------------------------------------------------------------------- | -------------------------------------- | ------------------------------------ | --------------------------------------------------------------------------------------------------------- |
| **オリックス**                                                              | **4,473億円**（+27.2%）                | 独立系                               | 多角化が最も進む。環境エネルギー・事業投資・コンセッション・保険・銀行まで持ち、**リースは数ある柱の1つ** |
| **三菱HCキャピタル**                                                        | **1,622億円**（+20.0%、4期連続最高益） | 銀行系（MUFG）                       | 2021年に三菱UFJリースと日立キャピタルが統合。航空・ロジスティクス・不動産・環境に厚い                     |
| **東京センチュリー**                                                        | **1,113億円**（+30.5%）                | 銀行＋商社（みずほ・伊藤忠）         | 売上1兆4,577億円。航空機子会社ACGを持つ国際事業が牽引。国内リースの利益は228億円                          |
| **三井住友ファイナンス＆リース（SMFL）**                                    | **1,050億円**（−12.6%）                | 銀行＋商社（SMFG・住友商事、非上場） | 航空機のSMBC Aviation Capitalが世界有数。減益は前期のロシア関連和解金の反動                               |
| （参考）NTTファイナンス、芙蓉総合リース、リコーリース、九州リースサービス等 | —                                      | 事業会社系・地域系                   | 親会社の販売網に紐づくベンダーリースや、地域の中堅企業向けに特化                                          |

「シェア」で並べる意味が薄い業界である。**取扱高のシェアより、
どのアセット（航空機・不動産・再エネ）をどれだけ持っているかで収益力が決まる**。

## 5. 収益モデル・コスト構造

```
【リース会社のPLの骨格】

   売上高（リース料収入・割賦収入・金融収益・物件売却収入 …）
     − リース原価（**物件の減価償却費が最大の塊**）
     − 資金原価（支払利息）           ← 金利上昇で先に膨らむ
   ＝ 粗利（実質的な利ざや）            ← **売上比で数%しかない**
     − 販管費（人件費・システム）
     − 与信費用（貸倒引当金繰入・貸倒損失）
     ＋ 物件売却損益（残価の当たり外れ）
     ＋ 持分法投資損益・投資売却益（事業投資の果実）
   ＝ 税引前利益
```

| 指標         | 意味                  | 目安                                               |
| ------------ | --------------------- | -------------------------------------------------- |
| ROA          | 純利益 ÷ 総資産       | 1〜2%台。レバレッジ産業なので低い                  |
| ROE          | 純利益 ÷ 自己資本     | 大手は10%前後を目標に置く会社が多い                |
| D/Eレシオ    | 有利子負債 ÷ 自己資本 | 3〜5倍程度。金利感応度が高い                       |
| 調達利回り   | 支払利息 ÷ 有利子負債 | 上昇局面。ある大手で1.33%→1.70%（2026年3月期開示） |
| 与信費用比率 | 与信費用 ÷ 営業資産   | 平時0.1〜0.3%程度                                  |

要点は**「薄いスプレッド × 巨大な資産」**という装置産業的な性格。
売上高や利益率で比べても意味がなく、**資産利回りと与信費用で見る**のが定石である。
詳細は [② リース会社の収益とリスク](02_リース会社の収益とリスク.md)。

## 6. 競争要因（KSF）と参入障壁

| 優位の源泉                                 | 中身                                                       | 真似しにくさ |
| ------------------------------------------ | ---------------------------------------------------------- | ------------ |
| **調達力（格付け・親会社の信用）**         | 預金がない分、低コストで長く借りられることが直接利益になる | ★★★          |
| **アセットの目利き（残価設定と中古販路）** | 航空機・車両・建機の価値を読み、売り切れること             | ★★★          |
| **与信の仕組み化**                         | 小口・多数の案件を速く正確にさばくモデルとデータ           | ★★           |
| **販売チャネル（ベンダーリース）**         | メーカー・販売店と組み、販売時点で提案する導線             | ★★           |
| **海外ネットワーク・現地法人**             | 航空機はアイルランド、現地リース会社の買収                 | ★★★          |
| **事業運営能力**                           | 発電所・空港・不動産を「運営」できること                   | ★★★          |

参入障壁は銀行ほど高くない。リース業自体に**免許制はなく登録も限定的**で、
新規参入はできる。しかし**調達コストで勝負が決まる**ため、
信用力のない新規参入者は利ざやを確保できない。**実質的な障壁は免許ではなく資金調達力**である。

## 7. 規制・法制度

| 制度                                       | 中身                                                                                        | リース業への効き方                                                                                                     |
| ------------------------------------------ | ------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| **企業会計基準第34号（新リース会計基準）** | 2027年4月1日以後開始事業年度から借手は原則オンバランス。2025年4月以後開始年度から早期適用可 | **最大の論点**。変わるのは借手の決算書。貸手の会計は基本維持 → [①](01_リースの仕組み.md)・[④](04_直近トピック_2026.md) |
| IFRS第16号／米国ASC 842                    | 国際・米国の先行するリース基準（2019年前後適用）                                            | 日本の新基準はこれに寄せたもの。海外子会社は既に適用済み                                                               |
| 法人税法（2008年度改正）                   | 所有権移転外ファイナンスリースを**売買として扱う**                                          | リース期間の下限・上限の縛り。節税目的の短期リースを封じた                                                             |
| 償却資産税（固定資産税）                   | 物件の所有者が申告・納付                                                                    | リース会社が納め、リース料に転嫁する。事務代行の価値の源                                                               |
| 貸金業法                                   | 営業貸付を行う場合は登録が必要                                                              | リース単体では対象外だが、金融子会社は登録している                                                                     |
| 金融商品取引法・銀行法                     | 銀行の子会社としての業務範囲、開示                                                          | 銀行系リース会社は親銀行のグループ規制の影響を受ける                                                                   |
| GX・再エネ関連制度（FIT／FIP等）           | 再エネ発電の買取価格・制度設計                                                              | 環境エネルギー事業の採算を左右する → [脱炭素・GX](../../01_注目テーマ/05_脱炭素・GX/README.md)                         |

**銀行業と違い、リース業には厳格な業法・自己資本比率規制がない**。
これがリース会社に事業の自由度（投資・不動産・海外への展開）を与えている一方、
**規制が守ってくれないぶん、格付けと市場の信認がすべて**という緊張も生む。

## 8. 最近のトピック

詳細は [④ 直近トピック（2026年9月時点）](04_直近トピック_2026.md)。要点は5つ。

1. **2027年4月から新リース会計基準が強制適用**。借手はオペレーティングリースも原則オンバランスとなり、
   自己資本比率・ROAが低下、費用が「減価償却費＋支払利息」に組み替わる。影響が大きいのは
   店舗・オフィスの賃借が多い会社
2. **2025年度のリース取扱高は5兆2,120億円（+3.0%）**で3年連続増。ただし**リース比率は4.34%**（2024年度）
   と低位横ばい。機種別では情報通信機器（+8.7%）が伸び、産業機械（−7.2%）・土木建設機械（−7.9%）が減少
3. **金利のある世界で調達コストが先行上昇**。ある大手は調達利回り1.33%→1.70%と開示。
   各社は料率転嫁と取扱高拡大で吸収する計画（R&Iレポート、2026年5月）
4. **2026年3月期は最高益ラッシュ**。オリックス4,473億円、三菱HCキャピタル1,622億円（4期連続最高益）、
   東京センチュリー1,113億円。**主役は航空機・不動産・環境エネルギーで、国内リース単体は伸びていない**
5. **住友商事がSMBC Aviation Capital等と共同で米Air Lease Corporationの買収を完了**（2026年4月8日）。
   Sumisho Air Leaseとして保有・管理機数で世界トップクラスへ。**商社が同じ土俵に入ってきた**
