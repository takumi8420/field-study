# 総合金融業への進化

このノートで分かること：**日本の大手リース会社はもはや「リースの会社」ではない**という事実、
何がそう変えたのか、航空機・不動産・再エネ・PE（未公開株）投資・海外事業といった
事業ポートフォリオの中身、そして銀行系・商社系・独立系で何が違うのか。

> ポイント：オリックスの利益に占める「国内のリース」は一部にすぎない。
> 大手リース各社の決算を見ると、**セグメント名に「リース」が出てこない会社すらある**。
> この業界を理解するとは、**「リース会社」という名前を疑うこと**から始まる。

## 1. なぜリースだけでは食えなくなったのか

原因は3つ重なっている。いずれも構造的で、元に戻らない。

```
【リース専業モデルが痩せた3つの理由】

  ①国内設備投資の頭打ち・リース比率の低下
     民間設備投資に占めるリース比率は **2024年度で4.34%**（リース事業協会）。
     1990年前後の1割超から半減以下。企業が手元現金で買うようになった
                     │
  ②スプレッドの競争激化                       ▼
     金融緩和期に調達金利が一律に下がり、         **同じ資産を積んでも
     差別化が「料率の安さ」だけになった            利益が増えない構造**
                     │
  ③会計・税制の後押しが消えた                  ▼
     2008年度税制改正でリースは「売買」扱いに。   → 利ざや以外の収益源を
     2027年度からは借手のオンバランス化。            取りにいくしかない
     「オフバランスできる」という売り文句が消える
```

結果として大手各社は、**「リース料の利ざや」から「資産を持って運用し、値上がりで抜く」**
方向へ重心を移した。これは[総合商社](../../06_商社・卸売/01_総合商社/README.md)が
口銭ビジネスから事業投資へ移った動きと、驚くほど似た構造変化である。

## 2. 収益の3層構造

大手リース会社の損益は、次の3層の重ね合わせとして読むと分かりやすい。

| 層                        | 中身                           | 利益の性質                                         | 代表的な事業                                                 |
| ------------------------- | ------------------------------ | -------------------------------------------------- | ------------------------------------------------------------ |
| **第1層：ファイナンス**   | 従来型リース・割賦・営業貸付   | 薄いが**安定的**。景気で与信費用が振れる           | 国内リース、ベンダーリース、オートリース                     |
| **第2層：アセット**       | 資産を保有して貸し、期末に売る | 料金収入＋**売却損益**。振れが大きい               | 航空機、コンテナ、鉄道貨車、不動産、船舶                     |
| **第3層：投資・事業運営** | 会社そのものを持ち、経営する   | 持分利益＋**投資売却益**。一過性が多く金額が大きい | PEファンド、コンセッション（空港等）、再エネ発電、保険・銀行 |

```
【利益の積み上がり方のイメージ】

   従来型リース専業（〜2000年代）      現在の大手（2020年代）
   ┌──────────────┐              ┌──────────────┐
   │                            │              │ 第3層 投資・事業運営     │ ← 金額が大きく
   │                            │              │ （売却益・持分利益）     │    振れも大きい
   │                            │              ├──────────────┤
   │                            │              │ 第2層 アセット           │ ← 航空機・不動産
   │  第1層 ファイナンス         │              │ （賃貸料＋売却損益）     │
   │  （リース利ざや）           │              ├──────────────┤
   │                            │              │ 第1層 ファイナンス       │ ← 割合は縮小
   └──────────────┘              └──────────────┘
    利益の源泉が1本 → 金利と景気で沈む    源泉が3本 → 1つが沈んでも他で埋める
```

この構造が分かると、決算の読み方も決まる。**「純利益が伸びた」だけでは評価できない**。
不動産の大口売却益や投資の出口が1回で数百億円出ることがあるため、
経常的な利ざやが伸びたのか、一過性の売却益なのかを分けて見る必要がある。

## 3. 主なアセット領域

### 3.1 航空機リース

大手の中核アセット。世界の旅客機の相当部分がリース機で、日本勢は世界の有力プレイヤーである。

- 経済の本質は**ドライリース**（機体だけを貸し、乗員・整備・保険は航空会社持ち）。
  リース会社は**残価と稼働の読み**で稼ぎ、運航そのもののリスクは取らない
- 強みは①機体の流動性が高い（世界中に買い手がいる）②長期契約でキャッシュフローが読める
- 弱みは①景気・地政学に弱い（2020年のコロナ、2022年以降のロシア関連機材の損失が典型）
  ②単価が大きく集中リスクになる
- 2020年代後半は**機体メーカーの生産遅延で新造機が足りず、中古機の価値が上がる**という
  追い風が続いたと報じられる（→ [④ 直近トピック](04_直近トピック_2026.md)）
- 関連：[航空](../../13_運輸・物流/02_航空/README.md)／[航空機・防衛](../../02_自動車・機械/13_航空機・防衛/README.md)

### 3.2 不動産

物件を保有して賃料を得るだけでなく、**開発・バリューアップして売却する**ところまで踏み込む。
利益の振れが大きい反面、一度の売却で全社利益を押し上げる力がある。
関連：[不動産デベロッパー](../../12_建設・住宅・不動産/08_不動産デベロッパー/README.md)／
[不動産金融・REIT](../13_不動産金融・REIT/README.md)

### 3.3 再生可能エネルギー・環境エネルギー

太陽光・風力・バイオマス発電所を保有し、売電やPPA（電力購入契約）で回収する。
発電所は「長期の固定収入を生む大型資産」という点でリースと相性がよく、
リース会社の得意技（資金調達＋資産管理）がそのまま効く領域である。
関連：[再生可能エネルギー](../../11_資源・エネルギー・鉄鋼金属/07_再生可能エネルギー/README.md)／
[脱炭素・GX](../../01_注目テーマ/05_脱炭素・GX/README.md)

### 3.4 その他のアセット

| ------------------ | --------------------------------------------- | -------------------------------------------------------------------------------------------- |
| コンテナ・鉄道貨車 | 海上コンテナ、北米の貨車をリース              | 世界の物流量に連動。中古市場が国際的                                                         |

【出自による性格の違い】

  低コスト調達が武器        グローバル網が武器          取りにいく
     │                        │                        │

**銀行系は調達と顧客基盤、商社系はアセットの目利きと海外網、独立系は意思決定の自由度**。
この3つの性格は、[メガバンク](../01_メガバンク/README.md)と
[総合商社](../../06_商社・卸売/01_総合商社/README.md)のそれぞれの強みが、
子会社・関連会社に持ち込まれた結果と理解すると腑に落ちる。

## 5. 海外展開の型

国内市場が伸びないため、海外は避けて通れない。ただし進め方は2つに分かれる。

| 型                     | 中身                                                                     | 例                                                   | リスク                                   |
| ---------------------- | ------------------------------------------------------------------------ | ---------------------------------------------------- | ---------------------------------------- |
| **アセットごと海外へ** | 航空機・コンテナ・貨車のように、**そもそも国境をまたいで動く資産**を持つ | 航空機リース（アイルランド拠点が定番）、海上コンテナ | 地政学（制裁・接収）、為替、単価の大きさ |
| **現地企業を買う**     | 現地のリース会社・ノンバンク・資産運用会社をM&Aし、現地顧客を取る        | 米州・アジアのリース会社買収、資産運用会社の取得     | 与信文化の違い、のれん減損、現地規制     |

航空機リースでアイルランドが定番なのは、**税制と航空機関連の法制度・人材が集積している**ため。
日本の大手も現地法人や買収先を通じて事業を行っている。

2026年には、住友商事がSMBC Aviation Capital・Apollo・Brookfieldと共同で
**米Air Lease Corporationの買収を完了**（2026年4月8日、住友商事発表）し、
「Sumisho Air Lease Corporation」として保有・管理機数で世界トップクラスになったとされる。
リース会社と商社が**同じ土俵で大型アセットを取り合う**ようになった象徴的な事例である。

## 6. 「リース会社」の定義がぼやけていく

ここまで見てきたとおり、大手の実態は次のように整理できる。

```
【業態の重なり：リース会社はどこに立っているか】

           ┌──────────────┐
           │      銀行・ノンバンク      │ 与信・資金供給
           │   （メガバンク、地銀）     │
           └──────┬───────┘
                  重なる：設備資金、ストラクチャードファイナンス
           ┌──────┴───────┐
           │     **リース会社**         │ ←──┐
           └──────┬───────┘      │ 重なる：資産の保有・運用
                  重なる：事業投資、海外           │
           ┌──────┴───────┐      │
           │   総合商社・投資ファンド   │ ──┘
           └──────────────┘
                  重なる：不動産の保有・開発
           ┌──────────────┐
           │  不動産・インフラ運営者    │
           └──────────────┘
```

- **銀行から見れば**：リース会社は子会社であり、同時に設備資金の競合でもある
- **商社から見れば**：リース会社は事業投資の同業者であり、共同出資のパートナーでもある
- **ファンドから見れば**：リース会社は長期資金を持つ競合であり、LP（出資者）でもある

だから、就職や取引でこの業界を見るときは、
**「どのリース会社か」ではなく「その会社のどの事業部か」で性格がまるで違う**。
航空機リース部門と国内の中小企業向けリース部門では、必要な能力も景気感応度も別物である。

## 7. まとめ：この章の骨

1. 国内リース市場の頭打ち・スプレッド競争・会計税制の後押し消失という3点が、
   **専業モデルを痩せさせた**
2. 大手は「ファイナンス／アセット／投資」の3層構造へ。**利益の源泉を分散させることが戦略の中心**
3. 中核アセットは航空機・不動産・再エネ・コンテナ。いずれも**長期の固定収入を生む大型資産**
4. 出自で性格が違う。**銀行系＝調達と顧客、商社系＝目利きと海外網、独立系＝自由度**
5. 業態の境界は消えつつあり、**商社・ファンド・銀行と同じ土俵で資産を取り合う**段階に入った

## 8. 用語メモ

| 用語                             | 意味                                                                                 |
| -------------------------------- | ------------------------------------------------------------------------------------ |
| **ドライリース／ウェットリース** | 機体のみを貸す／乗員・整備・保険込みで貸す。リース会社の本業は前者                   |
| **コンセッション**               | 公共施設の運営権を長期で取得して運営する方式。空港・上下水道などが対象               |
| **PPA（電力購入契約）**          | 発電事業者と需要家が長期で電力を売買する契約。再エネ投資の回収の土台                 |
| **PEファンド／プリンシパル投資** | 未公開企業の株式に投資して価値を高め売却する／自己資金で直接投資すること             |
| **ストラクチャードファイナンス** | 資産や事業のキャッシュフローを裏付けに組成する仕組み金融。プロジェクトファイナンス等 |
| **のれん（減損）**               | 買収価格が純資産を上回る差額／その価値が落ちたときの損失計上                         |
| **持分法投資損益**               | 20〜50%程度出資する関連会社の利益のうち、自社の取り分                                |
| **LP／GP**                       | ファンドの出資者／運営者。リース会社は両方の立場を取ることがある                     |
| **セグメント利益**               | 事業部門ごとの利益。リース会社の実態は**セグメント別に見ないと分からない**           |
