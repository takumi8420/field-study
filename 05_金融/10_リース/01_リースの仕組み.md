# リースの仕組み

このノートで分かること：リースとは何を売っている商売なのか、ファイナンスリースと
オペレーティングリースはどこが違うのか（答えは**残価リスクを誰が背負うか**）、
なぜ企業は買わずに借りるのか、リース料には何が入っているのか、
そして2027年度から始まる**新リース会計基準**が何をひっくり返すのか。

> ポイント：リースは「モノの貸借」の顔をした**金融**である。
> リース会社が売っているのは機械ではなく、**設備を使う権利と、その代金の分割払い**。

## 1. リースとは何か

リースは、リース会社（貸手＝レッサー）が**ユーザーの指定した物件をメーカーから買い取り**、
それをユーザー（借手＝レッシー）に一定期間貸して、毎月のリース料を受け取る取引である。

```
【リース取引の三者関係：モノとカネが別の経路を通る】

              ①物件を選定・仕様を決める
   ユーザー ───────────────────────────▶ メーカー／販売会社
  （借手）  ◀───────────────────────────
     │        ④物件を直接納品（モノの流れ）
     │
     │ ⑤リース料を毎月支払う（60回など）
     ▼
  リース会社 ────────────────────────────▶ メーカー／販売会社
  （貸手）      ②売買契約・③物件代金を一括で支払う（カネの流れ）
     │
     │ ⑥リース会社は銀行借入・社債で資金を調達している
     ▼
  銀行・社債市場
```

ここで効いているのが、**物件はユーザーに直接届くのに、所有権はリース会社に残る**という点。
リース会社は物件を見ないまま買うことも多い。実質は「設備購入資金の立替払い」であり、
だからこそリースは金融業に分類される。[メガバンク](../01_メガバンク/README.md)の
設備資金融資と経済的な機能はほとんど同じで、違うのは**所有権が担保の代わりになること**である。

## 2. ファイナンスリースとオペレーティングリース

リースの二大分類。違いは一言でいうと「**契約が終わったときの物件の値段（残価）のリスクを、
貸手と借手のどちらが背負うか**」に尽きる。

| 論点                                       | ファイナンスリース                                                   | オペレーティングリース                                                   |
| ------------------------------------------ | -------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| 経済的な中身                               | 分割払いでの購入に近い                                               | 賃貸借に近い                                                             |
| **残価リスク**（期末の物件価値の読み違い） | **借手が実質負担**（リース料で全額回収するため貸手は読まなくてよい） | **貸手（リース会社）が負担**                                             |
| リース料の総額                             | 物件価格＋付随費用のほぼ全額を回収（フルペイアウト）                 | 想定残価を差し引くので**月額が安くなる**                                 |
| 中途解約                                   | 原則不可（解約時は残リース料相当を支払う）                           | 契約により可の場合がある                                                 |
| 物件の返却後                               | ユーザーが再リース／買取することが多い                               | リース会社が引き取り、中古売却・再リースする                             |
| 向いている物件                             | 汎用性が低く中古市場が薄いもの（生産設備、特注機）                   | 中古市場が厚く値崩れしにくいもの（**航空機、自動車、建設機械、IT機器**） |
| 貸手の腕の見せどころ                       | 与信審査（相手が払えるか）                                           | **残価設定と中古売却**（モノの目利き）                                   |

```
【残価リスクの所在：リース料の高さで一目で分かる】

  物件価格 1,000
  ┌──────────────────────────────────────────┐
  │ ファイナンスリース（5年）                 │
  │ ■■■■■■■■■■■■■■■■■■■■  リース料総額で1,000＋金利を全部回収 │
  │ 残価＝ほぼ0で設定 → リース会社は値崩れを気にしなくてよい      │
  └──────────────────────────────────────────┘
  ┌──────────────────────────────────────────┐
  │ オペレーティングリース（5年）             │
  │ ■■■■■■■■■■■■□□□□□□□□  リース料で回収するのは600だけ       │
  │                  ↑ここが想定残価400 → **5年後に400で売れなければ赤字** │
  └──────────────────────────────────────────┘

  月額が安い＝リース会社が残価400を取りにいっている、ということ。
```

オペレーティングリースは、リース会社にとって**金融ではなく「中古資産の商売」**に近づく。
航空機リースでリース会社が儲かったり損したりするのは、ほぼこの残価の当たり外れである
（→ [② リース会社の収益とリスク](02_リース会社の収益とリスク.md)）。

## 3. なぜ買わずに借りるのか

ユーザー側の動機は3つに分解できる。「金利が高い/安い」だけの話ではない。

| 動機                                   | 中身                                                                                   | どんな会社に効くか                                                                  |
| -------------------------------------- | -------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| **資金繰り（キャッシュフロー平準化）** | 1,000万円の機械を一括で払わず、月17万円×60回にできる。手元資金を運転資金に残せる       | 資金に余裕のない中堅・中小企業                                                      |
| **事務負担の移転**                     | 固定資産の登録、減価償却計算、償却資産税の申告・納付、動産保険の手配をリース会社がやる | 経理人員が薄い会社。**台数が多い会社ほど効く**                                      |
| **陳腐化リスクの移転**                 | PC・サーバ・複合機のように数年で古くなるものを、使い切らずに入れ替えられる             | IT機器、医療機器、[事務機器](../../03_電機・電子部品/12_事務機器・複合機/README.md) |
| （副次）**与信枠の温存**               | 銀行の借入枠を使わずに設備を調達できる、と説明されることがある                         | 借入余力の小さい会社                                                                |

逆に「借りない」理由もはっきりしている。長く使う設備なら、**買ったほうが総額は安い**。
リース料には後述のとおりリース会社の利益が乗るからで、自己資金が潤沢な大企業ほど
「現金で買う」を選ぶ。日本の**リース比率（民間設備投資に占めるリース設備投資の割合）は
2024年度で4.34%**（リース事業協会）と1桁台にとどまり、1991年前後の1割超から長期低落した。
これは日本企業が手元現金を厚く持つようになったことの裏返しでもある。

## 4. リース料の中身

リース料は「値段」ではなく「**積み上げの結果**」である。分解すると4つ。

```
【月額リース料の分解（ファイナンスリースの例）】

   ┌─────────────┐
   │ ① 物件価格   │  ← メーカーへの支払額。最大の塊（総額の8割前後）
   ├─────────────┤
   │ ② 金利       │  ← リース会社の調達金利＋スプレッド。**金利上昇局面で膨らむ**
   ├─────────────┤
   │ ③ 固定資産税  │  ← 償却資産税。所有者＝リース会社が払い、リース料に織り込む
   │   ＋動産保険料│  ← 火災・盗難などの保険。これも織り込む
   ├─────────────┤
   │ ④ リース会社の│  ← 事務コスト＋利益。ここが薄い（後述）
   │   経費・利益  │
   └─────────────┘
       ÷ リース期間（月数） ＝ 月額リース料
```

重要なのは、**③の税と保険が込みである**こと。ユーザーから見ると「毎月定額を払えば
税金も保険も面倒を見てもらえる」点が価値で、この「丸投げできる」性質が
リースがただの分割払いと違うところである。一方、④の利幅は極めて薄く、
リース会社の粗利率は数%台にすぎない（→ [②](02_リース会社の収益とリスク.md)）。

## 5. 割賦・レンタル・融資との違い

隣接する調達手段との線引き。**所有権・期間・物件の特定・解約可否**の4軸で整理する。

| 手段                         | 所有権                   | 物件は誰が選ぶか                                   | 期間                   | 中途解約       | 経済的な意味                         |
| ---------------------------- | ------------------------ | -------------------------------------------------- | ---------------------- | -------------- | ------------------------------------ |
| **リース**                   | リース会社               | **ユーザーが指定**（特定の1台）                    | 中長期（3〜7年が中心） | 原則不可（FL） | 設備購入資金の立替＋事務代行         |
| **割賦（分割払い）**         | 完済で**ユーザーへ移転** | ユーザー                                           | 中期                   | 不可           | 所有前提の分割払い。最初から自社資産 |
| **レンタル**                 | レンタル会社             | **在庫から選ぶ**（誰が使うか決まっていない汎用品） | 短期（日・月単位）     | 可             | 稼働に応じた都度課金。モノの商売     |
| **銀行融資で購入**           | ユーザー                 | ユーザー                                           | 中長期                 | 繰上返済可     | 純粋な資金の貸借。事務は全部自前     |
| **サブスクリプション／XaaS** | 提供者                   | サービスを選ぶ                                     | 月次更新               | 可             | 設備ではなく「機能」を買う           |

```
【「モノ性」と「カネ性」のグラデーション】

  カネ寄り ◀──────────────────────────────────▶ モノ寄り

  銀行融資   割賦   ファイナンスリース   オペレーティングリース   レンタル
   純粋な     所有     所有権だけ          残価を読む＝           在庫を
   貸借      前提の    貸手に残す          中古の目利きが要る      回す商売
            分割
            ▲                              ▲                      ▲
        与信力が勝負                  与信力＋資産の目利き      稼働率が勝負
```

レンタルとの差は「**在庫を持つかどうか**」。レンタル会社は汎用機を在庫し、
借りたい人が現れるのを待つ（[建設機械](../../02_自動車・機械/06_建設機械/README.md)の
レンタルや[レンタカー](../../13_運輸・物流/12_レンタカー・カーシェア/README.md)が典型）。
リース会社は**契約が決まってから買う**ので在庫リスクを負わない。
ただしオペレーティングリースが増えると、返却物件という形で在庫リスクが入り込んでくる。

## 6. 2027年度から始まる新リース会計基準（オンバランス化）

日本のリース会計は2027年度から大きく変わる。ここは**この業界を語るうえで今いちばん重要な論点**。

### 6.1 何が変わるのか

企業会計基準委員会（ASBJ）は2024年9月に企業会計基準第34号「リースに関する会計基準」を公表した。

| 項目       | 内容                                                                                                                                         |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| 適用時期   | **2027年4月1日以後開始する事業年度から**（3月決算なら2028年3月期）。2025年4月1日以後開始年度からの早期適用可                                 |
| 対象       | 上場企業・会社法上の大会社など、日本基準を使う会社の**借手側**。中小企業の会計（中小指針・中小要領）は当面対象外とされる                     |
| 中核の変更 | 借手について**ファイナンス／オペレーティングの区分を廃止**。原則すべてのリースで**使用権資産とリース負債を貸借対照表に計上**（オンバランス） |
| 例外       | 短期リース（12か月以内）と少額リースは簡便処理でオフバランス可                                                                               |
| 貸手側     | 現行の会計処理が基本的に維持される（リース会社自身のPLが激変するわけではない）                                                               |

背景は国際的な整合。IFRS第16号（2019年適用）と米国基準ASC 842が先に借手のオンバランス化を
済ませており、**日本だけがオフバランスを許していた**状態を解消するものである。

### 6.2 何が「効く」のか

```
【新基準適用前後の借手のバランスシート（イメージ）】

  ＜現行：オペレーティングリースは注記だけ＞      ＜新基準：オンバランス＞
   資産            負債・資本                      資産              負債・資本
  ┌────────┬────────┐                   ┌────────┬────────┐
  │ 有形固定 │ 借入金   │                   │ 有形固定  │ 借入金    │
  │ 資産     ├────────┤                   │ 資産      ├────────┤
  │          │          │                   ├────────┤ **リース負債**│ ←新たに載る
  │          │ 自己資本 │                   │**使用権資産**├────────┤
  └────────┴────────┘                   │（店舗・車両│ 自己資本  │ ←金額は変わらない
                                              │ ・複合機） │           │
   賃借料は販管費に1行だけ                    └────────┴────────┘
                                               → **総資産と負債が同時に膨らむ**
   ↓                                          ↓
   自己資本比率 40%                            自己資本比率が下がる（分母が増えるため）
                                               ROA も下がる（同じ利益／大きい資産）
                                               費用は「減価償却費＋支払利息」に組み替え
                                               → **EBITDA は見かけ上増える**
```

影響が大きいのは、**リースというより不動産賃借が多い業種**である。多店舗の
[コンビニ](../../07_小売・流通/01_コンビニエンスストア/README.md)や[食品スーパー](../../07_小売・流通/03_食品スーパー/README.md)などの多店舗小売・外食、大量の営業車両を抱える会社、
オフィスを多く借りる会社ほど、使用権資産の計上額が膨らむ。
「うちはリースを使っていない」という会社でも、**店舗やオフィスの賃貸借契約が
リースとして拾われる**点が最大の落とし穴である。

### 6.3 リース会社にとっては追い風か向かい風か

両面ある。整理すると次のとおり。

| 向かい風                                                                      | 追い風                                                                                     |
| ----------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| 「オフバランスにできる」というオペレーティングリースの**売り文句が1つ消える** | 賃貸借契約まで台帳管理が必要になり、**契約管理・システム・アドバイザリーの需要**が生まれる |
| 借手が総資産圧縮を優先して、リース利用を絞る可能性                            | どうせ載るなら、と**物件の陳腐化リスク移転や事務代行という本来の価値**で選ばれるようになる |
| 借手側の会計処理が重くなり、導入検討の手間が増える                            | 短期・少額リースの例外を狙った**短期契約・サービス型（XaaS）商品**の設計余地               |

リース会社側の会計は大きく変わらないため、**自社の決算より顧客の決算が変わる**
という意味で、営業・提案の論点が変わる改正だと理解するのが実務的である。

## 7. リース期間と税務の縛り

会計とは別に、法人税法上の「リース取引」の定義がある。ここが日本のリース実務の骨格を作ってきた。

- 税務上のリース取引（所有権移転外ファイナンスリース）は、**売買があったものとして扱う**（2008年度改正以降）
- リース期間は法定耐用年数を基準に**下限（おおむね70%、耐用年数10年以上は60%）と上限（120%）**が課されるのが実務慣行。
  極端に短い期間にして損金を前倒しする節税を防ぐため
- 物件の所有者であるリース会社が**償却資産税**を申告・納付し、リース料に転嫁する
- 消費税は原則としてリース開始時に総額で認識される（所有権移転外ファイナンスリースの場合）

つまりリース期間は自由に決められるわけではなく、**税務の枠の中で決まっている**。
この縛りがあるため、「3年で入れ替えたい」というニーズは
オペレーティングリースやレンタル、サービス契約へ流れやすい。

## 8. まとめ：この章の骨

1. リースは**金融**。モノを貸す顔をした設備資金の立替払いで、所有権が担保の役割をする
2. ファイナンスとオペレーティングの分かれ目は**残価リスクを誰が持つか**。
   オペレーティングは貸手が持つので月額が安く、そのぶん**中古の目利きが要る**
3. 借りる理由は資金繰り・事務負担・陳腐化の3つ。金利だけの話ではない
4. リース料＝物件価格＋金利＋税金保険＋利益。**税と保険が込み**なのがレンタルや融資と違う点
5. 2027年度からの新基準で借手は原則オンバランス。**「オフバランスできる」という売り文句が消え、
   価値の説明をやり直す必要がある**

## 9. 用語メモ

| 用語                               | 意味                                                                                                                             |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| **レッサー／レッシー**             | 貸手（リース会社）／借手（ユーザー）。英語の lessor / lessee                                                                     |
| **フルペイアウト**                 | リース料総額で物件価格＋付随費用のほぼ全額を回収する設計。ファイナンスリースの要件                                               |
| **残価（残存価額）**               | リース期間終了時に見込む物件の価値。オペレーティングリースではこれを引いてリース料を決める → [②](02_リース会社の収益とリスク.md) |
| **所有権移転外ファイナンスリース** | 期間終了後も所有権がユーザーに移らないファイナンスリース。日本の実務の大半がこれ                                                 |
| **再リース**                       | 契約満了後、大幅に安い料率（年額が元の月額程度になることが多い）で継続すること                                                   |
| **使用権資産／リース負債**         | 新基準で借手のBSに載る、「借りて使う権利」という資産と、その支払義務                                                             |
| **オンバランス／オフバランス**     | 貸借対照表に載せる／載せない。新基準は借手を原則オンバランスにする                                                               |
| **IFRS第16号／ASC 842**            | 国際財務報告基準／米国会計基準のリース基準。日本の新基準はこれに寄せたもの                                                       |
| **リース比率**                     | 民間設備投資額に占めるリース設備投資額の割合。2024年度4.34%（リース事業協会）                                                    |
| **償却資産税**                     | 土地・家屋以外の事業用固定資産にかかる市町村税。リース物件は所有者であるリース会社が納める                                       |
