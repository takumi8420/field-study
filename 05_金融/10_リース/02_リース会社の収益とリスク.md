# リース会社の収益とリスク

このノートで分かること：リース会社はどこからお金を調達し、何で利益を出しているのか
（＝**利ざや商売**という本質）、粗利が薄いのになぜ成立するのか、
どんなリスクを背負っているのか（与信・残価・金利・集中）、
そして中古市場と残価設定がなぜ勝負どころなのか。

> ポイント：リース会社は**銀行から借りた金を、銀行より高い金利で企業に流す**商売。
> 銀行と違い預金を集められないので、**調達コストで負け、審査スピードと手間の肩代わりで勝つ**。

## 1. 資金の流れ：どこから調達し、どこへ回すか

```
【リース会社のバランスシートと資金の流れ】

  ＜調達サイド（負債）＞                     ＜運用サイド（資産）＞
   銀行借入（シンジケートローン含む）─┐     ┌─▶ リース債権・リース投資資産
   社債（普通社債・グリーンボンド） ─┤     │    （ファイナンスリース＝実質は貸付金）
   CP（コマーシャルペーパー・短期） ─┼─▶ ├─▶ 賃貸資産（オペレーティングリース）
   証券化（債権流動化・ABS）       ─┤     │    （航空機・車両・不動産など**自社所有**）
   親会社・株主からの出資          ─┘     ├─▶ 割賦債権・営業貸付金
                                            └─▶ 事業投資・出資（ファンド、再エネ、海外子会社）
        ▲                                        │
        │ **預金を集められない**のが銀行との決定的な違い            ▼
        │ → 調達は市場性資金に依存し、格付けが生命線          資金運用利回り
        └────────────────────────────────────────────────────────┘
                     差＝**利ざや（スプレッド）**が粗利
```

銀行は預金という**ほぼ無利息で大量に集まる資金**を持つが、リース会社にはそれがない。
だからリース会社の資金コストは常に銀行より高く、**同じ相手に同じ金利では貸せない**。
その代わりに、①銀行が嫌う小口・多数の案件を機械的にさばく、②物件を担保代わりにして
与信を取る、③審査が速い、といった土俵で戦うことになる。
[メガバンク](../01_メガバンク/README.md)や[地方銀行](../02_地方銀行/README.md)が
親会社・株主にいるリース会社が多いのは、この調達の弱点を資本と信用でカバーするためでもある。

| 調達手段                             | 特徴                                                  | 効きどころ・弱点                                       |
| ------------------------------------ | ----------------------------------------------------- | ------------------------------------------------------ |
| 銀行借入                             | 最も基本。長期・短期の両方                            | 親銀行との関係が太い会社は安定。金利上昇がそのまま効く |
| 社債                                 | 期間を長く固定でき、ALM（資産負債の期間合わせ）に有効 | **格付けが命**。格下げされると発行条件が悪化する       |
| CP                                   | 短期で機動的、調達コストが低い                        | 市場が詰まると借り換えできない（流動性リスク）         |
| 証券化・ABS                          | 債権をまとめて投資家に売り、BSから外す                | 資産を回転させられる。組成コストと開示負担             |
| グリーンボンド／トランジションボンド | 再エネ・省エネ資産に紐づけて発行                      | 投資家層を広げられる。使途の報告義務                   |

## 2. 利ざや商売という本質

リース会社の損益は、突き詰めると**「運用利回り − 調達利回り − 経費 − 与信費用」**である。

```
【リース会社のPLの骨格】

   売上高（リース料収入・割賦収入・金融収益・物件売却収入 …）
     − リース原価（**物件の減価償却費が最大の塊**）
     − 資金原価（支払利息）
   ＝ 粗利（実質的な利ざや）        ← **ここが売上比で数%しかない**
     − 販管費（人件費・システム）
     − **与信費用**（貸倒引当金繰入・貸倒損失）
     ＋ 物件売却損益（中古売却＝残価の当たり外れ）
     ＋ 持分法投資損益・投資売却益（事業投資の果実）
   ＝ 税引前利益
```

ここで独特なのが、**売上高が巨大で利益率が極端に低く見える**こと。
物件の購入代金がそのまま売上・原価に立つため、売上高純利益率は数%台にとどまる。
だから**リース会社を売上や利益率で比べても意味がない**。見るべきは次の指標である。

| 指標                                   | 意味                               | 目安・読み方                                                  |
| -------------------------------------- | ---------------------------------- | ------------------------------------------------------------- |
| **セグメント利益／営業資産**           | 資産をどれだけ効率よく回しているか | リース会社にとっての実質的な利回り                            |
| **ROA**                                | 純利益 ÷ 総資産                    | 1〜2%台が通常。**銀行と同じくレバレッジ産業**なので低い       |
| **ROE**                                | 純利益 ÷ 自己資本                  | 大手は10%前後を目標に置く会社が多い                           |
| **D/Eレシオ（有利子負債 ÷ 自己資本）** | どれだけ借りて資産を持っているか   | 業態上3〜5倍程度が一般的。上がるほど金利感応度が高い          |
| **調達コスト（調達利回り）**           | 支払利息 ÷ 有利子負債              | 2026年にかけて上昇局面。ある大手は1.33%→1.70%へ上昇したと開示 |
| **与信費用比率**                       | 与信費用 ÷ 営業資産                | 平時0.1〜0.3%程度。景気後退と特定業種の破綻で跳ねる           |

> ポイント：リース会社は**薄いスプレッドを大量の資産に掛け算して稼ぐ装置**。
> だから、規模を落とさずに資産を積むことと、与信費用を跳ねさせないことが同時に要る。

## 3. 金利上昇はリース会社に効くのか

2024年のマイナス金利解除以降、日本は「金利のある世界」に戻った
（→ [メガバンク④ 金利のある世界への転換](../01_メガバンク/04_金利のある世界への転換.md)）。
リース会社への効き方は、**銀行と逆向きに出る部分がある**。

```
【金利上昇の伝わり方：タイムラグが損益を歪める】

  時点 T          T+3か月         T+1年          T+3年
   │               │               │               │
   ├─ 調達：短期借入・CPの借り換えで**即座に**コスト上昇 ─────────▶
   │
   └─ 運用：既存のリース契約は**固定料率で数年間動かない**
                     │
                     └─ 新規契約から順にリース料率へ転嫁 ────────▶

   結果：上昇局面の初期は「調達コストが先、料率転嫁が後」で**利ざやが一時的に縮む**。
          残高が入れ替わりきると、むしろ高い利回りで回るようになる。
```

- 銀行は預金（調達）がすぐには上がらず貸出（運用）が先に上がるので、利上げは即座に追い風になる
- リース会社は逆に**調達が先に上がり、料率転嫁は契約更新のタイミングまで待たされる**
- したがって、利上げ局面では**固定・変動のミスマッチ管理（ALM）**と、
  リース料率に金利上昇分を素直に乗せられる**価格交渉力**が試される
- 2026年にかけて大手各社は「調達コスト上昇は料率転嫁と取扱高拡大で吸収する」方針を示しており、
  実際に増益を確保した会社が多いが、**転嫁の遅れが出れば利ざやは削られる**

## 4. 4つのリスク

| リスク                 | 中身                           | 現れ方                                                     | 打ち手                                           |
| ---------------------- | ------------------------------ | ---------------------------------------------------------- | ------------------------------------------------ |
| **与信リスク**         | 借手が払えなくなる             | 貸倒引当金繰入、貸倒損失。中小企業向けが多いほど景気に連動 | 審査モデル、業種・与信先の分散、保証・保険の付保 |
| **残価リスク**         | 期末に物件が想定価格で売れない | 物件売却損、減損。オペレーティングリース固有               | 保守的な残価設定、中古販路の確保、再リース       |
| **金利・流動性リスク** | 調達コスト上昇、借り換え不能   | 利ざや縮小、最悪は資金繰り破綻                             | ALM、調達手段の分散、コミットメントラインの確保  |
| **集中リスク**         | 特定の資産・国・業種に偏る     | 航空機の運航停止、特定国の制裁・接収                       | ポートフォリオの分散、地域分散                   |

このうち**リース固有**なのは与信リスクと残価リスクの2つ。それぞれ掘り下げる。

### 4.1 与信リスクと「物件が担保になる」効果

リース会社の与信は、銀行の融資審査と違って**物件の価値で一部が保全される**。
契約者が支払えなくなっても、リース会社は所有権を持っているので物件を引き揚げられるからだ。

```
【損失が出るまでの3段階】

  ① 借手のデフォルト ───▶ ② 物件の引き揚げ ───▶ ③ 中古売却
                            │                      │
                            │ 引き揚げられない      │ 想定より安い
                            │（設備が据付済み、     │（中古市場が薄い、
                            │  海外にある、行方不明）│  型落ち、状態が悪い）
                            ▼                      ▼
                        **全額が損失**          **差額が損失**

  → 「担保になる物件」とは、**外せて・運べて・買い手がいる**物件のこと。
     工場に据え付けた特注ラインは、理屈のうえで担保だが実際には回収できない。
```

この違いが業種別の物件構成に直結する。航空機・車両・建設機械・IT機器が
オペレーティングリースに向くのは、**動かせて中古市場が世界規模で存在する**からである。

### 4.2 残価設定と中古市場

オペレーティングリースの利益は、**リース期間中の料金収入＋期末の売却代金 − 物件取得原価 − 資金コスト**
で決まる。売却代金の読みがそのまま損益になるため、残価設定は最重要の経営判断になる。

| 物件                                                                        | 中古市場の厚み         | 残価の読みやすさ       | 効いてくる要因                                           |
| --------------------------------------------------------------------------- | ---------------------- | ---------------------- | -------------------------------------------------------- |
| [航空機](../../02_自動車・機械/13_航空機・防衛/README.md)（ナローボディ機） | 世界規模で厚い         | 比較的読みやすい       | 機種の需要、航空需要、燃費、製造遅延による中古機の希少化 |
| 自動車・商用車                                                              | 厚い（国内・輸出とも） | 読みやすい             | 中古車相場、EV化による内燃機関車の評価変動               |
| [建設機械](../../02_自動車・機械/06_建設機械/README.md)                     | 厚い（新興国向け輸出） | 読みやすい             | 稼働時間、為替、新興国需要                               |
| [工作機械](../../02_自動車・機械/07_工作機械/README.md)・産業機械           | 薄い（用途特化）       | 読みにくい             | 業界の設備投資サイクル                                   |
| IT機器・サーバ                                                              | 中程度                 | 陳腐化が速く読みにくい | 世代交代のスピード。近年はAI需要でGPU等の評価が変動      |
| [医療機器](../../09_医薬・医療・ヘルスケア/05_医療機器/README.md)           | 薄い                   | 読みにくい             | 保守契約の有無、薬事規制                                 |

> ポイント：**残価を強気に置けばリース料を安くでき、競合に勝てる。ただし外れたら数年後に損失が出る。**
> 営業の勝ちと数年後の損失が時間的に離れているため、リース会社の規律はここで試される。

## 5. 業種別・物件別の姿（国内リース市場）

日本国内のリース取扱高は、公益社団法人リース事業協会の統計で毎月開示される。

| 項目                                       | 数値                              | 時点・出典                       |
| ------------------------------------------ | --------------------------------- | -------------------------------- |
| リース取扱高                               | **5兆2,120億円**（前年度比+3.0%） | 2025年度（速報）、リース事業協会 |
| リース取扱高                               | 5兆847億円（前年度比+9.8%）       | 2024年度、リース事業協会         |
| リース設備投資額                           | 4兆6,710億円（+8.0%）             | 2024年度、同上                   |
| **リース比率**（民間設備投資に占める割合） | **4.34%**                         | 2024年度、同上                   |

機種別の2025年度の動きは次のとおり（いずれも前年度比、リース事業協会）。

```
【2025年度 機種別の増減（速報ベース）】

   情報通信機器        ████████▲ +8.7%   ← サーバ・ネットワーク更新、DX投資
   輸送用機器          ██████▲   +6.7%   ← 商用車・車両
   事務用機器          ████▲     +4.9%   ← 複合機など
  ─────────────────────────────────────── 0
   工作機械            ▼█        −1.5%
   商業・サービス業用機器 ▼████   −5.2%
   医療機器            ▼████     −5.6%
   産業機械            ▼█████    −7.2%   ← 製造業の設備投資サイクルの谷
   土木建設機械        ▼██████   −7.9%
```

読み取れる構図は明確で、**情報通信・事務機・輸送用が伸び、産業機械・建機が減る**。
リースは**製造業の設備投資サイクルに連動する景気敏感な部分**と、
**IT機器のように更新需要で回る安定した部分**の二層構造になっている。

## 6. 稼ぎ方の3類型

同じ「リース会社」でも、収益の作り方は3つに分かれる。どれを主軸に置くかで財務の姿が変わる。

| 類型                                      | 稼ぎ方                                               | 必要な能力                                   | リスクの所在     |
| ----------------------------------------- | ---------------------------------------------------- | -------------------------------------------- | ---------------- |
| **①ファイナンス型**（従来型リース・割賦） | 利ざや。薄いが安定                                   | 与信審査、事務効率、販売網（ベンダーリース） | 与信リスク       |
| **②アセット型**（オペレーティングリース） | 料金収入＋**売却益**。振れが大きい                   | 残価の目利き、中古販路、メンテナンス         | 残価リスク       |
| **③投資型**（事業投資・ファンド・不動産） | 持分利益、**投資売却益**。ロットが大きく一過性も多い | 投資判断、ハンズオンの経営                   | 事業リスク・市況 |

大手は3つを重ねている。だから決算を読むときは、
**「増益の中身が経常的な利ざやなのか、物件や投資の売却益という一過性なのか」**を
分けて見るのが定石になる（→ [③ 総合金融業への進化](03_総合金融業への進化.md)）。

## 7. 会計基準の変更は収益にどう効くか

2027年4月1日以後開始事業年度から適用される新リース会計基準（企業会計基準第34号）は、
**借手側の基準**である。貸手（リース会社）の会計処理は基本的に維持されるため、
**リース会社自身のPLが直接ひっくり返るわけではない**。効くのは需要と営業の側である。

- オペレーティングリースの「オフバランスにできる」という訴求が消える → 価値の説明をやり直す必要
- 借手は契約台帳・割引率・リース期間判定の実務を抱える → **管理システムやアドバイザリーの商機**
- 短期・少額リースの簡便処理が残る → **短期契約やサービス型（XaaS・サブスク）への設計変更余地**
- 詳細は [① リースの仕組み 第6章](01_リースの仕組み.md)、直近の動きは [④ 直近トピック](04_直近トピック_2026.md)

## 8. まとめ：この章の骨

1. リース会社は**預金を持たない金融機関**。調達は借入・社債・CP・証券化で、格付けが生命線
2. 稼ぎは薄いスプレッド×巨大な資産。**売上や利益率ではなく、資産利回りと与信費用で見る**
3. 利上げは銀行と逆に**調達が先に効く**。料率転嫁が追いつくまで利ざやが縮む
4. 固有リスクは**与信と残価**。担保になる物件とは「外せて・運べて・買い手がいる」物件のこと
5. 大手はファイナンス型・アセット型・投資型を重ねており、**増益が一過性か経常かの切り分け**が要る

## 9. 用語メモ

| 用語                           | 意味                                                                                   |
| ------------------------------ | -------------------------------------------------------------------------------------- |
| **スプレッド（利ざや）**       | 運用利回りと調達利回りの差。リース会社の粗利の源泉                                     |
| **ALM（資産負債管理）**        | 資産と負債の金利タイプ・期間を合わせてリスクを抑える管理。金利上昇局面で重要性が増す   |
| **CP（コマーシャルペーパー）** | 企業が短期資金を市場から直接調達する無担保の約束手形                                   |
| **証券化／ABS**                | 債権をまとめて投資家に売る仕組み。資産をBSから外して回転させられる                     |
| **営業資産**                   | リース債権・賃貸資産・割賦債権・営業貸付金などの合計。リース会社の「元手を投じた資産」 |
| **与信費用**                   | 貸倒引当金繰入＋貸倒損失。景気後退で最も大きく利益を振らす項目                         |
| **残価設定／残価保証**         | 期末の物件価値をいくらと見込むか／第三者がその価格を保証する仕組み                     |
| **ベンダーリース**             | メーカー・販売店と組み、販売時点でリースを提案するチャネル。小口を大量に取る           |
| **D/Eレシオ**                  | 有利子負債 ÷ 自己資本。レバレッジの大きさ                                              |
| **グリーンボンド**             | 資金使途を環境事業に限定して発行する債券                                               |
