保険はどういう仕組みか

金融生命保険

このノートで分かること：生命保険は「確率の平均化」と「超長期の借金」を組み合わせた装置である。
保険料がどう決まり、利益がどこから出て、なぜバランスシートの大半が負債になるのかを、計算の順序どおりに追う。

1. 保険とは「不確実な大損失」を「確実な小さな支出」に替えること

個人にとって、働き手の死亡やがんの治療費は確率は低いが起きたら生活が壊れる種類の損失である。
一方、同じ条件の人を何万人も集めると、「そのうち何人が死ぬか」は驚くほど安定する。
この個人には読めないが集団では読めるという性質のギャップを商売にしたのが保険である。

【保険の基本構造：相互扶助（そうごふじょ）】

   1万人の加入者                保険会社                  不幸に遭った人
  ┌──────────┐        ┌──────────────┐        ┌──────────┐
  │ 一人ひとり   │  保険料 │  集めて          │  保険金 │  数十人だけ │
  │ 少額を払う   │ ──────▶ │  プールし        │ ──────▶ │  大金を    │
  │ （確実な支出）│        │  運用して待つ     │        │  受け取る  │
  └──────────┘        └──────────────┘        └──────────┘
                             ↑
                      ここに「時間」が入る＝生命保険の最大の特徴
                      （払うのは今、受け取るのは20〜60年後）

ポイント：損害保険が「1年ごとに精算するスポット取引」に近いのに対し、
生命保険は数十年にわたる契約である。この時間差がすべての論点の源になる。
対比は 損害保険 を参照。

2. 大数の法則 ── なぜ集団にすると読めるのか

大数の法則とは、試行回数を増やすと実際の発生率が理論上の確率に近づく、という統計の性質である。

加入者数 40歳男性の年間死亡率を0.1%とした場合 実際の死亡者数のブレ幅（目安）
100人期待値0.1人0人か1人か。予測不能
1万人期待値10人おおむね4〜16人
100万人期待値1,000人おおむね940〜1,060人（±6%程度）

数字は理解のための概算（二項分布の標準偏差から計算した目安）であり、実際の商品設計値ではない。
重要なのは規模が大きいほど予測が当たる＝安全マージンを薄くできるという点で、
これが生命保険業に規模の経済が働く最大の理由である。同時に、

  • 大数の法則が壊れる事象（パンデミック、大震災）は保険のもっとも苦手な相手
  • 健康な人だけ／病気がちな人だけが偏って入ると前提が崩れる（逆選択）

ため、告知義務・健康診断・免責期間といった仕組みで集団の質をそろえている。

3. 保険料は「純保険料」と「付加保険料」に分かれる

契約者が払う保険料（営業保険料）は、次の2つでできている。

【保険料の分解】

  営業保険料（契約者が払う額）
    │
    ├─ 純保険料 ────── 将来の保険金支払いに充てる原資
    │     ├─ 死亡保険料 … 「予定死亡率」で計算
    │     └─ 生存保険料 … 満期金・年金の原資。「予定利率」で割り引く
    │
    └─ 付加保険料 ──── 保険会社の事業運営費。「予定事業費率」で計算
          ├─ 新契約費 … 募集手数料・営業職員の報酬・診査費用（**契約初年度に集中**）
          ├─ 維持費   … 契約管理、コールセンター、システム
          └─ 集金費   … 保険料の収納コスト

ここで効くのが新契約費が初年度に偏るという事実である。1年目の付加保険料だけでは
新契約費を賄えないため、保険会社は契約獲得の瞬間にいったん持ち出しになり、
契約が長く続いて初めて回収できる。だから生保は「解約されること」を極端に嫌う。
早期解約時の解約返戻金が払込額を大きく下回るのも、この費用構造から来る（解約控除）。

4. 3つの予定率と、そこから生まれる三利源

保険料は契約時に「こうなるはず」という3つの仮定（3予定）を置いて計算する。
そして実績が仮定よりよければ差が利益になる。これが三利源である。

予定率（契約時の仮定） 何の仮定か 実績がよいと出る利益 名前
予定利率集めた保険料をこの利回りで運用できる運用利回り > 予定利率利差益
予定死亡率この確率で保険金の支払いが起きる実際の死亡・入院が想定より少ない死差益
予定事業費率この比率で経費がかかる実際の経費が想定より少ない費差益
【三利源の考え方：契約時の見積もりと実績の差が利益】

  契約時の見積もり ────────▶ 実績
    予定利率 1.0%              運用実績 2.0%   → 利差益（＋）
    予定死亡率 0.10%           実際 0.07%      → 死差益（＋）
    予定事業費率 10%           実際 8%         → 費差益（＋）
                                               ─────────
                                                基礎利益の中身
  • 日本の生保では歴史的に死差益が利益の柱で、利差はむしろ足を引っ張ってきた
  • 予定利率を高く設定した契約（1980年代後半〜90年代前半、5%台の契約が存在した）は、
    その後の超低金利で運用実績が予定利率を下回り、逆ざやが長く続いた
  • 逆ざやは契約を解約しない限り消えないため、1990年代の契約が2020年代まで損益を圧迫する
    という、他業種ではまず起きない現象が起きた

ポイント：生保の損益は「今年売った商品」よりも「数十年前に売った契約の予定利率」で決まる部分が大きい。

利益指標としては、一過性の売買損益を除いた本業の利益である基礎利益（おおむね三利源の合計）が
長く使われてきたが、開示の枠組みは経済価値ベース規制へ移行しつつある（→ ③ 運用とALM）。

5. 責任準備金 ── 生保のバランスシートは「負債の塊」

保険会社は、受け取った保険料をそのまま利益にはできない。
将来の支払いに備えて積み立てる義務があり、これが責任準備金（会計上は負債）である。

【生命保険会社のバランスシート（イメージ）】

   資産                         負債・純資産
 ┌────────────────┐   ┌────────────────────┐
 │ 有価証券          │   │ **責任準備金**          │
 │  ・国債（超長期）  │   │   （総資産の8〜9割）     │
 │  ・外国証券       │   │                        │
 │  ・株式           │   ├────────────────────┤
 │ 貸付金            │   │ その他負債（支払備金など）│
 │ 不動産            │   ├────────────────────┤
 │ 現預金            │   │ 純資産・基金・内部留保    │
 └────────────────┘   └────────────────────┘

  → 資産の大半は「他人（契約者）のお金を将来返すために預かっているもの」
  • 責任準備金の大半は保険料積立金。契約ごとに、将来の保険金の現在価値から
    将来受け取る保険料の現在価値を引いた額を積む（将来法）
  • 予定利率が高い古い契約ほど、割引率が高く積立額は小さい。だが実際にはその利回りを
    稼げないため、追加責任準備金を積むことがある
  • 銀行が「預金＝いつでも返す短期の負債」を持つのに対し、生保は
    「数十年後に確定額を返す超長期の負債」を持つ。この違いが運用戦略を決定づける
    （銀行側の構造は 銀行のビジネスの基本 を参照）

6. なぜ超長期の負債を持つのか

答えは単純で、商品がそうだからである。終身保険は被保険者が亡くなるまで、
個人年金は受取開始後も数十年続く。20代で加入すれば、契約終了は60年先になりうる。

負債の性質 生命保険 銀行（預金） 損害保険
期間20〜60年要求払い〜数年多くは1年
金額の確定度死亡保険金は契約時に確定元本＋約定金利事故が起きるまで不明
早期に引き出されるか解約返戻金という形であり得るいつでも引き出される基本なし
金利上昇時の影響負債の現在価値が下がる（有利な面も）調達コストが上がる影響小

この「超長期・金額がほぼ確定」という負債を持つがゆえに、生保は
同じくらい長い資産（超長期国債）で受けるという運用（ALM）に向かう。
詳細は ③ 運用とALM。

7. 保険会社が抱える固有のリスク

リスク 中身 効き方
保険引受リスク死亡・入院・長生きが想定より多い大数の法則の前提が崩れたとき
長寿リスク年金商品で、想定より長生きされる死亡保障とは逆向き。両方持つとヘッジになる
金利リスク（ALMリスク）資産と負債の期間がずれる生保で最大。金利低下で負債価値が膨らむ
解約失効リスク想定より早く解約される新契約費を回収できない。金利上昇局面で増えやすい
信用・市場リスク保有する債券・株式の価格変動資産側の問題
オペレーショナルリスク募集品質、事務ミス、情報漏えい近年は募集の適正性が監督の焦点

8. 用語メモ

用語 意味
大数の法則試行回数が増えると実績が理論上の確率に近づく性質。保険成立の前提
逆選択リスクの高い人ほど加入したがること。告知義務や査定で抑える
営業保険料契約者が実際に払う保険料。純保険料＋付加保険料
純保険料保険金支払いに充てる部分。予定死亡率と予定利率で計算
付加保険料保険会社の経費部分。新契約費・維持費・集金費
予定利率契約時に約束する運用利回り。高いほど保険料は安くなる
予定死亡率標準生命表などに基づく死亡発生率の仮定
予定事業費率事業運営にかかる費用の仮定
三利源利差・死差・費差。実績と仮定の差から生まれる損益
逆ざや運用実績が予定利率を下回る状態。利差損
責任準備金将来の保険金支払いに備えて積む負債。総資産の8〜9割
解約返戻金解約時に契約者へ戻る金額。初期は新契約費の分だけ払込額を下回る
基礎利益保険本業の期間損益。おおむね三利源の合計。経済価値ベース指標へ移行中
