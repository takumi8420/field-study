# 運用とALM

このノートで分かること：**生保は日本最大級の機関投資家**であり、その運用は「儲けるため」ではなく
**「数十年後の支払い約束に資産の形を合わせるため」**に行われる。
なぜ国債中心になるのか、金利が上がると何が起きるのか、健全性はどう測られるのかを追う。

## 1. 生保は「運用会社」ではなく「負債に合わせる投資家」

[資産運用会社](../06_資産運用/README.md)は預かったお金を「できるだけ増やす」ことを仕事にする。
生保は違う。**返す金額と時期がほぼ決まっている負債**（責任準備金）を先に抱えていて、
その形に資産を寄せていく。これを**ALM（Asset Liability Management＝資産負債の総合管理）**という。

```
【ALMの基本発想：負債の形に資産を合わせる】

   負債（責任準備金）                資産
   ＝ 将来の保険金・年金の支払い

   年 0   10   20   30   40   50        同じ形の資産を持てば
   │    │    │    │    │    │        金利が動いても
   ▼    ▼    ▼    ▼    ▼    ▼        純資産はブレない
  ███  ███  ████ ████ ███  ██   支払い   ←──┐
                                             │ マッチング
  ███  ███  ████ ████ ███  ██   超長期国債 ←─┘
   の利払い・償還

   → ずれ（デュレーション・ギャップ）が残っている部分だけが金利リスク
```

**デュレーション**とは「金利が1%動いたときに価格が何%動くか」を年数で表した指標である。
日本の生保の負債デュレーションは20年前後とされ、これに資産を近づけるには
**20年債・30年債・40年債を買い続けるしかない**。これが「生保＝超長期国債の主要な買い手」と
言われる理由で、市場の需給を動かすほどの存在になっている。

## 2. 資産構成 ── なぜ国債中心なのか

| 資産クラス | 位置づけ | ALM上の役割 |
| --- | --- | --- |
| **国債（特に超長期）** | 中核。運用資産の大きな部分 | 負債とデュレーションを合わせる。信用リスクがほぼない |
| 社債・地方債 | 国債より利回りを取る | 期間は合うが信用リスクを負う |
| **外国証券（米国債・外国社債）** | 利回り上乗せ | 為替ヘッジコストが乗る。**日米金利差で採算が変わる** |
| 国内株式 | 配当と値上がり益、政策保有の名残 | リスク性資産。価格変動が大きい |
| 貸付金 | 企業向け・住宅ローン | 銀行と競合する領域 |
| 不動産・オルタナティブ | 分散と利回り | 流動性は低いが安定収益 |

ポイントは**「利回りが高い資産を買えばよい」わけではない**こと。
外国債券は利回りが高くても、為替リスクを避けるためのヘッジコスト（短期金利差に連動）が
高くなると実質利回りが潰れる。実際、2026年度の運用計画では主要10社のうち半数が
**国内債を積み増す**方針と報じられ、外債から国内超長期債へ資金が戻る動きが出た（2026年4月、報道ベース）。

## 3. 金利が上がると何が起きるか ── 二面性を分けて理解する

金利上昇は生保にとって**長期的には追い風、短期的には見栄えが悪くなる**という、ねじれた効き方をする。

```
【金利上昇の二面性】

  ＜会計（時価評価される資産だけ見る世界）＞
    保有債券の価格が下がる → **含み損が拡大** → 見た目が悪い
    大手3社の国内債含み損は7.8兆円規模（2025年12月末、報道ベース）

  ＜経済価値（資産も負債も時価で見る世界）＞
    保有債券の価格が下がる（資産↓）
    将来の支払い約束の現在価値も下がる（**負債↓**）
    → 資産と負債の期間が合っていれば **純資産はさほど減らない**
    → むしろ負債の減り方が大きければ **ESRは改善する**

  ＜事業（これから先の話）＞
    新しく買う債券の利回りが上がる → **逆ざやが解消していく**
    予定利率を上げられる → 貯蓄性商品が売れる
    ただし予定利率を上げた分、将来の約束も重くなる
```

> ポイント：「生保が巨額の含み損」という報道と「生保は最高益」という報道が同時に出るのは、
> **前者が資産だけを時価で見た数字**、後者が期間損益だからである。矛盾ではない。

実際、2026年3月期は金利上昇と株式配当の増加で基礎利益が大きく伸び、
日本生命はグループ基礎利益1兆3,016億円（前期比+29%）、単体で初めて1兆円台に乗せたと報じられた。
一方で同じ局面で債券含み損は拡大している。

金利上昇の副作用もある。

- **解約の増加**：より条件のよい新商品や他の金融商品に乗り換えたい契約者が増える
- **既契約の逆ざや解消には時間がかかる**：資産の入れ替えは満期到来分から少しずつしか進まない
- **超長期金利のオーバーシュート**：30年債利回りが急騰すると、ヘッジしきれない部分の損失が出る

## 4. 健全性はどう測られるか ── ソルベンシーマージン比率からESRへ

### 従来：ソルベンシーマージン比率

**ソルベンシーマージン比率**は「通常の予測を超えるリスクに、どれだけ支払余力があるか」を示す指標で、

```
  ソルベンシーマージン比率 ＝ ソルベンシーマージン総額 ÷（リスクの合計 × 1/2）× 100
```

200%を下回ると金融庁の早期是正措置の対象になる。日本の大手生保はおおむね600〜1,000%前後で
推移してきた。ただしこの指標には弱点があった。

| 弱点 | 中身 |
| --- | --- |
| 負債が時価でない | 責任準備金を契約時の前提で計算するため、**金利が動いても負債が動かない** |
| 資産だけ時価 | 金利低下で資産価値が上がると比率が改善して見える（実際は負債も膨らんでいる） |
| 国際比較しにくい | 欧州のソルベンシーIIや国際資本基準（ICS）と物差しが違う |

### 2026年3月末から：経済価値ベースのソルベンシー規制（ESR）

**ESR（Economic Solvency Ratio）**は、**資産も負債も市場整合的に時価評価**して、
その差である純資産（適格資本）がリスク量の何倍あるかを見る指標である。

```
  ESR ＝ 適格資本（＝時価の資産 − 時価の負債 ＋ 調整） ÷ 所要資本（リスク量）× 100

  ┌──────────┐            ┌──────────┐
  │  資産（時価）│            │ 負債（時価）│  ← ここが新しい
  │            │            │            │     金利で動く
  │            │            ├──────────┤
  │            │            │ 適格資本    │ ← この厚みをリスク量と比べる
  └──────────┘            └──────────┘
```

| 項目 | 内容 |
| --- | --- |
| 適用開始 | **2026年3月31日**（金融庁が2025年7月に内閣府令・告示・監督指針・Q&Aを公布） |
| 基準水準 | ESR 100%が規制上の基準。下回ると監督上の対応が段階的に発動 |
| 3つの柱 | 第1の柱＝共通の健全性基準／第2の柱＝内部管理（ORSA等）の検証／第3の柱＝開示の充実 |
| 背景 | 2007年の金融庁検討チーム報告以来の長い議論。国際資本基準（ICS）とも整合を取る |

ESR導入で何が変わるか。

1. **金利リスクが可視化される**。負債デュレーションと資産デュレーションのずれが、そのまま数字に出る
2. **超長期債への需要がさらに強まる**。ギャップを埋めるのが最も直接的な対策だから
3. **商品設計が変わる**。資本を食う商品（長期の高い予定利率保証）は出しにくくなる
4. **再保険の使い方が増える**。リスクを外に出せば所要資本が減る。ただし監督上の論点にもなった
5. **ESRの数値がIR指標になる**。株主・格付会社との対話が経済価値ベースに寄る

> ポイント：ESRは「健全性を測る物差しの入れ替え」にとどまらず、
> **どんな商品を作り、どんな資産を持つかという経営判断そのものを変える規制**である。

## 5. 再保険 ── リスクを外に出す仕組み

**再保険**は、保険会社が引き受けたリスクの一部を別の保険会社（再保険会社）に移すこと。
生保では近年、保有契約のブロックごと海外の再保険会社に移す**資産集約型再保険**が使われてきた。

| 使う理由 | 注意点 |
| --- | --- |
| 所要資本を減らし、ESRを改善できる | リスクが本当に移っているのか（実質的な移転か）の検証が必要 |
| 資本を新規事業に回せる | 相手先の信用リスク（カウンターパーティリスク）を負う |
| 運用を外部の専門会社に任せられる | 海外再保険会社のガバナンスが見えにくい |

金融庁の「2026年 保険モニタリングレポート」（2026年8月6日公表）は、
**海外再保険会社へのリスク移転に伴う構造的リスクとガバナンス**を主要論点の一つに挙げている。

## 6. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **ALM** | 資産と負債を一体で管理すること。生保の運用の基本思想 |
| **デュレーション** | 金利1%の変動に対する価格感応度を年数で表した指標 |
| **デュレーション・ギャップ** | 資産と負債のデュレーションの差。ここが金利リスクの正体 |
| **含み損益** | 時価と簿価の差。満期保有なら実現しないが、健全性の見方には影響する |
| **為替ヘッジコスト** | 外貨資産の為替リスクを避ける費用。短期金利差に連動して増減する |
| **ソルベンシーマージン比率** | 従来の支払余力指標。200%が早期是正措置の分岐点 |
| **ESR（経済価値ベースのソルベンシー比率）** | 資産・負債とも時価評価して資本の厚みを見る指標。2026年3月末から適用 |
| **ICS** | 保険資本基準。IAIS（保険監督者国際機構）が定める国際共通の資本規制 |
| **ORSA** | リスクと資本の自己評価。第2の柱で求められる内部管理プロセス |
| **再保険** | 引き受けたリスクの一部を他社に移すこと。所要資本の圧縮に使われる |
| **資産集約型再保険** | 貯蓄性契約のブロックごと再保険に出す手法。監督上の論点になっている |
| **基礎利益** | 期間損益ベースの本業利益。ESR（ストック指標）と役割が異なる |
