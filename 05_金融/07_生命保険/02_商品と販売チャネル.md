# 商品と販売チャネル

このノートで分かること：**生命保険は「何を売るか」より「誰がどう売るか」で経済が変わる**産業である。
商品類型ごとの利益の出方と、チャネル（販売経路）ごとに丸ごと異なるコスト構造を整理する。
※ここでは産業構造として説明する。個別商品の良し悪しや加入の助言は扱わない。

## 1. 商品は「何のリスクを引き受けるか」で4つに分かれる

| 類型 | 引き受けるリスク | 利益の主な源泉 | 特徴 |
| --- | --- | --- | --- |
| **死亡保障**（定期・終身・収入保障） | 早く死ぬこと | 死差 | 生保の原型。世帯人数の減少で単価が下がってきた |
| **第三分野**（医療・がん・介護・就業不能） | 病気・けが・要介護 | 死差（発生率差） | 保険期間が長く単価は小さいが**利差に依存しない**。成長分野 |
| **年金・貯蓄性**（個人年金・養老・一時払終身） | 長生きすること／元本の約束 | 利差 | 金利水準に業績が直結。銀行預金・投信と競合 |
| **変額・外貨建て**（変額保険、外貨建一時払） | 運用リスクは契約者が負う部分あり | 手数料（保険関係費） | 会社の金利リスクは小さいが、**販売の適正性**が問われる |

```
【会社から見た「リスクの引受先」と収益源】

                  リスクを誰が負うか          会社の収益源
  定期保険      ┌ 死亡リスク＝会社          → 死差
  医療・がん    ├ 発生率リスク＝会社        → 死差（発生率差）
  終身・年金    ├ 運用リスク＝**会社**       → 利差（金利が低いと苦しい）
  変額保険      ├ 運用リスク＝**契約者**     → 手数料
  外貨建保険    └ 為替リスク＝**契約者**     → 手数料＋為替の取引差

  → 低金利期に変額・外貨建てが増えたのは、会社が金利リスクを負わずに
    手数料を取れる構造だから。逆に金利が戻ると貯蓄性の円建てが復活する。
```

> ポイント：死亡保障と年金は**逆向きのリスク**（早く死ぬ／長生きする）なので、
> 両方を持つこと自体が会社にとってのヘッジになる。

## 2. 業績はどの指標で見るか ── 年換算保険料

保険は契約期間も払い方（月払・年払・一時払）もばらばらなので、単純な「売上」では比較できない。
そこで**年換算保険料**（契約1件あたりの保険料を年額に換算した額）を使う。

| 指標 | 意味 | 何が分かるか |
| --- | --- | --- |
| **新契約年換算保険料** | その年に新しく取った契約の年換算保険料 | **その年の営業力**。一時払の大型契約で大きく振れる |
| **保有契約年換算保険料** | 期末に有効な契約の合計 | **ストックの厚み**。ここが会社の体力 |
| 保有契約高 | 死亡保険金額の総額 | 昔からの指標だが、医療保険が増えたため実態を映しにくい |
| 保険料等収入 | その年に入ってきた保険料（会計上の収益） | 一時払が増えると跳ねる。**利益とは別物** |

参考値：個人保険の保有契約年換算保険料は約22兆円、新契約は約1.9兆円（2025年度、
生命保険協会の事業概況ベース。年度の区切りに注意し、最新は協会サイトで確認）。
主要16グループ・社の保険料等収入は24兆6,704億円（前期比+14.9%）、
本業利益は3兆994億円（同+13.9%）と報じられる（2026年3月期、報道ベース）。

なお**新契約年換算保険料を増やす動機**が強すぎると、乗換販売や不適切募集につながりやすい。
この緊張関係が監督上の論点になり続けている（→ [④ 業界構造と論点](04_業界構造と論点.md)）。

## 3. チャネル ── ここで経済がまったく変わる

同じ商品でも、誰が売るかで**新契約費（獲得コスト）の水準・払い方・誰が顧客を握るか**が変わる。

```
【チャネルの地図：保険会社から見た距離と支配力】

  会社が直接抱える ◀────────────────────────▶ 会社から遠い
  ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐
  │ 営業職員 │ │ 専属代理店│ │ 銀行窓販 │ │ 乗合代理店│ │ ダイレクト│
  │（内勤扱い）│ │（1社専属）│ │（銀行が売る）│ │（複数社比較）│ │（ネット・通販）│
  └────────┘ └────────┘ └────────┘ └────────┘ └────────┘
    固定費が重い    中間          手数料が高い   比較され負ける  獲得は広告費
    顧客は会社の    　　          顧客は銀行の   顧客は代理店の  顧客は会社の
```

| チャネル | コスト構造 | 売れやすい商品 | 会社にとっての強み・弱み |
| --- | --- | --- | --- |
| **営業職員** | 人件費＝**ほぼ固定費**。採用・教育・拠点維持が重い | 死亡保障、医療 | 継続率が高く関係が長い。一方で採用難と離職で規模維持が難しい |
| **専属代理店** | 手数料＝変動費。一定の固定支援 | 死亡保障、法人向け | 固定費を持たずに営業網を持てる |
| **銀行窓販** | 銀行へ支払う**販売手数料が高い** | 一時払終身、個人年金、外貨建て | 一度に大型契約が取れる。ただし顧客接点は銀行が握る |
| **乗合代理店（保険ショップ等）** | 手数料＋比較で選ばれるコスト | 医療、がん、学資 | 大量に売れるが**他社と並べて比較される**。推奨理由の透明性が課題 |
| **ダイレクト（ネット・通販）** | 広告費＝**変動費**。人手が薄い | シンプルな定期・医療 | 付加保険料を薄くできる。ただし高額・複雑商品は売りにくい |

### チャネル別のシェア感

- 営業職員チャネル（自宅訪問＋職域）のシェアは1994年の約87%から2018年に約54%まで低下したが、
  その後反転し2024年も57%程度で横ばい〜微増（第一生命経済研究所の分析、2025年）
- 来店型保険ショップの市場規模（新契約年換算保険料）は2024年度に2,173億円（前年度比+5.2%）、
  2025年度は2,232億円（同+2.7%）と予測される（矢野経済研究所の推計、2025年）
- ダイレクトは伸びているが構成比は一桁%にとどまる（同上）

> ポイント：「営業職員は終わった」とよく言われるが、データ上はむしろ下げ止まっている。
> 生命保険は**説明されないと買われない商品**であり、対面が完全には消えないのが実態。

## 4. 手数料と利益相反 ── なぜ開示が論点になるのか

乗合代理店は複数社の商品を並べて勧める。だが受け取る手数料は会社ごとに違うため、
**「顧客に合うから勧める」のか「手数料が高いから勧める」のか**が外から見えない。
これが構造的な利益相反であり、規制の焦点になってきた。

| 時期 | 動き |
| --- | --- |
| 2016年 | 改正保険業法施行。募集人に**意向把握義務・情報提供義務**、乗合代理店に比較推奨の説明義務 |
| 2019年 | 法人向け「節税保険」への税務通達改正（→ [④](04_業界構造と論点.md)） |
| 2020年代前半 | 外貨建保険の販売時説明・苦情が監督テーマに。販売量は減少傾向 |
| 2025年 | 令和7年保険業法改正。**特定大規模乗合保険募集人**の枠組みを新設 |
| 2026年3月30日 | 改正に係る内閣府令等を公布（金融庁）。施行は2026年6月1日 |
| 2026年6月1日 | 過度な便宜供与の禁止、比較推奨販売の適正確保、体制整備義務の強化が施行 |

2026年施行の改正では、①特定大規模乗合保険募集人への体制整備義務（営業所ごとの法令等遵守責任者、
本店の統括責任者、苦情処理体制）、②保険会社による代理店への**過度な便宜供与の禁止**、
③比較推奨販売の適正確保、④保険仲立人（ブローカー）の活用促進、が柱になっている。
手数料等の対価の額についても施行令・施行規則で範囲が整理された。

## 5. 商品設計と金利の関係 ── 2026年に何が起きたか

予定利率は契約時に固定されるため、**金利が上がると新規契約の条件がよくなる**。
長期金利の上昇を受けて、貯蓄性商品の予定利率が相次いで引き上げられた。

| 時期 | 動き | 出所 |
| --- | --- | --- |
| 2026年前半 | 一時払終身・個人年金の予定利率が1.75〜2.08%が主流に。2001年以来の水準 | 報道ベース |
| 2026年7月 | 一部大手が一時払終身の予定利率を1.75%→**2.25%**へ。引き上げ幅0.50ポイント | 各社リリース・報道ベース |
| 2026年6月 | 住友生命が一時払終身保険の保険料率を改定 | 同社ニュースリリース（2026年6月25日） |

会社側から見ると、貯蓄性商品が売れることは**必ずしも利益ではない**。
予定利率を上げた分だけ将来の支払い約束が重くなるので、
それに見合う超長期の運用資産を同時に確保できて初めて成立する（→ [③ 運用とALM](03_運用とALM.md)）。

```
【金利局面ごとの「売れる商品」の移り変わり】

  超低金利（2016〜2023）        金利のある世界（2024〜）
  ─────────────────       ─────────────────
  円建て貯蓄性 … 予定利率を   円建て貯蓄性 … 予定利率を上げられる
                 下げるしかない               → 主戦場に復帰
  外貨建て     … 相対的に有利   外貨建て     … 円との金利差が縮小、販売は減少傾向
  変額保険     … 運用リスクを   変額保険     … 資産形成需要で残る
                 契約者へ移す
  第三分野     … 金利に左右さ   第三分野     … 引き続き安定的な柱
                 れず安定
```

## 6. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **第三分野** | 医療・がん・介護など、生保（第一分野）と損保（第二分野）の中間にある保険 |
| **年換算保険料** | 払い方の違いをならして年額に換算した保険料。新契約／保有の2種類で見る |
| **保有契約高** | 死亡保険金額の合計。医療保険中心の時代には実態を映しにくい |
| **一時払** | 保険料を契約時に一括で払う方式。金額が大きく、保険料等収入を大きく振らす |
| **変額保険** | 運用実績で受取額が変わる保険。運用リスクの相当部分を契約者が負う |
| **外貨建保険** | 米ドル等で運用・支払いを行う保険。為替リスクは契約者側 |
| **乗合代理店** | 複数の保険会社の商品を扱う代理店。保険ショップが代表例 |
| **銀行窓販** | 銀行の窓口で保険を販売すること。2007年に全面解禁 |
| **比較推奨販売** | 複数商品を比較して特定商品を勧める販売。推奨理由の説明が義務 |
| **特定大規模乗合保険募集人** | 令和7年改正で新設された、一定規模以上の乗合代理店の区分。体制整備義務が重い |
| **保険仲立人（ブローカー）** | 保険会社の代理ではなく**顧客側の立場**で契約を媒介する免許業者 |
| **継続率（13回目・25回目）** | 契約が初期に維持されている割合。募集品質の代表的な指標 |
