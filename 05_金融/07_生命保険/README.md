# 生命保険

- 大分類: 金融
- 状態: done
- 更新日: 2026-09-20

**一言でいうと**：大勢から少しずつ保険料を集め、**数十年後に確定額を返す超長期の負債**を抱えながら、
その間の運用差・死亡率差・経費差（**三利源**）で稼ぐ装置。銀行が「短い負債」を持つのに対し、
生保は「長い負債」を持つ。2026年3月末から**経済価値ベースの健全性規制（ESR）**が始まり、
物差しそのものが変わった年にあたる。

※本フォルダは**産業構造と制度の説明**に徹する。個別商品の推奨・加入助言は一切行わない。

## 1. 業界の定義・範囲

**生命保険業**とは、保険業法の免許（生命保険業免許）を受け、人の生存・死亡に関して
一定額の保険金を支払うことを約して保険料を収受する事業を指す（第一分野）。
医療・がん・介護などの**第三分野**は生損保どちらも扱える。

| 区別する相手 | 境界 |
| --- | --- |
| [損害保険](../08_損害保険/README.md) | もの・賠償の「実際に生じた損害」を1年単位で補償（第二分野）。生保は**契約時に決めた定額**を払う |
| [少額短期保険](../09_少額短期保険/README.md) | 登録制。保険金額・保険期間に上限があるミニ保険 |
| 共済（こくみん共済、JA共済、県民共済 等） | 保険業法ではなく協同組合法に基づき、監督官庁も異なる。実質的な競合 |
| [資産運用](../06_資産運用/README.md)・[証券](../05_証券/README.md) | 変額保険・個人年金は投信と同じ資産形成需要を奪い合うが、免許も規制も別 |
| 公的年金・公的医療保険 | 強制加入の社会保険。生保はその**上乗せ**という位置づけ |
| 再保険会社 | 保険会社のリスクを引き受ける「保険会社のための保険会社」 |

**含める範囲**：生命保険会社本体に加え、販売を担う代理店、保険料を運用する資産運用子会社、
海外子会社までを一体で見る。生保の損益は**契約の残存期間全体**でしか意味をなさないため。

## 2. 市場規模と成長性

| 指標 | 数値 | 時点・出典 |
| --- | --- | --- |
| 主要16グループ・社の保険料等収入 | **24兆6,704億円**（前期比+14.9%） | 2026年3月期、報道ベース |
| 同 本業利益（基礎利益・業務利益） | **3兆994億円**（同+13.9%、13社が増益） | 同上 |
| 日本生命 グループ基礎利益 | **1兆3,016億円**（同+29%）。単体で初の1兆円台 | 2026年3月期、報道ベース |
| 個人保険の保有契約年換算保険料 | 約22兆円 | 2025年度、生命保険協会 事業概況ベース |
| 個人保険の新契約年換算保険料 | 約1.9兆円 | 同上 |
| 生命保険の世帯加入率（2人以上世帯） | **89.2%** | 2024年度、生命保険文化センター 全国実態調査 |
| 単身世帯の加入率 | 45.6% | 同上（初調査） |
| 世帯年間払込保険料 | 平均35.3万円 | 同上 |
| 生命保険協会 加盟会社数 | 40社強 | 2025年時点 |

成長性の見方は銀行に似て独特で、**「加入者が増えるか」ではなく「金利がどこにあるか」**でほぼ決まる。

- 世帯加入率はすでに約9割。**新規加入者を増やす余地は構造的に小さい**
- 世帯人数の減少で1件あたりの死亡保険金額は下がり続けている
- 一方、金利が上がるだけで①逆ざやが解消し②貯蓄性商品が売れ③利息配当金が増える
- したがって成長ドライバーは ①金利水準 ②第三分野（医療・がん・介護） ③海外M&A の3つ

## 3. バリューチェーン（お金の流れ）

生保のバリューチェーンは物ではなく、**お金が数十年かけて往復する流れ**である。

```
【生命保険のお金の流れ：集める → 積む → 運用する → 返す】

 ＜集める＞                 ＜積む＞                ＜運用する＞          ＜返す＞

  契約者 ─ 保険料 ─┐                              超長期国債
   （数千万人）      │      ┌──────────┐       外国証券          保険金・給付金
                     ├──▶ │ 責任準備金  │ ──▶  株式          ──▶  年金・満期金
  ＜売る人＞         │      │（総資産の   │       貸付金             解約返戻金
   営業職員         │      │  8〜9割）   │       不動産                │
   代理店・保険ショップ│      └──────────┘                            ▼
   銀行窓販          │            ↑                                 20〜60年後
   ネット           ─┘      ここが「負債」。
                            会社の資産ではない
        ↑
   新契約費（手数料・人件費）は**契約初年度に集中**
   → 長く続いて初めて回収できる ＝ 解約が最大の敵

  付加価値が集まるのは
    ①**長く続く契約を大量に持っている者**（保有契約のストック）
    ②**負債に合う超長期資産を確保できる者**（ALM）
    ③**顧客接点を握っている者**（営業職員か、代理店か、銀行か）
```

詳細は [① 保険はどういう仕組みか](01_保険はどういう仕組みか.md) と
[② 商品と販売チャネル](02_商品と販売チャネル.md)。

「シェア」は単年の新契約では振れが大きいため、**保有契約年換算保険料（ストック）**で見るのが実態に近い。
一時払商品が売れた年は保険料等収入が跳ねるが、それは利益とは別物である。

## 5. 収益モデル・コスト構造

```
【生保の利益はどこから出るか（三利源）】

  ①利差 ＝（実際の運用利回り − 予定利率）× 責任準備金
       → 金利がすべて。1990年代の高予定利率契約が長く「逆ざや」を生んだ

  ②死差 ＝（予定死亡率 − 実際の死亡・入院発生率）× 保険金額
       → 日本の生保の伝統的な利益の柱。医療の発達で死亡率は想定より低く出やすい

  ③費差 ＝（予定事業費 − 実際の事業費）
       → 営業職員は**固定費**、代理店手数料は**変動費**。チャネル構成で性格が変わる

      ①＋②＋③ ≒ **基礎利益**（期間損益ベースの本業の儲け）
       ± キャピタル損益（有価証券売却損益）
       ± 臨時損益（追加責任準備金の繰入など）
      ＝ 経常利益 → 当期純剰余（相互会社）／当期純利益（株式会社）
```

| 指標 | 意味 | 見方 |
| --- | --- | --- |
| **基礎利益** | 三利源の合計。本業の期間損益 | 一過性の売買益を除いた実力。ただしストック指標ではない |
| **新契約年換算保険料** | その年に取った契約の年額換算保険料 | 営業力。ただし追い過ぎると不適切募集の温床になる |
| **保有契約年換算保険料** | 期末の有効契約の合計 | **会社の体力**。ここが縮むと将来の利益が細る |
| **継続率（13回目・25回目）** | 契約が初期に維持されている割合 | 募集品質。低いと新契約費を回収できない |
| **ソルベンシーマージン比率** | 従来の支払余力指標 | 200%が早期是正措置の分岐点。負債が時価でないのが弱点 |
| **ESR** | 資産・負債とも時価評価した資本の厚み | **2026年3月末から適用**。100%が基準 |

コスト構造の要点は**新契約費が初年度に集中する**こと。契約獲得の瞬間は持ち出しで、
長く続いて初めて回収できる。だから生保は解約・失効を極端に嫌い、
営業職員という重い固定費を維持してでも継続率を守ろうとする（→ [②](02_商品と販売チャネル.md)）。

## 6. 競争要因（KSF）と参入障壁

| 優位の源泉 | 中身 | 真似しにくさ |
| --- | --- | --- |
| **保有契約のストック** | 数十年分の契約が生む安定収益。時間でしか積めない | ★★★ |
| **顧客接点（チャネル）** | 営業職員網、郵便局網、銀行との関係 | ★★★ |
| **資本の厚み** | ESR下では資本がそのまま引受能力になる | ★★★ |
| **超長期資産の確保力** | 負債に合う資産を買い続ける市場でのプレゼンス | ★★ |
| **アクチュアリー（保険数理人）の層** | 商品設計と責任準備金計算を担う専門職。人数が限られる | ★★ |
| **死亡・罹患データの蓄積** | 予定率の精度に直結 | ★★ |
| **ブランド・信用** | 数十年後に本当に払ってくれるか、という信頼 | ★★ |

参入障壁は**生命保険業免許（金融庁の免許制）**と**資本要件**。
ネット系・損保系の新規参入はあったが、取れたのは主にシンプルな定期・医療であり、
**超長期の貯蓄性商品と巨大な営業職員網**という中核には届いていない。
参入しやすい方向として[少額短期保険](../09_少額短期保険/README.md)（登録制）がある。

## 7. 規制・法制度

| 制度 | 中身 | 生保への効き方 |
| --- | --- | --- |
| **保険業法** | 免許制、生損保兼営の禁止、相互会社制度、募集規制 | 業界の基本法。子会社方式での相互参入の根拠 |
| **標準責任準備金制度** | 金融庁が定める標準利率・標準生命表で責任準備金を計算 | 会社ごとの恣意を排し、積立不足を防ぐ |
| **ソルベンシーマージン比率規制** | 200%割れで早期是正措置 | 従来の健全性の物差し |
| **経済価値ベースのソルベンシー規制（ESR）** | 資産・負債とも時価評価。**2026年3月31日適用開始**（2025年7月に府令等公布） | 金利リスクが可視化され、商品設計・運用・再保険が同時に変わる |
| **令和7年保険業法改正** | 特定大規模乗合保険募集人の体制整備義務、**過度な便宜供与の禁止**、比較推奨販売の適正確保、保険仲立人の活用促進 | 2026年3月30日に府令等公布、**2026年6月1日施行** |
| **意向把握義務・情報提供義務** | 2016年施行の改正保険業法 | 乗合代理店の比較推奨に説明義務 |
| **保険契約者保護機構** | 破綻時に責任準備金の原則90%まで補償 | 契約者が会社の信用リスクを全部は負わない前提 |
| **法人税基本通達（定期保険等）** | 最高解約返戻率50%超は保険料の一部を資産計上（2019年7月8日以後契約） | 「節税保険」の販売手法を封じた |
| **金融サービス提供法・顧客本位の業務運営原則** | 最終顧客の利益を優先する行動規範 | 手数料と推奨理由の透明性を要求 |

## 8. 最近のトピック

詳細は [⑤ 直近トピック（2026年9月時点）](05_直近トピック_2026.md)。要点は5つ。

1. **ESRが2026年3月31日から適用開始**。資産・負債とも時価評価する物差しに移行し、
   デュレーション・ギャップがそのまま数字に出るようになった
2. **2026年3月期は歴史的な増益**。主要16グループ・社の本業利益3兆994億円（+13.9%）、
   日本生命はグループ基礎利益1兆3,016億円（+29%）と報じられる。主因は金利上昇と株式配当
3. **同時に巨額の含み損**。大手3社の国内債含み損は7.8兆円規模（2025年12月末、報道ベース）。
   最高益と含み損が同時に出るのは、見ている断面が違うため
4. **予定利率が2001年以来の水準へ**。一時払終身で1.75%→2.25%へ引き上げた社があると報じられ、
   貯蓄性商品が主戦場に戻った。運用計画も外債から国内超長期債へ傾いた
5. **令和7年保険業法改正が2026年6月1日施行**。乗合代理店の体制整備義務、過度な便宜供与の禁止。
   金融庁「2026年 保険モニタリングレポート」（2026年8月6日）は海外再保険と経済価値ベース管理を論点に挙げた
