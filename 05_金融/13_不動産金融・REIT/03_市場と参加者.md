# 市場と参加者（私募ファンド・AM会社・アセットタイプ・金利）

このノートで分かること：**日本の不動産金融市場は誰のお金が、どの器を通って、どの種類の建物に
流れているのか**。そして**金利が上がると不動産価格はなぜ下がるのか**という、
この業界で最も重要な因果関係（キャップレート）。

> ポイント：上場しているJ-REITは、日本の不動産金融市場の**一部にすぎない**。
> 金額で見れば、表に出ない私募ファンドの方が大きい。

**本ノートは市場構造の説明であり、個別銘柄・ファンドの推奨ではない。**

## 2. 器（ビークル）の種類 — 何が違うのか

同じ「不動産ファンド」でも、**上場しているか／解約できるか／期限があるか**で性質が全く異なる。

| 種類                                             | 上場      | 期限                         | 換金方法                                   | 価格の決まり方                     | 主な投資家                 |
| ------------------------------------------------ | --------- | ---------------------------- | ------------------------------------------ | ---------------------------------- | -------------------------- |
| **J-REIT**                                       | ○（東証） | なし（永続）                 | 市場で売る                                 | **市場の需給**（NAVから乖離する）  | 個人、海外、投信、金融機関 |
| **私募REIT**                                     | ✕         | なし（永続＝オープンエンド） | **運用会社に解約請求**（回数・上限に制限） | **鑑定評価ベース**（日々動かない） | 年金基金、地銀、生保       |
| **私募ファンド（クローズドエンド）**             | ✕         | **あり**（3〜7年程度）       | 期限まで動かせない                         | 鑑定＋出口の売却価格               | 機関投資家、外資ファンド   |
| **不動産特定共同事業（クラウドファンディング）** | ✕         | あり（数か月〜数年）         | 原則できない／事業者次第                   | 事業者の設定                       | 個人（1万円〜）            |
| **上場インフラファンド**                         | ○（東証） | なし                         | 市場で売る                                 | 市場の需給                         | 個人中心                   |

### オープンエンドとクローズドエンドの違い

```
【クローズドエンド型】期限がある＝出口で必ず売る

  組成 ──── 運用（3〜7年）──── 期限：物件を売って解散
   ↑                                    ↓
  投資家が出資                   売却益込みで返ってくる
  → 出口の市況に成績が全面的に左右される
  → 市況が悪いと投げ売りになる（2008〜2009年に起きたこと）

【オープンエンド型】期限がない＝持ち続ける

  組成 ──── 運用（無期限）──────────────▶
              ↑↓ 随時の追加出資と解約請求（上限あり）
  → 出口の市況に賭けなくてよい
  → 年金基金のように「長く持ちたい」お金と相性がよい
  → ただし解約が殺到すると物件を売らざるを得ない（解約制限＝ゲートを設ける）
```

**私募REITが2010年代以降に伸び続けているのはこの性質による。**鑑定評価ベースで日々の値動きがなく期限もないため、
年金基金や地域金融機関が「賃料利回りを長く受け取る資産」として組み入れやすい。
資産総額は2026年6月末で8兆665億円（前年比+11.3%、ARES調査）と拡大が続いている。

```
   年金基金（企業年金・公的年金）… 長期・安定志向 → 私募REIT、コア型
   生命保険                      … 負債が超長期 → [生命保険](../07_生命保険/README.md)
   地方銀行・信金                … 利回り資産 → [地方銀行](../02_地方銀行/README.md)
   海外の機関投資家・ソブリンファンド … GIC、年金、大学基金など
   デベロッパー・商社            … 自社案件への共同出資
   個人                          … J-REIT、クラウドファンディング

  ＜デット＞
   銀行（メガ・信託・地銀）      … ノンリコースローンのシニア → [メガバンク](../01_メガバンク/README.md)
   生命保険                      … 長期のシニア
   ノンバンク・専門ファンド      … メザニン
   社債市場                      … 投資法人債（J-REITのみ）
```

| 投資家           | 求めるもの                                         | 好む器                         |
| ---------------- | -------------------------------------------------- | ------------------------------ |
| **年金基金**     | 長期の安定インカム、株式との分散                   | 私募REIT、コア型私募ファンド   |
| **生命保険**     | 超長期の利回り資産（負債と期間を合わせる）         | シニアローン、私募REIT         |
| **地域金融機関** | 貸出だけでは埋まらない利回り                       | 私募REIT、J-REIT               |
| **海外ファンド** | 円安と低金利を活かしたリターン、バリューアップ余地 | 私募ファンド、開発型、大型一棟 |
| **個人**         | 少額・換金性・分配金                               | J-REIT、クラウドファンディング |

## 4. リスク・リターン別の4類型

不動産ファンドの世界では、運用スタイルを4つに分けるのが国際的な共通語になっている。

| 類型                     | 中身                                         | 想定リターン（年、目安） | レバレッジ          | 典型例                 |
| ------------------------ | -------------------------------------------- | ------------------------ | ------------------- | ---------------------- |
| **コア（Core）**         | 都心の優良な稼働済み物件を長く持つ           | 3〜5%程度                | 低め（LTV 30〜50%） | 私募REIT、J-REIT       |
| **コアプラス**           | コアに軽い改善余地を足す                     | 5〜8%程度                | 中                  | 私募ファンド           |
| **バリューアッド**       | 空室を埋める、改修して賃料を上げる、用途転換 | 10〜15%程度              | 高め（LTV 50〜70%） | 外資系・独立系ファンド |
| **オポチュニスティック** | 開発、不良債権、経営難の物件、大規模再生     | 15%以上を狙う設計        | 最も高い            | PEファンド、開発型     |

> 数値は市場慣行としてよく語られる目安であり、保証された利回りではない。
> 実際のリターンは物件・時期・金利水準で大きく変わる。

## 5. 不動産アセットマネジメント（AM）会社

**実際に物件を買い、貸し、売るのを決めているのがAM会社**である。
投資家から預かった資金を運用するため、金商法上の**投資運用業（投資一任）**などの登録が要る。

| 系統                           | 成り立ち                     | 強み                                       | 弱み                         |
| ------------------------------ | ---------------------------- | ------------------------------------------ | ---------------------------- |
| **デベロッパー系**             | 親会社の開発部門から派生     | 自社開発物件のパイプライン、都心の大型物件 | 親会社の方針に左右される     |
| **商社系**                     | 商社の不動産部門             | 資金力、海外ネットワーク、複数アセット     | 開発の現場力は外部依存もある |
| **金融系（信託・銀行・証券）** | 金融グループの運用会社       | 資金調達、機関投資家との関係               | 物件のオペレーション         |
| **外資系**                     | グローバルファンドの日本拠点 | 資金調達の多様性、バリューアップの手法     | 撤退・方針転換が速い         |
| **独立系**                     | 専門家が創業                 | 意思決定の速さ、ニッチ特化                 | 資金調達力、信用             |

AM会社の収益は**預かり資産（AUM）×料率**が基本で、ここは [資産運用](../06_資産運用/README.md) 業とまったく同じ構造。
違いは**物件そのものの運営判断まで担う**点で、金融というより事業に近い部分がある。

```
【AM会社の収益の作り方】

  運用報酬（AUM × 0.3〜0.5%前後） … 安定収入。AUMを積むほど増える
  ＋ 取得・売却報酬（取引額の0.5〜1%前後） … 動かすと入る
  ＋ 成功報酬（目標リターン超過分の一部） … 私募ファンドで一般的
  − 人件費（ほぼ全部これ）

  → 装置産業ではなく人の商売。固定費は人件費。
  → AUMが一定規模を超えると急に儲かる（オペレーティングレバレッジ）
```

## 6. アセットタイプ別の経済性 — 建物の種類で儲け方が違う

**同じ「不動産」でも、賃料の決まり方とリスクの出方が全く異なる**。
これが分かると、ファンドやREITがなぜ特定の用途に特化するのかが見えてくる。

| アセット                     | 賃料の決まり方                     | 景気感応度           | 主なリスク                     | 運営の手間         |
| ---------------------------- | ---------------------------------- | -------------------- | ------------------------------ | ------------------ |
| **オフィス**                 | 2〜3年の定期改定。市況に連動       | 高い                 | 空室、新規供給、在宅勤務       | 中                 |
| **物流施設**                 | 長期の一棟貸しが多い（5〜10年）    | 中                   | **新規供給の集中**、立地依存   | 低                 |
| **住宅（賃貸マンション）**   | 入退去のたびに小刻みに改定         | **低い**（生活必需） | 人口動態、修繕費               | 中〜高             |
| **商業施設**                 | 固定賃料＋**売上歩合**             | 高い                 | EC化、テナント業績             | 高                 |
| **ホテル**                   | **変動賃料**（GOP連動）や自主運営  | **最も高い**         | 観光需要、災害、感染症         | 最も高い           |
| **データセンター**           | 超長期契約、電力容量で価格が決まる | 低い（契約期間中）   | **電力確保**、陳腐化、大型投資 | 特殊（専門運営）   |
| **ヘルスケア（高齢者住宅）** | 長期固定。オペレーター依存         | 低い                 | オペレーターの経営破綻         | 低（賃貸型の場合） |

### 私募ファンドのアセット別構成（2026年6月末、ARES調査）

```
  オフィス     ████████████████████  35.1%
  住宅         ████████████          22.1%
  物流施設     ███████████           19.6%
  商業施設     ████████               15.1%
  ホテル       ███                     5.9%
  その他       █                       2.2%
```

> 読み方：**オフィスが依然として最大だが、住宅と物流で4割を超える**。
> 2010年代以降、EC拡大とサプライチェーン再編で物流施設が独立した投資対象として確立し
> （→ [物流施設](../../12_建設・住宅・不動産/16_物流施設/README.md)）、
> 景気に左右されにくい住宅が「守りの資産」として組み入れられた結果である。

### アセット別の具体的な違い

- **オフィス**：2026年7月時点で都心5区の平均空室率1.95%、平均募集賃料2万3,287円/坪と30か月連続上昇（三鬼商事、報道ベース）。
  **賃料が上がる＝内部成長が効く局面**。ただし新築ビルの空室率は高めに出るので、大型供給の年は全体の数字が振れる
- **物流施設**：契約が長い分、賃料改定の機会が少なく**インフレに弱い**という裏側がある。エリアごとの空室率の差も大きい
- **ホテル**：**GOP（営業粗利益）連動**の変動賃料だと需要の波がそのまま分配金に出る。2020年に分配金がほぼ消えたREITもあった
  → [ホテル](../../15_サービス・生活関連/09_ホテル/README.md)
- **データセンター**：日本では上場REITへの組入れ実績が乏しく「その他」扱いが中心。2025〜2026年は**専門の私募ファンド組成が相次ぐ**
  （→ [④](04_直近トピック_2026.md)）→ [データセンター](../../04_情報通信・IT・ネット/03_データセンター/README.md)

## 7. 金利と不動産価格 — キャップレートの算数

**この業界で最も重要な1本の式**がこれ。

```
       NOI（年間の純収益）
 価格 ＝ ─────────────────
       キャップレート（期待利回り）

  ＊キャップレート（Cap Rate、還元利回り）＝ 投資家がその物件に求める年間利回り
```

分母が上がると価格は下がる。**分母は「安全な金利＋リスクの上乗せ」で決まる**。

```
  キャップレート ＝ 長期金利（リスクフリーレート） ＋ リスクプレミアム
                     └ 日銀の政策と国債需給で動く ┘   └ 物件・用途・立地・流動性 ┘
```

### 数字で見る効き方

前提：NOI＝4.0億円（一定）。

| キャップレート | 価格          | 元（3.5%）からの変化 |
| -------------- | ------------- | -------------------- |
| 3.0%           | 133.3億円     | +16.7%               |
| **3.5%**       | **114.3億円** | —                    |
| 4.0%           | 100.0億円     | **−12.5%**           |
| 4.5%           | 88.9億円      | −22.2%               |
| 5.0%           | 80.0億円      | −30.0%               |

> **キャップレートが0.5ポイント上がるだけで価格は1割以上下がる**。
> 低い利回りの物件ほど影響が大きい（3.0%→3.5%は−14%、5.0%→5.5%は−9%）。
> だから**都心の高額・低利回り物件ほど金利上昇に脆い**。

### ただし一方向ではない — NOIも動く

```
【金利上昇が不動産に効く3つの経路】

  ① 割引率の経路（マイナス）
     長期金利↑ → キャップレート↑ → 価格↓

  ② 借入コストの経路（マイナス）
     政策金利↑ → 変動金利の利払い↑ → 分配金↓
     （→ [①のレバレッジの算数](01_不動産を金融商品にする仕組み.md)）

  ③ インフレ・賃料の経路（プラス）
     物価↑・賃金↑ → 賃料↑ → NOI↑ → 価格↑
     ＋ 建設費↑ → 新規供給が減る → 既存物件の希少性↑

  結論：①②と③のどちらが速いかで勝負が決まる。
        賃料が上がる局面の利上げは耐えられ、
        賃料が上がらない局面の利上げは効く。
```

2026年時点の日本はこの綱引きの真っただ中にある。日銀は2026年9月18日に政策金利を1.0%程度から**1.25%程度**へ引き上げ、
1995年以来およそ31年ぶりの水準と報じられた。一方でオフィス賃料は30か月連続で上昇している（三鬼商事、2026年7月）。
どちらが勝つかがそのまま不動産価格の方向になる。詳細は [④ 直近トピック](04_直近トピック_2026.md)。

## 8. 海外投資家の存在感

| 動き                   | 内容                                                                                       | 時点                                          |
| ---------------------- | ------------------------------------------------------------------------------------------ | --------------------------------------------- |
| **投資額の増加**       | 外国資本の購入額が前年同期比で約4割増。全体に占める比率も過去10年平均を上回る              | 2026年上期（JLL、報道ベース）                 |
| **主な出し手**         | 米国が最大。香港・シンガポールなどアジア勢の存在感も上昇                                   | 同上                                          |
| **J-REIT市場での売買** | 海外投資家は2026年6月時点で売り越しに転じたと報じられる                                    | 2026年6月                                     |
| **TOBへの参画**        | シンガポール政府系ファンドGICがトーセイと組み、サンケイリアルエステート投資法人のTOBに参画 | 2026年1〜2月（→[④](04_直近トピック_2026.md)） |

> 現物不動産は買い越し、上場J-REITは売り越しという**逆方向の動き**が同時に起きうる点が理解の勘どころ。
> 現物は「円安と賃料上昇を取りに行く長期資金」、J-REITは「金利観測で機動的に売買される上場商品」として扱われているためである。

日本が海外資金から選ばれてきた理由は、おおむね次の3つと整理される。

1. **調達金利が世界的に低い**（レバレッジのスプレッドが取りやすい）→ ただし縮小中
2. **円安**（ドル建てで見た取得価格が安い）
3. **市場の透明性と物件の質**（登記制度、鑑定慣行、テナントの信用）

## 9. 不動産クラウドファンディング（個人向けの小口化）

**不動産特定共同事業法（不特法）**に基づき、事業者が物件を小口化して個人に販売する仕組み。
2017年の法改正で電子取引業務が認められ、オンライン完結型が広がった。

| 項目             | 中身                                                                    |
| ---------------- | ----------------------------------------------------------------------- |
| **最低投資額**   | 1万円程度から                                                           |
| **仕組み**       | 匿名組合型が主流。事業者が物件を運用し、利益を分配                      |
| **優先劣後構造** | 事業者が劣後出資（例：全体の10〜30%）を負担し、損失を先に被る設計が多い |
| **流動性**       | 原則として途中解約できない。市場がない                                  |
| **主なリスク**   | 事業者の破綻、元本毀損、運用期間の延長。**事業者の審査が実質的な審査**  |
| **監督**         | 国土交通省・都道府県の許可制                                            |

**J-REITとの最大の違いは流動性と価格の透明性**。J-REITは毎日値段が付き売りたいときに売れるが価格が振れる。
クラウドファンディングは価格が動かない代わりに**売りたいときに売れない**。どちらが良い悪いではなく、性質が違う。

## 11. 用語メモ

| 用語                                                       | 意味                                                               |
| ---------------------------------------------------------- | ------------------------------------------------------------------ |
| **キャップレート（還元利回り）**                           | 投資家がその物件に求める年利回り。NOI ÷ 価格。上がれば価格は下がる |
| **リスクプレミアム**                                       | 長期金利に上乗せされる、その物件固有のリスク分                     |
| **イールドギャップ**                                       | キャップレート − 借入金利。レバレッジで儲かるかの目安              |
| **オープンエンド／クローズドエンド**                       | 期限がなく随時出入りできる／期限があり出口で売却する               |
| **私募REIT**                                               | 非上場・無期限の不動産投資法人。鑑定評価ベースで価格が動かない     |
| **コア／コアプラス／バリューアッド／オポチュニスティック** | リスクとリターンによる運用スタイルの4類型                          |
| **AUM**                                                    | Assets Under Management。預かり資産残高。AM会社の収益の分母        |
| **LP／GP**                                                 | Limited Partner（出資する投資家）／General Partner（運用する側）   |
| **GOP連動賃料**                                            | ホテルの営業粗利益に連動する変動賃料                               |
| **売上歩合賃料**                                           | 商業施設で、テナント売上の一定割合を賃料とする方式                 |
| **不動産特定共同事業（不特法）**                           | 個人向けに不動産を小口化して販売する制度。国交省・都道府県の許可制 |
| **優先劣後構造**                                           | 事業者が劣後出資を負担し、損失を先に被ることで投資家を保護する設計 |
| **ARES**                                                   | 一般社団法人不動産証券化協会。この業界の統計の一次情報源           |
| **デューデリジェンス（DD）**                               | 物件の法務・物理・環境・収益の事前調査                             |
| **バリューアップ**                                         | 改修・リーシング・用途転換で物件価値を上げる作業                   |
