# 直近トピック（2026年9月時点）

報道・調査会社レポートをもとにした整理。一次情報（ARES、JPX、国土交通省、各投資法人の開示）で
必ず裏取りすること。**本ノートは市況の記録であり、投資判断の助言ではない。**

このノートで分かること：**2026年の不動産金融で何が起きているのか**を5つのテーマで。
一言でいえば、**「賃料は上がっているが、金利はもっと速く上がっている」という綱引き**である。

```
【2026年の構図（1枚図）】

   日銀の利上げ（2026年9月に1.25%）        オフィス賃料30か月連続上昇
   長期金利の上昇                          稼働率ほぼ満室（都心5区 空室率1.95%）
        │                                        │
        ▼ キャップレート↑／借入コスト↑           ▼ NOI↑
   ┌────────────────────┐        ┌────────────────────┐
   │  価格への下押し圧力        │ ←比べる→ │  収益の押し上げ        │
   └────────────────────┘        └────────────────────┘
        │                                        │
        └──────────┬───────────────┘
                           ▼
     現物不動産：取引額は上半期として過去最高（3.75兆円）＝ 買いが勝っている
     J-REIT ：NAV倍率1倍前後で増資が難しく、TOB・再編が起きる
     → **「現物は強いが、上場市場は評価してくれない」というねじれ**
```

## 1. 日銀の利上げが1.25%に — 31年ぶりの水準

| 事項         | 内容                                                                                           | 時点                                              |
| ------------ | ---------------------------------------------------------------------------------------------- | ------------------------------------------------- |
| 政策金利     | 1.0%程度 → **1.25%程度**へ引き上げ                                                             | 2026年9月17〜18日の金融政策決定会合（報道ベース） |
| 水準の意味   | 1995年以来、約31年ぶりの高さと報じられる                                                       | 2026年9月                                         |
| 長期金利     | 2026年2月以降、想定を超えて上昇が続いたとされる                                                | 2026年                                            |
| 住宅ローン   | 多くの金融機関で変動・固定ともに引き上げ。短期プライムレート連動で変動型基準金利を上げる動きも | 2026年9月                                         |
| 先行きの見方 | 0.25%刻みの緩やかな利上げが続き、2027年ごろに1.5〜2.0%との予想も（民間の予想）                 | —                                                 |

不動産金融への効き方は3経路（→ [③ 市場と参加者](03_市場と参加者.md) の第7章）。

1. **キャップレートの上昇圧力** → 同じNOIでも物件価格が下がる
2. **借入コストの上昇** → J-REIT・ファンドの分配金を直接削る
3. **賃料上昇（インフレ）** → NOIを押し上げる。**唯一のプラス要因**

2026年時点では、**賃貸住宅のキャップレートは金利上昇を受けて横ばいで下げ止まり、
今後は上昇の余地がある**という見方が出ていると報じられる。
不動産価格も「急ピッチの上昇から停滞へ」移行したという整理が複数の証券系レポートに見られる。

> 実務的な論点：**変動金利比率と借入の平均残存年数**。
> 借入の多くが固定・長期であれば影響は数年かけて現れるが、
> 変動・短期が多いと即座に分配金に出る。
> 2026年のJ-REIT分析で「変動金利比率の見方」が論点として語られるのはこのため。

## 2. 現物の不動産投資は過去最高 — 上半期3兆7,517億円

| 指標                               | 数値                                                               | 時点・出典        |
| ---------------------------------- | ------------------------------------------------------------------ | ----------------- |
| 日本の商業用不動産投資額（上半期） | **3兆7,517億円**（前年同期比+17%、上半期として過去最高）           | 2026年上期、JLL   |
| うち1〜3月                         | **2兆752億円**                                                     | 2026年1〜3月、JLL |
| セクター別                         | **オフィスが全体の44%**                                            | 2026年上期、JLL   |
| 外国資本の購入額                   | 前年同期比**約4割増**。比率は過去10年平均を上回る                  | 同上              |
| 主な買い手                         | 米国が最大。香港・シンガポールなどアジア勢の存在感も上昇           | 同上              |
| CBRE集計（事業用不動産）           | 前年同期比+2%の2兆430億円、海外投資家による1,000億円超の取得が継続 | 2026年、CBRE      |

金利が上がっているのに投資額が過去最高という**一見矛盾した構図**が生じている。
説明としてよく挙げられるのは次の3点。

| 要因                           | 中身                                                    |
| ------------------------------ | ------------------------------------------------------- |
| **賃料上昇の期待**             | 都心オフィスがほぼ満室で賃料が上がり続けている（第3章） |
| **円安**                       | ドル建てで見た取得価格が依然として割安                  |
| **データセンターという新需要** | 需要拡大が見込まれ、投資が堅調と報じられる（第4章）     |

> 注意：投資額はあくまで**取引金額の合計**であり、大型案件が1件あるだけで大きく振れる。
> 「活発さ」の指標として見るのが妥当で、価格の方向とは別物。

## 3. オフィス市況 — 空室率2%割れ、賃料30か月連続上昇

| 指標                 | 数値                                           | 時点・出典                        |
| -------------------- | ---------------------------------------------- | --------------------------------- |
| 都心5区 平均空室率   | **1.95%**                                      | 2026年7月、三鬼商事（報道ベース） |
| 同（推移）           | 3月 2.22% → 5月 2.07% → 6月 1.99% → 7月 1.95%  | 2026年、同上                      |
| 都心5区 平均募集賃料 | **2万3,287円/坪**（**30か月連続上昇**）        | 2026年7月、同上                   |
| 同（3月時点）        | 2万2,302円/坪（26か月連続上昇）                | 2026年3月、同上                   |
| 新築ビル空室率       | 12.65%（前月比+3.08pt）と高め。既存ビルは2.02% | 2026年、同上                      |

> 読み解き：**空室率2%割れは需給が極めて締まった状態**。
> 貸し手優位なので、契約更改のたびに賃料を上げられる。
> これが J-REIT の**内部成長**（物件を買わずに分配金を増やす道）を支えている。
> 一方で新築ビルの空室率が高いのは、竣工直後は埋まりきらないのが普通だから。
> 大型竣工が集中する年は全体の数字が一時的に悪化するので、**既存ビルの数字を見る**のが実務。

賃料上昇はインフレに対する不動産の強みそのもので、
**賃料の伸びがキャップレート上昇を打ち消せるか**が2026年の最大の論点になっている。

## 4. データセンターが新しい投資対象として立ち上がる

AIの普及で電力と計算資源の需要が急拡大し、**データセンターが不動産投資の新しいアセットクラス**
として日本でも本格的に立ち上がってきた（→ [データセンター](../../04_情報通信・IT・ネット/03_データセンター/README.md)）。

| 動き         | 内容                                                                                       | 時点                       |
| ------------ | ------------------------------------------------------------------------------------------ | -------------------------- |
| 日本GLP      | 米Ares Managementと組み、データセンター特化ファンドで**3,500億円**を機関投資家から調達     | 2025年（報道ベース）       |
| 三井物産     | データセンターコアファンドの組成に向け、国内の稼働型データセンター資産を取得               | 2025年（同社リリース）     |
| ESR          | アジアのデータセンター成長が顕著とし、専用ファンドを組成する方針                           | 2026年（報道ベース）       |
| 政府・金融庁 | **データセンターのREITへの組入れ**に向けた環境整備、上場インフラファンド市場の活性化を検討 | 2025年、国家戦略特区WG資料 |

```
【なぜデータセンターが「不動産」として扱われるのか】

  普通のオフィス                      データセンター
   ・賃料は坪単価                      ・**料金は電力容量（kW）単価**
   ・テナント入替あり                  ・契約は10〜20年の超長期
   ・内装は借り手の負担                ・電源・冷却設備が資産の大半
   ・立地＝人の集まる場所              ・立地＝**電力と通信回線が取れる場所**

  → 不動産（土地建物）とインフラ（電力設備）の中間。
    そのため通常のJ-REITでは「その他」扱いになり、
    私募ファンドや専用ファンドが先行している。
```

日本の上場REIT市場では組入れ実績が乏しく、米国のように独立したデータセンターREITが
確立しているわけではない。**制度整備と私募ファンドの実績積み上げが先行している段階**と整理できる。

## 5. J-REIT市場の再編 — 市場初の「友好的TOB」

上場J-REITは、**NAV倍率が1倍前後にとどまり増資がしづらい**状態が続いた結果、
これまで例のなかった形の再編が起き始めている。

| 事象                                               | 内容                                                                                                                                                                 | 時点                                                   |
| -------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| **サンケイリアルエステート投資法人（SRE）へのTOB** | トーセイ（8923）とシンガポール政府系ファンド**GIC**がSPCを通じて公開買付。1口125,000円、下限53%。投資法人役員会が**賛同を表明し応募を推奨**                          | 2026年1月6日賛同表明、1月7日〜2月6日買付（報道ベース） |
| 位置づけ                                           | **J-REIT市場で投資法人側・スポンサー側がともに賛同した初の友好的TOB**と報じられる                                                                                    | 2026年                                                 |
| 報道される買収規模                                 | 583億円規模での非公開化と報じられる                                                                                                                                  | 2026年                                                 |
| スポンサー交代の例                                 | セントラル・リート投資法人（3488）は独立系ザイマックス単独スポンサーから、名鉄都市開発が51%を保有するメインスポンサーへ                                              | 近年                                                   |
| 公募増資の再開                                     | 2026年に入り、複数の投資法人が公募増資を発表（日本ビルファンド、東海道リート、MIRARTH、ジャパンリアルエステイト、ジャパン・ホテルリート、One REIT など、報道ベース） | 2026年                                                 |
| 資産入替の広がり                                   | 増資しづらい環境下で、含み益のある物件を売って利回りの高い物件を買う手法が広がる                                                                                     | 2025〜2026年                                           |

```
【なぜ「NAV倍率1倍割れ」が再編を呼ぶのか】

  投資口価格 ＜ 保有不動産の価値（NAV）
       ↓
  ①  REIT側：増資すると既存投資主の価値が薄まる → 物件を買えない → 成長できない
  ②  買収側：市場で投資口を買い集めれば、**物件を直接買うより安く手に入る**
       ↓
  ③  スポンサーや外部ファンドが非公開化（TOB）を仕掛ける誘因が生まれる
       ↓
  ④  上場のまま放置するより、非公開にして自由に運営する方が合理的な場面が出る
```

一方、市場全体のNAV倍率は**2026年1月16日に1.00倍まで回復**したものの、
過去平均とされる1.10倍とはなお差があると三井住友トラスト基礎研究所が整理している。
分配金利回りは市場平均で**4.9%前後**と報じられ、
「NAV倍率1倍に戻すには、利回りが4.9%のままならDPUが16%増えるか、
DPUが変わらないなら利回りが4.2%まで下がる必要がある」といった試算も出ている（報道・推計ベース）。

**海外投資家は2026年6月時点でJ-REIT市場では売り越しに転じた**と報じられており、
第2章の「現物は買い越し」と方向が逆である点が、この市場のねじれを象徴している。

## 6. 私募REIT・私募ファンドは拡大が続く

上場市場が足踏みする一方で、**非上場の器には資金が入り続けている**。

| 指標                       | 数値                                                                   | 時点・出典                                             |
| -------------------------- | ---------------------------------------------------------------------- | ------------------------------------------------------ |
| 私募REIT 資産総額          | **8兆665億円**（前年比+11.3%）                                         | 2026年6月末、ARES                                      |
| 同・前四半期               | 7兆9,722億円（前年比+10.9%）                                           | 2026年3月末、ARES                                      |
| 不動産私募ファンド市場全体 | **約47.1兆円**（前回調査44.9兆円から+2.2兆円、+4.9%）                  | 2025年12月末、ARES／三井住友トラスト基礎研究所（推計） |
| アセット別内訳             | オフィス35.1%／住宅22.1%／物流19.6%／商業15.1%／ホテル5.9%／その他2.2% | 2026年6月末、ARES                                      |

理由として整理されるのは次の点。

- **鑑定評価ベースなので日々値が動かない**。年金基金や地域金融機関の会計・運営と相性がよい
- **無期限（オープンエンド）**なので出口の市況に賭けなくてよい
- **上場市場の需給に左右されない**。J-REITが売られても私募REITの評価額は連動しない

> ここが理解の勘どころ：**同じ不動産を持っていても、上場しているかどうかで
> 「値動き」がまったく違って見える**。J-REITの下落は必ずしも物件価値の下落を意味しない。

| 動き                                | 内容                                                                                   | 時点                   |
| ----------------------------------- | -------------------------------------------------------------------------------------- | ---------------------- |
| **金融庁 2026事務年度金融行政方針** | 大手金融機関の**不動産業向け融資**、超長期住宅ローン、流動性リスクの点検を重点に据えた | 2026年9月15日公表      |
| **データセンターのREIT組入れ**      | 環境整備と上場インフラファンド市場の活性化を政府が検討                                 | 2025年、国家戦略特区WG |
| **導管性要件の運用**                | 配当可能利益の90%超の分配など、J-REIT・TMKの非課税の前提（制度自体は継続）             | —                      |
| **不動産特定共同事業**              | 電子取引業務（クラウドファンディング）が定着。事業者数が増加                           | 2017年改正以降         |

金融庁が不動産向け融資を重点項目に挙げたのは、
**金利上昇局面で不動産融資の質が悪化しないかを早めに点検する**趣旨と読める
（→ [メガバンク](../01_メガバンク/README.md)、[地方銀行](../02_地方銀行/README.md)）。
2008年のリーマン危機では、ノンリコースローンのリファイナンス不能が
ファンドの連鎖的な破綻につながった経緯がある。

## 8. 全体の構図（まとめ）

1. **賃料と金利の綱引き**。都心オフィスは空室率1.95%・賃料30か月連続上昇でNOIは伸びているが、
   日銀の政策金利は2026年9月に1.25%（約31年ぶりの水準）まで上がり、
   キャップレート上昇と借入コスト増が同時に効き始めている
2. **現物市場は強い**。2026年上半期の商業用不動産投資額は3兆7,517億円と上半期として過去最高。
   外国資本の購入額は約4割増で、円安と賃料上昇期待が買いを支えている
3. **上場J-REITは評価が追いつかない**。NAV倍率は1倍前後、分配金利回りは4.9%前後。
   増資がしづらいため資産入替で利益を作る動きが広がり、
   ついに**市場初の友好的TOB（サンケイリアルエステート投資法人、2026年1〜2月）**が成立する局面に至った
4. **非上場（私募REIT・私募ファンド）は拡大が続く**。私募REITは2026年6月末で8兆665億円（+11.3%）。
   鑑定評価ベースで値が動かない性質が、長期資金の受け皿になっている
5. **データセンターという新アセット**が立ち上がりつつある。私募ファンドが先行し、
   REIT組入れは制度整備の段階。日本の不動産金融の「次の柱」候補として注目されている

> つまり2026年は、**「物件の中身は良いのに、上場市場での値段が付かない」**という
> ねじれが最も鮮明になった年であり、そのねじれが再編（TOB・非公開化）という形で
> 解消され始めた年、と整理できる。

## 9. 用語メモ

| 用語                   | 意味                                                                                        |
| ---------------------- | ------------------------------------------------------------------------------------------- |
| **NAV倍率**            | 投資口価格 ÷ 1口あたり純資産価値。1倍割れだと増資しづらい → [②](02_J-REITの仕組みと経済.md) |
| **キャップレート**     | NOI ÷ 価格。上がれば価格は下がる → [③](03_市場と参加者.md)                                  |
| **内部成長／外部成長** | 既存物件の賃料・稼働率の改善／物件の買い増し                                                |
| **資産入替**           | 含み益のある物件を売り、利回りの高い物件を買う。売却益は一過性                              |
| **変動金利比率**       | 借入のうち変動金利の割合。高いほど利上げが即座に分配金へ効く                                |
| **TOB（公開買付）**    | 市場外で株式・投資口を買い集める手続。J-REITでは2026年に初の友好的事例                      |
| **非公開化**           | 上場を廃止して非上場にすること。TOBの目的になることが多い                                   |
| **都心5区**            | 千代田・中央・港・新宿・渋谷。東京オフィス市況の標準指標                                    |
| **GOP**                | Gross Operating Profit。ホテルの営業粗利益。変動賃料の算定基礎                              |
| **ARES**               | 一般社団法人不動産証券化協会。私募REIT・私募ファンド統計の一次情報源                        |
| **JLL／CBRE**          | 世界的な不動産サービス会社。投資額統計の主要な出し手                                        |
