# 不動産を金融商品にする仕組み（不動産証券化）

このノートで分かること：**1棟のビルが、どうやって「誰でも少額で買える金融商品」に化けるのか**。
その中核にあるのが**証券化**であり、鍵になるのは「器（うつわ）」「倒産隔離」「ノンリコースローン」
「シニア／メザニン／エクイティの階層」の4つ。ここを押さえると [J-REIT](02_J-REITの仕組みと経済.md) も私募ファンドも同じ設計図で読める。

> ポイント：不動産証券化とは、**建物を切り刻む技術ではなく、「そのビルが生むキャッシュフロー」を
> リスクの順番に並べ替えて、別々の投資家に売り分ける技術**である。

---

## 1. なぜ「そのまま」では売れないのか

100億円のオフィスビルがあるとする。現物のまま売買しようとすると、次の壁にぶつかる。

| 壁                       | 中身                                                                    | 証券化がどう解くか                                                       |
| ------------------------ | ----------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| **単位が大きすぎる**     | 100億円を一括で出せる投資家は限られる                                   | 権利を小口に分けて多数の投資家で持つ                                     |
| **買い手の信用と混ざる** | 保有会社が倒産すると、ビルも債権者に持っていかれる                      | **倒産隔離**（第3章）で切り離す                                          |
| **流動性がない**         | 売りたいときに買い手が見つからない                                      | 上場させる（J-REIT）／解約可能にする（オープンエンド）                   |
| **リスクの好みが違う**   | 「安全に3%」の投資家と「リスクを取って15%」の投資家が同じ商品を買えない | **シニア／メザニン／エクイティ**に階層化（第5章）                        |
| **税金が二重にかかる**   | 保有会社に法人税、投資家に配当課税                                      | **導管体**（税金が素通りする器）にする → [②](02_J-REITの仕組みと経済.md) |

**「証券化」という言葉が指しているのは、この5つをまとめて解くパッケージ**だと考えればよい。

---

## 2. 全体像：現物不動産 → 金融商品

```
【不動産証券化の基本形】

  ＜元の持ち主（オリジネーター）＞
   デベロッパー／事業会社  ──── 物件を売却（＝資金化）
        │                         ※バランスシートから外れる（オフバランス）
        ▼
  ┌──────────────────────────────┐
  │   SPC（特別目的会社）＝ 器      │ ← この器は「そのビルを持つためだけ」に存在する
  │   保有するのは物件 1〜数件のみ   │    従業員なし、他の事業なし、倒産隔離
  │   ┌────────────────────────┐   │
  │   │ 資産： 信託受益権 or 現物 │   │
  │   │ 負債： ノンリコースローン │◀──── 銀行（シニア）
  │   │       メザニンローン      │◀──── ノンバンク・ファンド（メザニン）
  │   │ 資本： 出資（TK出資等）   │◀──── 投資家（エクイティ）
  │   └────────────────────────┘   │
  └──────────────────────────────┘
        │  賃料 −（管理費・税・修繕）＝ NOI
        │  NOI − 支払利息 − 元本返済 ＝ 投資家への分配
        ▼
  ＜運営を担う人たち＞
   AM（アセットマネジャー）… 買う・貸す・売るの意思決定
   PM（プロパティマネジャー）… テナント募集、賃料回収  → [賃貸管理](../../12_建設・住宅・不動産/10_賃貸管理/README.md)
   BM（ビルマネジャー）… 清掃・設備保守             → [ビル管理](../../12_建設・住宅・不動産/11_ビル管理・不動産サービス/README.md)
```

この図の**箱（SPC）と矢印（お金の出入り）が全て**である。J-REITも私募ファンドも、
この箱の形と上場の有無が違うだけで、原理は同一。

## 3. 器その1：信託受益権 — 不動産を「紙」に変える

証券化される不動産の多くは、まず**信託銀行に信託される**。
信託とは「自分の財産の名義を信頼できる人に移し、決めた目的のために管理してもらう仕組み」
（詳しくは [信託銀行／信託とは何か](../03_信託銀行/01_信託とは何か.md)）。

```
 ＜信託前＞                      ＜信託後＞
  所有者 ───── ビル（現物）      委託者 ──信託──▶ 信託銀行（受託者）
                                              │  名義はここに移る
                                              ▼
                                        委託者は「信託受益権」を受け取る
                                        ＝ ビルから生じる賃料を受け取る権利（＝債権的な「紙」）
                                        この紙を売買する
```

現物のままではなく**受益権という紙にしてから売買する実務上の理由**は次のとおり。

| 理由                     | 中身                                                                                                                                               |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **流通コストが下がる**   | 現物売買には不動産取得税・登録免許税がかかるが、受益権の売買なら登録免許税が軽い扱いになる場面がある（税制は改正が多く、最新の税率は国税庁で確認） |
| **分割しやすい**         | 受益権は準共有や数量分割がしやすく、複数投資家で持ちやすい                                                                                         |
| **管理の受け皿ができる** | 受託者（信託銀行）が名義人として契約・登記を担い、器（SPC）は身軽でいられる                                                                        |
| **調査の質が上がる**     | 信託受託時に信託銀行が物件を厳しく審査するため、**受益権＝一定の品質保証**という市場慣行がある                                                     |

> 注意：受益権にしても**物件のリスクは消えない**。証券化は「リスクの置き場所を変える技術」であって「消す技術」ではない。

## 4. 器その2：倒産隔離 — 誰かが潰れても物件を守る

**倒産隔離（bankruptcy remoteness）** とは、「もとの持ち主やスポンサーが倒産しても、
その物件と賃料が巻き込まれない」状態を作ること。証券化の生命線である。

```
【倒産隔離がない場合】              【倒産隔離がある場合】

  事業会社                            事業会社（オリジネーター）
   ├ 工場                              │ 売却済み。もう関係ない
   ├ 在庫                              ✕───────────────
   └ ビル ← 会社が倒産すると          SPC（器）
       一般債権者が差し押さえる         └ ビルのみ保有
                                         ・他事業なし（目的制限）
  → 投資家は物件だけを                  ・追加の借入禁止
     切り出して守れない                  ・株式は一般社団法人等が保有
                                         ・倒産申立てをしない旨の取り決め
                                       → 貸し手はビルの賃料だけを見れば足りる
```

具体的に使われる仕掛けは次の4点セット。

| 仕掛け                    | 何をしているか                                                                                  |
| ------------------------- | ----------------------------------------------------------------------------------------------- |
| **目的の限定**            | SPCの定款で「本物件の取得・保有・処分」以外の事業を禁じる                                       |
| **株主の中立化**          | SPCの株式を一般社団法人などに持たせ、スポンサーの子会社にしない（連結や倒産の巻き込みを避ける） |
| **追加債務の禁止**        | 契約で新たな借入・保証を禁じ、債権者が増えないようにする                                        |
| **真正売買（true sale）** | 「担保付き融資ではなく、本当に売ったのだ」と法的に整理する。ここが崩れると倒産隔離も崩れる      |

## 5. デットとエクイティの階層 — この業界の中心概念

同じ物件のキャッシュフローを、**受け取る順番（優先順位）で切り分ける**。
先に受け取る人ほど安全でリターンが低く、後の人ほど危険でリターンが高い。

```
【賃料の分配順序（ウォーターフォール＝滝）】

   賃料収入
     ↓  −運営費・税・修繕 ＝ NOI（純収益）
     ↓
 ┌───────────────────────────────┐
 │ ① シニア（ノンリコースローン）    │ 銀行。LTV 0〜60%の部分
 │    金利 低い／最優先で受け取る     │ 担保順位1位。返せなければ物件を取る
 ├───────────────────────────────┤
 │ ② メザニン（劣後ローン・優先出資） │ ノンバンク、ファンド。LTV 60〜75%の部分
 │    金利 高い／シニアの次           │ 「中2階」の意味
 ├───────────────────────────────┤
 │ ③ エクイティ（出資）              │ 残り全部を受け取る＝残余請求権
 │    リターン青天井／損も最初に被る   │ 空室が出れば真っ先に削られる
 └───────────────────────────────┘
     ↓ 残った分が投資家の分配金
```

| 階層           | 出し手の典型                                                             | 想定リターン（平時の目安）                                        | 損失を被る順番 |
| -------------- | ------------------------------------------------------------------------ | ----------------------------------------------------------------- | -------------- |
| **シニア**     | [銀行](../01_メガバンク/README.md)、[生命保険](../07_生命保険/README.md) | 調達コスト＋スプレッド（国内では年1〜2%台が目安。金利水準で変動） | 最後           |
| **メザニン**   | ノンバンク、専門ファンド                                                 | 年5〜10%程度と言われる（案件ごとに大きく異なる）                  | 2番目          |
| **エクイティ** | 年金、機関投資家、REIT、個人                                             | コア型で年3〜5%、開発型で年15%以上を狙う設計もある                | **最初**       |

> ポイント：不動産ファンドの世界で「シニア」「メザニン」「エクイティ」という言葉が
> 飛び交うのは、**同じビルを見ていても、立っている階層が違えば見える景色が正反対**だから。
> 貸し手は「最悪いくらで売れるか」を見て、出資者は「賃料がどれだけ伸びるか」を見る。

## 6. ノンリコースローン — 「物件だけが担保」の借金

**ノンリコースローン（non-recourse loan、責任財産限定特約付き融資）** とは、
返済原資と担保が**その物件とその賃料に限られる**借入のこと。
借り手（SPC）や背後のスポンサーの他の財産には請求が及ばない（＝遡及しない＝non-recourse）。

|              | 通常の企業向け融資（リコース）       | ノンリコースローン                         |
| ------------ | ------------------------------------ | ------------------------------------------ |
| 返済原資     | 借り手企業の全事業のキャッシュフロー | **その物件のNOIのみ**                      |
| 担保         | 不動産＋保証＋他の資産               | その物件（または信託受益権）のみ           |
| 審査の目     | 企業の財務・信用力                   | **物件の収益力と売却可能性**               |
| 返せない場合 | 会社全体が債務不履行                 | 物件を渡して終わり（スポンサーは追わない） |
| 金利         | 相対的に低い                         | やや高い（リスク相応のスプレッド）         |

貸し手はスポンサーの信用を当てにできないため、代わりに**契約で縛る**。
代表的なのが次の指標で、これを割ると金利上昇・分配停止・期限前弁済が強制される
（コベナンツ＝財務制限条項）。

| 指標          | 計算             | 意味                 | よく使われる水準感               |
| ------------- | ---------------- | -------------------- | -------------------------------- |
| **LTV**       | 借入 ÷ 物件価値  | どれだけ借りているか | 60%以下に抑える設計が多い        |
| **DSCR**      | NOI ÷ 元利返済額 | 返済余力             | 1.2〜1.3倍以上を求めるのが一般的 |
| **NOI利回り** | NOI ÷ 物件価格   | 物件の素の利回り     | アセットと立地で大きく異なる     |

## 7. レバレッジの算数 — なぜ借金でリターンが増幅するのか

証券化の経済性の心臓部。**「物件の利回り > 借入金利」である限り、借りるほど
出資者の利回りは上がる**。数字で見ると一目で分かる。

前提：物件価格100、NOI利回り4.0%（NOI＝4.0）、借入金利2.0%。

| ケース     | 借入 | 自己資金 | 支払利息 | 出資者の取り分 | **エクイティ利回り** |
| ---------- | ---- | -------- | -------- | -------------- | -------------------- |
| A：無借金  | 0    | 100      | 0        | 4.0            | **4.0%**             |
| B：LTV 50% | 50   | 50       | 1.0      | 3.0            | **6.0%**             |
| C：LTV 60% | 60   | 40       | 1.2      | 2.8            | **7.0%**             |
| D：LTV 70% | 70   | 30       | 1.4      | 2.6            | **8.7%**             |

増幅の正体はこの式。

```
 エクイティ利回り ＝ NOI利回り ＋ （NOI利回り − 借入金利）×  借入 ÷ 自己資金
                                    └── スプレッド ──┘   └── レバレッジ倍率 ──┘

 例（ケースC）： 4.0% ＋ (4.0% − 2.0%) × 60/40 ＝ 4.0% ＋ 3.0% ＝ 7.0%
```

**逆回転も同じ式で起きる**。ここが2026年時点で最も重要な論点になっている。

| シナリオ（ケースC、LTV60%）  | NOI利回り | 借入金利 | エクイティ利回り    |
| ---------------------------- | --------- | -------- | ------------------- |
| 低金利時代                   | 4.0%      | 0.7%     | **8.95%**           |
| 金利が上がる                 | 4.0%      | 2.0%     | 7.0%                |
| 金利が上がり、賃料も伸びる   | 4.5%      | 2.0%     | 8.25%               |
| 金利が上がり、賃料は伸びない | 4.0%      | 3.5%     | **4.75%**           |
| 金利が物件利回りを超える     | 4.0%      | 4.5%     | **3.25%（逆ざや）** |

> 結論：不動産金融の損益は「賃料が伸びるスピード」と「金利が上がるスピード」の
> **かけっこ**で決まる。物件を見るだけでは半分しか分からない。
> 金利と価格の関係は [③ 市場と参加者](03_市場と参加者.md) のキャップレートの章で扱う。

## 8. 日本のスキーム2種：GK-TK と TMK

日本の不動産証券化では、器のつくり方が実務上ほぼ2種類に固まっている。
**どちらを選ぶかは「税金」と「投資家の顔ぶれ」で決まる**。

### 8-1. GK-TK スキーム（合同会社＋匿名組合）

```
  投資家（匿名組合員）── TK出資 ──▶ GK（合同会社＝器）
      ↑                                │
      └─── 利益の分配（損金算入）──────┤ 借入 ◀── 銀行（ノンリコース）
                                        ▼
                                  信託受益権（＝物件）
   ※ GKの業務執行は一般社団法人が保有する社員などが担い、倒産隔離を効かせる
   ※ AM会社が実質的な運用判断を行う（金商法の登録が必要）
```

- **匿名組合（TK）** ＝ 出資はするが経営に関与しない契約形態（商法上の匿名組合）。出資者名が表に出ないので「匿名」。
- **税金が抜ける理屈**：GKが匿名組合員に支払う分配は**損金（費用）扱い**になり、GKの段階で法人税がほぼ残らない。
- **使いどころ**：私募ファンド、開発型、期間限定の案件。設立が速く柔軟で、日本の私募不動産ファンドの主流。
- **制約**：匿名組合員は運営に口を出せない。投資家の属性（外国法人・年金等）で課税の扱いが変わるため税務専門家の領域。

### 8-2. TMK スキーム（特定目的会社）

- **資産流動化法（SPC法）**に基づく法定の器。財務局への**資産流動化計画の届出**が必要。
- **優先出資証券**と**特定社債**を発行でき、階層構造を法制度として作れる。
- **導管性要件**（配当可能利益の90%超を配当する等）を満たすと**配当が損金算入**され、法人段階の課税が実質的に消える（→ [②](02_J-REITの仕組みと経済.md)）。
- **使いどころ**：現物不動産の保有、長期保有、海外投資家を含む複数階層の資金を入れる大型案件。

|                | **GK-TK**                                                | **TMK**                            |
| -------------- | -------------------------------------------------------- | ---------------------------------- |
| 根拠法         | 会社法（合同会社）＋商法（匿名組合）                     | 資産流動化法                       |
| 行政手続       | 不要（ただしAMは金商法登録が必要）                       | **資産流動化計画の届出**が必要     |
| 保有形態       | ほぼ**信託受益権**（現物保有は宅建業免許の論点が生じる） | 現物不動産も保有しやすい           |
| 資金調達       | TK出資＋ノンリコースローン                               | 優先出資証券＋特定社債＋借入       |
| 二重課税の回避 | TK分配金が**損金**になる                                 | **導管性要件**を満たせば配当が損金 |
| 設立の速さ     | 速い・柔軟                                               | 手続が重い                         |
| 典型用途       | 私募ファンド、開発、短中期                               | 大型・長期・現物保有・複数階層     |

> 覚え方：**「速くて柔らかいのがGK-TK、重くて堅いのがTMK」**。
> そして**上場して永続させたものがJ-REIT（投資法人）**である。

## 9. 誰が何をやっているのか（登場人物の整理）

| 役割                           | 何をする                         | 必要な免許・登録                 | 典型的な担い手                                                                        |
| ------------------------------ | -------------------------------- | -------------------------------- | ------------------------------------------------------------------------------------- |
| **オリジネーター**             | 物件を出す（売る）               | —                                | [デベロッパー](../../12_建設・住宅・不動産/08_不動産デベロッパー/README.md)、事業会社 |
| **AM（アセットマネジャー）**   | 取得・運営方針・売却を決める     | 金商法の投資運用業（投資一任）   | 不動産AM会社、[資産運用会社](../06_資産運用/README.md)                                |
| **PM（プロパティマネジャー）** | テナント誘致・賃料回収・収支管理 | 宅建業免許（賃貸媒介を伴う場合） | 不動産管理会社                                                                        |
| **BM（ビルマネジャー）**       | 清掃・警備・設備保守             | —                                | ビルメンテナンス会社                                                                  |
| **受託者**                     | 不動産信託の名義人               | 信託業免許                       | [信託銀行](../03_信託銀行/README.md)                                                  |
| **レンダー**                   | ノンリコースローンを出す         | 銀行業等                         | 銀行、生保、ノンバンク                                                                |

ほかに、スキームを組み立てるアレンジャー（証券会社・信託銀行）、鑑定・デューデリの専門家、SPCの経理を担う事務受託者が関わる。
**AMとPMの違い**は頻出で、**AM＝「持ち続けるか売るかを決める人」、PM＝「テナントに向き合う人」**。報酬の出所も投資家と物件で異なる。

## 10. リスクの所在 — 証券化しても消えないもの

| リスク                             | 中身                                               | 誰が主に被るか                                                 |
| ---------------------------------- | -------------------------------------------------- | -------------------------------------------------------------- |
| **空室・賃料下落**                 | テナント退去、賃料改定                             | エクイティ → 深刻ならメザニン                                  |
| **金利上昇**                       | 変動金利の借入コスト増、リファイナンス時の条件悪化 | エクイティ（第7章の逆回転）                                    |
| **リファイナンス（借換）**         | 借入期限に新しい貸し手が見つからない               | 全階層。2008〜2009年に多発                                     |
| **価格変動（キャップレート上昇）** | 同じNOIでも価値が下がる                            | エクイティ、LTVが跳ね上がるとレンダーも                        |
| **物件固有**                       | 土壌汚染、耐震、アスベスト、災害                   | デューデリで事前に潰す。残りは保険                             |
| **運用者リスク**                   | AMの利益相反、スポンサー破綻                       | 投資家全体（→ [②](02_J-REITの仕組みと経済.md) の利益相反の章） |

リーマン危機（2008年）では、**LTVを高く取った私募ファンドがリファイナンスできず、物件を投げ売りして
価格が連鎖的に下がる**展開が起きた。その反省が、現在のLTV抑制（多くのJ-REITで40〜50%台）と、
借入の**固定金利比率・返済期限の分散**の重視につながっている。

## 11. 用語メモ

| 用語                             | 意味                                                                                                                   |
| -------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| **証券化**                       | 資産が生むキャッシュフローを切り出し、優先順位を付けて複数の投資家に売り分ける手法                                     |
| **SPC／SPV**                     | Special Purpose Company/Vehicle。その資産を持つためだけの器                                                            |
| **信託受益権**                   | 信託した財産から生じる利益を受け取る権利。不動産証券化での売買単位 → [信託とは何か](../03_信託銀行/01_信託とは何か.md) |
| **倒産隔離**                     | もとの持ち主やスポンサーが倒産しても資産が巻き込まれない状態                                                           |
| **真正売買（true sale）**        | 担保融資ではなく本当の売買であるという法的整理。倒産隔離の前提                                                         |
| **ノンリコースローン**           | 返済原資と担保をその物件・賃料に限定した融資                                                                           |
| **LTV**                          | Loan to Value。借入 ÷ 物件価値                                                                                         |
| **DSCR**                         | Debt Service Coverage Ratio。NOI ÷ 元利返済額。1.0を割ると返済できない                                                 |
| **コベナンツ**                   | 財務制限条項。LTVやDSCRが基準を割ると分配停止などが発動する契約                                                        |
| **NOI**                          | Net Operating Income。賃料収入 − 運営費。減価償却前・金利前の純収益                                                    |
| **シニア／メザニン／エクイティ** | 受け取り順が早い順の階層。早いほど低リスク低リターン                                                                   |
| **レバレッジ**                   | 借入で自己資金あたりのリターンを増幅すること。損失も同じ倍率で増幅する                                                 |
| **GK-TK**                        | 合同会社（GK）＋匿名組合（TK）出資による私募ファンドの標準スキーム                                                     |
| **匿名組合（TK）**               | 出資するが経営に関与しない契約形態。分配が損金になる                                                                   |
| **TMK**                          | 特定目的会社。資産流動化法に基づく器。優先出資証券と特定社債を発行できる                                               |
| **導管性要件**                   | 器の段階で法人税がかからないための条件。配当可能利益の90%超の配当などが柱 → [②](02_J-REITの仕組みと経済.md)            |
| **AM／PM／BM**                   | 投資判断／テナント対応／建物の維持管理。担い手と報酬の出所が違う                                                       |
| **オフバランス**                 | 売却により自社の貸借対照表から資産と負債を外すこと                                                                     |
