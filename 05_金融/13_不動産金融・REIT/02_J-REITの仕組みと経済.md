# J-REITの仕組みと経済

このノートで分かること：**J-REIT（上場不動産投資信託）が、なぜ利益のほとんどを
配り続けられるのか**。その答えは税制（導管性）と、**スポンサー＝親会社が物件を供給する構造**にある。
[① 証券化の仕組み](01_不動産を金融商品にする仕組み.md) の「器」を上場させて永続化したものがJ-REITだと考えればよい。

> ポイント：J-REITは**会社の形をしているが、従業員が1人もいない**。
> 中身は「物件と借入と契約書の束」であり、実務はすべて外部の資産運用会社が担う。
> この構造が、安定した分配金の源泉であると同時に、利益相反という宿命的な論点を生む。

**本ノートは仕組みの説明であり、個別銘柄やファンドの売買を勧めるものではない。**

---

## 1. J-REITとは何か（3行で）

- **不動産投資法人**という法人（＝器）が、投資家から集めた資金と銀行借入でオフィスや物流施設を買う
- 賃料から経費と利息を引いた利益を、**ほぼ全額、投資家に分配する**
- その投資口（株式に相当）が**東京証券取引所に上場**しており、株と同じように売買できる

|              | 株式（事業会社）   | **J-REIT（投資法人）**                         |
| ------------ | ------------------ | ---------------------------------------------- |
| 呼び名       | 株式／株主／配当   | **投資口／投資主／分配金**                     |
| 中身         | 事業と従業員       | **不動産（または信託受益権）だけ**             |
| 従業員       | いる               | **いない**（法律上、使用人を雇えない）         |
| 利益の使い道 | 内部留保して再投資 | **90%超を分配しないと法人税がかかる**          |
| 法人税       | かかる             | 条件を満たせば**実質的にかからない**           |
| 根拠法       | 会社法             | **投資信託及び投資法人に関する法律（投信法）** |

## 2. 構造図：誰が何を持ち、誰が何をするか

```
【J-REITの基本構造】

   投資主（個人・年金・投信・海外投資家）
        │ 投資口を東証で売買／分配金を受け取る
        ▼
 ┌────────────────────────────────────┐
 │      不動産投資法人（＝上場する器）        │
 │   執行役員1名＋監督役員2名以上／従業員ゼロ  │
 │   資産：物件・信託受益権                   │
 │   負債：借入金・投資法人債（LTV 40〜50%台） │◀── 銀行・社債市場
 └────────────────────────────────────┘
      │ 資産運用委託            │ 資産保管委託     │ 事務委託
      ▼                        ▼                 ▼
 ┌──────────────┐      信託銀行          一般事務受託者
 │ 資産運用会社（AM）│      （物件の保管）      （経理・投資主名簿）
 │ 買う・貸す・売るを│
 │ 実際に決める      │
 └──────────────┘
      △ 株式の過半を保有・人材を派遣
      │
 ┌──────────────┐
 │  スポンサー（親会社）│  デベロッパー、商社、金融、外資系ファンドなど
 │  ・物件を供給する    │  → [不動産デベロッパー](../../12_建設・住宅・不動産/08_不動産デベロッパー/README.md)
 │  ・ブランドと信用    │
 │  ・投資口も一部保有  │
 └──────────────┘
```

**投資法人に人がいない**のが最大の特徴。役員会（執行役員＋監督役員）はあるが日常の判断は資産運用会社が行うため、
**「どのJ-REITを見るか」は実質的に「どの資産運用会社とスポンサーを見るか」**とほぼ同義になる。

## 3. なぜ利益の90%超を配るのか — 導管性要件

J-REITの分配金利回りが株式配当より高いのは、**器の段階で法人税を払わないから**である。
これを可能にするのが**導管性要件（支払配当損金算入要件）**。

```
【二重課税が起きる場合と、起きない場合】

 ＜普通の不動産会社＞               ＜J-REIT（導管性要件を満たす）＞
  賃料利益 100                      賃料利益 100
    −法人税（約30%）  30             −法人税  ほぼ 0   ← 分配が「費用」になる
    ＝ 70 を配当                      ＝ 100 を分配
      −投資家の課税 約20%              −投資家の課税 約20%
    ＝ 手取り 56                      ＝ 手取り 80
       ※二重に取られる                  ※投資家段階の1回だけ
```

主な要件（投信法・租税特別措置法。細目は改正されるので最新は国税庁・投信法で確認）。

| 要件                                             | 中身                         | なぜこの条件か                                       |
| ------------------------------------------------ | ---------------------------- | ---------------------------------------------------- |
| **配当可能利益の90%超を分配**                    | 利益を貯め込まない           | 「内部留保しないなら実体は導管（パイプ）」という理屈 |
| **他人からの借入は適格機関投資家に限る**         | 素性の知れた貸し手に限定     | 器の私物化・租税回避の防止                           |
| **投資口を50人以上が保有、または機関投資家のみ** | 広く分散して持たれていること | 公募性の担保                                         |
| **同族支配でない**（上位1人で50%超を保有しない） | 特定の者の節税の箱にしない   | 制度の公共性                                         |
| **他の法人の株式を50%以上保有しない**            | 事業会社化しない             | 不動産保有に専念させる                               |
| **設立時の募集が国内で行われている** 等          | —                            | —                                                    |

> ここから生まれる重要な帰結：
> **J-REITは利益を貯められないので、物件を買い増すには必ず外から資金を調達する**。
> 新規の投資口を発行する（公募増資）か、借入を増やすか、既存物件を売るしかない。
> だから**J-REITの成長は株式市場と銀行の顔色に左右される**。
> 投資口価格が低迷すると増資ができず、外部成長が止まる（→ [④ 直近トピック](04_直近トピック_2026.md)）。

なお、**減価償却費は現金の支出を伴わない費用**なので会計上の利益より手元の現金が多くなる。
この差額を使った分配を**利益超過分配（OPD）**といい、実質は出資の払い戻しに近い。利回りを見る際は区別が要る。

## 4. スポンサーとパイプライン — J-REITの生命線

J-REITは自分で土地を仕入れてビルを建てることが基本的にできない（開発リスクは取らない設計）。
では物件はどこから来るのか。**スポンサー（＝親会社）から来る**。

```
【スポンサーとJ-REITの分業】

  スポンサー（デベロッパー等）
     土地を仕入れる ─▶ 建てる ─▶ テナントを入れて稼働させる
                                        │ ここまでの「開発リスク」はスポンサーが取る
                                        ▼
                             ┌──────────────────┐
                             │  稼働済みで安定した物件  │
                             └──────────────────┘
                                        │ 売却（＝開発利益の実現）
                                        ▼
                                     J-REIT が取得
                                     安定賃料 → 分配金

  ＊この「供給ルート」を パイプライン と呼ぶ
  ＊スポンサーにとってのメリット：開発資金を早く回収でき、売却益が出る。
    さらに運用報酬と管理業務がグループに残る（＝出口を自前で持つ）
```

| 項目           | J-REIT側のメリット                                   | スポンサー側のメリット     |
| -------------- | ---------------------------------------------------- | -------------------------- |
| **物件の供給** | 市場で競り合わずに優良物件を買える                   | 開発資金の早期回収、売却益 |
| **優先交渉権** | パイプライン契約で先に検討できる                     | REITという安定した出口     |
| **人材**       | 運用のプロを派遣してもらえる                         | グループ内でのキャリア形成 |
| **信用**       | 増資・借入の条件が良くなる                           | ブランド価値               |
| **緊急時**     | ウェアハウジング（一時的にスポンサーが物件を預かる） | —                          |

スポンサーのタイプは大きく次の4系統に分かれ、**どの系統かで得意なアセットと物件の質が決まる**。

| 系統                 | 特徴                                         | 典型的なアセット         |
| -------------------- | -------------------------------------------- | ------------------------ |
| **デベロッパー系**   | 自社開発物件を継続供給。都心の大型物件に強い | オフィス、商業、住宅     |
| **商社・金融系**     | 調達力と目利き。外部からの取得も多い         | 複合型、物流、ホテル     |
| **外資・独立系**     | グローバル基準の運用。開発力を併せ持つ場合も | 物流施設、データセンター |
| **不動産サービス系** | 管理・仲介の現場情報が強み                   | 住宅、中小型オフィス     |

> 弱点も裏表。**スポンサーが弱ると、物件の供給も信用も同時に細る**。
> 2008〜2010年には、スポンサーの経営悪化をきっかけにJ-REITの合併・救済が相次いだ。
> 2020年代の再編でもスポンサー交代が引き金になっている（→ [④](04_直近トピック_2026.md)）。

## 5. 利益相反 — 構造上避けられない論点

資産運用会社はスポンサーの子会社である。すると、次の場面で**スポンサーの利益と
投資主の利益がぶつかる**。

| 場面                         | 何が起きうるか                                         | 主な歯止め                                                               |
| ---------------------------- | ------------------------------------------------------ | ------------------------------------------------------------------------ |
| **スポンサーからの物件取得** | 高値で買わされる                                       | 第三者の不動産鑑定評価、利害関係者取引規程、**投資法人役員会の事前承認** |
| **スポンサーへの物件売却**   | 安値で売らされる                                       | 同上                                                                     |
| **運用報酬の設計**           | 資産を増やすほど報酬が増える＝規模拡大が自己目的化する | 報酬体系に**分配金連動（DPU連動）**部分を組み込む設計が広がった          |
| **管理業務の発注**           | グループ会社に割高で発注                               | 相見積り、開示                                                           |
| **増資のタイミング**         | 投資口価格が安いときの増資は既存投資主の希薄化を招く   | **NAV倍率1倍割れでは増資しない**という市場規律                           |

制度面では投信法と金商法により、①**監督役員による役員会でのチェック**、②**利害関係者取引の開示**、
③**資産運用会社の忠実義務・善管注意義務**が課される。それでも構造上の利益相反は消えないため、
実務では**運用報酬の体系とガバナンス開示を読むのが定石**とされる。

```
【運用報酬の典型的な3階建て】

  ① 運用報酬Ⅰ ＝ 総資産 × 0.3〜0.5%程度   → 規模が増えると増える
  ② 運用報酬Ⅱ ＝ 利益（NOIやDPU）連動      → 投資主と利害が一致しやすい
  ③ 取得・譲渡報酬 ＝ 取引額 × 0.5〜1%程度  → 売買するほど増える（要注意項目）

  ①③の比重が高いほど「規模拡大が報酬になる」設計、
  ②の比重が高いほど「投資主の分配金と報酬が連動する」設計、と読む。
```

## 6. 読むべき指標 — NAV倍率・分配金利回り・LTV

J-REITを理解するには4つの指標で足りる。

### 6-1. NAV倍率（Price to NAV）

**NAV（Net Asset Value、純資産価値）**＝ 保有物件の鑑定評価額 − 負債。
「今すぐ全部売って借金を返したら1口あたりいくら残るか」の数字。

```
  NAV倍率 ＝ 投資口価格 ÷ 1口あたりNAV

   1.0倍より低い（NAV倍率1倍割れ）
     → 市場は「鑑定評価額ほどの価値はない」または「金利上昇で価値が下がる」と見ている
     → このとき増資すると既存投資主の1口あたりNAVが減る（希薄化）ので、増資できない
     → 外部成長が止まり、資産入替（売って買う）でしか利益を伸ばせなくなる

   1.0倍より高い
     → 増資して物件を買うと1口あたりNAVが増える（増価）
     → 増資 → 取得 → 分配金増 の好循環が回りやすい
```

2026年の状況：市場全体のNAV倍率は2026年1月16日に**1.00倍**まで回復したが、過去平均とされる1.10倍とはなお差がある
（三井住友トラスト基礎研究所、2026年）。**1倍前後が増資できるかどうかの分水嶺**という点がこの市場の作法として重要。

### 6-2. 分配金利回り

```
  分配金利回り ＝ 1口あたり年間分配金（DPU） ÷ 投資口価格
```

- 2026年時点の市場平均は**4.9%前後**と報じられる（媒体により集計時点が異なる）
- **長期金利との差（イールドスプレッド）**で割高・割安が語られる。長期金利が上がればスプレッドが縮み、価格に下押し圧力がかかる
- 利回りが高いのは、**市場がリスクを高いと見ている**からであることが多い

### 6-3. LTV（有利子負債比率）

```
  LTV ＝ 有利子負債 ÷ 総資産（または鑑定評価ベースの資産)
```

| 水準    | 意味                                     |
| ------- | ---------------------------------------- |
| 40%台   | J-REITの標準的な水準。保守的             |
| 50%台   | 借入余力が減る。増資圧力が高まる         |
| 60%前後 | 多くのJ-REITが自主的な上限としている水準 |

LTVが低い＝**借入余力（デットキャパシティ）がある**＝増資せずに物件を買える、ということ。
不況時にはこの余力そのものが競争力になる。

### 6-4. 借入の質（2026年に最も重視される項目）

金利が上がる局面では、**「いくら借りているか」より「どう借りているか」**が効く。

| 見る点             | なぜ重要か                                               |
| ------------------ | -------------------------------------------------------- |
| **固定金利比率**   | 変動が多いほど利上げが即座に分配金を削る                 |
| **平均残存年数**   | 短いほど早く高い金利に借り換わる                         |
| **返済期限の分散** | 同じ年に集中していると、その年の市場環境に運命を握られる |
| **平均調達コスト** | 既存の低金利借入がいつ入れ替わるかで将来の費用が読める   |

## 7. 分配金がどう作られるか（損益の流れ）

```
【J-REITの損益計算の流れ】

   賃貸事業収入（賃料＋共益費＋駐車場等）
     − 賃貸事業費用（PM/BM費、水道光熱費、固定資産税、修繕費、保険）
   ＝ NOI（純収益）                    ← 物件の実力はここで決まる
     − 減価償却費                      ← 現金は出ていかない
   ＝ 不動産賃貸事業損益
     − 資産運用報酬・資産保管料・事務委託料・監査報酬（＝器の運営コスト）
     − 支払利息・融資関連費用           ← 金利上昇で膨らむ
     ± 不動産等売却損益                 ← 資産入替で作る一過性の利益
   ＝ 当期純利益
     → その 90%超（実務上はほぼ全額）を分配
   （＋ 利益超過分配を行う場合はここに上乗せ）
     ÷ 発行済投資口数
   ＝ **DPU（1口あたり分配金）**
```

| 分配金を増やす道 | 中身                                               | 性質                                         |
| ---------------- | -------------------------------------------------- | -------------------------------------------- |
| **内部成長**     | 既存物件の賃料を上げる、稼働率を上げる、費用を削る | 持続的。オフィス市況が良い局面で効く         |
| **外部成長**     | 物件を買い増す（増資・借入）                       | 増資できる環境が必要（NAV倍率が効く）        |
| **資産入替**     | 含み益のある物件を売り、利回りの高い物件を買う     | 売却益は一過性。**継続性を見極める必要あり** |
| **財務**         | 借換えで金利を下げる、自己投資口の取得             | 金利低下局面で効く。2026年は逆風             |

> 2026年の文脈：**公募増資がしづらく、資産入替による利益成長が広がった**と報じられている。
> 売却益は一度きりなので、**DPUの伸びが売却益由来か賃料上昇由来かを分けて見る**のが基本作法になる。

## 8. J-REITと他の不動産の持ち方の比較

| 持ち方                           | 最低単位                   | 流動性                 | レバレッジ             | 運営の手間 | 価格の決まり方                     |
| -------------------------------- | -------------------------- | ---------------------- | ---------------------- | ---------- | ---------------------------------- |
| **現物の賃貸不動産**             | 数百万〜数億円             | 低い（数か月）         | 自分で借りる           | 自分で担う | 個別交渉                           |
| **J-REIT**                       | 数万〜数十万円             | **高い（即日）**       | REIT内部でLTV40〜50%台 | なし       | **市場の需給**。NAVから乖離する    |
| **私募REIT**                     | 億円単位（機関投資家向け） | 中（期中解約に制限）   | 同程度                 | なし       | **鑑定評価ベース**。市場で振れない |
| **不動産私募ファンド**           | 億円単位                   | 低い（期限まで固定）   | 高め                   | なし       | 鑑定＋出口価格                     |
| **不動産クラウドファンディング** | 1万円〜                    | 低い（途中解約に制限） | 案件次第               | なし       | 事業者の設定                       |
| **不動産株（デベロッパー）**     | 数万円〜                   | 高い                   | 会社全体の財務         | なし       | 株式市場                           |

> 重要な性質：**J-REITは不動産でありながら価格の振れ方が株式に近い**。東証で売買される以上、
> 物件の中身が変わらなくても金利観測や資金フローで価格が動く。一方、**私募REITは鑑定評価に基づくので日々の値動きがない**。
> 年金基金などが私募REITを好むのは、この「値が動いて見えない」点も理由とされる（→ [③](03_市場と参加者.md)）。

## 9. 投資主の顔ぶれ

J-REITの投資口を誰が持っているかは、市場の値動きを理解するうえで欠かせない。

| 投資主                         | 立ち位置                                                                                          |
| ------------------------------ | ------------------------------------------------------------------------------------------------- |
| **海外投資家**                 | 売買代金のシェアが大きく、**価格を動かす主役**。日本の金利と円相場に反応する                      |
| **個人投資家**                 | 分配金を目的とした長期保有が中心。下落局面の受け皿になりやすい                                    |
| **投資信託（毎月分配型など）** | 資金流出入がそのまま需給になる → [資産運用](../06_資産運用/README.md)                             |
| **地方銀行・信用金庫**         | 利回り資産として保有。金利上昇時に他資産へ振り替える動きも → [地方銀行](../02_地方銀行/README.md) |
| **日本銀行**                   | 金融緩和期にETFとあわせてJ-REITを買い入れていた（新規買入は2024年3月の政策変更で終了）            |
| **スポンサー**                 | 一定割合を保有し、コミットメントを示す                                                            |

## 10. 用語メモ

| 用語                           | 意味                                                                      |
| ------------------------------ | ------------------------------------------------------------------------- |
| **投資法人**                   | 投信法に基づく法人。従業員を持たず、資産運用を外部に委託する器            |
| **投資口／投資主**             | 株式／株主に相当。分配金は配当に相当                                      |
| **導管性要件**                 | 器の段階で法人税がかからないための条件。**配当可能利益の90%超の分配**が柱 |
| **DPU**                        | Distribution Per Unit。1口あたり分配金                                    |
| **NAV／NAV倍率**               | 純資産価値（鑑定評価額−負債）／投資口価格 ÷ 1口あたりNAV                  |
| **LTV**                        | 有利子負債 ÷ 総資産。J-REITでは40〜50%台が標準                            |
| **NOI**                        | 賃料 − 運営費。減価償却前・金利前の純収益                                 |
| **FFO**                        | 純利益 ＋ 減価償却費 − 売却損益。現金創出力を見る指標                     |
| **内部成長／外部成長**         | 既存物件の賃料・稼働率の改善／物件の買い増し                              |
| **資産入替**                   | 物件を売って別の物件を買うこと。売却益は一過性                            |
| **利益超過分配（OPD）**        | 会計上の利益を超える分配。減価償却相当の現金を原資とする                  |
| **スポンサー／パイプライン**   | 親会社／そこから物件が供給される仕組み                                    |
| **ウェアハウジング**           | スポンサーが一時的に物件を保有し、後でREITに引き渡す機能                  |
| **利害関係者取引**             | スポンサー等との取引。鑑定評価と役員会承認が必要                          |
| **監督役員**                   | 投資法人の役員会で執行役員を監督する外部の役員。ガバナンスの要            |
| **イールドスプレッド**         | 分配金利回り − 長期金利。割高・割安の目安に使われる                       |
| **希薄化（ダイリューション）** | 増資により1口あたりの価値が下がること                                     |
