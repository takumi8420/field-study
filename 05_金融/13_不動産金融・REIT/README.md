# 不動産金融・REIT

- 大分類: 金融
- 状態: done
- 更新日: 2026-09-20

**一言でいうと**：ビルや倉庫という「動かせない資産」を、証券化という技術で
**金融商品に作り替えて売買する産業**。中核にあるのは器（SPC・投資法人）、倒産隔離、
ノンリコースローン、そして**シニア／メザニン／エクイティという階層構造**である。
上場した形が **J-REIT**（2026年8月末で58銘柄・時価総額15.6兆円）、
表に出ない形が **私募ファンド**（2025年12月末で約47.1兆円と推計）。

> **本フォルダは仕組みの解説であり、投資助言ではない。**
> 特定の銘柄・ファンド・商品の推奨は一切行わない。数値は時点と出典を添えているが、
> 市況は日々動くため、実際の判断には必ず一次情報を確認すること。

## 1. 業界の定義・範囲

「不動産金融」とは、**不動産そのものを開発・仲介・管理する仕事ではなく、
不動産を裏付けとした資金の出し入れとリスクの配分を担う仕事**を指す。
具体的には、証券化のスキーム組成、ファンドの運用（AM）、ノンリコースローンの貸出、
J-REITの運営が中心になる。

| 区別する相手                                                                                                                                 | 境界                                                                                                                         |
| -------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| [不動産デベロッパー](../../12_建設・住宅・不動産/08_不動産デベロッパー/README.md)                                                            | 土地を仕入れて建てる＝**開発リスクを取る**。J-REITは原則取らない。ただしデベロッパーはスポンサーとしてこの業界の中心にもいる |
| [不動産仲介・流通](../../12_建設・住宅・不動産/09_不動産仲介・流通/README.md)                                                                | 売買の媒介で手数料を得る。自分では保有しない                                                                                 |
| [賃貸管理](../../12_建設・住宅・不動産/10_賃貸管理/README.md)／[ビル管理](../../12_建設・住宅・不動産/11_ビル管理・不動産サービス/README.md) | PM/BMとして現場を回す。投資判断（買う・売る）はしない                                                                        |
| [信託銀行](../03_信託銀行/README.md)                                                                                                         | 不動産信託の受託者。併営業務として不動産仲介・鑑定も行う。この業界の裏方                                                     |
| [資産運用](../06_資産運用/README.md)                                                                                                         | 株式・債券の運用。収益構造（AUM×料率）は不動産AMとほぼ同型                                                                   |
| [メガバンク](../01_メガバンク/README.md)／[地方銀行](../02_地方銀行/README.md)                                                               | ノンリコースローンの出し手。不動産金融は彼らの一業務                                                                         |
| [証券](../05_証券/README.md)                                                                                                                 | J-REITの増資引受、スキームのアレンジ                                                                                         |
| [リース](../10_リース/README.md)                                                                                                             | 不動産リース、ファンドへの出資で一部重なる                                                                                   |

**含める範囲**：証券化スキームの組成／不動産AM会社／J-REITと投資法人／私募REITと私募ファンド／
ノンリコースローンとメザニン／不動産特定共同事業（クラウドファンディング）まで。

**成長性の見方が独特**である。この業界は「人口が増えるか」ではなく、
**①金利水準 ②賃料の伸び ③証券化される不動産の比率**の3つで決まる。

- **①金利**：日銀の政策金利は2026年9月に1.25%程度へ（約31年ぶりの水準、報道ベース）。
  金利上昇はキャップレート上昇と借入コスト増の両方でマイナスに効く
- **②賃料**：都心オフィスは30か月連続で上昇。インフレは不動産にとってプラス要因
- **③証券化比率**：日本の不動産ストックのうち証券化されているのは一部にすぎず、
  企業の保有不動産のオフバランス化が進めば市場は拡大する余地がある

## 3. バリューチェーン（お金と物件の流れ）

```
【不動産金融のバリューチェーン】

 ＜川上：物件を作る／出す＞
  デベロッパー ──開発──▶ 稼働物件
  事業会社     ──売却──▶ （オフバランス化）
        │
        ▼
 ＜中流：器に入れる＝ここが不動産金融の本体＞
  信託銀行 ──信託受益権化──▶ ┌──────────────┐
  アレンジャー ──組成──────▶│ SPC／投資法人（器）│
  銀行 ──ノンリコースローン──▶│ 倒産隔離された箱  │
  メザニン投資家 ──劣後資金──▶│ LTV 40〜60%      │
  エクイティ投資家 ──出資────▶└──────────────┘
                                      │ AM会社が運用判断
        ┌──────────────────────┴──────────┐
        ▼                                            ▼
 ＜川下：投資家に届ける＞                    ＜現場：物件を回す＞
  J-REIT（東証に上場）… 個人・海外・投信      PM：テナント募集・賃料回収
  私募REIT（非上場・無期限）… 年金・地銀      BM：清掃・設備保守
  私募ファンド（期限あり）… 機関投資家        → 賃料 − 費用 ＝ NOI
  クラウドファンディング（1万円〜）… 個人

  【付加価値が集まる場所】
   ① **物件を安定供給できる者**（スポンサー＝デベロッパー系が強い理由）
   ② **資金を最も安く集められる者**（信用力＝調達コストがそのまま競争力）
   ③ **AUMを積み上げた運用会社**（人件費が固定費なので規模で一気に儲かる）
```

詳細は [① 証券化の仕組み](01_不動産を金融商品にする仕組み.md) と [③ 市場と参加者](03_市場と参加者.md)。

## 4. 主要プレイヤーとシェア

この業界の「プレイヤー」は**器ではなく、器を動かす運用会社とスポンサー**で見る。
J-REIT 58銘柄（2026年8月末）はスポンサーの系統で分類すると理解しやすい。

| 系統                           | 立ち位置                                         | 特徴                                                                           |
| ------------------------------ | ------------------------------------------------ | ------------------------------------------------------------------------------ |
| **デベロッパー系**             | J-REITの最大勢力。都心の大型オフィス・商業を供給 | 自社開発物件のパイプラインが強み。開発リスクは親会社が取り、稼働後にREITへ渡す |
| **商社系**                     | 複数アセットに分散。資金力と目利き               | 外部からの取得も多く、物流・ホテルにも展開                                     |
| **金融系（信託・銀行・証券）** | 機関投資家との関係と調達力                       | 私募REITの運用会社としての存在感が大きい                                       |
| **外資・独立系**               | 物流施設・データセンターなど新アセットで先行     | グローバルの資金調達力。バリューアッド〜オポチュニスティックも担う             |
| **不動産サービス系**           | 管理・仲介の現場情報を投資に活かす               | 住宅・中小型オフィスに強い                                                     |

**シェアの見方**：J-REITは銘柄数より**資産規模と時価総額の集中度**で見る。
上位数銘柄が時価総額の相当部分を占める一方、小型銘柄は流動性が低く、
**NAV倍率1倍割れが続くと再編（合併・TOB）の対象になりやすい**（→ [④](04_直近トピック_2026.md)）。

> 個別の銘柄名・ファンド名を挙げていないのは意図的である。
> 本フォルダは仕組みの理解を目的としており、特定の商品を評価・推奨しない。

## 5. 収益モデル・コスト構造

この業界には**性格の異なる3つの稼ぎ方**が同居している。ここを混同すると理解できない。

| 稼ぎ方                   | 誰が                   | 収益の源                                                             | 性質                                                                          |
| ------------------------ | ---------------------- | -------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| **① 運用報酬（フィー）** | AM会社                 | AUM × 0.3〜0.5%程度＋取得・売却報酬（取引額の0.5〜1%程度）＋成功報酬 | **安定・積み上げ型**。コストはほぼ人件費なので、AUMが増えると急激に利益が出る |
| **② 金利（スプレッド）** | 銀行、メザニン投資家   | 貸出金利 − 調達コスト                                                | 安定。ただし物件が傷むと元本を失う                                            |
| **③ 分配金＋売却益**     | エクイティ投資家、REIT | NOI − 利息、および売却損益                                           | **レバレッジで増幅される。損も同じ倍率で増幅**                                |

### J-REITの損益の流れ（→ 詳細は [②](02_J-REITの仕組みと経済.md)）

```
  賃料収入 −（管理費・税・修繕・光熱費）＝ NOI
    − 減価償却費                             ← 現金は出ない
    − 運用報酬・保管料・事務委託料             ← 器の運営コスト
    − 支払利息                                ← **金利上昇で膨らむ**
    ± 不動産売却損益                          ← 資産入替による一過性の利益
  ＝ 当期純利益 → **90%超を分配**（導管性要件）
  ÷ 投資口数 ＝ DPU（1口あたり分配金）
```

### レバレッジの算数（この業界の核心）

```
 エクイティ利回り ＝ NOI利回り ＋ （NOI利回り − 借入金利）× 借入 ÷ 自己資金

  例：NOI利回り4.0%、借入金利2.0%、LTV60%（借入60／自己資金40）
     → 4.0% ＋ (4.0% − 2.0%) × 1.5 ＝ **7.0%**
  借入金利が4.5%に上がると
     → 4.0% ＋ (4.0% − 4.5%) × 1.5 ＝ **3.25%（逆ざや）**
```

**利益率の目安**：J-REITのNOI利回りは物件と用途で3〜6%程度、
LTVは40〜50%台が標準（自主的な上限は60%前後が多い）。
AM会社の営業利益率は規模によるが、AUMが一定を超えると20〜40%台に乗ることがある。

## 6. 競争要因（KSF）と参入障壁

| 優位の源泉                           | 中身                                                                         | 真似しにくさ |
| ------------------------------------ | ---------------------------------------------------------------------------- | ------------ |
| **物件の供給ルート（パイプライン）** | スポンサーが継続的に優良物件を供給できるか。市場で競り合わずに買える         | ★★★          |
| **資金調達コスト**                   | 信用力が高いほど安く借りられ、同じ物件でもリターンが高くなる                 | ★★★          |
| **AUMの規模**                        | 人件費が固定費なので、規模が利益率に直結する。大型案件を単独で引き受けられる | ★★★          |
| **投資家との関係**                   | 年金・生保・海外機関投資家からの継続的な資金コミットメント                   | ★★           |
| **物件のオペレーション力**           | ホテル・商業・データセンターは運営力がNOIを左右する                          | ★★           |
| **スキーム組成のノウハウ**           | 税務・法務・会計の複合技。人に宿る                                           | ★★           |

参入障壁は**免許・登録**（金商法の投資運用業、宅建業免許、信託業免許、不特法の許可）と、
**スポンサーの有無**。免許は取得できても、
**物件を継続的に買える立場（パイプライン）を持たない運用会社は成長できない**。
これが独立系AM会社がニッチ特化に向かう理由でもある。

## 7. 規制・法制度

| 制度                                                       | 中身                                                                                 | 効き方                                                                   |
| ---------------------------------------------------------- | ------------------------------------------------------------------------------------ | ------------------------------------------------------------------------ |
| **投資信託及び投資法人に関する法律（投信法）**             | 投資法人の設立、役員会、資産運用の外部委託義務                                       | J-REITの器そのものの根拠法                                               |
| **資産流動化法（SPC法）**                                  | TMK（特定目的会社）、資産流動化計画の届出、優先出資証券・特定社債                    | 大型・長期・現物保有の証券化スキームの根拠                               |
| **租税特別措置法（導管性要件）**                           | **配当可能利益の90%超の分配**、同族支配でないこと、借入先を適格機関投資家に限定 等   | これを満たすと**器の段階の法人税が実質的に消える**。J-REITの高分配の源泉 |
| **金融商品取引法**                                         | 投資運用業・第二種金融商品取引業の登録、開示義務、利害関係者取引規制                 | AM会社の免許。利益相反の歯止め                                           |
| **宅地建物取引業法**                                       | 現物不動産の売買・媒介には宅建業免許が必要                                           | 信託受益権での取引が多い理由の一つ                                       |
| **信託業法**                                               | 不動産信託の受託者は信託業免許が必要                                                 | 信託銀行が裏方として不可欠な理由                                         |
| **不動産特定共同事業法（不特法）**                         | 個人向け小口化商品の許可制。2017年改正で電子取引業務（クラウドファンディング）を解禁 | 個人の1万円単位の参入を可能にした                                        |
| **不動産鑑定評価基準**                                     | 物件価格の算定基準。収益還元法（DCF、直接還元法）                                    | 利害関係者取引・NAV算定の客観性を支える                                  |
| **金融庁 金融行政方針（2026事務年度、2026年9月15日公表）** | 大手金融機関の**不動産業向け融資**、超長期住宅ローン、流動性リスクの点検を重点化     | レンダー側の審査が厳しくなる方向                                         |

| **シニア／メザニン／エクイティ**               | 受け取り順が早い順の階層。早いほど低リスク低リターン → [①](01_不動産を金融商品にする仕組み.md)                       |
| **LTV／DSCR**                                  | 借入÷物件価値／NOI÷元利返済額。ローンの契約条件（コベナンツ）に使う → [①](01_不動産を金融商品にする仕組み.md)        |
| **GK-TK／TMK**                                 | 合同会社＋匿名組合の私募スキーム／資産流動化法に基づく法定の器 → [①](01_不動産を金融商品にする仕組み.md)             |
| **投資法人／投資口／分配金**                   | J-REITの器／株式に相当／配当に相当 → [②](02_J-REITの仕組みと経済.md)                                                 |
| **導管性要件**                                 | 器の段階で法人税がかからない条件。**配当可能利益の90%超の分配**が柱 → [②](02_J-REITの仕組みと経済.md)                |
| **NAV／NAV倍率**                               | 純資産価値／投資口価格÷1口あたりNAV。1倍割れだと増資しづらい → [②](02_J-REITの仕組みと経済.md)                       |
| **DPU／FFO**                                   | 1口あたり分配金／純利益＋減価償却−売却損益 → [②](02_J-REITの仕組みと経済.md)                                         |
| **スポンサー／パイプライン**                   | 親会社／そこから物件が供給される仕組み → [②](02_J-REITの仕組みと経済.md)                                             |
| **内部成長／外部成長／資産入替**               | 既存物件の改善／物件の買い増し／売って買う → [②](02_J-REITの仕組みと経済.md)                                         |
| **NOI**                                        | 賃料 − 運営費。減価償却前・金利前の純収益 → [①](01_不動産を金融商品にする仕組み.md)                                  |
| **キャップレート**                             | NOI ÷ 価格。長期金利＋リスクプレミアムで決まる。上がれば価格は下がる → [③](03_市場と参加者.md)                       |
| **私募REIT**                                   | 非上場・無期限の投資法人。鑑定評価ベースなので日々値動きしない → [③](03_市場と参加者.md)                             |
| **オープンエンド／クローズドエンド**           | 期限なしで随時出入り可能／期限があり出口で売却 → [③](03_市場と参加者.md)                                             |
| **コア／バリューアッド／オポチュニスティック** | リスクとリターンによる運用スタイルの類型 → [③](03_市場と参加者.md)                                                   |
| **AM／PM／BM**                                 | 投資判断／テナント対応／建物の維持管理 → [①](01_不動産を金融商品にする仕組み.md)                                     |
| **AUM**                                        | 預かり資産残高。運用会社の収益の分母 → [③](03_市場と参加者.md)                                                       |
| **不動産特定共同事業（不特法）**               | 個人向けの小口化商品の制度。クラウドファンディングの根拠法 → [③](03_市場と参加者.md)                                 |
