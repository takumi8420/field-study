# 市場インフラと規制

このノートで分かること：株の売買注文が出てから決済が終わるまでに **どんな機関が関わるか**、
そして証券業を縛る規制が **どんな事件を受けて作られてきたか**。

> ポイント：証券市場は「誰でも参加できる」ように見えて、実際は
> **取引所・清算機関・保管振替機構という3層のインフラ**と、
> **信用を守るための規制**が支えている。この2つが分かると業界ニュースの意味が変わる。

---

## 1. 注文から決済までの流れ

```
【日本株を1単元買うときに動く機関】

 投資家
   │ ①注文
   ▼
 証券会社（金融商品取引業者）
   │ ②発注（SORで取引所かPTSかを選ぶ）
   ▼
 東京証券取引所（JPX） ─── または PTS（私設取引システム）
   │ ③売り注文と付け合わせて約定（値段が決まる）
   ▼
 日本証券クリアリング機構（JSCC）＝清算機関
   │ ④債務引受・ネッティング（売り買いを相殺して差額だけにする）
   │   「相手が破綻しても決済は守る」役割
   ▼
 証券保管振替機構（ほふり／JASDEC）＝振替機関
   │ ⑤株式は現物の紙ではなく口座間の振替で移る（2009年に株券電子化）
   ▼
 資金決済（日銀ネット・銀行）
   │ ⑥現在は T+2（約定日から2営業日後）に受渡
   ▼
 投資家の口座に株式が入る
```

| 機関 | 役割 | ないとどうなるか |
| --- | --- | --- |
| **取引所（東証）** | 売り買いを集め、値段を付ける。上場審査と上場廃止も担う | 公正な価格が形成されず、どこで買えば正しいか分からない |
| **PTS（私設取引システム）** | 取引所外の売買の場。夜間取引や価格改善を提供 | 取引所が独占し、手数料と執行条件が改善されない |
| **JSCC（清算機関）** | 売買の債務を引き受け、相殺して決済量を圧縮する | 取引相手の破綻が連鎖する（カウンターパーティーリスク） |
| **JASDEC（保管振替機構）** | 株式・社債の保有記録を電子的に管理し、口座間で振り替える | 株券の現物を運ぶ必要がある。紛失・偽造リスク |
| **信託銀行（カストディ）** | 機関投資家の資産の保管・決済代行 | 大口投資家が自前で管理する必要があり、コストが跳ねる |

## 2. 東証と市場区分

東京証券取引所は2022年4月に、従来の1部・2部・マザーズ・JASDAQを
**プライム・スタンダード・グロース** の3区分へ再編した。
狙いは「1部上場」の看板が形骸化していた状態を正すこと。

| 市場 | 位置づけ | 主な上場維持基準（概要） |
| --- | --- | --- |
| **プライム** | グローバル投資家との対話を中心に据える企業 | 流通株式時価総額100億円以上、流通株式比率35%以上 など |
| **スタンダード** | 公開された市場で安定的に事業を行う企業 | 流通株式時価総額10億円以上、流通株式比率25%以上 など |
| **グロース** | 高い成長可能性を持つ企業。実績より計画を見る | 上場後一定年数での時価総額基準。2030年から基準を見直し |

### 2-1. 経過措置の終了が何を意味するか

再編時、基準を満たさない企業には長い **経過措置**（当面は緩い基準でよい、という猶予）が付いたため、
「看板を変えただけ」という批判が強かった。この猶予が2025年3月以降に順次終了し、
**本来の上場維持基準が実際に適用される段階**に入った。

```
【東証再編の実際の効き方】

 2022.4  3区分へ再編 ──┐
                       │ 経過措置（猶予）が長く、実質は温存
 2025.3  経過措置が終了 ┘
   │
   ├─▶ 基準未達 ──▶ 1年間（売買高基準は6か月）の改善期間
   │                     │
   │                     └─▶ 改善できなければ監理・整理銘柄 ──▶ 上場廃止
   │
   └─▶ プライム→スタンダードへ市場変更する企業が続出
        （2022年4月〜2025年3月末で170社以上）

 2026年4月末時点：スタンダード市場の上場企業数がプライムをわずかに上回った
```

証券会社にとっての意味：

- **上場企業が減る／移る**こと自体より、企業が基準を満たそうとして **自社株買い・政策保有株の売却・MBO・親子上場の解消** を進めることが重要。
  そのすべてが証券会社の引受・アドバイザリー業務になる
- グロース市場の基準見直し（2030年から適用予定）は、**IPOの出口設計**に影響する

## 3. 規制の全体像

証券業を規律する法律の中心は **金融商品取引法**（2007年施行。前身は証券取引法）。
「投資家を守る」と「市場の信頼を保つ」という2つの目的で組み立てられている。

| 規制 | 内容 | なぜあるか |
| --- | --- | --- |
| **登録制（第一種金融商品取引業）** | 証券業を営むには内閣総理大臣の登録が必要 | 誰でも他人の資産を扱えると被害が広がる |
| **自己資本規制比率** | 120%を下回ると業務改善、100%割れで業務停止の対象 | 自己勘定でリスクを取る業態なので体力を測る必要がある |
| **分別管理義務** | 顧客資産を会社の資産と完全に分けて管理 | 証券会社が破綻しても顧客資産を守るため |
| **投資者保護基金** | 分別管理が機能しなかった場合、1人1,000万円を上限に補償 | 最後の安全網 |
| **適合性の原則** | 顧客の知識・経験・財産・目的に照らして不適当な勧誘をしてはならない | 高齢者へのリスク商品販売などの被害を防ぐ |
| **断定的判断の提供の禁止** | 「必ず上がる」と言って勧誘してはならない | 投資は不確実であるという前提を守る |
| **最良執行義務** | 顧客にとって最も有利な条件で注文を執行する | SOR・PTSの選択にも関わる |
| **インサイダー取引規制** | 未公表の重要事実を知る者による売買の禁止 | 情報の非対称性で市場の信頼が壊れる |
| **相場操縦の禁止** | 見せ玉、仮装売買などで価格を歪める行為の禁止 | 価格形成の正しさが市場の存在理由 |
| **銀証ファイアウォール規制** | 同一グループの銀行・証券間で非公開の顧客情報を無断共有することの禁止 | 銀行の優越的地位の乱用を防ぐ |

### 3-1. 顧客本位の業務運営（フィデューシャリー・デューティー）

**フィデューシャリー・デューティー**＝他人の信頼を受けて仕事をする者が負う責任。
もともとは信託の受託者の義務を指したが、いまは金融機関全般に使われる。

金融庁は2017年に **「顧客本位の業務運営に関する原則」** を策定（2021年・2024年に改訂）。
法律ではなく **プリンシプルベース**（細かい規則ではなく原則を示し、各社が自ら考えて守る形）。
7つの原則は、方針の策定・公表、顧客の最善の利益の追求、利益相反の適切な管理、
手数料等の明確化、重要な情報の分かりやすい提供、顧客にふさわしいサービスの提供、
従業員への適切な動機づけ。

さらに2024年11月には **「顧客の最善の利益を勘案した誠実公正義務」が法定化** され
（金融サービス提供法）、原則にとどまっていたものが法的義務に格上げされた。
2024年9月の原則改訂では **プロダクトガバナンス**（商品を作る側＝運用会社も、
売る側＝販売会社と情報連携して商品の適切性に責任を持つ）が加えられている。

```
【顧客本位の規制が向かっている方向】

  従来：ルールベース             いま：プリンシプル＋法定義務
  ┏━━━━━━━━━━━┓          ┏━━━━━━━━━━━━━━━┓
  ┃ 禁止行為を列挙   ┃  ───▶  ┃ 「最善の利益」という結果責任 ┃
  ┃ 書面を交付すれば ┃          ┃ 商品設計から販売後まで一貫   ┃
  ┃ 説明したことに   ┃          ┃ （プロダクトガバナンス）     ┃
  ┗━━━━━━━━━━━┛          ┗━━━━━━━━━━━━━━━┛
      ▲ 抜け道を探す動機が残る        ▲ 手数料の高い商品を売る営業が成立しにくくなる
```

これが [② 手数料ゼロ時代](02_手数料ゼロ時代.md) で触れた「回転売買からの脱却」を
制度側から押している力である。

## 4. 不正の歴史と、そこから生まれた規制

規制は抽象的な理念からではなく、**実際に起きた事件の後始末**として積み上がってきた。

| 時期 | 出来事 | 生まれた／強化された規制 |
| --- | --- | --- |
| 1991年 | 大手証券の **損失補填問題**（大口顧客の損失を穴埋めしていた） | 損失補填の禁止が明文化。証券取引等監視委員会が1992年に設置 |
| 1997年 | 総会屋への利益供与事件、**山一證券の自主廃業**（簿外債務） | 財務の透明化、破綻時の投資者保護の仕組み整備 |
| 2006年 | ライブドア事件（有価証券報告書の虚偽記載） | 2007年の金融商品取引法施行、**内部統制報告制度（J-SOX）** |
| 2012年 | **増資インサイダー事件**（公募増資の情報が証券会社から機関投資家へ漏れた） | 情報伝達・取引推奨行為への規制導入（2013年改正） |
| 2022年 | SMBC日興証券の **相場操縦事件**（ブロックオファーに絡む買い支え） | 自己勘定と顧客業務の間の管理体制強化、行政処分 |
| 2024年 | 三菱UFJ銀行と系列証券の **顧客情報の無断共有** | 銀証ファイアウォール規制の運用強化、業務改善命令 |
| 2025年 | **証券口座の不正アクセス・乗っ取り**の急増 | 多要素認証の実質必須化、監督指針・協会ガイドラインの改正（→[④](04_直近トピック_2026.md)） |

> 証券業は **「信用」を売る商売**なので、不祥事のコストが他業種より重い。
> 1回の事件が業務停止・顧客流出・制度変更につながる。

## 5. 資産運用立国とNISA

政府は2023年に **「資産運用立国」** を掲げ、家計の金融資産を預金から投資へ動かす方針を打ち出した。
その中核が **NISA**（少額投資非課税制度）である。通常なら売却益・配当に約20%課税されるところ、
NISA口座内なら非課税になる。

| 項目 | 内容 |
| --- | --- |
| 2024年からの新NISA | 非課税保有期間が無期限化。年間投資枠は つみたて投資枠120万円＋成長投資枠240万円の計360万円。生涯の非課税保有限度額1,800万円 |
| 政府目標 | 2027年末までに口座数3,400万、買付額56兆円 |
| 進捗 | 買付額56兆円の目標は **2025年3月に前倒しで達成**。2025年12月末時点で累計買付額は約71兆円（前年比36%増）、口座数も約1割増（金融庁公表ベース） |
| 2026年度の動き | 金融庁は2026年度税制改正でNISAの対象商品拡充を含む制度の充実を要望。利用者目線での使い勝手改善が論点 |
| 課題 | **未稼働口座**（開設したが買付額ゼロ）の多さ。口座数だけでは実態を測れない |

```
【資産運用立国の狙い】

 家計金融資産 約2,200兆円（日銀資金循環統計ベース）
     │  うち現預金が半分超 ← 米国は1割台、欧州は3割前後
     │
     ▼ NISAで税制の壁を下げる
 投資へ ──▶ 企業に資金が回る ──▶ 企業価値向上 ──▶ 家計の資産が増える
     ▲                                                    │
     └────────────── 好循環をつくる、という設計 ──┘

 証券会社にとって：口座と預り資産が増える最大の追い風。
 ただし非課税枠の商品は低コストのインデックス投信が中心で、
 「残高は増えるが料率は低い」＝ 薄利多売の構造になる点に注意。
```

## 6. 決済インフラの次の論点：T+1

現在の日本株の受渡は **T+2**（約定日から2営業日後）。
米国・カナダは2024年5月にT+1へ移行し、欧州・英国も移行を予定している。
日本でも金融庁・日本証券業協会・JSCC・東証が検討会を設け、
2025年7月に中間的な検討状況を公表した段階（2026年9月時点で移行時期は確定していない）。

| 論点 | 中身 |
| --- | --- |
| なぜ短縮するか | 決済が終わるまでの期間が短いほど、相手方が破綻するリスクと必要な担保が減る |
| 難しさ | 海外投資家は時差の中で為替手当てと証券の準備を1日で終える必要がある |
| 証券会社への影響 | 約定から決済までの事務を大幅に前倒し・自動化する必要があり、システム投資が発生 |
| 副次効果 | 貸株・信用取引・投信の設定解約など、周辺業務すべてのスケジュールが変わる |

## 7. まとめ

1. 市場は **取引所→清算機関（JSCC）→振替機関（JASDEC）** の3層で支えられている
2. 東証の市場区分見直しは、**経過措置の終了（2025年3月〜）でようやく実効性を持った**
3. 規制の中心は金融商品取引法。**登録制・分別管理・自己資本規制・不公正取引の禁止**が骨格
4. 顧客本位の業務運営は原則から **法定義務（2024年11月）** へ格上げされた
5. NISAは政府目標を前倒しで達成。**口座と残高は増えたが料率は低い**という新しい課題がある
6. 次のインフラ論点は **T+1**。証券会社にとってはシステム投資の負担

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **金融商品取引法（金商法）** | 証券業と市場を規律する中心的な法律。2007年施行 |
| **第一種金融商品取引業** | 株式・債券などの売買・引受を行う業務区分。登録が必要 |
| **JSCC（日本証券クリアリング機構）** | 清算機関。売買の債務を引き受け、相殺して決済を確実にする |
| **JASDEC（証券保管振替機構／ほふり）** | 株式・社債の保有を電子的に記録し、口座間で振り替える機関 |
| **株券電子化** | 2009年に紙の株券を廃止し、すべて振替口座の記録に移した制度変更 |
| **T+2／T+1** | 約定日の2営業日後／1営業日後に受渡を行う決済サイクル |
| **ネッティング** | 売りと買いを相殺し、差額だけを決済すること。決済量とリスクを圧縮する |
| **自己資本規制比率** | 証券会社の財務健全性指標。120%未満で改善命令、100%未満で業務停止の対象 |
| **分別管理** | 顧客資産を自社資産と分けて管理する法定義務 |
| **投資者保護基金** | 分別管理が機能しなかった場合に1人1,000万円まで補償する制度 |
| **適合性の原則** | 顧客の知識・経験・財産・目的に合わない勧誘を禁じる原則 |
| **インサイダー取引** | 未公表の重要事実を知る立場の者が、公表前に売買すること。刑事罰の対象 |
| **相場操縦** | 見せ玉・仮装売買などで価格を人為的に動かす行為。禁止されている |
| **顧客本位の業務運営（FD）** | 顧客の最善の利益を追求する原則。2024年11月に誠実公正義務として法定化 |
| **プロダクトガバナンス** | 商品を作る側と売る側が連携し、商品の適切性に責任を持つ考え方 |
| **銀証ファイアウォール規制** | グループ内の銀行と証券の間で非公開顧客情報の授受を制限する規制 |
| **上場維持基準** | 上場を続けるために満たすべき基準。未達なら改善期間を経て上場廃止 |
| **流通株式** | 大株主や役員の保有分などを除いた、市場で実際に流通しうる株式 |
| **NISA** | 少額投資非課税制度。口座内の売却益・配当が非課税になる |
| **資産運用立国** | 家計金融資産を投資へ動かし、資産運用業を成長産業にする政府方針 |
