# 直近トピック（2026年9月時点）

このノートで分かること：2025〜2026年に証券業界で実際に何が起きたか。相場・制度・事件・市場再編の4方向から、
[①](01_証券会社は何で稼ぐか.md)〜[③](03_市場インフラと規制.md)で説明した構造が **現実にどう動いたか** を追う。

> 本ノートは報道・公表資料ベースの整理であり、**投資判断の助言ではない**。
> 特定の銘柄・商品・時期についての推奨は一切含まない。数値は一次情報で裏取りすること。

## 1. 相場環境：日経平均7万円と、フローの一時的な復活

2026年6月16日、日経平均株価は取引時間中に初めて **7万円台** に乗せ、終値6万9,404円で連日の最高値を更新したと
報じられた（日本経済新聞、2026年6月）。AI・半導体関連への成長期待と企業の資本効率改善への評価を背景に
**海外投資家の資金が継続的に流入した**ことが要因として挙げられている。

証券会社にとって、株高は次の4経路で効く。分けて理解するのが重要。

| 経路 | 何が増えるか | 性格 | どの部門に効くか |
| --- | --- | --- | --- |
| **売買が増える** | 委託手数料（日本株は無料化済のため直接効果は限定）、信用取引の残高、FX・先物 | フロー | ネット証券・リテール |
| **残高が増える** | 預り資産の時価が上がり、信託報酬・ラップ報酬が自動的に増える | ストック | 全社 |
| **金利が動く** | 債券売買が活発化し、FICCのトレーディング損益が伸びる | フロー（相場観依存） | ホールセール |
| **発行が増える** | 株価が高い局面は増資・IPO・M&Aが出やすい | フロー（案件依存） | ホールセール |

> 注意点：**株高による預り資産の増加は営業努力ではない**。だから各社は「資金純増」を併記する
> （→[①-2-3](01_証券会社は何で稼ぐか.md)）。2026年3月期の好決算は、この4経路が同時にプラスに働いた結果だった。

日銀が急激な引き締めを避け緩和的な環境を維持していることも支援材料とされる（三井住友DSアセットマネジメント、2026年2月）。
大手証券は2026年中に日本株の見通しを相次ぎ上方修正しているが、**これは各社の調査部門の見解であり確定した将来ではない**。

## 2. NISAの「次の設計」：拡充は続くが、方向が変わった

新NISA（2024年〜）の量的な拡大は続いている。

| 指標 | 2025年12月末時点 | 政府目標（2027年末） |
| --- | --- | --- |
| NISA口座数 | 約2,826万口座（前年比約1割増） | 3,400万口座 → 達成率およそ8割 |
| 累計買付額 | 約71兆円（前年比36%増） | 56兆円 → **2025年3月に前倒し達成済** |

（金融庁「NISA口座の利用状況に関する調査」および日本経済新聞、2026年2月報道ベース）

注目すべきは、制度が **「枠を広げる」から「使い方を広げる」へ舵を切った** こと。2025年12月19日に与党が公表し
12月26日に閣議決定された **令和8年度（2026年度）税制改正大綱** では、次が決まった／見送られた。

| 項目 | 結果 | 中身と狙い |
| --- | --- | --- |
| **こどもNISA**（大綱上の名称は未成年者特定累積投資勘定） | **創設**（2027年開始予定） | 0〜17歳を対象に年間投資枠60万円・非課税保有限度額600万円。払出しは12歳以降、子本人の同意が必要という設計で、親が自由に引き出せないようにする |
| **つみたて投資枠の対象商品拡大** | **実施** | 債券中心の投資信託を追加。値動きの小さい選択肢を用意し、取り崩し期の利用者にも合うようにする |
| **定期売却サービスの手数料徴収** | **容認** | 資産を計画的に取り崩すサービスに販売会社が手数料を取れるようにする。「売らせない」だけでなく「取り崩しを支える」業務が収益化できる |
| **プラチナNISA**（高齢者向けの別枠。毎月分配型投信を対象に加える案） | **見送り** | 毎月分配型は元本の払い戻しを分配金と誤認させる懸念があり、顧客本位の原則との整合が論点になった |

```
【NISA制度の重心の移り方】

 2014 一般NISA      「まず口座を作らせる」
 2018 つみたてNISA  「長期・積立・分散を制度で誘導」
 2024 新NISA(恒久化)「枠を大きくして残高を積む」        ←ここまでが“入口”
 2026 大綱で方向転換 ┬ こどもNISA(2027)  → 入口を年齢の下へ広げる
                     ├ つみたて枠に債券   → 出口（取り崩し期）に合わせる
                     ├ 定期売却の手数料容認→ 取り崩しを“業務”として認める
                     └ プラチナNISAは見送り→ 高手数料商品の呼び込みは認めない

 証券会社への意味：「売る」より「預かり続けて、取り崩しまで面倒を見る」方が儲かる制度設計へ。
```

課題として残るのが **未稼働口座**（開設したが買付額ゼロ）の多さで、
口座数という指標だけでは実態を測れない点は変わっていない（→[③-5](03_市場インフラと規制.md)）。

## 3. ネット証券：NISAから「準富裕層」へ軸足が動いた

2026年3月期の主要ネット証券5社の合計純利益は前期比24%増の992億円で、金利上昇と株高を背景にした
**信用取引などの金融収益とトレーディング収益** が牽引した（日本経済新聞、2026年5月）。
株式売買手数料がゼロでも利益が出る構造の実証である（→[② 手数料ゼロ時代](02_手数料ゼロ時代.md)）。新しい動きは2つ。

**(1) 信用取引の残高が収益の主柱として明確化した**。SBI証券は主要ネット証券で初めて国内株式の信用建玉残高
**3兆円** に到達したと発表（SBI証券プレスリリース、2026年）。2024年4月の2兆円到達から2年弱の積み上がりで、
**「売買手数料ゼロ＋信用金利で回収」というモデルがフル稼働している**ことを示す。

**(2) 獲得の主戦場がNISA層から準富裕層へ移った**。新NISAによる口座獲得のペースが鈍り、各社は数千万円規模の
金融資産を持つ層の取り込みに照準を移していると報じられている（日本経済新聞、2026年5月）。

```
【ネット証券の顧客獲得の重心移動】

 2024-2025                        2026以降
 ┏━━━━━━━━━━━┓           ┏━━━━━━━━━━━┓
 ┃ 新NISA層         ┃           ┃ 準富裕層         ┃
 ┃ 口座数を稼ぐ     ┃  ───▶   ┃ 1口座あたり残高  ┃
 ┃ 単価：低         ┃           ┃ 単価：高         ┃
 ┃ ポイント・手数料0 ┃           ┃ 相談機能・商品の幅┃
 ┗━━━━━━━━━━━┛           ┗━━━━━━━━━━━┛
     ▲ 数の勝負（規模の経済）      ▲ 質の勝負（対面証券の土俵に接近）

 ネット証券と対面証券は「富裕層・準富裕層」という同じ場所で正面からぶつかり始めた。
```

対面側も同じ方向を向く。野村ホールディングスは個人向け部門を **ウェルス・マネジメント部門** に改称して富裕層
ブランドの確立を掲げ、大和証券グループも2026年度の経営方針でウェルスマネジメントの深化と富裕層・法人向けの
オーダーメイド商品拡充を掲げている（各社公表、2026年）。
**「手数料で差が付かないなら、誰を顧客にするかで差を付ける」**——これが現在の競争軸である。

## 4. 証券口座乗っ取り事件の後始末：セキュリティが固定費になった

2025年に急増した証券口座の不正アクセス・不正取引は、業界の運営コストの構造を変えた。

| 時点 | 状況（いずれも報道・公表ベース） |
| --- | --- |
| 2025年1〜6月 | 不正アクセス12,758件、不正取引の金額は5,700億円超と集計された。手口はフィッシングと**パスワードリスト型攻撃**（他サービスから流出したID・パスワードの使い回しを突く）が中心 |
| 2025年10月 | 日本証券業協会が、2026年6月までに高度な多要素認証を必須化する方針の指針を示したと報じられる |
| 2026年6月末 | **パスキー**（パスワードを使わず端末の生体認証等でログインする仕組み。フィッシングに強い）等の多要素認証を原則必須とする対応が本格化 |
| 2026年7月 | 月間の不正取引が1件（200万円）まで減少したと報告される |

> 構造的な意味：**セキュリティ対策は一度上げたら下げられない固定費**になった。[②-3](02_手数料ゼロ時代.md) の
> 「固定費÷口座数」の分子が恒久的に増えたということで、口座数の少ない中堅ほど1口座あたりの負担が重くなる。

補償は各社が自主的な方針を公表する形で対応が進んだが、**法律上の一律補償制度はない**
（投資者保護基金は分別管理の失敗を対象とし、本人IDでのログインによる不正取引は原則対象外）。制度の空白が残る。

## 5. IPO市場の縮小：グロース市場の基準見直しが効き始めた

[③-2](03_市場インフラと規制.md) で触れた東証の市場区分見直しは、IPO市場に直接効いた。

```
【東証グロース市場のIPO社数（各年上半期）】

 2024上  ████████████████████████████████  34社
 2025上  ██████████████████               18社
 2026上  ███████████                      11社
         └ 上場維持基準の見直し（上場5年経過後に時価総額100億円以上）が
           2025年12月8日施行。「上場後に基準を割る」リスクを引受側が織り込んだ
```

2026年上半期の一般市場（プライム・スタンダード・グロース）への新規上場は **17社**。前年同期28社を大きく下回り
4年連続の減少で、内訳はプライム0社・スタンダード6社・グロース11社（OBC「IPO Compass」集計、2026年）。

| 何が起きているか | なぜそうなるか |
| --- | --- |
| **小粒上場の減少** | 上場5年後に時価総額100億円を維持できないと判断される案件は、主幹事が引き受けにくい。想定時価総額100億円未満の比率は2025年上半期の約61%から2026年上半期は約54.5%へ低下 |
| **「主幹事証券難民」の発生** | 引受審査のハードルが上がり、主幹事を確保できない準備会社が増えていると指摘される |
| **証券会社の収益への影響** | 引受手数料が減るだけでなく、上場準備の助言・上場後の売買という長期の収益機会も減る |
| **出口の多様化** | IPOに代わりM&A（事業売却）が出口として選ばれる場面が増え、**M&Aアドバイザリー業務の側に需要が移る** |

> ポイント：上場維持基準の厳格化は「市場の質を上げる」施策だが、証券会社から見ると **引受ビジネスの母数を減らす**。
> ただしMBO・親子上場解消・非上場化の助言という別の案件を生むので、総量では相殺されうる。

## 6. 再編とプラットフォーム化、そして暗号資産の金商法移管

### 6-1. 中堅証券は「自前の店」から「他社のインフラ」へ

| 動き（公表時期） | 内容 | 意味 |
| --- | --- | --- |
| 岡三証券グループ（2026年5月公表） | 子会社の証券ジャパンと岡三ビジネス＆テクノロジーを2026年8月1日に統合し「岡三ビジネス＆テクノロジー証券」を設立。**証券プラットフォーム事業に特化** | 自社でリテールを抱えるより、他社に売買・バックオフィスの基盤を貸す方が収益が安定するという判断 |
| ドコモSMTBネット銀行（旧・住信SBIネット銀行）×マネックス証券（2026年2月） | 金融商品仲介で業務提携。銀行は2026年8月3日に商号変更 | **銀行の顧客基盤を証券が借りる**形。通信キャリアの経済圏が金融に組み込まれる流れ |
| 金融庁の出資規制緩和（2025年11月報道） | 銀行子会社の出資規制を2026年半ばにも緩和し、上場後も一定期間の出資継続を可能にする方向 | 銀行グループがスタートアップの株式を持ち続けられる＝銀証グループの投資業務が広がる |

背景は一貫している。**規模の経済が効く業態では、下位のプレイヤーは「自分で顧客を持つ」より
「上位のインフラの一部になる」方が合理的**になる。IFAプラットフォーム化（→[②-5](02_手数料ゼロ時代.md)）も同じ論理の別形態。

### 6-2. 暗号資産が「証券会社の商品棚」に近づいた

2026年7月15日、**金融商品取引法および資金決済法の改正法が成立**した。暗号資産の規制を資金決済法から
**金商法へ移管** し、有価証券とは別の金融商品として位置づける内容で、インサイダー取引規制・適合性の原則・
情報開示義務・無登録業者への規制強化などを含む。施行は2027年中とみられる。

| 変わること | 証券業への意味 |
| --- | --- |
| 暗号資産が金商法の枠内に入る | 証券会社が扱う際の法的な位置づけが整理される |
| 暗号資産ETFの組成に道が開く（投信法施行令の改正が前提） | 取引所に上場する形の商品になれば、**既存の売買・保管・販売のインフラがそのまま使える** |
| 税制（申告分離課税化）の議論 | 課税方式が株式に近づけば、取扱いのハードルがさらに下がる |

詳細は [暗号資産](../14_暗号資産/README.md) に譲る。証券業から見た論点は「新しい資産クラスが、既存の市場インフラの上に載るかどうか」である。

## 7. 全体の構図（3〜5行まとめ）

1. 2026年は **株高・金利上昇・M&A増加** が重なり、フローとストックが同時に効いた稀な年だった。ただし持続性は相場次第で、構造的な強さとは分けて見る必要がある。
2. 制度は「枠を広げる」段階から **「取り崩しまで面倒を見る」段階** に移った（こどもNISA創設、つみたて枠への債券追加、定期売却の手数料容認、プラチナNISA見送り）。
3. 競争軸は価格からセグメントへ移り、ネット証券も対面証券も **富裕層・準富裕層** という同じ場所で戦い始めた。
4. 口座乗っ取り対策と上場維持基準の厳格化は、どちらも **固定費と参入ハードルを上げる** 方向に働き、上位集中をさらに進めている。
5. 次の論点は **暗号資産の金商法移管（2027年施行見込み）と決済期間T+1** で、いずれも「既存インフラをどこまで使い回せるか」が鍵になる。

| **こどもNISA** | 令和8年度税制改正大綱で創設が決まった未成年向けNISA（大綱上は未成年者特定累積投資勘定）。2027年開始予定、年間60万円・非課税保有限度額600万円 |
| **プラチナNISA** | 高齢者向けに毎月分配型投信などを対象に加える案として検討されたが、令和8年度改正では見送られた構想 |
| **準富裕層** | 一般に金融資産5,000万円〜1億円程度の層を指す区分（定義は調査機関により異なる） |
| **ウェルス・マネジメント** | 富裕層の資産全体（金融資産・不動産・事業・相続）を包括的に扱う業務。対面証券の主戦場 |
| **信用建玉残高** | 信用取引で建てられたポジションの残高。証券会社の金利・貸株料収入の元になる |
| **主幹事証券難民** | IPOを目指すが引受審査のハードルにより主幹事を確保できない企業を指す業界用語 |
| **証券プラットフォーム事業** | 自社ブランドのリテール営業ではなく、他社に売買システムやバックオフィス機能を提供する事業形態 |
