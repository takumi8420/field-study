手数料ゼロ時代

金融証券
あこのページの単語集用語に触れると意味を確認できます12語
委託手数料の自由化ゼロ革命／ゼロコースPFOFSORPTS最良執行義務ラップ口座IFA（金融商品仲介業者）フィーオンリークレカ積立回転売買限界費用

このノートで分かること：日本株の売買手数料がなぜ 無料 になったのか、
無料にした証券会社は代わりに何で稼いでいるのか、そして対面証券はどこへ向かっているのか。

ポイント：手数料ゼロは値下げ競争の終着点ではなく、ビジネスモデルの置き換えである。
「株の売買で稼ぐ会社」から「預かった資産と、そこにぶら下がる金融サービスで稼ぐ会社」への転換。

1. なぜ無料にできたのか：3段階の歴史

【日本の株式売買手数料の歴史】

 〜1998  固定手数料の時代
         │  料率は国が決める。証券会社は価格で競争しない
         ▼
 1999    委託手数料の完全自由化（金融システム改革＝日本版ビッグバン）
         │  同時期にネット証券が相次ぎ誕生
         ▼
 2000年代 ネット証券による価格破壊
         │  対面の数十分の一の手数料。定額プランが登場
         ▼
 2023.9〜 「ゼロ革命」（SBI証券）／「ゼロコース」（楽天証券）
         │  条件付きで日本株の売買手数料が0円に
         ▼
 2026.5  三菱UFJ eスマート証券も国内株式（現物・信用）を無料化
         ▼
 いま    「日本株の売買で手数料を取る」前提が崩れた状態

無料化を可能にした条件は3つある。

条件 中身 なぜ効くか
限界費用がほぼゼロ口座が1件増えても、注文が1本増えても追加コストはほぼ発生しない固定費をどこかで回収できれば、売買自体はタダで提供できる
他の収益源が育った信用取引の金利、外国株の為替、投信の信託報酬、FX株式手数料が全収益に占める比率が十分下がった
口座獲得が資産になる新NISA（2024年〜）で口座開設が一気に増えた局面だった無料化＝広告費。獲得した口座から長く回収する

2. では何で稼ぐのか：ネット証券の収益源マップ

【株式手数料ゼロのネット証券：お金の入り口】

   顧客の口座（預り資産）
        │
        ├─▶ 信用取引 ──────▶ 金利・貸株料        ← 最大級の柱
        │
        ├─▶ 外国株（米国株）─▶ 為替スプレッド＋売買手数料
        │
        ├─▶ 投資信託 ──────▶ 信託報酬の販売会社取り分（ストック）
        │
        ├─▶ FX・CFD ───────▶ スプレッド
        │
        ├─▶ 現金残高 ──────▶ グループ銀行に回して運用（連携口座）
        │
        ├─▶ 貸株サービス ───▶ 借り手（空売り筋）から受け取る貸株料の一部
        │
        └─▶ ポイント・カード積立▶ 経済圏へ送客。グループ全体で回収
収益源 仕組み 性格
信用取引の金利・貸株料買い方から金利、売り方から貸株料を取るフローに近いが残高に比例するので半ストック
外国株の為替スプレッド円↔ドルの両替時に実勢レートに上乗せ。片道25銭などの形取引のたび。無料化の対象外に置かれがち
投信の信託報酬残高×年率のうち販売会社の取り分純粋なストック。各社が最も増やしたい収益
銀行との連携（預金）証券口座の待機資金をグループ銀行の預金として受け入れ、運用に回す金利上昇局面で価値が上がる
FX・先物などのデリバティブスプレッドと手数料値動きが大きい局面で伸びる
ポイント・経済圏への送客ポイント付与で自社経済圏に囲い込む。回収はグループ連結で考える証券単体では費用、グループでは投資

2-1. 注文回送（PFOF）との違い

米国では、証券会社が顧客の注文を特定のマーケットメイカーに回送し、
その対価を受け取る PFOF（Payment for Order Flow、注文回送に対する支払い） が
手数料ゼロの原資になっている。ロビンフッドの収益の柱として知られる。

日本では制度が異なり、PFOFそのものは日本証券業協会の規則で禁止されている。
ただし類似の構造はある。

米国のPFOF 日本のSOR／PTS
仕組み注文をマーケットメイカーへ回送し、対価を受け取るSOR（Smart Order Routing＝複数市場の中で有利な板へ自動で注文を回す仕組み）で、取引所と PTS（私設取引システム）を比較して執行
証券会社の収入回送先からの支払いグループのPTS（例：ジャパンネクストPTS）の取引量が増えることによるグループ内収益、および執行の効率化
規制開示義務あり。禁止はされていない注文回送の対価受領は禁止。ただしSOR利用を無料化の条件にする運用はある
論点最良執行との利益相反同じく最良執行義務との関係が論点。無料コースがSOR必須になっている点への指摘がある

日本の無料化は「PFOFで穴埋め」ではなく、信用金利と投信残高で穴埋めという理解が実態に近い。

3. 規模の経済：なぜ大手ネット証券だけが無料にできるか

【固定費 ÷ 口座数 = 1口座あたりコスト】

  口座数 100万                口座数 1,600万
  ┏━━━━━━━━━━┓             ┏━━━━━━━━━━┓
  ┃ システム固定費 ┃             ┃ システム固定費 ┃  ←ほぼ同じ金額
  ┗━━━━━━━━━━┛             ┗━━━━━━━━━━┛
     ÷ 100万                       ÷ 1,600万
   = 1口座あたり高い              = 1口座あたり極小
     → 手数料を取らないと無理       → 無料でも他の収益で十分回る
  • SBI証券は2026年5月に証券総合口座 1,600万口座 到達を発表（SBIホールディングス公表、2026年）
  • 楽天証券は2026年4月に証券単体で 1,400万口座 突破を発表（楽天グループ公表、2026年）
  • 上位2社に口座が集中した結果、中堅ネット証券は無料化に追随しづらい構造になっている

2026年3月期は主要ネット証券5社の合計純利益が前期比24%増の992億円と報じられ
（日本経済新聞、2026年）、営業利益率は松井証券26.7%、楽天証券24.8%といった水準が集計されている
（各社開示をもとにした集計。定義は会社ごとに異なる）。
手数料をゼロにしても利益率は高い——ここが無料化の本質を示している。

4. 対面証券はどうするのか

手数料ゼロは、対面証券にとって「同じ土俵で戦えなくなった」ことを意味する。
そこで各社が取ったのは 土俵を変える 戦略である。

方向 中身 収益の取り方
富裕層・準富裕層へ集中金融資産1億円以上の層に営業資源を寄せる。相続・事業承継・不動産まで含めて提案預り資産に比例するストック収益
ラップ口座投資判断を丸ごと任せる契約。残高に対し年率1〜1.5%程度の報酬純粋なストック。相場に関係なく入る
オーナー経営者の周辺業務自社株対策、事業承継、M&Aの紹介ホールセール部門との連携で手数料
銀証連携銀行の法人・個人基盤から紹介を受けるグループ全体で回収
コンサルティング型への転換回転売買（頻繁に乗り換えさせて手数料を取る）からの脱却顧客本位の業務運営（→③）が制度的な追い風
【対面とネットのポジショニング】

          高い ┃                 ● 対面総合証券（野村・大和・銀行系）
               ┃                   富裕層・相続・事業承継まで面倒を見る
  1顧客あたり  ┃         ● IFA
  のサービス量 ┃           独立系。中立性を売りにする
               ┃  ● ネット証券
          低い ┃    セルフサービス。単価は低いが口座数が桁違い

                少ない              顧客数              多い

5. IFA：独立系ファイナンシャルアドバイザー

IFA（Independent Financial Advisor、法令上は 金融商品仲介業者）は、
証券会社に雇われず、業務委託の形で証券会社の商品を仲介する事業者。

論点 中身
立ち位置特定の会社のノルマに縛られないため、転勤がなく長期で同じ担当者が付くことが売り
収益顧客が払う手数料を、委託元の証券会社とIFAで分け合う
規模楽天証券のIFA経由の顧客預り資産は 2.5兆円（楽天証券2025年12月期決算説明資料）。業界全体では数兆円規模とされる
委託元楽天証券、SBI証券、あかつき証券、岡三系など。ネット証券がプラットフォームを提供する構図
課題中立をうたっても 手数料の高い商品を勧める誘因 は残る。金融庁は開示と最善利益義務で対応

日本では金融審議会でもIFAの育成が論点になっており、
「特定の金融機関に縛られない助言者」を増やす方向で制度が整理されてきている。
一方で、助言だけで料金を取る（フィーオンリー）モデルは日本ではまだ小さい。

6. 無料化が生んだ副作用

副作用 何が起きているか
収益の集中信用取引・外国株・投信に依存。この3つが細ると一気に苦しくなる
価格以外の競争軸の消失手数料で差が付かない分、ポイント還元・アプリの使い勝手・取扱商品数での競争になる
ポイント原資の負担クレカ積立のポイント付与はグループの持ち出し。還元率の引き下げ合戦が起きやすい
セキュリティコストの増大口座数が増えるほど不正アクセスの標的になる（→④ 直近トピック）
中堅証券の淘汰圧力規模の経済で勝てない層が、IFAプラットフォーム化や統合を迫られる

7. まとめ

  1. 手数料ゼロは 限界費用ゼロ＋他の収益源の成熟＋NISAによる口座急増 が重なって成立した
  2. 代わりの収益は 信用取引の金利・外国株の為替・投信の信託報酬・経済圏への送客
  3. 米国型のPFOFは日本では禁止。ただし SORとPTS をめぐる似た論点はある
  4. 対面証券は価格競争から降りて、富裕層・ラップ・事業承継というストック型に移った
  5. 無料化の勝者は 口座数上位のネット証券とグループ経済圏。中堅には構造的な逆風
