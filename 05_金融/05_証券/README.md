# 証券

- 大分類: 金融
- 状態: done
- 更新日: 2026-09-20

投資家のお金と、資金を必要とする企業・国とのあいだに立ち、**お金が動いた瞬間に手数料を取る**業界。
銀行が「預かって貸す（利ざや）」のに対し、証券は「つなぐ（手数料）」と「自分で張る（トレーディング）」で稼ぐ。
だから **相場が動くかどうかで業績が跳ねる**。ここが銀行・保険との最大の違いになる。

## 1. 業界の定義・範囲

法律上は **第一種金融商品取引業**（内閣総理大臣の登録が必要）を営む会社が中核。
やっていることは大きく4つで、この4つの組み合わせが会社の性格を決める。

```
【証券会社の4業務】

  ① 委託売買（ブローカー）   顧客の注文を市場へ取り次ぐ。手数料
  ② 自己売買（ディーラー）   自分のお金で売買する。差益と評価損益
  ③ 引受（アンダーライター） 発行される株・債券を買い取って売りさばく。引受手数料
  ④ 募集・売出しの取扱い     発行体に代わって投資家を募る

  ①②③④ をフルで持つ = 総合証券　　①④中心 = ネット証券・仲介中心の会社
```

| 隣接業界 | 境界線 |
| --- | --- |
| [銀行](../01_メガバンク/README.md) | 銀行は預金を集めて貸す（利ざや）。証券は売買・発行を仲介する（手数料）。同一グループでも免許は別で、[銀証ファイアウォール規制](03_市場インフラと規制.md)がかかる |
| [資産運用](../06_資産運用/README.md) | 運用会社は商品を「作って運用する」、証券会社は「売る・売買を取り次ぐ」。信託報酬を分け合う関係 |
| [信託銀行](../03_信託銀行/README.md) | 信託銀行は資産の保管・管理（カストディ）と年金運用が中心 |
| [暗号資産](../14_暗号資産/README.md) | 従来は資金決済法の世界だったが、2026年7月成立の改正で**金商法へ移管**（2027年施行見込み）。境界が溶けつつある |

**含まれないもの**：投資助言・代理業のみの会社（第二種・投資助言業）、FX専業業者、取引所そのもの（JPXは市場運営者）。

## 2. 市場規模と成長性

| 指標 | 数値 | 出典・年 |
| --- | --- | --- |
| 協会員259社の営業収益合計 | 6兆905億円（前年度比12%増）、純利益合計8,024億円 | 日本証券業協会統計、2024年度 |
| 主要証券10社の当期純利益合計 | 1兆4,207億円（前期比45%増） | 報道ベース、2026年3月期 |
| 主要ネット証券5社の純利益合計 | 992億円（前期比24%増） | 報道ベース、2026年3月期 |
| 家計金融資産 | 約2,200兆円。うち現預金が半分超 | 日銀 資金循環統計ベース |
| NISA累計買付額／口座数 | 約71兆円（前年比36%増）／約2,826万口座 | 金融庁調査、2025年12月末時点 |

成長性の見方は2段構え。**短期は相場サイクル**（株価・金利・M&A件数で上下する）、
**中長期は家計金融資産のシフト**（現預金→投資）。後者が政府の「資産運用立国」方針の中身であり、
証券業にとって構造的な追い風になっている。ただし新NISAの中心は低コストのインデックス投信で、
**残高は増えるが料率は低い＝薄利多売**という副作用がある（→[③-5](03_市場インフラと規制.md)）。

## 3. バリューチェーン（川上 → 川下）

```
【資金の流れと、証券会社の立ち位置】

 川上：資金の出し手            中間：値段がつく場所         川下：資金の受け手
 ┌──────────┐    ┌─────────────┐    ┌──────────┐
 │ 個人・家計      │    │ 取引所（東証）    │    │ 企業（IPO・増資）│
 │ 年金・機関投資家 │──▶│ PTS（私設取引）   │◀──│ 国・自治体（国債）│
 │ 海外投資家      │    │ 店頭（債券・OTC） │    │ ファンド・SPC    │
 └──────────┘    └─────────────┘    └──────────┘
        ▲                      │                        ▲
        │                      ▼                        │
   販売・助言              清算 JSCC → 振替 JASDEC       引受・M&A助言
   （リテール部門）         （決済インフラ。→③）        （ホールセール部門）

 付加価値が集まる場所：
   ・川下側＝「値付けと売りさばき」の力（主幹事の座）→ 引受手数料・アドバイザリー料
   ・川上側＝「預り資産を抱え続ける」力（口座と信頼）→ 信託報酬・信用金利・ラップ報酬
```

## 4. 主要プレイヤーとシェア

| 類型 | 企業 | 立ち位置・特徴 |
| --- | --- | --- |
| 総合証券 | 野村ホールディングス | 国内最大手。海外ホールセールを持つ。個人部門は「ウェルス・マネジメント部門」に改称し富裕層に集中 |
| 総合証券 | 大和証券グループ本社 | 銀行を持たない独立系総合証券。ウェルスマネジメントとM&Aが柱 |
| 銀行系 | みずほ証券／SMBC日興証券／三菱UFJモルガン・スタンレー証券 | 銀行の法人基盤を使った引受・M&Aが強い。IPO引受実績の上位を占める |
| ネット証券 | SBI証券 | 2026年5月に証券総合口座1,600万口座。国内株の信用建玉残高3兆円に到達 |
| ネット証券 | 楽天証券 | 2026年4月に1,400万口座。楽天経済圏との連携が武器 |
| ネット証券 | マネックス証券／松井証券／三菱UFJ eスマート証券 | 米国株、独自サービス、通信・銀行グループ連携などで差別化 |
| 中堅・地場 | 岡三証券グループ、東海東京フィナンシャル、丸三証券など | 規模の経済が効かず、プラットフォーム提供やIFA連携へ転換が進む |
| 外資系 | ゴールドマン・サックス、モルガン・スタンレー、JPモルガンなど | ホールセール特化。引受・M&A・トレーディングで高収益 |

「シェア」は業務ごとに見る必要がある。**個人の口座数はネット証券に集中**し、
**引受・M&Aは大手・銀行系・外資に集中**する。同じ「証券会社」でも戦っている市場が違う。

## 5. 収益モデル・コスト構造

- 収益は **フロー**（売買・販売のたび）と **ストック**（預り資産の残高に比例）に分かれる。全社が後者を厚くしようとしている
- 日本株の売買手数料は実質ゼロ化したため、ネット証券の柱は **信用取引の金利・貸株料、外国株の為替スプレッド、投信の信託報酬**
- ホールセールは **引受手数料・M&Aアドバイザリー料・トレーディング損益**。案件次第で振れるが利益率が高い
- コストは対面＝**人件費**（営業員1人あたりの預り資産で採算が決まる労働集約型）、ネット＝**システム費**（固定費を口座数で割る装置産業型）
- どちらも固定費が重く、**相場の谷で赤字になりやすい**。2025年以降はセキュリティ対策費が恒久的な固定費として上積みされた

詳細は [① 証券会社は何で稼ぐか](01_証券会社は何で稼ぐか.md) と [② 手数料ゼロ時代](02_手数料ゼロ時代.md)。

## 6. 競争要因（KSF）と参入障壁

| 要因 | 中身 |
| --- | --- |
| **規模の経済** | システム固定費÷口座数。口座数上位でなければ手数料無料化に追随できない |
| **預り資産の厚み** | ストック収益はほぼ「預り資産×料率」。相場に左右されない収益基盤になる |
| **引受実績と信用** | 主幹事の座は過去の実績が呼ぶ。新規参入が最も難しい領域 |
| **免許と体制** | 第一種金融商品取引業の登録、自己資本規制比率、分別管理、コンプライアンス人材 |
| **グループの顧客基盤** | 銀行・通信キャリア・EC経済圏からの送客。単独では獲得コストが見合わない |
| **不祥事を起こさないこと** | 信用が商品なので、1件の事件が業務停止・顧客流出・制度変更に直結する |

## 7. 規制・法制度

中心は **金融商品取引法**（2007年施行）。骨格は、登録制／自己資本規制比率（120%未満で改善命令、100%未満で業務停止対象）／
顧客資産の分別管理と投資者保護基金／適合性の原則・断定的判断の禁止／最良執行義務／
インサイダー取引・相場操縦の禁止／銀証ファイアウォール規制。

2024年11月には **顧客の最善の利益を勘案した誠実公正義務が法定化** され、
原則（プリンシプル）だったものが法的義務へ格上げされた。詳細は [③ 市場インフラと規制](03_市場インフラと規制.md)。
