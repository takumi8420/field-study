証券会社は何で稼ぐか

金融証券
あこのページの単語集用語に触れると意味を確認できます16語
主幹事委託手数料（ブローカレッジ）自己勘定（ディーリング）引受（アンダーライティング）ブックビルディングM&AアドバイザリーFICCマーケットメイクスプレッド預り資産資金純増（ネットフロー）フロー収益／ストック収益信託報酬信用取引逆日歩（品貸料）分別管理

このノートで分かること：証券会社の収益を リテール（個人向け） と ホールセール（法人・機関投資家向け） に分け、
「誰のお金を、どう動かして、どこで手数料や差益を取っているか」を一本の線でたどる。

ポイント：銀行が 利ざや（集めた預金と貸出金利の差）で稼ぐのに対し、
証券会社は基本的に 他人のお金が動いた瞬間に手数料を取る 商売。
だから「市場が動くかどうか」で業績が跳ねる。これが銀行との最大の違い。

1. まず全体像：お金と手数料の流れ

証券会社は、お金の出し手（投資家）と、お金の受け手（企業・国）のあいだに立つ。
立つ位置によってリテールとホールセールに分かれる。

【資金の流れ】                              【証券会社の稼ぎ方】

  個人・家計                     企業・国
  （お金の出し手）               （お金の受け手）
      │                              ▲
      │ 買う・売る                   │ 資金を調達する
      ▼                              │
 ┌──────────────┐   ┌─────────────────┐
 │  リテール部門   │   │   ホールセール部門       │
 │  ・委託手数料   │   │   ・引受手数料（IPO/社債）│
 │  ・投信販売手数料│  │   ・M&Aアドバイザリー料   │
 │  ・信託報酬の分配│  │   ・トレーディング損益     │
 │  ・信用取引の金利│  │   ・機関投資家向け委託手数料│
 └──────────────┘   └─────────────────┘
      │                              │
      └────────▶ 取引所・店頭市場 ◀───┘
                （値段が付く場所。詳細は ③市場インフラと規制）

証券会社が「自分のお金」を使うか「客のお金」を使うかでも性格が変わる。ここは必ず区別する。

区分 誰のお金でリスクを取るか 収益の出方 代表的な業務
受託（ブローカー、委託売買）客のお金。会社は仲介するだけ手数料。売買が成立すれば確実に入る株式の委託売買、投資信託の販売
自己勘定（ディーラー、principal）会社自身のお金。損益が直撃する売買の差益・評価損益。読み違えれば赤字債券トレーディング、マーケットメイク
引受（アンダーライティング）いったん会社が買い取るので会社のお金引受手数料。売れ残れば在庫リスクIPO、公募増資、社債の発行

「証券会社が儲かった」というニュースを見たら、まず 受託で稼いだのか、自己勘定で稼いだのか を確かめる。
前者は市場の活況、後者は相場観の当たり外れを意味する。持続性がまったく違う。

2. リテール部門：個人から取る3種類のお金

2-1. 委託手数料（ブローカレッジ）

投資家の注文を取引所に取り次いだ対価。約定代金の何% という形が伝統的だった。
1999年の株式売買委託手数料の完全自由化まで、日本では手数料率が固定されていた。
自由化後にネット証券が価格破壊を起こし、2023年以降は日本株が実質無料という段階に入っている
（→ ② 手数料ゼロ時代）。

2-2. 投資信託の販売手数料と信託報酬

投資信託（多数の投資家から集めた資金をまとめて運用する商品）には2種類の手数料がある。
ここが「フロー収益」と「ストック収益」の分かれ目なので、証券業を理解する上で最重要。

種類 誰が払うか いつ発生するか 証券会社にとって
販売手数料（フロント手数料）買った人買った時に1回だけ。上限3%前後が一般的フロー収益。売らないと入らない
信託報酬（運用管理費用）保有している間ずっと年率で日割り計上。販売会社・運用会社・信託銀行で分け合うストック収益。残高がある限り毎日入る
【フロー収益とストック収益】

 フロー型（売買・販売のたび）        ストック型（残高に比例）
  ┃                                  ┃
  ┃  ██      ██                      ┃ ▁▂▃▄▅▆▇█
  ┃  ██  ██  ██   ██                 ┃ ▁▂▃▄▅▆▇█
  ┗━━━━━━━━━━━━━━━▶ 時間        ┗━━━━━━━━━━━━━━━▶ 時間
   相場が止まると一気にゼロ          相場が静かでも積み上がる
   （委託手数料・販売手数料）        （信託報酬・ラップ報酬・貸株料）

2000年代以降の日本のリテール証券は「フロー依存から脱却してストックを厚くする」ことを
ほぼ全社が掲げている。理由は単純で、フロー依存だと相場の谷で赤字になるから。
そのために各社が使う指標が次の「預り資産」である。

2-3. 預り資産という指標

預り資産＝顧客が証券会社に預けている株式・投信・債券などの時価合計。
銀行でいう預金残高に近いが、意味は違う。

  • 銀行の預金は 負債（返す義務のあるお金）。証券の預り資産は原則 顧客のもの（分別管理され、会社の資産ではない）
  • それでも証券会社が預り資産を最重要KPIにするのは、ストック収益がほぼ預り資産×料率で決まるから
  • 弱点：株価が上がるだけで預り資産は増える。営業努力と相場上昇が混ざるので、
    各社は「純増（＝資金の流入額から流出額を引いたもの）」を併記する
 ストック収益 ≒ 預り資産 × 料率（信託報酬の取り分・ラップ報酬など）
                    ▲
                    ├─ 相場が上がる（努力と無関係）
                    └─ 資金純増（営業の実力。ここを各社は開示したがる）

2-4. 信用取引

信用取引＝証券会社からお金または株券を借りて売買する仕組み。
自己資金の約3.3倍まで売買できるかわりに、借りた対価を払う。

種類 何を借りるか 投資家が払うもの 証券会社の収益
信用買い買い付け資金金利（年2〜3%程度が目安、2026年時点の各社公表水準）金利収入
信用売り（空売り）株券貸株料＋品貸料（逆日歩）貸株料収入

信用取引は日本株の売買代金の相当部分を占めるため、売買手数料を無料にしても
信用の金利で回収できる構造が成り立つ。ネット証券の収益モデルの中核である。

3. ホールセール部門：企業と機関投資家から取るお金

3-1. 引受（アンダーライティング）

企業が株式や社債を発行して資金を集めるとき、証券会社がいったん 買い取って投資家に売りさばく。
「売れ残ったら証券会社が抱える」という約束（買取引受）なので、単なる仲介ではなくリスクを取る業務。

【IPO（新規株式公開）の流れと証券会社の役割】

 企業「上場したい」
   │
   ▼
 主幹事証券の選定 ──▶ 引受審査（この会社を投資家に売って大丈夫か）
   │                    ▲ ここが証券会社の信用そのもの
   ▼
 上場申請 ──▶ 取引所・財務局の審査 ──▶ 承認
   │
   ▼
 仮条件決定 ──▶ ブックビルディング（投資家の需要を積み上げて値段を決める）
   │
   ▼
 公開価格決定 ──▶ 買取引受 ──▶ 投資家へ販売 ──▶ 上場初日の値付け
                     ▲ 売れ残りリスクは証券会社が負う
  • 主幹事：案件を取り仕切る証券会社。引受手数料の取り分が最も大きく、実績が次の案件を呼ぶ
  • 引受手数料は、投資家に売る価格と企業から引き受ける価格の差（スプレッド）として取るのが一般的
  • 2020年〜2026年の累計IPO引受実績はみずほ証券130社、SMBC日興証券127社、野村證券116社と集計されている
    （96ut.com 集計、2026年時点。集計主体により数値は異なる）

3-2. M&Aアドバイザリー

企業の買収・合併を助言し、成功報酬を取る。取引金額に応じた料率（レーマン方式が代表的）で、
大型案件になるほど絶対額が大きい。人件費以外のコストがほとんどかからないため、
利益率が非常に高い一方、案件の有無で収益が大きく振れる。
日本では政策保有株の解消、事業ポートフォリオの見直し、PEファンドの参入拡大を背景に、
2025〜2026年にかけて案件が積み上がっていると報じられている。

3-3. トレーディング（自己勘定）

債券・為替・株式・デリバティブを自ら売買して差益を狙う、あるいは
顧客の注文の相手方になって（マーケットメイク）ビッド・アスクの差（スプレッド）を取る。

  • 日本の大手証券では FICC（Fixed Income＝債券、Currencies＝為替、Commodities＝商品）が中核
  • 金利が動く局面ほど債券の売買が増えるため、日銀の金融政策が直接業績に効く
  • リスクを取る業務なので、自己資本規制の対象になる（→ ③ 市場インフラと規制）

4. 収益構成を横に並べて見る

プレイヤー類型 主な収益源 収益の性格 弱点
総合証券（野村、大和）引受・M&A・トレーディング＋リテールホールセール比率が高く、案件次第で振れる固定費（人件費・海外拠点）が重い
銀行系証券（大和を除く、みずほ・SMBC日興・三菱UFJモルガン・スタンレー）銀行の法人基盤を使った引受・M&A、富裕層グループの顧客基盤が強み銀証ファイアウォール規制の制約
ネット証券（SBI、楽天、松井、マネックス、三菱UFJ eスマート）信用金利、外国株の為替差、投信の信託報酬、FX低コストで薄く広く。口座数が資産手数料無料化で株式売買そのものは稼げない
中堅・地場証券対面のリテール、地域の法人顧客との関係性規模の経済が効かず構造的に苦しい
外資系証券ホールセール特化（引受・M&A・トレーディング）高収益・高報酬景気後退時の人員削減が激しい

2026年3月期は主要証券10社の当期純利益合計が前期比45%増の1兆4,207億円で、
野村ホールディングスと大和証券グループ本社が過去最高益を更新したと報じられている
（ニッキンONLINE、2026年）。株高とM&A増加が背景で、フローもストックも同時に効いた年だった。
なお主要ネット証券5社の合計純利益は前期比24%増の992億円（日本経済新聞、2026年）で、
規模としては大手証券の側が依然として圧倒的に大きい。

 人件費         ████████ 約4〜5割   人件費        ███ 
 店舗・不動産   ███                 システム・通信 ██████ ←最大費目
 システム       ███                 広告・獲得費   ████
 取引関係費     ██                  取引関係費     ███
 その他         ██                  その他         ██
   ▲ 営業員1人あたりの預り資産で      ▲ 口座が1つ増えても追加費用はほぼゼロ。
     採算が決まる労働集約型            だから口座獲得競争になる（規模の経済）
  • 対面証券は労働集約。営業員の生産性（1人あたり預り資産・収益）が経営指標
  • ネット証券は装置産業に近い。固定費を口座数で割るので、規模が大きいほど有利
  • どちらも売上が落ちても費用はすぐ下がらない。相場の谷で赤字になりやすいのはこのため

6. 他業態との違いを1枚で

業態 主な収益源 リスクの取り方 代表的な指標
銀行利ざや（貸出金利−預金金利）＋役務収益信用リスク（貸し倒れ）利ざや、自己資本比率、不良債権比率
証券（本ノート）手数料＋売買差益市場リスク・引受リスク預り資産、フロー／ストック比率
資産運用信託報酬（残高×料率）運用成績の評判リスク運用資産残高（AUM）
生命保険保険料と支払の差＋運用収益保険引受リスク新契約年換算保険料、ソルベンシー

証券・運用・銀行は境界が溶けつつある。証券会社が投信を売り、銀行が投信を売り、
運用会社が直販する。「どの免許で何をやっているか」で切り分けるのが実務的な理解の仕方。

7. まとめ

  1. 証券会社の収益は フロー（売買・販売のたび） と ストック（残高に比例） に分かれる
  2. リテールは手数料無料化でフローが消え、信用金利・投信の信託報酬・預り資産が主戦場になった
  3. ホールセールは 引受・M&A・トレーディング。案件次第で振れるが、当たると利益率が高い
  4. 自己勘定か受託かを見分けると、その利益の持続性が判断できる
  5. コストは対面＝人件費、ネット＝システム。どちらも固定費なので相場の谷に弱い
