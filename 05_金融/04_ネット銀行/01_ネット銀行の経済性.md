# ネット銀行の経済性 ― 店舗と人がないという一点で決まる

このノートで分かること：ネット銀行の強さは新技術ではなく、**「経費率（OHR）が圧倒的に低い」という一点**から来ている。
その差がどこで生まれ、どう預金金利と貸出金利に還元され、なぜ住宅ローンが主戦場になるのかを分解する。

> ポイント：ネット銀行は「便利な銀行」ではなく、**同じ商品をより安い原価で作れる銀行**である。
> 原価が安いから高い預金金利を払え、安い貸出金利を出せる。順番はこの向きで理解する。

## 1. まず銀行の儲け方を1分で復習する

銀行の本業収益は2つしかない。

| 収益 | 中身 | 決まり方 |
| --- | --- | --- |
| **資金利益**（利ざや） | 預金者に払う金利と、貸出先から取る金利の差 | 貸出金利 − 預金金利 − 経費 |
| **役務取引等収益**（手数料） | 振込・ATM・為替・投信販売・デビットカード・保証料など | 件数 × 単価 |

ここに**営業経費**（人件費・店舗家賃・システム費）が引かれ、さらに**与信費用**（貸倒れ引当）が引かれて利益になる。

```
【銀行の損益のかたち（簡略）】

  貸出金利息 ＋ 有価証券利息 ＋ 手数料      ← 業務粗利益
        −  預金利息など（調達コスト）
        −  営業経費（人件費・物件費・税金）  ← ここの大小が OHR
        −  与信費用（貸倒れ）
        ＝  利益
                ▲
        ネット銀行が効かせているのは、ほぼこの1行だけ
```

**OHR**（Overhead Ratio、経費率）＝ 営業経費 ÷ 業務粗利益。
噛み砕くと「**100円の粗利を稼ぐのに何円の経費をかけたか**」。低いほど効率が良い。

## 2. OHRの実数：ネット銀行は既存金融機関より約10ポイント低い

信金中央金庫 地域・中小企業研究所の分析（2023年3月期ベース、2024年1月公表）によれば、

| 区分 | OHR | 注 |
| --- | --- | --- |
| 信用金庫 平均 | **78.4%** | 全信用金庫の加重平均 |
| ネット銀行等 加重平均 | **68.8%** | ネット専業＋流通系12行ベース |
| 楽天銀行 | **45.8%** | ネット銀行等のなかでも最上位 |
| 住信SBIネット銀行（現・ドコモSMTBネット銀行） | **50.0%** | 同上 |

- 大手行のOHRはおおむね60%前後、地域銀行は70%前後というのが近年の相場観（各行開示ベース）。
- つまり**上位ネット銀行は「粗利の半分」で運営できている**。ここが本質。
- 数値は2023年3月期時点。金利上昇で粗利が膨らむと分母が増えてOHRは下がりやすいので、**最新は各行の決算短信で確認**。

## 3. なぜ低いのか ― 経費の中身が違う

同じ研究所の分析では、営業経費の内訳（人件費率・物件費率・税金率）が既存金融機関とまるで違う。

| 区分 | 人件費の割合 | 物件費の割合 |
| --- | --- | --- |
| 信用金庫 加重平均 | **約61.5%** | 残り（3割台） |
| ネット銀行等（最も人件費率が高いイオン銀行でも） | **約27%** | 6割超 |
| ローソン銀行・セブン銀行 | ごく小さい | **営業経費の約9割が物件費** |

読み方はこうなる。

```
【同じ「預金を集めて貸す」でも、原価の置き場所が違う】

 既存銀行          ネット銀行
 ┌──────────┐      ┌──────────┐
 │ 支店 500〜  │      │ 支店 0〜数店 │
 │ 行員 数万人 │  →   │ 行員 数百人  │
 │ 現金・通帳  │      │ システム／  │
 │ 窓口・警備  │      │ クラウド費  │
 └──────────┘      └──────────┘
   人件費が主役          物件費（＝IT）が主役
   ＝ 顧客が増えると      ＝ 顧客が増えても
      人も増える            コストはあまり増えない
```

> ポイント：既存銀行のコストは**顧客数にほぼ比例して増える**（人と窓口が要る）。
> ネット銀行のコストは**システムという固定費**なので、口座が増えるほど1口座あたりが薄まる。
> 同じ「経費が安い」でも、**逓減するかどうか**が決定的に違う。

### 口座あたりコストのイメージ（推計・オーダー感）

正確な開示はないが、公表数字からの**粗い推計**として桁感だけ押さえておく。

| | 既存の大手・地域銀行 | 上位ネット銀行 |
| --- | --- | --- |
| 1口座あたり年間の運営コスト | 数千円規模とされる（維持手数料議論の根拠） | その数分の1に収まるとみられる |
| 口座が2倍になったときのコスト | 人・店舗が必要なので大きく増える | システム増強分のみで**ほぼ横ばい** |

※これは開示値ではなく**推計**。「絶対額」ではなく「増え方の違い」だけを覚えればよい。

## 4. 安い原価が、そのまま金利に化ける

経費が浮けば、その分を**預金者と借り手に配れる**。これがネット銀行の顧客価値の正体。

```
【原価差の配り方】

           既存銀行                   ネット銀行
 貸出金利  ━━━━━━━━━━━━━━━     ━━━━━━━━━━━  （低くできる＝住宅ローンで勝つ）
             │  経費が厚い  │         │ 経費 薄 │
 預金金利  ━━━━━━                ━━━━━━━━━     （高くできる＝預金が集まる）
             ↑ 利ざやの中身が経費に食われる   ↑ 同じ利ざやでも配れる幅が広い
```

2026年9月時点の状況で言えば、日銀の政策金利引き上げを受けてメガバンクの普通預金も年0.40%まで上がり、
「ネット銀行だけが金利を付ける」時代ではなくなった。それでも**定期・条件付き普通預金の上乗せ幅**では
ネット銀行・新形態銀行が優位に立ちやすい（例：あおぞら銀行の定期が年1.60%との比較報道、2026年9月時点）。

## 5. 住宅ローンが主戦場になる理由

ネット銀行の貸出はほとんどが住宅ローンに寄っている。偶然ではなく、**ネットの経済性と最も相性が良い商品**だから。

| 住宅ローンの性質 | ネット銀行にとっての意味 |
| --- | --- |
| 不動産担保があり、貸倒れ率が低い | 対面で人物を見なくても与信できる＝**人を置かなくてよい** |
| 1件が数千万円と大口 | 1件あたりの獲得コストを吸収できる |
| 期間20〜35年と長い | 一度取れば長く利息が入る＝**LTVが極端に長い** |
| 商品性が横並びで比較されやすい | **金利0.01%の差で選ばれる**＝原価が安い側が勝つ |
| 申込〜審査〜契約を電子化しやすい | 電子契約なら印紙税も不要 |

結果として、住宅ローンは「**原価の安さがそのまま勝敗になる商品**」になった。
2026年3月期時点で、au じぶん銀行の貸出金は**6兆3,497億円**、ソニー銀行の貸出金は**3兆5,981億円**（各行決算短信）で、
いずれも大半が住宅ローンとされる。地方銀行1行に匹敵する規模を、支店なしで積んでいる。

ただし2026年は**変動金利の引き上げ局面**でもある。2026年9月にはドコモSMTBネット銀行が年0.200%、
楽天銀行が年0.014%、三菱UFJ・三井住友が各年0.250%の引き上げを実施したと報じられている。
借り手の負担が増える局面で、**金利の低さだけでは差別化しにくくなる**（団信の手厚さ、手数料体系、審査スピードに競争軸が移る）。

## 6. 損益構造の比較 ― 同じ銀行でも形が違う

| 項目 | メガバンク | 地方銀行 | ネット専業銀行 | 流通系（セブン銀行など） |
| --- | --- | --- | --- | --- |
| 主な収益源 | 利ざや＋大型手数料（M&A・外為・信託） | 利ざや中心 | 利ざや＋決済・為替・デビット手数料 | **ATM受入手数料がほぼすべて** |
| 貸出の中身 | 大企業・海外・不動産 | 中小企業・地元事業者 | **住宅ローンに集中** | 貸出はごく小さい（預貸率5%未満） |
| 経費の主役 | 人件費 | 人件費 | 物件費（IT） | 物件費（ATM機・設置・現金輸送） |
| OHR感 | 60%前後 | 70%前後 | **45〜70%** | 業態特有（ATM原価が物件費） |
| 顧客接点 | 支店・法人営業 | 支店・渉外 | アプリ・Web | コンビニ店頭のATM |
| 増えるときのコスト | 比例して増える | 比例して増える | **あまり増えない** | ATM台数に比例して増える |

> 同じ「銀行」でも、**セブン銀行は事実上ATMという装置産業**であり、
> 利ざやを稼ぐネット専業銀行とは別の生き物。詳しくは [② 各社の出自と戦略の違い](02_各社の出自と戦略の違い.md)。

## 7. 弱点も同じ構造から生まれる

安い原価は強みだが、裏返しの弱点もセットで付いてくる。

1. **預金が粘着しない**。支店も担当者もいない分、顧客は金利だけで動く。金利競争が始まると調達コストが一気に上がる。
2. **調達コストの上昇が先に効く**。変動金利の住宅ローンは基準金利改定に時間差があるのに、預金金利はすぐ上がる。
   実際、au じぶん銀行の2026年3月期は経常収益が1,265億円へ増えた一方で**業務粗利益は427億円へ減り、
   当期純利益は46.1億円（前期比68.5%減）**となった（同行決算短信、時事通信）。金利上昇は自動的な追い風ではない。
3. **自前ATMがない**。他行・コンビニATMに手数料を払う側なので、無料回数を増やすほどコストが出ていく。
4. **法人取引が薄い**。当座貸越や手形、事業性融資の目利きは人がいないとやりにくい（→ここを狙うのがGMOあおぞらネット銀行）。
5. **不正送金・フィッシングの標的**になりやすい。対策コストは全行に等しくかかり、**規模の小さい行ほど重い**
   （→ [③ BaaSと今後](03_BaaSと今後.md)）。

## 8. まとめ：覚える式はひとつ

```
 ネット銀行の強さ ＝ （粗利 − 経費）を、経費側を削って作る
                          ↑
      店舗ゼロ・人員数百人・システムは固定費 → 口座が増えるほど薄まる
                          ↓
      浮いた分を 預金金利↑ と 住宅ローン金利↓ に配る → 顧客が来る → さらに薄まる
                          ↑
            この循環が止まるのは「調達コストが急に上がるとき」
```

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **OHR（経費率）** | 営業経費 ÷ 業務粗利益。100円の粗利を稼ぐのに何円かけたか。低いほど効率的 |
| **業務粗利益** | 銀行の「売上総利益」にあたる。資金利益＋役務取引等収益＋その他業務利益 |
| **資金利益（利ざや）** | 貸出・運用で得た利息 − 預金などに払った利息 |
| **役務取引等収益** | 手数料収入。振込・為替・ATM・投信販売・デビット関連など |
| **預貸率** | 貸出金 ÷ 預金。高いほど預金を貸出に回している。ネット専業は80%超、流通系は5%未満と両極 |
| **与信費用** | 貸倒れに備えて積む引当金などのコスト |
| **調達コスト** | 預金金利や市場調達の利息。銀行にとっての「仕入れ値」 |
| **団信（団体信用生命保険）** | 住宅ローン返済中に契約者が死亡等した際にローンが消える保険。ネット銀行の差別化ポイント |
