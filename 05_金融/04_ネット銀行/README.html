1. 業界の定義・範囲

ネット銀行とは、実店舗（支店網）をほとんど持たず、インターネットとアプリを主な顧客接点とする銀行の総称。
法令上の正式な業態区分ではなく、金融庁の分類では多くが 「新たな形態の銀行等」（新形態銀行）に含まれる。

境界の引き方は次のとおり。

【「銀行免許を持つか」「店を持つか」の2軸で置く】

          店舗あり ◀──────────────────────▶ 店舗なし
  銀行     ┌───────────────┬───────────────┐
  免許     │ メガバンク       │ 楽天銀行／PayPay銀行 │
  あり     │ 地方銀行・信託    │ ドコモSMTB／ソニー   │  ← このフォルダの主役
           │                  │ セブン銀行（ATMは有） │
           ├───────────────┼───────────────┤
  免許     │ 信販・消費者金融   │ 資金移動業（○○ペイ） │
  なし     │ の店舗            │ 前払式支払手段        │  ← 預金も貸出もできない
           └───────────────┴───────────────┘
隣接する業態 違い
メガバンク・地方銀行支店網と法人営業を持つ。人件費が経費の主役。ネット専用支店を持っていても本体は店舗型
ネット証券（証券）預金を受け入れない。ネット銀行はスイープでここと直結している
フィンテック・キャッシュレス の決済事業者銀行免許を持たない（資金移動業・前払式支払手段）。預金と貸出はできない
流通系銀行（セブン銀行・ローソン銀行）「ネット銀行」と一括りにされがちだが、収益の柱はATM手数料で別の生き物（→ ②）

銀行業全体の市場を測る統一指標はないので、口座数と預金残高で規模感を押さえる。

 預金者（個人・法人）
   │ 預金（＝調達）    金利＋ポイントで集める ← ここが年々高くつくようになった
   ▼
 ネット銀行  ── 経費（ほぼシステムの固定費）──▶ 小さい ＝ 強さの源
   │
   ├─▶ 住宅ローン（貸出の主力・長期・低リスク）────▶ 利ざや
   ├─▶ 有価証券運用 ───────────────────▶ 利息
   ├─▶ 決済・為替・デビット・ATM ───────────▶ 手数料
   └─▶ BaaS（免許とシステムを他社に卸す）────────▶ 受託預金＋手数料

付加価値が集まるのは ①調達コストを低く抑えられる場所（経済圏・給与振込の指定） と
②固定費を分母で薄められる場所（口座数・BaaS受託） の2か所。

5. 収益モデル・コスト構造

  • 収益は 資金利益（利ざや）＋役務取引等収益（手数料）。流通系だけは手数料がほぼ全て
  • コストの主役は物件費（システム・クラウド・ATM）。人件費比率は既存金融機関より大幅に低い
  • 効率指標は OHR（経費率＝営業経費÷業務粗利益）。信用金庫平均78.4%に対しネット銀行等の加重平均68.8%、
    楽天銀行45.8%、住信SBIネット銀行50.0%（いずれも2023年3月期ベース、信金中央金庫 地域・中小企業研究所）
  • 固定費型なので口座が増えるほど1口座あたりのコストが薄まる。この逓減が強さの本体（→ ①）
  • 逆に調達コスト（預金金利）は口座数で薄まらない。金利上昇局面では利ざやが先に潰れる（→ ③・④）

6. 競争要因（KSF）と参入障壁

要因 中身
低い経費率同じ商品を安く作れることが、そのまま金利競争力になる
顧客接点（経済圏）給与振込・引落・ポイントで口座を粘着させられるか
システムの信頼性障害は即座に信用問題になる。勘定系の安定運用そのものが資産
免許と資本銀行免許・自己資本比率規制・預金保険。新規参入の最大の壁
規制対応能力マネロン対策・本人確認・不正検知の体制。口座数で薄められない固定費で、小規模行ほど重い
BaaS受託力他社ブランドの銀行を短期間で立ち上げられる開発・運用力

7. 規制・法制度

  • 銀行法：免許、自己資本比率規制、大口信用供与規制、システムリスク管理
  • 銀行代理業（銀行法）：事業会社がBaaSで自社ブランド銀行を出すための登録制度
  • 預金保険法：1金融機関あたり元本1,000万円とその利息までを保護（決済用預金は全額）
  • 犯罪収益移転防止法（犯収法）：本人確認（eKYC）の方式を規定。2027年4月から非対面はマイナンバーカードICチップ（JPKI）へ原則一本化、現行の「ホ方式」は廃止予定
  • 資金決済法：決済事業者との境界を決める法律（ネット銀行自身は銀行法側）
  • 当局の要請：金融庁・警察庁が2025年9月12日付で口座の不正利用防止策の強化を要請。全銀協は不正利用口座の情報共有枠組みを検討

8. 最近のトピック

詳細と出典は ④ 直近トピック（2026年9月時点）。要点は5つ。

  • 預金金利が年1%の世界へ — 日銀の政策金利が2026年6月に約1.0%。メガバンク普通預金は同年8月から0.4%、ネット銀行は条件付きで1%台
  • 2026年3月期は増収減益が並んだ — 預金金利は即時、住宅ローン変動金利の反映は遅れる。時間差で利ざやが潰れた
  • ドコモSMTBネット銀行が誕生（2026年8月3日商号変更） — 経済圏4陣営がそれぞれ銀行を持ち切った
  • BaaSが成長の主戦場に — JRE BANKが開始1年で約54万口座、みんなの銀行はパートナー30社超
  • 規制コストが次の制約 — 2027年4月の本人確認厳格化と不正利用対策。口座数で薄められない固定費
