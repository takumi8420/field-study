# 各社の出自と戦略の違い ― 「ネット銀行」で一括りにすると何も見えない

このノートで分かること：ネット銀行は十数行あるが、**母体（親会社）が誰かで経済構造が別物**になる。
ATMで稼ぐ銀行、経済圏の入口として作られた銀行、証券の付属装置として設計された銀行、法人に特化した銀行。
どの類型かを先に判定すれば、決算の読み方も戦略も一気に見通せる。

> ポイント：ネット銀行の戦略は「銀行として何をしたいか」ではなく、
> **「親会社が銀行に何をさせたいか」**で決まる。だから同じ業態名でも利益の出方が違う。

## 1. 4つの類型

```
【母体で分かれるネット銀行の4類型】

  ① 流通系            ② 経済圏系（EC・通信）      ③ 証券・金融系        ④ 独立・法人特化
  ┌──────────┐     ┌─────────────┐     ┌────────────┐   ┌────────────┐
  │ コンビニ │     │ EC／携帯／ポイント │     │ 証券・信託     │   │ ITベンダー等 │
  └────┬─────┘     └────────┬────────┘     └──────┬─────┘   └──────┬─────┘
       │ 店頭に              │ 会員を銀行に            │ 証券口座と       │ 法人の
       │ ATMを置く           │ 引き込む                │ つなぐ           │ 決済を握る
       ▼                     ▼                         ▼                 ▼
   セブン銀行            楽天銀行／PayPay銀行      ドコモSMTB(旧住信SBI) GMOあおぞら
   ローソン銀行          auじぶん銀行              ソニー銀行             大和ネクスト
   イオン銀行            みんなの銀行 など         SBI新生銀行            UI銀行
       ↓                     ↓                         ↓                 ↓
   手数料が収益          経済圏のLTVが目的         運用商品への導線   決済・振込・API
```

| 類型 | 誰の持ち物か | 銀行に期待される役割 | 主な収益源 | 見るべき指標 |
| --- | --- | --- | --- | --- |
| **① 流通系** | セブン＆アイ、ローソン、イオン | 店頭に人を呼ぶ／現金インフラ | **ATM受入手数料** | ATM台数、1日1台あたり利用件数 |
| **② 経済圏系** | 楽天、ソフトバンク／LINEヤフー、KDDI、NTTドコモ | 会員の**決済と資金を経済圏内に留める** | 利ざや＋決済手数料 | 口座数、預金残高、経済圏内の利用率 |
| **③ 証券・金融系** | SBI（→ドコモ・三井住友信託）、ソニー、大和 | 証券・資産運用への**資金の待機場所** | 利ざや（住宅ローン）＋手数料 | 住宅ローン残高、証券連携口座数 |
| **④ 独立・法人特化** | GMOインターネット＋あおぞら銀行 ほか | **法人の決済口座**を押さえる | 振込手数料＋法人融資 | 法人口座数、API接続社数 |

## 2. ① 流通系 ― セブン銀行は「銀行の顔をしたATM会社」

セブン銀行は預金を集めて貸す銀行ではない。**預貸率は5%未満**（2023年3月期、信金中金調べ）で、
本業収益のほとんどが役務取引等収益＝**他行のカードで自社ATMを使わせたときに他行からもらう手数料**。

```
【セブン銀行の収益の流れ】

  利用者（他行のキャッシュカード）
        │ コンビニATMで出金
        ▼
   セブン銀行ATM ──── ATM利用手数料 ───▶ 利用者が払う分
        │
        └── ATM受入手数料（1件あたり百数十円規模） ◀── 提携先の銀行が払う
                  ▲
        この「銀行が払う手数料」が収益の柱。
        つまり顧客は預金者ではなく【提携金融機関】である
```

- 経費の**約9割が物件費**（ATM機・設置費・現金輸送・保守）。人件費比率は極端に低い。**装置産業**そのもの。
- 2026年3月期は経常収益 約2,200億円・経常利益 約301億円で**増収減益**。国内ATM事業の利用件数は過去最高だった一方、
  クレジットカード事業で特別損失（約63億円）を計上し、通期純利益予想を110億円に下方修正したと報じられている。
- 2026年度（2027年3月期）計画では**ATM期末台数 2万9,404台**、年度総利用件数 11億3,900万件を想定。

そして2025〜2026年の最大の変化が**ファミリーマートのATM約1万6,000台をセブン銀行が引き受ける件**。
2026年春から4年程度かけて順次入れ替え、**ATM台数は約4万4,000台となりゆうちょ銀行（約3万1,000台）を抜いて国内首位**になる見通し。
同時に伊藤忠商事がセブン銀行に約2割出資し持分法適用会社化するとも報じられ、「コンビニ金融」の勢力図が組み替わっている
（→ [④ 直近トピック](04_直近トピック_2026.md)）。

> 覚え方：セブン銀行の業績は**キャッシュレス化で減り、外国人観光客と外貨引き出しで増える**。
> 金利が上がっても、ほとんど関係がない。利ざやで稼いでいないため。

## 3. ② 経済圏系 ― 銀行は「入口」であって目的ではない

楽天・PayPay（ソフトバンク／LINEヤフー）・au（KDDI）・ドコモ（NTT）。
いずれも**通信・ECの会員を金融に引き込み、ポイントで囲い込む**ための装置として銀行を持つ。

```
【経済圏における銀行の位置】

   通信契約 ─┐
   EC購入  ─┼─▶ 【ポイント】 ◀─┬─ 決済（コード決済・カード）
   広告    ─┘                    ├─ 銀行（給与振込・引落・預金）
                                  └─ 証券（積立投資）
                 ▲                       ▲
      ポイント原資はグループ全体で負担    銀行は「お金の置き場所」を押さえる役
                                          → 引落口座になった瞬間に解約されにくくなる
```

銀行がここで果たす機能は3つ。
1. **給与振込・引落の受け皿**になる（＝毎月お金が入ってくる導線を握る）
2. **ポイント優遇の条件**として使われる（例：dカードの引落口座に指定するとdポイント還元率が上がる施策）
3. **預金という滞留資金**を生み、グループ内の証券・決済に流す

| 銀行 | 母体 | 2026年前後の規模感 | 特徴 |
| --- | --- | --- | --- |
| **楽天銀行** | 楽天グループ（東証上場） | 預金口座 **1,807万**、預金約 **12.9兆円**、2026年3月期 純利益 **730億円**（前期比+44%）、ROE 21.7% | ネット銀行最大手。楽天証券との「マネーブリッジ」、BaaSでJRE BANKを受託 |
| **PayPay銀行** | ソフトバンク／LINEヤフー系 | 2026年4月に**1,000万口座突破**。10〜20代が約180万口座（2026年3月末、2021年3月末の約4倍） | PayPayアプリからの口座開設導線が強い。若年層比率が高い |
| **au じぶん銀行** | KDDI＋三菱UFJ銀行 | 2026年3月期 純利益 **46.1億円**（前期比−68.5%）、預金 5兆7,145億円、貸出金 6兆3,497億円 | 住宅ローンに大きく振った構成。顧客満足度調査で3年連続1位との調査結果も |
| **ドコモSMTBネット銀行**（旧・住信SBIネット銀行） | NTTドコモ＋三井住友信託銀行 | 預金口座 **900万突破**（2026年2月）、預金残高11兆円超（2025年8月）、2026年3月期 連結純利益 **300.6億円**（+6.9%） | 2025年10月にドコモの連結子会社化、2026年8月3日に商号変更。BaaSの先行者 |

> 経済圏系の読み方：銀行単体の利益より、**「経済圏全体で1人あたりいくら落ちるか」**で評価されている。
> だから銀行が赤字でも撤退しないし、ポイント優遇という形で利益を外に出すこともできる。
> 経済圏そのものの構造は [通信キャリア](../../04_情報通信・IT・ネット/01_通信キャリア/README.md) と
> [フィンテック・キャッシュレス](../../04_情報通信・IT・ネット/13_フィンテック・キャッシュレス/README.md) を参照。

## 4. ③ 証券・金融系 ― 「証券の待機資金置き場」という発明

SBIグループが作った住信SBIネット銀行（現・ドコモSMTBネット銀行）の**SBIハイブリッド預金**、
楽天銀行と楽天証券の**マネーブリッジ**は、同じ発想の商品。

```
【証券連携のしくみ】

   銀行の普通預金  ←────自動スイープ────→  証券口座の買付余力
        ▲                                        │
        │ 高めの優遇金利を付ける                 │ 株・投信を買うときに
        │ （＝預金が集まる）                     ▼ そのまま使える
        └──── 利用者は「金利ももらえて、すぐ投資もできる」

   銀行にとって  ： 低コストで大量の預金が集まる
   証券にとって  ： 買付のハードルが消え、入金忘れによる機会損失がなくなる
   グループにとって： 資金がグループ外に出ていかない
```

- **ドコモSMTBネット銀行（旧・住信SBIネット銀行）**：三井住友信託銀行とSBIの合弁として2007年開業。
  住宅ローンと BaaS（→ [③ BaaSと今後](03_BaaSと今後.md)）の二本柱。2025年10月にドコモの連結子会社となり、
  2026年8月に商号変更。ドコモにとっては**金融事業売上を倍増させるための中核**と位置づけられている。
- **ソニー銀行**：外貨預金と住宅ローンに強い。2026年3月期は経常収益1,298.6億円（+9.6%）に対し
  **当期純利益115.6億円（−25.3%）**、預金4兆7,115億円、貸出金3兆5,981億円。金利上昇局面で調達コストが先に効いた形。
- **大和ネクスト銀行**：大和証券グループ100%。大和証券の支店を銀行代理店に使う、実店舗を「借りる」タイプ。

## 5. ④ 独立・法人特化 ― 個人ではなく法人の決済を取りにいく

個人向けは経済圏を持つ大手が強い。そこを避けて**法人（特に新設法人・スタートアップ）**に寄せたのが
**GMOあおぞらネット銀行**（GMOインターネットグループ＋あおぞら銀行）。

| 打ち手 | ねらい |
| --- | --- |
| **当日中の法人口座開設** | 会社設立直後、いちばん急いでいるタイミングを取る |
| 設立1年未満は他行宛振込手数料が月20回まで無料 | 創業期の固定費を下げて乗り換えコストを消す |
| **API（銀行機能の外部接続）を早期から開放** | 会計ソフト・請求書SaaSと直結させ、抜けられなくする |
| 入出金明細の自動取得 | 経理業務ごと囲い込む |

2025年7月時点で**法人口座20万・預金残高1兆円超**、その後**法人口座26万超・預金約1.4兆円**まで伸びたと開示・報道されている。
東京商工リサーチの調査では「メインバンク取引社数の増加率トップ」とされ、**地方銀行の法人口座を実際に削っている**。

> なぜ法人が狙い目か：法人の預金は**口座振替や給与振込が紐づくので動きにくい**（粘着性が高い）。
> 個人預金のように金利だけで移らない。さらに振込件数が多いため**手数料が安定的に積み上がる**。

## 6. 類型ごとに「何が起きると儲かるか」が違う

| 出来事 | 流通系 | 経済圏系 | 証券・金融系 | 法人特化 |
| --- | --- | --- | --- | --- |
| 政策金利の上昇 | ほぼ無関係 | 利ざや拡大（ただし預金金利競争も激化） | 調達コスト先行で**一時的にマイナス**も | 預金が積まれていればプラス |
| キャッシュレス化の進展 | **マイナス**（ATM利用が減る） | プラス（決済手数料） | 中立 | プラス |
| 訪日外国人の増加 | **プラス**（海外カード出金手数料） | 中立 | 中立 | 中立 |
| 住宅市況の悪化 | 無関係 | 中立 | **マイナス**（主力商品） | 無関係 |
| 起業・法人設立の増加 | 無関係 | 中立 | 中立 | **プラス** |
| 不正送金の増加 | 対策コスト増 | 対策コスト増 | 対策コスト増 | 対策コスト増 |

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **ATM受入手数料** | 他行の顧客が自社ATMを使ったとき、その**銀行側から**受け取る手数料。セブン銀行の収益の柱 |
| **預貸率** | 貸出金 ÷ 預金。流通系は5%未満、ネット専業は80%超と両極端 |
| **経済圏** | 通信・EC・決済・金融をポイントで束ねた顧客囲い込みの仕組み |
| **スイープ（自動振替）** | 銀行預金と証券の買付余力を自動で行き来させる機能。SBIハイブリッド預金、マネーブリッジなど |
| **銀行代理業** | 銀行に代わって預金・貸出の契約締結を媒介する業務。大和ネクスト銀行が証券支店を使う根拠 |
| **持分法適用会社** | 出資比率がおおむね20%以上で、利益のうち持分相当を取り込む関係の会社 |
