学習済み更新 2026-09-20金融
あこのページの単語集用語に触れると意味を確認できます5語
信用金庫・信用組合最初に覚えるべき3つだけ挙げるなら利ざや（貸出金利−預金金利＝本業の粗利）預貸率（貸出÷預金＝集めた預金をどれだけ貸せているか）コア業務純益（本業の稼ぐ力）である

日本の都道府県を単位に、地域の家計から預金を集め、地元の中小企業と個人に貸す銀行。
人口減少で貸出先が細る一方、2024年以降の金利上昇で利ざやが戻るという、
構造問題と追い風が同時に走っている業界である。

1. 業界の定義・範囲

「地方銀行」は法律上の分類ではなく、加盟している業界団体による慣行上の呼び名である。

区分 根拠法・形態 数（2026年時点） 位置づけ
第一地銀銀行法・株式会社。全国地方銀行協会加盟61行各県のトップ行。自治体の指定金融機関を担うことが多い
第二地銀銀行法・株式会社。第二地方銀行協会加盟35行前身は相互銀行。より小口の取引先が厚い
信用金庫信用金庫法・協同組織約250金庫会員の相互扶助が目的。営業区域が法律で限定される
信用組合中小企業等協同組合法・協同組織約140組合さらに小規模。原則、組合員以外に貸せない

※行数・金庫数は各協会公表ベース。再編で毎年動く。

隣接業界との境界は次のとおり。

  • メガバンク：全国＋海外に展開。大企業向けと市場業務が主戦場。
    都市部では地銀と正面から競合する
  • ネット銀行：店舗を持たず高めの預金金利を出す。
    2020年代後半は預金の奪い合いで直接ぶつかる相手になった
  • 政府系金融：日本政策金融公庫、商工中金。危機時の補完と協調融資の相手
  • 信用金庫・信用組合：協同組織。株価がないため市場からの再編圧力が弱い

2. 市場規模と成長性

指標 数値 時点・出典
上場地銀の連結純利益合計1兆7,118億円（前期比＋37%）。2期連続で過去最高2026年3月期・報道ベース
地銀合計の当期純利益1兆8,043億円（前年比＋37.9%）※母集団が上記と異なる2026年3月期・金融庁集計の報道ベース
貸出金残高（上場73社合計）約56.0兆円（前年比＋3%）2026年4〜6月期・報道ベース
第二地銀の預金残高71兆8,426億円2026年3月末・第二地方銀行協会
預貸率（貸出÷預金）73.9% → 75.8%（1.8ポイント上昇）2026年1〜3月期・日本総研集計
東証基準ROEが5%未満の行全国95行のうち34行2026年3月期・東洋経済オンライン集計

成長性はマイナスの構造要因とプラスの循環要因が同居していると見るのが正確である。
人口・企業数の減少は貸出の分母を確実に縮める。一方で政策金利は2026年6月に1.00%へ上がり、
利ざやが戻った。前者は10年単位、後者は数年単位で効くため、足元の増益と長期の縮小は矛盾しない。

3. バリューチェーン（お金の流れ）

製造業のような川上・川下はない。地銀の「バリューチェーン」は資金の循環である。

  【集める】            【回す】                   【返ってくる】

   地域の家計   ──預金──▶  地  方  銀  行  ──貸出──▶ 地元の中小企業
   （給与・年金・相続）      ┌──────────┐            （運転資金・設備投資）
   地元企業の決済資金  ──▶  │ 審査・与信管理 │──貸出──▶ 個人（住宅ローン）
   自治体の公金        ──▶  │ 資金繰り・運用 │            │
                            └──────────┘            └─利息＋元本─┐
                                   │                                  │
                      貸せない余剰 │                                  ▼
                                   ▼                            利ざや＝粗利
                      有価証券（国債・外債・投信）
                      越境融資（都市部の不動産・大企業）
                                   │
                                   └── 金利・為替・信用のリスクを銀行が抱える

付加価値が集まるのは審査・与信管理のところである。預金を集めることも貸すことも
他行にできるが、「この会社に貸して返ってくるか」を判断する力だけは移転しにくい。
ところが実際には担保・保証に依存してきたため、そこが弱点になっている（→03）。

グループ／行 中核銀行 立ち位置
ふくおかフィナンシャルグループ福岡銀行ほか九州の広域グループ。ネット専業の「みんなの銀行」を傘下に持つ

5. 収益モデル・コスト構造

   業務粗利益 ─┬─ 資金利益（貸出利息＋有価証券利息 − 預金利息）… 7〜8割
               ├─ 役務取引等利益（投信・保険の販売、為替、M&A仲介）
               └─ その他業務利益（債券売買損益など）
                         │
                         ├─ 経費（人件費＋物件費＋税金）… 固定費の塊
                         │   └ 店舗網・勘定系システム・人員
                         ▼
                コア業務純益 ＝ 業務粗利益 − 経費（債券売買損益を除く）
                         │
                         ├─ 与信費用（貸倒引当金・貸倒損失）
                         └─ 株式・債券の損益
                         ▼
                      当期純利益
  • 儲けの源は利ざや。貸出金利と預金金利の差。業務粗利益の7〜8割を占めるのが一般的
  • コストはほぼ固定費。店舗と勘定系システムは、貸出が減っても勝手には減らない。
    だから再編は「固定費を割る相手を探す」作業になる（→02）
  • 経費率（OHR＝経費÷業務粗利益）は60〜80%台の行が多く、ここが体力差に直結する
  • 利益率の目安としては、2026年3月期でもROE8%に届かない行が8割超（東洋経済集計）

6. 競争要因（KSF）と参入障壁

勝敗を分ける要素 中身
預金の粘着性給与振込・年金受取・公金・口座振替を押さえていれば、金利を上げなくても資金が残る
経費率店舗統廃合と勘定系の共同利用でどこまで固定費を落とせたか
変動金利貸出の比率利上げがそのまま利ざやに乗るか、数年遅れて効くか
有価証券の入れ替え余力含み損を損切りできるだけの利益と資本があるか
目利き力担保・保証に頼らず事業を評価して貸せるか（企業価値担保権の時代の必須条件）
非金利収益事業承継・M&A・人材紹介など、貸出以外の手数料の積み上げ

参入障壁は高い。銀行業免許が必要で、自己資本規制・預金保険・マネロン対策・システム投資という
重い負担がかかる。ただし障壁は「新規参入を防ぐ壁」としては機能しても、
既存行を守る壁にはなっていない。ネット銀行が金利で預金を取り、
メガバンクと都市部で競合し、同一県内では信金とも顧客が重なるためである。

7. 規制・法制度

制度 内容 時期
銀行法免許制、自己資本規制、業務範囲規制。2021年改正で非金融業務を大幅に緩和継続／2021年改正
独占禁止法特例法地域銀行の統合を独禁法の企業結合審査から外し、金融庁の認可制とする10年の時限措置2020年11月施行
金融機能強化法国が優先株等で資本参加する制度。コロナ特例・震災特例あり継続
改正金融機能強化法資本参加の申請期限を「当分の間」＝事実上恒久化。資金交付制度を2031年3月末まで延長。中小地域金融機関のシステム共同化支援を新設2026年4月成立、6月25日施行
事業性融資推進法企業価値担保権を新設。事業全体（将来キャッシュフローを含む）を担保にできる2026年5月25日施行
地域金融力強化プラン金融庁の方針文書。中堅企業支援、M&A・事業承継、事業性融資、スタートアップ支援、DX支援が重点分野2025年12月19日策定
金融行政方針（2026事務年度）不動産業向け融資、超長期住宅ローン、預金などの流動性リスクを重点点検2026年7月〜2027年6月

政策の向きは「アクセルとブレーキの同時踏み」である。
地域への資金供給と役割拡大を促しつつ、越境融資・不動産融資・有価証券運用には監視を強めている。

8. 最近のトピック

詳細は 04 直近トピック 2026。要点は次の5つ。

  1. 金利上昇は「時間差の利益」を生んだ。貸出金利が先に上がり、預金金利が後から追う。
    上場地銀の2026年3月期純利益は1兆7,118億円で2期連続の過去最高（報道ベース）
  2. 全体は最高益、中身は二極化。ROE5%未満が34行、PBR1倍超は約3割（2026年）
  3. 次の戦線は調達側。預金残高が前年割れする行が出ており、引き止めに金利を上げれば利ざやが縮む
  4. 再編が連鎖。2026年1月に八十二長野銀行が発足、3月にしずおかFGと名古屋銀行が統合で基本合意、
    5月に福井銀行と福邦銀行が合併（いずれも公表・報道ベース）
  5. 制度が再編を後押し。改正金融機能強化法（2026年6月施行）で公的資本参加が事実上恒久化し、
    資金交付は2031年3月末まで延長、システム共同化の支援枠も新設された
