# 地域経済との関係

このノートで分かること：地銀と地元企業の関係（メインバンク制）が実際どう成り立っているか。
担保・保証に頼ってきた融資がなぜ問題視され、事業性評価・企業価値担保権へ向かっているのか。
そしてゼロゼロ融資の後始末と、金融庁が地銀に何を求めているか。

## 1. まず結論：地銀は「地域で唯一、企業の中身を見られる立場」にいる

地方の中小企業には、株式市場も格付け機関もアナリストもいない。
その企業が健全かどうかを判断できるのは、**日々の入出金を見ている取引銀行**だけである。

> ポイント：だからこそ地銀は「**目利き**」を期待される。
> ところが現実には、**不動産担保と経営者の個人保証、そして信用保証協会の保証**という
> 「見なくても貸せる仕組み」に長く依存してきた。
> この依存から抜け出せるかが、2020年代の地域金融の最大テーマになっている。

## 2. メインバンク制とは何か

**メインバンク**とは、ある企業にとって取引の中心となる銀行のこと。法律上の定義はなく、
慣行として次のような役割の束を指す。

| 役割 | 中身 |
| --- | --- |
| **最大の貸し手** | 借入残高が最も多い。他行もメイン行の動きを見て追随する |
| **決済の受け皿** | 売上の入金、仕入・給与の支払、手形・でんさいの決済口座を持つ |
| **情報の集約点** | 入出金の流れから、売上の増減・資金繰りの詰まりが最初に見える |
| **危機時の調整役** | 業績が悪化したとき、他行との調整（リスケジュールや協調）を主導する |
| **経営への関与** | 役員の派遣、後継者や幹部人材の紹介、M&A相手の紹介 |

```
                   ┌──────── 地元の中小企業 ────────┐
                   │  売上入金／給与・仕入支払／手形 │
                   └───────────┬──────────────────┘
                               │ 日々の資金の流れが全部見える
                   ┌───────────▼──────────────┐
                   │      メインバンク（地銀）     │
                   └───┬──────────┬────────┬────┘
                       │          │        │
          追随する他行 ─┘   信用保証協会 ─┘   政府系金融 ─┘
          （地銀・信金）      （保証で補完）   （日本公庫・商工中金）
```

メインバンク制は**情報の非対称性**（貸し手が借り手の実態を知りにくい問題）を、
長期の取引関係で埋める仕組みだと説明される。うまく働けば、
一時的に業績が落ちた企業にも資金が回り、地域の雇用が守られる。

一方で、**関係が固定化すると金利交渉が甘くなる**、
**メイン行が支えるという前提で他行が審査を省く**といった弊害も指摘されてきた。

## 3. 担保・保証依存という構造

中小企業への融資は、実務上ほぼ次の3点セットで組まれてきた。

| 手段 | 中身 | 銀行にとっての意味 | 企業にとっての副作用 |
| --- | --- | --- | --- |
| **不動産担保** | 社屋・工場・経営者の自宅に抵当権 | 返せなければ処分して回収 | 不動産を持たない企業（サービス業、スタートアップ）は借りにくい |
| **経営者保証** | 社長個人が会社の借金を連帯保証 | 経営者の逃げ道を塞ぎ、規律をきかせる | 事業に失敗すると個人も破産。**事業承継の最大の障害**になる |
| **信用保証協会の保証** | 公的な保証機関が返済を保証 | 焦げ付いても保証協会から回収できる | 保証料を負担。銀行が中身を見なくなる誘因にもなる |

この3点セットは、**銀行の審査能力が乏しくても貸せてしまう**点が問題視されてきた。
金融庁が2014年ごろから「**事業性評価**」（財務データや担保・保証に過度に依存せず、
事業内容と成長可能性を評価して融資すること）を繰り返し求めてきたのは、この構造への是正である。

## 4. 信用保証協会の仕組み

各都道府県などに置かれた公的機関で、中小企業の借入を保証する。
名前だけは誰でも聞くが、お金の流れを押さえないと報道の意味が取れない。

```
 ①企業が申込        ②保証審査・保証料
 企業 ──────▶ 銀行 ──────▶ 信用保証協会
   ▲            │              │
   │            │③保証付きで融資 │④再保険（保険料）
   └────────────┘              ▼
                          日本政策金融公庫（信用保険）

 【返済できなくなったとき】
 企業 ──✕ 返済できない
              │
              ▼
   信用保証協会 ──⑤代位弁済──▶ 銀行（残債を肩代わりして受け取る）
              │
              └──⑥求償権──▶ 企業（協会が企業に請求する。借金は消えない）
```

押さえるべき点は2つ。

- **代位弁済されても企業の債務は消えない**。債権者が銀行から保証協会に替わるだけで、
  協会は**求償権**にもとづいて回収を続ける
- **責任共有制度**（2007年導入）により、通常の保証は**協会80%・銀行20%**の負担。
  銀行にも痛みを残して審査を働かせる仕組み。ただし**100%保証の制度もあり**、
  危機時にはそちらが使われる

## 5. ゼロゼロ融資の後始末

**ゼロゼロ融資**とは、コロナ禍の2020年から実施された「**実質無利子・無担保**」の融資のこと。
民間金融機関経由の分は、信用保証協会の**100%保証**に、都道府県が利子を一定期間補給する形で、
銀行にとってほぼノーリスクで実行できた。結果、極めて短期間に巨額が供給された。

その返済が、据置期間を終えて順次始まっている。時系列で見ると次のようになる。

| 時期 | 出来事 |
| --- | --- |
| 2020年〜2021年 | ゼロゼロ融資の実行がピーク。多くが3年程度の据置期間付き |
| 2023年1月〜 | 返済負担を軽くする**コロナ借換保証**が開始。2025年2月末で30.1万件の利用と報じられる |
| 2023年〜2025年 | 「ゼロゼロ融資利用後倒産」が増加。2025年通年で433件（東京商工リサーチ集計）、636件（帝国データバンク集計） |
| 2026年4〜9月 | 借換保証の**返済開始の最後のピーク**を迎えると報じられる |
| 2026年1〜5月 | 月別の同倒産は20件台で小康状態。2026年5月までの累計2,363件（東京商工リサーチ） |

> 整理：数字は「急増」ではなく「**高止まりしたまま長引いている**」状態。
> 銀行から見ると、100%保証の分は損失が直接は出にくい一方、
> **保証のない自前の貸出（プロパー融資）**と、取引先の廃業による**将来の貸出先の消失**が効いてくる。
> 保証協会側では代位弁済と求償権の回収という後処理が続く。

## 6. 事業性評価から「企業価値担保権」へ

担保・保証依存からの転換は、長く掛け声にとどまっていた。
そこに制度の裏付けを与えたのが**事業性融資推進法**（正式名称：事業性融資の推進等に関する法律）である。

| 項目 | 内容 |
| --- | --- |
| 成立・施行 | 2024年6月成立、**2026年5月25日施行** |
| 新設された担保 | **企業価値担保権** |
| 担保の対象 | 不動産や在庫といった個別資産ではなく、**将来のキャッシュフローを含む事業全体** |
| 担保権者 | **信託会社等**が担保権者となる（信託のスキームを使う）。貸し手側に制限はなく、銀行のほかファンドも利用できる |
| 経営者保証との関係 | 企業価値担保権が設定されている場合、**経営者保証の利用が制限される** |
| 想定される使い道 | スタートアップ融資（VCとの協調）、中小・中堅企業融資、事業再生・事業承継、M&A・プロジェクトファイナンス |

```
  【従来】                              【企業価値担保権】

  工場・土地 ──抵当権──▶ 銀行          事業まるごと ──信託──▶ 担保権者
  社長個人 ──連帯保証──▶ 銀行          （将来CFを含む）        │
                                                             ▼
  ＝「モノ」と「個人」を押さえる         ＝「稼ぐ力」を押さえる
  → 不動産のない事業は借りにくい         → 目利きができないと貸せない
  → 失敗すると個人も破産                 → 経営者保証は制限される
```

制度が変わっても、**銀行側に事業を評価する力がなければ使えない**点は変わらない。
実務では、モニタリング（融資後の継続的な経営状況の確認）の体制、
再生局面での他の債権者との調整、担保価値の評価手法など、積み上げるべき論点が多いと指摘されている。

あわせて、**経営者保証改革**も進んでいる。
「経営者保証に関するガイドライン」（2014年適用開始）に加え、2023年以降は
保証を求める場合に金融機関が理由を説明する義務が強められ、保証に頼らない融資が促されている。

## 7. 事業承継とM&A支援 ―― 貸出先を「なくさない」仕事

地方の企業が消える最大の理由は、業績悪化よりも**後継者不在による廃業**だとされる。
貸出先が消えれば地銀の収益基盤も消えるため、事業承継支援は慈善ではなく**自衛**である。

| 支援の種類 | 中身 | 銀行の収入源 |
| --- | --- | --- |
| **親族内承継** | 自社株の評価・移転、納税資金の融資、持株会社スキーム | 融資＋コンサル手数料 |
| **従業員承継（MBO/EBO）** | 従業員が株を買い取る資金を融資 | 融資 |
| **第三者承継（M&A）** | 売り手・買い手のマッチング、仲介・アドバイザリー | 仲介手数料＋買収資金の融資 |
| **人材紹介** | 後継者候補・経営幹部・専門人材の紹介 | 紹介手数料 |
| **ビジネスマッチング** | 取引先どうしの販路紹介 | 紹介手数料 |

M&Aは銀行にとって、**手数料（フロー）と買収資金の融資（ストック）の両方が取れる**数少ない領域で、
[人材紹介](../../15_サービス・生活関連/02_人材紹介・求人メディア/README.md) と並び、
非金利収益の柱として各行が力を入れている。
一方で、仲介の利益相反（売り手と買い手の双方から手数料を取る構造）への目配りが必要とされる。

## 8. 金融庁は地銀に何を求めているか

金融庁の姿勢は、この10年でかなり変わった。

| 時期 | 監督の重心 |
| --- | --- |
| 〜2000年代 | **不良債権の処理**。資産査定と自己資本比率が中心（検査マニュアル時代） |
| 2010年代 | **金融仲介機能の発揮**。事業性評価、顧客本位の業務運営（フィデューシャリー・デューティー）を提唱。2019年に検査マニュアルを廃止 |
| 2020年代前半 | **持続可能なビジネスモデル**。再編の後押し（独禁法特例法）、業務範囲規制の緩和 |
| 2020年代後半 | **地域金融力の強化**。2025年12月に「**地域金融力強化プラン**」を策定。中堅企業の成長支援、M&A・事業承継支援、企業価値担保権を使った事業性融資の促進を掲げ、「中小・地域金融機関向けの総合的な監督指針」の改正が進む |

同時に、**リスク管理面の監視も強めている**。
有価証券運用（特に外債）の管理体制、そして越境融資・不動産融資の与信管理は
重点テーマとして挙げられており、Bloombergは2025年12月、金融庁が地銀の不動産融資の監視を強化し
越境リスク管理に重点を置く方針だと報じた。

> つまり当局のメッセージは二本立てである。
> **「地域に資金と知恵をもっと回せ」**と**「背伸びした運用と越境で足元を崩すな」**。
> この二つを同時に満たすことが、地銀に課された宿題になっている。

## 9. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **メインバンク** | 企業にとって取引の中心となる銀行。最大の貸し手であり決済口座を持ち、危機時の調整役も担う。法律上の定義はない |
| **事業性評価** | 財務データや担保・保証に過度に依存せず、事業の内容・将来性を評価して融資判断すること |
| **信用保証協会** | 都道府県等に置かれた公的保証機関。中小企業の借入を保証し、返済不能時は銀行へ代位弁済する |
| **代位弁済** | 保証機関が借り手に代わって銀行へ残債を支払うこと。借り手の債務は消えず、保証機関に移る |
| **求償権** | 代位弁済した保証機関が、借り手に対して支払った分を請求する権利 |
| **責任共有制度** | 2007年導入。通常の保証で協会80%・金融機関20%の負担とし、銀行にも審査の動機を残す仕組み |
| **プロパー融資** | 信用保証協会の保証を付けない、銀行が自らリスクを取る融資 |
| **ゼロゼロ融資** | コロナ禍の実質無利子・無担保融資。民間金融機関経由分は信用保証協会の100%保証が付いた |
| **コロナ借換保証** | 2023年1月開始。ゼロゼロ融資等の返済負担を軽くするための借換用の保証制度 |
| **企業価値担保権** | 事業性融資推進法（2026年5月25日施行）で新設。将来キャッシュフローを含む事業全体を担保にする権利 |
| **経営者保証** | 会社の借入を経営者個人が連帯保証すること。ガイドラインにより利用の抑制が進む |
| **地域金融力強化プラン** | 金融庁が2025年12月に策定。地域金融機関の役割拡大と、それを支える制度整備の方針 |
