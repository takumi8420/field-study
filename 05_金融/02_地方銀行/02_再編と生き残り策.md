# 再編と生き残り策

このノートで分かること：なぜ地銀は次々と合併・統合するのか、その「型」は何通りあるのか。
そして、統合以外に地銀が取っている生き残り策（システム共同化、非金融業務、公的資金）の中身。

## 1. まず結論：固定費を割る相手を探している

地銀の再編は、ひとことで言えば**固定費の分母を増やす作業**である。

銀行の経費は、店舗・人員・そして**勘定系システム**（預金と為替の記帳を24時間処理する基幹システム。
一度作れば1行で使っても10行で使っても同じ額がかかる）という、**貸出が減っても減らない費用**が中心を占める。
収益（利ざや）が細るなかで固定費が動かなければ、答えは二つしかない。

1. **費用を減らす**（店舗統廃合、システム共同化）
2. **費用を分け合う相手を増やす**（合併・経営統合）

> ポイント：地銀再編は「弱い行が助けを求める」話だけではない。
> 2020年代後半は、単独でも黒字を出せる有力行どうしの統合が増えており、
> 報道ではこれを「守りの再編から攻めの再編へ」と表現することが多い。

## 2. 再編には4つの深さがある

同じ「組む」でも、踏み込みの深さがまったく違う。ニュースを読むときはここを見分ける。

| 型 | 何が一つになるか | 効果 | 難しさ |
| --- | --- | --- | --- |
| **① 業務提携** | 商品・ノウハウ・共同店舗など一部 | 小さいが早い。いつでも解消できる | 低い |
| **② システム共同化** | 勘定系システムの利用 | システム費用を頭割り。効果は大きい | 移行に数年と数百億円規模の投資 |
| **③ 経営統合（持株会社）** | 資本と経営。**銀行の名前とブランドは残る** | 経費・資本を共通化しつつ地元の看板を守れる | 二重の本部が残りやすい |
| **④ 合併** | 銀行そのものが一つになる | 効果は最大（店舗・人員・システムを一本化） | 地元の反発、文化の衝突、公正取引委員会の審査 |

```
  ① 提携          ② システム共同化      ③ 経営統合           ④ 合併
  A行  B行         A行   B行            ┌─ 持株会社 ─┐        A＋B銀行
   │   │           └─┬─┘              A行      B行         （1つの看板）
   └─商品─┘          共同センター        （看板は残る）
  資本関係なし      資本関係なしでも可     資本は一体          完全に一体
```

**③→④へ段階的に進む**のが日本の地銀の定番ルートである。
まず持株会社を作って数年一緒に仕事をし、システムを寄せ、そのうえで合併する。
八十二銀行と長野銀行、福井銀行と福邦銀行など、「統合してから合併」の例が続いている（報道ベース）。

## 3. 再編の系譜（主な動き）

※いずれも公表・報道ベース。個別行の経営の良し悪しを評価するものではない。

| 時期 | 主な動き | 型 |
| --- | --- | --- |
| 1990年代末〜2000年代 | 金融危機を受けた救済型の合併が相次ぐ。公的資金注入も | ④ |
| 2007年 | ふくおかフィナンシャルグループ発足（福岡銀行・熊本ファミリー銀行ほか） | ③ |
| 2016年 | コンコルディア・フィナンシャルグループ（横浜銀行・東日本銀行） | ③ |
| 2016年 | めぶきフィナンシャルグループ（常陽銀行・足利銀行） | ③ |
| 2018年 | 第四北越フィナンシャルグループ発足（2021年に両行合併） | ③→④ |
| 2020年11月 | **独占禁止法特例法**施行。同一県内の統合が通りやすくなる | 制度 |
| 2022年 | 青森銀行・みちのく銀行が経営統合（2025年に合併し青森みちのく銀行） | ③→④ |
| 2026年1月 | 八十二銀行と長野銀行が合併し「八十二長野銀行」が発足と報じられる | ④ |
| 2026年5月 | 福井銀行と福邦銀行が合併予定と報じられる | ④ |
| 2026年3月 | しずおかフィナンシャルグループと名古屋銀行が経営統合に向け基本合意と報じられる | ③ |

近年の特徴は**県境をまたぐ統合**と、**上位行どうしの統合**である。
報道では「1エリア1グループ」「総資産20兆円クラブ」といった見立てが語られているが、
これは記者・アナリストの整理であり、当局が定めた基準ではない。

## 4. 独禁法特例法 ―― 「県内シェア独占」を認めた10年限りの措置

地銀の県内合併は長らく難しかった。理由は単純で、**合併するとその県の貸出シェアが過半になり、
公正取引委員会が「競争が失われる」と判断する**からだ。
実際、2016年のふくおかFGと十八銀行の統合は公取委の審査が長引き、
債権の一部譲渡などを経て2019年にようやく実現した（報道ベース）。

そこで2020年5月に成立、同年11月27日に施行されたのが
**地域銀行および乗合バスに関する独占禁止法の特例法**である。

| 論点 | 内容 |
| --- | --- |
| 何をした法律か | 一定の要件を満たす地域銀行の合併・統合を、**独禁法の企業結合審査の対象外**にする |
| 誰が判断するか | 公取委ではなく**金融庁（主務大臣）が認可**。公取委とは協議する |
| 要件 | 経営基盤の強化につながること、**サービスの維持**（利用者に不当な不利益を与えない）こと等 |
| 期限 | **施行から10年の時限措置**。2030年ごろに期限を迎える |

つまり、「地域に銀行が1つしかなくなっても、金融サービスが維持されるなら認める」という
政策判断が10年限定で置かれている。**この期限が再編を急がせる圧力にもなっている**。

## 5. 持株会社化はなぜ好まれるのか

地銀の統合は、いきなり合併せず**金融持株会社**をかぶせる形が多い。理由は地域固有である。

- **看板を残せる**。地元では銀行名が地域の信用そのもので、消すと反発と口座流出を招く
- **指定金融機関の地位**（自治体の公金の出納業務）を各行が保てる
- **人事の衝突を先送りできる**。旧行ごとの人事体系をすぐ一本化しなくてよい
- **傘下に銀行以外の会社を置ける**。証券・リース・地域商社・コンサル会社など

```
        ┌──────────── ○○フィナンシャルグループ（持株会社）───────────┐
        │                                                            │
   ┌────┴────┐   ┌────┴────┐   ┌───┴────┐   ┌────┴─────┐   ┌───┴────┐
   │  A銀行   │   │  B銀行   │   │ 証券会社 │   │ 地域商社  │   │ リース  │
   │（甲県）  │   │（乙県）  │   │          │   │ 人材紹介 │   │        │
   └─────────┘   └─────────┘   └──────────┘   └──────────┘   └────────┘
        ↑看板は地元に残す            ↑ここで非金利収益を作りにいく
```

反面、**二重の本部・二重のシステムが残ると効果が出ない**。
統合したのに経費率が下がらない、という批判が出るのはこのためで、
最終的に合併まで進む行が多いのはこの問題を解くためである。

## 6. システム共同化 ―― 見えないが最大のコスト削減

勘定系システムは、地銀にとって最も重い投資である。単独で刷新すれば数百億円規模になり、
その後も維持費がかかる。そこで1990年代末から、**複数行が同じシステムを共同利用する**
「共同センター」方式が広がった。

| 代表的な共同システム | 中核ベンダー | ざっくりした性格 |
| --- | --- | --- |
| **地銀共同センター** | NTTデータ | 参加行数が多い最大級の共同化陣営 |
| **Chance（チャンス）** | NTTデータ | 大手地銀中心の陣営 |
| **MEJAR（メジャー）** | NTTデータ | 大手地銀数行による陣営 |
| **BeSTA／BeSTAcloud 系** | NTTデータ | 地銀・第二地銀向けの共通基盤 |
| **Bankingweb21／NEXTBASE 等** | 日本IBM 系 | IBM陣営の共同化 |
| **STELLA CUBE／その他** | 日立・富士通ほか | 中小規模行向けを含む |

近年は、**共同センターどうしを寄せる「共同化の共同化」**と、**クラウド移行**が焦点になっている。
2026年3月には、NTTデータと地銀共同センター参加13行が、システムの共同利用にとどまらず
「モノ・知見・人」を共有する共助モデルの高度化を正式決定したと発表されており、
サイバーセキュリティ、AI・データ活用、業務改革を共同で進める方向が示されている。

> ポイント：**どの共同センターに属しているかが、再編の組み合わせを左右する**。
> システムが同じ陣営どうしなら統合コストが小さく、違う陣営だと移行に数年と多額の費用がかかる。
> 「なぜあの2行が組むのか」を読むとき、地理と並んで勘定系の系列を見るとよい。
> 参考：[SIer・ITサービス](../../04_情報通信・IT・ネット/05_SIer・ITサービス/README.md)

## 7. 非金融業務の解禁 ―― 銀行が銀行以外のことをする

銀行は長らく、**業務範囲規制**（銀行法で定められた業務しかできない）によって
本業以外に手を出せなかった。他業のリスクが預金者に及ぶことを防ぐためである。
しかし地域経済の担い手として期待する政策の流れのなかで、段階的に緩められてきた。

| 時期 | 緩和の内容 |
| --- | --- |
| 2017年〜 | **人材紹介業**が銀行の付随業務として明確化。取引先の後継者・幹部人材の紹介が可能に |
| 2019年〜 | **地域商社**（地元の産品を仕入れて販売する会社）への出資・設立が事実上可能に |
| 2021年 銀行法改正 | **銀行業高度化等会社**の枠組みを整理し、登録型人材派遣、自行開発システムの外販、広告・データ分析、地域活性化事業などを解禁。**出資比率規制（5%・15%ルール）にも特例**を導入 |
| 2020年代後半 | 金融庁「地域金融力強化プラン」（2025年12月策定）に沿って、**中堅企業支援・M&A・事業承継**など役割拡大に向けた監督指針の改正が進む |

日本経済新聞の報道によれば、地方銀行・信用金庫のうち90を超える先が人材仲介に取り組んでいる。
ただし、**非金融事業は売上規模が小さく、利益貢献はまだ限定的**という指摘が一般的で、
「本業の穴を埋める」というより「取引先との関係を深めて本業に返す」位置づけと理解するのが正確である。

## 8. 公的資金という最後の道具

地銀の資本が細ったときの制度が**金融機能強化法**である。
国（預金保険機構）が優先株などの形で資本を注入し、地域金融の機能を維持する。

- 通常の枠組みでは、収益性などの経営強化計画の達成が求められる
- **コロナ特例**（2020年の改正）では、新型コロナ対応の資金繰り支援を優先する観点から、
  収益目標を課さず、**返済期限（公的資金の返済時期）を定めない**枠組みが用意された
- 東日本大震災向けの**震災特例**の枠組みもある

注入を受けること自体は「破綻」ではなく、**資本の厚みを確保して貸出を続けるための制度**である。
一方で、優先株には配当負担があり、返済（優先株の買い戻し）までは経営の自由度に制約が残る。
個別行の状況は各行の開示資料で確認するべきで、ここでは制度の説明にとどめる。

## 9. 外からの再編プレイヤー：SBIとメガバンク系

自力の統合とは別に、**外部資本が地銀に入る**流れがある。

| プレイヤー | 動き |
| --- | --- |
| **SBIホールディングス** | 2019年以降、地銀への出資と業務提携を進め「第4のメガバンク構想」を掲げる。2025年12月に1行が資本提携を解消し、提携先は9行になったと報じられる。運用の共同化で外債の損失が拡大した局面もあったとされ、近年は**システム・運用・人材の支援**に軸足が移ったとの報道が目立つ |
| **りそなグループ** | 資本を入れない**業務提携型**の地銀連携を志向。システムや商品の相互利用が中心 |
| **メガバンク・大手金融** | 特定地銀との資本業務提携、証券・信託分野での協業 |

外部資本の関与は、資本と技術を持ち込む一方で、**地元の経営の独立性との緊張**を生む。
報道でもこの綱引きが繰り返し取り上げられている。

## 10. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **勘定系システム** | 預金・為替・融資の記帳を担う銀行の基幹システム。止まると営業できない。開発・維持費が固定費の柱 |
| **共同センター** | 複数の銀行が同じ勘定系システムを共同利用する仕組み。費用を頭割りできる |
| **金融持株会社** | 傘下に銀行や証券などをぶら下げる持株会社。銀行の看板を残したまま資本を一体化できる |
| **独占禁止法特例法** | 2020年11月施行。地域銀行の統合を独禁法の企業結合審査から外し、金融庁の認可制とする10年の時限法 |
| **業務範囲規制** | 銀行が銀行法上認められた業務しか行えないとする規制。2021年改正で大きく緩和された |
| **銀行業高度化等会社** | 銀行が出資できる、地域活性化やIT関連などを行う子会社の枠組み。出資比率規制の特例が適用される |
| **地域商社** | 地元の農産品・特産品などを仕入れて販路開拓・販売する会社。銀行が出資・設立する例が増えた |
| **金融機能強化法** | 国が金融機関に資本参加して地域金融機能を維持するための法律。コロナ特例・震災特例がある |
| **5%・15%ルール** | 銀行が一般事業会社の議決権を持てる上限（銀行単体5%、持株会社グループ15%）。特例で緩和されている |
