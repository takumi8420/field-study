# 直近トピック（2026年9月時点）

このノートで分かること：2025年後半〜2026年にかけて地方銀行の周辺で実際に起きたことを、
報道・公表資料ベースで整理する。中心は**金利上昇が収益をどう変えたか**と、
その結果として加速した**再編・制度改正・監督の重心移動**である。

仕組みそのものの解説は
[地銀のビジネスモデルと苦境](01_地銀のビジネスモデルと苦境.md)／
[再編と生き残り策](02_再編と生き残り策.md)／
[地域経済との関係](03_地域経済との関係.md) に譲り、ここでは「直近で何が動いたか」に絞る。

> 注意：以下は報道・調査会社集計・各社公表を整理したもので、確定した公式統計ばかりではない。
> 個別行の経営の良し悪しを評価するものではなく、投資判断に用いるものでもない。

## 1. 金利上昇 ―― 何が、どの順番で効いたか

2026年の地銀を語るうえで出発点になるのが、日銀の政策金利である。
第一生命経済研究所のレポートによれば、**2026年6月の金融政策決定会合で無担保コールレートは
1.00%へ引き上げられ、7月会合では据え置かれた**。日本総研のコラム（2026年）では、
エコノミスト37名中30名が2026年末の政策金利を1%以上と予測していたと紹介されている。

重要なのは、**金利上昇が銀行のPLに一斉には効かない**ことである。効き方には順番がある。

```
  政策金利が上がってから、地銀の損益に届くまでの時間差

  【貸出＝プラス】
   0〜数カ月  短プラ連動の変動金利貸出がすぐ上がる ────▶ 利息収入が即増える
   半年〜2年  固定金利貸出が期日を迎え、高い金利で借換 ─▶ じわじわ上積み
   2〜5年〜   既往の長期固定貸出・超長期住宅ローンが入替 ▶ 最後にようやく効く

  【預金＝マイナス、遅れて来る】
   0〜数カ月  普通預金金利は小幅・後追い
   半年〜2年  定期・法人預金の金利競争が効き始める ─────▶ 2026年の新しい戦線

  【有価証券＝マイナス、即座に来る】
   同 時      保有済みの低利回り債券が値下がりし、含み損になる
```

> ポイント：**利益は先に出て、コストは後から来る**。
> 2025〜2026年の「過去最高益」は、貸出金利がすでに上がり、預金金利がまだ十分に上がっていない
> **時間差の期間に生まれた利益**という側面がある。この差が縮まったときに何が残るかが本当の実力になる。

| --- | --- | --- |
| 上場地銀の連結純利益合計 | 1兆7,118億円（前期比＋37%）。2期連続で過去最高 | 2026年3月期・日本経済新聞報道 |
| 翌期の会社計画合計 | 前期比＋11%の1兆9,000億円程度 | 2027年3月期見通し・同報道 |
| 上場地銀のコア業務純益 | 前年同期比約3割増 | 2025年度中間期・日本総研 |

| 四国の地銀8行 | うち6行が純利益で最高益を更新 | 2026年3月期・日本経済新聞報道 |
| 東証基準ROEが5%未満の行 | 全国95行のうち34行。8割以上が8%に届かず | 2026年3月期・東洋経済オンライン集計 |
| PBR1倍超の地銀 | 全体の約3割。首位は群馬銀行 | 2026年3月・日本経済新聞報道 |

※[01](01_地銀のビジネスモデルと苦境.md) に載せた「1兆8,043億円」は全地銀ベースの集計、
ここでの1兆7,118億円は**上場地銀ベース**。集計範囲が違うので、数字を並べるときは母集団を確認する。

構図はこうである。**全体は最高益、しかし中身は二極化している**。

```
   収益力（ROE）の分布イメージ（2026年3月期・全国95行）

   高 ┃              ○ ○ ○         ← 変動金利貸出が厚く、粘着性の高い預金を持つ行
      ┃        ○ ○ ○ ○ ○ ○ ○
      ┃    ○ ○ ○ ○ ○ ○ ○ ○ ○     ← 多数派。増益だが ROE は8%に届かない
      ┃  ○ ○ ○ ○ ○ ○               ← ROE5%未満が34行
   低 ┃  ○ ○                       ← 債券の損失処理や預金流出が重い行
      ┗━━━━━━━━━━━━━━━━━━━▶ 総資産規模
       小                        大
   ※模式図。大和総研は「預金量と経費率の間に負の相関」と整理している（2026年5月）
```

同コラムは、規模と経費率の負の相関に加え、**サイバー対策・マネロン対策・高度人材の確保という
「規模に関係なく必要な固定費」が増え続ける**ことを、二極化を進める要因に挙げている。

## 3. 預金争奪戦 ―― 2026年の新しい戦線

利上げ局面で地銀が最も気にするのは、実は貸出ではなく**調達**である。

- 東洋経済オンラインの集計によれば、**2025年3月期に地銀・第二地銀の約4割にあたる38行で
  預金残高が前年度比マイナス**となった
- 大和総研は、**2023年12月以降、個人預金が減っている地域金融機関の数が増えている機関の数を上回る**
  状態が続いていると整理している（2026年5月）
- ネット銀行が相対的に高い金利を打ち出しており、金利差が見える形になったことで資金が動きやすい
  → [ネット銀行](../04_ネット銀行/README.md)
- 相続を契機に、地方の預金が都市部の大手銀行へ移る流れも指摘される

預金が減ること自体が即座に危機なのではない。問題は、**引き止めるために金利を上げると
第1章の「時間差の利益」が縮む**点にある。金利を上げずに預金が残る行と、上げないと逃げる行の差が、
そのまま収益力の差になる。

| 引き止め手段 | 中身 | 効き方 |
| --- | --- | --- |
| **金利で勝負** | 定期預金のキャンペーン金利を上げる | 即効性はあるが調達コストがそのまま増える |
| **決済口座を押さえる** | 給与振込・年金受取・公金・口座振替 | 金利感応度が低い資金が残る。最も強い |
| **デジタルで広く集める** | アプリ専用預金、ネット支店、他地域からの預け入れ | 地元以外からも集められるが、金利で来た資金は金利で去る |
| **法人の決済基盤** | 売上入金・振込・でんさい | 取引全体の関係で残る |

## 4. 有価証券 ―― 損切りが進んだ行と、残した行

日本経済新聞は2025年11月、地銀の国内債の含み損が前年の約2倍の**約3兆円**に達し、
上位行は損切り（低利回り債を売って損失を確定し、高い利回りの債券に入れ替える）を進める一方、
下位行にリスクが残ると報じた。この構図は[01の第5章](01_地銀のビジネスモデルと苦境.md)で扱ったとおりで、
2026年に入ってからの焦点は「**誰が入れ替えを終えたか**」に移っている。

損切りには**利益の余力**が要る。金利上昇で本業が好調な今こそ損を出しやすい局面であり、
**好業績の期にどれだけ入れ替えたかが次の数年の利回りを決める**。余力がなく持ち続ければ、
低い利回りに資金が縛られたまま時間が過ぎる。

## 5. 再編 ―― 「20兆円クラブ」という物差し

2026年は再編の発表が続いた年である（いずれも公表・報道ベース）。

| 時期 | 動き | 型 |
| --- | --- | --- |
| 2026年1月 | 八十二銀行と長野銀行が合併し「八十二長野銀行」発足 | 合併 |
| 2026年3月27日 | しずおかフィナンシャルグループと名古屋銀行が経営統合で基本合意。最終契約2027年3月、統合2028年4月を目標 | 経営統合 |
| 2026年5月 | 福井銀行と福邦銀行が合併 | 合併 |
| 2026年以降 | 千葉銀行と千葉興業銀行、第四北越FGと群馬銀行など、新たな組み合わせが取り沙汰される | 報道・観測 |

しずおかFGと名古屋銀行の件は、**県境をまたぐうえに、どちらも単独で黒字を出せる規模の行どうし**
という点で象徴的に扱われ、日本経済新聞は「地銀再編ドミノ、『20兆円クラブ』に照準」と報じた。
「1エリア1グループ」「生き残りの目安は総資産20兆円」といった見立ても語られるが、
**これらは記者・アナリストの整理であって、当局が定めた基準ではない**。
再編の型の分類は [02の第2章](02_再編と生き残り策.md) を参照。

## 6. 制度 ―― 改正金融機能強化法（2026年）

再編を後押しする制度が、2026年に一段進んだ。

**金融機能の強化のための特別措置に関する法律等の一部を改正する法律**が
**2026年4月24日に成立、5月7日公布、6月25日に全面施行**された。要点は3つである。

| 項目 | 改正前 | 改正後 |
| --- | --- | --- |
| **資本参加制度**（国が優先株等で資本を入れる制度）の申請期限 | 2026年3月末 | **「当分の間」**＝事実上の恒久化。大規模災害・感染症まん延に備えた特例も整備 |
| **資金交付制度**（再編に伴う費用を国が交付する制度）の申請期限 | 2026年3月末 | **2031年3月末**まで延長し、対象も拡充 |
| **システム共同化の支援** | 明示的な枠組みなし | 中小規模の地域金融機関による**勘定系システム共同化を支援する枠組み**を新設 |

3つ目が地味だが効く。[02の第6章](02_再編と生き残り策.md) のとおり、
**どの共同センターに属しているかが再編の組み合わせを左右する**ため、
移行費用の一部に公的な手当てがつくことは、組み合わせの自由度を広げる方向に働く。

あわせて、金融庁は2025年12月19日に**地域金融力強化プラン**を策定しており
（→[03の第8章](03_地域経済との関係.md)）、中堅企業の成長支援、M&A・事業承継、
事業性融資、スタートアップ支援、DX支援を重点分野として掲げている。
日本総研はこれに対し、「地域金融力とは地域の持続的発展への貢献であって、
プランが並べた各分野の取り組みを進めること自体が目的ではない」と釘を刺している。

```
   2026年に揃った「再編を促す制度」の三点セット

   独禁法特例法        ＝「組んでよい」  県内シェアが独占でも統合を認める
   （2020年11月施行）                    ★施行から10年の時限措置

   改正金融機能強化法  ＝「資金を出す」  資本参加を事実上恒久化／
   （2026年6月施行）                     資金交付を2031年3月末まで／
                                         システム共同化を支援

   地域金融力強化プラン＝「何をやるか」  中堅企業支援・M&A・事業性融資など
   （2025年12月策定）                    重点分野の方向づけ
            │
            ▼  「2030年ごろの特例法の期限まで」という時間の圧力が働く
```

## 7. 監督の重心 ―― 不動産・越境・流動性

金融庁は**2026事務年度（2026年7月〜2027年6月）の金融行政方針**で、
金利上昇が加速するなかでのリスク管理を重点に据えたと報じられている。
点検の対象として挙げられるのは次のとおり。

- **不動産業向け融資**。銀行の不動産融資の伸びは9年ぶりの高水準になったと報じられている
- **超長期の住宅ローン**。返済期間が長いほど、金利リスクと与信リスクが重なって効く
- **預金などの流動性**。預金が動きやすくなった環境そのものをリスクとして見る姿勢
- **越境融資の保全**。Bloombergは2025年12月、金融庁が地銀の不動産融資の監視を強化し越境リスク管理に
  重点を置くと報じ、越境案件は**貸し倒れに備えた保全比率が低位**にとどまる点が課題とされる
  （→[01の第7章](01_地銀のビジネスモデルと苦境.md)）

加えて、金融庁自身が**生成AIを使って監督・市場監視を高度化する**方針も示されている。

## 8. 地域経済の足元 ―― 倒産は12年ぶりの高水準

貸出先の側の数字も押さえておきたい（東京商工リサーチ集計）。

| 指標 | 2026年上半期（1〜6月） | 前年同期比 |
| --- | --- | --- |
| 全国企業倒産（負債1,000万円以上） | 5,346件。上半期で5,000件超は2014年以来12年ぶり | ＋7.1% |
| うち「人手不足」倒産 | 237件。2013年の調査開始以降で最多 | ＋37.7% |
| うち人件費高騰を要因とするもの | 120件 | ＋140.0%（2.4倍） |
| 「後継者難」倒産 | 264件 | ＋14.7% |

※2025年度（令和7年度）の全国企業倒産は1万505件。帝国データバンクの集計では
2026年上半期を5,335件としており、**集計基準が異なると件数も変わる**点に注意。

注目すべきは倒産の「理由の変質」である。かつての倒産は売上不振が中心だったが、
2026年の増加分は**人が採れない・人件費が払えない・後継者がいない**という、
景気が良くても起きる種類の倒産が押し上げている。
ゼロゼロ融資の後始末（→[03の第5章](03_地域経済との関係.md)）と重なり、
地銀から見れば**金利で利ざやが取れるようになった一方、貸出先そのものが減っていく**という
構図が続いている。金利上昇は借り手の返済負担も押し上げるため、与信費用の行方も論点になる。

## 9. 生成AIの実装段階入り

2026年は、地域金融でのAI活用が「実証」から「全店展開」に移った時期として語られることが多い。

金融庁のAI関連会合資料（2025年6月）では回答事業者の9割超が従来型AIまたは生成AIを業務に使うと示され、
金融庁自身も顧客接点での活用を後押しして地銀と実証実験を行っていると報じられる。
個別行では**融資稟議書のドラフト作成**をAIで内製し全店展開した例（宮崎銀行、2024年4月開始・同年12月全店と報じられる）、
議事録要約や文案作成の効率化、顧客情報を使った提案チャットボットの開発などが公表されている。

効きどころは**人件費ではなく時間**である。地銀は店舗と人員の削減余地を長年削ってきており、
ここから先は「同じ人数で融資・事業承継提案にどれだけ時間を割けるか」が勝負になる。
稟議や議事録の時間を減らし、その分を[03](03_地域経済との関係.md)で見た事業性評価や
事業承継支援に回す、というのが各行の説明の型である。

## 10. 全体の構図（まとめ）

1. **金利上昇は「時間差の利益」をもたらした**。貸出金利が先に上がり、預金金利が後から追う。上場地銀の純利益は2026年3月期に1兆7,118億円で2期連続の最高益（報道ベース）。
2. **中身は二極化している**。ROE5%未満が34行、PBR1倍超は約3割（2026年）。変動金利貸出の厚み・預金の粘着性・債券を入れ替える余力の差が効いている。
3. **次の戦線は調達側**。預金残高が前年割れする行が出ており、金利で引き止めれば利ざやが縮む。
4. **制度は再編を後押しする方向で整った**。改正金融機能強化法（2026年6月施行）で公的資本参加が事実上恒久化し、資金交付は2031年3月末まで延長、システム共同化の支援枠も新設。
5. **当局は同時にブレーキも踏む**。不動産融資・越境融資・超長期住宅ローン・流動性が2026事務年度の重点点検項目。「地域に資金を回せ」と「背伸びするな」が並走している。

## 11. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **無担保コールレート（翌日物）** | 銀行どうしが1日だけ資金を貸し借りする金利。日銀の政策金利の操作目標 |
| **短プラ（短期プライムレート）** | 銀行が優良企業に1年以内で貸す際の基準金利。中小企業向け変動金利貸出の多くがこれに連動する |
| **コア業務純益** | 業務粗利益 − 経費（債券売買損益を除く）。本業の稼ぐ力 → [01](01_地銀のビジネスモデルと苦境.md) |
| **ROE（自己資本利益率）** | 純利益 ÷ 自己資本。株主の出したお金をどれだけ効率よく利益に変えたか |
| **PBR（株価純資産倍率）** | 株価 ÷ 1株あたり純資産。1倍割れは「解散した方が価値が高い」と市場に見られている状態 |
| **政策保有株（持ち合い株）** | 取引関係の維持を目的に保有する取引先の株式。資本効率の観点から縮減が求められている |
| **損切り** | 含み損のある資産を売って損失を確定させること。高い利回りの資産に入れ替えるために行う |
| **資金交付制度** | 再編に取り組む地域金融機関に対し、統合に要する費用の一部を国が交付する制度。2031年3月末まで延長された |
| **資本参加制度** | 金融機能強化法に基づき、国（預金保険機構）が優先株等の形で資本を入れる制度。2026年改正で申請期限が「当分の間」となった |
| **保全比率** | 貸出のうち担保・保証でカバーされている割合。低いほど焦げ付いたときの損失が大きい |
| **金融行政方針** | 金融庁が事務年度（7月〜翌年6月）ごとに公表する、重点的に取り組む監督テーマの方針 |
| **後継者難倒産** | 経営者の死亡・引退などで後継者が不在となったことが一因の倒産。業績不振とは別の理由で起きる |
