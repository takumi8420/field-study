地銀のビジネスモデルと苦境

金融地方銀行

このノートで分かること：地方銀行が「何で食べているか」と、その食い扶持がなぜ細ってきたのか。
第一地銀・第二地銀・信用金庫・信用組合の違いも、ここで整理する。

1. まず結論：集めた預金を地元に貸せなくなった

地方銀行（地銀）は、地域の家計から預金を集め、地元の中小企業と個人に貸す銀行である。
儲けの源は、貸出金利と預金金利の差（＝利ざや）。ここまではメガバンクと同じで、
基礎の仕組みは メガバンク に譲る。

地銀固有の問題は、営業エリアが都道府県単位に事実上固定されていることから来る。

ポイント：人口が減ると企業数が減り、貸出先が減る。
ところが預金は減らない。高齢者が相続や年金で積み上げた残高がそのまま残るからだ。
結果、「貸せない預金」が銀行の中に溜まり、運用先を探して有価証券に回る。
これが地銀の苦境の出発点である。

       【人口が増えていた時代】            【人口が減る時代】

  家計 ──預金──▶ 地銀 ──貸出──▶ 企業    家計 ──預金──▶ 地銀 ──貸出─▶ 企業
   増                増        増          横ばい            細る       減る
                                                              │
                                                              ▼
                                                     余った資金は有価証券へ
                                                   （国債・外債・投信・REIT）
                                                              │
                                                              ▼

                                                     銀行が丸ごと引き受ける

2. 銀行の儲けを3行で

地銀の損益計算書は、慣れるとほぼこの形に分解できる。

収益・費用 中身 地銀での位置づけ
資金利益貸出金利息＋有価証券利息 − 預金利息本業。地銀の業務粗利益の7〜8割を占めるのが一般的
役務取引等利益投資信託・保険の販売手数料、為替手数料、M&A仲介料などいわゆる「手数料ビジネス」。増やしたいが伸び悩む行が多い
経費（OHR）人件費＋物件費（店舗・システム）＋税金店舗網と勘定系システムが重く、固定費化しやすい
与信費用貸したカネが返らない見込み分の引当・損失景気と地元企業の体力次第で跳ねる

この4つから、コア業務純益 ＝ 業務粗利益 − 経費（国債等売買損益を除いた本業利益）を見るのが定石。
「最終利益は過去最高でも、コア業務純益は横ばい」という決算は珍しくなく、
本業の実力と、有価証券の売買益・損失処理を分けて見る必要がある。

3. 「地銀」と一口に言うが、四つの層がある

日本の地域金融機関は、根拠となる法律と組織形態で層が分かれている。
名前が似ていて紛らわしいので、ここを押さえると報道が一気に読めるようになる。

層 根拠法・形態 行数・数（2026年時点） 特徴
第一地銀（地銀）銀行法・株式会社。全国地方銀行協会（地銀協）加盟61行各県のトップ行が中心。県庁所在地に本店、指定金融機関（自治体の出納業務）を担うことが多い
第二地銀銀行法・株式会社。第二地方銀行協会加盟35行前身は相互銀行（さらに前は無尽会社）。1989年前後に普通銀行へ転換。規模が小さく、第一地銀より小口・高金利先が多い
信用金庫（信金）信用金庫法・協同組織（会員制）約250金庫営利目的ではなく会員（地域の中小企業・住民）の相互扶助。会員資格に従業員300人以下等の制限。営業区域が法律で限定
信用組合（信組）中小企業等協同組合法・協同組織（組合員制）約140組合信金よりさらに小規模・限定的。原則として組合員以外への貸出ができない

※行数・金庫数は各協会公表ベース。再編で毎年動くので、最新は
全国地方銀行協会 ・
第二地方銀行協会 ・信金中央金庫 で確認する。

株式会社か協同組織かは決定的な違いを生む。株式会社である地銀は株主に配当と
株価で応え、増資で資本を調達できる代わりに再編圧力を受ける。協同組織の信金・信組は
株価がないため市場の圧力が弱く、代わりに外部からの資本調達手段が乏しい。

  規模・広域性
    大 ┃  メガバンク（全国＋海外）
       ┃      ↑ 都市部で地銀と競合
       ┃  第一地銀（県内トップ、中堅企業まで）
       ┃      ↑↓ 同一県内で正面衝突しがち
       ┃  第二地銀（県内、小口・高金利先が厚い）
       ┃      ↑↓ 顧客層が重なる
       ┃  信用金庫（市町村単位、小規模事業者・個人）
    小 ┃  信用組合（さらに限定。業域・職域型もある）
       ┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━▶ 顧客の規模

境界は固定ではない。優良な中小企業には、地銀・第二地銀・信金が同時に営業をかける。
これが地元での金利競争を生み、利ざやを削ってきた最大の要因である。

4. 預貸率 ―― 苦境を一発で表す指標

預貸率 ＝ 貸出金 ÷ 預金。集めた預金のうち何％を貸出に回せているかを示す。

  • 1990年代には地銀でも90%前後あったが、過去20年ほど低下が続いた
  • 2023年ごろを底に反転し、2026年1〜3月期には73.9%→75.8%へ1.8ポイント上昇（日本総研の集計）

なぜ下がり続けたのか。理由は3つに分けられる。

  1. 借り手が減った。地方の事業所数・企業数が減り、後継者不在の廃業も進んだ
  2. 借り手が借りなくなった。手元資金が厚い中小企業は設備投資に慎重で、無借金化が進んだ
  3. 預金だけが残った。高齢化した地域では、年金・相続・退職金が預金として滞留する

反転した理由も併せて押さえておきたい。ゼロゼロ融資（コロナ期の実質無利子・無担保融資）
の残高、都市部への越境融資、そして不動産向け・事業承継向け貸出が押し上げている。
ただし越境融資は後述のとおり別のリスクを伴う。

  預貸率＝貸出÷預金

  100% ┤
       │  ＼
   90% ┤    ＼ 1990年代
       │      ＼
   80% ┤        ＼＿＿＿
       │              ＼＿＿＿＿＿＿＿      ／ ← 2023年ごろ反転
   70% ┤                            ＼＿＿／    （利上げ・越境融資・不動産向け）
       └──────────────────────────────────────▶
        1995      2005      2015      2025

5. 余った資金はどこへ行ったか ―― 有価証券運用への依存

貸せない預金は、有価証券ポートフォリオ（国債、地方債、社債、外国債券、投資信託、REIT等）
に回される。低金利期には日本国債の利回りがほぼゼロだったため、多くの地銀が
より高い利回りを求めて外国債券や投資信託へ踏み込んだ。

ここに二重の危うさがある。

リスクの種類 何が起きるか 地銀にとっての意味
金利リスク市場金利が上がると、既に保有する低利回り債券の価格が下がる含み損が発生。売れば損失確定、持ち続ければ低い利回りに資金が縛られる
為替リスク外債は円高で円換算の価値が減る。為替ヘッジには調達コストがかかるドル金利が高いとヘッジコストが利回りを食い、「ヘッジ付き外債」が逆ざやになる
信用リスク社債・証券化商品の発行体が傷む本業の地元融資とは別の損失源
集中リスク同じ商品を多くの地銀が同時に持つ相場が崩れると各行が同時に売りに回り、損失が拡大しやすい

日本経済新聞は2025年11月、地銀の国内債の含み損が前年の約2倍となる約3兆円に達し、
上位行は損切り（売却して損失を確定させ、高い利回りの債券に入れ替える）を進める一方、
下位行にリスクが残ると報じた。金利上昇は貸出には追い風だが、すでに抱えた債券には向かい風になる。

  金利が上がると、地銀の中で逆向きの力が働く

   ＋ 追い風                          − 向かい風
   ┌──────────────┐              ┌──────────────┐
   │ 貸出金利が上がる │              │ 保有債券の価格が │
   │ → 利ざや拡大    │              │ 下がる→含み損   │
   └──────────────┘              └──────────────┘
          ▲                                  ▲
          │                                  │
   短期で効く（変動金利貸出）        既往の長期債に直撃
          │                                  │
   ┌──────────────┐              ┌──────────────┐
   │ 預金金利も上げる │              │ 借り手の返済負担 │
   │ 必要 → 一部相殺 │              │ 増→与信費用増  │
   └──────────────┘              └──────────────┘

どちらが勝つかは、貸出のうち変動金利がどれだけあるか、債券の平均残存年限が何年か、
預金金利をどれだけ上げずに済むか（＝顧客基盤の粘着性）で決まる。
同じ「金利上昇」でも行ごとに損得が分かれるのは、この3点の差による。

7. 越境融資 ―― 苦境の解であり、新しいリスク

地元で貸せないなら、東京・大阪・名古屋で貸す。これが越境融資である。
都市部の再開発、物流施設、大型マンション、大企業向けシンジケートローンなどが主な対象で、
金融庁の資料によれば残高ベースで地元向けを上回る水準（55.5%）に達している。

ただし、以下の点が繰り返し指摘されている。

  • 新規開拓のため、金利・担保条件が緩くなりやすい（＝価格競争に負けて引き受ける）
  • 取引が浅く、借り手の実態が見えにくいため与信管理が難しい
  • 1社あたりの金額が大きく、焦げ付いたときの損失が一気に効く
  • 地元への資金還流が減り、「地域金融機関」としての存在意義が問われる

金融庁は2025年末以降、地銀の不動産融資の監視と越境リスク管理に重点を置く方針と報じられている。

8. 何が勝敗を分けるか（KSF）

論点 強い行の特徴
顧客基盤の粘着性給与振込・年金受取・公金口座を押さえ、金利を上げなくても預金が逃げない
経費率（OHR）店舗の統廃合と勘定系の共同利用でコストを落としている → 再編と生き残り策
非金利収益事業承継・M&A・人材紹介など、貸出以外の手数料が積み上がっている
有価証券の入れ替え力損切りできるだけの利益余力と資本がある
目利き力担保・保証に頼らず事業を評価して貸せる → 地域経済との関係

9. 用語メモ

用語 意味
利ざや（預貸利ざや）貸出金利回り − 預金等利回り。銀行の本業の粗利率にあたる
預貸率貸出金 ÷ 預金。集めた預金をどれだけ貸出に回せているか
コア業務純益業務粗利益 − 経費（国債等債券売買損益を除く）。本業の稼ぐ力
OHR（経費率）経費 ÷ 業務粗利益。低いほど筋肉質。地銀では60〜80%台が多い
与信費用貸倒引当金の繰入や貸倒損失。「将来返ってこないかもしれない分」の費用計上
含み損保有資産の時価が取得原価を下回っている状態。売らなければ損益計算書には出ないが、資本の実質的な目減りとして見られる
越境融資本店のある都道府県外への貸出。多くは大都市圏の不動産・大企業向け
第二地銀第二地方銀行協会に加盟する銀行。前身は相互銀行。第一地銀より小規模
信用金庫・信用組合株式会社ではなく協同組織の地域金融機関。会員・組合員の相互扶助が目的で、営業区域と取引先が法律で限定される
指定金融機関自治体の公金の収納・支払を担う銀行。県内トップの地銀が指定されることが多く、地域での信用の裏づけになる
