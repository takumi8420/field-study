# 消費者金融

- 大分類: 金融
- 状態: done
- 更新日: 2026-09-20

**一言でいうと**：担保も保証人も取らずに個人へ少額を貸し、**年15〜18%という高い金利で貸倒を吸収する**商売。
2006年の最高裁判決と貸金業法改正（過払い金返還＋総量規制）で市場が縮み、大手は破綻か銀行傘下入りとなった。
現在は**銀行グループの一部門**として、自前の貸付（4兆7,600億円）より**銀行カードローンの保証（6兆8,799億円）**
のほうが大きい、という姿になっている（いずれも2026年2月、日本貸金業協会）。

> このフォルダは制度と業界構造の解説であり、**借入を勧めるものではなく、特定の貸金業者を推奨するものでもない**。
> 金利負担と多重債務のリスクは事実として扱い、制度の観点から説明している。
> 返済に困ったときの公的な相談先は [② 第7章](02_グレーゾーン金利と総量規制.md) と [④ 第8章](04_直近トピック_2026.md) に記載。

## 1. 業界の定義・範囲

法律上「消費者金融業」という業態区分はない。**貸金業法に基づく登録を受けた貸金業者のうち、
個人向けの無担保・無保証貸付を主業とする事業者**を実務上そう呼ぶ。
日本貸金業協会の統計では「消費者金融業態」として、クレジット業態等・事業者金融業態と区別して集計される。

| 区別する相手                                                                                     | 境界                                                                                              |
| ------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------- |
| [クレジットカード・決済](../11_クレジットカード・決済/README.md)                                 | 根拠法が割賦販売法（ショッピング）。ただしキャッシングは貸金業法の世界なので重なる                |
| [メガバンク](../01_メガバンク/README.md)・[地方銀行](../02_地方銀行/README.md)の**カードローン** | 銀行法で営業するため総量規制がかからない。ただし**審査と保証は消費者金融子会社が担う**ことが多い  |
| [リース](../10_リース/README.md)                                                                 | 物の賃貸借。金銭の貸付ではない                                                                    |
| 事業者金融・ビジネスローン                                                                       | 同じ貸金業法だが相手が法人・個人事業主。総量規制は個人向けの規制                                  |
| [政府系金融](../15_政府系金融/README.md)                                                         | 政策目的の資金供給。利益最大化が目的ではない                                                      |
| BNPL（後払い決済）                                                                               | 支払期間2か月以内なら割賦販売法の対象外。貸金業でもない → [③ 第5章](03_現在の姿と周辺サービス.md) |
| ヤミ金融・SNS個人間融資                                                                          | **無登録営業＝違法**。業界の外側にある犯罪類型 → [② 第7章](02_グレーゾーン金利と総量規制.md)      |

**このフォルダで扱う範囲**：消費者向け無担保貸付を軸に、そこから派生した①信用保証事業
②事業者向け貸付 ③海外（アジア）の消費者金融まで。同じ会社の収益構造として一体だからである。

## 2. 市場規模と成長性

| 指標                                   | 数値                      | 時点・出典                                 |
| -------------------------------------- | ------------------------- | ------------------------------------------ |
| 消費者向無担保貸付 残高（3業態計）     | **4兆7,600億円**（+6.9%） | 2026年2月、日本貸金業協会 月次統計（速報） |
| うち消費者金融業態13社                 | 3兆68億円（+9.4%）        | 同上                                       |
| うちクレジット業態等                   | 1兆7,531億円（+2.9%）     | 同上                                       |
| **金融機関向け信用保証残高（無担保）** | **6兆8,799億円**（+7.8%） | 同上                                       |
| 総貸付残高（事業者向け含む）           | 15兆1,599億円（+13.6%）   | 同上                                       |
| 平均約定金利（消費者向無担保）         | 15.11%                    | 同上                                       |
| 月間契約件数                           | 97万9,692件（+14.5%）     | 同上                                       |
| 登録貸金業者数                         | 1,436社（▲45社）          | 2026年2月末、金融庁公表値                  |
| （参考）ピーク時の登録業者数           | **47,504社**              | 1986年度末、金融庁 貸金業関係資料集        |

成長の見方が独特で、**「景気」より「制度」で決まる**。

- 2000年代半ばのピーク期には業界全体で10兆円を超えたとされる（推計・報道ベース）残高が、
  2006年の法改正で3兆円前後まで縮小した
- そこから緩やかに回復し、2026年2月は4兆7,600億円（+6.9%）と増加局面にある
- ただし**自前の貸付より保証残高のほうが大きい**（6兆8,799億円）。市場を測るときは両方を見る必要がある
- 事業者向けが急伸（その他営業貸付+24.3%）しており、総貸付残高は+13.6%と二桁の伸び

## 3. バリューチェーン（お金の流れ）

```
【消費者金融のバリューチェーン】

 ＜調達＞                 ＜審査＞               ＜貸付／保証＞          ＜回収＞
  銀行借入 ─┐                                 ┌─ ① 自前で貸す ──▶ 受取利息（15%前後）
  社債・CP ─┼─▶ 資金 ─▶ スコアリング ─▶ │    （BSに載る／貸倒は自社）
  親銀行   ─┘            ＋信用情報照会      │
  （MUFG/SMFG/SBI新生）    （JICC・CIC）      └─ ② 銀行を保証 ──▶ 保証料
                             │                   （BSに載らない／代位弁済）
                             │
                        **ここが付加価値の源泉**
                        「誰が返さないか」を当てる能力
                             │
                             └─▶ ③ 海外（タイ等）へ横展開

 ＜回収＞ 約定返済 → 初期延滞 → 長期延滞 → 債務整理／償却
          （取立行為は貸金業法21条で厳格に規制）
```

付加価値が集まるのは**「与信の目利き」**の一点である。
それを自前の貸付で使うか（①）、銀行に売るか（②）、海外に持っていくか（③）の違いにすぎない。
詳細は [① 無担保で貸す商売の経済](01_無担保で貸す商売の経済.md)。

## 5. 収益モデル・コスト構造

```
【貸付残高100あたり・年間（概算モデル／実績は各社で大きく異なる）】

  受取利息                    ＋15.1   ← 平均約定金利15.11%（2026年2月）
  − 調達コスト                 1〜3    ← 自分で借りてくる。政策金利に連動
  − **貸倒（与信費用）**        3〜5    ← これを吸収するための高金利
  − 広告宣伝費                 1〜2
  − 人件費・システム等          4〜6
  − 利息返還損失引当金          α      ← 過払い金。2026年は縮小局面
  ──────────────────────
  ＝ 営業利益                  2〜5
```

| 指標                   | 意味                       | 目安                                                           |
| ---------------------- | -------------------------- | -------------------------------------------------------------- |
| **平均約定金利**       | 契約金利の加重平均         | 15.11%（3業態計）／15.38%（消費者金融業態）＝2026年2月         |
| **成約率**             | 申込のうち契約に至った割合 | 32.1%（消費者金融業態、2026年2月）＝申込の3分の2は通らない     |
| **与信費用率**         | 貸倒関連費用 ÷ 貸付残高    | 各社開示で概ね数%台。ここが2ポイント動くと利益が半減する感応度 |
| **1件あたり平均残高**  | 貸付残高 ÷ 有残件数        | 消費者金融業態で約48万円（2026年2月、筆者算出）                |
| **保証残高／貸付残高** | 保証事業の比重             | 6兆8,799億円 ÷ 4兆7,600億円 ＝ **1.45倍**                      |

コスト構造の要点は、**金利の上限が法律で固定されていること**。
値上げができないので、利益を作る手段は「貸倒を減らす（審査）」「経費を減らす（店舗をやめる）」
「残高を増やす」の3つに限られる。無人店舗が1年で4割減った（2026年2月、前年同月比▲40.3%）のは、
2つ目の帰結である。

## 6. 競争要因（KSF）と参入障壁

| 優位の源泉                     | 中身                                                               | 真似しにくさ |
| ------------------------------ | ------------------------------------------------------------------ | ------------ |
| **与信データの蓄積**           | 自社の貸倒履歴がスコアリング精度を決める。新規参入は白紙から始まる | ★★★          |
| **親銀行グループの調達力**     | 預金を持てない業態にとって調達コストは死活問題                     | ★★★          |
| **保証提携のネットワーク**     | 銀行との提携は一度組むと長期。乗り換えコストが高い                 | ★★★          |
| **登録・コンプライアンス体制** | 純資産5,000万円以上、貸金業務取扱主任者、取立規制、苦情処理        | ★★           |
| **ブランド認知と広告**         | 新規獲得は広告依存。全国規模の広告費を賄える残高が要る             | ★★           |
| **アプリのUXと審査速度**       | 最短即日・Web完結・カードレス。差別化はしにくいが遅れると致命的    | ★            |

参入障壁は**貸金業の登録**そのものより、**与信データと調達力**にある。
ピーク時47,504社（1986年度末）→1,436社（2026年2月末）という約33分の1への減少は、
規制強化と規模の経済が同時に効いた結果である。

## 7. 規制・法制度

| 制度                             | 中身                                                                         | 効き方                                                                     |
| -------------------------------- | ---------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| **利息制限法**                   | 民事上の上限金利。10万円未満20%／10万〜100万円未満18%／100万円以上15%        | 超過部分は無効。過払い金の根拠                                             |
| **出資法**                       | 刑事罰の上限。**2010年6月から年20%**                                         | グレーゾーン金利を消滅させた                                               |
| **貸金業法**                     | 登録制、返済能力調査義務、書面交付、取立規制（21条）、広告規制               | 業界の基本法                                                               |
| **総量規制**（貸金業法）         | 個人の借入総額を**年収の3分の1**まで（2010年6月〜）                          | 除外（住宅・自動車ローン等）と例外（借換え・配偶者貸付・個人事業者等）あり |
| **指定信用情報機関制度**         | JICC・CICへの加入と照会を義務化                                              | 総量規制を機能させる装置。FINEで残高情報を相互交流                         |
| **銀行法**                       | 銀行カードローンの根拠法。**総量規制はかからない**                           | 2017年の全銀協申し合わせ以降、各行が自主規制（年収の3分の1〜2分の1目安）   |
| **割賦販売法**                   | クレジット・後払いの業法。支払期間2か月超で適用                              | **BNPLの多くは適用外**。規制の空白                                         |
| **貸金業務取扱主任者**           | 国家資格。営業所ごとに設置義務                                               | 2006年改正での参入要件の柱                                                 |
| **（検討中）貸金業法の抜本改正** | 2026年夏に金融審議会で議論開始、2027年通常国会に法案提出を目指すと報じられる | 主眼は**法人向け規制の柔軟化**。個人向けの保護は維持する方向               |

詳細は [② グレーゾーン金利と総量規制](02_グレーゾーン金利と総量規制.md)。

## 8. 最近のトピック

詳細は [④ 直近トピック（2026年9月時点）](04_直近トピック_2026.md)。要点は5つ。

1. **貸金業法が約20年ぶりに本格改正へ**（2026年4月8日、時事通信）。2026年夏に金融審議会で議論開始、
   2027年通常国会への提出を目指す。主眼は法人向け規制の柔軟化で、個人の保護は維持の方向
2. **アイフルが持株会社ムニノバホールディングスへ移行**（2026年4月1日）。アイフル株は2026年3月30日に上場廃止
3. **残高は回復局面**。消費者向無担保4兆7,600億円（+6.9%）、月間契約件数+14.5%。
   事業者向けが牽引し総貸付残高は15兆1,599億円（+13.6%）
4. **過払い金返還は最終局面**。月間の利息返還金29億円（▲37.6%）。
   アコムの2026年3月期営業利益は1,003億円（+71.4%）と報じられ、営業貸付金は1兆円台へ
5. **無人店舗が1年で4割減**（▲40.3%）。アプリ完結が標準化。一方で成約率は32.1%と審査は緩んでいない
