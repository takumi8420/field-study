# 現在の姿と周辺サービス

このノートで分かること：いまの消費者金融は「**銀行グループの一部門であり、主力は自前の貸付ではなく
銀行カードローンの保証業務**」という姿になっている。そこに海外（アジア）とアプリ完結が加わり、
外側からはBNPL（後払い決済）とファクタリング・給与前払いが接近している。

> ポイント：2026年2月時点で、業界の**信用保証残高6兆8,799億円は自前の消費者向無担保貸付残高4兆7,600億円を
> 上回っている**（日本貸金業協会 月次統計）。「消費者金融は自分で貸す商売」という理解は、もう半分しか正しくない。

※ このノートは業界構造の解説であり、借入を勧めるものではない。特定の事業者の推奨も行わない。

## 1. 大手4ブランドと資本関係

2006年の法改正と過払い金返還で資本を失った業界を、銀行が買った（→ [② 法改正](02_グレーゾーン金利と総量規制.md) 第5章）。
その結果が現在の勢力図である。

| ブランド     | 運営会社                                                                     | 資本関係                                                 | 特徴                                                                       |
| ------------ | ---------------------------------------------------------------------------- | -------------------------------------------------------- | -------------------------------------------------------------------------- |
| **アコム**   | アコム株式会社（東証プライム）                                               | **三菱UFJフィナンシャル・グループの連結子会社**          | 業界最大級。三菱UFJ銀行カードローンの保証も担う。タイのEASY BUYが海外の柱  |
| **プロミス** | SMBCコンシューマーファイナンス                                               | **三井住友フィナンシャルグループの完全子会社**（非上場） | 保証事業を早くから拡大。地銀との共同コールセンター運営                     |
| **アイフル** | アイフル株式会社 → **ムニノバホールディングス**（2026年4月1日 持株会社移行） | 独立系（メガバンク系列に属さない）                       | ライフカード等を傘下に持つ多角化グループ。2026年4月に持株会社化            |
| **レイク**   | 新生フィナンシャル                                                           | **SBI新生銀行グループ**                                  | 提携（保証）事業を主力の一つに。2026年3月末で金融機関30社・非金融1社と提携 |

```
     ├─ ライフカード（クレジットカード）
     └─ その他（事業者向け金融・海外 等）

  ＊「親銀行が貸し、子会社が保証する」構造がほぼ全社で共通
```

### アイフルの持株会社移行（2026年4月1日）

2025年5月に公表され、2026年4月1日に実行された。純粋持株会社**ムニノバホールディングス**を新設し、
傘下にアイフル、ライフカードなどを置く。アイフル株式会社は2026年3月30日に上場廃止となり、
持株会社が東証プライムに新規上場した。社長はアイフルの福田光秀氏が兼務すると報じられている。
狙いは**M&Aで多角化したグループの統制強化**（日本経済新聞・ニッキンONLINE、報道ベース）。

## 2. 収益の三本柱

| 事業                       | 何をしているか                           | 収益の性格                 | リスクの持ち主                                       |
| -------------------------- | ---------------------------------------- | -------------------------- | ---------------------------------------------------- |
| **① 無担保ローン（自前）** | 自社ブランドで個人に貸す                 | 受取利息（年15%前後）      | **自社**（貸倒を全部かぶる）                         |
| **② 信用保証**             | 銀行カードローンの審査・保証を引き受ける | 保証料収入                 | **自社**（代位弁済する）。ただし貸出資金は銀行が出す |
| **③ 海外**                 | アジアの現地法人で無担保ローン           | 受取利息（国内より高金利） | 現地法人。為替と国別の規制                           |

加えて、事業者向け貸付（ビジネスローン）、債権買取・サービサー、クレジットカードなどを
グループで持つ会社が多い（アイフル＝ライフカード、アコム＝マスターカードのイシュアー業務など）。

```
【① 自前 と ② 保証 の違い】

〈① 自前で貸す〉
  自社が調達 ──▶ 自社が貸す ──▶ 受取利息15% を丸取り
      │                              └ 貸倒も丸かぶり
      └ バランスシート（BS）に残高が載る＝自己資本が要る

〈② 銀行カードローンを保証する〉
  銀行が調達 ──▶ **銀行が貸す**（金利1.5〜14.5%程度）
      │                    │
      │              保証料を払う
      ▼                    ▼
  BSに貸付金は載らない  自社が審査・保証（代位弁済）
      └ 資本効率が高い。ただし取り分は保証料のみ

  → **同じ「審査して回収する」能力を、2つの売り方で回している**
```

> ここが現在の業界の核心：**貸倒の目利きという能力を、銀行に外販している**。
> 銀行は総量規制の外側で個人に貸せる（→ ② 第6章）が、無担保の与信ノウハウを自前では持たない。
> その不足を消費者金融が埋める、という分業が成立している。

## 3. 数字で見る「保証のほうが大きい」

| 指標（3業態計）                              | 2026年2月        | 前年同月比 |
| -------------------------------------------- | ---------------- | ---------- |
| 消費者向無担保貸付 残高（自前）              | 4兆7,600億円     | +6.9%      |
| **金融機関の無担保貸付に対する信用保証残高** | **6兆8,799億円** | **+7.8%**  |
| 同 保証件数                                  | 755万件          | +2.3%      |

出典：日本貸金業協会 月次統計（2026年2月度実績・速報値、調査協力47社）。
※保証残高の「無担保貸付」にはカードローンのほか教育ローン・自動車ローン等も含む。

個社でも同じ傾向が確認できる。SMBCコンシューマーファイナンスは保証提携先186先・保証残高1兆1,022億円
（2021年3月末、SMBCグループ二十年史）と早くから保証を主力化しており、
新生フィナンシャルも提携事業を事業の柱として明示している（金融機関30社・非金融事業者1社、2026年3月31日時点）。

## 4. チャネルの激変 ── 無人契約機からアプリへ

かつてこの業界の象徴は、駅前の**無人契約機**（自動契約機）だった。いまその店舗は急速に消えている。

| 店舗数（日本貸金業協会 月次統計、3業態計） | 2026年2月 | 前年同月  | 前年同月比 |
| ------------------------------------------ | --------- | --------- | ---------- |
| 有人店舗                                   | 480       | 526       | ▲8.7%      |
| **無人店舗**                               | **1,369** | **2,292** | **▲40.3%** |
| （うち消費者金融業態）有人                 | 106       | 101       | +5.0%      |
| （うち消費者金融業態）**無人**             | **1,077** | **1,966** | **▲45.2%** |

```
【契約チャネルの移行】

 〈2000年代〉                     〈2026年〉
  テレビCM                         Web広告・比較サイト・アプリストア
     ▼                                ▼
  駅前の無人契約機                  スマホアプリ／Webサイト
   ・免許証を機械に通す              ・eKYC（オンライン本人確認）
   ・カードがその場で出る            ・カードレス／郵送物なし
   ・設置と保守に固定費               ・振込 or スマホ決済に直接入金
     ▼                                ▼
  店舗網＝参入障壁                  **店舗網＝重荷**
                                    アプリのUXと審査速度が競争軸

  無人店舗数：2,292（2025年2月）→ 1,369（2026年2月）▲40.3%
```

無人契約機は**固定費**である。残高が伸びない局面ではこの固定費が重く、
eKYCと電子契約が実用化された時点で一気に不要になった。
「最短即日」「Web完結」「カードレス」「郵送物なし」といった訴求は、この技術的前提の上に立っている。

一方で、**審査の厳しさ自体は緩んでいない**。成約率（申込のうち契約に至った割合）は
2026年2月の消費者金融業態で**32.1%**（同統計）。申込が簡単になった分、
「申し込んだが通らない」件数はむしろ増えている構造にある。

## 5. 外から近づいてくるもの ── BNPL・後払い決済

**BNPL（Buy Now, Pay Later＝いま買って後で払う）**は、EC決済の後払いサービスを指す。
日本では「◯◯あと払い」「ツケ払い」などの名前で普及した。
これが消費者金融の競合になるのは、**実質的に短期の与信でありながら、業法の枠外にあるから**である。

| 論点                     | 貸金業者の無担保ローン | クレジットカード（[→](../11_クレジットカード・決済/README.md)） | BNPL（2か月以内の後払い）                |
| ------------------------ | ---------------------- | --------------------------------------------------------------- | ---------------------------------------- |
| 根拠法                   | 貸金業法               | 割賦販売法                                                      | **原則として対象外**                     |
| 総量規制                 | あり（年収の3分の1）   | キャッシングはあり／ショッピング枠はなし                        | **なし**                                 |
| 指定信用情報機関への照会 | **義務**               | 義務（包括支払可能見込額の調査）                                | **義務なし**                             |
| 上限金利／手数料         | 年20%（出資法）        | 割賦手数料の規制あり                                            | 手数料は「遅延損害金」「事務手数料」の形 |
| 他社での利用が見えるか   | 見える                 | 見える                                                          | **見えない**                             |

割賦販売法は、**購入から支払完了までの期間が2か月を超える**場合に適用されるのが基本線である
（翌月一括払いと同じ扱いになる2か月以内は対象外）。
多くのBNPLはこの2か月以内に収まるよう設計されているため、登録も与信調査義務もかからない。

```
【「見えない負債」が生まれる構造】

  Aさんの実際の負債
  ┌────────────────────────────┐
  │ 消費者金融     50万円  → JICC/CICに登録 ✔    │← 総量規制の計算に入る
  │ カードのキャッシング 20万円 → 登録 ✔         │← 入る
  │ 銀行カードローン  60万円 → KSCに登録         │← **貸金業者の計算には入らない**
  │ BNPL（後払い）    8万円 → **どこにも載らない** │← 誰も把握していない
  └────────────────────────────┘
                  ▲
        貸し手が見ている範囲はここまで
        → 返済能力の評価が実態から乖離しうる
```

2026年時点でBNPLを直接規制する法律はなく、消費者委員会や金融審議会で議論が続いている段階である
（日本経済新聞 2026年6月「後払い決済、法規制なし」ほか、報道・解説ベース）。
業界団体（日本BNPL協会）による自主的な取組みと並行して制度整備が検討されている。

## 6. ファクタリング・給与前払いという周辺領域

「借金ではない」という形式をとりながら、経済的には前借りに近いサービス群がある。
ここは**適法なものと違法なものが混在している**ため、区別が要る。

| サービス                     | 中身                                                                           | 法的な位置づけ（2026年時点）                                                                   |
| ---------------------------- | ------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------- |
| **事業者向けファクタリング** | 企業が売掛債権を割り引いて売却し、入金を早める                                 | 真正な債権譲渡であれば適法。登録制はまだ導入されていない                                       |
| **給与前払いサービス**       | 勤務先が福利厚生として、働いた分の給与を給料日前に支払う。事業者はシステム提供 | **雇用主が自社の賃金を前払いする**形なら貸付に当たらない（労働基準法25条の非常時払いの考え方） |
| **給与ファクタリング**       | 個人が将来の給与債権を業者に売る形をとる                                       | **2023年2月、最高裁第三小法廷が「貸付け」と判断**。無登録営業はヤミ金融                        |
| **後払い（ツケ払い）現金化** | 後払いで商品を買わせ、業者が即座に安値で買い取る                               | 実質は高金利の貸付。金融庁が注意喚起                                                           |
| **先払い買取現金化**         | 将来送る商品の代金を先に受け取り、送れなければ高額な違約金                     | 同上。金融庁が注意喚起                                                                         |

> 見分け方の軸は1つ：**「返す義務」が誰にあるか**。
> 個人が最終的に返済義務を負うなら、形式がどうであれ経済的には貸付である。
> 給与ファクタリングが最高裁で「貸付け」とされたのも、この実質論による。

## 7. 海外展開 ── アジアの無担保ローン

国内市場が制度によって縮小した2010年代、大手は**人口が増え、与信インフラがまだ薄いアジア**へ出た。
国内の上限金利20%に対し、現地の上限はより高い国が多く、利ざやが厚い。

| 会社                           | 主な進出先                                                                             | 内容                                                                                                  |
| ------------------------------ | -------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| アコム                         | **タイ**（EASY BUY）、フィリピン、マレーシア、ベトナム（ライセンス申請中と報じられる） | EASY BUYはタイのノンバンク無担保ローンで有力な地位。アコムの収益の一定割合を担うと報じられる          |
| アイフル                       | **タイ**（AIRA & AIFUL、「A Money」ブランド、2014年12月合弁設立）、インドネシア ほか   | 2024年3月末の貸付残高357億円・45店舗（同社開示）                                                      |
| SMBCコンシューマーファイナンス | 中国、タイ ほか（SMBCグループの海外戦略と一体）                                        | [三井住友FG](../01_メガバンク/02_メガバンクの稼ぎ方.md)のマルチフランチャイズ戦略の一部として位置づけ |

海外事業の難しさは3つ。**①カントリーリスク（規制が一夜で変わる）②現地の信用情報インフラが未整備
③為替**。とくに②は、日本国内で効いている「指定信用情報機関で他社借入が見える」という前提が
成り立たない国があり、貸倒率が国内より高く出やすい。

## 8. 誰が借りているのか（利用者像）

制度の説明として押さえておくべき点を、事実ベースで挙げる。

- 有残件数（残高のある口座）は3業態計で**1億1,812万件**（2026年2月）。ただしこれには
  キャッシング機能付きクレジットカードやローンカードの発行件数が含まれるため、
  **「1億人が借りている」という意味ではない**
- 消費者金融業態に限った有残件数は**619万7千件**（同月）
- 1件あたりの平均残高は、消費者金融業態で約48万円（3兆68億円 ÷ 619.7万件、筆者算出）
- 成約率は32.1%（同月）で、申込の約3分の2は契約に至らない
- 平均約定金利は消費者金融業態で年15.38%（同月）

> 金利負担の実感：年18%で50万円を借り、毎月1万5,000円ずつ返す場合、
> 完済まで約4年、支払総額は約70万円になる（単純計算）。
> **元本の4割相当が利息**という水準であり、これは制度上の上限内であっても重い負担である。
> だからこそ総量規制と上限金利が置かれている、という理解が制度を読む出発点になる。

## 9. 用語メモ

| 用語                         | 意味                                                                                              |
| ---------------------------- | ------------------------------------------------------------------------------------------------- |
| **信用保証（保証事業）**     | 銀行が貸した個人向けローンの返済を保証会社が引き受けること。消費者金融の主力収益                  |
| **保証料**  | 保証の対価。銀行が受け取る金利の一部が保証会社に回る形 |
| **代位弁済**                 | 借り手が返せなくなったとき、保証会社が銀行へ代わりに返済すること                                  |
| **無人契約機（自動契約機）** | 店頭で無人契約を完結させる機械。2020年代に急減                                                    |
| **eKYC**                     | オンライン完結の本人確認。アプリ完結の前提                                                        |
| **BNPL**                     | Buy Now, Pay Later。後払い決済。支払期間2か月以内なら割賦販売法の対象外                           |
| **割賦販売法**               | クレジット・後払いの業法。適用の分かれ目は「支払期間2か月超」                                     |
| **ファクタリング**           | 売掛債権を割り引いて売却し資金化すること。事業者向けは適法な取引類型                              |
| **給与ファクタリング**       | 個人の給与債権の買取を装った貸付。2023年2月の最高裁判決で「貸付け」と判断                         |
| **給与前払いサービス**       | 雇用主が働いた分の賃金を給料日前に支払う福利厚生。貸付とは別                                      |
| **イシュアー**               | クレジットカードを発行する会社 → [クレジットカード・決済](../11_クレジットカード・決済/README.md) |
