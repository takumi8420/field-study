消費者金融

学習済み更新 2026-09-20金融
あこのページの単語集用語に触れると意味を確認できます15語
無担保・無保証貸付利息制限法／出資法グレーゾーン金利みなし弁済過払い金／引き直し計算総量規制除外／例外指定信用情報機関（JICC・CIC）FINE／CRINスコアリング／成約率信用保証（保証事業）／代位弁済BNPL／割賦販売法給与ファクタリングヤミ金融／SNS個人間融資利息返還損失引当金

一言でいうと：担保も保証人も取らずに個人へ少額を貸し、年15〜18%という高い金利で貸倒を吸収する商売。
2006年の最高裁判決と貸金業法改正（過払い金返還＋総量規制）で市場が縮み、大手は破綻か銀行傘下入りとなった。
現在は銀行グループの一部門として、自前の貸付（4兆7,600億円）より銀行カードローンの保証（6兆8,799億円）
のほうが大きい、という姿になっている（いずれも2026年2月、日本貸金業協会）。

このフォルダは制度と業界構造の解説であり、借入を勧めるものではなく、特定の貸金業者を推奨するものでもない。
金利負担と多重債務のリスクは事実として扱い、制度の観点から説明している。
返済に困ったときの公的な相談先は ② 第7章 と ④ 第8章 に記載。

1. 業界の定義・範囲

法律上「消費者金融業」という業態区分はない。貸金業法に基づく登録を受けた貸金業者のうち、
個人向けの無担保・無保証貸付を主業とする事業者を実務上そう呼ぶ。
日本貸金業協会の統計では「消費者金融業態」として、クレジット業態等・事業者金融業態と区別して集計される。

区別する相手 境界
クレジットカード・決済根拠法が割賦販売法（ショッピング）。ただしキャッシングは貸金業法の世界なので重なる
メガバンク・地方銀行のカードローン銀行法で営業するため総量規制がかからない。ただし審査と保証は消費者金融子会社が担うことが多い
リース物の賃貸借。金銭の貸付ではない
事業者金融・ビジネスローン同じ貸金業法だが相手が法人・個人事業主。総量規制は個人向けの規制
政府系金融政策目的の資金供給。利益最大化が目的ではない
BNPL（後払い決済）支払期間2か月以内なら割賦販売法の対象外。貸金業でもない → ③ 第5章
ヤミ金融・SNS個人間融資無登録営業＝違法。業界の外側にある犯罪類型 → ② 第7章

このフォルダで扱う範囲：消費者向け無担保貸付を軸に、そこから派生した①信用保証事業
②事業者向け貸付 ③海外（アジア）の消費者金融まで。同じ会社の収益構造として一体だからである。

成長の見方が独特で、「景気」より「制度」で決まる。

  • 2000年代半ばのピーク期には業界全体で10兆円を超えたとされる（推計・報道ベース）残高が、
    2006年の法改正で3兆円前後まで縮小した
  • そこから緩やかに回復し、2026年2月は4兆7,600億円（+6.9%）と増加局面にある
  • ただし自前の貸付より保証残高のほうが大きい（6兆8,799億円）。市場を測るときは両方を見る必要がある
  • 事業者向けが急伸（その他営業貸付+24.3%）しており、総貸付残高は+13.6%と二桁の伸び

  親銀行   ─┘            ＋信用情報照会      │
  （MUFG/SMFG/SBI新生）    （JICC・CIC）      └─ ② 銀行を保証 ──▶ 保証料
                             │                   （BSに載らない／代位弁済）
                             │
                        **ここが付加価値の源泉**
                        「誰が返さないか」を当てる能力
                             │

 ＜回収＞ 約定返済 → 初期延滞 → 長期延滞 → 債務整理／償却

付加価値が集まるのは「与信の目利き」の一点である。
それを自前の貸付で使うか（①）、銀行に売るか（②）、海外に持っていくか（③）の違いにすぎない。
詳細は ① 無担保で貸す商売の経済。

コスト構造の要点は、金利の上限が法律で固定されていること。
値上げができないので、利益を作る手段は「貸倒を減らす（審査）」「経費を減らす（店舗をやめる）」
「残高を増やす」の3つに限られる。無人店舗が1年で4割減った（2026年2月、前年同月比▲40.3%）のは、
2つ目の帰結である。

規制強化と規模の経済が同時に効いた結果である。

7. 規制・法制度

制度 中身 効き方
利息制限法民事上の上限金利。10万円未満20%／10万〜100万円未満18%／100万円以上15%超過部分は無効。過払い金の根拠
出資法刑事罰の上限。2010年6月から年20%グレーゾーン金利を消滅させた
貸金業法登録制、返済能力調査義務、書面交付、取立規制（21条）、広告規制業界の基本法
総量規制（貸金業法）個人の借入総額を年収の3分の1まで（2010年6月〜）除外（住宅・自動車ローン等）と例外（借換え・配偶者貸付・個人事業者等）あり
指定信用情報機関制度JICC・CICへの加入と照会を義務化総量規制を機能させる装置。FINEで残高情報を相互交流
銀行法銀行カードローンの根拠法。総量規制はかからない2017年の全銀協申し合わせ以降、各行が自主規制（年収の3分の1〜2分の1目安）
割賦販売法クレジット・後払いの業法。支払期間2か月超で適用BNPLの多くは適用外。規制の空白
貸金業務取扱主任者国家資格。営業所ごとに設置義務2006年改正での参入要件の柱
（検討中）貸金業法の抜本改正2026年夏に金融審議会で議論開始、2027年通常国会に法案提出を目指すと報じられる主眼は法人向け規制の柔軟化。個人向けの保護は維持する方向

8. 最近のトピック

詳細は ④ 直近トピック（2026年9月時点）。要点は5つ。

  1. 貸金業法が約20年ぶりに本格改正へ（2026年4月8日、時事通信）。2026年夏に金融審議会で議論開始、
    2027年通常国会への提出を目指す。主眼は法人向け規制の柔軟化で、個人の保護は維持の方向
  2. アイフルが持株会社ムニノバホールディングスへ移行（2026年4月1日）。アイフル株は2026年3月30日に上場廃止
  3. 残高は回復局面。消費者向無担保4兆7,600億円（+6.9%）、月間契約件数+14.5%。
    事業者向けが牽引し総貸付残高は15兆1,599億円（+13.6%）
  4. 過払い金返還は最終局面。月間の利息返還金29億円（▲37.6%）。
    アコムの2026年3月期営業利益は1,003億円（+71.4%）と報じられ、営業貸付金は1兆円台へ
  5. 無人店舗が1年で4割減（▲40.3%）。アプリ完結が標準化。一方で成約率は32.1%と審査は緩んでいない
