# ② 事業としての暗号資産 ── 誰がどこで、いくら抜いているか

このノートで分かること：価格の話を一切せずに、**この業界の会社がどうやって売上を立てているか**。
交換業者（取引所）、マイニング、ステーブルコイン発行体、DeFi／NFT、機関投資家向けの5層に分けて見る。

> 結論を先に：暗号資産ビジネスの収益は、**価格そのものではなく「取引量」と「預り資産」**から生まれる。
> だから業界の売上は、値段の上下ではなく**人がどれだけ売買したか**に連動する。
> 値上がりしなくても売買が活発なら儲かり、高値で膠着すると儲からない。

      ▼

      ▼
 ┌────────────────┐   ┌────────────────────┐

      ▼

## 2. 交換業者（取引所） ── 手数料よりスプレッドで稼ぐ

国内の暗号資産交換業者は**金融庁の登録制**で、2026年9月1日時点で**27社**（金融庁 登録業者一覧）。
自主規制団体であるJVCEA（日本暗号資産等取引業協会）の会員社数は2026年9月時点で30社。

収益源は4つあり、**看板に出ている「取引手数料無料」は本当の収益源ではない**ことが重要。

| 収益源 | 中身 | 性格 |
| --- | --- | --- |
| **販売所のスプレッド** | 業者が提示する買値と売値の差。「手数料無料」でも、この差が実質の取り分 | **最大の収益源**。初心者ほどここを使う |
| **取引所（板取引）の売買手数料** | 利用者同士のマッチングに対する手数料。0.01〜0.15%程度が目安 | 薄い。玄人向け |
| **証拠金取引（レバレッジ）** | 建玉維持手数料（日歩）。国内はレバレッジ**2倍**が上限 | 値動きが大きいほど回転して稼げる |
| **レンディング・ステーキング代行** | 利用者の資産を貸し出す／預け入れる仲介の取り分 | 預り資産に比例するストック収益 |

```
【販売所と取引所の違い ＝ ここが収益の核心】

 販売所（業者が相手）        取引所（利用者同士）
   買いたい人 ──▶ 業者         買いたい人 ─┐
   ◀── 高めの価格で売る                   ├─ 板でマッチング
   売りたい人 ──▶ 業者         売りたい人 ─┘
   ◀── 安めの価格で買う           ↑ 業者は場所代（手数料）だけ
        ↑ この値差＝スプレッドが業者の粗利
```

SBIホールディングスの暗号資産事業セグメントは、**2026年3月期に収益896億円（前期比10.9%増）、税引前利益212億円**（同社IR）。
収益は伸びたが利益はほぼ横ばいで、**システム・セキュリティ・コンプライアンスの固定費が重い**構造が読み取れる。

> なぜ再編が起きるか：交換業は**固定費型**である。
> 24時間365日のシステム、コールドウォレット管理、監査、AML（マネロン対策）、規制対応の人員は、
> 口座が10万でも300万でもほぼ同じだけかかる。だから**規模が正義**になり、中小は続かない。

## 3. マイニング ── 実態は電力の裁定取引

PoWの計算競争に参加して報酬を得る事業（→ [技術の仕組み](01_技術の仕組み.md)）。
しかし中身を見ると、**安い電気を買って暗号資産に変換して売る**という変換装置であり、事業としては**電力事業に近い**。

```
【マイニング事業の損益】

  収入 = 採れた枚数 × 売却価格
         ↑ 枚数はネットワーク全体の計算力（ハッシュレート）に占める自分の割合で決まる
           ＝ 他社が設備を増やすと、自分は何もしなくても取り分が減る

  費用 ─ 電気代         60〜80%程度（事業の生死を決める）
        ─ 専用機（ASIC）の償却  数年で陳腐化
        ─ 立地・冷却・人件費

  ▶ 損益分岐は「1kWhいくらで電気を買えるか」でほぼ決まる
  ▶ 約4年ごとの半減期で報酬が半分になるため、定期的に高コスト業者が脱落する
```

| 指標 | 数値 | 出典・時点 |
| --- | --- | --- |
| ネットワーク全体のハッシュレート | 約1,004 EH/s（2026年初の高値から約5.8%縮小） | 集計サイト・調査ベース、2026年 |
| 年間電力消費（推計） | 138 TWh（ケンブリッジ大CCAF）／204 TWh（Digiconomist） | 推計。手法で大きく差が出る |
| 世界の総発電量に占める割合 | 約0.5% | 推計、2026年 |
| ゼロエミッション電源の比率 | 約52.4% | 推計、2026年 |
| 国別ハッシュレート | 米国37〜38%、ロシア約17%、中国約12% | 推計、2026年 |

**日本にマイニングが根付かない理由は単純で、電気が高いから**。
北米・北欧・中東に集まるのは、余剰の天然ガス・水力・原子力や、需給調整用の安価な電力があるため。
近年は**電力系統の需給調整力**として扱われる（余っているときだけ動かし、逼迫時に止める）例も出ており、
この点は電力ビジネスの文脈で読むと分かりやすい（→ [電力](../../11_資源・エネルギー・鉄鋼金属/04_電力/README.md)）。

なおPoSに移行したイーサリアムでは、計算競争の代わりに**通貨を預けて検証者（バリデータ）になる**形になり、
電力事業ではなく**預け入れ資産の利回りビジネス**に性格が変わった。

## 4. ステーブルコイン ── 収益源は「預かったお金の運用益」

**ステーブルコイン**は法定通貨に価値を連動させたデジタル通貨。日本の法律上は「**電子決済手段**」と呼ばれる。
発行体のビジネスモデルは、驚くほど単純である。

```
【発行体の損益】

  利用者 ──1ドル入金──▶ 発行体 ──1トークン発行──▶ 利用者
                          │
                          └─ 預かった1ドルを米国債・預金で運用
                                   ↓
                        金利収入（例：年4%なら1ドルあたり4セント）
                        ─ 利用者には利息を払わない（米GENIUS法は利払いを禁止）
                        ＝ まるごと発行体の収益

  ▶ つまり「無利息で集めた預金を国債で回す」構造。金利が高いほど儲かる
  ▶ 逆に金利が下がると収益が消える。金利連動の事業である
```

| 銘柄 | 発行体・型 | 規模 | 時点 |
| --- | --- | --- | --- |
| **USDT**（テザー） | 海外発行、米ドル連動 | 約1,850億ドル（シェア約58%） | 2026年5月、集計ベース |
| **USDC** | 米サークル社、米ドル連動 | 約780億ドル | 2026年5月、集計ベース |
| ステーブルコイン全体 | — | 供給量3,200億ドル超（2025年初は約2,050億ドル） | 2026年4月16日、集計ベース |
| **JPYC** | JPYC社、資金移動業者型、円連動 | 累計発行額100億円突破 | 2026年9月18日、同社発表 |
| **JPYSC** | SBI VCトレード、信託型、円連動 | — | 2026年 |

円建ては始まったばかりで、**規模はドル建ての1万分の1以下**。
決済用途としての実装は [フィンテック・キャッシュレス](../../04_情報通信・IT・ネット/13_フィンテック・キャッシュレス/04_直近トピック_2026.md) 側で詳しく扱う。
ここで押さえるべきは、**発行体の収益が金利であり、裏付け資産の質がそのまま信用リスク**になるという点である。
2023年3月には、USDCの準備金の一部を預けていた米シリコンバレー銀行の破綻で、一時的に1ドルを割り込んだ例がある。

## 5. DeFi・NFT・Web3 ── ブームと現在地

| 領域 | 何をするものか | 収益の出どころ | 現在地（2026年時点） |
| --- | --- | --- | --- |
| **DeFi**（分散型金融） | 取引所・貸借・デリバティブをスマートコントラクトで代替 | 取引手数料・金利差をプロトコル参加者で分配 | 2020〜21年の「DeFiサマー」以降、資金は残るが**脆弱性を突いた盗難が継続**。日本の規制下では扱いが限定的 |
| **NFT** | デジタルデータの保有履歴をチェーンに記録 | 一次販売＋二次流通のロイヤルティ（数%） | 2021〜22年に高額取引が話題化したが**取引高は大幅に縮小**。実務ではチケット・会員証など用途が絞られた |
| **Web3** | 利用者がデータと持分を持つネットの構想 | トークン発行による資金調達 | 用語としてのブームは沈静化。**残ったのは金融用途とインフラ**という評価が主流 |
| **GameFi／ブロックチェーンゲーム** | 遊んで稼ぐ（Play to Earn） | トークン・NFTの販売 | 新規参加者の流入が止まると成立しにくく、多くが縮小 |

> ここでのパターンは毎回同じ。
> **①新しい用語 → ②トークン価格の高騰 → ③参入殺到 → ④脆弱性・詐欺・値崩れ → ⑤実用的な一部だけ残る**。
> 2017年のICO、2021年のDeFi／NFTがいずれもこの形をたどった。事実として記録しておく価値がある。

## 6. 機関投資家の参入とETF

2024年1月に米国でビットコイン現物ETF（上場投資信託）が承認されたことが、この業界の性格を変えたとされる。
**個人が取引所で直接売買する世界**から、**機関投資家が証券口座で他の資産と並べて持つ世界**が併存するようになった。

```
【流通経路が二本立てになった】

 従来：個人 ─▶ 暗号資産交換業者 ─▶ 自己保管 or 取引所保管
                （資金決済法の世界。秘密鍵の管理が自己責任）

 ETF：投資家 ─▶ 証券会社 ─▶ ETF ─▶ 運用会社 ─▶ カストディアン（保管専門業者）
                （証券の世界。秘密鍵は見ない。信託報酬が運用会社の収益）
```

日本では投資信託がビットコイン等を組み入れることが認められておらず、**国内でのETFは未解禁**。
2026年7月に成立した改正法で暗号資産が金融商品取引法の対象になったことを受け、
**投資信託法の施行令改正を経て2028年にも解禁される見通し**と報じられている（日本経済新聞ほか）。
野村ホールディングスやSBIHDの運用会社が商品開発を進めていると報じられる。

利害の整理をすると、解禁は交換業者にとって**両刃**である。

| 立場 | 影響 |
| --- | --- |
| 証券会社・運用会社 | 新しい商品ラインが増える（→ [証券](../05_証券/README.md)、[資産運用](../06_資産運用/README.md)） |
| 暗号資産交換業者 | 顧客の一部がETFへ流れる一方、**カストディ・現物供給の受託**という新しい役割が生まれる |
| 利用者 | 秘密鍵の管理から解放される。一方で信託報酬という継続コストがかかる |

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **暗号資産交換業者** | 金融庁に登録して売買・交換・保管を行う事業者。2027年施行見込みの改正で「暗号資産取引業」に改称予定 → [規制と事故の歴史](03_規制と事故の歴史.md) |
| **販売所／取引所** | 業者が相手になる売買／利用者同士のマッチング。前者のスプレッドが主な収益源 |
| **スプレッド** | 買値と売値の差。表示上「手数料無料」でも実質の手数料になる |
| **カストディ** | 顧客資産の保管業務。秘密鍵を預かること |
| **レンディング／ステーキング** | 暗号資産を貸す／PoSに預けて報酬を得ること。いずれも元本保証ではない |
| **ハッシュレート** | ネットワーク全体の計算力。自分の取り分はこの中の割合で決まる |
| **ASIC** | マイニング専用チップ。数年で陳腐化する |
| **ステーブルコイン／電子決済手段** | 法定通貨連動のデジタル通貨／その日本法上の呼称 |
| **DeFi** | スマートコントラクトで金融機能を再現する仕組み。管理者がいないぶん救済もない |
| **NFT** | 代替不可能なトークン。デジタルデータの保有履歴を記録する |
| **現物ETF** | 現物を裏付けに持つ上場投資信託。日本は未解禁で2028年にも解禁の見通しと報道 |
