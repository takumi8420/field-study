# ③ 規制と事故の歴史 ── 日本のルールは事故から作られた

このノートで分かること：日本の暗号資産規制がなぜ世界的に見て厳しいのか。
答えは単純で、**大きな流出事件が起きるたびに、その穴を塞ぐ形で法律が作られてきた**からである。

> 結論を先に：日本の制度は「**事故 → 改正 → 事故 → 改正**」の繰り返しでできている。
> だから条文を暗記するより、**どの事故がどの条文を生んだか**をセットで覚えると腹落ちする。

---

## 1. 年表 ── 事故と法改正の対応関係

```
2014.02  マウントゴックス破綻（約85万BTC消失）
            │ 「そもそも業者が無免許・無規制」という問題が露呈
            ▼
2016.06  資金決済法 改正成立 ──▶ 2017.04 施行
            世界初の「仮想通貨交換業」登録制。分別管理・本人確認を義務化

2017.xx  ICOブーム／価格高騰。個人の参入が急増
2018.01  コインチェック NEM 約580億円 流出
            │ 「登録はしていても、ホットウォレットに全額置いていた」
            ▼
2019.05  資金決済法・金商法 改正成立 ──▶ 2020.05 施行
            ・名称を「仮想通貨」→「暗号資産」へ
            ・顧客の暗号資産は原則コールドウォレット管理
            ・例外でホットに置く分は同種同量の弁済原資を自社保有（履行保証暗号資産）
            ・証拠金取引を金商法のデリバティブ規制へ／レバレッジ上限2倍

2022.xx  FATF勧告への対応。2023.06 トラベルルールを法的義務化

2024.05  DMMビットコイン 4,502.9BTC（約482億円）流出
            │ 2025.03 サービス終了、顧客資産はSBI VCトレードへ移管
2025.02  海外Bybitで約14〜15億ドル相当の流出（報道。北朝鮮系関与の指摘）
            ▼
2025.12  金融審議会WG報告 ──▶ 2026.04 法案提出 ──▶ 2026.07.15 成立／07.23 公布
            暗号資産規制を資金決済法 → 金融商品取引法へ移管（2027年施行見込み）
```

## 2. マウントゴックス（2014年） ── 「業者が無規制だった」時代の終わり

東京に拠点を置き、当時は世界最大級のビットコイン取引所だったマウントゴックスが、
**2014年2月に取引を停止し民事再生を申請**。約85万BTC（うち約20万BTCは後に発見）と顧客の預り金が失われた。

この時点の日本には、**暗号資産の事業者を規制する法律が存在しなかった**。
免許も、分別管理義務も、報告義務も、監督官庁もない。だから事故が起きても、
金融機関の破綻処理のような仕組みが使えず、通常の倒産手続きに落ちた。

そこで2016年の資金決済法改正（2017年4月施行）が**世界に先駆けて**、次を義務づけた。

| 導入された義務 | 中身 |
| --- | --- |
| **登録制** | 内閣総理大臣（金融庁）への登録なしに交換業を営めない |
| **分別管理** | 顧客の金銭・暗号資産を自社のものと分けて管理し、外部監査を受ける |
| **本人確認（KYC）** | 犯罪収益移転防止法の特定事業者となり、口座開設時の本人確認が必須 |
| **情報提供義務** | 価格変動リスク等の説明 |

> なぜ日本が最初だったか：**最大の事故が日本で起きたから**。
> 規制が進んでいたからではなく、被害が先に出たからである。

## 3. コインチェック（2018年） ── 「登録しても安全とは限らない」

2018年1月26日、コインチェックから暗号資産NEMが**約580億円相当**流出。
同社は当時**みなし業者**（登録申請中でも営業を続けられる経過措置の対象）だった。
原因は、顧客資産の大半を**ホットウォレット＝ネットにつながったまま**保管していたこと。

つまり2017年の規制は「**分けて管理せよ**」とは言っていたが、「**どう保管せよ**」までは決めていなかった。
ここを塞いだのが2019年改正（2020年5月施行）である。

| 2019年改正で入った規律 | なぜ入ったか |
| --- | --- |
| **顧客の暗号資産は原則コールドウォレット** | ネットにつながっている限り盗まれる、という事実への対応 |
| **履行保証暗号資産** | 例外的にホットに置く分は、同種・同量を業者が自己資金で別に保有。流出しても顧客に返せる |
| 顧客の**金銭は信託**（信託会社等に信託） | 業者が倒産しても金銭が倒産財団に取り込まれないようにする |
| 証拠金取引を**金商法のデリバティブ規制**へ、**レバレッジ上限2倍** | 高倍率取引による個人の損失拡大への対応 |
| 「仮想通貨」→「**暗号資産**」に名称変更 | 「通貨」と誤認させないため（国際的な crypto-asset に合わせた） |
| 「暗号資産カストディ業務」も規制対象 | 売買はせず保管だけする業者が規制の外にいた穴を塞ぐ |

```
【顧客資産の守り方（現行）】

  顧客の金銭 ──▶ 信託銀行等に信託 ──▶ 業者が倒産しても隔離される
  顧客の暗号資産 ─┬─▶ コールドウォレット（原則・大半）
                  └─▶ ホットウォレット（出金対応の最小限）
                         └─ 同種同量の「履行保証暗号資産」を業者が自己保有
                            ＝ 流出しても顧客には返す前提を作る
```

**ただしこれは「盗まれない」という保証ではない**。守っているのは「盗まれたときに返せるか」であり、
価格変動リスクや、業者の経営悪化リスクまでは対象外である。

## 4. DMMビットコイン（2024年） ── 内部・委託先の管理という新しい穴

2024年5月31日、DMMビットコインから**4,502.9 BTC（当時約482億円相当）**が不正流出。
コインチェック事件に次ぐ規模で、同社は2025年3月8日にサービスを終了し、顧客資産はSBI VCトレードへ移管された。

この事件が示したのは、**コールド／ホットの切り分けだけでは足りない**ということ。
鍵そのものではなく、**署名の手続きや委託先・従業員を経由する経路**が狙われうる。
2025年2月の海外Bybitの流出（約14〜15億ドル相当と報道、北朝鮮系集団の関与が指摘される）も、
署名プロセスに関わる部分が突かれたとされ、方向性は同じである。

> 事実として：**国内外を問わず、暗号資産の事故はチェーン本体ではなく、
> その周辺（取引所・鍵管理・ブリッジ・人）で起きている**（→ [技術の仕組み](01_技術の仕組み.md)）。

## 5. トラベルルールとマネロン対策 ── 「匿名だから使われる」への回答

**トラベルルール**は、暗号資産を業者間で送るとき、**送付人・受取人の情報を業者間で通知する**義務。
銀行間送金では当然のことを、暗号資産にも持ち込んだものである。

- 発端は**FATF（金融活動作業部会）の勧告15**。国際的なマネロン・テロ資金対策の枠組み
- 日本では犯罪収益移転防止法の改正により**2023年6月1日から法的義務**化
- 実務上は、送付先が「登録業者の口座か、個人のウォレットか」で扱いが変わり、
  未対応国の業者への送付が制限されるなど、**利用者から見ると「送金が通らない」**形で現れる

| 対策 | 何を防ぐためか |
| --- | --- |
| 本人確認（KYC） | 匿名での口座開設 |
| トラベルルール | 業者間送付での出所不明化 |
| 疑わしい取引の届出 | 犯罪収益の流入 |
| 匿名性の高い銘柄の取扱制限 | 追跡不能な資金移動（日本では実質的に扱われていない） |

## 6. 税制 ── 「雑所得・総合課税」が業界最大の論点だった

現行（2026年9月時点）の個人の取り扱いは次のとおり。**これは有利・不利の話ではなく、制度の説明である**。

| 項目 | 現行の扱い | 株式・投資信託の場合 |
| --- | --- | --- |
| 所得区分 | **雑所得**（原則） | 譲渡所得等 |
| 課税方式 | **総合課税**。他の所得と合算して累進 | **申告分離課税** |
| 税率 | 所得税最大45%＋住民税10%＝**最大約55%** | 20.315%（所得税・復興特別所得税・住民税） |
| 損失の繰越 | **できない** | 3年間繰越可 |
| 他の所得との通算 | 原則できない（雑所得内の通算のみ） | 上場株式等の中で通算可 |
| 課税タイミング | 売却時だけでなく、**暗号資産同士の交換・決済利用時にも発生** | 売却・分配時 |

とくに**「暗号資産で買い物をしたら課税イベント」**という点が、決済手段としての普及を難しくしてきた。
支払いのたびに取得価額との差額を計算する必要があるためである。

### 2026年度税制改正大綱で方向が変わった

政府・与党が2025年12月19日に公表した令和8年度税制改正大綱では、
**「国民の資産形成に資する暗号資産」に限り**、現物取引・デリバティブ取引・ETFからの所得を
**申告分離課税（20%）の対象とする**方針が明記された（損失繰越の導入も検討）。

- 適用は**金商法改正の施行の翌年から**とされ、**2028年が見込み**と報じられる
- **全銘柄が対象ではない**点が重要。「資産形成に資する」＝一定の基準を満たす特定銘柄に限る設計
- 大綱は方針であり、実際の適用条件は今後の法令で確定する（→ [直近トピック](04_直近トピック_2026.md)）

## 7. 2026年改正 ── 資金決済法から金融商品取引法へ

2026年7月15日に成立、7月23日公布。**公布から1年以内の施行**とされ、2027年施行の見込み。
「決済手段として規制する」という当初の建て付けを改め、**投資対象としての規制に作り替える**ものである。

```
【規制の土台が移る】

  これまで          これから（2027年施行見込み）
 ┌──────────┐      ┌──────────────────┐
 │ 資金決済法   │ ──▶ │ 金融商品取引法          │
 │ ＝決済手段   │      │ ＝投資商品（株・債券と同じ棚）│
 │ 暗号資産交換業│      │ 暗号資産取引業（第一種金商業相当）│
 └──────────┘      └──────────────────┘
   ※ ステーブルコイン（電子決済手段）は引き続き資金決済法側に残る
```

| 改正の柱 | 中身 |
| --- | --- |
| **区分の新設** | 発行者の有無で **特定暗号資産**（発行権限を持つ者がいる）と **非特定暗号資産**（ビットコイン等、発行者が特定できない）に分ける |
| **情報公表規制** | 特定暗号資産の発行者に、募集・売出し時の情報公表と**年1回の継続的報告**を義務づけ |
| **業規制の強化** | 暗号資産取引業者に第一種金融商品取引業に相当する規制を適用。責任準備金、外務員制度の導入 |
| **インサイダー取引規制の新設** | 発行者や取引業者の関係者が、重要事実の公表前に売買することを禁止 |
| **取扱基準** | 一定の基準を満たさない暗号資産の取扱いを禁止する規定、**日々の売買高等の公表**義務 |
| **無登録業者への罰則強化** | 10年以下の拘禁刑・1,000万円以下の罰金へ引き上げ |

> なぜこう変わったか：**実態が投資だったから**。
> 決済に使われる量はごくわずかで、実際には値動きを取りに来る人がほとんどだった
> （→ [事業としての暗号資産](02_事業としての暗号資産.md)）。
> 制度の建て付けと実態のズレを、実態に合わせて直したのがこの改正である。

なお、資金決済法側でも2026年6月1日施行の改正で
**「電子決済手段等・暗号資産サービス仲介業」**が新設され、自ら資産を預からず媒介だけを行う事業者が登録制の枠に入った。

## 8. 各国の規制動向 ── 方向性は「禁止」ではなく「枠に入れる」

| 国・地域 | 枠組み | 要点 |
| --- | --- | --- |
| **日本** | 資金決済法（2017〜）→ 金商法（2027年施行見込み） | 登録制・分別管理・コールド保管。事故起点で世界最速級に整備 |
| **EU** | **MiCA**（暗号資産市場規制。2024年から段階適用） | EU域内で統一免許。ステーブルコイン発行に準備資産要件 |
| **米国** | **GENIUS法**（2025年7月18日成立）ほか | 支払用ステーブルコインの連邦枠組みを創設。**利用者への利払いを禁止**し、準備資産・開示・監督を規定。証券該当性は当局間で論点が続く |
| **韓国・シンガポール・香港** | 各国の免許制 | 取引所ライセンス制と投資家保護要件を導入 |

共通するのは、**禁止ではなく「既存の金融規制の棚に入れる」**という方向。
結果として、**規制の重さに耐えられる大手が残り、小規模業者が退出する**という産業構造の変化が世界的に起きている。

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **資金決済法** | 前払式支払手段・資金移動業・暗号資産等を規律する法律。2017年から暗号資産交換業の登録制を置いた |
| **金融商品取引法（金商法）** | 株式・債券等の投資商品を規律する法律。2026年改正で暗号資産が移管される（2027年施行見込み） |
| **暗号資産交換業／暗号資産取引業** | 現行の登録業種／改正後の名称。後者は第一種金融商品取引業相当の規制 |
| **みなし業者** | 登録申請中に経過措置で営業できた事業者。コインチェック事件当時の立場 |
| **分別管理** | 顧客資産を自社資産と分けて管理すること。金銭は信託、暗号資産は原則コールド |
| **履行保証暗号資産** | ホットウォレットに置く顧客分と同種同量を業者が自己保有する制度。流出時の弁済原資 |
| **トラベルルール** | 業者間送付で送付人・受取人情報を通知する義務。日本は2023年6月1日から法的義務 |
| **FATF** | 金融活動作業部会。マネロン対策の国際基準を作る組織 |
| **特定暗号資産／非特定暗号資産** | 2026年改正の区分。発行権限を持つ者がいるか否かで分ける |
| **雑所得・総合課税** | 現行の個人の暗号資産所得の扱い。最大約55%、損失繰越不可 |
| **申告分離課税** | 他の所得と分けて一律課税する方式。2026年度大綱で一定の暗号資産に導入する方針（2028年見込み） |
| **MiCA／GENIUS法** | EUの暗号資産市場規制／米国のステーブルコイン法 |
