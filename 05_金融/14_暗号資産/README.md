# 暗号資産

- 大分類: 金融
- 状態: done
- 更新日: 2026-09-20

管理者のいない台帳（ブロックチェーン）の上で動く資産と、それを売買・保管・発行する事業の集まり。
名前に「資産」とあるが、**産業としての中身はほぼ「取引の場」の商売**で、
売上は価格ではなく**売買の量と預り資産**に連動する。
2026年7月の法改正で、法律上の位置づけが「決済手段」から「投資商品」へ移ることが決まった。

> **このノートは投資助言ではない。価格の見通しも書かない。**
> 扱うのは仕組み・制度・事業構造だけである。
> 一方で、**価格変動・ハッキング・詐欺というリスクは事実として明記する**。

## このフォルダの読み方

暗号資産は「金融」の棚に置いてあるが、理解の順番は他の金融業界と違う。
銀行や保険は制度から入れるのに対し、こちらは**先に技術の仕組みを押さえないと、
事業も規制も意味が分からない**。だから ①技術 → ②事業 → ③規制 → ④直近 の順に組んだ。

## 1. 業界の定義・範囲

法律上の「**暗号資産**」は、資金決済法で定義された**電子的に記録され、不特定の者への支払いに使え、
法定通貨・通貨建資産ではない財産的価値**を指す（2019年改正で「仮想通貨」から名称変更）。
ビットコイン、イーサリアムなどが該当する。

産業としての中核は、これを**売買・交換・保管する「暗号資産交換業者」**。
金融庁の登録が必要で、2026年9月1日時点で**27社**（金融庁 登録一覧）。

```
【何が「暗号資産」で、何が違うのか】

  暗号資産           ビットコイン、イーサリアム等
   └ 資金決済法 →（2027年施行見込みで金商法へ移管）

  電子決済手段        ステーブルコイン（JPYC、USDC等）
   └ 資金決済法。法定通貨に連動 → 決済利用は フィンテック側で詳述

  電子記録移転有価証券表示権利等（セキュリティトークン）
   └ 最初から金商法。不動産・社債等を裏付けに持つ

  前払式支払手段      Suica残高、各種ポイント
   └ 資金決済法。発行者に払い戻し義務なし・特定の店でしか使えない

  中央銀行デジタル通貨（CBDC）
   └ 中央銀行の負債。日本は実証段階で発行決定はされていない
```

| 含まれるもの | 含まれないもの |
| --- | --- |
| 暗号資産の売買・交換・保管（交換業） | 銀行預金・電子マネー・ポイント |
| 暗号資産のデリバティブ（証拠金取引） | セキュリティトークン（もともと金商法の世界） |
| マイニング／バリデータ運営 | CBDC（中央銀行の負債） |
| ステーブルコインの発行（＝電子決済手段） | ステーブルコインの**決済利用側の実装** → [フィンテック](../../04_情報通信・IT・ネット/13_フィンテック・キャッシュレス/README.md) |

ETF解禁（2028年見込み）が、機関投資家と一般の資産形成層をどれだけ呼び込むかに依存する。

## 3. バリューチェーン（川上 → 川下）

```
 【発行・生成】        【インフラ】          【流通】              【利用・保有】

  マイニング         ブロックチェーン      暗号資産交換業者        個人（1,400万口座）
  ／バリデータ  ──▶  （台帳・L1/L2）  ──▶  ・販売所（スプレッド）──▶ 法人（決済・財務）
  ＝電力事業          ＝公共財に近い        ・取引所（板・手数料）    機関投資家（ETF経由）
       │                    │              ・証拠金取引（2倍まで）        ▲
       │                    │              ・カストディ                    │
  ステーブルコイン発行体 ────┘              ・レンディング                  │
  ＝預かり資産の運用益                             │                        │
                                             自主規制：JVCEA                │
                                             監督：金融庁 ──── 規制コスト ──┘

  ▶ 付加価値は「流通」に集中する。台帳そのものは誰のものでもなく、収益化されない
```

**付加価値が集まるのは取引所レイヤー**。台帳自体はオープンで誰も課金できないので、
儲かるのは「**人が出入りする窓口を持つ者**」になる。この点はプラットフォーム型ビジネスに近い。

## 5. 収益モデル・コスト構造

| プレイヤー | 主な収益 | 主なコスト | 特徴 |
| --- | --- | --- | --- |
| 交換業者 | **販売所のスプレッド**（最大）、板取引手数料、証拠金の維持手数料、レンディング | システム、セキュリティ、AML・監査、人件費（いずれも固定費） | **固定費型**。取引量が減ると一気に苦しい |
| マイニング | 新規発行報酬＋取引手数料 | **電気代60〜80%**、専用機の償却 | 実質は電力の裁定取引。半減期ごとに淘汰 |
| ステーブルコイン発行体 | 預かった資金の**運用益（国債・預金）** | 準備資産管理、監査、償還対応 | 金利連動。利用者に利息は払わない |
| 運用会社（ETF） | 信託報酬 | カストディ費用、運用管理 | ストック型。日本は未解禁 |

SBIホールディングスの暗号資産事業セグメントは**2026年3月期に収益896億円（前期比10.9%増）、税引前利益212億円（同0.1%減）**（同社IR）。
**増収でも増益にならない**のが、この業界のコスト構造をよく表している。

## 6. 競争要因（KSF）と参入障壁

| 要因 | 中身 |
| --- | --- |
| **登録免許** | 金融庁の登録が必須。2027年施行見込みの改正で第一種金商業相当の規制になり、障壁はさらに上がる |
| **規模** | 固定費型なので口座数・取引量が効く。規模が取れないと利益が出ない |
| **セキュリティの実績** | 一度の流出で事業が終わる（DMMビットコインは流出後にサービス終了）。信用が直接の競争力 |
| **資本と親会社** | 流出時の弁済、履行保証暗号資産の自己保有には資本が要る。ネット金融グループ傘下が有利 |
| **流動性** | 板が厚いほど有利な価格で約定する。流動性が流動性を呼ぶ |
| **銀行との接続** | 円の入出金の導線。AML対応ができないと銀行が繋いでくれない |

参入障壁は**上がる方向**にある。規制強化は新規参入を難しくし、既存大手の地位を固める。

## 7. 規制・法制度

詳細は [③ 規制と事故の歴史](03_規制と事故の歴史.md)。骨格だけ。

| 制度 | 内容 |
| --- | --- |
| **資金決済法**（2017年4月〜） | 暗号資産交換業の登録制、分別管理、本人確認。マウントゴックス事件を受けた世界初の枠組み |
| **2019年改正**（2020年5月施行） | 顧客暗号資産の原則コールドウォレット管理、履行保証暗号資産、証拠金取引の金商法化（レバレッジ2倍）。コインチェック事件を受けたもの |
| **トラベルルール**（2023年6月1日〜） | 業者間送付で送付人・受取人情報の通知を義務化。FATF勧告への対応 |
| **改正資金決済法**（2026年6月1日施行） | 「電子決済手段等・暗号資産サービス仲介業」の新設、信託型ステーブルコインの運用要件緩和 |
| **改正金商法**（2026年7月15日成立・7月23日公布、**2027年施行見込み**） | 暗号資産を金商法へ移管。特定／非特定の区分、発行者の情報公表義務、**インサイダー取引規制の新設**、無登録業者の罰則強化（10年以下の拘禁刑・1,000万円以下の罰金） |
| **税制（現行）** | 個人は雑所得・総合課税で最大約55%。損失繰越不可。暗号資産同士の交換や決済利用も課税イベント |
| **税制（方向）** | 令和8年度税制改正大綱（2025年12月19日）で、一定の暗号資産に**申告分離課税20%**を導入する方針。適用は2028年見込み |

## 8. 最近のトピック

→ [④ 直近トピック（2026年9月時点）](04_直近トピック_2026.md)

- **2026年7月15日、改正金商法が成立**。暗号資産が「決済手段」から「投資商品」へ。2027年施行見込みで、インサイダー取引規制と発行者の情報公表義務が入る
- **税制は申告分離課税20%の方向**が令和8年度大綱に明記。ただし「資産形成に資する」特定銘柄に限られ、適用は2028年見込み

- **国内は大手主導の再編へ**。SBIがビットバンクを467億円で完全子会社化すると発表（2026年6月）、統合後の預り資産は約1.1兆円の見込み
- **取扱銘柄の絞り込みが進行**。2026年8〜9月に各社で上場廃止が相次いだ。制度の裏付けがある銘柄へ集約されつつある
