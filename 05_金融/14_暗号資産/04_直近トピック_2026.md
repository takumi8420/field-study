# ④ 直近トピック（2026年9月時点）

報道・一次資料ベースの整理。**投資判断のための情報ではなく、制度と事業構造の変化を追う**ためのノート。
価格の見通しには触れない。数値は時点とセットで読むこと。

> この1年の構図を一言でいうと：**暗号資産が「決済の法律」から「投資の法律」へ引っ越した年**。
> 2026年7月に金商法改正が成立し、税制も分離課税の方向が示され、国内業者は大手主導の再編に入った。
> 一方で取扱銘柄は絞り込まれ、**裾野が広がるのではなく上澄みが制度化される**動きになっている。

```
【2026年の主要な出来事】

 2026.04  SBI VCトレード×ビットポイントジャパン 合併

 2026.06.01 改正資金決済法 施行（電子決済手段等・暗号資産サービス仲介業 新設）

 2026.08〜09 国内取引所で取扱銘柄の廃止（上場廃止）が相次ぐ
```

## 1. 改正金商法が成立 ── 暗号資産が「株と同じ棚」に移る

2026年7月15日、**金融商品取引法及び資金決済に関する法律の一部を改正する法律**が参院本会議で可決・成立。
7月23日公布、**公布から1年以内に施行**とされ、2027年施行の見込み。

制度の中身は [③ 規制と事故の歴史](03_規制と事故の歴史.md) に整理したが、直近トピックとしての要点は3つ。

| 変わること | 実務へのインパクト |
| --- | --- |
| 暗号資産交換業 → **暗号資産取引業**（第一種金商業相当） | 責任準備金・外務員制度など、証券会社並みの体制コストがかかる。**中小業者の負担が重くなる** |
| **インサイダー取引規制の新設** | 発行者・取引業者の関係者は、重要事実の公表前の売買が禁止される。上場企業と同じ内部管理が要る |
| **特定暗号資産の発行者に情報公表義務**（募集時＋年1回の継続報告） | 発行者がいるトークンは、実質的に開示企業に近い義務を負う |

加えて、**一定の基準を満たさない暗号資産の取扱い禁止**と**日々の売買高等の公表**が盛り込まれたと解説されている
（大和総研、2026年4月20日）。取扱銘柄の絞り込み（後述の第3節）は、この方向と整合する。

> なぜ移管したのか：実態が投資だから。
> 決済に使われる量はごく小さく、利用者の大半は値動きを見て売買している。
> 「決済手段の法律で投資商品を規制していた」ズレを、実態側に合わせた。

## 2. 税制 ── 申告分離課税20%の方向が大綱に入った（適用は2028年見込み）

2025年12月19日に公表された**令和8年度税制改正大綱**で、
**「国民の資産形成に資する暗号資産」に限り**、現物取引・デリバティブ取引・ETFから生ずる所得を
**申告分離課税の対象とする**方針が明記された。

| 論点 | 現行（2026年9月時点） | 大綱の方向 |
| --- | --- | --- |
| 所得区分・課税方式 | 雑所得・総合課税 | 申告分離課税 |
| 税率 | 最大約55%（所得税＋住民税） | 20%（分離） |
| 損失繰越 | 不可 | 導入を検討（金融庁要望では3年） |
| 対象 | 全銘柄 | **一定の基準を満たす特定銘柄に限る** |
| 適用時期 | — | **金商法改正の施行の翌年から**。2028年が見込みと報じられる |

注意点は2つ。**①大綱は方針であって確定した条文ではない**こと、
**②全銘柄が対象になるわけではない**こと。「資産形成に資する」という限定がついている。

金融庁は2025年8月29日公表の令和8年度税制改正要望でも、分離課税の導入を掲げていた（金融庁公表資料）。

## 3. ETF解禁は2028年にも ── ただしまだ「見通し」

暗号資産が金商法の対象になったことで、投資信託がビットコイン等を組み入れる道が開く。
報道では、**投資信託法の施行令改正を経て2028年にも国内でのETF解禁**という見通しが示されている（日本経済新聞ほか）。
野村ホールディングスやSBIHDの運用会社が商品開発を進めていると報じられる。

```
【日本が米国より4年遅れた理由（報道ベースの整理）】

 米国  2024.01 現物ビットコインETF承認
          ↓ 機関投資家が証券口座で持てるようになる
 日本  2026.07 金商法改正 成立（＝そもそも投信に入れられなかった）
       2028?   施行令改正でETF解禁の見通し
          ↑ 「有価証券でない」という法的位置づけと、
            投資家保護・税制（総合課税）の未整備が足かせだった
```

交換業者にとっては、**顧客の一部がETFへ流れる**一方で**カストディや現物供給の受託**という役割が生まれる、
両刃の変化になる（→ [② 事業としての暗号資産](02_事業としての暗号資産.md)、[証券](../05_証券/README.md)）。

## 4. 国内業界は大手主導の再編へ ── SBIがビットバンクを買収

| 出来事 | 内容 | 時点 |
| --- | --- | --- |
| SBI VCトレード×ビットポイントジャパン 合併 | グループ内統合 | 2026年4月 |
| SBI、**ビットバンクの完全子会社化**を発表 | 取得総額**467億円**。完了は2026年10月ごろの計画 | 2026年6月25日 |
| 統合後の規模 | 預り資産**約1.1兆円**・口座**約292万**で国内首位の見込み（2026年4月末の単純合算） | 報道ベース |
| SBI 暗号資産事業セグメント | 収益**896億円**（前期比10.9%増）、税引前利益**212億円**（同0.1%減） | 2026年3月期、同社IR |
| 主要他社の預り資産 | bitFlyer 約9,600億円（2025年12月末）／Coincheck 約8,000億円（2025年3月末） | 報道ベース |

**収益は増えたのに利益が横ばい**という点が、この業界の現在地をよく表している。
システム・セキュリティ・AML・規制対応という固定費が先に膨らむため、**規模を取らないと利益が出ない**。
2027年施行の金商法規制でこの固定費がさらに上がるので、再編圧力は続くと見るのが自然である。

### 同時に進む「取扱銘柄の絞り込み」

2026年8月以降、国内取引所で取扱廃止（上場廃止）の発表が相次いだ。

- 2026年8月5日：SBI VCトレードがSANDなど7銘柄の廃止を発表
- 2026年8月20日：ビットトレードがBOBA・FLR・XTZを廃止
- 2026年9月4日：ビットポイントが6銘柄、SBI VCトレードが3銘柄
- 2026年9月9日：GMOコインが3銘柄（いずれも各社発表・報道ベース）

背景として流動性の低さなどが挙げられているが、
**「基準を満たさない銘柄は扱えない」という改正法の方向**と合わせて読むと筋が通る。
利用者から見れば、**選べる銘柄は減り、残る銘柄は制度的な裏付けが厚くなる**という変化である。

## 5. ステーブルコインは規模で先行 ── 日本円建てはまだ小さい

| 指標 | 数値 | 時点・出典 |
| --- | --- | --- |
| ステーブルコイン供給量（世界） | **3,200億ドル超**（2025年初は約2,050億ドル） | 2026年4月16日、集計ベース |
| USDT | 約1,850億ドル（シェア約58%） | 2026年5月、集計ベース |
| USDC | 約780億ドル | 2026年5月、集計ベース |
| **JPYC** 累計発行額 | **100億円突破**（3年で1兆円を目標と表明） | 2026年9月18日、同社プレスリリース |
| JPYC 海外上場 | 韓国大手取引所アップビットに上場 | 2026年9月17日、報道ベース |

米国では**GENIUS法**（2025年7月18日成立、公法119-27）が支払用ステーブルコインの連邦枠組みを定め、
認可発行体・準備資産・開示・監督を規定した。**利用者への利払いを禁止**しているため、
準備資産の運用益はそのまま発行体の収益になる（→ [② 事業としての暗号資産](02_事業としての暗号資産.md)）。

日本側では**改正資金決済法が2026年6月1日施行**され、
「電子決済手段等・暗号資産サービス仲介業」の新設と、信託型ステーブルコインの運用要件緩和が入った。
**決済としての実装の話は [フィンテック・キャッシュレス ④直近トピック](../../04_情報通信・IT・ネット/13_フィンテック・キャッシュレス/04_直近トピック_2026.md) 側**にまとめてある。

> ここで押さえるべきは規模感。円建ては累計100億円で、ドル建ての1万分の1以下。
> **「制度は整った。実需はこれから」**が2026年時点の正確な言い方になる。

## 6. マイニングと電力 ── 相変わらず「電気代の事業」

| 指標 | 数値 | 時点・出典 |
| --- | --- | --- |
| ネットワーク全体のハッシュレート | 約1,004 EH/s（2026年初の高値から約5.8%縮小） | 2026年、集計ベース |
| 年間電力消費（推計） | 138 TWh（ケンブリッジ大CCAF）／204 TWh（Digiconomist） | 推計。手法差が大きい |
| 世界の総発電量比 | 約0.5% | 推計 |
| ゼロエミッション電源比率 | 約52.4% | 推計 |
| 国別ハッシュレート | 米国37〜38%、ロシア約17%、中国約12% | 推計 |

**推計値の幅が大きい**ことに注意が必要で、調査主体によって1.5倍近い差が出る。
「ビットコインは◯◯国の電力消費に匹敵」という類の表現は、どの推計を使ったかで結論が変わる。

構造は変わっていない。**安い電力のある場所に設備が移動し、半減期のたびに高コスト事業者が脱落する**。
近年は電力系統の需給調整力（余剰時に動かし、逼迫時に止める）として扱う議論もある
（→ [電力](../../11_資源・エネルギー・鉄鋼金属/04_電力/README.md)）。

## 7. リスク面で起きていること（事実の記録）

- **大型流出は続いている**。2025年2月のBybit流出は約14〜15億ドル相当と報じられ、北朝鮮系集団の関与が指摘された
- 国内では2024年5月のDMMビットコイン流出（4,502.9BTC・約482億円相当）を受け、同社は2025年3月にサービス終了。顧客資産はSBI VCトレードへ移管された
- **詐欺・不正勧誘**は継続的に報告されている。SNSや著名人を騙った投資勧誘、偽の取引所サイト、サポートを装ったフィッシングなど
- **価格変動は大きい**。裏付け資産も利息もない資産の価格は需給のみで決まり、短期間で大きく動いた事例が繰り返し観測されている

これらは制度が整っても消えない性質のもので、**規制は「事故を減らす」「起きたときに返せるようにする」までしかできない**。

## 8. 全体の構図（まとめ）

1. **2026年は制度の年**。7月の金商法改正成立で、暗号資産は「決済手段」から「投資商品」へ法的に引っ越した。施行は2027年見込み
2. **税制も分離課税の方向**が大綱に入った（20%、2028年見込み）。ただし対象は「資産形成に資する」特定銘柄に限られる設計
3. **業界は大手主導の再編へ**。SBIのビットバンク買収で預り資産1.1兆円規模の首位が生まれ、規制コストの上昇が中小の退出を促す
4. **銘柄は絞られる**。取扱廃止が相次ぎ、制度の裏付けがある銘柄に集約されつつある
5. **ステーブルコインは規模で先行、日本円建ては始まったばかり**。ドル建て3,200億ドルに対しJPYCは100億円で、実需はこれから

要するに、**裾野が広がる局面ではなく、枠組みが固まって参加者が絞られる局面**にある。
