## 1. 信託財産総額が2,000兆円目前（2026年3月末）

信託協会が2026年8月6日に公表した信託統計「全国信託財産調」（2026年3月末現在）によれば、
**信託財産総額は約1,994.2兆円**。2,000兆円の大台にほぼ届いた水準となった。

| 項目 | 数値 | 時点 |
| --- | --- | --- |
| 信託財産総額 | 約1,994.2兆円 | 2026年3月末 |
| 公表日 | 2026年8月6日 | 信託協会 |
| 統計の更新頻度 | 年2回（3月末・9月末） | — |

読み方の注意：

- この数字は**信託契約の残高の合計**であり、日本の総資産ではない。
  同じ資産が年金信託 → 投資信託 → 有価証券の信託と多段で経由すれば、その都度カウントされる。
- 増加の主因は、株式市場の水準上昇による**評価額の増加**と、
  NISA拡充以降の**投信残高の積み上がり**、そして証券化・流動化案件の積み上げと考えられる。
  内訳の寄与度は信託協会の種類別統計で確認するのが正確。

```
  信託財産総額の押し上げ要因（定性的な整理）

  ① 市況（株価・債券・不動産の評価額）─┐
  ② 投信残高の増加（NISA・年金）    ─┼─▶ 信託財産総額
  ③ 証券化・流動化案件の増加        ─┘
      ▲
      └ ①は市況次第で反転する。趨勢を見るなら②③を分けて見る
```

## 2. 資産運用立国とアセットオーナー改革が信託の仕事を増やしている

政府が2023年12月に決定した「資産運用立国実現プラン」を起点に、
**アセットオーナー（年金基金など資産の保有者）の運用高度化**が制度として求められる局面に入った。

- 2024年：**アセットオーナー・プリンシプル**が策定され、年金基金等に受入れが促される。
- 2025年1月：厚生労働省の**DB運用ガイドラインが改訂**。
  運用委託機関の定期評価、専門性の確保、スチュワードシップ活動の充実などが求められるようになった
  （出典：企業年金関連の解説記事、2025年）。

企業年金、とくに中小規模の基金は専門人材を自前で抱えにくい。
結果として**外部の助言と事務代行の需要が増え、年金分野に長くいる信託銀行に仕事が集まる**。

> ポイント：資産運用立国は「運用会社の成長戦略」として語られがちだが、
> 実務上の負荷（評価、報告、記録、説明資料）を吸収するのは信託銀行側。
> **制度改正がそのまま手数料収入の母数を増やすタイプの追い風**になっている。

## 3. 相続・認知症対策のデジタル化（2026年）

高齢化の進行で、資産承継は信託銀行の最重要テーマのひとつであり続けている。
2026年に入り、**デジタルで完結させる方向**の動きが目立ってきた。

- 2026年8月26日、MUFG（三菱UFJフィナンシャル・グループ／三菱UFJ銀行／三菱UFJ信託銀行）が、
  三菱UFJ銀行が開発・提供するプラットフォーム上で、**スマートフォンアプリを活用して
  生前の資産管理と資産承継を一体で提供する信託商品**を発表したと公表している（同社リリース、2026年8月26日）。
  国内金融機関として初の取り組みと説明されている。
- 三菱UFJ信託銀行は2026年に、ゴールベースアプローチ型の投資一任運用サービスの提供や、
  MUFGファイナンス＆リーシングからの事業承継による**国内オルタナティブ投資のSPC管理事業への参入**なども公表している。

| 背景要因 | 信託商品への影響 |
| --- | --- |
| 認知症による資産凍結リスク | 判断能力があるうちに管理を託す商品の需要増 |
| 相続手続きの煩雑さ | 遺言信託・遺産整理の一括受託ニーズ |
| 相続人の地方分散・高齢化 | 対面前提からアプリ・オンライン完結へ |
| 家族信託（民事信託）の普及 | 「信託」の認知度上昇。銀行の商品化も後押し |

**家族信託との関係**：家族信託は親族が受託者になるため信託銀行の直接の競合ではないが、
「信託で備える」という考え方を一般に広げた効果は大きい。
信託銀行側はそこを取り込む形で、商品のデジタル化と低価格帯化を進めているとみられる。

## 4. 三井住友トラスト・グループの再編と収益

独立系として唯一残る三井住友トラスト・グループでは、2026年に事業ポートフォリオの組み替えが続いている。

| 時期 | 内容 |
| --- | --- |
| 2026年2月26日 | 組織再編に関するお知らせを公表（同社リリース） |
| 2026年3月30日 | 三井住友トラスト・パナソニックファイナンス（SMTPFC）について、三井住友信託銀行を筆頭株主としつつ、**芙蓉総合リース・横浜FGを含む共同事業とする**方針を公表（同社リリース） |

リース事業を単独保有から共同事業に切り替えるのは、
**バランスシートを使う事業（リース）への資本配分を抑え、手数料型の事業に資源を寄せる**動きと読める。
信託銀行の基本形である「資本を使わずに稼ぐ」という方向と整合的。
リース業の構造は [リース](../10_リース/README.md) を参照。

業績面では、三井住友トラストグループの2026年3月期は親会社株主に帰属する当期純利益が
**約3,175億円（前期比 約+23%）、ROE 約9.5%** と、過去最高水準になったと集計・報道されている。
※これは決算情報の集計サイト経由の数値。**正式な数値は同社の決算短信・決算説明資料で確認すること。**

## 5. 信頼という資産 ─ コンプライアンス事案の重み

信託銀行は他人の財産と未公開情報を大量に預かるため、**情報管理の破綻が業態の存立に直結する**。

- 三井住友信託銀行では、元社員によるインサイダー取引の疑いで証券取引等監視委員会の強制調査が行われ、
  同社は**2025年3月24日に元社員を金融商品取引法違反の疑いで東京地方検察庁に告発した**と公表している（同社リリース）。
  報道では不正取引による利益が約3,000万円規模と伝えられた。
  同社にとって2012年の公募増資インサイダー事案に続く2度目の事案にあたるとされる。

この種の事案が重いのは、罰則そのものより**ビジネスモデルへの打撃**による。

```
  信託銀行が預かっているもの
        │
        ├─ 顧客の財産        ── 事務ミス → 直接の損害賠償
        ├─ 上場企業の未公開情報 ── 漏洩・悪用 → 証券代行・M&A助言の信用失墜
        └─ 年金加入者の将来   ── 計算誤り → 制度全体への不信
                    ▲
                    └ どれも「信用」でしか担保できない。だから情報隔壁（チャイニーズウォール）が生命線
```

証券代行を通じて企業の株主構成や資本政策を知り、不動産で売却意向を知り、
年金で人事施策を知る——信託銀行は構造的に未公開情報の結節点にある。
**情報の壁を維持する内部統制コストは、この業態の避けられない固定費**である。

## 6. 金利環境と信託銀行

日本銀行の金融政策正常化により、国内金利は長らくのゼロ近辺から離れた環境が続いている。
信託銀行への影響は普通銀行とは違う形で出る。

| 経路 | 影響 |
| --- | --- |
| 銀行勘定の貸出・預金 | 利ざやの改善。ただし信託銀行の収益に占める比率は普通銀行より小さい |
| 債券運用の含み | 金利上昇局面では保有債券に評価損。年金・投信の基準価額にも影響 |
| 不動産 | 金利上昇は不動産価格・取引量に逆風。仲介・証券化の案件数に効く |
| 手数料ビジネス | 株価が堅調なら残高が増え、報酬も増える |

つまり**信託銀行は「金利」より「株価と不動産市況」に効かれる**。
この点は [メガバンク](../01_メガバンク/README.md) との読み方の大きな違いになる。

## 7. 全体の構図（まとめ）

- 信託財産総額は2026年3月末で約1,994.2兆円と、統計上の過去最高水準。
  ただし市況による評価額の増加分が相当含まれる点は割り引いて読む必要がある。
- 構造的な追い風は2つ。**資産運用立国とアセットオーナー改革による年金・受託業務の需要増**、
  そして**高齢化による資産承継ニーズ**。どちらも制度と人口動態に支えられており、市況ほど揺れない。
- 構造的な逆風も2つ。**料率の低下圧力**（とくに投信・運用まわり）と、
  **システム・内部統制の固定費増**。規模のない信託は生き残りにくくなる。
- 各社の動きは「**資本を使う事業を外に出し、手数料型の事業に寄せる**」方向で一致している。
  三井住友トラストのリース共同事業化、三菱UFJ信託のSPC管理事業承継はいずれもその文脈で読める。
- 最大のリスクは市況ではなく**事務とコンプライアンスの事故**。
  この業態は信用で成り立っており、信用の毀損は残高の流出に直結する。
