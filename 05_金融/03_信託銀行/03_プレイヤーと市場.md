# プレイヤーと市場（3大信託・カストディ専業・信託の応用）

このノートで分かること：日本の信託銀行が**どういう類型に分かれているか**、
なぜ再編でこの形に落ち着いたか、そして信託が**金融インフラとしてどこに埋め込まれているか**。

> 結論：日本の信託業界は「**3大信託＋カストディ専業2行＋専業・外資の周辺**」という形に収れんした。
> 総合信託は顧客接点で、カストディ専業は規模の経済で戦う。**同じ免許でも経済性がまったく違う**。

---

## 1. 市場の大きさ

| 指標 | 数値 | 時点・出典 |
| --- | --- | --- |
| 全国の信託財産総額 | 約1,994.2兆円 | 2026年3月末、信託協会「全国信託財産調」 |
| 統計の更新頻度 | 年2回（3月末・9月末） | 信託協会 |
| 長期推移の入手範囲 | 2001年9月末〜2026年3月末 | 信託協会「信託の受託概況推移表」 |

信託財産総額は、金銭信託・投資信託・年金信託・金銭債権の信託・包括信託などの残高の合計。
**同じ資産が別の信託を経由して二重に数えられる部分がある**ので、
「日本の全資産」を意味する数字ではない。規模感と趨勢を見るための指標と割り切るのが正しい読み方。

```
 信託財産総額の内訳イメージ（種類別の枠組み）

 ┌──────────────────────────────────────────────┐
 │ 金銭信託        … 現金を信託して運用・管理        │
 │ 投資信託        … 公募・私募の投信の受託          │
 │ 年金信託        … DB・厚年基金等の年金資産        │
 │ 金銭債権の信託  … 売掛債権・ローン債権の流動化     │
 │ 有価証券の信託  … 株式・債券の管理（カストディ）   │
 │ 不動産の信託    … 実物不動産を受益権化            │
 │ 包括信託        … 複数種類をまとめて信託          │
 └──────────────────────────────────────────────┘
   ※構成比は時点で変わる。最新は信託協会の統計で確認
```

## 2. プレイヤーの4類型

信託業の免許を持つ会社は多いが、**やっていることは4つに分かれる**。ここを混同すると業界が読めない。

| 類型 | 何で稼ぐか | 代表 | 経済性の特徴 |
| --- | --- | --- | --- |
| **総合信託銀行** | 銀行＋信託＋併営の3階建て。法人・個人の両輪 | 三菱UFJ信託、三井住友信託、みずほ信託 | 顧客接点の幅が武器。人件費が重い |
| **資産管理専業（カストディ）** | 保管・決済・記帳に特化 | 日本カストディ銀行、日本マスタートラスト信託銀行 | 装置産業。残高を積んで固定費を薄める |
| **グループ内専業・特化型** | 親会社の顧客向けに投信受託、富裕層向け等 | 野村信託銀行、SMBC信託銀行、各社系の信託会社 | 親の顧客基盤に依存。小回りが利く |
| **外資系信託銀行・信託会社** | グローバル・カストディ、証券化の受託 | ステート・ストリート信託銀行 ほか | 海外投資家の日本資産の受け皿 |

さらに信託業法の側には、銀行ではない**信託会社**がある。

- **運用型信託会社**：自ら財産を運用する。免許制。求められる要件が重い。
- **管理型信託会社**：運用の裁量を持たず、指図に従って管理するだけ。登録制。要件が軽い。

証券化案件のSPC（特別目的会社）まわりで名前が出る小さな信託会社は、多くがこの**管理型**である。

## 3. 3大信託の顔ぶれ

| グループ | 信託の中核会社 | 立ち位置と特徴 |
| --- | --- | --- |
| 三井住友トラスト・グループ | 三井住友信託銀行 | **唯一の独立系（メガバンク傘下ではない）信託専業グループ**。信託・不動産・証券代行・年金の総合力で勝負。日本カストディ銀行の主要出資者 |
| 三菱UFJフィナンシャル・グループ | 三菱UFJ信託銀行 | MUFGの資産運用・資産管理の中核。銀行側の顧客基盤と組んだ「総資産営業」を推進。日本マスタートラスト信託銀行系 |
| みずほフィナンシャルグループ | みずほ信託銀行 | 3社の中では規模で劣るが、不動産・証券代行・資産承継に強みを持つとされる。みずほ銀行・みずほ証券との一体運営（One MIZUHO） |

**三井住友トラスト・グループだけが銀行持株会社の傘下に入らず独立している**点は、
この業界を理解するうえで外せない。他の2社は「メガバンクの一部門」として機能しているのに対し、
三井住友トラストは信託そのものを主戦場としてグループ全体を設計している。

```
 メガ系                                   独立系
 ┌──────────────┐  ┌──────────────┐   ┌──────────────────┐
 │  MUFG        │  │  みずほFG     │   │ 三井住友トラストG   │
 │   ├ 銀行      │  │   ├ 銀行      │   │   ├ 三井住友信託銀行 │
 │   ├ 証券      │  │   ├ 証券      │   │   ├ 運用会社        │
 │   └ 三菱UFJ信託│  │   └ みずほ信託 │   │   └ 不動産関連      │
 └──────────────┘  └──────────────┘   └──────────────────┘
   信託は「一部門」        信託は「一部門」        信託が「本体」
```

## 4. なぜカストディが専業に集約されたのか

1990年代まで、資産管理は各信託銀行が自前でやっていた。それが2000年前後から集約に向かう。

理由は単純で、**カストディは規模の経済がすべてだから**である。
システム投資（決済・記帳・基準価額計算・海外決済のネットワーク）は残高が増えても大きく変わらない固定費。
一方、料率はベーシスポイント（0.01%）単位で極端に薄い。
したがって**残高が2倍になれば利益率は跳ね上がり、半分になれば赤字になる**。

```
  カストディの損益イメージ

  収益 ＝ 預り残高 × 極薄い料率 ＋ 取引件数 × 単価
  費用 ＝ システム費（ほぼ固定） ＋ 人件費（半固定）
          ▲
          └─ ここが動かないので、残高の増加分がそのまま利益に落ちる
             ＝ 業界全体で1〜2社に集約するのが経済合理的
```

結果、日本では2つの巨大な専業銀行に集約された。

- **日本カストディ銀行**：三井住友トラスト・グループなどが出資。
  信託財産総額 約476兆円、他勘定管理分を含む管理資産 約696兆円（2025年3月末、同社公表）。
  日本最大の資産管理専門信託銀行とされる。
- **日本マスタートラスト信託銀行**：三菱UFJ信託銀行系。
  マスタートラスト（複数運用会社に分散した年金資産の保管・記帳を一元化する仕組み）の担い手。

上場企業の大株主欄に「日本マスタートラスト信託銀行（信託口）」「日本カストディ銀行（信託口）」が
必ず並ぶのはこのため。**あれは投資判断をしている主体ではなく、名義を集約しているだけ**である。
実際の議決権行使は、その背後にいる年金基金や運用会社の指図で決まる。

## 5. 資産運用立国政策との関係

政府は2023年12月に「資産運用立国実現プラン」を決定し、
家計の貯蓄を投資へ動かし、運用業とアセットオーナー（年金など資産の保有者）の高度化を進める方針を掲げた。
信託銀行はこの政策の**裏方のインフラ**として、3か所で関わる。

| 政策の柱 | 信託銀行の関わり方 |
| --- | --- |
| 家計の資産形成（NISA拡充等） | 投資信託の受託。残高増加がそのまま受託者報酬に効く |
| 運用業の高度化・新規参入 | 新設運用会社のための受託・事務インフラの提供 |
| **アセットオーナーの高度化** | 企業年金のガバナンス強化。運用コンサル・数理・受託の需要増 |

とくに3つ目が本丸。2024年策定の**アセットオーナー・プリンシプル**と、
2025年1月改訂の**DB運用ガイドライン**により、企業年金には運用体制の説明責任が重くかかるようになった。
自前で専門人材を抱えられない中小の基金ほど外部の助言に頼ることになり、
**年金の管理・助言を長年やってきた信託銀行に仕事が集まる構図**になっている。

> ポイント：資産運用立国は「運用会社の話」に見えるが、
> 実際に事務と制度対応の負荷を吸収するのは信託銀行。**政策が需要を作るタイプのビジネス**。

## 6. 信託の応用 ─ 流動化・SPC・セキュリティトラスト

信託銀行の収益として目立たないが、金融の裏側で信託は構造材として使われている。
すべて [倒産隔離](01_信託とは何か.md) の応用である。

### (1) 資産の流動化（証券化）

企業が持つ売掛債権やローン債権、不動産を信託して受益権に変え、それを投資家に売る。

```
  オリジネーター（原資産の持ち主）
        │ ①資産を信託（ここで倒産隔離が成立）
        ▼
  【 信託（受託者＝信託銀行） 】
        │ ②受益権を発行
        ▼
   SPC（特別目的会社）── ③証券を発行 ──▶ 投資家
        │
        └ ④原資産のキャッシュフローで元利を支払う
```

ポイントは①。**オリジネーターが倒産しても、信託した資産は投資家のもの**として守られる。
だから投資家は、会社の信用力ではなく**資産そのものの質**を見て投資できる。
これが証券化という技術の中核であり、信託がなければ成立しない。

### (2) 不動産の信託受益権化

実物不動産の売買は登録免許税・不動産取得税が重く、権利関係の調査も煩雑。
そこで不動産を信託して**信託受益権**という権利にしてから売買する。
J-REITや私募ファンドの取引の多くがこの形を取る。
詳細は [不動産金融・REIT](../13_不動産金融・REIT/README.md)。

### (3) セキュリティトラスト（担保権信託）

協調融資（シンジケートローン）で貸し手が何十社もいると、担保権を誰の名義にするかが問題になる。
貸し手が入れ替わるたびに担保の登記を書き換えるのは非現実的。

そこで**担保権だけを信託し、信託銀行が全員のために担保権を保有する**。
貸し手が入れ替わっても担保権の名義は動かない。
2006年の信託法改正で正面から認められた仕組みで、大型のプロジェクトファイナンスなどで使われる。

```
  【従来】各貸し手が担保権を分有 → 貸出債権が移るたびに登記変更が必要
  【セキュリティトラスト】
      貸し手A ┐
      貸し手B ┼─ 受益者 ─▶ 【信託銀行が担保権者として保有】─▶ 担保物件
      貸し手C ┘                （貸し手が入れ替わっても名義は不動）
```

## 7. 競争要因（KSF）と参入障壁

| 要因 | 中身 | どれくらい効くか |
| --- | --- | --- |
| **免許・認可** | 兼営法の認可。併営業務（不動産仲介・証券代行・遺言）は信託銀行の独占領域 | 非常に高い。新規参入はほぼ不可能 |
| **事務の精度と実績** | 株主名簿・年金計算でのミスは致命傷。過去の無事故が信用になる | 高い。切り替えコストの源泉 |
| **システム投資** | カストディ・年金・株主名簿はすべて大規模システム | 高い。規模がないと回収できない |
| **顧客接点の幅** | 証券代行で経営層、年金で人事、不動産で総務に接点 | 中〜高。クロスセルの母体 |
| **人材** | 年金数理、不動産鑑定、相続・税務、法務 | 中。育成に時間がかかる |

> ポイント：信託銀行の参入障壁は「免許」だけではない。
> **数十年の無事故実績と大規模システム**という、お金では買いにくい資産が本当の壁になっている。

## 8. 隣接業界との境界

| 隣接 | 重なる部分 | 違う部分 |
| --- | --- | --- |
| [メガバンク](../01_メガバンク/README.md) | 預金・貸出・為替は同じ | 信託業務と併営業務を持たない |
| [資産運用](../06_資産運用/README.md) | 投信・年金を扱う | 運用会社は「運用判断」、信託銀行は「保管・管理」 |
| [証券](../05_証券/README.md) | 株式・債券を扱う | 証券会社は売買の媒介、信託銀行は名義と保管 |
| [不動産金融・REIT](../13_不動産金融・REIT/README.md) | 不動産の証券化 | 信託銀行は受託者・仲介、REITは投資主体 |
| [生命保険](../07_生命保険/README.md) | 年金資産の運用受託で競合 | 保険は保険料を集めて給付を約束する（リスクを取る） |

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **総合信託銀行** | 銀行業務・信託業務・併営業務をすべて営む信託銀行。3大信託が該当 |
| **資産管理専門信託銀行** | カストディ業務に特化した信託銀行。日本カストディ銀行など |
| **運用型信託会社** | 自ら運用の裁量を持つ信託会社。免許制 |
| **管理型信託会社** | 指図に従い管理のみ行う信託会社。登録制 |
| **SPC（特別目的会社）** | 証券化のために設立される器。資産の保有と証券発行だけを行う |
| **オリジネーター** | 証券化の対象となる資産をもともと持っていた者 |
| **流動化** | 売りにくい資産を証券に変えて売買できるようにすること |
| **セキュリティトラスト** | 担保権を信託し、受託者が全貸し手のために担保権を保有する仕組み |
| **シンジケートローン** | 複数の金融機関が協調して行う大型融資 |
| **資産運用立国** | 2023年12月に政府が決定した、家計の資産形成と運用業高度化の方針 |
| **信託口（しんたくぐち）** | 株主名簿上、信託財産として保有されていることを示す名義表記 |
