信託とは何か（三者構造と倒産隔離）

金融信託銀行
あこのページの単語集用語に触れると意味を確認できます16語
委託者からの隔離受託者からの隔離分別管理義務委託者受託者受益者信託財産固有財産倒産隔離忠実義務フィデューシャリー・デューティー兼営法実績配当元本補填契約信託勘定／銀行勘定民事信託（家族信託）

このノートで分かること：「信託」とは財産を他人に預けて管理・運用してもらう法的な箱であり、
その箱が「預けた人の破産からも、預かった人の破産からも切り離される」ことが最大の特徴だ、という一点。

結論：信託とは、財産の名義を受託者に移したうえで、「あなたのものにはならない」という縛りをかける仕組み。
名義は動くのに所有の実質は動かない。この「ねじれ」こそが信託の発明であり、信託銀行という特殊な業態が存在する理由。

1. まず身近な3つの例から入る

「信託」という言葉は抽象的で、定義から入ると必ず迷子になる。先に実物を3つ見る。

身近な例 財産を出す人 預かって管理する人 利益を受け取る人
投資信託（投信）買った個人投資家信託銀行（受託会社）買った個人投資家（同じ人）
企業年金会社（掛金を拠出）信託銀行（年金信託）退職した従業員
遺言信託遺言を書いた本人信託銀行相続人

3つとも「①財産を出す人 → ②預かって管理する人 → ③利益を受け取る人」という同じ形をしている。
投信では①と③が同じ人、年金と遺言では①と③が別人。この三角形が信託のすべてである。

法律用語では ①を委託者（いたくしゃ）、②を受託者（じゅたくしゃ）、③を受益者（じゅえきしゃ）と呼ぶ。

  ① 委託者（財産を出す人）
        │
        │ 財産を移す＋「この目的のために使え」と指図（＝信託行為）
        ▼
  ② 受託者（信託銀行など）───── 信託財産を管理・運用 ─────┐
        │   ・名義は受託者                                  │
        │   ・でも受託者の自腹財産（固有財産）とは完全に別管理  │
        │                                                  ▼
        └──── 収益・元本を引き渡す ────▶ ③ 受益者（利益を受け取る人）

2. 「預ける」と何が違うのか（信託の定義）

銀行預金も「お金を預ける」。ロッカーも「荷物を預ける」。信託はそのどちらとも違う。

形態 名義（法的な持ち主） 預かった側の扱い 預けた人が受け取るもの
銀行預金銀行に移る銀行の負債。自由に貸出に回せる元本＋約定利息（銀行が返済義務を負う）
貸金庫・寄託預けた人のまま預かるだけ。運用しない預けた物そのもの
信託受託者に移る受託者の帳簿外（オフバランス）。目的外に使えない信託財産の運用実績そのもの

要点は2つ。

  1. 名義は受託者に移る。だから受託者は自分の名前で株を買い、不動産を登記し、訴訟もできる。
    投信の株主名簿に「◯◯信託銀行（信託口）」と並ぶのはこのためで、運用会社の名前は出てこない。
  2. それでも受託者の財産にはならない。信託財産は受託者の貸借対照表（BS）に載らず、
    受託者が倒産しても債権者は手を出せない。これを倒産隔離（とうさんかくり）という。

ポイント：預金は「銀行にお金を貸す」契約、信託は「財産を別の箱に隔離する」制度。
だから預金には元本保証と預金保険があり、信託には原則それがない（実績配当）。

3. 信託財産の独立性＝倒産隔離

信託が金融インフラとして使われる最大の理由がここ。信託財産は三方向から守られる。

                    ┌──────────────────────────┐
  委託者が倒産  ✕──▶│                          │
                    │      信 託 財 産         │
  受託者が倒産  ✕──▶│   （独立した財産の箱）    │──▶ 受益者だけが果実を得る
                    │                          │
  受託者の債権者 ✕──▶└──────────────────────────┘
                              ▲
                              └ 分別管理義務・忠実義務・善管注意義務で縛られる
  • 委託者からの隔離：いったん信託した財産は委託者の手を離れる。委託者が破産しても差押えの対象外
    （ただし債権者を害する目的の信託は取り消される＝詐害信託の否認）。
  • 受託者からの隔離：信託法上、信託財産に対して受託者の債権者は強制執行できない。
  • 分別管理義務：受託者は信託財産を自分の固有財産や他の信託と分けて管理しなければならない。

この「箱」の性質は、証券化（資産流動化）やプロジェクトファイナンスの担保設計で徹底的に使われる。
詳しくは プレイヤーと市場 の応用編を参照。

4. 受託者が負う3つの義務

信託は「信じて託す」制度なので、受託者には普通の取引より重い義務が課される。

義務 中身 破るとどうなるか
忠実義務受益者の利益のためだけに行動する。自己取引・利益相反は原則禁止得た利益の吐き出し、損害賠償
善管注意義務職業的専門家として通常期待される注意を払う（善良な管理者の注意）損失の補填責任
分別管理義務固有財産・他の信託財産と混ぜない倒産隔離が崩れ、信託の意味が消える

これらをまとめて受託者責任（フィデューシャリー・デューティー）と呼ぶ。
近年、金融庁が金融機関全般に求めている「顧客本位の業務運営」の法的な源流はここにある。

5. なぜ銀行と別の免許なのか

素朴な疑問：「銀行も信託銀行も、お金を預かって運用するなら同じでは？」
答えはバランスシートに載るか載らないかで、これが監督の考え方を根本から変える。

【普通銀行】                          【信託銀行の信託勘定】

 資産        負債                      資産        負債
┌────────┬────────┐                  ┌────────┬────────┐
│ 貸出   │ 預金   │← 銀行が返済義務    │ 株式   │        │
│ 有価証券│        │   を負う          │ 債券   │ 受益権 │← 返済義務なし
│        ├────────┤                  │ 不動産 │        │   （実績配当）
│        │ 自己資本│← 損失の吸収材      │        │        │
└────────┴────────┘                  └────────┴────────┘
  リスクは銀行が取る                     リスクは受益者が取る
  → 自己資本比率規制で守る                → 分別管理・情報開示・行為規制で守る
  • 銀行業は、預金という返済義務（負債）を負って自分のリスクで貸す商売。
    破綻すると預金者が損をするので、自己資本比率規制と預金保険で守る。
  • 信託業は、他人の財産を他人の計算で管理する商売。受託者は原則リスクを取らない。
    守るべきは資本の厚みではなく、ちゃんと分別され、ちゃんと働いているかという行為の適正さ。

監督の効きどころが違うので、法律も分かれている。

法律 対象 位置づけ
信託法（2006年全面改正、2007年施行）信託そのもののルール民事の基本法。当事者の権利義務を定める
信託業法（2004年全面改正）信託を業として引き受ける者免許・登録、行為規制。信託会社はこれで参入
兼営法（金融機関の信託業務の兼営等に関する法律）銀行等が信託業務を兼営する場合これが「信託銀行」の根拠。銀行免許＋兼営の認可

つまり「信託銀行」という独立の免許があるわけではない。
正しくは「銀行免許を持つ会社が、兼営法の認可を受けて信託業務と併営業務を営んでいる」状態を指す。
ここは面接や実務でよく誤解されるポイント。

6. 普通銀行との業務範囲の違い

信託銀行ができることは、普通銀行の業務に「信託」と「併営」の2階層が積み上がった形になる。

階層 業務 普通銀行 信託銀行
1階：銀行業務預金・貸出・為替○○
2階：信託業務金銭信託、年金信託、投信の受託、不動産の信託、金銭債権の信託✕（原則）○
3階：併営業務不動産の売買仲介・鑑定、証券代行（株主名簿管理）、遺言の保管・執行✕○

3階の併営業務が信託銀行の「らしさ」を作っている。
とくに不動産仲介と証券代行は、本来まったく金融らしくない仕事で、普通銀行には認められていない。
なぜ信託銀行に認められたかというと、信託財産として不動産や株式を預かる以上、
その評価・移転・名義管理の実務能力が必要だからという筋立てである。
結果として信託銀行は「金融＋不動産仲介＋株式事務代行」という他国にあまり例のない複合業態になった。

ポイント：信託銀行の強さは免許の希少性そのものより、3階建て構造でしか取れない顧客接点にある。
詳しくは 信託銀行の収益源。

7. 元本保証はあるのか（実績配当の原則）

信託は原則実績配当。運用がマイナスなら受益者が損を被る。ここが預金との決定的な差。

ただし例外があり、合同運用指定金銭信託（一般口）など一部には元本補填契約が付き、
預金保険の対象にもなる。かつて主力商品だった貸付信託（1952年創設、2009年に新規募集終了）は
この元本補填型の代表で、高度成長期には長期資金の供給源として機能した。

商品 元本 預金保険 今の位置づけ
円預金保証対象（1金融機関1人1,000万円まで＋利息）銀行勘定の中核
元本補填付きの合同運用指定金銭信託補填契約あり対象残っているが主力ではない
貸付信託補填あり対象2009年に新規募集終了（歴史的商品）
投資信託・年金信託・実績配当型金銭信託なし対象外現在の主流

※本ノートは仕組みの説明であり、特定の商品の購入を勧めるものではない。

8. 誰が受託者になれるのか

信託の受託者は信託銀行だけではない。ここを整理しておくと、業界地図が見やすくなる。

                       受託者になれる人
                              │
        ┌─────────────────┬───┴────────────┬──────────────────┐
        ▼                 ▼                ▼                  ▼
  信託銀行            信託会社         個人・一般法人      特別法に基づく者
  （兼営法の認可）   （信託業法の免許/登録）  （家族信託など）    （共済・機構など）
        │                 │                │
  銀行業務も営む    運用型／管理型に分かれる  営業として反復
  併営業務も可      信託業のみ             継続はできない

「家族信託（民事信託）」が近年よく話題になるのは、2007年施行の新信託法で使い勝手が良くなり、
親の財産を子が受託者として管理する形が実務に乗ったため。
ただしこれは営業として報酬を取る信託ではないので、信託銀行の商売とは直接は競合せず、
むしろ「信託という言葉の認知度を上げる」役割を果たしている面がある。

9. 歴史を1段落だけ

日本の信託は1905年の担保付社債信託法に始まり、1922年の（旧）信託法・信託業法で制度が整った。
戦時統制と戦後の再編を経て、1943年の兼営法により銀行が信託業務を兼営する形が定着し、
「信託銀行」という業態が生まれる。戦後は貸付信託で長期資金を供給し、
1960年代に企業年金（適格退職年金・厚生年金基金）の受託で年金ビジネスの土台を築いた。
1990年代以降の金融自由化で普通銀行との垣根が下がり、2000年代の金融再編で
3メガグループの傘下に収まる形へと整理された。この流れは プレイヤーと市場 で扱う。

10. ここまでの要点

  • 信託＝委託者・受託者・受益者の三者構造。投信も企業年金も遺言信託も同じ形。
  • 名義は受託者に移るが受託者の財産にはならない＝倒産隔離。これが信託の商品価値。
  • 受託者には忠実義務・善管注意義務・分別管理義務という重い義務がかかる。
  • 銀行業は自分のリスクで貸す商売、信託業は他人の財産を他人の計算で管理する商売。
    リスクの所在が違うので免許と規制が分かれている。
  • 信託銀行＝銀行業務＋信託業務＋併営業務（不動産・証券代行・遺言）の3階建て。
