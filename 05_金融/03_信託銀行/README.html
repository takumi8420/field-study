信託銀行

学習済み更新 2026-09-20金融

隣との境界委託者／受託者／受益者倒産隔離分別管理義務兼営法実績配当カストディマスタートラスト証券代行信託受益権セキュリティトラスト

信託銀行とは、銀行業務に加えて「他人の財産を預かって管理・運用する仕事（信託）」を兼営している銀行のこと。
普通銀行が自分のバランスシートを膨らませて利ざやを稼ぐのに対し、
信託銀行は自分のバランスシートに載らない預り資産から手数料を取る。ここが業態の本質。

まず ① 信託とは何か を読めば、投資信託も企業年金も遺言信託も同じ形をしていることが分かる。
そのうえで ② 収益源 → ③ プレイヤーと市場 と進むのが最短。

1. 業界の定義・範囲

「信託銀行」という独立の免許は存在しない。正確には、
銀行免許を持つ会社が、兼営法（金融機関の信託業務の兼営等に関する法律）の認可を受けて
信託業務と併営業務を営んでいる状態を指す。業務は3階建てになる。

 ┌────────────────────────────────────────────────┐
 │ 3階 併営業務  不動産の売買仲介・鑑定 ／ 証券代行 ／ 遺言の保管・執行 │ ← 普通銀行は不可
 ├────────────────────────────────────────────────┤
 │ 2階 信託業務  金銭信託・年金信託・投信の受託・不動産の信託・債権の信託 │ ← 普通銀行は原則不可
 ├────────────────────────────────────────────────┤
 │ 1階 銀行業務  預金・貸出・為替                                  │ ← 普通銀行と同じ
 └────────────────────────────────────────────────┘
  • 隣との境界：メガバンク は1階だけ。
    資産運用 会社は「運用判断」を担い、信託銀行は「保管・名義・事務」を担う。
    証券 は売買の媒介で、信託銀行は保管側。
  • 3階の併営業務が「信託銀行らしさ」を作っている。金融らしくない不動産仲介や株主名簿管理が
    認められているのは、信託財産として不動産や株式を預かる以上、その評価・移転・名義管理の実務能力が要るという筋立てによる。

2. 市場規模と成長性

指標 数値 時点・出典
全国の信託財産総額約1,994.2兆円2026年3月末、信託協会「全国信託財産調」（2026年8月6日公表）
日本カストディ銀行 信託財産総額約476兆円2025年3月末、同社公表
同 管理資産（他勘定管理分を含む）約696兆円2025年3月末、同社公表
統計の更新頻度年2回（3月末・9月末）信託協会

読み方の注意が2つある。

  1. 信託財産総額は信託契約の残高の合計であり、日本の総資産ではない。
    同じ資産が年金信託 → 投資信託 → 有価証券の信託と多段で経由すれば、その都度カウントされる。
  2. 増加分の相当部分が株価・不動産の評価額の上昇による。
    趨勢を見たいなら、投信残高の増加と証券化案件の増加を分けて読む必要がある。

3. バリューチェーン（お金と事務の流れ）

信託銀行は「川上から川下へモノを流す」型の業界ではない。
資産の持ち主と、運用する人と、記録する人のあいだに立つ構造で捉えるのが正しい。

  資産の出し手                  判断する人               記録・保管する人
 ┌──────────┐            ┌──────────┐           ┌──────────────┐
 │ 企業(年金)  │─委託─────▶│ 運用会社   │──指図───▶│ 信託銀行     │
 │ 個人(投信)  │            │（買う判断） │           │ カストディ専業 │
 │ 上場企業    │─事務委託──────────────────────────▶│（保管・決済・  │
 │ 不動産の売主 │─仲介依頼──────────────────────────▶│  記帳・名義）  │
 └──────────┘            └──────────┘           └──────────────┘
        ▲                                                  │
        └──── 給付・分配・売却代金 ◀────────────────────────┘

  付加価値が乗るのは ①判断（運用会社）と ②接点（提案・仲介）。
  ③記録・保管は料率が極薄いので、規模を積んだ者だけが儲かる。
  • 運用の「判断」部分は運用会社に流れており、信託銀行本体の取り分は
    管理・年金数理・コンサルティング・事務にシフトしている。
  • 一方で、証券代行で経営層、年金で人事、不動産で総務と、企業の3つの部署に同時に接点を持てるのが強み。
    ここが不動産仲介やM&A関連の提案につながる。

4. 主要プレイヤーとシェア

企業 立ち位置 特徴
三井住友信託銀行（三井住友トラスト・グループ）独立系の総合信託メガバンク傘下に入らない唯一の信託専業グループ。信託・不動産・証券代行・年金の総合力。日本カストディ銀行の主要出資者

みずほ信託銀行（みずほFG）メガ系の総合信託3社では規模で劣るが、不動産・証券代行・資産承継に強みを持つとされる。One MIZUHOの一体運営
日本カストディ銀行資産管理専業信託財産総額 約476兆円（2025年3月末）。装置産業として残高を積む

野村信託銀行、SMBC信託銀行 ほかグループ内特化型親会社の顧客向けに投信受託・富裕層業務。小回りが利く
ステート・ストリート信託銀行 ほか外資グローバル・カストディ海外投資家が持つ日本資産の受け皿
  • 上場企業の大株主欄に「日本マスタートラスト信託銀行（信託口）」が常に並ぶのは、
    多数の年金・投信の名義がそこに集約されているだけで、同社が投資判断をしているわけではない。
    日本の株式市場で最も誤解されやすい点。
  • 証券代行の受託社数は三菱UFJ信託・三井住友信託の2行に集中し、みずほ信託が続く構図とされる。
    公表の仕方がまちまちなので、「上位2行に集中」という構造で捉えるのが安全。

5. 収益モデル・コスト構造

【普通銀行】 預金を集める → 貸す → 利回り − 調達コスト ＝ 利ざや
              ★資本を積まないと増やせない／貸倒れで元本が毀損する

【信託銀行】 財産を預かる → 管理・運用・事務 → 預り資産残高 × 料率 ＝ 信託報酬
              ★資本をほとんど使わずに増やせる／運用損は受益者が被る
収益源 課金の形 経済的な性格
年金信託預り年金資産 × 料率（管理＋運用）残高連動。超長期で剥がれにくい
証券代行株主数・事務量に応じた年間フィー固定費的。切替コストが高く契約が長い
資産管理（カストディ）残高 × 極薄い料率（bp単位）＋件数規模の経済が極端に効く装置産業
投資信託の受託信託財産 × 受託者報酬（年0.0x%台とされる）残高連動。NISA拡充が追い風
不動産（仲介・信託・証券化）成約時の仲介手数料＋管理報酬案件ベース。業績のブレ幅を作る
相続・資産承継申込時／保管中／執行時の3段階単価が大きく、次世代顧客の獲得口
  • コストの中心は人件費とシステム費で、どちらも半固定。
    だから残高が増えた分はそのまま利益に落ち、減ると一気に苦しくなる。
  • 見るべき指標は自己資本比率ではなく、受託財産残高と料率（bp）。
  • 弱みは、株価・不動産市況に残高が連動すること、料率の低下圧力、内部統制コストの増加。

ポイント：信託銀行は「儲け方が静かで、壊れ方が派手」な業態。
日々の収益は残高 × 薄い料率の積み上げだが、事務事故や情報漏洩で信用を失うと契約が一気に動く。

6. 競争要因（KSF）と参入障壁

要因 中身 効き方
免許・認可兼営法の認可。併営業務は信託銀行の独占領域非常に高い。新規参入はほぼ不可能
無事故の実績株主名簿・年金計算のミスは致命傷。過去の無事故が信用になる高い。切替コストの源泉
システム投資カストディ・年金・株主名簿はすべて大規模システム高い。規模がないと回収できない
顧客接点の幅証券代行＝経営層、年金＝人事、不動産＝総務中〜高。クロスセルの母体
人材年金数理、不動産鑑定、相続・税務、法務中。育成に時間がかかる

本当の壁は免許ではなく、数十年の無事故実績と大規模システムという、お金では買いにくい資産にある。

7. 規制・法制度

法律・制度 対象 位置づけ
信託法（2006年全面改正、2007年施行）信託そのもの民事の基本法。セキュリティトラストや自己信託を正面から認めた
信託業法（2004年全面改正）信託を業として引き受ける者免許（運用型）／登録（管理型）。信託会社の参入根拠
兼営法銀行等が信託業務を兼営する場合これが「信託銀行」の根拠
銀行法1階の銀行業務自己資本比率規制、預金保険
金融商品取引法投信受託・証券代行まわりインサイダー規制、業務管理体制
確定給付企業年金法／DB運用ガイドライン（2025年1月改訂）企業年金運用委託機関の定期評価、専門性の確保を要求
アセットオーナー・プリンシプル（2024年策定）年金基金等の資産保有者受入れ表明が促され、外部助言の需要を生む
資産運用立国実現プラン（2023年12月決定）政策方針家計の資産形成と運用業・アセットオーナーの高度化

規制は「資本の厚みを守る」方向ではなく、分別管理・情報開示・行為の適正さを見る方向に効く。
他人の財産を他人の計算で管理する商売なので、守るべきものが銀行と違うため。

8. 最近のトピック

詳細は ④ 直近トピック（2026年9月時点） に分けてある。要点5つ。

  1. 信託財産総額が約1,994.2兆円（2026年3月末、信託協会）と2,000兆円目前。ただし市況による評価増が相当含まれる。
  2. 資産運用立国・アセットオーナー改革が制度として需要を作っている。中小の年金基金ほど外部助言に頼り、年金に長くいる信託銀行に仕事が集まる。
  3. 資産承継のデジタル化。2026年8月26日、MUFGがスマホアプリで生前の資産管理と承継を一体提供する信託商品を発表（同社リリース）。
  4. 資本を使う事業を外に出す再編。三井住友トラストはリース子会社を共同事業化（2026年3月30日公表）、三菱UFJ信託はSPC管理事業を承継。方向は手数料型への集中で一致。
  5. コンプライアンスが最大のリスク。三井住友信託は元社員のインサイダー疑いで2025年3月24日に告発を公表。罰則より、証券代行・M&A助言の信用失墜がビジネスに効く。
