# 信託銀行

- 大分類: 金融
- 状態: done
- 更新日: 2026-09-20

信託銀行とは、**銀行業務に加えて「他人の財産を預かって管理・運用する仕事（信託）」を兼営している銀行**のこと。
普通銀行が自分のバランスシートを膨らませて利ざやを稼ぐのに対し、
信託銀行は**自分のバランスシートに載らない預り資産から手数料を取る**。ここが業態の本質。

## 1. 業界の定義・範囲

「信託銀行」という独立の免許は存在しない。正確には、
**銀行免許を持つ会社が、兼営法（金融機関の信託業務の兼営等に関する法律）の認可を受けて
信託業務と併営業務を営んでいる状態**を指す。業務は3階建てになる。

```
 ┌────────────────────────────────────────────────┐
 │ 3階 併営業務  不動産の売買仲介・鑑定 ／ 証券代行 ／ 遺言の保管・執行 │ ← 普通銀行は不可
 ├────────────────────────────────────────────────┤
 │ 2階 信託業務  金銭信託・年金信託・投信の受託・不動産の信託・債権の信託 │ ← 普通銀行は原則不可
 ├────────────────────────────────────────────────┤
 │ 1階 銀行業務  預金・貸出・為替                                  │ ← 普通銀行と同じ
 └────────────────────────────────────────────────┘
```

- **隣との境界**：[メガバンク](../01_メガバンク/README.md) は1階だけ。
  [資産運用](../06_資産運用/README.md) 会社は「運用判断」を担い、信託銀行は「保管・名義・事務」を担う。
  [証券](../05_証券/README.md) は売買の媒介で、信託銀行は保管側。
- 3階の併営業務が「信託銀行らしさ」を作っている。金融らしくない不動産仲介や株主名簿管理が
  認められているのは、**信託財産として不動産や株式を預かる以上、その評価・移転・名義管理の実務能力が要る**という筋立てによる。

## 2. 市場規模と成長性

| 指標                              | 数値                  | 時点・出典                                                  |
| --------------------------------- | --------------------- | ----------------------------------------------------------- |
| 全国の信託財産総額                | 約1,994.2兆円         | 2026年3月末、信託協会「全国信託財産調」（2026年8月6日公表） |
| 日本カストディ銀行 信託財産総額   | 約476兆円             | 2025年3月末、同社公表                                       |
| 同 管理資産（他勘定管理分を含む） | 約696兆円             | 2025年3月末、同社公表                                       |
| 統計の更新頻度                    | 年2回（3月末・9月末） | 信託協会                                                    |

読み方の注意が2つある。

1. 信託財産総額は**信託契約の残高の合計**であり、日本の総資産ではない。
   同じ資産が年金信託 → 投資信託 → 有価証券の信託と多段で経由すれば、その都度カウントされる。
2. 増加分の相当部分が**株価・不動産の評価額の上昇**による。
   趨勢を見たいなら、投信残高の増加と証券化案件の増加を分けて読む必要がある。

## 3. バリューチェーン（お金と事務の流れ）

信託銀行は「川上から川下へモノを流す」型の業界ではない。
**資産の持ち主と、運用する人と、記録する人のあいだに立つ**構造で捉えるのが正しい。

```
  資産の出し手                  判断する人               記録・保管する人
 ┌──────────┐            ┌──────────┐           ┌──────────────┐
 │ 企業(年金)  │─委託─────▶│ 運用会社   │──指図───▶│ 信託銀行     │
 │ 個人(投信)  │            │（買う判断） │           │ カストディ専業 │
 │ 上場企業    │─事務委託──────────────────────────▶│（保管・決済・  │
 │ 不動産の売主 │─仲介依頼──────────────────────────▶│  記帳・名義）  │
 └──────────┘            └──────────┘           └──────────────┘
        ▲                                                  │
        └──── 給付・分配・売却代金 ◀────────────────────────┘

  付加価値が乗るのは ①判断（運用会社）と ②接点（提案・仲介）。
  ③記録・保管は料率が極薄いので、規模を積んだ者だけが儲かる。
```

- 運用の「判断」部分は運用会社に流れており、信託銀行本体の取り分は
  **管理・年金数理・コンサルティング・事務**にシフトしている。
- 一方で、証券代行で経営層、年金で人事、不動産で総務と、**企業の3つの部署に同時に接点を持てる**のが強み。
  ここが不動産仲介やM&A関連の提案につながる。

- 上場企業の大株主欄に「日本マスタートラスト信託銀行（信託口）」が常に並ぶのは、
  **多数の年金・投信の名義がそこに集約されているだけ**で、同社が投資判断をしているわけではない。

  公表の仕方がまちまちなので、**「上位2行に集中」という構造で捉えるのが安全**。

## 5. 収益モデル・コスト構造

```
【普通銀行】 預金を集める → 貸す → 利回り − 調達コスト ＝ 利ざや
              ★資本を積まないと増やせない／貸倒れで元本が毀損する

【信託銀行】 財産を預かる → 管理・運用・事務 → 預り資産残高 × 料率 ＝ 信託報酬
              ★資本をほとんど使わずに増やせる／運用損は受益者が被る
```

| 収益源                       | 課金の形                                   | 経済的な性格                         |
| ---------------------------- | ------------------------------------------ | ------------------------------------ |
| 年金信託                     | 預り年金資産 × 料率（管理＋運用）          | 残高連動。超長期で剥がれにくい       |
| 証券代行                     | 株主数・事務量に応じた年間フィー           | 固定費的。切替コストが高く契約が長い |
| 資産管理（カストディ）       | 残高 × 極薄い料率（bp単位）＋件数          | 規模の経済が極端に効く装置産業       |
| 投資信託の受託               | 信託財産 × 受託者報酬（年0.0x%台とされる） | 残高連動。NISA拡充が追い風           |
| 不動産（仲介・信託・証券化） | 成約時の仲介手数料＋管理報酬               | 案件ベース。業績のブレ幅を作る       |
| 相続・資産承継               | 申込時／保管中／執行時の3段階              | 単価が大きく、次世代顧客の獲得口     |

- **コストの中心は人件費とシステム費**で、どちらも半固定。
  だから残高が増えた分はそのまま利益に落ち、減ると一気に苦しくなる。
- **見るべき指標は自己資本比率ではなく、受託財産残高と料率（bp）**。
- 弱みは、株価・不動産市況に残高が連動すること、料率の低下圧力、内部統制コストの増加。

> ポイント：信託銀行は「儲け方が静かで、壊れ方が派手」な業態。
> 日々の収益は残高 × 薄い料率の積み上げだが、事務事故や情報漏洩で信用を失うと契約が一気に動く。

## 6. 競争要因（KSF）と参入障壁

| 要因             | 中身                                                       | 効き方                           |
| ---------------- | ---------------------------------------------------------- | -------------------------------- |
| **免許・認可**   | 兼営法の認可。併営業務は信託銀行の独占領域                 | 非常に高い。新規参入はほぼ不可能 |
| **無事故の実績** | 株主名簿・年金計算のミスは致命傷。過去の無事故が信用になる | 高い。切替コストの源泉           |
| **システム投資** | カストディ・年金・株主名簿はすべて大規模システム           | 高い。規模がないと回収できない   |
| **顧客接点の幅** | 証券代行＝経営層、年金＝人事、不動産＝総務                 | 中〜高。クロスセルの母体         |
| **人材**         | 年金数理、不動産鑑定、相続・税務、法務                     | 中。育成に時間がかかる           |

本当の壁は免許ではなく、**数十年の無事故実績と大規模システム**という、お金では買いにくい資産にある。

## 7. 規制・法制度

| 法律・制度                                                  | 対象                           | 位置づけ                                                     |
| ----------------------------------------------------------- | ------------------------------ | ------------------------------------------------------------ |
| **信託法**（2006年全面改正、2007年施行）                    | 信託そのもの                   | 民事の基本法。セキュリティトラストや自己信託を正面から認めた |
| **信託業法**（2004年全面改正）                              | 信託を業として引き受ける者     | 免許（運用型）／登録（管理型）。信託会社の参入根拠           |
| **兼営法**                                                  | 銀行等が信託業務を兼営する場合 | **これが「信託銀行」の根拠**                                 |
| **銀行法**                                                  | 1階の銀行業務                  | 自己資本比率規制、預金保険                                   |
| **金融商品取引法**                                          | 投信受託・証券代行まわり       | インサイダー規制、業務管理体制                               |
| **確定給付企業年金法／DB運用ガイドライン**（2025年1月改訂） | 企業年金                       | 運用委託機関の定期評価、専門性の確保を要求                   |
| **アセットオーナー・プリンシプル**（2024年策定）            | 年金基金等の資産保有者         | 受入れ表明が促され、外部助言の需要を生む                     |
| **資産運用立国実現プラン**（2023年12月決定）                | 政策方針                       | 家計の資産形成と運用業・アセットオーナーの高度化             |

規制は「資本の厚みを守る」方向ではなく、**分別管理・情報開示・行為の適正さ**を見る方向に効く。
他人の財産を他人の計算で管理する商売なので、守るべきものが銀行と違うため。

## 8. 最近のトピック

詳細は [④ 直近トピック（2026年9月時点）](04_直近トピック_2026.md) に分けてある。要点5つ。

1. **信託財産総額が約1,994.2兆円**（2026年3月末、信託協会）と2,000兆円目前。ただし市況による評価増が相当含まれる。
2. **資産運用立国・アセットオーナー改革が制度として需要を作っている**。中小の年金基金ほど外部助言に頼り、年金に長くいる信託銀行に仕事が集まる。
3. **資産承継のデジタル化**。2026年8月26日、MUFGがスマホアプリで生前の資産管理と承継を一体提供する信託商品を発表（同社リリース）。
4. **資本を使う事業を外に出す再編**。三井住友トラストはリース子会社を共同事業化（2026年3月30日公表）、三菱UFJ信託はSPC管理事業を承継。方向は手数料型への集中で一致。
5. **コンプライアンスが最大のリスク**。三井住友信託は元社員のインサイダー疑いで2025年3月24日に告発を公表。罰則より、証券代行・M&A助言の信用失墜がビジネスに効く。

| **委託者／受託者／受益者** | 財産を出す人／預かって管理する人／利益を受け取る人 → [①](01_信託とは何か.md)                    |

| **兼営法**                 | 金融機関の信託業務の兼営等に関する法律。信託銀行の法的根拠 → [①](01_信託とは何か.md)            |

| **カストディ**             | 投資家に代わり有価証券を保管し、決済・配当受取・報告を行う業務 → [②](02_信託銀行の収益源.md)    |
| **マスタートラスト**       | 複数運用会社に分散した年金資産の保管・記帳を1か所に集約する仕組み → [②](02_信託銀行の収益源.md) |
| **証券代行**               | 上場企業の株主名簿管理・配当支払・総会運営支援を受託する業務 → [②](02_信託銀行の収益源.md)      |
| **信託受益権**             | 信託財産から利益を受ける権利。不動産をこの形にして流通させる → [②](02_信託銀行の収益源.md)      |
| **セキュリティトラスト**   | 担保権を信託し、受託者が全貸し手のために担保権を保有する仕組み → [③](03_プレイヤーと市場.md)    |
