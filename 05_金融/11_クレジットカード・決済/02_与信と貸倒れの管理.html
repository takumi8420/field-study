② 与信と貸倒れの管理 ── カード会社が本当に売っているもの

金融クレジットカード・決済
あこのページの単語集用語に触れると意味を確認できます14語
支払可能見込額調査生活維持費年間請求予定額例外（調査不要）与信包括支払可能見込額指定信用情報機関異動情報途上与信総量規制抗弁の接続期限の利益喪失貸倒引当金／信用コストサービサー

このノートで分かること：カード会社が売っているのは決済の便利さではなく、「見ず知らずの人に、担保なしで、数十万円まで後払いを許す」という信用。
その信用をどう測り、外れたときにどう回収し、法律がどこまで縛るのかを扱う。

結論を先に：カードの与信は「入口の審査」と「使い始めてからの継続審査（途上与信）」の二段構えで管理されている。
入口では割賦販売法が「年収からの機械的な計算式」を義務づけ、
使い始めてからは各社が信用情報機関のデータと自社の利用履歴で枠を上げ下げする。
そして貸倒率が1〜2%動くだけで利益が消えるため、この業界は「伸ばす」より「外さない」ことに執着する。

① カード会社の収益3本柱 で見たとおり、利益は残高（分割・リボ・キャッシング）から出る。
残高を伸ばせば利益が増えるが、同時に貸倒れも増える。その綱引きがこのノートのテーマ。

2. 【核心】入口の審査は法律で計算式が決まっている

日本では「いくらまで後払いを許してよいか」がカード会社の裁量ではなく法律で枠づけられている。
これは2006〜2010年の多重債務問題（貸金業法改正の時代）の反省から入った規制。

【包括支払可能見込額の計算式（割賦販売法）】

  包括支払可能見込額 ＝ （年収 － 生活維持費 － 年間請求予定額） × 90%
                          ▲          ▲              ▲          ▲
                          │          │              │          経済産業大臣が
                          │          │              │          定める割合
                          │          │              他社カード等の
                          │          │              1年間の支払予定額
                          │          省令で定める定額
                          │         （居住形態と扶養人数で決まる。
                          │           例：持家・本人のみ90万円 など）
                          申告された年収

  → ショッピング利用可能枠は、この金額を超えて設定できない
用語 意味 実務上のポイント
支払可能見込額調査申込時と、その後も定期的に行う義務やらずに枠を出すと行政処分の対象
生活維持費省令で定額が決まっている実際の家計ではなく居住形態（持家/借家）と扶養家族数で機械的に決まる
年間請求予定額他社を含む既存のクレジット債務ここが指定信用情報機関の出番
例外（調査不要）極度額30万円以下のカード、翌月一括払い専用、支払回数2か月以内 など少額・短期のカードは簡易に出せる

なぜ機械的な式なのか。「この人は大丈夫そう」という各社の主観に任せると、
景気が良いときに各社が一斉に枠を出し、同じ人に何社からも枠が積み上がる。
それが2000年代の多重債務問題の構図だった。
だから「年収から引き算する」という全社共通の物差しを法律で置いた。

3. 指定信用情報機関 ── 業界共有のブラックリストではなく「共有台帳」

日本には3つの信用情報機関があり、カード会社は割賦販売法の指定信用情報機関であるCICへの加入と照会が事実上必須。

機関 主な会員 根拠法 扱う情報
CICクレジットカード会社、信販、携帯キャリア割賦販売法の指定信用情報機関／貸金業法の指定信用情報機関割賦・クレジットの契約と支払状況
JICC（日本信用情報機構）消費者金融、信販、一部カード貸金業法の指定信用情報機関貸金の契約と支払状況
KSC（全国銀行個人信用情報センター）銀行、信金、保証会社全国銀行協会の自主運営銀行ローン、保証履行
【登録される主な情報と、おおよその保有期間】

  申込情報 ──────────────── 照会日から6か月
   （短期間に何社も申し込むと
     「申込ブラック」と呼ばれる状態になる）

  契約・支払状況 ─────────── 契約終了から5年
   ・入金区分（毎月「$（入金）」「A（未入金）」などで24か月分が並ぶ）
   ・残債額、利用可能枠

  異動（＝事故情報） ───────── 契約終了から5年
   ・61日以上または3か月以上の延滞
   ・代位弁済（保証会社が肩代わり）
   ・強制解約
   ・自己破産等（KSCは最長10年とされる）

実務上の含意：いわゆる「ブラックリスト」という名簿が存在するわけではない。
あるのは支払いの履歴データで、そこに「異動」という記録が付くと
各社の審査ロジックがほぼ自動で否決する、というだけ。
逆に言えば、カード会社は他社での支払いぶりを見て自社の枠を決めている。
これは業界全体で貸倒れを抑えるための、事実上のインフラである。

4. 途上与信 ── 使い始めてからが本番

審査を通した後も、カード会社は定期的に会員を見直す。これが途上与信。

トリガー 見ているもの 典型的なアクション
定期（半年〜1年ごと）信用情報機関の最新データ、他社での延滞増枠案内／枠の据置／減枠
支払遅延の発生何日遅れたか、初回か常習か利用停止、枠の引下げ
利用パターンの急変急なキャッシング増、高額利用の連発、換金性の高い商品への集中一時停止、確認連絡
会員からの増枠申請改めて支払可能見込額を算定承認／否認
リボ残高の増加残高の絶対額と返済ペース収益機会であると同時にリスク要因。両面で見る

カード会社のジレンマ：リボ残高が増えると①で見たとおり利益が増える。
しかしリボ残高が増えている会員は、同時にいちばん貸倒れやすい会員でもある。
「儲かる顧客」と「危ない顧客」が同じ人物であるという構造が、この業界の与信を難しくしている。
実務では「リボ残高は伸ばすが、その質（返済継続率）を落とさない」という運用になる。

 会計上：延滞が進むにつれ「貸倒引当金」を積み増す
        ＝ 実際に回収不能になる前から、費用として先に計上される
会計・実務の用語 意味
貸倒引当金将来回収できないと見込む金額をあらかじめ費用計上したもの。クレディセゾン単体の流動資産の貸倒引当金は443億円（2026年3月期、前期417億円）
貸倒償却回収不能が確定し、債権を落とすこと
貸倒関連費用／信用コスト引当金繰入＋償却。カード会社の決算で利益を最も動かす項目のひとつ
期限の利益喪失「分割で払ってよい」という権利を失い、残額を一括で請求される状態
代位弁済保証会社が本人に代わって支払うこと。信用情報に記録される
サービサー（債権回収会社）法務大臣の許可を受けた債権回収の専門会社。不良債権を額面より大幅に安く買い取る

貸倒率がなぜ致命的か

【簡単な感度分析：取扱高1兆円・リボ等残高1,000億円のカード会社】

  収益  加盟店手数料（イシュア取り分1.5%） … 150億円
        リボ・分割手数料（残高×14%）      … 140億円
        合計                              … 290億円

  費用  ポイント還元（取扱高の1.0%）       … 100億円
        資金調達・システム・人件費など      … 120億円
        貸倒れ                            … ？

  貸倒率が 残高の 2% → 20億円 : 営業利益 約50億円
           残高の 5% → 50億円 : 営業利益 約20億円
           残高の 8% → 80億円 : 営業損失 ▲10億円
                                   ▲
                   数%の違いで黒字と赤字が入れ替わる
                   （数値は構造を示すための例示。実際の各社の水準ではない）

ポイント：カード会社の利益は「貸倒率の想定がどれだけ当たっているか」でほぼ決まる。
だから各社はスコアリングモデルに投資し、景気が悪化しそうなときは
収益を捨ててでも枠を絞る。伸ばす競争より、外さない競争が本質である。

6. 法規制の地図 ── カードは2つの法律にまたがる

カードの「ショッピング」と「キャッシング」は、別の法律で規制されている。これが理解の要。

項目 ショッピング（後払い） キャッシング（借入）
根拠法割賦販売法貸金業法＋利息制限法
監督官庁経済産業省金融庁
登録包括信用購入あっせん業者の登録貸金業の登録
与信の上限支払可能見込額（年収－生活維持費－既存債務）×90%総量規制：年収の1/3まで
金利の上限明示的な上限金利規制はない（実務は年率15%前後）利息制限法：年15〜20%（元本により変動）
書面交付契約内容・支払条件の書面（電磁的方法も可）交付義務契約書面・受取証書の交付義務
抗弁の接続あり（商品に問題があればカード会社への支払いを拒める）なし

「抗弁の接続」はカードの隠れた価値。買った商品が届かない・欠陥があるとき、
一定の条件下でカード会社への支払いを止められる（割賦販売法30条の4等）。
これは「翌月一括払い」には原則適用されず、分割・リボなど割販法の対象取引で機能する。
カード会社はこのリスクも負っているため、加盟店の審査・管理が重い仕事になる
（④ 不正利用とセキュリティ 参照）。
