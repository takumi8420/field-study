③ 会員獲得の経済学と業界の出自

金融クレジットカード・決済
あこのページの単語集用語に触れると意味を確認できます10語
CAC（顧客獲得コスト）LTV（顧客生涯価値）稼動会員休眠会員プロパーカード提携カード（コブランドカード）ハウスカードリカーリング収益3者モデル（クローズドループ）アクワイアリング

このノートで分かること：なぜ日本には成人1人あたり3枚ものカードがあり、そのうち大半が使われていないのか。
そして、なぜ「銀行系」「流通系」「信販系」で同じカード事業なのに儲け方が違うのか。

結論を先に：カードは「1人に何枚持たせるか」ではなく「1人のメインカードになれるか」の勝負。
獲得にかけた費用は、その会員が何年もメインで使い、あわよくば残高を作ってくれて初めて回収できる。
2枚目・3枚目の休眠カードはコストだけを生む負債である。
だから2020年代後半の各社は、会員数を増やす競争から降り、
休眠の整理（会員数の減少）と稼動率・単価の引き上げに方針を変えている。

1. 日本のカードは「多すぎる」

指標 値 出典
クレジットカード発行枚数（2025年3月末）3億2,057万枚（前年比+2.2%）日本クレジット協会（2025年11月14日公表、回答243社）
うち家族カード2,505万枚（+1.0%）同上
うち法人カード1,214万枚（+3.8%）同上
成人人口（概算）約1.04億人総務省人口推計ベースの概算
成人1人あたり約3枚上記からの計算
【1人が3枚持つと何が起きるか】

  会員A ─┬─ カードX（メイン）… 月10万円利用、リボ残高あり ＝ 利益が出る
         ├─ カードY（サブ） … 年に数回、1万円   ＝ ほぼトントン
         └─ カードZ（休眠） … 0円               ＝ 赤字

  カードZの発行会社から見ると：
    入会時の獲得費（広告・入会ポイント）  ▲3,000〜10,000円 …すでに支払済み
    毎年の維持費（明細・与信管理・
    システム・カード再発行・信用情報照会） ▲数百円/年
    収入                                    0円
    ─────────────────────────────────────
    永久に回収できない

ここが2020年代の転換点。「とにかく枚数を配る」戦略は、
加盟店手数料が薄く、金利収入も生まない会員を大量に抱え込むだけだった。
クレディセゾンは2026年3月期にカード会員数を2,180万人（前期末比 -6.9%）まで減らす一方、
稼動会員数は1,358万人（+0.3%）を維持している（決算短信）。
会員を「減らして」利益を増やすフェーズに入ったことが数字に出ている。

2. 【核心】会員1人の採算 ── CACとLTV

【カード1枚の生涯収支（イメージ。数値は構造説明のための例示）】

 ■ 獲得コスト（CAC：Customer Acquisition Cost）
   入会特典ポイント          ▲5,000円  ← 「入会で8,000ポイント」の原資
   広告・アフィリエイト報酬    ▲3,000円  ← 比較サイト経由の成果報酬
   審査・発行・郵送           ▲1,000円
   ───────────────────────────
   合計                      ▲9,000円  …発行した瞬間の赤字

 ■ 年間の回収（メイン利用してくれる場合）
   年間利用額 100万円 × イシュア取り分1.5%  ＝ +15,000円
   ポイント還元 100万円 × 1.0%              ＝ ▲10,000円
   与信・明細・コールセンター等              ＝ ▲2,000円
   ───────────────────────────────────
   一括払いだけの会員          年 +3,000円 → 回収に3年
   リボ残高20万円を持つ会員     年 +3,000円 +28,000円（残高×14%）
                              ＝ 年 +31,000円 → 4か月で回収

 ■ 休眠した場合
   年 ▲数百円が延々と続き、9,000円は永久に戻らない
会員の型 カード会社から見た価値 打ち手
メイン＋残高あり圧倒的に良い顧客ゴールド/プラチナへ誘導、枠の増額
メインだが一括のみトントン〜薄利公共料金・家賃・サブスクの登録を促す（解約されにくい＝粘着性）
サブ（たまに使う）薄利メイン化キャンペーン
休眠純粋なコスト利用喚起 → 効かなければ未稼働会員手数料か退会

なぜ公共料金と家賃を押すのか。一度登録されると解約の手間が大きく、
何年も自動的に取扱高が積み上がるから。丸井グループは「家計シェア最大化」と呼び、
家賃払いや公共料金の定期払いの伸長でカードクレジット取扱高4兆9,640億円（2026年3月期、+10%）を達成したと説明している。
同社は売上総利益の67.1%がリカーリング（繰り返し発生する）収益であると開示している。

3. プロパーカードと提携カード ── 誰が獲得コストを払うのか

種類 発行主体 会員を連れてくるのは 手数料・ポイント原資の負担 例
プロパーカードカード会社自身カード会社（広告・店頭・銀行窓口）カード会社が全額三井住友カード（NL等）、JCBカード、アメリカン・エキスプレス
提携カード（アフィニティ／コブランド）カード会社＋事業会社事業会社（航空会社、小売、鉄道、大学、球団など）ポイント原資は事業会社が一部負担、カード会社は送客料を払う場合も航空会社系、百貨店系、通信キャリア系、球団カード
ハウスカード小売・専門店が自社のみで発行自社自社一部の百貨店カード、店舗独自の後払い
【提携カードのお金の流れ】

  提携先（例：小売チェーン）           カード会社（イシュア）
       │                                    │
       │  会員を連れてくる（店頭で勧誘）────▶ │  審査・発行・与信・回収
       │                                    │
       │ ◀──── 獲得報酬／手数料の一部分配 ───│
       │                                    │
       │  自社ポイントの原資を負担           │  インターチェンジフィーを取得
       │  （自社店舗での利用分）             │
       ▼                                    ▼
  得るもの：来店頻度・客単価の上昇       得るもの：獲得コストの外部化
            顧客データ                            会員基盤の拡大
  
  ▲ 提携先にとってカードは「値引きの手段」でもある。
    自社店舗で5%オフにする原資は、結局は自社の粗利から出ている。

提携カードの本質：カード会社は獲得コストを提携先に肩代わりさせている。
代わりに、提携先が強いところ（その小売の店内）でしか使われない偏った会員を抱えることになる。
一方でプロパーカードは獲得が重いが、どこで使われても自社の利益になるし、
提携先の都合で関係を切られるリスクがない。

4. 出自による4つの類型 ── 同じカードでも稼ぎ方が違う

日本のカード会社は、もともと何の会社だったかで戦い方が決まっている。

類型 代表例 出自 会員をどう集めるか 収益の重心 弱点
銀行系三井住友カード、三菱UFJニコス、UCカード銀行の決済機能の延長銀行の口座・窓口・アプリ加盟店手数料（アクワイアリングも強い）＋銀行グループ全体での回収単体では収益性が低くなりがち
流通系イオンカード、エポスカード（丸井）、セゾン小売の販売促進（自社店舗での分割払い）店頭でその場で勧誘＝獲得コストが安い分割・リボの比率が高い。金利収入型自社商圏の外で使われにくい
信販系オリコ、ジャックス、アプラスショッピングクレジット（自動車・教育・リフォームの個別割賦）加盟店（販売店）経由オートローン、個別信用購入あっせん、信用保証カード単体のブランド力が弱い
独立系／ネット系楽天カード、PayPayカード、アメリカン・エキスプレスEC・ポイント経済圏／外資ブランドネット経由・経済圏内の送客で大量獲得経済圏全体（EC・銀行・証券・通信）での回収還元原資が重い。単体黒字化が課題になりやすい

なぜ流通系は分割・リボが厚いのか。もともと
「高額な衣料品や家具を月賦で売る」ところから始まった業態だから、
会員も店舗も分割払いが当たり前という文化を持っている。
銀行系は口座の延長線で「決済の道具」として広まったため、一括払いの比率が高くなる。
同じクレジットカードでも、中身の商売がまるで違う。

5. ポイント原資は誰が負担しているか

ポイント還元は「カード会社のサービス」に見えるが、原資の出どころは3か所ある。

原資の出どころ 誰が払うか 典型例
インターチェンジフィー最終的には加盟店標準的な「どこで使っても1%還元」
提携先の販促予算提携先の事業会社「自社店舗で使うと5%オフ」「特約店で+2%」
カード会社の投資（先行赤字）カード会社新規入会キャンペーン、期間限定の大型還元
【還元率と採算のライン（一括払い会員の場合、概算）】

  イシュア取り分 ≒ 1.5%
    │
    ├─ 還元 0.5%  → 残り1.0%  … 余裕がある
    ├─ 還元 1.0%  → 残り0.5%  … ここが標準。ギリギリ
    ├─ 還元 1.5%  → 残り0.0%  … 一括払い会員は赤字
    └─ 還元 3.0%〜 → 大幅赤字  … 提携先負担か、金融収益での回収が前提
                                  でないと成立しない

「高還元カードのからくり」：還元率が1.5%を超えるカードは、
①提携先が販促費として負担しているか、②グループの他事業（証券・銀行・通信・EC）で回収しているか、
③カード会社が獲得投資として一時的に出血しているか、のどれか。
純粋にカード事業の中だけで成立しているケースはほとんどない。

JCBという特殊な存在

日本には国際ブランドを自前で持つカード会社がある。JCBは
イシュア・アクワイアラ・ブランドの3役を兼ねる3者モデル（クローズドループ）を取れる。

国際ブランドを持つことの意味 中身
収益面他社（フランチャイジー）にライセンスを出し、ブランドフィーを取れる
戦略面手数料の水準やルールを自分で決められる。海外展開の足がかりになる
負担面世界規模のネットワークと加盟店網を自前で維持する必要がある。受容性（使える店の数）でVisa/Mastercardに劣る

公正取引委員会の調査（2022年4月）では、JCB等が属するカテゴリーⅡの平均加盟店手数料率は2.89%と、
カテゴリーⅠ（Visa・Mastercard等）の2.63%より高い。
