# ③ 会員獲得の経済学と業界の出自

このノートで分かること：**なぜ日本には成人1人あたり3枚ものカードがあり、そのうち大半が使われていないのか**。
そして、なぜ「銀行系」「流通系」「信販系」で同じカード事業なのに儲け方が違うのか。

> **結論を先に**：カードは**「1人に何枚持たせるか」ではなく「1人のメインカードになれるか」の勝負**。
> 獲得にかけた費用は、その会員が何年もメインで使い、あわよくば残高を作ってくれて初めて回収できる。
> 2枚目・3枚目の休眠カードは**コストだけを生む負債**である。
> だから2020年代後半の各社は、会員数を増やす競争から降り、
> **休眠の整理（会員数の減少）と稼動率・単価の引き上げ**に方針を変えている。

## 1. 日本のカードは「多すぎる」

| 指標 | 値 | 出典 |
| --- | --- | --- |
| クレジットカード発行枚数（2025年3月末） | **3億2,057万枚**（前年比+2.2%） | 日本クレジット協会（2025年11月14日公表、回答243社） |
| 　うち家族カード | 2,505万枚（+1.0%） | 同上 |
| 　うち法人カード | 1,214万枚（+3.8%） | 同上 |
| 成人人口（概算） | 約1.04億人 | 総務省人口推計ベースの概算 |
| **成人1人あたり** | **約3枚** | 上記からの計算 |

```
【1人が3枚持つと何が起きるか】

  会員A ─┬─ カードX（メイン）… 月10万円利用、リボ残高あり ＝ 利益が出る
         ├─ カードY（サブ） … 年に数回、1万円   ＝ ほぼトントン
         └─ カードZ（休眠） … 0円               ＝ 赤字

  カードZの発行会社から見ると：
    入会時の獲得費（広告・入会ポイント）  ▲3,000〜10,000円 …すでに支払済み
    毎年の維持費（明細・与信管理・
    システム・カード再発行・信用情報照会） ▲数百円/年
    収入                                    0円
    ─────────────────────────────────────
    永久に回収できない
```

> **ここが2020年代の転換点**。「とにかく枚数を配る」戦略は、
> 加盟店手数料が薄く、金利収入も生まない会員を大量に抱え込むだけだった。
> クレディセゾンは2026年3月期に**カード会員数を2,180万人（前期末比 -6.9%）まで減らす一方、
> 稼動会員数は1,358万人（+0.3%）を維持**している（決算短信）。
> **会員を「減らして」利益を増やす**フェーズに入ったことが数字に出ている。

## 2. 【核心】会員1人の採算 ── CACとLTV

```
【カード1枚の生涯収支（イメージ。数値は構造説明のための例示）】

 ■ 獲得コスト（CAC：Customer Acquisition Cost）
   入会特典ポイント          ▲5,000円  ← 「入会で8,000ポイント」の原資
   広告・アフィリエイト報酬    ▲3,000円  ← 比較サイト経由の成果報酬
   審査・発行・郵送           ▲1,000円
   ───────────────────────────
   合計                      ▲9,000円  …発行した瞬間の赤字

 ■ 年間の回収（メイン利用してくれる場合）
   年間利用額 100万円 × イシュア取り分1.5%  ＝ +15,000円
   ポイント還元 100万円 × 1.0%              ＝ ▲10,000円
   与信・明細・コールセンター等              ＝ ▲2,000円
   ───────────────────────────────────
   一括払いだけの会員          年 +3,000円 → 回収に3年
   リボ残高20万円を持つ会員     年 +3,000円 +28,000円（残高×14%）
                              ＝ 年 +31,000円 → 4か月で回収

 ■ 休眠した場合
   年 ▲数百円が延々と続き、9,000円は永久に戻らない
```

| 会員の型 | カード会社から見た価値 | 打ち手 |
| --- | --- | --- |
| **メイン＋残高あり** | 圧倒的に良い顧客 | ゴールド/プラチナへ誘導、枠の増額 |
| メインだが一括のみ | トントン〜薄利 | 公共料金・家賃・サブスクの登録を促す（解約されにくい＝**粘着性**） |
| サブ（たまに使う） | 薄利 | メイン化キャンペーン |
| **休眠** | 純粋なコスト | 利用喚起 → 効かなければ**未稼働会員手数料**か退会 |

> **なぜ公共料金と家賃を押すのか**。一度登録されると解約の手間が大きく、
> **何年も自動的に取扱高が積み上がる**から。丸井グループは「家計シェア最大化」と呼び、
> 家賃払いや公共料金の定期払いの伸長でカードクレジット取扱高4兆9,640億円（2026年3月期、+10%）を達成したと説明している。
> 同社は売上総利益の**67.1%がリカーリング（繰り返し発生する）収益**であると開示している。

## 3. プロパーカードと提携カード ── 誰が獲得コストを払うのか

| 種類 | 発行主体 | 会員を連れてくるのは | 手数料・ポイント原資の負担 | 例 |
| --- | --- | --- | --- | --- |
| **プロパーカード** | カード会社自身 | カード会社（広告・店頭・銀行窓口） | カード会社が全額 | 三井住友カード（NL等）、JCBカード、アメリカン・エキスプレス |
| **提携カード（アフィニティ／コブランド）** | カード会社＋事業会社 | **事業会社**（航空会社、小売、鉄道、大学、球団など） | ポイント原資は事業会社が一部負担、カード会社は送客料を払う場合も | 航空会社系、百貨店系、通信キャリア系、球団カード |
| **ハウスカード** | 小売・専門店が自社のみで発行 | 自社 | 自社 | 一部の百貨店カード、店舗独自の後払い |

```
【提携カードのお金の流れ】

  提携先（例：小売チェーン）           カード会社（イシュア）
       │                                    │
       │  会員を連れてくる（店頭で勧誘）────▶ │  審査・発行・与信・回収
       │                                    │
       │ ◀──── 獲得報酬／手数料の一部分配 ───│
       │                                    │
       │  自社ポイントの原資を負担           │  インターチェンジフィーを取得
       │  （自社店舗での利用分）             │
       ▼                                    ▼
  得るもの：来店頻度・客単価の上昇       得るもの：獲得コストの外部化
            顧客データ                            会員基盤の拡大
  
  ▲ 提携先にとってカードは「値引きの手段」でもある。
    自社店舗で5%オフにする原資は、結局は自社の粗利から出ている。
```

> **提携カードの本質**：カード会社は**獲得コストを提携先に肩代わりさせている**。
> 代わりに、提携先が強いところ（その小売の店内）でしか使われない偏った会員を抱えることになる。
> 一方でプロパーカードは獲得が重いが、**どこで使われても自社の利益になる**し、
> 提携先の都合で関係を切られるリスクがない。

## 4. 出自による4つの類型 ── 同じカードでも稼ぎ方が違う

日本のカード会社は、**もともと何の会社だったか**で戦い方が決まっている。

| 類型 | 代表例 | 出自 | 会員をどう集めるか | 収益の重心 | 弱点 |
| --- | --- | --- | --- | --- | --- |
| **銀行系** | 三井住友カード、三菱UFJニコス、UCカード | 銀行の決済機能の延長 | 銀行の口座・窓口・アプリ | 加盟店手数料（アクワイアリングも強い）＋銀行グループ全体での回収 | 単体では収益性が低くなりがち |
| **流通系** | イオンカード、エポスカード（丸井）、セゾン | 小売の販売促進（自社店舗での分割払い） | **店頭でその場で勧誘**＝獲得コストが安い | **分割・リボ**の比率が高い。金利収入型 | 自社商圏の外で使われにくい |
| **信販系** | オリコ、ジャックス、アプラス | ショッピングクレジット（自動車・教育・リフォームの個別割賦） | 加盟店（販売店）経由 | オートローン、個別信用購入あっせん、信用保証 | カード単体のブランド力が弱い |
| **独立系／ネット系** | 楽天カード、PayPayカード、アメリカン・エキスプレス | EC・ポイント経済圏／外資ブランド | **ネット経由・経済圏内の送客**で大量獲得 | 経済圏全体（EC・銀行・証券・通信）での回収 | 還元原資が重い。単体黒字化が課題になりやすい |

```
【出自の違いが数字に出る】

  流通系（丸井グループ 2026年3月期）
    カードクレジット取扱高 4兆9,640億円
    分割・リボ取扱高        4,732億円 …… 取扱高の 9.5%
    フィンテック営業利益      470億円 …… グループ営業利益502億円の大半
    → 「小売の顔をした金融業」

  銀行系（三井住友カード 2025年度）
    会員数        4,335万人（23年度3,615万 → 24年度3,972万）
    カード取扱高  42兆7,500億円
    → 圧倒的な規模。アクワイアリングも併営し、SMBCグループの
      Olive・Vポイントと一体で回収する

  独立系（楽天カード 2025年度）
    カード発行枚数  3,431万枚（2026年6月末）
    ショッピング取扱高 26.5兆円
    営業収益 3,754億円／経常利益 484億円
    → 取扱高は巨大だが、収益率は経済圏全体で見ないと評価できない
```

出典：各社IR（丸井グループ 2026年3月期決算短信、三井住友カード業績データ、楽天カード「数字で見る楽天カード」）。

> **なぜ流通系は分割・リボが厚いのか**。もともと
> 「高額な衣料品や家具を月賦で売る」ところから始まった業態だから、
> 会員も店舗も**分割払いが当たり前**という文化を持っている。
> 銀行系は口座の延長線で「決済の道具」として広まったため、一括払いの比率が高くなる。
> **同じクレジットカードでも、中身の商売がまるで違う**。

## 5. ポイント原資は誰が負担しているか

ポイント還元は「カード会社のサービス」に見えるが、**原資の出どころは3か所ある**。

| 原資の出どころ | 誰が払うか | 典型例 |
| --- | --- | --- |
| **インターチェンジフィー** | 最終的には**加盟店** | 標準的な「どこで使っても1%還元」 |
| **提携先の販促予算** | **提携先の事業会社** | 「自社店舗で使うと5%オフ」「特約店で+2%」 |
| **カード会社の投資（先行赤字）** | カード会社 | 新規入会キャンペーン、期間限定の大型還元 |

```
【還元率と採算のライン（一括払い会員の場合、概算）】

  イシュア取り分 ≒ 1.5%
    │
    ├─ 還元 0.5%  → 残り1.0%  … 余裕がある
    ├─ 還元 1.0%  → 残り0.5%  … ここが標準。ギリギリ
    ├─ 還元 1.5%  → 残り0.0%  … 一括払い会員は赤字
    └─ 還元 3.0%〜 → 大幅赤字  … 提携先負担か、金融収益での回収が前提
                                  でないと成立しない
```

> **「高還元カードのからくり」**：還元率が1.5%を超えるカードは、
> ①提携先が販促費として負担しているか、②グループの他事業（証券・銀行・通信・EC）で回収しているか、
> ③カード会社が獲得投資として一時的に出血しているか、のどれか。
> **純粋にカード事業の中だけで成立しているケースはほとんどない**。

> [② キャッシュレスの日本的事情](../../04_情報通信・IT・ネット/13_フィンテック・キャッシュレス/02_キャッシュレスの日本的事情.md) を参照。

## 6. 業界再編 ── 「独立したカード会社」が消えていく

```
【カード会社の集約の方向（2020年代）】

   かつて                      いま
   ─────────                 ─────────
   独立した信販・カード会社      ┌─ 銀行グループの傘下
   が多数併存                   │   （三井住友カード＝SMFG、三菱UFJニコス＝MUFG）
      │                        │
      │  単独では               ├─ 通信キャリアの傘下
      │  ・ポイント原資を出せない │   （dカード＝NTTドコモ、au PAY カード＝KDDI）
      │  ・システム投資が重い    │
      │  ・会員獲得の入口がない  ├─ 流通グループの中核
      ▼                        │   （イオンフィナンシャル、エポス＝丸井）
   親会社を持つか、             │
   経済圏に入るか               └─ EC・ネット経済圏の一部
                                   （楽天カード、PayPayカード）

   ▲ 理由：カードは「単体で儲ける事業」から
     「グループの顧客接点と決済データを取るための装置」に役割が変わった
```

| 年 | 動き | 意味 |
| --- | --- | --- |
| 2025年10月 | 三井住友カードがVポイント運営のCCCMKホールディングスを子会社化すると発表（出資比率を三井住友カード55%／SMFG25%／CCC20%へ。2026年3月末めど、商号を「Vポイントマーケティング」に変更予定） | **決済データとポイントデータの統合**。Oliveと一体運用へ |
| 2026年5月20日 | 楽天グループがフィンテック事業再編の最終合意を公表。楽天銀行が楽天カード・楽天証券HDを子会社化（2026年10月1日予定）。みずほ銀行が楽天銀行の議決権10.52%を保有予定 | カードが**銀行の傘下に入る**という、この業界の方向性を象徴する再編 |

詳細は [⑤ 直近トピック（2026年9月時点）](05_直近トピック_2026.md)。

### JCBという特殊な存在

日本には**国際ブランドを自前で持つカード会社**がある。JCBは
イシュア・アクワイアラ・ブランドの3役を兼ねる**3者モデル（クローズドループ）**を取れる。

| 国際ブランドを持つことの意味 | 中身 |
| --- | --- |
| 収益面 | 他社（フランチャイジー）にライセンスを出し、ブランドフィーを取れる |
| 戦略面 | 手数料の水準やルールを自分で決められる。海外展開の足がかりになる |
| 負担面 | 世界規模のネットワークと加盟店網を自前で維持する必要がある。受容性（使える店の数）でVisa/Mastercardに劣る |

公正取引委員会の調査（2022年4月）では、JCB等が属するカテゴリーⅡの平均加盟店手数料率は2.89%と、
カテゴリーⅠ（Visa・Mastercard等）の2.63%より高い。

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **CAC（顧客獲得コスト）** | 会員1人を獲得するのにかかった費用。入会特典＋広告＋発行費 |
| **LTV（顧客生涯価値）** | その会員から生涯に得られる利益の総額。CACを上回らないと事業が成立しない |
| **稼動会員** | 一定期間に実際に利用のあった会員。会員数との差が休眠会員 |
| **休眠会員** | 発行済みだが使われていないカードの会員。維持コストだけが発生する |
| **プロパーカード** | カード会社自身のブランドで発行するカード |
| **提携カード（コブランドカード）** | 事業会社と共同で発行するカード。獲得を提携先に依存する |
| **ハウスカード** | 特定の店舗チェーンでのみ使える自社発行カード |
| **リカーリング収益** | 家賃・公共料金・サブスクのように繰り返し自動的に発生する収益 |
| **3者モデル（クローズドループ）** | イシュア・アクワイアラ・国際ブランドを1社が兼ねる形。JCB、アメリカン・エキスプレスが該当 |
| **アクワイアリング** | 加盟店を開拓・管理する側の事業。銀行系カード会社はここも大きい |
