## このフォルダの読み方

クレジットカードは「決済の道具」に見えるが、**カード会社という事業者の実態は貸金業に近い**。
利益の大半は決済手数料ではなく、**分割・リボ・キャッシングという「残高」から生まれる金利収入**で作られている。
だからこのフォルダは、決済の流れではなく **カード会社の損益計算書** を軸に組み立てた。

## 1. 業界の定義・範囲

**クレジットカード・決済業**とは、消費者に後払いの信用枠を与えてカードを発行し（イシュイング）、
加盟店を開拓して決済を受け入れさせ（アクワイアリング）、その間の立替と回収を担う事業を指す。

| 含むもの | 含まないもの（隣接） |
| --- | --- |
| クレジットカードの発行・与信・回収 | 銀行の口座・預金業務 → [メガバンク](../01_メガバンク/README.md) |
| 加盟店契約・端末設置・加盟店管理 | 無担保の現金貸付専業 → [消費者金融](../12_消費者金融/README.md) |
| ショッピングクレジット（個別割賦）、オートローン、信用保証 | コード決済アプリの運営 → [フィンテック](../../04_情報通信・IT・ネット/13_フィンテック・キャッシュレス/README.md) |
| デビットカード・プリペイドカードの発行 | 決済代行（PSP）・ゲートウェイ → 同上 |
| 国際ブランド運営（JCBのみ日本発） | 電子マネー・交通系IC → 同上 |

境界の引き方：**「誰かに与信して、後で回収する」なら金融側（このフォルダ）**、
**「お金を運ぶ・アプリで集める」ならフィンテック側**、と分けている。

## 2. 市場規模と成長性

| 指標 | 値 | 年・出典 |
| --- | --- | --- |
| クレジットカードショッピング信用供与額 | **134.6兆円** | 2025年。経済産業省キャッシュレス統計（2026年3月31日公表） |
| キャッシュレス決済額に占めるカードの比率 | **82.7%** | 2025年。同上 |
| クレジットカード発行枚数 | **3億2,057万枚**（前年比+2.2%） | 2025年3月末。日本クレジット協会（2025年11月14日公表） |
| 　うち家族カード | 2,505万枚（+1.0%） | 同上 |
| 　うち法人カード | 1,214万枚（+3.8%） | 同上 |
| 成人1人あたりの枚数 | 約3枚 | 上記からの概算 |
| 不正利用被害額 | **510.5億円**（前年比 -8.0%） | 2025年。日本クレジット協会（2026年3月6日公表） |
| 平均加盟店手数料率 | 単純平均 2.70% ／ 加重平均 1.66% | 2022年4月。公正取引委員会 実態調査 |

**成長性の見方**：取扱高は年1割前後で伸び続けているが、**それは利益の成長を意味しない**。
手数料率は競争で下がり、ポイント原資と調達金利という変動費が膨らむため、
取扱高の伸びが利益に落ちる比率は小さい。
2026年時点の成長の中心は「金額」ではなく「**残高（分割・リボ）**」と「**稼動率**」にある。
詳細は [① カード会社の収益3本柱](01_カード会社の収益3本柱.md)。

## 3. バリューチェーン（川上 → 川下）

```
 資金調達            与信・発行            利用            回収・資金化
 ─────────          ─────────           ─────────       ─────────
 社債・CP・借入  ─▶  会員募集             加盟店で決済  ─▶ 翌月引落し
 銀行グループの      信用情報照会          オーソリ         （一括）
 預金（傘下の場合）   支払可能見込額算定    売上確定         分割・リボ
      │             利用可能枠の設定           │           ＝残高として滞留
      │                  │                     │                │
      ▼                  ▼                     ▼                ▼
 【コスト】支払利息   【コスト】獲得費     【収入】加盟店   【収入】金利・手数料
  2025年以降           入会ポイント         手数料(IRF)      ＝ここが利益の本体
  急上昇               広告・審査           ▲ポイント還元
                                                            【リスク】延滞・貸倒れ
                                                                    ↓
                                                            督促 → サービサー売却

  付加価値が集まる場所 ──▶ ① 残高を持つ会員（金利収入）
                        ② 稼動する会員基盤と決済データ
                        ③ 安い資金（＝銀行グループに属すること）
```

**どこに付加価値が集まるか**：決済処理そのものは完全にコモディティ化している。
価値は「**誰の与信を持っているか**」と「**いくらで資金を調達できるか**」に集まる。
2026年に楽天カードが楽天銀行の傘下に入る再編は、後者の論理そのものである。

## 5. 収益モデル・コスト構造

| 収益源 | 中身 | 性格 |
| --- | --- | --- |
| **加盟店手数料（インターチェンジフィー）** | 決済額に比例。イシュア取り分は加盟店手数料の6〜7割 | 最大の売上。ただしポイント原資でほぼ消える |
| **分割・リボ手数料** | 残高 × 実質年率12〜15%前後 | **利益の本体**。ストック型 |
| **キャッシング利息** | 残高 × 実質年率15〜18% | 総量規制で伸びにくく、残高は減少傾向 |
| **年会費・未稼働会員手数料** | 取扱高と無関係の固定収入 | 小さいが確実。2025〜2026年に拡大 |
| 業務代行・加盟店関連収益 | 他社カードの処理受託、端末・PSP的サービス | 安定収益 |

| コスト | 性格 |
| --- | --- |
| **ポイント還元原資** | 変動費。実質的な顧客獲得・維持コスト。還元率1.5%超で一括払い会員は赤字 |
| **支払利息（資金調達）** | 2025年以降の最重要コスト。クレディセゾン単体で1年に+47% |
| **貸倒関連費用（信用コスト）** | 残高に比例して増える。数%の振れで黒字と赤字が入れ替わる |
| 会員獲得費 | 入会特典・広告・アフィリエイト報酬。発行時に先行して出ていく |
| システム・不正対策 | 固定費。規模で薄まる唯一の費目 |

> **この業界の核心**：取扱高の**9割を占める一括払いはほぼ利益を生まず、
> 残り1割の分割・リボが利益を作る**。
> 丸井グループでは分割・リボ取扱高4,732億円がカードクレジット取扱高4兆9,640億円の9.5%にすぎないが、
> フィンテックセグメント営業利益470億円の主要な源泉になっている（2026年3月期）。

## 6. 競争要因（KSF）と参入障壁

**KSF（成功の鍵）**

| 要因 | なぜ効くか |
| --- | --- |
| **メインカード化** | 2枚目・3枚目は使われない。家賃・公共料金・サブスクを押さえると粘着性が生まれる |
| **安い資金調達** | 立替が事業の本質。調達金利の差がそのまま利益差になる。銀行グループが有利 |
| **与信モデルの精度** | 貸倒率が数%動くだけで利益が消える |
| **会員獲得の入口を持つこと** | 店舗、通信契約、EC、銀行口座。獲得コストを外部化できるかが分かれ目 |
| 不正対策と承認率の両立 | 厳しすぎると正常取引を弾き、手数料収入を失う |

**参入障壁**

| 障壁 | 中身 |
| --- | --- |
| 登録・許認可 | 包括信用購入あっせん業者の登録（経産省）、貸金業登録（キャッシング）、クレジットカード番号等取扱契約締結事業者の登録 |
| 国際ブランドのライセンス | プリンシパルメンバー資格には資本・体制要件がある |
| 信用情報機関への加入 | 指定信用情報機関への加入と照会が実質必須 |
| **資金調達力** | 数千億〜数兆円の立替資金を継続的に借りられる信用力・格付け |
| 加盟店網とシステム | 端末、オーソリ基盤、不正検知。単独構築は現実的でない |

## 7. 規制・法制度

| 法令・制度 | 対象 | 要点 |
| --- | --- | --- |
| **割賦販売法** | ショッピング（後払い） | 包括支払可能見込額調査の義務、書面交付、**抗弁の接続**、カード番号の適切管理、加盟店調査義務。監督は経済産業省 |
| **貸金業法** | キャッシング | 貸金業登録、**総量規制（年収の1/3）**、取立行為の規制。監督は金融庁 |
| **利息制限法・出資法** | キャッシング | 上限金利（元本に応じ年15〜20%） |
| **犯罪収益移転防止法** | 発行時 | 本人確認（eKYC） |
| **個人情報保護法** | 与信・マーケティング | 信用情報・購買データの取扱い |
| **資金決済法** | プリペイド・チャージ残高 | 前払式支払手段、資金移動業（→[フィンテック側](../../04_情報通信・IT・ネット/13_フィンテック・キャッシュレス/01_決済はどう流れ誰が取り分を得るか.md)） |
| クレジットカード・セキュリティガイドライン | 業界自主基準 | EMV 3-Dセキュア原則義務化（2025年3月末）、【6.1版】承認（2026年3月11日）、磁気フォールバック禁止（2026年4月〜） |

> **二重規制の理解が要**：同じ1枚のカードでも、**ショッピングは経産省・割販法**、
> **キャッシングは金融庁・貸金業法**と、監督官庁も上限ルールも違う。
> 総量規制（年収の1/3）はキャッシングにのみかかり、ショッピングにはかからない。
> 詳しくは [② 与信と貸倒れの管理](02_与信と貸倒れの管理.md)。

## 8. 最近のトピック

詳細は [⑤ 直近トピック（2026年9月時点）](05_直近トピック_2026.md)。要点は5つ。

1. **金利上昇が原価を直撃**。クレディセゾン単体の支払利息は2026年3月期に264億円（前期比+47%）。
2. **値上げできる場所に負担が寄った**。分割・リボ手数料率の引き上げ（丸井は2025年10月実施）と未稼働会員手数料の導入。
3. **会員数を減らす経営へ**。クレディセゾンはカード会員数 -6.9%の一方、稼動会員を維持。過剰発行の後始末が始まった。
4. **不正利用被害が5年ぶり減少**（2025年510.5億円、-8.0%）。ただし偽造カードは+22.0%と増加し、規制は対面側を塞ぎにいった。
5. **再編はグループへの集約で決着**。楽天カードは2026年10月に楽天銀行の子会社へ。三井住友カードはVポイント運営会社を子会社化。
