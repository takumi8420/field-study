# ④ 不正利用とセキュリティ ── 損失は誰が被るのか

このノートで分かること：日本のカード不正利用被害は**年間500億円規模**で、
その**9割以上がEC（ネット）でのカード番号盗用**。
そして、その損失を最終的に負担しているのは多くの場合**加盟店**であり、
カード会社にとってこれは「利用者の信頼」と「加盟店管理の負荷」という二重のコストになっている。

> **結論を先に**：不正利用対策とは技術の話ではなく、**「損失を誰が負担するかのルール設計」**である。
> チャージバック（売上の取消）という仕組みで、原則として損失は加盟店に戻る。
> だから国は「加盟店に対策を義務づけ、やらない加盟店に損失を負わせる」形で規制を組み立てており、
> その到達点が**2025年3月末のEMV 3-Dセキュア原則義務化**だった。

---

## 1. 被害額の推移 ── 2025年、5年ぶりに減少した

| 年 | 不正利用被害額 | うち番号盗用 | うち偽造カード | 備考 |
| --- | --- | --- | --- | --- |
| 2020年 | 約253億円 | 約223億円 | 約9億円 | － |
| 2022年 | 約437億円 | 約412億円 | 約1.7億円 | EC急拡大とフィッシング増 |
| 2023年 | 約541億円 | 約505億円 | 約2.8億円 | 初めて500億円超 |
| 2024年 | **約555.0億円**（過去最高） | 約534億円 | 約5.9億円 | ピーク |
| **2025年** | **510.5億円（前年比 -8.0%）** | **475.4億円（構成比93.1%）** | **7.2億円（+22.0%）** | **5年ぶりの減少** |

出典：一般社団法人 日本クレジット協会（2026年3月6日公表）。2025年の不正利用発生率は**0.038%**。

```
【2025年 四半期別の被害額（億円）】

  Q1(1-3月)  ████████████████████████  193.2
  Q2(4-6月)  ███████████████           121.4
  Q3(7-9月)  █████████████             102.0
  Q4(10-12月)████████████               93.9   ← 前年同期比 約42%減

  ▲ 2025年3月末のEMV 3-Dセキュア原則義務化を境に、
    四半期ごとに右肩下がりになっている（報道・協会統計ベース）
```

> **読み方の注意**：被害額が減ったのは対策が効いた結果と説明されるが、
> **偽造カード被害は7.2億円へ+22.0%と逆に増えている**。
> ECを固めた結果、犯罪側が**対面のすきま（磁気ストライプや非接触の抜け道）に移動した**
> という見方ができる。不正は「消える」のではなく「移る」。

## 2. 【核心】チャージバック ── 損失が戻っていく仕組み

```
【不正利用が起きたときのお金の動き】

 ①犯罪者が盗んだカード番号でEC加盟店から商品を購入
        │
        ▼
 ②加盟店は商品を発送（＝商品を失う）
        │
        ▼
 ③後日、本人が明細を見て「身に覚えがない」とイシュアへ申告
        │
        ▼
 ④イシュアが調査し、不正と認定
        │
        │  ・会員への請求は取り消される（会員は原則として負担しない）
        │  ・イシュアは国際ブランド経由でアクワイアラへ売上を差し戻す
        ▼
 ⑤アクワイアラが加盟店から代金を回収 ＝【チャージバック】
        │
        ▼
 ⑥加盟店：商品も失い、代金も入らない ＝ 二重の損失
        ＋ チャージバック手数料を取られる場合もある
        ＋ 発生率が高いと加盟店契約を切られる

 【例外】加盟店がEMV 3-Dセキュアで認証を成立させていた場合
        → 「ライアビリティシフト」により、
           損失負担がイシュア側に移る（加盟店は保護される）
```

| 登場人物 | 不正利用での負担 |
| --- | --- |
| **会員（利用者）** | 原則として負担しない。カード会社の会員保障制度で補填（ただし紛失・盗難の届出遅れ、重過失、家族による利用などは対象外となることがある） |
| **加盟店** | **原則としてここが被る**。商品＋代金＋手数料 |
| **アクワイアラ** | 加盟店が倒産・不在なら回収できず、自らが被る |
| **イシュア** | 3-Dセキュア認証済み取引では自らが被る。また調査・コールセンター・カード再発行のコストを常に負う |

> **これが「加盟店に対策を義務づける」規制の理屈**。
> 損失を負うのは加盟店なのだから、対策するインセンティブも加盟店にある、という設計になっている。
> 逆に言うと、**加盟店が対策すればイシュアの調査コストも減る**ので、業界全体の利害が一致する。

## 3. 規制の到達点 ── EMV 3-Dセキュアの原則義務化

**EMV 3-Dセキュア**（3Dセキュア2.0）は、EC決済時に
「取引のリスクを判定し、あやしいときだけ追加認証を求める」本人認証の仕組み。
旧来の3Dセキュア1.0が「毎回パスワードを求める」方式で離脱（かご落ち）を招いたのに対し、
**リスクベース認証**により、通常の取引は素通りさせる。

| 時期 | 内容 |
| --- | --- |
| 2024年3月15日 | 経済産業省が「クレジットカード・セキュリティガイドライン【5.0版】」の改訂を公表。**2025年3月末までに原則すべてのEC加盟店にEMV 3-Dセキュア導入**を求める |
| 2025年3月末 | 期限到来。イシュア側も「EC利用会員ベースで80%の3-Dセキュア登録」を目標とされた |
| 2025年4月以降 | EC加盟店は**脆弱性対策**（ウイルス対策・管理者権限の管理等）と**不正利用対策**（3-Dセキュア導入、不正ログイン対策等）の実施が求められる |
| 2025年3月 | 【6.0版】発行 |
| **2026年3月11日** | クレジット取引セキュリティ対策協議会 第13回本会議で**【6.1版】を承認** |

### 6.1版（2026年3月）で決まったこと

| 項目 | 内容 |
| --- | --- |
| 非接触IC取引の本人確認 | PIN入力できない非接触IC取引について、**一定金額以上は接触ICへ遷移してPIN入力**させる実装方法で合意 |
| **磁気フォールバックの禁止** | **2026年4月以降の新規決済端末の開発・システム更改では磁気フォールバック取引を禁止**することで国際ブランド・カード会社と合意 |
| EC加盟店の好事例集 | 不正抑止に成功した加盟店の事例を附属文書に追加 |

> **磁気フォールバックとは**：ICチップの読み取りに失敗したとき、
> 磁気ストライプで決済を通す「逃げ道」のこと。
> 磁気ストライプは複製が容易なため、**偽造カード被害の温床**になっていた。
> 2025年に偽造被害が+22%となったこととこの禁止は、明らかにつながっている。

## 4. 加盟店管理 ── アクワイアラの見えない仕事

カード会社（アクワイアラ）は、店を増やすだけでなく**店を監視する義務**を負う。
これは2018年施行の改正割賦販売法で明文化された。

```
【加盟店管理の流れ】

 ①加盟店審査（入口）
   ・実在性、業種、取扱商品の適法性
   ・代表者・法人の反社チェック
   ・換金性の高い商材（金券・ゲーム内通貨等）でないか
        ↓
 ②登録
   ・クレジットカード番号等取扱契約締結事業者としての登録（経産省）
   ・加盟店情報を「日本クレジット協会の加盟店情報交換制度（JDM）」へ
        ↓
 ③継続的なモニタリング
   ・不正利用発生率、チャージバック率
   ・苦情の発生状況
   ・カード番号の適切な管理（非保持化 or PCI DSS準拠）
        ↓
 ④是正指導 → 改善なければ【加盟店契約の解除】

 ▲ 2025年9月25日、経済産業省は事業報告書を改訂し、
   「加盟店ごとの不正利用発生状況」を報告事項に追加した。
   国が加盟店単位の実績を把握しにいく方向に進んでいる。
```

| 加盟店管理で見る主な指標 | 意味 |
| --- | --- |
| **チャージバック率** | 取扱高に対するチャージバック発生額の比率。国際ブランドが上限を定め、超えると是正プログラムの対象 |
| 不正利用発生率 | 2025年の業界全体は0.038%（日本クレジット協会） |
| **カード情報の非保持化** | 加盟店の環境にカード番号を「通過も保存もさせない」こと。トークン決済やリダイレクト方式で実現 |
| **PCI DSS** | カード情報を保持する場合に求められる国際的なセキュリティ基準。準拠には監査が必要でコストが重い |

> **中小加盟店にとっての現実**：非保持化もPCI DSSも自前では難しいため、
> **PSP（決済代行）に丸ごと任せる**という選択が主流になる。
> セキュリティ規制の強化は、結果として**決済代行会社に加盟店が集中する力**として働いている。

## 5. 攻撃側の手口と、イシュア側の防御

| 手口 | 中身 | 主な防御 |
| --- | --- | --- |
| **フィッシング** | カード会社・宅配・通信事業者を装ったSMS/メールで、偽サイトに番号と3-Dセキュアのワンタイムパスワードを入力させる | 送信ドメイン認証（DMARC）、アプリ認証への移行、会員への注意喚起 |
| クレジットマスター | 有効なカード番号の規則性を突いて番号を機械的に生成し、少額決済で有効性を試す | 連続オーソリの検知、BIN単位の速度制限 |
| 情報漏えい | 加盟店サイトの改ざん（Webスキミング）、データベース侵害 | カード情報の非保持化、脆弱性診断の義務化 |
| **偽造カード** | 磁気ストライプを複製して対面で使う | 磁気フォールバックの禁止（2026年4月〜）、IC/PINの徹底 |
| なりすまし申込 | 他人の名義でカードを申し込む | eKYC（オンライン本人確認）、犯罪収益移転防止法に基づく確認 |

```
【イシュア側の不正検知（オーソリの瞬間に走る判定）】

  決済リクエスト
     │
     ├─▶ ルールベース：国・金額・時間帯・加盟店カテゴリ（MCC）の異常
     ├─▶ 速度チェック：数分で複数回、複数の店
     ├─▶ 機械学習スコア：その会員の普段の行動からの乖離
     └─▶ デバイス・IPの評価（EC）
              │
      ┌───────┴────────┐
    承認              否認 or 3-Dセキュアで追加認証
                           │
                     本人に確認の連絡／カード停止・再発行

  ▲ トレードオフ：厳しくすれば不正は減るが、
    正常な取引まで弾く（フォールスポジティブ）。
    承認率が下がると加盟店の売上も、カード会社の手数料収入も減る。
    「不正率」と「承認率」の両立がイシュアの技術課題になる。
```

> **見落とされがちなコスト**：カード会社にとって不正利用の痛手は損失額だけではない。
> 番号が漏れたカードは**再発行**が必要で、1枚あたりのカード製造・郵送・
> 継続課金の登録変更案内などのコストが発生する。
> さらに、サブスクや公共料金の自動引落しが切れると
> [③](03_会員獲得の経済学と業界の出自.md) で見た**リカーリング収益の土台が崩れる**。

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **チャージバック** | 不正やトラブルを理由に売上が取り消され、代金が加盟店から引き戻されること |
| **ライアビリティシフト** | 3-Dセキュアで認証が成立した取引では、不正の損失負担がイシュア側へ移る仕組み |
| **EMV 3-Dセキュア（3Dセキュア2.0）** | EC決済のリスクベース本人認証。あやしい取引だけ追加認証する。2025年3月末に原則義務化 |
| **リスクベース認証** | 取引のリスクを推定し、低リスクなら認証を省略する方式 |
| **磁気フォールバック** | ICの読取失敗時に磁気ストライプで決済を通すこと。偽造の温床。2026年4月以降の新規端末で禁止 |
| **CNP取引** | Card Not Present。カードを提示しない取引（EC・電話注文）。不正の大半がここ |
| **番号盗用** | 盗んだカード番号での不正利用。2025年の被害額の93.1%を占める |
| **カード情報の非保持化** | 加盟店の環境にカード番号を保存も通過もさせない構成 |
| **PCI DSS** | カード情報を扱う事業者向けの国際セキュリティ基準 |
| **加盟店情報交換制度（JDM）** | 日本クレジット協会が運営する、問題のある加盟店情報を業界で共有する仕組み |
| **eKYC** | オンラインで完結する本人確認。なりすまし申込の防止に使われる |
| **承認率（オーソリ承認率）** | 決済リクエストのうち承認された割合。不正対策を強めすぎると下がる |
