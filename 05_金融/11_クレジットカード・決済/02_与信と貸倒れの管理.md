# ② 与信と貸倒れの管理 ── カード会社が本当に売っているもの

このノートで分かること：カード会社が売っているのは決済の便利さではなく、**「見ず知らずの人に、担保なしで、数十万円まで後払いを許す」という信用**。
その信用をどう測り、外れたときにどう回収し、法律がどこまで縛るのかを扱う。

> **結論を先に**：カードの与信は**「入口の審査」と「使い始めてからの継続審査（途上与信）」の二段構え**で管理されている。
> 入口では割賦販売法が「年収からの機械的な計算式」を義務づけ、
> 使い始めてからは各社が信用情報機関のデータと自社の利用履歴で枠を上げ下げする。
> そして**貸倒率が1〜2%動くだけで利益が消える**ため、この業界は「伸ばす」より「外さない」ことに執着する。

[① カード会社の収益3本柱](01_カード会社の収益3本柱.md) で見たとおり、利益は残高（分割・リボ・キャッシング）から出る。
**残高を伸ばせば利益が増えるが、同時に貸倒れも増える**。その綱引きがこのノートのテーマ。

---

## 1. 与信の全体像 ── 3つの門

```
【カード会員が通る3つの門】

 ①入口（申込時）        ②途中（利用中）           ③出口（延滞後）
 ─────────────       ─────────────         ─────────────
 本人確認(eKYC)          途上与信                  督促（電話・書面）
 信用情報機関を照会      ・信用情報の定期照会        ↓
 支払可能見込額の算定    ・自社の利用/入金履歴      期限の利益喪失
 （割賦販売法の義務）    ・枠の増枠/減枠/停止        ＝残額の一括請求
        ↓                      ↓                     ↓
 利用可能枠を決定        リスクに応じて枠を調整      債権回収会社(サービサー)へ
        ↓                      ↓                    売却 or 委託
 カード発行              異常検知で即時停止も         ↓
                                                  貸倒処理（損失確定）

 ▲入口だけでは足りない。審査時に優良でも、3年後に失業するかもしれない。
   だから「継続して見張る」②が実務の中心になる。
```

| 門 | 何を見るか | 根拠 |
| --- | --- | --- |
| ① 入口 | 年収・雇用形態・勤続年数・居住形態・他社借入 | 割賦販売法（包括支払可能見込額調査）、各社の審査基準 |
| ② 途中 | 支払遅延、利用額の急増、キャッシング比率、他社での延滞 | 割賦販売法（定期的な信用情報の照会）、各社の内規 |
| ③ 出口 | 延滞日数、連絡可否、回収見込み | 民法、貸金業法（取立行為の規制）、各社の債権管理規程 |

## 2. 【核心】入口の審査は法律で計算式が決まっている

日本では「いくらまで後払いを許してよいか」が**カード会社の裁量ではなく法律で枠づけられている**。
これは2006〜2010年の多重債務問題（貸金業法改正の時代）の反省から入った規制。

```
【包括支払可能見込額の計算式（割賦販売法）】

  包括支払可能見込額 ＝ （年収 － 生活維持費 － 年間請求予定額） × 90%
                          ▲          ▲              ▲          ▲
                          │          │              │          経済産業大臣が
                          │          │              │          定める割合
                          │          │              他社カード等の
                          │          │              1年間の支払予定額
                          │          省令で定める定額
                          │         （居住形態と扶養人数で決まる。
                          │           例：持家・本人のみ90万円 など）
                          申告された年収

  → ショッピング利用可能枠は、この金額を超えて設定できない
```

| 用語 | 意味 | 実務上のポイント |
| --- | --- | --- |
| **支払可能見込額調査** | 申込時と、その後も定期的に行う義務 | やらずに枠を出すと行政処分の対象 |
| **生活維持費** | 省令で定額が決まっている | 実際の家計ではなく**居住形態（持家/借家）と扶養家族数**で機械的に決まる |
| **年間請求予定額** | 他社を含む既存のクレジット債務 | ここが**指定信用情報機関の出番** |
| **例外**（調査不要） | 極度額30万円以下のカード、翌月一括払い専用、支払回数2か月以内 など | 少額・短期のカードは簡易に出せる |

> **なぜ機械的な式なのか**。「この人は大丈夫そう」という各社の主観に任せると、
> 景気が良いときに各社が一斉に枠を出し、**同じ人に何社からも枠が積み上がる**。
> それが2000年代の多重債務問題の構図だった。
> だから「年収から引き算する」という**全社共通の物差し**を法律で置いた。

## 3. 指定信用情報機関 ── 業界共有のブラックリストではなく「共有台帳」

日本には3つの信用情報機関があり、カード会社は**割賦販売法の指定信用情報機関であるCICへの加入と照会が事実上必須**。

| 機関 | 主な会員 | 根拠法 | 扱う情報 |
| --- | --- | --- | --- |
| **CIC** | クレジットカード会社、信販、携帯キャリア | **割賦販売法**の指定信用情報機関／貸金業法の指定信用情報機関 | 割賦・クレジットの契約と支払状況 |
| **JICC**（日本信用情報機構） | 消費者金融、信販、一部カード | **貸金業法**の指定信用情報機関 | 貸金の契約と支払状況 |
| **KSC**（全国銀行個人信用情報センター） | 銀行、信金、保証会社 | 全国銀行協会の自主運営 | 銀行ローン、保証履行 |

```
【登録される主な情報と、おおよその保有期間】

  申込情報 ──────────────── 照会日から6か月
   （短期間に何社も申し込むと
     「申込ブラック」と呼ばれる状態になる）

  契約・支払状況 ─────────── 契約終了から5年
   ・入金区分（毎月「$（入金）」「A（未入金）」などで24か月分が並ぶ）
   ・残債額、利用可能枠

  異動（＝事故情報） ───────── 契約終了から5年
   ・61日以上または3か月以上の延滞
   ・代位弁済（保証会社が肩代わり）
   ・強制解約
   ・自己破産等（KSCは最長10年とされる）
```

> **実務上の含意**：いわゆる「ブラックリスト」という名簿が存在するわけではない。
> あるのは**支払いの履歴データ**で、そこに「異動」という記録が付くと
> 各社の審査ロジックがほぼ自動で否決する、というだけ。
> 逆に言えば、カード会社は**他社での支払いぶりを見て自社の枠を決めている**。
> これは業界全体で貸倒れを抑えるための、事実上のインフラである。

## 4. 途上与信 ── 使い始めてからが本番

審査を通した後も、カード会社は定期的に会員を見直す。これが**途上与信**。

| トリガー | 見ているもの | 典型的なアクション |
| --- | --- | --- |
| 定期（半年〜1年ごと） | 信用情報機関の最新データ、他社での延滞 | 増枠案内／枠の据置／減枠 |
| 支払遅延の発生 | 何日遅れたか、初回か常習か | 利用停止、枠の引下げ |
| 利用パターンの急変 | 急なキャッシング増、高額利用の連発、換金性の高い商品への集中 | 一時停止、確認連絡 |
| 会員からの増枠申請 | 改めて支払可能見込額を算定 | 承認／否認 |
| リボ残高の増加 | 残高の絶対額と返済ペース | 収益機会であると同時にリスク要因。両面で見る |

> **カード会社のジレンマ**：リボ残高が増えると[①](01_カード会社の収益3本柱.md)で見たとおり利益が増える。
> しかし**リボ残高が増えている会員は、同時にいちばん貸倒れやすい会員でもある**。
> 「儲かる顧客」と「危ない顧客」が同じ人物であるという構造が、この業界の与信を難しくしている。
> 実務では「リボ残高は伸ばすが、その質（返済継続率）を落とさない」という運用になる。

## 5. 延滞から貸倒れまで ── お金が消えていく段取り

```
【延滞が損失に変わるまでのタイムライン】

 支払日  ─▶ +1〜10日        ─▶ +30日        ─▶ +61〜90日     ─▶ +数か月
  │          │                 │                │                 │
 引落不能   再振替・             督促強化         【異動】登録      期限の利益喪失
            メール/SMS通知       電話・書面       カード利用停止    （残額を一括請求）
            この段階で           この時点で       信用情報に         ↓
            大半が解消           遅延損害金       記録される       サービサーへ
                                 年14.6%が発生                    売却 or 委託
                                                                    ↓
                                                              貸倒償却（損失確定）

 会計上：延滞が進むにつれ「貸倒引当金」を積み増す
        ＝ 実際に回収不能になる前から、費用として先に計上される
```

| 会計・実務の用語 | 意味 |
| --- | --- |
| **貸倒引当金** | 将来回収できないと見込む金額をあらかじめ費用計上したもの。クレディセゾン単体の流動資産の貸倒引当金は443億円（2026年3月期、前期417億円） |
| **貸倒償却** | 回収不能が確定し、債権を落とすこと |
| **貸倒関連費用／信用コスト** | 引当金繰入＋償却。カード会社の決算で利益を最も動かす項目のひとつ |
| **期限の利益喪失** | 「分割で払ってよい」という権利を失い、残額を一括で請求される状態 |
| **代位弁済** | 保証会社が本人に代わって支払うこと。信用情報に記録される |
| **サービサー（債権回収会社）** | 法務大臣の許可を受けた債権回収の専門会社。不良債権を額面より大幅に安く買い取る |

### 貸倒率がなぜ致命的か

```
【簡単な感度分析：取扱高1兆円・リボ等残高1,000億円のカード会社】

  収益  加盟店手数料（イシュア取り分1.5%） … 150億円
        リボ・分割手数料（残高×14%）      … 140億円
        合計                              … 290億円

  費用  ポイント還元（取扱高の1.0%）       … 100億円
        資金調達・システム・人件費など      … 120億円
        貸倒れ                            … ？

  貸倒率が 残高の 2% → 20億円 : 営業利益 約50億円
           残高の 5% → 50億円 : 営業利益 約20億円
           残高の 8% → 80億円 : 営業損失 ▲10億円
                                   ▲
                   数%の違いで黒字と赤字が入れ替わる
                   （数値は構造を示すための例示。実際の各社の水準ではない）
```

> ポイント：**カード会社の利益は「貸倒率の想定がどれだけ当たっているか」でほぼ決まる**。
> だから各社はスコアリングモデルに投資し、景気が悪化しそうなときは
> 収益を捨ててでも枠を絞る。伸ばす競争より、**外さない競争**が本質である。

## 6. 法規制の地図 ── カードは2つの法律にまたがる

カードの「ショッピング」と「キャッシング」は、**別の法律で規制されている**。これが理解の要。

| 項目 | ショッピング（後払い） | キャッシング（借入） |
| --- | --- | --- |
| 根拠法 | **割賦販売法** | **貸金業法**＋利息制限法 |
| 監督官庁 | 経済産業省 | 金融庁 |
| 登録 | 包括信用購入あっせん業者の登録 | 貸金業の登録 |
| 与信の上限 | 支払可能見込額（年収－生活維持費－既存債務）×90% | **総量規制**：年収の1/3まで |
| 金利の上限 | 明示的な上限金利規制はない（実務は年率15%前後） | 利息制限法：年15〜20%（元本により変動） |
| 書面交付 | 契約内容・支払条件の書面（電磁的方法も可）交付義務 | 契約書面・受取証書の交付義務 |
| 抗弁の接続 | **あり**（商品に問題があればカード会社への支払いを拒める） | なし |

> **「抗弁の接続」はカードの隠れた価値**。買った商品が届かない・欠陥があるとき、
> 一定の条件下で**カード会社への支払いを止められる**（割賦販売法30条の4等）。
> これは「翌月一括払い」には原則適用されず、**分割・リボなど割販法の対象取引で機能する**。
> カード会社はこのリスクも負っているため、加盟店の審査・管理が重い仕事になる
> （[④ 不正利用とセキュリティ](04_不正利用とセキュリティ.md) 参照）。

### 直近の規制動向（2025〜2026年）

| 時期 | 動き |
| --- | --- |
| 2025年4月 | 経済産業省「加盟店における不正利用対策の在り方に関する検討会」開始 |
| 2025年9月 | 割賦販売法（後払分野）に基づく**監督の基本方針**を改正（経産省） |
| 2025年9月25日 | クレジットカード番号等取扱契約締結事業者の**事業報告書を改訂**。加盟店ごとの不正利用発生状況が報告事項に追加 |
| 2026年4月1日 | 令和8年度の信用購入あっせん業者等に対する**検査基本方針・検査基本計画**を策定 |

詳しくは [⑤ 直近トピック（2026年9月時点）](05_直近トピック_2026.md)。

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **与信** | 「この人は後で払える」と判断してお金や商品を先に渡すこと |
| **包括支払可能見込額** | 割賦販売法が定める、1年間に支払える見込み額。（年収－生活維持費－年間請求予定額）×90% |
| **生活維持費** | 省令で定額が定められた生活費。居住形態と扶養人数で機械的に決まる |
| **指定信用情報機関** | 法律に基づき信用情報を集約・提供する機関。割販法はCIC、貸金業法はCIC・JICC |
| **異動情報** | 61日以上または3か月以上の延滞、代位弁済、強制解約などの記録。契約終了から5年程度保有される |
| **途上与信** | 契約後も定期的に信用状態を調べ、枠を上げ下げすること |
| **総量規制** | 貸金業法の規制。個人の借入残高を年収の1/3までに制限。**ショッピングには適用されない** |
| **抗弁の接続** | 商品に問題があるとき、カード会社への支払いを拒める割賦販売法上の仕組み |
| **期限の利益喪失** | 分割で払う権利を失い、残額を一括請求される状態 |
| **貸倒引当金／信用コスト** | 将来の回収不能に備えて先に計上する費用。カード会社の利益を最も動かす項目 |
| **サービサー** | 法務大臣の許可を受けた債権回収会社。不良債権を割引価格で買い取る |
