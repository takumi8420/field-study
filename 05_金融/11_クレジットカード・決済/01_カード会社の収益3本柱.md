# ① カード会社の収益3本柱 ── どこで儲けているのか

このノートで分かること：**カード会社は「決済の手数料屋」ではなく「消費者金融に近い貸金業」である**。
取扱高の9割を占める一括払いはほとんど利益を生まず、
残り1割の**分割・リボ・キャッシング（＝金利のつく残高）が利益の本体**を作っている。

> **結論を先に**：カード会社の収入は ①加盟店手数料 ②金利・手数料収入（分割・リボ・キャッシング）
> ③年会費 の3本柱。**売上の順位は①＞②＞③だが、利益の順位は②＞①＞③**。
> ①は原価（ポイント・処理コスト・資金の立替）が重く、②は貸したお金に利息が乗るだけなので粗利が厚い。
> だからカード会社の決算は「取扱高が伸びたか」ではなく「**残高が積み上がったか**」で読む。

> ⚠️ このノートは収益構造を事実として説明するもので、**リボ払いや分割払いの利用を勧めるものではない**。
> 後述のとおり、利用者から見ればこれは年率15%前後の借金であり、支払総額は確実に増える。

決済の流れそのもの（4者モデル、インターチェンジフィーの分配）は
[① 決済はどう流れ誰が取り分を得るか](../../04_情報通信・IT・ネット/13_フィンテック・キャッシュレス/01_決済はどう流れ誰が取り分を得るか.md)
で詳述しているので、ここでは**カード会社の損益計算書の側**だけを扱う。

---

## 1. まず全体像 ── 3本柱の大きさと利益率

```
【カード会社の収益の作られ方】

  カード取扱高（例：10兆円）
        │
        ├─ ① 一括払い分 約9割 ─────▶ 加盟店手数料（インターチェンジフィー）
        │                              収入は大きいが、ここから
        │                              ・ポイント還元原資
        │                              ・カード発行/システム/明細コスト
        │                              ・数週間の立替資金の調達コスト
        │                              を全部払う ＝ 薄利、時に赤字
        │
        ├─ ② 分割・リボ・キャッシング 約1割 ─▶ 金利・手数料（年率12〜18%）
        │                              追加コストはほぼ「貸倒れ」と「調達金利」だけ
        │                              ＝ ここが利益の本体
        │
        └─ ③ 年会費 ────────────────▶ 取扱高と無関係の固定収入
                                       ゴールド/プラチナ会員から集める
                                       ＝ 金額は小さいが確実
```

| 収益の柱 | 何から生まれるか | 収入規模 | 変動費（原価） | 利益への効き方 |
| --- | --- | --- | --- | --- |
| **① 加盟店手数料** | 決済1件ごとの手数料。イシュア（発行会社）はインターチェンジフィーとして受け取る | **最大** | ポイント原資・システム・立替資金の金利 | 薄い。還元率を上げると簡単に逆ザヤ |
| **② 金利・手数料収入** | 分割払手数料、リボ払手数料、キャッシング利息 | 中 | 貸倒れ＋調達金利 | **厚い。利益の本体** |
| **③ 年会費** | 本会員・家族会員から年1回 | 小 | ほぼゼロ（付帯サービス原価のみ） | 取扱高ゼロでも入る。近年は「未稼働会員手数料」に発展 |

> ポイント：①は**フロー（流れた金額）**に比例し、②は**ストック（積み上がった残高）**に比例する。
> フローは景気とキャンペーンで上下するが、ストックは一度積み上がると長く残る。
> カード会社が「残高」という言葉を決算で連呼するのはこのため。

## 2. 【核心】①加盟店手数料がなぜ儲からないか

加盟店が払う手数料率は、公正取引委員会の実態調査（2022年4月公表）によれば
**単純平均2.70%、加重平均1.66%**。加重平均が低いのは、
取扱高の大きい大手加盟店ほど交渉力があり低い料率で契約しているため。

| 指標（2022年4月 公正取引委員会 実態調査） | 値 |
| --- | --- |
| 平均加盟店手数料率（単純平均） | **2.70%** |
| 平均加盟店手数料率（加重平均＝金額ベース） | **1.66%** |
| 　カテゴリーⅠ（Visa・Mastercard等） | 2.63% |
| 　カテゴリーⅡ（JCB・AmEx等） | 2.89% |
| イシュア手数料率（＝アクワイアラからイシュアへ渡る率） | **1.56%** |
| カード会員が持つ国際ブランドの平均数 | 1.8ブランド |
| 加盟店が使える国際ブランドの平均数 | 4.9ブランド |

単純平均ベースで見ると、加盟店手数料2.63〜2.89%のうち1.56%がイシュアへ渡る計算＝**6割前後**。
業種やカードランクによって比率は動き、**7割前後**とされることも多い（分配の詳細は
[フィンテック側のノート](../../04_情報通信・IT・ネット/13_フィンテック・キャッシュレス/01_決済はどう流れ誰が取り分を得るか.md)）。

問題は、**その1.56%からイシュアが払うもの**である。

```
【イシュアの一括払い1万円あたり収支（概算イメージ）】

  受け取り：インターチェンジフィー  約156円（1.56%）
        │
        ├─ ポイント還元原資 1.0%      ▲100円  ← 還元率1%のカードなら
        ├─ 立替資金の調達コスト        ▲10〜25円 ← 平均45日ぶん。金利上昇で急拡大
        ├─ 発行・明細・コールセンター   ▲10〜20円
        ├─ 不正利用・チャージバック損   ▲5円前後
        └─ システム・ブランドフィー     ▲10円前後
        ─────────────────────────────
  残り：ほぼゼロ、還元率1.5%なら赤字
```

> **ここがこの業界の急所**：還元率1%のカードは、インターチェンジフィーの
> **6割以上をポイントで会員に返している**。つまり一括払いだけを使う会員は、
> カード会社にとって**利益がほぼ出ない、場合によっては赤字の顧客**である。
> 「年会費無料・高還元」のカードが成立するのは、
> **会員全体のうち一部が②の金利収入を生んでくれる**ことを前提にしているから。

## 3. 【核心】②金利収入が利益を作る ── 丸井グループの数字で見る

構造がいちばんきれいに見えるのが丸井グループ（エポスカード）。
小売（マルイ）と金融（エポス）の両方を持ち、セグメント別に開示している。

| 丸井グループ 2026年3月期（2026年5月15日 決算短信） | 値 | 前年比 |
| --- | --- | --- |
| グループ総取扱高 | 5兆3,921億円 | +9% |
| 売上収益 | 2,769億円 | +9% |
| **連結営業利益** | **502億円** | +13% |
| 　小売セグメント営業利益 | 112億円 | +30% |
| 　**フィンテックセグメント営業利益** | **470億円** | +7% |
| カードクレジット取扱高 | 4兆9,640億円 | +10% |
| **分割・リボ取扱高** | **4,732億円** | +10% |
| 分割・リボ払い残高（流動化債権含む） | 4,994億円（過去最高） | +6% |
| エポスカード期末会員数 | 830万人 | +41万人 |

```
【丸井グループ：取扱高と利益のねじれ】

 カードクレジット取扱高 4兆9,640億円
 ├──────────────────────────────────────────┬────┐
 │        一括払い等 約4兆4,900億円（90.5%）      │分割 │
 │                                              │・リボ│
 │        → 加盟店手数料。薄利                    │4,732│
 │                                              │億円 │
 └──────────────────────────────────────────┴────┘
                                                  ▲
                                          取扱高では1割弱
                                          しかないこの部分が
                                          年率12〜15%の手数料を生み、
                                          フィンテック営業利益470億円の
                                          大きな部分を支えている
```

> **読み方**：グループの営業利益502億円のうち、金融であるフィンテックが470億円。
> **百貨店型の小売業が、実態は「店舗を集客装置にしたカード金融会社」**になっている。
> 丸井自身、店舗を「売ることを目的としない体験型テナント」に転換していると説明しており
> （2026年3月期 決算短信）、非物販テナント面積構成は70%に達した。

### クレディセゾンでも同じ形が見える

| クレディセゾン 2026年3月期（2026年5月15日 決算短信、IFRS連結） | 純収益 | 事業利益 |
| --- | --- | --- |
| 連結合計 | 4,727億円（+11.8%） | 1,019億円（+8.9%） |
| 　**ペイメント事業**（カード本業） | 2,772億円（+9.7%） | **306億円**（+1.9%） |
| 　**ファイナンス事業**（信用保証・ローン） | 827億円（+14.0%） | **473億円**（+21.5%） |
| 　不動産関連 | 312億円 | 192億円 |

**カード本業の純収益はファイナンス事業の3.4倍あるのに、利益は下回っている**。
決済という仕事そのものが、いかに薄利かがここに出ている。

同社単体の損益計算書（2026年3月期）を見ると、収益の中身はこうなっている。

| 科目（クレディセゾン単体） | 2025年3月期 | 2026年3月期 |
| --- | --- | --- |
| 包括信用購入あっせん収益（加盟店手数料＋分割・リボ手数料） | 1,645億円 | **1,787億円** |
| カードキャッシング収益 | 244億円 | 241億円 |
| 業務代行収益 | 302億円 | 321億円 |
| ペイメント関連収益 | 154億円 | 198億円 |
| **支払利息（＝資金調達コスト）** | 179億円 | **264億円（+47%）** |

> **2026年の新しい論点**：日本の金利が上がったことで、**支払利息が1年で47%増えた**。
> カード会社は「利用者が払う前に加盟店へ払う」ため、常に数千億〜数兆円を借りている。
> 金利上昇は、この業界にとって**原価の上昇**そのものである。
> 各社が2025〜2026年にリボ・分割の手数料率を引き上げたのは、この原価上昇への対応という説明がなされている
> （丸井グループは「金利上昇による金融費用増加への対応」として
> 2025年10月からの分割・リボ手数料率変更を決算短信に明記）。

## 4. 利用者から見た②の姿 ── 金利負担の構造

同じ現象を利用者の側から見ると、こうなる。事実として押さえておくべき数字。

| 支払方法 | 実質年率の目安（2026年時点、各社公表の一般的水準） | 上限の根拠 |
| --- | --- | --- |
| 翌月一括払い | **0%** | － |
| ボーナス一括払い | 0%（無手数料の場合が多い） | － |
| 分割払い（3〜24回） | 実質年率 **12〜15%前後** | 割賦販売法（利率の上限規制はない） |
| リボルビング払い | 実質年率 **15%前後** | 同上 |
| キャッシング（借入） | 実質年率 **15〜18%** | **利息制限法**（10万円未満20%、100万円未満18%、100万円以上15%） |
| 遅延損害金 | 年 **14.6%** 前後（ショッピング） | 割賦販売法 |

```
【リボ払いで何が起きるか：10万円を月5,000円ずつ返す場合（年率15%・元金定額）】

 残高10万円 ──▶ 20か月かけて返済
   ・元金の返済    100,000円
   ・手数料の合計   約13,000円前後（概算）
   ・支払総額      約113,000円

 【途中で追加利用すると】
 残高が減らないまま利用が積み上がり、
 「毎月の支払額は一定」なのに「残高は減らない」状態になる
   月々5,000円 ＝ そのうち手数料が1,000円超 → 元金は4,000円弱しか減らない
        ↓
   完済までの期間が延び、支払総額がさらに増える
```

> **事実として言えること**：リボ払いは「毎月の支払額が一定になる」仕組みであって、
> 「支払総額が減る」仕組みではない。**残高に年率15%前後がかかり続ける借入**である。
> 一方でカード会社から見れば、この残高こそが安定した利息収入の源になる。
> **利用者の負担とカード会社の利益は、ここで完全に同じものを指している**。

金融庁・消費者庁・日本クレジット協会はいずれもリボ払いの仕組みを事前に理解するよう注意喚起しており、
カード会社側も明細やアプリで残高・手数料の表示を強化している。

## 5. ③年会費 ── 小さいが確実な柱、そして「未稼働会員手数料」へ

年会費は取扱高に関係なく入る固定収入。無料カードが主流の日本では長く軽視されてきたが、
2020年代に入って**2つの方向で重みが増している**。

| 方向 | 中身 | 経済的な意味 |
| --- | --- | --- |
| **上へ（プレミアム化）** | ゴールド・プラチナの拡大。年会費数千円〜数万円 | 年会費に加え、**カードランクが高いほどインターチェンジフィーも高い**（Visa標準料率で一般0.90%→プラチナ1.20%等、2022年公開値）。二重に儲かる |
| **下へ（未稼働の有料化）** | 一定期間使わない会員に「カードサービス手数料」を課す | 休眠会員はコストだけ発生する。使わせるか、退会してもらうかの二択を迫る |

クレディセゾンは2026年3月期の決算短信で
「**リボルビング払いに関する手数料改定や、未稼働会員へのカードサービス手数料導入の効果が着実に顕在化**」
と明記している。ライフカードなども同種の手数料を2026年11月請求分から拡大すると案内している（各社公式サイト）。

> なぜ今なのか。次のノート
> [③ 会員獲得の経済学と業界の出自](03_会員獲得の経済学と業界の出自.md) で詳しく扱うが、
> ひとことで言えば**「会員数を増やす競争」が終わり、「使われる会員だけを残す競争」に変わった**から。

## 6. 3本柱を1枚にまとめる

```
【カード会社の損益 ざっくり構造】

  収益                              費用
  ┌──────────────────────┐      ┌──────────────────────┐
  │ ① 加盟店手数料        大  │      │ ポイント還元原資      大 │← ①をほぼ食い尽くす
  │   (インターチェンジフィー)│      │ 資金調達コスト(支払利息)│← 金利上昇で急増
  │                          │      │ 貸倒引当金・貸倒損失   │← ②の対価
  │ ② 分割・リボ・キャッシング│      │ 会員獲得費(広告・入会特典)│
  │   の金利・手数料      中  │      │ システム・不正対策     │
  │                          │      │ 人件費・コールセンター  │
  │ ③ 年会費・未稼働手数料 小 │      │ 加盟店開拓・端末       │
  └──────────────────────┘      └──────────────────────┘
          ▲                                  ▲
   ②が増えるほど利益が出る          ポイントと金利が二大コスト
```

| 決算を読むときに見る指標 | なぜ見るか |
| --- | --- |
| **ショッピングリボ残高／分割払残高** | 利益の源泉そのもの。取扱高より重要 |
| キャッシング残高 | 貸金業法の総量規制（年収の1/3）で伸びにくい。減少傾向が続く |
| **稼動会員数／会員数** | 実際に使われている比率。休眠が多いほどコストだけ出ていく |
| 貸倒関連費用・貸倒引当金 | [②与信と貸倒れの管理](02_与信と貸倒れの管理.md) 参照 |
| 支払利息 | 2025年以降の最重要コスト |
| 営業債権残高と有利子負債 | 立替と借入のバランス。丸井は営業債権7,137億円に対し有利子負債7,163億円（2026年3月期） |

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **イシュア** | カードを発行し、会員に請求・回収する会社。このノートの主役 |
| **インターチェンジフィー（IRF）** | 加盟店手数料のうちアクワイアラからイシュアへ渡る部分。イシュア最大の収入 |
| **包括信用購入あっせん** | 割賦販売法上の用語。カードを使った後払い全般（一括・分割・リボを含む）。カード会社の主収益科目名になる |
| **リボルビング払い（リボ）** | 毎月の支払額を一定にし、残高に年率15%前後の手数料がかかる方式。支払総額は増える |
| **分割払手数料** | 3回以上の分割にかかる手数料。実質年率12〜15%前後 |
| **キャッシング** | カードでの現金借入。貸金業法が適用され、利息制限法の上限（15〜20%）と総量規制（年収の1/3）がかかる |
| **稼動会員** | 一定期間に実際に利用のあった会員。会員数との差が休眠 |
| **カードサービス手数料** | 一定期間利用のない会員に課される手数料。実質的な「未稼働会員の年会費」 |
| **支払利息（金融費用）** | 立替資金を借りるコスト。2025年以降の金利上昇で急増している |
| **リカーリングレベニュー** | 繰り返し発生する収益。丸井は売上総利益の67.1%（2026年3月期）と開示 |
