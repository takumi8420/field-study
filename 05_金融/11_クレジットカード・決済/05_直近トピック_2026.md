# ⑤ 直近トピック（2026年9月時点）

報道および各社IR・官公庁資料ベースの整理。数値は公表時点のもので、最新は一次情報で確認すること。
決済サービス側の動き（キャッシュレス比率、PayPay上場、ステーブルコイン、teppay など）は
[フィンテック・キャッシュレス ④ 直近トピック](../../04_情報通信・IT・ネット/13_フィンテック・キャッシュレス/04_直近トピック_2026.md) に置いてある。
**ここはカード会社という事業者の経営に起きていること**に絞る。

> **この1年の一言**：2025〜2026年のカード会社は、**「金利が上がり、会員を減らし、不正が減った」**年だった。
> 資金調達コストの上昇が収益構造を直撃し、各社はリボ・分割の手数料率引き上げと
> 未稼働会員の有料化で対応した。同時に、カードは銀行・経済圏の傘下へ最終的に収まりつつある。

## 1. 金利上昇がカード会社の原価を直撃した

**これが2026年の最大のテーマ**。カード会社は「利用者が払う前に加盟店へ払う」ため、
常に巨額の運転資金を借りている。日本の金利が上がったことで、その利息が跳ね上がった。

| 指標 | 2025年3月期 | 2026年3月期 | 変化 |
| --- | --- | --- | --- |
| クレディセゾン（単体）**支払利息** | 179億66百万円 | **264億84百万円** | **+47%** |
| 丸井グループ 有利子負債（リース債務除く） | 6,365億円 | **7,163億円** | +798億円 |
| 丸井グループ 営業債権（割賦売掛金・営業貸付金） | 6,298億円 | **7,137億円** | +839億円 |

出典：クレディセゾン 2026年3月期決算短信（2026年5月15日）、丸井グループ 2026年3月期決算短信（2026年5月15日）。

```
【金利上昇がカード会社に効く経路】

  政策金利↑
     │
     ├─▶ 社債・CP・借入の調達金利↑ ──▶ 支払利息↑ ＝ 直接の原価上昇
     │                                    （セゾン単体で年+85億円）
     │
     ├─▶ 対抗手段①：分割・リボの手数料率を引き上げる
     │       丸井グループ：2025年10月から料率変更
     │       クレディセゾン：「リボルビング払いに関する手数料改定」を明記
     │
     ├─▶ 対抗手段②：使わない会員から手数料を取る
     │       未稼働会員へのカードサービス手数料
     │
     └─▶ 対抗手段③：調達年限の短縮、格付け向上（丸井が決算短信に明記）

  ▲ 一方で加盟店手数料は競争で上げられない。
    「原価は上がるが売価は上げられない」ので、
    値上げできる場所（会員が払う手数料）に負担が寄る構図になっている。
```

> 注意：これは構造の説明であって、リボ払いや分割払いの利用を勧めるものではない。
> 利用者の側から見れば、**手数料率の引き上げは支払総額の増加**を意味する。
> 仕組みは [① カード会社の収益3本柱](01_カード会社の収益3本柱.md) を参照。

## 2. 「会員数を減らして稼ぐ」フェーズへ ── 未稼働会員の有料化

クレディセゾンは2026年3月期の決算短信で、カード会員数が**2,180万人（前期末比 -6.9%）**となる一方、
**稼動会員数は1,358万人（+0.3%）**を維持したと開示している。

| クレディセゾン 2026年3月期 | 値 |
| --- | --- |
| 新規カード会員数 | 141万人（+2.3%） |
| **カード会員数** | **2,180万人（-6.9%）** |
| **年間稼動会員数** | **1,358万人（+0.3%）** ＝ 稼動率 約62% |
| ショッピング取扱高 | 6兆1,860億円（+3.3%） |
| ショッピングのリボルビング残高 | 5,079億円（+3.6%） |
| カードキャッシング残高 | 1,908億円（-0.9%） |

同社は収益施策として「リボルビング払いに関する手数料改定や、**未稼働会員へのカードサービス手数料導入**の効果が着実に顕在化」と説明している。
ライフカードなども、従来年会費無料だったカードに対し2026年11月請求分から
カードサービス手数料の対象を広げると公式サイトで案内している。

> **構図**：日本には成人1人あたり約3枚のカードがある（発行枚数3億2,057万枚、2025年3月末、日本クレジット協会）。
> 大量に配った結果の休眠会員は、システム・与信管理・信用情報照会のコストだけを生む。
> **「枚数を増やす競争」が終わり、「使われないカードを整理する競争」に変わった**。
> 詳しくは [③ 会員獲得の経済学と業界の出自](03_会員獲得の経済学と業界の出自.md)。

## 3. 不正利用被害が5年ぶりに減少、ただし偽造は増加

日本クレジット協会が2026年3月6日に公表した集計によると、
**2025年のクレジットカード不正利用被害額は510億5,000万円（前年比 -8.0%）**。
前年からの減少はコロナ禍の2020年以来5年ぶり。

| 内訳（2025年） | 金額 | 構成比／前年比 |
| --- | --- | --- |
| 合計 | **510.5億円** | -8.0%（2024年は555.0億円） |
| 番号盗用 | 475.4億円 | 構成比 93.1% |
| **偽造カード** | **7.2億円** | **+22.0%** |
| 不正利用発生率 | 0.038% | － |

四半期別では 1〜3月 193.2億円 → 4〜6月 121.4億円 → 7〜9月 102.0億円 → 10〜12月 93.9億円と、
**2025年3月末のEMV 3-Dセキュア原則義務化以降、一貫して減っている**。

```
【なぜ「減った」と同時に「偽造が増えた」のか】

  EC（番号盗用）を3-Dセキュアで固めた
        │
        ▼
  犯罪側が相対的に手薄な「対面」へ移動
        │
        ├─ 磁気ストライプの複製（偽造カード）
        └─ 非接触ICでPIN入力を求められない取引
        │
        ▼
  2026年3月の【6.1版】で塞ぎにいった
    ・2026年4月以降の新規端末で磁気フォールバック禁止
    ・一定金額以上の非接触ICは接触ICへ遷移してPIN入力

  ▲ 不正は消えるのではなく、いちばん弱いところへ移る。
    規制が「いたちごっこ」になる理由がここにある。
```

詳細は [④ 不正利用とセキュリティ](04_不正利用とセキュリティ.md)。

## 4. 楽天のフィンテック再編 ── カードが銀行の傘下に入る

2026年5月20日、楽天グループは**楽天銀行を統括会社とするフィンテック事業再編の最終合意**を公表した。

| 項目 | 内容 |
| --- | --- |
| スキーム | **株式交付**により、楽天銀行が**楽天カード**と楽天証券ホールディングスを子会社化 |
| 効力発生日 | **2026年10月1日（予定）**。株主総会承認は2026年6月24日予定 |
| みずほの関与 | みずほ銀行は楽天カード株式の14.99%を保有。再編後は**楽天銀行の議決権10.52%**を保有予定 |
| シナジー | 中期的に**年間約850億円以上**（経常利益ベース）。2028年3月期には年間約330億円を見込む |
| 付随する動き | 楽天カードが保有する楽天ペイメント株式（95.28%）は楽天グループへ譲渡予定 |

参考：楽天カードは2025年度のショッピング取扱高26.5兆円、カード発行枚数3,431万枚（2026年6月末）、
営業収益3,754億円・経常利益484億円（同社「数字で見る楽天カード」）。

> **なぜカードが銀行の下に入るのか**。カード単体では
> [①](01_カード会社の収益3本柱.md) で見たとおり薄利で、しかも調達コストが上がっている。
> **預金という安い資金の出し手（銀行）と、与信の出し手（カード）を同じ箱に入れる**ほうが、
> 資金コストでも資本効率でも有利になる。
> これは楽天固有の話ではなく、**カードが単独事業として成立しにくくなったことの象徴**と読める。

## 5. ポイントとデータの囲い込み ── 三井住友カードのVポイント完全掌握

2025年10月3日、三井住友フィナンシャルグループと三井住友カードは、
**Vポイントを運営するCCCMKホールディングスの子会社化**を発表した。

| 項目 | 内容 |
| --- | --- |
| 資本構成の変更 | 三井住友カード20%／SMFG20%／CCC60% → **三井住友カード55%／SMFG25%／CCC20%** |
| 実行時期 | **2026年3月末めど** |
| 商号 | CCCMKホールディングス → **Vポイントマーケティング株式会社**（変更予定） |
| 狙い | 2つに分かれていたアプリの統合（2026年度）、カード決済・預金データとポイント利用履歴の統合、Olive との連携 |

Vポイントは2024年に旧Vポイント（三井住友）と旧Tポイント（CCC）が統合して生まれたもので、
**アプリが2つ並立**していた。統合により運営コストを下げると同時に、
「誰が・どこで・何に使ったか」を1つの基盤に集約する。

参考：三井住友カードの会員数は2025年度 4,335万人（2023年度3,615万人 → 2024年度3,972万人）、
カード取扱高42兆7,500億円（同社「業績データ」）。

> **読み筋**：ポイントは還元のコストであると同時に、
> **購買データを取得するための対価**でもある。
> カード会社が決済データと購買データを1社で持つと、
> 与信（[②](02_与信と貸倒れの管理.md)）にも広告にも使える資産になる。
> 各経済圏が「アプリを1つにまとめたがる」のはこの理由。

## 6. 規制側の動き ── 国が加盟店単位で不正を見にいく

| 時期 | 動き | 意味 |
| --- | --- | --- |
| 2025年4月 | 経産省「加盟店における不正利用対策の在り方に関する検討会」開始 | 不正対策の責任配分を加盟店側へ明確化する議論 |
| 2025年9月 | 割賦販売法（後払分野）に基づく**監督の基本方針**を改正 | 監督の重点の見直し |
| 2025年9月25日 | クレジットカード番号等取扱契約締結事業者の**事業報告書を改訂**。加盟店の不正利用発生状況が報告事項に追加 | **国が加盟店ごとの不正実績を把握**する方向 |
| 2026年3月11日 | クレジットカード・セキュリティガイドライン【6.1版】承認 | 磁気フォールバック禁止、非接触ICのPIN運用 |
| 2026年4月1日 | 令和8年度 信用購入あっせん業者等に対する検査基本方針・検査基本計画を策定 | 通常の年次サイクル |

> **方向性**：規制の重心が「カード会社を監督する」から
> **「カード会社を通じて加盟店を管理させる」**へ移っている。
> アクワイアラにとっては、加盟店の開拓よりも**加盟店の管理・切り捨て**が重い仕事になる。

## 7. 全体の構図（まとめ）

1. **原価が上がった**。金利上昇で調達コストが急増し（セゾン単体の支払利息が1年で+47%）、
   薄利だった加盟店手数料ビジネスの採算がさらに苦しくなった。
2. **値上げできる場所に負担が寄った**。分割・リボの手数料率引き上げ、未稼働会員手数料の導入。
   加盟店手数料は競争があるため上げられない。
3. **会員数を減らす経営に転換した**。休眠を整理し、稼動会員と客単価を上げる。
   「1人あたり3枚」という過剰発行の後始末が始まった。
4. **不正は減ったが移動した**。ECを固めた結果、偽造カードへ流れ、規制が対面側を塞ぎにいった。
5. **カードは単独事業でなくなった**。楽天カードは銀行の傘下へ、三井住友カードはポイント会社を丸ごと取り込む。
   カードは「決済とデータの入口」として、より大きな金融・経済圏の部品になった。

## 用語メモ

| 用語 | 意味 |
| --- | --- |
