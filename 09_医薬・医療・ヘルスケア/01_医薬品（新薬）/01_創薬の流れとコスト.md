# 創薬の流れとコスト｜なぜ1つの薬に10年以上と数百億円かかるのか

**このノートで分かること**：新薬が世に出るまでの工程を、基礎研究から製造販売後調査まで一本の線でたどる。
そのうえで「開発費が高い」と言われる金額が**どういう算数で出てくるのか**を分解する。

> 大原則：新薬開発は**ほとんど失敗する事業**である。
> 1つの成功品の値段には、その裏で消えた何千・何万という失敗分のコストが乗っている。
> この一点を押さえると、薬価・特許・M&A の話がすべて同じ理屈でつながる。

なお、このノートは**産業と制度の説明**であり、個別の薬や治療法についての助言ではない。

## 1. 全体の流れを一枚で

```
【1つの新薬ができるまで（日本の場合）】

 ①基礎研究        ②非臨床試験        ③臨床試験（治験）           ④承認申請・審査   ⑤発売後
  2〜3年            3〜5年              3〜7年                        1〜2年            ずっと
  ┌──────┐        ┌──────┐   ┌────┬────┬──────┐      ┌────────┐     ┌────────┐
  │標的探索│──────▶│動物・ │──▶│第I相│第II相│第III相│─────▶│PMDA審査│────▶│製造販売│
  │化合物  │        │細胞で │   │安全 │用量 │有効性 │      │  ↓     │     │後調査  │
  │スクリー│        │毒性と │   │性   │決め │の証明 │      │薬価収載│     │(PMS)   │
  │ニング  │        │動態   │   │     │     │       │      │        │     │再審査  │
  └──────┘        └──────┘   └────┴────┴──────┘      └────────┘     └────────┘
      ↑                                                            ↑
  特許を出すのはここ（物質特許）                        ここで初めて売上が立つ
  ＝特許20年の時計はここから回り始める                  ＝残りの独占期間は10年強しかない
```

- **治験**＝人に投与して有効性と安全性を確かめる試験のうち、承認申請のデータを取るためのもの。
  法律（医薬品医療機器等法＝**薬機法**）と GCP（臨床試験の実施基準）に沿って行う
- **PMDA**＝独立行政法人 医薬品医療機器総合機構。承認審査の実務を担う国の機関。
  最終的な承認は厚生労働大臣が出す
- 期間は「約9〜16年」「10〜15年」など資料によって幅がある（日本製薬工業協会＝**製薬協**の
  一般向け資料では9〜16年、2020年代の各種調査でもおおむねこの範囲）

> ポイント：**特許の時計は発売前に回り始める**。ここが医薬品ビジネス最大の構造的制約で、
> 詳しくは [03_特許の崖とパイプライン](03_特許の崖とパイプライン.md) で扱う。

## 2. 各段階で何をしているのか

| 段階       | やること                                                                                           | 対象         | 期間の目安   | 落ちる主な理由                           |
| ---------- | -------------------------------------------------------------------------------------------------- | ------------ | ------------ | ---------------------------------------- |
| 基礎研究   | 病気の原因分子（**創薬標的**）を決め、そこに効く候補物質を探す                                     | 試験管・細胞 | 2〜3年       | そもそも標的が病気の原因でなかった       |
| 非臨床試験 | 動物・細胞で毒性、体内での動き（吸収・分布・代謝・排泄＝**ADME**）を調べる                         | 動物・細胞   | 3〜5年       | 毒性が強すぎる、体内で効く濃度に届かない |
| 第I相      | **主に安全性**と体内動態を見る。健康な成人（抗がん剤など毒性の強い分野は患者）が対象               | 数十人       | 1〜2年       | 忍容できない副作用                       |
| 第II相     | **どの量をどう使うか**を決める（用量設定）。有効性の兆しも見る                                     | 数十〜数百人 | 1〜3年       | 効果が見えない。ここが最大の関門         |
| 第III相    | **本当に効くか**を既存薬やプラセボ（偽薬）と比べて証明する                                         | 数百〜数千人 | 2〜4年       | 既存薬に勝てない、差が統計的に出ない     |
| 申請・審査 | 資料一式を提出し PMDA が審査。通常品目で**約12か月**、優先審査で**約9か月**が目標                  | —            | 1〜2年       | データ不足、追加試験の指示               |
| 発売後     | **製造販売後調査（PMS）**。実際に使われた中での安全性を集める。新有効成分は原則**8年**の再審査期間 | 数千〜数万人 | 発売後ずっと | 市販後に重い副作用が判明し回収・撤退     |

- **プラセボ**＝見た目は同じで有効成分の入っていない偽薬。思い込みによる効果を差し引くために使う
- **二重盲検**＝医師も患者も、どちらを投与しているか分からない状態で行う比較試験。最も証拠力が高い
- 第III相は患者数も施設数も桁違いに増えるため、**開発費の過半がここで出ていく**。
  実務の大半は受託研究機関に外注される → [CRO・CDMO](../03_CRO・CDMO/README.md)

## 3. 成功確率の算数

```
【漏斗（ファネル）で見る新薬開発】

  候補化合物        数万〜数十万
      │            ↓ ほとんどがここで消える
  非臨床に進む        数十〜数百
      │            ↓
  治験に入る（第I相）    十数
      │            ↓ 第II相で約半分が落ちる（業界通説）
  第III相に進む          数個
      │            ↓
  承認・発売             1
  ─────────────────────────────
  製薬協の一般向け資料では
  「発売に至る確率は約2〜3万分の1」（2020〜2025年の各版で 22,407分の1 / 約3万分の1 など）
```

| 指標                                  | 数値                                             | 年・出典の性格                                                               |
| ------------------------------------- | ------------------------------------------------ | ---------------------------------------------------------------------------- |
| 合成〜発売の成功確率                  | 22,407分の1                                      | 製薬協「てきすとぶっく 製薬産業 2020-2021」                                  |
| 同（別の版）                          | 約3万分の1                                       | 製薬協ガイド2025                                                             |
| 1新薬を上市するための期待研究開発費用 | **約1,415億円**（資本コスト10%前提、2023年価格） | 製薬協 医薬産業政策研究所 RESEARCH PAPER No.82（アンケート調査に基づく推計） |
| 開発期間                              | 9〜16年                                          | 製薬協 一般向け資料                                                          |

> 注意：「数万分の1」は**研究室で合成した化合物の数を分母にした数字**であり、
> 「治験に入った薬が承認される確率」（分野により10〜20%程度とされる）とは分母が違う。
> ニュースでこの2つが混ざって使われることが多い。

## 4. なぜ数百億〜数千億円になるのか＝失敗分を成功品が背負う

高いのは「1つの薬を作る作業が高い」からではない。**失敗した99.99%の費用を、
生き残った1品目の売上で回収しなければならない**からである。

```
【費用の負担構造】

  失敗した開発  ┐
  失敗した開発  ├─── すべて費用（資産にならない）
  失敗した開発  │     ＝ 会計上は発生した期の研究開発費として処理される
  失敗した開発  ┘
        ＋
  成功した1品目 ────▶ 売上  ──────▶ ここで全部を回収する
                                       ＋次の開発の原資も出す

  さらに：投じた金は10年以上寝る → 資本コスト（時間の値段）が乗る
          1,415億円という推計値の内訳の相当部分が、この「待ち時間の金利」
```

高コストの内訳を言葉にすると次の4つになる。

| 要因                | 中身                                             | なぜコストを押し上げるか                                                           |
| ------------------- | ------------------------------------------------ | ---------------------------------------------------------------------------------- |
| **失敗の吸収**      | 上の漏斗で消えた分                               | 成功品1つが全部を背負う                                                            |
| **資本コスト**      | 投資から回収まで10年以上                         | 10年間資金が寝る分の機会費用が複利で乗る                                           |
| **第III相の大型化** | 数千人規模、多国籍、長期追跡                     | 患者1人あたり数百万円規模の実施費用がかかるとされる                                |
| **要求水準の上昇**  | 既存薬が良くなるほど「それより良い」証明が難しい | 必要な被験者数と観察期間が増える（**イルームの法則**＝Eroom's law と呼ばれる現象） |

> **イルームの法則**：半導体の「ムーアの法則」を逆さに綴ったもじり。
> 技術が進歩しても、新薬1つあたりの開発費は時代とともに**上がり続けてきた**という観察。

## 5. モダリティ（治療手段の種類）の移り変わり

**モダリティ**＝薬の「作り」の種類。低分子か、タンパク質か、核酸か、細胞か。
ここが変わると、開発の難所も製造設備も営業のやり方もまるごと変わる。

| モダリティ             | 実体                                           | 製造の主体                   | 産業上の性格                     | 特許切れ後の脅威                                     |
| ---------------------- | ---------------------------------------------- | ---------------------------- | -------------------------------- | ---------------------------------------------------- |
| **低分子**             | 化学合成した小さな分子。飲み薬にしやすい       | 化学プラント                 | 量産が安く、患者数の多い病気向け | **後発医薬品**。同じ物が安く作れる                   |
| **抗体医薬**（バイオ） | 免疫のタンパク質を利用。注射が基本             | 培養タンク（細胞に作らせる） | 単価が高い。製造設備が参入障壁   | **バイオシミラー**。完全同一は作れず置き換わりが遅い |
| **核酸医薬**           | 短い人工の遺伝情報。遺伝子の読み取りを邪魔する | 化学合成                     | 希少疾患向けが中心。反復投与     | 参入は限定的                                         |
| **細胞・遺伝子治療**   | 細胞そのもの／遺伝子を運び込む                 | 無菌の細胞培養施設           | 1回数千万〜数億円。患者数が極小  | 実質なし（別の難しさがある）                         |

- 売上の重心は**低分子から抗体へ、さらに一部が核酸・細胞遺伝子へ**移ってきた。
  世界の売上上位品目に抗体医薬や生物学的製剤が並ぶようになって久しい
- 細胞・遺伝子治療の詳細（CAR-T、ベクター、条件及び期限付承認、製造の難所）は
  重複を避けて別ノートに置いてある → [再生医療・ゲノム](../../01_注目テーマ/14_再生医療・ゲノム/README.md)
- モダリティが変わると**売り先も変わる**。低分子は開業医まで広く、抗体や細胞治療は
  一部の専門病院だけ。これが営業体制を作り替えた → [04_営業と情報提供](04_営業と情報提供.md)

## 6. 創薬標的とバイオマーカー＝「誰に効くか」を先に決める

昔の創薬は「広く効く薬を作り、効く人を後から探す」形だった。
いまは逆で、**効く患者をあらかじめ選別してから開発する**のが主流になっている。

- **創薬標的（ドラッグターゲット）**＝薬が結合して働きかける分子。多くはタンパク質。
  「この分子を止めれば病気が止まる」という仮説そのものが資産になる
- **バイオマーカー**＝患者の体を測って得られる指標。遺伝子変異、血液中のタンパク質量など。
  これで「効きそうな患者」を選ぶ

```
【従来型 vs バイオマーカー型の開発】

 従来型：  全患者1,000人に投与 ─▶ 3割に効いた ─▶ 差が出にくい／失敗しやすい
                                                   でも売れる相手は多い

 選別型：  遺伝子検査 ─▶ 該当する200人だけに投与 ─▶ 7割に効いた ─▶ 少人数の治験で承認
                                                   でも売れる相手は少ない
                                                   → 1人あたりの薬価は高くなる
```

> ポイント：**バイオマーカーで患者を絞ると、治験は小さく速くなるが、市場も小さくなる**。
> 「少人数・高単価」という近年の新薬の姿は、この選別の結果として出てくる。
> がん領域でこの考え方を制度に組み込んだのが「がんゲノム医療」である
> → [ゲノム医療の実装](../../01_注目テーマ/14_再生医療・ゲノム/04_ゲノム医療の実装.md)

## 7. 誰が開発しているのか＝自前で全部はやらない

| 担い手                       | 役割                                                 | 経済的な特徴                               |
| ---------------------------- | ---------------------------------------------------- | ------------------------------------------ |
| 製薬企業（自社研究所）       | 標的探索から承認申請まで一通り                       | 固定費が重い。近年は研究拠点の統廃合が進む |
| 創薬ベンチャー               | 標的発見〜第I/II相で価値を作り、大手に売る／導出する | 1品目に社運を賭ける。資金調達が生命線      |
| **CRO**（開発業務受託機関）  | 治験の設計・実施・データ管理を受託                   | 製薬企業の変動費化の受け皿                 |
| **CDMO**（開発製造受託機関） | 原薬・製剤の製造を受託                               | 設備投資を肩代わりする                     |
| **SMO**／治験施設支援        | 医療機関側で治験を回す支援                           | 症例集めの実行部隊                         |
| アカデミア・公的機関         | 基礎研究、標的の発見                                 | 論文と特許が出口                           |

- 開発の実務は大きく外部化された。製薬企業は**自社で抱えるのは意思決定と目利き**に寄っている
  → [CRO・CDMO](../03_CRO・CDMO/README.md)、[創薬ベンチャー・バイオ](../04_創薬ベンチャー・バイオ/README.md)
- 会計上、研究開発費は**発生した期に費用処理**される（資産計上しない）。
  よって開発が進むほど利益が減って見える。一方で買収した他社の開発品は無形資産に計上され、
  失敗すれば減損として一気に損失が出る。**自社開発と買収では、損の出方が違う**

## 8. 開発が終わって初めて始まるもの

承認は終わりではなく、規制の入口が別のものに変わるだけである。

| 発売後の仕組み               | 中身                                                                                 |
| ---------------------------- | ------------------------------------------------------------------------------------ |
| **製造販売後調査（PMS）**    | 実際の使用下で安全性・有効性の情報を集めて報告する義務                               |
| **再審査制度**               | 新有効成分は原則8年（希少疾病用医薬品は最長10年）、期間後に有効性・安全性を再評価    |
| **GVP／GPSP**                | 市販後の安全管理・調査の基準。これを守れる体制がないと製造販売業の許可が維持できない |
| **副作用報告**               | 重篤な副作用は期限付きで当局へ報告する義務                                           |
| **医薬品副作用被害救済制度** | 適正に使用しても生じた副作用被害を救済する公的制度。企業の拠出金で運営               |
| **GMP**                      | 製造管理・品質管理の基準。査察で不備が出れば業務停止になり得る                       |

> 2020年代前半に後発医薬品メーカーで相次いだ製造不正・出荷停止は、この GMP の運用が
> 破られた事例である。新薬メーカーにとっても他人事ではない
> → [後発医薬品](../02_後発医薬品/README.md)

## 用語メモ

- **治験**：承認申請用のデータを取るために人に投与して行う試験。薬機法と GCP に従う
- **GCP**：医薬品の臨床試験の実施の基準。被験者保護とデータの信頼性を担保するルール
- **非臨床試験（前臨床）**：人に入れる前の動物・細胞での試験。毒性と体内動態を見る
- **ADME**：吸収・分布・代謝・排泄。薬が体内でどう動くか
- **第I/II/III相**：順に安全性、用量設定、有効性の証明を主目的とする臨床試験の段階
- **プラセボ**：有効成分を含まない見た目だけの薬。比較対照に使う
- **PMDA**：医薬品医療機器総合機構。承認審査・安全対策・健康被害救済を担う国の機関
- **薬機法**：医薬品医療機器等法。医薬品・医療機器の承認と品質を規律する基本法
- **モダリティ**：薬の種類（低分子・抗体・核酸・細胞・遺伝子など）
- **創薬標的**：薬が作用する分子。多くはタンパク質
- **バイオマーカー**：効きそうな患者を選ぶための体の測定指標
- **PMS**：製造販売後調査。発売後に安全性情報を集める仕組み
- **再審査期間**：新薬の発売後、有効性・安全性を再評価するまでの期間。新有効成分は原則8年
- **GMP／GVP／GPSP**：それぞれ製造、市販後安全管理、市販後調査の基準
- **CRO／CDMO**：開発業務／開発製造を受託する事業者
- **イルームの法則**：技術進歩にもかかわらず新薬1つあたりの開発費が上昇し続けてきた現象
