儲け方と流通 ——「値引きしない家電」はなぜ生まれたか

電機・電子部品白物家電
あこのページの単語集用語に触れると意味を確認できます10語
指定価格制度（メーカー指定価格）再販売価格の拘束オープン価格メーカー希望小売価格買取仕入／委託販売販促金（販売奨励金・リベート）ショールーミング延長保証補修用性能部品の保有期間家電リサイクル法

このノートで分かること：白物家電メーカーが何で儲け、どこで利益を削られてきたか。
そして日本の家電流通を理解する最大の鍵である指定価格制度（メーカーが小売価格を決め、
売れ残りはメーカーが引き取る売り方）が、なぜ生まれ、誰が得をし、なぜ独占禁止法に触れないのかを説明する。

結論を先に：家電メーカーの利益は「作る力」ではなく、「値崩れをどれだけ防げるか」で決まる。
発売から1年で店頭価格が半分になる商品を作っても、利益は残らない。
指定価格制度は、在庫リスクをメーカーが引き受ける代わりに値決めを取り戻すという取引であり、
30年続いた「量販店が値段を決める」構造をひっくり返そうとする試みである。

1. まず、1台の家電の儲けの構造

ドラム式洗濯乾燥機（店頭30万円クラス）を例に、金額の流れをつかむ。
※業界の一般的な水準感であり、企業・機種により大きく異なる概算モデル。

【店頭価格30万円の家電が、どう分配されるか（概算モデル）】

  店頭価格 300,000円
   ├─ 小売（量販店）の粗利  約 45,000〜75,000円（15〜25%）
   │    └ 人件費・家賃・配送・設置工事・ポイント原資はここから出る
   └─ メーカー出荷価格      約 225,000〜255,000円
        ├─ 材料費・部品費        約 110,000〜140,000円（50〜60%）★最大
        ├─ 製造労務費・工場経費   約  25,000〜 35,000円
        ├─ 物流費                約  10,000円
        ├─ 販売促進費（販促金）   約  10,000〜 20,000円 ★値引き原資に消える
        ├─ 研究開発費・広告宣伝   約  15,000〜 25,000円
        └─ 営業利益              約   5,000〜 20,000円（営業利益率 2〜8%）

  → 原価率が高く利益が薄い。**5%の値引きが営業利益の半分を消す**

コストの性格：材料費（鋼板・樹脂・銅・半導体）は市況と為替で動く変動費、
工場は稼働率次第の固定費、物流・設置は重量物ゆえ高くドライバー不足で上昇中、
研究開発は高付加価値路線を続ける限り削れない固定費。

ポイント：家電メーカーの営業利益率は概して数%で、
電子部品（10%前後）より薄い。だから値引き1回の重みが他産業より圧倒的に大きい。

2. なぜ値崩れするのか ——「メーカー希望小売価格」が機能しなくなった歴史

かつて家電にはメーカーが示す希望小売価格（定価）があり、街の電器店はその前後で売っていた。
これが崩れた流れは以下のとおり。

時期 出来事 値決めの主導権
〜1980年代メーカー系列の街の電器店（ナショナルショップ等）が主力。定価販売メーカー
1990年代家電量販店が台頭。「他店より1円でも安く」の価格競争量販店へ移動
2000年代量販店の全国チェーン化。販促金を積んで棚を取り合う。価格.com等で全国の最安値が可視化量販店＋消費者
2010年代Amazon・楽天などECが伸長。実店舗は「ショールーミング」に悩む量販店＋EC
2020年代メーカーが指定価格制度で値決めを取り戻しにいくメーカーへ揺り戻し

多くのメーカーは今、「オープン価格」（希望小売価格を示さず、値段は小売に委ねる形）を採る。
定価を示すと「定価の半額！」という値引き表示に使われ、ブランド価値が下がるためだが、
その結果値段の基準そのものが消え、発売直後から下がり続ける状態になった。

【オープン価格のもとでの、典型的な価格の落ち方】

  店頭価格
   │ ●  発売  （実勢 30万円）
   │  ●
   │    ●     3か月後  25万円
   │      ●
   │        ● 半年後   20万円
   │          ●
   │            ●  1年後・後継機発表 → 在庫処分 15万円
   │              ●●●●●
   └──────────────────────────▶ 時間

  メーカーの痛み：
   ・売れ残り在庫を「処分価格」で引き取る／販促金を追加投入
   ・翌年の新製品の価格の基準が、前年の“投げ売り価格”になってしまう
   ・高機能を載せても値引きで吸収され、開発費を回収できない

3. 指定価格制度とは何か

メーカーが小売価格を指定し、その価格でしか売らせない。代わりに売れ残りはメーカーが引き取る売り方。
2020年度にパナソニックがナノケアドライヤーとドラム式洗濯乾燥機で試験導入し、以降拡大した。

3-1. 通常取引との違い

論点 従来の取引（買取仕入） 指定価格制度
小売価格を決めるのは小売（量販店・EC）メーカー
在庫の所有小売が仕入れて保有形式上は小売だが、売れ残りは返品可能
売れ残りリスク小売が負うメーカーが負う
保管中の滅失・毀損リスク小売メーカー
小売の粗利仕入値と売値の差（値引きすれば減る）あらかじめ決まった率で固定（薄いが確実）
値引き交渉できるできない（どの店でも同じ値段）
対象商品全般冷蔵庫・洗濯機・エアコン・美容家電などの上位機種中心
【在庫リスクの持ち先が入れ替わる】

  ＜従来＞
    メーカー ──販売（買取）──▶ 量販店 ──▶ 消費者
       利益確定                 在庫リスクを負う
                                ↓ だから売り切るために値引きする
                                ↓ 値引き原資をメーカーに要求する（販促金）
                                ↓ 結果、メーカーの利益も削れる

  ＜指定価格＞
    メーカー ──委託に近い形──▶ 量販店 ──▶ 消費者
       ★在庫リスクを負う         値引きできない／粗利は固定
       ★価格を決められる         売れ残りは返品してよい
       ↓
       値崩れしない＝開発費を回収できる／ブランド価値が守られる
       ただし**売れ残りは全部自分に返ってくる**（需要予測を外せば直撃）

3-2. なぜ独占禁止法に違反しないのか

ここが最も誤解されやすい点。メーカーが小売の販売価格を拘束することは、原則として
独占禁止法が禁じる「再販売価格の拘束」（不公正な取引方法）にあたる。
ではなぜ指定価格制度は許されるのか。

理由：小売が「転売者」ではなく「メーカーの販売代行」に近い立場になっているから。
在庫リスク・返品・保管中の滅失毀損リスクをすべてメーカーが負うなら、
商品の実質的な所有者はメーカーであり、小売は委託販売の受託者に近い。
自分の商品の値段を自分で決めているだけなので、「他人の再販価格の拘束」にあたらない。

公正取引委員会は令和元年度の相談事例「家電メーカーによる小売業者への販売価格の指示」で、
メーカーが上記のリスクを負う形であれば独占禁止法上問題ないとの見解を示している。
さらに2026年5月13日、公取委は「流通・取引慣行に関する独占禁止法上の指針」の改正案を公表し
（意見募集は同年6月11日まで）、再販売価格維持行為が通常は違法とならない場合の考え方と具体例を追加
する方針を示した。指定価格型の取引が制度として定着しつつあることの表れと読める。

形態 独禁法上の扱い 条件
単なる価格指示（買取仕入のまま）違反（再販売価格の拘束）—
「希望」小売価格の提示適法拘束しないこと。実質的に守らせると違反
指定価格制度（委託販売型）適法とされるメーカーが在庫・返品・滅失毀損のリスクを負うこと
直販（メーカー自身のECで売る）適法自社商品の自社価格

4. 誰が得をして、誰が困るのか

立場 メリット デメリット
メーカー値崩れしない／利益率が上がる／ブランドが守れる／店頭価格を自分で設計できる在庫リスクを全部背負う／売れないと返品の山／需要予測の精度が経営を左右
家電量販店粗利率が安定する／値引き交渉の人件費が減る／他店と同じ値段なので価格対抗が不要「安さ」で客を呼べない／粗利の絶対額は薄い／売る動機が弱まる
EC（Amazon等）同上最安値という最大の武器を封じられる
地域の電器店量販店と同じ値段で戦える＝工事・相談・アフターで勝負できる安さ目当ての客は来ない
消費者どこで買っても同じ／時期を待つ損得が減る／販売員の説明が丁寧になる値引きが一切できない／待っても安くならない（型落ちまで待つしかない）

見落としやすい効果：指定価格制度は、地域電器店とECの競争条件を揃える。
価格が同じなら、消費者は「設置してくれる」「相談できる」方を選びうる。
メーカーにとっては、自社に近い販路（系列店・自社EC）の価値を回復させる手でもある。

【指定価格制度が広がる順番（なぜこの順なのか）】

  第1段階：小物の高付加価値品（ドライヤー・美容家電）
            └ 単価が安く在庫リスクが小さい。失敗しても傷が浅い
  第2段階：ドラム式洗濯乾燥機など「説明が要る」高額品
            └ 値引き前提で買う客が少なく、機能で選ばれる商品
  第3段階：冷蔵庫の上位機種 ← 三菱電機はここから（2026年1月）
            └ 大型・重量物。返品されると保管コストが重い
  第4段階：エアコン（※各社慎重）
            └ 天候で需要が激変。返品リスクが読みにくい最大の難所

広げられない領域がある。指定価格はメーカーが在庫を丸抱えする制度なので、
需要予測が外れやすい商品ほど導入しにくい。エアコンが典型で、冷夏になれば
返品が一気に来る。だから制度は「読める商品」から順に広がっている。

6. 販路の全体像と力関係

【白物家電が消費者に届くまで】

  メーカー
    ├─▶ 家電量販店（ヤマダ・ビック・ヨドバシ・ケーズ・エディオン・ノジマ）
    │     最大の販路。配送・設置・工事・長期保証を持つ ★従来の値決め主体
    ├─▶ EC（Amazon、楽天、量販店の自社EC）
    │     最安値を可視化した張本人。大物は設置が課題で量販に分がある
    ├─▶ 地域電器店（メーカー系列店）
    │     高齢層・アフター重視層に強い。単価は高いが台数は小さい
    ├─▶ 住宅・工務店・リフォーム経由（ビルトイン機器・エアコン）
    │     住宅着工とセット。BtoBに近い
    ├─▶ ホームセンター・ディスカウント・ニトリ等 … 低価格帯とPBの主戦場
    └─▶ メーカー直販EC／サブスク … 台数は小さいが“基準価格”を示す役割
  • 量販店側の経済性（坪効率・ポイント原資・保証の収益化）は
    → 家電量販
  • EC側の構造は → 通販・D2C
  • 低価格帯の売り場は → ディスカウントストア

7. 売った後でも儲ける ——修理・延長保証・消耗品

台数が増えない市場では、1台あたりからどれだけ長く回収するかが重要になる。

収益源 誰が取るか 特徴
修理・部品供給メーカー（サービス子会社）補修用性能部品の保有年数は製品ごとに定められる（冷蔵庫・洗濯機・エアコンで9年前後が目安）。修理費が高いと買い替えに流れる
延長保証量販店（保証料は店の収益）5年・10年保証。実質は保険商品で、量販店の高収益源
消耗品・フィルターメーカー空気清浄機・浄水器などで効く「替え刃モデル」
サブスク・レンタル新興事業者・メーカー単身・短期需要。まだ小さい

延長保証がメーカーではなく量販店の収益である点が重要。
量販店が値引き圧力に耐えられるのは、本体で薄くても保証・工事・ポイントで回収できるから。
指定価格制度は本体の粗利を固定するので、量販店はいっそう保証と工事に依存することになる。

8. 逆風としてのリユース市場と家電リサイクル法

新品が売れない方向に働く要因も押さえておく。

  • 家電リサイクル法（特定家庭用機器再商品化法）の対象は4品目＝エアコン、テレビ、
    冷蔵庫・冷凍庫、洗濯機・衣類乾燥機。廃棄時に消費者がリサイクル料金と収集運搬料を負担する。
    2026年2月に主要メーカーのエアコンのリサイクル料金が990円→550円に下がったと報じられる一方、
    運営費上昇で引き上げられた品目もある（最新は家電製品協会の料金表で確認）
  • 中古は「廃棄物」ではなく「商品」。買い取って再販する場合はリサイクル料金が発生しない。
    捨てると金がかかり、売ると金が入るという非対称がリユース市場を後押ししている
  • 単身・学生向けの安価な需要は中古と低価格新品が食い合う。
    高価格帯に逃げた日本勢は、この層をほぼ手放している

→ リユース・中古、
　廃棄物処理・環境リサイクル

9. まとめ

  1. 利益率が薄く、値引きが利益を直撃する。30年かけて値決めの主導権は量販店・ECへ移った
  2. 指定価格制度＝在庫リスクを引き受ける代わりに値決めを取り戻す取引。
    独禁法上は「委託販売に近い形」だから適法とされる
  3. 制度は「需要が読める商品」から順に広がる。天候依存のエアコンが最大の難所
  4. 量販店は本体粗利が固定される分、延長保証・工事・ポイントへの依存を強める
