# 直近トピック（2026年9月時点）

報道と統計をもとにした整理。**確定した事実と、報道ベース・推計を区別して書く**。
数値は発表時点のものなので、最新はJEMA統計と各社IRで必ず確認すること。

> **2026年の白物家電を一言でいうと**：
> **「猛暑と省エネ規制の駆け込みで市場は史上最高圏。しかし儲けているのは日本メーカーとは限らない」**。
> 出荷金額は過去最高を更新する一方、日立は家電事業を量販店に売り、
> パナソニックの家電は赤字、中国勢は洗濯機でシェア2位を主張している。

## 1. 白物家電の国内出荷が「上期として過去最高」（2026年7月発表）

日本電機工業会（JEMA）の民生用電気機器統計で、**2026年1〜6月の国内出荷金額は1兆4,350億円**。
**1986年以降の統計で上期として過去最高**となった（従来の最高は1991年の1兆3,671億円）。

| 指標 | 2026年1〜6月 | 前年同期比 |
| --- | --- | --- |
| 白物家電 国内出荷金額 | **1兆4,350億円** | 増（上期の過去最高） |
| ルームエアコン 出荷台数 | **652万7,000台** | **+19.4%** |
| ルームエアコン 出荷金額 | **6,102億7,700万円** | **+21.7%** |
| 参考：2026年4月のエアコン出荷額 | 1,002億円 | **+34.1%**（4月として過去最高） |

参考に近年の流れ（JEMA、暦年）：

| 年 | 国内出荷金額 | 前年比 |
| --- | --- | --- |
| 2025年 | 2兆6,418億円 | +2.4%（2年連続プラス、1991年に次ぐ過去2番目） |
| 2025年度（25/4〜26/3） | 2兆6,813億円 | +3.8%（2年連続プラス） |

> **なぜ伸びたのか**。3つが重なった。
> ①**猛暑の常態化**でエアコンの買い替え・増設が進んだ
> ②**エアコン2027年問題**を前にした駆け込み（次節）
> ③**自治体の省エネ家電補助**（東京ゼロエミポイント等）が背中を押した
> いずれも**メーカーの実力ではなく外部環境**であることに注意。2027年度以降の反動減が読みどころになる。

## 2. エアコン「2027年問題」——規制が需要を前倒しさせている

**2027年4月から、家庭用エアコンの省エネ基準（トップランナー制度）が強化される**。
同時期に冷媒規制（フロン排出抑制法にもとづく温室効果の低い冷媒への移行）も強まるため、
2つが重なる状況を業界・報道が「**2027年問題**」と呼んでいる。

```
【2027年問題が需要と価格に効く仕組み】

  2027年4月 ─── 省エネ基準（トップランナー制度）強化
                  │
                  ├─▶ メーカーは「出荷製品の加重平均」で基準達成を求められる
                  │      └ 個々の製品に一律の義務ではない点に注意
                  │
                  ├─▶ 基準未達の【安価なスタンダードモデル】を減らすしかない
                  │      └ 業界では現行スタンダードの約7割が未達と言われる（報道ベース）
                  │
                  ├─▶ 低価格帯の品数が減る／省エネ部材が増えて原価が上がる
                  │
                  └─▶ 【結論】安いエアコンほど値上がりしやすい

  消費者の反応：2026年のうちに買っておこう  ──▶ ★駆け込み需要（いま起きていること）
  2027年度以降：買った人はもう買わない      ──▶ ▼反動減のリスク
```

押さえるべき前提：

- **トップランナー制度は「メーカーの出荷全体の加重平均」で目標達成を求める仕組み**。
  「基準未達の機種は違法になる」という単純な話ではない
- **規制対象はメーカー**であり、いま使っているエアコンを買い替える義務はない
- 資源エネルギー庁も2026年に解説を公表しており、制度自体は公式情報で確認できる

> **業界構造への含意**：省エネ規制の強化は、**技術力と開発費を持つ側に有利**に働く。
> 安さだけで勝負する低価格モデルが減るため、**高価格帯に逃げていた日本勢には追い風**になりうる。
> 一方で、市場全体の台数は2027年度以降に落ちる可能性が高い。

## 3. 指定価格制度が三菱電機にも広がる（2026年1月）／公取委はガイドライン改正へ（2026年5月）

**三菱電機は2026年1月8日、指定価格制度の導入を発表**した。
まず同年1月23日発売の新型冷蔵庫の上位機種から適用する（時事通信・日経などの報道）。
パナソニック（2020年度から）、日立（2023年から）に続く3社目の大手で、
**「値引きしない家電」が日本の主要メーカーに定着しつつある**ことを示す動きである。

| メーカー | 開始 | 範囲（報道ベース） |
| --- | --- | --- |
| パナソニック | 2020年度に試行→2022年度拡大 | **国内白物家電の約3割** |
| 日立 | 2023年9月 | 全製品の約1割から開始 |
| **三菱電機** | **2026年1月** | まず冷蔵庫の上位機種 |
| シャープ | — | 導入予定なしと報じられる |

制度の中身と独占禁止法との関係は → [儲け方と流通](02_儲け方と流通.md)

**制度面の動き**：公正取引委員会は**2026年5月13日、「流通・取引慣行に関する独占禁止法上の指針」の
改正案**を公表し、意見募集を行った（同年6月11日まで）。
改正の趣旨は、**再販売価格維持行為が通常は違法とならない場合の考え方と具体例を追加する**こと。
指定価格型の取引が「例外的な工夫」から「制度として整理される段階」に入ったと読める。

> **論点**：消費者から見ると値引きが消える。小売から見ると粗利は安定するが安さで客を呼べない。
> **「価格競争が消えたぶん、消費者は本当に得をしているのか」**は、まだ答えの出ていない問いである。
> 販促金の削減と値崩れ防止で浮いた分が、性能向上や修理サービスに還元されるかが評価の分かれ目になる。

## 4. 日立の家電事業、ノジマへ——「家電量販店がメーカーを持つ」（2026年4月）

2026年4月21日、日立製作所と日立グローバルライフソリューションズ（日立GLS）は、
**家電事業を新会社に分離し、その株式80.1%を家電量販店大手ノジマへ約1,100億円で譲渡する契約**を締結した。

| 項目 | 内容 |
| --- | --- |
| 発表日 | 2026年4月21日 |
| 対象 | 日立の家電事業（冷蔵庫・洗濯機・掃除機等）。**空調事業は日立GLSに残る** |
| スキーム | 新会社を設立し、株式**80.1%**をノジマへ譲渡。残り**19.9%**は日立GLSが保有 |
| 金額 | **約1,100億円** |
| 完了予定 | **2027年3月期中**（各国競争法クリアランス等を経て） |
| 海外 | トルコ・アルチェリクとの合弁株式を日立が全取得し、**国内外の家電を統合してから渡す** |
| 規模 | 従業員は約7,000人規模と報じられる。買収後のノジマ連結売上高は約1兆2,000億円規模の見込み |

```
【この取引が異例である理由】

  従来の家電の力関係
    メーカー ──商品を供給──▶ 量販店 ──▶ 消費者
                  ▲ 値引き要求・販促金要求
                  └─ 量販店の方が強い（値決めの主導権を持つ）

  今回の形
    ノジマ（量販店）
      ├── 小売（店舗・EC）
      └── ★メーカー（日立ブランドの家電）を傘下に持つ
              │
              └─▶ 企画から製造・販売・設置・保証まで一気通貫
                   ＝いわゆる SPA（製造小売）に近い形

  狙い：・中間マージンを自社に取り込む
        ・自社で企画した商品を確実に売り場に置ける
  課題：・製造・開発の固定費を小売が背負う（量販店にはない体力の使い方）
        ・他の量販店が「ノジマ傘下のブランド」を売りにくくなる可能性
```

> **背景の論理**：日立にとって家電は「**最後の非中核事業**」だった。
> 日立は送配電とITで稼ぐ会社になっており、**売り切り型のBtoC事業は成長戦略に乗らなかった**。
> → [総合電機](../01_総合電機/README.md)、[直近トピック（総合電機）](../01_総合電機/04_直近トピック_2026.md)
> ノジマ側から見れば「量販店の逆襲」とも読めるが、**メーカー機能を小売が持ちこなせるか**は未知数。

## 5. パナソニック：家電を主体とする新「パナソニック株式会社」が発足（2026年4月）

2025年2月に発表されたグループ経営改革が、2026年に形になった。

| 時期 | 内容 |
| --- | --- |
| 2025年2月 | グループ経営改革を発表。**課題事業4つ**（産業デバイス／メカトロニクス／キッチンアプライアンス／**テレビ**）を挙げ、撤退や事業承継を検討。家電・空質空調・ハウジングは**再建事業**と位置づけ |
| 2025年 | 白物・空調・照明を束ねていた事業会社「パナソニック」を**解体して3社に分割**。国内外で1万人規模の人員削減を打ち出す（後に規模は拡大と報じられる） |
| 2026年3月期 | 家電を含む**スマートライフ部門は営業▲373億円**で、グループ唯一の赤字セグメント |
| **2026年4月1日** | **家電を主体とする「くらし事業」の新しいパナソニック株式会社が発足** |
| 目標 | 2026年度までに1,500億円以上、2028年度までにさらに1,500億円以上（計3,000億円以上）の収益改善効果 |

> **読み方**：「パナソニック＝家電」というイメージと、実際の稼ぎ頭（電池・電材・業務ソフト）の
> ズレが最も大きい会社である。**家電は看板だが稼ぎ頭ではない**。
> それでも手放さないのは、ブランドと流通網（系列電器店）が全社の資産だからだと説明される。
> パナソニックが**指定価格制度の先駆者**であることも、この文脈で理解できる——
> 台数で勝てない以上、値崩れを止めるしかない。
> → [各社の再編史と現在の稼ぎ頭](../01_総合電機/02_各社の再編史と現在の稼ぎ頭.md)

## 6. 中国勢が「最後の牙城」白物に本格参入（2025〜26年）

テレビで日本市場を崩した中国勢が、白物家電へ攻め込んでいる。
以下は**報道および各社発表**にもとづく整理で、第三者統計による確定値ではない。

| 時期 | 出来事 |
| --- | --- |
| 2024年12月 | **ハイアール日本法人**が大型白物家電のラインアップ拡充と販売体制強化を発表 |
| 2024年 | 中国ブランドが日本の薄型テレビ市場で**初めて過半**を占めたとされる。日本の冷蔵庫市場でも中国ブランドのシェアが**3割近く**に迫ったとされる |
| 2025年 | **ハイセンスジャパン**が大型白物家電市場へ本格参入 |
| 2026年6月 | **ハイアールが日本の洗濯機市場でパナソニックを抜き2位に浮上したと発表**（自社発表であり、集計範囲に注意） |

低価格を実現できる理由は明快で、**世界で売る台数が桁違いに多く、
グループ共通のベースモデルをマイナーチェンジして各国に出すため、開発費と部材費を薄く配れる**こと。
日本勢の白物家電事業（1社あたり数千億円規模）と、美的集団（2025年に売上約4,585億元と報じられる）や
ハイアールスマートホーム（2024年12月期 約2,860億元）とでは、そもそも規模が1桁違う。

→ [日本メーカーの現在地](03_日本メーカーの現在地.md)

## 7. 全体の構図（まとめ）

1. **市場は絶好調、企業は苦しい**。2026年上期の国内出荷は過去最高だが、
   押し上げたのは猛暑・省エネ規制の駆け込み・補助金という外部要因であり、実力ではない
2. **2027年4月の省エネ基準強化が最大の変数**。いまの好調は前倒し需要を含むため、
   2027年度以降の反動減を織り込んで見る必要がある。一方で規制強化は技術力のある側に有利に働く
3. **値決めの構造が変わりつつある**。指定価格制度がパナソニック・日立に続き三菱電機へ広がり、
   公取委もガイドライン改正でその整理に動いた。**「安さで選ぶ」時代の終わりの始まり**かもしれない
4. **日本企業の撤退は最終局面**。日立の家電売却（2026年4月）で総合電機の「脱家電」はほぼ完了し、
   家電を看板に残すのは実質パナソニックのみになる
5. **空いた場所に中国勢が入る**。テレビで実証済みの手法（ブランド買収→低価格帯→大型化）が
   白物でも進行中。**日本ブランドの家電を買っても資本は日本にない**ことが当たり前になった

| --- | --- |

| **トップランナー制度** | 最も省エネ性能の高い製品を基準に目標値を設定する規制。**出荷製品の加重平均**での達成を求める点が重要 |
| **冷媒規制** | エアコンに使う冷媒の温室効果（GWP）を下げる規制。フロン排出抑制法などにもとづく |
| **東京ゼロエミポイント** | 東京都の省エネ家電買い替え支援。対象期間は令和6年10月1日〜令和9年3月31日で、購入時に最大8万円相当を直接値引く方式 |
| **指定価格制度** | メーカーが小売価格を指定し、売れ残りの返品を受けて在庫リスクを負う売り方 → [儲け方と流通](02_儲け方と流通.md) |
| **流通・取引慣行ガイドライン** | 公正取引委員会が示す、流通や取引慣行に関する独占禁止法上の考え方。2026年5月に改正案が意見募集にかけられた |
| **SPA（製造小売）** | 企画・製造から販売までを小売が一貫して手がける形。ノジマの日立家電買収はこれに近いと分析される |
| **日立GLS** | 日立グローバルライフソリューションズ。家電はノジマへ移り、空調が本業として残る |
