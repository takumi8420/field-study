# 日本メーカーの現在地 ——「売却の連鎖」と、その後に残ったもの

このノートで分かること：かつて世界を席巻した日本の家電メーカーが、**なぜ次々に家電事業を手放したのか**。
売った先で事業はどうなったのか。そして残った各社が今どこで戦っているのか。

> **結論を先に**：日本の白物家電は**「負けて消えた」のではなく、「日本企業の手を離れた」**。
> 三洋→ハイアール、東芝→美的、シャープ→鴻海、日立→ノジマ。
> ブランドは今も店頭にあるが、**資本と意思決定は日本の外か、メーカー以外の手に移った**。
> 理由は単純で、**台数を稼げない会社に、この産業のコスト構造は合わなくなった**からである。

---

## 1. なぜ総合電機は家電を手放したのか

[総合電機](../01_総合電機/README.md)のノートで詳しく扱うが、家電側から見た理由を3つに絞る。

| 理由 | 中身 | 効き方 |
| --- | --- | --- |
| **① 台数の経済性で負けた** | 材料費が原価の5〜6割を占める産業では、**調達量の差が直接コスト差になる**。世界で数千万台作る中国勢と、国内中心で数百万台の日本勢では勝負にならない | 構造的・不可逆 |
| **② BtoBの方が儲かると分かった** | 送配電・鉄道・ITサービス・FAは景気変動が小さく利益率が高い。**同じ1兆円を投じるなら家電より確実** | 経営判断 |
| **③ 資本市場からの圧力** | 低収益事業を抱えるとROIC（投下資本利益率）とPBRが下がる。東証の資本効率改善要請もあり、**赤字・低採算の事業は売る方が株主に説明しやすい** | 2020年代に加速 |

```
【家電事業が「ノンコア」に分類される仕組み】

  各社は事業をこう仕分ける（ポートフォリオ経営）
   ┌────────────┬────────────────┐
   │ 成長事業       │ 投資する（DC・電池・FA・IT） │
   ├────────────┼────────────────┤
   │ 基盤事業       │ 効率化して現金を吸い上げる    │
   ├────────────┼────────────────┤
   │ 再生対象事業    │ 期限付きで改善。ダメなら次へ   │ ← パナソニックの家電
   ├────────────┼────────────────┤
   │ ノンコア事業    │ ★売却・分社・撤退           │ ← 日立・東芝の家電
   └────────────┴────────────────┘

   白物家電が引っかかる点：
    ・利益率が低い（数%）        → 全社ROICを押し下げる
    ・BtoBとの相乗効果が薄い      → 持っている理由を説明できない
    ・売れる（買い手がいる）      → 現金化して成長事業に回せる
```

→ 詳しくは [事業ポートフォリオ経営](../01_総合電機/03_事業ポートフォリオ経営.md)

## 2. 売却の連鎖 ——年表で見る

| 年 | 出来事 | 売り手 → 買い手 | その後 |
| --- | --- | --- | --- |
| 2008〜11年 | **三洋電機**をパナソニックが買収・完全子会社化（狙いは電池と太陽電池） | 三洋 → パナソニック | 家電ブランド「SANYO」は縮小 |
| 2011年 | パナソニックが**三洋の白物家電事業（日本・東南アジア）をハイアールへ売却** | パナソニック → ハイアール（中国） | ハイアールの日本進出の足場に。「AQUA」ブランドとして継続 |
| 2016年 | **東芝が白物家電子会社（東芝ライフスタイル）の株式80.1%を美的集団へ売却** | 東芝 → 美的（中国） | 「TOSHIBA」ブランドでの家電販売は継続。中国資本で立て直し |
| 2016年 | **シャープが鴻海（ホンハイ）傘下に**（台湾企業による日本大手の買収） | シャープ → 鴻海（台湾） | 白物家電は継続。プラズマクラスターを軸に高付加価値路線 |
| 2025年 | **富士通ゼネラル**をパロマ・リームHDが買収・完全子会社化（富士通は保有株を約920億円で売却、買収総額は約2,560億円と報じられる） | 富士通 → パロマ・リームHD（日本） | 2026年1月に商号を「**ゼネラル**」へ変更 |
| **2026年4月** | **日立が家電事業をノジマへ売却契約**。新会社株式80.1%を約1,100億円で譲渡（2027年3月期中に完了予定） | 日立GLS → ノジマ（家電量販店） | 空調は日立GLSに残る。従業員は約7,000人規模と報じられる |

```
【日本の白物家電ブランドは誰のものか（2026年9月時点）】

  日本資本のまま
   ├ パナソニック ───── パナソニックHD（家電は「くらし」事業）
   └ 三菱電機 ───────  三菱電機（家電は全社の一部門）

  日本資本だがメーカー以外の手に
   ├ 日立（家電） ───── ノジマ（家電量販店）※2027年3月期中に完了予定
   └ ゼネラル（旧富士通ゼネラル）─ パロマ・リームHD（給湯器大手）

  外国資本
   ├ AQUA（旧三洋） ─── ハイアール（中国）
   ├ TOSHIBA（家電） ── 美的／Midea（中国）
   └ SHARP ─────── 鴻海／Foxconn（台湾）

  → 「日本ブランドの家電」を買っても、資本はすでに日本の外、ということが普通に起きる
```

> **重要な含意**：売却後にむしろ伸びた事業がある。東芝の白物家電は美的の傘下で立て直された。
> AQUAはハイアールの日本展開の中核になった。
> **「日本企業が下手だっただけではないか」**という指摘は、この業界では避けられない。

## 3. 中国・韓国勢の攻め方

中国勢は「安いから勝った」だけではない。**勝ち方の型**がある。

| 攻め方 | 中身 | 具体例 |
| --- | --- | --- |
| **ブランドごと買う** | 日本人が知っている名前を手に入れ、信用を買う | ハイアール→AQUA（旧三洋）、美的→東芝ライフスタイル |
| **世界規模で1つのベースモデル** | グループ共通の土台を作り、各国向けにマイナーチェンジ。**開発費を台数で割る** | 美的・ハイアールの標準化 |
| **下から入って上へ登る** | 単身向けの小型冷蔵庫・洗濯機で足場を作り、大型・高機能へ上がる | ハイアールの日本での大型白物強化（2024年12月発表） |
| **量販店の棚を取りにいく** | 売り場を押さえ、PB（量販店の自社ブランド）も受託する | 中国・ODM各社 |
| **テレビで先に崩して家電へ** | 価格競争力を証明してから白物に来る | ハイセンス（東芝映像を取得）→2025年に大型白物へ本格参入 |

報道ベースの数字（**推計・各社発表を含むので断定はできない**）：

- 2024年、**中国ブランドが日本の薄型テレビ市場で初めて過半**を占めたとされる
- 2024年の日本の冷蔵庫市場で**中国ブランドのシェアが3割近く**に迫ったとされる
- 2026年6月、**ハイアールが日本の洗濯機市場でパナソニックを抜き2位に浮上したと自社発表**

```
【中国勢の「下から上へ」の登り方】

  価格帯
   高 │                                  ◎ ← 日本勢が逃げ込んだ場所
      │                            ●     （ここへ登ってくる）
   中 │                    ●  ●
      │            ●  ●              ← 中価格帯は既に激戦
   低 │    ●  ●                       ← まずここを取る（単身・セカンド需要）
      └────────────────────────▶ 時間

  日本勢の対応：
   （A）さらに上へ逃げる  → 台数が減り、規模の利益をさらに失う
   （B）同じ土俵で戦う    → コストで勝てない
   （C）事業ごと手放す    → 実際に選ばれたのがこれ
```

韓国勢（サムスン・LG）は世界では強いが、**日本の白物家電市場ではシェアが小さい**。
日本の住宅事情（設置スペース・電源）と流通慣行が独特で、
**日本市場は「世界標準モデルが通用しにくいガラパゴス」**であることが、むしろ日本勢を守ってきた面がある。

## 4. 残った日本勢はどこで戦っているか（2026年9月時点）

| 企業 | 家電事業の位置づけ | 戦い方 | 注意点 |
| --- | --- | --- | --- |
| **パナソニック** | 2026年4月1日、家電を主体とする新「パナソニック株式会社」が発足。グループ内では**再建事業**の扱い | フルラインで高付加価値（ナノイー、自動投入、ラムダッシュ等）＋**指定価格制度の先駆者** | 家電を含むスマートライフは2026年3月期に**営業▲373億円**と唯一の赤字セグメント |
| **三菱電機** | 全社（売上約5.9兆円）の一部門。**家電は主力ではない** | 冷蔵庫・エアコン（霧ヶ峰）に絞った高価格帯。2026年1月に**指定価格制度を導入** | FA・昇降機・インフラが本業。家電は無理に伸ばさない |
| **シャープ（鴻海傘下）** | 家電は継続事業 | プラズマクラスター、ヘルシオ等の独自機能。**指定価格は導入予定なしと報道** | 鴻海の経営方針に左右される |
| **日立（→ノジマ）** | 2027年3月期中にノジマ傘下へ。空調は日立GLSに残る | ビッグドラム、真空チルド等のブランド力 | **量販店の傘下に入るメーカー**という前例のない形 |
| **東芝ブランド（美的傘下）** | 中国資本で運営 | 大容量・コスパ路線 | 資本は中国 |
| **アイリスオーヤマ** | 家電は主力事業の一つ | **なるほど家電**＝機能を絞って安く。企画は自社、製造は委託中心 | メーカーというより**生活用品の企画会社**に近い |
| **バルミューダ、Anker、ティファール等** | ニッチ・新興 | デザイン・体験・特定機能に絞って高単価 | 台数は小さいが利益率は高い |

> **見落とされがちな点**：三菱電機にとって家電は「本業ではない一部門」である。
> 同じ「日本の家電メーカー」と括っても、**会社の中での重みがまったく違う**。
> パナソニックだけが「家電が看板」であり、だからこそ手放せず、だからこそ苦しい。

## 5. OEM／ODMという生き残り方

自社で全部作らない選択肢が一般化している。用語を押さえる。

| 用語 | 意味 | 家電での使われ方 |
| --- | --- | --- |
| **OEM** | 相手先ブランドでの製造。**設計は発注側**、製造だけ請ける | 量販店PBの製造受託 |
| **ODM** | **設計から製造まで**受託先が行い、発注側はブランドを載せる | 中国・台湾メーカーが日本向け機種を丸ごと設計・製造 |
| **EMS** | 電子機器の受託製造専業（鴻海など）。大規模・多品種 | シャープの親会社が鴻海であることの意味 |
| **PB（プライベートブランド）** | 小売の自社ブランド商品 | ヤマダセレクト、ニトリの家電など |

```
【日本メーカーの生産の使い分け】

  高価格帯（日本向け・差別化機種）
     └─▶ 国内自社工場 ／ 自社の海外工場（中国・タイ・ベトナム）
          理由：ノウハウが機構部分（乾燥・圧縮・断熱）にあり外に出せない

  中〜低価格帯（値段で選ばれる機種）
     └─▶ ★ODM調達（中国・台湾メーカーが設計から）
          理由：自社で作ると固定費が乗って勝てない

  小物家電（調理・美容・掃除）
     └─▶ ほぼODM。ブランドと企画だけが自社

  結果：「日本メーカーの家電」でも、中身は同じODM工場、ということが起きる
        → 差別化の源泉が機能から【ブランド・売り方・保証】へ移る
        → だから指定価格制度が効いてくる → 02_儲け方と流通.md
```

## 6. 日本勢に残っている強み

悲観一色で終えるのは正確ではない。構造的に残っている強みを挙げる。

1. **設置・工事・修理のネットワーク**。エアコン工事、大型冷蔵庫の搬入、
   十数年後の修理。これは現地に人がいないと成立せず、**新規参入が最も嫌う部分**
2. **日本の住環境に合わせた設計**。狭い設置スペース、4.5畳用エアコン、
   軟水前提でない洗濯、日本の食材に合わせた冷蔵室の設計など
3. **省エネ性能**。電気代が高い日本では省エネが実利になり、
   トップランナー制度の規制強化は**技術力のある側に有利に働く**（→[直近トピック](04_直近トピック_2026.md)）
4. **BtoB・部品への横展開**。冷凍・圧縮・モーター・熱交換の技術は
   [空調・冷凍機](../../02_自動車・機械/16_空調・冷凍機/README.md)や
   [モーター](../../02_自動車・機械/15_モーター/README.md)につながる。
   ダイキンが世界で勝っているのは、この延長線上にある

> **押さえるべき対比**：**家庭用エアコンでは苦戦しても、業務用空調では日本勢が世界で強い**。
> 同じ技術でも、BtoCは台数とブランドの勝負、BtoBは据付・保守・システムの勝負になるため。
> 日本の電機メーカーがBtoBへ寄っていったのは、この違いをよく説明している。

---

## 7. まとめ

1. 日本の白物家電は**技術で負けたというより、台数と資本の論理で手放された**
2. 売却の連鎖：三洋→ハイアール、東芝→美的、シャープ→鴻海、富士通ゼネラル→パロマ、**日立→ノジマ**
3. 店頭の日本ブランドの多くは、**すでに外国資本または非メーカーの傘下**
4. 残った日本勢は高価格帯と省エネ・設置網で戦うが、**台数が減るほど規模の利益を失う**という
   逃げ切れない矛盾を抱える
5. 生産はODM活用が常態化し、**差別化の軸は機能からブランドと売り方へ移った**

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **ノンコア事業** | 会社の中核から外れた事業。低採算かつ他事業との相乗効果が薄いものが該当し、売却・撤退の対象になる |
| **ROIC** | 投下資本利益率。投じた資本に対してどれだけ利益を出したか。低採算事業を抱えると下がる |
| **美的集団（Midea）** | 中国・広東省の家電大手。2016年に東芝の白物家電子会社を買収。グループ売上は2025年に約4,585億元と報じられる |
| **ハイアール（Haier）** | 中国・青島の家電大手。冷蔵庫・洗濯機で世界首位級。2011年にパナソニックから三洋の白物家電事業を取得し「AQUA」を展開 |
| **ハイセンス（Hisense）** | 中国の家電大手。日本ではテレビ（東芝映像を取得）から入り、2025年に大型白物家電へ本格参入 |
| **鴻海（ホンハイ／Foxconn）** | 台湾のEMS最大手。2016年にシャープを買収 |
| **OEM／ODM／EMS** | OEM＝相手先ブランドでの製造（設計は発注側）。ODM＝設計から製造まで受託。EMS＝電子機器の受託製造専業 |
| **日立GLS** | 日立グローバルライフソリューションズ。日立の家電・空調を担う子会社。家電はノジマへ、空調は残る |
| **アルチェリク（Arçelik）** | トルコの家電大手。日立と海外家電の合弁を組んでいたが、日立が全株を取得して新会社へ統合すると発表（2026年4月） |
| **トップランナー制度** | 最も省エネ性能が高い製品を基準に目標値を定める省エネ規制。出荷製品の加重平均で達成を求める |
