製品と市場の構造

電機・電子部品白物家電
あこのページの単語集用語に触れると意味を確認できます9語
白物家電／黒物家電JEMA（日本電機工業会）国内出荷金額普及率／平均使用年数買い替え需要家電エコポイント二極化PB（プライベートブランド）エアコン2027年問題

このノートで分かること：白物家電がどんな製品の集まりで、日本国内でどれくらいの大きさの市場なのか。
そして「ほぼ全世帯が既に持っている製品を、なぜ毎年2.6兆円も売れるのか」という一番の疑問に答える。

結論を先に：白物家電の国内市場は、新しく買う人がほとんどいない「買い替え100%市場」である。
だから台数は人口と世帯数で天井が決まり、金額を伸ばす方法は「単価を上げる」しかない。
加えて需要の山谷が気温と省エネ規制で動く。この2点が、以降のすべての話の前提になる。

1. 「白物家電」とは何を指すか

もともとは本体が白い塗装だった生活必需品の電気製品（冷蔵庫・洗濯機）を指す業界の俗語。
テレビ・オーディオなど「娯楽のための機器」を黒物家電と呼んで区別したことに由来する。
現在は色ではなく用途で分ける言葉として使われ、統計上は次のように整理される。

区分 何が入るか 買う動機 本ノート群での扱い
大物白物（重量家電）冷蔵庫、洗濯機（縦型・ドラム式）、ルームエアコン壊れたら生活が止まる。必需品中心。市場金額の大半
調理家電電子レンジ、炊飯器、IHクッキングヒーター、食器洗い乾燥機必需品＋時短中心
小物家電（美容・健康含む）ドライヤー、電気シェーバー、空気清浄機、掃除機買い増しあり。趣味性が強い補足的に扱う
黒物家電（AV）テレビ、レコーダー、オーディオ娯楽。買わなくても困らない→ AV機器
住宅設備側ビルトイン食洗機、給湯器、業務用エアコン住宅・建物とセットで売れる→ 空調・冷凍機

境界で注意すべきこと：

  • エアコンは半分だけ白物。家庭用のルームエアコンは白物家電だが、ビル用マルチ・業務用は
    「空調機器」としてダイキン・三菱電機などのBtoB空調事業に属する。統計も分かれている
  • 照明は独立した業界として扱われることが多い → 照明
  • 日本電機工業会（JEMA）の統計名は「民生用電気機器」。白物家電＝この統計、と覚えておけばよい

2. 市場規模：国内は約2.6兆円、しかも今は「過去最高圏」

日本電機工業会（JEMA）の民生用電気機器 国内出荷金額（工場出荷ベース＝メーカーが卸した額）。

期間 国内出荷金額 前年比 備考
1991年 上期（1〜6月）1兆3,671億円—バブル期。長く上期の最高記録だった
2024年（暦年）約2兆5,800億円（2025年実績と伸び率からの逆算・推計）—2年連続プラスの起点
2025年（暦年）2兆6,418億円+2.4%1991年に次ぐ過去2番目（JEMA、電波新聞報道）
2025年度（25/4〜26/3）2兆6,813億円+3.8%2年連続プラス
2026年1〜6月1兆4,350億円大幅増1986年以降の統計で上期として過去最高（JEMA、2026年7月発表）

意外に思えるところ：「家電は斜陽産業」と言われながら、金額ベースの国内市場は史上最高圏にある。
台数はほとんど増えていない。伸びているのは単価であり、その単価を押し上げているのが
エアコンの高機能化と、後述する省エネ規制・指定価格制度である。

一方、世界市場では日本勢の存在感は小さい。参考として（各社IR、2025年12月期）：

企業 グループ売上高 位置づけ
美的集団（Midea、中国）約4,585億元（2025年、過去最高と報道。1元≒21円換算で約9.6兆円規模）世界最大級。東芝の白物を傘下に持つ
ハイアールスマートホーム（中国）約2,860億元（2024年12月期）冷蔵庫・洗濯機で世界首位級
パナソニックHD「くらし」領域グループ全体で約8.0兆円のうちの一部門家電は赤字セグメント（2026年3月期）

日本メーカーの家電事業は、1社あたり数千億円規模。中国大手のグループ売上とは1桁違う。
この規模差がコスト競争力の差に直結する → 日本メーカーの現在地

3. なぜ「買い替え100%市場」なのか

普及率がほぼ天井に達しているため、新規購入（1台目）の需要がほとんど存在しない。

内閣府「消費動向調査」（2026年3月末、二人以上の世帯）では、

  • ルームエアコン普及率 92.2%、平均使用年数 13.4年
  • 電気冷蔵庫 平均使用年数 13.1年、買い替え理由の最多は「故障」
  • 冷蔵庫・洗濯機はほぼ全世帯が保有

つまり市場の姿はこうなる。

【白物家電の需要の正体】

  (A) 新規需要  ── 新しい世帯ができる（進学・就職・結婚・単身化）
        ↑ 世帯数の増加分だけ。年間の市場のごく一部
        │
  (B) 買い替え需要 ── 壊れた／古くて電気代が高い／機能が欲しい  ★ 需要の大半
        │           平均13年前後で1回めぐってくる
        │
  (C) 増設需要  ── 2台目のエアコン、サブ冷凍庫など
        └ 猛暑・在宅勤務などイベントで変動

   ┌────────────────────────────────────┐
   │ 台数 ＝ ほぼ一定（世帯数と寿命で決まる）             │
   │ 金額 ＝ 台数 × 単価 → 伸ばせるのは【単価】のみ      │
   └────────────────────────────────────┘

ここが業界のすべての行動を説明する。台数が伸びない以上、メーカーの生きる道は
①単価を上げる（高機能化）②値崩れを防ぐ（→儲け方と流通）
③海外で売る（→中国勢と正面衝突）の3つしかない。

13年周期がもたらす「買い替えの波」

過去に大きく売れた年の13年後に、買い替えの山が来る。
2009〜11年の家電エコポイント制度（省エネ家電購入にポイントを付けた景気対策）で
エアコン・冷蔵庫・テレビが大量に売れており、2022〜24年頃にその買い替えが来たと見られる。
制度が需要を先食いすると、数年後に谷、十数年後に山という長い波ができる。

4. 製品ごとの性格の違い

同じ「白物家電」でも、儲け方・競争の仕方はまったく違う。

製品 需要のドライバー 平均単価の傾向 価格競争の激しさ 参入のしやすさ
ルームエアコン夏の気温、省エネ規制、電気代高機能化で上昇中（工事が必要で差別化しやすい）低い（工事網・冷媒技術が壁）
冷蔵庫故障、世帯人数の変化、まとめ買い志向大容量化で上昇中〜高中（断熱・コンプレッサーの技術）
洗濯機故障、共働きの時短需要（ドラム式・乾燥）ドラム式化で大幅上昇中〜高中
調理家電（レンジ・炊飯器）買い替え、生活提案二極化高高い（OEM調達で参入容易）
掃除機・小物買い増し、トレンド二極化非常に高非常に高い（新興ブランドの主戦場）

設置工事が必要かどうかが、実は競争構造を分ける最大の線になる。
エアコンは取り付け工事、冷蔵庫・洗濯機は搬入・設置・古い機器の引き取りが要る。
この工事・配送網を持つこと自体が参入障壁であり、量販店の力の源泉でもある。
→ 家電量販

5. 二極化：高価格帯と低価格帯に割れ、真ん中が消えた

【価格帯の分布は「ふたこぶ」になっている】

  台数
   │        ●                                ●
   │       ●●●                              ●●●
   │      ●●●●●                            ●●●●●
   │     ●●●●●●●        （かつての山）        ●●●●●●●
   │   ────────────  ░░░░░░░░░░░  ────────────
   └────────────────────────────────────────▶ 価格
      2〜6万円            10万円前後          20〜35万円
      低価格帯            中価格帯（縮小）      高価格帯

   低価格帯：アイリスオーヤマ、ハイアール、ハイセンス、
             量販店PB（ヤマダセレクト、アイリスOEM 等）、ニトリ
   高価格帯：パナソニック、日立、三菱電機、シャープ、東芝（美的傘下）、
             バルミューダ・Anker等の新興ブランド（デザイン・体験で高単価）

なぜ真ん中が消えたのか。

  1. 低価格帯を中国勢と量販店PBが押さえた。世界で数千万台を作る中国大手が、
    ベースモデルを小改良して投入するためコストで勝てない
  2. 日本勢は中価格帯で戦うと赤字になるので、意図的に高価格帯へ逃げた
    （＝「高付加価値路線」。乾燥機能・自動投入・ナノイー・鮮度保持など）
  3. 消費者側も「安く済ませる家電」と「こだわる家電」を分けて買うようになった。
    洗濯機はドラム式に30万円出すが、電子レンジは1万円台で済ませる、という買い方

注意：二極化は「日本勢が高価格帯で勝っている」という意味ではない。
高価格帯に逃げた結果、台数シェアを落として規模の利益を失ったという側面が強い。

6. 需要が気温と規制で動く

白物家電は、当年の天候と制度変更でその年の売上が2割動くという珍しい製造業である。

変動要因 効き方 2026年の実例
猛暑6〜8月のエアコン出荷を直撃。猛暑年は2割増もある2026年1〜6月のルームエアコン出荷は652.7万台（前年同期比+19.4%）、6,102億円（+21.7%）
冷夏・長梅雨逆に在庫が積み上がり、翌年前半まで響く—
省エネ規制基準強化の前に駆け込み、後に反動減エアコン2027年問題（2027年4月に省エネ基準強化）で2026年に駆け込み
補助金自治体の省エネ家電補助が上乗せ需要を作る東京ゼロエミポイント（最大8万円相当の値引き、2027年3月末まで）
消費増税・災害駆け込みと反動—
【1年のリズム（メーカー側の見え方）】

  1〜3月  新製品発表・投入期（冷蔵庫・洗濯機）／決算期末で押し込みも
  4〜6月  ★エアコンの仕込み。量販店に在庫を積む（気温予報が命）
  7〜9月  ★猛暑ならフル生産・フル出荷。冷夏なら在庫の山
 10〜12月 年末商戦。調理家電・美容家電が動く
  1〜3月  進学・就職・転勤の新生活需要（単身向けの安い機種が売れる）

  → 「在庫を誰が持つか」がメーカーと量販店の最大の交渉点になる
     ここから【指定価格制度】の話につながる → 02_儲け方と流通.md

8. まとめ：この業界を見るときの3つの物差し

  1. 台数は増えない。金額は単価で決まる。 → 高付加価値化が続く限り市場金額は伸びうる
  2. その年の売上は天候と規制で決まる。 → 単年の好不調を実力と読み違えない
  3. 在庫リスクを誰が持つかが利益を決める。 → 次のノートの主題

用語メモ

用語 意味
