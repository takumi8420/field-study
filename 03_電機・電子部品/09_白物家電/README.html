最初に押さえること
白物家電は「ほぼ全世帯が既に持っている製品」を売る産業である。
台数は世帯数と製品寿命（10〜14年）で天井が決まり、伸ばせるのは単価だけ。
その結果、業界の行動はすべて「値崩れをどう止めるか」に収束する。
2020年代に広がった指定価格制度（メーカーが小売価格を決め、売れ残りは引き取る売り方）は、
その最も分かりやすい答えである。
一方で日本メーカーの多くは家電事業そのものを手放した。
三洋→ハイアール、東芝→美的、シャープ→鴻海、そして2026年、日立→ノジマ。
店頭の日本ブランドの多くは、もう日本のメーカーのものではない。

「どんな市場か → どう儲けるか → 誰が残っているか → 今何が起きているか」の順に読む。

1. 業界の定義・範囲

白物家電＝冷蔵庫・洗濯機・エアコン・調理家電など、生活に必要な家庭用電気製品の総称。
もとは筐体が白かったことに由来する俗称で、娯楽向けの黒物家電（テレビ・オーディオ）と対になる。
統計上は日本電機工業会（JEMA）の「民生用電気機器」がこれに当たる。

境界の引き方：

  • 家庭用エアコンは白物家電だが、業務用・ビル用空調は別業界
    → 空調・冷凍機
  • テレビ・レコーダーは黒物家電として別扱い → AV機器
  • 照明は独立した業界として扱われることが多い → 照明
  • ビルトイン食洗機・給湯器など住宅設備と一体のものは住宅側の商流に乗る

4. 主要プレイヤーとシェア

まず「日本ブランドの家電は誰のものか」を押さえる。ここを知らないと業界の話が噛み合わない。

【店頭に並ぶ日本ブランドの資本（2026年9月時点）】

  日本のメーカー資本のまま
   ├ パナソニック ──── パナソニックHD（家電は「くらし」事業。唯一の赤字セグメント）
   └ 三菱電機 ─────  三菱電機（家電は全社の一部門。本業はFA・インフラ）

  日本資本だが、メーカー以外の手に
   ├ 日立（家電） ──── ノジマ（家電量販店）※2027年3月期中に完了予定
   └ ゼネラル（旧富士通ゼネラル）── パロマ・リームHD（給湯器大手、2025年）

  外国資本
   ├ AQUA（旧三洋） ── ハイアール（中国、2011年）
   ├ TOSHIBA（家電） ─ 美的／Midea（中国、2016年）
   └ SHARP ────── 鴻海／Foxconn（台湾、2016年）

  → 「日本ブランドの家電」を買っても、資本と意思決定は日本のメーカーにない
     ことの方がむしろ多い。これが白物家電を見るときの出発点になる

シェアの確定的な統計は乏しく、以下は各社IR・報道ベースの立ち位置整理（2026年9月時点）。

企業 立ち位置 特徴
パナソニック日本で唯一「家電が看板」の会社フルライン・高付加価値。指定価格制度の先駆者（2020年度〜）。2026年4月に家電主体の新会社が発足。ただし家電を含むセグメントは赤字
三菱電機全社の一部門。家電は主力ではない冷蔵庫・霧ヶ峰に集中。2026年1月に指定価格制度を導入
シャープ（鴻海傘下）台湾資本プラズマクラスター等の独自機能。指定価格は導入予定なしと報じられる
日立（→ノジマ）2027年3月期中に量販店ノジマ傘下へビッグドラム、真空チルド。空調は日立GLSに残る
東芝ブランド（美的傘下）中国資本2016年に美的が80.1%を取得。大容量・コスパ路線
ハイアール／AQUA中国。日本での攻勢が最も強い旧三洋の白物事業が源流。2026年に洗濯機で国内2位に浮上と自社発表
ハイセンス中国。テレビから白物へ2025年に大型白物へ本格参入
アイリスオーヤマ生活用品の企画会社に近い機能を絞った「なるほど家電」。製造は委託中心
量販店PBヤマダセレクト等低価格帯。製造はODM
バルミューダ、Anker等ニッチ・新興デザインと体験で高単価。台数は小さいが利益率は高い
（参考）世界大手美的、ハイアール、ワールプール、BSH、LG、サムスン美的の売上は2025年に約4,585億元と報じられ、日本勢の家電事業とは1桁違う規模

5. 収益モデル・コスト構造

  • 原価率が高い。材料費・部品費が原価の5〜6割を占め、鋼板・樹脂・銅・半導体の市況と為替で動く
  • 営業利益率は数%。電子部品（10%前後）より薄く、値引き1回の重みが極端に大きい
  • 固定費は工場と研究開発。台数が落ちると1台あたりの負担が跳ね上がる
  • 販促金（量販店への販売協力費）が実質的な値引き原資として利益を削ってきた
  • 売った後の回収：修理・部品供給はメーカー、延長保証は量販店の収益。
    本体の粗利が薄いほど、量販店は保証・工事・ポイントに依存する

→ 詳細と1台の分解は 儲け方と流通

6. 競争要因（KSF）と参入障壁

要因 効き方 誰に有利か
台数（調達規模）材料費が原価の過半なので、調達量の差が直接コスト差になる中国大手
設置・工事・修理網エアコン工事、大型品の搬入、十数年後の修理。現地に人がいないと成立しない日本勢・量販店
省エネ技術電気代が高い日本では実利。規制強化は技術力のある側に有利日本勢
日本の住環境への適合狭い設置スペース、小容量エアコン、日本の生活様式日本勢（ただし中国勢も対応を進める）
ブランドと売り方ODM活用で中身が似てくるほど、ブランドと価格政策が効く指定価格を敷ける側
売り場の確保量販店の棚と配送網量販店（＝ノジマの日立買収の意味）

参入障壁は製品によって大きく違う。掃除機・調理家電はODM調達で誰でも参入できるが、
エアコンは工事網と冷媒技術、冷蔵庫は断熱・コンプレッサーの技術で壁がある。

7. 規制・法制度

制度 中身 効き方
省エネ法／トップランナー制度最も省エネな製品を基準に目標値を設定。出荷製品の加重平均での達成を求める2027年4月にエアコンの基準強化。安価なモデルが減り値上がりするとされる（2027年問題）
フロン排出抑制法（冷媒規制）温室効果の低い冷媒への移行2027年問題のもう一つの要素
家電リサイクル法エアコン・テレビ・冷蔵庫（冷凍庫）・洗濯機（衣類乾燥機）の4品目が対象。廃棄時に消費者がリサイクル料金を負担廃棄コストが買い替え判断とリユース市場に影響
独占禁止法（再販売価格の拘束）メーカーが小売価格を拘束することは原則違法。ただしメーカーが在庫・返品・滅失毀損のリスクを負う場合は該当しないとされる指定価格制度が成立する根拠。2026年5月に公取委が流通・取引慣行ガイドラインの改正案を公表
景品表示法／家電公取協のルール二重価格表示などの規制「定価の半額」表示が使えない理由の一つ
自治体の省エネ家電補助東京ゼロエミポイント（2027年3月末まで、最大8万円相当の値引き）など単年の需要を押し上げる

9. 用語メモ

用語は各ノート末尾の「用語メモ」にまとめている。最小限の押さえどころは次の3つ。

用語 意味
指定価格制度メーカーが小売価格を指定し、売れ残りの返品を受けて在庫リスクを負う売り方。値引きはできないが値崩れも起きない。在庫リスクを負うため独禁法の再販売価格拘束に当たらないとされる → ②
トップランナー制度最も省エネ性能の高い製品を基準に目標値を定める規制。出荷製品の加重平均で達成を求める → ④
ODM設計から製造まで受託先が行い、発注側はブランドを載せる方式。低〜中価格帯の日本ブランド家電の多くがこれ → ③
