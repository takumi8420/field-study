# 計測・分析機器

- 大分類: 電機・電子部品
- 状態: done
- 更新日: 2026-09-20

**「測る機械」を売る産業**。ただし一枚岩ではなく、**中身がまったく違う3つの商売の寄せ集め**である。
オシロスコープを電機メーカーの技術者に売る商売と、質量分析計を製薬会社の研究所に売る商売と、
流量計をプラントに納める商売は、顧客も売り方も儲け方も別物だ。

そして共通する急所が一つある。**装置本体を売った時点では、まだ本当の利益は出ていない**。
カラム・試薬・消耗品・校正・保守という後追いの売上こそが、この業界の利益の源泉である。

## 1. 業界の定義・範囲

物理量・化学組成・電気信号などを**定量的に測る機器**を設計・製造・販売し、
据付・校正・保守・消耗品供給まで行う産業。

| 含む | 含まない（隣接業界） |
| --- | --- |
| 電気計測器（オシロスコープ、スペクトラムアナライザ、信号発生器、テスタ、通信計測器） | 半導体チップを量産ラインで選別するテスタ（装置産業側）→ [半導体製造装置](../03_半導体製造装置/README.md) |
| 分析機器（クロマトグラフ、質量分析計、分光光度計、X線分析、電子顕微鏡、熱分析） | 患者検体を測る体外診断（IVD）装置と試薬 → [臨床検査・検査受託](../../09_医薬・医療・ヘルスケア/06_臨床検査・検査受託/README.md) |
| 産業用計測（流量計、圧力計、温度計、液面計、ガス分析計、環境計測） | それらを束ねて工場を動かす制御システム（DCS/PLC）→ [FA・制御機器](../14_FA・制御機器/README.md) |
| 上記の消耗品（カラム、標準試薬、電極、プローブ）と校正・保守サービス | 試薬そのものを主力に売る化学メーカー → [総合化学](../../10_素材・化学/01_総合化学/README.md) |

**境界の引き方のコツ**：
「測って**数値を出す**」のが計測・分析機器、「測った値で**機械を動かす**」のがFA・制御機器、
「測った値で**人の診断を下す**」のが体外診断。同じセンサ技術でも売り先と法規制が変わる。
ただし現実には横河電機（計測＋制御）、堀場（分析＋半導体用流量制御）のように
またがる企業が多く、**企業単位では切れない**のがこの業界の特徴である。

## 2. 市場規模と成長性

| 指標 | 数値 | 出典・時点 |
| --- | --- | --- |
| 世界の分析機器市場 | **約606〜631億ドル**（調査会社により幅あり） | 複数調査会社の推計、2026年見通し |
| 同 成長率 | 年平均 **5〜6%** 程度 | 調査会社推計、2026〜2033年 |
| 日本の分析機器市場 | **約2,162億円** | 調査会社推計（時点は最新版で要確認） |
| 世界のオシロスコープ市場 | **約40.3億ドル**、2031年に58.7億ドル | 調査会社推計、2026年 |
| ライフサイエンス機器の上位5社合計シェア | **約30〜35%** | 調査会社推計（Thermo/Agilent/Danaher/Waters/島津） |

- 成長は**GDP成長よりやや速い程度**。半導体製造装置のような2〜3割の変動は起きにくい
- 理由は明快で、**研究予算・規制対応・品質管理という「止められない支出」が需要の土台**だから
- ただし部分的には激しく振れる。半導体向け（堀場の流量計、電子顕微鏡）と
  通信計測器（アンリツ）は投資サイクルに直撃される
- 日本の一次統計は **JAIMA（日本分析機器工業会）の生産・輸出統計**と
  **JEMIMA（日本電気計測器工業会）の統計**が基本。両者は母集団が違うので合算しない

```
 検出器・センサ素子                                 ┌─ 直販（高額機）──▶ 製薬・食品・化学の研究所

 精密機構部品               島津 / 堀場 / JEOL      │  （アズワン等）      自治体・環境分析会社
 ソフトウェア               キーエンス / アンリツ   └─ 代理店・EC ────▶ 電機・自動車の開発部門
        │                   横河 / Keysight                                  プラント・工場
        │                        │                                               │
        │                        └──── 消耗品・校正・保守（10〜15年続く）────────┘
        └─ 検出器など中核部品は内製 or 専業に依存。ここが性能差の源泉
```

**付加価値が集まる場所**は3か所。
① 検出器・イオン源など**測定の核**（内製できるかで性能と原価が決まる）、
② **アプリケーション（分析手法のレシピ）とソフト**、
③ **消耗品と保守の供給権**。
金属加工や筐体組立は薄く、外注しても差がつかない。

## 5. 収益モデル・コスト構造

```
 売上 ＝ ① 装置本体            ＋ ② 消耗品・試薬・カラム ＋ ③ 保守・校正・受託分析
         粗利 30〜50%              粗利 60〜80%              粗利 50〜70%
         波がある／値引き圧力あり   毎月買い続ける            契約で固定的に入る
         ＝「ひげ剃りの本体」      ＝「替刃」                ＝「床屋の定期券」
```

- **ジレットモデル**（本体を安く売り、替刃で稼ぐ）がこの業界の基本。
  液体クロマトグラフのカラムは消耗品で、数か月ごとに交換が要る。
  標準試薬も毎回使う。**装置は一度きり、消耗品は装置の寿命10〜15年ぶん続く**
- 営業利益率の目安は**10〜20%**（島津13.1%、堀場15.9%、アンリツ12.6%、横河13.6%／各社直近期）。
  例外がキーエンスの51.0%で、これは工場を持たず代理店も通さない構造による
- コストの主役は**部品・外注費と研究開発費**。R&D比率は売上の7〜10%が相場で、
  「測る精度」の競争が止まらないため削れない
- **売上計上は据付・立会検収の後**。高額機は受注から売上まで数か月〜1年かかる

詳しくは [② 儲け方とジレットモデル](02_儲け方とジレットモデル.md)。

## 6. 競争要因（KSF）と参入障壁

1. **アプリケーション（分析手法）の蓄積**。機械が同じでも「この試料をこう測る」ノウハウが差になる。
   公定法（法令で定められた測定手順）に自社機が書き込まれれば実質的な指名買いになる
2. **消耗品の囲い込み**。純正カラム・純正試薬でないと保証しない、という設計が効く
3. **校正・保守網**。装置が止まると顧客の研究・出荷が止まる。全国・全世界のサービス拠点が要る
4. **論文・規制文書での実績**。研究者は「先行論文と同じ装置」を選ぶため、**採用が採用を呼ぶ**
5. **検出器など中核部品の内製**。ここを外部依存すると性能でも原価でも勝てない
6. **バリデーション対応**。製薬向けはFDA 21 CFR Part 11等への適合が必須で、
   ソフトの監査証跡まで作り込む必要がある

参入障壁は「技術」よりも**実績と承認の積み上げ時間**にある。
性能の良い新型を出しても、公定法と論文に載るまで数年かかる。

## 7. 規制・法制度

- **規制が需要を作る産業**である。測定が義務化されると、その瞬間に機器需要が立つ
- **PFAS（有機フッ素化合物）**：PFOS・PFOAの合計50 ng/L以下が水道水質基準となり、
  2026年4月施行。**3か月に1度の定期検査が義務化**され、LC-MS/MS需要が立ち上がった
- **食品衛生法／ポジティブリスト制度**：残留農薬の一斉分析にGC-MS・LC-MSが要る
- **薬機法・GMP／FDA 21 CFR Part 11**：製薬の品質管理は装置とソフトの適格性確認（IQ/OQ/PQ）が必須
- **計量法**：取引・証明に使う計量器は検定が要る。校正のトレーサビリティ（国家標準まで辿れること）を
  担保する仕組みが産業の前提になっている
- **輸出管理**：高性能の質量分析計・電子顕微鏡は外為法のリスト規制（キャッチオール含む）対象になりうる
- **公的研究費**：科研費・NIH予算などの増減が、大学・公的研究機関向け需要をほぼそのまま左右する

## 9. 用語メモ

- **クロマトグラフ（GC／LC）**：混合物を成分ごとに時間差で分離する装置。ガス／液体で方式が違う
- **質量分析計（MS）**：分子を電荷を持つ粒子にして質量で識別する装置。GC/LCと繋いで使うのが定番
- **カラム**：クロマトグラフの分離を担う細い管。**消耗品**であり、この業界の「替刃」の代表
- **マスフローコントローラ（MFC）**：ガスの流量を精密に制御する機器。半導体製造装置に組み込まれる
- **インストールドベース**：顧客先で稼働中の自社装置の総数。消耗品・保守収入の母数になる
- **トレーサビリティ**：測定値が国家標準まで切れ目なく辿れること。校正ビジネスの根拠
- **公定法**：法令・告示で定められた測定手順。ここに載る装置構成は事実上の指名買いになる
- **IQ/OQ/PQ**：据付時・稼働時・性能の各適格性確認。製薬向けで必須の手続き
- 各ノート末尾の用語メモも参照
