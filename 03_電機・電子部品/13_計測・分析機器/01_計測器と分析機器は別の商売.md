# 計測器と分析機器は別の商売

このノートで分かること：「計測・分析機器業界」と一括りにされる集団が、
実際には**顧客も価格帯も売り方も違う3つの商売**に分かれていること。
そして、その境目がどこにあるのかを自分で判断できるようになる。

> ポイント：オシロスコープを買う人と、質量分析計を買う人は、社内で会ったことがない。
> 同じ「測る機械」でも、購買部門も予算の出どころも別である。

## 1. まず3つに割る

| 類型 | 何を測るか | 代表的な機器 | 主な顧客 | 1台の価格帯 |
| --- | --- | --- | --- | --- |
| **電気計測器**（テスト＆メジャメント） | 電気信号・電波 | オシロスコープ、スペクトラムアナライザ、信号発生器、ネットワークアナライザ、テスタ | 電機・半導体・通信・自動車の**開発部門** | 数万円〜数千万円 |
| **分析機器**（サイエンティフィック） | 物質の成分・構造 | ガスクロマトグラフ（GC）、液体クロマトグラフ（LC）、質量分析計（MS）、分光光度計、X線分析、電子顕微鏡、NMR | 製薬・食品・化学の**研究所と品質管理部門**、大学、公的機関、分析受託会社 | 数百万円〜数億円 |
| **産業用計測**（プロセス計測） | プラント内の物理量 | 流量計、圧力計、温度計、液面計、ガス分析計、pH計 | 化学・石油・電力・水道の**プラント設備部門** | 数万円〜数百万円 |

この3つは、**同じ会社の中に同居していることはあっても、同じ営業が売ることはまずない**。

```
              測る対象で分ける                        買う人で分ける
 ┌──────────────────────────────┐        ┌──────────────────────────────┐
 │ 電気信号  → 電気計測器        │        │ 開発エンジニア（R&D予算）     │
 │ 物質の中身 → 分析機器         │   ≒   │ 研究者・品証（研究費/QC予算） │
 │ 流れ・圧力 → 産業用計測       │        │ 設備保全（設備投資予算）      │
 └──────────────────────────────┘        └──────────────────────────────┘
```

## 2. 電気計測器：開発現場の道具である

**「作った回路がちゃんと動いているか」を確かめる道具**。
だから需要は、製品の量産ではなく**開発プロジェクトの数**に連動する。

- 買うのは技術者本人であることが多い。購買部より先に**現場が機種を決める**
- 「前に使っていた機種と同じ操作でないと困る」という慣性が強く、乗り換えが起きにくい
- 通信規格（5G、Wi-Fi、光伝送の高速化）が新しくなると**測定器も買い替えが必要**になる。
  規格更新が需要イベントになる、という点がこの領域の最大の特徴
- 高価な最先端機はレンタル市場が発達している（プロジェクト期間だけ借りる）

**主なプレイヤーと立ち位置**

| 企業 | 強い領域 | 備考 |
| --- | --- | --- |
| Keysight Technologies（米） | オシロ、ネットワークアナライザ、高周波全般 | HP計測部門 → Agilent → 分離独立という系譜 |
| Tektronix（米） | オシロスコープ | Fortive 傘下。ベンチトップ機の定番 |
| Rohde & Schwarz（独） | 無線・EMC測定 | 非上場。欧州の通信試験で強い |
| アンリツ（日） | 通信計測（5G、光、モバイル端末試験） | 2026年3月期 売上1,174.6億円、営業利益148.3億円（前期比+22.3%） |
| NI（旧National Instruments） | 計測ソフト＋モジュール式計測 | Emerson 傘下。LabVIEW で自動計測を押さえた |

調査会社の推計では、オシロスコープ市場は2026年に約40.3億ドルで、
上位5社で**約68%**を占める（推計値）。計測器全体でも上位数社で5割超とされる。

## 3. 分析機器：研究予算と規制で動く

**「中に何がどれだけ入っているか」を突き止める道具**。
電気計測器と決定的に違うのは、**装置を買っただけでは何も測れない**ことだ。

```
 装置を買う  →  分析手法を確立する  →  消耗品を買い続ける  →  データを規制当局へ出す
 （一度きり）    （アプリ・メソッド）   （カラム・試薬・ガス）  （ここが目的）
      │                 │                      │
      │                 └─ ここにメーカーの技術サポートが要る
      └─ 装置代は入口の費用にすぎない
```

- 顧客は製薬・食品・化学の研究所、大学、公的研究機関、環境分析の受託会社
- **需要の源は研究予算と法規制**。景気ではない。だから半導体ほど激しく振れない
- **論文が販売資料になる**。「◯◯社の装置でこう測った」という先行論文があると、
  後続の研究者は同じ装置を選ぶ。採用が採用を呼ぶ構造
- 高額機（質量分析計、電子顕微鏡、NMR）は**直販＋アプリケーションエンジニア同行**が基本。
  中低価格帯は理化学商社（アズワン等）や代理店を経由する
- 研究機関向けは**年度末（日本なら3月、米国なら9月）に発注が集中する**。
  予算消化のタイミングに合わせるため、四半期業績に季節性が出る

**主なプレイヤーと立ち位置**

| 企業 | 強い領域 | 備考 |
| --- | --- | --- |
| Thermo Fisher Scientific（米） | 質量分析（Orbitrap）、電子顕微鏡、試薬全般 | 売上約430億ドル規模（2025年）。業界最大 |
| Agilent Technologies（米） | LC、GC、GC-MS、カラム・消耗品 | 売上約65億ドル規模。分析に特化 |
| Waters（米） | 液体クロマト（UPLC）、質量分析 | 2026年2月にBDのバイオサイエンス事業と統合 |
| Danaher（米） | SCIEX（質量分析）、Leica（顕微鏡）、Beckman Coulter | 持株会社型。ブランドを束ねる |
| 島津製作所（日） | GC、GC-MS、LC、分光、X線 | 2026年3月期 売上5,607億円。国内最大の分析機器メーカー |
| 日本電子（JEOL）（日） | 電子顕微鏡、NMR、質量分析 | 電子顕微鏡で世界首位級 |
| 日立ハイテク（日） | 電子顕微鏡、分析装置、臨床検査装置 | 日立製作所傘下 → [総合電機](../01_総合電機/README.md) |

## 4. 産業用計測：プラントの神経である

**「工場・プラントが正常に動いているか」を測り続ける機器**。
分析機器が「サンプルを持ってきて測る」のに対し、産業用計測は**配管に付けっぱなし**である。

- 選定するのは設備保全・エンジニアリング部門。プラント建設時にまとめて採用が決まる
- **一度入ると10〜20年替わらない**。配管を切って交換する手間とリスクが大きいため
- したがって**新設プラント案件の獲得が最重要**。既設更新は後から確実についてくる
- 制御システム（DCS）とセットで売られることが多く、ここで計測と制御の境界が曖昧になる。
  横河電機やエマソンは両方を持つ → [FA・制御機器](../14_FA・制御機器/README.md)
- 防爆認証（引火性ガスのある環境で使える認証）などの**認証取得が参入の足かせ**になる

堀場製作所の**マスフローコントローラ（MFC）**はこの分類の変種で、
半導体製造装置に組み込まれる「部品としての計測器」である。
世界シェア約6割とされ、装置メーカーに納めるB2B2Bの商売になっている
→ [半導体製造装置](../03_半導体製造装置/README.md)。

## 5. 3つの商売を並べて比べる

| 観点 | 電気計測器 | 分析機器 | 産業用計測 |
| --- | --- | --- | --- |
| 需要の源 | 新規格・新製品の開発案件 | 研究予算、法規制、品質管理義務 | プラントの新設・改修 |
| 買う人 | 開発エンジニア | 研究者・品質保証部門・受託分析会社 | 設備保全・EPC（プラント建設会社） |
| 予算の性質 | R&D費（景気に左右される） | 研究費・固定的なQC費（粘る） | 設備投資（案件ベース、山谷が大きい） |
| 売り方 | 代理店＋直販、デモ機貸出 | 直販＋アプリケーションエンジニア同行、商社 | EPC経由、仕様書への型番記載を狙う |
| 買い替え周期 | 3〜7年（規格更新で前倒し） | 7〜15年 | 10〜20年 |
| 消耗品の重み | 小さい（プローブ程度） | **非常に大きい**（カラム・試薬） | 中程度（センサ素子・電極） |
| 景気連動性 | 高い | 低い | 中（プラント投資サイクル） |

> ポイント：**分析機器だけが「消耗品で稼ぐ」構造を持つ**。
> ここが業界全体の利益率と安定性を語るときの分かれ目になる
> → [② 儲け方とジレットモデル](02_儲け方とジレットモデル.md)。

## 6. 境界が曖昧な領域

実務で混乱しやすいのは、次の4つの境目である。

```
 計測・分析機器 ────┬──── 体外診断（IVD）
                   │      同じ質量分析でも、患者検体を測ると薬機法の世界になる
                   │      → 09_医薬/06_臨床検査・検査受託
                   │
                   ├──── 半導体製造装置の検査・計測装置
                   │      量産ラインに並ぶ測長SEM・ウェハ検査機は装置産業側
                   │      → 03_半導体製造装置
                   │
                   ├──── FA用センサ・画像処理
                   │      キーエンスの主力はここ。工程を動かすための計測
                   │      → 14_FA・制御機器
                   │
                   └──── 制御システム（DCS/PLC）
                          横河・エマソンは計測と制御を一体で売る
```

判断の順番はこうする。
① 測った値の**行き先**は人の診断か、機械の制御か、報告書か。
② **法規制**はどれに服するか（薬機法／計量法／食品衛生法）。
③ **買う部署**はどこか。
この3つを見れば、たいてい所属がはっきりする。

## 7. 日本勢がどこに固まっているか

日本のメーカーは、**「総合」ではなく「特定の測る対象で世界一」**という形で残っている。

| 企業 | 世界的に強い領域 | 位置づけ |
| --- | --- | --- |
| 島津製作所 | GC、GC-MS、液体クロマト、X線 | 分析機器の総合に近いが、規模ではThermo/Agilentに劣る |
| 堀場製作所 | 自動車排ガス計測、半導体用MFC（世界シェア約6割） | ニッチトップ型。2025年12月期の営業利益530億円のうち445億円（約84%）が先端材料・半導体セグメント |
| 日本電子 | 電子顕微鏡、NMR | 学術・研究機関で世界首位級 |
| アンリツ | 通信計測（モバイル端末試験、光通信） | 規格更新が需要イベント |
| 横河電機 | プラント制御＋産業用計測 | 2026年3月期 売上6,048億円。主力は制御 |
| キーエンス | FAセンサ、画像処理、変位計、顕微鏡 | 厳密にはFA寄りだが計測機器としても大きい |

つまり日本勢の生存戦略は、**総合力ではなく「この測定項目なら絶対にうちだ」という一点突破**である。
規模で劣る分、M&Aで規模を取りにいく動きが2026年に表面化した

## 8. 用語メモ

- **オシロスコープ**：電気信号の波形を時間軸で表示する装置。電子回路開発の基本道具
- **スペクトラムアナライザ**：電波・信号を周波数ごとに分解して強さを見る装置
- **ネットワークアナライザ**：部品や回路の高周波特性（通しやすさ・反射）を測る装置
- **クロマトグラフ**：混合物を成分ごとに分離する装置。ガス（GC）と液体（LC）がある
- **質量分析計（MS）**：分子をイオン化し、質量の違いで識別・定量する装置
- **NMR（核磁気共鳴装置）**：強い磁場で分子構造を解析する装置。有機化学の必需品
- **マスフローコントローラ（MFC）**：ガス流量を精密に制御する機器。半導体装置に組み込まれる
- **アプリケーションエンジニア**：顧客の試料に合わせた測定条件を組み立てる技術営業
- **防爆認証**：可燃性ガスのある場所で使える機器の安全認証。プラント計測の必須条件
- **EPC**：プラントの設計・調達・建設を請け負う会社。産業用計測の実質的な発注者
