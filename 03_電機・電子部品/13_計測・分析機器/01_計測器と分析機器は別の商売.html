計測器と分析機器は別の商売

電機・電子部品計測・分析機器
あこのページの単語集用語に触れると意味を確認できます10語
オシロスコープスペクトラムアナライザネットワークアナライザクロマトグラフ質量分析計（MS）NMR（核磁気共鳴装置）マスフローコントローラ（MFC）アプリケーションエンジニア防爆認証EPC

このノートで分かること：「計測・分析機器業界」と一括りにされる集団が、
実際には顧客も価格帯も売り方も違う3つの商売に分かれていること。
そして、その境目がどこにあるのかを自分で判断できるようになる。

ポイント：オシロスコープを買う人と、質量分析計を買う人は、社内で会ったことがない。
同じ「測る機械」でも、購買部門も予算の出どころも別である。

2. 電気計測器：開発現場の道具である

「作った回路がちゃんと動いているか」を確かめる道具。
だから需要は、製品の量産ではなく開発プロジェクトの数に連動する。

  • 買うのは技術者本人であることが多い。購買部より先に現場が機種を決める
  • 「前に使っていた機種と同じ操作でないと困る」という慣性が強く、乗り換えが起きにくい
  • 通信規格（5G、Wi-Fi、光伝送の高速化）が新しくなると測定器も買い替えが必要になる。
    規格更新が需要イベントになる、という点がこの領域の最大の特徴
  • 高価な最先端機はレンタル市場が発達している（プロジェクト期間だけ借りる）

3. 分析機器：研究予算と規制で動く

「中に何がどれだけ入っているか」を突き止める道具。
電気計測器と決定的に違うのは、装置を買っただけでは何も測れないことだ。

 装置を買う  →  分析手法を確立する  →  消耗品を買い続ける  →  データを規制当局へ出す
 （一度きり）    （アプリ・メソッド）   （カラム・試薬・ガス）  （ここが目的）
      │                 │                      │
      │                 └─ ここにメーカーの技術サポートが要る
      └─ 装置代は入口の費用にすぎない
  • 顧客は製薬・食品・化学の研究所、大学、公的研究機関、環境分析の受託会社
  • 需要の源は研究予算と法規制。景気ではない。だから半導体ほど激しく振れない
  • 論文が販売資料になる。「◯◯社の装置でこう測った」という先行論文があると、
    後続の研究者は同じ装置を選ぶ。採用が採用を呼ぶ構造
  • 高額機（質量分析計、電子顕微鏡、NMR）は直販＋アプリケーションエンジニア同行が基本。
    中低価格帯は理化学商社（アズワン等）や代理店を経由する
  • 研究機関向けは年度末（日本なら3月、米国なら9月）に発注が集中する。
    予算消化のタイミングに合わせるため、四半期業績に季節性が出る

4. 産業用計測：プラントの神経である

「工場・プラントが正常に動いているか」を測り続ける機器。
分析機器が「サンプルを持ってきて測る」のに対し、産業用計測は配管に付けっぱなしである。

  • 選定するのは設備保全・エンジニアリング部門。プラント建設時にまとめて採用が決まる
  • 一度入ると10〜20年替わらない。配管を切って交換する手間とリスクが大きいため
  • したがって新設プラント案件の獲得が最重要。既設更新は後から確実についてくる
  • 制御システム（DCS）とセットで売られることが多く、ここで計測と制御の境界が曖昧になる。
    横河電機やエマソンは両方を持つ → FA・制御機器
  • 防爆認証（引火性ガスのある環境で使える認証）などの認証取得が参入の足かせになる

堀場製作所のマスフローコントローラ（MFC）はこの分類の変種で、
半導体製造装置に組み込まれる「部品としての計測器」である。
世界シェア約6割とされ、装置メーカーに納めるB2B2Bの商売になっている
→ 半導体製造装置。

観点 電気計測器 分析機器 産業用計測
需要の源新規格・新製品の開発案件研究予算、法規制、品質管理義務プラントの新設・改修
買う人開発エンジニア研究者・品質保証部門・受託分析会社設備保全・EPC（プラント建設会社）
予算の性質R&D費（景気に左右される）研究費・固定的なQC費（粘る）設備投資（案件ベース、山谷が大きい）

ここが業界全体の利益率と安定性を語るときの分かれ目になる

6. 境界が曖昧な領域

実務で混乱しやすいのは、次の4つの境目である。

 計測・分析機器 ────┬──── 体外診断（IVD）
                   │      同じ質量分析でも、患者検体を測ると薬機法の世界になる
                   │      → 09_医薬/06_臨床検査・検査受託
                   │
                   ├──── 半導体製造装置の検査・計測装置
                   │      量産ラインに並ぶ測長SEM・ウェハ検査機は装置産業側
                   │      → 03_半導体製造装置
                   │
                   ├──── FA用センサ・画像処理
                   │      キーエンスの主力はここ。工程を動かすための計測
                   │      → 14_FA・制御機器
                   │
                   └──── 制御システム（DCS/PLC）
                          横河・エマソンは計測と制御を一体で売る

判断の順番はこうする。
① 測った値の行き先は人の診断か、機械の制御か、報告書か。
② 法規制はどれに服するか（薬機法／計量法／食品衛生法）。
③ 買う部署はどこか。
この3つを見れば、たいてい所属がはっきりする。

7. 日本勢がどこに固まっているか

日本のメーカーは、「総合」ではなく「特定の測る対象で世界一」という形で残っている。

企業 世界的に強い領域 位置づけ

8. 用語メモ

  • オシロスコープ：電気信号の波形を時間軸で表示する装置。電子回路開発の基本道具
  • スペクトラムアナライザ：電波・信号を周波数ごとに分解して強さを見る装置
  • ネットワークアナライザ：部品や回路の高周波特性（通しやすさ・反射）を測る装置
  • クロマトグラフ：混合物を成分ごとに分離する装置。ガス（GC）と液体（LC）がある
  • 質量分析計（MS）：分子をイオン化し、質量の違いで識別・定量する装置
  • NMR（核磁気共鳴装置）：強い磁場で分子構造を解析する装置。有機化学の必需品
  • マスフローコントローラ（MFC）：ガス流量を精密に制御する機器。半導体装置に組み込まれる
  • アプリケーションエンジニア：顧客の試料に合わせた測定条件を組み立てる技術営業
  • 防爆認証：可燃性ガスのある場所で使える機器の安全認証。プラント計測の必須条件
  • EPC：プラントの設計・調達・建設を請け負う会社。産業用計測の実質的な発注者
