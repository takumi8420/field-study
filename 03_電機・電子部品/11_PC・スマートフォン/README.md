### 最初に押さえる一行

> **この産業は「作る人がいちばん儲からない」構造になっている。**
> スマホは年間11〜12億台売れるが、業界の営業利益の **75〜85% を Apple 1社**が取り
> （Counterpoint 推計、2025年）、組み立てる Foxconn の粗利率は **5.88%**（2026年Q1）。
> そして2026年は、**AI データセンターがメモリを奪ったせいで端末が値上がりし、
> 台数が減る**という、過去にない形の不況が起きている。

**仕様決定・ブランド・値決め・販売網・OS生態系の産業**に近い。

| 国内PC出荷（2026年度予測）     | **約1,123万台（4割減）**                                 | 報道ベースの予測        |
| 国内新品スマホ出荷（2025年度） | 3,132.8万台                                              | MM総研                  |

```
【台数はもう増えない。動くのは「買い替えの間隔」と「1台の単価」】

  スマホ：総保有台数 ÷ 買い替えサイクル(年) ＝ 年間出荷台数
          ほぼ頭打ち      4年超に長期化       11〜12億台で横ばい〜微減
                              ▲ここが1年延びるだけで市場は2〜3割縮む

  PC   ：法人の更新計画 ×  OSサポート期限  ＝ 需要の山と谷
          予算年度に連動    2025年10月に Win10 終了 → 2025年が山
                                                    → 2026年は谷（反動）
  ───────────────────────────────────────────────────────────
  2026年はそこに「メモリ高騰」が重なり、**台数↓ 単価↑** という珍しい形に
```

- **台数と金額は逆方向に動く年がある**。2026年はその典型で、台数は減るのに平均単価は上がる
- 「成熟市場」と言われるが、需要が消えたのではなく**買い替えサイクルが延びた**だけ。
  総保有台数 ÷ サイクル年数が出荷台数になる（→ [② スマホ市場の成熟](02_スマホ市場の成熟.md)）
- PC は**サポート期限**というカレンダーで需要が作られるため、山と谷が周期的に来る

## 5. 収益モデル・コスト構造

**儲けは「作る能力」ではなく「値段を決められる立場」から出る。**

| 費目（ハイエンド端末の目安） | 売価に対する比率                    | 性質                                        |
| ---------------------------- | ----------------------------------- | ------------------------------------------- |
| BOM（部品原価の合計）        | **35〜50%**                         | 変動費。2026年はメモリ高騰で比率が上昇      |
| └ うち SoC                   | BOM の15〜20%（最大項目）           | 先端プロセスの値上がりが効く                |
| └ うちメモリ（DRAM＋NAND）   | BOM の15〜25%                       | **2026年Q1に価格が前年比約2倍**             |
| 組立費（EMS への支払い）     | 2〜5%                               | ここが受託側の売上。粗利は5〜6%             |
| 研究開発・広告・流通・保証   | 20〜30%                             | ほぼ固定費。台数が減ると1台あたりが重くなる |
| ブランドの粗利               | Apple のハードは35〜40%前後とされる | 値決め力の結果                              |

- **ブランド側は固定費型**。研究開発と広告は台数が減っても減らない。
  だから台数が減る局面では、**単価を上げるか、モデル数を減らすか**しかない
- **EMS/ODM は変動費型で薄利**。稼働を埋めることがすべてなので、
  2026年は AI サーバーという単価の大きい仕事に資源を移している
- **OS 層は限界費用がほぼゼロ**。1台増えても追加コストが出ないため、
  端末が売れた台数がそのまま利益の土台になる。粗利率70%超
- PC は本体の利幅が薄く、**保守契約・キッティング・DaaS（月額提供）**で稼ぐ形に移行している
  → [③ PC市場の構造](03_PC市場の構造.md#7-pc-を買う側の経済法人のものさし)

## 6. 競争要因（KSF）と参入障壁

| 要因               | 中身                                                                                 |
| ------------------ | ------------------------------------------------------------------------------------ |
| **OS と生態系**    | アプリ・決済・データ移行。端末の性能以上に乗り換えを止めている力                     |
| **部品の優先配分** | 最先端 SoC・最新メモリは大口顧客に優先的に回る。**小規模ブランドはそもそも買えない** |
| **値決め力**       | 値下げ競争に参加せずに済むかどうか。Apple と他社の利益差はほぼこれで説明できる       |
| **規模（購買力）** | 年1億台を超えると部品調達価格が変わる。中位の会社が最も苦しい                        |
| **通信特許**       | 標準必須特許のロイヤリティは避けられない固定的なコスト                               |
| **販売・保守網**   | 棚を押さえること、修理拠点を持つこと。日本の法人PC市場ではこれが最大の資産           |
| **地政学**         | 生産地（中国・インド・ベトナム）、関税、輸出管理。設計以上に読みにくいリスク         |

> 逆に**参入障壁になっていないもの**は「工場」。
> 製造は委託できるため、工場を持つことは強みではなくコストになった。
> **日本メーカーが完成品から退いた理由もここにある** ── 技術ではなく、
> 世界規模の調達力・OS生態系・販売網を維持できる台数が取れなかった。

## 7. 規制・法制度

| 制度                                             | 内容                                                                                                                                                                 |
| ------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **電気通信事業法 27条の3（日本）**               | 通信契約に紐づく端末値引きの上限を規定（原則 税抜4万円、4〜8万円の端末は半額、4万円以下は2万円）。2023年12月27日施行の水準。**総務省が2025年12月から見直しを議論中** |
| **分離プラン義務化（2019年、日本）**             | 通信料金と端末代金の完全分離。「実質0円」モデルを終わらせた                                                                                                          |
| **技術基準適合証明（技適）**                     | 国内で電波を出す機器に必須。並行輸入端末の制約になる                                                                                                                 |
| **EU デジタル市場法（DMA）**                     | アプリストアの外部決済・サイドローディング開放を義務付け。Apple の収益モデルに直接効く                                                                               |
| **USB Type-C 統一（EU）**                        | 充電端子の共通化義務。iPhone の端子変更の直接の引き金になった                                                                                                        |
| **修理する権利**                                 | 部品・工具・マニュアルの提供義務。米州法や EU で進む                                                                                                                 |
| **省エネ・リサイクル（資源有効利用促進法ほか）** | 回収・再資源化。中古流通の制度的な下支えにもなる                                                                                                                     |
| **輸出管理・関税**                               | 米中間の措置。生産地の分散（インド・ベトナム）はこれへの対応でもある                                                                                                 |

## 8. 最近のトピック

詳細と出典URLは **[④ 直近トピック_2026](04_直近トピック_2026.md)**。

1. **メモリ高騰がすべての起点**。AI データセンター向けに生産が優先配分され、
   2026年Q1の DRAM／NAND 価格は**前年同期比で約2倍**。
   IDC は **2028年初頭より前に根本解消はない**と見る
2. **スマホは13年ぶりの低水準**。2026年Q2 の世界出荷は 2億7,630万台（−7.4%、IDC）、
   Counterpoint 集計では −11% で**2013年以来のQ2最低**
3. **痛みは均等ではない**。同Q2で伸びたのは Apple（+14.9%）と Samsung（+8.1%）だけ。
   エントリー価格帯に偏る Xiaomi は −26.4%。**安い端末ほど原価上昇に耐えられない**
4. **PC は二重の谷**。Windows 10 サポート終了（2025年10月）の特需の反動に
   メモリ高騰が重なり、2026年Q2 は −4.9%、通年で約11%減の見通し。
   国内は2026年度に**4割減（約1,123万台）**の予測
5. **需要は中古と長期利用に逃げている**。国内中古スマホは2025年度 360.7万台で
   7年連続過去最高。「1円端末」は原価上昇で成立しなくなりつつあると報じられる
