# ① 誰が作り、誰が儲けているか

このノートで分かること：スマホ・PCという「誰もが持っている製品」の裏で、
**作っている会社と儲けている会社がまったく別**であること、そしてその理由。

> **結論を先に。** スマートフォンは年間約12億台売れるが、
> 業界全体の営業利益の **75〜85% を Apple 1社が取っている**（Counterpoint 推計、2025年）。
> 残りをサムスンが取り、中国勢のハード事業はほぼ利益ゼロ近辺で回っている。
> 組み立てているのは Foxconn などの**受託企業で、粗利率は 5〜6% 程度**。
> つまりこの産業は「作る人」がいちばん儲からない構造になっている。

---

## 1. まず4つの層に分けて見る

「スマホメーカー」という言い方は理解の邪魔になる。実際には**4つの別々の産業**が縦に重なる。

```
┌─────────────────────────────────────────────────────────────┐
│ 【層4】OS・アプリストア・サービス                             │
│   Apple（iOS / App Store）, Google（Android / Play）          │
│   ★端末を売らずに端末から稼ぐ層。粗利率 70% 超               │
└─────────────────────────────────────────────────────────────┘
                    ▲ 使用料・手数料・検索収益
┌─────────────────────────────────────────────────────────────┐
│ 【層3】ブランド（設計・値決め・販売）                         │
│   Apple / Samsung / Xiaomi / OPPO / vivo / Transsion          │
│   Lenovo / HP / Dell / ASUS / Acer（PC側）                    │
│   ★仕様を決め、部品を指名買いし、価格を決める。利益はここに集中 │
└─────────────────────────────────────────────────────────────┘
                    ▲ 製造委託（1台あたり数ドル〜十数ドル）
┌─────────────────────────────────────────────────────────────┐
│ 【層2】EMS / ODM（受託生産）                                  │
│   Foxconn(鴻海) / Pegatron / Luxshare / BYD Electronics       │
│   Quanta / Compal / Wistron / Inventec（PC・サーバー）        │
│   ★人と設備を持つ。粗利 5〜6%。規模だけが武器                 │
└─────────────────────────────────────────────────────────────┘
                    ▲ 部品供給（ここが原価の大半）
┌─────────────────────────────────────────────────────────────┐
│ 【層1】半導体・部品・材料                                     │
│   SoC: Apple(設計)/Qualcomm/MediaTek → 製造は TSMC            │
│   メモリ: Samsung / SK hynix / Micron / キオクシア             │
│   画像センサ: ソニー  ／ 有機EL: Samsung Display / BOE        │
│   受動部品: 村田 / TDK / 太陽誘電  ／ 電池: ATL / CATL        │
│   ★数量は安定。ただし市況で利益が乱高下する                   │
└─────────────────────────────────────────────────────────────┘
```

部品側の中身は別ノートに委譲する。受動部品 → [電子部品](../05_電子部品/README.md)、
チップ側 → [半導体（ロジック・メモリ）](../02_半導体（ロジック・メモリ）/README.md)。

## 2. BOM（部品代）と販売価格の差はどこへ行くのか

**BOM**（Bill of Materials ＝ 部品表）は、その製品を構成する部品の原価合計。
組立費・物流費・保証費は含まない、純粋な「モノ代」。

ハイエンドスマホの一般的な内訳イメージ（金額は公開 teardown 各社の推計を丸めた概算。
Counterpoint や TechInsights の BOM 分析は有料レポートで、細目は非公開部分が多い）。

| 項目                                 | 販売価格に占める割合の目安                          | 誰が取るか                               |
| ------------------------------------ | --------------------------------------------------- | ---------------------------------------- |
| SoC（頭脳チップ）                    | BOM の **15〜20%** と最大項目                       | Apple/Qualcomm/MediaTek（製造は TSMC）   |
| メモリ（DRAM＋NAND）                 | BOM の 15〜25%。**2026年は急騰で比率が上昇**        | Samsung / SK hynix / Micron / キオクシア |
| ディスプレイ                         | BOM の 15〜20%                                      | Samsung Display / BOE / LG Display       |
| カメラモジュール                     | BOM の 10〜15%                                      | ソニー（センサ）＋ 中台のモジュール各社  |
| 電池・筐体・受動部品ほか             | BOM の 20〜30%                                      | ATL/CATL、機構部品各社、村田ほか         |
| **BOM 合計**                         | **販売価格の 35〜50% 程度**                         | 上記の部品メーカー群                     |
| 組立費（EMS への支払い）             | 販売価格の **2〜5% 程度**                           | Foxconn など                             |
| 研究開発・マーケティング・流通・保証 | 販売価格の 20〜30%                                  | ブランド自身                             |
| **ブランドの利益**                   | 残り。Apple は**ハード粗利率 35〜40% 前後**とされる | ブランド                                 |

> **ポイント：BOM の話をするときは「原価率」の錯覚に注意する。** BOM が売価の 4 割でも、
> 研究開発・広告・流通・保証・アプリ生態系の維持費が乗るので「6 割まるごと儲け」ではない。
> それでも Apple が突出して儲かるのは、**同じ BOM で他社より 2〜3 倍高く売れる**からであって、
> 原価が安いからではない。

## 3. 利益がどれだけ偏っているか

| 指標（2025年通年、Counterpoint 推計・報道ベース） | 数値                                                      |
| ------------------------------------------------- | --------------------------------------------------------- |
| スマホ世界出荷に占める Apple のシェア             | **約20%**                                                 |
| スマホ業界の売上（金額）に占める Apple のシェア   | 4〜5割程度                                                |
| スマホ業界の**営業利益**に占める Apple のシェア   | **75〜85%**                                               |
| Apple 2026年度第2四半期（2026年1〜3月）売上高     | **1,111.8億ドル**（前年同期比 +17%、3月期として過去最高） |
| 同 iPhone 売上高                                  | 569.9億ドル（3月期として過去最高）                        |
| 同 サービス売上高                                 | 309.8億ドル（過去最高）                                   |

同じ期間に、Foxconn（鴻海）の粗利率は **5.88%**（前年同期 6.15% から低下）と報じられる。
台数では Foxconn のほうがはるかに多くの端末に触れているのに、利益はこれだけ違う。

```
   台数シェア            売上シェア            営業利益シェア
   ┌────────┐           ┌────────┐           ┌────────┐
   │ Apple  │ 20%       │ Apple  │ 45%       │ Apple  │ 80%
   ├────────┤           ├────────┤           │        │
   │Samsung │ 19%       │Samsung │ 20%       ├────────┤
   ├────────┤           ├────────┤           │Samsung │ 15%
   │中国勢   │ 40%      │中国勢   │ 28%       ├────────┤
   ├────────┤           ├────────┤           │中国勢≒0〜5%
   │その他   │ 21%      │その他   │  7%      └────────┘
   └────────┘           └────────┘
   ※2025年の各種推計を丸めたイメージ図。出荷は IDC/Counterpoint、
     利益配分は Counterpoint 推計（75〜85%）に基づく概算。
```

**なぜここまで偏るのか。** 理由は3つある。

1. **値決めができる**。iPhone は値下げ競争に参加しない。
   Android 勢は同じ SoC・同じパネルを使えるため、差別化が価格に流れやすい
2. **交換コストが高い**。iMessage、写真、購入済みアプリ、Apple Watch との連携。
   個々は小さいが、束になると乗り換えが面倒になる
3. **端末の外でも稼ぐ**。App Store 手数料、iCloud、Google からの検索デフォルト料。
   端末が売れなかった年でもサービス収益は積み上がる

## 4. EMS / ODM はなぜ薄利なのか

**EMS**（Electronics Manufacturing Services ＝ 受託製造）は他社ブランドの製品を作る会社、
**ODM**（Original Design Manufacturer）は設計まで請け負う会社。ノートPCは ODM が
設計・製造のほとんどを担い、ブランドはロゴと販売網を提供する形が主流になっている。

| 会社                            | 主戦場                        | 経済的な特徴                                                                                       |
| ------------------------------- | ----------------------------- | -------------------------------------------------------------------------------------------------- |
| **Foxconn（鴻海）**             | iPhone 組立、AIサーバーラック | 世界最大。AIサーバーラック組立で約4割のシェアと報じられる。2026年Q1 売上 約666億ドル、粗利率 5.88% |
| **Pegatron（和碩）**            | iPhone の第2供給源            | AIサーバーへの参入が遅れ、2024年は減収。2026年に本格参入と報じられる                               |
| **Luxshare（立訊）**            | AirPods → iPhone へ拡大       | 中国系。Apple 依存を武器にも弱点にもしている                                                       |
| **Quanta（廣達）**              | ノートPC最大手、AIサーバー    | NVIDIA の AI サーバー受注の 25〜30% を持つとの推計                                                 |
| **Wistron / Compal / Inventec** | ノートPC・サーバー            | Wistron は2025年に売上 NT$2兆超で Quanta を初めて抜いたと報じられる                                |

薄利になる理由は、この層に**指名される理由がないから**。

```
ブランド側の交渉 ─────────────────────────────
  「同じ図面で、A社は1台8ドル、B社は7.5ドルと言っている」
        │
        ▼
  EMS は値下げでしか受注を取れない
        │
        ├─ 対抗策1：規模を取る（1社で数十万人を雇う）
        ├─ 対抗策2：垂直統合する（筐体・コネクタ・組立を丸ごと）
        └─ 対抗策3：儲かる別の客を探す ← いま起きていること
                        ▼
              AIサーバー（1ラック数千万円）へ全力移動
              スマホ組立の比重を意図的に下げる
```

2024〜2026年の EMS/ODM は、**スマホ・PCの受託から AI サーバーの受託へ主戦場を移している**。
AI サーバーは1台の金額が桁違いに大きく、同じ利益率でも絶対額が稼げる。逆に言えば、
スマホ組立という仕事の魅力が業界内で相対的に落ちている。
→ [データセンター](../../04_情報通信・IT・ネット/03_データセンター/README.md)

## 5. 垂直統合と水平分業：2つのやり方

|            | **Apple 型（垂直統合）**                | **Android 型（水平分業）**             |
| ---------- | --------------------------------------- | -------------------------------------- |
| OS         | 自社（iOS）。他社に渡さない             | Google の Android を各社が使う         |
| 主要チップ | 自社設計（A シリーズ／M シリーズ）      | Qualcomm・MediaTek から買う            |
| 製造       | 外部委託（Foxconn 等）                  | 外部委託または自社工場                 |
| 差別化の源 | ハード×OS×サービスの一体設計            | カメラ・充電速度・価格                 |
| 利益の出方 | **端末で厚く取り、サービスで積む**      | 端末は薄利。広告・サービス・金融で補う |
| 弱点       | 1つの製品に依存。中国依存の地政学リスク | 同じ部品を使うため差別化が続かない     |

Apple が「工場を持たないのに垂直統合」と言われるのは、
**設計とOSとサービスを握り、製造だけを外に出している**から。
握っているのは工場ではなく、**仕様を決める権利と、値段を決める権利**。

一方 Samsung は珍しく**両方**をやっている。
自社でメモリ・有機ELパネル・一部 SoC（Exynos）を作りながら端末も売る。
2026年のようにメモリが高騰する局面では、部品部門の利益が端末部門の苦境を埋める
（内製部品を持つことが保険として効く、数少ない例）。

## 6. 部品はどこの国が作っているか

| 部品                       | 主な供給国・企業                                            | 代替のしやすさ                                                          |
| -------------------------- | ----------------------------------------------------------- | ----------------------------------------------------------------------- |
| 先端ロジック（SoC 製造）   | 台湾（TSMC）が圧倒的                                        | **極めて難しい**。最大の一点集中リスク                                  |
| DRAM / NAND                | 韓国（Samsung, SK hynix）、米（Micron）、日（キオクシア）   | 難しい。3〜4社の寡占                                                    |
| 画像センサ                 | 日本（ソニー）が首位                                        | 中位機はサムスン・OVで代替可                                            |
| 有機ELパネル               | 韓国（Samsung Display）、中国（BOE）                        | 中国勢の台頭で代替可能に → [ディスプレイ](../07_ディスプレイ/README.md) |
| 受動部品（MLCC 等）        | 日本（村田・太陽誘電・TDK）、韓（サムスン電機）、台（国巨） | 汎用は代替可、高容量品は難しい → [電子部品](../05_電子部品/README.md)   |
| リチウムイオン電池（民生） | 中国（ATL・CATL）                                           | 一時期は日本が主導 → [二次電池](../08_二次電池/README.md)               |
| コネクタ・基板             | 日台中                                                      | → [コネクタ・プリント基板](../06_コネクタ・プリント基板/README.md)      |

> 日本勢の立ち位置を一言でいうと、
> **「最終製品では完敗したが、部品では残った」**。
> 世界で売れるスマホのほとんどに日本製の部品が入っているが、
> 日本ブランドのスマホは世界市場でほぼ姿を消した。
> この落差がこの業界を見る上で最も重要な事実の一つ。

## 7. では中国ブランドは何で食べているのか

出荷台数では中国勢が世界の4割前後を占めるのに、営業利益はほとんど取れていない。
それでも続けられるのは、**端末を入口にした別の商売**があるから。

- **広告・プリインストール**：自社アプリストア、テーマ、ブラウザ広告
- **IoT・家電へのクロスセル**：シャオミはテレビ・掃除機・EV まで自社生態系に取り込む
- **金融・与信**：新興国では端末の分割販売そのものが金融商品になる。国内の買い替え補助金も効く

ただし 2026年はこのモデルが直撃を受けている。
メモリ価格の高騰は**安い端末ほど原価に占める比率が高い**ため、
エントリー〜ミドル価格帯に偏る中国勢の出荷が最も落ちた
（2026年Q2：Xiaomi は前年同期比 −26.4%、IDC）。
→ [直近トピック_2026](04_直近トピック_2026.md)

## 8. 新規参入が難しい本当の理由

「工場は Foxconn に頼めるのだから、誰でもスマホを作れる」は半分正しく、半分間違い。

| ハードル                 | 中身                                                                                                                                                                        |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **部品を買えない**       | 最先端 SoC・最新メモリは大口顧客に優先配分される。少量発注は後回しか、そもそも売ってもらえない                                                                              |
| **OS がない**            | Android は使えるが、Google のアプリ群（GMS）のライセンスが要る。中国向けは別世界                                                                                            |
| **特許**                 | 通信規格の必須特許。Qualcomm 等へのロイヤリティが避けられない                                                                                                               |
| **アフターサービス**     | 故障対応・部品在庫を数年間維持する体制。規模がないと赤字                                                                                                                    |
| **量販店・キャリアの棚** | 売り場に置いてもらえるかどうかが最後の関門 → [家電量販](../../07_小売・流通/06_家電量販/README.md)、[通信キャリア](../../04_情報通信・IT・ネット/01_通信キャリア/README.md) |

日本メーカーが撤退したのは技術がなかったからではなく、**この5つを世界規模で維持する
台数が取れなかった**から、と整理するのが実態に近い。
→ [PC市場の構造](03_PC市場の構造.md#6-日本のpcメーカーはいまどうなっているか)

## 9. 用語メモ

| 用語                   | 意味                                                                                                    |
| ---------------------- | ------------------------------------------------------------------------------------------------------- |
| **BOM**                | Bill of Materials。部品表・部品原価の合計。組立費や保証費は含まない                                     |
| **EMS**                | 他社ブランド製品の製造を請け負う事業。Foxconn が代表                                                    |
| **ODM**                | 設計まで請け負う受託。ノートPCはこの形が主流で、ブランド側は設計をほぼしていない                        |
| **SoC**                | System on a Chip。CPU・GPU・通信・AI処理を1チップに載せたスマホの頭脳                                   |
| **ファブレス**         | 自社工場を持たず設計に専念する形。Apple・Qualcomm・MediaTek が該当                                      |
| **GMS**                | Google Mobile Services。Play ストアや Gmail 等のセット。Android 端末を海外で売るための実質的な入場券    |
| **垂直統合／水平分業** | 前者は設計から販売まで自社で握る形、後者は工程ごとに別会社が担う形                                      |
| **粗利率**             | 売上から原価を引いた割合。EMS は 5〜6%、Apple のハードは 35〜40% 前後とされ、同じ「製造業」でも桁が違う |
