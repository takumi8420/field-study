③ PC市場の構造 ── 法人需要とサポート期限が需要を作る

このノートで分かること：PC がスマホとはまったく違う需要の作られ方をしていること、
そして「日本メーカーのPC」がいま実際には何を指しているのか。

結論を先に。 PC市場の主役は個人ではなく法人で、
需要を作っているのは技術の進歩ではなく Windows のサポート期限である。
Windows 10 のサポート終了（2025年10月14日）が2025年の需要を押し上げ、
その反動で2026年は大きく落ち込んでいる。
そこへメモリ高騰が重なり、IDC は2026年の世界出荷を 約11%減と見込む。
日本のPCメーカーは、NEC も富士通も dynabook もすでに資本は海外で、
残っているのはブランドと国内向けの設計・サポート体制である。

1. スマホとPCは別の産業だと考えたほうがいい

スマートフォン PC
主な買い手個人法人が半分以上（国内はとくに法人比率が高い）
買い替えの引き金故障、価格、気分、キャリアの施策減価償却の期限とOSサポート期限
サイクル4年超に長期化法人は 4〜5年。予算年度に紐づく
価格帯2万円〜30万円と幅が広い5万円〜25万円
設計の担い手ブランドが仕様を決めるODM（Quanta 等）がほぼ設計している
差別化カメラ、デザイン、OS生態系重量、堅牢性、保守サービス、調達のしやすさ
利益の出方Apple に極端集中各社とも薄利。法人保守サービスで補う

ポイント：PC の需要は「欲しくなったから買う」ではなく、
「期限が来たから買う」で動く。 だからサイクルが読みやすく、同時に、
期限が過ぎると需要が崖のように消える。

2. Windows のサポート期限が需要カレンダーを作る

【需要が作られる仕組み】

 Microsoft がサポート終了日を宣言
        │
        ▼
 情報システム部門「その日以降はセキュリティ更新が来ない」
        │        → 監査・取引先要件・保険の観点で放置できない
        ▼
 予算化（前年度に計上）
        │
        ▼
 大量一括入替（数千〜数万台）    ← ここが山
        │
        ▼
 入れ替え完了 → 次の期限まで需要ゼロ ← ここが谷

 ───────────────────────────────────────────
  2014年4月 : Windows XP 終了     ──▶ 大きな山
  2020年1月 : Windows 7 終了      ──▶ 大きな山
  2025年10月: Windows 10 終了     ──▶ 直近最大の山
  2026年〜  : 期限イベントなし     ──▶ 反動の谷 ★いまここ

この「山と谷」は毎回繰り返されている。
2025年は Windows 10 のサポート終了と、GIGAスクール構想で配られた
教育用端末の更新期が重なり、国内出荷は過去最大の1,805万台（2025年度、MM総研）に達した。

その反動で、2026年度の国内出荷は4割減（1,123万台前後）との予測が報じられている。
「4割減」という数字が示すのは市場の崩壊ではなく、前年が特殊に高かったということ。

メモリ高騰がPCに効くのは、PC のほうがスマホより1台あたりのメモリ搭載量が多いから。
8GB〜32GB の DRAM と 512GB〜1TB の SSD を積む。
DRAM 価格が2倍になれば、5万円クラスの安価なノートは原価が成り立たなくなる。
「低価格モデルの消滅」が繰り返し報じられているのは、この単純な算数による。
→ 半導体（ロジック・メモリ）

4. 「AI PC」は谷を埋められるか

AI PC とは、NPU（AI 専用演算器）を搭載し、端末内で AI 処理を回せる PC のこと。
Microsoft の「Copilot+ PC」は NPU 性能 40 TOPS 以上を要件とした。

期待されていること 現実
新しい買い替え理由になる法人は期限で買う。「AIが載っている」は購買の決定要因になりにくい
単価が上がる上がるが、その分だけメモリを多く積む必要があり原価も上がる
業務効率が上がるクラウド版 Copilot / ChatGPT で足りる業務が多く、オンデバイスの必然性が弱い
2027年以降の回復を支えるIDC 等はメモリ制約の緩和とAI PC拡大で2027年に安定化と見る。ただし2026年の谷は埋まらない

AI PC の位置づけは、需要を新しく作るものというより、
どうせ買い替えるなら載っているものを選ぶ「仕様」に近い。
この点はスマホの AI 機能とまったく同じ構図になっている。
→ スマホ市場の成熟

5. Arm への移行 ── PC の土台が静かに入れ替わりつつある

PC はずっと x86（Intel と AMD）の世界だった。
そこへ、スマホで使われてきた Arm 系の設計が入ってきている。

【従来】                          【いま起きていること】

  Windows ── x86 ── Intel          Windows ─┬─ x86 ── Intel / AMD
                    AMD                      └─ Arm ── Qualcomm(Snapdragon X)
                                                        NVIDIA（参入と報じられる）
  macOS ──── x86 ── Intel          macOS ──── Arm ── Apple silicon（M シリーズ）
                                              ★2020年に完全移行を開始し完了
指標 数値 注記
Arm 系（Apple silicon ＋ Snapdragon X 等）のクライアントCPU比率2026年Q2 に 15.3% で過去最高報道ベース。大半は Apple
Windows on Arm の AI ノート浸透率2025年 1.2% → 2026年 3.2% 見込み調査会社推計
Canalys の予測2026年末に Arm 系が PC 市場の最大30%かなり強気な予測で、実績は下回っている
Snapdragon X2 Elite2026年4月にレビュー解禁。18コア、最大5.0GHz、NPU 80 TOPS報道ベース

Arm 化が進む理由は省電力（バッテリー持ち）と、スマホ向けチップ設計資産の流用。
進まない理由は互換性で、x86 用に書かれた業務アプリ・周辺機器ドライバが
そのままでは動かない場合がある。法人にとってこれは致命的な障害になる。

Apple が Arm 移行に成功したのは、OS もチップも自社で握っていたから。
Windows 側は Microsoft・チップ各社・PCメーカー・アプリ開発者の足並みを
揃える必要があり、同じことをやるのに何倍も時間がかかる。
ここでも「垂直統合か水平分業か」の差が出る。
→ 誰が作り誰が儲けているか

6. 日本のPCメーカーはいまどうなっているか

結論：ブランドは残ったが、資本はほぼ海外に移った。

ブランド 実際の資本関係 補足
NEC パーソナルコンピュータNEC と Lenovo の合弁（Lenovo が過半）。NEC レノボ・ジャパングループ国内出荷シェア首位
FCCL（富士通クライアントコンピューティング）Lenovo が過半を出資「FMV」ブランド

パナソニック（レッツノート）日本資本のまま国内法人・モバイル特化。数量より単価で成立させている珍しい例
マウスコンピューター／サードウェーブ日本資本国内組立・BTO（受注生産）に特化

なぜこうなったのか。 PC は ODM が設計・製造を担う産業になったため、
自前の工場や設計チームを持つこと自体がコスト要因に変わった。
一方で、日本の法人市場で求められるのは
「キーボード配列」「保守拠点」「入札対応」「長期供給」といった国内向けの運用力で、
これはブランドと販売・サポート体制があれば維持できる。

【PCメーカーに残った仕事】            【外に出た仕事】

  ・国内向けの仕様決め                 ・基板設計 ─┐
  ・法人向け営業・入札                 ・筐体設計   ├─▶ ODM
  ・保守・修理ネットワーク             ・製造・検査 ┘   (台湾/中国)
  ・プリインストールとセキュリティ設定  ・部品調達（一部）
  ・ブランドと広告
        │
        ▼
  1台あたりの利幅は薄いが、
  保守契約・リース・キッティング（初期設定代行）で稼ぐ
  → 実態は「製造業」より「法人向けサービス業」に近づいている

パナソニックのレッツノートだけは別の戦い方をしている。
頑丈さ・軽さ・国内生産（神戸）を売りに、台数を追わず単価と法人の指名買いで成立させる。
これは規模で勝てない市場で唯一残る道の実例として読む価値がある。
→ 総合電機

7. PC を買う側の経済（法人のものさし）

PC の商談で実際に使われる指標は、本体価格ではない。

指標 中身
TCO（総所有コスト）本体＋保守＋故障時の業務停止＋キッティング＋廃棄まで含めた総額。3〜5年で割る
キッティング費用初期設定・ソフト導入・資産登録。1台数千円〜1万円かかる。本体値引きより効く場合がある
リース／サブスク（DaaS）Device as a Service。月額で端末＋保守をまとめて提供。資産計上を避けられる
リプレース計画何年に何台入れ替えるかの年次計画。ここに乗らないと売れない
残価・廃棄情報漏洩対策としてのデータ消去証明。中古市場に流す場合の価値

なぜここが重要か。 法人相手では「安い1台」より「面倒でない数千台」が勝つ。
だから日本メーカーのブランドが残っているのは郷愁ではなく、
保守網と入札実績という実務的な資産があるから、と読むのが正確。

8. 用語メモ

用語 意味
EOS（サポート終了）OS の更新提供が終わる日。以降は脆弱性が放置されるため、法人は買い替えを迫られる
AI PC / Copilot+ PCNPU を積み端末内で AI 処理を行う PC。Copilot+ は NPU 40 TOPS 以上が要件とされた
NPU / TOPSAI 専用演算器と、その処理能力の単位（1秒あたり何兆回の演算か）
x86 / ArmPC の CPU 設計の系統。前者は Intel・AMD、後者は Apple・Qualcomm。命令の互換性がない
ODM設計から製造まで請け負う受託企業。ノートPCは実質的に ODM が設計している
BTOBuild To Order。注文を受けてから構成を組む方式。国内メーカーが在庫リスクを避けるのに使う
キッティング納品前に初期設定・ソフト導入・資産登録を済ませる作業。法人PC商談の重要な収益源
DaaSDevice as a Service。端末を買わず月額で使う形態。リースと保守を束ねたもの
GIGAスクール構想児童生徒1人1台の端末整備を進めた国の施策。更新期が数年おきに大きな需要の山を作る
