# ④ 直近トピック（2026年9月時点）

報道・調査会社レポートベースの整理。数値は発表元と時点を必ず添えている。
確定した実績と、予測・推計は書き分けている。

> **この年の一行まとめ：2026年の PC・スマホ市場は「AI に部品を奪われた年」。**
> AI データセンター向けの需要がメモリ（DRAM／NAND）を吸い上げ、価格が前年同期比で約2倍に。
> その結果、**端末は値上がりし、台数は減り、安いモデルは市場から消えつつある**。
> AI は端末を売る武器として喧伝されてきたが、実際には最大の逆風として効いている。

---

## 1. メモリ高騰がすべての起点になっている

**何が起きたか。** 生成AI向けデータセンターの建設ラッシュで、
メモリメーカーが HBM（AI向け広帯域メモリ）と高収益なサーバー用途に生産を優先配分した。
その結果、スマホ・PC 向けの汎用 DRAM と NAND が不足し、価格が急騰した。

| 事実                             | 数値・時点                                                                                   |
| -------------------------------- | -------------------------------------------------------------------------------------------- |
| 2026年Q1 のメモリ価格            | 前年同期比で **約2倍**。NAND も同様に約2倍（報道ベース）                                     |
| スマホの 12GB メモリの調達コスト | 200元 → **600元** へ上昇（中国市場、報道ベース）                                             |
| 供給正常化の見通し               | 新ラインの稼働待ちで**早くても2027年以降**。IDC は**2028年初頭より前の根本解消はない**と見る |

```
【2026年のドミノ倒し】

  生成AIブーム
      │
      ▼
  データセンター投資が急拡大 ──▶ HBM・サーバー用DRAMへ生産を優先配分
      │                              → [データセンター](../../04_情報通信・IT・ネット/03_データセンター/README.md)
      ▼
  スマホ・PC向け汎用メモリが不足 ──▶ 価格が前年比約2倍
      │
      ├──▶ 端末の BOM（部品原価）が上昇
      │         │
      │         ├──▶ 値上げ（中国勢は2026年3〜4月に一斉改定）
      │         ├──▶ スペックダウン（メモリ搭載量を削る）
      │         └──▶ 低価格モデルの生産終了
      │
      └──▶ 出荷台数の減少
                │
                ├── スマホ：2026年Q2 世界出荷が13年ぶりのQ2最低水準
                └── PC  ：2026年Q2 で9四半期ぶりの前年割れ
```

## 2. スマートフォン ── 13年ぶりの低水準

**2026年第2四半期（4〜6月）の実績**。調査会社によって集計定義が違うため、数字に幅がある。

| 調査会社         | 世界出荷         | 前年同期比                                        |
| ---------------- | ---------------- | ------------------------------------------------- |
| **IDC**          | **2億7,630万台** | **−7.4%**                                         |
| **Counterpoint** | （台数非公表）   | **−11%**。**2013年以来、第2四半期として最低水準** |
| **Omdia**        | （同上）         | −4%                                               |

**メーカー別（IDC、2026年Q2）**

| メーカー    | 出荷台数  | シェア | 前年同期比 |
| ----------- | --------- | ------ | ---------- |
| **Samsung** | 6,270万台 | 22.7%  | **+8.1%**  |
| **Apple**   | 5,570万台 | 20.2%  | **+14.9%** |
| **Xiaomi**  | 3,120万台 | 11.3%  | **−26.4%** |

> **注目すべきは、上位5社で伸びたのが Apple と Samsung の2社だけだったこと。**
> 理由ははっきりしている。**メモリ高騰は安い端末ほど痛い**からである。8万円の端末で
> 部品代が5,000円上がれば価格に転嫁するしかないが、15万円の端末なら吸収の余地がある。
> Xiaomi・OPPO・vivo はエントリー〜ミドル価格帯の比率が高く、直撃を受けた。Samsung は
> 自社でメモリを作っているため、部品部門の利益が端末部門を支える構造になっている。

通年の見通しは発表元で割れている。「前年比 2.1%減」とする穏当な予測がある一方、
**「過去最大の年間減少率になり、低迷は2027年まで深刻化する」**との見方も報じられている
（いずれも調査会社の予測であり、確定値ではない）。

## 3. PC ── 駆け込みの反動と、低価格モデルの消滅

| 時点             | 世界出荷             | 前年同期比                | 説明                                   |
| ---------------- | -------------------- | ------------------------- | -------------------------------------- |
| 2026年Q1         | —                    | **+3.2%**（Counterpoint） | **値上げ前の先回り需要**。実需ではない |
| 2026年Q2         | **6,820万台**（IDC） | **−4.9%**                 | 9四半期続いた成長が止まった            |
| 2026年通年見通し | —                    | **約11%減**（IDC）        | メモリ不足が主因                       |
| 米国2026年見通し | —                    | 約13%減（報道ベース）     |                                        |

さらに 2026年は **Windows 10 のサポート終了（2025年10月14日）による特需の反動**が重なる。

| 日本市場（MM総研）  | 数値                              |
| ------------------- | --------------------------------- |
| 2025年度 国内PC出荷 | **1,805万台**（過去最大）         |
| 2026年度 予測       | **約1,123万台（前年度比 4割減）** |

**「低価格モデル消滅」が繰り返し報じられる理由**は単純な算数にある。

```
  5万円のノートPC（メモリ8GB＋SSD 512GB）の場合
   従来    メモリ・SSD の原価 ≒ 8,000円 → 売価の16%
   2026年  同じ構成の原価     ≒16,000円 → 売価の32% ▲この増分を吸収できない
       ├─ 値上げする      → 5万円のPCが7万円に。売れない
       ├─ 容量を減らす    → 8GB→4GB。Windows がまともに動かない
       └─ 作るのをやめる  → ★実際に起きている選択
```

## 4. 日本市場 ── 「1円スマホ」の終わりと中古の拡大

| トピック                          | 内容                                                                                                                                                                                                         |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **1円端末の消滅**                 | 端末原価そのものが上がり、法定の値引き上限（原則 税抜4万円）いっぱいに値引いても1円にならない。MM総研は2026年のスマホについて「1円端末終了か」と指摘したと報じられる                                         |
| **中古スマホが7年連続で過去最高** | 2025年度の国内中古販売は **360.7万台**（前年度比+12.4%）。2026年度は **396万台（+9.8%）**の予測。メモリ高騰で新品が高くなり、さらに拡大するとされる（MM総研、2026年7月発表）                                 |
| **新品出荷**                      | 2025年度の国内新品スマホ出荷は **3,132.8万台**。新品＋中古に占める中古比率は **10.3%**                                                                                                                       |
| **値引き規制の見直し議論**        | 総務省が2025年12月に「利用者視点を踏まえたモバイル市場の検証に関する専門委員会」を設置し、電気通信事業法27条の3の見直し議論を開始。ミリ波対応端末の割引上限を時限的に最大1.5万円引き上げる案も検討されている |

> **構図：メモリ高騰と値引き規制が、同じ方向に効いている。**
> どちらも「新品の実質負担を上げる」効果を持つため、
> 結果として**中古と長期利用に需要が逃げる**。
> 日本市場では、この2つが重なった 2026年が中古の分岐点になる可能性がある。

## 5. 供給側 ── Apple の好調と、EMS の関心の移動

**Apple**（2026年度第2四半期＝2026年1〜3月期）

| 項目         | 数値                                                      |
| ------------ | --------------------------------------------------------- |
| 売上高       | **1,111.8億ドル**（前年同期比 +17%、3月期として過去最高） |
| 純利益       | 295.8億ドル（+19%）                                       |
| iPhone 売上  | 569.9億ドル（3月期として過去最高）                        |
| サービス売上 | 309.8億ドル（過去最高）                                   |

台数が縮む市場で、**上位が伸びて下位が縮む**という二極化が鮮明に出ている。
Counterpoint の推計では、Apple は 2025年通年でスマホ出荷シェア約20%を取り、
業界の営業利益の **75〜85%** を占めるとされる。

**EMS / ODM 側**

| 事実                       | 内容                                                                                    |
| -------------------------- | --------------------------------------------------------------------------------------- |
| Foxconn（鴻海）2026年Q1    | 売上 約666億ドル。AIサーバー収入が30%増。一方で**粗利率は5.88%**（前年同期6.15%）に低下 |
| AIサーバーラック組立       | Foxconn が約40%のシェアと報じられる。Quanta は NVIDIA 向け受注の25〜30%との推計         |
| Wistron                    | 2025年に売上 NT$2兆超で、Quanta を初めて追い抜いたと報じられる                          |
| Pegatron・Compal・Inventec | AIサーバーの初期の波に乗り遅れたが、2026年に本格参入                                    |

> **読み方：受託製造の主戦場が、スマホ・PC から AI サーバーへ移っている。**
> AI サーバーは1台（1ラック）の単価が桁違いに大きいため、同じ薄い利益率でも絶対額が稼げる。
> スマホの組立という仕事は、業界内での相対的な魅力を落としている。

## 7. 全体の構図（3〜5行まとめ）

1. **2026年の端末市場は、AI にリソースを奪われた側として整理できる。**
   メモリがデータセンターに流れ、端末は値上がりし、台数が減った。
2. **痛みは均等ではない。** 安い端末ほど原価上昇の比率が高いため、
   中国勢とエントリー市場が最も削られ、Apple と Samsung はむしろシェアを伸ばした。
3. **PC は「特需の反動 × メモリ高騰」の二重の谷**にいる。日本市場は2026年度4割減の予測。
4. **需要は消えるのではなく、後ろにずれ、中古と長期利用に逃げる。**
   中古スマホが7年連続で過去最高というのはその現れ。
5. **回復の条件はひとつ、メモリの供給。** 各社とも2027〜2028年を見ている。
   それまでは「台数は減るが単価は上がる」という歪んだ市場が続く。

## 8. 用語メモ

| 用語                             | 意味                                                                                                                   |
| -------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| **HBM**                          | High Bandwidth Memory。DRAM を積層した AI 向け広帯域メモリ。ここに生産が優先配分されたことが端末用メモリ不足の直接原因 |
| **先回り需要（プルイン）**       | 値上げや供給不安の前に買っておく動き。翌四半期以降の需要を食うため、後の落ち込みを深くする                             |
| **スペックダウン**               | 価格を据え置くためにメモリ容量などを下げること。2026年に頻発すると見られている                                         |
| **1円端末**                      | 通信契約とセットで端末を実質1円で販売する手法。法定の値引き上限と原価上昇で成立しにくくなった                          |
| **27条の3**                      | 電気通信事業法の条文。端末値引きの上限を定める。2026年時点で総務省が見直しを議論中                                     |
| **BB比／出荷シェアと利益シェア** | 端末産業では台数シェアと利益シェアが大きく乖離する。台数だけ見ても産業の実態は分からない                               |
