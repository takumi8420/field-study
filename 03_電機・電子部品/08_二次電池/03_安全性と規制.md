# 二次電池｜安全性と規制

**このノートで分かること**：民生用リチウムイオン電池がなぜ「規制で形が変わる部品」なのか。
PSE（電気用品安全法）、航空輸送規制、リコール、そして廃棄時の火災という4つの局面を、
制度の仕組みとして整理する。

> 一言でいうと：**この部品は、消費者が自分で買い、持ち歩き、最後に捨てる**。
> 車載電池のようにメーカーが最後まで管理できないため、
> **規制が製品設計そのものを決める**構造になっている。

熱暴走（発熱が自己加速して止まらなくなる現象）の原理と材料側の対策は
[蓄電池｜電池の仕組みと種類](../../01_注目テーマ/04_蓄電池/01_電池の仕組みと種類.md) を参照。
ここでは**使われ方・流通・制度**の側面に絞る。

## 1. なぜ小さい電池ほど事故が表に出るのか

事故件数そのものは容量に比例しない。表に出やすい理由は**使われ方**にある。

| 要因           | 車載・定置用                 | 民生用（特にモバイルバッテリー）           |
| -------------- | ---------------------------- | ------------------------------------------ |
| 誰が管理するか | メーカー・事業者が設置・保守 | **消費者本人**。点検も交換判断もしない     |
| 使用環境       | 温度管理された筐体内         | 車内放置、布団の上、カバンの中             |
| 物理的ストレス | 固定されている               | **落とす・踏む・圧迫する**が日常的に起きる |
| 充電器         | 純正・専用                   | 汎用USB、社外品、粗悪品が混ざる            |
| 寿命の扱い     | 交換時期を管理               | 膨れても使い続ける                         |
| 廃棄           | 事業者が回収                 | **家庭ごみに混ざる**（第6章）              |

```
民生電池の事故に至る典型パターン

 ①製造起因   異物混入・電極の巻きずれ ──┐
 ②設計起因   保護回路の不足・放熱不足 ──┤
 ③使用起因   圧迫・落下・高温放置     ──┼──▶ 内部短絡 ──▶ 熱暴走 ──▶ 発火
 ④充電起因   粗悪充電器・過充電       ──┤
 ⑤劣化起因   膨れたまま使用           ──┘
```

規制はこの5経路それぞれに手を打っている。①②には技術基準と第三者検査、
③④には輸送・使用ルール、⑤にはリコールと回収制度が対応する。

## 2. PSE（電気用品安全法）の仕組み

日本国内で電気用品を販売するには、**電気用品安全法（電安法）**に基づく手続きが要る。
ポイントは「誰が責任を負うか」が制度で決まっていることである。

```
[事業届出] ──▶ [技術基準への適合確認] ──▶ [検査記録の保存] ──▶ [PSEマーク表示] ──▶ 販売
 製造事業者      基準に合っているか          3年以上保存          本体・包装に
 または輸入者                                                    表示して出荷
      ▲
  ここに書かれた名前の事業者が、リコール・報告の義務を負う
```

電気用品は2つに分かれる。

| 区分                 | マーク                | 手続き                                                               | 代表例                                                   |
| -------------------- | --------------------- | -------------------------------------------------------------------- | -------------------------------------------------------- |
| **特定電気用品**     | **ひし形PSE（◇PSE）** | 事業届出＋技術基準適合＋**登録検査機関（第三者）の適合性検査**が必要 | 電源コード、ACアダプタ、直流電源装置など危険性が高いもの |
| **特定電気用品以外** | **丸形PSE（○PSE）**   | 事業届出＋技術基準適合＋**自主検査**                                 | 従来のモバイルバッテリー、リチウムイオン蓄電池など       |

モバイルバッテリーは2019年2月から丸形PSEの規制対象になった。
ただし**検査は事業者の自主検査**でよく、第三者が工場を見るわけではない。
ここが弱点として指摘されてきた。

### 2026年の見直し方針

2026年8月の報道によれば、経済産業省はモバイルバッテリーを**「特定電気用品」に指定**し、
国の登録を受けた**第三者機関による検査を製造・輸入事業者に義務づける**方針を示した。

- 背景：モバイルバッテリーの事故が**4年で約4倍**に増えたとされる
- 内容：丸形PSE（○）から**ひし形PSE（◇）**へ移行。製品検査だけでなく**製造工程・工場の品質管理**まで確認する
- 技術基準も見直し、**異物混入の防止、電極の巻きずれ防止**などを義務づける方向
- スケジュール：2026年度内に政省令を改正し、**2027年3月にも施行**して第三者検査を開始する見通しと報じられる

> なぜこれが効くのか：熱暴走の原因の多くは**製造ばらつき**にある。
> 完成品を抜き取り検査しても、数千個に1個の異物混入は見つけにくい。
> **工場の品質管理を見に行く**方式に変えることが、確率的な不良を減らす唯一の現実解とされる。

産業への影響は明確で、**検査・認証コストと工場監査に耐えられない低価格輸入品は退出圧力を受ける**。
逆に、パック設計とトレーサビリティを持つ事業者（→[02_セル・パック・セットの取引構造](02_セル・パック・セットの取引構造.md)）には追い風になる。

## 3. 航空輸送の規制

リチウム電池は航空危険物である。ルールは**Wh（ワット時定格量）**で決まる。

| 対象                                | 機内持ち込み         | 預入手荷物 |
| ----------------------------------- | -------------------- | ---------- |
| 機器に内蔵された電池（160Wh以下）   | 可                   | 可         |
| **モバイルバッテリー（160Wh以下）** | **可（1人2個まで）** | **不可**   |
| 160Wh超のリチウム電池               | 不可                 | 不可       |

（成田国際空港の案内をもとに整理。個数・容量の運用は航空会社で差があるため、搭乗前に各社の最新案内で確認する）

**モバイルバッテリーを預入手荷物に入れられない理由**は単純で、
貨物室では発火しても乗務員が気付けず消火できないからである。
逆に言えば「**人の目が届く場所に置く**」ことが規制の設計思想になっている。

### 2026年4月24日からの変更

ICAO（国際民間航空機関）の国際基準変更と国土交通省の指針改正に伴い、
**2026年4月24日搭乗分から**、日本の主要航空会社で取り扱いが変更された。要点は次の通り。

- モバイルバッテリーを**座席上の収納棚に入れず、座席ポケットなど手元で保管**する
- **機内の電源からモバイルバッテリーへ充電することを禁止**
- モバイルバッテリーから電子機器への充電も控えるよう求める
- 端子部をテープで絶縁する、袋に入れるなどの短絡防止措置

「容量規制の強化」ではなく「**見える場所に置かせる**」方向の改正である点が特徴で、
これは機内での発火事案が実際に起きたことへの対応とされる。

なお、電池を輸送するには国連の試験基準 **UN38.3**（高度シミュレーション、熱、振動、衝撃、
外部短絡、過充電など8項目）への適合が必要で、これはセルを作る段階から必須の関門になっている。

## 4. リコール：回収できないという構造問題

不具合が見つかったときの制度上の流れはこうなる。

```
事故発生 ──▶ 事業者が把握 ──▶ 重大製品事故なら消費者庁へ報告
                                   │
                            NITE（製品評価技術基盤機構）が原因究明
                                   │
                            リコール（回収・交換・返金）公表
                                   │
                            ▼
                       告知 → 消費者が申し込む → 回収
                                   ▲
                        ここで止まる。届かない・気付かない
```

象徴的な事例として、アンカー・ジャパンが輸入した Anker Power Bank（10000mAh, 22.5W）のリコールがある。

- 対象は**40万1,771台**を超えるとされる
- **回収率は2026年1月13日時点で21.6%**にとどまると報じられる
- リコール公表後の2026年4〜6月にも、対象機種（A1652、A1263 等）で
  充電中の焼損事故が複数件発生したと報じられている

> ここが民生電池特有の難所：**8割近い製品が市中に残ったまま**になる。
> 車載であれば車台番号で追跡できるが、モバイルバッテリーは
> **誰が持っているか分からない**。だから「回収」ではなく「事前の品質」でしか解決できない、
> というのが2026年のPSE見直し（第2章）の論理につながっている。

## 5. 表示・トレーサビリティという地味な論点

事故が起きたとき、原因を特定できるかどうかは**どのロットのセルが、どの製品に入ったか**を
追えるかで決まる。ここが製品によって大きく違う。

| 水準                   | できること                                             | 典型                             |
| ---------------------- | ------------------------------------------------------ | -------------------------------- |
| **高**（産業・医療）   | 製品番号からセルのロット、製造日、検査値まで遡れる     | 医療機器、産業機器のパック       |
| **中**（大手民生）     | 製品ロット単位で対象を絞れる。リコール範囲を限定できる | 大手ブランドのモバイルバッテリー |
| **低**（低価格輸入品） | どこのセルか分からない。全数回収か放置かの二択になる   | ノーブランド品、通販専売品       |

**トレーサビリティの水準は、そのままリコール時のコストになる**。
対象を絞れない企業は、全数回収か、回収しないかの極端な選択を迫られる。

## 6. 廃棄：いま最も件数が増えている事故

事故は「使用中」より「**捨てられた後**」に多く起きている。

- 環境省・政府広報によれば、リチウムイオン電池が原因とみられる**ごみ処理時の火災事故等の発生件数**は
  **2022年度 4,260件 → 2023年度 8,543件**と、1年で倍増した
- 収集車の圧縮機や破砕機で電池が潰れ、内部短絡して発火する
- 施設によっては復旧に**数億円**を要した例、ごみ収集が長期間停止した例も報告されている

制度面では、**改正資源有効利用促進法が2026年4月1日に全面施行**され、
スマートフォン、**モバイルバッテリー**、加熱式たばこが**「指定再資源化製品」**に指定された。
メーカー・輸入事業者に回収・再資源化の義務が課される。

| 製品               | 対象となる事業者の目安（報道ベース） |
| ------------------ | ------------------------------------ |
| モバイルバッテリー | 年1,000台以上の生産・輸入販売        |
| スマートフォン     | 年1万台以上                          |
| 加熱式たばこ       | 年30万台以上                         |

> 構造としては、**EU電池規則が輸入品に課している生産者責任と同じ方向**を、日本も国内制度で取り始めた
> と読める（EU側は [蓄電池｜サプライチェーンと資源](../../01_注目テーマ/04_蓄電池/03_サプライチェーンと資源.md) 参照）。
> 電池を「売って終わり」にできなくなることは、**安いだけの輸入品にとって最も重いコスト**になる。

## 7. 規制が産業構造を変える

以上をまとめると、規制は次の順で効いてくる。

```
 事故増加 ──▶ 規制強化 ──▶ 認証・検査・回収コスト増 ──▶ 小規模／低価格事業者の退出
                                     │
                                     ▼
                       品質管理とトレーサビリティを持つ事業者に集約
                                     │
                                     ▼
                     製品価格の上昇（安全のコストが価格に乗る）
```

- **短期**：対応コストで製品価格が上がる。売価が数百円上がっても不思議ではない
- **中期**：PSE・回収義務に耐えられる事業者へ集約が進む
- **長期**：安全性を訴求できる方式（**全固体電池**など）の商品価値が上がる。
  民生・産業用の全固体電池を日本勢が狙っているのは、この文脈でも説明できる
  （→[04_直近トピック_2026](04_直近トピック_2026.md)）

## 用語メモ

- **電気用品安全法（電安法）／PSE**：電気用品の安全を定める日本の法律と、その適合表示マーク
- **特定電気用品（◇PSE）**：危険性が高いとされ、登録検査機関による適合性検査が要る区分
- **特定電気用品以外（○PSE）**：自主検査で足りる区分。モバイルバッテリーは従来こちら
- **登録検査機関**：国に登録された第三者検査機関
- **UN38.3**：リチウム電池を輸送するための国連の試験基準。8項目の試験からなる
- **Wh（ワット時定格量）**：航空規制の判断基準。Wh＝mAh×公称電圧÷1000
- **ICAO**：国際民間航空機関。航空危険物の国際基準を定める
- **NITE**：製品評価技術基盤機構。製品事故の原因究明と情報提供を行う独立行政法人
- **重大製品事故**：死亡・火災など重大な被害を伴う事故。事業者に消費者庁への報告義務がある
- **指定再資源化製品**：資源有効利用促進法で、メーカー等に回収・再資源化が義務づけられる製品
- **トレーサビリティ**：どのロットの部材がどの製品に入ったかを追える仕組み
