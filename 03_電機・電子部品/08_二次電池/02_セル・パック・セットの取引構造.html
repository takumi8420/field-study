二次電池｜セル・パック・セットの取引構造

電機・電子部品二次電池
あこのページの単語集用語に触れると意味を確認できます12語
PSEの届出事業者が誰か長期供給品のラストバイ告知セルパックPCM／PCB（保護回路モジュール）BMSセルバランス二次ソースクオリフィケーション（認定）4M変更ラストバイPPM

このノートで分かること：電池が「セル」のまま売られることはほとんどなく、
パック（保護回路と筐体を付けた状態）になって初めて機器に載ること。
そして、セルの量産で稼ぐ会社と、パック・BMSの設計で稼ぐ会社は別の会社であることが多い、という分業の形。

一言でいうと：セルは装置産業、パックは設計・責任引受のビジネスである。
セルは工場の稼働率で利益が決まるが、パックは「安全を保証して名前を出す」ことに対価が付く。

電池の材料・工程そのものは 蓄電池｜製造工程 を参照。
ここでは取引関係と付加価値の付き方に絞る。

取引の実務では、次の3パターンが混在している。

パターン 誰がパックを作るか 典型例 特徴

ポイント：セットメーカーが「電池メーカー」と呼ぶ相手は、必ずしもセルを作っていない。
ニュースで「◯◯社の電池が発火」と出たとき、セル・パック・完成品のどの層の話かを切り分けないと、
責任の所在も対策も読み違える。

2. セルの「認定」という関門

セルは買ってきてすぐ使えるわけではない。セットメーカーは機種ごとに認定（クオリフィケーション）を行う。

セル選定 ──▶ サンプル評価 ──▶ 安全試験 ──▶ 量産ライン監査 ──▶ 量産認定 ──▶ 量産
 仕様合致    容量・寿命・膨れ   UN38.3等   工程・トレーサビリティ   ロット管理
 （3〜6か月）                              （工場まで見に行く）

ここが参入障壁になる。理由は3つ。

  1. 時間がかかる。評価だけで半年、量産認定まで含めると1年近くかかることもある
  2. 工場ごとに認定する。同じ会社の同じ型番でも、別工場・別ラインなら再認定が必要になるのが通例
  3. 一度認定したセルは変えにくい。変えれば再評価と再認証（PSE、UN38.3など）が要る

このため、セットメーカーは二次ソース（second source＝同じ仕様を2社以上から買える状態）を確保したがる。
1社依存だと、災害・事故・値上げ交渉で一気に弱くなるからである。
逆にセルメーカー側は、独自形状・独自仕様を作って乗り換えコストを上げる動機を持つ。
この綱引きが、民生電池の値決めの実態を作っている。

3. パックとは何か

「電池パック」は、セルに次のものを足して初めて完成する。

構成要素 役割 ないとどうなるか
セル電気をためる本体—
保護回路（PCM／PCB）過充電・過放電・過電流・短絡を検知して遮断充電器の故障でそのまま過充電され、熱暴走に至る
サーミスタ（温度センサ）温度を測り、異常時に充電を止める高温・低温充電による劣化と析出を防げない
ヒューズ／PTC素子最終手段として電流を物理的に切る保護ICが壊れたときの砦がなくなる
セル間の接続（タブ溶接）複数セルを直列・並列につなぐ接触抵抗で発熱する。溶接品質が寿命を左右する
筐体・絶縁材変形・異物・衝撃からセルを守る圧迫による内部短絡が起きやすくなる
通信（SMBus／I2C 等）残量や健全度を機器に伝える「残量表示」ができない

  │  ┌──────┐ ┌──────┐   温度センサ●   │
  │  │ セル │ │ セル │ ← タブ溶接       │──▶ 機器へ
  │  └──────┘ └──────┘                  │    （＋／−／通信）
  │        ▲                              │
  │   保護回路(PCM) ─ ヒューズ ─ 端子     │
  └────────────────────────────────────┘
        「安全を担保する層」が、この箱の中身

セルは中国・韓国製でも、パック設計と検査は日本・台湾、という分業がよく見られる。
セル単体の価格競争には勝てなくても、パックの設計・安全保証・トレーサビリティ（どのロットのセルが
どの製品に入ったかを追える仕組み）では価値を出せるからである。

4. 民生の「保護回路」と、産業・車載の「BMS」は別物

BMS（Battery Management System＝電池の制御コンピュータ）の基本は
蓄電池｜電池の仕組みと種類 で扱っている。
ここでは民生と産業・車載で、同じ「BMS」という言葉の中身が大きく違う点を押さえる。

観点 民生用（保護IC／PCM中心） 産業・車載用（本格BMS）
セル数1〜4直列程度数十〜数百直列
主な機能過充電・過放電・過電流・短絡の遮断、温度監視＋ セルバランス、SOC/SOH推定、絶縁監視、冷却制御、故障診断
演算専用ICで完結。マイコンなしの構成も多いマイコン／MCU＋制御ソフト。通信はCANなど
ソフトほぼファームウェア固定アルゴリズムが競争要素。推定精度が製品寿命に直結
単価に占める比率数%10%を超えることもある
誰が作るか保護ICメーカー＋パックメーカー電池メーカー、セットメーカー、専業BMS企業

なぜ差が出るか：直列数が増えるほど「一番弱いセル」が全体を縛るため、
セルのばらつきを均す仕事（セルバランス）が不可欠になる。
1〜2直列の民生機器ではこの問題が小さく、遮断機能だけで足りてしまう。

このため民生用パックの付加価値は、BMSのアルゴリズムよりも
「壊れない構造」と「不良を出荷しない検査」に寄っている。

5. 付加価値はどこに付くか

概算のイメージとして、民生用パックのコストは次のように分かれる（機種・構成で大きく振れる）。

 民生パックのコスト構成（イメージ）

  セル          ████████████████████████████  60〜80%
  保護回路・部材 ██████                        10〜20%
  組立・検査     ████                           5〜15%
  物流・認証     ██                             数%
  • セルが圧倒的。つまりパックメーカーの利益率は、セルの調達力でほぼ決まる
  • パックメーカーが利益を出す道は3つ：
    1. 設計で部材を減らす（構造を簡素化し、溶接点を減らす）
    2. 不良率を下げる（工程内検査を増やして、出荷後のリコールを避ける）
    3. 責任を引き受ける対価を取る（PSEの届出事業者になる、保証を持つ）
  • 3つめが重要で、日本国内で売るならPSEの責任を誰かが負わなければならない。
    この「名前を出す役」に価値があるため、商社・OEM元が担うことも多い
    （→ 03_安全性と規制）

6. 値決めと在庫：この商売の痛点

痛点 何が起きるか 対策の実際
年次の値下げ要求セットメーカーは毎年数%の単価低減を求める設計変更（部材削減）で吸収。吸収できないと撤退
機種専用寸法機種が売れないと在庫が転用できない発注ロットを小さく刻む、汎用円筒形を提案する
材料価格の転嫁ラグリチウム・ニッケルが上がっても値上げは次の改定まで待つ材料連動条項を入れられるかが交渉の焦点
長期供給義務産業・医療機器は10年以上の供給を求める生産終了時のラストバイ（最終一括購入）で対応
認定の縛り工場移管・材料変更に再認定が要る変更管理（4M変更）の手続きを顧客と握っておく

7. 日本勢の現在地：車載から民生・産業への棲み分け

車載電池では中国・韓国勢が量で圧倒的になった（蓄電池｜サプライチェーンと資源）。
その結果、日本のセルメーカーは「量で勝てない領域から降り、特性で勝てる領域に寄る」という動きを取っている。

企業 主戦場 現在地（2026年時点の公表・報道ベース）
パナソニックエナジー車載円筒形＋民生・産業用円筒形＋一次電池車載が主力だがEV減速の影響を受け、パナソニックHDは2026年3月期業績見通しを下方修正（純利益29%減と報じられる）。一方でデータセンター向け蓄電池が支える構図。国内向け乾電池・ニッケル水素等は2026年9月出荷分から平均約10%値上げ
村田製作所小型円筒形・ラミネート型、酸化物系全固体電池2017年にソニーから電池事業を取得。ウェアラブル（イヤホン等）向けの小型全固体電池を量産化し、電子部品の販路と組み合わせる
マクセルボタン形・コイン形、円筒形、産業機器向け全固体電池高温環境の工場・プラント向けなど「置き換えが難しい用途」に集中。産業機器向け全固体電池の量産を2026年度にも開始すると報じられる
FDKニッケル水素電池、一次電池乾電池互換の充電池と産業用途が中心。全固体・ニッケル亜鉛など次世代電池の開発も進める
GSユアサ鉛蓄電池、産業用リチウムイオン自動車始動用・産業用の鉛で国内基盤。宇宙・防衛・潜水艦など特殊用途にも強い
東芝SCiB（チタン酸リチウム系）急速充電と長寿命、低温性能に振った特殊系。鉄道・産業車両・バス向け

日本勢に共通する勝ち筋は次の3つに整理できる。

  1. 高温・低温・長寿命など「量産品が苦手な条件」に絞る（マクセル、東芝）
  2. 極小サイズや新方式で先に出す（村田の酸化物系全固体）
  3. 一次電池・ニッケル水素の販売網とブランドを守る（パナソニック、FDK）

裏返すと、汎用スマホ用ラミネートセルの価格競争からは、日本勢はほぼ降りている。
ここは中国・韓国勢の土俵であり、日本の存在感は
蓄電池｜サプライチェーンと資源 にある通り、
セルよりも材料（セパレータ・電解液・負極材）と製造装置の側に残っている。

8. この構造を見るときの指標

  • セットメーカーの二次ソース比率：1社依存か複数社か。供給リスクの大きさが分かる
  • パックメーカーの歩留まりと市場不良率（PPM）：安全ビジネスの実力
  • PSEの届出事業者が誰か：責任を誰が引き受けているかが製品ラベルで分かる
  • セルメーカーの民生／車載の売上構成：需要変動の受け方がまるで違う
  • 長期供給品のラストバイ告知：産業機器向けの事業継続性の兆候

用語メモ

  • セル：電池の最小単位。1本・1枚のこと
  • パック：セル＋保護回路＋筐体をまとめた完成部品。機器に載るのはこの状態
  • PCM／PCB（保護回路モジュール）：過充電・過放電・過電流を遮断する回路。民生用BMSの中核
  • BMS：電池の監視・制御システム。民生では保護ICで完結、産業・車載ではソフトが競争要素になる
  • セルバランス：直列につないだセルの電圧ばらつきを均す機能
  • 二次ソース：同一仕様を複数社から調達できる状態。供給途絶と値上げへの保険
  • クオリフィケーション（認定）：セル・工場が量産に使えるかを顧客が確認する手続き
  • 4M変更：人・機械・材料・方法の変更。届け出と再評価の対象になる
  • ラストバイ：生産終了前の最終一括購入。長期供給が必要な産業機器で使われる
  • PPM：百万個あたりの不良数。民生部品の品質指標
