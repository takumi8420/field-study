### 最初に押さえる一行

> **民生用電池は「小さい部品」ではなく「消費者の手元で燃えうる部品」**である。
> だから技術競争より先に、**規制・認証・回収の設計**が事業の形を決める。
> 2026年はその規制が一斉に動いた年だった。

## 1. 業界の定義・範囲

**二次電池＝充電して繰り返し使える電池**。使い切りの一次電池（乾電池等）の対語。
本フォルダは、そのうち**機器に組み込まれる部品としての電池**を扱う。

範囲は「セル」だけではない。実務では次の3層をまとめて「電池」と呼ぶ。

```
[セル]      電池の最小単位。1本・1枚。ATL、パナソニック、Samsung SDI 等が作る
   ↓
[パック]    セル＋保護回路＋温度センサ＋筐体。ここで初めて機器に載る
   ↓
[機器]      スマホ、PC、電動工具、掃除機、モバイルバッテリー、産業機器
```

## 2. 市場規模と成長性

| 指標                                        | 数値                                                    | 年・出典                                                 |
| ------------------------------------------- | ------------------------------------------------------- | -------------------------------------------------------- |
| 国内 リチウムイオン電池 販売数量            | **375,129千個**（約3.8億個）                            | 2025年度／電池工業会 自主統計（会員各社報告）            |
| 同（直近5年の推移）                         | 417,850 → 310,483 → 243,555 → 306,454 → 375,129（千個） | 2021〜2025年度／同上                                     |
| 国内 アルカリ蓄電池（ニカド＋ニッケル水素） | 165,706千個                                             | 2025年度／同上                                           |
| 国内 自動車用鉛蓄電池                       | 15,968千個                                              | 2025年度／同上（2023年度以降は二輪車用を含まない）       |
| 民生用電子機器向けLIBの成長率               | 年7〜8%程度                                             | 2026〜2032年の予測／調査会社の推計。定義により幅が大きい |
| スマホ用電池シェア（世界）                  | ATL約42%、LGES約22%、Samsung SDI約18%                   | 2021年時点の集計。近年の推計ではATLは3〜4割水準とされる  |

**読み方の注意**：民生用は容量（GWh）ではなく数量（個）で語られる。
車載と同じ物差しで比べると規模を見誤る。
また国内統計は会員企業の報告ベースであり、世界市場のシェアとは別物である。

> 押さえるべき性格：**成長市場ではなく、循環（サイクル）市場**。
> 2021年度から2023年度にかけて数量が4割以上落ち、その後2年で戻している。
> スマホ・PCの買い替えサイクルと在庫調整がそのまま出る、電子部品と同じ振れ方をする。

付加価値の付き方は層ごとに違う。

| 層         | 利益の源泉                           | 経済的な性格                                           |
| ---------- | ------------------------------------ | ------------------------------------------------------ |
| 材料       | 配合・品質の作り込み                 | 少数寡占。日本勢が残る領域                             |
| **セル**   | **量産規模と歩留まり**               | 装置産業。稼働率が落ちた瞬間に赤字になる               |

| セット     | ブランドと販路                       | 電池は原価の一部。ただし事故が起きれば全責任を負う     |

## 5. 収益モデル・コスト構造

**セルメーカー**（装置産業）

- 固定費（設備償却）が重く、**稼働率がそのまま利益率**になる
- 品種切替の段取りが多い民生用では、**切替時間と歩留まり**がコストを左右する
- 機種専用寸法のセルは、機種が売れなければ在庫が転用できない

**パックメーカー**（設計・責任引受ビジネス）

```
 民生パックのコスト構成（イメージ）

  セル          ████████████████████████████  60〜80%
  保護回路・部材 ██████                        10〜20%
  組立・検査     ████                           5〜15%
  物流・認証     ██                             数%
```

- 利益率はセルの調達力でほぼ決まる。だから**二次ソース確保**が生命線になる
- 稼ぐ道は3つ：部材を減らす設計、不良率を下げる検査、**責任を引き受ける対価**（PSE届出事業者になる）
- 年次の値下げ要求が恒常的にあり、設計変更で吸収できなければ撤退する

**一次電池・ニッケル水素**（成熟市場）

- 数量成長は見込めず、**価格改定でしか採算を維持できない**
- 2026年9月出荷分からのパナソニックの平均約10%値上げがその典型

## 6. 競争要因（KSF）と参入障壁

| 要因                             | 中身                                       | 効き方                                     |
| -------------------------------- | ------------------------------------------ | ------------------------------------------ |
| **量産規模**                     | セルは装置産業。規模がコストを決める       | 民生汎用セルでは中韓勢に勝てない           |
| **認定（クオリフィケーション）** | 機種ごと・工場ごとの認定に半年〜1年        | **一度入ると外れにくい**。最大の障壁       |
| **安全実績と保証能力**           | 事故時のリコール費用を負える体力           | 規制強化でこの要件が重くなる               |
| **トレーサビリティ**             | どのロットのセルがどの製品に入ったか追える | リコール範囲を絞れるかどうかが生死を分ける |
| **特殊条件への対応力**           | 高温・低温・長寿命・極小サイズ             | 日本勢が残っている領域                     |
| **長期供給の約束**               | 産業・医療で10年以上の供給を求められる     | 価格より重視されることがある               |

> 参入障壁の本質は技術より**時間**。セルを作れても、
> セットメーカーの認定を取るのに1年、実績を積むのに数年かかる。

## 7. 規制・法制度

| 制度                               | 内容                                             | 2026年時点の動き                                                                                                                                       |
| ---------------------------------- | ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **電気用品安全法（PSE）**          | 製造・輸入事業者が届出、技術基準適合、マーク表示 | モバイルバッテリーを**特定電気用品（ひし形PSE）に指定**し、**第三者機関の検査を義務化**する方針。2026年度内に政省令改正、2027年3月にも施行と報じられる |
| **航空危険物規制（ICAO／国交省）** | Wh基準での持ち込み制限、預入禁止                 | **2026年4月24日搭乗分から**、手元保管の義務化と機内充電禁止                                                                                            |
| **消費生活用製品安全法**           | 重大製品事故の報告義務、リコール                 | Anker製品のリコール（回収率21.6%）が制度の限界を露呈                                                                                                   |
| **資源有効利用促進法**             | 指定再資源化製品の回収・再資源化義務             | **2026年4月1日に改正全面施行**。モバイルバッテリー・スマホ・加熱式たばこを指定                                                                         |
| **UN38.3**                         | 輸送のための国連試験基準（8項目）                | セル開発段階から必須の関門                                                                                                                             |
| 化学物質規制（RoHS等）             | カドミウム・鉛等の使用制限                       | ニカド電池の縮小要因                                                                                                                                   |

## 9. 用語メモ

- **二次電池**：充電して繰り返し使える電池。一次電池（使い切り）の対語
- **セル／パック**：電池の最小単位／保護回路と筐体を付けた完成部品
- **セットメーカー**：完成品を作る企業。電池メーカーから見た顧客
- **保護回路（PCM）**：過充電・過放電・過電流を遮断する回路。民生BMSの中核
- **BMS**：電池の監視・制御システム。民生と産業・車載で中身の規模が大きく違う
- **クオリフィケーション（認定）**：セル・工場が量産に使えるかを顧客が確認する手続き
- **二次ソース**：同一仕様を複数社から調達できる状態
- **PSE**：電気用品安全法の適合表示マーク。丸形（○）とひし形（◇）がある
- **Wh（ワット時定格量）**：航空規制の判断基準。mAh×電圧÷1000
- **UN38.3**：リチウム電池輸送のための国連試験基準
- **指定再資源化製品**：回収・再資源化が義務づけられる製品区分
- **18650／21700**：円筒形セルの規格呼称（直径×長さ）
- **ラミネート型（パウチ）**：薄型セル。機種専用外形になりやすい

各ノート末尾にも用語メモを置いている。電池の材料・工程の用語は
