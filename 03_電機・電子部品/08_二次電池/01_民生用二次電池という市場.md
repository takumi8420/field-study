# 二次電池｜民生用二次電池という市場

**このノートで分かること**：スマホ・PC・電動工具・モバイルバッテリーに入る「小さい電池」の市場が、
車載電池とはまったく別の商売であること。そして、なぜリチウムイオン一色にならず
ニッケル水素や鉛蓄電池が生き残っているのか。

> 一言でいうと：**民生用二次電池は「GWh（容量）」ではなく「個（本数）」で数える部品ビジネス**である。
> 車載が1件の商談で数GWh・10年契約を動かす世界なのに対し、
> こちらは**年に何億本**を、数百円以下の単価で、機種ごとの仕様に合わせて流す世界である。

電池そのものの原理・材料・製造工程・資源は
[注目テーマ｜蓄電池](../../01_注目テーマ/04_蓄電池/README.md) 側で詳述している。
このノートは**電機・電子部品の一部品としての電池**に絞る。

## 1. 「民生用」とはどこを指すか

業界では電池の用途を大きく **車載（xEV）／定置用（ESS）／民生・産業機器** の3つに分ける。
このうち3つめが本ノートの範囲で、実務ではさらに細かく割って呼ばれる。

| 区分             | 具体例                                              | 1台あたり容量の目安 | 電池に求められる第一条件         |
| ---------------- | --------------------------------------------------- | ------------------- | -------------------------------- |
| **モバイル機器** | スマートフォン、タブレット                          | 10〜30Wh程度        | 薄さ・体積あたり容量・形状自由度 |
| **ウェアラブル** | 完全ワイヤレスイヤホン、スマートウォッチ            | 0.1〜2Wh程度        | 極小サイズ、安全、発熱の少なさ   |
| **PC**           | ノートPC                                            | 40〜100Wh程度       | 容量と薄さの両立、長期保証       |
| **パワーツール** | 電動工具、電動アシスト自転車、芝刈機                | 100〜500Wh程度      | **高出力（大電流）**と寿命       |
| **生活家電**     | コードレス掃除機、シェーバー、電動歯ブラシ          | 10〜100Wh程度       | コスト、繰り返し寿命             |
| **アクセサリ**   | モバイルバッテリー                                  | 30〜100Wh程度       | 価格、そして**安全（後述）**     |
| **産業機器**     | UPS（無停電電源）、計測器、医療機器、業務用ロボット | 数十Wh〜数kWh       | 信頼性、長期供給、動作温度範囲   |

**境界の引き方**：同じ「小型電池」でも、データセンターのサーバーラックに積むバックアップ電源（BBU）は
定置用として扱われることが多く、[蓄電池｜用途別市場と事業モデル](../../01_注目テーマ/04_蓄電池/04_用途別市場と事業モデル.md) 側で扱う。
「人が持ち歩く／手に取る機器に入る電池」かどうかが、実務上いちばん分かりやすい線引きになる。

## 2. 数量で見る：この市場は「個」で数える

国内の出荷感覚をつかむには、一般社団法人 電池工業会（BAJ）の自主統計が使いやすい。
会員各社の報告に基づく販売数量で、単位は**千個**である。

| 年度         | リチウムイオン電池 | アルカリ蓄電池（ニカド＋ニッケル水素） | 自動車用鉛蓄電池 | 二次電池 合計 |
| ------------ | ------------------ | -------------------------------------- | ---------------- | ------------- |
| 2021年度     | 417,850            | —                                      | —                | —             |
| 2022年度     | 310,483            | —                                      | —                | —             |
| 2023年度     | 243,555            | —                                      | —                | —             |
| 2024年度     | 306,454            | —                                      | —                | —             |
| **2025年度** | **375,129**        | 165,706                                | 15,968           | **560,414**   |

（出典：電池工業会 自主統計「二次電池販売数量年度別推移」。単位は千個。
自動車用鉛蓄電池は2023年度以降、二輪車用を含まない）

読み取れることが3つある。

1. **数量が乱高下する**。2021年度の約4.2億個から2023年度は約2.4億個まで4割以上落ち、
   2025年度に約3.8億個まで戻している。スマホ・PCの買い替えサイクルと在庫調整が、
   そのまま電池の出荷に出る。電子部品と同じ**ブルウィップ効果**（川下の小さな需要変動が、
   川上にいくほど増幅される現象）の世界である
2. **ニッケル水素はまだ1.6億個以上流れている**。「リチウムイオンに置き換わった」は言い過ぎで、
   用途が住み分けている（第4章）
3. **鉛蓄電池は数量では少ないが、1個が重く高い**。個数で見ると規模を見誤る

```
数量の数え方が市場ごとに違う

  車載    ─ GWh（容量） ─▶ 「今年は何百GWh」    …エネルギー量で語る
  定置用  ─ MW×h        ─▶ 「2MW×4時間」        …出力と継続時間で語る
  民生    ─ 個（本数）   ─▶ 「年間◯億個」        …部品の数で語る
                             ＋ mAh・Wh（1本の容量）
```

## 3. 車載電池と何が違うのか

同じリチウムイオン電池でも、**商売の形がまったく違う**。ここが部品産業として見たときの核心である。

| 観点           | 車載電池                               | 民生用電池                                                                                |
| -------------- | -------------------------------------- | ----------------------------------------------------------------------------------------- |
| 顧客           | 自動車メーカー（OEM）、数社に集中      | セットメーカー（スマホ・PC・工具・家電）、多数                                            |
| 開発期間       | 3〜5年。車両開発と一体                 | **半年〜1年半**。機種のモデルチェンジに合わせる                                           |
| 契約の形       | 数年〜10年の供給契約、合弁・専用ライン | 機種ごとの発注。年次で価格改定                                                            |
| ロット         | 1機種で数GWh                           | 1機種で数百万〜数千万本                                                                   |
| カスタム度     | セル設計から共同開発                   | **寸法は機種ごとに別物**。ただし中身の設計は流用                                          |
| 要求寿命       | 8〜10年、走行距離保証つき              | 2〜4年（機器の寿命に合わせる）                                                            |
| 価格の決まり方 | 材料価格連動条項を入れることが多い     | 年次の値決め交渉。**下げ圧力が恒常的**                                                    |
| 在庫リスク     | OEMの計画変更で工場が止まる            | 機種が売れないと**専用寸法のセルが滞留する**                                              |
| 事故のとき     | リコールは車両単位で巨額               | リコールは製品単位だが、**消費者の手元で燃える**（[03_安全性と規制](03_安全性と規制.md)） |

> ポイント：車載は「大口1社を取れば工場が埋まる」ビジネス、
> 民生は「機種ごとの寸法違いを大量に回す」ビジネス。
> 前者は**稼働率**、後者は**品種切替の段取りと歩留まり**が利益を決める。

寸法の話は軽視されがちだが重要で、スマホ用のラミネート型セルは**機種専用の外形**になる。
機種が売れなければそのセルは他に転用できない。
逆に電動工具や掃除機で使う円筒形（18650、21700 など規格化された外径・長さ）は汎用性が高く、
在庫リスクが小さい。**形状の標準化度合いが、そのまま事業リスクの大小になっている**。

## 4. 用途ごとに電池の種類が違う理由

「性能が高いリチウムイオンが全部置き換える」とはならなかった。理由は、
**機器ごとに効く物差しが違う**からである。

| 電池の種類                | 電圧（1セル） | 残っている理由                                                                               | 主な用途（2020年代）                             |
| ------------------------- | ------------- | -------------------------------------------------------------------------------------------- | ------------------------------------------------ |
| **リチウムイオン（LIB）** | 3.6〜3.7V     | 体積・重量あたり容量が圧倒的。1セルで機器を動かせる                                          | スマホ、PC、工具、掃除機、モバイルバッテリー     |
| **ニッケル水素（NiMH）**  | 1.2V          | **乾電池と互換の形・電圧**。過充電に強く、低温にも比較的強い。発火リスクが低く輸送・廃棄が楽 | 単3・単4の充電池、コードレス電話、玩具、一部HV車 |
| **ニカド（Ni-Cd）**       | 1.2V          | 大電流放電と低温に強いが、カドミウム規制で縮小                                               | 一部の産業用・非常用                             |
| **鉛蓄電池**              | 2.0V          | **とにかく安い**。過放電に耐え、リサイクル網が確立。重さが問題にならない用途で強い           | 自動車の始動用、UPS、フォークリフト、非常用照明  |
| **一次電池（使い切り）**  | 1.5V 等       | 自己放電が極めて小さく、**10年放置しても動く**。充電器も制御回路も要らない                   | リモコン、時計、火災報知器、非常用               |

### なぜ鉛蓄電池がいまだに使われるのか

UPS（無停電電源装置）を例にすると分かりやすい。UPSは**普段はずっと満充電で待機し、年に数回しか放電しない**。
この使い方では、エネルギー密度（軽さ）よりも次が効く。

- **初期コストの安さ**：kWhあたりの単価は鉛が依然として最安の部類
- **過充電・満充電待機への耐性**：リチウムイオンは満充電で放置すると劣化が進みやすい
- **発火リスクと消防法・設置規制**：設置場所の制約が少ない
- **回収・リサイクルの仕組みが既にある**：自動車用バッテリーの回収網に乗る

逆に、**毎日充放電する**・**軽さが効く**・**大電流が要る**用途ではリチウムイオンが勝つ。
つまり「充放電の頻度」と「重量制約」の2軸で、どの化学系を選ぶかがほぼ決まる。

```
              重量・体積の制約が強い
                        ▲
                        │
       スマホ/PC/工具   │   ドローン/ウェアラブル
        （LIB）         │      （LIB）
  ──────────────────────┼──────────────────────▶ 充放電の頻度が高い
       UPS/非常電源     │   フォークリフト
        （鉛）          │    （鉛→LIBへ移行中）
                        │
        乾電池互換の充電池（ニッケル水素）
```

### 一次電池が消えない理由

火災報知器や時計のように「**電池交換を10年したくない**」機器では、
自己放電の小ささと、充電回路を持たなくてよい単純さが勝つ。
一次電池は成熟市場だが、パナソニックのように**二次電池と一次電池を同じ事業会社で持つ**企業にとっては、
販売網（量販店・ホームセンター）とブランドを維持する土台にもなっている。

民生用セルは、車載とはプレイヤーの並びが違う。**スマホ用ラミネート型では中国のATLが最大手**とされる。

## 6. 価格と収益の見方

民生用は「kWhあたり何ドル」では語られない。**1本（1セル）いくら**、
あるいは**mAhあたりいくら**で語られる世界である。

- 車載・定置用のパック価格はBNEF調査で2025年に世界平均108ドル/kWh（定置用セグメントは70ドル/kWh）まで下がったが、
  これは大量生産・大型セルの数字であり、**民生用小型セルの単価水準とは別物**
  （出典整理は [蓄電池｜用途別市場と事業モデル](../../01_注目テーマ/04_蓄電池/04_用途別市場と事業モデル.md)）
- 民生用は小型・形状多品種のため**kWhあたりでは割高**。代わりに、
  安全設計・薄さ・急速充電対応・認証取得といった付加価値で価格を取る
- 利益を削るのは、**年次の値下げ要求**と**品種切替による設備の段取り替え**
- 市場の伸び自体は緩やか。民生用電子機器向けリチウムイオン電池の成長率を
  年7〜8%程度とする調査会社の推計があるが、調査会社ごとに定義と数字の幅が大きい（2026年時点）

## 7. この市場を見るときの指標

- **スマホ・PCの世界出荷台数**：民生電池の需要そのもの。台数×1台あたり容量で概算できる
- **電池工業会の月別・年度別販売数量**：国内の体温計。品種別の増減が見える
- **セットメーカーの新機種サイクル**：発売の3〜6か月前に電池の発注が立つ
- **炭酸リチウム・ニッケル価格**：材料の体温計。ただし民生では値決めへの反映が遅れやすい
- **リコール・事故件数**：この市場では規制コストが直接収益に効く（[03_安全性と規制](03_安全性と規制.md)）

## 用語メモ

- **民生用（コンシューマ）電池**：消費者向け機器に入る電池。業界では産業機器向けと合わせて語られることが多い
- **セットメーカー**：完成品（スマホ・PC・工具など）を作る企業。電池メーカーから見た顧客
- **18650／21700**：円筒形セルの規格呼称。直径18mm×長さ65.0mm、直径21mm×長さ70mm の意味
- **ラミネート型（パウチ）**：アルミラミネートフィルムで包む薄型セル。機種専用の外形になりやすい
- **mAh／Wh**：mAhは電流容量、Whはエネルギー量。Wh＝mAh×電圧÷1000。航空規制はWhで判断する
- **ニッケル水素電池（NiMH）**：1.2Vの充電池。乾電池と同じ形で作れるのが強み
- **ブルウィップ効果**：川下の小さな需要変動が、川上にいくほど増幅して伝わる現象
