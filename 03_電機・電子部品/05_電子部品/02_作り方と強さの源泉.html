このノートで分かること：MLCC の作り方には秘密の技術がない。
設計図もレシピも公開されている。それでも日本勢が数十年勝ち続けているのは、
「粉から作っている」ことと「不良を出さない歩留まり」という、
真似しにくい2点に理由がある。

ポイント：この産業の競争は「何を作るか」ではなく
「同じものを、1か月に何百億個、不良ゼロで作れるか」の競争である。
1個 0.5円の部品で検査コストをかけられない以上、
最初から不良を出さない工程を持っている会社しか儲からない。

2. なぜ「粉」が勝敗を決めるのか

MLCC の誘電体は チタン酸バリウム（BaTiO₃） という白いセラミック粉である。

   ＜層を薄くすると何が起きるか＞

   層の厚み 3μm 時代                 層の厚み 0.5μm 時代
   ┌──────────────┐            ┌──────────────┐
   │ ●   ●   ●  ●  │ 粉の粒     │ ●●●●●●●●●●●● │
   │  ●  ●  ●   ●  │ 0.3μm     │ ●●●●●●●●●●●● │ 粉の粒 0.1μm 未満
   └──────────────┘            └──────────────┘
    粒が10段重なる                  粒が3〜5段しか重ならない
    → 1粒に欠陥があっても平気        → 1粒の欠陥が層を貫通＝ショート（不良）

   結論：層を薄くするには、粉を「小さく」かつ「粒径を揃えて」作るしかない。
        しかも小さくすると誘電率（溜める力）が落ちる性質があり、
        「小さいのに溜まる粉」を作り分けることが技術そのものになる。

ここが後発が越えられない最初の壁である。

材料の内製度 できること 該当するとされる企業
粉の合成から自社層厚・誘電率・焼成温度を製品設計と一体で最適化できる。新製品を自分の都合で出せる村田製作所、太陽誘電、TDK（各社の技術開示ベース）
粉は外部購入、シート以降は自社汎用品は作れる。最先端の薄層化は材料メーカーの進歩待ちになる台湾・中国勢の多く
完成品の組立・選別中心価格でしか戦えない新興の低価格メーカー

材料を外から買う会社は、自社の設計が材料メーカーの進歩に縛られる。
しかも良い粉は先行企業が押さえているので、
「最先端品を作りたいが、そのための粉が買えない」という構造になる。
→ 材料側の産業は 電子材料 と
セラミックス を参照。

3. 焼成：一発勝負で元に戻せない

MLCC は最後に 1,100〜1,300℃ で焼く。ここで起きることが4つある。

  1. 収縮する。セラミックは焼くと体積が縮む（線寸法で十数%規模）。
    誘電体と内部電極（ニッケル）は縮み方が違うので、
    ズレると層が剥がれる（デラミネーション）
  2. ニッケルが酸化してはいけない。普通に空気中で焼くとニッケル電極が酸化して導体でなくなる。
    だから酸素をほとんど含まない還元雰囲気で焼く。
    しかし今度はチタン酸バリウム側が還元されて絶縁性を失う。
    「ニッケルは酸化させず、セラミックは還元させない」極めて狭い条件を通す必要がある
  3. 添加物で条件を作る。希土類（レアアース）などを微量添加して、
    還元雰囲気でも絶縁性が保たれるように材料側を設計する。
    この配合こそが各社最大の機密とされる
    → レアメタル・レアアース
  4. やり直せない。焼いた後に直す工程は存在しない。不良は捨てるしかない
   ＜焼成の条件窓（イメージ）＞

   酸素濃度 高 ┤ ニッケル電極が酸化 → 導通しない（不良）
              │
              │  ┌──────────┐
              │  │ ここだけ良品 │ ← 窓は非常に狭い。温度と酸素濃度の両方を
              │  └──────────┘    炉の位置ごとに一定に保つ必要がある
              │
   酸素濃度 低 ┤ セラミックが還元 → 絶縁性を失う（不良）
              └──────────────────────────
                低        焼成温度         高

「ニッケル電極を使う」という選択自体が、かつての大きな分岐点だった。
もともと内部電極にはパラジウム（貴金属）が使われていたが、価格が暴騰した。
安いニッケルに置き換えるために、還元雰囲気で焼ける材料系を開発した会社が
コスト構造ごと競争を有利にした。材料を持つ強みが効いた典型例である。

4. 歩留まりという名の利益率

1個 0.5円の部品では、不良を検査ではじく作戦が成り立たない。
検査コストが部品単価に見合わないからである。

想定歩留まり 同じ設備投資から得られる良品 1個あたりコストの相対値
98%981.00
95%95約1.03
90%90約1.09
80%80約1.23

※説明用の単純計算。実際には不良品にも材料費・工程費がかかっているため差はさらに開く。

数字だけ見ると「1割の差」に見えるが、営業利益率が10〜20%の商売では
歩留まり数ポイントの差が利益をそっくり食う。
しかも歩留まりは、

  • 設備を買えば上がるものではない
  • 原因が材料・雰囲気・粉の分散・印刷のかすれなど数百因子に分散している
  • 各因子の対策が品種ごとに違う

という性質を持つ。つまり「長く作り続けた会社ほど強い」という、
時間でしか買えない資産になる。ここは
ベアリングの
鋼の清浄度・熱処理ノウハウと同じ構造である。

5. 日本勢が強い理由を分解する

企業名を並べても説明にならないので、何を握っているから強いのかで整理する。

企業 握っているもの だから何が起きるか
村田製作所粉の合成から自社。製造装置も内製部分が大きいとされる。品種数・サイズ展開が最も広い新しい層厚・新サイズを他社より先に量産化できる。高容量小型品でシェアが集中し、値決め力を持つ
TDKフェライト（磁性材料）の会社として出発。磁性材料の蓄積インダクタと磁性部品で強い。そこから HDDヘッド、さらに二次電池（ATL）へ展開でき、部品会社としては珍しく電池が最大収益源になった
太陽誘電MLCC と積層インダクタの材料・積層技術。規模より高容量品に集中大手の中でMLCC 依存度が最も高い。市況の波を最も強く受けるが、上げ相場では利益の伸び率が大きい
京セラファインセラミックスの総合力。半導体パッケージ、水晶、コネクタ、産業機器まで広い単品の電子部品より セラミックパッケージなど半導体周辺で稼ぐ構図。電子部品事業単体の利益率は低め
日本電波工業（NDK）／セイコーエプソン水晶の人工育成・加工周波数精度という壊れたら製品ごと止まる領域で選ばれ続ける
ローム／KOA抵抗器・小信号半導体抵抗は単価が最も低く、規模と自動化がすべての世界

共通しているのは、材料・工程・設備の三つを自分の側に抱えていること。

   ＜垂直統合が効く仕組み＞

   ┌─ 材料（粉） ─┐   新しい粉を試す
   │              │      ↓
   │   工程条件   │   すぐ焼いて試作できる       ← 3つが社内にあると
   │              │      ↓                        この輪が1〜2週間で回る
   └─ 製造装置 ──┘   装置側を作り変えて合わせる

   外から材料を買う会社：
   材料メーカーに要望 → 数か月 → サンプル入手 → 試作 → 要望 → …
   → 同じ改良に**年単位**かかる。差は開く一方になる

日本勢が強いのは「技術が高い」からというより、
改良のループを速く回せる体制を持っているから。
追いつくには技術だけでなく組織の形ごと真似する必要があり、そこが最大の壁になる。

6. では後発はどこから崩しているのか

障壁は絶対ではない。実際、台湾・中国・韓国勢は下の層から順に取ってきた。

層 攻略のしやすさ 状況（2020年代半ば時点の一般的な見方）
汎用・低容量の小型品易しい。装置を買えば作れる台湾の国巨（Yageo）、華新科（Walsin）、中国の風華高科・三環集団などが数量で強い
中容量・民生グレード中程度競争が激化。日本勢は採算品種の絞り込みで応じている
高容量・超小型（スマホ・AIサーバー向け）難しい村田、サムスン電機、太陽誘電、TDK が中心
車載グレード（高信頼性・長期供給）最も難しい認定取得に年単位。品質保証体制ごと問われる
抵抗器易しいすでに台湾・中国勢が大きなシェア

注目すべきは、日本勢が汎用品から撤退することで後発に道を開いている面があること。
2026年には村田製作所が一部の汎用 MLCC 品番の生産終了を進め、
台湾勢への転注が起きると報じられている（最終受注期限は2028年3月末とされる）。
→ 直近トピック_2026

これは負けではなく意図的な陣地の入れ替えだが、
汎用品を手放すと、後発がそこで規模と経験を積み、
次の層に上がってくる時間を与えることにもなる。

7. 信頼性：車載グレードの意味

同じ 1005 サイズの MLCC でも、民生用と車載用では値段が数倍違う。理由は性能ではない。

項目 民生グレード 車載グレード（AEC-Q200 準拠）
想定使用温度〜85℃程度−40〜125℃（エンジン周りは150℃級）
想定寿命数年10〜15年
不良率の目標ppm（100万分の1）オーダーppb（10億分の1）を志向
供給保証期間短い。EOL（生産終了）も出しやすい10年以上の継続供給を求められる
変更管理比較的柔軟材料・工程を変えるだけで再認定が必要
実装後の課題—基板のたわみによるクラック対策（金属端子付き・ソフト端子品）

車載品の本質は「良い部品」ではなく「10年間、同じものを作り続ける約束」。
工程を改善したくても勝手に変えられない。
この不自由さを引き受けられる会社だけが車載で稼げる。
逆に言えば、いったん採用されれば設計変更まで置き換えられない。

8. 用語メモ

用語 意味
