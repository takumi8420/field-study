# 電子部品｜電子部品とは何か（受動部品・MLCC・水晶・センサ）

**このノートで分かること**：電子部品とは、半導体チップが計算するための
**「電気の道路整備」をする部品**のこと。スマホ1台に1,000個以上入っていて、
1個あたりの価格は数円。その筆頭が MLCC（積層セラミックコンデンサ）である。

> ポイント：半導体は「考える部品」、電子部品は「電気をきれいに整える部品」。
> 半導体が速く・大食いになるほど、**その周りを固める電子部品の数が増える**。
> だからこの産業は、半導体の性能競争に**寄生する形で伸びる**。

## 1. 三行での定義

**電子部品**とは、電子回路を成立させるために基板上に載る部品のうち、
**能動素子（＝半導体）以外のもの**を指す、というのが実務上の区切り方である。

- **能動素子（半導体）**：電気信号を増幅したりスイッチしたりする。自分で「仕事」をする
- **受動素子（受動部品）**：増幅しない。**溜める・妨げる・消費する**だけ
- ただし業界の「電子部品」には、受動部品に加えて
  **水晶デバイス・センサ・コネクタ・モジュール**なども含めて語られることが多い

| 区分 | 何をするか | 代表 | 日本で言う「電子部品メーカー」の守備範囲 |
| --- | --- | --- | --- |
| 能動素子 | 増幅・スイッチ・演算・記憶 | IC、トランジスタ、ダイオード | 原則そと（[半導体](../02_半導体（ロジック・メモリ）/README.md)の領域） |
| **受動部品** | 電気を溜める／妨げる／消費する | **コンデンサ・インダクタ・抵抗器** | **ここが本丸** |
| 機構部品 | つなぐ・切る | コネクタ、スイッチ、リレー | [コネクタ・プリント基板](../06_コネクタ・プリント基板/README.md)と重なる |
| 周波数デバイス | 時間の基準をつくる／選ぶ | 水晶振動子、SAWフィルタ | 村田・NDK・エプソンなど |
| センサ・アクチュエータ | 物理量を電気に変える／その逆 | 加速度センサ、圧電ブザー | 電子部品メーカーが取り込み中 |
| モジュール | 上記＋ICを一体化 | 通信モジュール、電源モジュール | 付加価値の移動先 |

## 2. 基板の上で何が起きているか

```
                  ＜スマートフォンの基板（模式）＞

   [バッテリー] ──┬── [電源IC] ──┬───────────┬──────────┬────▶ [ SoC ]
                  │               │           │          │      ＝計算する頭脳
              ┌───┴───┐      ┌────┴───┐  ┌────┴───┐ ┌───┴────┐
              │インダクタ│     │ MLCC  │  │ MLCC  │ │ MLCC  │ ×数百個
              │(妨げる) │      │(溜める)│  │(溜める)│ │(溜める)│
              └────────┘      └────────┘  └────────┘ └────────┘
                  ↑               ↑
        電流の急変をならす   電圧の谷を一瞬で埋める（デカップリング）

   [アンテナ] ──▶ [SAWフィルタ] ──▶ [高周波モジュール] ──▶ [通信IC]
                   ＝必要な周波数だけ通す        ＝部品の塊を1パッケージに

   [水晶振動子] ──▶ 時間の物差し（何 MHz で動くかの基準。これが無いと全部動かない）
```

ここで起きていることを一言で言うと、
**「半導体は電源電圧がほんの少し揺れただけで誤動作する」**という事実への対処である。

SoC（スマホの頭脳チップ）は、演算負荷が変わった瞬間に電流を大きく変動させる。
電源ICから配線を通って電気が届くには時間がかかるので、
その一瞬の谷を埋めるために、**チップのすぐ隣に電気の貯金箱を大量に置く**。
これが MLCC であり、**数が要るのは「近くに置く」ことに意味があるから**である。

> つまり MLCC の需要は、性能ではなく**距離と物理**で決まっている。
> ソフトウェアで減らすことができない。だから半導体が進化するほど数が増える。

## 3. 受動部品「三兄弟」

| 部品 | 記号的な働き | 直感的な比喩 | 主な材料 | 単価の目安 |
| --- | --- | --- | --- | --- |
| **コンデンサ**（容量／キャパシタ） | 電気を溜めて放す | 小さなダム | セラミック（チタン酸バリウム）、アルミ箔、タンタル | 汎用品で1個 0.1〜数円 |
| **インダクタ**（コイル） | 電流の変化を妨げる | 水流の慣性（はずみ車） | フェライト、金属磁性粉、銅 | 数円〜数十円 |
| **抵抗器** | 電気を熱に捨てて量を決める | 蛇口の絞り | 酸化ルテニウム系厚膜、金属皮膜 | 0.1円台〜 |

この3種は**組み合わせて使う**ことに意味がある。

```
   ＜電源ラインの基本形：LCフィルタ＞

   ざらついた電気 ──[ インダクタ ]──┬──▶ きれいな電気 ──▶ IC へ
   （リップルあり）  変化を通さない   │
                                  [ MLCC ]  高い周波数の揺れを地面へ逃がす
                                     │
                                  ───┴─── GND（基準）

   インダクタ＝「速い変化を通さない壁」
   コンデンサ＝「速い変化だけを通す抜け道」
   → 二つ合わせると、遅い（欲しい）成分だけが残る
```

コンデンサとインダクタは**互いに逆の性質**を持つ。だから両方を置くと
「欲しい信号だけ残す」フィルタになる。電子回路は、この組合せの塊でできている。

## 4. MLCC が主役である理由

**MLCC**＝Multi-Layer Ceramic Capacitor、積層セラミックコンデンサ。
誘電体（電気を溜めるセラミック）と電極を交互に何百層も重ね、
**1005（1.0×0.5mm）や0603（0.6×0.3mm）といった米粒より小さい塊**にした部品。

```
      ＜MLCC の断面（模式）。実物は 1mm 以下＞

   外部電極 ┃                                    ┃ 外部電極
   （端子） ┃━━━━━━━━━━━━━━━━━━━┃
           ┃░░░░░░░░░░░░░░░░░░░░░░┃  ← 誘電体（チタン酸バリウム系セラミック）
           ┃━━━━━━━━━━━━━━━━━━━┃  ← 内部電極（ニッケル）
           ┃░░░░░░░░░░░░░░░░░░░░░░┃
           ┃━━━━━━━━━━━━━━━━━━━┃
           ┃░░░░░░░░░░░░░░░░░░░░░░┃      これを 500〜1,000 層
           ┃━━━━━━━━━━━━━━━━━━━┃
           ┗━━━━━━━━━━━━━━━━━━━┛

   1層の誘電体の厚み ＝ 0.5μm 前後（髪の毛の 1/150 程度）まで薄くなっている
   → 層を薄く・多くするほど容量が増える。だから「薄く積む」ことが全ての勝負になる
```

MLCC が電子部品産業の主役になっている理由は3つある。

1. **数が圧倒的**。スマートフォン1台で 700〜1,000 個超、
   EV1台で数千〜1万個規模とされる（メーカー解説・報道ベース）。
   金額ではなく**個数で世界を埋め尽くしている**部品
2. **代替が効かない**。高容量・低ESR（内部抵抗が小さい）・小型を同時に満たすのは
   セラミック積層構造しかない。アルミ電解コンデンサは大きく、タンタルは高価で供給が細い
3. **性能が製造技術そのもの**。設計図に秘密はなく、
   **「何μmの層を、歩留まりよく、何百層積めるか」**という工程力が製品性能になる
   → [作り方と強さの源泉](02_作り方と強さの源泉.md)

### コンデンサの種類の住み分け

| 種類 | 容量 | 大きさ | 寿命・信頼性 | 主用途 |
| --- | --- | --- | --- | --- |
| **MLCC（積層セラミック）** | pF〜数百μF | **極小** | 摩耗劣化なし。ただし機械的に割れやすい | デジタル回路全般。圧倒的主役 |
| アルミ電解 | 数μF〜数万μF | 大 | 電解液が蒸発して寿命がある | 電源の平滑、産業機器 |
| 導電性高分子（固体） | 中〜大 | 中 | 液が無く長寿命。高価 | サーバー電源、車載 |
| タンタル | 中 | 小 | 安定だが原料（タンタル）供給が細い | 医療、航空、一部車載 |
| フィルム | 小〜中 | 大 | 高耐圧・自己回復性 | EVインバータ、太陽光 |

**アルミ電解コンデンサ**は日本ケミコン・ニチコン・ルビコンなど別の企業群の世界で、
MLCC 勢とは競合しつつも用途が分かれている。

## 5. 水晶デバイス：見落とされがちな必須部品

**水晶振動子**は、水晶（石英）の薄片に電圧をかけると決まった周波数で振動する性質
（圧電効果）を使い、**回路に「1秒とは何秒か」を教える部品**である。

- これが無いと、CPU も通信も**そもそも動き出さない**
- 通信規格が高度になるほど**周波数のズレ（偏差）への要求が厳しくなる**。
  車載通信向けでは ±40ppm 級（100万分の40の狂いまで）という製品が実用化されている
  （日本電波工業 NX1612SA、2026年4月量産開始と発表）
- 日本電波工業（NDK）、セイコーエプソン、村田製作所、大真空が主要プレイヤー
- NDK の2026年3月期は**車載向け売上 約301億円で全社の約半分**、
  2027年3月期は約314億円を見込むとされる（会社説明・報道ベース）

> 水晶は「性能で選ばれる部品」ではなく「狂わないことで選ばれる部品」。
> 数円〜数十円の部品だが、狂えば製品ごとリコールになる。
> このリスク構造が、日本勢の値決め力の源泉になっている。

## 6. センサとモジュール：付加価値の移動先

受動部品は成熟して価格が下がり続けるので、各社は**上に登ろうとする**。

```
   ＜付加価値の登り方＞

   [単品部品]  MLCC・インダクタ・抵抗          単価 0.1〜数円   利幅：工程力しだい
       │
       ▼ 複数部品＋ICを1つの小さな基板に載せる
   [モジュール] 高周波フロントエンド、電源モジュール、
                通信モジュール（Wi-Fi/Bluetooth）    単価 数百〜数千円
       │
       ▼ 物理現象を扱う（作れる会社が限られる）
   [センサ]     MEMS慣性センサ、圧力、超音波、
                電流センサ、磁気センサ              単価 数十〜数百円

   ※モジュール化は売上単価を上げるが、中に他社のICを買って載せるため
     「売上は増えるが利益率は下がる」ことがある。ここが各社の悩みどころ
```

- **モジュール**は、顧客（スマホメーカー等）の設計負担を肩代わりする商売。
  部品を売るのではなく**基板の一区画を丸ごと請け負う**
- **センサ**は、MEMS（微細加工でシリコン上に機械構造を作る技術）が中心で、
  半導体の作り方と受動部品の作り方の中間にある
- TDK は買収（InvenSense など）で慣性センサに入り、村田は自社技術と買収の両輪で広げてきた

## 7. 半導体との違い（ここを混同しない）

| 論点 | 半導体 | 電子部品（受動部品） |
| --- | --- | --- |
| 価値の源泉 | **設計**（回路・アーキテクチャ）と微細化 | **材料と工程**。設計図に秘密は少ない |
| 分業 | ファブレス／ファウンドリに分離済み | **垂直統合のまま**。材料から自社で作る |
| 1個の単価 | 数百円〜数万円 | **0.1円〜数十円** |
| 1製品への搭載数 | 数個〜数十個 | **数百〜数千個** |
| 品種数 | 少数の型番に集約 | **数万〜十数万品番**（サイズ×容量×温度特性×耐圧の掛け算） |
| 投資の単位 | 1工場 数千億〜兆円 | 1ライン 数十〜数百億円。**小刻みに積める** |
| 競争の決着 | 勝者総取りになりやすい | シェアは動くが**総取りにはならない** |

**最大の違いは「分業していない」こと**。
半導体が設計と製造に分かれたのに対し、電子部品は
**セラミックの粉を作るところから完成品まで一社でやる**会社が強い。
これが日本勢の優位の正体であり、次のノートの主題になる。
→ [作り方と強さの源泉](02_作り方と強さの源泉.md)

## 8. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **受動部品** | 増幅もスイッチもしない部品。コンデンサ・インダクタ・抵抗器の3種が中心 |
| **MLCC** | 積層セラミックコンデンサ。誘電体と電極を数百層積んだチップコンデンサ → [作り方と強さの源泉](02_作り方と強さの源泉.md) |
| **誘電体** | 電気を溜める絶縁材料。MLCC ではチタン酸バリウム（BaTiO₃）系が主流 |
| **デカップリング** | ICのすぐ隣にコンデンサを置き、電源の一瞬の電圧変動を吸収すること。MLCC 大量搭載の理由 |
| **ESR** | 等価直列抵抗。コンデンサが内部に持つ抵抗成分。小さいほど大電流を素早く出せる |
| **0603／1005** | チップ部品の外形サイズ表記（mm）。0603＝0.6×0.3mm。小さいほど難度が上がる |
| **圧電効果** | 力を加えると電圧が出る／電圧をかけると変形する性質。水晶振動子・圧電ブザー・SAWフィルタの原理 |
| **ppm（周波数偏差）** | 100万分のいくつ狂うか。水晶デバイスの精度を表す単位 |
| **MEMS** | 微細加工でシリコン上に機械構造を作る技術。加速度・角速度・圧力センサの基盤 |
| **BBレシオ** | 受注額÷出荷額。1を超えると需要が供給を上回っている状態 → [市場の波と儲け方](03_市場の波と儲け方.md) |
