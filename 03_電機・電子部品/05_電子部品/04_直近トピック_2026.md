# 電子部品｜直近トピック（2026年9月時点）

報道・各社開示ベースの整理。数値は年月とセットで読むこと。
確定事実と推計・報道を区別して書いている。

> **2026年の一行**：AIサーバーが MLCC を食い尽くし、
> スマートフォンはメモリ不足で縮み、日本勢は汎用品を捨てて高付加価値品に寄せた。
> **「需要が増えたから好況」ではなく「供給が増やせないから好況」**という年である。

## 1. MLCC の供給逼迫と値上げ

2024年以降のAIデータセンター投資が、受動部品の需給を一変させた。

| 事象 | 内容 | 時点・出典 |
| --- | --- | --- |
| BBレシオが高水準に | 村田 1.30、サムスン電機 1.31、太陽誘電 1.25。コロナ後の新高値と報じられる | 2026年6月下旬時点・報道ベース |
| 村田が値上げ | AIサーバー向け高容量MLCC・車載ハイエンド品で **15〜35%** | 2026年4月1日実施と報じられる |
| サムスン電機が値上げ | ポートフォリオ全体で **約30%** | 2026年8月1日実施と報じられる |
| 供給制約の理由 | 製造装置の納期が最大18か月、能力増は年10〜15%が限界とされる一方、需要は年率で大幅増 | 報道・業界分析ベース |

**なぜ増産で解決しないのか**。ここが今回の逼迫の本質である。

```
   ＜増やしたくても増やせない理由＞

   需要（AIサーバー向け高容量MLCC）
      ▲ 年率で数十%増
      │        ／
      │      ／
      │    ／
      │  ／  ←─ ギャップ＝逼迫・値上げ
      │／───────────  供給：年 10〜15% しか増えない
      └──────────────────▶ 時間

   供給が伸びない3つの理由
   ① 焼成炉・積層機の納期が最大18か月とされる（発注しても来ない）
   ② 高容量品は歩留まりが低く、同じ設備でも取れる良品が少ない
   ③ 材料（粉）の増産も同時に必要で、そこもボトルネックになる
```

AIサーバー1台あたりの MLCC 搭載数は報道によって幅が大きく
（**数万個から数十万個まで**の数字が出ている）、
NVIDIA の新世代プラットフォームでは基板1枚あたり1万個超になるとも報じられる。
**いずれの数字を取ってもスマートフォン1台の数十〜数百倍**という点は共通している。

> 数円の部品が、数千万円のサーバーの出荷を止める。
> **サプライチェーンのボトルネックは、最も安い部品に現れる**という典型例。

## 2. 主要各社の2026年3月期決算

AI需要で全体に好調だったが、**中身は各社でかなり違う**。

| 企業 | 売上高 | 利益 | コメント |
| --- | --- | --- | --- |
| **村田製作所** | **1兆8,308億円**（+5.0%、過去最高） | — | MLCCがサーバー向けを中心に幅広い用途で増加。2025年度Q2（7〜9月）は四半期として過去最高の売上4,866億円 |
| **TDK** | 過去最高 | 営業利益 **+21.5%**（過去最高） | AIデータセンター向け需要の回復が寄与。次期も増益継続の見通し |
| **太陽誘電** | **3,553億円**（+4.1%） | 営業利益 **200億円（+91.2%）**、純利益 148億円（+535.9%） | コンデンサ売上 2,518億円（+8.5%）。**売上の伸びを利益の伸びが大きく上回る＝営業レバレッジ** |
| **京セラ** | 全社 **2兆702億円**（+2.8%） | 営業利益 1,181億円（+332.8%と報じられる） | 電子部品事業は3,635億円（+2.5%）、セグメント利益率 **2.0%** と依然低い。牽引役はコアコンポーネント（6,534億円、+10.4%）＝半導体用セラミック・有機パッケージ |

読み方のポイント：

- **太陽誘電の利益が倍近く伸びたのは、MLCC 依存度が最も高いから**。
  市況が上向けば最も伸び、下がれば最も落ちる構造
- **京セラの電子部品事業の利益率2%は、この産業の厳しさを示す数字**。
  同じ「電子部品」でも、品種構成が違えば利益率は10倍違う
- **TDK は電池が稼ぐ会社**であり、受動部品の話だけで業績を説明できない

## 3. 村田製作所の「汎用MLCC生産終了」と陣地の入れ替え

2026年、村田製作所が一部 MLCC 品番の生産終了を進めていると報じられた。

| 論点 | 内容 |
| --- | --- |
| 対象 | GRM、GRJ、GRT、GXM、GXT、GCM、GCJ、GCG、ZRA などの一般民生グレードおよび一部車載グレードの品番（報道ベース） |
| 最終受注期限 | **2028年3月31日**とされる |
| 理由 | 需要減による撤退ではなく、**製品ラインの最適化**。生産能力を利益率の高いAIサーバー向け高付加価値品に振り向けるため、と説明されている |
| 影響 | 台湾の国巨（Yageo）、華新科（Walsin）などへの転注が期待されると報じられる。中国メーカーも代替型番の日本市場向け供給を打ち出している |

```
   ＜陣地の入れ替えという戦略＞

   ＜これまで＞                      ＜これから＞
   ┌─────────────┐              ┌─────────────┐
   │ 高付加価値品   │ 30%         │ 高付加価値品   │ 50%  ← 能力をこちらへ
   ├─────────────┤              ├─────────────┤
   │               │              │               │
   │  汎用品       │ 70%         │  汎用品  30%  │      ← EOLで絞る
   │               │              └─────────────┘
   └─────────────┘                    ↓ 空いた市場
                                    台湾・中国勢が取る

   短期の利益率：上がる
   長期のリスク：後発が汎用品で規模と経験を積み、上の層に登ってくる時間を与える
```

> これは2000年代以降、日本の電機・部品産業が繰り返してきたパターンでもある。
> 「儲からない領域から撤退して高付加価値に集中する」は正しい判断だが、
> **撤退した領域で育った競合が、数年後に上がってくる**。
> 今回それが起きるかどうかは、材料（粉）の壁を後発が越えられるかにかかっている。
> → [作り方と強さの源泉](02_作り方と強さの源泉.md)

同時に村田は、社長自身が **「MLCC依存からの脱却」** を課題として語っていると報じられている。
MLCC が儲かっている局面でこの発言が出ること自体が、
**市況依存の重さ**をよく表している。

## 4. スマートフォン市場の異例の縮小

電子部品の最大の数量需要先であるスマートフォンが、2026年は逆風にある。

| 項目 | 内容 | 出典 |
| --- | --- | --- |
| 2026年 世界スマホ出荷 | 前年比 **約−14%**、**10.8億台**程度まで落ち込む予測 | Counterpoint Research の予測・報道ベース |
| 原因 | **メモリ（DRAM/NAND）の供給不足と価格高騰**。AI向けにメモリ生産が振り向けられ、スマホ用 LPDDR4 の供給が2026年に40%超減るとの見方 | 報道ベース |
| 価格への影響 | スマートフォンの卸売価格が2026年Q1に約14%上昇。平均単価は565ドル程度へ | 調査会社推計・報道ベース |
| 低価格帯 | 格安モデルが成立しなくなり市場から縮小 | 報道ベース |
| 部品業界への含意 | 台数は減るが**1台あたりの部品搭載数は減らない**。金額ベースでの打撃は台数ほどではないが、数量前提の汎用品には効く | — |

```
   ＜2026年の需要の綱引き＞

   AIサーバー   ████████████████████  ＋＋＋  数量は少ないが単価・員数が桁違い
   車載・EV     ██████████            ＋      緩やかに増加
   産業機器     ███████               ＋      設備投資しだい
   PC          ██████                 →      横ばい
   スマートフォン ████                  −−     台数−14%予測（メモリ不足が主因）

   → 全体では「量は伸びないが、単価の高い品種が伸びる」という形の好況
   → だから出荷個数の統計と売上・利益が食い違って見える
```

これは [半導体（ロジック・メモリ）](../02_半導体（ロジック・メモリ）/README.md) で起きている
メモリ逼迫が、**別の産業（電子部品）の需要構成を書き換えている**例である。
産業をまたいで波及する構図として押さえておきたい。

## 5. 設備投資の競争

逼迫が続くと予想されるため、各社が能力増強に動いている。

| 企業 | 投資 | 時点・出典 |
| --- | --- | --- |
| 村田製作所 | 2026年度に **設備投資 2,500億円** 計画。うち **800億円をサーバー向けMLCCの能力増強**に充当と報じられる | 2026年・報道ベース |
| TDK | 2026年4月時点の予想で設備投資を **1,300億円積み増し**する計画とされる | 同社IR資料・報道ベース |
| サムスン電機 | 車載・AIサーバー向けに攻勢をかけていると報じられる | 報道ベース |

ただし、**投資してもすぐには効かない**。装置納期が最大18か月とされるうえ、
立ち上げて歩留まりを出すまでにさらに時間がかかる。
逼迫の解消は2027〜2028年にずれ込むとの見方も報じられている。

> ここに部品産業の古典的なジレンマがある。
> **逼迫している時に投資を決めると、能力が立ち上がる頃には需給が緩んでいる**。
> 過去の在庫調整局面は、ほぼこのパターンで起きてきた。
> → [市場の波と儲け方](03_市場の波と儲け方.md#3-在庫調整サイクルなぜこれほど揺れるのか)

## 6. 水晶デバイス・車載の動き

- 日本電波工業（NDK）は、周波数安定度 **±40ppm** で車載狭偏差に対応する
  水晶振動子 **NX1612SA** を開発し、**2026年4月から量産開始**と発表（2025年9月30日）
- NDK の車載向け売上は 2026年3月期で **約301億円**、全社売上の約半分を占め、
  2027年3月期は約314億円を見込むとされる（会社説明・報道ベース）
- 車載通信の高機能化により、小型・高精度のタイミングデバイス需要は拡大が見込まれる

派手さはないが、**車載向けは値崩れしにくく、長期に読める需要**である。
AIサーバーの波が去ったあとの支えになるのはこちらの領域になる。

## 8. 全体の構図

1. **2026年の好況は「需要増」より「供給制約」で説明できる**。
   装置納期・歩留まり・材料の3つが同時にボトルネックになっており、
   金を出せば能力が増える局面ではない。だから値上げが通っている
2. **需要の中身が入れ替わった**。スマートフォンが二桁減の予測である一方、
   AIサーバーが牽引役になった。数量は減るのに金額は増えるという、
   過去のサイクルとは違う形の好況になっている
3. **日本勢は汎用品を手放して高付加価値に寄せている**。
   短期の利益率は上がるが、空いた市場で台湾・中国勢が力をつける。
   この構図が数年後にどう効くかが最大の論点
4. **利益率の差は「どの品種を作れるか」で決まる**。
   同じ2026年3月期で、太陽誘電の営業利益は+91%、
   京セラの電子部品事業の利益率は2.0%。同じ業界とは思えない差がある
5. **投資のタイミングが次のサイクルを作る**。
   村田2,500億円、TDK積み増しといった能力増強は、
   立ち上がる頃に需給が緩んでいれば次の在庫調整の引き金になる。
   部品産業は繰り返しこれをやってきた

## 9. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **BBレシオ** | 受注額÷出荷額。1超で需要超過。2026年6月下旬時点で主要3社とも1.25〜1.31と報じられる |
| **EOL（生産終了）** | 品番の供給打ち切り。村田の汎用MLCC生産終了はこの形で進む。最終受注期限が設定される |
| **高容量MLCC** | 同じサイズでより多くの電気を溜められる品種。層を薄く多く積む必要があり、作れる会社が限られる |
| **低ESR** | 内部抵抗が小さいこと。AIサーバーの電源回路で必須になる特性 |
| **LPDDR4／メモリ逼迫** | スマホ向けの低消費電力DRAM。AI向けにメモリ生産が振り向けられ不足している → [半導体（ロジック・メモリ）](../02_半導体（ロジック・メモリ）/README.md) |
| **狭偏差（水晶）** | 周波数のズレが小さいこと。±40ppm級が車載通信向けの水準 |
| **JEITA赤本** | JEITA「電子情報産業の世界生産見通し」の通称。毎年12月頃に翌年見通しが公表される |
