このノートで分かること：電子部品は「単価が数円、数量が年間で兆個」という商売。
だから1個いくらで売るかではなく、どの用途に何個流れるかで利益が決まる。
そして需要は驚くほど激しく上下する。その波の正体と、各社の儲け方を整理する。

ポイント：この業界の業績が乱高下するのは、需要が乱高下するからではない。
サプライチェーンの各段階が在庫を持つため、末端の小さな需要変動が
川上に行くほど増幅される（ブルウィップ効果）。
部品メーカーは一番川上にいるので、一番大きく揺れる。

1. 誰に売っているのか

需要先 数量の性質 単価・利益率 波の特徴
スマートフォン1台あたり700〜1,000個超。年10億台規模単価は低いが数量で稼ぐ。値下げ圧力は強い年次モデルサイクル。在庫調整が激しい
PC・タブレット1台あたり数百〜千個超中程度買い替え周期に連動。長期では横ばい
AIサーバー・データセンター1台で数万個規模（報道により幅がある）高容量・低ESR品＝最も利益率が高い2024年以降の最大の成長源

3. 在庫調整サイクル：なぜこれほど揺れるのか

   ＜ブルウィップ効果：末端の小さな変動が川上で増幅される＞

   [ 消費者 ] 需要 −5%
        │
        ▼
   [ 完成品メーカー ] 在庫が積み上がる → 生産を −15% に絞る
        │                                （持っている在庫の分だけ余計に絞る）
        ▼
   [ EMS・基板メーカー ] 手持ち部品が余る → 部品発注を −30%
        │
        ▼
   [ 電子部品メーカー ] 受注 −40%、工場稼働率が急落
        │
        ▼
   [ 材料メーカー ] さらに大きく揺れる

   ＜回復時は全く逆＞
   末端が +5% 戻ると、各段が在庫を積み直すので部品発注は +50% にもなる
   → 部品メーカーは「需要が戻った」と錯覚して増産し、次の在庫調整を自分で作る

この構造があるために、電子部品メーカーの業績は
2〜3年おきに好況と不況を往復する。以下のような指標が波の位置を教えてくれる。

指標 意味 見方
BBレシオ（受注÷出荷）1を超えると需要超過2026年6月下旬時点で村田1.30、サムスン電機1.31、太陽誘電1.25と報じられ、コロナ後の高水準
稼働率固定費の回収度合い8割を切ると急速に利益が消える
顧客の在庫週数EMS・セットメーカーの手持ち「正常水準に戻った」というコメントが底打ちのサイン
リードタイム納期の長さ延びる＝逼迫、縮む＝緩和

業績が「良い／悪い」ではなく、波のどこにいるかで読む必要がある。
増益決算が出た時点で、すでにピークを過ぎていることも珍しくない。

4. コスト構造

電子部品メーカーは典型的な装置産業である。

費目 目安 性質
材料費（セラミック粉、ニッケル、銅、パラジウム、希土類）売上の2〜3割程度変動費。金属市況の影響を受ける
減価償却費大きい。売上の1割前後固定費。工場を建てた瞬間から発生する
電力・ガス焼成炉が電気を食う半固定

   （償却・  │

   稼働率が 100% → 70% に落ちると
   ・売上は 30% 減る
   ・変動費は 30% 減る
   ・固定費は **減らない**
   → 利益はゼロか赤字になる（営業レバレッジが強く効く）

逆に、好況期には増えた売上のかなりの部分がそのまま利益になる。
2026年3月期に太陽誘電の営業利益が前年比+91.2%と、売上の伸び（+4.1%）を
大きく上回って伸びたのは、この営業レバレッジが効いた結果である。

5. 値決めの構造

電子部品は基本的に買い手の力が強い商売である。理由は簡単で、

  • 買い手（アップル、サムスン、EMS、完成車メーカー）は極めて大口
  • 規格化された部品は型番が違っても代替が効く
  • 毎年の値下げ（年次値引き）が商習慣として組み込まれている

したがって「値上げが通る」局面は限られる。値上げが通る条件は3つしかない。

条件 中身 実例
作れる会社が少ない高容量・超小型・高耐圧など、供給できるのが数社2026年、AIサーバー向け高容量MLCCと車載ハイエンド品で村田が15〜35%の値上げを4月1日から実施と報じられる。サムスン電機も8月1日付で約30%と報じられる
増産に時間がかかる装置の納期が最大18か月とされ、能力増は年10〜15%が限界と報じられる。需要が年率で数十%伸びると埋まらない2026年のMLCC逼迫
買い手が止まると損が大きいAIサーバー1台の価値に比べ、部品代は微々たるもの。数円の部品のために出荷を止められない逼迫時の価格転嫁
   ＜0.02ドルの部品が数千万円のサーバーを止める＞

   AIサーバー 1台の価格         数千万円
        ▲
        │  この1台を完成させるために必要な MLCC：数万個
        │  MLCC の金額：せいぜい数万円 ＝ 全体の 0.1% 未満
        │
        └─ だから「2倍に値上げします」と言われても払う
           ＝ 逼迫時の電子部品は、極端に価格弾力性が低い

   逆に、平時は「代替品があるなら安いほうで」となり値下げ圧力に晒される
   → この非対称が、業績の振れ幅をさらに大きくしている

6. 車載シフトが構造を変えた

2010年代後半から各社が明確に舵を切ったのが車載比率の引き上げである。

論点 民生（スマホ）中心の時代 車載比率を上げた後
搭載数スマホ1台 約1,000個EV1台で数千〜1万個規模とされる
製品寿命1年でモデルチェンジ10年以上の供給義務
需要変動激しい相対的に緩やか（ただし完成車生産に連動）
価格毎年値下げ単価が数倍。値崩れしにくい
在庫リスク品番がすぐ陳腐化長く売れるので設備投資を回収しやすい
制約変更が自由工程を勝手に変えられない（再認定が必要）

車載シフトの本質は「単価が高い」ことではなく、
需要の寿命が長くなり、設備投資の回収計画が立つようになったこと。
償却の重い装置産業にとって、これは利益率そのものを変える。

ただし2026年は事情が変わっている。
AIサーバー向けの需要が急伸し、車載よりデータセンターが成長ドライバーになった。
一方でスマートフォンはメモリ不足による供給制約で、
2026年の世界出荷が前年比で二桁減になるとの予測が出ている
（Counterpoint の予測では −14% 程度、報道ベース）。

7. 各社の儲け方の違い

企業 収益の柱 儲け方の型
村田製作所MLCC を軸に、高周波モジュール、センサ、電池高容量・超小型品でシェアを集中させ、値決め力を持つ。同社開示では MLCC 世界シェア約4割水準とされる（調査会社推計では3割強という数字もあり、定義により幅がある）。ただし MLCC 依存の高さが課題とされ、経営陣自身が脱却を語っている
TDK実は二次電池（ATL）が最大の柱。受動部品、センサ、磁気応用部品会社でありながら電池で稼ぐという異例の構造。スマホ用小型電池で高シェア
太陽誘電MLCC が売上の約7割（コンデンサ 2,518億円／全社 3,553億円、2026年3月期）最も MLCC 純度が高い。市況の上下がそのまま利益に出る「ハイベータ」型
京セラ半導体用セラミックパッケージ、産業用部品、機械工具、太陽光など電子部品単体より半導体周辺・産業向けの幅で稼ぐ。電子部品事業の利益率は2%台と低く、構造改革の対象
ローム／KOA／日本ケミコン等抵抗器・アルミ電解・小信号半導体ニッチ寡占と規模の経済。値決め力は限定的
国巨（Yageo）／華新科（Walsin）汎用受動部品数量と買収で規模を作る。日本勢が抜けた汎用品の受け皿になる
サムスン電機（SEMCO）MLCC、基板、カメラモジュールグループ内需要を基盤に、車載・AIサーバーへ攻勢

企業名の裏にある共通の問いは一つで、
「償却の重い設備を、どれだけ利益率の高い品種で埋められるか」である。
どの会社の戦略もこの問いへの答えとして読むと分かりやすい。

8. リスク

リスク 中身
需要の急反転好況の終わりは突然来る。増産投資が完成した頃に不況入りするのが最悪のパターン
顧客集中大口顧客の設計変更ひとつで数量が消える
後発の追い上げ汎用品から順に台湾・中国勢が取っている → 作り方と強さの源泉
原材料パラジウム、ニッケル、希土類の価格・供給。中国の輸出管理の影響も受けうる
為替輸出比率が高く、円安は利益にプラスだが、現地生産比率の高さで効き方は各社で異なる
通商・関税米中間の関税・輸出管理。部品は最終製品に組み込まれて動くため影響が読みにくい
技術の置き換え半導体側の電源設計が変わると必要な部品数が変わる（例：電源の統合、基板内蔵化）

9. 用語メモ

用語 意味
ブルウィップ効果末端需要の小さな変動が、サプライチェーンを遡るほど増幅される現象。部品業界の業績変動の主因 → 本ノート3章
BBレシオBook-to-Bill。受注額÷出荷額。1超で需要超過
プロダクトミックス売れた製品の構成。同じ売上でも高付加価値品の比率で利益が変わる
営業レバレッジ固定費が大きいと、売上変動に対して利益が大きく振れる性質
EMS電子機器の受託製造。鴻海（Foxconn）など。部品メーカーの実際の発注元になることが多い
年次値引き毎年決まった率で単価を下げる商習慣。民生・車載とも一般的
価格弾力性値上げしたときにどれだけ需要が減るか。逼迫時の電子部品は極端に小さい
EOL（生産終了）品番の供給打ち切り。採算品種の絞り込み手段でもある
ハイベータ市況変動に対して業績・株価の振れが大きい状態を指す言い方
