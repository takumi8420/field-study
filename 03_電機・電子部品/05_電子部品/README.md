### 最初に押さえる一行

> **電子部品とは「半導体が計算するための電気の道路整備」をする部品**であり、
> 1個 0.1〜数円、スマホ1台に1,000個超、世界で年間に**兆個**流れる。
> 勝敗は設計ではなく、**セラミックの粉と、不良を出さない工程**で決まる。

## 1. 業界の定義・範囲

**電子回路を成立させるために基板上に載る部品のうち、半導体（能動素子）以外**を作る産業。
中心は**受動部品**（コンデンサ・インダクタ・抵抗器）で、
業界の慣用では水晶デバイス、センサ、モジュールも含めて語られる。

| 隣接領域 | 境界 |
| --- | --- |
| [半導体（ロジック・メモリ）](../02_半導体（ロジック・メモリ）/README.md) | **増幅・演算する側**。電子部品は増幅しない。分業構造も違い、半導体は設計と製造が分離したが、電子部品は**垂直統合のまま** |
| [コネクタ・プリント基板](../06_コネクタ・プリント基板/README.md) | 部品を「つなぐ・載せる」側。京セラなど両方を手がける企業もあり境界は曖昧 |
| [電子材料](../../10_素材・化学/03_電子材料/README.md) ／ [セラミックス](../../10_素材・化学/12_セラミックス/README.md) | **原料側**。ただし村田・太陽誘電などはセラミック粉を自社で合成しており、川上に食い込んでいるのが特徴 |
| [二次電池](../08_二次電池/README.md) | 本来は別産業だが、TDK（ATL）のように電子部品メーカーの最大の収益源になっている例がある |
| [PC・スマートフォン](../11_PC・スマートフォン/README.md) ／ [自動車部品](../../02_自動車・機械/02_自動車部品/README.md) | **売り先**。どちらに何%売っているかで各社の業績の振れ方が変わる |
| アルミ電解コンデンサ | 同じコンデンサだが、日本ケミコン・ニチコン・ルビコンという別の企業群。用途も大型・電源系で住み分けている |

業界の中は、**製品で**（コンデンサ／インダクタ／抵抗／水晶／センサ／モジュール）、
**グレードで**（民生／産業／車載）、
**売り先で**（スマホ／PC・サーバー／車載／産機）に分かれる。
この3軸の掛け算で見ると、同じ「電子部品メーカー」でも中身が全く違うことが分かる。

```

セラミック粉                 スラリー → シート成形 → 電極印刷   ┌─▶ スマートフォン（年10億台規模）
(チタン酸バリウム)      ──▶  → 積層 → 切断 → 焼成 → 外部電極  │    ※台数は最大、単価は最低
ニッケル・銅・希土類          → めっき → 全数選別 → テーピング  │
      │                          │                          ├─▶ AIサーバー・DC（2024年〜急伸）
      │ ★村田・太陽誘電などは     │ ★ここで歩留まりが          │    ※1台で数万個。最も高利益
      │   粉から自社で作る        │   利益率を決める            │
      │   ＝後発との最大の差      │   （やり直しの効かない焼成） ├─▶ 自動車（1台で数千〜1万個）
      ▼                          ▼                           │    ※認定の壁。長期安定
  外から買う会社は          1個 0.1〜数円                       │
  材料メーカーの進歩待ち     年間で兆個規模                      ├─▶ 産業機器・FA・インフラ
  → 最先端品が作れない      → 検査ではじく作戦が                 │
                              そもそも成り立たない               └─▶ 電子部品商社 → EMS → 各セット
```

付加価値が集まるのは **(1) 粉の合成、(2) 薄層化と焼成の歩留まり、
(3) 車載・高信頼グレードの認定実績** の3点。
いずれも**装置を買えば手に入るものではない**ところが、この産業の性格を決めている。

## 4. 主要プレイヤーとシェア

**企業名より「何を握っているから強いのか」で読む。**

| 企業 | 立ち位置 | 握っているもの／特徴 |
| --- | --- | --- |
| **村田製作所** | MLCC 世界首位 | **粉の合成から製造装置まで内製**。品種・サイズ展開が最も広く、新しい層厚をいち早く量産化できる。MLCC シェアは同社開示で約4割水準（調査会社推計では3割強との数字もあり定義で幅）。2026年3月期 売上1兆8,308億円 |
| **TDK** | 総合電子部品 | 出自は**フェライト（磁性材料）**。インダクタ・磁性部品に強い。実は最大の収益源は**二次電池（ATL）**で、部品会社としては異例の構造 |
| **太陽誘電** | MLCC特化 | コンデンサが売上の約7割。**最も MLCC 純度が高い**ため市況の波が利益に直撃する。2026年3月期は営業利益+91.2% |
| **京セラ** | セラミック総合 | ファインセラミックスの幅。稼ぎ頭は**半導体用セラミック／有機パッケージ**であり、電子部品事業単体の利益率は2.0%と低い |
| **日本電波工業（NDK）／セイコーエプソン／大真空** | 水晶デバイス | 周波数精度。**狂えば製品ごと止まる**領域で選ばれ続ける。NDK は車載向けが売上の約半分 |
| **ローム／KOA** | 抵抗・小信号 | 単価が最も低い世界。規模と自動化がすべて |
| **日本ケミコン／ニチコン／ルビコン** | アルミ電解 | 大容量・電源系。MLCC とは用途で住み分け |
| **サムスン電機（SEMCO）**（韓） | MLCC 2番手級 | グループ内需要を基盤に車載・AIサーバーへ攻勢。2026年8月に約30%の値上げと報じられる |
| **国巨（Yageo）／華新科（Walsin）**（台） | 汎用受動部品 | **数量と買収で規模を作る**。日本勢が抜けた汎用品の受け皿 |
| **風華高科／三環集団**（中） | 追い上げ | 国産化政策を背景に汎用品から浸透。代替型番を日本市場にも供給 |

> 共通する問いは一つ。**「償却の重い設備を、どれだけ利益率の高い品種で埋められるか」**。
> どの社の戦略もこの問いへの答えとして読むと整理できる。

## 5. 収益モデル・コスト構造

**利益は「何を作ったか」ではなく「どの品種を、どの歩留まりで作れたか」で決まる。**

| 費目 | 目安 | 性質 |
| --- | --- | --- |
| 材料費（セラミック粉、ニッケル、銅、希土類、パラジウム） | 売上の2〜3割程度 | 変動費。金属市況に連動 |
| 減価償却費 | 売上の1割前後 | **固定費**。工場を建てた瞬間から発生 |
| 電力（焼成炉）・人件費 | 半固定 | 自動化が進み人件費比率は低い |
| 研究開発費 | 売上の5〜7%程度 | 固定 |

- **営業レバレッジが極端に強い**。稼働率が落ちると固定費が減らず、利益が一気に消える。
  逆に好況では売上の伸び以上に利益が伸びる（太陽誘電 2026年3月期：売上+4.1%、営業利益+91.2%）
- **1個 0.5円の部品では、不良を検査ではじく作戦が成り立たない**。
  だから歩留まりを最初から出せる工程力そのものが利益率になる
- **品番数が数万〜十数万**（サイズ×容量×温度特性×耐圧の掛け算）。
  段取り替えと在庫が重く、**採算品種の絞り込み（EOL）**が構造改革の定番テーマになる
- 同じ「電子部品」でも品種構成で利益率は桁違い。
  2026年3月期で京セラ電子部品事業が2.0%、太陽誘電が営業利益+91%というのはその現れ

→ 詳細は [市場の波と儲け方](03_市場の波と儲け方.md)

## 6. 競争要因（KSF）と参入障壁

**障壁は「金額」ではなく「材料」と「時間」でできている。**

| 要因 | 中身 |
| --- | --- |
| **粉を自分で作れるか** | チタン酸バリウム粉を、粒径0.1μm級で揃えて合成できるか。層を薄くするほど粉の質が直接効く。**外から買う会社は自社設計が材料メーカーの進歩に縛られる** |
| **焼成条件の窓** | ニッケル電極を酸化させず、セラミックを還元させない極めて狭い条件を通す。希土類の微量添加設計が各社最大の機密とされる |
| **歩留まり** | 原因が数百因子に分散し、品種ごとに対策が違う。**長く作った会社しか持てない資産** |
| **改良ループの速さ** | 材料・工程・装置が社内にあると試作サイクルが1〜2週間。外注だと年単位。差が開き続ける |
| **車載認定（AEC-Q200等）** | 取得に年単位。しかも**10年以上の継続供給義務**と、工程を勝手に変えられない不自由さを引き受ける必要がある |
| **品番の幅** | 顧客が欲しい容量・サイズ・温度特性が即座に出せるか。品揃えそのものが参入障壁になる |

逆に**崩されている部分**もある。汎用・低容量品は装置を買えば作れるため、
すでに台湾・中国勢の主戦場になっている。
しかも日本勢が採算品種を絞る（EOL する）ことで、後発が規模と経験を積む場を与えている面がある。
→ [作り方と強さの源泉](02_作り方と強さの源泉.md#6-では後発はどこから崩しているのか)

## 7. 規制・法制度

許認可で守られた産業ではない。効くのは**規格・通商・資源**の3つ。

| 制度 | 内容 |
| --- | --- |
| **AEC-Q200** | 車載用受動部品の信頼性試験規格。車載グレードの事実上の入場券 |
| **IATF 16949／ISO 9001** | 自動車産業の品質マネジメント規格。取引の前提条件 |
| **EIA／JIS のチップ寸法規格** | 0603・1005 等の外形標準。互換性を担保する一方、価格競争の土台にもなる |
| **RoHS／REACH（EU）** | 有害物質の使用制限。鉛フリー化などで材料設計に直接影響した |
| **輸出管理・通商** | 米中間の関税・輸出管理。部品は最終製品に組み込まれて動くため影響が読みにくい |
| **資源政策（希土類等）** | 添加物に使う希土類の供給・輸出管理 → [レアメタル・レアアース](../../11_資源・エネルギー・鉄鋼金属/13_レアメタル・レアアース/README.md) |
| **各国の国産化政策** | 中国の部品国産化推進が、汎用品市場での競合を後押ししている |

## 8. 最近のトピック

詳細と出典は **[直近トピック_2026](04_直近トピック_2026.md)**。

1. **AI需要で MLCC が逼迫**。2026年6月下旬時点でBBレシオは村田1.30、サムスン電機1.31、太陽誘電1.25と報じられ、コロナ後の高水準。**装置納期が最大18か月、能力増は年10〜15%が限界**とされ、金を出しても増えない
2. **値上げが通っている**。村田はAIサーバー向け高容量品・車載ハイエンド品で**15〜35%**（2026年4月1日）、サムスン電機は全体で**約30%**（同8月1日）と報じられる
3. **村田が一部汎用MLCCを生産終了へ**。最終受注期限2028年3月31日とされ、台湾の国巨・華新科などへの転注が見込まれると報じられる。**陣地の入れ替えだが、後発に育つ時間を与える**側面もある
4. **2026年3月期は各社好調だが中身が違う**。村田は売上過去最高（1兆8,308億円、+5.0%）、TDKは営業利益+21.5%で過去最高、太陽誘電は営業利益+91.2%、一方で京セラ電子部品事業の利益率は2.0%
5. **スマートフォンは逆風**。メモリ不足を主因に2026年の世界出荷が**前年比 約−14%（10.8億台程度）**との予測（Counterpoint・報道ベース）。**数量は減るのに金額は増える**という、過去とは違う形の好況になっている

## 9. 用語メモ

各ノート末尾にも用語メモがある。ここでは最重要の8語。

| 用語 | 意味 |
| --- | --- |
| **受動部品** | 増幅もスイッチもしない部品。コンデンサ・インダクタ・抵抗器 → [電子部品とは何か](01_電子部品とは何か.md) |
| **MLCC** | 積層セラミックコンデンサ。誘電体と電極を数百層積んだチップ部品。この産業の主役 → [電子部品とは何か](01_電子部品とは何か.md) |
| **デカップリング** | ICのすぐ隣にコンデンサを置いて電源変動を吸収すること。**MLCC が大量に必要になる物理的な理由** → [電子部品とは何か](01_電子部品とは何か.md) |
| **チタン酸バリウム** | MLCC の誘電体セラミック。粉の粒径と純度が製品性能を決める → [作り方と強さの源泉](02_作り方と強さの源泉.md) |
| **還元雰囲気焼成** | ニッケル電極を酸化させないための低酸素焼成。セラミック側は還元させてはいけない、という狭い条件 → [作り方と強さの源泉](02_作り方と強さの源泉.md) |
| **歩留まり** | 投入に対する良品比率。単価が極小の部品では利益率をほぼ決める → [作り方と強さの源泉](02_作り方と強さの源泉.md) |
| **ブルウィップ効果** | 末端需要の小さな変動が川上ほど増幅される現象。業績が乱高下する主因 → [市場の波と儲け方](03_市場の波と儲け方.md) |
| **BBレシオ** | 受注額÷出荷額。1超で需要超過。市況の位置を測る代表指標 → [直近トピック_2026](04_直近トピック_2026.md) |
