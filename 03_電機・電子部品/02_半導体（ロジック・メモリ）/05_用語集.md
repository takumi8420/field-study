# 半導体 用語集

半導体まわりのノートに出てくる用語を1か所に集めた索引。
詳しい説明があるノートへリンクしてある。

## 1. 物理・デバイス

| 用語 | 意味 |
| --- | --- |
| **ドーピング** | シリコンに微量の不純物を混ぜて電気的性質を変えること → [トランジスタの原理](04_トランジスタの原理.md) |
| **n型 / p型** | 電子が余る型／電子が足りない（正孔がある）型 |
| **正孔（ホール）** | 電子の空席。プラスの電荷として振る舞う |
| **MOSFET** | 現在のICの主役。ゲート電圧でチャネルを作りON/OFFする電界効果トランジスタ |
| **ソース / ドレイン / ゲート** | 電子の出口／入口／制御電極 |
| **チャネル** | ソース-ドレイン間の電流の通り道 |
| **反転層** | ゲート電圧で表面に誘起される電子の層。これがチャネルになる |
| **しきい値電圧（Vth）** | ONになる境目の電圧 |
| **CMOS** | nMOSとpMOSを対にした構成。静止時の消費電力がほぼゼロ |
| **リーク電流** | OFFにしても漏れる電流。微細化の最大の敵 |
| **短チャネル効果** | チャネルが短すぎてゲートが制御しきれなくなる現象 |
| **High-k / メタルゲート** | 絶縁膜のトンネル漏れ対策（2007年頃導入） |
| **FinFET** | チャネルをヒレ状に立て3面から囲む構造（2011年〜） |
| **GAA / ナノシート** | 板状チャネルを全周から囲む構造（2nm世代の主役） |
| **デナード則** | 寸法を縮めれば電圧も下げられ、速く省電力になるという経験則。2000年代に崩れた |
| **ムーアの法則** | 集積度が約2年で倍になるという経験則。鈍化したが等価スケーリングで延命中 |
| **IGBT** | MOSFETで制御しバイポーラで大電流を流す複合素子。パワー用途 |
| **SiC / GaN** | 高電圧・高温に強い次世代パワー半導体材料 |

## 2. 材料・ウェハー

| 用語 | 意味 |
| --- | --- |
| **ウェハー** | 回路を作り込むシリコンの円盤。主流は直径300mm → [シリコンウェハー](../04_半導体材料/01_シリコンウェハー.md) |
| **インゴット** | 輪切りにする前の円柱状の単結晶 |
| **CZ法（チョクラルスキー法）** | 溶かしたシリコンから単結晶を引き上げる製法 |
| **ノッチ** | ウェハー端の切り欠き。結晶方位の目印 |
| **エピウェハー** | 表面にさらに単結晶層を成長させた高品質ウェハー |
| **フォトレジスト** | 光で溶けやすさが変わる感光性樹脂。パターンを転写する主役 |
| **CMPスラリー** | 平坦化研磨に使う研磨液 |
| **封止材（モールド樹脂）** | チップを保護する樹脂 |

## 3. 前工程（ウェハープロセス）

| 用語 | 意味 |
| --- | --- |
| **前工程** | ウェハー上にトランジスタと配線を作り込む工程。2〜3ヶ月 → [前工程](02_前工程.md) |
| **成膜（CVD / ALD / PVD）** | 表面に薄膜を付ける工程。ALDは原子層単位 |
| **リソグラフィ（露光）** | マスクの回路パターンを光で転写する工程 |
| **レチクル（フォトマスク）** | 回路の原版。先端品では1セット数億円以上 |
| **ペリクル** | マスクを異物から守る薄膜カバー |
| **EUV** | 波長13.5nmの露光技術。ASMLの独占 |
| **High-NA EUV** | 解像度を上げた次世代EUV。1台400億円級 |
| **ArF液浸** | 193nm光源＋水を挟んで実効解像度を上げる方式 |
| **マルチパターニング** | 1つのパターンを複数回に分けて描く手法。EUVが使えない場合の代替 |
| **エッチング** | レジストのない部分を削り、パターンを膜に転写する工程 |
| **イオン注入** | 不純物を撃ち込んでn型/p型を作る工程 |
| **CMP** | 化学機械研磨。表面を平らに戻す |
| **FEOL / MOL / BEOL** | トランジスタ形成／コンタクト／多層配線。**BEOLは後工程ではなく前工程の後半** |
| **ダマシン法** | 溝を掘って銅を埋め、余りを削る配線形成法 |
| **low-k** | 配線間の寄生容量を下げる低誘電率絶縁膜 |
| **BSPDN（裏面電源供給）** | 電源配線をウェハー裏面に回す技術。Intel PowerVia、TSMC Super Power Rail |
| **歩留まり（Yield）** | 良品ダイの割合。収益性を決める最重要KPI |
| **ウェハーテスト（EDS）** | 切り出す前にプローブ針で良否判定する検査 |
| **標準セル** | NANDなどの検証済み小回路。EDAが多数配置してデジタル回路を組み上げる → [ウェハー上にチップができるまで](06_ウェハー上にチップができるまで.md) |
| **配置配線（Place and Route）** | 論理ゲートをチップ上へ物理配置し、金属配線で接続する設計工程 |
| **スクライブライン** | ウェハー上でダイ同士を隔てる切断用の余白 |
| **OPC** | 光の回折による像の崩れを予測し、マスク形状を逆補正する技術 |
| **オーバーレイ** | 異なる回路層を上下に重ねる位置精度 |
| **プローブカード** | 切断前のダイへ電源・信号を与えて検査する多数の微小端子を持つ治具 |

## 4. 後工程（組立・検査）・パッケージ

| 用語 | 意味 |
| --- | --- |
| **後工程** | ウェハーを切り、パッケージに仕立て検査する工程。数日〜2週間 → [後工程](03_後工程.md) |
| **ダイ（Die）** | 切り出した個々のチップ |
| **バックグラインド** | ウェハー裏面を削って薄くする工程 |
| **ダイシング** | ウェハーをチップに切り分ける工程。ステルスダイシング等 |
| **ワイヤボンディング** | 細線でチップと端子をつなぐ古典的な接続法 |
| **フリップチップ** | バンプを介してチップを裏返して直接接合する方式 |
| **バンプ** | 接続用の微小なはんだ突起 |
| **モールド（封止）** | 樹脂で固めて保護する工程 |
| **ファイナルテスト** | 全機能・全速度を試す最終検査。テスタ＋ハンドラ |
| **バーンイン** | 高温高電圧で初期不良を炙り出す試験 |
| **ビニング** | テスト結果で性能別に品番を分けること |
| **KGD（Known Good Die）** | 良品と確認済みの裸チップ。積層前に必須 |
| **TSV** | シリコン貫通電極。チップを縦方向につなぐ |
| **インターポーザ** | チップと基板の間に挟む中継配線板 |
| **CoWoS** | TSMCの2.5D実装技術。AI向けGPUのボトルネック |
| **WLP / FOWLP** | ウェハー状態のままパッケージまで作る方式 |
| **ハイブリッドボンディング** | バンプを使わず銅同士を直接接合する高密度接続 |
| **チップレット** | 機能別の小チップを1パッケージに統合する設計思想 |
| **UCIe** | チップレット間の接続標準規格 |
| **FC-BGA / BGA / CSP / SiP** | パッケージ形式。FC-BGAはCPU・GPU向けの本命 |
| **HBM** | DRAMを積層した広帯域メモリ。AI用途の必需品 |

## 5. 業界構造・ビジネス

| 用語 | 意味 |
| --- | --- |
| **IDM** | 設計から製造・販売まで自社で行う垂直統合型 → [サプライチェーンと業界構造](01_サプライチェーンと業界構造.md) |
| **ファブレス** | 設計専業。製造は外注 |
| **ファウンドリ** | 製造受託専業。TSMCが最先端をほぼ独占 |
| **OSAT** | 後工程（組立・検査）の受託企業 |
| **EDA** | 設計自動化ツール。Synopsys、Cadence、Siemens EDA |
| **IP** | 設計の再利用部品（Armコア等）。ライセンス商売 |
| **PDK** | プロセス設計キット。そのファウンドリで設計するための情報一式 |
| **テープアウト** | 設計を確定してマスク製造に回すこと |
| **リスク生産** | 量産直前の試作段階 |
| **シリコンサイクル** | 数年周期の需給・価格変動 |
| **BBレシオ** | 受注額÷出荷額。1を超えると需要拡大の目安 |
| **TAT** | Turn Around Time。依頼から納品までの時間 |
| **ホットロット** | 優先的に流す特急ロット |
| **PPAC** | Performance / Power / Area / Cost。ノード比較の物差し |

## 6. 先端ノード・AI

| 用語 | 意味 |
| --- | --- |
| **プロセスノード（◯nm）** | 世代を示すブランド名。**実寸ではない** → [「2nm」「3nm」の正確な意味](../../01_注目テーマ/02_半導体・先端半導体/05_プロセスノード名の正確な意味.md) |
| **CPP** | ゲートピッチ。先端で45〜50nm前後 |
| **MMP** | 最小配線ピッチ。20〜30nm前後 |
| **トラック（T）** | 標準セルの高さの単位。6T→5Tで面積が縮む |
| **MTr/mm²** | 面積あたりのトランジスタ数。密度の指標 |
| **Å（オングストローム）** | 0.1nm。A16＝1.6nm世代、A14＝1.4nm世代 |
| **DTCO** | 設計と製造を一体で最適化する手法 |
| **学習 / 推論** | AIモデルを作る工程／作ったモデルを使う工程 → [AI半導体とHBM](../../01_注目テーマ/02_半導体・先端半導体/02_AI半導体とHBM.md) |
| **メモリの壁** | 演算性能に対しデータ転送が追いつかない問題 |
| **ラックスケール** | チップ単体でなくラック丸ごとを1台の計算機として売る形態 |
| **トークン** | 生成AIの処理単位。推論コストはトークン当たりで語られる |

## 7. 地政学・制度

| 用語 | 意味 |
| --- | --- |
| **エンティティリスト** | 米国が輸出を制限する企業リスト → [地政学と各国政策](../../01_注目テーマ/02_半導体・先端半導体/03_地政学と各国政策.md) |

## 8. 半導体の種類

詳しい比較は[半導体の種類と役割](07_半導体の種類と役割.md)を参照。

| 用語 | 意味 |
| --- | --- |
| **ロジック半導体** | 計算・判断・制御を担う。CPU、GPU、MCU、ASIC、FPGAなど |
| **メモリ半導体** | 情報を保持する。SRAM、DRAM、NAND、NORなど |
| **揮発性／不揮発性** | 電源を切ると内容が消える／残るというメモリの分類 |
| **アナログ半導体** | 音、温度、電圧、電波など連続的な信号を増幅・変換・調整する |
| **ミックスドシグナル** | アナログ回路とデジタル回路を1チップに統合した構成 |
| **ADC / DAC** | アナログからデジタルへの変換／デジタルからアナログへの変換 |
| **PMIC** | 電圧変換、電源順序、監視、保護などを担う電源管理IC |
| **パワー半導体** | 大きな電圧・電流を変換・制御する半導体。ダイオード、MOSFET、IGBTなど |
| **ディスクリート** | 単一または少数の素子を独立部品にした半導体 |
| **オプトエレクトロニクス** | 電気と光を相互変換する半導体。LED、レーザー、受光素子など |
| **MEMS** | 半導体加工で作る微小な機械構造。加速度センサーやマイクなどに使う |
| **ワイドバンドギャップ半導体** | SiCやGaNなど、高耐圧・高温・高速動作に適した材料群 |
