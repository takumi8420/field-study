半導体｜後工程（Back-End / 組立・検査）

電機・電子部品半導体（ロジック・メモリ）
あこのページの単語集用語に触れると意味を確認できます14語
配線を外に出す守る熱を逃がす扱えるようにするDIP / QFP / SOPBGAFC-BGACSPSiPダイ（Die）バンプインターポーザKGD（Known Good Die）BEOL との混同注意

定義：完成したウェハーを切り分け、1個ずつ扱える「パッケージ」に仕立てて検査する工程。
入口は回路が焼き込まれたウェハー、出口はトレイやテープに載った製品としてのチップ。

  • 期間：数日〜2週間（前工程の2〜3ヶ月に比べて圧倒的に短い）
  • 場所：前工程ほどの超クリーン環境は不要。かつては人件費の安い東南アジア・中国に集約
  • 担い手：IDMの自社工場、またはOSAT（ASE、Amkor、JCET、PTI）。近年はTSMCも先端パッケージに本格参入

なぜパッケージが必要か

  1. 配線を外に出す：µm単位のチップの端子を、基板にはんだ付けできるmm単位に変換する（再配線）
  2. 守る：湿気・汚れ・物理衝撃・光からチップを保護する
  3. 熱を逃がす：発熱をヒートスプレッダ・基板へ伝える
  4. 扱えるようにする：実装機で自動搭載できる形状・強度を与える

標準的な後工程フロー

バックグラインド → ダイシング → ダイボンディング → 接続(ワイヤ/フリップチップ)
   → 封止(モールド) → メッキ・マーキング → 切断成形 → 最終テスト → 外観検査 → 梱包出荷
# 工程 中身 要点
1バックグラインド（裏面研削）ウェハー裏を削って 775µm → 数十〜200µm に薄くする薄型化・放熱・積層のため。割れとの戦い
2ダイシングウェハーを碁盤目に切ってチップ（ダイ）に分割ブレード／レーザー／ステルスダイシング（内部改質して割る、ディスコ・浜松ホトニクス）
3ダイボンディング（マウント）良品ダイをリードフレームや基板に接着ウェハーテストの良品マップを見て良品だけ拾う
4-aワイヤボンディング金または銅の細線でチップと端子を接続安価で枯れた技術。端子数に限界
4-bフリップチップチップ表面にバンプ（はんだ突起）を作り、裏返して基板に直接接合端子数を多く取れ、配線が短く高速。先端品の主流
5封止（モールド）エポキシ樹脂で固める材料は住友ベークライト、レゾナック等が強い
6メッキ・マーキングはんだ濡れ性確保、品番レーザー刻印トレーサビリティ
7切断成形（トリム＆フォーム）連結したリードを切り、脚を曲げるパッケージ形状が確定
8最終テスト（ファイナルテスト）高温・低温も含めて全機能・全速度を試験テスタ（アドバンテスト、Teradyne）＋ハンドラ。不良を市場に出さない最後の砦
9バーンイン高温・高電圧で強制的に初期不良を炙り出す車載・産業向けなど信頼性要求が高い品種で実施
10外観検査・梱包テープ＆リール、トレイに載せて出荷セットメーカー／EMSの実装ラインへ

選別の考え方

  • 同じ設計でも、テスト結果で動作周波数や有効コア数ごとにグレード分けして別品番として売る（ビニング）
  • 前工程のウェハーテストで落とし、後工程の最終テストで再度落とす二段構え。
    後工程まで進んだ不良は組立コストが無駄になるので、前段で落とすほど得

先端パッケージ：いまの主戦場

微細化が鈍った結果、「1つのチップを小さくする」競争から「複数のチップを賢く束ねる」競争へ移った。
後工程は「安い労働集約工程」から「性能を決める付加価値工程」に変わった。

技術 内容
WLP / FOWLPウェハーの状態のままパッケージまで作る。小型・薄型（TSMC InFO、スマホ向け）
2.5D（CoWoS等）シリコンインターポーザという「土台の配線板」の上に、ロジックとHBM（積層DRAM）を並べて載せる。AI向けGPUの標準構成
3D積層・TSVチップに垂直の穴（TSV）を空けて上下を直結し、積み重ねる。HBMや3D NANDで使用
ハイブリッドボンディングバンプを使わず銅と絶縁膜を直接接合。極めて高密度・短配線
チップレットCPU/GPUを機能ブロックごとの小チップに分割し、1パッケージに統合。歩留まりと設計効率が上がる。接続規格がUCIe

AI半導体の供給制約が「TSMCのCoWoS能力」と語られるのは、前工程ではなく後工程がボトルネックだから。
この一点を理解しているかどうかで、半導体ニュースの読み方が変わる。

パッケージの呼び名（読めれば十分）

  • DIP / QFP / SOP：脚が外に出ている古典的タイプ
  • BGA：裏面にはんだボールを格子状に配置。端子数を稼げる
  • FC-BGA：フリップチップ＋BGA。CPU・GPU向けの本命。基板はイビデン、新光電気、AT&Sなどが供給
  • CSP：チップとほぼ同サイズの超小型パッケージ
  • SiP：異種のチップや受動部品を1パッケージに同居させる

ビジネスとして見たときの要点

  • 従来型の後工程は参入障壁が低く低利益率。OSATは稼働率商売
  • 一方で先端パッケージは装置・材料・歩留まりノウハウが効き、TSMCとOSAT上位が寡占
  • 日本勢の強み：ダイシング・グラインダ（ディスコ）、テスタ（アドバンテスト）、ボンダ、封止材、パッケージ基板
  • 後工程の投資は前工程より1桁小さく、立ち上げが速い。需要急増時の調整弁になりやすい

用語メモ

  • ダイ（Die）：切り出した半導体チップ本体
  • バンプ：フリップチップ接続用の微小なはんだ突起
  • インターポーザ：チップと基板の間に挟む中継配線板
  • KGD（Known Good Die）：良品と確認済みの裸チップ。積層前に必須
  • BEOL との混同注意：BEOLは前工程の配線工程。後工程＝Assembly & Test
