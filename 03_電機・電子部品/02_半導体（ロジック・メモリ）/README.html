1. 業界の定義・範囲

シリコン等の半導体材料に微細な回路を形成し、演算・記憶・電力制御を担う部品を作る産業。
設計（ファブレス）／製造（ファウンドリ）／後工程（OSAT）／装置／材料の5層に分かれ、
それぞれ別の業界として分析するのが実務的。

2. 市場規模と成長性

  • 世界市場は2024年時点で約6,000億ドル台。2030年に1兆ドル到達が業界共通の目標値（WSTS等）
  • シリコンサイクルとは何か
  • 足元の成長ドライバーはAIデータセンター向け（GPU・HBM・先端パッケージ）
  • ※具体的な数値は必ず最新のWSTS統計・各社IRで確認する

3. バリューチェーン

EDA/IP → 設計 → マスク → 前工程 → 後工程 → 実装 。
詳細は ① サプライチェーンと業界構造。

5. 収益モデル・コスト構造

  • 製造側は装置の減価償却が主コストの典型的な装置産業 → 稼働率がすべて
  • 設計側（ファブレス）は固定費が軽く高利益率。価値の源泉は設計資産とソフトウェアエコシステム
  • 単価は ウェハー加工費 ÷ 1枚から取れる良品ダイ数 で決まる → 歩留まりとダイ面積が命

6. 競争要因（KSF）と参入障壁

微細化投資を継続できる資金力／歩留まりの改善ノウハウ／顧客との共同開発／
装置・材料の調達力／（設計側は）開発ツールとエコシステム。
工場1つで1兆円超という投資規模そのものが最大の障壁。

7. 規制・法制度

米国の対中輸出規制（先端装置・AI半導体）、日本・オランダの装置輸出管理、
各国の補助金（米CHIPS法、EUチップス法、日本の経済安保関連予算）。
経済安全保障の中心テーマであり、政治が需給に直接影響する数少ない産業。

8. 最近のトピック・技術トレンド

  • 微細化の減速 → チップレット＋先端パッケージへ主戦場が移動
  • AI向けの制約は前工程よりもCoWoS等の後工程能力とHBM供給
  • GAA（2nm世代）とHigh-NA EUVの立ち上がり
  • パワー半導体のSiC／GaN化（EV・再エネ）
  • 各国の国内生産回帰と、日本のRapidus・熊本TSMCなど国内投資
