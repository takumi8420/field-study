# 半導体｜種類と役割

このノートで分かることは、ロジック、メモリ、アナログ、パワー、光半導体、センサーなどの違いと、電子機器の中でどう協力しているかである。
結論から言えば、半導体は「計算する」「覚える」「現実世界と信号をやり取りする」「電力を制御する」という役割に分かれる。ただし分類軸は重なり、1つのチップが複数の役割を持つことも多い。

## 1. まず押さえる分類の全体像

米国半導体工業会（SIA）は、半導体製品を大きくロジック、メモリ、アナログ、ディスクリート、オプトエレクトロニクス、センサー／アクチュエーターの6種類に整理している。

| 種類 | 一言でいうと | 代表製品 | 主な用途 |
| --- | --- | --- | --- |
| ロジック | 計算・判断する | CPU、GPU、MCU、ASIC、FPGA | PC、スマホ、車、データセンター |
| メモリ | 情報を覚える | SRAM、DRAM、NAND、NOR | 作業領域、キャッシュ、データ保存 |
| アナログ | 現実の連続信号を扱う | アンプ、ADC/DAC、電源管理IC、RF IC | 音、温度、電圧、無線、電源 |
| ディスクリート | 単機能の素子として使う | ダイオード、トランジスタ、パワーMOSFET | 整流、保護、増幅、電力スイッチ |
| オプトエレクトロニクス | 光を出す・受ける | LED、レーザーダイオード、受光素子、イメージセンサー | 照明、通信、カメラ |
| センサー／アクチュエーター | 物理量を測る・動きに変える | 加速度、圧力、温度、MEMSマイク | 自動車、スマホ、産業機器 |

```
現実世界
   │ 光・音・温度・圧力
   ▼
センサー → アナログ変換 → ロジック処理 ↔ メモリ
                                │
                                ▼
                          通信・表示・制御
                                │
電源 ── パワー半導体 ────────────┘
```

電子機器は、どれか1種類だけでは成立しない。たとえばCPUが計算できても、電源を適切な電圧へ変えるパワー／アナログ回路や、プログラムを置くメモリがなければ動作できない。

## 2. 「分類軸が重なる」ことが重要

「ロジック半導体」と「パワー半導体」を完全に排他的な箱として考えると混乱する。半導体には少なくとも3つの分類軸がある。

| 分類軸 | 分類例 | 何を見ているか |
| --- | --- | --- |
| 機能 | ロジック、メモリ、アナログ、パワー、センサー | 何をするか |
| 集積度・形態 | ディスクリート、IC、モジュール | 1個の素子か、多数を集積した回路か |
| 材料 | Si、SiC、GaN、GaAs | 何で作るか |

たとえばパワー半導体には、パワーMOSFETのような単体素子も、電圧を制御する電源管理ICもある。前者は統計上「ディスクリート」、後者は「アナログIC」に分類されることがある。

また、SoC（System on a Chip）は主分類としてロジックであっても、内部にSRAM、アナログ回路、画像処理回路などを内蔵する。SIAも、SoCはロジック製品でありながらアナログとメモリを含み得ると説明している。

> ポイント：「何をする半導体か」と「どんな形・材料で作られたか」を分けて考える。

## 3. ロジック半導体――計算・判断・制御する

ロジック半導体は、0と1の信号を論理回路で処理する。微細化により多くのトランジスタを集積すると、一般に計算量、並列度、内蔵機能を増やしやすい。

| 種類 | 得意なこと | 特徴 |
| --- | --- | --- |
| CPU / MPU | 幅広いプログラムの実行 | 高機能なコアで複雑な処理を行う |
| GPU | 同じ種類の計算を大量並列実行 | 画像処理、AI、科学計算に強い |
| MCU（マイコン） | 機器の制御 | CPU、メモリ、周辺回路を1チップに統合 |
| DSP | 信号処理 | 音声、画像、通信の積和演算に強い |
| ASIC | 特定用途専用の処理 | 用途に最適化できるが設計変更しにくい |
| FPGA | 出荷後にも回路を書き換えられる | 柔軟だが、同等ASICより面積・電力で不利になりやすい |
| SoC | 複数機能を1チップに統合 | スマホや組み込み機器の中核 |

ロジックでは、同じ面積へ多くの回路を入れ、配線を短くし、電力当たりの処理性能を上げることが重要である。そのため高性能CPU、GPU、スマホSoCは先端プロセスの主要顧客になる。一方、車載や家電のMCUは最高速度より、長期供給、信頼性、コスト、内蔵アナログ機能が重視され、成熟した製造世代も広く使われる。

## 4. メモリ半導体――情報を保持する

メモリは「電源を切ると消えるか」「読み書き速度」「容量」「書き換え耐久性」「ビット単価」の組み合わせで使い分ける。

| 種類 | 電源OFF後 | 速さ | 主な役割 |
| --- | --- | --- | --- |
| SRAM | 消える | 非常に速い | CPU/GPUのキャッシュ |
| DRAM | 消える | 速い | PC、スマホ、サーバーの主記憶 |
| HBM | 消える | 非常に広帯域 | AIアクセラレーターの近傍メモリ |
| NANDフラッシュ | 残る | 読み出しは速いがDRAMより遅い | SSD、スマホ、メモリーカード |
| NORフラッシュ | 残る | ランダム読み出しが得意 | 機器を起動するプログラムの保存 |

```
CPUに近い                                           容量が大きい

レジスタ → SRAMキャッシュ → DRAM / HBM → NANDストレージ
  最速・小容量                           低速・大容量・不揮発
```

### SRAM・DRAM・NANDの構造差

- **SRAM**：一般に1ビットを複数のトランジスタで保持する。速いが面積を使う
- **DRAM**：一般に1トランジスタ＋1キャパシタで1ビットを保持する。定期的な再書き込みが必要
- **NAND**：メモリセルの電荷状態を読み分ける。3D NANDではセルを縦方向に多数積層して容量を増やす

メモリは同じ規格の製品を大量生産する市況商品の性格が強い。需要より供給能力が増えると単価が急落しやすく、設備投資、在庫、価格の循環が利益を大きく左右する。DRAMはSamsung Electronics、SK hynix、Micron、NANDはこれらにキオクシアなどが主要企業である。

## 5. アナログ半導体――現実世界との通訳

音、光、温度、電圧、電波などは、0か1だけではなく連続的に変化する。アナログ半導体は、この連続信号を増幅・変換・調整し、デジタル回路へ橋渡しする。

| 種類 | 役割 | 例 |
| --- | --- | --- |
| アンプ | 小さな信号を大きくする | マイク信号、センサー信号 |
| ADC | アナログ信号をデジタル値へ変換 | 音声録音、温度計測 |
| DAC | デジタル値をアナログ信号へ変換 | 音声再生、モーター制御 |
| インターフェースIC | 異なる電圧・通信方式をつなぐ | USB、車載通信、産業通信 |
| RF IC | 高周波の電波を送受信・変換する | スマホ、Wi-Fi、基地局 |
| PMIC | 電圧変換、電源順序、保護を管理する | スマホ、サーバー、車載機器 |

アナログでは、単にトランジスタを小さくするよりも、雑音の少なさ、電圧精度、耐圧、温度安定性、長期信頼性が重要になる。そのため最先端ノードだけが競争力を決めるわけではなく、独自プロセス、回路設計ノウハウ、数万品種を長期間供給する能力が参入障壁になる。代表企業にはTexas Instruments、Analog Devices、Infineon、STMicroelectronics、ルネサスなどがある。

## 6. パワー半導体――電力を変換・制御する

パワー半導体は情報そのものより、電気エネルギーを「流す・止める・変換する」役割を担う。小さな制御信号で大きな電圧・電流を高速に切り替え、電力損失を減らすことが価値になる。

```
バッテリー／商用電源
        ↓
パワー半導体で高速スイッチング
        ↓
直流↔交流、昇圧・降圧、周波数変換
        ↓
モーター、CPU、照明、充電器などへ必要な電力を供給
```

| 素子 | 得意な領域 | 主な用途 |
| --- | --- | --- |
| パワーダイオード | 一方向に電流を流す、整流する | 電源、保護回路 |
| パワーMOSFET | 高速スイッチング | 電源、車載補機、低〜中電圧用途 |
| IGBT | 大電力を比較的低損失で制御 | 産業モーター、鉄道、EVインバーター |
| SiC MOSFET | 高電圧・高温・高効率 | EV、急速充電、太陽光、データセンター電源 |
| GaN HEMT | 高速・高周波スイッチング | 小型充電器、通信、データセンター電源 |
| パワーモジュール | 複数素子と接続・放熱を一体化 | 車、鉄道、産業設備 |

### ロジックとの設計思想の違い

| ロジック半導体 | パワー半導体 |
| --- | --- |
| 小さな信号を高速処理する | 大きな電力を安全に扱う |
| 集積度と計算性能を重視 | 耐圧、オン抵抗、スイッチ損失、放熱を重視 |
| 水平方向に回路を高密度集積 | 電流を縦方向に流す構造も多い |
| 先端微細化が競争軸になりやすい | 材料、膜厚、欠陥、実装技術が重要 |

Infineonの製品説明では、Si、SiC、GaNを使い分け、マイクロアンペア級からメガワット級までの電力制御を対象としている。パワー半導体は「性能の高い計算機」ではなく、電子機器が必要な電力を無駄なく供給するための高速スイッチである。

## 7. ディスクリート半導体――単機能を1部品として使う

ディスクリートは、1つまたは少数の半導体素子を独立部品にしたものを指す。多数の素子を一体化するICとは、機能ではなく集積の形が違う。

| ディスクリート製品 | 役割 |
| --- | --- |
| ダイオード | 整流、逆流防止、保護 |
| 小信号トランジスタ | 増幅、スイッチング |
| パワートランジスタ | 電力のON/OFF |
| サージ保護素子 | 静電気や異常電圧から回路を守る |

ディスクリートは単価が低い製品も多いが、電源、車載、産業機器では数多く必要になる。高耐圧、高温、高信頼性の製品は材料技術や製造ノウハウが差別化要因になる。

## 8. 光半導体――電気と光を変換する

オプトエレクトロニクスは、電気を光へ、または光を電気へ変換する半導体である。シリコンだけでなく、GaAs、InP、GaNなどの化合物半導体も使われる。

| 製品 | 変換 | 用途 |
| --- | --- | --- |
| LED | 電気→光 | 照明、表示、赤外線通信 |
| レーザーダイオード | 電気→指向性の高い光 | 光通信、LiDAR、光ディスク |
| フォトダイオード | 光→電気 | 受光、距離測定、光通信 |
| CMOSイメージセンサー | 光→画像データ | スマホ、車載カメラ、監視カメラ |
| 光通信用トランシーバー | 電気↔光 | データセンター、通信網 |

イメージセンサーは光を受ける画素だけでなく、読み出し用のアナログ回路やデジタル処理回路を同じダイまたは積層ダイに持つ。このため「光」「センサー」「アナログ」「ロジック」の境界にまたがる代表例である。

## 9. センサーとMEMS――物理世界を測る

センサーは、温度、圧力、加速度、磁気、化学物質などの変化を電気信号へ変換する。MEMS（微小電気機械システム）は、半導体加工技術で微小な機械構造を作る方式である。

| センサー | 測るもの | 使用例 |
| --- | --- | --- |
| 加速度・ジャイロ | 動き、傾き、回転 | スマホ、ドローン、車 |
| 圧力センサー | 気圧、液圧 | タイヤ、産業設備、医療機器 |
| 磁気センサー | 磁界、位置 | モーター、電子コンパス |
| 温度センサー | 温度 | 電池管理、家電、サーバー |
| MEMSマイク | 空気の振動 | スマホ、イヤホン、音声機器 |
| アクチュエーター | 電気を微小な動作へ変換 | インクジェット、微小ミラー |

センサー単体の出力は小さく不安定なことが多いため、増幅するアナログ回路、補正・判断するロジック、設定値を覚えるメモリと組み合わせて製品化される。

## 10. 材料による分類――Si、SiC、GaN、GaAs

半導体材料は、それぞれ電圧、周波数、光、コストへの適性が異なる。「新材料がシリコンをすべて置き換える」のではなく、得意領域で使い分ける。

| 材料 | 強み | 主な用途 |
| --- | --- | --- |
| Si（シリコン） | 安価、大口径、高品質、製造基盤が成熟 | ロジック、メモリ、アナログ、パワー全般 |
| SiC（炭化ケイ素） | 高耐圧、高温、低損失 | EV、鉄道、産業・再エネ電力変換 |
| GaN（窒化ガリウム） | 高速・高周波、高効率 | 小型電源、通信、RF、LED |
| GaAs（ヒ化ガリウム） | 高周波性能、発光・受光特性 | 無線フロントエンド、レーザー、光通信 |
| InP（リン化インジウム） | 超高速通信、長波長光通信 | 光トランシーバー、高周波通信 |

材料の違いは、基板価格、結晶欠陥、ウェハー径、製造装置、歩留まりにも影響する。詳細は[半導体材料](../04_半導体材料/README.md)と合わせて読むとよい。

## 11. 製品の中では複数種類が協力する

### スマートフォン

```
SoC（ロジック＋内蔵SRAM）
  ＋ DRAM、NAND（メモリ）
  ＋ RF・音声・電源管理IC（アナログ）
  ＋ イメージセンサー、MEMSマイク、加速度センサー
  ＋ 充電・保護用パワー半導体
```

### 電気自動車

```
MCU / SoC ── 判断・制御
センサー ─── 周囲・車両状態を計測
メモリ ───── プログラム・地図・一時データ
アナログIC ─ 信号変換・電池監視
Si / SiCパワー半導体 ─ モーターと充電電力を制御
```

### AIサーバー

```
CPU・GPU・AI ASIC ─ 演算
SRAM・HBM・DRAM ── 作業データ
NAND SSD ───────── 長期保存
ネットワークIC・光半導体 ─ サーバー間通信
PMIC・パワーMOSFET ───── 電圧変換・電力供給
温度センサー ────────── 監視と冷却制御
```

つまり「AI半導体需要」はGPUだけでなく、HBM、ネットワーク、光通信、電源管理、パワー半導体などへ波及する。

## 12. 種類によってビジネスモデルも違う

| 種類 | 競争の中心 | 供給・収益の特徴 | 主な企業例 |
| --- | --- | --- | --- |
| 先端ロジック | 設計、微細化、ソフトウェア | 開発費が巨大。ファブレス＋ファウンドリ分業が中心 | NVIDIA、AMD、Qualcomm、Intel |
| メモリ | 微細化、積層、量産コスト | 市況変動が激しく、少数IDMの設備投資競争 | Samsung、SK hynix、Micron、キオクシア |
| アナログ | 精度、品種、長期供給 | 製品寿命が長く、独自製造プロセスが効く | Texas Instruments、Analog Devices |
| パワー | 損失、耐圧、放熱、信頼性 | 材料からモジュールまでの統合力が重要 | Infineon、ST、onsemi、ローム、三菱電機 |
| イメージセンサー | 画質、画素、積層技術 | 設計・製造・顧客共同開発が密接 | ソニー、Samsung、OmniVision |
| MCU | 信頼性、周辺機能、ソフト資産 | 車載・産業は認証と長期供給が参入障壁 | ルネサス、NXP、Infineon、ST |

同じ「半導体不足」でも、先端ロジックの露光能力、メモリの投資抑制、車載MCUの成熟ノード能力、SiC基板の品質など、詰まる場所は種類ごとに違う。

## 13. ニュースを読むときの順番

半導体ニュースを見たら、次の順番で確認すると混同しにくい。

1. **機能は何か**：計算、記憶、信号変換、電力制御、検出のどれか
2. **製品形態は何か**：単体素子、IC、複数ダイを組み合わせたモジュールか
3. **材料は何か**：Si、SiC、GaN、GaAsなど
4. **製造世代は何か**：本当に先端微細化が必要か
5. **用途は何か**：PC、スマホ、車、産業、データセンターなど
6. **誰が作るか**：IDM、ファブレス、ファウンドリ、OSATのどこか

## 14. まとめ

半導体の役割は、ロジックが考え、メモリが覚え、アナログが現実世界を翻訳し、センサーが測り、パワー半導体がエネルギーを制御し、光半導体が光を送受信する、と整理できる。

一方、製品は複数の機能を統合するため境界は重なる。「パワー半導体」「ディスクリート」「SiC」はそれぞれ機能、製品形態、材料という別の軸の言葉である。この3軸を分けることが、半導体の種類を理解する最も重要なポイントである。

## 用語メモ

- **ロジック**：デジタル信号を計算・判断・制御する半導体
- **揮発性メモリ**：電源を切ると内容が消えるメモリ。SRAM、DRAMなど
- **不揮発性メモリ**：電源を切っても内容が残るメモリ。NAND、NORなど
- **ミックスドシグナル**：アナログ回路とデジタル回路を1チップに持つ構成
- **ADC / DAC**：アナログ→デジタル変換／デジタル→アナログ変換
- **PMIC**：電源管理IC。複数の電圧生成、監視、保護などを担う
- **ディスクリート**：単一または少数の素子を独立部品にした半導体
- **ワイドバンドギャップ半導体**：SiCやGaNなど、高耐圧・高温・高速動作に適した材料群
- **MEMS**：半導体加工で作る微小な機械構造
