# 半導体｜サプライチェーンと業界構造

## 0. まず押さえる全体像

半導体は「設計 → マスク → 前工程 → 後工程 → 実装」という一本の流れで作られる。
かつては1社が全部やっていた（IDM）が、工場のコストが跳ね上がったため、
工程ごとに世界で分業する **水平分業** が主流になった。

```
仕様・設計 ──▶ フォトマスク ──▶ 前工程(ウェハー加工) ──▶ 後工程(組立・検査) ──▶ 基板実装
 ファブレス      マスク専業        ファウンドリ / IDM        OSAT / IDM          EMS・セットメーカー
 (NVIDIA等)     (凸版, DNP)       (TSMC, Samsung)         (ASE, Amkor)        (Foxconn等)
        ▲                ▲                 ▲                      ▲
      EDA・IP          マスク材料        製造装置・材料          後工程装置・材料
   (Synopsys, Arm)   (HOYA, AGC)   (ASML, AMAT, TEL, 信越)   (ディスコ, アドバンテスト)
```

所要期間の目安：設計 1〜3年 → 前工程 **2〜3ヶ月** → 後工程 **数日〜2週間**。
つまり注文から出荷まで最短でも3〜4ヶ月かかり、これが半導体不足／在庫過剰（シリコンサイクル）を生む構造的な原因になる。

## 1. プレイヤーの4類型

| 類型 | やること | 代表企業 | 経済的な特徴 |
| --- | --- | --- | --- |
| IDM（垂直統合） | 設計〜製造〜販売まで自社 | Intel、Samsung、Micron、キオクシア、TI、Infineon、ルネサス、ローム | 設備投資が重く、稼働率が利益を左右する |
| ファブレス | 設計だけ。製造は外注 | NVIDIA、Qualcomm、Broadcom、AMD、Apple（内製設計） | 固定費が軽く高利益率。設計力とソフト資産が命 |
| ファウンドリ（受託製造） | 他社設計を製造 | TSMC、Samsung Foundry、SMIC、UMC、GlobalFoundries、Rapidus | 装置償却の塊。最先端は実質TSMCの寡占 |
| OSAT（後工程受託） | 組立・検査を受託 | ASE、Amkor、JCET、PTI | 従来は労働集約・低利益率。先端パッケージで地位上昇中 |

ポイント：**「設計と製造が分かれている」ことが半導体を理解する最大の鍵**。
NVIDIAは工場を持たず、TSMCが作る。だからTSMCの生産能力が世界のAI供給量の上限になる。

## 2. 製品カテゴリ（何を作っているか）

ここでは業界を見るための要約を示す。機能・製品形態・材料という分類軸の違いと、各種類の詳しい役割は[半導体の種類と役割](07_半導体の種類と役割.md)を参照。

| 区分 | 中身 | 性格 |
| --- | --- | --- |
| ロジック | CPU、GPU、SoC、FPGA、ASIC | 微細化競争。設計付加価値が大きい |
| メモリ | DRAM（短期記憶）、NAND（保存） | ほぼ汎用品＝**市況商品**。価格変動が激しい |
| アナログ | 電源制御、アンプ、信号変換 | 微細化より品種数と長寿命。景気連動は穏やか |
| パワー半導体 | IGBT、SiC、GaN | EV・再エネで需要増。微細化より材料と耐圧 |
| マイコン（MCU） | 機器の頭脳。車載・家電 | 車載向けは認証が重く、乗り換えが起きにくい |
| センサー | イメージセンサー（CIS）等 | ソニーが世界シェア首位級 |
| ディスクリート | トランジスタ、ダイオード単体 | 汎用・低単価 |

「半導体が高い／足りない」と言うとき、どのカテゴリの話かで原因がまったく違う。
メモリなら市況、車載マイコンなら能力不足、AI向けGPUなら先端パッケージ（CoWoS）の制約、という具合。

## 3. 微細化とムーアの法則

- 線幅（プロセスノード）は 28nm → 16/14nm → 7nm → 5nm → 3nm → 2nm と進んできた。
- 現在の「◯nm」は**物理的な寸法ではなくマーケティング上の世代名**。同じ3nmでもメーカー間で密度が違う。
- トランジスタ構造は プレーナ → **FinFET**（3次元のヒレ）→ **GAA/ナノシート**（2nm世代）へ。
- 微細化は減速し、代わりに「**チップレット**」（小さなチップを複数並べて1つのパッケージに統合）が主流化。
  ここで後工程＝パッケージ技術が性能の主戦場になった（→ 03_後工程.md）。

## 4. なぜ地政学の話になるのか

- 最先端ロジックの製造は台湾（TSMC）と韓国に集中し、EUV露光装置はオランダのASMLが世界唯一の供給者。
  つまり**代替不可能な単一障害点が複数ある**。
- 米国は対中輸出規制（先端装置・AI半導体）、各国は補助金（米CHIPS法、EUチップス法、日本の経済安保予算）で自国生産を誘致。
- 日本の強みは**装置と材料**（シリコンウェハー、フォトレジスト、CMPスラリー等で世界シェア上位）。
  逆に最先端ロジックの量産は空白で、そこを埋めようとしているのがRapidus。

## 5. この業界を見るときの指標

- 世界半導体売上高（WSTS統計）、月次のBBレシオ、DRAM/NANDのスポット価格
- TSMCの月次売上・設備投資（CapEx）、ASMLの受注（先行指標になりやすい）
- 稼働率と在庫日数（シリコンサイクルの位置を測る）
- 先端パッケージ（CoWoS）能力：AI需要のボトルネックそのもの

> 数値は年によって大きく動くので、具体的な金額は都度WSTS・各社IRで確認すること。

## 6. 用語集

| 用語 | 意味 |
| --- | --- |
| IDM | 半導体の設計から製造、販売までを自社で一貫して行う企業 |
| ファブレス | 自社工場を持たず、半導体の設計と販売に集中する企業 |
| ファウンドリ | 他社が設計した半導体の製造を受託する企業 |
| OSAT | 半導体の組立、パッケージング、検査などの後工程を受託する企業 |
| 水平分業 | 設計、前工程、後工程などを、それぞれ専門の企業が分担する産業構造 |
| シリコンサイクル | 半導体需要と設備投資のずれにより、不足と供給過剰が周期的に繰り返される現象 |
| プロセスノード | 半導体製造技術の世代を示す呼称。現在のnm値は特定の物理寸法と必ずしも一致しない |
| チップレット | 小さな半導体ダイを複数組み合わせ、一つのパッケージとして機能させる設計手法 |
| 前工程 | ウェハー上にトランジスタと配線を形成する製造工程 |
| 後工程 | ウェハーを個片化し、パッケージへの組立と検査を行う工程 |
