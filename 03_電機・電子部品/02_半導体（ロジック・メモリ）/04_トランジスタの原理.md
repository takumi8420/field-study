# トランジスタの原理

チップの中で何が起きているのか。**トランジスタ＝電気で操作するスイッチ**という一点から積み上げる。
製造の手順は [前工程](02_前工程.md)、用語の索引は [用語集](05_用語集.md)。

## 1. 前提：半導体は不純物で性質を変えられる

純粋なシリコンはほとんど電気を通さない。そこに微量の不純物を混ぜる（**ドーピング**）と性質が変わる。

| 型 | 混ぜるもの | 電気を運ぶもの |
| --- | --- | --- |
| **n型** | リン、ヒ素（電子が余る） | **電子**（マイナスの電荷） |
| **p型** | ホウ素（電子が足りない） | **正孔（ホール）**（電子の空席。プラスとして振る舞う） |

前工程の**イオン注入**は、この n / p を狙った場所に打ち分ける工程。

## 2. MOSFETの構造

現在のICに使われているのはほぼ **MOSFET**（金属-酸化膜-半導体 電界効果トランジスタ）。
nチャネル型（nMOS）の断面：

```
              ゲート（電極）
           ┌──────────────┐
    ═══════│  絶縁膜（1〜2nm）  │═══════
    ┌──────┴──────────────┴──────┐
    │ n+ ソース │ ←── チャネル ──→ │ n+ ドレイン │
    │              p型シリコン（土台）            │
    └──────────────────────────┘
```

| 部位 | 役割 |
| --- | --- |
| **ソース** | 電子の出口 |
| **ドレイン** | 電子の入口 |
| **ゲート** | 制御用の電極。**絶縁膜で隔てられ、電流は流れない** |
| **チャネル** | ソース-ドレイン間。普段はp型なので電子は通れない＝**OFF** |

## 3. なぜスイッチになるのか

ゲートにプラスの電圧をかけると、**絶縁膜越しの電界**が p型シリコン中の電子を表面に引き寄せる。

1. 電圧が小さいうちは何も起きない（**OFF**）
2. **しきい値電圧（Vth）** を超えると、表面に電子が集まって薄いn型の層ができる（**反転層＝チャネル**）
3. ソースとドレインが電子の通り道でつながり、電流が流れる（**ON**）

つまり **ゲート電圧で「通り道そのものを作ったり消したりしている」**。
蛇口をひねるというより、**橋を架けたり外したりする**イメージが近い。

> 決定的に重要な点：**ゲートは絶縁されているので、制御に電流をほとんど使わない**。
> 状態の保持に電力が要らない。これがMOSFETが他方式を駆逐した理由。

## 4. CMOS：2種類を組み合わせる

実際の論理回路は nMOS と pMOS を対にした **CMOS** 構造。pMOSは極性が逆で、ゲートを下げるとONになる。

```
入力 0 →  pMOS:ON / nMOS:OFF  → 出力は電源側につながる ＝ 1
入力 1 →  pMOS:OFF / nMOS:ON  → 出力はアース側につながる ＝ 0
```

どちらの状態でも**電源からアースへ一直線に電流が流れる経路がない**ので、静止時の消費電力がほぼゼロ。
電力を食うのは**状態が切り替わる瞬間だけ**。したがって、

```
消費電力 ∝ 容量 × 電圧² × 動作周波数
```

電圧が**2乗**で効くので、微細化で電圧を下げられることが省電力に直結した。
逆に周波数を上げると発熱が比例して増えるため、2000年代半ば以降は
クロック競争からコア数（並列化）競争へ移った。

## 5. 微細化すると速くなる理由

- チャネルが短い＝電子の走る距離が短い → **速い**
- 電極が小さい＝溜める電荷（容量）が小さい → **切り替えが速く、消費電力も小さい**

これが **デナード則**（寸法を縮めれば電圧も下げられ、速く・省電力になる）の中身。
2000年代半ばに崩れた経緯は [「2nm」「3nm」の正確な意味](../../01_注目テーマ/02_半導体・先端半導体/05_プロセスノード名の正確な意味.md) を参照。

## 6. なぜ構造が3次元化したのか

チャネルを短くしすぎると、**ゲートがチャネルを制御しきれなくなる**（**短チャネル効果**）。
ドレイン側の電圧の影響が勝ち、OFFにしても電気が漏れる（**リーク電流**）。
その対策の歴史が、そのまま先端プロセスの歴史になっている。

| 時期 | 問題 | 対策 |
| --- | --- | --- |
| 2007年頃 | 絶縁膜が薄すぎてトンネル電流が漏れる | **High-k絶縁膜＋メタルゲート** |
| 2011年〜 | 平面構造では制御が足りない | **FinFET**（チャネルをヒレ状に立て3面から囲む） |
| 2nm世代〜 | さらに強い制御が必要 | **GAA / ナノシート**（板状チャネルを全周から囲む） |

「2nm世代の主役はGAA」と言われるのは、**ゲートの支配力を取り戻す戦い**が世代交代の本質だから。

## 7. MOSFET以外のトランジスタ

| 種類 | 原理 | 主な用途 |
| --- | --- | --- |
| **バイポーラトランジスタ** | ベースに流す**電流**でコレクタ電流を制御（電流制御型） | アナログ増幅、高速回路 |
| **IGBT** | 入口をMOSFETで制御し、大電流はバイポーラで流す複合型 | パワー半導体（産業機器、鉄道、EV） |
| **SiC / GaN** | 材料自体を変え、高電圧・高温・高周波に耐える | EV、再エネのインバータ、急速充電器 |

デジタル＝MOSFET、パワー＝IGBT / SiC、と押さえておけば実務上は足りる。

## まとめ

トランジスタとは、**絶縁されたゲートに電圧をかけ、電界の力で半導体の中に電流の通り道を作ったり消したりする装置**。
それを数百億個並べ、ON/OFFの組み合わせで計算しているのが現在のチップ。
