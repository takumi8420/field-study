半導体｜前工程（Front-End / ウェハープロセス）

電機・電子部品半導体（ロジック・メモリ）
あこのページの単語集用語に触れると意味を確認できます12語
CZ法熱酸化CVDALDPVD（スパッタ）エピタキシャル成長ウェハープローブ検査（EDS／ウェハーテスト）レチクルペリクルタクトタイム／サイクルタイムホットロットシュリンク

定義：シリコンウェハーの上に、トランジスタと配線を作り込む工程。
出口は「回路が焼き込まれた1枚のウェハー」。まだ個々のチップには切り離されていない。

トランジスタ、ダイ、ウェハーの粒度や、「数百億個をどう設計して紫外線で形成するのか」から理解したい場合は、先にウェハー上にチップができるまでを読むと全体像をつかみやすい。

  • 場所：クリーンルーム（ISO Class 1〜3。空気1立方フィート中の0.1µm粒子が数個レベル）
  • 期間：投入から完成まで 2〜3ヶ月（先端ロジックは1,000工程超）
  • 工場コスト：先端ロジックの新工場で1〜2兆円規模。装置代が過半
  • 特徴：同じ工程を何十回も繰り返す。1層ずつ積み上げるので、工程数＝層数×各層の処理

0. その前：ウェハーを作る（素材メーカーの仕事）

  1. 珪石 → 金属シリコン → 高純度多結晶シリコン（イレブンナイン＝99.9999999999%級）
  2. CZ法：溶かしたシリコンに種結晶を漬けてゆっくり引き上げ、単結晶インゴット（円柱）にする
  3. スライス → ラッピング → エッチング → 鏡面研磨（ポリッシング） → 洗浄
  4. 直径300mm（12インチ）が主流。パワー半導体等は150/200mmも現役

世界シェアは信越化学・SUMCOの日本勢が約半分。ここが日本の強さの代表例。

1. 前工程の8つの基本動作

前工程は、次の動作の組み合わせの繰り返しでしかない。まずこの8つを覚える。

# 工程 やること 主な装置メーカー
1成膜ウェハー表面に薄い膜を付けるAMAT、TEL、Lam、ASM、KOKUSAI
2レジスト塗布感光性の樹脂（フォトレジスト）を均一に塗るTEL（塗布現像装置は世界シェア首位級）
3露光マスクの回路パターンを光で転写するASML（EUVは独占）、Canon、Nikon
4現像光が当たった／当たらない部分を溶かし、レジストのパターンを出すTEL、SCREEN
5エッチングレジストがない部分を削る（＝パターンを膜に転写）Lam、TEL、AMAT
6イオン注入不純物を撃ち込んで半導体の電気的性質を作るAMAT、住友重機械
7平坦化（CMP）研磨して表面を鏡のように平らに戻すAMAT、荏原製作所
8洗浄各工程間でパーティクルと残渣を落とす（工程数の2〜3割は洗浄）SCREEN、TEL

成膜の代表的な手法

  • 熱酸化：シリコンを酸化させてSiO2（絶縁膜）を作る。最も基本
  • CVD：ガスを化学反応させて膜を堆積（プラズマCVDなど）
  • ALD：原子層を1層ずつ積む。極薄・均一。微細化で重要度が上昇
  • PVD（スパッタ）：金属膜を物理的に叩き出して付ける
  • エピタキシャル成長：結晶の向きを揃えて単結晶層を成長させる

露光（リソグラフィ）＝前工程の心臓部

  • 回路原版であるフォトマスク（レチクル）の像を、レンズで1/4に縮小してウェハーに焼く
  • 光源の波長が細さを決める：i線365nm → KrF 248nm → ArF 193nm → ArF液浸（水を挟んで実効134nm相当）→ EUV 13.5nm
  • EUV装置はASMLの独占。1台 300〜400億円規模、輸送に飛行機数便。次世代のHigh-NA EUVはさらに高額
  • EUVが使えない／使わない場合はマルチパターニング（SADP、LELE等）で1つのパターンを複数回に分けて描く
    → 工程数とコストが跳ね上がる。EUVの価値はここにある
  • ステッパ（1ショットずつ）→ スキャナ（走査しながら）へ進化

2. 工程の三段構え：FEOL / MOL / BEOL

段 名称 作るもの
前半FEOL（Front End of Line）トランジスタそのもの。ウェル形成、素子分離（STI）、ゲート形成、ソース/ドレイン
中間MOL（Middle of Line）トランジスタと配線をつなぐコンタクト
後半BEOL（Back End of Line）多層配線。銅ダマシン法＋low-k絶縁膜。先端品では10〜20層

※ BEOLの「Back End」は後工程のことではない。前工程の後半という意味。混同しやすい要注意用語。

3. 典型的な1層の流れ（これを何十回も回す）

成膜 → レジスト塗布 → 露光 → 現像 → エッチング → レジスト剥離・洗浄 → （必要なら）イオン注入・アニール → CMP
      └──────────── これで膜に1層分のパターンが刻まれる ────────────┘

4. 出口：ウェハーテストと歩留まり

  • ウェハープローブ検査（EDS／ウェハーテスト）：プローブ針をパッドに当て、チップ1個ずつ電気的に良否判定
  • 結果は良品マップになり、不良ダイは後工程に送らない（後工程コストの無駄を防ぐ）
  • 歩留まり（Yield）＝ 良品ダイ数 ÷ 全ダイ数。ここが半導体の収益性を決める最重要KPI
    • 立ち上げ直後は低く、経験曲線とともに改善する（ランプアップ）
    • 微細化すると1個の欠陥が致命傷になりやすく、歩留まり確保が難しくなる
  • ダイあたりコスト ≒ ウェハー1枚の加工費 ÷（1枚から取れる良品ダイ数）
    → チップ面積が小さいほど有利。大面積のAI向けGPUが高価なのはこの算数

5. ビジネスとして見たときの要点

  • コストの大半は装置の減価償却。よって稼働率が落ちた瞬間に赤字になる装置産業
  • 「世代が1つ進むごとに工場投資が倍増する」ため、最先端を追える企業が数社に絞られた（TSMC・Samsung・Intel）
  • 微細化が効くのはロジックとメモリ。アナログ・パワーは成熟ノードで十分なので競争軸が違う
  • 日本勢は装置（TEL、アドバンテスト、SCREEN、ディスコ、荏原）と材料（信越、SUMCO、JSR、東京応化、レゾナック、富士フイルム）で強い

用語メモ

  • レチクル：露光に使う回路原版（フォトマスク）。1セット数億円になることも
  • ペリクル：マスクを異物から守る薄膜カバー
  • タクトタイム／サイクルタイム：1ロットが工程を回り切る時間
  • ホットロット：優先的に流す特急ロット
  • シュリンク：同じ回路を微細ノードで作り直してダイを小さくすること
