シリコンウェハー

半導体を作る土台になるシリコンの円盤。日本語では「基板」とも呼ぶ。
日本勢が世界シェアの過半を握る、日本の半導体産業の柱のひとつ。

1. 何者か

項目 内容
材質単結晶シリコン（原子がきれいに整列した一枚岩の結晶）
形円盤。主流は直径300mm（12インチ）、厚さ約0.775mm
その他の口径150mm / 200mm も現役（パワー半導体、アナログ、車載など）
表面鏡面に研磨されており、その上に回路を何百層も焼き付けていく
純度イレブンナイン（99.9999999999%） 級

チップは1個ずつ作るのではなく、1枚のウェハーの上に同じチップを数百〜数千個まとめて作り、
最後に切り分ける。この「まとめて作る」ことが半導体の量産経済性の本体。

  │  ▦▦▦▦▦▦▦▦▦▦  │   ← 1マスが1個のチップ（ダイ）
  │  ▦▦▦▦▦▦▦▦▦▦  │      300mmウェハー1枚に、
  │  ▦▦▦▦▦▦▦▦▦▦  │      10mm角のチップなら約600個取れる

2. なぜ円盤なのか — CZ法

作り方に由来する。

  1. 珪石 → 金属シリコン → 高純度多結晶シリコン
  2. 溶かしたシリコンに種結晶を浸し、回しながらゆっくり引き上げる（CZ法／チョクラルスキー法）
  3. 原子が種結晶の並びを引き継いで成長し、円柱状の単結晶インゴット（重さ数百kg）ができる
  4. インゴットを輪切り（スライス）→ ラッピング → エッチング → 鏡面研磨 → 洗浄

円柱を輪切りにするので、必然的に丸くなる。
原子の並びが揃っていないとトランジスタが正しく動かないため、結晶の完全性と純度が命。

3. なぜ「300mm」が重要か

ウェハー1枚を処理するコストは、口径が変わってもさほど変わらない。一方で面積は直径の2乗で効く。

  • 200mm → 300mm で取れるチップ数が約2.25倍
  • つまりチップ1個あたりのコストが下がる

過去に450mmへの移行構想があったが、装置をすべて作り直す投資に見合わず立ち消えになった。
当面は300mmが最大口径のまま推移する見通し。

4. 種類

種類 用途
ポリッシュドウェハー標準的な鏡面ウェハー
エピタキシャルウェハー（エピウェハー）表面にさらに単結晶層を成長させた高品質品。先端ロジック、パワー向け
SOIウェハー絶縁層を挟んだ構造。低消費電力・高周波用途
SiC / GaN ウェハーパワー半導体向け。硬く加工が難しく、大口径化とコストが課題
再生（リクレーム）ウェハー試験用に表面を削り直して再利用するもの

5. 業界構造

  • ウェハーを作るのは半導体メーカーではなく素材メーカーの仕事
  • 信越化学工業とSUMCOの日本勢で世界シェアの過半。他に台湾のGlobalWafers、ドイツのSiltronic
  • 装置産業であり、需要変動に対して増産が遅い（結晶育成の設備投資に時間がかかる）
  • 顧客は世界の半導体メーカー。長期契約（LTA）で数量と価格を固定する取引慣行が強まっている

価格感

状態 目安
加工前の300mm鏡面ウェハー1枚あたり数千〜1万円台
最先端ロジックの加工を終えた1枚200〜300万円規模と言われる

つまり価値のほとんどは加工賃。ウェハー代そのものはチップ原価のごく一部にすぎない。
逆に言えば、歩留まりを落として1枚を無駄にしたときの損失が極めて大きい。

6. 指標としてのウェハー

  • 半導体の生産能力は「月産◯万枚（ウェハー換算）」で語られる。業界ニュースの標準単位
  • 工場の規模、増設の発表、稼働率の議論はすべてこの単位で行われる
  • シリコンウェハーの出荷面積（SEMI統計）は、半導体市況の先行指標としてよく使われる
