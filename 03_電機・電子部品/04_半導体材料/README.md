## 1. 業界の定義・範囲

半導体の製造工程で消費される材料の総称。**前工程材料**（ウェハー、フォトレジスト、各種ガス、
CMPスラリー、洗浄薬液、フォトマスク材料）と、**後工程材料**（封止樹脂、パッケージ基板、
ボンディングワイヤ、ダイアタッチ材）に分かれる。

装置と違って**消耗品**なので、工場が稼働し続ける限り繰り返し売れるのが特徴。

## 2. 市場規模と成長性

世界市場は年間700億ドル前後の規模とされ、装置市場よりやや小さい。
半導体生産量と工程数に連動するため、**微細化が進んで工程数が増えるほど材料消費も増える**。

## 3. バリューチェーンでの位置

```
材料メーカー → 半導体メーカー／ファウンドリ → セットメーカー
   （消耗品を継続供給。品質認定に数年かかるため、いったん採用されると乗り換えられにくい）
```

半導体そのものでは負けたが、材料では世界を押さえているという構図。

## 5. 収益モデル・コスト構造

- 消耗品なので**稼働率に連動したストック型の売上**になる
- 品質認定（クオリフィケーション）に年単位かかるため、**切り替えコストが高く価格競争になりにくい**
- 一方で原材料（レアガス、貴金属、樹脂原料）の市況と為替の影響を受ける

## 6. 競争要因（KSF）と参入障壁

純度・粒子制御などの品質の安定性／顧客の工程に合わせ込む共同開発力／
供給責任（止めないこと）／認定実績。**技術より「信頼と実績」が障壁になる典型**。

## 7. 規制・法制度

先端材料は輸出管理の対象になりうる。2023年には日本が先端半導体製造装置の輸出管理を強化し、
材料側でも地政学リスクが意識されるようになった。
レアガス（ネオン等）やレアメタルは産地が偏在し、供給途絶リスクを持つ。
