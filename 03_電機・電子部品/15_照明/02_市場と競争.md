# 市場と競争

このノートで分かること：照明が**どの用途で誰に売られ、どの経路を通って建物に付くのか**。
そして、値段だけの戦いから抜け出すために業界が何を売ろうとしているのか。

> **ポイント**：照明は「店で買う商品」より「**工事で付く設備**」である。
> 国内市場の主戦場は住宅ではなく**非住宅（オフィス・店舗・工場・施設）**で、
> 売り先は消費者ではなく**電気工事店**、その手前にいるのが**電材商社**。
> だから照明メーカーの競争力は、製品の良し悪しと同じくらい
> 「**電材ルートにどれだけ食い込んでいるか**」で決まる。

## 2. 市場は3つに分かれる——住宅／非住宅屋内／屋外

同じ「照明」でも、買う人・選ぶ理由・売る経路がまるで違う。ここを混ぜると業界が分からなくなる。

| 区分                         | 主な製品                                                                             | 誰が選ぶか                                                 | 選ぶ基準                                               | 商流                                                      |
| ---------------------------- | ------------------------------------------------------------------------------------ | ---------------------------------------------------------- | ------------------------------------------------------ | --------------------------------------------------------- |
| **住宅用**                   | シーリングライト、ダウンライト、電球、間接照明                                       | 施主・ハウスメーカー・リフォーム業者・消費者本人           | 価格、デザイン、明るさ、調光調色                       | ①ハウスメーカー／工務店経由 ②家電量販・ホームセンター ③EC |
| **非住宅屋内（施設・店舗）** | ベースライト（天井の長方形の器具）、ダウンライト、スポットライト、非常用照明、誘導灯 | 設計事務所、照明デザイナー、ゼネコン・サブコン、施設管理者 | 器具効率、演色性、制御対応、法適合、**メンテナンス性** | **電材ルートが主役**（後述）                              |
| **屋外**                     | 道路灯、防犯灯、投光器、街路灯、トンネル灯、景観照明                                 | 自治体、道路管理者、工場・物流施設の管理者                 | 耐久性、防水防塵（IP等級）、配光、寿命                 | 官公庁入札、電材ルート、リース／ESCO                      |

```
【日本の照明市場の構図（金額ベースのイメージ）】

   ┌──────────────────────────────┐
   │              非住宅屋内（施設・店舗）                  │  ← 最大。単価も高い
   │  オフィスのベースライト／店舗のスポット／工場の高天井灯 │    LED化の主戦場
   │  ★ 蛍光灯2027年問題の影響が最も大きいのはここ          │
   ├───────────────────┬──────────┤
   │        住宅用                   │      屋外          │
   │  シーリング／ダウンライト        │ 道路・防犯灯・投光器│
   │  ★ 消費者が値段で選ぶ＝価格競争  │ ★ 自治体予算と入札 │
   └───────────────────┴──────────┘

   住宅は「小売の論理」、非住宅は「建設の論理」、屋外は「行政の論理」で動く
```

> **なぜ非住宅が主戦場か**：1棟のオフィスビルには数千台の器具が入る。
> 住宅1戸は10〜20台。**1件あたりの金額が2桁違う**。
> しかも非住宅は「省エネ改修」「規制対応」という**買う理由**を外から与えられる。

## 3. 商流——「電材ルート」を理解する

照明業界の話が家電と噛み合わない最大の理由がここにある。
非住宅の照明は**店頭で売られていない**。

```
【電材ルート（照明器具が建物に付くまで）】

 照明器具メーカー
   │  ・カタログに「品番」を載せる
   │  ・設計事務所・ゼネコンに対して営業（＝図面に書かせる＝「物件仕込み」）
   ▼
 電材商社（電設資材の卸）        例：因幡電機産業、立花エレテック、
   │  ・在庫を持ち、短納期で届ける      西日本電線系・地場の電材屋 多数
   │  ・工事店へ掛売り（与信を負う）
   │  ・値引き（掛率）の実質的な決定者
   ▼
 電気工事店・サブコン            例：街の電気工事店〜関電工・きんでん等
   │  ・実際に器具を取り付ける。配線・調光線の敷設
   │  ・「メーカー指定がなければ、使い慣れた品番を選ぶ」
   ▼
 建物所有者・テナント（エンドユーザー）
   ・器具の品番を知らないことも多い

 ※別ルート
   住宅用 ──▶ ハウスメーカー／工務店 ──▶ 施主
   住宅用 ──▶ 家電量販・ホームセンター・EC ──▶ 消費者
   高級店舗 ─▶ 照明デザイナー／設計事務所が品番を「指定」──▶ そのまま発注
```

この構造から、業界の常識がいくつも出てくる。

| 現象                                     | 理由                                                                                                                             |
| ---------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| **カタログと品番が異様に分厚い**         | 設計者が図面に書ける「型番」がないと採用されない。品番を持つこと自体が営業資産                                                   |
| **「定価」と実売価格が大きく乖離する**   | 電材ルートは「定価×掛率」で取引する慣行。定価は値引き交渉の基準値として機能する                                                  |
| **工事店との関係が売上を左右する**       | 指定がない案件では、工事店が使い慣れたメーカーを選ぶ。取付のしやすさ・施工説明書の分かりやすさが効く                             |
| **納期と在庫が競争力になる**             | 工事は日程が動かせない。「明日欲しい」に応えられるかで選ばれる。だから電材商社の在庫機能が重い                                   |
| **新規参入は「モノは作れても売れない」** | 器具は作れても、全国の電材商社と工事店に品番が浸透していない。アイリスオーヤマが法人向けで時間をかけて拠点網を作ったのはこのため |
| **設計事務所への営業が最上流**           | 図面に品番が書かれた時点で、ほぼ勝負がついている（「**物件仕込み**」）                                                           |

> **要点**：照明メーカーの競争は、**エンドユーザーの手前2段（商社・工事店）と、設計の最上流（図面）**で起きる。
> 良い製品を作れば売れる市場ではない。

## 5. 収益モデルとコスト構造

照明器具メーカーの経済性を一言でいうと「**原価率が高く、固定費は販売網**」。

| 項目               | 目安             | なぜそうなるか                                                                              |
| ------------------ | ---------------- | ------------------------------------------------------------------------------------------- |
| **材料費（原価）** | 売上の6〜7割     | 鋼板・アルミ・樹脂・LEDチップ・電源。**チップの比率が下がり、金属と物流が効く**ようになった |
| **販管費**         | 2〜3割           | カタログ制作、ショールーム、設計事務所・工事店への営業人員、全国の物流拠点                  |
| **営業利益率**     | **数%〜10%程度** | 専業でデザイン提案型（遠藤照明など）は10%前後を出せるが、汎用ベースライト中心だと数%に沈む  |
| **在庫**           | 重い             | 品番点数が膨大。かつ「明日欲しい」に応える必要があるため、在庫を持たないと選ばれない        |

**儲け方の分岐点**は次のどちらに寄せるかである。

```
   汎用品（ベースライト・電球）        提案型（演出照明・制御）
   ─────────────        ─────────────
   ・カタログの品番で比較される       ・空間の見え方を設計して売る
   ・掛率（値引き率）勝負            ・器具＋制御＋設計サポートで一式
   ・中国勢・量販PBと同じ土俵        ・比較されにくい＝値崩れしにくい
   ・数量は出るが利益率は低い        ・数量は小さいが利益率は高い
        ▼                                 ▼
   規模と調達力がないと勝てない       デザイン・光の知見・制御技術が要る
   （パナソニック、アイリス）          （大光電機、遠藤照明、シグニファイ）
```

## 6. 付加価値化——「LEDからLEDへ」を作れるか

LED置き換えが一巡すると需要が消える（→[①](01_LED化が業界に何をしたか.md)）。
その先を作るために業界が押している価値が3つある。

### ① 照明制御・IoT

器具を「つける／消す」だけのものから、**ネットワークにつながる端末**にする。

| 技術・規格                                         | 中身                                                                                 |
| -------------------------------------------------- | ------------------------------------------------------------------------------------ |
| **DALI**（Digital Addressable Lighting Interface） | 器具1台ずつに番号を振り、専用の2線で個別に調光・状態監視する国際規格。施設照明の標準 |
| **Bluetooth Mesh／Zigbee／Wi-Fi**                  | 無線で制御。**既設配線を触らずに後付けできる**のが改修工事で効く                     |
| **PoE給電照明**                                    | LANケーブルで電力と通信を同時に送る。ITインフラ側に照明を取り込む発想                |
| **人感・照度センサー連携**                         | 在室検知と昼光利用で自動調光。省エネ効果を上乗せする                                 |

照明は建物のあらゆる場所に、電源付きで、等間隔に設置されている。
**建物内センサーネットワークの土台として、これ以上に都合の良い設備はない**——
これが「照明をIoTの入口にする」という主張の根拠である。

### ② 人間中心照明（HCL：Human Centric Lighting）

「明るさ」ではなく「**人の体と心への効果**」を売る考え方。
朝は青白い光、夕方は暖色——と**自然光の1日の変化を模倣**し、
体内時計（サーカディアンリズム）・覚醒度・集中力に働きかける。

- オフィスの生産性、病院・介護施設での睡眠改善、学校での集中力などが訴求点
- 技術的には**調光（明るさ）＋調色（色温度）＋制御スケジュール**の組み合わせ
- 論点：効果の定量化・標準化が未成熟。JLMAもCIE（国際照明委員会）国内委員会を通じて
  「光の人への影響」の評価指標づくりに取り組んでいる（JLMA 2026年度事業計画書）

### ③ Lighting 5.0

JLMAが掲げる次世代照明の概念。Society 5.0（超スマート社会）に対応する照明システムという位置づけで、
**センサー・通信・制御を備え、空間の状態に応じて光を変える**製品を指す。

| KPI（LIGHTING VISION 2030）   | 目標                              | 現状                     |
| ----------------------------- | --------------------------------- | ------------------------ |
| ストックのSSL（LED）化率      | 2030年末に**98%以上**（実質100%） | **67.5%**（2026年3月末） |
| Lighting 5.0 製品の出荷構成比 | **40%**                           | **34.8%**（2026年3月）   |
| LED機器の消費電力量削減       | **60%削減**                       | 推進中                   |

> **構図**：SSL化率の目標は「**置き換え需要を最後まで刈り取る**」ための旗。
> Lighting 5.0の目標は「**刈り取った後に売るもの**」を用意する旗。
> 業界団体の2つのKPIは、需要の山と谷にそのまま対応している。

## 7. 需要を作る制度——ZEB・省エネ改修・補助金

照明の非住宅需要は、**制度が作る**。

| 制度・枠組み                                  | 中身                                                                                                                                                          | 照明への効き方                                                                                                    |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| **ZEB**（Net Zero Energy Building）           | 建物の一次エネルギー消費を大幅に削減する設計。国が補助制度を持ち、2026年度のZEB化事業は補助上限が公募区分共通で3億円／年（複数年度事業は全体で7億円）とされる | 照明は建物の消費電力の2〜3割を占める。**最も手をつけやすい削減項目**であり、ZEB案件では必ず高効率照明＋制御が入る |
| **省エネ法／建築物省エネ法**                  | 建物の省エネ基準。2025年4月から原則すべての新築建築物に省エネ基準適合が義務化                                                                                 | 新築時点で高効率照明が前提になる                                                                                  |
| **各種省エネ補助金（国・自治体）**            | 設備更新に対する補助。LED化単独でも対象になる枠がある                                                                                                         | 「補助金があるうちに」が更新のトリガーになる。自治体ごとに枠が異なり、情報提供自体が工事店の営業ツール            |
| **水銀規制（水俣条約）**                      | 蛍光ランプの製造・輸出入禁止                                                                                                                                  | **最強のトリガー**。補助金と違い「やらない」選択肢がない → [①](01_LED化が業界に何をしたか.md)                     |
| **建築物のLCA（ライフサイクルアセスメント）** | 国土交通省が**2028年度から建築物へのLCA導入を予定**。JLMAは照明器具のカーボンフットプリント算定ガイドライン案を策定中                                         | 器具ごとのCO2排出量の開示が求められる方向。**数値を出せないメーカーが選ばれなくなる**可能性                       |
| **消防法・建築基準法**                        | 非常用照明・誘導灯の設置と定期点検が義務                                                                                                                      | 景気に左右されない需要。2025年の点検要領改正で、点検を効率化する「周期始動方式」の誘導灯が各社から発売された      |

## 8. 用語メモ

| 用語                                            | 意味                                                                                                              |
| ----------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| **電材ルート**                                  | 電設資材の流通経路。メーカー→電材商社→電気工事店→建物。照明の非住宅需要の主経路                                   |
| **電材商社**                                    | 電線・配線器具・照明などを扱う卸。在庫を持ち、工事店への掛売りで与信も負う。値引き（掛率）の実質的な決定者        |
| **物件仕込み**                                  | 設計段階で設計事務所・ゼネコンに自社品番を図面へ書かせる営業活動。ここで勝負がほぼ決まる                          |
| **掛率**                                        | 定価に対する実取引価格の比率。照明業界は定価表と掛率で取引する慣行が残る                                          |
| **ベースライト**                                | オフィス・工場の天井に並ぶ長方形の基本照明器具。台数が最も出る汎用品で、価格競争が最も激しい                      |
| **DALI**                                        | 器具を1台ずつアドレス管理して調光・監視する国際規格。施設向け照明制御の標準                                       |
| **HCL（Human Centric Lighting／人間中心照明）** | 自然光の変化を模倣し、体内時計・覚醒度・気分に働きかける照明。「明るさ」でなく「人への効果」を売る                |
| **Lighting 5.0**                                | JLMAが掲げる次世代照明の概念。センサー・通信・制御を備えた高付加価値照明システム。出荷構成比34.8%（2026年3月）    |
| **ZEB**                                         | Net Zero Energy Building。年間の一次エネルギー消費を実質ゼロに近づける建物。照明は削減の主要項目                  |
| **JLMA**                                        | 一般社団法人 日本照明工業会。照明業界の業界団体。自主統計の公表、認証・評定事業、LIGHTING VISION 2030の推進を行う |
