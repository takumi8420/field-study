# 照明

- 大分類: 電機・電子部品
- 状態: done
- 更新日: 2026-09-20

> **最初に押さえること**
> 照明は**自分の市場を自分で壊した産業**である。
> かつては器具を売りながら、切れるたびにランプが売れる「消耗品ビジネス」だった。
> LEDは**寿命を10倍にし、光源と器具を一体化した**。
> **寿命が10倍になれば、交換需要は10分の1になる**——業界の背骨だった安定収益が消えた。
> 代わりに来たのが「既設をLEDに置き換える」という**1回限りの特需**。
> それを最後まで押し出すのが**水俣条約による蛍光灯の製造終了（2028年1月1日に全面禁止）**である。
> 2025年度の出荷金額は**初の1兆円超**。だが台数は+4.8%、金額は+12.5%——
> **差は値上げ**であり、好調の中身は「規制が作った特需と価格転嫁」である。
> 置き換えが終わった後に売るものを作れるか。それがこの業界の唯一の論点になっている。

## 1. 業界の定義・範囲

**照明業界**＝光源（ランプ）と照明器具を設計・製造し、建物・屋外空間に供給する産業。
統計上は一般社団法人 日本照明工業会（JLMA）の「照明器具」「電球類」がこれに当たる。

境界の引き方：

- **LEDチップ（発光素子）そのものを作る事業は半導体側**。日亜化学工業、豊田合成、ams OSRAMなど。
  照明器具メーカーはチップを**買ってくる**立場 → [半導体（ロジック・メモリ）](../02_半導体（ロジック・メモリ）/README.md)
- **家庭用シーリングライトは照明業界**だが、家電量販の売り場では家電と同じ棚に並ぶ。
  ただし**統計・商流とも家電（JEMA）とは別系統** → [白物家電](../09_白物家電/README.md)
- **照明の取り付け工事は電気工事業**。照明メーカーは工事をしない → [サブコン](../../12_建設・住宅・不動産/02_サブコン（電気・空調・設備）/README.md)
- **ディスプレイのバックライト、車載ランプ、信号機、液晶用LED**は照明業界には含めないのが通例
- **非常用照明・誘導灯**は照明業界の製品だが、消防法・建築基準法で設置が義務づけられた**防災設備**でもある

## 5. 収益モデル・コスト構造

- **原価率が高い**。材料費が売上の6〜7割。鋼板・アルミ・樹脂・LEDチップ・電源部品
- **LEDチップの原価比率は下がった**（普及初期の5割前後→現在1〜2割程度のイメージ）。
  その結果、**照明の原価は金属市況・樹脂・物流費に支配される**ようになった
  → 技術で差がつきにくく、材料市況と為替に振られる
- **販管費は「販売網」の固定費**。カタログ、ショールーム、設計事務所・工事店への営業人員、全国の物流拠点
- **在庫が重い**。品番点数が膨大で、しかも「明日欲しい」に応えられないと工事案件で選ばれない
- **営業利益率は数%〜10%程度**。汎用ベースライト中心だと数%、
  演出照明＋制御の提案型（遠藤照明など）は10%前後
- **売った後の収益はほぼない**。LEDは交換しないので、かつてのランプ消耗品収益は存在しない。
  代わりに狙うのが**制御システムと保守（誘導灯の自動点検など）**

→ 儲け方の分岐（汎用品 vs 提案型）は [②](02_市場と競争.md)

## 6. 競争要因（KSF）と参入障壁

| 要因                         | 効き方                                                                                                 | 有利なのは                           |
| ---------------------------- | ------------------------------------------------------------------------------------------------------ | ------------------------------------ |
| **電材ルートへの浸透**       | 品番が図面に書かれ、商社が在庫を持ち、工事店が指名する状態を作れるか。**製品の良し悪しより手前に効く** | パナソニック、老舗専業               |
| **品番点数と納期**           | 工事日程は動かせない。欠品＝失注                                                                       | 在庫と物流網を持つ側                 |
| **設計提案力・光のデザイン** | 演出照明は比較されにくく値崩れしない                                                                   | 大光電機、遠藤照明、オーデリック     |
| **制御システムの囲い込み**   | 制御を握ると器具も同じメーカーで揃えざるを得ない                                                       | 遠藤照明、シグニファイ、パナソニック |
| **調達規模とコスト**         | 汎用ベースライト・電球は純粋な価格勝負                                                                 | アイリスオーヤマ、中国勢、量販PB     |
| **法規対応・認証**           | 非常用照明・誘導灯・公共施設用照明器具はJLMAの認証／評定が要る                                         | 既存メーカー                         |
| **環境データの開示**         | 2028年度の建築物LCA導入に備え、器具ごとのCO2を算定・提示できるか                                       | 体力のある大手                       |

**参入障壁の実態**：器具そのものは作れる（チップも電源も買える）。
壁は**製品ではなく、全国の電材商社と工事店に品番を浸透させること**にある。
アイリスオーヤマが法人向けで長期に拠点網を作ったのは、この壁を越えるためである。

## 7. 規制・法制度

| 制度                               | 中身                                                                                                           | 効き方                                                                                                                                                                 |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **水俣条約／水銀汚染防止法**       | 2023年11月のCOP5で一般照明用蛍光ランプの製造・輸出入の段階的廃止を決定。日本は2024年12月に政令改正             | **業界最大のトリガー**。電球形2026年1月、コンパクト形・ハロりん酸塩系2027年1月、三波長形2028年1月に禁止開始＝**2028年1月1日に全面禁止** → [③](03_直近トピック_2026.md) |
| **建築物省エネ法**                 | 2025年4月から原則すべての新築建築物に省エネ基準適合が義務化                                                    | 新築では高効率照明が前提になる                                                                                                                                         |
| **省エネ法**                       | エネルギー使用の合理化。事業者に定期報告・省エネ努力を課す                                                     | 照明は建物の消費電力の2〜3割。最も着手しやすい削減項目                                                                                                                 |
| **ZEB関連補助金**                  | 新築ZEB・既築ZEB化の双方を支援。2026年度は補助上限が公募区分共通で3億円／年（複数年度事業は全体7億円）とされる | 改修案件で高効率照明＋制御が入る理由                                                                                                                                   |
| **各種省エネ補助金（国・自治体）** | LED化単独でも対象になる枠がある。自治体ごとに条件が異なる                                                      | 「補助金があるうちに」が更新のトリガー。内容は毎年変わるため最新を確認                                                                                                 |
| **消防法・建築基準法**             | 非常用照明・誘導灯の設置と定期点検が義務                                                                       | 景気に左右されない需要。2025年の点検要領改正で自動点検対応の誘導灯が製品化                                                                                             |
| **電気用品安全法（電安法）**       | 照明器具・LEDランプの安全基準とPSEマーク                                                                       | ネット直販の海外製品の品質が論点。JLMAが試買調査を実施                                                                                                                 |
| **建築物のLCA（国土交通省）**      | **2028年度から建築物へのLCA導入を予定**。JLMAは照明器具のCFP算定ガイドライン案を策定中                         | 器具ごとのCO2排出量の開示が事実上の参入資格になり得る                                                                                                                  |

   メーカー側はさらに前倒しで、パナソニックEW社と東芝ライテックが2027年9月末、ホタルクスが2027年12月に生産終了
2. **2025年度の照明器具出荷が1兆234億円で初の1兆円超**（台数6,692万7,000台、+4.8%）。
   ただし金額+12.5%との差は**値上げ（価格転嫁）**
3. **ボトルネックが施工側に移った**。工事店の予定が半年先まで埋まる、
   器具・部材が数か月待ちになるといった逼迫が報じられる
4. **ストックのLED化率は67.5%**（2026年3月末）。2030年末98%以上という目標に対し
   「なお大きなギャップ」とJLMA自身が記す。残り3割は投資回収の悪い層
5. **世界最大手シグニファイは2025年に既存事業ベース-3.4%の減収**。
   世界の出荷SSL化率はすでに85%。**置き換えが終わった市場がどうなるかの先例**

## 9. 用語メモ

用語は各ノート末尾の「用語メモ」にまとめている。最小限の押さえどころは次の4つ。

| 用語                      | 意味                                                                                                                                                                                                          |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **電材ルート**            | メーカー→**電材商社**→**電気工事店**→建物という、非住宅照明の主流通経路。照明の競争は店頭ではなくこの経路と図面の上で起きる → [②](02_市場と競争.md)                                                           |
| **SSL化率／ストック市場** | SSL＝Solid State Lighting（LED等の半導体照明）。すでに設置されている器具（ストック、国内約18.1億台）のうちLEDが占める比率。2026年3月末で67.5%、2030年末98%以上が業界目標 → [①](01_LED化が業界に何をしたか.md) |
| **水俣条約**              | 水銀による健康被害・環境汚染を防ぐ国際条約。2023年のCOP5で一般照明用蛍光ランプが規制対象に追加され、2028年1月1日に製造・輸出入が全面禁止になる → [③](03_直近トピック_2026.md)                                 |
| **Lighting 5.0**          | JLMAが掲げる次世代照明の概念。センサー・通信・制御を備え空間に応じて光を変える照明システム。出荷構成比34.8%（2026年3月）、目標40% → [②](02_市場と競争.md)                                                     |
