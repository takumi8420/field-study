LED化が業界に何をしたか

電機・電子部品照明
あこのページの単語集用語に触れると意味を確認できます12語
2023年11月2024年12月24日LEDlm/W（ルーメン毎ワット）SSLストック市場／フロー市場水俣条約特定水銀使用製品三波長形／ハロりん酸塩系安定器（バラスト）Lighting 5.0演色性（Ra）

このノートで分かること：照明業界が自分の市場を自分で壊した構造を、寿命・価格・規制の3点から理解する。
「省エネで良いことずくめ」と言われたLED化が、業界にとっては需要の前借りと蒸発だったという話である。

ポイント：照明は「器具を売る商売」であると同時に「ランプを売り続ける商売」だった。
LEDは光源と器具を一体化し、寿命を10倍にした。
寿命が10倍になれば、同じ設置台数に対する交換需要は10分の1になる。
ここが、この業界を理解する最大の鍵である。

1. まず、照明が何を売っていたのかを押さえる

LED以前の照明ビジネスは、2階建ての構造だった。

【LED以前（〜2010年ごろ）の二階建て構造】

  ① 器具（ソケット・安定器・反射板・カバー）
     └─ 建物を建てたとき／模様替えしたときにだけ売れる
        単価は高いが、買い替えは十数年に一度  ……「フロー」

  ② ランプ（白熱電球・蛍光管）＝消耗品
     └─ 切れるたびに買い替える。器具はそのまま
        単価は安いが、毎年必ず売れる          ……「ストック課金」

     ┌──────────────┐
     │ 設置台数 × 1/寿命 = 毎年の交換需要 │  ← ここが安定収益
     └──────────────┘

②が業界の背骨だった。日本国内には照明器具が 約18.1億台（JLMAが2022年に公表した推計）あり、
そこに毎年一定割合でランプ交換が発生する。
プリンタとインク、ひげ剃りと替刃と同じ「消耗品モデル」である。

2. 寿命が10倍になると、交換需要は10分の1になる

光源ごとの寿命は次の通り（カタログ値の一般的な目安。使用条件で変わる）。

光源 定格寿命の目安 発光効率の目安 消耗品としての性格
白熱電球1,000〜2,000時間10〜15 lm/W年に何度も切れる。最も売れる消耗品だった
蛍光ランプ6,000〜12,000時間60〜100 lm/Wオフィスで2〜3年に一度の一斉交換
HID（水銀灯・ナトリウム灯）6,000〜12,000時間50〜130 lm/W工場・道路。高所作業を伴い交換費用が高い
LED40,000時間前後100〜180 lm/W建物の改修周期より長い。実質「交換しない」

lm/W（ルーメン毎ワット）＝1ワットの電力で何ルーメンの明るさを出せるかという効率の指標。

40,000時間は、オフィスで1日10時間・年250日使うと16年に相当する。
つまりLEDの寿命は、建物の内装更新サイクル（10〜20年）とほぼ同じか、それより長い。

【同じ100万台の設置に対する、年間の交換ランプ需要】

  白熱電球（寿命1,500h／年3,000h使用）  ██████████████████████ 200万個/年
  蛍光ランプ（寿命10,000h／年3,000h）   ███                      30万本/年
  LED（寿命40,000h／年3,000h）          █（実質ゼロ。器具ごと交換） 7.5万台/年

  → 消耗品として見たとき、LEDは「売れない商品」である

さらに致命的なのは、LEDは光源と器具が一体になったこと。
LEDは半導体素子であり、熱を逃がす放熱板と電源回路（ドライバ）が必要になる。
その結果、多くのLED照明は「器具ごと交換する」設計になった。
ソケットに差すだけのランプ交換（＝メーカーにとって手離れの良い消耗品売り）という商売自体が、構造的に消えた。

因果：LED化は省エネ技術の勝利であると同時に、
業界にとっては「消耗品売上の消滅」と「器具需要の一括前倒し」だった。

3. 「1回限りの特需」という形の需要

LED化は、市場を静かに縮ませたのではなく、山と谷を作った。

【LED化がもたらす需要の形（模式図）】

 出荷額
   ▲
   │                 ┌──────┐   ←② 既設のLED化置き換え（特需）
   │                 │      │      ・1軒／1棟につき「1回だけ」
   │   ─────┘      └──┐   ・補助金・規制がトリガー
   │  ①従来の            │
   │   ランプ＋器具需要     └────  ←③ 一巡後の「谷」
   │                                   ・交換需要はほぼ消えている
   │                                   ・残るのは新築＋LED→LEDの買い替え
   └────────────────────────▶ 時間
      2010年代前半         2020年代       2030年代？

① 従来需要：ランプが毎年売れ、器具は建て替えのときに売れる
② 置き換え特需：「電気代が半分になる」「補助金が出る」「蛍光灯が買えなくなる」で一斉に更新が起きる
③ 谷：置き換えが終わった建物は、次の更新まで十数年何も買わない

②は一度しか起きない。しかも②の期間中に③の需要まで前借りしている。
業界が「LED化率が上がるほど将来が苦しくなる」というねじれた立場に置かれるのは、このためである。

実際、世界最大手のシグニファイ（旧フィリップスライティング、オランダ）は
2025年12月期の売上高が 57億6,500万ユーロ（約58億ユーロ）で、前年の約61億ユーロから減少し、
既存事業ベースの成長率は -3.4%（同社IR、2026年1月30日発表）。
世界の出荷ベースSSL化率（LED等の半導体照明の比率）はすでに 85% に達しており（JLMA 2026年度事業計画書）、
「置き換えるべき非LED」が世界的に減ってきたことが、そのまま売上減になって表れている。

4. 価格下落とコモディティ化

LEDのもう一つの破壊力は、値段が猛烈に下がることである。理由は3つ。

要因 中身 結果
半導体だからLEDチップはウエハから大量に取れる。生産量が増えるほど単価が落ちる（半導体と同じ学習曲線）10年で1/10のオーダーで下落
参入障壁が低いチップは日亜化学・クリー・サムスンなどから買える。電源・筐体は汎用部品。組み立てだけなら誰でもできる中国勢・新興ブランドが大量参入
性能が頭打ちになった効率は物理限界に近づき、「明るさ」では差がつかないスペック競争が効かず、価格競争になる
【LED照明のコストの分解（イメージ）】

  LED普及初期（2010年前後）        現在（2020年代）
  ┌────────────┐        ┌────────────┐
  │ LEDチップ        50%  │        │ LEDチップ  15%          │
  ├────────────┤        ├────────────┤
  │ 電源(ドライバ)   20%  │  ──▶  │ 電源(ドライバ) 25%      │
  ├────────────┤        ├────────────┤
  │ 筐体・放熱・光学 20%  │        │ 筐体・放熱・光学 40%    │
  ├────────────┤        ├────────────┤
  │ その他           10%  │        │ その他・物流  20%       │
  └────────────┘        └────────────┘
   ★チップが高い＝技術で差がつく        ★鋼材・樹脂・物流費が主役
                                      ＝「モノづくりのコスト」勝負に戻った

チップ比率が下がった結果、照明の原価は鋼材・アルミ・樹脂・物流費に支配されるようになった。
これは「技術で差別化しにくく、材料市況と為替に振られる」ということであり、
2023年4月にパナソニック・三菱電機照明・東芝ライテック・岩崎電気などが
一斉に10〜20%の値上げに踏み切ったのも、この構造が背景にある（報道ベース）。
値上げは2025〜2026年にも続き、パナソニック エレクトリックワークス社が2026年1月1日、
東芝ライテックが2026年4月1日に価格改定を実施している（各社告知）。

重要：2025年度に照明器具の出荷金額が過去初めて1兆円を超えた（後述）のは、
台数が伸びたからだけではない。台数+4.8%に対して金額+12.5%——
差の分は値上げ（価格転嫁）である。業界は「数量の成長」ではなく「単価の回復」で1兆円に乗せた。

5. 水銀規制（水俣条約）——最後にして最大の押し出し

LED化を「自発的な買い替え」から「買わざるを得ない更新」に変えたのが、水銀規制である。

水俣条約＝水銀による健康被害・環境汚染を防ぐための国際条約（日本の水俣病に由来する名前）。
蛍光ランプは放電のために微量の水銀を封入しており、この対象になった。

  • 2023年11月：水俣条約 第5回締約国会議（COP5）で、すべての一般照明用蛍光ランプの
    製造・輸出入を2027年末までに段階的に廃止することが決定
  • 2024年12月24日：日本で水銀汚染防止法施行令の改正を閣議決定（12月27日公布）。
    一般照明用蛍光ランプ全てが「特定水銀使用製品」に指定された

ランプの種類ごとの製造・輸出入の禁止開始日（環境省）：

種類 どんなランプか 禁止開始
電球形蛍光ランプ電球ソケットに付く渦巻き型。「電球形蛍光灯」2026年1月1日（30W超は2027年1月1日）
コンパクト形蛍光ランプダウンライト等に使う細身の蛍光灯2027年1月1日
直管形・環形（ハロりん酸塩系）安価な旧型蛍光体を使うタイプ2027年1月1日
直管形・環形（三波長形）オフィス・家庭の主流。演色性の高いタイプ2028年1月1日

つまり2028年1月1日以降、一般照明用蛍光ランプは全面的に作れず輸入もできない。

注意点を2つ。

  1. 使用が禁止されるわけではない。既存在庫の流通・販売・使用は規制対象外。
    「2027年に蛍光灯が使えなくなる」は正確ではなく、「新しく作られなくなる」が正しい
  2. 特殊用途（殺菌灯、医療・工業用など）は一般照明用と区分され、規制の外に置かれる

そしてメーカーは規制より前に降りた。

メーカー 一般照明用蛍光ランプの生産終了 発表
パナソニック エレクトリックワークス社2027年9月末2024年10月1日
東芝ライテック2027年9月末2024年11月
ホタルクス（旧NECライティング）2027年12月2024年12月2日

国内の主要3社がすべて終了を表明した時点で、日本の蛍光灯供給は事実上終わった。
製造ラインを規制ぎりぎりまで維持しても、需要が消える商品に設備を残す意味がないからである。

6. 規制が業界にもたらすもの——「谷」を深くする

規制は業界にとって短期の福音であり、中長期の負債である。

【蛍光灯規制がつくる需要のタイムライン】

  └───────────┴────────────────────────────────────┘
       山（2025〜2028）              ▶       谷（2030年代前半）

ストック市場のLED化率は2026年3月末時点で67.5%（JLMA 2026年度事業計画書）。
残り3割強が2030年までに更新されれば、そこで置き換え需要は原理的に尽きる。
JLMAが掲げる「2030年末にストックのSSL化率98%以上」という目標は、
業界にとっては目標であると同時に、需要の終点でもある。

だから業界は「LEDからLEDへの買い替え」を作らなければならない。
そのための答えが、制御・IoT・人間中心照明といった付加価値化である
→ ② 市場と競争

7. 誰が得をして、誰が損をしたか

プレイヤー LED化の影響 理由
ランプ専業（光源メーカー）最大の被害者。事業そのものが消えた消耗品モデルの消滅。NECは2018年に照明事業からの撤退を決め、2019年にホタルクスへ承継
総合電機の照明子会社縮小・切り離しの対象に本体からみて低収益。東芝ライテック・三菱電機照明などは規模を絞る方向
器具専業メーカー相対的に有利。器具需要は残った照明は「器具を選ぶ商売」に一本化された。デザインと提案力が効く
新規参入（アイリスオーヤマ等）最大の受益者安定器・蛍光体などの旧技術資産がゼロでも参入できた
電気工事店・施工業者人手が足りないほどの仕事置き換えには必ず工事が伴う。2026年は納期・施工の逼迫が報じられる
中国メーカー・EC直販低価格帯を席巻組み立てのハードルが低く、ネット通販で直接入ってくる
ユーザー（建物所有者）電気代が下がるが、更新費用は前倒しで発生補助金と電気代削減で回収する計算

総括：LED化は照明を「消耗品ビジネス」から「設備投資ビジネス」に変えた。
設備投資ビジネスは、景気・建設投資・規制・補助金に左右される。
毎年安定して売れていた業界は、波の大きい業界になった。

8. 用語メモ

用語 意味
LEDLight Emitting Diode（発光ダイオード）。電流を流すと光る半導体素子。寿命40,000時間前後、効率100〜180 lm/W

ストック市場／フロー市場ストック＝すでに設置されている器具（国内約18.1億台と推計）。フロー＝新たに出荷される器具。照明業界の需要はストックの更新で決まる

特定水銀使用製品水銀汚染防止法で製造・輸出入が規制される製品の区分。2024年12月の政令改正で一般照明用蛍光ランプが指定された
三波長形／ハロりん酸塩系蛍光ランプの蛍光体の種類。三波長形は色の見え方（演色性）が良く主流。ハロりん酸塩系は安価な旧型で、規制の期日が1年早い
安定器（バラスト）蛍光灯やHIDランプに必要な電流制御装置。LEDでは電源回路（ドライバ）に置き換わる。既設器具の安定器を残したままLEDランプを付ける「直管LED化」は発火事故の原因になり得るため、JLMAが注意喚起している

演色性（Ra）光の下で物の色がどれだけ自然に見えるかの指標。最大100。店舗・美術館では高い演色性が売りになる
