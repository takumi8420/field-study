# 直近トピック（2026年9月時点）

報道・業界団体公表ベースの整理。数値は一次情報で裏取りすること。
このノートで分かること：**蛍光灯の終わりがいま何合目にあるか**、そしてそれが市場に何を起こしているか。

> **一行でいうと**：2026年の照明業界は「**規制が作った特需のまっただ中**」にある。
> 出荷金額は過去初の1兆円超え、工事は半年先まで埋まり、値上げが通る。
> しかし全面禁止は**2028年1月1日**。その先には前借りした需要の反動が待っている。

---

## 1. 蛍光ランプの製造終了——スケジュールの現在地

**これが業界最大のテーマ**。2023年11月の水俣条約COP5の決定を受け、
日本では2024年12月24日に水銀汚染防止法施行令の改正が閣議決定（12月27日公布）され、
一般照明用蛍光ランプ全てが「特定水銀使用製品」に指定された。

### 法規制（製造・輸出入の禁止）のスケジュール

| ランプの種類                                         | 禁止開始         | 2026年9月時点の状況                             |
| ---------------------------------------------------- | ---------------- | ----------------------------------------------- |
| **電球形蛍光ランプ**（渦巻き型の電球代替）           | **2026年1月1日** | **すでに禁止済み**（30W超のみ2027年1月1日から） |
| **コンパクト形蛍光ランプ**                           | **2027年1月1日** | あと約3か月                                     |
| **直管形・環形（ハロりん酸塩系＝安価な旧型蛍光体）** | **2027年1月1日** | あと約3か月                                     |
| **直管形・環形（三波長形＝オフィス・家庭の主流）**   | **2028年1月1日** | あと約1年3か月で**全面禁止**                    |

出典：環境省「一般照明用蛍光ランプの規制について」

### メーカーの生産終了（法規制より前倒し）

| ------------------------------------- | ------------------------------ | ------------- |

国内主要3社がすべて終了を表明済み。**法規制を待たずに供給が細る**のが実態である。

                     └────────────────────┘

### 誤解されやすい3点

1. **「2027年に蛍光灯が使えなくなる」は不正確**。禁止されるのは**製造・輸出入**であり、
   既存在庫の販売・流通・使用は規制対象外。手持ちのランプはそのまま使える
2. **殺菌灯など特殊用途は規制の対象外**。一般照明用との区分の周知がJLMAの重要課題になっている
3. **「直管LEDランプへの付け替え」には注意が必要**。既設の蛍光灯器具の安定器を残したまま
   LEDランプだけ挿す方式は、発火・落下のリスクがあり、JLMAが繰り返し注意喚起している。
   原則は**器具ごとの交換**

### 認知度が上がりきらない

JLMAの2026年度事業計画書によれば、蛍光灯終息の**認知度は2026年2月時点で42.4%**。
全面禁止まで2年を切った時点で、**半分以上が知らない**。
「やや広がりにかげりが見られる」としてテレビCMを含む啓発を展開しているが、
逆にいえば**2027〜2028年に「買えない」と気づく層が大量に残っている**ということでもある。

## 2. 2025年度、照明器具の出荷金額が初の1兆円超

JLMAの自主統計によれば、2025年度（2025年4月〜2026年3月）の照明器具の国内出荷は
**6,692万7,000台（前期比+4.8%）／1兆234億1,000万円（同+12.5%）**。
**照明器具単独で年度出荷額が1兆円を超えたのは初めて**と報じられた（電波新聞デジタル、2026年）。

```
【1兆円超えの中身を分解する】

  金額 +12.5%
    ├─ 台数の寄与     +4.8%  ← 27年問題の駆け込み更新＋施設投資
    └─ 単価の寄与     +7.4%程度 ← 価格転嫁（値上げ）
                              材料費・エネルギー費・物流費の高止まり

  ▶「市場が成長した」のではなく「値上げが通るようになった」
    需要が逼迫しているから値上げが通る＝特需の裏返し
```

値上げは各社が継続的に実施している。パナソニック エレクトリックワークス社は
2026年1月1日から照明器具（補修部品含む）の価格改定、
東芝ライテックは2026年4月1日に照明器具・LED電球・配線器具等の価格改定を実施（各社告知）。

## 3. 工事のボトルネック——器具はあっても付けられない

2026年に入り、LED化工事の駆け込み需要がピークに達し、
**照明業界のボトルネックがメーカーから施工側に移った**と報じられている。

| 現象                 | 中身                                                                                                                                                                                                     |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **施工業者の逼迫**   | 工事店の予定が半年先まで埋まる事例が報じられる                                                                                                                                                           |
| **納期の長期化**     | 特定の器具・部材が数か月待ちになるケース                                                                                                                                                                 |
| **施工費の上昇**     | 需要過多に物流コスト上昇が重なる                                                                                                                                                                         |
| **改修特有のリスク** | 古い建物の天井改修では、**石綿（アスベスト）含有建材**の事前調査が必要になる場合がある。2022年4月から一定規模以上の解体・改修工事で事前調査結果の報告が義務化されており、照明のLED化工事もこれに触れ得る |

> **構図**：蛍光灯の期限は動かせないが、**電気工事の人手は増やせない**。
> 照明業界の供給制約は、いまや器具の生産能力ではなく**電気工事士の頭数**である

## 4. LED化率67.5%——残り3割と「その先」

JLMAの2026年度事業計画書によれば、**ストック市場のLED化率は2026年3月末時点で67.5%**。
JLMAは「LIGHTING VISION 2030」で**2030年末にストックのSSL化率98%以上**を掲げており、
「なお大きなギャップがある」と自ら記している。

| KPI                           | 目標              | 2026年時点                                 |
| ----------------------------- | ----------------- | ------------------------------------------ |
| ストックのSSL（LED）化率      | 2030年末に98%以上 | **67.5%**（2026年3月末）                   |
| Lighting 5.0 製品の出荷構成比 | 40%               | **34.8%**（2026年3月）／34.5%（2026年2月） |
| Lighting 5.0 の認知度         | —                 | **12.3%**                                  |
| 蛍光灯終息の認知度            | —                 | **42.4%**（2026年2月）                     |
| LED機器の消費電力量削減       | 60%削減           | 推進中                                     |

**残り3割強の内訳**が難所である。
更新が進んでいないのは、①予算のない中小事業者・古い賃貸ビル、②自治体の街路灯・防犯灯、
③高所や特殊用途で工事費が跳ね上がる箇所、④「まだ点いているから」と先送りされている家庭——
いずれも**価格に敏感で、動かすには補助金か強制力が要る**層である。

```
【LED化率の伸び方（模式）】

 100% ┤                                     ･･･◆ 2030年目標98%
      │                                ･･･
  80% ┤                          ･･･
      │                    ●67.5%（2026年3月）
  60% ┤              ／
      │         ／           ←ここまでは「得をするから」進んだ
  40% ┤    ／                  （電気代削減で回収できる案件から順に）
      │ ／
  20% ┤                        ←ここから先は「損でもやる」層
      └────────────────────────────
       2015      2020      2026      2030

  ★ 残り3割は投資回収が悪い案件。規制と補助金がないと動かない
```

## 5. 「谷」への備え——付加価値化と環境データ

特需の後をどうするか。2026年時点で業界が打っている手は主に3つ。

### ① Lighting 5.0 の本格的な市場投入

JLMAは2026年度、**Lighting 5.0 対応製品の「市場周知」から「市場普及」へ舵を切る**と明記し、
2026年5月開催のJECAフェア（電設工業展）への出展を決定。
単なる概念の啓発ではなく、蛍光ランプ終息の周知と**高付加価値製品への移行**を同じ場で訴求する構えである。
出荷構成比は34.8%まで来ており、目標の40%は「目前」とされる。

### ② 環境データ（カーボンフットプリント）の整備

- 国土交通省が**2028年度から建築物へのLCA（ライフサイクルアセスメント）導入を予定**
- これを受けJLMAはワーキンググループを設置し、**照明器具のCFP（カーボンフットプリント）
  算定ガイドライン案と業界代表データ**を策定中
- 海外ではIEC（国際電気標準会議）でPCR（プロダクトカテゴリー・ルール）制度の導入が進む

> **意味**：建物のCO2を計算する制度が入ると、**器具ごとのCO2排出量を出せないメーカーは図面に書かれなくなる**。
> 環境対応は「良いこと」ではなく、**参入資格**に変わりつつある。

### ③ メンテナンス簡素化という新しい価値

2025年の消防用設備等の点検要領改正を受け、**周期始動方式の自動点検機能を持つ誘導灯**が各社から順次発売。
JLMAは2026年度、これを「メンテナンスの簡素化という新たな価値」として普及させる方針を掲げ、
同じ方式を非常用照明器具にも広げるため**2026年12月を目標にJIL5501の改正**を進めるとしている。
非常用照明・誘導灯は法定設備で景気に左右されず、**点検コストの削減は施設オーナーに直接効く**。

## 7. 全体の構図（まとめ）

```
   【2026年の照明業界を1枚で】

   水俣条約（外圧）
        │
        ▼
   蛍光灯の製造終了（2026.1〜2028.1）
        │
        ├──▶ 駆け込み更新 ──▶ 台数+4.8%
        │                        │
        ├──▶ 需給逼迫 ─────▶ 値上げが通る ──▶ 金額+12.5%
        │     （工事・納期）                        │
        │                                          ▼
        │                              2025年度 初の1兆円超
        ▼
   LED化率67.5% ──▶ 2030年に98%へ ──▶ ★置き換え需要の終点
                                              │
                                              ▼
                     付加価値化（Lighting 5.0／HCL／制御）
                     環境データ（LCA・CFP）
                     メンテナンス簡素化（誘導灯の自動点検）
                            ＝「谷」を埋められるかの勝負
```

1. **需要は規制が作っている**。2026年の好調は市場の成長ではなく、期限のある特需である
2. **1兆円超えの過半は値上げ寄与**。数量成長は+4.8%にとどまる
3. **ボトルネックは工事側**。電気工事の人手が照明の売上上限を決めている
4. **LED化率67.5%の残り3割は、補助金と強制力なしには動かない層**
5. **世界最大手はすでに減収**。日本の谷は数年遅れて来る。業界の勝負どころは
   「置き換えが終わった後に、LEDからLEDへ買い替えさせる理由」を作れるかどうかにある

## 8. 用語メモ

| 用語                                    | 意味                                                                                                                                                           |
| --------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **水俣条約COP5**                        | 2023年11月開催の水銀に関する水俣条約 第5回締約国会議。すべての一般照明用蛍光ランプの製造・輸出入を2027年末までに廃止することを決定した                         |
| **水銀汚染防止法施行令**                | 水俣条約を国内で実施するための政令。2024年12月24日に改正を閣議決定、12月27日公布                                                                               |
| **特定水銀使用製品**                    | 水銀汚染防止法で製造・輸出入が規制される製品区分。一般照明用蛍光ランプ全てが指定された                                                                         |
| **三波長形蛍光ランプ**                  | 赤・緑・青の3つの波長域を強く出す蛍光体を使った蛍光灯。色の見え方が良く、オフィス・家庭の主流。禁止は最後の2028年1月1日                                        |
| **直管LED化（既設器具流用）**           | 蛍光灯器具のソケットを残したままLEDランプに差し替える方式。安定器の扱いを誤ると発火・落下の恐れがあり、JLMAが注意喚起している                                  |
| **周期始動方式（誘導灯）**              | 誘導灯・非常用照明の点検を自動化する方式。2025年の消防用設備等点検要領の改正を受けて製品化が進む                                                               |
| **JIL5501**                             | 日本照明工業会規格のひとつ。非常用照明器具に関する規格で、2026年12月を目標に改正が進められている                                                               |
| **LCA／CFP**                            | LCA＝ライフサイクルアセスメント（製品の一生分の環境負荷評価）。CFP＝カーボンフットプリント（製品ごとのCO2排出量）。国交省が2028年度から建築物へのLCA導入を予定 |
| **PCR（プロダクトカテゴリー・ルール）** | 製品カテゴリーごとに環境負荷の算定方法を定めたルール。IECで照明分野の導入が進む                                                                                |
| **JECAフェア**                          | 日本電設工業協会が主催する電設工業展。電気工事業界向けの最大級の展示会で、電材ルートへの訴求の場                                                               |
