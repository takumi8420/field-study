# FAとは何か・機器の構成

**このノートで分かること**：FA（ファクトリーオートメーション＝工場の自動化）が
どんな機器の組み合わせでできているか。PLC（シーケンサ）・サーボ・インバータ・センサ・
画像処理・表示器という**6つの定番部品**が工場の中でどんな役割を分担しているか。
そして「ERP → MES → SCADA → PLC → 現場機器」という**制御の5階層**の意味。

結論を先に書く。**FA・制御機器とは「工場の神経と筋肉を構成する部品群」である。**
産業用ロボットが「腕」だとすれば、こちらは**脳（PLC）・神経（産業用ネットワーク）・
感覚器（センサ）・筋肉（サーボ・インバータ）**にあたる。
ロボットが1台も入っていない工場はいくらでもあるが、
**PLCとセンサが1つも入っていない工場はほぼない**。これがこの業界の裾野の広さを決めている。

ロボット本体（垂直多関節・スカラ・協働ロボット）の話は
[産業用ロボット](../../02_自動車・機械/09_産業用ロボット/README.md) に委ね、ここでは**その下に敷かれた制御の層**に絞る。

## 1. FAの定義：どこからどこまでか

FAとは、**工場の中で「人がやっていた判断と動作」を機械に置き換える仕組み全体**を指す。
ただし業界用語としての「FA・制御機器」は、もう少し狭く、
**現場の機械を動かし・測り・つなぐための汎用部品**を意味することが多い。

| 含む（FA・制御機器）                                           | 含まない（隣接業界）                                                                           |
| -------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| PLC（シーケンサ）、産業用PC                                    | ロボット本体 → [産業用ロボット](../../02_自動車・機械/09_産業用ロボット/README.md)             |
| サーボモータ・サーボアンプ、インバータ                         | 汎用モータ全般 → [モーター](../../02_自動車・機械/15_モーター/README.md)                       |
| 光電・近接・ファイバセンサ、変位計、画像処理（マシンビジョン） | 研究室の分析装置 → [計測・分析機器](../13_計測・分析機器/README.md)                            |
| 表示器（HMI）、操作スイッチ、リレー、電磁開閉器                | 工作機械そのもの → [工作機械](../../02_自動車・機械/07_工作機械/README.md)                     |
| 空気圧シリンダ・電動アクチュエータ・電磁弁                     | 油圧ポンプ・油圧ユニット → [油圧・空圧機器](../../02_自動車・機械/11_油圧・空圧機器/README.md) |
| 産業用ネットワーク機器、安全（セーフティ）機器                 | 工場のERP・会計システム → IT業界                                                               |
| CNC（工作機械の数値制御装置）                                  | 半導体製造装置 → [半導体製造装置](../03_半導体製造装置/README.md)                              |

> 境界のコツ：**「機械メーカーが自分の機械を作るために買う部品」がFA・制御機器**。
> 工作機械メーカーはファナックのCNCを買い、装置メーカーは三菱電機のシーケンサを買う。
> つまりこの業界の**顧客の大半は最終ユーザーではなく、機械を作る会社（装置メーカー）**である。

## 2. 6つの定番機器：何が何を担当しているか

FAの現場で必ず出てくる機器は、次の6種類に整理できる。

```
                        ┌─────────────────────┐
                        │ 表示器（HMI）         │ ← 人が見る・触る
                        └──────────┬──────────┘
   【感覚器】                 【脳】│                 【筋肉】
   センサ ──────────▶  PLC（シーケンサ）  ──────────▶ サーボモータ
   「ワークが来た」        「来たら、掴んで、          「指定位置へ
   光電/近接/ファイバ       右に80mm動かして、          0.01mm単位で」
                           次工程へ流せ」
   画像処理 ──────────▶      │        ──────────▶ インバータ
   「キズがある／            条件分岐・タイマ    「コンベアを
    位置が3mmずれてる」      ラダープログラム     30Hzで回せ」
                                   │
                        ┌──────────┴──────────┐
                        │ 産業用ネットワーク     │ ← 神経（配線）
                        │ CC-Link/EtherCAT/…    │
                        └─────────────────────┘
```

| 機器                           | 何をするか                                                 | ひとことで                             | 代表メーカー                                                                     |
| ------------------------------ | ---------------------------------------------------------- | -------------------------------------- | -------------------------------------------------------------------------------- |
| **PLC（シーケンサ）**          | センサの信号を読み、条件に従って出力を出す専用コンピュータ | **工場の脳**                           | 三菱電機（国内首位）、シーメンス（世界首位）、オムロン、キーエンス、ロックウェル |
| **サーボモータ＋アンプ**       | 「どこへ、どれだけ」を位置で指定して回すモータ一式         | **正確に位置を決める筋肉**             | 安川電機、三菱電機、ファナック、パナソニック、汇川技術（中）                     |
| **インバータ**                 | 電源の周波数を変えてモータの回転数を変える装置             | **速さを変える筋肉**（位置は決めない） | 三菱電機、安川電機、富士電機、ABB、シーメンス                                    |
| **センサ**                     | 物の有無・距離・色・温度を電気信号に変える                 | **感覚器**                             | キーエンス、オムロン、SICK（独）、パナソニック                                   |
| **画像処理（マシンビジョン）** | カメラ画像から位置・傷・文字を判定する                     | **目と判断**                           | キーエンス、コグネックス（米）、オムロン                                         |
| **表示器（HMI）**              | 現場の作業者が状態を見て操作する画面                       | **人との窓口**                         | 三菱電機、シュナイダー（Pro-face）、キーエンス                                   |

### サーボとインバータの違い（ここを混同しやすい）

どちらも「モータを動かす」機器だが、**目的が違う**。

```
  インバータ（速度制御）              サーボ（位置制御）
   ───────────────              ───────────────
   コンベアを「秒速30cmで回す」        アームを「原点から123.45mmへ動かす」
   止まる位置は気にしない              止まる位置が全て
   フィードバックなしでも成立          エンコーダで位置を常時読んで補正
   1台あたり数万〜数十万円             1軸あたり十数万〜数十万円
        │                                  │
        └── 搬送・ポンプ・ファン             └── 組立・位置決め・切断・巻取
```

**エンコーダ**（モータの回転角度を読む部品）が付いて「今どこにいるか」を常に測り、
指令とのズレを打ち消し続けるのがサーボ。この**閉じた輪（クローズドループ）**があるかどうかが分かれ目である。

## 3. 制御の5階層：ERP / MES / SCADA / PLC / 現場機器

工場のシステムは**5段のピラミッド**で説明されるのが慣例である（ISA-95という国際規格の考え方が元）。
上に行くほど「経営の言葉」、下に行くほど「電気の言葉」になる。

```
  ┌──────────────────────────────────────────┬──────────────┐
  │ Lv4 ERP（基幹系）  受注・在庫・原価・会計   │ 日〜月／IT部門 │
  │ Lv3 MES（製造実行）作業指示・実績・トレース │ 時間〜分／IT･OTの境目│
  │ Lv2 SCADA / HMI    監視・警報・操作画面     │ 秒            │
  │ Lv1 PLC / CNC / DCS 論理制御・位置制御      │ ミリ秒／FAの主戦場│
  │ Lv0 現場機器       センサ・アクチュエータ   │ マイクロ秒     │
  └──────────────────────────────────────────┴──────────────┘
        ↑ 上へ行くほど「情報」、下へ行くほど「物理」
   例：Lv4「今月1万個作る」→ Lv3「ライン2でロット#331を3時から」
       → Lv2「3号機が停止、温度異常」→ Lv1「X0がONならY3をON」
```

- **OT（Operational Technology）**：Lv0〜Lv2の、現場を動かす技術。止まると生産が止まる
- **IT**：Lv3〜Lv4の、情報を扱う技術。止まっても生産自体は続く

> この業界を理解する鍵：**FA・制御機器メーカーの本丸は Lv0〜Lv1 である。**
> そして2010年代以降、各社が争っているのは「**Lv1で得たデータを、どうLv3へ上げるか**」。
> シーメンスがソフトウェア（Siemens Xcelerator）に、三菱電機が e-F@ctory に、
> オムロンが i-Automation に力を入れるのは、すべてこの「縦の階層をつなぐ」競争である。

なお化学プラントや製鉄所では、Lv1にPLCではなく **DCS（分散制御システム）** が入る。
**PLCは「動く／動かない」の離散制御**（組立・搬送）、**DCSは「温度・圧力・流量を一定に保つ」連続制御**が得意で、
横河電機・アズビル・エマソンなどが強く、FA機器各社とは別の競争圏にある。

## 4. ラダー言語：なぜFAだけ特殊なプログラミングなのか

PLCのプログラムは、いまだに**ラダー（ladder＝はしご）図**という、
左右2本の縦線の間に接点とコイルを並べる図で書かれることが多い。

```
   母線                                          母線
    │  ┌ ─┤├─ ──┤/├── ──────( )─┐        │
    ├──┤  X0      X1           Y0   ├────────┤
    │  └────────────────────────────┘        │
    │      ↑         ↑              ↑
    │   a接点     b接点          出力コイル
    │  「X0がON」 「X1がOFF」    「ならY0をON」
    │  意味：センサX0が検知し、かつ非常停止X1が押されていなければ、シリンダY0を前進
```

なぜこんな古い形式が残るのか。理由は3つある。

1. **元がリレー回路の図だから**。PLC以前は物理的なリレー（電磁式のスイッチ）を配線して
   制御していた。ラダー図はその配線図をそのまま画面に持ってきたもので、
   **電気技術者がそのまま読める**
2. **保全（メンテナンス）の現場で読めることが最優先**。深夜にラインが止まったとき、
   駆けつけるのはソフト技術者ではなく現場の保全員。C言語では対応できない
3. **動作が「1スキャン」ごとに上から下へ確定する**ので、タイミングの読み違いが起きにくい

IEC 61131-3 という国際規格では、ラダー（LD）のほかに
ST（構造化テキスト、Pascal風）、FBD（ファンクションブロック）、SFC（フローチャート風）など
計5言語が定義されている。**近年はSTの比率が上がっている**が、
現場の保全性を理由にラダーが残る工場は依然として多い。

> ここが人材面の論点にもなっている。**ラダーが書ける技術者は「電気屋」の系譜で、
> IT系の人材プールとほぼ重ならない**。そのため制御設計者の高齢化・不足が、
> 自動化投資の実行スピードそのものを縛っている。

## 5. 産業用ネットワーク：規格が割れたままの理由

工場の中の配線は、**メーカーごとに別の規格**が使われている。
ここがFA業界の特徴であり、ユーザーにとっての最大の悩みでもある。

| 規格                    | 主導                 | 特徴                                                                               |
| ----------------------- | -------------------- | ---------------------------------------------------------------------------------- |
| **CC-Link IE**          | 三菱電機（CLPA）     | 国内シェアが高い。1Gbpsのイーサネットベース                                        |
| **EtherCAT**            | ベッコフ（独、ETG）  | 高速・低遅延。モーション制御で強い。オムロンも採用                                 |
| **PROFINET / PROFIBUS** | シーメンス（PI）     | 欧州で圧倒的。世界の設置ベースが大きい                                             |
| **EtherNet/IP**         | ロックウェル（ODVA） | 北米で主流                                                                         |
| **MECHATROLINK**        | 安川電機             | サーボ間の高速同期に特化                                                           |
| **IO-Link**             | 業界団体（PI傘下）   | センサ1個1個と双方向通信し、設定や故障予兆を吸い上げる下位規格                     |
| **OPC UA**              | OPC Foundation       | メーカーの壁を越えて「意味付きデータ」を上位へ渡すための共通規格                   |
| **TSN**                 | IEEE（802.1）        | 標準イーサネット上で時刻同期と遅延保証を実現する技術。上記を統合する土台になりうる |

```
   規格が割れている理由（＝それが収益構造そのもの）

   自社規格のネットワーク
     → 周辺機器（I/O・サーボ・表示器）も自社製で揃えるのが一番安く速い
     → 一度組んだラインは10〜20年使う
     → 増設・更新のたびに同じメーカーを選ぶ   ← 乗り換え障壁（ロックイン）
     → 規格を統一すると、この障壁が消える     ← だから各社は統一に本気になりきれない
```

近年は **OPC UA over TSN**（意味付きデータ＋時刻保証を標準イーサネットで実現する組み合わせ）が
「ベンダの壁を越える切り札」として2018年頃から推進されている。
ただし**2026年時点でも現場の置き換えは限定的**で、既存の各社規格と併存している状態である。

## 6. 安全（セーフティ）という別カテゴリ

FA機器にはもう一つ、**「止めるための機器」**という独立したカテゴリがある。

| 機器                                 | 役割                                                 |
| ------------------------------------ | ---------------------------------------------------- |
| 非常停止スイッチ                     | 人が押して全体を止める                               |
| ライトカーテン（安全光線式防護装置） | 光の幕を人が横切ったら止める                         |
| セーフティリレー／セーフティPLC      | 止める判断だけを、通常制御とは別系統で二重化して行う |
| インターロックスイッチ               | 扉が開いている間は動かさない                         |

安全機器が通常のPLCと別系統なのは、**「制御が壊れても、安全は壊れてはいけない」**ため。
国際規格 ISO 13849（PL＝パフォーマンスレベル）や IEC 62061（SIL＝安全度水準）で
「どれだけ壊れにくいか」が等級化されており、**等級を満たす部品でなければ売れない**。
これが参入障壁として効いている領域である（ライトカーテンは光の幕で人の侵入を検知する装置）。

## 7. 一つのラインを例に、機器がどう並ぶか

抽象論を避けるため、小さな組立ラインを例に取る。

```
 ┌──────────────────────────────────────────────────────────────┐
 │                       制御盤（キャビネット）                    │
 │  ブレーカ → 電磁開閉器 → ［ PLC ］←→［ サーボアンプ×3 ］        │
 │                            ↑ ↓          ↑                     │
 │                       ［ 表示器 ］    ［ インバータ ］          │
 └───────────────────────┬──────────────────┬─────────────────┘
                         │ 産業用ネットワーク │ 動力線
   ━━━━━━━━━━━━━━━━━┷━━━━━━━━━━━━━━━━━━┷━━━━━━━━━━━
    ① 供給        ② 位置決め      ③ 組付け        ④ 検査        ⑤ 排出
   コンベア      ストッパ＋        サーボ2軸      画像処理       振分ゲート
   （インバータ）  近接センサ       ＋空圧チャック   カメラ        （電磁弁）
        │             │               │             │             │
     光電センサ    近接センサ      変位センサ     照明＋レンズ   光電センサ
    「ワーク来た」 「所定位置」    「高さ確認」   「キズ・位置」  「流れた」
 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

このラインでロボットは1台も使っていないが、**FA機器は数十点使われている**。
制御盤の中身（PLC・サーボアンプ・電源・配線）とセンサ類だけで数百万円規模になることが珍しくない。
**FA機器市場がロボット市場より大きく、かつ景気の谷でもゼロにならないのは、
この「どんな自動化にも必ず要る」性質による。**
なお、これらを選定して盤を作りラインとして立ち上げるのは装置メーカー・制御盤メーカー・SIerの仕事で、
その商売の構造は [システムインテグレーション](../../02_自動車・機械/09_産業用ロボット/02_システムインテグレーション.md) に詳しい。

## 用語メモ

| 用語                      | 意味                                                                                                                                      |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| **FA**                    | Factory Automation。工場の自動化、およびそのための機器群                                                                                  |
| **PLC／シーケンサ**       | Programmable Logic Controller。入力に応じて出力を出す産業用の制御コンピュータ。「シーケンサ」は三菱電機の登録商標だが一般名詞的に使われる |
| **サーボ**                | 位置や速度を指令どおりに追従させる制御方式。モータ＋エンコーダ＋アンプの一式を指すことが多い                                              |
| **インバータ**            | 交流の周波数を変えてモータの回転数を変える装置。位置決めはしない                                                                          |
| **エンコーダ**            | 回転角度・移動量を電気信号で出す検出器。サーボの「目」                                                                                    |
| **HMI**                   | Human Machine Interface。現場の作業者が見る操作パネル（表示器）                                                                           |
| **SCADA**                 | Supervisory Control And Data Acquisition。複数の設備を監視・記録する上位ソフト                                                            |
| **MES**                   | Manufacturing Execution System。製造実行システム。ERPの指示を現場の作業指示に翻訳し、実績を戻す                                           |
| **DCS**                   | Distributed Control System。プラントの連続制御用。PLCとは守備範囲が違う                                                                   |
| **OT**                    | Operational Technology。現場を動かす技術。ITと対で使う                                                                                    |
| **ラダー図**              | リレー回路図の形をしたPLCプログラム。IEC 61131-3の5言語の一つ                                                                             |
| **IO-Link**               | センサ1個単位と双方向通信する下位ネットワーク規格。設定値や故障予兆を吸い上げられる                                                       |
| **OPC UA**                | メーカーの違いを越えて「意味の付いたデータ」をやり取りする共通規格                                                                        |
| **TSN**                   | Time-Sensitive Networking。標準イーサネットで時刻同期と遅延保証を行う技術群                                                               |
| **制御盤**                | PLC・アンプ・電源・端子台を収めた金属キャビネット。FA機器の販売単位はここに集約される                                                     |
| **ISO 13849 / IEC 62061** | 安全関連制御システムの規格。PL・SILという等級で壊れにくさを表す                                                                           |
