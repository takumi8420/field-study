## 1. 制御機器の出荷が6期連続でプラス。半導体・電子部品向けが牽引

NECA（日本電気制御技術工業会）の2026年度第1四半期（2026年4〜6月）の
電気制御機器出荷統計は、**出荷総額1,727億2,000万円、前年同期比＋9.1%**。
前年同期比100%超えは**6期連続**である（2026年8月発表）。

| 項目（2026年度Q1） | 金額                 | 前年同期比                  |
| ------------------ | -------------------- | --------------------------- |
| 出荷総額           | **1,727億2,000万円** | **＋9.1%**（6期連続プラス） |
| 国内出荷           | 960億6,000万円       | ＋8.2%（2期連続増）         |
| 輸出               | 766億6,000万円       | ＋10.2%（7期連続プラス）    |

品目別では、**PLC・FAシステム機器が＋19.3%**、操作用スイッチ＋18.9%、
検出用スイッチ（センサ）＋12.1%、制御用リレー＋8.8%と軒並み伸びた一方、
**制御用専用機器は▲11.4%**と分かれた。

NECAは2026年度の年間出荷見通しを**前年度比5.4%増の7,000億円**
（国内3,970億円＝＋5.2%、輸出3,030億円＝＋5.6%）としている（2026年3月発表）。

```
   何が伸びているのか（2026年）

   AI向けデータセンター投資
        ↓
   半導体・電子部品メーカーの設備投資が拡大
        ↓
   前工程・後工程の搬送装置、検査装置、実装機が増産される
        ↓
   その装置に載るPLC・サーボ・センサが大量に必要   ← 今ここ
        ↓
   PLC・FAシステム機器 ＋19.3%（2026年度Q1）

   ※ 一方で「制御用専用機器 ▲11.4%」のように、用途によっては落ちている。
      「FAが全面的に好調」ではなく、**半導体系に偏った好調**である点に注意
```

> 読み方の注意：NECAは会員ベースの統計で、日本市場の全数ではない。
> また輸出比率が44%（2026年度Q1）あるため、**国内の自動化が進んだ結果とは限らない**。
> この構図はロボット本体（輸出85%）ほど極端ではないが、方向は同じである。

## 2. JEMAの2026年度見通し：重電機器が29年ぶりの4兆円超

JEMA（日本電機工業会）は2026年度の電気機器の見通しで、
**重電機器の国内生産を4兆467億円**とし、**1997年度以来29年ぶりに4兆円を超える**見通しを示した
（2026年3月発表）。FA機器も前年度を上回るとされる。

| 品目（2026年度見通し）            | 金額          | 前年度比    | 牽引要因                                       |
| --------------------------------- | ------------- | ----------- | ---------------------------------------------- |
| インバータ                        | **1,371億円** | ＋9.2%      | 省エネ・搬送需要                               |
| プログラマブルコントローラ（PLC） | **980億円**   | **＋12.1%** | 国内・輸出ともに半導体・電子部品産業向けが好調 |
| サーボモータ                      | 849億円       | ＋4.9%      | 装置向け                                       |
| サーボアンプ                      | 824億円       | ＋3.0%      | 同上                                           |

> 補足：重電機器の4兆円超えを押し上げているのはFAだけではなく、
> **データセンター向けの受変電設備・変圧器**の寄与が大きいとされる。
> FA機器単体の回復とデータセンター特需は、分けて読む必要がある。

## 4. 中国：汇川技術（Inovance）が国産化を加速させている

中国のFA最大手・汇川技術が、PLCとサーボで急速にシェアを伸ばしていると報じられている。

| 事象                             | 内容                                 | 時点・性格                     |
| -------------------------------- | ------------------------------------ | ------------------------------ |
| サーボシステム中国シェア         | **32%で首位**                        | 2025年、第三者調査の報道ベース |
| 小型PLCの中国シェア              | 9%（2025年Q4）→ **15%**（2026年Q2）  | 第三者調査の報道ベース         |
| ACサーボドライブの中国シェア     | 26%（2025年Q4）→ **37%**（2026年Q2） | 同上                           |
| 三菱電機の小型PLCシェア（比較）  | 12% → **7%**（同期間）               | 同上                           |
| 三菱電機のACサーボシェア（比較） | 6% → **3%**（同期間）                | 同上                           |
| 香港上場                         | H株発行・香港上場の計画を公表        | 2026年、報道ベース             |

※いずれも**第三者調査会社の推計を報じたもので、各社の公表値ではない**。
四半期単位のシェアは振れが大きいため、水準そのものより**方向**を見るべき数字である。

中国のFA市場については、**2027年まで上昇局面が続く**との見方も出ている（市況分析ベース）。
つまり「市場は伸びるが、伸びた分を国産勢が取る」という構図が想定されている。

> 日本勢への含意：中国市場での直接競合よりも、
> **中国製の装置に中国製の制御機器が載ったまま第三国へ輸出される経路**のほうが影響が大きい。
> FA機器は装置メーカーの設計段階で採用が決まる（デザインイン）ため、
> **一度装置ごと置き換わると取り返しにくい**。

## 5. 競争軸がハードからソフトへ：シーメンスの受注が示すもの

シーメンスの2026年度第2四半期（2026年1〜3月）は、
**売上198億ユーロ（＋6%）に対し受注241億ユーロ（比較可能ベース＋18%）**、
ブック・トゥ・ビル（受注÷売上）1.22。
上半期のデジタル事業は**＋19%**と報じられている。

デジタルインダストリーズ部門はソフトウェア事業とオートメーション事業の両方で伸びており、
**需要がハードウェア単体からソフトウェア・ソリューションへ移りつつある**ことを示すとされる。

```
   2020年代後半のFA競争軸

   〜2010年代              2020年代後半
   ────────              ──────────
   センサの分解能           設計データが生産計画までつながるか
   サーボの応答速度    →    仮想試運転で立ち上げ工数をどれだけ削れるか
   PLCの処理速度            工場のデータを上位（MES/クラウド）へどう渡すか
        ↓                        ↓
   機器単体のカタログ競争     環境（プラットフォーム）の囲い込み競争
        ↓                        ↓
   日本勢が強かった領域      シーメンスが先行している領域
```

日本勢も三菱電機の **e-F@ctory**、オムロンの **i-Automation**、
安川電機の **i³-Mechatronics** で対応しているが、
**設計CADから生産管理まで垂直に持つのはシーメンスとダッソー系に限られる**ため、
提携とオープン規格（OPC UA、TSN）での対抗が基本線になっている。

なお **OPC UA over TSN**（メーカーを越えたデータ流通＋標準イーサネットでの時刻保証）は
業界横断の解として推進が続いているが、**2026年時点でも現場の置き換えは限定的**で、
CC-Link IE・PROFINET・EtherCAT など各社規格との併存が続いている。

## 6. 政策：省力化投資補助金の一般型が2026年9月に公募開始

人手不足を背景とした**中小企業省力化投資補助金**が、FA機器の国内需要を下支えしている。

| 類型               | 仕組み                                                                                                                                                 | 2026年の状況                                            |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------- |
| **カタログ注文型** | あらかじめ登録された汎用製品（IoT機器・ロボット等）から選んで導入する。**個別設計が不要**                                                              | 2027年3月末頃まで随時受付                               |
| **一般型**         | 現場に合わせた個別の設備導入・システム構築を支援。補助率は中小1/2（最低賃金引上げ特例で2/3）、小規模事業者等2/3。大幅な賃上げを伴う計画は上限最大1億円 | **2026年9月18日10:00 申請受付開始、10月16日17:00 締切** |

> 制度設計の意味：**中小企業の自動化が進まない最大の理由は機器の値段ではなく、
> 設計と立ち上げの工数（SIerの人月）である。**
> カタログ注文型はその工数をゼロに近づけるための仕組みで、
> 「補助金＝値引き」ではなく「補助金＝設計工数の回避」として読むのが正しい
> （→ [システムインテグレーション](../../02_自動車・機械/09_産業用ロボット/02_システムインテグレーション.md)）。

## 7. 全体の構図（2026年9月時点）

1. **市場は回復局面にある**。NECAの出荷は6期連続プラス（2026年度Q1で＋9.1%）、
   2026年度見通しは7,000億円（＋5.4%）。JEMAはPLC＋12.1%、インバータ＋9.2%を見込む
2. **ただし牽引役は半導体・AI関連に偏っている**。同じ統計の中で
   「PLC・FAシステム機器＋19.3%」と「制御用専用機器▲11.4%」が同居している
3. **企業業績は回復しても、利益率の差は構造で決まったまま**。
   キーエンス51.0%、SMC22.6%、ファナック21.4%、三菱電機・オムロンは全社で7%台。
   これは技術差ではなく**流通経路とファブレスかどうかの差**である
4. **中国の国産化が数字に出始めた**。汇川技術が小型PLC・ACサーボでシェアを急伸させ、
   同期間に三菱電機のシェアが落ちたと報じられる（いずれも調査・報道ベース）
5. **競争軸がハードからソフトへ移りつつある**。シーメンスの受注＋18%・デジタル＋19%が象徴。
   日本勢は機器の性能で勝ってきた分、この転換への対応が中期の論点になる

> ひとことで：**「回復はしたが、勝ち方が変わりつつある」**。
> 需要の波（設備投資サイクル）は循環だが、
> 中国の国産化とソフト主導への転換は**戻らない構造変化**である。
