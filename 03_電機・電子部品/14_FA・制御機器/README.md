# FA・制御機器

- 大分類: 電機・電子部品
- 状態: done
- 更新日: 2026-09-20

FA・制御機器を一言でいえば、**「工場の脳・神経・感覚器・筋肉を構成する汎用部品」**。
産業用ロボットが「腕」だとすれば、こちらは**PLC（脳）・産業用ネットワーク（神経）・
センサ（感覚器）・サーボとインバータ（筋肉）**にあたる。
ロボットが1台もない工場はいくらでもあるが、**PLCとセンサが1つもない工場はほぼない**。
これがこの業界の裾野の広さを決めている。

そしてこの業界の最大の面白さは、**同じ市場に営業利益率51%の会社と7%の会社が同居している**こと。
差を作っているのは技術力ではなく、**直販か代理店か／ファブレスか自社工場か**という
流通と製造の設計である。

ロボット本体（垂直多関節・協働ロボット）とSIerの商売は
[産業用ロボット](../../02_自動車・機械/09_産業用ロボット/README.md) に委ね、
ここでは**その下に敷かれている制御の層**を扱う。

## 1. 業界の定義・範囲

FA（Factory Automation＝工場の自動化）・制御機器とは、
**工場の機械を「動かし・測り・つなぐ」ための汎用部品群**を指す。

| 含む                                       | 含まない（隣接業界）                                                               |
| ------------------------------------------ | ---------------------------------------------------------------------------------- |
| PLC（シーケンサ）、産業用PC、CNC           | ロボット本体 → [産業用ロボット](../../02_自動車・機械/09_産業用ロボット/README.md) |
| サーボモータ・アンプ、インバータ           | 汎用モータ全般 → [モーター](../../02_自動車・機械/15_モーター/README.md)           |
| 光電・近接センサ、変位計、画像処理         | 研究室の分析装置 → [計測・分析機器](../13_計測・分析機器/README.md)                |
| 表示器（HMI）、スイッチ、リレー            | 工作機械そのもの → [工作機械](../../02_自動車・機械/07_工作機械/README.md)         |
| 空気圧・電動アクチュエータ、電磁弁         | 油圧ユニット → [油圧・空圧機器](../../02_自動車・機械/11_油圧・空圧機器/README.md) |
| 産業用ネットワーク、安全（セーフティ）機器 | 半導体製造装置 → [半導体製造装置](../03_半導体製造装置/README.md)                  |

> 境界のコツ：**「機械メーカーが自分の機械を作るために買う部品」がFA・制御機器**。
> 工作機械メーカーはファナックのCNCを買い、装置メーカーは三菱電機のシーケンサを買う。
> つまり**顧客の大半は最終ユーザーの工場ではなく、機械を作る会社（装置メーカー）**である。

なお、化学プラントや製鉄所で使われる **DCS（分散制御システム）** は
温度・圧力を一定に保つ連続制御が主で、PLCとは守備範囲が違う。
横河電機・アズビル・エマソンなどが強く、FA機器各社とは別の競争圏にある。

①人手不足による自動化の必然性、②10〜20年ごとの更新需要、③新興国の工業化、
という3つが底を持ち上げ続けている。

## 5. 収益モデル・コスト構造

**この業界の利益率の差は、技術力ではなく流通経路の設計で決まる。**

| 企業           | 売り方                     | 作り方                 | 営業利益率（2026年3月期）  |
| -------------- | -------------------------- | ---------------------- | -------------------------- |
| **キーエンス** | 直販（課題解決型）         | ファブレス             | **51.0%**（粗利率約83%）   |
| **SMC**        | 代理店＋直販併用           | 自社生産（超多品種）   | **22.6%**                  |
| **ファナック** | 直販＋工作機械メーカー経由 | 垂直統合・大量生産     | **21.4%**                  |
| **三菱電機**   | 代理店                     | 自社生産（フルライン） | 7.3%（全社。FA以外を含む） |
| **オムロン**   | 代理店                     | 自社生産＋外注         | 7.8%（全社。FA以外を含む） |

> キーエンスの51%は4つの仕掛けの掛け算である。
> **①ファブレス**（工場を持たないので固定費と減価償却が乗らない）、
> **②直販**（代理店マージンが消え、値決めの主導権を握る）、
> **③新製品比率**（新製品の約7割が世界初・業界初とされ、比較対象を作らせない）、
> **④粗利設計**（原価からではなく顧客が得する額から値段を決める）。
> 詳細は [儲け方とビジネスモデルの違い](02_儲け方とビジネスモデルの違い.md)。

コスト構造の共通点は、**製品原価より「導入工数」のほうが大きい**こと。
機器自体は数万〜数十万円でも、それを設計し、盤に収め、プログラムを書き、
立ち上げるまでの人件費のほうが高くつく。
**ここを減らせる機器が選ばれる**という力学が、業界全体を貫いている。

販売後の収益も重要で、補修部品・生産中止に伴うリプレース・
エンジニアリングソフトのライセンスが、設備投資の谷を静かに支えている。

## 6. 競争要因（KSF）と参入障壁

**KSF（成功要因）**

1. **装置メーカーの設計段階に食い込む（デザインイン）**。一度図面に型番が載れば、量産中は発注が続く
2. **納期と入手性**。半導体不足期に中国勢が伸びた決め手は価格ではなく納期だった
3. **長期供給と互換性**。10〜20年後の更新需要を自社に引き寄せる仕掛け
4. **エンジニアリング工数の削減**。設定の簡便さ、ライブラリ、仮想試運転
5. **自社ネットワーク規格による囲い込み**。CC-Link IE、PROFINET、EtherNet/IP
6. **上位（MES・クラウド）へのつなぎ方**。シーメンスが仕掛けている土俵

**参入障壁**

- **信頼性の実績**（工場は「止まらない証明」がないと採用しない）
- **安全規格の認証**（ISO 13849のPL、IEC 62061のSIL）。等級を満たさない部品は売れない
- **保守・供給の継続性**（10年以上供給できる体力）
- **既存ネットワーク規格のロックイン**（他社に替えると周辺機器も総取り替えになる）
- 一方で**汎用リレー・汎用インバータの下位機種は障壁が低く**、中国勢の主戦場になっている

## 7. 規制・法制度

| 制度                           | 内容                                                                                                                  |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------- |
| **電気用品安全法（PSE）**      | 国内で販売する電気機器の安全規制。対象品目は届出・表示が必要                                                          |
| **ISO 13849 / IEC 62061**      | 安全関連制御システムの規格。PL（パフォーマンスレベル）・SIL（安全度水準）で壊れにくさを等級化                         |
| **IEC 61131-3**                | PLCのプログラミング言語規格（ラダー、ST、FBD、SFC、IL）                                                               |
| **IEC 62443**                  | 産業用制御システムのサイバーセキュリティ規格。工場のネット接続が進むほど重要度が上がる                                |
| **労働安全衛生規則**           | 産業用ロボットの隔離義務など。安全機器の需要を直接生む                                                                |
| **RoHS / REACH（EU）**         | 有害物質規制。輸出比率が高いため設計制約になる                                                                        |
| **中小企業省力化投資補助金**   | カタログ注文型（登録済み汎用製品から選ぶ）と一般型。**設計工数をなくすための制度設計**。一般型は2026年9月18日受付開始 |
| ものづくり補助金／IT導入補助金 | 設備投資・システム導入の一般的な支援                                                                                  |
| **中国の国産化政策**           | 「中国製造2025」以来の調達優遇。国産FA機器のシェア上昇の背景                                                          |

## 8. 最近のトピック・技術トレンド

詳細と出典URLは [04_直近トピック_2026](04_直近トピック_2026.md) に。要点は5つ。

1. **出荷が6期連続でプラス**。2026年度Q1のNECA統計は1,727億円（＋9.1%）、
   PLC・FAシステム機器は＋19.3%。JEMAは重電機器の国内生産を29年ぶりの4兆円超と見込む
2. **ただし牽引はAI・半導体関連に偏る**。同じ統計内で「制御用専用機器▲11.4%」が同居している。
   「FAが全面的に好調」ではない
3. **回復しても利益率の差は構造のまま**。キーエンス51.0%、SMC22.6%、ファナック21.4%に対し、
   三菱電機・オムロンは全社で7%台。**流通経路とファブレスかどうかの差**である
4. **中国の国産化が数字に出た**。汇川技術が小型PLCで9%→15%、ACサーボで26%→37%
   （2025年Q4→2026年Q2、調査・報道ベース）。同期間に三菱電機のシェアは低下したと報じられる
5. **競争軸がハードからソフトへ**。シーメンスは2026年度Q2の受注＋18%、上半期のデジタル事業＋19%。
   機器単体の性能競争から、設計〜運用の環境を握る競争へ移りつつある

| HMI | 作業者が設備の状態を確認し、指示を入力する画面や操作機器 |
| SCADA | 工場やインフラの設備を広域に監視し、データを収集・制御するシステム |
| SIer | 複数メーカーの機器を組み合わせ、顧客向けの自動化システムを構築する事業者 |
| KSF | Key Success Factorの略。業界で競争に勝つための重要な成功要因 |
