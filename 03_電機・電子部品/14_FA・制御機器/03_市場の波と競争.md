# 市場の波と競争（設備投資サイクル・中国・スマートファクトリー）

**このノートで分かること**：FA・制御機器の需要が**設備投資サイクルで上下する**理由と、その波の読み方
（NECA・JEMAの統計）。中国が最大市場になり**国産勢（汇川技術）が急伸している**構図。欧米勢との競争軸の違い。
そして「スマートファクトリー」「人手不足」という2つの追い風が、実際にどこまで数字になっているか。

結論を先に書く。**FA・制御機器は、設備投資の波に乗った部品産業である。**
ただしロボットや工作機械ほど振れ幅が極端ではない。理由は単純で、**FA機器は「新しい工場を建てるとき」だけでなく
「既存ラインの改造・更新」でも売れる**から。波はあるが、谷がゼロにはならない。
同じ波の中にいるロボット本体・SIerの話は
[産業用ロボット 市場の波と競争](../../02_自動車・機械/09_産業用ロボット/03_市場の波と競争.md) に委ね、
ここでは**制御機器側から見た市場**に絞る。

## 1. 需要はどこから来るのか：3層の顧客

FA機器の買い手は、最終ユーザーの工場だけではない。**3つの層に分かれている。**

```
  【層1】装置メーカー（工作機械・半導体装置・包装機・食品機械・電池装置）← 最大の買い手
       │ 自社の機械にPLC・サーボ・センサを組み込んで出荷する
       │ 「組込み需要」。点数が多く、量産が続くと継続発注になる
       ▼
  【層2】制御盤メーカー・SIer・エンジニアリング会社
       │ 盤を設計・製作し、ラインとして立ち上げる
       │ 「案件需要」。設計者がどのメーカーの型番で図面を描くかで決まる
       ▼
  【層3】エンドユーザー（自動車・電機電子・半導体・食品・医薬・物流倉庫）
       │ 「保全需要・更新需要」。故障交換、ライン改造、老朽更新
       └ 景気の谷でも止まらない。ここが下支えになる
```

| 層               | 需要の性格                   | 波の激しさ                       | 決め手                         |
| ---------------- | ---------------------------- | -------------------------------- | ------------------------------ |
| 装置メーカー     | 組込み（量産が続く限り継続） | 中（機種のライフサイクルに連動） | 設計段階での採用＝デザインイン |
| SIer・盤メーカー | 案件ごと                     | 大（設備投資に直結）             | 納期・入手性・設計者の慣れ     |
| エンドユーザー   | 保全・更新                   | 小（谷でも残る）                 | 部品の供給期間、互換性         |

> 重要な示唆：**層1（装置メーカー）で採用されると、その機種が売れ続ける限り自動的に売れる。**
> だからFA機器メーカーは最終ユーザーではなく**機械を設計している技術者**に営業をかける。SMCが
> 「設計者の図面に型番を書かせる」ことを重視するのはこの構造による（→ [儲け方](02_儲け方とビジネスモデルの違い.md)）。

## 3. 波はなぜ起きるのか：3つのサイクルの重なり

FA機器の受注は、性格の違う3つの波が重なって上下する。

```
   ① 半導体・電子部品サイクル（1〜2年周期・振れが最大）
      ∿∿∿∿∿∿∿∿∿∿∿∿   半導体の設備投資に直結。今（2026年）はAI需要で山
   ② 自動車の車種・工場サイクル（4〜6年周期・1回が巨額）
      ‾‾‾＼＿＿＿／‾‾‾    EV転換で一度膨らみ、その後調整。欧州は低迷
   ③ 更新・保全需要（周期なし・ほぼ一定）
      ────────────   10〜20年前に入れた機器の寿命。谷でも消えない
   合成すると： ∿‾∿＼_∿‾‾∿   ← 山谷はあるが、③のぶんゼロにはならない
```

ロボット本体（→ [産業用ロボット](../../02_自動車・機械/09_産業用ロボット/README.md)）が「工場を建てるときだけ売れる」のに対し、
FA機器は③の更新需要が厚い。**これがFA機器メーカーの業績のほうが相対的に安定している理由**である。

### 在庫調整という、もう一つの波

2021〜2022年の半導体不足期、FA機器は納期が1年以上に伸びた。すると顧客と代理店は
**実際に必要な量より多く発注する**（二重発注・押さえ発注）。供給が正常化した2023〜2024年、
この水増し分が一斉に消え、**実需は落ちていないのに受注だけが急減する**局面が起きた。

> これは**ブルウィップ効果**（実需の小さな変動が流通段階を遡るごとに増幅される現象）の典型例で、
> 代理店流通が厚いFA業界の構造的な弱点である。オムロンが2024年2月に構造改革「NEXT 2025」を
> 発表したのは、この調整局面が長引いたことが背景にある。

## 4. 中国：最大市場であり、最大の競争相手

FA機器の最大市場は中国である。そして**そこで国産勢が急速にシェアを取っている**。

### 汇川技術（Inovance）の台頭

深圳の汇川技術は、インバータから始まりサーボ・PLC・ロボットへ展開した中国のFA最大手。

| 指標                             | 数値                                 | 時点・性格               |
| -------------------------------- | ------------------------------------ | ------------------------ |
| 中国国内のサーボシステムシェア   | **32%で首位**                        | 2025年、調査・報道ベース |
| 小型PLCの中国シェア              | 9%（2025年Q4）→ **15%**（2026年Q2）  | 調査・報道ベース         |
| ACサーボドライブの中国シェア     | 26%（2025年Q4）→ **37%**（2026年Q2） | 調査・報道ベース         |
| （比較）三菱電機の小型PLCシェア  | 12% → **7%**                         | 同期間、調査・報道ベース |
| （比較）三菱電機のACサーボシェア | 6% → **3%**                          | 同期間、調査・報道ベース |
| 香港上場                         | H株発行・香港上場の計画を発表        | 2026年、報道ベース       |

※これらのシェアは第三者調査会社の推計を報じたもので**各社の公表値ではない**。四半期単位のシェアは振れが大きく、方向感を見る材料である。

```
   中国国産化が進んだ3つの理由

   ① 納期  半導体不足期、外資は納期1年。国産は数週間 → 「試しに使った」工場が定着
   ② 価格  同等スペックで3〜5割安いとされる
   ③ 政策  「中国製造2025」以来の国産化推進。補助と調達優遇
     → 低〜中価格帯は国産、高精度・高信頼領域はまだ外資という二層化
     → ただし境界線は毎年上へ動いている  ← ここが日本勢の懸念
```

同じ構図はロボット本体でも起きている（Estunの台頭）が、**制御機器のほうが国産化の進みが速い**。
ロボットが減速機という高い参入障壁を持つ部品に依存するのに対し、**PLCやインバータは部品の調達障壁が低い**ためである。

> 日本勢にとっての本当の脅威は中国市場を失うことよりも、**中国製の装置に中国製の制御機器が載ったまま
> 東南アジア・インド・中東へ輸出されること**。装置メーカー経由の組込み需要（層1）が、まとめて置き換わる経路になる。

## 5. 欧米勢：シーメンスとロックウェル

| 企業                                     | 立ち位置                                         | 競争の軸                                                                                                        |
| ---------------------------------------- | ------------------------------------------------ | --------------------------------------------------------------------------------------------------------------- |
| **シーメンス**（独）                     | PLC世界首位（SIMATIC）。PROFINETの主導者         | **ソフトウェアとの抱き合わせ**。設計ソフト（NX）からシミュレーション、MES、クラウド（Xcelerator）まで垂直に持つ |
| **ロックウェル・オートメーション**（米） | 北米で圧倒的。Allen-Bradleyブランド、EtherNet/IP | 北米の自動車・食品・飲料に深く入り込む。規格と商習慣で守られている                                              |
| **シュナイダーエレクトリック**（仏）     | 配電とFAの両方。Pro-faceの表示器                 | エネルギー管理との組み合わせ                                                                                    |
| **ABB**（スイス／スウェーデン）          | インバータ・モータ・ロボット                     | 重電とFAの中間                                                                                                  |

シーメンスの2026年度第2四半期（2026年1〜3月）は売上198億ユーロ（＋6%）、受注241億ユーロ
（比較可能ベース＋18%）、ブック・トゥ・ビル1.22。上半期のデジタル事業は＋19%と報じられている。

```
   日本勢と欧米勢の戦い方の違い

   日本勢（三菱電機・オムロン・キーエンス・安川）＝ ハードウェアが主語
     「機器の性能と信頼性」で勝つ：センサの分解能、サーボの応答、故障しないこと

   シーメンス ＝ ソフトウェアが主語
     「設計から運用までの一貫したソフト環境」で勝つ
      設計データがそのままシミュレーションと生産計画につながり、
      機器は「その環境で動く部品」として売られる
     → ここが2020年代のFA競争の本丸。機器単体の性能競争ではなくなりつつある
```

日本勢も三菱電機の **e-F@ctory**、オムロンの **i-Automation**、安川電機の **i³-Mechatronics** で対応しているが、
**設計CADから生産管理まで垂直に持つのはシーメンスとダッソー（仏）に限られる**ため、提携とオープン化での対抗になっている。

## 6. スマートファクトリーとデータ活用：どこまで実体があるか

「工場のデータを集めて活用する」という話は2010年代半ば（インダストリー4.0、IoT）から続くが、**定着度には強い濃淡がある**。

| 段階                             | やっていること                                     | 普及度（2026年時点の感覚値）                   |
| -------------------------------- | -------------------------------------------------- | ---------------------------------------------- |
| **見える化**                     | 設備の稼働・停止・サイクルタイムを収集して表示する | 大手工場ではかなり普及                         |
| **異常検知・予兆保全**           | 電流値・振動・温度から故障の予兆を掴む             | 導入は進むが、重要設備に限定されがち           |
| **品質のトレーサビリティ**       | どのロットをどの条件で作ったか記録する             | 自動車・医薬・食品では義務に近い               |
| **自動での条件最適化**           | AIが加工条件を自動で書き換える                     | **実運用はまだ限定的**。止まるリスクを取れない |
| **仮想試運転（デジタルツイン）** | 実機の前にPC上でラインを動かして検証する           | 装置メーカーで採用が進行中                     |

普及を阻んでいるのは技術ではなく**現場の事情**である。①**止まるリスクを取れない**（制御をAIに委ねて生産が止まれば損失が直撃）、
②**既存設備が古い**（20年前の設備にはデータを出す口がない）、③**規格が割れている**（データを1か所に集める工数が重い）、
④**誰がやるのか問題**（IT部門は現場を知らず、現場はITを知らない）。

> だからこそ **OPC UA**（メーカーを越えて意味付きデータを渡す共通規格）と **TSN**（標準イーサネットで時刻同期・
> 遅延保証を行う技術）の組み合わせが業界横断の解として推進されている。ただし**2026年時点でも置き換えは限定的**で、
> 既存の各社規格と長く併存する見込み（仕組みは [機器の構成](01_FAとは何か・機器の構成.md) を参照）。
> 一方、実務で静かに普及しているのが **IO-Link**。センサ1個ごとに双方向通信でき、
> **「どのセンサが汚れて感度が落ちてきたか」が分かる**ため投資対効果が明快である。

## 7. 人手不足という構造的な追い風

FA機器の需要を長期で支えているのは景気ではなく**労働力人口の減少**である。

| 現象               | FA需要への影響                                                           |
| ------------------ | ------------------------------------------------------------------------ |
| 生産年齢人口の減少 | 人でやっていた検査・搬送・段取りを機械に置き換える必要が出る             |
| 賃金上昇           | 自動化の投資回収年数が短くなる。**人件費が上がるほど自動化が有利になる** |
| 保全人材の高齢化   | ラダーが読める技術者が減り、**より簡単に扱える機器**への需要が生まれる   |
| 多品種少量化       | 段取り替えを自動化する需要。サーボ・画像処理が効く領域                   |

政策としては**中小企業省力化投資補助金**が代表的で、登録済み汎用製品から選ぶ「カタログ注文型」と個別の設備導入を
支援する「一般型」の2類型がある（金額・時期は [直近トピック 2026](04_直近トピック_2026.md) を参照）。

> カタログ注文型が作られた理由が、この業界の核心を突いている。
> **中小企業の自動化が進まない最大の理由は機器の値段ではなく、設計と立ち上げの工数（SIerの人月）**である。
> 「選ぶだけで済む」形にして工数をゼロに近づけるのがこの制度の狙いで、「補助金＝値引き」ではない
> （→ [システムインテグレーション](../../02_自動車・機械/09_産業用ロボット/02_システムインテグレーション.md)）。

## 8. 競争の勝ち筋はどこにあるか

以上を踏まえると、勝ち続けるための条件は次の5つに整理できる。

1. **装置メーカーの設計段階に食い込む**（デザインイン）。最終ユーザーへの営業より効率が高い
2. **納期と入手性**。半導体不足期に中国勢が伸びたのは価格ではなく納期だった
3. **部品の長期供給と互換性**。10〜20年後の更新需要を自社に引き寄せる
4. **エンジニアリング工数を減らす**（設定の簡単さ、ライブラリ、仮想試運転）。**機器の値段より導入工数のほうが大きい**以上、ここが最大の差別化余地
5. **上位（MES・クラウド）へのつなぎ方**。シーメンスが仕掛けている土俵。機器を売る会社からソフト込みで売る会社へ移れるか

> 進路は2つに分かれる。**(A) 部品として強くなる**（キーエンス型。比較されない製品を出し続ける。高粗利だが
> 毎回勝ち続ける必要がある）か、**(B) 環境として囲い込む**（シーメンス型。設計〜運用のソフト環境を握る。
> 一度入れば長く効くが投資が重い）。日本の専業メーカーの多くは前者、三菱電機・オムロンが目指すのは後者である。
