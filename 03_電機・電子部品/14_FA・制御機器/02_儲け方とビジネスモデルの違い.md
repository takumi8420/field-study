# 儲け方とビジネスモデルの違い

**このノートで分かること**：同じ「FA・制御機器」に括られる三菱電機・オムロン・キーエンス・SMC・
ファナックが、**売り方も儲け方もまったく違う**という事実。とくに
**キーエンスの営業利益率50%超がなぜ成立するのか**を、ファブレス・直販・新製品比率・粗利設計という
4つの仕掛けに分解して説明する。

結論を先に書く。**FA業界の利益率の差は、技術力の差ではなく「流通経路の設計」の差である。**
同じ工場に、同じ現場に売っていても、
**代理店を通すか直販か／標準品の在庫を持つか受注生産か／自社工場を持つかファブレスか**で、
営業利益率は7%にも51%にもなる。

| 企業（2026年3月期・連結） | 売上高                           | 営業利益             | 営業利益率   | 売り方の骨格                   |
| ------------------------- | -------------------------------- | -------------------- | ------------ | ------------------------------ |
| **キーエンス**            | 1兆1,692億円（＋10.4%）          | 5,957億円（＋8.4%）  | **51.0%**    | 直販・ファブレス・当日出荷     |
| **SMC**                   | 8,425億円（＋6.4%）              | 1,906億円（＋0.2%）  | **22.6%**    | 標準品の超多品種在庫＋直販併用 |
| **ファナック**            | （FA・ロボット・ロボマシン合算） | ―                    | **21.4%**    | CNCの寡占＋保守網              |
| **三菱電機**（全社）      | 5兆8,947億円（＋6.8%）           | 4,330億円（＋10.5%） | 7.3%（全社） | 代理店流通＋総合電機の一部門   |
| **オムロン**（全社）      | 7,674億円（＋7.3%）              | 599億円（＋12.1%）   | 7.8%（全社） | 代理店流通＋構造改革途上       |

※出典：各社決算発表（2026年4〜5月）。ファナックの利益率は2026年3月期の全社営業利益率。
オムロンは電子部品事業の分社化により前年と範囲が異なる。三菱電機・オムロンはFA以外の事業を含む全社値であり、
**キーエンス・SMCと単純比較はできない**点に注意。それでも桁の違いは実態を表している。

## 1. まず理解すべき「2つの流通経路」

FA機器がユーザーに届くルートは、大きく2本しかない。**この選択が利益率の8割を決める。**

```
 【経路A：代理店流通】三菱電機・オムロン・富士電機・パナソニック など

  メーカー ──▶ 一次代理店（在庫・与信）──▶ 二次代理店/商社 ──▶ 装置メーカー・SIer ──▶ 工場
    └─ メーカーの仕事は「部品を出荷するところまで」
       → 販管費は軽いが、値引き要求は代理店経由で常に来る
       → 現場が何に困っているかの情報が薄まって届く

 【経路B：直販】キーエンス・（SMCは併用）

  メーカー営業 ──────────────────────────▶ 工場の生産技術者
    └─ 営業が現場に立ち、課題を聞き、その場で提案し、翌日納品する
       → 販管費は重い（人件費が高い）が、値決めの主導権を握れる
       → 「何に困っているか」が一次情報でそのまま開発へ戻る
```

> ここが最大の分かれ目：**代理店を使うと、値決めの主導権が自分の手を離れる。**
> 代理店は複数メーカーを扱うので、同等品があれば価格で比較される。
> 直販は一社の製品しか提案しないので、**「この課題をいくらで解決するか」という会話**になる。
> 同じ品質の製品でも、後者のほうが高く売れる。

## 2. キーエンスの営業利益率51%はなぜ成立するのか

2026年3月期のキーエンスは売上高1兆1,692億円、営業利益5,957億円、**営業利益率51.0%**、
粗利率は約83%（同期決算短信ベース）。
製造業としては異常値に見えるが、これは偶然ではなく**4つの仕掛けが噛み合った結果**である。

```
   ┌──────────────────────────────────────────────────────────┐
   │ ①ファブレス  自社工場を持たない → 固定費と減価償却が乗らない  │
   │ ②直販      代理店マージンが乗らない＋値決めの主導権を握る    │
   │ ③新製品比率  「世界初・業界初」を出し続け、比較対象を作らせない │
   │ ④粗利設計   原価ではなく「顧客が得する額」から値段を決める    │
   │      ↓                                                     │
   │   粗利率 約83%（2026年3月期） − 販管費率 約32% ＝ 営業利益率 51.0% │
   └──────────────────────────────────────────────────────────┘
```

### ① ファブレス：工場を持たないから、稼働率に殺されない

キーエンスは製品の企画・開発・設計を自社で行い、**製造はほぼ全量を外部の協力工場に委託**している
（グループ内に生産機能はあるが、量産工場を自社で大きく抱えない構造）。効果は2段階ある。

1. **固定費が軽い**。設備の減価償却がほぼ乗らないので損益分岐点が低いまま。FA業界の宿命である設備投資サイクルの谷で、**他社が赤字になる局面でも黒字が残る**
2. **開発リソースを製品企画に集中できる**。工場の稼働率を埋めるための製品開発が不要になる

同じFAでもファナック（大規模な量産工場を持ち、垂直統合で原価を下げる）とは**正反対の思想**である。
どちらが正しいという話ではなく、**利益率の出方が構造的に違う**。

### ② 直販：営業が「販売員」ではなく「コンサルタント」として機能する

キーエンスの営業は代理店を介さず、直接工場の生産技術者・設備担当者を訪問する。
そこで行われているのは値引き交渉ではなく、**「この工程のこの不良を、この製品でこう潰せる」という提案**である。

| 直販が生む効果           | 中身                                                                                           |
| ------------------------ | ---------------------------------------------------------------------------------------------- |
| **中間マージンが消える** | 代理店分の利益が自社に残る。粗利率が10〜20ポイント変わる                                       |
| **値決めの主導権**       | 比較見積もりの土俵に乗らない。「課題解決の価値」で値段が決まる                                 |
| **一次情報が開発に直結** | 「こういう検査ができない」という声が、そのまま次の新製品の仕様になる                           |
| **当日出荷・即納体制**   | 標準品を大量在庫し、原則当日出荷。ラインが止まっている顧客にとって**価格より速さが価値**になる |

> ポイント：**「困っている工場は、値段を気にしない」**。
> ラインが1時間止まれば数百万円が飛ぶ現場にとって、センサが3万円か8万円かは論点にならない。
> 直販の営業はこの「止まっている時間の価値」を会話の軸に置いている。

### ③ 新製品比率：比較されない製品を出し続ける

キーエンスは新製品のうち**7割程度が「世界初・業界初」**であると自社で説明している。
この方針が効くのは、**比較対象が存在しない製品は値引きの根拠を持たない**からである。

```
   一般的なFA部品                      キーエンスの新製品
   ──────────────                    ──────────────────
   同等品が3社から出ている              「これしかない」機能で出す
        ↓                                   ↓
   カタログスペックの比較                 何と比較すればいいか分からない
        ↓                                   ↓
   価格勝負・相見積もり                   「導入して何がいくら改善するか」の勝負
        ↓                                   ↓
   粗利 30〜40%                          粗利 80%超
```

もう一つ重要なのは、**新製品の企画が営業現場から生まれる**点。
直販で得た「現場の困りごと」が商品企画に直結しているため、
**「作ったが売れない」という在庫リスクが構造的に小さい**。①②③は独立ではなく循環している。

### ④ 粗利設計：原価から値段を積み上げない

多くの部品メーカーは「原価＋利益」で値段を決める（コストプラス）。
キーエンスは**「その製品を入れると顧客はいくら得をするか」から値段を決める**
（バリュープライシング）と説明される。

例えば検査工程に人が2人張り付いていて画像処理装置1台で1人分が浮くなら、年間の人件費相当分が顧客の得る価値になる。
そこから逆算して値段を置けば、**製造原価が10万円の装置を60万円で売っても顧客は合理的に買う**。

> 誤解しやすい点：**「高く売っている」のではなく「安く作って高い価値を渡している」**。
> ファブレスで原価を抑え、直販で価値を伝え、新製品で比較を回避し、
> バリュープライシングで値段を置く。**4つが揃わないとこの利益率は再現できない。**

### 再現しにくい理由（＝参入障壁）

他社がキーエンスを模倣しようとしても、難しい理由が3つある。

1. **直販は営業人員を大量に抱えるモデル**で、先に販管費が立つ。利益率の低い既存事業を抱えたまま切り替えると一時的に大赤字になる
2. **代理店を切ると既存の販路と関係が壊れる**。長年の流通網を持つ総合メーカーほど、後戻りできないコストが大きい
3. **「即納」を支えるのは巨大な在庫と物流**。ファブレスなのに在庫を厚く持つのは矛盾に見えるが、**在庫コストを払って納期価値を売る**という設計そのものが模倣対象である

## 3. ファナック：CNCの寡占＋垂直統合という、別の高収益モデル

ファナックは直販でもファブレスでもない。むしろ**正反対の「作り込み型」**で高収益を出している。

| 仕掛け                 | 中身                                                                                          |
| ---------------------- | --------------------------------------------------------------------------------------------- |
| **CNCの圧倒的シェア**  | 工作機械の頭脳であるCNC（数値制御装置）で世界シェア約50%、国内約70%とされる                   |
| **乗り換えが起きない** | 工作機械ユーザーは操作画面とプログラムに慣れている。機械を買い替えてもCNCは同じメーカーを選ぶ |
| **垂直統合と量産**     | サーボモータ・アンプも自社製。山梨の集約生産で原価を下げる                                    |
| **保守・サービス**     | 世界中に稼働している装置の保守収入が、設備投資の谷でも下支えする                              |
| **超保守的な財務**     | 自己資本比率89.2%（2026年3月期）。谷でも耐えられる体力                                        |

2026年3月期の全社営業利益率は**21.4%**（前期19.9%）、純利益1,665億円（＋12.9%）。
牽引したのは中国のEV関連・一般産業向けロボットと、工作機械向けCNC需要である。

> キーエンスとの対比：**キーエンスは「比較されない製品」で高粗利を作り、
> ファナックは「乗り換えられない地位」で高利益率を作っている。**
> 前者は製品ごとに毎回勝ち続ける必要があり、後者は一度取った標準の座が長く効く。

## 4. SMC：標準品の「超多品種・即納」という第三のモデル

SMCは空気圧機器（シリンダ・電磁弁・エアフィルタなど）の世界最大手で、
自社公表値で**世界シェア約36%、国内約62%**。
2026年3月期は売上高8,425億円（＋6.4%）、営業利益1,906億円（＋0.2%）、**営業利益率22.6%**。

```
   SMCのモデル ＝「規格品を、途方もない種類だけ、すぐ出す」

   製品バリエーション：70万点超と言われる（公表ベース）
     → 装置メーカーは「ちょうどいいサイズ」が必ず見つかる
     → 設計者は最初にSMCの型番で図面を描く        ← ここが決定的
     → その装置が量産されるかぎり、同じ型番が発注され続ける
     → 設計段階で入り込む＝「指定されたら替えられない」
```

**設計段階で型番が図面に書かれてしまえば、あとは自動的に売れる。**
これは半導体や電子部品の「デザインイン」と同じ構造である
（→ [電子部品](../05_電子部品/README.md)）。
価格競争の土俵に上がる前に、設計の土俵で勝負が付いている。

一方で弱点も構造的で、**装置メーカーの設備投資が止まると即座に受注が落ちる**。
2026年3月期に増収なのに営業利益がほぼ横ばい（＋0.2%）だったのも、
売価より先に人件費・材料費が上がる局面では利益が圧縮されるためである。

## 5. 三菱電機・オムロン：総合メーカーの中のFA

三菱電機とオムロンは、上の3社とは立ち位置が違う。
**幅広い品目を代理店経由で売る「総合型」**であり、利益率は単体では出にくい。

| 企業         | FAでの位置                                                                         | 2026年3月期の状況                                                                                                                                                                      |
| ------------ | ---------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **三菱電機** | シーケンサ（MELSEC）国内首位。サーボ・インバータ・表示器・放電加工機までフルライン | 全社売上5兆8,947億円（＋6.8%）、営業利益4,330億円（＋10.5%）、純利益4,077億円（＋25.8%）で**4期連続の最高益**。データセンター需要とFAの回復が牽引                                      |
| **オムロン** | センサ・リレー・スイッチ・PLC・セーフティ。制御機器（IAB）が主力                   | 全社売上7,674億円（＋7.3%）、営業利益599億円（＋12.1%）、純利益285億円（＋75.1%）。構造改革「NEXT 2025」（2024年2月発表、国内外約2,000人の人員削減を含む）を経て制御機器事業が回復基調 |

総合型の経済的な特徴は次のとおり。

- **強み**：ラインをまるごと1社で揃えられる。PLCからサーボ、表示器、ネットワークまで同一メーカーで組めば、設計工数と不具合の切り分け工数が劇的に減る。**CC-Link IE（三菱）のような自社ネットワークがこの束ね役**になる
- **弱み**：品目ごとに専業の強豪がいる。センサではキーエンス、サーボでは安川、空圧ではSMC。**「全部そこそこ」が価格で押される**
- **代理店依存**：流通が厚いぶん現場の一次情報が届きにくく、新製品の企画が「現場発」になりにくい

> オムロンの構造改革はこの弱点が露呈した例として読むと分かりやすい。
> 2021〜2022年の半導体不足期に顧客が二重発注し、その反動で2023〜2024年に在庫調整が長引いた。
> **代理店流通では「実需」と「発注」の区別が付きにくく、需要の山谷が増幅される**という
> 経路Aの弱点がそのまま業績に出た形である。

## 6. 5社を1枚の表で比べる

| 企業           | 売り方                     | 作り方                 | 何で差別化するか                   | 弱点                                   |
| -------------- | -------------------------- | ---------------------- | ---------------------------------- | -------------------------------------- |
| **キーエンス** | 直販（コンサル営業）       | ファブレス             | 世界初・業界初の新製品と即納       | 営業人員に依存。景気の谷で販管費が重い |
| **ファナック** | 直販＋工作機械メーカー経由 | 垂直統合・大量生産     | CNCの標準の座と保守網              | 設備投資サイクルに直撃される           |
| **SMC**        | 代理店＋直販の併用         | 自社生産（多品種）     | 品種数と即納、設計段階での型番指定 | 装置メーカーの投資に連動               |
| **三菱電機**   | 代理店                     | 自社生産（フルライン） | ライン全体を1社で揃えられる        | 品目ごとに専業に押される               |
| **オムロン**   | 代理店                     | 自社生産＋外注         | センサ・セーフティの品揃え         | 需要変動の増幅を受けやすい             |
| **安川電機**   | 代理店＋装置メーカー直     | 自社生産               | サーボ・インバータの性能           | ロボット事業と合わせて波が大きい       |

> 並べ直すと軸は一本しかない。**直販・課題解決型に寄るほど利益率が高く、
> 代理店・部品供給型に寄るほど低い**（キーエンス51% → SMC22.6%・ファナック21.4% →
> 三菱電機・オムロンは全社で7%台）。ただし後者2社はFA以外を含む全社値で、FA単体はこれより高い。

## 7. 保守・更新という、見えにくい収益源

FA機器は10〜20年使われる。そのため**販売後の収益**が各社の業績を静かに支えている。

| 収益の種類                               | 中身                                                                           |
| ---------------------------------------- | ------------------------------------------------------------------------------ |
| **補修部品**                             | 故障したサーボアンプ・PLCユニットの交換。粗利が高い                            |
| **生産中止への対応**                     | PLCの世代交代時に、旧型番の後継品や変換アダプタを売る                          |
| **リプレース案件**                       | 20年前のシーケンサが生産終了になり、ラインごと更新する。**数千万円規模になる** |
| **ソフトウェア・エンジニアリングツール** | プログラム開発環境の年間ライセンス。近年比率が上がっている                     |

> この「生産中止 → 更新需要」のサイクルは**FA業界にとっての定期収入に近い**。
> 各社が部品の供給期間を長く保証するのは、**数十年後の更新案件を囲い込むための投資**でもある。

## 用語メモ

| 用語                       | 意味                                                                                                          |
| -------------------------- | ------------------------------------------------------------------------------------------------------------- |
| **ファブレス**             | 自社で量産工場を持たず、設計・企画に特化して製造を外部委託する形態                                            |
| **直販**                   | 代理店を挟まず、メーカーの営業が直接ユーザーに売る方式                                                        |
| **代理店流通**             | 一次・二次代理店を経由してユーザーに届ける方式。在庫と与信を代理店が担う                                      |
| **粗利率（売上総利益率）** | (売上−売上原価)÷売上。製造の効率と値決めの強さが出る                                                          |
| **販管費率**               | 販売費および一般管理費÷売上。直販モデルは営業人件費でここが厚くなる                                           |
| **バリュープライシング**   | 原価ではなく顧客が得る価値から値段を決める方式（対義語はコストプラス＝原価＋利益）                            |
| **デザインイン**           | 顧客の設計段階で自社型番を図面に入れてもらうこと。量産が続く限り発注が続く                                    |
| **当日出荷／即納**         | 標準品を在庫し、注文当日に出荷する体制。ラインが止まっている顧客への価値                                      |
| **新製品比率**             | 直近数年に投入した製品が売上に占める割合。キーエンスの説明では新製品の約7割が世界初・業界初とされる           |
| **NEXT 2025**              | オムロンが2024年2月に発表した構造改革プログラム。国内外約2,000人の人員削減を含む                              |
| **ブルウィップ効果**       | 実需の小さな変動が流通段階を遡るごとに増幅される現象。代理店流通の弱点                                        |
