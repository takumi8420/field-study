## 1. 富士フイルムHD、複合機事業（富士フイルムBI）の分離・上場を検討（2026年8月）

2026年8月6日、富士フイルムホールディングスが、複合機・プリンターとITソリューションを手がける
完全子会社・**富士フイルムビジネスイノベーション（旧・富士ゼロックス）の株式上場の検討開始**を発表した。

| 項目 | 内容 |
| --- | --- |
| 方式 | **パーシャル・スピンオフ**（親会社が一部持分を残して分離）を想定 |
| 富士フイルムHDの持分 | **20%弱**まで引き下げ。残りは同社株主へ分配 |
| 時期 | **2〜3年後**を視野 |
| 対象事業の規模 | 「ビジネスイノベーション」セグメント売上 **1兆1,748億円**（2026年3月期）、グループ売上3兆3,570億円の約**35%** |
| ブランド | 独立後も「富士フイルム」ブランドの使用は継続 |
| 親会社の狙い | ヘルスケア（バイオCDMO、医療機器）とエレクトロニクス（半導体材料）に資源集中 |

**この一件が示すもの**：グループ最大の売上セグメントであっても、
成長が見込めなければ資本を置いておけない、という判断が公に示された。
「儲かっているが縮む事業」の扱いとして、業界全体に効く前例になりうる。

> 写真フイルムの消失を多角化で乗り越えた会社が、
> その乗り換え先だった複合機をも手放そうとしている構図。
> 東洋経済はこれを「第3の創業」と位置づける報道を行っている（2026年8月）。

   └──────────────────────────┘

        ＝ 設置ベース（将来のカウンター収入の母数）が細っている

| 指標 | 数値 | 年・出典 |
| --- | --- | --- |
| 事務機 出荷額 | 1兆7,376億5,800万円（▲9.5%） | 2025年、JBMIA 出荷実績（流通業界紙報道） |

**A3複合機の弱さが最も痛い**。A3機は単価が高く、カウンター保守が必ず付き、印刷枚数も多い。
つまり**業界の利益率が最も高い層から先に縮んでいる**。

## 3. 米国の追加関税がコスト構造を直撃（2025〜2026年）

日本勢が世界シェアの大半を握る複合機は、生産拠点が中国・東南アジアに集中しているため、
米国の関税措置の影響を受けやすい。日経ビジネスは「**生産移転先にも高関税**」がかかる構図を報じている（2025年）。

| 会社 | 関税の影響として説明された内容 | 年・出典 |
| --- | --- | --- |
| **キヤノン** | 米国追加関税に加え、欧州・アジアの景気不透明感でレーザープリンターを中心に購入の先送り。プリンティング営業利益 2,574億円（**▲11.8%**） | 2025年12月期、キヤノン決算説明会（2026年1月29日） |
| **エプソン** | 米関税政策に端を発する商業印刷市場の投資先送りを踏まえ、米Fiery社で **259億円の減損** | 2026年5月、エプソン発表 |
| **リコー** | 2026年3月期は米関税の一過性影響を含む計画未達。営業利益900億円（関税影響を除くと約1,100億円）と説明 | 2026年、リコーIR（報道整理） |
| **富士フイルムBI** | 2026年9月1日より一部商品の価格改定を実施 | 2026年、同社発表 |

**関税は「値上げで転嫁できるか」の勝負になる**が、
カウンター保守契約は複数年の契約が多く、**すぐには単価を上げられない**。
ここが自動車などと違う痛みで、コスト増が契約期間中は利益を削り続ける。

## 4. 再編と提携 ― 単独で規模を維持できない

| 案件 | 内容 | 時期 |
| --- | --- | --- |
| **ゼロックス × レックスマーク** | ゼロックスが**15億ドル**（負債引受を含む）でレックスマークを買収完了。全主要プリント区分でトップ5、マネージドプリントサービスで首位と説明 | 2025年7月1日完了 |
| **富士フイルムBI × コニカミノルタ** | 複合機・プリンターの**原材料・部材調達で合弁会社を設立**。株主間協定は2024年7月締結、各国競争法審査により設立予定日を変更 | 2024年〜 |
| **富士フイルムHD → 富士フイルムBI** | 分離・上場の検討開始 | 2026年8月 |

```
  ────  再編の3つのパターン  ────

  ①水平統合（規模を足す）      ゼロックス × レックスマーク
       目的：MPSとサービス網の規模、販売チャネルの拡大

  ②機能提携（コストだけ割る）  富士フイルムBI × コニカミノルタ（調達合弁）
       目的：競合のまま、部材調達の規模の経済だけ共有

  ③切り離し（資本を移す）      富士フイルムHD → 富士フイルムBIの分離上場
       目的：成長事業へ資本を集中。縮む事業は独立採算へ
```

**②が特徴的**。製品では競合し続けたまま、調達だけ手を組む。
市場が縮んで1社あたりの購買量が落ちると、部材メーカーへの交渉力が失われるため、
**競合と組んででも量をまとめる**必要が出てきた、ということである。

## 5. リコー「中期経営戦略'26」― 本業の比率を自ら下げる計画（2026年3月）

2026年3月25日、リコーが2026〜2030年度を対象とする中期経営戦略を発表。

| 項目 | 内容 |
| --- | --- |
| 策定方式 | 3年周期の固定から、**5年先を見据えた毎年ローリング更新**へ変更 |
| 2030年度の営業利益 | **1,400億円以上**を「目線」として提示（確定目標ではなく参考値との位置づけ） |
| 目指す姿 | 「**ワークプレイスのインテグレーター**」＝オフィスに限らずデジタルでつながる働く場全体を統合する |
| ストック利益構成の計画 | オフィスプリンティング **59% → 42%**／ワークプレイスサービス **24% → 37%**／商用・産業印刷 **13% → 14%**（2025年度見通し→2030年度） |
| オフィスプリンティングの扱い | 成熟市場と認識。環境性能に優れたエンジンを競合にも供給するなどして「**事業縮小を微減にとどめる**」 |

短期の業績は好調で、2026年3月期は**純利益が前期比33%増**の見通しに上方修正された
（国内企業向けDX支援の需要拡大と研究開発費見直し等のコスト削減が要因、2026年2月、日本経済新聞）。

> **読み方**：業績が良いときに本業比率を下げる計画を出したところが重要。
> 本業が崩れてから動くと買収資金も時間も足りない、という
> [③ 各社の転換](03_各社の転換.md) の第8章で述べた罠を避けにいっている。

## 6. コニカミノルタの黒字転換 ― 削って治した1年（2026年3月期）

| 指標 | 数値 |
| --- | --- |
| 売上高 | 約1兆877億円（前期比 **▲3.6%**） |
| 営業利益 | 約499億円（前期の大幅赤字から**黒字転換**） |
| 事業貢献利益 | 約532億円と大幅伸長 |
| プロフェッショナルプリント売上 | 2,551億円（**▲10.4%**） |
| 黒字化の要因 | グローバル構造改革による販管費率改善、減損損失の剥落、構造改革費用の剥落、子会社株式売却損益 |

（出典：コニカミノルタ 2026年3月期決算短信・決算説明会資料、2026年5月14日）

**売上は減ったのに利益は出た**。つまり売上成長ではなく、
**費用削減と事業売却で利益を作った**という構図である。縮小市場の企業に典型的な回復であり、
削り切ったあとに何を成長の柱として残すかが次の課題になる。

## 7. 全体の構図（まとめ）

1. **需要は戻っていない**。2025年の国内事務機出荷は金額▲9.5%、複合機台数▲12.4%。
   2026年も世界のプリンター出荷は前年割れが続き、**利益率が最も高いA3複合機から先に縮んでいる**
2. **短期の業績は悪くない**。リコーは増益、コニカミノルタは黒字転換、キヤノンは過去最高売上。
   ただしそれは**値上げ・コスト削減・事業売却で作った利益**であって、枚数が戻ったからではない
3. **関税が上乗せされた**。生産拠点が中国・東南アジアにあるため米関税の影響が大きく、
   複数年のカウンター契約ゆえに**値上げで即座に転嫁できない**
4. **再編は「統合・提携・切り離し」の3方向で進行中**。
   とくに富士フイルムHDによる富士フイルムBIの分離上場検討（2026年8月）は、
   「儲かっているが縮む事業」の扱いを公に示した点で象徴的
5. **各社の本質的な課題は同じ**。カウンター保守という優秀すぎた収益モデルの代わりに、
   何を継続課金の柱に据えるか。リコーはITサービス、キヤノンはメディカルと半導体、
   コニカミノルタは計測とヘルスケア、エプソンはインクジェットの商業・産業印刷に賭けている

> **一文でいうと**：本体を安く入れて紙1枚ごとに課金するモデルは、
> オフィスが紙を使い続ける限り最強だった。その前提が消えたいま、
> 業界は「何で継続的に課金するか」をゼロから作り直している最中にある。

## 8. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **パーシャル・スピンオフ** | 親会社が一部株式を残したまま子会社を分離・上場させる手法 |
| **ページボリューム** | 市場全体の印刷枚数。複合機業界の需要そのもの |
| **設置ベース** | 稼働中の自社機の総数。将来のカウンター収入の母数 |
| **MPS** | マネージドプリントサービス。出力環境を一括で請け負う契約 |
| **構造改革費用の剥落** | 前年に計上した一時費用が今年は発生しないこと。増益要因になる |
| **一過性影響** | 関税・減損など、その期限りの損益要因 |
| **DFE** | デジタルフロントエンド。印刷機を制御するソフト／コントローラー（Fieryなど） |
