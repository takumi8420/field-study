事務機器・複合機

学習済み更新 2026-09-20電機・電子部品
あこのページの単語集用語に触れると意味を確認できます14語
MFP／複合機カウンター保守契約クリック課金ジレットモデルノンハード売上設置ベース（インストールベース）ページボリュームMPS電子写真方式（ゼログラフィ）感光体ドラム／定着ヒートフリープロダクションプリントパーシャル・スピンオフJBMIA

この業界を一言で：オフィスにコピー機（複合機）を置き、刷られた紙1枚ごとに課金して稼ぐ産業。
本体では稼がず、トナーと保守を込みにした「カウンター料金」で回収する仕組みが、
40年にわたって極めて安定した現金を生み続けてきた。

問題は、その収益の分母が「オフィスで印刷される枚数」だったこと。
ペーパーレス化とリモートワークで分母が縮み始めた瞬間、
儲けの仕組みが優秀すぎたがゆえに、需要減がそのまま売上減へ直結する構造が露呈した。
このフォルダはその一点を軸に構成している。

このフォルダの読み方

ノート 内容
① 複合機ビジネスの仕組み本体で稼がずトナー・保守で稼ぐジレットモデル、カウンター保守契約という日本独特の商習慣、リースとの二階建て、1枚あたりの経済、販売チャネル、電子写真方式の原理
② 市場の構造的縮小「売れない」のではなく「刷られない」。ペーパーレス・リモートワークの効き方、JBMIA／IDCの数値、新興国と先進国の差、互換トナーと中古機、主要プレイヤーの構図
③ 各社の転換逃げ道は3つ（オフィスサービス／商業・産業印刷／別事業）。リコー・キヤノン・富士フイルムBI・コニカミノルタ・エプソンの選択と、転換が遅れる理由
④ 直近トピック 20262026年9月時点。富士フイルムBIの分離上場検討、出荷減の継続、米関税、ゼロックス×レックスマーク、リコー中期経営戦略'26

1. 業界の定義・範囲

事務機器とは、オフィスで文書を扱うための機械の総称。
中心は複合機（MFP：Multi Function Peripheral）、すなわちコピー・プリント・スキャン・FAXを
1台にまとめた機械である。ほかにプリンター、シュレッダー、ラベルプリンター、
プロジェクター、POSレジなども広義の事務機に含まれる。

隣接業界との境界は次のとおり。

業界 違い
PC・スマートフォン同じオフィス機器だが、消耗品課金がなく買い切り。HPのように両方やる会社もある
印刷印刷をサービスとして請け負う側。複合機メーカーは印刷会社に機械を売る立場
総合電機事業ポートフォリオの一部として事務機を持つ場合がある（シャープ、東芝テック）
計測・分析機器光学・画像技術が近く、複合機メーカーの転換先になっている
医療機器キヤノン・コニカミノルタ・富士フイルムの転換先。画像処理技術が共通
SIer・ITサービスリコー等が参入した領域。既存の複合機顧客に売る
リース複合機の販売はほぼリースとセット。金融側の当事者

この業界の特殊性は、機械メーカーでありながら収益の実態が従量課金サービス業である点にある。
そのため「製造業」の型だけでは読み解けず、設置ベース（稼働台数）×枚数×単価という
ストックビジネスの型を重ねて見る必要がある。→ ① 仕組み

4. 主要プレイヤーとシェア

A3複合機の世界市場は日本勢がほぼ独占という珍しい構図。
シェアは公的統計がなく、販売会社サイトが四季報オンライン等を引用した目安の数値である。

リコー2位約16%オフィスサービス（中小企業向けIT・DX支援）への転換が最も鮮明

寡占なのに儲からないのがこの業界の現在地。
シェアを取っても市場そのものが縮んでいるため、競争の焦点は
「シェア争い」から「どこへ逃げるか」へ移った。→ ③ 各社の転換

5. 収益モデル・コスト構造

売上 ＝ ①本体販売（薄利。値引きの原資は将来のカウンター収入）
      ＋ ②カウンター料金＝設置台数 × 1台あたり印刷枚数 × 単価  ← 利益の本体
      ＋ ③消耗品・部品販売（保守契約外の機種）
      ＋ ④ITサービス・MPS（成長させたい領域）
      － 変動費（トナー・部品）
      － 準固定費（保守員の人件費・訪問コスト）  ← 枚数ほどは減らない
      － 固定費（工場・開発・販売網）            ← まったく減らない
収益源 性格 利益率のイメージ
本体販売競争が激しく値引き前提薄い。赤字で入れることもある
カウンター料金（保守・消耗品）設置後5〜7年、毎月発生厚い。売上構成で6〜7割を占めるとされる
プロダクションプリント単価が大きく、印刷会社の設備投資に連動中。景気変動が大きい
ITサービス・MPS人月とソフトが混ざる薄〜中。だが成長する

コスト側の要点は、保守員の人件費が準固定費であること。
訪問1回のコストは枚数に関係なくほぼ一定なので、
1台あたりの枚数が減ると1枚あたりの保守原価が跳ね上がる。
売上が減るスピードよりコストが減るスピードが遅く、利益率が先に崩れる。
→ ② 市場の構造的縮小

6. 競争要因（KSF）と参入障壁

┌────────────────────────────────┐
│ ①機械を作る（光学＋化学＋精密機構＋ソフトのすり合わせ）  │ 水平分業が起きにくい層
├────────────────────────────────┤
│ ②売って入れる（提案力・リース・値引きの体力）            │
├────────────────────────────────┤
│ ③止めない（全国の保守員・部品在庫・遠隔監視）            │ ← 最大の障壁だった層
└────────────────────────────────┘
                    ↓ 枚数が減ると…
         ③が「障壁」から「固定費」へ反転する
KSF なぜ効くか
消耗品の内製トナー・感光体を自社で作れると、消耗品利益を他社に取られない
保守サービス網「止まらない」ことに金が払われる。30分で駆けつける体制は一朝一夕に作れない
すり合わせ開発力光学・化学・機構・ソフトが絡み、部品を買い集めても作れない
設置ベースの大きさ将来のカウンター収入の母数。台数シェアに各社が執着する理由
省エネ・環境性能定着の消費電力が大きいため、省エネ規制と電気代が選定基準になる
セキュリティ複合機はハードディスクを持つネットワーク機器。官公庁調達では必須要件
リースを含む提案力顧客は本体価格でなく月額総額で判断する

7. 規制・法制度

分野 内容
省エネ法（トップランナー制度）複写機・プリンターはトップランナー基準の対象機器。消費電力性能が製品要件を規定する
国際エネルギースタープログラム日米等の省エネ基準。官公庁・大企業の調達条件になることが多い
グリーン購入法国等の機関が調達する際の環境配慮基準。複写機も対象品目
電子帳簿保存法・インボイス制度帳票の電子化を促し、結果として印刷需要を減らす制度。同時にITサービスの商機でもある
個人情報保護法・政府調達のセキュリティ要件複合機は内部にデータを保持するため、暗号化・上書き消去が要件化
資源有効利用促進法・廃棄物処理法使用済みトナーカートリッジ・機器の回収リサイクル義務
通商・関税米国の追加関税が中国・東南アジア生産分のコストを直撃（2025〜2026年）
競争法（各国）富士フイルムBI×コニカミノルタの調達合弁は各国審査で設立時期が変更された

8. 最近のトピック

詳細は ④ 直近トピック 2026。要点は次の5つ。

  1. 富士フイルムHDが富士フイルムBIの分離・上場を検討と発表（2026年8月）。
    グループ売上の約35%（1兆1,748億円）を占める最大セグメントを、
    パーシャル・スピンオフで持分20%弱まで下げて切り離す構想
  2. 出荷減は続いている。2025年のJBMIA統計で事務機出荷額▲9.5%、複合機台数▲12.4%。
    IDCによれば2026年も世界のプリンター出荷は前年割れで、A3複合機の落ち込みが顕著
  3. 米国の追加関税がコストを直撃。生産が中国・東南アジアに集中しており、
    複数年のカウンター契約ゆえにすぐ値上げで転嫁できないのが痛い
  4. 再編は3方向で進行。ゼロックスによるレックスマーク買収完了（2025年7月、15億ドル）、
    富士フイルムBI×コニカミノルタの調達合弁、富士フイルムBIの分離上場
  5. リコーが中期経営戦略'26を発表（2026年3月）。2030年度に向け、ストック利益に占める
    オフィスプリンティングの比率を59%→42%へ自ら下げ、ワークプレイスサービスを24%→37%へ
