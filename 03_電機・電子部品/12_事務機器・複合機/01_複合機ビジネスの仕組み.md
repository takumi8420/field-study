# 複合機ビジネスの仕組み

このノートで分かること：**なぜ複合機メーカーは本体を安く売るのか**、
そして「カウンター保守契約」という日本特有の商習慣が、どうやって
1枚のコピーを毎月の現金収入に変えているのか。

## 1. 結論：売っているのは機械ではなく「紙1枚」

複合機（コピー機）の商売を一言でいうと、**印刷した紙の枚数で課金する従量課金ビジネス**である。

- 本体（ハードウェア）は薄利、ときに赤字覚悟で入れる
- 入った機械が**1枚刷るたびに数円が入ってくる**
- その数円にトナー代・部品代・保守サービス代が全部含まれている

つまり「機械を置かせてもらう権利」を取りにいく商売であって、
機械を売る商売ではない。剃刀の本体を安く配って替刃で稼ぐのと同じ構造なので、
**ジレットモデル**（消耗品課金モデル）と呼ばれる。

> **ポイント**：この構造は「入れてしまえば10年近く自動的に金が入る」という意味で極めて優秀だった。
> しかし収入の母数が**印刷枚数**である以上、印刷枚数が減れば売上は自動的に減る。
> 優秀すぎる仕組みが、需要減にそのまま連動する仕組みでもあった。
> → [② 市場の構造的縮小](02_市場の構造的縮小.md)

## 2. 複合機（MFP）とは何か

**MFP** = Multi Function Peripheral（多機能周辺機器）。
コピー機・プリンター・スキャナー・FAXを1台に統合したもの。
1990年代までは「複写機（コピー機）」「レーザープリンター」「FAX」が別々の機械だったが、
内部のエンジン（印刷機構）が同じなので統合された。

| 区分 | 中身 | 用途 | 単価の目安 |
| --- | --- | --- | --- |
| **A3カラー複合機** | 大型。床置き。業界の主力 | オフィス、学校、自治体 | 本体定価100万〜300万円。実売は大幅値引き |
| **A4複合機・プリンター** | 小型。卓上 | 小規模オフィス、在宅 | 数万〜数十万円 |
| **プロダクションプリンター** | 商業印刷用の高速デジタル印刷機 | 印刷会社、DMや帳票の出力センター | 1,000万〜1億円 |
| **インクジェット（オフィス向け）** | レーザーでなくインクで刷る | 中小企業、エプソン・ブラザーが強い | 数万〜数十万円 |
| **産業用インクジェット** | 看板・サイン、捺染（布）、ラベル | 印刷・繊維・包装 | 数百万〜数億円 |

**A3機が業界の中心**なのは、単価が高く、印刷枚数が多く、保守契約が必ず付くから。
逆にいえば、業界の統計で「A3が弱い」と出たら、それは利益の中心が崩れているという意味になる。

## 3. お金の流れ：本体では稼がない

```
【メーカー】                【販売会社／OA商社】          【ユーザー企業】

 複合機を製造 ──────▶ 仕入れて提案・設置 ────▶ オフィスに1台設置
   原価が重い                                          │
                                                       │
      ▲                                                ▼
      │                                        ①リース料（月額固定）
      │                                          → リース会社へ
      │                                        ②カウンター料金（枚数×単価）
      └──── トナー・部品・保守員 ◀────────── → 販売会社／メーカーへ
             （ここが利益の本体）                ③紙は別途、ユーザー負担
```

- **①リース料**は原則メーカーの手には入らない。リース会社が機械代を立て替え、
  ユーザーが5〜7年で分割返済する形になる（→ [リース](../../05_金融/10_リース/README.md)）
- **②カウンター料金**がメーカーと販売会社の継続収入。トナー・感光体・修理・訪問が込み
- メーカー側の売上構成は、おおむね**ハード3〜4割・ノンハード（消耗品＋保守）6〜7割**とされる

## 4. カウンター保守契約 ― 日本独特の商習慣

「カウンター」とは機械内部の**印刷枚数カウンター**のこと。
毎月の検針値（または遠隔取得値）に単価を掛けて請求する。

| 保守契約の型 | 中身 | どこで使われるか |
| --- | --- | --- |
| **カウンター保守** | 枚数×単価。トナー・部品・修理・出張がすべて込み | 日本のA3複合機の事実上の標準 |
| **キット保守（トナーカートリッジ保守）** | トナー購入時に保守料を上乗せ。低枚数向け | 小規模オフィス、A4機 |
| **スポット保守** | 故障のたびに都度課金。トナーは実費購入 | 中古機、使用枚数が極端に少ない事業所 |
| **年間保守契約** | 年額固定。枚数に依存しない | 一部の海外市場、官公庁の一部 |
| **MPS（マネージドプリントサービス）** | 複数機種・複数拠点を一括で管理し、枚数と運用を丸ごと請け負う | 欧米大企業、日本の大手にも拡大 |

カウンター料金の相場（2026年時点、各種販売会社の公開情報ベース。実際は交渉と枚数で大きく変動）。

| 種別 | 1枚あたりの目安 |
| --- | --- |
| モノクロ | 約0.6〜3円 |
| カラー | 約6〜25円 |

幅が非常に広いのは、**枚数コミット（最低印刷枚数の約束）と値引きが連動する**ため。
月1万枚刷る事業所と月500枚の事業所では、同じ機械でも単価が桁で違う。

> **なぜカウンター保守が日本で定着したか**：
> ①ユーザーは「トナー切れ・故障で業務が止まる」リスクを月額に丸め込める、
> ②販売会社は毎月の安定収入が立つので営業が値引きしやすい、
> ③故障してもメーカー負担なので、メーカーに「壊れない機械を作る」動機が生まれる。
> 三者の利害が一致するため、40年以上も商習慣として残った。

## 5. ユーザーが払う月額の内訳（二階建て）

```
ユーザー企業が毎月払うもの
┌───────────────────────────────┐
│ ①リース料 15,000円/月（60回払い、機械代＋金利）   │ 固定費
├───────────────────────────────┤
│ ②カウンター料金                                   │ 変動費
│   モノクロ 5,000枚 × 1.0円 = 5,000円              │
│   カラー   1,000枚 × 10円  = 10,000円             │
├───────────────────────────────┤
│ ③用紙代（自社購入）                               │ 変動費
└───────────────────────────────┘
        合計 約30,000円/月 → 5年で約180万円
```

**ここが要点**。ユーザーは本体価格をほとんど見ていない。見ているのは月額総額である。
だから販売側は**本体を値引いてでも入れて、カウンターで回収する**。
本体値引きの原資はカウンター収入であり、値引きは「将来の枚数の前借り」に等しい。

逆にいうと、**入れたあとに枚数が想定より減ると、値引き分が回収できず赤字になる**。
これがペーパーレス時代に効いてくる。

## 6. 1枚あたりの経済 ― 何にいくらかかっているか

モノクロ1枚を1円で請け負ったとき、その1円の中身はおおむね次のように分解される
（公開されている正確な原価表はなく、業界慣行からの**概算イメージ**）。

| 費目 | 中身 | 性格 |
| --- | --- | --- |
| トナー・感光体・定着部材 | 消耗品の実費 | 変動費 |
| 交換部品・修理部品 | 一定枚数ごとに交換する部材 | 変動費（枚数比例） |
| 保守員の人件費・移動費 | 訪問サービス。**最大のコスト要因** | 準固定費 |
| 遠隔監視・受付センター | コールセンター、遠隔診断 | 固定費 |
| 販売会社の粗利 | 営業・回収・在庫 | ― |

**保守員の人件費が準固定費である**ことが決定的に重要。
訪問1回のコストは枚数に関係なくほぼ一定なので、
**1台あたりの印刷枚数が減ると、1枚あたりの保守原価が跳ね上がる**。
枚数が半分になっても訪問回数は半分にならない。ここが構造縮小の痛点になる。

## 7. 誰が売っているか ― 直販・代理店・OA商社

```
メーカー
  ├─ 直販部門（自社の販売会社）
  │     大企業・官公庁・全国チェーン向け。値引き権限が大きい
  │
  ├─ 系列ディーラー（地域の販売会社）
  │     地場の中堅・中小企業向け。保守員を自前で抱える
  │
  └─ 独立系OA商社・事務機販売店
        1社で複数メーカーを扱う。中古機・リース組み換えも手がける
        └─ 「リース満了の2年前から次の提案に来る」のがこの層の生業
```

| チャネル | 強み | 弱み |
| --- | --- | --- |
| **直販** | 大口を押さえられる。MPSやITサービスを乗せやすい | 固定費が重い。台数が減ると採算悪化 |
| **系列ディーラー** | 地域密着。保守の即応性が高い | 事業承継難。高齢化で統廃合が進む |
| **独立系OA商社** | 提案の自由度。価格競争力 | 保守品質がばらつく。メーカーの囲い込みが効きにくい |

この**保守員を抱えた販売・サービス網こそが、この業界最大の参入障壁**だった。
新規参入者は機械を作れても、全国に「30分で駆けつける人」を置けない。
→ 逆に、枚数が減って訪問が減ると、この網そのものが重荷になる。

## 8. 技術の中身 ― 電子写真方式（レーザー）

複合機が紙にトナー（粉のインク）を載せる仕組みは、ほぼ全社が**電子写真方式**（ゼログラフィ）である。
1938年に米チェスター・カールソンが発明し、ゼロックスが実用化した。

```
①帯電    ②露光        ③現像       ④転写      ⑤定着      ⑥クリーニング
 ドラムに   レーザーで    トナーを     紙に       熱と圧力で   残ったトナーを
 一様に     画像部の電荷  静電気で     トナーを    トナーを     かき落とす
 マイナス   を消す        吸着させる   移す        溶かして固定
 電荷を与える
  ▼           ▼            ▼           ▼          ▼           ▼
 ┌──┐    ┌──┐     ┌──┐    ┌──┐   ┌──┐    ┌──┐
 │ドラム│──▶│潜像  │──▶ │トナー│──▶│紙へ  │──▶│加熱  │──▶│清掃  │→ 繰り返し
 └──┘    └──┘     └──┘    └──┘   └──┘    └──┘
```

| 要素技術 | 何が難しいか | なぜ参入障壁になるか |
| --- | --- | --- |
| **感光体ドラム** | 光で電気抵抗が変わる有機材料。均一に塗る技術 | 材料と塗工の蓄積が要る |
| **トナー** | 数μmの粒子。粒径分布・帯電量・溶ける温度の設計 | 化学メーカー並みの開発力が要る |
| **定着** | 熱でトナーを溶かす。**消費電力の大半がここ** | 省エネ規制の主戦場 |
| **紙搬送** | 秒間数枚の紙を斜行・重送なく送る | 機構設計のすり合わせ。故障の主因 |
| **画像処理・コントローラー** | 解像度、色再現、ネットワーク、セキュリティ | ソフトウェアの比重が年々上昇 |

この「光学＋化学＋精密機構＋ソフト」のすり合わせが必要なため、
**複合機は半導体やPCのような水平分業化が起きにくかった**（内閣府CSTPの資料でも
複合機はすり合わせ型ハイテク産業として整理されている、2023年）。
→ だから寡占が長く続き、日本勢が世界シェアの大半を握れた。

**インクジェット方式**（エプソン、ブラザー、リコーの一部）は熱を使わずインクを吹きつける。
定着の加熱が要らないぶん消費電力が桁違いに小さく（エプソンの「ヒートフリー」訴求）、
部品点数も少ない。オフィス領域でレーザーの牙城を削りつつある。

## 9. なぜ「優秀すぎた」のか

| 優れていた点 | それが逆回転すると |
| --- | --- |
| 入れてしまえば5〜7年、枚数分の現金が自動で入る | 枚数が減れば**何もしなくても売上が減る** |
| 本体値引きをカウンターで回収できる | 枚数が想定割れすると値引き分が**回収不能** |
| 全国の保守網が参入障壁になる | 訪問が減ると保守網が**固定費の塊**に変わる |
| 故障を減らすほど利益が出る（＝技術が進む） | 故障が減り長寿命化すると**買い替えが遠のく** |
| リースで需要を前倒しできる | 満了時に**更新されない**リスクが積み上がる |
| 顧客がオフィスにいる前提 | リモートワークで**オフィスに人がいない** |

> **この業界を理解する最大の鍵**：
> 収益の分母が「オフィスで紙に印刷された枚数」に固定されていること。
> 技術でもシェアでもなく、**分母そのものが縮む**という一点が、この産業の全問題である。

## 10. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **MFP／複合機** | コピー・プリント・スキャン・FAXを統合した機械。A3機が業界の主力 |
| **カウンター保守契約** | 印刷枚数×単価で請求する保守契約。トナー・修理・出張が込み。日本の商習慣 |
| **クリック課金** | 1枚（1クリック）ごとの課金。カウンター料金の別称 |
| **ノンハード売上** | 本体以外（消耗品・保守・サービス）の売上。業界の利益の本体 |
| **枚数コミット** | 月間最低印刷枚数の約束。コミットが高いほど単価を下げられる |
| **MPS** | マネージドプリントサービス。出力環境を丸ごと請け負う契約形態 |
| **電子写真方式（ゼログラフィ）** | 帯電→露光→現像→転写→定着でトナーを紙に載せる方式 |
| **感光体ドラム** | 光で電気抵抗が変わる筒。画像の元（潜像）を作る中核部品 |
| **定着** | 熱と圧力でトナーを紙に固める工程。消費電力の大半を占める |
| **ヒートフリー** | エプソンのインクジェット技術訴求。定着の加熱が不要で低消費電力 |
| **プロダクションプリンター** | 印刷会社向けの高速デジタル印刷機 → [③ 各社の転換](03_各社の転換.md) |
| **リース満了** | 5〜7年のリース期間の終わり。更新提案の勝負どころ |
