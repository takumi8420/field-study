# 市場の構造的縮小

このノートで分かること：**なぜ複合機業界の縮小は「不景気」ではなく「構造」なのか**。
ペーパーレス化とリモートワークが、[① 複合機ビジネスの仕組み](01_複合機ビジネスの仕組み.md)で見た
収益の分母（印刷枚数）そのものを削っていく過程を追う。

## 1. 結論：売れないのではなく、刷られない

複合機業界の縮小は、他の成熟産業とは性質が違う。

- 自動車や白物家電：**買い替えが遅れる**（景気が戻れば需要も戻る）
- 複合機：**稼働中の機械が刷る枚数が減る**（景気が戻っても戻らない）

カウンター保守契約では売上＝枚数×単価だから、
**機械が1台も減らなくても、社員が印刷をやめれば売上は減る**。
しかも保守員の訪問コストは枚数に比例して下がらない。
結果、売上が減るスピードよりコストが減るスピードのほうが遅く、利益率が先に崩れる。

```
従来の成熟産業                    複合機
─────────────             ─────────────
需要 ↓ → 販売台数 ↓              設置台数 → ほぼ維持（リース満了まで）
      → 景気回復で戻る                 印刷枚数 ↓↓ → 戻らない
                                        単価 → 競争で ↓
                                  ＝ 売上 ↓↓、保守固定費 → 横ばい
                                  ＝ 利益率が先に壊れる
```

## 2. 分母は三方向から削られる

| 削る力 | 何が起きているか | 戻るか |
| --- | --- | --- |
| **ペーパーレス化** | 稟議・契約・請求・図面が電子化。電子帳簿保存法やインボイス制度対応で紙の出番が減った | 戻らない（制度と業務設計の変更） |
| **リモート／ハイブリッドワーク** | オフィスにいる人数が減れば、オフィスの複合機で刷る枚数も減る | 部分的に戻る（出社回帰）が、コロナ前には戻らない |
| **画面で済ます文化** | 会議資料の投影、タブレット閲覧、チャットでの共有。**そもそも印刷する動機がない世代**に交代 | 戻らない |

IDCは米国のページボリューム予測で、オフィス再開の遅さとペーパーレス業務プロセスの進展を理由に、
**2023年以降のページ数は緩やかに減少し、長期ではより急な減少に入る**と見通している（IDC、2023年）。

さらに2026年には、**世界のプリンター出荷が第2四半期に前年比7%減**と報じられ、
IDCの2026年第1四半期の更新では**レーザー機、とくに単機能レーザーとA3複合機の落ち込みが顕著**と整理された。
A3複合機は業界の利益の中心なので、ここが弱いことは「利益率の高い層から先に溶ける」ことを意味する。

## 3. 日本の統計で見る縮小

一般社団法人ビジネス機械・情報システム産業協会（**JBMIA**）が国内メーカーの出荷統計を公表している。

| 指標 | 数値 | 年・出典 |
| --- | --- | --- |
| 事務機（全体）出荷額 | **1兆7,376億円**（前年比 **▲9.5%**） | 2025年、JBMIA 出荷実績（流通業界紙報道ベース） |
| うち国内向け | 3,066億円（▲0.4%） | 同上 |
| うち海外向け | 1兆4,309億円（**▲11.3%**） | 同上 |
| 複写機・複合機 出荷額 | 前年比 **▲9.2%** | 同上 |
| 複写機・複合機 出荷台数 | 約316万台（前年比 **▲12.4%**） | 2025年、JBMIA（報道ベース） |

読み取るべき点は3つ。

1. **海外の落ち込みが国内より大きい**。日本勢の事務機は輸出比率が高く、
   欧米オフィスのリモートワーク定着がそのまま数字に出る
2. **台数（▲12.4%）が金額（▲9.2%）より速く減っている**。
   高付加価値機へのシフトで単価は保てているが、設置ベース（＝将来のカウンター収入の母数）が細る
3. 国内が▲0.4%と踏みとどまったのは、**値上げと高機能機へのシフト**によるところが大きい。
   枚数が戻ったわけではない

> **設置台数が減ることの怖さ**：台数減は今期の売上より**来期以降の保守収入**を削る。
> 今年1台入れ損なうと、そのあと5〜7年分のカウンター収入を丸ごと失う。
> 複合機業界の営業が「台数シェア」に執着するのはこのためである。

## 4. 新興国と先進国で事情が違う

```
     印刷枚数
      ▲
      │           先進国（日米欧）
      │  ─────╲
      │           ╲______   ペーパーレス＋リモートで減少、戻らない
      │
      │           新興国（インド、東南アジア、中東、アフリカ）
      │       ______╱‾‾‾‾   オフィス増・識字率・行政書類で増加
      │  ____╱
      └──────────────────────▶ 時間
          2010      2020      2026
```

| 地域 | 需要の性格 | メーカーにとっての意味 |
| --- | --- | --- |
| **日本・北米・西欧** | 縮小。ただし**保守契約の単価が高く利益率がよい** | 守るほど利益は出るが、母数が減り続ける |
| **中国** | 縮小＋現地勢の台頭。官公庁の国産化要求 | 価格競争が厳しく、撤退・縮小の判断が出やすい |
| **インド・東南アジア** | 拡大。ただしA4・低価格機が中心 | 台数は取れるが、**1台あたりの利益が薄い** |
| **中東・アフリカ・中南米** | 拡大。中古機と再生トナーの市場も厚い | 純正消耗品のシェアを守りにくい |

**問題は「増える市場は儲からない市場」である点**。
成長地域はA4・低価格帯が中心で、日本型のカウンター保守が根付いていない。
台数を取っても、失った先進国のカウンター収入は埋まらない。

## 5. 互換トナーと中古機 ― 利益の本体が横から削られる

ジレットモデルの弱点は、**替刃だけを他人に売られること**である。

| 侵食する存在 | 何をするか | 効き方 |
| --- | --- | --- |
| **互換トナー（サードパーティ）** | 純正より安いトナーを製造・販売 | カウンター保守外の機種（A4プリンター等）で効く |
| **リサイクルトナー** | 使用済みカートリッジを再生 | 環境訴求と価格で採用が進む |
| **中古複合機市場** | リース満了機を整備して再販 | 新品需要を食う。新興国輸出の主力でもある |
| **独立系保守業者** | メーカー系より安い保守を提供 | 保守収入の単価を押し下げる |

カウンター保守契約は「トナーも修理もこちら持ち」という設計なので、
**日本のA3複合機では互換トナーが入り込みにくい**。これは日本市場の強みだった。
一方、欧米やA4領域ではカートリッジ購入型が多く、互換品の浸食が直撃する。

> 日本のカウンター保守は、消耗品ビジネスを守る「堀」としても機能していた。
> だからこそ、その堀の内側にある**枚数そのものが減ると逃げ場がない**。

## 6. 固定費が落ちない ― 縮小が利益を壊す経路

```
【売上】枚数 ↓ × 単価 ↓（競争）        …… 上から減る
──────────────────────────
【変動費】トナー・部品     ↓          …… 枚数に比例して減る（ここは救い）
【準固定費】保守員の人件費・車両  →    …… 訪問頻度は枚数ほど減らない
【固定費】工場・開発・販売網・物流 →    …… まったく減らない
──────────────────────────
【利益】= 先に消える
```

複合機の開発は光学・化学・機構・ソフトのすり合わせで、**1機種あたりの開発費が重い**。
枚数が減っても新機種は出さないと競合に負けるので、開発費は落とせない。
工場も同じで、稼働率が落ちると固定費が1台あたりに重くのしかかる。

だから各社の対応は次の3つに収斂する。

1. **統合して固定費を割る**（共同調達、エンジンのOEM供給、合弁）
2. **値上げして単価で耐える**（2022年以降、各社が本体・消耗品を値上げ）
3. **別の収益源を足す**（→ [③ 各社の転換](03_各社の転換.md)）

## 7. 主要プレイヤーの構図

世界の複合機（A3中心）市場は、**ほぼ日本勢の寡占**という珍しい産業である。

| 企業 | 立ち位置 | 世界シェア（概算） | 特徴 |
| --- | --- | --- | --- |
| **キヤノン** | 世界首位 | 約18% | プリンティングが売上の過半。メディカル・半導体露光へ多角化 |
| **リコー** | 2位 | 約16% | オフィスサービス（IT・DX支援）への転換が最も鮮明 |
| **コニカミノルタ** | 3位 | 約14% | 構造改革の真っ最中。プロダクションプリントと計測に軸足 |
| **京セラドキュメントソリューションズ** | 4位 | 約10% | 長寿命部材による低ランニングコストで欧米に強い |
| **富士フイルムビジネスイノベーション** | 5位 | 約8% | 旧富士ゼロックス。分離・上場が検討されている（2026年8月発表） |
| **シャープ** | 5位 | 約8% | 鴻海傘下。BtoB事業の柱 |
| **東芝テック** | 7位 | 約7% | POSレジと複合機の二本柱 |
| **エプソン** | インクジェット陣営 | ― | ヒートフリー技術で低消費電力を訴求。商業・産業印刷が成長軸 |
| **ブラザー** | A4中心 | ― | 中小・在宅向けで強い。工作機械など多角化 |
| **ゼロックス（米）** | 欧米のMPS | ― | 2025年7月にレックスマークを買収し、印刷分野で再編の受け皿に |
| **HP（米）** | A4プリンター | ― | オフィスプリンターの世界最大手。A3は限定的 |

（シェアは四季報オンライン等の公開情報をまとめた販売会社サイトの数値。年次・定義がまちまちなので**目安**）

> **寡占なのに儲からない**という状態が、この業界の現在地。
> シェア争いで勝っても、市場そのものが縮んでいるので報われない。
> だから各社の関心は「シェア」から「どこへ逃げるか」に移った。

## 8. 縮小のタイムライン

| 時期 | 何が起きたか |
| --- | --- |
| 1990年代 | アナログ複写機からデジタル複合機へ。ネットワーク接続で「プリンター」を飲み込む |
| 2000年代 | カラー化。カラーカウンター単価が高く、**業界の黄金期** |
| 2008〜2010年 | リーマンショックで設備投資が凍結。ただし枚数は戻った |
| 2010年代前半 | 先進国の枚数がピークアウト。新興国と商業印刷に活路を求め始める |
| 2018年 | 富士ゼロックスと米ゼロックスの統合が破談。資本関係の整理へ |
| 2020〜2021年 | コロナ禍。**オフィスに人がいなくなり枚数が急減**。構造縮小が一気に顕在化 |
| 2021年 | 富士ゼロックスが富士フイルムビジネスイノベーションへ社名変更、ゼロックスとの提携終了 |
| 2022〜2023年 | 部品不足と値上げ。出荷は回復したが枚数は戻らず |
| 2024年 | コニカミノルタと富士フイルムBIが複合機の調達で合弁を検討（基本合意） |
| 2025年 | ゼロックスがレックスマークを買収（7月完了）。各社が構造改革費用を計上 |
| 2026年 | 富士フイルムHDが富士フイルムBIの分離・上場を検討と発表（8月）。米関税がコストを直撃 |

詳細は [④ 直近トピック 2026](04_直近トピック_2026.md)。

## 9. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **ページボリューム（枚数）** | 市場全体で印刷される枚数。この業界の需要そのもの |
| **設置ベース（インストールベース）** | 市場で稼働中の自社機の総数。将来のカウンター収入の母数 |
| **ペーパーレス化** | 業務文書の電子化。電子帳簿保存法・インボイス制度が後押し |
| **A3機／A4機** | 大型床置き機／小型卓上機。利益はA3に集中する |
| **互換トナー** | 純正でない第三者製トナー。消耗品利益を侵食する |
| **JBMIA** | ビジネス機械・情報システム産業協会。国内の事務機出荷統計を公表 |
| **IDC** | 米調査会社。プリンター・複合機の出荷とページ数の予測を出す |
| **構造改革費用** | 人員削減・拠点統廃合・減損などの一時費用。近年各社が計上 |
| **MPS** | マネージドプリントサービス → [① 仕組み](01_複合機ビジネスの仕組み.md) |
