# 事務機器・複合機

- 大分類: 電機・電子部品
- 状態: done
- 更新日: 2026-09-20

**この業界を一言で**：オフィスにコピー機（複合機）を置き、**刷られた紙1枚ごとに課金して稼ぐ産業**。
本体では稼がず、トナーと保守を込みにした「カウンター料金」で回収する仕組みが、
40年にわたって極めて安定した現金を生み続けてきた。

問題は、その**収益の分母が「オフィスで印刷される枚数」だった**こと。
ペーパーレス化とリモートワークで分母が縮み始めた瞬間、
**儲けの仕組みが優秀すぎたがゆえに、需要減がそのまま売上減へ直結する**構造が露呈した。
このフォルダはその一点を軸に構成している。

## 1. 業界の定義・範囲

**事務機器**とは、オフィスで文書を扱うための機械の総称。
中心は**複合機（MFP：Multi Function Peripheral）**、すなわちコピー・プリント・スキャン・FAXを
1台にまとめた機械である。ほかにプリンター、シュレッダー、ラベルプリンター、
プロジェクター、POSレジなども広義の事務機に含まれる。

隣接業界との境界は次のとおり。

| 業界 | 違い |
| --- | --- |
| [PC・スマートフォン](../11_PC・スマートフォン/README.md) | 同じオフィス機器だが、消耗品課金がなく買い切り。HPのように両方やる会社もある |
| [印刷](../../14_メディア・広告・エンタメ/02_印刷/README.md) | 印刷を**サービスとして請け負う側**。複合機メーカーは印刷会社に機械を売る立場 |
| [総合電機](../01_総合電機/README.md) | 事業ポートフォリオの一部として事務機を持つ場合がある（シャープ、東芝テック） |
| [計測・分析機器](../13_計測・分析機器/README.md) | 光学・画像技術が近く、複合機メーカーの転換先になっている |
| [医療機器](../../09_医薬・医療・ヘルスケア/05_医療機器/README.md) | キヤノン・コニカミノルタ・富士フイルムの転換先。画像処理技術が共通 |
| [SIer・ITサービス](../../04_情報通信・IT・ネット/05_SIer・ITサービス/README.md) | リコー等が参入した領域。既存の複合機顧客に売る |
| [リース](../../05_金融/10_リース/README.md) | 複合機の販売はほぼリースとセット。金融側の当事者 |

**この業界の特殊性**は、機械メーカーでありながら**収益の実態が従量課金サービス業**である点にある。
そのため「製造業」の型だけでは読み解けず、**設置ベース（稼働台数）×枚数×単価**という
ストックビジネスの型を重ねて見る必要がある。→ [① 仕組み](01_複合機ビジネスの仕組み.md)

## 2. 市場規模と成長性

| 区分 | 数値 | 年・出典 |
| --- | --- | --- |
| 国内メーカーの事務機 出荷額 | **1兆7,376億円**（前年比 **▲9.5%**） | 2025年、JBMIA 出荷実績（流通業界紙報道ベース） |
| うち国内向け | 3,066億円（▲0.4%） | 同上 |
| うち海外向け | 1兆4,309億円（**▲11.3%**） | 同上 |
| 複写機・複合機 出荷額 | 前年比 **▲9.2%** | 同上 |
| 複写機・複合機 出荷台数 | 約**316万台**（前年比 **▲12.4%**） | 2025年、JBMIA（報道ベース） |
| 世界プリンター出荷 | 2026年第2四半期に前年比 **▲7%** | 2026年、IDC（業界紙報道） |
| 主要各社の売上（参考） | キヤノン プリンティング 2兆4,944億円／富士フイルムBI 1兆1,748億円／リコー 全社約2兆6,000億円 | 2025年12月期・2026年3月期、各社IR |

- **成長率はマイナスが基調**。景気循環による波ではなく、
  印刷枚数という需要の母数が減り続ける構造的な縮小である
- **台数の減少が金額の減少より速い**（▲12.4% vs ▲9.2%）。
  高付加価値機へのシフトと値上げで単価は保てているが、
  **将来のカウンター収入の母数である設置ベースが細っている**
- 海外（▲11.3%）が国内（▲0.4%）より大きく落ちている。日本勢は輸出比率が高く、
  欧米オフィスのリモートワーク定着が数字に直結する
- 一方で**商業印刷・産業印刷（ラベル、包装、捺染、サイン）は成長領域**とされ、
  各社がここに機械を持ち込んでいる → [③ 各社の転換](03_各社の転換.md)

## 3. バリューチェーン（川上 → 川下）

```
【川上】                【製造】            【流通】                【川下】

 トナー（化学）  ──┐
 感光体ドラム    ──┤
 レンズ・光学部品 ──┼──▶ 複合機メーカー ──┬─▶ 直販（自社販売会社）──▶ 大企業・官公庁
 モーター・ギア   ──┤   キヤノン/リコー/   ├─▶ 系列ディーラー ─────▶ 地域の中堅・中小
 半導体・基板     ──┤   コニカミノルタ/    └─▶ 独立系OA商社 ───────▶ 中小・個人事業主
 鋼板・樹脂       ──┘   富士フイルムBI 他          │
                                                     │（リース会社が機械代を立替）
                          ▲                          ▼
                          │                    ユーザー企業に設置
                          │                          │
                  トナー・部品の継続供給 ◀────── カウンター料金（枚数×単価）
                  保守員の訪問                 ＝ 付加価値はここに集まる
                                                     │
                                                     ▼
                                       リース満了 → 入替 or 中古市場へ → 新興国へ輸出
```

- **組立そのものの付加価値は薄い**。利益は設置後5〜7年のトナー・保守に集まる
- 川上のトナーと感光体は化学・材料の世界で、**内製している会社が多い**
  （消耗品の利益を守るため）。→ [電子材料](../../10_素材・化学/03_電子材料/README.md)
- 川下の**保守員を抱えた販売・サービス網が最大の参入障壁**だった。
  ただし枚数が減ると、この網は固定費の塊に変わる

## 4. 主要プレイヤーとシェア

A3複合機の世界市場は**日本勢がほぼ独占**という珍しい構図。
シェアは公的統計がなく、販売会社サイトが四季報オンライン等を引用した**目安の数値**である。

| 企業 | 立ち位置 | 世界シェア（概算） | 特徴 |
| --- | --- | --- | --- |
| **キヤノン** | 世界首位 | 約18% | プリンティングが売上の過半。メディカル・半導体露光・ネットワークカメラへ多角化 |
| **リコー** | 2位 | 約16% | オフィスサービス（中小企業向けIT・DX支援）への転換が最も鮮明 |
| **コニカミノルタ** | 3位 | 約14% | 構造改革で黒字転換。プロフェッショナルプリント、計測、ヘルスケアへ |
| **京セラドキュメントソリューションズ** | 4位 | 約10% | 長寿命部材による低ランニングコストで欧米に強い |
| **富士フイルムBI** | 5位 | 約8% | 旧富士ゼロックス。2026年8月に分離・上場の検討が発表された |
| **シャープ** | 5位 | 約8% | 鴻海傘下。BtoB事業の柱 |
| **東芝テック** | 7位 | 約7% | POSレジと複合機の二本柱 |
| **エプソン** | インクジェット陣営 | ― | ヒートフリー技術で低消費電力。商業・産業印刷が成長軸 |
| **ブラザー** | A4中心 | ― | 中小・在宅向けに強い。工作機械など多角化 |
| **ゼロックス（米）** | 欧米のMPS | ― | 2025年7月にレックスマーク買収を完了。再編の受け皿 |
| **HP（米）** | A4プリンター世界最大手 | ― | A3複合機は限定的。消耗品サブスクに強い |

> シェアを取っても市場そのものが縮んでいるため、競争の焦点は

## 5. 収益モデル・コスト構造

```
売上 ＝ ①本体販売（薄利。値引きの原資は将来のカウンター収入）
      ＋ ②カウンター料金＝設置台数 × 1台あたり印刷枚数 × 単価  ← 利益の本体
      ＋ ③消耗品・部品販売（保守契約外の機種）
      ＋ ④ITサービス・MPS（成長させたい領域）
      － 変動費（トナー・部品）
      － 準固定費（保守員の人件費・訪問コスト）  ← 枚数ほどは減らない
      － 固定費（工場・開発・販売網）            ← まったく減らない
```

| 収益源 | 性格 | 利益率のイメージ |
| --- | --- | --- |
| 本体販売 | 競争が激しく値引き前提 | 薄い。赤字で入れることもある |
| **カウンター料金（保守・消耗品）** | 設置後5〜7年、毎月発生 | **厚い**。売上構成で6〜7割を占めるとされる |
| プロダクションプリント | 単価が大きく、印刷会社の設備投資に連動 | 中。景気変動が大きい |
| ITサービス・MPS | 人月とソフトが混ざる | 薄〜中。だが成長する |

**コスト側の要点**は、保守員の人件費が**準固定費**であること。
訪問1回のコストは枚数に関係なくほぼ一定なので、
**1台あたりの枚数が減ると1枚あたりの保守原価が跳ね上がる**。
売上が減るスピードよりコストが減るスピードが遅く、利益率が先に崩れる。
→ [② 市場の構造的縮小](02_市場の構造的縮小.md)

## 6. 競争要因（KSF）と参入障壁

```
┌────────────────────────────────┐
│ ①機械を作る（光学＋化学＋精密機構＋ソフトのすり合わせ）  │ 水平分業が起きにくい層
├────────────────────────────────┤
│ ②売って入れる（提案力・リース・値引きの体力）            │
├────────────────────────────────┤
│ ③止めない（全国の保守員・部品在庫・遠隔監視）            │ ← 最大の障壁だった層
└────────────────────────────────┘
                    ↓ 枚数が減ると…
         ③が「障壁」から「固定費」へ反転する
```

| KSF | なぜ効くか |
| --- | --- |
| **消耗品の内製** | トナー・感光体を自社で作れると、消耗品利益を他社に取られない |
| **保守サービス網** | 「止まらない」ことに金が払われる。30分で駆けつける体制は一朝一夕に作れない |
| **すり合わせ開発力** | 光学・化学・機構・ソフトが絡み、部品を買い集めても作れない |
| **設置ベースの大きさ** | 将来のカウンター収入の母数。台数シェアに各社が執着する理由 |
| **省エネ・環境性能** | 定着の消費電力が大きいため、省エネ規制と電気代が選定基準になる |
| **セキュリティ** | 複合機はハードディスクを持つネットワーク機器。官公庁調達では必須要件 |
| **リースを含む提案力** | 顧客は本体価格でなく月額総額で判断する |

## 7. 規制・法制度

| 分野 | 内容 |
| --- | --- |
| **省エネ法（トップランナー制度）** | 複写機・プリンターはトップランナー基準の対象機器。消費電力性能が製品要件を規定する |
| **国際エネルギースタープログラム** | 日米等の省エネ基準。官公庁・大企業の調達条件になることが多い |
| **グリーン購入法** | 国等の機関が調達する際の環境配慮基準。複写機も対象品目 |
| **電子帳簿保存法・インボイス制度** | 帳票の電子化を促し、**結果として印刷需要を減らす**制度。同時にITサービスの商機でもある |
| **個人情報保護法・政府調達のセキュリティ要件** | 複合機は内部にデータを保持するため、暗号化・上書き消去が要件化 |
| **資源有効利用促進法・廃棄物処理法** | 使用済みトナーカートリッジ・機器の回収リサイクル義務 |
| **通商・関税** | 米国の追加関税が中国・東南アジア生産分のコストを直撃（2025〜2026年） |
| **競争法（各国）** | 富士フイルムBI×コニカミノルタの調達合弁は各国審査で設立時期が変更された |

## 8. 最近のトピック

詳細は [④ 直近トピック 2026](04_直近トピック_2026.md)。要点は次の5つ。

1. **富士フイルムHDが富士フイルムBIの分離・上場を検討と発表**（2026年8月）。
   グループ売上の約35%（1兆1,748億円）を占める最大セグメントを、
   パーシャル・スピンオフで持分20%弱まで下げて切り離す構想
2. **出荷減は続いている**。2025年のJBMIA統計で事務機出荷額▲9.5%、複合機台数▲12.4%。
   IDCによれば2026年も世界のプリンター出荷は前年割れで、**A3複合機の落ち込みが顕著**
3. **米国の追加関税がコストを直撃**。生産が中国・東南アジアに集中しており、
   複数年のカウンター契約ゆえに**すぐ値上げで転嫁できない**のが痛い
4. **再編は3方向で進行**。ゼロックスによるレックスマーク買収完了（2025年7月、15億ドル）、
   富士フイルムBI×コニカミノルタの調達合弁、富士フイルムBIの分離上場
5. **リコーが中期経営戦略'26を発表**（2026年3月）。2030年度に向け、ストック利益に占める
   オフィスプリンティングの比率を**59%→42%**へ自ら下げ、ワークプレイスサービスを24%→37%へ

## 9. 用語メモ

各ノート末尾にも用語メモを置いている。共通する基本用語は次のとおり。

| 用語 | 意味 |
| --- | --- |
| **MFP／複合機** | コピー・プリント・スキャン・FAXを1台にまとめた機械 → [① 仕組み](01_複合機ビジネスの仕組み.md) |
| **カウンター保守契約** | 印刷枚数×単価で請求する保守契約。トナー・修理・出張が込み。日本独特の商習慣 |
| **クリック課金** | 1枚（1クリック）ごとの従量課金。カウンター料金の別称 |
| **ジレットモデル** | 本体を安く売り消耗品で稼ぐモデル。剃刀の替刃商法が語源 |
| **ノンハード売上** | 本体以外（消耗品・保守・サービス）の売上。業界の利益の本体 |
| **設置ベース（インストールベース）** | 稼働中の自社機の総数。将来のカウンター収入の母数 |
| **ページボリューム** | 市場全体の印刷枚数。この業界の需要そのもの → [② 構造的縮小](02_市場の構造的縮小.md) |
| **MPS** | マネージドプリントサービス。出力環境を丸ごと請け負う契約形態 |
| **電子写真方式（ゼログラフィ）** | 帯電→露光→現像→転写→定着でトナーを紙に載せる方式 |
| **感光体ドラム／定着** | 画像の元を作る筒／熱と圧力でトナーを固める工程（消費電力の大半） |
| **ヒートフリー** | 加熱せずインクを吐出するエプソンのインクジェット技術 |
| **プロダクションプリント** | 印刷会社向けの高速デジタル印刷機事業 → [③ 各社の転換](03_各社の転換.md) |
| **パーシャル・スピンオフ** | 親会社が一部株式を残して子会社を分離・上場させる手法 |
| **JBMIA** | ビジネス機械・情報システム産業協会。国内の事務機出荷統計を公表 |
