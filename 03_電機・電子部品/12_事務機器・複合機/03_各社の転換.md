# 各社の転換

このノートで分かること：[② 市場の構造的縮小](02_市場の構造的縮小.md)で見た「分母が縮む」問題に対し、
各社がどこへ逃げようとしているのか。**逃げ先は3方向しかなく、どれを選んだかで会社の姿が変わる。**

## 1. 結論：逃げ道は3つ、そして全部が難しい

```
                    ┌──▶ ①オフィスの「紙の外」へ
                    │      IT・DX支援、MPS、ワークフロー、クラウド
                    │      （顧客基盤は使える／競合はSIerとSaaS）
  複合機ビジネス ────┼──▶ ②「紙」を別の紙へ
   （縮む本業）      │      商業印刷・産業印刷（ラベル、包装、捺染、サイン）
                    │      （技術は使える／顧客も競合も別世界）
                    │
                    └──▶ ③まったく別の事業へ
                           医療機器、計測、半導体露光、材料、ヘルスケア
                           （本業と無関係／M&Aと時間が要る）
```

| 逃げ先 | 使える資産 | 難しさ |
| --- | --- | --- |
| **①オフィスサービス・ITサービス** | 全国の顧客基盤と訪問網、中小企業への接点 | 人月商売で粗利が薄い。SIerやSaaSと真正面から競合 |
| **②商業・産業印刷** | 電子写真／インクジェットの技術、色の作り込み | 顧客は印刷会社・ブランドオーナー。景気に左右されやすく投資が重い |
| **③別事業（医療・計測・半導体等）** | 光学・精密加工・画像処理の基礎技術 | 買収費用が巨額。承認・認証に年単位。既存の強者がいる |

> **共通する厳しさ**：どの逃げ先も、複合機ほど「入れたら自動で現金が入る」仕組みではない。
> カウンター保守の代わりになる継続課金（ストック収益）をどう作るかが、全社共通の宿題になっている。

## 2. 5社の選んだ道（早見表）

| 企業 | 主戦場の再定義 | 本業（複合機）の扱い | 現状（2026年時点） |
| --- | --- | --- | --- |
| **キヤノン** | プリンティングを稼ぎ頭に残しつつ、**メディカル・半導体露光・ネットワークカメラ**で成長 | 維持・効率化。生産は続ける | 2025年12月期は売上4兆6,247億円と過去最高。プリンティングは減益 |
| **リコー** | **オフィスサービス（IT・DX支援）**へ軸足を移す。「ワークプレイスのインテグレーター」 | 「縮小を微減にとどめる」。エンジンを他社にも供給 | 2026年3月期は増益。ストック利益のオフィスプリンティング比率を2030年度に42%まで下げる計画 |
| **富士フイルムBI** | 親会社から**分離・上場**し、独立した複合機＋ITサービス会社に | 本業そのもの。切り離される側 | 2026年8月、富士フイルムHDが上場検討を発表 |
| **コニカミノルタ** | **構造改革と選択と集中**。プロフェッショナルプリントと計測・ヘルスケアへ | 事業として維持しつつコスト削減 | 2026年3月期は黒字転換。プロフェッショナルプリントは減収 |
| **エプソン** | **インクジェット**（ヒートフリー）で、オフィスと商業・産業印刷の両取り | レーザーを持たず、インクジェットで攻める | 2026年3月期は増収減益。米子会社の減損を計上 |

## 3. リコー ― 「コト売り」への転換が最も鮮明

リコーは早くから「モノ売りからコト売りへ」を掲げ、
複合機販売の顧客基盤を**中小企業向けITサービス**に転用してきた。

```
【従来】                          【転換後】
 複合機を入れる                    複合機を入れる（変わらず）
   ↓                                ↓
 カウンター料金を取る                +  PC・ネットワークの面倒を見る
   ↓                                +  クラウド・グループウェアの導入
 5年後に入れ替え提案                 +  電子帳簿・ワークフローの構築
                                     +  セキュリティ、電話、複合機の一括管理
                                       ↓
                                    月額のITサービス契約（ストック）
```

なぜ勝てる可能性があるか。日本の中小企業には**情報システム部門がない**。
リコーの販売会社は「毎月コピー機の保守で顔を出している業者」であり、
**すでに社内に入り込んでいる**。この接点は大手SIerが持っていない資産である。

| リコーの主要数値 | 内容 | 年・出典 |
| --- | --- | --- |
| 連結売上高 | 約2兆6,000億円規模 | 2026年3月期、リコーIR |
| 2026年3月期 純利益 | 前期比 **+33%** の見通しに上方修正（DX支援の好調が要因と報道） | 2026年2月、日本経済新聞 |
| 中期経営戦略'26 | 2026〜2030年度。**2030年度の営業利益は1,400億円以上が「目線」** | 2026年3月25日発表、リコー |
| ストック利益構成（オフィスプリンティング） | 2025年度見通し **59%** → 2030年度 **42%** へ低下させる計画 | 同上（報道ベースの整理） |
| ストック利益構成（ワークプレイスサービス） | **24% → 37%** へ引き上げる計画 | 同上 |
| ストック利益構成（商用・産業印刷） | **13% → 14%** | 同上 |

**注目すべきはこの数字の意味**。リコーは「複合機をやめる」とは言っていない。
言っているのは「**利益の6割を稼いでいる本業を、4割まで下げる**」である。
これは成長戦略というより、**縮む本業に会社の重心を預けないための計画**と読むのが正確だろう。

なお中期経営戦略は3年周期から**5年先を見据えた毎年ローリング方式**に変更された（2026年3月）。
環境変化が速すぎて3年固定の計画が持たない、という判断である。

## 4. キヤノン ― 本業を守りながら別の柱を育てる

キヤノンは複合機・レーザープリンターの世界首位でありながら、
**プリンティング以外の3本柱**を育ててきた。

| セグメント | 2025年12月期 売上高 | 位置づけ |
| --- | --- | --- |
| **プリンティング** | **2兆4,944億円** | 依然として売上の過半。営業利益は前年比 ▲11.8%（2,574億円） |
| **イメージング** | 1兆549億円 | カメラ、ネットワークカメラ。監視カメラが成長 |
| **メディカル** | 5,806億円（+2.1%） | CT、MRI、超音波。旧東芝メディカルの買収（2016年）が源流 |
| **インダストリアル** | 3,611億円 | 半導体露光装置、有機ELディスプレイ製造装置、ナノインプリント |
| 連結合計 | **4兆6,247億円**（+2.5%、2期連続で過去最高） | 営業利益 4,554億円 |

（出典：キヤノン 2025年12月期 決算短信・決算説明会資料、2026年1月29日発表）

> キヤノンの設計思想は「**プリンティングで稼いだ現金を、別の柱の買収と開発に回す**」。
> 東芝メディカルの買収（約6,655億円、2016年）はその典型で、
> いまやメディカルはカメラ事業に迫る規模になった。

一方で2025年は、米国の追加関税と欧州・アジアの景気不透明感で、
レーザープリンターを中心に**購入の先送り**が見られたとしている。
本業を守る難易度は上がり続けている。

半導体露光装置は、ASMLがEUV（極端紫外線）で独占する最先端を追わず、
**ナノインプリント**（型を押し付けて回路を転写する方式）という別ルートを選んだ。
→ [半導体製造装置](../03_半導体製造装置/README.md)

## 5. 富士フイルムBI ― 親会社から切り離される側

旧・富士ゼロックス。2021年に富士フイルムビジネスイノベーションへ社名変更し、
米ゼロックスとの技術提携・販売territory の関係を終えた。

2026年8月6日、富士フイルムホールディングスが**富士フイルムBIの株式上場の検討開始**を発表した。

| 項目 | 内容 |
| --- | --- |
| 方式 | **パーシャル・スピンオフ**（親会社が一部株式を残して分離）を想定 |
| 出資比率 | 富士フイルムHDの持分を**20%弱**まで引き下げる |
| 手順 | 残り株式を富士フイルムHD株主へ分配 → 東証上場 |
| 時期 | **2〜3年後**を視野 |
| 事業規模 | 「ビジネスイノベーション」セグメント売上 **1兆1,748億円**（2026年3月期）、グループ全体の約**35%** |
| ブランド | 独立後も「富士フイルム」ブランドの使用を継続 |

（出典：富士フイルムHD 2026年8月6日発表、日本経済新聞・週刊BCN報道）

**なぜ最大セグメントを切り離すのか**。
富士フイルムHDは写真フイルムの需要消失を乗り越えた会社で、
経営資源を**ヘルスケア（バイオCDMO、医療機器）とエレクトロニクス（半導体材料）**に集中させたい。
複合機は稼いでいるが、**成長しない事業に資本を置いておけない**という判断である。

> 「写真フイルムからの転身」で知られる会社が、
> 転身先として手に入れた複合機事業もまた手放そうとしている。
> 市場が縮む産業を抱え続けることのコストが、それだけ大きいということでもある。

富士フイルムBIとコニカミノルタは、複合機・プリンターの**原材料／部材調達で合弁会社の設立**に合意している
（2024年、各国競争法の審査で設立予定日を変更）。**競合同士が調達だけ手を組む**のは、
規模の経済が失われつつある市場でコストを割るための典型的な動きである。

## 6. コニカミノルタ ― 構造改革の教科書的な事例

コニカミノルタは複合機（デジタルワークプレイス）、プロフェッショナルプリント、
計測機器、ヘルスケアを持つが、近年は**赤字と減損に苦しみ、構造改革に踏み切った**。

| 項目 | 数値 | 年・出典 |
| --- | --- | --- |
| 連結売上高 | 約1兆877億円（前期比 ▲3.6%） | 2026年3月期、コニカミノルタ決算短信 |
| 営業利益 | 約499億円（前期の大幅赤字から**黒字転換**） | 同上 |
| 事業貢献利益 | 約532億円と大幅に伸長 | 同上 |
| プロフェッショナルプリント売上 | 2,551億円（前期比 **▲10.4%**） | 同上 |
| 黒字転換の要因 | グローバル構造改革による販管費率改善、減損損失の剥落、構造改革費用の剥落、子会社株式売却損益 | 同上 |

**読み解き方**：売上は減っているのに利益は出た。
つまり**売上を伸ばして治したのではなく、費用と事業を削って治した**。
これは縮小市場にいる企業の典型的な回復パターンで、削り切ったあとに何を残すかが次の論点になる。

コニカミノルタが「残す」と決めているのは、計測機器（色・光の測定）や
ヘルスケア（医療用画像）など、**複合機の技術（光学・画像処理）が効く周辺領域**である。
→ [計測・分析機器](../13_計測・分析機器/README.md)、[医療機器](../../09_医薬・医療・ヘルスケア/05_医療機器/README.md)

## 7. エプソン ― 「レーザーを持たない」という戦い方

エプソンはレーザー（電子写真）の複合機を主力に持たず、**インクジェット一本**で戦う。

| 項目 | 内容 | 年・出典 |
| --- | --- | --- |
| 売上収益 | 1兆4,132億円（前期比 +3.7%） | 2026年3月期、エプソンIR |
| 営業利益 | 495億円（前期比 **▲34.0%**） | 同上 |
| 減損 | 米Fiery社（商業印刷向けソフト）で **259億円**の減損を計上。米関税に端を発する商業印刷市場の投資先送りを踏まえた保守的見直し | 2026年5月、エプソン発表 |
| 商業印刷 | 実質増収率は2桁超と説明 | 2026年5月、日本経済新聞 |

**ヒートフリー技術**は、インクを熱で飛ばさず圧電素子（ピエゾ）で押し出す方式。
定着のための加熱が要らないため、**消費電力がレーザー機より桁違いに小さい**。
省エネと待機時間ゼロを武器にオフィス市場を削りにいく戦略で、
電気料金が高い地域や、カーボン削減目標を持つ企業に刺さる。

一方、**商業・産業印刷への展開は投資が重く、景気の影響をまともに受ける**。
Fieryの減損はその現実を示した例といえる。

## 8. なぜ転換は「遅れる」のか ― ジレットモデルの副作用

```
複合機が儲かっている間は…

 営業：既存客の更新提案のほうが確実に数字になる
 開発：新機種を出さないとシェアを失う → 開発費が本業に貼り付く
 販社：保守員を抱えている → 訪問件数を維持したい
 経営：本業の利益で全社の固定費を賄えている
   ↓
 新規事業に人も金も回らない ＝「優秀な本業」が転換の足を引っ張る
   ↓
 本業が崩れ始めてから動く → 買収資金も時間も足りない
```

| 転換を遅らせる力 | 具体例 |
| --- | --- |
| **既存顧客からの安定収入** | 更新提案のほうが新規開拓より確実。営業の行動が変わらない |
| **保守網という固定費** | 抱えた人員を遊ばせられないので、本業の台数を追い続ける |
| **すり合わせ型の開発組織** | 機構・光学・化学の人材構成が、ソフト／サービス事業に合わない |
| **成功体験** | 40年続いた収益モデルを「そのうち戻る」と考えてしまう |

> これは複合機だけの話ではない。
> [AV機器](../10_AV機器/README.md)や[PC・スマートフォン](../11_PC・スマートフォン/README.md)、
> 写真フイルム、固定電話など、**過去に強すぎた収益モデルを持つ事業に共通する症状**である。
> 複合機が特殊なのは、その収益モデルが「紙の枚数」という、
> 社会の働き方そのものに直結した分母に乗っていた点にある。

## 9. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **オフィスサービス** | 複合機以外のIT・DX支援（PC、ネットワーク、クラウド、ワークフロー）。リコーの成長軸 |
| **ワークプレイスのインテグレーター** | リコーの目指す姿。オフィスに限らず「デジタルでつながる働く場」全体を統合する役割 |
| **ストック収益** | 継続的に入る収益。カウンター料金、保守、サブスクリプション |
| **プロフェッショナルプリント／プロダクションプリント** | 印刷会社向けの高速デジタル印刷事業 |
| **産業印刷** | ラベル、包装、捺染（布）、サイン、建材などへの印刷 |
| **パーシャル・スピンオフ** | 親会社が一部株式を残して子会社を分離・上場させる手法。税制優遇が適用されうる |
| **ナノインプリント** | 型を押し当てて回路パターンを転写する半導体製造技術。キヤノンが推進 |
| **ヒートフリー** | 加熱せずにインクを吐出するエプソンのインクジェット技術 |
| **Fiery** | 商業印刷向けの印刷制御ソフト／DFE。エプソンが買収したが2026年に減損 |
| **事業貢献利益** | コニカミノルタが使う管理指標。一過性要因を除いた事業の実力値に近い |
