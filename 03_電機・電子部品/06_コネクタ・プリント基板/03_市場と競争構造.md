# 市場と競争構造

**このノートで分かること**：世界のプリント基板・コネクタは誰がどこで作っているのか。
日本勢はなぜ量で負けたのに存在感が残っているのか。そして、AIサーバーという新需要が
競争の地図をどう塗り替えているのか。

結論を先に言うと、**量の中心は中国・台湾、利益の中心は「材料」と「先端パッケージ基板」「高速コネクタ」**。
日本勢は汎用基板の量産からは退いた代わりに、上流（材料）と最先端（パッケージ基板・FPC）に残り、
そこがちょうどAI需要の直撃点になっている。

## 2. 地域構造：なぜ中国・台湾なのか

```
      [プリント基板の生産、ざっくりの地理]

   中国本土  ██████████████████████████  金額ベースで世界の5割前後
   台湾(台湾企業の本国＋中国工場) ████████  技術リードと最大手企業群
   韓国      ████   パッケージ基板・FPCに強い（サムスン電機、LG系）
   日本      ███    高多層・パッケージ基板・FPC・材料に特化
   東南アジア ███    「China+1」で急拡大中（タイ、ベトナム、マレーシア）
   欧米      ██     少量・防衛・航空・医療などの特殊用途が中心
```

中国・台湾に集まった理由は、技術ではなく**産業の性格**にある。

1. **セットメーカーが近い**：スマホ・PC・家電の組立が中国に集中した。基板はカスタム品で
   設計変更の往復が多いので、**客の近くでないと商売にならない**
2. **湿式工程＝水と環境規制**：大量の水と廃液処理設備が要る。土地・水・電力・規制がセットで必要
3. **労働集約性が残る**：検査・ハンドリングに人手が要る工程が多い
4. **投資の連続性**：基板は設備更新を止めた瞬間に競争力を失う。市場が伸びる場所に投資が向かう

台湾企業（Zhen Ding／臻鼎、Unimicron／欣興、Nan Ya PCB など）は本社が台湾で、量産工場は中国に持つ、
という形が典型。近年は米中摩擦を受けて、タイ・ベトナムへの分散（China+1）が加速している。

## 3. 日本勢の立ち位置：量では負け、ポジションで残った

日本の基板産業は1990年代まで世界トップクラスだったが、価格競争で汎用品を失った。
生き残った領域は、**「設備と歩留まりノウハウが効き、客が品質で選ぶところ」**に偏っている。

| 領域                            | 日本勢の位置                       | 代表企業                                | なぜ残れたか                                                                  |
| ------------------------------- | ---------------------------------- | --------------------------------------- | ----------------------------------------------------------------------------- |
| **FC-BGAパッケージ基板**        | 世界トップクラス。寡占の一角       | イビデン、新光電気工業                  | 微細配線＋そり制御＋歩留まりが職人芸。客（Intel/NVIDIA等）が品質で選ぶ        |
| **高多層リジッド基板**          | 車載・産業・通信の高信頼領域に残存 | メイコー、CMK、京写 ほか                | 長期供給と品質保証が要求される分野                                            |
| **FPC・リジッドフレックス**     | 高シェア領域あり                   | 日本メクトロン（NOK）、住友電工、藤倉   | スマホ・車載の難易度が高い部位                                                |
| **基板材料（CCL・プリプレグ）** | 高グレード帯で強い                 | パナソニック、レゾナック、三菱ガス化学  | 低誘電樹脂の配合技術                                                          |
| **ガラスクロス**                | **特殊ガラスで事実上の寡占**       | 日東紡、旭化成                          | 低熱膨張Tガラス等は代替が効かない                                             |
| **銅箔・めっき薬品**            | 高機能帯で強い                     | 三井金属、上村工業 ほか                 | 微細配線向けの極薄・低粗度品                                                  |
| **コネクタ**                    | 高付加価値帯で上位                 | ヒロセ電機、日本航空電子、JST、ホシデン | デザインイン型のビジネス（[02_コネクタという商売](02_コネクタという商売.md)） |

> ポイント：日本勢の強さは「川上（材料）」と「最先端（パッケージ基板）」の**両端**にある。
> 真ん中の汎用量産は中国・台湾に渡した。これは[半導体材料](../04_半導体材料/README.md)や
> [半導体製造装置](../03_半導体製造装置/README.md)と同じ構図で、電機・電子分野の日本の典型パターン。

## 5. 材料メーカーがいちばん強い、という事実

基板業界を理解するうえで最も重要な事実は、**利益率が高いのは基板メーカーより材料メーカー**だということ。

```
 [付加価値の分布：AIサーバー向け基板を例に]

  ガラスクロス ──▶ CCL/プリプレグ ──▶ 基板メーカー ──▶ 実装(EMS) ──▶ サーバー
   日東紡ほか        パナソニック等      台湾・中国       鴻海等       NVIDIA等
   ┃ 代替困難         ┃ 配合ノウハウ      ┃ 設備＋歩留まり   ┃ 薄利      ┃
   ┗━ 供給制約で        ┗━ 値上げ転嫁      ┗━ 材料高の板挟み   ┗━ 量で稼ぐ
      価格決定力         しやすい            みになりやすい
```

- **代替が効かない材料ほど強い**。低熱膨張のTガラスは日東紡が世界シェア9割程度とされ、
  これが足りないとABF基板もハイエンドCCLも作れない（2026年の逼迫は[直近トピック](04_直近トピック_2026.md)を参照）
- 基板メーカーは材料を買う側なので、**材料が上がれば原価が上がる**。転嫁できるかは客の強さ次第
- したがってニュースを読むときは、「基板が足りない」のか「**材料が足りない**」のかを分けて読むと構図が見える

## 6. 競争要因（KSF）と参入障壁

| 分野                       | 勝ち筋                                           | 参入障壁                                           |
| -------------------------- | ------------------------------------------------ | -------------------------------------------------- |
| 汎用リジッド基板           | コストと納期。稼働率勝負                         | 低い。だから利益率も低い                           |
| 高多層・高速基板           | 層間の位置精度、インピーダンス制御、材料の扱い   | 中〜高。設備投資＋ノウハウ                         |
| パッケージ基板             | 微細配線、そり制御、歩留まり、客の認定           | **非常に高い**。認定に数年、投資は数千億円規模     |
| FPC                        | 曲げ寿命設計、量産歩留まり、客の機種サイクル対応 | 中〜高。客の集中リスクあり                         |
| 材料（ガラス・樹脂・銅箔） | 配合・製造ノウハウ、長期の実績                   | **非常に高い**。窯や設備の増設に数年               |
| コネクタ                   | デザインイン力、品番数、金型内製                 | 高い。ただし技術というより**顧客関係と品番の蓄積** |

共通して効くのは「**客の認定（クオリフィケーション）**」。
自動車も半導体も通信も、部材を切り替えるには試験と承認が必要で、年単位の時間がかかる。
これが不況でもシェアが動きにくく、好況でも新規参入が間に合わない理由である。

## 7. 業績の振れ方：何に連動するか

- **民生（スマホ・PC）向け**：モデルサイクルに連動。四半期でぶれる
- **車載向け**：自動車生産台数に連動。振れは小さいが成長も緩やか。EV化で単価は上昇
- **産業・FA向け**：設備投資サイクルに連動。[FA・制御機器](../14_FA・制御機器/README.md)と同じ波
- **サーバー・通信向け**：2024年以降はAI投資に連動。**いま最も振れ幅が大きく、最も伸びている**
- **材料**：上記すべての合算＋在庫循環。逼迫すると価格が跳ねる

基板メーカーは装置産業寄りで固定費が重く、**稼働率が数ポイント落ちると利益が大きく削れる**。
一方コネクタは固定費が相対的に軽く、品番分散が効くので、業績の底は堅い。
同じ「つなぐ部品」でも、損益の作りがかなり違う。

## 8. 用語メモ

- **Prismark**：プリント基板業界で広く参照される米調査会社。市場規模の出典としてよく引かれる
- **JPCA**：一般社団法人 日本電子回路工業会。国内生産統計を整理・公表
- **China+1**：生産の中国一極集中を避け、東南アジア等に分散する動き
- **ABF基板**：味の素ABFフィルムを使うビルドアップ型パッケージ基板。FC-BGAの主流
- **Tガラス**：熱膨張が小さい特殊ガラス繊維。パッケージ基板・高速CCLに必須
- **クオリフィケーション（認定）**：顧客が部材を正式採用するための試験・承認プロセス。年単位
- **インピーダンス制御**：高速信号が反射しないよう、配線幅と層構成で特性を揃える設計
- **CCL**：銅張積層板。基板の母材（[01_プリント基板の作られ方と種類](01_プリント基板の作られ方と種類.md)参照）
- **稼働率**：設備をどれだけ動かせているか。装置産業の利益を決める最大の変数
