# 直近トピック（2026年9月時点）

報道・調査会社レポートをもとにした整理。確定事実（企業の公式発表・IR）と、推計・報道を区別して書く。
数値は出典の年・時点を必ず添えた。最新はリンク先の一次情報で確認すること。

この1年でこの業界に起きたことを一言でまとめると、
**「AIサーバーがプリント基板と材料を食い尽くし、基板が半導体に次ぐボトルネックになった」**である。
コネクタ側でも同じことが起きていて、最大手の主戦場が自動車からデータセンターへ移った。

## 1. 基板材料（CCL・ガラスクロス）の逼迫が本格化

2026年に入り、プリント基板の母材である**銅張積層板（CCL）**と、その骨になる**ガラスクロス**の
供給逼迫が業界全体の制約になったと報じられている。

| 項目               | 内容                                                             | 時点・出典の種類                      |
| ------------------ | ---------------------------------------------------------------- | ------------------------------------- |
| CCL納期            | 通常8〜10週 → **20週超**に長期化                                 | 2026年、業界報道                      |
| Tガラス価格        | 供給制約で **20〜30%上昇**                                       | 2026年、業界報道                      |
| AIクラス基板の納期 | 高多層＋HDI＋特殊材料品で **12〜20週**、材料指定次第でさらに長期 | 2026年、業界メディア                  |
| 需給ギャップ       | Tガラスで**10%超の供給不足**との推計                             | 2026年、Counterpoint の推計として報道 |
| ガラスクロス全体   | **2028年まで**目立った緩和は見込みにくいとの見方                 | 2026年、業界報道                      |

逼迫しているのはガラスクロスだけではなく、銅箔、特定品番のプリプレグ（PP1080・PP2116 など）、
高性能樹脂、さらには穴あけドリル刃に使う**超硬（タングステンカーバイド）**にまで及んでいる、と報じられている。

```
 [どこが詰まっているのか：2026年の供給制約マップ]

  ガラスクロス  ████████████  ← 最大のボトルネック。増炉に数年、緩和は2028年ごろ
  銅箔          ███████       ← 極薄・低粗度品が不足
  高性能樹脂    ██████        ← M8/M9級の配合品
  CCL/プリプレグ ████████      ← 上の3つの合算として詰まる。納期20週超
  基板工場の設備 ████          ← 装置はあるが材料が来ない、という状態
  超硬ドリル刃  ███           ← 穴あけ量の激増で消耗品まで逼迫

  ※ 棒の長さは逼迫度合いの概念図（報道内容にもとづく筆者整理。統計値ではない）
```

> なぜここまで効くのか：基板の材料はどれも**認定済みの型番しか使えない**。
> 「別メーカーの同等品に切り替える」には客の再認定が要り、年単位かかる。
> だから物理的に代替が効かず、価格と納期にそのまま出る。
> 構造の説明は [プリント基板の作られ方と種類](01_プリント基板の作られ方と種類.md) の材料の章を参照。

## 2. 日東紡：Tガラスの独占的地位と増産判断

特殊ガラス繊維の**日東紡**は、低熱膨張の**Tガラス**で世界シェア9割程度、
低誘電の**NEガラス**でも6〜7割程度を握るとされる（2026年時点、調査会社推計・報道ベース）。
AIサーバー用パッケージ基板・高速CCLの事実上の関門になっている。

- 2024年5月ごろからTガラス需要が急増し、2025年度に在庫が尽きて供給がタイト化したと同社関係者が説明（業界紙インタビュー）
- 福島事業センターに**約150億円**を投じ、Tガラスクロスの生産能力を最大3倍へ増強、**2027年稼働**を目指すと報じられた
- 2026年後半には台湾拠点の増炉計画もあり、2028年度には現状比3倍程度の生産が可能になるとの見方

**ガラス溶解炉は増設に数年かかる**。だから需要が急に増えても、供給は数年遅れてしか来ない。
これが「2028年まで緩まない」と言われる理由である。

## 3. イビデン：FC-BGAパッケージ基板に3年で約5,000億円

2026年2月、**イビデン**は高機能ICパッケージ基板の生産能力増強に向け、
**2026〜2028年度の3年間で総額約5,000億円規模**の設備投資を計画すると発表した（同社公式発表）。

| 内容        | 詳細                                                                 |
| ----------- | -------------------------------------------------------------------- |
| 総額        | 3年で約5,000億円規模                                                 |
| 第1フェーズ | 河間事業場のCell 6 を中心に**約2,200億円**を投じて生産設備を追加     |
| 稼働時期    | **2027年度から順次**                                                 |
| 狙い        | 生成AI／AIサーバー向け高機能ICパッケージ基板（FC-BGA）の需要増に対応 |

背景には、AI向けパッケージがどんどん大型化・多層化していることがある。
大きく反りやすいパッケージを歩留まりよく作れる会社は世界に数社しかなく、
イビデン、新光電気工業、Unimicron、AT&S などに需要が集中している。
ICパッケージ基板市場は2026年前後に現状から倍増して**140〜150億ドル**規模になるとの見方も出ている（業界紙報道）。

技術的な位置づけは [半導体｜後工程](../02_半導体（ロジック・メモリ）/03_後工程.md) の先端パッケージの章と合わせて読むとよい。

## 4. 新光電気工業の非公開化：国策ファンドが先端基板を抱えた

富士通子会社だった**新光電気工業**（FC-BGA・リードフレーム大手）は、
産業革新投資機構（JIC）系のJICC-04によるTOBを経て非公開化された。

| 時期          | できごと                                                                                |
| ------------- | --------------------------------------------------------------------------------------- |
| 2023年12月    | JICキャピタルが1株5,920円でTOBを開始すると発表（買収総額は約8,000億円規模と報じられた） |
| 2025年2〜3月  | TOB実施。下限を上回る応募でTOB成立                                                      |
| 2025年6月ごろ | スクイーズアウトを経て非公開化の手続きへ                                                |
| 2026年        | 非上場の状態で、AI向けFC-BGAの増強を進める段階と報じられる                              |

注目点は、**政府系ファンドがパッケージ基板を「国が抱えるべき技術」と位置づけた**こと。
半導体そのものだけでなく、**チップを載せる基板も安全保障上の重要部材**という認識が定着した表れと読める。
上場を外れたことで、短期業績にとらわれない大型投資がしやすくなった一方、
情報開示が減り、外部から業況が見えにくくなった点は留意したい。

- Amphenol の2026年第2四半期は売上87.6億ドル・前年同期比55%増、IT datacom が43%を占め前年比89%増と報じられた
- AI関連の売上ランレートは**105〜110億ドル規模**に達したとされる（同社説明に関する報道）

## 6. AIサーバーが要求する基板の「次の世代」

- AIサーバーのPCBは、一般的なサーバーの**3〜5倍の層数**を使うとされる（2026年、業界報道）
- 1台のAIサーバーが消費する基板材料は、従来型サーバーの**10〜15倍**に達するとの試算もある
- 結果として、AI以外の用途（産業機器、FPGAボードなど）の納期と価格が押し上げられる
  「**AIによる吸い上げ（siphon effect）**」が起きていると指摘されている
- NVIDIAの次世代「Rubin」プラットフォームは2026年下期から量産予定とされ、
  高速伝送要求から**M9クラスCCL**とさらなる多層化への移行が迫られる、と報じられている

| 世代                   | 材料グレードの目安 | 典型的な層数 |
| ---------------------- | ------------------ | ------------ |
| 従来型サーバー         | M4〜M6             | 8〜16層      |
| 現行AIサーバー         | M7〜M8             | 20〜28層     |
| 次世代（2026年下期〜） | **M9クラス**       | 28層超も     |

この「層数インフレ」と「材料グレードインフレ」が同時に進むので、
**基板の単価は数量以上のスピードで上がる**。基板メーカーの売上が数量以上に伸びているのはこのため。

## 7. 生産地の分散（China+1）

米中摩擦と関税リスクを背景に、基板生産の東南アジアシフトが続いている。

- タイ、ベトナム、マレーシアでの新工場立ち上げが相次ぐ（台湾・中国系メーカーが主導）
- ただし新拠点は**認定取得と歩留まり立ち上げに時間がかかる**ため、
  逼迫の緩和にすぐには効かない
- 欧米では防衛・航空・医療用途を中心に「域内調達」志向が強まり、TTM など北米勢の受注が増えているとされる

## 8. 全体の構図（まとめ）

1. AIデータセンター投資が、半導体だけでなく**その下の基板・材料まで需要を引き上げた**
2. ボトルネックは基板工場よりも**上流の材料（ガラスクロス・CCL・銅箔）**にあり、増設に数年かかるため緩和は遅い
3. 日本勢は量産では中国・台湾に譲ったが、**材料（日東紡ほか）とFC-BGA（イビデン・新光電気）という
   置き換えの効かない位置**を押さえており、今回の需要をまともに受けている
4. コネクタも同じ波の上にあり、最大手の売上構成が自動車からIT datacom へ入れ替わった。
   値上げが通る珍しい局面になっている
5. リスクは明確で、**AI投資が一巡したときの反動**。層数・単価インフレで積み上がった売上は、
   需要が止まれば稼働率の急落に直結する。2026年時点では過熱と供給制約が同居している

## 9. 用語メモ

- **CCL**：銅張積層板。基板の母材。いま最も逼迫している部材のひとつ
- **プリプレグ（PP1080 / PP2116 など）**：層間に挟む半硬化シート。番号は織り方・厚みの規格
- **Tガラス／NEガラス**：低熱膨張・低誘電の特殊ガラス繊維。日東紡が高シェア
- **M4〜M9**：CCLの高速グレード（損失の小ささ）を示す業界慣用の世代呼称。数字が大きいほど高性能・高価
- **FC-BGA**：フリップチップBGA用パッケージ基板。AIチップの土台
- **JIC**：産業革新投資機構。経産省所管の官民ファンド。新光電気工業を非公開化した
- **IT datacom**：コネクタ業界でデータセンター・通信インフラ向けを指す区分
- **224G**：1レーンあたり224Gbps級の伝送。AIサーバー内接続の次世代規格帯
- **siphon effect**：AI向けが材料・生産能力を吸い上げ、他用途の納期・価格を悪化させる現象
