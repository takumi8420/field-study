1. 業界の定義・範囲

プリント基板（PWB/PCB）：絶縁板に銅の配線を形成した板。電子部品を載せ、互いをつなぐ土台。
コネクタ：機器・基板・ケーブルを着脱できる形で電気的につなぐ部品。

隣接業界との境界を明確にしておく。

5. 収益モデル・コスト構造

  • 基板：受注生産のカスタム品。材料費が原価の4〜6割、残りは設備償却と加工費。
    在庫でならせないため稼働率がそのまま利益になる。層数・微細度が上がるほど歩留まりが効く
  • コネクタ：1個数円〜数千円の部品を膨大な品番で売る。金型が資産。
    デザインインで採用されれば製品寿命の間、発注が続く。利益率は電子部品の中でも高水準
  • 材料：代替の効かない特殊材料ほど価格決定力が強い。増設に数年かかるので需給が締まりやすい

6. 競争要因（KSF）と参入障壁

  1. 顧客の認定（クオリフィケーション）：部材の切り替えには試験と承認で年単位。最大の障壁
  2. 歩留まりノウハウ：高多層・微細配線は設備を買っても即座には作れない
  3. 投資の継続力：パッケージ基板は1件で数千億円規模。体力が要る
  4. 品番の蓄積とデザインイン力（コネクタ）：技術より顧客関係と設計支援の厚み
  5. 上流の押さえ：材料・ガラスクロスを握る側が需給逼迫時に最も強い

7. 規制・法制度

  • 環境規制：めっき・エッチングの排水処理、六価クロム等の規制。工場立地を強く縛る
  • RoHS／REACH：鉛フリーはんだ・有害物質規制。材料選定と製造条件（リフロー温度）に直結
  • IATF 16949（車載品質）、UL規格（難燃性）：実質的な参入要件
  • 経済安全保障：先端パッケージ基板は国の重要部材と位置づけられ、
    新光電気工業の非公開化にはJIC（経産省所管の官民ファンド）が関与。
    半導体関連の国内投資支援（半導体・デジタル産業戦略）の対象にもなりうる
  • 通商：米中摩擦・関税リスクからChina+1（東南アジアへの分散）が進行

8. 最近のトピック

詳細は 04_直近トピック_2026。要点は5つ。

  1. 材料逼迫：CCLの納期が8〜10週から20週超へ、Tガラス価格は20〜30%上昇と報じられる（2026年）
  2. 日東紡：福島に約150億円でTガラスクロス能力を最大3倍へ、2027年稼働を目指す
  3. イビデン：AI向けFC-BGAに2026〜2028年度で約5,000億円投資（第1フェーズ約2,200億円）
  4. 新光電気工業：JIC主導のTOBを経て非公開化。パッケージ基板が国策部材に
  5. コネクタ：Amphenol の2026年2QはIT datacom が売上の43%・前年比89%増と報じられ、主戦場がクルマからAIへ
