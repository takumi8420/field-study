# プリント基板の作られ方と種類

**このノートで分かること**：プリント基板（PWB／PCB）とは何で、どんな種類があり、どういう順番で作られ、
なぜ「層数」と「材料」で値段が10倍も100倍も変わるのか。そして、なぜパッケージ基板だけが別格の世界なのか。

結論を先に言うと、プリント基板は「**絶縁板に銅の配線を印刷した、電子機器の土台**」である。
部品はそれ単体では動かず、必ずこの板の上に載って、板の中の銅配線でつながって初めて回路になる。
つまり基板は**電子機器の骨格であり、同時に配線そのもの**。ここが高速・高密度になれないと、
どれだけ高性能なチップを買ってきても性能が出ない。

---

## 1. プリント基板とは何か

昔の電子機器は、部品同士を職人が電線で1本ずつつないでいた。手間もかかるし、個体差も出る。
そこで「**板の上にあらかじめ配線の絵を焼き付けておき、部品はその上に載せるだけ**」にした。これがプリント基板。

- **プリント配線板（PWB）**＝部品がまだ載っていない裸の板。基板メーカーが作るのはこれ
- **プリント回路板（PCA/PCBA）**＝部品を実装（はんだ付け）した状態。実装業者／EMSの領域。日本語では両方まとめて「プリント基板」「基板」と呼ぶことが多い

板の正体は、**ガラス繊維の布に樹脂を染み込ませて固めた絶縁板**に**銅の薄い膜**を貼ったもの。
この銅を必要な形だけ残し、いらない部分を薬品で溶かすと配線になる（エッチング）。

```
       [断面のイメージ：両面板]

   ┌─ 銅パターン（配線）
   │      ┌─ スルーホール（表裏をつなぐ、めっきされた穴）
   ▼      ▼
 ━━━━━━  ◎  ━━━━━━   ← 表面の銅箔
 ▓▓▓▓▓▓▓▓║▓▓▓▓▓▓▓▓   ← 絶縁層（ガラス布＋樹脂）
 ━━━━━━  ◎  ━━━━━━   ← 裏面の銅箔
```

## 2. 種類：3つの軸で整理する

基板の種類は「①硬さ」「②層数」「③配線の細かさ」の3軸で見ると混乱しない。

### 2-1. 硬さの軸

| 種類                        | 中身                                                 | 使われるところ                                                             | 価格感           |
| --------------------------- | ---------------------------------------------------- | -------------------------------------------------------------------------- | ---------------- |
| **リジッド基板**            | 硬い板。ガラス布＋エポキシ樹脂（FR-4）が標準         | PC、サーバー、家電、産業機器の主基板                                       | 標準             |
| **フレキシブル基板（FPC）** | ポリイミド（耐熱フィルム）＋銅箔。曲がる・折り畳める | スマホの折り曲げ部、カメラモジュール、ディスプレイ接続、車載配線の置き換え | リジッドより高い |
| **リジッドフレックス**      | 硬い部分と曲がる部分を一体で作る                     | スマホ、ウェアラブル、カメラ、医療機器、航空宇宙                           | さらに高い       |
| **メタルコア／セラミック**  | 金属板やセラミックを芯にして放熱を稼ぐ               | LED照明、パワー半導体モジュール、車載インバータ                            | 用途特化         |

> FPCが高いのは、素材（ポリイミド）が高いだけでなく、**曲げても割れない配線設計**と
> 実装時のハンドリングが難しいから。単なる「柔らかい基板」ではなく、信頼性商品である。

### 2-2. 層数の軸

層数＝絶縁層と銅配線を何段重ねたか。配線が増えれば層を増やすしかない。

| 層数             | 呼び方                | 典型用途                             | 目安                       |
| ---------------- | --------------------- | ------------------------------------ | -------------------------- |
| 1層              | 片面板                | 電源アダプタ、単純な家電、リモコン   | 最も安い                   |
| 2層              | 両面板                | 汎用の民生機器                       | 安い                       |
| 4〜8層           | 多層板                | PC、家電、車載ECU の大半             | 普及帯                     |
| 10〜16層         | 高多層板              | サーバー、通信機器、基地局           | 高付加価値                 |
| 18〜30層超       | 超高多層板            | AIサーバー、スイッチ、ハイエンド通信 | 数量は少ないが単価が別次元 |
| （層数とは別軸） | **HDI／ビルドアップ** | スマホ主基板、ウェアラブル           | 微細化商品                 |

層を増やすと難しくなる理由は単純で、**何層も重ねてから穴を開けてつなぐので、1枚でもズレたら全部不良**になるから。
層数が増えるほど工程が増え、歩留まり（良品率）が落ち、検査も増える。単価は層数に対して直線ではなく**曲線的に上がる**。

## 3. 材料：銅張積層板とプリプレグ

基板の原価と性能は、実は**材料メーカーが握っている**。基板メーカーは材料を買ってきて加工する立場に近い。

| 材料                  | 何か                                              | 役割                                                                | 主なメーカー（例）                                                 |
| --------------------- | ------------------------------------------------- | ------------------------------------------------------------------- | ------------------------------------------------------------------ |
| **銅張積層板（CCL）** | 絶縁板の両面に銅箔を貼った「素板」                | 基板の母材そのもの                                                  | パナソニック、レゾナック、三菱ガス化学、台湾EMC、台湾TUC、中国建滔 |
| **プリプレグ（PP）**  | ガラス布に樹脂を半硬化状態で染み込ませたシート    | 層と層の間に挟み、熱と圧力で固めて接着する「のり兼絶縁層」          | 同上                                                               |
| **ガラスクロス**      | プリプレグの骨になるガラス繊維の布                | 寸法を安定させる。Tガラス／NEガラスなど低膨張・低誘電の特殊品がある | 日東紡、旭化成、ニッタイ（台湾）                                   |
| **銅箔**              | 配線になる薄い銅の膜（厚さ12〜35µm程度）          | 細かい配線を作るには表面が平滑で薄い箔が要る                        | 三井金属、福田金属、古河電工                                       |
| **ABFフィルム**       | 味の素製の絶縁フィルム（Ajinomoto Build-up Film） | パッケージ基板のビルドアップ層に使う。事実上の世界標準              | 味の素ファインテクノ                                               |
| **ソルダーレジスト**  | 表面を覆う緑色の膜                                | はんだが不要な場所に流れないようにする・配線を保護する              | 太陽ホールディングス ほか                                          |

### なぜ「低誘電材料」が騒がれるのか

信号が速くなると、絶縁層の樹脂が**信号のエネルギーを熱として食ってしまう**（誘電損失）。
食われると波形がなまり、遠くまで届かない。だから高速品では、損失の小さい樹脂とガラスに置き換える。
業界ではこのグレードを **M4 / M6 / M7 / M8 / M9** のように世代で呼び、世代が上がるほど
材料は高く、加工も難しく、供給者も限られる。AIサーバー向けはこの上位グレードに集中している。

## 4. どう作るか：多層板の工程フロー

```
CCL投入
  │
  ├▶ ① 内層回路形成（露光→エッチング）……内側の層の配線を作る
  │
  ├▶ ② 黒化処理 ……銅の表面を荒らして接着力を上げる
  │
  ├▶ ③ 積層プレス ……内層板＋プリプレグ＋銅箔を重ね、高温高圧で一体化
  │
  ├▶ ④ 穴あけ（ドリル／レーザー）……層をまたぐ縦の道を開ける
  │
  ├▶ ⑤ デスミア→無電解めっき→電気銅めっき ……穴の内壁を銅で覆い、上下を導通させる
  │
  ├▶ ⑥ 外層回路形成 ……表面の配線を作る
  │
  ├▶ ⑦ ソルダーレジスト塗布・露光 ……緑の保護膜。部品を載せる場所だけ開ける
  │
  ├▶ ⑧ 表面処理（金めっき／OSP／はんだレベラー）……はんだが濡れるようにする
  │
  ├▶ ⑨ 外形加工（ルーター／レーザー）……板の形に切り出す
  │
  └▶ ⑩ 電気検査（フライングプローブ／専用治具）＋外観検査（AOI）→ 出荷
```

工程の性格をつかむポイントは次の3つ。

1. **湿式工程が主役**：めっき・エッチングなど薬液工程が中心。水と廃液処理が必須で、環境規制と用地の制約が強く効く（基板工場が日本から出ていった一因）
2. **穴が勝負**：層をつなぐのは穴（ビア）だけ。1枚に数万〜十数万穴を開けるため、**加工時間とドリル刃の消耗がコストを支配**する
3. **まとめて作る**：小さい基板は大判ワーク（例：510×410mm）に何十個も並べて（面付け）同時に作る。原価は「**面付け数をいくつ取れるか**」でほぼ決まる

## 5. ビルドアップ工法とHDI：スマホが薄くなった理由

従来の多層板は「先に全層を重ねてから、上から下まで貫通する穴を開ける」（貫通スルーホール）。
この穴は太く（φ0.2〜0.3mm）、しかも**表から裏まで貫くので、通り道の全層で場所を食う**。

そこで「1層ずつ積み上げながら、レーザーで浅い穴だけ開ける」やり方が生まれた。これが**ビルドアップ工法**。
浅い穴を**ブラインドビア**（片側だけ開いた穴）と呼び、φ0.05〜0.1mmまで小さくできる。
こうして高密度化した基板を **HDI（High Density Interconnection）基板**という。

```
 [貫通スルーホールのみ]            [ビルドアップ／HDI]

  ●━━━━━━━━━━●              ┌─ビルドアップ層（レーザービア）
  ┃  全層を貫く   ┃              ○  ○   浅い穴で済む
  ┃  太い穴が     ┃          ━━━━━━━━━━  ← コア層（貫通穴あり）
  ┃  全層の場所を ┃              ○  ○
  ●━━━━━━━━━━●              └─ビルドアップ層

   配線を通せる面積が減る          表層に配線を密集させられる
```

微細さの指標が **L/S（ライン／スペース）**＝配線の幅と、配線どうしの隙間。単位はµm（マイクロメートル）。

| 区分                           | L/S の目安           | どこで使うか                         |
| ------------------------------ | -------------------- | ------------------------------------ |
| 一般のリジッド多層板           | 100/100µm 〜 75/75µm | 産業機器、車載ECU                    |
| HDI（スマホ主基板）            | 40/40µm 〜 25/25µm   | スマートフォン、ウェアラブル         |
| パッケージ基板（ビルドアップ） | 10/10µm 前後         | FC-BGA、CPU/GPU用                    |
| 先端パッケージ基板／再配線層   | 5/5µm 以下           | AI向け大型パッケージ、インターポーザ |

L/Sが細くなるほど、露光装置・めっき・クリーン度の要求が半導体前工程に近づく。
「基板屋」と「半導体屋」の境界が溶けていくのは、この微細化競争の結果である。

## 6. パッケージ基板：同じ「基板」でも別格の世界

**パッケージ基板（ICパッケージ基板）**は、半導体チップを直接載せるための極小・極微細な基板。
半導体の[後工程](../02_半導体（ロジック・メモリ）/03_後工程.md)で使われる部材で、
一般のプリント基板とは工場も設備も客も別物と考えてよい。

なぜ必要か。チップ側の端子は数µm間隔だが、マザーボード側は1mm間隔。この**桁違いの差を橋渡しする変換器**が要る。
その役割を担うのがパッケージ基板であり、代表格が **FC-BGA**（フリップチップBGA）。

| 一般のリジッド多層板                 | パッケージ基板（FC-BGA）                                    |
| ------------------------------------ | ----------------------------------------------------------- |
| L/S 100〜50µm                        | L/S 10µm前後、先端は数µm                                    |
| 材料はFR-4系のプリプレグ             | **ABFフィルム**（味の素）＋低熱膨張コア                     |
| 穴はドリル＋レーザー                 | レーザービアが主体、コアレス品もある                        |
| サイズは大きく、精度要求は中程度     | サイズは数十mm角だが、**そり（ワーページ）0.1mm単位**の戦い |
| 客は電機・車載・通信のセットメーカー | 客は半導体メーカー（Intel、NVIDIA、AMD 等）とOSAT           |
| 中国・台湾が量産の主戦場             | **日本・台湾・オーストリアの少数社が寡占**                  |

先端AIチップでは、パッケージがどんどん大きくなっている（レチクルサイズの数倍）。
大きくなるほど**熱で反る**ため、反りを抑える低膨張材料と設計が効く。
ここで [半導体材料](../04_半導体材料/README.md) の供給力がそのままボトルネックになる。

> ポイント：AIサーバーの供給制約が「基板が足りない」と語られるとき、
> 指しているのは**FC-BGAパッケージ基板**と**高多層のマザーボード**という、まったく別の2つである。
> ニュースを読むときはどちらの話か必ず区別する。

## 7. 実装（SMT）との関係：基板は「半製品」である

基板メーカーが出荷するのは裸の板であって、そのままでは製品にならない。
次の工程が**実装（SMT：表面実装）**で、部品を載せてはんだ付けする。担い手はセットメーカーの自社ラインか、EMS（電子機器受託製造）。

```
[基板メーカー]        [部品メーカー]            [EMS／セットメーカー]
リジッド/FPC   ──┐    コネクタ・抵抗・コンデンサ
パッケージ基板   ├──▶ ─── 半田印刷 ──▶ マウンタで部品搭載 ──▶ リフロー炉で加熱溶融
                 │                     ──▶ 検査(AOI/X線) ──▶ 筐体組立 ──▶ 完成品
[半導体メーカー]─┘
   チップ（パッケージ済み）
```

基板の設計は実装を前提にして決まる。たとえば、

- 部品を置くパッドの大きさ・間隔は、マウンタの精度とはんだの量で決まる
- BGAのような裏面端子の部品は、はんだ付けを目視できないので**X線検査**が前提になる
- 反った基板は部品が浮いて不良になる。だから基板側の**平坦度**が実装の歩留まりを左右する

つまり基板メーカーの品質問題は、自社工場ではなく**客の実装ラインで顕在化する**。
これが「一度採用された基板メーカーを簡単には変えられない」構造をつくる。詳しくは
[コネクタという商売](02_コネクタという商売.md) の「デザインイン」の節と同じ論理である。

## 8. コスト構造：何で値段が決まるか

| コスト要素                      | 内訳のイメージ                             | 効いてくるところ                               |
| ------------------------------- | ------------------------------------------ | ---------------------------------------------- |
| 材料費（CCL・プリプレグ・銅箔） | 原価の4〜6割。高グレード品ほど比率が上がる | 材料値上げが直撃する。2026年はここが逼迫       |
| 加工費（ドリル・めっき・露光）  | 設備の減価償却と電力・薬液                 | **稼働率商売**。装置を止めると赤字             |
| 歩留まり損                      | 層数・微細度が上がるほど悪化               | 高多層品の利益はここで決まる                   |
| 検査・保証                      | 車載・医療は検査工程が厚い                 | 単価に反映できれば高付加価値、できなければ重荷 |

重要なのは、基板は**カスタム品**だということ。型番ごとに設計が違い、在庫で持てず、**受注してから作る**。
したがって需要変動がそのまま稼働率に出るし、少量多品種の試作（売りはリードタイム）と量産（売りは単価）は
まったく別のビジネスになる。設計データ（ガーバーデータ）を預かる関係上、顧客の乗り換えコストも高い。

## 9. 用語メモ

- **PWB / PCB**：Printed Wiring Board（裸板）／Printed Circuit Board。日本語ではまとめて「プリント基板」
- **CCL（銅張積層板）**：絶縁板の両面に銅箔を貼った基板の母材。Copper Clad Laminate
- **プリプレグ**：ガラス布に樹脂を半硬化状態で含浸させたシート。層間の接着＋絶縁を担う
- **FR-4**：ガラス布＋エポキシ樹脂の標準グレード。汎用リジッド基板の代名詞
- **FPC**：フレキシブルプリント配線板。ポリイミド基材で曲がる
- **HDI**：高密度配線基板。レーザービアとビルドアップで微細化したもの
- **ビア**：層と層をつなぐ穴。貫通＝スルーホール、片側だけ＝ブラインドビア、内層のみ＝ベリードビア
- **L/S（ライン/スペース）**：配線幅／配線間隔。µm単位。小さいほど高難度
- **ソルダーレジスト**：基板表面の保護膜（一般的に緑色）。はんだの流れを制御する
- **面付け**：大判のワークに小さい基板を並べて同時に作ること。原価を左右する
- **AOI**：自動外観検査（Automated Optical Inspection）
- **FC-BGA**：フリップチップBGA用パッケージ基板。CPU/GPU向けの本命
- **ABFフィルム**：味の素製のビルドアップ用絶縁フィルム。パッケージ基板の事実上の標準材料
- **低誘電材料（Low-Dk/Low-Df）**：高速信号の損失を減らす樹脂・ガラス。M6〜M9などの世代で呼ばれる
- **SMT / EMS**：表面実装技術／電子機器受託製造サービス。実装・組立を請け負う（鴻海、Jabil など）
