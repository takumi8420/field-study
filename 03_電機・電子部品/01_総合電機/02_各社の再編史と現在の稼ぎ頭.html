2. 日立製作所：17年かけた「全部売る」改革

2-1. 再編史

時期 出来事
2009年3月期最終赤字7,873億円（当時の製造業で過去最大）。改革の起点
2010年代前半薄型テレビ自社生産撤退、HDD（日立GST）をWDへ売却、中小型液晶をJDIへ
2010年代後半日立工機・日立国際電気を売却、日立物流・日立キャピタルを手放す
2020〜2021年ABBの送配電事業を買収（日立エナジー）、GlobalLogicを約1兆円で買収（デジタル人材）
2022〜2023年上場子会社を全て整理（日立金属→プロテリアル、日立建機を持分法へ）
2025年4月新経営計画 「Inspire 2027」：Lumada売上比率50%、調整後EBITA率13〜15%、ROIC 12〜13%を目標
2026年4月家電事業をノジマへ売却契約（新会社株式80.1%を約1,100億円、2027年3月期中完了予定）。あわせて5,000億円の自社株買いを発表

「最後の非中核事業」が白物家電だったと報じられた。

3. 東芝：不正会計から分割案、そして非上場化

3-1. 再編史

2015 会計不正の発覚（インフラ工事の損失先送り）
  │
2016-17 ウェスチングハウス（米原子力子会社）で巨額損失 → 債務超過の危機
  │      医療機器(東芝メディカル)をキヤノンへ、白物家電を美的(Midea)へ売却
  │
2018 半導体メモリ事業を分離・売却 → 東芝メモリ（現 キオクシア）
  │      ※ 6,000億円増資で上場は維持したが、稼ぎ頭を失った
  │
2021-22 「3分割案」→「2分割案」→ 撤回。物言う株主との攻防
  │
2023.12 日本産業パートナーズ(JIP)連合による買収で **上場廃止（非上場化）**
  │
2024-26 「東芝再興計画」：3コア事業（エネルギー／デジタルインフラ／デバイス&ストレージ）へ集中
  │      キオクシア株を段階的に売却（2026年3月に19.6%、同年9月に12.84%へ低下と報道）
  ▼
2028年度以降 **再上場を目指す**（最短。報道ベース）

3-2. 現在の稼ぎ頭

  • FY2025（2026年3月期）の純利益は前期比約7倍の1兆9,673億円で過去最高（時事通信報道）。
    ただしこれは本業の力ではない。キオクシア株の売却益・評価益など
    「キオクシア関連利益」が2兆2,770億円あり、営業外の一過性要因が大半を占める。
  • 本業を見る指標は売上高営業利益率（ROS）で8.1%（会社発表、過去最高）。
    FY2026には全社ROS 10%を掲げる。
  • セグメント別では デバイス&ストレージ（HDD・パワー半導体）が好調。
    AIデータセンター向けの大容量HDD（ニアラインHDD）需要が追い風。
    エネルギー（送変電、火力・水力、原子力）とデジタルインフラ（鉄道、産業、防衛）も伸長。

読み方の注意：東芝の「過去最高益」は、ほぼキオクシア株の話。
一過性利益と本業利益を分けて読む練習にちょうどよい題材。

4. 三菱電機：捨てるものを早めに捨て、強い分野に居座った

4-1. 再編史

他の6社に比べて派手な再編が少ないのが特徴。2000年代前半にテレビの海外生産・携帯電話・PC・
汎用DRAM（→エルピーダへ）から早期に退き、FA・空調・昇降機・電力・宇宙防衛という
「日本で勝てる重い分野」に絞った。2021〜22年の品質不正（鉄道用空調の検査不正など）で経営陣が刷新され、
その後は不採算事業の整理と、「循環型デジタル・エンジニアリング」を掲げたデータ活用型の成長戦略へ移行している。

4-2. 現在の稼ぎ頭（FY2025、会社発表）

インフラ1兆4,634億円1,547億円電力システム、交通、宇宙・防衛。再エネ・DC増設が追い風

5. パナソニックHD：家電の会社から、電池と現場インフラの会社へ

5-1. 再編史

時期 出来事
2008〜11年三洋電機を買収・完全子会社化（電池と太陽電池が狙い）。社名を松下電器からパナソニックへ
2012年前後液晶・プラズマパネルで巨額損失。テレビ事業を縮小
2017年〜テスラ向け車載電池（米ネバダ州ギガファクトリー）に集中投資
2020年半導体事業をヌヴォトン（台湾）へ売却
2021年米Blue Yonder（サプライチェーンソフト）を約7,000億円超で買収 → コネクト部門の中核
2022年持株会社制へ移行（パナソニック ホールディングス）
2025年グループ経営改革を発表。白物・空調・照明を束ねていた事業会社「パナソニック」を解体し3社に分割。国内外で1万人規模の人員削減を打ち出す
2026年構造改革は「予定通り完了」と発表。ただし削減規模は1万2,000人に拡大、構造改革費用も1,500億円→1,800億円へ増えたと報じられる。テレビは欧州で中国スカイワース（Skyworth）と包括提携

6. ソニーG：もはや電機ではない（エンタメ＋センサー）

6-1. 再編史

2000年代にテレビとPC（VAIO）で長期低迷。2012年の平井体制以降、PC売却・テレビの分社化・スマホ縮小と
ハードを絞り込み、音楽・映画・ゲームのIP（知的財産）とネットワークサービスへ重心を移した。
同時にCMOSイメージセンサー（スマホのカメラの目）へ集中投資し、世界首位級を確保。

2025年9月29日、金融事業をパーシャルスピンオフで分離上場（ソニーフィナンシャルグループ、東証プライム、
直接上場、初値205円）。日本初の「パーシャルスピンオフ税制」適用事例。
これによりソニーGは金融を連結から外し、エンタメ＋半導体の会社としての姿が明確になった。

6-2. 現在の稼ぎ頭（FY2025）

分野 内容
ゲーム&ネットワークサービス（G&NS）PlayStation。本体販売よりもPS Plus等のネットワークサービスとソフトが利益源
音楽ソニーミュージック。ストリーミングの成長で大幅増収増益。レーベル＋出版（著作権）の二階建て
映画制作・配給。他社配信向けの制作受託も
I&SS（イメージング&センシング・ソリューション）CMOSイメージセンサー。スマホ向け中心、車載へ拡大
ET&Sテレビ・カメラ・オーディオ。縮小均衡で利益は確保
全社売上高12兆4,796億円（+3.7%）、営業利益1兆4,475億円（+13.4%、過去最高）

ソニーの利益構造は「著作権とプラットフォーム」。
音楽は一度作った原盤・楽曲が何十年も収益を生む（在庫も工場も要らない）。
電機メーカーの損益計算書とは根本的に別物。
→ ゲーム、音楽、半導体（ロジック・メモリ）

8. 「同じ業界名でも収益源が全く違う」総まとめ

社名 利益を生む根本的な仕組み 需要が反応する対象
日立長期のインフラ案件＋その保守・データ運用世界の送電網投資、鉄道投資、国内DX予算
東芝設備の受注生産＋ストレージ部品の市況電力設備投資、AIデータセンターのHDD需要
三菱電機機器の量産販売＋保守（昇降機・空調）ビル建設、設備投資サイクル、防衛予算
パナソニックHD電池の量産（稼働率勝負）＋電材のシェア＋ソフトのサブスクEV販売、住宅着工、物流IT投資
ソニーG著作権とネットワーク課金＋センサーの量産音楽ストリーミング、ゲーム課金、スマホ販売
NEC人の稼働で稼ぐ受託開発＋長期保守官公庁・金融のIT予算
富士通同上（国内＋欧州）同上＋欧州公共IT

利益の出方がこれだけ違うということは、同じニュースでも効き方が真逆になる。
例：円安 → 輸出比率の高いソニー・日立にはプラス、輸入部材の多い国内向け事業には原価増。
例：AI投資ブーム → 日立（送配電）・東芝（HDD）・ソニー（センサー）にプラス、家電事業には無関係。
