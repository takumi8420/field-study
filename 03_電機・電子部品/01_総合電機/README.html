最初に断っておくこと
「総合電機」は、2026年時点ではもはや業界名ではなく“出自の名前”である。
日立・東芝・三菱電機・パナソニック・ソニー・NEC・富士通の7社は、
かつて似た事業構成（重電＋家電＋通信＋半導体＋コンピュータ）を持っていたが、
現在の収益源は全く違う。日立はインフラとIT、ソニーはエンタメと半導体、
パナソニックは電池と住宅設備、NEC・富士通はITサービス、東芝はエネルギーとストレージの会社である。
したがって本フォルダでは 「総合電機の市場規模は◯兆円」という一本の物差しを作らない。
各社を同じ物差しで比べないことが、この業界を理解する最初の一歩になる。

このフォルダの読み方

「総合電機」を産業としてではなく、ひとつの経営史・ポートフォリオ論の教材として理解するノート群。
「なぜフルセット型が壊れたのか → 各社がどこへ行ったのか → その背後の理屈 → 直近の動き」の順に読む。

1. 業界の定義・範囲

総合電機＝重電（発電機・変圧器・送配電など大電力の設備）から
家電（テレビ・冷蔵庫・洗濯機）まで、電気に関わる製品を幅広く手がけてきた大手メーカーの総称。
対象は通常、次の7社（東芝を含めて「電機大手8社」と数える集計ではシャープを加えることもある）。

6. 競争要因（KSF）と参入障壁

KSF（成功の鍵）

  1. 事業を選ぶ勇気と速さ：ノンコアを抱え続けるほどディスカウントが深まる
  2. 供給が逼迫している重い資産を持っているか：変圧器、HDD、センサー、電池。
    増産に2〜3年かかるものは価格が通る
  3. 納めた後で稼げるか：保守契約・遠隔監視・データ活用。ここが粗利の源泉
  4. 大型案件のリスク管理：原子力・海外プラント・大型システム開発。
    1件の見積もり誤りが数百億〜兆円の損失になる（東芝・ウェスチングハウスの教訓）
  5. ソフトウェアの内製力：GlobalLogic（日立）、Blue Yonder（パナソニック）のように
    買ってでも確保する動きが続く
  6. 資本規律：ROIC > WACC を事業ごとに問い続ける仕組み

参入障壁

障壁 強さ 理由
機器の組み立て弱EMSに委託できる。ここだけなら誰でも入れる
電力インフラの実績と認証強送配電設備は事故が許されず、数十年の納入実績が前提になる
量産デバイスの投資額強工場1棟で数千億円。稼働率が落ちれば即赤字
官公庁・金融のシステム強過去のシステムを知っている会社が強い（乗り換えコストが極めて高い）
IP（楽曲・ゲーム）強買うしかない。時間では作れない
家電弱中国勢が量とスピードで圧倒。だから各社が手放した
