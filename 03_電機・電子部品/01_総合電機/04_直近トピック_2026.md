## 1. AI・データセンター需要が、電機大手の最大の追い風になった

2025〜2026年の電機業界で**最も効いている単一の要因**。
ただし効き方は社によって全く違う。

| 社                 | 効いている場所                                                         | 直近の数字                                                                           |
| ------------------ | ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| **日立**           | 日立エナジー（送配電）。変圧器・HVDC                                   | 2026年4〜6月期は全社売上収益**+20%**、パワーグリッドが**+37%**（欧州の大型HVDC案件） |
| **東芝**           | デバイス&ストレージ。大容量HDD（ニアライン）                           | FY2025のROS **8.1%**（過去最高、会社発表）。HDD好調が牽引                            |
| **三菱電機**       | インフラ（電力システム）、FA（半導体・サーバ設備投資）                 | インフラ 売上1兆4,634億円／営業益1,547億円。FAは営業益**+298億円**の766億円へ回復    |
| **ソニーG**        | イメージセンサー（AI用途は限定的だが半導体需給全般が堅調）             | FY2025 営業利益**1兆4,475億円**（過去最高）                                          |
| **パナソニックHD** | エナジー：**データセンター向けリチウムイオン電池セル**の国内ライン拡充 | セグメント営業益697億円                                                              |
| **NEC・富士通**    | 国内DX予算、データセンター関連のシステム需要                           | NEC営業益3,599億円（+40%）／富士通3,483億円（+31%）                                  |

```
【AI需要が電機に届く経路】

  AIサーバ増設
      │
      ├─▶ 電力が足りない ──▶ 送配電網の増強 ──▶ 変圧器・HVDC ──▶ 日立エナジー
      │                                            ▲ 納期2〜3年待ちと報じられる
      │
      ├─▶ データを貯める ──▶ 大容量HDD ──────────▶ 東芝
      │
      ├─▶ 電源のバックアップ ▶ 蓄電池・UPS ────────▶ パナソニック、他
      │
      └─▶ 工場で作る装置 ──▶ 半導体・実装設備投資 ──▶ 三菱電機FA、電子部品各社
```

> 日本の総合電機にとっては**電力インフラの話**として届いている。
> 東京電力HDは今後10年で**11兆円超**（従来計画の約1.5倍）の投資計画を示したと報じられ、
> 電力8社がデータセンター向けに全国30カ所で送電網を増強するとの報道もある。

## 2. 日立が家電事業をノジマへ売却（2026年4月）——「脱家電」の完了

**2026年4月21日**、日立製作所は子会社・日立グローバルライフソリューションズ（GLS）の
**家電事業を新会社に分離し、その株式80.1%をノジマ傘下のSPCへ約1,100億円で譲渡**する契約を締結した
（残り19.9%は日立GLSが継続保有。完了は2027年3月期中の予定）。

- あわせて、日立ブランドの海外家電を手がけていた**トルコ・アルチェリク（Arçelik）との合弁会社の株式を
  日立が全て取得し、新会社に統合**する。国内外の家電を1つにまとめてから渡す形
- 売却後の**日立GLSには業務用空調機器事業（清水事業所が中核）が残る**
- 対象人員は**約7,000人規模**と報じられる
- 日立は同時に**5,000億円の自社株買い**を発表

> **なぜ今か**：日立の事業選別基準は、報道ベースでは「**Lumada（データで稼ぐ仕組み）に乗るか否か**」。
> 白物家電は消費者向けの売り切りビジネスで、そのロジックに乗らなかった。
> 2009年3月期の最終赤字7,873億円から始まった構造改革の、**17年越しの集大成**と位置づけられている。
> → [白物家電](../09_白物家電/README.md)、[③ 事業ポートフォリオ経営](03_事業ポートフォリオ経営.md)

**買い手側の論理も面白い**：ノジマは家電量販店。メーカー機能を持つことで
**SPA（製造小売）化**を狙うと分析されている。
「メーカーが小売に売る」構図が「小売がメーカーを持つ」構図に反転した事例。

## 3. 東芝：本業ROS 8.1%、純利益1.97兆円——ただし大半はキオクシア

2026年3月期（FY2025）、東芝の**純利益は前期比約7倍の1兆9,673億円**で過去最高
（2026年5月15日発表、時事通信ほか）。

| 項目                    | 数値                                                   | 注意点                                                                 |
| ----------------------- | ------------------------------------------------------ | ---------------------------------------------------------------------- |
| 純利益                  | **1兆9,673億円**（前期比約7倍）                        | うち**キオクシア関連利益が2兆2,770億円**（売却益・評価益）。**一過性** |
| 売上高営業利益率（ROS） | **8.1%**（過去最高）                                   | こちらが本業の実力。FY2026は**全社ROS 10%**を目標                      |
| キオクシア保有比率      | 2026年3月に**19.61%**、同年9月に**12.84%**へ低下と報道 | 筆頭株主はベインキャピタル運営のSPCへ交代                              |
| 再上場                  | **最短で2028年度**を目指すと報じられる                 | 2023年12月にJIP連合の買収で上場廃止                                    |

好調なのは **デバイス&ストレージ（HDD、パワー半導体）／エネルギー（送変電、火力・水力、原子力）／
デジタルインフラ（鉄道、産業システム、防衛）** の3コア。

> **読み方の練習**：「東芝が過去最高益」という見出しだけを見て
> 「本業が絶好調」と受け取ると誤る。**営業利益と純利益を分けて読む**典型例。

## 4. パナソニックHD：構造改革は「完了」、ただし規模は拡大

2026年3月期は**減収減益**（売上収益8兆487億円、営業利益2,364億円、当期利益約1,895億円）。
構造改革費用が重石となった。

- 2025年に打ち出した**国内外1万人規模の人員削減**は、
  希望退職の応募が想定を上回り**1万2,000人規模に拡大**、
  構造改革費用も**1,500億円→1,800億円**へ膨らんだと報じられる
- 会社は「グループ構造改革は**予定通り完了**」と説明。FY2028までに累計3,000億円超の収益改善を見込む
- 組織面では、白物・空調・照明を束ねていた事業会社「パナソニック」を**解体して3社に分割**
- **テレビ事業は欧州市場で中国スカイワース（Shenzhen Skyworth Display Technology）と包括的パートナーシップ**を締結。
  自前での世界展開から撤退方向

```
【FY2025 セグメント営業利益（億円）】

  コネクト           ■■■■■■■■■■  1,000
  エナジー           ■■■■■■■        697
  エレクトリックワークス ■■■■■■          576
  インダストリー      ■■■■            404
  HVAC&CC            ■■              231
  スマートライフ      ▲373  ←── 唯一の赤字（白物家電・テレビ・美容）
```

> **構図**：「パナソニック＝家電」というイメージと実際の収益源のズレが、2026年決算で最も鮮明になった。
> 利益を出しているのは**業務用ソフト（Blue Yonder）・電池・配線器具**という地味なBtoB事業。

## 5. NECが富士通を売上・営業利益の両方で逆転（2026年3月期）

2026年4月28日、NECと富士通がともにFY2025決算を発表。

| 項目     | NEC                         | 富士通              | 差                                     |
| -------- | --------------------------- | ------------------- | -------------------------------------- |
| 売上収益 | **3兆5,827億円**（+5%）     | 3兆5,029億円（▲1%） | NECが約800億円上回る                   |
| 営業利益 | **3,599億円**（+40%）       | 3,483億円（+31%）   | NECが上回る                            |
| 純利益   | 2,702億円（+54%、過去最高） | **4,494億円**       | 富士通が上回る（**事業売却益による**） |

- 富士通の純利益が大きいのは、**新光電気工業（半導体パッケージ）や
  ゼネラル（旧・富士通ゼネラル、空調）の売却益**が乗ったため。**翌期には剥落する**
- 富士通のITサービス海外事業は売上3,335億円／営業利益317億円、**利益率9.5%**へ改善
  （欧州3社の改善が他の不採算案件を吸収したと説明されている）
- 両社とも**2025年度を最終年度とする中期経営計画の目標を達成**したとされ、
  NECは「BluStellar」、富士通は「Fujitsu Uvance」という
  業種横断ソリューション・ブランドを次の柱に据えている

> **2026年度の国内IT需要**：両社の見通しからは、
> 官公庁・金融の更新需要と生成AI関連投資が続くという読みが共通している。
> ただし**人月ベースのSIは人員の制約**があり、伸ばすには単価改善と再利用可能な製品化が要る。

## 7. 三菱電機：4期連続の最高益、次は5期連続へ

2026年3月期は売上高**5兆8,947億円**（+6.8%）、営業利益**4,330億円**（+10.5%）、
純利益**4,077億円**（+25.8%）で**4期連続の最高益更新**。

- 牽引したのは**データセンター需要と、FAの中国・日本での回復**
- FY2026（2027年3月期）予想は売上6兆2,000億円（+5.2%）、営業利益5,900億円（+17.7%）で
  **5期連続更新**を見込む。**防衛・データセンター需要が追い風**と報じられる
- 一方で、不採算事業の整理は継続しており、
  「リストラ中のパナソニックと三菱電機」という整理をする報道もある

> **注意点**：好調の柱である**インフラ（電力・交通・宇宙防衛）と空調・昇降機は、
> 景気ではなく「設備投資計画」で動く**。半年〜数年の遅れで効いてくるので、
> AI投資の失速があっても業績への影響は遅れて出る。

## 8. 全体の構図（2026年9月時点）

1. **7社とも、同じ「AI・電力・防衛」という追い風を受けている**。ただし届く経路が違う。
   日立＝送配電、東芝＝HDDと発電、三菱電機＝インフラとFA、パナソニック＝電池、
   ソニー＝半導体、NEC・富士通＝システム投資
2. **家電（BtoC）は各社から最終的に外れた**。2026年の日立の家電売却が「脱家電」の区切りで、
   残るパナソニックのスマートライフも唯一の赤字セグメント。業界の重心はBtoBへ完全に移った
3. **「過去最高益」の見出しには一過性が混ざっている**。
   東芝＝キオクシア株、富士通＝事業売却益。本業の実力はROSやセグメント営業利益で見る
4. **構造改革のコストは想定より膨らむ**。パナソニックは削減1万→1万2,000人、
   費用1,500億→1,800億円。改革は「発表したら終わり」ではない
5. **次の焦点は東芝の再上場（最短2028年度）**と、各社が集めた現金の使い道
   （自社株買いか、成長投資か）。日立の5,000億円自社株買いはその最初の答えの一つ

## 9. 用語メモ

| 用語                           | 意味                                                                                                |
| ------------------------------ | --------------------------------------------------------------------------------------------------- |
| **HVDC**                       | 高圧直流送電。長距離・海底の大容量送電に使う。日立エナジーが世界大手                                |
| **ニアラインHDD**              | データセンターの大容量保管用ハードディスク。AI時代に需要増                                          |
| **SPC**                        | 特別目的会社。買収のために設立される受け皿会社                                                      |
| **SPA（製造小売）**            | 企画・製造から販売までを小売が一貫して手がける形。ノジマの日立家電買収がこれに当たると分析される    |
| **パーシャルスピンオフ**       | 親が子会社株の一部（20%未満）を残して大半を株主へ現物配当し、分離上場する手法。一定要件で実質非課税 |
| **ROS**                        | 売上高営業利益率（Return On Sales）。東芝が本業の指標として使う                                     |
| **一過性利益**                 | 売却益・評価益など、その期だけの利益。本業の実力と分けて読む                                        |
| **BluStellar／Fujitsu Uvance** | NEC／富士通の業種横断ソリューション・ブランド                                                       |
| **Lumada（ルマーダ）**         | 日立のデジタル事業の総称。FY2025で売上の40%（4兆1,460億円）                                         |
