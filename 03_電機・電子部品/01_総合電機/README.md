- 大分類: 電機・電子部品
- 状態: done
- 更新日: 2026-09-20

> **最初に断っておくこと**
> **「総合電機」は、2026年時点ではもはや業界名ではなく“出自の名前”である。**
> 日立・東芝・三菱電機・パナソニック・ソニー・NEC・富士通の7社は、
> かつて似た事業構成（重電＋家電＋通信＋半導体＋コンピュータ）を持っていたが、
> **現在の収益源は全く違う**。日立はインフラとIT、ソニーはエンタメと半導体、
> パナソニックは電池と住宅設備、NEC・富士通はITサービス、東芝はエネルギーとストレージの会社である。
> したがって本フォルダでは **「総合電機の市場規模は◯兆円」という一本の物差しを作らない**。
> **各社を同じ物差しで比べないこと**が、この業界を理解する最初の一歩になる。

## 1. 業界の定義・範囲

**総合電機**＝重電（発電機・変圧器・送配電など大電力の設備）から
家電（テレビ・冷蔵庫・洗濯機）まで、**電気に関わる製品を幅広く手がけてきた大手メーカー**の総称。
対象は通常、次の7社（東芝を含めて「電機大手8社」と数える集計ではシャープを加えることもある）。

```
【「総合電機」7社の出自と現在】

  出自：みな1990年頃は下の全部を持っていた
  ┌─────────────────────────────────────────┐
  │ 重電 / 産業 / 交通 / 通信 / コンピュータ / 半導体 / 家電 / 部品  │
  └─────────────────────────────────────────┘
                          │  1995〜2025年の30年
                          ▼
  現在：それぞれ違う場所に着地した
   日立      ── インフラ（送配電・鉄道）＋ IT（Lumada）
   東芝      ── エネルギー ＋ デジタルインフラ ＋ ストレージ（非上場）
   三菱電機   ── FA ＋ 空調・昇降機 ＋ 電力・宇宙防衛
   パナソニック ── 電池 ＋ 電材（配線器具）＋ 業務ソフト ＋ 車載
   ソニー     ── ゲーム ＋ 音楽 ＋ 映画 ＋ イメージセンサー
   NEC       ── ITサービス ＋ 社会インフラ（生体認証・海底ケーブル）
   富士通     ── ITサービス（国内SI ＋ 欧州）
```

境界の引き方：

- **単一分野に特化したメーカーは含めない**。ダイキン（空調）、キーエンス・オムロン（FA）、
  村田製作所・TDK（電子部品）、キヤノン・リコー（事務機器）は別業界として扱う
- **重電専業**（明電舎、東光高岳、ダイヘンなど）も総合電機とは呼ばない
- **7社のセグメント単位の話は、対応する隣接ノートに置く**（上の表を参照）。
  ここでは「複数事業を抱えた企業体としての経営」に絞る

## 3. バリューチェーン（川上 → 川下）

総合電機は**川上から川下まで全部やっていた**のが元々の姿。
現在は「どこを残したか」が会社ごとに違う。

```
 素材・部品 ──▶ デバイス ──▶ 装置・機器 ──▶ システム統合 ──▶ 運用・保守 ──▶ データ活用
  鋼板・樹脂     半導体      変圧器・FA機器   プラント・IT      サービス契約    Lumada等
  電子部品      センサー     空調・昇降機     システム開発      遠隔監視        改善提案
  電池セル      ストレージ    鉄道車両        建設・据付        部品供給

  利益率:  中           高〜変動        中             低〜中          高            高
  必要資本: 中           非常に大        大             小              小            小
           ▲                  ▲                              ▲──────────▲
        ほぼ撤退       ソニー・東芝のみ残存              ここが7社の現在の主戦場
```

> **付加価値の移動**：
> かつては「作って売る（機器）」に価値があったが、モジュール化で機器の利益は薄くなった。
> 現在の利益は **① 供給が逼迫している重いデバイス（変圧器、HDD、センサー）** と
> **② 納めた後の保守・運用・データ** の両端に寄っている。真ん中の「組み立て」が最も薄い。

## 5. 収益モデル・コスト構造

7社に共通する現在の稼ぎ方は、大きく3つに分類できる。

| 型                         | 稼ぎ方                                                         | コストの性質                                                         | 該当する事業                                                          |
| -------------------------- | -------------------------------------------------------------- | -------------------------------------------------------------------- | --------------------------------------------------------------------- |
| **① 設備・システム受注型** | 大型案件を受注 → 数年かけて納入 → 10〜30年の保守               | 固定費（技術者）＋案件ごとの原価。**見積もり誤りが巨額損失に直結**   | 日立エナジー、東芝のエネルギー、三菱電機インフラ、NEC・富士通の大型SI |
| **② 量産デバイス型**       | 工場で量産して外販                                             | **装置の減価償却が重い＝稼働率が落ちた瞬間に赤字**。市況で単価が動く | ソニーのセンサー、東芝のHDD・パワー半導体、パナソニックの電池         |
| **③ サービス・IP型**       | 一度作った資産（ソフト、楽曲、プラットフォーム）を繰り返し売る | 追加コストがほぼゼロ。**粗利が高い**                                 | ソニーの音楽・ゲーム課金、Lumada、Blue Yonder、保守契約               |

```
【利益率の目安（セグメント営業利益率のイメージ、2026年3月期前後）】

  音楽・IP          ■■■■■■■■■■■■■■■■■■■■  20%前後〜
  送配電・保守       ■■■■■■■■■■■■■■         10〜15%
  FA・空調          ■■■■■■■■■■              約8〜10%
  ITサービス         ■■■■■■■■■■              約10%
  電池              ■■■                       数%
  白物家電・テレビ    ▲赤字〜数%
     ▲ 同じ会社の中にこれだけの幅がある ＝ 平均で語ると何も分からない
```

> **総合電機の損益を読む鉄則**：
> 全社の営業利益率を見ても意味がない。**セグメント別に、その分野の専業と比べる**。

## 6. 競争要因（KSF）と参入障壁

**KSF（成功の鍵）**

1. **事業を選ぶ勇気と速さ**：ノンコアを抱え続けるほどディスカウントが深まる
2. **供給が逼迫している重い資産を持っているか**：変圧器、HDD、センサー、電池。
   増産に2〜3年かかるものは価格が通る
3. **納めた後で稼げるか**：保守契約・遠隔監視・データ活用。ここが粗利の源泉
4. **大型案件のリスク管理**：原子力・海外プラント・大型システム開発。
   1件の見積もり誤りが数百億〜兆円の損失になる（東芝・ウェスチングハウスの教訓）
5. **ソフトウェアの内製力**：GlobalLogic（日立）、Blue Yonder（パナソニック）のように
   買ってでも確保する動きが続く
6. **資本規律**：ROIC > WACC を事業ごとに問い続ける仕組み

**参入障壁**

| 障壁                         | 強さ | 理由                                                               |
| ---------------------------- | ---- | ------------------------------------------------------------------ |
| 機器の組み立て               | 弱   | EMSに委託できる。ここだけなら誰でも入れる                          |
| **電力インフラの実績と認証** | 強   | 送配電設備は事故が許されず、数十年の納入実績が前提になる           |
| **量産デバイスの投資額**     | 強   | 工場1棟で数千億円。稼働率が落ちれば即赤字                          |
| **官公庁・金融のシステム**   | 強   | 過去のシステムを知っている会社が強い（乗り換えコストが極めて高い） |
| **IP（楽曲・ゲーム）**       | 強   | 買うしかない。時間では作れない                                     |
| 家電                         | 弱   | 中国勢が量とスピードで圧倒。**だから各社が手放した**               |

## 7. 規制・法制度

| 分野                   | 主な制度                                                                                                                            |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| **資本市場**           | **東証「資本コストと株価を意識した経営」要請**（2023年3月〜）。PBR1倍割れ企業への改善方針の開示要求。コーポレートガバナンス・コード |
| **事業再編**           | 経産省「**事業再編実務指針**」（2020年）。ベストオーナーの考え方、事業ポートフォリオ管理の枠組み。産業競争力強化法                  |
| **税制**               | **パーシャルスピンオフ税制**（2023年度改正で導入、期限延長）。一定要件で分離上場が実質非課税に。ソニーが日本初の適用                |
| **独占禁止法・競争法** | 大型買収時の各国競争当局の審査（日立のABB送配電買収など）。下請法による取引適正化                                                   |
| **経済安全保障**       | 重要物資（半導体、蓄電池、電力設備）の供給確保。**外為法による対内直接投資審査**（コア事業の海外売却に影響）。防衛装備移転三原則    |
| **エネルギー・環境**   | 第7次エネルギー基本計画、GX推進法。省エネ法（データセンターの省エネ基準）。原子力規制                                               |
| **製品安全・品質**     | 電気用品安全法（PSE）、JIS。三菱電機の品質不正（2021〜22年）以降、社内の検査体制が厳格化                                            |
| **輸出管理**           | 外為法・安全保障輸出管理。半導体・製造装置の対中規制                                                                                |

  三菱電機＝インフラとFA、パナソニック＝DC向け電池セル、ソニー＝センサー、NEC・富士通＝システム投資
- **日立が家電事業をノジマへ約1,100億円で売却**（2026年4月契約、2027年3月期中完了予定）。
  17年に及ぶ構造改革の集大成。あわせて5,000億円の自社株買いを発表
- **東芝はFY2025の純利益1兆9,673億円で過去最高**だが、
  **キオクシア関連の一過性利益2兆2,770億円が大半**。本業はROS 8.1%。最短2028年度に再上場を目指す
- **パナソニックHDは減収減益**。人員削減は1万人→**1万2,000人**、構造改革費用は1,500億→1,800億円に拡大と報じられる。
  家電を含むスマートライフは唯一の赤字セグメント（▲373億円）
- **NECが売上・営業利益の両方で富士通を逆転**（FY2025）。
  富士通の純利益4,494億円は新光電気・富士通ゼネラルの売却益を含み、翌期に剥落する
- **ソニーは2025年9月29日に金融をパーシャルスピンオフで分離上場**。
  エンタメ＋半導体の会社として営業利益1兆4,475億円と過去最高
