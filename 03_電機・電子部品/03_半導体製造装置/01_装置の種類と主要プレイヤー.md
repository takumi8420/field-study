# 装置の種類と主要プレイヤー

**このノートで分かること**：半導体工場に並ぶ装置が何種類あり、各カテゴリで誰が強く、
1台いくらなのか。「装置メーカー」とひとくくりにされる企業群の、実際の棲み分け。

工程そのものの説明は [半導体｜前工程](../02_半導体（ロジック・メモリ）/02_前工程.md) と
[半導体｜後工程](../02_半導体（ロジック・メモリ）/03_後工程.md) にある。
ここでは **「その工程を誰の装置がやっているか」というビジネス側** に絞る。

## 0. 結論を先に

- 装置産業は **カテゴリごとに別の会社が勝っている**。総合1位は存在しない
- 5社（ASML／Applied Materials／Lam Research／東京エレクトロン／KLA）で
  前工程装置（WFE）売上のおよそ **7割** を占めるとされる（2026年時点の各種推計）
- 日本勢はカテゴリ単位で見ると、**塗布現像・洗浄・ダイシング・研削・テスタ・マスク検査**などで
  8〜9割級のシェアを持つ。「全体では3位」ではなく「**要所を押さえている**」が正しい理解

## 1. 装置産業の地図

半導体装置は大きく3つに分かれる。統計を読むときはこの区分がそのまま効いてくる。

```
                    半導体製造装置（SEMI統計の「Total Equipment」）
   ┌──────────────────────┴───────────────────────┐
   │                                                │
 前工程装置（WFE = Wafer Fab Equipment）        後工程装置（Back-End）
 市場の約8〜9割を占める最大ブロック          ┌──────┴────────┐
   ├ 露光（リソグラフィ）                  組立・実装装置     テスト装置
   ├ 成膜（CVD/ALD/PVD/エピ）              ダイサ・グラインダ  テスタ・ハンドラ
   ├ エッチング                            ボンダ・モールド    プローバ
   ├ 洗浄                                  ディスコ／ASMPT     アドバンテスト
   ├ CMP（平坦化）                          BESI／TOWA         ／Teradyne
   ├ イオン注入
   ├ 熱処理（アニール）
   └ 検査・計測（プロセス制御）
```

> ポイント：ニュースで「半導体装置市場」と言うとき、たいてい **WFE（前工程装置）** の話をしている。
> 後工程装置とテスタは別カテゴリで、AI向けでは後者のほうが伸び率が高い年がある。
> 統計の読み分けは [② 装置ビジネスの経済性](02_装置ビジネスの経済性.md) の6章にまとめた。

### なぜ露光だけが別格なのか

EUV（極端紫外線、波長13.5nm）の光源は、**錫の液滴にレーザーを当ててプラズマ化する**という
きわめて力技の方式で、装置1台が部屋いっぱいのサイズ・重量150トン級になる。
光学系はドイツのツァイス（Carl Zeiss SMT）、光源は米Cymer（ASML傘下）と、
**ASMLを中心にした一群のサプライヤが束にならないと1台が成立しない**。
結果として「作れるのが世界で1社」という状況が20年近く続いている。

キヤノン・ニコンはEUVに進まず、ニコンはArF液浸と成熟ノード向け、
キヤノンはi線・KrFに加え **ナノインプリント（回路原版を樹脂に押し付けて転写する方式）** という
別の道を選んでいる。量産採用はまだ限定的で、2026年時点では「代替候補の一つ」という位置づけ。
→ 技術面は [先端ロジックとプロセスノード](../../01_注目テーマ/02_半導体・先端半導体/01_先端ロジックとプロセスノード.md) 参照。

## 3. 5強の顔ぶれ

| 社名                          | 本拠     | 主戦場                                     | 位置づけ                                                                         |
| ----------------------------- | -------- | ------------------------------------------ | -------------------------------------------------------------------------------- |
| **ASML**                      | オランダ | 露光                                       | EUV独占。2026年の売上見通しは430〜450億ユーロに上方修正（2026年7月、同社Q2発表） |
| **Applied Materials（AMAT）** | 米国     | 成膜・イオン注入・CMPほか最も品揃えが広い  | 装置の「総合商社」。サービス部門AGSも最大級                                      |
| **Lam Research**              | 米国     | エッチング・成膜（特にメモリ）             | 導体エッチングで約43%シェアとされる（2026年時点の推計）。FY2026売上232.3億ドル   |
| **東京エレクトロン（TEL）**   | 日本     | 塗布現像・エッチング・成膜・洗浄・プローバ | 塗布現像は世界シェア9割級。FY2026（2026年3月期）売上2兆4,435億円で過去最高       |
| **KLA**                       | 米国     | 検査・計測（プロセス制御）                 | 「不良を見つける」領域の実質的な標準                                             |

この5社は **お互いの主戦場をあまり食い合っていない**。
AMATとLamはエッチング・成膜で重なるが、ASMLの露光、KLAの検査には誰も入ってこない。
装置産業が「寡占の集合体」と呼ばれるのはこのためで、価格競争が起きにくい構造の根拠でもある。

## 5. 後工程装置とテスタ

後工程は前工程より装置単価が1桁安く、市場規模も小さい。
ただし **AI向けの先端パッケージ（CoWoS等）で位置づけが変わった**。

| 分野                     | 装置                                           | 主なメーカー                                    |
| ------------------------ | ---------------------------------------------- | ----------------------------------------------- |
| 裏面研削                 | グラインダ                                     | **ディスコ**、東京精密                          |
| 切断                     | ダイシングソー、レーザーダイサ                 | **ディスコ**（7〜8割とされる）、東京精密        |
| 接合                     | ダイボンダ、ワイヤボンダ、フリップチップボンダ | ASMPT、BESI、新川、ヤマハ発動機                 |
| ハイブリッドボンディング | 銅‐銅直接接合装置                              | BESI（AMATと協業）、東京エレクトロン            |
| 封止                     | モールド装置                                   | TOWA、ASMPT                                     |
| **テスト**               | SoCテスタ、メモリテスタ                        | **アドバンテスト**、**Teradyne**（2社で圧倒的） |
| ハンドラ・プローバ       | 被検査チップを運ぶ／針を当てる                 | 東京エレクトロン（プローバ）、東京精密、Cohu    |

AI用GPUは1個あたりのテスト時間が長く、しかも単価が高いので **落とせない**。
結果としてテスタの需要はチップの個数ではなく **「テスト時間の総量」** で伸びる。
アドバンテストの利益率が装置業界でも突出して高い背景はここにある。

## 6. 工場1棟の装置構成をイメージする

先端ロジックの新工場は1〜2兆円規模で、そのうち **7〜8割が装置代** とされる。
おおまかな配分を頭に入れておくと、どの装置メーカーがどれだけ潤うかが読める。

```
 先端ロジックの新工場（投資額を100とした概算イメージ／各種推計）
 ┌────────────────────────────────────────────┐
 │ 建屋・クリーンルーム・用力設備      20〜30    │  ゼネコン、空調、超純水、ガス
 ├────────────────────────────────────────────┤
 │ 装置                                70〜80    │
 │   ├ 露光（EUV含む）           装置費の 2〜3割 │  ASML
 │   ├ 成膜                      装置費の 2割前後│  AMAT / Lam / TEL / ASM
 │   ├ エッチング                装置費の 2割前後│  Lam / TEL / AMAT
 │   ├ 洗浄・塗布現像            装置費の 1割強  │  SCREEN / TEL
 │   ├ 検査・計測                装置費の 1割前後│  KLA / 日立ハイテク
 │   └ CMP・注入・熱処理ほか     残り            │  AMAT / 荏原 / KOKUSAI
 └────────────────────────────────────────────┘
 ※メモリ工場は露光比率が下がり、成膜・エッチングの比率が上がる（層を深く積むため）
```

**ロジック工場は露光が重く、メモリ（特に3D NAND）は成膜・エッチングが重い。**
だから「今回の投資サイクルはメモリ主導だ」と聞いたら、
ASMLよりLam ResearchやTELのほうが恩恵が大きい、と推測できる。

## 7. カテゴリごとに寡占度が違う理由

```
   寡占度 高 ──────────────────────────────▶ 低
   ┌──────────┬──────────────┬─────────────────┐
   │ EUV露光   │ 検査・テスタ  │ エッチング・成膜  │ 汎用搬送・周辺
   │ ASML 1社  │ KLA/アドバン  │ 2〜3社で分け合う  │ 多数
   └──────────┴──────────────┴─────────────────┘
     ↑                ↑               ↑
  物理の壁      「見逃さない」実績   レシピが顧客ごと
  光源と光学が   の蓄積が参入障壁    に違い、複数社が
  1社にしか作れない                  併存できる
```

- **エッチング・成膜が複数社併存なのは、顧客が意図的に2社購買（デュアルソース）するから。**
  1社に依存すると価格も供給も握られるため、大手ユーザーは同じ工程で2社の装置を入れる
- 逆に露光は選択肢がないので、価格交渉が効かない。ASMLの粗利率が高い構造的理由
- 検査・テスタは「不良を見逃した実績がないこと」自体が資産で、切り替えが起きにくい

## 用語メモ

- **WFE（Wafer Fab Equipment）**：前工程装置の総称。半導体装置市場の8〜9割を占める
- **枚葉（まいよう）式／バッチ式**：ウェハーを1枚ずつ処理するか、何十枚もまとめて処理するか。
  微細化とともに均一性が要る枚葉式が増えた
- **プローバ**：ウェハー上のチップに針を当てて電気検査するための装置。テスタとセットで使う
- **ハンドラ**：パッケージ済みチップをテスタに出し入れする装置。温度をかける機能を持つ
- **デュアルソース**：同じ工程に複数メーカーの装置を導入し、依存を避ける調達方針
- **ナノインプリント**：光ではなく型押しでパターンを転写する方式。キヤノンが推進
