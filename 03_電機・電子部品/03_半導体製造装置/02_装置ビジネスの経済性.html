装置ビジネスの経済性

電機・電子部品半導体製造装置

このノートで分かること：装置メーカーは「1台売って終わり」ではない。
すでに顧客の工場で動いている装置の総数＝インストールドベースから、
部品・保守・アップグレードという形で毎年お金が入り続ける。
この構造が、激しい設備投資サイクルの中で装置メーカーを生き延びさせている。

0. 結論を先に

  1. 装置の売上は 新品（システム） と インストールドベース（部品・サービス・アップグレード） の二層
  2. 新品は顧客の設備投資（CapEx）に完全連動し、年20〜30%単位で上下する
  3. インストールドベースは工場が動いている限り減らないので、下り坂で会社を支える
  4. だから装置株を見るときは「受注」と「サービス売上比率」を必ず分けて見る

1. 装置1台の生涯：売って終わりではない

  受注 ─▶ 製造 ─▶ 出荷 ─▶ 据付・立ち上げ ─▶ 顧客が量産で使う（10〜20年）─▶ 中古 or 廃棄
   │                │        │                      │
   │                │        │                      ├ 消耗部品（毎年）
   │                │        │                      ├ 定期保守・技術者常駐
   │                │        │                      ├ 予備機・スペア在庫
   │                │        │                      ├ 性能アップグレード（旧型を新ノード対応に）
   │                │        │                      └ レシピ最適化・歩留まり改善サービス
   │                │        │                          ↑↑↑
   └── ここが「システム売上」┘                     ここが「インストールドベース売上」
        山あり谷ありの世界                          工場が止まらない限り毎年入る

装置は消耗品を食べながら動く機械である。
真空チャンバー内の部品はプラズマに晒されて削れるし、光学部品は汚れる。
顧客は止められないので、予防交換のために部品を買い続ける。
この「静脈」的な収入が、装置メーカーの利益率を支えている。

3. 利益率：なぜこんなに高いのか

企業 指標 水準（2026年時点）
ASML粗利率2026年Q2で 54.0%、通期見通し54〜56%
Applied Materials粗利率FY2026で 50%前後
アドバンテスト営業利益率FY2026（2026年3月期）44.2%（売上1兆1,286億円、営業利益4,991億円）
ディスコ営業利益率FY2026 約42%（売上4,368億円、営業利益1,849億円）
東京エレクトロン営業利益率おおむね20%台後半〜30%台（年による）

製造業としては異常に高い。理由は3つ。

  1. 代替がない：その装置がないと工程が成り立たないので、値引き圧力が効きにくい
  2. 部品・サービスの粗利が本体より高い：消耗部品は純正品指定になりやすい
  3. 開発費は先に払い終わっている：ノード開発は量産の2〜4年前に済んでおり、
    売れ始めるころには開発投資が過去のものになっている（＝限界利益が大きい）

逆に言えば、開発に失敗した世代は丸ごと損失になる。この博打性が参入障壁でもある。

4. 受注から売上計上まで：時間差を理解する

 顧客が投資を決める     装置を発注       装置を製造      出荷       据付・立ち上げ   検収
      ●─────────────────●───────────────●──────────●──────────────●──────▶ 売上計上
      │                   │  リードタイム  │          │   1〜3ヶ月   │
      │                   │   6〜12ヶ月    │          │（EUVは数ヶ月）│
      └───── 半年〜1年 ───┘
      ＝「工場を建てる」ニュース  →  装置メーカーの売上になるのは 1〜2年後
  • 受注残（バックログ） が積み上がっていても、売上計上までに時間がかかる
  • 装置は据付・調整して顧客が性能を確認（検収）してはじめて売上になるのが基本。
    だから「出荷したのに売上が立たない」四半期が普通に発生する
  • EUVのような超大型装置は輸送だけで航空機数便、据付に数ヶ月かかる
  • この時間差のせいで、装置メーカーの決算は半導体市況より半年〜1年遅れて動く

実務的な示唆：TSMCやSamsungの設備投資（CapEx）計画の発表は、
装置メーカーの1〜2年先の売上の先行指標になる。逆に装置メーカーの受注は
半導体市況全体の先行指標として使われる。

5. 設備投資サイクル：波の正体

装置の需要は「半導体がどれだけ売れたか」ではなく「顧客がどれだけ工場を建てたか」で決まる。
そして工場投資は、半導体価格の上下に遅れて・過剰に反応する。

 半導体価格 ↑ ─▶ 顧客が儲かる ─▶ 増産投資を決める ─▶ 装置発注 ↑↑
                                         │（1〜2年）
                                         ▼
                       工場が立ち上がる ─▶ 供給過剰 ─▶ 価格 ↓
                                         │
                       投資を止める ─▶ 装置発注 ↓↓（急ブレーキ）

顧客の数が少ない（先端ロジックは実質3社、DRAMは3社）ため、
1社が投資を止めるだけで市場が二桁%動く。これが装置業界の振れ幅の大きさの理由。

年 世界の半導体製造装置売上（SEMI） 備考
2024年末時点の予測2026年に1,390億ドルSEMI 2024年12月発表
2025年末時点の予測2026年に1,450億ドル／2027年に1,560億ドルSEMI 2025年12月発表
2026年央の予測2026年に1,659億ドル（前年比+23.2%）、2027年 +21.8%、2028年に2,290億ドルSEMI 2026年7月発表

半年で予測が2割上振れしたのがこの1年の特徴で、AI向けの先端ロジックと
HBM用DRAMへの投資が想定を超えたため。予測が頻繁に書き換わること自体が、
この業界の性格をよく表している。

6. WFE市場規模とSEMI統計の読み方（重要）

数字が飛び交う業界なので、どの統計の、どの定義かを毎回確認する癖をつける。

6-1. 主な統計の違い

統計 発表元 測っているもの 通貨 注意点
Total Equipment ForecastSEMI（国際的な装置・材料業界団体）世界の新品装置売上（前工程＋後工程＋テスト）ドル年2回（年末／年央）に改訂。中古装置は含まない
WFESEMI、各社IR、調査会社前工程装置だけドル定義が発表元で微妙に違う。後工程・テストを含むか要確認
日本製装置販売高SEAJ（日本半導体製造装置協会）日本メーカーが世界中で売った額円「日本国内で売れた額」ではない。円安だと自動的に増える
日本市場向け販売高SEAJ日本に設置された装置（外資製含む）円上と混同しやすい最大の落とし穴
Billings（出荷額）SEMI／SEAJ実際に出荷・請求した金額ドル／円受注（Bookings）とは別物

6-2. よくある取り違え

  ✕「SEAJが6.5兆円と言っているのに、SEMIは1,659億ドル（約24兆円）。数字が合わない」
  ○ SEAJ＝日本メーカー製だけ。SEMI＝世界中の全メーカー分。母集団が違う

  ✕「SEMIの装置市場が過去最高なら、ASMLもTELも過去最高のはず」
  ○ 内訳の偏りで勝ち負けが分かれる。メモリ主導の年は成膜・エッチングが伸び、
     ロジック主導の年は露光が伸びる

  ✕「装置市場が伸びている＝半導体が売れている」
  ○ 装置は先行投資。半導体の売上が落ちている年に装置が伸びることもある

6-3. 2026年時点の実数（押さえておく基準値）

  • 世界の半導体製造装置売上：2026年に1,659億ドル（SEMI 2026年7月・2026年央予測）
  • うちWFE（前工程装置）は 2027〜2028年に2,000億ドル突破 の見通し（同）
  • 日本製半導体製造装置の販売高：2026年度に6兆5,502億円（前年度比+26%）、
    2027年度は7兆4,017億円の予測（SEAJ 2026年7月発表）。
    同年1月時点の予測（5兆5,004億円）から 約1兆円の上方修正

BBレシオ（Book-to-Bill＝受注÷出荷） はかつて業界の体温計として使われたが、
SEMIは北米装置メーカー分の公表を2010年代に終了している。
現在は各社の受注残（バックログ）開示や、SEMI/SEAJの予測改訂幅で代用するのが実務。

7. 中古装置という第二の市場

  • 装置は寿命が長く、成熟ノード（28nm以上）なら20年前の装置でも現役で使える
  • 先端を追う顧客が入れ替えた装置は、成熟ノードやパワー半導体・アナログの工場へ流れる
  • 中古半導体装置の市場規模は 2025年の45.5億ドルから2026年に54億ドル、
    2030年に105.9億ドルへ拡大するとの推計がある（調査会社の推計、2026年時点）
  • 韓国SurplusGLOBALなどが取引プラットフォームを運営し、
    リース会社（SMFLなど）も売買・オペレーティングリースで参入している

中古市場が大きいことは装置メーカーにとって 両刃。
新品が売れにくくなる一方で、中古で動いている装置からも 部品・保守収入は入る。
だからメーカーは中古流通そのものより、「純正部品と認定リファービッシュ」の囲い込みを重視する。

8. コスト構造：装置メーカーは何にお金を使うか

費目 感覚値 中身
材料費・外注加工費売上の4〜5割真空ポンプ、ロボット、光学部品、電源、制御機器など買ってくる部品が多い
研究開発費売上の1〜2割次ノード対応の開発。ASMLは特に高い
人件費（含むフィールドエンジニア）相応に重い顧客工場に常駐する技術者を世界中に配置する必要がある
設備投資比較的軽い装置メーカー自身は「組み立てと評価」が中心。巨大工場は要らない

装置メーカーは自分が装置産業ではない、というのが面白いところ。
顧客（半導体メーカー）は減価償却の塊だが、装置メーカーは
人と開発費が主コストの、ファブライトなビジネスである。
だから不況期でも固定費で沈みにくい。

用語メモ

  • インストールドベース（installed base）：顧客の工場で稼働中の自社装置の総数。
    ここからの部品・サービス収入がサイクルの谷を埋める
  • CapEx（設備投資）：顧客が工場・装置に投じる金額。装置メーカーの売上の源
  • バックログ（受注残）：受注したがまだ売上計上していない金額
  • 検収：顧客が据付後の性能を確認して受け入れること。ここで売上が立つのが原則
  • BBレシオ：受注÷出荷。1を超えると需要拡大局面とされた指標（北米分は公表終了）
  • リファービッシュ：中古装置を分解・洗浄・部品交換して再生し、性能保証を付けて再販すること
  • ファブライト：自社の製造設備を最小限にし、外注を活用する経営形態
