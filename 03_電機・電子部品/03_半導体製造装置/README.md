# 半導体製造装置

- 大分類: 電機・電子部品
- 状態: done
- 更新日: 2026-09-20

半導体そのものではなく、**半導体を作る機械**を売る産業。
顧客は世界で数十社しかなく、1台数億〜数百億円の機械を、
顧客の工場に入り込んで一緒に作り込みながら売る。
そして売ったあとも、部品と保守で10年以上お金が入り続ける。

## 1. 業界の定義・範囲

半導体を製造する工程で使う装置を設計・製造・販売し、据付から保守まで行う産業。

| 含む                                                                | 含まない（隣接業界）                                                                            |
| ------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| 前工程装置（露光・成膜・エッチング・洗浄・CMP・注入・熱処理・検査） | フォトレジストやウェハーなどの**材料** → [半導体材料](../04_半導体材料/README.md)               |
| 後工程装置（研削・ダイシング・ボンディング・封止）                  | 半導体そのものの製造 → [半導体（ロジック・メモリ）](../02_半導体（ロジック・メモリ）/README.md) |
| テスト装置（テスタ・プローバ・ハンドラ）                            | 電子部品の実装機（SMT）やFPD製造装置（近接業界、SEAJは統計上まとめて扱う）                      |
| 真空ポンプ・ガス供給などの周辺装置                                  | クリーンルーム建設・空調（建設業）                                                              |

**境界の引き方のコツ**：ウェハーに触れる機械が装置、ウェハーに消費されるものが材料。

 ────────────         ──────────            ───────────────────       ──────

        │                      │                       │
        │                      └── 保守・部品・改造 ────┘（10〜20年続く）
        └── 装置1台の材料費・外注費は売上の4〜5割。部品メーカーへの波及が大きい

**付加価値が集まる場所**：装置メーカー自身（設計・レシピ・据付ノウハウ）と、
代替の効かない一部の部品メーカー（光学、真空）。
組立や板金加工は相対的に薄い。

## 5. 収益モデル・コスト構造

```
 売上 ＝ ① 新品装置（システム）   ＋ ② インストールドベース（部品・保守・改造）
         波が激しい／顧客CapEx連動    工場が動く限り毎年入る／全社売上の2〜3割
```

- 粗利率は40〜55%程度、営業利益率は20〜45%と製造業として高水準（2026年時点、各社IR）
- 高い理由は「代替がない」「部品・サービスの粗利が高い」「開発費は数年前に払い終えている」
- コストの主役は **材料費・外注費（売上の4〜5割）と研究開発費（1〜2割）**。
  装置メーカー自身は巨大工場を持たない **ファブライト** な構造なので、不況期に固定費で沈みにくい
- 受注 → 製造 → 出荷 → 据付 → **検収で売上計上**。発注から売上まで1〜2年かかることがある

詳細は [② 装置ビジネスの経済性](02_装置ビジネスの経済性.md)。

## 6. 競争要因（KSF）と参入障壁

1. **PoR（量産採用）を取ること**。一度量産レシピに組み込まれると世代をまたいで替えられない
2. **顧客との共同開発力**。量産の2〜4年前から評価機を持ち込み、一緒にデータを取る
3. **世界規模の保守網**。装置が止まると顧客の損失が巨額になるため、24時間の対応力が必須
4. **信頼性の実績（MTBF）**。時間でしか積み上がらず、新規参入者が最も苦しむ
5. **部品サプライチェーン**。光学・真空・制御の良い部品は既存大手が押さえている

→ 図解は [③ 競争のルールと輸出規制](03_競争のルールと輸出規制.md) の8章。

## 7. 規制・法制度

- **輸出管理が事業の可否を決める**産業。日本は外為法・外為令のリスト規制で先端装置を管理
- 米国は2022年10月以降、対中規制を段階的に強化。**装置本体だけでなく部品・保守・技術支援も対象**
- **Affiliates Rule（50%ルール）** は2026年11月10日に再適用予定とされる
- オランダは2026年6月に新規定を公布（同年9月施行）し、先端DUVにも許可申請を要求
- 米下院では2026年4月、同盟国の装置にも網をかける法案（通称MATCH法案）が公表された
- 規制は「先端」に限られ、**成熟ノード向け装置は基本的に対象外**。この線引きの理解が重要
- 支援策としては経済安保推進法に基づく補助、SEMICON関連の人材育成施策など

## 8. 最近のトピック

詳細は [④ 直近トピック 2026](04_直近トピック_2026.md)。要点は5つ。

1. SEMIの装置市場予測が **半年で2割上方修正**（2026年1,659億ドル → 2028年2,290億ドル）
2. 需要の中心が **HBM用DRAM＋先端パッケージ＋テスト**へ移り、後工程装置とテスタが同時に伸びた
3. 各社とも **サービス・部品収入の伸びが本体を上回り**、サイクル耐性が上がった
4. 輸出規制は **同盟国の装置と資本関係**にまで拡大。Lamは暦年2026年で約6億ドルの減収要因と説明
5. 中国は **成熟ノード増設と装置国産化**（国産化率2025年23.2%との推計）で応じる

## 9. 用語メモ

- **WFE**：前工程装置の総称。装置市場の8〜9割を占める
- **インストールドベース**：顧客の工場で稼働中の自社装置の総数。ここからの部品・保守収入が利益の柱
- **PoR（Process of Record）**：量産で使うと正式決定された工程条件と装置の組み合わせ
- **スループット／MTBF**：1時間あたり処理枚数／平均故障間隔。装置の生産性と信頼性の指標
- **枚葉式／バッチ式**：1枚ずつ処理するか、まとめて処理するか
- **Affiliates Rule（50%ルール）**：規制対象企業の子会社にも輸出規制を及ぼす米国規則
- 半導体全体の用語は [半導体｜用語集](../02_半導体（ロジック・メモリ）/05_用語集.md) を参照
