# 直近トピック（2026年9月時点）

報道・調査会社の推計を含む整理。**一次情報（SEMI／SEAJ／各社IR）で必ず裏取りすること**。
数値は年・出典とセットで記載し、推計・報道は明示した。

## 1. 装置市場が予測を上振れし続けている

SEMIの予測が半年で2割書き換わった、というのがこの1年で最も象徴的な出来事。

| 発表時期                       | 2026年の装置売上予測            | その先                                                       |
| ------------------------------ | ------------------------------- | ------------------------------------------------------------ |
| 2024年12月（SEMI 年末予測）    | 1,390億ドル                     | ―                                                            |
| 2025年12月（SEMI 年末予測）    | 1,450億ドル                     | 2027年に過去最高の1,560億ドル                                |
| **2026年7月（SEMI 年央予測）** | **1,659億ドル（前年比+23.2%）** | 2027年 +21.8%、**2028年に2,290億ドル**。WFEは2,000億ドル超へ |

日本勢の統計も同じ方向に動いている。

- **SEAJ（日本半導体製造装置協会）**は2026年7月発表の需要予測で、
  **2026年度の日本製装置販売高を6兆5,502億円（前年度比+26%）**、
  2027年度を7兆4,017億円と予測。
  2026年1月時点の予測（2026年度5兆5,004億円）から **約1兆500億円の上方修正**
- 上振れの理由としてSEAJが挙げるのは **AIサーバー向け先端ロジック投資**と
  **HBMを中心としたDRAM投資の大幅増**

> 読み方の注意：SEAJの数字は「**日本メーカーが世界中で売った額（円建て）**」であり、
> SEMIの「世界の全メーカー合計（ドル建て）」とは母集団も通貨も違う。
> 統計の定義については [② 装置ビジネスの経済性](02_装置ビジネスの経済性.md) の6章を参照。

## 2. 投資の中身が「ロジック単独」から「HBM＋先端パッケージ」へ

```
 2023〜2024年             2025〜2026年
 ─────────────            ─────────────
 先端ロジック中心    ──▶   先端ロジック
 （TSMC N3/N2）             ＋ HBM向けDRAM（1x/1y nm、TSV、積層）
 メモリ投資は抑制中         ＋ 先端パッケージ（CoWoS、ハイブリッドボンディング）
                            ＋ テスト工程の大幅増

 恩恵を受ける装置            恩恵を受ける装置
 露光（ASML）中心      ──▶  成膜・エッチング（Lam/TEL/AMAT）
                             研削・切断（ディスコ）
                             テスタ（アドバンテスト）
                             ボンダ（BESI/ASMPT/TEL）
```

AI向けチップは前工程だけでは作れない。**HBMを積み、インターポーザに載せ、長時間テストする**
という後半の工程がそのまま装置需要になっている。
背景の技術は [AI半導体とHBM](../../01_注目テーマ/02_半導体・先端半導体/02_AI半導体とHBM.md) と

## 4. 輸出規制：次の波は「同盟国の装置」と「資本関係」

- **2026年4月**、米下院の超党派議員が対中半導体装置規制を強化する法案（通称MATCH法案）を公表。
  AI半導体の製造に使う装置・部品の対中輸出を絞り、
  **日本・オランダなど同盟国にも規制強化での連携を求める**内容と報じられた。
  成立した場合に影響が大きいとされるのは、中国向け比率の高い東京エレクトロンなど
- **Affiliates Rule（50%ルール）** は **2026年11月10日に再適用予定**とされる。
  規制対象企業が50%以上出資する子会社にも網がかかるため、
  取引先の資本関係を調べないと出荷可否が判断できない
- **オランダ**は2026年6月に新たな輸出規定を公布（9月施行）し、
  ASMLの先端DUV（NXT:2000i / 2050i / 2100i 等）にも許可申請を要求
- **2026年6月**、米商務省がASML幹部に対し、
  EUV装置が規制に反して中国へ流出した可能性への懸念を伝達したと報じられた
- **中国側の対抗措置**も進み、日本向けには2026年2月24日・6月29日の2波で
  累計およそ80社が対象に加えられたとされる（2026年時点の報道・整理）

```
 規制の広がり方（対象がどんどん外側へ）

 2022/10  装置本体（先端ロジック・メモリ向け）  ──┐
 2023     部品・消耗品、技術支援                  │  「モノ」から
 2024     日本・オランダも独自のリスト規制        │  「人・サービス・資本関係」へ
 2025     エンドユーザー確認の厳格化              │
 2026/06  蘭：先端DUV（NXT:2000i等）も許可制 ─────┤
 2026/04  米：同盟国の装置にも網をかける法案公表  │
 2026/11  米：Affiliates Rule（50%ルール）再適用 ─┘
          ＝ 取引先の親会社・子会社まで調べないと出荷できない
```

業績への実額インパクトも出ている。**Lam Researchは新たな米輸出規制により
2026年12月期四半期に約2億ドル、暦年2026年で約6億ドルの減収要因**になると説明している。

## 5. High-NA EUV が「評価」から「実戦」へ

- ASMLは2026年に **Low-NA EUVを約65台出荷**し、EUV事業は約45%成長する見通しを示した（2026年Q2）
- **High-NA EUV（EXE:5000系）は2026年通期で4〜5台が売上に寄与**する見込み。
  High-NAで初めて量産ロジック製品の準備マイルストーンに到達したとされ、Intelが先行
- 価格は **1台3億5,000万ユーロ／約3億8,000万ドル**規模、重量150トン級（2024年の報道ベース）。
  年産能力は5〜6台程度とされ、需要に供給が追いつかない状態が続く

High-NAは「入れれば速くなる」装置ではなく、
**マルチパターニングの工程数を減らしてトータルコストを下げられるか**が採否の分かれ目。
だから各社の導入判断が割れている。
→ [先端ロジックとプロセスノード](../../01_注目テーマ/02_半導体・先端半導体/01_先端ロジックとプロセスノード.md)

## 6. 中国の国産装置と、成熟ノードの増設

- 中国の装置国産化率は **2021年の8%から2025年に23.2%**、2030年に39%との予測がある（推計）
- エッチング・成膜・CMP・薄化などでは NAURA、AMEC といった国産メーカーの採用が拡大。
  一方で **露光と先端の検査・計測は依然として空白**
- 規制対象外の **成熟ノード（28nm級）への投資は続いており**、
  Applied Materialsは2026年の中国売上増を「28nmファウンドリ/ロジック投資が牽引」と説明している
- 論点は「中国が先端に追いつくか」より、
  **成熟ノードの大量増設が世界の価格と稼働率をどこまで揺らすか**に移りつつある

## 7. 中古装置市場が静かに拡大

- 中古半導体装置の市場規模は **2025年の45.5億ドル → 2026年に54億ドル → 2030年に105.9億ドル**
  と推計される（調査会社の推計、2026年時点）
- 韓国 SurplusGLOBAL が2025年2月にAI搭載のレガシー装置向けマーケットプレース「SemiMarket」を開設するなど、
  断片的だった中古流通のプラットフォーム化が進む
- 日本でもリース会社（SMFLなど）がオペレーティングリースと中古売買を組み合わせたサービスを展開
- 背景：**成熟ノードの装置は20年使える**。先端を追う顧客の入れ替え品が
  パワー半導体・アナログ・車載向けの工場へ流れる循環ができている

## 8. 全体の構図（2026年9月時点のまとめ）

1. 装置市場は **2026年1,659億ドル、2028年2,290億ドル**へ向かう強気局面。予測は半年ごとに上方修正されている
2. 需要の中心は **AIサーバー向け先端ロジック＋HBM用DRAM＋先端パッケージ**。
   前工程だけでなく **後工程装置とテスタが同時に伸びている**のが今回のサイクルの特徴
3. どの装置メーカーも **サービス・部品（インストールドベース）収入の伸びが本体を上回り**、
   サイクルの谷に対する耐性が上がった
4. 一方で **輸出規制は同盟国の装置と資本関係にまで対象を広げる方向**で、
   Lamのように実額の減収要因を明示する企業が出てきた
5. 中国は **成熟ノード増設と装置国産化**で応じる。露光と先端検査の空白が埋まるかが次の10年の焦点

## 用語メモ

- **年央予測／年末予測**：SEMIが年2回出す装置市場予測。改訂幅そのものが景況の指標になる
- **MATCH法案**：2026年4月に米下院で公表された対中半導体装置規制強化法案の通称（報道ベース）
- **Affiliates Rule（50%ルール）**：規制対象企業が50%超出資する子会社にも規制を及ぼす規則
- **Low-NA / High-NA**：EUV露光装置のレンズの開口数の違い。High-NAはより細かく描けるが極めて高価
- **ポストセールス**：SCREENでの保守・部品・改造の呼称。他社のAGS／CSBG／フィールドソリューションに相当
