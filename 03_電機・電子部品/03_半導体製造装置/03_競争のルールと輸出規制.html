このノートで分かること：装置メーカーはカタログとスペックで勝負しているわけではない。
顧客の工場に入り込んで一緒に開発し、いったん採用されたら替えられなくなるという
独特の競争構造がある。そこに2020年代、輸出規制という政治的な変数が加わった。

0. 結論を先に

  • 装置は「買ってもらう」のではなく「顧客の量産レシピに組み込まれる」ことで勝つ
  • いったん採用（PoR）されると、次世代でも同じメーカーが選ばれやすい（＝ロックイン）
  • 開発は量産の 2〜4年前 に始まる。今の売上は数年前の技術選定の結果
  • 輸出規制により、装置ビジネスは「売れる相手を政府が決める商売」に変質した

1. 顧客は買い手であり、共同開発者でもある

 装置メーカー                              半導体メーカー（顧客）
 ────────────                              ────────────────────
 次世代機のコンセプト ──────▶  一緒に仕様を詰める（数年前から）
        │                                        │
 α機（試作1号機）を持ち込む ──▶  顧客の研究ラインで評価
        │                                  ＝「評価機」「デモ機」
 データを持ち帰り改良 ◀────────  歩留まり・スループットの実測データ
        │
 β機 ──────────────────────▶  パイロットラインで量産条件を作る
        │                                        │
 量産機を大量受注 ◀──────────  **PoR（量産採用）決定**
                                                 │
                              以後、そのノードの全工場で同じ装置が使われる
  • 装置メーカーは 自社で量産していないのに、量産の勘所を知っている必要がある。
    だから顧客のラインに技術者を常駐させ、データを一緒に見る
  • 評価機は 無償または大幅値引きで持ち込むことが多い。ここは投資であって売上ではない
  • ベルギーの imec のような中立研究機関は、装置・材料メーカーと半導体メーカーが
    競合関係を保ったまま次世代技術を検証できる「共有の実験場」として機能している

2. PoR（Process of Record）＝この業界最大のロックイン

PoR とは、ある工程について「この装置の、この条件で量産する」と顧客が正式に決めた仕様のこと。

なぜ替えられないのか。

  1. 半導体の歩留まりは 装置の個体差レベルまで作り込まれている。
    装置を替えると、1,000工程のうちの1つを変えただけで全体の歩留まりが崩れかねない
  2. 車載・医療向けなどは 工程変更に顧客（自動車メーカー等）の再認定が要る。数ヶ月〜年単位
  3. 一度作った量産レシピは、次ノードへ「移植」するほうが早い。
    → 世代をまたいで同じメーカーが選ばれ続ける

つまり装置業界の勝負は、新ノードの立ち上げのタイミングでしか決着しない。
「2nm世代でどの装置が採用されたか」は、その後10年の売上を決める。
逆に言えば、1世代負けると挽回に10年かかる。キヤノン・ニコンがEUVで
一度降りたあと戻れないのは、技術だけでなくこの構造による。

3. 先行投資のタイミング

時期 装置メーカーがやっていること 売上への影響
量産の4〜5年前要素技術の研究、imec等での検証費用のみ
量産の2〜3年前α機を顧客に持ち込み、共同評価ほぼ費用のみ
量産の1〜2年前β機、パイロットライン、PoR獲得競争少量の売上
量産開始量産機を大量出荷ここで一気に回収
量産後10年以上部品・保守・アップグレードインストールドベース収入

研究開発費は売上の1〜2割にのぼり、当たらなかった世代はまるごと損失になる。
このリスクを取れるのは、すでに大きなインストールドベースを持つ企業だけ。
「強い会社がさらに強くなる」循環が働いている。

4. 特許とブラックボックスの使い分け

装置メーカーの技術は、次の3層に分けて守られている。

層 守り方 例
構造・機構特許で公開して守る露光装置の光学系、ステージ制御、チャンバー構造
プロセスレシピ秘匿（ブラックボックス）ガス種・流量・圧力・温度の組み合わせ。特許にすると真似される
部品の作り込みサプライヤ管理で守る特定の商社・部品メーカーとの専属的な関係
  • 装置の「外形」は特許で分かるが、歩留まりを出す条件は装置メーカーと顧客の間にしかない
  • 中国メーカーの追い上げに対し、日米欧勢が余裕を持てる理由の一つがこれ。
    装置を分解しても、レシピと信頼性データは出てこない
  • 一方で、退職者の移籍による技術流出は繰り返し問題になっている

5. 輸出規制が商売をどう変えたか

2022年10月の米国の対中規制を起点に、装置ビジネスの前提が変わった。

5-1. 何が規制されるのか

   規制される対象は「装置本体」だけではない
   ┌─────────────────────────────────────────┐
   │ ① 装置そのもの（性能のしきい値で線引き）      │
   │ ② 交換部品・消耗品                            │
   │ ③ 保守・修理・技術支援（＝サービス）★         │
   │ ④ 米国籍者による支援行為（US persons rule）   │
   │ ⑤ 規制対象企業の子会社・関連会社（Affiliates）│
   └─────────────────────────────────────────┘

③が効く。装置は保守なしには数ヶ月で止まる。
本体を売れても部品とサービスを止められれば、顧客の工場は稼働を維持できない。
規制の実効性がここにある一方、装置メーカーにとっては
インストールドベース収入 が直接削られることを意味する。

5-2. 商売の進め方がどう変わったか

項目 規制前 規制後（2026年時点）
販売判断顧客の信用と支払能力エンドユーザーと用途の確認が先。許可が下りるまで出荷できない
見積・納期技術・生産都合許可申請の期間を織り込む必要
保守契約標準サービス規制対象顧客には部品供給・技術者派遣を止める判断が発生
業績見通し需要予測規制改定で一夜にして数百億円が消えるリスクを注記
組織営業・技術貿易管理部門が事業の可否を握る体制へ
  • 米国は2026年11月に Affiliates Rule（50%ルール） を再適用する予定とされ、
    規制対象企業が50%以上出資する子会社にも網がかかる。
    取引先の資本関係まで調べないと売れない、という世界になっている
  • 日本は外為令に基づく輸出管理でリスト規制品目を拡大、
    オランダも2026年6月に新規定を公布（同年9月施行）し、先端DUV装置にも許可申請を求めた

5-3. 規制の対象は「先端」だけ

見落とされがちだが、成熟ノード（概ね28nm以上）向けの装置は基本的に規制外。
このため中国の投資は成熟ノードに集中し、そこでは日米欧の装置が今も売れている。
「対中売上が高い＝規制で全部消える」ではないことに注意。

6. 中国向け売上比率という論点

装置各社にとって、中国は長く最大の市場だった。その比率がいま論点になっている。

企業 中国向け比率（2026年時点） 備考
東京エレクトロンFY2026通期で 34.1%（最大市場）。ただしQ4単体では 26.8% へ低下同社決算
Applied MaterialsFY2026 Q3で 26%（半導体システム＋AGS）Q2の24%から上昇。28nmファウンドリ投資が牽引
Lam Research34% から低下見込み。新たな米輸出規制で CY2026に約6億ドルの逆風、12月期に約2億ドルの減収を想定同社説明
ASML総売上の 約20%。2026年Q2の中国本土向けシステム売上は約9億ユーロ（出荷地域ベースで14%）同社決算

読み方のポイント。

  1. 比率は「分母」でも動く。AI向けの台湾・韓国向けが急増すれば、
    中国向けの実額が減らなくても比率は下がる
  2. 成熟ノード向けと先端向けを分けて見る。規制影響は先端に集中する
  3. サービス売上への影響は遅れて出る。本体販売が止まった数年後に効いてくる
  4. 日本の装置メーカーは、コータ・デベロッパ、洗浄装置、プローバ、ダイサ、グラインダなどで
    8〜9割前後のシェアを持つとされ、規制の当事者になりやすい構造がある

7. 中国の国産装置という新しい競争相手

  • 装置の国産化率は2021年の8%から 2025年に23.2%、2030年には39%との予測がある（推計）
  • NAURA（北方華創）、AMEC（中微半導体）、SiCarrier などが
    エッチング・成膜・CMP・薄化といった分野で採用を広げている
  • 中国の半導体メーカーには「国産装置を一定比率使う」という政策的な誘導があり、
    技術で劣っていても評価機会が与えられる。これはPoRの壁を政策で突破する動きにほかならない
  • 一方、露光（特にEUV）と先端の検査・計測は依然として空白。
    ここが埋まるかどうかが今後10年の焦点

8. 参入障壁を図にすると

  新規参入者が越えなければならない壁（上から順に高い）

  ┌─────────────────────────────────────────────┐
  │ ⑤ 顧客の量産レシピに入る（PoR）             │ ← 最大の壁。技術が良くても越えられない
  ├─────────────────────────────────────────────┤
  │ ④ 世界中に保守網を持つ（24時間365日）        │ ← 止まる装置は買ってもらえない
  ├─────────────────────────────────────────────┤
  │ ③ 信頼性の実績（MTBF、稼働率の履歴）         │ ← 時間でしか積み上がらない
  ├─────────────────────────────────────────────┤
  │ ② 部品サプライチェーン（真空・光学・制御）    │ ← 良い部品は既存大手に押さえられている
  ├─────────────────────────────────────────────┤
  │ ① 装置を設計・製造する技術                   │ ← ここだけなら越える会社はある
  └─────────────────────────────────────────────┘

①だけを見て「中国が装置を作れるようになった」と評価するのは早い。
逆に、国家が顧客に採用を促すという手段は ⑤ を飛ばせるので、
中国市場の中に限れば国産装置のシェアは上がり得る、というのが2026年時点の構図。

用語メモ

  • PoR（Process of Record）：量産で使うと正式に決めた工程条件と装置の組み合わせ
  • 評価機／デモ機：顧客の研究・パイロットラインに持ち込んで性能を実証するための装置
  • imec：ベルギーの半導体研究機関。装置・材料・半導体各社が集まる共同開発の場
  • エンティティリスト：米国が輸出を制限する企業のリスト
  • Affiliates Rule（50%ルール）：リスト対象企業が50%以上出資する子会社にも規制を及ぼす規則
  • US persons rule：米国籍者・米国居住者が規制対象活動を支援することを禁じる規定
  • MTBF：平均故障間隔。装置の信頼性指標で、稼働率と直結する
  • スループット：1時間あたりに処理できるウェハー枚数。装置の生産性指標
