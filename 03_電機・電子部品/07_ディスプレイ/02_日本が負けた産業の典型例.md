# 日本が負けた産業の典型例

このノートで分かること：**液晶を発明し、世界シェアほぼ100%だった日本が、なぜ20年で消えたのか**を
「投資のタイミング」「減価償却」「価格下落」という3つの数字の話として理解する。

> 結論を先に。日本は**技術で負けたのではない**。
> **「赤字になる期間の長さに耐えられる資金の持ち方」で負けた。**
> ディスプレイは、①投資判断から量産まで2〜3年かかり、②その間に価格が半分になり、
> ③固定費（減価償却）が売上と無関係に発生する産業である。
> この3条件が揃うと、**正しい技術を持った会社ほど早く倒れる**。

## 2. 敗因の中核：「投資が実る頃に価格が半分になっている」

ディスプレイ産業の時間軸を並べると、構造的な罠が見える。

```
       投資を決める                  装置搬入・立上げ           量産開始
           │                             │                      │
  t=0 ──────┼──────── 1.5〜2年 ──────────┼──── 0.5〜1年 ────────┼────▶ 以後5年間、償却が続く
           │                             │                      │
        【好況】                                              【不況】
   パネル価格が高い              ← この間に競合も同じ判断をする →   全社の新ラインが同時に立ち上がる
   「今なら回収できる」と判断      ← 需要は年率数%しか伸びない  →   供給だけが階段状に増える
           │                                                    │
           ▼                                                    ▼
    4,000億円の投資を決裁                                 パネル価格が 40〜60% 下落
                                                          売上は半分、償却費は満額
```

**需要はなだらかに伸びるのに、供給は工場単位で階段状にしか増えない。**
1つの G10.5 工場が立ち上がると、世界の大型パネル供給が一気に数%増える。
その結果、価格は「じわじわ下がる」のではなく **好況と暴落を2〜3年周期で往復する**。

液晶テレビ用パネル（オープンセル）の価格は、この20年で以下のような動きを繰り返してきた。

| 時期 | 32型オープンセル価格の目安 | 局面 |
| --- | --- | --- |
| 2010年頃 | 100ドル超 | 高値 |
| 2019年央 | 30ドル台前半 | 歴史的底値。全社が赤字 |
| 2021年央 | 80ドル台後半 | コロナ巣ごもりで急騰 |
| 2022年秋 | 20ドル台後半 | 1年強で **約3分の1** に暴落 |
| 2024〜26年 | 30〜40ドル台で推移 | 中国勢の意図的な稼働調整で下支え |

※ 価格は調査会社（Omdia／WitsView 等）の公表値を報道が引用したもの。目安として読む。

> **同じ32型パネルが、2年で価格3分の1になる。**
> この振れ幅を、5年償却の固定費を抱えたまま乗り切れるか。これが事業としての勝敗を決めた。

## 3. 減価償却という「消せない固定費」の正体

工場を建てると、その金額は建てた年に一括で費用化されず、**耐用年数で割って毎年の費用**になる。
これが減価償却費で、**売上がゼロでも発生する**。

### 試算（イメージ／単純化した仮想モデル）

G10.5 級の大型パネル工場を想定する。数字は理解のための単純化であり、実際の各社決算値ではない。

| 項目 | 仮定 |
| --- | --- |
| 設備投資額 | 4,000億円 |
| 償却年数 | 5年（定額） |
| **年間の減価償却費** | **800億円** |
| 月産能力 | 65型換算で 月 80万枚（年 960万枚） |
| フル稼働時の**1枚あたり償却費** | 800億円 ÷ 960万枚 = **約8,300円** |

ここに稼働率を掛ける。**償却費の総額は変わらない**のがポイント。

| 稼働率 | 年間生産枚数 | 1枚あたり償却費 | 65型パネル価格を150ドル(約2.2万円)とすると |
| --- | --- | --- | --- |
| 100% | 960万枚 | 約 8,300円 | 材料・変動費 1.2万円 → 差引 +1,700円／枚 → **黒字** |
| 70% | 672万枚 | 約 11,900円 | 差引 **−1,900円／枚** → 赤字 |
| 50% | 480万枚 | 約 16,700円 | 差引 **−6,700円／枚** → 大幅赤字 |

```
  1枚あたりコスト              利益が出る線（パネル価格）
       │                    ─────────────────────────
  16,700├─■                      ▲
       │  ■                       │ 稼働率が落ちると
  11,900├─  ■                     │ コストが線を突き抜ける
       │      ■                   │
   8,300├────────■────────────────┘
       └───┬────┬────┬───▶ 稼働率
          50%  70%  100%

  ★ 変動費なら減産すれば減る。償却費は減らない。
    だから「売れないから作らない」を選んだ瞬間、1枚あたりコストが跳ね上がる。
    結果、赤字でも作り続けるしかなくなる → 供給が減らない → 価格が戻らない
```

> **これが「赤字なのに減産できない」構造の正体。**
> 全社が同じ計算をするので、市況が崩れても供給が絞られず、下落が長期化する。

### 償却年数の差が、そのまま損益の差になる

同じ4,000億円の工場でも、**償却年数を何年に置くか**で年あたりの固定費が変わる。

| 償却年数 | 年間償却費 | フル稼働時の1枚あたり | 備考 |
| --- | --- | --- | --- |
| 5年 | 800億円 | 約8,300円 | 日本の電機各社が採ってきた保守的な設定 |
| 7年 | 571億円 | 約5,900円 | |
| 10年 | 400億円 | 約4,200円 | 中国勢が採るとされる長期設定 |

**償却年数が2倍になれば、年あたりの固定費は半分になる。**
同じパネルを同じ価格で売っても、片方は黒字、片方は赤字になる。
中国勢が長期償却を採るとされること、地方政府からの補助金・低利融資・土地／電力の優遇を受けること、
上場子会社として赤字でも増資で資金を得られることが重なり、
**「同じ市況を戦っているのに損益分岐点が違う」**という状態が生まれた（報道・アナリストレポートベース）。

## 4. 日本勢がつまずいた具体的な3つのタイミング

| 時期 | 何が起きたか | 結果 |
| --- | --- | --- |
| **1997〜2001年** | アジア通貨危機と国内金融危機で、日本の電機各社が液晶投資を抑制。サムスン・LGは逆にこの局面で大型投資を継続（いわゆる逆張り投資） | 大型TFT液晶の主導権が韓国へ。**2001年に日韓のシェアが逆転** |
| **2009年** | シャープが堺（G10、約4,300億円）を立ち上げた直後にリーマン後の需要蒸発と円高（〜2011年に1ドル80円割れ）が直撃。**世界最先端の工場が低稼働のまま償却だけが進む** | 2012年3月期・2013年3月期でシャープは2期連続巨額赤字。単独保有できず鴻海（郭台銘氏個人）と折半へ |
| **2012〜2019年** | JDI が中小型液晶に特化した直後、スマホが**液晶から有機ELへ転換**。有機EL量産投資に必要な資金が集まらず、最大顧客の減産にも直撃された | 12期連続の最終赤字（2026年3月期時点、報道ベース）。茂原工場の生産終了へ |

> 共通するのは、**「投資を決めるべき時に金がなく、金ができた時には狙う技術がずれていた」**こと。
> シャープの堺は「大型液晶が伸びる」という読み自体は正しかったが、**タイミングが1年ずれた**。
> JDIは「中小型は日本が強い」という読みは正しかったが、**液晶に賭けた瞬間に有機ELへ移った**。

## 5. 「技術で勝って事業で負けた」の分解

```
 【技術】                      【事業】
  ○ IGZO（酸化物TFT）          ✕ 需要の谷を越える資金の厚み
  ○ 低温ポリシリコン量産         ✕ 1社で年数千億円を継続投入する体力
  ○ 亀山モデルの品質             ✕ 顧客集中（最大顧客の判断1つで稼働が飛ぶ）
  ○ 有機EL材料・蒸着装置         ✕ 償却年数の保守性 → 損益分岐点が高い
  ○ 印刷方式OLED（JOLED）        ✕ 「勝ち筋が見えるまで待つ」意思決定の遅さ
         │                            │
         └────── どちらが効くか ───────┘
                      ▼
      パネルは「規格品」。技術が違っても
      同じ32型パネルとして同じ価格で売られる。
      → 技術の差が価格差にならない領域では、
        コスト構造と資金力だけが勝敗を決める。
```

ここが最大の教訓。**パネルは差別化が価格に転嫁しにくい「規格品（コモディティ）」**である。
32型フルHDパネルは、誰が作っても同じ32型フルHDパネルとして値付けされる。
液晶の画質が多少良くても、テレビメーカーは1ドル安いほうを買う。

同じ電機・電子部品でも、[電子部品](../05_電子部品/README.md)（MLCC等）は
「その会社の部品でないと成立しない」設計組み込みが起きるため、価格支配力が残った。
[半導体製造装置](../03_半導体製造装置/README.md) や
[半導体材料](../04_半導体材料/README.md) も同様に、代替が効かない位置にいる。

> **同じ「日本の電機」でも、コモディティ側に立ったのがディスプレイで、
> 代替不可側に立ったのが部品・材料・装置だった。**
> この差が、そのまま今日の明暗になっている。

## 6. 国主導の再編は何を間違えたのか

JDI（2012年設立、産業革新機構が約2,000億円出資）は、
ソニー・東芝・日立の中小型液晶事業を統合した官民ファンド主導の再編だった。

| 狙い | 実際に起きたこと |
| --- | --- |
| 規模を作って投資余力を得る | 統合したのは**3社の赤字事業**。規模は増えたが収益源は増えなかった |
| 重複投資を避ける | 3社の工場・文化・システムの統合に時間を取られ、技術の先行投資が後回しに |
| 中小型で世界と戦う | 最大顧客への依存度が高く、顧客の機種計画変更が業績を直撃する構造が残った |
| 有機ELへ移行する | 移行に必要な追加投資（数千億円規模）を調達できず、**液晶のまま残された** |

JOLED（2015年設立、JDIとソニー・パナソニックの有機EL部門を統合）も同じ形を辿り、
印刷方式という独自技術を実用化しながら量産規模に届かず、2023年3月に民事再生法を申請した。

> 再編の教訓は「弱った事業を足し算しても強くならない」こと。
> この産業で必要だったのは統合ではなく、**不況期に数千億円を投じ続けられる資本の性格**だった。
> それを持っていたのが、財閥系グループ（韓国）と地方政府（中国）だった。

## 8. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **減価償却費** | 設備投資額を耐用年数で割って毎年計上する費用。**売上がゼロでも発生する固定費**。この産業の損益をほぼ決める |
| **償却年数（耐用年数）** | 何年で費用化するか。短いほど1年の負担が重い。日本5年前後／中国7〜10年とされる差が損益分岐点の差になる |
| **損益分岐点** | 売上がここを超えれば黒字になる水準。固定費が重いほど高くなる |
| **稼働率** | 能力に対する実生産の比率。償却費は固定なので、稼働率が下がると1枚あたりコストが跳ね上がる |
| **オープンセル** | バックライトを付ける前のパネル（セル）。テレビ用パネルの取引はこの単位。価格指標としても使われる |
| **コモディティ（規格品）** | 作り手が違っても同じ仕様なら同じ価格で売買される財。技術差が価格差にならない |
| **逆張り投資** | 不況期にあえて投資を継続・拡大すること。韓国勢が1990年代後半に採ったとされる戦略 |
| **産業革新機構（INCJ）** | 官民ファンド。JDI に約2,000億円を出資した |
| **SDP（堺ディスプレイプロダクト）** | シャープの大型液晶子会社。G10工場を運営。2024年8月にテレビ用大型液晶の生産を停止 |
| **JOLED** | 印刷方式有機ELを手がけた国策会社。2023年3月に民事再生法を申請 |
