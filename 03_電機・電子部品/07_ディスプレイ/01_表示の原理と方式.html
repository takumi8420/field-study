表示の原理と方式

電機・電子部品ディスプレイ

バックライト偏光板TFT（薄膜トランジスタ）バックプレーンLTPS／IGZOFMM（ファインメタルマスク）マザーガラス／世代（G◯）面取り数ミニLEDマイクロLEDマイクロOLEDドライバIC（DDI）

このノートで分かること：画面に絵が出る仕組みを、液晶・有機EL・マイクロLEDの3方式で理解する。
そして「パネル工場とは何をしている工場なのか」（TFT → セル → モジュール、マザーガラスの世代）を掴む。

大前提：ディスプレイとは 「光を作る仕組み」＋「光を画素ごとに制御する仕組み」 の組み合わせでしかない。
方式の違いは、この2つを分けているか、1つにまとめているかの違いに尽きる。

1. 3方式を1枚で

方式 光をどう作るか 画素をどう制御するか ひとことで
液晶（LCD）裏側のバックライト（LED）が常に光る液晶分子の向きを変えて光を通す／遮る（＝シャッター）「懐中電灯＋ブラインド」
有機EL（OLED）画素そのものが光る（自発光）画素に流す電流の量で明るさを決める「豆電球を敷き詰める」
マイクロLED画素そのものが光る（自発光）同上。ただし発光体が無機の微小LED「有機ELのLED版」

液晶が「シャッター方式」であることが、この産業のほぼすべての長所短所を決めている。
バックライトは常に光っているので、黒を表示したいときも光を完全には遮りきれず、黒が浮く。
逆に、光源と制御が分離しているので大きな面積を安く作れる。

【液晶＝光源と制御が分離】               【有機EL＝光源と制御が一体】

  ┌─────────────┐  偏光板             ┌─────────────┐ 封止（水分を遮断）
  │░░░░░░░░░░░░░│  カラーフィルタ      │░░░░░░░░░░░░░│ カラーフィルタ or 塗り分け
  │▓▓▓▓▓▓▓▓▓▓▓▓▓│  液晶層（シャッター）│●  ●  ●  ●  │ 有機EL層（ここが光る）

2. 液晶：なぜ「安くて大きい」が得意なのか

液晶分子は、電圧をかけると向きが変わる棒状の分子。
2枚の偏光板（特定方向に振動する光だけ通すフィルム）で挟み、間の液晶の向きで
「光が通る／通らない」を切り替える。これが1画素分のシャッターになる。

長所 なぜそうなるか
大面積が安い発光は裏の面光源に任せきり。画素側は「電圧をかけるだけ」の単純構造で、大きくしても難しくならない
寿命が長い・焼き付かない光っているのはLEDバックライトだけ。画素ごとの劣化差が出にくい
高輝度が出しやすいバックライトのLEDを増やせば明るくなる。屋外・車載で効く
残った課題黒が浮く（コントラスト）、応答が遅い、厚い、曲げられない

ミニLEDは液晶の弱点を「バックライト側の改良」で潰す手法。
バックライトを数千〜数万個の小さなLEDに分け、暗い部分のLEDだけ消す（ローカルディミング）。
有機ELに近い黒を、液晶のコスト・輝度のまま得る狙い。
※ マイクロLEDとは全くの別物。ミニLEDはバックライトの話、マイクロLEDは画素そのものの話。

3. 有機EL：自発光がもたらす「薄い・曲がる・黒い」

電流を流すと光る有機材料を、画素ごとに配置する。バックライトが要らない。

長所 短所
黒は完全に消灯＝コントラストが理論上無限有機材料が水分・酸素で劣化する。封止が必須で難しい
薄い・軽い・曲げられる（フレキシブル）青色材料の寿命が短く、焼き付き（残像）が起きうる
応答が桁違いに速い大面積になるほど歩留まりが悪化し、コストが跳ね上がる

有機ELの作り分けには2系統ある。ここがスマホ用とテレビ用で製法が違う理由。

方式 やり方 使われる先
RGB塗り分け（FMM蒸着）細かい穴の空いた金属マスク（ファインメタルマスク）を当て、赤・緑・青の有機材料を真空中で蒸着して塗り分けるスマホ向け中小型。サムスンディスプレイが確立
白色OLED＋カラーフィルタ（WOLED）全面を白く光らせ、カラーフィルタで色を作る。マスク不要で大面積に向くテレビ用大型。LGディスプレイの方式
QD-OLED青く光らせ、量子ドット（特定の色に変換するナノ粒子）で赤・緑を作るサムスンディスプレイのテレビ・モニタ向け
印刷（インクジェット）有機材料をインクとして吹き付ける。材料ロスが小さい実用化に苦戦。JOLEDが挑み、2023年に経営破綻した

ポイント：FMM蒸着は大きくすると使えない。マスクが自重でたわむため、
スマホサイズは作れてもテレビサイズは作れない。
「なぜテレビ用有機ELだけ方式が違うのか」の答えはこれ。

4. マイクロLED：原理は最強、組み立てが地獄

画素そのものを無機のLED（数〜数十μm）にする。有機物を使わないので劣化せず、
明るさ・寿命・コントラストのすべてで上回る。原理的には最終解に近い。

問題は数。4K（3840×2160）をRGB3色で作ると、必要なLEDは 約2,490万個。
これを1枚の基板に1個ずつ移し替える（マストランスファー）必要がある。
1個でも死ねば輝点・欠点になる。歩留まり99.99%でも約2,500個が不良になる計算で、
「ほぼ100%」では足りない、というのが実用化が進まない最大の理由。

現状は、①数億円クラスの大型サイネージ（LEDの間隔を広く取れる）と、
②XR用の超小型（1インチ以下。既存の半導体プロセスで作れるので移し替えが少なくて済む）
という、大きい端と小さい端の両方から攻めている状況。

5. 画素とドライバIC：「電気で絵を描く」部分

パネルは格子状に配線され、交点ごとに TFT（薄膜トランジスタ＝ガラスの上に作った極小スイッチ）が置かれる。

            ソース線（列）＝「何色をどれだけ」を送る配線
              │      │      │      │
  ゲート線 ───┼──────┼──────┼──────┼──  ← この行を「開ける」
  （行）      □      □      □      □      ソースドライバIC が
              │      │      │      │      各列に電圧を送る
  ゲート線 ───┼──────┼──────┼──────┼──
              □      □      □      □      □ = 1副画素（R/G/B のどれか）
              │      │      │      │          中に TFT が1個入っている

  1行ずつ開けて → 全列に一斉に書き込む → 次の行へ。
  これを 1/60 秒（60Hz）や 1/120 秒で全行くり返す。
部品 役割 主な作り手
ゲートドライバ行を1本ずつ選ぶ。今は回路をパネル上に直接作り込む（GOA）ことが多く、IC が不要にパネル内蔵化が進行
ソースドライバ（DDI）各列に階調どおりの電圧を送る。チップ数・単価ともに大きいサムスンLSI、Novatek（台）、Silicon Works（韓）、シナプティクス、ラピステクノロジー（ROHM系）
タイミングコントローラ（T-CON）映像信号を行列の書き込み順に並べ替える同上
TFTの材料a-Si（安い・遅い）／LTPS（速い・スマホ用）／酸化物（IGZO）（省電力・大型向き）／LTPO（LTPS＋酸化物。可変リフレッシュで省電力）IGZO は東京工業大学（当時）細野秀雄氏らの発明。シャープが実用化

有機ELではTFTの役割が変わる。液晶のTFTは「電圧を保持するスイッチ」で済むが、
有機ELは電流で光るため、TFTが電流源として働く必要がある。
TFTの特性ばらつきがそのまま輝度ムラになるため、1画素あたり数個のTFTと補償回路を積む。
有機ELの難しさの半分は、実は発光材料ではなくバックプレーン（TFT側）にある。

7. マザーガラスの世代：なぜ「大きいガラス」を争うのか

パネルは大きな1枚のガラス（マザーガラス）に複数枚分をまとめて作り、最後に切り分ける。
ガラスが大きいほど、1枚あたりの処理コストが薄まる。これが世代競争の理由。

  ┌───────┬───────┐             ┌──────┬──────┬──────┬──────┐
  │  65型 │  65型 │             │ 65型 │ 65型 │ 65型 │ 65型 │

     3面取り・端材が多い              8面取り・ほぼ無駄なし
     → 65型の原価が下がらない          → 65型で圧倒的に有利

世代は「新しいほど偉い」のではなく「狙うサイズ専用」。
G10.5 で6型のスマホパネルを作っても、切断精度や搬送の都合でまったく得にならない。
だから各社は 狙う用途ごとに別々の世代の工場を持つ。
そして「どのサイズが伸びるか」を2〜3年先読みして投資する必要がある。
この先読みを外したときに何が起きたかが次のノートの主題 →

8. 方式の使い分け：どこで何が使われているか

用途 主流方式 理由
テレビ（〜50型・量販）液晶（LCD）面積あたりの安さが絶対。有機ELは大型で歩留まりが悪い
テレビ（高級・55型〜）有機EL／ミニLED液晶画質差が価格差を正当化できる層
スマートフォン有機EL（フレキシブル）薄さ・省電力・曲面・穴あけ自由度。単価も許容される
ノートPC・タブレット液晶 →（移行中）有機EL2026年から G8.6 の IT向け有機ELラインが本格稼働
車載（メーター・ナビ）液晶（ミニLED増加）高温・振動・10年以上の供給義務。信頼性で液晶が優位
産業・医療・FA液晶長期供給・多品種少量。単価が高い
XR（VR/AR）マイクロOLED（シリコン基板上の有機EL）1インチ前後で4K級。4,000ppi クラスが必要
大型サイネージLED（マイクロLED含む）何メートルでも継ぎ足せる

9. 用語メモ

用語 意味
バックライト液晶の裏で常に光る面光源。今はLED。これが「黒が浮く」原因であり、同時に「安い」理由
偏光板特定方向の振動の光だけ通すフィルム。液晶を挟んで使う。日東電工・住友化学が強い
TFT（薄膜トランジスタ）ガラス上に作った極小スイッチ。全画素に1個以上入っている
バックプレーンTFT側の基板全体のこと。有機ELではここの出来が輝度ムラを左右する
LTPS／IGZOTFT の材料。LTPS＝低温ポリシリコン（速い、スマホ向け）、IGZO＝酸化物半導体（省電力、大型向き）
FMM（ファインメタルマスク）有機EL を RGB に塗り分ける金属マスク。大きくするとたわむため、大型には使えない
マザーガラス／世代（G◯）まとめ取りする大判ガラスとその寸法規格。狙うサイズごとに最適世代が違う
面取り数マザーガラス1枚から何枚のパネルが取れるか。原価を直接決める
ミニLED液晶のバックライトを細かく分割する技術。画素の話ではない
マイクロLED画素そのものを微小LEDにする方式。移し替え（マストランスファー）が最大の壁
マイクロOLEDシリコンウェハ上に作る超高精細な有機EL。XR向け。ソニーなどが供給
ドライバIC（DDI）各列に階調電圧を送るIC。パネル以外で最も金額の大きい部品
