報道ベースの整理。数値は一次情報（各社IR・調査会社リリース）で裏を取ること。
このノートの前提となる構造は [現在の市場と残った領域](03_現在の市場と残った領域.md) を先に読むと分かりやすい。

> 2026年のディスプレイ業界を一行で言うと、
> **「需要は縮むのに、パネル会社は久々に儲かっている」年**。
> 理由は簡単で、**赤字で作り続ける会社が居なくなった**から。

## 1. スマホ用有機ELが3年ぶりに減少する——原因はメモリ価格

Omdia は2026年、**スマートフォン向けAMOLEDディスプレイの出荷が約7億7,800万台（前年比 約−7%）**となり、
3年続いた成長が止まるとの見通しを示した（2026年4月、報道ベース）。
新品スマホ向けに限ると **前年比 約−12%** の予測も出ている。

**原因がディスプレイ側にないのが今年の特徴**。
AIサーバー需要でDRAM・NANDが逼迫し、メモリ価格が急騰した結果、
スマホメーカーが1台あたりの部材コストを吸収しきれず、
**生産計画そのものを下方修正した**ことが響いている。

| 影響 | 中身 |
| --- | --- |
| 新品スマホ向けパネル | 2026年は減少。中位機種でのAMOLED採用拡大が止まった |
| **リファービッシュ（再生品）向けパネル** | 逆に**過去最高の伸び**。新品が高くなったため、既存端末を修理して使う動きが拡大（Omdia、2026年8月） |
| パネルメーカー | サムスンディスプレイは2026年に約2億4,400万枚のスマホ向け有機EL出荷見通し。BOEのフレキシブル有機ELは約1億5,300万枚の見通し（報道ベース） |

```
  AIサーバー需要 ──▶ DRAM/NAND 逼迫 ──▶ メモリ価格急騰
                                            │
                          ┌─────────────────┘
                          ▼
     スマホの原価が上がる ──▶ 端末メーカーが生産計画を削る
                          │
                          └──▶ 有機ELパネル需要 −7%（2026年）
                          └──▶ 修理・再生市場向けパネルは過去最高の伸び

  ★ ディスプレイ業界の需要が、ディスプレイと無関係な要因で決まった年。
```

## 2. パネル大手が久々の好業績——「撤退が進んだから儲かる」

2025年通期の主要各社の業績は、この産業としては異例の水準になった（報道ベース、ドル換算）。

| 企業 | 売上 | 利益 | 利益率 |
| --- | --- | --- | --- |
| サムスンディスプレイ（韓） | 約230億ドル | 営業利益 約32億ドル | 約14% |
| LGディスプレイ（韓） | 約198億ドル | 純利益 約3.6億ドル | 約1.8% |
| BOE（中） | 約215億ドル（2025年1〜9月） | 純利益 約6.4億ドル | 約3% |
| TCL CSOT（中） | 約69億ドル（2025年上期） | 純利益 約6.0億ドル | 約8.6% |
| HKC（中） | 約26億ドル（2025年上期） | 純利益 約3.0億ドル | 約11.4% |
| Visionox（中） | 約8.4億ドル（2025年1〜9月） | **純損失 約2.3億ドル** | 赤字継続 |

読み取るべき点は3つ。

1. **韓国勢の利益は OLED から出ている**。LGディスプレイは OLED が売上の **61%**（2024年55%、2020年32%）に達した
2. **中国勢は液晶で黒字を出せるようになった**。かつて赤字でも作り続けた面々が、
   稼働率調整で価格を守れるようになったため。**競合が減ったこと自体が利益源**
3. **有機EL単独の後発（Visionox）は依然赤字**。参入コストの重さは変わっていない

## 3. G8.6 の IT向け有機EL が2026年に立ち上がる

ノートPC・タブレット向けの有機EL化が、2026年に量産段階へ入る。
これまでの IT向け有機ELは G6 ラインの流用だったが、
**2290×2620mm の G8.6 専用ライン**が立ち上がることで面取り効率が上がり、コストが下がる。

| 企業 | 状況 |
| --- | --- |
| **サムスンディスプレイ** | 牙山（アサン）の A6 ライン。約4.1兆ウォン（約31億ドル）を投じ、旧LCD工場を転換。2026年に生産開始、第3四半期に量産拡大の見通し |
| **BOE** | 成都の B16。**2026年5月に量産開始**と報じられる。初期はAcer・ASUSの14型ノートPC向け。第3四半期に本格量産との見方も。Apple向けは初期段階では難しいとされる |
| **LGディスプレイ／Visionox** | G8.6 の投資は遅延していると報じられる |

> **ここが2020年代後半の主戦場**。スマホ有機ELは中国勢が追いつきつつあり、
> テレビ有機ELは市場が小さい。**残る大きな移行先がノートPC・タブレット**なので、
> ここを先に押さえた社が次の5年の利益を取る。
> 装置側では [キヤノントッキ](03_現在の市場と残った領域.md#6-日本に残ったもの1装置と材料) などの日本勢に受注が回る局面でもある。

## 4. JDI が債務超過を脱出——ただし「事業が治った」わけではない

ジャパンディスプレイ（JDI）は2026年、長期の再建局面で節目を迎えた。

| 時点 | 状況 |
| --- | --- |
| 2025年11月 | **茂原工場のパネル生産を終了**（当初計画の2026年3月から前倒し）。生産は石川工場へ集約 |
| 同時期 | 希望退職。募集目標1,500人程度に対し国内1,483人が応募。**年間135億円の人件費削減**を見込む |
| 2026年3月期 | **12期連続の最終赤字**。期末に**74億円の債務超過** |
| 2026年4〜6月期 | 売上高 239億円（茂原の生産終了で減収）、営業損益 **約12億円の赤字**（前年同期 約92億円の赤字）、最終損益 **約35億円の赤字**（前年同期 約202億円の赤字） |
| 2026年6月末 | 親会社いちごトラストの新株予約権行使等により**純資産が約36億円のプラスとなり、債務超過を解消**。経営陣は「上場維持を必ず果たす」と表明 |

```
  【JDIの損益改善の中身】

  売上   324億円 ──────────▶ 239億円   ← 工場を止めたので減収
                                         （売上が減ることが改善策になる状態）
  営業損益 −92億円 ─────────▶ −12億円   ← 固定費（償却・人件費）を落とした効果
  最終損益 −202億円 ────────▶ −35億円   ← 特別損失の一巡＋資産売却

  ★ 改善の主因は「売れたから」ではなく「止めたから」。
    ここが、この産業の構造改革の典型。
    固定費が重い産業では、縮小そのものが最も効く打ち手になる。
```

**注意点**：茂原工場の売却交渉が難航し、2026年3月期には債務超過を解消できなかった経緯がある。
今回の解消も親会社の資本支援によるもので、**本業の黒字化はまだ達成されていない**。
JDI は現在、ディスプレイに加えてセンサー・半導体パッケージ事業への転換を進めている。

## 5. シャープ堺工場跡地が AIデータセンターになった

日本の大型液晶の象徴だったシャープ堺工場（G10、2009年稼働、投資約4,300億円）は、
2024年8月21日にテレビ用大型液晶パネルの生産を停止。
SDP（堺ディスプレイプロダクト）は事業を終息し、約240人が退職した。

跡地は**AIデータセンター**へ転換されている。

| 動き | 内容 |
| --- | --- |
| ソフトバンクへの土地売却 | 約1,000億円規模と報じられ、シャープは2025年3月期に3期ぶりの黒字へ |
| KDDIのデータセンター | 堺工場跡の土地・建物・**電源設備**を譲り受け、2025年度中の本格稼働を目指して転換。2026年に稼働開始と報じられる |
| 亀山第2工場 | 売却が不成立となり、液晶生産の「火を落とす」方針と報じられる（2026年2月） |

> **パネル工場がデータセンターになる**のは偶然ではない。
> パネル工場は「大容量の受電設備・冷却設備・広い床・堅固な床荷重」を備えており、
> **データセンターに必要なものとほぼ同じ**。
> ただし転換は簡単ではなく、「できたときには陳腐化」との闘いだったとも報じられている。
> 日本の液晶投資が、20年越しに別の装置産業のインフラとして回収されている形。

## 7. 全体の構図

1. **需要はディスプレイの外側で決まっている**。2026年の減少要因はメモリ価格高騰であり、
   ディスプレイ技術や価格の問題ではない。AI投資の副作用が、スマホを経由してパネルに届いた
2. **供給側は寡占が効き始めた**。日本（2024年）・韓国（2025年）が大型LCDから退場し、
   残った中国勢が稼働率を調整できるようになった。**赤字を出す参加者が減ったこと自体が利益源**
3. **次の争点は IT向け有機EL（G8.6）**。スマホは伸びず、テレビ有機ELは小さい。
   ノートPC・タブレットが最後の大きな移行先で、2026年がその立ち上がり年
4. **日本勢の現在地**。パネル製造はJDI（車載・小型中心）とシャープ（縮小中）のみ。
   実質的な陣地は装置（キヤノントッキ等）・材料（偏光板・有機EL材料・ガラス）・
   小型高精細（ソニーのマイクロOLED）に移った
5. **象徴的なのは堺工場**。世界最大の液晶工場だった建屋が、AIデータセンターとして再利用されている。
   装置産業の設備は、産業そのものが終わっても電力と床として残る

## 8. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **AMOLED** | アクティブマトリクス有機EL。スマホ用有機ELの一般的な呼称 |
| **リファービッシュ（再生品）** | 中古端末を整備して再販売すること。2026年は新品高騰の反動でパネル需要が伸びた |
| **G8.6（第8.6世代）** | 2290×2620mm のマザーガラス。ノートPC・タブレット向け有機ELの新標準 |
| **債務超過** | 負債が資産を上回る状態。上場維持基準に抵触しうる。JDIは2026年6月末に解消 |
| **いちごトラスト** | JDIの親会社（投資ファンド）。新株予約権の行使などで資本支援を行っている |
| **SDP（堺ディスプレイプロダクト）** | シャープの大型液晶子会社。2024年8月にテレビ用パネル生産を停止 |
| **Omdia** | ディスプレイ市場の代表的な調査会社（旧IHS Markit系）。この分野の数値の多くが同社由来 |
| **UBI Research** | 韓国の有機EL専門調査会社。OLED関連の予測で広く引用される |
