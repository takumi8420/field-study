# 現在の市場と残った領域

このノートで分かること：**いま誰がパネルを作っていて、どこで儲かっているのか**。
そして、パネルから撤退した日本勢が**どこに陣地を残したのか**。

> 結論を先に。パネル製造の重心は **日本 → 韓国 → 中国** と移り終わった。
> 韓国勢は「大型液晶を捨てて有機ELに逃げ切る」戦略で利益を回復し、
> 中国勢は「液晶を寡占して価格を自分でコントロールする」段階に入った。
> 日本に残ったのは **装置・材料・小型高精細** の3つで、いずれも
> **数量では小さいが、代替が効かないため価格支配力がある**領域である。

## 2. 市場規模と方向

| 指標 | 数値 | 出典・注記 |
| --- | --- | --- |
| 大型ディスプレイ出荷台数 | 2025年 **約9億1,050万台**（前年比+2.9%） | Omdia 予測（報道ベース、2026年1月） |
| 大型ディスプレイ出荷 | 2026年上期 **4億6,610万台**（前年同期比+3%）、下期は4億5,080万台（同−7%）の見通し | Omdia 予測（報道ベース、2026年7月） |
| 大型LCD出荷 | 2025年 約8億7,680万台（+2.6%） | 同上 |
| 大型OLED出荷 | 2025年 約3,370万台（**+12.9%**） | 同上。台数は小さいが伸びは高い |
| スマホ向けAMOLED出荷 | 2026年 **約7億7,800万台（前年比 約−7%）** の見通し。3年続いた成長が止まる | Omdia（2026年4月、報道ベース）。主因は**メモリ価格高騰**による端末コスト上昇 |
| 産業用ディスプレイ市場 | 2025年 **34億ドル（前年比+24%）**、2026年は台数+6.5%だが金額はほぼ横ばい | Omdia（報道ベース） |
| 車載向け | Mini-LED の売上シェアが 2024年の約3.0% から **2026年に初めて10%超**へ | UBI Research 推計（報道ベース） |

- **「ディスプレイ市場規模」の統計は定義で桁が変わる**。
  パネルだけか、モジュール・完成品まで含むか、面積ベースか台数ベースかを必ず確認する
- 大きな傾向は **「台数は横ばい、面積はじわじわ増、金額はOLED比率で決まる」**。
  テレビの台数は増えないが、平均サイズが年0.5〜1インチずつ大きくなるため面積は増える

## 3. 中国勢の寡占：価格を「作る側」に回った

2024〜25年にかけて、大型液晶から韓国勢（LGディスプレイが広州工場を TCL CSOT へ売却、約108億元＝当時約2,228億円、2025年に手続き完了）と
日本勢（シャープ堺SDP、2024年8月停止）が退場した。
残ったのは中国勢と台湾勢で、**大型LCDは中国勢で世界の7割超**とされる。

| 何が変わったか | 中身 |
| --- | --- |
| **減産で価格を守るようになった** | かつては各社が赤字でも作り続けて価格が崩れた。いまは BOE・CSOT・HKC といった上位数社が、需要減の局面で**揃って稼働率を落とす**。2024年第1四半期には4社の稼働率が60%以下に下がると報じられた |
| **利益が出るようになった** | BOE の2025年1〜9月は売上約215億ドル・純利益約6.4億ドル（純利益率 約3%）、TCL CSOT の2025年上期は売上約69億ドル・純利益約6.0億ドル（同 約8.6%）と報じられる |
| **次は OLED を取りに来ている** | BOE は第8.6世代（G8.6）IT向け有機ELの量産を2026年に開始予定。スマホ向けフレキシブル有機ELの2026年出荷は約1億5,300万枚の見通し（報道ベース） |

```
  かつて（2010年代）                        いま（2024年〜）

  需要↓ → でも全社が作り続ける            需要↓ → 上位数社が揃って稼働率を落とす
       → 供給過剰 → 価格暴落                    → 供給が絞られる → 価格が下げ止まる
       → 全社赤字 → 体力のない社が退場           → 全社が薄いが黒字

  ★ 撤退が進んだ結果、残った側が
    「供給量を調整できる」立場になった。
    寡占が進むと、赤字の産業は黒字の産業に変わる。
```

> ここが重要。**日本と韓国が撤退したこと自体が、中国勢の収益を改善させた。**
> 「負けた側が抜けたので、勝った側が儲かるようになった」という、
> 装置産業ではよくある終わり方をしている。

## 4. 韓国勢：大型液晶を捨てて有機ELへ逃げ切った

| 企業 | 打ち手 | 結果（2025年、報道ベース） |
| --- | --- | --- |
| **サムスンディスプレイ** | 大型LCDから完全撤退。スマホ向けフレキシブル有機ELと QD-OLED に集中。G8.6 の IT向け有機EL ライン（A6）へ約4.1兆ウォン投資 | 売上 約230億ドル、営業利益 約32億ドル（**営業利益率 約14%**） |
| **LGディスプレイ** | 広州LCD工場を TCL CSOT へ売却し大型LCDを終了。WOLED（テレビ用）と iPhone 向け有機ELに集中 | 売上 約198億ドル、純利益 約3.6億ドル。**OLED比率が売上の61%**（2024年55%、2020年32%から上昇） |

> 韓国勢の戦略は「**中国勢が来られない場所へ、来られるより先に移る**」の一点。
> ただし BOE・Visionox が中小型有機ELで追い上げており、
> この逃げ切りが何年もつかが2020年代後半の焦点になっている。

## 5. 用途別：どこで何が求められているか

パネルは「テレビ用」と一括りにできない。**要求仕様がまったく違う4つの市場**がある。

| 用途 | 年間規模の目安 | 単価 | 決め手 | 誰が強いか |
| --- | --- | --- | --- | --- |
| **テレビ** | 2億台規模 | 数千〜数万円 | **面積あたりの安さ**。G10.5 の面取り効率がすべて | 中国勢（BOE・CSOT・HKC） |
| **スマートフォン** | 11〜12億台規模 | 数千円 | 薄さ・省電力・穴あけや折りたたみへの対応 | サムスンディスプレイ／BOE |
| **ノートPC・タブレット・モニタ** | 数億台規模 | 数千〜数万円 | 解像度と省電力。2026年から有機EL化が本格化 | LCDは中国勢、OLEDは韓国勢が先行 |
| **車載** | 2億面規模（1台に複数枚） | 数千〜数万円 | **10年超の供給義務・高温／振動耐性・認定** | 日本・韓国・台湾・中国が混戦。JDI・シャープ・京セラ・デンソーが残る |
| **産業・医療・航空** | 小さい（2025年で34億ドル規模） | **高い** | 長期供給・多品種少量・カスタム | 日本・台湾の中堅が強い |

> **車載と産業用が「日本勢の避難先」になった理由**は単純で、
> ここだけは**数量が少なく多品種で、10年以上同じものを供給し続ける必要がある**から。
> 中国勢の武器である「巨大ラインを1品種でフル稼働させる」やり方が効かない。
> 逆に言えば、**規模が効かない領域しか残らなかった**ということでもある。

### 車載ディスプレイが伸びている理由

- 1台あたりの**枚数が増える**：メーター＋センターディスプレイ＋助手席＋後席＋電子ミラー
- 1枚あたりの**面積が増える**：ピラー間を横断する大型ディスプレイの採用
- **高付加価値化**：Mini-LED バックライト、有機EL、曲面。Mini-LED の売上シェアは2024年の約3.0%から**2026年に10%超**へ（UBI Research 推計）
- ただし**車の台数自体は増えない**ので、「枚数×面積×単価」の掛け算で伸びる市場

## 6. 日本に残ったもの（1）装置と材料

**パネルからは撤退したが、パネルを作る道具と中身は握っている。**

| 領域 | 主な日本企業 | 立ち位置 |
| --- | --- | --- |
| **有機EL蒸着装置** | **キヤノントッキ**（キヤノン子会社） | 中小型有機ELの量産蒸着装置で**世界シェアほぼ独占**とされる。年産台数が限られ、「順番待ち」が業界の投資スケジュールを縛ると言われる |
| 露光装置（FPD用） | ニコン、キヤノン | 大型ガラス用ステッパー。ここも日本勢が中心 |
| 塗布・現像、エッチング等 | 東京エレクトロン、SCREEN、アルバック | FPD向けラインを持つ |
| **有機EL発光・周辺材料** | 出光興産、JSR、日産化学、保土谷化学 | 発光材料そのものはUDC（米）・独メルクも強いが、輸送層など周辺材料で日本勢のシェアが高い |
| **偏光板** | 日東電工、住友化学 | 液晶に必須。ただし中国・韓国勢の内製化が進行 |
| **ガラス基板** | AGC、日本電気硝子（＋米コーニングが最大手） | マザーガラスは割れやすく輸送できないため、**工場の隣に建てる**のが基本。中国投資に追随して現地化 |
| **メタルマスク（FMM）** | 大日本印刷（DNP）、凸版 | 有機ELのRGB塗り分けに必須。精密加工の塊 |
| 偏光板保護フィルム（TAC）等 | 富士フイルム、コニカミノルタ | |

> **なぜここだけ残れたのか。**
> パネルは「同じ32型なら同じ価格」のコモディティだが、
> 蒸着装置や偏光板は **「これが無いとラインが動かない」** 位置にある。
> 数量が少なくても、代替が効かないので値段を自分で決められる。
> これは [電子部品](../05_電子部品/README.md) や [半導体材料](../04_半導体材料/README.md) と
> まったく同じ構図 → [日本が負けた産業の典型例](02_日本が負けた産業の典型例.md#5-技術で勝って事業で負けたの分解)

**ただし安泰ではない**。中国のパネル各社は装置・材料の国産化を国策で進めており、
偏光板・ガラス・一部装置はすでに現地調達へ移りつつある。
残っているのは「まだ置き換えられていない」領域であり、固定された陣地ではない。

## 7. 日本に残ったもの（2）小型高精細とXR

| 領域 | 中身 |
| --- | --- |
| **マイクロOLED（シリコンOLED）** | シリコンウェハの上に有機ELを作る。**4,000ppi 級**の超高精細が可能で、1インチ前後の中に4K級を詰め込める。ソニー（半導体部門）が1.3型4K（3,552×3,840）品を商品化し、VR/AR ヘッドセット向けに供給 |
| **なぜ日本が強いのか** | これは **ディスプレイ産業ではなく半導体産業**だから。イメージセンサのバックプレーン技術（単結晶シリコン、微細配線）がそのまま効く。ガラス上のTFTでは到底届かない精細度が、半導体プロセスなら出る |
| **競合** | SeeYa／BOE系（中国）、Kopin・eMagin（米）、セイコーエプソン（自社HMD向け）。中国勢が価格で追い上げている |
| **市場の性格** | XRヘッドセットの出荷台数はまだ年数百万台規模で小さい。ただし**1枚あたりの単価が桁違いに高い**ので、金額では無視できない |

→ [メタバース・XR](../../01_注目テーマ/12_メタバース・XR/README.md) ／ [半導体（ロジック・メモリ）](../02_半導体（ロジック・メモリ）/README.md)

### マイクロLEDの位置づけ

原理的には最も優れるが、[表示の原理と方式](01_表示の原理と方式.md#4-マイクロled原理は最強組み立てが地獄) のとおり
**数千万個のLEDを1個ずつ移し替える**必要があり、量産の目処は立っていない。
市場予測は「2035年に6,058億ドル、CAGR 77.4%」といった極端に強気なものから
車載用で「2025年464万ドル → 2032年3,851万ドル」といった極小のものまで**桁が3つ以上違う**。
**調査会社ごとに定義がまったく違うため、この分野の市場予測は鵜呑みにしない**のが安全。

## 8. この産業を読むときの視点

```
  「パネルを作るか」ではなく「パネルの値段に左右されない場所にいるか」

     パネル製造          ←── 価格が2年で1/3になる世界。規模と資本の勝負
        ↑↓
     装置・材料          ←── 代替が効かない。数量は小さいが利益率は高い
        ↑↓
     小型高精細・車載     ←── 規模の経済が効かない＝中国勢の武器が効かない
        ↑↓
     完成品（テレビ等）   ←── パネルが安くなると得をする側
```

> テレビメーカーにとって、パネル価格の暴落は**コスト減**である。
> つまり同じ日本の電機でも、パネルを作っていた側と買っていた側では損得が逆になる。
> [AV機器](../10_AV機器/README.md) と合わせて読むと、この産業の全体像が見える。

## 9. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **BOE（京東方）** | 中国最大のパネルメーカー。大型LCD・中小型OLEDの両方で上位 |
| **TCL CSOT（華星光電）** | TCL傘下。LGディスプレイの広州LCD工場を買収し、大型LCDで規模を拡大 |
| **HKC（惠科）** | 中国のパネル大手。大型LCDで利益率が高いと報じられる |
| **G8.6（第8.6世代）** | 2290×2620mm。ノートPC・タブレット向け有機ELの新標準ライン。2026年から各社が立ち上げ |
| **WOLED／QD-OLED** | 大型有機ELの2方式。前者はLGディスプレイ、後者はサムスンディスプレイ |
| **AMOLED** | アクティブマトリクス型有機EL。TFTで画素ごとに制御する方式。スマホ用有機ELはほぼこれ |
| **マイクロOLED** | シリコンウェハ上に作る超高精細有機EL。XR向け。ディスプレイというより半導体の技術 |
| **稼働率調整** | 需要減に合わせて意図的に生産を落とすこと。寡占が進んだことで中国勢が採れるようになった |
| **オープンセル価格** | バックライトを付ける前のパネル価格。テレビ用パネル市況の代表指標 |
| **FMM（ファインメタルマスク）** | 有機ELのRGB塗り分けに使う精密マスク。DNP・凸版が供給 |
