# ② 音響・カメラ・その他AV（日本勢が残った領域）

このノートで分かること：テレビが崩壊する一方で、**イヤホン・ヘッドホンは市場ごと生き返り、
カメラは台数1/10でも商売として成立している**。その理由と、両者に共通する「残れる条件」を整理する。

---

## 0. 結論を先に

- **イヤホン・ヘッドホンは、ワイヤレス化で「買い替えが起きる商品」に変わった**。
  有線イヤホンは壊れるまで使うが、ワイヤレスは**電池が2〜3年で劣化する＝消耗品**になる。
  さらにノイズキャンセリングという分かりやすい付加価値が単価を押し上げた。
- **デジタルカメラはスマホに食われて台数が激減したが、残ったのは高単価の客だけ**。
  台数はピークの1割以下でも、**平均単価が数倍になったので金額は維持**されている。
- 日本勢が残った領域には共通点がある。**小さくて軽い／単価が高い／すり合わせが効く／BtoBが混じる**。
  テレビはこの4条件をすべて外していた。

## 1. 「テレビ以外のAV機器」の地図

| 分野 | 主な製品 | 日本勢の立ち位置 | 経済的な性格 |
| --- | --- | --- | --- |
| **ポータブルオーディオ** | 完全ワイヤレスイヤホン（TWS）、ヘッドホン | ソニーが世界2番手級、オーディオテクニカも健在 | 消耗品サイクルあり。単価上昇中 |
| **ホームオーディオ** | サウンドバー、AVアンプ、スピーカー | ヤマハ、デノン／マランツ（Masimo傘下→再編）、ソニー | 台数は小さいが粗利が厚い |

## 2. イヤホン・ヘッドホン：なぜ市場が「再生」したのか

### 2-1. 3つのスイッチが同時に入った

```
【有線の時代】                    【ワイヤレスの時代】

 買う ─▶ 壊れるまで使う（5年）     買う ─▶ 電池が劣化（2〜3年）─▶ 買い直す
 単価 2,000〜5,000円               単価 15,000〜40,000円
 差別化は「音」だけ                 音＋ノイキャン＋接続性＋アプリ
     ↓                                  ↓
 市場は成熟＝伸びない               買い替えサイクル＋単価上昇＝伸びる
```

1. **スマホのイヤホンジャック廃止**（2016年のiPhone 7以降が象徴）で、有線が物理的に使えなくなった
2. **左右完全分離（TWS）の技術的成立**。Bluetoothの省電力化と低遅延化で実用レベルに達した
3. **ANC（アクティブノイズキャンセリング＝逆位相の音をぶつけて騒音を打ち消す機能）**が
   「高いモデルを買う理由」になった。音質は比べにくいが、静かさは店頭で体感できる

### 2-2. 数値で見る

| 指標 | 数値 | 出典・注記 |
| --- | --- | --- |
| 世界のワイヤレスイヤホン市場 | 2025年 約60.8億ドル → 2026年 約66.3億ドル（CAGR 9.1%） | 調査会社の推計。定義により幅が大きい |
| 日本の完全ワイヤレス出荷 | 2026年に前年比+13%、約1,200万本の見込み | 調査会社の推計 |
| 上位5社の世界シェア | Apple・Huawei・Xiaomi・Samsung・boAt で約50%（2025年） | 調査会社の推計 |
| 日本のメイン利用ブランド | Apple 27.4%、ソニー 21.3%、Bose 9.6% | MMD研究所の調査（2026年） |
| 日本のワイヤレスヘッドホン実売台数シェア | ソニー 18.7%、BOSE 11.4%、ロジクール 9.4%、オーディオテクニカ 9.2% | BCN調べ（2026年7月） |

> **注意**：イヤホン市場の金額はレポート会社ごとに数倍の差がある。
> 「完全ワイヤレスだけか、ヘッドホンを含むか、小売価格か出荷価格か」で定義が違うため。
> **数字を引用するときは必ず定義を見る**。

### 2-3. なぜ日本勢（ソニー）が残れたのか

テレビと真逆の条件が揃っている。

| 条件 | テレビ | イヤホン |
| --- | --- | --- |
| 原価に占める「買ってくる部材」 | パネルで5〜6割 | ドライバー・SoC・電池に分散。特定部材への依存が低い |
| 輸送費 | 大きく重い。地産地消が有利 | 数十グラム。**世界どこへでも同じコストで送れる** |
| すり合わせの余地 | ほぼ消えた | **音のチューニングとANCのアルゴリズムは各社固有** |
| ブランドの効き方 | 店頭で価格が並ぶと効かない | 「音がいい」は信仰として効く。値引きしにくい |
| 買い替え頻度 | 7〜10年 | 2〜3年 |

ソニーの場合、**ANC用の自社チップと、音楽事業を持つグループの信用**が効いている。
→ [③ 収益構造とビジネスモデル](03_収益構造とビジネスモデル.md)

## 3. 高付加価値オーディオ：実はBtoBが本体

家庭用の派手な製品の裏で、**プロ用・業務用・車載が利益を支える**構造が各社に共通する。

| 企業 | 家庭向けの顔 | 実際の収益の柱 | 直近の数値 |
| --- | --- | --- | --- |
| **ヤマハ** | AVアンプ、サウンドバー | 楽器＋**プロ音響（ホール・スタジオ・配信向けミキサー）** | 2026年3月期は中国市況の低迷、プロ音響の高需要一巡、米国追加関税で減収減益（会社説明資料） |
| **JVCケンウッド** | ビクターのヘッドホン | **業務用無線（公共安全）・車載機器** | 2026年3月期の連結最終利益 167億円（前期比▲17.2%）、2027年3月期予想 150億円（▲10.6%） |
| **オーディオテクニカ** | ヘッドホン、カートリッジ | **業務用マイク（会議システム・放送）** | 非上場。国内ヘッドホンで上位常連 |
| **ソニー** | WF/WH-1000XMシリーズ | 業務用カメラ・放送機器、ゲーム周辺機器 | ET&S全体で2026年3月期は減収減益（後述） |

> **ポイント**：BtoBは**値引き競争が起きにくい**。
> ホールに納めたミキサーや消防無線は「安いから他社に替える」ができない（設置・訓練・保守が絡む）。
> 家庭用AVの価格が壊れても、この部分は残る。

## 4. デジタルカメラ：台数は消え、金額は残った

### 4-1. 何が起きたか

スマホのカメラが「そこそこ以上」になった時点で、**記録用のカメラは不要になった**。
一方で「スマホでは撮れない写真」を撮る層は残り、そこは**むしろ単価が上がった**。

```
【台数と単価のハサミ】

 台数  ■■■■■■■■■■■■ (2010年 約1.2億台)
        │
        │  スマホが記録用途を全部持っていった
        ▼
 台数  ■ (2025年 約944万台)   ← 1割以下

 単価  ○○           (コンデジ中心の時代)
 単価  ○○○○○○○○○  ← ミラーレス＋交換レンズ。金額はさほど減らない
```

### 4-2. CIPA統計（一般社団法人カメラ映像機器工業会）

| 区分 | 2025年実績（1〜12月） | 前年比 |
| --- | --- | --- |
| デジタルカメラ総出荷 | **9,438,876台** | 111.2% |
| うちミラーレス | **6,311,054台** | 112.5% |
| うちレンズ一体型（コンパクト） | 総出荷の**52.7%**を占めたと報じられる | 金額ベースで+62%との報道 |
| うち一眼レフ | **690,911台** | 69.3% |
| 2026年見通し（総出荷） | **959万台** | 101.6% |

> **読み方**：一眼レフが年率3割減で消えつつあり、**ミラーレスへの置き換えは完了段階**。
> 直近で目立つのは**高級コンパクトの復活**で、Vlog・SNS用途の「スマホと違う画」を求める需要とされる。
> ただし2010年代の一般用コンデジとは客層も単価もまったく別物。

### 4-3. 収益構造はレンズにある

カメラ本体（ボディ）は2〜4年で買い替えられるが、**レンズは10年以上使われ、しかも本数が増える**。
マウント（レンズ取り付け規格）を握ると、**ユーザーは他社に移れない**（＝スイッチングコスト）。

- ボディ：新型競争が激しく、開発費も重い
- レンズ：設計が長寿命、粗利が厚い、**既存ユーザーがリピートで買う**
- キヤノン（RFマウント）、ソニー（Eマウント）、ニコン（Zマウント）はいずれも
  サードパーティへのマウント開放をコントロールしており、**規格の主導権が事業価値**になっている

## 5. ゲーム機との関係

ゲーム機は分類上AV機器に入ることがあるが、**経済的にはまったく別物**。
ハードで儲けず、ソフトと課金で回収する。

| 項目 | 数値 | 注記 |
| --- | --- | --- |
| PlayStation 5 累計販売 | 約9,370万台（2026年時点） | 報道ベース |
| Nintendo Switch 2 | 発売初年度（2026年3月末まで）に約1,986万台 | 任天堂発表ベース |
| 2026年の年間出荷予測 | Switch 2 が PS5 を上回るとの見方 | 調査会社の予測。報道ベース |

AV機器としてのゲーム機の意味は2つ。

1. **テレビの最大の相棒**。4K・120Hz・低遅延といった高性能テレビを買う動機の多くはゲーム
2. **ハード薄利モデルの先輩**。テレビOSの広告モデルは、ゲーム機が先に確立した
   「本体を安く配り、後から回収する」構造の焼き直しでもある
   → [ゲーム](../../04_情報通信・IT・ネット/10_ゲーム/README.md)

## 6. 日本勢が残った領域の共通項

| 条件 | なぜ効くか | 当てはまる製品 |
| --- | --- | --- |
| **小さい・軽い** | 輸送費が効かず、世界へ同じ原価で出せる | イヤホン、カメラ、マイク |
| **単価が高い** | ブランドと技術を価格に乗せられる | ミラーレス、高級ヘッドホン、AVアンプ |
| **すり合わせが残る** | 部品を買ってきても同じ性能が出ない | 音のチューニング、レンズ光学、ANC |
| **BtoB／業務用が混じる** | 保守・訓練・規格でロックインでき、値引き圧が弱い | プロ音響、業務用カメラ、業務用無線 |
| **消耗・リピートがある** | 一度買って終わりにならない | 交換レンズ、電池劣化するワイヤレス機 |

> **逆に言えば**：大きくて・安くて・部品を組めば作れて・法人客がいない商品（＝テレビ）は
> 日本の人件費とブランドでは戦えない。これが業界全体の教訓。

## 7. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **TWS** | True Wireless Stereo。左右が完全に分離したワイヤレスイヤホン |
| **ANC** | Active Noise Cancelling。マイクで拾った騒音の逆位相をぶつけて打ち消す機能 |
| **ドライバー** | イヤホン・スピーカーで音を出す振動板ユニット。ダイナミック型／BA型などがある |
| **サウンドバー** | テレビの前に置く横長スピーカー。薄型テレビの音の弱さを補う商品として定着 |
| **ミラーレス** | 一眼レフの反射鏡を廃した構造のレンズ交換式カメラ。小型・動画に強い |
| **マウント** | カメラ本体とレンズの接合規格。ユーザーを囲い込む最大の資産 |
| **CIPA** | 一般社団法人カメラ映像機器工業会。デジタルカメラの出荷統計を月次で公表 |
| **プロ音響** | ホール・スタジオ・放送向けの業務用音響機器。BtoBで値引き圧力が小さい |
| **ディスプレイオーディオ** | ナビ機能を持たず、スマホを画面に映す車載機器。カーナビを置き換えつつある |
