# ③ 収益構造とビジネスモデル（ハードはどこで儲けるのか）

このノートで分かること：AV機器の会社が**「何を売って、どこで利益を取っているのか」**を4つの型に分けて整理し、
ブランドライセンス化・合弁化がP/L（損益計算書）とB/S（貸借対照表）に何をもたらすかを見る。
最後に、サブスク時代にハードが置かれた立ち位置を確認する。

---

## 0. 結論を先に

- AV機器の儲け方は**4つの型**しかない。①単品売り切り、②ハード薄利＋サービス回収、
  ③ブランドライセンス、④BtoB業務用。**テレビは①しか持たなかったので崩れた**。
- **ライセンス化・合弁化は「売上を捨てて利益率と資本効率を買う」操作**。
  連結売上は減るが、工場も在庫も持たなくてよくなり、ROIC（投下資本利益率）は上がる。
- サブスク時代、ハードは**「サービスへの入口（端末）」**に位置づけが変わった。
  入口を押さえた者が、後ろで流れるお金から取り分を得る。

---

## 1. 儲け方の4類型

| 型 | 儲け方 | 代表例 | 営業利益率の目安 | 弱点 |
| --- | --- | --- | --- | --- |
| **①単品売り切り** | 原価に利幅を乗せて売る。以後の収入なし | テレビ、白物家電、カメラ | テレビ 0〜3%（赤字も常態）／カメラは高め | 値引き競争で利幅が消える |
| **②ハード薄利＋サービス** | 本体は原価近くで配り、後から回収 | ゲーム機、テレビOS、スマートスピーカー | ハード単体は低〜マイナス、サービスは数十% | 入口（OS・ストア）を持つ者しか使えない |
| **③ブランドライセンス／合弁** | 名前と技術を貸し、ロイヤルティや持分利益を得る | 東芝→ハイセンス、ソニー→TCL合弁 | 売上は小さいがほぼ原価ゼロ | ブランドが劣化すると収入も消える |
| **④BtoB業務用** | 法人へ機器＋保守を納める | プロ音響、業務用カメラ、業務用無線 | 10%前後〜 | 案件型で伸びが緩やか |

> **ポイント**：日本のAVメーカーの再建は、ほぼすべて
> **「①から③・④へ移る」**という同じ形をしている。②に移れたのはソニーのゲームくらい。

## 2. 単品売り切りモデルはなぜ苦しいか

```
【テレビ1台の損益イメージ（推計）】

 売価 100 ─┬─ パネル       55  ← 市況で上下。交渉力は中国大手が上
           ├─ 半導体・部品  20
           ├─ 組立・物流     8
           ├─ 販促・リベート 10  ← 量販店への販売協力金。年末商戦で膨らむ
           ├─ 開発・保証      5
           └─ 営業利益       2  ← パネルが5ポイント上がるだけで赤字
```

- **季節性が極端**：年末商戦とスポーツイベント（五輪・W杯）に需要が寄る。
  読み違えると**在庫が一気に不良化**する。テレビは陳腐化が早く、値下げでしか捌けない
- **売り場が価格を作る**：家電量販とECでは型番が横並びで比較される。
  ブランドは「同じ値段ならこっち」には効くが、**価格差を正当化するほどには効かない**
- **為替が直撃**：部材はドル建て、売上は現地通貨。円安は輸入部材コストを押し上げる
  → [家電量販](../../07_小売・流通/06_家電量販/README.md)

## 3. ハード薄利＋サービス回収の3パターン

| パターン | 入口 | 回収経路 | 実例 |
| --- | --- | --- | --- |
| **ゲーム機型** | 本体 | ソフトのロイヤルティ、サブスク（PS Plus）、ストア手数料 | PlayStation |
| **テレビOS型** | ホーム画面 | 広告枠、配信アプリへの送客料、視聴データ | Fire TV、Google TV、Tizen、Roku |
| **エコシステム型** | 周辺機器 | 本体（スマホ）の囲い込みを強め、買い替えを維持 | AirPods と iPhone |

### 3-1. なぜ「薄利で配る」が合理的になるのか

一度置かれた端末は**数年間、毎日使われる**。
1台あたりの粗利を1,000円削っても、その端末が**3年間で広告・手数料を数千円生む**なら、
**配ったほうが得**になる。これがハードを「顧客獲得コスト」とみなす発想。

> **日本勢が②に行けなかった理由**：回収する側のサービス（OS、ストア、広告在庫）を持っていなかった。
> テレビを作る技術はあっても、**広告を売る営業組織とアドテクがない**。
> 逆にソニーは、ゲームでだけこの構造を先に作ってあった。
> → [① テレビという事業の崩壊と現在](01_テレビという事業の崩壊と現在.md)

## 4. ブランドライセンス・合弁は何を変えるのか

```
【自前でテレビを作る】            【合弁・ライセンスに出す】

 連結売上 ：大きい（数千億円）     連結売上 ：ほぼ消える
 営業利益 ：ほぼゼロ〜赤字         営業利益 ：ロイヤルティ＝ほぼ全額が利益
 在庫     ：抱える（季節変動）     在庫     ：持たない
 工場・設備：持つ（減価償却）      工場・設備：持たない
 投下資本 ：大きい                投下資本 ：小さい → ROICが上がる
 リスク   ：パネル市況・為替       リスク   ：ブランドの毀損、パートナー依存
```

| 打ち手 | 会計上の扱い | 実例 |
| --- | --- | --- |
| **事業売却** | 連結から外れる。売却損益が一括計上 | 東芝の映像事業をハイセンスへ（2018年）／日立の家電事業をノジマへ（2026年4月） |
| **販売移管＋開発協業** | 販売機能だけ相手に渡し、開発は残す | パナソニックが欧米のテレビ販売をスカイワースへ移管（2026年） |
| **合弁（少数持分）** | 連結を外れ、**持分法投資利益**として一行で計上 | ソニーのホームエンタテインメント事業をTCL51%／ソニー49%の新会社「BRAVIA」へ（2027年4月開始予定、企業価値約1,028億円、TCL取得額約754億円） |
| **破産・清算** | 事業消滅 | 船井電機（2024年10月、負債約461億円） |

> **投資家目線での意味**：売上規模は企業価値に直結しない。
> 「赤字の売上5,000億円」を「利益だけ拾う持分49%」に変えれば、**見かけは縮んでも企業価値は上がる**。
> 総合電機各社が10年以上かけてやってきたことと同じ論理。
> → [事業ポートフォリオ経営（総合電機）](../01_総合電機/03_事業ポートフォリオ経営.md)

## 5. ソニーの事業間シナジーは実際のところ何か

ソニーはよく「ハードとコンテンツの両方を持つ稀有な会社」と説明されるが、
**シナジーの中身を具体化しないと精神論になる**。実務的には次の3つに分解できる。

| シナジーの種類 | 具体的な中身 | 効き方 |
| --- | --- | --- |
| **技術の横展開** | イメージセンサー技術がカメラ・スマホ・車載へ／音響処理がイヤホンとゲーム機へ | 開発費を複数事業で割れる |
| **規格の主導** | 映像・音の規格（Hi-Res、空間オーディオ等）を制作側と機器側の両方から押せる | 業界標準を取れると長期の優位 |
| **ブランドと顧客接点** | 映画・音楽・ゲームで築いた信用が、イヤホンやカメラの値付けを支える | 値引きせずに売れる |

一方で、**部品共通化や製造の共用といった「工場レベルのシナジー」はほとんどない**。
テレビとゲーム機とイメージセンサーは、作る場所も客も別だからだ。
だからこそ、テレビのような「シナジーが効かないハード」は切り離す判断になった。

### 5-1. ソニーの中でAVハードが占める位置

| セグメント | 位置づけ | 直近（2026年3月期） |
| --- | --- | --- |
| ゲーム&ネットワークサービス | 最大の柱。ソフト・サブスクで稼ぐ | 増益（為替とネットワークサービス） |
| 音楽 | 原盤・楽曲の権利収入。ストリーミングで成長 | 大幅増収増益 |
| 映画 | 制作・配給、他社配信向け受託 | — |
| イメージング&センシング（I&SS） | CMOSイメージセンサー。スマホ→車載へ | 大幅増収増益 |
| **ET&S（テレビ・カメラ・オーディオ）** | **本ノートの対象。AVハードそのもの** | **売上高 約2.26兆円、営業利益 約1,586億円。ディスプレイ数量減で減収減益（報道ベース）** |
| 全社 | — | 売上高 12兆4,796億円（+3.7%）、営業利益 1兆4,475億円（+13.4%、過去最高） |

> **読み方**：全社営業利益1.4兆円のうち、**AVハードを含むET&Sは1割強**。
> しかもその中身はカメラと業務用が中心で、テレビは足を引っ張る側だった。
> **「ソニー＝AV機器の会社」というイメージは、少なくとも損益上はもう成り立たない**。
> → [総合電機：各社の再編史と現在の稼ぎ頭](../01_総合電機/02_各社の再編史と現在の稼ぎ頭.md)

## 6. サブスク時代、ハードはどこに立つのか

```
【お金の流れ】

 視聴者 ──(月額)──▶ 配信サービス ──(手数料/送客料)──▶ テレビOS事業者
   │                    │                                    │
   │                    └─(制作費)─▶ 制作会社・IPホルダー     │
   └─(端末購入)──▶ メーカー ◀───(OS採用料・広告分配)────────┘
                     ↑
             ここだけ「一度きり」の収入
```

- **ハードは一度しかお金を生まない**。サービスは毎月生む。この非対称が構造のすべて
- したがってメーカーの戦略は2択になる。
  **(a) 入口の取り分をもらう側に回る**（OS採用料・広告分配・アプリ送客のレベニューシェア）、
  **(b) 買い替えが頻繁に起きる商品に移る**（イヤホン、レンズ、消耗品）
- 日本勢の現実的な答えは (b) が中心で、(a) は海外OS事業者に握られている
  → [動画・音楽配信](../../04_情報通信・IT・ネット/12_動画・音楽配信/README.md)

## 7. 決算を読むときのチェックリスト

- [ ] **セグメント名に騙されない**。「テレビ」という区分は多くの会社にもう存在せず、
      業務用や周辺機器と一緒くたにされている
- [ ] **出荷台数と売上を分けて見る**。台数減・単価増（カメラ）と、台数横ばい・単価減（テレビ）は別の話
- [ ] **一過性を除く**。事業売却益、構造改革費用、減損は毎年は出ない
- [ ] **持分法投資利益の行を見る**。合弁に出した事業はここに1行で現れる
- [ ] **為替前提を確認する**。AVは輸出入の両建てなので、円安が追い風か逆風かは会社ごとに違う
- [ ] **パネル市況・部材市況のコメントを探す**。テレビ系は必ずここが増減益の説明に出てくる

## 8. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **売り切りモデル** | 販売時点で収益が完結し、その後の継続収入がない商売の形 |
| **ロイヤルティ** | ブランドや特許の使用料。原価がほぼかからないため利益率が極めて高い |
| **持分法投資利益** | 20〜50%程度出資した会社の利益を、出資比率分だけ1行で取り込む会計処理 |
| **ROIC** | 投下資本利益率。事業に突っ込んだお金に対してどれだけ利益を生んだか |
| **レベニューシェア** | 売上や広告収入を、関与した事業者どうしで分け合う契約 |
| **リベート（販売協力金）** | メーカーが量販店に払う販促費。実質的な値引きとして機能する |
| **CAC / LTV** | 顧客獲得コストと顧客生涯価値。ハードを安く配る判断はこの比較で行う |
| **一過性損益** | 事業売却益や減損など、その期だけ発生する損益。実力値を見るときは除く |
