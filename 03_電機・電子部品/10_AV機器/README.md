# AV機器

- 大分類: 電機・電子部品
- 状態: done
- 更新日: 2026-09-20

**ひとことで言うと**：映像と音を扱う民生機器（テレビ、オーディオ、カメラ）の業界。
かつて日本のお家芸だったが、**部品のモジュール化で「誰でも作れる」商品になり、
利益はハードから“テレビOSと広告”へ移った**。日本勢が残ったのは小型・高単価・BtoBの領域だけ。

## 1. 業界の定義・範囲

**AV機器＝Audio Visual機器**。映像と音を扱う民生用の電子機器を指す。
業界用語では白物家電（冷蔵庫・洗濯機など）に対して**「黒物家電」**と呼ばれてきた。

| 含まれるもの | 含まれないもの（隣接） |
| --- | --- |
| テレビ（液晶・有機EL）、レコーダー、プロジェクター | PCモニター、サイネージ用ディスプレイ → [ディスプレイ](../07_ディスプレイ/README.md) |
| イヤホン・ヘッドホン、スピーカー、AVアンプ、サウンドバー | スマートスピーカー（IT側で扱われることが多い） |
| デジタルカメラ、ビデオカメラ、交換レンズ | スマートフォンのカメラ → [PC・スマートフォン](../11_PC・スマートフォン/README.md) |
| カーナビ、ディスプレイオーディオ、ドライブレコーダー | 完成車そのもの → [自動車（完成車）](../../02_自動車・機械/01_自動車（完成車）/README.md) |
| 業務用カメラ、プロ音響機器 | 放送局そのもの → [テレビ・ラジオ](../../14_メディア・広告・エンタメ/05_テレビ・ラジオ/README.md) |
| ゲーム機（分類により含む） | ゲームソフト・課金 → [ゲーム](../../04_情報通信・IT・ネット/10_ゲーム/README.md) |

```
【AV機器を3つの層で見る】

  映像（見る）        音（聴く）           記録（撮る）
  ┌──────────┐  ┌──────────────┐  ┌──────────────┐
  │ テレビ    │  │ イヤホン/ヘッドホン │  │ ミラーレス    │
  │ プロジェクタ│  │ スピーカー/サウンドバー│ │ 交換レンズ    │
  │ レコーダー │  │ AVアンプ/プロ音響   │  │ ビデオカメラ  │
  └──────────┘  └──────────────┘  └──────────────┘
   崩壊した領域        再生した領域          縮小し高級化した領域
   （日本勢ほぼ撤退）  （ソニー等が健在）     （日本勢が寡占）
```

> **境界の引き方の注意**：JEITAの「民生用電子機器」統計はテレビ・音声機器・カーAVを含むが、
> カメラはCIPA（カメラ映像機器工業会）が別に統計を取る。**数値を引くときは母集団を必ず確認する**。

## 2. 市場規模と成長性

| 指標 | 数値 | 時点・出典 |
| --- | --- | --- |
| 世界のテレビ出荷台数 | 2026年Q1 **4,712万台**（前年同期比+3.3%） | TrendForce調査、報道ベース |
| 世界のテレビ出荷（通年予測） | 2026年 **1億9,420万台**（前年比▲1%） | TrendForce予測、報道ベース |
| 国内の薄型テレビ出荷 | 2026年1月 **351千台**（前年比104.8%）、5月 **280千台**（85.4%） | JEITA 民生用電子機器国内出荷統計 |
| 世界のワイヤレスイヤホン市場 | 2025年 約60.8億ドル → 2026年 約66.3億ドル（CAGR 9.1%） | 調査会社の推計。定義で幅が大きい |
| 国内の完全ワイヤレス出荷 | 2026年 約1,200万本（前年比+13%）の見込み | 調査会社の推計 |
| デジタルカメラ世界出荷 | 2025年 **9,438,876台**（前年比111.2%）／2026年見通し **959万台**（101.6%） | CIPA |
| 国内CTV広告需要 | 2025年 **1,295億円**（前年比127%） | 調査会社の推計、報道ベース |

**成長性の読み方**

- **テレビは「台数横ばい・金額微減」**。市場が消えたのではなく、**安い会社がシェアを取った**
- **イヤホンは数少ない成長分野**。ワイヤレス化で買い替えサイクルが生まれた
- **カメラは下げ止まり**。台数はピーク（2010年 約1.2億台）の1割以下だが、単価上昇で金額は残っている
- **最も伸びているのはハードではなく広告**（CTV広告）。市場の主役が入れ替わった

## 5. 収益モデル・コスト構造

AV機器の儲け方は4つしかない。詳細は [③ 収益構造とビジネスモデル](03_収益構造とビジネスモデル.md)。

| 型 | 儲け方 | 代表例 | 利益率の目安 |
| --- | --- | --- | --- |
| ①単品売り切り | 原価に利幅を乗せる。以後の収入なし | テレビ、カメラ | テレビ 0〜3%（赤字も常態） |
| ②ハード薄利＋サービス | 本体を原価近くで配り後から回収 | ゲーム機、テレビOS | サービス側は数十% |
| ③ブランドライセンス／合弁 | 名前と技術を貸す | 東芝→ハイセンス、ソニー→TCL | 原価ほぼゼロ |
| ④BtoB業務用 | 機器＋保守を法人へ | プロ音響、業務用無線 | 10%前後〜 |

**テレビのコスト構造（推計）**：パネル50〜60%／半導体10〜15%／電源・機構10%前後／
組立・物流5〜10%／残りが開発・販促。**パネル市況が5ポイント動くだけで黒字と赤字が入れ替わる**。

## 6. 競争要因（KSF）と参入障壁

| 要因 | テレビ | イヤホン・カメラ |
| --- | --- | --- |
| **規模（調達力）** | 決定的。年2,000万台級でないとパネルを安く買えない | 相対的に低い |
| **技術のすり合わせ** | ほぼ消えた（モジュール化） | **残っている**（音のチューニング、ANC、光学設計） |
| **ブランド** | 価格差を正当化できない | 「音がいい」「画がいい」が値引き回避に効く |
| **規格・囲い込み** | 弱い | **カメラのマウント**が強力なスイッチングコストになる |
| **制度の壁** | 日本は地デジチューナーとACASチップが必要で、海外モデルを直接持ち込めない | 特になし |
| **販路** | 量販店・ECで価格が横並びになる | 同左だが単価が高く値引き耐性がある |

> **参入障壁の逆説**：テレビは**参入が易しく、退出も易しい**商品になった。
> だからこそ誰でも入ってきて、利益が消えた。障壁の低さが業界を壊した典型例。

## 7. 規制・法制度

| 制度 | 内容 |
| --- | --- |
| **家電リサイクル法**（特定家庭用機器再商品化法） | エアコン・テレビ・冷蔵庫・洗濯機が対象。テレビはブラウン管／液晶／プラズマに加え、**令和6年度から有機ELテレビも追加**。消費者がリサイクル料金を負担し、メーカーが再商品化義務を負う |
| **省エネ法（トップランナー制度）** | 市場で最も効率の良い機種を基準に目標値を設定。テレビも対象で、大画面化と省エネの両立が設計制約になる |
| **放送法・電波法** | 地上デジタル／BS／CSの受信仕様。日本で「テレビ」を売るにはチューナーとACASチップが必要 |
| **電気用品安全法（PSE）** | 電源を持つ機器の安全基準。PSEマークがないと販売できない |
| **電波法（技適）** | Bluetooth／Wi-Fiを使う機器は技術基準適合証明が必要。イヤホンも対象 |
| **通商政策** | 米国の追加関税が2025〜2026年の各社業績に影響したと各社が説明している |

## 9. 用語メモ

各ノート末尾にも用語メモがある。ここでは業界全体で頻出するものだけ。

| 用語 | 意味 |
| --- | --- |
| **黒物家電** | テレビ・オーディオなど映像音響機器の通称。冷蔵庫等の「白物家電」と対になる |
| **モジュール化** | 部品が規格品化し、組み合わせるだけで製品が作れる状態。すり合わせの価値が消える |
| **テレビOS** | テレビ内蔵のソフト基盤。Tizen／webOS／Google TV／Fire TV／VIDAA など |
| **CTV** | Connected TV。ネットにつながったテレビ画面。広告の出稿先として独立市場を形成 |
| **TWS / ANC** | 完全ワイヤレスイヤホン／アクティブノイズキャンセリング |
| **ミラーレス／マウント** | 反射鏡を廃したレンズ交換式カメラ／レンズ接合規格。マウントが囲い込みの資産 |
| **EMS** | 電子機器の製造受託会社。鴻海が代表格 |
| **ACASチップ** | 日本の放送のコンテンツ保護を担うチップ。B-CASカードの後継 |
| **JEITA / CIPA** | 電子情報技術産業協会（民生用電子機器の出荷統計）／カメラ映像機器工業会（カメラ統計） |
