# ① テレビという事業の崩壊と現在

このノートで分かること：**なぜテレビは「作れば作るほど赤字」の商品になったのか**、
そして日本メーカーがそこからどう退却し、**価値がハードからテレビOS（ソフト）と広告へ移った**のかを追う。

---

## 0. 結論を先に

- テレビが儲からなくなった理由は不況でも技術力の差でもなく、**「誰でも作れるようになった」こと**に尽きる。
  部品がモジュール化（規格品の組み合わせ）され、パネルは外から買えるようになった。
  すると価格以外に差がつかず、**一番安く作れる会社が勝つゲーム**に変わった。
- 日本勢の答えは3つに収束した。**撤退／ブランドだけ貸す（ライセンス）／中国勢と組む（合弁）**。
  2026年にはソニーまでがテレビ事業をTCLとの合弁へ移す決定をした。
- 一方で**テレビというハコの上の「OS」には価値が移った**。
  Google TV、Fire TV、Tizen などが入口を押さえ、**ホーム画面の広告枠**という新しい収益源が生まれた。

> **要点**：テレビ業界を理解する鍵は「箱を売る商売」と「箱の中のOSで稼ぐ商売」が
> 完全に分離したこと。前者は薄利、後者は高収益。日本勢は前者側に残ってしまった。

---

## 1. かつてテレビが儲かっていた理由＝垂直統合

1990年代までのテレビは「自社でしか作れない」商品だった。

- ブラウン管（CRT）は**自社のガラス・蛍光体・電子銃**でしか性能が出ず、
  画質は各社の**アナログ回路の作り込み（すり合わせ）**で差がついた
- 大型のブラウン管は重くて壊れやすく、**輸送費が高い＝地産地消**。新興国は簡単に参入できない
- 流通も系列電器店（ナショナルショップ、東芝ストアなど）が押さえていた

つまり**技術・製造・流通のすべてが内側で閉じていた**から、価格を守れた。

```
【垂直統合の時代（〜2000年代前半）】

 ガラス・蛍光体 ─▶ ブラウン管 ─▶ 回路設計 ─▶ 組立 ─▶ 系列店
   自社/系列        自社工場      自社技術陣   自社     自社販路
   └──────────── すべて内側 ＝ 真似できない ────────────┘
```

---

## 2. 何が壊したか：4つの力

### 2-1. デジタル化＝モジュール化

液晶になった瞬間、**画を出す仕事がパネルと半導体（SoC）に移った**。
SoC（System on a Chip＝映像処理・チューナー・OSを1チップに載せた部品）を買ってきて、
パネルと電源と外装を組めば、テレビは動く。**アナログ回路の職人芸が要らなくなった**。

### 2-2. パネルが「買えるもの」になった

液晶パネルは**巨大な設備投資を回して初めて安くなる装置産業**。
第10世代クラスの工場は1本で数千億〜1兆円規模。テレビメーカーが自前で持つのは無理筋になり、
**パネルは外から買う部材**になった。これで最大の差別化要因が共通化した。
→ [ディスプレイ](../07_ディスプレイ/README.md)

### 2-3. 中国勢の登場（自国パネル＋巨大な内需）

中国のパネルメーカー（BOE、China Star、HKC）は面積ベースで**世界の生産能力の約6割**を握るとされる
（2025年時点、報道ベース）。韓国勢はテレビ用液晶から退き、サムスンディスプレイは2022年に完全撤退、
LGディスプレイも広州工場のテレビ用液晶生産を2025年3月までに終えたと報じられる。
**「パネルを作る国」と「テレビを作る国」が同じになった**ことが決定的だった。

### 2-4. 値段の壊れ方が非対称

パネル価格が上がるときは店頭価格に転嫁しにくく、下がるときはすぐ値下げ競争になる。
**原価は上にブレやすく、売価は下にブレやすい**。これが常態化すると赤字が構造化する。

```
【モジュール化後（2010年代〜）】

 パネル ──┐
 SoC   ──┼─▶ 組立（EMS/自社）─▶ 量販店・EC
 電源   ──┘        誰でもできる       価格比較される
   ↑
   ここに価値が集中（中国・台湾）
   テレビメーカーに残るのは「ブランド」と「画質チューニング」だけ
```

## 3. テレビ1台の原価はどうなっているか

| 費目 | 目安の比率 | 補足 |
| --- | --- | --- |
| **液晶／有機ELパネル** | 50〜60% | 最大の変動費。市況で上下する |
| SoC・メモリなどの半導体 | 10〜15% | 台湾・中国のチップが主流 |
| 電源・バックライト・機構部品 | 10%前後 | ミニLEDは素子数が多くコスト増 |
| 組立・物流 | 5〜10% | 大型化するほど輸送費が効く |
| 開発費・ブランド・販促 | 残り | ここを削ると差別化が消える |

※比率は各種報道・業界解説をもとにした**おおまかな推計**。機種・サイズで大きく変わる。

> **なぜ利益が出ないか**：原価の過半を占めるパネルを外部から買っている以上、
> **調達量が多い会社（＝中国大手）が自動的にコストで勝つ**。
> 年間数百万台の日本勢と、年間2,000万台級の中国勢では、同じパネルでも仕入れ値が違う。

## 4. 日本勢の3つの出口

| 出口 | 中身 | 実例 |
| --- | --- | --- |
| **①撤退・清算** | 事業そのものをやめる | 船井電機（FUNAI）が2024年10月24日に破産手続開始決定。負債は2024年3月末で約461億円 |
| **②ブランドだけ貸す／売る** | 開発・製造は他社。名前と保証だけ残す | 東芝の映像事業 → 2018年に中国ハイセンス傘下へ（現 TVS REGZA）。日立は家電事業をノジマへ売却（2026年4月） |
| **③外資の傘下・合弁に入る** | 資本ごと組む | シャープは2016年に鴻海（ホンハイ）傘下へ。パナソニックは欧米のテレビ販売を中国スカイワースへ移管（2026年）。ソニーはTCLとの合弁「BRAVIA」へ承継（2027年4月開始予定） |

### 4-1. ソニーのTCL合弁（2026年の最大の事件）

2026年1月20日発表。ソニーの**ホームエンタテインメント事業（テレビ・ホームオーディオ）を新会社へ承継**し、
**TCL Electronics が51%、ソニーが49%**を保有する。譲渡対象事業の企業価値は**約1,028億円**、
TCLの取得額は**約754億円**。新会社の社名は**BRAVIA**で、製品には引き続き「ソニー」「ブラビア」の
名を付ける。事業開始は**2027年4月**を想定。

> **これが意味すること**：ソニーは「テレビを作る会社」をやめ、
> **ブランドと画質技術をライセンスして49%の持分で果実だけ受け取る**形に変えた。
> 資本を使わずに名前で稼ぐ、②と③の中間形。
> → [③ 収益構造：ハードは薄利、稼ぐのは別の場所](03_収益構造とビジネスモデル.md)

### 4-2. その結果どうなったか（日本市場）

BCNの集計によると2025年1〜12月の国内薄型テレビ販売台数シェアは**TVSレグザ 26.0%、シャープ 19.0%、
ハイセンス 17.6%、TCL 10.8%、ソニー 8.4%**と報じられる。1位のレグザもハイセンス傘下なので、
**国内で売れているテレビの過半は中国資本**。ソニーのTCL移管が実行されれば「中国系が6割」との見方もある。

## 5. 世界シェアの現状

| 順位（2026年Q1、TrendForce調査ベース） | ブランド | 特徴 |
| --- | --- | --- |
| 1 | **サムスン電子（韓国）** | 高価格帯を押さえ続けている。OSはTizen |
| 2 | **TCL（中国）** | 2026年Q1出荷768万台（前年同期比+11.3%）。ミニLEDと大型で伸長 |
| 3 | **ハイセンス（中国）** | レグザ（日本）、東芝ブランドを保有。調査会社によっては2位 |
| 4 | **LG電子（韓国）** | 有機ELが主力。OSはwebOS |
| 5 | **シャオミ（中国）** | 低価格＋スマホ連携 |

2026年Q1の世界出荷は**4,712万台（前年同期比+3.3%）**、通年では**1億9,420万台（前年比▲1%）**
との予測が報じられている（TrendForce）。

> **台数は横ばいなのに、儲けは中国へ移った**。市場が縮んだのではなく、
> **同じ台数を安い会社が取った**というのが正しい理解。

## 6. 価値はどこへ移ったか：テレビOSと広告

テレビが「安いハコ」になった結果、**ハコの中で入口を押さえるOS**に価値が移った。

```
【価値の移動】

 むかし： メーカー ──(テレビを売る)──▶ 視聴者
            ↑ここで利幅を取る

 いま  ： メーカー ──(原価ギリギリで売る)──▶ 視聴者
                                        ↑
                          テレビOS事業者 ─┘
                          ホーム画面／レコメンド／広告枠で稼ぐ
```

| テレビOS | 提供元 | 収益の取り方 |
| --- | --- | --- |
| **Tizen** | サムスン | 自社テレビに搭載。ホーム画面のスポンサー枠と自社FASTチャンネル |
| **webOS** | LG電子 | 自社搭載に加え、他社へ外販も開始 |
| **Google TV / Android TV** | Google | 各社へライセンス。アプリ課金と広告。ソニー・TCL・シャープなどが採用 |
| **Fire TV** | Amazon | ホーム画面の広告が最も多いとされる。EC送客と一体 |
| **VIDAA** | ハイセンス | 自社系列（レグザ含む）で採用。安価な垂直統合 |
| **Roku** | Roku | 北米中心。ハードは薄利、広告が本業 |

OSシェアは2024年Q4時点で**Android／Google TVが世界のスマートテレビ出荷の24%超、Tizen 16.9%、
webOS 11.8%、Roku 9%**と報じられる（Omdia等の推計）。

### 6-1. なぜOSが儲かるのか

テレビは**1日数時間、家族全員が見る画面**で、しかもリビングにある。
この画面の「最初に出るホーム画面」を押さえると、次の3つが取れる。

1. **広告枠**：ホーム画面のバナー、動画配信サービスのプロモ枠
2. **送客料**：配信アプリへの誘導1件あたりの手数料、アプリ内課金の取り分
3. **視聴データ**：ACR（画面に映っている内容を自動判別する仕組み）で「何を見たか」を取得し広告に使う

> **ハードの利益率が1〜2%でも、広告の利益率は数十%**。
> だからOS事業者は**テレビを原価割れで売ってもよい**という発想になる。
> 日本勢はハードだけを持ち、この収益源を持たなかった。

## 7. 日本固有の事情：TVer・地上デジタル・ACAS

日本のテレビは**放送法と受信機の制度**に縛られており、海外とまったく同じ構図にはならない。

- **チューナーとACASチップ**：日本で「テレビ」として売るには地デジ／BS／CSのチューナーと、
  ACASチップ（番組の著作権保護を扱うチップ。B-CASカードの後継）が要る。海外モデルをそのまま
  持ち込めない**参入障壁**であり、日本メーカーが細々と残れた理由でもある
- **TVer**：民放公式の無料配信。2026年1月時点で月間4,470万MUBを突破したと発表。テレビ画面
  （CTV＝コネクテッドTV）での視聴が増え、**OSにとってTVerアプリの置き場所が価値**になった
- **国内CTV広告**：2025年の需要は**1,295億円（前年比127%）**との推計。TVerの運用型広告
  「TVer広告」は2025年度売上が前年度比166%
  → [テレビ・ラジオ](../../14_メディア・広告・エンタメ/05_テレビ・ラジオ/README.md)、[ネット広告](../../04_情報通信・IT・ネット/07_ネット広告/README.md)

## 8. 制度：家電リサイクル法と省エネ

- **家電リサイクル法**（特定家庭用機器再商品化法）：エアコン・テレビ・冷蔵庫・洗濯機が対象。
  テレビはブラウン管／液晶／プラズマに加え、**令和6年度から有機ELテレビも対象品目に追加**された。
  消費者がリサイクル料金を負担し、メーカーが再商品化義務を負う
- **省エネ法のトップランナー制度**：市場で最も効率の良い機種を基準に目標値を設定する方式。
  テレビも対象機器で、**大画面化と省エネ基準の両立**が設計制約になる

## 9. これから起きそうなこと

| 論点 | 見立て |
| --- | --- |
| **大型化** | 65型以上が主戦場。輸送と設置の制約から、地産地消の組立が有利 |
| **ミニLED vs 有機EL** | 中国勢がミニLED（小さなLEDを敷き詰めて明暗を細かく制御）を武器に高価格帯へ。有機ELは韓国勢の牙城 |
| **8K** | コンテンツが揃わず、事実上普及していない。4Kで止まった |
| **AI搭載テレビ** | 2026年、TCL日本法人が「世界初のGemini搭載TV」を訴求するなど、**OS上のAIアシスタント**が新しい売り文句に |
| **広告付きテレビOS** | ハードを安く売り、OS広告で回収するモデルが標準化しつつある |

## 10. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **モジュール化** | 部品が規格品化し、組み合わせるだけで製品が作れる状態。すり合わせの価値が消える |
| **SoC** | System on a Chip。映像処理・チューナー・OS実行を1チップに集約した半導体 |
| **EMS** | Electronics Manufacturing Service。製造受託会社。鴻海が代表格 |
| **ミニLED** | バックライトのLEDを微細化・多分割し、明暗のコントラストを上げる方式 |
| **テレビOS** | テレビ内蔵のソフト基盤。Tizen／webOS／Google TV／Fire TV／VIDAA など |
| **CTV** | Connected TV。ネットにつながったテレビ画面。広告の出稿先として独立した市場を形成 |
| **FAST** | Free Ad-supported Streaming TV。広告付きの無料チャンネル。OS事業者が自前で持つ |
| **ACR** | Automatic Content Recognition。テレビが表示中の映像・音声を判別し視聴データを取る仕組み |
| **ACASチップ** | 日本の放送の著作権保護（コンテンツ保護）を担うチップ。B-CASカードの後継 |
| **パネル市況** | 液晶パネルの取引価格の水準。テレビの原価の過半を占めるため損益を直撃する |
