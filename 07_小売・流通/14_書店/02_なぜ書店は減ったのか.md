# なぜ書店は減ったのか ── 1万店割れに至る算数

このノートで分かること：**書店数がピークの4割まで減った経緯**と、その裏にある「粗利22%では家賃と人件費を賄えない」という単純な算数。そして、とどめを刺したのが**本離れではなく雑誌の消滅**だったこと。

> ポイント：書店が減った直接の犯人はAmazonでも電子書籍でもない。**雑誌である**。雑誌が書店に運んできていた「毎週来る客」と「回転の速い粗利」が消えたことで、粗利22%の商売が物理的に成立しなくなった。

---

## 1. 数字で見る書店の消滅

### 1-1. 書店数の推移

| 年度                        | 書店数                         | 備考                                             |
| --------------------------- | ------------------------------ | ------------------------------------------------ |
| 1998年度                    | **24,237店**                   | ピーク（日本出版インフラセンター／JPO 調査）     |
| 2010年度                    | 約15,000店台                   | ピークから約4割減                                |
| 2020年度                    | 約11,000店台                   |                                                  |
| 2024年度                    | 10,417店                       |                                                  |
| **2025年度末（2026年3月）** | **9,993店**（前年度比 −424店） | **調査開始以来はじめて1万店割れ**。ピークの約41% |

- 2025年度の内訳は **開業102店・閉店499店**。閉店が開業の約5倍
- 「1日に1店以上が消えている」計算になる

```
【書店数の推移（イメージ・千店）】

 25 ┤●24.2（1998年度）
 20 ┤   ●
 15 ┤        ●
 12 ┤              ●
 10 ┤                   ●10.4（2024年度）
  9 ┤                      ●9.99（2025年度末）← 初の1万店割れ
    └┬────┬────┬────┬────┬────┬──
    1998  2005  2010  2015  2020  2026
```

### 1-2. 無書店自治体

**無書店自治体＝書店が1軒もない市区町村**。出版文化産業振興財団（JPIC）が調査している。

| 時点                | 無書店自治体  | 全市区町村に占める割合 |
| ------------------- | ------------- | ---------------------- |
| 2022年9月（初調査） | 456自治体     | 約26%                  |
| 2024年11月          | 493自治体     | 28.2%                  |
| **2026年3月**       | **510自治体** | **29.3%（約3割）**     |

- 地域差が大きい。沖縄県56.1%、長野県54.5%、奈良県51.3% は**過半数の自治体に書店がない**一方、広島県・香川県は全自治体に書店がある（2024〜2025年時点の公表値）
- 都道府県別の差は「人口密度」よりも「町村の細かさ」と「モールの分布」に効かれている面がある

> 書店は「文化のインフラ」と言われるが、**インフラとして扱われてこなかった**ことがこの数字の意味。電気・水道と違ってユニバーサルサービス義務がなく、民間の採算だけで配置が決まる。

## 2. 算数の話 ── 粗利22%で何が払えるのか

[① 再販制度と委託販売](01_再販制度と委託販売.md) の通り、書店の粗利率は約22%に固定されている。これが何を意味するか、逆算してみる。

### 2-1. 「家賃を払うのに必要な売上」を逆算する

```
【家賃60万円/月を粗利で賄うには、いくら売ればよいか】

  必要粗利 ＝ 家賃 60万円
  粗利率   ＝ 22%
  ─────────────────────────
  必要売上 ＝ 60万 ÷ 0.22 ＝ 約273万円/月 …「家賃だけ」で

  同じ計算を人件費130万円で行うと
  必要売上 ＝ 130万 ÷ 0.22 ＝ 約591万円/月

  → 家賃＋人件費だけで 月商 約864万円 が必要。
    水道光熱・システム・カード手数料・保険を足すと 月商1,000万円超が損益分岐点。
```

**同じ家賃でも、粗利率が違うと必要売上はこう変わる。**

| 業態                           | 粗利率の目安 | 家賃60万円を賄う月商 |
| ------------------------------ | ------------ | -------------------- |
| 書店                           | 22%          | **273万円**          |
| 食品スーパー                   | 25%          | 240万円              |
| コンビニ（加盟店の粗利ベース） | 30%          | 200万円              |
| ドラッグストア                 | 28%          | 214万円              |
| アパレルSPA                    | 50%超        | 120万円              |

- 同じ家賃でも、**書店はコンビニの1.4倍売らないと同じ利益が残らない**
- 一方で本は単価が安く（文庫600〜900円、コミック500〜700円、単行本1,500〜2,000円）、**客単価は1,000〜1,500円程度**。つまり月商1,000万円には月間7,000〜10,000人の来店が要る
- 書店は**坪あたりの売上（坪効率）が低い**業態でもある。本は重く嵩張り、1坪あたりに置ける「金額」が他業態より小さい

> 結論：書店は「駅前一等地で成立しない商売」になった。家賃が上がった都心から順に消えていったのはこのため。残ったのは①家賃が安い地方ロードサイド、②自社物件、③モールのテナント（集客を家主が担う）の3類型。

### 2-2. 追い打ちになったコスト

| 項目                                      | 影響                                                     |
| ----------------------------------------- | -------------------------------------------------------- |
| **カード・コード決済手数料**（3%前後）    | 粗利22%のうち3ポイント分。**粗利の1割超**が消える        |
| **最低賃金の上昇**                        | 2010年代半ば以降の連続引き上げ。人件費比率が構造的に上昇 |
| **万引きロス**（売上の1〜2%とされる推計） | 粗利率で見ると利益の5〜10%相当。書店の粗利では致命的     |
| **物流費**（2024年問題）                  | 取次の採算悪化 → 配送頻度削減・遠隔地からの撤退に波及    |

## 3. 本当の犯人：雑誌の消滅

### 3-1. 雑誌は書店にとって「主食」だった

| 雑誌が担っていた機能 | なぜ重要か                                                                      |
| -------------------- | ------------------------------------------------------------------------------- |
| **来店頻度**         | 週刊誌・月刊誌は発売日が決まっている。「毎週◯曜日に本屋へ行く」習慣を作っていた |
| **回転の速さ**       | 書籍と違い、数日〜数週間で売り切る。資金が寝ない                                |
| **ついで買い**       | 雑誌を買いに来た客が、書籍・文具・コミックを買う。**雑誌は集客装置**            |
| **粗利額の厚み**     | 正味は書籍とほぼ同じでも、**回転が速い分だけ同じ売場から稼げる粗利額が大きい**  |
| **配送の基盤**       | 雑誌の配送ルート（毎日・全国）があるから、書籍も同じ便で安く運べた              |

### 3-2. 雑誌の推定販売金額

| 年         | 雑誌（紙）の推定販売金額       | 備考                                     |
| ---------- | ------------------------------ | ---------------------------------------- |
| **1997年** | **1兆5,644億円**               | ピーク                                   |
| 2010年     | 約1兆500億円                   |                                          |
| 2020年     | 約5,600億円                    |                                          |
| 2024年     | 約4,100億円                    |                                          |
| **2025年** | **3,708億円（前年比 −10.0%）** | **ピークの4分の1以下**（出版科学研究所） |

```
【雑誌販売金額（兆円）】

 1.6 ┤●1997  1.56
 1.2 ┤    ●
 0.8 ┤         ●
 0.6 ┤              ●2020  0.56
 0.4 ┤                   ●2024  0.41
 0.37┤                     ●2025  0.37
     └┬────┬────┬────┬────┬────┬──
    1997  2005  2010  2015  2020  2025

  → 書店の「毎週来る客」と「速い回転」が、この線と一緒に消えた。
```

- 情報がスマートフォンに移り、**雑誌が担っていた「暇つぶし」「トレンド情報」「実用情報」の全機能がネットに置き換わった**
- 雑誌の減少で配送ルートの採算が崩れ、取次はコンビニ向け雑誌配送からの撤退を進めた（トーハンはファミリーマート・ローソン計約1万店への雑誌配送を終了、2024年）
- **雑誌が減る → 配送効率が落ちる → 書籍の配送コストも上がる → 遠隔地の書店が切られる**、という連鎖が起きている

> ポイント：「本離れ」ではない。**紙の書籍の落ち込みより、雑誌の落ち込みのほうがはるかに急だった**。書店の収益基盤は書籍ではなく雑誌に乗っていたので、雑誌の消滅が直撃した。

### 3-3. 出版市場全体の姿（2025年）

| 区分                | 2025年 推定販売金額 | 前年比                     |
| ------------------- | ------------------- | -------------------------- |
| 紙（書籍＋雑誌）    | **9,647億円**       | −4.1%（**初の1兆円割れ**） |
| ── うち書籍         | 約5,900億円台       |                            |
| ── うち雑誌         | 3,708億円           | −10.0%                     |
| 電子                | **5,815億円**       | +2.7%                      |
| ── うち電子コミック | 5,273億円           | +2.9%                      |
| **紙＋電子 合計**   | **1兆5,462億円**    | −1.6%（4年連続減）         |

出典：全国出版協会・出版科学研究所（2026年1月発表）

- 合計額はコロナ前の2019年とほぼ同規模。**市場全体はそれほど縮んでいないのに、書店が売れる部分（紙）だけが縮んでいる**
- 電子出版5,815億円のうち**約9割が電子コミック**。書店の店頭で売れていたコミックが、まるごとアプリへ移動した

## 4. Amazon・電子書籍・コンビニ・図書館

### 4-1. Amazon ── 定価は同じなのに勝たれた理由

再販制度により**Amazonも書店と同じ定価**で売っている。それでも書店が負けたのは、価格以外の4点。

| 要因                         | 内容                                                                             |
| ---------------------------- | -------------------------------------------------------------------------------- |
| **在庫の深さ**               | 書店の在庫は数万点。Amazonは数百万点。「探している本がある」確率が段違い         |
| **配送とポイント**           | 送料無料・翌日配送・ポイント還元。**実質値引きは再販制度で禁じられていない**     |
| **検索性**                   | 著者名・シリーズ・レビューで探せる。書店の棚は「知っている本」しか見つけられない |
| **マーケットプレイス／中古** | 中古本は再販の対象外。新刊の隣に安い中古が並ぶ                                   |

> 再販制度は「定価」を守ったが、「**ポイント還元**」「**送料**」という定価の外側は守れなかった。制度の穴が、制度を無力化した典型例。

### 4-2. 電子書籍

```
【紙と電子の分かれ道】

  紙の本  ─── 再販制度あり ──▶ 値引き不可 ──▶ 書店に22%
  電子書籍 ── 再販の対象外 ──▶ 半額セール・無料連載 ──▶ 書店に 0円
                （有体物ではないため独禁法23条の対象外）
```

- 電子書籍はそもそも**書店の商圏の外**。書店が仲介できない
- 最大の打撃は**コミック**。かつて書店の粗利を支えた分野が、丸ごとアプリ経済圏に移った
- ただしコミックは紙でも依然として書店の主力（→ [③ 生き残りの形](03_生き残りの形.md)）

### 4-3. コンビニ

- 1980〜2000年代、コンビニは雑誌・コミックの販売で書店の客を奪った。**24時間・徒歩圏という利便性**で勝った
- ところが2020年代、そのコンビニも雑誌売場を縮小。**書店の敵だったコンビニ自身が雑誌から撤退している**
- 結果として「雑誌をどこで買うのか」という問い自体が消えつつある → [コンビニエンスストア](../01_コンビニエンスストア/README.md)

### 4-4. 図書館

- 図書館の**複本（ふくほん）問題**＝同じベストセラーを1館で何十冊も購入し、貸し出すこと。出版社・書店側から「販売機会の喪失」として批判が続く
- 一方で、図書館は**書店にとって法人外商の顧客**でもある（選書・納品・装備を請け負う）。丸善CHIホールディングスの図書館サポート事業などはここが本業に近い
- 「敵」と「客」の両面がある、というのが実態

## 5. 取次が倒れかけていることの意味

書店の減少は、**取次の採算を壊し、それがさらに書店を減らす**という自己増殖の輪に入っている。

```
【負のループ】

   書店が減る
      ↓
   1件あたりの配送効率が落ちる（配送ルートが維持できない）
      ↓
   取次の赤字 → 配送頻度の削減／遠隔地の配送打ち切り／手数料引き上げ
      ↓
   残った書店の条件が悪化（新刊が翌日に届かない）
      ↓
   さらに書店が減る ──┐
      ▲              │
      └──────────────┘
```

| 会社                         | 2026年3月期 最終損益 | 備考                                                               |
| ---------------------------- | -------------------- | ------------------------------------------------------------------ |
| 日販グループホールディングス | **約24億円の赤字**   | 取次事業の部門経常損益は約36億円の赤字。前期は黒字                 |
| トーハン                     | **約11億円の赤字**   | 前期は約18億円の黒字から転落。取次事業は40億円超の赤字と報じられる |

出典：2026年5月29日発表、日本経済新聞・The Bunka News などの報道ベース

- 両社とも本業（取次）の赤字を、**不動産・雑貨・IT・エンタメなどの非取次事業で埋めている**構図
- 2社は競合でありながら、**返品物流の協業**（日販グループの所沢センターが担っていた書籍返品業務をトーハン桶川センターへ移管、2026年7月から段階的）など、生存のための共同化に踏み出している

## 6. まとめ ── 3つの層が同時に抜けた

| 層           | 何が起きたか                            | 書店への効き方                                             |
| ------------ | --------------------------------------- | ---------------------------------------------------------- |
| **制度の層** | 粗利22%固定・値引き不可・在庫リスクなし | コスト上昇を価格転嫁できない。経営努力が粗利に反映されない |
| **商品の層** | 雑誌が4分の1に。コミックが電子へ移動    | 来店頻度・回転・粗利額の柱が同時に折れた                   |
| **流通の層** | 取次の赤字、物流費上昇、配送頻度削減    | 「本がすぐ届く」という書店の価値が落ちた                   |

> どれか1つなら耐えられた。3つが同時に来たので、**粗利22%という設計の余裕のなさ**が一気に露呈した。制度が商売を規定する、とはこういうこと。

打開策については [③ 生き残りの形](03_生き残りの形.md) を参照。

## 7. 用語メモ

| 用語                 | 意味                                                                                                  |
| -------------------- | ----------------------------------------------------------------------------------------------------- |
| **無書店自治体**     | 書店が1店もない市区町村。2026年3月時点で510自治体、全体の29.3%（出版文化産業振興財団 JPIC 調査）      |

| **物流の2024年問題** | トラック運転手の時間外労働上限規制（2024年4月適用）。長距離配送のコスト上昇を招き、出版物流を直撃した |

| **推定販売金額**     | 出版科学研究所が推計する出版物の販売額。取次ルートを基礎にした推計値で、実売の全量ではない            |
| **ロードサイド店**   | 郊外幹線道路沿いの大型店。家賃が安く駐車場が取れるため、書店の生き残り形態のひとつ                    |
