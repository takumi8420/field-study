# 書店

- 大分類: 小売・流通
- 状態: done
- 更新日: 2026-09-20

本を仕入れて売る小売業。ただし**値段を自分で決められず、仕入値も交渉できず、その代わり売れ残りは返品できる**という、他のどの小売業とも違う取引条件のもとで営まれている。

この条件を作っているのが **再販売価格維持制度（値引き禁止）** と **委託販売（返品可）** の2つで、結果として書店の粗利益率は **約22%に固定**されている。コンビニ（約30%）より8ポイント低いこの数字が、家賃と人件費を払えるかどうかの分かれ目になり、書店は **1998年度の24,237店から2025年度末の9,993店へ**、ピークの4割まで減った。**制度が商売を規定する典型**であり、書店を理解するとは制度を理解することに等しい。

## 1. 業界の定義・範囲

「書店」＝書籍・雑誌を店頭で販売する小売業。日本標準産業分類では「書籍・文房具小売業」に含まれる。許認可は不要で、**誰でも開業できる**（ただし取次と取引口座を開くには保証金と信用が要る）。

```
【書店に隣接する事業者】

              ┌── 出版社（本を作る・定価を決める）
              │
  読者 ◀── 書店 ◀── 取次（卸） ◀──┘
    ▲         ▲
    │         └ 図書館・大学（法人外商の顧客であり、競合でもある）
    │
    ├── ネット書店（Amazon、楽天ブックス、honto）… 同じ定価で戦う
    ├── 電子書店（Kindle、ピッコマ、LINEマンガ）… 再販の対象外
    ├── コンビニ（雑誌・コミック）… 縮小中
    └── 新古書店（BOOKOFF）… 中古は再販の対象外
```

| 隣接分野                                                                    | 境界線                                                                                      |
| --------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| [出版](../../14_メディア・広告・エンタメ/03_出版/README.md)                 | 本を作り、**定価を決める側**。書店の取り分はここが決めた定価の22%。直取引の交渉相手でもある |
| 取次（日販・トーハン）                                                      | 出版社と書店をつなぐ卸。物流・金融・情報・配本を担う。独立した上場企業ではないが業界の要    |
| [EC・ネット通販](../../04_情報通信・IT・ネット/08_EC・ネット通販/README.md) | Amazon・楽天ブックス。**定価は同じ**が、送料無料とポイント還元で実質的に勝っている          |
| 電子書籍ストア                                                              | 有体物でないため**再販制度の対象外**。半額セール・無料連載が可能。市場の約4割               |
| [リユース・中古](../16_リユース・中古/README.md)                            | BOOKOFFなど。中古本は再販の対象外で、自由価格                                               |
| [コンビニエンスストア](../01_コンビニエンスストア/README.md)                | かつての雑誌販売の主戦場。2020年代は雑誌売場を縮小し、書店の競合から降りつつある            |
| 図書館                                                                      | 法人外商の顧客であると同時に、複本問題では販売機会の競合                                    |

## 2. 市場規模と成長性

| 年         | 紙（書籍＋雑誌）                    | 電子                   | 紙＋電子 合計             |
| ---------- | ----------------------------------- | ---------------------- | ------------------------- |
| 1996年     | 約2兆6,500億円（ピーク）            | ─                      | 約2兆6,500億円            |
| 2019年     | 約1兆2,400億円                      | 約3,000億円            | 約1兆5,400億円            |
| 2024年     | 約1兆56億円                         | 5,660億円              | 1兆5,716億円（−1.5%）     |
| **2025年** | **9,647億円（−4.1%）初の1兆円割れ** | **5,815億円（+2.7%）** | **1兆5,462億円（−1.6%）** |

出典：全国出版協会・出版科学研究所（推定販売金額、2026年1月発表）

- **紙の内訳（2025年）**：書籍 約5,900億円台、雑誌 3,708億円（−10.0%）。雑誌の落ち方が突出している
- **電子の内訳（2025年）**：電子コミック 5,273億円（+2.9%）、電子書籍 459億円、電子雑誌 83億円。**電子の約9割がコミック**
- 紙＋電子の合計はコロナ前の2019年とほぼ同水準。**市場全体は横ばいで、書店を通る部分（紙）だけが縮んでいる**
- 書店数：1998年度 24,237店 → **2025年度末 9,993店**（初の1万店割れ、日本出版インフラセンター）。無書店自治体は510（29.3%、2026年3月、出版文化産業振興財団）

> 見落としやすい点：「本が読まれなくなった」のではない。**本が書店を通らなくなった**。この区別が業界理解の分かれ目になる。

## 3. バリューチェーン（川上 → 川下）

```
【出版流通の商流（定価1,000円の本で見る）】

 著者 ── 出版社 ─────▶ 取次 ─────▶ 書店 ──▶ 読者
  印税     編集・製造     物流・与信    販売      1,000円
  10%      約700円        約80円       約220円
  （出版社   （70%）        （8%）       （22%）
   の中）
                ◀── 返品 ──◀── 返品 ──┘
                （返品率：書籍31.9%、雑誌4割台）

 【直取引ルート（2023年〜拡大中）】
 出版社 ──────────────────────▶ 書店
     返品率をコミットする代わりに、書店の取り分を25〜30%へ
```

| 工程           | 担い手                                                          | 付加価値の源泉                                               |
| -------------- | --------------------------------------------------------------- | ------------------------------------------------------------ |
| 企画・編集     | 出版社                                                          | **ここに価値の大半が集まる**。定価の決定権を持つ             |
| 印刷・製本     | [印刷](../../14_メディア・広告・エンタメ/02_印刷/README.md)会社 | 受注産業。返品の断裁も担う                                   |
| 卸・物流・与信 | 取次（日販・トーハン）                                          | 多対多の取引を圧縮する装置。**構造赤字化している**           |
| 小売           | 書店                                                            | 品揃え・棚づくり・接客。ただし**配本で品揃えの自由度が低い** |
| 二次流通       | 新古書店・フリマ                                                | 再販の対象外。自由価格                                       |

## 5. 収益モデル・コスト構造

```
【書店1店舗の損益イメージ（駅前50坪・月商1,000万円）】

  売上         10,000,000円
  ─ 原価(78%)  -7,800,000円   ← 正味78%。値引きも仕入交渉もできない
  ───────────────────────────
  粗利(22%)     2,200,000円
   ├ 人件費     -1,300,000円   （59%）
   ├ 家賃       -  600,000円   （27%）
   ├ 水光熱・システム・カード手数料 -300,000円（14%）
   └ ─────────────────────
     営業利益     ほぼゼロ〜赤字
```

| 指標         | 目安                    | コメント                                                           |
| ------------ | ----------------------- | ------------------------------------------------------------------ |
| 粗利益率     | **22〜23%**             | 制度で事実上固定。コンビニ30%、食品スーパー25%と比べて低い         |
| 客単価       | 1,000〜1,500円          | 文庫600〜900円、コミック500〜700円、単行本1,500〜2,000円           |
| 返品率       | 書籍31.9%（2025年）     | 在庫リスクを負わない代わりに物流費が業界全体に跳ね返る             |
| カード手数料 | 3%前後                  | 粗利22%に対し**粗利の1割超**を食う。書店でキャッシュレスが重い理由 |
| 万引きロス   | 売上の1〜2%（推計）     | 粗利率で見ると利益の5〜10%相当                                     |
| 損益分岐点   | 50坪で月商1,000万円前後 | 家賃60万＋人件費130万を粗利22%で賄うには約864万円の売上が必要      |

**儲け方は3通りしかない。** ①冊数を増やす（粗利率が固定なので売上を伸ばすしかない）、②本以外を売る（文具40%、カフェ70%）、③制度の外に出る（直取引・買切で25〜30%）。詳しくは [③ 生き残りの形](03_生き残りの形.md)。

## 6. 競争要因（KSF）と参入障壁

| 項目                         | 実態                                                                                              |
| ---------------------------- | ------------------------------------------------------------------------------------------------- |
| **参入障壁（低い）**         | 許認可不要。仕入は取次経由で誰でも可能（保証金は要る）。だから独立系書店が年100店ペースで生まれる |
| **退出は多い**               | 2025年度は開業102店に対し閉店499店。参入しやすいが**続けられない**                                |
| **KSF①：家賃を下げる**       | 粗利22%では一等地の家賃が払えない。自社物件・郊外・モール（家主が集客）が生き残りの条件           |
| **KSF②：粗利ミックス**       | 文具・雑貨・カフェ・トレカを混ぜ、店全体の粗利率を28〜32%へ引き上げる                             |
| **KSF③：法人需要**           | 大学・図書館・企業への外商。**役務収入は粗利が読める**。最大手の利益源はここ                      |
| **KSF④：選書とコミュニティ** | 配本に頼らない自前の品揃え。Amazonが苦手な「知らない本との出会い」を作れるか                      |
| **価格では戦えない**         | 再販制度によりネットも実店舗も同じ定価。差がつくのは送料・ポイント・在庫の深さ・利便性            |

## 7. 規制・法制度

| 制度                                                 | 内容                                                                                                               | 書店への効き方                                                             |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------- |
| **独占禁止法 第23条（著作物再販適用除外）**          | 書籍・雑誌・新聞・音楽ソフトについて、メーカーの価格拘束を例外的に容認                                             | **値引き不可**。粗利率が固定される根源。公取委は2001年に「当面存置」と結論 |
| **委託販売（返品条件付売買）の慣行**                 | 法律ではなく取引慣行。期限内なら返品可                                                                             | **在庫リスクなし／返品率3〜4割**。最近は買切・直取引への揺り戻し           |
| 電子書籍の扱い                                       | 有体物ではないため再販の対象外                                                                                     | 電子は自由に値引き・無料公開できる。紙との競争条件が非対称                 |
| **経産省 書店振興プロジェクトチーム**（2024年3月〜） | 課題整理（2025年1月、5分類29項目）→ **書店活性化プラン（2025年6月10日）** → 支援施策活用ガイド更新（2026年7月8日） | 補助金の新設ではなく、既存の中小企業支援策を書店向けに整理する方向         |
| **出版産業における返品削減研究会**（2025年〜）       | **2026年4月21日にとりまとめ公表**。RFID普及、直接取引・直送、適正配本を提示                                        | 委託制度の運用に間接的に手を付けた形                                       |
| 消費税・インボイス                                   | 軽減税率の対象外（本は10%）                                                                                        | 値上げを価格転嫁しづらい業態で負担が重い                                   |

> 公正取引委員会が「書店活性化プラン」に連名で入っている点は注目に値する。**再販制度・取引慣行の見直しが政策の視野に入った**ことを意味する。

## 8. 最近のトピック

詳細は [④ 直近トピック（2026年9月時点）](04_直近トピック_2026.md)。

1. **書店数が初の1万店割れ**（2025年度末 9,993店、前年度比 −424店）。無書店自治体は510（29.3%）。開業102店に対し閉店499店
2. **取次2社が同時に最終赤字**（2026年3月期：日販GHD 約−24億円、トーハン 約−11億円）。輸送費上昇・書店減少・返品高止まりの三重苦。危機の中心が書店から取次へ移った
3. **経産省「返品削減研究会」とりまとめ**（2026年4月21日）。RFID（電子タグ）普及と直接取引・直送を方向性として提示
4. **正味改定論の表面化**。出版社70：取次8：書店22 を 60：10：30 とする「イメージ」が業界で示され、出版社側は中小の体力を理由に急激な移行に慎重
5. **直取引と在庫融通の実装**。ブックセラーズ＆カンパニーほか15社の共同声明（2026年6月）、約600店の在庫データベースで返品6割減を目指す試み（2026年1月報道）

## 9. 用語メモ

各ノート末尾の「用語メモ」に詳しい説明がある。中核は次の4つ。

| 用語                               | 意味                                                                                                                             |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| **再販制度（再販売価格維持制度）** | 出版社が決めた定価での販売を小売に守らせる制度。独禁法23条の適用除外。**本が値引きできない理由** → [①](01_再販制度と委託販売.md) |
| **委託販売**                       | 売れ残りを期限内に返品できる取引慣行。**書店が在庫リスクを負わない理由** → [①](01_再販制度と委託販売.md)                         |
| **取次（とりつぎ）**               | 出版社と書店の間に立つ卸売業者。物流・金融・情報・配本を担う。日販とトーハンの2社が中心 → [①](01_再販制度と委託販売.md)          |
| **配本（はいほん）**               | 取次が書店の注文を待たず、店舗ランクに応じて新刊を割り振ること。品揃えが均質化する原因 → [①](01_再販制度と委託販売.md)           |
| **正味（しょうみ）**               | 定価に対する仕入値の割合（書籍で77〜78%）。正味を下げる交渉＝書店の粗利率引き上げ → [④](04_直近トピック_2026.md)                 |
| **無書店自治体**                   | 書店が1店もない市区町村。2026年3月時点で510、全体の29.3% → [②](02_なぜ書店は減ったのか.md)                                       |
