# 生き残りの形 ── 「本だけの店」をやめた書店たち

このノートで分かること：粗利22%の本だけでは店が回らないと分かったあと、書店が取った**5つの生き残り戦略**。複合化、大型店＋法人外商、独立系、直取引、そして政策。どれも「制度の縛りをどこで外すか」という一点で説明できる。

> ポイント：生き残っている書店に共通するのは、**売上の一部を「本以外」または「制度の外」に移していること**。カフェ（粗利70%）、文具（粗利40%）、法人外商（固定客）、直取引（粗利30%）、シェア棚（棚代収入）。本の22%だけでは、もう店は建たない。

---

## 1. 5つの生き残りモデル

| モデル                 | 何で粗利を稼ぐか                                   | 代表                                         | 弱点                                   |
| ---------------------- | -------------------------------------------------- | -------------------------------------------- | -------------------------------------- |
| **① 複合化**           | 文具・雑貨・カフェ・レンタル・ゲーム               | TSUTAYA、未来屋書店、明屋書店                | 本の売場が縮む。雑貨の競合はもっと強い |
| **② 大型店＋法人外商** | 品揃えの深さ＋大学・図書館・企業への納品           | 紀伊國屋書店、丸善ジュンク堂                 | 大型店は家賃が重い。外商は値引き圧力   |
| **③ 独立系・セレクト** | 店主の選書とコミュニティ。イベント・カフェ・棚貸し | 各地の小規模書店、シェア型書店               | 規模が小さく生活給を出しにくい         |
| **④ 直取引・買切**     | 粗利率そのものを22%→25〜30%に上げる                | ブックセラーズ＆カンパニー、独立書店の直仕入 | 返品できないので目利きの責任を負う     |
| **⑤ 政策・公共化**     | 自治体・行政の支援、公共施設との一体化             | 経産省 書店振興PT、公共図書館複合施設        | 補助金依存では自走できない             |

```
【売場構成の変化：本だけの店 → 複合店】

  1995年の書店（50坪）          2026年の複合店（300坪）
  ┌────────────────┐        ┌──────┬──────┬──────┐
  │ 雑誌 30%       │        │ 書籍  │ 文具  │ カフェ│
  │ コミック 20%   │        │ 40%   │ 20%   │ 10%   │
  │ 書籍 45%       │   ──▶  ├──────┼──────┴──────┤
  │ 文具 5%        │        │コミック│ 雑貨・トレカ │
  └────────────────┘        │ 20%   │ 10%          │
  粗利率 22%                └──────┴─────────────┘
                             加重平均の粗利率 30%前後
```

## 2. ① 複合化 ── TSUTAYA型

### 2-1. なぜ複合化するのか（粗利率の話）

| 商材                 | 粗利率の目安                | 再販制度           |
| -------------------- | --------------------------- | ------------------ |
| 書籍・雑誌           | 22%                         | あり（値引き不可） |
| コミック             | 22%                         | あり               |
| 文具                 | 35〜45%                     | なし               |
| 雑貨・生活用品       | 40〜50%                     | なし               |
| カフェ（飲食）       | 65〜75%                     | なし               |
| トレーディングカード | 20〜30%（回転が非常に速い） | なし               |
| レンタル（かつて）   | 実質的に高粗利              | なし               |

**本の隣に粗利の高い商品を置けば、店全体の加重平均粗利率が上がる**。これが複合化の全部である。300坪の店で書籍4割・非書籍6割なら、平均粗利率は30%前後まで上がり、家賃と人件費が払える水準に届く。

### 2-2. TSUTAYA／CCCの軌跡

| 時期           | 主力                                     | 意味                                                               |
| -------------- | ---------------------------------------- | ------------------------------------------------------------------ |
| 1980〜2000年代 | **レンタルビデオ・CD**                   | 高粗利のレンタルが書籍の低粗利を補い、書店を全国展開できた         |
| 2003年〜       | **Tポイント**                            | 会員データが本業になる。FCへの加盟メリットにもなった               |
| 2011年〜       | **代官山 蔦屋書店**                      | 「ライフスタイル提案」型。本を目的ではなく空間の構成要素として使う |
| 2015年〜       | **武雄市図書館など公共図書館の指定管理** | 公共施設の運営に進出。賛否両論を呼んだ                             |
| 2020年代       | **レンタル撤退・シェアラウンジ**         | 定額制動画配信でレンタルが消滅。カフェ／コワーキングへ転換         |

- TSUTAYAの店舗は2022〜2024年に年間100店超のペースで閉店し、その後も減少が続くと報じられる。**レンタルという最大の粗利源が消えた**のが直接の原因
- 一方で**蔦屋書店（TSUTAYA BOOKSTORE／T-SITE）**は、書店というより不動産・商業施設のコンテンツとして生き残っている。デベロッパーが「集客装置」として書店を求めるので、家賃条件が優遇されるケースがある

> 構図：TSUTAYAは「高粗利の何かで本を支える」モデルの元祖であり、その高粗利の柱（レンタル → ポイント → カフェ）を**入れ替え続けている**。柱の乗り換えに成功する限り書店は残る。

### 2-3. モール型 ── 未来屋書店

- イオンモール内に出店する **未来屋書店**（イオングループ）は、店舗数で国内最大級とされる
- 強みは**集客を家主（モール）が担ってくれる**こと。書店自身が客を呼ぶ必要がない
- 弱みはモールの盛衰と運命を共にすること。モールの客層（ファミリー）に合わせた品揃えに寄りやすい

## 3. ② 大型店＋法人外商 ── 紀伊國屋・丸善ジュンク堂

### 3-1. 品揃えの深さで戦う

```
【大型店の理屈】

  Amazon の在庫 …… 数百万点（検索で見つける）
  街の書店     …… 2〜5万点（探せない）
  大型書店     …… 50万〜150万点（並んでいるのを「見つけてしまう」）
                      ▲
                      └ これが「棚で偶然出会う」体験。
                        Amazon は目的の本には強いが、
                        「知らなかった本」を並べて見せることは苦手。
```

- ジュンク堂書店（丸善ジュンク堂書店）は「座り読み用の椅子」「専門書のフルライン」で知られる。**在庫を持ちすぎることを競争力に転換した**稀な例
- とはいえ在庫は資金を食う。委託販売で在庫リスクがない（返品できる）からこそ成立している面が大きい ── **制度の恩恵を最大限に使い切った形**

### 3-2. 法人外商（がいしょう）が本当の稼ぎ頭

**外商＝店に来ない顧客のところへ出向いて売る部隊**。書店の場合は大学・図書館・研究機関・企業・病院・自治体が相手。

| 事業                                   | 内容                                                   | 特徴                                                   |
| -------------------------------------- | ------------------------------------------------------ | ------------------------------------------------------ |
| **大学・研究機関向け販売（文教市場）** | 教科書・学術書・電子ジャーナル・実験機器               | 年度予算で買う固定需要。競争入札もある                 |
| **図書館サポート**                     | 選書・納品・装備（フィルム掛け・ラベル貼り）・指定管理 | 単なる物販でなく**役務（サービス）収入**。粗利が読める |
| **企業向け**                           | 社内図書室、書籍の一括納入                             | 法人の与信が効く                                       |

- **丸善CHIホールディングス**（東証、コード3159）は、書店（丸善ジュンク堂書店）だけでなく、丸善雄松堂による文教市場販売・図書館サポート・出版（丸善出版）を持つ。2026年1月期の連結経常利益は約54.9億円（前期比約59%増）と報じられる（株探、2026年3月）。**店舗小売より法人向け・役務のほうが利益を生んでいる**構図
- **紀伊國屋書店**（非上場）も、国内外の大学・図書館向け洋書・学術情報事業が大きな柱。海外店舗網（アジア・北米・中東）も持つ

> ポイント：日本最大級の書店チェーンの利益は、**店頭で本を売って出ているのではない**。「法人にサービスとして売る」ことで、再販制度の粗利22%という縛りの外に出ている。

## 4. ③ 独立系書店とセレクトの価値

### 4-1. 減る書店、増える独立系

- 書店全体は年400店以上減っているが、**個人経営の独立系書店（セレクト書店）は年間90〜100店前後のペースで新規開業している**と報じられる（2023年100店超、2024年90店超、2025年上半期52店）
- 規模はごく小さい（10〜20坪、蔵書数千点）。既存の書店チェーンの穴を埋めるものではないが、**モデルが違う**

### 4-2. なぜ小さい店のほうが成り立つのか

| 論点   | 大型店                     | 独立系                                        |
| ------ | -------------------------- | --------------------------------------------- |
| 仕入   | 取次からの配本（選べない） | **自分で選ぶ**。直取引・買切も使う            |
| 粗利率 | 22%                        | 買切・直仕入で25〜35%も                       |
| 家賃   | 駅前一等地・高額           | 郊外・二階・住宅街。月5〜15万円               |
| 人件費 | 正社員＋パート             | **店主ひとり**（＝人件費が生活費と同一）      |
| 集客   | 通行量                     | SNS・イベント・口コミ。**店主のキャラクター** |
| 併営   | 文具・カフェ               | カフェ、酒、ギャラリー、出版、宿              |

```
【独立系の損益イメージ（15坪・店主ひとり）】

  月商        80万円
  ─ 原価(72%)  -58万円   ← 買切・直取引で正味を下げている
  ──────────────────
  粗利(28%)    22万円
   ├ 家賃      -10万円
   ├ 光熱・雑費 -3万円
   └ 残り        9万円 ← 店主の生活費（＝人件費）

  → カフェ・イベント・棚貸しの収入を足して初めて生活できる水準になる。
```

### 4-3. シェア型書店（棚貸し書店）

**棚を月額（3,000〜1万円程度）で貸し、「棚主」が自分で選んだ本を売る**形式。

- 書店側：**本が売れなくても棚代が入る**。在庫リスクも仕入資金も棚主が負う。実質的に不動産賃貸業
- 棚主側：数千円で「本屋の主」になれる。売上は自分の取り分（手数料を引いた分）
- 2026年4月時点で全国139店舗との集計がある（民間の調査、note「本のある場所研究会」）。大手書店や作家の参入も報じられる

> 見方：シェア型書店は「書店の再生」というより、**書店という場所を趣味として消費する市場**が生まれたということ。収益源が「本の粗利」から「場所代」に変わっている点で、構造的には ① 複合化と同じ発想（本以外で稼ぐ）。

### 4-4. 独立系による流通交渉

独立系書店が単独で出版社と交渉するのは難しいため、**業界団体を作って仕入値（正味）を交渉する動き**が出ている（2025年、日本経済新聞報道）。これは ④ 直取引の小規模版にあたる。

## 5. ④ 直取引 ── 制度そのものを迂回する

### 5-1. ブックセラーズ＆カンパニー

| 項目     | 内容                                                                                          |
| -------- | --------------------------------------------------------------------------------------------- |
| 設立     | 2023年10月                                                                                    |
| 出資     | **紀伊國屋書店 40%／CCC（TSUTAYA）30%／日本出版販売 30%**                                     |
| 目的     | 参画書店を代表して出版社と**直接取引契約**を結ぶ。販売・返品をコミットする代わりに正味を改善  |
| 規模目標 | **2027年3月期までに年間500億円**（国内の書籍取引の約1割）と報じられる                         |
| 進捗     | 日経BPなど出版社との直接取引契約が進む。2026年6月には直取引拡大を目指す書店運営15社が共同声明 |

```
【従来の商流 と 直取引】

  【従来】
    出版社 ─▶ 取次 ─▶ 書店      出版社70 : 取次8 : 書店22
                 （配本・返品自由）

  【直取引】
    出版社 ──────▶ 書店          出版社  : 書店25〜30
       （仕入数・返品率をコミット／物流は取次に委託することも）
       ▲
       └ 「返品しない約束」と引き換えに粗利をもらう。
         ＝ 委託販売の逆。在庫リスクを書店が引き受ける。
```

- ここで起きているのは**リスクと利益の交換**。返品権（リスク回避）を差し出して、粗利率（利益）を取りに行く
- 出資者に日販が入っているのがポイント。**取次自身が「取次を通さない取引」に出資している**。物流だけは自社が担う形で残そうという狙いと読める
- 2026年1月には、TSUTAYAや紀伊國屋など**約600店の在庫データベース**を共通化し、チェーンをまたいで在庫を融通して返品を6割減らす試みが報じられた

### 5-2. 出版社側の反応

書店の取り分を22%→30%に引き上げれば、その原資は出版社（70%）から出る。日本出版者協議会は2026年7月の文書で、方向性は理解しつつ**中小出版社の体力を理由に急激な移行に慎重**な姿勢を示した。→ [④ 直近トピック](04_直近トピック_2026.md)

## 6. ⑤ 政策 ── 経産省 書店振興プロジェクトチーム

| 時期              | 動き                                                                                                        |
| ----------------- | ----------------------------------------------------------------------------------------------------------- |
| 2024年3月         | 経済産業省に**書店振興プロジェクトチーム**を設置（当時の齋藤健経産大臣の主導）                              |
| 2024年10月        | 「関係者から指摘された書店活性化のための課題（案）」公表、パブリックコメント募集                            |
| 2025年1月         | 課題を5分類・計29項目に整理して公表                                                                         |
| **2025年6月10日** | **「書店活性化プラン」公表**（経産省・中小企業庁・内閣官房・公正取引委員会・文科省・文化庁・国交省の連名）  |
| 2025年〜2026年4月 | **「出版産業における返品削減研究会」**。2026年4月21日にとりまとめ公表。RFID普及、直接取引・直送の推進を提示 |
| 2026年7月8日      | 「書店経営者向け支援施策活用ガイド」を更新                                                                  |

- 特徴は、**補助金を出すのではなく「既存の中小企業支援策を書店が使えるように整理する」**方向であること（設備投資、事業承継、キャッシュレス、省力化投資など）
- 公正取引委員会が連名に入っているのは、**再販制度・取引慣行の見直しが視野に入っている**ことを示唆する
- 「書店が地域コミュニティに与える影響を可視化する」研究（広島大学との連携、2026年）も進められている。**文化インフラとしての価値を数値化して政策の根拠にする**試み

> 評価：政策は「制度をいじる」までは踏み込めておらず、当面は経営支援と物流合理化が中心。ただし**国が「書店は放っておけない」と態度表明した意味**は小さくない。無書店自治体3割という数字が政治的な問題になった。

## 7. 最後の砦 ── コミックとライトノベル

| 分野                     | 書店にとっての意味                                                                                                                            |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------- |
| **コミック（紙）**       | 単価は安いが回転が速く、シリーズ買い（1巻買ったら全巻）で客単価が跳ねる。新刊発売日に客が来る。**雑誌が失った「来店習慣」を唯一代替している** |
| **ライトノベル**         | コミックと同じ棚に置ける。アニメ化で需要が跳ねる。10〜20代を書店に呼ぶ数少ない商材                                                            |
| **アニメ・IPのコラボ**   | 特典付き、フェア、キャラクターグッズ併売。**非再販の物販**を抱き合わせられる                                                                  |
| **トレーディングカード** | 2020年代に書店が力を入れる分野。高回転・非再販・在庫が小さい                                                                                  |

- 日販の店頭売上調査（2026年4月期）では、書籍全体が前年比100.7%、コミックが96.2%と全体では伸び悩む一方、**少年コミックはアニメ化作品を軸に前年比108.6%**と健闘した
- ただし電子コミックが5,273億円（2025年、出版科学研究所）まで育っており、**紙コミックは長期的には削られる側**にある。「最後の砦」という表現は、裏を返せばこれが崩れると次がないという意味でもある

## 8. 生き残りモデルの整理

```
【どこで制度の縛りを外すか】

  制度の内側（粗利22%・値引き不可・返品可）
       │
       ├─▶ 商品を変える ……… 文具・雑貨・カフェ・トレカ  → ① 複合化
       ├─▶ 客を変える ……… 大学・図書館・企業           → ② 法人外商
       ├─▶ 仕入を変える ……… 直取引・買切               → ④ 直取引
       ├─▶ 収入源を変える … 棚代・イベント・会費          → ③ 独立系・シェア型
       └─▶ 外から支える ……… 行政支援・公共施設との複合   → ⑤ 政策
```

> どのモデルも「本を売って22%」のままでは成立しない、という一点で共通する。**書店業の再生とは、書店を本屋でなくす過程**でもある、という居心地の悪い結論がここにある。

## 9. 用語メモ

| 用語                           | 意味                                                                                                 |
| ------------------------------ | ---------------------------------------------------------------------------------------------------- |
| **複合書店**                   | 書籍に加えて文具・雑貨・カフェ・レンタルなどを併設した店。粗利の高い商材で平均粗利率を引き上げる     |
| **外商（がいしょう）**         | 店舗に来ない顧客（大学・図書館・企業・個人富裕層）に出向いて販売する営業形態。書店では法人外商が中心 |
| **文教市場**                   | 大学・研究機関・学校向けの販売市場。教科書、学術書、電子ジャーナル、実験機器など                     |
| **図書館サポート**             | 図書館向けの選書・納品・装備・運営受託。物販ではなく役務収入なので粗利が安定する                     |
| **指定管理者制度**             | 公共施設の運営を民間に委託する制度。CCCが武雄市図書館などを受託し議論を呼んだ                        |
| **独立系書店（セレクト書店）** | チェーンに属さず、店主が自分で選書する小規模書店。買切・直取引を使い粗利率を上げることが多い         |
| **シェア型書店（棚貸し書店）** | 棚を月額で棚主に貸す形式の書店。書店の収入は棚代（＝賃料）になる                                     |
| **直取引（直仕入）**           | 取次を通さず出版社と直接取引すること。返品率をコミットする代わりに正味を優遇される                   |
| **買切（かいきり）**           | 返品権のない仕入。粗利率が上乗せされる代わりに売れ残りは自己負担                                     |
| **書店振興プロジェクトチーム** | 経済産業省が2024年3月に設置した書店支援の省内横断チーム。2025年6月に「書店活性化プラン」を公表       |
