# 百貨店の商売の仕組み

このノートで分かること：百貨店は「自分で商品を仕入れて売る店」ではなく、**売り場を貸して口銭（手数料）を抜く場所貸し業**に近い、ということ。
その独特の取引慣行が「消化仕入（しょうかしいれ）」で、ここを押さえると粗利率の低さも、固定費の重さも、アパレル不況の直撃も、全部つながって見えてくる。

---

## 1. まず結論：百貨店は「商品を持っていない小売」

スーパーやコンビニは、卸から商品を買い取り、自社の在庫として抱え、売れ残れば自分で値下げして処分する。
百貨店は違う。売り場に並んでいる服やバッグの多くは、**売れる瞬間まで百貨店のものではない**。

```
【一般的な小売（買取）】
  メーカー ──売る──▶ 小売 ──売る──▶ 客
                      ↑ ここで所有権が移る。売れ残りリスクは小売が負う

【百貨店の消化仕入】
  アパレル ─────────────────────────▶ 客
              （百貨店の売り場を通るだけ）
              売れた瞬間に「仕入→売上」を同時計上
              ↑ 所有権は売れるまでアパレル側。売れ残りはアパレルが引き取る
```

> ポイント：**在庫リスクを負っていない＝リスクの対価としての利益も取れない。**
> だから百貨店の粗利率はスーパーより低い。ここが全ての出発点になる。

## 2. 3つの仕入形態を分解する

| 仕入形態     | 所有権が移るタイミング | 在庫リスク | 保管責任 | 値引き権限 | 百貨店の取り分            |
| ------------ | ---------------------- | ---------- | -------- | ---------- | ------------------------- |
| **買取仕入** | 納品時                 | 百貨店     | 百貨店   | 百貨店     | 大きい（30〜40%も可）     |
| **委託仕入** | 販売時（商品は預かる） | 仕入先     | 百貨店   | 仕入先寄り | 中くらい                  |
| **消化仕入** | 販売と同時             | 仕入先     | 仕入先   | 仕入先     | 小さい（おおむね20〜30%） |

- **買取仕入**：食品（デパ地下の一部）、贈答品、自社企画品などで使う。売れ残ったら自腹で処分するので、当てれば儲かるが外すと在庫損が出る
- **委託仕入**：商品を預かって店に並べるが、所有権は仕入先。売れ残りは返品する。百貨店は「置き場所と販売員の一部」を提供する
- **消化仕入**：**販売された瞬間に「仕入れたこと」にして同時に売上を立てる**取引。商品も、販売員（メーカー派遣の販売員）も、値引き判断も仕入先側にある

現在の主力衣料・雑貨売り場はほぼ消化仕入。だから百貨店の売り場に立っている店員の多くは、**百貨店の社員ではなくブランド側の社員**である。

### 会計処理の変化（重要）

2021年4月以降に強制適用された「収益認識に関する会計基準」により、消化仕入は**代理人取引**と整理された。
主たる責任・在庫リスク・価格決定権が仕入先にあるため、百貨店は「商品を売っている当事者」ではなく「仲介している代理人」とみなされる。

```
【旧】総額表示           【新】純額表示（代理人取引）
 売上高   100            売上高    25   ← 手数料だけが売上
 売上原価  75            売上原価   0
 売上総利益 25           売上総利益 25   ← 利益額は同じ
```

- 利益額は変わらないが、**見かけの売上高が大きく減る**。各社が「売上高」ではなく「総額売上高」「取扱高」を併記するのはこのため
- 決算資料を読むときは、どちらのベースの数字かを必ず確認する（EY「小売業における収益認識基準の重要論点」など会計解説が詳しい）

## 3. 1店舗の経済性 ―― なぜ固定費が重いのか

百貨店の店舗は、都心の一等地に建つ大型建物を、朝から夜まで、多数の人員で運営する。
**売上が減っても、家賃・減価償却・光熱費・警備・清掃・エレベーター整備は減らない。**

```
【百貨店1店舗のざっくりP/L（総額ベースのイメージ・目安）】

  総額売上高               100
   └ 売上原価（仕入先取り分） 72〜78
  ───────────────────────────
  売上総利益（粗利）        22〜28   ← スーパーは25〜30、SPAは50超
   └ 人件費                 8〜11
   └ 地代家賃・減価償却      5〜8
   └ 水道光熱・販促・その他   5〜7
  ───────────────────────────
  営業利益                  1〜5     ← 数%動くだけで黒字と赤字が入れ替わる
```

- 粗利率が低いのに固定費が重い＝**損益分岐点（赤字と黒字の境目の売上高）が高い**
- したがって売上が1割落ちると、利益は簡単に吹き飛ぶ。これが地方店の閉店ドミノの数理的な理由（→ [② なぜ縮小したのか](02_なぜ縮小したのか.md)）

| 指標         | 意味                    | 百貨店の目安                                              |
| ------------ | ----------------------- | --------------------------------------------------------- |
| 坪効率       | 売場1坪あたりの年間売上 | 都心旗艦店で数百万円〜、地方店はその数分の一              |
| 客単価       | 1人あたりの購入額       | 数千円〜。免税客は2026年7月で約10.3万円（日本百貨店協会） |
| 既存店前年比 | 同一店舗の売上の伸び    | 業界ニュースで最も注目される数字                          |
| 免税売上比率 | 訪日客向け売上の割合    | 都心旗艦店で2〜3割、地方店はほぼゼロ                      |

## 4. 売り場の3層構造 ―― 店頭・デパ地下・催事

百貨店の建物の中は、性格の違う3つのビジネスが同居している。

```
【フロア構成と役割（典型的な都心店）】

  屋上・上層階  催事場・レストラン・ギャラリー ── 集客装置。物産展・美術展
  中層階        紳士・婦人・子供服、リビング ─── 消化仕入の本丸。縮小中
  1〜2階        化粧品・ラグジュアリーブランド ── 現在の稼ぎ頭。免税客と富裕層
  地下          デパ地下（食品・惣菜・菓子） ──── 来店頻度をつくる。買取も多い
```

| 層                                   | 役割                                 | 収益への効き方                                                                                             |
| ------------------------------------ | ------------------------------------ | ---------------------------------------------------------------------------------------------------------- |
| **1〜2階（化粧品・ラグジュアリー）** | 高単価・高回転。免税と富裕層の受け皿 | 売上・利益の主力。ここが強い店だけが生き残っている                                                         |
| **デパ地下**                         | 週に何度も来る理由をつくる           | 単価は低いが来店頻度を稼ぐ。菓子・惣菜は買取や高い歩率も                                                   |
| **催事（物産展・美術展）**           | 期間限定で非日常をつくる             | 北海道物産展などは1回で数億円規模。固定客の来店動機                                                        |
| **中層階（衣料）**                   | かつての主役                         | 郊外モールとファストファッションに食われ、最も縮んだ層（→ [アパレル・SPA](../10_アパレル・SPA/README.md)） |

デパ地下は中食（なかしょく＝調理済み食品を買って家で食べる）市場と直結している（→ [中食・弁当](../../08_食品・農水産・外食/20_中食・弁当/README.md)）。

## 5. 外商（がいしょう）―― 富裕層に「行って売る」営業

**外商**とは、店の外に出て顧客の自宅や会社を訪問し、商品を持ち込んで売る営業部隊のこと。百貨店固有の仕組みで、法人向け（贈答品・記念品）と個人向け（富裕層）がある。

```
【外商の流れ】

  外商員（担当者が顧客に1対1で付く）
     │ 自宅訪問・電話・LINE・カタログ
     ▼
  顧客の好み・家族構成・行事（結婚、進学、法事）を把握
     │
     ▼
  美術品・宝飾・時計・着物・家具を「持ち込んで」見せる
     │
     ▼
  外商カード（与信付き）で購入。請求は後日まとめて
     │
     ▼
  特別室・優待・招待会・海外展示会へ招く（囲い込み）
```

- **なぜ強いか**：高額品は「何を買うか」より「誰から買うか」で決まる。信頼関係が参入障壁そのものになる
- **数字での存在感**：伊勢丹新宿本店では購入額上位5%の顧客が売上の約50.9%、三越日本橋本店では約48.3%を占めると報じられる（WWDJAPAN）。松坂屋名古屋店では外商が店舗売上の約47〜48%を占めるという調査もある（ダイヤモンド・チェーンストア）
- **弱点**：外商員1人あたりの担当顧客数に上限があり、人が辞めると顧客ごと失う。近年は「デジタル外商」（アプリ・オンライン接客）で担当のいない準富裕層まで届かせる試みが進む

## 6. 不動産賃貸化 ―― 「売り場」を「テナント区画」に変える

消化仕入でも在庫リスクは負わないが、それでも百貨店は売り場の運営責任を持ち、人も置く。
そこからさらに一歩進めて、**区画をまるごとテナントに貸して家賃だけ受け取る**形に変える動きが、2010年代後半から本格化した。

**定期借家（ていきしゃっか）** とは、契約期間が満了したら更新されずに必ず終了する建物賃貸借契約のこと（借地借家法38条）。
普通借家は借り手が強く保護され、貸し手から「出ていってくれ」と言いにくい。定期借家なら**期間満了で入れ替えができる**ので、貸し手（百貨店）はテナント構成を計画的に組み替えられる。

| 方式                     | 百貨店の収入       | 在庫リスク | 人員               | 売り場の入替           |
| ------------------------ | ------------------ | ---------- | ------------------ | ---------------------- |
| 買取仕入                 | 売上−原価          | あり       | 自社販売員         | 自由                   |
| 消化仕入                 | 販売額の20〜30%    | なし       | ブランド派遣が中心 | 契約次第               |
| **定期借家（不動産化）** | 固定家賃＋売上歩合 | なし       | テナント持ち       | 期間満了で確実に入替可 |

- **GINZA SIX**（2017年開業、東京・銀座）は松坂屋銀座店跡地を建て替えた商業施設で、百貨店ではなく定期賃貸借契約によるテナントビルとして運営されている。運営会社はJ.フロントリテイリング系の大丸松坂屋百貨店、Lキャタルトン リアルエステート、住友商事の共同出資（GINZA SIX公式）
- **大丸心斎橋店本館**（2019年建て替え）も、約380億円を投じてGINZA SIX型の定期借家モデルを一部導入したと報じられる（日経クロストレンド）
- 百貨店会社が不動産デベロッパー的になっていく流れ（→ [不動産デベロッパー](../../12_建設・住宅・不動産/08_不動産デベロッパー/README.md)、[ビル管理・不動産サービス](../../12_建設・住宅・不動産/11_ビル管理・不動産サービス/README.md)）

> ポイント：百貨店の進化の方向は「小売業 → 場所貸し業 → 不動産業」。
> 消化仕入はその途中段階であり、定期借家はゴールに近い形。

## 7. 収益の全体像 ―― 百貨店会社は百貨店だけで食べていない

上場している百貨店グループは、いまや以下の4本立てになっている。

```
【百貨店グループの収益4本柱】

 ① 百貨店事業     店頭・外商・催事の販売手数料（消化仕入の口銭が中心）
 ② 不動産事業     自社保有ビルの賃貸、商業施設の運営受託、再開発
 ③ 金融・カード    百貨店カードの会費・加盟店手数料・キャッシング、友の会積立
 ④ その他        スーパー、食品、海外店（アジア）、通販
```

三越伊勢丹ホールディングスの2026年3月期を例にとると、売上高5,456億円・営業利益800億円のうち、百貨店業が売上4,497億円／営業利益655億円、クレジット・金融・友の会業が売上356億円／営業利益63億円、不動産業が営業利益47億円（前期比29.5%増）という構成（流通ニュース報道による同社決算）。
**本業以外の利益が全体の2割近くを占める**構造になっている点は押さえておきたい（→ [クレジットカード・決済](../../05_金融/11_クレジットカード・決済/README.md)）。

## 8. 「友の会」という前払いの仕組み

百貨店の**友の会**は、毎月一定額を積み立てると満期時に1か月分上乗せされた買物カードが戻る制度（例：月1万円×12回＝12万円積立で13万円分）。
会計上は前受金（負債）であり、**無利子で顧客からお金を預かり、その資金でしばらく運転資金を回せる**という側面がある。同時に「積み立てた以上その店で使うしかない」ので、強力な囲い込みにもなる。

## 9. まとめ ―― この仕組みが全てを説明する

| 仕組み                           | そこから生じる帰結                                                 |
| -------------------------------- | ------------------------------------------------------------------ |
| 消化仕入（在庫リスクを持たない） | 粗利率が低い。商品開発力・目利き力が社内に育ちにくい               |
| 都心一等地の大型自社ビル         | 固定費が重く、損益分岐点が高い。一方で**不動産としての価値は巨大** |
| 衣料品への依存                   | 郊外モール・ファストファッション・ECの直撃を受けた                 |
| 外商という対面営業               | 富裕層に強い。人依存で規模拡大しにくいが、EC時代でも代替されにくい |
| 定期借家への転換                 | 小売の利益を捨てて安定家賃を取る。売上高は減るが利益は安定         |

## 用語メモ

| 用語           | 意味                                                                                                                                                           |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **消化仕入**   | 店頭で商品が売れた瞬間に「仕入」と「売上」を同時に計上する取引。売れるまで商品の所有権は仕入先にあり、在庫リスクも仕入先が負う。百貨店の衣料・雑貨売り場の主流 |
| **買取仕入**   | 納品時に商品を買い取る通常の仕入。売れ残りリスクは小売が負うが、粗利は厚い                                                                                     |
| **委託仕入**   | 商品を預かって並べる形態。所有権は仕入先のままだが、保管責任は百貨店が負う                                                                                     |
| **代理人取引** | 収益認識会計基準上の区分。自ら商品を売る「本人」ではなく仲介役と判定される取引。収益は手数料部分のみ（純額）で計上する                                         |
| **総額売上高** | 消化仕入を総額ベースに引き直した売上。純額表示になった後も実態把握のため各社が併記する                                                                         |
| **外商**       | 百貨店の訪問営業部門。担当者が富裕層・法人に1対1で付き、商品を持ち込んで販売する                                                                               |
| **デパ地下**   | 百貨店地下階の食品売り場。惣菜・菓子・生鮮を扱い、来店頻度を稼ぐ役割                                                                                           |
| **催事**       | 物産展・美術展など期間限定の売り場。北海道物産展が代表格                                                                                                       |
| **定期借家**   | 契約期間の満了で確実に終了する建物賃貸借契約（借地借家法38条）。更新がないため貸主がテナントを計画的に入れ替えられる                                           |
| **歩合賃料**   | 固定家賃に加えてテナントの売上の一定割合を受け取る家賃。売上連動なので貸主も売れ行きを気にする                                                                 |
| **友の会**     | 毎月積み立てると満期に1か月分上乗せされて買物カードで戻る前払い制度。実質的な無利子の資金調達と囲い込みを兼ねる                                                |
| **坪効率**     | 売場1坪あたりの売上高。店舗の生産性を測る小売業共通の指標                                                                                                      |
