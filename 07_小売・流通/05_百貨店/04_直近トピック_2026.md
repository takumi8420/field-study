# 直近トピック（2026年9月時点）

報道・協会統計ベースの整理。数値は発表時点のもので、最新は日本百貨店協会（depart.or.jp）と各社IRで確認すること。

## 1. 2025年は5年ぶりの減収 ―― 免税が12.7%減った

日本百貨店協会が2026年1月に発表した2025年の全国百貨店売上高は**5兆6,754億円、既存店ベースで前年比1.5%減**。4年続いた増収が止まり、5年ぶりのマイナスとなった（時事通信・ダイヤモンド・チェーンストア）。

| 項目                   | 2025年       | 前年比          |
| ---------------------- | ------------ | --------------- |
| 全国売上高             | 5兆6,754億円 | −1.5%（既存店） |
| 免税売上高             | 5,667億円    | **−12.7%**      |
| 訪日購買客数           | 621万人超    | 過去最高        |
| 雑貨（化粧品・宝飾等） | 1兆2,550億円 | +2.2%           |
| 衣料品                 | ―            | −2.2%           |
| 食料品                 | ―            | −0.4%           |

```
【2025年に起きたこと】

  訪日客数        ↑ 過去最高（客は増えた）
  客単価          ↓ 高額品 → 消耗品（化粧品・食品）へシフト
  ──────────────────────────────────────
  免税売上        ↓ 12.7%減

  ＋ 2025年11月以降、日中関係をめぐる問題で中国発の航空便が大幅減
    → 免税売上の柱だった中国人客が急減したと報じられる（WWDJAPAN）
```

> ポイント：**「客数は最高なのに免税売上は減った」**というねじれが2025年の本質。
> 人数ではなく単価で稼ぐ業態なので、訪日客数の記録更新は必ずしも追い風にならない。

## 2. 2026年に入って免税は回復 ―― 5か月連続プラス、単価も戻る

2026年は月次で免税売上のプラスが続いている（日本百貨店協会、調査対象86店舗）。

| 月        | 免税売上高       | 前年同月比 | 備考                                                                           |
| --------- | ---------------- | ---------- | ------------------------------------------------------------------------------ |
| 2026年4月 | 約520億1,000万円 | +18.3%     | 2か月連続プラス。中国の売上は2%減まで回復                                      |
| 2026年6月 | 約509億5,000万円 | +29.8%     | 中国が7か月ぶりにプラス転換                                                    |
| 2026年7月 | 約506億2,000万円 | +25.5%     | 5か月連続プラス。購買客数 約49.1万人（+3.0%）、**客単価 約10.3万円（+21.8%）** |

- 2026年7月は香港・韓国・台湾が好調。中国は**客数が約26%減ったまま売上は約5%増**という構図で、来る人数は戻らなくても1人あたりの購入額が回復している
- 円安基調が続き、ラグジュアリーブランドの時計・宝飾など高額品が牽引していると協会は説明している
- 2026年7月の百貨店全体売上高は4,889億円余（前年同月比5.1%増）で7か月連続のプラス（流通ニュース）

```
【インバウンドの質の変化】

  2024年：人数も単価も高い（ブーム期）
     ↓
  2025年：人数は最高／単価が急落（化粧品・食品などの消耗品へ）
     ↓
  2026年：人数はほどほど／単価が戻る（時計・宝飾の高額品へ）

  → 百貨店が求めているのは「人数」ではなく「高単価の客」。
     観光客数の増減だけを見ても百貨店の業績は読めない。
```

## 3. 2026年3月期決算 ―― 三越伊勢丹だけが独走

インバウンド一服の影響で、2025年度は上場百貨店大手10社のうち増収増益を達成したのは2社だけだったと報じられる（ダイヤモンド・チェーンストア「百貨店決算ランキング2026」）。

| 企業                            | 売上高    | 前期比 | 営業利益    | 前期比 | メモ                                     |
| ------------------------------- | --------- | ------ | ----------- | ------ | ---------------------------------------- |
| 三越伊勢丹HD                    | 5,456億円 | −1.8%  | **800億円** | +4.9%  | 3年連続で営業最高益。国内顧客売上は+2.7% |
| 高島屋                          | 4,923億円 | −1.2%  | 535億円     | −6.9%  | インバウンドの正常化が響く               |
| エイチ・ツー・オー リテイリング | 6,802億円 | −0.2%  | 323億円     | −7.0%  | インバウンド売上は19.9%減                |
| J.フロント リテイリング         | 4,450億円 | +0.7%  | 490億円     | −15.8% | 前期の会計上の要因による反動を含む       |

- 三越伊勢丹HDの純利益は760億円（+44.1%）で過去最高を大幅更新。セグメント別では百貨店業の営業利益655億円（+1.5%）に加え、**クレジット・金融・友の会業が63億円（+10.3%）、不動産業が47億円（+29.5%）**と非小売が伸びた（流通ニュース報道）
- 高島屋は2026年3〜5月期で純利益が前年同期比58.4%増と回復傾向（日本経済新聞）
- **売上は減っても利益は出る**構造に変わったことが、各社の決算から読み取れる（→ [② なぜ縮小したのか](02_なぜ縮小したのか.md) 第9章）

## 4. 2026年11月から免税制度が「リファンド方式」に変わる

外国人旅行者向け消費税免税制度が、2026年11月1日の販売分から大きく変わる（国税庁・全国免税店協会）。

```
【旧方式（免税販売）】
  店頭で税抜き価格で販売 → その場で免税
  ↑ 転売目的の不正な免税購入が問題化していた

【新方式（リファンド方式）2026年11月1日〜】
  店頭で税込み価格で販売 ＋ 購入記録情報を送信
        ↓
  出国時に税関で「持ち出し」を確認
        ↓
  確認情報を店舗が取得 → 消費税相当額を購入者へ返金
```

| 論点         | 内容                                                                                                                                       |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 購入時の負担 | 旅行者は**購入時点で消費税を払う**。手元の支払額が10%分増える                                                                              |
| 不正防止     | 国外へ持ち出したことを税関が確認するため、国内転売目的の免税購入を防げる                                                                   |
| 店舗の実務   | システム改修が必須。返金オペレーション（現金・カード返金・空港カウンター等）の整備も要る                                                   |
| 懸念         | 制度変更を知らない旅行者からの問い合わせ対応、購買意欲の一時的な鈍化。**2026年10月に駆け込み需要、11月に反動減**が起きる可能性が指摘される |

> 百貨店にとっては、免税売上が売上の1〜3割を占める旗艦店ほど影響が大きい。
> 2026年後半〜2027年前半の月次売上を読むうえで、この制度変更は必ず織り込む必要がある。

## 5. 閉店と開業が同時に進む ―― 2026年の店舗地図

2026年は「地方の名門店が消え、都心にラグジュアリー施設ができる」年になった（WWDJAPAN、FASHIONSNAP）。

| 動き                                                  | 内容                                                                                                                                                                                                                         |
| ----------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **高島屋堺店 閉店**（2026年1月7日）                   | 1964年開業。南海高野線・堺東駅。売場面積2.5万m²（百貨店区画1.6万m²＋専門店区画0.9万m²）                                                                                                                                      |
| **名鉄百貨店本店 閉店**（2026年2月28日）              | 1954年開業。東海地区初のターミナル百貨店。2024年に開業70周年を迎えたばかりだった                                                                                                                                             |
| **名古屋・栄「ハエラ」開業**                          | 大丸松坂屋百貨店やパルコなどによるラグジュアリーモール。名駅から栄へという名古屋の商業重心の移動を象徴                                                                                                                       |
| **西武池袋本店 グランドリニューアル**（2026年中予定） | 創業以来初の全面改装。2025年7月の3階コスメを皮切りに段階開業し、2026年1月以降に地下2階デパチカ（生鮮・酒）、1階インターナショナルブティック、7・8階などが順次オープン。約380店舗規模（そごう・西武公表、ファッションプレス） |
| **ヨドバシの池袋出店**                                | 百貨店売場の圧縮部分に、ヨドバシカメラの体験型新業態「ヨドブルーム池袋店」が入る計画と報じられる                                                                                                                             |

- 東京商工リサーチの調査では、百貨店業者は5年で8社減り、直近決算で「減収」が約8割、「減益」が約7割
- 閉店ペースは2010年（リーマン後）を超える水準とも報じられる（日経BizGate）
- 跡地は商業＋オフィス＋ホテル＋レジデンスの複合再開発が主流だが、建設費高騰と民間投資の慎重化で「同規模・同機能の施設が再び建つとは限らない」との指摘がある（Yahoo!ニュース エキスパート）

```
【2026年の百貨店地図】

  地方・準都心      都心一等地
  ──────────      ──────────
  堺（高島屋）閉店   池袋（西武）全面改装 → 百貨店＋ヨドバシ
  名駅（名鉄）閉店   栄（ハエラ）ラグジュアリーモール開業
        ↓                  ↓
  跡地は再開発待ち    高級・体験・免税に特化した施設へ

  → 「百貨店」という業態名のまま中身が入れ替わっていく
```

## 6. 国内富裕層シフトという共通戦略

インバウンドの振れが大きいことを各社が学習した結果、2026年の各社方針は揃って**「国内顧客の深耕」**に向かっている。

- 三越伊勢丹HDは2026年3月期に国内顧客売上が2.7%増。インバウンド減を国内で埋めた
- 各社とも既存店のリノベーションと外商・カード会員の上位層強化に投資を振り向けている
- 背景として、純金融資産1億円以上の富裕層・超富裕層世帯が増えているという調査がある（野村総合研究所の推計などが引用される）
- ただし富裕層の購買は株価・資産価格に連動するため、**インバウンド依存を富裕層依存に置き換えただけ**という見方もできる

## 7. 全体の構図（まとめ）

1. **2025年は5年ぶりの減収**。訪日客数は過去最高なのに免税売上は12.7%減という「量は増え単価は落ちた」年だった
2. **2026年は免税が回復**。7月で前年同月比25.5%増、客単価は+21.8%。中国は客数が戻らないまま単価で戻すという形
3. **利益構造は完全に入れ替わった**。三越伊勢丹は減収でも営業利益800億円と3年連続最高益。不動産・金融が利益を底上げしている
4. **2026年11月のリファンド方式移行**が最大の実務・需要両面の不確実要素。直前の駆け込みと直後の反動に注意
5. **閉店と開業の同時進行**。地方の名門店が消え、都心はラグジュアリーと体験型に再編される。業態名は残っても中身は「不動産＋高額品＋免税」に置き換わっている

## 用語メモ

| 用語                     | 意味                                                                                                    |
| ------------------------ | ------------------------------------------------------------------------------------------------------- |
| **既存店ベース**         | 前年も営業していた店舗だけを比べた数字。新規開店・閉店の影響を除いて実力を測る                          |
| **免税売上高**           | 訪日外国人が消費税免除で購入した金額。日本百貨店協会が調査対象86店舗について月次で公表する              |
| **リファンド方式**       | 2026年11月1日開始。購入時は税込みで支払い、出国時の税関確認を経て消費税相当額が返金される新しい免税方式 |
| **輸出物品販売場**       | 免税販売ができる店舗の法律上の呼称。税務署への許可申請が必要                                            |
| **駆け込み需要と反動減** | 制度変更や増税の直前に需要が前倒しで発生し、直後に落ち込む現象                                          |
| **グランドリニューアル** | 建物全体を対象とした大規模改装。段階的に各フロアを開けながら進めることが多い                            |
| **ターミナル百貨店**     | 私鉄などのターミナル駅に直結して建てられた百貨店。名鉄百貨店本店、阪急うめだ本店など                    |
| **ラグジュアリーモール** | 高級ブランドを中心に構成した商業施設。百貨店と違い定期借家によるテナント運営が基本                      |
