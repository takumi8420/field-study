# 百貨店

- 大分類: 小売・流通
- 状態: done
- 更新日: 2026-09-20

都心一等地の大型店に、衣・食・住・贈答のすべてを揃えて売る業態。ただし実態は「自分で仕入れて売る店」ではなく、**売り場を貸して売れた分だけ手数料を抜く場所貸し業**に近い。
この「消化仕入（しょうかしいれ）」という独特の取引慣行と、都心の自社ビルという重い固定費の組み合わせが、この業界の栄光と凋落のすべてを説明する。
売上はピーク（1991年 約9.7兆円）から2025年は5兆6,754億円へ約4割減ったが、**不採算店を閉じ富裕層と免税客に絞った結果、利益だけは過去最高圏**という逆転が起きている。

## 1. 業界の定義・範囲

「百貨店」に法律上の定義はないが、実務上は**日本百貨店協会の加盟店**を指すことが多い。特徴は次の4点。

```
【百貨店を百貨店たらしめている4条件】

  ① 総合性   衣・食・住・贈答を1つの建物で全部そろえる
  ② 立地     都心または主要駅前の一等地・大型自社建物
  ③ 対面     販売員による接客が前提（セルフサービスではない）
  ④ 外商     店に来ない富裕層・法人へ訪問して売る部隊を持つ
```

| 隣接業態                                       | 境界線                                                                                             |
| ---------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| [スーパー・GMS](../02_スーパー・GMS/README.md) | GMSも総合品揃えだが、セルフサービス・買取仕入・郊外立地が基本。価格帯も違う                        |
| ショッピングセンター／モール                   | テナントに貸す不動産業。百貨店は（建前上）自ら販売する。ただし百貨店の不動産化で境界は溶けつつある |
| [家電量販](../06_家電量販/README.md)           | 単一カテゴリの専門大型店。近年は百貨店の一等地を取りに来ている（西武池袋とヨドバシ）               |
| [アパレル・SPA](../10_アパレル・SPA/README.md) | 百貨店の売り場の中身を供給する側。消化仕入では在庫リスクを負う当事者でもある                       |
| [通販・D2C](../15_通販・D2C/README.md)         | 衣料品需要の流出先。百貨店自身のECは在庫を持たない構造ゆえに出遅れた                               |

## 2. 市場規模と成長性

| 年         | 全国百貨店売上高                 | 出典・備考                                                                      |
| ---------- | -------------------------------- | ------------------------------------------------------------------------------- |
| 1991年     | 約9兆7,000億円                   | ピーク（日本百貨店協会）                                                        |
| 2019年     | 約5兆7,000億円                   | インバウンド1次ブーム期                                                         |
| 2020年     | 約4兆2,000億円（−26%）           | コロナ禍。45年ぶり低水準と報じられる（日本経済新聞）                            |
| 2024年     | 約5兆8,000億円                   | 4年連続増                                                                       |
| **2025年** | **5兆6,754億円（既存店 −1.5%）** | 5年ぶり減。免税5,667億円（−12.7%）が主因（日本百貨店協会／時事通信・2026年1月） |

- 加盟店舗数は2012年4月末249店 → 2022年4月末190店（10年で59店減）。2025年1月時点で72社168店とされる（同協会公表値）
- 2026年は月次で回復基調。7月の全国売上高は4,889億円余（前年同月比5.1%増）で7か月連続プラス、免税売上は506億円（+25.5%）で5か月連続プラス（→ [④](04_直近トピック_2026.md)）

```
【長期推移のイメージ（兆円）】
 10 ┤●1991 9.7
  8 ┤ ＼
  6 ┤  ＼＿＿＿＿●2019 5.7  ／￣●2024 5.8 ●2025 5.7
  4 ┤            ●2020 4.2
  2 ┼────────────────────────────────
    1991    2000    2010    2020   2025
```

> 市場は縮んだが下げ止まりつつある。ただし回復分の多くがインバウンドと富裕層という**外部変数に依存**している点が構造的な弱さ。

## 3. バリューチェーン（川上 → 川下）

```
【百貨店を通る商流】

  ブランド・メーカー（アパレル／化粧品／時計・宝飾）
        │  ← 商品も販売員も価格決定権もここが持つ（消化仕入）
        ▼
  ［百貨店］  場所・信用・接客インフラ・顧客名簿を提供
        │      収益 = 販売額 × 20〜30%（口銭）
        │      ＋ 定期借家の家賃（不動産化した区画）
        │      ＋ カード手数料・友の会（金融）
        ├──── 店頭（1〜2階の化粧品・ラグジュアリーが主力）
        ├──── デパ地下（来店頻度をつくる。買取仕入も多い）
        ├──── 催事（物産展・美術展。非日常の集客装置）
        └──── 外商（顧客の自宅・法人へ訪問。高額品）
        ▼
  顧客（富裕層／訪日客／ハレの日需要／贈答）
```

**付加価値が集まる場所**は、商品そのものではなく「一等地の床」と「富裕層の顧客名簿」。
どちらもブランド側が自前で持つのは難しく、ここが百貨店の残された強みになっている。

## 5. 収益モデル・コスト構造

```
【総額売上ベースのP/Lイメージ（目安）】
  総額売上高                100
   └ 仕入先の取り分          72〜78
  ─────────────────────────────
  売上総利益                22〜28   ← スーパー25〜30、SPA 50超と比べて薄い
   └ 人件費                  8〜11    ┐
   └ 地代家賃・減価償却       5〜8     ├ ほぼ固定費
   └ 光熱・警備・清掃・販促    5〜7     ┘
  ─────────────────────────────
  営業利益                   1〜5     ← 売上1割減で吹き飛ぶ
```

| 収益の柱           | 内容                                                   | 性質                               |
| ------------------ | ------------------------------------------------------ | ---------------------------------- |
| ① 百貨店事業       | 消化仕入の口銭（販売額の20〜30%）、買取品の粗利        | 売上変動を直接かぶる               |
| ② 不動産事業       | 定期借家による固定家賃＋歩合賃料、商業施設運営、再開発 | 安定。利益率が高い                 |
| ③ クレジット・金融 | カード年会費・加盟店手数料・リボ、友の会の前受金       | 安定。百貨店の外で使われても稼げる |
| ④ その他           | 食品スーパー、海外店、EC                               | 会社により差が大きい               |

三越伊勢丹HDの2026年3月期では、百貨店業の営業利益655億円に対し、金融63億円・不動産47億円。**非小売が利益の1割超**を担う（→ [①](01_百貨店の商売の仕組み.md) 第7章）。

## 6. 競争要因（KSF）と参入障壁

| KSF                            | なぜ効くか                                                                                                          |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------- |
| **一等地の床を持っていること** | 新規に銀座・新宿・梅田の大型床を確保するのは事実上不可能。最大の参入障壁                                            |
| **富裕層の顧客名簿と外商員**   | 高額品は「誰から買うか」で決まる。信頼関係は買えない。伊勢丹新宿本店では上位5%の顧客が売上の約50.9%を占めるとされる |
| **ブランドに選ばれること**     | ラグジュアリーブランドは出店先を厳選する。格の落ちた店には出てくれない＝負のスパイラルが起きる                      |
| **免税対応力**                 | 多言語人員、決済、税関確認（2026年11月〜のリファンド方式）への対応                                                  |
| **不動産を開発・運用する力**   | 建て替え・複合化を自前で回せるか。J.フロントが先行                                                                  |
| **固定費を下げる決断力**       | 不採算店を閉じ、床を貸しに回す判断の速さが利益を分ける                                                              |

**参入障壁は極めて高いが、それは「守り」の障壁**であって成長を保証しない。新規参入がないまま市場だけ縮むのがこの業界の難しさ。

## 7. 規制・法制度

| 制度                                                | 内容・影響                                                                                                                                                      |
| --------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **大規模小売店舗立地法**（2000年〜）                | 旧・大規模小売店舗法（大店法）に代わる制度。出店調整ではなく交通・騒音など周辺環境への配慮を求める。大店法の緩和・廃止は郊外モール増加の制度的背景になった      |
| **収益認識に関する会計基準**（2021年4月〜強制適用） | 消化仕入を代理人取引と整理し、収益を純額（手数料のみ）で計上させる。**各社の見かけの売上高が大きく減った**（→ [①](01_百貨店の商売の仕組み.md) 第2章）           |
| **輸出物品販売場制度（免税）**                      | 2026年11月1日から**リファンド方式**へ移行。購入時は税込み、出国時の税関確認後に返金。旗艦店ほど実務・需要の両面で影響が大きい（→ [④](04_直近トピック_2026.md)） |
| **借地借家法38条（定期借家）**                      | 期間満了で確実に終了する賃貸借。テナント入替を計画的にできるため、百貨店の不動産化を支える法的基盤                                                              |
| **中心市街地活性化法／都市再生特別措置法**          | 地方百貨店の跡地再開発や、自治体との連携による公共複合施設化の枠組み                                                                                            |
| **景品表示法・食品表示法・割賦販売法**              | 催事・デパ地下・カード事業にそれぞれ適用                                                                                                                        |

## 8. 最近のトピック

詳細 → [④ 直近トピック（2026年9月時点）](04_直近トピック_2026.md)

1. **2025年は5年ぶりの減収**。売上5兆6,754億円（既存店 −1.5%）。訪日購買客数は621万人超と過去最高なのに、免税売上は12.7%減の5,667億円。**人は増えたが単価が落ちた**
2. **2026年は免税が回復**。7月の免税売上は506億円（+25.5%）で5か月連続プラス、客単価は約10.3万円（+21.8%）。中国は客数減のまま売上プラスという形
3. **売上減でも利益は最高**。三越伊勢丹HDは2026年3月期に営業利益800億円で3年連続最高益。不動産・金融が下支え。一方で大手10社中、増収増益は2社のみ
4. **2026年11月にリファンド方式へ移行**。直前の駆け込みと直後の反動減が見込まれる
5. **閉店と開業が同時進行**。高島屋堺店（2026年1月）・名鉄百貨店本店（同2月）が閉店、名古屋栄に「ハエラ」開業、西武池袋本店は創業以来初の全面改装で2026年中グランドリニューアル

## 9. 用語メモ

各ノート末尾に用語メモを置いている。特に重要な3語は以下。

| 用語         | 意味                                                                                                                                                                                              |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **消化仕入** | 店頭で商品が売れた瞬間に仕入と売上を同時計上する取引。売れるまで所有権も在庫リスクも仕入先（アパレル等）にある。百貨店の粗利が薄い最大の理由 → [詳しくは ①](01_百貨店の商売の仕組み.md)           |
| **外商**     | 富裕層・法人の自宅や会社を訪問して高額品を売る百貨店固有の営業部隊。少数の上顧客が売上の半分近くを支える → [詳しくは ③](03_今の稼ぎ方.md)                                                         |
| **定期借家** | 期間満了で確実に終了する建物賃貸借契約（借地借家法38条）。テナントを計画的に入れ替えられるため、百貨店が「小売」から「場所貸し」へ移る手段になっている → [詳しくは ①](01_百貨店の商売の仕組み.md) |
