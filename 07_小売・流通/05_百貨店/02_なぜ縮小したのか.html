なぜ縮小したのか

小売・流通百貨店
あこのページの単語集用語に触れると意味を確認できます8語
損益分岐点固定費閉店ドミノ大店法・大店立地法SPAアクティビスト簿価と時価の乖離ターミナル百貨店

このノートで分かること：百貨店の売上はピークからほぼ半減した。原因は「不景気だから」ではなく、主力だった衣料品の売り場が郊外モール・ファストファッション・ECに丸ごと持っていかれ、なのに都心・地方の大型店という重い固定費は残り続けた、という構造の問題である。

1. 数字で見る縮小 ―― ピークから約4割減

2. 何が減ったのか ―― 犯人は衣料品

売上の中身を分解すると、減ったのは全てではない。衣料品が沈み、化粧品・宝飾などの「雑貨」が支えている。

雑貨（化粧品・宝飾・時計・美術品）脇役現在の主力前年比2.2%増、1兆2,550億円

3. なぜ衣料品が地盤沈下したのか ―― 3方向からの攻撃

① 郊外ショッピングモール（1990年代後半〜）

1990年代の大規模小売店舗法（大店法）緩和とその後の大規模小売店舗立地法への移行で、郊外に大型商業施設が出せるようになった。
イオンモールのような無料駐車場・映画館・フードコート付きの一日過ごせる施設が、地方都市の「休日は駅前の百貨店へ」という行動を置き換えた。

② ファストファッションとSPA（2000年代〜）

ユニクロ、ZARA、H&Mなど、企画から製造・小売まで一社でやる（SPA）業態が台頭。
消化仕入の百貨店は、ブランド側が決めた商品を並べるだけなので、価格でも鮮度でも勝負できなかった（→ アパレル・SPA、繊維商社）。

③ EC（2010年代〜）

サイズ・色をネットで選んで届けてもらう。試着の必要が薄い定番品ほどECに流れた。
百貨店自身のECは、消化仕入ゆえに在庫データを自社で持っていないという致命的なハンデを抱え、出遅れた（→ 通販・D2C）。

【かつての客の動線】            【今の客の動線】

  休日 → 駅前百貨店             平日夜 → スマホでEC
   └ 服も食品も贈答品も          休日   → 郊外モール（駐車場無料）
                                 ハレの日→ 都心旗艦店・デパ地下
                                 中古で → リユース（→ ../16_リユース・中古/）

4. なぜ耐えられなかったのか ―― 固定費の構造

売上が落ちても、百貨店のコストは比例して落ちない。

コスト 性質 売上が1割落ちたとき
仕入原価（消化仕入分）完全変動費1割落ちる
人件費ほぼ固定ほとんど落ちない
地代家賃・減価償却完全固定落ちない
光熱費・警備・清掃・エレベーター保守ほぼ固定落ちない
【損益分岐点の考え方】

  売上 ─────────────────────────────▶
        ┃          ┃
      赤字        黒字
        ┃          ┃
   固定費が重い＝この境目（損益分岐点）が右にずれる
   ＝少しの売上減で赤字に落ちる

  粗利率25%・固定費が売上の23%相当の店なら、
  売上が1割減るだけで粗利は2.5ポイント分減り、営業利益はほぼゼロになる

さらに悪いのは、売り場の面積を部分的に縮めても固定費はあまり減らないこと。
建物の空調も警備も、フロアを半分閉めても半額にはならない。だから「じわじわ縮める」のではなく「丸ごと閉める」判断になりやすい。これが閉店ドミノの正体である。

5. 地方店の閉店ドミノ

地方百貨店が抱えた三重苦。

【地方百貨店を襲った3つの同時進行】

  人口減少・高齢化 ──┐
                     ├──▶ 商圏そのものが縮む
  郊外モール開業 ────┤
                     │
  免税需要が来ない ──┘  ← インバウンドは都心と一部観光地に集中

  → 売上減 → 赤字 → 閉店 → 駅前の空洞化 → さらに客足が減る
     （残った店にも波及するので「ドミノ」と呼ばれる）
  • 2025年以降の閉店ペースは2010年（リーマン後の閉店期）を上回るとも報じられる（日経BizGate）
  • 東京商工リサーチの調査では、百貨店業者は5年で8社減り、直近で「減収」が約8割、「減益」が約7割
  • 2026年にも複数の店舗が姿を消した。高島屋堺店が1月7日に営業終了（1964年開業、売場面積2.5万m²）、名鉄百貨店本店が2月28日に閉店（1954年開業、東海地区初のターミナル百貨店）と報じられる（WWDJAPAN、FASHIONSNAP）

「県庁所在地に百貨店がない県」が生まれるという現象は、単なる商業の話ではなく、地域の贈答文化・催事・雇用の受け皿が同時に消えることを意味する。

6. 不動産価値と本業の乖離 ―― 最大の皮肉

百貨店が持っている最大の資産は、実は商売ではなく土地と建物である。

【百貨店会社のバランスシートのゆがみ】

  資産サイド                          損益サイド
  ┌────────────────────┐           ┌────────────────┐
  │ 都心一等地の土地・建物  │           │ 百貨店営業      │
  │ （簿価は取得時のまま／  │  ≫≫≫    │ 営業利益率      │
  │   時価は数千億円規模）  │           │ 数%程度         │
  └────────────────────┘           └────────────────┘

  「その土地でその商売を続けるのが最適か？」という問いが必ず立つ
  → オフィス・ホテル・タワマン・高級テナントビルに建て替えた方が儲かる、という結論が出やすい
  • 銀座・日本橋・心斎橋・梅田といった立地は、百貨店以外の用途で使った方が利回りが高いことが多い
  • ゆえに再開発が進む。GINZA SIX（松坂屋銀座店跡）がその象徴（→ ① 百貨店の商売の仕組み 第6章、不動産デベロッパー）
  • 同時にこれは投資家からの圧力を生む。「本業が稼げないなら不動産を活かせ」という要求は、アクティビスト（物言う株主）の定番の主張になった

7. そごう・西武の売却が象徴するもの

2023年、セブン&アイ・ホールディングスは傘下のそごう・西武を米投資ファンドのフォートレス・インベストメント・グループへ売却した。同日、西武池袋本店ではストライキが実施され、大手百貨店では約60年ぶりの労働争議として大きく報じられた。

論点 内容
売却の理由コンビニを中核とする親会社にとって、低採算の百貨店事業は資本効率を下げる存在だった
買い手投資ファンド。狙いは店舗の不動産価値と再構築後の売却益とみられる
家電量販の参入ヨドバシカメラが池袋・渋谷などの一等地に売り場を確保。百貨店の一等地が家電量販に渡る構図（→ 家電量販）
労働側の反発「売り場と雇用が守られるのか」が争点。百貨店が地域の雇用装置でもあることを可視化した
その後西武池袋本店は創業以来初の全面改装に入り、2026年中のグランドリニューアルオープンを予定（そごう・西武公表）。百貨店売場を圧縮し、ヨドバシの体験型店舗「ヨドブルーム池袋店」などが入る計画と報じられる

ポイント：この一件が象徴するのは「百貨店は小売の王様である」という前提が株式市場からも、親会社からも、もう共有されていないということ。
資産としての百貨店（＝不動産）と、事業としての百貨店（＝低採算の小売）が完全に切り離して評価されるようになった。

9. ただし「衰退産業」と言い切るのは早い

  • 2023〜2024年は4年連続の増収で、三越伊勢丹ホールディングスは2026年3月期に営業利益800億円と3年連続の過去最高を記録した（流通ニュース報道）。売上が半減しても利益は過去最高という逆転が起きている
  • 理由は、不採算店を閉め、衣料品を縮め、高粗利の化粧品・宝飾と不動産・金融にシフトしたから。縮小は「敗北」であると同時に「損益構造の入れ替え」でもあった
  • 残った問題は、その利益がインバウンドと富裕層という2つの変数に強く依存していること（→ ③ 今の稼ぎ方、④ 直近トピック）
