# 家電量販

- 大分類: 小売・流通
- 状態: done
- 更新日: 2026-09-20

> **最初に押さえること**
> 家電量販店は「安く売る店」ではなく、**「本体を薄利で売り、それ以外で回収する店」**である。
> 商品を仕入れて売るだけの粗利率は**25〜30%程度**（食品スーパーと同水準か、やや上）しかなく、
> しかもその粗利には**リベート（メーカーからの販売協力金）が大きく食い込んでいる**。
> 足りない分は、**延長保証・配送・設置工事・リサイクル回収・ポイント・通信回線契約**で埋める。
> 「1台の家電をいくらで売ったか」ではなく「**1人の客からいくら回収したか**」で見る商売である。
>
> そしていま、その構造が2つの方向から揺さぶられている。
> ひとつは**メーカーの指定価格制度**——値決めの主導権をメーカーが取り返しにきた。
> もうひとつは**業界再編**——2026年6月、**ヤマダHDとエディオンが経営統合に基本合意**（合算売上約2.5兆円）。
> 同年4月には**ノジマが日立の家電事業を約1,100億円で買収**すると発表した。
> **小売がメーカーを買い、メーカーが小売の値段を決める**。力関係が両方向にひっくり返りつつある。

## 1. 業界の定義・範囲

**家電量販店**＝家電製品を中心に、多店舗・大量販売で低価格を実現する専門小売業。
統計上は経済産業省「商業動態統計」の**「家電大型専門店」**（売場面積500m²以上で
家電を主に販売する事業所）がこれに当たる。

境界の引き方：

| 区分 | 含む／含まない | 理由 |
| --- | --- | --- |
| ヤマダ・ビック・ヨドバシ・ケーズ・エディオン・ノジマ・上新 | **含む** | 中核 |
| 地域電器店（パナソニックの系列店など） | 含まない | 単独店。メーカー系列の商流で、経済性がまったく違う |
| Amazon・楽天（家電販売） | 含まない（**最大の競合**） | 店舗を持たない。ただし競争相手として必ずセットで見る |
| ドン・キホーテ、ホームセンター、ニトリの家電 | 含まない | 主業が別。家電は品揃えの一部 |
| 携帯ショップ（ドコモショップ等） | 含まない | ただし**量販店自身がキャリア代理店を大量に運営**しており、事業としては重なる |
| PCデポ、パソコン工房など | 周辺 | PC・サービス特化 |

> **注意**：「家電量販店」という名前と実態がずれてきている。
> ヤマダHDは売上の**約2割が住宅・リフォーム**、ノジマは携帯キャリアショップ運営とISP（ニフティ）が
> 利益の柱の一つ、ビックカメラは酒・食品・医薬品まで扱う。
> **家電だけを見ていると各社の利益の出どころを読み違える**。

## 2. 市場規模と成長性

| 指標 | 値 | 出典・年 |
| --- | --- | --- |
| 家電大型専門店 販売額（2025年度） | **4兆9,214億円**（前年度比 +4.1%） | 経産省 商業動態統計 |
| 家電大型専門店 店舗数（2025年度） | **2,657店**（-0.5%） | 経産省 商業動態統計 |
| 同 月次（2026年3月） | 5,015億円（前年同月比 +4.4%） | 経産省 商業動態統計 |
| 同 月次（2026年5月） | 4,716億円（**+27.5%**）＝エアコン駆け込み | 経産省 商業動態統計 |
| 家電のEC市場規模（2024年） | **2兆7,443億円**、**EC化率43.03%** | 経産省「電子商取引に関する市場調査」（2025年8月公表） |
| （参考）物販系BtoC-EC全体のEC化率 | 9.78%（2024年） | 同上 |

**成長性の見方**：

- **店舗数は減り、1店舗あたり売上は増える**。すでに出店余地は乏しく、成長は「客単価×付帯サービス」で作る
- **2025〜26年の伸びは実力ではない**。エアコンの駆け込み（[2027年問題](../../03_電機・電子部品/09_白物家電/04_直近トピック_2026.md)）、
  Windows10サポート終了に伴うPC特需、インバウンド、自治体補助——いずれも**一過性**
- **EC化率43%は物販の中で突出して高い**。家電は型番が同じなら品質差がなく、比較しやすいため
  ネットに流れやすい。**店舗は「見て触る場所」「工事と保証を頼む場所」に役割が変わっている**

```
【家電量販の売上が動く4つの外部要因（自社努力ではないもの）】

   気温 ────────▶ エアコン・冷蔵庫（猛暑の年は跳ねる）
   規制 ────────▶ 省エネ基準強化（2027年4月）→ 前年に駆け込み、翌年に反動
   OSサポート終了 ─▶ PC（Windows10終了 = 2025年10月）→ 買い替え特需と、その反動
   為替・インバウンド ▶ 都市型店舗の免税売上

   → この4つで説明できてしまう年が多い。
     「既存店前年比が+20%」と聞いたら、まず外部要因を疑うのが正しい読み方。
```

## 3. バリューチェーン（川上 → 川下）

```
 メーカー            卸・商流              量販店の中               顧客
 ┌────────┐      ┌────────┐   ┌──────────────┐   ┌──────┐
 │ 白物家電    │      │ 直接取引     │   │ 仕入・バイヤー      │   │ 個人    │
 │ AV・PC      │─────▶│（大手は中抜き）│──▶│ 店舗（見る・触る）   │──▶│ 法人    │
 │ スマホ      │      │ 卸（中小は経由）│   │ EC（比べる・買う）   │   │ 工務店  │
 │ ゲーム・日用品│      └────────┘   │ 配送・設置工事       │   └──────┘
 └────────┘            ▲          │ 延長保証・修理受付   │
      │                    │          │ 下取り・リサイクル   │
      │  ★リベート（販売協力金）│          └──────────────┘
      └────────────────┘                    │
         ここが量販店の利益を実質的に決める           ▼
                                            リユース・リサイクル

 【付加価値が集まる場所】
  ・商品の差＝ほぼゼロ（同じ型番はどこでも同じ物）
  ・だから価値は「値段」「在庫があるか」「いつ届くか」「工事できるか」「保証」に移る
  ・→ 物流・工事網・保証のオペレーションを持つ側が強い
  ・→ それを持たないECに対する、量販店の唯一の堀（moat）でもある
```

**仕入の実態**：大手量販店はメーカーと直接取引し、卸を通さない。
ただし**「いくらで仕入れたか」だけでは粗利が決まらない**のがこの業界の特徴で、
伝票上の仕入価格とは別に、期末や達成条件ごとに**リベート**が支払われる。
→ 詳細は [① 量販店の経済](01_量販店の経済.md)

## 5. 収益モデル・コスト構造

**「本体は薄利、周辺で回収」**が原則。1取引の利益の作り方は次のとおり。

| 収益源 | 粗利率の目安 | 性格 |
| --- | --- | --- |
| **商品本体の販売** | 20〜25% | 価格競争にさらされ、ネットと比較される。**指定価格品は率が固定される** |
| **リベート（販売協力金）** | — （粗利に加算） | メーカーからの販売協力金。**これが無ければ多くの量販店は赤字**とされる |
| **延長保証** | 非常に高い（実質は保険） | 5年・10年保証。修理費の支払は一部で済むため残りが利益 |
| **配送・設置工事** | 中 | エアコン工事は特に高単価。外注比率が高いが手数料が残る |
| **リサイクル回収** | 低〜中 | 法定料金＋収集運搬料 |
| **通信回線・キャリア契約** | 高（手数料収入） | スマホ・光回線・電気。契約1件あたりの手数料。**規制の影響を直接受ける** |
| **クレジット・保険・金融** | 高 | 分割手数料、カード。ヤマダは金融セグメントを持つ |
| **リフォーム・住宅** | 中 | ヤマダの住建セグメントが代表 |

コスト側：

```
【家電量販店の損益のかたち（売上100とした概算モデル）】

  売上高                         100
   └ 売上原価                    -72   ← 仕入。ここからリベートが控除される
  ────────────────────
  売上総利益（粗利）              28    ★25〜30%が業界の相場
   ├ 人件費                       -9〜11   販売員・配送・設置
   ├ 地代家賃                     -4〜7    都市型は高い／郊外型は自社所有も多い
   ├ 販促費・広告・チラシ          -3〜4
   ├ 物流費（配送・設置）          -2〜4    ★ドライバー不足で上昇中
   ├ 減価償却・水道光熱            -2〜3
   └ その他                       -2〜3
  ────────────────────
  営業利益                        1〜6    ★1桁%。ヤマダ1.0%、ノジマ5.9%（2026年3月期）

  → 粗利が1ポイント動くと営業利益が数十%動く。
    だから「リベート交渉」と「延長保証の付帯率」が経営そのものになる。
```

**固定費型のビジネス**であることが重要。店舗の家賃と人件費はほぼ動かないので、
**売上が数%落ちるだけで営業利益が吹き飛ぶ**。2026年3月期のヤマダのデンキ事業
（売上+1.3%なのに営業利益-91.7%）がその典型で、在庫処分とポイント原資の増加が直撃した。

→ 詳しくは [① 量販店の経済](01_量販店の経済.md)

## 6. 競争要因（KSF）と参入障壁

| 要因 | 効き方 | 誰に有利か |
| --- | --- | --- |
| **仕入規模（バイイングパワー）** | 台数が多いほど仕入値とリベートが有利。**規模が直接、粗利率になる** | ヤマダ、統合後のヤマダ＋エディオン |
| **配送・設置工事網** | 冷蔵庫・エアコンは「運んで据え付ける」までが商品。**ECが最も真似しにくい** | 全量販店（ECに対する堀） |
| **物流と在庫の即応性** | 「今日欲しい」に応えられるか。**ヨドバシの即日配送はここを極めた** | ヨドバシ、Amazon |
| **立地・商圏** | 郊外は商圏の独占、都市はターミナルの一等地。**後から取れない** | 既存事業者すべて |
| **延長保証の運用力** | 付帯率と支払率の管理。実質は保険の引受 | 規模の大きい社 |
| **通信・リフォーム等の周辺販売** | 家電以外で客単価を上げられるか | ヤマダ（住宅）、ノジマ（通信） |
| **ブランドとポイント経済圏** | 囲い込み。ただしポイントは**原資が自社負担** | ビック、ヨドバシ |

**参入障壁**：新規の全国チェーンはもう作れない。
理由は①メーカーとの取引条件（リベート）が規模に比例するため後発が構造的に不利、
②配送・工事網の構築に時間がかかる、③一等地が空いていない、の3つ。
**ただしECからの参入は障壁が低い**——Amazonは店舗も工事網も持たずに43%のEC化率の一角を取った。

## 7. 規制・法制度

| 制度 | 中身 | 効き方 |
| --- | --- | --- |
| **独占禁止法（優越的地位の濫用）** | 大規模小売業者が納入業者に不当な負担（従業員派遣、協賛金、返品）を強いることを禁じる | **エディオンは2012年に課徴金40億4,796万円の納付命令**（従業員無償派遣、2019年10月審決で確定）。リベート要求の線引きはこの法律で決まる |
| **大規模小売業告示** | 上記を具体化した告示。不当な返品・減額・協賛金要求などを列挙 | 仕入条件交渉の実務上の上限 |
| **独占禁止法（再販売価格の拘束）** | メーカーが小売価格を拘束することは原則違法。**ただしメーカーが在庫リスクを負う場合は該当しない** | **指定価格制度の根拠**。2026年5月に公取委が流通・取引慣行ガイドライン改正案を公表 → [白物家電②](../../03_電機・電子部品/09_白物家電/02_儲け方と流通.md) |
| **景品表示法／家電公取協ルール** | 二重価格表示、有利誤認の規制 | 「メーカー希望小売価格の○%引き」表示ができない理由 |
| **電気通信事業法 第27条の3** | 通信契約に紐づく端末値引きの上限規制。販売代理店の届出制度 | **スマホの「1円販売」を封じた規制**。量販店の携帯販売手数料と客足に直撃 |
| **家電リサイクル法** | エアコン・テレビ・冷蔵庫（冷凍庫）・洗濯機（衣類乾燥機）の4品目。**小売業者に引取義務** | 量販店はコストと同時に、買い替え接点を得る |
| **消費税の免税制度** | 訪日外国人向け免税販売 | 都市型店舗の収益に直結。**2026年11月に「リファンド方式」への移行が予定される** |
| **収益認識に関する会計基準（企業会計基準第29号）** | 2021年4月1日以後開始年度から原則適用。**ポイントは別個の履行義務**として契約負債に計上 | **ポイント付与分が売上から控除される**。実質値引きであることが会計上も明示された → [①](01_量販店の経済.md) |
| **大規模小売店舗立地法** | 大型店の出店時に騒音・交通・駐車場を届出・調整 | 郊外大型店の出店スピードを規定 |

## 9. 用語メモ

各ノート末尾に詳しい用語メモがある。最小限の押さえどころは次の5つ。

| 用語 | 意味 |
| --- | --- |
| **リベート（販売協力金・販売奨励金）** | メーカーが量販店に支払う販売協力の対価。伝票上の仕入価格とは別に支払われ、**量販店の粗利を実質的に決める**。過度な要求は優越的地位の濫用になりうる → [①](01_量販店の経済.md) |
| **指定価格制度** | メーカーが小売価格を指定し、売れ残りの返品を受けて在庫リスクを負う売り方。量販店は値引きできず、粗利率は固定される → [③](03_売る商品の変化.md)／[白物家電②](../../03_電機・電子部品/09_白物家電/02_儲け方と流通.md) |
| **延長保証** | メーカー保証（通常1年）の後を小売が有償・無償で引き受ける商品。実質は保険で、**量販店の高収益源** → [①](01_量販店の経済.md) |
| **EC化率** | 商取引全体に占めるEC（電子商取引）の割合。**家電は43.03%（2024年、経産省）**で物販中トップクラス → [②](02_業界再編と各社の違い.md) |
| **ショールーミング** | 店舗で実物を見て、購入はより安いECで行う消費行動。量販店が最も恐れた行動 → [②](02_業界再編と各社の違い.md) |
