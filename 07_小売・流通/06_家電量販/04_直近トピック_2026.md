# 直近トピック（2026年9月時点）

報道と統計をもとにした整理。**確定した事実と、報道ベース・推計・会社計画を区別して書く**。
数値は発表時点のものなので、最新は経産省 商業動態統計と各社IRで必ず確認すること。

> **2026年の家電量販を一言でいうと**：
> **「特需で数字は良いが、業界の形そのものが作り替えられている年」**。
> エアコン駆け込みで売上は跳ねた。しかし同じ年に、業界1位と5位が統合を決め、
> 2位がメーカーを買い、メーカー側は指定価格制度で値決め権を取り返しにきた。
> **数字の良さは一過性で、構造変化は不可逆**という読み方が要る。

## 1. ヤマダHDとエディオンが経営統合に基本合意（2026年6月5日）

業界最大手の**ヤマダホールディングス**と、業界4〜5位の**エディオン**が、
**持株会社方式による経営統合**に向けた基本合意書を締結したと発表した。

| 項目 | 内容 |
| --- | --- |
| 発表日 | **2026年6月5日**（基本合意書の締結） |
| 方式 | **株式移転による持株会社方式**（共同持株会社の下に両社が入る） |
| スケジュール | 2027年5〜6月に最終契約 → 2027年6月に両社株主総会 → **2027年10月1日**に効力発生・統合会社の上場 |
| 経営体制 | 代表取締役会長：**山田昇**氏（ヤマダHD会長兼CEO）／代表取締役社長：**久保允誉**氏（エディオン会長執行役員CEO） |
| 規模 | 2026年3月期実績の単純合算で**売上高 約2.5兆円**（ヤマダ1兆6,918億円＋エディオン7,937億円） |
| ブランド | 当面は「ヤマダデンキ」「エディオン」を**併用**する方針 |
| 検討事項 | **全国配送網の共通化、PB（プライベートブランド）開発の強化**など |

```
【この統合の狙いと壁】

  狙い（＝規模がそのまま粗利になる業界だから）
   ┌────────────────────────────────┐
   │ 仕入規模2.5兆円 ──▶ メーカーへの交渉力／リベート条件の改善    │
   │ 配送・工事網の統合 ─▶ 重複する物流拠点・配送便の削減          │
   │ PBの共同開発 ─────▶ リベートに依存しない自前の粗利を作る     │
   │ システム・本部機能の統合 ▶ 販管費の削減                       │
   └────────────────────────────────┘

  壁①：独占禁止法（企業結合審査）
   ヤマダとエディオンは**西日本で店舗網が重なる**とされ、
   地域によっては極端にシェアが高くなる。公正取引委員会の審査が焦点になる。
   ▼先例：2012年のヤマダによるベスト電器買収では、
     公取委が一部店舗の第三者への譲渡を承認の条件とした（報道ベース）
   → 今回はそれを大きく上回る規模のため、**店舗譲渡や再編を求められる可能性**がある

  壁②：文化とブランドの統合
   ヤマダ（郊外型・価格）とエディオン（地域密着・アフター重視）は売り方が違う。
   「当面は両ブランド併用」という発表自体が、統合の難しさを示している。

  壁③：そもそも家電市場は伸びない
   規模を大きくしても、市場が縮めば1店舗あたりの売上は増えない。
   「統合＝成長」ではなく「統合＝コスト削減と延命」である点を見誤らない。
```

> **消費者から見た論点**：同一商圏でヤマダとエディオンが同じグループになれば、
> **「他店の価格を見せて値引きさせる」という交渉が成立しにくくなる**地域が出る。
> これは公取委が最も注視する種類の影響であり、
> メーカーの[指定価格制度](03_売る商品の変化.md)の広がりと合わせると、
> **家電の価格競争そのものが細っていく**方向にある。

## 2. ノジマが日立の家電事業を約1,100億円で買収（2026年4月）

**2026年4月21日**、日立製作所・日立グローバルライフソリューションズ（日立GLS）とノジマは、
**日立の家電事業を新会社に分離し、その株式80.1%をノジマへ譲渡する契約**を締結した。

| 項目 | 内容 |
| --- | --- |
| 契約日 | **2026年4月21日** |
| 対象 | 日立GLSの**国内家電事業**（冷蔵庫・洗濯機・掃除機等）。**空調は日立GLSに残る** |
| 規模 | 日立GLSの2025年3月期の売上高は**3,676億円** |
| スキーム | 新会社を設立し株式**80.1%**をノジマへ譲渡。**19.9%は日立GLSが保有** |
| 金額 | **約1,100億円** |
| 完了予定 | 2027年3月期中（各国の競争法クリアランス等を経て）。野島廣司社長は**2026年9月にも新会社発足**を目指す考えを示したと報じられる |
| 買収の決め手 | 野島社長は**「日本国内の工場」**を挙げ、**「製販バラバラでは衰退」**と述べたと報じられる |

```
【「量販店がメーカーを持つ」とはどういうことか】

   従来の家電の力関係
     メーカー ──供給──▶ 量販店 ──▶ 消費者
                 ▲ 値引き要求・リベート要求
                 └ 量販店の方が強かった（値決めの主導権）

   ノジマの形（2026年〜）
     ノジマ
       ├── 小売（店舗・EC）
       ├── キャリアショップ運営・ニフティ（ISP）
       └── ★メーカー（日立ブランドの家電・国内工場）
                 │
                 └─▶ 企画 → 製造 → 販売 → 配送 → 設置 → 保証 を一気通貫
                      ＝ SPA（製造小売）に近い形

   狙い：中間マージンの取り込み／自社企画品を確実に棚へ／国内生産という訴求
   課題：①製造・開発の固定費を小売の体力で背負えるか
         ②他チェーンが「競合傘下のブランド」を売りにくくなる
         ③日立ブランドの価値をノジマが維持できるか
```

> **文脈**：日立にとって家電は「最後の非中核事業」だった。
> 一方ノジマにとっては、**メーカーが指定価格制度で値決め権を取り返しにくる流れへの答え**でもある。
> 「値段を決められるのが嫌なら、自分がメーカーになればよい」という解である。

## 4. ヤマダのデンキ事業が失速 ——在庫処分とポイントの重さ

業界最大手の2026年3月期は、**特需の年にもかかわらず営業利益が6割減**という結果になった。

| 区分 | 売上高 | 営業利益 |
| --- | --- | --- |
| 全社 | 1兆6,918億800万円（**+3.9%**） | **161億6,600万円（-62.2%）** |
| デンキ | 1兆3,294億2,600万円（+1.3%） | **24億9,200万円（-91.7%）** |
| 住建 | 3,338億6,600万円（+12.3%） | 102億5,400万円（+9.4%） |
| （2027年3月期 会社計画） | 1兆7,800億円（+5.2%） | 515億円（+218.6%） |

主因は**約240億円規模の戦略的な在庫処分**と、**ポイント施策に伴う先行的な利益負担**とされる。

> **読みどころは2つ**。
> ① **ポイントは原資が自社負担**であり、会計上も売上から繰り延べられる（契約負債）。
> 　「ポイント還元」は集客策であると同時に**確実に利益を削る費用**である → [① 量販店の経済](01_量販店の経済.md)
> ② **売上の8割を占めるデンキの営業利益が、売上2割の住建より少ない**。
> 　一時的要因を割り引いても、**家電販売だけでは利益が出にくい**構造が露出した
> 　→ [② 業界再編と各社の違い](02_業界再編と各社の違い.md)

## 5. ビックカメラが初の売上1兆円へ ——インバウンドと都心回帰

都市型の代表であるビックカメラは、2025年8月期に売上9,744億円（+5.6%）、
営業利益302億円（+24.1%）といずれも過去最高を更新した。
**2026年8月期は売上高1兆220億円（+5%）、営業利益344億円（+14%）、純利益184億円（+5%）**の
見通しを示しており（2026年4月時点の会社予想）、実現すれば**初の売上1兆円**となる。

牽引役は、

- **インバウンドの免税売上**（2026年8月期第1四半期に過去最高を記録と発表）
- **エアコン・スマホ・理美容家電**の好調
- 既存店のリニューアルと新業態店舗

一方、**2026年11月1日から免税制度が「リファンド方式」に変わる**点は要注意。
店頭では税込で販売し、出国時の税関確認を経て**後から消費税相当額を返金する**方式になる。
不正防止と、一般物品／消耗品の区分廃止などの簡素化が狙いだが、
**「その場で安くなる」体験が失われる**ため、都市型店舗の免税売上への影響は現時点では読み切れない。

## 6. 指定価格制度の拡大と、公取委のガイドライン改正案

メーカーが小売価格を決める**指定価格制度**が、2026年に大手3社体制になった。

| メーカー | 開始 | 範囲（報道ベース） |
| --- | --- | --- |
| パナソニック | 2020年度試行 → 2022年度拡大 | 国内白物家電の**約3割** |
| 日立（日立GLS） | 2023年9月 | 全製品の約1割から |
| **三菱電機** | **2026年1月8日発表**（1月23日発売の新型冷蔵庫から） | まず冷蔵庫の上位機種 |

さらに**2026年5月13日、公正取引委員会は「流通・取引慣行に関する独占禁止法上の指針」の改正案**を
公表し、意見募集を行った（同年6月11日まで）。
趣旨は**再販売価格維持行為が通常は違法とならない場合の考え方と具体例を追加する**ことで、
指定価格型の取引が「例外的な工夫」から「制度として整理される段階」に入ったと読める。

> **量販店側の受け止め**：
> 得＝粗利率が安定し、在庫リスク・型落ちリスクが消え、ECと同じ値段になるので店舗の強み（工事・保証・即日）が効く。
> 損＝**「安さで客を呼ぶ」という30年の武器が使えなくなる**。粗利の絶対額は薄いままで、売る動機も弱まる。
> → [③ 売る商品の変化](03_売る商品の変化.md)、
> 　[白物家電：儲け方と流通](../../03_電機・電子部品/09_白物家電/02_儲け方と流通.md)

## 7. 全体の構図（まとめ）

1. **2026年の好決算は外部要因で説明できる**。エアコン2027年問題の駆け込み、猛暑、
   Windows10サポート終了後のPC単価上昇、インバウンド免税。**実力ではない**
2. **同じ年に、業界の形が両方向から作り替えられた**。
   横（ヤマダ×エディオン＝仕入規模2.5兆円）と縦（ノジマ×日立家電＝製販一体）
3. **値決め権がメーカー側へ戻りつつある**。指定価格が大手3社に広がり、公取委も整理に動いた。
   量販店の競争軸は「安さ」から「工事・保証・配送・相談」へ移らざるを得ない
4. **家電だけでは利益が出ない**ことが、業界1位の決算に露出した（デンキの営業利益率0.2%）。
   だから各社は住宅・通信・日用品・リユースへ広がる
5. **最大の不確実性は2027年度**。省エネ基準強化による反動減、補助金の終了、
   ヤマダ×エディオンの独禁法審査の結論、ノジマの製販一体が機能するか——すべて2027年に答えが出る

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **持株会社方式の経営統合（株式移転）** | 両社が新設する共同持株会社の傘下に入る方式。既存の法人とブランドを残したまま統合できる。ヤマダHD×エディオンが採る形 |
| **企業結合審査** | 合併・買収が競争を実質的に制限しないかを公正取引委員会が審査する手続き。問題がある場合は店舗譲渡などの措置を条件に承認されることがある |
| **商業動態統計（家電大型専門店）** | 経済産業省の統計。売場面積500m²以上で家電を主に販売する事業所の販売額。**店頭販売ベース**で、メーカー出荷ベースのJEMA統計とは別 |
| **エアコン2027年問題** | 2027年4月の省エネ基準強化と冷媒規制が重なり、安価なモデルが減る／値上がりするとされる問題 |
| **指定価格制度** | メーカーが小売価格を指定し、売れ残りの返品を受けて在庫リスクを負う売り方。量販店は値引きできない |
| **流通・取引慣行ガイドライン** | 公正取引委員会が示す流通・取引慣行に関する独占禁止法上の考え方。2026年5月13日に改正案が意見募集にかけられた |
| **リファンド方式** | **2026年11月1日施行**の新しい免税制度。店頭では税込で販売し、出国時の税関確認後に消費税相当額を返金する。一般物品と消耗品の区分は廃止される |
| **契約負債（ポイント）** | 付与したポイントに対応する、まだ果たしていない義務。収益認識基準のもとで売上から繰り延べられる |
| **製販一体（SPA）** | 企画・製造から販売までを一貫して手がける形。ノジマの日立家電買収がこれに近い |
