# 業界再編と各社の違い ——同じ「家電量販店」が、まったく違う商売をしている

このノートで分かること：ヤマダ・ビックカメラ・ヨドバシ・ケーズ・エディオン・ノジマ・上新が、
**なぜこれほど利益率が違うのか**。そして2026年に起きた**ヤマダ×エディオンの統合合意**と
**ノジマの日立家電買収**が、業界の何を変えようとしているのか。

> **結論を先に**：家電量販店の差は「どこに店があるか」でほぼ決まる。
> **郊外型**（ヤマダ・ケーズ・エディオン・ノジマ）は広い面積で大型家電と工事を売り、
> **都市型**（ヨドバシ・ビックカメラ）は狭い一等地で小型・高回転の商品と免税を売る。
> この2つは**客も商品も原価構造も別物**である。
> そして各社は「家電だけでは伸びない」と分かったあと、**別々の方向に逃げた**——
> ヤマダは住宅、ノジマは通信とM&A、ビックは免税と都心集客、ヨドバシはEC、
> ケーズは何もせずコストを絞る。**この選択の差が、そのまま利益率の差になっている**。

## 1. 再編の歴史 ——なぜ7社に絞られたか

家電量販は**1990年代から2010年代にかけて、ひたすら統合が続いた業界**である。
理由は単純で、**仕入規模が大きいほどリベートと仕入条件が有利になる**から（→ [① 量販店の経済](01_量販店の経済.md)）。
規模が利益率を作るなら、勝ち方は「買って大きくなる」しかない。

| 時期 | 出来事 | 意味 |
| --- | --- | --- |
| 1990年代 | ロードサイド型の全国チェーンが台頭。地域の電器店・地場チェーンが淘汰される | 価格競争の始まり |
| 2000年代 | ベスト電器、さくらや、石丸電気など老舗が苦境。**ヤマダが日本一へ** | 規模の経済が決定的に |
| 2010年代前半 | **ビックカメラがコジマを子会社化**（2012年）、**ヤマダがベスト電器を子会社化**（2012年） | 上位への集約 |
| 2010年代 | エディオン（デオデオ＋エイデン＋ミドリ＋石丸）が西日本で統合完了 | 地域連合の完成 |
| 2010年代後半 | **ヤマダが大塚家具を傘下に**（2019年）、住宅事業へ本格進出 | **家電以外への多角化**の始まり |
| 2020年代 | ノジマがニフティ・スルガ銀行等へ出資・買収。**業種を超えたM&A** | 家電量販が「投資会社」的に |
| **2026年4月** | **ノジマが日立の家電事業を約1,100億円で買収すると発表** | **小売がメーカーを持つ（製販一体）** |
| **2026年6月** | **ヤマダHDとエディオンが経営統合に基本合意**（合算売上約2.5兆円） | **最後の大型統合**とみられる |

```
【業界再編の「2つの方向」──2026年に両方が同時に起きた】

   ① 横の統合（同業を束ねて仕入規模を最大化）
        ヤマダHD ────┐
                      ├──▶ 持株会社（2027年10月予定）売上約2.5兆円
        エディオン ───┘
        狙い：仕入条件、PB開発、全国配送網の共通化
        懸念：店舗が重なる地域の整理、公正取引委員会の審査

   ② 縦の統合（川上のメーカーを取り込む＝製販一体）
        ノジマ（小売）
          └──▶ 日立の家電事業（新会社の80.1%）※日立GLSが19.9%保有
        狙い：中間マージンの取り込み、自社企画商品、国内工場の確保
        懸念：製造・開発の固定費を小売が背負う／他チェーンが扱いにくくなる

   → ①は「安く仕入れる力」を、②は「そもそも自分で作る」を選んだ。
     同じ業界の1位と2位が、まったく違う解を出したのが2026年である。
```

## 2. 郊外型と都市型 ——経済構造がまったく違う

| 項目 | **郊外型**（ヤマダ・ケーズ・エディオン・ノジマ） | **都市型**（ヨドバシ・ビックカメラ） |
| --- | --- | --- |
| 立地 | 幹線道路沿い・大型駐車場 | 駅前・ターミナル直結 |
| 1店舗の面積 | 広い（数百〜数千坪） | 広いが賃料が高い |
| 主力商品 | **冷蔵庫・洗濯機・エアコン・テレビ**（大型・設置が要る） | **PC・スマホ・カメラ・オーディオ・時計・小物** |
| 客 | 家族連れ、住宅購入・買い替え層、高齢層 | 通勤客、単身者、**訪日外国人** |
| 客の来店理由 | 「実物を見て、運んで据え付けてほしい」 | 「今すぐ欲しい」「品揃えを見たい」「免税で買いたい」 |
| 坪効率 | 低い（面積で稼ぐ） | **非常に高い** |
| 家賃負担 | 低い（土地を自社所有するケースも） | 高い |
| 人件費 | 配送・設置の人員が重い | 販売員・多言語対応が重い |
| 利益の出どころ | 工事・保証・リフォーム | 回転の速さ・免税・ポイント経済圏 |
| 弱点 | **人口減と車離れ**。商圏が痩せる | **インバウンドと為替に左右される** |

> **なぜ分かれるのか**：冷蔵庫は電車で持ち帰れない。カメラは駐車場が要らない。
> **「商品を持ち帰れるかどうか」が、立地と業態を決めている**。
> 大型家電は配送・設置というオペレーションを伴うため郊外型が強く、
> 小型高額品は回転と集客が効く都市型が強い。この分業は今も崩れていない。

### 3-1. ヤマダ ——「家電の外」で稼ぐ会社になった

ヤマダHDは**デンキ（家電）／住建（住宅・リフォーム・住設）／金融／環境（リユース）** の
セグメントを持つ。2026年3月期の実績を見ると、その意味がはっきり出る。

```
【ヤマダHD 2026年3月期のセグメント（実績）】

  デンキ   売上 1兆3,294億円（+1.3%） ── 営業利益   24.9億円（-91.7%） 利益率 0.2%
  住建     売上  3,338億円（+12.3%） ── 営業利益  102.5億円（ +9.4%） 利益率 3.1%
            ├ ヒノキヤグループ  1,772億円／81.6億円
            ├ ヤマダホームズ     938億円／ 5.9億円
            └ ハウステック       648億円／28.9億円
  ────────────────────────────────────
  全社     売上 1兆6,918億円（+3.9%） ── 営業利益  161.7億円（-62.2%）

  ★読み方：売上の8割を占めるデンキの営業利益が、売上2割の住建より少ない。
    約240億円規模の在庫処分とポイント施策が響いたとされる一時的な要因もあるが、
    「家電を売るだけでは利益が出ない」という構造がそのまま現れている。
    2027年3月期は売上1兆7,800億円・営業利益515億円を会社計画として掲げる。
```

**「暮らしまるごと」戦略**とは、家電・家具（大塚家具）・住宅（ヤマダホームズ、ヒノキヤ）・
住設（ハウステック）・リフォーム・金融を一つの店で提供する構想である。
論理は明快で、**家電の客単価は数万円だが、リフォームは数百万円、住宅は数千万円**だから、
同じ来店客から取れる金額の桁が違う。ただし**住宅は在庫も工期も人材も家電と別物**であり、
多角化の管理コストは小さくない。

### 3-2. ヨドバシ ——ECで自ら最強になった唯一の量販店

**ヨドバシカメラは非上場**で、詳細な決算は公表されない。
それでも業界で特別視されるのは、次の3点による。

| 特異点 | 内容 |
| --- | --- |
| **店舗効率** | 店舗数は**約24店**にすぎないのに売上は**8,654億円（2025年度、前年比+6.0%）**。1店舗あたり約360億円 |
| **EC比率** | **ヨドバシ.com**が自社売上の相当部分（報道ベースで3割前後とされる）を占める。**国内EC売上でAmazon・楽天に次ぐ規模**と評されることが多い |
| **送料無料・即日配送** | **全国どこでも1点から送料無料**、都市部では当日配送。**Amazonが有料会員（プライム）で実現していることを、会員制なしでやっている** |

```
【なぜヨドバシのECは「異質」なのか】

  一般的な量販店のEC             ヨドバシ.com
  ┌────────────┐      ┌──────────────────┐
  │ 店舗が主、ECは補完    │      │ EC・店舗・倉庫を一体で運用       │
  │ 店舗在庫とEC在庫が別  │      │ 在庫を一元管理（店の在庫も引当）  │
  │ 送料は条件付き無料    │      │ ★1点・少額でも送料無料           │
  │ 配送は外部委託        │      │ 自社配送を厚く持つ（都市部）      │
  │ 品揃えは家電中心      │      │ 日用品・書籍・食品まで超広品揃え  │
  └────────────┘      └──────────────────┘
            │                                  │
            ▼                                  ▼
      Amazonに客を取られる            ★Amazonの代替になれている

  成立している理由（推定される要素）
   ・非上場で短期の利益を求められない → 送料無料という先行投資を続けられる
   ・店舗数が少なく一等地に集中 → 在庫を集約しやすく、物流の設計が単純
   ・高単価商品が多い → 1件あたりの配送コストを吸収できる
  ※非上場のため物流コストの実額は公表されておらず、以上は構造からの推定を含む。
```

> **業界への含意**：家電のEC化率は**43.03%（2024年、経産省）**で、物販の中でも突出して高い。
> 普通ならECの台頭は量販店の脅威だが、**ヨドバシは自分がECになることで脅威を回避した**。
> 他社が「店舗を守りながらECも」と二兎を追ったのに対し、構造ごと作り替えた点が違う。
> → [EC・ネット通販](../../04_情報通信・IT・ネット/08_EC・ネット通販/README.md)

### 3-3. ケーズ ——「やらないこと」で利益率を作る

ケーズデンキは業界の常識をいくつも外している。

- **ポイントを付けない**（その場の現金値引き）→ 会計上の契約負債を抱えない、価格が分かりやすい
- **長期保証を原則無料で付ける** → 保証を収益源でなく集客装置にする
- **過剰な出店をしない／販売ノルマを課さない**（「がんばらない経営」）→ 販管費が膨らまない

結果として、**売上規模は6位前後でも営業利益率は3.5%（2026年3月期）**と上位に入る。
**規模を追わずに率を取る**という、この業界では珍しい立ち位置である。

### 3-4. ノジマ ——家電量販の皮をかぶった事業投資会社

ノジマの2026年3月期は**売上9,828億円（+15.2%）、営業利益580億円（+20.1%）、利益率5.9%**。
家電量販としては突出した利益率だが、その源泉は家電販売そのものではない。

- **携帯キャリアショップの運営**（ドコモショップ等の受託運営）——手数料収入で粗利率が高い
- **ニフティ（ISP）**——通信サービスの継続課金
- **海外事業・投資**

そのうえで**日立の家電事業を約1,100億円で買収**（2026年4月21日契約）。
日立GLSの国内家電事業（2025年3月期の売上3,676億円規模）を新会社化し、その**80.1%を取得**、
日立GLSが19.9%を保有する形で、野島廣司社長は**国内工場を持つこと**を決め手として挙げたと報じられる。

> **「製販一体」の賭け**：小売がメーカーを持てば中間マージンを取り込め、
> 自社企画商品を確実に棚に置ける。一方で、**製造と開発の固定費は小売の体力では重い**。
> また**他の量販店が「ノジマ傘下のブランド」を売りにくくなる**という副作用もある。
> → [白物家電：直近トピック](../../03_電機・電子部品/09_白物家電/04_直近トピック_2026.md)

## 4. Amazon・楽天との競合 ——負けた領域と勝っている領域

```
【家電を買うとき、客は何で店を選ぶか】

                          EC（Amazon・楽天）   量販店の店舗   ヨドバシ.com
  価格の安さ                    ◎                 △             ○
  すぐ届く／持ち帰れる          ○（プライム）      ◎             ◎
  品揃えの広さ                  ◎                 ○             ◎
  実物を見て比べる              ✕                 ◎             ✕
  設置工事（エアコン等）        △                 ◎             ○
  大型品の搬入・階段上げ        △                 ◎             ○
  旧機の引き取り                △                 ◎             ○
  長期保証・修理の窓口          △                 ◎             ○
  使い方の相談・設定代行        ✕                 ◎             △

  ★量販店が勝ち続けている領域は「工事・搬入・下取り・相談」に集中する。
    これは人と車と技能がいる仕事で、ECが後から積み上げるのが最も難しい。
    逆に言えば、ここを失えば量販店の存在理由はなくなる。
```

**ショールーミング**（店で見てネットで買う）への各社の答え：

| 対策 | 内容 | 評価 |
| --- | --- | --- |
| 自社ECの強化 | ヨドバシ.com、ビックカメラ.com、ヤマダウェブコム | ヨドバシ以外は「店舗の補完」の域を出にくい |
| 店頭での他店対抗 | ネット価格を提示されたら合わせる | 粗利が消える。原資はリベート |
| 販路限定モデル | 比較できない型番を作る | 効くが、消費者の不信も招く |
| 当日配送・店頭受取 | ECで注文して店で受け取る | 送料を削れ、来店のきっかけにもなる |
| **工事・保証の付加** | 本体で勝てなくても「据え付けまで」で選ばれる | **最も本質的な差別化** |

## 5. 法人向け・その他の販路

見落とされやすいが、量販各社は**法人販売**を持つ。
企業のPC・複合機・オフィス家電・厨房機器、学校のICT機器、
自治体の防災備品、ホテル・賃貸物件への一括納入などである。

- **個人向けより価格競争が穏やか**で、保守・設置・リースとセットにできる
- ただし**与信と納期管理**が必要で、小売のオペレーションとは別の能力が要る
- ヤマダは住宅・リフォームからの流れで工務店向けが強く、
  ビック・ヨドバシは都心企業向け、ノジマはキャリア代理店経由の法人回線が絡む

## 6. まとめ

1. **差は立地で決まる**。郊外型は大型品と工事、都市型は回転と免税。原価構造が別物
2. **家電だけでは伸びないと全社が気づいた**。逃げ先が各社バラバラ——
   ヤマダは住宅、ノジマは通信とM&A、ビックは免税、ヨドバシはEC、ケーズはコスト
3. **2026年に再編の2形態が同時に起きた**。
   ヤマダ×エディオンの**横の統合**（仕入規模）と、ノジマ×日立家電の**縦の統合**（製販一体）
4. **ECに勝てる領域は工事・搬入・下取り・相談**に絞られている。
   ヨドバシだけは「自分がECになる」という別解を出し、送料無料と即日配送で成立させた

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **郊外型（ロードサイド型）** | 幹線道路沿いに大型駐車場を備えて出店する業態。大型家電と設置工事が主力 |
| **都市型（駅前型）** | ターミナル駅前の一等地に出店する業態。小型高額品・免税・高回転が主力 |
| **坪効率** | 売場1坪あたりの売上高。都市型が高く、郊外型は面積で稼ぐ |
| **ショールーミング** | 店舗で実物を確認し、購入はより安いECで行う消費行動 |
| **ウェブルーミング** | 逆にネットで調べてから店舗で買う行動。工事や即日入手が必要な商品で起きる |
| **製販一体（SPA的統合）** | 小売が企画・製造まで持つ形。ノジマの日立家電買収がこれに近い |
| **持株会社方式の経営統合** | 共同で持株会社を作り、両社がその傘下に入る方式。ブランドや組織を残したまま統合できる。ヤマダHD×エディオンが採る形 |
| **キャリアショップ運営（代理店）** | 通信事業者から委託を受けて携帯ショップを運営する事業。手数料収入型で粗利率が高い → [③](03_売る商品の変化.md) |
| **免税（輸出物品販売場制度）** | 訪日外国人向けの消費税免除。都市型店舗の収益に直結。**2026年11月1日から「リファンド方式」（出国確認後に返金）へ移行** |
| **EC化率** | 商取引全体に占めるECの割合。家電は43.03%（2024年、経産省）で物販中トップクラス |
