# 量販店の経済 ——「本体で儲けない店」はどう成り立っているか

このノートで分かること：家電量販店が**1台の家電を売って実際にいくら儲けているのか**。
そして、なぜ「本体の値段」だけを見ていると経営が理解できないのか。
鍵になるのは**リベート（メーカーからの販売協力金）**、**ポイント**、**延長保証・工事・配送**、
そして**在庫回転と型落ちリスク**の4つである。

> **結論を先に**：家電量販店の粗利率は**25〜30%程度**しかない。
> 家電は型番が同じなら物理的に同じ商品なので、価格.comで最安値が秒で分かる。
> **商品そのもので差を付けられない業界**では、粗利は構造的に薄くなる。
> その薄い粗利を成立させているのが**リベート**で、**リベートが減れば利益はすぐ消える**。
> そのうえで、**ポイント・延長保証・工事・通信契約**という4つの「本体以外」で回収する。
> **家電量販店は、家電を売る会社というより「家電を入口にした総合サービス業」**である。

---

## 1. まず、1台の家電の儲けを分解する

店頭25万円のドラム式洗濯乾燥機を例に、量販店の側から見た金額の流れをつかむ。
※業界の一般的な水準感にもとづく**概算モデル**で、企業・商品・時期により大きく変わる。

```
【店頭25万円の洗濯乾燥機 ── 量販店の取り分（概算モデル）】

  店頭価格                          250,000円
   ├ 消費税（10%）                   -22,727円   → 預かり金。利益ではない
   ├ 付与ポイント（10%＝22,700円分）  -22,700円   ★実質値引き。会計上も売上から控除
  ─────────────────────────────────
  実質的な売上計上額                 約204,500円
   └ 仕入原価（伝票上）              -170,000円
  ─────────────────────────────────
  伝票上の粗利                       約 34,500円（率 約17%）  ← これだけでは食えない
   ＋ リベート（販売協力金）           + 10,000〜20,000円  ★★ここが生命線
  ─────────────────────────────────
  実質粗利                           約 44,500〜54,500円（率 22〜27%）

  さらに、この1人の客から取りにいくもの：
   ＋ 延長保証（5年）                 約 10,000円（うち利益は相当部分）
   ＋ 配送・設置                      約  3,000〜 8,000円
   ＋ 旧機のリサイクル回収            約  2,500〜 4,000円（法定料金＋収集運搬料）
   ＋ 洗剤・関連小物                  数百〜数千円（粗利率は本体より高い）
  ─────────────────────────────────
  この1取引から店が取れる粗利の合計   約 6万〜7万5千円

  → 本体だけなら粗利17%。周辺を積んで、ようやく25〜30%に届く。
```

> **ポイント**：ここで分かるのは、**量販店の粗利率25〜30%という数字が「本体の粗利」ではない**
> ということ。本体は20%前後、そこに**リベートと周辺サービスを積み上げて**25〜30%にしている。
> 「家電量販は粗利が薄い」と言われるのは、この構造を指している。

## 2. リベート ——「仕入値」が仕入値でない理由

### 2-1. 何者か

**リベート**＝メーカーが小売に対し、販売協力の対価として支払う金銭。
**販売奨励金、販売協力金、協賛金**などとも呼ばれ、
**伝票上の仕入価格とは別に、後から支払われる**点が特徴である。

なぜわざわざ別建てにするのか。**メーカーが「建値（表向きの仕切価格）」を崩したくない**からである。
仕入価格そのものを下げると全チェーンに波及するが、リベートなら
**「販売台数を達成した店だけ」「この機種を目立つ場所に置いた店だけ」**に個別に出せる。

| リベートの種類 | 何に対して払うか | 量販店から見た性格 |
| --- | --- | --- |
| **数量リベート** | 一定台数・一定金額を仕入れた／売ったこと | 期末に効く。**規模が大きいほど有利**＝寡占が進む理由 |
| **販売協力金・陳列協賛金** | 特定商品の売り場確保、エンド（棚の端）展開、チラシ掲載 | 「棚を売る」商売。**リテールメディアの原型** |
| **売価対応リベート（粗利補填）** | 他店に対抗して値引きしたときの穴埋め | **値引き競争の原資そのもの**。これがあるから安売りできた |
| **新製品導入リベート** | 新機種を早期に採用したこと | 型落ちリスクの補償に近い |
| **人的支援（派遣店員）** | メーカー社員を売り場に送る | 人件費の肩代わり。**優越的地位の濫用になりやすい領域** |

### 2-2. なぜ「リベートが利益を左右する」のか

```
【リベートが消えると何が起きるか（概念図）】

   ＜リベートがある世界＞
     伝票粗利 17% ─┐
                    ├─▶ 実質粗利 25〜28% ─▶ 販管費 24% ─▶ 営業利益 1〜4%
     リベート  8〜11%┘

   ＜リベートが2ポイント減った世界＞
     伝票粗利 17% ─┐
                    ├─▶ 実質粗利 23〜26% ─▶ 販管費 24% ─▶ 営業利益 ▲1〜2%
     リベート  6〜 9%┘
                                                            ★赤字に転落する

   → 粗利がたった2ポイント動くだけで黒字と赤字が入れ替わる。
     販管費（人件費・家賃）はほぼ固定なので、粗利の変動がそのまま利益の変動になる。
```

**近年リベートは減る方向にある**と指摘される。理由は3つ。

1. **メーカーの体力低下**。家電メーカーの営業利益率自体が数%しかなく、販促費を削っている
   → [白物家電：儲け方と流通](../../03_電機・電子部品/09_白物家電/02_儲け方と流通.md)
2. **指定価格制度**。メーカーが値決めを握る取引では、値引き原資としてのリベートが要らなくなる
3. **家電以外の商品の比率上昇**。日用品・食品・玩具にはリベート文化が薄い。
   量販店が家電以外に広げるほど、**「リベートに支えられない粗利」の比率が上がる**

> **見落としやすい因果**：家電量販店がこぞって日用品・酒・食品・リフォームに手を広げているのは、
> 「ついで買いを増やしたい」だけではない。**リベートに依存しない収益源を作りにいっている**
> という側面がある。 → [③ 売る商品の変化](03_売る商品の変化.md)

### 2-3. どこからが違法か

リベートは合法だが、**優越的地位の濫用**（独占禁止法）になる線がある。
実例として、**エディオンは納入業者から従業員を無償で派遣させたとして、
2012年2月に課徴金40億4,796万円の納付を命じられた**（2019年10月4日審決で確定）。

| 行為 | 独禁法上の扱い |
| --- | --- |
| 販売台数に応じた合理的なリベートの受領 | 適法 |
| 事前に条件を明示した陳列協賛金 | 原則適法 |
| **一方的な粗利補填の要求、事後の値引き要求** | **違反のおそれ（減額・不当な経済上の利益の提供要請）** |
| **費用負担なしの従業員派遣の強要** | **違反**（エディオン事件） |
| 自己都合の返品 | 違反のおそれ |

## 3. 価格.comと店頭価格 ——「最安値」が業界の物差しになった

### 3-1. 何が起きたのか

家電は**型番が同じなら完全に同じ商品**である。服のようにサイズ感も着心地も違わない。
つまり**比較コストがゼロに近い**。この性質が価格比較サイトと決定的に相性が良かった。

```
【価格.comが変えた売り場の力学】

  ＜1990年代＞
    客は「この街の3店」の値段しか知らない
     └▶ 店は商圏の中で相対的に安ければよかった
     └▶ 「他店より1円でも安く」の“他店”はご近所だった

  ＜2000年代以降＞
    客はスマホで「全国の最安値」を見ながら店員と話す
     └▶ 実店舗の“他店”が、家賃も人件費も持たないネット専業店になった
     └▶ ★店頭価格は「最安値＋α」に張り付く
         αの中身 ＝ 今日持ち帰れる／工事してくれる／保証が付く／ポイントが付く

  ＜量販店の反撃＞
    ① 他店対抗（最安値に合わせる）→ 粗利が消えるので原資はリベート
    ② ポイントで見かけの価格を作る（後述）
    ③ 型番を変える（「量販店専用モデル」）→ ★比較そのものを封じる
    ④ 自社ECを強化して、自分が最安値表示に載りにいく
```

### 3-2. 「量販店専用モデル」という回避策

同一型番だと比較されてしまうので、メーカーと量販店は**販路限定モデル**（型番末尾だけ違う、
機能を1つ足す／削る）を作る。**比較サイト上で「同じ商品」として並ばなくなる**ため、
価格競争から外れられる。消費者から見れば分かりにくいが、
**量販店が粗利を守るための最も実務的な手段**の一つである。

> **指定価格制度は、これを制度としてやったもの**とも言える。
> メーカーが値段を決めてしまえば、そもそも比較の意味がなくなる。
> 量販店にとっては「粗利が守られる」と「安さで客を呼べない」が同時に起きる。
> → [③ 売る商品の変化](03_売る商品の変化.md)

## 4. ポイント還元 ——「実質値引き」であることを会計が認めた

### 4-1. 客から見た10%ポイントと、店から見た10%ポイント

| 立場 | 10%ポイント付与の意味 |
| --- | --- |
| 客 | 「1割引と同じ」……ただし**使えるのは同じ店**。使い忘れ・失効もある |
| 店 | **将来その分だけ無料で商品を渡す約束**＝**負債**。原資は自社持ち |
| メーカー | 直接は関係ない……はずだが、**ポイント原資の一部をリベートで負担する慣行**があるとされる |

ポイントが値引きと違うのは、**客を自店に縛れる**点（再来店率が上がる）と、
**失効分は儲けになる**点である。だから量販店はポイントを好んだ。
一方で**原資は自社負担**なので、**ポイント率を上げた期は利益が減る**。

> **実例**：ヤマダHDの2026年3月期は、約240億円規模の在庫処分と**ポイント施策**の負担などにより、
> デンキセグメントの営業利益が**24億9,200万円（前年比-91.7%）**まで落ちた。
> 売上は+1.3%だったにもかかわらず、である。**ポイントは無料の集客策ではない**ことが数字に出た例。

### 4-2. 会計上の扱い（2021年度から明確になった）

**収益認識に関する会計基準（企業会計基準第29号）**が
2021年4月1日以後開始する事業年度から原則適用され、ポイントの扱いが統一された。

```
【ポイント付与時の会計処理（収益認識基準）】

  客が 100,000円の商品を買い、10,000ポイントが付いた

   従来（引当金方式）
     売上高       100,000円  ← 全額を売上に計上
     ポイント引当金  数千円   ← 使われそうな分だけ費用として引き当てる

   現行（収益認識基準）★
     ポイントは「別個の履行義務」＝将来商品を渡す約束とみなす
      ┌───────────────────────────┐
      │ 売上高      約 90,900円  ← 商品を渡した分だけ収益    │
      │ 契約負債    約  9,100円  ← ポイント分は“まだ売上でない”│
      └───────────────────────────┘
     後日、ポイントが使われた／失効した時点で 契約負債 → 売上高 へ振り替える

   → ★ポイント付与は会計上も「売上の先送り＝実質値引き」として扱われる。
     「ポイント10%還元」は、店にとって“10%引き”とほぼ同義である。
```

**ケーズデンキ（ケーズホールディングス）はポイント制度を採らず、その場の現金値引きを掲げている**。
これは「後で使わせる複雑さを持たない」という戦略であり、
会計上も負債を抱えない分、経営が読みやすい。**「がんばらない経営」**と呼ばれる同社の方針と整合する。

## 5. 周辺収益 ——延長保証・工事・配送・リサイクル

本体の粗利が薄い以上、ここが利益の実質的な出どころになる。

| 収益 | 客が払う額の目安 | 店にとっての性格 |
| --- | --- | --- |
| **延長保証（5年・10年）** | 本体価格の5%前後（有料の場合） | **実質は保険商品**。集めた保証料に対し実際に発生する修理費は一部。差額が利益 |
| **配送・設置** | 数千円〜1万円台 | 自社便＋協力会社。**ドライバー不足で原価が上昇中**。無料化すると利益を直接削る |
| **エアコン標準工事** | 1.5万〜3万円（追加工事は別） | **高粗利かつECが最も真似しにくい領域**。繁忙期は工事枠が販売台数の上限になる |
| **家電リサイクル回収** | リサイクル料金＋収集運搬料（合計数千円） | 法律上の引取義務。**同時に買い替え接点を握る** |
| **通信回線・電気・保険** | 契約時0円が多い | **手数料はキャリア・事業者から入る**。粗利率という概念がない純収入 |
| **設定・データ移行サービス** | 数千円〜 | PC・スマホの高齢者需要。人件費だけで作れる粗利 |

```
【「保証」が高収益である理由 ── 保険の論理】

  1,000人が 5年延長保証を 10,000円 で購入   →  保証料収入 10,000,000円
                     │
                     ├─ 5年以内に故障する人  … 仮に 8%（80人）
                     ├─ 1件あたり修理費     … 仮に 25,000円
                     └─ 支払総額            … 2,000,000円
  ──────────────────────────────────
   差額 8,000,000円 が店に残る（事務コストを除く）

  ★ただし前提が崩れると一気に逆転する：
    ・製品の故障率が上がる（品質低下）
    ・修理費が上がる（部品高騰・人件費上昇）
    ・保証期間中に修理部品が無くなり、新品交換になる
  → だから量販店は「故障率の読み」を持つ必要があり、
    これは実質的に保険の引受業務と同じ能力である。

  ※ケーズデンキは長期保証を“無料”で付ける方針を掲げており、
    保証を収益源ではなく集客装置として使う逆の設計になっている。
```

> **指定価格制度が広がると何が起きるか**：本体の粗利率が固定されるため、
> **量販店はいっそう保証・工事・通信に依存する**ことになる。
> 「家電量販店」という名前と実態のズレは、今後さらに広がる。

## 6. 在庫回転と型落ちリスク

家電は**腐らないが、確実に値下がりする**商品である。この性質が在庫管理を難しくしている。

```
【型落ちの時間構造 ── なぜ在庫が命取りになるか】

  価値
   │ ●━━━● 発売直後：粗利が最も厚い（新製品プレミアム）
   │       ╲
   │        ●━━━● 3〜6か月：競合の値下げに追随し始める
   │              ╲
   │               ●━━● 後継機の発表 ← ★ここで価値が階段状に落ちる
   │                   ╲
   │                    ●━━━●━━━● 在庫処分（粗利ゼロ〜逆ざや）
   └──────────────────────────▶ 時間
     ↑                    ↑
   仕入判断のタイミング    店が在庫を抱えていると、ここで損失が確定する

  対策：
   ・仕入を絞る → 品切れで売り逃す（機会損失）
   ・仕入を積む → リベートは増えるが型落ちリスクを負う  ★このジレンマが本質
   ・メーカーに返品する → 通常はできない（買取仕入のため）
   ・アウトレット店・リユース店に流す → ヤマダ・エディオン等が自社で持つ理由
```

| 指標 | 意味 | 家電量販の特徴 |
| --- | --- | --- |
| **在庫回転日数** | 在庫が売れるまでの平均日数 | 食品スーパーより長い。大型品は場所も取る |
| **交差比率（粗利率×回転率）** | 売場の効率 | **回転の遅い高額品は粗利率を確保しないと割に合わない** |
| **坪効率（売場1坪あたり売上）** | 立地の使い方 | 都市型（ヨドバシ・ビック）が圧倒的に高い → [②](02_業界再編と各社の違い.md) |
| **既存店前年比** | 新規出店を除いた成長 | **外部要因（猛暑・規制・OS終了）で大きく振れる**ので単月では判断できない |

**在庫処分は「決算に効く」**。ヤマダHDの2026年3月期は、
約240億円規模の戦略的な在庫処分を行ったことが営業利益の急減（-62.2%）の主因の一つとされる。
在庫を抱えるという判断は、数年遅れで損益計算書に現れる。

## 7. まとめ ——量販店の経済を1枚で

```
【家電量販店の利益はどこから来ているか】

  ┌─ 本体の粗利（20%前後） ────── 価格.comとECに削られ続ける
  │
  ├─ リベート（+5〜10ポイント相当） ─ ★規模が大きいほど有利／減少傾向／指定価格で不要化
  │
  ├─ 延長保証 ──────────── 実質は保険。高収益
  ├─ 配送・設置・工事 ─────── ECが真似しにくい堀。ただし人手不足でコスト上昇
  ├─ リサイクル回収 ──────── 義務であり買い替え接点
  ├─ 通信回線・電気・金融の手数料 ─ 規制で振れる
  └─ リフォーム・住宅（一部企業） ── 客単価の桁が違う
        △
        │ ポイント（-数%）は上の全部から引かれる自社負担のコスト

  → 「安い店」ではなく「入口が家電の総合サービス業」として見るのが正しい
```

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **リベート（販売奨励金・販売協力金）** | メーカーが小売に支払う販売協力の対価。伝票上の仕入価格とは別建てで、後から支払われる。**量販店の実質粗利を決める** |
| **建値（たてね）／仕切価格** | メーカーが示す表向きの卸価格。リベートで実質価格を調整するため、建値だけでは実際の仕入コストが分からない |
| **売価対応リベート（粗利補填）** | 他店対抗で値引きした分をメーカーが埋める形のリベート。値引き競争の原資。一方的な要求は優越的地位の濫用になりうる |
| **優越的地位の濫用** | 取引上強い立場を利用して相手に不当な負担を負わせること。独占禁止法違反。エディオンは従業員の無償派遣で課徴金40億4,796万円（2012年命令、2019年審決） |
| **収益認識に関する会計基準（企業会計基準第29号）** | 2021年4月1日以後開始年度から原則適用。**ポイントを「別個の履行義務」とみなし、付与分を契約負債として繰り延べる** |
| **契約負債** | 代金は受け取ったが、まだ商品・サービスを提供していない義務。ポイント残高がこれに当たる |
| **他店対抗（価格対抗）** | 他店の提示価格に合わせて値下げする慣行。粗利を直接削る |
| **量販店専用モデル（販路限定モデル）** | 特定チェーン向けに型番や仕様を変えた商品。価格比較サイト上で同一商品として並ばないため、価格競争から外れられる |
| **交差比率** | 粗利率×商品回転率。売場の稼ぎの効率を測る小売の基本指標 |
| **坪効率** | 売場1坪あたりの売上高。都市型店舗が高く、郊外型は面積で稼ぐ |
| **延長保証** | メーカー保証（通常1年）終了後を小売が引き受ける仕組み。実質は保険で、故障率と修理費の見積もりが収益を決める |
| **家電リサイクル料金** | エアコン・テレビ・冷蔵庫（冷凍庫）・洗濯機（衣類乾燥機）の廃棄時に消費者が負担する料金。小売業者には引取義務がある |
| **既存店前年比** | 新規出店分を除いた既存店舗の売上の前年同期比。小売の実力を測る基本指標 |
