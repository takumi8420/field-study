# 売る商品の変化 ——売り場から家電が減っていく

このノートで分かること：家電量販店の売り場で**何が減り、何が増えているのか**。
テレビ・PCの単価下落、白物の高額化とエアコン特需、スマホ販売と通信手数料、
ゲーム・玩具・日用品への拡大、リユース・買取。そして最後に、
**メーカーの指定価格制度が量販店から「値決め権」を奪うことの意味**を扱う。

> **結論を先に**：家電量販店の商品構成は、**「安くなった物から、高い物と家電以外へ」**移っている。
> テレビとPCは単価が落ち、買い替え周期が伸び、売り場面積に見合わなくなった。
> 代わりに稼ぐのは**高額化した白物家電（ドラム式洗濯機30万円、冷蔵庫40万円）**、
> **スマホと通信契約の手数料**、そして**家電ですらない商品**（日用品・酒・食品・ゲーム・玩具）である。
> ところがその高額白物で、**メーカーが指定価格制度によって値決め権を取り返しにきた**。
> 「安く売る」という量販店30年の武器が、**利益率の高いカテゴリから順に使えなくなっていく**。

## 1. 全体像 ——売り場の重心はどう移ったか

```
【家電量販店の売り場の重心（概念図・時系列）】

  1990年代            2000年代            2010年代            2020年代
 ┌─────┐        ┌─────┐        ┌─────┐        ┌─────┐
 │ テレビ   │        │ 薄型TV   │        │ スマホ   │        │ エアコン │
 │ ビデオ   │        │ DVD      │        │ タブレット│        │ 冷蔵庫   │
 │ 白物     │        │ デジカメ  │        │ 白物     │        │ 洗濯機   │
 │ ラジカセ │        │ PC       │        │ PC       │        │ ★スマホ  │
 └─────┘        │ 携帯電話  │        │ 美容家電 │        │ ★日用品  │
                     └─────┘        └─────┘        │ ★ゲーム  │
                          ▲                                  │ ★酒・食品│
                     地デジ移行・エコポイント                  │ ★リフォーム│
                     （2009〜2011の特需）                     └─────┘

  ★＝「家電ではない／家電以外の収益」が増えた部分

  共通する動き：
   ・単価が落ちた物（テレビ・PC・デジカメ）は面積あたりの稼ぎが悪化 → 縮小
   ・単価が上がった物（ドラム式・冷蔵庫・エアコン）は台数が増えなくても金額が伸びる
   ・粗利率が高い物（保証・工事・通信手数料・日用品）へ重心が移る
```

| カテゴリ | 台数の動き | 単価の動き | 量販店にとって |
| --- | --- | --- | --- |
| **テレビ** | 横ばい〜減少 | **下落**（大型でも安くなった） | 面積を取るのに稼げない。縮小 |
| **PC** | 特需と反動で乱高下 | 下落傾向 | 周辺機器・設定サービスで補う |
| **エアコン** | **増加**（猛暑・規制） | 上昇 | **最大の稼ぎ頭。工事もセット** |
| **冷蔵庫・洗濯機** | 横ばい | **大幅に上昇**（高額機種化） | 単価が上がり金額は伸びる。**指定価格の主戦場** |
| **スマホ** | 横ばい | 上昇（本体価格） | **手数料収入が本体粗利より重要** |
| **ゲーム・玩具・ホビー** | 変動大 | — | 集客商材。粗利率は低め |
| **日用品・酒・食品・医薬品** | 増加 | — | **来店頻度を上げる。リベートに依存しない粗利** |
| **リユース・中古** | 増加 | — | 買取＝仕入。**新品の下取り接点にもなる** |

## 2. テレビとPC ——「単価が落ちて周期が伸びた」二重苦

### 2-1. テレビ

テレビは**家電量販店の象徴でありながら、最も割に合わなくなった商品**である。

```
【テレビが売り場で割に合わなくなる仕組み】

  ① 単価が落ちる
      薄型化・中国勢の参入で、同じサイズなら年々安くなる
      （JEITAは2025年度について「大型の単価が下がり買い求めやすくなっている」と指摘）
                    ↓
  ② 大型化しても金額が伸びない
      50型が昔の32型の値段になる → サイズは上がるが客単価は上がりにくい
                    ↓
  ③ 買い替え周期が伸びる
      壊れにくい／画質の差が分かりにくい／4Kで十分
                    ↓
  ④ 売り場は広い面積を取り続ける
      並べて比べないと売れない商品なので、面積は減らせない
                    ↓
  ★結論：面積あたりの粗利（交差比率）が悪化する

  直近の出荷（JEITA、薄型テレビ国内出荷台数）
    2025年度  前年度比 -0.8%（大型は好調だが中小型が補えず）
    2026年4月  30.8万台（前年比 91.3%）
    2026年5月  28.0万台（前年比 85.4%）※60型以上のみ111.8%と大型は堅調
```

> **地デジ移行の後遺症**：2011年の地上デジタル放送移行と家電エコポイントで、
> **本来10年かけて売れるはずの台数が2〜3年に前倒し**された。
> その反動が今も尾を引いており、テレビの「山」は10年サイクルでしか戻らない。
> → [AV機器](../../03_電機・電子部品/10_AV機器/README.md)

### 2-2. PC ——Windowsのサポート終了で動く市場

PCは**OSのサポート終了という人為的なイベント**で動く、特殊な商品である。

| 時期 | 出来事 | 量販店への影響 |
| --- | --- | --- |
| 2020年1月 | Windows 7 サポート終了 | 買い替え特需 → 翌年の反動減 |
| **2025年10月** | **Windows 10 サポート終了** | **2025年に大きな特需** |
| **2026年** | その反動 | **2026年7月の国内出荷は47万4,000台（前年比56.1%）＝ほぼ半減**。金額は798億円（同82.2%）で、**台数ほどは落ちていない＝単価は上がっている** |

> **読み方**：台数56.1%・金額82.2%というズレが重要。
> **安いPCが減り、AI PC等の高単価機が残った**ことを示す。
> 量販店から見れば「台数は減ったが、客単価と周辺機器・設定サービスで一部を取り返せる」形になる。

## 3. 白物家電 ——高額化が量販店を支えている

テレビ・PCと逆に、**白物家電は単価が上がっている**。
ドラム式洗濯乾燥機は上位機種で30万円超、大型冷蔵庫は40万円台が普通になった。

台数は増えない（普及率はほぼ100%、平均使用年数13年前後）ので、
**金額の伸びは単価が作っている**。これは量販店にとって都合がよい——
**同じ1台を売る手間で、取れる粗利額が増える**からである。

### 3-1. エアコン ——2026年の主役

```
【エアコン特需の構造（2025〜2026年）】

   猛暑の常態化  ─────┐
                        │
   2027年4月の          ├──▶ 2026年に需要が集中
   省エネ基準強化       │      ・家電大型専門店の販売額（2026年5月）前年同月比 +27.5%
   （＝2027年問題）     │      ・ケーズHD 2026年3月期 純利益 +50.3%
                        │      ・ビックカメラ・ヤマダも4〜6月にエアコン特需
   自治体の省エネ補助 ──┘
   （東京ゼロエミポイント等）

                   ▼
   2027年度以降 ── ▼ 反動減が確定的
                   「買い替えた人はもう買わない」
                   ＋ 低価格モデルが減り、台数はさらに落ちる可能性

   ★量販店にとってのエアコンの価値は、本体粗利だけではない
     ・標準工事（1.5万〜3万円）が付く … 高粗利。ECが最も真似しにくい
     ・工事枠が販売の上限になる      … 繁忙期は「売れる台数＝工事できる台数」
     ・旧機のリサイクル回収が付く
```

制度の詳細（トップランナー制度、冷媒規制）は

## 4. スマホ販売と通信キャリア手数料

家電量販店にとって**スマホは「端末を売る商売」ではなく「回線契約を取る商売」**である。

| 収益 | 誰が払うか | 性格 |
| --- | --- | --- |
| 端末本体の粗利 | 客 | 薄い。キャリア経由なら仕入値も決まっている |
| **新規契約・機種変更の手数料** | **通信キャリア** | **本命**。1件あたりの手数料。原価がほぼ無い |
| 光回線・電気の取次手数料 | 通信事業者・電力会社 | 同上 |
| アクセサリ・保護フィルム貼付 | 客 | 粗利率が非常に高い |
| データ移行・設定サポート | 客 | 人件費だけで作れる粗利 |

```
【規制がこの商売を直撃した経緯】

  〜2019年   「実質0円」「1円スマホ」
              キャリアが端末を大幅に割り引き、量販店は契約手数料で稼ぐ
              客は2年ごとに乗り換え、店は回転で稼げた
                       │
  2019年10月  ★電気通信事業法 第27条の3 施行
              回線契約に紐づく端末値引きに上限（当初は一律2万円）
              「通信料と端末代金の分離」が義務化
                       │
  2020年1月   回線契約なしの端末にも規制が及ぶ
                       │
  2023〜24年  規制の見直し。上限は「本体価格に応じた額」へ
              2024年12月26日からガイドライン改正が適用
              2024年10月には販売代理店の届出制度も整備
                       │
  2026年時点  一定条件下（最大6か月・同一契約者1回限りなど）で
              22,000円の通信料割引が認められる等、運用は緩和方向にある

  → 量販店への影響
     ・「安いから買い替える」客が減り、買い替え周期が伸びた
     ・1件あたりの手数料への依存が強まった
     ・規制が動くたびに売上が数%単位で振れる
```

> **ノジマの利益率が高い理由の一端がここにある**。同社は**キャリアショップの受託運営**を
> 事業として持っており、これは端末の粗利ではなく**手数料収入**なので、粗利率の概念が違う。
> → [② 業界再編と各社の違い](02_業界再編と各社の違い.md)、[通信キャリア](../../04_情報通信・IT・ネット/01_通信キャリア/README.md)

## 5. 家電以外への拡大 ——「来店頻度」を買いに行く

家電は**10年に1度しか買わない商品**である。これが量販店の根本的な弱点だった。
そこで各社は、**日常的に来る理由**を売り場に作った。

| 拡大先 | 狙い | 代表例 |
| --- | --- | --- |
| **日用品・洗剤・食品・酒・医薬品** | **来店頻度を上げる**。ついで買いを取る | ビックカメラ（酒・食品・医薬品）、ヤマダ |
| **ゲーム機・ソフト・玩具・ホビー** | 若年層と親子の集客。発売日の行列 | 上新電機（鉄道模型・ホビー）、各社 |
| **家具・インテリア** | 家電とセットで新生活需要を取る | ヤマダ（大塚家具を傘下に） |
| **リフォーム・住宅・住設** | **客単価の桁を上げる** | ヤマダの住建セグメント（2026年3月期 3,338億円） |
| **金融・保険・クレジット** | 手数料・金利収入 | ヤマダの金融セグメント、各社カード |
| **リユース・買取** | 仕入＝買取、新品の下取り接点 | ヤマダのアウトレット・リユース店（テレビ・冷蔵庫・洗濯機は24か月保証を付けて再販） |

> **経済的な意味**：これらの商品は**リベートに依存しない粗利**である。
> 家電のリベートが細っていく以上（→ [① 量販店の経済](01_量販店の経済.md)）、
> **自力で粗利を作れる商品の比率を上げること**は、多角化というより**防衛策**に近い。

### リユース・買取

**捨てるとお金がかかり、売るとお金が入る**——この非対称が中古市場を押し上げている
（家電リサイクル法の対象4品目は廃棄時に消費者がリサイクル料金を負担するが、
中古品として売買される場合は「廃棄物」にならない）。

量販店にとって買取は、
①**新品の下取りという形で買い替えを促せる**、
②**買取品が仕入原価の安い商品になる**、
③**リユース専門店（セカンドストリート等、全国約920店）に客を取られない**、
という3つの意味がある。一方で**検品・清掃・保証を自前で回す必要があり、小売とは別の業務**になる。
→ [リユース・中古](../../07_小売・流通/16_リユース・中古/README.md)

## 6. 指定価格制度 ——量販店から値決め権が奪われる

ここが、量販店の商売にとって**最も構造的な変化**である。

### 6-1. 何が起きているのか

メーカーが**小売価格を指定し、売れ残りは引き取る**（在庫リスクを負う）という売り方が広がっている。
在庫リスクをメーカーが負うため、独占禁止法が禁じる「再販売価格の拘束」に当たらないと整理される。
制度の詳細とメーカー側の論理は
→ [白物家電：儲け方と流通](../../03_電機・電子部品/09_白物家電/02_儲け方と流通.md)

| メーカー | 開始 | 範囲（報道ベース） |
| --- | --- | --- |
| パナソニック | 2020年度に試行（ドライヤー、ドラム式洗濯乾燥機）→2022年度拡大 | 国内白物家電の**約3割** |
| 日立（日立GLS） | 2023年9月 | 全製品の約1割から |
| **三菱電機** | **2026年1月**（1月23日発売の新型冷蔵庫から） | まず冷蔵庫の上位機種 |
| シャープ | 導入予定なしと報じられる | — |
| 中国勢（ハイアール等） | 採用していない | — |

### 6-2. 量販店から見ると何が変わるか

```
【量販店にとっての指定価格制度 ── 得と損】

  ＜従来の取引＞
    仕入値 17万円 → いくらで売るかは店が決める
      ├ 20万円で売れば粗利3万円（でも他店に負ける）
      ├ 18.5万円で売れば粗利1.5万円（客は来る）
      └ ★「安さで客を呼ぶ」という武器を自分で握っていた
         その代わり、売れ残れば自分で値下げして処分する（在庫リスク）

  ＜指定価格＞
    店頭価格 20万円（メーカーが決定）、量販店の粗利は決められた率で固定
      ├ ◎ 粗利率が確実に取れる。他店対抗の値下げが起きない
      ├ ◎ 売れ残りは返品できる → ★在庫リスクと型落ちリスクが消える
      ├ ◎ 値引き交渉の接客時間が減る。販売員は機能説明に集中できる
      ├ ✕ ★「他店より安い」で客を呼べない
      ├ ✕ 粗利の絶対額は薄い（率は安定しても金額は伸びない）
      └ ✕ 売る動機が弱まる … 指定価格品より、粗利の大きい他社品を薦めたくなる

  ★最も重い意味：
    量販店の30年の競争力は「大量に仕入れて安く売る」ことだった。
    指定価格が広がるほど、その力が効かない売り場が増える。
    → 残る差別化は「工事・保証・配送・相談」しかなくなる
```

### 6-3. 量販店にとって「悪い話」だけなのか

必ずしもそうではない。次の3点で得もある。

1. **在庫リスクがなくなる**。型落ち処分損（ヤマダの2026年3月期の約240億円規模の在庫処分のような話）が
   構造的に発生しなくなる
2. **粗利率が安定する**。リベート交渉に依存しない、読める粗利が手に入る
3. **ECとの価格差が消える**。Amazonも同じ値段になるので、
   **「実物を見せられる」「今日届く」「工事できる」という店舗の強みが相対的に効く**

> **つまり、指定価格は「量販店の安売り力」と「量販店のリスク」を同時に取り上げる取引である**。
> 安さで勝ってきた会社ほど痛く、サービスで勝ってきた会社（エディオン、地域電器店）ほど有利になる。
> ノジマが**自らメーカーを持つ**選択をした背景にも、
> 「値決めをメーカー側に取られるなら、自分がメーカーになる」という論理が読める。

---

## 7. まとめ

1. **安くなった物（テレビ・PC）は売り場に見合わなくなり、高くなった物（白物）が支えている**
2. **エアコンは2026年の主役**だが、2027年問題の駆け込みであり反動減は確定的
3. **スマホは端末ではなく手数料の商売**。電気通信事業法の規制で売上が振れる
4. **家電以外（日用品・ゲーム・住宅・リユース）への拡大は、リベート依存からの防衛策**でもある
5. **指定価格制度は量販店から値決め権と在庫リスクを同時に取り上げる**。
   安売りで勝ってきた会社ほど戦い方の変更を迫られる

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **指定価格制度** | メーカーが小売価格を指定し、売れ残りの返品を受けて在庫リスクを負う売り方。量販店は値引きできず、粗利率は固定される → [白物家電②](../../03_電機・電子部品/09_白物家電/02_儲け方と流通.md) |
| **再販売価格の拘束** | メーカーが小売の販売価格を守らせること。独占禁止法が禁じる不公正な取引方法。指定価格制度はメーカーが在庫リスクを負うため該当しないとされる |
| **エアコン2027年問題** | 2027年4月の省エネ基準（トップランナー制度）強化と冷媒規制が重なり、安価なモデルが減る／値上がりするとされる問題。2026年に駆け込み需要を生んだ |
| **トップランナー制度** | 最も省エネ性能の高い製品を基準に目標値を定める規制。**出荷製品の加重平均**での達成を求める |
| **地デジ移行・家電エコポイント** | 2009〜2011年のテレビ特需。本来10年分の需要を前倒しし、その後の長い反動を生んだ |
| **電気通信事業法 第27条の3** | 回線契約に紐づく端末値引きの上限を定めた規制。2019年10月施行。「1円スマホ」を封じた |
| **代理店手数料** | 通信事業者が販売代理店に支払う契約獲得等の手数料。原価がほぼ無く、量販店の高収益源 |
| **交差比率** | 粗利率×商品回転率。売場効率の指標。単価が落ちて回転も落ちた商品は売り場から外される |
| **下取り／買取** | 下取り＝新品購入を条件に旧品を引き取る（値引きに近い）。買取＝単独で現金を払って仕入れる |
| **家電リサイクル法** | 正式名称は特定家庭用機器再商品化法。エアコン・テレビ・冷蔵庫（冷凍庫）・洗濯機（衣類乾燥機）の4品目が対象。小売業者に引取義務がある |
