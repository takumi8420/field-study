# 商圏と出店

食品スーパーは**「半径1〜3kmの人口を何人囲い込めるか」だけで勝負が決まる商売**である。
このノートで分かること：なぜ全国チェーンより地域密着の中堅が強い場面があるのか、
なぜ各社が同じエリアに固めて出店するのか、そして人口減少が何を壊すのか。

## 1. 商圏の大きさ — 「歩いて・自転車で」が前提

商圏（しょうけん）＝その店に客が来てくれる地理的な範囲のこと。
食品スーパーの商圏は**業態の中で最も狭い部類**に入る。

| 業態                         | 主な商圏                                              | 来店頻度     | 移動手段                 |
| ---------------------------- | ----------------------------------------------------- | ------------ | ------------------------ |
| コンビニ                     | 半径 300〜500m                                        | 週3回〜毎日  | 徒歩                     |
| **食品スーパー**             | **半径 700m〜2km**（都市部は700m前後、地方は2km前後） | **週2〜3回** | 徒歩・自転車・近距離の車 |
| ドラッグストア（食品強化型） | 半径 1〜2km                                           | 週1〜2回     | 自転車・車               |
| 総合スーパー（GMS）・SC      | 半径 3〜10km                                          | 月1〜2回     | 車                       |
| 百貨店                       | 都市圏全域                                            | 年数回       | 鉄道                     |

※食品スーパーの商圏距離は業界で広く使われる目安（エリアマーケティング各社の解説ベース）。
実際には川・線路・幹線道路といった「渡りにくい線」で商圏は歪む。

なぜ狭いのか。理由は単純で、**生鮮食品と重い飲料を、頻繁に、自力で運ぶから**である。

```
【 商圏が狭い理由の連鎖 】

 買う物が「重くて・かさばって・日持ちしない」
        ↓
 まとめ買いしにくい → 来店頻度が高い（週2〜3回）
        ↓
 1回あたりの移動時間を短くしたい（10分以内）
        ↓
 徒歩・自転車圏 ＝ 半径1〜2km に商圏が縮む
        ↓
 ★その狭い円の中の人口が、その店の売上の上限を決める
```

> ポイント：食品スーパーの売上は「魅力」より先に**円の中の人口**で天井が決まる。
> だからこの業界の競争は、商品開発より前に**立地の取り合い**として現れる。

一般に出店の目安は**商圏内人口5,000〜10,000人以上**とされる。
逆に言えば、人口が減って5,000人を切ったエリアの店は、
どれだけ努力しても構造的に成り立たなくなる。

## 2. 1店舗の経済性 — 月商・坪数・坪効率

小売業を読むときの基本は「1店舗がいくら売っていくら残すか」である。
業界統計から標準的な姿を組み立てるとこうなる。

| 指標                        | 水準                                   | 出典・注                                   |
| --------------------------- | -------------------------------------- | ------------------------------------------ |
| 総店舗数（パネル270社）     | 8,422店                                | 2025年12月・スーパーマーケット販売統計調査 |
| 総売場面積（同）            | 1,413万㎡                              | 同上                                       |
| **1店舗あたり平均売場面積** | **約1,678㎡（約508坪）**               | 上記2項目からの計算値                      |
| **店舗平均月商**            | **1億5,303万円**（2025年12月・繁忙月） | 同上                                       |
| 同（11月＝平常月）          | 1億2,920万円                           | 2025年11月確報                             |
| **売場1㎡あたり売上高**     | 9.1万円（12月）／7.7万円（11月）       | 同上                                       |

※12月は歳末需要で月商が2割ほど膨らむ。**年間の平均月商は1.3億円前後**と見るのが実態に近い。
1坪＝約3.306㎡で換算。

ここから1店舗の損益をおおまかに組むとこうなる（年商15億円、粗利率26%、営業利益率2%の場合）。

```
【 標準的な1店舗（年商 約15億円・売場 約500坪）の年間損益イメージ 】

 売上高          1,500  百万円
  − 売上原価      1,110          粗利率 26%
 ─────────────────────
 売上総利益         390
  − 人件費         185          ★粗利のほぼ半分
  − 地代家賃        50
  − 水道光熱費       30          冷蔵・冷凍設備を24時間動かす
  − 減価償却         35
  − その他販管費     60
 ─────────────────────
 営業利益           30  百万円   ← 営業利益率 2%
```

※各費目は業界統計の平均的な構成比から組んだ**モデル計算**であり、特定企業の数値ではない。

重要なのは**水道光熱費の重さ**である。食品スーパーは冷蔵ケース・冷凍ケース・
冷凍庫を24時間止められない。電気料金の上昇はコンビニ以上に直接効く。
売上比で2%前後というのは、営業利益率と同じオーダーの金額である。

> ポイント：営業利益率2%＝**年商15億円の店で年3,000万円の儲け**。
> 店長1人と社員数人、パート数十人を抱えてこの水準。これがこの業界の薄さ。

## 3. 出店の型 — 新規・居抜き・スクラップ&ビルド

| 型                      | やること                                         | 初期投資     | 速さ           | リスク                             |
| ----------------------- | ------------------------------------------------ | ------------ | -------------- | ---------------------------------- |
| **新規（スクラッチ）**  | 更地から建てる／テナントとして新築SCに入る       | 大（数億〜） | 遅い（1〜2年） | 需要予測を外すと重い               |
| **居抜き（いぬき）**    | 撤退した他社スーパーの建物・設備を引き継ぐ       | 小〜中       | 速い（数ヵ月） | 前の店のイメージが残る。設備が古い |
| **スクラップ&ビルド**   | 古い自社店舗を閉め、近くに大型の新店を建て替える | 大           | 中             | 一時的に売上が途切れる             |
| **M&A（企業ごと買う）** | 他社チェーンを買収し、店舗網をまるごと取得       | 最大         | 最速           | 統合（PMI）に数年かかる            |

近年、**居抜きとM&Aの比重が上がっている**。理由は3つ。

1. **良い立地がもう空いていない**。人口が増えている地域が限られる
2. 建築費・人件費の高騰で新築の投資回収年数が延びた
3. **撤退する中小スーパーが増えた**ので、居抜き物件と売り案件が市場に出てきた

2025〜2026年の大型再編（トライアルによる西友買収、U.S.M.Hといなげやの統合、
イズミヤ・阪急オアシスと関西スーパーマーケットの合併など）は、
**「出店」を企業買収で行う流れ**の表れである。→ [直近トピック 2026](04_直近トピック_2026.md)

## 4. ドミナント — 「同じエリアに固めて出す」の意味

**ドミナント出店**とは、特定エリアに店舗を集中させる戦略のこと。
一見すると自社店舗同士で客を食い合う（カニバリゼーション）だけに見えるが、
食品スーパーでは次の理由で合理的になる。

```
【 ドミナントが効く仕組み 】

 同一エリアに 10 店を固める
        │
        ├─▶ 物流：1台のトラックが1日で全店を回れる → 配送費／店 が下がる
        │
        ├─▶ 加工：プロセスセンター1ヵ所で10店分を賄える → 設備投資が回収できる
        │
        ├─▶ 人：店舗間の応援・異動ができる → 突発的な欠員を吸収できる
        │
        ├─▶ 販促：そのエリアのチラシ・TVCMが10店に効く → 広告費／店 が下がる
        │
        └─▶ 産直：「このエリアで週◯トン売る」と言えて産地と直接組める
                    → [生鮮が決める商売](01_生鮮が決める商売.md) の直接取引が可能に

 逆に、飛び地に1店だけ出すと上記すべてが効かず、
 配送費も加工費も販促費もその1店で負担することになる ＝ ほぼ赤字
```

> ポイント：ドミナントは「シェアを取る戦略」であると同時に、
> **固定費を店数で割るための戦略**である。だから中途半端な店数では逆効果になる。

これが、全国展開しているように見える企業でも
**実態は「エリアごとの局地戦の集合」**である理由である。
食品スーパー業界に圧倒的な全国1位が生まれないのは、
商圏が狭くドミナントが効く以上、**全国シェアより県内シェアが意味を持つ**からだ。

## 5. 地方スーパーはなぜ強いのか

全国チェーンが地方に出て行っても、地元の中堅スーパーに勝てないことがよくある。
理由は「地域密着」という曖昧な言葉ではなく、次の具体的な差である。

| 論点         | 地場スーパーの優位                                     | 全国チェーンの不利                                     |
| ------------ | ------------------------------------------------------ | ------------------------------------------------------ |
| **品揃え**   | その県の味付け・魚種・野菜・地酒を知っている           | 全国共通の商品構成になりがち。本部の標準化が邪魔をする |
| **地場産品** | 地元農家・漁協との長年の関係。朝どれ野菜の直売コーナー | 一元調達の仕組みに少量の地場品が乗らない               |
| **価格決定** | 店長・バイヤーの裁量で当日の相場に即応できる           | 本部決裁で遅れる                                       |
| **人**       | 地元採用で定着率が高い。客と顔なじみ                   | 転勤前提で地域知識が蓄積しにくい                       |
| **不動産**   | 自社所有の土地が多く家賃負担が軽い                     | 賃借が中心で固定費が重い                               |
| **意思決定** | オーナー経営でスピードが速い                           | 階層が多い                                             |

ただし、地場スーパーには決定的な弱点もある。

- **仕入規模が小さい**ので、一般食品・日配のメーカー仕入価格で大手に負ける
- **システム投資が単独では重い**（POS更新、AI発注、ネットスーパー、電子棚札）
- **後継者がいない**。オーナー経営ゆえの事業承継問題

この弱点を埋める仕組みが**ボランタリーチェーン**である。
CGCグループ（シジシージャパンが本部）は2026年1月時点で
**加盟204社・4,534店・グループ総年商5兆5,421億円・PB開発1,896品**（同社公表）。
共同仕入れとPB開発だけを共同化し、店舗運営は各社の自由に残す。
**「規模の経済は共有し、地域密着は手放さない」**という解であり、
日本の食品スーパーの分散構造を支えている柱の1つである。
→ 詳しくは [競争環境](03_競争環境.md)

## 6. 人口動態が壊すもの

食品スーパーの売上＝**商圏人口 × 来店頻度 × 客単価**である。
人口減少はこの式の第1項を直撃する。

```
【 人口減少エリアで起きる連鎖 】

 商圏人口が減る
      ↓
 店の売上が下がる（来店頻度と客単価では埋まらない）
      ↓
 生鮮の品揃えを減らす／惣菜の品目を減らす
      ↓
 「行っても欲しい物がない」→ 来店頻度がさらに落ちる
      ↓
 撤退
      ↓
 ★買い物困難者（いわゆる「買い物弱者」）が発生
      ↓
 移動販売・宅配・行政支援の対象になるが、採算は取れない
```

一方で、**人口が増えている場所は限られる**。都市部のタワーマンション群、
再開発エリア、新設の駅周辺といった狭いスポットに出店が集中する。
ここでは**小型店（200〜300坪級）**の開発が進んでいる。
都心では大きな箱が取れず、地価も高いため、
**売場を絞って生鮮と惣菜に特化する**形が合理的になるからだ。

| 立地タイプ             | 売場規模   | 品揃えの重心             | 想定客                 |
| ---------------------- | ---------- | ------------------------ | ---------------------- |
| **郊外ロードサイド**   | 500〜800坪 | フル。非食品も置く       | 車で来るファミリー     |
| **駅前・商店街**       | 200〜400坪 | 生鮮＋惣菜。日用品は薄く | 通勤帰りの単身・共働き |
| **都心小型・デパ地下** | 100〜200坪 | 惣菜・こだわり生鮮に特化 | 単身、高所得層         |
| **住宅地内（近隣型）** | 300〜500坪 | フルだが価格重視         | 徒歩圏の主婦・高齢者   |

高齢化も見逃せない。高齢者は**移動距離が短く、少量しか買わない**。
商圏はさらに縮み、客単価も上がりにくい。
一方で惣菜や小容量パックの需要は増えるため、
**「近くて・少量で・調理済み」に寄せた品揃え**が必要になる。
これは[コンビニ](../01_コンビニエンスストア/README.md)と正面から重なる領域でもある。

## 7. まとめ — 出店ニュースの読み方

食品スーパーの出店・閉店のニュースは、次の3点で読むと意味が取れる。

1. **その店は既存ドミナントの中か、飛び地か**
   飛び地なら物流・加工・販促の固定費を単独で背負う。よほどの理由がないと苦しい
2. **商圏人口は何人か、そして増えているか減っているか**
   「駅前一等地」でも、実際の居住人口が薄ければ夜と週末が死ぬ
3. **居抜きか、新築か、M&Aか**
   居抜きとM&Aは「良い立地がもう空いていない」ことの裏返し。
   業界全体が成熟期＝奪い合いの段階に入っているサイン

## 用語メモ

| 用語                           | 意味                                                                   |
| ------------------------------ | ---------------------------------------------------------------------- |
| **商圏**                       | その店に客が来る地理的範囲。食品スーパーは半径700m〜2kmが目安          |
| **1次商圏／2次商圏**           | 来店客の大半を占める近い範囲が1次、その外側が2次                       |
| **坪効率（坪当たり売上）**     | 売場1坪あたりの年間・月間売上。店舗の生産性指標                        |
| **店舗平均月商**               | 1店舗の1ヵ月の売上。2025年12月で1億5,303万円（協会統計）               |
| **ドミナント出店**             | 特定エリアに集中出店し、物流・加工・販促の固定費を店数で割る戦略       |
| **カニバリゼーション**         | 自社店舗同士の客の食い合い。ドミナントの副作用                         |
| **居抜き（いぬき）**           | 撤退した他社の建物・設備をそのまま引き継いで出店すること               |
| **スクラップ&ビルド**          | 古い自社店舗を閉め、近隣に大型の新店を建て替えること                   |
| **近隣型・小型店**             | 200〜400坪級の都市型店舗。生鮮と惣菜に特化する                         |
| **ボランタリーチェーン（VC）** | 独立した小売企業が共同仕入れ・PB開発だけを共同化する組織。CGCなど      |
| **買い物困難者（買い物弱者）** | 近隣に食料品店がなく日常の買い物が難しい人。撤退の社会的コスト         |
| **PMI**                        | M&A後の統合作業（Post Merger Integration）。店舗網の再編には数年かかる |
