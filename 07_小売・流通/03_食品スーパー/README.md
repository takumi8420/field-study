# 食品スーパー

- 大分類: 小売・流通
- 状態: done
- 更新日: 2026-09-20

**生鮮食品を中心に、半径1〜2kmの住民が週2〜3回通う店**。
営業利益率1〜3%という薄利で、粗利の半分が人件費に消える労働集約型の商売である。
いま業界を動かしているのは、**食品を武器にしたドラッグストアの攻勢**と、
**値上げでは利益を守れなくなった2026年の局面**、そして**M&Aによる規模の追求**の3つ。

## 1. 業界の定義・範囲

食品スーパー（SM＝スーパーマーケット）とは、**セルフサービス方式で、
売場の過半を食品が占め、生鮮3部門を自前で扱う小売店舗**を指す。
法律上の業態区分ではなく、統計や業界慣行による呼び名である。

経産省「商業動態統計」の「スーパー」は総合スーパー（GMS）を含むため、
食品スーパーだけを見るには業界3団体（全国スーパーマーケット協会、
日本スーパーマーケット協会、オール日本スーパーマーケット協会）の
「スーパーマーケット販売統計調査」を使うのが実務的である。

隣接業態との境界は次の通り。

| 業態                       | 違い                                                 | 参照                                                         |
| -------------------------- | ---------------------------------------------------- | ------------------------------------------------------------ |
| **総合スーパー（GMS）**    | 食品に加え衣料・住居関連を大きく扱う。売場は数千坪級 | [スーパー・GMS](../02_スーパー・GMS/README.md)               |
| **コンビニ**               | 商圏300〜500m、24時間、即食中心。生鮮は扱わない      | [コンビニエンスストア](../01_コンビニエンスストア/README.md) |
| **ドラッグストア**         | 医薬品・化粧品が利益源。食品は集客用。生鮮は弱い     | [ドラッグストア](../04_ドラッグストア/README.md)             |
| **ディスカウントストア**   | 価格訴求に特化。生鮮を扱う企業も多く、境界は曖昧     | [ディスカウントストア](../09_ディスカウントストア/README.md) |
| **食品EC・ネットスーパー** | 店舗を持たない、または店舗から配送                   | [通販・D2C](../15_通販・D2C/README.md)                       |

「食品スーパー」と「ディスカウントストア」の境界は、近年ほぼ消えかけている。
オーケーやロピアは生鮮をフルに扱う食品スーパーでありながら、価格政策はディスカウント型である。
**業態名より、価格政策（EDLPかHi-Loか）と生鮮の厚みで分類するほうが実態に合う。**

| 売上高営業利益率              | 1〜3%台（規模で大きく差。小規模はほぼゼロ）                      | 2025年前後・業界統計                                             |

※集計母体が異なるため数値は一致しない。**「商業動態統計＝GMS込み」「3団体統計＝パネル270社」
「ランキング集計＝企業の連結売上」**と、それぞれ何を数えているかを確認して読むこと。

成長性は**「金額は伸びるが数量は伸びない」**と見るのが正確である。
2022年以降の売上増は主に値上げによる単価上昇であり、来店客数と買上点数はむしろ減っている。
人口減少が数量の天井を押し下げ続けるため、
**市場の実質的な成長余地はほぼない＝シェアの奪い合い**という前提で読む必要がある。

## 3. バリューチェーン（川上 → 川下）

```
 【川上】生産                【中間】流通              【川下】小売      消費者
 ─────────────────────────────────────────────────────
  農家・漁業者 ─┬─ JA・出荷団体 ─ 卸売市場 ─┬────────┐
  畜産農家     │   （卸売業者→仲卸）        │        │
               │                             │        ▼
               └────── 産直・契約栽培 ───────┘   ★食品スーパー ─▶ 家庭
                            （中間を飛ばす）          │
                                                      │ ←─ 店内加工（バックヤード）
  食品メーカー ── 食品卸（一次・二次）───────────────┘      │
   （NB商品）                                                 └─ 惣菜として再加工
                                                                 （ロスを売上に変換）
  受託製造メーカー ──── PB委託 ─────────────────▶（PB商品）
                                    ↑ CGC等の共同仕入れ本部がまとめて発注
```

付加価値がどこに残るかを見ると、この業界の性格が分かる。

| 工程                       | 付加価値 | 誰が取るか                                                                         |
| -------------------------- | -------- | ---------------------------------------------------------------------------------- |
| 生産                       | 中       | 農家・メーカー。相場に左右される                                                   |
| 卸・市場                   | 低〜中   | 卸売業者・仲卸。口銭商売で薄利 → [食品卸](../../06_商社・卸売/06_食品卸/README.md) |
| **店内加工（生鮮・惣菜）** | **高**   | **食品スーパー自身**。ここが唯一の製造機能                                         |
| 陳列・販売                 | 低       | 一般食品は誰がやっても同じ                                                         |
| PB企画                     | 中〜高   | 小売。ただし販売量が必要                                                           |

> ポイント：食品スーパーが自分で価値を作れるのは**店内加工と品揃えの編集**だけ。
> 一般食品を並べるだけなら、ドラッグストアやディスカウント業態と代替可能になる。

**業界構造の特徴は、圧倒的な1位がいないこと**である。
上位でも売上1兆円前後、シェアで見れば数%。
商圏が半径1〜2kmと狭く、ドミナント（地域集中出店）が効くため、
**全国シェアより県内シェアが意味を持つ**。
これが「地方スーパーが大手に勝てる」構造の根拠であり、
同時に「システム投資や仕入交渉では大手に負ける」弱点の根拠でもある。

## 5. 収益モデル・コスト構造

```
売上 100
 ├─ 売上原価      約 74
 └─ 粗利          約 26     ← 業態としては薄い（百貨店30%台、ドラッグストア28%前後）
      ├─ 人件費   約 12〜13   ★粗利のほぼ半分。生鮮の加工作業が主因
      ├─ 地代家賃  約  3〜4
      ├─ 水道光熱  約  2      冷蔵・冷凍を24時間止められない
      ├─ 減価償却  約  2〜3
      ├─ その他    約  4〜5   販促、消耗品、包材
      └─ 営業利益  約  1〜3   ★100円売って2円
```

※業界統計の平均的な構成比から組んだモデル。企業により幅がある。

部門別の性格は次の通り（値入率＝計画上の粗利率、ロス率＝廃棄・値下げ・目減りによる損失率）。

| 部門     | 構成比（2025年） | 値入率の目安 | ロス率の目安      | 役割                                                |
| -------- | ---------------- | ------------ | ----------------- | --------------------------------------------------- |
| 青果     | 13.9%            | 30%前後      | 数%（天候で激変） | 集客の顔。相場変動が大きい                          |
| 水産     | 8.2%             | 30%台後半    | 約9.0%            | 差別化が最も出る。技量勝負                          |
| 畜産     | 11.2%            | 30%前後      | 約6.0%            | 客単価を上げる                                      |
| 惣菜     | 11.3%            | 40%台        | **約10.4%**       | 利益の源泉かつ最大のリスク                          |
| 日配     | 20.4%            | 20%台        | 約3.5%            | 来店頻度を支える                                    |
| 一般食品 | 26.5%            | 15〜20%      | ほぼゼロ          | 薄利。価格競争の主戦場                              |
| 非食品   | 5.9%             | 25〜30%      | 低い              | **2025年は前年比99.0%と減少**。ドラッグストアに流出 |

> ポイント：**営業利益率2%は、ロス率が2ポイント悪化しただけで消える**。
> 鮮度管理と発注精度は「品質の話」ではなく「損益の話」である。

詳しくは [生鮮が決める商売](01_生鮮が決める商売.md)。

## 6. 競争要因（KSF）と参入障壁

### 勝つための条件（KSF）

| KSF                      | なぜ効くか                                                             |
| ------------------------ | ---------------------------------------------------------------------- |
| **生鮮と惣菜の質**       | 値段以外で選ばれる唯一の領域。来店頻度＝生命線を支える                 |
| **立地とドミナント密度** | 商圏人口が売上の上限を決める。集中出店で物流・加工・販促の固定費を割る |
| **ロス管理と発注精度**   | 営業利益率2%の商売では、ロス率1ポイントが致命的                        |
| **人の確保と定着**       | 生鮮加工は機械化しにくい。パート比率の高い職場で定着率が効く           |
| **PB比率と仕入規模**     | 比較されない商品を持つと価格競争から半歩逃げられる                     |
| **省人化投資の体力**     | セルフレジ、電子棚札、AI発注。最低賃金上昇への唯一の構造的対応         |

### 参入障壁

参入障壁は**制度ではなく経済性**にある。許認可はほぼ不要に近い（下記7章）一方で、

- **良い立地が既に埋まっている**。人口が増えるエリアは限られる
- **単独店ではドミナントの効果が得られず、固定費を割れない**
- **生鮮のノウハウと人材**（目利き、加工技能）は短期に作れない
- **プロセスセンターや物流網は数十店規模がないと回収できない**

逆に言えば、**既に店舗網とノウハウを持つ既存プレイヤー同士の買収**が
最も合理的な参入手段になる。2025〜2026年の再編ラッシュはこの帰結である。
→ [直近トピック 2026](04_直近トピック_2026.md)

## 7. 規制・法制度

食品スーパーに固有の「業法」は存在しないが、複数の法令が横断的に効く。

| 法令・制度                                                     | 効き方                                                                                                    |
| -------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| **食品衛生法**                                                 | 営業許可（飲食店営業、食肉販売業、魚介類販売業など）。店内加工を行う以上、必須                            |
| **HACCP（ハサップ）**                                          | 2021年6月から原則すべての食品事業者に義務化。衛生管理の手順書化と記録。バックヤードの作業負荷を押し上げた |
| **食品表示法**                                                 | 原材料・アレルゲン・原産地・消費期限の表示。生鮮・惣菜は表示作業が重い                                    |
| **大規模小売店舗立地法（大店立地法）**                         | 売場面積1,000㎡超の店舗は、騒音・駐車場・交通への配慮を届出。出店のリードタイムを延ばす                   |
| **独占禁止法・優越的地位の濫用**                               | 納入業者への不当な値引き要求、協賛金、従業員派遣の要請を規制。公取委が小売を注視                          |
| **下請法／取引適正化**                                         | 仕入先との取引条件。PB委託でも適用されうる                                                                |
| **食品ロス削減推進法**（2019年施行）                           | 廃棄削減の努力義務。「3分の1ルール」など商慣行の見直しが進む                                              |
| **最低賃金法**                                                 | 全国加重平均は2024年度1,054円、2025年度約1,090円。パート比率が高い業態に直撃                              |
| **省力化投資支援**（省力化投資促進プラン ―小売業―、2025年6月） | 中小小売の省人化設備投資を後押し                                                                          |

**かつて最大の障壁だった大規模小売店舗法（大店法）は2000年に廃止**され、
出店規制は「需給調整」から「周辺環境への配慮」（大店立地法）へ転換した。
この規制緩和が2000年代以降の出店競争と、今日の過当競争の出発点になっている。

## 8. 最近のトピック

詳細と出典URLは [直近トピック 2026](04_直近トピック_2026.md) に。要点は5つ。

1. **食品値上げは続く**。2026年は1〜11月判明分で1万8,347品目（帝国データバンク）。
   うち90.7%が原材料高を理由に挙げる
2. **コメ価格はピーク比で約25%下落**。スーパー店頭5kg平均は2026年9月で3,003円。
   ただし前年の備蓄米特需の反動で、一般食品部門は前年割れ（2026年6月の一般食品DIは −15.2）
3. **2026年6月、売上高DIと収益DIがマイナス圏へ転落**（売上高 −6.6、収益 −10.5）。
   客単価は上がっているが来客数DIは −13.2。**値上げだけでは利益を守れない局面**に入った
4. **再編ラッシュ**。トライアルによる西友買収（約3,800億円、2025年7月完了、合算1.2兆円規模）、
   U.S.M.H×いなげや、イズミヤ・阪急オアシス×関西スーパー（2026年4月合併）など
5. **ドラッグストアの食品攻勢**。業態売上10兆307億円のうちフーズ2兆8,329億円（前年比13.2%増、
   2024年度）。スーパーの非食品は前年比99.0%と減少し、売場が移っている
