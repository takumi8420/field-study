# 競争環境

食品スーパーの敵は、もはや別の食品スーパーではない。
**食品を武器に使い始めたドラッグストアが最大の脅威**であり、
そこにディスカウント業態、コンビニ、ネットスーパーが絡む。
このノートで分かること：**なぜドラッグストアの食品はスーパーより安いのか**、
そして食品スーパー側の対抗手段（PB強化・共同仕入れ・省人化）が何を狙っているのか。

## 2. 最大の脅威 — ドラッグストアの食品攻勢

### なぜドラッグストアの食品は安いのか

「企業努力」ではない。**利益の出し場所が別にあるから**である。これが構造の核心。

```
【 ドラッグストア 】              │ 【 食品スーパー 】
  食品      粗利率 15〜20%       │   生鮮4部門    粗利率 30〜40%（ロス控除前）
    ↑ 儲けない。集客用の撒き餌  │   一般食品・日配 粗利率 15〜25%
  日用品    粗利率 25〜30%       │   非食品       粗利率 25〜30%
  化粧品    粗利率 35〜45% ★    │      ↑★ここをドラッグストアに奪われた
  調剤・医薬 粗利率 35〜40% ★   │
  ─────────────────────────────│──────────────────────────────────
  食品で毎日来させ、化粧品と     │  高粗利の逃げ場が「生鮮」しかない
  医薬品で稼ぐ                   │
```

> ポイント：ドラッグストアにとって食品は**集客用の撒き餌（ロスリーダー）**だが、
> 食品スーパーにとって食品は**本業そのもの**。同じ値段で売り合えば、構造上勝てない。

裏付けとなる数字がいくつかある。

- ドラッグストアの食品比率は2019年頃から上昇し、2020年には平均30%を超えた（業界報道ベース）
- 2024年度のフーズ・その他は**前年比13.2%増**の2兆8,329億円と、業態全体（9.0%増）を上回る伸び
- 一方、スーパーマーケットの**非食品は2025年に前年比99.0%とマイナス**
  （スーパーマーケット販売統計調査）。日用品・医薬化粧品はドラッグストアに移っている

北陸では「越境ドラッグストア」と呼ばれるクスリのアオキ、Genky DrugStores などが
食品を厚くした店舗で攻め込み、**エリアによってはスーパーの売上を追い抜いた**と報じられている
（日経クロストレンド、2025年）。

### ではドラッグストアの弱点はどこか

| 論点                 | ドラッグストア                         | 食品スーパー |
| -------------------- | -------------------------------------- | ------------ |
| 加工食品・飲料の価格 | **強い**（ロスリーダー戦略）           | 勝てない     |
| 生鮮の鮮度・品揃え   | 弱い。青果は限定的、鮮魚はほぼ置けない | **強い**     |
| 惣菜（作りたて）     | 弱い。バックヤードの調理設備がない     | **強い**     |
| 調剤・健康相談       | **強い**                               | ない         |

つまり**生鮮と惣菜だけが安全地帯**である。
これが [生鮮が決める商売](01_生鮮が決める商売.md) で書いた「生鮮を守る」話の理由になる。
食品スーパー側も、調剤薬局の買収やドラッグストアとの共同出店（隣接させ相互送客する）で
**敵の土俵を自陣に取り込む**動きを見せている（業界報道ベース）。

## 3. ディスカウント業態 — 価格訴求層をまるごと取る

トライアル、オーケー、ロピア、業務スーパー（神戸物産のFC）など、**徹底した低価格で
「安さで選ぶ客」を丸取りする**プレイヤーが伸びている。共通する仕組みは次の通り。

| 手法                                 | 中身                                                   | 効果                                                  |
| ------------------------------------ | ------------------------------------------------------ | ----------------------------------------------------- |
| **EDLP（エブリデー・ロープライス）** | 特売をやめ、常に安い                                   | チラシ代・特売時の人員配置が不要。値付け作業も減る    |
| **作業の簡素化**                     | 段ボールのまま陳列（カットケース陳列）、品出しを減らす | 人件費が下がる                                        |
| **品目数（SKU）を絞る**              | 1カテゴリ2〜3品に絞る                                  | 1品あたりの仕入量が増え、仕入価格が下がる。在庫も減る |
| **家賃の安い立地**                   | 郊外、居抜き、2階以上                                  | 固定費が軽い                                          |
| **PB比率を上げる**                   | 自社ブランド                                           | 粗利を確保しつつ売価を下げられる                      |

**EDLP** に対する従来型を **Hi-Lo（ハイ・ロー）** という。チラシで一部商品を極端に安くして
集客し、他の商品で粗利を取る方式。Hi-Lo はチラシ制作費・特売時の大量陳列作業・値札貼り替えが
発生するため、**人手不足の時代にはEDLPのほうが構造的に有利**になってきた。

```
【 Hi-Lo と EDLP 】

 Hi-Lo   価格 ┤  ╱╲      ╱╲      ╱╲     ← 特売日に人も客も集中
              │ ╱  ╲    ╱  ╲    ╱  ╲       チラシ費・作業負荷・在庫の山
              └──────────────────

 EDLP    価格 ┤ ────────────────      ← 常に安い
              │                           チラシ不要・作業平準化
              └──────────────────
                   客は「いつ行っても安い」と学習し、来店が分散する
```

ディスカウント勢の脅威は、ドラッグストアと違って**生鮮も安く売ってくる**点にある。
ロピアは精肉を、オーケーは生鮮全般を看板にしており、食品スーパーの「安全地帯」に入り込む。
→ [ディスカウントストア](../09_ディスカウントストア/README.md)

## 4. コンビニとの棲み分け

コンビニとは商圏（300〜500m vs 700m〜2km）も用途も違うため、
ドラッグストアほどの直接的な脅威ではない。しかし**惣菜では正面からぶつかる**。

| 軸       | コンビニ                          | 食品スーパー                     |
| -------- | --------------------------------- | -------------------------------- |
| 買う理由 | 今すぐ食べる／切らした物を1点だけ | 今晩と明日の食事をまとめて       |
| 単価     | 低い（500〜800円程度）            | 高い（2,000〜3,000円程度）       |
| 惣菜     | 工場製・常温/チルド。品質は均一   | **店内調理・作りたて・量が多い** |
| 価格     | 定価志向                          | 安い。夕方は値下げも             |
| 営業時間 | 24時間                            | 9〜22時が中心                    |

近年は**コンビニ側が苦戦し、スーパーの惣菜が伸びている**。日本惣菜協会「惣菜白書」
（2026年4月発表）によれば、2025年の中食市場11兆7,075億円のうちコンビニは3兆6,044億円で
最大規模を維持したものの成長は鈍化し、**食料品スーパーは前年比104.9%**と市場拡大を牽引した。
物価高で「コンビニは高い」という意識が強まり、量が多くて安いスーパーの惣菜に流れている。

## 5. ネットスーパー — 伸びるが儲からない

食品ECは市場としては伸びている。経産省「電子商取引に関する市場調査」によれば、2024年の
「食品、飲料、酒類」のBtoC-EC市場規模は**3兆1,163億円、EC化率4.29%**。
他分野（家電やアパレルは30〜40%台）と比べると**EC化率は極端に低い**。

しかし食品スーパー各社にとって、ネットスーパーは**やらざるを得ないが儲からない**事業である。

```
【 ネットスーパーが赤字になる理由（1注文あたりの試算） 】

  客単価 5,000円 ── 粗利率25% ──▶ 粗利 1,250円
       ├─ ピッキング（店員が店内を回って集める。1件20〜30分）  500〜800円
       ├─ 梱包・保冷資材                                      100〜200円
       └─ 配送（三温度帯・時間指定）                          400〜700円
                                   合計 1,000〜1,700円 ★粗利を食い尽くす
```

構造的な難しさは4つ。

1. **三温度帯物流**（常温・冷蔵・冷凍を分けて運ぶ）が要る。1台のトラックに区画が必要
2. **生鮮は客が自分で選びたい**。代替品の可否、鮮度の好みが人によって違う
3. **客単価が上がらない**。送料無料ラインを超える程度で止まる
4. **配送密度が低い**と1件あたりの配送コストが跳ね上がる。都市部でしか採算が見えない

ネットスーパーの実施率は業界推計で20.7%（2023年）まで上がったが、**総売上高に占める比率は
1.5%**にとどまる（業界推計）。市場規模は2026年に3,000億円超との予測もあるが（調査会社推計）、
食品スーパー全体16.8兆円（2025年）に対しては依然として小さい。
対策として、店舗の一角や専用拠点を**ダークストア**（客が入らないネット注文専用の小型拠点）
にして作業効率を上げる試み、複数社共同配送、外部プラットフォームへの商品供給が模索されている。
**「自前で全部やる」を諦めるかどうか**が分かれ目になっている。

## 6. 対抗手段(1) — PB強化と共同仕入れ

### PB（プライベートブランド）

PB＝小売が企画し自社ブランドで売る商品。メーカーのブランド（NB＝ナショナルブランド）の対義語。

| 観点     | NB（メーカー品）             | PB（自社ブランド）                             |
| -------- | ---------------------------- | ---------------------------------------------- |
| 粗利率   | 15〜25%                      | **25〜35%**                                    |
| 売価     | 定価がある。他店と比較される | 比較対象がない。**価格競争から逃げられる**     |
| 差別化   | できない（どこでも同じ）     | できる                                         |
| リスク   | なし                         | 売れ残りは自社責任。開発費も自社               |
| 必要条件 | なし                         | **一定の販売量**（最低ロットを引き取れること） |

> ポイント：PBの本質は「安いこと」ではなく、**比較不能にして値下げ圧力から逃れること**。
> ドラッグストアが加工食品を原価割れで売っても、PBなら直接比較されない。

### 共同仕入れ（ボランタリーチェーン）

PBを作るには販売量が要る。中堅・中小単独では無理なので、共同化する。
代表が**CGCグループ**（本部：シジシージャパン）。

| 項目           | 数値             | 時点                     |
| -------------- | ---------------- | ------------------------ |
| 加盟企業数     | 204社            | 2026年1月1日（同社公表） |
| 加盟店舗数     | 4,534店          | 同上                     |
| グループ総年商 | **5兆5,421億円** | 同上                     |
| 開発PB品目数   | 1,896品          | 同上                     |

2026年度は50カテゴリーの商品強化を重点項目に掲げたと報じられている（食品新聞、2026年1月）。
総年商5.5兆円はイオン、セブン&アイに次ぐ規模であり、**「PBの第3極」**と呼ばれる。

ボランタリーチェーン（VC）は、コンビニのフランチャイズチェーン（FC）とは別物である。
FCが本部と加盟店の**垂直的な契約**で屋号も運営もほぼ統一するのに対し、
VCは独立企業同士の**水平的な連合**で、各社は自社の屋号・品揃え・価格を保ったまま、
仕入れ・PB開発・システム・教育だけを共同化する（CGC、ニチリウ、全日食チェーンなど）。

VCは**「規模の経済だけを買って、地域密着を手放さない」**仕組みであり、
[商圏と出店](02_商圏と出店.md) で述べた地方スーパーの強さを制度的に支えている。

## 7. 対抗手段(2) — 値上げ下の値付けと節約志向

2022年以降の食品値上げは、食品スーパーにとって**追い風と逆風の両方**である。

```
【 値上げが損益に効く2つの経路 】

 (＋) 売価が上がる → 客単価が上がる → 売上高が伸びる
        ↑ 2025年の販売統計は全店103.9%（既存店102.8%）

 (−) 仕入原価が上がる → 転嫁が遅れると粗利率が落ちる
     消費者が買い控える → 買上点数が減る、安い店へ流れる
        ↑ 2026年6月の来客数DIは −13.2、収益DIは −10.5 とマイナス圏
```

**客単価は上がっているのに、買上点数と客数は減っている**——これが2026年の実態である。
「スーパーマーケット景気動向調査」（2026年7月調査／6月実績）では、販売価格DI +16.1・
客単価DI +8.1 とプラスである一方、来客数DI −13.2、売上高DI −6.6、収益DI −10.5 と
マイナス圏に転落した（**DI**＝「増えた」と答えた企業の割合から「減った」を引いた指数、0が横ばい。
全指標は [直近トピック 2026](04_直近トピック_2026.md) 第3章の表に）。同調査は「価格上昇による
一品単価の下支えは続いているものの、販売数量や買上点数は依然伸び悩み、生活者の節約志向、
生活防衛意識の強さがうかがえる」と述べている。

節約志向への対応として各社が打つ手は、おおむね次の3通り。

1. **PB・低価格ラインの拡充**（比較されない安さを作る）
2. **EDLPへの転換**（特売依存から抜ける）
3. **少量・小容量パック**（1回の支出額を抑えて買いやすくする）

## 8. 対抗手段(3) — 人手不足と省人化

食品スーパーは労働集約型で、粗利の約半分が人件費。
そこへ人手不足と最低賃金の上昇が重なっている。

「各種商品小売業」の**非正社員の不足率**は2023年4月56.9% → 2024年60.8% → 2025年62.5%と
上昇を続け（調査報道ベース）、最低賃金の全国加重平均も2024年度1,054円、2025年度は約1,090円へ上がった。

省人化の打ち手を効果と限界で整理するとこうなる。

| 打ち手                                          | 何が減るか               | 限界                                           |
| ----------------------------------------------- | ------------------------ | ---------------------------------------------- |
| **セミセルフレジ**（登録は店員、支払は客）      | レジの精算時間           | 登録作業は残る                                 |
| **フルセルフレジ**                              | レジ人員                 | 高齢客の抵抗、万引きロス増、サポート要員は必要 |
| **カートPOS**（買い物カートでスキャンして決済） | レジ工程ごと             | 端末の初期投資が大きい                         |
| **電子棚札（ESL）**                             | 値札貼り替え、値下げ作業 | 全店導入の投資が重い                           |
| **AI発注**                                      | 発注作業、ロス           | データ蓄積が要る。生鮮は相場変動で読みにくい   |

これに加え、生鮮の加工人員そのものを減らすプロセスセンター化・アウトパック化があるが、
特色が薄れる／加工賃が原価に乗るという代償を伴う
（→ [生鮮が決める商売](01_生鮮が決める商売.md)）。

> ポイント：省人化投資が効くのは**レジ・値札・発注**であって、
> **生鮮の加工作業ではない**。しかし人件費の大半はそこにある。
> だから省人化は「効くが、足りない」。最終的にはPC化か、生鮮を薄めるかの選択になる。

なお省人化投資には政府の支援もある。農林水産省・経済産業省は
「省力化投資促進プラン ―小売業―」（2025年6月）を示し、
中小小売の省力化投資を後押しする枠組みを整えている。

## 9. まとめ — 5つの圧力

```
   ドラッグストア ──▶┌────────────────┐◀── ディスカウント
   （一般食品・      │  食品スーパー   │    （価格訴求層を丸取り）
     非食品を奪う）  │                 │
                     │ 守れるのは      │◀── コンビニ（惣菜で競合）
   ネットスーパー ──▶│ 生鮮 と 惣菜    │
   （やらないと      └────────────────┘
     置いていかれる            ▲
     が、やると赤字）          │
              人手不足・最低賃金上昇・仕入原価上昇
```

食品スーパーの生き残り方は、突き詰めると次の3つのどれかである。

| 路線           | 具体策                                                       | 代表的な性格                   |
| -------------- | ------------------------------------------------------------ | ------------------------------ |
| **差別化路線** | 生鮮・惣菜を磨き、産直・地場産で特色を出す。価格では戦わない | 地域密着の中堅、高質スーパー   |
| **コスト路線** | EDLP、作業簡素化、SKU削減、PB比率向上。徹底的に安くする      | ディスカウント型               |
| **規模路線**   | M&A・統合で仕入とシステムの固定費を薄める                    | 大手、ボランタリーチェーン加盟 |

中途半端に全部やろうとした店から消えていく、というのが
2020年代後半の業界再編が示していることである。
→ [直近トピック 2026](04_直近トピック_2026.md)

## 用語メモ

| 用語                                     | 意味                                                                   |
| ---------------------------------------- | ---------------------------------------------------------------------- |
| **ロスリーダー**                         | 儲けを捨てて集客するための商品。ドラッグストアの食品がこれ             |
| **NB（ナショナルブランド）**             | メーカーが企画し自社ブランドで売る商品。どの店でも同じ                 |
| **PB（プライベートブランド）**           | 小売が企画し自社ブランドで売る商品。粗利が高く、価格比較されにくい     |
| **ボランタリーチェーン（VC）**           | 独立小売の水平連合。仕入れ・PBだけ共同化する。CGCなど                  |
| **フランチャイズチェーン（FC）**         | 本部と加盟店の垂直契約。運営をほぼ統一する。コンビニが代表             |
| **EDLP**                                 | Every Day Low Price。特売をやめ常時低価格にする方式                    |
| **Hi-Lo**                                | 特売で集客し他商品で粗利を取る従来型の方式                             |
| **SKU**                                  | 在庫管理上の品目単位。SKUを絞ると仕入価格が下がり在庫も減る            |
| **カットケース陳列**                     | 段ボールを切ってそのまま並べる陳列。品出し作業を減らす                 |
| **三温度帯物流**                         | 常温・冷蔵・冷凍を区分して運ぶ配送。ネットスーパーのコスト要因         |
| **ダークストア**                         | 客が入店しない、ネット注文専用の小型拠点                               |
| **ピッキング**                           | ネット注文の商品を店内・倉庫から集める作業。ネットスーパー最大のコスト |
| **DI（ディフュージョン・インデックス）** | 「増えた」と答えた企業の割合から「減った」を引いた指数。0が横ばい      |
| **セミセルフレジ／フルセルフレジ**       | 登録のみ店員が行う方式／全工程を客が行う方式                           |
| **カートPOS**                            | 買い物カートに端末を付け、商品を入れながらスキャン・決済する仕組み     |
