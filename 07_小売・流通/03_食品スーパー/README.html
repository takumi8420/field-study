1. 業界の定義・範囲

食品スーパー（SM＝スーパーマーケット）とは、セルフサービス方式で、
売場の過半を食品が占め、生鮮3部門を自前で扱う小売店舗を指す。
法律上の業態区分ではなく、統計や業界慣行による呼び名である。

経産省「商業動態統計」の「スーパー」は総合スーパー（GMS）を含むため、
食品スーパーだけを見るには業界3団体（全国スーパーマーケット協会、
日本スーパーマーケット協会、オール日本スーパーマーケット協会）の
「スーパーマーケット販売統計調査」を使うのが実務的である。

隣接業態との境界は次の通り。

業態 違い 参照
総合スーパー（GMS）食品に加え衣料・住居関連を大きく扱う。売場は数千坪級スーパー・GMS
コンビニ商圏300〜500m、24時間、即食中心。生鮮は扱わないコンビニエンスストア
ドラッグストア医薬品・化粧品が利益源。食品は集客用。生鮮は弱いドラッグストア
ディスカウントストア価格訴求に特化。生鮮を扱う企業も多く、境界は曖昧ディスカウントストア
食品EC・ネットスーパー店舗を持たない、または店舗から配送通販・D2C

「食品スーパー」と「ディスカウントストア」の境界は、近年ほぼ消えかけている。
オーケーやロピアは生鮮をフルに扱う食品スーパーでありながら、価格政策はディスカウント型である。
業態名より、価格政策（EDLPかHi-Loか）と生鮮の厚みで分類するほうが実態に合う。

※集計母体が異なるため数値は一致しない。「商業動態統計＝GMS込み」「3団体統計＝パネル270社」

成長性は「金額は伸びるが数量は伸びない」と見るのが正確である。
2022年以降の売上増は主に値上げによる単価上昇であり、来店客数と買上点数はむしろ減っている。
人口減少が数量の天井を押し下げ続けるため、
市場の実質的な成長余地はほぼない＝シェアの奪い合いという前提で読む必要がある。

6. 競争要因（KSF）と参入障壁

勝つための条件（KSF）

KSF なぜ効くか
生鮮と惣菜の質値段以外で選ばれる唯一の領域。来店頻度＝生命線を支える
立地とドミナント密度商圏人口が売上の上限を決める。集中出店で物流・加工・販促の固定費を割る
ロス管理と発注精度営業利益率2%の商売では、ロス率1ポイントが致命的
人の確保と定着生鮮加工は機械化しにくい。パート比率の高い職場で定着率が効く
PB比率と仕入規模比較されない商品を持つと価格競争から半歩逃げられる
省人化投資の体力セルフレジ、電子棚札、AI発注。最低賃金上昇への唯一の構造的対応

参入障壁

参入障壁は制度ではなく経済性にある。許認可はほぼ不要に近い（下記7章）一方で、

  • 良い立地が既に埋まっている。人口が増えるエリアは限られる
  • 単独店ではドミナントの効果が得られず、固定費を割れない
  • 生鮮のノウハウと人材（目利き、加工技能）は短期に作れない
  • プロセスセンターや物流網は数十店規模がないと回収できない

逆に言えば、既に店舗網とノウハウを持つ既存プレイヤー同士の買収が
最も合理的な参入手段になる。2025〜2026年の再編ラッシュはこの帰結である。

7. 規制・法制度

食品スーパーに固有の「業法」は存在しないが、複数の法令が横断的に効く。

法令・制度 効き方
食品衛生法営業許可（飲食店営業、食肉販売業、魚介類販売業など）。店内加工を行う以上、必須
HACCP（ハサップ）2021年6月から原則すべての食品事業者に義務化。衛生管理の手順書化と記録。バックヤードの作業負荷を押し上げた
食品表示法原材料・アレルゲン・原産地・消費期限の表示。生鮮・惣菜は表示作業が重い
大規模小売店舗立地法（大店立地法）売場面積1,000㎡超の店舗は、騒音・駐車場・交通への配慮を届出。出店のリードタイムを延ばす
独占禁止法・優越的地位の濫用納入業者への不当な値引き要求、協賛金、従業員派遣の要請を規制。公取委が小売を注視
下請法／取引適正化仕入先との取引条件。PB委託でも適用されうる
食品ロス削減推進法（2019年施行）廃棄削減の努力義務。「3分の1ルール」など商慣行の見直しが進む
最低賃金法全国加重平均は2024年度1,054円、2025年度約1,090円。パート比率が高い業態に直撃
省力化投資支援（省力化投資促進プラン ―小売業―、2025年6月）中小小売の省人化設備投資を後押し

かつて最大の障壁だった大規模小売店舗法（大店法）は2000年に廃止され、
出店規制は「需給調整」から「周辺環境への配慮」（大店立地法）へ転換した。
この規制緩和が2000年代以降の出店競争と、今日の過当競争の出発点になっている。
