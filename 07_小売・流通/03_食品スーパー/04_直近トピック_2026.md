# 直近トピック（2026年9月時点）

報道・統計ベースの整理。数値は一次情報（業界団体統計・企業IR・官公庁）を優先したが、
一部は報道・調査会社推計を含む。その場合は本文に明示した。
構造的な背景は [生鮮が決める商売](01_生鮮が決める商売.md)、
[商圏と出店](02_商圏と出店.md)、[競争環境](03_競争環境.md) を参照。

## 1. 食品値上げは「常態化」フェーズへ — 2026年は年間1.8万品目超

値上げは終わっていない。むしろ2026年は再加速した。

| 期間                             | 値上げ品目数                    | 出典                                               |
| -------------------------------- | ------------------------------- | -------------------------------------------------- |
| 2025年（通年）                   | 2万609品目（2024年比 64.6%増）  | 帝国データバンク「食品主要195社 価格改定動向調査」 |
| 2026年1〜5月                     | 4,197品目                       | 同上                                               |
| 2026年7月                        | 2,269品目（4月以来の最大波）    | 同上                                               |
| 2026年9月                        | 4,531品目（単月で2026年内最多） | 同上                                               |
| 2026年10月（見通し）             | 3,033品目                       | 同上（2026年9月公表分）                            |
| **2026年 累計（1〜11月判明分）** | **1万8,347品目**                | 同上                                               |

値上げの理由は原材料高が圧倒的である。2026年の値上げ品目のうち**90.7%が「原材料高」**、
**65.1%が「エネルギー」**を要因に挙げ、中東情勢の影響を挙げたものも27.8%あった
（帝国データバンク調査、報道ベース）。

食品スーパーから見ると、これは次の二面性を持つ。

```
 値上げ  ──┬──▶ 売価が上がる → 客単価が上がる → 売上高は伸びる
           │        2025年通年：全店 103.9% ／ 既存店 102.8%
           │
           └──▶ 仕入原価が上がる → 転嫁が遅れると粗利が削られる
                  消費者が買い控える → 買上点数が減る
                    2026年6月：来客数DI −13.2、収益DI −10.5
```

> ポイント：**売上は伸びているのに収益は悪化している**。
> 「増収」というヘッドラインだけ見ると業界の苦しさを見誤る。

## 2. コメ価格 — 高騰のピークから約25%下落、ただし平年比では高止まり

2024〜2025年の「令和の米騒動」で跳ね上がったコメ価格は、2026年に入って明確に下落した。
コメは一般食品の中でも構成比が大きく、**主食であるため客の価格感度が極端に高い**商品である。

| 時点                       | スーパー店頭のコメ5kg平均売価 | 出典・注                                         |
| -------------------------- | ----------------------------- | ------------------------------------------------ |
| 2025年秋（新米流通開始時） | 4,200円前後                   | 調査会社集計・報道ベース                         |
| 2026年6月21日              | **3,179円**                   | 備蓄米放出後の最安値を更新（PR TIMES発表の調査） |
| 2026年8月31日〜9月6日      | **3,003円**（税込）           | 報道ベース                                       |
| 令和8年産の見通し          | 3,000〜3,500円程度            | 報道・推計                                       |

ピーク比で**約25%（約1,000円）の下落**。ただし米騒動前の水準（5kg 2,000円前後）
と比べるとなお高く、「下がったが安くはない」状態である。

食品スーパーへの影響は次の通り。

1. **一般食品部門のマイナス要因になった**。2026年6月の一般食品DIは −15.2。
   協会の景気動向調査は「前年の備蓄米放出による特需の反動もあり、
   マイナス幅が拡大した」と明記している。前年に備蓄米で膨らんだ売上の反動が出ている
2. **客の目玉商品としての機能が戻る**。コメは「あの店は米が安い」で来店動機になる商品。
   価格が落ち着いたことで、再び集客の武器として使える
3. **ただし銘柄米は下がらない**。銘柄米は5kg税込4,500円超との報道もあり、
   **価格の二極化**（安い銘柄・ブレンド米と、高価格の銘柄米）が起きている

> ポイント：コメの「価格が下がった」は消費者には朗報だが、
> スーパーの売上統計では**前年の高値の反動でマイナス**として現れる。
> 数量が回復しても金額ベースでは前年割れになりうる、という読み方が要る。

## 3. 2026年6月、景況感が一段と悪化 — 売上DI・収益DIがマイナス圏へ

全国スーパーマーケット協会ほか2団体の「スーパーマーケット景気動向調査」
（2026年7月調査／6月実績、2026年7月21日公表）は、業界の温度を最も直接に示す。

| 指標（2026年6月実績）    | 当月DI    | 前月からの変化            |
| ------------------------ | --------- | ------------------------- |
| 景気判断DI（現状）       | 41.7      | −5.7（大幅悪化）          |
| 景気判断DI（見通し）     | 41.0      | −1.5                      |
| 消費者購買意欲DI（現状） | 41.2      | −3.3                      |
| **売上高DI**             | **−6.6**  | −15.4（プラス圏から転落） |
| **収益DI**               | **−10.5** | −12.5（プラス圏から転落） |
| 客単価DI                 | +8.1      | −5.0                      |
| **来客数DI**             | **−13.2** | −9.2                      |
| 販売価格DI               | +16.1     | −1.7                      |
| 生鮮品仕入原価DI         | +13.5     | −6.3                      |
| 食品仕入原価DI           | +15.7     | −5.1                      |

カテゴリー別では、青果 +2.5、水産 +7.4、畜産 +6.4、惣菜 +4.0 と
**生鮮4部門はプラス圏を維持**した一方、日配 −7.9、一般食品 −15.2、非食品 −9.2 と
それ以外が総崩れになった。

```
【 2026年6月の構図 】

  販売価格 DI +16.1   ← 値上げは続いている
       ＋
  客単価   DI  +8.1   ← 1点あたりは高くなった
       −
  来客数   DI −13.2   ← 客が減った
       −
  （買上点数も減少）
  ─────────────────
  売上高   DI  −6.6   ← 単価上昇で埋め切れなかった
       −
  仕入原価 DI +13.5〜15.7  ← コストは上がり続けている
  ─────────────────
  収益     DI −10.5   ★ 値上げだけでは利益が守れない局面に入った
```

協会は「価格上昇による一品単価の下支えは続いているものの、
販売数量や買上点数は依然伸び悩みが続き、生活者の節約志向、生活防衛意識の強さがうかがえる」
「売上確保と利益確保の両立が引き続き課題」と総括している。

※6月は前年より日曜日が1日少ない曜日回りの影響もあるため、単月のブレは差し引いて読む必要がある。

## 4. 節約志向の深まり — 「値上げに慣れた」のではなく「削る対象を変えた」

2026年4月の値上げを受けた調査では、**71.2%が「節約意識がさらに高まった」**と回答した
（報道ベースの消費者調査）。具体的な行動は次の通り。

| 節約行動                   | 回答率 |
| -------------------------- | ------ |
| 高いと感じる食材を買わない | 64.4%  |
| 割引品を選ぶ               | 52.0%  |
| 安い食材で代用する         | 43.5%  |

その結果として「食材やレシピの固定化（マンネリ化）」55.5%、
「味や品質を妥協しなければいけない」39.0%、「おかずの品数が減った」33.1%といった
生活の質の低下も報告されている（同調査、報道ベース）。

食品スーパーにとって重要なのは、**「割引品を選ぶ」が52%**という点である。
これは値下げ（見切り）商品への依存度が上がるということで、
[生鮮が決める商売](01_生鮮が決める商売.md) で触れた**ロス率と粗利のせめぎ合いを悪化させる**。
夕方の見切り品狙いの客が増えれば、廃棄は減るが粗利率は落ちる。

## 5. 業界再編が一段と加速 — 「出店」から「買収」へ

2025〜2026年は、食品スーパーの歴史上でも突出した再編期になった。

| 時期           | 内容                                                                                       | 規模・効果                                |
| -------------- | ------------------------------------------------------------------------------------------ | ----------------------------------------- |
| 2024年11月     | U.S.M.H（ユナイテッド・スーパーマーケット・ホールディングス）が**いなげや**を完全子会社化  | 26年2月期売上9,637億円（前年比18.8%増）   |
| 2025年3月〜7月 | **トライアルホールディングスが西友を買収**（約3,800億円、7月1日に全株式取得完了）          | 合算売上1兆2,000億円規模。店舗数352→611店 |
| 2025年10月     | ブルーゾーンHDが**文化堂・デライトHD**を子会社化                                           | 26年3月期売上8,131億円                    |
| 2026年3月1日   | U.S.M.H傘下のマックスバリュ関東が**イオンマーケットとダイエーの関東事業を統合**            | 27年2月期見通し1兆1,332億円               |
| 2026年4月1日   | **イズミヤ・阪急オアシスが関西スーパーマーケットと合併**、社名を関西フードマーケットに変更 | H2O系食品スーパーの統合。各ブランドは維持 |

2026年の食品スーパー売上ランキング上位（各社決算、ダイヤモンド・チェーンストアオンライン集計）。

| 順位 | 企業                       | 売上高                     | 決算期    |
| ---- | -------------------------- | -------------------------- | --------- |
| 1    | **U.S.M.H**                | 9,637億円（前年比18.8%増） | 26年2月期 |
| 2    | **ライフコーポレーション** | 8,809億円（同3.6%増）      | 26年2月期 |
| 3    | **フジ**                   | 8,142億円（同0.7%増）      | 26年2月期 |
| 4    | **ブルーゾーンHD**         | 8,131億円                  | 26年3月期 |
| 5    | **オーケー**               | 7,556億円（同10.0%増）     | 26年3月期 |

食品スーパー286社の総売上高は**20兆1,154億円**（前年295社で19兆7,089億円）と、
**集計企業数が減ったのに総額は4,065億円増えた**（同集計）。
これが再編の実態を最もよく表している。**退出と統合が同時に進んでいる**のである。

読み解きのポイントは次の3つ。

1. **「1兆円クラブ」の形成**。U.S.M.Hが27年2月期に1兆円超の見通し、
   トライアル＋西友は既に1.2兆円規模。仕入交渉力とシステム投資で規模が効く局面に入った
2. **買収が出店の代替手段になった**。良い立地が空いていないため、
   店舗網ごと買うほうが速い → [商圏と出店](02_商圏と出店.md)
3. **PMI（統合作業）には数年かかる**。トライアルHDは今後3年（2027年6月期〜2029年6月期）を
   西友のPMIと流通改革の基盤づくりの期間と位置づけていると報じられている。
   **売上が足された瞬間と、シナジーが出る瞬間は数年ずれる**

## 6. ドラッグストアの食品攻勢は止まらない

日本チェーンドラッグストア協会によると、2024年度のドラッグストア約2万店の推定総売上高は
**前年度比9%増の10兆307億円**と初めて10兆円を超えた。
カテゴリー別構成は調剤・ヘルスケア33.2%、**フーズ・その他28.2%**、
ホームケア20.3%、ビューティーケア18.2%。
フーズ・その他は**前年比13.2%増の2兆8,329億円**と、業態全体の伸びを上回った。

一方、スーパーマーケットの**非食品は2025年通年で前年比99.0%（既存店98.7%）とマイナス**。
日用品・医薬化粧品の売場がドラッグストアに移っていることが統計に表れている。

北陸ではクスリのアオキ、Genky DrugStores などの食品強化型ドラッグストアが
エリアによってスーパーの売上を追い抜いたと報じられている（日経クロストレンド）。
食品スーパー側は調剤薬局の買収やドラッグストアとの共同出店で対抗し始めている
（ダイヤモンド・チェーンストアオンライン）。

構造的な理由（なぜドラッグストアの食品は安いのか）は
[競争環境](03_競争環境.md) の第2章にまとめた。

## 7. 全体の構図（まとめ）

```
  【 需要側 】値上げ継続（2026年1.8万品目超）→ 客単価↑ だが 客数・買上点数↓
                     ＋ 節約志向71.2% ＋ コメ価格はピーク比−25%（前年の反動でマイナス寄与）
                                    ↓
  【 店の損益 】売上高DI −6.6 ／ 収益DI −10.5（2026年6月）
                仕入原価DI +13〜16、人件費上昇（最賃1,090円台）、電気代
                                    ↓
  【 競争 】ドラッグストア（食品2.8兆円・13.2%増）が非食品と一般食品を奪う
            ディスカウント勢が価格訴求層を奪う／ネットスーパーは伸びるが赤字
                                    ↓
  【 業界の答え 】規模の追求 ＝ M&A・統合（1兆円クラブの形成）
                  差別化の追求 ＝ 生鮮と惣菜（唯一の安全地帯）
                  効率の追求   ＝ EDLP化、省人化投資、PB強化
```

2026年の食品スーパーを一言でまとめるなら、
**「値上げで売上は伸びたが、利益は守れなくなった年」**である。
2022〜2025年は値上げが客単価を押し上げて増収増益を演出できたが、
2026年に入って客数の減少が単価上昇を上回り始めた。
ここから先は、**値上げ以外の方法で利益を作れる会社だけが残る**局面に入る。
その方法が、規模（M&A）か、差別化（生鮮・惣菜）か、効率（EDLP・省人化）かの三択である。

## 用語メモ

| 用語                                     | 意味                                                                                    |
| ---------------------------------------- | --------------------------------------------------------------------------------------- |
| **DI（ディフュージョン・インデックス）** | 「増えた」と答えた企業の割合から「減った」を引いた指数。0が横ばい。景況感DIは50が横ばい |
| **令和の米騒動**                         | 2024年以降のコメ品薄・価格高騰。2026年にかけて価格は下落に転じた                        |
| **備蓄米**                               | 政府が不作・不足に備えて保有するコメ。2025年に放出され一時的な特需を生んだ              |
| **PMI**                                  | Post Merger Integration。M&A後の統合作業。店舗網・システム・人事の統合に数年かかる      |
| **買上点数**                             | 客1人が1回の買い物で買う商品の点数。節約局面で真っ先に減る                              |
| **フーズ・その他**                       | 日本チェーンドラッグストア協会の区分で食品カテゴリー。2024年度2兆8,329億円              |
