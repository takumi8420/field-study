# ③ 業界再編と生き残り — 市場が伸びないなかで、誰が誰を買っているか

このノートで分かること：ホームセンター（HC）市場が3兆〜4兆円で頭打ちになったあと、
業界が**「出店で伸びる」から「買収で伸びる」**へ切り替わった経緯。
カインズ・DCM・コーナン・コメリ・アークランズら主要陣営の立ち位置と、
PB（プライベートブランド）強化・プロ特化・EC対応という3つの生き残り策。

> 結論：HCの再編は **「市場が伸びないのに店だけ増えた」** ことへの答えである。
> 1店あたり売上が細るなか、各社は**仕入れ規模とPB開発費を分担できる相手**を探した。
> 2026年は、コーナン商事によるアレンザHDのTOB成立と、
> ジョイフル本田×アークランズの経営統合合意という
> **業界地図を塗り替える2件**が同じ年に起きた年である。

## 1. まず「なぜ再編するのか」を数字で押さえる

再編の理由は、たった2つの数字の交差で説明できる。

```
【市場は横ばい、店舗数は増え続けた】

  市場規模（日本DIY・HC協会推計）        店舗数
  4.3兆 ┤        ╭╮ 4兆2,680億(2020)      5,080 ┤              ╭──
  4.0兆 ┤ ────╯ ╰──────── 4兆130億(2025)  4,800 ┤        ╭────╯
  3.5兆 ┤                                  4,300 ┤ ╭────╯
        └──┬────┬────┬────┬────┬          4,000 └─┬────┬────┬────┬
          2010  2015  2020  2023  2025            2010 2015 2020 2025

  1店あたり売上 ＝ 市場 ÷ 店舗数
    2010年  3兆8,450億 ÷ 4,180店 = 約 9.2億円
    2020年  4兆2,680億 ÷ 4,860店 = 約 8.8億円
    2025年  4兆  130億 ÷ 5,080店 = 約 **7.9億円**  ← 15年で約14%減
```

（日本DIY・ホームセンター協会の年間総売上高・店舗数の推計値より算出。
1店あたり売上は筆者の計算）

**店を増やしても市場のパイは増えない**。この状態で利益を出す方法は2つしかない。

| 方法                 | 具体策                                       | 必要なもの                                       |
| -------------------- | -------------------------------------------- | ------------------------------------------------ |
| **粗利率を上げる**   | PBを増やし、メーカー品への依存を減らす       | 開発人員、最低発注ロットを消化できる**販売規模** |
| **コスト率を下げる** | 仕入れの集約、物流センター共用、システム統合 | やはり**規模**                                   |

どちらも「規模」が前提になる。しかし新規出店で規模を作ろうにも、
市場が伸びていないので新店は既存店の客を奪うだけ（カニバリゼーション）。
**だから買うしかない**。これが再編の力学である。

> ポイント：HCの再編は「弱い会社が身売りする」話ではない。
> **PBを作るための最低ロットを消化できる販売規模**を、
> 自社の成長では間に合わないので買って埋めている、という話である。

## 4. 生き残り策① — PB（プライベートブランド）を厚くする

**PB＝小売が企画し、製造を委託して自社ブランドで売る商品**。
メーカー品（NB）と違って売価を自分で決められるので、粗利率が5〜15ポイント高くなる。

| 企業               | PB比率                    | 目標・特徴                                                 |
| ------------------ | ------------------------- | ---------------------------------------------------------- |
| **カインズ**       | **約40%**（約1万3,000種） | PB開発を成長の中核に据える。デザイン家電・収納で評価を確立 |
| **コメリ**         | 約4割台との指摘           | 農業・金物という専門領域でのPB                             |
| **DCM**            | **30.1%**（2024年度）     | **2030年度に50%**を目標に掲げる                            |
| （参考）ワークマン | **71.9%**（2026年3月期）  | PB売上1,501億円・+19.9%。HCより一段上の水準                |

（各社IR・流通ニュース等の報道ベース）

PBを増やすと何が起きるか。良い面と悪い面の両方を押さえる。

```
【NB中心の店】                    【PB中心の店】

 メーカーが値段を決める            自分で値段を決められる
   │                                │
   ▼                                ▼
 どの店でも同じ商品                 比べられない（比較不能）
   │                                │
   ▼                                ▼
 価格比較で削られる                 粗利率 +5〜15pt
 粗利率 20〜28%                     粗利率 30〜45%
   │                                │
   ▼                                ▼
 売れ残りはメーカー返品も可         **売れ残りは全部自分の損**
 開発費ゼロ                         **開発費・最低ロット・金型は自社負担**
```

つまりPBは**「粗利率と引き換えに在庫リスクと開発費を自分で背負う」**取引である。
最低ロットを売り切るには販売規模が要る。
**PB比率を上げたいから規模が要る → だからM&Aする**という連鎖が、前節の年表の背景にある。

## 5. 生き残り策② — プロ特化（建デポ型）

[② 品揃えと客層の二面性](02_品揃えと客層の二面性.md)で見たとおり、
プロ市場は**6兆円規模**と試算され、3〜4兆円のHC市場より大きい。

| 取り組み               | 実績・数値                                                     |
| ---------------------- | -------------------------------------------------------------- |
| コーナン商事のプロ業態 | グループ売上の**約3割**。建デポ取得（2019年・約240億円）が転機 |
| コメリのPRO業態        | 2026年3月期に**+7.3%**成長。全体（+1.6%）を大きく上回る        |
| 営業時間               | プロ向けは**朝6:30〜7:00開店、20〜21時閉店**が標準             |

プロ特化が効く理由は、HCの弱点をちょうど裏返しているからである。

| HCの弱点                    | プロ特化で何が変わるか                                               |
| --------------------------- | -------------------------------------------------------------------- |
| 坪効率が低い（90〜120万円） | 倉庫型の粗い什器で坪単価を抑え、**高単価をまとめ買い**してもらう     |
| 在庫が回らない（年5回転）   | **同じ商品が毎日出る**ので回転が上がる                               |
| 来店頻度が低い（月1回）     | **週3〜5回**の来店                                                   |
| ECに流出する                | 「今日いる」「重い」「量が読めない」は**ECが最も不得意**             |
| 接客に人を割けない          | 決め打ちで買うので**接客が要らない**（代わりに与信・配送に人が要る） |

一方で、プロ特化には固有の難しさもある。

- **粗利率が20〜25%に下がる**。薄利多売なので、物流費・人件費の上昇に弱い
- **掛け売りの与信リスク**。建設業の倒産が増える局面では売掛金が焦げ付く
  （→ [ゼネコン](../../12_建設・住宅・不動産/01_ゼネコン/README.md)、
  [土木・インフラ維持](../../12_建設・住宅・不動産/05_土木・インフラ維持/README.md)）
- **建材卸・工具商社という既存プレイヤーとの正面衝突**
  （→ [建材](../../12_建設・住宅・不動産/13_建材/README.md)、
  [機械商社](../../06_商社・卸売/04_機械商社/README.md)）
- **建設需要そのものが人手不足で頭打ち**。職人が減れば資材も減る

## 6. 生き残り策③ — ECと専門業態への対応

### ECとの関係

HC業界のEC化率は、BtoC物販全体の国内EC化率（2023年で9.38%）を**下回る**とみられている。
理由は単純で、**重くて大きい商品は送料が商品代を超える**から。

```
【HCの商品とECの相性】

  送料が効かない ←─────────────────────────▶ 送料で負ける
   ビス1袋 300円          塗料 3,000円         合板1枚 2,000円
   （送料のほうが高い）    （ぎりぎり）          （送料が商品代を超える）
       ↑                                              ↑
   ECが取りにくい                              ECが絶対に取れない
   （でも客も買いに来ない）

  ★ECに最も奪われるのは「軽くて単価が高い」もの
     → 電動工具、消耗品、ペットフード（定期便）、日用品
  ★HCに残るのは「重くて単価が安い」もの
     → 坪効率が最も低いカテゴリー
```

各社の対応は、**EC専業と正面から戦わず、店舗を物流拠点として使う**方向に収れんしている。
ネット注文・店舗受取（BOPIS）、店舗在庫の可視化、プロ向けの現場配送がその中身である
（→ [倉庫・3PL](../../13_運輸・物流/08_倉庫・3PL/README.md)）。

一方、**間接資材のEC**は明確な脅威である。
モノタロウは取扱商品**2,866万点以上**をうたい、事業者向けに翌日配送を提供する。
「在庫の確実性」というプロ業態の強みに、正面から挑んでいる。

### 専門業態の台頭

もう1つの脅威が、HCの1カテゴリーを切り出して専業化したプレイヤーである。

| 専門業態                                                                                                       | 奪ったカテゴリー         | 規模                                                                                        |
| -------------------------------------------------------------------------------------------------------------- | ------------------------ | ------------------------------------------------------------------------------------------- |
| **ワークマン**                                                                                                 | 作業服・作業用品・安全靴 | 2026年3月期 チェーン全店売上**2,092億円**（+14.3%）、営業利益296億円（+21.7%）、**1,094店** |
| ニトリ・[家具・インテリア](../../12_建設・住宅・不動産/14_家具・インテリア/README.md)                          | 家具・収納・カーテン     | ─                                                                                           |
| [ペット専門店](../../15_サービス・生活関連/27_ペット関連/README.md)                                            | ペットフード・用品・生体 | ─                                                                                           |
| [ドラッグストア](../04_ドラッグストア/README.md)・[ディスカウントストア](../09_ディスカウントストア/README.md) | 日用品・消耗品           | ─                                                                                           |
| モノタロウ等の現場向けEC                                                                                       | 間接資材・工具           | ─                                                                                           |

ワークマンが示したのは、**「HCの1コーナーでも、専業化して商品を作り込めば
2,000億円の事業になる」**という事実である。
HCは同じ商品を「ついでに売る」ので、商品開発の密度で勝てない。

> ポイント：HCの敵はAmazonだけではない。
> **自分の売場の1列を切り出して専業化した会社**が、カテゴリーごとに存在する。
> 総合業態が専門業態に削られるのは百貨店やGMSと同じ構図で、
> HCも[スーパー・GMS](../02_スーパー・GMS/README.md)が通った道を歩いている。

## 7. これから何が起きそうか

2026年時点で観測できる方向は、大きく4つ。

| 方向                       | 中身                                        | 根拠                                                           |
| -------------------------- | ------------------------------------------- | -------------------------------------------------------------- |
| **1兆円企業の出現**        | 陣営同士の統合が進み、売上1兆円級が生まれる | 業界紙が「1兆円企業時代へ」と報じる。現状は5,000億円台が3社    |
| **プロ比率の上昇**         | グループ売上に占めるプロ業態が3割→5割へ     | コーナンの約3割、コメリPROの+7.3%成長                          |
| **異業態との資本提携**     | 食品スーパー・外食との複合                  | コーナン×バロー（アレンザHD共同保有）、アークランズ×ロピア協業 |
| **不振店の閉鎖と跡地転用** | 1,000坪級の箱が市場に出る                   | 12社中5社しか増収増益を達成できていない（2026年決算）          |

一方で、統合には固有のリスクもある。
2026年7月には**アークランズ子会社の不適切会計の疑義**により、
ジョイフル本田との統合日程が未定になったと報じられた。
**統合の合意と実行の間には、必ず会計・システム・人事の統合作業がある**。
発表だけで業界地図を書き換えないことも、あわせて押さえておきたい。

```
【HCが取りうる3つの道】

           高い粗利
              ▲
              │
   PB特化型   │   専門特化型
   （カインズ）│   （コメリ＝農業・金物）
              │
  ────────────┼────────────▶ 来店頻度・実需
              │
   総合大箱型  │   プロ特化型
   （従来のHC）│   （コーナンPRO・建デポ）
              │
              ▼
           低い粗利

  ★左下（総合大箱型・低粗利・低頻度）が最も苦しい。
    どの会社も、そこから上か右へ抜け出そうとしている。
```

## 用語メモ

| 用語                      | 意味                                                                                                  |
| ------------------------- | ----------------------------------------------------------------------------------------------------- |
| **TOB（株式公開買付け）** | 買付価格・期間・株数を公告して市場外で株式を買い集める手法。2026年のコーナン→アレンザHDが典型例       |
| **持分法適用関連会社**    | 議決権の20〜50%程度を保有し、重要な影響力を持つ会社。利益の持分だけを連結に取り込む                   |
| **株式移転**              | 既存の複数社が新しく共同持株会社を作り、その傘下に入る方式。ジョイフル本田×アークランズが採用         |
| **カニバリゼーション**    | 自社の店同士で客を奪い合うこと。市場が伸びない局面で新規出店の効果を打ち消す                          |
| **PB比率**                | 売上高に占めるプライベートブランド商品の割合。粗利率と連動する最重要のKPI                             |
| **BOPIS**                 | Buy Online, Pick-up In Store。ネットで買って店で受け取る仕組み。送料を回避しつつ来店も作れる          |
| **EC化率**                | 商取引全体に占めるEC（電子商取引）の割合。日本のBtoC物販全体は2023年で9.38%、HCはこれを下回るとされる |
| **間接資材（MRO）**       | Maintenance, Repair and Operations。製品にはならないが現場の維持運営に必要な資材。モノタロウの主戦場  |
| **スーパーセンター**      | HCに食品・衣料を加えた超大型のワンストップ店。アークランズとロピアの協業などが該当                    |
| **営業収益**              | 売上高に賃料収入・サービス収入等を加えた収益の総称。企業間で順位を比べるときは中身の確認が必須        |
