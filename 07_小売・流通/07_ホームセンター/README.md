# ホームセンター

- 大分類: 小売・流通
- 状態: done
- 更新日: 2026-09-20

ホームセンター（HC）は、DIY資材、園芸、日用品、ペット用品などを郊外の大きな売場で扱う小売業。
本質は**「坪あたりでは稼げない商品を、安い土地・少ない人手・大量の在庫で成立させる」**ことにある。

> 市場は約4兆円で20年近く横ばいなのに店舗数は増えた。
> したがって現在の競争は、店を増やすことより、PBで粗利を上げる、プロ客の頻度を取る、
> M&Aで調達・物流を共同化する、という**1店舗あたりの生産性改善**へ移っている。

## 1. 業界の定義・範囲

HCは、住まいの維持・改善に必要な資材と生活用品を、原則セルフサービスで販売する業態である。
標準店は600〜1,000坪、スーパーセンター型は1,800〜2,400坪に達し、広い平面駐車場を持つ。

| 隣接業態 | 境界線 |
| --- | --- |
| [ドラッグストア](../04_ドラッグストア/README.md) | 日用品は重なるが、HCは建材・工具・園芸・大型品が核 |
| [家電量販](../06_家電量販/README.md) | 家電は重なるが、HCは住設・修繕と一緒に売る |
| [ディスカウントストア](../09_ディスカウントストア/README.md) | 安さは共通。HCは住関連の専門性と加工・配送を持つ |
| 建材・金物卸 | プロ向けHCは卸に近いが、店頭在庫を持ち現金販売する点が違う |
| [住宅設備機器](../../12_建設・住宅・不動産/12_住宅設備機器/README.md) | HCは販売・施工窓口、設備メーカーは製造側 |

## 2. 市場規模と成長性

| 指標 | 直近値 | 出典・注意 |
| --- | ---: | --- |
| 業界推計売上高 | **4兆130億円** | 2025年、日本DIY・ホームセンター協会 |
| 店舗数 | **5,080店** | 2025年、同協会 |
| 商業動態統計の販売額 | **3兆3,917億円**、前年比▲0.2% | 2025年、経済産業省 |
| コロナ特需のピーク | 4兆2,680億円 | 2020年、協会推計 |

協会推計と商業動態統計は対象範囲が違うため、金額を直接比較しない。
構造的には2005年ごろから4兆円前後で横ばいで、2020年の巣ごもり・DIY特需は剥落した。
一方で店舗数は増え、協会統計から計算した1店あたり売上は2010年比で約14%減っている。

## 3. バリューチェーン

```
素材メーカー ─▶ 工具・建材・日用品メーカー ─▶ 卸/共同仕入れ ─▶ HC店舗 ─▶ 消費者
                                      │                    ├─ DIY客
海外OEM ─────────▶ PB企画・直接輸入 ───┘                    ├─ 職人
                                                           └─ 農家
                         HC ─▶ 配送・木材カット・施工会社 ─▶ 現場
```

NB（メーカー品）は価格比較されやすく粗利が薄い。大手はPB（自社企画商品）と直接輸入で
メーカー・卸の取り分を内製化する。一方、リフォームや現場配送では施工・物流の管理能力が必要になる。

## 5. 収益モデル・コスト構造

標準的な郊外店を年商9億円と置いた説明モデルでは、粗利率32%、人件費率12%、
地代家賃4%、営業利益率4〜6%程度になる。

```
客数 × 客単価 ＝ 売上
売上 − 商品原価 ＝ 粗利
粗利 − 人件費 − 地代 − 物流 − 償却 − 光熱費 ＝ 営業利益
                           ↑
             広い売場と駐車場は売上が落ちても縮まない
```

| 指標 | 目安 | なぜ重要か |
| --- | ---: | --- |
| 坪あたり年商 | 90〜120万円 | コンビニの約7分の1。地代の安さが前提 |
| 粗利率 | 32〜35% | PB比率と商品ミックスで上がる |
| 在庫回転 | 年5回前後 | 数万〜10万SKUに現金が寝る |
| 営業利益率 | 4〜6% | 人件費・物流費・値下げで簡単に削られる |
| GMROI | 粗利額÷平均在庫原価 | 在庫が生む粗利を測る中心指標 |

## 6. 競争要因（KSF）と参入障壁

| 成功要因 | 理由 |
| --- | --- |
| 安い土地を確保する | 低い坪効率を成立させる最初の条件 |
| PBを共同開発・大量調達する | 粗利率を上げ、他店との単純比較を避ける |
| 在庫を店舗間で最適化する | 品揃えを保ちながら死に筋を減らす |
| プロ客の欠品を防ぐ | 頻度が高く、必要な規格が無いと店を乗り換える |
| 加工・配送・施工まで提供する | ECでは代替しにくい「今すぐ使える」を作る |

参入障壁は、広い物件だけでなく、SKU管理、全国調達、物流、危険物を含む法令対応、
プロに信用される品揃えである。大箱を建てただけでは回らない。

## 7. 規制・法制度

| 制度 | HCへの影響 |
| --- | --- |
| 大規模小売店舗立地法 | 交通、騒音、廃棄物など出店時の調整が必要 |
| 都市計画法・用途地域 | 郊外大規模店を建てられる場所を制約 |
| 消防法・危険物規制 | 灯油、塗料、溶剤、ガスボンベ等の保管・販売 |
| 農薬取締法・肥料法 | 農薬・肥料の表示、販売、保管管理 |
| 電気用品安全法等 | 工具・家電・資材の安全表示とリコール対応 |
| 建設業法等 | リフォームを請け負う場合の許可・施工管理 |

HCは「何でも売る」ため、単一の業法より**商品カテゴリーごとの規制を横断管理する負担**が大きい。

## 8. 最近のトピック

詳細は [④ 直近トピック（2026年9月）](04_直近トピック_2026.md)。

1. 2025年市場は協会推計4兆130億円、5,080店。市場横ばい・店舗増で1店が細る
2. 2026年2〜3月期は主要社で「増収でも減益」が目立ち、人件費・物流費・在庫が圧迫
3. コーナンによるアレンザHDへのTOBが成立し、食品スーパー資本を交えた再編が進んだ
4. ジョイフル本田とアークランズの統合は合意後に日程未定となり、統合リスクも表面化
5. コメリPROやコーナンPROなど、職人・農家向けが総合店を上回って成長
6. ワークマンのようなカテゴリー専門店が、HCより高い利益率で売場を切り取っている

## 9. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **HC** | Home Center。ホームセンターの略称 |
| **坪効率** | 売上高÷売場坪数。広さが売上を生む効率 |
| **PB / NB** | PBは小売の自社企画品、NBはメーカー共通ブランド品 |
| **SKU** | 色・サイズ・規格まで分けた在庫管理の最小単位 |
| **GMROI** | 在庫原価1円が何円の粗利を生んだかを見る指標 |
| **プロ業態** | 職人・工事業者・農家向けに資材と早朝営業、現場配送等を提供する店 |
| **持分法適用会社** | 支配まではしないが重要な影響力を持ち、利益の一部を連結に反映する会社 |
