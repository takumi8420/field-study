この1年のホームセンター（HC）業界を一言でいうと 「市場は微減、利益は減、再編は加速」。
2026年2〜3月期決算では上場12社のうち増収増益を達成できたのは5社のみ。
その一方で、コーナン商事によるアレンザHDのTOB成立（3月）と、
ジョイフル本田×アークランズの経営統合合意（4月）という大型案件が続いた。
ただし後者は7月に会計処理の疑義で日程未定となり、統合の難しさも同時に露呈した。

3. コーナン商事 × アレンザHD — TOB成立と「食品スーパーとの共闘」

日付 出来事
2026年2月コーナン商事が、バローホールディングス傘下のアレンザホールディングスへのTOB（株式公開買付け）を発表。議決権49.45%の取得を目指すと報じられる
2026年3月30日TOB成立。応募1,172万3,970株、買付価格1株1,465円、取得価額171億2,000万円
2026年4月6日議決権所有割合38.79%となり、持分法適用関連会社に
2026年4月大量保有報告書により、バローHDとコーナン商事が共同で89.32%を保有していることが判明。アレンザHDは上場廃止となる見込み

この案件の含意は3つ。

  • HCの再編に食品スーパーが資本で絡んだ。バローHDは中部地盤の食品スーパーで、
    HC子会社を単独で抱えるより、専業のコーナンと共同保有するほうが競争力が出るという判断
    （→ スーパー・GMS、食品スーパー）
  • コーナンのM&A巧者ぶり。建デポ（2019年・LIXILから約240億円）、
    ホームインプルーブメントひろせ、ホームセンターみつわに続く案件で、
    グループのプロ業態比率は約3割に達している
  • 完全子会社化ではなく持分法という設計。一気に連結せず、段階的に統合する形をとった

4. ジョイフル本田 × アークランズ — 業界4位誕生…のはずが日程未定に

日付 出来事
2026年4月14日両社が2027年3月の経営統合に合意と発表。株式移転で共同持株会社を設立し、両社が傘下に入る
（計画）2027年2月25日に両社が東証プライム上場廃止、3月1日に共同持株会社が上場
（体制）会長にジョイフル本田の本田理顧問、社長に同社の平山育夫社長、副社長にアークランズの坂本晴彦会長が就任予定
2026年7月3日アークランズ子会社に不適切な会計処理の疑義が判明し、統合の日程は未定に

規模感（統合前）。

    発表だけで業界地図が書き換わるわけではない

5. プロ向けシフトと、専門業態の伸長

プロ向け（職人・農家）が唯一の成長領域

  • プロ市場は6兆円規模と試算され、HC市場（3〜4兆円）より大きい
    （ダイヤモンド・チェーンストアオンラインの分析）
  • コーナンPROは2026年で25周年。2026年9月には奈良・PRO桜井店、
    9月30日には鹿児島・PRO鹿児島東店の開店が予定されるなど、出店が続いている
  • プロ業態の店は朝6:30〜7:00開店、20〜21時閉店が標準。
    職人が現場に向かう前に資材を積む時間に合わせている
  • コメリのPRO業態は2026年3月期に+7.3%。全体（+1.6%）を大きく上回る

専門業態：ワークマンの過去最高益

HCの1カテゴリー（作業服・作業用品）を切り出して専業化したワークマンは、
2026年3月期に過去最高業績を記録した。

指標 2026年3月期 前年比
チェーン全店売上高2,092億円+14.3%
営業利益296億円+21.7%
純利益206億円+22.1%

分野別ではワーク（作業服）が+1.5%と堅調な一方、カジュアルウェアが+48.5%、

HC大手の4〜6%の2〜3倍である。
「総合で薄く売る」よりも「1カテゴリーを作り込む」ほうが儲かる、という差がそのまま出ている

アパレル・SPA）。

6. コスト構造の圧迫：人件費・物流費・在庫

各社の減益要因として繰り返し挙がっているのが次の3つ。

要因 内容 HCへの効き方
人件費帝国データバンクの2026年の調査では、値上げ要因として「人件費」が34.4%を占めるHCは人件費率12%前後と小売で最低水準だが、セルフサービスをこれ以上進めにくいので逃げ道が少ない
物流費燃料費とドライバー不足。資材の現場配送はHC固有の負担プロ業態ほど配送依存が高く、粗利率20〜25%を直撃（→ 陸運・トラック）
在庫効率在庫回転は年5回程度（回転日数約70日）。「4年間で約2割低下」との分析も（FULL KAITEN）数万〜10万点超のSKUを抱える構造そのものが原因。ROI・GMROI重視への転換が課題として語られる

加えて、天候リスクも2025〜2026年に繰り返し話題になった。
園芸・エクステリアが売上の約15.5%、季節家電・熱中症対策を含めると3割前後が天候感応で、
春の低温や長雨、猛暑の前倒しが月次を大きく振らせる。
コメリでは園芸用品・建築資材の苦戦が減益要因として報じられた期がある。

7. 全体の構図

【2026年のHC業界を1枚で】

  市場 4兆円で横ばい（店舗数だけ5,080店へ増加）
        │
        ├─ 1店あたり売上が15年で約14%減
        │        │
        │        ├─▶ 【再編】コーナン×アレンザHD（TOB成立）
        │        │          ジョイフル本田×アークランズ（合意、日程未定）
        │        │          → 1兆円企業時代へ、と業界紙
        │        │
        │        ├─▶ 【PB強化】カインズ約40% / DCM 30.1%→2030年度50%目標
        │        │          → 粗利率を上げる。ただし在庫リスクは自社負担
        │        │
        │        └─▶ 【プロ特化】6兆円市場。コーナン約3割、コメリPRO +7.3%
        │                   → 頻度と実需はあるが粗利率は20〜25%
        │
        └─ コスト（人件費・物流費・在庫）が利益を削る
                 → 4期連続増収でも利益は4年連続減
                 → 12社中5社しか増収増益できず

まとめると、2026年のHC業界は次の4行に集約できる。

  • 市場は伸びない。4兆円で20年横ばい、コロナ特需はすでに剥落した
  • 店は増えたが1店は細った。だから成長は自社の出店ではなく買収から取るしかない
  • 利益の源泉はPBとプロの2つだけ。どちらも実行には規模が要り、規模を買うのが再編
  • 総合大箱のまま何もしない選択肢はない。カテゴリーごとに専門業態が削りに来ている

用語 意味
商業動態統計経済産業省が毎月公表する小売・卸売の販売統計。HCは業態別の独立集計対象。速報性が高い
日本DIY・ホームセンター協会HCの業界団体。年間総売上高・店舗数の全国推計を公表する。商業動態統計より広い範囲を捕捉

持分法適用関連会社議決権20〜50%程度で重要な影響力を持つ会社。利益の持分のみを取り込む
PB比率売上高に占めるプライベートブランドの割合。粗利率に直結する
