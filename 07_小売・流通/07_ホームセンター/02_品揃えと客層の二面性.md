# ② 品揃えと客層の二面性 — 趣味の客とプロの職人が同じ店にいる

このノートで分かること：ホームセンター（HC）の売場には、**買い方も来店時間も客単価も
まったく違う2種類の客**が同居している。その二面性がどう品揃え・売場・営業時間・粗利を
歪めているか、そして業界がなぜ「プロ向け」に舵を切ったのか。

> 結論：HCは **「日曜の午後に来る趣味の客」と「平日の朝6時半に来る職人」** という、
> 本来なら別々の店で売るべき2つの商売を1つの箱に入れている。
> 趣味客は**買上点数が少なく客単価が低いが粗利率は高い**。
> プロ客は**客単価が10倍以上で来店頻度も高いが粗利率は低い**。
> 市場が頭打ちのいま、業界の成長はほぼ全部**プロ側**から出ている。

---

## 1. HCが扱っているものの広さ

まず「ホームセンターとは何を売る店か」を定義から押さえる。
経済産業省の商業動態統計では、HCを**「DIY用具・素材、園芸・エクステリア、
家庭用品・日用品などを中心にセルフサービス方式で販売する店舗」**として区分し、
商品を次のように分類している。

| 商品分類                                         | 販売額（2025年）                | 構成比  | 主な買い手       | 粗利率の目安  |
| ------------------------------------------------ | ------------------------------- | ------- | ---------------- | ------------- |
| **DIY用具・素材**                                | 7,678億円                       | 約22.6% | 趣味客＋**プロ** | 25〜30%       |
| **家庭用品・日用品**                             | 7,395億円                       | 約21.8% | 一般家庭         | 25〜30%       |
| **園芸・エクステリア**                           | 5,244億円                       | 約15.5% | 趣味客＋**農家** | **35〜45%**   |
| ペット・ペット用品                               | ─                               | 約9%    | 一般家庭         | **35〜45%**   |
| 電気・インテリア・カー用品・オフィス用品・その他 | ─                               | 約31%   | 一般家庭         | 20〜35%       |
| 合計                                             | **3兆3,917億円**（前年比▲0.2%） | 100%    | ─                | 全体で32〜35% |

（販売額・構成比は経済産業省 商業動態統計 2025年。粗利率は各社IR・業界解説からの**概算**で、
同じ分類のなかでも商品により大きく振れる）

なお、業界団体である**日本DIY・ホームセンター協会**の全国推計では
2025年の総売上高は**4兆130億円**、店舗数は**5,080店**である。

```
【同じ「ホームセンター市場」でも2つの数字がある】

  経産省 商業動態統計   3兆3,917億円（2025年）
    └ 調査対象は一定規模以上のHCチェーン。毎月公表・速報性が高い

  日本DIY・HC協会推計   4兆 130億円（2025年）
    └ 全国のHC全体を推計。中小・地場チェーンを含むので数字が大きい

  → どちらが正しいという話ではなく「範囲が違う」。
     前年比を追うなら商業動態統計、業界全体の大きさを言うなら協会推計。
```

協会推計でたどると、HC市場は**1973年の110億円から50年かけて4兆円へ**成長したが、
**2020年の4兆2,680億円（巣ごもり特需）をピークに横ばい〜微減**が続いている。
店舗数だけは5,080店まで増え続けており、**1店あたりの売上は縮んでいる**。

## 2. 2つの客を並べて比べる

HCの売場に立つと、時間帯で客層が入れ替わるのがはっきり分かる。

| 軸         | **DIY・園芸の趣味客**              | **プロ（職人・工務店・農家）**              |
| ---------- | ---------------------------------- | ------------------------------------------- |
| 来店時間   | 土日の10〜16時に集中               | **平日の朝6:30〜8:00**（現場に向かう前）    |
| 来店頻度   | 月1回〜年数回                      | **週3〜5回**。ほぼ毎営業日                  |
| 客単価     | 2,000〜4,000円                     | **2万〜10万円以上**                         |
| 買い方     | 売場を回遊して選ぶ。迷う           | **決め打ち**。品番で買う。滞在5分           |
| 求めるもの | 品揃えの広さ、見て選べること、安さ | **在庫の確実性、早さ、掛け売り、現場配送**  |
| 価格感度   | 中（1点あたりの金額が小さい）      | **高い**（同じ物を大量に買うので数%が効く） |
| 粗利率     | 高い（園芸・ペット・日用品）       | **低い**（建築資材・木材・金物）            |
| 決済       | 現金・カード                       | **法人掛け（月締め）**                      |
| ECへの流出 | しやすい（日用品・ペット）         | しにくい（今日いる／重い／量が読めない）    |

> ポイント：**粗利率が高い客ほど、来店頻度が低い**。これがHCの構造的なジレンマ。
> 趣味客は儲かるが年に数回しか来ない。プロは薄利だが毎日来る。
> 「薄く広く」のHCは、来てもらえないと固定費を回収できないので、
> 結局**頻度の高いプロ客の比重を上げる**方向に動く。

```
【1日の来店カーブ（模式）】

 客数
     │                      ╭──────╮
     │                     ╱        ╲        ← 土日の趣味客
     │ ╭╮                 ╱          ╲
     │ ││╲              ╱              ╲
     │ ││ ╲───────────╯                ╲───
     └─┴┴─────────────────────────────────────
      6:30 8  10  12  14  16  18  20  21時
       ▲
       プロの山（平日）：短時間に、高単価が、大量に抜けていく
```

この「朝の山」があるからこそ、プロ業態の店は**朝6時半〜7時に開け、夜20〜21時まで開ける**。
職人は現場入りの前に資材を積み、現場から戻って翌日分を買う。
**一般客向けの9時開店では、プロの需要をまるごと取り逃がす**。

## 3. プロ向けは「小売」ではなく「卸」に近い

プロ向けの商売は、同じ建物の中にあっても経済の作りが違う。

```
【一般客向けHC】              【プロ向け業態】

 店が仕入れて棚に並べる        店が仕入れて棚に並べる
   │                            │
   ▼                            ▼
 客が選ぶ・迷う                客は品番で決め打ち
   │                            │
   ▼                            ▼
 レジで現金/カード             法人カード・月締め掛け売り
   │                            │
   ▼                            ▼
 客が自分で運ぶ                店が現場へ配送／客が軽トラで積む
   │                            │
   ▼                            ▼
 粗利率 32〜40%                粗利率 20〜25%
 在庫回転 遅い                 在庫回転 速い（同じ物が毎日出る）
 売場に人が要らない            **与信・配送・見積で人が要る**
```

プロ向けが「卸に近い」というのは、次の3点が卸売業と同じだからである。

- **掛け売りと与信**。月締め・請求書払いが基本。取りっぱぐれのリスクを店が負う。
  つまり**売上と同時に売掛金という資産が増える**（現金商売の小売とは資金繰りが違う）
- **同一商品の反復販売**。趣味客のように「毎回違う物」を買わない。
  だから**発注が読め、在庫回転が速く、欠品が致命的**になる
- **配送が商品の一部**。現場に届けて初めて価値になる。
  ここは[機械商社](../../06_商社・卸売/04_機械商社/README.md)や
  [建材](../../12_建設・住宅・不動産/13_建材/README.md)流通と直接ぶつかる領域

その代わり、プロ客には**圧倒的な粘着性**がある。
使い慣れた店の在庫配置・掛け口座・担当者を変えるコストが高く、
一度囲い込めば週3〜5回の来店が何年も続く。
**「粗利率は低いが、生涯価値（LTV）が高い客」**というのがプロ客の本質である。

## 4. プロ向け業態という「別の店」

こうした違いがあるので、大手は**プロ向けを別業態の店として切り出した**。

| 業態                            | 運営           | 特徴                                                                     | 規模感                                          |
| ------------------------------- | -------------- | ------------------------------------------------------------------------ | ----------------------------------------------- |
| **コーナンPRO**                 | コーナン商事   | 職人専門店。合板・資材・電動工具・住設。朝6:30〜7:00開店。2026年で25周年 | プロ業態がグループ売上の**約3割**（報道ベース） |
| **建デポ**                      | コーナン商事   | 2019年にLIXILから**約240億円**で買収。会員制のプロ向け建材センター       | 上記に含む                                      |
| **コメリ PRO／ハード&グリーン** | コメリ         | 農業・建築資材に強い。PRO業態の伸びが2026年3月期で**+7.3%**              | 全国約1,200店ネットワーク                       |
| **カインズ PRO／カインズ プロ** | カインズ       | 資材館の強化、プロ会員向けサービス                                       | 非開示                                          |
| **ジョイフル本田 プロ売場**     | ジョイフル本田 | 超大型店内に資材館を持つ形式                                             | 1店あたり売場が巨大                             |

プロ向け市場そのものは**6兆円規模**と試算されており
（ダイヤモンド・チェーンストアオンラインの分析）、
3兆〜4兆円で頭打ちのHC市場より大きい。
つまり業界にとって**「隣に自分より大きい未開拓市場がある」**という状態であり、
各社がプロ業態へ一斉に向かう理由はここにある。

> ポイント：プロ業態を「HCの一部門」と見るのは誤り。
> 営業時間も、決済方法も、在庫の作り方も、競合相手も違う。
> **HCが建材卸・工具卸の商売に入っていった**と理解するほうが実態に近い。

## 5. SKUの多さが利益を食う — 「品揃えが武器」の裏側

HCの売りは「なんでもある」ことだが、それは**そのまま在庫の重さ**になる。

```
【SKU数の比較（おおよその目安）】

  コンビニ          約 3,000 SKU     ■
  食品スーパー      約 15,000 SKU    ■■■■■
  ドラッグストア    約 20,000 SKU    ■■■■■■
  ホームセンター    **40,000〜100,000超 SKU**
                    ■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■

  → ビス1本、パッキン1個、蝶番1種を切らすと「あの店には無い」になる。
     だから切れない。だから積む。だから回らない。
```

HCの商品には、**「年に3個しか売れないが、置いていないと信用を失う」**という
典型的なロングテール（少量しか売れない長い裾野）が大量にある。

- 水道のパッキン、特殊な寸法のビス、古い規格の蛍光灯、特定メーカーの替刃
- これらは1点あたりの売上はゼロに近いが、**「HCに行けばある」という期待**を支えている
- その期待が崩れると、客は最初から[EC](../../04_情報通信・IT・ネット/08_EC・ネット通販/README.md)や
  モノタロウ（取扱2,866万点以上とされる現場向けEC）で買うようになる

結果として起きているのが、**在庫効率の継続的な悪化**である。
業界では在庫回転率が**約5回転**（＝回転日数約70日）とされ、
「HCの在庫効率は4年間で2割低下した」という分析も出ている（FULL KAITEN）。

| 打ち手         | 内容                             | トレードオフ                                       |
| -------------- | -------------------------------- | -------------------------------------------------- |
| SKU削減        | 売れない商品を切る               | 「あの店には無い」が始まる                         |
| PB化           | 自社企画品に集約して点数を減らす | 開発コスト・最低ロット・売れ残りリスクを自社で負う |
| 店頭在庫の集約 | 地域の1店に集め、取り寄せる      | 「今日いますぐ」というHC最大の強みを自ら削る       |
| 取り寄せEC化   | ネット注文・店舗受取             | 送料と作業工数。客単価が低いと赤字                 |

**どれを選んでも何かを失う**。この解けなさが、HCの利益率が4〜6%から上がらない一因である
（→ [① 1店舗の経済学](01_1店舗の経済学.md)）。

## 6. 客層ごとに「どこへ逃げていくか」が違う

HCの客は、一様に減っているのではない。**カテゴリーごとに別々の業態へ流出している**。

```
【HCの売場から客が抜けていく先】

  日用品・洗剤・トイレットペーパー
      └──▶ ドラッグストア／ディスカウントストア（食品と一緒に買える）

  ペット用品・ペットフード
      └──▶ ペット専門店／EC（定期購入のほうが安く、重い物が届く）

  収納・インテリア小物
      └──▶ 100円ショップ／ニトリ・家具専門店

  作業服・軍手・安全靴
      └──▶ **ワークマン**（2026年3月期チェーン全店売上 2,092億円・+14.3%、1,094店）

  工具・間接資材（プロ）
      └──▶ モノタロウ等の現場向けEC

  ★ 逃げないもの
      └── 木材・合板・セメント・土・砂利・ブロック・植木
          （重い／かさばる／今日いる／量が読めない）
```

この図が示すのは、**HCの「なんでもある」という価値が、
カテゴリーごとに専門業態へ切り出されていった**という歴史である。
HCは各カテゴリーで2番手・3番手になり、**残ったのは誰も取りにこない重量物**だった。

- [ドラッグストア](../04_ドラッグストア/README.md)：調剤・化粧品の高粗利を原資に日用品を安く売る
- [100円ショップ](../08_100円ショップ/README.md)：小物の価格で勝負にならない
- [ペット関連](../../15_サービス・生活関連/27_ペット関連/README.md)：専門知識と生体販売で差がつく
- [アパレル・SPA](../10_アパレル・SPA/README.md)／ワークマン：作業服を機能服として再定義した
- [家具・インテリア](../../12_建設・住宅・不動産/14_家具・インテリア/README.md)：品質とコーディネートで上を取られた

> ポイント：HCの苦戦は「ECに負けた」という単純な話ではない。
> **各カテゴリーの専門業態に少しずつ削られ、
> 最後に残った重量物カテゴリーは坪効率が最も低い**という二重の問題である。
> だから業界は、重量物を大量に買ってくれる**プロ客**に活路を求めた。

## 7. 農業という、もう1つの「プロ」

HCのプロ客は職人だけではない。**農家**も重要なプロ客である。

- 肥料・農薬・培土・農業資材・農機具・潅水設備・パイプハウス部材
- 一般の園芸客と違い、**季節ごとにまとまった量**を買い、掛け売りを使う
- [農業・種苗・肥料](../../08_食品・農水産・外食/12_農業・種苗・肥料/README.md)流通における
  JA（農業協同組合）の購買事業と直接競合する

ここに強いのが**コメリ**である。新潟を本拠に、全国に小商圏型の
「ハード＆グリーン」を張り巡らせ、農村部の生活資材と農業資材をまとめて押さえている。
2026年3月期に大手のなかでコメリだけが増益（営業利益230億円・+2.9%）だったのは、
都市近郊の消費に依存せず、**農業・金物・建築資材という実需に寄っている**ことが大きい。

| プロ客の種類           | 何を買うか                           | 季節性                   | どのチェーンが強いか        |
| ---------------------- | ------------------------------------ | ------------------------ | --------------------------- |
| 大工・内装・設備の職人 | 木材、合板、金物、電動工具、住設機器 | 低（通年）               | コーナンPRO、建デポ         |
| 土木・外構             | セメント、砂利、ブロック、型枠       | 中（冬場に落ちる）       | コーナンPRO、ジョイフル本田 |
| **農家**               | 肥料、農薬、培土、パイプ、農機部品   | **高（作付け期に集中）** | **コメリ**                  |
| 清掃・ビルメン         | 洗剤、モップ、消耗品                 | 低                       | 各社（間接資材EC と競合）   |

## 8. 二面性が突きつける、経営上の選択

同じ箱に2つの商売が入っていると、あらゆる意思決定が板挟みになる。

| 論点       | 一般客に寄せると            | プロ客に寄せると                     |
| ---------- | --------------------------- | ------------------------------------ |
| 開店時間   | 9〜10時開店で人件費を抑える | **6:30開店**。早朝の人員コストが乗る |
| 売場づくり | 見やすく・楽しく・広い通路  | **積みやすく・出しやすく・倉庫的に** |
| 品揃え     | 生活雑貨・インテリアを厚く  | **資材・金物の規格を切らさない**     |
| 立地       | 住宅地に近い幹線道路沿い    | **工業団地・現場が多いエリア**       |
| 粗利率     | 高い（35%前後）             | 低い（20〜25%）                      |
| 成長余地   | 人口減・EC流出で縮小        | **6兆円市場。伸びている**            |

大手が出した答えは、**「1つの箱で両方やる」のをやめること**だった。
プロ向けは別ブランド・別店舗・別営業時間で切り出し、
一般向けの大型店はPB比率を上げて粗利を守る。
この分離をどこまで徹底できたかが、次のノートで見る**再編の勝敗**を分けている
（→ [③ 業界再編と生き残り](03_業界再編と生き残り.md)）。

## 用語メモ

| 用語                       | 意味                                                                                                   |
| -------------------------- | ------------------------------------------------------------------------------------------------------ |
| **DIY**                    | Do It Yourself。自分で作る・直すこと。HCの原点にあたる概念で、日本では1970年代に業態として輸入された   |
| **プロ業態／プロショップ** | 職人・工務店・農家など事業者向けに特化したHCの店舗形態。早朝開店・掛け売り・現場配送が特徴             |
| **掛け売り（法人掛け）**   | その場で現金をもらわず、月末締めで請求する販売方法。与信管理と売掛金の回収リスクが伴う                 |
| **与信**                   | 取引先に「いくらまでツケで売ってよいか」を決めること。プロ向け商売の前提になる管理業務                 |
| **ロングテール**           | 少量しか売れないが種類が非常に多い商品群。HCの品揃えの信頼を支える一方、在庫効率を悪化させる           |
| **間接資材**               | 製品そのものにはならないが業務に必要な資材（工具、消耗品、作業用品など）。モノタロウなどのECが強い領域 |
| **エクステリア**           | 住宅の外まわり（門・塀・フェンス・カーポート・デッキ）。園芸と並ぶHCの主力かつ高粗利カテゴリー         |
| **資材館**                 | 大型HCに併設される、木材・建材・セメント等を扱う専用棟。カット・配送サービスを備える                   |
| **商業動態統計**           | 経済産業省が毎月公表する小売・卸売の販売統計。HCは2014年から業態別の独立集計対象                       |
| **LTV（生涯価値）**        | 1人の客が取引期間全体で生む利益の合計。プロ客は1回の粗利が薄くても頻度と継続年数でLTVが大きい          |
