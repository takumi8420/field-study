# ④ 直近トピック（2026年9月時点）

報道・統計ベースの整理。数値は発表時点のものであり、
一次情報（各社の適時開示・有価証券報告書、経済産業省および日本DIY・ホームセンター協会の統計）で
必ず裏取りすること。

> この1年のホームセンター（HC）業界を一言でいうと **「市場は微減、利益は減、再編は加速」**。
> 2026年2〜3月期決算では上場12社のうち**増収増益を達成できたのは5社のみ**。
> その一方で、コーナン商事によるアレンザHDのTOB成立（3月）と、
> ジョイフル本田×アークランズの経営統合合意（4月）という大型案件が続いた。
> ただし後者は7月に**会計処理の疑義で日程未定**となり、統合の難しさも同時に露呈した。

## 1. 市場規模：4兆円の壁、5,080店という飽和

| 指標                      | 数値                                                             | 年・出典                                 |
| ------------------------- | ---------------------------------------------------------------- | ---------------------------------------- |
| HC総売上高（業界推計）    | **4兆130億円**                                                   | 2025年。日本DIY・ホームセンター協会 推計 |
| HC店舗数（業界推計）      | **5,080店**                                                      | 2025年。同上                             |
| HC販売額（統計ベース）    | **3兆3,917億円**、前年比 **▲0.2%**                               | 2025年。経済産業省 商業動態統計          |
| コロナ特需時のピーク      | 4兆2,680億円（協会推計）／3兆5,211億円（商業動態統計・2020年度） | 2020年                                   |
| 1店あたり売上（筆者算出） | 約 **7.9億円**（2010年比 約14%減）                               | 協会推計より計算                         |

読み方のポイント。

- **2つの数字が併存する**。協会推計は中小・地場チェーンを含む全国推計、
  商業動態統計は一定規模以上の調査対象企業ベース。
  **どちらが正しいかではなく「範囲が違う」**。前年比を追うなら商業動態統計が向く
- **店舗数だけが増え続けている**。市場が横ばいで店が増えれば、1店あたりは必ず細る。
  これが再編の直接の動機になっている（→ [③ 業界再編と生き残り](03_業界再編と生き残り.md)）
- 商品別では **DIY用具・素材 7,678億円（約22.6%）／家庭用品・日用品 7,395億円（約21.8%）／
  園芸・エクステリア 5,244億円（約15.5%）** で、この3区分で約6割（2025年・商業動態統計）

```
【協会推計でたどるHC市場の50年】

  4.3兆 ┤                                    ╭╮ 2020年 4兆2,680億（巣ごもり特需）

  3.0兆 ┤              ╭──────────╯
  2.0兆 ┤        ╭────╯
  1.0兆 ┤   ╭───╯  1985年 1兆500億
      0 ┤──╯  1973年 110億
        └──┬──────┬──────┬──────┬──────┬──────┬
          1973   1985   1995   2005   2015   2025

  ★2005年ごろに4兆円手前で伸びが止まり、以後20年ほぼ横ばい。
    コロナ特需（2020年）は一時的な上振れで、すでに剥落している。
```

## 2. 2026年決算：4期連続増収も、利益は減益が続く

2026年2〜3月期の主要各社（ダイヤモンド・チェーンストアオンライン
「ホームセンター決算ランキング2026」および各社IR）。

| 企業                | 営業収益  | 前年比 | 営業利益 | 前年比     | 既存店    | 決算期      |
| ------------------- | --------- | ------ | -------- | ---------- | --------- | ----------- |
| DCMホールディングス | 5,423億円 | ▲0.4%  | 310億円  | **▲6.7%**  | **▲4.2%** | 2026年2月期 |
| コーナン商事        | 5,197億円 | +3.7%  | 223億円  | **▲10.4%** | ▲0.4%     | 2026年2月期 |
| コメリ              | 3,853億円 | +1.6%  | 230億円  | **+2.9%**  | ─         | 2026年3月期 |
| アークランズ        | 3,411億円 | +8.0%  | 141億円  | **▲12.5%** | ─         | 2026年2月期 |

- **上場12社のうち、増収増益は5社のみ**と報じられた。
  減益の主因は**人件費・物流費・原材料費の上昇**で、値上げが追いついていない
- **DCMの既存店▲4.2%** が目立つ。全国に均等に店を持つ総合型ほど、
  カテゴリーごとの専門業態への流出を受け止めきれていない
- **コメリだけが増益**。農業・金物・建築資材という実需に寄っており、
  **PRO業態の売上は+7.3%**と全体（+1.6%）を大きく上回った
- 帝国データバンクの業界レポートでも、**4期連続増収・利益は4年連続減**という整理が示されている

> ポイント：「増収なのに減益」が4年続いているのが、この業界の現在地。
> 値上げで売上は保てても、**面積・在庫・人という固定的なコストの増分を吸収できていない**
> （→ [① 1店舗の経済学](01_1店舗の経済学.md)）。

## 3. コーナン商事 × アレンザHD — TOB成立と「食品スーパーとの共闘」

| 日付          | 出来事                                                                                                                                          |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| 2026年2月     | コーナン商事が、バローホールディングス傘下の**アレンザホールディングス**へのTOB（株式公開買付け）を発表。議決権49.45%の取得を目指すと報じられる |
| 2026年3月30日 | **TOB成立**。応募1,172万3,970株、買付価格**1株1,465円**、取得価額**171億2,000万円**                                                             |
| 2026年4月6日  | 議決権所有割合**38.79%**となり、**持分法適用関連会社**に                                                                                        |
| 2026年4月     | 大量保有報告書により、**バローHDとコーナン商事が共同で89.32%を保有**していることが判明。アレンザHDは上場廃止となる見込み                        |

この案件の含意は3つ。

- **HCの再編に食品スーパーが資本で絡んだ**。バローHDは中部地盤の食品スーパーで、
  HC子会社を単独で抱えるより、専業のコーナンと共同保有するほうが競争力が出るという判断
  （→ [スーパー・GMS](../02_スーパー・GMS/README.md)、[食品スーパー](../03_食品スーパー/README.md)）
- **コーナンのM&A巧者ぶり**。建デポ（2019年・LIXILから約240億円）、
  ホームインプルーブメントひろせ、ホームセンターみつわに続く案件で、
  グループのプロ業態比率は**約3割**に達している
- **完全子会社化ではなく持分法**という設計。一気に連結せず、段階的に統合する形をとった

```
【アレンザHDの株主構成の変化（概略）】

  2026年2月まで                    2026年4月以降
  ──────────────                   ──────────────
  バローHD（親会社）               バローHD ┐
      │                                     ├ 共同保有 89.32%
  東証に上場                        コーナン商事 ┘
  （一般株主あり）                          │
                                    コーナンは議決権38.79%で持分法適用
                                    アレンザHDは上場廃止へ
```

| ---------------- | -------------------------------------------------------------------------------------------------------- |
| 2026年4月14日    | 両社が**2027年3月の経営統合**に合意と発表。**株式移転**で共同持株会社を設立し、両社が傘下に入る          |

| **2026年7月3日** | **アークランズ子会社に不適切な会計処理の疑義**が判明し、**統合の日程は未定**に                           |

| 企業                   | 売上高          | 決算期      | 業界順位                                 |
| ---------------------- | --------------- | ----------- | ---------------------------------------- |
| アークランズ           | 3,411億円       | 2026年2月期 | 5位                                      |

- 一方で7月の会計疑義は、**統合の合意と実行の間にある距離**を示した。

## 5. プロ向けシフトと、専門業態の伸長

### プロ向け（職人・農家）が唯一の成長領域

- **プロ市場は6兆円規模**と試算され、HC市場（3〜4兆円）より大きい
  （ダイヤモンド・チェーンストアオンラインの分析）
- **コーナンPRO**は2026年で25周年。2026年9月には奈良・PRO桜井店、
  9月30日には鹿児島・PRO鹿児島東店の開店が予定されるなど、出店が続いている
- プロ業態の店は**朝6:30〜7:00開店、20〜21時閉店**が標準。
  職人が現場に向かう前に資材を積む時間に合わせている
- **コメリのPRO業態は2026年3月期に+7.3%**。全体（+1.6%）を大きく上回る

### 専門業態：ワークマンの過去最高益

HCの1カテゴリー（作業服・作業用品）を切り出して専業化したワークマンは、
2026年3月期に**過去最高業績**を記録した。

| 指標               | 2026年3月期   | 前年比                    |
| ------------------ | ------------- | ------------------------- |
| チェーン全店売上高 | **2,092億円** | +14.3%                    |
| 営業利益           | **296億円**   | +21.7%                    |
| 純利益             | 206億円       | +22.1%                    |
| 期末店舗数         | **1,094店**   | ─                         |
| PB売上高           | 1,501億円     | +19.9%（**PB比率71.9%**） |

分野別ではワーク（作業服）が+1.5%と堅調な一方、カジュアルウェアが+48.5%、
アウトドア・スポーツウェアが+10.3%と伸び、リカバリーウェアは**+808.2%**と急増した。

> ポイント：営業利益率で比べると、ワークマンは**14.2%**（296÷2,092）。
> HC大手の4〜6%の**2〜3倍**である。
> 「総合で薄く売る」よりも「1カテゴリーを作り込む」ほうが儲かる、という差がそのまま出ている
> （→ [② 品揃えと客層の二面性](02_品揃えと客層の二面性.md)、
> [アパレル・SPA](../10_アパレル・SPA/README.md)）。

## 6. コスト構造の圧迫：人件費・物流費・在庫

各社の減益要因として繰り返し挙がっているのが次の3つ。

| 要因         | 内容                                                                                     | HCへの効き方                                                                                                           |
| ------------ | ---------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| **人件費**   | 帝国データバンクの2026年の調査では、値上げ要因として「人件費」が**34.4%**を占める        | HCは人件費率12%前後と小売で最低水準だが、**セルフサービスをこれ以上進めにくい**ので逃げ道が少ない                      |
| **物流費**   | 燃料費とドライバー不足。資材の現場配送はHC固有の負担                                     | プロ業態ほど配送依存が高く、粗利率20〜25%を直撃（→ [陸運・トラック](../../13_運輸・物流/06_陸運・トラック/README.md)） |
| **在庫効率** | 在庫回転は**年5回程度**（回転日数約70日）。「4年間で約2割低下」との分析も（FULL KAITEN） | 数万〜10万点超のSKUを抱える構造そのものが原因。**ROI・GMROI重視への転換**が課題として語られる                          |

加えて、**天候リスク**も2025〜2026年に繰り返し話題になった。
園芸・エクステリアが売上の約15.5%、季節家電・熱中症対策を含めると3割前後が天候感応で、
春の低温や長雨、猛暑の前倒しが月次を大きく振らせる。
コメリでは園芸用品・建築資材の苦戦が減益要因として報じられた期がある。

## 7. 全体の構図

```
【2026年のHC業界を1枚で】

  市場 4兆円で横ばい（店舗数だけ5,080店へ増加）
        │
        ├─ 1店あたり売上が15年で約14%減
        │        │
        │        ├─▶ 【再編】コーナン×アレンザHD（TOB成立）
        │        │          ジョイフル本田×アークランズ（合意、日程未定）
        │        │          → 1兆円企業時代へ、と業界紙
        │        │
        │        ├─▶ 【PB強化】カインズ約40% / DCM 30.1%→2030年度50%目標
        │        │          → 粗利率を上げる。ただし在庫リスクは自社負担
        │        │
        │        └─▶ 【プロ特化】6兆円市場。コーナン約3割、コメリPRO +7.3%
        │                   → 頻度と実需はあるが粗利率は20〜25%
        │
        └─ コスト（人件費・物流費・在庫）が利益を削る
                 → 4期連続増収でも利益は4年連続減
                 → 12社中5社しか増収増益できず
```

まとめると、2026年のHC業界は次の4行に集約できる。

- **市場は伸びない**。4兆円で20年横ばい、コロナ特需はすでに剥落した
- **店は増えたが1店は細った**。だから成長は自社の出店ではなく**買収**から取るしかない
- **利益の源泉はPBとプロ**の2つだけ。どちらも実行には規模が要り、規模を買うのが再編
- **総合大箱のまま何もしない選択肢はない**。カテゴリーごとに専門業態が削りに来ている

| 用語                            | 意味                                                                                       |

| **商業動態統計**                | 経済産業省が毎月公表する小売・卸売の販売統計。HCは業態別の独立集計対象。速報性が高い       |
