# カテゴリ別の違い

このノートで分かること：**「リユース業界」とひとくくりにできない理由**。
中古品は扱う品目によって、**原価の決まり方・在庫の怖さ・必要な人材・利益の出方が別物**になる。
ブランド品は相場と真贋の商売、家電は修理業、アパレルは物量の商売、書籍・ゲームは薄利の装置産業、
自動車は別の巨大市場、宝飾・金は素材相場の商売である。

---

## 1. まず全体像：何が売買されているか

環境省「令和6年度リユース市場規模調査」（2025年6月公表）によれば、
2024年の国内リユース市場（一般消費者の最終需要ベース）の品目構成は、
**ブランド品 17.2%（2,208億円）、ブランド品を除く衣類・服飾品 8.6%（1,099億円）、
テレビ・洗濯機・冷蔵庫・エアコン 6.4%（814億円）** などとなっている
（この調査は自動車・バイクを含まない範囲で、リユース経済新聞の市場推計とは集計対象が異なる点に注意）。

```
  【中古品が動く経路（カテゴリ共通の骨格）】

   一般消費者（売り手）
      │        │             │
      │店頭買取 │出張・宅配買取 │フリマアプリ（C2C）
      ▼        ▼             ▼
  ┌────────────────────────┐        ┌──────────────┐
  │  リユース事業者（買取再販）      │◀──────▶│ 業者間オークション │
  │   検品・真贋・修理・清掃・撮影   │  仕入   └──────────────┘
  └────────────────────────┘  在庫処分        │ 海外バイヤー
      │店頭  │自社EC  │モール・フリマ出品                ▼
      ▼      ▼        ▼                           越境（輸出）
   一般消費者（買い手）

  ※どの経路が主戦場になるかは、カテゴリごとに大きく違う
```

## 2. カテゴリ別の一覧（この表が本ノートの核）

| カテゴリ                       | 原価が決まる要因               | 粗利率の目安              | 在庫回転                 | 単価             | 必要な専門性                           | 代表プレイヤー                                   |
| ------------------------------ | ------------------------------ | ------------------------- | ------------------------ | ---------------- | -------------------------------------- | ------------------------------------------------ |
| **ブランド品（バッグ・財布）** | 中古相場＋真贋                 | 低〜中（20〜30%台）       | **速い（数週間〜）**     | 数万〜数百万円   | **真贋・相場読み**                     | コメ兵、なんぼや（バリュエンス）、大黒屋         |
| **時計（高級）**               | 中古相場＋真贋＋整備           | 低〜中                    | 中                       | 数十万〜数千万円 | 真贋＋オーバーホール                   | コメ兵、宝飾・時計専業                           |
| **宝飾・地金（金・プラチナ）** | **地金相場×重量**              | 低（数%〜十数%）          | **非常に速い**           | 数万〜数百万円   | 鑑別・計量・精錬先の確保               | 買取専門店全般、貴金属商                         |
| **家電（生活家電・AV）**       | 年式＋動作＋修理可否           | 中（30〜40%台）           | 遅め                     | 数千〜数万円     | **検査・修理・保証運用**               | ハードオフ、セカンドストリート                   |
| **スマホ・PC**                 | **新型発売サイクル**           | 中                        | **速さが必須**           | 1万〜十数万円    | データ消去、バッテリー判定、赤ロム対応 | ゲオ、イオシス、携帯買取専門店                   |
| **アパレル・服飾**             | ブランド＋季節＋状態           | **高（50%超も）**         | **遅い（点数が膨大）**   | 数百〜数千円     | 採寸・撮影・物量オペレーション         | セカンドストリート、トレジャーファクトリー       |
| **書籍**                       | 需要の薄さ＋新刊サイクル       | **非常に高い（70%超も）** | 遅い                     | 100〜1,000円台   | 分類・値付けの自動化                   | ブックオフ                                       |
| **ゲーム・ソフト**             | タイトル人気＋新作             | 中〜高                    | 中                       | 数百〜数千円     | 相場の日次更新                         | ゲオ、ブックオフ                                 |
| **家具・生活雑貨**             | 状態＋運べるか                 | 中〜高                    | **遅い（保管コスト大）** | 数千〜数万円     | 配送・大型保管                         | トレジャーファクトリー、リサイクルショップ       |
| **自動車・バイク**             | **オークション相場＋走行距離** | 低（十数%）               | 中                       | 数十万〜数百万円 | 査定士資格、整備、名義変更             | ネクステージ、IDOM（ガリバー）、ビッグモーター系 |

※粗利率・回転はいずれも各社IRや業界紙の記述から読み取れる**傾向の目安**であり、
確定した統計値ではない。会社ごとの定義（商品化コストを原価に入れるか等）でも差が出る。

## 3. ブランド品：相場と真贋、そして「在庫が資金を食う」商売

**特徴**：粗利率は低いのに、利益額は大きい。単価が高いから。

- 1点50万円のバッグを40万円で買い取り、50万円で売れば粗利は10万円（粗利率20%）。
  同じ10万円を書籍（1冊300円・粗利率70%）で稼ぐには約476冊売らなければならない
- したがって**高単価カテゴリは粗利率で見てはいけない。1人・1坪あたりの粗利額で見る**
- 同時に、在庫1点あたりの資金拘束が大きい。**寝かせた瞬間に資金繰りが苦しくなる**ので、
  回転を優先し、売れないものは業者間オークションへ放出する

```
  【ブランド品の値付けが動くメカニズム】

   一次流通（正規店）の定価改定 ─┐
   為替（円安）             ─┤
   海外バイヤーの購買意欲    ─┼──▶ 業者間オークションの落札相場
   人気モデルの入れ替え      ─┤            │
   供給量（持ち込みの増減）  ─┘            ▼
                                     各社の買取上限価格
                                            │
                                            ▼
                                      店頭の買取提示額

  一次流通の値上げが、そのまま中古相場を押し上げる
  → [靴・バッグ・宝飾](../12_靴・バッグ・宝飾/README.md)
```

- **一次流通（新品）の値上げが中古相場を引き上げる**という珍しい関係がある。
  高級ブランドが定価を上げると、中古の相対的な割安感が強まり、中古価格も上がる
- 真贋判定が参入障壁。鑑定人材と真贋データベースを持たない事業者は、高額帯に入れない
  （→ [① 買取再販の経済／第5章](01_買取再販の経済.md)）

## 4. 宝飾・金：これは小売ではなく「素材相場の商売」

金・プラチナの買取は、他のカテゴリと原理がまったく違う。

| 論点         | 一般の中古品                     | 金・地金                                                                                                |
| ------------ | -------------------------------- | ------------------------------------------------------------------------------------------------------- |
| 価格の根拠   | その商品が中古でいくらで売れるか | **地金相場（円建て）×重量×純度**                                                                        |
| 相場の可視性 | 不透明（査定員の知識が価値）     | **毎日公示され、売り手も見られる**                                                                      |
| 差別化       | 目利き                           | **買取率（相場の何%で買うか）のみ**                                                                     |
| 在庫リスク   | 陳腐化する                       | **陳腐化しない。ただし相場変動を直撃する**                                                              |
| 出口         | 店頭・EC・業者間                 | 精錬業者・地金商（→ [金属リサイクル](../../11_資源・エネルギー・鉄鋼金属/14_金属リサイクル/README.md)） |

相場が公開されている以上、**差別化は「相場の何%で買い取るか」しかない**。
これが金買取を価格競争に落とし込み、同時に「集客商材」にしている。

```
  【なぜ買取専門店は「金・貴金属」を看板に掲げるのか】

   店頭の看板「金・プラチナ高価買取」
        │  ① 相場が公開されていて客が来やすい（比較しやすい＝呼び込みやすい）
        ▼
   来店（売りに来る人）
        │  ② 「ほかにもありませんか？」
        ▼
   ブランド品・時計・切手・骨董も一緒に査定
        │  ③ こちらは相場が不透明で、粗利率を確保できる
        ▼
        利益は「ついで査定」で作る

   金そのものは薄利。それでも看板になるのは、集客装置だから
```

> ポイント：**金は儲かるから扱うのではなく、客を呼べるから扱う。**
> 2020年代の買取専門店の大量出店は、この集客モデルと地金相場の高騰がセットで起きたもの。
> 相場が反転すると、この集客装置が一気に止まる（→ [④ 直近トピック](04_直近トピック_2026.md)）。

## 5. 家電・スマホ：実態は「修理業」と「時間との競走」

**家電のリユースは、売るまでに技術的な仕事が入る唯一のカテゴリ**である。

- 通電確認、動作確認、清掃、部品交換、そして**保証をつけて売る**
- 保証をつけるということは、**返品・修理の引当（将来の費用）を粗利から差し引く**ということ
- 製造年で相場が階段状に落ちる。家電リサイクル法対象品（テレビ・エアコン・冷蔵庫・洗濯機）は、
  値段がつかなければ**逆に処分費がかかる**ので、買取ラインの設定が厳しい

スマホ・PCはさらに時間制約が強い。

| 論点                 | 中身                                                                       |
| -------------------- | -------------------------------------------------------------------------- |
| 新型発売             | 年1回の新モデルで旧機種の相場が一段下がる。**在庫を持ち越すと確実に損**    |
| ネットワーク利用制限 | 分割代金未払いで通信が止まる端末（俗に「赤ロム」）のリスク。保証条項が必要 |
| データ消去           | 個人情報の完全消去が事業者の責任。工程と証跡が要る                         |
| バッテリー           | 劣化度が価格を左右。判定の標準化が必要                                     |

> ポイント：**家電・スマホの粗利率は中程度だが、工程コストと保証コストが重い。**
> 「安く買えた」だけでは利益にならず、修理・検査の内製化が競争力になる。
> → [家電量販](../06_家電量販/README.md)（新品側。下取りで中古の入口を押さえる動きがある）

## 6. アパレル：単価が低く、点数で勝負する物流オペレーション

- 1点あたり数百〜数千円。**粗利率は高いが粗利額が小さい**ので、
  とにかく**点数をさばく速度**がすべてになる
- 1点ごとに採寸・撮影・ハンガー掛けが必要。**人件費が粗利を食う最大のカテゴリ**
- 季節商材なので、**シーズンをまたいだ在庫は価値が半減する**。
  店舗間の在庫移動（北へ冬物、南へ夏物）と値下げ運用が生命線
- 近年は**ヴィンテージ・古着の海外需要**が価格を支えている面がある。
  国内で値がつかない古着が海外バイヤー経由で出ていく構造

```
  【アパレルリユースの規模の経済】

   店舗数 ↑ ─▶ 買取点数 ↑ ─▶ 品揃えの厚み ↑ ─▶ 来店頻度 ↑ ─┐
      ▲                                                        │
      └────────────────── 売上 ↑ ────────────────┘

   ＋ 店舗間の在庫移動で「売れる店」に商品を寄せられる
   ＋ 1点ごとの処理コストは、作業の標準化と自動採寸・自動撮影で下がる

   → 点数と店舗網が増えるほど強くなるため、アパレル中心の総合リユースは
     「出店を止めない」戦略を取りやすい（セカンドストリート、トレジャーファクトリー）
```

実際、ゲオHDの2026年3月期はセカンドストリート事業の売上が1,552億円（前期比+17.6%）、
国内で当初計画60店舗に対し**64店舗を前倒しで新規出店**したと発表されている。
→ [アパレル・SPA](../10_アパレル・SPA/README.md)

## 7. 書籍・ゲーム：薄利だが、値付けを自動化できた唯一の領域

- 1点100〜1,000円台。**粗利率は業界最高水準だが、1点の粗利は数百円**
- したがって**1点あたりの処理時間を秒単位で削る**ことが利益の源泉になる。
  ISBN／型番スキャンで自動値付けし、査定員の判断をほぼ排除できるのが特徴
- 市場そのものは縮小圧力を受けている。電子書籍・配信への移行で、
  中古に回る「モノ」が減る（→ [書店](../14_書店/README.md)、[ゲーム](../../04_情報通信・IT・ネット/10_ゲーム/README.md)）
- だからブックオフもゲオも、**書籍・ソフトの店舗をアパレル・ブランド・トレカへ転換**してきた。
  ブックオフグループHDの2026年5月期は売上1,301億円（前期比+9.2%）、経常利益47.2億円（+20.9%）で、
  貴金属相場の高騰も増益要因として説明されている

> ポイント：**書籍・ソフトは「箱と人の使い方」を学習する装置だった。**
> そこで鍛えた多店舗運営のノウハウを、より単価の高いカテゴリへ流し込んだのが2010年代以降の勝ち筋。

## 8. 自動車・バイク：別の巨大市場として切り分ける

中古車は金額規模がまったく違う。

| 指標                   | 値                          | 時点・出所                                                     |
| ---------------------- | --------------------------- | -------------------------------------------------------------- |
| 中古車登録・届出台数   | 648万7,868台（前年比−0.2%） | 2025年。日本自動車販売協会連合会（JADA）等の統計にもとづく報道 |
| 中古車市場規模         | 5兆円超と報じられる         | 2025年。報道ベースの推計                                       |
| ネクステージ 売上高    | 約5,528億円                 | 2024年11月期。同社IR                                           |
| IDOM（ガリバー）売上高 | 約4,199億円                 | 2024年2月期。同社IR                                            |

構造が他カテゴリと違う点。

- **業者間オークション（USS等のオートオークション）が価格の基準**として完全に機能している。
  相場が透明なので、買取店は「オークション相場−手数料−利益」で提示額を作る
- **名義変更・整備・保証・ローン・保険**が付随し、利益は車両粗利より**周辺の金融・サービス**から出る
- 査定は国家資格ではないが、日本自動車査定協会の**中古自動車査定士**という業界資格が標準になっている
- 海外バイヤーの購買力が強く、円安局面では**輸出向けに相場ごと引き上げられる**

→ [自動車（完成車）](../../02_自動車・機械/01_自動車（完成車）/README.md)、
[二輪車](../../02_自動車・機械/04_二輪車/README.md)、
[レンタカー・カーシェア](../../13_運輸・物流/12_レンタカー・カーシェア/README.md)

## 9. 越境販売：国内で値がつかないものを海外に売る

リユースの出口として近年重みを増しているのが**海外バイヤーへの卸**である。

| 形                                     | 中身                                 | 向いている商材                   |
| -------------------------------------- | ------------------------------------ | -------------------------------- |
| 業者間オークションに海外バイヤーが参加 | オンライン化で海外からの入札が可能に | ブランド品、時計                 |
| 現地法人・直営店の出店                 | 自社で海外に売場を持つ               | アパレル（セカンドストリート等） |
| コンテナ単位の卸                       | 選別せず量で出す                     | 古着、家電、自転車、中古車       |
| 越境EC                                 | 個別に海外消費者へ販売               | ブランド品、ホビー、トレカ       |

- 円安は**輸出側に有利・輸入側に不利**。国内買取価格を押し上げる方向に働く
- ゲオHDはセカンドストリートを海外展開しており、2026年3月期にシンガポール・香港へ新規出店。
  カンボジア進出で7か国目になると報じられている
- 注意点：海外向けに出すと**国内の在庫が減り、国内店頭の品揃えが薄くなる**という副作用がある。
  「どこまで海外に出すか」は品揃え戦略と表裏一体

## 10. カテゴリ選択が会社の形を決める

```
  【カテゴリが決める「会社の重さ」】

   軽い ←──────────────────────────────────→ 重い
   書籍・ソフト      アパレル        家電・スマホ      ブランド・時計   自動車
   ・自動値付け      ・物量          ・修理工程        ・真贋人材      ・整備工場
   ・在庫単価が低い  ・店舗網        ・保証引当        ・資金拘束大    ・法規制
   ・人は増えない    ・人が要る      ・技術者が要る    ・鑑定士が要る  ・資格・免許

   必要な資本      小 ────────────────────────▶ 大
   参入のしやすさ  易 ────────────────────────▶ 難
   価格競争の激しさ 激 ◀───────────────────────  緩（ただし相場連動）
```

> ポイント：**リユース企業の戦略とは、結局「どのカテゴリの組み合わせを持つか」である。**
> 低単価カテゴリで店舗網と客数を作り、高単価カテゴリで粗利額を取る。
> この二層構造を作れた会社が、上場して規模を保っている。
> 各社の戦略差は [③ 市場の拡大と構造](03_市場の拡大と構造.md) で扱う。

## 11. 用語メモ

| 用語                   | 意味                                                                                                 |
| ---------------------- | ---------------------------------------------------------------------------------------------------- |
| **一次流通／二次流通** | 新品として最初に売られる流通が一次、中古として再び売られるのが二次。リユースは二次流通               |
| **地金（じがね）相場** | 金・プラチナなど貴金属の素材としての取引価格。毎営業日公示される                                     |
| **買取率**             | 地金相場の何%で買い取るか。金買取の実質的な唯一の競争軸                                              |
| **鑑別**               | 宝石が本物か（天然か合成か等）を判定すること。真贋判定より専門性が高い                               |
| **オーバーホール**     | 時計の分解整備。中古時計の商品化に必要で、費用が原価に乗る                                           |
| **赤ロム**             | 端末代金の未払い等で通信が使えなくなった中古スマホの俗称。買取時のリスク要因                         |
| **家電リサイクル法**   | テレビ・エアコン・冷蔵庫・洗濯機の廃棄に費用負担を求める法律。値がつかない古い家電の処理コストに直結 |
| **中古自動車査定士**   | 日本自動車査定協会の業界資格。中古車査定の標準として機能している                                     |
| **オートオークション** | 中古車の業者間市場。USS等。中古車相場の事実上の基準価格                                              |
| **越境販売**           | 海外バイヤーや海外消費者への販売。円安局面で国内買取価格を支える                                     |
