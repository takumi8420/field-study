# 買取再販の経済

このノートで分かること：**リユース（中古品の買取再販）が、なぜ他の小売と根本的に違う商売なのか**。
結論を先に言うと、**仕入先が「お客さん」であり、仕入価格を自分で決められる唯一の小売**だからである。
そこから高い粗利率も、在庫の怖さも、査定という職人技の重みも、すべて導かれる。

---

## 1. 決定的に違う一点：仕入先がメーカーや問屋ではなく「客」

普通の小売は、メーカーや卸から**言い値に近い価格で仕入れる**。
仕入価格は交渉で多少動くが、基本的には相手が決める。
だから小売の利益は「どう売るか（販売価格・販促・立地）」でしか作れない。

リユースは逆で、**売りに来た一般消費者に対して「これはいくらで買います」と自分で提示する**。
相手は納得すれば売り、しなければ持ち帰る。つまり**仕入価格の決定権が小売側にある**。

```
  【普通の小売】                        【リユース（買取再販）】

  メーカー ──仕入価格を提示──▶ 小売       一般消費者
      （相手が値段を決める）                  │ 「これ売りたい」
                                              ▼
  小売 ──販売価格を決める──▶ 消費者      店（査定）──「◯◯円で買います」──▶ 消費者
                                              │ （自分が値段を決める）
  利益＝販売価格だけで作る                    ▼
                                          店 ──販売価格を決める──▶ 別の消費者

                                          利益＝仕入価格と販売価格の「両方」で作る
```

> ポイント：**リユースは、仕入と販売の両方に価格決定権を持つ。**
> これが粗利率の高さの正体であり、同時に「査定を誤ると原価が壊れる」という固有のリスクの正体でもある。

| 論点             | 普通の小売            | リユース（買取再販）                         |
| ---------------- | --------------------- | -------------------------------------------- |
| 仕入先           | メーカー・卸          | **一般消費者（客そのもの）**                 |
| 仕入価格の決定者 | 相手                  | **自社**                                     |
| 商品の供給量     | 発注すれば入る        | **来店・持込に依存し、コントロールしにくい** |
| 同じ商品の補充   | 可能                  | **不可能（一点物）**                         |
| 粗利率の目安     | 20〜35%（業態による） | **40〜50%前後（カテゴリ差が大きい）**        |
| 在庫の値下がり   | ある                  | **速い。時間とともに相場ごと動く**           |
| 返品・不良       | メーカーに戻せる      | **戻せない。自社で値下げして処理**           |

## 2. 粗利率が40〜50%になる理由を分解する

リユースの売上総利益率（粗利率）は、総合リユースでおおむね **40〜50%台**、
書籍・ソフトのような低単価カテゴリではさらに高くなる（各社IRから読み取れる傾向。
カテゴリ別の詳細は [② カテゴリ別の違い](02_カテゴリ別の違い.md) 参照）。
普通の小売から見ると異常に高い。理由は3つある。

**① 売り手に「相場を調べる手間」があるから**
不用品を売る人の多くは、その商品の中古相場を知らない。
調べるには時間がかかり、フリマアプリに出品すれば撮影・梱包・発送・トラブル対応が発生する。
店に持ち込めば**その場で現金になる**。この「即時性と手間の削減」に対して、売り手は値引きを受け入れる。

**② 売り手にとっての選択肢が「捨てる」だから**
不用品の代替案は廃棄（費用が発生することすらある）。
ゼロ円と比べれば、提示額が相場の3割でも「得」に見える。
→ 廃棄側の事情は [廃棄物処理・環境リサイクル](../../15_サービス・生活関連/23_廃棄物処理・環境リサイクル/README.md) を参照。

**③ 検品・清掃・補修・保証という付加価値を乗せられるから**
汚れた中古品と、クリーニング済み・動作確認済み・3か月保証付きの中古品は別の商品である。
この「商品化」の工程がそのまま値差になる。

```
  【中古品の価格が積み上がる様子（イメージ）】

   売り手の受取額  ┃■■■■■■              30〜50
   　　　　　　　　┃
   商品化コスト    ┃      ■■              10〜15   検品・清掃・補修・撮影・採寸
   　　　　　　　　┃
   店頭の販売価格  ┃■■■■■■■■■■■■■■■■■■■■  100
                   └──────────────────────────────▶
                     粗利＝100 −（買取額＋商品化コスト）
                     ※商品化コストを原価に入れるか販管費に入れるかは会社により異なる
```

## 3. 査定＝原価管理。目利きが会社の利益を決める

普通の小売では原価は経理が管理する数字だが、**リユースでは店頭スタッフが原価を決めている**。
査定員が1件ごとに提示した金額が、そのまま売上原価になる。

査定価格は「勘」ではなく、**販売できる価格からの逆算**で決まる。

```
  【査定価格の決め方＝出口からの逆算】

   ① 出口価格を読む      いま自社の店頭／自社EC／業者間オークションで
                          いくらで売れるか（相場データベース・過去実績）
            │
            ▼
   ② 状態で減額          キズ・汚れ・付属品欠品・製造年・保証書の有無
            │
            ▼
   ③ 回転見込みで減額    何日で売れるか。長く残るものほど深く引く
            │
            ▼
   ④ 必要粗利を引く      目標粗利率＋商品化コスト＋値下げ引当
            │
            ▼
        買取提示額
```

| 査定のインプット | 見るもの                                   | 外すとどうなるか                       |
| ---------------- | ------------------------------------------ | -------------------------------------- |
| 相場             | 自社実績、業者間オークション落札値、EC相場 | 高値づかみ。そのまま赤字在庫になる     |
| 真贋             | 縫製・刻印・シリアル・付属品・素材         | **偽物を仕入れる＝全額損失＋信用問題** |
| 状態             | キズ、動作、欠品、においなど               | 商品化コストが想定超過                 |
| 回転             | 季節性、人気、在庫の重複                   | 売れ残りの値下げ損                     |
| 素材価値         | 金・プラチナの重量×地金相場                | 相場が動くと数日で採算が変わる         |

> ポイント：**査定員の育成に年単位かかるため、店舗を増やすスピードは人の供給で決まる。**
> 出店計画より先に査定員の数が制約になる。これが「出店すれば伸びる」型のチェーンと違うところ。

## 4. 在庫の陳腐化：中古品は「置いておくと腐る」

リユースの在庫は3方向から価値が落ちる。

| 劣化の種類           | 中身                                 | 効きやすいカテゴリ         |
| -------------------- | ------------------------------------ | -------------------------- |
| **物理的劣化**       | 保管中のキズ、電池劣化、においの移り | 家電、楽器、アパレル       |
| **技術的陳腐化**     | 新型が出て旧型の相場が一段下がる     | スマホ、PC、家電、ゲーム機 |
| **流行・相場の変動** | ブランドの人気変動、地金相場の下落   | ブランド品、宝飾、アパレル |

しかも中古は**一点物**なので、「売れ筋だから追加発注」ができない。
結果として、リユースの店舗運営は**値下げの設計**そのものになる。

```
  【値下げの階段（総合リユース店の典型パターン・イメージ）】

  価格
   100 ┤■■■■■■■■
    85 ┤        ■■■■■■■■
    70 ┤                ■■■■■■■■
    50 ┤                        ■■■■■■■■
    30 ┤                                ■■■■■■■■  → 最終的に業者間
       └──┬────┬────┬────┬────┬──────▶ 経過日数   オークションへ放出
          0日   30日   60日   90日  120日

  「いつ下げるか」をルール化できるかが、粗利率と在庫回転の両立を決める
```

- 下げるのが早すぎる → 粗利が削れる
- 下げるのが遅すぎる → 在庫が積み上がり、資金が寝て、最後はもっと深く下げる
- **逃げ道として業者間オークションがある**のがリユースの特徴
  （売れ残りを他社に卸して現金化する。→ [③ 市場の拡大と構造](03_市場の拡大と構造.md)）

## 5. 真贋判定（鑑定）：偽物を1点仕入れた損失は「粗利」では埋まらない

**真贋（しんがん）＝本物かニセモノかの判定**。ブランド品・時計・宝飾で決定的に重い。

なぜ重いか。粗利率40%の商売で、**50万円の偽物を1点つかむと、200万円以上売ってようやく穴が埋まる**。
さらに、偽物を販売してしまえば商標法違反のリスクと信用毀損が加わる。

| 対応策           | 中身                                         | コスト構造                                          |
| ---------------- | -------------------------------------------- | --------------------------------------------------- |
| 鑑定士の内製     | 社内に専門人材を置き、研修・階層資格を設ける | 人件費（固定費）。規模が出るほど1点あたりは安くなる |
| 集中鑑定センター | 難物は本部に送って判定                       | 物流費＋リードタイム。店舗の査定を標準化できる      |
| 機器・データ     | 分析機器、真贋データベース、画像照合         | 初期投資＋更新費用                                  |
| 業界横断の仕組み | 協会の鑑定研修、業者間オークションでの保証   | 会費・手数料                                        |

> ポイント：**真贋判定はコストであると同時に参入障壁である。**
> ブランド品の買取が高粗利なのは、誰でもできる仕事ではないから。
> 逆に、真贋リスクのない書籍・衣料は参入しやすく、その分だけ価格競争になりやすい。

## 6. 古物営業法：この業界を成り立たせている法律

**古物営業法**＝中古品（古物）の売買を規制する法律。目的は**盗品の流通を防ぎ、被害品を早期に発見すること**。
つまりこの業界は「リサイクルのため」ではなく「防犯のため」に規制されている。

| 義務                 | 中身                                               | 実務での効き方                                                     |
| -------------------- | -------------------------------------------------- | ------------------------------------------------------------------ |
| **古物商許可**       | 都道府県公安委員会の許可。営業所ごとに届出         | 許可なく反復継続して買い取れば無許可営業                           |
| **本人確認**         | 買い受ける相手の氏名・住所・職業・年齢の確認       | 免許証等の確認が必要。eKYC（オンライン本人確認）の整備が近年の論点 |
| **帳簿（古物台帳）** | 取引の年月日、品目、特徴、相手方の情報を記録し保存 | 警察からの照会に応じられる状態を保つ                               |
| **不正品の申告**     | 盗品の疑いがあるときは警察へ申告                   | 現場判断が求められる                                               |
| **品触れへの対応**   | 警察が示す被害品リストと在庫を照合                 | 店舗オペレーションに組み込む必要がある                             |

押さえるべき例外と改正の流れ。

- 原則として**対価1万円未満の買受けは本人確認義務が免除**されるが、免除されない品目がある
- 金属盗（太陽光発電設備の銅線、エアコン室外機など）の急増を受け、
  **2025年10月1日施行の施行規則改正で、電線・グレーチング・エアコン室外ユニット・
  ヒートポンプ給湯機などが「1万円未満でも本人確認・帳簿記載が必要」な品目に追加された**
  （警視庁・警察庁の周知資料）。金属くず買取を対象とする新法も2025年6月に成立したと報じられる
- 中古品を個人が**自分の不用品として売るだけなら許可は不要**。
  一方、**転売目的で反復継続して仕入れるなら個人でも古物商許可が要る**
- フリマアプリでの仕入れは相手方の本人確認ができないため、
  「古物営業法上の義務を履行できない」という指摘が実務上続いている
  （→ [マッチング・シェアリング／規制と社会受容](../../04_情報通信・IT・ネット/16_マッチング・シェアリング/03_規制と社会受容.md)）

## 7. 1店舗の経済性：高粗利なのに営業利益率が3〜5%にとどまる理由

小売型の分析軸（坪効率・原価率・人件費率）で見ると、リユース店の特徴がはっきりする。

```
  【総合リユース店の損益イメージ（売上を100とした構成・概念図）】

  売上高                     100
   − 売上原価（買取額など）   50〜60      ← ここが自分で決められる
  ─────────────────────
   売上総利益                 40〜50      ★ 普通の小売よりかなり高い
   − 人件費                   18〜22      ← 査定・検品・清掃・撮影が人手
   − 地代家賃                  8〜12      ← 「売場＋買取カウンター＋バックヤード」で面積が要る
   − 広告宣伝費                3〜 6      ← 買取（＝仕入）を集めるための広告
   − 物流・その他              5〜 8
  ─────────────────────
   営業利益                    3〜 6 程度

  ※構成比は各社IRから読み取れる一般的な傾向をもとにした概念図であり、特定企業の数値ではない
```

高粗利が利益まで残らないのは、**中古品を売れる状態にするまでの工程が全部人件費と面積だから**である。

| コスト項目 | 普通の小売との違い                                                                     |
| ---------- | -------------------------------------------------------------------------------------- |
| 人件費     | 検品・査定・清掃・補修・採寸・撮影・出品。**1点ごとに人が触る**                        |
| 面積       | 売場に加え、**買取カウンターと作業用バックヤード**が要る。坪効率は構造的に上がりにくい |
| 広告費     | 販売の広告だけでなく、**「売ってください」という仕入の広告**が要る。ここが独自         |
| 物流       | 店舗間移動が多い。売れない店から売れる店へ在庫を動かす                                 |

> ポイント：**リユースの成長は「売上を増やす」より「買取（仕入）を集める」ゲーム。**
> 広告費・出店・アプリ・宅配買取はすべて、**売り手を集めるための投資**である。

上場各社の実績（直近）を並べると、高粗利でも最終的な利益率は小売らしい水準に落ち着くことが分かる。

| 企業                 | 期          | 売上高                   | 利益                        | 利益率 |
| -------------------- | ----------- | ------------------------ | --------------------------- | ------ |
| ブックオフグループHD | 2026年5月期 | 1,301億円（前期比+9.2%） | 経常利益47.2億円（+20.9%）  | 約3.6% |
| ゲオHD（全社）       | 2026年3月期 | 4,812億円（+12.5%）      | 営業利益142.4億円（+26.6%） | 約3.0% |
| コメ兵HD             | 2026年3月期 | 2,217億円（+39.4%）      | 営業利益92億円（+50.4%）    | 約4.1% |

（各社決算発表・報道ベース。コメ兵の売上急増はタイヤ・ホイール事業等も含む連結の数値）

## 8. 粗利率と在庫回転はトレードオフになる

同じリユースでも、**「高く売って寝かせる」か「薄く抜いて回す」か**で会社の形が変わる。

```
     粗利率
      高 ┃  ブックオフ型
         ┃  （低単価・高粗利率・回転はゆっくり）
         ┃         ●
         ┃
         ┃                    ● 総合リユース（セカスト／トレファク型）
         ┃
         ┃                              ● コメ兵型
      低 ┃                              （高単価・低粗利率・回転は速い）
         ┗━━━━━━━━━━━━━━━━━━━━━━━▶ 在庫回転
            遅                              速

    ※各社IRから読み取れる一般的な傾向。高額品ほど資金が寝るため回転を優先せざるを得ない
```

- **高単価カテゴリ（ブランド・時計・宝飾）**：1点あたりの資金拘束が大きいので、
  粗利率を落としてでも回転を上げないと資金が持たない。業者間オークションへの放出が前提になる
- **低単価カテゴリ（書籍・ソフト・衣料）**：1点が安いので寝かせても痛くない。
  そのかわり**点数をさばく物量のオペレーション**が生命線になる

カテゴリごとの具体的な違いは [② カテゴリ別の違い](02_カテゴリ別の違い.md) で扱う。

## 9. 一点物であることが生む、独特の不正リスク

原価を店頭の人間が決め、商品が一点物で、しかも現金が動く。
この3つが揃うと、**内部不正が起きやすい構造**になる。

実例として、ブックオフグループHDは2024年、子会社店舗での在庫差異をきっかけに特別調査委員会を設置し、
同年10月に調査報告書を公表した。**架空買取、商品持ち出し、棚卸偽装、現金着服など
26店舗・1事業部で29件の事案、16類型の不正**が確認されたと報じられている。

> ポイント：**「仕入価格を自分で決められる」ことの裏返しが「仕入価格を偽装できる」こと。**
> 買取の証憑（本人確認記録・古物台帳）と現物在庫の突合が、そのまま内部統制になる。
> 古物営業法の帳簿義務は、防犯だけでなく会社を守る仕組みでもある。

## 10. 用語メモ

| 用語                   | 意味                                                                                                                                                |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| **リユース**           | 中古品を再び使うこと。分解して素材に戻す「リサイクル」とは別（→ [金属リサイクル](../../11_資源・エネルギー・鉄鋼金属/14_金属リサイクル/README.md)） |
| **買取再販**           | 一般消費者から買い取り、商品化して別の消費者に売る事業モデル。リユース小売の中心                                                                    |
| **査定**               | 持ち込まれた品に買取価格を付ける行為。実質的な原価決定                                                                                              |
| **真贋（しんがん）**   | 本物か偽物かの判定。ブランド品・時計・宝飾で必須                                                                                                    |
| **鑑定**               | 真贋判定と品質評価を行うこと。社内資格や集中センターで担保する                                                                                      |
| **古物営業法**         | 中古品売買を規制する法律。**盗品流通の防止が目的**。古物商許可・本人確認・帳簿が三本柱                                                              |
| **古物台帳**           | 取引記録の保存簿。警察の照会に応じるためのもの                                                                                                      |
| **品触れ（しなぶれ）** | 警察から古物商に示される被害品の手配。在庫と照合する義務がある                                                                                      |
| **商品化**             | 検品・清掃・補修・採寸・撮影・値付けの工程。中古品を「売り物」に変える作業                                                                          |
| **在庫回転**           | 在庫が何日（何回転）で売れるか。中古では値下げタイミングと直結する                                                                                  |
| **業者間オークション** | 事業者だけが参加する中古品の卸売市場。仕入と在庫処分の両方に使う（→ [③](03_市場の拡大と構造.md)）                                                   |
| **eKYC**               | オンラインで完結する本人確認。宅配買取・アプリ買取の拡大で必要性が高まっている                                                                      |
