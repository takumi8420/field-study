市場の拡大と構造

小売・流通リユース・中古
あこのページの単語集用語に触れると意味を確認できます14語
世帯の縮小と高齢化一次流通の値上げインバウンド業者間オークション（古物市場）買取専門店出来高押し買い訪問購入クーリング・オフ品触れ不招請勧誘C2CB2C（買取再販）EC化率

このノートで分かること：なぜリユース市場は15年以上も伸び続けているのか、
そしてその中で各社がどう違う戦い方をしているのか。
需要側の変化（節約志向・サステナビリティ・断捨離）、供給側の変化（フリマアプリが「売る」を日常にした）、
業者間オークションという裏方、そして買取専門店の乱立と社会問題までを扱う。

1. 市場は15年連続で拡大している

指標 値 時点・出所
国内リユース市場規模3兆2,628億円（前年比+4.5%）2024年。リユース経済新聞（旧リサイクル通信）の推計
同・拡大の継続年数2009年以降15年連続の拡大同上
2009年の市場規模1兆1,274億円同上。15年で約2.9倍
2030年の予測4兆円規模同紙の予測（実績ではない）
買取サービス市場規模7,843億円（2018年）→ 1兆3,274億円（2023年）消費者庁の調査として報じられる数値。6年で約1.7倍
品目別トップ（2024年）ブランド品17.2%（2,208億円）環境省「令和6年度リユース市場規模調査」2025年6月公表

※統計の注意点が2つある。
① 政府の公式統計に「リユース産業」という括りはない。上の数値は業界紙の推計と環境省の委託調査であり、
集計範囲（自動車・バイクを含むか、C2Cを含むか）が異なるため単純比較できない。
② 3兆円台の数字にはメルカリ等のC2C取引が含まれる。事業者の買取再販だけの規模ではない。

2. 需要を作った3つの力

リユースが伸びたのは「エコだから」ではない。3つの別々の動機が同じ方向に働いた結果である。

動機 誰の動機か 効いた時期 何を生んだか
節約志向買う側リーマン後、そして2022年以降の物価高「新品でなくてよい」という許容。買い手を増やした
断捨離・片づけ売る側2010年代〜コロナ期の在宅時間増家に眠るモノを市場に出した。売り手を増やした
サステナビリティ両方＋企業・行政2020年代中古を買うことの気まずさを消した。社会的な正当性の付与

ポイント：「安いから中古」から「中古でもよい／中古がよい」への意識変化が一番効いている。
節約は買い手しか増やさないが、断捨離は売り手を増やし、
サステナビリティは中古品を選ぶことへの心理的抵抗を取り除いた。
供給・需要・心理の3つが同時に緩んだことで、市場が構造的に拡大した。

補助線として、供給側の物理的な事情もある。

  • 世帯の縮小と高齢化：実家の片づけ、生前整理、遺品整理が供給源として無視できない規模になった
  • 一次流通の値上げ：新品価格が上がると、中古の相対的な割安感が増して需要が移る
    （ブランド品で顕著。→ ② カテゴリ別の違い）
  • インバウンド：訪日客が中古品（ブランド品、古着、ホビー）を買う。円安が追い風

3. フリマアプリ（C2C）は競合か、補完か

両方である、というのが実務的な答え。

  【同じ中古品でも、経路によって売り手の得るものが違う】

                   受取額        手間        時間        安心
  店頭買取          小（3〜5割）  ほぼゼロ    即日        高（現金・トラブルなし）
  宅配・出張買取    中            小          数日        高
  フリマアプリ      大（7〜9割）  大          数日〜数か月 中（トラブルは自己責任）
  業者間オークション （事業者のみ）

   売り手は「いくらになるか」だけでなく「どれだけ面倒か」で経路を選んでいる
観点 競合する面 補完する面
供給（売り手）高く売れる商品はフリマに流れ、買取店には残りが来るフリマが「売る」行為を日常にし、中古市場そのものの裾野を広げた
需要（買い手）同じ商品をフリマで安く買える店は現物確認・保証・真贋保証を売れる。フリマにない価値
事業者の使い方—買取店がフリマアプリを販売チャネルとして使う（コメ兵は2023年11月からメルカリで販売を開始し約6万点を出品したと報じられる）
相場形成—フリマの売買実績が中古相場の参照データとして使われる

ポイント：フリマアプリは「中古品の供給を奪う敵」であると同時に「販路」でもある。
低単価で手離れのよい商品はフリマに、高単価・真贋リスクのある商品は店舗に、
という住み分けが実質的に成立している。
C2Cプラットフォーム側の経済は マッチング・シェアリング を参照。

4. 主要4社の戦略差

同じ「リユース」でも、出自が違えば戦い方が違う。

ブックオフグループHD古書書籍・ソフト → アパレル・ホビー・貴金属へ拡大低単価×大量処理。標準化した値付けと店舗網。総合化で客単価を上げる2026年5月期 売上1,301億円（+9.2%）、経常利益47.2億円（+20.9%）

5. 買取専門店の乱立：なぜ増えたのか、なぜ苦しいのか

2010年代後半から、駅前・商店街・空きテナントに小さな買取専門店が急増した。
販売機能を持たず、買い取ることだけをする店である。

  【買取専門店の事業モデル】

   小さな店（10〜20坪）        ┌─────────────────────┐
   ・売場が要らない            │ 買い取った品は自社で売らず、    │
   ・在庫を持たない            │ 業者間オークションに出す        │
   ・スタッフ1〜2人            │ →在庫リスクをほぼ持たない      │
   ・看板は「金・貴金属高価買取」└─────────────────────┘
        │
        ▼
   出店コストが小さい ＋ FC（フランチャイズ）で誰でも始められる
        │
        ▼
   店舗数が急増 ──▶ 商圏が重なる ──▶ 買取価格競争 ──▶ 粗利が薄くなる
                           ＋ 広告費の高騰
                           ＋ 査定員の不足・高齢化
増えた理由 中身
出店コストが低い売場がないので小さな物件でよい。内装も軽い
在庫リスクが小さい業者間オークションにすぐ流せば、在庫を抱えなくてよい
地金相場の高騰金の買取が儲かりやすく、集客もしやすかった
FCパッケージの整備査定マニュアル・相場データ・オークション会員資格をパッケージで提供

しかし2026年時点では、「出せば儲かる時代」は終わりつつあると業界メディアは指摘している。
報じられている構造変化は3つ。

  1. 金相場高騰による収益構造の変化（相場が上がると買取額も上がり、利ざやの率は薄くなる）
  2. 人手不足と査定員の高齢化
  3. 買取FC加盟ブームの終焉（商圏の重複、価格競争、広告費高騰、近隣FCの撤退）

市場自体は伸びているが、店舗数がそれ以上のペースで増えれば1店舗あたりの客数は減る。
これが現在の買取専門店セグメントの基本問題である。

6. 業者間オークション：業界を裏で支える卸売市場

業者間オークション（古物市場）＝古物商の資格を持つ事業者だけが参加できる中古品の卸売市場。
一般の目に触れないが、この業界の心臓部にあたる。

  【業者間オークションが果たす4つの役割】

   ① 在庫処分     店頭で売れ残った品を現金化する出口
   ② 仕入         自店に持ち込みがないカテゴリを仕入れる入口
   ③ 相場形成     落札価格が「いまの中古相場」の基準になる
   ④ 海外接続     海外バイヤーがここから日本の中古品を買う

      買取専門店 ──出品──▶ ┌──────────────┐ ──落札──▶ 小売型リユース店
      （在庫を持たない）      │ 業者間オークション │
      小売型リユース店 ─────▶ │  （会員制）       │ ──落札──▶ 海外バイヤー
      （売れ残りを放出）      └──────────────┘            （越境）

   「買取専門店は在庫リスクを持たない」という説明は、
    このオークションが常に買い手として存在していることが前提になっている

規模感（報道ベース）。

事実 値 時点・出所
エコリング「EcoRing the Auction」の月間出来高109億6,184万円（税抜）2026年4月開催分。リユース経済新聞
同月の主要ブランド古物市場の出来高合計約645億円（同社シェア約17%でトップ）同上
出来高を押し上げた要因オンライン開催による個人事業主・海外バイヤーの参加同上

ポイント：業者間オークションのオンライン化が、海外バイヤーを日本の中古市場に直結させた。
円安と相まって、国内の中古相場が海外の需要で動くようになっている。
これは「買取価格が高くなる」という点では売り手に有利だが、
国内の店頭在庫が薄くなるという副作用も持つ。

7. 社会問題と規制：盗品、押し買い、そして真贋

リユースは「不用品を活かす」という良い面だけの産業ではない。
盗品の出口になりやすいという構造的な問題を抱えており、それゆえに規制されている。

問題 中身 制度上の対応
盗品の流通万引き品・窃盗品の換金先になりうる古物営業法（許可・本人確認・古物台帳・品触れ）。→ ① 買取再販の経済
金属盗太陽光発電設備の銅線、エアコン室外機、グレーチングの盗難が急増2025年10月1日施行の古物営業法施行規則改正で、これらは1万円未満でも本人確認・帳簿記載が必要に。金属くず買取業者を対象とする新法も2025年6月成立と報じられる
押し買い（悪質な訪問購入）「不用な食器を買う」と言って訪問し、貴金属を強引に買い取っていく商法特定商取引法の訪問購入規制。書面交付、8日間のクーリング・オフ、不招請勧誘の禁止、依頼されていない物品の勧誘禁止など
偽ブランド品偽物の混入・販売商標法。実務上は各社の真贋体制と業者間オークションの保証に依存
フリマ経由の仕入れ相手の身元が分からず、本人確認義務を果たせない警視庁は「古物法の本人確認等の履行困難」との見解を示したと報じられる

押し買いについては被害者の偏りが明確で、国民生活センターは契約当事者の8割近くが60歳以上
であると注意喚起している（同センター公表資料）。買取という行為が高齢者宅を訪ねる口実になりやすく、
業界の評判リスクそのものになっている。

ポイント：この業界の規制は「環境」ではなく「防犯」の文脈で作られている。
古物営業法は警察庁・都道府県公安委員会の所管であり、
リユース推進の環境省とは別の系統から規制がかかる。
事業者は環境政策の追い風と、防犯規制の締め付けを同時に受ける。

8. 構造まとめ：この業界が抱える3つの緊張

  ┌────────────────────────────────────────────┐
  │ ① 供給の取り合い                                        │
  │    フリマアプリ・買取専門店・総合リユースが同じ「不用品」を奪い合う │
  │    → 買取価格の上昇 → 粗利率の低下                      │
  ├────────────────────────────────────────────┤
  │ ② 相場依存                                              │
  │    金・ブランド品・為替の相場が、そのまま損益に直撃する           │
  │    → 追い風のときは過去最高益、反転すると在庫評価が崩れる        │
  ├────────────────────────────────────────────┤
  │ ③ 人の制約                                              │
  │    査定員・鑑定士は数年かけないと育たない                      │
  │    → 出店ペースの上限を人が決める。高齢化が進行中             │
  └────────────────────────────────────────────┘

市場が伸びていること自体は疑いがない。ただし伸びの中身は、
「客数が増えた」よりも「単価（＝相場）が上がった」寄与が大きい局面に入っている可能性がある。
相場が反転したときに何が起きるかは、④ 直近トピック（2026年9月時点） で扱う。

9. 用語メモ

用語 意味
業者間オークション（古物市場）古物商だけが参加できる中古品の卸売市場。仕入・在庫処分・相場形成・海外接続の4役
買取専門店販売売場を持たず、買い取った品を業者間オークション等に流す業態。出店コストが低い
出来高オークションの落札総額。市場の活況を示す指標
押し買い訪問購入の悪質な形態。強引に貴金属等を買い取っていく商法の通称
訪問購入事業者が消費者宅を訪ねて物品を買い取ること。特定商取引法の規制対象
クーリング・オフ一定期間内なら無条件で契約を解除できる制度。訪問購入は法定書面受領日から8日間
品触れ警察が古物商に示す被害品の手配。在庫との照合が義務
不招請勧誘消費者から求められていないのに行う勧誘。訪問購入では原則禁止
C2C消費者間取引（Consumer to Consumer）。フリマアプリが典型
B2C（買取再販）事業者が消費者から買い、消費者に売るモデル。このフォルダの主題
