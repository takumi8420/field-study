## このフォルダの読み方

中古品を**買い取って売る**商売を、産業として理解するためのノート群。
型としては **小売型**（店舗の経済性・出店戦略・商品調達）だが、他のどの小売とも違う一点がある。

> **仕入先がメーカーや卸ではなく「お客さん」であり、仕入価格を自分で決められる。**

ここからすべてが導かれる。粗利率が40〜50%と高いのも、査定員という職人が会社の原価を握るのも、
在庫が一点物で陳腐化していくのも、そして古物営業法という**防犯目的の法律**に縛られるのも、
「客から仕入れる」という一点の帰結である。

したがって骨格は「①買取再販という商売の原理」→「②品目で別物になる実態」→「③市場が伸びた理由と業界構造」の3段で作る。

## 1. 業界の定義・範囲

**リユース・中古**＝一度使われた物品（古物）を、事業者が買い取り、商品化して再び販売する産業。
本フォルダは**B2C／C2B の買取再販**を主対象とする。

```
  【このフォルダの守備範囲】

  ┌──────────────────────────────────────────────┐
  │ ● 総合リユース店      アパレル・家具・家電・雑貨を広く扱う      │
  │ ● 専門リユース店      ブランド品・時計・宝飾・楽器・カメラ      │
  │ ● 買取専門店          売場を持たず買い取るだけ（業者間へ流す）  │
  │ ● 書籍・ソフトチェーン 書籍・CD/DVD・ゲーム                    │
  │ ● 業者間オークション  古物商だけが参加する卸売市場             │
  │ ● 宅配買取・出張買取  店舗を持たない買取チャネル               │
  └──────────────────────────────────────────────┘
   ▲ 隣接だが別フォルダ：C2Cフリマ本体／中古車販売／金属スクラップ／廃棄物処理
```

境界の引き方。

| 素材に戻す（金属スクラップ・製錬）               | ×                                | [金属リサイクル](../../11_資源・エネルギー・鉄鋼金属/14_金属リサイクル/README.md)                 |

**リユースとリサイクルは違う**。リユース＝そのままの形で再使用、リサイクル＝分解して素材に戻す。
「リサイクルショップ」という呼称が定着しているが、やっていることはリユースである。

## 3. バリューチェーン（川上 → 川下）

```
  一般消費者（売り手）
     │ ①集客：チラシ・Web広告・アプリ・出張／宅配
     ▼
  ┌──────────────────────────────────────────┐
  │  リユース事業者                                          │
  │   ② 査定（真贋・相場・状態）  ← ここで原価が決まる ★最重要  │
  │   ③ 商品化（検品・清掃・補修・採寸・撮影・値付け）          │
  │   ④ 在庫配置（店舗間移動・EC出品）                        │
  │   ⑤ 販売（店頭／自社EC／モール・フリマ出品）               │
  │   ⑥ 処分（値下げ → 業者間オークションへ放出）              │
  └──────────────────────────────────────────┘
     ▼                    ▼                     ▼
  一般消費者（買い手）  海外バイヤー（越境）   他の事業者（卸）

  付加価値が集まるのは ② と ③。
  ②で原価が決まり、③で「中古品」が「商品」に変わる。
  ⑤⑥は誰でもできるので差がつきにくい。
```

- **②査定**が利益の8割を決める。ここだけは人の技能に依存し、自動化が進みにくい
- **③商品化**は人件費そのもの。ここの効率が営業利益率を決める
- **⑥業者間オークション**という出口があるおかげで、在庫リスクを外に逃がせる

## 5. 収益モデル・コスト構造

```
  売上高                     100
   − 売上原価（買取額等）     50〜60     ← 自分で決められる
  ─────────────────────
   売上総利益                 40〜50     ★ 普通の小売より高い
   − 人件費                   18〜22     ← 査定・検品・清掃・撮影
   − 地代家賃                  8〜12     ← 売場＋買取カウンター＋バックヤード
   − 広告宣伝費                3〜 6     ← 「売ってください」の広告が要る
   − 物流・その他              5〜 8
  ─────────────────────
   営業利益                    3〜 6 程度

  ※各社IRから読み取れる一般的傾向をもとにした概念図。特定企業の数値ではない
```

| 指標            | 目安・考え方                                                        |
| --------------- | ------------------------------------------------------------------- |
| **粗利率**      | 40〜50%台（カテゴリ差が大きい。書籍は70%超、ブランド品は20〜30%台） |
| **営業利益率**  | 3〜6%程度。高粗利が人件費と面積に食われる                           |
| **在庫回転**    | 高単価ほど速く回す必要がある（資金拘束が大きいため）                |
| **坪効率**      | 構造的に上がりにくい。売場以外の面積が必要なため                    |
| **客単価×客数** | 相場高の局面では客単価が押し上げられ、増収の質が見えにくくなる      |

> ポイント：**粗利率と在庫回転はトレードオフ**。
> ブックオフ型（高粗利率・低回転）とコメ兵型（低粗利率・高回転）は、
> 同じ業界でも財務の形がまったく違う。→ [① 買取再販の経済](01_買取再販の経済.md)

収益の第2エンジンとして、**業者間オークションの運営手数料**がある（バリュエンス、エコリング）。
自社で売れない在庫を他社に売る場を持つことは、在庫リスクの出口を内製することでもある。

## 6. 競争要因（KSF）と参入障壁

| 要因                 | 中身                                               | 障壁の高さ                               |
| -------------------- | -------------------------------------------------- | ---------------------------------------- |
| **査定員・鑑定士**   | 相場を読み、真贋を見抜ける人材。育成に年単位かかる | **最も高い**。出店ペースの上限を決める   |
| **買取集客力**       | 「売るならここ」という想起。広告・立地・アプリ     | 高い。広告費が膨らみやすい               |
| **相場データベース** | 過去の販売実績・オークション落札値の蓄積           | 中。規模が効く                           |
| **在庫処分の出口**   | 業者間オークションへのアクセス、海外販路           | 中。会員資格・関係性                     |
| **店舗網・物流**     | 在庫を売れる店へ動かせるか                         | 中〜高。規模が効く                       |
| **古物商許可**       | 公安委員会の許可                                   | **低い**。誰でも取れるので障壁にならない |

> ポイント：**この業界の参入障壁は「許可」ではなく「人」。**
> 買取FCが急増して淘汰が始まったのは、パッケージで補えるのは相場データまでで、
> 目利きと接客は補えなかったからである。→ [③ 市場の拡大と構造](03_市場の拡大と構造.md)

## 7. 規制・法制度

| 制度                                         | 所管                       | 中身                                                                                                                |
| -------------------------------------------- | -------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| **古物営業法**                               | 警察庁・都道府県公安委員会 | 古物商許可、**本人確認**、古物台帳、品触れへの対応、不正品の申告。目的は**盗品流通の防止**                          |
| 同施行規則の改正（2025年10月1日施行）        | 同上                       | 電線・グレーチング・エアコン室外ユニット・ヒートポンプ等を、**1万円未満でも本人確認必須**の品目に追加（金属盗対策） |
| 盗難特定金属製物品の処分の防止等に関する法律 | —                          | 金属くず買取業者を対象とする新法。2025年6月成立と報じられる                                                         |
| **特定商取引法（訪問購入）**                 | 消費者庁                   | 押し買い対策。不招請勧誘の禁止、書面交付、**8日間のクーリング・オフ**                                               |
| **質屋営業法**                               | 警察庁・公安委員会         | 品物を担保に金を貸す業態。買取業と隣接（→ [消費者金融](../../05_金融/12_消費者金融/README.md)）                     |
| **家電リサイクル法**                         | 環境省・経産省             | テレビ・エアコン・冷蔵庫・洗濯機。値がつかない古い家電は**処分費がかかる**                                          |
| **商標法**                                   | 特許庁                     | 偽ブランド品の取扱い。真贋体制の根拠                                                                                |
| **犯罪収益移転防止法**                       | —                          | 高額取引での本人確認。古物営業法とは別系統で義務がかかる場合がある                                                  |
| 資源循環政策（サーキュラーエコノミー）       | 環境省                     | リユース推進は政策的な追い風。一方で規制は防犯の文脈から来る                                                        |

> ポイント：**追い風（環境政策）と締め付け（防犯規制）が、別々の官庁から同時に来る。**
> リユースは「推進される産業」であると同時に「監視される産業」でもある。

## 8. 最近のトピック

詳細は [④ 直近トピック（2026年9月時点）](04_直近トピック_2026.md)。要点は5つ。

1. **金価格が史上最高値圏**（2026年1月に国内小売1g 3万円突破と報道）。集客と売上を押し上げる一方、
   粗利率を薄め運転資金を重くし、反転時の在庫評価損リスクを残す
2. **大手は軒並み過去最高益**（コメ兵2,217億円、ゲオ4,812億円、ブックオフ1,301億円）。
   ただし増収の中身は各社で違い、客数よりも単価（相場高）の寄与が大きい局面に入っている
3. **買取専門店の乱立は転換点へ**。市場の伸び以上に店舗が増え、
   価格競争・広告費高騰・査定員不足・FC撤退が同時進行していると業界メディアが指摘
4. **規制が両面から強化**。金属盗対策の施行規則改正（2025年10月施行）と、
   押し買い（訪問購入）トラブルへの対応。被害者の8割近くが60歳以上（国民生活センター）
5. **円安・インバウンドが中古品を輸出商材に変えた**。業者間オークションのオンライン化で
   海外バイヤーが直接参加し、国内相場を押し上げている

## 9. 用語メモ

各ノート末尾に詳しい用語メモがある。最低限これだけは。

| 用語                               | 意味                                                                                                 |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------- |
| **古物**                           | 一度使用された物品、または使用のために取引された未使用品。古物営業法上の定義                         |
| **古物商許可**                     | 中古品を業として売買するのに必要な公安委員会の許可。→ [①](01_買取再販の経済.md)                      |
| **査定**                           | 持ち込まれた品に買取価格を付ける行為。**実質的な原価決定**。→ [①](01_買取再販の経済.md)              |
| **真贋（しんがん）**               | 本物か偽物かの判定。ブランド品・時計・宝飾で必須。→ [①](01_買取再販の経済.md)                        |
| **業者間オークション（古物市場）** | 古物商だけが参加する卸売市場。仕入・在庫処分・相場形成・海外接続の4役。→ [③](03_市場の拡大と構造.md) |
| **買取専門店**                     | 売場を持たず買い取るだけの業態。在庫を業者間オークションに流す。→ [③](03_市場の拡大と構造.md)        |
| **一次流通／二次流通**             | 新品としての流通が一次、中古としての流通が二次。→ [②](02_カテゴリ別の違い.md)                        |
| **地金相場**                       | 金・プラチナの素材価格。貴金属買取の原価を直接決める。→ [②](02_カテゴリ別の違い.md)                  |
| **押し買い**                       | 悪質な訪問購入の通称。特定商取引法の規制対象。→ [③](03_市場の拡大と構造.md)                          |
| **eKYC**                           | オンラインで完結する本人確認。宅配・アプリ買取の拡大に不可欠。→ [④](04_直近トピック_2026.md)         |
