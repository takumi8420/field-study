もうひとつは「ブランド」の視点——1人の顧客をいくらで獲得し、何回買ってもらえば黒字になるかという話。

前者は EC・ネット通販 側で詳述済み。

ここで扱うのは、自社で売る事業者の経営である。

1. 業界の定義・範囲

通販（通信販売）とは、店舗を持たず、広告やカタログを見た消費者が郵便・電話・ネットで注文する販売形態を指す。
法律上は特定商取引法の「通信販売」に位置づけられる。

D2C（Direct to Consumer）は、メーカーが卸・小売を通さず直接消費者に売る形。
通販の一形態であり、2015年以降のSNSとカートSaaS（Shopify等）の普及で広まった呼び方である。

境界を整理すると次のようになる。

  ┌──────────────── 無店舗小売 ────────────────┐
  │                                              │
  │  【通販（通信販売）】                        │
  │   ├ ネット通販 ─┬ モール出店   ← EC側で詳述 │
  │   │              └ 自社EC ─┬ D2C（メーカー直販）│  ← このフォルダ
  │   │                        └ 小売業者の自社EC    │
  │   ├ テレビ通販・ラジオ通販     ← このフォルダ │
  │   ├ カタログ通販               ← このフォルダ │
  │   └ 新聞・折込・DM             ← このフォルダ │
  │                                              │
  │  【訪問販売・電話勧誘販売】← 別の規制体系    │
  └──────────────────────────────────────────────┘

隣接業界との線引き：

  • ECとの違い：ECは「ネットで売買が成立する取引」全般を指す概念。通販はそれを含むより広い販売形態
  • 訪問販売との違い：消費者が広告を見て自分から申し込むのが通販。事業者から出向くのが訪問販売。クーリングオフの有無が分かれる
  • 小売業との違い：通販は立地ではなく広告で客を得る。固定費（家賃）ではなく変動費（広告費）で集客する

構図はこうである。市場全体は伸びているが、伸びているのはネット部分だけ。
カタログ・テレビ・ラジオといった旧来型メディアの通販は縮小しており、
しかもネット部分の伸びの大半はモール・大手に集まる。
中小のブランドは「伸びている市場の中で個別には苦しい」という状態に置かれている。

類型 代表企業 立ち位置 特徴

5. 収益モデル・コスト構造

単品リピート通販の売上100に対する費用構成の目安（業界の実務値であり、公式統計ではない）。

項目 目安 性質 コメント
売上100——
商品原価10〜25変動費粗利率75〜90%。これが高いから広告費を払える
物流費（送料・梱包）8〜15変動費小さく軽い商材が選ばれる理由
決済手数料2〜4変動費後払い・コンビニ払いは料率が高め
広告宣伝費20〜40変動費最大の費目。ここが業績の振れ幅を作る
コールセンター・CRM5〜10準固定費継続率を買っている費用
人件費・その他販管費10〜15固定費—
営業利益0〜15—新規獲得を増やすと一時的に下がる

ポイント：新規獲得を増やした期は利益が下がり、抑えた期は利益が出る。
通販会社の決算は「利益が出た＝好調」とは限らない。新規顧客数と定期顧客数の増減を必ずセットで見る。

詳しい計算は ① 定期通販の経済学 を参照。

6. 競争要因（KSF）と参入障壁

KSF 中身
上限CPOの管理LTVから逆算した獲得単価の上限を持ち、媒体別・日次で守れるか
継続率（リテンション）継続率1ポイントの改善がLTVに非線形で効く。獲得より投資効率が高い
媒体の分散単一媒体依存はアルゴリズム変更・規制で一気に崩れる
商材の粗利率粗利率が低いと広告費を払えない。この一点で参入可否が決まる
運転資金広告費が先払い、回収は数か月後。成長率の上限は資金力で決まる
法務・薬事の体制表現の審査体制がないと、成長した瞬間に行政処分で止まる

参入障壁は低く、撤退障壁も低い。
カートSaaSで店は当日作れ、OEMで商品も作れる。だからこそ競合が絶えず入り、CPOが上がる。
本当の障壁は「顧客リストと継続率」で、これだけは買うか時間をかけるしかない。

7. 規制・法制度

法律 何を規制するか 押さえるポイント
特定商取引法通信販売の広告表示義務、最終確認画面の6項目表示、解約妨害2021年改正（2022年6月1日施行）で定期購入対策を導入。誤認表示には取消権。通販にクーリングオフはない
