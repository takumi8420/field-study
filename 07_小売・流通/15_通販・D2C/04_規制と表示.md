# ④ 規制と表示（特商法・景表法・薬機法・機能性表示食品）

このノートで分かること：通販・D2Cは「何を売るか」より「**どう表示して、どう契約させるか**」が
法律で細かく決まっている業界だということ。そのルールが誰によって、どの段階で効くのか。

> 結論：通販の規制は**4層**でできている。
> ①契約の手続（特定商取引法）、②表示の誇張（景品表示法）、③効能をうたうこと（薬機法）、
> ④食品の機能表示（食品表示法・健康増進法）。
> 4つは所管も罰則も違い、**同じ1枚のLP（ランディングページ）が4つ全部に引っかかりうる**。

なお本ノートは**規制の構造**を説明するもので、特定の商品の効果や有効性を扱うものではない。
個別の表現可否は専門家（弁護士・薬事の審査事業者）の判断が必要になる。

---

## 1. 4つの法律の役割分担

| 法律                       | 所管                 | 何を見るか                                                   | 典型的な違反                                               | 主な処分                         |
| -------------------------- | -------------------- | ------------------------------------------------------------ | ---------------------------------------------------------- | -------------------------------- |
| **特定商取引法（特商法）** | 消費者庁             | **契約の手続と表示のルール**。誰が売り主か、いつ解約できるか | 定期購入なのに単発に見える表示、解約方法を分かりにくくする | 指示、業務停止命令、業務禁止命令 |
| **景品表示法（景表法）**   | 消費者庁             | **表示の誇張**。実際より著しく優良／有利に見せていないか     | 根拠のない効果の断定、「今だけ」が常時続く二重価格         | 措置命令、課徴金                 |
| **薬機法**                 | 厚生労働省・都道府県 | **医薬品的な効能をうたっていないか**                         | 化粧品で「シミが消える」、食品で「免疫力が上がる」         | 中止命令・措置命令、課徴金、罰則 |
| **食品表示法／健康増進法** | 消費者庁             | 食品の機能表示が制度どおりか、誇大でないか                   | 届出の範囲を超えた機能表示、根拠を欠く誇大表示             | 撤回指導、措置命令               |

```
  1枚のLPに対して、それぞれの法律が見ている場所が違う

  ┌─────────────────────────────────────────┐
  │  【キャッチコピー】「飲むだけで◯◯」        │ ← 薬機法・景表法
  │  【体験談・口コミ】「1か月で実感！」        │ ← 景表法（効果の暗示）・ステマ規制
  │  【価格表示】「初回980円（通常5,980円）」   │ ← 景表法（二重価格）
  │  【定期の条件】「4回の継続が条件です」      │ ← 特商法（申込期間・解除の条件）
  │  【最終確認画面】分量・価格・解約方法…      │ ← 特商法（12条の6：6項目の表示義務）
  │  【事業者表示】社名・住所・電話番号         │ ← 特商法（11条：広告表示義務）
  └─────────────────────────────────────────┘
```

## 2. 特定商取引法——通販の「型」を決める法律

### 通信販売にクーリングオフはない

よくある誤解だが、通信販売には**クーリングオフ制度がない**。
代わりに「返品特約」の表示ルールがあり、事業者が返品条件を表示していればそれに従い、
表示がなければ**商品到着後8日以内、送料は消費者負担**で返品できる。
訪問販売・電話勧誘販売のような無条件解除とは別物である。

### 2022年6月施行の改正——定期購入対策

2021年改正（**2022年6月1日施行**）で、いわゆる「詐欺的な定期購入商法」への規制が入った。
注文の**最終確認画面**に、次の6項目を明示することが義務づけられた。

| #   | 表示すべき事項                                | 実務上のポイント                                  |
| --- | --------------------------------------------- | ------------------------------------------------- |
| 1   | 分量（定期なら各回の分量と総回数）            | 「◯回のお届け」を明示する。無期限なら無期限と書く |
| 2   | 販売価格・対価（定期なら2回目以降を含む総額） | 初回価格だけの表示は不可                          |
| 3   | 支払いの時期・方法                            | 毎回の決済タイミング                              |
| 4   | 引渡し・提供の時期                            | 各回の配送間隔                                    |
| 5   | 申込みの撤回・解除に関すること                | 解約の方法・期限・連絡先                          |
| 6   | 申込期間の定めがあるときはその旨              | 「本日限り」等を使う場合                          |

あわせて、誤認させる表示によって申し込んだ消費者に**取消権**が与えられた。
つまり事業者側から見ると、「誤認させる表示＝**契約が後から無効になりうる**」ということになる。

### 執行の現実

施行から3年以上経った2025〜2026年も、消費者庁・都道府県による執行は継続しており、
業務停止命令の事例が報じられている。行政が問題視するパターンは次のようなものである。

| 違反のパターン         | 具体例                                                                 |
| ---------------------- | ---------------------------------------------------------------------- |
| **最終確認画面の不備** | 総額や回数を画面の下部に小さく置く、スクロールしないと見えない         |
| **「お試し」の誤認**   | 「初回無料」を大きく出し、定期条件を極端に目立たなくする               |
| **解約の妨害**         | 電話しか受け付けず繋がらない、返品先住所を教えない、解約フォームを隠す |
| **申込期間の偽装**     | 「本日限り」のカウントダウンが毎日リセットされる                       |

> ポイント：**解約のしにくさ自体が違反になりうる**という点が、従来との大きな違い。
> [① 定期通販の経済学](01_定期通販の経済学.md) で見たとおり継続率は利益に直結するので、
> 事業者には「やめにくくする」経済的な動機が常に働く。規制はまさにそこを狙っている。

## 3. 景品表示法——「言い過ぎ」を取り締まる

景表法が禁じるのは大きく2つ。

- **優良誤認表示**：品質・内容が実際より著しく優れていると見せること
- **有利誤認表示**：価格・取引条件が実際より著しく有利だと見せること

さらに、効果をうたう広告については、消費者庁が**合理的根拠の提出**を15日以内に求めることができ、
出せなければ不当表示とみなされる（不実証広告規制）。
「効果があると信じていた」は抗弁にならず、**先に根拠資料を持っていること**が求められる。

### 2023年改正（2024年10月1日施行）で何が変わったか

| 変更点             | 内容                                                                               |
| ------------------ | ---------------------------------------------------------------------------------- |
| **確約手続の導入** | 事業者が自主的な是正計画を申し出て認定されれば、措置命令・課徴金を回避できる       |
| **課徴金の割増**   | 過去10年以内に課徴金納付命令を受けた事業者は、算定率が1.5倍に（通常3% → **4.5%**） |
| **直罰の新設**     | 故意の優良誤認・有利誤認表示に対し、措置命令を経ずに**100万円以下の罰金**を科せる  |

課徴金は**対象商品の売上額（原則3年分）の3%**が基本。
通販のように単品で大きな売上を積む事業ほど、金額が大きくなりやすい。

### ステルスマーケティング規制（2023年10月1日〜）

広告であることを隠して第三者の感想のように見せる表示は、景表法上の不当表示として禁止された。

- 規制の名宛人は**商品を供給する事業者（広告主）**。インフルエンサー本人は対象外
- 「PR」「広告」等の表示を、消費者が分かる形で明示する必要がある
- **自社サイトへの口コミ転載**も、広告と分からない見せ方なら対象になりうる
- 事業者が投稿内容に関与していれば、報酬の有無にかかわらず広告と判断されうる

## 4. 薬機法——「効くと言えるのは誰か」を決める

薬機法（医薬品医療機器等法）は、商品のカテゴリーごとに**言ってよい範囲**を定めている。

| カテゴリー                       | 言える範囲の目安                             | 承認・届出 |
| -------------------------------- | -------------------------------------------- | ---------- |
| 医薬品                           | 疾病の治療・予防                             | 承認が必要 |
| 医薬部外品                       | 定められた効能（防止・緩和など）の範囲       | 承認が必要 |
| 化粧品                           | 定められた56の効能の範囲（「肌を整える」等） | 届出       |
| 健康食品（機能性表示食品を除く） | **身体の機能への影響をうたえない**           | —          |

未承認の商品について医薬品的な効能をうたうと、承認の有無にかかわらず違反になる（68条）。
また虚偽・誇大な広告は66条で禁じられ、**2021年8月に課徴金制度が導入**された
（対象期間の売上額の4.5%、遡及は原則3年）。
2025年11月には家庭用電位治療器（医療機器）について、薬機法に基づく**初の措置命令**が出されたと報じられている。

言える範囲は、承認・届出のハードルが高いカテゴリーほど広い。

```
  【言える範囲】広い ◀────────────────────────▶ 狭い
  【参入の手間】重い ◀────────────────────────▶ 軽い

   医薬品        医薬部外品      化粧品        機能性表示食品   いわゆる健康食品
   （承認）       （承認）       （届出）        （届出）         （なし）
     │             │              │              │                │
   治療・予防    定められた      定められた     届出した根拠     身体の機能に
   をうたえる    効能の範囲      56効能の範囲   の範囲のみ       触れられない
     │             │              │              │                │
     └─────────────┴──── 薬機法 ───┴──────────────┴──── 景表法・健康増進法 ──┘
                                        ※どのカテゴリーでも「言い過ぎ」は景表法で別途見られる
```

> 実務上の勘所：薬機法は「嘘かどうか」を問わない。
> **本当に効いていても、そのカテゴリーで言ってよい範囲を超えていれば違反**になる。
> だから通販の広告制作は、効果の検証より先に「この言葉を使ってよいか」の審査から始まる。

## 5. 機能性表示食品——届け出れば言える、が事後に見られる

食品で機能をうたう制度は3つある。

| 制度                         | 審査                       | 表示できること                     | 特徴                                             |
| ---------------------------- | -------------------------- | ---------------------------------- | ------------------------------------------------ |
| **特定保健用食品（トクホ）** | 国の個別審査・許可         | 許可された保健の用途               | 時間と費用がかかる。信頼性は高い                 |
| **栄養機能食品**             | 規格基準に合えば届出不要   | 定められたビタミン・ミネラルの機能 | 表現が固定されている                             |
| **機能性表示食品**           | **届出制**（国の審査なし） | 届出した科学的根拠の範囲           | 事業者の責任。参入しやすく、通販商材で多用される |

機能性表示食品は届出制のため参入しやすい反面、**事後チェックで問題になるリスク**を事業者が負う。
届出は通っていても、広告表現が届出の範囲を超えれば景表法の措置命令・課徴金の対象になりうる。

2024年の紅麹関連の健康被害問題を受け、制度は見直された。

| 見直し                              | 内容                                                                                                                 |
| ----------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| 健康被害情報の報告義務化            | 医師が健康被害を疑う情報を得たら、事業者は行政へ報告する義務                                                         |
| **GMPによる製造・品質管理の義務化** | 天然抽出物等を原材料とする錠剤・カプセル剤等が対象。2024年9月施行、**経過措置は2026年8月31日まで**（以降は完全適用） |
| 科学的根拠の質の向上                | 届出に用いるシステマティックレビューの要件を引き上げ                                                                 |

小規模な通販事業者にとって、GMP対応は製造委託先の選定と原価の両方に影響する。
2026年9月以降に体制が整っていない商品は、届出の維持が難しくなる可能性がある。

## 6. 実務のチェックポイント

| 段階     | 見るところ                                     | 根拠法                         |
| -------- | ---------------------------------------------- | ------------------------------ |
| 企画     | その商材カテゴリーで何を言えるか               | 薬機法、食品表示法             |
| 根拠     | 効果をうたうなら合理的根拠資料を先に用意したか | 景表法（不実証広告規制）       |
| LP制作   | 体験談・ビフォーアフター・二重価格の扱い       | 景表法、薬機法                 |
| 申込画面 | 最終確認画面の6項目、総額・回数・解約方法      | 特商法12条の6                  |
| 広告出稿 | インフルエンサー投稿に「PR」表示があるか       | 景表法（ステマ告示）           |
| 解約対応 | 電話が繋がるか、解約導線が分かるか             | 特商法                         |
| 記録     | 表示の根拠・画面のキャプチャを保存しているか   | 全般（立入・報告徴求への備え） |

## 7. 用語メモ

| 用語                       | 意味                                                                                                                              |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| **特定商取引法（特商法）** | 訪問販売・通信販売など、トラブルの起きやすい取引類型の手続と表示を定める法律。通販は「通信販売」に該当                            |
| **最終確認画面**           | 注文確定の直前に表示される内容確認画面。2022年6月施行の改正で6項目の表示が義務化                                                  |
| **返品特約**               | 通販での返品条件についての事業者の定め。表示がなければ到着後8日以内・送料消費者負担で返品可                                       |
| **優良誤認／有利誤認**     | 品質が実際より著しく良く見える表示／価格・条件が著しく有利に見える表示                                                            |
| **不実証広告規制**         | 効果をうたう表示について、消費者庁が15日以内に合理的根拠の提出を求められる制度                                                    |
| **課徴金**                 | 違反行為の売上に応じて納付させる金銭。景表法は原則3%（繰り返しは4.5%）、薬機法は4.5%                                              |
| **確約手続**               | 事業者の自主的な是正計画を認定し、措置命令・課徴金を回避できる制度。2024年10月施行                                                |
| **ステマ規制**             | 広告であることを隠した表示を不当表示とする景表法の告示指定。2023年10月1日施行。規制対象は広告主                                   |
| **機能性表示食品**         | 事業者が科学的根拠を届け出ることで機能を表示できる食品。国の個別審査はない                                                        |
| **GMP**                    | Good Manufacturing Practice。製造・品質管理の基準                                                                                 |
| **ダークパターン**         | 消費者を意図せぬ選択へ誘導する画面設計。解約の隠蔽や偽の期限表示など。規制の動きは [⑤ 直近トピック](05_直近トピック_2026.md) 参照 |
