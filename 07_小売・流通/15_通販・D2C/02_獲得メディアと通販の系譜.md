# ② 獲得メディアと通販の系譜（広告依存・テレビ通販・カタログ通販）

このノートで分かること：通販ブランドの新規顧客は「来る」のではなく「**買ってくる**」ものだということ。
どの媒体でいくらで買えるのか、そしてテレビ通販とカタログ通販がいまどうなっているのか。

> 結論：通販・D2Cは小売業の顔をした**広告業**である。
> 店舗小売が家賃を払って立地から客を得るのに対し、通販は**広告費を払って客を得る**。
> 家賃は下がらないが広告単価は競争で上がり続けるため、この業界の最大の経営リスクは**CPOの高騰**になる。

---

## 1. 店舗小売との対比で見る

| 項目             | 店舗小売                         | 通販・D2C                                |
| ---------------- | -------------------------------- | ---------------------------------------- |
| 客を得る手段     | 立地（家賃・保証金）             | 広告（CPO）                              |
| そのコストの性質 | **固定費**。売れなくても発生する | **変動費**。出稿を止めれば止まる         |
| コストの推移     | 契約期間中は一定                 | オークションなので**競合次第で毎日動く** |
| 売上を伸ばす方法 | 出店（時間と資本がかかる）       | 出稿を増やす（**翌日からできる**）       |
| 上限             | 物件がない                       | CPOが上限CPOを超えた瞬間に止まる         |

「翌日から増やせる」のが通販の強みだが、同時に**参入障壁が低い**という意味でもある。
誰でも同じ広告枠を買えるので、儲かるカテゴリーにはすぐ競合が入り、CPOが上がる。
通販の利益率は、商品力よりも**広告市場の需給**で決まってしまう部分が大きい。

## 2. 媒体別の特性

通販の獲得媒体は「ネットか否か」ではなく、**レスポンス（反応）を直接取れるか**で分類すると分かりやすい。

| 媒体                           | 反応の取り方                 | 主な年齢層     | CPOの傾向                | 量（一度に取れる数）       |
| ------------------------------ | ---------------------------- | -------------- | ------------------------ | -------------------------- |
| 検索広告（リスティング）       | LPへ誘導しカート             | 全年代         | 高いが安定               | 検索需要の分だけ（頭打ち） |
| SNS広告（Meta・TikTok等）      | LPへ誘導しカート             | 20〜50代       | **変動が激しい**         | 大きい                     |
| アフィリエイト                 | 成果報酬でLPへ               | 全年代         | 成果課金なので読める     | 媒体主の数に依存           |
| テレビCM（インフォマーシャル） | **フリーダイヤル**・QRコード | 50代以上       | 番組と時間帯で大きく変動 | 非常に大きい               |
| テレビショッピング（専門番組） | 電話・番組サイト             | 50代以上       | 枠買いは高額             | 大きい                     |
| ラジオショッピング             | 電話                         | 50代以上       | 相対的に安い             | 中                         |
| 新聞広告・折込チラシ           | 電話・ハガキ                 | 60代以上       | 部数×反応率で計算可能    | 中〜大                     |
| 同梱・同封（他社の荷物に同封） | ハガキ・電話                 | 媒体先の顧客層 | **最も安い部類**         | 小〜中                     |
| DM（ダイレクトメール）         | 電話・ハガキ                 | 既存・休眠顧客 | 既存向けなので安い       | 小                         |

```
  【認知させる】      【反応させる】        【初回を買わせる】   【定期に乗せる】
   テレビCM ─┐
   SNS動画 ──┼──▶ LP（ランディングページ）──▶ お試し購入 ──▶ 定期コース
   折込・新聞 ┘         └ 電話（コールセンター）┘        ↑
                                                    同梱物・LINE・アウトバウンド
```

**電話注文が今も現役**なのが通販業界の特徴である。
高齢層はネットのフォーム入力を嫌うため、テレビ・ラジオ・新聞を使うブランドは
コールセンターを持たないと商売にならない。ここが純ネット系D2Cとの大きな違いになる。

## 3. CPO高騰の3つの原因

CPOが上がり続けるのは景気の話ではなく、構造の話である。

1. **広告枠は有限でオークション**。Meta・Googleの広告在庫（表示回数）は人口とスクリーン時間で頭打ちで、
   出稿者が増えれば単価（CPM＝1,000回表示あたり単価）が上がる。
   SUPER STUDIOの調査では、EC／D2C事業者の**66.5%がデジタル広告の高騰を実感**していると報じられている（2025年、調査ベース）。
   2020年比でMeta・Google・TikTokのCPMが2〜3倍になったとする分析もある（2026年、推計・報道ベース）
2. **ターゲティング精度の低下**。AppleのATT（アプリのトラッキング許可）やCookie規制により、
   「買いそうな人」を当てる精度が落ちた。当たらない分だけ広告費が無駄になり、実質CPOが上がる
3. **同質な商材の乱立**。定期通販のモデルが広く知られ、同じような機能をうたう商品が増えた。
   差別化がなければ勝負は入札額になり、CPOは利益がゼロになるところまで上がる

> ポイント：CPO高騰の本質は「広告が高くなった」ではなく、
> 「**誰でも同じやり方ができるようになった**」こと。
> 参入障壁の低さが、そのまま利益の薄さとして返ってくる。

## 4. メディアミックス——旧来型メディアが残る理由

ネット広告が主流になっても、テレビ・ラジオ・折込が生き残っているのは次の理由による。

| 理由                       | 中身                                                                                    |
| -------------------------- | --------------------------------------------------------------------------------------- |
| **顧客層が違う**           | 高齢層はネット広告の接触が薄い。健康食品の主要顧客層と重なる                            |
| **LTVが高い**              | テレビ・新聞経由の顧客は継続率が高い傾向があるとされ、CPOが高くても採算が合う場合がある |
| **一度に大量に取れる**     | ネットは日々の入札で細かく積むが、テレビは1回の放送でまとまった件数が入る               |
| **信頼の調達**             | 「テレビでやっている」こと自体が信用になる。ネットの怪しさを打ち消す役割                |
| **ネット広告との相乗効果** | テレビCMを打つと指名検索が増え、検索広告のCPOが下がる（オンオフ統合）                   |

このため、規模の大きい通販会社ほど「Web＋テレビ＋紙」の**媒体ポートフォリオ**を組む。
媒体ごとにCPOとLTVを別々に測り、**媒体別の上限CPO**を設定するのが実務の標準形である。

## 5. テレビ通販の現在

テレビ通販は3つの型に分かれる。ここを混同すると業界地図が読めない。

| 型                                 | 仕組み                                                           | 代表                                      | 経済の特徴                                                           |
| ---------------------------------- | ---------------------------------------------------------------- | ----------------------------------------- | -------------------------------------------------------------------- |
| **インフォマーシャル（枠購入型）** | 放送局から30分程度の枠を買い、自社商品の番組を流す               | 健康食品・化粧品メーカー各社              | 枠代＝広告費。CPOが読みやすいが枠の質で乱高下                        |
| **専門チャンネル型**               | 24時間ショッピング専門の放送局を運営し、多数のメーカー商品を売る | QVCジャパン、ジュピターショップチャンネル | 自社が**媒体であり小売**。生放送で売れ行きを見て商品を差し替えられる |
| **自社メディア一体型**             | 放送枠・スタジオ・物流・コールセンターを自前で持つ               | ジャパネットホールディングス              | 媒体費を内部化。企画から販売までの回転が速い                         |

ジャパネットホールディングスの2025年12月期の連結売上高は**2,908億円（前期比6.7%増）で過去最高**と報じられている
（2026年4月報道、非上場のため開示は限定的）。
エアコン等の主力商品に加え、クルーズ船事業、2024年10月開業の長崎スタジアムシティ、
2025年1月開局のBS放送局「BS10」など、**通販の外側**が成長を支えている点が特徴的である。

一方で、テレビショッピング市場そのものは縮小方向にある。
調査会社の推計では国内テレビショッピング市場は約4,555億円で、今後5年間で約12%縮小するとされる
（2025年時点の推計。調査会社により定義・数値が異なる点に注意）。

> なぜ縮小するのか：テレビ通販の強さは「**尺（時間）で説明できる**」ことにあった。
> 実演して長所を語れば、比較検討なしに買ってもらえる。
> だがスマホ動画・ライブコマースが同じ機能をより安く提供するようになり、
> 優位性が相対的に薄れた。残るのは**高齢層への到達力**と**信頼**である。

## 6. カタログ通販の現在

カタログ通販は「紙の媒体費」と「在庫」を同時に抱えるため、需要が落ちると急速に苦しくなる。

```
  カタログ通販のコスト構造（イメージ）

   [制作費]+[印刷費]+[発送費]  ← 反応が0でも全額出ていく（≒固定費）
        │
        ▼  発行部数 × レスポンス率（注文率）
     注文件数
        │
        ▼
     売上 −（商品原価＋物流＋返品）＝ 粗利
        │
        ▼  粗利 < カタログ費 になった瞬間、部数を減らす
     部数削減 → 注文減 → さらに1冊あたりコスト上昇（印刷は部数が多いほど安い）
                        ↑______ 縮小のスパイラル ______↓
```

千趣会（ベルメゾン）は、2024年12月期に連結最終損益が**36億5,800万円の赤字**、
2025年12月期も**29億円の赤字見込み**と報じられている（2025年2月・2026年2月の決算報道）。
会員数の減少に対しカタログの獲得効果が追いつかず、前期までの3年間で営業赤字の累計が約174億円に達したとされる。
同社は通販事業を世代別に再編し、ベルメゾンネットを「**40〜50代女性**」にターゲットを絞る方針を示している（2025年）。

主要プレイヤーの現在地は次のとおり。

| 企業               | 主力ブランド       | 位置づけ                                                    |
| ------------------ | ------------------ | ----------------------------------------------------------- |
| 千趣会             | ベルメゾン         | 総合カタログ→ネット・世代特化へ転換中。赤字が続く           |
| ベルーナ           | ベルーナ、グラン   | 通販に加え不動産・ホテル・金融など多角化で収益を補う        |
| ディノス・セシール | ディノス、セシール | フジ・メディア・ホールディングス傘下。テレビ通販と紙を併用  |
| スクロール         | スクロール         | 通販に加え**通販事業者向けの支援（BPO・物流）**へ軸足を移す |
| フェリシモ         | フェリシモ         | 「毎月1回、テーマで届く」定期便型の企画通販                 |
| ニッセン           | ニッセン           | カタログ縮小・ネット中心へ。通販支援事業も展開              |

富士経済の調査では、カタログ・テレビ・ラジオ等を含む非ネット通販市場は
**2035年に2023年比11.2%減の1兆5,513億円**と予測されている（2025年公表の予測）。
縮小の理由は、消費者のECシフトに加え、**事業者自身がコスト削減のためカタログ部数を減らしている**こと。
つまり需要と供給の両側から縮んでいる。

## 7. それでも紙が残る用途

カタログは「集客媒体」としては厳しいが、**既存顧客向けのCRM媒体**としては生きている。

- 同梱物・DMとして送れば、CPOはネット広告より安く済むことが多い
- 高単価商品（宝飾、家具、旅行）は、紙のほうが検討時間を作れる
- 紙のカタログを見て**ネットで注文する**行動が一般化し、紙＝注文手段からカタログ＝カタログ（陳列）へ役割が変わった

この「紙で見てネットで買う」動きは、カタログの効果測定を難しくした。
電話注文が主だった時代は「このカタログから何件」と数えられたが、
いまは経路が分断され、**媒体別のCPO計算が難しくなっている**のが実務上の悩みである。

## 8. 用語メモ

| 用語                   | 意味                                                                                                        |
| ---------------------- | ----------------------------------------------------------------------------------------------------------- |
| **インフォマーシャル** | information + commercial。商品説明を番組仕立てにした長尺のテレビCM。通販の主力獲得手段のひとつ              |
| **レスポンス広告**     | 資料請求・注文など、直接の反応を目的とした広告。イメージ広告（ブランド広告）と対になる概念                  |
| **CPM**                | Cost Per Mille。広告が1,000回表示されるごとの費用。広告枠の需給を映す指標                                   |
| **LP**                 | Landing Page。広告から最初に着地するページ。通販では商品説明から注文まで1枚で完結させるものを指すことが多い |
| **レスポンス率**       | 配布・発行した媒体のうち、注文や問い合わせに至った割合                                                      |
| **オンオフ統合**       | オンライン（ネット）とオフライン（テレビ・紙）の広告効果を合わせて設計・測定すること                        |
| **アウトバウンド**     | 事業者から顧客へかける電話。対してインバウンドは顧客からの注文・問い合わせ電話                              |
| **BPO**                | Business Process Outsourcing。コールセンターや物流など、業務の外部受託                                      |
