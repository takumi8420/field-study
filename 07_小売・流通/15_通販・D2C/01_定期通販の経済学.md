# ① 定期通販の経済学（CPO・LTV・継続率）

このノートで分かること：通販・D2Cのブランドが「1人の顧客」をどう採算に乗せているか。
なぜ**初回は赤字で売るのが正常**で、なぜその商売が健康食品と化粧品に偏るのか。

> 結論：定期通販は小売業の見た目をしているが、経済の実体は**前払いの投資回収ビジネス**である。
> 広告費という形で先に数千円を投資し、顧客が3回・5回と買い続けることで回収する。
> だから経営の中心指標は売上ではなく、**CPO・LTV・継続率**の3つになる。

---

## 1. 結論：初回は赤字、回収は3〜5回目

単品の定期通販（サプリメント、化粧品など1〜数品目を繰り返し売る形）は、
初回を「お試し価格」で安く売り、2回目以降の通常価格で稼ぐ。
初回の時点では、商品原価＋送料＋広告費が売価を大きく上回るので、**確実に赤字**になる。

```
   累計利益
     ↑
  +  │                                    ┌─── 6回目以降は全部利益
     │                              ┌─────┘
   0 ├───────────────┬────●─────────┘          ● = 損益分岐（4〜5回目）
     │               │  回収点
  －  │  ●────●──────┘
     │  初回  2回目
     └──────────────────────────────────▶ 購入回数
        ↑
        広告費（CPO）をここで一括で払っている
```

この形を理解すると、通販会社の決算の読み方が変わる。
**新規獲得を増やすほど短期利益は減る**（広告費が先に立つ）ので、
「減益＝不調」とは限らず、「意図的に仕込んでいる」場合がある。
逆に「増益なのに新規顧客数が減っている」会社は、将来の売上を食い潰している可能性がある。

## 2. 3つの数字：CPO・LTV・継続率

| 用語         | 正式には                        | 意味（噛み砕くと）                                                                  | 計算式                            |
| ------------ | ------------------------------- | ----------------------------------------------------------------------------------- | --------------------------------- |
| **CPO**      | Cost Per Order                  | **新規顧客を1人連れてくるのにかかった広告費**。通販業界ではこの呼び方が定着している | 広告費 ÷ 新規注文件数             |
| **CPA**      | Cost Per Acquisition / Action   | ほぼ同義。ネット広告側の用語で、「資料請求1件」など注文以外の成果にも使う           | 広告費 ÷ 成果件数                 |
| **LTV**      | Life Time Value（顧客生涯価値） | **1人の顧客が生涯（実務では1年）に落とす金額、または粗利**                          | 平均単価 × 購入回数（×粗利率）    |
| **継続率**   | Retention Rate                  | 定期購入が翌月も続く割合。逆が**解約率（チャーン）**                                | 翌月も継続した人 ÷ 当月の定期顧客 |
| **F2転換率** | Frequency 2                     | 初回購入者のうち**2回目を買った人の割合**。ここが最大の関門                         | 2回目購入者 ÷ 初回購入者          |
| **引上率**   | —                               | お試し購入者が**定期コースに移行した割合**                                          | 定期移行者 ÷ お試し購入者         |

実務では「**LTV > CPO**」が事業成立の最低条件で、
健全な水準として「**1年LTV（粗利ベース）が CPO の2〜3倍**」を置く会社が多い。
上場企業の例では、北の達人コーポレーションが1年LTVから逆算した「上限CPO」を設定し、
それを超えた広告をシステムが自動停止する運用を公表している（同社IR・報道ベース、2026年）。

> ポイント：LTVは「結果」ではなく「**先に決める制約条件**」として使う。
> LTVが分からないまま広告を出すと、赤字を量産していることに数か月気づけない。

## 3. 数値例：1本3,980円のサプリメントで計算する

架空のモデルケース（実在企業の数値ではない）。
初回お試し980円、2回目以降3,980円、原価率20%、送料等の変動費を1件400円とする。

| 回数  | 売価    | 原価  | 送料等 | 粗利    | 広告費(CPO) | 累計損益     |
| ----- | ------- | ----- | ------ | ------- | ----------- | ------------ |
| 初回  | 980円   | 796円 | 400円  | −216円  | 6,000円     | **−6,216円** |
| 2回目 | 3,980円 | 796円 | 400円  | 2,784円 | 0           | −3,432円     |
| 3回目 | 3,980円 | 796円 | 400円  | 2,784円 | 0           | −648円       |
| 4回目 | 3,980円 | 796円 | 400円  | 2,784円 | 0           | **+2,136円** |
| 5回目 | 3,980円 | 796円 | 400円  | 2,784円 | 0           | +4,920円     |
| 6回目 | 3,980円 | 796円 | 400円  | 2,784円 | 0           | +7,704円     |

ここから3つのことが読める。

1. **初回の原価は「売れば売るほど損」**。お試し価格は商品ではなく**顧客名簿への支払い**である
2. 回収は4回目。つまり**平均4回続かないブランドは存在できない**
3. CPOが6,000円から9,000円に上がれば、回収は5〜6回目にずれる。
   CPOの上昇は、そのまま**必要継続回数の上昇**に変換される

なお、実務ではここに**コールセンター費・同梱物・カード決済手数料・在庫廃棄**が乗る。
広告費以外の販管費も10〜20%規模でかかるため、上の表より回収は遅くなるのが普通である。

## 4. 継続率が1ポイント動くと何が起きるか

定期購入の平均継続回数は、継続率 r のとき **1 ÷ (1 − r)** で近似できる。
この式は非線形なので、継続率が高いほど1ポイントの改善価値が跳ね上がる。

| 月次継続率 | 平均継続回数 | 売上LTV（3,980円換算） | 粗利LTV（概算） |
| ---------- | ------------ | ---------------------- | --------------- |
| 70%        | 3.3回        | 約13,200円             | 約9,200円       |
| 80%        | 5.0回        | 約19,900円             | 約13,900円      |
| 85%        | 6.7回        | 約26,600円             | 約18,600円      |
| 90%        | 10.0回       | 約39,800円             | 約27,900円      |
| 95%        | 20.0回       | 約79,600円             | 約55,700円      |

80%→85%の改善でLTVは約1.34倍、90%→95%では約2倍になる。
**継続率の改善は、広告費の削減より効きが大きい**。
だから定期通販の会社は、獲得部隊と同じかそれ以上の人数をCRM（既存顧客の維持）に割く。

ただし実際の解約は「毎月一定率」ではなく、**初期に集中して後半は落ち着く**。
1〜3回目の離脱が全体の大半を占めるため、F2転換率（2回目を買わせること）が最重要KPIになる。

## 5. なぜ健康食品と化粧品なのか

定期通販の主力カテゴリが偏っているのは、嗜好の問題ではなく**経済条件**である。
（以下は商品の効果についての説明ではない。効果・効能の訴求は法規制の対象で、[④ 規制と表示](04_規制と表示.md) で扱う）

| 条件                               | なぜ必要か                     | 健康食品                       | 化粧品 | 一般食品        | 家電・アパレル  |
| ---------------------------------- | ------------------------------ | ------------------------------ | ------ | --------------- | --------------- |
| **粗利率が高い**                   | 初回赤字とCPOを吸収できる      | ◎（原価率10〜25%程度とされる） | ◎      | △               | ✕〜△            |
| **なくなる（消費サイクルが一定）** | 次回が自動的に必要になる       | ◎（約1か月で消費）             | ◎      | ◎               | ✕               |
| **軽い・小さい**                   | 宅配便の送料・メール便が使える | ◎                              | ◎      | △（重い・冷蔵） | ✕               |
| **品目が少なくて済む**             | 在庫管理が単純、欠品しにくい   | ◎                              | ○      | ✕               | ✕（サイズ・色） |
| **店頭で比較されにくい**           | 価格競争に巻き込まれにくい     | ○                              | ○      | ✕               | ✕               |
| **結果が出るまで時間がかかる**     | 「もう少し続けよう」が働く     | ○                              | ○      | —               | —               |

最後の行は誤解されやすいが、これは**商品の良し悪しの話ではない**。
「1か月で結論が出ない性質の商材は、解約の意思決定が先送りされやすい」という消費者行動の観察であり、
だからこそ**消費者保護の規制が厳しく入る領域**でもある、と理解するのが正確である。

逆に、生鮮食品やアパレルで定期購入が定着しにくい理由も同じ表で説明できる。
重くて送料負けする、サイズや好みで返品が出る、在庫のSKU（品目数）が多すぎる。

## 6. キャッシュフローの罠——成長するほど現金が減る

定期通販の最大の落とし穴は、損益ではなく**資金繰り**にある。

```
  【現金の出】                           【現金の入】
   広告費 ────▶ 媒体に翌月払い             初回代金 980円（同月）
   商品仕入 ──▶ 製造委託先に1〜2か月後      2回目 3,980円（1か月後）
                                          3回目 3,980円（2か月後）…

   ┌─────────────────────────────────────────────┐
   │ 新規1人あたり −6,216円 を今月出し、          │
   │ 回収完了は3〜4か月後                          │
   │ → 新規を月1,000人増やす＝約620万円の運転資金が消える │
   └─────────────────────────────────────────────┘
```

売上が伸びているのに現金が足りない、という現象がここで起きる。
成長期のD2Cが借入やエクイティ（増資）に依存しやすいのはこの構造のためで、
金利上昇や資金調達環境の悪化が、そのまま成長の上限になる。
（資金調達環境の変化については [③ D2Cブームの総括](03_D2Cブームの総括.md) 参照）

## 7. 解約を減らす仕組みと、その法的な限界

継続率を上げる打ち手は大きく4つある。

| 打ち手                                         | 内容                                             | 注意点                                                     |
| ---------------------------------------------- | ------------------------------------------------ | ---------------------------------------------------------- |
| **同梱物（インサート）**                       | 商品に冊子・使い方ガイド・次回案内を同封         | 通販で最もCPOが安い「媒体」。ただし効果測定がしにくい      |
| **コールセンター（アウトバウンド）**           | 購入後のフォロー電話、解約希望者への引き止め提案 | 引き止めが度を越すと「解約妨害」として規制の対象になりうる |
| **LINE・メール・アプリ**                       | 配送前通知、休止・スキップの案内                 | 解約導線を隠すと特商法・景表法上の問題になる               |
| **柔軟な設計（休止・周期変更・回数縛りなし）** | 「やめる」を「止める」に変える                   | 短期の継続率は下がるが、LTVは上がることが多い              |

> 重要：**経済的に合理的でも、法的に許されない売り方がある**。
> 「初回実質無料」の強調表示、解約電話が繋がらない設計、最終確認画面での条件の伏せ方などは、
> 2022年6月施行の改正特定商取引法の直接の対象であり、業務停止命令の実例がある。
> 詳しくは [④ 規制と表示](04_規制と表示.md)。

## 8. 定期通販のKPI一覧（経営会議で見る順番）

| 段階 | KPI                      | 見方                                                       |
| ---- | ------------------------ | ---------------------------------------------------------- |
| 獲得 | 新規件数／CPO            | CPOは「上限CPO」との比較で見る。絶対値だけでは意味がない   |
| 引上 | 引上率／F2転換率         | 初回から2回目の壁。1ポイントの改善価値が最も大きい         |
| 継続 | 月次継続率／平均継続回数 | コース別・獲得媒体別に分解する（媒体でLTVが違う）          |
| 収益 | 1年LTV／LTV÷CPO          | 2〜3倍が健全とされる目安（業界の実務値、公式統計ではない） |
| 資金 | 運転資金／回収期間       | 成長率の上限を決める。損益より先に効く                     |
| 在庫 | 在庫回転／欠品率         | 定期は「届かない」が即解約に直結する                       |

## 9. 用語メモ

| 用語                     | 意味                                                                                                         |
| ------------------------ | ------------------------------------------------------------------------------------------------------------ |
| **CPO**                  | Cost Per Order。新規顧客1人（1注文）の獲得にかかった広告費。広告費÷新規注文件数                              |
| **CPA**                  | Cost Per Acquisition。CPOとほぼ同義。ネット広告側の呼び方                                                    |
| **LTV**                  | Life Time Value（顧客生涯価値）。1人の顧客が生涯にもたらす売上または粗利。実務では「1年LTV」を使うことが多い |
| **上限CPO**              | LTVから逆算して「ここまでなら払ってよい」と決めた獲得単価の上限                                              |
| **F2転換率**             | 初回購入者のうち2回目を購入した割合。定期通販で最重要のKPI                                                   |
| **引上率**               | お試し購入者が定期コースへ移行する割合                                                                       |
| **チャーン（解約率）**   | 一定期間に定期購入をやめた顧客の割合。1−継続率                                                               |
| **単品通販**             | 1〜数品目に絞って繰り返し売る通販の形。定期購入と組み合わせて使われる                                        |
| **CRM**                  | Customer Relationship Management。既存顧客の維持・育成の活動全般                                             |
| **同梱物（インサート）** | 商品に同封する冊子やチラシ。安価な販促媒体として使われる                                                     |
| **SKU**                  | Stock Keeping Unit。在庫管理上の最小品目単位（色・サイズ違いは別SKU）                                        |
