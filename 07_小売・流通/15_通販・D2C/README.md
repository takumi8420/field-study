## 1. 業界の定義・範囲

**通販（通信販売）**とは、店舗を持たず、広告やカタログを見た消費者が郵便・電話・ネットで注文する販売形態を指す。
法律上は特定商取引法の「通信販売」に位置づけられる。

**D2C（Direct to Consumer）**は、メーカーが卸・小売を通さず直接消費者に売る形。
通販の一形態であり、2015年以降のSNSとカートSaaS（Shopify等）の普及で広まった呼び方である。

境界を整理すると次のようになる。

```
  ┌──────────────── 無店舗小売 ────────────────┐
  │                                              │
  │  【通販（通信販売）】                        │
  │   ├ ネット通販 ─┬ モール出店   ← EC側で詳述 │
  │   │              └ 自社EC ─┬ D2C（メーカー直販）│  ← このフォルダ
  │   │                        └ 小売業者の自社EC    │
  │   ├ テレビ通販・ラジオ通販     ← このフォルダ │
  │   ├ カタログ通販               ← このフォルダ │
  │   └ 新聞・折込・DM             ← このフォルダ │
  │                                              │
  │  【訪問販売・電話勧誘販売】← 別の規制体系    │
  └──────────────────────────────────────────────┘
```

隣接業界との線引き：

- **ECとの違い**：ECは「ネットで売買が成立する取引」全般を指す概念。通販はそれを含むより広い販売形態
- **訪問販売との違い**：消費者が広告を見て自分から申し込むのが通販。事業者から出向くのが訪問販売。クーリングオフの有無が分かれる
- **小売業との違い**：通販は立地ではなく広告で客を得る。固定費（家賃）ではなく変動費（広告費）で集客する

## 2. 市場規模と成長性

| 指標                                       | 数値                                              | 年         | 出典                               |
| ------------------------------------------ | ------------------------------------------------- | ---------- | ---------------------------------- |
| 通販・EC市場売上高                         | **15兆4,085億円**（前年比+5.9%、速報）            | 2025年度   | JADMA（日本通信販売協会）          |
| 同上                                       | 14兆5,500億円（前年比+7.3%）                      | 2024年度   | JADMA                              |
| 非ネット通販（カタログ・テレビ・ラジオ等） | 2035年に**1兆5,513億円**（2023年比11.2%減）と予測 | 2025年公表 | 富士経済（予測）                   |
| テレビショッピング市場                     | 約4,555億円、今後5年で約12%縮小と推計             | 2025年     | 調査会社推計（定義により差がある） |

構図はこうである。**市場全体は伸びているが、伸びているのはネット部分だけ**。
カタログ・テレビ・ラジオといった旧来型メディアの通販は縮小しており、
しかもネット部分の伸びの大半はモール・大手に集まる。
中小のブランドは「伸びている市場の中で個別には苦しい」という状態に置かれている。

## 3. バリューチェーン（川上 → 川下）

```
 ①商品開発      ②製造        ③獲得（広告）     ④受注・決済    ⑤物流      ⑥CRM
  企画・処方     OEM／自社工場  Web広告・TV・紙   カート・CC      3PL・自社    同梱・LINE
    │              │              │                │             │           │
    ▼              ▼              ▼                ▼             ▼           ▼
  原価を決める   品質と供給を   ★ここに金が     取りこぼしを   欠品と遅延    継続率を
                 決める          集中する         防ぐ          が解約を生む  決める
                                （売上の20〜40%）
```

**付加価値が集まるのは①商品開発と⑥CRM**、**コストが集中するのは③獲得**である。
製造はOEM（他社への製造委託）で外に出すのが一般的なので、通販会社は製造業ではなく
「広告と顧客管理の会社」に近い。
CC＝コールセンター。電話注文が残るカテゴリーでは、ここが売上の入口になる。

## 4. 主要プレイヤーとシェア

「通販事業者」は出自で4つに分かれ、経済構造がそれぞれ違う。

| 類型                      | 代表企業                                                                             | 立ち位置                         | 特徴                                                                                |
| ------------------------- | ------------------------------------------------------------------------------------ | -------------------------------- | ----------------------------------------------------------------------------------- |
| **メディア一体型**        | ジャパネットホールディングス                                                         | 放送局・スタジオ・物流・CCを内製 | 2025年12月期 売上高2,908億円（+6.7%）で過去最高。通販の外（スポーツ・観光）にも展開 |
| **専門チャンネル型**      | QVCジャパン、ジュピターショップチャンネル                                            | 24時間のショッピング専門放送     | 自社が媒体かつ小売。生放送で売れ行きを見て商品を差し替えられる                      |
| **カタログ通販**          | 千趣会（ベルメゾン）、ベルーナ、ディノス・セシール、スクロール、フェリシモ、ニッセン | 紙を起点にネットへ移行中         | 千趣会は2025年12月期に29億円の最終赤字見込み。多角化や通販支援で補う企業も          |
| **単品リピート通販／D2C** | 健康食品・化粧品メーカー各社（上場例：北の達人コーポレーション、新日本製薬など）     | 少品目を定期購入で売る           | CPOとLTVの差が利益そのもの。広告市況に業績が左右される                              |

シェアの公式統計は存在しない（非上場企業が多く、定義も分かれるため）。
上の表は各社の公表値・報道をもとにした位置づけの整理である。

## 5. 収益モデル・コスト構造

単品リピート通販の売上100に対する費用構成の目安（業界の実務値であり、公式統計ではない）。

| 項目                 | 目安       | 性質     | コメント                                    |
| -------------------- | ---------- | -------- | ------------------------------------------- |
| 売上                 | 100        | —        | —                                           |
| 商品原価             | 10〜25     | 変動費   | 粗利率75〜90%。これが高いから広告費を払える |
| 物流費（送料・梱包） | 8〜15      | 変動費   | 小さく軽い商材が選ばれる理由                |
| 決済手数料           | 2〜4       | 変動費   | 後払い・コンビニ払いは料率が高め            |
| **広告宣伝費**       | **20〜40** | 変動費   | **最大の費目**。ここが業績の振れ幅を作る    |
| コールセンター・CRM  | 5〜10      | 準固定費 | 継続率を買っている費用                      |
| 人件費・その他販管費 | 10〜15     | 固定費   | —                                           |
| **営業利益**         | **0〜15**  | —        | 新規獲得を増やすと一時的に下がる            |

> ポイント：**新規獲得を増やした期は利益が下がり、抑えた期は利益が出る**。
> 通販会社の決算は「利益が出た＝好調」とは限らない。新規顧客数と定期顧客数の増減を必ずセットで見る。

詳しい計算は [① 定期通販の経済学](01_定期通販の経済学.md) を参照。

## 6. 競争要因（KSF）と参入障壁

| KSF                        | 中身                                                             |
| -------------------------- | ---------------------------------------------------------------- |
| **上限CPOの管理**          | LTVから逆算した獲得単価の上限を持ち、媒体別・日次で守れるか      |
| **継続率（リテンション）** | 継続率1ポイントの改善がLTVに非線形で効く。獲得より投資効率が高い |
| **媒体の分散**             | 単一媒体依存はアルゴリズム変更・規制で一気に崩れる               |
| **商材の粗利率**           | 粗利率が低いと広告費を払えない。この一点で参入可否が決まる       |
| **運転資金**               | 広告費が先払い、回収は数か月後。成長率の上限は資金力で決まる     |
| **法務・薬事の体制**       | 表現の審査体制がないと、成長した瞬間に行政処分で止まる           |

**参入障壁は低く、撤退障壁も低い**。
カートSaaSで店は当日作れ、OEMで商品も作れる。だからこそ競合が絶えず入り、CPOが上がる。
本当の障壁は「**顧客リストと継続率**」で、これだけは買うか時間をかけるしかない。

## 7. 規制・法制度

| 法律                       | 何を規制するか                                            | 押さえるポイント                                                                                                                                     |
| -------------------------- | --------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **特定商取引法**           | 通信販売の広告表示義務、最終確認画面の6項目表示、解約妨害 | 2021年改正（**2022年6月1日施行**）で定期購入対策を導入。誤認表示には取消権。通販に**クーリングオフはない**                                           |
| **景品表示法**             | 優良誤認・有利誤認の禁止、不実証広告規制                  | 課徴金は対象売上の3%（繰り返しは4.5%）。2023年改正（**2024年10月1日施行**）で確約手続・直罰を新設。ステマ規制は**2023年10月1日**施行で、対象は広告主 |
| **薬機法**                 | 医薬品的な効能表示の禁止、虚偽誇大広告の禁止              | 2021年8月に課徴金制度（対象売上の4.5%）を導入                                                                                                        |
| **食品表示法・健康増進法** | 機能性表示食品の届出制、誇大表示の禁止                    | 2024年の制度見直し。GMP義務化の経過措置は**2026年8月31日**まで                                                                                       |
| **消費者契約法**           | 不当な勧誘・不当条項の無効                                | 取消権や無効条項が定期購入の契約設計に影響する                                                                                                       |
| **個人情報保護法**         | 顧客データの取得・利用・提供                              | D2Cの生命線である顧客データの扱いに直結                                                                                                              |

2026年時点の焦点は**ダークパターン規制**である。
消費者庁の「デジタル取引・特定商取引法等検討会」が2026年8月に中間とりまとめ案を公表し、
申込画面だけでなく**解約プロセス全体**を規律の対象とする方向が示された（法案化・施行時期は未定）。

詳しくは [④ 規制と表示](04_規制と表示.md)。

## 8. 最近のトピック

→ [⑤ 直近トピック（2026年9月時点）](05_直近トピック_2026.md)

1. **市場は15.4兆円**（2025年度、JADMA速報、+5.9%）。ただし伸び率は7.3%（2024年度）から鈍化
