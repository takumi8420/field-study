② SPAというモデル

小売・流通アパレル・SPA
あこのページの単語集用語に触れると意味を確認できます19語
SPA（製造小売）PB（プライベートブランド）バイイング型消化仕入れ（売上仕入れ）定期借家（定期賃貸借）歩率（ぶりつ）ニアショア（近隣生産）後染めBOPISショールーミングSKUオンデマンド生産マルチブランド関連ノート：① アパレルの経済学③ 市場の変化④ 直近トピック（2026年9月）百貨店通販・D2C繊維商社

このノートで分かること：SPA＝企画から販売までを1社でやる服屋。
ただの垂直統合ではない。「売れ行きの情報が企画に直接返ってくる」ことと、「在庫リスクを全部自分で背負う」ことがセットで、この2つが同時に起きるとどう変わるかを見ていく。

ポイント：SPAは「中間マージンを抜いて安くする仕組み」だと説明されがちだが、それは副産物。
本質は 「値下げするかどうかを自分で決められる」「何枚作るかを売れ行きを見て決められる」という意思決定の一元化 にある。

1. SPAとは何か

SPA＝ Specialty store retailer of Private label Apparel。日本語では 製造小売（せいぞうこうり）。
1986年に米GAPの当時の会長が自社を説明するために使った言葉が、そのまま業界用語になった。

定義を実務的に言い直すと、「自社ブランドの服を、自分で企画し、自分で作らせ、自分の店（とEC）で売る会社」。
※ 自社工場を持つ必要はない。ユニクロもZARAも縫製は外部委託が中心。持つのは工場ではなく「企画権・発注権・売価決定権」。

従来の分業型との違い

【従来型：アパレルメーカー → 卸/百貨店 → 消費者】

  企画       生産手配       卸売        売場運営      販売
  ├────────┤ ├──────┤ ├─────┤ ├──────┤
  アパレルメーカー   商社/OEM      問屋      百貨店/専門店   消費者
     ↑                                    ↑
     │                                    │
     └──── 売れ行きの情報が返るのは数週間〜数ヶ月後 ───┘
           （しかも「何がなぜ売れなかったか」は分からない）

  ※ 値下げの判断・在庫の持ち方・売場の作り方が全部バラバラの会社の手にある


【SPA型：全部1社】

  企画 ──▶ 素材調達 ──▶ 生産委託 ──▶ 物流 ──▶ 自社店舗/EC ──▶ 消費者
   │                                                    │
   └────────── 日次で売上データが戻る ──────────┘
                         ↓
          翌週の追加発注・値下げ・店間移動を即決できる
論点 分業型 SPA型
売れ行き情報のスピード遅い（卸・百貨店経由）日次・店別・SKU別で即座
値下げの決定権分散（売場は百貨店、商品はメーカー）自社で一元
在庫リスク分担（消化仕入れなら小売はノーリスク）全部自社
粗利の取り分各段階で薄く分かれるまとめて取れる
失敗したときの傷分散されて浅い深い。一社で被る
価格の自由度低い（卸価格の慣行に縛られる）高い。安くも高くもできる

つまりSPAは 「リターンと引き換えにリスクを全部引き取った形態」。
だから 在庫管理が下手なSPAは、分業型より早く死ぬ。

2. 一気通貫にすると具体的に何が変わるか

① アパレルの経済学 で見たとおり、利益のスイッチは プロパー消化率（定価のまま売れた割合） にある。
SPAはこの数字を上げるための仕掛けを、4カ所で持てる。

変わる場所 分業型では SPAでは 効く指標
① 需要の読み方展示会での受注数＝小売の読み実売データそのもの。店別・サイズ別・時間帯別初期投入量の精度
② 追加生産卸を通すので遅い・小ロット不可生地を先に押さえ、期中に直接追加発注プロパー消化率
③ 値下げ判断売場の主導権が小売側にある消化率を見て自社判断。早く浅く打てる値下げロス率
④ 価格設計卸価格＋小売マージンの積み上げ最終売価から逆算して原価を決められる値入率

④が特に大きい。分業型は「原価→卸値→定価」と積み上がるので、各段階のマージンが売価に乗る。
SPAは「この服は1,990円で売りたい」から始めて、素材・工程・ロットを逆算で設計できる。ユニクロが素材メーカーと共同開発をするのはこの構造ゆえである（例：東レと共同開発したヒートテック、2003年発売）。

【価格の作り方が逆になる】

  分業型（積み上げ）
   原価 2,000 ─▶ 卸値 4,000 ─▶ 定価 9,800
                （メーカー粗利）  （小売粗利）

  SPA型（逆算）
   定価 3,990 ─▶ 許容原価 1,600 ─▶ この原価で作れる素材・工程・ロットを探す
                                      ↓
                  「100万枚まとめて発注するから、この値段で」という交渉が成立

3. ベーシックとトレンド：在庫リスクの向きが逆になる

SPAの中でも 何を売るか で、リスクの形が正反対になる。ここを混同すると業界が理解できない。

【在庫の「賞味期限」が違う】

  ベーシック（白T・ヒートテック・チノパン・ダウン）
   価値 ██████████████████████████  ← 翌年も同じ値段で売れる
        S1    S2    S3    S4    S5
   ★ 売れ残りは「持ち越せる」＝在庫は資産に近い
   ★ ただし計画は大ロット・長期。外すと在庫の山が何年も残る

  トレンド（今季の柄・シルエット・色）
   価値 ██████▓▓▒▒・・                ← 3ヶ月で値打ちが消える
        投入  6週  10週  14週  セール後
   ★ 売れ残りは「損失」＝在庫は爆弾に近い
   ★ ただし少量ずつ投入できるので、1回のミスは小さい
軸 ベーシック型（ユニクロ・GU の定番） トレンド型（ZARA・一部の国内SPA）
1品番あたりの生産量数十万〜数百万枚数千〜数万枚
生産地遠い・安い（中国内陸／ベトナム／バングラデシュ）近い・速い（欧州近隣／中国沿岸）
リードタイム6〜9ヶ月2〜6週間
年間の企画本数少ない（改良の積み重ね）非常に多い（年に万単位のデザイン）
売れ残りの扱い翌年に持ち越し可能値下げで消化、持ち越し不可
リスクの形大きな塊が一度に外れる（計画リスク）小さく何度も外れる（運用リスク）
原価率低い（大ロットで安く作れる）高い（小ロット・近場生産）
値下げ率低く抑えやすい構造的に値下げ前提（でも浅く早く打つ）
勝ち筋素材の差別化と規模の経済回転の速さとプロパー消化率

面白いのは、両方とも「値下げを減らす」という同じゴールを、正反対の方法で追っている点。
ベーシックは「賞味期限を無くす」ことで、トレンドは「賞味期限内に売り切る速さ」で解いている。

4. ZARAの短サイクル：なぜ定価で売れるのか

ZARA（スペイン・インディテックス）は「ファストファッション」の代名詞だが、実態は安さより回転の速さで儲ける会社である。

【ZARA型の週次ループ】

     ┌──────────────────────────────────┐
     │                                                        │
     ▼                                                        │
  店頭投入 ──▶ 日次で売上データ ──▶ 本社デザインチーム        │
  （少量）        （店長の所見も）      ・売れた要素を抽出      │
     ▲                                  ・翌週の企画に反映      │
     │                                        │                │
     │          ┌─────────────────┘                │
     │          ▼                                              │
     └── 近隣生産（スペイン・ポルトガル・モロッコ・トルコ）──┘
            2〜4週間で店頭へ

  ★ シーズン当初に投入するのは全体の2〜3割程度とされ、
    残りは「売れ行きを見てから」決める。
  ★ だから「作りすぎ」が構造的に起きにくく、
    定価で売れる比率（プロパー消化率）が高くなる。
  • 生地は先に大量に押さえる（未染色のまま）。染色と裁断縫製だけを直前に走らせる＝「後染め」の活用
  • 近場生産のぶん原価は高い。それでも値下げが少ないので最終粗利は残る
  • 広告費をほとんど使わず、その分を一等地の家賃に回す（店舗そのものが広告）

一方で、ZARAの成長は近年鈍化している。インディテックスの2025年売上は約400億ユーロ、純利益は60億ユーロ超に達した一方、ZARAブランド単体の売上は約280.5億ユーロで前年比+1%にとどまり、2020年を除けば少なくとも10年で最低の伸びと報じられている（Modaes、2026年）。欧州の消費の弱さと、後述するSHEIN型の攻勢が背景にある。

6. 店舗とECの融合

SPAはチャネルを自社で握っているので、店舗とECを「別の会社」ではなく「1つの在庫」として運営できる。ここが百貨店経由のブランドとの決定的な差になる。

やり方 中身 効果
在庫の一元化店の在庫もECの在庫も同じデータベースで見る欠品の機会損失が減る。値下げ判断の精度が上がる
店舗受取（BOPIS）ECで買って店で受け取る送料が浮く。来店するのでついで買いが起きる
店頭在庫のEC販売店の在庫をEC注文の出荷元にする在庫消化が速くなる。物流距離が短い
試着だけの店舗売らずに見せる（ショールーミング）賃料を抑えつつ、ECの返品率を下げる
アプリ会員購買履歴で個別に提案。クーポン配信値下げを「全員一律」ではなく「反応する人だけ」に打てる
【在庫を1つにすると値下げが減る】

  分離しているとき
   店A 在庫30 ← 売れない → 値下げ
   店B 在庫30 ← 欠品      → 売り逃し
   EC  在庫30 ← 売れない → 値下げ
   ＝ 同時に「値下げ」と「売り逃し」が起きる最悪の状態

  一元化したとき
   共通在庫 90 ──▶ 需要のある場所へ都度引き当て
   ＝ 値下げの前に「移す」という手が一手増える

ただしEC比率が上がると 物流費と返品コスト が増える。
店舗は「賃料は高いが返品がほぼ無い」チャネル、ECは「賃料は無いが配送と返品が乗る」チャネル。
どちらが安いかは商品単価と返品率次第で、一概にECが有利とは言えない。→ 通販・D2C

7. グローバル展開の難しさ

SPAは国内で完成度を上げても、海外に出ると同じようには効かない。理由は「服がローカルな商品」だから。

壁 中身 実際に起きること
気候北半球と南半球、熱帯と寒帯で季節が逆・無い秋冬の主力（ダウン・ヒートテック）が売れない市場がある
体型・サイズ同じMでも欧米とアジアで寸法が違うサイズ展開が増える＝SKUが増える＝在庫が分散する
嗜好色・柄・丈・着丈の好みが国ごとに違う「日本で売れた服」がそのままでは売れない
価格の位置づけ同じ価格でも国によって「安い服」「中価格帯」が変わる日本では量販、東南アジアでは中上位ブランド、という現象
物流とリードタイム生産地と販売地が遠いほど在庫を積む必要がある在庫回転が落ち、値下げリスクが上がる
現地競合と商慣行出店条件、モールの力関係、人件費一等地が取れないと集客ができない

ユニクロは海外ユニクロ事業が第3四半期累計で売上収益1兆8,340億円（前年同期比+25.9%）・事業利益3,453億円（同+45.4%）と、国内（売上8,676億円）を大きく上回る規模に育った（2026年8月期）。ただしこれは20年以上かけた結果で、その過程では英国・米国での苦戦と撤退・縮小を繰り返している。

グローバル展開の本質的な難しさは「在庫リスクが国の数だけ増える」こと。
1つの国で売れ残った在庫を別の国に回すのは、関税・表示・サイズ・季節の問題で思ったほど簡単ではない。

8. 百貨店アパレルの凋落との対比

日本のアパレルを理解するうえで避けて通れないのが、百貨店を主戦場にしてきたブランドがなぜ苦しくなったかである。ここはSPAの裏写しとして読むと分かりやすい。

消化仕入れという仕組み

消化仕入れ（しょうかしいれ）＝ 商品が客に売れた瞬間に、百貨店がその商品を納入業者から仕入れたことにする取引形態。「売上仕入れ」とも呼ぶ。

【消化仕入れ：在庫リスクは誰が持っているか】

  通常の仕入（買取）
   百貨店が商品を買う ──▶ 在庫は百貨店のもの ──▶ 売れ残りは百貨店の損

  消化仕入れ
   商品はアパレル企業のまま ──▶ 客に売れた瞬間に
                                 「仕入れ」と「販売」が同時発生
   ┌─────────────────────────────────┐
   │ 在庫リスク      ：アパレル企業                      │
   │ 販売員の人件費  ：アパレル企業（派遣販売員）        │
   │ 売場の内装・改装：アパレル企業                      │
   │ 百貨店の取り分  ：売上の25〜35%程度（歩率）         │
   └─────────────────────────────────┘
   ＝ 百貨店から見れば「リスクなしで場所を貸している」に近い
論点 百貨店アパレル SPA
売場の主導権百貨店（配置・改装・催事）自社
値下げの決定百貨店のセール日程に従う自社判断でいつでも
販売データPOSは百貨店のもの。粒度が粗い自社で全て持つ
販売員自社負担の派遣販売員自社スタッフ
実質的なコスト売上の25〜35%が百貨店へ家賃10%前後
在庫リスクアパレル企業が全部持つ自社が全部持つ

「リスクは自分、主導権は相手」——これが百貨店アパレルの構造的な弱点だった。
SPAは同じ在庫リスクを負うが、そのかわり売価・値下げ・売場・データの全部を握っている。同じリスクなら主導権がある方が有利、という単純な帰結になる。

さらに百貨店側も、近年は 消化仕入れから定期借家（テナント賃貸）への転換 を進めている。大丸心斎橋店本館の改装では、化粧品・ラグジュアリー等の一部を除き、アパレル・食品を基本的に定期賃貸借契約とする方針が報じられた。これは百貨店が「アパレルを売る場所」から「場所を貸す不動産業」へ性格を変えつつあることを意味する。→ 百貨店

9. SPAの弱点

SPAは万能ではない。構造上の弱点も明確にある。

弱点 なぜ起きるか
在庫を外したときの傷が深い全部自社で被るため。分業型は卸・小売と痛みを分け合える
固定費が重い店舗網・物流センター・システム・企画人員は売上が落ちても減らない
ブランドの幅を広げにくい1つのブランドで客層を広げると、誰にも刺さらなくなる（だからマルチブランド化する）
規模が要る大ロット発注の交渉力も、物流センターも、システム投資も規模ありき。中途半端な規模が一番苦しい

用語メモ

用語 意味
SPA（製造小売）Specialty store retailer of Private label Apparel。企画・生産手配・販売を1社で行う業態。1986年に米GAPが自称したのが起源
PB（プライベートブランド）小売が自ら企画する自社ブランド商品。SPAはPBのみで構成される形態
バイイング型他社が作った商品を仕入れて売る形態。しまむらが源流だが近年はPB比率を上げている
消化仕入れ（売上仕入れ）客に売れた瞬間に小売が仕入れたことにする取引。在庫リスクは納入側が持つ。百貨店の標準形
定期借家（定期賃貸借）期間を定めた賃貸契約。百貨店が売場をテナントに貸す形へ転換する際の契約形態
歩率（ぶりつ）消化仕入れで百貨店が取る売上に対する割合。アパレルで25〜35%程度
ニアショア（近隣生産）販売地に近い国・地域で作ること。リードタイムが短い代わりに原価は高い
後染め生地を先に織り／編んでおき、色は直前に付ける手法。色の意思決定を遅らせられる
BOPISBuy Online, Pick-up In Store。EC購入・店舗受取
ショールーミング店では見るだけで、購入はECで行う行動。またはそれを前提にした「売らない店」
SKU在庫管理の最小単位。色・サイズ違いは別SKU
オンデマンド生産少量を投入して反応を見てから追加生産する方式。SHEIN型
