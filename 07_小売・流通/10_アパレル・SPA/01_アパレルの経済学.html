このノートで分かること：服屋の利益は「いくらで仕入れたか」ではなく「いくらで売り切れたか」で決まる。
定価で6割の粗利が取れる設計でも、セールで削られて最終的には5割を割る——その削られ方を数字で追う。

ポイント：アパレルは原価率の商売ではなく、消化率（売り切り率）の商売である。
同じ原価40%の服でも、定価で売れれば粗利60%、半額で売れれば粗利20%。利益の振れ幅は原価より値引きのほうが大きい。

1. まず用語を3つだけ：値入・プロパー・消化率

用語 読み・英語 意味 数値例
値入（ねいれ）markup定価と仕入原価の差。「これだけ儲かる予定」という設計値定価10,000円・原価4,000円 → 値入高6,000円
値入率initial markup値入高 ÷ 定価6,000 ÷ 10,000 = 60%（＝原価率40%）
プロパーproper / full price値引きしていない元の売価。「プロパー価格」「プロパー消化」と使う10,000円のまま売ること
プロパー消化率full-price sell-through仕入れた枚数のうち、定価のまま売れた枚数の割合100枚のうち55枚 → 55%
（総）消化率sell-through値引き分も含めて、期中に売れた枚数の割合100枚のうち95枚 → 95%
値下げ（値引きロス）markdown定価から実際の売価を引いた額の合計。粗利を直接食う30%offで30枚 → 3,000円×30枚＝9万円のロス

値入率60%は「取れる粗利」ではなく「取れるかもしれない粗利の上限」。
ここから値下げロスを引いた残りが実際の粗利であり、業界では 実現粗利率／最終粗利率 と呼ぶ。

   値入率60%（設計上の粗利）
   ├──────────────────────────────────────┐
   │              ↓ ここから引かれていく                    │
   │  値下げロス   在庫廃棄・評価損   返品・ロス（万引等）  │
   └──────────────────────────────────────┘
                     ↓
   最終粗利率 45〜52% ← 実際に手元に残る粗利

2. 100枚の服の行方：数字で追う

定価10,000円・原価4,000円（値入率60%）の服を 100枚 仕入れたとする。
シーズンを通して次のように売れた、という典型的な形を置く。

【100枚の消化ウォーターフォール（典型的なトレンド商品）】

  投入      プロパー      30%OFF      50%OFF      70%OFF     残
  100枚 ──▶  55枚  ──▶   20枚  ──▶   15枚  ──▶   5枚  ──▶  5枚
             @10,000      @7,000      @5,000      @3,000     @0
             55.0万円     14.0万円     7.5万円     1.5万円   0円

  売上合計 ＝ 78.0万円
  原価合計 ＝ 4,000円 × 100枚 ＝ 40.0万円
  ───────────────────────────────────
  粗利 ＝ 38.0万円　→　最終粗利率 ＝ 38.0 / 78.0 ＝ 48.7%
                      （設計は60%だったのに、11ポイント以上落ちた）

もしプロパー消化率が55%→70%に上がったらどうなるか。

ケース プロパー消化率 売上 粗利 最終粗利率 粗利額の差
A（不振）40%71.5万円31.5万円44.1%—
B（標準）55%78.0万円38.0万円48.7%+6.5万円
C（好調）70%84.5万円44.5万円52.7%+13.0万円

※ 残りの枚数は30%OFF・50%OFF・70%OFF・廃棄に同じ比率で按分した試算。あくまで構造を見るためのモデル計算。

プロパー消化率が15ポイント動くと、粗利額が2割前後動く。
原価を5%下げる交渉より、消化率を10ポイント上げるほうが利益へのインパクトが大きい。これがアパレルの勘所。

だから現場は「原価をいくら下げたか」ではなく、週次でプロパー消化率を見て、いつ値下げを打つかを議論している。

3. なぜ値下げを「早く」打つのか

直感に反するが、売れ行きが悪いと分かった瞬間に値下げしたほうが、粘るより粗利が残ることが多い。

【値下げを打つタイミングの違い】

  早く打つ（投入6週目に30%OFF）
   定価枠 ████████ 　値引き枠 ██████████████      廃棄 ▓
   → 値引き幅は浅く済む（30%で消化しきる）

  粘ってから打つ（投入12週目に50%OFF、最後は70%OFF）
   定価枠 ██████ 　　値引き枠 ████████     廃棄 ▓▓▓▓▓▓
   → 鮮度が落ちた在庫は深い値引きでしか動かない＋残りやすい

理由は3つ。

  1. 服は時間が経つほど値打ちが下がる。季節商品は気温が変われば需要そのものが消える。粘っても回復しない
  2. 売場の面積は有限。売れない商品が棚を占めると、売れる新商品を置く場所がない（機会損失）
  3. 現金が戻ってこない。値下げは「粗利を捨てて現金を取り戻す」行為。次のシーズンの仕入れ資金が要る

逆に、ブランド価値を守る立場（ラグジュアリー・一部のセレクト）は値下げしないことで価格の信頼を保つ戦略を取る。どちらが正しいかではなく、どのポジションで戦うかで最適な値下げ方針が変わる。

4. 在庫＝現金が服に姿を変えたもの

アパレルで最大のリスクは在庫である。理由は、在庫は「まだ現金化されていない現金」だからだ。

【アパレルの現金の一巡（キャッシュ・コンバージョン）】

   現金 ──▶ 生地を買う ──▶ 縫製代を払う ──▶ 製品が入る ──▶ 店に並ぶ ──▶ 売れる ──▶ 現金
    │        （6〜9ヶ月前）   （4〜6ヶ月前）   （1〜2ヶ月前）              （売価で回収）
    │                                                                              │
    └──────────────────────────────────────────────┘
                              この一周にかかる時間 ＝ 半年〜1年

   ★売れ残ると、この輪が閉じない。
     現金は「服」という形のまま倉庫に凍結され、次の仕入れに使えない
在庫が生む問題 具体的に何が起きるか
現金が固定される仕入代金はすでに払っている。売れるまで回収できない。運転資金が枯れると黒字倒産する
保管コストがかかる倉庫料・在庫管理の人手。持っているだけで毎月お金が出ていく
価値が落ちる翌シーズンには売価が半分以下。会計上は棚卸資産の評価損として利益を直撃する
売場を塞ぐ古い在庫が並ぶと店の鮮度が落ち、新商品も売れなくなる
処分にもお金がかかる廃棄・アウトレット移送・二次流通への放出。ブランド価値を傷つけるリスクもある

在庫回転率（年間売上原価 ÷ 平均在庫額）は、アパレル小売でおおむね 年3〜6回転 が目安とされる。
回転が速いほど少ない資金で商売が回り、遅いほど資金と保管費を食う。

ユニクロ（ファーストリテイリング）は「在庫コントロール」を決算説明で毎回のように語る。
好調の説明が「値引き販売が減り、粗利率が改善した」という形になるのは、利益のスイッチが在庫にあるからである。

5. MD（商品計画）：いつ・何を・いくつ作るか

MD＝マーチャンダイジング（merchandising、商品計画）。「どの商品を、いくらで、いつ、何枚用意し、いつまでにどう売り切るか」を設計する仕事、またはその担当者（MD）を指す。

MDが決める数字は、ざっくり次の4つに集約される。

決める数字 何を意味するか 外したときに起きること
投入量（枚数）シーズン全体で何枚用意するか多すぎ→値下げ・残。少なすぎ→機会損失（品切れ）
価格（上代）定価をいくらにするか。値入率が決まる高すぎ→売れずに値下げ前提に。安すぎ→粗利が取れない
投入タイミングいつ店頭に出すか（立ち上がり）早すぎ→気温が合わず不振。遅すぎ→ピークを逃す
品揃えの幅（SKU数）色・サイズをいくつ用意するか広すぎ→在庫分散で欠品と残が同時発生。狭すぎ→売り逃し

※ SKU（stock keeping unit）＝ 在庫管理の最小単位。同じデザインでも「黒のM」と「黒のL」は別SKU。

【1シーズン（秋冬）のMDカレンダー：決めた瞬間は1年前】

  昨年 9月   11月      1月        3月      6月      9月      翌1月
   │         │         │          │        │        │        │
  企画開始  素材決定  サンプル  生産発注  工場稼働  店頭投入  セール
   │         │         │          │        │        │        │
   └─── 需要予測はここで固まる ────┘        └── 実需 ──┘
            ↑                                          ↑
      「1年後の秋に何が流行るか」を今決める     答え合わせ

   ★ この時間差こそがアパレルの本質的な難しさ。
     予測が外れても、生産をやめられない地点をとっくに過ぎている

生産の側（糸から生地、染色、縫製をどう束ねるか）は 繊維商社 に詳しい。

6. 期中消化：シーズンが始まってからの戦い

計画が外れるのは前提。だからシーズンが始まってからの調整（期中運営）が利益を左右する。

打ち手 中身 使える条件
期中追加（追加生産）売れている商品を追加で作る。最も利益貢献が大きい生地の在庫があること、工場の生産枠が空いていること。リードタイム勝負
店間移動売れている店へ在庫を移す店舗網があること。物流コストとの見合い
EC振り向け店頭の売れ残りをECの在庫として売る在庫の一元管理ができていること
値下げ（マークダウン）売価を下げて消化を促すいつでもできるが、粗利を捨てる
持ち越し（キャリーオーバー）翌年の同じ季節まで倉庫で寝かせる定番商品のみ。トレンド品は不可
アウトレット・二次流通へ放出別チャネルで処分ブランド毀損とのトレードオフ → リユース・中古

期中追加ができるかどうかが、そのままプロパー消化率の差になる。
「売れている商品が品切れのまま」＝ 定価で売れる機会を捨てていることになるからだ。
ZARAが定価販売比率で他社を上回るとされるのは、この期中追加の速さに由来する → ② SPAというモデル

7. リードタイムと発注サイクル

リードタイム＝発注してから商品が手元に届くまでの期間。アパレルでは「どの工程から数えるか」で長さが大きく変わる。

起点 期間の目安 内容
糸から作る6〜9ヶ月紡績→織り／編み→染色→縫製。最も安いが最も遅い
生地在庫から作る（先行生地）1.5〜3ヶ月生地をあらかじめ押さえておき、縫製だけ走らせる。期中追加の主力
完成品在庫から引く2週間〜1ヶ月商社・工場が持つ在庫から。単価は高い
近場生産（ニアショア）2〜6週間ZARAのスペイン・ポルトガル・モロッコ、SHEINの広州近郊など
【リードタイムとコストのトレードオフ】

  安い ◀─────────────────────────────▶ 速い
   │                                                    │
   バングラデシュ  ベトナム  中国内陸  中国沿岸  国内/近隣
   （6〜9ヶ月）   （4〜6ヶ月）        （2〜3ヶ月）（2〜6週）
   単価 100        120       140       160        250〜
   │                                                    │
   └── 定番・大ロット向き ──┘   └── トレンド・追加生産向き ──┘

  ★ 実務では「定番は遠くで安く、トレンドは近くで速く」と使い分ける

発注サイクルは業態で大きく違う。

  • 百貨店アパレル・セレクト：年2回の展示会で翌シーズン分をまとめて発注（半年先の一発勝負）
  • SPA（ユニクロ型）：年間計画で大ロット発注＋期中に追加・調整
  • ファストファッション（ZARA型）：週次で企画と発注を回す。シーズン当初の投入は全体の2〜3割にとどめ、残りは期中に決める
  • 越境EC（SHEIN型）：数十〜数百枚の超小ロットで投入し、売れたものだけ追加生産（テスト&リオーダー）

アパレル小売の損益は、売価100に対する比率で見ると業態を超えて比較しやすい。

【売上100円が消えていく道（SPAの標準的な姿）】

  売上 100円
   ├─ 原価        48円  ████████████████████
   ├─ 家賃        10円  ████
   ├─ 人件費      12円  █████

  ★ 原価を1円下げるのは難しいが、値下げを1円減らせば
    そのまま営業利益が1円増える。だから消化率が最重要になる

坪効率（1坪あたり年間売上）は店舗の良し悪しを測る基本指標で、都心大型SPA店で年100〜200万円/坪、郊外量販型で50〜100万円/坪あたりが一つの目安とされる。家賃は売上の10%前後に収まるかが採算ラインの判断基準になる。

そして小売全般に共通する 既存店前年比（同じ店舗だけを比べた前年同月比）が、成長の実力を見る指標になる。新店を出せば全社売上は増えるが、既存店がマイナスなら中身は悪化している。

9. まとめ：アパレルの利益方程式

営業利益 ＝ 〔 売上 × 最終粗利率 〕 － 販管費

    最終粗利率 ＝ 値入率 － 値下げロス率 － 廃棄・評価損率
                    ↑            ↑
              設計で決まる   期中運営で決まる ←★ここが勝負

    売上 ＝ 客数 × 客単価
              ↑        ↑
         立地・集客   価格帯 × 買上点数
  • 値入率（設計）は誰でも60%に置ける。差がつくのは値下げロス
  • 値下げロスを減らす方法は2つだけ：①最初から作りすぎない ②売れているものを速く追加する
  • ①②を同時にやるには企画から販売までの情報が1本につながっている必要がある——これが次ノートの SPA（製造小売） の話になる → ② SPAというモデル
