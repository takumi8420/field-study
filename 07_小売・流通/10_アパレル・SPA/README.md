# アパレル・SPA

- 大分類: 小売・流通
- 状態: done
- 更新日: 2026-09-20

アパレルは、服を企画し、生産し、販売する産業。SPAはそのうち、企画から小売までを一体運営する企業形態を指す。
この業界の本質は流行そのものではなく、**半年前に作った服を、値下げせずシーズン内に売り切れるか**にある。

> 服は粗利率が高い一方、売れ残った瞬間に価値が急落する。
> したがって最大の競争力はデザインの一発勝負ではなく、
> **需要を早く知り、少量投入し、売れた商品だけを速く追加する仕組み**である。

## 2. 市場規模と成長性

国内アパレル市場はバブル期の約15兆円から、近年は8〜10兆円規模へ縮小した。
統計・調査により「衣料だけ」「服飾雑貨を含む」「小売金額」の定義が違うため、同じ系列で推移を見る。

| 指標 | 数値 | 読み方 |
| --- | ---: | --- |
| 国内アパレル市場 | 2020年に約8.5兆円 | 経産省資料。コロナで落ち込み、その後金額は回復 |
| バブル期の市場 | 約15兆円 | 長期では市場金額が大幅縮小 |
| 国内新規衣類供給 | **82万トン** | 2025年版環境省マテリアルフロー |
| 衣類の輸入量 | 81万トン | 新規供給のほぼ全量。重量ベース |
| 2025年家計支出 | 月10,063円、名目+0.8%、実質▲1.8% | 二人以上世帯、被服及び履物 |

長期には供給点数が増え、平均単価が下がった。2020年代は原材料・物流・賃金・円安で値上げが進み、
**金額は戻っても購入量は弱い**という局面にある。人口減少下で国内だけの数量成長は期待しにくい。

## 3. バリューチェーン

```
原料 ─▶ 紡績/化繊 ─▶ 織編 ─▶ 染色加工 ─▶ 縫製 ─▶ 輸入 ─▶ 店舗/EC ─▶ 消費者
綿・石油       生地づくり          中国・ASEAN        │
                                                     ├─ 回収 ─▶ リユース
企画/MD ─▶ 発注数量・価格・納期 ───────────────────────┤
                                                     └─ 再資源化/廃棄

SPAは「企画/MD」と「店舗/EC」を自社データで直結する。
```

日本で売られる服の多くは海外縫製で、素材、染色、縫製、物流を繊維商社やOEMが束ねる。
付加価値は、素材技術、高品質な縫製よりも、最終的には**ブランド、需要予測、売場、顧客データ**へ集まりやすい。

## 5. 収益モデル・コスト構造

服は原価率だけを見れば高粗利だが、粗利は**プロパー消化率**（定価で売れた割合）で大きく変わる。

```
定価 10,000円の商品、原価3,000円

  定価販売：売価10,000 − 原価3,000 ＝ 粗利7,000（70%）
  半額販売：売価 5,000 − 原価3,000 ＝ 粗利2,000（40%）

  値札は50%引きでも、粗利額は71%減る。
```

| 費用・指標 | 意味 |
| --- | --- |
| 売上原価 | 生地、縫製、加工、輸送、関税。為替の影響が大きい |
| 値下げロス | 当初値入と実現粗利の差。利益を最も動かす |
| 人件費・家賃 | 店舗売上が落ちてもすぐには減らない固定費 |
| 物流・返品 | EC比率が上がるほど個配と返品の負担が増える |
| 在庫回転率 | 年3〜6回程度が一つの目安。商品特性で異なる |
| プロパー消化率 | 値下げ前に定価で売れた割合 |
| GMROI | 在庫原価に対して得た粗利。売上高だけでなく資金効率を見る |

## 6. 競争要因（KSF）と参入障壁

| 成功要因 | なぜ効くか |
| --- | --- |
| 初回投入を絞る | 外したときの在庫損失を限定する |
| 期中追加を速くする | 売れた商品を定価のまま増やせる |
| 生地・工場の枠を先に確保する | 追加生産のリードタイムを短くする |
| 店舗とECの在庫を一元化する | 店ごとの欠品と余剰を同時に減らす |
| ブランドの価格帯を守る | 安売りによる将来の値上げ力低下を防ぐ |
| グローバルで商品を現地化する | 気候、体型、嗜好、価格ポジションの違いに対応する |
| 原料まで追跡できる | 人権・環境規制への対応を取引条件に変える |

ブランドは少額でも作れるが、安定成長には工場の優先枠、物流、IT、店舗網、広告投資が要る。
一方、歴史や顧客の記憶が価値になる高級ブランドは、資金だけでは再現しにくい。

## 7. 規制・法制度

| 制度 | 影響 |
| --- | --- |
| 家庭用品品質表示法 | 繊維組成、取扱い表示等の表示責任 |
| 景品表示法 | 原産国、素材、環境訴求、二重価格の根拠が必要 |
| 関税・消費税 | 原料・完成品の輸入コスト。2028年4月から越境ECの少額課税を見直し |
| 人権デューデリジェンス | 強制労働等を原料・縫製まで確認する要請が強まる |
| 国内循環政策 | 2030年度までに家庭の衣類廃棄を2020年度比25%削減する目標 |
| EU ESPR | 大企業の売れ残り衣料廃棄を2026年7月から禁止 |
| EU DPP | 製品単位の素材・循環情報。繊維の具体要件は今後の委任法令で確定 |

## 9. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **SPA** | Specialty store retailer of Private label Apparel。企画・製造調達・小売を一体運営する形 |
| **MD** | マーチャンダイジング。何を、いつ、いくらで、何枚売るかという商品計画 |
| **SKU** | 色・サイズまで分けた在庫管理の最小単位 |
| **値入率** | 定価と原価の差を定価で割った、販売前の粗利率 |
| **プロパー消化率** | 値下げせず定価で売れた割合 |
| **マークダウン** | シーズン中の値下げ。売上を作るが粗利を減らす |
| **リードタイム** | 発注から入荷までの時間 |
| **期中追加** | シーズン中に売れ筋を追加生産・追加発注すること |
| **D2C** | 卸や百貨店を介さず、自社EC等で消費者へ直接売る形 |
| **DPP** | 素材・製造・修理・再資源化等を製品単位で扱うデジタル製品パスポート |
