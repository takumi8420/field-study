# ③ 市場の変化

このノートで分かること：**日本のアパレル市場は金額が縮んだのに、出回る服の点数は増えた**。
つまり1枚あたりの単価が半分以下になり、その裏側で大量の売れ残りと廃棄が生まれた。
この1つの事実から、ファストファッションの揺り戻し、SHEIN の衝撃、古着市場の拡大、サステナビリティ規制まで、いまの論点がほぼ全部つながる。

> ポイント：**「安くしないと売れない」と「安くすると作りすぎる」が同時に起きた**のが、この30年の日本のアパレル。
> 供給過剰は在庫の問題であると同時に、**環境負荷と規制の問題**に変わりつつある。

## 1. 金額は半減、点数は倍増

| 指標 | 数値 | 時点・出典 |
| --- | --- | --- |
| 国内アパレル総小売市場規模 | **約8兆5,010億円**（前年比+1.7%、4年連続プラス） | 2024年、矢野経済研究所の推計 |
| 同・2023年 | 約8兆3,564億円（前年比+3.7%） | 2023年、同推計 |
| ピーク時（バブル期） | **約15兆円** | 1990年代前半、経済産業省資料 |
| 国内供給量（点数） | 約20億点 → **約40億点**へほぼ倍増 | 経済産業省資料（1990年代→2010年代） |
| 衣料品の輸入浸透率（数量ベース） | **98.5%** | 2022年、経済産業省資料 |
| 国内で手放される衣類 | 新規供給 **82万トン** に対し、約7割の **56万トン** が手放され焼却等で処理（うち家庭から51万トン） | 2024年版「衣類のマテリアルフロー」、環境省請負調査（2025年7月公表） |
| 今後の見通し | 2030年ごろまで2024年比で微増水準。**数量は減るが単価上昇で金額は支えられる** | 矢野経済研究所の予測（2025年） |

```
【国内アパレル：金額と数量が逆向きに動いた】

 金額（兆円）                          数量（億点）
  15 ┤●                                   40 ┤                     ●
     │  ●                                    │                ●
  12 ┤     ●                               30 ┤          ●
     │        ●                              │     ●
   9 ┤           ●───●───●              20 ┤●
   8 ┤                      ●─●            10 ┤
     └────────────────────        └─────────────────
    1991        2009      2020  2024          1991      2009    2020

   ＝ 1点あたりの平均単価が大幅に下落（おおむね半分以下）
   ＝ 同じ売上を作るのに、倍の枚数を作って運んで並べる必要が出た
```

### なぜこうなったか（3つの重なり）

1. **生産地の海外移転で原価が下がった**。中国→ASEAN→バングラデシュと安い生産地に移り、同じ服がどんどん安く作れるようになった → [繊維商社](../../06_商社・卸売/09_繊維商社/01_アパレル生産の裏方.md)
2. **可処分所得が伸びなかった**。1990年代後半以降、衣料は家計支出の中で削られる側に回った
3. **供給側が「安くして数で稼ぐ」を選んだ**。単価が下がれば枚数を増やさないと売上が維持できない。増やすとさらに売れ残り、さらに値下げする——という循環に入った

```
【供給過剰のループ】

   単価が下がる ──▶ 同じ売上を作るのに枚数が要る ──▶ 作りすぎる
        ▲                                                  │
        │                                                  ▼
   値下げで消化 ◀── 売れ残る（プロパー消化率が落ちる）◀─┘

   ★ このループの出口は2つしかない
     (a) 作る量を減らす（＝売上を諦める）
     (b) 単価を上げる（＝価値を上げる／値下げをやめる）
```

いま業界が「適量生産」「値上げ」「プロパー消化率」を合言葉にしているのは、**(a)と(b)を同時にやろうとしている**からである。

## 2. 価格帯の地図

市場を理解するには「いくらの服を、どこで、誰が買っているか」で切るのが早い。

| 価格帯 | Tシャツ1枚の目安 | 主なプレイヤー | 稼ぎ方 | いま起きていること |
| --- | --- | --- | --- | --- |
| **超低価格** | 〜1,000円 | SHEIN、Temu、一部の量販 | 越境EC・超小ロット多品種 | 急伸。ただし課税・規制の風当たりが強まる |
| **低価格** | 1,000〜3,000円 | GU、しまむら、ワークマン | 大量生産の規模の経済 | 堅調。しまむらは2026年2月期に過去最高 |
| **ボリュームゾーン** | 3,000〜8,000円 | ユニクロ、アンドエスティHD各ブランド、SC系専門店 | SPAの標準形 | 値上げを吸収できるかが分かれ目 |
| **中価格（DC・セレクト）** | 8,000〜20,000円 | 百貨店系ブランド、セレクトショップ | ブランドと接客 | 最も苦しい層。上にも下にも逃げられない |
| **ラグジュアリー** | 20,000円〜 | 欧州メゾン、国内デザイナーズ | 価格そのものが価値 | 2024年以降は世界的に減速。値上げで金額を維持 |

## 3. SHEIN・Temu：越境ECの衝撃

**SHEIN（シーイン）** は中国発（現在はシンガポールに本社機能）のファッション越境EC。**Temu** は同じく中国系の総合越境EC。両者がアパレルに与えた衝撃は、単に「安い」ことではない。

### 何が新しかったのか

| 要素 | 従来のファストファッション（ZARA等） | SHEIN型 |
| --- | --- | --- |
| 初回投入ロット | 数千〜数万枚 | **数十〜数百枚** |
| 1日あたりの新規投入 | 週単位で数百点 | **1日に数千点規模と報じられる** |
| 売れなかったとき | 値下げして店頭で消化 | **追加を止めるだけ。在庫が積み上がらない** |
| 店舗 | 一等地に多数 | **原則持たない**（ショールーム・ポップアップのみ） |
| 物流 | 大量を船で送り倉庫へ | **個別小包を航空便で消費者へ直送**（近年は現地在庫も併用） |
| 価格の成立理由 | 規模の経済 | 小ロット＋店舗なし＋**少額輸入の税制優遇** |

```
【在庫リスクの持ち方が根本的に違う】

  従来型：先に作って、売れるかを後で知る
    企画 ─▶ 大量生産 ─▶ 在庫 ─▶ 店頭 ─▶ 売れ残り ─▶ 値下げ・廃棄
                        ▲▲▲ ここにリスクが溜まる

  SHEIN型：少しだけ作って、売れたら追加する
    企画 ─▶ 100枚 ─▶ サイトに出す ─▶ 反応を見る
                                        ├─ 売れた → 追加生産
                                        └─ 売れない → 終了（損失は100枚分）
    ★ 「何が売れるか予測する」問題を、「売れたものを速く増やす」問題に
      置き換えた。これがオンデマンド生産の本質
```

日本では2022年11月に東京・原宿へ常設のショールーム「SHEIN TOKYO」を開設した。**商品を展示するだけで売らない店**で、試着してアプリで買う設計になっている（ダイヤモンド・チェーンストア、Business Insider Japan 報道）。

### 追い風だった税制が逆風に変わる

SHEIN・Temu型のビジネスを支えてきたのが、**少額輸入品の税制優遇**である。

- 日本では長らく、個人輸入に対して課税価格を**小売価格の0.6倍**とみなす特例があり、また課税価格1万円以下の輸入は関税・消費税が免除されてきた
- 米国は2025年に小口貨物の免税措置（デミニミス）を撤廃し、SHEIN・Temuが米国向け価格を引き上げると発表した
- 日本でも **2026年度税制改正** で、①個人輸入の0.6倍特例の廃止、②1万円以下の輸入への消費税適用、③販売事業者の登録納税制度の創設、が柱として打ち出されたと報じられる
- あわせて、**年間販売額50億円超の越境ECプラットフォームに消費税の納税義務を課す「プラットフォーム課税」**も議論されている

→ 詳細と出典は [④ 直近トピック（2026年9月）](04_直近トピック_2026.md)

> **「安さの一部は税制の差から来ていた」**という認識が各国で共有され、制度が揃えられつつある。
> 国内の小売・ECにとっては競争条件の是正であり、越境EC側にとっては**現地在庫・現地法人化への転換圧力**になっている。

## 4. 古着・二次流通の拡大

供給過剰の裏返しとして、**すでに世の中にある服を売り買いする市場**が伸びている。

| 指標 | 数値 | 時点・出典 |
| --- | --- | --- |
| 国内リユース市場全体 | **約3兆2,628億円**（前年比+4.5%、15年連続拡大） | 2024年、リサイクル通信の推計 |
| ファッションリユース市場 | **約1兆4,100億円**（前年比+10.2%） | 2025年、矢野経済研究所の推計 |
| 一次流通（新品）との比較 | 新品市場 約8.5兆円に対し、二次流通が約1.4兆円 | 2024〜2025年、上記2推計の対比 |

※ 統計の定義（衣料のみか、バッグ・靴・時計を含むか）が調査ごとに異なるため、**異なる調査の数値を単純に足し引きしない**こと。

```
【服の流れが「線」から「輪」に変わりつつある】

  かつて（線）
   工場 ─▶ 小売 ─▶ 消費者 ─▶ ゴミ

  いま（輪が生まれた）
   工場 ─▶ 小売 ─▶ 消費者 ┬─▶ フリマアプリ（C2C）──┐
                           ├─▶ 買取店（リユース事業者）┤
                           ├─▶ ブランド自身の回収     │
                           └─▶ 廃棄・焼却             │
                                     ▲                 │
                                     └── 別の消費者 ◀─┘

  ★ メルカリ等のC2C（個人間取引）が入口を大衆化させたのが最大の変化
    「捨てる」より「売る」ほうが得、という行動が定着した
```

### ブランド側から見た二次流通の意味

| 見え方 | 中身 |
| --- | --- |
| **脅威** | 新品の需要を食う。特に定番品は中古で十分になる |
| **前提条件** | 「あとで売れる」ことが購入の理由になる。**リセールバリューが購買動機**に |
| **廃棄削減の出口** | 売れ残りを廃棄せずに回す先。規制対応としても意味を持つ |
| **ブランド毀損リスク** | 管理外の場所で安売りされる。だから公式の回収・再販（リコマース）に乗り出す例が増えた |

伸びた背景には、物価上昇と社会保険料負担で**可処分所得が伸び悩んでいる**ことに加え、訪日客の増加（2024年に3,687万人と過去最高）によるインバウンド需要も挙げられている（矢野経済研究所ほか）。
→ [リユース・中古](../16_リユース・中古/README.md)

## 5. ファストファッションからの揺り戻し

2000年代後半に日本に上陸したファストファッション（H&M 2008年、Forever21 2009年、ZARAは1998年）は、**「安くて今っぽい服を大量に」**という価値観を広めた。しかし2020年代に入って、逆流が起きている。

| 揺り戻しの形 | 中身 |
| --- | --- |
| **数を減らす** | 「適量生産」を掲げるブランドが増えた。受注生産・限定数生産の試み |
| **長く着る** | 修理サービス、リペア前提の設計、保証の長期化 |
| **値上げを受け入れる** | 原材料・人件費・物流費の上昇を価格に転嫁。安さ競争から降りる動き |
| **素材を説明する** | リサイクル素材・オーガニック素材の採用と、その証明 |
| **出口を作る** | 回収・再販・リサイクルを自社でやる |

ただし、揺り戻しは**一枚岩ではない**。SHEIN・Temu が伸びているのは、「安さ」への需要が消えていない証拠でもある。
実際に起きているのは価値観の転換というより、**市場が「安さで選ぶ層」と「意味で選ぶ層」に分かれた**ことに近い。

## 6. サステナビリティ規制：善意から義務へ

いちばん変化が速いのがここである。**「やったほうがいい」から「やらないと売れない／輸出できない」に変わりつつある**。

| 制度 | 誰が | いつ | 何を求めるか |
| --- | --- | --- | --- |
| **EU ESPR**（エコデザイン規則） | EU | 2024年発効。繊維の具体要件は今後 | 製品の耐久性・修理可能性・リサイクル可能性の基準設定 |
| **デジタル製品パスポート（DPP）** | EU | **2026年7月までにレジストリ（登録簿）を設置**。繊維向けの詳細要件は2027年ごろと見られる | 繊維組成・製造国・認証・廃棄時の指示などを製品ごとに電子的に開示 |
| **売れ残り衣料の廃棄禁止** | EU（ESPR） | 大企業から順次 | 売れ残った衣料・靴の**意図的な廃棄を禁止**し、廃棄量の開示を義務化 |
| **繊維EPR**（拡大生産者責任） | EU（改正廃棄物枠組指令） | **2028年ごろまでに各加盟国が制度を整備** | 生産者が回収・処理の費用を負担。設計に応じて料率が変わる（エコモジュレーション） |
| **環境配慮情報開示ガイドライン** | 経済産業省 | 2024年6月 | 国内の繊維・アパレル企業向けの情報開示の考え方を整理 |
| **人権デューデリジェンス** | 日本政府ガイドライン（2022年）／米UFLPA（2022年施行）／EU強制労働製品禁止規則（2027年12月適用予定） | 順次 | 原料まで遡ったサプライチェーンの可視化 |

```
【「証明できること」が商品価値になる】

  これまで
   「リサイクル素材を使っています」 → 表示すればよかった

  これから
   「この服のポリエステルは、どこで回収されたPETボトルを、
     どの工場で、いつ再生したものか」
        ↓
   ・原料まで遡れるトレーサビリティの記録
   ・第三者認証
   ・デジタル製品パスポートでの電子開示
        ↓
   ★ 記録を持てない会社は、EU市場に出られなくなる可能性がある
   ★ 逆に、記録を持てる会社にとっては新しい参入障壁になる
```

> 重要なのは、これが **「環境のための負担」ではなく「取引の前提条件」** に変わりつつある点。
> 素材と工程の記録を誰が作るのかという問題であり、**アパレル企業単独ではなく繊維商社・素材メーカーとの共同作業**になる → [繊維商社 ② 市場の変化と生き残り](../../06_商社・卸売/09_繊維商社/02_市場の変化と生き残り.md)、[脱炭素・GX](../../01_注目テーマ/05_脱炭素・GX/README.md)

## 7. D2Cブランドの現実

**D2C**（Direct to Consumer）＝ 卸や百貨店を通さず、自社ECで直接消費者に売るブランド。2010年代後半に「小資本でもブランドが作れる」として注目された。

| 期待されたこと | 実際に起きたこと |
| --- | --- |
| 中間マージンが無いので安く・高粗利で売れる | 粗利は確かに高い。**ただし広告費が中間マージン以上にかかった** |
| SNSで低コストに集客できる | 初期は成立したが、**広告単価（CAC＝顧客獲得コスト）が年々上昇**し採算が悪化 |
| 店舗が要らないので固定費が軽い | 服は試着したい商品。**返品率が高く、物流費が利益を食う** |
| 規模を追わなくていい | 小さいままでは仕入ロットが小さく原価が下がらない。**規模の壁は消えない** |

```
【D2Cの損益が崩れる典型パターン】

  想定                          現実
   売価 10,000                   売価 10,000
   原価  3,000（30%）            原価  3,000
   粗利  7,000                   粗利  7,000
   広告  1,500                   広告  3,500 ← CAC上昇で倍以上に
   物流    500                   物流  1,200 ← 返品と再配送
   その他 1,000                  その他 1,500
   ───────                   ───────
   利益  4,000                   利益    800 ← ほぼ消える
```

結果として、成功しているD2Cブランドの多くは **(a) リアル店舗を持つ**、**(b) 卸や百貨店にも出す**、**(c) 大手の傘下に入る** のいずれかに向かっている。
**「直販だけで完結する」という前提が崩れ、チャネルを組み合わせる方向に収束した**というのが、いまの理解に近い。→ [通販・D2C](../15_通販・D2C/README.md)

## 8. インフルエンサーとSNSが販売に与える影響

SNSはアパレルの売り方を変えたが、**在庫計画から見ると難易度を上げた**という側面がある。

| 変化 | 良い面 | 難しくなった面 |
| --- | --- | --- |
| **インフルエンサー起用** | 広告費より効率よく認知が取れることがある | **いつバズるか予測できない**。バズった瞬間に在庫が尽きる |
| **ライブコマース** | 短時間に大量に売れる | 短時間に大量の在庫を用意する必要がある |
| **UGC（ユーザー投稿）** | 信頼性が高い。無料 | コントロールできない。炎上リスク |
| **トレンドの高速化** | 需要の立ち上がりが速い | **立ち下がりも速い**。追加生産が間に合う頃には終わっている |
| **比較の容易化** | — | 価格・レビューが即座に比較される。**値決めの自由度が下がった** |

```
【SNS時代の需要曲線：立ち上がりも立ち下がりも急になった】

  かつて                          いま
   需要                            需要
    │    ●●●●●●                  │     ●
    │  ●●      ●●                │    ● ●
    │●●          ●●              │   ●   ●
    └────────────           └──●─────●───
     ゆるやかに来てゆるやかに去る    突然来て突然消える

  ★ 追加生産のリードタイム（最短でも2〜6週間）より
    ブームの寿命が短いケースが増えた
  ★ だから「バズる前提の在庫」を持つか、持たずに売り逃すかの
    二択を迫られる
```

これに対する実務的な答えが、**生地を先に確保しておき、縫製だけを直前に走らせる**やり方（[② SPAというモデル](02_SPAというモデル.md) 第4章のZARA型、SHEIN型のオンデマンド生産）である。つまり **SNSがトレンドを速くしたことが、生産側の短サイクル化を押し進めた** という因果になっている。

## 9. まとめ：この10年の論点

```
   単価下落・供給過剰 ──┬──▶ 大量の値下げと廃棄
                        │            │
                        │            ├──▶ 環境規制（EU ESPR / DPP / EPR）
                        │            └──▶ 二次流通の拡大（1.4兆円規模）
                        │
                        ├──▶ 超低価格の越境EC（SHEIN/Temu）
                        │            └──▶ 税制の見直し（2026年度改正）
                        │
                        └──▶ 揺り戻し（適量生産・値上げ・長く着る）

  ★ 出口の方向は1つに収束しつつある
    ＝「作る量を減らし、1枚あたりの価値と価格を上げ、出口まで責任を持つ」
    これができる会社だけが、縮む市場で利益を出せる
```

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **供給点数** | 国内に供給された衣料品の枚数。金額と逆向きに動いたことが日本のアパレルの特徴 |
| **輸入浸透率** | 国内で売られる衣料のうち輸入品が占める割合。数量ベースで98.5%（2022年、経産省） |
| **マテリアルフロー** | 衣類が供給され、使われ、手放され、処理されるまでの物量の流れ。環境省が調査 |
| **適量生産** | 需要に見合った量だけ作るという考え方。売れ残りと廃棄を減らす狙い |
| **越境EC** | 海外の事業者が直接国内消費者に販売する電子商取引 |
| **デミニミス（少額輸入免税）** | 一定金額以下の輸入に関税・消費税を課さない制度。各国で見直しが進む |
| **プラットフォーム課税** | ECプラットフォーム事業者に消費税の納税義務を課す仕組み |
| **オンデマンド生産** | 少量を投入して反応を見てから追加生産する方式 |
| **二次流通／リユース** | 中古品の売買市場。C2C（個人間）とB2C（買取店）に大別される |
| **リセールバリュー** | 中古で売ったときの値段。購買動機になりつつある |
| **リコマース** | ブランド自身が自社製品の中古を回収・再販する事業 |
| **ESPR** | EUのエコデザイン規則。製品の耐久性・修理可能性等の要件を定める |
| **DPP（デジタル製品パスポート）** | 製品ごとの素材・製造・リサイクル情報を電子的に開示する仕組み |
| **EPR（拡大生産者責任）** | 製品の廃棄・リサイクル費用を生産者が負担する制度 |
| **エコモジュレーション** | EPRの負担料率を製品の設計（耐久性・リサイクル性）に応じて変える仕組み |
| **D2C** | Direct to Consumer。自社ECで直接消費者に売るブランド |
| **CAC** | Customer Acquisition Cost。顧客1人を獲得するのにかかる費用 |
| **UGC** | User Generated Content。消費者自身が作る投稿・レビュー |
