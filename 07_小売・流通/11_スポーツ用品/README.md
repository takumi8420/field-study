## このフォルダの読み方

スポーツ用品業界を理解する鍵は、たった1つ。
**「同じ業界」と呼ばれている会社が、実はまったく別の商売をしている**ということ。

- **メーカー（ブランド）**＝ナイキ、アディダス、アシックス、ミズノ、デサント
- **小売（専門店チェーン）**＝ゼビオ、アルペン、ヒマラヤ、スポーツオーソリティ、ワークマン

この2層は利益率が桁で違う。2025〜26年の決算では、アシックスの営業利益率が約17.6%、
ミズノが約8.7%だったのに対し、アルペンは3.2%、ゼビオHDは0.9%。
**同じ靴を扱っていても、値段を決める側と並べる側では取り分が20倍違う。**

そしていま、その力関係がさらにメーカー側へ傾いている。原因は **DTC（直販）**。
メーカーが直営店と自社ECで直接売れば粗利率は50%台から70〜80%へ跳ね上がる。
そのぶん小売の棚は薄くなる。ただしナイキが2026年に卸売へ揺り戻したように、
DTC一本足にも限界がある——このせめぎ合いが業界の現在地になっている。

需要側では、**部活動人口の縮小と高齢者スポーツ・アスレジャーの拡大**という
主役の交代が進んでいる。市場全体は微増しているが、中身はそっくり入れ替わった。

## 1. 業界の定義・範囲

**スポーツ用品業界 ＝ 運動競技と身体活動に使う用具・シューズ・ウェアを
企画・製造・流通させる産業**。ただし実務上は、次の2つの産業が同居している。

1. **用品メーカー業**（製造業寄り。実態はブランドビジネス）
2. **スポーツ用品小売業**（小売業。専門店チェーンと地域店）

```
【スポーツを巡る産業の位置関係】

              ＜やる＞                      ＜観る＞
  ┌────────────────────────┐  ┌──────────────────┐
  │ ★スポーツ用品★         │  │ スポーツビジネス   │
  │  用具・シューズ・ウェア │  │ 興行・放映権       │
  │  （本フォルダ）         │  │ スポンサー・グッズ │
  └────────────────────────┘  └──────────────────┘
       ↑                ↑                   ↑
       │                │                   │
  ┌──────────┐  ┌──────────────┐   ここへの支出が
  │フィットネス│  │ アパレル     │   用品メーカーの
  │ジム・スタジオ│  │ アスレジャー │   「広告宣伝費」
  └──────────┘  └──────────────┘

  境界の引き方：
   ・自転車、釣具、スキー場運営 … 独自の流通を持ち、別業界として扱われることが多い
   ・スポーツ施設の運営           … サービス業（フィットネス、レジャー）
   ・スポーツドリンク・サプリ     … 食品・飲料
   ・スマートウォッチ・活動量計   … 家電／IT。ただし売場は重なってきている
```

押さえるべき境界は3つ。

- **「競技用品」と「日常着」の境目が消えた**。アスレジャー（運動着を普段着る流れ）により、
  競合はアパレル全般に広がった
- **メーカーは製造業に分類されるが、工場は持たないことが多い**。海外委託生産が主流で、
  社内に残るのは設計・ブランド・販路
- **小売は「専門店」だけではない**。量販、EC、そしてメーカー直販が同じ棚を奪い合っている

## 2. 市場規模と成長性

| 指標                           | 数値                                                       | 年・出典                         |
| ------------------------------ | ---------------------------------------------------------- | -------------------------------- |
| 国内市場（メーカー出荷ベース） | **1兆7,313億円**（前年比103.1%）                           | 2025年。矢野経済研究所の推計     |
| 同・翌年予測                   | **1兆7,762億円**（前年比102.6%）                           | 2026年予測。矢野経済研究所の推計 |
| 国内スポーツ用品小売市場       | **1兆5,339億円**（前年度比+3.3%、4年連続増加）             | 2024年度。帝国データバンクの調査 |
| 国内ゴルフ用品市場             | **2,933億円**（前年比95.0%）／2025年は+5.5%予測            | 2024年。矢野経済研究所の推計     |
| カテゴリ構成（出荷ベース）     | シューズ **22.3%**／アウトドア **21.5%**／ゴルフ **17.1%** | 2025年。矢野経済研究所の推計     |

**出荷ベースと小売ベースは集計段階が違う**ので、足し引きしてはいけない。

成長性の読み方。

- **数量ではなく単価で伸びている**。人数（特に10代）は減っており、
  市場の微増は値上げと高単価化が支えている。物価上昇が止まれば伸びも止まりやすい
- **カテゴリ間格差が大きい**。矢野経済研究所の推計では、2026年に17カテゴリ中16がプラス成長だが、
  **5%以上の伸びが見込まれるのはアウトドアだけ**
- **アウトドアの中身は「用具から衣料へ」**。キャンプ用具は大幅縮小し、
  アウトドアアパレルが伸びて全体を押し上げている
- **市場が伸びても個社は楽ではない**。帝国データバンクの調査では、
  2024年度に赤字（28.5%）と減益（28.3%）を合わせた業績悪化企業が**56.8%**にのぼる

## 3. バリューチェーン（川上 → 川下）

```
【スポーツ用品のモノとカネの流れ】

  素材            製造             ブランド           流通             消費者
 ┌──────┐   ┌────────────┐  ┌──────────┐  ┌──────────────┐
 │合成樹脂│   │海外委託工場 │  │ナイキ    │  │スポーツ専門店│
 │ゴム    │─▶│ベトナム     │─▶│アシックス│┬▶│ゼビオ/アルペン│┐
 │化学繊維│   │中国         │  │ミズノ    ││ │ヒマラヤ      ││
 │カーボン│   │インドネシア │  │デサント  ││ └──────────────┘│
 └──────┘   └────────────┘  └──────────┘│ ┌──────────────┐├▶ 消費者
                                      │      ├▶│量販・作業服系││
                                      │      │ │ワークマン    ││
                                      │      │ └──────────────┘│
                                      │      │ ┌──────────────┐│
                                      │      └▶│EC・モール    │┘
                                      │        └──────────────┘
                                      └── DTC（直営店・自社EC）──▶ 消費者

  ＜別ルート＞ 学校・部活の指定品
    学校 ──指定──▶ 地域のスポーツ店 ──▶ 生徒・保護者
    （値引き不要・毎年自動発生。ただし部活動の地域展開で揺らいでいる）
```

**付加価値が集まる場所**（実売15,000円のシューズの概念図）。

| 段階             | 取り分の目安         | なぜそうなるか                                                   |
| ---------------- | -------------------- | ---------------------------------------------------------------- |
| 委託工場（海外） | 約3,000円（20%）     | 代替可能な受託生産。価格決定力がない                             |
| **ブランド**     | **約5,000円（33%）** | 素材・ソール技術と、選手契約で作った信頼への対価                 |
| **小売**         | **約7,000円（47%）** | 粗利は大きいが、家賃・人件費・**売れ残りの値引き**で大半が消える |

> ポイント：**小売の粗利は大きいのに、利益は小さい**。
> ゼビオHDの2026年3月期は売上総利益率37.7%に対し営業利益率0.9%。
> 粗利の96%以上が販管費で消えている。**在庫の健全さがそのまま利益**になる商売。

## 5. 収益モデル・コスト構造

| 項目                         | メーカー                                         | 小売（専門店）                                  |
| ---------------------------- | ------------------------------------------------ | ----------------------------------------------- |
| 売上総利益率                 | 50〜55%                                          | 30〜38%                                         |
| 営業利益率（2025〜26年実績） | アシックス 約17.6%、ミズノ 約8.7%                | アルペン 3.2%、ゼビオHD 0.9%                    |
| 主な固定費                   | 研究開発、広告宣伝、**契約選手・チームへの支払** | 家賃、人件費                                    |
| 最大のリスク                 | ブランドの陳腐化、為替、中国市場                 | **在庫の売れ残り**、天候、EC・DTCによる需要流出 |
| 利益を伸ばす手               | DTC比率の引き上げ、値上げ、競技外への拡張        | PB比率の引き上げ、在庫回転の改善、サービス収益  |

```
【スポーツ専門店の損益イメージ（郊外型500坪・年間／概念図）】

  売上高                   500,000千円 (100.0%)
  └ 売上総利益             188,000千円 ( 37.6%)
       ├ 人件費             65,000千円 ( 13.0%)
       ├ 地代家賃           50,000千円 ( 10.0%)
       ├ その他経費         45,000千円 (  9.0%)
       └ 営業利益           28,000千円 (  5.6%)

  在庫の10%を半額処分すると → 粗利率 37.6% → 約32% → 営業利益はほぼ消滅
```

> ポイント：メーカーの利益は**ブランド（値付けの自由）**から、
> 小売の利益は**在庫回転（売れ残らないこと）**から生まれる。
> 同じ商品を扱っていても、経営者が朝いちばんに見る数字が違う。

## 6. 競争要因（KSF）と参入障壁

| 立場             | 勝負どころ                                                   | 参入障壁                                                       |
| ---------------- | ------------------------------------------------------------ | -------------------------------------------------------------- |
| メーカー（大手） | 素材・ソール技術、トップ選手契約、ブランドの歴史             | **非常に高い**。10年単位の蓄積が要る                           |
| メーカー（新興） | 単一カテゴリへの一点突破＋DTC＋SNS                           | **下がった**。委託生産とECで参入できる                         |
| 小売（チェーン） | 立地、在庫の回し方、PB比率、サービス（フィッティング・修理） | 中程度。資本と物流が要る                                       |
| 小売（地域店）   | 競技知識、部活・チームとの関係、刺繍や名入れなどの加工       | 低いが、**関係資産は模倣されにくい**。ただし部活動改革で揺らぐ |

**メーカー側の障壁は高いまま、小売側の障壁だけが崩れた**のが現在の構図。
ECとDTCが「棚を持つこと」の価値を下げたため、
小売は棚以外の資産（PB、中古、サービス、施設運営）を持たないと差別化できない。

## 7. 規制・法制度

| 制度                               | 内容                                                                            | 効き方                                                       |
| ---------------------------------- | ------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| **部活動改革（地域展開）**         | スポーツ庁の方針。2026年度から平日も対象、2026〜2032年度が実施期間              | 購買主体が学校から保護者個人へ。地域スポーツ店に最大のリスク |
| **免税制度の見直し**               | 2026年11月1日から**リファンド方式**へ。消耗品／一般物品の区分と50万円上限を撤廃 | 都市型店・直営店の実務とインバウンド売上に影響               |
| **競技団体の用具規定**             | 水着、シューズのソール厚、クラブの反発係数など                                  | **ルール改定が一夜で製品を陳腐化させる**                     |
| **PL法・SG規格等**                 | ヘルメット、プロテクター等の安全関連                                            | 公認規格の取得が事実上の参入条件                             |
| **景品表示法・家庭用品品質表示法** | 機能訴求と繊維表示                                                              | 「軽量」「疲労回復」等の表示に根拠が必要                     |
| **関税**                           | 履物は素材（革の有無）と原産国で税率が変わる                                    | 調達先の選択に効く                                           |

## 8. 最近のトピック

詳細は [③ 直近トピック 2026](03_直近トピック_2026.md) に。要点は5つ。

1. **メーカー最高益 vs 小売低収益の二極化**。アシックス（+42.4%営業増益）、ミズノ（4期連続最高）に対し、大手小売の営業利益率は0.9〜3.2%
2. **ナイキのDTC巻き戻し**。2026年5月期は卸売+6%／直販▲6%。「直販一本足」の限界が数字で確認された

4. **部活動改革が2026年度から実施期間に入り、平日も対象**。用品の購買ルートが学校経由から個人購買へ分解する
5. **アウトドアだけが高成長、ただし「用具から衣料へ」**。キャンプ用具は縮小、アウトドアアパレルとリカバリーウェアが伸びる

| 用語                                 | 意味                                                                                                                          |

| **DTC（D2C／Direct to Consumer）**   | メーカーが卸・小売を通さず直営店や自社ECで直接売ること。粗利率は上がるが露出機会を失う → [①](01_メーカーと小売の二層.md)      |
| **アスレジャー**                     | athletic＋leisure。運動着を日常着として着る流れ。市場の上限が競技人口から人口全体へ広がった → [①](01_メーカーと小売の二層.md) |
| **学校指定品**                       | 学校・部が指定する体操服や用具。値引き不要で毎年発生する安定需要 → [②](02_市場と競争.md)                                      |
| **部活動の地域展開**                 | 学校部活動を地域クラブ・民間事業者へ移す政策。2026年度から平日も対象 → [②](02_市場と競争.md)                                  |
| **SKU**                              | 在庫管理の最小単位。サイズ×色でSKUが膨らみ、スポーツ用品は在庫が重くなる → [②](02_市場と競争.md)                              |
| **リファンド方式（免税）**           | 店頭では税込で売り、出国時に還付する免税方式。2026年11月から移行 → [③](03_直近トピック_2026.md)                               |
| **PB（プライベートブランド）**       | 小売が自ら企画する自社ブランド。粗利率が10〜20ポイント高い                                                                    |
| **厚底（カーボンプレート）シューズ** | 反発素材とカーボン板を仕込んだ長距離用シューズ。技術競争の象徴                                                                |
| **ショールーミング**                 | 店で試し、ネットで買う行動。専門店には試着コストだけが残る                                                                    |
