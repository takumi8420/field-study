# ① メーカーと小売の二層

このノートで分かること：**「スポーツ用品業界」と一括りにされる会社は、実は
まったく別の商売をしている2種類の会社**だということ。そしてその2層の力関係が、
いま急速に崩れつつあること。

---

## 1. 結論：同じ業界に見えて、稼ぎ方が正反対の2層がある

ニュースで「スポーツ用品業界」と言うとき、そこには2種類の会社が混ざっている。

- **メーカー（ブランド）**＝アシックス、ミズノ、デサント、ナイキ、アディダス
- **小売（専門店チェーン）**＝ゼビオ、アルペン、ヒマラヤ、スポーツオーソリティ、ワークマン

この2つは、**利益の出どころがまるで違う**。

|                                | メーカー（ブランド）                             | 小売（専門店）                             |
| ------------------------------ | ------------------------------------------------ | ------------------------------------------ |
| 売っているもの                 | **ブランドと機能**                               | **売場と品揃え**                           |
| 粗利率の目安                   | 50〜55%                                          | 30〜38%                                    |
| 営業利益率の目安（2025〜26年） | アシックス 約17.6%、ミズノ 約8.7%                | アルペン 約3.2%、ゼビオ 約0.9%             |
| 主な固定費                     | 研究開発、広告宣伝、**契約選手・チームへの支払** | **家賃、人件費、在庫**                     |
| 一番怖いこと                   | 商品が売れ筋から外れる（ブランドの陳腐化）       | **在庫が売れ残る**（値引きで粗利が消える） |
| 数字を動かすレバー             | 単価を上げる、直販比率を上げる                   | 坪効率を上げる、在庫回転を上げる           |

（各社決算および流通系メディア報道ベース。アシックスは2025年12月期、ミズノは2026年3月期、
アルペンは2025年6月期、ゼビオHDは2026年3月期）

> ポイント：**アシックスの営業利益率はゼビオの約20倍**。
> 同じ靴を扱っていても、「作って名前を付ける側」と「並べて売る側」では
> 取り分の桁が違う。この非対称が、業界を読むときの出発点になる。

## 2. 誰が何を取っているのか（1足15,000円のランニングシューズ）

```
【ランニングシューズ1足の値段のゆくえ（実売15,000円・概念図）】

  製造原価         ブランドの取り分            小売の取り分
  (海外委託工場)   (研究開発・広告・契約選手)  (家賃・人件費・在庫リスク)
 ┌──────────┬────────────────────┬──────────────────────┐
 │ 約3,000円 │      約5,000円      │       約7,000円       │
 └──────────┴────────────────────┴──────────────────────┘
   20%              33%                      47%
   ↑                ↑                        ↑
 ベトナム・中国   ここが「ブランド」        卸値7,500〜8,000円で仕入れ、
 の委託生産が     の正体。工場は            15,000円で売る＝粗利率 約47%
 大半             持たないことが多い        ただし売れ残れば半額セール
                                             → 粗利は一気に 0 近くへ

 ★ メーカーが自社直営店で同じ靴を売ると（DTC）
 ┌──────────┬───────────────────────────────────────────┐
 │ 約3,000円 │        約12,000円（ブランドが全部取る）        │
 └──────────┴───────────────────────────────────────────┘
   → 粗利率が 50% → 80% に跳ね上がる。これがDTCの誘惑。
```

（構成比は業界一般の目安として示した概念図。実際の卸値・原価率は商品と契約で変わる）

**なぜ小売の取り分が大きいのに、小売の利益率は低いのか**。
答えは「粗利は大きいが、そこから出ていくものも大きい」から。
売場の家賃、販売員の人件費、そして**売れ残り在庫の値引き**が粗利を削る。
ゼビオHDの2026年3月期は売上総利益率37.7%に対して営業利益率0.9%。
粗利の**96%以上が販管費で消えている**。

## 3. メーカー側の仕組み：工場を持たず、契約選手に払う

### 3-1. 製造は外に出し、中には「設計」と「名前」が残る

ナイキは自社工場をほぼ持たない。アシックス・ミズノも主力は海外の委託工場で作る。
残るのは **①素材とソール（靴底）の設計、②ブランド、③販路** の3つ。

```
【スポーツブランドの中身】

  [ 研究開発 ]      [ 契約・宣伝 ]        [ 販路 ]
  素材・ソール      選手／チーム／大会    卸（専門店）
  足型データ    ─▶  への露出        ─▶   直営店・自社EC（DTC）
  スポーツ工学      ＝広告宣伝費そのもの   海外代理店
       │                   │
       └──── 仕様書 ───▶ 海外委託工場（ベトナム・中国・インドネシア）
                              ↑
                       ここは自社では持たない
```

### 3-2. 契約選手・チームへの支払は「広告宣伝費」である

スポーツ用品業界に独特なコストが、**選手・チーム・大会へのスポンサード**。
これは寄付ではなく、会計上も実態としても**広告宣伝費**にあたる。

| 支払の形                                   | 何を買っているか                     | 効き方                                 |
| ------------------------------------------ | ------------------------------------ | -------------------------------------- |
| **選手契約**（マラソン、テニス、ゴルフ等） | 勝った瞬間にロゴが映ること           | 短期。勝てば跳ね、負ければ消える       |
| **チーム／クラブ供給**（サッカー、野球）   | ユニフォーム全体の露出とレプリカ販売 | 中期。レプリカ販売そのものが売上になる |
| **競技団体・大会**（五輪、世界陸上）       | 大会名と結びついた権威               | 長期。ブランドの「格」を作る           |
| **部活・学校への供給**                     | 10代の最初の1足                      | 超長期。**習慣が一生の購買を決める**   |

> ポイント：スポーツ用品の広告は「CMを打つ」ことではなく
> **「勝つ人に履かせる」**こと。だから強化費は研究開発費と一体で動く。
> 厚底シューズ競争が激しいのは、記録が出た瞬間に市場が動くから。

スポーツ大会そのものの経済圏（放映権・スポンサー・チーム運営）は
[スポーツビジネス](../../14_メディア・広告・エンタメ/12_スポーツビジネス/README.md) を参照。
スポーツ用品メーカーから見れば、そこは**広告の買い場**にあたる。

### 3-3. シューズが最大カテゴリで、技術競争の主戦場

国内市場でもっとも大きいカテゴリは**スポーツシューズ**で、
2025年は市場全体の **22.3%** を占めた（矢野経済研究所の推計）。

シューズが主戦場になる理由は3つ。

- **消耗品**である。500〜800km走れば買い替える。アパレルより回転が速い
- **技術差が記録として見える**。カーボンプレート入りの厚底が記録を塗り替えた例が典型
- **競技外に染み出す**。競技用として開発した機能が、そのまま街履き（アスレジャー）に流れる

アシックスの2025年12月期は売上高8,109億円（前期比+19.5%）、営業利益1,425億円（+42.4%）で
5年連続の増収増益・過去最高。牽引したのは競技用ではなく
**スポーツスタイルとオニツカタイガー**で、両者がそれぞれ単体で初めて1,000億円を超えた。
つまり「**競技で作った技術と信頼を、街履きで換金した**」構図になっている。

## 4. 競技用品と日常使い（アスレジャー）は別の商売

**アスレジャー**とは athletic（運動）＋ leisure（余暇）の造語で、
**運動用の服や靴を、運動しないときにも着る**流れのこと。
2010年代後半から定着し、いまやスポーツ用品メーカーの主力になっている。

|                | 競技用品                   | 日常使い（アスレジャー）                       |
| -------------- | -------------------------- | ---------------------------------------------- |
| 買う理由       | **記録・勝敗**。性能が全て | **見た目と快適さ**。性能は「らしさ」の記号     |
| 買い替え周期   | 消耗したら（半年〜1年）    | 飽きたら／流行が変わったら                     |
| 価格の決まり方 | 機能に対する納得感         | ブランドと希少性（限定品はプレミアが付く）     |
| 販路           | スポーツ専門店、競技専門店 | セレクトショップ、ファッションEC、直営店       |
| 競合           | 同業ブランド               | **アパレル全般**（ユニクロ、ワークマン、H&M…） |
| 市場の大きさ   | 競技人口に上限がある       | **人口全体が対象**。上限がない                 |

```
【技術が競技から日常へ流れる道すじ】

  トップ選手向けに開発         競技者向け量販              街履き・普段着
  (数百人が使う)               (数十万人が買う)            (数千万人が買う)
  カーボンプレート厚底  ──▶  一般ランナー向け厚底  ──▶  クッション性を売りにした
  ・単価3〜5万円               ・単価1.5〜2.5万円          スニーカー
  ・赤字でも構わない           ・ここで開発費を回収        ・単価8,000〜15,000円
  ・「記録」という広告          ・競技人口が上限           ・**ここが一番大きい**

   利益は右へ行くほど大きく、技術の説得力は左から来る。
   ＝ 左を捨てるとブランドが死に、左だけだと儲からない。
```

> ポイント：ミズノの2026年3月期は売上高2,590億円（+7.8%）、営業利益226億円（+8.8%）で
> **4期連続の過去最高**。ファッションスニーカーは6年で9.5倍に伸びたと報じられる。
> 「競技ブランドのまま、競技の外で稼ぐ」が現在の勝ち筋になっている。
> 一方で野球／ソフトボール、ランニングの売上は減少し、ゴルフとフットボールが補った。

## 5. DTC（直販）が小売を圧迫する

**DTC**（Direct to Consumer ＝ 直販）とは、メーカーが卸や小売を通さず、
自社の直営店・自社ECで消費者に直接売ること。**D2C**とほぼ同義。

### 5-1. なぜメーカーはDTCに走るのか

```
【従来の卸モデル】
 メーカー ──卸値(定価の50〜55%)──▶ 専門店 ──定価──▶ 消費者
   粗利率 約50%                     粗利率 約45%
   ・顧客が誰か分からない
   ・値引きを小売にコントロールされる
   ・棚は他ブランドと共有

【DTCモデル】
 メーカー ──────────定価──────────▶ 消費者
   粗利率 70〜80%
   ・**誰が何を買ったかが分かる**（顧客データ）
   ・値引きを自分で決められる＝ブランドが守れる
   ・ただし家賃・人件費・物流・返品を自前で抱える
```

### 5-2. ナイキの「行き過ぎたDTC」と揺り戻し

ナイキは2017年以降、卸先を大幅に絞ってDTCへ寄せた。ところが
需要が鈍り新商品の切れ味が落ちると、**売場を失ったぶんだけ一気に売上が減った**。
2024〜25年にかけて卸売チャネルへの回帰に舵を切り、
2026年5月期は売上高463億9,800万ドルでほぼ横ばい（為替影響を除くと約2%減）。
内訳は**卸売が275億ドルで前年比+6%、直販が177億ドルで▲6%**と、明確に逆転した。
同社は2026年に「S&P100」から除外されたとも報じられている。

> ポイント：DTCは粗利率を上げるが、**「見つけてもらう場所」を捨てる**という副作用がある。
> 専門店の棚は、比較して選んでもらうための装置でもあった。
> ナイキの揺り戻しは「DTCか卸か」ではなく「**両方を整合させる**」という結論に落ち着いた。

### 5-3. 日本の小売から見たDTCの痛み

日本のスポーツ専門店にとってDTCは、次の3方向から効いてくる。

| 効き方                     | 具体的に何が起きるか                                                 |
| -------------------------- | -------------------------------------------------------------------- |
| **良い商品が回ってこない** | 限定色・上位モデルはメーカー直営とメーカーECに優先配分される         |
| **価格で勝てない**         | メーカー公式が定価を守るので、専門店も値引きできない。差別化が消える |
| **役割が「試着場」になる** | 店で履いて、サイズを確かめ、公式ECで買われる（ショールーミング）     |

だから専門店は、①メーカーが作らない領域（プライベートブランド）、
②メーカーが手を出しにくい領域（中古、修理、フィッティング、施設運営）へ逃げる。
アルペンの「ALPEN OUTDOORS」「ALPEN SELECT」、ゼビオの自社ブランド群がその答えにあたる。
詳しくは [② 市場と競争](02_市場と競争.md) の小売側の話で扱う。

## 7. どこを見れば各社の調子が分かるか

| 立場     | 見るべき指標                                 | 読み方                                                           |
| -------- | -------------------------------------------- | ---------------------------------------------------------------- |
| メーカー | **売上総利益率**                             | 上がっていればDTC比率上昇か値上げ成功。下がれば在庫処分中        |
| メーカー | **カテゴリ別売上**（競技／スポーツスタイル） | スポーツスタイルが伸びていれば「競技外への染み出し」が効いている |
| メーカー | **地域別売上**（特に中国・北米）             | 中国の失速は各社共通のリスク                                     |
| 小売     | **既存店売上前年比**                         | 出店効果を除いた地力。天候に大きく振られる                       |
| 小売     | **商品在庫の金額と回転日数**                 | 在庫が増えたら翌期の値引きが確定する先行指標                     |
| 小売     | **売上総利益率**                             | 38%前後が専門店の水準。35%を割ったら値引き依存                   |

## 8. 用語メモ

| 用語                                 | 意味                                                                                                                           |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| **DTC（D2C／Direct to Consumer）**   | メーカーが卸・小売を通さず、直営店や自社ECで消費者に直接売ること。粗利率は上がるが、家賃・人件費・物流・返品を自分で抱える     |
| **アスレジャー（athleisure）**       | athletic（運動）＋leisure（余暇）。運動用の服や靴を日常着として着る流れ。市場の上限が「競技人口」から「人口全体」に広がった    |
| **ショールーミング**                 | 実店舗で現物を試し、購入はネットで済ませる行動。専門店の試着コストだけが残る                                                   |
| **スポンサード／サプライ契約**       | 選手・チーム・大会に用具やユニフォームを提供し、露出を買う契約。会計上は広告宣伝費                                             |
| **PB（プライベートブランド）**       | 小売が自ら企画して作らせる自社ブランド商品。仕入れではないので粗利率が10〜20ポイント高い                                       |
| **厚底（カーボンプレート）シューズ** | 靴底に反発性素材とカーボン繊維の板を仕込んだ長距離用シューズ。2017年以降の記録更新ラッシュの原因になり、技術競争の象徴になった |
| **売上総利益率（粗利率）**           | （売上高−売上原価）÷売上高。メーカーは50%前後、スポーツ専門店は30〜38%が目安                                                   |
