# ② 市場と競争

このノートで分かること：**スポーツ用品の需要は「人口」ではなく「誰がどの競技をやるか」で決まる**。
その中身がいま入れ替わっていること。そして、小売側の店がどういう算数で回っているか。

---

## 1. 結論：市場は微増だが、中身がそっくり入れ替わっている

国内のスポーツ用品市場は縮んでいない。むしろ毎年少しずつ増えている。
ところが**買っている人と買っているモノが変わった**。

```
【需要の主役の交代（概念図）】

  2000年前後                     2020年代後半
 ┌──────────────────┐        ┌──────────────────┐
 │ 中高生の部活         │        │ 中高年の健康・趣味   │
 │ ・野球、サッカー     │  ───▶ │ ・ゴルフ、ランニング │
 │ ・学校指定品         │        │ ・登山、ウォーキング │
 │ ・親が買う           │        │ ・本人が自分に買う   │
 │ ・単価は抑えめ       │        │ ・**単価が高い**     │
 └──────────────────┘        └──────────────────┘
        ↓ 少子化で母数が縮小              ↓ 人数も可処分所得も多い
        ↓ 部活の地域移行で               ↓ 競技より「健康」「趣味」
        ↓ 買う主体も変わる                ↓ アウトドア・アスレジャー

  ＋ 新しい層： 運動しないけどスポーツウェアを着る人（アスレジャー）
              → 母数は人口全体。ここが一番大きい
```

> ポイント：**人数は減り、単価が上がっている**。
> 市場が横ばい〜微増なのは、単価上昇が人数減をちょうど埋めているから。
> だから物価上昇が止まると、市場の伸びも止まりやすい。

## 2. 市場規模（2025〜2026年）

| 指標                                       | 数値                                                          | 年・出典                                          |
| ------------------------------------------ | ------------------------------------------------------------- | ------------------------------------------------- |
| 国内スポーツ用品市場（メーカー出荷ベース） | **1兆7,313億円**（前年比103.1%）                              | 2025年。矢野経済研究所の推計                      |
| 同・翌年予測                               | **1兆7,762億円**（前年比102.6%）                              | 2026年予測。矢野経済研究所の推計                  |
| スポーツ用品小売市場（小売段階）           | **1兆5,339億円**（前年度比+3.3%、4年連続増加・初の1.5兆円超） | 2024年度。帝国データバンクの調査                  |
| 国内ゴルフ用品市場                         | **2,933億円**（前年比95.0%）                                  | 2024年。矢野経済研究所の推計。2025年は+5.5%を予測 |

**2つの数字が違うのは段階が違うから**。出荷ベース（メーカーが出した金額）と
小売ベース（店が売った金額）は集計範囲も定義も異なるので、
「1.7兆円」と「1.5兆円」を足したり引いたりしてはいけない。

### カテゴリ別の構成（2025年・国内出荷ベース）

| 順位 | カテゴリ                                                   | 構成比    | 特徴                                                                         |
| ---- | ---------------------------------------------------------- | --------- | ---------------------------------------------------------------------------- |
| 1    | **スポーツシューズ**                                       | 22.3%     | 最大かつ技術競争の主戦場。消耗品なので回転が速い                             |
| 2    | **アウトドア**                                             | 21.5%     | キャンプ用具は縮小、**アウトドアアパレルが伸びて全体を牽引**                 |
| 3    | **ゴルフ**                                                 | 17.1%     | 単価が高く高齢層の可処分所得を吸う。用品は2024年に一度落ち込み、2025年に回復 |
| —    | その他（野球、サッカー、テニス、水泳、武道など14カテゴリ） | 残り約39% | 競技人口に規定され、少子化の影響を直接受ける                                 |

矢野経済研究所の推計では、全17カテゴリのうち**ラグビーを除く16カテゴリが2026年にプラス成長**、
そのうち**5%以上の成長が見込まれるのはアウトドアのみ**とされる。
つまり「全体的にゆるく伸びて、アウトドアだけが強い」というのが現在の絵柄。

```
  シューズ  ████████████████████████  22.3%
  アウトドア ██████████████████████    21.5%   ← 唯一の高成長
  ゴルフ     █████████████████         17.1%
  その他14   ███████████████████████████████████  約39%
             （野球・サッカー・テニス・水泳・武道・スキー…）

  上位3つで市場の約6割。しかもこの3つは
  「競技人口」より「**大人の趣味**」で動く。
```

## 3. 需要変化その1：部活動人口の縮小と「地域移行」

### 3-1. なぜ部活が業界の生命線だったか

中学・高校の運動部は、スポーツ用品業界にとって特殊な需要だった。

- **必ず買う**。入部した時点でシューズ・ウェア・用具の購入が確定する
- **値引き競争が起きにくい**。学校指定品・チーム一括購入は地域の店が担う
- **毎年発生する**。学年が上がるたび新入生が入ってくる＝リピートが自動
- **一生の好みを作る**。10代で履いたブランドは、その後も選ばれやすい

### 3-2. いま起きている2つの変化

| 変化                             | 内容                                                                                                                         | 用品への影響                                                                                         |
| -------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| **少子化**                       | 中学生・高校生の絶対数が減り続ける                                                                                           | 母数がそのまま縮む。競技別用品（野球・柔道等）に直撃                                                 |
| **部活動の地域移行（地域展開）** | 学校の部活を地域のクラブ・団体へ移す政策。休日から始まり、**2026年度からは平日も対象**。2026〜2032年度が「実施期間」とされる | **買う主体が「学校経由」から「保護者個人」へ移る**。まとめ買いが個別購入になり、指定品の縛りが弱まる |

2025年5月には、スポーツ庁が呼称を「地域移行」から「**地域展開**」へ改めたと報じられている。
学校から切り離すのではなく、地域全体で支える枠組みへ、という意味合いの修正。
2024年度までに、4分の3を超える市区町村が協議会を設置（予定を含む）したとされる。

> ポイント：地域移行は「需要が減る」話ではなく、**「需要の流れる道が変わる」**話。
> 学校 → 地域の指定店、という固定ルートが壊れ、
> 保護者がECや量販店で自由に買うようになる。
> **地域密着の中小スポーツ店にとっては、最大の構造変化**になる。

```
【部活の用品購買ルートの変化】

 ＜これまで＞
  学校（顧問が指定）──▶ 地域のスポーツ店 ──▶ 生徒・保護者
                        ・チーム一括発注
                        ・刺繍、名入れ、修理も担う
                        ・値引き不要、粗利が厚い

 ＜地域展開後＞
  地域クラブ／民間事業者 ─┬─▶ 地域のスポーツ店（従来どおり残る分）
                          ├─▶ 量販チェーン（ゼビオ・アルペン）
                          ├─▶ EC（Amazon・楽天・メーカー公式）
                          └─▶ リユース（中古・お下がり）
                        保護者が自分で選ぶ＝価格比較が働く
                        → 単価は下がり、粗利も薄くなる
```

関連：[リユース・中古](../16_リユース・中古/README.md)、
[EC・ネット通販](../../04_情報通信・IT・ネット/08_EC・ネット通販/README.md)

## 4. 需要変化その2：高齢者スポーツと「ブームの循環」

### 4-1. 上の世代が市場を支えている

減った10代の穴を埋めているのが、**50〜70代の健康・趣味需要**。
ゴルフ、ウォーキング、登山、テニス、ジムが代表格。この層の特徴は明快。

- **人数が多い**（人口構成上のボリュームゾーン）
- **可処分所得が多い**。数万円のゴルフクラブ、2万円のシューズに抵抗が薄い
- **買い替えの理由が「消耗」ではなく「良くなりたい」**。単価が上がりやすい
- ただし**健康を損ねた瞬間に市場から消える**。需要の寿命に限りがある

運動する「場所」側の動向は
[フィットネス](../../15_サービス・生活関連/12_フィットネス/README.md) を参照。
ジムやクラブが増えれば、そこで使う用品も増えるという補完関係にある。

### 4-2. ブームは循環する（在庫リスクの正体）

スポーツ用品の需要はブームで大きく上下する。過去の代表例を並べると分かりやすい。

| 時期         | 主なブーム                         | 終わり方                                                                   |
| ------------ | ---------------------------------- | -------------------------------------------------------------------------- |
| 2000年代後半 | ランニング（市民マラソン）         | 定着。いまも中核カテゴリ                                                   |
| 2010年代前半 | 自転車（ロードバイク）             | 縮小。専門店の淘汰が進んだ                                                 |
| 2010年代後半 | ヨガ・アスレジャー                 | ファッションとして定着                                                     |
| 2020〜2022年 | **キャンプ**（コロナ禍の屋外志向） | **急減**。キャンプ用具市場は大幅縮小し、アウトドア「アパレル」だけが残った |
| 2020年代前半 | ゴルフ（若年層の流入）             | 用品市場は2024年に前年比95.0%まで落ち、2025年に回復基調                    |
| 2020年代後半 | リカバリーウェア、ウォーキング     | 進行中                                                                     |

> ポイント：**ブームの怖さは、終わったときに在庫が残ること**。
> キャンプブームの終息では、テント・調理器具を大量に仕入れた小売が
> 値引き処分に追われた。アウトドアが「用具から衣料へ」シフトしたのは、
> 衣料のほうが回転が速く、型落ちの痛みが小さいから。

## 5. 小売の算数：粗利と在庫がすべて

### 5-1. スポーツ専門店1店舗の損益イメージ

```
【スポーツ専門店（郊外型・売場500坪）の損益イメージ／年間・概念図】

  売上高                        500,000千円  (100.0%)
  ├ 売上原価                    312,000千円  ( 62.4%)
  └ 売上総利益（粗利）          188,000千円  ( 37.6%)  ← 専門店の標準水準
       ├ 人件費                  65,000千円  ( 13.0%)
       ├ 地代家賃                50,000千円  ( 10.0%)  ← 郊外ロードサイドでも重い
       ├ 水道光熱・物流・広告     45,000千円  (  9.0%)
       └ 営業利益                28,000千円  (  5.6%)

  ここに「値引き」が効くと：
   10%の在庫を半額処分 → 粗利率 37.6% → 約32% → 営業利益はほぼ消える
   ＝ **在庫の健全さが、そのまま利益**。
```

（業界一般の構造を示した概念モデル。実際の数値は企業・立地により大きく異なる）

### 5-3. 専門店が抱える3つの構造的弱点

| 弱点                     | 中身                                                           | 打ち手                                                           |
| ------------------------ | -------------------------------------------------------------- | ---------------------------------------------------------------- |
| **在庫が重い**           | サイズ×カラー×モデルで品番が爆発する。1型で20SKUを超えることも | 在庫を絞る＝品揃えの魅力が落ちる。常にこのジレンマ               |
| **季節と天候に振られる** | 暖冬でスキー・防寒が動かない、冷夏で水着が残る                 | 季節商材を減らし、通年商材（シューズ・アスレジャー）へ寄せる     |
| **ECと価格で勝てない**   | 同一商品なのでネットと比較される                               | ①PB、②フィッティング等のサービス、③中古・修理、④施設運営へ逃げる |

帝国データバンクの2024年度調査では、売上は「前年度並み」が57.1%で最多、「増収」は22.0%。
損益は「増益」39.1%が最多だが、「赤字」28.5%と「減益」28.3%を合わせた
**業績悪化が56.8%**にのぼる（前年度から2.6ポイント低下）。
市場全体は伸びているのに、**個社の過半は苦しい**という典型的な成熟市場の姿を示している。

## 6. 競争要因（KSF）と参入障壁

| 立場                       | 勝負どころ                                                | 参入障壁の高さ                                                  |
| -------------------------- | --------------------------------------------------------- | --------------------------------------------------------------- |
| **メーカー（グローバル）** | 素材・ソール技術、トップ選手契約、ブランドの歴史          | **非常に高い**。技術と信頼の蓄積が10年単位で必要                |
| **メーカー（新興）**       | 単一カテゴリへの一点突破（ランニング、リカバリー等）＋DTC | **下がった**。委託生産とSNS・ECで参入できる。OnやHOKAの台頭が例 |
| **小売（大型チェーン）**   | 出店立地、在庫の回し方、PB比率                            | 中程度。資本と物流が要るが、技術は要らない                      |
| **小売（専門店・地域店）** | 競技知識、フィッティング、部活・チームとの関係            | 低いが、**関係資産は模倣されにくい**                            |

> ポイント：**メーカー側の障壁は高いまま、小売側の障壁だけが崩れた**。
> ECとDTCが「棚を持つこと」の価値を下げたため、
> 小売は「棚以外の何か」（PB・サービス・中古・施設）を持たないと生き残れない。

## 7. 規制・制度で押さえるべきもの

| 制度                               | 内容                                                                                                                          | 業界への効き方                                                             |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| **部活動改革（地域展開）**         | スポーツ庁の方針。2026年度から平日も対象、2026〜2032年度が実施期間                                                            | 購買主体が学校から個人へ。地域スポーツ店の最大のリスク要因                 |
| **免税制度の見直し**               | 2026年11月1日から**リファンド方式**（店頭は税込で販売し、出国時に還付）へ移行。消耗品と一般物品の区分、消耗品50万円上限も撤廃 | 免税手続きの実務負担が変わる。インバウンド比率の高い都市型店に影響         |
| **家庭用品品質表示法・景品表示法** | 繊維製品の表示義務、機能性の表示規制                                                                                          | 「〇〇%軽量」などの機能訴求に根拠が要る                                    |
| **PL法（製造物責任）**             | ヘルメット、プロテクター等の安全関連用品                                                                                      | 各競技団体の公認規格（野球のSGマーク等）が事実上の参入条件になる           |
| **競技団体の用具規定**             | 水着、シューズの厚さ、ゴルフクラブの反発係数など                                                                              | **ルール改定が一夜で製品を陳腐化させる**。水着やシューズの規制強化が代表例 |

## 8. まとめ：3つの問いで業界が読める

1. **誰が買っているか**（中高生 → 中高年・非競技者へ移った）
2. **どこで買っているか**（専門店 → EC・メーカー直販・量販へ分散した）
3. **在庫は健全か**（ブームの終わりに残った在庫が、翌期の利益を食う）

この3つを押さえると、各社の決算も、店の閉店も、値引きセールの意味も読める。

## 9. 用語メモ

| 用語                             | 意味                                                                                                               |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| **部活動の地域移行（地域展開）** | 学校の部活動を地域のクラブ・民間事業者へ移す政策。2026年度から平日も対象。用品の購買主体が学校から保護者個人へ移る |
| **学校指定品**                   | 学校・部が指定する体操服・ジャージ・用具。値引き競争が起きにくく、地域の店の安定収入源だった                       |
| **SKU（Stock Keeping Unit）**    | 在庫管理上の最小単位。同じモデルでもサイズ・色が違えば別SKU。スポーツ用品はSKUが膨らみやすく在庫が重い             |
| **坪効率**                       | 売場1坪あたりの年間売上高。小売の店舗効率を測る基本指標                                                            |
| **在庫回転日数**                 | 在庫が売り切れるまでの平均日数。伸びていれば売れ残りが増えている＝翌期の値引き予告                                 |
| **既存店売上前年比**             | 新規出店分を除いた、1年以上営業している店だけの売上前年比。地力を示す                                              |
| **リファンド方式（免税）**       | 店頭では消費税込みで販売し、出国時に税関で確認のうえ還付する方式。2026年11月から日本もこの方式へ移行する           |
| **リカバリーウェア**             | 着用して休むことで疲労回復を促すとうたう衣料。一般医療機器として届出される商品もある。近年の成長カテゴリ           |
