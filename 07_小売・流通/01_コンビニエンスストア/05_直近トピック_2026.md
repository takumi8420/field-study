## 1. 3社の決算が逆転した — ローソン・ファミマが最高益、セブンは減益

2026年2月期（2025年度）の決算は、**長年の序列が初めて崩れて見えた**年になった。

| チェーン                           | チェーン全店売上高    | 事業利益／営業利益                                 | 平均日販                                  | 既存店客数   |
| ---------------------------------- | --------------------- | -------------------------------------------------- | ----------------------------------------- | ------------ |
| **セブン-イレブン（国内CVS事業）** | —                     | 営業利益 **2,336億円**（前年比95.3%、減益）        | 約 **69.9万円**                           | **伸び悩み** |
| **ローソン**                       | 3兆223億円（+4.5%）   | 事業利益 **1,123億円**（+7.0%、**3期連続最高益**） | **59.8万円**（前年差+2.4万円、過去最高）  | **プラス**   |
| **ファミリーマート**               | 3兆3,002億円（+1.7%） | 事業利益 **1,002億円**（+17.9%、**過去最高**）     | **58.5万円**（過去最高）、既存店日商+3.0% | **プラス**   |

（各社決算発表、および時事通信・流通ニュース・ダイヤモンド・チェーンストアオンライン等の報道ベース）

セブン&アイ・ホールディングス連結では、
**営業収益 10兆4,302億円（▲12.9%）、営業利益 4,229億円（+0.5%）**。
営業収益の大幅減は、**イトーヨーカ堂を中心とするスーパーストア事業とセブン銀行の非連結化**
によるもので、事業の縮小ではない。スーパー譲渡益もあり、**純利益は過去最高水準**となった。
つまりセブン&アイは、2025年度に**「コンビニ専業企業」へと姿を変えた初年度**を終えている。

**なぜ逆転したのか（解釈）**

- ローソンは**増量企画**（「盛りすぎチャレンジ」等）で量の訴求に振り、
  インフレ下の節約志向に刺さって客数を取ったと報じられる
- ファミリーマートはPB「ファミマル」、コンビニエンスウェア、店舗メディアという
  **本業以外の利益源**を積み上げた
- セブン-イレブンは高品質・高価格路線を維持したが、**「コンビニは高い」という意識**が
  強まる局面では価格面で不利に働いた

> 構図：**日販トップのセブンが客数で負けている**という事実が、2026年の最大のニュース。
> 小売は景気局面で勝ち筋が入れ替わるという教科書的な例が、日本最大級の小売で起きた。

## 2. 客単価は12年連続で伸び、客数は4年ぶりにマイナス

日本フランチャイズチェーン協会（JFA）の**コンビニエンスストア統計調査 年間集計（2025年1〜12月）**。

| 指標           | 前年比    | 補足                  |
| -------------- | --------- | --------------------- |
| 既存店売上高   | **+1.9%** | 5年連続のプラス       |
| 年間平均客単価 | **+2.4%** | **12年連続で伸長**    |
| 年間来店客数   | **▲0.5%** | **4年ぶりのマイナス** |

```
【売上が伸びている理由の分解】

  既存店売上 +1.9%
      = 客数 ▲0.5%  ×  客単価 +2.4%
        ────────      ────────
        来る人は減った   1人が使う額は増えた
                          （＝値上げと買上点数）

  → 売上の伸びは「値段」が作っている。
    物価上昇が止まれば、この+1.9%は消える。
```

経済産業省の**商業動態統計**でも、2025年のコンビニエンスストア販売額は
**前年比 +3.4%**、金額ベースで **13兆3,212億円** 規模。
「1店舗当たり販売額」の増加が続くとともに、**店舗数も4年ぶりに増加**した。

> 構図：**店舗数の微増と客単価の上昇で売上は伸びているが、来店客数は減っている**。
> これは「業界が縮み始めた」のではなく、**「値上げで持たせている」**という状態。
> 2026年以降、客数をプラスに戻せるかどうかが各社の最大の経営課題になっている。

## 3. 最低賃金の上昇が加盟店モデルを直撃している

2026年に最も重い論点は、決算数字ではなく**加盟店の人件費**である。

- 加盟店の人件費は、加盟店総収入の**6〜7割**を占める最大の経費
  （→ [① 1店舗の経済学](01_1店舗の経済学.md)）
- 最低賃金は2020年代を通じて毎年引き上げられており、コンビニの日販の伸び率を上回る年が続く
- **最低賃金の引き上げは時給だけでなく、社会保険料・割増賃金・賞与に自動的に波及する**ため、
  人件費比率の高い小売・外食では経営への影響が増幅される

ダイヤモンド・オンラインの「総予測2026」は、
**最低賃金上昇によりセブン-イレブンの加盟店は数年後に「利益半減」もありうる**とし、
**既存モデルでの出店はもはや限界ではないか**という論点を提起している（推計・分析記事ベース）。

構造としてはこう整理できる。

```
【加盟店モデルに効く2つの伸び率】

   日販の伸び        年 +1〜4%   ← 値上げと客単価で稼いでいる
   最低賃金の伸び    年 +3〜5%   ← 政策として継続する見通し
   ─────────────────────────────
   差がマイナスに振れる年が続くと、
   オーナー利益（売上の2〜4%の薄い層）が消える

   打ち手は2つしかない
     ① チャージ率（本部の取り分）を下げる  → 本部の利益が減る
     ② 店舗の労働時間そのものを減らす      → 時短・省人化・作業削減
```

①は本部の収益を直接削るため、簡単には動かない。
②は省人化投資（セルフレジ、AI発注、自動釣銭機）と作業の削減で進んでいるが、
コンビニ店舗の作業は検品・陳列・清掃・調理・接客と多岐にわたり、
**レジだけ無人化しても人は減らない**という現実がある。

なお2025年度、セブン-イレブンが打ち出した加盟店のテコ入れ策について
**「ワンオペ（1人勤務）推奨」と受け取られる内容が含まれ、加盟店オーナーから反発が出た**
と報じられている（ダイヤモンド・オンライン、報道ベース）。
省人化と加盟店の負担軽減が、必ずしも同じ方向を向かないことを示す例になっている。

## 4. 北米セブンの上場が2027年度以降へ延期された

2024年8月、カナダの**アリマンタシォン・クシュタール**がセブン&アイに買収を提案した。
1株2,600円、総額約7兆円規模と報じられ、実現すれば**海外企業による日本企業の買収として
過去最大級**になるはずだった（クシュタールによる提案は2005年・2020年に続き3度目）。

- 2025年3月、井阪隆一社長兼CEOが退き、社外取締役のスティーブン・デイカス氏が
  社長兼CEOに就任。対抗策として **①7-Eleven, Inc.（北米コンビニ事業）の米国上場**、
  **②総額2兆円規模の自社株買い** を掲げた
- **2025年7月、クシュタールが買収提案を撤回**。セブン&アイは自力成長路線へ
- ところが **2026年、北米IPOは「早くても2027年度」へ延期**されたと報じられた
  （C-Store Dive、CSP Daily News、NACS等の米業界メディア）

延期の理由として挙げられているのは3点。

| 要因                     | 内容                                                                               |
| ------------------------ | ---------------------------------------------------------------------------------- |
| **米国の個人消費の減速** | インフレの継続で、とくに低所得層の消費が弱い                                       |
| **ガソリン需要の減少**   | 北米のコンビニは**ガソリンスタンド併設型が主流**で、燃料マージンへの依存が大きい   |
| **自社の立て直しの遅れ** | 日本型のフレッシュフード（中食）を北米に移植する転換が、まだ結果に結びついていない |

一方で、**株主還元方針（約130億ドル規模の自社株買い）は変更しない**としている。

> 構図：北米セブンは、**「日本のコンビニのやり方は輸出できるのか」**という問いそのもの。
> 中食・1日3便・単品管理は、**店舗密度・労働力・食文化**の3条件の上に成り立つ
> （→ [③ 商品と物流](03_商品と物流.md)）。
> この3条件が違う北米で同じモデルを作るには、専用工場と配送網を一から建てる必要がある。
> IPO延期は、その工事がまだ終わっていないという宣言に近い。

## 5. 食品ロス対策が「ポイント還元」から「本部主導の値引き」へ

長年、コンビニは**見切り販売（値引き）を事実上抑制してきた**。
定価を崩すと「夕方に行けば安い」という行動が定着し、チェーン全体の粗利率が下がるためである。
これに対し公正取引委員会は、**見切り販売を不当に制限することは独占禁止法上問題となりうる**
との立場を示してきた（→ [② フランチャイズという仕組み](02_フランチャイズという仕組み.md)）。

流れは次のように動いてきた。

| 時期         | 動き                                                                                                                                                                    |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2009年ごろ   | 各社が**廃棄ロス原価の15%程度を本部が負担**する制度を導入（報道ベース）                                                                                                 |
| 2019年〜     | セブン「エシカルプロジェクト」（期限間近の商品にnanacoポイント還元）、ローソン「てまえどり」。**値札は崩さず実質値引き**する折衷策                                      |
| **2024年〜** | **セブン-イレブンが本部主導で値引きを推奨する方針に転換**したと報じられる。販売期限を店舗に通知する仕組みと、統一の値引きシールを本部が整備（日本経済新聞、報道ベース） |
| 現在         | フードバンクへの寄贈DX、AI需要予測、包装技術による賞味期限延長が並行して進む                                                                                            |

背景となる数字。

- 日本全体の食品ロス量は **2023年度で約464万トン**（消費者庁・環境省・農水省の推計）
- ローソンは食品ロスを **2018年比で2025年に25%削減、2030年に50%削減**する目標を公表
- 政府は、コンビニで販売期限の迫った商品を寄贈に活用する**フードドネーションDX**を支援している
  （消費者庁の食品ロス削減関係資料、2026年1月版）

> 構図：**食品ロス削減という社会的要請と、加盟店の収益悪化という経営課題が、
> はじめて同じ方向を向いた**。
> 廃棄が減れば加盟店の経費が減り、本部のチャージも（コンビニ会計により）減るが、
> 社会的な批判とブランド毀損のコストを考えれば本部にも合理性がある。
> 長年こじれてきた対立が、外部環境の変化で解けつつある例として読める。

## 6. 24時間営業は「選べるが、選ばれない」状態が続いている

2019年の時短営業問題と、2020年9月の公正取引委員会の実態調査を受け、
各社は**時短営業を選択できる制度**を整えた。
ところが実際の移行は限定的で、報道ベースでは次のような状態が続いている。

| 指標                     | 状況                                                                                           |
| ------------------------ | ---------------------------------------------------------------------------------------------- |
| 24時間営業店の比率       | **3社とも90%前後**まで低下したと報じられる                                                     |
| 実際に時短へ切り替えた店 | **数%台**にとどまるとの報道もあり、数字は集計基準で幅がある                                    |
| 非24時間の新しいタイプ   | 病院・大学・オフィス・工場・スポーツジム内の店舗など、**そもそも24時間の必要がない立地**が増加 |

**なぜ選べるのに選ばれないのか。** 経済としてはこう説明できる。

```
   時短にすると…
     ・深夜の人件費が消える              → プラス
     ・深夜売上が消える                  → マイナス
     ・24時間営業インセンティブを失う     → マイナス
     ・「いつでも開いている」信頼が落ち、
       昼間の客数にも効く                → マイナス（効きが読めない）

   → 深夜が極端に暇な店以外は、計算が合わない
```

つまり、**制度上の自由は手に入ったが、経済的な自由は手に入っていない**。
一方で、上の表の3行目のように、**立地の多様化によって自然に非24時間の店が増える**という
別の経路で、24時間比率は下がり続けている。

## 7. 全体の構図（まとめ）

- **値上げで持たせた5年間が限界に近づいている。** 既存店売上は5年連続プラスだが、
  内訳は客単価+2.4%と客数▲0.5%。**来る人は減っている**
- **勝ち筋が入れ替わった。** 節約志向に寄せたローソン・ファミマが客数を取って最高益、
  品質路線のセブンが国内で減益。小売は景気局面で順位が動く
- **最大の変数は最低賃金。** 加盟店の人件費は総収入の6〜7割。
  賃金の伸びが日販の伸びを上回り続けると、フランチャイズ契約の分配比率そのものが問い直される
- **対立の構造は緩和の方向にある。** 見切り販売は本部主導の値引きへ、
  24時間営業は選択制へ。ただし時短は「選べるが選ばれない」状態が続く
- **海外が宿題として残っている。** クシュタールの買収提案は撤回されたが、
  北米セブンの立て直しは道半ばで、IPOは2027年度以降へ延期された

| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **既存店／全店**        | 既存店＝開店1年以上の店だけの集計。全店＝新店を含む合計。決算を読むときはどちらの数字かを必ず確認する                                                   |
| **事業利益**            | ローソン・ファミリーマートが使う利益指標。おおむね営業利益に相当するが定義が各社で異なる                                                                |
| **非連結化**            | 子会社を連結決算の範囲から外すこと。セブン&アイは2025年度にスーパーストア事業とセブン銀行を非連結化したため、営業収益が大きく減ったが事業の縮小ではない |
| **IPO（新規株式公開）** | 未上場会社が株式を市場に公開すること。セブン&アイは北米コンビニ事業の米国上場を検討し、2027年度以降へ延期した                                           |
| **ワンオペ**            | 1人勤務で店舗を回すこと。人件費は減るが、防犯・作業量・従業員の負担の面で批判がある                                                                     |
| **フードドネーション**  | 販売期限が迫った食品をフードバンク等へ寄贈すること。政府がアプリ開発や保管設備の導入を支援                                                              |
| **てまえどり**          | 棚の手前にある（期限の近い）商品から取るよう客に促す取り組み。すぐ食べるなら手前で十分、という発想                                                      |
