# ④ 市場の成熟と次の一手 — 店を増やせなくなった業界

このノートで分かること：日本のコンビニが**なぜ店舗数を増やせなくなったのか**、
そのなかで各社が**既存店の日販をどう上げようとしているのか**。
そして店舗以外の収益（金融・収納代行・行政サービス）と海外展開が、
成熟した本業の外側でどんな役割を担っているのか。

> 結論：コンビニの成長エンジンは **「店を増やす」→「1店の売上を上げる」** に切り替わった。
> ところが1店の売上を分解すると **客数 × 客単価** で、
> 客数はすでに減り始めており、**伸びているのは客単価＝値上げの分だけ**。
> だから各社は ①客数を戻す手（生鮮・冷凍・宅配）、②店舗以外の収益（金融・行政）、
> ③海外、の3方向に同時に手を伸ばしている。

## 1. 店舗数はなぜ頭打ちになったのか

```
【日本のコンビニ店舗数（イメージ）】

  店舗数
   5.6万 ┤                    ╭──────────────  横ばい〜微増
   5.4万 ┤              ╭─────╯
   5.0万 ┤        ╭─────╯
   4.0万 ┤   ╭────╯
   3.0万 ┤ ╭─╯
   2.0万 ┤╭╯
        └┴────┴────┴────┴────┴────┴────▶
        1990  2000  2010  2018  2020   2026
                          ▲
                    このあたりで伸びが止まる
```

（大手3社の合計は2026年1月時点で約51,700店と報じられる。
業界全体では日本フランチャイズチェーン協会の月次統計で確認するのが確実）

| チェーン         | 国内店舗数      | 時点             | 前年比 |
| ---------------- | --------------- | ---------------- | ------ |
| セブン-イレブン  | 約 **21,700店** | 2026年1〜2月時点 | +1.0%  |
| ファミリーマート | 約 **16,100店** | 同上             | +0.6%  |
| ローソン         | 約 **13,800店** | 同上             | +0.3%  |
| 大手3社 合計     | 約 **51,700店** | 同上             | —      |

（各社公表を集計した報道ベース。集計時点と「国内/海外」「FC/直営」の定義で数値が動く）

止まった理由は4つあり、**どれか1つではなく重なって効いている**。

| 理由                            | 中身                                                                                                                                 |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| **①良い立地が尽きた**           | コンビニの立地条件（交通量・視認性・駐車場・商圏人口）を満たす場所は有限。すでに主要な場所は埋まっている                             |
| **②オーナーが集まらない**       | 夫婦2人・単店で年収500万円前後、24時間シフトの穴埋め付き（→ [① 1店舗の経済学](01_1店舗の経済学.md)）。この条件で独立したい人が減った |
| **③ドミナントの副作用が見えた** | 出せば出すほど既存店の日販が落ち、加盟店との関係が悪化する（→ [② フランチャイズという仕組み](02_フランチャイズという仕組み.md)）     |
| **④人口が減る**                 | 商圏人口3,000人で成立する業態は、人口減少の影響をまともに受ける                                                                      |

ただし2025年は、商業動態統計ベースで**店舗数が4年ぶりに増加**した。
これは「再び拡大局面に入った」というより、**コロナ禍で止めていた建て替え・移転・
不採算店整理が一巡し、新しい立地への出し直しが動いた**結果と読むのが自然。

## 2. 既存店をどう伸ばすか — 客数 × 客単価に分解する

小売の既存店売上は、必ず **客数 × 客単価** に分解して読む。
これは業種を問わず使える基本の分解で、コンビニではとくに効く。

```
【既存店売上の分解】

  既存店売上 = 客 数 × 客単価
                │        │
                │        ├─ 1品単価（値上げ・高価格帯へのシフト）
                │        └─ 買上点数（ついで買いの誘発）
                │
                ├─ 来店頻度（週に何回来るか）
                └─ 商圏人口 × 自店シェア
```

### 直近の数字（日本フランチャイズチェーン協会、2025年1〜12月 年間集計）

| 指標           | 前年比                         | 意味                       |
| -------------- | ------------------------------ | -------------------------- |
| 既存店売上高   | **+1.9%**（5年連続プラス）     | 見た目は好調               |
| 年間平均客単価 | **+2.4%**（12年連続で伸長）    | 値上げと買上点数で押し上げ |
| 年間来店客数   | **▲0.5%**（4年ぶりのマイナス） | **ここが問題**             |

> ポイント：**売上が伸びているのは値段が上がっているからで、
> 来る人はむしろ減っている**。これが2020年代後半のコンビニ業界を貫く一行。
> 客単価の上昇は物価上昇と表裏一体なので、物価が落ち着けば売上の伸びは止まる。
> だから各社は「客数を戻す」ことに本気で取り組まざるを得ない。

### 客数が減っている理由

| 要因                       | 中身                                                                                                                                 |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| **節約志向**               | 物価上昇で「コンビニは高い」という意識が戻った。昼食を弁当持参やスーパーに切り替える動き                                             |
| **小型食品スーパーの台頭** | まいばすけっとなど都市型の小型スーパー、[ドラッグストア](../04_ドラッグストア/README.md)の食品強化が、コンビニの商圏に直接入ってきた |
| **人口減・高齢化**         | 単純に商圏人口が減る。高齢層はコンビニの主力客層ではなかった                                                                         |
| **たばこ需要の減少**       | たばこ目的の来店が減ると、ついで買いも消える。売上構成比20〜25%の商材なので効きが大きい                                              |

### 3社の打ち手が分かれた

2026年2月期の決算では、**ローソンとファミリーマートが既存店客数をプラスにした一方、
セブン-イレブンは客足が伸び悩んだ**と報じられた。

| チェーン             | 直近の方向性                                                                                 | 効いたこと／課題                                                           |
| -------------------- | -------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| **ローソン**         | 増量企画・値頃感の訴求。「盛りすぎチャレンジ」など量で訴える販促                             | インフレ下の節約志向に刺さり、客数がプラス。全店平均日販59.8万円で過去最高 |
| **ファミリーマート** | PB「ファミマル」、アパレル「コンビニエンスウェア」、店舗メディア「ファミリーマートビジョン」 | 事業利益+17.9%で過去最高。日商58.5万円                                     |
| **セブン-イレブン**  | 品質・商品力重視。焼きたてパン、7NOW（宅配）、大型店フォーマット                             | 日販は依然トップの約69.9万円だが、客数が伸び悩み、国内コンビニ事業は減益   |

> ポイント：**日販トップのセブンが客数で苦戦している**のが2026年の特徴的な構図。
> 「高品質・高価格」という強みが、節約志向の局面では逆風になりうる。
> 逆にローソン・ファミマは「量」と「値頃感」で客数を取りに行って成果を出した。
> 小売は**景気局面によって勝ち筋が入れ替わる**という典型例。

## 3. 高齢化と「食品スーパー化」

コンビニの主力客層はもともと **20〜30代の男性単身者** だった。
今は客層が高齢側にずれており、それに合わせて売場が変わりつつある。

| 変化                       | 具体的に何をしているか                         | 狙い                                                                                                   |
| -------------------------- | ---------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| **生鮮の導入**             | カット野菜、少量パックの肉・魚、豆腐、卵、牛乳 | 近所のスーパーが撤退した地域で、日常の買い物先になる                                                   |
| **冷凍食品の拡大**         | 冷凍弁当・冷凍惣菜の売場を2〜3倍に             | 単身高齢者の備蓄需要。**廃棄が出ない**という経営上の利点も大きい（→ [③ 商品と物流](03_商品と物流.md)） |
| **少量・小分け**           | 半人前の惣菜、小容量のパン・菓子               | 食べきれる量。高齢世帯・単身世帯向け                                                                   |
| **店内飲食（イートイン）** | 座席の設置                                     | 高齢者の居場所。滞在時間を伸ばす                                                                       |
| **移動販売・買い物支援**   | 移動販売車、ネットスーパー連携、自治体との協定 | 買い物弱者対策。自治体の補助が付くこともある                                                           |

この方向を突き詰めると、コンビニは
**[食品スーパー](../03_食品スーパー/README.md)の小型版**に近づいていく。
ただし決定的な違いが2つある。

- **価格**：コンビニは定価販売が基本。スーパーの特売には勝てない
- **売場面積**：30坪では生鮮のフル品揃えはできない。**「補完」であって「代替」ではない**

だからコンビニの生鮮強化は、スーパーを倒しに行く戦略ではなく、
**スーパーが撤退した地域や、少量しか買わない客を拾う戦略**として読むのが正確。

## 4. 店舗以外の収益 — コンビニは「窓口」でもある

コンビニの収益は、商品の粗利だけではない。
**モノを売らずに手数料を得る収益**が、日販とは別の層として積み上がっている。

```
【コンビニが担っている「窓口」機能】

   お金まわり              情報・手続きまわり        物流まわり
  ┌──────────┐         ┌──────────────┐       ┌────────────┐
  │ ATM        │         │ 住民票・印鑑登録 │       │ 宅配便取次   │
  │ 収納代行   │         │ 証明書のコンビニ │       │ 受取ロッカー │
  │ （公共料金 │         │ 交付             │       │ ECの受取拠点 │
  │   通販代金 │         │ チケット発券     │       │ 返品受付     │
  │   税・保険）│         │ 各種申込         │       └────────────┘
  │ 電子マネー │         │ 住民票以外の     │
  │ ・コード決済│         │ 自治体サービス   │
  └──────────┘         └──────────────┘

   → 手数料収入そのものは小さいが、
     「来店する理由」を作ることで日販を支えている
```

| 機能                                 | 収益の性格                                                | ポイント                                                                                                                                                               |
| ------------------------------------ | --------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **収納代行**                         | 1件あたり数十円の手数料。件数が膨大                       | 公共料金・通販代金・税金・社会保険料。**手数料は微小でも、支払いついでの買い物を生む**                                                                                 |
| **ATM**                              | セブン銀行モデル。提携金融機関から**ATM受入手数料**を取る | セブン銀行は収益の約9割がATM受入手数料と報じられた。設置台数は2万台超規模。→ [ネット銀行](../../05_金融/04_ネット銀行/README.md)                                       |
| **行政サービス**                     | 証明書のコンビニ交付（住民票、印鑑登録証明、戸籍など）    | 自治体の窓口コスト削減とセット。手数料は小さいが公共インフラ化が進む                                                                                                   |
| **宅配便取次・受取**                 | 取次手数料                                                | ECの拡大で受取拠点としての価値が上昇。→ [宅配便](../../13_運輸・物流/07_宅配便/README.md)、[EC・ネット通販](../../04_情報通信・IT・ネット/08_EC・ネット通販/README.md) |
| **店舗メディア（リテールメディア）** | 店内デジタルサイネージの広告枠をメーカーに売る            | **粗利率がほぼ100%の新収益**。ファミリーマートの「ファミリーマートビジョン」が先行                                                                                     |

> ポイント：これらの機能で直接稼ぐ金額は、商品の粗利に比べれば小さい。
> 価値の本体は **「来店理由の束」** にある。
> 公共料金を払いに来た客が缶コーヒーを買う。この連鎖が日販を支えている。
> 逆に言うと、**キャッシュレス化とオンライン手続きの普及は、この来店理由を1つずつ削る**。
> ATM利用も収納代行も長期では減少圧力にさらされる。
> だから各社は**リテールメディア**という、来店を前提にしない新しい収益を探している。

## 5. ネットコンビニ・宅配 — 「近くて便利」をもう一段近くする

コンビニの価値は「近さ」だった。宅配はその近さを**距離ゼロ**にする試み。

| サービス                               | 内容                                                  | 経済性の論点                                                                               |
| -------------------------------------- | ----------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| **7NOW（セブン-イレブン）**            | 自社アプリで注文、店舗から最短20〜30分で配達          | 自社で配達網を持つか委託するかでコストが変わる。**配送費をどちらが負担するか**が最大の論点 |
| **ローソンデリバリー／ファミマの宅配** | Uber Eats・出前館などのプラットフォーム連携＋自社配達 | プラットフォームの手数料（売上の2〜3割）が粗利30%を食い尽くす                              |
| **ネットスーパー型の取り組み**         | まとめ買い・置き配・定期配送                          | 客単価を上げないと配送費が合わない                                                         |

**構造的な難しさ**を数字で見ると分かりやすい。
コンビニの粗利率は約30%。客単価は700円前後。
つまり1回の買い物で生まれる粗利は**約200円**。
ここから配達員の人件費（1配達あたり数百円）を出すと、**確実に赤字になる**。

だから宅配が成立する条件は3つに絞られる。

- **客単価を大きく上げる**（まとめ買い、配送料の徴収、最低注文金額の設定）
- **配達を既存のリソースで賄う**（店舗スタッフの手空き時間、近隣の複数注文をまとめる）
- **配送そのものでは儲けず、来店できない客を取り込む手段と割り切る**

加えて、加盟店側から見ると **宅配の労力は誰が負うのか** という論点がある。
ピッキングと梱包は店舗の作業になるので、人手不足の店にとっては負担増になりうる。
[② フランチャイズという仕組み](02_フランチャイズという仕組み.md)で見た
「本部は売上、加盟店はコスト」という非対称が、ここでも顔を出す。

## 6. 海外展開 — 2つのまったく違うゲーム

日本のコンビニ3社はいずれも海外に出ているが、**北米とアジアではやっていることが違う**。

```
【北米型 と アジア型】

■ 北米（7-Eleven, Inc.）
   ガソリンスタンド併設型が主流
   ┌─────────────┐
   │ 給油所（大） │ ← 売上の大半は燃料。粗利は薄い
   │  ＋          │
   │ 売店（小）   │ ← 飲料・スナック・たばこ中心。中食が弱い
   └─────────────┘
   課題：EV化とガソリン需要の減少 → 燃料マージンに頼れなくなる
   打ち手：日本型のフレッシュフード（中食）を移植する

■ アジア（台湾・タイ・中国・東南アジア）
   日本とほぼ同じ都市型・中食中心のフォーマット
   ・台湾：統一超商（セブン）、全家（ファミマ）が生活インフラ化
   ・タイ：CPグループ傘下でセブンが圧倒的店舗数
   ・中国：都市部で各社が展開。ローソンは上海圏に密度を作る戦略
   形態：ライセンス供与、合弁（現地有力企業と組む）が中心
   → 本部は出資と技術供与で、店舗投資のリスクを取らない
```

| チェーン         | 海外展開の規模（報道ベース）          | 特徴                                                     |
| ---------------- | ------------------------------------- | -------------------------------------------------------- |
| セブン-イレブン   | 世界20か国以上、全体で約 **85,000店** | 北米は直接経営（7-Eleven, Inc.）、アジアはライセンス中心 |
| ファミリーマート | 海外 約 **27,000店**                  | 台湾・タイ・中国など。**現地有力企業との合弁**が基本     |
| ローソン         | 中国・タイ・フィリピン・ハワイ        | 3社で最も小規模。中国は上海周辺に密度を作る戦略          |

（2026年時点の各種集計・報道ベース。集計方法で数値が動くため、各社IRで確認のこと）

**北米が経営上の最大の論点**になっている理由。

- 北米事業はセブン&アイの連結売上の大きな部分を占めるが、**燃料の粗利は薄く景気に振られる**
- **EV化とガソリン需要の減少**という構造的な逆風がある
- そこで「日本型の中食を北米に移植する」という転換を進めているが、
  **専用工場と多頻度配送というインフラを北米で一から作る必要がある**（→ [③ 商品と物流](03_商品と物流.md)）
- 2024年8月、カナダのアリマンタシォン・クシュタールがセブン&アイに買収を提案（1株2,600円、
  総額約7兆円規模と報じられた）。**海外企業による日本企業の買収として過去最大級**だったが、
  2025年7月に撤回された
- 対抗策として掲げられた **7-Eleven, Inc. の北米上場**は、当初2026年後半の予定だったが、
  **2027年度以降へ延期**されたと2026年に報じられている

> ポイント：北米セブンをめぐる一連の動きは、
> **「日本のコンビニのノウハウは、海外でそのまま通用するのか」**という問いそのもの。
> 中食・多頻度配送・単品管理は、**店舗密度と労働力の安さと食文化**の上に成り立っている。
> この3条件が違う北米では、同じモデルが同じようには効かない。
> アジアで成功し北米で苦戦しているのは、そういうことだと読める。

## 7. 次の10年に効く3つの制約

| 制約                | 中身                                                                    | 効き方                                                                                                                                             |
| ------------------- | ----------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **①人件費**         | 最低賃金の継続的な引き上げ。加盟店の人件費は総収入の6〜7割              | 日販の伸び（年1〜4%）より賃金の伸び（年3〜5%）が上回ると、**加盟店モデルが数式として成り立たなくなる**。ロイヤリティ体系そのものの見直し圧力になる |
| **②物流**           | 2024年問題（ドライバーの時間外労働上限）と改正物流効率化法              | **1日3便という前提が揺らぐ**。便数削減、共同配送の他チェーンとの相互利用、深夜便の見直し                                                           |
| **③来店理由の消失** | キャッシュレス化でATM利用減、オンライン手続きで収納代行減、たばこ需要減 | 商品を買わない来店が減ると、ついで買いも消える。**日販の土台が細る**                                                                               |

これに対する各社の答えは、大きく3つの方向に整理できる。

```
【成熟市場での3つの方向】

  ① 店のなかを変える       省人化（セルフレジ、AI発注、自動釣銭機）
                            廃棄が出ない商品（冷凍）への構成シフト
                            高単価商材（店内調理、高価格PB）

  ② 店の外に稼ぎを作る     リテールメディア（広告枠）
                            宅配・EC受取拠点
                            行政・金融サービスの受託

  ③ 日本の外に出る         アジア（フォーマットがそのまま効く）
                            北米（中食の移植に挑戦中）
```

省人化については、[ロボット](../../01_注目テーマ/09_ロボット/README.md)や
[生成AI](../../01_注目テーマ/01_生成AI/README.md)の適用（AI発注、需要予測、シフト作成）が
実装段階に入りつつある。ただしコンビニ店舗の作業は
**検品・陳列・清掃・調理・接客**と多岐にわたり、レジだけ無人化しても人は減らない。
**「人がやる作業の総量」を減らせるかどうか**が、省人化投資の本当の評価軸になる。

## 8. 他の小売業態と並べて見る

| 業態                                                         | 成長の主エンジン    | 現在の状況                                    | コンビニとの関係                   |
| ------------------------------------------------------------ | ------------------- | --------------------------------------------- | ---------------------------------- |
| **コンビニ**                                                 | 店舗数 → 既存店日販 | 店舗数は頭打ち、客数はマイナス                | —                                  |
| [食品スーパー](../03_食品スーパー/README.md)                 | 商圏シェア          | 都市型小型店が伸び、コンビニの商圏に侵入      | **最も直接的な競合になりつつある** |
| [ドラッグストア](../04_ドラッグストア/README.md)             | 食品強化と調剤      | 出店が続き、食品で集客して調剤・化粧品で稼ぐ  | 食品の安さでコンビニの客を奪う     |
| [スーパー・GMS](../02_スーパー・GMS/README.md)               | 大型店・SC          | 苦戦。セブン&アイはイトーヨーカ堂を切り離した | セブン&アイの構造改革の当事者      |
| [ディスカウントストア](../09_ディスカウントストア/README.md) | 価格                | 節約志向の追い風                              | 節約局面でコンビニから客を吸う     |
| [通販・D2C](../15_通販・D2C/README.md)                       | オンライン          | 受取拠点としてコンビニと補完関係              | 競合でもあり、協業相手でもある     |

> ポイント：コンビニの競合は、もう他のコンビニだけではない。
> **「昼食をどこで買うか」という同じ問いに答えるすべての業態**が競合になっている。
> だから既存店の客数を見るときは、業界内のシェア争いではなく
> **「食の買い方」全体のなかでの位置**として読む必要がある。

## 用語メモ

| 用語                               | 意味                                                                                                    |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------- |
| **既存店売上**                     | 開店から1年以上経った店だけを集計した売上。新店の効果を除いた実力値。**客数 × 客単価**に分解して読む    |
| **客単価**                         | 1人の客が1回の買い物で使う金額。1品単価 × 買上点数                                                      |
| **買上点数**                       | 1回の会計で買った商品の数。ついで買いの多寡を示す                                                       |
| **リテールメディア**               | 小売が自社の店舗・アプリ・サイトの広告枠をメーカーに売る事業。在庫も原価もないため粗利率が極めて高い    |
| **収納代行**                       | 公共料金・通販代金・税金などの支払いを店頭で受け付ける業務。1件あたりの手数料は小さいが、来店理由を作る |
| **ATM受入手数料**                  | 提携金融機関がATM設置者に払う手数料。セブン銀行の主な収益源                                             |
| **証明書のコンビニ交付**           | 住民票や印鑑登録証明書をコンビニのマルチコピー機で取得できる自治体サービス                              |
| **7NOW**                           | セブン-イレブンの宅配サービス。自社アプリから注文し、店舗から短時間で配達する                           |
| **アリマンタシォン・クシュタール** | カナダのコンビニ大手。2024年8月にセブン&アイへ買収を提案し、2025年7月に撤回                             |
| **7-Eleven, Inc.**                 | セブン&アイの北米コンビニ事業会社。ガソリン併売型が主流で、北米上場が検討されている                     |
| **買い物弱者**                     | 近隣に店がなく日常の買い物が困難な人。過疎地・高齢者に多く、コンビニの社会的役割の論点になる            |
