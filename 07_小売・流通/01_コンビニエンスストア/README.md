## このフォルダの読み方

コンビニは **「30坪の店を5万軒つくり、その1軒ごとの日販を最大化する装置」**である。
売上も利益も、**日販（1日あたり売上高）** というたった1つの数字から機械的に決まる。
粗利率は約30%でほぼ固定、本部チャージ率は契約で固定、家賃と設備は多くの型で本部持ち。
だから動かせる変数は実質**「日販」と「人件費」の2つだけ**しかない。

そして、この業界を他の小売と分けている最大の特徴は
**店を経営しているのが本部ではなく加盟店だ**ということ。
本部は不動産・物流・システム・商品開発・ブランドを提供し、粗利の40〜60%台を受け取る。
この分配の非対称が、24時間営業・見切り販売・ドミナント出店をめぐる対立の根にある。

**本フォルダは小売分類の最初のノート**なので、①で「1店舗の経済性」を丁寧に扱った。
後続の小売業（スーパー、食品スーパー、ドラッグストア等）は、この読み方を土台にしている。

## 1. 業界の定義・範囲

**コンビニエンスストア ＝ 売場面積30坪前後、年中無休・長時間営業、
食品を中心に約3,000品目を扱う小型小売店**。
経済産業省の商業動態統計では「飲食料品を扱い、セルフサービス方式で、
売場面積30平方メートル以上250平方メートル未満、営業時間が1日14時間以上」の店舗を指す。

```
【コンビニの位置（売場面積 × 品揃え）】

  売場面積
   大 ┤   [GMS]        [ホームセンター]
      │      [食品スーパー]
      │         [ドラッグストア]
      │            [小型食品スーパー]
      │               ★コンビニ★  ← 30坪・3,000品目
   小 ┤          [キオスク・自販機]
      └────────────────────────────▶
        少                          多   品揃え

  隣接するが別扱いのもの：
   ・小型食品スーパー（まいばすけっと等）… 価格が安く、生鮮が中心 → 03_食品スーパー
   ・ミニスーパー／ローソンストア100      … 100円均一中心。コンビニの派生業態
   ・駅ナカ売店（キヨスク等）             … 面積が小さく、FCでない
   ・ガソリンスタンド併設店（北米型）     … 燃料が主、売店は従
```

境界の引き方で押さえるべき点は3つ。

- **「便利さ」を売る業態**であって、「安さ」も「品揃え」も売っていない。
  定価販売が基本で、品目数はスーパーの10分の1以下。それでも成立するのは
  **近さ・営業時間・待たないこと**に対価が払われているから
- **フランチャイズが前提**。日本のコンビニは加盟店が9割超で、
  「小売業」であると同時に「フランチャイズ本部業」という性格を持つ
- **本部は小売にとどまらない**。商品企画では実質メーカー、
  配送設計ではオペレーター、決済・収納代行では金融の窓口を兼ねている

| 指標                           | 数値                                                                     | 年・出典                                          |
| ------------------------------ | ------------------------------------------------------------------------ | ------------------------------------------------- |
| コンビニ販売額（事業所ベース） | 約 **13兆3,212億円**、前年比 **+3.4%**                                   | 2025年。経産省 商業動態統計                       |
| 店舗数                         | 2025年は**4年ぶりに増加**。大手3社合計で約 **51,700店**（2026年1月時点） | 経産省 商業動態統計／各社公表を集計した報道ベース |
| 既存店売上高                   | 前年比 **+1.9%**（5年連続プラス）                                        | 2025年1〜12月。日本フランチャイズチェーン協会     |
| 年間平均客単価                 | 前年比 **+2.4%**（12年連続で伸長）                                       | 同上                                              |
| 年間来店客数                   | 前年比 **▲0.5%**（**4年ぶりのマイナス**）                                | 同上                                              |

成長性の読み方。

- **名目は伸びている／人は減っている**。売上の伸びは客単価（＝値上げと買上点数）が作っており、
  来店客数は減少に転じた。物価上昇が落ち着けば、この伸びは止まる
- **店舗数はほぼ飽和**。2018〜2019年ごろに伸びが止まり、以後は横ばい〜微増。
  2025年の増加は、コロナ禍で止まっていた建て替え・移転・不採算店整理の一巡と読むのが自然
- **成長エンジンは3つに分散した**。①既存店の日販（客数を戻す）、
  ②店舗以外の収益（リテールメディア・金融・行政サービス）、③海外

## 3. バリューチェーン（川上 → 川下）

```
【コンビニを中心に見たモノ・カネ・情報の流れ】

 モノ  食品メーカー ─┬─▶ 食品卸 ────┐
       （NB）         │               ├─▶ 共同配送センター ─▶ 店舗 ─▶ 消費者
                      │               │     （温度帯別・1日3便）
       （PB受託製造） └─▶ ベンダー ──┘
                            （専用工場）
                              ▲
                              │ レシピ・原材料・数量を指定
                         コンビニ本部（商品開発）

 カネ  消費者 ──代金──▶ 加盟店
                          │
                          ├─ 売上原価 ──▶ 本部（多くの型で本部が仕入を集約）
                          ├─ チャージ（粗利の40〜60%台） ──▶ 本部
                          ├─ 人件費 ──▶ アルバイト（加盟店が全額負担）
                          └─ 残り ──▶ オーナーの手取り
       本部 ──水道光熱費の約8割・廃棄原価の15%程度──▶ 加盟店

 情報  POS（単品ごとの販売データ）
         ├─▶ 加盟店：仮説を立てて発注する（発注権は加盟店にある）
         ├─▶ 本部  ：商品開発・死に筋排除・配送計画
         └─▶ メーカー／ベンダー：生産計画
```

**付加価値がどこに集まるか**（売上1,000円あたりのイメージ）。

| 段階                   | 取り分の目安      | なぜそうなるか                                                                           |
| ---------------------- | ----------------- | ---------------------------------------------------------------------------------------- |
| 食品メーカー・ベンダー | 原価側（約700円） | ここから製造原価と物流費が出る。PBは本部が価格を決めるため利幅が薄い                     |
| **本部（チャージ）**   | **約170円**       | 粗利300円の56%（本部が土地建物を出す型の場合）。不動産・物流・システムの固定費を回収する |
| **加盟店（総収入）**   | **約130円**       | ここから人件費・廃棄・消耗品を払う                                                       |
| **オーナーの手取り**   | **約20〜40円**    | 売上の2〜4%。夫婦2人分の労働対価                                                         |

> ポイント：コンビニの利益は **「薄い層が5万枚重なっている」** 構造。
> 1店の利益は小さいが、本部は5万店分のチャージを受け取る。
> だから本部にとっては**店数が、加盟店にとっては自店の日販が**すべてになる。
> この非対称を押さえれば、この業界のニュースの9割は読める。

## 5. 収益モデル・コスト構造

**本部と加盟店で損益構造がまったく違う**ので、必ず分けて見る。

```
【加盟店の損益（日販60万円のモデル）】

  年間売上 2億1,900万円
    ├─ 売上原価（約70%） 1億5,330万円
    └─ 売上総利益（30%）   6,570万円
         ├─ 本部チャージ（56%）  3,679万円 ──▶ 本部へ
         └─ 加盟店総収入          2,891万円
              ├─ 人件費           1,800万円  ← 総収入の62%
              ├─ 廃棄ロス           350万円
              ├─ 棚卸ロス            60万円
              ├─ 水道光熱費          60万円（本部が約8割負担した後の自己負担）
              ├─ 消耗品・雑費       130万円
              └─ オーナー利益      約495万円  ← 夫婦2人分の年収

  損益分岐日販 ≒ 45万円
  日販が10万円増えると、オーナー利益は約336万円増える
```

（筆者の試算モデル。粗利率30%・チャージ率56%・諸経費＝固定1,520万円＋売上の4.0%を仮定。
実際の契約・立地で大きく振れる。詳細は [① 1店舗の経済学](01_1店舗の経済学.md)）

| 主体       | 収益源                                                       | 主なコスト                                                                       | 利益の効きどころ                                                  |
| ---------- | ------------------------------------------------------------ | -------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| **本部**   | ①加盟店からのチャージ、②直営店売上、③商品供給、④広告・その他 | 本部人件費、物流費、システム費、**店舗賃借料**（本部が土地建物を出す型）、広告費 | **店舗数 × 日販 × 粗利率 × チャージ率**。人件費（店舗分）は無関係 |
| **加盟店** | 店頭売上の粗利からチャージを引いた残り                       | **人件費（総収入の6〜7割）**、廃棄ロス、棚卸ロス、消耗品                         | **自店の日販 と 人件費**。この2つしか動かせない                   |

**利益率の目安**

- 本部の利益率は**2つの分母で見え方が変わる**。セブンの国内コンビニ事業は
  2026年2月期に営業利益2,336億円。**チェーン全店売上高（約5兆円規模）に対しては4〜5%**だが、
  **本部の営業収益（1兆円前後）に対しては20%台**になる。
  後者が異様に高いのは、本部が店頭売上ではなくチャージを計上する**フランチャイズ本部業**だから。
  小売同士を比べるときは、必ず**チェーン全店売上高ベース**にそろえる
- 加盟店のオーナー利益：**売上の2〜4%**。小売の店舗としては標準的だが、
  これが夫婦2人分の年収であることを踏まえると薄い

## 6. 競争要因（KSF）と参入障壁

| KSF                          | 中身                                                 | なぜ効くか                                                             |
| ---------------------------- | ---------------------------------------------------- | ---------------------------------------------------------------------- |
| **中食の商品力**             | 弁当・おにぎり・惣菜・カウンターFFの味と新商品の回転 | 粗利率が最も高く、毎日来る理由を作る。ここがそのまま日販差になる       |
| **店舗密度（ドミナント）**   | 特定エリアへの集中出店                               | 1日3便の多頻度配送も、専用工場の建設も、**密度がないと採算に乗らない** |
| **ベンダー網**               | 専用工場の確保と専属性                               | レシピが漏れず、品質が揃う。新エリア進出は工場建設とセット             |
| **立地**                     | 交通量・視認性・駐車場・商圏人口                     | 日販の7割は立地で決まるとも言われる。良い立地はすでに埋まっている      |
| **加盟店（オーナー）の確保** | 独立希望者、複数店経営者、法人加盟                   | **出店余地を実質的に縛る制約**。近年はここが最大のボトルネック         |
| **システムと単品管理**       | POS、発注端末、需要予測                              | 3,000品目を30坪で回すには不可欠                                        |

**参入障壁は許認可ではない**（コンビニに特別な免許は不要。たばこ・酒類は個別に免許が要る）。
障壁の実体は **「密度 → 物流 → 工場 → 商品力 → 日販 → さらに密度」という自己強化ループ**。
新規参入者がこのループの外側から入ろうとすると、
**店が少ないので物流が高く、工場が建たず、商品力が出ず、日販が上がらない**。
だから日本では1990年代以降、大手3社の外から新たな全国チェーンは生まれていない。

例外はセイコーマート（北海道）で、**自社で工場・物流・農場まで垂直統合し、
地域に密度を作る**ことで別のループを成立させている。

## 7. 規制・法制度

| 制度                                                             | 内容                                                                                                               | コンビニへの効き方                                                 |
| ---------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------ |
| **中小小売商業振興法**                                           | FC本部に、加盟契約前の**法定開示書面**の交付を義務づけ。ロイヤリティの算定方法・契約期間・解約条件の開示           | 加盟条件を比較する根拠。数値の裏取りはここを見る                   |
| **独占禁止法（優越的地位の濫用）／フランチャイズ・ガイドライン** | 本部が取引上の強い立場を背景に加盟店へ不利益を押しつけることを規制                                                 | 24時間営業の強制、必要以上の仕入数量の強制、見切り販売の制限が対象 |
| **公正取引委員会 コンビニ実態調査（2020年9月公表）**             | 全国57,524店を対象にした初の大規模調査。意に反した仕入が「ある」51.1%、必要以上の数量を強要された経験「ある」47.5% | 各社が時短制度・値引き方針を見直す契機になった                     |
| **経産省「新たなコンビニのあり方検討会」報告書（2020年2月）**    | 本部と加盟店の好循環が「目詰まりした」と指摘し、加盟店優先・オーナー重視でのモデル再構築を提言                     | 各社の自主行動計画につながった                                     |
| **最低賃金法**                                                   | 毎年の引き上げ。全国加重平均で年3〜5%の上昇が続く                                                                  | 加盟店の人件費に直撃。**業界最大の構造リスク**                     |
| **働き方改革関連法（2024年問題）／改正物流効率化法**             | トラックドライバーの時間外労働上限、荷主への物流効率化義務                                                         | **1日3便という配送前提が揺らぐ**。便数削減・共同配送の見直し       |
| **食品ロス削減推進法／食品リサイクル法**                         | 食品ロスの削減、再生利用の推進                                                                                     | 見切り販売・フードドネーション・AI発注の後押し                     |
| **食品衛生法・HACCP／食品表示法**                                | 衛生管理、期限表示                                                                                                 | ベンダーと店内調理の管理コスト                                     |
| **たばこ事業法・酒税法（免許）／風営法（深夜）**                 | 販売免許、深夜営業の扱い                                                                                           | 店舗ごとの免許取得が必要。たばこ免許は日販に直結                   |

   本部主導で見切り販売を推奨する方針に転じたと報じられる。長年の対立が緩和の方向へ。

## 9. 用語メモ

各ノートの末尾に詳しい用語メモがある。ここでは最重要の6つだけ。

| 用語                         | 意味                                                                                                                                                         |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **日販（にっぱん）**         | 1店舗が1日に売り上げる金額。コンビニで最も重要な指標。損益がここから機械的に決まる → [①](01_1店舗の経済学.md)                                                |
| **ロイヤリティ（チャージ）** | 加盟店が本部に払う対価。コンビニでは**売上ではなく粗利に率をかける「粗利分配方式」**。土地建物を誰が出すかで40〜76%と大きく変わる → [①](01_1店舗の経済学.md) |
| **コンビニ会計**             | 廃棄・棚卸ロスを売上原価に含めず加盟店の経費として別建てにする会計方式。結果として**廃棄原価にもチャージが乗る** → [①](01_1店舗の経済学.md)                  |
| **ドミナント出店**           | 特定地域に集中出店してシェアを取る戦略。物流・広告・指導の効率が上がる一方、既存加盟店とのカニバリ（共食い）を生む → [②](02_フランチャイズという仕組み.md)   |
| **ベンダー**                 | コンビニ本部の中食を作る専用工場。1チェーン専属で他チェーンには納めない。新エリア進出は工場建設とセット → [③](03_商品と物流.md)                              |
| **中食（なかしょく）**       | 調理済みのものを買って帰って食べる形態。弁当・おにぎり・惣菜。**粗利率30〜40%台でコンビニの粗利の主力** → [③](03_商品と物流.md)                              |
