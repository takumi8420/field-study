このフォルダの読み方

コンビニは 「30坪の店を5万軒つくり、その1軒ごとの日販を最大化する装置」である。
売上も利益も、日販（1日あたり売上高） というたった1つの数字から機械的に決まる。
粗利率は約30%でほぼ固定、本部チャージ率は契約で固定、家賃と設備は多くの型で本部持ち。
だから動かせる変数は実質「日販」と「人件費」の2つだけしかない。

そして、この業界を他の小売と分けている最大の特徴は
店を経営しているのが本部ではなく加盟店だということ。
本部は不動産・物流・システム・商品開発・ブランドを提供し、粗利の40〜60%台を受け取る。
この分配の非対称が、24時間営業・見切り販売・ドミナント出店をめぐる対立の根にある。

本フォルダは小売分類の最初のノートなので、①で「1店舗の経済性」を丁寧に扱った。
後続の小売業（スーパー、食品スーパー、ドラッグストア等）は、この読み方を土台にしている。

ノート 内容
① 1店舗の経済学日販がすべての起点。日販→粗利→チャージ→経費→オーナー手取りの計算、損益分岐日販45万円、粗利率30%の内訳（たばこが日販を押し上げ粗利を押し上げない理由）、ロイヤリティの計算方法、コンビニ会計と廃棄ロス、人件費が総収入の6〜7割という急所、なぜ24時間営業だったのか
② フランチャイズという仕組み本部は「店」でなく「店を経営する仕組み」を貸している。本部が出す5つのもの、直営とFCの違い、契約タイプ（誰が土地建物を出すか）、ドミナント出店とカニバリゼーション、3つの対立（24時間・見切り販売・仕入数量）を構造として読む、公取委2020年調査と経産省報告書
③ 商品と物流日販の源泉は中食（弁当・おにぎり・惣菜）。商品別の粗利率、ベンダー（専用工場）の専属性、温度帯別の共同配送と1日3便（納品トラックを70台→9台に）、PB＝セブンプレミアム1兆5,000億円の意味、発注は加盟店が行う＝単品管理とPOS、廃棄ロスと食品ロス対策の推移
④ 市場の成熟と次の一手店舗数の頭打ち（大手3社で約5万1,700店）、既存店＝客数×客単価の分解、高齢化と食品スーパー化、収納代行・ATM・行政サービス・リテールメディアという店舗以外の収益、ネットコンビニと宅配の採算、海外（北米型とアジア型はまったく違うゲーム）
⑤ 直近トピック（2026年9月時点）ローソン・ファミマが最高益でセブンが国内減益という逆転、客単価12年連続増／客数4年ぶり減、最低賃金と加盟店モデル、北米IPOの2027年度以降への延期、本部主導の値引きへの転換、時短営業は「選べるが選ばれない」

1. 業界の定義・範囲

コンビニエンスストア ＝ 売場面積30坪前後、年中無休・長時間営業、
食品を中心に約3,000品目を扱う小型小売店。
経済産業省の商業動態統計では「飲食料品を扱い、セルフサービス方式で、
売場面積30平方メートル以上250平方メートル未満、営業時間が1日14時間以上」の店舗を指す。

【コンビニの位置（売場面積 × 品揃え）】

  売場面積
   大 ┤   [GMS]        [ホームセンター]
      │      [食品スーパー]
      │         [ドラッグストア]
      │            [小型食品スーパー]
      │               ★コンビニ★  ← 30坪・3,000品目
   小 ┤          [キオスク・自販機]
      └────────────────────────────▶
        少                          多   品揃え

  隣接するが別扱いのもの：
   ・小型食品スーパー（まいばすけっと等）… 価格が安く、生鮮が中心 → 03_食品スーパー
   ・ミニスーパー／ローソンストア100      … 100円均一中心。コンビニの派生業態
   ・駅ナカ売店（キヨスク等）             … 面積が小さく、FCでない
   ・ガソリンスタンド併設店（北米型）     … 燃料が主、売店は従

境界の引き方で押さえるべき点は3つ。

  • 「便利さ」を売る業態であって、「安さ」も「品揃え」も売っていない。
    定価販売が基本で、品目数はスーパーの10分の1以下。それでも成立するのは
    近さ・営業時間・待たないことに対価が払われているから
  • フランチャイズが前提。日本のコンビニは加盟店が9割超で、
    「小売業」であると同時に「フランチャイズ本部業」という性格を持つ
  • 本部は小売にとどまらない。商品企画では実質メーカー、
    配送設計ではオペレーター、決済・収納代行では金融の窓口を兼ねている

成長性の読み方。

  • 名目は伸びている／人は減っている。売上の伸びは客単価（＝値上げと買上点数）が作っており、
    来店客数は減少に転じた。物価上昇が落ち着けば、この伸びは止まる
  • 店舗数はほぼ飽和。2018〜2019年ごろに伸びが止まり、以後は横ばい〜微増。
    2025年の増加は、コロナ禍で止まっていた建て替え・移転・不採算店整理の一巡と読むのが自然
  • 成長エンジンは3つに分散した。①既存店の日販（客数を戻す）、
    ②店舗以外の収益（リテールメディア・金融・行政サービス）、③海外

ポイント：コンビニの利益は 「薄い層が5万枚重なっている」 構造。
1店の利益は小さいが、本部は5万店分のチャージを受け取る。
だから本部にとっては店数が、加盟店にとっては自店の日販がすべてになる。
この非対称を押さえれば、この業界のニュースの9割は読める。

主体 収益源 主なコスト 利益の効きどころ
本部①加盟店からのチャージ、②直営店売上、③商品供給、④広告・その他本部人件費、物流費、システム費、店舗賃借料（本部が土地建物を出す型）、広告費店舗数 × 日販 × 粗利率 × チャージ率。人件費（店舗分）は無関係
加盟店店頭売上の粗利からチャージを引いた残り人件費（総収入の6〜7割）、廃棄ロス、棚卸ロス、消耗品自店の日販 と 人件費。この2つしか動かせない

利益率の目安

  • 本部の利益率は2つの分母で見え方が変わる。セブンの国内コンビニ事業は
    2026年2月期に営業利益2,336億円。チェーン全店売上高（約5兆円規模）に対しては4〜5%だが、
    本部の営業収益（1兆円前後）に対しては20%台になる。
    後者が異様に高いのは、本部が店頭売上ではなくチャージを計上するフランチャイズ本部業だから。
    小売同士を比べるときは、必ずチェーン全店売上高ベースにそろえる
  • 加盟店のオーナー利益：売上の2〜4%。小売の店舗としては標準的だが、
    これが夫婦2人分の年収であることを踏まえると薄い

6. 競争要因（KSF）と参入障壁

KSF 中身 なぜ効くか
中食の商品力弁当・おにぎり・惣菜・カウンターFFの味と新商品の回転粗利率が最も高く、毎日来る理由を作る。ここがそのまま日販差になる
店舗密度（ドミナント）特定エリアへの集中出店1日3便の多頻度配送も、専用工場の建設も、密度がないと採算に乗らない
ベンダー網専用工場の確保と専属性レシピが漏れず、品質が揃う。新エリア進出は工場建設とセット
立地交通量・視認性・駐車場・商圏人口日販の7割は立地で決まるとも言われる。良い立地はすでに埋まっている
加盟店（オーナー）の確保独立希望者、複数店経営者、法人加盟出店余地を実質的に縛る制約。近年はここが最大のボトルネック
システムと単品管理POS、発注端末、需要予測3,000品目を30坪で回すには不可欠

参入障壁は許認可ではない（コンビニに特別な免許は不要。たばこ・酒類は個別に免許が要る）。
障壁の実体は 「密度 → 物流 → 工場 → 商品力 → 日販 → さらに密度」という自己強化ループ。
新規参入者がこのループの外側から入ろうとすると、
店が少ないので物流が高く、工場が建たず、商品力が出ず、日販が上がらない。
だから日本では1990年代以降、大手3社の外から新たな全国チェーンは生まれていない。

例外はセイコーマート（北海道）で、自社で工場・物流・農場まで垂直統合し、
地域に密度を作ることで別のループを成立させている。

9. 用語メモ

各ノートの末尾に詳しい用語メモがある。ここでは最重要の6つだけ。

用語 意味
日販（にっぱん）1店舗が1日に売り上げる金額。コンビニで最も重要な指標。損益がここから機械的に決まる → ①
ロイヤリティ（チャージ）加盟店が本部に払う対価。コンビニでは売上ではなく粗利に率をかける「粗利分配方式」。土地建物を誰が出すかで40〜76%と大きく変わる → ①
コンビニ会計廃棄・棚卸ロスを売上原価に含めず加盟店の経費として別建てにする会計方式。結果として廃棄原価にもチャージが乗る → ①
ドミナント出店特定地域に集中出店してシェアを取る戦略。物流・広告・指導の効率が上がる一方、既存加盟店とのカニバリ（共食い）を生む → ②
ベンダーコンビニ本部の中食を作る専用工場。1チェーン専属で他チェーンには納めない。新エリア進出は工場建設とセット → ③
中食（なかしょく）調理済みのものを買って帰って食べる形態。弁当・おにぎり・惣菜。粗利率30〜40%台でコンビニの粗利の主力 → ③
