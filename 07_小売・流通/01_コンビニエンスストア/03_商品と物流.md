# ③ 商品と物流 — 日販の源泉は中食にある

このノートで分かること：コンビニの30坪の棚に何が並び、どこから来て、誰が発注しているのか。
なぜ**弁当・おにぎり・惣菜（中食）**が勝負どころなのか。
1日3便という常識外れの配送がなぜ成立し、その裏で**食品ロス**がなぜ生まれ続けるのか。

> 結論：コンビニの競争は**「中食（なかしょく）」の一点で決まる**。
> 中食は粗利率が高く、毎日来店する理由を作り、他チェーンが真似しにくい。
> ただし中食は日持ちしないので、**1日3便の多頻度配送**と**専用工場（ベンダー）**という
> 重い仕掛けが要る。そしてこの仕掛けの代償が**廃棄ロス**である。
> 中食・物流・廃棄は、**同じ1つの設計から出てくる3つの顔**。

---

## 1. 中食とは何か、なぜ中心なのか

**中食（なかしょく）＝ 家で作る「内食」でも、店で食べる「外食」でもない、
調理済みのものを買って帰って食べる形態**。弁当、おにぎり、サンドイッチ、惣菜、サラダ、麺類。

コンビニにとって中食が中心になる理由は4つ。

| 理由                   | 中身                                                                |
| ---------------------- | ------------------------------------------------------------------- |
| **粗利率が高い**       | 中食は30〜40%台。加工食品（25〜30%）やたばこ（約10%）より厚い       |
| **毎日来る理由になる** | 洗剤は月1回しか買わないが、昼食は毎日要る。**来店頻度＝日販**の源泉 |
| **模倣が難しい**       | 専用工場・専用レシピ・毎日3便の物流が要る。資本と時間がかかる       |
| **ついで買いを呼ぶ**   | 弁当を買う客は飲料とデザートも買う。**客単価**が上がる              |

```
【30坪の棚に何が並ぶか（売上構成比の目安）】

  たばこ            ████████████░░░░░░  20〜25%   粗利率 約10%
  中食（日配食品）  ██████████████░░░░  25〜30%   粗利率 30〜40%  ← 主戦場
  加工食品          ████████████░░░░░░  20〜25%   粗利率 25〜30%
  飲料              █████████░░░░░░░░░  15〜20%   粗利率 25〜30%
  カウンターFF      ████░░░░░░░░░░░░░░   5〜10%   粗利率 40〜60%  ← 最も厚い
  非食品            ████░░░░░░░░░░░░░░   5〜10%   粗利率 20〜40%

  （各社IR資料と業界解説をもとにした概算。立地で大きく振れる）
```

> ポイント：**たばこは日販を押し上げるが粗利をほとんど押し上げない**。
> 売上構成比で中食と並ぶのに、粗利への貢献は3分の1以下。
> だから「たばこの多い店」と「中食の多い店」では、同じ日販でもオーナーの手取りが
> まったく違う（→ [① 1店舗の経済学](01_1店舗の経済学.md)）。
> 本部が中食とカウンターFFを執拗に押すのは、ここに粗利があるから。

## 2. 商品はどこから来るのか — 3つのルート

コンビニの商品は、すべて同じ経路で来るわけではない。**3つの違うルート**がある。

```
【商品の3ルート】

■ ルートA：専用工場（ベンダー）から来る  ← 中食・カウンターFF
   本部が商品を企画・設計
        ↓ レシピ・原材料の指定
   専用工場（ベンダー） ── チェーン専属。他チェーンには納めない
        ↓ 1日2〜3回の製造
   共同配送センター（米飯20℃帯）
        ↓ 1日3便
   店舗

■ ルートB：メーカー → 卸 → 共同配送センター  ← 加工食品・飲料・日用品
   食品メーカー（味の素、カルビー等）
        ↓
   食品卸（日本アクセス、三菱食品、国分等） ← 本部が指定する
        ↓
   共同配送センター（常温帯・冷凍帯）
        ↓ 週数回〜1日1便
   店舗

■ ルートC：直接搬入  ← 雑誌、たばこ、一部の地域商材
   取次・専売所などが直接店舗へ
```

**ルートAが競争力の源泉**で、ルートBは各社ほぼ同じ（同じメーカーの同じ商品）。
だから「どのコンビニでも買えるもの」と「そこでしか買えないもの」が
きれいに分かれる。

### ベンダーとは

**ベンダー（vendor）＝ コンビニ本部の商品を作る専用の製造委託先**。
コンビニ業界では特に**中食を作る専用工場**を指すことが多い。

| 特徴             | 内容                                                                                                   |
| ---------------- | ------------------------------------------------------------------------------------------------------ |
| **専属性**       | 1つのチェーン専属で、他チェーンには納めない。レシピが漏れない                                          |
| **立地**         | 店舗から2時間以内など、配送時間で立地が決まる。**ドミナント出店とセット**で建つ                        |
| **共同組織**     | セブン-イレブンは「日本デリカフーズ協同組合（NDF）」という専用工場の協同組合を持つ                     |
| **代表企業**     | わらべや日洋ホールディングス（セブン向け中心）、武蔵野（セブン向け）、プライムデリカ（セブン向け）など |
| **本部との関係** | 本部が商品を設計し、原材料の調達先まで指定することが多い。ベンダーは製造と品質管理を担う               |

> ポイント：ベンダーは「下請け工場」ではなく、**チェーンの生産設備そのもの**。
> 本部の資産ではないのに、本部の戦略に完全に従属している。
> だから、あるチェーンが新しい県に進出するときは、
> **先に工場を建てられるだけの店舗数を見込めるか**が出店可否を決める。
> セブンが沖縄進出に2019年までかかったのは、この工場の問題が大きい。

## 3. 共同配送と1日3便

**共同配送 ＝ 複数のメーカーの商品を、温度帯ごとに1台のトラックにまとめて運ぶ仕組み**。

コンビニが生まれた1970年代、店舗には**1日70台以上のトラックが来ていた**とされる。
メーカーごとに別々のトラックが来るからである。30坪の店に70台。荷受けだけで一日が終わる。

```
【共同配送の前と後】

■ 1970年代（メーカー別配送）
   パン屋 ─┐
   牛乳屋 ─┤
   菓子屋 ─┼──▶ 店舗   1日 70台以上
   飲料屋 ─┤           荷受けで店が回らない
   ...    ─┘

■ 現在（温度帯別の共同配送）
   複数メーカー ─▶ 共同配送センター ─▶ 店舗   1日 9台程度
                    ↓ 温度帯ごとに仕分け
                  ┌─ 米飯   約20℃  1日3便（朝・昼・夜）
                  ├─ チルド   5℃   1日2〜3便
                  ├─ 常温    常温   1日1便〜週数便
                  └─ 冷凍   −20℃   週3〜7便
```

### なぜ温度帯で分けるのか

弁当・おにぎりの米は、**冷やすとデンプンが老化して固くなる**。だから米飯は
**5℃ではなく20℃前後**で運ぶ。一方でサラダやチルド惣菜は5℃、アイスは−20℃。
**同じトラックに混ぜられない**ので、温度帯ごとに別の車両・別の便になる。
これが「1日に何便も来る」ことの技術的な理由。

### なぜ1日3便なのか

| 便     | 主な商品                         | 狙い                                       |
| ------ | -------------------------------- | ------------------------------------------ |
| 早朝便 | 朝食向けのおにぎり・サンドイッチ | 通勤前の客に、できたてを出す               |
| 昼便   | 昼食向けの弁当・麺               | 昼のピークに合わせる                       |
| 夕便   | 夕食・夜食向けの弁当・惣菜       | 夕方以降の客に、朝の残りではないものを出す |

**1日3便でないと成立しないこと**が2つある。

- **鮮度**：消費期限が製造から十数時間という商品を、常に「できたて」に保てる
- **在庫の薄さ**：30坪の店にはバックヤードがほとんどない。
  **店が倉庫を持たない代わりに、トラックが走る倉庫になっている**

そして1日3便は、**店舗が密集していないと成立しない**。
1台のトラックが1日に何度も回るには、短い距離に多くの店がなければならない。
**ドミナント出店 → 多頻度配送 → 中食の鮮度 → 日販**、という連鎖ができている
（→ [② フランチャイズという仕組み](02_フランチャイズという仕組み.md) 第5章）。

物流側の事情は [陸運・トラック](../../13_運輸・物流/06_陸運・トラック/README.md) と
[倉庫・3PL](../../13_運輸・物流/08_倉庫・3PL/README.md)、
卸側の事情は [食品卸](../../06_商社・卸売/06_食品卸/README.md) を参照。
2024年問題（トラックドライバーの時間外労働上限）は、
**この1日3便という前提そのものに効く**ので、業界の中期の最大リスクの1つになっている。

## 4. PB（プライベートブランド）— セブンプレミアムの意味

**PB（プライベートブランド）＝ 小売が自ら企画し、自社ブランドで売る商品**。
対語は **NB（ナショナルブランド）**＝メーカーのブランドで売る商品。

|          | NB                         | PB                                     |
| -------- | -------------------------- | -------------------------------------- |
| 企画     | メーカー                   | **小売（本部）**                       |
| ブランド | メーカー名                 | **小売名（セブンプレミアム等）**       |
| 製造     | メーカー                   | メーカーに委託（多くは大手NBメーカー） |
| 価格決定 | メーカー希望小売価格が基準 | **小売が決められる**                   |
| 粗利率   | 標準                       | **数ポイント高い**                     |
| 広告費   | メーカー負担               | 小売の棚がそのまま広告になる           |

### セブンプレミアムの規模

| 指標                     | 数値                                             | 年・出典                     |
| ------------------------ | ------------------------------------------------ | ---------------------------- |
| 年間売上金額             | **1兆5,000億円**超（前年比 +3.4%）で初の大台     | 2024年度。セブン&アイHD 発表 |
| アイテム数               | 3,460品目                                        | 2024年度末。同上             |
| 年間販売10億円以上の商品 | **315アイテム**                                  | 2024年度末。同上             |
| 累計売上金額             | 15兆円突破                                       | 2024年5月時点。同上          |
| 2025年度の計画           | 売上1兆5,500億円、3,550アイテム、1,800品目を刷新 | 会社計画                     |

> ポイント：**1兆5,000億円は、日本の食品メーカー大手の売上を単独で超える規模**。
> つまりセブン&アイは、小売でありながら日本有数の「食品ブランド」を持っている。
> しかも工場を持たずに。PBの本質は**「工場を持たずにメーカーになる」**ことにある。

PBが小売にとって重要な理由は3つ。

- **粗利が厚い**：中間マージンがなく、価格も自分で決められる
- **他チェーンにない**：同じNB商品を売っている限り、価格でしか差がつかない
- **値上げ局面で武器になる**：NBが値上げするとき、PBを据え置けば客が移ってくる。
  2020年代の物価上昇局面で、PBの存在感が一段と増した

一方で、**PBはメーカーとの関係を難しくする**。PBを作るのは大手NBメーカー自身であることが多く、
自社のNB商品と競合する。この緊張関係は [総合食品](../../08_食品・農水産・外食/01_総合食品/README.md)
や [食品卸](../../06_商社・卸売/06_食品卸/README.md) の側から見ると、より鮮明に見える。

## 5. 発注は誰がするのか — 単品管理とPOS

**コンビニで発注するのは本部ではなく、加盟店（店舗）である。** これは制度の根幹。

```
【仮説検証型発注のサイクル】

   POSデータ           ①何が、いつ、誰に売れたか
   （単品ごと）          を単品単位で記録
        │
        ▼
   仮説を立てる        ②「明日は雨・金曜・近所で運動会中止
                          → おにぎりは減る、麺は増える」
        │
        ▼
   発注する            ③発注端末で数量を入力（加盟店の判断）
        │
        ▼
   結果を見る          ④売れ残ったか、品切れたか
        │
        └──────────▶ 次の仮説へ

   ※ この一周が「単品管理」。1店で扱う約3,000品目のうち、
     日々の判断が要るのは中食・FFを中心に数百品目。
```

**POS（Point of Sale＝販売時点情報管理）** は1980年代にセブン-イレブンが全店導入し、
日本の小売を変えた仕組み。「レジで何が売れたか」を単品単位で記録し、
発注と商品開発に使う。年間で売れない商品を棚から外す**死に筋排除**もここから来る。

**なぜ本部ではなく店が発注するのか。** 理由は2つ。

- **情報が現場にしかない**：近所の学校行事、工事、天気、常連客の顔。データに出ない需要
- **契約の建て付け**：発注は加盟店の経営判断であり、だからこそ廃棄も加盟店が負う
  （→ [① 1店舗の経済学](01_1店舗の経済学.md) 第6章）

そして本部側は **OFC（経営相談員）** が週2回ほど巡回し、発注を助言する。
ここが第2ノートで見た「推奨発注」の論点につながる。
**発注権を加盟店に置くという建て付けと、本部が実質的に数量を左右する実務**のあいだの
ズレが、公正取引委員会の指摘（意に反した仕入が「ある」51.1%、2020年9月公表）を生んだ。

## 6. 廃棄ロスと食品ロス

### なぜ廃棄が出るのか

中食モデルの必然として出る。理由は3つ。

| 理由                             | 中身                                                                                                                           |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **品切れが最大の罪とされてきた** | 棚が空だと客は次回から来ない。**機会損失**はデータに残らないが、廃棄は数字に残る。それでも本部は「欠品を出すな」と指導してきた |
| **消費期限が極端に短い**         | 弁当・おにぎりは製造から十数時間〜1日。売れ残りは翌日に回せない                                                                |
| **需要が読めない**               | 天気、曜日、イベント、近隣の工事。1店の1日の弁当販売はせいぜい数十個で、統計的なばらつきが大きい                               |

### 数字で見る

| 指標                       | 数値                                                  | 年・出典                                 |
| -------------------------- | ----------------------------------------------------- | ---------------------------------------- |
| 日本全体の食品ロス量       | 約 **464万トン**                                      | 2023年度。消費者庁・環境省・農水省の推計 |
| ローソンの食品ロス削減目標 | 2018年比で 2025年に **25%削減**、2030年に **50%削減** | 会社公表                                 |

コンビニ1店の廃棄は、日販60万円の店で**年間300万〜500万円（原価ベース）**の規模になる
（[① 1店舗の経済学](01_1店舗の経済学.md)のモデル）。
これは**オーナー利益とほぼ同じ桁**であり、廃棄をどう扱うかが経営そのものになる。

### 対策の流れ

```
【食品ロス対策の推移】

 〜2010年代前半   見切り販売は事実上抑制される
                   ↓ 公取委の指摘（見切り制限は独禁法上問題となりうる）
 2009年ごろ       本部が廃棄ロス原価の15%程度を負担する制度を導入
                   ↓
 2019年〜         セブン「エシカルプロジェクト」（期限間近の商品に
                   nanacoポイント還元）／ローソン「てまえどり」
                   ＝ 値引きではなくポイントで実質値引きする形
                   ↓
 2024年〜         セブン-イレブンが本部主導で値引き（見切り）を推奨する
                   方針に転換したと報じられる。値引きシールを本部が標準化
                   ↓
 現在             フードバンクへの寄贈、AI需要予測、包装技術による
                   賞味期限延長、発注単位の細分化が並行して進む
```

**ポイント還元という形が長く使われた理由**は、
「定価は崩さないが、実質的な負担を下げる」という折衷だったから。
定価を崩すと「夕方に行けば安い」という行動が定着し、チェーン全体の粗利率が下がる。
一方、ポイント還元なら値札は動かない。
ただしポイント原資は本部が持つため、本部のコストになる。

2024年以降、本部が値引きそのものを推奨する方向に転じたのは、
**食品ロス削減という社会的要請と、加盟店の収益悪化という経営課題が同じ方向を向いた**から。
これは第2ノートで見た対立②が、環境要因によって解けつつある例と読める。

## 7. 新しい商品の方向 — 店が厨房と冷凍庫を持ち始めた

2020年代に入って、中食の中身が変わりつつある。

| 方向                 | 内容                                           | 狙い                                                                       |
| -------------------- | ---------------------------------------------- | -------------------------------------------------------------------------- |
| **店内調理**         | 焼きたてパン、店内で揚げる惣菜、コーヒーマシン | 廃棄を減らしつつ、できたて感を出す。**売れた分だけ作る**ので歩留まりがよい |
| **冷凍食品の拡大**   | 冷凍弁当・冷凍麺・冷凍惣菜の売場を拡大         | **廃棄がほぼ出ない**。単身世帯・高齢世帯の備蓄需要にも合う                 |
| **生鮮・日配の強化** | カット野菜、少量パックの肉・魚、豆腐、牛乳     | 近所のスーパーが減った地域での「小型スーパー化」                           |
| **少量・高価格帯**   | 高価格の惣菜、こだわり素材のPB                 | 客数が減るなかで客単価を上げる                                             |

**冷凍食品の拡大が構造的に効く**点を押さえておきたい。
冷凍は**賞味期限が長く廃棄が出ない**ので、廃棄ロスという最大の経費が消える。
その代わり冷凍ケースは電気代が重く、売場面積も取る。
つまり **「廃棄ロス vs 水道光熱費・売場効率」のトレードオフ**であり、
人件費と廃棄が高騰している現在は、冷凍側に振れる合理性がある。

## 8. 商流全体のなかでのコンビニの位置

```
【コンビニを中心に見た商流】

  原料・農水産 ──▶ 食品メーカー ──┬──▶ 食品卸 ──┐
                    （NB）         │              │
                                    │              ├──▶ 共同配送センター ──▶ コンビニ ──▶ 消費者
                    （PBを受託製造）│              │      （温度帯別）
                                    └──▶ ベンダー ┘
                                       （専用工場）
                                         ▲
                                         │ レシピ・原材料・数量を指定
                                    コンビニ本部（商品開発）

  ※ 本部は「小売」でありながら、商品企画では実質メーカー、
    物流設計ではオペレーターとして、商流の上流まで手を伸ばしている
```

この図から読める、コンビニ業界の特徴的な立ち位置。

- **本部は卸にとって最大級の顧客**であり、同時に**最も厳しい顧客**。
  1日3便・温度帯別・欠品ゼロという要求は、卸の物流コストを押し上げる
  （→ [食品卸](../../06_商社・卸売/06_食品卸/README.md)）
- **本部はメーカーにとって、販路でありながら競合**。PBを作らせつつ、NBの棚を削る
  （→ [総合食品](../../08_食品・農水産・外食/01_総合食品/README.md)、
  [冷凍食品・惣菜](../../08_食品・農水産・外食/06_冷凍食品・惣菜/README.md)）
- **中食市場そのものの主要プレイヤー**。
  惣菜・弁当の市場は[中食・弁当](../../08_食品・農水産・外食/20_中食・弁当/README.md)を参照

## 用語メモ

| 用語                                 | 意味                                                                                                                    |
| ------------------------------------ | ----------------------------------------------------------------------------------------------------------------------- |
| **中食（なかしょく）**               | 調理済みのものを買って帰って食べる形態。弁当・おにぎり・惣菜。内食（家庭調理）と外食の中間。コンビニの粗利の主力        |
| **ベンダー**                         | コンビニ本部の商品を作る専用の製造委託先。特に中食の専用工場。1チェーン専属で他チェーンには納めない                     |
| **共同配送**                         | 複数メーカーの商品を温度帯ごとに1台のトラックにまとめて運ぶ仕組み。店舗への納品トラックを1日70台超から9台程度に減らした |
| **温度帯**                           | 米飯（約20℃）、チルド（5℃）、常温、冷凍（−20℃）の4区分。混載できないため便が分かれる                                    |
| **PB（プライベートブランド）**       | 小売が企画し自社ブランドで売る商品。セブンプレミアム、ローソンセレクト、ファミマル等                                    |
| **NB（ナショナルブランド）**         | メーカーのブランドで売る商品。どのチェーンでも買える                                                                    |
| **POS（販売時点情報管理）**          | レジで何がいつ売れたかを単品単位で記録する仕組み。発注と商品開発の基礎                                                  |
| **単品管理**                         | 商品を分類単位ではなく1品ごとに管理し、仮説→発注→検証を回す手法。セブン-イレブンが確立した                              |
| **死に筋排除**                       | 売れない商品を棚から外すこと。30坪という限られた棚を回転させるための基本動作                                            |
| **機会損失（欠品）**                 | 品切れで売れたはずのものが売れないこと。データに残らないため軽視されやすいが、廃棄より重いとされてきた                  |
| **カウンターFF**                     | レジ横の調理商材（揚げ物・おでん・コーヒー）。Fast Food の略                                                            |
| **エシカルプロジェクト／てまえどり** | 期限の近い商品を買う客にポイントを還元したり、手前の商品から取るよう促す食品ロス対策                                    |
