このノートで分かること：日本のコンビニがなぜ店舗数を増やせなくなったのか、
そのなかで各社が既存店の日販をどう上げようとしているのか。
そして店舗以外の収益（金融・収納代行・行政サービス）と海外展開が、
成熟した本業の外側でどんな役割を担っているのか。

結論：コンビニの成長エンジンは 「店を増やす」→「1店の売上を上げる」 に切り替わった。
ところが1店の売上を分解すると 客数 × 客単価 で、
客数はすでに減り始めており、伸びているのは客単価＝値上げの分だけ。
だから各社は ①客数を戻す手（生鮮・冷凍・宅配）、②店舗以外の収益（金融・行政）、
③海外、の3方向に同時に手を伸ばしている。

止まった理由は4つあり、どれか1つではなく重なって効いている。

理由 中身
①良い立地が尽きたコンビニの立地条件（交通量・視認性・駐車場・商圏人口）を満たす場所は有限。すでに主要な場所は埋まっている
②オーナーが集まらない夫婦2人・単店で年収500万円前後、24時間シフトの穴埋め付き（→ ① 1店舗の経済学）。この条件で独立したい人が減った
③ドミナントの副作用が見えた出せば出すほど既存店の日販が落ち、加盟店との関係が悪化する（→ ② フランチャイズという仕組み）
④人口が減る商圏人口3,000人で成立する業態は、人口減少の影響をまともに受ける

ただし2025年は、商業動態統計ベースで店舗数が4年ぶりに増加した。
これは「再び拡大局面に入った」というより、コロナ禍で止めていた建て替え・移転・
不採算店整理が一巡し、新しい立地への出し直しが動いた結果と読むのが自然。

2. 既存店をどう伸ばすか — 客数 × 客単価に分解する

小売の既存店売上は、必ず 客数 × 客単価 に分解して読む。
これは業種を問わず使える基本の分解で、コンビニではとくに効く。

【既存店売上の分解】

  既存店売上 = 客 数 × 客単価
                │        │
                │        ├─ 1品単価（値上げ・高価格帯へのシフト）
                │        └─ 買上点数（ついで買いの誘発）
                │
                ├─ 来店頻度（週に何回来るか）
                └─ 商圏人口 × 自店シェア

直近の数字（日本フランチャイズチェーン協会、2025年1〜12月 年間集計）

指標 前年比 意味
既存店売上高+1.9%（5年連続プラス）見た目は好調
年間平均客単価+2.4%（12年連続で伸長）値上げと買上点数で押し上げ
年間来店客数▲0.5%（4年ぶりのマイナス）ここが問題

ポイント：売上が伸びているのは値段が上がっているからで、
来る人はむしろ減っている。これが2020年代後半のコンビニ業界を貫く一行。
客単価の上昇は物価上昇と表裏一体なので、物価が落ち着けば売上の伸びは止まる。
だから各社は「客数を戻す」ことに本気で取り組まざるを得ない。

客数が減っている理由

要因 中身
節約志向物価上昇で「コンビニは高い」という意識が戻った。昼食を弁当持参やスーパーに切り替える動き
小型食品スーパーの台頭まいばすけっとなど都市型の小型スーパー、ドラッグストアの食品強化が、コンビニの商圏に直接入ってきた
人口減・高齢化単純に商圏人口が減る。高齢層はコンビニの主力客層ではなかった
たばこ需要の減少たばこ目的の来店が減ると、ついで買いも消える。売上構成比20〜25%の商材なので効きが大きい

3社の打ち手が分かれた

2026年2月期の決算では、ローソンとファミリーマートが既存店客数をプラスにした一方、
セブン-イレブンは客足が伸び悩んだと報じられた。

チェーン 直近の方向性 効いたこと／課題
ローソン増量企画・値頃感の訴求。「盛りすぎチャレンジ」など量で訴える販促インフレ下の節約志向に刺さり、客数がプラス。全店平均日販59.8万円で過去最高
ファミリーマートPB「ファミマル」、アパレル「コンビニエンスウェア」、店舗メディア「ファミリーマートビジョン」事業利益+17.9%で過去最高。日商58.5万円
セブン-イレブン品質・商品力重視。焼きたてパン、7NOW（宅配）、大型店フォーマット日販は依然トップの約69.9万円だが、客数が伸び悩み、国内コンビニ事業は減益

ポイント：日販トップのセブンが客数で苦戦しているのが2026年の特徴的な構図。
「高品質・高価格」という強みが、節約志向の局面では逆風になりうる。
逆にローソン・ファミマは「量」と「値頃感」で客数を取りに行って成果を出した。
小売は景気局面によって勝ち筋が入れ替わるという典型例。

3. 高齢化と「食品スーパー化」

コンビニの主力客層はもともと 20〜30代の男性単身者 だった。
今は客層が高齢側にずれており、それに合わせて売場が変わりつつある。

変化 具体的に何をしているか 狙い
生鮮の導入カット野菜、少量パックの肉・魚、豆腐、卵、牛乳近所のスーパーが撤退した地域で、日常の買い物先になる
冷凍食品の拡大冷凍弁当・冷凍惣菜の売場を2〜3倍に単身高齢者の備蓄需要。廃棄が出ないという経営上の利点も大きい（→ ③ 商品と物流）
少量・小分け半人前の惣菜、小容量のパン・菓子食べきれる量。高齢世帯・単身世帯向け
店内飲食（イートイン）座席の設置高齢者の居場所。滞在時間を伸ばす
移動販売・買い物支援移動販売車、ネットスーパー連携、自治体との協定買い物弱者対策。自治体の補助が付くこともある

この方向を突き詰めると、コンビニは
食品スーパーの小型版に近づいていく。
ただし決定的な違いが2つある。

  • 価格：コンビニは定価販売が基本。スーパーの特売には勝てない
  • 売場面積：30坪では生鮮のフル品揃えはできない。「補完」であって「代替」ではない

だからコンビニの生鮮強化は、スーパーを倒しに行く戦略ではなく、
スーパーが撤退した地域や、少量しか買わない客を拾う戦略として読むのが正確。

4. 店舗以外の収益 — コンビニは「窓口」でもある

コンビニの収益は、商品の粗利だけではない。
モノを売らずに手数料を得る収益が、日販とは別の層として積み上がっている。

【コンビニが担っている「窓口」機能】

   お金まわり              情報・手続きまわり        物流まわり
  ┌──────────┐         ┌──────────────┐       ┌────────────┐
  │ ATM        │         │ 住民票・印鑑登録 │       │ 宅配便取次   │
  │ 収納代行   │         │ 証明書のコンビニ │       │ 受取ロッカー │
  │ （公共料金 │         │ 交付             │       │ ECの受取拠点 │
  │   通販代金 │         │ チケット発券     │       │ 返品受付     │
  │   税・保険）│         │ 各種申込         │       └────────────┘
  │ 電子マネー │         │ 住民票以外の     │
  │ ・コード決済│         │ 自治体サービス   │
  └──────────┘         └──────────────┘

   → 手数料収入そのものは小さいが、
     「来店する理由」を作ることで日販を支えている
機能 収益の性格 ポイント
収納代行1件あたり数十円の手数料。件数が膨大公共料金・通販代金・税金・社会保険料。手数料は微小でも、支払いついでの買い物を生む
ATMセブン銀行モデル。提携金融機関からATM受入手数料を取るセブン銀行は収益の約9割がATM受入手数料と報じられた。設置台数は2万台超規模。→ ネット銀行
行政サービス証明書のコンビニ交付（住民票、印鑑登録証明、戸籍など）自治体の窓口コスト削減とセット。手数料は小さいが公共インフラ化が進む
宅配便取次・受取取次手数料ECの拡大で受取拠点としての価値が上昇。→ 宅配便、EC・ネット通販
店舗メディア（リテールメディア）店内デジタルサイネージの広告枠をメーカーに売る粗利率がほぼ100%の新収益。ファミリーマートの「ファミリーマートビジョン」が先行

ポイント：これらの機能で直接稼ぐ金額は、商品の粗利に比べれば小さい。
価値の本体は 「来店理由の束」 にある。
公共料金を払いに来た客が缶コーヒーを買う。この連鎖が日販を支えている。
逆に言うと、キャッシュレス化とオンライン手続きの普及は、この来店理由を1つずつ削る。
ATM利用も収納代行も長期では減少圧力にさらされる。
だから各社はリテールメディアという、来店を前提にしない新しい収益を探している。

5. ネットコンビニ・宅配 — 「近くて便利」をもう一段近くする

コンビニの価値は「近さ」だった。宅配はその近さを距離ゼロにする試み。

サービス 内容 経済性の論点
7NOW（セブン-イレブン）自社アプリで注文、店舗から最短20〜30分で配達自社で配達網を持つか委託するかでコストが変わる。配送費をどちらが負担するかが最大の論点
ローソンデリバリー／ファミマの宅配Uber Eats・出前館などのプラットフォーム連携＋自社配達プラットフォームの手数料（売上の2〜3割）が粗利30%を食い尽くす
ネットスーパー型の取り組みまとめ買い・置き配・定期配送客単価を上げないと配送費が合わない

構造的な難しさを数字で見ると分かりやすい。
コンビニの粗利率は約30%。客単価は700円前後。
つまり1回の買い物で生まれる粗利は約200円。
ここから配達員の人件費（1配達あたり数百円）を出すと、確実に赤字になる。

だから宅配が成立する条件は3つに絞られる。

  • 客単価を大きく上げる（まとめ買い、配送料の徴収、最低注文金額の設定）
  • 配達を既存のリソースで賄う（店舗スタッフの手空き時間、近隣の複数注文をまとめる）
  • 配送そのものでは儲けず、来店できない客を取り込む手段と割り切る

加えて、加盟店側から見ると 宅配の労力は誰が負うのか という論点がある。
ピッキングと梱包は店舗の作業になるので、人手不足の店にとっては負担増になりうる。
② フランチャイズという仕組みで見た
「本部は売上、加盟店はコスト」という非対称が、ここでも顔を出す。

6. 海外展開 — 2つのまったく違うゲーム

日本のコンビニ3社はいずれも海外に出ているが、北米とアジアではやっていることが違う。

【北米型 と アジア型】

■ 北米（7-Eleven, Inc.）
   ガソリンスタンド併設型が主流
   ┌─────────────┐
   │ 給油所（大） │ ← 売上の大半は燃料。粗利は薄い
   │  ＋          │
   │ 売店（小）   │ ← 飲料・スナック・たばこ中心。中食が弱い
   └─────────────┘
   課題：EV化とガソリン需要の減少 → 燃料マージンに頼れなくなる
   打ち手：日本型のフレッシュフード（中食）を移植する

■ アジア（台湾・タイ・中国・東南アジア）
   日本とほぼ同じ都市型・中食中心のフォーマット
   ・台湾：統一超商（セブン）、全家（ファミマ）が生活インフラ化
   ・タイ：CPグループ傘下でセブンが圧倒的店舗数
   ・中国：都市部で各社が展開。ローソンは上海圏に密度を作る戦略
   形態：ライセンス供与、合弁（現地有力企業と組む）が中心
   → 本部は出資と技術供与で、店舗投資のリスクを取らない
チェーン 海外展開の規模（報道ベース） 特徴
セブン-イレブン世界20か国以上、全体で約 85,000店北米は直接経営（7-Eleven, Inc.）、アジアはライセンス中心
ファミリーマート海外 約 27,000店台湾・タイ・中国など。現地有力企業との合弁が基本
ローソン中国・タイ・フィリピン・ハワイ3社で最も小規模。中国は上海周辺に密度を作る戦略

（2026年時点の各種集計・報道ベース。集計方法で数値が動くため、各社IRで確認のこと）

北米が経営上の最大の論点になっている理由。

  • 北米事業はセブン&アイの連結売上の大きな部分を占めるが、燃料の粗利は薄く景気に振られる
  • EV化とガソリン需要の減少という構造的な逆風がある
  • そこで「日本型の中食を北米に移植する」という転換を進めているが、
    専用工場と多頻度配送というインフラを北米で一から作る必要がある（→ ③ 商品と物流）
  • 2024年8月、カナダのアリマンタシォン・クシュタールがセブン&アイに買収を提案（1株2,600円、
    総額約7兆円規模と報じられた）。海外企業による日本企業の買収として過去最大級だったが、
    2025年7月に撤回された
  • 対抗策として掲げられた 7-Eleven, Inc. の北米上場は、当初2026年後半の予定だったが、
    2027年度以降へ延期されたと2026年に報じられている

ポイント：北米セブンをめぐる一連の動きは、
「日本のコンビニのノウハウは、海外でそのまま通用するのか」という問いそのもの。
中食・多頻度配送・単品管理は、店舗密度と労働力の安さと食文化の上に成り立っている。
この3条件が違う北米では、同じモデルが同じようには効かない。
アジアで成功し北米で苦戦しているのは、そういうことだと読める。

7. 次の10年に効く3つの制約

制約 中身 効き方
①人件費最低賃金の継続的な引き上げ。加盟店の人件費は総収入の6〜7割日販の伸び（年1〜4%）より賃金の伸び（年3〜5%）が上回ると、加盟店モデルが数式として成り立たなくなる。ロイヤリティ体系そのものの見直し圧力になる
②物流2024年問題（ドライバーの時間外労働上限）と改正物流効率化法1日3便という前提が揺らぐ。便数削減、共同配送の他チェーンとの相互利用、深夜便の見直し
③来店理由の消失キャッシュレス化でATM利用減、オンライン手続きで収納代行減、たばこ需要減商品を買わない来店が減ると、ついで買いも消える。日販の土台が細る

これに対する各社の答えは、大きく3つの方向に整理できる。

【成熟市場での3つの方向】

  ① 店のなかを変える       省人化（セルフレジ、AI発注、自動釣銭機）
                            廃棄が出ない商品（冷凍）への構成シフト
                            高単価商材（店内調理、高価格PB）

  ② 店の外に稼ぎを作る     リテールメディア（広告枠）
                            宅配・EC受取拠点
                            行政・金融サービスの受託

  ③ 日本の外に出る         アジア（フォーマットがそのまま効く）
                            北米（中食の移植に挑戦中）

省人化については、ロボットや
生成AIの適用（AI発注、需要予測、シフト作成）が
実装段階に入りつつある。ただしコンビニ店舗の作業は
検品・陳列・清掃・調理・接客と多岐にわたり、レジだけ無人化しても人は減らない。
「人がやる作業の総量」を減らせるかどうかが、省人化投資の本当の評価軸になる。
