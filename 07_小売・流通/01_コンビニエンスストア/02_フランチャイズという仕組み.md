# ② フランチャイズという仕組み — 本部は何を売っているのか

このノートで分かること：コンビニ本部と加盟店がそれぞれ何を出し合っているのか、
なぜ本部は直営ではなくフランチャイズを選ぶのか、そして
**24時間営業・見切り販売・ドミナント出店をめぐる対立が、なぜ「構造」として起きるのか**。

> 結論：**コンビニ本部は「店」を経営していない。「店を経営する仕組み」を貸している。**
> 本部が出すのは 不動産・物流・システム・商品開発・ブランド の5つ。
> 加盟店が出すのは 労働力・運転資金・現場判断 の3つ。
> 対価として本部は粗利の一定割合を取る。
> この分け方から、**「売上に連動する本部」と「利益に連動する加盟店」** という
> 立場の違いが必然的に生まれる。対立はここから来る。

---

## 1. フランチャイズ（FC）とは何か

**フランチャイズ ＝ 本部（フランチャイザー）が、看板・商品・ノウハウ・仕入ルートを
パッケージにして加盟店（フランチャイジー）に貸し、対価を受け取る契約**。

加盟店は**独立した事業者**であって、本部の社員ではない。ここが重要。

```
【直営 と フランチャイズ の違い】

■ 直営
   本部 ──── 店舗（自社）
   ・売上も利益もすべて本部のもの
   ・店長は社員。人件費も家賃も本部が払う
   ・出店に必要な資金と人員をすべて本部が用意する
   → 1店つくるのに数千万円＋店長1人が要る。増やすのが重い

■ フランチャイズ
   本部 ──契約──▶ 加盟店（独立した事業者）
     │                  │
     │ 提供             │ 提供
     ▼                  ▼
   ・ブランド          ・労働力（オーナー＋アルバイト）
   ・商品開発          ・運転資金（在庫・人件費の立替）
   ・物流網            ・現場判断（発注・売場づくり・採用）
   ・情報システム      ・地域の信用
   ・不動産（型による）
     │
     ◀── 粗利の40〜60%台（チャージ） ──
   → 本部は資金と人員を出さずに店を増やせる。増やすのが軽い
```

日本のコンビニでは **加盟店（FC店）が9割以上**を占める。
直営店は残るが、その多くは「新人の研修用」「新立地の実験用」「オーナー引継ぎ待ちの一時運営」
といった役割で、**本部の収益源というより人材と検証のための装置**になっている。

## 2. 本部は5つのものを提供している

「粗利の半分以上を取るのは高すぎないか」という問いに答えるには、
**本部が何を出しているか**を分解する必要がある。

| 本部が提供するもの   | 具体的に何か                                                           | もし自前でやったら                             |
| -------------------- | ---------------------------------------------------------------------- | ---------------------------------------------- |
| **① 不動産**         | 土地・建物のリース契約、店舗設計・建築、什器（冷ケース・レジ・看板）   | 初期投資5,000万〜1億円規模。立地の目利きも必要 |
| **② 物流**           | 共同配送センター、1日3便の多頻度配送、温度帯別輸送                     | 個人商店が1日3便で弁当を仕入れることは不可能   |
| **③ 情報システム**   | POSレジ、発注端末、単品管理、勤怠・会計システム                        | システム開発・保守に年数千万円                 |
| **④ 商品開発**       | PB（セブンプレミアム等）、中食・カウンターFFの商品開発、専用工場の確保 | 1商品の開発に数千万円と数百回の試作            |
| **⑤ ブランドと集客** | 看板の認知、全国広告、キャンペーン、アプリ・ポイント                   | TVCMは年数十億円規模                           |

これに加え、**⑥ 経営指導（OFC の巡回）** と **⑦ 水道光熱費の8割負担**、
**⑧ 会計・税務の代行**（多くの契約で本部が帳簿を作る）が付く。

> ポイント：チャージ率が高いのは、**本部が固定費の大きい部分（不動産・物流・システム）を
> 抱えているから**。本部の取り分が粗利の56〜76%（セブンのCタイプ）と高いのは、
> 土地建物という最も重い投資を本部が背負っている型だからで、
> 加盟店が土地建物を用意するAタイプなら45%まで下がる。**率の高低だけを見ても意味がない。**

## 3. 本部の収益構造 — 加盟店の損益とはまったく違う

ここが最も誤解されやすい。本部の決算書と、加盟店の損益は**別物**である。

```
【本部（チェーン全体）の売上の見え方】

  チェーン全店売上高   … 加盟店＋直営店の店頭売上の合計
      約3兆円規模（セブン・ファミマ・ローソンともこの水準）
        │
        │  ※ FC店の店頭売上は本部の売上高には計上されない
        ▼
  本部の営業収益      … ①加盟店からのチャージ収入
      数千億〜1兆円規模   ②直営店の売上高
                         ③本部から加盟店への商品供給（型による）
                         ④広告・その他収入
        │
        ├─ 販管費（本部人件費、物流費、システム費、店舗賃借料、広告費）
        ▼
  営業利益
```

| チェーン              | 2026年2月期 実績                                                                   | 出典     |
| --------------------- | ---------------------------------------------------------------------------------- | -------- |
| セブン&アイHD（連結） | 営業収益 10兆4,302億円（▲12.9%）、営業利益 4,229億円（+0.5%）                      | 決算短信 |
| うち国内コンビニ事業  | 営業利益 2,336億円（前年比 95.3%）、営業収益 +1.2%                                 | 決算短信 |
| ローソン              | チェーン全店売上高 3兆223億円（+4.5%）、事業利益 1,123億円（+7.0%、3期連続最高益） | 決算発表 |
| ファミリーマート      | チェーン全店売上高 3兆3,002億円（+1.7%）、事業利益 1,002億円（+17.9%、過去最高）   | 決算発表 |

（各社決算発表および流通系メディア報道ベース。セブン&アイは2025年度にスーパーストア事業と
セブン銀行を非連結化したため、営業収益の減少は事業売却によるもので、実態の縮小ではない）

**本部の損益に効く変数**は次の3つで、加盟店とはまったく違う。

| 本部にとって                                              | 加盟店にとって                                     |
| --------------------------------------------------------- | -------------------------------------------------- |
| **店舗数 × 日販 × 粗利率 × チャージ率** が収入            | **日販 × 粗利率 ×（1−チャージ率）− 人件費** が利益 |
| 人件費は**本部社員とOFCの分だけ**。店舗の人件費は関係ない | **人件費が総収入の6〜7割**。ここが生命線           |
| 1店の日販が下がっても、店数を増やせば総額は維持できる     | 自分の店の日販がすべて。他店が増えると減る         |

> ポイント：この表の3行を並べると、対立の理由がそのまま読める。
> **本部は「店数 × 売上」の合計を最大化したい。加盟店は「自分の店の利益」を最大化したい。**
> どちらも合理的で、どちらも間違っていない。それでも利害は一致しない。

## 4. 契約タイプ — 誰が土地建物を出すかで全部変わる

| 型                                                             | 土地・建物 | 加盟時の資金                             | チャージ率                           | 誰に向くか                                 |
| -------------------------------------------------------------- | ---------- | ---------------------------------------- | ------------------------------------ | ------------------------------------------ |
| **加盟店が用意する型**<br>（セブンAタイプ／ローソンBタイプ等） | 加盟店     | 高い（内外装・什器を負担する契約もある） | 低い（セブンAで45%、ローソンBで34%） | もともと土地を持つ地主、元・個人商店       |
| **本部が用意する型**<br>（セブンCタイプ／ローソンCタイプ等）   | 本部       | 低い（セブンCで約315万円とされる）       | 高い（セブンCで56〜76%の累進）       | 資産を持たない脱サラ独立者。**現在の主流** |

（各社の加盟店募集資料および解説記事をもとにした概算。契約年次で条件が変わるため、
実際の検討時は法定開示書面＝**中小小売商業振興法に基づく情報開示書面**で確認する）

歴史的には「商店主が看板を掛け替える」ところから始まったので、
加盟店が土地建物を持つ型が主だった。今は**脱サラ独立者を本部が土地建物ごと迎える型が中心**。
これは本部にとって、①候補地を自分で選べる（＝出店戦略の自由度）、
②チャージ率を高く取れる、という2つの利点がある一方、
**本部のバランスシートに賃借契約が大量に積み上がる**という負担も生む。

### 契約期間と「やめられなさ」

- 契約期間は **15年（セブンCタイプ）** など長期。ローソン・ファミマも10〜15年が一般的
- 中途解約には違約金が設定されている
- 店舗が本部名義なので、やめるときに**資産が手元に残らない**（設備は本部のもの）

この「長期・違約金・資産が残らない」の3点セットが、
後述する優越的地位の問題の土台になっている。**やめられない相手との交渉は、交渉にならない**。

## 5. ドミナント出店 — なぜ同じチェーンが向かいにできるのか

**ドミナント出店 ＝ 特定の地域に集中して出店し、その地域で圧倒的なシェアを取る戦略**。
セブン-イレブンが1974年の1号店以来、一貫して取ってきた基本戦略で、
だからこそセブンは**未出店の県が長く残った**（沖縄進出は2019年）。

```
【ドミナント出店の効果】

  ■ 全国にバラバラに20店            ■ 1エリアに集中して20店

     ● ・ ・ ● ・ ・ ・ ●              ・ ・ ・ ・ ・ ・ ・ ・
     ・ ・ ● ・ ・ ● ・ ・              ・ ● ● ● ● ・ ・ ・
     ● ・ ・ ・ ● ・ ・ ●              ・ ● ● ● ● ・ ・ ・
     ・ ● ・ ・ ・ ・ ● ・              ・ ● ● ● ● ・ ・ ・
     ・ ・ ・ ● ・ ・ ・ ・              ・ ● ● ● ● ・ ・ ・

   配送：1台が長距離を走って数店      配送：1台が短距離で多数店を回る
   広告：地域紙もTVCMも効率が悪い      広告：1エリアの広告が20店に効く
   指導：OFCの移動時間ばかり           指導：1人で近隣7〜8店を週2回巡回できる
   認知：「たまに見る店」              認知：「どこにでもある店」
```

ドミナントには、経済的に強い理由が4つある。

- **物流効率**：1便のトラックが短い距離で多数店を回れる。多頻度配送（1日3便）は
  店密度がないと成立しない（→ [③ 商品と物流](03_商品と物流.md)）
- **広告効率**：エリア広告・TVCMの費用が店数で割られる
- **指導効率**：OFC（経営相談員）1人が7〜8店を週2回訪問できる
- **競合排除**：良い立地を先に押さえれば、他チェーンが入れない

### ドミナントの副作用 — カニバリゼーション

一方、既存の加盟店から見ると、**近くに同じ看板の店ができれば客を取られる**。
これを **カニバリゼーション（共食い）** と呼ぶ。

|                    | 本部の視点                                                                                                  | 既存加盟店の視点                                                                        |
| ------------------ | ----------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| 新店が近くにできる | エリア全体のチェーン売上が増えるならプラス。既存店の日販が1割減っても、新店が日販50万円を作れば合計は増える | 日販が1割減れば、利益は3〜4割減る（[① 1店舗の経済学](01_1店舗の経済学.md)のレバレッジ） |
| 判断基準           | **エリア合計のチャージ総額**                                                                                | **自分の店の利益**                                                                      |

セブン-イレブンなどの標準契約には、**明示的なテリトリー権（一定範囲に他店を出さない約束）が
基本的にない**とされる。これが「向かいに同じチェーンができた」という事態を法的に可能にしている。

近年は、店舗数の頭打ちと出店余地の縮小を受けて、
各社とも**「新規出店より既存店の日販を上げる」**方向に舵を切っている。
ドミナントの副作用が、市場の成熟によって自然に抑制されつつある、という言い方もできる。

## 6. 3つの対立点 — 構造として読む

2019年前後、コンビニをめぐって社会的な議論が噴出した。論点は主に3つ。
**どちらが悪いかではなく、契約の建て付けから必然的に生じる非対称として読む**のが理解の近道。

### 対立①：24時間営業

|                  | 本部                                         | 加盟店                                         |
| ---------------- | -------------------------------------------- | ---------------------------------------------- |
| 深夜の**売上**   | 粗利が増え、チャージが増える                 | 粗利が増える                                   |
| 深夜の**人件費** | **負担しない**                               | **全額負担**（しかも深夜は割増・人が採れない） |
| 結論             | 深夜売上がゼロでない限り、開いていたほうが得 | 深夜の粗利 < 深夜人件費 なら、閉めたほうが得   |

**同じ店について、本部と加盟店で損益分岐点が違う**。これが2019年の東大阪の店舗を発端とする
「時短営業問題」の核心だった。2020年代に入って各社が時短を選べる制度を整えたが、
時短を選ぶと日販が落ち、24時間営業インセンティブも失うため、
**制度上選べても経済的には選びにくい**状態が続いている（→ [① 1店舗の経済学](01_1店舗の経済学.md) 第9章）。

### 対立②：見切り販売（値引き）

消費期限の近い弁当を値引きして売り切るか、定価のまま廃棄するか。

- **加盟店**：値引きしてでも売れば、廃棄原価の負担が減る。粗利は薄くなるが手元は改善する
- **本部**：値引きが常態化すると「閉店前に行けば安い」という行動が定着し、
  定価で買う客が減る。チェーン全体の粗利率が下がる。ブランドの毀損にもなる
- **さらに**：[① 1店舗の経済学](01_1店舗の経済学.md)で見たコンビニ会計により、
  廃棄が増えると本部のチャージは増える。ここで「本部には廃棄を減らす動機がない」という
  批判が成立してしまう

この点は過去に訴訟にもなり、公正取引委員会は
**「見切り販売を不当に制限することは独占禁止法上問題となりうる」**との立場を示している。
2024年以降、セブン-イレブンが本部主導で値引きを推奨する方針に転じたと報じられ、
構図は緩和の方向に動いている。

### 対立③：仕入数量（推奨発注）

発注権は加盟店にあるが、実務ではOFCが「これだけ発注しましょう」と推奨する。
新商品の導入、キャンペーン商品の数量、季節商材（恵方巻・クリスマスケーキ）の仕入。

公正取引委員会の実態調査（2020年9月公表、全国57,524店の加盟店を対象）では、

- 本部から強く推奨され**意に反して仕入れている商品が「ある」…51.1%**
- 必要以上の数量を仕入れるよう**強要された経験が「ある」…47.5%**

と報告された。公取委は、①年中無休・24時間営業の強制、②必要以上の仕入数量の強制、
③見切り販売の制限、といった行為が**独占禁止法上の「優越的地位の濫用」に該当しうる**として、
本部各社に改善を要請した。

> ポイント：公取委が問題にしたのは「本部が加盟店に助言すること」ではなく、
> **「やめられない契約関係を背景に、実質的に断れない要請をすること」**。
> 契約期間15年・違約金・資産が残らない、という条件が
> 「推奨」を「強制」に変えてしまう。**構造が言葉の意味を変える**というのがこの問題の本質。

## 7. 規制と行政の関与

| 制度・動き                                                       | 内容                                                                                                                     | コンビニへの効き方                                         |
| ---------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------- |
| **中小小売商業振興法**                                           | FC本部に、加盟契約前の**法定開示書面**の交付を義務づけ。ロイヤリティの算定方法、契約期間、解約条件などを事前に示させる   | 加盟希望者が条件を比較できる根拠。数値の裏取りはここを見る |
| **独占禁止法（優越的地位の濫用）／フランチャイズ・ガイドライン** | 公正取引委員会が、FC本部と加盟店の取引について問題となる行為類型を示す                                                   | 24時間強制・仕入強制・見切り制限が対象                     |
| **公取委 コンビニ実態調査（2020年9月公表）**                     | 全国57,524店を対象にした初の大規模調査。上記の実態を数値で示し、本部に改善を要請                                         | 以後、各社が時短制度・値引き方針を見直す契機になった       |
| **経産省「新たなコンビニのあり方検討会」報告書（2020年2月）**    | 「本部と加盟店の双方がメリットを得る好循環が目詰まりした」と指摘し、加盟店優先・オーナー重視の視点でのモデル再構築を提言 | 業界の自主的な行動計画（アクションプラン）につながった     |
| **労働法制との関係**                                             | 加盟店オーナーは事業者か労働者か、という論点。労働組合法上の労働者性をめぐり判断が分かれた経緯がある                     | オーナーが団体交渉権を持つかどうかに直結する               |
| **最低賃金**                                                     | 毎年の引き上げ。加盟店の人件費に直撃                                                                                     | 制度は加盟店を守るが、コストは加盟店が負う                 |

## 8. それでもフランチャイズが続く理由

対立ばかりを見ると「なぜこの仕組みが残るのか」が分からなくなる。
実際には、**双方にとって代替手段より合理的**だから続いている。

|            | フランチャイズを選ぶ理由                                                                           | 代替案とその問題                                                                               |
| ---------- | -------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| **本部**   | 資金も人員も出さずに店を増やせる。現場の採用・シフト・クレームという最も面倒な変動要素を切り離せる | **直営化**：1店あたり数千万円の投資と店長1人。5万店を直営にすることは不可能                    |
| **加盟店** | 300万円台の自己資金で年商2億円の事業を始められる。物流・商品開発・システムは既製品として使える     | **独立の個人商店**：仕入ルートがない。弁当を1日3便で仕入れることも、PB商品を作ることもできない |

> ポイント：加盟店がフランチャイズを選ぶ最大の理由は
> **「300万円で年商2億円の装置を借りられる」というレバレッジ**にある。
> そして本部が選ぶ最大の理由は **「変動費（人件費）を外部化できる」**こと。
> この2つは同じコインの裏表で、**うまくいっている間は双方の利益が一致し、
> 人件費が上がったりカニバリが起きたりすると一気に利害が割れる**。

---

## 9. 他業界のフランチャイズとの比較

| 業態                                                                      | ロイヤリティの取り方        | 本部が出すもの                   | 加盟店の主なリスク         |
| ------------------------------------------------------------------------- | --------------------------- | -------------------------------- | -------------------------- |
| **コンビニ**                                                              | 粗利の40〜60%台（粗利分配） | 不動産・物流・商品開発・システム | 人件費、廃棄ロス、カニバリ |
| [ファストフード](../../08_食品・農水産・外食/14_ファストフード/README.md) | 売上の3〜7%＋広告分担金     | ブランド・レシピ・原材料         | 家賃、人件費、原材料高     |
| [カフェ](../../08_食品・農水産・外食/19_カフェ/README.md)                 | 売上の数% or 直営中心       | ブランド・豆・オペレーション     | 立地依存が極めて強い       |
| [学習塾・予備校](../../15_サービス・生活関連/15_学習塾・予備校/README.md) | 売上の10〜20%               | カリキュラム・教材・講師研修     | 生徒数、講師確保           |

コンビニのFCが特殊なのは、**①本部が不動産まで出すこと、②ロイヤリティを売上でなく粗利に
かけること、③在庫（廃棄リスク）が加盟店に残ること**の3点。
この3点セットは他業種にはあまり見られない。

## 用語メモ

| 用語                                                | 意味                                                                                                                     |
| --------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| **フランチャイズ（FC）**                            | 本部が看板・商品・ノウハウ・仕入ルートをパッケージで貸し、加盟店が対価を払う契約。加盟店は独立した事業者                 |
| **フランチャイザー／フランチャイジー**              | 本部／加盟店。日本のコンビニでは加盟店が9割超                                                                            |
| **チェーン全店売上高**                              | 加盟店と直営店の店頭売上の合計。FC店の売上は本部の売上高には計上されないため、本部の営業収益とは桁が違う                 |
| **ドミナント出店**                                  | 特定地域に集中出店してシェアを取る戦略。物流・広告・指導の効率が上がる一方、既存加盟店とのカニバリを生む                 |
| **カニバリゼーション（カニバリ）**                  | 同一チェーンの店舗同士が客を奪い合うこと。共食い                                                                         |
| **OFC（オペレーション・フィールド・カウンセラー）** | 本部の巡回経営指導員。1人が7〜8店を担当し、週2回程度訪問して発注・売場・採用を助言する                                   |
| **優越的地位の濫用**                                | 独占禁止法の規制類型。取引上強い立場を使って相手に不利益を押しつける行為。FC本部と加盟店の関係が典型例の1つ              |
| **法定開示書面**                                    | 中小小売商業振興法により、FC本部が加盟契約前に交付を義務づけられる書面。ロイヤリティの算定方法・契約期間・解約条件を記載 |
| **テリトリー権**                                    | 一定範囲に同一チェーンの他店を出さないという約束。コンビニの標準契約には基本的にないとされる                             |
| **見切り販売**                                      | 消費期限の近い商品を値引きして売ること。本部が不当に制限すると独禁法上問題となりうる                                     |
