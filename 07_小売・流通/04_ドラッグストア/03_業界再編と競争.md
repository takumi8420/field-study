# 03. 業界再編と競争 ── なぜ数社に集約されたのか

このノートで分かること：**上位10社で市場の8割弱**という寡占がどう作られたか、各社のモデルの違い、そして「出店で伸びる時代」が終わったあとの競争軸。

> 結論：ドラッグストアの再編は「弱者救済」ではなく **仕入価格とPBを取りに行くための規模競争** である。
> 粗利ミックス（→[01](01_粗利ミックスの経済学.md)）で食品を安く売るモデルは、**仕入が1%安くなるだけで営業利益が跳ねる**。
> 営業利益率が3〜5%の商売では、原価を1%下げることは利益を2〜3割増やすのと同じ意味を持つ。だから統合が止まらない。

**なぜドラッグストアだけ集約が進んだのか**が、このノートの主題である。

## 4. なぜ統合するのか ── 数字で見る規模の効果

営業利益率4%の会社を考える。売上1兆円なら営業利益400億円。

| 打ち手                 | 効果                            | 営業利益への影響 |
| ---------------------- | ------------------------------- | ---------------- |
| 仕入原価を**1%**下げる | 売上原価7,200億円 × 1% = 72億円 | **+18%**         |
| 販管費を1%削る         | 販管費2,400億円 × 1% = 24億円   | +6%              |
| 既存店売上を1%伸ばす   | 100億円 × 粗利28% = 28億円      | +7%              |

> **仕入価格の改善が、他のどの打ち手より効く。** これが再編の経済的な動機。
> 売上規模が2倍になれば、メーカーとの取引条件は確実に良くなる。だから「まず大きくなる」ことが合理的になる。

さらに規模が効くのは仕入だけではない。

- **PB開発**：自社ブランド商品は最低ロットが大きい。数千店規模でないと単品を成立させられない。マツキヨココカラのPB比率は14.8%（2026年3月期）で、PBは粗利率が高く利益を押し上げる。
- **物流**：食品（とくに冷蔵・冷凍）を扱うには多温度帯の物流センターが要る。投資額が大きく、店舗密度がないと回収できない。
- **システム・データ**：ポイント会員基盤、需要予測、発注自動化。固定費なので店舗数で割ると1店あたりが下がる。
- **広告・採用**：知名度が採用コストを下げる。登録販売者の確保が出店制約になるため（→[02](02_規制と資格.md)）、採用力は直接的な成長要因。

## 5. コスモス薬品という例外 ── M&Aをしない成長

業界の再編潮流の中で、**コスモス薬品はM&Aをほぼ使わずに1兆円へ到達**した。モデルが明確に異なる。

| 論点             | 一般的な大手DgS        | コスモス薬品                                                 |
| ---------------- | ---------------------- | ------------------------------------------------------------ |
| 成長手段         | M&A＋出店              | **自力出店のみ**（2026年5月期は新規105店）                   |
| 価格政策         | 特売・チラシ・ポイント | **EDLP**（特売をしない）                                     |
| 食品比率         | 20〜30%台              | **62.9%**                                                    |
| 商圏             | 数万人規模             | **小商圏型メガドラッグストア**（人口の少ない地域にも大型店） |
| 店舗フォーマット | 地域ごとに可変         | **標準化**。同じ店を量産する                                 |
| 営業利益率       | 4〜7%                  | 3.9%（薄利多売）                                             |

**なぜEDLPと標準化がセットになるのか**。

```
  特売をする店                        EDLPの店
  ┌────────────┐          ┌────────────┐
  │ チラシ作成・配布      │          │ 広告費ほぼゼロ        │
  │ 値札の付け替え        │          │ 値札は固定            │
  │ 特売日の人員増        │          │ 人員が平準化          │
  │ 需要が日によって乱高下 │          │ 需要が読める          │
  │  → 在庫・欠品リスク   │          │  → 発注が簡単        │
  └────────────┘          └────────────┘
        販管費が重い                      販管費が軽い
              │                                │
              ▼                                ▼
      粗利を高くしないと回らない        粗利が低くても回る
```

コスモス薬品の粗利率は業界でも低い水準だが、**販管費率がそれ以上に低い**ため成立している。
「安い理由」を仕入だけでなく**オペレーション設計**に求めている点が、この会社を独自にしている。
ただし利益率は薄く、株価は2026年にかけてドラッグストア各社のなかで下落率が大きかったと報じられるなど、市場評価は分かれている。

## 6. 地域別の強さ ── 全国チェーンは実は少ない

ドラッグストアは**地域ごとに勝者が違う**。これは食品を扱う業態の宿命で、物流の経済圏が地域単位だからである。

| 地域         | 強いプレイヤー                                               |
| ------------ | ------------------------------------------------------------ |
| 北海道・東北 | ツルハHD、薬王堂HD                                           |
| 関東         | ウエルシアHD、マツキヨココカラ、サンドラッグ、クスリのアオキ |
| 中部         | スギHD、V・drug（中部薬品）、クスリのアオキ                  |
| 関西         | スギHD（I&H）、ココカラファイン系、キリン堂                  |
| 九州         | コスモス薬品、ドラッグイレブン、ダイレックス（サンドラッグ） |

- 統合が進んだ理由の一つは、**地盤が補完関係にある相手を選べる**こと。ツルハ（北海道・東北）とウエルシア（関東）は重複が比較的少ない。
- 逆に、地盤が重なる統合は**カニバリ（自社店舗同士の食い合い）**を起こすため、統合後に店舗の整理・閉鎖が必要になる。統合効果が遅れる一因。

## 7. 出店余地と商圏の重複 ── 成長モデルの転換点

```
【これまで】                    【これから】

  白地に出店 → 客数増            白地が減る
     │                             │
  固定費が薄まる                  隣に自社・他社の店
     │                             │
  さらに安くできる                商圏が重なる
     │                             │
  もっと客が来る                  1店あたり売上が落ちる
                                   │
                                既存店の生産性／M&A／
                                新フォーマットへ
```

- 店舗数は10年で1.5倍超に増え、人口あたりの店舗密度は国際的にも高い水準に達したとされる（業界分析ベース）。
- 主要な駅前・幹線道路沿いでは大手同士が至近距離で競合。**ドミナント戦略**（地域集中出店）は物流・広告を効率化する一方、自社店舗同士の食い合いと紙一重。
- 結果として、成長の主役が **出店 → ①既存店の生産性向上 ②M&A ③新フォーマット** へ移っている。
  - ①既存店：調剤併設率の引き上げ、PB比率の引き上げ、セルフレジ・自動発注による人時生産性の改善
  - ②M&A：地域チェーンの取り込み、調剤薬局チェーンの買収
  - ③新フォーマット：生鮮を扱う「ドラッグ＆フード型店舗」（ウエルシアが2025年8月に開始）、小型の受渡拠点（→[02](02_規制と資格.md)の登録受渡店舗）

## 8. ネット通販との競合 ── どこが奪われ、どこが残るか

| カテゴリ               | ネットに移りやすいか | 理由                                                                 |
| ---------------------- | -------------------- | -------------------------------------------------------------------- |
| 日用品（紙製品・洗剤） | **移りやすい**       | 重い・かさばる・ブランド指名買い。定期購入と相性がよい               |
| 化粧品（定番品）       | 移りやすい           | 指名買いが多い。ただし新製品の試用・カウンセリングは店が有利         |
| OTC医薬品              | **移りやすくなった** | 第1類以下はすでにネット販売可。2026年5月からは要指導も条件付きで可に |
| 食品（生鮮・日配）     | 移りにくい           | 鮮度・配送コスト。ネットスーパーは採算が厳しい                       |
| 調剤                   | 部分的に移る         | オンライン服薬指導と配送。ただし対面のニーズは残る                   |

- 構図としては、**ドラッグストアの高粗利カテゴリほどネットに奪われやすく、低粗利の食品ほど店に残る**。粗利ミックスにとっては不利な方向の圧力である。
- これに対する店側の答えが「**店でしか得られないもの**」＝即時性（今すぐ要る）、相談（登録販売者・薬剤師）、ついで買いの利便性、そして生鮮。
- ドラッグストアが食品・生鮮に踏み込む動きは、ネット対抗という観点からも説明できる。詳しくは [通販・D2C](../15_通販・D2C/README.md)。

## 9. まとめ ── 今後の競争軸

1. **統合効果を実装できるか**。ツルハ×ウエルシアののれん4,400億円（報道）を上回るシナジーを、共同仕入・共通PB・物流統合で出せるか。
2. **粗利ミックスを守れるか**。食品比率を上げれば客数は増えるが利益率は落ちる。どこで止めるか。
3. **制度変化への対応**。OTC類似薬の見直し（OTCに追い風／調剤に逆風）と、オンライン販売解禁（ネット勢に有利）のどちらが効くか。→[02](02_規制と資格.md)
4. **人時生産性**。登録販売者・薬剤師の人件費は上がる。省人化投資と新しい販売区分への対応コストの両方が乗る。
5. **業態の境界の消失**。[食品スーパー](../03_食品スーパー/README.md)・[ディスカウントストア](../09_ディスカウントストア/README.md)・[コンビニ](../01_コンビニエンスストア/README.md)との競争が、同じ客・同じ商圏で直接起きるようになった。

## 用語メモ

| 用語                           | 意味                                                                                           |
| ------------------------------ | ---------------------------------------------------------------------------------------------- |
| **TOB（公開買付け）**          | 買付価格・期間・株数を公告して株式市場外で株を買い集める手法。経営権取得に使う                 |
| **のれん**                     | 買収額が買収先の純資産額を上回った差額。会計上は資産に計上され、償却や減損で利益を押し下げうる |
| **シナジー**                   | 統合によって生まれる上乗せ効果。共同仕入による原価低減、物流・本部費の統合など                 |
| **PB（プライベートブランド）** | 小売が企画し製造委託して自社ブランドで売る商品。粗利率が高い                                   |
| **EDLP**                       | Every Day Low Price。特売をせず常時低価格。販促費と運営の手間が減る                            |
| **ドミナント戦略**             | 特定地域に集中出店して物流・広告・人員配置の効率を上げる方法                                   |
| **カニバリゼーション**         | 自社店舗同士で客を食い合うこと。ドミナントの副作用                                             |
| **人時生産性**                 | 従業員1人が1時間働いて生み出す粗利益。小売の生産性指標                                         |
| **小商圏型**                   | 人口の少ない地域にも出店できるよう、低コスト運営で損益分岐点を下げた店舗モデル                 |
