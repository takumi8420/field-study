# 02. 規制と資格 ── 制度が業態を作った

このノートで分かること：ドラッグストアが全国2万店超まで増えられた**制度上の理由**と、これから収益を左右する**制度の変更点**。
医薬品の使い方・選び方には一切触れない。**産業構造と法制度の説明に徹する**。

> 結論：ドラッグストアの多店舗展開を可能にしたのは、2009年に始まった **登録販売者制度** である。
> それ以前、薬を売る店には薬剤師が必要だった。薬剤師は養成に6年かかり、数も限られ、人件費も高い。
> **「薬剤師なしでも大半の市販薬を売れる」資格を国が作った瞬間に、ドラッグストアは全国チェーン化できる業態に変わった。**

---

## 1. 医薬品の販売区分 ── 誰が売れるかが決まっている

日本の医薬品は、**処方箋が要るかどうか**と**リスクの程度**で分類され、区分ごとに「誰が売れるか」「どう売れるか」が法律（医薬品医療機器等法＝薬機法）で決まっている。

| 区分                                    | 位置づけ                                         | 販売できる人             | 販売方法                                            |
| --------------------------------------- | ------------------------------------------------ | ------------------------ | --------------------------------------------------- |
| 医療用医薬品                            | 医師の処方箋に基づく                             | 薬剤師                   | 保険薬局での調剤                                    |
| **要指導医薬品**                        | 市販に切り替わって間もない、リスク評価途中のもの | 薬剤師のみ               | 従来は対面必須。2026年5月から条件付きでオンライン可 |
| **第1類医薬品**                         | 副作用リスクが特に高い一般用医薬品               | 薬剤師のみ               | 書面等による情報提供が義務                          |
| **第2類医薬品**                         | リスクが比較的高い                               | **薬剤師 or 登録販売者** | 情報提供は努力義務                                  |
| **第3類医薬品**                         | リスクが比較的低い                               | **薬剤師 or 登録販売者** | 情報提供義務なし                                    |
| **指定濫用防止医薬品**（2026年5月新設） | 過量服用の懸念がある成分を含むもの               | 薬剤師 or 登録販売者     | 氏名・年齢の確認と販売記録の作成が**法的義務**      |

※要指導・第1類は一般に品目数が少なく、ドラッグストアの医薬品売上の大半は**第2類・第3類**が占める。
ここが「薬剤師がいなくても医薬品売場を回せる」という業態設計の土台になっている。

## 2. 登録販売者制度が変えたもの

```
【2009年より前】                    【2009年 改正薬事法 以降】

  薬を売る店                          薬を売る店
     │                                  │
     ▼                                  ▼
  薬剤師が必要                     ┌────────────┐
     │                            │ 第2類・第3類     │ ← 登録販売者でOK
     ▼                            │（売上の大半）     │
  薬学部6年 → 国家試験              └────────────┘
  人数も人件費も制約                       │
     │                            ┌────────────┐
     ▼                            │ 第1類・要指導     │ ← 薬剤師が必要
  店を増やせない                   │（品目は限定的）   │
                                  └────────────┘
                                          │
                                          ▼
                                  店舗数を一気に増やせる
```

- **登録販売者**は都道府県が実施する試験に合格して登録する公的資格。薬学部を出ている必要がない。
- 2015年度からは実務経験がなくても受験できるようになり、合格後に一定の実務経験を積むことで「店舗管理者」になれる仕組みに整理された。
- 効果は人件費だけではない。**採用母集団が桁違いに広がった**ことが大きい。既存のパート・社員が資格を取れば売場を回せるため、出店スピードの制約が外れた。

| 比較             | 薬剤師              | 登録販売者                             |
| ---------------- | ------------------- | -------------------------------------- |
| 養成             | 薬学部6年＋国家試験 | 都道府県試験（受験資格の学歴要件なし） |
| 扱える医薬品     | すべて              | 第2類・第3類                           |
| 調剤             | できる              | できない                               |
| 人数の制約       | 大きい              | 小さい                                 |
| 店舗展開への影響 | ボトルネック        | 制約を外した                           |

> ポイント：業態の成長要因を「経営努力」だけで説明すると間違える。
> **制度設計が業態の天井を決めている**という見方が、この業界を理解する第二の鍵。

## 3. 2026年5月施行の改正薬機法 ── 3つの変更

2025年5月21日に公布された改正薬機法のうち、主要部分が**2026年5月1日に施行**された。

### (1) 指定濫用防止医薬品の新設

これまで「濫用等のおそれのある医薬品」として通知レベルで扱われていたものが、**法律上の販売区分に格上げ**された。

- 販売時に**購入者の氏名・年齢の確認**と**販売記録の作成**が法的義務に。
- 若年者への販売数量の制限、複数個販売時の対応などが定められる。
- 店舗のオペレーション負荷が増える（本人確認の手順、記録システムの改修）。
- 業界団体・人材会社は、登録販売者の役割が「販売」から「管理・確認」へ移り、いわゆるゲートキーパー機能が期待されると整理している。

### (2) 要指導医薬品のオンライン販売の解禁

- 薬剤師が**ビデオ通話等で情報提供・指導を行うことを条件**に、店舗以外への販売（特定販売）が可能になった。
- ただし「**特定要指導医薬品**」は引き続き対面が必要。2026年7月時点で該当するのは緊急避妊薬のみとされる。
- 産業への含意：**ネット専業の事業者がOTC領域に踏み込みやすくなった**。リアル店舗の優位性が一段削られる。

### (3) 薬剤師不在店舗での受け渡し／登録受渡店舗制度

- 遠隔での服薬指導を前提に、薬剤師が常駐しない店舗でも一般用医薬品の受け渡しができる仕組みが整備される。
- **登録受渡店舗**の制度は2027年5月20日施行予定。
- 産業への含意：**「資格者を置かなくてもよい小型店」というフォーマットが成立しうる**。人手不足の地方や小商圏の出店余地が広がる可能性がある一方、コンビニなど他業態の参入余地も広がる。

```
   従来：店舗に資格者を置く ─── 出店の上限＝資格者の数

   改正後：
     ┌ 資格者がいる拠点 ┐
     │   薬剤師・登販    │──ビデオ通話──┐
     └──────────┘              ▼
                              ┌──────────┐
                              │ 受渡拠点（小型）  │──▶ 客
                              └──────────┘
     出店の上限が「資格者の数」から「拠点の数」へずれる
```

## 4. 調剤併設と制度 ── 収益が国の決定で動く

ドラッグストアの調剤事業は、次の2つの価格で成り立っている。

| 要素                         | 決め方                                                   | 改定頻度                        |
| ---------------------------- | -------------------------------------------------------- | ------------------------------- |
| **薬価**（薬そのものの値段） | 国が薬価基準で定める。市場実勢価に合わせて引き下げられる | 原則2年ごと（近年は毎年改定も） |
| **調剤報酬**（薬局の技術料） | 中央社会保険医療協議会の議論を経て国が定める             | 2年ごと                         |

2026年度（令和8年度）調剤報酬改定で報じられている主な論点。

- **敷地内薬局**（医療機関の敷地内に置く薬局）の評価が厳しくなった。かかりつけ機能を持ちにくい、独立性を確保しにくいという指摘が背景。
- **集中率**の基準が「95%以上」から「85%以上」へ厳格化。同一敷地内・同一建物内の医療機関は1つとみなして計算する。
- ドラッグストアは門前型・敷地内型ではなく**住宅地に面した併設店**が多いため、相対的な影響は独立系の門前薬局より小さいと見られるが、改定のたびに収益が動く事業であることに変わりはない。

関連：[調剤薬局](../../09_医薬・医療・ヘルスケア/07_調剤薬局/README.md)、[01_粗利ミックスの経済学](01_粗利ミックスの経済学.md)

## 5. 零売の原則禁止 ── グレーゾーンの終了

**零売**（れいばい）とは、処方箋なしで医療用医薬品を薬局が販売する行為を指す。

- 従来は厚生労働省の通知で「やむを得ない場合に限る」とされていたが、**通知には罰則がなく**、解釈が広がって「零売専門薬局」を名乗る店が増えていた。
- 2025年5月公布の改正薬機法で、**医療用医薬品は処方箋に基づいて販売することが法律上の原則**として明記された。例外は省令で限定される。
- 施行は「公布から2年以内」＝**遅くとも2027年5月まで**。2026年時点は移行期間にあたる。
- 産業への含意：零売は市場規模としては小さいが、「処方薬をどこまで小売チャネルに開放するか」という論点の縮図である。**国は零売を閉じる一方、OTC側の販売チャネルは広げている**（次章）。方向としては「医療用は医療で、セルフケアはOTCで」という線引きの明確化と読める。

## 6. OTC類似薬の保険給付見直し ── 最大の制度論点

**OTC類似薬**＝市販薬（OTC）と有効成分が似ている医療用医薬品のこと。

| 項目     | 内容（報道・政府文書ベース）                                                                                                 |
| -------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 経緯     | 2025年6月11日、自民・公明・日本維新の会の3党が見直しで合意。骨太の方針2025に「早期に実現可能なものは2026年度から実行」と記載 |
| 仕組み   | 対象薬について、患者が**薬剤費の4分の1相当を追加負担**する「特別の料金」を導入する方向                                       |
| 対象規模 | **77成分・約1,100品目**が対象と報じられる                                                                                    |
| 時期     | 2026年度から段階的に着手、制度開始は2027年3月が予定と報じられる                                                              |
| 配慮措置 | 子ども、がん・難病患者、低所得者、入院患者、医学的に長期使用が必要な患者などへの配慮が検討されている                         |

※制度の詳細は今後の政省令で確定する。上記は2026年9月時点の報道・合意文書ベースの整理であり、確定事項として読まないこと。

```
【患者の選択が変わる】

  これまで              見直し後
  ┌──────┐         ┌──────┐
  │受診して処方 │         │受診して処方 │ ← 追加負担が乗る
  │保険で3割負担 │   ──▶   │3割＋特別料金 │
  └──────┘         └──────┘
       安い                     │ 相対的に高くなる
                                ▼
  ┌──────┐         ┌──────┐
  │市販薬を買う │         │市販薬を買う │ ← 相対的に選ばれやすくなる
  │全額自己負担 │   ──▶   │全額自己負担 │
  └──────┘         └──────┘
```

**産業への含意**（ここが業界理解の要点）。

- OTC物販には追い風。処方から市販へ需要が移れば、粗利率の高いOTCカテゴリが伸びる。
- 一方、**調剤事業には逆風**。処方箋枚数と薬剤費が減る方向に働く。
- ドラッグストアは**物販と調剤の両方を持っている**ため、影響が相殺されうる。ここが独立系の調剤薬局との決定的な違いで、制度変更に対する耐性が高い。
- 登録販売者・薬剤師による相談対応の質が、実質的な競争要因として重みを増す。

## 7. インバウンド ── 免税制度という別の収益源

- 訪日外国人向けの**消費税免税販売**は、化粧品・医薬品・健康食品が中心。都市型・観光地型のドラッグストアにとって主要な収益源になっている。
- マツキヨココカラ&カンパニーの2026年3月期は、中国からの客の減少を台湾・タイなどが補い、ヘルス&ビューティ構成比が72.4%に拡大したと報じられる。売上1兆1,174億円（+5.3%）、営業利益849億円（+3.5%）で過去最高を更新。
- 免税販売は制度依存の収益であり、**免税制度の運用見直し**（不正転売対策としての手続き厳格化など）や為替・地政学で振れる。安定収益とは見なしにくい。
- 構造としては「国内の食品ロスリーダー戦略」とは全く別の、**高粗利カテゴリの輸出に近い商売**である。都市型と郊外型で経済性が違う一因になっている。

## 8. 制度マップ（まとめ）

```
        ┌──────────── 薬機法 ────────────┐
        │                                              │
  販売区分（誰が売れるか）              販売方法（どう売れるか）
        │                                              │
  要指導／第1類 → 薬剤師            対面 ⇄ オンライン（2026年5月〜要指導も条件付き可）
  第2類／第3類  → 登録販売者 ★       指定濫用防止医薬品：本人確認・記録が義務（2026年5月〜）
  指定濫用防止  → 確認・記録         登録受渡店舗（2027年5月〜）
        │
        └──▶ ★ここが業態の成立条件

        ┌──────── 健康保険制度 ────────┐
        │                                          │
     薬価（薬の値段）              調剤報酬（薬局の技術料）
        │                                          │
     毎年〜2年で引下げ              2026年度改定：敷地内薬局の評価厳格化、集中率95%→85%
        │
        └──▶ OTC類似薬の保険給付見直し（2026年度〜段階実施の方向）
                  処方 → 市販へ needs が移動しうる
```

## 用語メモ

| 用語                    | 意味                                                                                             |
| ----------------------- | ------------------------------------------------------------------------------------------------ |
| **薬機法**              | 医薬品医療機器等法。旧・薬事法。医薬品等の品質・有効性・安全性の確保と、販売方法・広告を規律する |
| **一般用医薬品（OTC）** | 処方箋なしで買える医薬品。リスクに応じて第1類〜第3類に分かれる                                   |
| **要指導医薬品**        | 医療用から市販に移って間もない等の理由で、薬剤師による対面指導が求められてきた区分               |
| **登録販売者**          | 2009年創設の公的資格。第2類・第3類の一般用医薬品を販売できる                                     |
| **指定濫用防止医薬品**  | 2026年5月施行の改正薬機法で新設された区分。販売時の確認・記録が法的義務                          |
| **特定販売**            | 店舗以外の場所にいる人への販売。いわゆるインターネット販売等                                     |
| **零売**                | 処方箋なしで医療用医薬品を販売する行為。2025年改正で原則禁止の方向                               |
| **OTC類似薬**           | 市販薬と有効成分が似た医療用医薬品。保険給付の見直し対象として議論されている                     |
| **薬価基準**            | 保険で使える医薬品と、その公定価格を定めたリスト                                                 |
| **調剤報酬**            | 保険薬局が受け取る技術料。2年ごとに国が改定する                                                  |
| **集中率**              | 1つの薬局の処方箋のうち、特定の医療機関由来が占める割合                                          |
| **免税販売**            | 訪日外国人等に対する消費税免税での販売制度                                                       |
