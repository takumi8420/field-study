# 04. 直近トピック（2026年9月時点）

報道・業界団体発表ベースの整理。確定事項と観測・推計を区別して書いている。数値は必ず年度・時点とセットで確認すること。

このノートで分かること：2025〜2026年にドラッグストア業界で実際に何が起きたか、そしてそれが[粗利ミックス](01_粗利ミックスの経済学.md)・[制度](02_規制と資格.md)・[再編](03_業界再編と競争.md)のどこに効くか。

## 1. 市場規模が10.6兆円へ ── 2025年度実態調査（2026年9月1日公表）

日本チェーンドラッグストア協会（JACDS）が2026年9月1日に公表した2025年度ドラッグストア実態調査（業界全体の推計）。

| 区分             | 2025年度          | 前年度比  | 構成比      |
| ---------------- | ----------------- | --------- | ----------- |
| ヘルスケア・調剤 | 3兆5,583億円      | +6.8%     | 33.4%       |
| フーズ・その他   | 3兆487億円        | +7.6%     | 28.6%       |
| ホームケア       | 2兆1,086億円      | +3.4%     | 19.8%       |
| ビューティケア   | 1兆9,271億円      | +5.5%     | 18.1%       |
| **合計**         | **10兆6,427億円** | **+6.1%** | 100%        |
| （参考）調剤額   | 1兆6,586億円      | +9.1%     | 売上の15.6% |
| 店舗数           | 2万4,536店        | +813店    | ―           |

読みどころ。

- **伸び率トップはフーズ（+7.6%）と調剤（+9.1%）**。この2つがドラッグストアの成長エンジンであることが数字に出ている。
- ホームケア（日用品）は+3.4%と鈍い。**ネット通販に最も奪われやすいカテゴリ**であることと整合する。
- 調剤額の対・調剤医療費シェアは19.7%（暫定値、JACDS）。全国の処方箋の約2割をドラッグストアが応需している計算になる。
- 前年度（2024年度）は10兆307億円で初の10兆円超だった。**2年連続で市場が拡大**している。
- なお業態全体の月次動向は経産省・商業動態統計が速報性で勝る。2026年の月次販売総額はおおむね8,000〜8,500億円台、前年同月比は月により+0.6%〜+7.3%で推移した。

> 注意：JACDS推計の店舗数2万4,536店に対し、大手チェーン中心の集計では1万9,000店超とする調査もある。「ドラッグストア」の定義が調査により異なるため、**別々の出所の数字を混ぜて比べない**。

## 2. ツルハ×ウエルシア統合の完了と、イオン傘下入り

- 統合効果のうち**商品調達のシナジーは2026年2〜3月以降に出てくる**とウエルシアHD側が説明している。共通PB「**+1（プラスワン）**」が発売された。
- 一方、2026年2月期については「統合効果が物足りない」「1店あたりの稼ぐ力が弱い」との報道もある（日本経済新聞）。統合は発表より実装が難しい。
- 構図として、**小売最大手のイオンが国内最大のドラッグストアを傘下に収めた**ことの意味は大きい。イオンは[スーパー・GMS](../02_スーパー・GMS/README.md)・[食品スーパー](../03_食品スーパー/README.md)も持つため、グループ内で業態が競合する局面が出てくる。

## 3. 改正薬機法が2026年5月1日に施行

2025年5月21日公布の改正薬機法の主要部分が施行された。ドラッグストアの店舗運営に直接効く3点。

| 変更                                         | 内容                                                                                                                                            | 産業への含意                                                                                                 |
| -------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| **指定濫用防止医薬品**の新設                 | 過量服用の懸念がある成分を含むものを法律上の区分に。販売時に**氏名・年齢の確認**と**販売記録の作成**が義務                                      | 店舗オペレーションの負荷増（本人確認手順、記録システム改修）。登録販売者の役割が「販売」から「確認・管理」へ |
| **要指導医薬品のオンライン販売解禁**         | 薬剤師がビデオ通話等で情報提供・指導を行うことを条件に特定販売が可能に。ただし「特定要指導医薬品」は対面必須（2026年7月時点では緊急避妊薬のみ） | ネット事業者がOTC領域に踏み込みやすくなる。リアル店舗の優位が一段削られる                                    |
| **薬剤師不在店舗での受け渡し**／登録受渡店舗 | 遠隔服薬指導を前提に、資格者常駐でない拠点での受け渡しを可能にする。登録受渡店舗制度は2027年5月20日施行予定                                     | 出店制約が「資格者の数」から外れる可能性。小型フォーマットや他業態の参入余地                                 |

> 見落としやすい論点：この改正は**規制強化と規制緩和が同時に入っている**。
> 濫用対策では店の責任を重くし（強化）、販売チャネルでは対面原則を緩めている（緩和）。
> 国の方向は「**セルフケアは広げる。ただし管理はきちんとさせる**」と読むのが素直。制度の詳細は[02_規制と資格](02_規制と資格.md)。

## 4. OTC類似薬の保険給付見直し ── 2026年度から段階的に

**OTC類似薬**＝市販薬と有効成分が似た医療用医薬品。

- 2025年6月11日、自民・公明・日本維新の会の3党が見直しで正式合意。骨太の方針2025に「早期に実現可能なものは2026年度から実行する」と記された。
- 報じられている制度設計：対象薬について**薬剤費の4分の1相当を患者が追加負担**する「特別の料金」を導入。対象は**77成分・約1,100品目**。制度開始は**2027年3月**が予定とされる。
- 子ども、がん・難病患者、低所得者、入院患者、医学的に長期使用が必要な患者などへの配慮措置が検討されている。
- 詳細は今後の政省令で確定する。**現時点では報道・合意文書ベース**であり、確定事項として扱わないこと。

```
【ドラッグストアへの二面的な影響】

     処方薬（保険）              市販薬（全額自己負担）
          │                            │
    追加負担が乗る ───needs が移動───▶ 相対的に選ばれやすく
          │                            │
          ▼                            ▼
   調剤事業に逆風                 OTC物販に追い風
   （処方箋枚数・薬剤費↓）        （粗利40%前後のカテゴリ↑）
          │                            │
          └────────┬───────┘
                      ▼
      ドラッグストアは両方を持つので、影響が相殺されやすい
      → 独立系の調剤薬局より制度変更への耐性が高い
```

これが、**ドラッグストアが調剤も物販も持っていることの戦略的な意味**である。[調剤薬局](../../09_医薬・医療・ヘルスケア/07_調剤薬局/README.md)単体の事業者は、この変化を一方的に受ける立場になる。

## 5. 2026年度調剤報酬改定 ── 敷地内薬局に厳しく

- **敷地内薬局**（医療機関の敷地内に置く薬局）への評価が厳しくなった。かかりつけ薬剤師・薬局としての機能を持ちにくいこと、薬局としての独立性を確保しにくいことが理由とされる。
- **集中率**（特定の医療機関からの処方箋が占める割合）の基準が**95%以上 → 85%以上**へ厳格化。同一敷地内・同一建物内の医療機関は1つとみなして計算する。
- ドラッグストアの併設薬局は住宅地・商業地に面した立地が多く、門前型・敷地内型に比べれば相対的な影響は小さいと見られる。ただし調剤は**2年ごとに一律で収益が動く事業**であり、改定のたびに前提が変わる。
- マツキヨココカラは2027年3月期について、外形標準課税の拡大（販管費で約18億円増）と**調剤報酬改定に伴う会計処理の変更**により、増収ながら実質減益の計画としている。制度が決算に直接効く実例。

## 6. 食品強化の次の段階 ── 生鮮への進出

| 動き                                 | 内容                                                                 | 時期          |
| ------------------------------------ | -------------------------------------------------------------------- | ------------- |
| ウエルシア「ドラッグ＆フード型店舗」 | 野菜・果物・精肉などの生鮮、冷凍食品、惣菜まで取り扱う新フォーマット | 2025年8月開始 |
| コスモス薬品                         | 一般食品の構成比62.9%、一般食品売上+11.7%。新規105店                 | 2026年5月期   |
| ウエルシアの客数                     | 2026年3〜6月の客数は前年同期比+1.3%と報じられる                      | 2026年        |

- 生鮮はこれまで[食品スーパー](../03_食品スーパー/README.md)の聖域だった。鮮度管理・ロス・多温度帯物流という参入障壁があったためである。
- ドラッグストアが**粗利15〜20%でも成立する損益構造**（→[01](01_粗利ミックスの経済学.md)）を持ったまま生鮮に入ってくると、食品スーパーは価格で追随できない。
- ただしドラッグストア側にもコストはある。生鮮は**廃棄ロス**と**作業時間**が重く、標準化しにくい。食品比率が上がるほど全体の粗利率は薄まる。**「どこまで食品に踏み込むか」は各社で判断が割れている**。
- 物価高が続く局面では、安い食品を持つ業態に客が流れる。マクロ環境が追い風として効いている点は割り引いて見る必要がある。

## 7. 出店余地の縮小と、成長モデルの転換

- 店舗数は10年で1.5倍超になり、人口あたりの店舗密度は国際的にも高い水準に達したとされる（業界分析ベース）。
- 主要な駅前・幹線道路沿いでは大手同士が至近距離で競合し、**1店舗あたりの商圏が縮小、新規出店の採算ラインが厳しくなっている**。
- 成長の主役が「白地への出店」から、**既存店の生産性向上・M&A・新フォーマット**へ移りつつある。
- 2026年にはスギHDがセキ薬品の議決権を51%へ引き上げるなど、**上位による地域チェーンの取り込み**が続いている。詳しくは[03_業界再編と競争](03_業界再編と競争.md)。

## 8. 全体の構図（まとめ）

1. **市場はまだ伸びている**。2025年度10.6兆円（+6.1%）。牽引はフーズ（+7.6%）と調剤（+9.1%）で、この2つがドラッグストアの成長の正体。
2. **プレイヤーは4社の1兆円企業に集約された**。ツルハ×ウエルシア統合とイオンのTOBで、小売最大手の傘下に国内最大のDgS連合ができた。統合効果の実装が2026年以降の試金石。
3. **制度が同時に緩み、同時に締まった**。要指導医薬品のオンライン解禁と零売の原則禁止、指定濫用防止医薬品の新設。方向は「セルフケアは広げ、管理は厳格に」。
4. **OTC類似薬の見直しは業界にとって両刃**。OTC物販に追い風、調剤に逆風。両方を持つドラッグストアは相殺できるが、独立系調剤薬局は一方的に影響を受ける。
5. **食品スーパーとの競合が生鮮まで到達した**。粗利ミックスを武器にした価格攻勢は続くが、食品比率を上げるほど自らの利益率も薄まる。**この業態の次の課題は「成長と利益率のトレードオフ」をどこで止めるか**である。

| -------------------------- | ---------------------------------------------------------------------------- |
| **JACDS**                  | 日本チェーンドラッグストア協会。業態の実態調査（市場規模推計）を毎年公表する |
| **商業動態統計**           | 経済産業省の統計。ドラッグストアの月次販売額を業態別・商品別に公表する       |

| **外形標準課税**           | 資本金等の企業規模に応じて課される地方税。2026年度以降、対象拡大が進む       |
