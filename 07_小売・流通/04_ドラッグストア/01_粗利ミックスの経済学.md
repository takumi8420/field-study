# 01. 粗利ミックスの経済学 ── なぜドラッグストアは強いのか

このノートで分かること：ドラッグストアが**なぜ食品をあれほど安く売れるのか**、そのお金がどこから出ているのか、そしてその構造が[食品スーパー](../03_食品スーパー/README.md)をなぜ苦しめるのか。

> 結論：ドラッグストアは「薬屋」ではなく、**粗利率の違う商品を意図的に混ぜて全体の利益を設計する装置**である。
> 医薬品と化粧品という粗利率40%・30%の商品を持っているから、粗利率15%の食品を「客寄せ」として使える。
> 食品スーパーは食品しか持っていないので、同じ値段では戦えない。**カテゴリの手札の差**が、そのまま業態の勝敗になっている。

---

## 1. まず数字で見る：カテゴリごとに粗利率が3倍違う

「粗利率」＝売価に対する売上総利益の割合。100円で売って原価が60円なら粗利率40%。

| カテゴリ            | 粗利率の目安 | 原価率  | なぜその水準になるか                                           |
| ------------------- | ------------ | ------- | -------------------------------------------------------------- |
| 一般用医薬品（OTC） | **35〜45%**  | 55〜65% | ブランドと薬事の壁で価格競争が起きにくい。比較購買されにくい   |
| 調剤                | **35〜40%**  | 60〜65% | 薬価と調剤報酬が国の制度で決まる。値引き競争が構造的に起きない |
| 化粧品              | **28〜33%**  | 67〜72% | メーカー主導の価格。ブランド指名買いが多い                     |
| 日用品・雑貨        | **20〜25%**  | 75〜80% | ブランド差が薄く、比較されやすい                               |
| **食品**            | **10〜20%**  | 80〜90% | 価格が完全に比較される。集客目的なので意図的に下げている       |

数値は各社IR・業界分析・報道をもとにした**2019〜2025年時点の目安**であり、企業・年度で動く。
実名の開示例としては、ウエルシアの部門別売上総利益率で調剤37.3%、化粧品31.5%、食品20.2%という数字が報じられている。また業界分析では食品15.1%／医薬品42.3%という対比も示されている（いずれも報道・分析ベース）。

**比較対象**：食品スーパーの一般食品の売上総利益率は20%程度、コンビニは30%前後とされる。
つまり**ドラッグストアの食品の粗利は、食品スーパーより低く、コンビニの半分以下**という水準になる。

## 2. 「なぜ食品を原価割れ近くで売れるのか」の答え

答えは単純で、**食品で利益を出す必要がないから**である。

```
【食品スーパーの損益】             【ドラッグストアの損益】

 食品 100%                         食品 30%   ─ 粗利15%  ┐
  └ 粗利 25%前後                    日用品 20% ─ 粗利22%  │ 合計で
      │                            化粧品 18% ─ 粗利30%  ├ 粗利 28%前後
      ▼                            医薬・調剤 32% ─ 粗利38% ┘
 これで人件費・家賃を                    │
 ぜんぶ払わないといけない                  ▼
  → 食品を安くできない             食品の粗利が0でも、他で払える
                                    → 食品を「広告費」として使える
```

食品スーパーにとって食品の値下げは**自分の利益を削る行為**だが、ドラッグストアにとっては**販促費の付け替え**にすぎない。
チラシに1,000万円使うのと、食品の粗利を1,000万円分削って安くするのは、どちらも「客を呼ぶための支出」として同じだからだ。

> ポイント：これを **ロスリーダー（客寄せ商品）** という。ドラッグストアが特殊なのは、ロスリーダーが「一部の目玉商品」ではなく**食品カテゴリまるごと**であること。

### 店舗の中で何が起きているか

```
   入口
    │
    ▼
┌──────────┐  ← 安い食品・飲料・米・トイレットペーパー
│  食品／日用品   │     （集客装置。粗利は薄い。重い物＝車で来る動機）
└──────────┘
    │  客はここを通って奥へ進む
    ▼
┌──────────┐  ← 化粧品・ヘアケア（粗利30%前後）
│  ビューティ     │     明るい照明・テスター・美容部員
└──────────┘
    │
    ▼
┌──────────┐  ← OTC医薬品（粗利40%前後）・健康食品
│  ヘルスケア     │     登録販売者が接客し、相談に乗る
└──────────┘
    │
    ▼
┌──────────┐  ← 調剤カウンター（処方箋受付）
│   調剤        │     待ち時間の間、客は店内を回遊する
└──────────┘
```

売場の動線そのものが、粗利の低い方から高い方へ客を流すように設計されている。
「調剤の待ち時間に買い物をしてもらう」のは、単なる親切ではなく**滞在時間＝購買機会の設計**である。

## 3. 客数×客単価の分解 ── 伸びの正体

小売の売上は必ず `客数 × 客単価` に分解できる。ドラッグストアの成長はこの両輪で説明できる。

| 要素             | 打ち手                                             | 効果                                                                            |
| ---------------- | -------------------------------------------------- | ------------------------------------------------------------------------------- |
| 客数（新規）     | 出店。ロードサイド・小商圏への高密度出店           | 2025年度で店舗数2万4,536店（JACDS推計、+813店）                                 |
| 客数（来店頻度） | **食品の安値**。週1回の買い物が週2〜3回に          | 物価高局面で特に効く。ウエルシアの2026年3〜6月客数は前年同期比+1.3%と報じられる |
| 客単価（点数）   | 食品ついでに医薬品・化粧品を買わせる「ついで買い」 | 粗利ミックスの実行部分                                                          |
| 客単価（単価）   | 調剤の取り込み。1回あたり単価が物販より大きい      | 調剤額は2025年度1兆6,586億円（+9.1%、JACDS）                                    |

> なぜ「食品で来店頻度を上げる」ことが決定的なのか。
> 医薬品は**必要なときしか買わない**（風邪をひいたとき、切り傷ができたとき）。
> 待っていても客は来ないので、**毎日買うもの＝食品で先に店に来てもらい、必要が生じたときに思い出してもらう**構造を作る。
> 医薬品は「来店ついでに買う商品」に変わり、高粗利カテゴリの回転が上がる。

## 4. 調剤併設の収益性 ── もう一つの高粗利カテゴリ

調剤（処方箋を受けて薬を渡す事業）は、物販とは経済性が違う。

| 論点           | 物販（OTC・食品）      | 調剤                                                 |
| -------------- | ---------------------- | ---------------------------------------------------- |
| 価格の決まり方 | 店が自由に決める       | **国が決める**（薬価基準・調剤報酬）                 |
| 値引き競争     | 激しい                 | 構造的に起きない（患者の自己負担割合は保険で決まる） |
| 代金の出所     | 客の財布               | 大半が健康保険（公費・保険料）                       |
| 需要の性質     | 景気・天候に左右される | 高齢化で安定的に増える                               |
| リスク         | 価格競争               | **制度改定リスク**。2年ごとの改定で一律に収益が動く  |

- 2025年度の調剤額は1兆6,586億円で、ドラッグストア売上の15.6%。全国の調剤医療費に対するシェアは19.7%（暫定値、JACDS）。**処方箋の5枚に1枚がドラッグストアで応需されている**計算になる。
- 伸び率も業界平均より高い。2024年度は+8.4%、2025年度は+9.1%。全国の保険調剤医療費の伸び（2024年度で+1.6%）を大きく上回っており、**独立系の調剤薬局からシェアを奪っている**構図が読める。
- 一方で2026年度調剤報酬改定では、敷地内薬局（医療機関の敷地内に置く薬局）の評価が厳しくなり、集中率（特定の医療機関からの処方箋が占める割合）の基準が95%以上→85%以上へ厳格化された。**制度で収益が変わる事業である**ことの実例。
- 隣接する業界の構造は [調剤薬局](../../09_医薬・医療・ヘルスケア/07_調剤薬局/README.md) を参照。

## 5. この構造が食品スーパーを苦しめる仕組み

```
    【需要は一定、供給が増える】

  ある町の食品需要 ────────────────────
                       ↑              ↑
                  食品スーパー      ドラッグストア
                  （粗利25%必要）   （粗利15%で十分）
                       │              │
                  価格を下げると      価格を下げても
                  即・赤字            医薬品が支える
                       │              │
                       ▼              ▼
                   客数が減る        客数が増える
                       │              │
                  固定費が重くなる    固定費が薄まる
                       │              │
                       ▼              ▼
                    悪循環            好循環
```

食品スーパーから見ると、**同じ商品を自分より安く売る相手が、自分より高い利益率で立っている**という状況になる。
これは努力の差ではなく、**損益計算書の構造の差**なので、価格で追いかけると自滅する。

### 食品スーパー側の対抗手段

| 手段             | 内容                                                      | 限界                                                                                    |
| ---------------- | --------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| 生鮮で差別化     | 青果・鮮魚・精肉の鮮度と品揃え。DgSが入りにくい領域だった | ウエルシアが2025年8月に生鮮入りの「ドラッグ＆フード型店舗」を開始。この聖域も崩れ始めた |
| 惣菜・中食の強化 | 加工度を上げて粗利を稼ぐ。DgSは調理設備を持ちにくい       | 人手と設備が要る。人件費上昇が直撃                                                      |
| PBによる原価低減 | 自社ブランドで中間マージンを取り込む                      | DgSも同じことをしており、規模で負ける                                                   |
| 規模統合         | 地域スーパー同士の統合で仕入を強化                        | 進行中だが、DgSの再編速度に追いつきにくい                                               |

> 逆に言うと、ドラッグストアが食品に深入りするほど**全体の粗利率は下がる**。
> コスモス薬品は食品比率62.9%（2026年5月期）で営業利益率3.9%、化粧品に強いマツキヨココカラは7.6%。
> 食品を取り込む戦略は「売上は伸びるが利益率は薄まる」トレードオフを抱えている。ここが次の論点になる。

## 6. 企業ごとに「別の商売」になっている

同じドラッグストアでも、カテゴリ構成が違えば経済性が全く違う。

| 企業                        | 直近売上高                | 営業利益率 | カテゴリの特徴                            | 実質的に近い業態             |
| --------------------------- | ------------------------- | ---------- | ----------------------------------------- | ---------------------------- |
| マツキヨココカラ&カンパニー | 1兆1,174億円（26年3月期） | 7.6%       | ヘルス&ビューティ構成比72.4%、PB比率14.8% | 化粧品専門店＋薬局           |
| サンドラッグ                | 8,425億円                 | 5.6%       | 都市型DgS＋ディスカウント（ダイレックス） | 二毛作                       |
| スギHD                      | 1兆103億円（26年2月期）   | 4.8%       | 調剤併設率が高い                          | 薬局チェーン＋小売           |
| ツルハHD                    | 1兆4,505億円（26年2月期） | 4.3%       | 地域網羅型。統合直後でのれん償却負担      | 総合型                       |
| コスモス薬品                | 1兆996億円（26年5月期）   | 3.9%       | 一般食品62.9%、EDLPで値引きしない         | **食品ディスカウントストア** |
| 薬王堂HD                    | 1,638億円                 | 3.2%       | 東北の小商圏、食品比率高い                | 小型食品スーパー             |

数値は2026年に発表された各社決算（IR・報道ベース）。

「ドラッグストア業界の平均粗利率」を語ってもあまり意味がなく、**各社のカテゴリ構成比を見ないと収益構造が分からない**。
分析するときはIR資料の「商品別売上構成」と「部門別売上総利益率」を最初に開くのが早い。

## 7. まとめ ── 3つの因果

1. **医薬品・化粧品という高粗利カテゴリを持っていることが、食品を安く売る原資になる。** これが客数を生む。
2. **客数が増えると固定費（家賃・人件費）が薄まり、さらに安くできる。** 規模の好循環に入る。
3. **調剤を併設すると、制度に守られた安定収益が乗る。** 物販の景気変動を吸収する。

この3つが噛み合ったことが、小売業態のなかでドラッグストアだけが伸び続けた理由である。
逆に、崩れるとしたら **①食品比率が上がりすぎて粗利ミックスが崩れる ②制度改定で調剤が痩せる ③出店余地がなくなり客数が伸びなくなる** の3つのどれかになる。
制度側のリスクは [02_規制と資格](02_規制と資格.md)、出店と再編の限界は [03_業界再編と競争](03_業界再編と競争.md) で扱う。

## 用語メモ

| 用語                       | 意味                                                                               |
| -------------------------- | ---------------------------------------------------------------------------------- |
| **粗利率（売上総利益率）** | 売上に対する「売上－売上原価」の割合。小売の稼ぐ力を最初に見る指標                 |
| **粗利ミックス**           | 粗利率の異なるカテゴリの構成比を調整し、全体の粗利率を設計すること                 |
| **ロスリーダー**           | 利益を削って安く売り、客を呼ぶための商品。日本語では客寄せ商品                     |
| **客単価**                 | 1人の客が1回の買い物で使う金額。`買上点数 × 1点単価` に分解できる                  |
| **既存店前年比**           | 新規出店を除いた、1年以上営業している店の売上の前年比。実力を見る指標              |
| **EDLP**                   | Every Day Low Price。特売をせず常時低価格にする方式。販促費と値札替えの手間が減る  |
| **調剤報酬**               | 保険薬局が調剤で受け取る技術料。2年ごとに国が改定する                              |
| **集中率**                 | ある薬局の処方箋のうち、特定の医療機関から来る割合。高いほど報酬上は不利に扱われる |
| **のれん**                 | 買収額が買収先の純資産を上回った差額。会計上、償却や減損で利益を圧迫することがある |
