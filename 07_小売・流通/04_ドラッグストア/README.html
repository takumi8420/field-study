ドラッグストア（DgS）は、医薬品・化粧品・日用品・食品を1店舗で扱う小型総合小売である。
日本の小売業態のなかで、この30年で最も伸びた業態であり、2024年度に売上10兆円を超えた（日本チェーンドラッグストア協会＝JACDS推計）。

ポイント：この業態を理解する鍵は「薬屋」ではなく 「高粗利の薬・化粧品で稼ぎ、低粗利の食品で客を呼ぶ」という粗利ミックス にある。
薬で得た利益を食品の安さに回せるので、食品スーパーと同じ土俵で価格勝負をしても耐えられる。ここが成長の源泉であり、他業態を苦しめている構造でもある。

1. 業界の定義・範囲

「ドラッグストア」に法律上の定義はない。実務上は次の3条件をおおむね満たす店を指す。

  1. 一般用医薬品（OTC医薬品＝処方箋なしで買える薬）を扱う
  2. 化粧品・日用品（トイレタリー）を主力に持つ
  3. セルフサービス方式のチェーン店である

経済産業省の商業動態統計では、「医薬品・化粧品小売業に属し、一般用医薬品を扱い、かつセルフサービス方式を採用する事業所」をドラッグストアとして集計している。

付加価値がどこに溜まるかを見ると、この業態の特徴が分かる。

  • メーカー寄り：医薬品・化粧品はブランドと薬事の壁があるため、メーカーの価格支配力が比較的強い。ただしDgS側の販売シェアが上がるにつれ、棚を握る小売の交渉力が増した。
  • 小売寄り：日用品・食品はブランド差がつきにくく、規模で仕入れる側が強い。PB（プライベートブランド＝小売の自社企画商品）にすると中間マージンを取り込める。
  • 保険寄り：調剤は価格（薬価・調剤報酬）が国の制度で決まるため、値引き競争が起きない代わりに制度改定で一律に収益が動く。

5. 収益モデル・コスト構造

1店舗の経済性が全て。標準的な郊外型DgS（売場200〜300坪、年商5〜6億円）を単純化するとこうなる。

売上高                       100%
 └ 売上原価                  △72%   ← 食品は原価率85%前後、医薬品は60%前後
売上総利益（粗利）              28%   ← カテゴリ構成で 20%〜32% と大きくブレる
 ├ 人件費                    △11%   ← 登録販売者主体だと薬剤師より安く済む
 ├ 地代家賃                   △4%   ← 郊外ロードサイドなら安い
 ├ 水道光熱・販促・その他        △9%
営業利益                       4%    ← 大手で3〜8%
  • 粗利率は業態内でも大きく違う。化粧品比率の高いマツキヨココカラは営業利益率7.6%、食品6割のコスモス薬品は3.9%。同じ「ドラッグストア」でも別の商売をしている。
  • 固定費（家賃・人件費）が先に立つので、客数が命。だから低価格の食品で来店頻度を作る。
  • 変動費の中心は仕入原価。ここを下げる手段が規模（バイイングパワー）とPBであり、M&Aの動機になる。
  • 詳細な粗利ミックスの説明は 01_粗利ミックスの経済学。

6. 競争要因（KSF）と参入障壁

要因 中身 効き方
粗利ミックス設計高粗利カテゴリの構成比を保ちつつ、低粗利の食品で客数を取る最重要。崩れると食品スーパーと同じ利益率になる
規模による仕入価格数千店規模の一括仕入。PB開発の最低ロットも規模次第上位集中が進む直接の理由
立地と商圏の押さえロードサイド・駅前の好立地は有限。ドミナント（地域集中出店）で物流と広告を効かせる先行者が強い。後発は買収で入るしかない
有資格者の確保登録販売者・薬剤師がいないと医薬品を売れない制度が作った参入障壁。02_規制と資格
調剤の取り込み医療機関の近くに調剤併設店を置ける立地力とオペレーション単価と来店頻度を底上げ
物流・情報システム多温度帯（常温・冷蔵・冷凍）への対応が食品強化の前提食品を本気でやるほど投資が重い

参入障壁は「免許」だけではない。資格者の頭数＋好立地＋仕入規模の3点セットが揃わないと戦えないため、新規に全国チェーンを作るのは事実上不可能になっている。

7. 規制・法制度

骨格は 医薬品医療機器等法（薬機法） と 健康保険制度（調剤報酬・薬価） の二本。

  • 販売区分：要指導医薬品／第1類／第2類／第3類。第2類・第3類は登録販売者（2009年創設の公的資格）で販売できる。これがDgSの多店舗展開を可能にした最大の制度要因。
  • 2026年5月1日施行の改正薬機法：「指定濫用防止医薬品」という新区分の創設、要指導医薬品のオンライン販売解禁（特定要指導医薬品を除く）など。
  • 零売（処方箋なしでの医療用医薬品販売）は2025年5月公布の改正薬機法で原則禁止の方向へ。公布から2年以内（＝2027年5月まで）に施行。
  • OTC類似薬の保険給付見直し：2025年6月の3党合意を受け、市販薬と成分が似た処方薬に患者の追加負担を課す方向。77成分・約1,100品目が対象と報じられる。
  • 調剤報酬改定（2026年度）：敷地内薬局への評価厳格化、集中率の基準を95%→85%へ。

詳しくは 02_規制と資格。

8. 最近のトピック

→ 04_直近トピック_2026

  1. ツルハHD×ウエルシアHDの統合が2025年12月に完了。さらに2026年1月にイオンがツルハHDをTOBで連結子会社化（議決権50.11%）。イオン傘下に売上2兆円級のDgS連合ができた。
  2. 改正薬機法が2026年5月1日に施行。市販薬の過量服用（オーバードーズ）対策として指定濫用防止医薬品が新設され、販売時の確認・記録が義務化。同時に要指導医薬品のオンライン販売が解禁された。
  3. OTC類似薬の保険給付見直しが2026年度から段階的に動き出す方向。処方薬から市販薬へ需要が移れば、DgSにとっては追い風だが、調剤側には逆風になる。
  4. 食品強化が次の段階へ。ウエルシアが生鮮を扱う「ドラッグ＆フード型店舗」を2025年8月に開始。コスモス薬品は食品62.9%。食品スーパーとの競合が正面衝突に。
  5. 出店余地の縮小。2万店超に達し、好立地の奪い合いと商圏重複が課題。成長の主役が出店からM&Aとシェア奪取に移りつつある。

9. 用語メモ

用語 意味
OTC医薬品Over The Counter。処方箋なしで買える一般用医薬品。「カウンター越しに売る薬」の意
登録販売者2009年の改正薬事法で創設された公的資格。第2類・第3類のOTC医薬品を販売できる。薬剤師より養成が容易 → 02
調剤併設店舗内に保険薬局を併設し、処方箋を受け付ける形態 → 01
粗利ミックス粗利率の異なる商品を組み合わせ、全体の粗利率を設計すること → 01
PB（プライベートブランド）小売が企画し、製造委託して自社ブランドで売る商品。中間マージンを取り込める
EDLPEvery Day Low Price。特売をせず常に安く売る方式。チラシ・値札替えのコストが減る
ドミナント戦略特定地域に集中出店し、物流・広告・人員配置の効率を上げる出店方法
インバウンド免税訪日外国人向けの消費税免税販売。化粧品・医薬品が中心で都市型DgSの収益源
薬機法医薬品医療機器等法。医薬品・化粧品・医療機器の製造販売と広告を規律する法律
