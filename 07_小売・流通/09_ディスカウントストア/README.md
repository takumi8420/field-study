# ディスカウントストア

- 大分類: 小売・流通
- 状態: done
- 更新日: 2026-09-20

ディスカウントストア（DS）は、単に値札が安い店ではない。
**低粗利でも利益が残るよう、仕入れ・売場・人員・立地を最初から低コストに設計した業態**である。

> 競争力は「安売り」ではなく、安く売っても壊れない費用構造にある。
> ただしドン・キホーテ、業務スーパー、トライアル、コストコは同じDSでも儲け方が違う。
> 企業比較では売価より、**粗利率・在庫回転・販管費率・会費やPBの有無**を見る。

## 1. 業界の定義・範囲

日本の公的統計に「ディスカウントストア」という明確な業態区分はない。
この教材では、継続的な低価格を中核価値とし、総合品または食品を低コストで販売する店を扱う。

| 類型 | 代表例 | 安さと利益の作り方 |
| --- | --- | --- |
| 時間消費・総合DS | ドン・キホーテ | スポット仕入れ、圧縮陳列、深夜、商品探索の娯楽性 |
| 食品DS・EDLP | トライアル、オーケー、ロピア | 食品の高回転、低販管費、定番品の毎日低価格 |
| FC＋自社製造 | 業務スーパー | 加盟店の資本、自社輸入・製造、簡素な店 |
| 会員制倉庫店 | コストコ | 年会費を利益源にし、商品粗利を抑える |

[100円ショップ](../08_100円ショップ/README.md)は均一価格、アウトレットは過年度・余剰品、
[リユース](../16_リユース・中古/README.md)は中古品という別の仕入れ構造なので分けて考える。

## 2. 市場規模と成長性

統一定義がないため、DS全体の精密な市場規模や企業別シェアは作れない。
小売市場全体から「DSだけ」を切り出した民間推計は、食品スーパーやGMSをどこまで含めるかで大きく変わる。

代わりに、主要企業の実績と隣接市場を追う。

| 観測点 | 直近値 | 意味 |
| --- | ---: | --- |
| PPIH売上高 | **2兆4,452億円** | 2026年6月期。国内DS、GMS、海外を含む |
| PPIH国内DS売上 | **1兆5,507億円** | ドン・キホーテ等。DS中核の規模感 |
| PPIH免税売上 | **2,286億円** | 同期、前年比31.2%増。インバウンドの寄与 |
| トライアルHD売上高 | **約1.3兆円** | 2026年6月期、西友を連結した統合初年度 |

DSは物価上昇で節約需要を取り込む一方、自社も仕入れ、人件費、電気代、物流費の上昇を受ける。
したがって**売上が伸びても利益率が上がるとは限らない**。

## 3. バリューチェーン

```
メーカー ─┬─ 定番品の大量仕入れ ─────────┐
          ├─ 余剰・旧型・終売品のスポット仕入れ ┤
海外工場 ─┴─ 直輸入/PB ─────────────────┤
                                             ▼
              物流センター ─▶ DS店舗/EC ─▶ 消費者
                    ▲              │
                    └── POSデータ ─┘ 売れ筋を発注へ戻す

会員制：消費者 ─▶ 年会費 ─▶ 商品粗利を薄くできる
FC型 ：加盟店 ─▶ 出店資本 ─▶ 本部は卸・ロイヤルティで回収
```

定番品は大量購入で値引きを取り、スポット品はメーカーの在庫処分を引き受けて安く買う。
PB・直輸入では中間マージンを省けるが、売れ残りと品質事故を自社で負う。

## 4. 主要プレイヤー

| 企業・業態 | 立ち位置 | 特徴 |
| --- | --- | --- |
| PPIH（ドン・キホーテ） | 総合DS最大手 | 深夜、圧縮陳列、権限委譲、インバウンド。ユニーも保有 |
| トライアルHD | 食品DS＋小売テック | 西友を統合。セルフレジ、データ、食品製造を組み合わせる |
| オーケー | EDLP食品スーパー | 会員割引、現金・低コスト、関西出店を拡大 |
| OICグループ（ロピア） | 生鮮・食品DS | 売場部門の専門店性と高い客数、国内外へ出店 |
| 神戸物産（業務スーパー） | FC＋製販一体 | 自社工場、輸入、加盟店で資本負担を分散 |
| コストコ | 会員制倉庫店 | 年会費、限定SKU、大容量、世界共通調達 |

企業別シェアを1枚で示すより、どの類型の収益モデルかを分けるほうが実態に近い。

## 5. 収益モデル・コスト構造

```
売上高 100
  − 商品原価 75〜80       → 粗利 20〜25
  − 人件費 8〜11
  − 家賃・償却 3〜5
  − 物流・光熱・決済等 5〜8
  ＝ 営業利益 2〜6

★薄い粗利なので、販管費が1ポイント増える影響が大きい。
```

| 利益レバー | 何をするか | 副作用 |
| --- | --- | --- |
| 高回転 | 食品・日用品を大量に売る | 欠品すると客が離れる |
| 低人件費 | 箱陳列、セルフレジ、作業標準化 | 接客不足、万引き、不正会計リスク |
| 低家賃 | 二等立地、居抜き、簡素な内装 | 来店の不便さ |
| PB・直輸入 | 比較されない商品で粗利を取る | 在庫・為替・品質を自社で負う |
| 年会費 | 商品以外で利益を作る | 更新率と会員価値の維持が必要 |

## 6. 競争要因（KSF）と参入障壁

| KSF | なぜ効くか |
| --- | --- |
| 調達量と仕入先ネットワーク | 定番品の条件と、余剰品の情報が先に回る |
| 物流密度 | 店が密集するほど1店あたり配送費が下がる |
| 店舗作業の削減 | 値札変更、品出し、レジの時間が価格に直結 |
| 商品ミックス | 目玉商品で集客し、比較されにくい商品で粗利を取る |
| データと現場権限 | 地域・時間帯ごとの需要へ早く反応する |
| 食品の鮮度・製造能力 | 来店頻度を上げるが、廃棄と衛生管理が難しい |

参入自体は可能でも、安さを継続するには規模、物流、資金、仕入信用が要る。
模倣店は安売りだけを先に行い、粗利不足で継続できなくなりやすい。

## 7. 規制・法制度

| 制度 | 影響 |
| --- | --- |
| 大規模小売店舗立地法 | 大型店出店時の交通・騒音・廃棄物対策 |
| 食品衛生法 | 生鮮・惣菜・自社製造を強めるほど管理範囲が広がる |
| 景品表示法 | 二重価格、「最安」表示、比較広告の根拠が必要 |
| 独占禁止法・下請法 | 納入業者への協賛金、返品、値下げ負担の押し付けを規制 |
| 酒税法・医薬品医療機器等法 | 酒類・医薬品の免許、資格、売場管理 |
| 消費税免税制度 | 2026年11月からリファンド方式。インバウンド店の実務が変化 |

## 8. 最近のトピック

詳細は [④ 直近トピック（2026年9月）](04_直近トピック_2026.md)。

1. PPIHは2026年6月期に売上2兆4,452億円、営業利益1,748億円で過去最高圏
2. 国内DSの免税売上は2,286億円。国籍分散が進み、観光後の夜間購買を取った
3. 食品強化型ドンキ「ロビン・フッド」など、非食品DSも来店頻度を求めて食品へ寄る
4. トライアルは西友を統合して売上約1.3兆円となったが、統合費用で最終利益が大幅減
5. オーケーは関西、ロピアは国内外、業務スーパーはFCで出店を続ける
6. 最低賃金・物流費・電力費の上昇で、低販管費モデルの余白が狭まっている

## 9. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **DS** | Discount Store。継続的な低価格を中核にする小売業態 |
| **EDLP** | Every Day Low Price。特売日でなく毎日低価格にする政策 |
| **スポット仕入れ** | 余剰・終売・旧型などを一回限りの好条件で買うこと |
| **圧縮陳列** | 商品を高密度に並べ、探索性と安売り感を演出する売場 |
| **ロスリーダー** | 採算を抑えて集客に使う目玉商品。他の商品で利益を回収する |
| **PB** | 小売が企画し、自社名等で販売する商品 |
| **販管費率** | 人件費・家賃・広告等の販売管理費÷売上高 |
| **免税売上** | 訪日外国人等への消費税免税販売。制度変更の影響を受ける |
