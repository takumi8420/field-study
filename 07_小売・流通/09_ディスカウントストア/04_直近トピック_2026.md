## 2. 中国依存からの分散 — 「訪日客の4人に1人がドンキ」

免税売上の内訳で注目されたのは、**全国籍で前年を上回った**点と
**ヨーロッパが前期比67.3%増**という伸びである（訪日ラボ、2026年8月）。
2026年6月期3Q時点では中国からの売上が減少する局面もあったが、通期では全体が押し上がった。

ITmedia ビジネスオンライン（2026年8月19日）は、免税売上2,000億円超の背景として
**訪日客のおよそ4人に1人がドンキで免税購入している計算になる**と報じている（試算ベース）。

```
【 なぜ百貨店ではなくドンキに移ったか 】

  2015年頃「爆買い」            2025〜2026年
  団体旅行・高額ブランド品      個人旅行（FIT）・消耗品の大量購入
  百貨店／免税専門店            ドンキ／ドラッグストア／コンビニ
  昼間に買う                    観光の後、夜に買う（深夜営業が効く）
  1点あたり数万円               1点あたり数百〜数千円 × 大量
```

ただしこれは**為替と訪日者数に完全連動する収益**であり、構造的に安定したものではない。

## 3. 新業態「ロビン・フッド」始動 — 食品強化型ドンキ

2026年3月3日、PPIHは**新業態（食品強化型ドンキ）戦略発表会**を開催。
1号店「驚楽の殿堂 ロビン・フッド 甚目寺店」（愛知県あま市）を **2026年4月24日** に開店し、
岐阜・静岡・三重を含め**5店舗**を展開中（2026年夏時点）。

| 項目         | 内容                                                                             |
| ------------ | -------------------------------------------------------------------------------- |
| 位置づけ     | **狭小商圏型**の食品強化業態。従来のドンキより小さい商圏で成立させる             |
| 組み合わせ   | ドンキのディスカウント・演出ノウハウ × ユニーの食品調達力・商品開発力・物流網    |
| 売場設計     | 「迷わせない売り場」。圧縮陳列を残しつつ、食品は探しやすさを優先したと報じられる |
| 目標（報道） | **2035年までに200〜300店舗、売上6,000億円、営業利益360億円**を計画               |

> ポイント：ドンキの強みだった「迷わせる売場」を、食品では**あえて弱めている**。
> 食品は週2〜3回の日常買い＝短時間で買いたい商品であり、
> 時間消費型の設計と真っ向から矛盾する。ここをどう折り合わせるかが成否を分ける。
> → [業態の分化](02_業態の分化.md)

## 4. トライアルHD、西友統合1年目 — 売上1.3兆円だが最終利益は70%減

トライアルホールディングスの**2026年6月期連結決算**。西友を2025年7月1日付で完全子会社化し、
通期で連結した最初の期にあたる。

| 項目                   | 金額              | 前期比     |
| ---------------------- | ----------------- | ---------- |
| 売上高                 | 1兆3,471億900万円 | **+67.6%** |
| 営業利益               | 303億7,100万円    | +43.9%     |
| 経常利益               | 201億8,600万円    | **−9.1%**  |
| 親会社株主帰属当期利益 | 35億2,200万円     | **−70.0%** |

セグメント別。

| セグメント     | 売上高                     | 営業利益                 | 備考                                  |
| -------------- | -------------------------- | ------------------------ | ------------------------------------- |
| トライアル事業 | 8,861億3,800万円（+10.2%） | 343億6,500万円（+62.8%） | 既存店2.1%増                          |
| 西友事業       | 4,609億7,100万円           | 137億6,300万円           | 既存店10か月連続プラス、客数10%超回復 |

- 店舗数（2026年6月末）：トライアル378店（FC3店含む）＋西友243店＝**グループ計621店**
- 2027年6月期予想：売上高1兆4,582億円（+8.2%）、営業利益390億円（+28.4%）、
  **経常利益286億円（+41.7%）、純利益107億円（+203.8%）**
- 西友買収額は約3,800億円と報じられている（報道ベース）

```
【 買収直後の決算はこう歪む 】

  売上高      ＋67.6%  ← 西友を丸ごと足したので当然増える
  営業利益    ＋43.9%  ← 本業は改善している
  経常利益    −9.1%   ← ★買収資金の支払利息が乗る
  当期純利益  −70.0%  ← ★さらに買収関連費用・のれん等の一時要因

  → 「増収増益」と「最終減益」が同時に起きる。
     買収初年度は 営業利益 と 買われた側の既存店 を見るのが正しい。
```

2027〜2029年度の3か年中期経営計画では、**西友との経営統合を軸に、
トライアル本体の既存店強化・PB拡大・惣菜の伸長・リテールAIの収益化**を並行して進めるとしている。
買収による垂直統合で**物流コスト15%削減**を進めるとの報道もある（ビジネスジャーナル、2026年）。

> ポイント：**西友の既存店が10か月連続プラス、客数10%超回復**という点が最も重要。
> 買収後に価格を下げて客を戻せたかどうかが、PMI（統合作業）の成否を示す最初のシグナルになる。

## 6. コストは上がり続ける — 最低賃金は2026年度1,177円

2026年度の地域別最低賃金は**全国加重平均1,177円**（2025年度1,121円から**+56円**）。
目安制度が始まった1978年度以降で2番目の引き上げ幅とされる。
政府は「全国平均1,500円」の達成時期を2030年代前半のできる限り早期へ調整したと報じられている。

```
【 最低賃金の推移（全国加重平均） 】

  2023年度  1,004円  ┤████████████████████
  2024年度  1,055円  ┤█████████████████████
  2025年度  1,121円  ┤██████████████████████
  2026年度  1,177円  ┤████████████████████████
            ─────────────────────────────
            3年間で約17%上昇

  DSの人件費率は売上の8〜11%。
  時給が17%上がれば、人時を同率で削らない限り
  人件費率は1.4〜1.9ポイント悪化する。
  → 営業利益率2〜4%の食品特化型DSには致命傷になりうる。
```

これが**省人化投資（トライアルのリテールAI、セルフレジ、電子棚札、自動発注）が
「やったほうがいい」ではなく「やらないと死ぬ」投資になっている**理由である。
→ [成長の源泉と限界](03_成長の源泉と限界.md)

## 7. コストコは年会費で稼ぐモデルを維持 — 国内36倉庫店

- 日本国内の倉庫店は**36店**前後（1999年の福岡・久山倉庫店が1号店、報道ベース）
- **2025年5月更新分から年会費を改定**。ゴールドスター（個人）4,840円 → **5,280円**（+440円）。
  日本での値上げは約9年ぶり（前回2016年）
- 会費収入はほぼ全額が利益になるため、**値上げはそのまま営業利益の押し上げ要因**になる

> ポイント：他のDSが「商品を安く売って粗利で稼ぐ」のに対し、
> コストコは**会費というサブスクリプション収入が利益の柱**。
> だから商品は原価に近い価格で売り続けられる。**値上げの意味が他社と全く違う**。

## 8. 市場規模の数字をどう読むか

DSには統計上の業態区分がない（商業動態統計に「ディスカウントストア」の項目はない）。
流通している数値はすべて**調査会社や媒体が企業を選んで足し上げた推計**である。

| 数値                                         | 時点           | 出どころ                                           | 注意点                                                   |
| -------------------------------------------- | -------------- | -------------------------------------------------- | -------------------------------------------------------- |
| 国内DS市場 **初の4兆円規模**                 | 2022年度       | ダイヤモンド・チェーンストアオンライン（推計報道） | 2008年度1.7兆円の約2.4倍。どの企業を含むかで大きく変わる |
| 2023〜2025年度も増収傾向                     | 2023〜2025年度 | 帝国データバンク 業界動向                          | 定性的な傾向。金額は媒体により差                         |
| 世界のディスカウントデパート市場 5,456億ドル | 2026年         | 海外調査会社レポート（推計）                       | 日本の「DS」と定義が一致しない。**混ぜて使わない**       |

> ポイント：**「DS市場は◯兆円」という数字は、必ず「何を数えたか」とセットで扱うこと。**
> 企業単位の決算（PPIH 2.4兆円、トライアル1.3兆円、オーケー0.75兆円）を積み上げたほうが実態に近い。

## 9. 全体の構図（まとめ）

1. **利益はドンキ型が突出**。PPIHのDS事業は営業利益率7.1%で、食品スーパーの2〜3倍。
   その差を作っているのは非食品の粗利と**免税2,286億円**
2. **成長の主戦場は食品に移った**。ロビン・フッド（PPIH）、食品強化を続けるトライアル、
   生鮮フルのオーケー・ロピア。DSは「雑貨の店」から「食品の店」になった
3. **出店から買収へ**。トライアル×西友（621店）、OIC×スーパーバリュー。
   ただし買収初年度は最終減益（トライアル純利益−70.0%）になるので営業利益で見る
4. **コストは構造的に上がり続ける**。最低賃金は3年で約17%上昇。
   省人化とリテールメディアによる収益化が、生き残りの条件になった
5. **追い風の向きは型によって逆**。円安はドンキの免税に追い風、業務スーパーの直輸入には逆風。
   「DS業界は好調」という一言で束ねると読み違える

## 用語メモ

| 用語                      | 意味                                                                                                     |
| ------------------------- | -------------------------------------------------------------------------------------------------------- |
| **PPIH**                  | パン・パシフィック・インターナショナルホールディングス。ドン・キホーテ、ユニー（アピタ・ピアゴ）等を持つ |
| **DS事業／UNY事業**       | PPIHのセグメント名。前者がドンキ、後者がアピタ・ピアゴ（GMS）                                            |
| **免税売上**              | 訪日客向けの消費税免除販売額。PPIHのDS事業で2,286億円（2026年6月期）                                     |
| **ロビン・フッド**        | PPIHの食品強化型新業態。2026年4月開店。狭小商圏型で200〜300店を計画                                      |
| **狭小商圏型**            | 半径1km前後の小さい商圏を前提にした店舗設計                                                              |
| **PMI**                   | Post Merger Integration。買収後の統合作業。既存店の推移が成否のシグナルになる                            |
| **のれん**                | 買収額と買収先の純資産の差額。償却や減損で利益を圧迫することがある                                       |
| **TOB**                   | 株式公開買付け。市場外で株式を買い集めて子会社化する手法                                                 |
| **リテールAI**            | トライアル傘下の技術会社／同社の省人化・データ活用の取り組みの総称                                       |
| **デリバティブ評価損**    | 為替予約等の金融商品の時価評価による損失。神戸物産の四半期利益を振らす要因                               |
| **最低賃金 全国加重平均** | 都道府県別の最低賃金を労働者数で加重平均した値。2026年度1,177円                                          |
