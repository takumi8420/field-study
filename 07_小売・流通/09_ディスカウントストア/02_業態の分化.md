# 業態の分化

このノートで分かること：「ディスカウントストア」という一つの言葉で呼ばれている企業群が、
実際には**まったく違う儲け方をする4つ以上の型**に分かれていること。そして隣接業態との境界線。

> 結論：DSは業態名ではなく**価格政策の名前**である。
> ドン・キホーテ（時間消費型）、トライアル・ロピア（食品特化型）、業務スーパー（FC＋自社製造型）、
> コストコ（会員制ホールセール）は、同じ「安い店」でも損益の形がまるで違う。
> **どこで粗利を取っているか**を見れば、型の違いが一目で分かる。

## 1. 「ディスカウントストア」に統計上の定義はない

経産省「商業動態統計」に**ディスカウントストアという区分は存在しない**。
百貨店・スーパー・コンビニ・家電大型専門店・ドラッグストア・ホームセンターは区分があるが、
DSはそのどれかに散らばって計上される。

| 企業           | 統計上どこに入りやすいか | 実態                       |
| -------------- | ------------------------ | -------------------------- |
| ドン・キホーテ | 「スーパー」または対象外 | 総合ディスカウント         |
| トライアル     | スーパー                 | 食品中心のスーパーセンター |
| ロピア         | スーパー                 | 生鮮フル扱いの食品スーパー |
| 業務スーパー   | スーパー（FC各店）       | 実体は卸売＋製造           |
| コストコ       | 対象外（会員制卸売）     | ホールセールクラブ         |

このため「DS市場は◯兆円」という数字は、調査会社が企業を選んで足し上げた**推計**である。
代表的なものとして、**2022年度に国内DS市場が初めて4兆円規模に達した**（2008年度の約1.7兆円の約2.4倍）
との推計が報じられている（ダイヤモンド・チェーンストアオンライン、2022年）。
**必ず「どの企業を数えた推計か」を確認して読む**必要がある。

> ポイント：定義がないということは、**業態名で分類しても何も分からない**ということ。
> 分類するなら「価格政策（EDLPかHi-Loか）」「食品比率」「粗利の源泉」の3軸で見るほうが実態に合う。

## 2. 4つの型 — 粗利をどこで取っているか

```
【 粗利の源泉で見た4類型 】

              粗利の源泉
                  │
  ┌───────────────┼───────────────┐
  │               │               │
非食品・趣味品   食品の回転      会費・卸売
  │               │               │
  ▼               ▼               ▼
┌──────────┐  ┌──────────┐  ┌──────────┐
│ドン・キホーテ│  │トライアル  │  │コストコ    │
│（時間消費型）│  │ロピア      │  │（会員制）  │
│          │  │（食品特化）│  ├──────────┤
│ 粗利 30%  │  │ 粗利 19〜22%│  │業務スーパー│
│ 滞在時間で │  │ 客数と回転で│  │（FC＋製造）│
│ 買わせる  │  │ 稼ぐ       │  │ 卸売で稼ぐ │
└──────────┘  └──────────┘  └──────────┘
    ↑
 売場は「探す場所」    売場は「早く買う場所」   売場は「まとめ買いの場所」
```

| 型                     | 代表                         | 何で客を呼ぶか                 | 粗利の源泉                     | 営業利益率の目安            | 弱点                                       |
| ---------------------- | ---------------------------- | ------------------------------ | ------------------------------ | --------------------------- | ------------------------------------------ |
| **時間消費型**         | ドン・キホーテ（PPIH）       | 安さ＋宝探しの楽しさ＋深夜営業 | 非食品（化粧品・雑貨）と免税   | 7%前後（2026年6月期DS事業） | 客数が落ちると一気に弱い。インバウンド依存 |
| **食品特化型**         | トライアル、ロピア、オーケー | 生鮮を含む食品の安さ           | 食品の高回転と省人化           | 2〜4%                       | 損益分岐点が高い。立地の取り合い           |
| **FC＋自社製造型**     | 業務スーパー（神戸物産）     | 業務用サイズと輸入品の安さ     | FCへの卸売＋自社工場の製造益   | 7〜8%（2025年10月期前後）   | 為替・原料相場に直撃される                 |
| **会員制ホールセール** | コストコ                     | 大容量・限定品・体験           | **年会費**（商品の粗利は薄い） | 商品3%前後＋会費が利益の柱  | 出店ペースが遅い。商圏が非常に広い         |

### (1) 時間消費型 — ドン・キホーテ

**時間消費型**とは、「必要なものを買いに行く」のではなく「見に行く」店のこと。
滞在時間が長いほど買上点数が増えるため、圧縮陳列で迷わせ、深夜まで開け、
POPで笑わせる。売場は効率ではなく**滞在時間を最大化するように設計されている**。
→ [安く売って儲ける仕組み](01_安く売って儲ける仕組み.md)

PPIH（パン・パシフィック・インターナショナルホールディングス）の2026年6月期連結は
売上高2兆4,452億円（前期比8.8%増）、営業利益1,748億円（同7.7%増）。
DS事業（ドンキ）単独で売上1兆5,507億円・営業利益1,107億円＝**営業利益率約7.1%**と、
食品スーパーの2〜3倍の利益率を出している（出典：流通ニュース、2026年8月）。

この利益率を支えているのが**非食品の厚み**と**免税売上2,286億円（同31.2%増）**。
つまりドンキは「安い店」であると同時に、**日本で最も免税売上の大きい小売**でもある。

### (2) 食品特化型 — トライアル、ロピア、オーケー

食品を主戦場にするDSで、食品スーパーとの境界がほとんどない。
違うのは価格政策（EDLP）と作業設計（省人化・カットケース陳列）だけ。

| 企業                      | 直近の売上高                               | 特徴                                                           |
| ------------------------- | ------------------------------------------ | -------------------------------------------------------------- |
| **トライアルHD**          | 1兆3,471億円（2026年6月期、前期比67.6%増） | 西友を連結。スーパーセンター型＋リテールAI（後述）             |
| **オーケー**              | 7,544〜7,557億円（2026年3月期、約10%増）   | 「高品質・Everyday Low Price」。既存店106.4%、客数103.9%と強い |
| **ロピア（OICグループ）** | 5,213億円（2025年2月期、グループ合計）     | 精肉が看板。個店に権限を委譲。店舗数145店（2026年1月時点）     |

※出典：各社IR・流通ニュース・激流オンライン等の報道ベース。決算期が異なるため単純比較はできない。

**スーパーセンター**とは、食品・日用品・衣料・家電などをワンフロアの大型店（3,000〜6,000㎡級）で
ディスカウント価格で売る業態。米ウォルマートの型を日本に持ち込んだもので、トライアルが代表。
GMSと似ているが、**内装と接客を極限まで削った低コスト版**と考えると分かりやすい。
→ [スーパー・GMS](../02_スーパー・GMS/README.md)

ロピアは個店主義という点でドンキに近く、**各店の精肉担当が自分で仕入れ・値付けをする**。
「食生活♥♥ロピア」という屋号の通り、チェーンの均質性より現場の裁量を優先する。

### (3) FC＋自社製造型 — 業務スーパー（神戸物産）

最も誤解されやすい型。**神戸物産は店をほとんど直営していない**。

```
【 神戸物産のお金の流れ 】

   自社工場（国内） ─┐
   （麺、豆腐、菓子、 │
     冷凍食品 等）    │
                      ├─▶ 神戸物産 ─(卸売)─▶ FC加盟店 ─(小売)─▶ 客
   海外メーカー ──────┘      ★ここが売上         ★ここは加盟企業の売上
   （直輸入）                  （BtoB＝卸売）        （神戸物産の連結売上ではない）

   神戸物産の利益 ＝ 製造マージン ＋ 卸売マージン ＋ ロイヤリティ
                     ↑ 店舗の人件費・家賃は加盟店が負う
```

**FC（フランチャイズ）**とは、本部がブランド・商品・運営ノウハウを提供し、
加盟店が自分の資本で店を出して売上の一部を本部に払う仕組み。
神戸物産は店舗の固定費リスクを加盟店に移しつつ、商品供給で稼ぐ。
だから**営業利益率7〜8%という小売離れした水準**が出る。

2026年10月期第3四半期（2025年11月〜2026年7月）の連結売上高は4,329億円（前年同期比5.2%増）、
営業利益313億円（同3.2%増）。業務スーパーの店舗数は2026年4月末時点で1,137店
（出典：神戸物産IR、日本食糧新聞）。中期計画では2026年10月期に1,130店超を目標としていた。

同じFCでもコンビニとは性格が違う。コンビニは**日販と廃棄**で本部の収益が決まるが、
業務スーパーは**卸した商品代金**で決まる。→ [コンビニエンスストア](../01_コンビニエンスストア/README.md)

### (4) 会員制ホールセールクラブ — コストコ

**ホールセールクラブ**とは、年会費を払った会員だけが買える倉庫型の卸売店。
日本では1999年の福岡・久山倉庫店が1号店で、**2026年時点で国内36倉庫店**前後（報道ベース）。

コストコの損益は他のDSと決定的に違う。

```
【 コストコの利益の出どころ 】

  商品売上 100
   ├─ 仕入原価  約 88      ← 粗利率11〜13%。小売として極端に薄い
   └─ 粗利      約 12
        ├─ 販管費 約 9〜10   人件費は高賃金だが、SKUを絞り作業を削って総額を抑える
        └─ 商品の営業利益 約 2〜3

  ＋ 会費収入（ほぼ全額が利益）
        日本のゴールドスター（個人）年会費 5,280円（2025年5月改定、従来4,840円）
        ↓
  営業利益の大半を会費が作る ＝ 商品はほぼ原価で売ってよい
```

> ポイント：コストコは**小売の顔をしたサブスクリプション事業**である。
> 「会費を払った以上、元を取らねば」という心理が来店頻度と客単価を押し上げる。
> 他のDSが真似できないのは、**会費を払ってもらえるだけの「ここでしか買えない感」**が要るから。

## 3. ディスカウントとEDLPスーパーの違い

「オーケーはDSか食品スーパーか」という問いは、実務ではあまり意味がない。
分けるとすれば次の2軸になる。

```
                  食品比率 高い
                        ▲
        ロピア ●        │        ● オーケー
      トライアル ●      │        ● 食品スーパー（標準）
                        │
  EDLP ◀────────────────┼────────────────▶ Hi-Lo（特売型）
                        │
      業務スーパー ●    │        ● GMS
        コストコ ●      │        ● ドン・キホーテ
                        │        （実は特売・目玉主導のHi-Lo色も強い）
                        ▼
                  食品比率 低い
```

| 観点             | ディスカウントストア                         | EDLPスーパー         |
| ---------------- | -------------------------------------------- | -------------------- |
| 何を削るか       | 品揃え・内装・接客・作業                     | 主にチラシと特売作業 |
| 生鮮の扱い       | 企業により大差（ロピアは厚い、ドンキは薄い） | 厚い。生鮮が集客の核 |
| 売場の性格       | 非日常・まとめ買い・宝探し                   | 日常・週2〜3回の来店 |
| 客単価／来店頻度 | 高単価・低頻度になりやすい                   | 低単価・高頻度       |

実際には両者は融合しつつある。オーケーは生鮮フルラインのEDLPスーパーだが価格政策はDS、
トライアルはDSだが生鮮を強化し続けている。**境界はすでに消えかけている**。
→ [食品スーパー](../03_食品スーパー/README.md)

## 4. 隣接業態との境界

| 隣接業態             | 重なる部分               | 決定的に違う部分                                                 | ノート                                           |
| -------------------- | ------------------------ | ---------------------------------------------------------------- | ------------------------------------------------ |
| **食品スーパー**     | 生鮮を含む食品全般       | SMは鮮度と品揃えで選ばれる。DSは価格で選ばれる                   | [食品スーパー](../03_食品スーパー/README.md)     |
| **GMS**              | 衣食住のワンストップ     | GMSはテナント・不動産収益も持つ。DSは物販に純化                  | [スーパー・GMS](../02_スーパー・GMS/README.md)   |
| **ドラッグストア**   | 食品・日用品の低価格販売 | DgSは調剤・医薬品・化粧品の高粗利が利益源。食品は撒き餌          | [ドラッグストア](../04_ドラッグストア/README.md) |
| **100円ショップ**    | 低価格・高回転           | 100均は**単一価格**が前提。値付けの自由がない                    | [100円ショップ](../08_100円ショップ/README.md)   |
| **ホームセンター**   | 大型・郊外・日用品       | HCはプロ客（職人）需要とDIYの専門性が軸                          | [ホームセンター](../07_ホームセンター/README.md) |
| **アウトレット**     | 型落ち・余剰在庫の処分   | アウトレットは**メーカー／ブランド側の在庫処理チャネル**         | [アパレル・SPA](../10_アパレル・SPA/README.md)   |
| **リユース（中古）** | 安さ、一点物、宝探し     | 仕入れが**一般消費者からの買い取り**。原価の考え方が根本的に違う | [リユース・中古](../16_リユース・中古/README.md) |
| **家電量販**         | 価格訴求、ポイント還元   | 家電は単価が高くメーカー支援金・長期保証が収益に絡む             | [家電量販](../06_家電量販/README.md)             |

### アウトレットとの違い

**アウトレット**は「小売業態」というより**流通チャネルの名前**である。
メーカーやSPA（製造小売）が、自社の型落ち品・B級品・過剰在庫を
ブランド価値を毀損せずに処分するための出口として使う。

```
【 余剰在庫が向かう3つの出口 】

              メーカー／ブランドの余剰在庫
                        │
      ┌─────────────────┼─────────────────┐
      ▼                 ▼                 ▼
  アウトレット      DSのスポット仕入れ    廃棄・焼却
  （自社で運営）    （第三者に売る）      （ブランド保護）
  ブランド管理可    ブランド管理不可      最も損失が大きい
  値引きは自分で    買い叩かれる          近年は批判が強く減少
  決められる        が、現金化が速い
```

DSがスポット仕入れで買うのは、この真ん中のルート。
**アウトレットは売り手側の装置、DSは買い手側の装置**という関係にある。

### リユースとの違い

リユース（中古）は、仕入れが**一般消費者からの買い取り**であるため、
原価が「相場」ではなく「買い取り査定額」で決まる。在庫は一点物で、同じ商品が二度と入らない。
「宝探し」という体験はDSと似ているが、**査定の目利きと真贋判定という別のノウハウ**が要る。
→ [リユース・中古](../16_リユース・中古/README.md)

## 5. 型の違いは、弱点の違いでもある

| 型                         | 効く追い風                                         | 効く逆風                                       |
| -------------------------- | -------------------------------------------------- | ---------------------------------------------- |
| 時間消費型（ドンキ）       | インバウンド、円安、節約志向、深夜需要             | 訪日客減、円高、客数減（損益分岐点が高い）     |
| 食品特化型（トライアル等） | 節約志向、食品値上げ、人手不足（省人化で差がつく） | 最低賃金上昇、出店余地の減少、競合のEDLP化     |
| FC＋製造型（業務スーパー） | 節約志向、円安時の国内製造回帰                     | **為替**（直輸入なので円安は原価高）、原料相場 |
| 会員制（コストコ）         | 大容量志向、体験消費、会員の固定化                 | 出店の遅さ、世帯人数の減少、年会費への抵抗     |

同じ「節約志向」という追い風でも、業務スーパーには**円安が原価高として跳ね返る**一方、
ドンキには**円安が免税売上の増加として効く**。**追い風の方向が型によって逆向きになる**。

> ポイント：「DS業界は好調」というヘッドラインは、実は4つの別々の話を束ねている。
> 決算を読むときは、まず**その企業がどの型か**を確認すること。

## 用語メモ

| 用語                         | 意味                                                                         |
| ---------------------------- | ---------------------------------------------------------------------------- |
| **時間消費型**               | 目的買いではなく「見に行く」店。滞在時間の長さが買上点数に直結する           |
| **スーパーセンター**         | 食品・日用品・衣料・家電をワンフロアの大型店で安く売る業態。トライアルが代表 |
| **ホールセールクラブ**       | 年会費制の倉庫型卸売店。商品粗利は薄く、会費が利益の柱。コストコ             |
| **FC（フランチャイズ）**     | 本部がブランド・商品を供給し、加盟店が自己資本で出店する仕組み               |
| **製販一体**                 | 製造と販売を同一グループが持つこと。神戸物産が掲げる                         |
| **免税売上**                 | 訪日客向けの消費税免除販売。PPIHのDS事業で2,286億円（2026年6月期）           |
| **アウトレット**             | メーカー・ブランドが自社の余剰在庫を処分する流通チャネル。業態名ではない     |
| **リユース**                 | 中古品の買い取り・販売。仕入れが一般消費者からなので原価構造が全く違う       |
| **カークランドシグネチャー** | コストコのPB。全世界共通で数量が桁違いに大きい                               |
| **情熱価格**                 | PPIHのPB。顧客の声を反映して作り直す方式を掲げる                             |
| **個店主義**                 | 仕入れ・値付け・陳列を各店の裁量に任せる方式。ドンキ、ロピアが採用           |
| **SPA**                      | 製造から小売までを一社で担う形態（製造小売）。ユニクロ等                     |
