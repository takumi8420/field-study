# ラグジュアリーと大衆品の二極化

このノートで分かること：この業界の利益は、**欧州の3つのコングロマリット（複合企業）**に集中している。強さの源泉は製造技術ではなく「**値上げしても客が離れないブランドを何本持っているか**」に尽きる。その対極で日本勢は「大衆品を大量に効率よく回す」側に立つ。この構図と、金価格・二次流通・免税・偽造品という4つの外部要因を整理する。

---

## 1. 結論：真ん中が消え、上と下だけが残る

```
【価格帯別の生存状況（2020年代半ば）】

  価格帯       状況                          代表
  ─────────────────────────────────────────────
  超高価格帯   伸びている                    エルメス、カルティエ、ロレックス
    ↑         値上げしても売れる
  高価格帯     やや鈍化                      ルイ・ヴィトン、グッチ、プラダ
    ↑         値上げの効きが限界に
  ─────────────────────────────────────────────
  中価格帯     ★ 最も厳しい ★               百貨店の国内ブランド、中堅専門店
              「高くも安くもない」＝選ぶ理由がない    ↓ここが消える
  ─────────────────────────────────────────────
  低価格帯     堅調                          ABCマート、しまむら系、SHEIN等
    ↓         価格で選ばれる
```

鞄・袋物市場の調査でも、購買の二極化が進む一方で「**中価格帯は引き続き厳しい競争環境に置かれる**」とされている（矢野経済研究所、2026年）。

> ポイント：中価格帯が消える理由は、**上には「一生物」という物語があり、下には「安い」という明快な理由がある**のに、真ん中にはどちらもないから。
> 加えて中価格帯こそ、中古のラグジュアリー品と真正面からぶつかる価格帯でもある。

## 2. 欧州コングロマリット3強

### 3社の性格の違い

| グループ       | 本拠     | 中核ブランド                                                                         | 性格                                                                           | 2026年前後の状況                                                                                                               |
| -------------- | -------- | ------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| **LVMH**       | フランス | ルイ・ヴィトン、ディオール、ティファニー、ブルガリ、ロエベ、セリーヌ、モエ・ヘネシー | 最大手。**ファッション＆レザーグッズが稼ぎ頭**。酒・化粧品・小売まで持つ総合型 | 2026年1〜6月は売上386億ユーロ、オーガニック（既存事業ベース）で2%増。レザーグッズは7四半期連続減のあと1%増へ回復（報道ベース） |
| **リシュモン** | スイス   | カルティエ、ヴァン クリーフ＆アーペル、IWC、ピアジェ                                 | **ジュエリー・時計に特化**（ハードラグジュアリー）                             | 2026年3月期は売上224億ユーロで前年比11%増。全事業・全地域・全チャネルで増収と報じられる                                        |
| **ケリング**   | フランス | グッチ、サンローラン、ボッテガ・ヴェネタ、バレンシアガ                               | **グッチ依存度が高い**。1ブランドの浮沈でグループが揺れる                      | 2026年上半期は売上72億ユーロ、報告ベース3%減。第2四半期に既存ベース2%増へ復帰。グッチの減少幅は8%減→2%減に縮小（報道ベース）   |

```
【同じ「ラグジュアリー」でも中身が違う】

            ソフトラグジュアリー        ハードラグジュアリー
            （バッグ・服・革小物）       （ジュエリー・時計）
             ↓                          ↓
  LVMH      ████████████░░░░            ░░░░████
  ケリング   ████████████████            ░░
  リシュモン ░░                          ████████████████
             ↑                          ↑
        流行に左右される              素材相場に支えられる
        今サイクルで苦戦               今サイクルで好調
```

2026年時点で**ジュエリーが好調でレザーグッズが苦戦**しているため、リシュモンが相対的に強い。「高騰した新品バッグより、価格に見合う価値を感じやすいジュエリーや中古品が支持される」と分析されている（DIGIDAY日本版ほか報道）。

### 強さの源泉＝「値上げできる」こと

ラグジュアリーの利益構造は、突き詰めると次の一点に帰着する。

```
【値上げの威力（単純化したモデル）】

  売価 1,000／原価 200 の商品を 10%値上げすると…

         値上げ前          値上げ後（売価1,100）
  売価     1,000              1,100   （+100）
  原価       200                200   （原価は変わらない）
  ───────────────────────────────
  粗利       800                900   （+100 ＝ 丸ごと利益に乗る）
  粗利率     80%              81.8%

  → 数量が 8%減っても粗利額は維持できる
     ＝ 値上げに耐える客がいる限り、ブランドは強くなる一方
```

この「値上げしても客が離れない力」を**プライシングパワー**（価格決定力）と呼ぶ。作るのが難しいのではなく、**やめられない需要を長い時間かけて作った**ことが参入障壁になっている。

| プライシングパワーの源 | 具体的な仕掛け                                                     |
| ---------------------- | ------------------------------------------------------------------ |
| 歴史・物語             | 創業年、職人、アーカイブ（過去作品の保管と展示）                   |
| 希少性の演出           | 生産量を意図的に絞る、指名買いでも待たせる、アウトレットに流さない |
| 流通の直営化           | 卸を減らし直営店で売る。値引きされる場を潰す                       |
| 値上げの継続           | 「毎年上がる」という期待が、買い控えではなく**買い急ぎ**を生む     |
| 中古価格の高さ         | 中古でも高いことが「損しない買い物」という安心を与える（→ 5章）    |

> ただし2020年代前半の急な値上げはやりすぎだったという見方もある。値上げが数量減を上回れなくなると、
> **「高くなりすぎて誰も買わない」領域に入る**。LVMHのレザーグッズが7四半期連続で減少したのは、その警告と読まれた。

## 3. 日本勢の立ち位置

日本企業でラグジュアリーの土俵に乗っているのはごく一部で、多くは「大衆品を効率よく回す小売」か「技術を持つ製造」に立っている。

| 企業                     | 分野   | 立ち位置                                    | 特徴                                                                                                     |
| ------------------------ | ------ | ------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| **ABCマート**            | 靴小売 | 国内シューズ小売の最大手                    | 全国の店舗網＋自社企画品で粗利を確保。2026年2月期 売上高 約3,786億円／営業利益 約633億円（同社適時開示） |
| **チヨダ**               | 靴小売 | 業界2位（東京靴流通センター、シュープラザ） | 紳士靴の比重が高く、テレワーク定着の逆風。機能性シューズ（スパットシューズ）で巻き返しを図ると報じられる |
| **ジーフット**           | 靴小売 | ASBee など。イオン系                        | SC（ショッピングセンター）内立地が中心                                                                   |
| **ミキモト**             | 宝飾   | 真珠の創始者。非上場                        | 真珠養殖の発明という歴史。国内ラグジュアリーに最も近い存在                                               |
| **TASAKI**               | 宝飾   | 真珠・ダイヤ                                | 海外ファンド傘下を経てブランド再構築                                                                     |

| **エース**               | 鞄     | スーツケース最大手級                        | 旅行需要の回復が直撃する（プラスにもマイナスにも）                                                       |
| **吉田カバン（PORTER）** | 鞄     | メイドインジャパンの代表格                  | 国内縫製と職人による「日本ブランド」戦略                                                                 |

```
【日本勢のポジション】

  高
  │        ミキモト・TASAKI       ← 数は少ない
  │           ●
単│
価│    4℃ ●        ● 吉田カバン   ← 中価格帯。最も競争が厳しい
  │
  │  ● ジーフット  ● チヨダ
  │        ● ABCマート             ← 規模と効率で戦う
  低└────────────────────────────▶ 規模・効率
```

> ポイント：日本勢の主戦場は「ブランドで値上げする」ではなく「**同じ物をいかに安く大量に回すか**」。
> だから業績を見るときは、ラグジュアリーなら値上げ率、日本の量販なら**既存店売上高前年比と在庫回転**を見る。

## 4. 金価格の高騰が宝飾に与える影響

### 何が起きたか

2020年代に入り金価格は上昇を続け、**2025〜2026年は1年で約50%上昇**する局面もあった（報道ベース）。国内小売価格（田中貴金属の店頭価格、税込）も史上最高値圏で推移し、2026年9月には1グラムあたり2万円台後半の水準が報じられている。

```
【金価格高騰が宝飾店に効く3つの経路】

  ① 仕入原価が上がる   → 値上げせざるを得ない
       ↓
  ② 客単価が上がる     → 市場規模（金額）は増える
       ↓                  ※ ただし客数は増えていない
  ③ 買取が増える       → 手持ちの金製品を売りに来る人が増える
                          （買取・リフォーム部門が儲かる）
```

| 影響                     | 中身                                                                                                                              |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------- |
| 市場金額は増える         | 2025年の国内宝飾品小売市場 1兆1,741億円（前年比103.8%）。伸びの主因は**値上げによる単価上昇**で、客数は伸び悩み（矢野経済研究所） |
| デザインが変わる         | 金の使用量を抑えた設計（中空構造、細身、メッキ、代替素材）へシフト。「**重さからデザインへ**」と表現される（DIGIDAY日本版）       |
| ブライダルは耐える       | 地金中心のマリッジリングは大幅値上げでも取得率が高く、金額ベースで伸長（矢野経済研究所）                                          |
| 在庫評価が膨らむ         | 地金在庫の評価額が上がる。会計上の利益が出る一方、**同じ量を仕入れ直すのに前より金がかかる**                                      |
| 買取・リフォームが伸びる | 手持ちの金製品を売る／作り替える需要。宝飾店が二次流通の入口になる                                                                |

※ 本ノートは相場の見通しや売買のタイミングを述べるものではない。金価格の水準は日々変動するため、**最新値は田中貴金属など取扱事業者の公表価格で確認すること**。

### ダイヤモンドは逆の動きをしている

金とは対照的に、ダイヤモンドは価格が下落している。

```
【金とダイヤの逆行（2020年代半ば）】

  金     ──────────────▲  上昇。地金は世界共通の相場で需要が厚い
                            （中央銀行の購入、地政学リスク）

  天然ダイヤ ────────────▼  下落。ラボグロウンの普及で
                             「希少だから高い」という前提が崩れた

  ラボグロウン ─────────▼▼ さらに急落。天然比で80〜90%安の例も
                             （報道ベース）
```

- **ラボグロウンダイヤモンド**＝ 実験室で人工的に育てたダイヤ。**成分も硬さも天然と同一**で、専用機器でないと区別できない
- 生産技術の進歩で量産コストが下がり、価格が急落。市場シェアは25%に達するとも言われる（報道ベース）
- 結果、天然ダイヤは「投資対象・希少品」として差別化を図る方向へ。ブライダルでも「ラボグロウンで大きい石を買う」選択肢が現実になった

> ポイント：**金＝素材の相場、ダイヤ＝希少性という物語**。
> 物語は技術で壊れうるが、相場は壊れない。これが宝飾業界で金とダイヤの運命が分かれた理由。

## 5. リセールバリューと二次流通の拡大

### 中古市場が「新品の価格」を支えている

かつてブランドは中古市場を嫌ったが、いまや**中古価格の高さがブランド価値の証明**になっている。

```
【二次流通がある商材の買い方】

  中古市場がない場合
    30万円のバッグ ＝ 30万円の出費

  中古市場がある場合（3年後に20万円で売れる）
    30万円のバッグ ＝ 実質10万円の出費（3年間の使用料）
         ↑ この計算が成立すると、新品の値上げにも耐えられる
```

- 国内のリユース市場は 2024年 3兆2,628億円（前年比4.5%増）で**15年連続拡大**。うち「ブランド品」は 4,230億円（同15.7%増）、衣料・服飾品 6,392億円と合わせたリユースファッション市場は**初めて1兆円を超えた**（リサイクル通信／リユース経済新聞の推計）
- ブランドバッグの買取ランキングではルイ・ヴィトンが首位級、エルメスのバーキン・ケリーは希少性・素材・色・サイズで価格が決まる（報道ベース）
- 百貨店も中古の取り扱いに本格参入し、富裕層・若年層の両方が中古を買う流れが定着

| 二次流通が業界に与えた変化 | 中身                                                                     |
| -------------------------- | ------------------------------------------------------------------------ |
| 新品の値上げを支える       | 「売れば戻る」が値上げへの抵抗を弱める                                   |
| 中価格帯を圧迫する         | 予算20万円なら「新品の中価格帯」より「中古のラグジュアリー」が選ばれる   |
| 真贋判定が事業になる       | 鑑定士・AI鑑定・シリアル管理が競争力に                                   |
| ブランド側も参入           | 公式の下取り・修理・認定中古（サーティファイド）で二次流通を取り込む動き |

→ 詳しくは [リユース・中古](../16_リユース・中古/README.md)。

## 6. インバウンドと免税

高単価・軽量・持ち帰り可能という条件を満たすため、**この3商材は免税販売の主役**である。

```
【免税が効く商材の条件】

  ① 単価が高い（10%の消費税免除が効く）   → バッグ・宝飾 ◎
  ② 持ち帰れる（軽い・小さい）             → 全部 ◎
  ③ 自国で買うより安い（為替・価格差）     → 円安局面で ◎
     ＝ 3条件が揃う数少ないカテゴリ
```

- 鞄・袋物市場が2024年度に前年度比116.3%と大きく伸びたのは、インバウンド消費と値上げの合わせ技（矢野経済研究所）
- 2025年度は反落予測。インバウンド消費の鈍化と国内の節約志向が理由（同）
- 百貨店の免税売上も、客数は過去最高でも**単価の安い消耗品へのシフトで金額が伸び悩む**局面があった（→ [百貨店](../05_百貨店/README.md)）

### 2026年11月の免税制度改正

2026年11月1日から、免税の仕組みが**購入時免税から「リファンド方式」へ**変わる。

| 項目                   | 現行（〜2026年10月）         | リファンド方式（2026年11月〜）                              |
| ---------------------- | ---------------------------- | ----------------------------------------------------------- |
| 支払い                 | 店頭で税抜価格を払う         | 店頭では**税込で払う**                                      |
| 還付                   | なし（最初から免税）         | 出国時に税関確認 → 後から消費税相当額を返金                 |
| 一般物品／消耗品の区別 | あり（消耗品は包装義務など） | **区別を廃止**。5,000円（税抜）以上なら一括で免税対象       |
| 高額品                 | ―                            | 税抜100万円以上は**シリアルナンバー等の商品情報登録が義務** |

```
【なぜ100万円以上にシリアル登録を課すのか】

  従来の抜け穴：
    訪日客名義で免税購入 ─▶ 国内で転売 ─▶ 消費税を払わずに国内流通
           ↑ 高額バッグ・宝飾・時計で起きやすかった

  改正後：
    シリアル番号で「どの個体が免税で出たか」を追跡できる
    ＋ 出国確認できなければ返金されない
           ↓
    転売目的の免税購入が成立しにくくなる
```

宝飾・バッグは100万円超の商材が多く、**この業界が制度改正の直撃を受ける**。店頭では一時的に税込で払わせるため、客の資金負担が増える点も売り場の懸念として挙げられている（免税事業者団体の説明資料）。

## 7. 偽造品対策

ブランド価値で稼ぐ以上、偽造品は売上の横取りであると同時に**ブランドそのものの毀損**になる。

| 対策                 | 中身                                                                                                                                 |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| 水際（税関）での差止 | 2022年10月施行の改正商標法・意匠法・関税法で、**海外事業者が個人宛に送る模倣品も、個人使用目的でも没収対象**になった（特許庁・税関） |
| 真贋判定の高度化     | 鑑定士の目視＋AI画像判定。二次流通事業者の中核能力                                                                                   |
| 個体管理             | シリアルナンバー、NFCタグ、デジタル証明（ブロックチェーン等）。免税制度改正とも連動                                                  |
| 越境ECへの対応       | プラットフォーム側への削除要請。出品者の身元確認                                                                                     |

背景には越境ECの普及がある。従来は「個人使用目的の輸入」は見逃されていたため、海外通販サイトで偽物を買う行為が実質的に野放しだった。2022年の法改正はこの抜け穴を塞ぐもので、**偽ブランド品の税関差止は年3万件超**と報じられている。

## 8. まとめ：この業界の損益を動かす4つの変数

```
  ① 値上げ力（プライシングパワー）
       ブランドが値上げを通せるか ─▶ ラグジュアリーの利益を決める

  ② 素材相場（金・プラチナ・革）
       上がれば宝飾の金額は増えるが、客数は減る

  ③ 二次流通の厚み
       中古が高く売れるほど新品の値上げが通る
       同時に中価格帯の新品が食われる

  ④ 訪日客と免税制度
       単価の高い商材ほど感応度が高い
       2026年11月のリファンド方式で運用が一変
```

| **オーガニック成長**             | 為替やM&Aの影響を除いた、既存事業だけの成長率。ラグジュアリー各社の発表で必ず使われる            |
| **ラボグロウンダイヤモンド**     | 実験室で育てた人工ダイヤ。成分・硬さは天然と同一で、価格は天然比で大きく安い                     |
| **リセールバリュー**             | 中古で売ったときの価格。高いほど新品購入の心理的ハードルが下がる                                 |
| **リファンド方式**               | 2026年11月1日施行の新免税制度。店頭では税込で払い、出国時の税関確認後に消費税相当額を返金する    |
| **水際措置**                     | 税関で模倣品の輸入を差し止める取り締まり。2022年10月から個人輸入も対象                           |
| **認定中古（サーティファイド）** | ブランド自身が真贋と状態を保証して販売する中古品。二次流通を自社で取り込む手法                   |
