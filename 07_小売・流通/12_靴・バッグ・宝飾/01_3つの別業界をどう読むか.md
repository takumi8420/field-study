# 3つの別業界をどう読むか

このノートで分かること：「靴・バッグ・宝飾」はひとまとめに呼ばれるが、**商売の原理がまったく違う3つの業界**である。靴は在庫オペレーションの勝負、バッグはブランド価値の勝負、宝飾は素材相場と資産性の勝負。この3つの違いを、粗利率・在庫回転・販売チャネルの3軸で分解する。

---

## 1. 結論：同じ「身の回り品」でも儲け方が違う

業界地図ではこの3つが1枠に入っている。理由は単純で、**百貨店やファッションビルの同じフロアに並んでいるから**であり、経済的な共通点があるからではない。

```
【同じ売り場に並ぶが、背後の構造は別物】

  靴          ：1型を売るのに 10サイズ × 3色 の在庫を持つ
                 └─ 在庫管理が本質。SKU（品番の最小単位）爆発との戦い

  バッグ      ：原価より「誰が作ったか」で値段が決まる
                 └─ ブランド価値が本質。値上げできるかどうかがすべて

  宝飾        ：素材そのものに世界共通の相場がある
                 └─ 地金・石の相場が本質。売った後も価値が残る
```

> ポイント：**「在庫の重さ」「ブランドの強さ」「素材の相場」のどれが利益を決めるか**。
> この問いの答えが3業界で違う。ニュースを読むときも、まずどの業界の話かを分けて考える。

## 2. 3業界の対比表

数値はいずれも**目安**。企業や価格帯で大きく振れる。

| 軸                           | 靴                                         | バッグ                                               | 宝飾                                                                  |
| ---------------------------- | ------------------------------------------ | ---------------------------------------------------- | --------------------------------------------------------------------- |
| 国内小売市場（直近）         | 約1兆2,367億円（2024年度、矢野経済研究所） | 約1兆9,611億円（2024年度、鞄・袋物、矢野経済研究所） | 約1兆1,741億円（2025年、矢野経済研究所）                              |
| 売上総利益率（粗利率）の目安 | 40〜50%（量販チェーン）。自社企画品は50%超 | 50〜70%（ブランド品）。ラグジュアリーは80%超とされる | 40〜60%。ただし**地金部分は原価がほぼ相場で決まる**ため圧縮されやすい |
| 在庫回転（年）               | 2〜3回転。**SKU数が多く滞留しやすい**      | 1〜3回転。定番は長く持てる                           | 0.5〜1.5回転。**1点数十万〜数百万円が動かない**                       |
| 値下げ（セール）圧力         | 強い。シーズン末に必ず残る                 | 中。ラグジュアリーは原則セールをしない               | 弱い。地金部分は相場が下支え                                          |
| 主な販売チャネル             | 専門店チェーン、スポーツ店、EC、量販       | 百貨店、路面旗艦店、SC、EC、二次流通                 | 百貨店、路面、専門店、ブライダル専門、二次流通                        |
| 需要の性質                   | **消耗品**（履けば減る＝買い替えが来る）   | 半耐久＋ファッション（気分で買う）                   | **記念・儀礼**（結婚・出産・還暦）＋**資産**                          |
| 最大の敵                     | 売れ残りサイズ                             | ブランド価値の毀損と偽造品                           | 素材相場の急変と客数減                                                |
| 日本の代表企業               | ABCマート、チヨダ、ジーフット              | サンエー・インターナショナル系、吉田カバン、エース   | ミキモト、4℃ホールディングス、TASAKI                                  |

### 粗利率が同じでも儲かり方が違う理由

粗利率が50%でも、**在庫が何回転するか**で年間に生む利益は変わる。

```
【粗利率 × 在庫回転 ＝ 在庫が生む年間利益（GMROI の考え方）】

  靴の量販チェーン : 粗利率45% × 回転2.5回 ＝ 在庫1に対し年1.1の粗利
  ラグジュアリーバッグ: 粗利率70% × 回転1.5回 ＝ 在庫1に対し年1.05の粗利
  高額宝飾         : 粗利率50% × 回転0.7回 ＝ 在庫1に対し年0.35の粗利
                                              ↑ 回転が低い分、
                                                「場所代」を抑えるか
                                                単価を上げるしかない
```

- **GMROI**（ジーエムロイ／Gross Margin Return On Inventory Investment）＝ 粗利額 ÷ 平均在庫額。「在庫に突っ込んだお金が年に何倍の粗利を生むか」を見る小売の基本指標
- 宝飾が百貨店の一等地に出られるのは、回転が低くても**1件の単価が桁違い**だから。逆に地方のロードサイドでは成立しにくい

## 3. 靴 ―― サイズ在庫が重い小売

### なぜ靴は在庫が爆発するのか

アパレルは S/M/L の3サイズで済むことが多いが、靴は**0.5cm刻みで10段階前後**必要になる。

```
【1つの型（デザイン）を店に置くのに必要な在庫】

  Tシャツ :  3サイズ × 4色 ＝ 12 SKU
  スニーカー: 10サイズ × 3色 ＝ 30 SKU   ← 2.5倍
  （紳士靴なら 24.0〜28.0cm の11サイズ × ワイズ（幅）2種 ＝ 22 SKU/色）

  ※ SKU（エスケーユー）＝ 在庫を数える最小単位。
    「同じ靴でもサイズ・色が違えば別の在庫」と数える
```

さらに悪いことに、**サイズごとの売れ方は正規分布**に近い。中央（26.0cmなど）は早く売り切れ、端（24.0cm、29.0cm）は最後まで残る。

```
【サイズ別の売れ残り構造】

  在庫数 ┤
        │        ████
        │      ████████
        │    ████████████
        │  ██▓▓████████▓▓██
        └──┴──┴──┴──┴──┴──┴──  サイズ
          24  25  26  27  28  29
            ▓＝最後まで残る部分（＝値下げ対象）
          ■中央サイズは早々に欠品 → 「欲しいサイズがない」で機会損失
```

つまり靴屋は、**「中央サイズの欠品」と「端サイズの残品」を同時に抱える**。これが靴小売の宿命で、対策は次の3つしかない。

| 対策                             | 中身                                         | 代表例                            |
| -------------------------------- | -------------------------------------------- | --------------------------------- |
| 店舗網を厚くして横持ちする       | 店間で在庫を融通し、欠品サイズを他店から回す | ABCマートの全国1,000店超の網      |
| 自社企画（PB）で仕入原価を下げる | 残っても値下げ余力がある状態にしておく       | ABCマートの自社ブランド比率の高さ |
| そもそもサイズを減らす           | フリーサイズ寄りの設計、伸縮素材             | サンダル、スリッポン系            |

### 靴小売の市場構造

- 国内靴・履物小売市場は 2023年度 約1兆2,267億円 → 2024年度 約1兆2,367億円（前年度比100.8%）→ 2025年度予測 約1兆2,478億円（同100.9%）と、**ほぼ横ばい**（矢野経済研究所、2026年発表）
- 内訳ではスポーツシューズ（スニーカー含む）が**58.0%と過半**を占め、全体を牽引（同）。紳士靴・婦人靴も「スニーカーライク」な設計に寄っている
- 子供靴は少子化で構造的に縮小

```
【靴の売れ筋シフト：革靴からスニーカーへ】

  ~2010年代        テレワーク定着後（2020年代）
  通勤＝革靴   ──▶  通勤＝スニーカー／ビジネススニーカー
  週末＝スニーカー   週末＝スニーカー
        ↓
  「革靴でしか満たせない需要」が縮み、
  紳士靴を主力にしてきたチェーンの既存店が苦しくなった
```

実例として、紳士靴の比重が高いチヨダ（東京靴流通センター、シュープラザ）は、テレワーク定着によるビジネスシューズ需要の減退が続くと説明しており、2026年2月期は減収減益の見通しを示していた（同社IR・報道ベース）。一方でスニーカー・スポーツ主体のABCマートは 2026年2月期に売上高 約3,786億円（前期比1.7%増）、営業利益 約633億円（同1.2%増）と増収増益（同社適時開示）。**同じ「靴屋」でも扱う品目で明暗が割れる**。

→ スポーツブランド側の視点は [スポーツ用品](../11_スポーツ用品/README.md) を参照。

## 4. バッグ ―― ブランド価値の商売

### 原価では値段が決まらない

バッグの値段は、革の値段や縫製の手間から積み上げて決まるわけではない。**「そのブランドでいくらなら買われるか」から逆算**される。

```
【値決めの向きが逆】

  普通の製造業        ラグジュアリーブランド
  原価 100            希望小売価格 1,000（ブランドが決める）
   ＋加工 50            ↓ここから逆算
   ＋利益 50          原価は 100〜200 に収まるよう設計
  ──────            ──────────────
  売価 200            差額はブランド維持費に回る
                       （広告、旗艦店、ショー、職人、アーカイブ）
```

ここで重要なのは、差額が丸ごと利益になるわけではない点。**一等地の路面店、広告、ファッションショー、職人の育成**といった「ブランドを保つための固定費」に相当額が消える。ブランドは放っておくと価値が減る資産で、**維持に金を払い続けないと値段を保てない**。

### 在庫の性質が靴と逆

| 論点         | 靴                     | バッグ                                                         |
| ------------ | ---------------------- | -------------------------------------------------------------- |
| サイズ展開   | 必須（在庫が増える）   | ほぼ不要（フリーサイズ）                                       |
| 色展開       | 2〜4色                 | 多い（同型で10色以上も）                                       |
| 定番の寿命   | 2〜3年でモデルチェンジ | **数十年**（アイコンバッグ）                                   |
| 売れ残り処理 | セール・アウトレット   | ラグジュアリーは**値引きせず在庫を保持**（ブランドを守るため） |

> ポイント：ラグジュアリーが「セールをしない」のは意地ではなく経済合理性。
> **一度値引きすると、客は次から定価で買わなくなる**。値下げは今期の在庫を捌く代わりに、
> 将来の粗利を前借りする行為になる。

### 日本の鞄市場

- 鞄・袋物の国内小売市場は 2024年度 約1兆9,611億円（前年度比116.3%）。インバウンド消費の拡大と各社の価格改定（値上げ）が押し上げた（矢野経済研究所）
- うち**旅行鞄が3,070億円（前年度比144.8%）**と突出。訪日客の増加とともに、日本人の海外旅行復活も効いた（同）
- 2025年度は 約1兆8,347億円（同93.3%）と**反落の予測**。インバウンド消費の鈍化と国内の節約志向が理由とされる（同）
- 購買は高価格帯と低価格帯に割れ、**中価格帯が最も厳しい**（同）→ 詳しくは [② ラグジュアリーと大衆品の二極化](02_ラグジュアリーと大衆品の二極化.md)

## 5. 宝飾 ―― 素材相場と資産性

### 他の2つと決定的に違う点

靴もバッグも、買った瞬間に価値が大きく下がる「消費」である。宝飾だけは違う。

```
【購入後の価値の残り方（イメージ）】

  価値
  100 ●──┐
      │  └─────●  宝飾（地金部分は相場に連動して残る）
   50 │        ╲
      │  ●──╲      バッグ（人気モデルは高く残るが型番次第）
      │      ╲──●
    0 │  ●──────────● 靴（ほぼ残らない。限定スニーカーは例外）
      └──────────────────▶ 時間
```

- **地金**（じがね）＝ 金・プラチナなど貴金属そのもの。世界共通の相場があり、指輪でもネックレスでも溶かせば同じ価値になる
- このため宝飾店は**売る側であると同時に買い取る側**でもある。地金相場が上がると、買取・下取りの窓口が忙しくなる
- 一方でダイヤモンドなどの**石**は地金と違い一物一価に近く、鑑定（4C＝カラット・カラー・クラリティ・カット）を経ないと価値が決まらない

※ 本ノートは業界の仕組みを説明するもので、金や宝飾品の購入・売却を勧めるものではない。資産性は**事実として**記述している。

→ 地金相場そのものの構造は [非鉄金属](../../11_資源・エネルギー・鉄鋼金属/10_非鉄金属/README.md) を参照。

### ブライダル需要と記念品需要

宝飾の需要は「欲しいから買う」より「**買う理由があるから買う**」比重が大きい。

```
【宝飾を買う2つの理由】

  ① ブライダル（儀礼需要）
     婚約指輪（エンゲージリング）→ ダイヤが主役
     結婚指輪（マリッジリング）  → 地金が主役。2本1組で必ず買う
       ↑ 婚姻件数に直結する。値上げしても「買わない」選択がしにくい

  ② 記念品・自分へのご褒美（イベント需要）
     出産（ベビーリング）、誕生日、昇進、還暦、相続・贈与
       ↑ 景気・株価・賞与に連動して振れやすい
```

矢野経済研究所の調査（2026年速報）では、**プラチナのブライダルリングは販売本数が大きく変わらないのに金額ベースでは大幅伸長**した。地金高騰による値上げがそのまま金額に乗った形で、「マリッジリングの取得率は依然として高く、市場全体の拡大に貢献した」とされる。

> ポイント：**ブライダルは価格弾力性が低い**（値段が上がっても本数が減りにくい）。
> だから地金が高騰しても宝飾市場の金額は増える。逆に**婚姻件数が減ると構造的に縮む**。
> 宝飾業界が少子化・婚姻減を最大のリスクと見るのはこのため。

### 市場規模

- 国内宝飾品（ジュエリー）小売市場は 2025年 1兆1,741億円（前年比103.8%）、2026年は 1兆2,223億円（同104.1%）の予測（矢野経済研究所、2026年速報）
- 伸びの主因は**値上げによる単価上昇**であり、客数は伸び悩んだとされる。つまり「よく売れた」のではなく「高く売れた」市場

## 6. 3業界を貫く共通点（あえて挙げるなら）

原理は違うが、以下は共通して効く。

| 共通項                       | 中身                                                                                                              |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| 百貨店・SCという場所への依存 | 3業界とも自前の集客力が弱く、人の集まる場所に依存する → [百貨店](../05_百貨店/README.md)                          |
| インバウンドの感応度が高い   | 単価が高く、免税が効く商材。訪日客の増減が業績に直結                                                              |
| 二次流通（中古）の存在       | 靴（限定スニーカー）、バッグ、宝飾のいずれもリセール市場がある → [リユース・中古](../16_リユース・中古/README.md) |
| 偽造品リスク                 | ブランドと素材の両方が偽造の標的。真贋（しんがん）判定が事業になる                                                |
| 素材の調達が海外             | 革・地金・宝石はほぼ輸入。為替と資源相場の影響を直に受ける → [繊維](../../10_素材・化学/08_繊維/README.md)        |

## 7. まとめ：3つの問いで見分ける

新しいニュースや企業を見たとき、次の3問でどのタイプか判定できる。

```
  Q1 サイズ・色の展開が多いか？
       YES → 在庫オペレーションで勝負する商売（靴型）
       NO  → Q2へ

  Q2 値段がブランド名で決まるか、素材相場で決まるか？
       ブランド名 → 値上げ力が命（バッグ型）
       素材相場   → 相場と在庫評価が命（宝飾型）
```

## 用語メモ

| 用語                    | 意味                                                                                          |
| ----------------------- | --------------------------------------------------------------------------------------------- |
| **SKU（エスケーユー）** | 在庫を数える最小単位。同じ靴でもサイズ・色が違えば別SKUと数える。靴は1型で30SKUを超えることも |
| **ワイズ（幅）**        | 足の幅のサイズ表記（2E、3Eなど）。長さと掛け算でSKUがさらに増える                             |
| **GMROI**               | 粗利額 ÷ 平均在庫額。在庫に投じた資金が年に何倍の粗利を生むかを見る指標                       |
| **地金（じがね）**      | 金・プラチナなど貴金属そのもの。世界共通の相場があり、加工品でも溶かせば同じ価値              |
| **4C**                  | ダイヤの評価軸（Carat 重さ／Color 色／Clarity 透明度／Cut 研磨）。石の値段を決める共通言語    |
| **ブライダルリング**    | 婚約指輪（エンゲージリング）と結婚指輪（マリッジリング）の総称。宝飾の安定需要層              |
| **価格弾力性**          | 値上げしたときに数量がどれだけ減るか。ブライダルは弾力性が低い（減りにくい）                  |
| **アイコンバッグ**      | ブランドを象徴する定番モデル。モデルチェンジせず数十年売り続けられる                          |
| **一物一価**            | 同じ物には1つの価格しかない状態。地金は一物一価に近く、宝石は個体差が大きいため成立しにくい   |
