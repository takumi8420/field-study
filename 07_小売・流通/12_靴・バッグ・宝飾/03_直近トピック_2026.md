# 直近トピック（2026年9月時点）

報道・調査会社ベースの整理。数値は発表時点のもので、相場や業績は随時更新される。一次情報（企業IR、官公庁、業界団体）で裏取りすること。
本ノートは市場の事実を整理するもので、**金・宝飾品その他の売買を勧めるものではない**。

## 1. 金価格の高騰が宝飾を「重さからデザインへ」動かした

| 時点         | 内容                                                                                               |
| ------------ | -------------------------------------------------------------------------------------------------- |
| 2025〜2026年 | 金価格が1年で約50%上昇する局面。ジュエリー各社の原材料コストを直撃（DIGIDAY日本版）                |
| 2026年9月    | 田中貴金属の店頭小売価格（税込）が1グラムあたり2万円台後半で推移。同月の高値は26,525円と報じられる |
| 2026年通年   | 「地金高騰が継続、本物志向の高まりから資産価値がより重要に」という業界展望（WWDJAPAN）             |

```
【高騰への3つの逃げ道】

  ① 値上げして通す      → ブライダルなど価格弾力性の低い領域で有効
  ② 金の使用量を減らす  → 中空構造・細身・部分使い・代替素材
  ③ デザインで勝負する  → 「何グラムか」でなく「どう見えるか」で売る
         ↑ 2026年は②③へのシフトが明確になった年とされる
```

- 国内宝飾品（ジュエリー）小売市場は 2025年 **1兆1,741億円（前年比103.8%）**、2026年予測 **1兆2,223億円（同104.1%）**（矢野経済研究所、2026年速報）
- ただし伸びの主因は**値上げによる単価上昇**。客数は伸び悩んだとされ、「よく売れた」市場ではない
- プラチナのブライダルリングは販売本数がほぼ横ばいでも金額ベースで大幅伸長。**マリッジリングは値上げに耐える**という構造が改めて確認された（同）

→ 仕組みの解説は [② ラグジュアリーと大衆品の二極化 4章](02_ラグジュアリーと大衆品の二極化.md)

## 2. ラグジュアリー市場は「ジュエリー好調・バッグ低迷」で二極化

2026年のグローバル・ラグジュアリーは、カテゴリごとに明暗がはっきり割れた。

| 企業           | 直近の業績                                                                                                     | 読みどころ                               |
| -------------- | -------------------------------------------------------------------------------------------------------------- | ---------------------------------------- |
| **リシュモン** | 2026年3月期 売上 224億ユーロ（前年比11%増）。全事業・全地域・全チャネルで増収                                  | ジュエリー特化が奏功。カルティエ等が牽引 |
| **LVMH**       | 2026年1〜6月 売上 386億ユーロ、オーガニック2%増。ファッション・レザーグッズは7四半期連続減のあと1%増           | 底は打ったが回復は小幅                   |
| **ケリング**   | 2026年上半期 売上 72億ユーロ、報告ベース3%減。第2四半期に既存ベース2%増へ復帰。グッチの減少幅は8%減→2%減に縮小 | グッチ依存の構造は変わらず               |

```
【2026年のカテゴリ別の温度差】

  ジュエリー・時計  ████████████  好調（素材価値が納得感を生む）
  ビューティ        ██████████    好調
  革製品・バッグ    ████          低迷（値上げしすぎの反動）
  シューズ          ████          低迷
```

- ベイン・アンド・カンパニーの見通しでは、2026年の個人向けラグジュアリー市場は **2〜4%成長で3,650〜3,730億ユーロ**（2025年は3,580億ユーロ）。中東の安定、地元消費の底堅さ、中国需要の緩やかな回復を前提とした「現実的シナリオ」とされる
- 地域別では**米州が牽引**、欧州・中東が足を引っ張る構図
- 「体験」への支出が物の支出を1.5倍のペースで上回るという指摘もあり、**所有から体験へ**という構造変化が続く

> 全体の構図：**高くなりすぎた新品バッグより、素材価値のあるジュエリーと、値ごろ感のある中古が選ばれている**。
> 値上げ一本槍のモデルが限界に近づいた、というのが2026年時点の市場の読み方。

## 3. 国内：鞄は反落予測、靴は横ばい、明暗は品目で割れる

| 市場             | 直近実績                                                                  | 見通し                                            | 出典                         |
| ---------------- | ------------------------------------------------------------------------- | ------------------------------------------------- | ---------------------------- |
| 鞄・袋物（小売） | 2024年度 1兆9,611億円（前年度比116.3%）。うち旅行鞄 3,070億円（同144.8%） | 2025年度 1兆8,347億円（同93.3%）と**反落予測**    | 矢野経済研究所（2026年）     |
| 靴・履物（小売） | 2024年度 1兆2,367億円（前年度比100.8%）                                   | 2025年度 1兆2,478億円（同100.9%）と**ほぼ横ばい** | 矢野経済研究所（2026年）     |
| 宝飾品（小売）   | 2025年 1兆1,741億円（前年比103.8%）                                       | 2026年 1兆2,223億円（同104.1%）                   | 矢野経済研究所（2026年速報） |

鞄の反落理由は、**インバウンド消費の鈍化と国内の節約志向による買い控え**とされる。2024年度の急伸が訪日客と値上げの合わせ技だったため、その反動が出る形。

靴は品目で明暗が分かれている。

```
【靴小売：同じ業界でも逆方向】

  ABCマート（スニーカー・スポーツ主体）
    2026年2月期 売上 約3,786億円（+1.7%）／営業利益 約633億円（+1.2%）
       ↑ 増収増益。自社企画品と全国店舗網で在庫を回す

  チヨダ（紳士靴・ビジネスシューズの比重が高い）
    2026年2月期は減収減益の見通しを提示（同社IR・報道ベース）
       ↑ テレワーク定着で革靴需要が戻らない
         機能性シューズ（スパットシューズ）で巻き返しを図ると報じられる
```

- 靴・履物のうち**スポーツシューズ（スニーカー含む）が58.0%と過半**を占め、市場を牽引（矢野経済研究所）
- 子供靴は少子化で構造的に縮小

## 4. 二次流通が1兆円を超え、「中価格帯の新品」を食い始めた

| 指標                                                      | 数値                                           | 出典                                   |
| --------------------------------------------------------- | ---------------------------------------------- | -------------------------------------- |
| 国内リユース市場（2024年）                                | 3兆2,628億円（前年比4.5%増）、**15年連続拡大** | リサイクル通信／リユース経済新聞の推計 |
| うちブランド品                                            | 4,230億円（前年比15.7%増）                     | 同                                     |
| リユースファッション（衣料・服飾品6,392億円＋ブランド品） | **初めて1兆円超**                              | 同                                     |

```
【予算20万円の客が今どう動くか】

              2015年頃                 2026年
  予算20万円 ─▶ 国内ブランドの     ─▶ ラグジュアリーの
                 新品バッグ             中古バッグ
                    ↑                      ↑
              中価格帯が受け皿      中古が受け皿になった
                                    ＝ 中価格帯の新品が最も苦しい
```

- 百貨店も中古の取り扱いに本格参入し、富裕層と若年層の双方が中古を買う流れが定着したと報じられる
- ブランドバッグ買取では、ルイ・ヴィトンが件数で上位を占めるとされる（コメ兵の2026年上期実績などの報道ベース）
- ブランド側も公式下取り・修理・認定中古で二次流通を取り込む動きを強めている

## 5. 2026年11月1日、免税が「リファンド方式」へ

高額品を扱うこの業界にとって、2026年最大の制度変更。

| 項目                   | 現行（〜2026年10月31日） | リファンド方式（2026年11月1日〜）                           |
| ---------------------- | ------------------------ | ----------------------------------------------------------- |
| 店頭での支払い         | 税抜（その場で免税）     | **税込で支払う**                                            |
| 還付                   | なし                     | 出国時の税関確認後、店舗が消費税相当額を返金                |
| 一般物品／消耗品の区別 | あり                     | **廃止**。5,000円（税抜）以上なら一括で免税対象             |
| 高額品の扱い           | ―                        | 税抜100万円以上は**シリアルナンバー等の商品情報登録が義務** |

```
【売り場に起きる実務の変化】

  客  ：その場で10%多く払う ──▶ 出国まで返ってこない
  店  ：購入記録情報の送信 ＋ 税関確認情報の取得 ＋ 返金処理
  高額：100万円以上はシリアル番号入力（宝飾・バッグ・時計が該当）
        ↑ 免税購入した個体を追跡し、国内転売を防ぐ狙い
```

- 制度の目的は、**免税で買った高額品が国内に転売される抜け穴を塞ぐこと**。宝飾・バッグ・時計はまさに標的だった商材
- 店側にはシステム改修とオペレーション変更の負担が生じる。売り場からは客の一時的な資金負担増を懸念する声も出ている（免税事業者団体の説明資料）
- 百貨店側の視点は [百貨店 ④ 直近トピック](../05_百貨店/04_直近トピック_2026.md) も参照

## 6. ラボグロウンダイヤが天然ダイヤの前提を壊した

- ラボグロウンダイヤモンド（実験室で育てた人工ダイヤ。成分・硬さは天然と同一）の量産化で価格が急落。天然比で**80〜90%安**の例もあり、市場シェアは25%に達するとの見方も（報道ベース）
- 天然ダイヤの価格は下落が続き、**過去最低水準**に達したと報じられる（Business Insider Japan ほか）
- これは一時的な需要減ではなく、**技術による市場構造の変化**と分析されている
- 天然側は「選ばれた宝石」「資産価値のある石」として差別化を図る方向へ

```
【同じ宝飾の中で正反対に動いた2つの素材】

  金       ▲▲▲  相場が支える。供給を人間が増やせない
  天然ダイヤ ▼▼  「希少」という前提が人工で崩れた
  ラボグロウン ▼▼▼ 技術進歩で自ら価格を下げ続ける

  → 宝飾の「資産性」は素材によって別物。ひとくくりにできない
```

## 7. 全体の構図

2026年9月時点でこの業界に起きていることは、次の4行に集約できる。

1. **素材価値が見直された年**。金は高騰し、ジュエリーが好調。一方で値上げを重ねた新品バッグは失速した
2. **単価は上がったが客数は増えていない**。宝飾市場の金額増は値上げの結果であり、需要が厚くなったわけではない
3. **中価格帯が二次流通に食われている**。ブランド品の中古が4,230億円まで伸び、「予算20万円の客」の行き先が変わった
4. **2026年11月の免税リファンド方式で、高額品の売り方が変わる**。シリアル管理と返金オペレーションが標準になる
