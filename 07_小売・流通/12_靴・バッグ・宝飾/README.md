# 靴・バッグ・宝飾

- 大分類: 小売・流通
- 状態: done
- 更新日: 2026-09-20

「身の回り品」としてひとまとめに扱われるが、**商売の原理がまったく違う3つの業界**の寄せ集めである。
靴は「1型でサイズ×色の在庫が爆発する」在庫オペレーションの商売、バッグは「原価ではなくブランド名が値段を決める」ブランド価値の商売、宝飾は「素材そのものに世界共通の相場があり、売った後も価値が残る」資産性の商売。
国内小売市場はそれぞれ約1.2兆円・約1.8〜2.0兆円・約1.2兆円。利益は欧州の3コングロマリット（LVMH・リシュモン・ケリング）に集中し、日本勢は大衆品を効率よく回す側に立つ。

## 1. 業界の定義・範囲

靴（フットウェア）、鞄・袋物（バッグ、財布などの革小物、スーツケース）、宝飾品（ジュエリー）および時計を扱う小売・製造を指す。統計上は別々に集計されるのが普通で、「靴・バッグ・宝飾」という統計は存在しない。

```
【この3つが1枠にまとめられる理由】

  百貨店・ファッションビルの
  同じフロアに並んでいる
        ↓
  客から見れば「服に合わせる小物」で同じ棚
        ↓
  だが売る側から見た経済構造は別物
   靴＝在庫戦 ／ バッグ＝ブランド戦 ／ 宝飾＝相場戦
```

| 隣接業態                                                              | 境界線                                                                                  |
| --------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| [アパレル・SPA](../10_アパレル・SPA/README.md)                        | 服そのもの。靴・バッグは「合わせる側」。ただしSPAは靴・小物まで自社で作るため境界は曖昧 |
| [スポーツ用品](../11_スポーツ用品/README.md)                          | スニーカーは両方に属する。競技用シューズはスポーツ側、街履きは靴小売側                  |
| [百貨店](../05_百貨店/README.md)                                      | 売り場を提供する側。百貨店の高額品売上の主力がまさに宝飾・時計・バッグ                  |
| [リユース・中古](../16_リユース・中古/README.md)                      | 同じ商材の二次流通。中古価格が新品の値付けを支える関係にある                            |
| [眼鏡](../13_眼鏡/README.md)                                          | 同じ「身に着ける小物」だが、視力矯正という機能と国家資格が絡む点で別世界                |
| [非鉄金属](../../11_資源・エネルギー・鉄鋼金属/10_非鉄金属/README.md) | 宝飾の川上。金・プラチナの相場を作る側                                                  |

## 2. 市場規模と成長性

すべて国内小売ベース。世界市場とは混ぜないこと。

| 分野     | 直近実績                                                           | 見通し                                         | 出典                         |
| -------- | ------------------------------------------------------------------ | ---------------------------------------------- | ---------------------------- |
| 靴・履物 | 2024年度 1兆2,367億円（前年度比100.8%）                            | 2025年度 1兆2,478億円（同100.9%）＝ほぼ横ばい  | 矢野経済研究所（2026年）     |
| 鞄・袋物 | 2024年度 1兆9,611億円（同116.3%）／うち旅行鞄3,070億円（同144.8%） | 2025年度 1兆8,347億円（同93.3%）＝**反落予測** | 矢野経済研究所（2026年）     |
| 宝飾品   | 2025年 1兆1,741億円（前年比103.8%）                                | 2026年 1兆2,223億円（同104.1%）                | 矢野経済研究所（2026年速報） |

```
【3市場の直近の動き（国内小売、兆円）】

 2.0 ┤        ●1.96 鞄（2024年度・インバウンドと値上げで急伸）
     │          ╲
 1.8 ┤            ●1.83 鞄（2025年度予測・反落）
     │
 1.4 ┤
 1.2 ┤  ●──●1.24 靴（ほぼ横ばい）
     │  ●──●1.17→1.22 宝飾（値上げで金額は増加）
 1.0 ┤
     └──────────────────────────
        2024      2025      2026
```

- 世界の個人向けラグジュアリー市場は 2025年 3,580億ユーロ → 2026年 3,650〜3,730億ユーロ（2〜4%成長）の見通し（ベイン・アンド・カンパニー）
- **3市場とも「数量が伸びた」のではなく「単価が上がった」市場**。宝飾は値上げ、鞄はインバウンドと値上げが押し上げ要因
- 靴はスポーツシューズ（スニーカー含む）が58.0%と過半を占め、紳士靴・婦人靴・子供靴は縮小傾向

## 3. バリューチェーン（川上 → 川下）

```
【靴】
  素材（革・ゴム・合成繊維）─▶ OEM工場（中国・ベトナム・インドネシア）
    ─▶ ブランド／商社 ─▶ 靴小売チェーン ─▶ 消費者
                                  ↑ ここに粗利が集まる（PB化でさらに厚く）

【バッグ】
  革なめし ─▶ 縫製（伊・仏・日・中）─▶ ★ブランド★ ─▶ 直営店／百貨店 ─▶ 消費者
                                      ↑ 付加価値の95%はここ    ─▶ 二次流通 ─▶ 消費者

【宝飾】
  鉱山（金・ダイヤ）─▶ 精錬／研磨（インド・ベルギー）─▶ 卸 ─▶ 宝飾小売 ─▶ 消費者
        ↑ ここが相場を作る                                   ↑ 買取もここが窓口
```

| 段階       | 誰が担うか                                        | 付加価値の集まり方                         |
| ---------- | ------------------------------------------------- | ------------------------------------------ |
| 素材・鉱山 | 海外がほぼ独占。金・プラチナ・ダイヤ・革は輸入    | 宝飾では**ここが価格の下限を決める**       |
| 製造       | 靴・バッグはアジアのOEM。ラグジュアリーは欧州内製 | 靴では薄い。ラグジュアリーは内製で囲い込む |
| ブランド   | 欧州コングロマリットが集中保有                    | **バッグ・宝飾の利益はここに集中**         |
| 小売       | 専門店チェーン、百貨店、直営店、EC                | 靴では**ここが主戦場**（在庫を回す力）     |
| 二次流通   | 買取専門店、フリマアプリ、百貨店                  | 新品の値付けを間接的に支える               |

## 5. 収益モデル・コスト構造

| 項目             | 靴（量販チェーン）                           | バッグ（ラグジュアリー）         | 宝飾                                           |
| ---------------- | -------------------------------------------- | -------------------------------- | ---------------------------------------------- |
| 粗利率の目安     | 40〜50%（自社企画品で50%超）                 | 50〜80%                          | 40〜60%（地金部分は相場に規定される）          |
| 在庫回転（年）   | 2〜3回転                                     | 1〜3回転                         | 0.5〜1.5回転                                   |
| 主な固定費       | 家賃、人件費、物流（店間移動）               | 旗艦店の家賃、広告、ショー、職人 | 家賃、鑑定・修理、**在庫そのものの資金コスト** |
| 利益を決める要素 | 値下げロス（売れ残り処分）をどれだけ抑えるか | 値上げを通せるか                 | 単価（＝相場と値上げ）と客数                   |

```
【儲けの方程式の違い】

  靴    : 粗利率 × 在庫回転 × 店舗数 ─ 値下げロス
             ↑ 回転を上げるため店間で在庫を横持ちする

  バッグ : 単価 × ブランド維持費をどこまで抑えるか
             ↑ 値引きは将来の粗利の前借りなのでやらない

  宝飾  : 単価（相場連動）× 客数 ＋ 買取・リフォーム
             ↑ 回転が極端に低いので、在庫を持つ資金力が要る
```

- 靴は**値下げロスが利益を削る最大要因**。端サイズの売れ残りが構造的に発生する（→ [①](01_3つの別業界をどう読むか.md)）
- 宝飾は在庫が動かないため、**在庫に寝かせる資金の重さ**が参入障壁になる。地金相場が上がると在庫評価額が膨らむ一方、仕入れ直すコストも上がる
- ラグジュアリーは粗利率が高いが、旗艦店・広告・職人育成という「ブランド維持費」が相当額を食う

## 6. 競争要因（KSF）と参入障壁

| 分野   | 成功要因（KSF）                                                  | 参入障壁                                                       |
| ------ | ---------------------------------------------------------------- | -------------------------------------------------------------- |
| 靴     | 店舗網の密度、在庫の横持ち、自社企画比率、人気ブランドの仕入枠   | **物流と店舗網の規模**。有力ブランドの卸枠が新規に回ってこない |
| バッグ | ブランドの歴史、値上げ力、直営流通、中古価格の高さ               | **時間**。ブランドは金では買えず、買収でしか手に入らない       |
| 宝飾   | 在庫を持つ資金力、鑑定力、ブライダル流通（式場・専門店）との関係 | **在庫の資金負担**と真贋判定の技能                             |

```
【この業界で新規参入が最も難しいのはバッグ】

  靴  : 資金と物流があれば参入可能（実際にECから新規が出る）
  宝飾: 資金と目利きがあれば参入可能（買取店からの上流展開が実例）
  バッグ（ラグジュアリー）:
        歴史・アーカイブ・職人・顧客の記憶が必要
        ＝ 後から作れない ＝ だからM&Aでしか広がらない
        ＝ だから欧州コングロマリットに集中する
```

## 7. 規制・法制度

| 制度                                         | 内容                                                                                                                                                                      | 影響                                                                          |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| **免税制度（リファンド方式）**               | 2026年11月1日施行。店頭では税込支払い、出国時の税関確認後に返金。一般物品／消耗品の区別を廃止し5,000円以上で一括免税。税抜100万円以上は**シリアルナンバー等の登録が義務** | 高額品を扱うこの業界が直撃。免税購入品の国内転売を防ぐ狙い                    |
| **商標法・意匠法・関税法（2022年10月施行）** | 海外事業者が個人宛に送る模倣品も、個人使用目的でも税関で没収対象                                                                                                          | 越境ECでの偽ブランド流入を塞ぐ。偽ブランド品の税関差止は年3万件超と報じられる |
| **古物営業法**                               | 中古品の売買には古物商許可が必要。本人確認・帳簿義務                                                                                                                      | 二次流通・買取事業の前提。宝飾店が買取を行う場合も対象                        |
| **家庭用品品質表示法**                       | 革製品等の素材表示                                                                                                                                                        | 「本革」「合成皮革」の表示義務                                                |
| **ワシントン条約（CITES）**                  | クロコダイル等のエキゾチックレザー、象牙の国際取引規制                                                                                                                    | ラグジュアリーの素材調達に直結。証明書管理が必須                              |
| **貴金属・宝石の取引時確認**                 | 犯罪収益移転防止法に基づき、200万円超の現金取引等で本人確認義務                                                                                                           | 高額宝飾の販売・買取実務に影響                                                |

## 8. 最近のトピック

詳細は [③ 直近トピック（2026年9月時点）](03_直近トピック_2026.md)。

1. **金価格が1年で約50%上昇**（報道ベース）。宝飾は値上げで金額が伸びたが客数は伸び悩み、設計は「重さからデザインへ」シフト
2. **ジュエリー好調・バッグ低迷**の二極化。リシュモンは2026年3月期に11%増収、LVMHのレザーグッズは7四半期連続減のあと微増に転じた
3. **鞄・袋物は2025年度に反落予測**（1兆8,347億円、前年度比93.3%）。インバウンド鈍化と国内の節約志向
4. **リユースのブランド品が4,230億円（前年比15.7%増）**、リユースファッションは初の1兆円超。中価格帯の新品を食っている
5. **2026年11月1日に免税がリファンド方式へ**。100万円超はシリアル管理が義務化され、売り場の実務が変わる
6. **ラボグロウンダイヤの普及**で天然ダイヤ価格が過去最低水準に。「希少だから高い」という前提が技術で崩れた
