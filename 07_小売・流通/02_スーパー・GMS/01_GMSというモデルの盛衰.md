# GMSというモデルの盛衰

このノートで分かること：**「衣食住を1か所で買える」ことが最大の武器だった業態が、なぜ各カテゴリを専門店に奪われたのか**。
ダイエーの興亡、大店法から大店立地法への転換、郊外モールの時代、そしてイオン／イトーヨーカドーの現在までを一本の線でたどる。

> ポイント：GMSが売っていたのは商品ではなく「**まとめ買いできるという便利さ**」だった。
> その便利さがクルマ・専門店・ネットによって別の形で供給されるようになった瞬間、総合であること自体が弱みに変わった。

## 1. GMSとは何か

GMS（General Merchandise Store＝総合スーパー）は、**1つの大型店舗で衣料品・食品・住居関連用品（＝衣食住）をセルフサービスで売る業態**を指す。
「セルフサービス」とは、店員が対面で接客・包装するのではなく、客が自分でカゴに入れてレジに運ぶ方式のこと。この方式によって人件費を下げ、安く売るのがスーパーの出発点だった。

| 業態 | 売場面積の目安 | 扱う範囲 | 粗利率の目安 | 代表例 |
| --- | --- | --- | --- | --- |
| **GMS（総合スーパー）** | 6,000〜30,000㎡ | 衣食住すべて | 25〜30% | イオン（旧ジャスコ）、イトーヨーカドー、平和堂 |
| 食品スーパー（SM） | 1,000〜3,000㎡ | 食品中心 | 24〜27% | ライフ、ヤオコー、オーケー |
| 百貨店 | 20,000㎡〜 | 衣料・雑貨中心（対面販売） | 25〜30%（消化仕入中心） | 三越伊勢丹、高島屋 |
| ディスカウントストア | 3,000〜6,000㎡ | 食品＋日用品、低価格 | 15〜20% | トライアル、ドン・キホーテ |
| コンビニ | 100〜200㎡ | 即食・日用最小限 | 30%前後 | セブン-イレブン、ファミリーマート |

※粗利率は業態の一般的な目安。個社・年度で大きく振れる。

隣接業態のノートは [食品スーパー](../03_食品スーパー/README.md)、[百貨店](../05_百貨店/README.md)、[ディスカウントストア](../09_ディスカウントストア/README.md)、[コンビニエンスストア](../01_コンビニエンスストア/README.md) を参照。

## 2. 総合化が強みだった時代（1960〜1980年代）

GMSが伸びた時代の条件は、いま振り返ると極めて特殊だった。

```
【1960〜80年代の前提】
 人口増  ×  核家族化  ×  三種の神器的な消費  ×  移動手段が徒歩・電車
        ↓
 「どの家庭も、だいたい同じものを、まとめて買う」
        ↓
 駅前・団地の近くに大箱を1つ置けば、家族の買い物が全部そこで完結する
        ↓
 GMS = 生活必需品のワンストップ装置として機能
```

ここで効いていた経済メリットは3つ。

1. **客の側の移動コスト削減**：クルマがない時代、店をハシゴするのは重労働だった。1か所で済むこと自体に価値があった
2. **店の側の固定費分散**：建物・レジ・駐車場・広告という固定費を、衣食住の3部門で山分けできた
3. **食品で客を呼び、衣料で儲ける**：食品は毎日来てもらえるが粗利が薄い。衣料は来店頻度が低いが粗利が厚い。**食品で集客し、その客に衣料を売る**という組み合わせが成立していた

> ポイント：3のクロス補填（ある部門の集客力で別の部門を儲けさせる構造）こそがGMSの収益エンジンだった。
> 後述するように、**衣料が売れなくなった瞬間にこのエンジンが止まる**。

## 3. ダイエーの興亡 ― GMS時代の象徴

| 時期 | 出来事 | 意味 |
| --- | --- | --- |
| 1957年 | 中内㓛が大阪・千林に「主婦の店ダイエー薬局」開業 | 安売り（価格破壊）を旗印にした出発 |
| 1960年代 | 多店舗化。生鮮・衣料へ拡大 | チェーンオペレーションの導入 |
| 1972年 | **三越を抜いて小売業売上高日本一**に | 百貨店の時代からスーパーの時代へ転換した象徴 |
| 1960〜70年代 | メーカーとの価格決定権争い（松下電器との取引停止＝いわゆる「ダイエー・松下戦争」は約30年続いた） | 「値段は誰が決めるか」を巡る小売とメーカーの主導権争い |
| 1980〜90年代 | 流通以外へ多角化（ホテル、球団、不動産、金融など）。借入で拡大 | 本業の利益率より規模を優先した拡大 |
| 1995年 | 阪神・淡路大震災で本拠地の店舗が被災 | 資金繰りの余力を失う契機のひとつ |
| 1990年代後半 | デフレとカテゴリーキラーの台頭で本業が失速。有利子負債が重石に | 総合化の優位が崩れ始める |
| 2004年 | 産業再生機構の支援決定 | 自力再建を断念 |
| 2015年 | イオンの完全子会社化 | 独立した上場GMSとしてのダイエーが消滅 |

ダイエーが失敗した理由を1行でまとめると、**「安く売る」ための規模拡大を、借金と多角化で続けたこと**に尽きる。
小売の利益率は良くても営業利益率3〜4%程度しかない。この薄い利益で不動産や事業投資の金利を払い続けるのは構造的に難しい。**低粗利のビジネスは、低レバレッジ（借金を抑えた経営）でなければ持たない**という教訓が残った。

## 4. 規制の歴史 ― 出店の自由度が業態を決めた

GMSの盛衰は、**大型店をどこに何㎡まで建てられるか**という規制の変遷とほぼ同期している。

```
1956 百貨店法       百貨店の出店・増床を許可制に
  │                 → スーパーは「百貨店ではない」ので規制の外で急成長
  ▼
1973 大規模小売店舗法（大店法）制定／74年施行
  │  大型店の出店・売場面積・閉店時刻・休業日数を調整対象に
  │  地元商業者との「調整」に何年もかかり、実質的な出店規制として機能
  ▼
1990年代 日米構造協議などを受けて運用を緩和
  │  → 大型店の出店が一気に増える（郊外・ロードサイドへ）
  ▼
2000 大規模小売店舗立地法（大店立地法）施行／大店法は廃止
  │  規制の目的が「中小小売業の保護」→「周辺環境（騒音・交通・廃棄物）の保全」へ転換
  │  = 商業調整をやめたので、環境をクリアできれば出店できる
  ▼
2006 まちづくり三法の改正（都市計画法改正など、2007年施行）
     床面積1万㎡超の大規模集客施設の郊外立地を原則制限
     = 「無秩序な郊外化」への揺り戻し
```

押さえるべき因果は次のとおり。

- **大店法の時代**：出店調整に時間がかかるため、**既に大型店を持っている企業が守られた**。GMSにとっては参入障壁だった
- **大店立地法への転換**：調整がなくなり出店が容易になった。ただし環境基準（駐車場・交通）を満たしやすいのは**土地の広い郊外**。結果として大型店は郊外へ流れ、中心市街地が空洞化した
- **2006年改正**：郊外の1万㎡超が原則不可になったため、**大型モールの新規供給ペースは鈍化**した。既存の大型モールの希少価値が相対的に上がった

> ポイント：「大店法が大型店を縛っていた」→「大店立地法で自由になった」→「行き過ぎて再び縛った」という三段階。
> **いまGMS各社が持っている郊外の大箱は、2000〜2006年という短い窓の間に建てられたものが多い**。

## 5. 郊外モールの時代 ― GMSが「核テナント」に格下げされる

クルマの普及と大店立地法が重なると、小売の器はGMS単独店から**ショッピングモール**に移る。

```
【GMS単独店】                     【ショッピングモール】
┌──────────────┐          ┌──────────────────────────────┐
│ 3F 住居・玩具    │          │ 専門店 150〜200店             │
│ 2F 衣料          │   ──▶   │ シネコン／フードコート         │
│ 1F 食品          │          │ ┌──────────┐                │
│ 駐車場           │          │ │ GMS（核店舗）│ ← 集客装置の1つに  │
└──────────────┘          │ └──────────┘                │
 売上＝自分の商売             │ 駐車場 3,000〜5,000台         │
                              └──────────────────────────────┘
                                売上＝テナント賃料（デベロッパー業）
```

モール化によって収益の性質が変わる。GMS単独店の利益は「商品を仕入れて売った差額」だが、モールの利益は「**場所を貸した賃料**」になる。
後者は在庫リスクを負わず、売上変動の影響も小さい。この転換に最も成功したのがイオンモールで、イオングループのディベロッパー事業は営業収益5,224億円・営業利益709億円（2026年2月期、イオンIR）と、**GMS事業（営業収益3兆6,918億円・営業利益214億円）の3倍以上の利益**を稼いでいる。

> つまり、**売上の桁が2つ違う事業のほうが利益は大きい**。GMSは「儲かる事業」ではなく「モールの集客部品」になった、というのが現在地。
> この構造の詳細は [業態再編と生き残り](03_業態再編と生き残り.md)、不動産としての見方は [不動産デベロッパー](../../12_建設・住宅・不動産/08_不動産デベロッパー/README.md) を参照。

## 6. なぜ各カテゴリを専門店に奪われたのか

1990年代以降、GMSの各売場は「そのカテゴリだけを深く・安く売る専門店（**カテゴリーキラー**）」に順番に切り取られていった。

| GMSの売場 | 奪った業態 | 奪えた理由 |
| --- | --- | --- |
| 衣料品 | SPA（ユニクロ、しまむら等） | 企画から生産・販売まで自前。同じ商品を大量に作るので原価が圧倒的に安い |
| 家電 | 家電量販店 | 品揃えの深さと価格。設置・保証というサービスまで込み |
| 医薬品・化粧品・日用品 | ドラッグストア | 調剤と化粧品の高粗利で、日用品を原価すれすれで売れる |
| 住居関連・園芸・DIY | ホームセンター | 専門知識と在庫の深さ。プロ需要も取り込む |
| 雑貨・文具 | 100円ショップ | 単価は低いが「見て回る楽しさ」で滞在時間を取る |
| 食品（低価格帯） | ディスカウントストア／食品スーパー | 商品を絞り込み、作業を標準化して売価を下げる |
| 書籍・CD・玩具 | ネット通販 | 品揃え無限。実店舗の棚の制約が致命的 |

各業態の詳細は [アパレル・SPA](../10_アパレル・SPA/README.md)、[家電量販](../06_家電量販/README.md)、[ドラッグストア](../04_ドラッグストア/README.md)、[ホームセンター](../07_ホームセンター/README.md)、[100円ショップ](../08_100円ショップ/README.md)、[通販・D2C](../15_通販・D2C/README.md) を参照。

構造的に言うと、こういうことが起きた。

```
【昔】 客の移動コストが高い          【いま】 客の移動コストが低い
      → 1か所で全部買いたい                → 安い店・良い店をハシゴできる
      → 「そこそこの品揃え×全部」が勝つ    → 「特定カテゴリで一番」が勝つ
                                            → 総合であることに支払う理由が消える
```

**総合スーパーの「総合」は、客が移動できないときにだけ価値を持つ**。クルマとネットが移動コストをゼロに近づけた時点で、総合化のプレミアムは消えた。

## 7. 衣料品売場が負けた決定的な理由

GMSの衰退を1点に絞るなら**衣料品**である。前述のとおり、GMSは衣料の粗利で全体を支えていた。そこを失った影響は大きい。

| 論点 | GMSの衣料売場 | SPA（ユニクロ等） |
| --- | --- | --- |
| 商品の作り方 | 卸・メーカーから**仕入れる**（バイヤーが選ぶ） | 自社で**企画・発注・生産**する |
| 1品番あたりの生産量 | 少ない（多品種少量） | 極めて多い（少品種大量） |
| 原価 | 中間マージンが乗る | 工場直取引で低い |
| 値入率（最初につける利幅） | 40%前後と高い | 45〜50%と高い |
| 売れ残り | 期末に大幅値下げ。**実現粗利は20%台に落ちることも** | 期中に週次で値下げを管理、消化率を作り込む |
| 売場の面積 | モールの2階に数千㎡。**面積が固定費** | 必要な面積だけ借りる |
| 意思決定の速さ | 前年実績ベースの計画発注 | 実売データで期中に追加生産（QR） |

負けの本質は3つ。

1. **原価で勝てない**：仕入れて売る商売は、自分で作る商売に原価で勝てない。同じ品質のシャツを、片方は工場から直接、片方は間に2社挟んで買っていた
2. **値下げロスが読めない**：ファッション商品は売れ残ると価値がゼロに近づく。「値入率40%」でも期末セールで半額にすれば実現粗利は激減する。GMSはこの**値下げロス（マークダウン）**の管理が弱かった
3. **面積が逃げられない**：モールの2階3階に何千㎡という衣料売場を確保してしまっているので、売れなくても家賃相当の固定費が発生する。**縮小できない固定費が赤字を固定化した**

現在、イオンリテールは衣料・住居余暇部門のSPA化（自ら企画・生産する体制への転換）を進め、2026年には「トップバリュ ベストプライス」ブランドを衣料で復活させる方針を示している（2026年、報道ベース）。ただし、SPA化には十分な販売量が要る。**GMSの店舗数と客数で、専門店並みの生産ロットを作れるか**が成否を分ける。

## 8. イオンとイトーヨーカドーの現在（2026年時点）

同じGMSから出発した2社が、真逆の方向へ進んだ。

| | イオン | イトーヨーカドー |
| --- | --- | --- |
| 親会社の戦略 | GMSを核にモール・金融・PBで生活圏を囲い込む | 本体はコンビニに集中、GMSを切り離す |
| 現在の位置づけ | イオンリテールのGMS事業（2026年2月期 営業収益3兆6,918億円、営業利益214億円） | 2025年9月、非中核29社超を束ねた「ヨーク・ホールディングス」がベインキャピタルへ売却完了（売却額8,147億円） |
| 出資構成 | 上場企業イオンの連結子会社 | ベイン60%／セブン＆アイ35.07%／創業家4.93% |
| 今後 | 2026〜2030年度の中期計画でGMS・SMの構造改革とPB拡大 | 2027〜28年のIPOを目指すと報じられる |
| 店舗 | 全国約350〜400店規模のGMS（イオン・イオンスタイル） | 構造改革で店舗数を大幅圧縮（93店体制を目標に閉店を継続） |

> ポイント：イオンは「**GMSを抱えたまま、モールと金融とPBで稼ぐ**」、セブン＆アイは「**GMSを手放し、コンビニ一本に絞る**」。
> 総合スーパー単体では十分な利益が出ないという認識は両社で共通しており、**違うのは処理の仕方だけ**である。

詳しい足元の動きは [直近トピック（2026年9月時点）](04_直近トピック_2026.md) を参照。

## 9. この歴史から読み取れること

1. **業態の寿命は、その業態が解決していた不便の寿命と等しい**。GMSは「買い回りの不便」を解いた。不便が消えれば業態も役目を終える
2. **規制は業態の形を決める**。大店法が守り、大店立地法が郊外へ押し出し、2006年改正が新規供給を止めた
3. **低粗利の商売に高い財務レバレッジは合わない**（ダイエーの教訓）
4. **総合小売は、儲かる部門が1つ抜けると全体が崩れる**。クロス補填の構造は強みであると同時に脆弱性でもある
5. 生き残り策は結局、**①食品への特化**、**②不動産（賃料）への転換**、**③PBによる粗利改善**の3つに収束する → [業態再編と生き残り](03_業態再編と生き残り.md)

## 10. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **GMS** | General Merchandise Store。衣食住を1店舗でセルフサービス販売する総合スーパー |
| **セルフサービス** | 対面接客・包装をやめ、客が自分で商品を選びレジに運ぶ方式。人件費を圧縮して安売りを可能にした |
| **カテゴリーキラー** | 特定カテゴリに絞って品揃えと価格で圧倒し、総合店からその売場を奪う専門店業態 |
| **SPA** | Speciality store retailer of Private label Apparel。企画・生産・販売を自社で一貫して行う小売。原価を下げ在庫を自分で管理できる → [アパレル・SPA](../10_アパレル・SPA/README.md) |
| **値入率（ねいれりつ）** | 仕入原価に対して最初につけた利幅の率。売価から見た「予定の粗利率」。値下げする前の数字 → [小売の経済学](02_小売の経済学.md) |
| **値下げロス（マークダウン）** | 売れ残りを値引きして売ることで失う利益。値入率と実際の粗利率の差の主因 |
| **核テナント（キーテナント）** | モールの集客を担う大型店舗。GMSはモールにおいてこの役割を担う |
| **大店法** | 大規模小売店舗法（1973年制定・74年施行、2000年廃止）。大型店の売場面積・営業時間を地元と調整させた事実上の出店規制 |
| **大店立地法** | 大規模小売店舗立地法（2000年施行）。規制目的を商業調整から周辺環境（交通・騒音・廃棄物）の保全へ転換した |
| **まちづくり三法** | 大店立地法・中心市街地活性化法・都市計画法の総称。2006年改正で1万㎡超の大規模集客施設の郊外立地を原則制限 |
| **クロス補填** | ある部門の集客力や利益で、別の部門の薄利を埋める構造。GMSは食品で集客し衣料の粗利で稼いでいた |
