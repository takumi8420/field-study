# 小売の経済学 ― 坪効率・在庫回転・粗利率・人件費率

このノートで分かること：**小売業の人が実際に使っている4つの共通言語**（坪効率／在庫回転／粗利率／人件費率）の意味と、その数字がどう噛み合って店の損益になるのか。
これが分かると、GMSでも食品スーパーでもコンビニでもドラッグストアでも、同じ物差しで比較できるようになる。

> ポイント：小売業の営業利益率は**良くて3〜4%**しかない。
> つまり **売価の3〜4%しか残らない商売**なので、どの数字が1ポイント動いても致命傷になりうる。「1%の議論」を真面目にするのが小売という業界。

## 1. まず1店舗のP/L（損益）を分解する

架空のGMS1店舗をモデルにする（**筆者の概算モデル。実在企業の数値ではない**）。

| 項目 | 金額 | 売上比 | 意味 |
| --- | --- | --- | --- |
| 売上高 | 40.0億円 | 100.0% | 客数 × 客単価の積み上げ |
| 売上原価 | 29.2億円 | 73.0% | 仕入れた商品の原価（値下げ・ロス込み） |
| **売上総利益（粗利）** | **10.8億円** | **27.0%** | 商品を売って手元に残る利益 |
| 人件費 | 5.2億円 | 13.0% | パート・社員の給与と社会保険料 |
| 賃借料・減価償却費 | 2.4億円 | 6.0% | 家賃、建物・什器の償却 |
| 水道光熱費・その他 | 2.4億円 | 6.0% | 電気、包装資材、宣伝、システム |
| **店舗営業利益** | **0.8億円** | **2.0%** | ここから本部経費を引くと本当の利益 |

読み方の勘所：

- **粗利27%のうち、人件費13%と家賃6%でほぼ2/3が消える**。この2つが小売の二大コスト
- **売上が5%落ちても、人件費と家賃はほとんど下がらない**（固定費）。だから売上減がそのまま利益減になる
- 逆に**売上が5%増えれば、増えた粗利のほとんどが利益として残る**。小売の利益は売上の増減に対して極端に振れる（オペレーティング・レバレッジが高い）

```
売上 40億 ──▶ 粗利 10.8億 ──┬─ 人件費  5.2億 （ほぼ固定）
 (100%)        (27%)          ├─ 家賃・償却 2.4億 （完全に固定）
                              ├─ 光熱その他 2.4億 （半固定）
                              └─ 営業利益 0.8億  ← 残りカスがここ

 売上が 5% 落ちると（38億）→ 粗利 10.26億、費用は据え置き 10.0億 → 利益 0.26億（▲68%）
 売上が 5% 増えると（42億）→ 粗利 11.34億、費用 10.1億        → 利益 1.24億（＋55%）
```

> これが「**既存店前年比**（既存店売上高の前年同月比）」が小売で最も注目される理由。新店を除いた既存店が前年を1%割るだけで、利益は二桁減る。

## 2. 坪効率 ― 面積あたりいくら売れているか

**坪効率**とは「売場1坪（約3.3㎡）あたり、年間いくら売れているか」。面積が固定費（家賃・光熱・清掃）を決めるので、**面積あたりの売上こそが小売の生産性**になる。

```
坪効率（年間） ＝ 年間売上高 ÷ 売場面積（坪）

例）年商40億円 ÷ 3,000坪（約10,000㎡）＝ 約133万円／坪・年
```

業態を並べると性格がはっきりする（**いずれも概算の目安。個社差が大きい**）。

| 業態 | 坪効率（年間・目安） | なぜその水準か |
| --- | --- | --- |
| コンビニ | 400〜600万円 | 面積が極小、単価は低いが回転が異常に速い |
| ドラッグストア | 200〜300万円 | 調剤・化粧品という高単価商材が面積を食わない |
| 食品スーパー | 180〜250万円 | 毎日来店。生鮮は面積効率が良い |
| **GMS** | **100〜150万円** | 衣料・住居に広い面積を割くが、その売場の回転が遅い |
| 百貨店 | 100〜200万円 | 立地次第で極端に振れる |
| ホームセンター | 60〜100万円 | 資材・園芸が大面積を必要とする |

**GMSの構造問題はここに集約される**。衣料と住居関連に売場の4〜5割を割いているのに、その売場の坪効率が食品の半分以下しかない。
面積は家賃と光熱費を発生させ続けるので、**売れない売場を持っていること自体がコストを垂れ流す**。

> だから各社は「GMSの衣料売場を縮めて食品を広げる」「空いた面積をテナントに貸す」という手を打つ → [業態再編と生き残り](03_業態再編と生き残り.md)

## 3. 在庫回転 ― 仕入れた商品が何回入れ替わるか

**在庫回転率**は「年間の売上原価 ÷ 平均在庫（原価ベース）」。1年に何回、棚の商品が入れ替わったかを示す。

```
在庫回転率 ＝ 年間売上原価 ÷ 平均在庫高
在庫日数   ＝ 365 ÷ 在庫回転率   （＝ 何日分の在庫を抱えているか）

例）年間原価 29.2億円 ÷ 平均在庫 2.0億円 ＝ 14.6回 → 在庫日数 25日
```

在庫回転が重要なのは、**在庫がお金だから**。仕入れた瞬間に現金が出ていき、売れるまで戻ってこない。回転が速ければ少ない運転資金で大きな売上が作れる。

部門別に見ると、GMSの中で全く性格が違う商品が同居していることが分かる。

| 部門 | 粗利率の目安 | 在庫回転（年） | 在庫日数 | 性格 |
| --- | --- | --- | --- | --- |
| 生鮮（青果・鮮魚・精肉） | 25〜35% | 80〜150回 | 2〜5日 | 粗利はそこそこ、回転は極端に速い。ロスが命 |
| 加工食品・日配 | 18〜23% | 30〜50回 | 7〜12日 | 薄利。集客の主役 |
| 日用品・雑貨 | 20〜25% | 10〜15回 | 25〜36日 | ドラッグストアと直接competing |
| 住居関連・家庭用品 | 28〜33% | 5〜8回 | 45〜73日 | 中間的 |
| **衣料品** | **35〜45%（値入）** | **3〜5回** | **73〜120日** | 粗利は厚いが回転が遅く、値下げロスが大きい |

**「食品は粗利が低く回転が速い／衣料は粗利が高く回転が遅い」**というのが小売の基本法則。
どちらが良いということはなく、両者は同じ結論（＝投下資本あたりの利益）に別ルートで到達する。

```
交差比率（GMROI的な見方） ＝ 粗利率 × 在庫回転率

 加工食品： 20% × 40回 ＝ 800
 衣料品　： 40% ×  4回 ＝ 160   ← 値下げ前でこの差
 生鮮　　： 30% × 100回 ＝ 3,000

 → 在庫に置いたお金がどれだけ効率よく粗利を生むかで見ると、
    「粗利が厚い」だけの衣料は、実は投資効率が悪い
```

> ポイント：**粗利率だけを見て「衣料は儲かる」と考えたのが、GMSの誤りだった**。
> 在庫に寝かせる金額と、売れ残りの値下げまで入れると、衣料の投資効率は食品に及ばない。

## 4. 値入とロス ― 「予定の利益」と「実際の利益」

小売に固有の重要概念が**値入（ねいれ）**と**ロス**。

- **値入率**：仕入原価に対して最初に設定した利幅。「この商品は原価600円、売価1,000円だから値入率40%」
- **粗利率**：実際に売れた結果の利幅。値引きやロスを引いた後の数字

```
        値入率 40%
           │
           ├─ 値下げロス（売れ残りの値引き）      ▲ 8%
           ├─ 棚卸ロス（廃棄・破損・万引き・計量誤差） ▲ 3%
           ├─ 従業員割引・販促原価               ▲ 1%
           ▼
        粗利率 28%   ← これが実際に手元に残る利幅
```

この「値入率と粗利率の差」を**ロス率**と呼び、小売の現場管理はほぼこの数字との戦いになる。

| ロスの種類 | 中身 | 起きやすい部門 | 対策 |
| --- | --- | --- | --- |
| 値下げロス（マークダウン） | 売れ残りの値引き・見切り | 衣料、生鮮、惣菜 | 発注精度、値引きのタイミング管理、需要予測AI |
| 廃棄ロス | 消費期限切れの処分 | 生鮮、惣菜、日配 | 小ロット製造、天候・曜日別の発注 |
| 不明ロス（シュリンク） | 万引き、計量ミス、レジ打ち誤り | 全般（特に小型高単価品） | ゲート、AIカメラ、セルフレジの重量検知 |

食品スーパーやGMSの生鮮部門では、**ロス率1%の改善が営業利益率0.3〜0.5%の改善に匹敵する**ことも珍しくない。営業利益率が2%台の商売なので、ロス管理は経営そのものになる。

## 5. 集客の2つの流儀 ― チラシ特売とEDLP

売上＝**客数 × 客単価**。客数を増やす方法に、対極的な2つの流儀がある。

| | チラシ特売（High-Low） | EDLP（Every Day Low Price） |
| --- | --- | --- |
| やり方 | 週に数品目を大幅値引き。チラシ・アプリで告知 | チラシをやめ、全品を常に安い価格で置く |
| 集客の仕組み | 目玉商品で来店動機を作り、ついで買いで粗利を取る | 「いつ行っても安い」という信頼で来店頻度を上げる |
| 必要なコスト | 販促費（チラシ・折込）、特売対応の作業（値札替え・大量陳列） | 継続的な原価低減。値札替えが少ないので作業コストは低い |
| 在庫・作業への影響 | 特売日に需要が跳ねるため作業とロスが増える | 需要が平準化し、発注・作業が安定する |
| 向いている企業 | 地域密着で競合が多い店 | 規模が大きくPBを持つ企業、ディスカウント業態 |
| 代表例 | 多くの食品スーパー、従来型GMS | オーケー、トライアル、海外ではウォルマート |

```
【High-Low】 需要が波打つ            【EDLP】 需要が平ら
   売上                                  売上
    │      ╱╲        ╱╲                  │ ────────────
    │  ╱╲╱  ╲  ╱╲╱  ╲                  │
    └──────────────▶ 日       └──────────────▶ 日
  → 特売日にピーク人員が要る          → 少ない人数で回せる
  → 発注が読みづらくロスが増える      → 発注が安定しロスが減る
  → 販促費が恒常的にかかる            → 販促費は低いが、価格で常に勝ち続ける必要
```

日本のGMSは長らくHigh-Lowだったが、**人手不足で「特売のたびに人を投入する」やり方が持たなくなった**こと、そしてディスカウント業態の台頭により、EDLP寄りへ傾斜する会社が増えている。イオンも中期計画で「価格強化と利益確保の両立」「省人化・高生産性の店舗オペレーション確立」を掲げている（2026年5月発表）。

## 6. PB（プライベートブランド）― 粗利を作り直す唯一の手

**PB**とは、小売企業が自らブランドを持ち、メーカーに製造委託して自社の店だけで売る商品のこと。対語は**NB（ナショナルブランド）**＝メーカーのブランド商品。

PBが効く理由は、単に「安いから売れる」ではない。**利益の取り分（マージンプール）の再配分**が本質。

```
【NB】 メーカー ──(卸値)──▶ 卸 ──(仕切)──▶ 小売 ──▶ 客
        広告費・営業費・              口銭        粗利 20%前後
        ブランド投資を負担                       （売価はメーカー主導）

【PB】 メーカー(受託製造) ──────────────▶ 小売 ──▶ 客
        広告なし・営業なし・企画は小売側        粗利 30〜40%
        工場の稼働を埋められる                （売価は小売が決める）
```

- メーカー側：広告・営業をせずに工場の稼働率を上げられる。余剰能力の埋め合わせになる
- 小売側：中間コストと広告費が乗らない分、**NBより2〜3割安く売って、なお粗利率は10ポイント高い**
- 客側：品質が同等なら安いほうを買う

実際の規模感として、イオンのPB「トップバリュ」は売上高1兆2,000億円（2026年2月期、イオン発表）に達し、PB全体では約1兆7,500億円。2027年2月期は1兆4,000億円、2030年度には2兆円という目標が示されている。トップバリュ内では最も価格訴求型の「ベストプライス」が伸びており、生活防衛意識の受け皿になっている。

ただしPBには弱点もある。

1. **売れ残りリスクを小売が負う**（NBなら返品・帳合調整の余地があるが、PBは自分の在庫）
2. **品質事故の責任が小売に来る**（ブランド毀損が全店に波及する）
3. **構成比が高すぎると客が飽きる**（NBの品揃えが薄い店は「選べない店」になる）
4. **PB比率が上がるほど、メーカーとの関係が調達交渉一辺倒になる**

食品メーカー側から見た構図は [総合食品](../../08_食品・農水産・外食/01_総合食品/README.md)、卸の立ち位置は [食品卸](../../06_商社・卸売/06_食品卸/README.md) を参照。

## 7. 人件費率と省人化 ― いま最大の論点

人件費率＝人件費 ÷ 売上高。GMSで12〜14%、食品スーパーで13〜16%程度が一般的な水準（目安）。
ここが崩れ始めている。

| 論点 | 状況（2025〜2026年） |
| --- | --- |
| 最低賃金 | 全国加重平均が1,121円へ、前年から＋66円・6.3%という過去最大級の引き上げ（報道ベース。年度の対応と正確な数値は厚生労働省の公表で確認） |
| 採用難 | 各種商品小売業の非正社員不足率は2023年4月56.9% → 2024年60.8% → 2025年62.5%（帝国データバンク調査） |
| 影響 | 売上比13%の人件費が6%上がると、**売上比で0.8ポイントの利益圧迫**。営業利益率2%の店なら利益が4割消える計算 |

対策は「レジ」と「バックヤード」の2方向。

```
【レジ周り】
 有人レジ → セミセルフ（会計だけ客） → フルセルフ → レジレス（カート・ゲート）
   人 1.0     人 0.4〜0.6            人 0.2〜0.3    人 0.1

【バックヤード】
 店内加工（精肉・鮮魚を店でさばく）
   → プロセスセンター／セントラルキッチンへ集約
   → 店では陳列だけ = 熟練者がいなくても店が回る
```

- セミセルフレジ（登録は店員、支払いは客）は導入が最も進んだ形。**現金の授受という最も時間のかかる工程だけを客に渡す**のが効率的だから
- 都市部のスーパーでセルフレジ導入により人件費を2割削減したという事例が紹介されるが、**ベンダー側の資料が出典であることが多く、条件依存が大きい**
- プロセスセンター化は人件費だけでなく**技能継承問題の解決**でもある。鮮魚をさばける人が採用できないので、集約するしかない
- 政府も「省力化投資促進プラン（小売業）」（2025年6月、農林水産省・経済産業省）として補助金で後押ししている

> ポイント：省人化投資は減価償却費（固定費）を増やす。**客数が減っている店で省人化投資をすると、人件費は下がっても償却費で相殺される**。
> だから省人化は「売上規模のある店」から順に入れるしかなく、地方の小型GMSほど打ち手が少ない。

## 8. 4つの数字の関係を1枚にまとめる

```
                    ┌─────────────┐
     店舗投資 ─────▶│  売場面積（坪） │──┐
                    └─────────────┘  │
                                        ▼
    商品調達 ───▶ 値入率 ──(ロス)──▶ 粗利率 ×  坪効率  ＝ 坪あたり粗利
     (PB/NB)                              ▲
                                          │
    在庫投資 ───▶ 在庫回転率 ───────┘（回転が速いほど少ない在庫で同じ売上）

    坪あたり粗利 －（人件費率＋賃借料率＋光熱費率）× 坪効率 ＝ 坪あたり利益
                                                                │
                                          全店合計 ＋ 本部経費 ＝ 会社の営業利益
```

覚えるべきは次の関係。

- **坪効率が低い売場は、粗利率が高くても赤字になる**（衣料売場の問題）
- **粗利率が低くても回転が速ければ成立する**（食品・ディスカウントの原理）
- **人件費率と賃借料率は売上に対する比率なので、売上が落ちると自動的に悪化する**
- 打ち手は4つしかない：**①売上を上げる ②粗利率を上げる（PB・ロス削減） ③面積を減らす ④人を減らす**

## 9. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **坪効率** | 売場1坪（約3.3㎡）あたりの年間売上高。面積が固定費を決めるため、小売の生産性指標として最重要 |
| **在庫回転率** | 年間売上原価 ÷ 平均在庫。棚の商品が1年に何回入れ替わるか。速いほど少ない運転資金で回せる |
| **在庫日数** | 365 ÷ 在庫回転率。何日分の在庫を抱えているか |
| **値入（ねいれ）／値入率** | 仕入原価に対して最初に設定した利幅。値引き前の「予定の粗利」 |
| **粗利率（売上総利益率）** | 実際に売れた結果の利幅。値入率からロスを引いた後の数字 |
| **ロス率** | 値入率と粗利率の差。値下げロス・廃棄ロス・不明ロスの合計 |
| **不明ロス（シュリンク）** | 原因が特定できない在庫の欠損。万引き、計量ミス、レジ誤りなど |
| **既存店前年比** | 新規開店・閉店を除いた同一店舗の売上前年比。小売の実力を測る最重要指標 |
| **客単価 × 客数** | 売上の分解式。客単価はさらに「1品単価 × 買上点数」に分解できる |
| **EDLP** | Every Day Low Price。特売をやめて常時低価格にする方式。需要と作業を平準化できる |
| **High-Low** | チラシ特売で目玉商品を安く出し、ついで買いで粗利を取る方式。日本のスーパーの伝統的手法 |
| **PB（プライベートブランド）** | 小売が自ら企画しメーカーに製造委託する自社ブランド商品。中間コストと広告費が乗らないため粗利率が高い |
| **NB（ナショナルブランド）** | メーカーが自ら広告・営業して全国展開するブランド商品 |
| **セミセルフレジ** | 商品登録は店員、支払いは客が専用機で行う方式。最も時間のかかる現金授受だけを客に渡す |
| **プロセスセンター（PC）** | 精肉・鮮魚などの加工を店舗から集約した加工センター。店の作業と技能依存を減らす |
| **オペレーティング・レバレッジ** | 固定費比率が高いほど、売上の変動が利益に増幅されて効く性質 |
