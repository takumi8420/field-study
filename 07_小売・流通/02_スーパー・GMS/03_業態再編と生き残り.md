# 業態再編と生き残り

このノートで分かること：**総合スーパーが単体では儲からないと分かった後、各社が何に転換したのか**。
食品スーパー化、ディスカウントとの競合、モール運営（デベロッパー業）への転換、金融・不動産・リテールメディアという非小売収益、ネットスーパーの採算、そして地方の地場スーパーの再編まで。

> ポイント：GMSの生き残り策は結局4つに収束する。
> **①食品に寄せる ②場所貸しで稼ぐ ③小売以外の収益源を作る ④規模を寄せ合う（再編）**。
> どれも「商品を仕入れて売る差額」以外から利益を取りに行く動きである点が共通している。

## 1. 生き残り策の全体地図

```
                        GMS（衣食住の総合大型店）
                        利益が出ない・坪効率が低い
                                  │
        ┌─────────────┬──────────┼──────────┬─────────────┐
        ▼             ▼          ▼          ▼             ▼
  ①食品スーパー化  ②モール化   ③非小売収益  ④ディスカウント化  ⑤再編・撤退
  衣料を縮め      空き面積を   金融・不動産  価格で正面から    地域内で統合
  食品を広げる    テナントへ   リテールメディア 戦う            or 閉店
        │             │          │          │             │
        ▼             ▼          ▼          ▼             ▼
  粗利は薄いが    在庫リスク   小売の客基盤  規模がないと   固定費の
  客数が戻る      ゼロの賃料   を他事業で    原価で負ける   絶対量を削る
                  ＝安定利益    現金化
```

## 2. ①食品スーパー化 ― 「総合」をやめる

最も普遍的な打ち手。**衣料・住居関連の売場を縮め、食品と日配・惣菜を広げる**。

理由は [小売の経済学](02_小売の経済学.md) で見たとおり、食品が坪効率と来店頻度で圧倒的に優れているから。

| 指標 | 食品 | 衣料品 |
| --- | --- | --- |
| 来店頻度 | 週2〜4回 | 年数回 |
| 坪効率（年・目安） | 200〜250万円 | 60〜100万円 |
| 在庫回転（年） | 30〜150回 | 3〜5回 |
| 粗利率 | 20〜30%（安定） | 値入40%前後だが値下げ後は20%台に落ちることも |
| 必要な能力 | 鮮度管理、発注精度、加工要員 | 商品企画（SPA能力）、消化率管理 |

食品化の具体的な形は次の3つ。

1. **売場の付け替え**：2階の衣料フロアを縮小し、1階の食品・惣菜を拡張する。イオンの「イオンスタイル」への転換はこの方向
2. **空いた面積のテナント化**：自前で売らず、専門店に貸して賃料に変える（＝②へ接続）
3. **食品スーパーへの業態転換**：GMSを閉じて、同じ商圏に小型の食品スーパーを出し直す

ただし食品化には落とし穴がある。**食品は粗利が薄いので、売上が同じでも利益は減る**。衣料の厚い粗利を失った分を、PBとロス削減と省人化で埋められなければ、食品化は「じり貧の別の形」になる。

詳細な食品小売の経済性は [食品スーパー](../03_食品スーパー/README.md)、惣菜・中食の伸びは [中食・弁当](../../08_食品・農水産・外食/20_中食・弁当/README.md)、[冷凍食品・惣菜](../../08_食品・農水産・外食/06_冷凍食品・惣菜/README.md) を参照。

## 3. ②モール運営 ― デベロッパー業への転換

GMSにとって最大の資産は、店ではなく**土地と建物と駐車場**だった。これを「自分で商売する場所」から「他人に貸す場所」へ切り替えたのがモール事業。

```
【小売業（GMS）】                    【デベロッパー業（モール）】
 仕入れる → 在庫を持つ → 売る        場所を作る → テナントを集める → 賃料を取る
   ↑ 在庫リスク                        ↑ 在庫リスクなし
   ↑ 売れ残りロス                      ↑ 空室リスクのみ
   ↑ 人件費が重い                      ↑ 運営人員は少数
 営業利益率 0〜2%                     営業利益率 12〜15%
```

数字で見ると差は歴然としている（イオン 2026年2月期、イオンIR）。

| セグメント | 営業収益 | 営業利益 | 営業利益率（概算） |
| --- | --- | --- | --- |
| GMS事業 | 3兆6,918億円 | 214億円 | 約0.6% |
| ディベロッパー事業 | 5,224億円 | 709億円 | 約13.6% |
| （うちイオンモール） | 4,727億円 | 684億円 | 約14.5% |

> **売上が7分の1の事業が、3倍以上の利益を出している**。
> GMSは「儲ける事業」ではなく「モールに客を呼ぶための集客装置」になっている、というのがイオンの現在の構造。

賃料の取り方には2種類あり、これがモールのリスク特性を決める。

| 賃料方式 | 仕組み | 誰が有利か |
| --- | --- | --- |
| 固定賃料 | テナント売上に関係なく定額 | モール側が安定。不況時にテナントが撤退しやすい |
| **歩合賃料（売上歩合）** | テナント売上の数%を賃料とする | モール側もテナントの好不調を共有。日本のモールで主流 |
| 固定＋歩合の併用 | 最低保証＋超過分の歩合 | 実務上最も多い折衷案 |

歩合賃料が主流であるため、**モールの業績はテナントの売上（＝専門店売上高）に直結する**。イオンモールは国内既存モールの専門店売上高が前期比105.7%、来店客数102.7%（2026年2月期）と回復しており、それが利益に反映された。海外（中国・ASEAN）も集客が回復している。

不動産としてのモールの見方は [不動産デベロッパー](../../12_建設・住宅・不動産/08_不動産デベロッパー/README.md)、証券化して外部資金で回す仕組みは [不動産金融・REIT](../../05_金融/13_不動産金融・REIT/README.md) を参照。

## 4. ③非小売収益 ― 客基盤を別の商売で現金化する

大型店には「毎週来る大量の顧客」という資産がある。これを商品以外で現金化するのが非小売収益。

| 収益源 | 中身 | なぜ小売が有利か |
| --- | --- | --- |
| **金融（銀行・カード・電子マネー）** | イオン銀行、イオンカード、WAON | 店舗が支店代わりになり、買い物データで与信できる。決済手数料も内部に残る → [クレジットカード・決済](../../05_金融/11_クレジットカード・決済/README.md) |
| **不動産（モール・賃貸）** | イオンモール、イオンリート | 上記②のとおり |
| **リテールメディア** | 店内デジタルサイネージ、アプリのクーポン枠、EC内の広告枠をメーカーに販売 | 「購買データを持つ媒体」としてメーカーの広告費を直接取れる → [広告代理店](../../14_メディア・広告・エンタメ/01_広告代理店/README.md) |
| **PB供給・卸** | 自社PBを他社へ供給する | 生産ロットが増え原価が下がる |
| **サービス（保険・旅行・電力）** | イオンでんき、保険代理 | 既存会員にクロスセルできるので獲得コストがほぼゼロ |

リテールメディアは足元で最も伸びている領域。国内市場は6,000億円規模を超え、2028年には1兆円規模へ拡大するという調査会社の予測がある（**推計であり、定義によって数字が大きく変わる点に注意**）。
イオンリテールでもリテールメディアの営業収益が前期比2倍になったとされ（2026年2月期）、イオンお買物アプリの会員は1,070万人超、統合アプリ「iAEON」のダウンロードは1,800万超と報じられている。

> ポイント：リテールメディアの本質は「**粗利率100%に近い収益**」であること。
> 商品を売る粗利は27%だが、広告枠を売る粗利はほぼ全額が利益になる。
> 営業利益率が1〜2%の小売にとって、数百億円の広告収益は本業の数千億円の売上に匹敵するインパクトを持つ。

ただし限界もある。広告枠は無限には売れず、**クーポンを出しすぎれば自社の売価を下げることと同じ**になる。メディア収益と商品粗利は一部でトレードオフの関係にある。

## 5. ④ディスカウントとの競合 ― 正面から価格で戦えるか

GMSの食品売場が直接ぶつかっているのがディスカウント業態。代表がトライアルとオーケー、そしてドン・キホーテ。

| | GMSの食品売場 | ディスカウント（トライアル型） |
| --- | --- | --- |
| 品揃え（SKU数） | 広い。NBを網羅する | 絞る。売れ筋だけを大量に |
| 陳列 | 什器に美しく陳列 | **ダンボールのまま積む（カットケース陳列）** |
| 作業量 | 多い（品出し・前出し・値札替え） | 少ない。作業を設計段階で削る |
| 粗利率 | 25〜30% | 15〜20% |
| 販促 | チラシ特売（High-Low） | EDLP |
| 営業時間 | 標準的 | 長時間・24時間も |
| テクノロジー | POS、セルフレジ | AIカメラ付きカート、リテールAI、購買データのメーカー販売 |

ディスカウントが安く売れるのは、**値引きしているからではなく、コストを構造から抜いているから**。
品揃えを絞る → 1品あたりの仕入量が増える → 原価が下がる。作業を減らす → 人件費率が下がる。この2つの積み重ねで粗利率15%でも利益が出る体質を作っている。

GMSが同じ土俵で戦うのは難しい。**総合であるがゆえに品揃えを絞れず、作業量も減らせない**からだ。だからGMS側の回答は「価格で完全には負けない水準まで下げつつ、鮮度・惣菜・専門売場という価格以外の価値で差をつける」という中間解になる。

業態そのものの詳細は [ディスカウントストア](../09_ディスカウントストア/README.md) を参照。

## 6. ⑤ネットスーパーの採算 ― なぜ長く赤字だったのか

ネットスーパーは便利だが、**構造的に儲けにくい**。理由は原価計算をすれば明らかになる。

```
【店舗型ネットスーパー】既存店の棚から店員が商品を集めて配送
  客単価 5,000円 × 粗利率 25% ＝ 粗利 1,250円
   － ピッキング人件費（30〜40分／件）  約 700〜900円
   － 配送コスト（自社便・委託）        約 500〜800円
   － 資材・システム                    約 100円
  ＝ 1件あたり ▲200〜▲600円 の赤字
   （※筆者の概算モデル。配送料を客が負担すれば改善する）
```

赤字の正体は**ピッキング（商品集め）**。店の棚は「客が歩いて選ぶ」ために設計されており、作業者が効率よく集めるようにはできていない。1件30分以上かかれば、粗利1,250円は人件費で消える。

そこで各社が取ったのが**専用倉庫型（ダークストア／CFC）**。

| 方式 | 仕組み | 損益 | 代表例 |
| --- | --- | --- | --- |
| 店舗型 | 既存店の棚から店員がピック | 初期投資は小さいが1件ごとに赤字が出やすい | 多くのスーパーの既存ネットスーパー |
| **専用倉庫型（CFC）** | 自動化倉庫で機械がピック。店を介さない | 初期投資が巨額だが、件数が増えるほど1件あたりコストが下がる | イオン「Green Beans」（2023年7月開業） |
| ダークストア | 小型の非公開店舗を配送拠点に | 中間的。都市部の即配向け | 各社が実験中 |

イオンの次世代ネットスーパー「Green Beans」は、英Ocadoの技術を使った自動化倉庫から配送する方式。会員数は60万人を突破し（2026年、報道ベース）、**2030年までに単年度黒字化**を目標としている。逆に言えば、**開業から7年かけてようやく黒字を目指す規模の事業**ということでもある。
一方、既存のイオンリテールのネットスーパー事業は2026年2月期に黒字転換したとされる。

> ポイント：ネットスーパーは「装置産業」である。
> 自動化倉庫は巨額の固定費なので、**稼働率（受注件数）がすべて**。半導体工場やデータセンターと同じ経済性を持つ。
> 倉庫側の設計思想は [倉庫・3PL](../../13_運輸・物流/08_倉庫・3PL/README.md)、[物流施設](../../12_建設・住宅・不動産/16_物流施設/README.md) も参照。

## 7. 地方の地場スーパーと再編

地方には、県内で数十店を展開する地場スーパーが数多くある。彼らは商圏を熟知し、地元の農産物や惣菜で強い支持を持つが、**単独では以下の3つが揃わない**。

1. **調達規模**：PBを作るロットに足りず、NBの仕入条件でも大手に劣る
2. **システム投資**：POS刷新、需要予測、セルフレジ、EC基盤に数十億円を出せない
3. **人材**：物流・デジタル・商品開発の専門人材を採用できない

この3つを共有するために、①大手の傘下に入る ②資本提携せずに共同仕入組織へ加盟する ③地域内で対等合併する、という選択肢が取られてきた。

| 再編の型 | 仕組み | 得られるもの | 失うもの |
| --- | --- | --- | --- |
| 大手グループ入り | イオン、ライフ、トライアル等の傘下へ | 調達条件、PB、システム | 商品編集の自由度、地域色 |
| 共同仕入（ボランタリーチェーン） | 資本は独立のまま、仕入とPBを共同化 | 調達条件の一部 | 効果は限定的。意思決定が遅い |
| 地域内合併 | 同一商圏の2〜3社が統合 | 重複店の整理、物流の共同化 | 商圏が重なると店を閉めることになる |
| ファンドへの売却 | PEファンドが買い、再建後にIPOや再売却 | 資本と経営人材 | 中期的に出口（売却）が前提になる |

足元での最大の再編は、**九州発のディスカウント大手トライアルホールディングスによる西友の買収**（2025年7月に完了、買収額は約3,800億円と報じられる）。合算売上高は1兆2,000億円規模となり、食品小売でセブン＆アイ、イオンに次ぐ位置に浮上した。トライアルは2027年6月期〜2029年6月期を西友のPMI（統合作業）に充て、その後さらなるM&Aも視野に入れるとしている。
またセブン＆アイは非中核29社超を束ねたヨーク・ホールディングスをベインキャピタルへ売却（2025年9月完了、8,147億円）し、2027〜28年のIPOを目指すと報じられている。**大手のGMS切り離しと、ディスカウント勢による買い集めが同時に進んでいる**のが現在の構図。

## 8. 何が生き残るのか ― 判断軸の整理

| 軸 | 生き残りやすい | 苦しい |
| --- | --- | --- |
| 立地 | 商圏人口が維持され、モール化できる大型店 | 商圏が縮む地方の中型GMS。モール化するには小さく、食品スーパーとしては大きすぎる |
| 面積 | 食品比率を高め、余剰面積をテナント化できる | 衣料フロアを持て余し、貸す相手もいない |
| 調達 | PB比率を上げ、粗利率を作り直せる規模がある | ロットが足りずPBが作れない |
| 人員 | 省人化投資を回収できる売上規模がある | 投資すると償却費で利益が消える規模 |
| 資本 | 非小売収益（金融・不動産・メディア）を持つ | 小売の粗利だけで勝負している |

> 最終的な結論：**「中途半端な大きさの、中途半端な総合店」が最も苦しい**。
> 大きければモールに、小さければ食品スーパーになれるが、その中間は逃げ場がない。
> 日本のGMSの閉店は、ほぼこの層で起きている。

足元の具体的な動きは [直近トピック（2026年9月時点）](04_直近トピック_2026.md)、歴史的経緯は [GMSというモデルの盛衰](01_GMSというモデルの盛衰.md) を参照。

## 9. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **デベロッパー事業** | 商業施設を開発・保有し、テナントから賃料を得る事業。在庫リスクがなく利益率が高い |
| **核テナント（キーテナント）** | モールの集客を担う大型店舗。GMSがこの役割を担うことが多い |
| **歩合賃料** | テナントの売上高に一定率を掛けて算出する賃料。好不調をモールとテナントで共有する |
| **PMI** | Post Merger Integration。M&A後に業務・システム・人事を統合する作業。買収の成否はここで決まる |
| **ボランタリーチェーン** | 資本関係のない独立小売が、仕入やPBを共同化するために組む組織 |
| **リテールメディア** | 小売が自社の店舗・アプリ・ECの広告枠をメーカーに販売する事業。購買データと結び付くため広告効果を測りやすい |
| **ダークストア** | 客を入れず、ネット注文の商品集めと配送専用に使う店舗型拠点 |
| **CFC** | Customer Fulfilment Centre。ネットスーパー専用の自動化倉庫。イオンの Green Beans が採用 |
| **ピッキング** | 注文された商品を棚から集める作業。ネットスーパーの最大のコスト要因 |
| **SKU** | Stock Keeping Unit。在庫管理上の最小単位（サイズ・色違いは別SKU）。品揃えの広さを表す |
| **カットケース陳列** | ダンボールの上部を切って箱ごと積む陳列。品出し作業を大幅に減らせるディスカウントの基本手法 |
| **オムニチャネル** | 店舗・EC・アプリを顧客IDで統合し、どこで買っても同じ体験にする考え方 |
