# 直近トピック（2026年9月時点）

報道・各社IRベースの整理。数値は発表時点のもので、一次情報での裏取りを前提とする。
構造的な背景は [GMSというモデルの盛衰](01_GMSというモデルの盛衰.md)、[小売の経済学](02_小売の経済学.md)、[業態再編と生き残り](03_業態再編と生き残り.md) を参照。

> このタイミングの論点を一言で：**業界の勢力図が「GMSを持つ会社」から「食品とディスカウントで規模を取る会社」へ書き換わりつつある**。
> 値上げ局面で売上は伸びているが、それは数量が増えているのではなく単価が上がっているだけ、という点に注意が要る。

## 1. イオンが国内小売首位に（2026年2月期）

イオンの2026年2月期（2025年度）決算は以下のとおり（イオンIR、2026年4月9日発表）。

| 指標 | 金額 | 前期比 |
| --- | --- | --- |
| 営業収益 | 10兆7,153億円 | +5.7% |
| 営業利益 | 2,704億円 | +13.8% |
| 経常利益 | 2,430億円 | +8.4% |
| 当期純利益 | 727億円 | +26.7% |

営業収益・営業利益・経常利益が過去最高を更新し、**営業収益でセブン＆アイ・ホールディングスを上回って国内小売業トップ**になった。ただしこれは、セブン＆アイが非中核事業（後述のヨークHD）を切り離した影響も大きく、**イオンが伸びたというより比較対象が縮んだ側面がある**点は割り引いて読む必要がある。

セグメント別に見ると、GMSとディベロッパーの利益格差が鮮明。

| セグメント | 営業収益 | 営業利益 | 利益率（概算） |
| --- | --- | --- | --- |
| GMS事業 | 3兆6,918億円（+3.7%） | 214億円（+51億円） | 約0.6% |
| ディベロッパー事業 | 5,224億円（+5.3%） | 709億円（+179億円） | 約13.6% |
| （うちイオンモール） | 4,727億円（+5.1%） | 684億円（+31.2%） | 約14.5% |

```
【グループ利益の出どころ】
  売上規模  GMS ████████████████████████████████████  3.7兆円
            DEV ████                                   0.5兆円

  利益規模  GMS █                                      214億円
            DEV ███                                    709億円
                 ↑ 売上7分の1の事業が3倍以上の利益を出している
```

当期純利益が営業利益に比べて小さいのは、減損損失（不採算店舗の資産価値の切り下げ）や少数株主持分の影響によるもの。**GMSは今も継続的に減損を出す事業**であることの裏返しでもある。

## 3. セブン＆アイのGMS切り離しとヨークHDのIPO

セブン＆アイ・ホールディングスは、イトーヨーカ堂・ヨークベニマル・ロフト・赤ちゃん本舗・セブン＆アイ・フードシステムズなど**非中核29社超を束ねた中間持株会社「ヨーク・ホールディングス」を米ベインキャピタルへ売却**した。

| 項目 | 内容 |
| --- | --- |
| 売却完了 | 2025年9月1日 |
| 売却額 | 8,147億円 |
| 売却後の出資比率 | ベインキャピタル60% / セブン＆アイHD 35.07% / 創業家 4.93% |
| 対象 | イトーヨーカ堂、ヨークベニマル、ロフト、赤ちゃん本舗、セブン＆アイ・フードシステムズなど29社超 |
| 今後 | ヨークHD社長が2027〜28年のIPOを目指すと発言（報道ベース） |

```
【セブン＆アイの構造転換】

 旧： セブン-イレブン ＋ イトーヨーカ堂 ＋ そごう・西武 ＋ 金融 ＋ 専門店
          （利益の大半）   （長年の赤字）   （2023年売却）

 新： セブン-イレブン（国内＋北米）に集中
          │
          └─ 非中核29社 → ヨークHD → ベイン60%出資 → 2027〜28年IPOへ
```

これはGMSという業態に対する経営判断としては最も明快な形、すなわち**「総合小売をやめてコンビニ専業になる」**という選択である。イオンが「GMSを抱えたままモール・金融・PBで稼ぐ」道を選んだのと対照的で、**同じ問いに対する2つの異なる解答**が並んでいるのが現在の日本のGMSである。

なおイトーヨーカ堂自体は、不採算店の閉鎖・PB強化・経費圧縮により、直近決算で売上は減ったが利益は大きく改善したと報じられている。**縮小によって黒字化する**という典型的な再建のパターンで、IPOに向けた収益性の作り込みが進んでいると読める。

## 4. トライアルによる西友買収と業界再編の主導権

九州発のディスカウント大手**トライアルホールディングスが西友を買収**（2025年7月完了、買収額は約3,800億円と報じられる）。合算売上高は1兆2,000億円規模となり、食品小売ではセブン＆アイ、イオンに次ぐ位置に浮上した。

| 論点 | 内容 |
| --- | --- |
| 規模 | 合算売上高 約1.2兆円（報道ベース） |
| 地理的な意味 | 九州地盤のトライアルが、西友の首都圏店舗網を一気に獲得 |
| 手法 | 西友の大型店をトライアル流に改装、既存店から商品を届ける小型店の出店も本格化 |
| 今後 | 2027年6月期〜2029年6月期をPMI（統合作業）に充て、2030年6月期以降に規模拡大。新たなM&Aも視野 |
| 技術 | AIカメラ付きスマートショッピングカート、購買データのメーカー向け提供（リテールAI）が特徴 |

トライアルの特異性は、**小売でありながら自社でテクノロジーを内製している**こと。カートに付けたカメラとディスプレイで、客ごとのクーポンを出しながら購買データを取得し、そのデータをメーカーに販売する。これは [小売の経済学](02_小売の経済学.md) で触れたリテールメディアの一形態であり、粗利率15〜20%という薄利のディスカウント業態を、データ収益で補強する設計になっている。

> ポイント：**GMSを手放す側（セブン＆アイ）と、GMS的な大箱を買い集める側（トライアル）が同時に存在する**。
> 同じ箱でも、High-Lowの総合スーパーとして使うか、EDLPのディスカウントとして使うかで経済性が全く変わる、ということの実証実験が進んでいる。

## 5. 人件費と省人化 ― 構造的なコスト圧力

| 論点 | 数値 | 出典の性質 |
| --- | --- | --- |
| 最低賃金 | 全国加重平均1,121円へ、前年から＋66円・6.3%という過去最大級の引き上げ | 報道ベース。適用年度と正確な数値は厚生労働省の公表で確認 |
| 採用難 | 各種商品小売業の非正社員不足率：2023年4月56.9% → 2024年60.8% → 2025年62.5% | 帝国データバンク調査 |
| 政府の支援 | 「省力化投資促進プラン ―小売業―」（2025年6月、農水省・経産省） | 政府資料 |
| セルフレジ効果 | 都市部スーパーで人件費2割削減の事例が紹介される | ベンダー資料。条件依存が大きい |

[小売の経済学](02_小売の経済学.md) で見たとおり、人件費は売上の13%前後を占める。これが6%上がれば売上比0.8ポイントの利益圧迫になり、**営業利益率2%の店なら利益の4割が消える**。
そのため各社は、セミセルフレジ・フルセルフレジ・レジレスカート、プロセスセンターへの加工集約、電子棚札による値札替え作業の廃止、といった省人化投資を継続している。

ただし省人化投資は減価償却費という固定費に変わる。**客数が細っている店では、人件費の削減分を償却費が食う**。結果として、省人化が進めば進むほど「投資を回収できる規模の店」と「できない店」の差が開き、閉店の判断が加速するという副作用がある。

## 6. 値上げ局面の売上と、数量の減少

2025年のスーパー販売額は16兆8,026億円（前年比+4.7%、既存店ベース+2.7%）で4年連続の増加、1990年以降で最大水準となった（経済産業省 商業動態統計）。

ただし読み方に注意が要る。

```
売上高の伸び ＝ 客数の変化 × 買上点数の変化 × 1品単価の変化
                  （横ばい〜減）   （減）        （大きく増 ← 値上げ）

  → 売上が過去最高でも、「たくさん売れている」わけではない
  → 米・生鮮を中心とした価格上昇が金額を押し上げている
```

- 商業動態統計の「スーパー」は売場面積1,500㎡以上のセルフ店を指し、**総合スーパー（GMS）と大型食品スーパーの両方を含む**。GMS単独の数字ではない
- 日本チェーンストア協会の販売統計（加盟企業ベース）では食品構成比が高まり続けており、**チェーンストア全体の「食品業態化」**が統計にも表れている
- 各社が「客数・買上点数の改善」を経営課題に掲げているのは、**金額は増えても数量は減っている**ことの裏返し

> ポイント：値上げによる増収は、粗利額も押し上げる一方で、客の生活防衛意識を強めて**PBとディスカウントへの移動を加速させる**。
> トップバリュの中で最も価格訴求型の「ベストプライス」の伸び率が最も高い（上期+13.9%）のは、その現れ。

## 8. 全体の構図（まとめ）

1. **GMS単体では利益が出ないという認識が、業界全体で確定した**。イオンでもGMS事業の営業利益率は約0.6%にとどまる
2. **処理の仕方が2つに割れた**。イオンは抱えたままモール・金融・PB・メディアで稼ぐ、セブン＆アイは切り離してコンビニに集中する
3. **切り離された大箱は、ディスカウント勢とファンドが引き受けている**。トライアル＋西友、ベイン＋ヨークHD。**箱の所有者が変わり、使い方が変わる局面**にある
4. **値上げで売上は過去最高だが、数量は減っている**。粗利額は増えても、客の生活防衛はPBとディスカウントへの移動という形で進んでいる
5. **人件費の上昇が省人化投資を強制し、それが店舗の選別を加速させる**。投資を回収できる規模の店だけが残る構造になりつつある

## 9. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **セグメント（報告セグメント）** | 決算で事業ごとに売上・利益を区分して開示する単位。イオンならGMS事業・SM事業・ディベロッパー事業・総合金融事業など |
| **減損損失** | 店舗などの資産が将来生む利益が帳簿価額を下回ると判断された際に、差額を一括で費用処理すること。不採算店を抱える小売では常に発生する |
| **PMI** | Post Merger Integration。M&A後に業務・システム・人事を統合する作業。トライアル×西友の成否はここで決まる |
| **IPO** | Initial Public Offering。新規株式公開。ヨークHDは2027〜28年の上場を目指すと報じられる |
| **既存店ベース** | 新規開店・閉店の影響を除いた同一店舗での比較。販売統計で全店ベースと区別して読む必要がある |
| **リテールメディア** | 小売が自社の店舗・アプリ・ECの広告枠をメーカーに販売する事業。商品粗利と違い、ほぼ全額が利益になる |
| **CFC** | Customer Fulfilment Centre。ネットスーパー専用の自動化倉庫。固定費が巨額なので稼働率（受注件数）が採算を決める |
| **セミセルフレジ** | 商品登録は店員、支払いは客が専用機で行う方式。現金授受という最も時間のかかる工程だけを客に渡す |
