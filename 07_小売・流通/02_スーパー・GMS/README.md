## 1. 業界の定義・範囲

**GMS（General Merchandise Store＝総合スーパー）**とは、1つの大型店舗で**衣料品・食品・住居関連用品（衣食住）をセルフサービスで販売する業態**を指す。
「セルフサービス」は、店員が対面で接客・包装するのではなく、客が自分で選んでレジに運ぶ方式のこと。この省人化によって安く売るのがスーパーの出発点だった。

隣接業態との境界は次のとおり。

| | GMS | 食品スーパー | 百貨店 | ディスカウント | コンビニ |
| --- | --- | --- | --- | --- | --- |
| 売場面積 | 6,000〜30,000㎡ | 1,000〜3,000㎡ | 20,000㎡〜 | 3,000〜6,000㎡ | 100〜200㎡ |
| 扱う範囲 | 衣食住すべて | 食品中心 | 衣料・雑貨中心 | 食品＋日用品 | 即食中心 |
| 販売方式 | セルフ | セルフ | 対面 | セルフ | セルフ |
| 価格 | 中位 | 中位 | 高位 | 最低位 | 高位 |
| 粗利率の目安 | 25〜30% | 24〜27% | 25〜30% | 15〜20% | 30%前後 |

業態の位置関係を「売場面積」と「価格帯」で置くと、GMSが挟まれている構図が見える。

```
 価格
  高 │  百貨店
     │    ●                     ● GMS（総合スーパー）
     │              ● コンビニ    ↑ 上からも下からも削られている
     │                            │
  中 │        ● 食品スーパー  ────┘
     │        ● ドラッグストア  ● ホームセンター
     │
  低 │        ● 100円ショップ   ● ディスカウント
     └────────────────────────────────────▶ 売場面積
       小                                   大
```

実務上は**「食品売場を持つ大型店のうち、衣料・住居関連も相当の面積で扱うもの」**がGMSと呼ばれる。ただし近年は各社が衣料を縮小しているため、GMSと大型食品スーパーの境界は曖昧になりつつある。
経済産業省の商業動態統計では「スーパー」を売場面積1,500㎡以上のセルフ店として一括りにしており、**GMS単独の統計は取りにくい**点に注意。

## 2. 市場規模と成長性

| 指標 | 数値 | 時点・出典 |
| --- | --- | --- |
| スーパー販売額（商業動態統計） | 16兆8,026億円、前年比+4.7%（既存店+2.7%） | 2025年・経済産業省。4年連続増、1990年以降で最大水準 |
| チェーンストア販売額（協会加盟ベース） | 12〜13兆円台。食品構成比が上昇中 | 2020年代半ば・日本チェーンストア協会。最新は協会サイトで確認 |
| イオンのGMS事業 営業収益 | 3兆6,918億円（+3.7%）／営業利益214億円 | 2026年2月期・イオンIR |
| イオン連結 営業収益 | 10兆7,153億円（+5.7%） | 2026年2月期・イオンIR。国内小売業トップ |

成長性の読み方が重要。

> **売上が過去最高でも、数量は増えていない。**
> 売上 ＝ 客数 × 買上点数 × 1品単価。近年の増収は米・生鮮を中心とした**単価上昇**によるもので、
> 客数と買上点数はむしろ減っている企業が多い。各社が「客数・買上点数の改善」を経営課題に掲げているのはこのため。

長期的には人口減と世帯縮小が需要の上限を押し下げる一方、**中食（惣菜・弁当）へのシフト**と**PBへの移動**という構成変化が続く。GMSにとっての成長余地は市場の拡大ではなく、**シェアの取り合いと粗利構造の作り直し**にある。

## 3. バリューチェーン（川上 → 川下）

```
【NBルート】
 メーカー ──▶ 卸（食品卸・日用品卸）──▶ GMS ──▶ 消費者
  広告・営業費      口銭・物流・帳合         粗利 20〜25%
  を負担                                    （売価の主導権はメーカー寄り）

【PBルート】
 受託メーカー ──────────────────▶ GMS ──▶ 消費者
  広告なし・営業なし                        粗利 30〜40%
  工場の稼働率を埋める                      （企画も売価も小売が決める）

【生鮮ルート】
 産地・市場 ──▶ 集荷・ベンダー ──▶ プロセスセンター ──▶ 店舗 ──▶ 消費者
                                     （加工を店から集約 ＝ 省人化）
```

付加価値がどこに集まるかは**「誰が売価を決めるか」**で決まる。NBはメーカー、PBは小売。だから各社はPB比率を上げようとする。
川上の卸・メーカー側の見方は [食品卸](../../06_商社・卸売/06_食品卸/README.md)、[総合食品](../../08_食品・農水産・外食/01_総合食品/README.md) を参照。

## 5. 収益モデル・コスト構造

モデル店舗（**筆者の概算。実在企業の数値ではない**）で見た1店舗の姿。

| 項目 | 売上比 |
| --- | --- |
| 売上高 | 100.0% |
| 売上総利益（粗利） | 27.0% |
| 　人件費 | 13.0% |
| 　賃借料・減価償却費 | 6.0% |
| 　水道光熱・その他 | 6.0% |
| 店舗営業利益 | 2.0% |

- **粗利27%の2/3を人件費と家賃が食う**。これが小売の基本構造
- 人件費・家賃は固定費なので、**売上が5%落ちると営業利益は6〜7割消える**（オペレーティング・レバレッジが高い）
- だから小売では「**既存店前年比**（新店を除いた同一店の売上前年比）」が最重要指標になる
- GMSの弱点は**坪効率**（売場1坪あたりの年間売上）。GMSは100〜150万円／坪・年で、食品スーパーの180〜250万円に大きく劣る。**衣料・住居に広い面積を割いているのに、その売場の回転が遅い**ため

利益を改善する打ち手は4つしかない：**①売上を上げる ②粗利率を上げる（PB・ロス削減） ③面積を減らす ④人を減らす**。
詳しい計算と各指標の意味は [② 小売の経済学](02_小売の経済学.md)。

## 6. 競争要因（KSF）と参入障壁

| KSF | 中身 |
| --- | --- |
| **立地と面積の確保** | 2006年のまちづくり三法改正で1万㎡超の郊外立地が原則制限され、**既存の大型店が希少資産になった**。これが最大の参入障壁 |
| **調達規模とPB開発力** | PBを作るには生産ロットが要る。トップバリュ1兆2,000億円（2026年2月期）のような規模は新規参入では作れない |
| **ロスと発注の精度** | 営業利益率2%の商売では、ロス率1%の改善が利益を数割動かす |
| **省人化のための投資余力** | 最低賃金上昇に対抗するにはセルフレジ・電子棚札・プロセスセンターが要るが、投資は償却費になる。回収できる売上規模が必要 |
| **物流網** | 常温・チルド・冷凍の三温度帯物流を自前で持てるか。共同配送・センター運営の巧拙が原価に直結 |
| **非小売収益** | 金融・不動産・リテールメディアを持つかどうかで、同じ小売売上でも利益がまるで違う |

参入障壁は高いが、**中にいる企業が儲かるとは限らない**のがこの業界の特徴。障壁は「新規参入を防ぐ」だけで、「既存企業が業態転換しなくてよい」ことを意味しない。

## 7. 規制・法制度

| 制度 | 年 | 内容 |
| --- | --- | --- |
| 百貨店法 | 1956年 | 百貨店の出店・増床を許可制に。スーパーは規制の外で急成長した |
| 大規模小売店舗法（大店法） | 1973年制定・74年施行 | 大型店の売場面積・営業時間・休業日数を地元と調整。事実上の出店規制として機能 |
| 大店法の運用緩和 | 1990年代 | 日米構造協議などを受けて緩和。大型店の郊外出店が一気に進む |
| **大規模小売店舗立地法（大店立地法）** | 2000年施行（大店法は廃止） | 規制目的を「中小小売業の保護」から「周辺環境（騒音・交通・廃棄物）の保全」へ転換 |
| **まちづくり三法の改正** | 2006年（2007年施行） | 都市計画法改正で床面積1万㎡超の大規模集客施設の郊外立地を原則制限 |
| 食品表示法、食品衛生法（HACCP） | 順次 | 店内加工・惣菜の衛生管理義務。プロセスセンター化の一因 |
| 最低賃金法 | 毎年改定 | 全国加重平均で1,121円へ、前年から＋66円・6.3%という過去最大級の引き上げ（報道ベース。詳細は厚労省の公表で確認） |
| 省力化投資促進プラン（小売業） | 2025年6月 | 農水省・経産省による省人化投資の後押し |

> ポイント：**規制がGMSの形を決めてきた**。大店法が守り、大店立地法が郊外へ押し出し、2006年改正が新規供給を止めた。
> いまGMS各社が持つ郊外の大箱の多くは、2000〜2006年という短い窓の間に建てられたもの。

## 8. 最近のトピック

詳細は [④ 直近トピック（2026年9月時点）](04_直近トピック_2026.md)。要点は5つ。

1. **イオンが国内小売首位に**（2026年2月期、営業収益10兆7,153億円）。ただしセブン＆アイが非中核事業を切り離した影響も大きい

4. **イオンの新中期計画（2026〜2030年度）**でPB2兆円、首都圏シェア拡大、省人化・高生産性の店舗オペレーション確立を明示
5. **値上げで売上は過去最高、数量は減少**。生活防衛意識がPBとディスカウントへの移動を加速させている

## 9. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **GMS** | General Merchandise Store。衣食住を1店舗でセルフサービス販売する総合スーパー |
| **坪効率** | 売場1坪（約3.3㎡）あたりの年間売上高。面積が固定費を決めるため小売の生産性指標として最重要 → [②](02_小売の経済学.md) |
| **在庫回転率** | 年間売上原価 ÷ 平均在庫。棚が1年に何回入れ替わるか |
| **値入（ねいれ）** | 仕入原価に対して最初に設定した利幅。値引き前の「予定の粗利」 |
| **ロス率** | 値入率と実際の粗利率の差。値下げロス・廃棄ロス・不明ロスの合計 |
| **EDLP** | Every Day Low Price。特売をやめて常時低価格にする方式。需要と作業が平準化する |
| **High-Low** | チラシ特売で目玉商品を安く出し、ついで買いで粗利を取る日本の伝統的手法 |
| **PB／NB** | PBは小売が企画しメーカーに製造委託する自社ブランド。NBはメーカーのブランド商品 |
| **既存店前年比** | 新規開店・閉店を除いた同一店舗の売上前年比。小売の実力を測る最重要指標 |
| **カテゴリーキラー** | 特定カテゴリに絞って品揃えと価格で圧倒し、総合店からその売場を奪う専門店業態 |
| **核テナント** | モールの集客を担う大型店舗。GMSはこの役割を担うことが多い |
| **大店立地法** | 大規模小売店舗立地法（2000年施行）。周辺環境の保全を目的とする大型店の立地規制 |
| **プロセスセンター（PC）** | 精肉・鮮魚などの加工を店舗から集約した加工センター。省人化と技能継承問題への対応 |
| **リテールメディア** | 小売が自社の店舗・アプリ・ECの広告枠をメーカーに販売する事業。粗利率がほぼ100% |
| **CFC** | Customer Fulfilment Centre。ネットスーパー専用の自動化倉庫 |

各ノート末尾にも用語メモがあるので、詳しくはそちらを参照。
