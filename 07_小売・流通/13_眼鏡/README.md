# 眼鏡

- 大分類: 小売・流通
- 状態: done
- 更新日: 2026-09-20

眼鏡は、視力を補正する器具を作って売る産業。ただし小売業として見ると、極めて変わった数字をしている。
**粗利率70〜78%という、日本の小売でほとんど例のない高さ**を持ちながら、営業利益率は10%台に落ち着く。

> ポイント：眼鏡店が売っているのは物ではなく、**測って・削って・合わせる作業込みのパッケージ**である。
> 値札の大部分は店頭で提供される技術サービスの対価であり、それは原価ではなく人件費として計上される。
> だから粗利は高く、利益は普通になる。この一点を押さえると、この業界の打ち手がほぼ説明できる。

## 1. 業界の定義・範囲

「眼鏡業界」と言うとき、実際には性質の違う3つの層が混ざっている。

| 層                     | 担うこと                                         | 主なプレイヤー                                     |
| ---------------------- | ------------------------------------------------ | -------------------------------------------------- |
| レンズメーカー         | 素材設計、光学設計、コーティング。技術集約で寡占 | EssilorLuxottica、HOYA、Zeiss、ニコン・エシロール  |
| フレームメーカー・産地 | 金属/樹脂の成形・加工。分散的で多数              | 福井（鯖江）の各社、中国・ベトナムの量産工場       |
| 小売（眼鏡店）         | 視力測定、レンズ加工、フィッティング、アフター   | JINS、Zoff、眼鏡市場、パリミキ、愛眼、OWNDAYS ほか |

隣接するが別物なのが次の領域である。

- **コンタクトレンズ**：薬機法上の高度管理医療機器。販売に都道府県の許可と管理者が必要
  → [医療機器](../../09_医薬・医療・ヘルスケア/05_医療機器/README.md)
- **眼科クリニック**：診断・治療・処方は医療行為
  → [医療機関・医療サービス](../../09_医薬・医療・ヘルスケア/08_医療機関・医療サービス/README.md)
- **サングラス・アイウエア**：度なしの服飾品としての需要
  → [靴・バッグ・宝飾](../12_靴・バッグ・宝飾/README.md)、[スポーツ用品](../11_スポーツ用品/README.md)

本フォルダは**眼鏡小売とその川上**を主に扱い、視力矯正の医学的な内容には立ち入らない。

| ------------------------------ | --------------------------------------: | ---------------------------------- |

国内市場はおおむね**横ばい圏**にある。人口減で数量成長は望みにくく、
**低価格SPAが数量を、機能性レンズが単価を支える二極化**で金額が保たれている構図である。
統計により「眼鏡のみ」「コンタクトを含む」「アイウエア全体」と定義が違うので、同じ系列で推移を見ること。

## 3. バリューチェーン

```
【レンズ】樹脂モノマー ─▶ 注型重合 ─▶ セミフィニッシュト（半製品）
                                          │
                                          ├─▶ 度数に合わせ裏面研磨 ─┐
【フレーム】金属/樹脂 ─▶ 成形・めっき ─▶ 完成フレーム ───────────┤
   鯖江（国産の大半）／中国・ベトナム（量産）                        │
                                                                    ▼
  顧客 ◀─ 引き渡し・フィッティング ◀─ 玉型加工 ◀─ 心取り ◀─ 視力測定 ◀─ 来店
                     ▲
                  店内ラボなら最短当日。ここが小売の付加価値の中心
```

付加価値は「良いフレームを仕入れること」ではなく、
**度数を正しく測り、正しく削り、顔に合わせ、数年間調整し続ける**工程に集まる。
レンズは在庫を半製品で持ち、注文後に加工するため、アパレルのような値下げロスが起きにくい。

## 4. 主要プレイヤーとシェア

| 企業・ブランド                   | 立ち位置                             | 特徴                                                       |
| -------------------------------- | ------------------------------------ | ---------------------------------------------------------- |
| メガネトップ（眼鏡市場）         | 非上場。店舗数・売上で長く国内最大手 | 傘下ブランド含む売上1,000億円規模。2025年にEC統合          |

## 5. 収益モデル・コスト構造

```
売上 100
 ├─ 売上原価 約22 …… フレーム＋レンズの調達・加工原価
 └─ 売上総利益 約78
      ├─ 人件費・家賃          約40〜45
      ├─ 広告宣伝・販促        約8〜12
      ├─ 減価償却（加工機等）  約5
      ├─ その他                約5〜8
      └─ 営業利益              約10〜13
```

- **高粗利の理由**：値札に測定・加工・フィッティング・アフターが内包されている（原価には入らない）
- **利益が普通になる理由**：販管費率が60%台。検眼室と加工室を持つため面積・人・設備が重い
- **在庫リスクが小さい理由**：レンズは半製品在庫＋受注加工。フレームも季節性が弱い
- **最大の弱点**：購入頻度が数年に1回。集客コストが単価に対して重くのしかかる

詳細は [① 眼鏡小売の経済学](01_眼鏡小売の経済学.md)。

## 6. 競争要因（KSF）と参入障壁

| 成功要因                             | なぜ効くか                                                       |
| ------------------------------------ | ---------------------------------------------------------------- |
| 測定・加工の品質を店舗網全体で揃える | 1店舗の失敗が返品・作り直しと評判の毀損に直結する                |
| 価格と納期を入店前に確定させる       | 均一価格型が旧来型から客を奪った最大の要因                       |
| 店内ラボを持つ                       | 当日渡しは強い来店理由になり、外注加工費も抑えられる             |
| 単価の高いレンズを提案できる         | 数量が伸びない市場で金額を伸ばす唯一の道                         |
| 度なし需要の入口を作る               | サングラス、ブルーライトカット、スマートグラスで来店頻度を上げる |
| 立地（SC・駅ビル）                   | ファッション文脈の売場に置けるかで客層が変わる                   |

参入障壁は許認可ではなく、**技能の再現性と店舗網**にある。
眼鏡作製技能士は名称独占であって業務独占ではないため、法的に守られた市場ではない。
それでもEC専業が既存チェーンを崩せないのは、測定と加工が物理的に店舗を必要とするからである。

## 7. 規制・法制度

| 対象             | 制度                                                       | 要点                                                                   |
| ---------------- | ---------------------------------------------------------- | ---------------------------------------------------------------------- |
| 眼鏡             | 特段の業法なし                                             | 一般の消費財として販売できる                                           |
| 眼鏡作製技能士   | 職業能力開発促進法に基づく国家検定（2022年創設、1級・2級） | 名称独占。旧「認定眼鏡士」（2001年〜）を引き継ぐ形                     |
| 視力測定         | 医師法                                                     | 診断・治療は医師の領域。眼鏡店の測定は度数合わせにとどまる             |
| コンタクトレンズ | 薬機法（高度管理医療機器）                                 | 製造販売は厚労大臣承認、販売は都道府県の許可＋営業所管理者が必要       |
| カラーコンタクト | 同上                                                       | 度なしでも高度管理医療機器。厚労省が適正使用を周知                     |
| 広告             | 景品表示法、薬機法                                         | コンタクトで「処方箋不要」等、受診不要と誤認させる表示は不適切とされる |
| 近視管理用レンズ | 学会ガイドライン（日本近視学会、2025年第1版）              | 眼科での処方・管理を前提とする商材                                     |

## 9. 用語メモ

| 用語                         | 意味                                                                                            |
| ---------------------------- | ----------------------------------------------------------------------------------------------- |
| **セミフィニッシュトレンズ** | 片面だけ仕上げたレンズの半製品。注文後に裏面を削って度数を作る → [①](01_眼鏡小売の経済学.md)    |
| **玉型加工**                 | レンズをフレームの形に削る作業。店内ラボがあれば当日渡しが可能                                  |
| **フィッティング**           | 顔・耳・鼻に合わせてフレームを調整すること。引き渡し後も無償が通例                              |
| **眼鏡作製技能士**           | 2022年創設の国家検定資格（1級・2級）。名称独占で業務独占ではない                                |
| **累進屈折力レンズ**         | 1枚で遠方から手元まで度数が連続的に変わるレンズ。遠近両用が代表 → [②](02_視力矯正市場と競争.md) |
| **高度管理医療機器**         | 薬機法の分類。コンタクトレンズが該当し、販売に許可と管理者が必要                                |
| **均一価格型（SPA）**        | 企画から小売まで一体運営し、レンズ込みで価格帯を固定する売り方                                  |
| **アイウエア**               | 眼鏡・サングラス・度なし眼鏡の総称。市場統計はこの単位が多い                                    |
| **既存店売上高**             | 1年以上前から営業する店だけの売上。眼鏡チェーンは月次で開示する社が多い                         |
