# 視力矯正市場と競争

このノートで分かること：眼鏡店の競争相手は他の眼鏡店だけではない。
眼鏡・コンタクトレンズ・屈折矯正手術は同じ「見えるようにする」需要を奪い合い、
それぞれ**規制も購入頻度も売り場も違う**。その違いがそのまま各社の業績を分けている。

> ポイント：眼鏡は雑貨として売れるが、コンタクトは医療機器としてしか売れない。
> この一線が、店舗の作り方、必要な許可、顧客との接点頻度、そして収益の出方を根本から変えている。

※ 本ノートは産業構造と制度の説明であり、どの矯正手段が適するかという医学的な判断は扱わない。
　視力や目の状態に関する判断は医療機関の領域である。

## 1. 「視力矯正市場」という見方

眼鏡業界だけを見ていると、市場の縮小・拡大の理由が読めない。
同じ需要に対し、少なくとも3つの供給方法が並んでいる。

| 手段                         | 法的な位置づけ                                               | 買い方                 | 支出の型                     | 主な売り場               |
| ---------------------------- | ------------------------------------------------------------ | ---------------------- | ---------------------------- | ------------------------ |
| 眼鏡                         | 一般の物品（視力補正用眼鏡は非課税対象外、通常の消費財扱い） | 数年に1回まとめ買い    | **一時金型**（1万〜3万円台） | 眼鏡専門店、SC、EC       |
| コンタクトレンズ             | **高度管理医療機器**（薬機法）                               | 1〜3カ月ごとに継続購入 | **サブスク型**（年数万円）   | 眼科併設店、専門店、通販 |
| 屈折矯正手術（LASIK、ICL等） | 医療行為（自由診療）                                         | 一度きり               | **高額一括型**               | 眼科クリニック           |

眼鏡小売から見ると、コンタクトは「**顧客の来店頻度を奪う競合**」であり、
同時に「**併売すれば継続収益になる商材**」でもある。
メガネスーパーのようにコンタクト・補聴器まで扱う業態が生まれるのは、この両義性のためである。

```
       視力矯正の需要（人口 × 矯正が必要な割合）
                      │
   ┌──────────┬────────┴────────┬──────────┐
 眼鏡            コンタクト          手術          何もしない
 数年に1本        毎月〜数カ月         一度         （未矯正）
 小売            医療機器販売        自由診療
   │                 │                │
   └─ 併売 ──────────┘                │
        （眼科併設・専門店）            └─ 一度抜けると
                                          長期間戻ってこない
```

## 2. コンタクトレンズは別の規制の世界にある

眼鏡とコンタクトは、店頭では隣に並んでいても制度上はまったく別物である。

| 論点       | 眼鏡                             | コンタクトレンズ                                           |
| ---------- | -------------------------------- | ---------------------------------------------------------- |
| 分類       | 一般消費財                       | 高度管理医療機器（薬機法）                                 |
| 製造・輸入 | 一般の規制                       | 厚生労働大臣の承認が必要                                   |
| 販売       | 許可不要                         | **都道府県知事の販売業許可が営業所ごとに必要**             |
| 人         | 眼鏡作製技能士は名称独占（任意） | **営業所管理者の設置が義務**（所定の講習受講等）           |
| 購入時     | 自由                             | 医師の診断・処方を受けることが前提とされる                 |
| 広告       | 景表法など一般規制               | 「処方箋不要」等、受診不要と誤認させる表示は不適切とされる |
| カラコン   | —                                | 度なしのおしゃれ用も**高度管理医療機器**に該当             |

度なしのカラーコンタクトまで医療機器に含められた経緯は、健康被害が問題化したためで、
厚生労働省も適正使用の周知を続けている。
結果として、**コンタクトを扱う瞬間に、店は医療機器の流通事業者になる**。
許可、管理者、記録、回収対応といった実務が発生し、出店の自由度が落ちる。

```
【眼科併設型コンタクト販売の典型的な構図】

  ビルの同一フロア
  ┌──────────────┐   ┌──────────────┐
  │ 眼科クリニック      │   │ コンタクト販売店     │
  │ 診察・処方          │──▶│ 高度管理医療機器      │
  │ 診療報酬（保険/自費）│   │ 販売業許可＋管理者    │
  └──────────────┘   └──────────────┘
        ↑                          │
        └───── 定期的な再購入 ──────┘
  ※ 医療機関と販売業者は別法人であることが前提。
     広告や誘導のあり方には制度上の注意点が多い。
```

この「診察 → 購入 → 数カ月後に再購入」という循環が、
眼鏡の「数年に1回」より圧倒的に強い顧客接点を生む。
眼鏡チェーンがコンタクトを併売したがる理由はここにあり、
逆に扱わない（JINSは眼鏡に特化）判断も、規制コストと専門性の集中という合理性を持つ。

## 3. 人口動態：老眼は増え、若年は減る

日本の視力矯正市場は、**需要の中身が入れ替わる**局面にある。

```
需要の構成（イメージ）

  1990年代            2020年代            2030年代
  ┌────────┐      ┌────────┐      ┌────────┐
  │ 若年・近視 │      │ 若年・近視 │      │ 若年・近視 │  ← 人口減で縮む
  │  （大）    │      │  （中）    │      │  （小）    │
  ├────────┤      ├────────┤      ├────────┤
  │ 中高年・老視│      │ 中高年・老視│      │ 中高年・老視│  ← 高齢化で増える
  │  （中）    │      │  （大）    │      │  （大）    │
  └────────┘      └────────┘      └────────┘
     総数は横ばい〜微減、しかし1本あたり単価は上がりやすい
```

- **老視（いわゆる老眼）**：加齢に伴い近くが見えにくくなる現象で、中高年では一般的。
  遠近両用などの累進レンズは単価が高く、**数量が減っても金額が保たれる**要因になる。
- **若年人口の減少**：新規に眼鏡を作る母数が減る。学生向けの量販需要は構造的に縮小する。
- 近視の子どもが増えているという指摘は国内外で共通しており、
  近視進行抑制を目的とした眼鏡レンズが新しい商材カテゴリとして立ち上がりつつある。
  HOYAの MiYOSMART とNikon-Essilorの Stellest が日本近視学会のガイドライン（2025年初版）で
  取り上げられ、MiYOSMARTは2026年6月に日本で提供開始と報じられている。
  **ただしこれは眼科での処方を前提とする商材であり、量販の文脈とは売り方が異なる。**

矢野経済研究所の推計では、国内アイウエア市場（小売金額ベース）は
2021年4,768億円、2022年4,918億円で、2022年は2019年比97.6%まで回復したとされる。
市場全体は横ばい圏であり、成長は**単価**と**新カテゴリ**から取りにいく構図になる。

## 4. 単価を上げる道具：機能性レンズ

数量が伸びない市場で金額を伸ばす方法は、レンズの付加価値化である。

| カテゴリ                       | 何をするものか                        | 価格への効き方                     |
| ------------------------------ | ------------------------------------- | ---------------------------------- |
| 累進屈折力レンズ（遠近・中近） | 1枚で遠方と手元の度数を連続的に変える | 単価を大きく押し上げる主力         |
| 高屈折率レンズ                 | 同じ度数でも薄く軽く仕上げる          | 強度数の顧客の追加支出             |
| 非球面・両面非球面設計         | 周辺の歪みを抑える設計                | 設計グレードで段階課金             |
| 調光レンズ                     | 紫外線量で濃度が変わる                | 1本で屋内外を兼ねる需要            |
| 偏光レンズ                     | 水面や路面の反射光を抑える            | 釣り・ドライブ・スポーツ           |
| ブルーライトカット             | 可視光の短波長域の透過を抑える        | 低価格帯でも付けやすい「入口」商材 |
| 近視進行抑制レンズ             | 特殊な光学設計を持つ小児向けレンズ    | 眼科処方が前提。高単価カテゴリ     |

ブルーライトカットは、2010年代にJINSが「JINS PC」として広め、
**度なしでも眼鏡を買う理由**を作った点で業界史的に大きい。
視力矯正を必要としない層が眼鏡売り場に入ってくる導線を作ったからである。
一方、その効果をめぐっては学術的な議論があり、本ノートでは効能の評価は扱わない。
産業的に重要なのは、**「度なし需要」というチャネルを開いたこと**そのものである。

## 5. ファッション化とアイウエア市場

眼鏡が服飾品として扱われるようになると、競争のルールが小売の外側にも広がる。

| 方向               | 内容                                               | 経済的な意味                                   |
| ------------------ | -------------------------------------------------- | ---------------------------------------------- |
| 複数本保有         | 用途・服装ごとに買い替える                         | 購入頻度の低さを部分的に克服                   |
| サングラス         | 屈折矯正と無関係に売れる。アウトドア・スポーツ需要 | 季節商材、度なし市場                           |
| ブランドライセンス | ラグジュアリーブランドの眼鏡をメーカーが製造       | EssilorLuxotticaの収益源の一つ                 |
| 有名人起用         | 広告塔による認知と来店動機                         | インターメスティックの「メガネが主役」戦略が例 |
| スマートグラス     | Ray-Ban Meta / Oakley Meta など                    | 度付き対応が必要 → **眼鏡店が販売接点になる**  |

スマートグラスは、**デジタル機器でありながら「度数を合わせる」必要がある**という点で、
眼鏡店に有利な要素を持つ。日本では2026年5月に発売され、
メガネスーパー（限定5店舗）や愛眼（限定21店舗）といった既存チェーンが取扱いを始めたと発表している。
家電量販店と眼鏡店のどちらが主戦場になるかは未確定で、
「測定と加工ができる売り場」という眼鏡店の資産が、久しぶりに新しい用途を得た形になる。

## 6. ECはどこまで行けるか

眼鏡は、EC化が進みにくい代表的な商材とされてきた。理由は単純で、**測って削る工程が要る**からである。

```
【EC化を止める3つの壁】

 1. 度数が分からない          → 処方箋・過去の購入履歴・店頭測定が必要
 2. 顔に合うか分からない      → 鼻幅、耳位置、傾き。写真では決まらない
 3. 仕上げの調整ができない    → 引き渡し時のフィッティングが品質の一部

【各社の越え方】
  JINS      … VIRTUAL FIT（カメラで3D試着）／店舗で測定→ECで再注文
  Zoff      … 店舗とECの会員基盤統合
  眼鏡市場  … 2025年にECとブランドサイトを統合。店舗の度数情報を引き継いで再注文
  メガネスーパー … 店舗を軸にしたオムニチャネル

  → 共通する解は「ECが店を代替する」ではなく
     「**店で1本目、ECで2本目**」という役割分担。
```

JINS・Zoffの売上に占めるEC比率は近年7%前後で推移するとされる（報道・分析ベース）。
アパレルのEC比率（2割前後の企業もある）と比べれば低く、
**店舗網そのものが依然として最大の資産**であることを示している。
裏を返せば、EC専業の新規参入が既存チェーンを壊しにくい業界でもある。

## 7. 既存チェーンの苦戦と再編

均一価格型の台頭で最も打撃を受けたのは、フレームとレンズを個別価格で売ってきた従来型チェーンだった。

| 企業                             | 位置づけ                                    | 近年の動き                                                                |
| -------------------------------- | ------------------------------------------- | ------------------------------------------------------------------------- |
| メガネトップ（眼鏡市場）         | 店舗数・売上で長く国内最大手。非上場        | 傘下ブランド含む売上が1,000億円規模に。EC統合を実施                       |
| ジンズHD（JINS）                 | 均一価格型SPA。海外展開                     | 2025年8月期に売上972億円・営業利益120億円と過去最高（報道）               |
| インターメスティック（Zoff）     | 均一価格型SPA。2024年10月に東証プライム上場 | 2025年12月期売上501.5億円。ビジョナリーHDを買収                           |
| ビジョナリーHD（メガネスーパー） | 総合型（眼鏡・コンタクト・補聴器）          | 経営難→ファンド傘下→2024年上場廃止→2025年10月にインターメスティック傘下へ |
| 三城HD（パリミキ）               | 老舗の接客重視型                            | 顧客推奨度（NPS）重視の改革を進めたと報じられる                           |
| 愛眼                             | 中堅チェーン                                | 月次の既存店売上を開示。スマートグラス取扱いなど新商材に対応              |
| OWNDAYS                          | 均一価格型。海外店舗比率が高い              | アジア中心に多店舗展開                                                    |

> 構図として整理すると、**「価格の不透明さ」を付加価値にしていた業態が最初に崩れ、
> 「測定・加工・アフターの品質」あるいは「価格と納期の明快さ」に軸足を移せた企業が残った**。
> メガネスーパーの再建と身売りは、その過程を最も分かりやすく示した事例といえる。

再編の到達点が、2025年10月のインターメスティックによるビジョナリーHD完全子会社化である。
Zoff約332店舗（2025年12月末）とメガネスーパー約300店舗（2025年4月末）が合わさり、
国内600店舗超・売上780億円規模になる見通しと報じられた。
**均一価格型がコンタクト・補聴器を含む総合型を取り込んだ**という点で、業界の主従が入れ替わった動きとして読める。

## 8. 競争の見取り図

```
                  高単価・専門性
                        ▲
        眼科併設コンタクト │  近視管理レンズ
        補聴器            │  遠近両用・高機能レンズ
                          │  オーダーメイド・鯖江ブランド
  規制が重い ◀────────────┼────────────▶ 規制が軽い
                          │
        ネット通販コンタクト│  均一価格眼鏡SPA
        （価格勝負）       │  度なし・サングラス・スマートグラス
                        ▼
                  低単価・量販
```

眼鏡小売の戦略は、この平面のどこに立つかで決まる。
JINS・Zoffは右下から入って上方向（機能性レンズ）へ登り、
メガネスーパー型は左上に立ったが固定費を支えきれなかった、という整理ができる。

## 9. 用語メモ

| 用語                         | 意味                                                                                             |
| ---------------------------- | ------------------------------------------------------------------------------------------------ |
| **高度管理医療機器**         | 薬機法の分類の一つ。不具合時のリスクが比較的高い機器。コンタクトレンズが該当し、販売に許可が必要 |
| **販売業許可／営業所管理者** | 高度管理医療機器を売る営業所ごとに必要な都道府県の許可と、置かねばならない責任者                 |
| **老視（老眼）**             | 加齢に伴い手元が見えにくくなる現象。累進レンズなどで対応する                                     |
| **累進屈折力レンズ**         | 1枚で遠方から手元まで度数が連続的に変わるレンズ。遠近両用が代表                                  |
| **屈折率（レンズの薄さ）**   | 高いほど同じ度数を薄く作れる。1.60、1.67、1.74などのグレードがある                               |
| **調光／偏光**               | 調光は紫外線量で濃度が変わる。偏光は反射光を抑える。別の技術                                     |
| **近視進行抑制レンズ**       | 特殊な光学設計を持つ小児向けレンズ。眼科での処方を前提とする                                     |
| **オムニチャネル**           | 店舗とECの在庫・顧客情報を一体運用する売り方                                                     |
| **NPS**                      | 顧客推奨度。「人に薦めたいか」を指標化したもの                                                   |
| **アイウエア**               | 眼鏡・サングラス・度なし眼鏡などを総称する呼び方。市場統計ではこの単位で集計されることが多い     |
