# ② 各社の違いと脱100円

このノートで分かること：ダイソー・セリア・キャンドゥ・ワッツが、
**同じ「100円均一」という看板を掲げながら、まったく違う商売をしている**こと。
そして「300円・500円商品の拡大（脱100円）」が、値上げとは別の何を意味しているのか。

> 結論：4社の違いは **「原価が上がったときに何を捨てるか」の違い**である。
> ダイソーは**価格帯を捨てて規模を取った**（300円・500円ブランドを別看板で増やす）。
> セリアは**品目を捨てて100円を守った**（作れなくなった商品はやめる）。
> キャンドゥは**単独での成長を捨ててイオングループに入った**。
> ワッツは**直営一本を捨てて卸・委託という他人の店で稼ぐ道**を作った。
> 「脱100円」は値上げではなく、**売価という軸を1本から複数本に増やす業態転換**である。

## 2. ダイソー — 規模でしか解けない問題を、規模で解いている

大創産業の戦略は一貫して **「店舗数を増やす → 発注ロットが増える → 原価が下がる →
100円で作れる商品が増える」** という循環を回すことにある。

2025年度（2025年3月〜2026年2月）の実績は、連結売上高7,710億円、世界5,891店。
ブランド別の内訳（2026年2月末時点）は次の通り。

| ブランド | 国内店舗数 | 海外店舗数 | 中心価格帯 | 位置づけ |
| --- | --- | --- | --- | --- |
| **DAISO** | 3,955 | 1,051 | 110円中心（〜1,100円） | 本体。品揃えの幅で勝負 |
| **Standard Products** | 228 | 21 | **300円中心**（〜数千円） | 素材感・デザイン重視。無印良品に近い客層 |
| **THREEPPY** | 601 | 35 | **300円中心** | 女性向け・かわいい系の雑貨 |

（出典：大創産業リリース、流通ニュース／流通スーパーニュース）

ここで重要なのは、**ダイソーが「DAISOの店内で値上げする」のではなく、
別の看板の店をつくった**ことである。

> ポイント：「ダイソーが300円に値上げした」ではなく、
> **「300円の商品を売る別ブランドを増やした」**。
> 100円ショップにとって売価は商号そのものなので、
> **看板を分けることでしか価格帯は増やせない**。
> THREEPPY 601店・Standard Products 228店という数字は、
> 「脱100円」が実験ではなく**すでに主力級の事業になっている**ことを示す。

同時にダイソーは、店頭商品の約8割が依然110円だと説明している（2026年時点の報道ベース）。
つまり**本体は100円のまま残し、その周りに300円の器を足している**という構造になる。

## 3. セリア — 全品100円を、POSデータの力で守っている

セリアは大手で唯一「全品100円」を続けている。これは根性論ではなく、
**売れない商品を早く見つけて切る仕組み**を持っているから成立している。

- **2004年**、100円ショップとして初めて POS（販売時点情報管理＝何がいつ何個売れたかを記録する仕組み）を導入
- **2006年**、POSデータに自社のアルゴリズムを組み合わせた**発注支援システム**を稼働
- 単品ごとの売れ方を見て、売れない品番を落とし、売れる品番の棚を広げる

```
【セリアの「100円を守る」ループ】

   POSで単品ごとの売れ方を把握
            │
            ▼
   売れない品番を落とす ──▶ 棚が空く
            │                  │
            ▼                  ▼
   売れる品番に棚を寄せる   新商品を大量投入（毎月数百品目規模）
            │
            ▼
   1品番あたりの販売数が増える ──▶ 発注ロットが増える
            │
            ▼
   原価が下がる ──▶ 100円で作れる商品が維持できる
            ▲                          │
            └──────────────────────────┘
```

**値上げの代わりに「売れない商品を切る」ことで原価を吸収している**、という言い方ができる。
これはコンビニの単品管理（[③ 商品と物流](../01_コンビニエンスストア/03_商品と物流.md)）と発想は同じだが、
コンビニと違って**売価を動かす逃げ道がない**ぶん、切る判断がより厳しくなる。

もう一つの柱が**デザイン**である。セリアはメーカーとの共同開発で
品質・機能・デザインを確認する体制を持ち、
「100円なのに部屋に置ける見た目」を武器に、20〜40代女性の支持を集めてきたとされる。
価格で差がつかない業界では、**差別化の軸がデザインと品揃えしか残らない**からである。

その結果が 2026年3月期の **営業利益率8.2%（前期7.1%）**。小売業としては高い水準で、
既存店売上高 104.1% が利益を押し上げた。
ただし裏を返せば、**原価が上がり続ける局面で「100円のみ」を守り切れるかが最大のリスク**でもある。

## 4. キャンドゥ — 単独成長をあきらめ、イオンの中に居場所を作った

キャンドゥは 2021年10月にイオンによる買収が発表され、**2022年1月に子会社化が完了**した。
買収前の計画では 2026年11月期に売上1,250億円・2,000店を掲げていたが、
2026年2月期時点の店舗数は **1,372店（直営930／FC435／海外7）**で、その水準には届いていない。

イオン傘下に入ったことの意味は、**調達より先に「出店場所」である**。

| 項目 | 単独時代 | イオングループ入り後 |
| --- | --- | --- |
| 出店場所 | 自力で商業施設と交渉 | **イオンモール・イオン系スーパーの区画に入れる** |
| 調達 | 自社で交渉 | グループの調達網を一部活用 |
| 競合関係 | ダイソー・セリアと真正面 | グループ内でも100円雑貨の担い手として機能 |
| 課題 | 規模でロットが作れない | 規模はまだ小さく、**グループ依存の度合い**が論点 |

100円ショップの出店は「SCの空き区画をどれだけ確保できるか」の競争でもある
（→ [① 100円で売って儲かる仕組み](01_100円で売って儲かる仕組み.md) 第8章）。
イオンは全国に[スーパー・GMS](../02_スーパー・GMS/README.md)と商業施設を持っているので、
**キャンドゥにとって最大の価値は親会社の不動産**だった、と読むのが素直である。

同社は100円にこだわらない付加価値型の新業態も育てており、
価格帯の拡大という点ではダイソー寄りの方向に動いている。

## 5. ワッツ — 直営だけで戦わない「他人の店で売る」モデル

ワッツ（「ワッツ」「meets.」「シルク」などを展開）は後発かつ最小手だが、
**直営店以外のチャネルを持っている**点で他の3社と違う。

```
【ワッツの展開ルート】

   本部（商品調達・企画）
     ├──▶ 直営店（SC・駅ビル・路面）
     ├──▶ 委託店（消化仕入：売れた分だけ仕入計上。場所を借りて置く）
     ├──▶ 卸売（グループの卸会社 → 他社が運営する店・売場へ供給）
     └──▶ スーパー内併設（スーパーの店内に100円ショップ区画を作る）
                 ▲
                 └ スーパー側は空き面積が埋まり、来店動機が増える
                   ワッツ側は出店コストと自前の集客負担が小さい
```

この構造の利点は、**自社で家賃と人を抱えずに商品を流せる**ことにある。
小さな商圏や、直営では採算が合わない立地でも、卸や委託なら100円ショップが置ける。
ワッツが業界4位の売上規模で店舗数では上位に食い込む（2026年8月時点で100円ショップ1,932店）のは、
この「他人の店を使う」構造による。

2026年8月期の実績では、**100円ショップ直営既存店 +4.4%、全店 +5.1%、全社売上 +4.8%**
（会社発表ベース）と、物価高局面でも既存店がプラスを保っている。

## 6. 「脱100円」とは何か — 値上げではなく「メニューの追加」

2020年代に各社が進めた 150円・300円・500円商品の拡大は、しばしば「値上げ」と呼ばれるが、
**やっていることは値上げとは別物**である。

| | 値上げ | 脱100円（価格帯の追加） |
| --- | --- | --- |
| 対象 | 同じ商品の売価を上げる | **新しい商品を別の価格で追加する** |
| 客の受け取り方 | 「高くなった」 | 「品揃えが増えた」 |
| 100円商品 | 消える | **残る**（ダイソーは店頭の約8割が110円） |
| 狙い | 原価上昇の転嫁 | **100円では作れない品質・機能の商品を扱えるようにする** |
| リスク | ブランドの否定 | 「100円ショップ」という定義が薄れる／プチプラ雑貨店との競合 |

帝国データバンクの2025年度調査でも、市場成長を支えているのは
**150〜500円の中価格帯の充実**とされている。
市場規模は 2016年度の7,369億円から 2025年度 約1兆1,100億円へ約1.5倍。
**100円のままでは増えなかった売上を、価格帯の追加で作った**というのが実態に近い。

```
【価格帯の地図（2026年時点）】

  100円 ─────── 300円 ─────── 500円 ─────── 1,000円 ───▶
   │             │             │              │
  DAISO本体    THREEPPY      Standard      無印良品
  セリア(全品)  3COINS等      Products      ニトリ等
  キャンドゥ    キャンドゥの                  ホームセンターPB
  ワッツ        200〜500円

   ← ここは「均一価格の世界」 →  ← ここは普通の小売の世界 →
                                （値札があり、セールもある）
```

> ポイント：右に行くほど、**100円ショップが持っていた「値付けをしない」という強みが消える**。
> 300円・500円の商品が増えるほど、客は他の雑貨店と品質と価格を比べ始める。
> つまり脱100円は、**自分たちを普通の小売の土俵に引きずり出す行為**でもある。
> この綱引きが、今の業界の中心論点になっている。

## 7. 海外出店 — 「日本の100円均一」ではなく「現地価格の均一ショップ」

ダイソーは海外で **25の国・地域に約1,107店**（2026年2月末時点）を展開し、
**2030年までに米国1,000店、海外合計3,000店、グループ売上に占める海外比率約30%** を掲げている。
米国は2005年のシアトル出店が最初で、2026年時点では約180店と報じられる。

海外展開が成立する理由は、100円均一の本質が価格水準ではなく
**「均一価格という仕組み」**だからである。

| 論点 | 国内 | 海外 |
| --- | --- | --- |
| 売価 | 110円（税込） | **現地通貨での均一価格**（例：米国は1.75ドル等、現地の物価に合わせる） |
| 強み | 品揃えと原価力 | 同じ。**むしろ日本より粗利が取りやすい**ことがある |
| 難しさ | 出店余地の減少 | 物流距離、関税、現地の嗜好、人件費 |
| 調達 | アジアの工場 | 同じ工場から現地へ直送できれば効率が上がる |

日本で 110円で売っている商品を、物価の高い国でそれ以上の均一価格で売れば、
**同じ原価でより大きな粗利が取れる**。
国内の出店余地が細っていくなかで、海外が成長の主戦場になるのはこの計算による。

## 8. 卸・併設 — コンビニやスーパーの中に100円売場が入る

100円ショップは、自分の店を持たずに「売場」として他業態に入り込むこともできる。

- **スーパー内併設**：ワッツがスーパーの店内に100円ショップ区画を出す形を進めている
- **卸売**：グループの卸会社が、他社が運営する店の100円売場に商品を供給する
- **コンビニ系の均一業態**：ローソンストア100は、生鮮・食品中心の均一業態として別系統で存在する

受け入れる側（スーパー・商業施設）から見ると、100円売場は
**空いた面積を埋めつつ、来店頻度を上げてくれる装置**になる。
[スーパー・GMS](../02_スーパー・GMS/README.md) や
[食品スーパー](../03_食品スーパー/README.md) が売場の一部を外部に開くのは、
自前で雑貨を仕入れても100円ショップの原価にはかなわないからである。

## 9. EC — 単価が低すぎて送料に勝てない

100円ショップは、**EC化がほとんど進んでいない小売**である。理由は単純で、
**1点110円の商品に数百円の送料がかかったら成立しない**からである。

```
【なぜ100円ショップのECは難しいか】

  1点110円の商品を1点送る
     商品     110円
     送料   + 770円      ← 送料が商品代の7倍
     ─────────────
     客の負担 880円      ← 誰も買わない

  → 解決策は2つしかない
     (A) まとめ買いを強制する（最低購入金額・送料無料ライン）
     (B) 店舗で受け取らせる（送料をゼロにし、ついで買いも取る）
```

実際、ダイソーのネットストアは **約4万商品を1点から購入できる**が、
**最低購入金額1,650円（税込）、送料770円（税込／北海道・沖縄・離島を除く）、
11,000円以上で送料無料**という条件になっている（2026年時点の公式案内ベース）。
法人・学校・団体向けには**まとめ買い専用のオンラインショップ**が別に用意されている。
ワッツもECの**店舗受取サービス**の対応店を拡大しており、
各社とも「送料を発生させない設計」に寄せている。

> ポイント：**ECは100円ショップの敵ではないが、味方にもなりにくい**。
> [EC・ネット通販](../../04_情報通信・IT・ネット/08_EC・ネット通販/README.md) が
> 他の小売を侵食してきたのに対し、100円ショップは
> **「送料より安い」という価格帯そのものが参入障壁になっている**。
> 逆に言えば、この業態はネットに移せないぶん、**店舗を持ち続けるしかない**。

## 10. 4社の戦略差をひとことで

| 企業 | 何を選んだか | 強さ | 弱さ・リスク |
| --- | --- | --- | --- |
| **ダイソー** | 規模と多価格帯。300円ブランドを別看板で展開 | 圧倒的な調達力、海外の成長余地 | 100円の看板が薄まる／為替の影響が最も大きい |
| **セリア** | 全品100円の維持とデザイン、POSによる単品管理 | 利益率の高さ、ブランドの明確さ | 原価上昇が続くと守り切れない／品揃えが痩せる |
| **キャンドゥ** | イオングループの出店網に乗る | 出店場所と資本の安定 | 規模が小さくロットで劣る／グループ依存 |
| **ワッツ** | 直営＋卸＋委託＋併設のチャネル分散 | 少ない投資で店数を伸ばせる | 1店あたりの規模が小さい／利益率は低め |

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **脱100円** | 150円・300円・500円など100円以外の価格帯の商品を増やすこと。既存商品の値上げではなく、**価格帯という選択肢を追加する**行為を指す |
| **Standard Products** | 大創産業の300円中心ブランド。素材感・シンプルなデザインを前面に出し、無印良品などに近い客層を狙う |
| **THREEPPY（スリーピー）** | 大創産業の300円中心ブランド。女性向けの雑貨・コスメが中心 |
| **プチプラ雑貨** | 手頃な価格帯（数百円〜）のデザイン雑貨店。3COINSなどが代表。脱100円を進めた100円ショップと売場が重なる |
| **POS（販売時点情報管理）** | 何が・いつ・何個売れたかをレジで記録する仕組み。セリアは2004年に業界で初めて導入し、単品ごとの売れ方で棚を組み替えている |
| **発注支援システム** | POSデータをもとに、店が何をいくつ発注すべきかを自動で提案する仕組み。セリアが2006年に稼働させた |
| **消化仕入（委託）** | 売れた時点で仕入を計上する契約。売れ残りリスクを供給側が持つため、店側は在庫リスクなしで売場を置ける |
| **均一業態** | 売価を1つ（または少数）に固定した小売業態。100円ショップのほか、ローソンストア100のような食品中心の均一店もある |
| **店舗受取（BOPIS）** | ネットで注文して店で受け取る方式。送料が発生しないため、単価の低い商材ではECの現実解になる |
