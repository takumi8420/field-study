このフォルダの読み方

100円ショップは「安売り店」ではない。売価を1つに固定することで、
小売業から“値付けの仕事”をまるごと消した装置である。
値札も、特売も、値引きシールも、レジでの価格照合もいらない。
その代わり、売価が動かないので原価が上がったら逃げ場がない。

利益は「1点あたりの原価」と「何点売れるか」だけで決まる。
だから各社は1商品あたりの発注ロットを数十万個規模まで膨らませて原価を削り、
原価率の違う商品を混ぜて平均粗利を作る。
店舗数がそのまま発注ロットになり、発注ロットがそのまま原価になる
——きわめて素直な規模の経済が効く業界である。

そして 2020年代、円安と原材料高がこの方程式を直撃した。
結果として起きているのが 「脱100円」、すなわち 150円・300円・500円という
価格帯の追加である。これは値上げではなく、売価という軸を1本から複数本に増やす業態転換にあたる。

ノート 内容
① 100円で売って儲かる仕組み均一価格＝値付けとレジ処理を極限まで簡素化した装置。損益が「原価」と「点数」だけで決まる構造、原価率の違う商品を混ぜて平均粗利を作るミックス、1品番数十万個というロットの大きさと金型負担、中国・アジア工場との直接取引と商社の残り方、為替・原材料高が粗利を丸ごと削る感応度、大量陳列で補充作業を減らす物流設計、SCテナントとしての店舗経済性
② 各社の違いと脱100円4社は「原価が上がったとき何を捨てるか」が違う。ダイソーの規模とStandard Products／THREEPPY（300円）、セリアの全品100円維持とPOS単品管理・デザイン、イオン傘下のキャンドゥ、卸・委託・スーパー内併設で広げるワッツ、脱100円は値上げでなく「メニューの追加」、海外出店（米国1,000店構想）、コンビニ・スーパーへの卸、ECの難しさ＝単価が送料に負ける
③ 直近トピック（2026年9月時点）市場3年連続1兆円超（2025年度 約1兆1,100億円）だが伸びは+2.7%へ鈍化、成長の中身は150〜500円帯、内容量調整と商品廃止という「見えない値上げ」、ダイソー15年連続最高益と海外シフト、全品100円のセリアが営業利益+24.5%、キャンドゥとワッツの別解

1. 業界の定義・範囲

100円ショップ ＝ 店内の商品を原則として同一の売価（日本では税込110円）で販売する、
生活雑貨中心の小売業態。均一価格ショップ、俗に「100均」。

定義の核心は 価格水準ではなく「売価が1つしかないこと」にある。
100円より安い日用品はドラッグストアにもディスカウントストアにもあるが、
それらは「値付けをする小売」であり、100円ショップは「値付けをしない小売」である。

【100円ショップの位置（1点単価 × 値付けの有無）】

  値付けをする
      ▲
      │  [百貨店]        [家電量販]
      │     [スーパー・GMS]   [ホームセンター]
      │        [ドラッグストア]  [ディスカウントストア]
      │                [3COINS など プチプラ雑貨]
      │                     ↑ 脱100円で ここへ接近
      │  ★100円ショップ★
  値付けをしない
      └──────────────────────────────▶
       単価 低                      単価 高

  隣接するが別扱いのもの：
   ・3COINS 等の300円ショップ  … 均一に近いが雑貨専門店に近い品揃え
   ・ローソンストア100         … 食品中心の均一コンビニ（→ 01_コンビニエンスストア）
   ・ディスカウントストア      … 安いが価格はバラバラ（→ 09_ディスカウントストア）
   ・無印良品・ニトリ          … 価格帯が上。脱100円で競合し始めた

5. 収益モデル・コスト構造

売上 = 販売点数 × 100円、粗利 = 販売点数 ×（100円 − 仕入原価）。
売価が定数なので、経営の努力は「原価を下げる」「点数を増やす」の2つに集約される。

項目 特徴
売上総利益商品ごとの原価率はバラバラ。プラ日用品・デザイン文具で稼ぎ、食品・電池・工具で客を呼ぶミックス構造
人件費客単価が低くレジ通過人数が多いため、売上比では重い。大量陳列で補充回数を減らすのが対策
賃料SC・駅ビル・スーパー内のテナントが主。自前の集客力が弱いぶん、他業態の集客に相乗りする
物流費数万SKUを全国数千店へ。海上運賃・国内配送費が直接効く
値引き・販促ほぼゼロ。1点の粗利が数十円なので値引く余地がなく、代わりに新商品の大量投入で来店頻度を作る
利益率の目安セリアの営業利益率 8.2%（2026年3月期）。小売としては高い水準

ポイント：売価が固定なので、既存店売上の増減がほぼそのまま利益の増減になる。
セリアは2026年3月期に売上+8.2%に対し営業利益+24.5%。伸びるときも落ちるときも増幅される。

6. 競争要因（KSF）と参入障壁

KSF 中身
店舗数（＝発注ロット）店が多いほど1品番の発注量が増え、原価が下がる。最も素直な規模の経済
商品企画力「100円で作れる仕様」に落とす設計力。原価から逆算する発想が要る
単品管理売れない品番を早く切ること。値引きで処分できないので、見切りの速さが在庫を決める
出店場所の確保SC・スーパーの空き区画の取り合い。キャンドゥがイオン傘下に入った理由でもある
金型・仕様の囲い込み金型費を負担できる規模の会社だけが専用商品を持てる

参入障壁は「許認可」ではなく 純粋に規模である。
小さく始めると原価が下がらず、原価が下がらないと100円で売れない。
一方、ワッツのように卸・委託で他人の店に置く形なら小資本でも参入できるため、
下位の入れ替わりは起きる。

7. 規制・法制度

この業態に固有の業法はない。関わるのは一般的な商取引・製品安全のルールである。

  • 消費税：総額表示の義務化により「100円均一」は店頭では110円表示。税率が変わると売価が動くという、均一価格ならではの論点がある
  • 製品安全：電気用品安全法（PSE）、食品衛生法（食品・食器）、家庭用品品質表示法など。低価格でも規制は同じにかかる
  • 輸入・通関：海外調達比率が高いため、関税・通商政策・原産地規制の影響を受ける
  • 下請法・独占禁止法：大ロット発注と金型負担を伴う取引は、優越的地位の濫用が問題になりうる領域
  • 最低賃金：店舗人件費に直結。売価を上げられないぶん、他業態より負担感が大きい

9. 用語メモ

各ノート末尾の「用語メモ」に分けて置いている。主要なものは次の通り。

用語 意味
均一価格店内の売価を1つに固定する方式。安売りではなく値付け作業の廃止が本質 → ①
