# 100円ショップ

- 大分類: 小売・流通
- 状態: done
- 更新日: 2026-09-20

## このフォルダの読み方

100円ショップは「安売り店」ではない。**売価を1つに固定することで、
小売業から“値付けの仕事”をまるごと消した装置**である。
値札も、特売も、値引きシールも、レジでの価格照合もいらない。
その代わり、**売価が動かないので原価が上がったら逃げ場がない**。

利益は「1点あたりの原価」と「何点売れるか」だけで決まる。
だから各社は1商品あたりの発注ロットを数十万個規模まで膨らませて原価を削り、
原価率の違う商品を混ぜて平均粗利を作る。
店舗数がそのまま発注ロットになり、発注ロットがそのまま原価になる
——**きわめて素直な規模の経済**が効く業界である。

そして 2020年代、円安と原材料高がこの方程式を直撃した。
結果として起きているのが **「脱100円」**、すなわち 150円・300円・500円という
価格帯の追加である。これは値上げではなく、**売価という軸を1本から複数本に増やす業態転換**にあたる。

## 1. 業界の定義・範囲

**100円ショップ ＝ 店内の商品を原則として同一の売価（日本では税込110円）で販売する、
生活雑貨中心の小売業態**。均一価格ショップ、俗に「100均」。

定義の核心は **価格水準ではなく「売価が1つしかないこと」**にある。
100円より安い日用品はドラッグストアにもディスカウントストアにもあるが、
それらは「値付けをする小売」であり、100円ショップは「値付けをしない小売」である。

```
【100円ショップの位置（1点単価 × 値付けの有無）】

  値付けをする
      ▲
      │  [百貨店]        [家電量販]
      │     [スーパー・GMS]   [ホームセンター]
      │        [ドラッグストア]  [ディスカウントストア]
      │                [3COINS など プチプラ雑貨]
      │                     ↑ 脱100円で ここへ接近
      │  ★100円ショップ★
  値付けをしない
      └──────────────────────────────▶
       単価 低                      単価 高

  隣接するが別扱いのもの：
   ・3COINS 等の300円ショップ  … 均一に近いが雑貨専門店に近い品揃え
   ・ローソンストア100         … 食品中心の均一コンビニ（→ 01_コンビニエンスストア）
   ・ディスカウントストア      … 安いが価格はバラバラ（→ 09_ディスカウントストア）
   ・無印良品・ニトリ          … 価格帯が上。脱100円で競合し始めた
```

## 3. バリューチェーン（川上 → 川下）

```
  原材料（樹脂・紙・金属）      ← 市況と為替がここで効く
        ▼
  海外工場（中国・東南アジア）  ← ダイソーは全商品の7割以上が海外製造とされる
        │  ※金型は本部が負担することが多く、実質的な専属化が起きる
        ▼
  商社／現地問屋（中小チェーン向けに残る）  or  本部と工場の直接取引（大手）
        ▼
  本部の商品部（企画・仕様・品質検査）
        │  ★ここが最大の付加価値
        │   「100円で作れるか」から逆算して仕様を決める
        ▼
  物流センター（コンテナ単位で受け、店別に仕分け）
        ▼
  店舗（直営／FC／委託）または 卸先の売場（スーパー内併設など）
        ▼
  消費者（客単価 数百円〜1,000円台、買上点数で稼ぐ）
```

付加価値が集まるのは **本部の商品企画**である。
「100円で作れる仕様に落とす力」と「何十万個を売り切る販売網」の2つを持つ会社だけが、
低い原価を引き出せる。

## 5. 収益モデル・コスト構造

**売上 = 販売点数 × 100円**、**粗利 = 販売点数 ×（100円 − 仕入原価）**。
売価が定数なので、経営の努力は「原価を下げる」「点数を増やす」の2つに集約される。

| 項目 | 特徴 |
| --- | --- |
| 売上総利益 | 商品ごとの原価率はバラバラ。**プラ日用品・デザイン文具で稼ぎ、食品・電池・工具で客を呼ぶ**ミックス構造 |
| 人件費 | 客単価が低くレジ通過人数が多いため、売上比では重い。**大量陳列で補充回数を減らす**のが対策 |
| 賃料 | SC・駅ビル・スーパー内のテナントが主。自前の集客力が弱いぶん、他業態の集客に相乗りする |
| 物流費 | 数万SKUを全国数千店へ。海上運賃・国内配送費が直接効く |
| 値引き・販促 | **ほぼゼロ**。1点の粗利が数十円なので値引く余地がなく、代わりに**新商品の大量投入**で来店頻度を作る |
| 利益率の目安 | セリアの営業利益率 **8.2%**（2026年3月期）。小売としては高い水準 |

> ポイント：売価が固定なので、**既存店売上の増減がほぼそのまま利益の増減になる**。
> セリアは2026年3月期に売上+8.2%に対し営業利益+24.5%。伸びるときも落ちるときも増幅される。

## 6. 競争要因（KSF）と参入障壁

| KSF | 中身 |
| --- | --- |
| **店舗数（＝発注ロット）** | 店が多いほど1品番の発注量が増え、原価が下がる。最も素直な規模の経済 |
| **商品企画力** | 「100円で作れる仕様」に落とす設計力。原価から逆算する発想が要る |
| **単品管理** | 売れない品番を早く切ること。値引きで処分できないので、見切りの速さが在庫を決める |
| **出店場所の確保** | SC・スーパーの空き区画の取り合い。キャンドゥがイオン傘下に入った理由でもある |
| **金型・仕様の囲い込み** | 金型費を負担できる規模の会社だけが専用商品を持てる |

参入障壁は「許認可」ではなく **純粋に規模**である。
小さく始めると原価が下がらず、原価が下がらないと100円で売れない。
一方、ワッツのように**卸・委託で他人の店に置く**形なら小資本でも参入できるため、
下位の入れ替わりは起きる。

## 7. 規制・法制度

この業態に固有の業法はない。関わるのは一般的な商取引・製品安全のルールである。

- **消費税**：総額表示の義務化により「100円均一」は店頭では110円表示。**税率が変わると売価が動く**という、均一価格ならではの論点がある
- **製品安全**：電気用品安全法（PSE）、食品衛生法（食品・食器）、家庭用品品質表示法など。低価格でも規制は同じにかかる
- **輸入・通関**：海外調達比率が高いため、関税・通商政策・原産地規制の影響を受ける
- **下請法・独占禁止法**：大ロット発注と金型負担を伴う取引は、優越的地位の濫用が問題になりうる領域
- **最低賃金**：店舗人件費に直結。売価を上げられないぶん、他業態より負担感が大きい
