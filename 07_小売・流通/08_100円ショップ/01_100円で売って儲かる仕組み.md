# ① 100円で売って儲かる仕組み

このノートで分かること：1点110円（税込）で売って、なぜ会社として利益が出るのか。
**「均一価格」という仕組みが、値付け・発注・レジ・棚替えの手間をどれだけ削っているか**。
そして、その仕組みがなぜ円安と原材料高にこれほど弱いのか。

> 結論：100円ショップの正体は「安売り店」ではなく、
> **売価を1つに固定することで、小売業から“値付けの仕事”をまるごと消した装置**である。
> 売価が動かないので、利益は「1品ごとの原価」と「何個作るか」だけで決まる。
> だから各社は **1商品あたりのロットを数十万個規模まで膨らませて原価を削り、
> 原価率の違う商品を混ぜて平均粗利を作る**。
> 売価を動かせない以上、原価が動いたら逃げ場がない。ここがこの業界の急所。

---

## 1. 「均一価格」はディスカウントではなく、業務の簡素化装置

100円ショップを「とにかく安い店」と理解すると、この業界は分からない。
実際には 100円ショップより安い日用品はドラッグストアにもディスカウントストアにもある。
均一価格の本質は価格水準ではなく、**売価が1つしかないこと**にある。

普通の小売と比べると、消えている仕事がはっきりする。

```
【普通の小売業（スーパー・ドラッグストア等）】

  仕入交渉 ─▶ 値入率を決める ─▶ 売価を決める ─▶ 値札をつくる
                                      │
                       競合の価格調査 ─┤（週次・日次）
                       特売の企画     ─┤
                       値下げ・見切り ─┘
                                      ▼
                              棚札の貼り替え・POS登録
                                      ▼
                       レジ：商品ごとに異なる価格を読み取る


【100円ショップ】

  仕入交渉 ─▶ 「100円で作れるか？」の一問だけ ─▶ YES なら採用 / NO なら不採用
                                      ▼
                       値札なし・棚札は共通・売価変更なし
                                      ▼
                       レジ：点数 × 110円（税込）で終わり
```

この差が効く場所は3つある。

- **本部の意思決定が速い**。価格を考えないので、商談は「この仕様でこの原価に収まるか」だけになる
- **店舗の作業が消える**。値付け・値札貼り替え・特売準備・見切りシール貼りがない
- **レジが速い**。点数を数えれば金額が出る。スキャンが不要だった時代（ワゴン販売・催事）から成立していた

> ポイント：100円ショップの原点は 1970年代の**移動販売のワゴン**である。
> トラックにワゴンを積んで催事場で売るとき、1点ずつ値付けしていては回らない。
> 「全部100円」はそのときの**現場の省力化の発明**であって、値下げ戦略ではなかった。

---

## 2. 売価が動かないと、損益は「原価」と「点数」だけで決まる

均一価格の会社の損益計算は、普通の小売より圧倒的に単純になる。

```
【100円ショップの損益の骨格】

   客数 × 買上点数 = 販売点数 N
        │
        │ × 100円（税抜売価）
        ▼
   売上高 = N × 100円
        │
        │ − 仕入原価（1点あたり C 円）
        ▼
   売上総利益（粗利） = N ×（100 − C）
        │
        ├─ 人件費（店舗の主費用）
        ├─ 地代家賃（SC・商業施設の賃料）
        ├─ 物流費（センター〜店の配送）
        ├─ 廃棄・ロス（万引き・不動在庫の処分）
        ▼
   営業利益
```

普通の小売では売価も原価も両方動くが、100円ショップでは **売価 100 円が定数**。
つまり粗利は「100 − C」で決まり、会社の努力の大半は **C（原価）を下げること**と
**N（点数）を増やすこと**に集中する。

セリア（全品100円を維持している唯一の大手）の実績で、この構造の効き方が確認できる。

| セリア 2026年3月期（2025年度・非連結） | 数値 | 前期比 |
| --- | --- | --- |
| 売上高 | 2,556億9,500万円 | +8.2% |
| 営業利益 | 209億6,800万円 | **+24.5%** |
| 経常利益 | 212億8,700万円 | +25.3% |
| 当期純利益 | 146億9,600万円 | +31.0% |
| 期末店舗数 | 2,134店（直営2,101／FC33） | — |
| 既存店売上高 | 前年同期比 **104.1%** | — |

（出典：セリア決算短信および流通スーパーニュース報道）

売上が8.2%増えたのに営業利益は24.5%増えている。
**売価が固定されている会社では、既存店の売上増がほぼそのまま利益に落ちる**からである。
店の家賃も店長の人件費も売上が増えても増えないので、
増えた分の粗利が固定費を超えた瞬間から、利益の伸びが売上の伸びを大きく上回る。
逆に言えば、**既存店がマイナスに振れた瞬間の落ち込みも同じ倍率で来る**。

## 3. 原価率の違う商品を「混ぜて」平均粗利を作る

「100円のものを100円で売る」と考えると成り立たないように見えるが、実際は
**1点ごとの原価率はまったく揃っていない**。会社は商品の構成比で平均粗利を作っている。

| 商品タイプ | 原価率の傾向 | 理由 | 売場での役割 |
| --- | --- | --- | --- |
| プラスチック日用品（収納・キッチン小物） | **低め** | 金型さえ作れば量産が効く。材料は樹脂 | 粗利の稼ぎ頭 |
| 文具・雑貨（デザイン系） | 低〜中 | 素材費が安く、デザインで価値を出せる | 粗利の稼ぎ頭 |
| 食品・菓子・飲料 | **高め** | 中身の原料費が固い。値引きできない | 来店頻度を作る |
| 電池・電球・工具・金属加工品 | **非常に高め** | 材料・電子部品の相場に直結 | 「あの店で買える」という信頼づくり |
| 化粧品・コスメ小物 | 中 | 容器と中身。ロット次第 | 若年層の来店動機 |

```
【平均粗利をつくるミックス（イメージ）】

   粗利大        プラ日用品・デザイン文具
      ▲   ┌──────────────────────┐
      │   │  ここで稼ぐ            │
      │   └──────────────────────┘
      │   ┌──────────┐
      │   │ コスメ等 │
      │   └──────────┘
      │           ┌──────────────┐
      │           │ 食品・菓子   │  ← 来店頻度を買っている
      ▼           └──────────────┘
   粗利小                 ┌──────────┐
                          │ 電池・工具│  ← ほぼ利益は出ない
                          └──────────┘

   平均すると会社としての粗利率が成立する
```

> ポイント：だから100円ショップの棚は「**儲かる商品の隣に、儲からないが客を呼ぶ商品**」が
> 必ず並んでいる。電池や電球が100円で置かれているのは、
> 単体で儲かるからではなく、**それを買いに来た人がついでに5点買う**からである。
> 1点の利益ではなく、**1回の来店で何点買うか（買上点数）**で設計されている。

原材料が上がったとき、まず消えるのは **原価率の高い商品**である。
実際、日本経済新聞（2025年12月）は、クリアファイルの入り数を10枚減らす、
洗濯ばさみを10個減らすといった**内容量の調整**や、採算の合わない商品の廃止が
進んでいると報じている。売価を動かせない以上、動かせるのは「中身の量」しかない。

## 4. 原価を下げる最大の武器は「1商品あたりのロットの大きさ」

100円ショップの商品が安いのは、仕入先を買い叩いているからだけではない。
**1品番あたりの発注数量が、他の小売と桁が違う**ことが効いている。

```
【1つの商品が生まれてから棚に並ぶまで】

  ① 本部の商品部が企画（仕様・サイズ・色・パッケージ）
        │  「100円で作れるか」を先に決める ＝ 原価から逆算した設計
        ▼
  ② メーカー／商社に打診・サンプル・金型製作
        │  金型代は本部持ちのことが多い（＝ 他社に使わせない）
        ▼
  ③ 発注：数十万〜100万個単位  ← ★ここが価格の源泉
        │  全国数千店 × 1店あたり数十個 で軽く到達する
        ▼
  ④ 中国・東南アジアの工場で生産（コンテナ単位）
        ▼
  ⑤ 海上輸送 → 国内港 → 自社／委託の物流センター
        ▼
  ⑥ 店舗へ配送 → 大量陳列（フェイスを広く取り、補充を減らす）
```

店舗が数千店あることが、そのまま調達力になる。
2026年3月末時点で大手4社の店舗数は**約9,400店**（帝国データバンク調査）。
1店に50個ずつ置くだけで47万個になる。**店舗数＝発注ロット＝原価**という連鎖が、
この業界を明確な規模の経済（大きいほど安く作れる）にしている。

さらに重要なのが **金型（プラスチックを成形する型）を本部が持つ**という慣行。
金型を本部が負担すれば、その形は自社専用になり、他社に流れない。
初期費用を負担できるのは大きな会社だけなので、ここでも規模が効く。

| 比較軸 | 一般的な小売のPB | 100円ショップ |
| --- | --- | --- |
| 1品番の発注ロット | 数千〜数万個 | **数十万個以上** |
| 売価の決め方 | 原価に値入率を掛けて決める | **売価が先にあり、原価を逆算** |
| 仕様変更の自由度 | 原価が上がれば売価を上げられる | 売価を変えられないので**仕様（量・材質）を変える** |
| 仕入先との関係 | 相見積もりで都度比較 | 金型・型代の負担で**事実上の専属化** |

## 5. 中国・アジアの工場との直接取引と、そこに残る商社の役割

100円ショップの商品の多くは海外で作られている。報道ベースでは、
**ダイソーは全商品のうち7割以上が海外製造**とされる（2026年時点の各種報道）。

なぜ直接取引が増えたか。理由は単純で、**間に人が入るたびに原価が数円上がるから**である。
売価100円の世界では、1円は粗利の数%に相当する。

```
【調達ルートの違いと原価への影響（イメージ）】

  (A) 商社経由
      海外工場 ─▶ 現地商社 ─▶ 日本の商社／問屋 ─▶ 100円ショップ本部
                  口銭      口銭・在庫リスク料
      → 原価は上がるが、与信・輸入手続き・品質保証・為替予約を任せられる

  (B) 直接取引（大手が進めてきた形）
      海外工場 ─────────────────────▶ 100円ショップ本部（現地に駐在員・検品拠点）
      → 原価は下がるが、品質管理・輸出入実務・為替リスクを自社で背負う
```

大手は(B)に寄せてきたが、(A)がなくなったわけではない。
**商社・問屋は「小さいチェーンのための調達代行」として残っている**。
業界4位のワッツは直営店のほかに**卸売**（グループの卸会社が他社の店へ商品を供給）と
**委託店（消化仕入＝売れた分だけ仕入を計上する形）**を持つ。
自社で工場と直接やり合える規模がなくても、卸に乗れば100円ショップは開ける。

→ 商社側から見た同じ構造は [総合商社](../../06_商社・卸売/01_総合商社/README.md) と
[食品卸](../../06_商社・卸売/06_食品卸/README.md) のノートが詳しい。

## 6. 為替と原材料高が「直撃」する理由

普通の小売なら、仕入値が上がれば売価に転嫁する。100円ショップはそれができない。
**売価が商号（店の名前）そのものだから**である。
「100円ショップなのに120円」は、値上げではなくブランドの否定になってしまう。

結果として、コストの変動が**そのまま粗利の変動になる**。

```
【1点の粗利がどう削られるか（税抜100円・例示のモデル計算）】

  円安前                        円安後（同じ商品・同じ原価$）
  ┌────────────────┐          ┌────────────────┐
  │ 仕入原価  55円 │          │ 仕入原価  68円 │  ← 為替と材料費で上昇
  ├────────────────┤          ├────────────────┤
  │ 物流・関税10円 │          │ 物流・関税13円 │  ← 海上運賃・燃料
  ├────────────────┤          ├────────────────┤
  │ 粗利      35円 │          │ 粗利      19円 │  ← ★ 約45%減
  └────────────────┘          └────────────────┘

  ※金額は構造を示すための例示。実際の原価は企業・商品ごとに大きく異なる
```

売価が動かないので、**原価が13円上がると粗利が13円丸ごと消える**。
これは売価を上げられる小売の感応度とはまったく違う。
売価110円（税込）のうち十数円が動くということは、**利益がほぼ吹き飛ぶ**ということである。

会社が取れる手は4つしかない。

| 手段 | 具体例 | 副作用 |
| --- | --- | --- |
| **量を減らす** | クリアファイル10枚減、洗濯ばさみ10個減（2025年12月・日経報道） | 実質値上げと受け取られる |
| **材質・仕様を落とす** | 薄くする、簡素なパッケージにする | 品質への信頼を損なう |
| **商品を廃止する** | 100円で作れなくなった品番をやめる | 品揃えが痩せ、来店理由が減る |
| **価格帯を増やす** | 150円・300円・500円の商品を導入する | 「100円ショップ」という前提が崩れる（→ [② 各社の違いと脱100円](02_各社の違いと脱100円.md)） |

> ポイント：**「脱100円」は攻めの多角化に見えて、その出発点はこの粗利の方程式**である。
> 原価が上がり、量を減らすのにも限界が来たとき、残る手は価格帯の追加しかない。

## 7. 物流と大量陳列 — 「補充しない」ことが人件費対策になる

100円ショップの店内は、他の小売と比べて**1つの商品が縦にも横にも大量に積まれている**。
これは見栄えのためではなく、はっきりした経済的な理由がある。

- 1点の粗利が数十円しかないので、**1点を売るのにかけられる作業時間が極端に短い**
- したがって、店では「並べ替える」「値付けする」作業を発生させてはいけない
- 棚に何日分も積んでおけば、**補充の回数そのものを減らせる**

```
【在庫をどこに置くかの設計思想】

  一般的な小売              100円ショップ
  ┌──────────┐             ┌──────────┐
  │ 店の棚   │ 少なめ      │ 店の棚   │ ★大量に積む（＝店頭が倉庫）
  ├──────────┤             ├──────────┤
  │ 店のバック│ 多め        │ 店のバック│ 少なめ
  ├──────────┤             ├──────────┤
  │ 物流センター│           │ 物流センター│ 大ロットをまとめて受け、店へ一括
  └──────────┘             └──────────┘
    頻繁に補充               補充回数を減らす＝人件費を減らす
```

取扱品目は各社とも **数万SKU（SKU＝品番のこと。色違い・サイズ違いも別に数える）** 規模になる。
品目が多いのに1点の単価が低いので、**物流費と在庫回転が利益を左右する**。品揃えの厚みで勝負する
[ホームセンター](../07_ホームセンター/README.md)・[ディスカウントストア](../09_ディスカウントストア/README.md)に近く、
少ない品目を高回転で回す [コンビニエンスストア](../01_コンビニエンスストア/README.md) とは逆の設計になっている。

## 8. 店舗の経済性 — 立地はほぼ「商業施設のテナント」

100円ショップは、路面の単独店より **ショッピングセンター（SC）や駅ビル、スーパーの区画に
テナントとして入る**形が主流である。理由はそのまま経済性になっている。

| 項目 | 100円ショップの特徴 | なぜそうなるか |
| --- | --- | --- |
| 客単価 | **数百円〜1,000円台**と低い | 1点110円だから。買上点数を増やすしかない |
| 集客 | 自前の集客力は弱い | 単価が低く、わざわざ遠出して来る店ではない |
| 立地 | SC・駅ビル・スーパー内の区画 | **他の店が集めた客を分けてもらう**のが最も効率的 |
| 面積 | 100〜300坪級の大型化が進む | 品目数の多さが売りなので、広いほど強い |
| 人件費 | 売上に対する比率が高い | 客単価が低く、レジ通過人数が多いため |

SC側から見れば100円ショップは、**面積を取ってくれて客を呼び、業態として潰れにくい**扱いやすいテナントである。
だからスーパーやSCの改装で空いた区画に入りやすく、
これが出店ペース（大手4社で年間100店超、2026年3月末で約9,400店）を支えている。

## 9. なぜ値引きもポイントも打たないのか

100円ショップはセールをしない。チラシもほとんど打たない。これも構造から説明できる。

- **値引きの余地がない**：1点の粗利が数十円。10%引けば粗利が3〜4割飛ぶ
- **値引きの作業費が粗利を超える**：シールを貼る人件費だけで粗利が消える
- **均一価格が壊れる**：1点でも値引きすると「レジは点数×110円」という前提が崩れる

代わりに各社が打つのは「**新商品を毎月大量に入れ替える**」という手である。
値引きではなく**新奇性で来店頻度を作る**のが、この業態の販促にあたる。

## 10. まとめ — この業態の強さと弱さは同じ場所から来る

```
        ┌──────────────────────────┐
        │   売価を100円に固定する   │
        └────────────┬─────────────┘
   【強さ】          │          【弱さ】
  ・値付け・特売・値引きが不要  ・原価上昇を転嫁できない
  ・レジと店舗運営が単純        ・粗利が為替と市況に直撃される
  ・大ロット発注で原価が下がる  ・原価率の高い商品から消えていく
  ・店が増えるほど原価が下がる  ・値上げ＝ブランドの否定になる
```

次のノート [② 各社の違いと脱100円](02_各社の違いと脱100円.md) では、
この方程式に対して4社がそれぞれ違う答え（規模／全品100円の維持／グループ活用／卸と委託）を
出していることを見る。

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **均一価格（均一ショップ）** | 店内の商品をすべて同じ売価で売る方式。値付け・値札・値引き作業が消えるのが本質で、単なる安売りとは別物 |
| **SKU（エスケーユー）** | 在庫管理の最小単位。色違い・サイズ違いは別SKUとして数える。100円ショップは各社数万SKU規模 |
| **買上点数** | 1人の客が1回の来店で買う点数。単価が固定の100円ショップでは、客単価＝買上点数×110円になる |
| **値入（ねいれ）** | 仕入原価に対してどれだけ利益を乗せて売価を決めるか。100円ショップは売価が先に決まるので、この工程が逆転している |
| **消化仕入（委託）** | 商品が売れた時点で仕入を計上する契約。売れ残りリスクを供給側が持つ。ワッツの委託店などで使われる |
| **金型** | プラスチックや金属を成形するための型。本体価格が高く、本部が負担すると事実上その仕様は自社専用になる |
| **ロット** | 1回にまとめて発注・生産する数量。100円ショップは数十万個規模になり、それが原価を押し下げる |
| **坪効率** | 売場1坪あたりの年間売上高。単価の低い100円ショップは、面積を広く取って品目数で稼ぐ設計になる |
| **消化率・死に筋** | 売れ残った商品（死に筋）をどれだけ早く処分できるか。値引きができないので、廃棄か在庫として残るかになる |
