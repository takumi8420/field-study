# 調査手順

## 1. 順番

1. **既存ノートを読む**（対象フォルダと関連業界）。重複を避け、加筆点を見つける
2. **基礎知識を自分の知識で下書きする**（構造・仕組み・プレイヤー）
3. **Web検索で直近動向を取る**（必須。最低3〜5クエリ）
4. **数値を確認する**。年・出典・単位を揃える
5. 書く

## 2. 検索クエリの型

業界名を `X` として、次の軸で組み立てる。日本語と英語の両方を試す。

| 軸 | クエリ例 |
| --- | --- |
| 市場規模 | `X 市場規模 2026 推移` / `X market size 2026` |
| 業界構造 | `X 業界 シェア ランキング 2026` |
| 最新動向 | `X 業界 最新動向 2026` / `X 再編 統合 2026` |
| 制度・規制 | `X 規制 改正 2026` / `X 補助金 政策` |
| 課題 | `X 業界 課題 人手不足 値上げ` |
| 主要企業 | `〈代表企業名〉 決算 2026 業績` |

**一次情報を優先**：官公庁（経産省・国交省・厚労省）、業界団体の統計、企業のIR。
まとめ記事は入口として使い、数値はできるだけ一次情報で裏を取る。

## 3. 数値の扱い

- 出どころを3段階で区別する
  1. **統計・公式**（政府統計、業界団体、企業IR）→ そのまま書いてよい
  2. **調査会社の推計** → 「〜の推計」と明記
  3. **報道・ブログ** → 「〜と報じられる」と明記。可能なら一次情報を探す
- 年を必ず付ける。「約◯◯」「◯◯前後」と丸めてよいが、桁は間違えない
- 分からない数値は**書かない**。曖昧なまま断定するより「最新は◯◯で確認」と書く

## 4. 業界ごとに押さえる定番の統計

| 分野 | 主な統計・情報源 |
| --- | --- |
| 製造業全般 | 経済産業省 生産動態統計、工業統計 |
| 半導体 | WSTS、SEMI、SEAJ |
| 自動車 | 日本自動車工業会（JAMA）、各社販売台数 |
| 小売 | 経産省 商業動態統計、日本チェーンストア協会、日本フランチャイズチェーン協会 |
| 外食 | 日本フードサービス協会 |
| 建設・不動産 | 国交省 建設工事受注動態統計、不動産経済研究所 |
| 金融 | 金融庁、日銀統計、全国銀行協会、生命保険協会 |
| 医薬 | 厚労省、日本製薬工業協会、IQVIA |
| 物流 | 国交省 自動車輸送統計、日本ロジスティクスシステム協会 |
| 通信・IT | 総務省 情報通信白書、MM総研 |
| エネルギー | 資源エネルギー庁、電力広域的運営推進機関 |

## 5. 直近トピックノートに書くこと

- **いつの話か**を見出しまたは本文に必ず入れる（YYYY年M月）
- 1トピック＝1見出し。5前後に絞る（全部載せない）
- 最後に「全体の構図」を3〜5行でまとめる
- **参考リンク**として実際に見たURLを列挙する

## 6. 出典提示のルール

- WebSearch を使ったら、ユーザーへの報告でも出典URLをマークダウンリンクで示す
- ノート内には `## 参考リンク` として URL をそのまま列挙する（リンク切れに備え媒体名も添える）
- 有料記事・ログインが必要なページは、その旨を書いておく
