# 実例：半導体（10本立て）

このスキルの基準となった実装例。**どこまで分解すれば「分かる」のか**の目安として使う。
実物は `03_電機・電子部品/02_半導体（ロジック・メモリ）/` と
`01_注目テーマ/02_半導体・先端半導体/` と `03_電機・電子部品/04_半導体材料/`。

## 1. 構成

| ノート | 何を解いたか |
| --- | --- |
| 概要（README） | 業界の定義、市場規模、プレイヤー、収益構造、KSF、規制 |
| サプライチェーンと業界構造 | 設計→マスク→前工程→後工程→実装の流れ。IDM/ファブレス/ファウンドリ/OSATの4類型 |
| 前工程 | 成膜・露光・エッチング等の8動作と、それを何十層も繰り返す構造。歩留まりの算数 |
| 後工程 | ダイシング〜最終テスト、先端パッケージ（CoWoS・HBM・チップレット） |
| トランジスタの原理 | MOSFETの動作原理。なぜ微細化で速くなり、なぜ3次元構造になったか |
| 用語集 | 7分野に分けた用語索引。各解説ノートへリンク |
| プロセスノード名の正確な意味 | 「2nm」は長さではない、という誤解の解消 |
| AI半導体とHBM | 需要側の構造。ボトルネックが後工程にあること |
| 地政学と各国政策 | チョークポイント、輸出管理、補助金 |
| 直近トピック_2026 | 出典URL付きの最新動向 |
| シリコンウェハー（材料側） | 素材メーカーの領域。日本勢の強さ |

## 2. ここから抽出できる「型」

### (1) 縦に3層で分解する

```
需要側（誰が何のために買うか）      ← AI半導体とHBM
   ↑
産業構造（誰が何を作り誰に売るか）   ← サプライチェーンと業界構造
   ↑
物理・技術（そもそもどう作るのか）   ← 前工程／後工程／トランジスタの原理
```

産業構造だけ書いても「分かった気」にしかならない。
**下（技術）と上（需要）を押さえて初めて、ニュースの意味が読める**。

### (2) 誤解を1本のノートで潰す

「2nm＝長さ」「BEOL＝後工程」のような**広く信じられている誤解**は、
独立したノートまたは明示的な注意書きで潰す。これが教科書の価値になる。

### (3) ボトルネックを名指しする

「AI半導体が足りない」の実体は CoWoS と HBM の能力不足だった。
**どの業界にも「実際に詰まっている場所」がある**ので、それを特定して書く。

### (4) テーマ面と業界面を分ける

技術の流れ（前工程・後工程）は業界フォルダに、
話題性のあるテーマ（AI・地政学・国策）は注目テーマのフォルダに置き、**相互リンクする**。
片方に全部入れると、どちらから来た読者も迷う。

### (5) 直近トピックは年つきで独立させる

本体ノート（構造・原理）は数年変わらない。動く部分だけを
`直近トピック_YYYY.md` に隔離すると、更新が楽で陳腐化も分かりやすい。

## 3. 分量の目安

- 概要（README）：120〜180行
- 仕組みのノート：150〜250行
- 直近トピック：80〜150行
- 用語集：業界規模しだい（半導体では約100語）

## 4. 他業界へ適用するときの読み替え

| 半導体での問い | 他業界での読み替え |
| --- | --- |
| どう作るのか（前工程・後工程） | どうやってその価値が生まれるか（工程／資金の流れ／店舗運営） |
| 誰が作り誰に売るか（4類型） | プレイヤーの類型と、分業の線引き |
| ボトルネックはどこか（CoWoS） | 供給・収益の制約になっている工程や資源 |
| 「2nm」の誤解 | その業界で広く誤解されている言葉 |
| 地政学・国策 | 規制・制度・補助金がどう需給を動かすか |
