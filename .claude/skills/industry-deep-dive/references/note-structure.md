# ノート構成の型

## 1. 1業界のフォルダ構成

```
NN_大分類/NN_業界名/
├── README.md                    # 概要。10章の骨格＋ノート索引
├── 01_サプライチェーンと業界構造.md
├── 02_〈その業界固有の仕組み〉.md
├── 03_〈さらに分解した仕組み〉.md   # 必要なら
├── 04_〈原理・技術／制度〉.md       # 必要なら
├── 05_用語集.md                  # 業界が大きいときのみ独立
└── 06_直近トピック_YYYY.md
```

- **1ノート = 1テーマ**。目安 150〜350 行。1テーマを分割してまで行数に収めない
  （因果の説明・数値の根拠・参考リンクを落とすくらいなら超えてよい）
- ファイル名は `NN_テーマ名.md`（連番2桁＋日本語）。サイト側は連番順に並ぶ
- 小さい業界なら README＋2〜3本で十分。無理に本数を増やさない

## 2. README.md の型（10章）

```markdown
# 〈業界名〉

- 大分類: 〈大分類名〉
- 状態: todo        ← 書き終えたら done
- 更新日: YYYY-MM-DD

## このフォルダの読み方
| ノート | 内容 |          ← 各深掘りノートへのリンク表

## 1. 業界の定義・範囲      隣接業界との境界をはっきり書く
## 2. 市場規模と成長性      数値には必ず年と出典。国内/世界を区別
## 3. バリューチェーン      川上→川下。どこに付加価値が集まるか
## 4. 主要プレイヤーとシェア  表形式。立ち位置と特徴を1行ずつ
## 5. 収益モデル・コスト構造  何で儲けるか。固定費/変動費、利益率の目安
## 6. 競争要因（KSF）と参入障壁
## 7. 規制・法制度          許認可、業法、政府方針、補助金
## 8. 最近のトピック        直近トピックノートへのリンク＋要点5行
## 9. 用語メモ              用語集へのリンク
## 10. 参考リンク           統計・業界団体・主要企業IR
```

## 3. 業界タイプ別「仕組み」ノートの切り口

**ここが最重要**。業界によって「分かる」ために必要な分解の軸が違う。
対象業界がどの型かを見極めてから書く。

| 型 | 中核ノートの切り口 | 必ず触れる指標 |
| --- | --- | --- |
| **製造業**（自動車、機械、電機、半導体） | 工程フロー（上流→下流）、設備投資と稼働率、内製/外注の線引き、系列構造 | 稼働率、歩留まり、内製率、設備投資額 |
| **素材・化学・資源** | 原料から製品までの流れ、市況商品か機能品か、プラントの経済性 | スプレッド（原料と製品の値差）、稼働率、市況 |
| **金融**（銀行、証券、保険、リース） | **お金の流れ**（誰から集めて誰に回すか）、収益源（利ざや／手数料／保険料と支払）、リスクの引受先 | 利ざや、手数料比率、自己資本比率、コンバインドレシオ |
| **小売・外食** | **店舗の経済性**（1店舗の売上・原価・人件費・家賃）、出店戦略、商品調達（PB/卸） | 坪効率、原価率、人件費率、客単価×客数、既存店前年比 |
| **サービス・人材・コンサル** | 人の稼働で稼ぐ構造、単価×稼働率、リピートと紹介 | 稼働率、単価、定着率、リピート率 |
| **インフラ**（電力、ガス、鉄道、通信、水道） | **料金がどう決まるか**（総括原価・認可・自由化）、設備投資の回収年数、ユニバーサルサービス義務 | 設備投資額、償却費、利用者数、料金規制 |
| **不動産・建設** | 開発〜保有〜運用のどこで稼ぐか、受注から引渡しまでの時間差、資金調達 | 利回り、稼働率、受注残、粗利率 |
| **医薬・ヘルスケア** | 開発から承認・保険収載までの流れ、特許の崖、診療報酬 | 開発期間、特許切れ、薬価改定、承認確率 |
| **メディア・エンタメ** | IPの権利構造、広告と課金の二本立て、制作と流通の分離 | 広告単価、課金ARPU、IP寿命 |
| **IT・ネット** | プラットフォームの両面市場、獲得と継続の経済性 | ARR、解約率、CAC/LTV、テイクレート |
| **物流・運輸** | ネットワークの経済性、積載効率、拠点配置 | 積載率、実車率、荷動き量 |
| **商社・卸** | 商流（口銭ビジネス）と投資（事業投資）の二層構造 | トレーディング損益、持分利益、在庫回転 |

複数の型にまたがる業界（例：コンビニ＝小売＋物流＋FC）では、
**主たる型で骨格を作り、副次の型を1章として足す**。

## 4. 「直近トピック」ノートの型

```markdown
# 直近トピック（YYYY年M月時点）

報道ベースの整理。一次情報で必ず裏取りすること。

## 1〜5. テーマ別の見出し（数値は年月とセットで）
## N. 全体の構図（3〜5行でまとめ）
## 参考リンク（URL一覧）
```

- ファイル名に年を入れる（`06_直近トピック_2026.md`）。翌年は新ファイルにして古いものを残す
- 「◯◯と報じられる」「推計」を明示し、確定事実と区別する

## 5. 用語集の型

用語を**分野別のテーブル**に分け、詳しい解説ノートへリンクする。
業界が小さければ各ノート末尾の「用語メモ」だけで足りる。
大きい業界（半導体、金融など）は独立した `用語集.md` を作る。

```markdown
| 用語 | 意味 |
| --- | --- |
| **○○** | 1〜2行の説明 → [詳しいノート](02_〜.md) |
```
