## このフォルダの読み方

繊維商社は **「服をつくりたい会社（アパレル企業）の代わりに、糸から生地、染色、縫製までバラバラの工場を束ねて、製品にして納める会社」**。
服づくりは工程ごとに会社が違い、しかもその工場が何カ国にも散らばっている。**その全部をつなぐ人がいないと1枚の服にならない**——この「つなぐ」機能を売っているのが繊維商社である。

もうひとつの顔が **日本の商社そのものの源流** であること。伊藤忠商事も丸紅も双日も、もとは綿花・綿布を扱う繊維商だった（→ [総合商社](../01_総合商社/README.md)）。
いまは**アパレル市場の縮小と、SPA（製造小売）が工場と直接取引する流れ**に挟まれ、機能素材・産業資材・海外市場へ軸足を移している最中にある。

## 1. 業界の定義・範囲

**繊維商社** ＝ 繊維原料・糸・生地（テキスタイル）・衣料品などを売買し、あわせて **生産の手配そのものを請け負う専門商社**。
単に右から左に流すのではなく、**「モノを作らせる」ところまで踏み込む**のが特徴で、この点が他の専門商社（[鉄鋼商社](../02_鉄鋼商社/README.md)・[化学商社](../03_化学商社/README.md)など）と大きく違う。

境界を整理すると次のようになる。

```
【繊維に関わる会社の役割の違い】

  ┌──────────┬──────────────────────────┐
  │ 素材メーカー     │ 糸・原綿・機能繊維を「作る」                 │
  │ （東レ・帝人ほか）│ 工場と研究所を持つ。→ 10_素材・化学/08_繊維 │
  ├──────────┼──────────────────────────┤
  │ ★繊維商社★      │ 作らない。ただし「作らせる」                 │
  │                  │ 生地の目利き・企画提案・工場手配・与信・在庫  │
  ├──────────┼──────────────────────────┤
  │ OEM専業メーカー  │ 自社工場を持ち、受託生産する                 │
  │                  │ 商社と似た仕事をするが、設備リスクを負う      │
  ├──────────┼──────────────────────────┤
  │ アパレル企業/SPA │ 企画・ブランド・販売。→ 07_小売・流通/10    │
  └──────────┴──────────────────────────┘
```

- **卸売業との違い** ＝ 既製品を仕入れて売るのが卸。繊維商社は **企画段階から入り、生産を組み立てる**
- **OEM専業メーカーとの違い** ＝ メーカーは自社工場という固定費を持つ。商社は **工場を選び直せる身軽さ**が武器
- **総合商社の繊維部門との違い** ＝ 実は機能はほぼ同じ。違いは **資金力と、川下ブランドへの出資規模**

本ノートでは、**独立系・素材メーカー系の繊維専門商社**を主役に置き、総合商社の一般論（事業投資で稼ぐ二層構造など）は [総合商社](../01_総合商社/README.md) に委ねる。

### 歴史は簡潔に：「五綿八社」

戦前から戦後にかけて、日本の貿易の主役は**綿花の輸入と綿布の輸出**だった。
その担い手が **「五綿（ごめん）」＝ 東洋棉花・日本綿花・江商・伊藤忠商事・丸紅** と、これに岩井産業・安宅産業・蝶理を加えた **「五綿八社」** である。

```
 五綿八社（繊維系商社）の主な行方

  東洋棉花 ─▶ トーメン ─────▶ 豊田通商に統合（2006年）
  日本綿花 ─▶ ニチメン ┐
  岩井産業 ─▶ 日商岩井 ┴───▶ 双日（2004年）
  江商　　 ─▶ 兼松江商 ─────▶ 兼松
  伊藤忠商事 ───────────▶ 伊藤忠商事（繊維カンパニーとして存続）
  丸紅　　　 ───────────▶ 丸紅
  安宅産業 ─────────────▶ 伊藤忠に吸収（1977年、経営破綻）
  蝶理　　 ─────────────▶ 東レが筆頭株主。東証プライム上場（8014）
```

> ポイント：総合商社は繊維から始まった。だから **「繊維商社が商社の原型」** であって、その逆ではない。
> 伊藤忠の非資源の強さも、丸紅の内需の厚みも、元をたどればこの繊維の商売のやり方に行き着く。

## 2. 市場規模と成長性

繊維商社そのものの市場統計は存在しない。**「顧客であるアパレル市場」と「日本の繊維産業」の2つの数字で挟んで捉える**のが実務的。

| 指標 | 数値 | 時点・出典 |
| --- | --- | --- |
| 国内アパレル総小売市場規模 | **約8兆5,010億円**（前年比 +1.7%、4年連続プラス） | 2024年、矢野経済研究所の推計 |
| 同・バブル期からの推移 | ピーク時 **約15兆円** → 直近 **8〜10兆円**へ縮小 | 経済産業省 資料 |
| 国内供給量（点数） | 約 **20億点 → 約40億点** へほぼ倍増 | 同上。金額は減り数量は増えた＝**単価が半分以下に** |
| 衣料品の輸入浸透率（数量ベース） | **98.5%** | 2022年、経済産業省 資料 |
| 国内繊維産業の出荷額 | 約 **3.7兆円** | 2021年、経済産業省 資料 |
| 国内繊維産業の従業者数 | 約 **23.1万人**（事業所数 約1.3万） | 2021年、同上 |
| 有力繊維商社の規模感 | トップ級で **売上高2,000〜3,000億円** | 2025〜2026年の各社決算。→ 第4章 |

この「**金額は半分、数量は倍**」という2本の線が、繊維商社の置かれた状況をほぼすべて説明する。

```
【国内アパレル市場：金額と数量が逆向きに動いた】

 金額（兆円）                         数量（億点）
  15 ┤●                                  40 ┤                    ●
     │ ●                                    │               ●
  12 ┤   ●                               30 ┤          ●
     │      ●                               │     ●
   9 ┤         ●───●───●                20 ┤●
     └─────────────────         └──────────────────
     1990        2010      2024            1990         2010    2024

  ＝ 1点あたりの単価が大幅に下落した（おおむね半分以下）
  ＝ 商社は「同じ売上を作るのに、倍の枚数をさばく」必要が出た
```

- 輸入浸透率98.5%（2022年）は、**国内で売られる服のほぼ全部が海外製**という意味。この輸入を実務として回しているのが繊維商社
- 成長ドライバーは国内アパレルではない。**(a) 海外販売、(b) 非衣料（産業資材）、(c) 高付加価値素材** の3方向 → [② 市場の変化と生き残り](02_市場の変化と生き残り.md)

## 3. バリューチェーン（川上 → 川下）

繊維は **工程数がきわめて多く、しかも工程ごとに会社が違う**。ここが他産業と決定的に異なる。

```
【綿のTシャツが1枚できるまで（工程と担い手）】

 原綿 ─▶ 紡績 ─▶ 織り/編み ─▶ 染色・加工 ─▶ 裁断・縫製 ─▶ 検品 ─▶ 物流 ─▶ 店頭
（産地）  (糸に)   (生地に)      (色と機能)     (製品に)      (品質)   (船)   (販売)

  担い手： 商社    紡績会社   機屋(はたや)  染工場      縫製工場    検品会社 フォワーダー アパレル
           /生産者                            (産地)      (海外中心)

  ─────────── ここ全部を1社で持つ会社は存在しない ───────────
                        ↓
        ★繊維商社が「横串」を通して、1枚の製品として納める★
          ・工程ごとに発注、支払、品質、納期を管理
          ・途中の在庫（糸・生地）は商社の名義で持つことが多い
```

**どこに付加価値が集まるか**は3カ所に偏っている。

| 付加価値が乗る場所 | 理由 | 主に取るのは誰か |
| --- | --- | --- |
| **素材（機能繊維・特殊生地）** | 代替が効かない。特許・製法・設備が壁 | 素材メーカー＋その系列商社 |
| **企画・ブランド** | 売価を決める権利を持つ | アパレル／SPA |
| **多工程を束ねる調整** | 属人的で、失敗コストが大きい | **繊維商社** |
| （中間の単純な売買） | 情報が透明になり口銭が薄い | 誰も取れない＝消えていく層 |

> ポイント：繊維商社の儲けは「モノの差額」ではなく **「面倒くささの代行料」**。
> 面倒が減る（＝取引が標準化する）ほど、商社の取り分は薄くなる。これが業界の構造的なジレンマ。

詳しくは [① アパレル生産の裏方](01_アパレル生産の裏方.md)。

## 5. 収益モデル・コスト構造

```
繊維商社の利益 ＝ ① 口銭（仲介手数料）
                ＋ ② OEM/ODMの製品売買マージン（企画込みの値差）
                ＋ ③ 素材・ブランドの独占販売権から来る利益
                ＋ ④ 事業投資（ブランド・工場・小売）の持分利益
                －   販管費（人件費・海外拠点費）
                －   在庫評価損（売れ残った生地・製品）
                －   貸倒損失（アパレル企業の倒産）
                ±   為替（ドル建て仕入れ × 円建て販売）
```

| 論点 | 中身 |
| --- | --- |
| **利益率は薄い** | 売上高営業利益率は **おおむね2〜5%**。上の企業一覧でも、売上2,000〜3,000億円クラスで営業利益100〜170億円の水準 |
| **薄い理由** | 取引先（アパレル）の数が多く、1件あたりの金額が小さい。かつ **同じ工場を複数の商社が使える**ので値段で比べられる |
| **在庫が命取り** | 服は**シーズンを越えると値段が付かない**。繊維商社は生地在庫・製品在庫を自分の名義で抱えることが多く、売れ残りが直接損失になる |
| **与信リスク** | 顧客のアパレル企業は中小が多く、倒産が珍しくない。**代金回収まで含めて商社の仕事**。逆に言えば与信を引き受けているから口銭が取れる |
| **為替** | 仕入れは主にドル建て、販売は円建て。**円安は仕入れコスト増**。ただし輸出取引や海外子会社の利益は円安で増える（会社ごとに向きが違う） |
| **固定費は軽い** | 工場を持たないので設備負担がない。主なコストは**人件費と海外拠点の維持費**。ただし帝人フロンティアのように工場を持つ例外もある |
| **口銭の水準** | 単純仲介で **数%**、企画から入るODMではより厚く取れる。「**どこまで面倒を引き受けたか**」で取り分が決まる |

## 6. 競争要因（KSF）と参入障壁

**KSF（成功の鍵）**

1. **生地の目利きと企画提案力**。「この生地でこういう服が作れます」と先に持ち込めるか。**発注を待つ側か、発注を作る側か**の差
2. **工場ネットワークの厚み**。国・地域・工程ごとに代替先を持っていること。1カ所が止まっても回せるか
3. **納期を守り切る力**。アパレルは発売日が決まっている。**遅れは即失注**。短納期・期中追加に応えられるか
4. **与信の見極め**。誰に売って、いくらまで掛けで出すか。1件の貸倒れが1年の利益を吹き飛ばす
5. **在庫の切り方**。持つ勇気と、損切りの規律の両方が要る
6. **非衣料の柱を持っているか**。アパレル市況に左右されない収益源（産業資材・寝装・資材）があるか
7. **サステナビリティと人権対応の体制**。取引の前提条件になりつつある（→ 第7章）

**参入障壁**

| 障壁 | 強さ | 理由 |
| --- | --- | --- |
| 資本・設備 | **弱** | 工場が要らない。小さな繊維商社は今も多数ある |
| 商流そのもの | 弱 | 貿易実務は学べる。ネットで工場も探せる時代 |
| **工場との長年の関係** | **強** | 「忙しい時期に枠を確保してもらえるか」は付き合いの長さで決まる |
| **産地の職人・産元とのつながり** | **強** | 尾州（毛織物）・播州（先染織物）・泉州（タオル）等、産地ごとの人脈は買えない |
| **素材メーカーの独占販売権** | **強** | 特定の機能繊維を扱えるのは限られた商社だけ、という構図がある |
| **与信情報の蓄積** | 中〜強 | どのアパレルが危ないかは、長く商売した会社ほど見える |
| 人材 | 中 | 生地を見て産地と工程を言い当てられる人は育成に10年単位かかる |

> 参入は簡単だが、**生き残るのは難しい**業界。だから会社数は多く、規模の大きい会社は少ない、という分布になる。

## 7. 規制・法制度

繊維商社を直接縛る業法はない。代わりに **「表示」「取引」「人権・環境」の3方向の規制**を受ける。

| 分野 | 主な制度 | 実務上の意味 |
| --- | --- | --- |
| **品質表示** | 家庭用品品質表示法（繊維製品品質表示規程）。組成・洗濯表示（JIS L 0001） | 表示を間違えると回収。**生地の組成を工場申告に頼れない**ので試験に出す |
| **有害物質** | 有害物質を含有する家庭用品の規制に関する法律（ホルムアルデヒド等）。乳幼児用品は特に厳格 | 染色加工の管理が輸入時の関門になる |
| **安全** | 消費生活用製品安全法、子ども服のひも（JIS L 4129） | 紐の長さ規格などデザインに直接効く |
| **関税・原産地** | 関税定率法、各EPA/FTAの原産地規則。**「糸から（yarn forward）」など、どの工程からその国で作れば特恵が使えるかの規則** | どこで糸を買うかが関税を左右する。商社の重要ノウハウ |
| **特恵関税** | 日本のGSP（一般特恵関税）・特別特恵（LDC向け）。**バングラデシュは2026年11月にLDC卒業予定** | 関税ゼロが終われば調達コストが変わる → [③ 直近トピック](03_直近トピック_2026.md) |
| **下請法・独占禁止法** | 下請代金支払遅延等防止法。2024年以降、価格転嫁と支払条件の指導が強化 | 商社は「発注する側」として規制対象になる |
| **強制労働・人権** | 米 UFLPA（ウイグル強制労働防止法、2022年施行）、EU 強制労働製品禁止規則（2027年12月適用開始予定）、日本政府「責任あるサプライチェーン等における人権尊重のためのガイドライン」（2022年） | 綿花は米国側で優先セクターに指定。**原料まで遡った供給網の可視化**が輸出の前提になる |
| **環境・循環** | 経産省「繊維・アパレル産業における環境配慮情報開示ガイドライン」（2024年6月）、繊維to繊維リサイクルのJIS化・ISO化の検討 | 素材の由来を証明できるかが取引条件になりつつある |

※ 人権・地政学に関わる論点は、**事実（どの制度が、いつから、何を求めるか）と、企業の対応**に絞って整理する。詳細は [②](02_市場の変化と生き残り.md) 第7章。

## 8. 最近のトピック

詳細と出典は [③ 直近トピック（2026年9月時点）](03_直近トピック_2026.md)。要点は次の5つ。

- **帝人フロンティアと旭化成アドバンスが2026年10月1日に統合し「TAフロンティア」が発足**。帝人80%・旭化成20%出資、単純合算売上高 約2,795億円で**繊維商社として最大規模**。2030年ごろに5,000億円を目指すと発表された
- **2026年の決算は明暗が分かれた**。豊島は2026年6月期に売上2,558億円（+18.3%）・経常利益169億円で4期連続の最高益。一方、蝶理は2026年3月期に売上2,992億円（▲3.9%）・営業利益130.6億円（▲9.9%）と減収減益（純利益は+3.0%）
- **バングラデシュが2026年11月24日にLDC（後発開発途上国）を卒業する見込み**。特恵関税の適用が段階的に終わり、**調達コストと生産地の選び直し**が課題に。日本・バングラデシュEPAの交渉が代替措置として注目される
- **人権デューデリジェンスが「輸出の前提条件」へ**。米UFLPAは綿花・綿製品を優先セクターに位置づけ、EUの強制労働製品禁止規則は2027年12月から適用予定。**原料まで遡ったサプライチェーンの可視化**が求められる
- **サステナビリティの制度化が進む**。経産省の環境配慮情報開示ガイドライン（2024年6月）、リサイクル繊維の判別・表示のJIS化とISO化の動き。**「リサイクル素材だと証明できること」自体が商品価値**になってきた
