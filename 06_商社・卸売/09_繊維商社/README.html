このフォルダの読み方

繊維商社は 「服をつくりたい会社（アパレル企業）の代わりに、糸から生地、染色、縫製までバラバラの工場を束ねて、製品にして納める会社」。
服づくりは工程ごとに会社が違い、しかもその工場が何カ国にも散らばっている。その全部をつなぐ人がいないと1枚の服にならない——この「つなぐ」機能を売っているのが繊維商社である。

もうひとつの顔が 日本の商社そのものの源流 であること。伊藤忠商事も丸紅も双日も、もとは綿花・綿布を扱う繊維商だった（→ 総合商社）。
いまはアパレル市場の縮小と、SPA（製造小売）が工場と直接取引する流れに挟まれ、機能素材・産業資材・海外市場へ軸足を移している最中にある。

ノート 内容
① アパレル生産の裏方OEM/ODMとは何か、糸→生地→縫製の多段階サプライチェーン、なぜアパレル企業は自分でやらないのか（与信・ロット・為替）、企画提案と生地の目利き、生産地の変遷（日本→中国→ASEAN→バングラデシュ）、短納期と期中追加、在庫リスクと口銭の水準
② 市場の変化と生き残り市場縮小と低価格化、SPAの直接調達による「中抜き」リスク、機能素材・産業資材（自動車内装／医療／インフラ）へのシフト、川下のブランド投資、サステナビリティとトレーサビリティ、人権デューデリジェンス、大手各社の戦い方と業界再編
③ 直近トピック（2026年9月時点）帝人フロンティア×旭化成アドバンスの統合（TAフロンティア、2026年10月発足）、2026年決算の明暗、バングラデシュのLDC卒業と特恵関税、EU強制労働製品禁止規則、繊維to繊維リサイクルの制度整備

1. 業界の定義・範囲

繊維商社 ＝ 繊維原料・糸・生地（テキスタイル）・衣料品などを売買し、あわせて 生産の手配そのものを請け負う専門商社。
単に右から左に流すのではなく、「モノを作らせる」ところまで踏み込むのが特徴で、この点が他の専門商社（鉄鋼商社・化学商社など）と大きく違う。

境界を整理すると次のようになる。

【繊維に関わる会社の役割の違い】

  ┌──────────┬──────────────────────────┐
  │ 素材メーカー     │ 糸・原綿・機能繊維を「作る」                 │
  │ （東レ・帝人ほか）│ 工場と研究所を持つ。→ 10_素材・化学/08_繊維 │
  ├──────────┼──────────────────────────┤
  │ ★繊維商社★      │ 作らない。ただし「作らせる」                 │
  │                  │ 生地の目利き・企画提案・工場手配・与信・在庫  │
  ├──────────┼──────────────────────────┤
  │ OEM専業メーカー  │ 自社工場を持ち、受託生産する                 │
  │                  │ 商社と似た仕事をするが、設備リスクを負う      │
  ├──────────┼──────────────────────────┤
  │ アパレル企業/SPA │ 企画・ブランド・販売。→ 07_小売・流通/10    │
  └──────────┴──────────────────────────┘
  • 卸売業との違い ＝ 既製品を仕入れて売るのが卸。繊維商社は 企画段階から入り、生産を組み立てる
  • OEM専業メーカーとの違い ＝ メーカーは自社工場という固定費を持つ。商社は 工場を選び直せる身軽さが武器
  • 総合商社の繊維部門との違い ＝ 実は機能はほぼ同じ。違いは 資金力と、川下ブランドへの出資規模

本ノートでは、独立系・素材メーカー系の繊維専門商社を主役に置き、総合商社の一般論（事業投資で稼ぐ二層構造など）は 総合商社 に委ねる。

歴史は簡潔に：「五綿八社」

戦前から戦後にかけて、日本の貿易の主役は綿花の輸入と綿布の輸出だった。
その担い手が 「五綿（ごめん）」＝ 東洋棉花・日本綿花・江商・伊藤忠商事・丸紅 と、これに岩井産業・安宅産業・蝶理を加えた 「五綿八社」 である。

5. 収益モデル・コスト構造

繊維商社の利益 ＝ ① 口銭（仲介手数料）
                ＋ ② OEM/ODMの製品売買マージン（企画込みの値差）
                ＋ ③ 素材・ブランドの独占販売権から来る利益
                ＋ ④ 事業投資（ブランド・工場・小売）の持分利益
                －   販管費（人件費・海外拠点費）
                －   在庫評価損（売れ残った生地・製品）
                －   貸倒損失（アパレル企業の倒産）
                ±   為替（ドル建て仕入れ × 円建て販売）
論点 中身
利益率は薄い売上高営業利益率は おおむね2〜5%。上の企業一覧でも、売上2,000〜3,000億円クラスで営業利益100〜170億円の水準
薄い理由取引先（アパレル）の数が多く、1件あたりの金額が小さい。かつ 同じ工場を複数の商社が使えるので値段で比べられる
在庫が命取り服はシーズンを越えると値段が付かない。繊維商社は生地在庫・製品在庫を自分の名義で抱えることが多く、売れ残りが直接損失になる
与信リスク顧客のアパレル企業は中小が多く、倒産が珍しくない。代金回収まで含めて商社の仕事。逆に言えば与信を引き受けているから口銭が取れる
為替仕入れは主にドル建て、販売は円建て。円安は仕入れコスト増。ただし輸出取引や海外子会社の利益は円安で増える（会社ごとに向きが違う）
固定費は軽い工場を持たないので設備負担がない。主なコストは人件費と海外拠点の維持費。ただし帝人フロンティアのように工場を持つ例外もある
口銭の水準単純仲介で 数%、企画から入るODMではより厚く取れる。「どこまで面倒を引き受けたか」で取り分が決まる

6. 競争要因（KSF）と参入障壁

KSF（成功の鍵）

  1. 生地の目利きと企画提案力。「この生地でこういう服が作れます」と先に持ち込めるか。発注を待つ側か、発注を作る側かの差
  2. 工場ネットワークの厚み。国・地域・工程ごとに代替先を持っていること。1カ所が止まっても回せるか
  3. 納期を守り切る力。アパレルは発売日が決まっている。遅れは即失注。短納期・期中追加に応えられるか
  4. 与信の見極め。誰に売って、いくらまで掛けで出すか。1件の貸倒れが1年の利益を吹き飛ばす
  5. 在庫の切り方。持つ勇気と、損切りの規律の両方が要る
  6. 非衣料の柱を持っているか。アパレル市況に左右されない収益源（産業資材・寝装・資材）があるか
  7. サステナビリティと人権対応の体制。取引の前提条件になりつつある（→ 第7章）

参入障壁

障壁 強さ 理由
資本・設備弱工場が要らない。小さな繊維商社は今も多数ある
商流そのもの弱貿易実務は学べる。ネットで工場も探せる時代
工場との長年の関係強「忙しい時期に枠を確保してもらえるか」は付き合いの長さで決まる
産地の職人・産元とのつながり強尾州（毛織物）・播州（先染織物）・泉州（タオル）等、産地ごとの人脈は買えない
素材メーカーの独占販売権強特定の機能繊維を扱えるのは限られた商社だけ、という構図がある
与信情報の蓄積中〜強どのアパレルが危ないかは、長く商売した会社ほど見える
人材中生地を見て産地と工程を言い当てられる人は育成に10年単位かかる

参入は簡単だが、生き残るのは難しい業界。だから会社数は多く、規模の大きい会社は少ない、という分布になる。

7. 規制・法制度

繊維商社を直接縛る業法はない。代わりに 「表示」「取引」「人権・環境」の3方向の規制を受ける。

分野 主な制度 実務上の意味
品質表示家庭用品品質表示法（繊維製品品質表示規程）。組成・洗濯表示（JIS L 0001）表示を間違えると回収。生地の組成を工場申告に頼れないので試験に出す
有害物質有害物質を含有する家庭用品の規制に関する法律（ホルムアルデヒド等）。乳幼児用品は特に厳格染色加工の管理が輸入時の関門になる
安全消費生活用製品安全法、子ども服のひも（JIS L 4129）紐の長さ規格などデザインに直接効く
関税・原産地関税定率法、各EPA/FTAの原産地規則。「糸から（yarn forward）」など、どの工程からその国で作れば特恵が使えるかの規則どこで糸を買うかが関税を左右する。商社の重要ノウハウ
特恵関税日本のGSP（一般特恵関税）・特別特恵（LDC向け）。バングラデシュは2026年11月にLDC卒業予定関税ゼロが終われば調達コストが変わる → ③ 直近トピック
下請法・独占禁止法下請代金支払遅延等防止法。2024年以降、価格転嫁と支払条件の指導が強化商社は「発注する側」として規制対象になる
強制労働・人権米 UFLPA（ウイグル強制労働防止法、2022年施行）、EU 強制労働製品禁止規則（2027年12月適用開始予定）、日本政府「責任あるサプライチェーン等における人権尊重のためのガイドライン」（2022年）綿花は米国側で優先セクターに指定。原料まで遡った供給網の可視化が輸出の前提になる
環境・循環経産省「繊維・アパレル産業における環境配慮情報開示ガイドライン」（2024年6月）、繊維to繊維リサイクルのJIS化・ISO化の検討素材の由来を証明できるかが取引条件になりつつある

※ 人権・地政学に関わる論点は、事実（どの制度が、いつから、何を求めるか）と、企業の対応に絞って整理する。詳細は ② 第7章。
