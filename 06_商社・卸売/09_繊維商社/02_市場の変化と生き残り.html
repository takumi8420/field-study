このノートで分かること：繊維商社が なぜ「中抜きされる」と言われるのか、そしてそれに対して各社がどこへ逃げ、何を武器にしようとしているのか。

結論から言うと、繊維商社は2つの圧力に同時に挟まれている。
(a) 顧客であるアパレル市場そのものが縮み、単価が下がったこと。(b) 最大顧客であるSPA（製造小売）が、工場と直接取引できるようになったこと。
その答えとして各社が出しているのが、川上（機能素材・産業資材）・川下（ブランドと小売への出資）・海外という3方向への移動である。

1. 圧力その1：市場が縮み、単価が下がった

国内アパレル市場は、金額が減りながら数量が増えるという珍しい縮み方をした。

指標 数値 時点・出典
国内アパレル総小売市場規模約8兆5,010億円（前年比 +1.7%）2024年、矢野経済研究所の推計
ピーク時からの変化約 15兆円（バブル期）→ 8〜10兆円台へ経済産業省 資料
国内供給量約 20億点 → 約 40億点 へ倍増同上
輸入浸透率（数量ベース）98.5%2022年、経済産業省 資料
今後の見通し2030年ごろまでは2024年比で微増水準で推移する見込み矢野経済研究所の予測
【商社から見た「縮み方」の意味】

  市場金額   15兆円 ──────────────▶ 8〜10兆円   （▲約4割）
  供給点数   20億点 ──────────────▶ 約40億点   （＋約2倍）
                        ↓
  1点あたりの平均単価が おおむね半分以下 に
                        ↓
  ┌──────────────────────────────┐
  │ 商社にとって：                                     │
  │  ・同じ売上を作るのに扱う枚数が倍になった          │
  │  ・1件あたりの手間は減らないのに、口銭の額は減った │
  │  ・＝ 人件費との勝負になり、薄利多売では持たない   │
  └──────────────────────────────┘

直近は数量よりも単価が支えている点にも注意が要る。
矢野経済研究所は、少子高齢化で販売数量は減るが、原材料費・物流費・人件費の上昇で商品単価が上がるため、市場の減少幅は抑えられると見ている（2025年の調査）。
つまり 「枚数は減り、値段は上がる」局面に入りつつある。これは低価格大量生産に最適化した商社にとって、前提の変更になる。

2. 圧力その2：SPAの直接調達と「中抜き」

SPA（製造小売） ＝ 企画から生産、販売までを自社で行う小売業。ユニクロ、GU、ZARA、H&M などが代表。
SPAが伸びたことは、繊維商社にとって 顧客が育って独立していくことを意味した。

【取引の形が3段階で変わってきた】

 ① 従来型（〜1990年代）
    素材メーカー ─▶ 商社 ─▶ アパレル ─▶ 百貨店/専門店 ─▶ 消費者
                      ↑ ここで口銭

 ② OEM/ODM型（2000年代〜）
    工場 ◀── 商社 ──▶ アパレル/SPA ─▶ 自社店舗 ─▶ 消費者
            （生産全体を受託。商社の付加価値は上がった）

 ③ 直接調達型（2010年代〜）
    工場 ◀─────────▶ SPA ─▶ 自社店舗/EC ─▶ 消費者
                  ↑
         商社を通さない。SPAが現地に生産管理拠点を持つ
         ＝「中抜き（ディスインターミディエーション）」

    ※ただし①②③は併存している。全部が③になるわけではない

SPAが直接調達に踏み切れる条件は次のとおり。裏返せば、この条件を満たさない顧客には商社が必要であり続ける。

SPAが自前でできる条件 商社が残る理由（条件を満たさない顧客）
1品番あたりの数量が大きく、工場のMOQを自力で満たせる中小アパレル・D2Cブランドは数百枚単位。ロットを満たせない
現地に生産管理の駐在員を置ける拠点維持は年間コストが大きい。数十社ぶんをまとめる商社のほうが安い
定番品中心で、企画変更が少ないトレンド品・多品種少量は工場選定が毎回変わる
自社で与信・資金繰りを回せる支払サイトを延ばしたい会社は商社の資金機能が要る
品質管理・人権監査の体制を自前で持てる監査体制の構築は中小には重い（→ 第7章）

ポイント：中抜きは「全面的に起きる」のではなく、取引の大きい定番品から順に起きる。
つまり商社に残るのは、手間がかかり数量が小さい仕事——すなわち利益率を上げないと割に合わない仕事のほうである。
だからこそ「ODM化」「非衣料」「海外」という打ち手が同時に語られる。

3. 打ち手A：川上へ——機能素材と産業資材（非衣料）

最も明確な打ち手が 「服以外の繊維」へ移ること。繊維は服だけの素材ではない。

用途分野 使われ方の例 なぜ商社に向くか
自動車内装シート表皮、天井材、カーペット、エアバッグ用基布車1台の採用が決まれば数年続く。トレンドで切られない
医療・衛生手術用ガウン、マスク、不織布、人工血管・縫合糸の素材認証が厳しく参入障壁が高い。単価も高い
インフラ・土木ジオテキスタイル（地盤補強シート）、コンクリート補強材、防水シート公共投資と紐づき、景気変動に強い
産業用フィルター（空気・液体）、ベルト、ホース補強、電池材料素材メーカーとの共同開発型。ODMの延長で入れる
スポーツ・アウトドア高機能素材、撥水・透湿、軽量中綿衣料だが単価が高く、素材の差が売価に反映される
寝装・インテリア寝具、カーテン、カーペット住宅市場と連動。衣料とは景気の波が違う
【衣料と非衣料：ビジネスの性質がまったく違う】

              衣料（アパレル）            非衣料（産業資材）
  ────────────────────────────────
  発注の単位   シーズンごと（年2〜4回）   数年単位の採用（車種ライフ等）
  切り替え     トレンドで毎回変わる       一度決まると容易に変わらない
  必要なもの   企画提案・スピード         試験データ・認証・共同開発
  価格決定     コスト競争に晒されやすい   性能で決まる。値崩れしにくい
  リスク       在庫・売れ残り             開発期間が長い・採用まで数年
  ────────────────────────────────
  ＝ 非衣料は「儲けが安定するが、入るのに時間がかかる」
  • 帝人フロンティアと旭化成アドバンスの統合（2026年10月、新社名 TAフロンティア）は、まさに 衣料と産業資材の両方を1社に束ねる狙いだと説明されている。旭化成アドバンスはナイロンのエアバッグ用テキスタイルを持ち、帝人フロンティアはポリエステル工場を中国・タイに持つ → ③ 直近トピック
  • ただし非衣料は 素材メーカーの土俵でもある。素材メーカー系商社（帝人フロンティア、旭化成アドバンス、東レ系の蝶理など）が有利で、独立系にとっては簡単な道ではない
  • 川上の素材そのものについては 繊維（素材） を参照

4. 打ち手B：川下へ——ブランド・小売への出資

もうひとつの方向が、下流に出資して利益を取り込むこと。これは 総合商社 が資源・インフラでやってきたことの繊維版である。

  • ブランドの権利（ライセンス）を持つ：海外ブランドの日本での商標権・販売権を押さえ、自社で企画生産して卸す。口銭ではなくブランドの利益が取れる
  • アパレル企業や小売に出資する：持分法や連結で利益を取り込む。伊藤忠商事の繊維カンパニーはこの型が最も厚く、2027年3月期の純利益 520億円 を計画し、2026年度はスポーツ・シューズ領域のM&Aを強化する方針と報じられている
  • 自社ブランド・D2Cを持つ：豊島などはサステナ素材を軸にした自社発の取り組みを展開している
【商社の収益の「層」の作り方】

  ┌── 第3層：ブランド／事業投資 ──────────┐ 利益率：高
  │ ブランド権利・出資先の利益・小売のマージン       │ リスク：高（減損）
  ├── 第2層：ODM（企画から受託） ───────────┤ 利益率：中〜高
  │ 素材の仕込み・企画提案・生産管理の対価           │ リスク：在庫・先行投資
  ├── 第1層：OEM／トレーディング ───────────┤ 利益率：低
  │ 仕様どおりの生産代行・単純仲介                   │ リスク：与信・在庫
  └────────────────────────────┘

  各社の戦略＝「第1層の比率をどこまで減らし、第2・第3層を積めるか」
  ＝ 総合商社の「商流と投資の二層構造」と同じ発想。規模が2桁小さいだけ
  • ただし 失敗すれば減損になるのも同じ。アパレルブランドは流行り廃りが速く、のれんが一気に毀損しうる
  • 繊維商社の規模（売上2,000〜3,000億円、営業利益100〜170億円クラス）では、総合商社ほど大きな失敗は吸収できない。この体力差が「総合商社の繊維部門」と「独立系専門商社」の戦い方の違いを生む

5. 打ち手C：海外へ——「世界で作り、世界で売る」

国内市場が縮む以上、作る場所だけでなく売る場所も海外に広げるのが自然な答えになる。

  • スタイレム瀧定大阪は「世界で作り、世界で売る」を掲げ、多拠点を生かした海外の生地販売を伸ばしている（2025年、繊研新聞）
  • 蝶理は繊維のうちテキスタイル（生地）の輸出が収益の柱のひとつで、2025年3月期には繊維事業の売上が前期比4.7%増の1,527億円まで伸びた（決算短信）
  • 国内アパレル向けのOEMは円建て・国内需要に縛られるが、海外バイヤーへの生地輸出は日本製生地の品質という明確な差別化要素がある
海外展開の型 中身 難しさ
生地輸出日本産地の生地を欧米・アジアのブランドへ直接売る産地の生産能力が限られる。職人の高齢化
三国間貿易日本を経由せず、海外で作って海外へ売る現地商社・現地企業と直接競合する
海外拠点でのOEM現地ブランド向けに現地で生産管理する日本流のきめ細かさが価格に転嫁できるか
海外ブランドの日本展開ライセンスを取って国内で売る契約更新のたびに条件が変わる

6. サステナビリティ：リサイクル素材とトレーサビリティ

繊維は 環境負荷が大きい産業として名指しされる側にある。これが商社の実務に直接効くようになった。

論点 制度・動き 時点
環境配慮情報の開示経済産業省「繊維・アパレル産業における環境配慮情報開示ガイドライン」策定2024年6月
環境配慮設計ガイドラインを発展させ、JIS策定・ISO策定を予定2026〜2028年
リサイクル繊維の表示日本化学繊維協会がリサイクル繊維の適合基準・検証方式・統一表示のJIS原案を取りまとめ、ISO国際規格化を目指す2023年度〜
リサイクル品の判別ニッセンケン品質評価センターがリサイクルポリエステル繊維の判別試験を開始2026年（報道ベース）
素材側のトレーサビリティ東レがリサイクルポリエステル「&+（アンドプラス）」にマーカー（添加剤）を入れて追跡可能に報道ベース
繊維to繊維リサイクル廃棄衣料の削減に向けた資源循環構築の検討が官民で進行2026年1月、環境省の資料
【なぜ「トレーサビリティ」が商社の仕事になるのか】

  ブランド「このシャツはリサイクルポリエステル50%と表示したい」
      ↓ 証明を求められる
  商社「では、そのペットボトル／古着はどこから来たか？」
      ↓ 工程を遡る
   回収業者 → 再生チップ工場 → 紡績 → 機屋 → 染工場 → 縫製
      ↑ ここまで全部の証跡（伝票・認証・第三者検査）を揃える必要がある

  ┌────────────────────────────────┐
  │ 工程が多い＝遡る手間も多い                          │
  │ ＝「多工程を束ねる」商社の本業がそのまま強みになる  │
  │ ＝ サステナ対応は商社にとってコストであり、同時に   │
  │    新しい存在理由でもある                            │
  └────────────────────────────────┘
  • 「リサイクル素材だと証明できること」そのものが商品価値になった。混ぜてしまえば見分けがつかない素材だからこそ、証跡の管理が差別化になる
  • 豊島はオーガニックコットン等のサステナ素材に早くから取り組み、帝人フロンティアはリサイクルポリエステル「エコペット」を30年近く手がけてきた。先行投資が制度化で回収される局面に入りつつある
  • 関連テーマは 脱炭素・GX、出口側は リユース・中古

7. 人権デューデリジェンス：制度と事実

繊維・アパレルは サプライチェーンが長く、労働集約的であるため、強制労働や労働環境に関する規制の対象として各国で優先的に扱われている。
ここでは どの制度が、いつから、何を求めるかという事実関係に絞って整理する。

制度 主体 内容 時期
UFLPA（ウイグル強制労働防止法）米国中国・新疆ウイグル自治区で全部または一部が生産された物品は、強制労働によるものと推定し、輸入を原則禁止。企業側が反証する必要がある（反証可能な推定）2022年6月施行
同・優先セクター米国綿花および綿製品が高優先セクターとして明示（2024年7月公表の戦略）2024年
EU 強制労働製品禁止規則（FLR）EU強制労働により生産された製品のEU市場への投入・域外輸出を禁止。企業の規模・業種・所在地を問わない2027年12月以降 適用
CSDDD（企業サステナビリティ・デューデリジェンス指令）EU大企業に対しサプライチェーン上の人権・環境デューデリジェンスを義務づけ段階適用
責任あるサプライチェーン等における人権尊重のためのガイドライン日本政府国連指導原則に沿った人権デューデリジェンスの実施を企業に促す（法的義務ではない）2022年9月策定
技能実習／育成就労日本国内縫製業の労働環境は国際的に注視されてきた分野。制度は育成就労へ移行が進む2024年法改正
【実務として何をするのか：サプライチェーンの可視化】

  従来： ブランド ─▶ 商社 ─▶ 「Tier1（縫製工場）」まで把握
                                    ↑ ここまでで十分だった

  現在： ブランド ─▶ 商社 ─▶ Tier1 縫製工場
                              └▶ Tier2 染色・生地
                                   └▶ Tier3 紡績
                                        └▶ Tier4 原料（綿花の産地）
                                             ↑ ★ここまで遡って示す★

  ・米国向け輸出では、原料まで遡った供給網の可視化が実務上の起点になる
  ・工程が多く多国籍にまたがるほど、可視化のコストは指数的に増える
  ・中小アパレルが単独でこれを行うのは難しい
     → 体制を持つ商社に発注を集約する動きにもつながる

事実として押さえるべきなのは、この対応が「できるか/できないか」が取引条件になったという点。
企業にとっては負担であると同時に、体制を先に整えた側には参入障壁として働く。
個別の地域や企業をめぐる評価は立場により大きく分かれるため、本ノートでは制度と実務の記述にとどめる。

8. 業界再編：数が多すぎる業界が縮んでいく

繊維商社は 参入障壁が低く会社数が多いまま市場が縮んだため、統合と撤退が続いている。

動き 内容 時期
帝人フロンティア × 旭化成アドバンス吸収合併により TAフロンティア が発足。帝人80%・旭化成20%出資。単純合算 約2,795億円で繊維商社として最大規模。2030年ごろに5,000億円を目標2026年10月1日予定
蝶理による住友商事系繊維商社の買収総合商社が繊維子会社を手放し、専門商社が受け皿になる構図過年度
トーメン→豊田通商、ニチメン＋日商岩井→双日五綿八社の統合。繊維単独では規模を維持できなかった2000年代
中小の廃業・事業承継アパレル・繊維製造分野でM&Aと事業承継が継続継続中
【再編の力学】

  市場が縮む ──▶ 1社あたりの取扱量が減る ──▶ 固定費（人件費・拠点）が重くなる
                                                   │
        ┌──────────────────────────┘
        ▼
  選択肢は3つ
   ① 統合して規模を取る       … 帝人フロンティア＋旭化成アドバンス
   ② 領域を絞って高付加価値化 … 生地特化、産業資材特化、ニッチ素材
   ③ 別事業の柱を持つ         … 蝶理（化学品・機械）、モリリン（寝装）

   ＊「①も②も③もやらない中堅」が最も苦しい、というのが業界の共通認識

10. まとめ：この業界の「次の10年」の論点

  1. 中抜きは全面的には起きないが、大口・定番から順に減る。残るのは手間のかかる仕事なので、ODM化しないと採算が合わない
  2. 非衣料（産業資材）が安定収益の柱になりうるが、入るのに数年かかり、素材メーカー系が有利
  3. サステナビリティと人権対応は「コスト」であると同時に「参入障壁」。証明できる体制を持つ会社に発注が集まる
  4. 生産地の選び直しが続く。バングラデシュのLDC卒業（2026年11月予定）など、関税前提の変化が随時起きる
  5. 国内産地の維持が長期の論点。生地を作れる工場が消えると、「日本製生地」という差別化要素そのものが失われる
  6. 統合は続く。市場が縮む中で会社数が多すぎる状態は解消されていない
