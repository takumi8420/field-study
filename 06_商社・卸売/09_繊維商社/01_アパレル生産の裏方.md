# ① アパレル生産の裏方

このノートで分かること：**店に並ぶ服が、誰の手を何回通って作られているのか**。そして、その工程をつなぐ繊維商社が具体的に何をして、何でお金を取っているのか。

結論を先に言うと、繊維商社の本業は **OEM/ODM**——「ブランドに代わって生産全体を引き受ける仕事」である。
服づくりは **糸 → 生地 → 染め → 縫製** と工程が分かれ、しかも工程ごとに別会社・別の国にある。これを1本につないで「◯月◯日に◯万枚」を成立させることに、相応の値段が付く。

## 1. OEMとODMの違い

まず言葉を押さえる。ここを曖昧にしたままだと業界の話がまったく読めない。

| 用語 | 正式名 | 何をするか | ブランド側の負担 | 商社の取り分 |
| --- | --- | --- | --- | --- |
| **OEM** | Original Equipment Manufacturing | ブランドが決めた**仕様どおり**に作って納める。「この型紙・この生地で1万枚」 | 企画・デザインは自分でやる | 薄い |
| **ODM** | Original Design Manufacturing | **企画・デザインから商社側が提案**して作る。「来春はこの素材でこの形が売れます」 | ブランド名を載せるだけでもよい | 厚い |
| （参考）**SPA** | Speciality store retailer of Private label Apparel | **製造小売**。企画・生産・販売を自社で全部やる小売業。ユニクロ、ZARA、GU など | ― | **商社を通さないこともできる** |

- **OEMは「作業の代行」、ODMは「頭脳の代行」**。だから利益率が違う
- 繊維商社が「企画提案力を強化する」と言うとき、それは **OEMからODMへ重心を移したい**という意味
- 逆に言うと、**OEMだけの会社は価格競争に巻き込まれる**。「同じ工場に同じ仕様で発注するなら、安いほうに頼む」で終わってしまうため

> ポイント：この業界で「付加価値を上げる」＝**発注を待つ立場から、発注を作り出す立場へ移ること**。
> 生地とトレンドを先に握っていれば、ブランドの企画会議に呼ばれる側になれる。

## 2. 糸から服になるまで：多段階サプライチェーン

繊維が他産業と決定的に違うのは、**工程数の多さ**と **工程ごとに会社も国も違う**という点。

```
【1枚のシャツができるまで：工程・担い手・場所】

 工程    ①原料    ②紡績    ③製織/編立  ④染色加工   ⑤裁断縫製   ⑥検品   ⑦輸送
        ────────────────────────────────────────
 中身   綿花/     糸に     生地に      色・風合い   製品に      品質    海上
        ポリマー   する     する        機能付与     する        確認    輸送
        ────────────────────────────────────────
 担い手 生産者/   紡績     機屋        染工場       縫製工場    検品     フォワー
        素材メーカー 会社    (はたや)                            会社     ダー
        ────────────────────────────────────────
 場所   米/豪/印  中国/印/ 中国/日本/  中国/日本/   中国/ASEAN/ 現地     ―
              越   ベトナム    ASEAN       バングラ

        ────────────────────────────────────────
 リード  ──────── ここまでで 3〜6か月かかるのが普通 ────────
 タイム
```

ここで効いてくるのが次の3つ。

1. **工程が分かれている＝どこかが遅れると全部が遅れる**。生地の染め上がりが2週間遅れれば、縫製の枠が埋まって納期が飛ぶ
2. **通貨も商習慣も違う**。糸はドル建て、縫製工賃は現地通貨、販売は円。誰かが為替を引き受けないと成立しない
3. **前工程ほどロットが大きい**。糸は数トン単位、生地は数千メートル単位でしか買えないのに、ブランドが欲しいのは数百枚ということがある

```
【ロットの段差：これが商社の存在理由になっている】

  糸（紡績）        ████████████████████  最低 数トン〜
  生地（機屋）      ██████████            最低 数千m〜（色ごと）
  縫製             ████                  最低 数百〜千枚（型ごと）
  ブランドの欲しい量 ██                    300枚だけ、など

        ↓ 段差をどう埋めるか
  ★商社が「複数ブランドの発注をまとめて」前工程のロットを満たす★
  ★または生地を先に買って在庫で持ち、小口で切り出す（＝在庫リスクを取る）★
```

この「**ロットの段差を吸収する**」機能が、アパレル企業が自前でやりにくい最大の理由である。

## 3. なぜブランドは自分でやらないのか

「工場に直接頼めばいいのでは」という疑問に、実務上の答えは5つある。

| ブランドが自前でやると起きること | 商社が引き受けている機能 |
| --- | --- |
| 工場が前払いや信用状（L/C）を要求し、**運転資金が先に出ていく** | **与信・資金の立て替え**（決済条件の橋渡し） |
| 欲しい枚数が少なく、**前工程のロットを満たせない** | **複数顧客の集約／生地在庫の保有** |
| 工場を探す・品質を確かめる・不良品を交渉する**手間** | **工場の選定・監査・品質トラブルの処理** |
| 為替が動いて**原価が確定しない** | **為替予約・円建て提示** |
| 期中に売れ行きが変わっても**追加生産できない** | **短納期の再手配（QR）・在庫からの供給** |

裏返すと、**このうちいくつかを自分でできるようになった会社は、商社を外す**。
売上規模が大きく、定番品を大量に売るSPAはまさにそれに当たる → [② 市場の変化と生き残り](02_市場の変化と生き残り.md)。

> ポイント：繊維商社が売っているのは布ではなく **「リスクと手間の肩代わり」**。
> 顧客が大きくなるほど肩代わりの必要が減る、という構造的な難しさを抱えている。

## 4. 企画提案力と「生地の目利き」

繊維商社の人が最も時間を使うのは、実は **生地を見て触ること**である。

- **生地（テキスタイル）** ＝ 糸を織る・編むして作られた布。同じ「綿100%」でも、糸の太さ、撚り、織り方、加工で**まったく別物**になる
- 目利きの中身は「この風合いは、どの産地のどの工程で、いくらで、何メートルから作れるか」を**手触りから逆算できる**こと
- スタイレム瀧定大阪のような生地系の商社は、自社で数万点規模の生地アーカイブを持ち、そこから提案する

```
【ODM提案の流れ（春夏物の場合、ざっくり18か月前から）】

 [T-18か月] 糸・原料の展示会、世界の素材見本市で素材を仕込む
      │        （プルミエール・ヴィジオンなど。商社はここに「買いに」行く）
      ▼
 [T-12か月] 自社の生地見本帳・企画サンプルを作る
      │        ★ここで自腹を切る。売れなければ丸損＝商社の先行投資★
      ▼
 [T-9か月]  ブランドの企画会議に提案。採用が決まる
      │
      ▼
 [T-6か月]  サンプル（試作）→ 修正 → 最終仕様の確定
      │
      ▼
 [T-4か月]  本生産の発注。生地を押さえ、縫製工場の枠を取る
      │
      ▼
 [T-1か月]  検品・出荷・通関
      ▼
 [発売]     店頭・EC。売れれば期中追加（QR）の打診が来る
```

この図の「★」が重要で、**商社は売れる保証がない段階でサンプル代と生地代を先に払っている**。
提案が通らなければ回収できない。ODMの利益率が高いのは、この先行投資の見返りでもある。

## 5. 生産地の変遷：日本 → 中国 → ASEAN → バングラデシュ

縫製は**人手がかかる仕事**なので、賃金の安い場所へ移動し続けてきた。これは繊維産業に共通する現象である。

| 時期 | 主な縫製地 | 移った理由 |
| --- | --- | --- |
| 〜1980年代 | **日本国内**（産地に縫製工場が集積） | 国内需要中心。円安で輸出も強かった |
| 1990年代〜2000年代 | **中国**（華東・華南） | プラザ合意後の円高と国内の人手不足。中国の改革開放 |
| 2010年代 | **ASEAN**（ベトナム・ミャンマー・カンボジア・インドネシア） | 中国の賃金上昇。「チャイナ・プラスワン」（中国一極集中を避ける考え方） |
| 2020年代 | **バングラデシュ・インド**ほかへ分散 | さらなるコスト差と、地政学リスクの分散。EU・米国向けの関税メリット |

```
【縫製の主力が移動してきた道筋】

  日本 ──▶ 中国 ──┬──▶ ベトナム ──▶ ｜
  (〜80s)  (90s〜)  │     (2010s)      ｜ バングラデシュ / インド
                    ├──▶ ミャンマー ─▶ ｜  (2020s)
                    ├──▶ カンボジア    ｜
                    └──▶ インドネシア  ｜
                                          ↓
   ＊移動の駆動力：① 賃金差  ② 関税・特恵  ③ 政治リスク分散
   ＊移動のブレーキ：① 技術の蓄積  ② 生地の調達距離  ③ リードタイム
```

移動は一方通行ではなく、**ブレーキも強い**。

- **技術が要る品目は動かない**。スーツ、ダウン、ブラジャーなど縫製難度の高いものは中国や日本に残る
- **生地が近くにないと成り立たない**。バングラデシュは縫製は強いが、生地（特に化合繊）の多くを輸入に頼る。生地を運ぶ日数が増えればリードタイムが伸びる
- **リードタイムとコストのトレードオフ**。遠くで安く作ると、売れ行きに合わせた追加生産ができない
- 2026年11月にバングラデシュが **LDC（後発開発途上国）を卒業する見込み**で、特恵関税の前提が変わる → [③ 直近トピック](03_直近トピック_2026.md)

> 商社の価値はここにもある。**どこで何を作ると、関税・納期・品質・コストの合計が最小になるか**を国をまたいで設計できること。
> この設計を「生産地ポートフォリオ」と呼ぶ会社もある。

## 6. 納期とロット：QR（短納期対応）が勝負を分ける

アパレルは **「作りすぎ」と「売り逃し」の間で常に揺れている**。

```
【なぜ作りすぎるのか：シーズンビジネスの構造】

  発注（4〜6か月前）      販売（6〜8週間）        シーズン終了
     ↓                       ↓                     ↓
  「たぶんこれくらい      実際は……              売れ残り
    売れるだろう」        ・売れ筋は即完売        ↓
    で数量を決める        ・死に筋は動かない      値下げ／在庫処分
                                                  ＝粗利が消える

  ─────────────────────────────────
  対策：最初は少なく作り、売れたら追加で作る（QR＝クイックレスポンス）
        ただし追加生産には「生地がすぐ手に入ること」が前提
  ─────────────────────────────────
```

**QR（クイックレスポンス）** ＝ 売れ行きを見てから短期間で追加生産すること。
これを成立させる条件は次のとおりで、**ほぼそのまま商社の仕事の説明になっている**。

| QRの条件 | 誰が担うか |
| --- | --- |
| 生地を先に染めずに持っておく（**後染め**で色だけ後から決める） | 商社が白生地在庫を保有 |
| 縫製工場の枠を「押さえておく」 | 商社が年間の枠取り交渉をしている |
| 近い場所で作る（国内・中国など） | 商社が生産地を使い分ける |
| 物流を速くする（船→航空便への切り替え） | 商社／[フォワーダー](../../13_運輸・物流/09_国際物流・フォワーダー/README.md) |

- **後染め**（生地を白いまま作っておき、売れ筋の色だけ後から染める）は、在庫リスクを減らす古典的かつ有効な手
- 近年は [通販・D2C](../../07_小売・流通/15_通販・D2C/README.md) の伸びで、**小ロット・短サイクル・多品種**の発注が増えた。商社側の手間は増え、1件あたりの金額は減っている

## 7. 在庫・与信・為替：商社が引き受ける3つのリスク

繊維商社の決算を読むときは、**売上より「何を抱えているか」を見る**のが実務的。

| リスク | 具体的に何が起きるか | 効いてくる場面 |
| --- | --- | --- |
| **在庫** | 生地・製品を自社名義で保有。シーズンを越すと**評価損**。服は翌年には値段が付かない | 暖冬・冷夏、トレンド外し |
| **与信** | 顧客が倒産して代金が回収できない。アパレルは中小企業が多い | 景気後退、EC企業の急成長→急失速 |
| **為替** | ドル建てで買い、円建てで売る間の変動。円安局面では仕入れ原価が上がる | 急激な相場変動 |

```
【商社の口銭は「引き受けたリスクの数」でほぼ決まる】

  単純仲介（伝票を通すだけ）      口銭：薄い（数%）
   └ 在庫なし・与信のみ

  OEM（仕様どおり作って納める）    口銭：中
   └ 在庫あり・与信あり・納期責任あり

  ODM（企画から提案して作る）      口銭：厚い
   └ 上記＋先行投資（サンプル代・生地の仕込み）＋トレンドを外すリスク

  ＝「何もリスクを取らない中間業者」が最初に消える理由がここにある
```

- 売上高営業利益率は **おおむね2〜5%**。これは「薄い」のではなく、**売上高という分母に自分のリスク以外のものも乗っている**から
- 見るべき指標は **粗利率（売上総利益率）**、**在庫回転日数**、**貸倒引当金**

## 8. 品質保証：見えないところで一番手間がかかる仕事

消費者から見えないが、クレームの発生源はここに集中する。

- **堅牢度（けんろうど）** ＝ 色落ちのしにくさ。摩擦・汗・洗濯・日光ごとに等級が決まっている。等級が足りないと「白い服に色移りした」という事故になる
- **寸法変化率** ＝ 洗濯で縮む度合い。基準を超えると返品になる
- **有害物質** ＝ ホルムアルデヒド等の規制（有害物質を含有する家庭用品の規制に関する法律）。**乳幼児用品は特に厳格**
- **表示** ＝ 家庭用品品質表示法。組成表示と洗濯表示（JIS L 0001）を間違えると回収対象
- **付属品** ＝ ボタン・ファスナー・紐。子ども服の紐の長さ規格（JIS L 4129）など安全規格がある

これらは **海外工場の自己申告では担保できない**ので、商社が第三者検査機関に試験を出し、量産前に承認を出す。
「検品費用をどちらが持つか」「不良の値引き交渉を誰がやるか」が、実務では毎日の論点になる。

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **OEM** | Original Equipment Manufacturing。ブランドの仕様どおりに作って納めること。企画はブランド側 |
| **ODM** | Original Design Manufacturing。企画・デザインから請け負うこと。商社の取り分が厚い |
| **SPA** | 製造小売。企画から販売まで自社で行う業態。ユニクロ、GU、ZARA など。商社を通さない調達ができる |
| **テキスタイル** | 生地・布地のこと。糸を織る（織物）／編む（ニット）して作る |
| **紡績（ぼうせき）** | 綿花などの繊維をより合わせて糸にする工程、またはその会社 |
| **機屋（はたや）** | 糸から生地を織る会社。産地に集積している中小企業が多い |
| **産元（さんもと）** | 産地で機屋に生産を割り振る卸。小規模な地域版の商社にあたる |
| **染工場（せんこうじょう）** | 生地や糸を染め、機能加工を施す工場 |
| **先染め／後染め** | 糸の段階で染めるか、生地になってから染めるか。後染めは色の決定を遅らせられるのでQRに向く |
| **堅牢度（けんろうど）** | 色落ちのしにくさの等級。摩擦・汗・洗濯・日光などの項目ごとに評価する |
| **ロット／MOQ** | 最低発注数量（Minimum Order Quantity）。工程が川上になるほど大きくなる |
| **QR（クイックレスポンス）** | 売れ行きを見てから短納期で追加生産すること |
| **期中追加** | シーズンが始まってから追加発注すること。QRの実務上の呼び名 |
| **リードタイム** | 発注から納品までの所要期間。海外生産では3〜6か月が普通 |
| **口銭（こうせん）** | 商社が取る手数料・マージン |
| **L/C（信用状）** | 銀行が代金支払いを保証する貿易決済の仕組み。与信の弱い相手との取引で使う |
| **チャイナ・プラスワン** | 中国一極集中を避け、別の生産国も併用する考え方 |
| **フォワーダー** | 貨物の国際輸送を手配する事業者 → [国際物流・フォワーダー](../../13_運輸・物流/09_国際物流・フォワーダー/README.md) |
