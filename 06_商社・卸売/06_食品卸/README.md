## このフォルダの読み方

食品卸は **「メーカー数万社 × 小売数十万店」をつなぐ結節点**。
売っているのはモノではなく、**品揃え形成・物流・情報・金融という4つの機能**である。
ところが粗利率はわずか**6〜9%**、営業利益率は**1%台**。
その粗利の半分近くを物流費が食べているので、**実態は商社というより巨大な物流業**になっている。
この「機能を売る会社なのに機能の対価が取れていない」というねじれを軸に、3本＋直近トピックに分けた。

## 1. 業界の定義・範囲

**食品卸（加工食品卸／食品商社）** ＝ 食品メーカーから商品を仕入れ、
小売・外食・中食などの事業者に販売する中間流通業。一般消費者には直接売らない。

```
【「食品卸」と呼ばれる範囲】

  川上                                                     川下
  ─────────────────────────────────▶

  農水産      食品          ★食品卸★        小売          消費者
  生産者  →  メーカー  →  （本ノートの   →  スーパー   →
  （農家・   （味の素・     対象）           コンビニ
   漁協）     ハウス等）                     ドラッグ
                              │
                              └────────▶ 外食・中食・給食
                                （業務用卸の領域）

  隣接するが別扱いのもの：
   ・青果/鮮魚/精肉の「卸売市場」（せり・相対取引の世界。制度が別）
   ・酒類卸（免許制。→ 08_酒類卸）
   ・医薬品卸（薬価という公定価格がある。→ 07_医薬品卸）
   ・総合商社の食料部門（原料・海外調達が主。→ 01_総合商社）
```

境界の引き方で押さえるべき点は3つ。

- **「加工食品卸」が中心** — 常温の加工食品・菓子・飲料に加え、冷凍・チルド（低温）を扱う。
  生鮮（青果・鮮魚・精肉）は卸売市場という別制度の世界で、プレイヤーも慣行も異なる。
- **一次卸と二次卸** — メーカーから直接仕入れる一次卸（元卸）と、一次卸から仕入れて小規模小売に売る二次卸（仲卸）がある。
  上位5社はいずれも一次卸だが、地域の二次卸に売る機能も持つ。
- **業務用卸** — 外食・給食・ホテルなど事業者向け。商品規格が異なり、小売向けより粗利率が高い。

## 2. 市場規模と成長性

| 指標                     | 数値                                                                               | 年・出典                                              |
| ------------------------ | ---------------------------------------------------------------------------------- | ----------------------------------------------------- |
| 食品卸売業の販売額       | 約 **63.3兆円**（過去最高）                                                        | 2023年。経産省 商業動態統計をもとにした業界解説ベース |
| 商業販売額全体           | 約 **635兆円**（前年比+1.3%）。うち卸売が約4分の3                                  | 2025年。経産省 商業動態統計                           |
| 飲食料品卸売業の増加要因 | 食品の小売価格上昇、コメなど農産物の市況上昇                                       | 2025年。経産省 経済解析室                             |
| 食品の値上げ品目数       | 2025年 **20,609品目**／2026年は1〜11月判明分で **19,083品目**、年間2万品目超が確実 | 帝国データバンク（民間調査会社の集計）                |

成長性の読み方。

- **名目は伸びている／実質は伸びていない** — 販売額が過去最高なのは、
  外食需要の回復と**物価上昇による名目膨張**が主因。数量（トン・ケース）ベースでは横ばい〜減少。
- **長期の人口減少が上限を決める** — 国内の食品消費総量は人口と食事回数で決まるため、構造的に縮む。
- **伸びる領域は3つ** — ①業務用（外食・中食）、②低温（冷凍・チルド）、③物流受託・海外。

## 3. バリューチェーン（川上 → 川下）

```
【モノ・カネ・情報の三重の流れ】

 モノ  メーカー ──▶ 卸のRDC ──▶ 卸のTC ──▶ 小売DC ──▶ 店舗 ──▶ 消費者
                     （在庫）     （仕分）   （再仕分）

 カネ  メーカー ◀── 代金（早払い） ── 卸 ◀── 代金（遅く回収） ── 小売
       メーカー ──── リベート ─────▶ 卸 ──── センターフィー ──▶ 小売
                  （後から払い戻し）        （納品額の数%を天引き）

 情報  メーカー ◀── 売れ筋・欠品・需要予測 ── 卸 ◀── POSデータ ── 小売
                                              │
                                     棚割り・販促提案を返す
```

付加価値がどこに集まるか。

| 段階         | 粗利率の目安 | なぜそうなるか                                       |
| ------------ | ------------ | ---------------------------------------------------- |
| 食品メーカー | 20〜40%      | ブランドと製法が模倣しにくい。価格決定力がある       |
| **食品卸**   | **6〜9%**    | 同じ商品を誰でも扱える。差別化が物流と提案力しかない |
| 食品スーパー | 25〜30%      | 立地と品揃えで差がつく。ただし販管費も重い           |

> ポイント：卸が薄利なのは「中間業者だから」ではなく、**扱う商品が他社と同じだから**。
> 同じ味の素のマヨネーズを卸A社も卸B社も仕入れられる。差がつくのは
> 「何円で、何時に、どんな荷姿で届けられるか」だけ。だから競争が物流に集約する。

## 5. 収益モデル・コスト構造

```
【売上1,000円の分解（大手総合食品卸のイメージ）】

 売上 1,000円
  ├─ 売上原価  約 925円  ← メーカーからの仕入（リベート差引後）
  └─ 売上総利益 約  75円（7.5%）
       ├─ 物流費      約 35円  ← センター運営・配送・保管
       ├─ 人件費      約 25円  ← 営業・センター作業
       ├─ その他       約  0円〜
       └─ 営業利益    約 15円（1.5%）

 感応度： 物流費が10%上がると → 営業利益は 23% 減る
```

| 収益源                       | 中身                                                      | 性格                                             |
| ---------------------------- | --------------------------------------------------------- | ------------------------------------------------ |
| 売買差益（卸売マージン）     | 仕入価格と販売価格の差                                    | 表の利益。競争で削られ続ける                     |
| **リベート（販売報奨金）**   | メーカーからの事後の払い戻し。数量・販促・物流・決済の4型 | **実質的な利益の主戦場**。期末に条件が動く       |
| 物流受託料・センター運営受託 | 小売の物流センターの運営を受託                            | 新しい収益源。フィーを払う側からもらう側へ回れる |
| 自社商品（卸PB）             | 国分「K&K」、各社オリジナル商品                           | 唯一マージンを自分で決められる領域               |
| （マイナス）センターフィー   | 小売に払う物流センター利用料。納品額の数%規模とされる     | 利益を直撃する固定的な流出                       |

## 6. 競争要因（KSF）と参入障壁

| KSF                    | 中身                                                                         |
| ---------------------- | ---------------------------------------------------------------------------- |
| **物流網の密度と効率** | 全国の拠点配置、温度帯別の設備、積載率。ここが最大の差別化要因               |
| **帳合の保持**         | 大手小売への納品権。失うと売上が階段状に落ちる                               |
| **提案力（情報機能）** | 棚割り、販促企画、需要予測。無償で提供するが、帳合を守る武器になる           |
| **資金力**             | 支払と回収のサイト差を埋める運転資金＋自動化投資                             |
| **規模**               | 仕入条件（リベート料率）は取扱量で決まる。規模が条件を呼び、条件が規模を呼ぶ |

**参入障壁**は許認可ではなく（食品卸に特別な免許は不要。酒類は免許制）、
**全国の物流網と帳合という既存関係**そのもの。
新規に全国網を作ろうとすれば数百億円規模の投資と数年の時間が要り、
その間ずっと粗利7%で戦うことになる。だから新規参入はほぼ起きない。

| **リベート（販売報奨金）** | メーカーが卸へあとから払い戻す金銭。表の建値を崩さずに相手ごとの実質価格を変えるための日本の商習慣。卸の利益の主戦場 → [①](01_食品卸は何をしているか.md)    |
| **センターフィー**         | 小売が自社の物流センター運営費として納入業者から徴収する手数料。卸から小売へ流れる逆向きのお金。納品額の数%規模とされる → [①](01_食品卸は何をしているか.md) |
| **1/3ルール**              | 製造日から賞味期限までを3等分し、最初の1/3以内に小売へ納品する商習慣。過ぎた在庫は卸が抱える → [①](01_食品卸は何をしているか.md)                            |
| **CLO（物流統括管理者）**  | 改正物流効率化法で特定荷主に選任が義務づけられる役員級の物流責任者（2026年4月施行） → [②](02_物流という本体.md)                                             |
