# ③ 業界構造と再編

このノートで分かること：食品卸が**上位5社の寡占**に収斂していく過程と、
そのほとんどが**総合商社の傘下にある理由**。
そして地場卸の淘汰、小売のPB（プライベートブランド）拡大と直取引、
メーカーの価格政策のあいだで、卸がどんな立場に置かれているか。

## 1. 結論：「系列を背負った5社」と「消えていく無数の地場卸」

```
【食品卸の階層構造（2026年時点のイメージ）】

 ┌─────────────────────────────────────┐
 │ 上位5社（売上7,000億〜2.5兆円）                       │
 │  三菱食品 / 日本アクセス / 国分グループ本社            │
 │  加藤産業 / 伊藤忠食品                                 │
 │  → 全国網・全温度帯・全業態をカバー。大半が商社系      │
 └─────────────────────────────────────┘
        ▲ 買収・提携で吸い上げ
 ┌─────────────────────────────────────┐
 │ 中堅・準大手（数百億〜数千億円）                        │
 │  地域に強い総合卸、カテゴリ特化卸（菓子・酒類・業務用）  │
 │  → 単独での自動化投資が難しく、選択を迫られる層        │
 └─────────────────────────────────────┘
        ▲ 後継者不在・物流費負担で退出
 ┌─────────────────────────────────────┐
 │ 地場卸・小規模問屋（数億〜数十億円）                    │
 │  → 廃業・M&A・大手の配送網への吸収                     │
 └─────────────────────────────────────┘
```

かつて日本には数万の食品問屋があった。それが淘汰・統合を重ね、
**全国をカバーできる総合食品卸は実質5社**になっている。

## 3. なぜ総合商社の傘下にあるのか

上位5社のうち3社（日本アクセス、三菱食品、伊藤忠食品）が総合商社の傘下にある。
これは偶然ではなく、**商社と卸の機能が補い合う関係にある**ため。

```
【商社と食品卸の役割分担】

 [総合商社]                          [食品卸]
  ├ 海外からの原料調達                ├ 国内メーカーからの仕入
  │ （小麦、大豆、油脂、水産、畜産）   │
  ├ 資本・与信（バランスシート）       ├ 全国の物流網
  ├ メーカーへの出資                   ├ 小売との帳合
  └ 海外販路                           └ 棚割り・販促の提案力
        │                                    │
        └──── 川上から川下まで一気通貫 ───┘
                （＝バリューチェーン戦略）
```

商社にとって食品卸を持つ意味は3つ。

1. **川下の出口を確保できる** — 海外で調達した原料や、出資先メーカーの商品を、
   確実に国内の棚まで運ぶルートを自前で持てる。
2. **巨大な売上と安定キャッシュフローが手に入る** — 資源価格に振られる商社の業績に対し、
   食品卸の利益は薄いが振れが小さい。非資源の安定収益として機能する。
3. **小売との接点が持てる** — 伊藤忠＝ファミリーマート、三菱商事＝ローソンという
   [コンビニ](../../07_小売・流通/01_コンビニエンスストア/README.md)の親会社構造と組み合わさると、
   **メーカー → 卸 → コンビニ**のすべてに同じ商社の影響が及ぶ。

一方、独立系の国分・加藤産業は、特定の商社色がないことを逆手に取り、
「どのメーカー・どの小売とも等距離で付き合える」ことを強みにしている。

関連：[総合商社](../01_総合商社/README.md)（商社が卸の上に乗る構造の全体像）

## 4. 地場卸の淘汰

### 4.1 何が地場卸を追い詰めているか

| 要因                     | 内容                                                                                                            |
| ------------------------ | --------------------------------------------------------------------------------------------------------------- |
| **物流費と人件費の上昇** | 粗利6〜9%の商売で、配送コストが1割上がると利益が2割以上飛ぶ（→ [② 物流という本体](02_物流という本体.md)）       |
| **自動化投資の壁**       | センター自動化には数十億円規模。売上数十億円の卸には不可能                                                      |
| **システム投資の壁**     | EDI（電子データ交換）、トレーサビリティ、需要予測AI。小売の要求水準が上がり続ける                               |
| **後継者不在**           | 家族経営が多く、経営者の高齢化と後継ぎ不在で事業停止に至る例が顕在化している（M&A仲介各社の解説、2025〜2026年） |
| **小売の広域化**         | 地域スーパーが全国チェーンに買収されると、帳合ごと大手卸に移る                                                  |

```
【地場卸が消える典型パターン】

 地元スーパーS（10店舗）と40年の取引
        │
        ▼ Sが全国チェーンTに買収される
 TのセンターはZ卸（大手）が運営
        │
        ▼ 帳合がZ卸に移る
 地場卸の売上の6割が1年で消える
        │
        ▼
 廃業 or 大手グループ入り（M&A）
```

### 4.2 生き残る地場卸の型

すべての地場卸が消えるわけではない。残るのは次の3型。

| 型               | 中身                                               | なぜ残れるか                                               |
| ---------------- | -------------------------------------------------- | ---------------------------------------------------------- |
| **業務用特化**   | 外食・給食・ホテル向け。小口・多品種・メニュー提案 | 大手の標準オペレーションでは採算が合わない領域。粗利が厚い |
| **地場商材特化** | 地域の特産品、地酒、郷土食材                       | 全国卸が扱わない。地元メーカーとの関係が資産になる         |
| **物流特化**     | 自社センターを大手や小売に貸す／運営受託する       | 商流を手放して物流機能だけを売る割り切り                   |

## 5. 小売のPB拡大と直取引という圧力

### 5.1 PB（プライベートブランド）は卸にとって何か

PBは小売が企画し、メーカーに製造委託して自社ブランドで売る商品。
セブンプレミアム、トップバリュ、みなさまのお墨付きなど。

```
【NB（ナショナルブランド）と PB の流れの違い】

 NB： メーカー ──▶ 卸 ──▶ 小売 ──▶ 消費者
       （企画もブランドもメーカー。卸はマージン＋リベート）

 PB： 小売が企画 ──▶ 製造委託先メーカー ──▶ 小売 ──▶ 消費者
                          │
                          └──▶ （卸は物流だけ担う／関与なし）

 → PBが増えるほど、卸の「商流」は薄くなる
 → ただし物流は必要なので、物流機能だけ残る＝ますます物流業になる
```

PB比率が上がると卸に起きること。

- **商流からの排除** — 商品の企画・調達に卸が関与しない。マージンが取れない。
- **リベートの消失** — PBにはメーカーからのリベートがない。利益源が1つ消える。
- **物流だけ残る** — ただし物流費は発生する。**利益なきオペレーション**になりやすい。

対抗策として、大手卸は**自社商品（卸のPB）の開発**を強めている。
国分の「K&K」、伊藤忠食品のオリジナル商品注力（2026年3月期の増益要因の1つ）などがその例。
「メーカーよりもメーカー力」（国分の2026年度方針）という標語は、この方向を示している。

### 5.2 直取引（メーカー ⇄ 小売の中抜き）

大手小売が大手メーカーと直接取引し、卸を飛ばす動き。
ただし**完全な中抜きは起きにくい**。理由は3つ。

1. **物流が代替できない** — メーカーが全国の店舗に多頻度小口で配送するのは非現実的。
2. **小口メーカーが残る** — 大手メーカーの数商品を直で買っても、残る数千SKUは卸が必要。
3. **与信と資金繰り** — 卸が担っている支払サイトの調整機能を、メーカーは引き受けたがらない。

> ポイント：直取引の脅威は「卸が消える」ことではなく、**卸が物流機能だけに切り下げられる**こと。
> 商流を抜かれても物流は残る。しかし物流だけでは、いまの薄いマージンでは食えない。
> だから卸は「物流の対価をきちんと取る」方向へ動かざるを得ない。

## 6. メーカーの価格政策と卸の立場

2022年以降続く食品の値上げ局面で、卸は**板挟み**の位置にいる。

```
【値上げの伝播と、卸が挟まれる構造】

  原材料・エネルギー・物流費 上昇
        ↓
  メーカー：出荷価格を引き上げたい（建値改定）
        ↓
      【卸】←────────────────┐
        ↓                              │ 小売：
  小売：納品価格の引き上げを受けたくない │ 「客が離れる」
        ↓                              │ 「他の卸なら
  消費者：値上げに敏感                   │  据え置ける」
                                         └────────

  ・値上げを飲ませられないと → 卸のマージンが削られる
  ・値上げを通せると        → 売上が名目で膨らみ、同じ粗利率でも粗利額が増える
```

実は、**値上げは食品卸にとって短期的には追い風**になる側面がある。
粗利率が一定なら、単価が上がるほど粗利額が増えるからである。
2023年の食品卸の販売額が過去最高の約63.3兆円に達したのも、外食回復と**物価上昇**が背景とされる。
2025〜2026年に上位5社がそろって増収・最高益圏にいるのも、この名目膨張の効果が大きい。

一方で長期的には逆風になる。

- 値上げで**数量が減る**（家計の節約、内食回帰、購入点数の減少）
- 数量が減っても**物流のコストは固定的**にかかる（便数は簡単には減らせない）
- 小売のPB・安売り志向が強まり、**NBのマージンが圧縮**される

## 7. 海外展開と業務用（外食向け）という出口

国内の人口減少と少子高齢化で、食品の国内需要は長期的に縮む。
上位卸が打ち出している成長の方向は大きく2つ。

| 方向                           | 中身                                                                                                                                                                                                                                                                                                             | 難しさ                                                                                                             |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| **業務用（外食・中食・給食）** | [ファストフード](../../08_食品・農水産・外食/14_ファストフード/README.md)・[ファミレス](../../08_食品・農水産・外食/15_ファミリーレストラン/README.md)・[給食](../../08_食品・農水産・外食/21_給食・フードサービス/README.md)・ホテル向けの食材供給。日本アクセスは2026年3月期の増収要因に「外食の増加」を挙げる | 配送1件あたりが小口で効率が悪い。メニュー提案力が要る                                                              |
| **海外（主にアジア）**         | 日本食材の輸出、現地の日系小売・外食への供給、現地卸への出資                                                                                                                                                                                                                                                     | 現地の物流網と商習慣を一から作る必要。単価が小さい。国分は第12次長期経営計画で「より地域へ、さらに世界へ」を掲げる |

```
【卸の事業ポートフォリオの広がり】

          国内小売向け（本業）
                 │ 成熟・薄利
       ┌─────┼─────┐
       ▼         ▼         ▼
   業務用      物流受託    海外
  （粗利厚い） （新収益源）（長期）
       │         │         │
       └── いずれも「物流と提案力」が資産になる ──┘

  ＋ 自社商品（卸PB）＝ 唯一マージンを自分で決められる領域
```

## 8. まとめ：構造を一枚で

| 論点       | いま起きていること                       | 5年後の焦点                                                  |
| ---------- | ---------------------------------------- | ------------------------------------------------------------ |
| 寡占       | 上位5社に集約済み。中堅以下が退出中      | 上位内での再編は起きるか（可能性は低いが物流での連携は進む） |
| 商社系列   | 3社が商社傘下。川上〜川下の一気通貫      | 商社のポートフォリオ判断次第で位置づけが変わる               |
| 収益構造   | 売上は値上げで膨らむが、営業利益率は1%台 | 物流の対価をどこまで取れるか                                 |
| PB・直取引 | 商流が薄くなり物流だけが残る圧力         | 卸PBと業務用でマージンを取り戻せるか                         |
| 物流       | 2024年問題後の運賃・人件費上昇が直撃     | 共同配送と自動化への投資余力が勝敗を分ける                   |

## 用語メモ

| 用語                           | 意味                                                                                                                                              |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| **NB（ナショナルブランド）**   | メーカーが企画・製造し自社ブランドで売る商品。卸はここでマージンとリベートを得る                                                                  |
| **PB（プライベートブランド）** | 小売が企画しメーカーに製造委託して自社ブランドで売る商品。卸の商流が薄くなり、物流だけが残りやすい                                                |
| **卸PB／オリジナル商品**       | 卸自身が企画する商品（国分の「K&K」など）。唯一、卸がマージンを自分で決められる領域                                                               |
| **直取引（中抜き）**           | 小売とメーカーが卸を通さず直接取引すること。物流と小口SKUが障壁となり、完全な中抜きは起きにくい                                                   |
| **建値改定**                   | メーカーが標準卸価格そのものを引き上げること。値上げ局面の主戦場                                                                                  |
| **業務用卸**                   | 外食・中食・給食・ホテル向けの食材卸。小売向けより粗利が厚いが配送効率は悪い                                                                      |
| **バリューチェーン戦略**       | 原料調達から小売までを1つのグループで押さえる考え方。商社が食品卸を傘下に置く理由                                                                 |
| **EDI**                        | Electronic Data Interchange。受発注・請求データを企業間で電子的にやり取りする仕組み。小売の要求水準が上がり、中小卸のシステム投資負担になっている |
