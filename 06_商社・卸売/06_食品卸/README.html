このフォルダの読み方

食品卸は 「メーカー数万社 × 小売数十万店」をつなぐ結節点。
売っているのはモノではなく、品揃え形成・物流・情報・金融という4つの機能である。
ところが粗利率はわずか6〜9%、営業利益率は1%台。
その粗利の半分近くを物流費が食べているので、実態は商社というより巨大な物流業になっている。
この「機能を売る会社なのに機能の対価が取れていない」というねじれを軸に、3本＋直近トピックに分けた。

ノート 内容
① 食品卸は何をしているか取引の組み合わせ爆発を1点に集約する存在理由、品揃え形成・物流・情報・金融の4機能、帳合という納品権、リベート（販売報奨金）とセンターフィーという独特の商習慣、粗利6〜9%／営業利益率1%台の分解、1/3ルールと温度帯別管理
② 物流という本体在庫拠点の3層構造（RDC/TC/専用センター）、1日2便・週7日という過剰サービス、温度帯が3つに割れることの意味、2024年問題とその後、改正物流効率化法とCLO選任義務、共同配送・モーダルシフト・センター自動化、物流費1割増で営業利益が23%飛ぶ計算
③ 業界構造と再編上位5社（日本アクセス／三菱食品／国分／加藤産業／伊藤忠食品）の寡占、総合商社が食品卸を傘下に置く理由、地場卸の淘汰と生き残る3類型、小売のPB拡大と直取引が商流を薄くする構造、値上げ局面で卸が挟まれる位置、業務用卸と海外という出口
④ 直近トピック（2026年9月時点）2年連続で年2万品目超の値上げ、上位5社の決算が「最高益組」と「減益組」に割れた理由、改正物流効率化法（2026年4月）と改正物流特殊指定（2027年4月施行）、令和のコメ騒動の反転と逆ザヤ、共同配送の実装

1. 業界の定義・範囲

食品卸（加工食品卸／食品商社） ＝ 食品メーカーから商品を仕入れ、
小売・外食・中食などの事業者に販売する中間流通業。一般消費者には直接売らない。

  ─────────────────────────────────▶

  農水産      食品          ★食品卸★        小売          消費者
  生産者  →  メーカー  →  （本ノートの   →  スーパー   →
  （農家・   （味の素・     対象）           コンビニ
   漁協）     ハウス等）                     ドラッグ
                              │
                              └────────▶ 外食・中食・給食
                                （業務用卸の領域）

  隣接するが別扱いのもの：
   ・青果/鮮魚/精肉の「卸売市場」（せり・相対取引の世界。制度が別）
   ・酒類卸（免許制。→ 08_酒類卸）
   ・医薬品卸（薬価という公定価格がある。→ 07_医薬品卸）
   ・総合商社の食料部門（原料・海外調達が主。→ 01_総合商社）

境界の引き方で押さえるべき点は3つ。

  • 「加工食品卸」が中心 — 常温の加工食品・菓子・飲料に加え、冷凍・チルド（低温）を扱う。
    生鮮（青果・鮮魚・精肉）は卸売市場という別制度の世界で、プレイヤーも慣行も異なる。
  • 一次卸と二次卸 — メーカーから直接仕入れる一次卸（元卸）と、一次卸から仕入れて小規模小売に売る二次卸（仲卸）がある。
    上位5社はいずれも一次卸だが、地域の二次卸に売る機能も持つ。
  • 業務用卸 — 外食・給食・ホテルなど事業者向け。商品規格が異なり、小売向けより粗利率が高い。

指標 数値 年・出典

飲食料品卸売業の増加要因食品の小売価格上昇、コメなど農産物の市況上昇2025年。経産省 経済解析室
食品の値上げ品目数2025年 20,609品目／2026年は1〜11月判明分で 19,083品目、年間2万品目超が確実帝国データバンク（民間調査会社の集計）

成長性の読み方。

  • 名目は伸びている／実質は伸びていない — 販売額が過去最高なのは、
    外食需要の回復と物価上昇による名目膨張が主因。数量（トン・ケース）ベースでは横ばい〜減少。
  • 長期の人口減少が上限を決める — 国内の食品消費総量は人口と食事回数で決まるため、構造的に縮む。
  • 伸びる領域は3つ — ①業務用（外食・中食）、②低温（冷凍・チルド）、③物流受託・海外。

付加価値がどこに集まるか。

段階 粗利率の目安 なぜそうなるか
食品メーカー20〜40%ブランドと製法が模倣しにくい。価格決定力がある
食品卸6〜9%同じ商品を誰でも扱える。差別化が物流と提案力しかない
食品スーパー25〜30%立地と品揃えで差がつく。ただし販管費も重い

ポイント：卸が薄利なのは「中間業者だから」ではなく、扱う商品が他社と同じだから。
同じ味の素のマヨネーズを卸A社も卸B社も仕入れられる。差がつくのは
「何円で、何時に、どんな荷姿で届けられるか」だけ。だから競争が物流に集約する。

5. 収益モデル・コスト構造

【売上1,000円の分解（大手総合食品卸のイメージ）】

 売上 1,000円
  ├─ 売上原価  約 925円  ← メーカーからの仕入（リベート差引後）
  └─ 売上総利益 約  75円（7.5%）
       ├─ 物流費      約 35円  ← センター運営・配送・保管
       ├─ 人件費      約 25円  ← 営業・センター作業
       ├─ その他       約  0円〜
       └─ 営業利益    約 15円（1.5%）

 感応度： 物流費が10%上がると → 営業利益は 23% 減る
収益源 中身 性格
売買差益（卸売マージン）仕入価格と販売価格の差表の利益。競争で削られ続ける
リベート（販売報奨金）メーカーからの事後の払い戻し。数量・販促・物流・決済の4型実質的な利益の主戦場。期末に条件が動く
物流受託料・センター運営受託小売の物流センターの運営を受託新しい収益源。フィーを払う側からもらう側へ回れる
自社商品（卸PB）国分「K&K」、各社オリジナル商品唯一マージンを自分で決められる領域
（マイナス）センターフィー小売に払う物流センター利用料。納品額の数%規模とされる利益を直撃する固定的な流出

6. 競争要因（KSF）と参入障壁

KSF 中身
物流網の密度と効率全国の拠点配置、温度帯別の設備、積載率。ここが最大の差別化要因
帳合の保持大手小売への納品権。失うと売上が階段状に落ちる
提案力（情報機能）棚割り、販促企画、需要予測。無償で提供するが、帳合を守る武器になる
資金力支払と回収のサイト差を埋める運転資金＋自動化投資
規模仕入条件（リベート料率）は取扱量で決まる。規模が条件を呼び、条件が規模を呼ぶ

参入障壁は許認可ではなく（食品卸に特別な免許は不要。酒類は免許制）、
全国の物流網と帳合という既存関係そのもの。
新規に全国網を作ろうとすれば数百億円規模の投資と数年の時間が要り、
その間ずっと粗利7%で戦うことになる。だから新規参入はほぼ起きない。

7. 規制・法制度

制度 内容 食品卸への影響
改正物流効率化法2024年5月公布。2025年4月に努力義務・判断基準、2026年4月に特定事業者の指定・中長期計画・CLO（物流統括管理者）選任義務が施行。対象は年間取扱貨物量9万トン以上の特定荷主（国交省試算で約3,200社）。罰則100万円以下大手卸はほぼ該当。物流が経営アジェンダに格上げされた
物流特殊指定（独禁法）2026年6月17日に改正告示、2027年4月1日施行。荷主の優越的地位の濫用（無償の荷役、一方的な運賃据え置き等）を規制卸は荷主として規制を受ける側
適正取引推進ガイドライン（農水省・中小企業庁）令和3年12月策定、令和8年（2026年）1月改定。センターフィーやリベートの算定根拠を示さない要請を問題行為として整理卸は納入業者として保護される側。センターフィー交渉の材料
働き方改革関連法（2024年問題）2024年4月からトラックドライバーの時間外労働に年960時間の上限輸送能力の総量が縮み、運賃が上昇
食品表示法・食品衛生法・HACCP表示、衛生管理、トレーサビリティセンター運営のコスト要因。回収時の責任範囲にも関わる
食品ロス削減推進法／納品期限の緩和1/3ルールの見直し（1/3→1/2）を農水省が働きかけ緩和が進むほど卸の在庫廃棄が減る
