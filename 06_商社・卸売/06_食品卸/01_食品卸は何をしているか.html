① 食品卸は何をしているか

商社・卸売食品卸
あこのページの単語集用語に触れると意味を確認できます10語
帳合（ちょうあい）リベート（販売報奨金・割戻金）センターフィー建値（たてね）SKU1/3ルール日配品（にっぱいひん）温度帯業務用卸口銭（こうせん）

このノートで分かること：食品卸が「メーカー数万社と小売数万店のあいだに立つ結節点」として
品揃え形成・物流・情報・金融の4つの機能を売っていること、そして粗利率6〜9%・営業利益率1%台という
超薄利の構造が、リベート（販売報奨金）やセンターフィーといった独特の商習慣とセットで成り立っていること。

1. 結論：食品卸は「機能を売る会社」である

食品卸（加工食品卸・食品商社）は、味の素やキユーピーのようなメーカーがつくった食品を仕入れ、
スーパー・コンビニ・ドラッグストア・外食チェーンに届ける中間業者。
「右から左に流して手数料を取っているだけ」と言われがちだが、実際に売っているのはモノではなく機能である。

【なぜ卸が要るのか：取引本数の爆発を止めている】

  卸がいない世界                      卸がいる世界
  メーカー 3社 × 小売 3社 = 9本        メーカー 3社 + 小売 3社 = 6本

   M1 ─┬─ R1                          M1 ─┐         ┌─ R1
       ├─ R2                          M2 ─┼─[卸]─┼─ R2
       └─ R3                          M3 ─┘         └─ R3
   M2 ─┬─ R1
       ├─ R2      取引数 = M × R        取引数 = M + R
       └─ R3
   M3 ─┬─ R1      メーカー約3万社 ×      3万 + 数万 で済む
       ├─ R2      小売約30万店 だと      ＝ 卸1社が真ん中に立つだけで
       └─ R3      文字どおり天文学的     組み合わせ爆発が消える

ポイント：食品卸の存在理由は「安く買って高く売る」ではなく、取引の組み合わせ爆発を1点に集約すること。
だから卸は、集約の規模が大きいほど強く、規模が小さいと存在価値そのものが消える。

日本の食品流通が卸に強く依存しているのは、メーカーの数が異常に多く、小売の店舗が異常に細かいから。
加工食品メーカーは中小零細を含めれば数万社、食品を売る小売店舗は数十万店ある。
1つのスーパーの棚には数千〜1万を超えるSKU（商品の最小管理単位。同じ商品でも味・容量が違えば別SKU）が並ぶが、
それを1社のメーカーが揃えることはできない。

2. 卸が売っている4つの機能

機能 具体的に何をするか 誰の手間を肩代わりしているか 対価の取り方
品揃え形成（取揃え）数万社のメーカーから商品を集め、店の棚1本分の単位に組み替える。新商品の提案、棚割り（どの商品をどこに置くか）の作成小売のバイヤー。メーカーの営業売買差益（卸売マージン）＋リベート
物流在庫を持ち、多頻度小口で店・センターに配送する。冷凍・冷蔵・常温の温度帯別に管理小売の配送・在庫管理。メーカーの小口配送マージンに内包。別建てで物流受託料
情報POS（レジ通過）データや自社の出荷データを分析し、売れ筋・死に筋、販促の提案をする小売の販促企画。メーカーのマーケ基本無料（マージンに内包）。ここが差別化
金融（与信）メーカーには早く払い、小売からは遅く回収する。実質的に取引先へ資金を立て替える小売の資金繰り。メーカーの与信管理マージンに内包。焦げ付けば丸損

この4つのうち、情報と金融は対価が取れていない。
つまり表向きは「商品を売買する会社」だが、実態は物流と与信をタダ同然で付けて商品を流す会社になっている。
これが薄利の根本原因である。

3. 帳合（ちょうあい）という日本独特の取引関係

帳合＝「このメーカーのこの商品を、この小売に納めるのはどの卸か」という担当割り当て。
帳簿を合わせる相手という意味の商業用語で、食品流通では「取引口座」「納品権」に近い。

【帳合の構造】

 メーカーA ──┐          ┌── 卸X が帳合 ──▶ スーパーS の全店
              ├─ 商品 ─┤
 メーカーB ──┘          └── 卸Y が帳合 ──▶ ドラッグZ の全店

 ・「S社の帳合を持っている」＝ S社へ納品する権利を持っている
 ・帳合を外されると、その小売への売上がまるごと消える
 ・逆に帳合を取ると、翌期から数十〜数百億円の売上が一気に乗る

帳合には2つの効果がある。

  1. 売上が階段状に動く — 食品卸の増収・減収は、商品が売れたかどうかより
    「大手小売の帳合を取ったか外されたか」で決まることが多い。決算説明でも「◯◯社との取引拡大」という表現が頻出する。
  2. 価格競争が起きにくい／起きると一気に壊れる — 帳合が固定されている間は卸同士が直接ぶつからないが、
    帳合の入札が起きると、マージンを削る消耗戦になる。

4. リベート＝販売報奨金という仕組み

リベートは、メーカーが卸（や小売）に対して、あとから払い戻す金銭のこと。
日本語では販売報奨金・割戻金。値引きを「仕入価格そのもの」ではなく「事後の支払い」で行う商習慣である。

リベートの型 何に対して払うか 卸から見た性格
数量リベート一定量・一定金額を売ったら支払う実質的な仕入値引き。量を積む動機になる
販促リベートチラシ掲載、エンド（棚の端の目立つ場所）展開など販促協力への対価販促の実行力に対する報酬
物流リベート（センターフィー相当）卸や小売の物流センター運営コストの負担物流費の補填。後述のセンターフィーと表裏
決済リベート早期に支払ったことへの割引金利相当。財務の巧拙が効く

なぜ値引きではなくリベートなのか。理由は主に3つ。

  • 建値（たてね）を崩さないため — 表向きの卸価格を下げると、他の取引先にも同じ価格を要求される。
    事後払いなら、相手ごとに実質価格を変えても表の価格は揺らがない。
  • 年間の売上目標をコントロールするため — 「年間◯億円達成でリベート◯%」とすることで、卸に量を積ませる。
  • 期末調整の弁になっている — 条件が期中に確定しないことが多く、決算直前に金額が動く。

ポイント：食品卸の利益は、売買差益（表のマージン）よりもリベート（裏の条件）で決まる部分が大きい。
決算資料で「売上総利益率が改善」と書かれていても、商品が高く売れたのではなく
リベート条件を取り直しただけ、ということが普通に起きる。

なお、リベートは不透明さを批判されてきた領域でもある。
農林水産省の「食品製造業者・小売業者間における適正取引推進ガイドライン」（2021年12月策定、2026年1月改定）は、
センターフィーやリベートの算定根拠を示さない要請を問題行為として整理している。

5. センターフィーという「逆向きのお金」

センターフィーは、小売が自社の物流センターを運営するコストとして、納入業者（卸やメーカー）から徴収する手数料。
卸から小売へ払う、流れが逆のお金である。

【モノとカネの流れ（簡略）】

  メーカー ──── 商品 ────▶ 卸 ──── 商品 ────▶ 小売センター ──▶ 店舗
      ▲                      ▲                      │
      │  代金（早く払う）     │  代金（遅く入る）     │
      └──────────┘                      │
      │                                             │
      └── リベート（メーカー→卸）                  │
                                                     │
        卸 ──── センターフィー（卸→小売）─────┘
                売上の数% を納品のたびに天引き

センターフィーの水準は取引条件次第で非公開だが、納品額の数%規模とされ、
粗利率が6〜9%しかない卸にとっては利益を直撃する。
公正取引委員会の調査では、納入業者の50.2%が「算定根拠の説明なしに金額・料率だけを提示された」と回答したと報じられている（2026年、公取委の物流・取引適正化関連の公表ベース）。

さらに問題とされてきたのがセンターフィーとリベートの付け替え。
センターフィーを下げる代わりに協賛金（リベート）を一方的に引き上げるといった運用が指摘されている。

6. 収益構造：粗利6〜9%、営業利益率1%台

食品卸の損益計算書は、他業種を見慣れた目には異様に見える。

項目 目安（大手総合食品卸、2025〜2026年の開示ベース） コメント
売上高1兆〜2.5兆円商品の代金がそのまま売上に立つので金額が巨大になる
売上総利益率（粗利率）おおむね 6〜9%製造業（20〜40%）と比べて桁違いに薄い
販管費率5〜8%大半が物流費と人件費
営業利益率1%台前半三菱食品2026年3月期は営業利益329億円／売上2兆1230億円＝約1.5%
【売上1,000円の分解（食品卸のイメージ）】

 売上 1,000円
  ├─ 売上原価  約 925円  ← メーカーからの仕入（リベート差引後）
  └─ 売上総利益 約  75円（7.5%）
       ├─ 物流費      約 35円  ← センター運営・配送・保管
       ├─ 人件費      約 25円  ← 営業・センター作業
       ├─ その他販管費 約  0円〜
       └─ 営業利益    約 15円（1.5%）

 → 物流費が 3円 上がるだけで、営業利益は 2割 吹き飛ぶ

ポイント：粗利75円のうち35円が物流費。だから食品卸の損益は、商品が売れたかどうかより
トラック運賃と倉庫人件費がいくら上がったかでほぼ決まる。詳しくは ② 物流という本体 へ。

7. 返品と鮮度管理という固有のコスト

食品卸が他の卸と決定的に違うのは、扱う商品に時間の寿命があること。

7.1 賞味期限と「1/3ルール」

日本の加工食品流通には 1/3ルール（三分の一ルール）という商習慣がある。
製造日から賞味期限までの期間を3等分し、

  • 最初の1/3以内に小売へ納品する（納品期限）
  • 次の1/3以内に消費者へ売り切る（販売期限）
  • 残り1/3を家庭での消費期間とみなす
【1/3ルール（賞味期限6か月の商品の例）】

 製造 ─────────────────────────▶ 賞味期限
  |◀─ 2か月 ─▶|◀─ 2か月 ─▶|◀─ 2か月 ─▶|
       納品期限      販売期限
        ↑             ↑
   ここを過ぎると   ここを過ぎると
   小売が受け取らない 店頭から撤去

 → 賞味期限まで4か月残っていても「納品できない在庫」になる
 → その在庫リスクは、原則として卸が抱える

納品期限を過ぎた商品は、賞味期限まで余裕があっても卸の在庫として滞留し、値引き処分か廃棄になる。
農林水産省は食品ロス削減の観点から納品期限の緩和（1/3→1/2）を業界に働きかけており、対応する小売は増えているが、全面的ではない。

7.2 温度帯という制約

温度帯 主な商品 管理の難しさ
常温（ドライ）調味料、缶詰、乾麺、菓子、飲料最も扱いやすい。物流の標準
チルド（冷蔵、5℃前後）日配品（牛乳、豆腐、惣菜、デザート）賞味期限が数日。1日2便の多頻度配送が必須
フローズン（冷凍、-18℃以下）冷凍食品、アイス冷凍設備が必要で、庫内作業の負担が大きい

温度帯が分かれると、トラックも倉庫も人も別々に用意しなければならない。
1台のトラックに常温品と冷凍品を混載できないため、積載率（トラックがどれだけ荷物で埋まっているか）が上がらない。
これも薄利を固定させる要因になっている。

8. 業態別に見る「卸の使われ方」

取引先 卸に求めるもの 卸の立場
コンビニ1日3便レベルの超多頻度配送、専用センターの運営実質は物流受託業者。マージンは最も薄い
食品スーパー・GMS品揃え提案、棚割り、販促企画、センター運営4機能をフルに使われる本丸。帳合争いが激しい
ドラッグストア食品の品揃えを丸ごと任せたい（食品は集客用で専門性が薄い）提案力が効きやすく、近年の成長ドライバー
外食チェーン（ファミレス等）・給食業務用規格の食材、小口配送、メニュー提案業務用卸の領域。粗利は相対的に厚い
ECプラットフォーム小口ピッキング、当日出荷作業コストが重く、収益化が難しい

業務用卸（外食・給食・ホテル向け）は、小売向けより粗利率が高い。
理由は、業務用は規格・容量が特殊で比較が効きにくく、小売のような激しい価格の横並び比較にさらされないため。
一方で、1件あたりの配送量が小さく、配送効率は悪い。

9. まとめ：この業界を理解する3つの鍵

  1. 売っているのはモノではなく機能（品揃え・物流・情報・金融）。うち2つは対価が取れていない。
  2. 利益は表のマージンではなくリベートとセンターフィーで決まる。決算の増減益は条件交渉の結果であることが多い。
  3. 粗利の半分近くが物流費。だから食品卸の本質は物流業であり、次のノートがこの業界の本丸になる。
