## 1. 2026年度薬価改定 — 薬剤費ベース▲4.02%

厚生労働省は2026年3月5日に薬価基準改定を告示し、**2026年4月1日**から実施した。
2026年度は診療報酬改定と同じ年（本改定）にあたり、ルール改正も同時に行われている。

| 項目 | 内容 |
| --- | --- |
| 改定率 | 医療費ベース **▲0.86%**／薬剤費ベース **▲4.02%** |
| 実施日 | 2026年4月1日 |
| 市場拡大再算定 | **13成分31品目**が対象（持続可能性特例価格調整対象を含む）。最大で40%超の引下げ |
| 主な引下げ例 | ロミプレート ▲40.6%、イラリス ▲25.0%、エンレスト ▲25.0%（いずれも報道ベース） |
| 不採算品再算定 | **232成分704品目**を引き上げ |
| 革新的新薬の薬価維持 | 383成分653品目（95社）が対象。一方で維持終了となった28成分49品目で約918億円の累積控除 |
| ルール改正 | 市場拡大再算定の **「共連れ」（類似品への波及適用）を廃止**。長期収載品の **G1ルール適用を後発品上市後10年→5年に前倒し** |

卸への効き方はこうなる。

```
【改定が卸の損益に届く3経路】

  ① 売上単価の低下
     薬剤費ベース▲4.02% ＝ 同じ数量を運んでも売上が約4%減る
                 ↓
  ② 改定日をまたぐ在庫の評価減
     4月1日に手持ち在庫の価値が一斉に下がる。第1四半期に損益直撃
                 ↓
  ③ 価格交渉の再スタート
     新薬価を前提に、買い手が再び値引きを要求。粗利の回復には時間がかかる

  ＊逆風ばかりではない：不採算品再算定（704品目の引上げ）は
    赤字品目を減らし、供給不安の緩和にも効く。卸にとっては数少ない追い風。
```

**G1前倒し**（長期収載品を早く安くするルール）は、単価の高い先発品の売上が早く縮むことを意味する。
一方、共連れ廃止は「売れていない類似品まで巻き込んで下げる」不合理を正すもので、
メーカー・卸の双方にとっては読みやすさの改善にあたる。

## 2. 大手4社の利益率が過去5年で最低の見込み

| 指標 | 2026年3月期（実績） | 2027年3月期（会社予想） |
| --- | --- | --- |
| 売上高合計 | 10兆9,614億円（前期比 +3.9%） | 11兆2,520億円（+2.65%） |
| 営業利益合計 | 1,423億円（▲5.0%） | — |
| 営業利益率 | **1.30%**（▲0.12pt） | **1.19%**（▲0.11pt、過去5年で最低の見込み） |

（出典：各社決算・会社予想をAnswersNewsが集計、2026年7月）

増収減益がそのまま数字に出ている。
売上が伸びているのは抗がん剤・希少疾患薬などの高額品が増えたためで、
これらは金額が大きい一方で値引き余地が小さく、在庫と品質管理の負担が重い（→[③](03_業界構造と変化.md) 第6章）。
メディパルHDは薬価制度改革による収益環境の悪化を課題として明示している。

各社が掲げる打ち手は、驚くほど似ている。

| 会社 | 2026年時点で掲げている中心テーマ |
| --- | --- |
| メディパルHD | 高機能物流センター（ALC）と提案型営業（AR）。データ連携で「必要な薬を必要な分だけ自動で届ける」供給網。PALTACとの医療・生活融合 |
| アルフレッサHD | **ロジスティクスネットワークの最適化**を最重要課題に。配送拠点の統廃合と自動化。スペシャリティをかかりつけ医領域に広げる「ネオプライマリー戦略」 |
| スズケン | デジタルプラットフォームに「AI-MS」を組み込むマルチチャネル戦略。**2028年度にデジタルで30億円以上、ロジスティクスで20億円以上**の経常利益（フィービジネス）目標 |
| 東邦HD | 営業と配送の役割分離でMS生産性を上げる。**2028年度に営業利益率1.5%以上**。CDMO・医療機器・検査薬へ多角化 |

> ポイント：4社とも「値上げ」を打ち手に挙げていない（挙げられない）。
> 公定価格の世界では、利益改善の変数は**コストと、卸以外の収益源**しかない。

## 3. メディパルHDがPALTACを完全子会社化（1,924億円）

2026年5月11日、メディパルHDは連結子会社で日用品・化粧品卸大手の **PALTAC** を
TOB（株式公開買付け）で完全子会社化すると発表した。

| 項目 | 内容 |
| --- | --- |
| 買付価格 | 1株 6,650円 |
| 買付総額 | 約 **1,924億円**（報道ベース） |
| 買付期間 | 2026年5月12日〜7月7日（41営業日） |
| 成立 | 2026年7月8日 |
| 完全子会社化 | 2026年8月13日 |
| 事前の保有比率 | メディパルHDがPALTAC株の約52.4%を保有する筆頭株主 |

意味合いは明快だ。**薬価の外にある流通を、連結の内側に完全に取り込む**という判断である。

```
【メディパルHDの二本柱】

  ┌── 医療用医薬品流通（メディセオ 他）──┐
  │   売値の上限 = 薬価（国定）          │  → 利益率は制度で決まる
  └────────────────────────────────────┘
                    ＋
  ┌── 日用品・化粧品・OTC流通（PALTAC）──┐
  │   売値は自由。顧客はドラッグストア    │  → 自力で利幅を作れる
  └────────────────────────────────────┘

  顧客（ドラッグストア）が重なるため、配送と情報の共有余地が大きい。
  一方、日用品流通は小売の価格圧力が強く、薄利という点は共通する。
```

なお PALTAC の完全子会社化に伴い、メディパルHDは2026年度通期の連結業績予想と配当予想を修正している（2026年7月、同社発表）。
ドラッグストア側の構図は [ドラッグストア](../../07_小売・流通/04_ドラッグストア/README.md)、
一般消費財の卸との違いは [食品卸](../06_食品卸/README.md) と読み比べると分かりやすい。

## 4. 後発医薬品の供給不安 — 対策が「産業再編」へ踏み込んだ

2020〜2021年の製造管理不備を発端とする後発医薬品の供給不安（→[②](02_物流と品質管理.md) 第7章）は、
2026年に入って対策の質が変わった。**個社の指導から、産業構造そのものの作り直しへ**移っている。

| 時期 | 動き |
| --- | --- |
| 2026年2月13日 | 中央社会保険医療協議会で、後発品の **薬価削除（市場撤退）ルールの明確化・簡素化**が決定。撤退手続きを簡素にし、経過措置期間の満了日を「3月末」に統一する方向 |
| 2026年2月20日 | 日本ジェネリック製薬協会「産業構造のあり方研究会」報告書を公表 |
| 2026年度診療報酬改定 | 後発品の評価軸を**使用促進から安定供給の評価へ**シフト。供給不安解消を目的とした加算の新設が報じられる |
| 予算措置 | 産業再編支援・備蓄強化・国内生産回帰・リアルタイム需給監視の4本柱で**総額1,000億円超**（うち再編支援に約844億円）と**解説記事ベースで報じられている**。一次情報での確認が望ましい |

需給見通しについては、**2026年度に供給量見込みが試算需要量をほぼ拮抗（+1.6%）し、
2029年度には上回る（+4.3%）**という試算が示されている（業界団体の研究会報告ベース）。

卸にとっての意味は2つ。

1. **撤退ルールの明確化はプラス**。「作り続ける義務が実質的に残る赤字品目」が整理されれば、
   限定出荷と代替探しのコストが減る。
2. **銘柄の集約は在庫効率にもプラス**。同一成分で多数の銘柄を抱える状態は、
   卸の在庫管理コストを直接押し上げていた。

ただし、移行期には「撤退が決まった品目の駆け込み需要」と「代替銘柄への切替」が同時に走るため、
**短期的には現場の混乱コストが増える**点に注意が要る。

## 5. 流通改善と価格交渉 — 代行業者にも目が向く

厚労省は流通改善ガイドラインの運用を段階的に強めている。2024年度以降の主な論点は次の通り。

| 論点 | 中身 |
| --- | --- |
| 単品単価交渉の定義 | 「他の医薬品の価格の影響を受けず、地域差や取引条件で生じる**安定供給に必要なコスト**を踏まえ、個別品目ごとに価格を決める交渉」と整理 |
| 妥結率報告の様式見直し | 2024年度改定で、単品単価契約率・一律値引き契約の報告に代えて、**取引の状況と流通改善の取組状況**の報告を求める形へ変更 |
| 解釈のズレ | 「単品単価交渉」の受け止めが当事者間でずれているとの指摘。報告様式の見直しが検討課題に |
| 価格交渉代行業者 | **医薬品の価値を踏まえた交渉**の遵守状況を確認するよう、厚労省が通知で促している（ミクスOnline 報道） |

> ポイント：未妥結減算（→[①](01_薬価制度が商売を決める.md) 第4章）が「いつまでに決めるか」を縛ったのに対し、
> 流通改善ガイドラインは「**どう決めるか**」を縛ろうとしている。
> 前者は罰則付きで効いたが、後者は遵守事項にとどまるため、実効性は現場の運用次第という段階にある。

## 6. 物流の作り直しが共通テーマに

制度で値段が決まる以上、残る変数は物流コストしかない。2026年時点で各社が進めている打ち手を並べる。

```
【いま各社が手を付けている場所】

  拠点     ─▶ 統廃合。幹線距離の短縮（物流2024年問題への対応も兼ねる）
  庫内     ─▶ 自動倉庫・仕分け自動化・ロボット。人手不足への備え
  温度帯   ─▶ 冷蔵ゾーンの増設。バイオ医薬品の比率上昇に対応
  配送     ─▶ 便数・ルートの見直し、共同配送。ただし欠品は許されないので下限がある
  受発注   ─▶ EDI／自動発注・需要予測AI。MSの受注業務を減らし提案へ振り向ける
  収益化   ─▶ メーカー向け3PL受託、流通データ提供、SPD受託 = フィービジネス化

  ＊ 拠点統廃合（効率）と 拠点分散（災害耐性）は相反する。
    能登半島地震（2024年1月）以降、この両立は各社の課題として残っている。
```

スズケンが「2028年度にロジスティクスで20億円以上の経常利益」と**金額目標**で掲げているのが象徴的で、
物流を社内コストではなく**外販する商品**として扱う方向に、業界全体が動いている。

## 7. 全体の構図

2026年の医薬品卸は、**本業の利益が制度で削られ続ける一方、その外側に活路を求める**という
一本の線で説明できる。
薬価改定（薬剤費ベース▲4.02%）で売上単価は落ち、大手4社の営業利益率は1.19%まで下がる見込みになった。
値上げという手段が制度上存在しないため、各社は物流の統廃合・自動化でコストを削り、
同時にメーカー向け物流受託・データ提供といったフィービジネスと、
薬価の外にある事業（日用品・化粧品、調剤、医療機器、CDMO、動物薬）へ資本を振り向けている。
メディパルHDによるPALTACの完全子会社化は、その最も大きな一手だった。
後発品の供給不安対策が産業再編に踏み込んだことは、中期的には卸の在庫・欠品対応コストを軽くする方向に働くが、
移行期の混乱コストは卸が受け止めることになる。

## 8. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **本改定／中間年改定** | 診療報酬改定と同じ年に行う全面改定と、その間の年に行う改定 |
| **市場拡大再算定** | 想定を超えて売れた薬の薬価を引き下げるルール |
| **共連れ** | 再算定の対象品と似た薬にも引下げを波及させる扱い。2026年度改革で廃止 |
| **不採算品再算定** | 採算割れで供給が危ぶまれる薬の薬価を引き上げるルール |
| **G1ルール** | 後発品に置き換わった長期収載品の薬価を段階的に引き下げ、最終的に市場から退出させる仕組み |
| **長期収載品** | 後発医薬品が発売されている先発医薬品 |
| **薬価削除（経過措置）** | 薬価基準から品目を外すこと。経過措置期間の満了で保険が使えなくなる |
| **TOB** | 株式公開買付け。買付価格・期間を公告して株式を買い集める手法 |
| **フィービジネス** | 商品の売買差益ではなく、サービスの対価（手数料）で稼ぐ事業 |
| **EDI** | Electronic Data Interchange。受発注データを電子的にやり取りする仕組み |
