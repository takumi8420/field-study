# ② 物流と品質管理

このノートで分かること：粗利6〜7%しかない卸が、なぜ**全国即日・翌日配送**と
**温度管理・免許管理**という重装備を背負わされているのか。その費用は誰も払ってくれない。

---

## 1. まず結論：この業界だけ「欠品」の意味が違う

食品卸なら、欠品は「売り逃し」で済む。
医薬品卸では、欠品は **その患者の治療が止まる**ことを意味する。
降圧薬でも抗がん剤でも、代替が効かない薬はいくらでもあるし、
薬は「明日でいいや」が通らない。

だから医薬品卸の物流は、コスト最適ではなく **欠品ゼロ最適**で設計されている。

| 論点 | 一般の卸 | 医薬品卸 |
| --- | --- | --- |
| 欠品の重み | 売り逃し | 治療の中断。社会的な責任問題 |
| 在庫の考え方 | 回転重視。切れてもよい | 動かない薬も置く（フルライン） |
| 配送頻度 | 週数回 | 1日複数便＋緊急配送（夜間・休日も） |
| 品質要件 | 常温中心 | 温度帯ごとの管理、逸脱時の記録と判定 |
| 返品 | 原則不可が多い | 回収・返品の実行部隊を担う |
| コスト転嫁 | 価格に乗せられる | **売値の上限が公定（薬価）なので乗せられない** |

> ポイント：最後の1行がすべて。サービス水準を上げても売値は1円も上がらない。
> [① 薬価制度が商売を決める](01_薬価制度が商売を決める.md) の構造が、物流の議論にも効いてくる。

## 2. 全国配送ネットワークの形

大手卸の物流は、おおむね3層で組まれている。

```
【医薬品卸の物流ネットワーク（典型例）】

  ┌─ 製薬メーカーの物流拠点 ─┐
  └──────────┬───────────────┘
             ▼
  ①【基幹物流センター】 広域をカバー。自動倉庫・仕分け機。温度帯別ゾーン
       数十万〜百万ピース/日を処理。24時間稼働の拠点もある
             ▼
  ②【支店・営業所の在庫拠点】 県〜広域市単位。緊急出荷の最終防衛線
             ▼
  ③【配送便】 自社便＋協力会社。1日複数便。
       病院・診療所・薬局へ ── 当日 or 翌日午前が標準サービス水準
             ▼
       病院・診療所・調剤薬局（→ 患者）

  ＊別系統：メーカー ──▶ 限定流通（特定卸のみ・直送）──▶ 特定の医療機関
```

押さえるべきは次の3点。

- **取扱品目数が桁違い**。医療用医薬品は薬価基準収載で1万数千品目規模あり、
  後発医薬品は同じ成分でも銘柄が多数あるため、実務上の管理コードはさらに増える。
  売れ筋だけ持てばよい商売ではなく、年に数回しか出ない薬も持つ。
- **緊急配送がサービスの本体**。「いま無い」は許されないので、
  営業所在庫から直接走る便、卸同士の融通、メーカー直送の手配まで含めて体制になっている。
- **配送は値段に乗らない**。だからこそ各社は拠点統廃合と自動化にしか手がない。
  実際、大手は中期計画で配送拠点の集約・自動倉庫投資・共同配送を並べている。

### 2024年問題との重なり

トラック運転手の時間外労働上限規制（2024年4月適用、いわゆる物流2024年問題）は、
長距離幹線輸送を持つ医薬品卸にも直撃した。
対応は、拠点を減らして幹線距離を縮める／夜間の積み替えを自動化する／
配送頻度を見直す（ただし欠品は許されないので下げ幅は限られる）という順になる。
→ 物流全体の構図は [陸運・トラック](../../13_運輸・物流/06_陸運・トラック/README.md)、[倉庫・3PL](../../13_運輸・物流/08_倉庫・3PL/README.md) も参照。

## 3. 温度管理とGDP

**GDP**（Good Distribution Practice＝医薬品の適正流通基準）は、
製造所を出てから患者に届くまでの間、薬の品質と同一性を守るための基準。
日本では厚労省が **2018年12月に「医薬品の適正流通（GDP）ガイドライン」** を発出した。
法的な強制力を持つ省令ではなく**ガイドライン**だが、
メーカーが取引先卸に順守を求めるため、実務上は取引条件として機能している。

GDPの柱は大きく3つ。

| 柱 | 具体的にやること |
| --- | --- |
| **温度管理** | 保管・輸送の全区間で規定の温度帯を維持。データロガーで記録し、逸脱したら品質判定を行う |
| **輸送業者の管理** | 委託先の物流会社も含めて手順・記録を管理する（丸投げできない） |
| **偽造医薬品対策** | 正規の流通経路以外から仕入れない。封の確認、記録の保存、疑わしい製品の報告 |

偽造品対策が柱に入っているのは、2017年に国内で **C型肝炎治療薬の偽造品**が
正規の薬局の流通経路に混入した事件があったため。
これを機に、薬機法施行規則が改正され、譲受・譲渡時の**記録と確認の義務**が強化された。

```
【温度帯と、そこに乗る薬】

  ▉ 超低温（−70℃前後）   一部のmRNAワクチンなど。ドライアイス・専用庫
  ▉ 冷凍（−20℃前後）     一部の生物学的製剤
  ▉ 冷蔵・冷所（2〜8℃）   ワクチン、インスリン、バイオ医薬品、血液製剤
  ▉ 室温（1〜30℃）       大半の内服薬・外用薬
  ▉ 常温（15〜25℃）      規定のある製品

  ─────────────────────────────────────────
  保管（倉庫の温度帯ゾーン）→ 積込 → 幹線輸送 → 支店 → 配送車 → 納品
       ↑ この全区間で記録が要る。「積み替えの5分」も逸脱になりうる
```

冷蔵品の比率はバイオ医薬品の増加とともに上がっており、
**冷蔵ゾーンの増設と保冷輸送の投資**が卸の設備投資の中心テーマの一つになっている。
→ 高額薬・バイオ医薬品の話は [③ 業界構造と変化](03_業界構造と変化.md)。

## 4. 免許の束 — 医薬品卸は「許可の集合体」

卸売販売業許可だけでは、扱えない薬が山ほどある。

| 対象 | 根拠法 | 求められること |
| --- | --- | --- |
| 医療用医薬品全般 | 薬機法（卸売販売業許可、都道府県知事） | 管理薬剤師の設置、構造設備基準、譲受・譲渡記録 |
| **麻薬** | 麻薬及び向精神薬取締法（**麻薬卸売業者免許**、都道府県知事） | 施錠可能な堅固な設備で保管、帳簿、譲渡・譲受の届出、事故時の届出 |
| **向精神薬** | 同法（向精神薬卸売業者免許） | 盗難防止措置、記録 |
| **覚醒剤原料** | 覚醒剤取締法 | 取扱者の指定、厳格な記録 |
| **毒薬・劇薬** | 薬機法 | 他の薬と区別して保管。毒薬は施錠 |
| **特定生物由来製品**（血液製剤など） | 薬機法 | 使用記録の保存。医療機関側は**20年間**の記録保存が求められる |
| **再生医療等製品** | 薬機法 | 温度管理と追跡。多くは限定流通 |
| **治験薬・未承認薬** | 個別の取り決め | 通常の卸流通と別建てになることが多い |

つまり、医薬品卸の倉庫は「温度帯 × 法規制」の二次元でゾーニングされている。
新規参入が事実上不可能なのは、この積み上げを全国の拠点数だけ作り直さねばならないからだ。

### トレーサビリティ

2021年4月以降、製造販売業者には医療用医薬品への **GS1バーコード表示**が求められるようになり
（調剤包装単位・販売包装単位・元梱包装単位）、
商品コードに加えて有効期限・製造番号（ロット）を機械可読で持てるようになった。
これにより、回収時に「どのロットがどこへ行ったか」を追える下地ができた。

## 5. 返品と回収 — 実行部隊は卸

薬の回収は、健康被害のリスクに応じて3段階に分けられる。

| クラス | 意味 | 対応の緊急度 |
| --- | --- | --- |
| **クラスI** | 使用により重篤な健康被害・死亡のおそれ | 最優先。夜間・休日も動く |
| **クラスII** | 一時的・医学的に治癒可能な健康被害のおそれ | 速やかに回収 |
| **クラスIII** | 健康被害のおそれはまず考えられない（表示ミス等） | 通常の回収 |

回収を決めるのはメーカーだが、**現場で薬を引き上げるのは卸**である。
納入先の医療機関・薬局の在庫を特定し、連絡し、代替品を手配し、引き取り、記録を残す。
クラスIなら数日で全国を回る必要があるし、その間の代替品供給も同時に要求される。

```
【回収が起きたときに卸で走る処理】

  メーカーの回収決定
        │
        ├─▶ 納入実績の抽出（ロット単位）… どの施設に何本行ったか
        ├─▶ 全対象施設へ連絡 …………… MSが電話・訪問
        ├─▶ 代替品の確保 ……………… 他メーカー品・他営業所在庫・卸間融通
        ├─▶ 現品の引き上げと隔離保管 … 誤出荷防止のため物理的に分ける
        └─▶ 記録の作成・報告 ………… 行政・メーカーへ

  この全部が「卸の粗利の中」で行われる。回収費用の精算はメーカーとの個別交渉次第。
```

通常の**返品**も同様に卸が吸収しがちで、
期限切れ間近の在庫、包装変更、規格変更といった事情の返品が日常的に発生する。
流通改善の議論では「返品ルールの明確化」も論点になっている。

## 6. 災害時の供給責任

医薬品卸は法律上の指定公共機関ではないが、実務では **都道府県と災害時の供給協定**を結び、
災害時に医薬品を運ぶ役割を担っている。
2011年の東日本大震災、2016年の熊本地震、2024年1月の能登半島地震などで、
道路寸断のなか卸が拠点・在庫・車両を出して供給を維持した例が報告されている。

災害時に効いてくるのは、平時の重装備そのものだ。

| 平時の投資 | 災害時に効くこと |
| --- | --- |
| 拠点の分散と相互バックアップ | 被災拠点の機能を隣接拠点が肩代わり |
| フルラインの在庫 | 何が必要になるか読めない状況で、まず出せる |
| 自社配送網と社員ドライバー | 委託任せでは動けない状況で走れる |
| 非常用電源つきの冷蔵設備 | 停電時にワクチン等を守る |

ただし、拠点統廃合（コスト削減）と拠点分散（災害耐性）はトレードオフの関係にある。
効率化圧力が強まるほど、この緊張は増す。

## 7. 後発医薬品の供給不安がもたらした負荷

2020年12月の小林化工による睡眠導入剤混入事案、2021年の日医工の業務停止処分をきっかけに、
後発医薬品メーカーの製造管理の不備が次々に明らかになり、
業務停止・自主回収・出荷調整が連鎖した。
結果、**限定出荷・供給停止の品目が数千規模**に達する状態が長く続いた。

これは卸にとって、売上が増えないのにコストだけが増える最悪の形で効いた。

```
【供給不安が卸のコストになる経路】

  メーカーの限定出荷
        ↓
  ① 数量の按分（アロケーション）… 誰にいくつ配るかを卸が決めることに
        ↓
  ② 代替銘柄の探索 ………… 同一成分の他社品を探し、価格も交渉し直す
        ↓
  ③ 問い合わせ対応 ………… 薬局・病院からの電話がMSに集中
        ↓
  ④ 分納・小口配送の増加 … 1回で届けられず配送回数が跳ね上がる
        ↓
  ⑤ 在庫の膨張 …………… 手に入るうちに確保する動きで在庫日数が伸びる

  → 売上はほぼ増えないまま、販管費と運転資金だけが増える
```

国の対策は2020年代半ばから本格化し、少量多品種の是正、企業間の連携・再編の促進、
薬価上の手当（不採算品再算定の適用拡大）、供給状況の可視化（供給状況報告の仕組み）などが進んだ。
2026年時点の最新状況は [④ 直近トピック](04_直近トピック_2026.md) にまとめている。
後発品側の事情は [後発医薬品](../../09_医薬・医療・ヘルスケア/02_後発医薬品/README.md)。

## 8. 物流を「コスト」から「商品」に変える試み

薄利のなかで各社が共通して狙っているのが、**物流と情報を有料サービスにする**ことだ。

| 取り組み | 中身 | 収益化の考え方 |
| --- | --- | --- |
| 医薬品専用の3PL受託 | メーカーの製品物流を丸ごと受託（保管・輸配送・返品処理） | 物流フィー。薬価改定の影響を受けにくい |
| 治験薬・再生医療等製品の取扱い | 超低温・厳格なトレーサビリティが要る領域 | 高難度＝高フィー |
| 流通・販売データの提供 | どの施設で何がどれだけ動いたかをメーカーへ | データフィー |
| 医療機関の院内物流（SPD）受託 | 病院内の物品管理・供給を請け負う | 業務委託料 |
| 需要予測・自動発注 | AIで発注と在庫を最適化し、欠品と過剰を同時に減らす | コスト削減＋顧客の囲い込み |

> ポイント：「配送料を取る」のは簡単ではない（買い手は薬価差の範囲で動いている）。
> そこで各社は、**メーカー側から物流費をもらう**方向に舵を切っている。
> 卸の顧客が医療機関だけでなくメーカーにもなる、という転換だ。

## 9. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **GDP** | Good Distribution Practice。医薬品の適正流通基準。日本では2018年12月にガイドラインが発出 |
| **GMP** | Good Manufacturing Practice。製造管理・品質管理の基準。GDPの前工程にあたる |
| **温度逸脱** | 規定の温度帯を外れること。記録に残し、品質への影響を判定する必要がある |
| **データロガー** | 輸送・保管中の温度を連続記録する機器 |
| **フルライン** | 売れ筋に限らず全品目をそろえること。医薬品卸の基本サービス |
| **緊急配送** | 通常便とは別に、要請を受けてその場で走る配送 |
| **麻薬卸売業者免許** | 麻薬を卸売するために必要な都道府県知事の免許。保管設備と帳簿が厳格 |
| **特定生物由来製品** | 血液製剤など、人・動物由来の原料を使う製品。使用記録の長期保存が求められる |
| **GS1バーコード** | 商品コード・有効期限・ロット番号を機械可読で持つ標準バーコード。2021年4月以降、医療用医薬品に表示 |
| **回収クラスI/II/III** | 健康被害リスクに応じた回収の区分 |
| **限定出荷** | メーカーが出荷量を絞ること。卸が配分を調整せざるを得なくなる |
| **アロケーション** | 不足時に得意先へ数量を割り振ること |
| **SPD** | Supply Processing and Distribution。病院内の物品管理・供給業務。卸が受託することがある |
| **物流2024年問題** | トラック運転手の時間外労働上限規制（2024年4月適用）による輸送能力の制約 |
