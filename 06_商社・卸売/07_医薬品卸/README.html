医薬品卸

学習済み更新 2026-09-20商社・卸売
あこのページの単語集用語に触れると意味を確認できます11語
薬価薬価差仕切価納入価一次売差リベート／アローアンス未妥結減算総価取引MSGDPスペシャリティ医薬品

製薬メーカーが作った薬を、全国の病院・診療所・薬局へ届ける流通業。
ただの物流業ではなく、売る値段の上限を国が決めている点が決定的に特殊だ。
保険で使われる薬にはすべて 薬価（やっか＝国が定める公定価格）が付いていて、
医療機関・薬局はその薬価で保険に請求し、卸からはそれより安く仕入れる。
この差額が医療機関・薬局の収益になるので、卸は「薬価より必ず安く売る」ことしかできない。

そのうえ薬価は改定のたびに下がり続ける。
結果、売上10兆円超の大手4社が横並びで 営業利益率1%台という、
日本の大企業のなかでも突出して薄い利益で回る産業になっている。
制度が商売の形をここまで直接に決めている業界は、そう多くない。

1. 業界の定義・範囲

法律上は、医薬品医療機器等法（薬機法）の 卸売販売業許可（都道府県知事の許可）を受けて、
医療機関・薬局・他の卸に医薬品を販売する事業者を指す。
一般消費者には売れない（売れるのは薬局・店舗販売業）。

この業界の主戦場は 医療用医薬品（処方箋が要る薬）で、市場の大半を占める。

【医薬品が患者に届くまで】

 製薬メーカー ──▶ 医薬品卸 ──▶ 病院・診療所 ──▶ 患者
   （製造）      （流通）    │
                            └─▶ 調剤薬局 ──▶ 患者

 お金は逆向きに流れ、さらに 保険者（健保・国保）→ 医療機関・薬局 の
 公的保険からの支払いが乗る。つまり最終的な支払者の7〜9割は「保険」。
隣接業界 境界線
医薬品（新薬）メーカーは薬を創り・作り・薬価を交渉する側。卸は買って運んで売る側。メーカーの営業（MR）は情報提供、卸の営業（MS）は価格交渉と受注
後発医薬品後発品メーカーの供給不安は、そのまま卸の欠品対応コストになる。→ ②
調剤薬局卸の最大の得意先。チェーンの大型化＝卸にとっての価格交渉相手の巨大化。→ ③
医療機関・医療サービス病院も得意先。入札（一般競争入札）で買う公的病院が多く、ここが談合事件の舞台になった
ドラッグストア一般用医薬品（OTC）・化粧品・日用品の流通は別系統の卸が担う（PALTAC など）
倉庫・3PL医薬品卸は自前で全国の物流センターを持つ「荷主かつ物流会社」。温度管理と法規制のぶん一般3PLでは代替しづらい
食品卸同じ卸でも、食品卸は値決めが自由。医薬品卸は上限価格が国定という点だけが違い、そこから収益構造の差が全部生まれる

含まれないもの：一般用医薬品（OTC）専業卸、医療機器専業ディーラー、原薬・治験薬の輸送を担う専門物流会社。
ただし大手4社はいずれも医療機器・検査試薬・動物用医薬品などへ手を広げており、境界は実務上あいまい。

2. 市場規模と成長性

指標 数値 出典・年
大手4社（メディパル・アルフレッサ・スズケン・東邦）の売上高合計10兆9,614億円（前期比3.9%増）各社決算、2026年3月期（AnswersNews 集計）
同 営業利益合計／営業利益率1,423億円（5.0%減）／1.30%同上、2026年3月期
同 2027年3月期の営業利益率予想1.19%（過去5年で最低の見込み）各社会社予想、2026年7月時点
医薬品・化粧品卸売業の販売額39兆3,760億円（前年比0.5%増、5年連続増）経産省 商業動態統計、2025年
2026年度薬価改定率医療費ベース ▲0.86%／薬剤費ベース ▲4.02%厚労省告示、2026年4月1日実施

成長の読み方は独特だ。数量（処方される薬の量）は高齢化で増えるが、単価（薬価）は制度で下がる。
だから売上は「高額な新薬がどれだけ市場に出るか」でしか伸びない。
実際、直近の増収は抗がん剤・希少疾患薬などの高薬価品が牽引している。
一方、利益は薬価改定のたびに削られるので、増収減益が業界の常態になっている。

3. バリューチェーン（川上 → 川下）

【価格の4層構造 — ここが医薬品卸の核心】

                     国が決める上限  ┌──────────── 薬価（公定価格） ────────────┐
                                     │                                          │
  メーカー ──仕切価──▶ 卸 ──納入価──▶ 医療機関・薬局 ──薬価で請求──▶ 保険者・患者
              (建値)        (実売価)                    │
                 ▲                                      └─ 薬価 − 納入価 = 薬価差
                 │                                         （医療機関・薬局の収益）
        リベート・アローアンス
        （メーカーから卸への事後的な戻し）

  卸の粗利 = (納入価 − 仕切価) + リベート + アローアンス
             ↑ここがしばしばマイナス（＝一次売差マイナス／逆ザヤ）

付加価値がどこに溜まるかは、この図がすべてを語る。
薬価という天井が決まっているため、卸が値引きすれば薬価差＝医療機関・薬局の利益になる。
卸はその値引きの原資を、自分の粗利ではなくメーカーからの事後的な戻し（リベート）に頼る。
詳しくは ① 薬価制度が商売を決める。

4. 主要プレイヤーとシェア

企業 売上規模の目安 立ち位置・特徴
メディパルホールディングス連結3兆6,713億円（2025年3月期）業界最大手。医療用医薬品のメディセオに加え、日用品・化粧品卸の PALTAC を2026年8月に完全子会社化。「医療と生活」の二本柱
アルフレッサホールディングス連結2兆9,610億円（同）2位。MS（営業）人数が業界最多とされ、スペシャリティ医薬品をかかりつけ医領域まで広げる戦略。製薬（アルフレッサ ファーマ）も持つ
スズケン連結2兆3,999億円（同）3位。製薬子会社の三和化学研究所、医療機器・在宅介護まで垂直に広い。「次世代卸」を掲げデジタル／物流のフィービジネス化を志向
東邦ホールディングス連結1兆5,184億円（同）4位。調剤薬局事業（共創未来グループ）を自ら抱えるのが特徴。営業と配送の役割分離で生産性を上げる方針
地域卸（バイタルケーエスケーHD、ほくやく・竹山HD ほか）数千億円規模特定地域に密着。大手の資本が入っているケースも多い

上位4社で医療用医薬品流通の 8割超を占めるとされる（報道・調査ベース、2020年代半ば）。
4社が全国をカバーし、そこに地域卸がぶら下がる構図。→ ③ 業界構造と変化

5. 収益モデル・コスト構造

売上100に対しておおよそこうなる（大手4社の平均的な姿、2020年代半ばの目安）。

項目 売上比 中身
売上高100納入価×数量
売上原価93〜94仕切価ベースの仕入からリベート・アローアンスを差し引いた最終原価
売上総利益6〜7いわゆる「売差＋リベート等」の合計
販管費5〜6MSの人件費、配送費、物流センターの償却、システム
営業利益約1.2〜1.32026年3月期の4社平均は1.30%

ポイント：粗利が6〜7%しかない商売で、販管費がその大半を食う。
だから 薬価改定で粗利が0.5ポイント削られるだけで営業利益は半減しうる。
卸の経営が「物流効率化」一色になるのは、それ以外に動かせる変数がほとんどないから。

6. 競争要因（KSF）と参入障壁

要因 中身
全国配送ネットワーク当日・翌日で全国どこへでも届ける拠点網と車両。新規に作るのは事実上不可能
品揃え（フルライン）数万品目を切らさず持つ。1品目の欠品で取引全体を失いかねない
許認可の束卸売販売業許可に加え、麻薬卸売業者免許、向精神薬、毒劇物、再生医療等製品など個別の免許 → ②
メーカーとの取引条件リベート・アローアンスの条件が利益を直接決める。規模が大きいほど有利
与信と資金力医療機関の支払サイトは長く、在庫と売掛で巨額の運転資金が要る
情報・データ需要予測、流通実績データ（メーカーへの提供）が新しい収益源になりつつある

参入障壁はきわめて高い一方、その障壁の中で儲かるわけではないのがこの業界の皮肉なところだ。
天井（薬価）が国定で、顧客（医療機関・薬局）は大型化し、仕入先（メーカー）は数社に集約されている。
川上と川下の両方が強く、真ん中の卸が最も弱い。

7. 規制・法制度

制度 内容 卸への効き方
薬機法 卸売販売業許可都道府県知事の許可。管理薬剤師の設置、構造設備基準事業そのものの免許
薬価基準保険が払う公定価格。厚労省告示売価の上限を国が決める
薬価改定2年に1度の本改定＋中間年改定。市場実勢価格の加重平均＋調整幅2%毎年価格が下がる
未妥結減算（2014年度〜）9月末時点の妥結率が50%以下の病院・薬局は診療報酬を減算価格交渉に期限を課す規制
流通改善ガイドライン（2018年、2021年・2024年改訂）単品単価交渉、一次売差マイナスの是正、期中の安易な値引き要求の抑制交渉のルールブック
麻薬及び向精神薬取締法麻薬卸売業者免許、施錠保管、帳簿・届出取扱いに別免許が要る
GDPガイドライン（2018年12月発出）医薬品の適正流通基準。温度管理、輸送業者管理、偽造品対策物流の品質要件
独占禁止法入札談合の摘発事例あり（2020年告発、2022年課徴金）官公需の取引慣行を変えた

制度の詳細は ①（価格系）と ②（品質・安全系）に分けて書いた。

9. 用語メモ

用語 意味
薬価保険で使える薬の公定価格。国（厚労省）が告示で決める上限価格 → ①
薬価差薬価 − 実際の納入価。医療機関・薬局の収益になる。かつて「薬価差益」と呼ばれた
仕切価メーカーが卸へ売る建値。薬価に対する割合を「仕切価率」という
納入価卸が医療機関・薬局へ売る実売価格
一次売差納入価 − 仕切価。マイナス（逆ザヤ）になることが多い
リベート／アローアンスメーカーが卸へ事後的に払う割戻し・販促費。卸の粗利の大部分
未妥結減算価格が決まらないまま取引を続ける病院・薬局の診療報酬を減らす制度
総価取引品目ごとではなく「まとめて何%引き」で決める取引。流通改善で是正対象
MSMarketing Specialist。卸の営業担当。メーカーのMR（情報提供）とは役割が違う
GDPGood Distribution Practice。医薬品の適正流通基準 → ②
スペシャリティ医薬品抗がん剤・希少疾患薬など、高額で取扱いが難しい薬 → ③
