# ① 薬価制度が商売を決める

このノートで分かること：**売値の上限を国が決めている**という一点から、
医薬品卸の粗利・値引き交渉・利益率1%までがどう導かれるのか。

---

## 1. まず結論：卸は「値下げしかできない」商売

保険で使われる薬にはすべて **薬価**（やっか）が付いている。
薬価とは、厚生労働省が告示で定める **公定価格＝保険が払う値段**のこと。
医療機関や薬局が患者に薬を使ったとき、保険に請求できるのはこの薬価であって、
それより高くも安くも請求できない。

ここから3つの帰結が自動的に出てくる。

1. 医療機関・薬局が儲けようと思ったら、**薬価より安く仕入れる**しかない。
2. その仕入れ先は卸だから、**卸は必ず薬価より安く売る**ことになる。
3. 薬価と実際の仕入値の差＝**薬価差**が、医療機関・薬局の収益になる。

```
【薬価差とは何か — 1錠100円の薬で考える】

  薬価 100円  ←── 医療機関はこの100円を保険に請求できる
     │
     │  卸から 88円 で仕入れた場合
     ▼
  納入価 88円 ─────────┐
                        │
   薬価差 = 100 − 88 = 12円  ← これが医療機関・薬局の粗利になる
                        │
  卸の取り分は「88円で売って、いくらで仕入れたか」だけ
```

> ポイント：卸の値引きは、そのまま医療機関・薬局の利益に変わる。
> だから買い手には「もっと引け」と言い続ける強い動機がある。
> 値引き競争の相手が価格ではなく**制度そのもの**にいる、というのがこの業界の出発点。

## 2. 価格の4層構造 — 仕切価・納入価・リベート

卸の損益を理解するには、薬1つに4つの値段があることを押さえる。

| 呼び名 | 誰が誰に付ける値段か | 決め方 |
| --- | --- | --- |
| **薬価** | 国が定める、保険が払う上限 | 厚労省告示。改定で下がる |
| **仕切価**（しきりか） | メーカー → 卸 の建値（伝票上の仕入値） | メーカーが提示。薬価に対する比率を「仕切価率」という |
| **納入価** | 卸 → 医療機関・薬局 の実売価格 | 個別交渉。薬価より必ず安い |
| **最終原価** | 仕切価からリベート等を引いた、卸の実質の仕入値 | 事後に確定する |

問題は **納入価 − 仕切価**（これを **一次売差** という）が、しばしば**マイナス**になること。
つまり卸は、伝票上は仕入値より安く売っている。これを **一次売差マイナス（逆ザヤ）** と呼ぶ。

ではなぜ潰れないのか。メーカーが事後的に **リベート（割戻）** と **アローアンス（販売促進費）** を卸へ払うからだ。

```
【卸の粗利がどう組み上がるか】

  仕切価 92 ──────────────────────────┐ （メーカーからの仕入、伝票上）
                                       │
  納入価 88 ────────────┐              │
                         │              │
   一次売差 = 88 − 92 = ▲4  ← 逆ザヤ！  │
                         │              │
   + リベート（割戻）   +5  ─── 二次差益と呼ばれることがある
   + アローアンス       +2  ─── 三次差益と呼ばれることがある
                       ────
   卸の粗利            +3   （売上88に対して約3.4%）
```

この構造には副作用がある。
**卸の利益がメーカーの匙加減で決まる**ということだ。
リベート条件はメーカーとの年度交渉で決まり、卸は値引きしても「あとで戻ってくる」前提で走る。
結果として、卸は自分の粗利を正確に見ないまま価格を出しやすくなる。
厚労省が流通改善で「一次売差マイナスの是正」を求めているのは、この不透明さが理由だ（後述・第6章）。

## 3. 薬価はどう決まり、どう下がるのか

新しい薬が保険に載るとき（**保険収載**）、薬価は次のどちらかで決まる。

| 算定方式 | どんなときに使うか | 考え方 |
| --- | --- | --- |
| **類似薬効比較方式** | 似た働きの既存薬がある | その薬の1日薬価に揃える。画期性・有用性などがあれば補正加算 |
| **原価計算方式** | 似た薬がない | 原材料費＋製造経費＋販管費＋営業利益＋流通経費＋消費税を積み上げる |

注目すべきは、原価計算方式に **流通経費** という項目が最初から入っていること。
つまり制度は「卸に渡す取り分」を織り込んでいる建前になっている。
ただしその率は決め打ちであり、実際に卸がいくら取れるかは交渉で決まる。

### 改定のしくみ

いったん決まった薬価は、その後ひたすら下がっていく。

```
【薬価改定のサイクル】

  ① 薬価調査（毎年9月頃）
     卸の販売実績＝実際の納入価を国が全数に近い形で調べる
             ↓
  ② 市場実勢価格の加重平均を出す
             ↓
  ③ 新薬価 = 加重平均値 × (1 + 消費税) + 調整幅（薬価の2%）
             ↓
  ④ 翌年度4月から新薬価で運用 ──▶ また ① へ

  ＝ 値引きすればするほど、翌年の公定価格が下がる
```

**調整幅2%** は、流通コストや地域差を吸収するための緩衝材として置かれている数字で、
実務的には「卸と医療機関に残される最低限の値差」とも言われる。

改定の頻度は2021年度から変わった。
それまでは診療報酬改定と同じ2年に1度だったが、**中間年（改定のない年）にも改定を行う**ことになり、
実質的に**毎年薬価が下がる**体制になった。卸から見れば、粗利が毎年リセットされるということだ。

| 改定の種類 | いつ | 中身 |
| --- | --- | --- |
| **本改定** | 診療報酬改定と同じ年（偶数年度） | 全品目対象。ルール改正も同時 |
| **中間年改定** | 奇数年度 | 乖離率が大きい品目を中心に引下げ |
| **市場拡大再算定** | 改定時 | 売れすぎた薬を引き下げる。2026年度は13成分31品目、最大40%超の引下げ |
| **不採算品再算定** | 改定時 | 採算が取れず供給が危うい薬を**引き上げる**数少ない仕組み。2026年度は232成分704品目 |
| **長期収載品の引下げ（G1/G2/Z2）** | 改定時 | 後発品が出た先発品を段階的に下げる。2026年度改革でG1適用が後発品上市後10年→**5年**に前倒し |

2026年度改定（2026年4月1日実施）の改定率は、**医療費ベース▲0.86%／薬剤費ベース▲4.02%**（厚労省告示）。
薬剤費ベースで4%落ちるということは、卸の売上単価が4%落ちるということでもある。

## 4. 未妥結減算 — 価格交渉に期限を課した規制

薬価が毎年、納入価の実績をもとに決まる以上、**納入価が決まらないと制度が回らない**。
ところが実務では「とりあえず納品してもらい、値段は後で」という **未妥結・仮納入**が長く横行していた。
半年、1年と価格が決まらないまま薬が流れ、薬価調査のデータも実態を映さなくなる。

そこで2014年度診療報酬改定で導入されたのが **未妥結減算** だ。

```
【未妥結減算の仕組み】

  4月 ───────────── 9月末 ────────────▶ 翌年3月
   価格交渉スタート      ここで妥結率を判定

   妥結率 = 妥結した取引金額 ÷ 総取引金額

   妥結率 50%以下 の 200床以上の病院・保険薬局
        ↓
   初診料・調剤基本料などが減算される（収入が減る）
        ↓
   → 買い手側に「9月までに価格を決める」強い動機が生まれる
```

対象は200床以上の病院と保険薬局で、妥結率などを地方厚生局に報告する義務も負う。
2024年度改定では報告様式が見直され、妥結率に加えて **流通改善ガイドラインを踏まえた取組状況**の報告も求められるようになった。

卸にとっての効き方は両面ある。
- 良い面：だらだら続く未妥結が減り、資金繰りと薬価調査の精度が改善した。
- 悪い面：**9月末という締切が買い手に握られている**ため、期限直前に強い値引き要求が集中しやすい。

## 5. 総価取引という積年の問題

**総価取引**とは、品目ごとに値段を決めず、「今回納入する薬を全部まとめて薬価の◯%引き」で決める買い方をいう。
買う側は交渉が1回で済み、卸も交渉工数を減らせるので、長く慣行として続いてきた。

| | 総価取引 | 単品単価取引 |
| --- | --- | --- |
| 決め方 | 全品まとめて一律◯%引き | 1品目ごとに価格を決める |
| 買い手の手間 | 小さい | 大きい |
| 薬の価値の反映 | されない。新薬も old な薬も同じ率 | 価値・安定供給コストが価格に乗る |
| 薬価調査への影響 | **歪む**。個別品の実勢価が分からない | 実勢価がそのまま取れる |
| 卸の粗利 | 読めない。赤字品目が混ざる | 品目ごとに管理できる |

問題の本質は、**総価で決めた値引きを、後から品目ごとに機械的に割り付けるしかない**点にある。
割り付け方によって「その薬がいくらで売れたか」の記録が変わり、その記録が翌年の薬価になる。
つまり、総価取引は薬価制度の土台であるデータを汚す。

厚労省の **流通改善ガイドライン**（2018年策定、2021年11月改訂・2022年1月適用、その後も改訂）は、
① 単品単価交渉の推進、② 一次売差マイナスの是正、③ 期中の安易な値引き要求の自粛、④ 頻繁な価格交渉代行への牽制、
などを関係者の遵守事項として掲げている。
2024年度以降は「単品単価交渉」の定義も整理され、
**他の医薬品の価格に影響されず、安定供給に必要なコストを踏まえて個別品目ごとに決める交渉**とされた。

それでも現場では、**価格交渉代行業者**（薬局チェーンなどに代わって一括交渉する事業者）の台頭もあって、
実質的な総価交渉は残っているとされる。→ 買い手側の構造は [③ 業界構造と変化](03_業界構造と変化.md) を参照。

## 6. なぜ営業利益率が1%前後になるのか

ここまでを1つの図にまとめると、卸の利益が薄い理由が見える。

```
【卸の利益を上下から挟む3つの力】

           ┌──────────────────────────────────┐
  上から：  │ 薬価（公定価格）が毎年下がる      │ → 売上単価が毎年削れる
           └──────────────────────────────────┘
                          ↓
           ┌──────────────────────────────────┐
  横から：  │ メーカーの仕切価率は下がりにくい  │ → 仕入値は硬直的
           │ リベート条件もメーカーが握る      │
           └──────────────────────────────────┘
                          ↓
           ┌──────────────────────────────────┐
  下から：  │ 買い手（病院・薬局チェーン）が大型化 │ → 値引き要求が強まる
           │ 総価・交渉代行で圧力が組織化       │
           └──────────────────────────────────┘
                          ↓
              残る粗利 6〜7% − 販管費 5〜6% = 営業利益 約1%
```

そのうえ、この1%の商売に **欠品が許されない物流**（[②](02_物流と品質管理.md)）という重いコストが乗る。
全国即日配送、温度管理、免許品の管理、返品・回収対応——これらは値段に転嫁できない。
公定価格の世界では、サービスを良くしても売値は上がらないからだ。

| 指標 | 2026年3月期（実績） | 2027年3月期（会社予想） |
| --- | --- | --- |
| 大手4社 売上高合計 | 10兆9,614億円（+3.9%） | 11兆2,520億円（+2.65%） |
| 大手4社 営業利益合計 | 1,423億円（▲5.0%） | — |
| 大手4社 営業利益率 | 1.30%（▲0.12pt） | **1.19%**（▲0.11pt、過去5年最低の見込み） |

（出典：各社決算・会社予想をAnswersNewsが集計、2026年7月）

> ポイント：この業界の利益率は「経営が下手だから低い」のではなく、
> **制度設計上そうなるように出来ている**。
> だから各社の中期計画は例外なく「物流の効率化」と「卸以外の収益源」の2本立てになる。

## 7. 制度が変わると何が起きるか（読み方の練習）

制度ニュースを見たときに、卸への影響を推し量る型を示す。

| 制度の動き | 卸への一次的な影響 | なぜそうなるか |
| --- | --- | --- |
| 薬価改定率が大きい | マイナス | 手持ち在庫が改定日に一斉に値下がりする（**改定時の在庫評価損**）＋売上単価減 |
| 中間年改定の対象拡大 | マイナス | 粗利の回復期間が短くなる |
| 不採算品再算定の拡大 | ややプラス | 赤字品目が減り、供給も安定する |
| 長期収載品のG1前倒し | マイナス | 単価の高い先発品が早く安くなる |
| 高額な新薬の増加 | 売上プラス／利益率マイナス | 金額は大きいが値引き余地が小さく、在庫リスクと資金負担は重い |
| 未妥結減算の厳格化 | 中立〜ややプラス | 交渉が早期に決着し資金繰りが読める |
| 流通改善ガイドラインの強化 | プラス（狙いとしては） | 単品単価化で赤字品目が減る。ただし実効性は現場次第 |

## 8. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **薬価** | 保険が払う薬の公定価格。厚労省が告示で定める上限 |
| **薬価基準** | 保険で使える薬のリストと、その薬価をまとめたもの |
| **薬価差** | 薬価 − 納入価。医療機関・薬局の収益になる差額。かつて「薬価差益」と呼ばれた |
| **仕切価** | メーカーが卸に提示する建値。薬価に対する比率が仕切価率 |
| **納入価** | 卸が医療機関・薬局に売る実売価格 |
| **一次売差** | 納入価 − 仕切価。マイナス（逆ザヤ）が常態化している |
| **リベート（割戻）** | 販売実績などに応じてメーカーが卸に事後的に払う金。二次差益とも |
| **アローアンス** | 販売促進を目的にメーカーが卸に払う金。三次差益とも |
| **薬価調査** | 卸の販売実績から実勢価格を調べる国の調査。翌年度の薬価の基礎 |
| **調整幅** | 薬価算定時に加える薬価の2%。流通コスト・地域差の緩衝材 |
| **中間年改定** | 診療報酬改定のない年にも行う薬価改定。2021年度から実施 |
| **市場拡大再算定** | 想定を超えて売れた薬の薬価を引き下げるルール |
| **不採算品再算定** | 採算割れで供給が危ぶまれる薬の薬価を引き上げるルール |
| **未妥結減算** | 9月末時点の妥結率が50%以下の病院・薬局の診療報酬を減算する制度（2014年度〜） |
| **妥結率** | 妥結した取引金額 ÷ 総取引金額 |
| **総価取引** | 品目ごとでなく一括で値引率を決める取引。薬価調査を歪めるため是正対象 |
| **単品単価取引** | 1品目ごとに価格を決める取引。流通改善ガイドラインが求める姿 |
| **流通改善ガイドライン** | 厚労省が示す、医薬品流通の関係者が守るべきルール（2018年〜、以後改訂） |
| **保険収載** | 新薬を薬価基準に載せ、保険で使えるようにすること |
