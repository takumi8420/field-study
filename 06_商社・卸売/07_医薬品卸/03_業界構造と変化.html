このノートで分かること：400社あった医薬品卸がなぜ4社に集約されたのか、
そして寡占になったはずなのに、なぜ値決めの主導権を持てないのか。

1. まず結論：寡占なのに弱い

医薬品卸は上位4社で医療用医薬品流通の 8割超を占めるとされる（報道・調査ベース、2020年代半ば）。
普通なら、ここまで集約されれば値決めの力を持つ。
ところが医薬品卸の営業利益率は1%台（①）で、寡占の果実がまるで見えない。

理由は3つ。

  1. 売値の天井が国定なので、集約しても価格を上げられない。
  2. 仕入先のメーカーも寡占で、仕切価とリベート条件を握られている。
  3. 買い手（薬局チェーン・病院グループ）が急速に大型化し、交渉力で追い抜かれた。
【交渉力の三角形 — 真ん中が一番弱い】

        製薬メーカー（数十社、製品は代替不能）
              │  仕切価・リベート条件を提示
              │  ＝ 卸の仕入コストを決める
              ▼
      ┏━━━━━━━━━━━━━━━┓
      ┃    医薬品卸 4社      ┃ ← 寡占だが、上下から挟まれる
      ┗━━━━━━━━━━━━━━━┛
              │  納入価を提示（薬価が上限）
              ▼
   薬局チェーン・病院グループ・価格交渉代行
     （1社で数千店舗。総価・一括交渉で値引きを引き出す）

以下、この構図がどう出来たかを時間軸でたどる。

2. 400社から4社へ — 再編の歴史

医薬品卸はもともと、県単位・地域単位の家業的な卸が全国に数百社あった。
それが1990年代以降、次の力で一気に集約した。

時期 何が起きたか 卸が統合に追い込まれた理由
1990年代前半薬価差の縮小政策が本格化。薬価算定に「R幅（後の調整幅）」の段階的縮小薬価差で成り立っていた商売の利幅が細り、規模がないと持たない
1990年代後半メーカーが 仕切価制へ移行し、建値と事後リベートに分離取引条件が規模依存になり、大手が有利に
2000年代大型統合が連続。メディセオ、クラヤ三星堂、アルフレッサ、スズケン、東邦など現在の骨格が固まる物流投資（センター・情報システム）が単独では回収できない
2010年代地域卸が大手グループの傘下に。上位4社体制が固定全国チェーン薬局への対応には全国網が要る
2014年度未妥結減算の導入（→①）価格交渉の期限管理・事務負荷が増え、体力差が出る
2021年度〜中間年改定で毎年薬価が下がる体制に粗利の回復期間が消え、効率化の規模がさらに要る
2020年代後発品の供給不安（→②）、物流2024年問題コストだけが増え、統合・拠点集約が加速

ポイント：この業界の再編は「攻めのM&A」ではなく、制度で利幅を削られた結果の集約だった。
統合しても薬価は上がらないので、統合の目的は一貫して「固定費（物流と情報システム）の共有」にある。

3. いまの主要プレイヤー

グループ 連結売上（2025年3月期） 中核会社 特徴・打ち手
メディパルホールディングス3兆6,713億円メディセオ（医療用医薬品）、PALTAC（日用品・化粧品）、エバルス ほか2026年8月に PALTACを完全子会社化。高機能物流センター（ALC）と、MR認定資格を持つ営業（AR）を軸にした提案型営業

4社はいずれも 卸単体では食えないと判断しており、
製薬、医療機器、調剤薬局、介護、検査、化粧品・日用品、動物用医薬品といった隣接領域へ出ている。
どこまで広げるかが各社の性格の違いになっている。

4. 公取委の入札談合摘発が業界に与えたもの

医薬品卸の取引慣行を最も強く揺さぶった外部ショックが、独占禁止法の摘発だった。

事件の骨格

項目 内容
舞台独立行政法人 地域医療機能推進機構（JCHO） が発注する医薬品の一般競争入札
行為2016年・2018年の入札で、受注予定者をあらかじめ決め、入札価格を記載した連絡票を交換していたとされる
刑事告発2020年12月9日、公正取引委員会がアルフレッサ、スズケン、東邦薬品の3社と関係者7名を検事総長に告発
行政処分2022年、排除措置命令と総額4億2,385万円の課徴金納付命令（アルフレッサ1億7,562万円、東邦薬品1億6,189万円、スズケン8,634万円）

金額そのものは、売上10兆円規模の業界からすれば小さい。
効いたのは金額ではなく、独禁法違反が刑事事件として扱われたという事実のほうだ。

【摘発が業界に残したもの】

  刑事告発（2020年12月）
       │
       ├─▶ 指名停止・入札参加資格の停止 …… 官公需（国公立病院・独法）の商売が一時止まる
       │
       ├─▶ コンプライアンス体制の再構築 …… 他社との接触記録、価格決定の承認フロー、研修
       │
       ├─▶ 価格交渉の「慎重化」 ………… 卸同士の情報交換が事実上できなくなる
       │        ↓
       │   逆説的な効果：買い手（病院・チェーン）の交渉力がさらに強まった
       │
       └─▶ 入札の実務見直し ……………… 発注側も仕様・ロットの作り方を再検討

  ＊背景にあった構造：全国をカバーできる卸が数社しかない入札で、
    毎回ガチンコで叩き合うと全社が赤字受注になる。そこに談合の誘因が生まれていた。

ポイント：寡占（供給者が数社）＋公定価格（利幅が薄い）＋大型入札（落札インパクトが大きい）の3条件が揃うと、
談合の誘因は構造的に生まれる。摘発はそれを断ち切ったが、利幅が薄い構造そのものは残った。
だから業界の関心は「どう交渉で勝つか」から「どうコストを下げるか」へ移った。

5. 買い手の大型化 — 薬局チェーンとGPO

卸の交渉相手は、この20年でまったく別物になった。

買い手の種類 昔 今
調剤薬局門前の個人薬局が主体アインHD、日本調剤、クオール、スギ薬局、ウエルシアなど数百〜数千店舗のチェーンが本部一括で交渉
病院個別病院ごとの購買国立病院機構・自治体病院グループ・大学病院などの共同購買・共同入札
交渉の担い手病院の事務、薬局の薬剤師価格交渉代行業者や共同購買組織（GPO）が代理で交渉
交渉の単位品目ごと全品一括（総価）／年間契約

医薬分業の進展で、処方箋の大半が院外の薬局に回るようになり、
その薬局がチェーン化したことで、卸の売上の大きな塊が少数の本部に集中した。
本部との交渉は1回で数百億円の取引条件が決まるため、卸は降りられない。

さらに 価格交渉代行が入ると、卸は「薬の価値」を説明する相手を失う。
代行業者の評価軸は値引率に寄りやすいからだ。
厚労省は流通改善の通知で、代行業者に対しても
医薬品の価値を踏まえた交渉を行うよう求める方向で運用を強めている。
→ 買い手側の経済構造は 調剤薬局、
医療機関・医療サービス。

6. 高額薬剤・バイオ医薬品が変えた商売の質

ここ10年で、卸が運ぶ薬の中身が大きく変わった。

かつて（プライマリー中心） いま（スペシャリティの比重増）
生活習慣病薬など、患者数が多く単価が低い抗がん剤・希少疾患薬・バイオ医薬品など、患者数が少なく単価が極端に高い
常温・大量・広域配送冷蔵・少量・施設限定配送
病院も診療所も薬局も扱う扱える施設が限られる（限定流通）
値引き交渉の余地がある値引き余地が薄い。高薬価ゆえ薬価差の絶対額は大きいが率は低い
在庫リスクは小さい1箱で数百万〜数千万円。誤配・温度逸脱・期限切れの損失が巨額

再生医療等製品やCAR-T細胞療法のように、1回の投与で数千万円〜1億円超という製品も出てきた。
こうした製品では、卸の役割は「量を運ぶ」から「確実に、記録を残して、1本を届ける」へ変わる。

【売上は増えるのに利益率が下がる理由】

  高額薬1本 1,000万円を納入
        │
        ├─ 売上 ……… +1,000万円  ← 売上規模は跳ね上がる
        ├─ 粗利率 …… 数%以下     ← 値引き余地が小さく率は低い
        ├─ 在庫負担 … 数百万〜数千万円を寝かせる（資金コスト）
        ├─ 品質責任 … 冷蔵切れ・破損 = 全損。保険と管理コスト
        └─ 返品不可 … 期限切れ在庫は自社損

  → 売上高は伸びるが、売上高営業利益率は構造的に下がる

これが「増収なのに利益率が過去最低」という決算が続く理由の一つでもある。

7. メーカー直販・限定流通という揺らぎ

一方で、メーカーが卸を通さない（あるいは卸を絞る）流通も増えている。

形態 内容 卸への影響
限定流通（Limited Distribution）特定の卸だけに取扱いを認める。超高額薬、厳格な温度管理品、副作用管理が必要な薬選ばれれば取扱いを独占できるが、選ばれなければ売上を失う
メーカー直送卸を通さず、医療機関へ直接配送商流から外れる。物流受託で入り込めるかが分かれ目
限定的な直販再生医療等製品など、メーカーが施設認定から管理まで一貫して行う卸は物流・記録の請負に回る
医薬品の受注データ連携EDI・API化で発注自動化MSの受注業務の価値が下がる。提案型へ移らざるを得ない

ポイント：直販が増えるほど「商流（売買差益）」は細り、
「物流・データの受託（フィー）」の比重が増える。
卸がフィービジネスを掲げるのは、この流れに合わせた生存戦略でもある（→② 第8章）。

8. 周辺事業への展開

卸単体の利益率が1%台である以上、各社の成長投資は卸の外にある。

領域 何をしているか 狙い
化粧品・日用品卸メディパルHDがPALTACを完全子会社化（2026年）薬価の外にある流通。ドラッグストア向けで医療用と顧客が重なる → ドラッグストア
調剤薬局東邦HDの共創未来グループ、地域卸の薬局事業川下を自ら押さえる。ただし調剤報酬改定のリスクを別に背負う
医薬品製造アルフレッサ ファーマ、三和化学研究所（スズケン）製造側の利幅を取りに行く
医療機器・検査試薬各社が卸機能を拡張。地域卸は機器卸を中核に持つ例も顧客（病院）が同じで、販路を共用できる
CDMO・再生医療支援受託製造・製造支援。アルフレッサ、東邦などが言及高難度領域でフィーを取る
動物用医薬品大手グループが動物薬の卸機能を持つ薬価制度の外側。ペット市場の成長 → 動物用医薬・ペット医療
在宅医療・介護在宅向け医療材料、介護用品、施設向けサービス高齢化で伸びる需要。医療と介護の連携が政策の方向

いずれも「薬価の外へ出る」という一点で共通している。
逆に言えば、卸の本業を伸ばす打ち手が制度上ほとんど存在しないということでもある。

9. この業界の見方（まとめの視点）

見るべき指標 なぜ見るか
売上総利益率（6〜7%が目安）薬価改定と価格交渉の結果がここに出る。0.1ポイントの変化が営業利益を大きく動かす
営業利益率（1%台）業界の体温計。1.5%が各社の中期目標ラインになっている
棚卸資産回転日数供給不安時には伸び、効率化が効けば縮む
改定期の在庫評価損薬価改定日をまたぐ在庫が一斉に値下がりする。改定年度の第1四半期に効く
スペシャリティ比率上がるほど売上は増え、利益率は下がりやすい
