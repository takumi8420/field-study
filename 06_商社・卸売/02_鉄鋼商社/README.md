# 鉄鋼商社

- 大分類: 商社・卸売
- 状態: done
- 更新日: 2026-09-20

鉄鋼メーカー（高炉・電炉）がつくった鋼材を、自動車・建設・造船などの使い手へ届ける流通の担い手。
ただし「運ぶだけ」ではなく、**切る・曲げるという加工**と、**代金を立て替える与信**と、**在庫を持つ危険の肩代わり**の3つを引き受けることで口銭（こうせん＝手数料）を得ている業種である。

## 1. 業界の定義・範囲

鉄鋼商社とは、**鋼材（鉄の板・棒・形鋼・鋼管など）の売買と流通加工を本業とする卸売業**を指す。
統計上は「鉄鋼製品卸売業」「金属卸売業」に分類される。

境界のはっきりしない3点を先に片づける。

| 隣接する相手                                                                                        | 違い                                                                                                     |
| --------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| 鉄鋼メーカー（[鉄鋼](../../11_資源・エネルギー・鉄鋼金属/09_鉄鋼/README.md)）                       | 商社は鉄を「つくらない」。高炉・電炉という巨大設備を持たず、在庫と債権が資産の中心                       |
| 総合商社（[総合商社](../01_総合商社/README.md)）                                                    | 総合商社は資源権益や事業投資で稼ぐ比率が高い。鉄鋼商社は鋼材のトレーディング（売買差益と口銭）が収益の柱 |
| 金属リサイクル（[金属リサイクル](../../11_資源・エネルギー・鉄鋼金属/14_金属リサイクル/README.md)） | スクラップ（製鋼原料）の集荷・販売。鉄鋼商社も原料部門で扱うが、主戦場は製品側                           |

なお大手の多くは鋼材以外（非鉄、食品、繊維、機械）も扱う。
「鉄鋼商社」は**扱い品目というより、鋼材の商流を握っていることを本業の核とする会社群**を指す呼び方だと理解するとよい。

## 2. 市場規模と成長性

鉄鋼商社の規模は、扱う鋼材の量（トン）と単価（円/トン）の掛け算でほぼ決まる。
まず量の相場観を押さえる。

| 指標                 | 数値                  | 時点・出典                                                       |
| -------------------- | --------------------- | ---------------------------------------------------------------- |
| 国内の鋼材内需       | 約4,957万トン（推計） | 2024年度／日本鉄鋼連盟「2026年度の鉄鋼需要見通し」2025年12月25日 |
| 同・ピーク時         | 6,289万トン           | 2017年度／同上                                                   |
| 同・コロナ下の底     | 5,264万トン           | 2020年度／同上                                                   |
| 2026年度の内需見通し | 前年度並み（横ばい）  | 2026年度見通し／同上                                             |
| 粗鋼生産量           | 8,295万トン           | 2024年度／同上（2017年度は1億483万トン）                         |

読み取れるのは、**この10年弱で国内の鋼材需要が2割以上縮んだ**ということ。
量が増えない市場なので、商社の成長は「単価上昇」「加工など付加価値の上乗せ」「海外」の3方向に限られる。

一方、企業の売上高は鋼材価格に大きく振られる。2026年3月期で見ると、伊藤忠丸紅鉄鋼が約3兆7,410億円、阪和興業が約2兆6,626億円（いずれも各社決算・報道ベース、2026年）。
売上は兆円単位でも**純利益率は1〜2%程度**という薄利構造が、この業界の最大の特徴である（→ [01_鉄鋼流通の仕組み.md](01_鉄鋼流通の仕組み.md)）。

## 3. バリューチェーン（川上 → 川下）

```
[原料]      [製鉄]            [流通・加工]                 [需要家]
鉄鉱石  ─▶ 高炉メーカー ─┬─▶ 商社（一次問屋）──▶ コイルセンター ─┬─▶ 自動車メーカー
石炭        日本製鉄     │     ひも付き＝行き先が決まった鋼材      │   （ひも付き）
            JFEスチール  │                                        │
スクラップ ─▶ 電炉メーカー └─▶ 商社／問屋（店売り）─▶ 二次問屋 ─┴─▶ 建設・町工場
            東京製鐵など        行き先を決めずに売り切る             （店売り）
```

付加価値がどこに乗るかを見ると、**鋼材そのものの価格はメーカーが握り、商社の取り分は加工・物流・金融の部分**にある。
商社が「鋼材を安く仕入れて高く売る」だけの会社なら、メーカーの直販に置き換えられる。置き換えられずに残っているのは、次の4機能を束ねているからである。

1. **加工**（コイルセンターで切る・曲げる）
2. **在庫と物流**（必要な量を必要な日に届ける）
3. **与信**（中小需要家の代金を立て替え、焦げ付きを引き受ける）
4. **情報**（誰がどの鋼種をいくらでいつ欲しいか）

詳細は [01_鉄鋼流通の仕組み.md](01_鉄鋼流通の仕組み.md)。

## 4. 主要プレイヤーとシェア

| 企業                                | 立ち位置                                     | 特徴                                                                       |
| ----------------------------------- | -------------------------------------------- | -------------------------------------------------------------------------- |
| 日鉄物産                            | 日本製鉄系（2023年に完全子会社化、上場廃止） | メーカー直系。鋼材のほか繊維・食品も扱う複合型                             |
| JFE商事                             | JFEスチール系                                | 川鉄商事とNKKトレーディングが2004年に統合。JFEの製品を出口まで運ぶ         |
| メタルワン                          | 三菱商事60%・双日40%の合弁（2003年設立）     | 特定高炉の系列に属さない大型専業。海外コイルセンター網が厚い               |
| 伊藤忠丸紅鉄鋼（MISI）              | 伊藤忠商事・丸紅の鉄鋼部門統合（2001年）     | 売上高で最大級。2030年代に「鉄鋼流通のグローバルトップ」を掲げる           |
| 阪和興業                            | 独立系・上場（東証プライム）                 | 特定メーカーに縛られない。在庫を厚く持って市況で稼ぐ「トレーダー色」が濃い |
| 小野建、神鋼商事、中山三星建材 ほか | 地域・品種特化型                             | 建材流通や特定鋼種に強い中堅。全国に数千社の問屋が連なる                   |

> ポイント：日本の鉄鋼商社は「高炉メーカーの系列」と「独立系」に大きく割れる。
> 前者は安定した数量を約束される代わりに口銭が薄く、後者は仕入れ先を選べる代わりに市況のリスクを自分で背負う。

シェアの公式統計は存在しない（各社の扱い数量が非開示のため）。売上高・取扱量の比較は業界紙や各社IRを突き合わせる必要がある。

## 5. 収益モデル・コスト構造

鉄鋼商社の利益は、大きく3つの源泉に分かれる。

| 収益源           | 中身                                                   | 変動要因                                   |
| ---------------- | ------------------------------------------------------ | ------------------------------------------ |
| 口銭（こうせん） | ひも付き取引の仲介手数料。取引額の数%以下              | 数量。単価が上がっても口銭率は上がりにくい |
| 売買差益         | 店売りで安く仕入れ高く売る差額。在庫の値上がり益を含む | 鋼材市況。下落局面では在庫評価損になる     |
| 加工・サービス料 | コイルセンターでの切断・スリット加工賃、物流手数料     | 加工数量と設備稼働率                       |

コストは人件費・物流費・倉庫と加工設備の減価償却・**在庫を持つための金利**が中心。
売上原価の9割以上が仕入れた鋼材そのものなので、売上総利益率（粗利率）は概ね5〜7%、純利益率は1〜2%にとどまる。
参考に2026年3月期の伊藤忠丸紅鉄鋼は、売上高約3兆7,410億円に対し売上総利益が約2,278億円（粗利率約6%）、純利益は約404億円（報道ベース、2026年）。

> ポイント：薄利なので、**在庫評価損と貸倒れの2つが利益を一瞬で消す**。
> だから鉄鋼商社の経営は「いくら売るか」より「いくら在庫を持ち、誰に信用を出すか」の管理になる。

## 6. 競争要因（KSF）と参入障壁

| KSF              | なぜ効くか                                                                                                   |
| ---------------- | ------------------------------------------------------------------------------------------------------------ |
| メーカーとの商権 | ひも付き取引は長年の取引関係で商社が固定されている。新規が割り込みにくい                                     |
| 加工拠点の配置   | 需要家の工場の近くにコイルセンターがあるかどうかで、輸送費と納期が決まる                                     |
| 与信・財務の厚み | 中小需要家への立替えを支えるには自己資本とバランスシートが要る。阪和興業の自己資本比率は35.3%（2026年3月期） |
| 在庫回転の速さ   | 市況下落時に在庫を抱えた会社から損を出す                                                                     |
| 海外ネットワーク | 日系自動車メーカーの海外生産に鋼材を追随供給できるか                                                         |

参入障壁は「免許」ではなく**関係と設備と信用**。
特別な許認可は要らないのに新規参入がほとんどないのは、商権・加工拠点・与信枠をゼロから積み上げるのに時間と資本がかかりすぎるからである。

## 7. 規制・法制度

- 業法としての「鉄鋼商社業法」は存在しない。一般の商法・会社法・独占禁止法の枠組みで営む
- **下請法・独禁法**：メーカーと需要家の間に立つ立場上、価格転嫁の拒否や買いたたきが問題化しやすい
- **通商措置**：米国の鉄鋼輸入関税（通商拡大法232条に基づく措置）、各国のアンチダンピング税が、取引の採算とルートを直接左右する
- **中国の輸出許可制**：2026年1月から一部鋼材が輸出許可の対象になったと報じられている（2025年12月発表、約300品目）。アジア市況に効く
- **GX（グリーントランスフォーメーション）政策**：低炭素鋼材（電炉材、グリーンスチール）の調達要請が需要家側から強まりつつあり、商社は「どの鋼材がどれだけCO2を出しているか」を証明する役回りを担い始めている

## 9. 用語メモ

| 用語                   | 意味                                                                                                                                                      |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **ひも付き（紐付き）** | 需要家の注文内容（価格・数量・品質）がメーカーまで通っており、その需要家向けとして鋼材を生産・販売する契約。商社が仲介する → [01](01_鉄鋼流通の仕組み.md) |
| **店売り（店売）**     | 最終需要家を特定せず、メーカーが問屋・商社に鋼材を売り切る契約。買った側が在庫リスクを負う → [01](01_鉄鋼流通の仕組み.md)                                 |
| **コイルセンター**     | 巻いた鋼板（コイル）を切る・細く割る・平らにする加工を行う流通加工拠点 → [01](01_鉄鋼流通の仕組み.md)                                                     |
| **口銭（こうせん）**   | 仲介の手数料。取引額に対する率で表され、鉄鋼では数%以下                                                                                                   |
| **一次問屋／二次問屋** | メーカーから直接買うのが一次問屋、そこから買って中小ユーザーに売るのが二次問屋 → [01](01_鉄鋼流通の仕組み.md)                                             |
| **商権**               | 特定の需要家・鋼種について、その商社が仲介する慣行上の権利 → [02](02_商社の役割と再編.md)                                                                 |
| **粗鋼**               | 精錬直後の鋼。製品に圧延する前の段階。国の生産統計の基準になる                                                                                            |
