# 商社の役割と再編

このノートで分かること：日本の鉄鋼商社が「メーカー系列」と「独立系」に分かれる理由と、**高炉メーカーの合併が起きるたびに、その系列商社も一緒に合併してきた**という歴史。そして海外展開と需要先（自動車・建設・造船）ごとの商売の違い。

> ポイント：鉄鋼商社の再編は、商社側の事情ではなく**上流の高炉メーカーの再編に引きずられて起きる**。
> ひも付き取引では商社の商権がメーカーとの関係に紐づいているため、メーカーが1社になれば、その傘下の商社も1社に集約せざるを得ない。

## 1. 鉄鋼商社の3類型

| 類型                         | 立ち位置                                   | 代表企業                                                               | 強み                                                               | 弱み                                             |
| ---------------------------- | ------------------------------------------ | ---------------------------------------------------------------------- | ------------------------------------------------------------------ | ------------------------------------------------ |
| **高炉メーカー系列**         | 特定の高炉の製品を出口まで運ぶ直系商社     | 日鉄物産（日本製鉄）、JFE商事（JFEスチール）、神鋼商事（神戸製鋼所）   | 数量が安定。親のひも付き商権を継承                                 | 口銭が薄い。親以外の鋼材を売りにくい             |
| **総合商社系（合弁・分社）** | 総合商社が鉄鋼部門を切り出して統合した会社 | メタルワン（三菱商事60%・双日40%）、伊藤忠丸紅鉄鋼（伊藤忠商事・丸紅） | 特定高炉に縛られず複数メーカーを扱える。親の海外網と金融力を使える | 親会社が複数で意思決定が重くなりやすい           |
| **独立系**                   | どのメーカーにも属さない自立した商社       | 阪和興業、小野建 ほか                                                  | 仕入れ先を自由に選べる。市況を取りにいける                         | 在庫と与信のリスクを自前で負う。資本の厚みが要る |

### 収益の出方の違い

```
                 数量の安定性 ◀────────────────────▶ 市況で稼ぐ自由度

メーカー系列 ████████░░  数量は堅いが口銭は薄い（親の生産計画に従う）
総合商社系   ██████░░░░  複数メーカー＋海外投資。持分利益も乗る
独立系       ███░░░░░░░  在庫を積んで市況を取る。上下のブレが最も大きい
```

2026年3月期の実績を並べると、この性格の違いが数字に出る（いずれも各社決算・報道ベース、2026年）。

| 企業           | 売上高                   | 純利益    | 前期比  | 特記                                                                                                       |
| -------------- | ------------------------ | --------- | ------- | ---------------------------------------------------------------------------------------------------------- |
| 伊藤忠丸紅鉄鋼 | 約3兆7,410億円（4.2%減） | 約404億円 | 21.3%減 | 売上総利益 約2,278億円（1.2%減）。北米建材の減益、海外減損、持分法利益減が響いた（日刊鉄鋼新聞・有料記事） |
| 阪和興業       | 約2兆6,626億円（4.2%増） | 約383億円 | 15.9%減 | 営業利益 約584億円（5.0%減）。リサイクルメタル事業の損益悪化と人件費増。自己資本比率35.3%                  |

> 読み方：売上は兆円規模なのに純利益は数百億円。**純利益率は約1%**。
> 「大きく動かして、薄く抜く」のが鉄鋼商社の基本形である。

## 2. 再編の歴史 — メーカーが先、商社が後

### 2-1. 年表

```
[高炉メーカー]                          [鉄鋼商社]
                                   2001 伊藤忠商事Gr＋丸紅Gr 鉄鋼部門分社統合
                                        → 伊藤忠丸紅鉄鋼
2002 日本鋼管＋川崎製鉄 経営統合    2003 三菱商事Gr＋双日Gr 鉄鋼部門分社統合
     → JFEホールディングス               → メタルワン
                                   2004 川鉄商事＋NKKトレーディング 経営統合
                                        → JFE商事
2012 新日本製鐵＋住友金属 経営統合  2013 日鐵商事＋住金物産 経営統合
     → 新日鐵住金                        → 日鉄住金物産（のち日鉄物産）
                                   2014 建材／製鋼原料部門を統合 → エムエム建材
                                   2016 建材部門統合 → 伊藤忠丸紅住商テクノスチール
2017 日新製鋼を子会社化            2017 日鉄住金物産が三井物産Grの鉄鋼製品事業の一部
                                        （売上高 約3,700億円）を約600億円で譲受。
                                        三井物産の議決権比率 11.0% → 20.0%
2019 新日鐵住金 → 日本製鉄に社名変更

```

出典：日鉄住金物産「三井物産グループ鉄鋼事業の一部譲受けと資本関係強化に関する参考資料」(2017年10月4日)、各社発表・報道。

### 2-2. なぜ連動するのか

理由は「商権」にある。
ひも付き取引では、**どの需要家のどの鋼種をどの商社が仲介するか**が長年の関係で固定されている。
高炉A社とB社が合併すると、同じ自動車メーカー向けに、A社系商社とB社系商社の両方がぶら下がった状態になる。
需要家から見れば窓口が2つある非効率な状態なので、商社側も統合して1本化する圧力がかかる。

```
[合併前]                        [合併後：そのままだと]        [統合後]
高炉A ─▶ 商社a ─┐              統合高炉 ─▶ 商社a ─┐        統合高炉 ─▶ 統合商社
                 ├▶ 自動車X社              ─▶ 商社b ─┼▶ X社            │
高炉B ─▶ 商社b ─┘                                     ┘                 ▼
                                 窓口が2つ＝価格も条件も二重管理        X社
```

### 2-3. 日鉄物産の完全子会社化（2023年）が意味したもの

日本製鉄は2022年12月21日、グループ中核商社の日鉄物産をTOB（株式公開買付け）で完全子会社化・非公開化すると発表した（買付価格1株9,300円、総額1,370億円規模で開始）。
2023年4月11日にTOB成立（買付額約1,070億円）、4月14日付で連結子会社、6月21日に上場廃止となった（各社発表・報道）。

狙いとして説明されたのは、**製鉄から流通・加工までを一貫で最適化すること**。
上場会社のままでは顧客情報の共有に制約があり、需要家の使い方まで踏み込んだ提案ができないという事情があった。

> ポイント：これは「商社機能の内製化」の動きである。
> メーカーが流通まで囲い込めば、価格交渉の主導権と需要情報の精度が上がる。
> 一方で系列外の商社にとっては、**中立的に複数メーカーを扱える立場の価値が相対的に上がる**ことも意味する。

日本製鉄は2025年12月に「2030中長期経営計画」を公表し、2026〜2030年度の国内製鉄事業でグループ会社再編とグループ総合力（営業・流通・生産）の強化を掲げている。系列商社への集約圧力は続く方向にある。

### 2-4. 下の層でも再編は進む

大手の統合と並行して、二次問屋・鋼材加工会社のM&Aも増えている。
背景は経営者の高齢化と後継者難で、**事業承継型のM&A**が主流と報じられる。
買い手側には、それまで外注していた加工を内製化できるという相乗効果がある。

## 3. 海外展開 — 「鉄は生産地に追随する」

### 3-1. なぜ海外に出るのか

鋼材は重くてかさばる。単価に対して輸送費が高いため、**遠くへ運ぶほど採算が悪くなる**。
だから日系自動車メーカーがタイやメキシコやインドで生産すれば、そこに鋼材を届ける拠点も現地に要る。
鉄鋼商社の海外展開は、「新市場を開拓する」より「**顧客の工場についていく**」性格が強い。

```
[日本]                                  [現地]
日本の高炉 ──母材（コイル）を輸出──▶ 商社の現地コイルセンター
                                            │  切る・曲げる・在庫を持つ
現地の製鉄所（合弁・提携）───────────────┤
                                            ▼
                                     日系自動車メーカーの現地工場
                                     現地の建材・家電メーカー
```

### 3-2. 各社の動き

| 企業           | 海外の重点                | 内容                                                                                                                                                                                                                  |
| -------------- | ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| メタルワン     | 中米・ASEAN・中国・インド | 海外コイルセンター事業の規模は日系商社で最上位級とされる。ベトナム・クアンニン省では現地企業との合弁でコイルセンターを設立し、2023年に操業開始                                                                        |
| 伊藤忠丸紅鉄鋼 | インド・北米              | インド北部ハリヤナ州のコイルセンター事業に国際協力銀行（JBIC）が2023年に融資。第8次中期経営計画（2024〜2026年度）で電磁鋼板の加工・流通強化とインドの機能拡充を掲げる。2030年代に「鉄鋼流通のグローバルトップ」を目標 |
| 日鉄物産       | ASEAN・インド             | 日本製鉄の海外展開と一体で動く                                                                                                                                                                                        |
| 阪和興業       | アジア全般                | 海外販売子会社の取引拡大が2026年3月期の増収要因                                                                                                                                                                       |

### 3-3. 海外の難しさ

- **減損リスク**：現地の需要が想定を下回れば、加工設備が重荷になる。伊藤忠丸紅鉄鋼の2026年3月期減益要因には海外事業の減損損失が挙げられている（報道ベース）
- **与信の難易度**：日本のような業界内の信用情報網がなく、回収リスクが高い
- **中国材との競合**：中国の鋼材輸出が2025年に過去最高水準に達したと報じられ、ASEAN市場では価格競争が厳しい

## 4. 需要先ごとの違い

鋼材の売り方は、届け先の産業ごとにまったく違う。ここを押さえると「同じ鉄鋼商社でも会社ごとに性格が違う」理由が分かる。

| 需要先                 | 商流                   | 求められるもの                                                     | 商社の役割                                           | 景気との関係                                       |
| ---------------------- | ---------------------- | ------------------------------------------------------------------ | ---------------------------------------------------- | -------------------------------------------------- |
| **自動車**             | ほぼひも付き           | 高張力鋼・電磁鋼板などの高機能材、寸法精度、ジャストインタイム納入 | コイルセンターでのブランキング、海外拠点での追随供給 | 世界の自動車生産に連動。関税政策の影響を受ける     |
| **建設（土木・建築）** | 店売り中心             | H形鋼・異形棒鋼などの汎用材、短納期、現場ごとの小口配送            | 地域在庫と配送網、中小建設会社への与信               | 公共事業予算と民間建設投資。人手不足が需要を抑える |
| **造船**               | ひも付き（厚板）       | 大量の厚板、船台のスケジュールに合わせた供給                       | 長期契約の数量調整                                   | 受注残（手持工事量）で数年先まで読める             |
| **産業機械・建機**     | ひも付き＋店売りの混合 | 切板（シャーリング材）、多品種少量                                 | 加工と在庫の両方                                     | 設備投資サイクル。海外在庫調整の影響大             |
| **電機・家電**         | ひも付き               | 表面処理鋼板、電磁鋼板                                             | 加工と海外供給                                       | 中国勢との競合が激しい                             |

日本鉄鋼連盟の「2026年度の鉄鋼需要見通し」（2025年12月25日）では、2026年度の部門別に次の方向が示されている。

- **土木**：建設コスト増は続くものの、公共事業予算措置の増加で**微増**
- **建築**：住宅は低調だった前年を上回るが、非住宅は人手不足とコスト高で前年割れ。建築全体では**微減**
- **造船**：フル稼働の建造が続き**微増**
- **自動車**：米国の関税政策の影響と、中国EVの東南アジアへの輸出攻勢が継続し**前年割れ**
- **機械**：建機が米国での在庫調整一巡から回復基調で**微増**

### EV化が鋼材需要に与える影響

電動化は「鉄が減る」とだけ言われがちだが、実際は**品目の入れ替え**として起きる。

```
[エンジン車]                           [電気自動車]
 エンジン・変速機の部品鋼材  ───▶ 減る（部品点数が大きく減少）
 高張力鋼（車体軽量化）       ───▶ 横ばい〜増（重い電池を積むため車体剛性が要る）
 電磁鋼板（モーターの鉄心）   ───▶ 大きく増（駆動モーターに大量に使う）
 アルミ・樹脂への置換         ───▶ 鉄の一部を侵食
```

商社にとって重要なのは、**電磁鋼板が高機能材＝加工が難しく、付加価値を取りやすい品目**だという点。
伊藤忠丸紅鉄鋼が電磁鋼板の加工・流通強化を掲げるのは、量が減る汎用材から、量は少ないが利幅の取れる高機能材へ軸足を移す動きとして読める。

## 5. これからの論点

| 論点                             | 中身                                                                                               |
| -------------------------------- | -------------------------------------------------------------------------------------------------- |
| メーカーの内製化 vs 商社の中立性 | 日本製鉄型の垂直統合が進むほど、系列外商社は「複数メーカーを比べられる」ことを売りにせざるを得ない |
| 国内の量的縮小                   | 内需は2017年度の6,289万トンから2024年度推計4,957万トンへ。国内だけでは成長しない                   |
| 高機能材へのシフト               | 電磁鋼板、高張力鋼など、加工難度が高く商社の技術営業が効く領域へ                                   |
| 脱炭素対応                       | 電炉材・低炭素鋼材の調達要請。鋼材ごとのCO2排出量を説明できる商社が選ばれる                        |
| 二次問屋の集約                   | 後継者難によるM&Aで、流通の段数が緩やかに減る                                                      |

## 6. 用語メモ

| 用語                      | 意味                                                                                                               |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| **商権**                  | 特定の需要家・鋼種について、その商社が仲介する慣行上の権利。メーカーとの関係に紐づくため、メーカー再編で商権も動く |
| **メーカー系列商社**      | 特定の高炉メーカーの資本下にあり、その製品の流通を担う商社。日鉄物産、JFE商事など                                  |
| **独立系商社**            | 特定メーカーの資本下になく、仕入れ先を自由に選ぶ商社。阪和興業など                                                 |
| **TOB（株式公開買付け）** | 買付価格・期間を公告して市場外で株式を買い集める手続き。日本製鉄は2023年にこれで日鉄物産を完全子会社化した         |
| **非公開化**              | 上場を廃止して株式を市場で売買できなくすること。情報開示の制約がなくなり、親会社との情報共有が進む                 |
| **持分法投資利益**        | 出資先（関連会社）の利益のうち、出資比率に応じて自社の利益に取り込む分。商社の利益の一部を構成する                 |
| **減損損失**              | 事業や設備の収益性が落ちたときに、帳簿価額を引き下げて計上する損失。海外の加工拠点で発生しやすい                   |
| **電磁鋼板**              | モーターや変圧器の鉄心に使う、磁気特性を高めた鋼板。EVの駆動モーターで需要が伸びる高機能材                         |
| **高張力鋼（ハイテン）**  | 薄くても強い鋼板。車体を軽くしながら強度を保つために使う                                                           |
| **厚板**                  | 厚い鋼板。造船、橋梁、建設機械に使う                                                                               |
| **手持工事量**            | 造船所などが受注済みで未着工・建造中の工事量。数年先の需要が読める指標                                             |
