# 酒類卸

- 大分類: 商社・卸売
- 状態: done
- 更新日: 2026-09-20

酒類卸は、酒をメーカー・蔵元から仕入れ、酒販店・量販店・飲食店へ流す中間流通である。
食品卸の一種に見えるが、**免許制・酒税・業務用と家庭用の分断**という3つの固有事情があり、
そこを押さえないと事業の形も収益の薄さも理解できない。

## 1. 業界の定義・範囲

**酒類卸＝酒類卸売業免許を持ち、酒類業者（小売店・他の卸）に酒類を販売する事業者**。

境界を押さえておく。

| 隣接業態 | 酒類卸との違い |
| --- | --- |
| [食品卸](../06_食品卸/README.md) | 食品卸の多くは酒類部門を持つ。**実務上は「酒類卸＝総合食品卸の1部門」になっているケースが大半** |
| 業務用酒販店（二次卸） | 名前は「卸」でも、飲食店に直接納めるには**小売免許**が要る。法的には小売業 |
| 酒類メーカー | 製造免許を持つが、消費者に売るには別途免許が必要 |
| [酒類小売（量販・DS等）](../../07_小売・流通/02_スーパー・GMS/README.md) | 免許の需給調整緩和（1998年〜段階的）で参入が広がり、卸の最大の得意先かつ最大の価格圧力源になった |
| 通販・EC | 広域通販には通信販売酒類小売業免許が要り、**国産酒は年間課税移出数量3,000kL未満の製造者のものに限られる** |

> この業界を一言で：**「税金と免許が乗った重い液体を、薄い利ざやで運ぶ商売」**。

## 2. 市場規模と成長性

| 指標 | 数値 | 年・出典 |
| --- | --- | --- |
| 酒税収入 | 約1.2兆円 | 2023年度・国税庁 |
| 酒類の消費（販売）数量 | 10年前比 約9%減 | 2023年度・国税庁「酒のしおり」 |
| 清酒の課税数量 | 39万kL（1973年度のピーク177万kLの3割以下） | 2023年度・国税庁 |
| 酒類製造免許場数 | 4,070場（2012年度以降は増加傾向） | 2023年度・国税庁 |
| 酒類卸売業免許場数（全酒類） | 4,751場 | 2023年度・国税庁 |
| 酒類小売業免許場数（全酒類） | 166,333場（2007年度がピーク） | 2023年度・国税庁 |
| 日本産酒類の輸出金額 | 1,337億円（前年比▲0.5%。過去最高は2022年の1,392億円） | 2024年・財務省貿易統計 |
| 清酒の輸出金額 | 458.8億円（前年比＋5.5%） | 2025年・日本酒造組合中央会 |

**成長性の見立て**：国内数量は人口減と1人当たり飲酒量の減少という二重の要因で構造的に縮小。
伸びているのは**高付加価値帯（純米酒系、クラフト、輸入酒）／ノンアル・低アル／輸出**の3つで、
いずれも1品目あたりの量は小さい。詳細は [02_市場の縮小と各社の戦略](02_市場の縮小と各社の戦略.md)。

## 3. バリューチェーン（川上 → 川下）

```
  ┌────────────┐
  │ 原料・容器 │ 麦芽・ホップ・酒米・果実／瓶・缶・樽・段ボール
  └─────┬──────┘
        ▼
  ┌────────────┐  ★酒税はここで発生（製造場から「移出」した時点）
  │ 酒類メーカー│  ビール大手4社、日本酒蔵、焼酎蔵、ワイナリー、クラフト醸造所
  │  ・蔵元     │  製造免許 4,070場（2023年度）
  └─────┬──────┘
        ▼
  ┌────────────┐  ★このフォルダの主役
  │  酒類卸     │  全国系（総合食品卸の酒類部門＋日酒販）
  │             │  卸売業免許 4,751場（2023年度）
  └──┬──────┬──┘
     │      │
 家庭用│      │業務用
     ▼      ▼
 ┌────────┐ ┌──────────────┐
 │量販・CVS│ │地場の業務用酒販店│ ← 二次卸。与信・早朝配送・樽生サーバーを担う
 │ DS・HC  │ │（小売免許）      │
 └───┬────┘ └────────┬─────┘
     ▼                  ▼
   消費者            料飲店（居酒屋・レストラン・ホテル）
                     → [居酒屋](../../08_食品・農水産・外食/16_居酒屋/README.md)
```

**付加価値がどこに集まるか**：メーカー（ブランド）と小売（棚）に集まり、卸は薄い。
卸が取れるのは、(a) 物流の効率差、(b) 品揃え（小さな蔵元へのアクセス）、(c) 提案（棚割り・メニュー）の3点。

## 4. 主要プレイヤーとシェア

| 企業 | 立ち位置 | 特徴 |
| --- | --- | --- |
| 日本酒類販売（日酒販） | 全国規模の**酒類専業卸**としてほぼ唯一 | 2025年3月期 連結売上高6,075億円、経常利益65億円（経常利益率1.07%） |
| 国分グループ本社 | 総合食品卸。酒類の歴史が長い | 酒類売上高で日酒販を抜きトップになったと報じられる。第12次長期計画でノンアル・低アル深耕と和酒の海外展開 |
| 三菱食品 | 総合食品卸（三菱商事グループ） | 2026年は酒税改正対応とビール回帰の販促を重点に置く |
| 日本アクセス | 総合食品卸（伊藤忠グループ）。低温・チルドに強い | 「マーケットイン」の提案型営業 |
| 伊藤忠食品 | 総合食品卸。**酒類比率が高い（約4割）** | 約4,000のメーカーと取引、約50万アイテムを約1,000の小売得意先へ。ワイン・スピリッツを強化 |
| 三井物産流通グループ（三井食品） | 総合食品卸（三井物産グループ） | 和酒の飲み方提案に注力 |
| カクヤス、やまや 等 | 業務用酒販＋小売 | 飲食店への直接配送網。小売免許ベースのモデル |
| 地場の業務用酒販店 | 全国に多数の中小企業 | 与信・早朝配送・樽生サーバーを担う業界の毛細血管 |

> 構造的な要点：**「酒類卸」という独立業界はもう小さい。**
> 全国規模では、日酒販を除けば酒類は総合食品卸の1部門として存在している。
> 食品と混載した方がトラックが埋まる、という物流の経済が統合を進めた。

## 5. 収益モデル・コスト構造

```
  売上高 100
   ├─ 売上原価  約 90〜93      ← 仕入。この中に酒税が2〜3割含まれる
   ├─ 粗利      約  7〜10
   │   ├─ 物流費（配送・倉庫）  約 3〜4
   │   ├─ 人件費               約 2〜3
   │   └─ その他販管費         約 1〜2
   └─ 営業利益  約 0.5〜1.0    ← これが業界の実力値
```

| 指標 | 目安 | 読み方 |
| --- | --- | --- |
| 粗利率 | 7〜10% | 業務用比率が高いほど上がる（その分コストと与信リスクも上がる） |
| 営業利益率 | 0.5〜1%台 | 1%を超えれば健闘の水準 |
| 在庫回転 | 高回転が命 | **酒税込みの在庫は資金を食う**。滞留＝資金繰り悪化 |
| 売上債権回転日数 | 30〜60日 | 業務用が長い。貸倒れリスクと表裏 |

利益源は、(1) 仕入と販売の差（口銭）、(2) メーカーからのリベート（販売促進金）、(3) 物流受託。
**薄利で回転と規模で稼ぐ業態**であり、運賃や人件費の上昇がそのまま利益を削る。

## 6. 競争要因（KSF）と参入障壁

| 要素 | 内容 | 障壁 |
| --- | --- | --- |
| **免許** | 全酒類卸売業免許・ビール卸売業免許は地域ごとに件数枠があり、年1回9月に申請・公開抽選 | **高い** |
| 物流網 | 重量物・静脈物流（空瓶・空樽の回収）・多頻度小口に耐える拠点と車両 | 高い |
| メーカー口座と仕切条件 | 既存卸に有利な取引条件・リベート | 高い |
| 得意先との帳合 | 既存の担当関係は簡単には動かない | 中〜高 |
| 与信の体力 | 飲食店の貸倒れを吸収できる資本 | 中 |
| 商品知識・目利き | 地酒・ワイン・クラフトは人に依存する | 中（**ここが新規参入の穴**） |

> **参入の穴**：洋酒卸売業免許と輸出入酒類卸売業免許には需給調整の枠がない。
> ワイン・クラフトビール・輸入スピリッツ・日本酒輸出の領域では小さな専門商社が次々生まれている。
> 逆に「全酒類をフルラインで全国に」という領域は、免許と物流の二重の壁でほぼ固定されている。

## 7. 規制・法制度

| 制度 | 中身 | 効き方 |
| --- | --- | --- |
| **酒税法** | 製造・卸売・小売すべてを免許制に。受払の帳簿記録義務も課す | 業界の根本ルール。所管は**国税庁** |
| **酒税の税率** | 2020年10月・2023年10月・**2026年10月**の3段階でビール系を一本化 | 商品設計と価格の前提が変わる |
| **酒類の公正な取引に関する基準**（2017年3月告示、6月適用） | **総販売原価（仕入＋物流＋人件費＋販管費）を下回る継続販売を禁止** | 行き過ぎた安売りを抑制。違反は指示・公表、悪質なら免許取消 |
| 独占禁止法（不当廉売） | 公正取引委員会が別建てで監視 | 上記と二重にかかる |
| 通信販売酒類小売業免許の制限 | 広域通販の国産酒は**年間課税移出数量3,000kL未満の製造者のもの**に限定 | 大手ブランドの全国EC通販を事実上制限 |
| 20歳未満の飲酒禁止／酒類販売管理者 | 年齢確認、販売管理研修の受講義務 | 小売・卸の運営コスト |
| 健康に配慮した飲酒に関するガイドライン（2024年2月、厚労省） | 純アルコール量（g）での把握を推奨 | 缶への純アルコール量表示が進み、商品マスタ改訂が発生 |
| 輸出関連（輸出促進法、輸出拡大実行戦略） | 国税庁が輸出コンソーシアム・補助金で支援 | 輸出参入の後押し |

詳しくは [01_酒類流通の特殊性](01_酒類流通の特殊性.md)。

## 8. 最近のトピック

→ 詳細は [03_直近トピック_2026](03_直近トピック_2026.md)

1. **2026年10月1日、ビール・発泡酒・新ジャンルの酒税が350ml換算54.25円に一本化**。ビールは▲9.10円の減税、発泡酒・新ジャンルは＋7.26円、チューハイ等は＋7円の増税。
2. 税差が消えることで**新ジャンルの存在理由が薄れ、主力ブランドのビールへのリニューアルが報じられている**。卸は価格改定・棚割り提案・マスタ切替に追われる。
3. **2026年上半期の飲食業倒産は509件と過去最多**、居酒屋は初の100件超（118件、東京商工リサーチ）。粗利の高い業務用チャネルで与信リスクが高まっている。
4. **輸出は清酒が牽引**。2025年の清酒輸出は458.8億円（＋5.5%）。ただし日本産酒類全体は2022年の1,392億円をピークに踊り場（2024年1,337億円）。
5. **ノンアル・低アルとクラフトが成長領域**。ただしアルコール1%未満は酒税も免許も不要で、免許の壁が効かない競争領域でもある。

## 9. 用語メモ

各ノート末尾の「用語メモ」に分野別に整理している。最小限の10語だけここに置く。

| 用語 | 意味 |
| --- | --- |
| **酒類** | 酒税法上、アルコール分1度（1%）以上の飲料。1%未満は酒類ではなく、酒税も免許も不要 |
| **課税移出** | 製造場から酒類を出荷すること。この時点で酒税の納税義務が発生する。需要指標「課税移出数量」の語源 |
| **全酒類卸売業免許** | すべての品目を卸売できる免許。地域ごとに件数枠があり、年1回9月に申請・公開抽選 |
| **総販売原価** | 仕入＋物流費＋人件費＋販管費。2017年の公正取引基準が「これを下回る継続販売の禁止」を定めた |
| **料飲店** | 酒を提供する飲食店（居酒屋・レストラン・バー・ホテル）の業界用語 |
| **業務用／家庭用** | 料飲店向け＝業務用、量販店・CVS向け＝家庭用。チャネルの呼び分け |
| **二次卸** | 全国卸から仕入れて地元飲食店に納める地場の酒販店。与信と早朝配送を担う |
| **樽生** | 樽詰め生ビール。サーバー設置・炭酸ガス・洗浄・空樽回収までがセットの業務用インフラ |
| **新ジャンル（第三のビール）** | 税率を抑えたビール風飲料。2023年10月に法令上は発泡酒へ統合、2026年10月にビールと同税率へ |
| **純アルコール量** | 飲料量×度数×0.8で求めるアルコールのグラム数。2024年の厚労省ガイドライン以降、表示が進む |

※本フォルダは流通構造の解説であり、飲酒を推奨するものではない。20歳未満の飲酒は法律で禁止されている。
