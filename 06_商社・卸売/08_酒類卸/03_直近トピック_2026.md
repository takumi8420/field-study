## 1. 最大の論点：2026年10月1日の酒税一本化

2026年10月1日、**ビール・発泡酒・新ジャンルの酒税が350ml換算で54.25円に統一**される。
2017年度税制改正で決まった3段階（2020年10月／2023年10月／2026年10月）の最終段階にあたる。

| 品目 | 〜2026年9月30日 | 2026年10月1日〜 | 増減 |
| --- | --- | --- | --- |
| ビール | 63.35円 | 54.25円 | **▲9.10円（減税）** |
| 発泡酒・新ジャンル | 46.99円 | 54.25円 | **＋7.26円（増税）** |
| チューハイ等（その他の発泡性酒類） | 28円（1kLあたり8万円） | 35円（同10万円） | **＋7円（増税）** |

※350ml換算。出典は財務省「酒税に関する資料」および各種解説記事。

### 何が変わるか

```
 【これまでの30年】
   「税の安いカテゴリを発明する」競争
     ビール ─► 発泡酒（麦芽比率を下げる） ─► 新ジャンル（麦芽を使わない）
            └ 税差があるから、味を犠牲にしてでも安いカテゴリに商品を作る意味があった

 【2026年10月以降】
   税差が消える
     ├─ 発泡酒・新ジャンルの「存在理由」が薄れる
     ├─ ビールが相対的に安くなり、棚と売価の序列が入れ替わる
     └─ メーカーは「中身と味」で勝負するしかなくなる
```

- **「金麦」「本麒麟」といった新ジャンル主力ブランドが、ビールにリニューアルされる**と報じられている（税率が同じなら、わざわざ新ジャンルで出す理由がないため）
- 飲食店では生ビールが1杯あたり約9.1円（350ml換算）の減税となり、原価が下がる。値下げに回すか利益に回すかは店側の判断（宿泊・飲食向け解説記事より）
- チューハイ・サワーは増税。**低価格の受け皿だったRTDの価格競争力が落ちる**

### 卸にとっての実務

| 論点 | 内容 |
| --- | --- |
| 価格改定 | 全SKUの仕切価格差し替え。10月1日をまたぐ受発注・在庫の扱いを得意先ごとに詰める |
| 駆け込みと反動 | 9月に増税品目の駆け込み、10月に反動減。**在庫を積みすぎると評価損**になる |
| 棚割り提案 | 「ビールが安くなった棚」をどう組むかの提案が、卸の付加価値を問われる場面 |
| 商品統廃合対応 | リニューアル・終売のマスタ切替が大量に発生する |

三菱食品は2026年の重点方針として「10月の酒税改正への対応と、減税を機としたビール回帰の促進」を掲げている（日本食糧新聞、2026年7月）。
日本食糧新聞は特集で「酒税改正は新たな転換点」「一杯の意味を問い直す時代へ」と位置づけている（2026年7月30日）。

## 2. 業務用チャネルの悪化 ― 飲食業倒産が過去最多

東京商工リサーチの集計によると、**2026年上半期（1〜6月）の「飲食業」倒産は509件**で、
1997年以降の30年間で初めて500件台に乗った。

| 区分 | 件数 | 前年同期比 |
| --- | --- | --- |
| 飲食業 全体 | **509件** | 過去最多 |
| うち居酒屋（酒場、ビヤホール） | **118件** | **初の100件超** |
| 「物価高」倒産 | 86件 | ＋53.5%（約1.5倍） |
| 「人手不足」関連倒産 | 36件 | ＋125.0%（約2.2倍） |

（出典：東京商工リサーチ、2026年発表・報道ベース）

```
 【卸への波及経路】
   飲食店の倒産増
     ├─► ① 売上の消滅（納品先そのものがなくなる）
     ├─► ② 売掛金の焦げ付き（納品済み・回収前の分が回収不能に）
     └─► ③ 貸与什器の回収不能（冷蔵庫・ビールサーバー等）

   さらに二次卸（地場の業務用酒販店）がこれを直接かぶるため、
   二次卸の廃業 → 全国卸の配送網の穴 という連鎖が起きる。
```

> 押さえどころ：業務用は粗利率が高い代わりに与信リスクが高いチャネル
> （→ [酒類流通の特殊性 6章](01_酒類流通の特殊性.md)）。
> **2026年は「粗利の高い方のチャネルが痛んでいる」年**と理解すればよい。

小・零細の飲食店ほど原価上昇を価格転嫁しにくく、来店客数の減少を恐れて値上げに踏み切れない、という構図が指摘されている。

| --- | --- | --- | --- |
| 日本産酒類の輸出総額 | 1,337億円（前年比▲0.5%） | 2024年 | 財務省貿易統計／国税庁 |

### 読み方

```
  【日本産酒類の輸出、構図の整理】

   2022年 過去最高 1,392億円
      │   ＝ コロナ後の反動＋円安＋ジャパニーズウイスキー人気
      ▼
   2023〜2024年 1,330〜1,340億円で横ばい（踊り場）
      │   ＝ 中国向けの落ち込み（2024年 ▲23.9%）が全体を押し下げ
      │     ウイスキーも▲12.8%
      ▼
   2025年 清酒は458.8億円まで回復・過去最高圏
          ＝ 中国向けの持ち直し＋韓国・カナダ・フランスの伸び

   ※伸びしろの根拠：世界の酒類市場に占める清酒のシェアは
     2023年時点で0.1%に満たない（IWSR）。
```

政府は農林水産物・食品の輸出額目標を5兆円と定め、国税庁も「輸出拡大実行戦略」（2025年5月改訂）にもとづいて
輸出促進コンソーシアムの運営、酒類輸出コーディネーターの配置、補助金による支援を続けている。

2024年12月の**ユネスコ無形文化遺産「伝統的酒造り」登録**は、この追い風として国内外の広報に使われている。

## 4. ノンアル・低アルの拡大と、健康・社会面の制度変化

- 厚生労働省が2024年2月に**「健康に配慮した飲酒に関するガイドライン」**を公表。
  「何杯飲んだか」ではなく**純アルコール量（グラム）**で把握することを推奨した
- これを受けて酒類メーカーは**缶への純アルコール量表示**を進めている。卸は商品マスタの改訂対応が発生する
- **スマートドリンキング**（2020年12月にアサヒビールが提唱、飲む／飲まないを自分で選ぶという考え方）が業界の共通言語になり、
  ノンアル・低アルの品揃え提案が卸の営業テーマになった
- 国分グループ本社は第12次長期経営計画で**ノンアル・低アルカテゴリの深耕**を重点に挙げている
- ノンアルコール飲料はビール系以外のフレーバーにも広がり、健康志向を背景に好調に推移していると報じられる（2026年、ダイヤモンド・チェーンストア）
- 市場規模の推計は調査会社により幅が大きい。世界のノンアルコールビール市場は
  2025年約328億ドル→2026年約354億ドル（CAGR約8%）などの推計がある（**調査会社の推計であり、定義により数値が大きく異なる点に注意**）

> 卸にとっての留意点：**アルコール分1%未満は酒税法上の「酒類」ではない**。
> つまり酒税もかからず、販売免許も不要。
> 免許という参入障壁が効かない領域なので、清涼飲料のプレイヤーとも競合する
> （→ [清涼飲料](../../08_食品・農水産・外食/09_清涼飲料/README.md)）。

なお、20歳未満の飲酒は法律で禁止されており、上記は飲酒を推奨する趣旨ではない。

## 5. クラフト・地酒の裾野拡大と、卸の対応

- 酒類製造免許場数は2012年度を境に**減少から増加に転じ**、2023年度は4,070場（国税庁）。
  果実酒（日本ワイン）・ビール（クラフト）と、構造改革特区による「どぶろく」「特産品リキュール」などが増加要因
- 清酒全体は減っているが、**純米酒・純米吟醸酒は2013年度9.2万kL → 2023年度10.4万kL（＋約13.6%）**と増加（国税庁）
- 2026年の近畿圏では、大阪・泉佐野に体験型醸造所が開業、京都で日本初のクラフトブルワリー団体が設立されるなど、
  クラフト関連の動きが活発と報じられる（日本食糧新聞、2026年）
- 一方で**酒米（酒造好適米）の価格高騰**が懸念されている。2024年産の主食用米が高騰した影響で、
  2025年産の酒造好適米の価格と作付けに影響が出るおそれがあると国税庁が指摘している

```
 【卸にとってのジレンマ】

   クラフト・地酒の拡大  ─► 銘柄数（SKU）は激増
                         ─► 1銘柄あたりの数量は極小
                         ─► 売上はさほど伸びないのに
                            物流・在庫・受発注の手間だけ増える

   → 「大量に速く流す」従来のオペレーションと逆方向の能力が要る
   → 専門部隊／専門子会社を持つか、専門商社と組むかの選択になる
```

## 6. コスト構造への圧力 ― 物流と原材料

- 物流の2024年問題（トラック運転手の時間外労働上限規制）以降、**人手不足倒産は過去最多**を更新し、
  2024年度の物流業の人手不足倒産は42件と報じられる（LNEWS等）
- 酒類は重量物であり、リターナブル瓶・ビール樽・P箱の**回収（静脈物流）**が必要なため、
  運賃上昇の影響を受けやすい
- 原材料面では酒米の高騰に加え、容器・包材のコスト上昇が続く。
  「お酒は嗜好品であるため、値上げによる購買意欲の低下を避けたい」一方で、
  急激な原価上昇を製品価格に転嫁することは容易ではない、と国税庁も指摘している
- 関西・中四国の酒類卸では、**営業体制の再編による組織強化**と得意先への付加価値提供が課題として挙げられている（日本食糧新聞、2026年8月）

## 7. 全体の構図（まとめ）

2026年の酒類卸は、**「国内の量が減り、稼げるチャネルが痛み、価格の前提が変わる」年**である。

1. **10月1日の酒税一本化**が最大の変数。ビールは減税、発泡酒・新ジャンル・チューハイは増税。
   税差を前提にした商品設計と棚割りがリセットされ、卸は価格改定と提案の両方で忙しくなる。
2. **業務用（飲食店向け）が痛んでいる**。飲食業倒産509件・居酒屋118件はいずれも過去最多で、
   粗利の高いチャネルが与信リスクの高いチャネルでもあるという構造が、いま悪い方向に出ている。
3. **成長は「高単価・少量」と「海外」にある**。純米酒系、クラフト、ノンアル・低アル、そして輸出。
   ただしどれも1品目あたりの量は小さく、従来の大量物流の効率とは相性が悪い。
4. その結果、**規模を取って物流コストを割る（＝総合食品卸との統合）**か、
   **免許の枠がない領域（洋酒・輸出入）で専門性を売る**かの二極化が進む。

## 8. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **酒税一本化** | ビール・発泡酒・新ジャンルの税率を同一にする改正。2020年10月・2023年10月・2026年10月の3段階で実施 |
| **その他の発泡性酒類** | チューハイ・サワー等が入る酒税法上の区分。2026年10月に1kLあたり8万円→10万円に引き上げ |
| **静脈物流** | 空き容器・パレット等を回収して戻す方向の物流。酒類では瓶・樽・P箱の回収が該当 |
| **物流2024年問題** | 2024年4月からトラック運転手に時間外労働の上限規制が適用され、輸送能力が不足する問題 |
| **酒造好適米** | 日本酒づくりに適した米（山田錦など）。主食用米の価格に引きずられて高騰する |
| **伝統的酒造り** | こうじ菌を用いた日本の酒造技術。2024年12月にユネスコ無形文化遺産に登録 |
| **純アルコール量** | 飲料量×度数×0.8で求めるアルコールのグラム数。2024年の厚労省ガイドライン以降、表示・啓発が進む |
