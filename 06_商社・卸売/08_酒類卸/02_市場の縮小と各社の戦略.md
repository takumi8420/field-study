# 市場の縮小と各社の戦略

このノートで分かること：国内の酒類消費は**構造的に減り続けている**。
その縮む市場のなかで、酒類卸がどこで稼ぎ、どこに逃げ道を探しているか。

前提となる免許・酒税・チャネルの話は [酒類流通の特殊性](01_酒類流通の特殊性.md) を先に読むと分かりやすい。

---

## 1. 結論：三つの逆風と、三つの逃げ道

```
  【逆風】                              【逃げ道】
  ① 人口減と若年層の飲酒離れ     ──►  ① 高付加価値化（クラフト・輸入酒・和酒）
     → 数量が構造的に減る                 単価を上げて数量減を補う
  ② 酒税一本化（2026年10月完了）  ──►  ② ノンアル・低アル
     → 商品設計の前提が崩れる              「飲まない人」も客にする
  ③ 業務用の需要不安定＋倒産増    ──►  ③ 輸出・海外
     → 与信リスクと配送コスト              人口が増える市場へ
                                        ＋ 食品卸との統合（規模でコストを割る）
```

> 一言でいうと：**「国内で酒を右から左に流す」だけの商売は、もう成り立たない。**
> 卸が生き残る道は、(a) 規模を取って物流コストを下げる、(b) 情報・提案で単価を上げる、
> (c) 酒以外（食品・食材）と束ねて1台のトラックの積載効率を上げる、のどれかである。

## 2. 需要の長期減少 ― 数字で見る

### 2-1. 全体の数量

| 指標 | 数値 | 年・出典 |
| --- | --- | --- |
| 酒類の消費（販売）数量 | 10年前と比べ**約9%減** | 2023年度（令和5年度）・国税庁「酒のしおり」 |
| 成人1人当たり酒類消費数量 | 1990年代前半のピークから一貫して低下傾向 | 国税庁「酒のしおり」図2 |
| 酒税収入 | 約**1.2兆円** | 2023年度・国税庁 |
| 清酒の課税数量 | 1973年度の**177万kL** → 2023年度は**39万kL**（ピークの3割以下） | 国税庁 |
| 酒類製造免許場数 | 4,070場（2012年度を境に増加へ転じた） | 2023年度・国税庁 |
| 酒類卸売業免許場数（全酒類） | 4,751場 | 2023年度・国税庁 |
| 酒類小売業免許場数（全酒類） | 166,333場（2007年度をピークに減少傾向） | 2023年度・国税庁 |

**減り方が「二重」である点**が重要。

```
  総需要の減少 ＝ ① 成人人口の減少  ×  ② 1人当たり飲酒量の減少
                    （人口動態）          （若年層の飲酒離れ、健康志向、
                                          飲み会文化の縮小、在宅化）

  → どちらか片方なら耐えられるが、両方が同時に効いているので
     「景気が戻れば戻る」類の減少ではない＝構造的な縮小。
```

### 2-2. 中身の入れ替わり

数量は減っているが、**中身は激しく入れ替わっている**。ここが卸の腕の見せどころになる。

| カテゴリ | 方向 | 背景 |
| --- | --- | --- |
| ビール（本来のビール） | 長期減 → 税率改正で**下げ止まり・回帰の兆し** | 2020年・2023年・2026年の減税 |
| 発泡酒・新ジャンル | 税率上昇で**縮小へ** | 税差がなくなればわざわざ選ぶ理由が薄れる |
| チューハイ・RTD | 伸びてきたが**2026年10月に増税** | 低価格の受け皿だったが前提が変わる |
| 清酒（日本酒） | 国内は減、ただし**純米・純米吟醸は増**（2013年度9.2万kL→2023年度10.4万kL、＋約13.6%） | 「安く多く」から「少なく良いものを」へ |
| 焼酎甲類 | 減。価格改定と主要飲用層の高齢化 | 日本酒類販売の2025年3月期コメント |
| ウイスキー・洋酒 | 好調が継続 | ハイボール定着、輸出でも主力 |
| ワイン | 横ばい〜微増。日本ワインは造り手が増加 | 果実酒の製造免許場数が増加 |
| **ノンアル・低アル** | **成長** | 健康志向、スマートドリンキング、飲酒ガイドライン |
| **クラフトビール** | **成長**（小規模のため金額の絶対値は小さい） | 醸造所の新設が続く |

> 卸にとって厄介なのは、**成長カテゴリほど1アイテムあたりの数量が小さい**こと。
> クラフトビールも地酒もノンアルも、品目数（SKU）は激増するのに1つあたりは少量。
> **売上は増えないのに物流と在庫の手間だけ増える**という構造になりやすい。

## 3. 2026年10月の酒税一本化 ― 商品設計の前提が変わる

2026年10月1日、**ビール・発泡酒・新ジャンルの税率が350ml換算で54.25円に統一**される。
2020年10月から3段階で進めてきた改正の最終段階である。

```
  350ml あたりの酒税（円）

   70 ┤ ●63.35（ビール）
   60 ┤        ╲
   54 ┤          ●━━━━━● 54.25 で一本化（2026/10〜）
   47 ┤        ╱ 46.99（発泡酒・新ジャンル）
   40 ┤      ╱
   35 ┤  ●35（チューハイ等、2026/10〜）
   28 ┤ ●28（チューハイ等、〜2026/9）
      └────────────────────────────────
         〜2026年9月        2026年10月〜

   ビール      ▲9.10円（減税）
   発泡酒・新ジャンル ＋7.26円（増税）
   チューハイ等 ＋7円（増税）
```

### 卸に起きること

| 論点 | 内容 |
| --- | --- |
| **価格改定オペレーション** | 全SKUの仕切価格を切り替える。10月1日をまたぐ在庫の扱い、既存の商談条件の巻き直しが発生 |
| **駆け込みと反動** | 増税品目（発泡酒・新ジャンル・チューハイ）は9月に駆け込み需要、10月に反動減。**在庫を積みすぎると評価損** |
| **棚割りの組み替え** | ビールが相対的に安くなる。小売の棚をどう組み替えるかの提案が卸の勝負どころ |
| **商品の統廃合** | 税差が消えれば新ジャンルの存在理由が薄れる。**「金麦」「本麒麟」などがビールにリニューアルされる**と報じられている |
| 業務用への影響 | 生ビールは減税。飲食店の原価が下がるが、それを値下げに回すか利益に回すかは店次第 |

三菱食品は2026年の重点課題として「10月の酒税改正への対応と、減税タイミングでのビール販売促進」を挙げている（日本食糧新聞、2026年7月）。

> 押さえるべき構図：**過去30年、日本のビール系市場は「税の安いカテゴリを発明する」競争だった。**
> 発泡酒も新ジャンルも、税率の隙間を狙った商品設計の産物である。
> その隙間が2026年10月に消える。つまり**メーカーは「味と中身」で勝負せざるを得なくなり、
> 卸も「安いから売れる」という説明が使えなくなる**。

## 4. 主要プレイヤーと収益構造

### 4-1. 誰がいるか

| 企業 | 立ち位置 | 特徴 |
| --- | --- | --- |
| **日本酒類販売（日酒販）** | 全国規模の**酒類専業卸**としてほぼ唯一の存在 | 2025年3月期 連結売上高6,075億円、経常利益65億円（経常利益率1.07%）。清酒・焼酎から洋酒まで総合的に扱う |
| **国分グループ本社** | 総合食品卸。酒類の歴史が長い | 酒類売上高で日酒販を抜きトップになったと報じられる（日本食糧新聞）。第12次長期経営計画でノンアル・低アルの深耕と和酒の海外展開を推進 |
| **三菱食品** | 総合食品卸（三菱商事グループ） | 2026年は酒税改正対応とビール回帰の販促を重点に置く |
| **日本アクセス** | 総合食品卸（伊藤忠グループ）。低温・チルドに強い | 「マーケットイン」を掲げた提案型営業 |
| **伊藤忠食品** | 総合食品卸。**酒類の比率が高い** | 約4,000の酒類・食品メーカーと取引、約50万アイテムを約1,000の小売得意先へ。**酒類が事業の約4割**。ワイン・スピリッツを強化 |
| **三井物産流通グループ（三井食品）** | 総合食品卸（三井物産グループ） | 和酒（日本酒・焼酎）の飲み方提案に注力 |
| **カクヤス、やまや 等** | 業務用酒販＋小売 | 飲食店への直接配送網を持つ。卸ではなく小売免許ベースのモデル |
| **地場の業務用酒販店（二次卸）** | 全国に多数の中小企業 | 与信・早朝配送・樽生サーバーの面倒を見る。業界の毛細血管 |

> 構造上の要点：**「酒類卸」という独立した業界はもう小さい。**
> 全国規模では日酒販を除けば、酒類は**総合食品卸の1部門**として存在している。
> なぜなら、飲食店にもスーパーにも「酒だけ」を運ぶより「食品と一緒に」運んだ方がトラックが埋まるからである。
> これが後述の「総合食品卸化」の経済的な理由。

### 4-2. 収益モデル ― なぜ利益率1%なのか

```
  売上高 100
   ├─ 売上原価  約 90〜93      ← メーカーからの仕入。酒税込み
   │   （うち酒税相当が2〜3割）
   ├─ 粗利      約  7〜10
   │   ├─ 物流費（配送・倉庫）  約 3〜4   ← 重い・割れる・戻る
   │   ├─ 人件費               約 2〜3
   │   └─ その他販管費         約 1〜2
   └─ 営業利益  約 0.5〜1.0    ← これが業界の実力値
```

- **仕入価格の中に酒税が入っている**ため、見かけの売上高が大きくなり、利益率は分母で薄まる
- 粗利のほとんどが**物流と人件費で消える**。運賃が上がれば即座に赤字圏に落ちる
- したがって、この業態は「**利益率で戦う商売ではなく、回転と規模で戦う商売**」
- リベート（メーカーからの販売促進金）が利益の一部を占める点は食品卸と同じ

| 指標 | 目安 | 読み方 |
| --- | --- | --- |
| 売上総利益率（粗利率） | 7〜10% | 業務用比率が高いと上がる |
| 営業利益率 | 0.5〜1%台 | 1%を超えれば健闘 |
| 在庫回転 | 高回転が命 | 酒税を含む在庫は資金を食う。滞留＝資金繰り悪化 |
| 売上債権回転日数 | 30〜60日 | 業務用が長い。貸倒れリスクと表裏 |

## 5. 再編と「総合食品卸化」

### 5-1. 何が起きてきたか

```
 【かつて】 メーカー系販社 ＋ 全酒類卸 ＋ 地場酒販店 が層をなす
              ↓ 1990年代〜 規制緩和（酒販免許の需給調整要件を段階的に撤廃）
 【変化】  量販・CVS・DS・ドラッグストアが酒類小売に大量参入
              ↓ 小売が巨大化 → 卸に対する価格・物流要求が強まる
 【帰結】  酒類専業卸は単独では耐えられず、食品卸に吸収・統合されていく
              ↓
 【現在】  総合食品卸の「酒類事業部」として存在。
           酒と食品を同じトラック・同じセンターで扱い、コストを割る
```

### 5-2. なぜ統合が合理的か

| 論点 | 酒類専業のまま | 食品と統合 |
| --- | --- | --- |
| 積載効率 | 重量物ばかりで容積が余る | 軽い食品と混載して**重量と容積の両方を使い切る** |
| 得意先 | 酒の商談しかできない | 同じバイヤー窓口で**食品も酒も提案**できる |
| 物流センター | 酒専用に建てるしかない | 共用でき、投資が割れる |
| 提案の幅 | 「この酒が売れます」まで | 「この料理にこの酒」という**メニュー提案**ができる |
| 人材・システム | 小さな業界で採用・投資が細る | 規模で吸収できる |

国分グループ本社は「食との親和性を売場で演出する」ことを酒類戦略に掲げており、
三井物産流通グループは「和酒の飲み方提案の拡充」を掲げている（いずれも日本食糧新聞の特集より）。
**「酒を運ぶ会社」から「食卓・メニューを提案する会社」への言い換え**が、各社に共通している。

### 5-3. 地場の再編

地方では、業務用酒販店（二次卸）の後継者難・人手不足による廃業・M&Aが続いている。
飲食店倒産が過去最多水準（2026年上半期509件・東京商工リサーチ）という環境では、
二次卸の与信負担も重い。関西・中四国では**営業体制の再編による組織強化**の動きが報じられている（日本食糧新聞、2026年8月）。

## 6. 成長領域 ― どこで単価を取るか

### 6-1. クラフト・地酒・輸入酒（高付加価値）

- 清酒の**純米酒・純米吟醸酒は2013年度9.2万kL → 2023年度10.4万kL（＋約13.6%）**と増加。全体が減る中での増加
- 果実酒（日本ワイン）・ビール（クラフト）の**製造免許場数が増加**。2012年度を境に製造免許場数全体が増加に転じた
- 2024年12月、**「伝統的酒造り」がユネスコ無形文化遺産に登録**。国内外での訴求材料になっている
- 京都では日本初のクラフトブルワリー団体が設立、大阪・泉佐野に体験型醸造所が開業するなど、近畿圏でクラフト関連の動きが活発と報じられる（2026年）

> 卸にとっての意味：**小ロット・多品種を扱えるかどうかが差になる**。
> 従来の「大手ブランドを大量に流す」オペレーションとは逆方向の能力が要る。
> 専門子会社・専門部隊を持つか、洋酒卸売業免許ベースの専門商社と組むかの選択になる。

### 6-2. ノンアル・低アル

- 厚生労働省が2024年2月に「健康に配慮した飲酒に関するガイドライン」を公表。**純アルコール量（g）**での把握を推奨
- メーカーは缶への純アルコール量表示を進行。**アサヒビールが2020年12月に「スマートドリンキング」を提唱**
- 世界のノンアルコールビール市場は2025年の約328億ドルから2026年に約354億ドルへ拡大する見通し（調査会社の推計。機関により数値に幅がある）
- 国内でもノンアル飲料はビール系以外のフレーバーに広がっていると報じられる

**アルコール分1%未満は酒税法上の「酒類」ではない**ため、酒税がかからず免許も不要。
つまりノンアルは**卸にとって「免許の壁がない＝競合が増えやすい」領域**でもある。
清涼飲料の流通と競合する点は [清涼飲料](../../08_食品・農水産・外食/09_清涼飲料/README.md) も参照。

### 6-3. 輸出 ― 人口が増える市場へ

| 指標 | 数値 | 年・出典 |
| --- | --- | --- |
| 日本産酒類の輸出金額 | **1,337億円**（前年比▲0.5%） | 2024年・財務省貿易統計／国税庁 |
| 同・過去最高 | 1,392億円 | 2022年 |
| うちウイスキー | 436億円（前年比▲12.8%） | 2024年 |
| うち清酒 | 435億円（前年比＋5.8%） | 2024年 |
| 清酒の輸出（翌年） | **458.8億円**（前年比＋5.5%）、3.35万kL（＋8.0%） | 2025年・日本酒造組合中央会 |
| 2024年の輸出先1位 | 米国 265億円（＋11.6%） | 財務省貿易統計 |
| 同2位 | 中国 245億円（▲23.9%） | 同上 |

- 2025年の清酒輸出では**中国が金額トップ（133億円、＋13.9%）**、米国が2位（110億円、▲3.5%）と報じられる
- 韓国・カナダ・フランスは金額ベースで過去最高を更新
- 政府は農林水産物・食品の輸出額目標を5兆円と定め、国税庁も「輸出拡大実行戦略」で酒類の輸出促進に取り組んでいる
- ただし**世界の酒類市場に占める清酒（Sake）のシェアは0.1%に満たない**（2023年、IWSR）。伸びしろは大きいが、認知度はまだ低い

```
  【輸出における卸の役割】
   蔵元（小規模・輸出ノウハウなし）
        │
        ├─► 輸出入酒類卸売業免許を持つ卸／商社
        │      ・現地規制（ラベル表示、関税、酒類の輸入免許）への対応
        │      ・温度管理された国際輸送の手配
        │      ・現地インポーター／レストランとの接続
        ▼
   海外の消費者・レストラン

   ※輸出は「免許の枠がない領域」（輸出入酒類卸売業免許）なので、
     全酒類卸売業免許を持たない新規プレイヤーでも参入できる。
```

国分グループも日本酒の海外展開支援を長期計画に盛り込んでいる。
メーカー側の輸出戦略は [ビール・酒類](../../08_食品・農水産・外食/08_ビール・酒類/README.md) を参照。

## 7. 競争要因（KSF）と参入障壁

| 要素 | 内容 | 障壁の高さ |
| --- | --- | --- |
| **免許** | 全酒類卸売業免許は地域ごとに枠があり、9月に抽選 | **高い**（ただし洋酒・輸出入は低い） |
| 物流網 | 重量物・静脈物流・多頻度小口に対応する拠点と車両 | 高い |
| メーカーとの取引口座 | 大手メーカーの仕切条件・リベートは既存卸に有利 | 高い |
| 小売・料飲店との帳合 | 既存の担当関係は簡単には動かない | 中〜高 |
| 与信の体力 | 貸倒れを吸収できる資本 | 中 |
| 商品知識・提案力 | 地酒・ワイン・クラフトは**人の目利きが差になる** | 中（ここは新規参入の穴） |
| 規模 | 営業利益率1%の世界では、規模がそのまま体力 | 高 |

> 参入の穴はどこか：**洋酒卸売業免許と輸出入酒類卸売業免許には需給調整の枠がない。**
> そのため、ワイン・クラフトビール・輸入スピリッツ・日本酒輸出といった領域では、
> 小さな専門商社が次々に生まれている。逆に「全酒類をフルラインで全国に」という領域は、
> 免許と物流の二重の壁でほぼ固定されている。

## 8. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **課税数量／課税移出数量** | 製造場から出荷され酒税が課された量。国内需要の代表指標 |
| **新ジャンル（第三のビール）** | 麦芽以外を原料にするなどして税率を抑えたビール風飲料。2023年10月に法令上は発泡酒へ統合され、2026年10月にビールと同税率になる |
| **RTD** | Ready To Drink。缶チューハイ・缶ハイボールなど、開ければそのまま飲める製品 |
| **SKU** | Stock Keeping Unit。在庫管理上の品目数。クラフトや地酒が増えるとSKUが膨らむ |
| **純米酒・純米吟醸酒** | 米・米こうじ・水だけで造る清酒（吟醸は精米歩合60%以下など要件あり）。高付加価値帯 |
| **ノンアルコール飲料** | アルコール分1%未満。酒税法上の「酒類」ではないため酒税も販売免許も不要 |
| **IWSR** | 酒類市場の国際的な調査会社（Drinks Market Analysis）。世界市場規模の出典としてよく使われる |
| **輸出入酒類卸売業免許** | 自社が輸出入する酒類を卸売できる免許。需給調整の枠がなく、輸出参入の入口になる |
| **GI（地理的表示）** | 産地名を品質保証として独占的に名乗れる制度。「日本酒」「山形」「灘五郷」などが指定されている |
| **リベート** | メーカーが卸・小売に支払う販売促進金。卸の利益の一部を構成する |
