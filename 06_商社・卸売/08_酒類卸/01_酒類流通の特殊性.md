# 酒類流通の特殊性 ― 免許・酒税・二つのチャネル

このノートで分かること：酒類卸がなぜ「食品卸の一部門」では済まないのか。
答えは3つ、**免許で相手が限定される／価格の3割前後が税金／業務用と家庭用でほぼ別事業**、である。

---

## 1. まず結論：酒は「モノ」でなく「税と免許が乗ったモノ」

一般の食品卸は、仕入れて運んで売るだけなら誰でも始められる。酒類はそうではない。

- 酒類（アルコール分1度以上の飲料）は**酒税がかかる**。納めるのは製造者（蔵元・メーカー）だが、税は出荷時点で商品の原価に乗る。
- 税を取りはぐれないように、国は**製造・卸売・小売のすべてを免許制**にした。相手が免許を持っていなければ、売ることも買うこともできない。
- さらに酒は「致酔性（酔う性質）・習慣性がある」社会的配慮が必要な物品とされ、**価格の叩き合いにも規制**がかかる（後述の公正取引基準）。

> ポイント：酒類卸の仕事の半分は「物流と商売」だが、残り半分は「**免許という通行証の管理**」である。
> どの免許を持つかで、扱える酒の種類も、売れる相手も変わる。

管轄は農水省でも経産省でもなく、**国税庁（酒税課）**。監督官庁が税務当局であることが、この業界の性格を決めている。

食品卸一般の仕組み（帳合、リベート、センターフィー、多頻度小口配送など）は
[食品卸](../06_食品卸/README.md) 側に譲り、ここでは酒類固有の話に絞る。

## 2. 免許の階層 ― 製造・卸売・小売の三段構え

### 2-1. 全体像

```
   ┌──────────────┐    酒税を納めるのはここ
   │ 酒類製造免許 │    （製造場から出荷＝「移出」した時点で課税）
   │  4,070場     │    ビール大手、日本酒蔵、焼酎蔵、ワイナリー…
   └──────┬───────┘    ※令和5年度・国税庁「酒のしおり」
          │  ← 製造者は「小売」はできない（別途免許が要る）
          ▼
   ┌──────────────┐    酒類を「酒類業者に」売る免許
   │ 酒類卸売業免許│    全酒類 4,751場（令和5年度）
   │  （8区分）   │    ← このノートの主役
   └──────┬───────┘
          │  ← 卸売免許では消費者に直接売れない
          ▼
   ┌──────────────┐    酒類を「消費者・料飲店に」売る免許
   │ 酒類小売業免許│    全酒類 166,333場（令和5年度）
   │  （3区分）   │    量販店、コンビニ、DS、街の酒販店、飲食店への販売店
   └──────┬───────┘
          ▼
     消費者／料飲店（居酒屋・レストラン）
```

**ここが最大のハマりどころ**：卸売免許は「事業者に売る」免許、小売免許は「消費者や飲食店に売る」免許で、
**両者は別物**。飲食店に直接納品したいなら、卸売免許ではなく**小売免許**が要る
（飲食店は酒を"消費する"側に分類されるため）。業務用卸が「卸」を名乗りながら小売免許を持つのは、このためである。

### 2-2. 卸売業免許の8区分

| 免許の種類 | 扱える範囲 | 枠（需給調整）の有無 |
| --- | --- | --- |
| **全酒類卸売業免許** | すべての品目 | **あり**。地域ごとに件数枠。年1回（9月）申請受付・公開抽選 |
| **ビール卸売業免許** | ビールのみ | **あり**。同上 |
| 洋酒卸売業免許 | ウイスキー、ワイン、スピリッツ、リキュール等 | なし |
| 輸出入酒類卸売業免許 | 自社が輸出入する酒類 | なし |
| 店頭販売酒類卸売業免許 | 自店の店頭で、会員である酒類業者へ | なし |
| 協同組合員間酒類卸売業免許 | 所属する組合の組合員へ | なし |
| 自己商標酒類卸売業免許 | 自社開発ブランド（PB）の酒類 | なし |
| 特殊酒類卸売業免許 | 上記に当てはまらない特別な事情がある場合 | なし |

> なぜ全酒類とビールだけ枠があるのか：**量が出て税収が大きい主力品目**だから。
> 無制限に卸が増えると価格競争で市場が荒れ、酒税の保全（取りはぐれ防止）に支障が出る、という建前である。
> 結果として、**全酒類卸売業免許は事実上の既得権**になり、新規参入の壁として働いてきた。

一方、洋酒・輸出入には枠がない。**クラフトビール／ワイン／輸入スピリッツの専門商社が次々生まれるのは、この差が理由**である。

### 2-3. 小売業免許の3区分

| 免許の種類 | 中身 |
| --- | --- |
| 一般酒類小売業免許 | 店舗での販売。飲食店への納品もこれ |
| **通信販売酒類小売業免許** | 2都道府県以上をまたぐ通販。ただし**国産酒は年間課税移出数量3,000kL未満の製造者の酒**に限る |
| 特殊酒類小売業免許 | 自社の役職員向け販売など限定的なもの |

通販免許の「3,000kL未満」制限が効いていて、**大手メーカーのビールをECで全国に広く通販することは原則できない**。
逆に、小さな蔵元の日本酒やクラフトビールは通販に載せやすい。
EC時代に地酒系の専門通販が伸び、ナショナルブランドがそうでもないのは、この線引きによる。

## 3. 酒税 ― 価格の3割前後が税金

### 3-1. 税額の重さ

2023年度（令和5年度）の酒税収入は約**1.2兆円**（国税庁）。内訳はビール約4,461億円、発泡酒約1,655億円、
リキュール（チューハイ・新ジャンル中心）約1,608億円で、**ビール系＋低アル系で全体の約3分の2**を占める。

価格の積み上げをビール350ml缶でイメージすると、こうなる（2026年9月時点の税率・小売価格は試算）。

```
  店頭価格 約220円（税込）
  ├─ 消費税 10%           約 20円
  ├─ 酒税               63.35円   ← 2026年10月からは 54.25円
  ├─ 小売のマージン        約 30円
  ├─ 卸のマージン        約 5〜10円  ← 薄い！
  └─ メーカー出荷原価・利益 約100円
       └ 原材料・製造・容器・広告宣伝

  ※酒税だけで価格の約3割弱。消費税と合わせると約4割が税。
```

> ここから導かれる帰結：**酒類卸は「税金を運んでいる」ようなもの**。
> 仕入価格の中に税が入っているため、同じ売上高でも食品より「中身の薄い」売上になり、
> 在庫金額も膨らむ。運転資金の負担が重い業態なのはこのためである。

### 3-2. 品目別の税率（350ml換算、2026年9月時点と10月以降）

| 品目 | 〜2026年9月 | 2026年10月1日〜 | 差 |
| --- | --- | --- | --- |
| ビール | 63.35円 | **54.25円** | ▲9.10円（減税） |
| 発泡酒（麦芽比率25%未満） | 46.99円 | **54.25円** | ＋7.26円（増税） |
| 新ジャンル（2023年10月から発泡酒に統合） | 46.99円 | **54.25円** | ＋7.26円（増税） |
| チューハイ等「その他の発泡性酒類」 | 28円 | **35円** | ＋7円（増税） |
| 清酒・果実酒（醸造酒類） | 1kLあたり10万円で統一済（2023年10月〜） | 同左 | ― |

2020年10月・2023年10月・2026年10月の**3段階でビール系の税率を一本化**する改正の、最終段階が2026年10月である。
影響の詳しい話は [市場の縮小と各社の戦略](02_市場の縮小と各社の戦略.md) と
[直近トピック_2026](03_直近トピック_2026.md) を参照。

## 4. 2017年の「酒類の公正な取引に関する基準」― 安売りができなくなった日

### 4-1. 何が起きたか

2016年（平成28年）改正酒税法にもとづき、2017年3月31日に国税庁が
**「酒類の公正な取引に関する基準」**（国税庁告示）を定め、**2017年6月1日から適用**された。

中身を一言でいうと、

> **正当な理由なく、総販売原価を下回る価格で継続して酒類を売ってはならない。**
> 違反すれば指示・公表、悪質なら**免許取消**もありうる。

「総販売原価」には、仕入価格に加えて**物流費・人件費・販売管理費までを算入する**。
つまり「仕入れ値ギリギリ」でも足りず、**自社のコストを全部乗せた上で黒字**でなければならない。

### 4-2. なぜ作られたか

```
 【2017年以前】 メーカー ─► 大手量販・DS ─► 消費者
    大量仕入れのリベート＋原価割れの集客用値付け（ビール1本98円など）
        └► 街の酒販店は対抗できず廃業／卸のマージンも際限なく圧縮

 【2017年6月以降】 総販売原価（仕入＋物流＋人件費＋販管費）割れの継続販売を禁止
        ├► 量販の目玉価格が消えた（ビールは全体に値上げ）
        ├► 卸が物流費を価格に転嫁しやすくなった
        └► ただし小規模酒販店の延命効果は限定的
```

### 4-3. 卸にとっての意味

| 論点 | 基準の導入前 | 導入後 |
| --- | --- | --- |
| 価格決定 | 量販の要求に押される一方 | 「原価割れはできない」と断る**法的な根拠**ができた |
| 物流費 | 卸が飲み込む慣行 | 「総販売原価に含む」ため**転嫁の交渉材料**になった |
| チャネル間の価格差 | 量販と街の酒販店で大差 | 差は縮小。ただし**量販の規模の優位は残る** |
| 卸の利益率 | 極薄 | **極薄のまま**（0.5〜1%台）。基準は下限を決めただけで、上限を押し上げてはいない |

> 誤解しやすい点：公正取引基準は「**価格の下限を守る**」規制であって、卸の利益を保証する制度ではない。
> 卸の営業利益率が1%前後に張り付いている構造は、これで変わっていない。

なお、独占禁止法の不当廉売規制（公正取引委員会）とは**別建ての規制**で、二重にかかる。

## 5. 業務用と家庭用 ― 同じ酒でも商売が違う

酒類卸を理解する最大の分水嶺がここ。同じ「ビールを運ぶ」仕事でも、**相手が飲食店か量販店かで別事業**である。

```
                     ┌──────────────────────┐
                     │   酒類メーカー・蔵元  │
                     └───────┬──────────────┘
                             │
          ┌──────────────────┴──────────────────┐
          ▼                                     ▼
   ┏━━━━━━━━━━━━━━━┓                    ┏━━━━━━━━━━━━━━━┓
   ┃  業務用ルート     ┃                    ┃  家庭用ルート     ┃
   ┃（料飲店＝飲食店） ┃                    ┃（量販店・CVS）   ┃
   ┗━━━━━━┳━━━━━━━━┛                    ┗━━━━━━┳━━━━━━━━┛
          │ 全国卸 → 地場の業務用酒販店       │ 全国卸が直接
          │（二次卸）が介在することが多い     │ センター納品
          ▼                                   ▼
    居酒屋・レストラン・ホテル             スーパー・コンビニ・DS
    ・樽生ビール、一升瓶、業務用サイズ      ・缶、小容量、PB
    ・少量多頻度、深夜・早朝納品            ・パレット単位、計画配送
    ・掛売り（月末締め翌月払い）            ・与信は基本的に安全
    ・提案営業（メニュー・イベント）        ・棚割提案、販促金、リベート
```

| 論点 | 業務用（飲食店向け） | 家庭用（量販店向け） |
| --- | --- | --- |
| 1回あたりの納品量 | 小さい（ビール数ケース＋各種） | 大きい（パレット・トラック単位） |
| 納品頻度・時間帯 | 多頻度。開店前の早朝や深夜 | 計画的。物流センター経由 |
| 粗利率 | **相対的に高い**（配送手間の対価） | 低い。値入れが薄い |
| 物流コスト | 非常に高い。人手依存 | 相対的に低い。機械化・共同配送が効く |
| 与信リスク | **高い**（後述） | 低い |
| 商品構成 | 樽生、一升瓶、業務用ボトル、地酒 | 缶、ペット、ギフト、PB |
| 営業のやること | メニュー提案、新規開店の獲得、機器の面倒 | 棚割・販促提案、チラシ対応 |
| 需要のブレ | 大きい（天候、感染症、景気、宴会需要） | 小さい |

> ポイント：業務用は「**粗利は高いがコストと回収リスクも高い**」、家庭用は「**薄利だが量とオペレーションで稼ぐ**」。
> 全国系の酒類卸は両方を持つが、収益の質はまったく違うので、社内では別組織になっていることが多い。

業務用のもう一つの特徴が、**樽生ビールのインフラ**。
ディスペンサー（ビールサーバー）、炭酸ガス、洗浄、空樽の回収まで卸や地場酒販店が面倒を見る。
これは「配送」ではなく**設備サービス**であり、一度入れると簡単には切り替わらない＝
**業務用のスイッチングコストが高い**理由になっている。

飲食店側の経済性は [居酒屋](../../08_食品・農水産・外食/16_居酒屋/README.md)、
酒類メーカー側は [ビール・酒類](../../08_食品・農水産・外食/08_ビール・酒類/README.md) を参照。

## 6. 料飲店への与信 ― 業務用卸の最大のリスク

### 6-1. なぜ焦げるのか

飲食店は、**開業しやすく、廃業しやすい**。酒類卸は、そこに掛売り（後払い）で商品を納める。

```
 【与信サイクル】
 月初 ─ 納品（毎日、少量ずつ）─► 月末 締め ─► 請求 ─► 翌月末 入金（or 未回収）

 納品から回収まで30〜60日の立て替え。その間に店が閉まれば商品も代金も戻らない。
 酒は「飲まれてしまう」ので、担保として引き揚げることもできない。
```

一般消費財の卸より**リスクが高い理由**は3つ。

1. **回収不能でも仕入代金は払う**。卸はメーカーへの支払いを止められない
2. **商品が担保にならない**。在庫は店で消費済み
3. **小口多数**。1件は数十万円でも、件数が多いので合計すると効く

### 6-2. 卸がやっている対策

| 対策 | 中身 |
| --- | --- |
| 与信限度額・保証金 | 店ごとに掛売りの上限を置き、新規開店時は預り金を取る |
| 締めサイトの短縮 | リスクの高い先は週払い・前払いに切り替える |
| 取引信用保険・ファクタリング | 貸倒れを保険や債権買取でヘッジする |
| 地場酒販店（二次卸）を挟む | **与信リスクを二次卸が負う**。全国卸は二次卸だけを見ればよい |
| 什器貸与とのセット | 冷蔵庫・サーバーの貸与と取引継続を条件で結びつける |

> 「なぜ全国卸がわざわざ地場の酒販店を残すのか」という問いの答えの半分がこれ。
> **与信と早朝配送という、大手がやると赤字になる仕事を二次卸が引き受けている**。
> 残り半分は、地域の飲食店との人的関係（誰が開店するかの情報）である。

### 6-3. 数字で見るリスクの現実

東京商工リサーチによると、**2026年上半期の「飲食業」倒産は509件**で、1997年以降で初めて500件台に乗った。
うち「居酒屋（酒場、ビヤホール）」が**118件**と、初めて100件を超えた（2026年8月発表・報道ベース）。
物価高倒産は86件（前年同期比53.5%増）、人手不足関連は36件（同125.0%増）。

**居酒屋の倒産が過去最多ということは、業務用酒類卸の焦げ付きリスクも過去最悪水準にある**、ということである。

## 7. 物流 ― 重い・割れる・戻ってくる

酒類固有の物流の難しさを整理しておく。

| 特性 | 中身 | 効いてくるところ |
| --- | --- | --- |
| **重い** | ビール1ケース（大瓶20本）で約25kg | トラックは**重量で先に上限**に達する。容積が余っても積めない |
| **割れる** | 瓶が主力の品目（日本酒、ビール大瓶、ワイン） | 荷扱いに人手がかかり、自動化しにくい |
| **戻ってくる** | リターナブル瓶・ビール樽・P箱（通い箱）の回収 | **静脈物流**が必要。片道では終わらない |
| 温度・記帳 | 定温・冷蔵が望ましい品目があり、受払の**帳簿記録義務**（酒税法）もある | 冷蔵投資と、食品とは違う在庫管理要件 |

```
 【酒類物流の往復構造】
   卸の物流センター ──── 満瓶・満樽 ────►  飲食店・小売店
          ▲                                     │
          └── 空瓶・空樽・P箱（静脈）← 洗浄 ←───┘ → メーカーへ返却 → 再充填

 ※食品卸の「行ったら終わり」の片道物流と決定的に違う。2024年問題（トラック
   運転手の時間外労働上限規制）で、この往復を誰が担うかが業界の共通課題になった。
```

物流全般の構造は [倉庫・3PL](../../13_運輸・物流/08_倉庫・3PL/README.md) を参照。

## 8. 健康・社会面の前提（中立に）

酒類は嗜好品であると同時に、健康リスクと社会的リスクを伴う物品として扱われている。
業界を理解するうえで、次の事実は押さえておく必要がある。

- **20歳未満の飲酒は法律で禁止**されている。販売時の年齢確認は酒類販売管理者の責務であり、卸・小売の運営コストの一部になっている。
- 厚生労働省は2024年2月に**「健康に配慮した飲酒に関するガイドライン」**を公表し、純アルコール量（グラム）で飲酒量を把握することを推奨している。これを受けたメーカーの**缶への純アルコール量表示**は、卸の商品マスタ管理・商品切替の実務に直結する。
- 「飲まない／飲めない人も一緒に楽しめる」という考え方（**スマートドリンキング**、2020年12月にアサヒビールが提唱）が業界の共通言語になりつつあり、ノンアル・低アルの品揃えは卸の提案テーマになっている。

本ノートは流通構造の解説であり、飲酒を推奨するものではない。

## 9. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **酒類** | 酒税法上、アルコール分1度（1%）以上の飲料。1%未満は「ノンアルコール飲料」で酒税がかからず、免許も不要 |
| **課税移出** | 製造場から酒類を出荷すること。この時点で酒税の納税義務が発生する。業界の需要指標として「課税移出数量」が使われる |
| **全酒類卸売業免許** | すべての品目を卸売できる免許。地域ごとに件数枠があり、年1回9月に申請受付、公開抽選で順位を決める |
| **総販売原価** | 仕入価格＋物流費＋人件費＋販管費。2017年の公正取引基準が「これを下回る継続販売の禁止」を定めた |
| **料飲店（りょういんてん）** | 酒類業界の用語で、酒を提供する飲食店のこと。居酒屋、レストラン、バー、ホテル等 |
| **業務用／家庭用** | 料飲店向け＝業務用、量販店・CVS向け＝家庭用。チャネルの呼び分け。「オントレード／オフトレード」とも |
| **二次卸** | 全国卸から仕入れて地元の飲食店に納める地場の酒販店。与信と早朝配送を担う |
| **樽生（たるなま）** | 樽詰めの生ビール。サーバー設置・炭酸ガス・洗浄・空樽回収までがセットの業務用インフラ |
| **P箱** | ビール瓶などを入れるプラスチック製の通い箱。返却が前提の資材 |
| **帳合（ちょうあい）** | どの卸がどの小売の取引窓口になるかという商流上の担当関係。食品卸と共通の用語 |
| **純アルコール量** | 飲料の量×度数×0.8で計算されるアルコールのグラム数。2024年の厚労省ガイドライン以降、表示が進む |
| **スマートドリンキング** | 体質や状況に応じて飲む量・飲まない選択を自分で選ぶという考え方。2020年12月にアサヒビールが提唱 |
