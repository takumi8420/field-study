# プレイヤーと商売の型

このノートで分かること：「機械商社」と一括りにされる会社が、実際は **在庫・物流で稼ぐ型** と
**技術提案で稼ぐ型** の2種類に分かれていること。そして両者を同時に揺さぶっている3つの力
（間接資材のネット通販、メーカー直販、設備投資サイクル）の正体。

## 1. 結論：同じ看板の下に、まったく別の商売が2つある

```
【機械商社の2類型】

                売るもの ──▶ 点数が多く単価が小さい      点数が少なく単価が大きい
                              （工具・部品・消耗品）        （機械・生産ライン）
              ┌──────────────────────┬──────────────────────┐
  在庫を持ち  │ ★在庫・物流型★                   │ （成立しにくい：1億円の機械を  │
  即納で勝つ  │ トラスコ中山／MonotaRO／ミスミ    │  見込みで在庫する体力はない）  │
              │ 武器＝品揃え・当日出荷・検索性     │                                │
              ├──────────────────────┼──────────────────────┤
  人が現場に  │ （地場の機工商社。御用聞き型。     │ ★技術提案型（装置商社）★      │
  出て勝つ    │  ネット通販に最も削られた層）      │ 山善／YUASA／第一実業／ユニソル│
              │                                    │ 武器＝技術営業・据付・保守     │
              └──────────────────────┴──────────────────────┘

  ◆ 損益計算書の形が違う：在庫・物流型＝粗利率高い／物流固定費重い
                            技術提案型＝粗利率薄い／人件費と与信が重い
```

両者は表面的には競合しない（売っている物が違う）。
しかし**客の財布は同じ**であり、客の購買部門から見れば「設備を買う窓口」は1つに統合したい。
そのため、在庫型は上位商材へ、技術型は消耗品へと、互いの領域へにじみ出している。

## 2. 在庫・物流型：品揃えと即納が商品

**どんな商売か** … カタログ（いまはサイト）に数百万点を載せ、注文が来たら当日〜翌日に届ける。
売っているのは製品そのものではなく、**「探す手間」と「待つ時間」を消す機能**である。

| 論点 | 中身 |
| --- | --- |
| 収益源 | 仕入れ値と売値の差（粗利）。1点の単価は数百円〜数万円 |
| 粗利率 | 技術提案型より高い。少額多品種で価格比較が起きにくいため |
| 最大の固定費 | **物流センターと在庫**。自動倉庫に数百億円を投じる |
| 損益分岐の性質 | 出荷点数が増えるほど1点あたり物流費が下がる。**規模が効く典型** |
| 弱点 | 需要が落ちても倉庫と在庫は残る。固定費が高い＝不況期の落ち込みが鋭い |

```
【在庫・物流型の稼ぎ方（点数のスケールメリット）】

  メーカー数千社 ──▶ ┌───────────────┐ ──▶ 全国の工場・現場
                      │ 物流センター        │      （1回あたり数千円の注文が
  数百万〜数千万点 →  │ ・自動倉庫          │       1日に何十万件）
  をあらかじめ在庫    │ ・当日出荷          │
                      └───────────────┘
        ▲                      │
        │                      ▼
   「在庫を持つ」＝資金を寝かせるリスク   「即納できる」＝価格より強い価値
   →持てる体力のある会社しか参入できない  →客は止まった設備を1日でも早く直したい

  ◆ 在庫回転率（年に何回、在庫が入れ替わるか）と
    出荷1件あたり物流コストが、この型の死活指標
```

### 主なプレイヤー（2025〜2026年の公表数値）

| 企業 | 直近売上 | 型 | 特徴 |
| --- | --- | --- | --- |
| **MonotaRO** | 2026年12月期 会社予想 **3,813億円**（前期比+14.2%、営業利益530億円予想） | ネット通販特化 | 事業者向けECの本命。2026年1〜3月期は売上955億円（+20.8%）と高成長が続く |

| **ミスミグループ本社** | 2026年3月期 売上 **4,413億円**（+9.8%）、営業利益476億円（+2.4%） | カタログ＋受注生産 | FA事業1,604億円（+18.2%）、金型部品883億円、流通商材のVONA事業1,925億円 |

> ポイント：トラスコ中山とMonotaROは似て見えて立ち位置が逆。
> **トラスコは「販売店に売る」卸**、**MonotaROは「使う人に直接売る」小売**。
> 前者は既存の流通を支え、後者は既存の流通を飛ばす。同じMRO市場にいながら、流通に与える力が正反対である。

## 3. 技術提案型（装置商社）：人と責任が商品

こちらは [① 機械を売る商社の付加価値](01_機械を売る商社の付加価値.md) で詳述した世界。
設備一式を提案し、据付・試運転まで責任を持ち、保守で食いつなぐ。

| 論点 | 中身 |
| --- | --- |
| 収益源 | 機械本体の粗利（薄い）＋工事・エンジニアリング＋保守部品（厚い） |
| 最大の固定費 | **人件費**。技術営業とサービス員を抱えることが参入障壁そのもの |
| 運転資金 | 受注から検収まで数か月。**立替金と在庫で資金が寝る** |
| 弱点 | 設備投資が止まると受注がほぼゼロになる（後述のサイクル） |
| 強み | 一度納めると10〜20年の保守収益がつく。代理店契約は簡単に動かない |

> 町工場に旋盤を売る世界とは別物。専門機械商社は**投資で稼ぐ層を持たない**点が決定的に違う。

## 4. MRO＝間接資材のネット通販が、流通の形を変えた

この20年で機械流通に起きた最大の変化は、**工具や部品の買い方がネットに移ったこと**である。

**MRO（Maintenance, Repair, Operations）** ＝ 製品そのものにはならないが、工場を動かすために要るもの。
切削工具、ねじ、軸受、手袋、潤滑油、清掃用品、測定器……点数は数百万点に及ぶ。
国内MRO市場の規模は**5兆〜10兆円規模**と見られ（2015年時点の推計で約8兆円という数字がよく引かれる／調査会社・事業者の推計）、
MonotaRO の売上（2026年12月期予想3,813億円）で割り戻しても**シェアは数%台**にとどまる。
つまり **市場の大半はいまも対面の地場商社が握っているが、成長分は丸ごとネットに流れている**。

```
【MRO購買のビフォー・アフター】

 ＜従来＞
  現場「これ無くなった」→ 地場商社の営業が御用聞きに来る → メーカー/二次卸へ発注
    → 数日後に届く → 請求は月まとめ
  価格は不透明（客ごとに違う）。だが「困ったら電話1本」という安心があった

 ＜ネット通販以後＞
  現場 → サイトで型番検索 → 価格と在庫がその場で見える → 当日出荷
    → 購買システムと連携して自動で仕訳
  ・価格が全国一律で可視化 →「客ごとの値段」が崩れる
  ・少額品を運ぶだけの営業訪問が成り立たなくなる
  ・地場商社の売上のうち「消耗品でつないでいた部分」が消える

 結果：地場商社は ①機械・エンジニアリングへ上がる
                  ②在庫・物流型の二次卸（トラスコ等）に物流を任せる
                  ③廃業・売却（後継者難）
       のいずれかを選ばされている
```

> ポイント：ネット通販が奪ったのは **「探す・比べる・運ぶ」という情報と物流の機能**だけ。
> **「選んでやる・据え付ける・直す」機能は奪えていない**。
> だから消耗品の商売は削られ、エンジニアリングの商売は残る、という分岐が起きている。

## 5. メーカー直販化の圧力

もう一方向からの圧力が、メーカーが商社を飛ばして直接売る動きである。

| 直販が進みやすい条件 | 進みにくい条件 |
| --- | --- |
| 客が少数の大企業に集中（半導体、自動車完成車メーカー） | 客が全国に数万社ある（町工場、建設業者） |
| 1件が大型で、自前の営業コストが回収できる | 1件が小口で、訪問コストが見合わない |
| 製品が自社完結（周辺機器が要らない） | 他社製品と組み合わせないと使えない |
| サービスを自社で持つ方針（ブランド管理） | 全国サービス網を自前で持つと赤字 |
| ソフトウェア・サブスクで課金したい | 現物の在庫と据付が必要 |

現場で実際に起きているのは「全面直販」ではなく、**取引の切り分け**である。
大口客はメーカーが直接持ち、中小口は商社に任せる。商社にとっては
**一番おいしい客だけ抜かれ、手間のかかる客が残る**という形になりやすい。

これに対する商社側の応手は3つ。

1. **一括責任の深掘り**：機械単体でなく「ライン一式」で受け、メーカー1社では受けられない範囲に立つ
2. **自社ブランド（PB）とオリジナル商品**：メーカーに代替されない商材を持つ
3. **M&Aによる規模と機能の確保**：技術者を抱えた会社を買い、エンジニアリング機能を買い足す
   （例：鉄鋼商社の阪和興業が工作機械・金属加工機械を扱うシンクスを買収したと報じられるなど、
   異業種からの機械商社領域への参入も起きている／報道ベース）

## 6. 中国・アジアでの現地販売

日本の機械商社の海外事業は「輸出の代行」から「現地で現地企業に売る」段階に移っている。

| 地域 | 商社にとっての意味 |
| --- | --- |
| **中国** | かつては日系工場向けの供給が中心。現在は現地メーカーの内製化・国産機の台頭で競争が激化。日本メーカーの中国向け工作機械は政策・景気の影響を強く受ける |
| **台湾・韓国** | 半導体・電子部品の設備需要。景気変動が激しいが単価が大きい（[半導体製造装置](../../03_電機・電子部品/03_半導体製造装置/README.md)） |
| **ASEAN（タイ・ベトナム・インドネシア）** | 日系製造業の集積地。自動車部品と電子部品が二本柱。中国からの生産移管（チャイナプラスワン）の受け皿 |
| **インド** | 最後の大型市場とされる。ただし回収リスクと商習慣の壁が高く、拠点を持つ商社が強い |
| **北米** | 単価が高く、自動化投資が旺盛。山善などが通期で前年超えと公表（2026年3月期） |

現地販売で商社が担うのは、**現地通貨での与信・回収、現地在庫、現地語のサービス、現地の補助金・規制対応**。
メーカーが自前で作るには固定費が重すぎるため、ここは直販化の圧力が比較的弱い。

## 7. 業績が設備投資サイクルに連動する構造

機械商社の業績は、自社の努力よりも **客の設備投資意欲**で決まる。これが業態の宿命である。

```
【設備投資サイクルと機械商社の業績】

  景気・企業収益
      ▲                 ╱‾‾╲                        ╱‾‾╲
      │        ╱‾╲    ╱      ╲      ╱‾╲          ╱      ╲
      │   ╱‾╲╱    ╲╱          ╲╱      ╲╱‾╲    ╱          ╲
      └──────────────────────────────────▶ 時間
              ↓ 半年〜1年遅れて
  設備投資（工作機械受注）
      ▲            ╱‾‾╲                    ╱‾‾╲
      │    ╱‾╲   ╱      ╲       ╱‾╲     ╱      ╲        振れ幅は景気より大きい
      │  ╱    ╲╱          ╲___╱    ╲__╱          ╲     （加速度原理：需要の伸びが
      └──────────────────────────────────▶       鈍るだけで投資は減る）
              ↓ さらに数か月遅れて（受注→据付→検収）
  機械商社の売上・利益
      ▲               ╱‾‾╲                     ╱‾‾╲
      │     ╱‾╲     ╱      ╲      ╱‾╲       ╱      ╲
      └──────────────────────────────────▶

  ◆ 商社の売上は「受注」ではなく「検収」で立つため、統計よりさらに遅れる
  ◆ 逆に言えば、工作機械受注統計（日工会）は機械商社の業績の先行指標になる
  ◆ 保守・部品・MROは投資が止まっても消えない＝この部分が厚い会社ほど業績が安定する
```

**足元の局面（2026年）は明確な上り坂**である。
日本工作機械工業会の集計で、2026年上期（1〜6月）の工作機械受注総額は前年同期比35.7%増の
**1兆551億円**と、暦年上期として初めて1兆円を超えた。
2026年7月も1,931億円（前年同月比+50.4%）で13か月連続の増加。
通年では **1兆7,000億円**規模との見方が報じられている（日本経済新聞・2026年1月報道）。
背景はAI関連投資、半導体、自動化・省人化投資で、詳細は
[③ 直近トピック（2026年9月時点）](03_直近トピック_2026.md) に整理した。

## 8. 再編・事業承継：数が減っていく業界

機械工具商社は全国に数千社あるとされるが、以下の力が同時にかかっている。

| 圧力 | 内容 |
| --- | --- |
| **後継者不在** | オーナー経営の中小商社が多く、経営者の高齢化が進む。M&Aの売り手が構造的に多い |
| **技術者の採用難** | 技術営業もサービス員も育成に年単位。中小単独では新卒採用が困難 |
| **システム投資** | EC化、在庫連携、電子受発注への対応に投資が要る。単独では償却できない |
| **メーカーの代理店整理** | メーカー側も管理コスト削減のため取引代理店数を絞る傾向 |

その結果が、**ジーネットとマルカの統合によるユニソル発足（2026年1月）** に代表される同業統合や、
商社による同業買収・異業種からの参入である。
機械商社の再編は「規模の追求」よりも **「技術者とメーカー代理店権をまとめて取りにいく」** 動機で起きる点が特徴。

## 9. 何を見れば会社の実力が分かるか

| 指標 | 見方 |
| --- | --- |
| **売上総利益率（粗利率）** | 単純転売中心か、エンジニアリング込みか。10%を切るなら横流し比率が高い |
| **販管費率と1人あたり粗利** | 技術営業を抱える会社は販管費が重い。1人あたり粗利が人件費を賄えているか |
| **在庫回転率** | 在庫・物流型は回転の速さが命。装置商社では立替と仕掛の重さを示す |
| **受注残高** | 装置商社では翌期以降の売上の予約。減り始めがサイクルの転換点 |
| **保守・部品・サービス比率** | 高いほど不況耐性が強い。開示は少ないが説明会資料で触れられることがある |
| **海外売上比率** | 国内設備投資の谷を埋める手段。ただし為替と回収リスクを背負う |
| **代理店権の顔ぶれ** | 決算書に出ないが最重要。どのメーカーの一次代理店かで将来の商権が決まる |

> まとめ：機械商社を見るときは「売上の大きさ」より **「粗利がどこから来ているか」** を見る。
> 本体転売の粗利なら削られる一方、エンジニアリングと保守の粗利は当面消えない。
> ネット通販と直販は前者を攻め、後者には届いていない。

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **MRO** | 生産設備の維持・補修・運用に使う間接資材。工具・部品・作業用品など。製品の材料（直接材）と対比される |
| **間接資材／直接材** | 直接材＝製品そのものになる材料。間接資材＝製品にはならないが操業に必要なもの |
| **二次卸** | メーカーから仕入れ、販売店（商社）に卸す立場。トラスコ中山が代表例。使う人には直接売らない |
| **在庫回転率** | 年間売上原価 ÷ 平均在庫。何回在庫が入れ替わったか。高いほど資金効率がよい |
| **受注残高** | 受注済みでまだ売上計上していない金額。装置商社の将来売上の目安 |
| **粗利率（売上総利益率）** | （売上−売上原価）÷ 売上。商社の付加価値の厚みを示す |
| **PB（プライベートブランド）** | 商社が自社ブランドで企画・供給する商品。メーカーに代替されにくい |
| **チャイナプラスワン** | 生産拠点を中国以外にも分散させる企業行動 |
| **加速度原理** | 需要の「伸び率」が鈍るだけで設備投資は減少に転じる、という経済学の考え方。設備投資が景気より激しく振れる理由 |
| **日工会（にっこうかい）** | 一般社団法人日本工作機械工業会。月次の受注統計が設備投資の代表的な先行指標 |
| **SEAJ** | 一般社団法人日本半導体製造装置協会。半導体・FPD製造装置の需要予測を年数回発表する |
| **一次代理店／二次代理店** | メーカーと直接契約するのが一次、一次から仕入れるのが二次 |
