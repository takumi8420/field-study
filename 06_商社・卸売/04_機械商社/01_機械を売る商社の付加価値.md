# 機械を売る商社の付加価値

このノートで分かること：**機械商社が「安く買って高く売る」だけでは1社も生き残れない理由**と、
その代わりに何を売っているのか（据付・試運転・保守・改造というエンジニアリング機能、そして技術営業という人）。

## 1. 結論：機械は「買った瞬間」には価値がない

食品や鉄鋼なら、モノが届けば取引は終わる。機械は違う。

```
【機械が「買い物」として特殊な理由】

  食品・日用品を買う                機械を買う
  ────────────      ────────────────────
  箱が届く                          機械が届く（まだ何も生み出さない）
      ↓                                  ↓  基礎工事・電源・配管・据付
  食べる／使う                      設置して、水平を出して、電気を通す
      ↓                                  ↓  試運転・ティーチング・精度出し
  終わり                            自社の製品が「図面どおりに」削れて初めて価値が出る
                                         ↓  操作教育・保守・部品交換
                                    10〜20年使い続ける（ここが一番長い）
```

> ポイント：機械の価値は **「動いて、狙った品質のモノを、狙った速度で作り続けられる」状態**にして初めて生まれる。
> その状態を作る作業を誰かがやらなければならない。**そこを引き受けるのが機械商社**である。

逆に言えば、カタログを見せて注文書を取り、メーカーに転送するだけの商社（＝**単純な横流し**）は、
機械の価値づくりに何も寄与していない。だからメーカーからも客からも「中間マージンを抜くだけの存在」と見なされ、
真っ先に外される。これが機械商社という業態を理解する出発点である。

## 2. なぜメーカーは商社を使うのか

「メーカーが直接売ればいい」は正しい指摘だが、多くの機械メーカーはそうしない（できない）。理由は3つ。

| メーカー側の事情 | 中身 | 商社が代わりに持っているもの |
| --- | --- | --- |
| **客が多すぎて散らばっている** | 工作機械の買い手は全国数万の町工場。1台1,000万〜1億円だが、1社が買うのは数年に1台 | 地場に張りついた営業網。「隣町の◯◯製作所が主軸を替えたい」という情報 |
| **与信を取りたくない** | 中小の工場に1億円の掛け売りをして倒れたら丸損。手形・分割・[リース](../../05_金融/10_リース/README.md)の面倒も見たくない | 商社が自分の信用で買い取り、客に売る（**与信の肩代わり**）。貸倒れは商社の損 |
| **売った後の面倒が重い** | 全国にサービス拠点を置くと固定費が跳ね上がる。海外ならなおさら | 商社の技術部隊が一次対応する。メーカーは重故障だけ出ていく |

この3つをまとめると、機械商社の存在理由は **「メーカーが持ちたくない固定費とリスクを、複数メーカー分まとめて引き受ける」** ことになる。
1社のメーカーのために営業所を置くと赤字でも、20社分の商材を同じ営業所で扱えば成り立つ。これが商社の規模の経済である。

## 3. 機械が納まるまでの工程と、商社が出てくる場面

```
【設備が導入されるまで（工作機械1台の例）】

 ①引合   ②仕様決め  ③見積・提案  ④受注   ⑤搬入・据付  ⑥試運転   ⑦量産立上げ  ⑧保守・改造
  客の困り   加工テスト   機械＋周辺    価格    基礎・搬入    精度出し   条件出し     部品・修理
  ごと      （デモ）     一式の構成    与信    クレーン手配  安全確認   歩留り改善   10〜20年
   │         │           │           │        │            │         │           │
   ▼         ▼           ▼           ▼        ▼            ▼         ▼           ▼
 ┌────────────────────────────────────────────────┐
 │ 商  社（技術営業＋サービス部隊）が全工程に関与                        │
 └────────────────────────────────────────────────┘
        ▲              ▲                        ▲                    ▲
     メーカー       メーカー技術           メーカー据付員         メーカー部品供給
     （②③で同行） （加工条件の相談）      （難物のみ）           （商社が在庫も持つ）

 ※単純な横流し商社は ④ だけに関与する ＝ 抜かれても誰も困らない
```

**注目すべきは②③と⑧**。ここに時間と人手がかかり、ここでしか差がつかない。

- ②**仕様決め**：客は「この部品を月3,000個作りたい」としか言わない。それを
  「この機種＋このチャック＋このツーリング＋ロボットでの自動供給」という**構成**に翻訳するのが商社の仕事
- ③**提案**：機械本体はメーカー品だから誰が売っても同じ。差がつくのは**周辺（治具・工具・搬送・計測・ソフト）の組み合わせ**
- ⑧**保守**：客が最も困るのは「止まったとき」。ここで駆けつけられるかどうかが次の1台の受注を決める

## 4. エンジニアリング機能の中身

「エンジニアリング機能」と一言で言われるが、実際は次の5つに分解できる。

| 機能 | やること | 収益への効き方 |
| --- | --- | --- |
| **据付（すえつけ）** | 搬入・アンカー打ち・水平出し（レベル出し）・電源／エア配管の接続 | 工事費として請求。粗利は工事の手配料 |
| **試運転（しうんてん）・立会い** | 実際に客のワークを削って精度・サイクルタイムを確認。**客の検収（けんしゅう＝合格判定）が出て初めて売上になる** | ここで揉めると入金が遅れる。回収リスクの源 |
| **ティーチング／条件出し** | ロボットの動作教育、加工条件（回転数・送り・工具）の作り込み | 有償のことも無償のこともある。無償なら実質的な値引き |
| **保守・修理（アフターサービス）** | 定期点検、故障対応、消耗部品交換、オーバーホール | **粗利率が本体より高い**。景気に左右されにくい |
| **改造・レトロフィット** | 古い機械の制御装置（NC）だけ新しくする、自動化装置を後付けする | 新規設備より安く、投資を渋る局面でも売れる |

> ポイント：本体販売の粗利率は薄い（後述）。**商社の利益の質を決めているのは、下2つ（保守と改造）の積み上げ**。
> 1台納めると10〜20年の部品・修理の権利がついてくる、という見方ができる。

### 検収（けんしゅう）という関門

機械の売買契約では、据付・試運転が終わり、客が「仕様どおり動いた」と認めた時点＝**検収**で所有権と代金支払義務が移るのが一般的。
つまり商社は、**メーカーに払ってから客から回収するまでの数か月分の資金を立て替える**。
機械商社の貸借対照表に「棚卸資産」と「前渡金」が膨らむのはこのためで、**在庫負担と与信負担こそが商社機能の実体**である。

## 5. 代理店という契約の形

機械の流通は「代理店（ディーラー）制」で組まれている。誰がどこで何を売ってよいかが契約で決まっている。

```
【代理店構造（工作機械の典型）】

  メーカー（例：NC旋盤メーカー）
      │  代理店契約（テリトリー・年間目標・仕切価格）
      ├──▶ 一次代理店（特約店）… 県単位・地域単位で1〜数社
      │        │  デモ機を置く／サービス員を抱える／在庫を持つ
      │        └──▶ 二次代理店（サブディーラー）… 町工場との接点だけを持つ
      │                     │
      └──────────────────▼
                          エンドユーザー（工場）

  ◆ 商社の格は「何のメーカーの一次代理店を持っているか」でほぼ決まる
  ◆ 一次の座は簡単には動かない＝この業界の最大の参入障壁
  ◆ ただしメーカーは不振代理店の契約を切れる＝安住もできない
```

- **仕切価格（しきりかかく）**：メーカーが代理店に卸す価格。販売実績や販促協力で階段状に変わる
- **テリトリー制**：地域や客先を割り当て、代理店同士の値引き合戦を防ぐ。だが実務では越境が起き、値崩れの火種になる
- **デモ機・実演**：一次代理店はショールームに実機を置く。**数千万円の在庫を自腹で持てるか**が一次になれるかの分かれ目

## 6. メーカーの海外販売網を「代替」する役割

日本の機械メーカーは中堅・中小が多く、単独で世界に販売網を作れない。
そこを商社が埋めているのが、機械商社の国際的な存在意義である。

```
【日本メーカーが海外で売るときの2つの道】

 (A) 自前で売る                        (B) 商社に任せる
  現地法人設立 ─ 人を雇う ─ 在庫を       商社の既存拠点に相乗り
  持つ ─ サービス員を育てる              （営業・通関・現地在庫・回収・サービスを共用）
  ────────────────         ────────────────
  固定費が重い。撤退もしにくい            1社あたりの負担が軽い。ただし客の顔は商社が握る
  大手（ファナック級）はこちら            中堅メーカーの大半はこちら
```

商社側が現地で実際にやっているのは、輸出入の書類・通関、現地通貨での与信と回収、現地在庫と部品供給、
現地語でのサービス、そして**その国の商習慣に合わせた支払条件の設計**である。
中国・ASEAN・インドでは「代金を取りはぐれない仕組み」を作れるかが最大の論点で、
ここは商社が数十年かけて作ったノウハウに強く依存する。詳しくは
[② プレイヤーと商売の型](02_プレイヤーと商売の型.md) の海外の章で扱う。

## 7. 技術営業という職種

機械商社の中核人材は「営業」ではなく **技術営業（セールスエンジニア）**。
図面が読め、加工の勘所が分かり、そのうえで値段と納期の交渉ができる人を指す。

| 求められること | 具体例 |
| --- | --- |
| 図面・公差が読める | 「この穴の公差0.01mmなら、旋盤では出ない。研削が要る」と即答できる |
| 加工の常識がある | 材質・工具・切削条件から、サイクルタイムと工具寿命をざっくり見積もれる |
| 複数メーカーを横に比べられる | メーカー営業は自社機しか勧められない。商社は「今回は御社の用途なら他社機」が言える |
| 投資対効果を語れる | 「人2人分の作業を置き換えて、償却は3.2年」と経営者の言葉に翻訳する |
| 周辺まで束ねられる | 機械＋治具＋工具＋ロボット＋計測を1社の責任でまとめる（**一括責任**が客の最大の安心） |

> ポイント：**メーカー営業には「他社製品を勧める自由」がない**。
> この一点が、メーカー直販が進んでも商社が消えない構造的な理由になっている。
> 客の工場には複数メーカーの機械が混在しており、それを横断して面倒を見られるのは商社だけ。

一方で、この人材は**育つのに時間がかかり、代替が利かない**。
業界全体の高齢化と採用難が、後述の再編（[②](02_プレイヤーと商売の型.md)の第9章）の直接の引き金になっている。

## 8. 部品供給と修理＝止まらない収益

機械は必ず壊れ、必ず消耗品を食う。ここが商社の**ストック収益**（継続的に入る収益）になる。

```
【1台の設備がもたらす収益の時間分布（イメージ）】

 金額
  ▲
  │ ███                                                    本体販売（一度きり・粗利薄）
  │ ███
  │ ███   ▓   ▓   ▓   ▓   ▓   ▓   ▓   ▓   ▓   ▓        消耗品・工具（毎月・粗利中）
  │ ███   ▓ ░ ▓   ▓ ░ ▓   ▓ ░ ▓   ▓ ░ ▓   ▓ ░ ▓        定期点検・修理（随時・粗利厚）
  │ ███   ▓ ░ ▓   ▓ ░ ▓ ▒ ▓ ░ ▓   ▓ ░ ▓ ▒ ▓ ░ ▓        改造・レトロフィット（数年に一度）
  └─┴───┴───┴───┴───┴───┴───┴───▶ 年
    0年   2   4   6   8  10  12  14  16

  ◆ 導入時の利益は小さい。10年で見ると累計はアフターの方が大きいことが珍しくない
  ◆ だから商社は「1台目を赤字覚悟で入れる」判断をする（据付台数＝将来の権利）
```

**消耗品（切削工具・砥石・オイル・フィルタ）と補修部品**は、単価が小さく点数が多いため、
在庫と物流を持つ商社でないと扱えない。ここが [② プレイヤーと商売の型](02_プレイヤーと商売の型.md) で扱う
**在庫・物流型商社**（トラスコ中山、MonotaRO など）の主戦場でもあり、装置商社とは別の競争が起きている。

## 9. 分野別に見る「付加価値の置き場所」

同じ機械商社でも、扱う機械によって稼ぎどころがまるで違う。

| 分野 | 商社が主に担うこと | 商流の特徴 | 参考ノート |
| --- | --- | --- | --- |
| **工作機械**（旋盤・マシニングセンタ） | 加工提案、デモ、据付、工具・治具の手配、下取り | 代理店制が強固。中小工場が客で件数が多い | [工作機械](../../02_自動車・機械/07_工作機械/README.md) |
| **半導体製造装置** | 装置の搬入据付・クリーン環境対応、部材・消耗部品供給、海外メーカー品の日本国内代理 | 客が大手数社に集中。1件が巨額。技術・秘密保持の要求が非常に高い | [半導体製造装置](../../03_電機・電子部品/03_半導体製造装置/README.md) |
| **産業機械・FA** | 生産ライン一式の設計・とりまとめ（**システムインテグレーション**）、ロボットのティーチング | 商社が元請けになり、複数メーカーの機器を束ねる。工事売上が立つ | [FA・制御機器](../../03_電機・電子部品/14_FA・制御機器/README.md)／[産業用ロボット](../../02_自動車・機械/09_産業用ロボット/README.md) |
| **建設機械** | 販売・レンタル・中古・整備の4点セット。稼働管理 | ディーラーがメーカー資本と結びつきやすい。レンタル比率が高い | [建設機械](../../02_自動車・機械/06_建設機械/README.md) |
| **ポンプ・バルブ・空圧機器など要素部品** | 選定（スペックイン）、常備在庫、短納期対応 | 型式が膨大で、選べること自体が価値。カタログ商社の領域 | [ポンプ・バルブ](../../02_自動車・機械/17_ポンプ・バルブ/README.md)／[油圧・空圧機器](../../02_自動車・機械/11_油圧・空圧機器/README.md) |

> ポイント：**客が集中している分野（半導体製造装置・建機）ほどメーカー直販が進みやすく、
> 客が散らばっている分野（工作機械・要素部品）ほど商社が残る**。
> 直販の圧力を測るときは、まず「その機械の客が何社いるか」を数えればよい。

## 10. 儲けの算術：口銭はいくらか

機械商社の粗利率（売上総利益率）は、商材と機能の深さで段階的に変わる。公表値を平均すると概ね次の姿になる。

| 商売の型 | 粗利率の目安 | なぜその水準か |
| --- | --- | --- |
| 単純な機械本体の転売 | **数%〜10%程度** | 型式が同じなら相見積もりで価格が丸見え。値引き競争になる |
| 工具・消耗品・MRO | **10〜20%台** | 点数が多く、在庫と即納で差がつく。1点あたりの比較がされにくい |
| エンジニアリング込みの設備一式 | **10〜20%台＋工事分** | 構成が各社バラバラで比較困難。責任範囲の対価が乗る |
| 保守・修理・部品 | **本体より高い** | 止められない状況で買うため価格弾力性が低い。代替供給先も少ない |

実際の上場機械商社の売上総利益率はおおむね**10〜20%台**に収まる（2026年3月期・各社決算、詳細は[②](02_プレイヤーと商売の型.md)）。
一方、在庫を大量に持つトラスコ中山型やネット通販型は、粗利率がこれより高い代わりに**物流固定費が重い**。
同じ「機械商社」でも損益計算書の形が違うことは、次のノートの主題である。

> まとめ：機械商社の付加価値は「情報の非対称性」ではなく、**手間と責任の引き受け**にある。
> 情報はネットで誰でも取れるようになったが、**据付・立上げ・修理を保証する人**はネットに置き換わっていない。

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **代理店（ディーラー）／特約店** | メーカーと契約し、指定地域・指定商材を販売する権利を持つ商社。一次（メーカー直取引）と二次（一次から仕入れる）がある |
| **仕切価格（しきりかかく）** | メーカーが代理店へ卸す価格。実績連動で変動する |
| **テリトリー制** | 代理店ごとに販売地域・客先を割り当てる仕組み。値崩れを防ぐのが目的 |
| **据付（すえつけ）** | 機械を設置し、水平出し・配線・配管まで行う作業 |
| **試運転／立会い** | 客のワーク（加工対象物）で実際に動かし、精度と速度を確認する工程 |
| **検収（けんしゅう）** | 客が「仕様どおり」と認める手続き。ここで売上計上と支払期日が確定する |
| **ティーチング** | ロボットに動作を覚えさせる作業。現場で人が動かして教える |
| **レトロフィット** | 既存設備の制御装置や一部機構を新しくして延命・高機能化すること |
| **オーバーホール** | 機械を分解し、摩耗部品を交換して再組立する大規模整備 |
| **スペックイン** | 客の仕様書（スペック）に自社扱いの型式を書き込ませること。実質的に受注が確定する |
| **システムインテグレーション（SI）** | 複数メーカーの機器を組み合わせて1つの生産ラインとして成立させる業務 |
| **MRO** | Maintenance, Repair, Operations の略。生産設備の維持・補修・運用に使う間接資材（工具、部品、作業用品など） |
| **口銭（こうせん）** | 商社が取る手数料・マージン。機械では粗利額を指すことが多い |
| **与信（よしん）** | 客に後払いを認めること。倒れた場合の損は商社が負う |
| **ストック収益** | 一度きりでなく継続的に入る収益。保守・部品がこれにあたる |
