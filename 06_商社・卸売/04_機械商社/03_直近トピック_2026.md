# 直近トピック（2026年9月時点）

報道・統計・各社IRをもとにした整理。数値には時点を添えている。
会社予想・調査会社推計・報道ベースのものはその旨を明記した（最新は各社IRと一次統計で確認のこと）。

## 1. 設備投資が明確な上昇局面に入った — 工作機械受注が暦年上期で初の1兆円超

機械商社の業績を先読みする最重要指標である工作機械受注が、2025年後半から連続で伸びている。

| 時点 | 受注総額 | 前年比 | 出典 |
| --- | --- | --- | --- |
| 2025年（暦年） | **1兆6,043億円** | +8% | 日工会集計（日刊工業新聞報道） |
| 2026年3月 | 1,934.7億円 | — | 日工会 速報 |
| 2026年6月 | **2,035.1億円** | +52.8% | 日工会 速報（月間2,000億円台に到達） |
| 2026年上期（1〜6月） | **1兆551.4億円** | +35.7% | 日工会（暦年上期として初の1兆円超） |
| 2026年7月 | 1,931.0億円 | +50.4% | 日工会（13か月連続増） |
| 2026年 通年見通し | **1兆7,000億円** | 前年超え | 日本経済新聞 2026年1月報道 |

**何が効いているか**

- AI・データセンター関連の投資が、半導体・電子部品の製造装置需要を押し上げている
- 国内の人手不足を背景にした**自動化・省人化投資**（ロボット、自動搬送、無人運転）
- 北米・台湾・中国・ASEANの外需が回復。山善は2026年3月期に海外各地域が通期で前年超えと説明

> 機械商社にとっての含意：受注→据付→検収のタイムラグがあるため、
> この受注の伸びは **2026年度後半から2027年度の売上**として現れる。
> 逆に言えば、いま好業績の商社は1年前の受注を食べている。

## 2. 半導体製造装置が牽引役 — 2026年の世界市場は前年比23%増の見通し

半導体製造装置の世界市場は2026年に**1,659億ドル（前年比+23.2%）**へ拡大する見通しと報じられている
（日本経済新聞 2026年7月報道、SEMI等の予測に基づく）。
日本半導体製造装置協会（SEAJ）も2026年1月に2025〜2027年度の需要予測を公表している。

機械商社への波及は次の3経路。

```
【AI投資 → 機械商社への波及経路】

  AI・データセンター投資
        │
        ├─▶ ①半導体メーカーの前工程投資 ──▶ 製造装置メーカーが増産
        │         │                              │
        │         │                              ├─▶ 装置の部品・ユニットを供給する商社
        │         │                              └─▶ 装置メーカー自身の工場設備（＝工作機械）
        │         └─▶ クリーンルーム・用力設備（ポンプ・配管・空調）
        │
        ├─▶ ②電子部品・基板の増産投資 ──▶ 実装装置・検査装置
        │
        └─▶ ③電力・変電・冷却設備の需要 ──▶ 産業機械・プラント系商社

  ◆ 機械商社は「AIそのもの」ではなく「AIを作る工場を作る設備」の側で受益する
  ◆ ただし客が大手に集中する分野なので、直販圧力も同時に強い
```

なお、装置市場には「スーパーサイクル（長期の上昇局面）」論と
「AI投資の過熱に対する警戒」の両論があると報じられており、ピークを2026年半ばとみる見方も紹介されている。
商社側は**受注残が積み上がる局面ほど、その後の反動に備える**のが定石である。

## 4. 再編：ジーネットとマルカが統合し「ユニソル」が発足（2026年1月）

機械工具商社の再編で最も目立つのが、ユニソルグループの動きである。

```
【ユニソルグループの成り立ち】

  2021年10月  扶桑産業 ＋ 旧マルカ が共同持株会社を設立
              （フソー・マルカホールディングス）
                    │
                    ▼
  2026年 1月  ジーネット ＋ マルカ が経営統合 →「ユニソル株式会社」
              同時に持株会社が「ユニソルホールディングス株式会社」へ商号変更
                    │
                    ▼
  新体制の事業部構成（会社公表）
   ・機械工具事業／産業機械事業／グローバル事業／食品機械事業
   ・横断の営業戦略事業（事業部をまたぐ提案機能）
```

会社は統合の狙いを「事業責任の明確化」と「オーナーシップ」による再編シナジーと説明している（社長メッセージ）。

**なぜ機械商社の統合が起きるのか**（[②](02_プレイヤーと商売の型.md) 第8章の再掲）

- 技術営業・サービス員が採用難で、単独では機能を維持できない
- メーカーが代理店数を絞る方向にあり、規模のない商社は代理店権を失いやすい
- EC・電子受発注への投資が単独では償却できない

異業種からの参入も見られ、鉄鋼商社の阪和興業が工作機械・金属加工機械を扱うシンクスを買収して
産業機械部門を強化したと報じられるなど、**機械商社領域は買い手が多いセクター**になっている（報道ベース）。

## 5. MRO市場のネット化は道半ば — 大半はまだ対面流通

**MRO（Maintenance, Repair, Operations ＝ 生産設備の維持・補修・運用に使う間接資材）** 市場は
国内**5兆〜10兆円規模**とされ、2015年時点の推計で約8兆円という数字がよく引かれる（事業者・調査会社の推計。年次が古い点に注意）。

これに対し、MonotaRO の売上は2026年12月期予想で3,813億円。**シェアは数%台**にとどまる。

```
【国内MRO市場のイメージ（規模感。推計ベース）】

  国内MRO市場  5兆〜10兆円規模（推計、2015年ごろの約8兆円という数字が広く引用される）
  ┌────────────────────────────────────────┐
  │                                                                  │
  │  対面流通（地場の機械工具商社・二次卸経由）                      │
  │  ████████████████████████████████████████████████████  大半      │
  │                                                                  │
  │  ネット通販（MonotaRO ほか）                                     │
  │  ███  数%台                                                      │
  └────────────────────────────────────────┘
        ▲                                          ▲
   縮小しているわけではないが                 市場全体より速く伸びている
   成長分をほぼ取れていない                   （2026年1〜3月期 +20.8%）
```

一方、経済産業省の商業動態統計では、**産業機械器具卸売業の販売額は2026年2月に1兆9,150億円（前年同月比+4.9%）**
と公表されており、卸売の現物流通自体は堅調に伸びている。
**「ネット化が進む」と「既存流通が縮む」は同義ではない**点に注意が要る。
起きているのは、既存流通の中で **消耗品のリピート注文がネットに移り、対面の役割が機械・エンジニアリングに寄る**という再配置である。

## 6. 全体の構図（まとめ）

- **2026年の機械商社は、順風のただ中にいる**。工作機械受注は2026年上期に暦年上期で初の1兆円超（+35.7%）、
  7月も13か月連続増。半導体製造装置の世界市場も2026年に+23%と見込まれ、受注残は厚い
- ただし受注は自社の実力ではなく**客の設備投資サイクル**の産物であり、商社の売上は検収ベースでさらに遅れる。
  好調の局面こそ、**保守・部品・MROというストック収益の比率**が下り坂への備えになる
- **伸び率で見ると、在庫・物流／カタログ型（ミスミFA +18.2%、MonotaRO +20.8%）が装置商社（+3〜5%）を上回る**。
  ネット通販が奪っているのは「探す・比べる・運ぶ」機能であり、「選ぶ・据え付ける・直す」機能はまだ奪えていない
- **供給側は統合が進む**。ジーネット＋マルカのユニソル発足（2026年1月）が象徴で、
  動機は規模よりも**技術者と代理店権の確保**。後継者難を背景にM&Aの売り手は構造的に多い
- 結論として、機械商社の勝敗は **「粗利がどこから来ているか」** に収束する。
  本体転売の粗利はネットと直販に削られ続け、エンジニアリングと保守の粗利は当面残る

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **日工会（日本工作機械工業会）** | 工作機械メーカーの業界団体。月次の受注統計が設備投資の先行指標として使われる |
| **SEAJ** | 日本半導体製造装置協会。半導体・FPD製造装置の需要予測を公表する |
| **商業動態統計** | 経済産業省が毎月公表する卸売・小売の販売額統計。機械器具卸売業の動向はここで追える |
| **受注総額／内需／外需** | 工作機械統計の基本区分。外需の増減は世界の製造業景気を映す |
| **検収ベース** | 客が設備を検査・合格させた時点で売上を計上する方法。受注から数か月遅れる |
| **スーパーサイクル** | 通常の景気循環を超えて長期間続く需要拡大局面を指す言い方。半導体装置でよく使われる |
| **MRO** | 生産設備の維持・補修・運用に使う間接資材。工具・部品・作業用品など |
| **在庫評価益** | 仕入価格の上昇により、保有在庫の評価額が上がって生じる利益。実力値とは区別して見る |
| **レトロフィット** | 既存設備の制御装置などを更新して延命・高機能化すること。投資抑制局面で伸びやすい |
