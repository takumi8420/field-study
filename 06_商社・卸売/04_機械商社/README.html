このフォルダの読み方

機械商社は 「機械を右から左に流す会社」ではない。
機械は届いただけでは1円も生まない。据え付け、試運転し、精度を出し、10〜20年間直し続けて初めて価値が出る。
その手間と責任を引き受けているのが機械商社であり、引き受けない商社（＝単なる横流し）は
ネット通販とメーカー直販に削られて消えていく。この一点を軸に2本＋直近トピックに分けた。

ノート 内容
① 機械を売る商社の付加価値横流しでは生き残れない理由、据付・試運転・保守・改造というエンジニアリング機能、代理店（一次／二次）の契約構造、メーカーの海外販売網を代替する役割、技術営業という職種、部品供給と修理という継続収益、分野別（工作機械／半導体製造装置／産業機械／建機）の稼ぎどころ
② プレイヤーと商売の型在庫・物流型（トラスコ中山／MonotaRO／ミスミ）と技術提案型（山善／YUASA／第一実業／ユニソル）の損益構造の違い、MRO＝間接資材のネット通販が流通に与えた影響、メーカー直販化の圧力、中国・アジアでの現地販売、設備投資サイクルとの連動、再編と事業承継、見るべき指標
③ 直近トピック（2026年9月時点）工作機械受注が2026年上期に暦年上期初の1兆円超、半導体製造装置市場+23%見通し、上場機械商社の2026年3月期決算、ジーネット＋マルカの「ユニソル」発足、MRO市場のネット化の実情

1. 業界の定義・範囲

機械商社 ＝ 工作機械、産業機械、半導体製造装置、建設機械、FA機器、工具・部品などを
メーカーから仕入れ、工場や建設現場などの使い手に供給する専門商社。
実務では 「機械工具商社」「産機（さんき）商社」「装置商社」 とも呼ばれる。

境界の引き方は2軸で整理できる。

【「機械商社」と呼ばれるものの広がり】

           扱う商材 →  工具・部品（点数多・単価小）    機械・設備（点数少・単価大）
          ┌───────────────────┬───────────────────┐
 投資では │ 在庫・物流型／カタログ型          │ 技術提案型（装置商社）          │
 稼がない │ トラスコ中山／MonotaRO／ミスミ    │ 山善／YUASA／第一実業／         │
 （商流）  │ ＝MRO・間接資材の世界             │ ユニソル／岡谷鋼機              │
          │                                   │ ＝エンジニアリングの世界        │
          ├───────────────────┴───────────────────┤
 投資でも │ 総合商社の機械部門                                                  │
 稼ぐ     │ （プラント・船舶・航空機・発電。事業投資とセット）→ ../01_総合商社   │
          └───────────────────────────────────────┘
  • 総合商社との違い ＝ 分野の広さではなく 「投資で稼ぐ層を持つか」。
    機械商社は商流の粗利とエンジニアリングの対価で食べる（総合商社 の定義と対）
  • メーカーとの違い ＝ 作らない。ただし複数メーカーを横断して選べる点が単一メーカーにない機能
  • ホームセンター・工具小売との違い ＝ 客が法人（工場・現場）で、掛け売り・与信・据付・保守がセットになる
  • 日本標準産業分類では 「機械器具卸売業」（産業分類コード54） に属する

5. 収益モデル・コスト構造

営業利益 ＝ ① 機械本体の粗利（薄い：数%〜10%台）
          ＋ ② 工具・消耗品・MROの粗利（10〜20%台）
          ＋ ③ 据付・工事・エンジニアリングの対価
          ＋ ④ 保守・修理・補修部品の粗利（本体より厚い・景気耐性あり）
          －   販管費（**人件費が最大**。技術営業とサービス員）
          －   物流費（在庫・物流型では最大の固定費）
          －   貸倒れ（与信を取るのは商社）
論点 中身
粗利率の水準上場機械商社でおおむね 10〜20%台（2026年3月期・各社決算）。単純転売中心だと10%を切る
在庫・物流型の形粗利率は高いが、物流センターと在庫という重い固定費を背負う。出荷点数が増えるほど有利
技術提案型の形粗利率は薄いが固定費は人件費中心。ただし技術者は増減させにくく、不況期に人件費が残る
運転資金受注から検収（客が仕様どおりと認める手続き）まで数か月。その間の立替が資金を食う
ストック収益1台納めると10〜20年の部品・修理がついてくる。景気に左右されにくい利益の源
在庫評価仕入価格上昇時には在庫評価益が出る（例：トラスコ中山 2025年12月期に約14億円）。実力値とは区別して見る

6. 競争要因（KSF）と参入障壁

KSF（成功の鍵）

  1. 代理店権（メーカーの一次代理店の座）。決算書には出ないが、将来の商権そのもの
  2. 技術営業とサービス員の層の厚さ。図面が読め、加工が分かり、値段が詰められる人の数
  3. 保守・部品の比率。ここが厚い会社ほど設備投資の谷を越えられる
  4. 在庫と物流（在庫・物流型の場合）。品揃えと即納は資金力がないと作れない
  5. 海外拠点と現地回収力。国内の谷を埋める手段であり、メーカーが最も欲しがる機能
  6. 一括責任で受けられる範囲。機械単体でなくライン一式を1社で保証できるか

参入障壁

障壁 強さ 理由
商材の仕入れ弱二次代理店としてなら小資本でも始められる。だから中小が数千社ある
一次代理店の座強既存代理店との数十年の関係。空き枠がほとんどない
技術者の育成強技術営業・サービス員は年単位で育つ。採用難で中小ほど維持が難しい
在庫と物流網強数百万点の在庫と自動倉庫は数百億円規模の投資
与信を取れる資本中〜強1件数千万〜数億円の掛け売りに耐える自己資本が要る
ブランド・信用中「止まったとき来てくれる」実績の蓄積。新規参入では作れない

7. 規制・法制度

機械商社を直接縛る業法はない。扱う商材と取引形態ごとの規制を受ける。

分野 主な制度
安全保障貿易管理外国為替及び外国貿易法（外為法）。工作機械・半導体製造装置は軍事転用可能な貨物としてリスト規制の対象。無許可輸出は刑事罰。機械商社にとって最も重い実務規制
経済安全保障経済安全保障推進法（2022年）。重要物資のサプライチェーン把握。半導体製造装置の輸出管理は各国の措置と連動する
労働安全衛生法機械の安全（はさまれ・巻き込まれ防止）、特定機械の検査、クレーン等の資格。据付作業そのものが規制対象
建設業法据付工事が「機械器具設置工事業」等にあたる場合、建設業許可が必要になる
電気事業法・高圧ガス保安法ほか受電設備や圧縮機など、設備の種類に応じた届出・資格
下請法・独占禁止法商社は「買う側」としても規制対象。価格転嫁、支払サイト短縮の要請
PL法（製造物責任法）輸入機械では輸入者が製造業者とみなされる。海外メーカー品を入れる商社の実質的なリスク
補助金ものづくり補助金、事業再構築補助金、省力化投資補助金など。申請支援が商社の営業ツールになっている
インボイス制度・電子帳簿保存法少額多品種の取引を扱う商社ほど事務負担が大きく、EC・電子受発注移行の後押しになった
