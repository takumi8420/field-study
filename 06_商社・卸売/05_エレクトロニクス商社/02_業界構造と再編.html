業界構造と再編

商社・卸売エレクトロニクス商社
あこのページの単語集用語に触れると意味を確認できます9語
代理店集約直販（ダイレクト）特約店ソリューション型EMS棚卸資産回転日数低価法（評価損）持株会社統合系列商社

このノートで分かること：日本のエレクトロニクス商社がなぜ数を減らし続けているのか、
世界大手との規模差がどれほどあるのか、そして生き残り策として掲げられる「ソリューション型」とは実際に何をすることなのか。

結論を先に：この業界の縮小は景気の話ではなく、構造の話である。
①半導体メーカーが代理店を減らし、②大口顧客には直販に切り替え、③顧客側も購買を集約した。
商社の数だけが減らずに残っていたので、合併して商権を束ねる以外に道がない。
「最低でも売上5,000億円規模がないと単独での生き残りは厳しい」というのが業界内の共通認識として語られている（日刊工業新聞の報道ベース）。

売上ランキングは強さのランキングではない。

3. なぜ数が減り続けるのか：3つの圧力

【エレクトロニクス商社を挟み撃ちにする力】

        ┌─────────── 川上（半導体メーカー）────────────┐
        │  ① 代理店集約     … 管理コスト削減・在庫可視化のため      │
        │     ルネサスは2019年に国内代理店を 16社 → 6社 へ絞る方針   │
        │     （日本経済新聞、日経クロステック報道）                  │
        │  ② 直販シフト     … 大口顧客は自社で直接取引した方が安い    │
        └────────────────┬───────────────────┘
                                 ▼   商社の取り分が削られる
        ┌──────── エレクトロニクス商社（数十社が並存）─────────┐
        │  粗利率は低下、在庫リスクは残る、FAEの人件費は固定         │
        └────────────────┬───────────────────┘
                                 ▲   単価引下げ圧力
        ┌─────────── 川下（セットメーカー）────────────┐
        │  ③ 購買の集約     … 取引商社数を絞りコストダウン           │
        │     ＋ 海外生産移管で、国内商社の出番が減る                │
        │     ＋ カタログ通販（Digi-Key/Mouser/RS）が試作需要を吸う   │
        └────────────────────────────────────┘
圧力 具体的に起きたこと
メーカーの代理店集約ルネサスエレクトロニクスが2019年に国内特約店を16社から6社へ絞る検討を開始したと報じられた。日立・三菱電機・NECの半導体部門が合流した経緯で代理店が重複していたことが背景
直販化大口顧客・EMS・データセンター事業者には、メーカーが直接売る方が中間コストが消える。商社に残るのは中小顧客
顧客側の購買集約セットメーカーが調達先商社を絞る。残れなかった商社は一気に売上を失う
カタログ通販試作・少量の需要をDigi-Key、Mouser、RSコンポーネンツが吸収。FAEが手間をかけていた「小さな種まき」の場が減った
国内生産の海外移管顧客の工場が海外へ出ると、国内商社は現地法人を作るかグローバル商社に譲るかの二択になる

要点：商社の数が多すぎること自体が問題だった。
日本の半導体産業が複数の総合電機の内部部門として育ったため、各社に系列代理店がぶら下がった。
半導体メーカーが統合（ルネサス＝日立＋三菱＋NEC）しても、代理店だけが残った。
その整理が2010年代後半から一気に進んでいる。

4. 再編の年表（主なもの）

時期 出来事 意味
2019年4月ルネサスが国内代理店を16社→6社へ集約する方針と報じられる再編の号砲。切られる側にならないための統合が始まる
2019年バイテックホールディングス＋UKCホールディングス → レスターホールディングス売上規模での生き残り。EMS・環境事業も抱える複合型へ
2019年加賀電子が富士通エレクトロニクスを取得富士通の半導体商権を丸ごと取り込んだ典型例
2023年11月マクニカがグローセルへのTOBを発表（最大約190億円、1株645円）中堅の取り込み
2024年4月リョーサン＋菱洋エレクトロが経営統合（リョーサン菱洋ホールディングス発足）両社ともルネサス代理店。重複商権を束ねる統合
2025年1月マクニカによるグローセルTOBが成立、完全子会社化—
2025年10月マクニカがグローセルを吸収合併商権を1つの法人に集約
2026年4月リョーサンと菱洋エレクトロの事業会社が合併し「リョーサン菱洋」に持株会社統合から2年かけて中身を一本化
2026年3月オムロンが電子部品事業（DMB）を米カーライルへ譲渡すると発表（事業価値810億円）メーカー側でも再編。商社にとっては仕入先の顔ぶれが変わる話

統合の順番には型がある：①持株会社を作って並存 → ②システム・物流を統合 → ③事業会社を合併 → ④重複商権の整理。
②〜④に2〜3年かかるため、統合直後は費用先行で利益が出にくい。
リョーサン菱洋HDの2026年3月期が「売上は横ばい（3,599億円）、経常利益は+25.2%」となったのは、
売上を増やす統合ではなく、重複コストを削る統合だったことの数字上の現れといえる。

5. 生き残り策としての「ソリューション型」

単なる仕入れ販売（buy-sell）だけでは粗利が守れないため、各社が掲げるのがソリューション型への転換である。
中身を分解すると、実は4つの別々の話が混ざっている。

類型 具体的にやること 儲け方 代表例
① モジュール開発複数部品を載せた基板・ユニットを自社設計し、型番を付けて売る部品の集合体に設計料を上乗せできる。価格比較されにくい東京エレクトロンデバイス、菱洋系の自社ブランド品
② 受託設計・EMS顧客の代わりに回路設計・基板実装・組立まで請ける製造の付加価値を取り込む。ただし設備と工場のリスクを負う加賀電子、レスター
③ ソフト／サービスセキュリティ、AI、クラウド、評価ツールなど非ハード商材ストック収益。在庫リスクがないマクニカ（サイバーセキュリティ 2026年3月期 1,739億円、+13.0%）→ 情報セキュリティ
④ 独自商材の発掘無名の海外スタートアップ製半導体を早期に見つけ、日本市場で立ち上げる競合がいないので粗利が厚い。当たれば数年の独占マクニカのFPGA・AI半導体など

6. 為替と在庫評価：数字の振れ方を読む

エレクトロニクス商社の決算は「本業の良し悪し」と「相場の追い風・向かい風」が混ざる。分けて読む必要がある。

要因 効き方 見るべき数字
円安外貨建て仕入の在庫評価が上がり、円建て売価も上げやすい。売上と粗利の両方を押し上げる為替前提レート、在庫残高の通貨別内訳
円高逆。在庫評価損と粗利縮小が同時に来る。レスターの2026年3月期デバイス事業は、円高と産機回復の遅れでセグメント利益が▲10.2%と報じられる同上
商品市況（特にメモリ）仕入れてから売るまでに相場が上がれば、その分がそのまま利益になる（逆も同じ）棚卸資産の増減、粗利率の急変
半導体サイクル好況は数量と価格が同時に伸び、不況は在庫調整で数量・価格・評価が同時に痛む棚卸資産回転日数、受注残

7. これからの論点

  1. さらなる統合は起きるか。売上5,000億円が単独生存の下限とされるなら、
    2,000億円前後の会社（立花エレテック、丸文、RYODEN、伯東など）が次の再編候補として語られやすい。
    ただし各社とも系列・独自商権があり、単純な規模論では動かない
  2. 中華系・台湾系の日本進出。WT×日電貿のような資本提携は、日本の受動部品商権が外資に移る入口になり得る
  3. AI・データセンター特需の後始末。2025〜2026年のメモリ・GPU高騰は商社に大きな利益をもたらしたが、
    相場が反転したときの在庫評価損が次の試練になる → ③ 直近トピック
  4. 経済安全保障と輸出管理。米中間の輸出規制で、商社は「誰に何を売ったか」の管理責任を負う。
    違反は外為法の刑事罰対象で、商社の実務負担が年々重くなっている
  5. 半導体の国内回帰。TSMC熊本、ラピダスなどの国内新工場は、材料・装置・部品の新しい商流を生む
    → 半導体・先端半導体、半導体製造装置
