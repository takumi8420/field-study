# 半導体・電子部品流通の仕組み

このノートで分かること：エレクトロニクス商社が**どの瞬間に商売を決めているのか**（答え：モノを売るときではなく、客が回路を設計しているとき）と、
そこから生まれる「商権」「在庫リスク」「FAE」という、この業界だけの独特な言葉の中身。

> 結論を先に：**エレクトロニクス商社は「注文を取る仕事」ではなく「注文が発生する前に、設計図に自社の型番を書き込ませる仕事」**である。
> 設計図に載った瞬間に、その機種が生産される数年間の売上が自動的に流れてくる。これを **デザインイン**、
> そこで得た「この客のこの機種は自分が供給する」という既得権を **商権（しょうけん）** と呼ぶ。

## 1. まず全体像：誰から買って誰に売るか

```
【川上】半導体・電子部品メーカー        【中間】エレクトロニクス商社      【川下】セットメーカー

 NVIDIA / Intel / TI / ADI          ┌──────────────────┐    ┌─ 国内セットメーカー
 ルネサス / 東芝デバイス            │  ① 代理店契約を結ぶ  │    │  （自動車・FA・計測・白物）
 ロームなど半導体メーカー   ──────▶│  ② デザインインする  │───▶│
                                     │  ③ 在庫を持つ        │    ├─ EMS / ODM
 村田 / TDK / 太陽誘電など           │  ④ 納期を捌く        │    │  （鴻海・Flex・国内EMS）
 電子部品メーカー           ──────▶│  ⑤ 技術支援する(FAE) │───▶│
                                     │  ⑥ 与信・為替を負う  │    └─ データセンター事業者
 メモリメーカー（Samsung/SK/Micron） │                      │       （AIサーバー向け）
                             ──────▶└──────────────────┘
                                              │
                                              ├─ 独立系ディストリビュータ（非正規）
                                              └─ ブローカー / オープンマーケット
                                                  ※逼迫時だけ値段が跳ねる現物市場
```

- 川上（部品そのものの話）は [電子部品](../../03_電機・電子部品/05_電子部品/README.md) と
  [半導体（ロジック・メモリ）](../../03_電機・電子部品/02_半導体（ロジック・メモリ）/README.md) に譲る。
  ここでは **「間に立つ会社が何をして食べているか」** だけを扱う
- 半導体メーカーが自前で全顧客を回らないのは単純な算数。
  **1社あたり年間数百万円しか買わない客が数千社ある**ので、直接営業すると赤字になる。その部分を商社が引き受けている

## 2. デザインイン：商売が決まる瞬間

**デザインイン**＝顧客の設計者が回路図・部品表（BOM＝Bill of Materials、使う部品の一覧表）を作っている段階で、
自社が扱う型番をそこに書き込ませること。

なぜこれが決定的かというと、**電子機器は部品を後から差し替えられないから**である。

```
【製品開発のタイムライン と 商社の関与】

 企画   →  回路設計   →  試作・評価  →  認証・量産準備 →  量産（3〜10年）
  |         ◀━━━━━━━━━━━━▶                              ━━━━━━━━━━━━
  |         ここが勝負。商社のFAEが          ここで決まった型番は、     ここは
  |         評価ボード・リファレンス回路・    基本もう動かない          ただの
  |         サンプル・技術資料を持ち込む      （再評価・再認証コストが  納品作業
  |                                          新規採用の利益を超える）   （価格交渉は毎年ある）
  |
  └─ 商社の営業活動費と人件費は「左側」で発生し、
     売上と利益は「右側」で数年かけて回収される ＝ 先行投資型のビジネス
```

| 段階 | 商社がやること | 失敗するとどうなるか |
| --- | --- | --- |
| 設計初期 | FAEが技術提案。評価ボード貸出、リファレンス回路提供 | 競合の型番が入り、以後数年入り込めない |
| 試作 | サンプル手配、不具合解析の同席 | 「あの商社は動かない」と設計者に記憶される |
| **デザインレジストレーション** | メーカーに「この客のこの案件は当社が開拓した」と登録し、**特価**をもらう | 登録が通らないと、他商社と同じ仕入値で値引き合戦になる |
| 量産 | 納期調整・在庫積み・価格改定交渉 | 欠品させると商権ごと外される |
| 世代交代 | 後継機種でも再びデザインイン | ここを外すと商権が一気に消える |

> ポイント：**この業界の営業は「買ってください」ではなく「この回路ならこの石（IC）が最適です」と言う仕事**。
> だから営業職より技術職（FAE）の質が競争力になる。

### デザインレジストレーションと「特価」

- メーカー各社は「この商社がこの顧客を開拓した」という登録制度を持っている（呼称は各社で違う）
- 登録が認められると、その案件限定で **標準仕入値より安い仕入値（特価）** が与えられる
- 実務上は **ship & debit（シップ・アンド・デビット）** という仕組みが多い。
  商社は標準価格で仕入れておき、特価で出荷した後にメーカーへ差額を請求して戻してもらう。
  つまり **在庫の仕入値と、実際の売値が後から帳尻を合わせる** 構造になっている
- 登録が「誰のものか」を巡る争いが、商社同士の最大の揉め事になる

## 3. 商権：既得権としての顧客×型番

**商権**＝「A社のB機種に使うC型番は、当社を通して流す」という、契約書に必ずしも書かれていない既得権のこと。

| 商権の性質 | 中身 |
| --- | --- |
| 単位 | **顧客 × 機種 × 型番** の組み合わせ。「ルネサスの商権を持つ」という言い方もするが、実態は案件の束 |
| 発生 | デザインインとレジストレーション |
| 強さ | 量産中はきわめて強い（変えると再評価・再認証コストが発生する） |
| 失い方 | ①機種の世代交代で外される ②メーカーが代理店契約を切る ③顧客が直接取引に切り替える ④商社が欠品・品質事故を起こす |
| M&Aとの関係 | **会社を買う最大の動機が「商権を買うこと」**。顧客リストと代理店契約を丸ごと手に入れる |

この「商権」という言葉があるせいで、エレクトロニクス商社の再編は
**「規模の拡大」というより「陣地の交換」** に近い動きになる。
→ 詳しくは [② 業界構造と再編](02_業界構造と再編.md)

## 4. 代理店契約（フランチャイズ）と独立系

英語では正規代理店を **franchised distributor / authorized distributor** と呼ぶ。
飲食のフランチャイズとは意味が違い、**「このメーカーの製品を正規に販売してよい」という指名**のこと。

| 類型 | 仕入元 | 強み | 弱み |
| --- | --- | --- | --- |
| **正規代理店（フランチャイズ）** | メーカーと直接契約 | 特価・技術資料・ロードマップにアクセスできる。偽造品リスクが原則ない | メーカーの方針変更（直販化・代理店集約）で一夜にして商権を失う |
| **二次店（サブディストリビュータ）** | 正規代理店から仕入れる | 小口顧客への細かな対応。地場密着 | 利幅が薄い。一次店の都合に左右される |
| **独立系ディストリビュータ／ブローカー** | 市中在庫・余剰在庫を買い集める | 欠品時に「あるだけで勝ち」。値決めが自由 | 真贋リスク。市況が緩むと在庫が死ぬ |
| **メーカー直販** | — | 大口顧客（EMS・データセンター）には最も効率的 | 中小顧客のサポートが回らない |

- 正規代理店契約には **年間の販売目標、担当地域、在庫返品条件、価格保護条項** が書かれるのが普通
- **価格保護（price protection）** ＝ 在庫を持っている間にメーカーが値下げしたら、差額をメーカーが補填する取り決め
- **ストックローテーション（stock rotation）** ＝ 期ごとに一定比率まで在庫をメーカーへ返品・交換できる権利
- この2つがあるかないかで、**商社が負う在庫リスクの重さがまったく違う**

## 5. 在庫リスクと価格変動：商社の損益はここで決まる

エレクトロニクス商社は **自分で買い取って、自分の倉庫に置いて、自分の名前で売る**（買取仕入）。
総合商社型の「口銭（手数料）だけ取る仲介」とは、負っているリスクの種類が違う。
→ [総合商社](../01_総合商社/README.md) の二層構造と比べると分かりやすい。

```
【商社のP/Lの骨格】

  売上高  100
  － 仕入   90         ← 粗利率は 8〜15% 程度が多い（品目と機能でかなり違う）
  ＝ 粗利   10
  － 販管費  7         ← 人件費（営業＋FAE）、物流費、システム費
  ＝ 営業利益 3        ← 売上高営業利益率は 2〜5% が相場
                          ※マクニカHD 2026年3月期は 3.5%（419億円 ÷ 1兆2,142億円）

【儲けの正体（3つ）】
  ① 価格差（buy-sell）… 特価で仕入れて顧客に売る差
  ② 機能対価          … 在庫・与信・物流・為替・技術支援の引受料
  ③ 相場益／相場損    … 仕入れてから売るまでの間の値動き（メモリで特に大きい）
```

| リスク | 中身 | どう効くか |
| --- | --- | --- |
| **在庫評価損** | 相場が下がると、倉庫の在庫の簿価を切り下げる（低価法） | 半導体サイクルの下り局面で一気に利益が飛ぶ |
| **デッドストック** | 顧客の機種が打ち切られ、専用品が残る | 返品条項がない品目は全損に近い |
| **為替** | 外貨建てで仕入れて円建てで売る取引が多い | 円安は在庫の評価と粗利に追い風、円高は逆風 |
| **与信** | 顧客が倒れると売掛金が飛ぶ | 実質的に **商社が顧客へ短期の金貸しをしている** |
| **NCNR** | Non-Cancellable / Non-Returnable。キャンセル・返品不可の発注条件 | 逼迫期にメーカーが要求する。**読み違えると数十億円の在庫が残る** |

> なぜ在庫を持つのか：**顧客は「明日欲しい」、メーカーは「20週後に出す」**。
> この20週のギャップを誰かが資金で埋めないと産業が回らない。そこを埋めるのが商社の存在理由。

## 6. 納期管理：フォーキャストという名の予言

半導体のリードタイム（発注から納入までの期間）は平常時で8〜20週、逼迫期は52週を超えることもある。
顧客は半年先の生産計画など持っていないので、**商社が代わりに予測（フォーキャスト）を出してメーカーへ発注する**。

| 用語 | 意味 |
| --- | --- |
| **フォーキャスト** | 顧客の将来の所要見込み。商社がメーカーへ提出する「買うつもりの数」 |
| **リードタイム** | 発注から納入までの期間。8〜20週が平常。逼迫期は1年超 |
| **アロケーション** | 供給不足時にメーカーが顧客ごとに配分を割り当てること。**ここで商社の交渉力が丸裸になる** |
| **ダブルブッキング** | 不安になった顧客が複数商社へ同じ数量を発注すること。需要が実態より膨らむ |
| **ブルウィップ効果** | 末端の小さな需要変動が川上ほど増幅される現象。商社の在庫が振れる元凶 → [電子部品の市場の波](../../03_電機・電子部品/05_電子部品/03_市場の波と儲け方.md) |
| **カンバン／VMI** | Vendor Managed Inventory。商社が顧客工場の近くに在庫を置き、使った分だけ売上計上する方式 |

**逼迫期の商社は「モノを取ってこられるか」だけで評価される。**
2021〜2022年の半導体不足では、正規ルートで入らない部品をブローカー経由で10倍以上の価格で調達する例も報じられた。
逆に緩和局面では、抱えた在庫が一斉に評価損に変わる。

## 7. FAE：技術者が売る

**FAE（Field Application Engineer／フィールド・アプリケーション・エンジニア）**
＝ 顧客の設計現場に出向いて、回路設計・部品選定・不具合解析を手伝う技術者。商社の社員である。

| FAEがやること | なぜ商社がやるのか |
| --- | --- |
| リファレンス回路の提案、評価ボードの貸出 | メーカーの本国エンジニアは日本の中小顧客まで回れない |
| データシート・アプリケーションノートの読み解き、日本語での説明 | 海外メーカー品は資料が英語で、規格解釈に慣れが要る |
| 電源設計・基板レイアウト・ノイズ対策の助言 | 「部品は正しいのに動かない」の大半は周辺設計の問題 |
| 不具合解析（故障品を預かり、メーカーへ橋渡し） | 顧客とメーカーの間の責任論を技術的に整理できるのは中間者だけ |
| ソフト・ファームウェア、AIモデルの実装支援 | 近年は「石を売る」から「動くシステムを渡す」へ比重が移った |

> **FAEの人数と質が、そのまま扱える商材の難易度を決める**。
> だから汎用品しか扱えない商社は価格競争に落ち、難しい石を扱える商社は粗利を守れる。
> マクニカが「技術商社」と自称し、サイバーセキュリティ（2026年3月期 売上1,739億円）まで手を広げられたのは
> この人材層があったからだと説明されることが多い。

## 8. 顧客タイプ別：EMS/ODM向けと国内メーカー向けの違い

同じ「エレクトロニクス商社」でも、誰に売っているかで商売の形がまったく違う。

```
【2つの世界】

 ◆ 国内セットメーカー向け（自動車・FA・計測・医療・白物）
   数量：小〜中   単価：中〜高   粗利：厚い（10〜20%）
   求められるもの：技術提案、長期供給、品質保証、少量多品種の在庫
   時間軸：デザインインから量産まで2〜3年、量産は5〜10年
   → 商権が長生きする。FAEの人件費を回収できる

 ◆ EMS / ODM 向け（鴻海・Flex・Jabil・国内EMS）
   数量：極大     単価：低      粗利：薄い（数%）
   求められるもの：価格、納期、物流（ハブ倉庫）、与信枠の大きさ
   時間軸：設計は「ブランド主（Apple等）」が決め、EMSは買うだけ
   → 技術提案の余地が小さい。規模と資金力の勝負

 ◆ データセンター／AIサーバー向け（2024年以降に急拡大）
   数量：大       単価：極大    粗利：品目次第
   GPU・HBM・電源・ネットワーク部品。商材1点が数十万円〜。
   → 売上が一気に膨らむが、与信と在庫の絶対額も膨らむ
```

| 論点 | 国内メーカー向け | EMS/ODM向け |
| --- | --- | --- |
| 誰が部品を決めるか | 顧客の設計者（＝デザインインが効く） | **ブランド主（OEM）が決め、EMSは指示通り買う** |
| 商社の価値 | 技術支援・少量在庫・長期供給 | 資金・物流・グローバル一括対応 |
| 粗利率 | 厚い | 薄い |
| 競合 | 国内商社同士 | Arrow・Avnet・WPG・WTなど世界大手 |
| リスク | 機種打ち切りによるデッドストック | 与信集中（1社で数百億円の売掛） |

**日本のエレクトロニクス商社が世界大手に規模で勝てない構造的な理由**がここにある。
日本の顧客は「少量・多品種・高信頼」が中心で、1社あたりの取引額が小さい。
一方で世界の大量取引はEMS経由に集約され、そこは規模と資金で決まる世界になっている。
→ [② 業界構造と再編](02_業界構造と再編.md)

## 9. 商社がいなくなると何が困るのか（存在理由の確認）

「ネットで買えるのに中間業者は要るのか」という問いには、次の4点で答えるのが実務的。

1. **在庫と資金**：20週のリードタイムを誰かが資金で埋める必要がある。メーカーはやりたがらない
2. **与信**：無数の中小顧客の与信審査と回収をメーカーが自前でやるのは非効率
3. **技術支援**：海外メーカーは日本語のFAEを日本の中小顧客向けに置けない
4. **組み合わせ**：1つの基板には複数メーカーの部品が載る。**まとめて手配できるのは中間者だけ**

逆に言えば、この4つが不要になる領域（大口・標準品・EMS経由）から順に
**メーカー直販とカタログ通販（Digi-Key、Mouser、RSなど）に侵食されている**。
これが業界が縮み続けている理由の半分である。

## 10. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **デザインイン** | 顧客の設計段階で自社扱い品を回路図・BOMに採用させること。**この業界の商売の起点** |
| **BOM** | Bill of Materials。製品に使う部品の一覧表。ここに載るかどうかがすべて |
| **商権（しょうけん）** | 「この顧客のこの機種は当社が供給する」という既得権。契約書にない場合も多い |
| **デザインレジストレーション** | 案件をメーカーに登録して特価を得る制度。登録が通れば値引き合戦を避けられる |
| **ship & debit** | 標準価格で仕入れ、特価で出荷した後に差額をメーカーへ請求する仕組み |
| **フランチャイズ（正規代理店）** | メーカーから正式に販売を任された商社。飲食のFCとは意味が違う |
| **FAE** | Field Application Engineer。顧客の設計現場を技術支援する商社の技術者 |
| **価格保護／ストックローテーション** | 在庫の値下がり補填と、一定比率の返品・交換の権利。在庫リスクの重さを決める |
| **NCNR** | Non-Cancellable / Non-Returnable。キャンセル・返品不可の発注条件 |
| **アロケーション** | 供給不足時のメーカーによる配分割当 |
| **VMI** | Vendor Managed Inventory。商社が顧客近傍に在庫を置き、使用分だけ売上計上する方式 |
| **EMS／ODM** | EMSは製造受託、ODMは設計込みの受託。**商社にとっては「部品を決めない客」** |
| **ブローカー／オープンマーケット** | 正規ルート外の現物市場。逼迫時に値が跳ね、真贋リスクを伴う |
