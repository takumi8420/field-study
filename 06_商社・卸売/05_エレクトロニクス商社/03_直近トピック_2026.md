# 直近トピック（2026年9月時点）

報道と各社IRをもとにした整理。数値は確認時点のもので、**一次情報（決算短信・適時開示）で裏取りすること**を前提に読む。
仕組みの説明は [① 半導体・電子部品流通の仕組み](01_半導体・電子部品流通の仕組み.md)、
構造の説明は [② 業界構造と再編](02_業界構造と再編.md) にある。

> この1年を一言で言うと：**AIメモリの争奪戦が、在庫を持つ商社に「棚ぼたの利益」を配った年**。
> ただし配られ方は平等ではなく、扱い商材と為替ポジションで明暗がはっきり割れた。

## 1. AIメモリ争奪戦が商社の損益を押し上げた（2025年末〜2026年）

生成AI向けデータセンター投資でHBM（広帯域メモリ）と汎用DRAMの奪い合いが起き、メモリ価格が記録的に上昇した。

| 指標 | 数値 | 時点・出典 |
| --- | --- | --- |
| DRAM契約価格 | 前四半期比 **+93〜98%**（1四半期でほぼ2倍） | 2026年第1四半期、報道ベース |
| 主要DRAMメーカーの在庫水準 | 13〜17週（2024年末）→ **2〜4週**（2025年10月） | 報道・調査会社の推計 |
| サーバー関連コスト | 2026年前半に **+125%以上** | 報道ベース |

```
【なぜメモリ高騰が「商社にとって追い風」になるのか】

  商社は買取仕入 ＝ 自分の倉庫に在庫を持っている

   仕入時点          保有期間          売却時点
   単価 100 で仕入 ──────────────▶ 単価 160 で販売
                    （相場が上昇）
                                       粗利 ＋60 が自動的に乗る
                                       ＝ 営業努力と無関係な「相場益」

  ただし反転すると同じ幅で逆に振れる（在庫評価損）。
  2026年の好決算の相当部分は、この一時的な相場益である点に注意。
```

- 半導体メーカーは利益率の高いHBMの増産を最優先しており、汎用DRAM・NANDの供給が細った構図と報じられる
- **PC・スマートフォン向けにはしわ寄せ**が行き、2026年はメモリ不足を理由に出荷が落ち込むとの見方が出ている
  → [PC・スマートフォン](../../03_電機・電子部品/11_PC・スマートフォン/README.md)
- サムスン半導体依存度の高いトーメンデバイス（2026年3月期 売上6,337億円）のような会社では、
  **業績＝メモリ相場**という色がさらに濃くなった

## 3. 再編は「統合の仕上げ」フェーズに入った

2019年のルネサスによる代理店集約（16社→6社の方針と報じられた）を起点にした再編は、
2025〜2026年に**持株会社統合の中身を一本化する段階**へ移っている。

```
【直近2年の再編の流れ】

 2023.11  マクニカ、グローセルへTOB発表（最大190億円 / 1株645円）
             │
 2025.01  TOB成立、グローセルを完全子会社化
             │
 2025.10  マクニカがグローセルを吸収合併 ──────▶ 商権を1法人に集約
 ──────────────────────────────────────────
 2024.04  リョーサン ＋ 菱洋エレクトロ → リョーサン菱洋ホールディングス発足
             │                              （両社ともルネサス代理店）
 2026.04  事業会社2社が合併し「リョーサン菱洋」に ─▶ 重複コストの削減が利益に出始める
                                                      （2026年3月期 経常利益 +25.2%）
```

- 統合の狙いは売上拡大ではなく **「重複する商権・管理コストの整理」**。
  だからリョーサン菱洋HDのように「売上横ばい・利益2桁増」という決算になる
- 業界では **「最低でも売上5,000億円規模がないと単独での生き残りは厳しい」** という見方が語られている（日刊工業新聞の報道ベース）。
  この線で見ると、2,000億円前後の中堅各社が次の再編候補として意識されやすい
- ただし各社とも系列関係（三菱電機系、東京エレクトロン系など）と独自商権を持つため、単純な規模論だけでは動かない

## 4. メーカー側でも再編：オムロンが電子部品事業を売却（2026年3月発表）

商社の仕入先である部品メーカー側でも、事業の切り出しが起きている。

| 項目 | 内容 |
| --- | --- |
| 対象 | オムロンのデバイス＆モジュールソリューション事業（DMB）。リレー、スイッチ、コネクタなど |
| 事業規模 | 売上高 **688億円**（2025年3月期） |
| 譲渡先 | The Carlyle Group（米投資会社）が設立する受け皿会社 |
| 事業価値 | **810億円** |
| スケジュール | 会社分割の効力発生 2026年7月1日／株式譲渡実行 2026年10月1日（予定） |
| その後 | 承継会社は「**Aratas**」へ商号変更。オムロンは取引後も特別目的会社に5%出資 |

- オムロンは「想定以上に迅速かつ大規模な投資が必要になった」ことを理由に挙げたと報じられる。**祖業の切り出し**にあたる
- **商社にとっての意味**：仕入先の資本が変わると、代理店契約の条件・販売方針が見直される可能性がある。
  商権の前提が動くイベントとして注視される

## 6. 全体の構図

1. **2026年はエレクトロニクス商社にとって数字の良い年だった**。ただし利益の相当部分は、
   AI起因のメモリ・GPU高騰による**相場益**であり、本業の実力とは分けて読む必要がある
2. **産業機器・FA向けの需要回復は遅れている**。国内セットメーカーを主顧客とする商社ほど、恩恵が薄い
3. **構造的な逆風（メーカーの直販化・代理店集約・顧客の購買集約）は止まっていない**。
   好況は逆風を一時的に覆い隠しているだけで、再編の圧力は続く
4. 生き残り策は **規模（統合）** と **付加価値（モジュール開発・受託設計・ソフト）** の二択。
   マクニカのサイバーセキュリティ事業のような成功例はまだ少数にとどまる
5. **次の試練はメモリ相場の反転**。好況の最後に積んだ在庫が評価損に変わるのが、この業界の典型的な負け方である

## 8. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **HBM** | High Bandwidth Memory。DRAMを積層した広帯域メモリ。AIアクセラレータに必須で、2025〜2026年の争奪戦の中心 |
| **相場益／相場損** | 仕入れてから売るまでの価格変動で生じる損益。商社の決算を膨らませたり凹ませたりする |
| **棚ぼた利益** | 本業の努力と無関係に相場で乗った利益。持続性がないため、次期予想と切り分けて読む必要がある |
| **セグメント利益** | 事業部門ごとの利益。全社の増収と部門の減益が同時に起きることがある（レスターのデバイス事業が例） |
| **吸収分割** | 事業を切り出して別会社へ承継させる会社法上の手続き。オムロンのDMB切り出しがこれ |
| **TOB** | 株式公開買付。買付価格・期間を公告して市場外で株を買い集める手法。商社の再編で多用される |
