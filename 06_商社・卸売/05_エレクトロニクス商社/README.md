## このフォルダの読み方

エレクトロニクス商社は **「半導体や電子部品を仕入れて売る会社」ではなく、「顧客が回路を設計している段階で、自社が扱う型番を設計図に載せさせる会社」**である。
設計図（BOM）に載った瞬間に、その機種が生産される数年間の売上が確定する。これを **デザインイン**、
そこで得た「この客のこの機種は当社が供給する」という既得権を **商権** と呼ぶ。

### 最初に押さえる一行

> **エレクトロニクス商社は「注文を取る会社」ではなく「注文が発生する前に設計図へ型番を書き込ませる会社」**。
> 儲けの正体は ①仕入と売値の差、②在庫・与信・物流・技術支援の引受料、③相場の値動き の3つ。
> そして業界は **メーカーの直販化と代理店集約によって、長期にわたり数を減らし続けている**。

## 1. 業界の定義・範囲

**エレクトロニクス商社（半導体商社・電子デバイス商社）** ＝
半導体・電子部品メーカーと正規の代理店契約を結び、**在庫・与信・物流・技術支援を引き受けたうえで、機器メーカーへ販売する専門商社**。

| 隣接領域 | 境界の引き方 |
| --- | --- |
| [総合商社](../01_総合商社/README.md) | 総合商社は **事業投資で稼ぐ層** を持つ。エレクトロニクス商社は原則**商流（買取仕入・買取販売）だけ**で食べる |
| 部品メーカー（[電子部品](../../03_電機・電子部品/05_電子部品/README.md) 等） | 作る側。ただし商社がモジュールを自社設計する領域では境界が溶ける |
| EMS（製造受託） | 本来は「作る側」だが、加賀電子・レスターのように商社がEMSを自社で持つ例がある |
| カタログ通販（Digi-Key、Mouser、RSなど） | 在庫販売だが**技術支援とデザインインを伴わない**。試作・少量の需要を吸っている |
| 独立系ディストリビュータ／ブローカー | 正規代理店契約を持たず、市中在庫を売買する。逼迫期だけ価格が跳ねる現物市場 |
| [機械商社](../04_機械商社/README.md) | 商材が装置・機械。技術営業型という点は共通 |

業界の中は **①扱いメーカー（国内系／海外系／メモリ系）、②顧客（国内セットメーカー／EMS・ODM／データセンター）、
③機能（純粋な商流／EMS保有／ソリューション開発）** の3軸で分かれる。
同じ「半導体商社」でも、この掛け算で中身がまったく違う。

## 2. 市場規模と成長性

「市場規模」を測りにくい業種である。**商社の売上を足すと、半導体・電子部品市場を二重計上する**ためだ。
実務では **主要各社の売上高の合計** と **半導体市場そのものの規模** を並べて見る。

| 指標 | 数値 | 時点・出典 |
| --- | --- | --- |
| 国内主要半導体・電子部品商社 上位10社の売上高合計 | **約3兆9,000億円** | 2026年3月期、各社決算からの集計（electro-ma） |
| 国内最大手の売上高 | マクニカHD **1兆2,142億円**（+17.4%） | 2026年3月期、決算短信・報道 |
| 増収増益社数 | 対象18社中 **8社**（2027年3月期予想では7社） | 2026年3月期通期、EE Times Japan 集計 |
| 世界最大手の売上高 | Arrow Electronics **約309億ドル**（+10%） | 2025年12月期、同社発表 |
| 世界2位 | Avnet **約222億ドル**（▲6.6%） | 2025年6月期（FY2025）、同社発表 |
| 単独生存の下限とされる規模 | **売上5,000億円** | 業界内の見方として報道（日刊工業新聞） |

- **成長性は「半導体市場の成長 −（直販化・代理店集約で失う分）」** で考えるのが実態に近い。
  市場が伸びても、商社が通す割合は長期的に下がっている
- 2026年3月期の好決算は、**AI起因のメモリ・GPU高騰による単価上昇**が主因。
  産業機器・FA向けの数量回復は遅れている → [③ 直近トピック](03_直近トピック_2026.md)
- 為替の影響が大きい。ドル建て仕入・円建て販売が多く、**円安は追い風、円高は逆風**に働く

 ─────────         ──────────────────       ──────────
 NVIDIA / TI / ADI                                             ┌─ 国内セットメーカー
 ルネサス / ローム      ┌─ ① 代理店契約（＝販売する権利）─┐   │  自動車・FA・計測・医療

                        │  ⑤ 物流（VMI・ハブ倉庫）          │──▶│  大量・低粗利・世界大手の陣地
                        │  ⑥ 技術支援（FAE）                │   │

## 5. 収益モデル・コスト構造

```
  売上高  100
  － 仕入   90    ← 粗利率 8〜15% が目安（商材と機能で大きく変わる）
  ＝ 粗利   10
  － 販管費  7    ← 最大は人件費（営業＋FAE）。次いで物流・システム
  ＝ 営業利益 3   ← 売上高営業利益率 2〜5% が相場
                    例：マクニカHD 3.5%（419億円÷1兆2,142億円、2026年3月期）
                        東京エレクトロンデバイス 経常利益率 4.8%（同期）
```

| 論点 | 中身 |
| --- | --- |
| 儲けの三本柱 | ① 価格差（buy-sell） ② 機能対価（在庫・与信・物流・技術支援） ③ 相場益（仕入〜販売の間の値動き） |
| **固定費の正体** | 工場は原則ない。**人件費（特にFAE）とシステム・物流費が固定費**。だから不況期に真っ先に削られるのが技術者になる矛盾がある |
| **最大のリスク資産** | **棚卸資産（在庫）**。相場下落時には低価法で評価損が立ち、利益が一気に消える |
| 与信 | 顧客倒産で売掛金が飛ぶ。**実質的に商社が顧客へ短期の金貸しをしている** |
| 為替 | ドル建て仕入・円建て販売が多く、円安は在庫評価と粗利に追い風 |
| 見るべき指標 | 売上より **粗利率** と **棚卸資産回転日数**。増収が数量なのか単価なのかを必ず分解する |

→ 詳細は [① 流通の仕組み](01_半導体・電子部品流通の仕組み.md) の第5章。

## 6. 競争要因（KSF）と参入障壁

**KSF（成功の鍵）**

1. **代理店契約を持っているか**。メーカーに指名されなければ、そもそも土俵に上がれない
2. **デザインイン力＝FAEの人数と質**。難しい石を扱えるかどうかが粗利率を決める
3. **独自商材の発掘**。無名の海外半導体メーカーを早期に見つけ、日本で立ち上げられるか
4. **在庫の読み**。需要の谷で仕入れすぎず、逼迫期に欠品させない。**負ける会社はここで負ける**
5. **規模と資金力**。メーカーからの仕入条件、与信枠、逼迫期のアロケーションはすべて規模で決まる
6. **商権の束としての顧客基盤**。M&Aの動機がここにある

**参入障壁**

| 障壁 | 強さ | 理由 |
| --- | --- | --- |
| 代理店契約 | **強** | メーカーは代理店を**増やす**より減らす方向。新規に枠をもらうのは難しい |
| 既存の商権 | **強** | 量産中の機種は部品を差し替えられない。再評価・再認証コストが新規採用の利益を超える |
| FAE人材 | **強** | 半導体・回路の実務が分かり、顧客対応もできる技術者は短期間では育たない |
| 資金力（在庫・与信） | 中〜強 | 数百億〜数千億円の運転資金が要る |
| 物流・システム | 中 | 構築できるが投資が要る |
| 事務としての商流 | 弱 | 貿易・通関・受発注の実務自体は模倣可能 |

## 7. 規制・法制度

許認可で守られた業種ではない。効くのは**通商管理**である。

| 制度 | 内容 |
| --- | --- |
| **外国為替及び外国貿易法（外為法）** | 安全保障貿易管理。軍事転用可能な貨物・技術の輸出許可。**違反は刑事罰**。半導体は該当品が多く、商社は該当性判定と顧客用途確認の責任を負う |
| **米国の輸出管理（EAR）・エンティティリスト** | 米国原産技術を含む製品の再輸出規制。**日本の商社も直接適用を受ける**。中国向け先端半導体の規制強化が続く |
| **経済安全保障推進法（2022年）** | 重要物資（半導体を含む）のサプライチェーン調査・支援。商社にも調達構造の開示が求められる場面がある |
| **関税・通商政策** | 米国の関税措置。2026年3月期については各社とも「直接的な影響は限定的」と説明したと報じられる |
| **紛争鉱物・人権デューデリジェンス** | タンタル・スズ・タングステン・金の調達先開示 → [レアメタル・レアアース](../../11_資源・エネルギー・鉄鋼金属/13_レアメタル・レアアース/README.md) |
| **RoHS／REACH（EU）** | 有害物質規制。商社は含有情報の伝達義務を負う |
| **下請法・独占禁止法** | EMS・加工委託を行う場合の発注者としての規制 |
| **偽造部品対策** | 正規ルート外調達で問題になる。AS6081など真贋判定の規格がある |

## 8. 最近のトピック

詳細と出典URLは **[③ 直近トピック（2026年9月時点）](03_直近トピック_2026.md)**。要点は5つ。

1. **AIメモリ争奪戦が商社の利益を押し上げた**。DRAM契約価格は2026年第1四半期に前四半期比+93〜98%（報道ベース）。
   在庫を持つ商社には**相場益**がそのまま乗ったが、これは本業の実力とは分けて読む必要がある
2. **2026年3月期は18社中8社が増収増益**（EE Times Japan 集計）。マクニカHDが売上1兆2,142億円（+17.4%）で**初の1兆円超**、
   加賀電子は純利益311億円（+82.0%）。一方レスターのデバイス事業は円高と産機回復の遅れでセグメント利益▲10.2%
3. **再編は「統合の仕上げ」段階へ**。マクニカが2025年10月にグローセルを吸収合併、
   リョーサンと菱洋エレクトロの事業会社が2026年4月に合併。**売上横ばい・利益2桁増**というコスト削減型の成果が出始めた
4. **メーカー側でも再編**。オムロンが電子部品事業（売上688億円）を米カーライルへ譲渡すると2026年3月に発表（事業価値810億円、譲渡実行2026年10月予定）
5. **台湾勢の日本浸透**。WT Microelectronics が受動部品商社の日電貿と株式交換で提携（2025年7月）、
   2026年5月にはWT側の人物が日電貿会長に就任したと報じられる。**日本の受動部品商権が外資に移る入口**として注視されている

## 9. 用語メモ

各ノート末尾にも用語メモがある。ここでは最重要の8語。

| 用語 | 意味 |
| --- | --- |
| **デザインイン** | 顧客の設計段階で自社扱い品を回路図・BOM（部品表）に採用させること。**この業界の商売の起点** → [①](01_半導体・電子部品流通の仕組み.md) |
| **商権（しょうけん）** | 「この顧客のこの機種は当社が供給する」という既得権。単位は顧客×機種×型番。**M&Aの最大の動機** → [①](01_半導体・電子部品流通の仕組み.md) |
| **FAE** | Field Application Engineer。顧客の設計現場に出向いて技術支援する商社の技術者。**扱える商材の難易度を決める** → [①](01_半導体・電子部品流通の仕組み.md) |
| **正規代理店（フランチャイズ）** | メーカーから正式に販売を任された商社。飲食のFCとは意味が違う → [①](01_半導体・電子部品流通の仕組み.md) |
| **デザインレジストレーション／ship & debit** | 案件をメーカーに登録して特価を得る制度と、その差額精算の仕組み → [①](01_半導体・電子部品流通の仕組み.md) |
| **アロケーション** | 供給不足時にメーカーが顧客ごとに配分を割り当てること。商社の交渉力が露わになる場面 → [①](01_半導体・電子部品流通の仕組み.md) |
| **代理店集約** | メーカーが取引する正規代理店の数を絞ること。ルネサスの16社→6社方針（2019年）が業界再編の号砲 → [②](02_業界構造と再編.md) |
| **ソリューション型** | 仕入販売から、モジュール開発・受託設計・ソフト提供へ広げる戦略の総称 → [②](02_業界構造と再編.md) |
