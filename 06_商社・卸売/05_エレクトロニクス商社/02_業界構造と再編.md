# 業界構造と再編

このノートで分かること：日本のエレクトロニクス商社が**なぜ数を減らし続けているのか**、
世界大手との規模差がどれほどあるのか、そして生き残り策として掲げられる「ソリューション型」とは実際に何をすることなのか。

> 結論を先に：**この業界の縮小は景気の話ではなく、構造の話**である。
> ①半導体メーカーが代理店を減らし、②大口顧客には直販に切り替え、③顧客側も購買を集約した。
> 商社の数だけが減らずに残っていたので、**合併して商権を束ねる以外に道がない**。
> 「最低でも売上5,000億円規模がないと単独での生き残りは厳しい」というのが業界内の共通認識として語られている（日刊工業新聞の報道ベース）。

## 1. 国内プレイヤーの並び（2026年3月期）

国内主要商社の規模は、上位2社と、それ以下の間に明確な段差がある。

| 順位 | 企業 | 売上高（2026年3月期） | 経常利益 | 特徴 |
| --- | --- | --- | --- | --- |
| 1 | **マクニカホールディングス** | **1兆2,142億円**（+17.4%） | 374億円 | 半導体事業が初の1兆円超（1兆286億円）。サイバーセキュリティ1,739億円という異色の第2本柱 |
| 2 | **加賀電子** | **6,589億円**（+20.3%） | 299億円 | 2019年に富士通エレクトロニクスを取得。EMS（製造受託）を自社で持つ |
| 3 | **トーメンデバイス** | 6,337億円 | 133億円 | **サムスン半導体1社への依存度が極端に高い**。メモリ相場で業績が激しく動く |
| 4 | **レスターホールディングス** | 6,309億円 | 138億円 | バイテックHDとUKCホールディングスの2019年統合で誕生。EMS・環境事業も持つ |
| 5 | **リョーサン菱洋ホールディングス** | 3,599億円（±0.0%） | 89億円（+25.2%） | 2024年にリョーサンと菱洋エレクトロが経営統合。2026年4月に事業会社も合併 |

| 8 | **RYODEN** | 2,128億円 | 58億円 | 旧・菱電商事。三菱電機系のもう一社 |
| 9 | **東京エレクトロンデバイス** | 2,037億円 | 98億円 | 東京エレクトロン系。**利益率が高い**（経常利益率4.8%）。設計受託・自社ブランド品を持つ |

細目の定義（IFRS／日本基準、総額／純額表示）が社ごとに違うため、順位は目安として読む。

> 読み方のコツ：**売上の桁は「何を扱っているか」でほぼ決まる**。
> メモリやGPUのような高単価・大量品を扱えば売上は数千億円単位で膨らみ、
> 少量多品種のアナログICや受動部品中心なら売上は伸びにくいが粗利率は高い。
> **売上ランキングは強さのランキングではない**。

- 台湾のWT Microelectronicsは2025年7月、受動部品商社の日電貿（Nichidenbo）と株式交換で提携し、

  2026年5月にはWT側の人物が日電貿の会長に就いたとも報じられており、**中華圏商社の日本市場への浸透**が進んでいる
- **規模差は「価格」に直結する**。メーカーから見れば、年間1兆円買う代理店と1,000億円買う代理店では、与えられる仕入条件が違う

## 3. なぜ数が減り続けるのか：3つの圧力

```
【エレクトロニクス商社を挟み撃ちにする力】

        ┌─────────── 川上（半導体メーカー）────────────┐
        │  ① 代理店集約     … 管理コスト削減・在庫可視化のため      │
        │     ルネサスは2019年に国内代理店を 16社 → 6社 へ絞る方針   │
        │     （日本経済新聞、日経クロステック報道）                  │
        │  ② 直販シフト     … 大口顧客は自社で直接取引した方が安い    │
        └────────────────┬───────────────────┘
                                 ▼   商社の取り分が削られる
        ┌──────── エレクトロニクス商社（数十社が並存）─────────┐
        │  粗利率は低下、在庫リスクは残る、FAEの人件費は固定         │
        └────────────────┬───────────────────┘
                                 ▲   単価引下げ圧力
        ┌─────────── 川下（セットメーカー）────────────┐
        │  ③ 購買の集約     … 取引商社数を絞りコストダウン           │
        │     ＋ 海外生産移管で、国内商社の出番が減る                │
        │     ＋ カタログ通販（Digi-Key/Mouser/RS）が試作需要を吸う   │
        └────────────────────────────────────┘
```

| 圧力 | 具体的に起きたこと |
| --- | --- |
| **メーカーの代理店集約** | ルネサスエレクトロニクスが2019年に国内特約店を16社から6社へ絞る検討を開始したと報じられた。**日立・三菱電機・NECの半導体部門が合流した経緯で代理店が重複していた**ことが背景 |
| **直販化** | 大口顧客・EMS・データセンター事業者には、メーカーが直接売る方が中間コストが消える。商社に残るのは中小顧客 |
| **顧客側の購買集約** | セットメーカーが調達先商社を絞る。残れなかった商社は一気に売上を失う |
| **カタログ通販** | 試作・少量の需要をDigi-Key、Mouser、RSコンポーネンツが吸収。**FAEが手間をかけていた「小さな種まき」の場が減った** |
| **国内生産の海外移管** | 顧客の工場が海外へ出ると、国内商社は現地法人を作るかグローバル商社に譲るかの二択になる |

> 要点：**商社の数が多すぎること自体が問題**だった。
> 日本の半導体産業が複数の総合電機の内部部門として育ったため、各社に系列代理店がぶら下がった。
> 半導体メーカーが統合（ルネサス＝日立＋三菱＋NEC）しても、代理店だけが残った。
> その整理が2010年代後半から一気に進んでいる。

## 4. 再編の年表（主なもの）

| 時期 | 出来事 | 意味 |
| --- | --- | --- |
| 2019年4月 | ルネサスが国内代理店を16社→6社へ集約する方針と報じられる | **再編の号砲**。切られる側にならないための統合が始まる |
| 2019年 | バイテックホールディングス＋UKCホールディングス → **レスターホールディングス** | 売上規模での生き残り。EMS・環境事業も抱える複合型へ |
| 2019年 | 加賀電子が**富士通エレクトロニクス**を取得 | 富士通の半導体商権を丸ごと取り込んだ典型例 |
| 2023年11月 | マクニカが**グローセル**へのTOBを発表（最大約190億円、1株645円） | 中堅の取り込み |
| 2024年4月 | **リョーサン＋菱洋エレクトロ**が経営統合（リョーサン菱洋ホールディングス発足） | **両社ともルネサス代理店**。重複商権を束ねる統合 |
| 2025年1月 | マクニカによるグローセルTOBが成立、完全子会社化 | — |
| 2025年10月 | マクニカがグローセルを吸収合併 | 商権を1つの法人に集約 |
| 2026年4月 | リョーサンと菱洋エレクトロの事業会社が合併し「**リョーサン菱洋**」に | 持株会社統合から2年かけて中身を一本化 |
| 2026年3月 | オムロンが電子部品事業（DMB）を米カーライルへ譲渡すると発表（事業価値810億円） | **メーカー側でも再編**。商社にとっては仕入先の顔ぶれが変わる話 |

**統合の順番には型がある**：①持株会社を作って並存 → ②システム・物流を統合 → ③事業会社を合併 → ④重複商権の整理。
②〜④に2〜3年かかるため、統合直後は費用先行で利益が出にくい。
リョーサン菱洋HDの2026年3月期が「売上は横ばい（3,599億円）、経常利益は+25.2%」となったのは、
**売上を増やす統合ではなく、重複コストを削る統合**だったことの数字上の現れといえる。

## 5. 生き残り策としての「ソリューション型」

単なる仕入れ販売（buy-sell）だけでは粗利が守れないため、各社が掲げるのが**ソリューション型**への転換である。
中身を分解すると、実は4つの別々の話が混ざっている。

| 類型 | 具体的にやること | 儲け方 | 代表例 |
| --- | --- | --- | --- |
| **① モジュール開発** | 複数部品を載せた基板・ユニットを自社設計し、型番を付けて売る | 部品の集合体に設計料を上乗せできる。価格比較されにくい | 東京エレクトロンデバイス、菱洋系の自社ブランド品 |
| **② 受託設計・EMS** | 顧客の代わりに回路設計・基板実装・組立まで請ける | 製造の付加価値を取り込む。ただし**設備と工場のリスクを負う** | 加賀電子、レスター |
| **③ ソフト／サービス** | セキュリティ、AI、クラウド、評価ツールなど非ハード商材 | ストック収益。在庫リスクがない | マクニカ（サイバーセキュリティ 2026年3月期 1,739億円、+13.0%）→ [情報セキュリティ](../../04_情報通信・IT・ネット/14_情報セキュリティ/README.md) |
| **④ 独自商材の発掘** | 無名の海外スタートアップ製半導体を早期に見つけ、日本市場で立ち上げる | **競合がいないので粗利が厚い**。当たれば数年の独占 | マクニカのFPGA・AI半導体など |

```
【粗利率と、そこに必要な能力】

  粗利率  低 ───────────────────────────▶ 高
          │                                            │
    汎用品の買取販売        技術提案つき販売      モジュール／ソフト／独自商材
    （EMS向け・標準品）      （FAEが介在）          （自社設計・自社ブランド）
          │                       │                        │
    必要なもの：資金・物流    必要なもの：FAE         必要なもの：開発部隊・
                                                       目利き・海外ネットワーク
          │                       │                        │
    ここは世界大手と            日本勢の本来の陣地      ここへ逃げられた会社だけが
    中華系が強い                                        利益率を保てている
```

- **②EMSは諸刃の剣**。工場を持つと固定費が乗り、稼働率が落ちた瞬間に赤字になる
  （→ 構造としては [電子部品](../../03_電機・電子部品/05_電子部品/README.md) の営業レバレッジと同じ）
- **③ソフト・サービスへの転換に成功した例は実はごく少ない**。マクニカのセキュリティ事業が繰り返し引き合いに出されるのは、
  裏を返せば他に大きな成功例が乏しいからでもある

## 6. 為替と在庫評価：数字の振れ方を読む

エレクトロニクス商社の決算は「本業の良し悪し」と「相場の追い風・向かい風」が混ざる。分けて読む必要がある。

| 要因 | 効き方 | 見るべき数字 |
| --- | --- | --- |
| **円安** | 外貨建て仕入の在庫評価が上がり、円建て売価も上げやすい。**売上と粗利の両方を押し上げる** | 為替前提レート、在庫残高の通貨別内訳 |
| **円高** | 逆。在庫評価損と粗利縮小が同時に来る。レスターの2026年3月期デバイス事業は、円高と産機回復の遅れでセグメント利益が▲10.2%と報じられる | 同上 |
| **商品市況（特にメモリ）** | 仕入れてから売るまでに相場が上がれば、その分がそのまま利益になる（逆も同じ） | 棚卸資産の増減、粗利率の急変 |
| **半導体サイクル** | 好況は数量と価格が同時に伸び、不況は在庫調整で数量・価格・評価が同時に痛む | **棚卸資産回転日数**、受注残 |

```
【半導体サイクルと商社業績のズレ】

 需要     ╱‾‾╲                ╱‾‾╲
         ╱    ╲              ╱    ╲
 ───╱──────╲────────╱──────╲───▶ 時間
                     ╲____╱

 商社の売上     　 ╱‾‾╲（半年ほど遅れてピーク）
 商社の利益   　　　╱‾╲   （在庫評価益が乗るのでさらに遅れ、
                           下りでは評価損で急落する）

 ＝ 商社の業績は「半導体需要の遅行指標」かつ「振れ幅が増幅される」
    好況の最後に仕入れた在庫が、不況の入口で評価損になるのが典型的な負け方
```

> 実務上の注意：**「増収＝好調」とは限らない**。
> メモリ高騰局面では、数量が減っていても単価上昇だけで売上が2桁伸びる。
> 中身を見るときは、売上より **粗利率と棚卸資産回転日数** を見る。

## 7. これからの論点

1. **さらなる統合は起きるか**。売上5,000億円が単独生存の下限とされるなら、
   2,000億円前後の会社（立花エレテック、丸文、RYODEN、伯東など）が次の再編候補として語られやすい。
   ただし各社とも系列・独自商権があり、単純な規模論では動かない
2. **中華系・台湾系の日本進出**。WT×日電貿のような資本提携は、日本の受動部品商権が外資に移る入口になり得る
3. **AI・データセンター特需の後始末**。2025〜2026年のメモリ・GPU高騰は商社に大きな利益をもたらしたが、
   **相場が反転したときの在庫評価損**が次の試練になる → [③ 直近トピック](03_直近トピック_2026.md)
4. **経済安全保障と輸出管理**。米中間の輸出規制で、商社は「誰に何を売ったか」の管理責任を負う。
   違反は外為法の刑事罰対象で、商社の実務負担が年々重くなっている
5. **半導体の国内回帰**。TSMC熊本、ラピダスなどの国内新工場は、材料・装置・部品の新しい商流を生む
   → [半導体・先端半導体](../../01_注目テーマ/02_半導体・先端半導体/README.md)、[半導体製造装置](../../03_電機・電子部品/03_半導体製造装置/README.md)

## 8. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **代理店集約** | メーカーが取引する正規代理店の数を絞ること。切られた商社はその商権を失う |
| **直販（ダイレクト）** | メーカーが商社を通さず顧客と直接取引すること。大口ほど起きやすい |
| **特約店** | 正規代理店の日本語での呼び方。メーカーごとに指名される |
| **ソリューション型** | 単純な仕入販売から、モジュール開発・受託設計・ソフト提供へ広げる戦略の総称 |
| **EMS** | Electronics Manufacturing Services。電子機器の製造受託。商社が自ら持つ場合もある |
| **棚卸資産回転日数** | 在庫が何日分あるか。商社の健康診断で最も重要な指標のひとつ |
| **低価法（評価損）** | 在庫の時価が簿価を下回ったとき簿価を切り下げる会計処理。相場下落局面で利益を直撃する |
| **持株会社統合** | まず持株会社を作って両社を並存させ、数年かけて中身を合併する統合方式 |
| **系列商社** | 特定メーカーの資本・人的関係が強い商社（立花エレテック・RYODEN＝三菱電機系、TED＝東京エレクトロン系など） |
