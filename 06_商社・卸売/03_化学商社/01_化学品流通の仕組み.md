# 化学品流通の仕組み

このノートで分かること：化学メーカーが作った製品が、どういう経路でユーザーの工場に届くのか。
そして「間に商社が入る」ことがなぜ消えないのか（＝化学商社の存在理由）を、品目数・危険物規制・与信の3点から説明する。

> ポイント：化学商社の参入障壁は「商品知識」ではなく、**数万点の危険物・毒劇物を、法令どおりに保管して小分けして運び、代金を立て替えられる体制**にある。
> モノを右から左に流すだけの会社は消えたが、この3つを持つ会社は消えていない。

---

## 1. まず全体像：化学品は「二段階の卸」を通る

化学品の流通は、鉄鋼や食品と同じく**メーカー → 商社（一次）→ 販売店（二次）→ ユーザー**という段階を踏む。
ただし化学品に特有なのは、**ユーザーの数が極端に多く、1件あたりのロットが極端に小さい**こと。
塗料工場も、化粧品会社も、めっき屋も、食品工場も、半導体工場も、全部が化学品のユーザーである。

```
【川上：化学メーカー】          【中間：商社・卸】              【川下：ユーザー】
                            ┌───────────────────────────┐
三菱ケミカル                 │ 一次商社（化学商社）        │   自動車部品メーカー
住友化学          ──販売──▶ │  長瀬産業／稲畑産業 など    │ ─▶ 電機・半導体工場
三井化学                     │   ・代理店契約で販売権      │    塗料・インキメーカー
信越化学                     │   ・在庫を持つ              │    化粧品・医薬メーカー
（海外メーカー）             │   ・与信を負う              │    食品メーカー
BASF / Dow / 中国勢  ─輸入─▶ │   ・小分け／調合する        │    めっき・表面処理業者
                            └──────────┬────────────────┘    印刷・繊維・建材
                                       │                     （数万〜数十万事業所）
                                       ▼
                            二次卸・販売店（地場の薬品店・資材店）
                              地域密着。1斗缶・20kg袋単位の御用聞き
```

- **一次商社**＝メーカーと直接の代理店契約を結び、販売権と在庫責任を持つ層。ここが「化学商社」
- **二次卸**＝地場の薬品商・資材商。1缶単位で町工場に届ける層
- 大口ユーザー（石化コンビナート内の相互取引など）は**メーカー直販**になることも多い。商社が強いのは「中小ロット・多品種・遠い顧客」の領域

## 2. なぜ中抜きされないのか：3つの理由

| 理由 | 中身 | メーカーが自前でやりたがらない訳 |
| --- | --- | --- |
| **品目が多すぎる** | 汎用樹脂から特殊な添加剤まで、1社で数万点を扱う。1品目あたりの年間売上が数百万円のものが大量にある | メーカー1社の品目では顧客の要求を満たせず、かといって少額取引に営業を置くと赤字になる |
| **法規制の塊** | 消防法の危険物、毒物及び劇物取締法（毒劇法）、化審法、労働安全衛生法、高圧ガス保安法…。**保管・輸送・表示のすべてに免許と設備が要る** | 危険物倉庫の建設・届出・有資格者配置は固定費。荷主が各社で持つより、商社が集約した方が安い |
| **与信（代金の立替）** | 中小ユーザーへの掛け売り。回収不能リスクを商社が負う | メーカーは数万社の信用調査をしたくない。倒産リスクを商社に移せる |

> なぜそうなるか：化学品は「少量・多品種・危険物・小口顧客」という、**規模の経済が効かない組み合わせ**を同時に抱えている。
> その非効率をまとめて引き受ける事業者がいないと流通が成り立たない。それが化学商社。

## 3. 参入障壁の実体：免許・設備・資格

化学商社を始めるのに必要なものは「営業力」ではなく、まず**ハコと資格**である。

| 法令 | 対象の例 | 商社に求められるもの |
| --- | --- | --- |
| 消防法（危険物） | ガソリン、シンナー、アルコール、油脂 | 危険物倉庫・屋外タンクの設置許可、**危険物取扱者（甲種・乙種）**の配置 |
| 毒物及び劇物取締法 | 硫酸、苛性ソーダ、シアン化合物、フッ化水素 | **毒物劇物販売業の登録**（店舗ごと）、毒物劇物取扱責任者の設置、譲渡手続書（購入者の身元記録）の5年保存 |
| 化審法（化学物質審査規制法） | 新規化学物質、第一種特定化学物質 | 輸入時の届出、規制物質の取扱可否判断。PFAS のように**ある日突然「禁止」になる**リスク管理 |
| 労働安全衛生法 | SDS（安全データシート）対象物質 | SDS 交付、ラベル表示、リスクアセスメント支援 |
| 高圧ガス保安法 | 水素、酸素、窒素、LPガス | 販売事業届出、保安統括者の選任、容器管理 |
| 薬機法・食品衛生法 | 医薬品原薬、食品添加物 | 医薬品販売業許可、食品添加物としての規格適合確認 |

```
   取扱品目を1つ増やすとき、商社の中で走るチェック
   ─────────────────────────────────────────────
   ① その物質は化審法上どの区分か（新規？ 第一種特定？）
        │ 該当 → 取扱不可 or 届出
   ② 消防法の危険物か（第4類第1石油類…）
        │ 該当 → 置ける倉庫はどこか。容量上限は
   ③ 毒劇物か
        │ 該当 → 販売業登録のある拠点からしか売れない。譲受書の受領要
   ④ 輸送はどうする（タンクローリー／ドラム／IBC／フレコン）
   ⑤ SDS は最新版か。顧客の海外工場に送るなら現地規制（REACH/TSCA）は
   ─────────────────────────────────────────────
   → この一連を回せる体制そのものが参入障壁。
      「安く仕入れて高く売る」だけの新規参入者は②③で詰まる。
```

## 4. 基礎化学品と機能化学品：同じ商社の中に別の商売がある

化学商社の損益を読むときは、**扱っている品目がどちらの性質か**を先に見る。利益率も営業のやり方も違う。

| | 基礎化学品（汎用品・コモディティ） | 機能化学品（スペシャリティ） |
| --- | --- | --- |
| 品目の例 | ポリエチレン、ポリプロピレン、苛性ソーダ、メタノール、汎用溶剤 | 半導体用フォトレジスト、電池材料、化粧品原料、食品添加物、医薬中間体 |
| 価格の決まり方 | **市況**。ナフサ価格や海外相場に連動し、毎月・毎四半期に改定 | **相対（あいたい）**。顧客の処方に組み込まれており価格は動きにくい |
| 商社の粗利率の目安 | 数％以下。薄い | 十数％〜。厚い |
| 勝負どころ | 物量、在庫の回転、物流コスト、為替と市況の読み | 技術提案、評価サンプルの提供、規格保証、代替材の提案 |
| 顧客との関係 | 相見積もりで切り替えられやすい | いったん採用されると数年〜十年単位で続く（**スイッチングコストが高い**） |
| 業績の振れ | 市況と数量で大きく振れる | 顧客の設備投資サイクルに連動（半導体は振れる） |

補足：**スペック・イン**（顧客の設計・処方段階で自社の商材を指定してもらうこと）ができるかどうかが、機能化学品の商売の分かれ目。
処方に入ってしまえば、顧客が材料を変えるには再評価と再申請が必要になるため、容易に外せなくなる。

## 5. 3つの稼ぎ方：代理店・輸入・自社ブランド

化学商社は同じ「売る」でも、立場が3通りある。

```
 (A) 国内メーカーの代理店              (B) 海外品の輸入              (C) 自社ブランド／製造
 ┌───────────┐                   ┌───────────┐              ┌───────────┐
 │国内メーカー│                   │海外メーカー│              │ 自社工場   │
 └─────┬─────┘                   └─────┬─────┘              │ or 委託先  │
       │ 代理店契約                      │ 独占販売権          └─────┬─────┘
       ▼ （販売地域・分野を指定）        ▼ （日本での窓口）           │ 自社処方・自社銘柄
 ┌───────────┐                   ┌───────────┐              ┌─────▼─────┐
 │  化学商社  │                   │  化学商社  │              │  化学商社  │
 └─────┬─────┘                   └─────┬─────┘              └─────┬─────┘
       │ 口銭（数％）                    │ 為替・通関・在庫を負う      │ 粗利は最も厚い
       ▼                                 ▼ 代わりに粗利は厚い         ▼ 在庫と品質責任も負う
     ユーザー                          ユーザー                     ユーザー
```

| 型 | 商社の役割 | 取り分 | リスク |
| --- | --- | --- | --- |
| (A) 代理店 | メーカーの販売網の代わり。顧客開拓・与信・在庫 | 口銭（コミッション）。薄い | 代理店契約を切られると売上が消える |
| (B) 輸入 | 海外メーカーの日本窓口。通関・法規対応・在庫・技術サポート | 厚い。為替差益／差損も乗る | 為替、船積み遅延、海外メーカーの直販転換 |
| (C) 自社ブランド・製造 | 自ら調合・製造して自社銘柄で売る。M&Aで工場を持つケースも多い | 最も厚い（メーカーの利益がそのまま入る） | 在庫、設備、品質・PL責任を全部負う |

近年の大手は (A) 一本足から (B)(C) へ重心を移している。**口銭商売だけでは利益率が上がらない**ためで、
これが後述の「メーカー機能の内製化」（→ [プレイヤーと戦略](02_プレイヤーと戦略.md)）につながる。

## 6. 在庫・小分け・調合という付加価値

化学商社の粗利は「情報」だけでなく、**物理的な手間**から出ている部分が大きい。

| 機能 | 具体的にやること | なぜ顧客が金を払うか |
| --- | --- | --- |
| **在庫（ストック）** | ローリー・ドラム・フレコンで持ち、必要なときに出す | メーカーのロットは大きすぎる。顧客は自社で危険物倉庫を持ちたくない |
| **小分け（リパック）** | 20tローリー → 200Lドラム → 18L缶 → 1kgボトル | 少量しか使わない顧客に、使う単位で届ける |
| **調合・混合（ブレンド）** | 複数の原料を顧客指定の比率で混ぜる、溶剤で希釈する | 顧客の工程が1つ減る。配合ノウハウを商社が持つケースもある |
| **保管条件の管理** | 冷蔵・冷凍・遮光・防爆・温調 | 電池材料や医薬原料は保管条件を外すと廃棄になる |
| **品質保証の中継** | ロット分析表（COA）の受け渡し、規格逸脱時の切り分け | 顧客の受入検査を省ける |
| **廃液・容器の回収** | 空容器の引き取り、リサイクル | 廃棄物処理の手間が減る |

```
  20t タンクローリー（メーカー出荷ロット）
        │
        ▼  商社の危険物倉庫／調合設備
   ┌────────────────────────────────────┐
   │  [受入タンク] ─▶ [調合タンク] ─▶ 充填 │   ← ここで粗利が乗る
   │      ▲            ▲                   │      （手間賃＋配合ノウハウ）
   │   他の原料      添加剤・希釈溶剤       │
   └────────────────────────────────────┘
        │        │         │          │
     200Lドラム  18L缶   4Lボトル   1kg小分け
        ▼        ▼         ▼          ▼
     中堅工場  町工場   研究所     ラボ・試作
```

> なぜそうなるか：メーカーは「大量・単品・連続生産」が得意で、「少量・多品種・小刻みな出荷」は苦手。
> その逆を引き受けるから、商社は口銭の外側に**手間賃**を取れる。これが「モノを流すだけ」との違い。

## 7. 与信と商流金融：実は金融業に近い

化学商社の資産のかなりの部分は、**売掛金と在庫**である。ここが理解の勘所。

```
 メーカーへの支払い    ←── 商社 ──→    ユーザーからの入金
   出荷後 30〜60日                        納品後 60〜120日
        │                                        │
        └──────── この差（運転資金）を商社が埋める ────┘
                     ＝ 商社が事実上の short-term ファイナンスをしている
```

| 機能 | 中身 | 商社が得るもの |
| --- | --- | --- |
| 掛け売り（与信） | ユーザーの支払いまでの期間、代金を立て替える | 金利相当分を口銭に織り込む |
| 債権保全 | 信用調査、与信枠設定、取引信用保険、担保・保証 | 焦げ付きを抑える。**ここが商社の生命線** |
| 在庫金融 | メーカーから買って寝かせ、顧客の要求どおりに出す | 保管料＋価格変動益（逆もある） |
| 為替ヘッジ | 輸入品の為替予約 | 為替変動を顧客に転嫁せず、安定価格を提示できる |

読み方のコツ：
- **在庫回転日数**が伸びていたら、売れ残りか、意図的な戦略在庫か（市況先高観）を見る
- **売上債権回転日数**が伸びていたら、顧客の資金繰りが苦しくなっているサイン
- 市況品の比率が高い商社は、**ナフサ価格が上がると売上も利益も増えて見える**（数量が増えていなくても）。数量ベースの動きを別に確認する

## 8. 物流：ここが2020年代の最大の制約

化学品の輸送は**危険物輸送**であり、一般貨物と同じようには扱えない。

- タンクローリーの運転には危険物取扱者と、車両側の免許・検査が要る。**運べるドライバーの母集団が小さい**
- 積み合わせ（混載）の制限がある。混ぜると危険な組み合わせは同じ車に載せられない
- 荷役（ホース接続・受入立会い）に時間がかかり、待機時間が長い
- 2024年4月からのドライバー時間外労働の上限規制（いわゆる**物流の2024年問題**）で、長距離の当日運行が成立しにくくなった

業界としては、経産省・国交省の「フィジカルインターネット実現会議・化学品ワーキンググループ」が
トラック附帯作業の適正化、タンクローリー荷役の安全向上、**パレチゼーション**（パレット積みへの転換）のガイドライン作成に動いている（2026年4月時点の公表資料ベース）。
→ 詳細は [直近トピック_2026](03_直近トピック_2026.md) と [陸運・トラック](../../13_運輸・物流/06_陸運・トラック/README.md)。

## 9. 商流の数字の読み方（まとめ）

| 指標 | 何が分かるか | 目安 |
| --- | --- | --- |
| 売上総利益率（粗利率） | 汎用品中心か機能品中心か | 汎用中心なら 5〜8%、機能品比率が高いと 10〜20% |
| 営業利益率 | 商社としての稼ぐ力 | 商社は 2〜5% が標準。7% を超えると機能品・自社品が効いている |
| 在庫回転日数 | 商売の重さ、市況ポジション | 30〜60日程度が多い |
| ROE | 資本効率。商社はレバレッジが効きやすい | 大手は 9〜12% を目標に置く例が多い（2026年時点の各社中計） |
| 海外売上比率 | 成長ドライバーの所在 | 大手は 4〜6割。アジア中心 |

> 注意：**売上高の大きさと強さは比例しない**。市況品を大量に流すだけでも売上は膨らむ。
> 粗利率と、機能品・自社製品の比率をセットで見ること。

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **口銭（こうせん）** | 商社が取引の仲介で得る手数料。売買差益として計上されることが多い |
| **代理店契約** | メーカーが特定の商社に販売を委ねる契約。地域・分野・独占の有無を定める |
| **毒劇法（毒物及び劇物取締法）** | 毒物・劇物の製造・販売・輸入を登録制にし、譲渡記録や保管を義務づける法律 |
| **化審法** | 化学物質審査規制法。新規化学物質の事前審査と、有害物質の製造・使用規制を定める |
| **SDS（安全データシート）** | 化学品の危険有害性、取扱い、応急措置を記した文書。譲渡時の交付が義務 |
| **COA（Certificate of Analysis）** | ロットごとの分析成績表。規格に合っていることの証明書 |
| **リパック** | 大容量の荷姿を小容量に詰め替えること。小分け |
| **ブレンド（調合）** | 複数の原料を指定比率で混ぜて、顧客仕様の液・粉にすること |
| **IBC** | Intermediate Bulk Container。1000L 程度の角型液体容器。ドラムとローリーの中間 |
| **フレコン** | フレキシブルコンテナバッグ。粉体を 500kg〜1t 単位で運ぶ袋 |
| **スペック・イン** | 顧客の設計・処方段階で自社品を指定材料として採用させること |
| **コモディティ／スペシャリティ** | 市況で値が決まる汎用品／機能で値が決まる特殊品 |
| **パレチゼーション** | 手積み手降ろしをやめ、パレット単位の荷役に統一すること |
| **フィジカルインターネット** | 物流資源（車両・倉庫）を業界横断で共有し、積載効率を上げる構想。経産省・国交省が推進 |
