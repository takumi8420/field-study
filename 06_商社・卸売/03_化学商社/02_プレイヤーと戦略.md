# プレイヤーと戦略

このノートで分かること：化学商社にはどんな会社がいて、何が違うのか。
そして各社が今どこへ向かっているのか（高付加価値分野へのシフト、M&A、アジア展開）を、決算数値とセットで押さえる。

> ポイント：化学商社を分ける最大の軸は売上規模ではなく、**メーカー系か独立系か**。
> 背後に親会社のメーカーがいるかどうかで、扱える商材・伸ばせる分野・海外での動き方がまるごと変わる。

---

## 1. 業界の構図：3つの層

```
              ┌──────────────────────────────────────────────┐
              │ ① 独立系 専門商社（売上5,000億〜1兆円）      │
              │    長瀬産業 ／ 稲畑産業                      │
              │    特定メーカーに縛られず全方位で仕入れる     │
              │    → 自前のメーカー機能・海外網を持つ        │
              └──────────────────┬───────────────────────────┘
                                 │
  ┌──────────────────────────────┴──────────────────────────────┐
  │ ② メーカー系／総合商社系（売上1,000億〜1兆円）               │
  │    三菱商事ケミカル、三菱商事プラスチック、                  │
  │    伊藤忠ケミカルフロンティア、蝶理（東レ系）、              │
  │    三井物産プラスチック、豊通ケミプラス 等                   │
  │    親会社の商材が土台。安定するが、親の外に出にくい          │
  └──────────────────────────────┬──────────────────────────────┘
                                 │
              ┌──────────────────┴───────────────────────────┐
              │ ③ 中堅・地場の専門卸（売上数十億〜1,000億）  │
              │    ソーダニッカ、三谷産業、明和産業、巴工業 等│
              │    品目特化（苛性ソーダ、溶剤、樹脂…）or 地域密着│
              │    → 後継者難と規制対応コストで再編の対象     │
              └──────────────────────────────────────────────┘
```

なお、日本の統計上「化学製品卸売業」は非常に広く、
2026年7月の月間販売額は約2兆9,900億円（経産省 商業動態統計）と大きい。
上場している化学商社はそのごく一部で、**大半は非上場の中堅・地場卸**である。

## 3. メーカー系と独立系：何が違うのか

| 論点 | メーカー系（親会社が化学・繊維メーカー／総合商社） | 独立系（長瀬、稲畑 など） |
| --- | --- | --- |
| 商材の源 | 親会社の製品が土台。安定して取れる | 全メーカーから仕入れ可能。**顧客の課題に合う物を選べる** |
| 顧客側から見た価値 | 親会社品の供給は確実。ただし提案の幅が狭い | 複数メーカーの比較提案ができる。代替材の提示が速い |
| 競合の制約 | 親会社と競合するメーカーの品は扱いにくい | 制約なし。ただしどこからも「二番手」に見られうる |
| 利益の出方 | 親の販売子会社としての口銭。薄めで安定 | 目利きと在庫・与信で稼ぐ。振れるが伸びしろがある |
| 海外展開 | 親の海外拠点に相乗りしやすい | 自前で現地法人を作る必要がある＝先行投資が重い |
| M&A の自由度 | 親会社の方針に縛られる | 自己判断で買える。**自社製造・自社ブランドへ進みやすい** |

```
  【メーカー系】                         【独立系】
  親会社（化学メーカー／総合商社）        多数のメーカー
        │ 製品供給・出向・資本             ＼ ｜ ／ 横並びで仕入れ
        ▼                                   ▼
     商社子会社                          独立系商社
        │ 安定商流                         │ 目利き・在庫・与信
        ▼                                   ▼
      ユーザー                             ユーザー
   「親の製品を確実に届ける」          「最適な材料を探して持ってくる」
```

> なぜそうなるか：化学品のユーザーが本当に欲しいのは「材料」ではなく「自分の製品の性能」。
> 独立系は複数メーカーから選べるぶん、その要求に答えやすい。だから独立系が最大手になっている。

## 4. 高付加価値分野へのシフト

### 4-1. どこへ向かっているか

汎用樹脂・汎用薬品は、国内需要の減少と中国の供給過剰で、数量も価格も伸びない。
各社が資本を振り向けている先は共通している。

| 分野 | 具体的な商材 | なぜ狙うか |
| --- | --- | --- |
| **エレクトロニクス材料** | フォトレジスト、洗浄液、封止材、フォトマスク関連、電池材料 | 半導体・AI 需要で数量が伸びる。規格が厳しく参入者が限られる＝粗利が厚い |
| **ライフサイエンス／医薬** | 医薬中間体、原薬（API）、培地、バイオ関連資材 | 景気に左右されにくい。品質・トレーサビリティ要求が高く、商社機能が効く |
| **食品添加物・食品素材** | 甘味料、酵素、機能性素材 | 参入に薬機法・食品衛生法の知見が要る。長期の相対取引になる |
| **化粧品原料** | 界面活性剤、機能性原料、処方提案 | 処方に入ると外れにくい。ブランド側は少量多品種で商社依存が強い |
| **環境・循環** | ケミカルリサイクル原料、バイオマス由来樹脂、CO2由来化学品 | ブランドオーナーの要求。商流の作り直しが必要で、商社の出番が生まれる |

### 4-2. 実例で見る

- **長瀬産業**は2026年5月、新中期経営計画「**Walk the Talk 2028**」を公表。報道および同社開示によると、セグメントを**5つから3つへ再編**し、**エレクトロニクスとライフサイエンスへ資本を集中**、営業利益500億円以上・ROE 9.0%以上・時価総額1兆円の早期実現を目標に置いた。「商社・製造・研究の三機能を組み合わせた独自性（ユニークネス）」を打ち出している
- **稲畑産業**は2026年3月期に、**中国向け半導体材料と AI 関連の先端半導体向け材料の販売が大幅増**となり、情報電子セグメントが伸びた（同社決算資料）。中期経営計画「New Challenge 2026」を推進中
- **岩谷産業**は水素に投資を続けており、出資先の日本水素エネルギーが川崎重工業と**世界最大級となる4万m3型液化水素運搬船**の造船契約を締結したと公表している（2026年）

> 読み方：この3社は「商社なのに設備投資が大きい」。商社の顔をしたメーカー／インフラ事業者に寄っている。
> **口銭ビジネスから資産を持つビジネスへ**、というのが 2020 年代の化学商社の方向。

## 5. 商社がメーカーになる：M&Aと自社製造

化学商社の M&A には、はっきりした型がある。

```
  【型①】販売網を買う      同業の中堅商社／海外ディストリビューターを買収
                            → 顧客リストと代理店契約がそのまま手に入る

  【型②】製造機能を買う    調合・加工メーカーを買収し、自社銘柄を持つ
                            → 粗利率が一段上がる。ただし在庫・設備・PL責任を負う

  【型③】技術を買う        素材ベンチャー、研究開発型企業への出資
                            → 将来の商材を確保する「種まき」

  【型④】親の切り出しを受ける  メーカーがノンコア事業をカーブアウト
                            → 商社が引き取って再成長させる
```

| 型 | 得られるもの | 落とし穴 |
| --- | --- | --- |
| ① 販売網 | 即座の売上、地域カバー | 買った先の与信が緩いと焦げ付きを引き継ぐ |
| ② 製造 | 粗利率の改善、供給の安定 | 稼働率が落ちると固定費が効いて赤字に転落する |
| ③ 技術 | 将来の商材、差別化 | 事業化までの時間が長い。減損リスク |
| ④ カーブアウト | 割安で事業を取得 | 親会社が手放す理由（赤字・規制）を引き継ぐ |

化学メーカー側も同じ時期に事業の入れ替えを進めており、商社にとっては**買い場**が増えている。
たとえば2026年2月には、三菱ケミカルが子会社の合成樹脂エマルジョン事業および自社のアクリルエマルジョン事業をコニシへ譲渡することで合意し、株式譲渡契約を締結したと公表された。
グローバルでは、2026年の化学セクターの M&A は件数・金額とも前年同期を下回り、**案件を厳選する動き**が続いていると分析されている（KPMG の 2026年第1四半期レポート）。

## 6. 海外展開：アジアの「現地商流」を取る戦い

日本の化学商社の海外売上比率は大手で4〜6割に達する。ただし中身は「輸出」ではなく**現地での売買**に移っている。

```
  【昔のモデル：輸出商社】
   日本メーカー ──日本から船積み──▶ 商社の海外事務所 ──▶ 現地の日系工場
        （日本で作って、日本企業に売る）

  【今のモデル：現地商流】
   現地メーカー（中国・韓国・台湾・東南アジア）
        │ 現地で仕入れ
        ▼
   商社の現地法人（現地採用の営業・現地倉庫・現地与信）
        │ 現地通貨建て・現地物流
        ▼
   現地企業（非日系）＋ 日系工場
        （現地で仕入れて、現地企業に売る）
```

| 論点 | 意味 |
| --- | --- |
| **日系顧客の追随から現地顧客の開拓へ** | 日系工場の増設が止まったため、非日系の現地企業に食い込めるかが成長の分かれ目 |
| **現地での在庫・倉庫** | リードタイム勝負。現地に危険物倉庫を持てるかが参入の条件になる |
| **現地の与信** | 決算書の信頼性が低い国では、与信管理そのものが競争力 |
| **地政学リスク** | 中国依存の見直し、輸出管理規制（半導体材料）が商流を寸断しうる |
| **通貨と回収** | 現地通貨の変動、送金規制。為替ヘッジと回収条件の設計が利益を決める |

稲畑産業の2026年3月期の地域別売上は、日本 約3,500億円に対し、東南アジア 約2,131億円、北東アジア 約2,110億円と、
**アジア2地域の合計が日本を上回る**構成になっている（同社資料ベース）。これが日本の化学商社の典型的な姿。

## 7. 各社の戦略を読むときのチェックポイント

| 見るところ | 何が分かるか |
| --- | --- |
| セグメント別**営業利益率** | どの分野で本当に稼いでいるか。売上比率と利益比率は一致しない |
| **自社製造品・自社ブランドの売上比率** | 口銭商売からどれだけ脱却できているか |
| **海外の現地法人数と現地売上比率** | 輸出商社か、現地商流を持つ会社か |
| **のれんの残高と減損履歴** | M&A が成功しているか。連続する減損は型②③の失敗サイン |
| **在庫回転日数と売上債権回転日数** | 商売の重さ、顧客の資金繰り |
| **研究・ラボ機能の有無** | 技術提案で差別化できるか（欧米勢との競争軸） |
| 中計の**KPIが売上かROEか** | 規模を追う会社か、資本効率を追う会社か。近年は後者に移っている |

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **メーカー系商社** | 化学メーカーや総合商社を親会社に持つ販売子会社型の商社 |
| **独立系商社** | 特定の親会社を持たず、複数メーカーから自由に仕入れる商社 |
| **カーブアウト** | 企業が事業の一部を切り出して別会社化・売却すること |
| **ボルトオン買収** | 既存事業に近い小規模な会社を買い足して積み上げる M&A |
| **のれん** | 買収額が買った会社の純資産を上回った差額。将来の稼ぎへの期待分。期待が外れると減損する |
| **原薬（API）** | Active Pharmaceutical Ingredient。医薬品の有効成分そのもの |
| **ディストリビューター** | 在庫と与信を持って販売する流通業者。欧米では化学品流通の主役 |
| **現地商流** | 現地で仕入れ、現地企業に売る取引。輸出とは別の商売 |
| **ROE** | 自己資本利益率。株主の資本でどれだけ稼いだか。商社の中計で目標に置かれることが多い |
| **セグメント再編** | 開示上の事業区分を組み替えること。経営の重心がどこへ移ったかの手がかりになる |
