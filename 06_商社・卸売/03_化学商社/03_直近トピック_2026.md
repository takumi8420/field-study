# 直近トピック（2026年9月時点）

報道および各社開示をもとにした整理。数値は発表時点のもので、一次情報（決算短信・官報・省庁資料）での裏取りを前提に読むこと。

このノートで分かること：2026年の化学商社が直面している5つの変化。
一言でいえば、**仕入れ先（国内石化）が縮み、扱える物質（PFAS等）が減り、運ぶ手段（トラック）が細り、代わりに電子材料と海外が伸びている**。

---

## 1. 国内石油化学の再編が「検討」から「決断」へ（2026年）

化学商社にとって最大の環境変化は、**仕入れ先である国内石化プラントの集約**である。

- 2026年1月、三井化学・三菱ケミカル・旭化成の3社が**西日本のエチレン生産の集約**を発表。2030年度をめどに、三菱ケミカルと旭化成が水島コンビナート（岡山県倉敷市）で共同運営するプラントを停止し、三井化学の大阪の設備へ集約する方針と報じられた
- 2026年5月、同3社は共同事業体の**出資比率を三井化学45%・三菱ケミカル45%・旭化成10%**とすることを前提に統合検討を進めると公表
- 千葉では2026〜27年度にかけて4つのエチレン拠点が2つに、川崎も2つが1つに集約され、**国内のエチレン製造は8基体制へ向かう**と報じられる
- 2026年5月、三菱ケミカルグループは、石油化学を中心とする基礎化学品事業の**分社化の検討開始**を公表。2027年度中の実行を計画していると報じられた
- 三井化学・出光興産・住友化学は国内の汎用樹脂事業の統合を発表している

背景は3つ。**国内需要の減少**、**中国の大規模増設による供給過剰**、**脱炭素対応のための設備更新負担**。

```
 【これまで】各社が自前のエチレン設備を持ち、商社は複数から引けた
   三菱ケミカル ┐
   三井化学   ├──▶ 商社 ──▶ ユーザー   仕入れ先を比較・分散できた
   旭化成    ┘

 【これから】設備が集約され、供給者が減る
   統合事業体（西日本） ┐
   千葉2拠点       ├──▶ 商社 ──▶ ユーザー
   輸入（中国・中東）  ┘        ↑
                               仕入れ先の選択肢が国内で減り、
                               輸入比率と為替・海上運賃の重みが増す
```

**化学商社への影響**
- 国内汎用樹脂・基礎化学品の**取扱数量は構造的に減る**。ここに依存する中堅卸ほど打撃が大きい
- 一方で、**輸入品の手当て・保管・品質保証**という機能の価値は上がる。輸入に強い商社には追い風
- 仕入れ先の統合で価格交渉力が売り手に寄る可能性があり、**口銭の薄い汎用品はさらに薄くなる**

## 2. PFAS規制が「管理」から「製造禁止」フェーズへ（2026年）

PFAS（有機フッ素化合物。分解しにくく体内に蓄積する性質から規制が進む一群の物質）をめぐる規制が、2026年に日本でも段階を上げた。

| 時期 | 内容 | 商社の実務への影響 |
| --- | --- | --- |
| 2026年1月 | 厚労省・経産省・環境省が **PFHxS（ペルフルオロヘキサンスルホン酸）およびその関連物質**の指定に関する省令等を公表。**2026年6月施行**と報じられる | 該当品の取扱停止。顧客への代替提案が必要 |
| 2026年4月 | **PFOS・PFOA 合算で 50ng/L 以下**の水質基準が施行 | 自社倉庫・工場の排水管理、顧客の受入基準が厳格化 |
| 2026年5月 | **LC-PFCA（長鎖ペルフルオロカルボン酸）** を化審法の**第一種特定化学物質**に指定することを閣議決定。**2026年11月22日施行**と報じられる | 第一種特定＝原則として製造・輸入が禁止される最も重い区分 |

```
 化審法の規制の強さ（イメージ）
 ──────────────────────────────────────────
  一般化学物質      届出のみ                 普通に売れる
      ↓
  優先評価化学物質  数量届出・有害性調査      売れるが報告義務
      ↓
  第二種特定化学物質 製造・輸入数量の制限      許可・数量枠の管理
      ↓
  第一種特定化学物質 原則、製造・輸入の禁止  ← LC-PFCA がここへ（2026年11月施行）
 ──────────────────────────────────────────
     ※ 商社にとっては「在庫が一夜にして売れない資産になる」区分の境目
```

**なぜ商社が最前線に立つのか**
- ユーザーは自社の製品に**どの原料のどこにPFASが入っているか**を把握しきれていない。最終製品メーカーが取引先にデータ開示を求めるため、間に立つ商社がサプライチェーン全体の情報をかき集める役になる
- EU や米国に輸出していない企業でも、**取引先の先が欧米企業なら対応を迫られる**
- 代替材（PFASフリー樹脂・フッ素フリー撥水剤など）の探索と評価サンプルの手配は、**まさに商社の目利き機能**が問われる仕事

> ポイント：規制強化は商社にとって「商材が消えるリスク」であると同時に、
> **代替材を提案できる会社にとっては顧客を奪う好機**でもある。ここが機能化学品に強い商社の差別化点になっている。

## 3. 物流制約と業界共同の取り組み（2025〜2026年）

- 2024年4月から適用されたドライバーの時間外労働上限規制（**物流の2024年問題**）の影響が定着し、危険物輸送では特に深刻。危険物取扱者を持つドライバーの母集団が小さいため、代替が効きにくい
- **改正物流関連法が2025年4月に施行**。荷主にも物流効率化の努力義務が課される
- **中小受託取引適正化法が2026年1月に施行**（旧・下請法の改正）。運賃・附帯作業の押し付けが規制対象になる
- 2026年4月、経産省・国交省の「**フィジカルインターネット実現会議・化学品ワーキンググループ**」が、**トラック附帯作業の適正化**と**タンクローリー荷役作業の安全向上**に向けた取り組みを推進すると公表。**パレチゼーション**（パレット積みへの転換）のガイドライン作成に着手したとされる

```
 化学品物流の「詰まり」がどこで起きているか
 ────────────────────────────────────────────────
  メーカー出荷 ──▶ 幹線輸送 ──▶ 商社倉庫 ──▶ 配送 ──▶ ユーザー受入
        │              │             │           │           │
    ①荷待ち         ②長距離が       ③危険物倉庫  ④小口多頻度  ⑤荷降ろし
     時間が長い       日帰り不可に    の容量制約    でコスト増    の附帯作業
        │              │
        └──── 2024年問題で①②が悪化 ───┘
  → 業界横断でパレット規格を揃え、荷役を機械化する（フィジカルインターネット）方向
 ────────────────────────────────────────────────
```

**化学商社への影響**：物流費の上昇を口銭に転嫁できるかが利益を左右する。
同時に、**自前の危険物倉庫と配送網を持つ商社の相対的な価値が上がる**。持たない卸は運べなくなる。

## 4. 大手商社の戦略転換：エレクトロニクスとライフサイエンスへ（2026年）

| 企業 | 2026年の動き | 数値（2026年3月期） |
| --- | --- | --- |
| **長瀬産業** | 2026年5月7日、中期経営計画「**Walk the Talk 2028**」を公表（5月12日に一部訂正）。セグメントを**5から3へ再編**し、エレクトロニクスとライフサイエンスに資本を集中。**営業利益500億円以上・ROE 9.0%以上**、時価総額1兆円の早期実現を目標に掲げる | 売上高 9,728億円、経常利益 440億円（前期比+14.9%）。2027年3月期の経常利益予想は450億円（+2.1%） |
| **稲畑産業** | 中期経営計画「New Challenge 2026」を推進。**中国向け半導体材料と AI 関連の先端半導体向け材料**の販売が大幅増。フォトマスク関連も半導体・FPD 両方で増加 | 売上高 8,327億円（前期比▲0.6%）、営業利益 262億円、純利益 206億円。セグメント別は合成樹脂4,080億円／情報電子2,393億円／化学品1,251億円／生活産業601億円 |
| **岩谷産業** | 水素・資源安全保障への投資を加速。出資先の日本水素エネルギーが川崎重工業と**世界最大となる4万m3型液化水素運搬船**の造船契約を締結。一方で LPガス市況とヘリウム市況の軟化が営業減益要因 | 売上高 9,085億円（+2.9%）、営業利益 383億円（▲17.1%）、経常利益 552億円、純利益 477億円（+17.8%、固定資産売却益を含む）。2027年3月期は売上高9,600億円・営業利益488億円を見込む |

読み取れる共通点：
1. **汎用品の数量ではなく、電子材料・ライフサイエンスの利益率で稼ぐ**方向に全社が向かっている
2. 目標が**売上高ではなく ROE・営業利益・時価総額**に置かれている（資本効率重視）
3. 商社でありながら**製造・研究・インフラ資産**を持つ方向（長瀬の「商社・製造・研究」、岩谷の水素インフラ）

## 5. M&A環境：案件は厳選され、メーカーの切り出しが増える（2026年）

- KPMG の2026年第1四半期レポートによると、グローバルの化学セクターの M&A は**件数が前年同期比▲2%、金額が約▲31%**。市場の不透明さと地政学リスクから、投資意欲は維持しつつ**案件を厳選する動き**が続いているとされる
- 企業側はポートフォリオ最適化のため、**カーブアウト（事業切り出し）とボルトオン買収（小規模な積み増し）**に注力している
- 具体例：2026年2月、三菱ケミカルが子会社ジャパンコーティングレジンの合成樹脂エマルジョン事業および自社のアクリルエマルジョン事業を**コニシへ譲渡**することで合意し、株式譲渡契約を締結したと公表

```
  メーカーが手放す ──▶ 誰が受け止めるか
  ─────────────────────────────────
   化学メーカー
    「ノンコアだから売る」
         │
         ├─▶ 同業メーカー（コニシの例）……事業の強化
         ├─▶ 投資ファンド……再構築して転売
         └─▶ 化学商社……販売網＋製造機能を一度に取得
                            （型②：メーカー機能の内製化）
  ─────────────────────────────────
   商社にとっては「買い場」が増えている局面。
   ただし M&A 市場全体は金額ベースで縮小しており、高値掴みは減っている。
```

国内では、中堅・地場の化学品卸の**後継者難と規制対応コスト**も再編要因になっている。
毒劇物の販売業登録、危険物倉庫の維持、SDS・PFAS対応といったコンプライアンス負担が固定費として重く、
規模のない事業者が単独で持ちこたえにくくなっている。

## 6. 全体の構図（まとめ）

```
   縮む側                              伸びる側
  ─────────────────────────────────────
   国内の汎用樹脂・基礎化学品          電子材料・電池材料（AI／半導体）
   （石化再編で供給者も需要も減る）     ライフサイエンス・食品・化粧品原料
                                        アジアの現地商流
   規制で消える商材（PFAS等）          代替材の提案・規制対応の代行
   運べない物流                        危険物倉庫・自社配送網を持つ商社
   口銭だけの商売                      自社製造・自社ブランド（粗利率が違う）
  ─────────────────────────────────────
        ↓                                    ↓
   規模のない地場卸は再編へ           大手は「商社＋メーカー」へ寄っていく
```

3〜5行でまとめると：
1. **仕入れ側**（国内石化）が集約に向かい、汎用品の商売は構造的に縮む
2. **規制側**（PFAS・化審法）と**物流側**（2024年問題）の負担が増え、対応できる規模の商社に商流が集まる
3. 各社の資本は**エレクトロニクスとライフサイエンス**、そして**アジアの現地商流**へ移動している
4. 口銭商売から抜け出すため、**M&A で製造機能を取り込む**流れが続く。メーカーのカーブアウトがその供給源になっている

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **エチレン設備（ナフサクラッカー）** | 石油由来のナフサを分解してエチレン等の基礎原料を作る装置。石化コンビナートの心臓部 |
| **コンビナート** | 原料・用役（電気・蒸気）をパイプでつないだ化学工場群 |
| **PFAS** | 有機フッ素化合物の総称。分解しにくく蓄積するため各国で規制が進む |
| **PFHxS／PFOS／PFOA／LC-PFCA** | いずれも PFAS に含まれる個別物質群。規制対象として順次指定されている |
| **第一種特定化学物質** | 化審法で最も重い区分。原則として製造・輸入が禁止される |
| **カーブアウト** | 企業が事業の一部を切り出して売却・別会社化すること |
| **ボルトオン買収** | 既存事業に隣接する小規模企業を買い足していく M&A |
| **パレチゼーション** | 手荷役をやめ、パレット単位の荷役に統一すること |
| **フィジカルインターネット** | 物流資源を業界横断で共有し積載効率を高める構想。経産省・国交省が推進 |
| **中小受託取引適正化法** | 2026年1月施行。委託側による不当な条件押し付けを規制する（旧・下請法の改正） |
| **液化水素運搬船** | 水素を ▲253℃ で液化して海上輸送する船。日本が先行して実証している |
