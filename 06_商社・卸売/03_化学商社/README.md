## このフォルダの読み方

化学商社は **「数万点の化学品を、法令どおりに保管・小分け・輸送し、代金を立て替えて中小ユーザーに届ける会社」**。
扱う品目の多くが危険物・毒劇物であるため、**物流設備と法規制対応そのものが参入障壁**になっている。
「モノを右から左に流すだけ」の卸が消えていくなかで、この業態が残っているのはそのためである。

## 1. 業界の定義・範囲

**化学商社** ＝ 化学メーカーが作った化学品（合成樹脂、溶剤、酸・アルカリ、添加剤、電子材料、医薬中間体など）を仕入れ、
**在庫・小分け・調合・与信・物流**を引き受けて、工場や研究所に販売する専門商社。
日本標準産業分類では「化学製品卸売業」にあたる。

境界の引き方は3つ。

```
              商材の性質 →  汎用・市況品           機能・特殊品
              ┌─────────────────┬─────────────────┐
  メーカー    │ 化学メーカーの        │ 化学メーカーの        │
  （作る）    │ 直販部門              │ 開発営業              │
              ├─────────────────┼─────────────────┤
  商社        │ ★化学商社（汎用系）★ │ ★化学商社（機能系）★ │
  （流す）    │ 樹脂・溶剤・基礎薬品  │ 電子材料・医薬原料    │
              │ 薄い口銭×大量         │ 厚い粗利×技術提案     │
              ├─────────────────┼─────────────────┤
  地場卸      │ 薬品店・資材店        │ （扱いきれない）      │
  （届ける）  │ 1缶単位の御用聞き     │                       │
              └─────────────────┴─────────────────┘
```

- **[総合商社](../01_総合商社/README.md) との違い** ＝ 事業投資で稼ぐ層を持たない。利益の源泉は商流（口銭）と、近年は自社製造
- **化学メーカーとの違い** ＝ 原則として自ら重合・合成はしない。ただし大手は調合・加工・自社ブランドを持ち、境界は曖昧になっている
- **[エレクトロニクス商社](../05_エレクトロニクス商社/README.md) との違い** ＝ 出発点が化学品か電子部品か。電子材料の領域では正面から競合する

## 2. 市場規模と成長性

| 指標 | 数値 | 時点・出典 |
| --- | --- | --- |
| 化学製品卸売業の販売額（国内） | 約 **26兆3,900億円**（前年比▲0.5%） | 2023年、経産省 商業動態統計 |
| 同 月間販売額 | 約 **2兆9,900億円**（前年同月比+7.9%） | 2026年7月、経産省 商業動態統計 |
| 世界の化学品ディストリビューション市場 | 約 **2,821億米ドル** | 2025年、調査会社の推計。2026〜2033年に年率8.5%成長との予測 |
| 国内最大手の売上高 | 長瀬産業 **9,728億円** | 2026年3月期、決算 |
| 上場化学商社の中堅規模 | 三谷産業 1,175億円、ソーダニッカ 667億円 | 2026年3月期 |

成長性の見方：
- **国内の汎用品は縮小**。人口減と国内石化の集約（→ [③](03_直近トピック_2026.md)）で数量が伸びない
- **成長はアジアの現地商流と、電子材料・ライフサイエンス**にある。大手の海外売上比率は4〜6割
- 市況品の比率が高い会社は、**ナフサ価格や為替で売上が上下する**。数量が伸びていなくても売上が増えて見える点に注意

## 3. バリューチェーン（川上 → 川下）

```
 原油・ナフサ ─▶ 石化メーカー ─▶ 誘導品メーカー ─▶【化学商社】─▶ 加工・配合 ─▶ 最終製品
   資源           エチレン等      樹脂・薬品・添加剤   在庫/小分け/    塗料・部品     自動車
   （輸入）       基礎原料        機能材料            調合/与信/物流  化粧品・食品   電機・半導体
                                  ＋海外メーカーから輸入 ↑                            日用品

  付加価値が集まるのは：
   (a) 誘導品・機能材料のメーカー（技術で値決めできる）
   (b) 商社の「在庫・小分け・調合」機能（手間賃が取れる）
   (c) 商社の自社ブランド・自社製造（メーカーの利益がそのまま入る）
  薄いのは：
   (d) 汎用樹脂・基礎薬品の単純な仲介（口銭数％以下）
```

詳しくは [① 化学品流通の仕組み](01_化学品流通の仕組み.md)。

## 5. 収益モデル・コスト構造

```
 営業利益 ＝ ① 口銭（仕入値と売値の差）
           ＋ ② 在庫・小分け・調合の手間賃
           ＋ ③ 自社製造品・自社ブランドの製造マージン
           ＋ ④ 為替差益（輸入品）
           －   販管費（人件費、倉庫費、物流費）
           －   貸倒引当（与信の失敗）
           ±   市況変動（在庫の評価）
```

| 論点 | 中身 |
| --- | --- |
| 粗利率 | 汎用品中心なら 5〜8%、機能品比率が高いと 10〜20%。**ここが会社の性格を示す最大の指標** |
| 営業利益率 | 2〜5% が標準。7% を超える会社は機能品・自社製造が効いている |
| コストの主役 | 人件費、倉庫費（危険物倉庫は固定費）、物流費。近年は物流費の上昇が利益を圧迫 |
| バランスシート | 資産の大半が**売掛金と在庫**。実質的に短期のファイナンス業でもある |
| 振れ幅の原因 | 市況（ナフサ・海外相場）、為替、半導体の設備投資サイクル |
| 近年の目標指標 | 売上高ではなく **ROE・営業利益・時価総額**。長瀬は ROE 9.0% 以上を掲げる（2026年中計） |

## 6. 競争要因（KSF）と参入障壁

**KSF（成功の鍵）**

1. **法規制対応の体制**。毒劇物販売業登録、危険物倉庫、有資格者、SDS・PFAS対応を回せること
2. **在庫と物流の設計**。どこに何を置き、どの荷姿で出すか。ここが手間賃の源泉
3. **与信管理**。中小ユーザーへの掛け売りで焦げ付かせないこと
4. **機能化学品の目利きと技術提案**。顧客の処方に入り込めるか（スペック・イン）
5. **仕入れ先の多様性**。特定メーカー依存だと代替提案ができず、代理店契約解消のリスクも負う
6. **海外の現地商流**。現地仕入れ・現地販売・現地与信を回せるか

**参入障壁**

| 障壁 | 強さ | 理由 |
| --- | --- | --- |
| 商品知識・営業力 | 弱 | 学べる。人の移動で持ち出される |
| **法令上の許認可** | 強 | 毒劇物販売業登録、危険物施設の設置許可、有資格者配置。拠点ごとに必要 |
| **危険物倉庫・調合設備** | 強 | 立地規制と近隣同意があり、新設が難しい。既存設備そのものが資産 |
| **代理店契約** | 強 | 主要メーカーの代理店枠は埋まっている。後から同じ商材を扱えない |
| **与信の体力** | 中〜強 | 数千社への掛け売りを支える運転資金と保険の枠 |
| 顧客の処方への組み込み | 強 | いったんスペック・インされると、代替には再評価と再申請が要る |

## 7. 規制・法制度

| 法令 | 化学商社にかかる義務 |
| --- | --- |
| **毒物及び劇物取締法** | 販売業の登録（店舗ごと）、毒物劇物取扱責任者の設置、譲渡手続書の5年保存 |
| **消防法** | 危険物の貯蔵・取扱施設の設置許可、危険物取扱者の配置、容量上限の管理 |
| **化審法** | 新規化学物質の届出、第一種／第二種特定化学物質の取扱制限。2026年は PFHxS・LC-PFCA の指定が進む |
| **労働安全衛生法** | SDS 交付、ラベル表示、リスクアセスメントの実施・支援 |
| **高圧ガス保安法** | 水素・酸素・LPガス等の販売事業届出、容器管理、保安統括者の選任 |
| **薬機法・食品衛生法** | 医薬品原薬・食品添加物を扱う場合の許可と規格適合確認 |
| **改正物流関連法（2025年4月施行）** | 荷主としての物流効率化の努力義務 |
| **中小受託取引適正化法（2026年1月施行）** | 運賃・附帯作業の押し付けの規制 |
| **海外規制（EU REACH、米 TSCA 等）** | 顧客が海外に輸出する場合、成分情報の開示要求に応じる必要がある |

> ポイント：これらは「守るべきルール」であると同時に、**守れる体制を持つことが競争優位そのもの**。
> 規制が厳しくなるほど、対応コストを負担できない中小卸が退出し、大手に商流が集まる。

## 8. 最近のトピック

→ [③ 直近トピック（2026年9月時点）](03_直近トピック_2026.md)

1. **国内石油化学の再編**：西日本のエチレン設備統合（三井45%・三菱ケミカル45%・旭化成10%で検討、2026年5月公表）、千葉・川崎の集約で**国内8基体制**へ。仕入れ先が減る
2. **PFAS規制が製造禁止フェーズへ**：PFHxS 関連が2026年6月施行、LC-PFCA が化審法第一種特定化学物質として2026年11月22日施行と報じられる。**扱える商材が減り、代替提案の力が問われる**
3. **物流制約**：2024年問題の定着に加え、改正物流関連法（2025年4月）・中小受託取引適正化法（2026年1月）。フィジカルインターネット化学品WGがパレチゼーションのガイドライン作成に着手（2026年4月）
4. **大手の資本集中**：長瀬産業が中計「Walk the Talk 2028」でセグメントを5→3に再編しエレクトロニクス・ライフサイエンスへ集中（2026年5月）。稲畑産業は AI 向け先端半導体材料が大幅増
5. **M&A環境**：2026年第1四半期のグローバル化学M&Aは件数▲2%・金額▲31%と縮小する一方、メーカーのカーブアウトが続き、商社にとっての買い場は残っている
