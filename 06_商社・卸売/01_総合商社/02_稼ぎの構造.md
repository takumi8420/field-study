# ② 稼ぎの構造

このノートで分かること：総合商社の利益が **資源と非資源という二本の足**でどう構成されているか、
「持分法投資利益」という商社決算の主役が何を意味するか、投資の入口と出口でどう稼ぐか、
そして5大商社の個性がどこで分かれるか。

## 1. 結論：利益の作り方は3通りしかない

```
【商社の利益エンジン】

 ┌── A. 商流（フロー） ──────────────────┐
 │  毎期のトレーディング損益。口銭。                  │
 │  特徴：金額は小さいが安定。資本をあまり食わない     │
 └────────────────────────────┘
 ┌── B. 保有（ストック） ─────────────────┐
 │  出資先からの配当 ＋ 連結子会社の利益              │
 │           ＋ 持分法による投資損益                  │
 │  特徴：利益の大半。資本を大量に食う                │
 └────────────────────────────┘
 ┌── C. 売却（イベント） ─────────────────┐
 │  持分を売った時の売却益（EXIT益）                  │
 │  特徴：数年に一度、数百〜数千億円が一気に出る       │
 │        「今期の好決算は一時益では？」と疑われる元凶 │
 └────────────────────────────┘
```

決算を読むときは、**Bが着実に伸びているか**と、**Cがどれだけ混ざっているか**を分けて見る。
2026年3月期の三菱商事が15.8%の減益になったのは、前期に **ローソンの再評価益と原料炭事業の売却益**という
大型のCが乗っていた反動、というのが会社説明である（2026年3月期決算短信および報道ベース）。

## 2. 資源と非資源という分け方

商社の決算を語るとき必ず出てくる区分。**利益の振れ方がまったく違うので分けて見る**。

| 区分 | 中身 | 利益の性格 | 何で決まるか |
| --- | --- | --- | --- |
| **資源** | 鉄鉱石、原料炭、銅、原油・ガス、LNG | 振れ幅が極端に大きい。良い年と悪い年で倍半分 | 市況（価格）。自分ではコントロールできない |
| **非資源** | 食料・生活消費、機械、自動車、電力・インフラ、金融・リース、不動産、化学品 | 比較的安定。ただし伸びも緩やか | 積み上げた事業の数と質。自分でコントロールできる |

```
【資源比率の違いが業績の振れ方を決める（イメージ）】

 純利益
   ▲
   │        ╱╲              資源比率が高い会社（三井物産・三菱商事）
   │      ╱    ╲            ＝ 山も谷も深い
   │    ╱        ╲    ╱
   │  ╱            ╲╱
   │─────────────────────────
   │  ＿＿＿─────＿＿＿─────      資源比率が低い会社（伊藤忠）
   │                                  ＝ なだらかに右肩上がり
   └──────────────────────────▶ 年
       資源価格 高          資源価格 低
```

2026年3月期は、鉄鉱石・原料炭の価格が下落局面に入った年だった。
その結果、**資源色の濃い三井物産・三菱商事が減益、非資源に厚い伊藤忠・住友商事・丸紅が最高益**という
きれいな明暗が出た（各社決算短信・報道ベース）。

> 注意：「非資源のほうが優れている」という話ではない。
> 資源は **上がった年の爆発力**が大きく、過去10年の商社の巨額利益はほぼ資源が作った。
> 問題は振れ幅であり、各社は「どの比率で持つか」を経営判断している。

## 3. 持分法投資利益＝「子会社の利益の取り込み」

商社決算で最重要かつ最も誤解されやすい項目。

### 3-1. 出資比率で会計処理が変わる

| 出資比率（目安） | 呼び方 | 会計処理 | 損益計算書での見え方 |
| --- | --- | --- | --- |
| おおむね50%超 | **連結子会社** | 全部連結 | 売上も費用も全部合算し、他人の持分を「非支配持分」として差し引く |
| おおむね20〜50% | **持分法適用関連会社** | 持分法 | **純利益 × 持分比率 を1行だけ**取り込む。売上は取り込まない |
| 20%未満 | 単なる投資 | 時価評価 | 配当を受け取ったときだけ収益。評価差額は資本に直入するのが基本 |

```
【持分法のしくみ】

 出資先A社（商社が30%保有）
   売上 1,000億円
   純利益  100億円
        │
        │ × 30%
        ▼
 商社の損益計算書
   ┌──────────────────────┐
   │ 収益（売上）        ……… 0円      │ ← 売上は一切入らない
   │ 持分法による投資損益 … 30億円      │ ← ここに1行だけ
   └──────────────────────┘

   → 「売上は小さいのに利益は大きい」構造の正体がこれ
```

### 3-2. なぜ商社にとって重要なのか

- 資源権益や海外インフラは **合弁（ジョイントベンチャー）が基本**。100%持つことはまずない
- 20〜50%という中途半端な比率でも、**利益はきちんと取り込める**
- 逆に言えば、持分法利益は **現金が入ってきているとは限らない**。配当されなければ社内に留保されたままになる
- だから各社は「基礎営業キャッシュ・フロー」を併記して、**利益と現金のギャップ**を説明する

三菱商事が2024年にローソンをKDDIとの共同経営（各50%）に移行したとき、
**連結子会社から持分法適用会社へ変わった**ことで再評価益が発生した。
これは持分法の会計処理を理解していないと読めない出来事である。
→ [コンビニエンスストア](../../07_小売・流通/01_コンビニエンスストア/README.md)、[③ 事業投資の実際](03_事業投資の実際.md)

## 4. 投資の入口と出口

商社の投資は「買って持つ」だけではない。**回転させて初めて利益率が上がる**。

```
【投資のライフサイクル】

 ①オリジネーション ──▶ ②デューデリジェンス ──▶ ③投資委員会 ──▶ ④実行
   案件発掘             調査（財務・法務・        社内審査        出資
   商流から情報が         環境・現地リスク）      ハードルレート
   降ってくる                                     との比較
        │                                                        │
        │                                                        ▼
        │                                          ⑤バリューアップ（数年〜十数年）
        │                                            役員派遣・KPI設定・
        │                                            調達改善・商流の接続
        │                                                        │
        └──────── 再投資 ◀──── ⑥EXIT（売却）または保有継続 ◀┘
                                     売却益 or 配当を取り続ける
```

| 局面 | 商社ならではの点 |
| --- | --- |
| **①案件発掘** | 商流を持っているので「売りたい人」が先に相談に来る。これが最大の参入障壁 |
| **③投資判断** | **ハードルレート**（最低限クリアすべき利回り。資本コスト＋リスクプレミアム）を国・業種別に設定。IRR（内部収益率）と回収年数で判断 |
| **⑤バリューアップ** | 役員を送り、グループの商流・調達・与信をつなぐ。ファンドが真似しにくい部分 |
| **⑥EXIT** | 売却益は一時的だが、**資本を回収して次に回せる**点が本質。低採算資産の入替は各社の中期経営計画の柱 |

住友商事の「中期経営計画2026」は、**事業別のROICとWACCを比較して低採算資産を入れ替える**方針を明示している。
これは「持ち続ければよい」という従来の発想からの転換である。

## 5. ROIC・ROEと株主還元

### 5-1. 指標の意味

| 指標 | 計算 | 読み方 |
| --- | --- | --- |
| **ROE**（自己資本利益率） | 純利益 ÷ 自己資本 | 株主のカネをどれだけ増やしたか。商社は近年10〜15%台 |
| **ROIC**（投下資本利益率） | 税引後営業利益 ÷（有利子負債＋自己資本） | **事業ごとに測れる**のが利点。どの事業が資本を無駄に食っているかが見える |
| **WACC**（加重平均資本コスト） | 負債コストと株主資本コストの加重平均 | 「最低これだけは稼がないと価値を壊す」ライン |
| **総還元性向** | （配当＋自社株買い）÷ 純利益 | 商社は近年これを高めて株価を支えている |

> ポイント：**ROIC < WACC の事業は、黒字でも価値を壊している**。
> 商社が「黒字なのに売る」のはこのためで、外から見ると不可解に映るが理屈は単純である。

### 5-2. 株主還元の実際（2026年時点、報道・各社開示ベース）

| 会社 | 還元の動き |
| --- | --- |
| **三菱商事** | 上限1兆円の自社株買いを2025年4月に決議し、2026年3月に完了・全株消却。配当は2025年度110円→2026年度125円の計画 |
| **伊藤忠商事** | 3,000億円超の自社株買いを実施と報じられる |
| **三井物産** | 2,000億円規模の自社株買いと報じられる |
| **住友商事** | 2026年5月1日に800億円を上限とする自己株式取得を決定（取得期間2026年5月7日〜2027年3月31日） |
| **丸紅** | 2027年3月期の年間配当を115円とする予想 |

背景には東京証券取引所の「資本コストや株価を意識した経営」の要請（2023年〜）がある。
**累進配当**（減配せず、維持か増配を続ける方針）を掲げる会社が増えたことも、商社株の性格を変えた。
→ [④ これからの論点](04_これからの論点.md) 第2章（バフェット投資）

## 6. 5大商社の個性の違い

同じ「総合商社」でも、出自と主戦場が違う。ここが分かると各社の決算の癖が読める。

| 会社 | 出自 | 利益の柱 | キャラクター |
| --- | --- | --- | --- |
| **三菱商事** | 三菱財閥の商事部門（1918年） | 原料炭・銅・LNG、[ローソン](../../07_小売・流通/01_コンビニエンスストア/README.md)、自動車（いすゞ）、電力 | 規模最大・総資産24兆円級（2026年3月期末）。「組織の三菱」。大型案件を長期で持つ |
| **三井物産** | 三井財閥（1876年、日本初の総合商社） | 鉄鉱石、原油・ガス、機械・インフラ、ヘルスケア | 最も資源色が濃い。「人の三井」。個の裁量が大きいと言われる |
| **伊藤忠商事** | 近江商人・繊維（1858年創業） | 生活消費（ファミリーマート）、食料、繊維、機械、金融 | 非財閥系。非資源が利益の中心。「三方よし」と現場主義。2026年3月期に純利益首位 |
| **住友商事** | 住友財閥（戦後に総合商社化） | メディア（JCOM）、不動産、リース、北米鋼管、インフラ | 「住友の事業精神」＝浮利を追わず。巨額減損の経験から撤退規律が厚い |
| **丸紅** | 伊藤忠から分立した繊維系 | 海外電力（IPP）、農業資材、アグリ、金属、インフラ | 電力の持分発電容量は世界有数。農業バリューチェーンに強い |

```
【資源／非資源のバランス感（定性的なイメージ。年により変動）】

 資源寄り                                              非資源寄り
   │                                                        │
   ├─ 三井物産 ──┬─ 三菱商事 ──┬─ 丸紅 ─┬─ 住友商事 ─┬─ 伊藤忠
   │              │                │          │              │
   鉄鉱石・原油    原料炭・銅・LNG   電力・農業  メディア・不動産  コンビニ・食料
                   ＋ローソン                    ・リース

   ※ 各社の開示区分が異なるため厳密な比率比較はできない。
     正確には各社の決算説明資料のセグメント別利益を参照すること。
```

## 7. セグメントの読み方（つまずきやすい点）

- **各社でセグメント区分がバラバラ**。三菱商事は2026年3月期に「地球環境エネルギー」「マテリアルソリューション」
  「電力ソリューション」「社会インフラ」などの区分で開示しており、他社と単純比較できない
- **「資源／非資源」は各社が任意に定義している**。同じ事業が会社によって分類が違うことがある
- **一時的な益・損（EXIT益、減損）が特定セグメントに集中する**ので、単年で判断しない
- したがって実務では **3〜5年の推移**と、**基礎営業キャッシュ・フローの推移**を併せて見る

## 8. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **連結子会社** | 議決権おおむね50%超で支配している会社。売上・費用をすべて合算して連結する |
| **持分法適用関連会社** | 議決権おおむね20〜50%で重要な影響力を持つ会社。純利益×持分比率だけを1行で取り込む |
| **持分法による投資損益** | 上記の取り込み額。商社の利益の中核。現金が入っているとは限らない点に注意 |
| **非支配持分** | 連結子会社のうち、自社以外の株主に帰属する利益部分。純利益から差し引かれる |
| **EXIT益（投資有価証券売却益）** | 持分を売却したときの売却益。一時的だが資本回転の証拠でもある |
| **オリジネーション** | 案件発掘。商社の場合は商流から自然に情報が入る構造そのものを指す |
| **デューデリジェンス（DD）** | 投資前の精査。財務・法務・税務・環境・現地リスクを調べる |
| **ハードルレート** | 投資を承認する最低利回り。資本コストにリスクプレミアムを上乗せして国・業種別に設定する |
| **IRR（内部収益率）** | 投資の年率換算リターン。回収年数とセットで判断する |
| **ROIC** | 投下資本利益率。事業ごとに測れるので、低採算事業のあぶり出しに使う |
| **WACC** | 加重平均資本コスト。ROICがこれを下回る事業は黒字でも価値を毀損している |
| **累進配当** | 減配せず、維持または増配を続けるという配当方針 |
| **総還元性向** | （配当＋自社株買い）÷ 純利益。株主還元の総量を測る |
