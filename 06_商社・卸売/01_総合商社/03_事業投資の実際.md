# ③ 事業投資の実際

このノートで分かること：総合商社が実際に **何に、どのくらいの規模で投資しているのか**。
資源権益の中身、コンビニや食料といった生活産業の持ち分、投資判断の基準、
そして **減損という「失敗の記録」** と、「経営人材の派遣業」という見えにくい側面。

## 1. 結論：商社の資産は「権益」と「事業会社の株」でできている

商社のバランスシートを開くと、工場や設備はほとんどない。代わりに並んでいるのは
**鉱区の権益、発電所の持分、事業会社の株式**である。

```
【総合商社の資産の中身（概念図。会社により構成は大きく異なる）】

 ┌─────────────────────────────────┐
 │ 資源・エネルギー権益                                      │
 │  LNGプロジェクト持分 / 鉄鉱石鉱山 / 銅鉱山 / 原料炭 / 油ガス田 │
 │  → 20〜50年の超長期。合弁が基本。持分法で利益を取り込む      │
 ├─────────────────────────────────┤
 │ インフラ・電力                                            │
 │  海外IPP（独立系発電）/ 送配電 / 上下水道 / 空港 / 鉄道      │
 │  → 20年前後の売電契約（PPA）で収益が固定されやすい          │
 ├─────────────────────────────────┤
 │ 生活産業・消費                                            │
 │  コンビニ / 食品卸 / 食品メーカー / 青果・水産 / 衣料        │
 │  → 国内内需。安定だが成長は緩やか                          │
 ├─────────────────────────────────┤
 │ 機械・モビリティ・金融                                    │
 │  自動車ディーラー（新興国）/ 建機レンタル / 航空機リース /    │
 │  船舶 / 不動産 / リース・ファイナンス                        │
 ├─────────────────────────────────┤
 │ 営業債権・在庫（＝商流を回すための運転資本）                │
 └─────────────────────────────────┘
```

## 2. 資源権益：LNG・鉄鉱石・銅

### 2-1. 商社は「掘る人」ではなく「持分を持つ人」

資源メジャー（BHP、リオ・ティント、シェブロンなど）が実際の操業（オペレーター）を担い、
**商社は10〜30%程度の持分を出して、生産量と利益の一部を受け取る**のが典型的な形。
これを **権益（持分）** と呼ぶ。→ [資源開発](../../11_資源・エネルギー・鉄鋼金属/02_資源開発/README.md)

| 資源 | 商社の関わり方 | 収益の性格 |
| --- | --- | --- |
| **LNG** | プロジェクトに出資し、長期契約で日本・アジアの電力・ガス会社へ売る。三井物産は取扱量1,000万トン規模と報じられる | **最も安定**。20年超の長期契約で価格が原油連動などに固定される → [LNG](../../11_資源・エネルギー・鉄鋼金属/03_LNG/README.md) |
| **鉄鉱石** | 豪州の鉱山に権益。三井物産が代表格 | 中国の鉄鋼生産に強く連動。振れ幅が大きい → [鉄鋼](../../11_資源・エネルギー・鉄鋼金属/09_鉄鋼/README.md) |
| **原料炭** | 製鉄用の石炭。三菱商事が豪州で大きな持分 | 価格変動が激しい。脱炭素の逆風もある |
| **銅** | チリ・ペルーなどの鉱山。三菱商事・三井物産・住友商事 | 電化・EV・送電網で需要が構造的に増える見通し → [非鉄金属](../../11_資源・エネルギー・鉄鋼金属/10_非鉄金属/README.md) |
| **原油・ガス** | 生産物分与契約（PSC）などで参画 | 価格変動と地政学リスクが直撃 |

### 2-2. 大型案件は「1件で数千億円」

2026年時点で報じられている動きの例。

- **三井物産**：豪州 **ローズリッジ鉄鉱石事業の権益40%を約8,000億円**で取得する計画。2030年までに生産開始の見通しと報じられる
- **三菱商事**：米国 **シェールガス事業に約8,000億円**規模で参画と報じられる
- **三井物産**：モザンビーク **Area1 LNG** に約20%の権益。治安問題で長期停止中で、再開は2027年以降との市場の見方

> ポイント：**1件で純利益の1年分に近い金額を張る**。だから投資委員会の規律が会社の命運を決める。

## 4. コンビニ＝小売を持つということ

総合商社を分かりにくくしている代表例が **コンビニの持ち分**である。
→ 詳細は [コンビニエンスストア](../../07_小売・流通/01_コンビニエンスストア/README.md)

| チェーン | 商社との関係 | 経緯 |
| --- | --- | --- |
| **ローソン** | 三菱商事とKDDIが共同経営（各50%） | 三菱商事が2017年に連結子会社化。2024年にKDDIとの共同経営へ移行し、**持分法適用会社に変更**。このとき再評価益が発生 |
| **ファミリーマート** | 伊藤忠商事の傘下 | 2020年のTOBで上場廃止。伊藤忠の連結子会社 |
| **セブン-イレブン** | 商社の支配下にない | セブン&アイ・ホールディングス傘下。商社との資本関係は薄い |

なぜ商社がコンビニを持つのか。理由は3つ。

```
【商社にとってのコンビニの意味】

 ①「川下の出口」を押さえる
    商社が握る食料・日用品の商流 ──▶ コンビニの棚
    → 上流（原料）から下流（店舗）までを自分のグループ内でつなげる

 ②「内需の安定収益」
    資源で振れる利益を、国内の安定収益で打ち消す（ヘッジ）

 ③「データと接点」
    日次の購買データ。金融・決済・広告への展開の土台
```

ただし、**コンビニは国内市場が成熟しており、成長ドライバーとしては期待しにくい**。
商社にとっては「伸ばす事業」ではなく「振れを抑える錨（いかり）」に近い位置づけである。

## 5. 投資判断の基準と、減損という失敗の記録

### 5-1. 投資判断の実務

| ステップ | 見るもの |
| --- | --- |
| 事業性 | 需要見通し、コストカーブ上の位置（その鉱山は安く掘れるか）、競合 |
| 財務 | IRR（内部収益率）、回収年数、**ハードルレート**（国・業種別に設定した最低利回り）との比較 |
| リスク | カントリーリスク、為替、資源価格の前提、パートナーの信用、操業者の実力 |
| 撤退 | **最初に「どうなったら売るか」を決める**。これを決めない案件が後で塩漬けになる |
| ESG | 環境影響評価、人権デューデリジェンス、Scope3排出の扱い |

### 5-2. 減損とは何か

**減損（インペアメント）** ＝ 投資した事業の将来キャッシュフローが当初見込みを下回ったとき、
**帳簿価額を回収可能額まで一気に切り下げて、差額を損失として計上する**こと（IAS第36号）。

```
【減損の考え方】

 投資時の簿価  1,000億円
     │
     │  資源価格が想定の半分に。将来CFの現在価値が 400億円に
     ▼
 回収可能額     400億円
 ───────────────────
 減損損失       600億円 ← この期の損益に一気に計上

 ※ 現金は出ていかない（過去に払い済み）。だが利益と自己資本は減る
 ※ 逆に前提が改善すれば「戻入（modorishi）」として利益に戻ることもある
   （三菱商事は2026年3月期に銅事業で過年度減損の戻入532億円を計上）
```

### 5-3. 代表的な失敗の記録

| 案件 | 内容 | 教訓 |
| --- | --- | --- |
| **住友商事／アンバトビー（マダガスカル・ニッケル）** | 2007年に投資決定。2014〜16年に累計2,500億円超の減損、2024年3月期にも約890億円の減損。**累計損失は4,000億円規模**。2026年5月に持分54.17%を英企業へ譲渡して完全撤退と発表。**逆に資金を払って手放す**異例の幕引きと報じられる | 操業リスクとカントリーリスクの過小評価。撤退判断の遅れが損失を膨らませた |
| **丸紅／ガビロン（米穀物集荷）** | 2013年に約2,700億円で買収（報道ベース）。期待した中国向け穀物輸出が伸びず減損。2022年にバンジへ売却 | 「商流をつなげば伸びる」というシナジー前提の甘さ |
| **三菱商事・三井物産／2016年3月期の初の赤字** | 資源価格急落で大型減損。三菱商事は約1,494億円、三井物産は約834億円の最終赤字（当時の開示） | 資源集中の危うさ。以後、非資源シフトが本格化 |
| **三菱商事／国内洋上風力3案件** | 2025年8月に秋田・千葉の3案件からの撤退を表明し、関連損失を計上したと報じられる | 資材費・金利の高騰で、入札時の価格前提が崩れた |

> ここが本質：**商社の実力は「当てた案件」ではなく「外した案件の処理の速さ」に出る**。
> 2026年8月には、丸紅をはじめ各社が失敗事例の研修（負け筋研修）やAIによる投資分析で
> 目利き力の向上を図っていると報じられている。

## 6. 「経営人材の派遣業」という側面

見落とされがちだが、**商社の本当の希少資源は人**である。

```
【商社社員のキャリアの典型（イメージ）】

 入社 ──▶ 営業（トレード）で商流と業界を覚える（20代）
      ──▶ 海外駐在。現地の商売と人脈（20代後半〜30代）
      ──▶ 投資案件の担当。DD・交渉・契約（30代）
      ──▶ 出資先へ出向。取締役・CFO・管理部長として送り込まれる（30代後半〜）
      ──▶ 出資先の社長、または本社の事業部長（40代〜）

 ＝ 商社は「自社の事業」より「他社の経営」をする時間のほうが長い
```

| 論点 | 中身 |
| --- | --- |
| 規模 | 各社とも連結対象会社は数百〜1,000社超。単体従業員（7大商社合計で3万人規模）の多くが出向・派遣される |
| ファンドとの違い | PEファンドは経営者を外部から探す。商社は **社内から送れる** |
| 報酬 | 平均年収は伊藤忠1,580万円、三菱商事1,559万円、住友商事1,556万円、三井物産1,549万円、丸紅1,469万円（2026年時点の各種まとめ、有価証券報告書ベースの平均年間給与） |
| 弱点 | 「その業界のプロ」ではなく「経営の型を持った人」を送る形になりがち。専門性で劣ると出資先から浮く |
| 人材流出 | 若手の転職が増えている。→ [④ これからの論点](04_これからの論点.md) 第5章 |

## 8. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **権益（持分）** | 鉱山・油ガス田・プロジェクトの所有割合。10〜30%程度の少数持分が典型 |
| **オペレーター** | 実際に操業を担う会社。資源メジャーが担い、商社は非オペレーターの出資者になることが多い |
| **生産物分与契約（PSC）** | 産出物の一部を資源国政府と分け合う契約形式。中東・アフリカで一般的 |
| **IPP（独立系発電事業）** | 電力会社以外が発電所を保有し、電力を売る事業。20年前後の売電契約（PPA）で回収する |
| **PPA（電力購入契約）** | 発電者と買い手が長期に価格と量を約束する契約。IPPの収益の安定性の源 |
| **減損（インペアメント）** | 将来キャッシュフローが下がったとき、帳簿価額を回収可能額まで切り下げて損失計上すること（IAS第36号）。現金は出ていかない |
| **戻入（もどしいれ）** | 前提が改善したとき、過去の減損の一部を利益に戻すこと。IFRSではのれん以外で認められる |
| **のれん** | 買収価格が純資産を上回った差額。将来の超過収益の期待値。期待が外れると減損対象になる |
| **ハードルレート** | 投資を承認する最低利回り。国・業種のリスクに応じて上乗せする |
| **PMI（統合作業）** | 買収後に経営を軌道に乗せる作業。商社の場合は人を送り込むこと自体がPMI |
| **カントリーリスク** | 政変・収用・送金規制・治安など、国に起因するリスク |
| **コストカーブ** | 世界の鉱山を生産コスト順に並べた曲線。左（低コスト）にいる鉱山ほど市況悪化に耐える |
