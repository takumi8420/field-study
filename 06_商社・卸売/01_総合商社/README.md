## 1. 業界の定義・範囲

**総合商社** ＝ 特定の商品分野に限定せず、**あらゆる産業のモノ・カネ・人・情報を扱い、かつ自ら事業に出資して経営に関与する事業体**。
英語に定訳がなく、`sogo shosha` とそのまま表記されることが多い。これ自体が「日本にしかない」ことの証拠でもある。

境界の引き方は3つ。

```
【「商社」と呼ばれるものの広がり】

           取扱分野  →  狭い                              広い
           ┌──────────────────┬──────────────────┐
 投資で   │ 専門商社（鉄鋼・化学・   │ ＝該当なし          │
 稼がない │ 機械・食品卸・医薬品卸） │  （分野を広げても   │
           │ 口銭（手数料）が主収益   │   口銭だけでは持たない）│
           ├──────────────────┼──────────────────┤
 投資で   │ 事業持株会社・ファンド   │ ★総合商社★         │
 稼ぐ     │ （単一分野のPE等）       │ 三菱商事/三井物産/   │
           │                          │ 伊藤忠/住友商事/丸紅 │
           └──────────────────┴──────────────────┘
```

- **専門商社との違い** ＝ 分野の広さではなく **「投資で稼ぐ層を持っているか」**。
  専門商社（[鉄鋼商社](../02_鉄鋼商社/README.md) 等）は基本的に商流の口銭で食べる
- **卸売業との違い** ＝ 卸は国内流通の一工程。総合商社は原料権益から小売店舗までを縦に持つ
- **投資ファンドとの違い** ＝ ファンドは期限（通常10年前後）内に必ず売る。商社は **売らずに持ち続けて配当を取る選択ができる**

一般に「5大商社」といえば三菱商事・三井物産・伊藤忠商事・住友商事・丸紅。
豊田通商・双日を加えて「7大商社」と呼ぶ。日本貿易会では七大商社が副会長会社を構成する。

## 2. 市場規模と成長性

総合商社は「市場規模」という言い方がしにくい。**あらゆる産業に薄く広く関わるので、売上を足すと産業の重複計上になる**からだ。
実態は **各社の純利益の合計**で見るのが普通。

| 指標 | 数値 | 時点・出典 |
| --- | --- | --- |
| 5大商社の当期純利益合計 | **約3兆6,800億円** | 2026年3月期、各社決算短信を合算 |
| 最大手の連結収益（旧・売上高） | 三菱商事 **18兆9,160億円**（前期比+1.6%） | 2026年3月期、決算短信 |
| 最大手の総資産 | 三菱商事 **24兆1,517億円** | 2026年3月期末、決算短信 |
| 単体従業員数 | 7大商社合計で **3万人規模** | 日本貿易会ベース |
| 連結従業員数 | 各社4万〜9万人規模（事業会社を含むため単体の10倍超） | 各社有価証券報告書 |
| 中期経営計画の投資枠 | 7大商社合計で **12兆円超**（三菱商事4兆円、三井物産1.8兆円、伊藤忠1.5兆円） | 2026年、ダイヤモンド・オンライン報道 |

2026年3月期の純利益（親会社所有者帰属分）はこうなった。**資源と非資源で明暗が割れた年**である。

| 2 | **三井物産** | 約 **8,340億円** | ▲7% | 鉄鉱石・原料炭の価格下落が直撃 |
| 3 | **三菱商事** | 約 **8,004億円** | ▲15.8% | 前期のローソン再評価益と原料炭売却益の反動 |

→ 詳細は [⑤ 直近トピック](05_直近トピック_2026.md)。

> 成長性の本質は「商流の拡大」ではなく **「投資残高をどこまで積み、どれだけの利回りで回せるか」**。
> つまり成長率は景気ではなく、**投資判断の巧拙と資源価格**で決まる。

## 3. バリューチェーン（川上 → 川下）

総合商社の特異さは、**同じ商品について川上から川下まで複数の階層に同時に出資している**こと。

```
【例：食料バリューチェーンへの関与（イメージ）】

 農地・種苗 ── 集荷・貯蔵 ── 海上輸送 ── 製粉・搾油 ── 食品メーカー ── 卸 ── 小売
   ↑出資        ↑出資(倉庫)   ↑傭船      ↑出資        ↑出資        ↑出資  ↑出資
   ───────────────────────────────────────────────
              すべてに持分を持ち、モノの流れ全体から利益を拾う
              ＝「垂直統合を、所有ではなく "持分" で行う」

【利益の出どころ（二層構造）】

 ┌─ 第1層：商流（トレーディング） ─────────────┐
 │ 売手 ──モノ──▶ 商社 ──モノ──▶ 買手               │
 │        ◀─カネ─      ◀──カネ─                      │
 │   利益＝口銭（手数料）。取扱高の 0.5〜数% が相場    │
 │   機能＝与信・在庫・物流・為替・品質保証            │
 └──────────────────────────────┘
 ┌─ 第2層：事業投資 ───────────────────┐
 │ 商社 ──出資──▶ 事業会社（鉱山/発電所/コンビニ…）  │
 │        ◀配当・持分利益─                            │
 │   利益＝配当＋持分法投資利益＋売却益（EXIT益）      │
 │   ここが現在の利益の大半                            │
 └──────────────────────────────┘
```

- 付加価値が集まるのは **(a) 資源権益（上流）、(b) インフラ・電力の長期契約、(c) 小売・生活消費の安定収益、(d) 投資の出口（売却益）**
- **中間の純粋なトレーディングは利益率が薄い**。情報がネットで流通し、メーカーが直接取引する流れが進んだため
- ただしトレーディングは捨てられない。**現場の商売がなければ「どこにいい案件があるか」が分からない**（案件発掘のレーダー）

詳細は [② 稼ぎの構造](02_稼ぎの構造.md)。

## 5. 収益モデル・コスト構造

```
純利益 ＝ ① トレーディング損益（口銭）
        ＋ ② 事業投資からの配当・子会社利益
        ＋ ③ 持分法による投資損益（出資20〜50%先の利益 × 持分比率）
        ＋ ④ 投資有価証券売却益（EXIT益）
        －   販管費（人件費が最大）
        －   減損損失（失敗した投資の簿価切り下げ）
        ±   為替・金利・資源価格
```

| 論点 | 中身 |
| --- | --- |
| 売上高が消えた | IFRS（国際会計基準）の適用で、**自分がリスクを負わない仲介取引は「純額（口銭だけ）」で計上**することになった。かつて「売上20兆円」と言われた数字は今の決算書にほぼ存在しない → [①](01_総合商社とは何をしている会社か.md) |
| 現在の中心指標 | **当期純利益**、**持分法による投資損益**、**基礎営業キャッシュ・フロー**（商社独自。実態としての稼ぐ力） |
| コストの中身 | 製造業と違い **原価の大半は仕入れ**。自社コストの主役は **人件費**（1人あたり年収1,400万〜1,600万円台） |
| 固定費の軽さ | 工場を持たないので固定費は軽い。ただし **投資簿価が「見えない固定費」**。減損すれば一気に損失になる |
| 利益率 | 収益（旧売上高）に対する純利益率は数%だが、**この分母には意味がない**。見るべきは ROE（近年10〜15%台）と ROIC |
| 振れ幅 | 資源価格が10%動くと、資源3社の純利益は数百億〜1,000億円単位で動く。**業績の振れ幅の原因はほぼ資源と為替** |

## 6. 競争要因（KSF）と参入障壁

**KSF（成功の鍵）**

1. **案件が持ち込まれる立場にあるか**（オリジネーション）。商流を握っているから「売りたい」相手が最初に相談に来る
2. **目利きと撤退判断**。入るときより **「いつ諦めるか」** の規律が差を生む（→ [③ 事業投資の実際](03_事業投資の実際.md)）
3. **経営人材の供給力**。出資先に社長・CFOを送り込んで実際に価値を上げられるか
4. **資源と非資源のバランス**。片寄ると資源価格で業績が乱高下する
5. **資金調達力と格付け**。低コストで長期資金を引ける会社が大型権益を取れる
6. **株主還元の一貫性**。累進配当と自社株買いで株価を支え、資本コストを下げる

**参入障壁**

| 障壁 | 強さ | 理由 |
| --- | --- | --- |
| 商流そのもの | 弱 | 貿易実務は誰でも学べる。専門商社は今も新規参入がある |
| **長期権益へのアクセス** | 強 | LNGや鉱山の持分は40〜50年単位の関係。今から入れる枠がない |
| **資本の厚み** | 強 | 1案件で数千億円。自己資本4兆〜7兆円規模でないと張れない |
| **失敗を吸収できる体力** | 強 | 数千億円の減損を出しても黒字を維持できる分散が要る |
| **人材プール** | 強 | 数百社の経営陣を送り出せる人材層は一朝一夕に作れない |
| ブランド・信用 | 中〜強 | 産油国政府や海外パートナーとの数十年の関係が効く |

## 7. 規制・法制度

商社を直接縛る「商社法」は存在しない。代わりに **扱う商品ごとの規制の束**を受ける。

| 分野 | 主な制度 |
| --- | --- |
| **貿易管理** | 外国為替及び外国貿易法（外為法）。安全保障貿易管理（軍事転用可能な貨物・技術の輸出許可）。違反は刑事罰 |
| **経済安全保障** | 経済安全保障推進法（2022年）による重要物資のサプライチェーン調査・支援。対内直接投資審査 |
| **制裁・輸出規制** | 米国のOFAC制裁、対ロシア制裁。サハリン2など **権益の保有そのものが外交問題になる** |
| **会計** | IFRS（大手は2013〜2015年ごろに相次いで任意適用）。IFRS第15号で代理人取引は純額表示。減損はIAS第36号 |
| **独占禁止法・下請法** | 国内流通での優越的地位の濫用、価格転嫁。商社は「買う側」としても規制対象 |
| **贈収賄** | 外国公務員贈賄（不正競争防止法）、米FCPA、英Bribery Act。資源国での案件が多いため実務上きわめて重い |
| **資源国側の制度** | 鉱業権、生産物分与契約（PSC）、ロイヤルティ、資源ナショナリズムによる条件変更リスク |
| **気候関連開示** | TCFD／ISSB（IFRS S1・S2）に沿った開示。Scope3（投融資先の排出）の扱いが商社最大の論点 → [脱炭素・GX](../../01_注目テーマ/05_脱炭素・GX/README.md) |
