## 1. 2026年3月期決算：資源と非資源で明暗が割れた

2026年3月期は、**鉄鉱石・原料炭など資源価格の高騰局面に一区切りがついた年**だった。
その結果、資源色の濃い2社が減益、非資源に厚い3社が最高益という対照的な決算になった。

| 会社 | 2026年3月期 純利益 | 前期比 | 内容 |
| --- | --- | --- | --- |
| **伊藤忠商事** | 約 **9,003億円** | +2.3% | **3期連続の過去最高益**。純利益で首位 |
| **三井物産** | 約 **8,340億円** | ▲7% | 鉄鉱石・原料炭の価格下落が直撃 |
| **三菱商事** | 約 **8,004億円** | **▲15.8%** | 前期のローソン再評価益・原料炭事業売却益の反動。3期連続減益 |
| **住友商事** | 約 **6,003億円** | 増益 | 過去最高益を更新 |
| **丸紅** | 約 **5,439億円** | +8.1% | 非資源の内需事業が堅調。ただし決算後に株価が急落したと報じられる |

  **地球環境エネルギー・マテリアルソリューション・モビリティが減益**

## 4. 住友商事、マダガスカルのニッケル事業から完全撤退（累計損失4,000億円規模）

商社の「失敗の記録」として業界史に残る案件が、2026年に幕を閉じた。

```
【アンバトビー・ニッケルプロジェクトの20年】

 2007年  住友商事がカナダのシェリット、韓国KORESと組んで投資決定
   │
 2014〜16年  累計 2,500億円超の減損
   │
 2024年3月期  さらに 約890億円の減損
   │
 2026年5月1日  完全撤退を発表
   │           保有株 54.17% をすべて英国企業へ譲渡
   │           2026年9月末までに完了予定
   ▼
  累計損失 4,000億円規模
  ※ 譲渡にあたり、逆に資金を払って事業を手放す異例の幕引きと報じられる
```

- 対価を受け取るどころか **支払って手放す**という形は、鉱山事業の閉山・環境復旧義務の重さを示している
- 住友商事の2026年3月期が最高益だったのは、この撤退処理を進めながらの数字である点が注目された
- 2026年8月には、丸紅をはじめ各社が **失敗投資を教材にした社内研修（負け筋研修）やAIによる投資分析**で
  目利き力の向上を図っていると報じられた
- 詳細な文脈は [③ 事業投資の実際](03_事業投資の実際.md) 第5章

## 6. 次の主戦場：AIデータセンターと電力

2026年に商社の投資テーマとして急速に立ち上がっているのが **AI向けデータセンターと、その電力**である。

| 事実 | 出典・時点 |
| --- | --- |
| AIデータセンターのIT供給電力量は2025年末の約300MWから、2026年末に約600MW、2027年末に約800MWへ増えるとの予測 | インプレス総合研究所『データセンター調査報告書2026』（2026年1月発売） |
| 大手電力8社が全国30カ所で変電所を新増設。需要予測の2倍のペースで整備 | 日本経済新聞（2026年5月） |
| 米AIデータセンターの電力供給制約解消に向け、日立など12社が連携 | JETRO ビジネス短信（2026年7月） |

商社にとってこの分野は、**電源開発（IPP・再エネ）、送変電機器の調達、用地、燃料、リース**を
まとめて提供できる数少ない事業者としての出番になる。
一方で、投資回収が20年単位になるため、**金利・資材価格の前提が崩れると洋上風力と同じ轍を踏む**リスクもある。

## 7. 全体の構図（まとめ）

- **2026年は「資源の春」に一区切りがついた年**だった。鉄鉱石・原料炭の下落で資源2社が減益、
  非資源3社が最高益という形で、各社の戦略の違いがはっきり数字に出た
- ただし **2027年3月期は全社増益予想**で、三菱商事は1.1兆円を掲げて首位奪還を狙う。
  資源のサイクルが一巡すれば順位はまた入れ替わる構造にある
- **バークシャーの保有比率が5社すべて10%台**に達し、株主還元（累進配当・巨額の自社株買い）が
  業界標準になった。これは商社株の性格を「資源連動の景気敏感株」から変えつつある
- 一方で **住友商事のアンバトビー撤退（累計損失4,000億円規模）** は、事業投資モデルの
  裏側にある失敗コストの大きさを改めて示した。各社が撤退規律の強化に動いている
- 投資枠は7大商社合計12兆円超。**資源の大型案件と非資源の積み上げを同時に張る**のが現在の共通解で、
  次の主戦場はAIデータセンターと電力インフラに向かっている

## 8. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **再評価益** | 連結子会社が持分法適用会社に変わるなど、支配関係が変化したときに、残った持分を公正価値で評価し直して生じる利益。現金は伴わない |
| **戻入（もどしいれ）** | 過去に計上した減損の前提が改善したとき、その一部を利益に戻すこと |
| **自社株買い・消却** | 自社株式を市場から買い戻すこと。消却すれば発行済株式数が減り、1株当たり利益とROEが上がる |
| **累進配当** | 減配せず、維持または増配を続ける配当方針 |
| **IT供給電力量** | データセンターがIT機器に供給できる電力の総量。データセンターの規模を表す実質的な単位（MW） |
| **権益40%取得** | 鉱山・プロジェクトの持分を40%取得すること。操業は別のオペレーターが担うことが多い |
| **3冠** | 商社業界で言われる「純利益・ROE・時価総額」の3指標での首位 |
