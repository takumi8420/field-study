脱炭素と資源権益の板挟み、バフェット（バークシャー）投資が何を変えたか、

1. 脱炭素と資源権益：捨てるべきか、持ち続けるべきか

商社の利益の柱は化石燃料と金属資源である。一方で 投融資先の排出量（Scope3） の開示が求められ、
資源権益を持ち続けること自体が資本市場からの評価を左右する。ここに構造的なジレンマがある。

【商社の脱炭素ジレンマ】

  ┌─ 売る（ダイベストメント） ─────────────────┐
  │ ・自社の排出量は減る／ESG評価は上がる                  │
  │ ・だが 権益は消えない。買った誰かが掘り続ける          │
  │ ・地球全体の排出は減らず、利益だけ失う                │
  └───────────────────────────────┘
  ┌─ 持ち続けて改善する（エンゲージメント） ───────────┐
  │ ・操業の低炭素化、メタン漏洩対策、CCS併設などに関与     │
  │ ・だが「化石燃料企業」と見なされ資本コストが上がる恐れ  │
  └───────────────────────────────┘
          ▲ 各社はこの中間で「一般炭は縮小、原料炭とLNGは当面維持」
            という立場を取ることが多い
論点 現状（各社開示・報道ベース）
一般炭（発電用石炭）各社とも縮小・撤退方針。最も明確に切られた分野
原料炭（製鉄用）代替技術（水素還元製鉄）が実用化するまで必要、として保有を続ける立場が主流 → 鉄鋼
LNG「移行期のエネルギー（トランジション燃料）」と位置づけ、投資を継続。三菱商事は2021年に2030年度までの脱炭素関連投資2兆円を掲げつつ、LNG投資は継続すると表明
銅・ニッケル・リチウム電化に必須なのでむしろ増やす方向。ただし鉱山の環境・人権リスクは重い → 非鉄金属
再エネ・水素・アンモニア投資はするが、洋上風力のようにコスト高騰で撤退する例も出ている → 水素・アンモニア、脱炭素・GX

読みどころ：「脱炭素投資を◯兆円」という発表だけ見ても実態は分からない。
資源セグメントの利益構成が何年でどう変わったか、を追うほうが実態に近い。

2. バフェット投資は何を変えたか

2020年8月、バークシャー・ハサウェイが5大商社それぞれに5%超を出資していたことが判明した。
以降、保有比率は段階的に引き上げられている。

時点 出来事
2020年8月5大商社に5%超の出資が判明。株価が急騰
2025年8月28日三菱商事の保有比率が10.23%に達したことが判明。三井物産・伊藤忠も買い増しと報じられる
2026年5月住友商事・丸紅も10%超となり、5社すべてで保有比率が10%台に到達したと報じられる
継続後継者のグレッグ・アベル氏も、5大商社を 「恒久的な投資先」 と位置づけていると報じられる

変わったのは株価だけではない。3つの実質的な変化が起きた。

【バークシャー効果の伝わり方】

 バークシャーが買う
      │
      ├─▶ ① 海外投資家の関心が向く
      │      「日本の商社」という未知の業態が国際的に認知された
      │
      ├─▶ ② 株主還元の圧力が強まる
      │      累進配当・自社株買いの拡大。三菱商事は上限1兆円の
      │      自社株買いを2026年3月に完了
      │
      └─▶ ③ 経営の物差しがROE/PBRに揃った
             東証の「資本コストを意識した経営」要請と同じ方向を向いた
  • 注意：バークシャーが買った理由として語られるのは「割安な資本配分」「永続性」「低コストの円調達」など。
    ただしこれは投資家側の判断であり、このノートは投資判断を示すものではない
  • 構造的な副作用として、浮動株が減った。流動性と株価形成への影響は今後の論点である

3. 非資源シフトはどこまで進んだのか

「非資源シフト」は2016年3月期の資源赤字以降、業界共通の合言葉になった。実態は 会社によって大きく違う。

会社 非資源シフトの進み方（定性評価） 根拠となる動き
伊藤忠商事ほぼ完了。もともと非資源中心ファミリーマート、食料、繊維、金融。2026年3月期に純利益首位
住友商事進んだメディア・不動産・リース。中期経営計画2026でデジタル・リース・都市総合開発を成長分野に
丸紅進んだ電力IPP、農業資材。穀物集荷のガビロンは2022年に売却
三菱商事部分的ローソン・電力・複合都市開発を厚くする一方、原料炭・銅・LNGは中核のまま
三井物産限定的鉄鉱石・原油ガスが依然として柱。2026年に豪ローズリッジ鉄鉱石権益40%取得の計画と報じられる

2026年3月期の結果は、この差がそのまま出た形になった（非資源3社が最高益、資源2社が減益）。

冷静に見るべき点：非資源シフト＝正解、ではない。
資源価格が上がる局面では資源2社が一気に稼ぐ。
実際、2022〜2023年の資源高局面では三菱商事・三井物産が純利益1兆円級を記録した。
各社が本当に狙っているのは「非資源化」ではなく 「どちらの局面でも一定の利益が出る構成」 である。

4. ポートフォリオ入れ替えの速度

商社が抱える最大の内部課題は、買うのは速いが、売るのが遅いこと。

【投資ポートフォリオの新陳代謝】

  理想                              現実になりがちな姿
 ┌──────────┐              ┌──────────┐
 │ 新規投資  ▓▓▓ │              │ 新規投資  ▓▓▓ │
 │ 売却     ▓▓▓ │              │ 売却     ▓     │ ← 売れない
 │ 残高     一定  │              │ 残高     膨張  │
 └──────────┘              └──────────┘
   資本が回転し                     資本が寝たまま
   ROICが上がる                     ROICが下がる
                                    → いずれ減損

売れない理由は構造的である。

売れない理由 説明
合弁契約の縛り他の出資者の同意やファーストリファーサル（優先買取権）がある
相手国の事情資源国では持分譲渡に政府承認が要ることが多い
社内の事情その案件を作った部署・担当者がいる。簿価割れで売ると損失が出る
買い手不在石炭火力や不採算インフラは、そもそも買い手がつかない

対策として各社が導入しているのが、事業別ROIC/WACCの比較（住友商事の中期経営計画2026が明示）、
投資のサンセット条項（一定年数で自動的に再審査）、そして 失敗事例の教材化である。
2026年8月には、丸紅など各社が負け筋研修やAIによる投資分析で目利き力向上を図っていると報じられた。

5. 若手人材の流出

商社は依然として就職人気の最上位にある（平均年収は1,400万〜1,600万円台）。
それでも 若手の離職が増えているというのが2020年代の実感として語られる。

流出の理由として語られるもの 背景
裁量が回ってくるまでが長い年功的な昇進。若手のうちは書類作成と社内調整が多い
配属の不確実性どの部門に行くかで仕事の中身がまったく違う。転勤・駐在も会社が決める
スタートアップ・外資との比較「自分で決めて自分で作る」経験の密度で見劣りする
市場価値の希薄さ幅広く扱う分、専門スキルが積み上がりにくいという不安
【商社のキャリアの「谷」】

  裁量・面白さ
    ▲
    │                             ┌─── 出資先の経営・投資判断
    │                          ╱
    │                       ╱
    │  入社直後       ╱  ← ここまで10年前後かかる
    │  （新鮮）  ╲ ╱
    │            ▽  ← 「谷」。若手が辞めるのはたいていここ
    └────────────────────────▶ 年次

対策として、各社は若手の海外派遣の前倒し、投資案件への早期アサイン、
専門人材のキャリア採用、社内公募制度の拡充などを進めている。
ただし 「経営人材を大量に育てる」という商社のモデル自体が、長い育成期間を前提にしているため、
構造的なジレンマが残る。→ ③ 事業投資の実際 第6章

6. 「商社不要論」への反論

商社無用論は1960年代から周期的に現れる。中身を分解して、いまも有効な部分と無効な部分を分ける。

不要論の主張 評価
「ネットで直接取引できるから中抜きは不要」部分的に正しい。情報機能はほぼ無料になった。実際、純粋な仲介部隊は縮小・統廃合されている
「メーカーが自分で海外に出れば商社はいらない」大手には正しい。ただし中小メーカーや、与信リスクの高い相手との取引では依然として商社が要る
「商社は資源価格に乗っているだけ」半分正しい。ただし非資源で最高益を出す会社がある時点で、説明としては不十分
「投資ならファンドのほうが上手い」部分的に正しい。財務的リターンだけならファンドが速い。ただしファンドは 数百社に経営者を送れない
「何でも屋は専門企業に勝てない」一面では正しい。だが商社の強みは個別分野の専門性ではなく、分野をまたぐ接続にある
【商社が代替されにくい4機能（情報だけが剥がれた）】

 ①情報     ──▶ ✕ インターネットとメーカー直販で代替された
 ②与信・資本 ──▶ △ 銀行・ファンドが一部代替。ただし事業リスクまでは取らない
 ③オペレーション ▶ ○ 現地実務・通関・品質・トラブル対応は人がやるしかない
 ④経営人材   ──▶ ◎ 数百社に送れる人材プールは他に存在しない

     ＝ 商社が残っているのは ③④ が残ったから

結論として、「卸売業としての商社」は縮小し、「事業投資会社＋オペレーターとしての商社」は拡大した。
不要論が繰り返し現れるのは、外から見える顔が古い業態のままだからである。

論点 見るべき指標・イベント

人材モデル専門人材のキャリア採用比率、若手の定着率
事業の入れ替え売却額／投資額の比率。ポートフォリオの回転速度

8. 用語メモ

用語 意味
Scope3自社以外（サプライチェーンや投融資先）で発生する温室効果ガス排出。商社では出資先の排出が該当し、算定が難しい
ダイベストメント環境・社会上の理由から特定資産（石炭等）を売却して手を引くこと
エンゲージメント売らずに保有したまま、対話を通じて対象企業の行動を変えさせるアプローチ
トランジション燃料脱炭素への移行期に、石炭より排出の少ない選択肢として使われる燃料。LNGがその代表とされる
累進配当減配せず、維持または増配を続ける配当方針
PBR（株価純資産倍率）株価 ÷ 1株当たり純資産。1倍割れは「解散価値を下回る」とされ、東証が改善を要請した
浮動株市場で実際に売買される株式。大株主の保有が増えると減る
ファーストリファーサル（優先買取権）合弁相手が持分を売るとき、他の出資者が優先的に買える権利。売却の足かせになることがある
サンセット条項一定年数が経過したら自動的に再審査・見直しを行う取り決め
負け筋研修過去の失敗投資を教材にした社内研修。2026年に各社が取り組んでいると報じられる
