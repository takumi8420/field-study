# ① 総合商社とは何をしている会社か

このノートで分かること：総合商社が **「手数料で食う仲介業」から「出資で食う事業投資会社」へ転換した経緯**と、
その結果として決算書から「売上高」という言葉が消えた理由。そして、なぜこの業態が日本にしか生まれなかったのか。

## 1. 結論：いまの総合商社は「商社」ではない

一言でいうと、**総合商社は世界中の事業に少しずつ出資して、その利益を吸い上げる会社**である。
モノを仲介する商売（トレーディング）は今も残っているが、利益に占める比重は昔よりずっと小さい。

```
【総合商社の利益の重心はこう移った（概念図）】

 1960年代            1990年代            2010年代〜現在
 ┌─────┐        ┌─────┐        ┌─────┐
 │  口銭   │        │  口銭   │        │口銭 ▓   │ ← 薄い
 │ ▓▓▓▓▓ │        │ ▓▓▓   │        │         │
 │ ▓▓▓▓▓ │        │         │        │         │
 ├─────┤        ├─────┤        ├─────┤
 │ 投資 ▓  │        │ 投資     │        │  事業投資 │
 │         │        │ ▓▓▓   │        │ ▓▓▓▓▓ │ ← 厚い
 │         │        │ （失敗も）│        │ ▓▓▓▓▓ │
 └─────┘        └─────┘        └─────┘
  貿易の窓口          多角化と            持分利益と配当が
  ＝口銭が主          バブル処理          利益の中心
```

この変化を頭に入れないと、決算書を見ても意味が読めない。
「売上が小さいのに純利益が兆円に近い」という一見おかしな姿は、ここから説明できる。

## 2. 口銭（こうせん）とは何だったのか

**口銭** ＝ 商社が売買を仲介したときに取るマージン（手数料）。
鉄鋼や化学品では **取扱高の0.5〜3%程度**、食品や雑貨ではもう少し厚い、というのが一般的な相場感である（公表基準はない）。

口銭が成立していたのは、商社が4つの面倒を引き受けていたから。

| 商社が引き受けた面倒 | 具体的に | 誰の代わりか |
| --- | --- | --- |
| **与信（信用リスク）** | 買手が倒産しても売手には満額払う | メーカー・銀行 |
| **在庫・物流** | 船・倉庫・通関・保険を手配し、在庫を自分で持つ | メーカー・需要家 |
| **為替・価格リスク** | ドル建て仕入れを円建てで売る。先物でヘッジ | 中小の需要家 |
| **情報** | どこに誰が何を売りたがっているか | 全員 |

> ポイント：口銭は「つなぐ手数料」ではなく **「リスクを引き受ける対価」**。
> だからリスクを引き受けない仲介は、後述のとおり会計上も「売上」として認められなくなった。

問題は、この4つのうち **「情報」が1990年代以降ほぼ無料になった**こと。
メーカーが自前で海外拠点を持ち、直接取引を始めた。これが「商社無用論（中抜き論）」の中身である。

## 3. 「売上高」が決算書から消えた話

総合商社を語るとき、昔はよく「三菱商事の売上は20兆円」と言われた。今の決算短信にこの数字はない。
理由は **会計基準の変更**である。

### 3-1. 総額表示と純額表示

```
【100億円の鉄鋼を仲介し、口銭1億円を得た取引】

■ 総額表示（かつての日本基準の慣行）
   売上高       100億円
   売上原価      99億円
   ───────────────
   売上総利益     1億円   ← 「売上100億円の会社」に見える

■ 純額表示（IFRS第15号の「代理人」処理）
   収益           1億円   ← 口銭だけが収益
   ───────────────
   売上総利益     1億円   ← 「収益1億円の会社」に見える

   利益は同じ1億円。変わったのは "分母" だけ。
```

- **本人（プリンシパル）** ＝ 自分が在庫を持ち、価格変動・滞留・代金回収のリスクを負う → **総額で計上できる**
- **代理人（エージェント）** ＝ 手配するだけでリスクを負わない → **手数料（純額）でしか計上できない**

IFRS第15号「顧客との契約から生じる収益」（2018年適用開始）と、
日本の収益認識に関する会計基準（2021年4月開始事業年度から強制適用）が、この線引きを明確にした。
大手商社は2013〜2015年ごろに相次いで IFRS を任意適用しており、このとき **表示上の売上高が大きく縮んだ**。

### 3-2. いま見るべき3つの指標

| 指標 | 意味 | 使いどころ |
| --- | --- | --- |
| **当期純利益（親会社所有者帰属）** | 最終的に株主のものになる利益 | 商社比較の事実上の唯一の物差し |
| **持分法による投資損益** | 出資20〜50%先の純利益 × 持分比率を1行で取り込んだもの | 「投資会社としての稼ぐ力」がここに出る |
| **基礎営業キャッシュ・フロー** | 営業CFから運転資本の増減を除いた、商社独自の開示指標 | 会計上の損益ではなく **実際に入ってきた現金**を見る |

なお各社は参考値として **取扱高（Trading transactions）** を注記することがある。
これが昔の「売上高」に近い概念だが、**会計上の売上ではない**ので他業種と比較してはいけない。

## 4. なぜ日本にしかないのか

海外にも巨大なトレーダーはいる（穀物のカーギル、資源のグレンコア、石油のビトルなど）。
しかし **「全産業を横断し、かつ自ら経営に入り込む」** 形は日本にしかない。理由は5つ重なっている。

| 要因 | 説明 |
| --- | --- |
| **島国で資源も市場も外にある** | 原料を買い、製品を売るという往復の貿易が経済の前提。誰かが窓口をやる必要があった |
| **後発工業国だった** | 明治期の中小メーカーに輸出能力がなかった。国が貿易を担う組織を必要とした |
| **財閥という器があった** | 三井物産（1876年）、三菱商事（1918年）はグループの「商事部門」として生まれた |
| **メインバンク制と株式持ち合い** | 銀行が与信を、商社が商流を担い、グループ企業が相互に株を持ち合う構造。商社が与信の肩代わりをできた |
| **戦後の外貨割当制度** | 輸入に必要な外貨の割当を受けられる商社に取引が集中し、規模が一気に膨らんだ |

```
【日本型「商社」の成立（ごく大づかみな系譜）】

 江戸〜明治  ─ 三井物産(1876) ─────────┐
              岩崎商会→三菱商事(1918) ──┐ │
                                          │ │
 繊維系      ─ 伊藤忠(1858 創業) ─┐      │ │
              丸紅（伊藤忠から分立）┘      │ │
              「関西五綿」＝伊藤忠/丸紅/   │ │
               日綿/東棉/江商              │ │
                                          ▼ ▼
 1947 財閥解体 ── 三井物産は約200社、三菱商事は約140社に分割
                  （繊維系・非財閥系は分割を免れ、相対的に力を得た）
                          │
 1954 三菱商事 大合同 ────┤
 1959 三井物産 大合同 ────┘   ＝ 財閥系の「復活」
                          │
 高度成長期 ── 外貨割当・プラント輸出・資源輸入で拡大
                「ラーメンからミサイルまで」
                          │
 1960年代後半 ── 第一次「商社冬の時代」（商社無用論）
 1990年代後半 ── 第二次「冬の時代」（バブルの不良資産処理）
                          │
 2000年代〜  ── 資源権益と事業投資へ重心を移す
```

- **五綿八社（ごめんはっしゃ）** ＝ 関西の繊維商社（伊藤忠・丸紅・日綿・東棉・江商の「五綿」）に、
  蝶理・第一物産・安宅産業などを加えた呼称。繊維から総合化した非財閥系の系譜
- 韓国にも総合商社（三星物産など）があるが、これは1970年代に日本を模倣した制度（総合商社指定制度）による

## 5. 二度の「冬の時代」が業態を変えた

### 5-1. 第一次：商社無用論（1960年代後半〜70年代）

戦後の混乱が収まり、流通ルートが安定すると、「商社を外したほうが安い」という声が出た。
メーカーが直販部門を持ち始め、口銭が圧迫された。
このとき商社は **プラント輸出**（発電所・製鉄所をまるごと輸出する）や **資源開発への出資**に活路を求めた。
「取引の仲介」から「案件そのものを作る」へ、最初の転換が起きた時期である。

### 5-2. 第二次：バブルの不良資産処理（1990年代後半〜2000年代前半）

バブル期、商社は不動産・ゴルフ場・株式に大量の資金を投じた。崩壊後は不良資産の山になる。
1977年には安宅産業が経営破綻して伊藤忠に吸収され、2000年前後には各社が数千億円規模の損失処理を迫られた。
この処理の過程で、業界は3つの規律を手に入れた。

| 得た規律 | 中身 |
| --- | --- |
| **リスクアセットという考え方** | 投資額ではなく「最悪どれだけ失うか」で資本を配分する |
| **撤退基準の明文化** | 何年で回収できなければ売る、という社内ルール |
| **連結経営への移行** | 単体の売上ではなく、連結の純利益で評価する |

> ここが重要：**いまの総合商社の強さは、二度の失敗を制度化したことから来ている**。
> 「投資で儲ける会社」になれたのは、失敗の数え方を覚えたからである。

## 6. では現在、何をしている会社なのか

機能で分解すると、総合商社の仕事は次の5つに整理できる。

```
【総合商社の5機能】

 ①トレード     モノを売買し、口銭を取る（商流の維持＝レーダーでもある）
     ↓
 ②ファイナンス  与信を与え、船・在庫・運転資金を立て替える
     ↓
 ③オペレーション 物流・通関・品質管理・現地対応を実務として回す
     ↓
 ④インベストメント 事業会社に出資し、配当と持分利益を取る  ← いまの利益の中心
     ↓
 ⑤マネジメント   出資先に役員・社員を送り込み、経営して価値を上げる
```

①〜③は昔からの商社機能。④⑤が現在の稼ぎ頭で、とくに⑤が他の投資家との決定的な違いになっている。
投資ファンドは資本は出せても、鉱山や食品工場を実際に回す人間を数百人単位では送れない。
その意味で総合商社は **「資本と人材をセットで出す投資会社」** と言える。
この人材の側面は [③ 事業投資の実際](03_事業投資の実際.md) の第6章で扱う。

## 7. よくある誤解

| 誤解 | 実際 |
| --- | --- |
| 「商社は中抜きしているだけ」 | 中抜きできる部分（情報）は既に剥がれた。残っているのは与信・実務・資本・人材 |
| 「売上が小さいから縮小している」 | 会計上の表示が変わっただけ。純利益は2010年代より大きい |
| 「商社＝資源会社」 | 資源依存は会社ごとに大差がある。伊藤忠は非資源が中心（→ [②](02_稼ぎの構造.md)） |
| 「メーカーの下請け的存在」 | 出資関係では商社が親会社側に立つことも多い（コンビニ、食品卸、発電事業など） |
| 「卸売業の延長」 | 卸売業（[食品卸](../06_食品卸/README.md) 等）は国内流通の一工程。総合商社はその卸の株主であることが多い |

## 8. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **口銭（こうせん）** | 売買仲介で商社が取るマージン。取扱高の0.5〜数%が目安。リスク引受の対価 |
| **取扱高（Trading transactions）** | 商社が関与した取引の総額。参考値として注記されることがあるが、会計上の売上ではない |
| **本人／代理人（プリンシパル／エージェント）** | 在庫・価格・回収のリスクを負うか否かの区分。本人なら総額表示、代理人なら純額表示 |
| **IFRS第15号** | 「顧客との契約から生じる収益」。2018年適用開始。日本の収益認識基準は2021年4月開始事業年度から強制適用 |
| **持分法による投資損益** | 出資比率おおむね20〜50%の会社の純利益 × 持分比率を、損益計算書に1行で取り込んだもの → [②](02_稼ぎの構造.md) |
| **基礎営業キャッシュ・フロー** | 営業CFから運転資本の増減を除いた商社独自の開示指標。実際の現金創出力を見る |
| **財閥解体** | 1947年、GHQの指令で三井物産は約200社、三菱商事は約140社に分割された。1954年・1959年にそれぞれ再統合 |
| **五綿八社** | 関西の繊維系商社の総称。伊藤忠・丸紅などの非財閥系が総合商社化した系譜 |
| **商社冬の時代／商社無用論** | 口銭が圧迫され存在意義が問われた時期。1960年代後半と1990年代後半の二度 |
| **外貨割当制度** | 戦後、輸入に必要な外貨を政府が割り当てた制度。商社への取引集中を生んだ |
