① ECの3つのモデル（直販・モール・自社EC）

このノートで分かること：ECは「誰の在庫を、誰のサイトで売り、誰が代金を受け取るか」で3つの型に分かれ、
儲け方も損益計算書の形も全く違う。最初の関門は GMV（流通総額）と売上高がまるで別物 だということ。

1. 結論：ECは3つの型しかない

ネット通販と一括りに言うが、事業としては次の3つに分解できる。
同じ「1万円の商品が売れた」でも、会社の売上に何円計上されるかが型によって桁違いになる。

型 誰の在庫か サイト運営者の売上 代表例 経済的な性格
直販型（1P＝ファーストパーティ）自社で仕入れた在庫商品代金の全額（1万円）Amazon自社出荷分、ヨドバシ.com、Rakuten24実質は小売業。在庫リスクを背負い、粗利で稼ぐ
マーケットプレイス型（3P＝サードパーティ／モール）出店者の在庫手数料だけ（1万円×十数%）楽天市場、Yahoo!ショッピング、Amazonマケプレ場所貸し＋両面市場。在庫を持たず、利益率が高い
自社EC型自社の在庫商品代金の全額（プラットフォーム側は月額＋決済手数料のみ）Shopify／BASE／STORESで作った店、D2Cブランドブランドが集客費を自腹で払う。顧客データは自分のもの
【商品とお金の流れ】

■ 直販型（Amazon自社在庫、ヨドバシ.com）
  メーカー・卸 ──仕入──▶ EC事業者の倉庫 ──販売──▶ 消費者
                          （在庫は自社のもの）        売上＝1万円
                                                     粗利＝1万円−仕入原価

■ マーケットプレイス型（楽天市場、Yahoo!ショッピング）
  出店者の倉庫 ────────── 商品 ──────────▶ 消費者
        ▲                                        │
        │ 代金（手数料を引いた残り）              │ 代金1万円
        └──────── モール運営者 ◀────────────────┘
                （売上は手数料＝十数%だけ）

■ 自社EC型（Shopify／BASEで作った店）
  ブランドの倉庫 ─── 商品 ──▶ 消費者
        ▲                        │ 代金1万円（全額ブランドに入る）
        │ 月額＋決済手数料        │
   プラットフォーム（SaaS）  ＋   広告会社（集客費は自腹）

ポイント：Amazonは1社の中に直販型とマーケットプレイス型の両方を持っている。
だから「Amazonの売上」と「Amazonで売れた総額」は全く違う数字になる。

2. GMV（流通総額）と売上高の違い

GMV＝Gross Merchandise Value、そのプラットフォーム上で売れた商品代金の合計。
売上高＝会計上、その会社の収益として計上される金額。
モール型では両者が一致しない。この差を埋めるのが テイクレート（take rate）＝売上高÷GMV である。

【テイクレートの図】

  GMV（プラットフォームで売れた総額）  ← 消費者が払った合計
   └─▶ うちプラットフォームの取り分（テイクレート ○%）＝ 売上高
          ├─ 出店料・システム利用料（固定＋従量）
          ├─ 決済手数料
          ├─ 広告料（リテールメディア → ③ノート）
          ├─ 物流サービス料（FBA等）
          └─ ポイント原資（マイナス要素。実質の値引き）
   └─▶ 残りは出店者の売上（プラットフォームの売上には乗らない）
企業 GMV（流通総額） 会計上の売上高 読み方
楽天グループ 国内EC6兆3,452億円（2025年、前年比+3.9%、同社IR）国内EC セグメント売上収益 1兆232億円（同+5.8%）単純比は約16%。ただし直販（Rakuten24等）や旅行の宿泊流通も混ざる合計値
Amazon 日本事業8兆円規模との推計（民間集計。マケプレ出品分を含む）306.88億ドル＝約4兆6,338億円（2025年、Amazon 10-K の国別売上、報道集計）開示されるのは「自社販売＋手数料等」。GMVは非開示なので推計しかない
3大モール合計約11.2兆円（2024年、前年比+13.0%、業界メディア集計）－物販系BtoC-EC（15.2兆円）の73.7%を3社が占めるという推計

注意：GMVの定義は会社ごとに違う（旅行の予約額を入れるか、キャンセル分を引くか、送料を含むか）。
他社比較のときは必ず定義を確認する。ここが業界記事でもっとも誤解されやすい点。

3. 直販型の経済性＝「ネット上の小売業」

直販型は在庫を買って売るので、損益の形は家電量販店やスーパーとほぼ同じ。
店舗の代わりに倉庫と配送があるだけ、と考えると分かりやすい。
（店舗型との比較は 家電量販 を参照）

項目 直販ECの目安 なぜそうなるか
売上総利益率（粗利率）家電なら10〜20%、日用品20〜30%、アパレル50%前後仕入原価は店舗小売とほぼ同じ。ネットだから安く仕入れられるわけではない
物流費（対売上）8〜15%が中心。嗜好品・アパレルでは30%超も（民間調査、2025年）1個ずつ箱詰めして個宅へ送る。店舗小売の「まとめてトラック1台」より高くつく
広告宣伝費5〜15%集客をすべて広告で買う場合。→ ネット広告
営業利益率0〜5%。赤字も珍しくない粗利から物流費と広告費を引くと、ほとんど残らない構造
在庫回転年8〜12回転が目安回転が落ちると滞留在庫→値下げ→粗利消滅

直販型の隠れた強み：キャッシュ・コンバージョン・サイクル（CCC）がマイナスになりうる。
消費者はカード決済で即入金、仕入先への支払いは60日後。
つまり 商品が売れるほど手元現金が増える。Amazonが長年、薄利でも投資を続けられた仕組みの一つがこれ。

4. マーケットプレイス型＝「場所貸し」と両面市場

モールは在庫を持たない。売るのは 集客力である。
買い手が多いほど出店者が集まり、出店者が多いほど品揃えが増えて買い手が集まる——
この 両面市場（ネットワーク効果） が参入障壁になる。

出店者が払うコストは1本ではなく、積み上げである点が重要。「手数料◯%」だけを見ると実態を見誤る。

費目 何に対して払うか イメージ（2026年時点の公開料金ベースの概算）
月額出店料場所代（固定費）楽天市場は月額数万円台〜のプラン制。Amazon大口出品は月額4,900円（税抜）、Yahoo!ショッピングは無料
システム利用料・販売手数料売れた金額に対する従量楽天は売上の数%台、Amazonはカテゴリ別に概ね8〜15%
決済手数料カード・コード決済の処理売上の3%前後
ポイント原資・アフィリエイト販促の負担分モール側の販促は実質、出店者が原資を負担する設計が多い
広告費（任意だが実質必須）検索結果の上位表示売上の5〜15%を投じる店も。→ ③ノートのリテールメディア
物流サービス保管・出荷代行AmazonのFBAなど。サイズ・重量で課金
【出店者から見た「手取り」】

 消費者が払う 10,000円
   − 販売手数料・システム利用料  ▼  約 800〜1,500円
   − 決済手数料                  ▼  約 300円
   − ポイント原資・販促負担      ▼  約 300〜1,000円
   − モール内広告               ▼  約 500〜1,500円
   − 送料・梱包・物流           ▼  約 800〜1,500円
   ───────────────────────────────
   残り（商品原価＋自社の粗利）   ≒ 5,000〜7,500円
       ▲ 原価率が50%を超える商材は、モールでは構造的に利益が出にくい

実額は契約プラン・カテゴリ・キャンペーン参加状況で大きく変わる。
正確な数字は各モールの出店案内（公開料金表）で最新版を確認すること。

モール運営側から見ると、この積み上げが テイクレートの上昇余地になる。
GMVが伸びなくても、広告と物流サービスの利用率を上げればテイクレートは上がり、売上は伸びる。
近年のモールの成長は、GMV成長よりテイクレート上昇が主役になりつつある（→ ③ 競争と成長の源泉）。

5. 自社EC型＝カートSaaSとD2C

Shopify・BASE・STORES・futureshop などは、店を作る道具を月額で貸すSaaSである。
モールと違い集客はしてくれない。その代わり手数料は安く、顧客リストは自分のものになる。

サービス 課金の形 向く規模 特徴
BASE初期・月額0円のプランあり。売れた分から手数料月商〜20万円程度の小規模累計190万ショップ規模（同社公表）。始めるコストがほぼゼロ
STORES無料プラン＋有料プラン小〜中規模、実店舗併用POS・予約など店舗側機能と連携
Shopify月額固定＋決済手数料（自社決済なら取引手数料なし）月商数十万円以上〜大規模アプリ連携と越境対応が強い。規模が出るほど割安になる

損益分岐の目安：月商20万円あたりまでは「固定費ゼロ・従量課金」のBASE／STORESが安く、
それを超えると「月額固定・従量低率」のShopifyが有利になる（各社料金表からの試算）。
これは通信や電力の料金プランとまったく同じ構造。

自社ECの本当のコストは月額料金ではなく CAC（顧客獲得単価） である。
モールなら「集客込みで手数料十数%」だが、自社ECは広告を自分で買う。
広告単価が上がれば、手数料を節約したつもりが赤字になる。
D2C（メーカーが直接消費者に売る形）の経済性は 通販・D2C 側で詳しく扱う。

6. モール vs 自社EC：同じ月商1,000万円で比べる

概念を理解するための単純化モデル（実額ではない）。原価率40%、送料は店舗負担と仮定する。

項目 モール出店 自社EC
売上1,000万円1,000万円
商品原価400万円400万円
モール手数料・ポイント原資約130万円0円
カートSaaS・決済手数料（手数料に含む）約40万円
広告費モール内広告 80万円外部広告 200万円
物流費120万円120万円
残る利益約270万円約240万円
顧客データモールが保有（限定的にしか使えない）自社で保有。再購入を安く取れる

同じ月商でも、1回きりの購入ならモールが有利、リピートする商材なら自社ECが有利になる。
サプリ・化粧品・食品など定期購入が成り立つ商材でD2Cが増えたのは、この計算式のためである。

7. 実際は「多店舗運営」になる

現実の事業者はどれか1つを選ばない。モールで認知を取り、自社ECでリピートを回すのが定石。
その結果、在庫・受注・顧客情報をまたいで管理する必要が生まれ、
受注管理システム（OMS）や在庫連携ツールの市場が育っている（→ ソフトウェア・SaaS）。

【よくある構成】

  認知・新規獲得          リピート・利益回収
  ┌──────────────┐      ┌──────────────┐
  │ 楽天市場      │      │ 自社EC        │
  │ Amazon        │──▶  │（Shopify等）  │──▶ 定期購入・LINE・会員
  │ Yahoo!ショッピング │  │               │
  └──────────────┘      └──────────────┘
      手数料は高いが客が    手数料は安いが
      勝手に来る            客は自分で連れてくる
           ▲ 在庫・受注・顧客データを串刺しで見る仕組み（OMS）が必須になる

8. 用語メモ

用語 意味
GMV（流通総額）そのプラットフォーム上で売れた商品代金の合計。会計上の売上ではない
テイクレート売上高÷GMV。プラットフォームの取り分の率
1P／3Pファーストパーティ＝自社在庫の直販、サードパーティ＝出店者による販売
