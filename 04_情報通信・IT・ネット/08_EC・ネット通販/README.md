## 1. 業界の定義・範囲

**EC（電子商取引／eコマース）**＝インターネット等のネットワークを介して行う商取引。
経済産業省の調査では、取引の当事者によって3つに分ける。

```
【ECの守備範囲】

 ┌────────────────────────────────────────────────────┐
 │ BtoC-EC  企業 → 消費者                                 │
 │   物販系：モール、自社EC、ネットスーパー、D2C           │
 │   サービス系：旅行予約、チケット、飲食予約、理美容       │
 │   デジタル系：電子書籍、音楽・動画配信、オンラインゲーム │
 │ BtoB-EC  企業 → 企業（受発注のEDI化、購買サイト）       │
 │ CtoC-EC  個人 → 個人（フリマアプリ、ネットオークション） │
 │ 越境EC   国をまたぐBtoC（SHEIN・Temu、日本発の海外販売） │
 └────────────────────────────────────────────────────┘
      ▲ このフォルダが主に扱うのは「BtoC-ECの物販系」
```

**隣接業界との境界**

- 店舗を持つ小売がネットでも売る場合（ヨドバシ.com、イオン）は、実態としてEC事業だが
  業界統計上は各小売業に分類される。**「EC企業」という業種は存在しない**
- デジタルコンテンツ（配信・ゲーム）は [動画・音楽配信](../12_動画・音楽配信/README.md)、
  [ゲーム](../10_ゲーム/README.md) 側の話題として扱い、ここでは深追いしない
- 旅行・チケットの予約はサービス系EC。取引額は大きいが在庫も物流も持たない別種のビジネス

## 2. 市場規模と成長性

| 指標（日本）      | 2024年             | 前年比                | 出典                                                                |
| ----------------- | ------------------ | --------------------- | ------------------------------------------------------------------- |
| BtoC-EC 全体      | **26兆1,225億円**  | +5.1%                 | 経産省「令和6年度 電子商取引に関する市場調査」（2025年8月26日公表） |
| 　物販系          | **15兆2,194億円**  | +3.7%                 | 同上                                                                |
| 　サービス系      | －                 | **+9.4%**             | 同上                                                                |
| **物販系 EC化率** | **9.78%**          | +0.40pt               | 同上                                                                |
| BtoB-EC           | **514兆4,000億円** | +10.6%（EC化率43.1%） | 同上                                                                |

- **コロナ特需は完全に剥落した**。物販系の成長率は3.7%で、通常の小売と大差ない水準に戻っている
- それでも **EC化率は約10%＝残り90%は店舗**。長期の成長余地はここにある
- 世界では中国・韓国・英国のEC化率が20〜30%台とされ、**日本は先進国の中では低め**
- 2025年実績（令和7年度調査）は例年8〜9月公表。最新値は経産省サイトで確認すること

## 3. バリューチェーン（川上 → 川下）

```
 メーカー ─▶ 卸・商社 ─▶ 【EC事業者】 ─▶ 物流 ─▶ 消費者
                           ▲                ▲
                    ┌──────┴──────┐    ┌────┴────┐
                    │ モール       │    │ 宅配便   │
                    │ 自社EC       │    │ 3PL      │
                    │ カートSaaS   │    │ 倉庫     │
                    │ 決済         │    └─────────┘
                    │ 広告         │
                    └──────────────┘
   付加価値が集まる場所 ──▶ ① 集客（検索結果と広告枠）
                          ② 決済と会員基盤（ポイント経済圏）
                          ③ 物流の元締め（倉庫と配送を握る）
           ▲ 商品そのものの粗利は薄い。「通す場所」を押さえた者が儲かる
```

EC業界の特徴は、**川中（EC事業者）が川下（物流）と川上（メーカー）の両方に食い込んでいる**こと。
Amazonは自社で在庫を持ち（川上化）、自社配送網を持つ（川下化）。
楽天は決済・金融・通信まで広げて顧客接点を囲い込む。
詳しくは [① ECの3つのモデル](01_ECの3つのモデル.md)。

## 4. 主要プレイヤーとシェア

| 企業                                            | 立ち位置                         | 特徴                                                                                                                  |
| ----------------------------------------------- | -------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| **Amazon（アマゾンジャパン）**                  | 直販＋マーケットプレイスの両建て | 日本事業売上 306.88億ドル＝約4兆6,338億円（2025年、+12.0%、報道集計）。GMVは8兆円規模との推計。自社物流と広告が利益源 |
| **楽天グループ**                                | 出店型モールの最大手             | 国内EC流通総額 6兆3,452億円（2025年、+3.9%）。ポイント経済圏で通信・金融と結合                                        |
| **LINEヤフー（Yahoo!ショッピング）**            | 出店無料でロングテール型         | PayPay経済圏と連動。店舗数は多いが1店あたりは小さい                                                                   |
| **ZOZO**                                        | アパレル特化のモール             | 受託販売型。サイズ・コーディネート提案で専門性を作る                                                                  |
| **ヨドバシカメラ／アスクル／ニトリ等**          | 自社EC型（直販）                 | 自社物流と即日配送。実店舗との在庫連携（OMO）                                                                         |
| **イオン（Green Beans／イオンネットスーパー）** | 生鮮EC                           | 専用自動化倉庫（CFC）に長期投資。単年度黒字は2030年度目標                                                             |
| **メルカリ**                                    | CtoC（フリマ）                   | 中古市場を作り、新品ECと需要を分け合う                                                                                |
| **SHEIN／Temu／AliExpress**                     | 中国発の越境EC                   | 極端な低価格。少額免税制度の見直しで前提が変わる                                                                      |
| **Shopify／BASE／STORES**                       | 自社ECの土台を提供するSaaS       | 手数料は安いが集客は自前。BASEは累計190万ショップ規模                                                                 |

> 集中度：3大モール（楽天市場・Amazon・Yahoo!ショッピング）の流通総額は合計 **11.2兆円**、
> 物販系BtoC-ECに対するシェア **73.7%**（2024年、業界メディア集計）。
> 市場全体の伸びを上回っており、**成熟と寡占が同時に進んでいる**。

## 5. 収益モデル・コスト構造

**何で儲けるか**は型によって全く違う。

| 型         | 売上に計上されるもの                             | 主な利益源                                             | 営業利益率の目安   |
| ---------- | ------------------------------------------------ | ------------------------------------------------------ | ------------------ |
| 直販型     | 商品代金の全額                                   | 商品粗利。ただし物流費・広告費で大半が消える           | 0〜5%              |
| モール型   | 手数料・広告・物流サービス（＝GMV×テイクレート） | **広告と物流サービス**。在庫を持たないので利益率が高い | 10〜20%            |
| 自社EC型   | 商品代金の全額                                   | リピート購入によるLTV。CAC次第で赤字にも黒字にもなる   | 0〜15%             |
| カートSaaS | 月額利用料＋決済手数料                           | 継続課金。解約率が命                                   | SaaSの経済性に従う |

**コスト構造の急所（→ [② 物流とコスト構造](02_物流とコスト構造.md)）**

| 費目                       | 対売上の目安                            | 性格                                             |
| -------------------------- | --------------------------------------- | ------------------------------------------------ |
| 商品原価                   | 40〜70%                                 | 変動費。ネットだから安く仕入れられるわけではない |
| **物流費**                 | **8〜15%**（嗜好品・アパレルは30%超も） | 変動費。運賃上昇局面で毎年上がる                 |
| 広告・集客費               | 5〜15%                                  | 自社ECほど重い。モールなら手数料に一部含まれる   |
| モール手数料・ポイント原資 | 10〜15%                                 | モール出店の場合                                 |
| 返品処理                   | 1件1,500〜3,000円                       | 見えにくいが利益を確実に削る                     |
| システム・人件費           | 固定費                                  | 規模拡大で薄まる唯一の費目                       |

> **この業界の核心**：固定費はシステムだけで、**それ以外がほぼ全部変動費**。
> だから「規模が10倍になれば利益率が10倍」にはならない。
> 1注文あたりの経済性（ユニットエコノミクス）が改善しない限り、売上成長は利益成長にならない。

## 6. 競争要因（KSF）と参入障壁

**KSF（成功の鍵）**

1. **集客コストの低さ**：指名検索・アプリ・会員基盤。広告依存を脱した店だけが利益を残す
2. **1出荷あたりの物流単価**：規模、自動化、配送網の選択肢をどれだけ持つか
3. **テイクレートの設計**（モール側）：手数料率ではなく広告・物流・金融で回収する
4. **在庫の精度**：需要予測が外れると値引きか欠品。どちらも粗利を直撃する
5. **リピート構造**：定期購入・会員制。LTVがCACを上回るかどうかが事業の存否
6. **制度対応力**：越境課税、特商法、景表法、物流効率化法。制度が競争条件そのもの

**参入障壁**

| 障壁                             | 強さ         | 理由                                                                                 |
| -------------------------------- | ------------ | ------------------------------------------------------------------------------------ |
| **ネットワーク効果（モール）**   | 極めて強     | 買い手が多いから出店者が集まり、出店者が多いから買い手が来る。後発が入る余地が小さい |
| **物流網**                       | 強           | 倉庫・配送は金と時間がかかる。Amazonの自社配送網は10年以上かけて作られた             |
| **広告在庫（リテールメディア）** | 強           | トラフィックがなければ広告枠は売れない。規模がそのまま参入障壁になる                 |
| 会員・ポイント経済圏             | 中〜強       | ポイント原資を出し続ける体力が要る                                                   |
| **店を開くこと自体**             | **極めて弱** | BASE等で誰でも無料で開店できる。だから店舗数は増え続け、売れない店が大半になる       |

> **非対称な構造**：参入は簡単、生き残りは難しい。
> これがEC業界の店舗数の多さ（BASEだけで190万ショップ規模）と、
> 上位寡占（3大モールで7割超）が同居している理由である。

## 7. 規制・法制度

| 法律・制度                                             | 内容                                                                                                                                            |
| ------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **特定商取引法（通信販売）**                           | 広告表示義務、返品ルール（クーリングオフは原則なし）。2022年6月施行の改正で、**定期購入の最終確認画面の表示義務**と誤認表示に対する取消権を新設 |
| **景品表示法**                                         | 優良誤認・有利誤認の禁止。2023年10月から**ステルスマーケティング規制**が告示指定                                                                |
| **消費者契約法**                                       | 不当な勧誘・不当条項の無効                                                                                                                      |
| **取引DPF消費者保護法**（2022年施行）                  | 取引デジタルプラットフォーム提供者に、販売業者情報の開示請求対応等を求める                                                                      |
| **デジタルプラットフォーム取引透明化法**（2021年施行） | 大規模モール・アプリストアに対し、**出店者への取引条件の開示と国への報告**を義務付ける                                                          |
| **プラットフォーム課税**（2025年4月〜）                | 国外事業者のデジタルサービスについて、プラットフォーム運営者が消費税を申告・納税                                                                |
| **少額輸入の免税（デミニミス）見直し**                 | **2026年度税制改正で個人輸入の免税特例を廃止**し、1万円以下の輸入にも課税する方向と報じられる                                                   |
| **改正物流効率化法**                                   | 2025年4月から荷主に努力義務、**2026年4月から特定事業者にCLO選任・中長期計画提出を義務化**                                                       |
| **個人情報保護法**                                     | 購買履歴の利用、Cookie（個人関連情報）の第三者提供規制                                                                                          |
| **古物営業法**                                         | 中古品を扱う場合に許可が必要（リユースEC）                                                                                                      |
| **食品衛生法・薬機法・酒税法**                         | 生鮮・医薬品・酒類などカテゴリ別の許認可                                                                                                        |

## 8. 最近のトピック

詳細と出典は [④ 直近トピック（2026年9月時点）](04_直近トピック_2026.md)。要点は次の5つ。

- **市場は成熟局面**。2024年の物販系は+3.7%、EC化率9.78%（経産省）。サービス系（+9.4%）が物販を上回った
- **寡占は進行**。Amazon日本事業は2025年に+12.0%（約4.6兆円）と市場平均の3倍で伸び、3大モールで物販系の73.7%
- **越境ECの前提が変わる**。2026年度税制改正で1万円以下の輸入免税を廃止する方向。米国は2025年8月、EUは2026年7月に廃止
- **物流は運賃上昇と法規制の二重圧力**。ヤマトが2025年10月に個人向け約10%値上げ、2026年4月から荷主にCLO選任義務。一方で再配達率は8.3%まで低下（2025年10月）
- **エージェンティックコマースの台頭**。ChatGPT Instant Checkout（2025年9月）、Google×ShopifyのUCP、楽天のRakuten AI（2026年1月）。**回遊を前提にした広告モデルが揺らぐ可能性**
