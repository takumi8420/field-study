# ② 物流とコスト構造（ECの利益は物流費と返品で決まる）

このノートで分かること：ECの勝敗を決めるのは商品力でも価格でもなく、**1個あたりいくらで届けて、何%返ってくるか**。
売上が伸びても物流費と返品が比例して増えるため、**規模だけでは利益が出ない**のがこの業界の宿命である。

## 1. 結論：ECは「小口・個宅・返品あり」の物流を背負った小売業

店舗小売は、トラック1台で1店舗にまとめて運び、あとは客が自分で持ち帰る。
ECは **1注文ごとに人が棚から拾い、箱に詰め、1軒ずつ届ける**。ここに構造的なコスト差がある。

```
【同じ1万円を売るときの物流の違い】

■ 店舗小売
  工場 ─▶ 物流センター ─▶ 店舗（パレット単位） ─▶ 客が持ち帰る
                          ▲ ここまでで物流は終わり。ラストワンマイルは客の負担

■ EC
  工場 ─▶ 物流センター ─▶ 【ピッキング→検品→梱包】 ─▶ 宅配便 ─▶ 個人宅
                          ▲ 1点ずつ人手            ▲ 1軒ずつ  ▲ 不在なら再配達
                                                              ▲ 気に入らなければ返品
```

> ポイント：ECの物流費は「売上に比例する変動費」であり、しかも**単価が年々上がっている**。
> だからEC事業者の利益率は、売上成長より運賃改定のほうに強く反応する。

## 2. EC物流の工程と、どこに金がかかるか

物流費を「送料」だけだと思っていると読み違える。実際は **庫内作業費＋配送費＋返品処理費** の3層である。

| 工程                 | 中身                                 | コストの性格                   | 削り方                                                        |
| -------------------- | ------------------------------------ | ------------------------------ | ------------------------------------------------------------- |
| **入庫・保管**       | 入荷検品、棚入れ、在庫保管           | 面積×日数の固定費              | 在庫回転を上げる。長期滞留は保管料が利益を食う                |
| **ピッキング**       | 注文ごとに棚から商品を拾う           | **人件費。EC物流最大の変動費** | 棚の配置最適化、GTP（棚が人のところへ来る）ロボット、自動倉庫 |
| **梱包・検品**       | 箱選定、緩衝材、伝票貼付             | 人件費＋資材費                 | 箱サイズの最適化（＝運賃のサイズ区分が下がる）                |
| **幹線輸送**         | センター間の移動                     | トラック運賃                   | 共同配送、モーダルシフト                                      |
| **ラストワンマイル** | 宅配便で個人宅へ                     | **1個あたり数百円の変動費**    | 置き配、宅配ボックス、コンビニ・ロッカー受取                  |
| **返品処理**         | 引き取り、検品、再販可否判定、再梱包 | **見えにくいが重い**           | 返品率そのものを下げる（写真・サイズ表記の改善）              |

## 3. 数字で見るコスト構造

| 指標                                     | 水準                                                                    | 出典・注記                                                                |
| ---------------------------------------- | ----------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| 物流費の対売上比率                       | **8〜15%** が中心。嗜好品・アパレル・アウトドアでは **30%超**が半数以上 | 民間のEC事業者調査（2025年、業界メディア報道ベース）                      |
| 食品・飲料                               | 10%以下の事業者が最多                                                   | 同上。単価に対し重量・体積が大きいが、まとめ買いで1配送あたりの点数が多い |
| 返品1件あたりの処理コスト                | **1,500〜3,000円程度**（送料往復＋検品＋再梱包）                        | 物流事業者の実務資料（推計）                                              |
| EC全体の返品率                           | 平均 **2%台**。アパレルは一桁後半〜20%台になることも                    | 業界推計。カテゴリ差が非常に大きい                                        |
| 宅配便取扱個数（国内）                   | 約 **50億個**（2024年度＝令和6年度、国土交通省）                        | EC成長とほぼ連動して増え続けている                                        |
| 再配達率                                 | **約8.3%**（2025年10月調査、国土交通省）                                | 2022年10月の約11.8%から継続的に低下                                       |
| 宅配会員サービス（置き配指定等）の利用率 | **約34.9%**（2025年9月時点、国土交通省調査）                            | 置き配の常態化が再配達率低下の主因とされる                                |

```
【EC事業者のP/Lを「1万円の注文」で分解した例】

  売上           10,000円  ████████████████████████████████████████
  商品原価       -4,000円  ████████████████
  広告費         -1,500円  ██████
  モール手数料等 -1,300円  █████
  庫内作業・資材   -500円  ██
  配送費           -700円  ███
  返品コスト       -200円  █    ← 返品率5%×往復4,000円 ≒ 1件あたり200円
  決済・その他     -400円  ██
  ───────────────────────────
  営業利益        1,400円  （利益率14%）※ 概念理解のための単純化モデル
        ▲ 配送費が100円上がると利益は7%減る。返品率が5%→10%になると利益は14%減る
```

> **ここが要点**：物流費と返品はどちらも「売れるほど増える」。
> 一方、システム費やブランド構築費は固定費。だからECは
> **固定費を吸収できるまでは規模拡大が効くが、そこから先は1個あたりの物流単価を下げないと利益が伸びない**。

## 4. 「送料無料」の罠

日本のECで最大の歪みが送料である。消費者は「送料無料」に強く反応するが、
**運賃が消えるわけではなく、誰かが払っている**。多くは商品価格か出店者の粗利に埋め込まれる。

| やり方                                | 実態                                        | 副作用                                                               |
| ------------------------------------- | ------------------------------------------- | -------------------------------------------------------------------- |
| 完全送料無料                          | 商品価格に運賃を上乗せ                      | 低単価品が成立しなくなる。単価の高い商品ほど有利になり、品揃えが歪む |
| **送料無料ライン**（例：3,980円以上） | まとめ買いを促し、1配送あたりの点数を増やす | 客単価は上がる。ラインに届かせるための「ついで買い」在庫が必要       |
| 有料配送・翌日配送オプション          | 速さに課金する                              | 速さを求めない客の運賃負担が減り、全体は健全化する                   |
| 会員制（年会費で配送込み）            | 年会費に運賃を織り込む                      | 使うほど得になるので購入頻度が上がる（＝LTV向上）                    |

「送料無料ライン」は、運賃が **1配送あたりでかかる**（商品点数にはあまり依存しない）性質を使った合理的な設計である。
1件1万円の注文なら配送費700円は7%だが、1件2,000円の注文だと35%になってしまう。
**低単価・単品購入はEC最大の赤字要因**で、ここを避けるのが送料設計の目的である。

なお送料表示については、国が「送料無料」という表示が運賃転嫁を妨げるとして見直しを呼びかけた経緯がある
（2023年以降、国土交通省・公正取引委員会などの取り組み）。Amazonは「送料込み」といった表現へ切り替えた。

## 5. ラストワンマイルと置き配

ECの荷物は最終的に宅配便に乗る。つまりEC事業者の運命は **宅配便の運賃と capacity（積載能力）** に握られている。
詳しくは [宅配便](../../13_運輸・物流/07_宅配便/README.md)、[陸運・トラック](../../13_運輸・物流/06_陸運・トラック/README.md) を参照。

```
【ラストワンマイルの選択肢】

  配送拠点
    ├─▶ 対面手渡し ……… 再配達リスクあり。1回で届かないとコストが倍になる
    ├─▶ 置き配 ………… 玄関前・宅配ボックス。再配達率低下の最大要因
    ├─▶ コンビニ受取 … 客が取りに来る。事業者側は配送1回で確実に完了
    ├─▶ 駅・街のロッカー … 同上。都市部で拡大
    └─▶ 自社配送網 …… Amazonのデリバリープロバイダ等。宅配便に依存しない選択
          ▲ 「再配達をなくす」＝ドライバー1人あたりの配達個数を増やす＝運賃上昇を抑える
```

**2024年問題とその後**：トラックドライバーの時間外労働上限規制（2024年4月適用）で輸送能力が不足し、
運賃は構造的な上昇局面に入った。ヤマト運輸は2025年10月に個人向け宅急便を平均約10%値上げ（同社発表）、
佐川急便も2026年4月に料金改定を実施したと報じられる。
さらに **改正物流効率化法により2026年4月から、一定規模以上の荷主（年間取扱9万トン以上）に
中長期計画の提出・定期報告・物流統括管理者（CLO）の選任が義務化**された。
EC事業者は「運賃を払えば運んでもらえる」立場から、**自ら効率化の当事者になることを法律で求められる**側に変わった。

## 6. 在庫回転と欠品——見えないコストの本体

物流費と並ぶもう一つの利益要因が在庫である。ECは棚のスペース制約がないぶん品揃えを増やしやすく、
その結果 **売れない在庫を抱えやすい**。

| 指標             | 意味                                           | 悪化するとどうなるか                                                    |
| ---------------- | ---------------------------------------------- | ----------------------------------------------------------------------- |
| **在庫回転率**   | 年間売上原価÷平均在庫。年8〜12回転が一つの目安 | 落ちると保管料が積み上がり、最後は値引き処分で粗利が消える              |
| **欠品率**       | 注文できない状態の割合                         | 売り逃しに加え、モールの検索順位が下がり将来の売上も失う                |
| **ロングテール** | 少量ずつ売れる多数の商品                       | 品揃えの武器だが、**1点ずつ保管料と作業費がかかる**ので無限には持てない |
| **消化率**       | シーズン内に定価で売れた割合                   | アパレルで特に重要。低いとセール依存になる                              |

> 欠品と過剰在庫はトレードオフ。**需要予測の精度がそのまま利益率になる**ため、
> 大手は需要予測と自動発注に投資する。ここが近年AI活用の最前線になっている
> （→ [生成AI](../../01_注目テーマ/01_生成AI/README.md)）。

## 7. 自前でやるか、任せるか（フルフィルメント）

**フルフィルメント**＝受注から出荷・返品対応までの一連の業務。選択肢は3つある。

| 方式                                  | 内容                                   | 向くケース                         | 弱点                                                                                  |
| ------------------------------------- | -------------------------------------- | ---------------------------------- | ------------------------------------------------------------------------------------- |
| **自社倉庫**                          | 自分で借りて自分で回す                 | 月間出荷数が多く、特殊な梱包が必要 | 固定費。繁閑差でムダが出る                                                            |
| **3PL／発送代行**                     | 物流会社に委託し、出荷個数に応じて課金 | 中小〜中堅。繁閑差が大きい         | 変動費化できるが単価は高め。→ [倉庫・3PL](../../13_運輸・物流/08_倉庫・3PL/README.md) |
| **モールのフルフィルメント（FBA等）** | モールの倉庫に預ける                   | Amazon中心に売る場合               | 手数料が改定されると利益が直撃される。在庫がモールに縛られる                          |

大手は倉庫の自動化（GTPロボット、自動梱包機）に投資するが、
**自動化は固定費を増やすので、出荷量が読めないと逆効果**になる。
「物流を自動化すれば安くなる」は半分しか正しくない。

## 8. 用語メモ

| 用語                       | 意味                                                                             |
| -------------------------- | -------------------------------------------------------------------------------- |
| **フルフィルメント**       | 受注・在庫管理・ピッキング・梱包・出荷・返品対応までの一連の業務                 |
| **ピッキング**             | 注文に応じて棚から商品を取り出す作業。EC庫内で最も人手がかかる                   |
| **GTP（Goods To Person）** | 人が棚へ行くのではなく、ロボットが棚を人のところへ運ぶ方式                       |
| **ラストワンマイル**       | 配送拠点から受取人の玄関までの最終区間。もっとも高コスト                         |
| **置き配**                 | 対面せず玄関前・宅配ボックス等に置く配達方法                                     |
| **再配達率**               | 宅配便のうち1回で届かなかった割合。国交省が年2回サンプル調査                     |
| **3PL**                    | Third Party Logistics。物流業務を一括して外部に委託する形態                      |
| **リバースロジスティクス** | 返品・回収など逆向きの物流                                                       |
| **2024年問題**             | トラックドライバーの時間外労働上限規制（2024年4月適用）による輸送能力不足        |
| **CLO**                    | 物流統括管理者。改正物流効率化法で特定事業者に選任が義務付けられた役員級の責任者 |
| **在庫回転率**             | 年間売上原価÷平均在庫。高いほど資金効率がよい                                    |
| **送料無料ライン**         | 一定金額以上の購入で送料を無料にする設定。客単価を引き上げる仕組み               |
