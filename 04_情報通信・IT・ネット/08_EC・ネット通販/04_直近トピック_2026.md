## 1. 市場データ：BtoC-ECは26.1兆円、EC化率9.78%（2024年実績）

経済産業省「**令和6年度 電子商取引に関する市場調査**」（2025年8月26日公表）が、
2026年9月時点で参照できる直近の公式統計である（1998年度から毎年実施、今回で27回目）。

| 区分          | 2024年                     | 前年比                         |
| ------------- | -------------------------- | ------------------------------ |
| BtoC-EC 全体  | **26兆1,225億円**          | +5.1%（2023年 24兆8,435億円）  |
| 　物販系      | **15兆2,194億円**          | +3.7%                          |
| 　サービス系  | （旅行・飲食・チケット等） | **+9.4%**                      |
| 物販系 EC化率 | **9.78%**                  | +0.40pt                        |
| BtoB-EC       | **514兆4,000億円**         | +10.6%（EC化率 43.1%、+3.1pt） |

読みどころは **物販系の伸びが3.7%まで落ち着き、サービス系（9.4%）に抜かれた**こと。
コロナ期の「巣ごもり特需」が完全に剥落し、物販ECは一般的な小売と同じ成熟した成長率に戻った。
一方でサービス系は旅行需要の回復で伸びており、**EC＝物販という前提が実態と合わなくなっている**。

> 2025年実績（令和7年度調査）は例年8〜9月に公表される。最新値は経産省の
> 「電子商取引実態調査」ページで確認すること（下記参考リンク）。

## 3. 越境ECの「免税廃止」：2026年度税制改正で価格前提が変わる

SHEIN・Temuなど中国発ECの低価格を支えてきた **1万円以下の少額輸入の免税**が、
日本でも見直される。2026年度税制改正で個人輸入の免税特例を廃止し、
**1万円以下の輸入にも消費税を課す**方向で制度設計が進んでいると報じられる。

- 日本の1万円以下の輸入は **1億6,966万件・4,258億円**（2024年）で、5年で約5倍に拡大（報道）
- **販売額50億円超のプラットフォームに納税義務**を課す案が報じられている（日本経済新聞）
- 国際的には **米国が2025年8月にデミニミス免税を廃止**、**EUは2026年7月1日から廃止**を決定
- 先行して、デジタルサービスには **2025年4月1日からプラットフォーム課税**が適用済み

> 意味するところ：これは値下げ競争への対抗ではなく **制度の非対称性の是正**である。
> 国内事業者は消費税10%を負担して売っていたのに、越境直送は免税だった。
> 制度が揃えば価格差は縮むが、製造原価と広告効率の差は残るため、国内勢が自動的に勝つわけではない。
> 詳しくは [③ 競争と成長の源泉](03_競争と成長の源泉.md) の5章。

## 4. 物流：運賃の構造的上昇と、2026年4月からの荷主義務

ECの利益を直接削るコスト側で、2つの変化が同時に起きている。

**(a) 運賃の上昇が「毎年の前提」になった**

- ヤマト運輸：2025年10月に個人向け宅急便を平均約10%値上げ（届出運賃も120〜200サイズで約3.5%改定）
- 佐川急便：2026年4月に資材を含む料金改定を実施したと報じられる
- 国土交通省の標準的運賃も引き上げ方向

**(b) 改正物流効率化法の本体部分が2026年4月に施行**

| 対象                                                | 義務                                                                             |
| --------------------------------------------------- | -------------------------------------------------------------------------------- |
| すべての荷主・物流事業者                            | 積載効率の向上、荷待ち時間・荷役時間の短縮（努力義務、2025年4月〜）              |
| **特定事業者**（年間取扱貨物9万トン以上の荷主など） | **中長期計画の作成・提出、定期報告、物流統括管理者（CLO）の選任**（2026年4月〜） |

一方、再配達は改善が続いている。国交省の調査では **2025年10月の再配達率は約8.3%**
（2022年10月の約11.8%から継続的に低下）。**置き配を含む宅配会員サービスの利用率は約34.9%**（2025年9月時点）。
宅配便の取扱個数は **2024年度で約50億個**。

> 構図：**運賃は上がるが、効率は改善している**。
> 置き配の定着で1回あたりの配達成功率が上がり、値上げ幅がそのままEC事業者の負担増にはなっていない。
> ただし法改正で、EC事業者（荷主）自身が効率化の当事者として計画と報告を求められる立場に変わった。

## 5. エージェンティックコマース：AIが「代わりに買う」流れ

2025〜2026年にかけて、購買行動が「検索」から「**委任**」へ移りうる変化が始まった。

| 出来事                                 | 時期                        | 内容                                                                               |
| -------------------------------------- | --------------------------- | ---------------------------------------------------------------------------------- |
| ChatGPT **Instant Checkout**           | 2025年9月発表               | Stripeと提携し、ChatGPTの会話内で購入まで完結。米国でEtsy・Shopify商品などから開始 |
| **UCP**（Universal Commerce Protocol） | 2025〜2026年                | GoogleとShopifyが、AIエージェントとEC決済システムを繋ぐ標準仕様として発表          |
| **Rakuten AI**                         | 2026年1月                   | 楽天が「楽天市場」アプリにエージェント型AIツールを搭載                             |
| Yahoo!ショッピング                     | 2026年                      | AI対話による商品提案・比較機能を拡充                                               |
| 楽天「AI店長」                         | 2026年8月の決算説明会で言及 | 出店者側の運営をAIが支援する構想                                                   |

```
【購買導線が変わる】

 これまで：  検索する ─▶ 比較する ─▶ カート ─▶ 決済
             （人がモールの中を回遊する＝広告を見る＝モールが儲かる）

 これから：  AIに頼む ─▶ AIが比較 ─▶ AIがカート ─▶ 人は承認だけ
             （回遊が消える。検索結果の広告枠を誰が見るのか？）
                   ▲ リテールメディア（③ノート4章）の前提が揺らぐ可能性
```

> 論点：**AIが買い手の代理人になると、モールの広告収入モデルと衝突する**。
> 一方で商品データを構造化して外部AIに読ませる必要が出てくるため、
> 「囲い込み」と「開放」のどちらを取るかが各社の分かれ目になる。まだ答えは出ていない。
> 技術側の全体像は [生成AI](../../01_注目テーマ/01_生成AI/README.md) を参照。

## 6. 生鮮EC：Green Beansは2030年度黒字を目指す長期戦

イオンのネット専用スーパー「Green Beans」は2023年7月に首都圏で本格開始し、
**2年で会員60万人を突破**（2025年、流通ニュース報道）。平均客単価は約1万円と高い。

- 八王子CFC（専用自動化倉庫）が **2026年度**に稼働予定
- 埼玉・久喜宮代CFCが **2027年度頃**に稼働予定
- 会員100万人を2025年度末目標、**単年度黒字は2030年度目標**

生鮮ECは「開始から7年かけて黒字化を目指す」設計であり、
**小売事業というより巨額の設備投資を回収するインフラ事業**として見るのが正しい。

## 7. リテールメディアの拡大

国内リテールメディア広告市場は **2025年 6,066億円 → 2029年 1兆3,174億円**との予測（民間調査）。
うちEC事業者分が5,236億円、店舗事業者分が830億円（デジタル広告620億円＋サイネージ210億円、
CARTA HOLDINGS調査・2026年1月公表）。
Amazon Adsは2026年第4四半期以降、Prime Video向けの新広告フォーマット（ポーズ広告など）を提供予定と発表している。

**EC事業者が広告会社としての顔を強めている**のが2026年の姿であり、
商品を売る利益より広告の利益のほうが率が高い構造は当面変わらない。

## 9. 全体の構図（まとめ）

1. **市場は成熟した**。物販系EC化率9.78%・成長率3.7%（2024年）で、もはや「急成長産業」ではない
2. **それでも寡占は進む**。3大モールが物販系の7割超。Amazonは日本で+12%と市場平均の3倍で伸びた
3. **利益の源泉は商品からサービスへ移った**。広告（リテールメディア）・物流サービス・会員費でテイクレートを上げる
4. **コスト側は法と運賃が主役**。運賃は構造的上昇局面、2026年4月から荷主にCLO選任等の義務
5. **制度が競争条件を書き換える**。越境ECの少額免税廃止で、価格の非対称性が是正される方向
6. **次の不確実性はAI**。エージェント経由の購買が広がれば、回遊を前提にした広告モデルが揺らぐ

## 10. 用語メモ

| 用語                                     | 意味                                                                                 |
| ---------------------------------------- | ------------------------------------------------------------------------------------ |
| **令和6年度 電子商取引に関する市場調査** | 経産省が毎年公表するEC市場の公式統計。BtoC/BtoB/CtoC・越境ECを対象                   |
| **エージェンティックコマース**           | AIエージェントが検索・比較・購入までを代行する購買形態                               |
| **Instant Checkout**                     | ChatGPT内で購入を完結させる機能（2025年9月発表、Stripe提携）                         |
| **UCP**                                  | Universal Commerce Protocol。AIエージェントとEC決済を繋ぐ標準仕様（Google・Shopify） |
| **デミニミス（少額免税）**               | 一定額以下の輸入品を免税とする制度。日本は1万円以下が対象で、廃止が進む              |
| **CLO**                                  | 物流統括管理者。改正物流効率化法で特定事業者に選任義務（2026年4月〜）                |
| **CFC**                                  | ネットスーパー専用の自動化フルフィルメントセンター                                   |
| **Non-GAAP営業利益**                     | 会計基準上の利益から一時的要因等を調整した、事業実態を示す利益指標                   |
