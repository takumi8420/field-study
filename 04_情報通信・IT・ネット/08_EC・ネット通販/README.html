このフォルダの読み方

EC（電子商取引）を 産業として 理解するためのノート群。
ネット企業に見えるが、経済の実体は 小売型＝1注文あたりの経済性 で動いている業界なので、
「1件売れたときに誰にいくら入るか」「その1件を届けるのにいくらかかるか」という2軸で骨格を作り、
そこに「プラットフォームの両面市場」というIT・ネット型の論点を重ねた。

ノート 内容
① ECの3つのモデル直販型（Amazon自社在庫）／マーケットプレイス型（楽天・出店料とテイクレート）／自社EC（Shopify・BASE）、GMVと売上高の違い、手数料の内訳、モール vs 自社ECの経済性比較
② 物流とコスト構造ECの利益を決めるのは物流費と返品。フルフィルメントの工程別コスト、送料無料の罠、置き配とラストワンマイル、2024年問題と改正物流効率化法、在庫回転と欠品
③ 競争と成長の源泉EC化率という指標、主要プレイヤーの構図、リテールメディア（広告が利益源になる構造）、SHEIN・Temuの攻勢と少額免税、生鮮ECが難しい理由、定期購入とD2C
④ 直近トピック（2026年9月時点）経産省調査の最新値、Amazon+12%と楽天のテイクレート改善、越境EC免税廃止、運賃上昇とCLO義務化、エージェンティックコマース、Green Beans、リテールメディア市場

ブランド側のマーケティングは 通販・D2C 側に置く。
ここでは「EC事業者にとってそれが何を意味するか」に絞る。

1. 業界の定義・範囲

EC（電子商取引／eコマース）＝インターネット等のネットワークを介して行う商取引。
経済産業省の調査では、取引の当事者によって3つに分ける。

【ECの守備範囲】

 ┌────────────────────────────────────────────────────┐
 │ BtoC-EC  企業 → 消費者                                 │
 │   物販系：モール、自社EC、ネットスーパー、D2C           │
 │   サービス系：旅行予約、チケット、飲食予約、理美容       │
 │   デジタル系：電子書籍、音楽・動画配信、オンラインゲーム │
 │ BtoB-EC  企業 → 企業（受発注のEDI化、購買サイト）       │
 │ CtoC-EC  個人 → 個人（フリマアプリ、ネットオークション） │
 │ 越境EC   国をまたぐBtoC（SHEIN・Temu、日本発の海外販売） │
 └────────────────────────────────────────────────────┘
      ▲ このフォルダが主に扱うのは「BtoC-ECの物販系」

隣接業界との境界

  • 店舗を持つ小売がネットでも売る場合（ヨドバシ.com、イオン）は、実態としてEC事業だが
    業界統計上は各小売業に分類される。「EC企業」という業種は存在しない
  • デジタルコンテンツ（配信・ゲーム）は 動画・音楽配信、
    ゲーム 側の話題として扱い、ここでは深追いしない
  • 旅行・チケットの予約はサービス系EC。取引額は大きいが在庫も物流も持たない別種のビジネス

3. バリューチェーン（川上 → 川下）

 メーカー ─▶ 卸・商社 ─▶ 【EC事業者】 ─▶ 物流 ─▶ 消費者
                           ▲                ▲
                    ┌──────┴──────┐    ┌────┴────┐
                    │ モール       │    │ 宅配便   │
                    │ 自社EC       │    │ 3PL      │
                    │ カートSaaS   │    │ 倉庫     │
                    │ 決済         │    └─────────┘
                    │ 広告         │
                    └──────────────┘
   付加価値が集まる場所 ──▶ ① 集客（検索結果と広告枠）
                          ② 決済と会員基盤（ポイント経済圏）
                          ③ 物流の元締め（倉庫と配送を握る）
           ▲ 商品そのものの粗利は薄い。「通す場所」を押さえた者が儲かる

EC業界の特徴は、川中（EC事業者）が川下（物流）と川上（メーカー）の両方に食い込んでいること。
Amazonは自社で在庫を持ち（川上化）、自社配送網を持つ（川下化）。
楽天は決済・金融・通信まで広げて顧客接点を囲い込む。
詳しくは ① ECの3つのモデル。

4. 主要プレイヤーとシェア

企業 立ち位置 特徴
Amazon（アマゾンジャパン）直販＋マーケットプレイスの両建て日本事業売上 306.88億ドル＝約4兆6,338億円（2025年、+12.0%、報道集計）。GMVは8兆円規模との推計。自社物流と広告が利益源
楽天グループ出店型モールの最大手国内EC流通総額 6兆3,452億円（2025年、+3.9%）。ポイント経済圏で通信・金融と結合
LINEヤフー（Yahoo!ショッピング）出店無料でロングテール型PayPay経済圏と連動。店舗数は多いが1店あたりは小さい
ZOZOアパレル特化のモール受託販売型。サイズ・コーディネート提案で専門性を作る
ヨドバシカメラ／アスクル／ニトリ等自社EC型（直販）自社物流と即日配送。実店舗との在庫連携（OMO）
イオン（Green Beans／イオンネットスーパー）生鮮EC専用自動化倉庫（CFC）に長期投資。単年度黒字は2030年度目標
メルカリCtoC（フリマ）中古市場を作り、新品ECと需要を分け合う
SHEIN／Temu／AliExpress中国発の越境EC極端な低価格。少額免税制度の見直しで前提が変わる
Shopify／BASE／STORES自社ECの土台を提供するSaaS手数料は安いが集客は自前。BASEは累計190万ショップ規模

集中度：3大モール（楽天市場・Amazon・Yahoo!ショッピング）の流通総額は合計 11.2兆円、
物販系BtoC-ECに対するシェア 73.7%（2024年、業界メディア集計）。
市場全体の伸びを上回っており、成熟と寡占が同時に進んでいる。

5. 収益モデル・コスト構造

何で儲けるかは型によって全く違う。

型 売上に計上されるもの 主な利益源 営業利益率の目安
直販型商品代金の全額商品粗利。ただし物流費・広告費で大半が消える0〜5%
モール型手数料・広告・物流サービス（＝GMV×テイクレート）広告と物流サービス。在庫を持たないので利益率が高い10〜20%
自社EC型商品代金の全額リピート購入によるLTV。CAC次第で赤字にも黒字にもなる0〜15%
カートSaaS月額利用料＋決済手数料継続課金。解約率が命SaaSの経済性に従う

コスト構造の急所（→ ② 物流とコスト構造）

費目 対売上の目安 性格
商品原価40〜70%変動費。ネットだから安く仕入れられるわけではない
物流費8〜15%（嗜好品・アパレルは30%超も）変動費。運賃上昇局面で毎年上がる
広告・集客費5〜15%自社ECほど重い。モールなら手数料に一部含まれる
モール手数料・ポイント原資10〜15%モール出店の場合
返品処理1件1,500〜3,000円見えにくいが利益を確実に削る
システム・人件費固定費規模拡大で薄まる唯一の費目

この業界の核心：固定費はシステムだけで、それ以外がほぼ全部変動費。
だから「規模が10倍になれば利益率が10倍」にはならない。
1注文あたりの経済性（ユニットエコノミクス）が改善しない限り、売上成長は利益成長にならない。

6. 競争要因（KSF）と参入障壁

KSF（成功の鍵）

  1. 集客コストの低さ：指名検索・アプリ・会員基盤。広告依存を脱した店だけが利益を残す
  2. 1出荷あたりの物流単価：規模、自動化、配送網の選択肢をどれだけ持つか
  3. テイクレートの設計（モール側）：手数料率ではなく広告・物流・金融で回収する
  4. 在庫の精度：需要予測が外れると値引きか欠品。どちらも粗利を直撃する
  5. リピート構造：定期購入・会員制。LTVがCACを上回るかどうかが事業の存否
  6. 制度対応力：越境課税、特商法、景表法、物流効率化法。制度が競争条件そのもの

参入障壁

障壁 強さ 理由
ネットワーク効果（モール）極めて強買い手が多いから出店者が集まり、出店者が多いから買い手が来る。後発が入る余地が小さい
物流網強倉庫・配送は金と時間がかかる。Amazonの自社配送網は10年以上かけて作られた
広告在庫（リテールメディア）強トラフィックがなければ広告枠は売れない。規模がそのまま参入障壁になる
会員・ポイント経済圏中〜強ポイント原資を出し続ける体力が要る
店を開くこと自体極めて弱BASE等で誰でも無料で開店できる。だから店舗数は増え続け、売れない店が大半になる

非対称な構造：参入は簡単、生き残りは難しい。
これがEC業界の店舗数の多さ（BASEだけで190万ショップ規模）と、
上位寡占（3大モールで7割超）が同居している理由である。

法律・制度 内容
特定商取引法（通信販売）広告表示義務、返品ルール（クーリングオフは原則なし）。2022年6月施行の改正で、定期購入の最終確認画面の表示義務と誤認表示に対する取消権を新設

8. 最近のトピック

詳細と出典は ④ 直近トピック（2026年9月時点）。要点は次の5つ。

  • 市場は成熟局面。2024年の物販系は+3.7%、EC化率9.78%（経産省）。サービス系（+9.4%）が物販を上回った
  • 寡占は進行。Amazon日本事業は2025年に+12.0%（約4.6兆円）と市場平均の3倍で伸び、3大モールで物販系の73.7%
  • 越境ECの前提が変わる。2026年度税制改正で1万円以下の輸入免税を廃止する方向。米国は2025年8月、EUは2026年7月に廃止
  • 物流は運賃上昇と法規制の二重圧力。ヤマトが2025年10月に個人向け約10%値上げ、2026年4月から荷主にCLO選任義務。一方で再配達率は8.3%まで低下（2025年10月）
  • エージェンティックコマースの台頭。ChatGPT Instant Checkout（2025年9月）、Google×ShopifyのUCP、楽天のRakuten AI（2026年1月）。回遊を前提にした広告モデルが揺らぐ可能性
