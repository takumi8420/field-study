# ③ 競争と成長の源泉（EC化率・越境EC・リテールメディア）

このノートで分かること：ECの成長は「まだECになっていない買い物」をどれだけ取れるかで決まる（＝**EC化率**）。
そして利益を実際に生んでいるのは商品の粗利ではなく、**広告（リテールメディア）と定期購入**である。

## 1. 市場の全体像——まずEC化率を掴む

**EC化率**＝すべての商取引のうち、ネット経由で行われた割合。
日本のBtoC物販は約10%で、**残り90%はまだ店舗**。この「余白」がEC業界の成長期待の正体である。

| 指標（日本）             | 2024年                                         | 前年                   | 出典                                                                |
| ------------------------ | ---------------------------------------------- | ---------------------- | ------------------------------------------------------------------- |
| BtoC-EC 市場規模（全体） | **26兆1,225億円**                              | 24兆8,435億円（+5.1%） | 経産省「令和6年度 電子商取引に関する市場調査」（2025年8月26日公表） |
| うち物販系               | **15兆2,194億円**（+3.7%）                     | 14兆6,760億円          | 同上                                                                |
| **物販系のEC化率**       | **9.78%**（+0.40pt）                           | 9.38%                  | 同上                                                                |
| サービス系               | 旅行・チケット等。**+9.4%**と物販より高成長    | －                     | 同上                                                                |
| BtoB-EC                  | **514兆4,000億円**（+10.6%）／EC化率 **43.1%** | 465.2兆円              | 同上                                                                |

> 数字の読み方：**BtoBのほうが桁違いに大きく、EC化率も4割を超えている**。
> 「EC＝消費者向け」というイメージは市場規模で見ると少数派で、
> 金額の主役は企業間取引のオンライン化（EDI・受発注システム）である。

物販系の内訳（2024年、経産省調査）は上位4カテゴリがいずれも2兆円超。

| カテゴリ                   | 市場規模     | 特徴                                                                                |
| -------------------------- | ------------ | ----------------------------------------------------------------------------------- |
| 食品、飲料、酒類           | 3兆1,163億円 | 金額は最大だが**EC化率は最も低い部類**。生鮮の難しさ（→6章）                        |
| 衣類・服装雑貨等           | 2兆7,980億円 | EC化率が高い一方、**返品率も高い**（→ [②物流とコスト構造](02_物流とコスト構造.md)） |
| 生活家電・AV機器・PC等     | 2兆7,443億円 | 型番商品で比較しやすく、EC化率が最も高い層                                          |
| 生活雑貨、家具、インテリア | 2兆5,616億円 | 大型・重量物の配送コストが課題                                                      |

```
【EC化率が高い商材／低い商材】

 高い ◀────────────────────────────────────────────▶ 低い
 家電・PC   書籍・CD   アパレル   化粧品   日用品   食品・生鮮
 （型番で   （規格品） （サイズ   （リピート）（低単価・（鮮度・温度管理・
  比較可能）            不安あり）           重い）   低単価）

 決め手：① 型番で比較できるか ② 実物を見なくても不安がないか
        ③ 単価が配送費に対して十分高いか ④ 温度・鮮度の管理が要らないか
```

3大モール（楽天市場・Amazon・Yahoo!ショッピング）の流通総額は **合計11.2兆円、前年比+13.0%**、
物販系BtoC-EC全体に対するシェアは **73.7%**（2024年、業界メディア集計）。
市場全体の伸び（+3.7%）を大きく上回っており、**寡占が進んでいる**ことを意味する。

## 3. 利益の源泉はどこに移ったか

EC事業者の利益構造は、この10年で「商品の粗利」から「**手数料以外の収益**」へ移った。

```
【モール運営者の収益の重心の変化】

 2010年代前半          2020年代後半
 ┌──────────┐        ┌──────────┐
 │ 出店料    │        │ 出店料    │  ← ほぼ横ばい
 │ 販売手数料 │  ──▶  │ 販売手数料 │  ← 料率は上げにくい（出店者が逃げる）
 └──────────┘        │ 物流サービス│  ← FBA等。使わせるほど固定化
                      │ 決済・金融 │  ← 後払い、出店者向け融資
                      │ ★広告     │  ← 最大の伸び。粗利率が極めて高い
                      │ 会員費    │  ← Prime等。継続課金
                      └──────────┘
       ▲ GMVが伸びなくても「テイクレートを上げれば」売上と利益は伸びる
```

## 4. リテールメディア——EC企業が広告会社になる

**リテールメディア**＝小売・EC事業者が自社の購買データと売り場（サイト・アプリ・店頭サイネージ）を
広告枠として売る事業。検索結果の上位に出す「スポンサー広告」が典型。

| 指標（日本）                 | 数値                                                                                 | 出典                                 |
| ---------------------------- | ------------------------------------------------------------------------------------ | ------------------------------------ |
| 国内リテールメディア広告市場 | **2025年 6,066億円 → 2029年 1兆3,174億円**（予測）                                   | 民間調査会社の推計                   |
| うちEC事業者分               | 5,236億円（2025年）                                                                  | 同上                                 |
| うち店舗事業者分             | 830億円（2025年、デジタル広告620億円＋サイネージ210億円）。2029年に1,939億円との予測 | CARTA HOLDINGS 調査（2026年1月公表） |

**なぜ利益源になるのか**。理由は3つある。

1. **原価がほぼゼロ**。すでに存在する検索結果の枠を売るだけなので、売上のほとんどが利益になる
2. **購買データで効果が証明できる**。「広告を見た人が実際に買ったか」が同じ画面の中で分かる。
   テレビやディスプレイ広告にはできない（→ [ネット広告](../07_ネット広告/README.md)）
3. **クッキー規制の逆風を受けにくい**。自社の会員データ（ファーストパーティデータ）だけで完結する

> 結果として、モールの営業利益は「商品を売って稼いだ分」より「出店者から広告費で回収した分」の
> 比重が高まっている。出店者から見れば、**広告費は実質的な手数料の上乗せ**である。
> ①ノートの「テイクレート」はこの分だけ静かに上がり続けている。

## 5. 中国系越境ECの攻勢

SHEIN（アパレル）、Temu（総合）、AliExpressに代表される中国発ECが、
極端な低価格で日本市場に入ってきた。Temuは日本上陸から半年で月間利用者1,500万人規模、
2024年11月時点で3,100万人に達したと報じられる（民間調査・報道ベース）。

彼らの安さを支えていたのが **少額免税制度（デミニミス）** である。

```
【少額免税がもたらした価格差】

  国内EC事業者                    中国発EC（直送モデル）
  仕入 ──▶ 国内倉庫 ──▶ 消費者    工場 ──▶ 国際小口便 ──▶ 消費者
   ▲ 消費税10%を負担              ▲ 1万円以下なら関税・消費税が免除されていた
   ▲ 国内の配送・人件費            ▲ 中間流通ゼロ、広告は自社アプリ内で完結
            ＝ 同じ商品でも価格差が二重についてしまう
```

| 論点           | 状況                                                                                                                                                      |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 日本の少額輸入 | 1万円以下の輸入は**1億6,966万件・4,258億円**（2024年、5年で約5倍に拡大）と報じられる                                                                      |
| 制度見直し     | **2026年度税制改正で個人輸入の免税特例を廃止**し、1万円以下の輸入にも消費税を課す方向。販売額50億円超のプラットフォームに納税義務を課す案が報じられている |
| 海外の動き     | 米国は2025年8月にデミニミス免税を廃止、EUは2026年7月1日からの廃止を決定                                                                                   |
| 既存の制度     | 2025年4月からデジタルサービスに「プラットフォーム課税」が適用開始（国外事業者に代わりプラットフォームが申告・納税）                                       |

> 構図：**価格競争ではなく制度競争**。国内事業者が中国系ECに勝てなかった主因の一つは
> 税と関税の非対称性だったので、制度が揃えば価格差は縮む。
> ただし製造コストと広告効率の差は残るため、免税廃止で全て解決するわけではない。

## 6. 生鮮ECはなぜ難しいのか

食品は物販系で最大の3兆円超だが、EC化率は最低クラス。理由は経済性にある。

| 障壁           | 中身                                        | なぜ利益が出ないか                              |
| -------------- | ------------------------------------------- | ----------------------------------------------- |
| 低単価×重量    | 1回の買い物が3,000〜5,000円で、重くかさばる | 配送費700円前後が売上の15〜20%を食う            |
| 温度帯管理     | 冷蔵・冷凍・常温の3温度帯を同一注文で扱う   | 庫内も配送も設備が3系統必要。コストが跳ね上がる |
| 短い賞味期限   | 在庫を持てない                              | 欠品か廃棄かの二択。予測が外れると即損失        |
| 品質のばらつき | 生鮮は個体差がある                          | クレーム・返金が発生しやすい                    |
| 配送の時間指定 | 在宅時間に届ける必要                        | 置き配が使えず、再配達コストが乗る              |

**2つのアプローチ**がある。

```
■ 店舗ピック型（従来のネットスーパー）
   既存の店舗の棚から従業員が商品を拾って配送
   長所：初期投資が小さい／短所：店員の作業が非効率、点数が増えると破綻

■ 専用センター型（CFC＝カスタマー・フルフィルメント・センター）
   ネット専用の自動化倉庫から配送
   長所：自動化で1件あたり作業費が下がる／短所：巨額の初期投資。稼働率が命
```

イオンの「Green Beans」は後者。2023年7月に首都圏で本格開始し、
**2年で会員60万人、平均客単価は約1万円**（同社公表・報道）。
八王子のCFCが2026年度、埼玉・久喜宮代のCFCが2027年度頃の稼働予定で、
**単年度黒字は2030年度が目標**とされる。
つまり **生鮮ECは7年がかりで損益分岐に届く装置産業**であり、小売というよりインフラ投資に近い。
（店舗側の経済性は [食品スーパー](../../07_小売・流通/03_食品スーパー/README.md) を参照）

## 7. 定期購入とD2C——LTVで戦う

広告単価が上がり続ける以上、**1回売って終わり**のモデルは成り立ちにくい。
そこで健康食品・化粧品・日用品では **定期購入（サブスクリプション）** が主流になった。

| 指標               | 意味                                   | 効く理由                                           |
| ------------------ | -------------------------------------- | -------------------------------------------------- |
| **LTV**            | 顧客が生涯に落とす金額                 | 定期購入なら1回目が赤字でも、3回目以降で回収できる |
| **CAC**            | 顧客獲得単価                           | 広告費÷新規顧客数。これがLTVを超えたら事業は破綻   |
| **引上率／継続率** | 初回購入者が定期に移る率／定期が続く率 | この2つが1ポイント動くだけで採算が反転する         |
| **F2転換率**       | 初回購入者が2回目を買う割合            | もっとも改善余地が大きい指標                       |

> 注意点：**定期購入は規制対象**でもある。解約しにくい設計や「初回実質無料」の誤認表示は
> 特定商取引法の規制強化（2022年6月施行の改正で、最終確認画面の表示義務・取消権を新設）の対象になった。
> 経済的に合理的でも、法的に許されない売り方がある。

## 8. この業界のKSF（成功の鍵）

1. **集客コストを下げる仕組み**：指名検索、会員・アプリ、ポイント経済圏。広告依存は利益を削る
2. **物流単価**：1出荷あたりいくらで届けられるか。規模と自動化と配送網の選択肢
3. **テイクレートの設計**：モール側は手数料ではなく広告と物流サービスで回収する
4. **品揃えとデータ**：何が売れ残るかを予測できる会社が在庫コストで勝つ
5. **制度対応**：越境課税、特商法、景表法、物流効率化法。**制度が競争条件そのもの**

## 9. 用語メモ

| 用語                         | 意味                                                                                  |
| ---------------------------- | ------------------------------------------------------------------------------------- |
| **EC化率**                   | 全商取引のうちEC経由の割合。日本のBtoC物販は約9.8%（2024年、経産省）                  |
| **リテールメディア**         | 小売・EC事業者が自社の売り場と購買データを広告枠として販売する事業                    |
| **スポンサー広告**           | モールの検索結果上位に有料で表示される広告枠                                          |
| **ファーストパーティデータ** | 自社が直接取得した顧客データ。クッキー規制の影響を受けにくい                          |
| **デミニミス（少額免税）**   | 一定金額以下の輸入品に関税・消費税を課さない制度。日本は1万円以下が対象だった         |
| **プラットフォーム課税**     | 国外事業者に代わり、プラットフォーム運営者が消費税を申告・納税する制度（2025年4月〜） |
| **CFC**                      | Customer Fulfillment Center。ネットスーパー専用の自動化倉庫                           |
| **OMO**                      | Online Merges with Offline。店舗とECを一体で運営する考え方                            |
| **LTV／CAC**                 | 顧客生涯価値／顧客獲得単価。LTV＞CACが事業成立の条件                                  |
| **F2転換率**                 | 初回購入者が2回目の購入に至る割合                                                     |
| **特定商取引法（通販規制）** | 定期購入の表示義務、返品ルール等を定める法律。2022年6月施行の改正で規制強化           |
