# 直近トピック（2026年9月時点）

報道・調査会社ベースの整理。数値は発表時点のもので、確定値と推計・報道を区別して書いている。
一次情報（各社IR、Gartner/IDCの原資料）での裏取りを前提に読むこと。

## 1. 「SaaSpocalypse」── 2026年2月の急落と、その後の戻り

2026年前半、エンタープライズソフト業界で **SaaSpocalypse（SaaS黙示録）** という造語が広まった。

| 出来事 | 時期 | 内容 |
| --- | --- | --- |
| ソフトウェア株の急落 | 2026年2月 | S&P北米ソフトウェア指数が年初来20%超下落。業界全体で1兆ドル規模の時価総額が失われたと報じられる |
| きっかけ | 2026年2月 | AI開発ツールがレガシーコード（COBOL等）の書き換えを高速化できると示したことが、「ソフトは作るより買う方が安い」という前提を揺るがした、と報じられる |
| 日本株への波及 | 2026年2月4日ごろ | ラクス、Sansan、弁護士ドットコム、freee など国内SaaS株が下落率上位に並んだと報じられる |
| 部分的な戻り | 2026年6月ごろ | ソフトウェア関連ETFが十数%回復し、「SaaSpocalypseは終わった」とする論調も出た |
| 2026年9月時点 | — | 株価は戻りつつある一方、**課金モデルと競争軸の変化は不可逆**という整理が主流 |

```
  株価の動き（模式図。実際の指数ではない）

  高 ┤ ●━━●
     │      ╲                          ●━━●━━●
     │       ╲                    ╱━━●
     │        ●━━●━━●━━●━━●
  低 ┤              ▲                  ▲
     └──────────────┼──────────────────┼────────▶
      2026/1        2月                6月      9月
                  急落                  戻り

   ▶ 株価は戻っても「シート課金の前提」は戻らない、というのが2026年9月時点の見方
```

> 注意：「AIがSaaSを殺す」という見出しと、実際の業績は連動していない。
> 多くのSaaS企業は2026年も二桁成長を維持している。**売られたのは業績ではなく前提**だった。

## 2. シート課金から従量・成果課金へ ── 課金モデルの再設計

2026年の最大の構造変化。理由は単純で、**AIエージェントは席（ユーザーアカウント）を必要としない**から。

```
【従来】 人が増える ─▶ 席が増える ─▶ 売上が増える
          ▲ 顧客の成長と売上が自動的に連動していた

【AI時代】 AIエージェントが5人分を処理 ─▶ 席は1つで足りる ─▶ 売上が減る
                                          │
                                          ├─▶ 対策A：処理件数で課金（従量）
                                          ├─▶ 対策B：解決件数で課金（成果）
                                          └─▶ 対策C：基本料＋従量（ハイブリッド）
```

| 課金モデル | 2026年時点の状況 | 具体例（報道ベース） |
| --- | --- | --- |
| シート単独 | **1年で21%→15%に低下**（調査会社推計） | 従来型SaaSの標準だった |
| ハイブリッド（固定＋従量） | **27%→41%に急増**（同） | 売上の読みやすさと上振れの両立 |
| 従量課金 | 何らかの形で従量要素を持つ企業が8割超（同、推計） | AI機能はクレジット制が多い |
| 成果課金 | まだ少数だが増加中 | Intercom Fin が「解決1件0.99ドル」、Zendesk が自動解決1件1.50ドルからの料金を導入したと報じられる |

- 調査会社IDCは、**2028年までに純粋なシート課金は陳腐化し、ソフトベンダーの約7割が価格指標を
  消費量・成果・組織能力へ組み替える**と予測している（IDC、推計）
- 一方で2026年には、**予測可能性を求める顧客の声を受けて、シート型に戻したり従量の上限を設ける
  動きも出ている**と報じられる。単純な一方向の移行ではない
- 買う側（情報システム部門）にとっての難所は**予算が組めないこと**。従量制は使うほど請求が増えるため、
  上限設定・クレジット前払いなどの運用が必要になる

## 3. AI売上は伸びるが、本体が鈍る ── Salesforceが示した構図

| 項目 | 数値 | 時点・出所 |
| --- | --- | --- |
| Agentforce（AIエージェント製品）のARR | 約8億ドル、前年同期比+169% | 2026年、同社決算（報道・二次引用） |
| その後の到達 | ARR 10億ドル超 | 2026年内、報道ベース |
| 全社の株価 | 2026年に約26%下落した局面があったと報じられる | 2026年 |
| FY2027（2027年1月期）通期ガイダンス | 459〜462億ドルへ上方修正と報じられる | 2026年 |

**読み取るべき構図**：AI製品そのものは急成長している。にもかかわらず評価が下がったのは、
市場が「AIで増えた売上 < AIで失われる席数」になるのではないかと疑ったため。
つまり **AIは既存SaaSにとって追い風であると同時に、自社のシート売上を食う共食いでもある**。

同じ論点は、Microsoft（Copilotを既存ライセンスに束ねる）、ServiceNow、Workday など
大企業向けSaaS全般に当てはまる。特に**束ね売りできる巨大ベンダーほど有利**で、
単機能SaaSは「大手のAI機能に無料で飲み込まれる」リスクを負う。

## 4. 評価軸の見直し ── AIコストがRule of 40を圧迫する

| 指標 | 2026年時点の状況 | 出所 |
| --- | --- | --- |
| Rule of 40（成長率＋利益率） | B2B SaaSの中央値は25%程度（前年15%から改善も基準未達） | 調査会社集計、推計 |
| 同・上場企業の達成率 | 上場SaaS 55社のうちEBITDAベースで達成は8社（約15%） | 同、推計 |
| 達成企業と未達企業の評価差 | 達成企業はEV/Revenue中央値6.6倍、未達2.3倍 | 同、推計 |
| NRR（売上維持率） | 中央値が101〜103%程度まで圧縮、上位でも111%前後 | SaaS Capital等のベンチマーク、推計 |
| 粗利率 | AI推論コスト（GPU・API料金）が原価に乗り、低下圧力 | Bain、High Alpha等の分析 |

- **粗利率75〜85%という前提が崩れ始めた**のが本質的な変化。AI機能は使われるほど原価が増える
- 結果、「成長しながら利益も出す」Rule of 40 の達成がこれまで以上に難しくなっている
- 投資家の見る指標も、ARR成長率一辺倒から **NRR・粗利率・Burn Multiple・AI売上の内訳**へ広がった
- 指標の意味は [SaaSの経済学](01_SaaSの経済学.md) を参照

## 6. 日本固有の論点 ── SIerとの綱引きが動く

生成AIによるコード生成が進むと、日本の企業ITの前提が二方向に揺れる。

```
  ① AIが「作る」コストを下げる ─▶ 自社開発が現実的に ─▶ SaaSを買う理由が減る（SaaSに逆風）
  ② AIが「作る」コストを下げる ─▶ SIerの受託単価が下がる ─▶ 人月商売が崩れる（SIerに逆風）
                                     │
                                     └─▶ SIerはSaaS導入・連携・運用の受け皿へ寄る動きも
```

- 「SaaSとSIerの棲み分け」という前提そのものが揺らぎ始めた、という指摘が2026年に増えている（報道・論考ベース）
- ただし**法令対応・可用性・監査証跡**は自作では負担が重く、業務基幹ほどSaaSが残りやすいという反論も強い
- → [SIer・ITサービス](../05_SIer・ITサービス/README.md)、[市場の構造](03_市場の構造.md)

## 7. 全体の構図

2026年に起きたのは「SaaSの死」ではなく、**SaaSを高く評価してきた3つの前提が同時に点検されたこと**である。
前提とは、①顧客が増えれば席が増える（＝NRR100%超が自動的に続く）、②粗利率が高い（原価がほぼ固定費）、
③ソフトは買った方が作るより安い、の3つ。AIエージェントは①を、AI推論コストは②を、AIコード生成は③を揺さぶった。

株価は2026年半ばに戻りつつあるが、課金単位の移行（シート→従量・成果）と、
評価軸の移行（成長率→NRR・粗利率・AI売上の内訳）は続いている。
勝ち残る条件として挙げられているのは、**業務データを押さえていること**、
**AI機能を追加課金に変換できること**、**顧客の成果を計測できること**の3点。
日本市場はこれに加えて、レガシー刷新需要という独自の追い風と、カスタマイズ要求という独自の重しを抱える。

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **SaaSpocalypse** | 2026年に広まった造語。AIによる代替懸念でSaaS株が一斉に売られた局面を指す |
| **シート課金** | 利用者1人あたりで課金する方式。AIエージェントとは相性が悪い |
| **従量課金** | 処理件数・データ量など使用量に応じた課金 |
| **成果課金** | 解決件数・成約件数など結果に応じた課金 |
| **ハイブリッド課金** | 基本料＋従量。2026年に最も増えた方式 |
| **クレジット制** | AI利用分を前払いのポイントで消費させる方式。予算管理をしやすくする |
| **Agentforce** | Salesforceが提供するAIエージェント製品 |
| **Rule of 40** | 成長率＋利益率が40以上あれば健全とみなす経験則 → [01](01_SaaSの経済学.md) |
| **Burn Multiple** | 現金燃焼額 ÷ 増加ARR。資本効率の指標 |
| **レガシー刷新** | 老朽化した既存システムの作り替え。国内市場の主要な需要源 |
