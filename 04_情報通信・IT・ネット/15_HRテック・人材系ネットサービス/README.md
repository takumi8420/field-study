# HRテック・人材系ネットサービス

- 大分類: 情報通信・IT・ネット
- 状態: done
- 更新日: 2026-09-20

**「人を採る」「人を管理する」をネットとソフトに置き換えた産業**。
求人サイトが広告の商売なのに対し、人事ソフト（HRテック）は従業員1人あたり月額の積み上げ商売で、
**同じ業界に見えて景気への強さも営業のやり方も正反対**という点がこの分野の面白さになる。
2026年は、採用の量が減るなかで単価とソフトが稼ぐ構図に切り替わった年にあたる。

## 1. 業界の定義・範囲

ここで扱うのは、**人材に関わる業務をネットサービス・ソフトウェアとして提供する事業**。
人が介在してサービスを提供する人材派遣・人材紹介そのものは隣のフォルダに譲る。

| 区別すべきもの | 中身 | どこで扱うか |
| --- | --- | --- |
| **求人メディア・アグリゲーター** | 求人情報を掲載・検索させる | **このフォルダ**（[01](01_求人メディアのビジネスモデル.md)） |
| **HRテック（人事SaaS）** | 労務・勤怠・給与・評価のソフト | **このフォルダ**（[02](02_HRテックの各領域.md)） |
| **ダイレクトリクルーティング** | 企業が候補者DBを検索してスカウト | **このフォルダ**（[03](03_人材ビジネス全体での位置づけ.md)） |
| 人材紹介（エージェント） | 人が仲介して成功報酬を取る | [人材紹介・求人メディア](../../15_サービス・生活関連/02_人材紹介・求人メディア/README.md) |
| 人材派遣 | 派遣会社が雇用して送り出す | [人材派遣](../../15_サービス・生活関連/01_人材派遣/README.md) |
| 業務そのものの受託 | BPO・アウトソーシング | [アウトソーシング・BPO](../../15_サービス・生活関連/03_アウトソーシング・BPO/README.md) |
| 企業向け業務ソフト全般 | SaaS の経済性・売り方 | [ソフトウェア・SaaS](../06_ソフトウェア・SaaS/README.md) |

```
  求職者 ──▶ 求人アグリゲーター ──▶ 求人メディア ──▶ 企業の採用担当
              Indeed/求人ボックス     タウンワーク等        │
                                                           ▼
                                        ATS（採用管理）─▶ 入社手続き・労務
                                                           ▼
                                        勤怠 ─▶ 給与計算 ─▶ 評価・配置
                                                    └── 従業員データベース ──┘
              ★左半分＝採用（広告の商売）  ★右半分＝人事管理（SaaSの商売）★
```

**境界の引き方**：左半分は景気に敏感な広告型、右半分は雇用が続く限り課金され続けるストック型。
両者を同じ「HR業界」と呼ぶと議論が混ざるので、この線を最初に引いておく。

## 2. 市場規模と成長性

| 指標 | 数値 | 時点・出所 |
| --- | --- | --- |
| 求人情報提供サービス市場（国内） | 約6,661億円 | 2024年度、全国求人情報協会 |
| 求人広告掲載件数（国内） | 2,887万件（2025年4〜12月は前年同期比 -4.6%） | 2025年、全国求人情報協会 |
| ダイレクトリクルーティング市場（国内） | 約1,275億円（前年度比+18.7%） | 2024年度、民間調査の推計（報道ベース） |
| 日本のHRテック市場 | 2025年 約21.6億ドル → 2034年 約39.3億ドル（年率6.87%） | IMARC Group の推計（2026年公表） |
| 国内タレントマネジメントシステム市場 | 2020年 約211億円 → 2026年 約447億円 | 民間調査の推計 |
| スポットワーク市場（賃金総額ベース） | 2024年 約1,216億円 | タイミーの推計 |
| 有効求人倍率 | 2025年度平均 1.20倍（3年連続低下）／2026年3〜4月 1.18倍 | 厚生労働省 一般職業紹介状況 |

**成長の性格**：採用広告は労働需給に連動して伸び縮みし、2025〜2026年は縮小局面。
一方でHRテックSaaSとスポットワークは二桁成長が続いている。
**市場全体が伸びているのではなく、中身が入れ替わっている**と読むのが正しい。

## 3. バリューチェーン（川上 → 川下）

```
 ①求職者の集客        ②求人の在庫       ③マッチング       ④採用の実務      ⑤入社後の管理
 ───────────────────────────────────────────────────────────────────────────────
 検索エンジン・SNS     企業・媒体        アグリゲーター     ATS・日程調整     労務・勤怠・給与
 口コミサイト          派遣/紹介会社     スカウト媒体       適性検査          評価・タレマネ
      │                    │                 │                │                │
      └─ 集客コストが      └─ 在庫の多さが   └─ ★ここに      └─ 効率化の      └─ ★ここに
         最大の変動費         競争力            利益が集まる      SaaS需要         継続収益★
```

**付加価値がたまる場所は2か所**。
③のマッチング層（求職者の行動データを持ち、採用に近い瞬間に課金できる）と、
⑤の従業員データベース（一度入ると外せず、機能を足すほど単価が上がる）。
①②は他人のもの（検索エンジン、企業の求人）に依存するため、単独では利益になりにくい。

## 4. 主要プレイヤーとシェア

| 企業・サービス | 立ち位置 | 特徴 |
| --- | --- | --- |
| **リクルートHD**（Indeed、Glassdoor、リクナビ、タウンワーク） | 求人アグリゲーターの世界最大手＋国内媒体 | 2026年3月期は売上約3.7兆円・営業利益約6,305億円。HRテクノロジーが利益の柱。Indeed PLUS で媒体を配信先に取り込む |
| **カカクコム（求人ボックス）** | 国内2番手のアグリゲーター | 価格比較サイトの検索流入ノウハウを転用 |
| **Visional（ビズリーチ、スタンバイ、HRMOS）** | ハイクラスのスカウト媒体＋HR SaaS | ダイレクトリクルーティングの代表格。採用管理・タレマネへ拡張 |
| **パーソルHD**（doda、HITO-Link） | 派遣・紹介・メディアの総合 | リアルとネットを併営。景気変動をポートフォリオで吸収 |
| **マイナビ** | 新卒・中途の媒体大手（非上場） | 新卒領域での学生接点が強い |
| **ディップ**（バイトル、はたらこねっと） | アルバイト・派遣の媒体 | 営業力に強み。スポットワーク領域にも進出 |
| **エン・ジャパン** | 中途媒体＋入社後の定着支援 | 口コミ（エンライトハウス）と媒体の組み合わせ |
| **SmartHR** | 労務管理クラウド最大手（非上場） | 2026年7月に ARR 300億円突破、登録社数7万社超と発表 |
| **カオナビ／プラスアルファ・コンサルティング（タレントパレット）／HRBrain** | タレントマネジメント | 人事データの可視化から評価・配置へ |
| **タイミー／シェアフル／メルカリ ハロ** | スポットワーク | 単発の雇用マッチング。二桁成長が継続 |
| **Works Human Intelligence／OBC／マネーフォワード／freee** | 給与・人事基幹 | 大企業向け（COMPANY）と中小向けで棲み分け |

> シェアの注意：この分野は**領域ごとに勝者が違う**。
> 採用の入口はリクルート（Indeed）が圧倒的だが、労務は SmartHR、大企業の人事基幹は
> Works Human Intelligence、というように、1社が全部を取っている構造にはなっていない。

## 5. 収益モデル・コスト構造

| モデル | 課金 | 粗利の性格 | 主なコスト |
| --- | --- | --- | --- |
| 求人メディア（掲載課金） | 掲載枠の前払い | 中〜高 | **営業人件費・原稿制作費**が重い |
| アグリゲーター（クリック課金） | クリック単価×クリック数 | 高 | 集客広告費（検索連動広告）が変動費 |
| ダイレクトリクルーティング | DB利用料＋低率の成功報酬 | 中〜高 | データベース維持、カスタマーサクセス |
| HRテックSaaS | 従業員数×月額（PEPM） | **高**（原価はサーバとサポート） | 開発費、導入支援、解約防止の人件費 |
| スポットワーク | 賃金の約30%の手数料 | 中 | 与信・決済・トラブル対応、集客 |

**HRテックSaaS特有の性質**：課金が顧客企業の従業員数に連動するため、
顧客が成長すれば自動的に増収し、**顧客が人員を減らせば解約されなくても減収する**。
SaaS一般の経済性（初年度赤字と回収期間、解約率、NRR）は
→ [SaaSの経済学](../06_ソフトウェア・SaaS/01_SaaSの経済学.md)

## 6. 競争要因（KSF）と参入障壁

| KSF | なぜ効くか |
| --- | --- |
| **求職者の集客力** | 求人の在庫より、見に来る人の数が希少。検索・アプリ・ブランドの蓄積が効く |
| **求人の在庫量** | 検索して「何も出てこない」と離脱される。在庫と集客は鶏と卵 |
| **行動データの蓄積** | 誰がどの求人をクリックし応募したか。マッチング精度と課金単価の源泉 |
| **従業員データベースの保有** | 一度入ると乗り換えコストが高い。上に機能を積める |
| **制度対応の速さ** | 法改正に施行日までに対応できないと即失注。対応力そのものが差別化 |
| **給与計算の正確性** | 間違えれば信頼を失う。実績年数が参入障壁になる |

参入障壁は**領域で全く違う**。求人メディアは比較的作りやすいが集客で詰む。
給与計算は機能が複雑で参入が難しい。スカウト媒体は候補者DBがゼロから始まるのが最大の壁。

## 7. 規制・法制度

| 法制度 | 要点 |
| --- | --- |
| **職業安定法** | 求人・募集情報の適正表示義務。2022年改正で募集情報等提供事業者（求人メディア・アグリゲーター）が届出制に |
| **労働者派遣法** | 派遣事業の許可制、同一労働同一賃金。ネット媒体でも派遣求人を扱う際に関わる |
| **労働基準法・労働安全衛生法** | 労働時間の上限、ストレスチェック。**改正のたびに勤怠・健康管理の需要が生まれる**（2026年4月から全事業場でストレスチェック義務化） |
| **企業内容等の開示に関する内閣府令** | 有価証券報告書での人的資本開示。2023年3月期に義務化、**2026年3月期から拡充** |
| **女性活躍推進法** | 男女間賃金差異・女性管理職比率の公表。2026年4月から対象拡大 |
| **個人情報保護法** | 応募者・従業員データの取り扱い。採用スコアリングでの利用目的の明示 |
| **育成就労制度** | 技能実習に代わる外国人材受け入れの新枠組み。移行準備が進む |

> **この業界を理解する最大の鍵**：HRテックは「便利だから買う」ではなく
> **「対応しないと違法になるから買う」**市場。法改正カレンダーがそのまま需要計画になる。
> 詳しくは [HRテックの各領域](02_HRテックの各領域.md) の第3章。
