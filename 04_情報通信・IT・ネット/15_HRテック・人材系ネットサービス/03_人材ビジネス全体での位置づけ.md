# 人材ビジネス全体での位置づけ ─ リアルとネットはどこで分かれるか

このノートで分かること：人材派遣・人材紹介・求人広告・HRテックが**同じ「採用予算」を取り合いながら、
まったく違う儲け方をしている**こと。そしてネットサービスが人の仕事をどこまで置き換え、
どこから先は置き換えられずにいるのか。最後に「雇用のミスマッチ」という社会課題との接続を見る。

## 1. 人材ビジネスの全体地図

同じ「人の採用」でも、**誰がお金を払い、誰が雇用契約を結ぶか**で業態が分かれる。
ここを押さえないと業界の議論がかみ合わない。

| 業態 | 雇用契約は誰と誰の間か | 課金 | 単価の目安 | 主な担い手 |
| --- | --- | --- | --- | --- |
| **求人広告・求人メディア** | 企業と求職者が直接 | 掲載・クリック課金 | 数万円〜数十万円／件 | リクルート、マイナビ、ディップ、Indeed |
| **人材紹介** | 企業と求職者が直接（仲介するだけ） | **成功報酬**（理論年収の15〜35%） | 100万〜300万円／人 | リクルート、パーソル、JACほか多数 |
| **人材派遣** | **派遣会社**と働く人（企業へ送り出す） | 時間単価×稼働時間 | 時給2,000〜4,000円相当 | パーソル、スタッフサービス、テンプ等 |
| **業務委託・BPO** | 委託先が自社で雇用 | 業務単位・月額 | 案件による | パーソル、トランスコスモス等 |
| **HRテック（SaaS）** | 関与しない（道具を売る） | 従業員数×月額 | 数百円／人月 | SmartHR、カオナビ、Visional ほか |
| **スポットワーク** | 企業と働く人が単発の雇用契約 | マッチング手数料（賃金の約30%） | 1件数千円 | タイミー、シェアフル、メルカリ ハロ |

```
   ＜企業から見た、人を確保する手段の階段＞

   コスト小 ┌──────────────────────────────────────────┐ コスト大
           │ 自社採用ページ                             │
           │   └ 求人メディア（掲載課金）               │
           │       └ 求人アグリゲーター（クリック課金） │
           │           └ ダイレクトリクルーティング     │
           │               └ 人材紹介（成功報酬）       │
           │                   └ 人材派遣（時間単価）   │
           └──────────────────────────────────────────┘
        　　手間：自社で頑張る ◀───────────▶ 丸投げできる

   ＝「お金を払うほど自社の手間が減る」。この直線上のどこを取るかが各社の戦略
```

> ポイント：ネットサービスは**階段の左側（安く・自分でやる）を広げる**方向に効いてきた。
> 右側（高く・丸投げ）ほど人の介在価値が残り、ネットに置き換わっていない。

## 2. なぜ人材紹介はネットに置き換わらないのか

求人広告はネットに置き換わったのに、人材紹介（エージェント）は残り続けている。理由は3つ。

| 残る理由 | 中身 |
| --- | --- |
| **求職者が「探していない」** | 優秀な人ほど転職活動をしていない。呼び起こす行為は人の仕事 |
| **情報の非対称が大きい** | 求人票に書けない実情（人間関係、評価制度の実態、なぜ空いたポジションか）を伝える |
| **意思決定を支える必要** | 転職は人生の決断。迷いを解きほぐし、年収交渉を代行し、退職を後押しする |

つまり**人材紹介が売っているのは情報ではなく「意思決定の伴走」**。
ここは検索やマッチングアルゴリズムで置き換えにくい。
→ 詳しくは [人材紹介・求人メディア](../../15_サービス・生活関連/02_人材紹介・求人メディア/README.md)

派遣も同様で、雇用責任・給与支払い・トラブル対応・法令対応を肩代わりしている。
この「リスクを引き受ける」部分がソフトに置き換えられない
→ [人材派遣](../../15_サービス・生活関連/01_人材派遣/README.md)

```
   人材紹介の仕事を分解すると
   ┌─────────────┬──────────────┬────────────────┬──────────────┐
   │ 候補者を探す │ 会って見極める│ 企業と引き合わす│ 決断を支える  │
   ├─────────────┼──────────────┼────────────────┼──────────────┤
   │ ★ネットが   │ 一部AIが支援 │ 日程調整は自動化│ ほぼ人のまま  │
   │  置き換えた  │              │                │              │
   └─────────────┴──────────────┴────────────────┴──────────────┘
        ↑ ここをネットサービスが切り出したのが「ダイレクトリクルーティング」
```

## 3. ダイレクトリクルーティングとスカウト型

**ダイレクトリクルーティング**＝企業が自分で候補者データベースを検索し、
直接スカウトを送って採用する方式。紹介会社を通さないので「攻めの採用」と呼ばれる。

| 比較軸 | 求人広告（待ち） | 人材紹介（任せる） | ダイレクトリクルーティング（攻め） |
| --- | --- | --- | --- |
| 候補者との接点 | 応募を待つ | エージェント経由 | **企業から直接送る** |
| 費用 | 掲載料 | 年収の15〜35% | データベース利用料＋成功報酬（低率） |
| 企業側の工数 | 小 | 小 | **大**（検索・文面作成・返信対応） |
| 転職潜在層 | 届かない | 一部届く | **届く**（今すぐ転職しない人にも） |

代表例はビズリーチ（Visional）、Wantedly、Green、新卒領域の OfferBox など。
ダイレクトリクルーティングサービスの市場規模は、2024年度に事業者売上高ベースで
**約1,275億円（前年度比+18.7%）**と推計されている（民間調査の推計・報道ベース）。
求人情報提供サービス全体（2024年度 約6,661億円、全国求人情報協会調べ）の2割弱にあたる。

**なぜ伸びたのか**：人手不足で「応募を待っていても来ない」状況が続き、
かつ企業側に採用専任者（リクルーター）が置かれるようになったため。
逆に言えば、**企業に工数を負わせるモデル**なので、採用体制のない企業には広がりにくい。

> このモデルの本質：紹介会社が担っていた「候補者を探す」工程だけを切り出して、
> データベースの利用料として企業に売り直した。人材紹介の**アンバンドル（分解）**。

## 4. 副業・ギグワーク・スポットワーク

雇用の形が「正社員か非正規か」の二択でなくなり、**時間単位で働く市場**が立ち上がった。

| 形態 | 期間 | 契約 | 代表サービス |
| --- | --- | --- | --- |
| **スポットワーク（スキマバイト）** | 数時間〜1日 | 単発の**雇用**契約 | タイミー、シェアフル、メルカリ ハロ |
| **副業マッチング** | 週数時間〜数ヵ月 | 業務委託が多い | ランサーズ、クラウドワークス、複業クラウド |
| **フリーランスのエージェント** | 数ヵ月〜年単位 | 業務委託 | レバテックフリーランス、Midworks |

スポットワークの市場規模は、2024年に**支払われた賃金総額ベースで約1,216億円**と推計される
（タイミーの推計レポート）。同社の四半期レポートでは、2026年5〜7月の全国募集件数は
411.8万件（前年同期比+13.1%）、総賃金額は314億円（同+18.2%）と、二桁成長が続いている。

```
  ＜従来＞ 採用 ─▶ 教育 ─▶ 配置 ─▶ 定着  （人を「抱える」）
            │
            └─ 固定費。閑散期も人件費が出ていく

  ＜スポットワーク＞ 必要な日・必要な時間だけ募集 ─▶ 当日来る ─▶ 終了
            │
            └─ 変動費化。ただし教育できない／品質が安定しない
               ＝「単純作業に切り出せる仕事」でしか成立しない
```

この市場の限界がここにある。**仕事を「初見の人でも数十分の説明でできる形」に分解できるか**が
導入可否を決める。物流倉庫・小売の品出し・飲食のホールが中心なのはそのため。
一方で、2025〜2026年には労働者保護（労災、報酬未払い、ドタキャン）や
偽装請負の懸念が制度論として議論されるようになっている。
→ [マッチング・シェアリング](../16_マッチング・シェアリング/README.md)

## 5. 雇用のミスマッチという社会課題との接続

人材系ネットサービスが社会的に語られるのは、**求人と求職が量では足りているのに、
中身が噛み合っていない**からだ。

厚生労働省の一般職業紹介状況によれば、2025年度（令和7年度）平均の有効求人倍率は1.20倍で
3年連続の低下、2026年3〜4月は1.18倍。全体では「1人に1.2件の求人がある」状態だが、
職種別に開くと事情がまったく違う。

| ミスマッチの種類 | 中身 | ネットサービスは効くか |
| --- | --- | --- |
| **職種のミスマッチ** | 建設・介護・運輸は求人が余り、事務職は求職が余る | 検索では埋まらない。**転換教育が要る** |
| **地域のミスマッチ** | 都市部に求職者、地方に求人 | リモート求人・移住支援で一部緩和 |
| **年齢・経験のミスマッチ** | 企業は即戦力を求め、未経験者が入れない | スキル可視化で一部緩和 |
| **情報のミスマッチ** | 入社後に「思っていたのと違う」＝早期離職 | 口コミ（OpenWork、Glassdoor）が効く領域 |

```
     求人側                          求職側
   ┌────────┐                    ┌────────┐
   │介護・建設│◀── 埋まらない ──  │事務職志望│
   │運輸・飲食│                    │一般職志望│
   └────────┘                    └────────┘
        ▲                              │
        │                              ▼
        └──── リスキリング／職種転換 ──┘
              ここを担うのが公的支援・EdTech・企業内教育
              ＝ HRテックの「スキル可視化」が社会政策とつながる理由
```

**スキルの可視化**（何ができる人なのかを職務経験ではなく能力で記述する）が
政策側でも民間側でも重視されるのは、職種転換を成立させる前提条件だからだ。
人的資本開示の制度化（2023年3月期〜、2026年3月期に拡充）も、
企業に人材データを持たせることで労働移動をなめらかにする狙いがある
→ [HRテックの各領域](02_HRテックの各領域.md)

## 6. どこに利益が集まるか

| レイヤー | 粗利の性格 | 景気耐性 |
| --- | --- | --- |
| HRテック（SaaS） | 高粗利。従業員数×月額で積み上がる | **強い**（雇用が続く限り課金） |
| 求人メディア・アグリゲーター | 中〜高。集客費が変動費 | 弱い（採用広告費は真っ先に削られる） |
| ダイレクトリクルーティング | 中。DBの維持に投資が要る | 中 |
| 人材紹介 | 売上総利益は高いが**人件費が重い** | 弱い（不況で成約が止まる） |
| 人材派遣 | 粗利率10〜20%台。スタッフ賃金が原価 | 中（不況では派遣に切り替える需要も） |

> 全体の構図：**景気に強いのは道具を売るHRテック、景気に弱いのは採用そのものを売る事業**。
> だから求人メディア各社はSaaSを、HRテック各社は採用領域を、互いに取りに行っている。

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **ダイレクトリクルーティング** | 企業が候補者DBを検索して直接スカウトする採用方式 |
| **スカウト媒体** | 候補者データベースを企業に開放するサービス。ビズリーチ等 |
| **転職潜在層** | 今すぐ転職する気はないが、良い話なら聞く層。ネット媒体の主戦場 |
| **スポットワーク** | 数時間〜1日単位の単発雇用。タイミー等が仲介する |
| **ギグワーク** | 単発・短期の仕事を請け負う働き方。雇用のものと業務委託のものがある |
| **アンバンドル** | まとめて提供されていたサービスを工程ごとに切り出して売ること |
| **有効求人倍率** | 求職者1人あたりの求人数。1を超えると人手不足側 |
| **ミスマッチ** | 求人と求職が量的に足りていても、職種・地域・経験が噛み合わない状態 |
| **リスキリング** | 職種転換のために新しい技能を身につけること |
| **理論年収** | 人材紹介の手数料算定に使う、想定される年間給与の総額 |
