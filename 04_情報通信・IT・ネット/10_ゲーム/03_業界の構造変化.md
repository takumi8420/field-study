# 業界の構造変化

2020年代のゲーム業界では、「ソフトを1本売る」という前提そのものを揺らす変化が同時に進んでいる。
このノートでは **サブスク／クラウド／eスポーツ／UGC／生成AI／規制** の6つを取り上げ、
それぞれが**業界の収益構造のどこを壊し、どこを作り直しているか**を見る。

## 0. 6つの変化の位置づけ

```
【何が、業界のどの部分を書き換えようとしているか】

   作る            配る            遊ぶ            稼ぐ
  ────────       ────────       ────────       ────────
  生成AI ─────▶  （開発費を下げる圧力。ただし現場の評価は割れている）

  UGC ────────────────────────▶  ユーザー自身が「作る」側に回る
  （Roblox/Fortnite）              ＝供給が無限に増え、可処分時間を奪う

                 サブスク ──────────────────────▶ 1本いくらから月額へ
                 （Game Pass）                      ＝単価の解体

                 クラウド ──────▶ ハードの必要性を薄める
                 （実験段階のまま10年）

                                eスポーツ ─────▶ ゲームを「観るもの」にする
                                                    ＝IPの寿命を延ばす装置

  規制 ────────────────────────────────────────▶ 稼ぎ方そのものに制約
  （ガチャ・課金・版号・アプリストア）
```

## 1. サブスク：Game Passが投げかけた「1本いくら」の解体

### 1-1. 何が起きたか

Xbox Game Passは「月額を払えば数百本が遊び放題」という定額制サービスで、
マイクロソフトは自社の大型新作を**発売日からサブスクに入れる（day one）**方針を取ってきた。
これは家庭用の伝統的な収益モデル（→ [①](01_3つの市場と収益構造.md)）への正面からの挑戦だった。

| 時点         | 出来事                                                                                        | 出典の性格                                          |
| ------------ | --------------------------------------------------------------------------------------------- | --------------------------------------------------- |
| 2024年2月    | 加入者3,400万人と公表                                                                         | Microsoft公式（**最後の公式単独発表**と報じられる） |
| 2025年10月   | Ultimateを月19.99ドル→**29.99ドル**（約50%）へ値上げ                                          | 公式発表                                            |
| 2026年4月    | 反発を受けてUltimateを**22.99ドル**へ引き下げ                                                 | 報道ベース                                          |
| 2026年       | 加入者は約3,000万人規模との報道（ピーク時約3,500万人から減）。一方で4,000万人とする推計もある | **報道・推計。数字は一致していない**                |
| 2026年11月〜 | クラウドゲーミングに月間プレイ時間の上限を導入（Ultimate 15時間 等）と報じられる              | 報道ベース                                          |

> **数字の扱いに注意**：Game Passの加入者数はマイクロソフトが継続開示しておらず、
> 2026年時点で報道・推計が3,000万〜4,000万人の幅で割れている。
> 本ノートでは**確定値として扱わない**。

### 1-2. 経済学的に何が難しいのか

```
【サブスクの構造的ジレンマ】

  加入者数 × 月額 ＝ 収入            （伸ばしたい）
        │
        ├─▶ 配信するソフトの対価を各パブリッシャーに支払う  （費用）
        │     ※人気作ほど高い
        │
        └─▶ 自社大作をday oneで入れると…
              ┌ 良い面：加入者が増える。作品が広く遊ばれる
              └ 悪い面：その作品の「1本7,000円の販売」が消える
                        ＝ 自社の売上を自分で共食い（カニバリ）する

  映像のNetflixと違い、ゲームは1本の制作費が桁違いに重い。
  「見放題にしても元が取れる」ラインに届く前に、費用が先に膨らむ
```

映像配信（→ [動画・音楽配信](../12_動画・音楽配信/README.md)）と同じ形に見えるが、
**1コンテンツあたりの制作費と消費時間が全く違う**。
映画は2時間で消費されるがゲームは数十時間かかるため、
**加入者が1か月に遊べる本数が少ない＝ラインナップを増やしても限界効用が低い**。
2025年の大幅値上げと2026年の撤回は、このモデルの採算点を探る過程と読める。

任天堂とソニーは対照的に、**サブスクを新作の販売と競合させない設計**を取っている。
Nintendo Switch Onlineは主にオンライン対戦と旧作ライブラリ、
PlayStation Plusも中心は対戦機能と旧作カタログで、**最新の大型自社作品は原則入れない**。

## 2. クラウドゲーミング：10年経っても「補助輪」のまま

クラウドゲーミング＝ゲームをサーバ側で動かし、映像だけを端末に配信する方式。
理屈の上では**ハードを不要にする**破壊的技術だが、2026年時点でも主役になっていない。

| 障壁                   | 中身                                                                                          |
| ---------------------- | --------------------------------------------------------------------------------------------- |
| **遅延（レイテンシ）** | 入力→サーバ→映像の往復。格闘・FPSなど反応速度が勝敗を決めるジャンルで致命的                   |
| **通信品質**           | モバイル回線・混雑時間帯で画質が落ちる。地方・海外で体験が一定しない                          |
| **原価構造**           | 1人が遊ぶ間、GPUを1つ占有する。**同時接続数に比例して原価が増える**＝限界費用がゼロにならない |
| **権利処理**           | 「持っているゲーム」をクラウドで動かしてよいか、ライセンス上の整理が必要                      |

> **なぜ儲からないか**：通常のソフト配信はダウンロードが終われば事業者のコストは消える。
> クラウドは**遊んでいる時間ずっとサーバ代がかかる**。
> 2026年に GeForce NOW が有料プランに月100時間、
> Xbox Cloud Gaming が月15時間などの**プレイ時間上限**を設けたと報じられるのは、
> 「遊ばれるほど赤字が膨らむ」構造への直接の対処である。
> 設備側の事情は [データセンター](../03_データセンター/README.md) を参照。

Googleは2019年にStadiaを開始したが2023年にサービス終了しており、
**大資本でも成立させられなかった前例**として業界で繰り返し参照される。
2026年時点の位置づけは「ハードの代替」ではなく、
**手持ちの端末で試す・出先で続きを遊ぶための補助輪**である。

## 3. eスポーツ：市場としては小さく、装置としては重要

| 指標                  | 数値                                    | 年・出典                                      |
| --------------------- | --------------------------------------- | --------------------------------------------- |
| 国内eスポーツ市場規模 | **約209.6億円**（前年比+14.6%）の見通し | 2026年／日本eスポーツ連合（JESU）系の**推計** |
| 同（2024年実績）      | 約161億円                               | 民間**推計**。定義により振れる                |

国内ゲーム市場2兆5,885億円（2025年）に対して**約0.8%**にすぎない。
それでもパブリッシャーが大会に投資するのは、eスポーツが**売上そのものではなく、IPの寿命を延ばす装置**だからである。

```
【eスポーツがパブリッシャーにもたらすもの】

  大会を開く（費用）
      │
      ├─▶ 配信視聴者が増える ──▶ 新規プレイヤーの流入（＝実質的な広告）
      ├─▶ 競技シーンが続く   ──▶ タイトルの寿命が延びる（5年→10年）
      ├─▶ プロ・配信者が育つ ──▶ 無償の継続的コンテンツ供給
      └─▶ スポンサー・放映権 ──▶ 直接収入（ただし規模は小さい）

  ＝ eスポーツ単体で黒字化するより、「本体タイトルのLTVを伸ばす投資」
     として評価されることが多い
```

産業としての詳細（チーム経営、スポンサー、大会運営）は [eスポーツ](../11_eスポーツ/README.md) に、
スポーツ興行としての比較は [スポーツビジネス](../../14_メディア・広告・エンタメ/12_スポーツビジネス/README.md) に委譲する。

## 4. UGC：ユーザーがゲームを作る側に回った

**UGC**（User Generated Content、ユーザー生成コンテンツ）型プラットフォームは、
ゲーム会社がゲームを作るのではなく、**ユーザーが作ったゲームを遊ぶ場を運営して手数料を取る**モデルである。
構造は完全にプラットフォームビジネスであり、ゲーム会社というよりYouTubeに近い。

| 指標（Roblox）           | 数値                              | 年・出典                                  |
| ------------------------ | --------------------------------- | ----------------------------------------- |
| DAU（1日あたり利用者）   | 約1億4,400万人                    | 2026年6月の講演で示された数値と報じられる |
| 同（2026年4〜6月期）     | 約1億2,300万人（+10%）            | 同社決算                                  |
| 四半期売上               | 14億6,900万ドル（前年同期比+36%） | 2026年4〜6月期／同社決算                  |
| クリエイターへの分配総額 | **年15億ドル**（2025年）          | 同社公表                                  |

```
【UGCプラットフォームの資金の流れ】

  プレイヤー
     │ 仮想通貨（Robux）を購入
     ▼
  ┌──────────────────────────────────────────┐
  │ プラットフォーム（Roblox）                  │
  │  ・App Store / Google Play に 30% を先に取られる │
  │  ・サーバ・開発ツール・安全対策の費用        │
  └──────────────────────────────────────────┘
     │ 一部をクリエイターへ分配（DevEx）
     ▼
  クリエイター（個人〜小規模チーム）
     ＝ 開発費を負担しているのはプラットフォームではなく彼ら

  ▲ ここが本質：プラットフォームは「開発リスクをゼロにした」
    ヒットしなくても損をしない。当たれば手数料が入る
```

> **既存のゲーム会社にとっての意味**：UGCは競合タイトルではなく、
> **可処分時間の競合**である。10代がRobloxやFortniteのクリエイティブモードに数百時間を費やせば、
> その分だけ他のゲームを買う時間と予算が減る。
> このため既存のIPホルダーは「敵対」ではなく「乗り入れ」を選びつつあり、
> RobloxはIPライセンスの登録制度を整備し、IP保有者が分配率を自分で決められる仕組みを導入したと報じられる。
> プラットフォームとしての理屈は [プラットフォームの経済学](../09_プラットフォーム・SNS/01_プラットフォームの経済学.md)、
> クリエイター分配の考え方は [SNSの収益と運営](../09_プラットフォーム・SNS/02_SNSの収益と運営.md) と同型である。

## 5. 生成AI：期待と現場の温度差

### 5-1. 開発費高騰への「答え」として期待されている

開発費が200〜500億円規模になった業界（→ [②](02_作り方と儲け方.md)）にとって、
生成AIは**工数を減らす唯一の希望**として語られてきた。

| 工程                                                 | 期待される使い方     | 2026年時点の実態            |
| ---------------------------------------------------- | -------------------- | --------------------------- |
| 企画・調査                                           | ブレスト、資料整理   | **最も普及**（利用者の81%） |
| 事務                                                 | メール・議事録       | 47%                         |
| プログラミング                                       | コード補完・デバッグ | 47%                         |
| プロトタイピング                                     | 試作の高速化         | 35%                         |
| 背景・テクスチャ                                     | 素材の大量生成       | 一部で実用。権利処理が壁    |
| **ゲーム内のAIキャラ等、プレイヤーが直接触れる機能** | NPCとの自由会話など  | **わずか5%**                |

出典：国際ゲーム開発者協会（IGDA）等が報じた「GDC 2026 State of the Game Industry」調査。
ゲーム業界関係者2,300人以上への調査。

### 5-2. しかし現場の評価は急速に悪化している

```
【「生成AIはゲーム業界に悪影響」と答えた割合の推移】

  2024年  18% ████████
  2025年  30% ██████████████
  2026年  52% ████████████████████████  ← 過半数に
                            ▲
   一方「良い影響」は 13%（2025年）→ 7%（2026年）に減少

  ※ 同じ調査で 36% が実際に生成AIを業務で使っていると回答している。
     「使ってはいるが、業界にとってよいとは思わない」という状態
```

悪化の背景として挙げられるのは次の3点である。

| 懸念           | 中身                                                         |
| -------------- | ------------------------------------------------------------ |
| **雇用**       | レイオフが続くなかで、AIが人員削減の口実になるという不信     |
| **権利**       | 学習データの出どころ。生成物の著作権の扱いが未整理           |
| **品質と受容** | プレイヤー側に「AI生成物」への忌避感があり、炎上リスクになる |

技術側の一般論は [生成AI](../../01_注目テーマ/01_生成AI/README.md) に委譲する。
ゲーム業界固有の論点は、**開発費削減の唯一の希望であると同時に、
作り手の反発が最も強い産業のひとつ**という緊張関係にある。

## 6. 規制：稼ぎ方そのものへの制約

### 6-1. 日本：ガチャと課金

| 規制                   | 内容                                                                                 | 根拠・時期                                                           |
| ---------------------- | ------------------------------------------------------------------------------------ | -------------------------------------------------------------------- |
| **コンプガチャ禁止**   | 複数の特定アイテムを全部揃えると別のレアが貰える設計は「カード合わせ」として禁止     | 景品表示法／消費者庁が2012年5月18日に見解を公表（2016年4月一部改定） |
| **有料ガチャ自体**     | 課金で直接得るアイテムは「取引そのもの」なので景品類には当たらない＝景品規制の対象外 | 同上                                                                 |
| **排出確率の表示**     | 確率を誇張・誤認させる表示は**表示規制**（優良誤認等）の違反になりうる               | 景品表示法                                                           |
| **確率表示の義務づけ** | 法律上の一律義務はなく、**業界団体の自主規制**（JOGA・CESAのガイドライン）で運用     | 自主規制                                                             |
| **未成年の課金**       | 民法上、法定代理人の同意のない契約は取り消しうる。各社が年齢別の上限額を自主設定     | 民法／自主規制                                                       |

> **日本の特徴は「法規制が薄く、自主規制が厚い」こと**。
> コンプガチャだけが明確に禁じられ、ガチャそのものは合法である。
> このため各国の規制（後述）と比べると、日本は**事業者にとって自由度が高い市場**であり、
> 逆に言えば**自主規制の運用が崩れたときに一気に法規制へ振れるリスク**を抱えている。

### 6-2. 海外：より踏み込んだ規制

| 国・地域           | 内容                                                                                                                                                                                                        |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **ベルギー**       | ルートボックス（有料ランダム報酬）を賭博に当たるとして2018年に事実上禁止                                                                                                                                    |
| **オランダ**       | 一時規制したが、その後司法判断で緩和                                                                                                                                                                        |
| **中国**           | **版号**（出版番号）がなければ商用配信できない。2025年12月には国産ゲーム105本が一括承認されたと報じられる。未成年には**毎日ログインボーナスの禁止**、課金上限、過剰課金時の警告ポップアップなどが求められる |
| **中国（未成年）** | 2021年から未成年のオンラインゲームは金・土・日および祝日の1日1時間に制限                                                                                                                                    |
| **EU**             | 消費者保護の枠組みで、ゲーム内通貨の価格表示の明瞭化などが議論されている                                                                                                                                    |

```
【中国市場の「関所」構造】

  日本のパブリッシャー
        │
        ▼
  中国の代理・運営パートナー（現地法人が必要）
        │
        ├─▶ 著作権の契約登記（国家版権局）
        ├─▶ ICP（インターネット情報サービス）許可
        └─▶ 版号の申請（国家新聞出版署）
              │
              ▼  ※審査は不定期・不透明。発給が止まる時期がある
        ようやく商用配信・課金が可能

  ＝ 世界最大級の市場でありながら、「いつ入れるか分からない」市場
```

### 6-3. アプリストア規制：ゲームが最大の当事者

日本のスマホソフトウェア競争促進法（2025年12月18日全面施行）とEUのDMAは、
**アプリ内課金の最大の支払者であるゲーム業界**に最も直接効く。
2026年5月には日本のiOS向けに Epic Games Store が開設され、
『フォートナイト』が約5年9か月ぶりにiPhoneで遊べるようになったと報じられた。
制度そのものの解説は [プラットフォーム・SNS ③ 規制と社会的論点](../09_プラットフォーム・SNS/03_規制と社会的論点.md) に委譲し、
ゲーム業界側で実際に何が起きたかは [④ 直近トピック](04_直近トピック_2026.md) に書いた。

## 7. まとめ：どの変化が、どれくらい効いているか

2026年時点で**すでに決算と雇用に表れている**のは、規制（アプリストア・ガチャ・版号）と
**UGC**（可処分時間の奪い合いで10代の行動が実際に変わった）の2つ。
**生成AI**は導入は進んだがコア制作には届いておらず、**サブスク**は提唱者自身が採算点を探っている段階。
**eスポーツ**は市場規模が小さくIP延命の装置としての価値が主で、
**クラウドゲーミング**は原価構造の壁を越えられていない。

> **通底する論点はひとつ**：「ゲームを1本いくらで売る」という20世紀型のモデルが、
> 開発費の膨張に耐えられなくなっている。
> サブスクもF2PもUGCも生成AIも、**その耐えられなさへの別々の回答**だと読むと整理しやすい。

## 用語メモ

| 用語                             | 意味                                                                         |
| -------------------------------- | ---------------------------------------------------------------------------- |
| **サブスクリプション（ゲーム）** | 月額で多数のタイトルが遊べる方式。Game Pass、PS Plus、Nintendo Switch Online |
| **day one（デイワン）**          | 新作を発売日からサブスクに含めること。販売売上と共食いする                   |
| **クラウドゲーミング**           | サーバ側で処理し映像だけ配信する方式。遅延と原価が壁                         |
| **レイテンシ**                   | 入力から画面反映までの遅れ。競技系タイトルで致命的                           |
| **UGC**                          | ユーザー生成コンテンツ。Roblox、Fortniteのクリエイティブなど                 |
| **DevEx**                        | Robloxで、クリエイターが稼いだ仮想通貨を現金に換える制度                     |
| **ルートボックス**               | 有料のランダム報酬箱。国によっては賭博規制の対象                             |
| **コンプガチャ**                 | 特定アイテムを全種揃えると別の報酬が出る設計。日本では2012年に禁止           |
| **版号**                         | 中国で商用配信に必要な出版番号。国家新聞出版署が発給する                     |
| **可処分時間**                   | 人が自由に使える時間。ゲーム同士だけでなくSNS・動画とも奪い合う              |
