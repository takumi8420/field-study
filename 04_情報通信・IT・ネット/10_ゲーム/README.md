## 1. 業界の定義・範囲

**ゲーム業界**＝コンピュータゲームの企画・開発・販売・運営と、
それを遊ぶための機械（ハード）とストア（流通）を提供する事業の総称。

```
【このフォルダの守備範囲】

 ┌───────────────────────────────────────────────────────┐
 │ ● ソフト（コンテンツ）                                     │
 │    家庭用ゲームソフト、PCゲーム、モバイルゲーム            │
 │    パブリッシャー／デベロッパー／インディー                │
 │                                                            │
 │ ● ハード・プラットフォーム                                 │
 │    据置機・携帯機、ゲーミングPC周辺、アプリストア、Steam   │
 │                                                            │
 │ ● 運営・サービス                                           │
 │    オンライン運営、サブスク、クラウドゲーミング、UGC       │
 └───────────────────────────────────────────────────────┘
   ▲ 隣接だが別フォルダ：eスポーツ興行／IPライセンス／アーケード・遊技機
```

境界の引き方の目安。

| 対象                                     | ここで扱う                              | 別フォルダ                                                                          |
| ---------------------------------------- | --------------------------------------- | ----------------------------------------------------------------------------------- |
| 家庭用・PC・モバイルのソフトとハード     | ○                                       | —                                                                                   |
| アプリストア手数料の「ゲーム側への影響」 | ○                                       | 制度の中身は [プラットフォーム・SNS](../09_プラットフォーム・SNS/README.md)         |

| キャラクターのライセンス・グッズ事業     | ×（ゲーム会社の収益源として触れるのみ） | [キャラクター・IP](../../14_メディア・広告・エンタメ/10_キャラクター・IP/README.md) |
| パチンコ・パチスロ、アーケード（AM）施設 | ×（遊技機は別業界）                     | 遊技機・アミューズメント関連                                                        |
| 半導体・メモリの供給                     | ×（部材高騰の影響のみ）                 | [半導体・先端半導体](../../01_注目テーマ/02_半導体・先端半導体/README.md)           |

> **最初に押さえるべき「ねじれ」**：ゲーム会社は、
> ①ソフトを作る**コンテンツ企業**、②ハードとストアを運営する**プラットフォーム企業**、
> ③キャラクターを貸す**IP企業**の3つの顔を持つ。
> 任天堂は3つ全部、カプコンは①と③、Valveは②だけ、という具合に**会社ごとに顔の組み合わせが違う**。
> 「ゲーム会社」とひと括りにすると決算が読めなくなる。

## 2. 市場規模と成長性

| 指標                     | 数値                                                                 | 年・出典                                                                         |
| ------------------------ | -------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| 世界ゲームコンテンツ市場 | **32兆1,024億円**（2,145.6億ドル、前年比+3.5%／同一通貨ベース+5.0%） | 2025年／角川アスキー総研『ファミ通ゲーム白書2026』の**推計**（2026年8月6日発表） |
| ── 家庭用                | 前年比 **+8.0%**                                                     | 同上。Nintendo Switch 2 発売の効果                                               |
| ── PC                    | 前年比 +5.8%                                                         | 同上                                                                             |
| ── モバイル              | **12兆6,001億円**（前年比+1.3〜1.4%）                                | 同上／『ファミ通モバイルゲーム白書2026』                                         |
| 国内ゲーム市場           | **2兆5,885億円**（前年比+8.0%）                                      | 2025年／同上                                                                     |
| 国内ゲーム人口           | 5,639.3万人（+3.0%）                                                 | 同上                                                                             |
| 国内スマホゲーム市場     | 2021年に約1.3兆円でピーク。その後は減少局面と報じられる              | 各種推計。定義差が大きい                                                         |
| 国内eスポーツ市場        | 約209.6億円の見通し（+14.6%）                                        | 2026年／JESU系の**推計**。国内ゲーム市場の約0.8%                                 |

```
【2025年の成長の中身】

  家庭用  +8.0%  ████████████████  ← 新ハードの年だから伸びた（一時的）
  PC      +5.8%  ███████████▌
  モバイル +1.3%  ██▌            ← 最大市場だが、もう伸びない
  ──────────────────────────────
  全体    +3.5%
```

> **成長の性格**：世界のゲーム人口はすでに広く行き渡っており、
> 成長は「人数」ではなく **「ハードの世代交代」と「1人あたり課金額」** から来る。
> したがってゲーム市場の数字は、**7年前後のハードサイクルで上下する波**として読む必要がある。
> 2025年の+8.0%（家庭用）は構造的な成長ではなく、Switch 2 の発売年だったことが大きい。

## 3. バリューチェーン（川上 → 川下）

```
【誰が価値を作り、誰が受け取るか】

  ① IP・企画            ② 開発               ③ 販売・運営        ④ 流通の関所
  ─────────────       ─────────────        ─────────────      ─────────────
  IPホルダー      ──▶  デベロッパー  ──▶  パブリッシャー ──▶  プラットフォーマー
  原作・権利者          （開発会社）        （販売元）          任天堂／ソニー／MS
  ロイヤリティ           受託＝人月         資金・宣伝・運営     Apple／Google／Valve
  数%〜十数%             固定収入・低リスク  最大のリスクを負う   手数料 約15〜30%
       ▲                     ▲                                      │
       │                     │                                      ▼
       │               外注（3Dモデル／モーション／            ⑤ プレイヤー
       │               ローカライズ／QA）                       6,000〜10,000円／本
       │                                                        または F2P課金
       └───── IPが育つと、ゲーム外（玩具・アニメ・カード）へ広がる ─────┘
                 ＝ 投資が軽く利益率が高い「右側の経済圏」
```

**付加価値がどこに溜まるか**は2か所に集中する。

1. **④の流通の関所**。作らず、リスクを負わず、売上の約30%を取る。
2. **①のIP**。一度育てば、本編を出さない年にもライセンス収入が入る。

逆に最もリスクを負うのは**③のパブリッシャー**で、
数百億円を先に出し、5〜7年後に売れるかどうかが決まる。
**②の受託デベロッパーは安全だが上振れもない**（→ [② 作り方と儲け方](02_作り方と儲け方.md)）。

## 5. 収益モデル・コスト構造

```
  【買い切り】 売上 ＝ 販売本数 × 単価 × （1 − 手数料30%）
                      ──────────    ─────
                      初動でほぼ確定   1万円時代へ上昇中

  【運営型】   売上 ＝ DAU × 課金率 × ARPPU × 継続日数
                      ─────────────────────────
                      この積（＝LTV）が、獲得広告費（CPI）を上回るかどうか
```

| 区分 | 項目                                 | 性質                                                          |
| ---- | ------------------------------------ | ------------------------------------------------------------- |
| 売上 | ソフト販売（買い切り・DLC）          | 発売時に集中。当たり外れが極端                                |
| 売上 | アプリ内課金（F2P）                  | 運営を続ける限り入る。上位1〜2%が売上の4〜6割を占めるとされる |
| 売上 | プラットフォーム手数料・ロイヤリティ | ハードを持つ会社の主柱。約30%                                 |
| 売上 | サブスク・ネットワークサービス       | 安定収入。PS Plus、Nintendo Switch Online など                |
| 売上 | **IPライセンス**                     | 原価がほぼゼロ。最も利益率が高い                              |
| 費用 | 開発費（人件費が中心）               | **固定費**。AAAで数百億円。回収までに5〜7年                   |
| 費用 | 広告宣伝費                           | モバイルでは売上の3〜5割に達する例も                          |
| 費用 | ハード製造原価                       | 部材高騰の影響を直接受ける。逆ざや戦略が揺らいでいる          |
| 費用 | サーバ・運営                         | 準変動費。オンライン前提で恒常的にかかる                      |
| 費用 | ローカライズ・審査対応               | 展開する国の数に比例                                          |

利益率は**会社の「顔」で全く違う**。
プラットフォーマーはハードが売れる年に利益率が下がり、世代後半に跳ね上がる。
IP型・リピート販売型の会社は、開発費が済んだ資産を売るので恒常的に高い。
受託デベロッパーは稼働率次第で薄い。

## 6. 競争要因（KSF）と参入障壁

| 要因                     | 中身                               | 効き方                                           |
| ------------------------ | ---------------------------------- | ------------------------------------------------ |
| **IPの強さ**             | 既存ファンという読める需要         | 最大の資産。続編は新規IPより圧倒的に安全         |
| **資金力**               | 数百億円を5〜7年寝かせられるか     | AAA領域は大手にしか手が出ない                    |
| **開発人材**             | 専門職の確保と定着                 | 世界規模の奪い合い。レイオフと採用が同時に起きる |
| **流通の関所**           | ハード・ストアを持っているか       | 持てば手数料側に回れる。持たなければ払う側       |
| **運営力**               | 発売後に数年ユーザーを繋ぎ止める力 | 運営型の生命線。開発力とは別のスキル             |
| **ローカライズと海外網** | 海外比率7〜8割の大手では必須       | 中国は版号という別の関門がある                   |
| **規制対応**             | ガチャ・年齢・決済・データ保護     | 国ごとに違い、固定費として効く                   |

> **参入障壁の二極化**：AAA領域の障壁は資金と人材で極めて高い。
> 一方**インディー（小規模開発）の障壁は史上最低**で、
> Steamに登録料100ドル程度で誰でも出せる。
> 結果として**中規模（AAではない中堅）が最も苦しい**という「ミドルの空洞化」が業界の通説になっている。

## 7. 規制・法制度

| 制度                             | 国・地域   | 要点                                                                                                                                                                                    |
| -------------------------------- | ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **景品表示法（コンプガチャ）**   | 日本       | 複数アイテムを揃えさせる「カード合わせ」型は禁止。消費者庁が2012年5月18日に見解公表（2016年4月一部改定）。**有料ガチャ自体は景品類に当たらず適法**                                      |
| **排出確率の表示**               | 日本       | 法律上の一律義務はなく、JOGA・CESAなど**業界団体の自主規制**で運用。誇張表示は景表法の表示規制に触れうる                                                                                |
| **未成年の課金**                 | 日本       | 民法上の取消しと、各社の自主的な年齢別上限で対応                                                                                                                                        |
| **CERO**                         | 日本       | 年齢別レーティングの**自主規制団体**（政府機関ではない）。米ESRB、欧州PEGIに相当                                                                                                        |
| **スマホソフトウェア競争促進法** | 日本       | 2025年12月18日全面施行。ゲームはアプリ内課金の最大の当事者。2026年5月にiOS版Epic Games Store が日本上陸 → [プラットフォーム・SNS ③](../09_プラットフォーム・SNS/03_規制と社会的論点.md) |
| **版号制度**                     | 中国       | 国家新聞出版署の出版番号がなければ商用配信不可。2025年12月に国産105本が一括承認と報じられる                                                                                             |
| **未成年のプレイ時間制限**       | 中国       | 2021年から金・土・日および祝日の1日1時間に制限。課金上限・警告表示も求められる                                                                                                          |
| **ルートボックス規制**           | ベルギー等 | 有料ランダム報酬を賭博と見なし2018年に事実上禁止。オランダは司法判断で緩和                                                                                                              |
| **DMA／DSA**                     | EU         | ゲートキーパーへの事前規制。アプリストア経由の課金に影響                                                                                                                                |

→ [④ 直近トピック（2026年9月時点）](04_直近トピック_2026.md)

1. **2025年の世界市場は32.1兆円（+3.5%）で最高水準。ただし伸びたのは家庭用（+8.0%）とPC（+5.8%）で、
   最大市場のモバイルは+1.3%とほぼ横ばい。** 成長の実態はハード世代交代による一時的な押し上げ。
2. **任天堂は売上が約2倍（2兆3,130億円）になったのに営業利益率は約24%→約16%に低下。**
   利幅の薄いハードの構成比が上がったため。ソニーG&NSは逆に台数減でも過去最高益4,632億円。
3. **開発費が業界最大のリスクに。** AAAで2.5億〜4億ドル規模、最大級は推定3,000億円とも報じられ、
   2026年9月には「アタリショック以来の危機」と業界重鎮が発言。ソフト価格は1万円台へ。
4. **生成AIは導入36%・否定的評価52%（GDC 2026調査）。** 使われてはいるが、
   プレイヤーが直接触れる機能への適用は5%にとどまる。レイオフと権利問題が不信の背景。
5. **日本のiOSに Epic Games Store が2026年5月に上陸し、フォートナイトが約5年9か月ぶりに復活。**
   ただし代替ストア経由でも21%相当の負担が残るとされ、実質負担をめぐる争いは続いている。

## 9. 用語メモ

各ノート末尾の「用語メモ」に分野別で置いた。最小限の索引だけここに示す。

| 用語                             | 意味                                                                                                      |
| -------------------------------- | --------------------------------------------------------------------------------------------------------- |
| **プラットフォーマー**           | ハードやストアを運営し流通を握る事業者。手数料約30%を取る → [①](01_3つの市場と収益構造.md)                |
| **かみそりの刃モデル**           | 本体を安く（時に赤字で）売り、ソフトのロイヤリティで回収する型 → [①](01_3つの市場と収益構造.md)           |
| **タイイング比率**               | ハード1台あたりのソフト販売本数。プラットフォームの活性度 → [①](01_3つの市場と収益構造.md)                |
| **デジタル比率**                 | ソフト売上に占めるダウンロード販売の割合。高いほど利益率が上がる → [①](01_3つの市場と収益構造.md)         |
| **F2P（基本無料）**              | 無料で遊べて一部に課金する方式。上位1〜2%が売上の大半を支える → [①](01_3つの市場と収益構造.md)            |
| **AAA（トリプルエー）**          | 最大規模の予算・人員をかけた大作。明確な定義はない → [②](02_作り方と儲け方.md)                            |
| **パブリッシャー／デベロッパー** | 販売元／開発会社。資金とリスクを持つのが前者 → [②](02_作り方と儲け方.md)                                  |
| **LTV／CPI**                     | 1人が生涯に落とす金額／1人を獲得する広告費。この差が運営型の黒字の源泉 → [②](02_作り方と儲け方.md)        |
| **バトルパス**                   | 期間限定の定額券。ガチャ依存を減らし課金額を平準化する → [②](02_作り方と儲け方.md)                        |
| **リピート販売**                 | 旧作の継続販売・移植。開発費が済んでおり利益率が極めて高い → [②](02_作り方と儲け方.md)                    |
| **UGC**                          | ユーザー生成コンテンツ。Roblox等は開発リスクを負わずに供給を得る → [③](03_業界の構造変化.md)              |
| **版号**                         | 中国で商用配信に必要な出版番号 → [③](03_業界の構造変化.md)                                                |
| **コンプガチャ**                 | 特定アイテムを全種揃えると報酬が出る設計。日本では2012年に禁止 → [③](03_業界の構造変化.md)                |
| **アタリショック**               | 1983年前後の北米家庭用ゲーム市場の急縮小。供給過剰と品質低下が原因とされる → [④](04_直近トピック_2026.md) |
