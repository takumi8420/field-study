# 3つの市場と収益構造

「ゲーム業界」はひとつの業界ではなく、**家庭用（コンソール）・PC・モバイルという3つの別々の商売**の集まりである。
同じ会社が同じゲームを出しても、どの市場で出すかで**誰にいくら払い、どこで利益が出るかが根本的に違う**。
このノートでは、その3つの経済構造を分解する。

## 1. まず全体像：32兆円のうち、誰がどこで稼いでいるか

| 区分                             | 2025年の市場規模                   | 前年比                       | 性格                                                                     |
| -------------------------------- | ---------------------------------- | ---------------------------- | ------------------------------------------------------------------------ |
| 世界ゲームコンテンツ市場（全体） | **32兆1,024億円**（2,145.6億ドル） | +3.5%（同一通貨ベース+5.0%） | 角川アスキー総研『ファミ通ゲーム白書2026』の**推計**（2026年8月6日発表） |
| ── モバイル                      | **12兆6,001億円**                  | +1.3%                        | 全体の約4割。最大だが成長は鈍化                                          |
| ── 家庭用                        | （上記の残余に含まれる）           | **+8.0%**                    | 2025年は新ハード効果で最も伸びた                                         |
| ── PC                            | 同上                               | +5.8%                        | Steam経済圏が中心                                                        |
| 日本国内市場                     | **2兆5,885億円**                   | +8.0%                        | 世界の約8%                                                               |
| 国内ゲーム人口                   | 5,639.3万人                        | +3.0%                        | 同上の推計                                                               |

> **読み方のコツ**：市場規模の数字は調査会社ごとに定義が違う（ハード本体を含むか、
> eスポーツや周辺機器を含むか）。**絶対額より「前年比とどこが伸びたか」を見る**のが実務的である。
> 2025年に家庭用が+8.0%と伸びたのは、Nintendo Switch 2という新ハードが出た年だからで、
> 家庭用市場は**ハードの世代交代に7年前後の周期で揺れる**。

```
【3つの市場：お金の通り道がまったく違う】

  ① 家庭用（コンソール）
     プレイヤー ──▶ ソフト代 6,000〜10,000円 ──▶ パブリッシャー
                        └─▶ プラットフォーマー（任天堂/ソニー/MS）が約30%
     ※ハード本体は別売り。プレイヤーはまず3〜7万円の機械を買わされる

  ② PC
     プレイヤー ──▶ ソフト代 ──▶ Steam（Valve）が30%（売上に応じ25%/20%）
                                  └─▶ 残りがパブリッシャー
     ※ハードはプレイヤーが勝手に用意する。プラットフォーマーは機械を売らない

  ③ モバイル
     プレイヤー ──▶ 基本無料。課金する人だけが払う（平均すると月数百円）
                        └─▶ App Store / Google Play が15〜30%
                        └─▶ 残りが運営会社。ただし広告宣伝費に3〜5割消える
     ※ハードはスマホ＝すでに全員が持っている
```

## 2. 家庭用：ハードを安く売り、ソフトで回収する「かみそりの刃モデル」

### 2-1. 仕組み

家庭用ゲーム機のビジネスは、古典的な **razor-and-blades（かみそり本体は安く、替刃で儲ける）** 型である。

```
【プラットフォームビジネスとしての家庭用ゲーム機】

   ハード（本体）                        ソフト（ゲーム）
   ─────────────                     ──────────────────
   原価に近い、または赤字で売る  ───▶  台数が増える
          ▲                                  │
          │                                  ▼
   台数が多い＝魅力的な市場  ◀───  サードパーティが集まる
          │                                  │
          │                                  ▼
          └────── ロイヤリティ（1本あたり約30%）を回収 ─────┘

   ＝ 典型的な両面市場（→ ../09_プラットフォーム・SNS/01_プラットフォームの経済学.md）
      A面＝ゲーム開発会社、B面＝プレイヤー。本体を安くしてB面を集める価格構造
```

- **ロイヤリティ（ライセンス料）**＝他社（サードパーティ）が自分のハード向けにソフトを出すとき、
  プラットフォーマーに払う手数料。業界慣行として**売上の約30%**とされる（各社非公表）。
- したがってプラットフォーマーの利益は「ハード台数 × 1台あたりのソフト購入本数（タイイング比率） × 単価 × 30%」で決まる。
- **ハードは赤字で売ってもよい**。あとでソフトで取り返せるから。
  PlayStation 5やXboxは発売当初、本体を原価割れで売っていたと報じられた。

### 2-2. ただし「赤字で売る」は2020年代に揺らいでいる

| 会社                   | 従来の姿勢                            | 近年の実態                                                     |
| ---------------------- | ------------------------------------- | -------------------------------------------------------------- |
| ソニー（PS）           | 立ち上げ期は逆ざや、途中から黒字化    | 2025年に**値上げ**を実施。部材高騰で逆ざやを維持できない       |
| マイクロソフト（Xbox） | 本体は一貫して逆ざや、Game Passで回収 | ハード販売が振るわず、ソフトのマルチプラットフォーム展開に転換 |
| 任天堂                 | **原則として本体も黒字**で売る主義    | Switch 2も同方針。ただし2026年に値上げを発表                   |

> **なぜ崩れたか**：メモリ（DRAM）などの部材価格がAI向け需要で高騰し、
> 「最初は赤字でもいい」という前提が成り立ちにくくなっている（2026年の業界の論点。→ [④](04_直近トピック_2026.md)）。

### 2-3. 数字で見る：新ハードを出すと利益率が下がる

任天堂の2026年3月期（Nintendo Switch 2の発売年度）決算は、この構造の教科書のような例である。

| 項目                             | 2025年3月期    | 2026年3月期                         | 変化            |
| -------------------------------- | -------------- | ----------------------------------- | --------------- |
| 売上高                           | 約1兆1,600億円 | **2兆3,130億円**                    | 約2倍（+98.6%） |
| 営業利益                         | 約2,820億円    | **3,601億円**                       | +27.5%          |
| 営業利益率                       | 約24%          | **約16%**                           | **低下**        |
| Switch 2 販売計画                | —              | 1,500万台 → **1,900万台**に上方修正 | —               |
| ゲーム専用機ソフトのデジタル比率 | —              | **54.6%**                           | 上昇            |

出典：任天堂 2026年3月期 決算短信・決算説明資料（2026年5月8日）。利益率は売上高と営業利益からの計算。

> **ここが重要**：売上は倍になったのに利益率は下がった。
> **ハードが売れる年は、利益率の低いハードの売上が構成比を押し上げるから**である。
> 逆に世代の後半（ハードが行き渡り、ソフトだけが売れる時期）に利益率が跳ね上がる。
> 家庭用ゲーム会社の決算は、**この周期を頭に入れないと読み間違える**。

ソニーのゲーム事業（G&NS）は逆に、ハード販売のピークを過ぎた成熟期に入っている。
2026年3月期は売上高約4兆6,856億円（ほぼ横ばい）、営業利益4,632億円（+11.6%）で**過去最高益**と報じられた。
PS5の販売台数は減っているのに利益は最高、という一見矛盾した姿は、
**利幅の薄いハードが減り、利幅の厚いネットワークサービス（PS Plus）とサードパーティ手数料が残った**結果である。

## 3. PC：ハードを売らないのに30%取る、Steamという流通支配

### 3-1. 何が違うのか

PCゲーム市場の最大の特徴は、**プラットフォーマーがハードを一切供給していない**のに、
流通（ストア）を握るだけで家庭用と同率の手数料を取っている点である。

| 論点           | 家庭用                                     | PC（Steam）                                           |
| -------------- | ------------------------------------------ | ----------------------------------------------------- |
| ハードの供給   | プラットフォーマーが作って売る（時に赤字） | 供給しない。ユーザーが自作・購入                      |
| 手数料         | 約30%（ロイヤリティ）                      | **30%**（累計1,000万ドル超で25%、5,000万ドル超で20%） |
| 手数料の根拠   | ハード赤字の回収、開発支援、品質管理       | 配信・課金・コミュニティ・実績・MOD・返金の運営       |
| 独占度         | 3社が並立                                  | **Steamが事実上の一強**                               |
| 参入のしやすさ | 開発機材の貸与・審査が必要                 | 登録料100ドル程度で誰でも出せる                       |

Steamの2025年のゲーム総流通額は**2兆5,000億円超**との推計が報じられている（民間推計、公式発表なし）。
Valveは非上場で数字を公表しないため、**外部推計しか存在しない点に注意**が必要である。

```
【なぜSteamは「ハードを持たずに関所」になれたか】

   ① ライブラリのロックイン
      買ったゲームがSteamアカウントに紐づく。何百本も溜まる
                  │
   ② フレンド・実績・ワークショップ（MOD共有）
      遊ぶ理由ではなく「居続ける理由」が積み上がる
                  │
   ③ 開発者から見て「ここに出さないと存在しないのと同じ」
      → 他ストアが30%を割っても（Epic は12%）決定打にならない
                  │
                  ▼
      ネットワーク効果 × スイッチングコスト の二重の堀
      （理屈は ../09_プラットフォーム・SNS/01_プラットフォームの経済学.md）
```

### 3-2. 30%は妥当か、という争い

Steamの手数料については2021年以降、開発者による集団訴訟が米国で起きている（係争中と報じられる）。
論点はアプリストアの30%問題と同型である（→ [プラットフォーム・SNS ③](../09_プラットフォーム・SNS/03_規制と社会的論点.md)）。
ただしSteamには**規制当局の事前規制が及んでいない**点が大きく違う。
日本のスマホ新法もEUのDMAも、対象はスマートフォンのOS・ストアであって、PCストアではない。

## 4. モバイル：基本無料と、少数の重課金者が支える経済

### 4-1. 構造

モバイルゲームの主流は **F2P（Free to Play、基本無料）** である。ダウンロードと基本プレイは無料で、
アイテム・キャラクター・時間短縮などに課金してもらう。

```
【F2Pの収益ピラミッド（業界で語られる典型的な形。比率は概念値）】

   課金者の構成                     売上への寄与
   ─────────────                 ────────────────
   ホエール（重課金者） 約1〜2%  ───▶  売上の 40〜60%  ← ここが生命線
   ドルフィン（中課金者）約5〜10% ───▶  売上の 20〜30%
   ミノー（少額課金者） 約10%     ───▶  売上の 10〜20%
   無課金者          約80〜90%   ───▶  売上ゼロ
                                         ▲
                                         └─ ただし「対戦相手」「人口」として
                                            課金者の満足度を支えている＝無駄ではない

   ※ 課金率（全プレイヤーのうち課金する人の割合）は数%が一般的とされる
```

**無課金者が8〜9割いるのに成立する**のがF2Pの本質である。
無課金者はコスト（サーバ代）でありながら、同時に**ゲームの賑わいそのもの**を供給している。
つまりモバイルゲームは、課金者と無課金者のあいだの一種の両面市場でもある。

### 4-2. 市場としての現在地

| 項目                         | 数値                                                  | 年・出典                                         |
| ---------------------------- | ----------------------------------------------------- | ------------------------------------------------ |
| 世界モバイルゲーム市場       | 12兆6,001億円（前年比+1.4%）                          | 2025年／『ファミ通モバイルゲーム白書2026』の推計 |
| 国内スマホゲーム市場         | 2021年に約1.3兆円でピーク、その後減少局面と報じられる | 各種推計。定義差が大きい                         |
| ユーザーの新規アプリ発見経路 | 動画系サービス26.9%、ネット上の情報・広告25.7%        | 2025年調査／同白書                               |

> **成長が止まった理由**：スマホの普及台数が頭打ちで、**プレイヤー人口が増えない**。
> かつ2021年のAppleのATT（アプリ追跡の透明性）導入で広告のターゲティング精度が落ち、
> **新規ユーザー1人を獲得するコスト（CPI）が上がった**。
> 「広告を打って人を集め、課金で回収する」というF2Pの方程式の分母が悪化している。
> 広告側の詳細は [ネット広告](../07_ネット広告/README.md) を参照。

### 4-3. モバイルの手数料は制度で動いた

日本では2025年12月18日にスマホソフトウェア競争促進法（スマホ新法）が全面施行され、
App Storeの標準課金手数料が30%→**26%（ストア21%＋決済5%）** に変わった。
ただし**外部決済を使ってもストア手数料21%は残る**ため、
「解禁されたのに実質負担は大きく下がらない」という批判が続いている。
制度の中身は [プラットフォーム・SNS ③](../09_プラットフォーム・SNS/03_規制と社会的論点.md) に委譲し、
**ゲーム業界側で何が起きたか**は [④ 直近トピック](04_直近トピック_2026.md) に書いた。

## 5. 3市場の横並び比較

| 軸             | 家庭用                      | PC                                   | モバイル                           |
| -------------- | --------------------------- | ------------------------------------ | ---------------------------------- |
| 課金形態       | 買い切り中心＋DLC・サブスク | 買い切り中心＋一部F2P                | **F2P＋アプリ内課金**が主流        |
| 1人あたり単価  | 6,000〜10,000円／本         | セールで大きく変動（半額以下も常態） | 無料〜青天井                       |
| 流通の関所     | 任天堂／ソニー／MS          | **Steam**（Epic、GOG等は少数派）     | App Store／Google Play             |
| 手数料         | 約30%                       | 30%（20〜25%の逓減あり）             | 15〜30%（日本は26%へ）             |
| ハード         | プラットフォーマーが供給    | ユーザーが自前調達                   | 全員が既に所有                     |
| 開発費の回収   | 発売直後の数週間が勝負      | セールで長期に薄く回収               | **運営を続けて年単位で回収**       |
| 失敗したとき   | 在庫と開発費が丸ごと損失    | 同左（ただし在庫は無い）             | サービス終了。運営費が先に出ている |
| 規制の当事者性 | 低い                        | 低い                                 | **高い**（スマホ新法・ガチャ規制） |

> **同じゲームでも収益構造が全く違う**、という本ノートの主題はこの表に集約される。
> 買い切りは「作り終えたら売上が確定する製造業」に近く、
> F2Pは「毎日客を迎え続けるサービス業」に近い。
> 必要な組織も、KPI（重視する指標）も、資金繰りも別物になる。
> 作り方と儲け方の中身は [② 作り方と儲け方](02_作り方と儲け方.md) で詳しく見る。

## 6. どの指標を見ればよいか

| 市場     | 主な指標                           | 意味                                                           |
| -------- | ---------------------------------- | -------------------------------------------------------------- |
| 家庭用   | ハード累計販売台数、タイイング比率 | 1台あたり何本ソフトを買ったか。プラットフォームの健康診断      |
| 家庭用   | デジタル比率                       | ダウンロード販売の比率。高いほど流通コストが減り利益率が上がる |
| PC       | 同時接続者数、レビュー数           | 公開データから売上を逆算する実務的な代用指標                   |
| モバイル | DAU／MAU、課金率、ARPPU、LTV、CPI  | → [② 作り方と儲け方](02_作り方と儲け方.md)                     |
| 全体     | 開発費とその回収期間               | 近年最大のリスク要因                                           |

## 用語メモ

| 用語                   | 意味                                                                                                                                 |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| **プラットフォーマー** | ゲーム機やストアを運営し、ソフトの流通を握る事業者。任天堂・ソニー・MS・Apple・Google・Valve                                         |
| **パブリッシャー**     | ゲームの販売元。資金を出し、宣伝し、リスクを負う → [②](02_作り方と儲け方.md)                                                         |
| **ロイヤリティ**       | サードパーティがプラットフォーマーに払うライセンス料。家庭用で約30%とされる                                                          |
| **かみそりの刃モデル** | 本体を安く売り、消耗品や関連商品で回収する収益モデル                                                                                 |
| **タイイング比率**     | ハード1台あたりのソフト販売本数。プラットフォームの活性度を示す                                                                      |
| **デジタル比率**       | ソフト売上のうちダウンロード販売が占める割合。パッケージより利益率が高い                                                             |
| **F2P（基本無料）**    | 無料で遊べて、一部の要素に課金する方式。モバイルの主流                                                                               |
| **課金率**             | 全プレイヤーのうち課金する人の割合。数%が一般的とされる                                                                              |
| **ホエール**           | 極端に多く課金する少数のユーザー。F2Pの売上の過半を支えることがある                                                                  |
| **ATT**                | Appleのアプリ追跡の透明性。2021年導入。広告ターゲティング精度を落とした                                                              |
| **スマホ新法**         | スマホソフトウェア競争促進法。2025年12月18日全面施行 → [プラットフォーム・SNS ③](../09_プラットフォーム・SNS/03_規制と社会的論点.md) |
