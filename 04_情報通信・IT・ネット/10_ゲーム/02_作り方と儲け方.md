# 作り方と儲け方

ゲームは「作るのに数年と数十〜数百億円かかり、売れるかどうかは出してみるまで分からない」商品である。
このノートでは、**開発費がなぜ膨らむのか**、**どう回収する設計になっているのか**、
そして**なぜIP（知的財産）の多角展開に各社が向かうのか**を分解する。

## 1. 開発費は30年で桁が3つ変わった

| 年代         | AAAタイトル1本の開発費（目安）         | 開発人数                    | 開発期間   |
| ------------ | -------------------------------------- | --------------------------- | ---------- |
| 1990年代前半 | 数千万〜1億円                          | 10〜30人                    | 1年前後    |
| 2000年代     | 10〜30億円                             | 50〜100人                   | 2〜3年     |
| 2010年代     | 50〜100億円                            | 100〜300人                  | 3〜4年     |
| 2020年代     | **200〜500億円が大型の中央値**との指摘 | 数百〜1,000人超（外注含む） | **5〜7年** |

- 2026年9月の報道では、AAAゲームの予算規模は**2.5億〜4億ドル（約380〜610億円）**、
  1990年代半ばからの30年で約400倍に膨らんだとされる（業界関係者の発言ベース）。
- 東京ゲームショウ2026（2026年9月開催）に合わせた報道では、
  最大級のタイトルで**推定3,000億円規模**という数字も挙がった。
  ただしこれは**開発費と宣伝費を合わせた推計**であり、公式発表ではない。
- 『グランド・セフト・オートVI』は開発費10億〜20億ドル規模との**推定**が複数報じられているが、
  Rockstar GamesもTake-Twoも公表していない。発売日は2026年11月19日に再延期された（2025年11月発表）。

> **AAA（トリプルエー）** ＝ 業界用語で「最大規模の予算・人員をかけた大作」のこと。
> 正式な定義はなく、映画の「大作」と同じくらい曖昧な呼び方である。

```
【なぜ開発費は膨らむのか：4つの独立した圧力】

  ① 映像品質の要求         4K・レイトレーシング・フォトリアル
     ハードが進化すると      ─▶ 作り込みの工数が指数的に増える
     ユーザーの期待も上がる      （草1本、顔の毛穴1つに人が張り付く）

  ② 世界の広さの要求       オープンワールド化
     「行ける場所は全部          ─▶ 面積 × 密度 で工数が掛け算になる
      遊べるべき」

  ③ 人件費と人材の希少性   専門職（テクニカルアーティスト等）の奪い合い
                              ─▶ 都市部の人件費水準に引きずられる

  ④ 発売後も終わらない     アップデート・シーズン運営・不具合対応
     運営型ゲームの普及         ─▶ 発売が終点でなく起点になった

        ▼ 結果
  開発期間の長期化（5〜7年）＝ 企画時点の「流行り」が発売時には古い
  ＝ 当たり外れの振れ幅が拡大し、1本の失敗が会社を傾ける
```

## 2. 当たり外れの構造：なぜ「ヒット依存」から抜けられないのか

ゲームの売上分布は極端な**べき乗分布**（ごく少数が売上の大半を占める）になる。

```
【売上の分布イメージ（概念図）】

  売上
   ▲
   │██
   │██
   │██▄
   │████▄▄
   │████████▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄
   └──────────────────────────────────────────────▶ タイトル数
     上位数%が                      大多数は開発費すら回収できない
     売上の大半

  ＝ 映画・音楽・出版と同じ「ヒット商売（hit-driven business）」
     （→ ../../14_メディア・広告・エンタメ/07_映画/README.md）
```

この構造が業界の行動をほぼ説明する。

| 帰結                     | 中身                                                                                                                                                   |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **続編・リメイク偏重**   | 既存ファンという「読める需要」がある。新規IPはリスクが高すぎる                                                                                         |
| **ポートフォリオ経営**   | 年に複数本出し、1本外れても全体で吸収する。中小ほどこれができない                                                                                      |
| **レイオフの常態化**     | プロジェクト単位で人を集め、終われば削る。2026年のGDC調査では回答者の**28%が過去2年でレイオフを経験**、AAAスタジオの**6割超が過去1年でレイオフを実施** |
| **リピート販売への依存** | 旧作の移植・セール販売。開発費が済んでいるので利益率が極めて高い                                                                                       |

> **リピート販売の威力**：カプコンの2026年3月期第3四半期は営業利益543億円（前年同期比+75%）で、
> 『ストリートファイター6』『バイオハザード RE:4』などの**旧作のリピート・移植販売**が大きく寄与したと報じられた。
> 通期では営業利益730億円（+11.0%）。**過去に作ったものを売り続けられる会社が強い**、というのが近年の教訓である。

## 3. 2つの儲け方：買い切りと運営型（F2P）

### 3-1. キャッシュフローの形が正反対

```
【買い切り（パッケージ／DL販売）】
  費用 ████████████████████████        ← 5〜7年、ひたすら出ていく
  収入                          ██▇▅▃▂▁▁▁  ← 発売week1で年間売上の3〜5割
                                └ 初速で「ほぼ決まる」。外したら取り返せない

【運営型（F2P・ライブサービス）】
  費用 ██████████▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓  ← 開発費＋運営費が続く
  収入        ▁▂▃▅▇███▇▆▅▅▄▄▄▃▃▃▂▂        ← リリース後に山、その後は運営次第
                    └ イベント・新キャラ投入でこの山を作り直し続ける
```

| 軸             | 買い切り                     | 運営型（F2P）                                    |
| -------------- | ---------------------------- | ------------------------------------------------ |
| 収益の確定     | 発売後数週間でほぼ決まる     | 数年かけて積み上がる                             |
| 見るべき指標   | 販売本数、初動、リピート販売 | **DAU／MAU／課金率／ARPPU／LTV**                 |
| 必要な組織     | 開発チーム中心               | 開発＋**運営（企画・CS・分析・広告）**が常時必要 |
| 失敗の形       | 売れずに在庫と開発費が残る   | ユーザーが集まらずサービス終了。撤退コストも発生 |
| 収益の上限     | 本数 × 単価で頭打ち          | 理論上は青天井（長寿タイトルは10年以上続く）     |
| 相性のよい市場 | 家庭用・PC                   | モバイル、一部PC                                 |

### 3-2. 課金の型

| 型                                   | 中身                                           | 経済的な性質                                                          |
| ------------------------------------ | ---------------------------------------------- | --------------------------------------------------------------------- |
| **ガチャ（ランダム型アイテム提供）** | 確率でキャラ・アイテムが出る                   | 単価が伸びやすい。確率表示が法的な論点（→ [③](03_業界の構造変化.md)） |
| **バトルパス**                       | 期間内に遊ぶほど報酬が段階的に解放される定額券 | **課金額を平準化**する。ガチャ依存のリスクを下げる狙い                |
| **スキン・コスメ**                   | 見た目だけを変える。性能に影響しない           | 「課金した人が強い（Pay to Win）」批判を回避できる                    |
| **時間短縮・スタミナ**               | 待ち時間を金で飛ばす                           | 初期のソーシャルゲームの主流。近年は比重が下がった                    |
| **DLC・シーズンパス**                | 買い切りゲームへの追加コンテンツ               | 開発資産を再利用でき、利益率が高い                                    |
| **サブスク**                         | 月額で遊び放題（→ [③](03_業界の構造変化.md)）  | 収益が安定するが、1本あたりの単価は下がる                             |

> **業界の流れ**：2010年代後半以降、**ガチャ一本足からバトルパス＋スキンへの分散**が進んだ。
> 理由は2つ。①規制と批判のリスクを下げるため。②**ホエール（重課金者）の離脱に左右されにくくするため**。
> 課金の設計は、売上の最大化と同時に「収益の安定性」を買う行為でもある。

### 3-3. LTVとCPIの引き算がすべて

運営型ゲームの経済性は、突き詰めるとこの一本の式になる。

```
  【運営型ゲームが成立する条件】

     LTV（1人が生涯に落とす金額）  >  CPI（1人を連れてくる広告費）
          │                                  │
          │                                  └─ 広告単価の上昇とATTで悪化中
          │
          └─ ARPPU（課金者1人あたり単価）× 課金率 × 継続期間
                   ▲            ▲             ▲
                   │            │             └ 運営の質・イベント設計
                   │            └ 導線とオファー設計
                   └ ガチャ天井・パス価格

  この差分（LTV − CPI）が黒字の源泉。
  差が薄いタイトルは「広告を止めた瞬間に萎む」＝実質的に広告代理業に近づく
```

**日本のモバイルゲームで広告宣伝費が売上の3〜5割に達する例がある**のはこのためで、
ゲーム会社でありながら**最大の費目が広告費**という会社が珍しくない。
広告出稿側の仕組みは [ネット広告](../07_ネット広告/README.md) を参照。

## 4. 誰が作り、誰が売るか：パブリッシャーとデベロッパー

```
【分業の構図】

  IPホルダー ────┐
  （原作・権利者） │  ライセンス料
                  ▼
  パブリッシャー ──── 資金・企画・品質管理・宣伝・流通・運営
  （販売元）        │         ▲
                    │ 開発費   │ 完成したゲーム
                    ▼         │
  デベロッパー ──────────────┘
  （開発会社）    受託または共同開発

                    │ 発注
                    ▼
  外注（アウトソース）── モーションキャプチャ／3Dモデル／ローカライズ／QA
                        中国・ベトナム・東欧のスタジオが担うことが多い

           ▼ 完成後
  プラットフォーマー ── 審査・配信・課金（約30%）
```

| 立場                                   | 収益の取り方                       | 持つリスク                                         |
| -------------------------------------- | ---------------------------------- | -------------------------------------------------- |
| **パブリッシャー**                     | 売上から手数料・開発費を引いた残り | **最大**。開発費を出し、売れなければ丸損           |
| **デベロッパー（受託）**               | 開発費を受け取る（固定）           | 小さいが、上振れの取り分も無い。**稼働率がすべて** |
| **デベロッパー（自社パブリッシング）** | 売上そのもの                       | パブリッシャーと同じリスクを負う                   |
| **IPホルダー**                         | ロイヤリティ（売上の数%〜十数%）   | ほぼ無い。原資産が傷むブランドリスクのみ           |
| **プラットフォーマー**                 | 手数料 約30%                       | ほぼ無い（→ [①](01_3つの市場と収益構造.md)）       |

> **受託開発は「人月商売」である**。1人月あたりの単価 × 稼働人数 × 期間で売上が決まるため、
> 経済構造は [SIer・ITサービス](../05_SIer・ITサービス/README.md) に近い。
> 大ヒットしても取り分は増えないので、実力のあるスタジオほど自社IPを持ちたがる。

## 5. IPの多角展開：ゲームが「入口」になる経済圏

開発費の高騰と当たり外れの激しさに対する、各社の共通の答えが **IPの多角展開**である。
ゲームで作ったキャラクターと世界観を、ゲーム以外の収益源に広げる。

```
【IPの展開マップ（ゲーム発のIPの典型）】

                   ┌──▶ 続編・スピンオフ（ゲーム）
                   ├──▶ アニメ・映画（→ ../../14_メディア・広告・エンタメ/09_アニメ/README.md）
   ゲーム本編 ─────┼──▶ トレーディングカード・玩具・グッズ
   （投資が最も重い）├──▶ ライセンス（アパレル・食品・コラボ）
                   ├──▶ テーマパーク・常設施設
                   ├──▶ eスポーツ大会（→ ../11_eスポーツ/README.md）
                   └──▶ 音楽・コンサート・舞台

   ※重要なのは「右に行くほど自社の投資が軽く、利益率が高い」こと
     ライセンス収入は原価がほぼゼロ。一方ゲーム本編は毎回リスクを取る
```

| IP                                   | 規模感                                                                                                 | 年・出典                             |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------ | ------------------------------------ |
| ポケモン                             | 世界のIP累積収入ランキングで1位、約921億ドル（ミッキーマウス約705億ドル、スター・ウォーズ約656億ドル） | 民間集計の**推計**。2026年時点の報道 |
| 株式会社ポケモン（IPを管理する会社） | 売上高 約4,109億円、純利益 約703億円                                                                   | 2025年2月期／同社決算                |

> **なぜゲーム会社がIPにこだわるのか**：ゲーム本編は5年に1本しか出せず、外す可能性がある。
> しかしIPが育てば、**本編を出していない年にもライセンス収入が入る**。
> ゲーム事業の「当たり外れ」を、IP事業の「安定収入」で平らにするのが各社の設計である。
> IPビジネスそのものの構造は [キャラクター・IP](../../14_メディア・広告・エンタメ/10_キャラクター・IP/README.md) に委譲する。

日本のゲーム大手がIP企業化している様子は決算にも表れる。
2026年3月期のバンダイナムコホールディングスの営業利益は1,895億円（+5.2%）、
スクウェア・エニックス・ホールディングスは547億円（+34.9%）と報じられた。
バンダイナムコは**トイホビー（玩具・カード）事業がゲーム事業と並ぶ柱**であり、
「ゲーム会社」という括りだけでは会社の姿を捉えきれない。

## 6. 海外展開とローカライズ

日本のゲームの売上は、大手ほど**海外比率が7〜8割**に達する。市場の大きさがそもそも違うためである。

| 段階               | やること                                           | 難しさ                                                                     |
| ------------------ | -------------------------------------------------- | -------------------------------------------------------------------------- |
| **翻訳**           | テキストの言語変換                                 | 量が膨大。1本100万文字を超えることもある                                   |
| **ローカライズ**   | 文化的な調整（ジョーク、固有名詞、UI幅、音声収録） | 直訳では成立しない。作品の評価を左右する                                   |
| **カルチャライズ** | 表現規制への対応（暴力・宗教・性的表現）           | 国ごとにレーティング機関の基準が違う                                       |
| **法令対応**       | 年齢制限、課金表示、データ保護（GDPR等）           | 中国は**版号**（出版番号）がないと配信できない → [③](03_業界の構造変化.md) |
| **運営体制**       | 現地カスタマーサポート、時差対応、決済手段         | 運営型では特に重い                                                         |

日本国内向けの「レーティング」は **CERO**（コンピュータエンターテインメントレーティング機構）が、
米国は ESRB、欧州は PEGI が担う。いずれも**業界の自主規制団体**であり、政府機関ではない。

## 用語メモ

| 用語                             | 意味                                                                       |
| -------------------------------- | -------------------------------------------------------------------------- |
| **AAA（トリプルエー）**          | 最大規模の予算・人員をかけた大作。明確な定義はない                         |
| **インディー**                   | 小規模・独立系の開発。数人〜十数人で作り、Steamを主戦場にする              |
| **パブリッシャー／デベロッパー** | 販売元／開発会社。資金とリスクを持つのが前者                               |
| **サードパーティ**               | プラットフォーマー以外のソフト供給者                                       |
| **ライブサービス（運営型）**     | 発売後も継続的に更新・イベントを行い、長期に課金してもらう方式             |
| **バトルパス**                   | 期間限定の定額券。遊ぶほど報酬が解放される。課金額を平準化する             |
| **DAU／MAU**                     | 1日／1か月あたりのアクティブ利用者数                                       |
| **ARPPU**                        | 課金者1人あたりの平均課金額（Average Revenue Per Paying User）             |
| **LTV**                          | 1人のユーザーが生涯に生む収益（Life Time Value）                           |
| **CPI**                          | ユーザー1人をインストールさせるのにかかった広告費（Cost Per Install）      |
| **リピート販売**                 | 過去作の継続販売・移植・セール。開発費が済んでおり利益率が高い             |
| **CERO**                         | 日本のゲームレーティング（年齢区分）を行う自主規制団体                     |
| **版号**                         | 中国でゲームを商用配信するために必要な出版番号 → [③](03_業界の構造変化.md) |
