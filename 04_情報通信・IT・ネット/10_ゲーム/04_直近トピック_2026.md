# 直近トピック（2026年9月時点）

報道・調査会社の推計・企業IRをもとにした整理。**確定した事実と、推計・報道ベースの数字を明示して区別する**。
数値は発表時点のものであり、最新は各一次情報で確認すること。

## 1. 市場は最高水準を更新。ただし伸びているのは家庭用とPCで、モバイルではない

**確定している事実（調査会社の推計として公表されたもの）**

角川アスキー総合研究所は2026年8月6日、『ファミ通ゲーム白書2026』を発刊した。

| 指標                                      | 2025年の数値                       | 前年比                             |
| ----------------------------------------- | ---------------------------------- | ---------------------------------- |
| 世界ゲームコンテンツ市場                  | **32兆1,024億円**（2,145.6億ドル） | +3.5%（同一通貨ベース+5.0%）       |
| ── 家庭用                                 | —                                  | **+8.0%**                          |
| ── PC                                     | —                                  | +5.8%                              |
| ── モバイル                               | 12兆6,001億円                      | **+1.3%**（モバイル白書では+1.4%） |
| 国内ゲーム市場                            | **2兆5,885億円**                   | +8.0%                              |
| 国内ゲーム人口                            | 5,639.3万人                        | +3.0%                              |
| 国内の家庭用ゲーム機平均単価（2026年6月） | 5万1,376円                         | 前年同月比+9.5%                    |

```
【2025年の成長の中身（前年比）】

  家庭用  +8.0%  ████████████████  ← Nintendo Switch 2 の発売年
  PC      +5.8%  ███████████▌
  モバイル +1.3%  ██▌            ← 市場は最大だが、ほぼ横ばい
  ────────────────────────────
  全体    +3.5%

  ＝ 「ゲーム市場は成長している」という話の実態は
     ハード世代交代による家庭用の一時的な押し上げが大きい
```

> **注意**：これは調査会社の**推計**であり、公的統計ではない。
> 定義（ハード本体・周辺機器・eスポーツを含むか）で金額は大きく変わる。
> 前年比と内訳の方向性を読む用途に使うのが適切である。

## 2. 任天堂：売上ほぼ倍増、しかし営業利益率は低下。ハード世代の教科書的な決算

**確定している事実（IR）**

任天堂の2026年3月期（2026年5月8日発表）は次のとおり。

| 項目                             | 2026年3月期                                           | 前期比   |
| -------------------------------- | ----------------------------------------------------- | -------- |
| 売上高                           | **2兆3,130億円**                                      | +98.6%   |
| 営業利益                         | **3,601億円**                                         | +27.5%   |
| 営業利益率                       | 約16%（前期は約24%）                                  | **低下** |
| Nintendo Switch 2 通期販売計画   | 当初1,500万台 → **1,900万台**へ上方修正（2025年10月） | —        |
| ゲーム専用機ソフトのデジタル比率 | **54.6%**                                             | 上昇     |
| 2027年3月期 営業利益予想         | 3,700億円                                             | +2.7%    |

- Switch 2は発売から約4か月（2025年9月末まで）で累計1,000万台を突破したと決算資料で示された。
- 2026年5月には Switch 2 本体の**値上げ**が併せて発表されたと報じられた。

> **読みどころ**：売上が倍になったのに利益率が8ポイント下がった。
> これは業績の悪化ではなく、**利幅の薄いハードの売上構成比が上がったため**である。
> 家庭用ゲーム会社の決算は世代サイクルで形が変わる（→ [① 3つの市場と収益構造](01_3つの市場と収益構造.md)）。

**ソニー（比較）**：2026年3月期のゲーム&ネットワークサービス（G&NS）は
売上高 約4兆6,856億円（ほぼ横ばい）、営業利益 **4,632億円（+11.6%）で過去最高益**と報じられた。
PS5の販売台数は減少したが、サードパーティソフトとネットワークサービスが伸び、円安も寄与した。
**ハードのピークを過ぎた成熟期に利益率が上がる**という、任天堂と対をなす姿である。

## 3. 開発費の高騰が「危機」として語られ始めた

**報道ベース**

- 2026年9月、業界の重鎮らが現状を**「アタリショック以来の危機」**と表現したと報じられた。
  AAAゲームの予算は**2.5億〜4億ドル（約380〜610億円）**規模、
  1990年代半ばから約400倍に膨らんだとされる。
- 東京ゲームショウ2026（2026年9月17〜21日開催、史上初の5日間）に合わせた日本経済新聞の報道では、
  大作ソフトの価格が**1万円台に乗る**動きと、**推定3,000億円規模**の開発費のタイトルが取り上げられた。
  この3,000億円は開発費と宣伝費を含む**推計**である。
- 同時に、AIデータセンター向け需要によるメモリ（DRAM）などの**部材不足・高騰**が指摘されている。
  ゲーム機は「まず安く売って後でソフトで回収する」設計なので、部材高騰の影響を受けやすい。

```
【2026年に業界が直面している板挟み】

     開発費 ↑↑        部材コスト ↑        ユーザーの可処分時間 →（増えない）
        │                  │                        │
        ▼                  ▼                        ▼
   1本あたりの      ハードを安く売る     UGC・動画・SNSと
   回収必要額が増    モデルが揺らぐ       時間を奪い合う
        │                  │                        │
        └──────────┴────────────────┘
                            ▼
              ソフト価格の上昇（1万円時代）／サブスク／
              リピート販売への依存／レイオフ
```

**レイオフ**：GDCの「2026 State of the Game Industry」（業界関係者2,300人以上、2026年1月公表）では、
回答者の**28%が過去2年でレイオフを経験**、**AAAスタジオの6割超が過去1年でレイオフを実施**と報告された。
マイクロソフトが2025年に約4,800人規模の削減を行ったことも、Xbox不振とAAA開発費高騰の文脈で報じられている。

## 4. 生成AIへの評価が急速に悪化。「使ってはいるが、良いとは思わない」

**確定している事実（調査結果）**

GDC「2026 State of the Game Industry」より。

| 設問                           | 2024年 | 2025年 | 2026年  |
| ------------------------------ | ------ | ------ | ------- |
| 生成AIは業界に**悪影響**       | 18%    | 30%    | **52%** |
| 生成AIは業界に**良い影響**     | —      | 13%    | **7%**  |
| 実際に業務で生成AIを使っている | —      | —      | **36%** |

用途の内訳は、調査・ブレスト81%、事務47%、コード支援47%、プロトタイピング35%に対し、
**ゲーム内のAIキャラなどプレイヤーが直接触れる機能は5%**にとどまる。

> **構図**：生成AIは開発費高騰への最有力の対抗手段として期待されている一方で、
> レイオフが続くなかで「人を減らす口実」と受け取られ、学習データの権利問題も未整理である。
> **導入は進み、評価は下がる**という分離が2026年の特徴である（→ [③ 業界の構造変化](03_業界の構造変化.md)）。

## 5. スマホ新法の施行1年目：日本にiOS版Epic Games Storeが上陸した

**確定している事実**

- スマホソフトウェア競争促進法（スマホ新法）は**2025年12月18日**に全面施行。
- **2026年5月1日**、Epic Games が日本のiOS向けに代替アプリマーケットプレイス
  **Epic Games Store** を開設。『フォートナイト』がApp Storeからの削除以来
  **約5年9か月ぶり**にiPhoneで遊べるようになった。
- 施行日には別の代替ストア「AltStore PAL」もインストール可能になったと報じられた。

**争点（報道ベース）**

- Appleは日本において、**代替ストア経由の取引に21%、アプリ外決済に15%**の手数料を課しているとされ、
  Epic Games のティム・スウィーニー氏はこれ（コアテクノロジー料を含む）が
  **スマホ新法に違反している**と主張したと報じられる。
- App Store標準課金の手数料は30%→**26%（ストア21%＋決済5%）** に変わったが、
  **外部決済を選んでもストア手数料21%は残る**。

```
【ゲーム事業者から見た「解禁」の実態（報道ベースの概念図）】

  課金1,000円あたりの取り分

  施行前        ┌─ Apple 300円 ─┬──────── 事業者 700円 ────────┐

  施行後(標準)  ┌ ストア210円 ┬決済50円┬─────── 事業者 740円 ──────┐

  施行後(外部)  ┌ ストア210円 ┬外部決済 ┬────── 事業者 755〜770円 ───┐
                       ▲
                       └ ここが消えないので「扉は開いたが下がらない」

  ※ 代替ストア経由でも21%相当の負担が残るとされる点が争点
```

制度そのものの詳細と両論は
[プラットフォーム・SNS ③ 規制と社会的論点](../09_プラットフォーム・SNS/03_規制と社会的論点.md) および
[同 ④ 直近トピック](../09_プラットフォーム・SNS/04_直近トピック_2026.md) に委譲する。

## 6. UGCプラットフォームの存在感：Robloxは日次1億人超

**確定している事実（同社決算・公表値）**

| 指標                     | 数値                       | 時点                              |
| ------------------------ | -------------------------- | --------------------------------- |
| DAU                      | 約**1億2,300万人**（+10%） | 2026年4〜6月期                    |
| 同（別発表）             | 約1億4,400万人             | 2026年6月の講演で示されたとの報道 |
| 四半期売上               | 14億6,900万ドル（+36%）    | 2026年4〜6月期                    |
| ブッキングス             | 15億5,700万ドル（+8%）     | 同上                              |
| クリエイターへの分配総額 | **年15億ドル**             | 2025年                            |

- 2026年4〜6月期決算では**売上は36%増だが、今後の課金収入は失速見通し**と報じられた。
  成長の中心は欧米圏以外に移っている。
- IP保有者が登録し、UGCクリエイターが公式に利用できるようにする**IPライセンス制度**が整備され、
  分配率をIP保有者側が設定できると報じられる。

> **既存ゲーム会社にとっての意味**：Robloxは「競合タイトル」ではなく**可処分時間の競合**である。
> かつ、**開発リスクを負わずにゲームを供給し続けられる**構造を持つため、
> 1本数百億円を賭ける従来型とは資本効率が根本的に違う（→ [③](03_業界の構造変化.md)）。

| 時期          | 出来事                                                                                                 |
| ------------- | ------------------------------------------------------------------------------------------------------ |
| 2024年2月     | 加入者3,400万人と公表（Microsoftの最後の単独開示と報じられる）                                         |
| 2025年10月    | Ultimateを19.99ドル→**29.99ドル**（約50%値上げ）                                                       |
| 2026年4月     | 反発を受け**22.99ドル**へ引き下げ。「数百万人の加入者を失った」と認めたと報じられる                    |
| 2026年9月時点 | Ultimate 22.99ドル／Premium 14.99ドル／PC 13.99ドル／Essential 9.99ドルの4階層                         |
| 2026年11月〜  | クラウドゲーミングに月間時間上限（Ultimate 15時間、Premium 10時間、Essential 5時間）を導入と報じられる |

加入者数は2026年時点で**約3,000万人（ピーク約3,500万人から減）**とする報道と、
**4,000万人**とする推計が併存しており、**確定値は存在しない**。

> **読み方**：値上げ→離脱→値下げ、という一連の動きは、
> **「遊び放題」の採算点が業界自身にもまだ分かっていない**ことを示している。
> クラウドへの時間上限導入は、遊ばれるほどGPU原価がかかるという構造への直接の対処である。

**確定している事実**

- 『グランド・セフト・オートVI』は2025年11月の発表で、
  発売日が2026年5月26日から**2026年11月19日**へ再延期された。
- 開発費は**10億〜20億ドル規模**との推定が複数あるが、Rockstar Games／Take-Two は公表していない。

> **なぜ一社の延期が業界ニュースになるのか**：この規模のタイトルは
> 発売週に他社の新作を吹き飛ばすため、**他社が発売日をずらす**。
> 1本のスケジュールが業界全体の年間カレンダーを規定するという点自体が、
> ヒット依存の産業構造（→ [② 作り方と儲け方](02_作り方と儲け方.md)）を象徴している。

## 10. 全体の構図（まとめ）

1. **市場は最高水準だが、成長の中身はハード世代交代による一時的な押し上げ**。
   最大市場のモバイルはほぼ横ばいで、成長エンジンではなくなっている。
2. **開発費が業界の最大のリスクになった**。AAAで数百億円、最大級で1,000億円超という水準は、
   1本の失敗が会社を傾けるレベルであり、レイオフとリピート販売依存を常態化させている。
3. **「1本いくらで売る」モデルが限界に来ており、答えが割れている**。
   ソフト価格1万円への値上げ、サブスク、F2P、UGC、生成AI——いずれも同じ問題への別解である。
4. **プラットフォーム手数料は制度で動き始めたが、経済実態はまだ大きく変わっていない**。
   日本ではEpic Games Storeが上陸したが、実質負担は依然として争点のまま。
5. **強いのはIPを持ち、ゲーム以外でも稼げる会社**。
   ゲーム単体の当たり外れを、IP事業の安定収入で平らにする設計が主流になっている。

| ------------------------------ | ----------------------------------------------------------------------------------------------------------- |
| **ブッキングス（Bookings）**   | 受け取った代金のうち、会計上まだ売上に計上していない分を含む「実際に入ってきたお金」。UGC系の実勢を見る指標 |
| **デジタル比率**               | ソフト売上のうちダウンロード販売が占める割合。任天堂は2026年3月期で54.6%                                    |
| **コアテクノロジー料**         | Appleが代替ストア・外部決済の利用時に課すとされる基盤利用料。争点のひとつ                                   |
| **アタリショック**             | 1983年前後に北米の家庭用ゲーム市場が急激に縮小した出来事。供給過剰と品質低下が原因とされる                  |
| **State of the Game Industry** | GDC（Game Developers Conference）主催団体による毎年の業界アンケート調査                                     |
