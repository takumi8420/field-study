## このフォルダの読み方

動画配信・音楽配信を **産業として** 理解するためのノート群。
この業界は **「メディア型＝IPの権利構造」** で読み解くのが正解で、
配信事業者は「コンテンツを作る人」ではなく **「他人が持つ権利を買い集めて束ね、月額で貸し出す人」** である。
だから骨格は、①動画のお金の回し方、②音楽のお金の分け方、③そもそも何の権利を買っているのか、の3本にした。

## 1. 業界の定義・範囲

**動画・音楽配信**＝ インターネット回線を通じて映像・音声コンテンツを視聴者に届け、
月額課金・広告・都度課金のいずれかで対価を得る事業。

```
【この業界の守備範囲】

 ┌──────────────────────────────────────────────┐
 │ 動画 │ SVOD（月額見放題）  Netflix / U-NEXT / Prime Video   │
 │      │ AVOD（広告型）      TVer / ABEMA無料 / YouTube        │
 │      │ FAST（広告型リニア） Samsung TV Plus / FAST ch         │
 │      │ TVOD・EST（都度／購入） Amazon / Apple TV             │
 │      │ ライブ配信          DAZN / 配信ライブ / ウェビナー     │
 ├──────────────────────────────────────────────┤
 │ 音楽 │ サブスク            Spotify / Apple Music / YouTube   │
 │      │ ダウンロード販売    mora / iTunes Store                │
 │      │ 広告収入型          YouTube / 無料プラン               │
 ├──────────────────────────────────────────────┤
 │ 支える層 │ CDN・エンコード・DRM・課金基盤・権利管理事業者     │
 └──────────────────────────────────────────────┘
```

境界の引き方：

- **コンテンツを「作る」側（制作会社・レーベル・製作委員会）は範囲外**。
  ただし Netflix のように自社で作る事業者が増え、境界は年々曖昧になっている
- **UGC（一般ユーザー投稿）中心のサービス**は [プラットフォーム・SNS](../09_プラットフォーム・SNS/README.md) 寄り。
  YouTube は両方にまたがるため、本フォルダでは「プロ制作コンテンツの流通経路」としてだけ扱う
- **ゲーム実況・eスポーツ配信**は [eスポーツ](../11_eスポーツ/README.md) と [ゲーム](../10_ゲーム/README.md) 側
- **放送そのもの（地上波・BS・CS）は範囲外**。TVer は放送局が出す「見逃し配信」なので本フォルダ

## 3. バリューチェーン（川上 → 川下）

```
 権利者 ──▶ アグリゲーター ──▶ 配信事業者 ──▶ 配信基盤 ──▶ 視聴者
 ────      ──────────      ────────      ──────      ──────
 制作会社     配給／ディストリ    Netflix       CDN         スマホ
 レーベル     ビューター          U-NEXT        エンコード   テレビ(CTV)
 製作委員会   権利管理事業者      Spotify       DRM         PC
 放送局       （JASRAC/NexTone）  ABEMA         課金基盤     スマートスピーカー

      ▲ 交渉力の源は   ▲ 束ねることで   ▲ 顧客接点と    ▲ 完全に
        「独占できるか」   小口権利を       視聴データを      コモディティ
                           使える形に       握る＝最強       （価格勝負）
```

- 付加価値が最も集まるのは **配信事業者**。理由は「顧客との契約」と「誰が何を何分見たか」を独占できるから
- 次に強いのは **代替不可能なIPを持つ権利者**。スポーツ中継権・人気アニメ・話題の新譜は買い手が複数いるので値が吊り上がる
- 逆に **CDN・エンコードは値下げ圧力が強い**。差別化しづらく、規模がすべて
- 詳細は [③ 権利とインフラ](03_権利とインフラ.md)

## 5. 収益モデル・コスト構造

```
【動画SVODの損益の骨格】

  売上 ＝ 会員数 × ARPU（1人あたり月額単価）× 12
       −
  コンテンツ費（償却）  ← 費用の 50〜60%。最大の固定費
  配信費（CDN・帯域）    ← 視聴時間に比例する変動費
  マーケティング費       ← 新規獲得（CAC）
  技術・人件費

  ▲ ポイント：コンテンツ費は「先に払って、後から会員で回収する」。
    作った瞬間は赤字。会員数が読み違うと一気に減損になる。
```

```
【音楽サブスクの損益の骨格】

  売上100 ──▶ 権利者へ約65〜70 ──▶ 原盤権（レーベル）へ大半
              （レベニューシェア）   ＋ 著作権（出版社・JASRAC等）へ一部
        ──▶ 手元に約30
              −（決済手数料・サーバ費・人件費・マーケ費）

  ▲ ポイント：売上が伸びても**原価率がほぼ固定**なので、
    利益は「規模でコストを薄める」以外に出しようがない。
```

| 論点                | 中身                                                                                             |
| ------------------- | ------------------------------------------------------------------------------------------------ |
| 動画のコンテンツ費  | 制作／ライセンス取得費を資産計上し、視聴の見込みに応じて数年で償却する。**見込みが外れると減損** |
| 動画の粗利構造      | 会員が1人増えたときの追加費用はCDN代のみ。**損益分岐を超えると利益が急に伸びる**                 |
| 音楽の原価率        | 売上の**65〜70%前後が権利者への支払い**。構造的に薄利で、Spotifyは長く赤字だった                 |
| 広告型（AVOD/FAST） | 売上＝視聴時間 × 広告挿入率 × CPM。会員数ではなく**視聴時間が商品**                              |
| 季節性              | 動画は年末年始・大型作品公開時に山。スポーツ配信は大会日程に完全連動                             |
| 解約率（チャーン）  | 月次 2〜5% が一つの目安とされる。**作品目当ての加入は見終わると抜ける**                          |

→ 詳細は [① 動画配信の経済](01_動画配信の経済.md)

## 6. 競争要因（KSF）と参入障壁

**KSF（成功の鍵）**

1. **独占できるコンテンツを持てるか**：同じ作品がどこでも見られるなら、選ばれる理由は価格だけになる
2. **コンテンツ投資の規模**：年間数千億〜2兆円級の投資を続けられるのは世界で数社しかいない
3. **解約されない理由づくり**：毎月「見たいもの」が切れないラインナップの厚み、束ね売り（バンドル）
4. **レコメンドと視聴データ**：何を作るか・何を買うかの判断精度に直結する
5. **課金と決済の摩擦の低さ**：キャリア決済・アプリ内課金・ポイント連携
6. **権利処理のオペレーション力**：1本の作品に何十もの権利者がいる。ここが遅いと配信できない

**参入障壁**

| 障壁                                            | 強さ     | 理由                                                                       |
| ----------------------------------------------- | -------- | -------------------------------------------------------------------------- |
| **グローバルSVODへの参入**                      | 極めて強 | 先行投資が兆円単位。回収まで数年赤字を許容できる資本が要る                 |
| **独占コンテンツの確保**                        | 強       | 人気IPは買い手が複数いて値が上がる。金だけでは勝てず、制作者との関係が要る |
| **配信技術そのもの**                            | **弱**   | CDNもエンコードもクラウドで買える。技術は差別化要因にならなくなった        |
| **ニッチ特化型（アニメ・スポーツ・K-POPなど）** | 中       | 権利さえ押さえれば小さく始められる。ただし更新時に権利料を吊り上げられる   |
| **音楽サブスクへの参入**                        | 強       | レーベル3大メジャーとの契約が前提。条件は先行者ほど有利                    |

> ポイント：**この業界の障壁は「技術」ではなく「権利」と「継続的な投資体力」**。
> だから勝者はどんどん減り、2025〜2026年にかけて大型再編が起きている。

## 7. 規制・法制度

| 領域                               | 中身                                                                                                   |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------ |
| **著作権法**                       | 配信は「公衆送信権（送信可能化権）」の対象。権利者の許諾なしには配信できない                           |
| **著作隣接権**                     | 実演家（歌手・俳優）とレコード製作者（レーベル）が持つ権利。**音楽配信では原盤権が最重要**             |
| **著作権等管理事業法**             | JASRAC・NexTone など管理事業者の業務を規律。使用料規程は文化庁に届出                                   |
| **放送法**                         | 配信サービスは原則として対象外。ただしNHKのネット必須業務化（2025年施行）で境界が動いた                |
| **電気通信事業法（外部送信規律）** | 2023年施行。利用者情報の外部送信について通知・公表が必要                                               |
| **消費者契約・特定商取引法**       | サブスクの解約導線（いわゆるダークパターン）への規制強化が進む                                         |
| **海賊版対策**                     | 2020年改正でリーチサイト規制とダウンロード違法化の範囲拡大。官民で削除要請体制                         |
| **生成AI**                         | 著作権法30条の4（情報解析目的の利用）の解釈を文化審議会が整理（2024年3月「AIと著作権に関する考え方」） |

→ 詳細は [③ 権利とインフラ](03_権利とインフラ.md)

## 8. 最近のトピック

→ [④ 直近トピック（2026年9月時点）](04_直近トピック_2026.md)

1. **ワーナー争奪戦が決着**：2025年12月にNetflixが827億ドルで合併契約 → Paramount Skydance が対抗 → 2026年2月にWBD取締役会が1,109億ドルの対案を優位と判断し、Netflixは撤退。規制審査と独禁訴訟が続く
2. **広告付きプランが主流に**：Netflixの新規加入の半数超が広告付きを選択。無料に近い入口を作り、**広告で二階建てに稼ぐ**モデルへ
3. **YouTubeがテレビの一番手に**：2026年5月にNielsen集計でテレビ視聴時間シェア13.8%と自己最高
4. **国内は「値上げで伸びる」局面**：SVOD市場6,017億円（2025年）。成長要因は新規加入ではなく単価上昇と複数契約。ABEMAは2026年4月に値上げ、同時期に初の四半期単体黒字化
5. **音楽はAIとの綱引き**：世界売上は11年連続成長の一方、Spotifyは過去1年で7,500万曲超のスパム楽曲を削除したと発表（2025年9月）

## 9. 用語メモ

| 用語                   | 意味                                                                           |
| ---------------------- | ------------------------------------------------------------------------------ |
| **SVOD**               | 月額見放題（Subscription VOD）→ [①](01_動画配信の経済.md)                      |
| **AVOD／FAST**         | 広告型の無料配信／広告型の無料「チャンネル」配信 → [①](01_動画配信の経済.md)   |
| **ARPU**               | 1利用者あたりの平均売上。会員数×ARPUが売上になる → [①](01_動画配信の経済.md)   |
| **チャーン（解約率）** | 月あたり何％が解約するか。LTVを決める最大変数 → [①](01_動画配信の経済.md)      |
| **プロラタ方式**       | 音楽サブスクの分配方法。再生シェアで原資を按分する → [②](02_音楽配信の経済.md) |
| **原盤権**             | 録音物そのものへの権利。レーベルが持つことが多い → [③](03_権利とインフラ.md)   |
| **CDN**                | 各地のサーバから動画を配る仕組み。配信費の中心 → [③](03_権利とインフラ.md)     |
| **CTV**                | ネットにつながったテレビ。広告在庫として急成長中 → [①](01_動画配信の経済.md)   |
