## 1. ワーナー争奪戦 ── 「払い続けられる会社」の選別が始まった

動画配信で最大のニュースは、**Warner Bros. Discovery（WBD）の争奪戦**だった。

| 時期          | 出来事                                                                                                                                |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| 2025年12月5日 | **Netflix が WBD と合併契約**。スタジオ・配信資産を取得し、旧来のテレビネットワーク事業は分離。事業価値 **827億ドル**（1株27.75ドル） |
| 2025年12月    | **Paramount Skydance が全額現金の対抗買収提案**を提示。以後、提案を上積み                                                             |
| 2026年2月26日 | WBD取締役会が、Paramount の **1,109億ドル（1株31ドル）** の修正提案を「より優れた提案」と判断                                         |
| その後        | **Netflix は上積みせず撤退**。Paramount Skydance が勝者に                                                                             |
| 2026年4月23日 | WBD株主が合併を承認。**現在は各国規制当局の審査中**で、独占禁止法を巡る訴訟も継続中                                                   |

**この案件が示していること**：

```
【なぜ「ワーナーを誰が買うか」が業界の分岐点なのか】

  コンテンツ費は年々上がる ──▶ 単独で払い続けられる会社が減る
                                   │
          ┌────────────────┴──────────────┐
          ▼                                            ▼
   売る側（WBD、Paramount旧体制）             買う側（Netflix、Skydance）
   ・名作ライブラリと制作力はある            ・会員基盤と配信の運営力がある
   ・でも自社配信では規模が足りない          ・でも自前のIPの元手が薄い
          └────────── 統合 ─────────────┘
                              ▼
            「IPの元手」×「会員基盤」を揃えた少数の巨人だけが残る

  ▲ Netflixが撤退したのは、価格が「回収可能な範囲」を超えたと判断したため
    （＝コンテンツ費の相場が、Netflixにとっても限界に近づいている）
```

権利の集中は、**制作会社・アーティスト側の交渉相手が減る**ことを意味する。
買い手が減れば作品の売値は下がる。→ [キャラクター・IP](../../14_メディア・広告・エンタメ/10_キャラクター・IP/README.md)、
[映画](../../14_メディア・広告・エンタメ/07_映画/README.md)

## 2. 広告付きプランが「主流」になった

かつて「安い妥協プラン」だった広告付きプランが、**新規加入の入口の標準**になった。

| 事実                                                                                                       | 時点・出典                      |
| ---------------------------------------------------------------------------------------------------------- | ------------------------------- |
| Netflix の新規加入者の **半数以上が広告付きプラン**を選択                                                  | 2025年、日経・AV Watch 等の報道 |
| Netflix の広告付きプランの月間利用者が **2.5億人以上**に                                                   | 2026年、ケータイWatch 等の報道  |
| 米国の18〜49歳では、**視聴の81.1%が広告つき階層**（YouTube、Hulu、Prime Video、Peacock、Paramount+）で発生 | 2026年、Nielsen                 |

理由は [① の第6節](01_動画配信の経済.md) で見たとおり、
広告付きプランが **「会費＋広告の二重取りでARPUが落ちにくいプラン」** だから。
しかも広告主から見れば、CTV（ネット接続テレビ）は
「テレビCM並みの画面で、誰が最後まで見たか分かる在庫」なので単価が高い。

> 補助線：**動画配信は「有料放送の代替」から「テレビ広告の代替」へ、商売の軸足を移しつつある**。
> 買い手側の事情は [ネット広告](../07_ネット広告/README.md) を参照。

## 3. YouTube が「テレビで一番見られている事業者」になった

| 指標                                     | 数値                                            | 時点・出典             |
| ---------------------------------------- | ----------------------------------------------- | ---------------------- |
| YouTube のテレビ視聴時間シェア           | **13.8%**（自己最高。全配信・全放送局中トップ） | 2026年5月、Nielsen     |
| 同（前半）                               | 12.5%                                           | 2026年2月、Nielsen     |
| ストリーミング全体のテレビ視聴時間シェア | **47.6%**（前年同月44.3%）                      | 2026年4月、Nielsen     |
| YouTube の広告売上                       | 四半期 **99億ドル**（前年同期比+10.7%）         | 2026年Q1、Alphabet決算 |

**これが厄介な理由**：YouTube はコンテンツ制作費をほぼ払っていない（作るのは投稿者）。
Netflix が年200億ドル規模を投じて競っている土俵で、
**制作費ゼロに近い相手が視聴時間のトップに立っている**という構図になっている。

```
【視聴時間1時間あたりのコスト構造の違い】

  Netflix ： コンテンツ費（償却） ＋ CDN ＋ 人件費  ── 高い
  YouTube ： 投稿者へのレベニューシェア ＋ CDN      ── 変動費のみ
  TVer    ： 放送済み番組の二次利用 ＋ CDN          ── 追加制作費ほぼゼロ

  ▲ コンテンツ費を「固定費として先払いする者」と
    「売れたぶんだけ後払いする者」が同じ画面で競争している。
```

## 7. 生成AIと権利処理 ── 制度は「考え方」の段階

日本では、文化審議会著作権分科会「AIと著作権に関する考え方について」（2024年3月）と
文化庁のチェックリスト＆ガイダンス（2024年7月）が実務の出発点になっており、
2025年以降も文化庁の作業チームで議論が継続している。

現時点で固まっている整理（詳細は [③](03_権利とインフラ.md)）：

- **学習段階**：情報解析目的の利用は著作権法30条の4で原則許される。
  ただし「特定の作品の表現を出力させる目的」や「権利者の市場を直接害する利用」は例外になりうる
- **生成・利用段階**：生成物を**配信・販売する行為は権利制限の外**。
  既存作品との**類似性＋依拠性**があれば侵害となり、差止・廃棄請求の対象になる
- **AIのみで生成した楽曲**の管理団体への信託登録は現状一般に難しく、
  人間の創作的関与（編曲指示・メロディ調整など）が必要という解釈が広がっている

つまり日本の現状は「法改正」ではなく **「既存法の解釈の明確化」** の段階にある。
配信事業者にとっては、**社内の権利処理オペレーションで運用しきれるかどうか**が当面の実務課題になる。

## 8. 全体の構図（まとめ）

1. **動画は統合期に入った**。コンテンツ費を単独で払い続けられる会社が減り、ワーナーの帰趨がその象徴になった。
   権利が少数の巨人に集まるほど、制作側の交渉相手は減る
2. **成長の源泉は会員数からARPUへ移った**。広告付きプランは後退ではなく本命で、
   日本市場の2025年の二桁成長も中身は「値上げ＋併用契約」だった
3. **視聴の場はテレビ画面に戻り、そこで一番見られているのは制作費をほぼ払わないYouTube**。
   固定費で戦う陣営と変動費で戦う陣営が、同じリモコンの先で競争している
4. **音楽は11年連続成長という健全な数字の裏で、分配方式そのものがAIに攻撃されている**。
   プロラタ方式は分母の水増しに弱く、プラットフォーム側の運用（スパム削除・足切り）でしか守れない
5. **海賊版と生成AIは、どちらも「正規が便利で、権利処理が速い」ことでしか抑えられない**。
   規制や訴訟は時間稼ぎにしかならない、というのが過去20年の教訓

## 用語メモ

| 用語                   | 意味                                                                                    |
| ---------------------- | --------------------------------------------------------------------------------------- |
| **MUB**                | Monthly Unique Browser。月間ユニークブラウザ数。TVerが公表指標として使う                |
| **単体黒字化**         | 連結ではなく、その事業会社単独での黒字。ABEMAの例では周辺事業を含めない数字             |
| **superior proposal**  | M&Aで、既存の合併契約より優れていると取締役会が判断した対抗提案。契約解除の引き金になる |
| **ストリーミング詐欺** | Botによる再生水増しなどで分配原資を不正に取得する行為。プロラタ方式の弱点を突く         |
| **声のクローン**       | 実在アーティストの声をAIで模倣した音声。許諾なき生成・配信が問題化している              |
