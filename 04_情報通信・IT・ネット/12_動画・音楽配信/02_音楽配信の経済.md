# ② 音楽配信の経済

このノートで分かること：**音楽サブスクの「1再生いくら」は、実は最初から決まっていない**こと。
そして、その分配の仕組みを知ると、音楽業界がなぜサブスクで救われ、
なぜアーティストが「儲からない」と言い続けるのかが同時に説明できる。

---

## 1. 「1再生いくら」は存在しない ── プロラタ方式

音楽サブスクの分配は、**1再生ごとに単価が決まっているのではない**。
月に集まった売上を、その月の全再生数で山分けする。これを **プロラタ（按分）方式** と呼ぶ。

```
【プロラタ方式の計算】

  ステップ1  その国のその月の売上を集める
             例：会員100万人 × 1,000円 = 10億円

  ステップ2  配信事業者の取り分（約30%）を引く
             10億円 × 70% = 7億円 ← これが権利者へ配る原資（ロイヤリティプール）

  ステップ3  その月の総再生数で割る
             総再生数10億回 なら  7億円 ÷ 10億回 = 0.7円／再生

  ステップ4  各楽曲の再生数を掛ける
             ある曲が100万回 → 70万円（＝権利者側に入る総額）

  ▲ つまり単価は「他人がどれだけ聴かれたか」で動く。
    自分の再生数が同じでも、全体の再生数が増えれば単価は下がる。
```

一般に言われる「1再生 0.3〜0.5円」といった数字は、**この計算の結果を後から割り戻した平均値**であり、
国・月・サービス・契約によって上下する。有料会員の単価と、広告型無料プランの単価は数倍違う。

| 方式                                             | 仕組み                                                 | 特徴                                                                 |
| ------------------------------------------------ | ------------------------------------------------------ | -------------------------------------------------------------------- |
| **プロラタ方式**（現在の主流）                   | 全体の売上を全体の再生数で按分                         | 再生数の多いメジャー曲に有利。ヘビーユーザーの支払いが人気曲へ流れる |
| **ユーザーセントリック方式**（一部で議論・試行） | 各ユーザーの支払いを、そのユーザーが聴いた曲だけに配る | ニッチな音楽を熱心に聴く層の支払いが、その音楽に届く                 |
| **最低再生数の足切り**（近年導入が進む）         | 年間の再生数が一定に満たない楽曲を分配対象外にする     | 分配コストの削減と、後述のストリーミング詐欺対策が狙い               |

> ポイント：**単価が「決まっていない」ことが、この産業の設計思想そのもの**。
> 事業者は売上のうち固定割合しか払わないので、何回再生されても赤字にならない。
> 代わりに権利者は「全体のパイの中でどれだけシェアを取れるか」の競争に放り込まれる。

## 2. 100円はどう流れるか ── 権利の二階建て

音楽には権利が2系統あり、**両方に別々に支払う必要がある**。
これを知らないと配分表が読めない。

| 権利                                 | 何に対する権利か               | 誰が持つか                                                         | 配信での呼び方                                       |
| ------------------------------------ | ------------------------------ | ------------------------------------------------------------------ | ---------------------------------------------------- |
| **著作権**                           | 楽曲そのもの（メロディ・歌詞） | 作詞家・作曲家、および**音楽出版社**（多くはJASRAC/NexToneが管理） | 著作権使用料                                         |
| **著作隣接権のうち「原盤権」**       | その**録音物（マスター音源）** | **レコード会社（レーベル）**、または制作費を出した人               | 原盤印税                                             |
| **著作隣接権のうち「実演家の権利」** | 演奏・歌唱という行為           | 歌手・演奏家                                                       | アーティスト印税（原盤権者から支払われることが多い） |

同じ曲でも、カバー版は著作権は同じで原盤権が別。だから「あの曲だけ入っていない」現象が起きる。

```
【リスナーが払った月額1,000円の行方（ざっくりの目安）】

  1,000円
    │
    ├─ 約300円 ── 配信事業者（Spotify等）
    │               └ 決済手数料・サーバ費・人件費・マーケ費
    │                 ＋アプリ内課金なら さらにApple/Googleへ手数料
    │
    └─ 約700円 ── 権利者へ（ロイヤリティプール）
          │
          ├─ 大半（目安550円前後）── **原盤権者＝レーベル**
          │        └─ 契約に基づきアーティスト印税を支払う
          │           （メジャー契約では原盤収入の10〜20%程度、
          │             近年は条件改善の動きもある）
          │
          └─ 残り（目安100〜150円）── **著作権者**
                   └ JASRAC／NexTone → 音楽出版社 → 作詞家・作曲家

  ▲ 数値は契約・国・時期で大きく変わるため、
    「構造としてこういう順番でお金が減っていく」という理解が本質。
```

**アーティストが「儲からない」と言う理由は、単価の低さだけではない。**
原盤権をレーベルが持っている限り、配信収入の大半はまずレーベルに入り、
アーティストには契約で決めた印税率を掛けた額しか届かないからである。
逆に、自分で制作費を出して原盤権を持ち、ディストリビューター（配信代行）経由で出せば、
手数料を引いた残りがほぼそのまま入る。これが近年のインディペンデント志向の経済的な理由。

## 3. サブスクが音楽業界を「救った」経緯

世界のレコード音楽売上は、1999年のCDピークから **約15年かけて半減**し、2014年前後に底を打った。
その後 **11年連続で成長**し、2025年には **317億ドル（前年比+6.4%）** まで回復した
（IFPI Global Music Report 2026、2026年3月発表）。

```
【世界のレコード音楽売上の形】

  売上
   │    ╭─╮ CDバブル（1999年ピーク）
   │   ╱   ╲
   │  ╱     ╲       違法ダウンロード（Napster以降）
   │ ╱       ╲___   ＋ CDが売れない
   │              ╲___
   │                   ╲__ 底（2014年前後）
   │                      ╱‾‾‾‾‾  サブスク普及
   │                     ╱      ╱‾‾‾  2025年 317億ドル
   └──────────────────────────────▶
    1999            2014            2025

  ▲ 何が起きたのか：
    「違法に無料で聴ける」に対抗できたのは、
    値下げでも取り締まりでもなく、**月額で全曲が合法に聴ける利便性**だった。
```

2025年の内訳（IFPI）：

| 区分                 | 比率・状況                                                                         |
| -------------------- | ---------------------------------------------------------------------------------- |
| ストリーミング全体   | 220億ドル超、全体の **69.6%**                                                      |
| うち有料サブスク     | 全体の **52.4%**（前年比+8.8%）                                                    |
| 有料サブスク利用者数 | 世界で **8億3,700万人**                                                            |
| 地域別の伸び         | ラテンアメリカ+17.1%、中東北アフリカ+15.2%、サブサハラアフリカ+15.2%、アジア+10.9% |

> ポイント：**売上を戻したのは「CDを買っていた人」ではなく、「これまで一銭も払っていなかった人」**。
> 月額1,000円を世界中の数億人から集める構造に変わったので、
> 1人あたりの支払額は減ったのに、総額は回復した。

## 4. 日本の特殊性 ── なぜCDが残ったのか

日本は **世界で唯一に近い「フィジカル（CD）が大きいまま残った市場」** である。

2025年の国内レコード市場は **3,988億円**（日本レコード協会）。その内訳が異様に見える。

| 区分                           | 金額（2025年）  | 備考                         |
| ------------------------------ | --------------- | ---------------------------- |
| 音楽ソフト 合計                | **約2,288億円** | 市場の約57%                  |
| ─ CD                           | 1,686億円       | 単体で音楽配信全体より大きい |
| ─ 音楽ビデオ                   | 507億円         | ライブ映像など               |
| ─ アナログディスク             | 88億円          | 近年は微増傾向               |
| 音楽配信 合計                  | **約1,700億円** | 市場の約43%                  |
| ─ ストリーミング（サブスク）   | 1,377億円       | 配信の8割                    |
| ─ ストリーミング（広告収入型） | 202億円         |                              |
| ─ ダウンロード                 | 114億円         | 縮小が続く                   |

世界ではストリーミングが7割なのに、日本ではCDが市場の4割を占める。理由は音楽的好みではなく、**制度と売り方**にある。

| 要因                                       | 中身                                                                               |
| ------------------------------------------ | ---------------------------------------------------------------------------------- |
| **CDが「音楽」ではなく「グッズ」になった** | 握手会・イベント参加券・投票券を封入し、複数枚購入を前提にした売り方が定着した     |
| **特典と形態のバリエーション**             | 初回限定盤・通常盤・ジャケット違いなど、コレクション需要が積み上がる               |
| **ランキング文化**                         | オリコン等のチャートが「枚数」で決まる時代が長く、枚数を作ること自体に価値があった |
| **再販売価格維持制度**                     | 書籍などと同じく、CDは定価販売が認められている。安売りによる価格崩壊が起きなかった |
| **レンタルCDという独自チャネル**           | 「借りて録音する」文化が長く残り、サブスクへの移行動機が弱かった                   |
| **権利許諾の遅れ**                         | 大手事務所所属アーティストの楽曲解禁が遅く、「聴きたい曲がない」期間が長かった     |

ただし方向は明確に変わっている。国内でもストリーミング売上は伸び続けており
（例：2025年第3四半期の音楽配信売上は前年比114%の339.7億円、うちストリーミング317億円＝前年比116%、RIAJ）、
CDの構成比は年々下がっている。**「CDが強い」ではなく「CDの減り方が遅い」が実態**に近い。

レーベル・事務所側の事情は [音楽](../../14_メディア・広告・エンタメ/08_音楽/README.md) を参照。

## 5. 収益の重心がライブへ移った

サブスクで録音物の売上は回復したが、**アーティスト個人の手取りとしては十分でない**ケースが多い。
そこで収益の柱として大きくなったのがライブである。

国内ライブ・エンタテインメント市場（音楽コンサート＋ステージのチケット販売額）は
2025年に **8,564億円**（前年比+12.6%、3年連続で過去最高）、動員9,223万人、公演10万820回
（ぴあ総研の推計、2026年6月公表）。**録音物市場（3,988億円）の2倍以上**である。

```
【アーティストの収入構造の変化】

  1990年代                     2020年代
  ┌──────────┐          ┌──────────┐
  │ CD売上      ████████ │          │ 配信       ██        │
  │ ライブ      ███      │   ───▶   │ ライブ     ████████  │
  │ タイアップ  ██       │          │ グッズ     ████      │
  │ グッズ      █        │          │ タイアップ ██        │
  └──────────┘          │ ファンクラブ・  │
                              │ SNS・投げ銭 ██       │
                              └──────────┘

  ▲ 配信は「収入源」というより「認知を取るための入口」になった。
    再生数はライブ動員とグッズ売上に変換されて初めて金額になる。
```

この構造転換は、**配信サービスにとっても意味を持つ**。
プレイリスト掲載やアルゴリズムでの露出が、直接ライブ動員に効くようになったため、
アーティスト側にとって配信は「稼ぐ場所」ではなく「発見される場所」としての価値が上がった。

## 6. プレイヤーの構図

| 事業者                                                 | 立ち位置                   | 特徴・狙い                                                                                                                                                                                              |
| ------------------------------------------------------ | -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Spotify**                                            | 世界最大の音楽サブスク専業 | 2026年3月末で MAU **7億6,100万人**、有料 **2億9,300万人**（2026年Q1）。無料プランを入口にし、有料へ引き上げるフリーミアム型。ポッドキャスト・オーディオブックへ拡張して**原価率の低い在庫**を増やす戦略 |
| **Apple Music**                                        | ハードとの一体化           | 無料プランを持たず、全員が有料会員。デバイス購入時の導線が最大の武器                                                                                                                                    |
| **Amazon Music**                                       | EC会員経済圏               | Prime会員に一部開放し、上位プランへアップセル。単体黒字を目的にしない戦い方ができる                                                                                                                     |
| **YouTube Music／YouTube**                             | **最大の無料入口**         | 公式MVもUGCも同居。広告収入型の売上規模が大きく、権利者にとって無視できない支払い元                                                                                                                     |
| **LINE MUSIC／AWA／mora**                              | 国内勢                     | メッセージアプリ連携、カラオケ採点連携、ハイレゾ販売など日本市場に特化した機能で差別化                                                                                                                  |
| **ディストリビューター**（TuneCore Japan、BIG UP! 等） | 配信代行                   | 個人が各サービスへ配信するための取次。手数料を取り、原盤権はアーティストに残る                                                                                                                          |

Spotify は長く赤字だったが、値上げと原価率の低いコンテンツ（ポッドキャスト等）の拡大で改善した。
日本では2025年8月に値上げを発表し、Premium Standard が月額1,080円（税込）となった。

```
【音楽サブスク事業者の利益が出にくい理由】

  売上100 ──▶ 権利者へ 65〜70 （契約で固定。交渉で下げられない）
           ──▶ 手元 30〜35
                 ├ 決済手数料（アプリ内課金なら さらに重い）
                 ├ サーバ・CDN費
                 ├ 人件費・開発費
                 └ マーケティング費

  ▲ 原価率が契約で固定されているので、
    「売れば売るほど儲かる」構造にならない。
    利益を出す道は ①規模で固定費を薄める ②原価率の低い在庫を混ぜる の2つだけ。
    → だからポッドキャスト・オーディオブックへ広げる。
```

## 7. この構造から言えること

1. **単価は事業者が決めていない**。売上の固定割合を按分しているだけなので、
   「Spotifyが安く買い叩いている」という批判は半分当たり、半分外れている
2. **儲けの分岐点は原盤権を誰が持つか**。ここがアーティストの手取りを決める最大変数
3. **サブスクは業界を救ったが、救ったのはレーベルと出版社**。個々のアーティストの手取りは別問題
4. **配信は発見のための場所**になり、換金はライブ・グッズ・ファンクラブで行われる
5. AI生成曲の大量投稿と「ストリーミング詐欺」は、**プロラタ方式そのものを攻撃する**
   （総再生数を水増しすれば、他人のパイを削って自分に回せる）
   → [③ 権利とインフラ](03_権利とインフラ.md)、[④ 直近トピック](04_直近トピック_2026.md)

## 用語メモ

| 用語                           | 意味                                                                             |
| ------------------------------ | -------------------------------------------------------------------------------- |
| **プロラタ方式**               | Pro-rata。月の売上を月の総再生数で按分して分配する方式。音楽サブスクの標準       |
| **ユーザーセントリック方式**   | 各利用者の支払いを、その人が実際に聴いた楽曲だけに配る方式                       |
| **ロイヤリティプール**         | 配信事業者の取り分を引いた後の、権利者へ配る原資                                 |
| **著作権**                     | 楽曲（メロディ・歌詞）に対する権利。作詞作曲家と音楽出版社が持つ                 |
| **著作隣接権**                 | 実演家（歌手・演奏家）とレコード製作者に認められる権利                           |
| **原盤権**                     | 録音物（マスター音源）に対する権利。実務上はレコード会社が持つことが多い         |
| **原盤印税／アーティスト印税** | 原盤権者が受け取る配分／そこからアーティストへ支払われる配分                     |
| **音楽出版社**                 | 作詞作曲家から著作権を預かり、管理・営業する事業者                               |
| **ディストリビューター**       | 個人・インディーの楽曲を各配信サービスへ取り次ぐ事業者                           |
| **フリーミアム**               | 無料プランで集め、有料へ引き上げるモデル。Spotifyの基本設計                      |
| **足切り（最低再生数）**       | 一定の再生数に満たない楽曲を分配対象から外す運用。分配コスト削減と不正対策が目的 |
| **再販売価格維持制度**         | CD・書籍などで定価販売を認める制度。日本でCDの価格が崩れなかった一因             |
