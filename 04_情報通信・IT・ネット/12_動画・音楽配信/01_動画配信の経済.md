# ① 動画配信の経済

このノートで分かること：**動画配信は「先にコンテンツへ巨額を払い、後から会員数で回収する」商売**であること。
そして今、その回収方法が「会員を増やす」から「単価を上げる・広告を足す」へ移っていること。

---

## 1. まず、儲け方が4種類ある

同じ「動画配信」でも、お金の取り方が違えば事業の性質はまるで別物になる。

| 類型          | 読み方・意味                         | お金の取り方        | 商品として売っているもの                   | 代表                     |
| ------------- | ------------------------------------ | ------------------- | ------------------------------------------ | ------------------------ |
| **SVOD**      | エスブイオーディー。月額見放題       | 会員から毎月定額    | **解約されない理由**（ラインナップの厚み） | Netflix、U-NEXT、Disney+ |
| **AVOD**      | エーブイオーディー。広告型で無料     | 広告主から広告費    | **視聴者の時間と注意**                     | TVer、ABEMA無料、YouTube |
| **TVOD／EST** | 都度レンタル／買い切り購入           | 1本ごとに視聴者から | **1本の作品そのもの**                      | Amazon、Apple TV         |
| **FAST**      | ファスト。広告型の「チャンネル」配信 | 広告主から広告費    | **選ばなくていい体験**（テレビ的な流し見） | Samsung TV Plus、FAST ch |

FAST だけ補足しておく。**FAST＝Free Ad-supported Streaming TV**。見たいものを選ぶオンデマンドではなく、
24時間ぶんの編成が組まれた「仮想チャンネル」が流れ続ける。テレビ受像機メーカー（Samsung、LG、TCL）が
自社テレビにプリインストールして広告を売る形が多く、旧作の二次利用先として権利者にも旨みがある。

```
【同じ画面の中で、実は4つの商売が同居している】

     有料 ◀─────────────────────────▶ 無料
       │                                   │
  TVOD/EST ──── SVOD ──── SVOD広告付き ── AVOD ── FAST
   1本売り     月額定額    月額＋広告      無料＋広告  無料＋広告
                                                    ＋編成あり
       └─ 商品＝作品 ─┘   └─── 商品＝時間と注意 ───┘

  ▲ 近年の動き：SVOD各社が右へにじり出て、
    「安い広告付きプラン」で無料勢の客を取りに行っている
```

---

## 2. 最大の論点：コンテンツ費という先行投資

**この業界の損益を理解する鍵は1つだけ。「コンテンツ費は先に出ていき、回収は後から来る」ことである。**

Netflix は 2026年のコンテンツ投資を **200億ドル規模**とする計画が報じられている（2026年1月、映画.com ほか報道ベース）。
これは日本の国内VOD市場全体（2025年で6,740億円＝約45億ドル、GEM Partners 推計）の4倍以上にあたる。

### なぜ「先行投資」と言い切れるのか

制作費や独占配信権の取得費は、払った期に全額を費用にするのではなく、
いったん資産に載せて（コンテンツ資産）、**視聴の見込みに応じて数年かけて償却**する。

```
【1本のオリジナル作品の資金繰り】

  年0        年1         年2         年3
  ├──────────┼───────────┼───────────┼──▶
  ▼
 制作費を支出      配信開始
 (キャッシュアウト)  ├─ 償却費として費用化（見込み視聴に応じ前倒し配分）
                    ├─ 会員の解約を止める（＝売上の維持）
                    └─ 新規会員を呼ぶ（＝売上の増加）

  ▲ 怖いのはここ：見込みが外れると「償却しきれない」→ 減損（一括で損失計上）
    だから配信事業者は「どれだけ見られたか」の社内データを外に出したがらない
```

| 費目                     | 性質                     | ざっくりの感覚                                |
| ------------------------ | ------------------------ | --------------------------------------------- |
| **コンテンツ費（償却）** | 固定費に近い             | 費用全体の**5〜6割**を占めるのが典型          |
| **配信費（CDN・帯域）**  | 変動費（視聴時間に比例） | 1会員増の追加コストはここだけ。相対的に小さい |
| **マーケティング費**     | 半固定                   | 新規獲得コスト（CAC）。成長期は膨らむ         |
| **技術・人件費**         | 固定費                   | プラットフォーム開発・推薦エンジン・課金基盤  |

> ポイント：**会員が1人増えたときの追加費用はCDN代だけ**。
> だから損益分岐点を超えた瞬間に利益率が跳ね上がり、超えられないと永遠に赤字が続く。
> 「勝者総取り」に見える構造の正体はこれ。

## 3. 会員数の綱引き ── 売上を決める4つの数字

```
【SVODの売上方程式】

  売上 ＝ 期首会員数 ×（1 − 解約率）× 12 ＋ 新規獲得 × 残存期間
                                  × ARPU（1人あたり月額）

  ┌ 新規獲得（＋） ───── 話題作、キャンペーン、バンドル（抱き合わせ）
  │
  ├ 解約率（−）  ───── 「見たい作品が切れた月」に抜ける
  │
  ├ ARPU（×）   ───── 値上げ、上位プラン誘導、広告収入の上乗せ
  │
  └ LTV ＝ ARPU ÷ 解約率  ← 1人の会員が生涯でいくら払うか
       これが CAC（獲得コスト）を上回っていないと、増やすほど損をする
```

| 指標                     | 読み方                                           | なぜ重要か                                               |
| ------------------------ | ------------------------------------------------ | -------------------------------------------------------- |
| **ARPU**                 | Average Revenue Per User。1人あたり平均売上      | 会員数が頭打ちになった市場では、成長はここでしか作れない |
| **チャーン（解約率）**   | 月あたり何%が解約するか。月次2〜5%が目安とされる | 5%なら平均20か月で入れ替わる計算。**LTVを直接決める**    |
| **CAC**                  | 新規1人を獲得する費用                            | LTV > CAC でないと成長が赤字を増やすだけになる           |
| **視聴完了率・視聴時間** | どれだけ見られたか                               | 解約の先行指標。次に何を作るかの判断材料                 |

**日本市場で起きていること（2025年、GEM Partners 推計）**：
SVOD市場は 6,017億円（前年比+14.3%）と成長が再加速したが、その要因は新規加入ではなく
**①各社の値上げ、②1人あたり利用サービス数が1.8→2.0に増えたこと** だった。
つまり **「人を増やす競争」から「財布のシェアを取る競争」へ**移っている。

## 4. なぜ自社でオリジナルを作るのか

配信事業者にとって、他社から作品を借りる（ライセンス）方が一見安い。
それでも自社制作に走るのは、4つの理由がある。

| 理由                           | 中身                                                                                                           |
| ------------------------------ | -------------------------------------------------------------------------------------------------------------- |
| **① 更新リスクを消す**         | ライセンスは契約期間が切れる。人気作ほど更新時に値を吊り上げられるか、権利者が自社配信を始めて引き上げてしまう |
| **② 独占でしか差別化できない** | 同じ作品がどこでも見られるなら、選ぶ基準は価格だけになる。価格競争は誰も勝たない                               |
| **③ 全世界で同時に使える**     | 国ごとに権利を買い直す必要がない。1本作って190か国で回せる                                                     |
| **④ IPを資産として持てる**     | 続編・スピンオフ・グッズ・ゲーム化まで自社の判断で展開できる                                                   |

> 実際、Disney+ が短期間で存在感を持てたのは、**ディズニー／ピクサー／マーベル／スター・ウォーズという
> 「他社が絶対に持てないIP」を親会社から引き上げた**から。
> 逆に言えば、IPを持たない配信事業者は永遠にコンテンツ費を払い続けるしかない。

ただし副作用もある。オリジナル制作は **失敗が自社の損失になる**。
ライセンスなら「見られなくても契約期間が終われば終わり」だが、自社制作は減損に直結する。
近年、各社が「制作本数を絞り、当たる企画に集中する」方向へ舵を切っているのはこのため。

## 5. 解約率との戦い ── パスワード共有対策という発明

SVODの最大の敵は競合ではなく **「見終わったら抜ける客」** である。
話題作目当てで加入し、見終わった翌月に解約する行動は **チャーン・アンド・バーン** などと呼ばれる。

対策は大きく3つ。

1. **配信ペースを刻む**：全話一括公開をやめ、毎週1話ずつ出して契約月をまたがせる
2. **バンドル（抱き合わせ）**：通信料金・ECの送料無料・他サービスとのセットにして、解約の判断を難しくする
3. **世帯外共有の有料化**

3つめが2023年以降の最大の打ち手だった。
Netflix は「同一世帯以外とのアカウント共有」を制限し、世帯外の人を使いたい場合は追加料金を払う仕組みへ移行した。

```
【パスワード共有対策が効いた理由】

 対策前                          対策後
 ┌──────────┐              ┌──────────┐
 │ 契約者A（払う）  │              │ 契約者A（払う）  │
 │  ├ 友人B（ただ乗り）│  ───▶     │  ├ 友人B → 自分で契約 or 追加料金 │
 │  └ 実家C（ただ乗り）│              │  └ 実家C → 同上                 │
 └──────────┘              └──────────┘

 ▲ 既に作品を気に入っている人（＝解約しにくい人）を
   いきなり有料会員に変換できる。獲得コスト(CAC)がほぼゼロの新規獲得。
   一方で「反発による解約」も起きるため、実施のタイミングは各社慎重だった。
```

## 6. 値上げと、広告付きプランへの移行

会員数の伸びが鈍る局面で残された手は「1人あたり単価を上げる」こと。
ただし単純な値上げは解約を呼ぶ。そこで各社が採ったのが **価格の二階建て**である。

```
【二階建て価格の狙い】

  従来：      1,500円 ── 全員これ ── 払えない人は去る

  現在：      1,900円 広告なし上位  ← 払える人からもっと取る
              1,500円 広告なし標準
              1,000円 広告付き      ← 去りそうな人を受け止める
                       └ 会費1,000円 ＋ 広告収入 = 実質ARPUは標準に近づく

  ▲ 広告付きプランは「安いプラン」ではなく、
    **会費と広告の二重取りで、実はARPUが落ちにくいプラン**。
    しかも広告主にとっては「誰が何を見ているか分かる在庫」なので単価が高い。
```

Netflix の場合、**新規加入者の半数以上が広告付きプランを選んでいる**と発表されており（2025年、報道ベース）、
広告付きプランの月間利用者は2.5億人以上に達したと報じられている（2026年、ケータイWatch ほか）。
国内でも ABEMA が 2026年4月1日から ABEMAプレミアムを1,080円→1,180円、
広告付きプレミアムを580円→680円へ改定している。

| 打ち手                       | 効く相手                     | 副作用                                               |
| ---------------------------- | ---------------------------- | ---------------------------------------------------- |
| 値上げ                       | 既に習慣化した会員           | 直後に解約が一時増える                               |
| 広告付き安価プラン           | 価格に敏感な層、離脱寸前の層 | 上位プランからの「下り」が起きると単純増収にならない |
| 上位プラン（4K・同時視聴数） | 家族利用・高画質志向         | 差別化できる機能が尽きつつある                       |
| バンドル                     | 通信・EC の既存顧客          | 取り分を相手に渡す。ARPUは下がる                     |

## 7. 主要プレイヤーの違い ── 「何で食っているか」が全部違う

| 事業者                    | 配信事業の位置づけ                 | 勝ち筋                                                                                        | 弱点                                                     |
| ------------------------- | ---------------------------------- | --------------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| **Netflix**               | **本業そのもの**。ほかに稼ぎがない | 世界190か国の会員基盤でコンテンツ費を薄める。各国オリジナルを世界に流す                       | 配信で稼げなければ会社が終わる。IPの元手を持たない       |
| **Disney+**               | 巨大IPの直販チャネル               | 劇場・グッズ・テーマパークと同じIPを何度も換金する                                            | 過去作中心だと目新しさが切れる                           |
| **Prime Video（Amazon）** | **EC会員を辞めさせない道具**       | 単体で黒字でなくていい。送料無料と同じ「特典」                                                | 配信単体の価値では測れず、投資判断が読みにくい           |
| **Apple TV+**             | ハード販売の付加価値               | 作品数を絞り、品質でブランドを作る                                                            | ラインナップが薄く、単体での継続理由が弱い               |
| **YouTube**               | 広告プラットフォーム               | コンテンツ費がほぼゼロ（作るのは投稿者）。**視聴時間でテレビを超えた**                        | プロ制作の独占作品を持たない                             |
| **U-NEXT**                | 国内SVODの最大手                   | 見放題の作品数と毎月ポイント付与で単価が高い。邦画・アニメ・成人向けまで幅広い                | 海外勢とのコンテンツ費の体力差                           |
| **ABEMA**                 | 広告＋課金のハイブリッド           | 無料で巨大な入口を作り、スポーツ・オリジナルで課金へ。**2026年9月期Q1に初の四半期単体黒字化** | 無料視聴が多いぶん広告市況に左右される                   |
| **TVer**                  | 民放各局の共同見逃し配信           | 放送済みコンテンツの二次利用なので**追加コストが小さい**。2026年1月に月間4,470万MUBで過去最高 | 収入は広告のみ。放送局の利害調整が必要                   |
| **DAZN**                  | スポーツ中継特化                   | 代替不可能な中継権。試合がある限り解約されにくい                                              | 中継権料が固定費として重く、値上げを繰り返さざるを得ない |

> ポイント：**Netflix だけが「配信で黒字を出さないと死ぬ」会社**。
> ほかは本業の補完や広告在庫として配信を持っている。
> 同じ土俵に見えて、耐えられる赤字の深さがまったく違う。

## 8. 視聴の場がテレビに戻った ── CTVという変数

**CTV（Connected TV）＝ ネットにつながったテレビ受像機**。
配信初期はスマホ・PCが中心だったが、視聴の主戦場はテレビ画面に移った。

- 米Nielsen の集計では、2026年5月に **YouTube がテレビ視聴時間シェア13.8%** と全事業者中トップ。
  ストリーミング全体では 2026年4月に総視聴時間の **47.6%** を占めた
- 国内でも TVer のコネクテッドテレビ経由の再生数が月間2.1億再生に達している（2026年1月）

```
【CTVが変えたもの】

 ① 広告としての価値が上がった
    テレビCMと同じ「大画面・家族で視聴」なのに、
    誰が最後まで見たかが分かる ──▶ 単価の高い広告在庫になる
 ② 競争相手がテレビ局になった
    リモコンの入力切替の先で、地上波とNetflixとYouTubeが横並びになり、
    テレビ受像機メーカーの初期画面（ホーム）の取り合いが始まる
```

広告としてのCTVの扱いは [ネット広告](../07_ネット広告/README.md)、
放送側の事情は [テレビ・ラジオ](../../14_メディア・広告・エンタメ/05_テレビ・ラジオ/README.md) を参照。

## 9. この構造から言えること

1. **コンテンツ費は減らせない**。減らした瞬間に解約が増えるので、勝つまで払い続けるしかない。
   その結果、**払い続けられない会社から脱落する**（2025〜2026年の大型再編はその帰結
   → [④ 直近トピック](04_直近トピック_2026.md)）
2. 成長の源泉は会員数から **ARPU（単価＋広告）** へ移った。広告付きプランは後退ではなく主戦略
3. 権利者（制作会社・レーベル・放送局）にとっては、**買い手が減ることは値下げ圧力**になる
4. インフラ側（CDN・データセンター）は視聴時間の増加をそのまま受ける
   → [データセンター](../03_データセンター/README.md)

## 用語メモ

| 用語                   | 意味                                                                                 |
| ---------------------- | ------------------------------------------------------------------------------------ |
| **SVOD**               | Subscription VOD。月額見放題型の動画配信                                             |
| **AVOD**               | Advertising VOD。広告を見る代わりに無料で視聴できる型                                |
| **TVOD／EST**          | 都度課金レンタル（Transactional）／買い切り購入（Electronic Sell-Through）           |
| **FAST**               | Free Ad-supported Streaming TV。24時間編成の無料広告型チャンネル配信                 |
| **ARPU**               | Average Revenue Per User。1利用者あたりの平均売上                                    |
| **チャーン（解約率）** | 一定期間に解約した会員の割合。月次で見るのが一般的                                   |
| **LTV**                | Life Time Value。1会員が生涯に払う金額の見込み。おおむね ARPU ÷ 解約率               |
| **CAC**                | Customer Acquisition Cost。新規会員1人を獲得するのにかかった費用                     |
| **コンテンツ償却**     | 制作費・権利取得費をいったん資産に計上し、視聴見込みに応じて数年で費用化する会計処理 |
| **減損**               | 資産の回収見込みが立たなくなったとき、帳簿価額を一括で切り下げて損失計上すること     |
| **バンドル**           | 他サービスとの抱き合わせ販売。単独解約の判断を難しくする狙い                         |
| **CTV**                | Connected TV。インターネットに接続されたテレビ受像機                                 |
| **MUB**                | Monthly Unique Browser。月間ユニークブラウザ数。TVerが公表に使う指標                 |
