このフォルダの読み方

動画配信・音楽配信を 産業として 理解するためのノート群。
この業界は 「メディア型＝IPの権利構造」 で読み解くのが正解で、
配信事業者は「コンテンツを作る人」ではなく 「他人が持つ権利を買い集めて束ね、月額で貸し出す人」 である。
だから骨格は、①動画のお金の回し方、②音楽のお金の分け方、③そもそも何の権利を買っているのか、の3本にした。

ノート 内容
① 動画配信の経済コンテンツ費という巨大な先行投資と会員数の綱引き、SVOD/AVOD/TVOD/FAST、オリジナル制作に走る理由、解約率（チャーン）とパスワード共有対策、値上げと広告付きプランへの移行、Netflix/Disney/Amazon と国内勢（U-NEXT・ABEMA・TVer・DAZN）の違い
② 音楽配信の経済1再生いくらが「決まっていない」分配の仕組み（プロラタ方式）、100円がレーベル・出版社・アーティストへ流れる道筋、サブスクが音楽業界を救った経緯、ライブへの収益シフト、Spotify/Apple/YouTube の構図、日本でCDが残った理由
③ 権利とインフラ著作権と著作隣接権（原盤権）の二階建て、JASRAC/NexTone の役割と包括契約、配信の技術（CDN・トランスコード・ABR・帯域コスト）、DRMと海賊版対策、生成AIと権利処理という新しい難問
④ 直近トピック（2026年9月時点）ワーナー争奪戦の決着、広告付きプランの主流化、YouTubeのテレビ視聴シェア、国内SVOD 6,000億円超と一斉値上げ、音楽11年連続成長、ストリーミング詐欺と海賊版被害

1. 業界の定義・範囲

動画・音楽配信＝ インターネット回線を通じて映像・音声コンテンツを視聴者に届け、
月額課金・広告・都度課金のいずれかで対価を得る事業。

【この業界の守備範囲】

 ┌──────────────────────────────────────────────┐
 │ 動画 │ SVOD（月額見放題）  Netflix / U-NEXT / Prime Video   │
 │      │ AVOD（広告型）      TVer / ABEMA無料 / YouTube        │
 │      │ FAST（広告型リニア） Samsung TV Plus / FAST ch         │
 │      │ TVOD・EST（都度／購入） Amazon / Apple TV             │

 │ 音楽 │ サブスク            Spotify / Apple Music / YouTube   │

 │      │ 広告収入型          YouTube / 無料プラン               │
 ├──────────────────────────────────────────────┤
 │ 支える層 │ CDN・エンコード・DRM・課金基盤・権利管理事業者     │
 └──────────────────────────────────────────────┘

境界の引き方：

  • コンテンツを「作る」側（制作会社・レーベル・製作委員会）は範囲外。
    ただし Netflix のように自社で作る事業者が増え、境界は年々曖昧になっている
  • UGC（一般ユーザー投稿）中心のサービスは プラットフォーム・SNS 寄り。
    YouTube は両方にまたがるため、本フォルダでは「プロ制作コンテンツの流通経路」としてだけ扱う
  • ゲーム実況・eスポーツ配信は eスポーツ と ゲーム 側
  • 放送そのもの（地上波・BS・CS）は範囲外。TVer は放送局が出す「見逃し配信」なので本フォルダ

5. 収益モデル・コスト構造

【動画SVODの損益の骨格】

  売上 ＝ 会員数 × ARPU（1人あたり月額単価）× 12
       −
  コンテンツ費（償却）  ← 費用の 50〜60%。最大の固定費
  配信費（CDN・帯域）    ← 視聴時間に比例する変動費
  マーケティング費       ← 新規獲得（CAC）
  技術・人件費

  ▲ ポイント：コンテンツ費は「先に払って、後から会員で回収する」。
    作った瞬間は赤字。会員数が読み違うと一気に減損になる。
【音楽サブスクの損益の骨格】

  売上100 ──▶ 権利者へ約65〜70 ──▶ 原盤権（レーベル）へ大半
              （レベニューシェア）   ＋ 著作権（出版社・JASRAC等）へ一部
        ──▶ 手元に約30
              −（決済手数料・サーバ費・人件費・マーケ費）

  ▲ ポイント：売上が伸びても**原価率がほぼ固定**なので、
    利益は「規模でコストを薄める」以外に出しようがない。
論点 中身
動画のコンテンツ費制作／ライセンス取得費を資産計上し、視聴の見込みに応じて数年で償却する。見込みが外れると減損
動画の粗利構造会員が1人増えたときの追加費用はCDN代のみ。損益分岐を超えると利益が急に伸びる
音楽の原価率売上の65〜70%前後が権利者への支払い。構造的に薄利で、Spotifyは長く赤字だった
広告型（AVOD/FAST）売上＝視聴時間 × 広告挿入率 × CPM。会員数ではなく視聴時間が商品
季節性動画は年末年始・大型作品公開時に山。スポーツ配信は大会日程に完全連動
解約率（チャーン）月次 2〜5% が一つの目安とされる。作品目当ての加入は見終わると抜ける

6. 競争要因（KSF）と参入障壁

KSF（成功の鍵）

  1. 独占できるコンテンツを持てるか：同じ作品がどこでも見られるなら、選ばれる理由は価格だけになる
  2. コンテンツ投資の規模：年間数千億〜2兆円級の投資を続けられるのは世界で数社しかいない
  3. 解約されない理由づくり：毎月「見たいもの」が切れないラインナップの厚み、束ね売り（バンドル）
  4. レコメンドと視聴データ：何を作るか・何を買うかの判断精度に直結する
  5. 課金と決済の摩擦の低さ：キャリア決済・アプリ内課金・ポイント連携
  6. 権利処理のオペレーション力：1本の作品に何十もの権利者がいる。ここが遅いと配信できない

参入障壁

障壁 強さ 理由
グローバルSVODへの参入極めて強先行投資が兆円単位。回収まで数年赤字を許容できる資本が要る
独占コンテンツの確保強人気IPは買い手が複数いて値が上がる。金だけでは勝てず、制作者との関係が要る
配信技術そのもの弱CDNもエンコードもクラウドで買える。技術は差別化要因にならなくなった
ニッチ特化型（アニメ・スポーツ・K-POPなど）中権利さえ押さえれば小さく始められる。ただし更新時に権利料を吊り上げられる
音楽サブスクへの参入強レーベル3大メジャーとの契約が前提。条件は先行者ほど有利

ポイント：この業界の障壁は「技術」ではなく「権利」と「継続的な投資体力」。
だから勝者はどんどん減り、2025〜2026年にかけて大型再編が起きている。

7. 規制・法制度

領域 中身
著作権法配信は「公衆送信権（送信可能化権）」の対象。権利者の許諾なしには配信できない
著作隣接権実演家（歌手・俳優）とレコード製作者（レーベル）が持つ権利。音楽配信では原盤権が最重要
著作権等管理事業法JASRAC・NexTone など管理事業者の業務を規律。使用料規程は文化庁に届出
放送法配信サービスは原則として対象外。ただしNHKのネット必須業務化（2025年施行）で境界が動いた
電気通信事業法（外部送信規律）2023年施行。利用者情報の外部送信について通知・公表が必要
消費者契約・特定商取引法サブスクの解約導線（いわゆるダークパターン）への規制強化が進む
海賊版対策2020年改正でリーチサイト規制とダウンロード違法化の範囲拡大。官民で削除要請体制
生成AI著作権法30条の4（情報解析目的の利用）の解釈を文化審議会が整理（2024年3月「AIと著作権に関する考え方」）
