1. 業界の定義・範囲

データセンター（DC）＝サーバ・ストレージ・ネットワーク機器を集約して設置し、
電力・冷却・回線・セキュリティを24時間提供する専用施設、およびその運営事業。

区別すべき言葉 中身
データセンター業建物と電源・冷却・回線を提供する。このフォルダの対象
コロケーション（ハウジング）顧客の機器を預かって場所・電源・回線を貸すサービス形態
ホスティング事業者が用意したサーバ自体を貸す
クラウド（IaaS/PaaS）DCの上で仮想化された計算資源を売る → クラウド・IaaS
ハイパースケーラー自社で超大規模DCを運営する巨大クラウド事業者

隣接領域との境界：

  • 計算資源をサービスとして売る層は クラウド・IaaS
  • AI需要そのものの話は 生成AI
  • 電気をどう作り、どう送るかは 電力
  • 建てる側の話は ゼネコン と
    サブコン（電気・空調・設備）

企業 立ち位置 特徴

富士通／NEC／IIJ／ブロードバンドタワー 等国内コロケーション・運用業務システムの受け皿。SIerと近い

シェアの見方：DCの「シェア」は拠点数や売上ではなく、受電容量（MW）ベースで見るのが実務的。
床面積は意味が薄く、同じ面積でも扱える電力が10倍違いうる。

5. 収益モデル・コスト構造

収益モデル 課金の単位 特徴
ラック貸し（リテール）1ラック月額＋電力従量単価は高いが営業件数が多い
kW課金（ホールセール）1kWあたり月額、10〜20年契約1契約が巨大。不動産賃貸に近い
クロスコネクト1本あたり月額粗利が高く、解約を防ぐ
リモートハンド等の運用代行作業時間単位人手商売

コスト構造の核心：

  • 減価償却＋電気代でコストの大半。建物20〜30年、電気・空調設備10〜15年で償却する
  • 固定費が重いため損益分岐となる稼働率が高く、半分空いていれば赤字になりやすい
  • 電気代は顧客へのパススルー（実費転嫁）が主流。転嫁できるかどうかで利益率が変わる
  • EBITDAマージンが高く見えるのは償却前の数字だから。営業利益率とは別物
  • 詳しくは 事業としての経済性

6. 競争要因（KSF）と参入障壁

要因 中身 障壁の高さ
受電権の確保系統に空きのある土地を先に押さえられるか非常に高い。2026年の最大の希少資源
資金調達力100MW級で1,000億円超。長期・低利の資金が要る高い
長期契約の獲得ハイパースケーラーとの関係高い。実績がないと入札に呼ばれない
接続性（回線の集積）既存集積地ほど有利。集まるほど強くなる高い（ネットワーク効果）
設計・運用の技術液冷、高密度、PUE改善中。ただし世代交代が速い
地域との合意形成住民説明、自治体との協定上がりつつある（新しい許認可に近い）

7. 規制・法制度

領域 内容
省エネ・非化石転換法DC業がベンチマーク制度の対象に。2026年度提出分から電力消費量とPUEの報告・自社サイト公表。目標は2030年度に平均PUE1.4以下、2029年以降の新設はPUE1.3以下（資源エネルギー庁、2026年4月ガイドライン）
建築基準法・都市計画法DCの明確な用途定義がなく「事務所」「倉庫」等で申請されるのが一般的。訴訟の争点になっている
消防法・大気汚染防止法・騒音規制法非常用発電機の燃料備蓄、排煙、騒音が対象
電気事業法受電設備、自家用電気工作物としての保安
補助金デジタルインフラ整備基金（1,300億円超）、GX戦略地域、環境省のゼロエミッション化事業 など
自治体ガイドライン東京都「大規模データセンター建設計画に係る話し合いガイドライン」（2026年3月）
経済安全保障政府調達での国内保管要件、ソブリンクラウドの議論
