# 日本の現状と論点 ── 集中、系統制約、地域との折り合い

このノートで分かること：日本のDCがなぜ東京圏・大阪圏に偏っているのか、電力系統がどう制約になるのか、
政府の地方分散政策と補助金、自治体誘致と住民の反対運動、そして経済安全保障・データ主権の論点。

## 1. 日本のDC地図 ── 2大都市圏への極端な集中

日本のDCは、電力容量ベースでおおむね**9割が東京圏と大阪圏に集中している**とされる（業界集計ベース）。

```
   ┌── 東京圏 ────────────────────────────┐
   │  印西・白井（千葉）… 内陸・地盤が堅い最大集積地      │
   │  昭島・多摩（東京） … 用地と受電を確保できた郊外     │
   │  大手町・品川    … 回線が集まる都心の接続拠点       │
   │  有明・江東     … 湾岸の大型開発（受電60MW級も）   │
   └───────────────────────────────────┘
   ┌── 大阪圏 ────────────────────────────┐
   │  南港（コスモスクエア）… 埋立地の大規模集積         │
   │  堂島・心斎橋    … 都心型・接続拠点             │
   └───────────────────────────────────┘
   ┌── 地方 ─────────────────────────────┐
   │  石狩・苫小牧（北海道）… 再エネ＋寒冷地＋GX戦略地域   │
   │  福島・会津、佐賀、堺、北九州 …… 誘致と補助金で拡大中 │
   └───────────────────────────────────┘
```

| 集中する理由     | 中身                                               |
| ---------------- | -------------------------------------------------- |
| 顧客がそこにいる | 本社機能・金融・通信の需要地。遅延が小さい         |
| 回線が集まる     | 国際海底ケーブルの陸揚局と国内幹線が都市圏に集中   |
| 運用人材がいる   | 24時間運用・保守の人手を確保できる                 |
| 既存DCの引力     | 相互接続が価値を生むので、既存集積地にさらに集まる |

| 集中の弊害   | 中身                                             |
| ------------ | ------------------------------------------------ |
| 災害リスク   | 首都直下地震で主要DCが同時被災する懸念           |
| 電力の逼迫   | 東京エリアの系統に空きがなく、新設が進まない     |
| 用地価格     | 地価高騰により建設単価が上がる                   |
| 地域との摩擦 | 住宅地に近く、騒音・排熱・景観の問題が起きやすい |

- CBRE集計では**東京の受電容量在庫は2026年第1四半期に1GWを超え**、空室率は6%。
  「電力制約が新規供給を抑えている、特に東京圏で」と指摘されている（2026年）
- 世界のDC数では米国が2025年3月時点で5,426に対し**日本は222**（総務省 令和7年版 情報通信白書）。
  拠点数では大きく水をあけられている

## 2. 電力系統という天井

日本でDCを建てるときの最大の制約は、土地でも資金でもなく**送電網に空きがあるか**である。

```
   発電所 ──▶ 基幹送電線 ──▶ 変電所 ──▶ 配電 ──▶ DC
                  ▲              ▲
             空き容量なし     増強工事に数年
                  │              │
        「接続はできるが、電気を流せるのは◯年後」という回答になる
```

| 数値          | 内容                                                       | 出所・時点                                    |
| ------------- | ---------------------------------------------------------- | --------------------------------------------- |
| **+762万kW**  | 2035年度に向けDC・半導体工場の新増設で増える最大需要電力   | OCCTO 2026年度供給計画取りまとめ（2026年3月） |
| **+568億kWh** | 同・電力量の増加分                                         | 同上                                          |
| 15,962.6万kW  | 2026年度の全国最大需要（送電端、夏季）                     | OCCTO（2026年度需要想定）                     |
| 約3%          | 国内DCの消費電力が国内総電力に占める割合（2021年は約1.5%） | 2026年、報道ベース                            |
| 約2倍／約9倍  | 日本のDC電力需要の2030年／2040年予測（現在比）             | BCG分析（推計）                               |

- OCCTOは、DC・半導体工場が**北海道・東京・中国エリア**で特に需要を押し上げると整理している
- 「全国の最大需要は微増」なのに「特定エリアだけ急増」する点が重要。**制約は全国平均ではなく地域単位**で来る
- 対策として、系統増強、需給調整市場への参加（DCが出力を絞る）、自家発・蓄電池併設などが議論されている
  → [電力](../../11_資源・エネルギー・鉄鋼金属/04_電力/README.md)、[新電力](../../11_資源・エネルギー・鉄鋼金属/05_新電力/README.md)

## 3. 省エネ規制 ── 2026年度から「測って公表する」段階へ

日本は2026年度から、DCを名指しした省エネ規制の運用に入った。

| 項目             | 内容                                                                         |
| ---------------- | ---------------------------------------------------------------------------- |
| 根拠法           | 省エネ・非化石転換法（改正省エネ法）。DC業がベンチマーク制度の対象業種に     |
| 対象             | 年間エネルギー使用量1,500kL（原油換算）以上、またはサーバ室300㎡以上の事業者 |
| 報告義務         | 電力消費量、PUE、エネルギー消費原単位とその目標（2026年度提出分から）        |
| ベンチマーク目標 | **2030年度に平均PUE1.4以下**                                                 |
| 新設基準         | **2029年以降に新設する施設はPUE1.3以下**                                     |
| 公表義務         | 自社ウェブサイトでPUEと電力消費量を公表。未対応には措置あり                  |
| ガイドライン     | 資源エネルギー庁が2026年4月10日に策定                                        |

> 意味するところ：**PUEが「努力目標」から「開示して比較される数値」に変わった**。
> 古い空冷DCは規制対応コストが重くなり、新設との差が開く。業界再編の一因になりうる。

- テナント型DC事業者（建物を借りて運営する事業者）も対象に含まれる点が実務上の注意点
- 電力の使用の見える化は、**電力会社側の需給計画にDC需要を織り込む**ためでもある

## 4. 地方分散政策と補助金

政府は「東京圏・大阪圏以外へ」という方向で、複数の枠組みを走らせている。

| 施策                             | 所管           | 中身                                                       |
| -------------------------------- | -------------- | ---------------------------------------------------------- |
| デジタルインフラ整備基金         | 総務省・経産省 | 1,300億円超。地方DC・海底ケーブル整備に補助（補助率1/2等） |
| デジタルインフラ整備計画2030     | 政府           | 2025年6月策定。DC・海底ケーブルの整備方針                  |
| GX産業立地・GX戦略地域           | 経産省         | 再エネが豊富な地域にDC等を誘致。2026年に地域選定           |
| ゼロエミッション化・地域共生事業 | 環境省         | 再エネ活用DCの脱炭素化と地域共生を支援                     |
| 地域DC整備促進                   | 総務省         | 地方拠点の整備を後押し                                     |

**個別案件への支援として報じられている額**（JETRO、2026年1月時点の整理）：

| 事業者・案件                   | 支援上限額         |
| ------------------------------ | ------------------ |
| さくらインターネット           | 最大575億円        |
| ソフトバンク                   | 最大474億円        |
| ソフトバンク（苫小牧のDC整備） | 最大300億円        |
| KDDI                           | 最大102億4,000万円 |
| ルティリア・AI福島             | 最大25億6,000万円  |

- 北海道では**石狩市・苫小牧市がGX戦略地域に認定**され（2026年）、誘致が加速
- 2026年7月28日、NTT東日本・さくらインターネット・NTT ME・京セラコミュニケーションシステム・
  ブロードバンドタワーなど11社と石狩市が「石狩データセンターコンソーシアム」の設立を発表
- ソフトバンクとIDCフロンティアは「北海道苫小牧AIデータセンター」を建設中（2026年度開業予定と報じられる）

> 地方分散が進む条件は補助金そのものではなく、**AI学習用途が遅延に鈍感**という技術的事実。
> レイテンシを要求する用途は都市圏から動かないので、分散は「用途の分化」として進む。

## 5. 自治体誘致と住民の反対運動

税収・雇用を期待する自治体と、生活環境を心配する住民のあいだで摩擦が顕在化している。

```
   誘致する側の期待              住民側の懸念
   ─────────────            ─────────────
   固定資産税の大幅増          非常用発電機の騒音・排煙
   建設期の雇用と地元発注      冷却装置の運転音・排熱
   企業立地によるブランド      日照・圧迫感・景観
   再エネの地産地消            大量の電力・水を使う割に雇用が少ない
                              計画の情報が出てこない（秘匿性）
```

| 論点               | 実態                                                                                           |
| ------------------ | ---------------------------------------------------------------------------------------------- |
| 用途の扱い         | 建築基準法にDCの定義がなく、「事務所」「倉庫」等として申請されるのが一般的                     |
| 訴訟               | 千葉県印西市では用途が「事務所」か「工場」かが争点となる建設訴訟が起きた（2026年、報道ベース） |
| 自治体の対応       | 東京都が2026年3月に「大規模データセンター建設計画に係る話し合いガイドライン」を策定            |
| ガイドラインの限界 | 合意形成の手順を定めるもので、**建設を止める法的拘束力はない**                                 |
| 雇用の実態         | 運用要員は規模のわりに少人数。「電気を大量に使うが人は雇わない」という批判が出やすい           |

- 発電機の排煙・騒音は、法規制の隙間に落ちやすい領域として指摘されている（2026年、報道ベース）
- 誘致成功例では、**排熱の地域利用や再エネの地元調達**を条件に合意を作っている（石狩の取り組みなど）
- 米国でも州によって税優遇（2025年11月時点で37州が売上税免除等を提供）と住民反発が並走しており、
  **日本だけの問題ではない**（JETRO整理）

## 6. 国内クラウド需要と「器は外資」という構図

| 層                    | 日本勢の立ち位置                                                                                                                         |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| DC建物・運営          | NTT系（NTTデータ／NTTグローバルデータセンター）、KDDI、ソフトバンク／IDCフロンティア、さくらインターネット、富士通、IIJ など一定の存在感 |
| 外資DC事業者          | Equinix、Digital Realty系、ESR、Princeton Digital、CloudHQ、SC Zeus 等が日本で開発を拡大                                                 |
| クラウド（IaaS/PaaS） | **AWS・Microsoft・Googleの3社が大半**。日本のパブリッククラウド市場は2024年に4兆1,423億円（前年比26.1%増、IDC Japan）                    |
| AI基盤モデル          | 国産勢は政策支援を受けつつ挑戦中 → [生成AI](../../01_注目テーマ/01_生成AI/README.md)                                                     |

> 構図を一言でいえば、**「箱は日本に建つが、中で動くサービスは外資」**。
> DC投資が増えても、その上の付加価値がどこに落ちるかは別問題である。
> → [クラウド・IaaS](../04_クラウド・IaaS/README.md)

## 7. 経済安全保障とデータ主権

- **データ主権（デジタル主権）**＝自国のデータを自国の法域・インフラの中で扱えるようにする考え方
- 政府調達では、国内保管や国内法人による運用を条件にするソブリンクラウド的な要件が広がりつつある
- EUでは域内DC需要の**65%を米国3社**が占めるという整理があり、
  「AI大陸行動計画」（2025年4月）、AIファクトリー（2025年10月時点で16加盟国・19拠点、
  26億ユーロ超）、AIギガファクトリー（最大200億ユーロ動員予定）、
  クラウド・AI開発法（CADA）の法案提出などで自律性確保を図っている（JETRO整理）
- 米国は許認可迅速化（大統領令14318、FAST-41枠組み）で建設を後押しする方向
- 日本の論点は、①機微データの国内保管、②有事の継続性（海底ケーブル・電力）、
  ③外資DCへの依存度、④AI計算資源を国内に確保できるか、の4点に整理できる
  → [情報セキュリティ](../14_情報セキュリティ/README.md)

## 用語メモ

- **OCCTO（電力広域的運営推進機関）**：全国の需給計画・系統計画を取りまとめる認可法人
- **系統制約**：送電網の空き容量不足により、新規需要の接続が制限されること
- **GX戦略地域**：再エネ等を生かした産業立地を進めるため国が選定する地域
- **省エネ・非化石転換法**：改正省エネ法。2026年度からDC業がベンチマーク制度の対象
- **ベンチマーク制度**：業種ごとに目指すべき効率水準を定め、達成状況を報告させる仕組み
- **テナント型DC事業者**：建物を自ら所有せず借りてDC事業を行う事業者
- **陸揚局**：国際海底ケーブルが陸に上がる施設。DC立地と密接に関係する
- **ソブリンクラウド**：自国の法域・運営主体の中で完結するクラウド
- **データ主権**：データを自国の管轄下に置くという政策上の考え方
