# 事業としての経済性 ── 不動産賃貸業として読む

このノートで分かること：DC事業の損益がどう積み上がるか、なぜ**稼働率と長期契約**が生命線なのか、
巨額の初期投資を誰がどう賄うか（REIT・ファンド・SPC）、そしてテナント集中と電力調達のリスク。

## 1. 結論：ITの会社に見えて、実態は不動産賃貸業

DC事業の損益構造は、ソフトウェア業よりも**オフィスビル・物流施設の賃貸業**にはるかに近い。

| 論点               | ソフトウェア／SaaS         | データセンター                   |
| ------------------ | -------------------------- | -------------------------------- |
| 原価の性格         | ほぼ人件費（変動しやすい） | **減価償却と電気代（ほぼ固定）** |
| 追加販売の限界費用 | ほぼゼロ                   | 受電容量の上限で頭打ち           |
| 契約期間           | 月次〜年次                 | 10〜20年（ホールセール）         |
| 成長の制約         | 人と営業力                 | **土地・電力・資金**             |
| 決定的な指標       | 解約率、ARR                | **稼働率、契約済み容量、利回り** |

> つまり「どれだけ速く容量を埋め、どれだけ長く埋め続けられるか」がすべて。
> 生成AIの需要そのものより、**その需要が長期契約に化けるか**を見るのが正しい読み方。

## 2. 1MWのDCを1年運営したときの損益（模型）

数値は構造を理解するための**概念モデル**であり、実在案件の値ではない。
比率の大小関係だけを見てほしい。

```
  売上  1MWを月額 250ドル/kW で満床貸し
        = 1,000kW × 250ドル × 12か月 ≒ 300万ドル/年
        ├── 電気代（PUE1.4 なら IT分の1.4倍を購入）… 売上の25〜40%  ← 変動費
        ├── 減価償却（建物20〜30年、設備10〜15年）… 売上の25〜35%  ← 固定費
        ├── 保守・運用・警備・保険 ……………………… 売上の10〜15%  ← 固定費
        └── 残り＝営業利益 ………………………………… 売上の15〜30%
```

| コスト項目 | 性格                                           | 誰が負担するか                                   |
| ---------- | ---------------------------------------------- | ------------------------------------------------ |
| 電気代     | 変動費。ただし**顧客へ転嫁する契約が主流**     | 実費精算・パススルー条項なら事業者リスクは小さい |
| 減価償却   | 固定費。**稼働率が低い期間もそのまま出ていく** | 事業者                                           |
| 保守・運用 | 準固定費。人の数は容量に比例しきらない         | 事業者                                           |
| 回線       | リテールでは収益源、ホールセールでは顧客手配   | 契約形態による                                   |

- **電気代を顧客に転嫁できるかどうか**が、この事業の利益率を大きく左右する。
  ホールセール契約では電力実費のパススルーが一般的で、事業者は電力価格変動のリスクを負いにくい
- 逆にリテールで電力込みの定額にしていると、燃料費調整の上昇がそのまま利益を削る
- EBITDAマージン（利払い・税・償却前利益率）で40〜60%台という水準が語られるのは、
  **償却前の数字**だからである。償却を引いた営業利益率とは別物なので混同しない

## 3. 初期投資と回収 ── なぜ「兆円」の話になるのか

新設DCの建設単価は、**1MWあたり10〜15億円規模**（受電・冷却設備込み、液冷対応でさらに上振れ）
というオーダーで語られることが多い（報道・業界推計ベース）。

```
   受電容量 100MW のハイパースケールDC
        ↓
   建設投資 1,000〜1,500億円規模（土地・設備込み）
        ↓
   年間売上 100MW満床で 300億円規模（月額250ドル/kW換算、為替次第）
        ↓
   償却は建物20〜30年、電気・空調設備10〜15年 → 回収は10年超の長期戦
```

| フェーズ                     | 期間         | キャッシュの向き               |
| ---------------------------- | ------------ | ------------------------------ |
| 用地・許認可                 | 1〜2年       | 出ていくだけ                   |
| 建設                         | 1.5〜3年     | 最大の流出。ここで借入が膨らむ |
| リースアップ（区画を埋める） | 1〜3年       | 段階的に入り始める             |
| 安定稼働                     | 10〜20年     | 回収期。契約更新が論点に       |
| 更新投資                     | 10〜15年ごと | 設備更新で再び出ていく         |

- IDC Japanの予測では、国内DCの建設投資規模は**2028年に1兆円を超える**とされる（推計）
- 建てている最中は**売上ゼロで金利と固定資産税が出ていく**。金利上昇局面では資金繰りが直接効く
- 国内DCサービス市場は2023年に2兆7,361億円、2028年に5兆812億円へ拡大する見通し
  （IDC Japan、2024年10月。総務省 令和7年版 情報通信白書が引用）

## 4. 稼働率とプレリース ── 空室は即赤字

固定費が大きいので、**損益分岐となる稼働率が高い**。半分空いていれば赤字になりやすい。

```
   稼働率 100% ─────────────────────■■■■■■■■■■  利益
   稼働率  70% ───────────────■■■■■■■         ぎりぎり黒字
   稼働率  50% ──────────■■■■■              赤字（償却が消えない）
                        ↑
                 損益分岐点はおおむね6〜7割付近（構造上の目安）
```

だから事業者は、**建てる前に契約を取りに行く（プレリース）**。

| 指標                         | 意味                         | 2026年の状況（海外含む）                                                       |
| ---------------------------- | ---------------------------- | ------------------------------------------------------------------------------ |
| **空室率（vacancy）**        | 使われていない容量の割合     | 北米主要市場1.4%（2026年上期、CBRE）と記録的低水準                             |
| **プレリース率**             | 建設中で既に契約済みの割合   | ダラス･フォートワースでは建設中716.7MWの88%が契約済み（2026年第1四半期、CBRE） |
| **純吸収（net absorption）** | その期間に新たに使われた容量 | 北米主要市場で1,456.2MW（2026年上期、前年同期比+11.7%、CBRE）                  |
| **稼働率**                   | 賃貸可能容量に対する使用割合 | Digital Realtyは84.7%（2025年12月末時点、同社開示）                            |

> 2026年時点のDC市場は**売り手市場**。電力制約で新規供給が絞られる一方で需要が強く、
> 「建てる前に埋まる」状態が続いていると報告されている。
> ただしこれは**好況の証拠であると同時に、供給が需要に追いつかない異常値**でもある。

## 5. 誰がお金を出すか ── REIT、ファンド、SPC

自己資金だけでは到底足りないので、資本市場から資金を引いてくる仕組みが発達している。

| 調達手段                          | 中身                                       | 特徴                                   |
| --------------------------------- | ------------------------------------------ | -------------------------------------- |
| **DC特化REIT**                    | 上場不動産投資信託がDCを保有し賃料を分配   | 米国のEquinix、Digital Realtyが代表格  |
| **インフラ／不動産ファンド**      | 機関投資家の資金でDCを開発・保有           | 年金・保険の長期資金と相性が良い       |
| **SPC／プロジェクトファイナンス** | 案件ごとに会社を作り、その案件の収益で返済 | 親会社のバランスシートから切り離せる   |
| **JV（共同事業）**                | デベロッパー＋外資DC事業者＋商社           | 用地・運営ノウハウ・資金を持ち寄る     |
| **自己資金＋社債**                | ハイパースケーラー自身の投資               | 2026年は借入依存が強まったと報じられる |

```
  機関投資家（年金・保険）
        │ 長期の安定利回りが欲しい
        ▼
   REIT／インフラファンド ──保有──▶ DC建物
        ▲                              │ 10〜20年の賃貸借
        │ 分配金                        ▼
        └──────────────── ハイパースケーラー（テナント）
```

- **DCがREITと相性が良い理由**＝長期契約・優良テナント・賃料の自動改定条項。物流施設と同じ論理
- 一方、日本では**DC特化の上場REITが実現していない**。理由として、設備更新負担の重さ、
  情報開示の制約（テナント名・所在の秘匿）、利回り水準の折り合いなどが指摘される（報道ベース）
- Equinixは2026年のAFFO（調整後営業資金）を41.6〜42.4億ドル、設備投資を37〜42億ドルと見込む
  （同社ガイダンス、2026年）
  → 不動産側の論理は [不動産デベロッパー](../../12_建設・住宅・不動産/08_不動産デベロッパー/README.md)、
  [物流施設](../../12_建設・住宅・不動産/16_物流施設/README.md) と共通点が多い

## 6. テナント集中というリスク

ホールセールDCの顧客は、実質的に**ハイパースケーラー数社しかいない**。

| 構図                       | 事業者にとっての意味                                       |
| -------------------------- | ---------------------------------------------------------- |
| 1棟まるごと1社に貸す       | 営業が楽。空室リスクは契約期間中ゼロ                       |
| 売上の過半が数社に集中     | **価格交渉力が顧客側にある**。更新時に条件を切り下げられる |
| 顧客が自社建設に切り替える | 需要が消える。借りるより建てる方が安くなると起きる         |
| 顧客のAI投資が減速する     | 新規契約が止まり、建設中の棟が空室化する                   |

> 最大のリスクは景気ではなく**顧客の内製化と投資サイクル**。
> ハイパースケーラーの設備投資計画が、そのままDC事業者の受注見通しになる。
> → [生成AI／ビジネスモデルと経済性](../../01_注目テーマ/01_生成AI/03_ビジネスモデルと経済性.md)

## 7. 電力調達と再エネ ── コストであり商品でもある

電気は最大の変動費であると同時に、**「再エネ100%です」と言えること自体が商品価値**になっている。

| 調達手段                 | 中身                          | 使いどころ                                 |
| ------------------------ | ----------------------------- | ------------------------------------------ |
| 小売電気事業者からの購入 | 通常の電力契約                | 基本。燃料費調整で変動する                 |
| **コーポレートPPA**      | 発電事業者と長期の直接契約    | 価格を固定でき、再エネ属性も得られる       |
| 非化石証書・再エネ証書   | 環境価値だけを購入            | 手軽だが「追加性がない」と批判されることも |
| オンサイト太陽光・自家発 | 敷地内に発電設備              | DCの規模に対しては量が小さい               |
| 将来の選択肢             | 原子力（既設活用・SMR）、地熱 | 24時間安定電源として海外で契約例           |

- 顧客であるハイパースケーラー自身が**24/7カーボンフリー電力**を掲げているため、
  DC事業者は再エネ調達を「コスト」ではなく「入札条件」として扱わざるをえない
- 日本では再エネの偏在（北海道・九州に多い）が、**そのまま地方立地の理由**になる
  → [再生可能エネルギー](../../11_資源・エネルギー・鉄鋼金属/07_再生可能エネルギー/README.md)、
  [脱炭素・GX](../../01_注目テーマ/05_脱炭素・GX/README.md)

## 8. この事業を見るときの指標

| 指標                                   | 何が分かるか                              |
| -------------------------------------- | ----------------------------------------- |
| **契約済み容量（MW）／受電容量（MW）** | 実質的な稼働率。床面積より正確            |
| **バックログ（契約残）**               | 将来の売上の確度                          |
| **加重平均残存契約年数（WALT）**       | 収益の安定性。短いほど更新リスク          |
| **1kWあたり月額単価**                  | 市場の需給。上がっていれば供給不足        |
| **PUE**                                | 電気代の効率。1.4と1.2では原価が十数%違う |
| **開発パイプライン（MW）**             | 何年先まで成長が見えているか              |
| **受電権の確保状況**                   | 建物より先に押さえるべき資産              |

## 用語メモ

- **稼働率（occupancy）**：貸せる容量のうち実際に契約・使用されている割合
- **プレリース**：建設中・計画段階で契約を先に確定させること
- **純吸収（net absorption）**：期間中に新規に使用され始めた容量の純増
- **リースアップ**：完成した区画を埋めていく期間
- **パススルー**：電気代などの実費をそのまま顧客に転嫁する契約条項
- **EBITDA**：利払い・税・減価償却前の利益。設備産業の比較に使われる
- **AFFO**：REITの分配原資を示す指標。営業資金から維持的投資を控除したもの
- **SPC／プロジェクトファイナンス**：案件単位の会社を作り、その案件の収益で返済する仕組み
- **WALT**：加重平均残存賃貸借期間。契約がどれだけ長く残っているか
- **コーポレートPPA**：需要家と発電事業者が長期で直接結ぶ電力購入契約
- **24/7カーボンフリー**：年間合計ではなく毎時間単位で脱炭素電力を使う考え方
