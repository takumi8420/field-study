# データセンター

- 大分類: 情報通信・IT・ネット
- 状態: done
- 更新日: 2026-09-20

サーバを安全・安定に動かすための専用建物と、そこで動く設備・運用を提供する産業。
**売っているのは床面積ではなく電力（kW）**であり、損益の構造はIT業よりも**不動産賃貸業**に近い。
生成AIの計算需要を物理的に受け止める層であり、2026年時点のボトルネックは半導体ではなく**電気と用地**にある。

## 1. 業界の定義・範囲

**データセンター（DC）**＝サーバ・ストレージ・ネットワーク機器を集約して設置し、
電力・冷却・回線・セキュリティを24時間提供する専用施設、およびその運営事業。

| 区別すべき言葉               | 中身                                                                                  |
| ---------------------------- | ------------------------------------------------------------------------------------- |
| **データセンター業**         | 建物と電源・冷却・回線を提供する。**このフォルダの対象**                              |
| コロケーション（ハウジング） | 顧客の機器を預かって場所・電源・回線を貸すサービス形態                                |
| ホスティング                 | 事業者が用意したサーバ自体を貸す                                                      |
| **クラウド（IaaS/PaaS）**    | DCの上で仮想化された計算資源を売る → [クラウド・IaaS](../04_クラウド・IaaS/README.md) |
| ハイパースケーラー           | 自社で超大規模DCを運営する巨大クラウド事業者                                          |

## 2. 市場規模と成長性

| 指標                               | 数値                               | 時点・出所                                                    |
| ---------------------------------- | ---------------------------------- | ------------------------------------------------------------- |
| 世界のDC市場（売上高）             | 4,161億ドル → 2029年6,241億ドル    | 2024年見込み、Statista（総務省 令和7年版 情報通信白書が引用） |
| 世界のDC拠点数                     | 米国5,426／**日本222**             | 2025年3月時点、同白書                                         |
| 国内DCサービス市場                 | 2兆7,361億円 → 2028年5兆812億円    | 2023年実績、IDC Japan（2024年10月、予測は推計）               |
| 国内DC建設投資                     | **2028年に1兆円超**                | IDC Japan 予測（推計）                                        |
| 国内パブリッククラウド市場（参考） | 4兆1,423億円（前年比26.1%増）      | 2024年、IDC Japan                                             |
| 東京の受電容量在庫                 | 1GW超、空室率6%                    | 2026年第1四半期、CBRE                                         |
| 国内DCの消費電力                   | 国内総電力の約3%（2021年は約1.5%） | 2026年、報道ベース                                            |

- 成長の制約は需要ではなく**供給**（電力・用地・建設能力）。市場予測は「建てられる前提」で作られている点に注意
- 数値は定義（建物のみか、機器・サービス込みか）で桁が変わる。単独の数字を根拠にしない

**シェアの見方**：DCの「シェア」は拠点数や売上ではなく、**受電容量（MW）ベース**で見るのが実務的。
床面積は意味が薄く、同じ面積でも扱える電力が10倍違いうる。

## 5. 収益モデル・コスト構造

| 収益モデル                 | 課金の単位                  | 特徴                          |
| -------------------------- | --------------------------- | ----------------------------- |
| ラック貸し（リテール）     | 1ラック月額＋電力従量       | 単価は高いが営業件数が多い    |
| kW課金（ホールセール）     | 1kWあたり月額、10〜20年契約 | 1契約が巨大。不動産賃貸に近い |
| クロスコネクト             | 1本あたり月額               | 粗利が高く、解約を防ぐ        |
| リモートハンド等の運用代行 | 作業時間単位                | 人手商売                      |

**コスト構造の核心**：

- **減価償却＋電気代でコストの大半**。建物20〜30年、電気・空調設備10〜15年で償却する
- 固定費が重いため**損益分岐となる稼働率が高く**、半分空いていれば赤字になりやすい
- 電気代は顧客へのパススルー（実費転嫁）が主流。**転嫁できるかどうかで利益率が変わる**
- EBITDAマージンが高く見えるのは償却前の数字だから。営業利益率とは別物
- 詳しくは [事業としての経済性](03_事業としての経済性.md)

## 6. 競争要因（KSF）と参入障壁

| 要因                     | 中身                                         | 障壁の高さ                           |
| ------------------------ | -------------------------------------------- | ------------------------------------ |
| **受電権の確保**         | 系統に空きのある土地を先に押さえられるか     | 非常に高い。2026年の最大の希少資源   |
| **資金調達力**           | 100MW級で1,000億円超。長期・低利の資金が要る | 高い                                 |
| **長期契約の獲得**       | ハイパースケーラーとの関係                   | 高い。実績がないと入札に呼ばれない   |
| **接続性（回線の集積）** | 既存集積地ほど有利。集まるほど強くなる       | 高い（ネットワーク効果）             |
| **設計・運用の技術**     | 液冷、高密度、PUE改善                        | 中。ただし世代交代が速い             |
| **地域との合意形成**     | 住民説明、自治体との協定                     | 上がりつつある（新しい許認可に近い） |

## 7. 規制・法制度

| 領域                               | 内容                                                                                                                                                                                             |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **省エネ・非化石転換法**           | DC業がベンチマーク制度の対象に。2026年度提出分から電力消費量とPUEの報告・自社サイト公表。目標は2030年度に平均PUE1.4以下、2029年以降の新設はPUE1.3以下（資源エネルギー庁、2026年4月ガイドライン） |
| 建築基準法・都市計画法             | DCの明確な用途定義がなく「事務所」「倉庫」等で申請されるのが一般的。訴訟の争点になっている                                                                                                       |
| 消防法・大気汚染防止法・騒音規制法 | 非常用発電機の燃料備蓄、排煙、騒音が対象                                                                                                                                                         |
| 電気事業法                         | 受電設備、自家用電気工作物としての保安                                                                                                                                                           |
| 補助金                             | デジタルインフラ整備基金（1,300億円超）、GX戦略地域、環境省のゼロエミッション化事業 など                                                                                                         |
| 自治体ガイドライン                 | 東京都「大規模データセンター建設計画に係る話し合いガイドライン」（2026年3月）                                                                                                                    |
| 経済安全保障                       | 政府調達での国内保管要件、ソブリンクラウドの議論                                                                                                                                                 |

## 8. 最近のトピック

→ 詳細と出典URLは [05_直近トピック_2026](05_直近トピック_2026.md)

1. **空室率が記録的低水準**。北米プライマリ市場1.4%（2026年上期、CBRE）、東京6%。建つ前に埋まる市場になった
2. **賃料は地域差が数倍**。東京は1kWあたり月280ドル前後（2026年第1四半期、CBRE）。差の主因は供給制約
3. **国内は2026〜2030年に38件の新増設計画、半数超が液冷対応**（日経クロステック調査、報道ベース）
4. **OCCTOは2035年度までにDC・半導体工場で最大需要+762万kW**と見通す（2026年度供給計画）
5. **2026年度からPUEの報告・公表義務が始動**。効率が公開値になり、新旧DCの二極化が進む
6. **地域との合意形成が制度化へ**。東京都のガイドライン、印西市の建設訴訟が象徴的

## 9. 用語メモ

各ノート末尾にも分野別の用語メモを置いている。

| 用語                 | 意味                                                                                    |
| -------------------- | --------------------------------------------------------------------------------------- |
| **受電容量**         | 電力会社から受け取れる電力の上限。DCの実質的な「容積」 → [01](01_何を売る商売か.md)     |
| **ラック**           | サーバを収める標準の棚。42Uが一般的 → [01](01_何を売る商売か.md)                        |
| **コロケーション**   | 顧客の機器を預かり場所・電源・回線を貸すサービス → [01](01_何を売る商売か.md)           |
| **ホワイトスペース** | 実際に機器を設置できる部屋の面積 → [01](01_何を売る商売か.md)                           |
| **ティア（Tier）**   | 冗長度による信頼性等級。Uptime Instituteの分類 → [01](01_何を売る商売か.md)             |
| **N+1 / 2N**         | 冗長構成の表記。必要台数に対する予備の持ち方 → [01](01_何を売る商売か.md)               |
| **PUE**              | 施設全体の消費電力 ÷ IT機器の消費電力。1.0に近いほど効率的 → [01](01_何を売る商売か.md) |
| **UPS**              | 無停電電源装置。停電から発電機起動までをつなぐ → [02](02_建てる・運ぶ・冷やす.md)       |
| **直接液冷（DLC）**  | チップに冷却板を密着させ液体で熱を運ぶ方式 → [02](02_建てる・運ぶ・冷やす.md)           |
| **系統制約**         | 送電網の空き不足で新規接続が制限されること → [02](02_建てる・運ぶ・冷やす.md)           |
| **プレリース**       | 竣工前に契約を確定させること → [03](03_事業としての経済性.md)                           |
| **パススルー**       | 電気代等の実費を顧客へ転嫁する契約条項 → [03](03_事業としての経済性.md)                 |
| **コーポレートPPA**  | 需要家と発電事業者の長期直接契約 → [03](03_事業としての経済性.md)                       |
| **GX戦略地域**       | 再エネを生かした産業立地のため国が選定する地域 → [04](04_日本の現状と論点.md)           |
| **ソブリンクラウド** | 自国の法域・運営主体で完結するクラウド → [04](04_日本の現状と論点.md)                   |
