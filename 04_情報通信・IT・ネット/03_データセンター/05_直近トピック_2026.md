# データセンター｜直近トピック（2026年9月時点）

報道・調査・公的資料ベースの整理。数値は発表主体で定義が異なるため、一次情報での裏取りを前提に読むこと。

## 1. 空室率が史上最低に ── 建てる前に埋まる市場

2026年のDC市場を一言で表すと「**器が足りない**」。

| 市場               | 空室率                   | 時点・出所            |
| ------------------ | ------------------------ | --------------------- |
| 北米プライマリ市場 | **1.4%**（前年同期1.6%） | 2026年上期、CBRE      |
| 北バージニア       | 0.3%                     | 2026年第1四半期、CBRE |
| シンガポール       | 2%                       | 同上                  |
| 東京               | 6%                       | 同上                  |
| 欧州（年末見通し） | 6.5%（過去最低の見込み） | 2026年、CBRE予測      |

- 北米プライマリ市場の供給は2026年上期に前年同期比**+33.7%の10,903MW**へ増えたが、
  純吸収も1,456.2MW（+11.7%）に達し、**完成した端から埋まっている**状態と報告されている
- ダラス・フォートワースでは建設中716.7MWのうち**88%が契約済み**（プレリース）
- 欧州では系統のボトルネックが新規供給を制限しており、2026年の追加は750MW超にとどまる見通し

```
   需要 ████████████████████████  強い（AI学習・推論）
   供給 ██████████░░░░░░░░░░░░░░  電力と系統で頭打ち
              ↑
        この差が賃料上昇と空室率低下として表れている
```

## 2. 賃料は上昇、地域差は数倍 ── 「電気が引ける場所」のプレミアム

CBRE集計（2026年第1四半期、250〜500kW帯の1kWあたり月額）では、
シンガポール330〜475ドル、香港295ドル、**東京280ドル**、シドニー188ドル、
フランクフルト235〜265ドル、北バージニア190〜235ドル、シカゴ200〜230ドル。

| 高い市場の共通点     | 中身                                                         |
| -------------------- | ------------------------------------------------------------ |
| 建てられる土地がない | シンガポール、香港、東京湾岸                                 |
| 系統に空きがない     | ロンドン西部（変電所増強は2030年代初頭まで見込めないと報告） |
| 許認可が厳しい       | 欧州主要都市、自治体規制の強い地域                           |

- シカゴでは電力会社ComEdの供給スケジュールが**2032年以降**まで延びていると報告されている
- 価格差の主因は電気料金ではなく**供給できる量の差**。規制と系統がきつい市場ほど単価が高い

## 3. 日本：2026〜2030年に38件の新増設、半数超が液冷対応

日経クロステックの調査では、国内24社が2026〜2030年に**38件の新設・増設**を計画し、
うち**受電容量100MW超の巨大案件が5件**あるとされる（2026年、報道ベース）。

| 案件                                 | 内容                                                             | 時点          |
| ------------------------------------ | ---------------------------------------------------------------- | ------------- |
| 北海道苫小牧AIデータセンター         | ソフトバンク／IDCフロンティア。2026年度開業予定                  | 建設中        |
| ESR 有明（東京都江東区）             | 受電容量60MWの計画                                               | 発表済み      |
| Zeus OSA1（大阪市）                  | 東京建物＋SC Zeus Data Centers。供給電力容量25MW、2028年稼働目標 | 開発中        |
| ESRコスモスクエアOS1（大阪・南港北） | 米CloudHQとのJVで運用開始                                        | 2025年        |
| 石狩データセンターコンソーシアム     | NTT東日本・さくらインターネットなど11社と石狩市が設立を発表      | 2026年7月28日 |

- **液冷対応が全体の半数超**に達したと報じられ、AI向け設計が標準になりつつある
- 国内DCサービス市場は2023年に2兆7,361億円、2028年に5兆812億円の見通し（IDC Japan、推計）
- 国内DC建設投資は**2028年に1兆円を超える**見通し（IDC Japan、推計）

## 4. 電力：2035年度に+762万kWという公式見通し

電力広域的運営推進機関（OCCTO）の2026年度供給計画取りまとめ（2026年3月）では、
**2035年度までにDC・半導体工場の新増設で最大需要が+762万kW、電力量が+568億kWh増える**と整理された。

```
  全国の最大需要（夏季・送電端）
   2026年度 15,962.6万kW ──（年平均+0.4%程度）──▶ 2035年度 16,460.1万kW
        ▲
   全国では微増に見えるが、
   北海道・東京・中国エリアではDCと半導体工場で局所的に急増する
```

| 論点     | 内容                                                   |
| -------- | ------------------------------------------------------ |
| 局所集中 | 全国平均ではなくエリア単位で系統が詰まる               |
| 接続待ち | 2026〜2027年は接続申込が積み上がる局面とされる         |
| 需給調整 | DC側が出力を絞る／蓄電池を併設する調整力提供の議論     |
| 電源確保 | 再エネ・原子力・自家発を含めた長期の電源手当てが論点に |

- 国内DCの消費電力は2026年時点で国内総電力の**約3%**に近づいたと報じられる（2021年は約1.5%）
- BCGの分析では日本のDC電力需要は2030年に現在の約2倍、2040年に約9倍（推計）
  → [電力](../../11_資源・エネルギー・鉄鋼金属/04_電力/README.md)

## 5. 規制：2026年度からPUEの報告・公表が始まった

資源エネルギー庁は2026年4月10日、省エネ・非化石転換法に基づく**データセンター業に係る措置のガイドライン**を策定した。

| 項目             | 内容                                                                 |
| ---------------- | -------------------------------------------------------------------- |
| 対象             | 年間エネルギー使用量1,500kL（原油換算）以上、またはサーバ室300㎡以上 |
| 報告             | 電力消費量、PUE、原単位と目標（2026年度提出分から）                  |
| ベンチマーク目標 | 2030年度に平均PUE **1.4以下**                                        |
| 新設基準         | 2029年以降の新設施設は PUE **1.3以下**                               |
| 公表             | 自社ウェブサイトでPUE・電力消費量を公表                              |
| 対象の広がり     | テナント型DC事業者も対象に                                           |

> 効率が「努力目標」から「公開される数値」になった。
> 旧式の空冷DCは規制対応と競争力の両面で不利になり、**新旧の二極化**が進む可能性がある。

## 6. 地域との摩擦が制度化の段階へ

- 東京都は2026年3月、**「大規模データセンター建設計画に係る話し合いガイドライン」**を策定。
  住民との合意形成プロセスを制度として整えた初めての試みとされるが、
  建設を止める法的拘束力はない
- 千葉県印西市では、建築基準法上の用途が「事務所」か「工場」かを争点とする建設訴訟が起きた（報道ベース）
- 非常用発電機の排煙・騒音が法規制の隙間に落ちやすいという指摘も出ている
- 米国では2025年11月時点で**37州**がDC向けの売上税免除や固定資産税減免を提供する一方、
  住民の反発も並走している（JETRO整理）

## 7. 政策：地方分散と経済安全保障

| 地域 | 2025〜2026年の動き                                                                                                                                           |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 日本 | デジタルインフラ整備基金1,300億円超。デジタルインフラ整備計画2030（2025年6月）。GX戦略地域に石狩市・苫小牧市が認定（2026年）                                 |
| 米国 | AI行動計画（2025年7月23日）、大統領令14318で連邦許認可を迅速化                                                                                               |
| EU   | AI大陸行動計画（2025年4月）、AIファクトリー16加盟国19拠点・26億ユーロ超（2025年10月時点）、AIギガファクトリー最大200億ユーロ、クラウド・AI開発法（CADA）法案 |

- 個別支援としてさくらインターネット最大575億円、ソフトバンク最大474億円、
  苫小牧のDC整備に最大300億円、KDDI最大102億4,000万円などが報じられている（JETRO整理）
- EUでは域内DC需要の**65%を米国3社**が占めるという整理があり、自律性確保が政策の軸になっている

## 8. REIT・資本市場：需要は最高でも、日本では上場が進まない

- Digital Realtyは2025年12月末時点で310拠点、白床IT負荷2,967.7MW、稼働率84.7%
- Equinixは280施設・77市場36カ国で展開。2026年のAFFOを41.6〜42.4億ドル、
  設備投資を37〜42億ドルと見込む（同社ガイダンス）。2026年2月に過去最高の受注と強気見通しを示し株価が急伸したと報じられる
- 一方、日本では**DC特化の上場REITが実現していない**。設備更新負担の重さ、
  テナント情報の秘匿性、利回り水準などが理由として挙げられている（報道ベース）

## 9. 全体の構図（まとめ）

1. **需要は強いが、器が足りない**。空室率は北米1.4%・欧州6.5%見通しと記録的低水準で、建つ前に埋まる
2. **制約は電気**。系統増強が2030年代まで見込めない市場もあり、用地より受電権が資産になっている
3. **設計の世代交代**。1ラック100kW級のAI向け構成が標準化し、液冷前提の新設と旧式空冷DCが二極化する
4. **日本は2大都市圏集中と系統制約の板挟み**。政策は地方分散だが、動くのは遅延に鈍感なAI学習用途から
5. **規制が数値の公開を要求する段階へ**。2026年度からPUEと電力消費量の報告・公表が始まった
6. **地域との合意形成が新しい許認可**になりつつある。東京都のガイドライン、印西の訴訟がその象徴

> 一文でいえば：**「需要は本物、供給は電気で詰まり、設計は液冷へ、立地は政治問題になった」**。

## 用語メモ

- **空室率（vacancy rate）**：貸せる容量のうち契約されていない割合。DCでは面積でなくkW基準
- **純吸収（net absorption）**：その期間に新たに使用され始めた容量の純増分
- **プレリース**：竣工前に契約を確定させること。DC開発の常態
- **受電容量**：その施設が電力会社から受け取れる電力の上限
- **GX戦略地域**：再エネを生かした産業立地を進めるため国が選定する地域
- **ベンチマーク制度**：業種ごとの効率目標を定め達成状況を報告させる省エネ法の仕組み
- **AFFO**：REITの分配原資を示す指標
- **CADA**：EUが検討するクラウド・AI開発法（Cloud and AI Development Act）
