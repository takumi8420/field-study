# 建てる・運ぶ・冷やす ── 立地・電気設備・冷却

このノートで分かること：データセンターの**立地がどう決まるか**、電気がラックに届くまでの経路、
空冷から液冷への転換、水の使用、そして「建てたくても建てられない」建設リードタイムの正体。

## 1. 立地を決める3条件：電力・光ファイバ・土地

DCの用地選定は、不動産の常識（駅からの距離、人通り）とはまったく別の軸で行われる。

| 条件           | 何を見るか                                                           | 満たせないと                     |
| -------------- | -------------------------------------------------------------------- | -------------------------------- |
| **電力**       | 近くに基幹変電所があるか、系統に空き容量があるか、受電契約までの年数 | 建物が完成しても電気が入らない   |
| **光ファイバ** | 主要な通信ルートに乗っているか、複数経路を引けるか                   | 遅延が大きく、大口顧客が入らない |
| **土地**       | まとまった面積、地盤と標高（水害・地震）、用途地域、騒音の許容度     | 許可が下りない／住民と揉める     |

```
   ① 基幹変電所から近い      ② 光ファイバ幹線に近い     ③ 安い広い平地
        ●                        ━━━━━                  ▭▭▭▭
        ＼                       ／                      ／
         ＼                     ／                      ／
          ▼───────────────▼─────────────▼
                     この3つが重なる場所しかDCは建たない
                     （日本では極端に少ない＝立地が集中する原因）
```

- 標高・地盤は保険料と顧客の審査に直結する。**浸水想定区域は避ける**のが原則
- 遅延（レイテンシ）が問題になる用途（金融取引、対話型サービス）は都心近くでないと困る
- 逆にAIの**学習**用途は遅延に鈍感なので、電気の安い地方でも成立する。ここが地方分散の論拠になる
  → [日本の現状と論点](04_日本の現状と論点.md)

## 2. 電気がラックに届くまで

DCの中身は、突き詰めると**電気を切らさずに運ぶ装置の集合**である。

```
 電力会社 ──▶ 受変電設備 ──▶ UPS ──▶ 分電盤(PDU) ──▶ ラック ──▶ サーバ
  特別高圧      66kV等を        停電の      各ラックへ       電源タップ
  (数万V)       6.6kV/400Vへ    数分間を    配電・計量        (2系統が基本)
                 落とす         肩代わり
                                  ▲
                                  │ 数十秒〜1分で起動
                            非常用発電機（ディーゼル/ガスタービン）
                                  ▲
                                  │ 通常48〜72時間分
                               燃料タンク
```

| 設備                      | 役割                                                 | 押さえどころ                           |
| ------------------------- | ---------------------------------------------------- | -------------------------------------- |
| **受変電設備**            | 高圧の電気を建物内で使える電圧に落とす               | 変圧器の納期が全体工程を縛る           |
| **UPS（無停電電源装置）** | 停電の瞬間から発電機が立ち上がるまでを蓄電池でつなぐ | 数分しか持たない。あくまで「つなぎ」   |
| **非常用発電機**          | 長時間の停電を肩代わり                               | 軽油の備蓄と排気・騒音が地域との摩擦点 |
| **PDU（分電盤）**         | ラック単位に配電し、使用量を計測                     | 顧客への従量課金の計測点になる         |

- 電源は**A系統・B系統の二重化**が基本。サーバ側も電源ユニットを2個持ち、片方が死んでも動く
- 非常用発電機は消防法・大気汚染防止法・騒音規制の対象で、**試運転の音と排煙が住民苦情の主因**になる
- 蓄電池を系統用にも使い、電力の需給調整に参加する動きも出ている
  → [蓄電池](../../01_注目テーマ/04_蓄電池/README.md)、[電力](../../11_資源・エネルギー・鉄鋼金属/04_電力/README.md)

## 3. 冷やす ── 空冷の限界と液冷への転換

サーバが消費した電力は**ほぼ100%が熱になる**。この熱を外に捨て続けられる量が、そのDCの上限を決める。

### 空冷（従来方式）

```
   [冷水チラー]──冷水──▶[空調機(CRAC)]
                            │冷風
                            ▼
      ┌─────────────────────────────┐
      │  ▒▒▒ラック▒▒▒   ▒▒▒ラック▒▒▒  │ ← コールドアイル（冷風側）を
      │  ←冷→  熱→      ←冷→  熱→    │    囲って混ざらないようにする
      └─────────────────────────────┘
                  温風を吸い戻す
```

- 冷えた空気を床下から吹き上げ、サーバの前面から吸わせて背面に熱を捨てる
- **コールドアイル・ホットアイル封じ込め**＝冷風と温風を物理的に分離する定石。PUE改善の第一歩
- 外気が冷たい地域では外気をそのまま使う**外気冷却（フリークーリング）**が効く。寒冷地立地の利点

### 液冷（AI向けで前提になりつつある方式）

| 方式                                  | 仕組み                               | 特徴                                     |
| ------------------------------------- | ------------------------------------ | ---------------------------------------- |
| **リアドア熱交換**                    | ラック背面に水冷の熱交換器を付ける   | 既存建物に後付けしやすい。30〜50kW級まで |
| **直接液冷（DLC／コールドプレート）** | チップに金属板を密着させ冷却液を通す | 100kW級に対応。**AIラックの主流**        |
| **液浸冷却（イマージョン）**          | サーバごと絶縁性の液体に沈める       | 効率は高いが保守作業と機器保証が課題     |

```
  空冷の限界                     液冷への移行
  ──────────                  ──────────
  1ラック 5〜20kW      ──▶     1ラック 100〜120kW
  風で熱を運ぶ                  液体で熱を運ぶ（水は空気の約3,500倍の熱容量）
  建物側の改造は小              **配管・二次側ループ・CDUの増設が必要**
```

- 液冷対応には**床荷重・配管スペース・漏水対策**が要り、古い建物の転用は難しい
- 日経クロステックの調査では、2026〜2030年に国内で予定される新設・増設38件のうち
  **半数超が液冷対応**とされる（2026年、報道ベース）
- 液冷市場は2025年の約55億ドルから2030年代に150〜270億ドル規模へ拡大するという推計がある（調査会社推計）
- 完全に液冷だけで済むわけではなく、**ネットワーク機器や電源は空冷のまま残る**ハイブリッドが現実解

## 4. 水をどれだけ使うか

冷却方式によって、DCは大量の水を使う。これが地域との摩擦点になりやすい。

| 冷却方式                 | 水の使い方                       | 水使用量 | 電力効率           |
| ------------------------ | -------------------------------- | -------- | ------------------ |
| 空冷（冷却塔あり）       | 蒸発させて熱を捨てる             | 多い     | 良い               |
| 空冷（空冷チラー）       | 水を使わず空気で捨てる           | ほぼゼロ | 悪い（電気を食う） |
| 液冷（閉ループ＋冷却塔） | 循環させるが冷却塔で蒸発分が出る | 中程度   | 良い               |

> **水と電気はトレードオフ**。水を使わない設計にするとPUEが悪化し、電気代が増える。
> 「省エネのDC」と「水を使わないDC」は必ずしも両立しない。

- 日本は水資源に比較的恵まれるが、**取水量と排水温度は自治体との協議事項**になる
- 排熱の地域利用（農業ハウス、融雪、地域熱供給）を条件に誘致する例も出てきている

## 5. 建設のリードタイムとサプライチェーン

「AI需要があるのにDCが足りない」原因の大半は、**買えないものと待たされるもの**にある。

```
  用地取得  設計・許認可   受電契約の申込〜供給         建設・施工      試験  開業
  ├──6〜18か月──┼──6〜12か月──┼════ 2〜7年（系統次第）════┼──18〜30か月──┼─3〜6か月─┤
                                    ▲
                        ここが最大のボトルネック。
                        建物は建つが電気が来ない、という状態が起きる
```

| 制約要因         | 具体的な中身                                                                                                        |
| ---------------- | ------------------------------------------------------------------------------------------------------------------- |
| **系統接続**     | 送電網に空きがなければ増強工事が必要。海外では2030年代まで待つ市場もある                                            |
| **変圧器**       | 受変電用の大型変圧器は世界的に需給逼迫。発注から納入まで年単位                                                      |
| **非常用発電機** | 大型ディーゼル・ガスタービンも同様に納期が長期化                                                                    |
| **GPU・サーバ**  | 半導体側の供給制約。→ [半導体・先端半導体](../../01_注目テーマ/02_半導体・先端半導体/README.md)                     |
| **人手**         | 電気工事・空調工事の技能者不足。→ [サブコン](../../12_建設・住宅・不動産/02_サブコン（電気・空調・設備）/README.md) |

- 海外の例として、シカゴでは電力供給のスケジュールが2032年以降まで延び、
  ロンドン西部やフランクフルトでも系統増強が2030年代前半まで見込めないと報告されている
  （CBRE、2026年第1四半期）
- 変圧器の制約は「作れるか」ではなく「**必要な順番で全工程が通るか**」という供給網の問題とされる（2026年、報道ベース）
- 結果として**先に電力枠を押さえた事業者が強い**。用地より受電権が資産になる

### モジュール化という回避策

工場で電源・冷却ごとユニット化して現地で組む**プレハブ／コンテナ型DC**が増えている。
現地工期を短縮でき、地方や寒冷地に小型を分散させる用途と相性が良い。
ただし1棟あたりの容量は小さく、ハイパースケールの主力にはなりにくい。

## 6. 誰が建てるのか

| 役割           | 担い手                                                              | 取り分の性格                               |
| -------------- | ------------------------------------------------------------------- | ------------------------------------------ |
| 開発・用地     | デベロッパー、商社、外資DC事業者                                    | 土地と受電権の確保が価値                   |
| 設計・施工     | ゼネコン（大成・鹿島・清水など）                                    | 大型案件の受注残として効く                 |
| 電気・空調設備 | サブコン（きんでん、高砂熱学、新日本空調など）                      | **工事の中身はほぼ設備工事**。粗利率が高い |
| 主要機器       | 変圧器・受変電（日立、東芝、富士電機など）、空調（ダイキン等）、UPS | 納期がそのまま参入障壁                     |
| 電力供給       | 一般送配電事業者、新電力、自家発                                    | 系統増強の負担配分が論点                   |

> DC建設ブームの恩恵は、DC事業者よりも**ゼネコン・サブコン・電機メーカーの受注**に先に現れる。
> 「AI関連銘柄」がハード寄りに広がるのはこのため。

## 用語メモ

- **受変電設備**：高圧の電気を施設内で使える電圧へ変換する設備一式
- **UPS**：無停電電源装置。停電から発電機起動までの数分を蓄電池でつなぐ
- **PDU**：ラックへ電力を配る分電盤。使用量の計測点でもある
- **コールドアイル／ホットアイル**：ラック列の冷風側と温風側。混ぜないよう封じ込める
- **フリークーリング（外気冷却）**：外気の冷たさをそのまま使う省エネ手法
- **DLC（直接液冷）**：チップに冷却板を密着させ液体で熱を運ぶ方式
- **液浸冷却**：サーバごと絶縁液に浸す方式
- **CDU**：液冷の一次側と二次側をつなぐ熱交換・循環ユニット
- **系統接続**：送電網につないで電気を受ける権利と工事。DC建設最大のボトルネック
- **モジュール型DC**：工場でユニット化して現地で組み立てるDC
- **レイテンシ**：通信の遅延。用途によって許容度が大きく違う
