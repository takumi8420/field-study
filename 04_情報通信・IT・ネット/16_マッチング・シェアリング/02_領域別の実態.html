このノートで分かること：フリマ・仕事・恋愛・家事・スペース・モビリティの6領域について、
実際に黒字化したのはどこで、期待ほど広がらなかったのはどこかを、理由とセットで並べる。

「シェアリングエコノミー」という言葉で一括りにされるが、中身の経済性はまったく違う。
マッチングの難しさ で挙げた条件（頻度・単価・決済の掌握・
相手が毎回変わるか）を当てはめると、勝敗はかなりきれいに説明できる。

1. まず全体像：国内市場は3兆円台、ただし中身は偏っている

国内シェアリングエコノミー市場は2024年度で3兆1,050億円（情報通信総合研究所と
一般社団法人シェアリングエコノミー協会の共同調査、2025年1月公表。2022年度比+18.7%）。
2030年度に14兆円規模へという推計も同協会から出ているが、これは潜在需要を含む将来予測であり、
現在の実績値と同列に扱ってはいけない。

  【儲かる領域はどこか：頻度 × 決済掌握】

  決済を
  握れる  ┌──────────────┬──────────────┐
    ↑     │ フリマ（物）    │ スキマバイト    │
          │ 駐車場シェア    │ 配車・デリバリー │  ← 手数料モデルが成立
          │ 民泊仲介       │                │
          ├──────────────┼──────────────┤
          │ スペース貸し    │ 家事・介護・育児 │
          │ （季節・時間偏り）│ （固定客化で場外へ）│ ← 苦戦しやすい
  握れない└──────────────┴──────────────┘
           低頻度 ←──────────────────→ 高頻度

  ※恋愛マッチングは例外。取引を握らず「会員課金」で成立する唯一に近い型

3. フリマ＝この業界で最も成功した型

なぜ勝てたかは4条件がすべて揃っているから。

  1. 供給が無限にある：家の中の不要品。追加コストがほぼゼロの純粋な遊休資産
  2. 決済を完全に握れる：代金は事業者が預かり、商品到着後に売り手へ渡す（エスクロー）
  3. 相手が毎回変わる：同じ人から繰り返し買う理由がないので場外取引が起きにくい
  4. 匿名配送で信頼の壁を越えた：氏名・住所を相手に見せずに送れる仕組みが、
    個人間取引の心理的ハードルを一段下げた

数字で見ると、メルカリの2026年6月期はGMV 1兆2,856億円（前期比+14.7%）、
売上収益2,292億円（+19.0%）、営業利益439億円（+57.7%）で、上場後初の自社株買い（最大100億円）を
決めている（同社決算発表、2026年8月）。国内のマッチング・シェアリングでこの規模に届いたのは事実上ここだけ。

  【フリマの収益構造（イメージ）】

   出品者 ──商品──▶ 購入者
      ▲               │代金
      │ 売上金        ▼
   ┌──────────────────────────┐
   │  プラットフォーム             │
   │   販売手数料 10%              │
   │   ＋ 配送（提携で低価格化）    │
   │   ＋ 売上金を原資にした金融    │ ← ここが第2の収益源
   │      （決済・後払い・投資）    │
   └──────────────────────────┘
      売上金をアプリ内に留めさせると、そのまま金融事業の原資になる

ポイント：フリマの利益の第2エンジンは金融。売上金をアプリ内に滞留させ、
決済・与信につなげる構造は フィンテック・キャッシュレス と地続きである。
中古品そのものの流通は リユース・中古 を参照。

4. 仕事の仲介：「成果物」より「時間」が伸びた

同じ「仕事のマッチング」でも、2020年代に入って明暗が分かれた。

型 例 何が起きたか
クラウドソーシング（成果物）クラウドワークス、ランサーズ単価下落と場外化。良い発注者と受注者は直接契約に移行しやすい。近年は人材紹介・エージェント型へ軸足を移す
スキル販売（個人の売り物）ココナラ商品として並ぶため場外化しにくく、相対的に手数料を維持
知見のスポット相談ビザスク単価が高く企業が発注者。コンプライアンス上、場外に出しにくい
スポットワーク（労働時間）タイミー、シェアフル人手不足と直結して急拡大。雇用契約なので場外化がそもそも難しい

スポットワークの伸びは数字にはっきり出ている。タイミーの2026年4月期は
売上高210億円（前期比+27.6%）、営業利益38億円（同+16.8%、同社決算説明資料）。
同社の市場レポートでは2026年5〜7月の全国スポットワーク募集件数411.8万件（前年同期比+13.1%）、
同社経由の総賃金額314億円（+18.2%）とされる。

ポイント：「成果物」の仲介は場外へ抜け、「労働時間」の仲介は抜けにくい。
労働時間は雇用契約・勤怠・賃金支払い・労災が付いて回るため、
個人同士で直接やるには重すぎるからである。この重さがそのまま参入障壁になっている。
人材ビジネス全般の構造は HRテック・人材系ネットサービス と
人材派遣 を参照。

5. 恋愛マッチング：取引を握らずに儲かる例外

マッチングアプリは、成立した「取引」から手数料を取らない。
会うところまでしか関与せず、月額課金で稼ぐ。それでも成立する理由は3つ。

  • 成果（交際・結婚）を事業者が検知・計測できないので、成功報酬にできない
  • 探索そのものに価値があり、成立しなくても課金が続く
  • 男性側に課金を寄せる非対称価格が定着している（女性無料で供給側を確保する構造）

国内市場は2026年時点で約1,094億円（民間調査「マッチングアプリ白書2026」の推計）。
主要アプリの累計会員数は2,000万人台と公表されるが、これは累計登録であって
アクティブ利用者ではない点に注意が必要。

  【恋愛マッチングの皮肉な構造】

   課金して探す ──▶ 相手が見つかる ──▶ 退会（＝解約）
        ▲                                   │
        └───── 別れる・再び探す ◀───────────┘

   「成功すると顧客を失う」が、母集団の入れ替わりが速いので回る。
   一方で、母集団（若年人口）が縮むと構造的に頭打ちになる。

婚礼周辺の産業は ブライダル と接続する。

6. 家事・介護・育児：期待ほど広がらなかった代表

「家事をシェアで」という構想は2015年前後に大量のサービスを生んだが、
大半はC2Cのマッチングを諦めて派遣・請負型に転換するか、撤退した。理由は5つ。

壁 中身
固定客化＝場外化気に入った人に毎週来てほしい。2回目以降は直接契約に流れやすい
品質のばらつきが致命的家の中に入れる以上、失敗の心理的コストが極端に高い
事故時の責任器物破損、子どもの怪我。仲介者は「場を貸しただけ」で済まない
資格・法規制保育・介護は資格や指定が絡み、純粋なマッチングにできない領域がある
単価と供給の板挟み利用者が払える額と、働き手が受け取りたい額の差が埋まらない

結果として、この領域で規模を作った事業者は自社で採用・研修・保険まで面倒を見る
「実質的なサービス会社」になっている。→ 家事代行・生活支援

ポイント：人が人の家に入る領域では、マッチングの軽さは長続きしない。
信頼の第4層（保険・補償）まで自前で用意すると、コスト構造は人材サービスに近づく。

7. スペース：民泊と駐車場は成立、会議室系は小粒

  • 民泊：住宅宿泊事業法の届出は累計63,658件、稼働中の届出住宅は40,745件（観光庁、2026年5月時点）。
    インバウンド回復で市場は戻ったが、自治体規制の強化局面に入っている
    → 規制と社会受容。宿泊産業全体は ホテル を参照
  • 駐車場シェア：小さいながら明快な成功例。akippaは会員登録550万人（2026年9月時点、同社公表）、
    掲載駐車場5.5万件規模で、2026年9月に東証スタンダードへ上場した（想定時価総額約33.8億円と報じられる）。
    供給が純粋な遊休資産で、決済がアプリ内で完結し、利用が繰り返されるという条件が揃っている
  • 会議室・イベントスペース：需要が平日昼と週末に偏り、稼働率が上がらない。
    単価も低く、CACを回収しづらい。企業向けの法人契約に寄せる動きが続く
  【スペース系の稼働率の壁】

   月  火  水  木  金  土  日
   ▁▁  ▃▃  ▃▃  ▃▃  ▆▆  ██  ██     ← イベントスペース（週末集中）
   ▆▆  ██  ██  ██  ██  ▁▁  ▁▁     ← 会議室（平日集中）
   ██  ██  ██  ██  ██  ██  ██     ← 駐車場（時間帯は違えど毎日使われる）

   「毎日使われるか」が、そのままユニットエコノミクスの差になる

8. モビリティ：事業者保有型は伸び、個人間シェアは不発

日本のカーシェアは、個人の車を貸し借りするC2Cではなく、事業者が車を保有して
時間貸しするB2C型（実質的な短時間レンタカー）が主流として定着した。
交通エコロジー・モビリティ財団の調査（2026年3月時点）では、
ステーション37,231か所、車両85,312台、会員5,391,855人。
→ レンタカー・カーシェア

一方ライドシェア（自家用車で客を運ぶ）は、日本では全面解禁されていない。
2024年4月に始まった「日本版ライドシェア（自家用車活用事業）」は、
タクシー事業者が運行主体になるという条件付きで、地域・時間帯を限って認められる制度である。
純粋なプラットフォーム型ではないため、海外のような急拡大は起きていない。
→ タクシー・バス、制度の詳細は 規制と社会受容

参考までに、規制が緩い市場での規模感。Uberの2026年第2四半期は総取扱高580億ドル（前年同期比+24%）、
Airbnbは同四半期の総予約額272億ドル（+16%）、実質テイクレート13.2%（各社IR）。
同じ事業でも、制度が違えば桁が変わることがよく分かる。

シェアサイクルは自治体・鉄道系を中心に拠点数を増やしたが、
再配置（偏った自転車を運ぶ）コストが重く、単独事業としての採算は厳しいとされる。
撤退・サービス終了の事例も継続的に出ている。

9. 総括：成功と失敗を分けた線

成功した領域 共通点
フリマ、スポットワーク、駐車場シェア、民泊仲介供給が遊休資産か労働時間／決済を握れる／相手が毎回変わる／繰り返し使われる
広がらなかった領域 共通点
家事・介護・育児、C2Cカーシェア、会議室シェア、一般のシェアサイクル固定客化して場外へ抜ける／事故責任が重い／稼働が偏る／単価が低い／法規制で純粋なマッチングにできない

結論：シェアリングエコノミーは「所有から利用へ」という思想で語られてきたが、
実際に残ったのは思想に合致した領域ではなく、上の経済条件を満たした領域だった。

用語メモ

用語 意味
C2C／B2C個人間取引／事業者から個人への取引。同じ「シェア」でも経済性が別物
スポットワーク数時間単位の単発の仕事。多くは雇用契約を伴う（業務委託のギグワークとは別）

稼働率貸せる時間のうち実際に使われた割合。スペース・モビリティの生命線

実質テイクレート総取引額に対する事業者売上の比率。手数料率の表示とは一致しないことが多い
