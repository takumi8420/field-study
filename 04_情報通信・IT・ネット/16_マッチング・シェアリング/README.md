## このフォルダの読み方

「人と人」「人とモノ」を出会わせて手数料を取る事業を、**産業として**理解するためのノート群。
型としては **IT・ネット型（両面市場）** だが、SNSや検索と決定的に違う点が2つある。

1. **取引が現実世界で起きる**（部屋に泊まる、車に乗る、人が家に来る）ので、必ず既存の業法にぶつかる
2. **ネットワーク効果が地理的に切れている**ので、都市ごとに市場を作り直さなければならない

したがって骨格は「①なぜマッチングは難しいのか（構造）」→「②どこが儲かり、どこが儲からなかったか（実態）」
→「③何が事業の前提を変えるのか（規制と社会受容）」の3段で作る。

## 1. 業界の定義・範囲

**マッチング・シェアリング**＝自社では商品もサービスも持たず、
**個人や小規模事業者が持つ遊休資産・時間・スキルを、必要とする人に結び付けて手数料を取る事業**。

```
 【このフォルダの守備範囲】

 ┌──────────────────────────────────────────────────┐
 │ ● モノのシェア／売買    フリマ、レンタル、シェアサイクル   │
 │ ● スペースのシェア      民泊、駐車場、会議室、倉庫        │
 │ ● 移動のシェア          カーシェア、ライドシェア          │
 │ ● スキル・時間のシェア  クラウドソーシング、スキマバイト   │
 │ ● 出会いのマッチング    恋愛・婚活、家事・育児・介護      │
 └──────────────────────────────────────────────────┘
   ▲ 隣接だが別フォルダ：広告技術／モール型EC／SNS／人材派遣の本体
```

## 3. バリューチェーン（川上 → 川下）

```
  供給側（個人・小規模事業者）
     ｜ 出品・登録・シフト提供
     ▼
  ┌──────────────────────────────────────────┐
  │  プラットフォーム                             │
  │  ① 集客（広告・SEO・紹介）  ← 最大の変動費      │
  │  ② マッチング（検索・推薦・配車アルゴリズム）    │
  │  ③ 信頼（レビュー・本人確認・審査）             │
  │  ④ 決済（エスクロー・立替・売上金保有）         │
  │  ⑤ 保証（補償・保険・カスタマーサポート）       │
  └──────────────────────────────────────────┘
     ▼                          ＼
  需要側（利用者）                 ＼ 周辺事業者
                                   （配送、決済、保険、eKYC、清掃代行など）

  付加価値が集まるのは ②③④。①は外部に流出し、⑤は原価として出ていく
```

- **②マッチング精度**が流動性を決め、流動性がGMVを決める
- **④決済を握れるか**がテイクレートの上限を決める。握れないと掲載課金・サブスクに落ちる
- **⑤保証**は規模が出ても比例して増えるため、利益率の自動改善は起きにくい

## 5. 収益モデル・コスト構造

| モデル             | 取り方             | 目安                                 | 成立条件                             |
| ------------------ | ------------------ | ------------------------------------ | ------------------------------------ |
| 取引手数料         | GMVの一定率        | 10%（フリマ）〜30%前後（労働・配車） | 決済を握れること                     |
| 掲載課金・サブスク | 月額・掲載枠       | 実質数%                              | 取引を検知できない領域（恋愛、求人） |
| 広告               | 上位表示・ブースト | 追加数%                              | 供給側が多く、競争があること         |
| 金融               | 決済・与信・投資   | —                                    | 売上金がアプリ内に滞留すること       |

```
  【マッチング事業の損益構造（イメージ）】

   売上＝GMV × テイクレート
     −  決済手数料 ................ 売上の10〜20%
     −  補償・CS・不正対策 ........ 売上の10〜20%   ← 取引数に比例して増える
     −  広告宣伝費（CAC） ......... 成長期は売上の30〜50%
     −  人件費・開発 .............. 固定費
     ＝ 営業利益

   ※ 在庫と物流を持たないので粗利率は高いが、
     「集客」と「信頼」が実質的な原価として立ちはだかる
```

## 6. 競争要因（KSF）と参入障壁

1. **地域ごとの流動性**：その街で「すぐ見つかる」状態を作れているか。全国平均の会員数は意味がない
2. **場外取引を塞ぐ設計**：決済・補償をプラットフォーム内に閉じ込められているか
3. **信頼インフラ**：本人確認・レビュー・補償の完成度。制度が厳格化する方向なので、後発ほど重い
4. **供給側の定着**：初回で稼がせて残す設計。90日後残存率が事業の体力
5. **規制対応力**：業法・自治体条例・労務の変化に追随する体制。**小規模事業者ほどここで脱落する**
6. **隣接事業への展開**：フリマ→金融、スポットワーク→採用支援のように、
   手数料だけでは足りない分を周辺で稼ぐ

参入障壁そのものは**技術ではなく「流動性と信頼の蓄積」**にある。
逆に言えば、地域単位で見ると障壁は薄く、局地戦は常に起きうる。

## 7. 規制・法制度

| 領域   | 主な法令                                                 | 要点                                                                          |
| ------ | -------------------------------------------------------- | ----------------------------------------------------------------------------- |
| 民泊   | 住宅宿泊事業法、旅館業法、国家戦略特区法                 | 届出制・年180日上限。自治体の上乗せ条例が主戦場。2026年に「ゼロ日条例」容認へ |
| 移動   | 道路運送法（78条）                                       | 自家用車の有償運送は原則禁止。日本版ライドシェアはタクシー事業者が運行主体    |
| 労働   | 職業安定法、労働基準法、フリーランス法（2024年11月施行） | スポットワークは雇用。ギグワークの労働者性は未決着                            |
| 中古品 | 古物営業法                                               | 業として反復継続するなら古物商許可。本人確認義務とアプリの匿名性が衝突        |
| 決済   | 資金決済法、犯罪収益移転防止法                           | エスクロー・売上金保有の設計次第で資金移動業の登録が必要                      |
| 共通   | 消費者契約法、特定商取引法、個人情報保護法               | 表示・解約・データの扱い                                                      |

詳細は [規制と社会受容](03_規制と社会受容.md) を参照。

## 9. 用語メモ

| 用語                         | 意味                                                                           |
| ---------------------------- | ------------------------------------------------------------------------------ |
| **流動性（リクイディティ）** | 探した人がすぐ相手を見つけられる度合い → [詳しくは①](01_マッチングの難しさ.md) |
| **テイクレート**             | 取引総額に対する事業者の取り分の比率                                           |
| **GMV／流通総額**            | プラットフォーム上で成立した取引額の合計。売上とは別                           |
| **場外取引**                 | 出会った当事者が手数料を避けて直接取引すること                                 |
| **エスクロー**               | 代金を事業者が一時預かりし、完了後に渡す仕組み                                 |
| **遊休資産**                 | 使われていない部屋・車・駐車場・時間                                           |
| **スポットワーク**           | 数時間単位の単発の仕事。多くは雇用契約を伴う                                   |
| **労働者性**                 | 実態として労働法の保護を受けるべきかの判断 → [詳しくは③](03_規制と社会受容.md) |
| **ゼロ日条例**               | 民泊の営業可能日数を条例でゼロにし実質禁止すること                             |
| **日本版ライドシェア**       | 自家用車活用事業。タクシー事業者が運行主体となる限定解禁                       |
