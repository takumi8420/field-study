マッチングの難しさ

情報通信・IT・ネットマッチング・シェアリング

このノートで分かること：マッチング・シェアリング事業が「サイトを作れば終わり」ではない理由。
自分の在庫を持たないのに需給を合わせ続けなければならないという、この商売固有の苦しさを分解する。

両面市場・ネットワーク効果・テイクレートといったプラットフォーム経済学の一般論は
プラットフォームの経済学 に委譲する。
ここでは「物やサービスを実際に受け渡す（＝現実世界に足が生えている）マッチング」に固有の論点だけを扱う。

1. 結論：在庫を持たない商売が、在庫商売より需給調整に苦しむ

普通の小売は、売れ残りのリスクを負う代わりに在庫を自分で動かせる。
足りなければ仕入れ、余れば値下げする。マッチング事業者にはそれができない。

在庫を持つ商売（小売・レンタル） マッチング（場を貸す商売）
商品の所有者自分他人（出品者・ホスト・ワーカー）
足りないとき仕入れるお願いする／報酬を上げる／広告を打つ
余ったとき値下げ・廃棄供給側が勝手に辞める（離脱）
品質自分で担保ばらつく。事故は自分の責任にされる
粗利売価−原価（20〜40%が普通）手数料（取引額の3〜35%）。原価はほぼゼロ
損益分岐在庫回転取引が成立した数

ポイント：粗利率は極端に高いが、売上のもとになる「取引成立数」を自分で作れない。
これがマッチング事業の全ての難しさの出発点である。

在庫を持たないので固定費は軽い。だから「儲かりそう」に見える。
しかし実際には、供給側を集める費用・信頼を作る費用・トラブル対応の費用が
在庫リスクの代わりに乗ってくる。在庫リスクが「オペレーションの重さ」に化けると考えるとよい。

2. 見るべきは会員数ではなく「流動性」

この業界で唯一重要な指標は流動性（リクイディティ）＝探しに来た人が、まともな時間内に
納得する相手を見つけられる確率である。会員数は流動性の代理指標にすぎない。

  • マッチ率：タクシー配車なら「配車依頼に対して車が付いた割合」。日本版ライドシェアの

時間帯・地域・条件が一致したときだけ取引は成立するので、細かく割ると常にどこかが枯れている。

3. 地域ごとに市場を作り直す──都市単位の勝負

SNSや検索は、世界中のユーザーが1つの巨大な市場を作る。
ところが物理的な受け渡しを伴うマッチングは、ネットワーク効果が地理的に切れている。

 【SNS型】ネットワーク効果が全体に効く      【ローカル・マッチング型】

    ┌─────────────────────┐           ┌────┐ ┌────┐ ┌────┐
    │    1つの巨大な市場     │           │東京 │ │大阪 │ │札幌 │
    │  ユーザーが増えるほど   │           │ 厚い │ │ 中位 │ │ 薄い │
    │  全員の価値が上がる     │           └────┘ └────┘ └────┘
    └─────────────────────┘             ↑ 各都市で別々に
       ＝世界で1〜2社が勝つ                 鶏と卵を解き直す
                                          ＝都市ごとに勝敗が分かれる

意味するところは3つ。

  1. 全国展開＝同じ苦労の繰り返し。東京で黒字でも、地方都市は白紙から始まる
  2. 地方は永久に薄いことが多い。人口密度が閾値を下回ると、
    どれだけ広告を打っても待ち時間が縮まらない
  3. 局地戦では後発でも勝てる。だからライドシェアやデリバリーは
    都市ごとの補助金・クーポン合戦（＝キャッシュバーン）になりやすい

例外はフリマ・スキル販売・オンライン完結の仕事。配送や通信が距離を吸収するので、
全国（さらに越境）が1つの市場になる。メルカリの越境取引GMVが
2026年6月期に1,122億円（Marketplace GMVの約9%、同社IR）まで伸びたのはこの型だからである。

4. 鶏と卵：現実に使われている6つの解き方

「客がいないから出品者が来ない／出品者がいないから客が来ない」問題。
教科書的な議論は プラットフォームの経済学 に譲り、
ここでは実務で実際に採られた手を並べる。

解き方 中身 実例のイメージ 副作用
① 極端に狭く始める1都市・1カテゴリ・1大学に絞る配車は都心の一部エリアから成長が遅く見え、資金調達が難しい
② 供給を自前で持つ（ハイブリッド）事業者が車・部屋・人を用意し、後から個人に置換カーシェア、法人ホスト在庫リスクを負うので本来の軽さを失う
③ 既存の在庫を取り込む既存事業者（タクシー会社、不動産会社、掲載中の駐車場）を一括接続駐車場シェア、宿泊既存業界との利害調整、値崩れ懸念
④ 片面に金を配る供給側に最低保証・紹介料、需要側にクーポン配車・デリバリーの初期補助が切れると両方消える
⑤ 単一面でも価値がある機能を先に出す出品前に「売れる価格」だけ見せる、空き情報だけ載せる相場検索、空室カレンダー収益化が遅れる
⑥ 既存の需要を横から借りる大手アプリ・ポイント経済圏・SNSに載せる経済圏連携、SNS経由送客手数料と主導権を相手に握られる

ポイント：②③は「軽い商売」を捨てて速さを買う選択。
シェアリングの成功例の多くは、純粋なC2Cではなく②③の混合に落ち着いている。

5. 信頼をどう作るか──4つの層

見知らぬ他人に、家の鍵を渡し、車に乗せ、前払いする。これを成立させる仕掛けは4層ある。

  ┌──────────────────────────────────────────────┐
  │ 第4層：保険・補償   事故が起きた後に金で埋める      │
  │        （ホスト保険、配送時の補償、自動車保険特約）  │
  ├──────────────────────────────────────────────┤
  │ 第3層：エスクロー   代金を事業者が預かり、完了で解放 │
  │        （＝持ち逃げの不可能化。資金決済法が絡む）    │
  ├──────────────────────────────────────────────┤
  │ 第2層：本人確認     eKYC、マイナンバーカード、銀行口座 │
  │        （＝逃げられない・再登録できない状態を作る）  │
  ├──────────────────────────────────────────────┤
  │ 第1層：評価・レビュー  過去の行動を可視化            │
  │        （安いが、偽装・報復・評価インフレに弱い）    │
  └──────────────────────────────────────────────┘
  • 第1層だけでは足りない。レビューは「良い人が良い評価を得る」のではなく
    「悪い評価を恐れて双方が甘く付ける」方向に歪む（評価インフレ）
  • 第2層はコストが上がる方向に制度が動いている。日本では
    公的個人認証（JPKI／マイナンバーカード読み取り）への一本化が進みつつあり、
    免許証画像などの簡易な確認は段階的に使えなくなる見通し（2026年時点の報道ベース）
  • 第3層は事業者に資金を滞留させる。預かり金の扱い次第で資金移動業の登録が必要になる
    → 規制と社会受容
  • 第4層は原価。取引額の1〜3%が補償・保険・カスタマーサポートに消える設計が珍しくない

ポイント：信頼は固定費ではなく変動費として効いてくる。
取引が増えるほどトラブルも比例して増えるので、「規模が出れば利益率が上がる」は
マッチングでは自動的には成立しない。

6. 手数料の決め方：テイクレートと「場外取引」

手数料率（テイクレート）の水準は、事業者がどこまで取引を握っているかでほぼ決まる。

型 テイクレート目安 事業者が握っているもの 例
掲載課金・サブスク実質数%出会いの場だけ恋愛マッチング（定額課金）、求人広告
決済を握る物販10%前後決済＋配送＋補償フリマアプリ（メルカリの販売手数料は10%、同社公表）
宿泊仲介合計で10%台予約・決済・レビュー民泊仲介（Airbnbの実質テイクレートは2026年Q2で13.2%、同社IR）
人の時間を売る20〜35%募集・勤怠・支払い・保険クラウドソーシング、スキマバイト
配車・配送総取引額の20〜30%相当価格決定・配車・保険・決済配車アプリ（Uberの非GAAP営業利益は総取扱高の3.7%、2026年Q2）

最大の敵は「場外取引（disintermediation）」。
一度出会った両者が、次回から直接やり取りして手数料を回避する行動である。

  1回目：  利用者 ──▶【プラットフォーム】──▶ 提供者   手数料あり
                         （決済・保険・保証）

  2回目：  利用者 ──────── LINE・現金 ────────▶ 提供者   手数料ゼロ
                    ▲ ここを塞げるかが収益の分かれ目

塞ぎ方は限られている。

  • 決済と補償を手放さない（場外に出た瞬間に保証が消える設計）
  • 毎回「探す」必要があるものを選ぶ（単発・不定期・相手が毎回違う仕事ほど強い）
  • 相手が事業者で、継続反復の関係が前提の領域は弱い（家事代行・習い事・専門職の紹介）

ポイント：リピートが強い領域ほど場外取引に抜けやすいという逆説がある。
だからマッチングは「毎回違う相手と、単発で、決済を伴って出会う」領域に利益が集まる。

7. ユニットエコノミクス：なぜ多くが赤字のまま終わったか

1取引あたりで見ると数字は小さい。ここに広告費と信頼コストが乗る。

  取引額 10,000円（例：スペース・スキル系の中間的な想定）
   ├ 手数料 20% ................ 2,000円   ← これが売上
   │   ├ 決済手数料 3%相当 ....... 300円
   │   ├ 補償・CS・不正対応 ....... 200〜400円
   │   └ 粗利 ................. 1,300〜1,500円
   └ 提供者の取り分 ........... 8,000円

  新規利用者の獲得費用（CAC）が 5,000円なら、
  粗利1,400円 × 4回以上リピートして初めて回収できる。
        ▲ 年1回しか使わないサービスは、構造的に黒字化しない

この単純な算数が、シェアリングの成否をほぼ説明する。

うまくいきやすい条件 うまくいきにくい条件
利用頻度が高い（週次・月次）年1〜2回（引っ越し、結婚、リフォーム）
決済がアプリ内で完結する現金・現地精算が残る
供給が「遊休資産」で追加コストがほぼゼロ供給者が人手で、毎回人件費が発生する
1回の単価が数千円以上単価が数百円（手数料が固定費に負ける）
相手が毎回変わる同じ相手に固定される（＝場外化）

8. 壊れ方の型

  • 供給の質が落ちる：報酬を下げると良い供給者から抜け、平均品質が落ち、需要が減る
  • 不正が閾値を超える：詐欺・盗品・なりすましが目立つと、対策コストが粗利を食い潰す
  • 地域が薄いまま広げる：全国展開の広告費だけ先に出ていき、どの都市も流動性に届かない
  • 規制で前提が変わる：営業日数の上限、業法適用、労働者性の認定で単価と供給量が一夜で変わる
    → 規制と社会受容
  • 経済圏に吸収される：単独では獲得費用が出ず、大手のアプリ内機能に置き換わる
