# 規制と社会受容

このノートで分かること：マッチング・シェアリングが**必ず既存の業法にぶつかる理由**と、
日本でそれがどう決着してきたか。民泊・ライドシェア・ギグワーカーの労働者性・古物営業法・
資金決済法・事故時の責任を順に見る。

> プラットフォーム一般の競争法・表現規制（スマホ新法、情プラ法、DMA／DSA）は
> [規制と社会的論点](../09_プラットフォーム・SNS/03_規制と社会的論点.md) に委譲する。
> ここで扱うのは**「現実世界の行為を仲介するがゆえに、個別の業法に当たる」問題**である。

## 1. なぜ必ず既存業法にぶつかるのか

日本の業法は「**事業としてやるなら許可を取れ**」という形で作られている。
プラットフォームは「個人が、たまたま、余っているものを」という顔で始まるので、
**その個人が事業者なのかどうか**が最初の争点になる。

```
  【同じ行為でも、誰がやるかで適用法が変わる】

   人を車に乗せて金を取る
     ├ タクシー会社が二種免許の運転手で ──▶ 道路運送法：許可あり（合法）
     └ 個人が自家用車で ────────────▶ 道路運送法78条：原則禁止（白タク）

   部屋に人を泊めて金を取る
     ├ ホテル・旅館 ─────────────▶ 旅館業法：許可
     └ 個人が住宅で ────────────▶ 住宅宿泊事業法：届出＋年180日上限

   人に仕事をさせて金を払う
     ├ 雇う ──────────────────▶ 労働基準法・労災・社会保険
     └ 外注する ──────────────▶ 民法の請負・委任＋フリーランス法
                                   ▲ ここの線引きが「労働者性」問題
```

> ポイント：**プラットフォームは「場を貸しただけ」と主張したがり、規制当局は
> 「実態として事業を支配している」と見たがる。** この綱引きが全領域で繰り返されている。

## 2. 民泊：解禁から「整理」の局面へ

### 2-1. 制度の骨格

| 制度                           | 根拠           | 中身                                                                  |
| ------------------------------ | -------------- | --------------------------------------------------------------------- |
| 旅館業法（簡易宿所）           | 旅館業法       | 許可制。日数制限なし。フロント・構造要件が重い                        |
| **住宅宿泊事業法（民泊新法）** | 2018年6月施行  | **届出制。年間営業日数の上限180日**。仲介事業者は観光庁への登録が必要 |
| 特区民泊                       | 国家戦略特区法 | 認定制。最低宿泊日数の要件あり。大阪市などで活用                      |

民泊新法の肝は2点。**①届出で始められる軽さ**と、**②自治体が条例で上乗せ規制できること**。
この②が、2020年代後半に効いてくる。

### 2-2. 現状の数字（2026年時点）

- 届出は累計63,658件、うち廃止を除いた稼働中の届出住宅は40,745件（観光庁、2026年5月時点）
- **累計の3分の1以上が既に廃業している**点が実態を物語る。180日上限では
  投資回収が難しく、参入と撤退が激しい

### 2-3. 2026年の転換：条例による実質禁止を容認

観光庁は2026年6月、**自治体が条例で営業可能日数を「ゼロ日」に設定すること（＝実質的な営業禁止）を
容認する通知を出す方針**を示したと報じられた。従来は「法の目的を逸脱する」として認めてこなかった
運用の転換である。背景は騒音・ごみ出し・近隣トラブルの増加で、
新宿区の苦情件数は2021年度70件から2025年度924件に増えたと報じられている。

```
  【民泊規制の振り子】

  2018 民泊新法施行 ──▶ 2020-22 コロナで壊滅 ──▶ 2023-25 インバウンドで回復
        （解禁）                （需要消滅）            （供給再拡大）
                                                          │
                                        2026 自治体が条例で実質禁止可へ
                                             （社会受容の限界が先に来た）
```

> ポイント：**シェアリングの規制は、経済合理性ではなく「近所の人が我慢できるか」で決まる。**
> これが「社会受容」という論点の実体である。

## 3. ライドシェア：部分解禁で止まっている

### 3-1. 何が禁止されているのか

道路運送法78条により、**自家用車で有償の旅客運送をすること（いわゆる白タク）は原則禁止**。
例外は3つに整理される。

| 類型                                       | 開始                   | 運行主体                                              | 条件                                                                                                                   |
| ------------------------------------------ | ---------------------- | ----------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| **日本版ライドシェア**（自家用車活用事業） | 2024年4月              | **タクシー事業者**                                    | 車両不足が生じる地域・時間帯・台数を国が算定。運転手は一種免許可、タクシー事業者が教育・運行管理・車両整備の責任を持つ |
| **公共ライドシェア**（自家用有償旅客運送） | 従来制度を2024年に拡充 | 市町村・NPO等（2025年からは都道府県や第三セクターも） | 交通空白地の移動確保が目的                                                                                             |
| 一般のライドシェア                         | **未解禁**             | —                                                     | プラットフォーム事業者が直接運行主体になる形は認められていない                                                         |

### 3-2. 全面解禁は繰り返し先送りされている

2026年6月に政府の規制改革推進会議がまとめた答申では、
**タクシー事業者以外がライドシェア事業を行えるようにする法整備は見送られ**、
「諸外国の事例及び各地域のニーズを踏まえ、必要な取組を進める」という記述にとどまったと報じられた。
国交省とタクシー業界側は一貫して慎重、全国知事会などは新法制定を要望しており、
**構図は「地方の移動手段不足」対「既存事業者の保護と安全責任」**で固定されている。

```
  【日本版ライドシェアの構造】

   利用者 ──配車アプリ──▶ ┌────────────────┐ ──▶ 一般ドライバー
                          │ タクシー事業者    │      （自家用車・一種免許）
                          │ ＝運行管理・整備  │
                          │   ＝事故の責任主体 │
                          └────────────────┘
                     ▲ ここに事業者が挟まるため、
                       プラットフォーム単独での価格決定・供給拡大ができない
```

> ポイント：**日本は「責任を取る事業者を必ず挟む」という形で決着させた。**
> 安全と既存産業は守られるが、供給を柔軟に増やすという本来の利点は大きく削られている。

## 4. 労働者性：ギグワーカーは従業員か

最大の未決着問題。プラットフォームが**指揮命令をしているとみなされれば、
働き手は「労働者」**となり、最低賃金・労災・社会保険の義務が発生する。

### 4-1. 日本の現在地

| 制度                                                             | 時期           | 中身                                                                                                                                                                                 |
| ---------------------------------------------------------------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| フリーランス法（特定受託事業者に係る取引の適正化等に関する法律） | 2024年11月施行 | 取引条件の書面明示、60日以内の報酬支払、募集情報の的確表示、ハラスメント対策など。**「労働者」と認めるものではなく、取引の適正化に限った法律**                                       |
| 労働基準関係法制研究会など                                       | 2023年〜       | 「労働者」の判断基準（労働者性）の見直しを議論。アプリによる間接的な指示、経済的従属性をどう評価するかが論点                                                                         |
| スポットワークへの行政対応                                       | 2024年〜       | 厚労省が留意事項リーフレットを作成し、スポットワーク協会経由で周知を要請。無断欠勤者への紹介を無期限停止した運用が職業安定法違反にあたるとして改善指導が行われた事例が報じられている |

### 4-2. 2つの型を混同しない

```
  ① スポットワーク（タイミー等）
     働き手 ──雇用契約──▶ 利用企業     ← 労働基準法が最初から適用される
              ▲
        プラットフォーム＝職業紹介・募集の仲介（職業安定法の世界）

  ② ギグワーク（配達・業務委託）
     働き手 ──業務委託──▶ プラットフォーム or 発注者
              ▲ 労働者ではない建前。ここで労働者性が争われる
                （フリーランス法は保護するが、労働者にはしない）
```

EUでは2024年にプラットフォーム労働指令が成立し、**一定の要件を満たせば雇用と推定する**
（推定を覆す立証責任を事業者側に置く）方向に進んでいる。日本はまだその段階にない。

> ポイント：**労働者性が認められると、テイクレート30%のビジネスは成立しなくなる。**
> 社会保険料と最低賃金の負担が乗るためで、この論点は事業モデルの生死に直結する。
> → [HRテック・人材系ネットサービス](../15_HRテック・人材系ネットサービス/README.md)

## 5. 古物営業法：中古品を「業として」売買するとき

- **古物商許可**が必要になるのは「利益を出す目的で中古品を反復継続して売買する」場合。
  自宅の不用品を売るだけなら不要
- 古物商は原則として**相手方の本人確認**が必要（対価1万円未満の買受けなど例外あり）。
  ところが**フリマアプリでは相手の身元が分からない**ため、
  「アプリ仕入れは古物営業法の本人確認義務を履行できない」という指摘が実務上続いている
- 盗品対策も論点。メルカリは2026年7月、警察庁と不正取引に関する情報共有の協定を締結したと公表しており、
  **プラットフォーム側が捜査協力の窓口として制度に組み込まれる**流れが進んでいる

## 6. 資金決済法：代金を預かった瞬間に金融になる

エスクロー（代金の一時預かり）は信頼の要だが、**預かり方を誤ると無許可の為替取引**になる。

| 形                                 | 位置づけ                                                                               |
| ---------------------------------- | -------------------------------------------------------------------------------------- |
| 収納代行（売り手の代理として受領） | 一定の整理のもとで登録不要とされてきたが、個人間送金に近い形態は規制対象化の議論が続く |
| 資金移動業の登録                   | 送金・残高保有を行う場合に必要。第一種〜第三種で上限額と規制の重さが異なる             |
| 前払式支払手段（アプリ内ポイント） | 発行保証金の供託義務などが生じる                                                       |

売上金をアプリ内に残す設計は収益上強力だが、その瞬間に金融規制の世界に入る。

## 7. 事故・トラブル時の責任

「場を貸しただけ」で逃げ切れる範囲は、年々狭くなっている。

| 論点                   | 現実の落としどころ                                                                           |
| ---------------------- | -------------------------------------------------------------------------------------------- |
| 物損・人身事故         | 事業者が保険を用意するのが事実上の標準。民泊ホスト保険、配達員向け補償、カーシェアの車両保険 |
| 商品の瑕疵・偽物       | 事業者独自の補償制度。返金原資は手数料収入から出る＝実質的に原価                             |
| 詐欺・盗品             | 本人確認の強化、捜査機関との連携、アカウント停止                                             |
| 提供者の急なキャンセル | ペナルティと代替手配。供給側を締めすぎると離脱するというジレンマ                             |
| 近隣への迷惑           | **法的責任ではなく社会受容の問題**。ここで潰されるサービスが最も多い                         |

```
  【責任の押し付け合いの構図】

   利用者：「アプリで頼んだのだから、アプリが責任を取れ」
     ▲
   プラットフォーム：「当事者間の契約であり、当社は場の提供者」
     ▼
   提供者（個人）：「支払い能力も保険もない」

     ── この三角形の空白を埋めるために、
        事業者が保険・補償を自腹で用意する構造になっている
```

## 8. 社会受容という最後の関門

規制をクリアしても、**周囲が受け入れなければ事業は続かない**。
日本のシェアリングが期待ほど広がらなかった要因として、繰り返し挙げられるのは次の3点。

1. **匿名の他人への警戒**：他人を家に入れる・他人の車に乗ることへの心理的抵抗が相対的に強い
2. **既存産業の雇用と安全責任**：タクシー・旅館・人材派遣といった、免許と責任で成り立つ産業との衝突
3. **迷惑の可視化**：SNSと自治体の苦情窓口を通じて、トラブルが即座に政治問題化する

> 結論：**この業界の規制は「解禁 → 拡大 → 迷惑の顕在化 → 再規制」というサイクルを描く。**
> 民泊はすでに3周目に入っており、スポットワークは今まさに2周目から3周目へ進みつつある。

## 用語メモ

| 用語                           | 意味                                                                           |
| ------------------------------ | ------------------------------------------------------------------------------ |
| **白タク**                     | 自家用車（白ナンバー）で有償運送すること。道路運送法78条で原則禁止             |
| **住宅宿泊事業法（民泊新法）** | 2018年施行。届出制で住宅に人を泊められるが、年180日が上限                      |
| **上乗せ条例**                 | 自治体が法律より厳しい制限を条例で課すこと。民泊規制の主戦場                   |
| **日本版ライドシェア**         | 自家用車活用事業。タクシー事業者が運行主体となる限定解禁                       |
| **公共ライドシェア**           | 自家用有償旅客運送。市町村やNPOが担う交通空白地向けの制度                      |
| **労働者性**                   | 実態として指揮命令下にあり、労働法の保護を受けるべきかの判断                   |
| **フリーランス法**             | 2024年11月施行。取引条件の明示や支払期日を義務づける。雇用とみなす法律ではない |
| **古物商許可**                 | 中古品を業として売買するのに必要な公安委員会の許可                             |
| **資金移動業**                 | 為替取引（送金）を行う事業者の登録制度。エスクロー設計に直結する               |
| **社会受容**                   | 法的に適法でも、周囲の住民・世論が受け入れるかという問題                       |
