# プレイヤーの類型 ── 出自で顧客基盤が決まる業界

このノートで分かること：日本のSIerを**メーカー系・ユーザー系・独立系・外資コンサル系**の4類型で捉える見方、
それぞれの顧客基盤がなぜ固定的なのか、各社の強みがどこから来ているのか。

## 1. 結論：SIerは「どこから生まれたか」で今も食い扶持が決まっている

日本のSIerは、ほとんどが**別の商売の副産物として生まれた**。
ハードを売るために技術者を抱えたメーカー、親会社のシステムを作るために分社した情報子会社、
ソフト開発だけで創業した独立系、そして経営コンサルから実装まで降りてきた外資。
**出自が違うと、入り口にできる顧客も、得意な工程も、利益率も違う。**

```
 【出自】                        【今の商売】                      【顧客基盤】

 コンピュータメーカー ─────▶ メーカー系SIer ─────────▶ 官公庁・大企業の基幹系
  富士通/NEC/日立               ハード＋SI＋保守               （納入実績で固定化）

 事業会社の情シス部門 ─────▶ ユーザー系SIer ─────────▶ 親会社＋同業種の他社
  NTTデータ/NRI/伊藤忠テクノ    業務知識＋SI                   （業種特化で横展開）

 ソフト会社として創業 ─────▶ 独立系SIer ─────────────▶ 特定の顧客に依存しない
  大塚商会/SCSK/BIPROGY         中立性＋製品・サービス          （中堅企業〜大企業）

 戦略コンサル／会計事務所 ──▶ 外資コンサル系 ────────▶ 大企業の経営層
  アクセンチュア/デロイト等     構想〜実装の一気通貫           （予算の出どころが違う）
```

## 2. 4類型の比較表

| 類型               | 代表企業                                                                                  | 強み                                                         | 弱み                                       | 典型的な入り口                 |
| ------------------ | ----------------------------------------------------------------------------------------- | ------------------------------------------------------------ | ------------------------------------------ | ------------------------------ |
| **メーカー系**     | 富士通、NEC、日立製作所                                                                   | 大規模案件の実行力、官公庁との関係、全国の拠点網、自社ハード | 自社製品に引っ張られる。事業が重い         | ハード更改・大型入札           |
| **ユーザー系**     | NTTデータ、野村総合研究所（NRI）、伊藤忠テクノソリューションズ（CTC）、SCSK（住友商事系） | 特定業種の業務知識、親会社グループの安定需要                 | 親会社依存。業種が傾くと一緒に傾く         | 親会社・同業種の業務システム   |
| **独立系**         | 大塚商会、BIPROGY（旧日本ユニシス）、TIS、DTS、SCSK（独立系寄り）                         | 特定メーカーに縛られない製品選定、中堅企業への面             | 大型案件での信用力・資金力で劣る場合がある | 業務課題からの提案             |
| **外資コンサル系** | アクセンチュア、デロイト トーマツ、PwC、IBM（コンサル＋GBS）                              | 経営層への提案力、グローバル事例、上流の単価の高さ           | 実装要員は国内SIerに外注することも多い     | 経営課題・全社変革プロジェクト |

※ SCSKや伊藤忠テクノは商社系で「ユーザー系」に分類されることも「独立系」に分類されることもある。
分類は絶対ではなく、**顧客基盤がどこから来ているかを見るための道具**として使う。

## 3. メーカー系 ── ハードが減っても、案件は残る

**富士通・NEC・日立製作所**の3社は、かつて国産メインフレームを作っていたメーカーである。

| 観点       | 中身                                                                                                                                                   |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 顧客       | 中央省庁、自治体、金融、通信、電力、大手製造業。**数十年単位の納入実績**で関係が固定                                                                   |
| 商流       | 自社が元請け（プライム）。実装は系列子会社＋数百社の協力会社                                                                                           |
| 収益構造   | ハード＋ソフト＋保守の一体。近年はハード比率が下がりサービス比率が上昇                                                                                 |
| 直近の動き | 2026年3月期は3社とも増益基調。NECの売上収益3兆5,827億円・営業利益3,599億円が富士通（3兆5,029億円・3,483億円）を上回った（日経クロステック、2026年5月） |

- 日立は鉄道・電力などの**社会インフラ＋IT（Lumada）**へ寄せ、富士通は非中核事業の切り離しを進めてきた
- ハードウェア事業の縮小は売上を削るが、**保守と運用の顧客基盤は残る**。ここが次の更改案件の源泉
- 官公庁の大型システムは、要件の複雑さと責任の重さから**事実上この3社＋NTTデータしか受けられない**案件が多い
- 総合電機としての側面は [総合電機](../../03_電機・電子部品/01_総合電機/README.md) も参照

## 4. ユーザー系 ── 親会社の業務知識が資産

事業会社の情報システム部門が分社してできた会社。**業務を知っていることが最大の参入障壁**になる。

| 企業                                    | 出自                                | 主戦場                                                                                   |
| --------------------------------------- | ----------------------------------- | ---------------------------------------------------------------------------------------- |
| **NTTデータグループ**                   | 日本電信電話公社のデータ通信本部    | 官公庁、金融（全銀システム、地銀共同センター）、海外。2026年3月期売上5兆46億円で国内最大 |
| **野村総合研究所（NRI）**               | 野村證券の調査部門＋システム部門    | 証券・保険の共同利用型システム、コンサルティング。**シンクタンク機能を持つ**             |
| **伊藤忠テクノソリューションズ（CTC）** | 伊藤忠商事系                        | 通信キャリア、製造、流通。海外製品の目利きと導入                                         |
| **SCSK**                                | 住友商事系（住商情報システム＋CSK） | 製造、金融、自動車。ERP・保守運用                                                        |
| **日鉄ソリューションズ**                | 日本製鉄の情報システム部門          | 鉄鋼・製造業の生産管理、金融                                                             |

- 強みは**業種の深い知識**。銀行の勘定系、証券の売買システム、保険の契約管理は業務を知らないと作れない
- 一度作ると**共同利用型サービス**（複数の地銀・証券会社で同じ基盤を使う）に発展でき、ストック収益になる
  → [メガバンク](../../05_金融/01_メガバンク/README.md)、[地方銀行](../../05_金融/02_地方銀行/README.md)
- 弱みは**親会社・特定業種への依存**。NRIは海外展開でつまずき、2026年3月期に1,000億円近い減損を計上した

## 5. 独立系 ── 中立であることが売り物

特定のメーカー・親会社に属さない会社。**製品を自由に選べる**ことと、
中堅企業まで含めた面の広さが武器になる。

| 企業                | 特徴                                                                                             |
| ------------------- | ------------------------------------------------------------------------------------------------ |
| **大塚商会**        | 中堅・中小企業向け。複合機・PCの販売から入り、保守・運用でストックを積む「たのめーる」等の物販も |
| **BIPROGY**         | 旧日本ユニシス。金融・流通の基幹系に強い。ハード販売依存から脱却しサービス比率を上げてきた       |
| **TIS**             | 決済・カード系に強い。2026年3月期は売上5,964億円・営業利益率約12.8%と**大手の中で最も高い水準**  |
| **DTS、SHIFT ほか** | DTSは受託開発中心。SHIFTはソフトウェアテストという工程特化で伸びた                               |

- **工程特化**（テスト、品質保証、インフラ構築）で独自の立ち位置を作るのは独立系の定石
- 中堅企業市場は大手が採算に乗せにくく、**独立系の主戦場**になっている
- SaaSの再販や自社プロダクトを持つ会社も増えている → [ソフトウェア・SaaS](../06_ソフトウェア・SaaS/README.md)

## 6. 外資コンサル系 ── 上流から降りてくる競合

アクセンチュア、デロイト トーマツ コンサルティング、PwCコンサルティング、IBM。
もともと戦略・業務コンサルだった会社が、**実装まで引き受ける**ようになった。

```
  【従来の分業】
   戦略コンサル ──▶ 構想・要件定義  ｜  SIer ──▶ 設計・開発・運用
        高単価（月300万円〜）        ｜      （月80〜120万円）
                                     ▲
                        この境界線が2010年代以降なくなった

  【現在】
   外資コンサル系 ──▶ 構想 ─ 要件定義 ─ 設計 ─ 開発 ─ 運用 まで一気通貫
                                            │
                                            └─ 実装要員は国内SIerや
                                               オフショアに外注することも多い
```

| 観点           | 外資コンサル系                            | 国内SIer                                 |
| -------------- | ----------------------------------------- | ---------------------------------------- |
| 予算の出どころ | 経営企画・事業部門（**IT予算の外**）      | 情報システム部門のIT予算                 |
| 提案の入り口   | 経営課題（成長戦略、コスト削減、M&A統合） | システム課題（老朽化、更改、法改正対応） |
| 単価           | 上流コンサルは月200〜400万円（推計）      | 上流SEでも月100〜150万円                 |
| 人の流れ       | 国内SIerから中途採用で大量に引き抜く      | 引き抜かれる側                           |

**この競合は単価の問題として効く**。同じ人材を外資が高い給与で採るので、
国内SIerは人件費を上げざるを得ず、しかし単価転嫁は追いつかない。
→ [コンサルティング](../../15_サービス・生活関連/04_コンサルティング/README.md)

## 7. その他の層

| 層                           | 役割                                                                                     |
| ---------------------------- | ---------------------------------------------------------------------------------------- |
| **ユーザー企業の情報子会社** | 親会社専属。外販が少なく、実質的に親会社の情シス部門（例：各メガバンクのシステム子会社） |
| **SES専業**                  | 技術者を客先に出すことに特化。数十〜数百人規模の会社が数千社ある                         |
| **オフショア／ニアショア**   | 中国・ベトナム・インドの開発拠点、国内地方拠点。コスト差で受注                           |
| **クラウドインテグレーター** | AWS/Azure特化。サーバーワークスなど。従来SIerとは技術スタックが違う                      |
| **Webシステム開発会社**      | スタートアップ・自社サービス向け。アジャイル・内製支援型                                 |

## 9. 顧客基盤はなぜ動かないのか

| 固定化の要因           | 説明                                                                     |
| ---------------------- | ------------------------------------------------------------------------ |
| **ブラックボックス化** | 20年動いているシステムの仕様書が古く、作った会社しか中身を知らない       |
| **保守契約**           | 保守を持つ会社が障害も法改正も対応する。切り替えのリスクが大きすぎる     |
| **入札の実績要件**     | 官公庁案件では「同規模の類似実績」が要件に入り、新規参入が難しい         |
| **人の関係**           | 常駐しているSEが顧客の業務を熟知し、事実上の社員のようになっている       |
| **責任の引受け手**     | 障害で業務が止まったとき、賠償と復旧を引き受けられる体力の会社は限られる |

> ポイント：この業界の参入障壁は技術ではなく、**「既に動いているものを知っていること」と「失敗したときに責任を取れる規模」**。
> だから新興企業が大型基幹系に入るのは極めて難しい。

## 用語メモ

| 用語                                 | 意味                                                                           |
| ------------------------------------ | ------------------------------------------------------------------------------ |
| **プライム（元請け）**               | 顧客と直接契約し全体責任を負う立場。単価も利益も最も高い                       |
| **メーカー系SIer**                   | コンピュータメーカー出身のSIer。富士通・NEC・日立が代表                        |
| **ユーザー系SIer**                   | 事業会社の情報システム部門が分社してできたSIer。業務知識が資産                 |
| **独立系SIer**                       | 特定メーカー・親会社に属さないSIer。製品選定が中立                             |
| **情報子会社**                       | 事業会社が自社システムのために持つ子会社。外販比率が低い                       |
| **共同利用型システム**               | 複数の顧客が同じ基盤を共同で使う形態。地銀共同センターが典型                   |
| **基幹系（ミッションクリティカル）** | 止まると業務が止まるシステム。勘定系、生産管理、販売管理など                   |
| **オフショア開発**                   | 海外拠点で開発すること。コスト差が動機だが、品質管理とコミュニケーションが課題 |
| **ニアショア**                       | 国内の地方拠点で開発すること。時差・言語の問題がない代わりに単価差は小さい     |
| **Lumada**                           | 日立が掲げるデータ利活用の事業ブランド。社会インフラとITの結合を指す           |
