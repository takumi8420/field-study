# 直近トピック（2026年9月時点）

報道・調査会社の公表資料をもとに整理した。一次情報（各社IR、官公庁発表）で裏取りできたものはそう明記し、
推計・報道ベースのものは区別して書いている。

## 1. 主要SIerの2026年3月期決算 ── 国内需要は堅調、利益率は10%前後に収束

2026年3月期は、国内のIT投資が堅調で各社おおむね好業績だった。
ただし**利益率は依然として10%前後**で、構造的な天井は動いていない（→ [儲け方とコスト構造](02_儲け方とコスト構造.md)）。

| 企業              | 売上高       | 営業利益  | 営業利益率 | 特記                                      |
| ----------------- | ------------ | --------- | ---------- | ----------------------------------------- |
| NTTデータグループ | 5兆46億円    | 4,882億円 | 約9.8%     | **売上高が初の5兆円超**。営業利益50.7%増  |
| NEC               | 3兆5,827億円 | 3,599億円 | 約10.0%    | 前期比5%増収、営業利益40%増               |
| 富士通            | 3兆5,029億円 | 3,483億円 | 約9.9%     | 1%減収だが営業利益31%増、純利益は約2倍    |
| 野村総合研究所    | 8,147億円    | 582億円   | 約7.1%     | 6.5%増収だが**海外減損で営業利益56.8%減** |
| TIS               | 5,964億円    | 762億円   | 約12.8%    | 主要社の中で最も高い利益率                |

※ NEC・富士通は非IT事業を含む全社数値。NTTデータは海外比率が高い。

**読み取りどころ**

```
   売上規模で見ると    NTTデータ ＞ NEC ≒ 富士通 ＞ NRI ＞ TIS
   利益率で見ると      TIS ＞ NEC ≒ NTTデータ ≒ 富士通 ＞ NRI

   → 規模と利益率は比例しない。国内特化で運用比率が高い会社のほうが利益率は高い
   → NECが売上収益・営業利益の両方で富士通を上回ったのは注目された（日経クロステック、2026年5月）
```

NRIの減益は、海外事業（豪州・米国のグループ会社）で1,000億円近い減損を計上したことによる。
**日本のSIerの海外展開の難しさ**を示す事例として受け止められている。

## 2. AI駆動開発が「PoC」から「本番」へ ── 各社が生産性目標を数字で出し始めた

2025年までは実証実験（PoC）中心だった生成AIの開発適用が、2026年は各社の中期戦略に**数値目標**として入った。

| 企業      | 打ち出している内容                                             |
| --------- | -------------------------------------------------------------- |
| TIS       | 2030年3月期までに**生産性50%向上**を目標に設定                 |
| NTTデータ | AIエージェント開発とAIプラットフォーム構築を成長戦略の柱に     |
| NRI       | 複雑な大規模システム向けの独自開発モデルを2030年度までに実用化 |
| 各社共通  | 人的リソースを**上流工程へシフト**する方針                     |

同時に、業界メディアでは「**生産性が上がるほど人月売上が減る**」という矛盾が繰り返し論じられている。
日経クロステックは、生産性を50%向上させれば顧客企業が大幅な値下げを要求するだろうと指摘し、
事業モデルの瓦解という強い表現を使っている（2026年、報道・論考ベース）。

```
   2024〜2025        2026                  2027〜
   ─────────────────────────────────────────────────▶
   PoC・試行        生産性目標を公表       契約モデルの見直し？
   個人が勝手に使う  組織的に導入          固定価格／成果報酬への移行が論点
                    ▲
             いまここ（2026年9月）
```

→ 論点の整理は [変化と論点](04_変化と論点.md)

## 3. 取適法（改正下請法）が2026年1月に施行 ── 多重下請けの商習慣に直接効く

**下請法が改正され、「中小受託取引適正化法（取適法）」として2026年1月1日に施行された。**
公正取引委員会・中小企業庁の公表資料による（一次情報）。

| 主な改正点                                   | SI・SES業界への影響                                      |
| -------------------------------------------- | -------------------------------------------------------- |
| **手形払い等の禁止**                         | 資金繰りの弱い2次・3次請けの負担が軽くなる               |
| **協議に応じない一方的な代金決定の禁止**     | 「単価は据え置き」と一方的に通告する行為が違法になりうる |
| **従業員数基準（300人・100人）の追加**       | 資本金を小さくして規制を逃れる形が塞がれた               |
| **振込手数料を受注者に負担させる行為の禁止** | 細かいが下請け側の実利に効く                             |
| 適用取引の拡大（運送委託の追加など）         | 業界横断の改正                                           |

加えて、フリーランス・事業者間取引適正化等法（2024年11月施行）の運用状況について、
公正取引委員会が2026年6月10日に令和7年度の運用状況を公表している（一次情報）。

**なぜこれがITで重い話になるのか**：ソフトウェア業は多重下請けが常態化しており、
公取委は2022年6月の実態調査報告書で、**商流に形式的に入るだけで実務を行わない「中抜き事業者」**を
問題として名指ししていた。取適法はその延長線上にある。
→ 構造の解説は [日本のIT産業の構造](01_日本のIT産業の構造.md)

業界内では「中抜き率の透明化圧力が高まり、エンド企業から**発注額と技術者への支払額の差**を
問われるケースが増えている」との指摘が出ている（事業者・メディアの発信ベース、2026年）。

## 5. SAP「2027年問題」の期限が1年半後に迫る

SAP ERP 6.0（ECC 6.0）の標準保守終了は**2027年末**。2026年9月時点で残り約1年3か月である。

| 論点             | 状況                                                                     |
| ---------------- | ------------------------------------------------------------------------ |
| 対象企業数       | 国内のSAP ERP導入企業は**約2,000社**とされる（報道・ベンダー資料ベース） |
| 移行の進捗       | 2024年時点で移行完了は**約6割**と報じられる（推計）                      |
| 支援可能ベンダー | 国内でS/4HANA移行を支援できるベンダーは**約100社程度**とされる（同）     |
| 2026年の状況     | 「2026年中に方針を確定させないと選択肢が狭まる」という論調が支配的       |
| リスク           | 駆け込みでベンダー・SAP人材の争奪が起き、**中堅企業が確保できなくなる**  |

```
   2026年9月（いま）      2027年末
   ─────┼────────────────┼──────▶
        │                │  標準保守終了
        │← 約1年3か月 →│
        │
   大企業の移行に必要な期間は2〜4年
   → いま未着手の大企業は、延長保守か他ERPかの二択に追い込まれる
```

SIer側から見れば**期限つきの大型特需**だが、2028年以降の反動減が構造的に見えている点が難しい。

## 6. エンジニア単価は上昇継続、AI関連は突出

2026年時点の相場観（事業者公表・各種調査をまとめたもの、いずれも**推計**）。

| レンジ                | 月額単価の目安                | 補足                                  |
| --------------------- | ----------------------------- | ------------------------------------- |
| 初級                  | 40万円〜                      | 未経験〜3年程度                       |
| 中堅                  | 60万円〜                      | 実務3〜5年                            |
| シニア                | 80万円〜                      | リーダー・設計担当                    |
| スペシャリスト        | 100万円〜                     | 専門領域を持つ                        |
| **AI/ML・LLM関連**    | **100万円超が標準化**         | 需要が前年比40%増との調査あり（推計） |
| クラウド（AWS認定等） | 2022年比で**平均20〜30%上昇** | 同上                                  |

- 一部では「130万円以上を提示しても高スキル人材が集まらない」という声も出ている（事業者の発信ベース）
- 単価上昇は元請けにとっては**原価インフレ**であり、顧客への転嫁が追いつかないと利益率が落ちる
- 取適法の施行で中間マージンに透明化の圧力がかかれば、**現場の技術者に届く金額**は増える方向に働く

## 7. 全体の構図（まとめ）

2026年のSIer業界は、**需要は強いが構造は揺れている**という状態にある。
国内IT投資はレガシー刷新・クラウド移行・SAP 2027年問題・AI投資に支えられて拡大基調で、
主要各社の決算も堅調だった。しかし利益率は相変わらず10%前後に張り付いたままで、
規模を大きくしても利益率が上がらないという人月モデルの天井は破れていない。

そこへ、①生成AIによる開発効率化（工数＝売上が減る）、②取適法による多重下請け取引の適正化
（中間マージンが削られる）、③ユーザー企業の内製化という3つの圧力が同時に来ている。
各社の回答は「上流シフト」と「AI駆動開発」で共通しているが、
**効率化の果実を値下げとして顧客に返すのか、利益として残すのか**という契約モデルの問題は
2026年9月時点でまだ答えが出ていない。ここが今後数年の最大の見どころになる。

## 用語メモ

| 用語                   | 意味                                                                         |
| ---------------------- | ---------------------------------------------------------------------------- |
| **DI（業況判断指数）** | 「増加」と答えた割合から「減少」と答えた割合を引いた値。プラスなら増加基調   |
| **取適法**             | 中小受託取引適正化法。2026年1月施行の改正下請法。手形払い禁止などを規定      |
| **減損**               | 買収した事業などの価値が下がったときに、帳簿価額を引き下げて損失計上すること |
| **AI駆動開発**         | 生成AIを設計・実装・テストに組み込んだ開発手法                               |
| **S/4HANA**            | SAPの後継ERP。2027年末の標準保守終了に伴う移行先の本命                       |
| **JISA**               | 一般社団法人 情報サービス産業協会。業界統計とDI調査を公表している            |
