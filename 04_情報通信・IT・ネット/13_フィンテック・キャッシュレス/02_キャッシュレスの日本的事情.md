# ② キャッシュレスの日本的事情

このノートで分かること：**なぜ日本だけ現金が強かったのか**、そして
**なぜ2019年以降になって急にキャッシュレスが伸びたのか**。数字と制度と経済合理性で説明する。

> **結論を先に**：日本の現金志向は「国民性」ではなく、
> **①現金を持っていても盗まれない治安、②どこでもタダ同然で現金が出るATM網、
> ③店にとって決済手数料が重すぎた**という3つの条件がそろっていたから。
> 2019年以降に伸びたのは、**国が税金でポイントを配り、事業者が赤字でポイントを配った**から。
> つまり**普及は「補助金で買われた」**のであり、その補助金が切れる局面が今。

---

## 1. 2025年時点の決済比率 ── 数字を正確に押さえる

経済産業省が2026年3月31日に公表した最新値。**この年から指標の定義が変わった**点に注意。

| 指標 | 2025年の値 | 意味 |
| --- | --- | --- |
| **キャッシュレス決済比率（新・国内指標）** | **58.0%** | 民間最終消費支出から、キャッシュレスになじまない項目（持家の帰属家賃など）を除いた分母で計算 |
| キャッシュレス決済比率（従来の国際比較指標） | **46.3%** | 民間最終消費支出をそのまま分母にした旧定義 |
| キャッシュレス決済額 | **162.7兆円** | 過去最高 |
| 政府目標 | 2030年までに**65%**、将来的に**80%**（いずれも新指標） | 「成長戦略フォローアップ」等の政府方針 |

**内訳（2025年、経産省）**

| 手段 | 金額 | 構成比 | 前年からの動き |
| --- | --- | --- | --- |
| **クレジットカード** | 134.6兆円 | **82.7%** | 依然として圧倒的。金額の8割以上はカード |
| **コード決済（QR）** | 16.6兆円 | 10.2% | 9.6% → 10.2% に拡大 |
| 電子マネー（Suica等） | 6.0兆円 | 3.7% | 4.4% → 3.7% に**縮小** |
| デビットカード | 5.5兆円 | 3.4% | 微増 |

```
【2025年 キャッシュレス162.7兆円の中身】

 クレジットカード 82.7% ████████████████████████████████████████▏
 コード決済       10.2% █████
 電子マネー        3.7% ██
 デビットカード    3.4% █▊

 ▲ 話題性はコード決済だが、金額のボリュームは圧倒的にクレジットカード。
   しかもコード決済の中身の多くは「登録したクレジットカードからの引落し」なので、
   実質的なカード経済圏はこの数字より大きい。
 ▲ 電子マネーが減っているのは、Suica等の少額用途をコード決済が食っているため。
```

> **押さえどころ**：「QR決済が日本を変えた」という語り口は半分しか正しくない。
> **変わったのは“少額の現金”がQRに置き換わった部分**で、
> 金額の主戦場は今もクレジットカードにある。

## 2. なぜ日本は現金が強かったのか ── 3つの構造的な理由

### 理由①：現金を持っていても損しない／取られない

現金流通高の名目GDP比は、日本が**約20%**（2015年末時点で19.4%）と世界的に突出している。
キャッシュレス先進国のスウェーデンの10倍規模という比較がよく使われる（報道ベース）。

| 現金を使う条件 | 日本 | 現金が廃れた国（北欧・中国など） |
| --- | --- | --- |
| 治安（現金を持ち歩くリスク） | 極めて良い。強盗・スリが少ない | 現金は盗まれる／強盗リスクが高い |
| 偽札 | ほぼ存在しない。券面の信頼が高い | 偽札問題が深刻だった（中国） |
| 金利 | **長らくゼロ金利**。現金で持っても機会損失が小さい | 金利があり、現金保有は損 |
| 銀行インフラ | 全国どこでも口座と支店 | 銀行口座を持てない層が多い（新興国） |

> **因果**：現金を持つコスト（盗難リスク・機会損失）がほぼゼロだったので、
> **わざわざ手数料を払ってキャッシュレスに乗り換える理由がなかった**。
> 一方、中国がQRで一気に飛んだのは、**カード網が未整備で偽札が多く、現金の方が不便だった**から。
> 日本は「現金がうまく機能しすぎていた」ことが、キャッシュレス後発の原因である。

### 理由②：ATM網が「実質無料の現金自販機」として機能していた

コンビニATMが全国に張り巡らされ、24時間いつでも現金が下ろせる。
自行ATM・提携時間帯なら手数料も無料か100円台。
**「現金の入手コストが世界一低い国」**が日本である。

ただし前提は崩れつつある。金融機関のATM・CD設置台数は2018年をピークに減少を続け、
2021年9月末で9万3,016台、ピーク（1999年、11万8,599台）から20%超の減少と報じられる。
2026年時点では**9万台割れが迫る**とされる（業界紙報道）。

```
【ATM網が縮むと何が起きるか】

  銀行：1台あたり年間数百万円の維持費（設置・警備・現金装填・回線）
         ↓ 店舗統廃合とともに削減へ
  ATMが減る ─▶ 現金の入手が不便に ─▶ キャッシュレスへ移行
         │
         └▶ 同時に「現金しか使えない高齢者・地方」が取り残される
             ＝金融包摂（ファイナンシャル・インクルージョン）の論点
```

> ただし現金需要そのものは根強く、コンビニATMの引出額はむしろ増えているという分析もある
> （三井住友信託銀行 調査月報 2026年2月号ほか）。**「ATMは減るが現金は減らない」**という
> ねじれが、日本の移行期の特徴になっている。

### 理由③：加盟店手数料が普及の最大の壁だった

ここが最も経済的な理由。**店から見れば、キャッシュレスは「売上の3%を失う制度」**でしかない。

| 業態 | 営業利益率の目安 | 決済手数料3.24%の意味 |
| --- | --- | --- |
| 食品スーパー | 2〜3% | **利益がまるごと吹き飛ぶ** |
| コンビニ（加盟店） | 数% | 同上 |
| 飲食（個人店） | 5〜10% | 利益の1/3〜半分が消える |
| ドラッグストア | 4〜6% | 利益の半分以上 |

> **だから日本の中小店は、長らく「現金のみ」で合理的だった**。
> 手数料を払っても客数が増えるなら得だが、**客が現金でも買ってくれる以上、
> 導入は純粋なコスト増**になる。これが普及を止めていた本質である。
> 手数料の中身の分解は [① 決済はどう流れ誰が取り分を得るか](01_決済はどう流れ誰が取り分を得るか.md) を参照。

一方で、キャッシュレスにすると**レジ締めの時間、釣銭準備、銀行への入金手数料、
現金紛失・盗難のリスク、売上金を運ぶ人件費**が減る。
人手不足と銀行の入金手数料引き上げが進んだ2020年代は、
**この「現金を扱うコスト」がようやく手数料と釣り合い始めた時期**でもある。

## 3. 普及の転換点 ── ポイント還元とキャンペーン合戦の経済

日本のキャッシュレス比率は2015年ごろ20%前後から、2025年に58%（新指標）まで伸びた。
その加速要因は**3回の「お金をばら撒くイベント」**でほぼ説明できる。

| 時期 | 出来事 | 誰が原資を出したか |
| --- | --- | --- |
| 2018〜2019年 | PayPay「100億円あげちゃうキャンペーン」等の事業者主導の還元合戦 | **事業者（自腹・赤字）** |
| 2019年10月〜2020年6月 | 消費増税に伴う**キャッシュレス・消費者還元事業**（中小店で2〜5%還元、決済手数料も3.25%以下に上限を設定し国が一部補助） | **国（税金）** |
| 2020〜2021年 | コロナ禍の非接触志向、自治体のプレミアム付き商品券のデジタル化 | 国・自治体 |

```
【キャッシュレス普及の資金の流れ（2019年還元事業）】

   国（税金）
     │  ①消費者へのポイント還元原資（2〜5%）
     │  ②決済事業者への端末導入補助
     │  ③加盟店手数料の1/3を補助（上限3.25%の条件付き）
     ▼
  決済事業者 ──▶ 中小加盟店 ──▶ 消費者
     ▲                              │
     └──── 手数料収入 ──────────────┘

  ▲ この期間だけ「店は手数料が安く、客は還元がもらえ、事業者は補助が出る」
    という全員得の状態が人工的に作られた。だから一気に普及した。
    裏を返せば、補助が終われば経済性は元に戻る。
```

**キャンペーン合戦の経済性**：コード決済事業者にとって、還元は「顧客獲得コスト（CAC）」。
1人あたり数千円を配ってでもアプリに残高を入れてもらえば、
その後の決済手数料と金融サービスで回収できる、という賭けだった。
実際PayPayは長く赤字を続け、2026年3月期にようやく調整後EBITDA 1,111億円
（決算発表、報道ベース）という水準に到達している。

> **2026年に各社が一斉に還元を絞っているのは、この回収フェーズに入ったから**。
> ポイント改悪は「裏切り」ではなく、**ビジネスモデル上あらかじめ予定されていた着地**である。

## 4. QRコードの乱立から集約へ

2018〜2019年には「〜Pay」が数十種類乱立した。理由は単純で、
**QRコードは紙に印刷するだけで始められ、参入コストがほぼゼロ**だったから。
しかし決済は**ネットワーク効果**（使える店が多いほど使われ、使う人が多いほど店が入れる）が
極端に強く、**上位数社に収斂するのが必然**だった。

| 段階 | 時期 | 起きたこと |
| --- | --- | --- |
| 乱立 | 2018〜2019年 | 通信・EC・銀行・流通が一斉参入。規格もバラバラ |
| 規格統一 | 2019年〜 | 経産省・キャッシュレス推進協議会が統一規格 **JPQR** を策定。店側の掲示を1枚に |
| 淘汰・撤退 | 2020〜2023年 | ファミペイ以外の流通系、通信系の一部が撤退・統合（LINE Pay は2025年4月末で国内サービス終了） |
| 寡占 | 2024年〜 | **PayPay一強＋楽天ペイ・d払い・au PAY** の構図。利用シェアはPayPay 65.2%（2025年7月、MMD研究所調査） |
| 新規参入の再開 | 2025〜2026年 | JR東日本が **teppay** を2026年秋開始予定。交通系の巻き返し |

```
【決済手段のネットワーク効果（両面市場）】

    使える店が増える
        ▲       │
        │       ▼
   店が入れたく   利用者が
   なる           増える
        ▲       │
        └───────┘
   ＝ 一度回り始めると勝者総取りになる。
     後発は「経済圏」「独自の入口」がないと入れない。
     teppayが「Suicaアプリの中に最初から入っている」形で出るのは、
     この壁を回避する唯一の現実解だから。
```

## 5. 経済圏との結合 ── 決済は「入口」にすぎない

日本のキャッシュレス競争の特徴は、**決済単体ではなく「経済圏」で戦っている**こと。
通信・EC・銀行・証券・ポイントを束ね、**ポイントで囲い込んで金融で稼ぐ**構造。

| 経済圏 | 中核企業 | 決済 | ポイント | 束ねているもの |
| --- | --- | --- | --- | --- |
| **PayPay／ソフトバンク** | ソフトバンク、LINEヤフー | PayPay、PayPayカード | PayPayポイント | 携帯、Yahoo!ショッピング、PayPay銀行・証券・保険 |
| **楽天** | 楽天グループ | 楽天ペイ、楽天カード | 楽天ポイント | 楽天市場、楽天モバイル、楽天銀行・証券・保険 |
| **ドコモ** | NTTドコモ | d払い、dカード | dポイント | 携帯、dショッピング、**マネックス（証券）**、三菱UFJ銀行との連携 |
| **au／KDDI** | KDDI | au PAY、au PAYカード | Pontaポイント | 携帯、au PAY マーケット、auじぶん銀行、auカブコム証券、ローソン |
| **イオン** | イオン | イオンペイ | WAON POINT | 全国の店舗網、イオン銀行、イオンカード |
| **JR東日本** | JR東日本 | Suica、teppay（2026年秋〜） | JRE POINT | 鉄道、駅ナカ、エキュート、ビューカード |

> **なぜ「経済圏」になるのか**：決済手数料だけでは利益が出ない。
> しかし決済を握れば **「誰が・いつ・どこで・いくら使ったか」** が分かる。
> このデータと接点を使って、金利のある商品（カードのリボ、ローン、銀行の貸出、証券の手数料）に
> 送客するのが本命である。**決済＝赤字の集客装置、金融＝利益の回収装置**。

## 6. 残された課題

| 課題 | 中身 |
| --- | --- |
| **中小店の手数料負担** | 政府目標80%に向けた最大の壁。インターチェンジフィーの公開（2022年）は進んだが、料率自体は大きく下がっていない |
| **地方・小規模事業者の未導入** | 屋台、個人商店、寺社、医療機関の一部など。端末コストと通信環境 |
| **高齢者・デジタル弱者** | スマホ前提の設計。ATM網縮小と同時に進むと金融包摂の問題になる |
| **災害・通信障害時の脆弱性** | 停電・通信断で決済が止まる。2018年北海道胆振東部地震や各種通信障害で顕在化 |
| **不正利用とフィッシング** | カード不正利用被害額は年間500億円超の水準で高止まり（日本クレジット協会統計）。EC（CNP取引）が中心 |
| **手数料の可視化不足** | 店が「自分は何に対していくら払っているか」を理解しづらい |

| 用語 | 意味 |
| --- | --- |
| **キャッシュレス決済比率（国内指標）** | 2026年公表分から採用された新定義。持家の帰属家賃等を分母から除く。2025年は58.0% |
| **国際比較指標** | 民間最終消費支出をそのまま分母にした従来定義。2025年は46.3% |
| **キャッシュレス・消費者還元事業** | 2019年10月〜2020年6月の国の事業。中小店で2〜5%還元、手数料上限3.25%を条件に補助 |

| **ネットワーク効果（両面市場）** | 利用者と加盟店が互いを呼び込む構造。勝者総取りになりやすい |
| **経済圏** | 決済・ポイント・通信・EC・金融を束ねた囲い込み。日本特有に発達した |
| **CAC（顧客獲得コスト）** | 1人の利用者を獲得するのにかけた費用。還元キャンペーンの正体 |

| **現金流通高のGDP比** | 現金の多さを測る国際比較指標。日本は約20%で突出 |
| **JRE POINT / WAON POINT / Ponta** | 流通・交通系のポイント。経済圏の通貨として機能する |
