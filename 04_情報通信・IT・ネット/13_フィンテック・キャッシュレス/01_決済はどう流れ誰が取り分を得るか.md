# ① 決済はどう流れ、誰が取り分を得るか

このノートで分かること：**あなたが店で1万円を払ったとき、その1万円がどの会社を経由し、
店にいくら残り、残りは誰がどう山分けするのか**。決済業界の損益はすべてここから説明できる。

> **結論を先に**：決済とは「お金を運ぶ仕事」ではなく、**「加盟店手数料という1つのパイを
> 4者で分け合う仕組み」**である。パイの**約7割はイシュア（カード発行会社）**へ行く。
> そして決済単体の利益は薄いので、各社は**決済を入口にして金融（与信・銀行・証券）で回収**している。

---

## 1. まず押さえる：決済は「お金の移動」と「情報の移動」が別ルートで動く

店頭で決済が「承認されました」と出た瞬間、お金はまだ1円も動いていない。
動いたのは**「この人は後で払える」という情報（オーソリゼーション＝与信承認）だけ**。
実際の資金は数日〜1か月後にまとめて移動する（クリアリング＝清算、セトルメント＝決済）。

```
【時間軸で見た1回の決済】

 0秒          数時間〜1日        2〜5営業日            翌月〜翌々月
 │             │                  │                     │
 承認          売上確定           加盟店に入金          利用者が引落し
(オーソリ)    (クリアリング)     (セトルメント)        (イシュアが回収)
 │             │                  │                     │
 情報だけ動く  金額を確定させる   手数料を引いて送金    ここで初めて
                                  ＝ここで取り分が      利用者のお金が
                                    差し引かれる        出ていく
```

> ポイント：**決済会社は「利用者が払う前に、加盟店に払う」**。
> つまり数週間ぶんの資金を立て替えている。この立替に必要な資金調達コストと貸倒れリスクが、
> 手数料の正体の一部である。

## 2. カード決済の4者モデル ── 登場人物を1人ずつ

カード決済は世界共通で「4パーティ（4者）モデル」と呼ばれる形をしている。

```
        ┌──────────────┐  ①カードを発行・与信・請求  ┌──────────────┐
        │  イシュア    │ ◀──────────────────────────▶ │   利用者     │
        │(カード発行会社)│                              │  (消費者)    │
        └───────┬──────┘                              └──────┬───────┘
                │                                             │
    ③インターチェンジフィー                              ②カードで支払う
      (アクワイアラ → イシュア)                               │
                │                                             ▼
        ┌───────┴──────┐   ④加盟店手数料を引いて入金  ┌──────────────┐
        │ アクワイアラ  │ ─────────────────────────────▶│   加盟店     │
        │(加盟店契約会社)│                              │    (店)      │
        └───────┬──────┘                              └──────────────┘
                │
        ┌───────┴──────────────────────────┐
        │  国際ブランド (Visa / Mastercard /  │ ← 両側から「ブランドフィー」を取る
        │  JCB / AmEx / Diners / UnionPay)   │   自分では与信も入金もしない
        │  ＝ルールと決済ネットワークの提供者  │
        └────────────────────────────────────┘
```

| 登場人物 | 日本語で言うと | やること | 抱えるリスク | 収入源 |
| --- | --- | --- | --- | --- |
| **イシュア** | カード発行会社 | 会員募集、与信審査、利用明細発行、請求・回収 | **貸倒れ（利用者が払わない）** | インターチェンジフィー、年会費、リボ・分割の金利手数料、キャッシング利息 |
| **アクワイアラ** | 加盟店契約会社 | 店の開拓・審査、端末設置、売上データ処理、店への入金 | **加盟店倒産（商品未提供でチャージバックが発生）** | 加盟店手数料からインターチェンジフィー等を引いた差額 |
| **国際ブランド** | ブランドホルダー | 決済ネットワーク運営、ルール策定、インターチェンジフィーの水準決定 | ほぼ負わない | **ブランドフィー**（両側から取る）、ライセンス料 |
| **加盟店** | 店・EC事業者 | 商品を売る | 代金不払いはない（保証される） | －（手数料の支払側） |
| PSP／決済代行 | 決済代行会社 | 複数ブランド・複数手段を1本化して店に提供 | 加盟店リスクの一部 | アクワイアラ手数料への上乗せ、月額・トランザクション課金 |

**なぜ4者に分かれているのか**。カードは「日本のどの店でも、海外でも使える」ことに価値がある。
1社で世界中の会員と世界中の店を同時に集めるのは不可能なので、
**会員集めの担当（イシュア）と店集めの担当（アクワイアラ）を分業し、
その間をつなぐ共通ルール（国際ブランド）を置いた**。これが4者モデルの理由である。

日本の特殊事情として、**イシュアとアクワイアラを同じ会社がやる例が多い**
（三井住友カード、JCB、三菱UFJニコスなど）。この場合、社内で左のポケットから右のポケットに
インターチェンジフィーを移すだけなので、手数料の「分配」は見えにくくなる。
JCBやAmExのように、ブランドも自社で持つ形を**3者モデル（クローズドループ）**という。

## 3. 【核心】加盟店手数料の何%が誰に行くか

ここがこの業界を理解する最大の急所。**1万円の買い物**で分解する。

```
【加盟店手数料 3.24%（＝324円）の行き先】※一般的な中小加盟店の料率を例に

  利用者が払う      10,000円
        │
        ▼
  ┌─────────────────────────────────────────────────┐
  │  加盟店手数料  324円 (3.24%)                     │
  │                                                  │
  │  ████████████████████████░░░░░░░░░░░░░░░░░░░░░   │
  │  ↑ インターチェンジフィー      ↑ アクワイアラ取り分 │
  │    約7割＝約227円 (2.27%)        約3割＝約90円     │
  │    → イシュア（発行会社）へ      → 加盟店開拓・端末・│
  │      ポイント原資・与信コスト      入金業務・貸倒れ  │
  │      ・回収コストに充てる          の費用に充てる    │
  │                                                  │
  │  そのうちブランドフィー 約0.1%前後＝約7〜10円(推計) │
  │  → Visa / Mastercard へ（イシュア側・アクワイアラ側 │
  │    の双方から徴収される）                          │
  └─────────────────────────────────────────────────┘
        │
        ▼
  加盟店の手取り  9,676円
```

| 取り分 | 受け取る人 | 目安 | 根拠 |
| --- | --- | --- | --- |
| **インターチェンジフィー（IRF）** | イシュア | 加盟店手数料の**約7割** | 公正取引委員会「クレジットカードの取引に関する実態調査報告書」（2022年4月） |
| アクワイアラ取り分 | アクワイアラ／PSP | 残り約3割 | 同上（差額として） |
| ブランドフィー | 国際ブランド | 0.1%前後（**推計・報道ベース**） | 各社非公表。業界解説記事の水準 |

### インターチェンジフィーの「標準料率」は2022年に公開された

長らく非公表だったが、公正取引委員会と経済産業省の働きかけで、
**2022年9月にVisa、11月にMastercard・UnionPayが日本国内の標準料率を公開**した
（JCBは2023年6月に加盟店手数料の配分率を公開）。

公開された料率の例（いずれも2022年公開時点。最新は各ブランドのサイトで確認）：

| ブランド | 加盟店の業種 | カードランク | 標準料率 |
| --- | --- | --- | --- |
| Visa | 日常利用系（スーパー等） | 一般 / ゴールド / プラチナ | 0.90% / 1.00% / 1.20% |
| Visa | 航空会社 | 一般 / ゴールド / プラチナ / Infinite | 1.10% / 1.20% / 1.40% / 1.70% |
| Visa | 公共サービス | 一般 / ゴールド / プラチナ | 0.60% / 0.70% / 0.90% |
| Mastercard | 日常利用系 | 一般〜プラチナ / チタン以上 | 0.85% / 1.30% |
| Mastercard | 航空会社 | 一般 〜 ワールドエリート | 1.25% 〜 1.90% |

> **ここから分かる3つのこと**
> 1. **「カードのランクが上がるほど店の負担が増える」**。プラチナ会員の手厚いポイントや
>    空港ラウンジの原資は、最終的に**加盟店が払っている**
> 2. **業種で料率が違う**。日常的に使ってほしい業種（スーパー、公共料金）は低く設定され、
>    単価が高く不正リスクの大きい業種（航空、EC）は高い
> 3. **料率を決めるのはブランドで、交渉相手ではない**。アクワイアラは
>    インターチェンジフィーを原価として受け取っているだけなので、
>    「手数料を下げてくれ」と店が交渉しても、下げられるのは残り3割の部分だけ

## 4. 加盟店手数料は誰にいくらで売られているか

同じ「カードが使える」でも、店が払う率は大きく違う。理由は**交渉力と業種リスク**。

| 加盟店の類型 | 加盟店手数料の目安（2025〜2026年） | なぜその水準か |
| --- | --- | --- |
| 大手チェーン・量販店 | **1%台前半〜2%台** | 取扱高が巨大でアクワイアラ間の取り合いになる。インターチェンジフィーも低業種区分 |
| 一般の中小実店舗 | **2.5〜3.5%（3.24%が定番の表示値）** | 交渉力がない。PSP経由で一括の標準料率が適用される |
| EC（ネット） | **3〜4%台** | カードを提示しない取引（CNP）は不正利用が多く、チャージバックのリスクが高い |
| 飲食・美容など小規模 | 3%台 | 同上。加えて1件あたりが小さく固定的な処理コストが重い |
| **コード決済（QR）** | **0.99〜3%程度**（PayPay等） | カードより低く設定して店を集めた。ただし後述のとおり支払手段によって原価が違う |

> **なぜ日本の中小店で3.24%という数字をよく見るのか**：
> インターチェンジフィー（約2.2〜2.3%相当）＋アクワイアラ・PSPの取り分を積み上げた
> 「標準料率」がそのまま提示されるため。**中小店に価格交渉の余地はほとんどない**。
> これがキャッシュレス普及の最大の摩擦になっている
> → [② キャッシュレスの日本的事情](02_キャッシュレスの日本的事情.md)

## 5. コード決済（QR）は、カードと何が違うのか

PayPayなどのコード決済は「新しい決済手段」に見えるが、
**内部はカード網と銀行網の上に乗った“アプリの皮”**であることが多い。
重要なのは、**利用者がどこからお金を出したか（ファンディングソース）で、事業者の原価が全く変わる**こと。

```
【コード決済の3つの原資と、事業者の原価】

 ① 残高（チャージ済み）  ─▶ 原価ほぼゼロ    ＝ 事業者にとって最も儲かる
    銀行口座/ATM/現金から
    事前にチャージ
                          ┌── 加盟店手数料 1.98% をほぼ丸取り

 ② 後払い（自社クレジット） ─▶ 原価は与信・貸倒れ ＝ 手数料＋金利で稼げる
    PayPayクレジット等                          （最も利益率が高い形）

 ③ 他社クレジットカード   ─▶ 原価＝カードの加盟店手数料(約2〜3%)
    登録したカードから引落      ＝ 受け取る手数料とほぼ同じか逆ザヤ
                             ＝ 事業者は儲からない
```

だからコード決済各社は、**「残高チャージで払ってくれ」「自社カードなら還元率を上げる」**と
執拗に誘導する。2026年に相次いだ「他社カード払いは還元対象外」「ポイント払いは還元ゼロ」という
いわゆる“改悪”は、感情の問題ではなく**③の逆ザヤを潰す構造的な動き**である
（詳細は [④ 直近トピック](04_直近トピック_2026.md)）。

### コード決済事業者の収益源

| 収益源 | 中身 | 性格 |
| --- | --- | --- |
| 加盟店手数料 | 決済額 × 1〜3% | 本業。GMV（取扱高）に比例 |
| **金融収益** | 後払い・カードの金利、ローン、銀行の利ざや、証券の手数料 | **伸びが速く利益率が高い。決済は入口で、稼ぎは金融** |
| 滞留残高の運用 | チャージされたまま使われない残高 | 金利が上がるほど効く |
| 広告・送客 | アプリ内クーポン、ミニアプリ、データ活用 | 経済圏の副産物 |

> 実例：PayPayの2026年3月期は、営業収益の**59%が決済手数料、41%が金融・決済金利**。
> 金融セグメントの営業収益は前年同期比+47%と、決済(+27%)を大きく上回った
> （PayPay 2026年5月7日 決算発表、報道ベース）。
> **「決済で客を集め、金融で回収する」**という設計がはっきり数字に出ている。

## 6. チャージ残高の正体 ── 前払式支払手段と資金移動業

アプリに入れた「残高」は預金ではない。法律上は2つに分かれ、**できることと規制が違う**。

| 区分 | 根拠法 | 代表例 | 送金・出金 | 主な義務 |
| --- | --- | --- | --- | --- |
| **前払式支払手段** | 資金決済法 | Suica等の電子マネー、各種プリペイド、PayPayマネーライト | **原則できない**（払戻し原則禁止） | 未使用残高の**2分の1以上を供託等で保全**、発行者登録・届出 |
| **資金移動業** | 資金決済法 | PayPayマネー、楽天キャッシュ（本人確認済）、Kyash 等 | **送金・出金できる** | **全額保全**、登録制、本人確認（eKYC）、第1〜3種で上限額が異なる |
| 預金 | 銀行法 | 銀行口座 | 自由 | 預金保険（1,000万円まで）、銀行免許 |

```
【同じ「残高」でも中身が違う】

  PayPayマネーライト          PayPayマネー
  （前払式支払手段）          （資金移動業）
  ├ 本人確認 不要             ├ 本人確認(eKYC) 必須
  ├ 送金：相手に譲渡は可      ├ 送金：可
  ├ 銀行口座への出金：不可    ├ 銀行口座への出金：可
  └ 保全：未使用残高の1/2以上 └ 保全：全額

  ▲ 2026年にPayPayが「eKYC未完了だと還元ゼロ」に踏み切ったのは、
    利用者を右側（資金移動業）に寄せて金融サービスに接続するため
```

> **なぜ「未使用残高の1/2」で済むのか**：前払式支払手段は本来「商品券」の延長線上にあり、
> 発行体が倒れたときの利用者保護が目的。一方、送金・出金できる資金移動業は
> 実質的に「お金を預かっている」ため全額保全が求められる。
> **送金できるかどうか**が、規制の重さを分ける境目になっている。

2025年6月成立・**2026年6月1日施行の改正資金決済法**では、資金移動業の保全方法として
「銀行等が供託を介さず直接利用者に弁済する」新制度が加わり、
クロスボーダー収納代行にも資金移動業の登録が求められることになった。
またステーブルコイン（電子決済手段）まわりで**「電子決済手段等・暗号資産サービス仲介業」**が新設された。
→ [暗号資産](../../05_金融/14_暗号資産/README.md)、[④ 直近トピック](04_直近トピック_2026.md)

## 7. 銀行口座直結・デビット・口座振替 ── カード網を通さないルート

カード網を通さずに銀行の仕組みを直接使う決済もある。**こちらは手数料の分配構造が違う**。

| 手段 | お金の動き | 加盟店側のコスト | 誰が取り分を得るか |
| --- | --- | --- | --- |
| **デビットカード**（Visaデビット等） | 決済と同時に口座から即時引落し | カードとほぼ同じ（やや低め） | 国際ブランド網を使うので4者モデルと同じ配分。イシュアは銀行 |
| **J-Debit** | 銀行間ネットワーク（CAFIS）で即時引落し | 低い | 銀行と運営主体 |
| **口座振替（引落し）** | 月次でまとめて口座から引落し | 1件数十円〜百数十円の**定額** | 収納代行会社と銀行 |
| **銀行振込** | 全銀システム経由 | 振込手数料（数百円） | 仕向銀行・全銀ネット |
| **ことら送金** | J-Debit基盤（CAFIS）を使い、全銀システムを個別には通さない | 個人間は**10万円まで無料** | 参加金融機関の設備投資として負担 |

**ことら送金**は、個人間の少額送金を電話番号・メールアドレスで無料にする仕組み
（2022年開始）。参加金融機関は2026年2月時点で418以上、
累計送金額は2025年6月時点で1.5兆円に達したと報じられる。
認知度28.7%・利用経験10.2%（2025年10月調査、報道ベース）とまだ浸透途上だが、
**「銀行側が決済アプリに送金機能を奪われないための反撃」**という位置づけで見ると分かりやすい。
→ [ネット銀行](../../05_金融/04_ネット銀行/README.md)、[メガバンク](../../05_金融/01_メガバンク/README.md)

> **構図**：カード網（国際ブランド）は手数料率が「%」、銀行網は「1件いくら」。
> 単価が高い買い物ほどカードは高くつき、少額決済ほど銀行網は割高になる。
> **この非対称が、決済手段の棲み分けを決めている。**

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **イシュア** | カードを発行し、会員に請求・回収する会社。貸倒れリスクを負う |
| **アクワイアラ** | 加盟店と契約し、店に入金する会社。加盟店倒産リスクを負う |
| **国際ブランド** | Visa / Mastercard / JCB / AmEx / Diners / UnionPay。決済網とルールの提供者 |
| **PSP／決済代行** | 複数の決済手段を店に一括提供する事業者（GMO-PG、SBPS、Square、Stripe 等） |
| **加盟店手数料（MDR）** | 店が決済1件ごとに払う手数料。Merchant Discount Rate |
| **インターチェンジフィー（IRF）** | アクワイアラがイシュアに払う手数料。加盟店手数料の約7割を占める |
| **ブランドフィー** | 国際ブランドがイシュア・アクワイアラ双方から取る手数料 |
| **オーソリ／クリアリング／セトルメント** | 与信承認（お金は動かない）／売上の確定／実際の資金移動 |
| **チャージバック** | 利用者の異議申立てで売上が取り消され、加盟店が代金を失うこと。CNP取引（カード非提示のEC等）で多い |
| **3者モデル（クローズドループ）** | イシュア・アクワイアラ・ブランドを1社で兼ねる形（AmEx、一部のJCB） |
| **ファンディングソース** | コード決済で実際にお金が出る元（残高／自社後払い／他社カード） |
| **前払式支払手段／資金移動業** | 前者は送金・出金できないプリペイド（1/2以上を保全）。後者は送金・出金でき全額保全とeKYCが必要 |
| **ことら送金** | 電話番号等で個人間を10万円まで無料送金する銀行界の仕組み（2022年〜） |
| **GMV／テイクレート** | 取扱高／GMVに対する手数料収入の比率。決済事業の規模と収益性の基本指標 |
