## このフォルダの読み方

フィンテック・キャッシュレスは「IT業界の一分野」に見えるが、
経済の実体は完全に **金融型＝お金の流れと収益源** で動いている。
だから骨格は、**「お金がどこからどこへ流れ、その途中で誰がいくら抜くか」**という軸で作った。

とくに重要なのが、この業界を理解する核心である
**「加盟店手数料の何%が誰に行くか」**。ここを押さえれば、
ポイント還元の改悪も、経済圏競争も、フィンテック各社の決算も、同じ1つの原理で説明がつく。

## 1. 業界の定義・範囲

**フィンテック（FinTech）＝金融（Finance）×技術（Technology）**。
既存の金融機能を、ITの力で **より安く・より速く・より使いやすく** 提供し直す事業の総称。
**キャッシュレス**は、その中でも「現金以外の支払手段」に絞った領域を指す。

```
【このフォルダの守備範囲】

 ┌──────────────────────────────────────────────────────┐
 │ 決済（Payments）                                       │
 │   コード決済（PayPay・楽天ペイ・d払い・au PAY）        │
 │   電子マネー（Suica・楽天Edy・nanaco・WAON）           │
 │   決済代行／PSP（GMO-PG・SBPS・Square・Stripe）        │
 │   アクワイアリング、オンライン決済、タッチ決済         │
 │ 送金・入出金（ことら送金、国際送金、デジタル給与）     │
 │ 与信（BNPL＝後払い、オンラインレンディング、スコア）   │
 │ 家計簿・会計（PFM、クラウド会計、経費精算、請求書）    │
 │ 投資（ロボアド、スマホ証券、投資型クラファン）         │
 │ 基盤（銀行API＝電子決済等代行業、BaaS、eKYC、不正検知）│
 │ ステーブルコイン（改正資金決済法上の「電子決済手段」） │
 └──────────────────────────────────────────────────────┘
```

**隣接業界との境界**

- **カード会社そのもの**（三井住友カード、JCB、楽天カード等）は業態としては金融。
  ここでは「決済の4者モデルの中でどう取り分を得ているか」という切り口で扱う
- **銀行・証券・保険の本体**は [05_金融](../../05_金融/) 側。
  ここでは「フィンテックが銀行のどの機能を切り取ったか」という視点で触れる
- **暗号資産の投機・取引所ビジネス**は [暗号資産](../../05_金融/14_暗号資産/README.md) 側。
  ここではステーブルコインの**決済利用**のみを扱う
- **「フィンテック企業」という統計上の業種は存在しない**。
  金融庁の業種（資金移動業、前払式支払手段発行者、電子決済等代行業など）で見るしかない

## 3. バリューチェーン（川上 → 川下）

```
 利用者 ──▶ フロント（アプリ・カード）──▶ 処理基盤 ──▶ 資金の出し手
   │              │                          │              │
   │         PayPay/楽天ペイ            PSP・決済代行    銀行・カード会社
   │         カード/Suica               ゲートウェイ     資金移動業者
   │         teppay                     国際ブランド網   信販・BNPL事業者
   │                                    全銀/CAFIS
   ▼
 加盟店 ◀── 入金（手数料を引いた額）────────────────┘

  付加価値が集まる場所 ──▶ ① 会員基盤（イシュア＝取り分の約7割）
                        ② 経済圏（決済で集めて金融で回収）
                        ③ ルールを決める立場（国際ブランド）
        ▲ 「お金を運ぶ」部分の付加価値は薄い。
          「誰の与信か」「誰の顧客か」を持つ者が取り分を得る
```

**この業界の特徴**は、川中（決済事業者）が川上（与信・銀行）へ向かって食い込んでいること。
PayPayは銀行・証券・保険を持ち、楽天は市場・カード・銀行・通信を束ねる。
**決済単体では儲からないので、必ず金融へ伸びる**のが構造的な必然である。
詳しくは [① 決済はどう流れ誰が取り分を得るか](01_決済はどう流れ誰が取り分を得るか.md)。

## 5. 収益モデル・コスト構造

| 収益源 | 中身 | 性格 |
| --- | --- | --- |
| **加盟店手数料** | 決済額 × 0.99〜4% | 本業。GMVに比例する変動収益。薄利 |
| **インターチェンジフィー** | 加盟店手数料の**約7割**（公正取引委員会 2022年調査） | イシュア側の主収入。カードランクが高いほど厚い |
| **金融収益** | 後払い・リボ・カードローンの金利、銀行の利ざや、証券手数料 | **利益の本体**。PayPayでは営業収益の41% |
| 滞留残高の運用益 | チャージされたまま使われない残高 | 金利上昇局面で効く |
| 月額・ID課金 | 法人SaaS（経費精算・会計・請求書） | ストック型。解約率が命 |
| 送客・広告 | アプリ内クーポン、金融商品への送客 | 経済圏の副産物 |

**コスト構造の急所**

| 費目 | 性格 |
| --- | --- |
| **ポイント還元原資（販促費）** | 変動費。**顧客獲得コスト（CAC）そのもの**。2026年に各社が一斉に絞っている |
| **他社への支払手数料** | 利用者が他社カードで払うと原価が発生し、逆ザヤになる |
| 貸倒れ（与信コスト） | BNPL・カード・ローンの生命線。数%動くだけで黒字と赤字が入れ替わる |
| システム・不正検知 | 固定費。規模で薄まる唯一の費目 |
| 加盟店開拓・端末 | 初期は重い。一度入れば回収が続く |

> **この業界の核心**：決済は**GMVが10倍になっても利益が10倍にはならない**。
> 手数料率が低く、還元原資と他社手数料という変動費が乗るから。
> だから各社は決済を赤字の集客装置と割り切り、**金融（与信・預金・運用）で回収**する。
> これが「決済会社はすべて銀行になりたがる」理由である。

## 6. 競争要因（KSF）と参入障壁

**KSF（成功の鍵）**

1. **使える店の数と使う人の数**：両面市場なので、どちらかが欠けると回らない
2. **自社の原資で払わせる設計**：残高チャージ・自社後払いに誘導できるかで原価が激変する
3. **金融への接続**：eKYCを済ませ、銀行・証券・ローンへ送客できるか
4. **与信データ**：決済履歴を持つほど貸倒れを抑えられる（PayPay加盟店ローンの貸倒率0.03%）
5. **経済圏の厚み**：通信・EC・小売など、決済以外の接点をいくつ持つか
6. **規制対応力**：資金移動業・前払式支払手段・電子決済等代行業の登録と保全義務

**参入障壁**

| 障壁 | 強さ | 理由 |
| --- | --- | --- |
| **ネットワーク効果** | 極めて強 | 一度回り始めると勝者総取り。後発は「既存の1億人アプリに内蔵する」等の裏口が要る |
| **還元原資の体力** | 極めて強 | 数年赤字を続けられる資本がなければ普及フェーズを戦えない |
| **免許・登録と保全義務** | 中〜強 | 資金移動業は全額保全。前払式支払手段も未使用残高の1/2以上を保全 |
| **加盟店網** | 強 | 全国の店を1軒ずつ開拓するのは時間がかかる。PSP経由で緩和はされる |
| **アプリを作ること自体** | 極めて弱 | QRは紙に印刷するだけで始められた。だから2018年に数十社が乱立した |

> **非対称な構造**：参入は簡単、生き残りは不可能に近い。
> 2018年の乱立から、LINE Pay終了（2025年4月）など淘汰を経て、
> 2026年には上位4社寡占に収斂した。
> 詳しくは [② キャッシュレスの日本的事情](02_キャッシュレスの日本的事情.md)。

## 7. 規制・法制度

| 法律・制度 | 内容 |
| --- | --- |
| **資金決済法（前払式支払手段）** | プリペイド残高の発行者を規制。原則払戻し禁止、**未使用残高の1/2以上を供託等で保全** |
| **資金決済法（資金移動業）** | 送金・出金できる残高を扱う登録制。**全額保全**、eKYCが必須。第1〜3種で上限額が異なる |
| **改正資金決済法（2025年6月成立／2026年6月1日施行）** | 「電子決済手段等・暗号資産サービス仲介業」の新設、信託型ステーブルコインの運用要件緩和、資金移動業の新保全制度、クロスボーダー収納代行への登録義務 |
| **割賦販売法** | 分割払い・後払い（包括／個別信用購入あっせん）を規制。**支払期間2か月以内は対象外**なのでBNPLの多くが外れる |
| **改正銀行法（2018年施行）** | **電子決済等代行業**の登録制を創設。銀行にオープンAPI整備の努力義務 |
| **犯罪収益移転防止法** | 本人確認（KYC／eKYC）義務。マネロン対策 |
| **貸金業法** | 貸付を行う場合の登録・総量規制（年収の1/3） |
| **金融商品取引法** | 証券・ロボアド（投資助言・投資運用業）の登録 |
| **労働基準法施行規則（2023年4月改正）** | **賃金のデジタル払い**を解禁。厚労大臣の指定を受けた資金移動業者のみ（2026年2月時点で4社） |
| **電子帳簿保存法・インボイス制度** | 請求書・経費精算SaaSの需要を制度側から作り出した |
| **独占禁止法／公正取引委員会の調査** | 2022年4月の実態調査を受け、インターチェンジフィーの標準料率（2022年）と加盟店手数料の配分率（2023年）が公開された |
| **割賦販売法・個人情報保護法** | 与信スコアリングにおける情報利用の制約 |

## 8. 最近のトピック

- **PayPayが2026年3月にNASDAQ上場**。2026年3月期は営業収益+27%、GMV 4.98兆円。**金融セグメントが+47%と決済（+27%）を上回り**、「決済で集め金融で稼ぐ」が数字で裏付けられた

- **改正資金決済法が2026年6月1日施行**。ステーブルコインが制度の中に入り、JPYCの累計発行額は2026年9月に100億円を突破。ただしカード決済134.6兆円の1万分の1未満で実証段階
- **JR東日本teppayが2026年秋開始予定**。Suica/PASMOアプリ内蔵・上限30万円で「2万円の壁」を回避。交通系の巻き返しと、クレカのタッチ決済による改札通過の拡大が同時進行
