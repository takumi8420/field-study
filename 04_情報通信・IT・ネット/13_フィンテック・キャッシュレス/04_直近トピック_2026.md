## 1. キャッシュレス決済比率58.0%、そして「指標そのものが変わった」

経済産業省は**2026年3月31日**、2025年のキャッシュレス決済比率を発表した。

| 項目 | 2025年 |
| --- | --- |
| キャッシュレス決済比率（**新・国内指標**） | **58.0%** |
| 同（従来の国際比較指標） | 46.3% |
| キャッシュレス決済額 | **162.7兆円**（過去最高） |
| 政府目標 | 2030年までに65%、将来的に**80%** |

**内訳**：クレジットカード 134.6兆円（82.7%）、コード決済 16.6兆円（10.2%）、
電子マネー 6.0兆円（3.7%）、デビットカード 5.5兆円（3.4%）。

ここでのニュースは数字そのものより**指標の定義変更**。
従来は民間最終消費支出をそのまま分母にしていたが、
新指標では**「持家の帰属家賃」など、そもそもキャッシュレスになりえない項目を分母から除いた**。
結果として同じ実態が46.3%から58.0%に見える。

> **なぜ変えたのか**：政府目標「将来的に80%」を、実態に即した分母で測るため。
> 帰属家賃（持家に住む人が自分に家賃を払っているとみなす統計上の擬制）を分母に入れたままでは、
> 100%は原理的に到達不能だった。**批判としては「ゴールポストを動かした」とも読める**ため、
> 今後の比率を語るときは**必ずどちらの指標かを明示する**必要がある。

電子マネーが4.4%→3.7%と縮小した一方でコード決済が9.6%→10.2%に伸びており、
**少額決済の主役がSuica等からQRへ移る流れ**が続いている。

## 2. PayPay、2026年3月にナスダック上場 ── 「決済で集め、金融で稼ぐ」が数字で証明された

PayPay株式会社は**2026年3月12日に米NASDAQへ上場**した
（公開価格16ドル、初値19ドルと報じられる）。
**2026年5月7日**には上場後初となる2026年3月期の決算を発表した。

| 指標（2026年3月期、報道ベース） | 数値 | 前年同期比 |
| --- | --- | --- |
| 営業収益 | 約3,807億円 | +27% |
| 調整後EBITDA | 1,111億円 | － |
| 決済セグメント GMV | **4.98兆円** | +23% |
| 決済セグメント営業収益 | 822億円 | +27% |
| **金融セグメント営業収益** | **212億円** | **+47%** |
| 月間取引ユーザー数（MTU） | 約4,100万人 | +10% |
| MTUあたり月間GMV | 41,293円 | +11% |
| PayPay銀行 預金残高／貸出残高 | 2.3兆円／1.2兆円 | +23%／+34% |
| PayPay資金調達（加盟店ローン） | 累計4万件超、**貸倒率0.03%** | － |

営業収益の内訳は**決済手数料59%／金融・決済金利41%**。
PayPay証券は会社設立以来初の通期黒字を達成した。

> **読み取り方**：決済（+27%）より金融（+47%）が速い。
> [③ フィンテックの各領域](03_フィンテックの各領域.md) で書いた
> **「決済＝集客装置、金融＝回収装置」**という構造が、決算の数字でそのまま確認できる形になった。
> 加盟店ローンの貸倒率0.03%は、**決済データを持つ者の与信がいかに強いか**を示す象徴的な数字。

## 3. ポイント還元の一斉縮小 ── 「改悪」は構造的な必然

2026年に入り、主要各社が相次いで還元条件を引き下げた（いずれも報道・各社告知ベース）。

| 時期 | 事業者 | 内容 |
| --- | --- | --- |
| 2026年2月 | dカード | 公共料金・税金の還元率 1.0% → **0.5%** |
| 2026年3月 | 楽天ペイ | 楽天キャッシュチャージ払いの還元率 1.5% → 1.0% を予定していたが、**準備の都合で見合わせ**と発表 |
| 2026年6月2日 | PayPay | ①**ポイント払いでの決済を還元対象外**に ②公共料金のカード払い還元率 1.0%→0.5% ③モバイルSuica/PASMO等へのチャージを還元0% ④**eKYC未完了ユーザーは還元ゼロ** |

```
【なぜ「改悪」が同時多発するのか】

  ① 公共料金・税金のカード払い
      加盟店手数料が極端に低い（IRFも低業種区分）
      → 1%還元すると事業者が確実に赤字  ▶ 0.5%へ

  ② 他社カード/ポイント払い・電子マネーチャージ
      原価＝他社に払う手数料が発生
      → 受け取る手数料とほぼ同額で逆ザヤ  ▶ 還元対象外へ

  ③ eKYC未完了ユーザー
      残高が「前払式支払手段」止まりで金融サービスに接続できない
      → 回収できない客  ▶ 還元を止めて本人確認へ誘導

  ▲ いずれも「回収できない取引に還元原資を出さない」という
    同じ1つの原理から出ている。感情論ではなく損益の整理。
```

> [② キャッシュレスの日本的事情](02_キャッシュレスの日本的事情.md) で見たとおり、
> 日本の普及は還元というCAC（顧客獲得コスト）で買われた。
> **その投資回収期に入った**というのが2026年の全体像である。

## 4. 改正資金決済法が2026年6月1日施行 ── ステーブルコインが「制度の中」に入った

2025年6月6日成立・6月13日公布の改正資金決済法が、**2026年6月1日に施行**された。主な内容は次のとおり。

| 改正項目 | 内容 |
| --- | --- |
| **電子決済手段等・暗号資産サービス仲介業の新設** | 「媒介のみ」を業として行う者を対象にした新たな業種区分。自ら預からない仲介者を登録制の枠に入れた |
| 信託型ステーブルコインの要件緩和 | 特定信託受益権の定義を改正し、一定の条件下で**要求払預貯金以外での信託財産の管理・運用**を認める（＝国債等での運用が可能に） |
| 資金移動業の新しい保全制度 | 銀行等・信託会社等が**供託を介さず直接利用者に弁済**する仕組みを創設 |
| クロスボーダー収納代行の規制 | 適用除外類型に当たらない限り、**資金移動業の登録が必要**に |

**現場での動き**

- 日本円ステーブルコイン **JPYC** の累計発行額が**2026年9月18日に100億円を突破**（同社プレスリリース）。
  2026年4月時点で21億円、5月末で30億円超・口座開設1万9,000件だったので、**半年で数倍の伸び**
- SBI VCトレードが信託型の円建てステーブルコイン **JPYSC** を提供
- **2026年2月**、JCB・デジタルガレージ・りそなホールディングスがマイナウォレットと
  ステーブルコイン決済の実証実験を実施（報道ベース）
- 三井住友カードとJPYCの実証で**マイナンバーカードを使ったタッチ決済**の取り組みが発表されたと報じられる

> **なぜ重要か**：ステーブルコインが普及すると、**加盟店手数料の4者分配モデルを迂回できる**。
> ブロックチェーン上の送金コストは理論上ほぼゼロなので、
> 「カード網を通さず、店と客が直接決済する」余地が生まれる。
> ただし現時点では発行額100億円規模＝**クレジットカード134.6兆円の1万分の1未満**で、
> 実用化はまだ実証段階にある。
> → [暗号資産](../../05_金融/14_暗号資産/README.md)

## 5. 交通系の巻き返し ── JR東日本「teppay」が2026年秋に開始予定

JR東日本は**2025年11月25日**、Suica・PASMOアプリに組み込むコード決済
**「teppay（テッペイ）」を2026年秋から提供開始**すると発表した。

| 特徴 | 内容 |
| --- | --- |
| 専用アプリ不要 | **既存のモバイルSuica／モバイルPASMOアプリの中で使える**。新規ダウンロードも新規登録も不要 |
| 決済上限 | **最大30万円**（従来のSuica残高上限2万円の制約を回避） |
| 機能 | 店頭コード決済、個人間送金、Suicaへのチャージ、JCBバーチャルカードによるオンライン決済 |
| 加盟店手数料 | 加盟店申込開始時に**最大12か月手数料無料**のキャンペーン（報道ベース） |
| モバイルPASMO対応 | 2027年春ごろを予定 |

> **狙い**：Suicaは「2万円の壁」＝FeliCaカード時代の残高上限に縛られ、
> 高額決済に使えなかった。これを根本解決するには
> **Suicaのシステム基盤をクラウド化する必要があり、10年規模の時間がかかる**とされる
> （日経ビジネス 2025年12月の解説）。teppayは**その間をつなぐ現実解**という位置づけ。
> [② キャッシュレスの日本的事情](02_キャッシュレスの日本的事情.md) の
> ネットワーク効果の壁を、**「1億人が既に持っているアプリの中に入れる」**ことで越えようとしている。

同時に、首都圏の鉄道では**クレジットカードのタッチ決済による改札通過**が各社で拡大しており、
「交通系ICカード」という日本独自の仕組みが、**国際ブランドのタッチ決済に置き換わる可能性**も論点になっている。

## 7. 全体の構図（まとめ）

1. **比率58%（新指標）で目標65%が視野に入った。ただし指標の定義が変わったことを忘れてはいけない**
2. **金額の8割超は今もクレジットカード**。QRは少額決済でSuicaを食う形で伸びている
3. **業界は普及フェーズから回収フェーズへ**。ポイント改悪は各社の損益整理の結果であり、今後も続く
4. **PayPayの上場と決算が「決済＝集客、金融＝収益」を実証した**。決済単体で儲ける会社は今後も出てこない
5. **次の変数はステーブルコインとタッチ決済**。前者はカードの4者分配モデルを、後者は交通系ICを、それぞれ迂回しうる。ただしどちらもまだ実証段階

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **国内指標／国際比較指標** | 2026年公表分から採用された新分母（帰属家賃等を除く）／従来の分母。同じ実態が58.0%と46.3%に見える |
| **帰属家賃** | 持家に住む人が自分に家賃を払っているとみなす統計上の擬制。キャッシュレスになりえない項目 |
| **調整後EBITDA** | 営業利益に減価償却費等を足し戻した利益指標。先行投資型の企業の実力を測るのに使われる |
| **MTU** | Monthly Transacting Users。月間で実際に決済したユーザー数 |
| **eKYC** | オンライン本人確認。これを済ませないと資金移動業の残高（送金・出金可能な残高）が使えない |
| **電子決済手段等・暗号資産サービス仲介業** | 改正資金決済法（2026年6月1日施行）で新設。媒介のみを行う事業者の登録制 |
| **ステーブルコイン** | 法定通貨等に価値を連動させたデジタル通貨。日本では資金決済法上の「電子決済手段」 |
| **JPYC／JPYSC** | 日本円建てステーブルコイン。前者は資金移動業型、後者は信託型 |
| **teppay** | JR東日本が2026年秋開始予定のコード決済。Suica／PASMOアプリに内蔵、上限30万円 |
