# 直近トピック（2026年9月時点）

報道・調査会社レポート・企業IRをもとにした整理。
調査会社の数値は推計であり、確定値ではない点に注意。一次情報は末尾の参考リンクから。

## 1. キャリアの財布は縮み、機器市場は伸びる ― ねじれが起きている

2026年の最大の特徴は、**買い手の一方（通信キャリア）が絞り、もう一方（クラウド事業者）が開いている**こと。

| 指標 | 2026年の動き | 出典 |
| --- | --- | --- |
| 世界の通信キャリア設備投資 | **前年比2%減**の見通し | Dell'Oro Group（2026年4月） |
| 世界の通信機器市場（6分野計） | 2026年上半期に**前年同期比5%増**。6四半期連続増 | Dell'Oro Group（2026年） |
| RAN（基地局） | 2026年は**ほぼ横ばい**、約350億ドル規模 | Omdia／Dell'Oro（2026年） |
| 光伝送装置 | **前年比16%成長、180億ドル超**（2000年以来の水準） | Dell'Oro Group（2026年） |

```
   キャリア設備投資  ─ 2% ▼   ┐
                              ├─▶ 通信機器市場 全体 ＋5% ▲
   クラウド／AI投資   大幅 ▲   ┘
                              （差分を埋めているのはAIデータセンター向け光・ルーティング）
```

Dell'Oro は減少の理由を「既存設備で現在のトラフィックには足りており、
大規模な新規投資を急ぐ必要がない」ためと説明している。
同社は2026〜2030年の世界設備投資は年率1.8%減で推移し、**再び増えるのは6G移行期**と見る。

## 2. シェア変動 ― 中国外でファーウェイとシスコが伸びた

Dell'Oro によると、2026年上半期の世界通信機器売上の首位は**ファーウェイ**、次いで**ノキア、エリクソン**。
注目すべきは中国を除いた市場での動きで、

- **ファーウェイとシスコがシェアを拡大**（2025年比）
- **エリクソンとノキアの合計シェアは約3ポイント低下**

理由として挙げられているのは、各社の**光伝送・ルーティング市場への露出度の差**と地域要因。
つまり「AIデータセンターに近い製品を持っているかどうか」がシェアを動かしている。

RAN に限れば集中度はさらに上がり、上位5社（ファーウェイ、エリクソン、ノキア、ZTE、サムスン）で
**96%** を占め、ファーウェイとエリクソンの2社だけで約3分の2（Dell'Oro、2026年）。

## 3. ノキアの決算に現れた「AI比重のシフト」

構造変化が最も分かりやすく出たのがノキアの2026年4〜6月期決算。

| 項目 | 2026年4〜6月期 | 前年同期比 |
| --- | --- | --- |
| 売上高 | 48億2,000万ユーロ | ＋8% |
| 比較可能営業利益 | 4億3,400万ユーロ | ＋18% |
| AI・クラウド顧客向け売上 | **4億4,600万ユーロ** | **2倍超** |
| 同事業の新規受注 | 28億ユーロ | — |
| ネットワークインフラ部門 | 20億4,000万ユーロ | ＋12% |
| └ 光ネットワーク | 8億6,800万ユーロ | ＋20% |
| └ IPネットワーク | 6億7,900万ユーロ | ＋16% |

通期の比較可能営業利益ガイダンスは21億〜26億ユーロへ引き上げられた。

> **読み方**：ノキアは「基地局の会社」から「AIデータセンターに光とIPを売る会社」へ
> 重心を移しつつある。同じく2026年には商用 **AI-RAN プラットフォーム**も発表し、
> 2028年までに100%超の周波数利用効率改善を示すとしている。

## 4. Open RAN ― 6年やって採用率は1ポイントしか動かなかった

政府補助まで付いて推進されてきた Open RAN だが、2026年時点の評価は厳しい。

| 調査 | 内容 | 時点 |
| --- | --- | --- |
| GSMA Intelligence | 6年間の取り組み・政府補助・提唱を経ても、**測定可能な採用率は1ポイントしか動かなかった**。性能が依然として足を引っ張る | 2026年 |
| Dell'Oro Group | **マルチベンダーRANは2030年でも総RANの5%未満**（従来予測の5〜10%から下方修正） | 2026年2月 |
| Omdia | O-RANアーキテクチャを「本番環境で積極展開」しているのは**13%**、「今後のRAN進化の指針として使用」が27% | 2026年 |

構造的な理由（責任分界点、電力効率、統合コスト、既存ベンダーの「O-RAN準拠だが自社一式」戦略）は
[② 産業構造と競争](02_産業構造と競争.md) の5章に整理した。

一方で日本発の動きもある。楽天モバイルと楽天シンフォニーは2026年2月、
商用Open RAN網でのRAN省電力化について TM Forum から
**「自律型ネットワーク レベル4」認定を世界初で取得**したと発表。
同年2月には商用網へのRIC全国展開とサードパーティ製rAppの統合も公表している。
NEC は O-RAN 準拠の vRAN を2025年3月に商用化し、2026年度までに5万局以上の展開を目指すとしている。

## 5. 地政学 ― EUが「高リスク供給業者」の排除を法制化へ

2026年1月20日、EU は重要分野で「高リスク」とされる供給業者の部品・機器を
段階的に排除する計画を盛り込んだ**草案を公表**した。報道ベースの要点は次の通り。

```
  リスト公表  ──────── 36か月 ────────▶  主要部品の使用終了
     ▲                                          ▲
     │                                          │
  対象は5Gに限らず、国境検問所のセキュリティスキャナー、
  水道などの供給システム、医療機器といった重要分野へ拡大しうるとされる
```

- ファーウェイはこれに強く反発していると報じられる
- 先行してドイツは、5Gコア網から2026年末まで、アクセス網も2027年末までに
  ファーウェイ・ZTE製品を切り替えるよう義務づけている（2024年決定）
- 排除は**キャリアにとって純粋なコスト**であり、設備投資の余力をさらに削る副作用がある

## 6. 6G ― スケジュールが確定した

2026年6月の3GPP会合で、6Gの最初の規格 **Release 21** のタイムラインが承認された。
波形やチャネル符号化といった空中インターフェースの基本方式も方向づけられている。

| 時点 | マイルストーン |
| --- | --- |
| 2027年3月 | 6G Work Item 承認、Stage-1 フリーズ |
| 2028年6月 | Stage-2 フリーズ |
| 2028年9月／12月 | 物理層／プロトコル設計の機能フリーズ、Stage-3 フリーズ |
| 2029年3月 | ASN.1／OpenAPI フリーズ（実装可能な状態に） |

> **業界への含意**：売上が谷にあるいま（2026〜2028年）に開発費のピークが来る。
> 体力のない会社は次の波に間に合わない、という選別が起きる時期でもある。

## 7. 光の高速化と電力の壁 ― CPO／光電融合が動き出す

- TrendForce の予測では、800G以上の光モジュールの世界出荷シェアは
  2024年の19.5%から**2026年に60%超**へ拡大するとされる
- データセンター向けイーサネットスイッチ市場は
  **2026年1〜3月に154億ドル、前年同期比39.8%増**（IDC）。
  エヌビディアが売上シェア21.5%で首位（前年同期比192.7%増）、アリスタが約14.6%
- NTT は光電融合デバイス **PEC-2** を2026年度中に商用提供開始する計画。
  16個の光エンジンで毎秒102.4Tbps、消費電力は従来比8分の1とされる。
  ブロードコム（ASIC）、アクトン（筐体組立）、新光電気工業（基板・CPOモジュール組立）と分業

```
  400G ──▶ 800G ──▶ 1.6T ──▶ CPO / 光電融合
                      ▲          ▲
                   いまの主戦場   電力と発熱が律速になり、
                                 「電気配線を短くする」実装へ関心が移る
```

## 8. 日本勢 ― NECと富士通で明暗

2026年3月期決算（2026年4月28日発表）では、売上収益・営業利益ともにNECが富士通を上回った。

| 企業 | 売上収益 | 前期比 | 営業利益 | 前期比 |
| --- | --- | --- | --- | --- |
| NEC | 3兆5,827億円 | ＋5% | 3,599億円 | ＋40% |
| 富士通 | 3兆5,029億円 | −1% | 3,483億円 | ＋31% |

通信機器（基地局）事業に限ると評価は逆で、
**富士通が米大手キャリア向けの大型案件に参画した一方、NECは基地局事業の抜本的見直しを表明**したと報じられている。
富士通はネットワークプロダクトを2,100億円規模へ伸ばす計画。

> 日本勢の現実的な勝ち筋は、世界のRANで正面から戦うことではなく、
> **光部品・光ファイバ・光電融合・計測器**という「部品と道具」側に寄せること
> ――という形が2026年時点ではっきりしてきた。

## 9. 全体の構図（まとめ）

1. **キャリア向けは谷、AIデータセンター向けは山**。この二層構造が2026年の市場を説明する唯一の軸
2. そのため**製品ポートフォリオに光とIPを持つ会社（ノキア、シエナ、ファーウェイ）が有利**、
   RAN依存が高い会社（エリクソン）は不利という差が、シェア変動に直接現れた
3. Open RAN は「技術的にできる」が「経済的に選ばれない」状態が固定化しつつある。
   政府補助では動かないことが6年かけて実証された形
4. 次の投資の波は6G（規格は2029年3月完成、商用は2030年前後）。
   **売上の谷と開発費のピークが重なる2026〜2028年**が業界の踏ん張りどころ
5. 地政学はEUの法制化で新段階へ。市場は西側圏と中国圏に分かれ、両方で規模の経済が落ちる

## 11. 用語メモ

- **Dell'Oro Group / Omdia / IDC**：通信・ネットワーク機器の市場データを出す調査会社。数値は推計
- **1H26**：2026年上半期（1〜6月）の意味。調査会社レポートで頻出
- **AI-RAN**：基地局処理にAIを用い、周波数利用効率や省電力を高める取り組み
- **RIC / rApp**：RANをソフトで制御するコントローラと、その上で動く拡張アプリ
- **高リスク供給業者**：安全保障上の懸念からEU・各国が排除対象とする通信機器ベンダーの分類
- **Release 21**：6Gの最初の規格が入る3GPPリリース。2029年3月に実装可能な状態になる予定
- **PEC-2**：NTTの光電融合デバイスの世代名。2026年度中の商用提供を計画
