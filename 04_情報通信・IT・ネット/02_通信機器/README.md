# 通信機器

- 大分類: 情報通信・IT・ネット
- 状態: done
- 更新日: 2026-09-20

通信サービスそのものではなく、**通信を成立させる機械**を売る産業。
基地局、光伝送装置、ルータ・スイッチ、企業のLAN機器などを作る。
顧客の中心は世界で数百社しかない通信キャリアで、
その設備投資予算がそのまま業界の天井になる――というのが長年の構図だった。
いまその構図が、**AIデータセンターという第二の顧客**の登場で変わりつつある。

## 1. 業界の定義・範囲

通信ネットワークを構成する装置を設計・製造・販売し、据付から保守・ソフトウェア更新まで行う産業。

| 含む | 含まない（隣接業界） |
| --- | --- |
| 基地局（RAN）、コアネットワーク装置 | 通信サービスそのもの → [通信キャリア](../01_通信キャリア/README.md) |
| 光伝送装置（WDM／ROADM）、海底ケーブルシステム | 光ファイバケーブルの敷設工事（通信建設業） |
| ルータ、スイッチ（キャリア用・データセンター用） | データセンターの建物・電源・冷却 → [データセンター](../03_データセンター/README.md) |
| 企業向けネットワーク機器、Wi-Fi アクセスポイント | スマートフォン・PC などの端末 → [PC・スマートフォン](../../03_電機・電子部品/11_PC・スマートフォン/README.md) |
| 光トランシーバなどの通信用モジュール | 半導体チップそのもの → [半導体（ロジック・メモリ）](../../03_電機・電子部品/02_半導体（ロジック・メモリ）/README.md) |

**境界の引き方のコツ**：ネットワークの中に置かれて**通信を中継する箱**が通信機器。
ネットワークの端にいる人が使う箱（スマホ、PC）は端末で別業界。

## 2. 市場規模と成長性

| 指標 | 数値 | 出典・時点 |
| --- | --- | --- |
| 世界の通信機器市場（6分野合計） | 2026年上半期に**前年同期比5%増**。6四半期連続のプラス | Dell'Oro Group（2026年） |
| RAN（基地局）市場 | **約350億ドル、2026年はほぼ横ばい** | Omdia／Dell'Oro（2026年） |
| 光伝送装置市場 | **2026年に前年比16%成長、180億ドル超**（2000年以来の水準） | Dell'Oro Group（2026年） |
| データセンター向けイーサネットスイッチ | **2026年1〜3月に154億ドル、前年同期比39.8%増** | IDC（2026年） |
| 世界の通信キャリア設備投資 | **2026年は前年比2%減**。2026〜2030年は年率1.8%減の見通し | Dell'Oro Group（2026年4月） |

- 広義の「通信機器市場」は定義次第で数千億ドル規模の推計も出回るが、**調査会社ごとに範囲が違う**ので
  単純比較は危険。RAN・光伝送・ルーティングなどカテゴリを指定して見るのが実務的
- 成長ドライバーは**AIデータセンター向けの光伝送・高速スイッチ・光トランシーバ**
- 一方で本来の主戦場である基地局は、5G投資の一巡により横ばい〜微減

## 3. バリューチェーン（川上 → 川下）

```
 部品・要素技術         機器メーカー              顧客                  その先
 ──────────          ──────────             ──────              ──────
 通信用半導体          エリクソン / ノキア        通信キャリア ────────▶ 一般利用者
 （ブロードコム等）    ファーウェイ / ZTE          （数百社）
 光デバイス            サムスン
 （住友電工/古河/      ─────────────────
  コヒーレント等）      シスコ / アリスタ          クラウド・AI事業者 ──▶ AIサービス
 電源・筐体・基板       ジュニパー(HPE) / シエナ    （ハイパースケーラー）
 汎用サーバー          ─────────────────
 （vRAN化で参入）      NEC / 富士通 / ODM各社      一般企業（数百万社） ─▶ 社内ネットワーク
        │                     │                        ▲
        │                     └── 保守・ソフト更新 ─────┘（契約期間中ずっと売上が立つ）
        └── AIデータセンター向けは部品（光モジュール）の比重が高く、
            付加価値が機器メーカーより部品側に寄りやすい
```

**付加価値が集まる場所**：キャリア向けでは機器メーカー自身（標準必須特許、統合保証、保守網）。
AIデータセンター向けでは**部品（光モジュール、スイッチICを作る半導体メーカー）**と、
GPUとセットで売るエヌビディアのような存在に寄りやすい。

## 4. 主要プレイヤーとシェア

| 企業 | 立ち位置 | 特徴 |
| --- | --- | --- |
| **ファーウェイ**（中） | 世界最大の通信機器ベンダー | RAN・コア・光伝送・ルータ・端末まで唯一の全方位。西側では排除が進む |
| **エリクソン**（瑞） | RAN・コアに集中 | 北米で強い。キャリア設備投資への感応度が最も高い |
| **ノキア**（芬） | RAN＋光＋IP | 2026年4〜6月期でAI・クラウド顧客向け売上が前年同期比2倍超の4億4,600万ユーロ |
| **ZTE**（中） | RAN・伝送 | 中国国内が主戦場。西側では排除対象 |
| **サムスン**（韓） | RAN | ファーウェイ排除の受け皿として北米・日本で採用が進んだ |
| **シスコ**（米） | 企業LAN・キャリアルータ・光 | 資格エコシステムと代理店網で企業向けを支配。DC高速スイッチでは3番手に後退 |
| **アリスタ**（米） | データセンタースイッチ専業 | 2026年1〜3月売上22億ドル（前年同期比37.3%増）、92%がDC向け |
| **エヌビディア**（米） | AI向けネットワーク | DC向けイーサネットスイッチで売上シェア21.5%の首位（IDC、2026年1〜3月） |
| **シエナ**（米） | 光伝送 | ファーウェイ・ノキア・ZTEと並び光伝送上位4社（合計シェア8割超） |
| **NEC・富士通**（日） | 国内キャリア向け・伝送・企業向け | 2026年3月期は両社とも増益。基地局事業では明暗が分かれた |
| **住友電工・古河電工・フジクラ**（日） | 光ファイバ・光部品 | AIデータセンター向け光需要の恩恵を受ける側 |

RAN では上位5社で **96%** を占め、ファーウェイとエリクソンの2社だけで約3分の2（Dell'Oro、2026年）。
**カテゴリごとに勝者が違い、総合1位は実質ファーウェイしかいない**のがこの業界の姿。

## 5. 収益モデル・コスト構造

```
  売上 ＝ ① ハードウェア  ＋ ② ソフトウェア   ＋ ③ サービス（保守・SI）
          粗利 30〜40%       粗利 70〜90%        粗利 30〜40%
          投資サイクル直撃   契約期間中は安定     人月がコストで拡大しにくい

  近年の潮流：①が縮み②が伸びる（5Gコアのソフト化、vRAN化でハードがサーバー側へ流出）
```

- 業界全体の営業利益率はおおむね一桁台後半〜十数%（2026年時点の各社IR）。
  半導体製造装置のような高利益体質ではない
- 理由は**顧客の交渉力が強い**こと。キャリアは意図的に複数ベンダーを並べて競わせるので、
  値引き圧力が構造的にかかる
- 一度採用されると5〜10年入れ替わらないため、**先行投資（実証・ラボ検証）を回収するのは受注後**
- AIデータセンター向けは伸びが速いが、顧客がハイパースケーラー数社に集中し、
  **ホワイトボックス（ODM製汎用機）との価格競争**にさらされる

詳細は [② 産業構造と競争](02_産業構造と競争.md) の7章。

## 6. 競争要因（KSF）と参入障壁

1. **標準必須特許（SEP）の保有**。3GPP規格を実装すると必ず踏むため、持たない会社は払う側になる
2. **研究開発の絶対額**。世代交代ごとに物理層から作り直す。年数千億円規模が前提
3. **グローバル保守網**。通信が止まればキャリアは行政報告義務を負う。24時間対応の組織自体が障壁
4. **実績（リファレンス）**。「何千万加入を支えたか」が入場券。実績がないと採用されない循環
5. **キャリアの席が構造的に少ない**。1キャリアが採用するのは通常2社、多くて3社

→ 5つの障壁の図解と、O-RANがこれを崩せない理由は [② 産業構造と競争](02_産業構造と競争.md) の2章・5章。

## 7. 規制・法制度

- **周波数割当**が需要の起点。国が周波数を割り当てないとキャリアは投資できない
- **安全保障を理由としたベンダー排除**が事業に直接効く産業。
  - 米国：政府調達からの排除、既設機器の撤去補助（rip and replace、2019年〜）
  - ドイツ：5Gコア網から2026年末まで、アクセス網も2027年末までに切替を義務化（2024年決定）
  - EU：2026年1月、「高リスク供給業者」の段階的排除を法制化する草案を公表。
    リスト公表から**36か月以内**に主要部品の使用終了とされ、対象は通信以外の重要分野へも拡大しうる
  - 日本：政府調達におけるサプライチェーンリスク考慮（2018年申合せ以降）
- **電気通信事業法・電波法**（日本）。技術基準適合証明（技適）を取らないと国内で使えない
- **標準化**は規制に近い拘束力を持つ。3GPP・IEEE・ITU-T・O-RAN ALLIANCE で決まった仕様が事実上の法になる

## 9. 用語メモ

- **RAN／RU・DU・CU**：無線アクセスネットワークと、基地局を機能分割した3つの箱
- **コアネットワーク（5GC）**：認証・課金・移動管理を担う中枢。5Gではソフトウェア化した
- **O-RAN**：RU・DU間の仕様を公開し、複数メーカーの組み合わせを可能にする取り組み
- **vRAN**：DU・CU を汎用サーバー上のソフトウェアで動かす方式
- **WDM／ROADM／DCI**：波長多重伝送、波長単位の振り分け装置、データセンター間接続
- **光トランシーバ**：電気と光を変換する差込式モジュール。400G/800G/1.6T と高速化中
- **CPO／光電融合**：光と電気を同一パッケージに載せ、配線距離と消費電力を削る実装
- **標準必須特許（SEP）／3GPP**：規格準拠に必須の特許と、それを決める標準化団体
- **CapEx／資本集約度**：キャリアの設備投資額と、売上に対するその比率
- **ホワイトボックス**：ODM製の汎用ハードに自由にソフトを載せる機器
