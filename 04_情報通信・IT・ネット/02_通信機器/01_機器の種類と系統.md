# 機器の種類と系統

このノートで分かること：「通信機器」と一括りにされる製品群を7つの系統に分け、
**系統ごとに顧客も競争相手も売り方もまるで違う**ことを押さえる。

> ポイント：通信機器業界を1枚で理解しようとすると必ず失敗する。
> 「基地局を売る会社」と「企業のスイッチを売る会社」は、同じ業界に分類されているだけで、
> 顧客数が数十社と数百万社、商談期間が数年と数週間、という**別の商売**をしている。

## 1. まずネットワーク全体を1本の線で見る

スマホから発した電波が、相手に届くまでに通る箱を並べると次のようになる。
この並びが、そのまま製品カテゴリの並びになっている。

```
 【無線アクセス】   【伝送】         【コア】          【インターネット/DC】   【企業・家庭の中】
  RAN              光伝送(WDM)      コアネットワーク    ルータ／スイッチ        企業向け機器・Wi-Fi
 ┌─────────┐   ┌───────────┐  ┌────────────┐  ┌──────────────┐  ┌─────────────┐
 │ アンテナ  │   │ 光ファイバ │  │ 加入者認証  │  │ キャリアルータ │  │ Wi-Fi AP     │
 │ 無線機RU  │──│ ROADM/WDM  │──│ 課金・位置  │──│ DCスイッチ     │──│ L2/L3スイッチ │
 │ DU / CU   │   │ 海底ケーブル│  │ 5GC(ソフト) │  │ 光トランシーバ │  │ FW / UTM     │
 └─────────┘   └───────────┘  └────────────┘  └──────────────┘  └─────────────┘
  買うのは        買うのはキャリア   買うのはキャリア   買うのはキャリア＋     買うのは一般企業
  キャリアだけ    ＋クラウド事業者   だけ              クラウド事業者         （数百万社）
     ▲                                                     ▲
     └─ 世界で顧客は数百社。1社失うと売上が消える            └─ AIデータセンターで急拡大中
```

固定回線（光ファイバのインターネット）も同じ構図で、
無線アクセスの代わりに **FTTH のアクセス装置（局側の OLT ／家庭側の ONU）** が入る。

## 2. 7つの系統と、その経済的な違い

| 系統 | 何をする機器か | 顧客 | 世界の顧客数 | 主なプレイヤー | 売り方 |
| --- | --- | --- | --- | --- | --- |
| **RAN（無線アクセス）** | スマホの電波を受けて有線網に渡す。いわゆる基地局 | 通信キャリア | 数百社 | エリクソン、ファーウェイ、ノキア、ZTE、サムスン | 直販。数年の商談と長期フレーム契約 |
| **コアネットワーク** | 誰が繋いでいるかを認証し、課金し、移動に追随する「頭脳」 | 通信キャリア | 数百社 | エリクソン、ノキア、ファーウェイ、マベニア等 | 直販。近年はソフトウェアライセンス |
| **光伝送（WDM）** | 1本の光ファイバに波長を多重して長距離を運ぶ | キャリア＋クラウド事業者 | 数千社 | ファーウェイ、シエナ、ノキア、ZTE（上位4社で8割超） | 直販＋入札 |
| **ルータ・スイッチ** | パケットの行き先を決める。キャリア用とデータセンター用 | キャリア、クラウド、大企業 | 数万社 | シスコ、ノキア、ジュニパー（HPE傘下）、アリスタ、エヌビディア | 直販＋代理店 |
| **光部品・光トランシーバ** | 電気信号を光に変える差込式モジュール | 機器メーカー、クラウド事業者 | 数百社 | コヒーレント、イノライト、住友電工、古河電工ほか | 部品供給。年次で値下げ交渉 |
| **企業向けネットワーク機器** | 会社のLAN、ファイアウォール、VPN | 一般企業 | **数百万社** | シスコ、HPE、フォーティネット、ヤマハ、NEC | 代理店（チャネル）経由が大半 |
| **Wi-Fi** | 無線LANのアクセスポイント、家庭用ルータ | 企業＋消費者 | 非常に多い | シスコ（Meraki）、HPE（Aruba）、TP-Link、バッファロー | 法人＝チャネル、家庭＝量販 |

**この表の読み方**：上に行くほど顧客が少なく単価が高く商談が長い。
下に行くほど顧客が多く単価が低く、営業は代理店網の広さで決まる。
つまり**上と下では必要な会社の作りが違う**ので、両方で勝っている会社はほとんど存在しない。

## 3. RAN（基地局）の中身

一番お金が動くのがここなので、少し分解する。
基地局は物理的には「鉄塔の上の箱」と「足元の箱」に分かれている。

```
        アンテナ（電波を出す板）
            │
    ┌───────┴────────┐  鉄塔の上
    │  RU (Radio Unit) │  電波←→デジタル信号の変換。増幅器が入る。発熱と電力を食う部分
    └───────┬────────┘
            │ フロントホール（光ファイバ。O-RANではここが「7-2x」規格の分界点）
    ┌───────┴────────┐  局舎・基地局の足元
    │  DU (Distributed Unit) │  リアルタイム処理。電波のスケジューリング（誰にいつ電波を割るか）
    └───────┬────────┘
            │ ミッドホール
    ┌───────┴────────┐
    │  CU (Central Unit)     │  上位層の処理。データセンターに集約できる
    └───────┬────────┘
            │ バックホール（コアネットワークへ）
```

- **RU/DU/CU に分けた理由**：全部を鉄塔の上に置くと重く高価なので、
  リアルタイム性が要る処理だけ現地に残し、残りは集約して安く作る、という発想
- **vRAN（仮想化 RAN）**：DU/CU を専用機ではなく汎用サーバー上のソフトにしたもの。
  NECは2025年3月に5G対応vRANを商用化し、2026年度までに5万局以上の展開を目指すと発表した
- **O-RAN**：RU と DU の間の規格を公開して**別メーカーの組み合わせを可能にする**試み。
  なぜ広がらないかは [② 産業構造と競争](02_産業構造と競争.md) の5章で扱う

## 4. コアネットワーク ― 「箱」から「ソフト」へ

コアは加入者の認証・課金・位置管理をする部分で、
かつては専用ハードの塊だったが、5G（5GC）では**クラウド上のソフトウェア群**になった。

| 世代 | 実装 | 買い方 | 機器メーカーへの影響 |
| --- | --- | --- | --- |
| 3G/4G（EPC） | 専用ハード＋専用ソフト | 箱を買う | ハード売上が立つ |
| 5G（5GC） | 汎用サーバー上のコンテナ | ソフトのライセンス＋サーバーは別調達 | **ハード売上が消え、ソフト売上に置き換わる** |

> ここが機器メーカーにとって痛いところ。5G化でコア領域の「機械としての売上」は縮んだ。
> 代わりにソフトウェアは粗利が高いので、利益率では必ずしも悪くない。

## 5. 光伝送と光トランシーバ ― いまの成長エンジン

光伝送は「1本の光ファイバに色（波長）の違う光を何十本も通して同時に運ぶ」技術（WDM）。
都市間、国際、海底ケーブル、そして**データセンター同士の接続（DCI）**で使う。

- Dell'Oro Group によると、光伝送装置市場は **2026年に前年比16%成長し、メーカー売上で180億ドル超**
  （2000年以来の水準）に達する見通し。牽引役はAIデータセンター
- 上位ベンダーはファーウェイ、シエナ、ノキア、ZTE で、直近4四半期合計の売上シェア合計8割超（Dell'Oro、2026年）
- DCI 向けの直接購入分は2026年1〜3月に前年比で約40%増と推計されている

**光トランシーバ**は、装置に差し込む親指サイズのモジュール。
速度で世代が決まり、いま 400G → 800G → 1.6T へ移行中。
TrendForce の予測では、800G以上の光モジュールの世界出荷シェアは
2024年の19.5%から**2026年には60%超**へ跳ね上がるとされる。

```
  光トランシーバの世代交代（データセンター向け）
  100G ──▶ 400G ──▶ 800G ──▶ 1.6T ──▶ CPO（チップに光を直付け）
   ~2018    ~2022     ~2025     2026-    2027以降？
                                  ▲
                          いまここ。消費電力と発熱が律速になり、
                          「電気配線を短くする」CPO/光電融合へ関心が移っている
```

NTT は光電融合デバイス（PEC-2）の商用提供を2026年度中に開始する計画で、
ブロードコム・アクトン・新光電気工業とエコシステムを組むと発表している（2026年）。
→ [③ 市場の性格と投資サイクル](03_市場の性格と投資サイクル.md) の6章

## 6. 企業向けネットワーク機器と Wi-Fi ― 数の商売

キャリア向けとまったく違うのがこちら。会社のオフィスに置くスイッチ、
ファイアウォール、Wi-Fi アクセスポイントなど。

| 項目 | キャリア向け（RAN・コア） | 企業向け（LAN・Wi-Fi） |
| --- | --- | --- |
| 1案件の金額 | 数十億〜数千億円 | 数十万〜数億円 |
| 商談期間 | 1〜3年 | 数週間〜数か月 |
| 販売経路 | 直販（自社営業＋自社エンジニア） | **代理店・SIer 経由が大半** |
| 意思決定者 | キャリアのネットワーク部門トップ | 情報システム部門 |
| 参入障壁 | 標準必須特許、保守網、実績 | **販売網と技術者の資格エコシステム** |
| 買い替え周期 | 5〜10年（世代交代に連動） | 4〜6年（保守終了に連動） |

企業向けでシスコが強い理由は、機器の性能そのものより
**「世界中の情報システム部門とSIerがシスコの資格（CCNAなど）で育っている」**こと。
機器を替えると人の再教育が要るので、乗り換えが起きにくい。
詳しくは [② 産業構造と競争](02_産業構造と競争.md) の4章。

## 7. 誰がどこで戦っているか（重なりの地図）

```
                RAN  コア  光伝送  キャリアルータ  DCスイッチ  企業LAN  光部品
 エリクソン       ◎    ◎     △        △            -          -        -
 ノキア           ◎    ◎     ◎        ◎            △          -        △
 ファーウェイ     ◎    ◎     ◎        ◎            ○          ○        ○
 ZTE              ○    ○     ○        ○            △          △        △
 サムスン         ○    △     -        -            -          -        -
 シスコ           -    △     ○        ◎            ○          ◎        ○
 アリスタ         -    -     -        △            ◎          △        -
 エヌビディア     -    -     -        -            ◎          -        -
 NEC / 富士通     ○    ○     ○        △            -          ○        △
 住友電工/古河電工 -    -     ○        -            -          -        ◎

  ◎=主力で高シェア  ○=一定の存在感  △=限定的  -=ほぼ関与なし
```

この図で見えること。

1. **全部で戦えているのはファーウェイだけ**。だからこそ地政学の標的になっている
2. エリクソンは RAN とコアに集中。逆に言うとキャリア設備投資への依存度が最も高い
3. ノキアは光伝送・IP を持つので、**AIデータセンター需要の恩恵を受けやすい**
4. エヌビディアはGPUの付属品としてネットワークに入ってきた**新参の最大の脅威**
5. 日本勢は特定領域（光部品、企業向け、国内キャリア向け）に寄っている

## 8. 用語メモ

- **RAN（Radio Access Network）**：基地局を中心とする無線アクセス部分。通信機器市場で最大のカテゴリ
- **RU / DU / CU**：基地局を機能分割した3つの箱。電波部／リアルタイム処理／上位処理
- **vRAN**：DU・CU を汎用サーバー上のソフトウェアで動かす方式
- **コアネットワーク（5GC）**：認証・課金・移動管理を担う中枢。5Gではソフトウェア化した
- **WDM（波長分割多重）**：1本の光ファイバに複数波長を通して容量を増やす技術
- **ROADM**：光のまま波長単位で行き先を振り分ける装置
- **DCI（データセンター間接続）**：データセンター同士を光で結ぶ用途。いまの成長源
- **光トランシーバ**：電気信号と光信号を変換する差込式モジュール。400G/800G/1.6Tと高速化
- **CPO（Co-Packaged Optics）**：スイッチICのすぐ隣に光を置き、電気配線を短くして電力を減らす実装
- **FTTH / OLT / ONU**：家庭までの光回線と、その局側装置／宅内装置
- **チャネル（販売）**：代理店・ディストリビュータ経由の間接販売網
