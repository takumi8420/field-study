通信サービスそのものではなく、通信を成立させる機械を売る産業。
基地局、光伝送装置、ルータ・スイッチ、企業のLAN機器などを作る。
顧客の中心は世界で数百社しかない通信キャリアで、
その設備投資予算がそのまま業界の天井になる――というのが長年の構図だった。
いまその構図が、AIデータセンターという第二の顧客の登場で変わりつつある。

1. 業界の定義・範囲

通信ネットワークを構成する装置を設計・製造・販売し、据付から保守・ソフトウェア更新まで行う産業。

含む 含まない（隣接業界）
基地局（RAN）、コアネットワーク装置通信サービスそのもの → 通信キャリア
光伝送装置（WDM／ROADM）、海底ケーブルシステム光ファイバケーブルの敷設工事（通信建設業）
ルータ、スイッチ（キャリア用・データセンター用）データセンターの建物・電源・冷却 → データセンター
企業向けネットワーク機器、Wi-Fi アクセスポイントスマートフォン・PC などの端末 → PC・スマートフォン
光トランシーバなどの通信用モジュール半導体チップそのもの → 半導体（ロジック・メモリ）

境界の引き方のコツ：ネットワークの中に置かれて通信を中継する箱が通信機器。
ネットワークの端にいる人が使う箱（スマホ、PC）は端末で別業界。

5. 収益モデル・コスト構造

  売上 ＝ ① ハードウェア  ＋ ② ソフトウェア   ＋ ③ サービス（保守・SI）
          粗利 30〜40%       粗利 70〜90%        粗利 30〜40%
          投資サイクル直撃   契約期間中は安定     人月がコストで拡大しにくい

  近年の潮流：①が縮み②が伸びる（5Gコアのソフト化、vRAN化でハードがサーバー側へ流出）
  • 業界全体の営業利益率はおおむね一桁台後半〜十数%（2026年時点の各社IR）。
    半導体製造装置のような高利益体質ではない
  • 理由は顧客の交渉力が強いこと。キャリアは意図的に複数ベンダーを並べて競わせるので、
    値引き圧力が構造的にかかる
  • 一度採用されると5〜10年入れ替わらないため、先行投資（実証・ラボ検証）を回収するのは受注後
  • AIデータセンター向けは伸びが速いが、顧客がハイパースケーラー数社に集中し、
    ホワイトボックス（ODM製汎用機）との価格競争にさらされる

詳細は ② 産業構造と競争 の7章。

6. 競争要因（KSF）と参入障壁

  1. 標準必須特許（SEP）の保有。3GPP規格を実装すると必ず踏むため、持たない会社は払う側になる
  2. 研究開発の絶対額。世代交代ごとに物理層から作り直す。年数千億円規模が前提
  3. グローバル保守網。通信が止まればキャリアは行政報告義務を負う。24時間対応の組織自体が障壁
  4. 実績（リファレンス）。「何千万加入を支えたか」が入場券。実績がないと採用されない循環
  5. キャリアの席が構造的に少ない。1キャリアが採用するのは通常2社、多くて3社

→ 5つの障壁の図解と、O-RANがこれを崩せない理由は ② 産業構造と競争 の2章・5章。

7. 規制・法制度

  • 周波数割当が需要の起点。国が周波数を割り当てないとキャリアは投資できない
  • 安全保障を理由としたベンダー排除が事業に直接効く産業。
    • 米国：政府調達からの排除、既設機器の撤去補助（rip and replace、2019年〜）
    • ドイツ：5Gコア網から2026年末まで、アクセス網も2027年末までに切替を義務化（2024年決定）
    • EU：2026年1月、「高リスク供給業者」の段階的排除を法制化する草案を公表。
      リスト公表から36か月以内に主要部品の使用終了とされ、対象は通信以外の重要分野へも拡大しうる
    • 日本：政府調達におけるサプライチェーンリスク考慮（2018年申合せ以降）
  • 電気通信事業法・電波法（日本）。技術基準適合証明（技適）を取らないと国内で使えない
  • 標準化は規制に近い拘束力を持つ。3GPP・IEEE・ITU-T・O-RAN ALLIANCE で決まった仕様が事実上の法になる

8. 最近のトピック

詳細は ④ 直近トピック 2026。要点は5つ。

  1. キャリア設備投資は2026年に2%減、なのに通信機器市場は5%増。差を埋めているのがAIデータセンター
  2. 中国外のシェアでファーウェイとシスコが伸び、エリクソン＋ノキアの合計は約3ポイント低下（Dell'Oro）

  4. EUが高リスク供給業者の排除を法制化する草案を2026年1月に公表。ドイツは2026年末が期限
  5. 6G（3GPP Release 21）のスケジュールが2026年6月に確定。実装可能になるのは2029年3月

9. 用語メモ

  • RAN／RU・DU・CU：無線アクセスネットワークと、基地局を機能分割した3つの箱
  • コアネットワーク（5GC）：認証・課金・移動管理を担う中枢。5Gではソフトウェア化した
  • O-RAN：RU・DU間の仕様を公開し、複数メーカーの組み合わせを可能にする取り組み
  • vRAN：DU・CU を汎用サーバー上のソフトウェアで動かす方式
  • WDM／ROADM／DCI：波長多重伝送、波長単位の振り分け装置、データセンター間接続
  • 光トランシーバ：電気と光を変換する差込式モジュール。400G/800G/1.6T と高速化中
  • CPO／光電融合：光と電気を同一パッケージに載せ、配線距離と消費電力を削る実装
  • 標準必須特許（SEP）／3GPP：規格準拠に必須の特許と、それを決める標準化団体
  • CapEx／資本集約度：キャリアの設備投資額と、売上に対するその比率
  • ホワイトボックス：ODM製の汎用ハードに自由にソフトを載せる機器
