# ② 儲け方の構造

このノートで分かること：通信キャリアの損益は結局 **「ARPU × 契約数 − 設備投資（とその償却）」** の一本の式に還元できる。
その式の各項が、なぜ今のような経営判断（サブブランド、経済圏、金融参入）を生むのかを追う。

> 結論を先に：通信料金そのものは **もう増えない前提**の商売になった。
> だから3社は「同じ契約者から通信以外でもう一度お金を取る」方向（＝経済圏）へ舵を切った。
> 通信キャリアの決算を読むとは、**通信の減り方と非通信の増え方の綱引きを見ること**である。

## 1. 基本の式

```
【通信事業の損益の組み立て】

  売上 ＝ ARPU（1契約あたり月額収入） × 契約数 × 12か月
        ＋ 端末販売収入（ほぼ利益は乗らない）
        ＋ 非通信収入（金融・決済・コマース・法人）

  費用 ＝ 減価償却費（過去の設備投資のツケ）   ← 固定
        ＋ ネットワーク運用費（電気・回線借料・保守） ← ほぼ固定
        ＋ 人件費・店舗・代理店手数料            ← 半固定
        ＋ 販売促進費（端末値引き・ポイント還元）  ← 変動だが経営判断で膨らむ
        ＋ 接続料の支払い                        ← 変動

  利益 ＝ 売上 − 費用
         ▲ 費用の7割前後が「契約が減っても減らない費用」＝装置産業
```

| 項           | 動かし方                                     | 難しさ                                       |
| ------------ | -------------------------------------------- | -------------------------------------------- |
| **ARPU**     | 上位プラン、データ大容量、オプション、値上げ | 競争と政治圧力で上げにくい                   |
| **契約数**   | MNP獲得、サブブランド、法人、IoT回線         | 人口減で総パイが増えない                     |
| **解約率**   | セット割、ポイント、家族割、家庭内シェア     | 下げると効果は複利で効く                     |
| **設備投資** | 投資の前倒し／先送り                         | 削ると品質が落ち、2〜3年後に解約率で跳ね返る |
| **非通信**   | 決済・金融・広告・コマース                   | 立ち上げに時間がかかるが伸びしろは大きい     |

## 2. ARPU：定義が会社ごとに違うので要注意

**ARPU（Average Revenue Per User）＝1契約あたりの月間平均収入**。
「ユーザー1人がいくら払っているか」ではなく「1回線あたり会社にいくら入るか」である点に注意。

| 会社         | 2025年度（2026年3月期）の開示         | 備考                                                 |
| ------------ | ------------------------------------- | ---------------------------------------------------- |
| NTTドコモ    | 通信ARPU **4,100円**（前年比 +20円）  | 別集計では4,000円とする資料もある                    |
| KDDI         | 通信ARPU **4,440円**（前年比 +100円） | 別集計では3,960円                                    |
| ソフトバンク | 3,700円台とされる                     | 開示区分が異なる                                     |
| 楽天モバイル | **2,000円台前半**                     | 低価格プランが主力。上げ余地はあるが解約リスクと表裏 |

※ 資料によって数字がずれるのは **分母（契約数）と分子（収入）の定義が各社で違う**から。IoT回線・MVNO卸・タブレットを含めるかで平均は大きく変わる。**必ず各社IRの定義注記を見ること**。

近年、各社は分子を広げた指標を併用している。

| 指標                                    | 中身                               | 狙い                                             |
| --------------------------------------- | ---------------------------------- | ------------------------------------------------ |
| 通信ARPU                                | 通信料だけ                         | 本業の実力                                       |
| **総合ARPU／付加価値ARPU**              | 通信＋コンテンツ・決済手数料・金融 | 「通信が下がっても総額は上がっている」と示したい |
| **ARPA**（Average Revenue Per Account） | 1契約でなく1顧客（世帯）単位       | 家族・固定とのセットで見せる                     |

> ここが読み方のコツ：**通信ARPUが横ばいでも総合ARPUが伸びている**という開示は、「通信では増えないが同じ顧客から他事業で回収できている」ことの表明である。

## 3. 契約数：もうパイは増えない

2026年3月末の国内携帯契約数は主要4社合計で **約2億3,312万件**。
人口（約1.2億人）の約2倍で、1人が複数回線（スマホ＋タブレット＋IoT）を持つ状態にある。

| 事業者       | 契約数（2026年3月末） | 直近四半期の純増       |
| ------------ | --------------------- | ---------------------- |
| NTTドコモ    | 約 **9,307万**        | +86.1万（4社中トップ） |
| KDDI（au等） | 約 **7,276万**        | +70.6万                |
| ソフトバンク | 約 **5,692万**        | +32.7万                |
| 楽天モバイル | 約 **1,036万**        | +35.0万                |

（各社四半期開示／集計サイトベース。事業者間で「契約」の定義＝MVNO卸・通信モジュールの扱いが異なる）

```
【純増の中身は「新規需要」ではない】

  人口・世帯数 ─ ほぼ横ばい
        │
        ├─ 1人あたり回線数の増加（サブ回線・タブレット・見守り）… 微増
        ├─ IoT・M2M回線（自販機・車・電力メーター）……………… ここが実は主戦場
        └─ MNP（他社からの奪い合い）………………………………… ゼロサム
                 ▲ 獲得コスト（端末値引き・ポイント）を払って取り合う
```

MNP（番号ポータビリティ）中心の市場では、**獲得コストが「他社に取られない防衛費」にもなる**。
ここを削ると解約率が上がり翌年以降の売上が減るので、販促費は「削れるのに削れない費用」になっている。

## 4. 解約率（チャーン）が最重要指標である理由

**解約率（churn rate）＝月あたり何%の契約が消えるか**。

```
 平均契約継続月数 ≒ 1 ÷ 月次解約率

   解約率 0.5%／月 → 平均 200か月（約16.7年）
   解約率 1.0%／月 → 平均 100か月（約 8.3年）
   解約率 2.0%／月 → 平均  50か月（約 4.2年）

 LTV（顧客生涯価値）≒ ARPU × 平均契約継続月数 × 粗利率
```

| 解約率 | ARPU 4,000円のときのLTV（粗利率60%と仮定） | 意味                                |
| ------ | ------------------------------------------ | ----------------------------------- |
| 0.5%   | 約 48万円                                  | 端末に5万円値引きしても十分ペイする |
| 1.0%   | 約 24万円                                  | 値引き競争の採算が厳しくなる        |
| 2.0%   | 約 12万円                                  | 獲得コストを回収できない領域        |

- 日本のMNOの月次解約率は **概ね0.5〜1.0%台**で推移。これは世界的に見ても低い（＝顧客が動かない市場）
- 解約率を下げる仕掛けが **固定回線とのセット割、家族割、ポイント経済圏、電気・金融の同時契約**。契約が絡むほど乗り換えの手間（スイッチングコスト）が増える
- 規制で「2年縛りの違約金」「MNP転出手数料」は実質撤廃された。**法的な足かせは消え、経済的な足かせだけが残った**

> ポイント：ARPUを100円上げるより **解約率を0.1ポイント下げるほうが利益インパクトが大きいことが多い**。だから経営は「値上げ」より「囲い込み」を選ぶ。

## 5. コスト構造：なぜ「実質的な装置産業」なのか

```
【売上100に対する費用のイメージ（国内通信事業、概算）】

  減価償却費        ███████████        15〜20   ← 過去の投資。契約が減っても不変
  ネットワーク運用   ██████             10前後   ← 電気代・回線借料・保守。ほぼ不変
  販売・代理店手数料 ██████████         12〜18   ← 半固定。削ると解約率が上がる
  端末原価          ████████████       販売分だけ通過（利益は薄い）
  人件費・その他     ████████           10前後
  ────────────────────────────────
  営業利益          ███████████        15〜19   ← 3社とも高い
```

| 特徴                 | 中身                                  | 結果として起きること                                                                           |
| -------------------- | ------------------------------------- | ---------------------------------------------------------------------------------------------- |
| 固定費比率が高い     | 設備が先、収入は後                    | 契約数がわずかに動くと利益が大きく振れる                                                       |
| 限界費用がほぼゼロ   | 1契約増えても追加設備はほぼ不要       | 規模が大きいほど利益率が上がる（規模の経済）                                                   |
| 減価償却が遅れて効く | 投資はP/Lに一気に出ず、数年かけて出る | **投資を増やした翌年以降に利益が圧迫される**                                                   |
| 電気代への感応度     | 基地局・データセンターは大口需要家    | 電力価格の上昇が直接コスト増（→[電力](../../11_資源・エネルギー・鉄鋼金属/04_電力/README.md)） |

2026年3月期に **NTTドコモだけが減益**になったのは象徴的で、設備投資を **8,575億円（前期比+20.0%）** へ前倒しし販促費も積んだため。
品質と顧客基盤の立て直しを優先した「先行投資の年」であり、**投資を増やした年は利益が落ちる**という装置産業の宿命がそのまま出ている。

## 6. 料金はどう決まるのか

通信は電気・ガス・鉄道と並ぶインフラだが、**料金規制のかかり方は他のインフラと違う**。

| インフラ                  | 料金の決まり方                                                             | 通信との違い                     |
| ------------------------- | -------------------------------------------------------------------------- | -------------------------------- |
| 電力・ガス（規制部門）    | 総括原価方式（原価＋適正利潤を国が認可）                                   | 通信の移動体は**認可不要**       |
| 鉄道                      | 上限運賃の認可                                                             | 同上                             |
| **携帯電話**              | **届出制**（事業法の改正で認可制は撤廃済み）。事後的な競争政策で誘導       | 法的には自由に決められる         |
| NTT東西の一部固定サービス | 特定電気通信役務として**料金の上限規制（プライスキャップ）**、接続料は認可 | 独占設備を持つ部分だけ規制が残る |

つまり携帯料金は **法律上は自由価格**。にもかかわらず上げづらいのは、(a) 政治的圧力（2020年の値下げ要請とahamo等の誕生）、
(b) 総務省のモバイル市場検証（料金水準を毎年国際比較して公表）、(c) 楽天モバイルという低価格プレイヤーの存在、の3点による。

> つまり **「規制で料金が決まる産業」ではなく「規制を気にしながら自分で決める産業」**。
> ここが電力・鉄道との決定的な違いで、値上げは常に政治リスクとセットになる。

総務省の資料では、料金水準は2020年前後の大幅下落のあと **2022年以降はやや上昇傾向**とされる。実際、各社は「大容量プランの単価引き上げ」「割引の縮小」という形で実質的な値上げを進めている（正面から「値上げ」と言わずにプラン改定で単価を上げるのが定石）。

## 7. ブランドの3層構造：価格帯を切り分ける

同じ会社が高い値段と安い値段を同時に出すのは、**顧客を価格感度で分けて取りこぼさない**ため。

| 層                 | 位置づけ                           | 例                                     | 販売チャネル           | ARPUの目安             |
| ------------------ | ---------------------------------- | -------------------------------------- | ---------------------- | ---------------------- |
| **メインブランド** | フルサービス・大容量・店舗サポート | ドコモ／au／SoftBank                   | 全国のキャリアショップ | 高（4,000〜6,000円台） |
| **サブブランド**   | 品質はそのまま価格を下げる         | UQ mobile／ワイモバイル                | 量販店＋一部店舗       | 中（2,000〜3,000円台） |
| **オンライン専用** | 店舗サポートなしで最安帯           | ahamo／povo／LINEMO／Rakuten最強プラン | オンラインのみ         | 低（2,000円台前後）    |

```
【なぜ3層に分けるのか】

  高価格1本だけ → 安さ重視層がMVNO・楽天へ流出（契約数が減る）
  安価格1本だけ → 払う気のある層からも取り損ねる（ARPUが下がる）

  そこで「同じネットワークを、違う看板で、違う値段で売る」
      ▲ 限界費用がほぼゼロだからこそ成立する戦略
      ▲ 一方でMVNOにとっては、価格でも品質でも勝てない相手が現れたことを意味する
```

サブブランドの存在は、MVNOが個人市場で **10.5%前後で頭打ち**になっている直接の理由でもある
（→ [③ 競争と規制](03_競争と規制.md)）。

## 8. 非通信への拡大：金融・決済・コマース

通信料が伸びないので、**同じ顧客基盤にもう一段の商売を載せる**のが2020年代の共通戦略。

| 会社         | 経済圏の名前            | 中核サービス                                                     | 2026年3月期の非通信の動き                                                          |
| ------------ | ----------------------- | ---------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| NTTドコモ    | **dポイント経済圏**     | d払い、dカード、マネックス（証券）、dアニメ                      | スマートライフ事業の営業利益 **3,027億円（+29.6%）**                               |
| KDDI         | **Pontaポイント経済圏** | au PAY、auじぶん銀行、au カブコム証券、au でんき                 | 金融セグメント営業利益 **432億円**（前期195億円の約2.2倍）                         |
| ソフトバンク | **PayPay経済圏**        | PayPay、PayPay銀行・証券・カード、LINEヤフー、Yahoo!ショッピング | ファイナンス事業 営業利益 **863億円（前年比+107%）**                               |
| 楽天         | **楽天経済圏**          | 楽天市場、楽天カード、楽天銀行・証券、楽天ペイ                   | モバイルの赤字を他事業が支える構造。2025年度にモバイル単体でEBITDA黒字（+129億円） |

```
【経済圏の輪】

        ┌──────── ポイント ────────┐
        ▼                            │
   通信契約 ──▶ 決済 ──▶ EC・実店舗 ─┘
        │         │          │
        └─ 金融（カード・銀行・証券・保険）
                  ▲
        どこで使っても自社ポイントが貯まる／使える
        ＝ 解約すると「損した感じ」がする ＝ 解約率が下がる
```

- ポイント原資は **販促費（費用）**。見返りは ①解約率の低下、②決済手数料収入、③金融の残高・手数料、④購買データの広告活用
- 特に **金融は通信と相性が良い**。与信情報と毎月の課金チャネルを持つので、カード・銀行・証券の獲得コストが安く済む（→ [クレジットカード・決済](../../05_金融/11_クレジットカード・決済/README.md)、[ネット銀行](../../05_金融/04_ネット銀行/README.md)）
- ただし **ポイント還元は「値引きの別形態」**でもあり、競争が過熱すると利益を削る。2026年7月にPayPayが公共料金・税支払いの還元率を1%→0.5%へ引き下げるなど、各社とも「還元の適正化」に入っている（報道ベース）

## 10. 用語メモ

| 用語                                     | 意味                                                                           |
| ---------------------------------------- | ------------------------------------------------------------------------------ |
| **ARPU**                                 | 1契約あたりの月間平均収入。定義が会社ごとに違うので注記必読                    |
| **総合ARPU／ARPA**                       | 通信以外も含めた1契約あたり収入／1顧客（世帯）単位の収入                       |
| **EBITDA**                               | 営業利益＋減価償却費。設備投資が重い事業の「現金の稼ぎ」を測る指標             |
| **解約率（チャーン）／LTV**              | 月あたりの契約消滅率。1÷解約率が平均継続月数。LTV＝ARPU×継続月数×粗利率        |
| **MNP**                                  | 番号ポータビリティ。番号を変えずに他社へ移る制度。奪い合いの主戦場             |
| **サブブランド／オンライン専用ブランド** | 同一ネットワークを別の価格帯で売るための第2・第3の看板                         |
| **オペレーティングレバレッジ**           | 固定費が重いと、売上変動が利益変動を増幅する性質                               |
| **経済圏**                               | ポイントを核に通信・決済・金融・ECを束ねた囲い込みの仕組み                     |
