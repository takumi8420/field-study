# ④ 法人・インフラ事業

このノートで分かること：個人向けの携帯料金が頭打ちになった通信キャリアが、
**どこで次の成長を作ろうとしているか**。法人ネットワーク、データセンター、IoT、5G SA、
そしてAI基盤への投資までを、収益構造の違いとあわせて見る。

> 結論を先に：通信キャリアの成長領域は **「回線を売る」から「回線の上に載る仕組みを売る」** へ移った。
> ただし本質は変わらない。**先に巨額の設備を作り、長期契約で回収する**という装置産業の作法のまま、
> 対象が基地局からデータセンターとGPUに変わっただけである。

## 1. 個人と法人はビジネスモデルが違う

```
【個人向けと法人向けの違い】

 個人向け                          法人向け
 ─────────────────────         ──────────────────────────
 1契約 月4,000円前後              1社 月数十万〜数億円
 解約は自由（MNPで即日）          複数年契約・SLA付き
 売るのは「回線」                 売るのは「つながる仕組み＋運用＋責任」
 競争軸＝価格とポイント           競争軸＝可用性・セキュリティ・提案力
 営業＝ショップと広告             営業＝法人営業＋SIer（→ 人が要る）
 粗利は高いが値下げ圧力が強い     粗利率は個人より低いが、剥がれにくい
```

| 観点       | 個人（コンシューマ） | 法人（エンタープライズ）                         |
| ---------- | -------------------- | ------------------------------------------------ |
| 収益の性格 | 薄く広いストック     | 厚く狭いストック＋SI（一時収益）                 |
| 契約期間   | 実質いつでも解約可   | 3〜5年が一般的                                   |
| 参入障壁   | 周波数・エリア       | **業務理解と実績**。回線だけでは勝てない         |
| 価格決定力 | 弱い（規制・政治）   | 相対的に強い（相見積もりはあるが値崩れしにくい） |
| 成長性     | 人口減で横ばい       | DX・AI需要で伸びしろ                             |

> ポイント：法人事業は **「規制と政治の圧力がかからない領域」**でもある。
> 総務省が携帯料金の国際比較を公表しても、法人ネットワークの値段は話題にならない。
> ここが3社そろって法人・DC・AIに投資する大きな理由。

## 2. 法人向けネットワーク：何を売っているのか

| サービス              | 中身                                          | 使われ方                     | 価格帯の性格                |
| --------------------- | --------------------------------------------- | ---------------------------- | --------------------------- |
| **専用線**            | 2拠点を物理的に占有する回線                   | 金融の基幹系、証券取引       | 最も高い。帯域を丸ごと占有  |
| **IP-VPN**            | 通信事業者の閉域IP網を共用しつつ論理的に分離  | 全国に拠点を持つ企業の基幹網 | 中〜高。品質保証（SLA）付き |
| **広域イーサネット**  | 拠点間をLANのように接続                       | データセンター間接続         | 中。帯域単価が安い          |
| **インターネットVPN** | 公衆インターネット上に暗号トンネル            | 小規模拠点、在宅             | 安い。品質は保証されない    |
| **SD-WAN**            | 複数回線をソフトで束ね、経路を自動選択        | クラウド利用が増えた企業     | 装置＋運用費。近年の主流    |
| **モバイル閉域**      | SIM単位でインターネットを経由せず社内網に直結 | 店舗端末、業務用スマホ       | 回線数課金                  |

**SLA（Service Level Agreement）**＝可用性や遅延を数値で約束し、守れなければ返金する契約。
法人向けの値段の正体は帯域ではなく **「この約束を守るための冗長構成と運用体制」** である。

```
【法人ネットワークが「剥がれにくい」理由】

  回線を変える ＝ 全国の拠点のルータ設定を変える
               ＝ 業務システムの疎通試験をやり直す
               ＝ 止まったら業務が止まる責任を誰が取るか決め直す
        ▲ 個人のMNPと違い、乗り換えに数か月と数千万円かかる
        ▲ だから一度取ると長い。逆に一度取られると長く戻らない
```

## 3. データセンター：キャリアがやる理由

通信キャリアがデータセンター（DC）を持つのは自然な流れだった。
**局舎（電源・空調・回線が揃った建物）を全国に持っていた**からである。

| DCの類型                         | 提供するもの                     | 主な顧客                   | 収益の単位                  |
| -------------------------------- | -------------------------------- | -------------------------- | --------------------------- |
| **コロケーション（ハウジング）** | ラックと電源と回線               | 金融、SIer、事業会社       | ラック数 × kW（電力）× 月額 |
| **ホスティング／マネージド**     | サーバーごと貸して運用も請け負う | 中堅企業                   | 台数・運用工数              |
| **ハイパースケール受託**         | 大規模フロアを丸ごと貸す         | クラウド事業者、大手テック | MW（メガワット）単位        |
| **AI／GPUクラウド**              | GPUサーバーを時間貸し            | AI開発企業、研究機関       | GPU時間・契約枠             |

近年の決定的な変化は、**課金単位が「面積」から「電力（kW・MW）」に移った**こと。
AI向けサーバーは1ラックあたり数十kWを消費し、従来型（1ラック数kW）とは桁が違う。
つまり **DC事業の制約条件は土地ではなく、電力が引けるかどうか**になった。

```
【AI時代のデータセンターの制約】

  用地  ──▶ 電力（受電容量）──▶ 冷却（液冷）──▶ 回線（海底ケーブル・IX近接）
              ▲ ここが最大のボトルネック
              変電所の増設に数年、送電線の空き容量に限りがある
              → 電力会社との交渉力・立地選定が事業の巧拙を決める
```

詳しくは [データセンター](../03_データセンター/README.md)、[電力](../../11_資源・エネルギー・鉄鋼金属/04_電力/README.md) を参照。

主要3社の動き（2025〜2026年、報道・各社発表ベース）

| 会社         | 動き                                                                                                                                                   | 規模                                  |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------- |
| NTT          | NTT3社が新AI基盤「**AIOWN**」を共同発表（2026年4月）。国内DC容量を約300MWから**2033年度に約1GW**へ拡張する計画。AI関連にグローバルで5年間**2兆円**規模 | 原発1基分に相当する電力規模           |
| KDDI         | 大阪・堺に**AIデータセンター**を2025年12月開設。NVIDIAと直接連携                                                                                       | 投資規模**5,000億円**規模と報じられる |
| ソフトバンク | AI DC・GPUクラウドに加え、電力・蓄電まで事業領域を拡大。シャープ堺工場跡地を活用                                                                       | AI・DC投資を成長の柱に位置づけ        |

※ いずれも報道・各社発表ベース。**計画値であり、実現時期・金額は変動しうる**点に注意。

## 4. IoT回線：契約数の「もう一つの伸びしろ」

人口が増えなくても、**モノに回線を載せれば契約数は増える**。

| 用途                                 | 使う技術       | 回線あたり単価             | 特徴                         |
| ------------------------------------ | -------------- | -------------------------- | ---------------------------- |
| コネクテッドカー                     | LTE／5G        | 中（車載は品質要求が高い） | 自動車メーカーと長期契約     |
| スマートメーター（電気・ガス・水道） | LPWA、専用無線 | 極小（月数十円〜）         | 数千万回線規模。10年以上稼働 |
| 自動販売機・POS                      | LTE-M          | 小                         | 安定した更新需要             |
| 物流トラッキング                     | LPWA／eSIM     | 小                         | グローバルSIMの需要          |
| 見守り・ウェアラブル                 | LTE-M          | 小〜中                     | 個人向けとの境界領域         |

- **LPWA（Low Power Wide Area）**＝低速でよいから、低消費電力で遠くまで届かせる無線方式の総称。
  電池1個で10年動くことを狙う。LTE-M、NB-IoTなどがある
- **eSIM／iSIM**＝基板に組み込むSIM。工場出荷後に回線事業者を書き換えられるため、
  グローバルに出荷する機器に向く
- IoT回線は **ARPUが極端に低い**（月数十〜数百円）。だからARPU指標を押し下げる。
  各社が「IoTを除いたARPU」を併記するのはこのため（→ [② 儲け方の構造](02_儲け方の構造.md)）

## 5. 5G SA とローカル5G：法人でどう使うか

5Gの「低遅延」「多接続」「スライシング」は、**5G SA（スタンドアロン）でないと本来の形では使えない**。
そして SA が最も価値を持つのは個人ではなく法人の現場である。

| 形態                                         | 誰が免許を持つか         | 誰が構築するか | 向く用途                                           |
| -------------------------------------------- | ------------------------ | -------------- | -------------------------------------------------- |
| **公衆5G（NSA）**                            | キャリア                 | キャリア       | 一般のスマホ利用                                   |
| **公衆5G SA＋スライシング**                  | キャリア                 | キャリア       | 中継放送、イベント、遠隔制御                       |
| **プライベート5G**（キャリア網の一部を専有） | キャリア                 | キャリア       | 工場・物流倉庫で品質を保証したい場合               |
| **ローカル5G**                               | **その企業・自治体自身** | 自社またはSIer | 工場、港湾、農地、病院。電波を外に出したくない用途 |

```
【ローカル5G が Wi-Fi と争う領域】

            カバー範囲   端末の移動   干渉耐性   導入コスト   免許
  Wi-Fi 6/7    狭い       弱い        弱い       安い        不要
  ローカル5G    広い       強い        強い       高い        必要（自社で取得）
       ▲ 「広い敷地で、機械が動き回り、止まると損害が大きい」現場ほどローカル5G有利
       ▲ 逆にオフィスはWi-Fiで足りるので、普及は工場・港湾・建設に偏る
```

- 日本の5G基地局は2025年3月末で約30.7万局、うち **SA対応は15.6万局**（前年度比+5.1万局、総務省）
- 総務省は2025年6月に「**デジタルインフラ整備計画2030**」を策定し、5G SA等の普及目標を設定
- 2026年の課題は「5Gの質とマネタイズ」と指摘される。
  つまり **エリアは広がったが、5Gでしか成立しないサービスがまだ少ない**という段階
- ローカル5Gは期待ほど数が伸びていないのが実情。理由は
  ① 免許取得と設計の手間、② 端末（産業用5Gモジュール）の価格、③ Wi-Fiで足りる用途が多いこと

## 6. IOWN／APN：光で通信とコンピューティングを溶かす

NTTが主導する **IOWN（Innovative Optical and Wireless Network）** は、
「電気の処理をできるだけ光に置き換える」という長期構想。その第一弾が **APN（All-Photonics Network）** で、
拠点間を光のまま（電気変換を挟まず）つなぐことで、遅延を大幅に下げる。

| 要素                                      | 狙い                         | 事業上の意味                                                                                      |
| ----------------------------------------- | ---------------------------- | ------------------------------------------------------------------------------------------------- |
| **APN（オールフォトニクスネットワーク）** | 低遅延・低消費電力の光専用線 | 遠隔地のデータセンターを1つのように扱える                                                         |
| **データセントリック基盤**                | 処理をデータの近くで行う     | DC分散立地が可能になる                                                                            |
| **光電融合デバイス**                      | チップ間まで光化             | 半導体分野への展開（→ [半導体](../../03_電機・電子部品/02_半導体（ロジック・メモリ）/README.md)） |

政府の「戦略17分野」でも情報通信の先行検討技術としてオール光ネットワーク（APN）が挙げられている。
ただし **商用としての収益はまだこれから**で、現時点では研究開発と実証が中心である点は押さえておきたい。

> なぜNTTが光にこだわるのか：
> AIデータセンターの制約が「電力」である以上、**消費電力を桁で下げる技術は事業の生命線**になる。
> IOWNは技術ロマンではなく、DC事業の原価低減策として読むと腑に落ちる。

## 7. 法人事業の収益構造

```
【法人事業の売上の組み立て】

  ストック収益（毎月入る）              フロー収益（都度入る）
  ─────────────────────            ────────────────────
  回線・専用線・VPN                     ネットワーク構築（SI）
  DCのラック・電力                      機器販売
  クラウド・GPU利用料                   コンサル・移行作業
  運用監視・保守（マネージド）
       ▲ 利益の安定性はここ              ▲ 波が大きく、人手が要る
```

| 指標               | 個人向け通信           | 法人向け                     | 備考                                                              |
| ------------------ | ---------------------- | ---------------------------- | ----------------------------------------------------------------- |
| 営業利益率の目安   | 高い（15〜20%超）      | 中（一桁後半〜十数%）        | SI・機器販売が混ざると下がる                                      |
| 収益の見通しやすさ | 高い                   | 高い（複数年契約）           | 解約率は極めて低い                                                |
| 必要な人員         | 少ない（無人化が進む） | **多い**（提案・構築・運用） | [SIer・ITサービス](../05_SIer・ITサービス/README.md) と競合・協業 |
| 成長率             | 横ばい                 | DX・AIで伸長                 | 各社が「非通信」に含めて開示                                      |

キャリアの法人事業は、しばしば **SIerと競合する**。
NTTデータ、KDDI（ミライト・ワンやAWSとの協業）、ソフトバンク（SB C&S、SB Technology）など、
グループ内にSI機能を抱えて「回線＋クラウド＋運用」を一括で売る形が定着した。
逆に言えば、**回線単体では差がつかなくなった**ことの裏返しでもある。

## 8. 用語メモ

| 用語                           | 意味                                                            |
| ------------------------------ | --------------------------------------------------------------- |
| **専用線／IP-VPN／広域イーサ** | 拠点間接続の形態。占有／閉域IP網／LAN的接続の順に安くなる       |
| **SLA**                        | 可用性・遅延などを数値で約束する契約。守れなければ返金          |
| **SD-WAN**                     | 複数回線をソフトで束ね、経路を自動で選ぶ仕組み                  |
| **コロケーション／ハウジング** | DCのラックと電源と回線を貸すサービス                            |
| **kW／MW課金**                 | DCの課金単位。AI時代は面積でなく電力で値段が決まる              |
| **ハイパースケーラー**         | 巨大クラウド事業者（AWS、Azure、Google Cloud 等）               |
| **LPWA／LTE-M／NB-IoT**        | 低速・低消費電力・広域の無線方式。電池で年単位稼働を狙う        |
| **eSIM／iSIM**                 | 組み込み型SIM。出荷後に回線事業者を書き換えられる               |
| **5G SA／NSA**                 | 5G専用コアを使う方式／コアが4Gのままの方式                      |
| **ネットワークスライシング**   | 物理網を用途別に仮想分割し、品質を保証して売る技術              |
| **ローカル5G**                 | 企業・自治体が自ら免許を取り、自分の敷地内で運用する5G          |
| **プライベート5G**             | キャリア網の一部を企業向けに専有させる形態                      |
| **IOWN／APN**                  | NTT主導の光中心ネットワーク構想／その中核となる全光ネットワーク |
| **AIOWN**                      | NTTが2026年4月に発表したAI基盤の呼称（報道・発表ベース）        |
