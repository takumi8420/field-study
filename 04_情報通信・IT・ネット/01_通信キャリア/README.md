## 1. 業界の定義・範囲

**通信キャリア**＝電気通信事業法に基づき、自ら電気通信回線設備を設置して
電気通信役務（通信サービス）を提供する事業者。日常語では「携帯会社」を指すことが多いが、
産業としては移動体（モバイル）と固定（光・電話）の両方を含む。

```
【通信キャリアの守備範囲】

 ┌──────────────────────────────────────────────────────┐
 │ 移動体：携帯電話（MNO）、サブブランド、MVNO、IoT回線          │
 │ 固定  ：光ファイバ（FTTH）、固定電話、専用線、IP-VPN          │
 │ 国際  ：海底ケーブル、国際専用線、陸揚局                      │
 │ 法人  ：ネットワーク構築、データセンター、クラウド、AI基盤     │
 │ 非通信：決済、金融、EC、広告、電力、コンテンツ（＝経済圏）     │
 └──────────────────────────────────────────────────────┘
      ▲ 「通信会社」と呼ばれるが、利益の伸びは右2つが作っている（→ ⑤直近トピック）
```

境界の引き方：

- **設備を持たずに回線を借りて売る事業者（MVNO）** も電気通信事業者だが、経済構造が別物なので
  [① 通信インフラの仕組み](01_通信インフラの仕組み.md) 第9章で分けて扱う
- **CATV事業者**は放送が本業なので [ケーブルテレビ](../../14_メディア・広告・エンタメ/06_ケーブルテレビ/README.md) 側
- **クラウド／SaaSそのもの**は [クラウド・IaaS](../04_クラウド・IaaS/README.md)、[ソフトウェア・SaaS](../06_ソフトウェア・SaaS/README.md)
- **端末メーカー**は [PC・スマートフォン](../../03_電機・電子部品/11_PC・スマートフォン/README.md)

**成長性の見立て**：国内の個人向け通信は **ほぼ成熟**。人口減で契約数の伸びしろは小さく、
料金も規制・政治圧力で上げにくい。成長は① 非通信（金融・決済・コマース）、
② 法人・データセンター・AI基盤、③ IoT回線、の3方向に限られる。
**「通信で稼ぎ、他で伸ばす」産業**と理解するのが実態に近い。

## 3. バリューチェーン（川上 → 川下）

```
 装置・部材 ──▶ ネットワーク構築 ──▶ キャリア（本ノート）──▶ 販売 ──▶ 利用者
 基地局装置     エンジニアリング会社    設備を保有・運用        代理店     個人・法人
 光ファイバ     工事・鉄塔・電源        周波数免許を持つ        量販店
 交換機・ルータ                        課金・認証・サポート    オンライン
 サーバ/GPU                            └─▶ 卸（MVNO・光コラボ）
   ▲ 需要はキャリアの     ▲ 労働集約・        ▲ 付加価値と利益が     ▲ 手数料商売
     設備投資額で決まる     受注産業             集中するのはここ        値引き規制の影響大
```

- 付加価値が集まるのは **キャリア本体**。周波数免許と全国設備という参入障壁が利益を守っている
- ただし近年、価値の一部が **上流（GPU・光部品）と下流（決済・金融）** へ染み出している。
  上流はAI需要で装置価格が上がり、下流は経済圏として新たな収益源になった
- 卸（MVNO・光コラボ）は **利益率が薄い**。接続料・卸価格がキャリア側に決定権があるため

## 5. 収益モデル・コスト構造

```
 利益 ＝ ARPU（1契約あたり月額収入）× 契約数 × 12
       ＋ 非通信収入（決済手数料・金融・コマース・法人）
       －（減価償却 ＋ ネットワーク運用 ＋ 販売促進 ＋ 人件費 ＋ 接続料）
                  ▲ 費用の7割前後が「契約が減っても減らない固定費」
```

| 論点               | 中身                                                                                                      |
| ------------------ | --------------------------------------------------------------------------------------------------------- |
| ARPU               | ドコモ4,100円／KDDI 4,440円（2026年3月期、各社開示。定義が異なる点に注意）。楽天は2,000円台               |
| 解約率             | 国内MNOは月0.5〜1.0%台と低水準。1÷解約率が平均継続月数＝LTVの基礎                                         |
| 固定費の重さ       | 設備投資は先、収入は後。**投資を増やした年は必ず利益が落ちる**（ドコモの2026年3月期が典型）               |
| 償却・回収         | 無線設備6〜10年、局舎・管路20〜30年。新世代投資の回収はおおむね7〜10年                                    |
| 売上高設備投資比率 | 概ね10〜15%                                                                                               |
| 営業利益率         | 3社とも **15〜19%**。日本の大企業として非常に高く、インフラ独占性の裏返し                                 |
| 非通信の寄与       | ドコモ スマートライフ3,027億円／KDDI 金融432億円／SB ファイナンス863億円（いずれも2026年3月期の営業利益） |

## 6. 競争要因（KSF）と参入障壁

**KSF（成功の鍵）**

1. **周波数ポートフォリオ**：特にプラチナバンド（700〜900MHz）を持つか。1局のカバー面積が数倍違う
2. **基地局数とエリア品質**：金だけでは短縮できない。建設に物理的な年数がかかる
3. **解約率の低さ**：固定セット割・家族割・ポイントで積み上げる。ARPUより利益インパクトが大きい
4. **経済圏の厚み**：決済・金融・ECを束ねてスイッチングコストを人為的に高める
5. **法人・データセンターという第2の柱**：規制・政治の圧力がかかりにくい成長領域
6. **規制対応力**：制度設計そのものが競争条件なので、審議会での主張が事業に直結する

**参入障壁**

| 障壁                 | 強さ     | 理由                                                          |
| -------------------- | -------- | ------------------------------------------------------------- |
| **周波数免許**       | 極めて強 | 国が配らない限り参入不能。金を積んでも買えない                |
| **設備投資の絶対額** | 極めて強 | 全国網に数兆円。楽天も累計兆円規模を投じた                    |
| エリア構築の時間     | 強       | 用地交渉・電源・工事。年単位でしか進まない                    |
| 経済圏               | 中〜強   | ポイント原資を用意し続ける体力が要る                          |
| ブランド・販売網     | 中       | オンライン専用ブランドで一部代替可能                          |
| MVNOとしての参入     | 弱       | 接続料を払えば誰でも参入可。だから250社あり、だから儲からない |

## 7. 規制・法制度

| 法律・制度                    | 内容                                                                                                                                               |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **電波法**                    | 周波数は免許制。日本は**比較審査**（事業計画を審査して割当）が主流でオークションは未導入。電波利用料は年約750億円規模（2024年度）                  |
| **再割当**                    | 2023年に700MHz帯を楽天モバイルへ割当。後発の弱点を行政が補正した例                                                                                 |
| **電気通信事業法**            | 事業の登録・届出、**接続義務**、利用者保護。携帯料金は**認可制ではなく届出制**（法的には自由価格）                                                 |
| **指定電気通信設備制度**      | NTT東西の加入者アクセス回線などボトルネック設備に接続義務・約款認可・会計分離を課す                                                                |
| **接続料規制**                | データ接続料（MVNO向け）、音声接続料、固定アクセス接続料。総務省が毎年検証し低廉化を促す                                                           |
| **27条の3（端末値引き規制）** | 端末購入を条件とする利益提供は上限**4万円（税抜）**。2023年12月から白ロム割も規制対象。**2026年に見直し議論が本格化**                              |
| **分離プラン**                | 2019年10月から通信料と端末代の完全分離を義務化。違約金も1,000円上限に                                                                              |
| **NTT法**                     | 政府の株式保有、外資規制、ユニバーサルサービス責務、NTT東西の構造規制。**2024年4月の改正で研究成果の開示義務を撤廃**、附則に廃止を含めた検討を明記 |
| **ユニバーサルサービス**      | 2023年からブロードバンドも対象に。交付金を利用者全体で負担。モバイル網での代替を認める方向で議論中                                                 |
| **MNP／eSIM**                 | 2023年からMNPワンストップ方式。乗り換えの摩擦を行政が意図的に下げている                                                                            |
| **外部送信規律**              | 2023年施行。利用者情報の外部送信に通知・公表義務                                                                                                   |
| **経済安全保障推進法**        | 基幹インフラの重要設備導入時に事前審査。基地局・コア設備の調達先が国の審査対象                                                                     |

詳細は [③ 競争と規制](03_競争と規制.md)。

## 8. 最近のトピック

詳細と出典は [⑤ 直近トピック（2026年9月時点）](05_直近トピック_2026.md)。要点だけ挙げると:

- **2026年3月期は3社とも増収。利益はKDDI・ソフトバンクが増益、ドコモのみ減益**。
  ドコモは設備投資を8,575億円（+20.0%）へ前倒しした「先行投資の年」。利益を伸ばしたのは金融・決済などの非通信
- **楽天モバイルが1,000万契約突破＆2025年度にEBITDA黒字化（+129億円）**。
  ただし**KDDIとのローミング提供期間が2026年9月30日に満了**予定で、ここが次の正念場と指摘される
- **AIデータセンター投資が競争の主戦場に**。NTTは「AIOWN」でDC容量を2033年度に約1GWへ、
  AI関連にグローバル5年で2兆円。KDDIは堺に5,000億円規模のAI DC。制約条件は用地ではなく**電力**
- **衛星ダイレクト通信が4社そろう**。au Starlink Direct（2025年4月）を先頭に、ドコモ・ソフトバンクが
  2026年4月に提供開始と報じられ、楽天はAST SpaceMobileで2026年度Q4のブロードバンド商用化を目指す
- **端末値引き規制（27条の3）の見直し議論が本格化**。2025年12月に総務省が専門委員会を設置。
  緩和されれば値引き競争の再燃が予想される
- **NTT法は「外資規制維持・構造規制維持強化・ユニバーサルサービス拡大」の方向**で継続審議
- **ドコモの3G（FOMA／iモード）が2026年3月末に終了予定**。周波数を4G/5Gへ転用する最終局面
