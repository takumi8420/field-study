# ① 通信インフラの仕組み

このノートで分かること：スマホの電波がどこを通ってインターネットに届くのか、
そして **その道具立て（基地局・光ファイバ・周波数）が、なぜ通信キャリアを「巨大な装置産業」にするのか**。

> 結論を先に：通信キャリアの正体は **「免許で守られた土地（周波数）の上に、
> 1兆円規模の設備を毎年積み増して、10年かけて回収する不動産業」** に近い。
> 電話やスマホは、その設備を使わせるための窓口にすぎない。

## 1. 全体像：端末からインターネットまで

```
【モバイルの通信経路】

 スマホ ))))) 基地局 ─── 光ファイバ ─── コアネットワーク ─── インターネット
  (UE)   電波   (RAN)     (バックホール)      (EPC / 5GC)        (IX・海底ケーブル)
         ▲              ▲                  ▲                 ▲
    免許が要る      掘る／借りる        誰の回線か判定      海外へ出る
    有限で高価      地味に最大の費用     課金・認証         国際接続
```

つまり「無線」と呼ばれる区間は、**端末と基地局の間の数百メートルだけ**。
その先は基地局まで敷いた光ファイバを通る、完全な有線ネットワークである。

| 区間           | 呼び名                  | 何があるか                       | 費用の性格                        |
| -------------- | ----------------------- | -------------------------------- | --------------------------------- |
| 端末〜基地局   | **無線アクセス（RAN）** | アンテナ、無線機、基地局装置     | 局数に比例。局数＝エリア品質      |
| 基地局〜集約局 | **バックホール**        | 光ファイバ、マイクロ波中継       | 土木・借用料。地味に重い          |
| 集約局〜中核   | **コア／バックボーン**  | 交換設備、ルータ、認証・課金     | 集中投資。1か所の障害が全国に波及 |
| 国内〜海外     | **国際・IX**            | 海底ケーブル、陸揚局、相互接続点 | 巨額・長寿命（20〜25年）          |

- **RAN（Radio Access Network）**＝無線アクセス網。基地局のかたまりのこと
- **バックホール**＝基地局を上位のネットワークへつなぐ回線。「裏側へ運ぶ」の意

## 2. 基地局：数がすべてを決める

基地局は用途で分かれる。エリアの「面」を作るのが**マクロセル**、
混雑地点の「点」を潰すのが**スモールセル**。

| 種類               | カバー範囲の目安 | 置き場所                     | 役割                             |
| ------------------ | ---------------- | ---------------------------- | -------------------------------- |
| マクロセル         | 半径 1〜10km     | 鉄塔、ビル屋上               | エリアの骨格。地方はほぼこれだけ |
| スモールセル       | 半径 数十〜数百m | 電柱、街灯、壁面             | 駅前・繁華街の容量対策           |
| 屋内基地局（IBS）  | 建物内           | 地下街、スタジアム、商業施設 | 「圏内なのに遅い」を解消         |

基地局の中身は近年3つに分解された。これが **Open RAN**（オープンラン）の前提になる。

```
【基地局の内部分解】

 従来型（一体）        分解後（C-RAN / Open RAN）
 ┌──────────┐        アンテナ＋RU ── 光 ── DU ── 光 ── CU
 │アンテナ    │        （鉄塔の上）        （局舎）    （データセンター）
 │無線機      │         RU: 無線信号を出す
 │信号処理    │         DU: リアルタイム処理（遅延にシビア）
 │制御        │         CU: 上位制御（集約できる＝局舎を減らせる）
 └──────────┘
   ▲ 1社の装置で丸ごと      ▲ 装置を別ベンダーで混ぜられる＝調達コストを下げられる
```

- **Open RAN**＝基地局の内部インタフェースを標準化し、複数メーカーの装置を組み合わせられるようにする考え方。
  楽天モバイルが全面採用して有名になった。装置は [通信機器](../02_通信機器/README.md) 業界の領域
- **仮想化（vRAN）**＝DU/CU の処理を専用機ではなく汎用サーバ上のソフトで行う。
  設備が [データセンター](../03_データセンター/README.md) 側に寄っていく流れ

> ポイント：**エリア品質の正体は「基地局の数」**。技術ではなく、どれだけ土地を借り、
> 電源を引き、光を敷いたかという土木の話。だから後発は追いつくのに時間と金がかかる。

## 3. 周波数＝免許制で有限な「土地」

電波は国の資源で、**総務大臣の免許がないと使えない**（電波法）。
つまり通信キャリアは、国から割り当てられた周波数という「土地」の上でしか商売できない。

周波数には、物理法則から来る明快なトレードオフがある。

```
【周波数の性質】

 低い（700MHz〜1GHz）                       高い（3.7GHz / 28GHz）
 ┌─────────────────────────────────────────────────┐
 │ 届く・回り込む・建物を透過する  ←→  速い（帯域幅が広く取れる）│
 │ でも帯域が狭い＝速度は出ない    ←→  でも飛ばない・遮られる    │
 └─────────────────────────────────────────────────┘
   ▲「プラチナバンド」と呼ばれる理由           ▲ 都市のピンポイント用
```

| 帯域             | 通称                     | 特徴                                          | 使いどころ           |
| ---------------- | ------------------------ | --------------------------------------------- | -------------------- |
| 700／800／900MHz | **プラチナバンド**       | 屋内・地下・山間に届く。1局で広くカバーできる | 全国エリアの土台     |
| 1.5／1.7／2.1GHz | ミッドバンド             | バランス型                                    | 4Gの主力             |
| 3.4〜4.1GHz      | **Sub6**（サブシックス） | 5Gの主力。速度と到達の妥協点                  | 都市部の5G           |
| 28GHz帯          | **ミリ波**               | 数Gbps出るが数百mで減衰                       | スタジアム、駅、工場 |

- 「プラチナ」と呼ぶのは希少で価値が高いから。**同じ1局でカバーできる面積が数倍違う**ため、
  低い帯域を持たない事業者は基地局を何倍も建てなければ同じエリアを作れない
- 日本は周波数オークション（競売）を採用せず、**比較審査**（総務省が計画を審査して割り当てる）が主流（→ [③ 競争と規制](03_競争と規制.md)）
- 楽天モバイルは2021年の参入時にプラチナバンドを持たず、2023年に700MHz帯の一部（各3MHz幅）を獲得、
  2024年6月から運用を開始した。**「後発はまず土地がない」という構造の実例**

## 4. コアネットワーク：誰の回線かを判定する頭脳

基地局が「入口」なら、コアは「誰が使っているか」を見分けて通す・課金する中枢。

| 世代      | コアの呼び名                 | 中身の変化                                                         |
| --------- | ---------------------------- | ------------------------------------------------------------------ |
| 2G／3G    | 回線交換＋パケット交換の併存 | 通話は専用の回線を占有                                             |
| 4G（LTE） | **EPC**                      | すべてIPパケット化。通話もVoLTEでデータの一種に                    |
| 5G NSA    | EPC を流用                   | 電波だけ5G、頭脳は4Gのまま（**ノンスタンドアロン**）               |
| 5G SA     | **5GC**                      | 5G専用コア。低遅延・スライシングが本来使える（**スタンドアロン**） |

- **ネットワークスライシング**＝1本の物理ネットワークを、用途別に仮想的に切り分ける技術。
  「工場のロボット用に遅延を保証した帯域」といった売り方ができる。5G SA が前提
- 日本の5G基地局は2025年3月末で約30.7万局、うち **SA方式に対応するのは15.6万局**（総務省）。
  つまり「5G」と表示されていても中身は NSA のことがまだ多い

## 5. 固定通信：光ファイバと局舎

モバイルばかり注目されるが、**光ファイバ網は通信キャリアの最大の資産**である。
日本の固定ブロードバンドはほぼ FTTH（光ファイバを家まで引く方式）に置き換わった。

```
【固定アクセスの構造】

 局舎(NTT東西) ── 光ファイバ ── クロージャ ── 電柱 ── 各家庭のONU ── ルータ
   ▲ 全国約7,000局規模           ▲ 1本を分岐して複数世帯で共用（GE-PON）
   │
   └─ ここが「指定電気通信設備」。他社に開放する義務がある（→ ③競争と規制）
```

- **NTT東日本・西日本が持つ加入者アクセス回線は、事実上の独占設備**。
  だから法律で「他社に接続料で貸す」ことを義務づけている（接続義務）
- 光コラボレーション（2015年〜）：NTT東西が光回線を卸し、ドコモ・ソフトバンク・楽天・ISPが
  自社ブランドで売る仕組み。**「ドコモ光」「ソフトバンク光」の中身はNTTの線**
- モバイルとセットで割り引く「固定モバイルセット割」は、解約率を下げる主要な武器（→ [② 儲け方の構造](02_儲け方の構造.md)）
- メタル（銅線）の固定電話は2023年度末で **1,353万契約**とピークの4分の1以下。維持の赤字が制度見直しの発端（→ [③ 競争と規制](03_競争と規制.md)）

## 6. 海底ケーブルと国際通信

国際通信の 99% 以上は海底ケーブルを通る（衛星ではない）。

| 論点       | 内容                                                                                                               |
| ---------- | ------------------------------------------------------------------------------------------------------------------ |
| 陸揚局     | ケーブルが上陸して陸上網につながる施設。日本は**千葉・三重に集中**してきた                                         |
| 集中リスク | 地震・工事・意図的な切断で国際通信が止まる。だから分散が国策に                                                     |
| 分散の動き | ソフトバンクが北海道・苫小牧と福岡・糸島に新設（2025年発表）。日本海側ルートも整備                                 |
| 新ケーブル | 「I-AM Cable」（2026年1月発表、住友商事・NTTデータ等）：千葉・三重・福岡の3拠点から東南アジアへ、設計容量約320Tbps |

> なぜ陸揚局が [データセンター](../03_データセンター/README.md) 立地とセットで語られるか：
> **国際回線の入口の近くにデータセンターを置くほど遅延と回線費が下がる**から。
> 日本の DC が千葉・印西や大阪に偏ってきた理由のひとつ。

## 7. 世代交代：3G→5G、そして次へ

| 世代                  | 商用化（日本）       | 特徴                             | 停波                                                             |
| --------------------- | -------------------- | -------------------------------- | ---------------------------------------------------------------- |
| 3G（W-CDMA/CDMA2000） | 2001年               | データ通信の普及、iモード        | **au 2022年3月／ソフトバンク 2024年1月／ドコモ 2026年3月末予定** |
| 4G（LTE）             | 2010年               | 動画が当たり前に。全面IP化       | 2030年代想定                                                     |
| 5G                    | 2020年               | 高速・低遅延・多接続。SA化が課題 | —                                                                |

世代交代は「速くなる」話に見えて、経営上は **「古い設備を畳んで周波数を新しい世代に付け替える作業」**。
3Gを止めれば周波数を4G/5Gに転用でき維持費も消えるが、古い端末や産業用機器の移行コストが発生する。

## 8. 設備投資の規模と回収年数

ここが **インフラ型ビジネスの核心**。

| 年度               | 国内モバイル設備投資 合計                 | 内訳の目安                                      |
| ------------------ | ----------------------------------------- | ----------------------------------------------- |
| 2024年度（実績）   | **約1兆3,260億円**                        | ドコモ5,552／KDDI 3,834／SB 2,618／楽天930 ほか |
| 2025年度（見通し） | **約1兆3,830億円**                        | ドコモ6,823／KDDI 3,140／SB 2,812／楽天742      |
| 2026年度（見通し） | **約1兆5,000億円規模**（前年度比約11%増） | ドコモ6,640／SB 3,350／KDDI 3,100／楽天2,000    |

（出典：MCA調べ、ケータイWatch連載。モバイル分のみ。固定・DC投資は別）

```
【設備投資の回収イメージ】

 投資年   1年目 ─────────────────────────────▶ 10年目
 支出   ██████ 基地局建設・工事費（先に全部出ていく）
 償却     ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░ 定額で毎年費用化（6〜10年程度）
 収入        ▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒ 月額料金で少しずつ回収
                  ▲ ここで契約者が減ると、費用だけ残って一気に赤字
```

| 項目               | 目安                                                  | なぜそうなるか                                           |
| ------------------ | ----------------------------------------------------- | -------------------------------------------------------- |
| 償却年数           | 無線設備 概ね6〜10年、局舎・鉄塔・管路は **20〜30年** | 土木資産は寿命が長い。だから一度敷けば強い               |
| 回収年数           | 新世代への投資は **おおむね7〜10年で回収**と語られる  | 1世代（約10年）で回収し、次世代投資に入るサイクル        |
| 投資の性格         | 需要が来る前に建てる（**先行投資**）                  | エリアがないと契約が取れないので、順序が逆にできない     |
| 売上高設備投資比率 | 国内キャリアで概ね **10〜15%**                        | この比率が上がると営業利益とフリーキャッシュフローを直撃 |

> なぜ通信が「実質的な装置産業」なのか：
> **売上が1円増えても追加費用はほぼゼロ、契約が1件減っても設備費は1円も減らない**。
> 固定費の塊なので、契約数がわずかに動くだけで利益が大きく振れる（オペレーティングレバレッジ）。
> 詳しくは [② 儲け方の構造](02_儲け方の構造.md)。

## 9. MNOとMVNO：設備を持つ者と借りる者

| 区分             | 正式名               | 設備               | 周波数免許 | 例                                       |
| ---------------- | -------------------- | ------------------ | ---------- | ---------------------------------------- |
| **MNO**          | 移動体通信事業者     | 自前で持つ         | 持つ       | ドコモ、KDDI、ソフトバンク、楽天モバイル |
| **MVNO**         | 仮想移動体通信事業者 | 持たない（借りる） | 持たない   | IIJmio、mineo、日本通信 など             |
| **MVNE**         | MVNO支援事業者       | 一部持つ           | 持たない   | MVNOに接続・課金基盤を提供する中間事業者 |
| **サブブランド** | —                    | MNO本体の設備      | 本体の免許 | UQ mobile（KDDI）、ワイモバイル（SB）    |

```
【MVNOの原価構造】

 利用者 ──料金──▶ MVNO ──接続料（データ量課金）──▶ MNOの設備
                     │                                  ▲
                     └─ 自社は課金・サポート・SIM発行だけ  │
                        設備投資がほぼゼロ＝身軽            │
                        でも原価（接続料）は相手が決める ───┘
```

- MVNOの生死は **データ接続料（1Mbps あたりいくら、で決まる卸価格）** に握られている。
  総務省が毎年検証して低廉化を促しているのはこのため（→ [③ 競争と規制](03_競争と規制.md)）
- MVNOの契約数は2025年9月時点で全体の **約18%**、ただし個人向けに限ると **10.5% で頭打ち**とされる
  （テレコムサービス協会MVNO委員会・総務省資料ベース）。
  理由は単純で、**MNO自身がサブブランドと格安プランで同じ価格帯に降りてきたから**
- サブブランドは「MVNOに見えるがMNO本体」。品質は同じで価格だけ下げられるため、MVNOは差をつけにくい

## 10. 用語メモ

| 用語                           | 意味                                                                 |
| ------------------------------ | -------------------------------------------------------------------- |
| **RAN／Open RAN**              | 無線アクセス網／その内部を標準化して複数ベンダー混在を可能にする方式 |
| **バックホール**               | 基地局を上位網につなぐ回線。実体は光ファイバ                         |
| **プラチナバンド**             | 700〜900MHz帯。よく届くので1局あたりのカバー面積が大きい             |
| **Sub6／ミリ波**               | 3.7GHz前後／28GHz帯。5Gの周波数。後者は速いが飛ばない                |
| **EPC／5GC**                   | 4G／5Gのコアネットワーク（認証・課金・経路制御の中枢）               |
| **NSA／SA**                    | 5Gの導入方式。コアが4Gのまま／5G専用コアを使う                       |
| **ネットワークスライシング**   | 1本の物理網を用途別に仮想分割して品質を保証する技術                  |
| **FTTH／ONU**                  | 光を家まで引く方式／宅内で光と電気信号を変換する装置                 |
| **光コラボレーション**         | NTT東西が光回線を卸し、他社が自社ブランドで販売する制度              |
| **陸揚局**                     | 海底ケーブルが上陸して陸上網に接続する施設                           |
| **MNO／MVNO／MVNE**            | 設備を持つ事業者／借りる事業者／MVNOを支援する事業者                 |
