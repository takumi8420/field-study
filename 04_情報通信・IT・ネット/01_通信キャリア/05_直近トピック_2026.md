# ⑤ 直近トピック（2026年9月時点）

報道・各社発表ベースの整理。数値は発表時点のもので、確定値・計画値・推計が混在する。
一次情報（各社IR、総務省資料）で裏を取ってから使うこと。

> この1年の構図をひと言で：**「通信で稼ぎ、AIに注ぎ込む」年**になった。
> 個人向け通信はほぼ横ばい、利益を押し上げたのは金融・決済などの非通信。
> そしてその利益は、AIデータセンターという次の巨大設備投資へ回っている。

## 1. 2026年3月期決算：主役は「非通信」と「AI」へ

通信3社はそろって増収。ただし利益は明暗が分かれた。

| 会社         | 売上高                | 営業利益                  | 非通信の動き                                            |
| ------------ | --------------------- | ------------------------- | ------------------------------------------------------- |
| NTTドコモ    | 6兆4,581億円（+3.9%） | **9,421億円（▲7.7%）**    | スマートライフ事業 営業利益 3,027億円（+29.6%）         |
| KDDI         | 6兆719億円（+4.1%）   | **1兆1,643億円（+6.0%）** | 金融セグメント 営業利益 432億円（前期195億円の約2.2倍） |
| ソフトバンク | 7兆387億円（+8%）     | **1兆426億円（+5%）**     | ファイナンス事業 営業利益 863億円（+107%）              |

ドコモだけが減益になった理由ははっきりしている。**設備投資を8,575億円（前期比+20.0%）へ前倒しし、
販促費も積んだ**ため。通信品質と顧客基盤の立て直しを優先した「先行投資の年」だったと報じられる。

```
【この決算の読み方】

  通信収入   ──── ほぼ横ばい（ARPUは微増、契約数も微増）
  非通信収入 ────▲ ここが全社の増益要因（金融・決済・コマース）
  設備投資   ────▼ ここが利益を食う（前倒しすると当期が減益になる）

  → 「通信の会社」ではなく「通信という顧客接点を持つ金融・IT複合体」の決算になった
```

モバイル契約数は2026年3月末で主要4社合計 **約2億3,312万件**。
四半期純増はドコモ+86.1万（首位）、au+70.6万、楽天+35.0万、ソフトバンク+32.7万。
**ドコモが純増首位に戻った**のは、品質改善と販促の効果が出たためとみられる。

## 2. 楽天モバイル：1,000万契約とEBITDA黒字化、そして「2026年9月末」

- 2025年末に **契約1,000万回線を突破**（2026年3月末で約1,036万）
- **2025年度通期のEBITDAが+129億円で黒字化**。MNO本格参入後、初の通期黒字化を達成したと発表
- 2026年度の設備投資は **2,000億円規模へ大幅増額**（2025年度見通しは742億円）。都市部の品質強化に充てる

```
【楽天モバイルの損益が黒字に近づく仕組み】

   収入 ＝ ARPU（約2,000円台）× 契約数（1,000万超）
   費用 ＝ 自社設備の償却  ＋  KDDIへのローミング費用
                                  ▲ 自社エリアが広がるほど減る
                                  ▲ ここが最大のコスト削減余地だった
   → 「自社エリアを広げる ＝ 他社に払う金が減る」という構造で黒字に近づいた
```

そのうえで、**2026年9月30日にKDDIとのパートナー回線（ローミング）の提供期間が満了**する予定とされる。
これが次の正念場と指摘されてきた。自社エリアで穴が残る地域では、
ローミングが切れた瞬間に品質低下が顕在化するおそれがあるためである。
（各社の対応・延長の有無は最新の公式発表で確認が必要）

## 3. AIデータセンター投資競争

利益の使い道が、基地局からAIデータセンターへはっきり移った。

| 会社         | 内容                                                                                               | 規模（発表・報道ベース）            |
| ------------ | -------------------------------------------------------------------------------------------------- | ----------------------------------- |
| NTT          | NTT3社が新AI基盤「**AIOWN**」を共同発表（2026年4月）。国内DC容量を約300MWから**2033年度に約1GW**へ | AI関連にグローバルで5年間 **2兆円** |
| KDDI         | 大阪・堺に**AIデータセンター**を2025年12月に正式オープン。NVIDIAと直接連携                         | **5,000億円**規模と報じられる       |
| ソフトバンク | AI DC・GPUクラウドに加え、**電力・蓄電**まで事業領域を拡大                                         | 成長投資の柱に位置づけ              |

- 1GWは「原発1基分」に相当する電力規模。**DC事業の制約はもはや土地ではなく電力**である
- 国内のAI供給網投資は過去最高を更新し、電力網・半導体工場へ連鎖しているとの分析もある
- 投資家からは「高配当の通信株が成長株化するのか」という論点で見られており、
  **AI投資が回収できるかが2026年以降の株価の分岐点**と報じられる

```
【投資の性格が変わった】

  〜2020年代前半          2020年代後半
  基地局への投資          データセンター・GPUへの投資
  回収期間 7〜10年        GPUの陳腐化は 3〜5年（！）
  需要は確実（全員が使う） 需要はAI市況次第
       ▲ 「長期で確実に回収」から「短期で陳腐化するが単価は高い」へ
       ▲ 装置産業の作法は同じだが、リスクの質が変わった点に注意
```

## 4. 衛星ダイレクト通信：4社が出そろう

スマホが **基地局なしで直接衛星につながる**サービスが、2026年に4社そろった。

| 事業者       | サービス                    | パートナー          | 状況（2026年時点）                                            |
| ------------ | --------------------------- | ------------------- | ------------------------------------------------------------- |
| KDDI（au）   | **au Starlink Direct**      | SpaceX（Starlink）  | 2025年4月開始（当初SMS/RCS）→ 2025年8月にデータ通信対応       |
| ソフトバンク | 衛星直接通信                | Starlink 等         | 2026年4月に提供開始と報じられる                               |
| NTTドコモ    | 衛星直接通信                | 同上                | 2026年4月に提供開始と報じられる                               |
| 楽天モバイル | **Rakuten最強衛星サービス** | **AST SpaceMobile** | 2026年度第4四半期の商用化を目標。**当初からデータ通信**を狙う |

- 技術的な違い：Starlink系は既存の小型衛星を使うため **テキスト・低速データ中心**。
  AST SpaceMobile は大型アンテナ衛星で **ブロードバンド（動画・通話）** を狙う設計
- 事業上の意味：① 山間・海上・災害時の「圏外ゼロ」という訴求、
  ② 楽天にとっては **KDDIローミング依存からの脱却手段**、
  ③ いずれも当面は無料または低価格で提供され、**直接の収益源というより解約防止の道具**
- 詳しくは [宇宙・衛星](../../01_注目テーマ/07_宇宙・衛星/README.md)

## 5. 端末値引き規制（27条の3）の見直し議論

2026年に通信業界で最も注目される制度論点の一つ。

| 経緯       | 内容                                                                           |
| ---------- | ------------------------------------------------------------------------------ |
| 2019年10月 | 分離プラン義務化、端末値引き上限2万円（税抜）、違約金1,000円上限               |
| 2023年12月 | 上限4万円（税抜）へ。回線契約なしの端末単体値引き（白ロム割）も規制対象に      |
| 2025年12月 | 総務省が「**利用者視点を踏まえたモバイル市場の検証に関する専門委員会**」を設置 |
| 2026年     | **27条の3の見直し議論が本格化**。規制緩和の可能性が報じられる                  |

背景は端末価格の高騰である。円安でハイエンドスマホが20万円超の水準となった一方、
値引きは4万円までに抑えられているため、消費者の実負担が急増した。
さらにメモリ価格の上昇でスマホの原価自体が上がるとの見方もあり、
**「規制を緩和しても端末は安くならないかもしれない」**という難しい局面にある。

> 見どころ：緩和されれば、**ドコモと楽天を中心に値引き競争が再燃する**と予想されている。
> 一方で「実質0円」の復活は通信料への転嫁を招くため、どこで線を引くかが論点。
> 制度の詳細は [③ 競争と規制](03_競争と規制.md)。

## 6. NTT法とユニバーサルサービスの見直し（継続中）

2024年4月の改正NTT法（研究成果の開示義務を撤廃、附則に「廃止を含めた検討」を明記）を受け、
議論は第2幕に入っている。

| 論点                               | 2025年2月の情報通信審議会 最終答申が示した方向              |
| ---------------------------------- | ----------------------------------------------------------- |
| 外資規制                           | **維持**                                                    |
| NTT東西の構造規制（分離）          | **維持・強化**。競合183者が「現状維持」案に賛同と報じられた |
| ユニバーサルサービス責務           | **拡大**。モバイル網での代替を認める方向                    |
| 特別な資産（管路・とう道等）の保全 | 保全・保護の方向                                            |

- メタル固定電話は2023年度末で **1,353万契約**（ピークの4分の1以下）、維持の赤字は **年間300億円程度**とされる。
  「使われない設備をいつまで法律で維持させるか」という問題が制度論の核心にある
- 総務省ではワーキンググループで公正競争・外資規制・ユニバーサルサービスの3議題を継続審議中

## 8. 3G停波の最終局面

| 事業者                     | 3G停波                                  |
| -------------------------- | --------------------------------------- |
| au（KDDI）                 | 2022年3月終了                           |
| ソフトバンク               | 2024年1月終了                           |
| NTTドコモ（FOMA／iモード） | **2026年3月末に終了予定**（発表ベース） |

3Gを止めることで、その周波数を4G/5Gへ転用でき、老朽設備の維持費も消える。
一方で、3Gしか使えない端末を持つ高齢者層や、産業用機器（エレベーターの非常通報、自販機、
警備システムなど）の入れ替えが必要になる。**停波は技術の話ではなく、社会的な移行作業**である。

## 9. 全体の構図（まとめ）

```
【2026年の通信キャリアを貫く4本の線】

 ① 個人向け通信は成熟 ──▶ ARPUも契約数も微増どまり。規制と政治で値上げしづらい
 ② 利益は非通信が作る ──▶ 金融・決済・コマース。経済圏の囲い込みが解約率を下げる
 ③ 稼いだ金はAIへ     ──▶ DC・GPU・電力。回収期間が短く、リスクの質が変わった
 ④ 制度は動き続ける   ──▶ 端末値引き規制の緩和、NTT法、ユニバーサルサービスの再設計
```

1. **通信キャリアの決算は、もう通信の決算ではない**。金融・決済の伸びが利益を作っている
2. **投資の対象が基地局からデータセンターへ移った**。制約条件は用地ではなく電力になった
3. **楽天モバイルは黒字化という節目を越えたが、ローミング満了という次の試練が控える**
4. **衛星直接通信は4社そろい、競争軸が「圏外をなくす」へ広がった**（当面は収益より囲い込み）
5. **制度面は「緩和（端末値引き）」と「維持（NTT法の構造規制）」が同時進行**しており、
   どちらも各社の損益に直結する
