# SNSの収益と運営

このノートで分かること：**タダで使えるSNSがどこで金を稼ぎ、その裏で何にいくら払っているか**。
収益（広告・課金・EC）と、表に出にくいコスト（モデレーション＝コンテンツ監視）の両方を見る。

## 1. SNSの売上は「滞在時間 × 広告単価」でほぼ説明できる

SNS企業の売上は、乱暴に言えば次の掛け算に分解できる。

```
【SNSの売上の分解式】

  売上 ＝ 利用者数 × 1人あたり滞在時間 × 広告表示密度 × 広告単価
          ─────────  ───────────────    ──────────────   ────────
           集める力        習慣化の力        詰め込む力      売る力
           （① 経済学）    （推薦アルゴリズム）（ユーザー体験と  （ターゲティング
                                              のトレードオフ）  精度と競争環境）
```

前2つが「在庫（広告を出せる枠）の量」、後ろ2つが「在庫の単価」。
だからSNS企業は、他のSNSだけでなく**テレビ・ゲーム・動画・睡眠と可処分時間を奪い合っている**。
「滞在時間の奪い合い」と言われるのはこの式のせいである。

## 2. 収益の3本柱

| 収益源 | 中身 | 特徴 | 主にどこが強いか |
| --- | --- | --- | --- |
| **広告** | 表示・クリック・視聴に応じて広告主が払う | 圧倒的主力。売上の9割前後に達する会社もある | Meta、TikTok、X、LINEヤフー |
| **課金・投げ銭** | サブスク、スタンプ、ライブ配信のギフト（投げ銭） | 単価が高く、景気に左右されにくい | ライブ配信系、一部SNSの有料版 |
| **EC・決済連携** | 商品タグ、ライブコマース、送客手数料 | 広告と地続き。購買データが広告精度を上げる | TikTok Shop、Instagram、LINEヤフー |

日本の数字で規模感をつかむと、電通「2025年 日本の広告費」（2026年3月発表）では、
インターネット広告費が **4兆459億円**で総広告費（8兆623億円）の **50.2%** と初めて過半数を超え、
そのうち**ソーシャル広告は1兆3,067億円**（前年比118.7%）だった。
ソーシャル広告の内訳はSNS系5,508億円、動画共有系5,126億円、その他2,434億円。

> ポイント：**「ネット広告の半分近くは、SNSと動画共有の上で起きている」**。
> つまりSNSはメディア産業の中心的な収益装置になっている。
> 広告の入札・配信・計測の技術は [ネット広告](../07_ネット広告/README.md) に委譲する。

## 3. 世界最大手の構造をMetaで見る

報道ベースの数字だが、構造を理解するには分かりやすい。
Metaの2026年1〜3月期は売上高563億ドル（前年同期比＋33%）で、
うち**Family of Apps（Facebook・Instagram・WhatsApp等）の広告売上が550億ドル**。
つまり**売上の約98%が広告**である。

同時に、AIインフラ向けの設備投資（CapEx）を2026年通期で1,250〜1,450億ドルへ引き上げた。
一方でReality Labs（VR・スマートグラス部門）の売上は約4億ドルと小さい。

```
【Metaの損益のかたち（2026年1Qの報道値からの模式図）】

  売上 563億ドル
   ├─ 広告 550億ドル ─────────────────────── ほぼ全部これ
   └─ その他 13億ドル（Reality Labs 約4億ドルを含む）

  ここから出ていく主なもの
   ├─ データセンター・AI推論（設備投資は年1,250〜1,450億ドル計画）
   ├─ 研究開発（AI人材の獲得競争）
   ├─ モデレーション・安全対策（数万人規模の人的体制）
   └─ 訴訟・規制対応（EU・米国・各国）

  → 「広告という現金製造機で、AIとハードへの巨額投資を賄う」構図
```

数値はいずれも報道・各社発表ベース。最新は各社のIR資料で確認するのが確実。

## 4. アルゴリズムによる推薦：フォローから「おすすめ」へ

SNSの見え方は、2010年代の**フォローグラフ型**（自分がフォローした人の投稿が時系列で並ぶ）から、
2020年代の**推薦（レコメンド）型**（知らない人の投稿でも、面白そうなら流れてくる）へ移った。
TikTokの「おすすめ」欄が決定打で、各社がこれに追随した。

| 方式 | 何が流れるか | 経済的な意味 |
| --- | --- | --- |
| フォローグラフ型 | 自分が選んだ相手の投稿 | 人間関係が資産。新規参入者は不利、既存ユーザーは抜けにくい |
| 推薦型 | AIが「見そう」と判断した投稿 | **コンテンツの面白さ勝負**。無名でも当たる。ただし乗り換えられやすい |

```
【推薦型フィードの回り方】

   投稿が少数の人に試験配信される
            │
            ▼
   反応（視聴完了率・いいね・シェア・滞在）を計測
            │
      ┌─────┴─────┐
      ▼           ▼
  反応が良い    反応が悪い
      │           └─▶ 配信をやめる
      ▼
  より大きな集団へ拡大配信 ──▶ さらに計測 ──▶ 拡大…
```

この仕組みは、**「面白いものを最短で見つける装置」であると同時に
「刺激の強いものが伸びやすい装置」**でもある。この二面性が後述の社会的論点につながる。

推薦型への移行はビジネス面でも大きい。
フォロワーが少ない新人でも当たれば伸びるため、供給側（クリエイター）の参入が増え、
コンテンツ在庫が増える。在庫が増えると滞在時間が伸び、広告枠が増える。
式の左半分（利用者数×滞在時間）を押し上げる打ち手として合理的だった。

## 5. クリエイターエコノミーと収益分配

**クリエイターエコノミー**＝個人の発信者が、プラットフォーム経由で収入を得る経済圏。
矢野経済研究所などの調査では、**国内市場は2024年時点で約2兆894億円**、
2021年以降おおむね年率15%前後で伸びているとされる（調査会社の推計）。
世界市場は2026年に3,200億ドル規模という推計もあるが、定義により数字が大きくぶれるため、
**「どの範囲を含めた推計か」を必ず確認する**必要がある。

| 収益経路 | 誰が払うか | プラットフォームの取り分の目安 | 特徴 |
| --- | --- | --- | --- |
| 広告収益分配 | 広告主 | プラットフォーム側が3〜5割程度 | 再生数に比例。単価はジャンルと国で大差 |
| 投げ銭・ギフト | 視聴者 | 3〜5割程度（アプリストア手数料が別途乗る） | 単価が高い。上位1割に極端に集中する |
| サブスク（月額会員） | ファン | 1〜3割程度 | 安定収入。ファンの絶対数が必要 |
| 企業案件（タイアップ） | 広告主が直接 | **0%（プラットフォームを通らない）** | クリエイターの取り分が最大。だから人気が高い |
| アフィリエイト・EC | 販売者 | 数%〜 | 購買に直結。ライブコマースで伸びている |

> ポイント：クリエイター側から見ると、**プラットフォームを通さない企業案件が一番儲かる**。
> プラットフォームはこれを取り込むため、公式のタイアップ仲介機能を用意して手数料を得ようとする。
> 「クリエイターの囲い込み」と「取り分を取りすぎない」のバランスが、供給側の離脱を左右する。

収益分配は**供給側へのネットワーク効果の投資**でもある。
分配率を上げればクリエイターが集まり、コンテンツが増え、ユーザーが増える。
[① プラットフォームの経済学](01_プラットフォームの経済学.md) の「片面を金で買う」に当たる。

## 6. モデレーション：見えないが巨大なコスト

**モデレーション（moderation）**＝投稿の中身を監視し、規約違反を削除・制限する運用のこと。
一般ユーザーには見えないが、SNS運営における最大級の固定費であり、最大級のリスク源でもある。

```
【投稿がユーザーに届くまでの関門】

  投稿
   │
   ├─▶ ① AIによる自動検知（投稿前／投稿直後）
   │      児童性的虐待、テロ、明白なスパムはここでほぼ止まる
   │
   ├─▶ ② ユーザーからの通報
   │
   ├─▶ ③ 人間のレビュー（委託会社を含む、各国語・24時間体制）
   │      文脈依存の判断（皮肉か、脅迫か、報道か）はここでしか判断できない
   │
   ├─▶ ④ 異議申立て・再審査
   │
   └─▶ ⑤ 行政・裁判所からの削除要請への対応
          → 日本では情報流通プラットフォーム対処法（→ ③ 規制ノート）
```

モデレーションが難しい理由は3つある。

1. **量が桁違い**。1日に数十億件の投稿を、数千人〜数万人と機械で捌く。
2. **文脈に依存する**。同じ言葉が、罵倒にも引用にも報道にもなる。AIだけでは決着しない。
3. **どちらに倒しても批判される**。削除しすぎれば「検閲だ」、放置すれば「加害の放置だ」。

| 方針 | 削除を厳しくする | 削除を緩くする |
| --- | --- | --- |
| メリット | 被害の抑止、広告主が安心する（ブランドセーフティ） | 表現の自由、運用コストが軽い |
| デメリット | 過剰削除・言論の萎縮、運用コストが重い | 広告主の離脱、規制当局の介入、被害の拡大 |
| ありがちな批判 | 「基準が不透明」「政治的に偏っている」 | 「野放しだ」「利益優先だ」 |

> ここは**評価が割れる領域**なので、本ノートでは立場を取らず論点のみ整理する。
> 詳しくは [③ 規制と社会的論点](03_規制と社会的論点.md) を参照。

広告主にとってのリスク（**ブランドセーフティ**＝自社広告が不適切な投稿の横に出てしまうこと）は、
モデレーションと広告収益を直結させる。監視を緩めると広告主が引くため、
モデレーションは「コスト」であると同時に**広告単価を守るための投資**でもある。

## 7. 日本のSNS利用の実像

総務省「情報通信白書」系の調査によると、SNSの利用率は全年代平均で8割を超え、
10〜30代では9割を上回る。サービス別では**LINEが全年代で約9割**と突出し、
X・Instagramは全体の半数程度、TikTokは若年層に強く偏る、という形になっている
（令和6〜7年版 情報通信白書などに基づく。調査年で数値は動く）。

| 特徴 | 日本のSNS事情 |
| --- | --- |
| メッセージの1強 | LINEがほぼインフラ化。行政・企業の連絡手段にもなっている |
| 用途での棲み分け | 連絡＝LINE、拡散＝X、写真・購買＝Instagram、短尺＝TikTok、動画＝YouTube |
| 匿名志向 | 実名SNSより匿名・ハンドルネーム文化が強く、Xの利用が国際比較で厚い |
| 高い併用率 | マルチホーミングが常態。1人が4〜5サービスを併用する |

日本市場の独自性は、**メッセージ（LINE）と拡散（X）が別会社に分かれている**点にある。
欧米ではMetaがメッセージ（WhatsApp・Messenger）と拡散（Facebook・Instagram）の両方を握るが、
日本では分散しており、その分だけ広告在庫も分散している。

## 8. コスト構造と利益率

| 費用項目 | 性質 | 規模感 |
| --- | --- | --- |
| サーバ・帯域・AI推論 | 準変動費（利用量に比例） | 動画とAIの比重が上がって急増中 |
| 研究開発（AI人材含む） | 固定費 | 大手では売上の2〜3割規模 |
| モデレーション・安全 | 準固定費 | 数千〜数万人規模の体制。多言語対応が高くつく |
| 販売・マーケティング | 変動しやすい | 広告主向け営業と、ユーザー獲得広告 |
| 法務・規制対応・制裁金 | 不確実 | EU・米国で数億ユーロ単位の事例あり（→ ③） |

限界費用が低いので、規模が出れば営業利益率が高くなる（大手SNSで3〜4割に達する例もある）。
ただし**AI投資とモデレーションがこの利益率を削る方向に効く**のが近年の構図である。

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **滞在時間（エンゲージメント）** | 利用者がサービスに費やす時間。広告在庫の総量に直結する |
| **推薦（レコメンド）型フィード** | フォロー関係ではなくAIの予測で表示を決める方式。TikTok以降の主流 |
| **インプレッション** | 広告の表示回数。広告の売買単位のひとつ |
| **ARPU** | 利用者1人あたり売上。SNSではほぼ「1人あたり広告単価」 |
| **クリエイターエコノミー** | 個人の発信者がプラットフォーム経由で稼ぐ経済圏 |
| **投げ銭（ギフティング）** | 視聴者が配信者に有料アイテムを贈る仕組み。単価が高く上位に集中する |
| **モデレーション** | 投稿内容の監視・削除・制限の運用。AI＋人手の二層で行う |
| **ブランドセーフティ** | 自社広告が不適切な内容の隣に出ないようにすること。広告主側の要求 |
| **ライブコマース** | ライブ配信しながら商品を売る手法。SNSとECの接続点 |
| **フィルターバブル／エコーチェンバー** | 推薦により似た意見ばかりが目に入る状態。影響の大きさには学術的な論争がある |
