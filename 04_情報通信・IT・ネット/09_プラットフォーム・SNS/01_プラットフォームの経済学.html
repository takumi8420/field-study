プラットフォームの経済学

情報通信・IT・ネットプラットフォーム・SNS
あこのページの単語集用語に触れると意味を確認できます12語
プラットフォーム両面市場（two-sided market）ネットワーク効果クリティカルマスニワトリと卵の問題マルチホーミングスイッチングコストテイクレートGMVDAU／MAUARPUフライホイール

このノートで分かること：なぜプラットフォームは「無料」でユーザーを集め、なぜ一度勝つと
なかなか負けないのか。その裏にある両面市場・ネットワーク効果・クリティカルマスという
3つの仕組みを、式と図で分解する。

1. プラットフォームとは「自分で作らずに、出会わせて取る」商売

ふつうのメーカーは、材料を仕入れて製品を作り、売る。
プラットフォーム（Platform＝土台・場）は違う。自分では商品を作らず、
売りたい人と買いたい人を出会わせ、取引が成立したときに手数料を取る。

【メーカー型】  材料 ──▶ 自社で製造 ──▶ 販売 ──▶ 顧客
                        （在庫・工場を持つ）

【プラットフォーム型】
                 出品者・投稿者・開発者（＝供給側の面）
                            │
                            ▼
                 ┌──────────────────┐
                 │   プ ラ ッ ト フ ォ ー ム   │ ← ルール・決済・検索・推薦を提供
                 └──────────────────┘
                            ▲
                            │
                 利用者・視聴者・買い手（＝需要側の面）

   在庫を持たない／作らない。持つのは「ルール」と「ユーザーの数」

自社でコンテンツを作らないYouTube、自社で部屋を持たないAirbnb、
自社でアプリを作らないApp Store。いずれも同じ形をしている。

ポイント：プラットフォーム企業の資産は工場でも在庫でもなく、
「そこに人がいる」という事実そのもの。だから人の数を増やすことに全てを賭ける。

2. 両面市場：客が2種類いて、互いを必要としている

両面市場（two-sided market）＝性質の違う2グループの利用者がいて、
一方が増えるともう一方にとっての価値が上がる市場のこと。
「面（side）」とは、プラットフォームから見た客のグループのこと。

例 A面（供給側） B面（需要側） 主に課金する側 無料にする側
App Storeアプリ開発者スマホ利用者開発者（手数料）利用者（ストア利用は無料）
SNS投稿者・クリエイター閲覧ユーザー広告主（＝第3の面）両方とも無料
フリマアプリ出品者購入者出品者（販売手数料）購入者
検索エンジンWebサイト運営者検索する人広告主両方とも無料
クレジットカード加盟店カード会員加盟店（加盟店手数料）会員（年会費無料カード）
配車・デリバリードライバー・店舗注文する人店舗＋利用者の両方—

SNSは正確には三面市場である。ユーザー（閲覧者）・クリエイター（投稿者）・広告主の3つ。
ユーザーとクリエイターは無料で、広告主だけが払う。
この非対称が「SNSはタダなのに巨大企業になる」からくりの正体である。

3. ネットワーク効果：人が集まるほど価値が上がる

ネットワーク効果＝利用者が増えるほど、そのサービスの価値が上がる性質。
電話が1台しかなければ無価値で、100万台あれば必需品になるのと同じ理屈。
4つの型に分けて考えると混乱しない。

型 中身 効きやすい例 注意点
直接（同じ面の中）同じ側のユーザーが増えると価値が上がるLINE、電話、メッセンジャー最も強力。友達がいる限り抜けられない
間接（面をまたぐ）反対側が増えると価値が上がるアプリストア（アプリ多い→端末買う→開発者増える）両面を同時に育てる必要がある
データ由来使われるほど推薦・検索精度が上がる検索、レコメンド、地図逓減しやすい（一定量を超えると差が出ない）
負（マイナス）増えすぎると逆に価値が下がる広告だらけのSNS、スパム、混雑実はこれが崩壊の引き金になる
【間接ネットワーク効果のループ（アプリストアの例）】

    端末ユーザーが増える
            │
            ▼
   開発者にとって儲かる市場になる
            │
            ▼
      アプリの数と質が上がる
            │
            ▼
   端末が魅力的になる ──────┐
            │                │
            └────────────────┘
        （ぐるぐる回って自己強化する＝フライホイール）

    ※ 逆回転もする。開発者が抜ける → アプリが減る → 端末が売れない

4. クリティカルマス：回り始めるまでが地獄

ループは強力だが、回り始める前は「誰もいない場所」でしかない。
出品者がいないフリマに買い手は来ないし、買い手がいないフリマに出品者は来ない。
これを ニワトリと卵の問題（chicken-and-egg problem） と呼ぶ。

クリティカルマス＝ループが自力で回り出す最低限のユーザー数。
ここを超えるまでは、赤字を垂れ流してでも人を集める。

立ち上げの手口 中身 実例のイメージ
片面を金で買う供給側に報酬・保証を出す配車アプリの「最低保証」、動画配信の制作費
片面を自前で用意最初のコンテンツを自社で作る初期のNetflix、ECの自社仕入れ
狭い領域で満たす全国ではなく1大学・1都市で密度を作る初期のFacebook（大学単位）、地域限定のデリバリー
既存の集団を連れてくる他サービスの連絡先や名簿を流用電話帳連携、既存SNSからの招待
単体でも役に立つ道具を配る片面だけで完結する機能を無料提供予約管理ツールを店に配り、後から集客面を足す

ポイント：プラットフォームの立ち上げ費用は「広告費」ではなく事実上の設備投資。
赤字は失敗ではなく、クリティカルマスに到達するまでの投資と見るのが業界の常識。

5. 価格構造の非対称：どちらの面から取るか

両面市場では、合計でいくら取るかよりどちらの面から取るかのほうが重要になる。
原則はひとつ。

価格に敏感で、逃げやすく、いないと困る面を無料（またはマイナス価格）にし、
そこに集まった人にアクセスしたい面から回収する。

面の性質 取り方 理由
数が命・移り気・払う習慣がない無料、むしろポイントを配る1人減ると反対側の価値が減るので、金を払ってでも留める
その人たちに会いたくて仕方ないここから回収する支払意思が高く、逃げにくい

SNSの広告主、アプリストアの開発者、カード加盟店は全て後者。
「ユーザーが商品である」という言い方はやや乱暴だが、経済構造としては
ユーザーの注意（アテンション）を広告主に売っているのは事実である。
広告そのものの仕組み（入札・配信・計測）は ネット広告 側に譲る。

6. マルチホーミングとスイッチングコスト

勝者総取りになるかどうかを決める2つの変数。

  • マルチホーミング（multi-homing）＝複数のサービスを同時に使うこと。
    多くの人はInstagramもXもTikTokも入れている＝マルチホーミングしている。
  • スイッチングコスト＝乗り換えるときに失うもの。
    友達関係、フォロワー数、購入履歴、評価スコア、慣れ。
【乗り換えやすさのマトリクス】

  マルチホーミング  易しい  │  複数が共存しやすい        │  1強になりにくいが
  （同時利用）              │  SNS・動画・ニュース        │  滞在時間を奪い合う
                            │                             │
                    難しい  │  ほぼ1強で固定される        │  OS・アプリストア
                            │  （端末に1つしか置けない）  │  決済網・メッセンジャー
                            └─────────────────────────────┘
                              低い          スイッチングコスト          高い

SNSは実はマルチホーミングが容易な分野で、
「乗り換え」ではなく「時間の奪い合い」として競争が起きる。
一方でOSとアプリストアは端末に実質1つしか載らないため、
競争が起きにくく規制の対象になる（→ ③ 規制と社会的論点）。

7. 勝者総取り（Winner-Takes-All）が起きる条件・起きない条件

勝者総取りになりやすい 勝者総取りになりにくい
直接ネットワーク効果が強い（友達がいないと成立しない）供給側の差別化が効く（コンテンツの中身で選ばれる）
マルチホーミングのコストが高い（端末に1つ）同時利用が簡単でタダ
データが効く領域で、規模＝精度になる一定量でデータの効き目が頭打ちになる
ローカル（地域）ではなくグローバルに効果が及ぶ地域ごとに供給が必要（配車・デリバリー・不動産）
標準規格・互換性が握られている相互接続が制度で義務づけられている

現実には「グローバル1強」より「用途ごとの1強が併存」になりやすい。
メッセージはLINE、写真はInstagram、短尺動画はTikTok、というように
用途で棲み分けたうえで、それぞれの用途内では強い集中が起きるのが日本の実情である。

8. テイクレート：手数料率をどこに置くか

テイクレート（take rate）＝プラットフォームを通った取引金額のうち、
プラットフォームが取る割合。プラットフォーム企業の利益率はほぼこれで決まる。

分野 おおよそのテイクレート 決まり方
アプリストア（従来の標準）15〜30%事実上の独占価格。規制の焦点になっている
フリマ・C2C6〜10%前後出品者が逃げる水準が上限
モール型EC数%〜10%台（出店料＋広告と併課金）広告で実質負担が上乗せされる
動画・音楽の収益分配プラットフォーム取り分 30〜45%程度権利者の交渉力が強いと下がる
配車・デリバリー20〜30%台供給側の離脱と行政の規制が上限

数値はいずれも各社の公表条件や報道からのおおまかな目安で、
国・カテゴリ・規模によって大きく変わる。最新は各社の利用規約で確認するのが確実。

テイクレートには物理的な原価の裏付けがない。
「その水準でも供給側が逃げないか」だけが上限なので、
逃げ先が無いほど高く設定できてしまう。これが独占禁止法の議論に直結する。

9. コスト構造：作るのは重く、配るのは軽い

【プラットフォームの費用の形】

  費用
   │      ┌──────── 初期開発・立ち上げ販促（巨額の固定費）
   │      │
   │      │              限界費用（ユーザー1人増やす追加費用）≒ ほぼゼロ
   │      │   ┌───────────────────────────────────────────
   │      │   │  ただし実際にはゼロではない：
   │      │   │  ・サーバ／通信／AI推論のコスト
   │      │   │  ・モデレーション（監視）の人件費
   │      │   │  ・不正・詐欺対応、法務、各国の規制対応
   │      └───┘
   └──────────────────────────────────────────── ユーザー数

限界費用がほぼゼロだから、クリティカルマスを超えた後の利益率は極端に高くなる。
一方で、規模が大きくなるほど比例して増える費用が2つある。
ひとつは動画・AIのインフラ費用（→ データセンター）、
もうひとつはコンテンツ監視の人件費（→ ② SNSの収益と運営）。

10. 見るべき指標

指標 意味 何が読めるか
MAU / DAU月間／日間の利用者数規模。ただし「登録者」ではなく「使った人」で見る
DAU÷MAU（スティッキネス）月に使った人のうち毎日使う割合習慣化の度合い。SNSでは50%超なら極めて強い
滞在時間1日あたりの利用分数広告の在庫（売れる枠の量）そのもの
ARPU利用者1人あたり売上地域差が大きい。北米が突出して高い
GMVプラットフォーム上の取引総額売上ではない。GMV×テイクレート≒売上
テイクレート手数料率収益性と、規制リスクの高さ
解約率／離脱率使わなくなる割合ネットワーク効果が逆回転していないかの早期警報

売上とGMVを混同しないこと。GMV 1兆円でテイクレート8%なら売上は800億円である。
報道で「流通総額◯兆円」と出ていても、企業の売上はその一部でしかない。

11. プラットフォームはどう衰退するか

一度勝つと強いが、不滅ではない。崩れ方には型がある。

崩れ方 中身 典型例のパターン
負のネットワーク効果広告過多・スパム・治安悪化で居心地が悪くなる古参ユーザーの離脱 → 質の低下 → さらに離脱
環境の断層PC→スマホ、検索→推薦、のように土俵が変わる前の土俵での強みが資産ではなく重荷になる
面の反乱供給側が手数料や規約に耐えられず離脱直販・自社サイト・別ストアへの移行
規制による強制開放法律で他社への開放や選択画面を義務づけられる→ ③ 規制と社会的論点
世代交代新規の若年層が最初から別のサービスを使う「親が使っているSNS」は若者に敬遠される

ポイント：ネットワーク効果は逆にも回る。強さの源泉がそのまま崩壊の加速装置になる。

用語 意味
