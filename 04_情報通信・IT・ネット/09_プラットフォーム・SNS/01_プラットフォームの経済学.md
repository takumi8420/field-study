# プラットフォームの経済学

このノートで分かること：**なぜプラットフォームは「無料」でユーザーを集め、なぜ一度勝つと
なかなか負けないのか**。その裏にある両面市場・ネットワーク効果・クリティカルマスという
3つの仕組みを、式と図で分解する。

## 1. プラットフォームとは「自分で作らずに、出会わせて取る」商売

ふつうのメーカーは、材料を仕入れて製品を作り、売る。
プラットフォーム（Platform＝土台・場）は違う。**自分では商品を作らず、
売りたい人と買いたい人を出会わせ、取引が成立したときに手数料を取る**。

```
【メーカー型】  材料 ──▶ 自社で製造 ──▶ 販売 ──▶ 顧客
                        （在庫・工場を持つ）

【プラットフォーム型】
                 出品者・投稿者・開発者（＝供給側の面）
                            │
                            ▼
                 ┌──────────────────┐
                 │   プ ラ ッ ト フ ォ ー ム   │ ← ルール・決済・検索・推薦を提供
                 └──────────────────┘
                            ▲
                            │
                 利用者・視聴者・買い手（＝需要側の面）

   在庫を持たない／作らない。持つのは「ルール」と「ユーザーの数」
```

自社でコンテンツを作らないYouTube、自社で部屋を持たないAirbnb、
自社でアプリを作らないApp Store。いずれも同じ形をしている。

> ポイント：プラットフォーム企業の資産は工場でも在庫でもなく、
> **「そこに人がいる」という事実そのもの**。だから人の数を増やすことに全てを賭ける。

## 2. 両面市場：客が2種類いて、互いを必要としている

**両面市場（two-sided market）**＝性質の違う2グループの利用者がいて、
一方が増えるともう一方にとっての価値が上がる市場のこと。
「面（side）」とは、プラットフォームから見た客のグループのこと。

| 例 | A面（供給側） | B面（需要側） | 主に課金する側 | 無料にする側 |
| --- | --- | --- | --- | --- |
| App Store | アプリ開発者 | スマホ利用者 | 開発者（手数料） | 利用者（ストア利用は無料） |
| SNS | 投稿者・クリエイター | 閲覧ユーザー | **広告主（＝第3の面）** | 両方とも無料 |
| フリマアプリ | 出品者 | 購入者 | 出品者（販売手数料） | 購入者 |
| 検索エンジン | Webサイト運営者 | 検索する人 | 広告主 | 両方とも無料 |
| クレジットカード | 加盟店 | カード会員 | 加盟店（加盟店手数料） | 会員（年会費無料カード） |
| 配車・デリバリー | ドライバー・店舗 | 注文する人 | 店舗＋利用者の両方 | — |

SNSは正確には**三面市場**である。ユーザー（閲覧者）・クリエイター（投稿者）・広告主の3つ。
ユーザーとクリエイターは無料で、広告主だけが払う。
この非対称が「SNSはタダなのに巨大企業になる」からくりの正体である。

## 3. ネットワーク効果：人が集まるほど価値が上がる

**ネットワーク効果**＝利用者が増えるほど、そのサービスの価値が上がる性質。
電話が1台しかなければ無価値で、100万台あれば必需品になるのと同じ理屈。
4つの型に分けて考えると混乱しない。

| 型 | 中身 | 効きやすい例 | 注意点 |
| --- | --- | --- | --- |
| **直接（同じ面の中）** | 同じ側のユーザーが増えると価値が上がる | LINE、電話、メッセンジャー | 最も強力。友達がいる限り抜けられない |
| **間接（面をまたぐ）** | 反対側が増えると価値が上がる | アプリストア（アプリ多い→端末買う→開発者増える） | 両面を同時に育てる必要がある |
| **データ由来** | 使われるほど推薦・検索精度が上がる | 検索、レコメンド、地図 | 逓減しやすい（一定量を超えると差が出ない） |
| **負（マイナス）** | 増えすぎると逆に価値が下がる | 広告だらけのSNS、スパム、混雑 | 実はこれが崩壊の引き金になる |

```
【間接ネットワーク効果のループ（アプリストアの例）】

    端末ユーザーが増える
            │
            ▼
   開発者にとって儲かる市場になる
            │
            ▼
      アプリの数と質が上がる
            │
            ▼
   端末が魅力的になる ──────┐
            │                │
            └────────────────┘
        （ぐるぐる回って自己強化する＝フライホイール）

    ※ 逆回転もする。開発者が抜ける → アプリが減る → 端末が売れない
```

## 4. クリティカルマス：回り始めるまでが地獄

ループは強力だが、**回り始める前は「誰もいない場所」でしかない**。
出品者がいないフリマに買い手は来ないし、買い手がいないフリマに出品者は来ない。
これを **ニワトリと卵の問題（chicken-and-egg problem）** と呼ぶ。

**クリティカルマス**＝ループが自力で回り出す最低限のユーザー数。
ここを超えるまでは、赤字を垂れ流してでも人を集める。

| 立ち上げの手口 | 中身 | 実例のイメージ |
| --- | --- | --- |
| 片面を金で買う | 供給側に報酬・保証を出す | 配車アプリの「最低保証」、動画配信の制作費 |
| 片面を自前で用意 | 最初のコンテンツを自社で作る | 初期のNetflix、ECの自社仕入れ |
| 狭い領域で満たす | 全国ではなく1大学・1都市で密度を作る | 初期のFacebook（大学単位）、地域限定のデリバリー |
| 既存の集団を連れてくる | 他サービスの連絡先や名簿を流用 | 電話帳連携、既存SNSからの招待 |
| 単体でも役に立つ道具を配る | 片面だけで完結する機能を無料提供 | 予約管理ツールを店に配り、後から集客面を足す |

> ポイント：プラットフォームの立ち上げ費用は「広告費」ではなく**事実上の設備投資**。
> 赤字は失敗ではなく、クリティカルマスに到達するまでの投資と見るのが業界の常識。

## 5. 価格構造の非対称：どちらの面から取るか

両面市場では、**合計でいくら取るか**より**どちらの面から取るか**のほうが重要になる。
原則はひとつ。

> **価格に敏感で、逃げやすく、いないと困る面を無料（またはマイナス価格）にし、
> そこに集まった人にアクセスしたい面から回収する。**

| 面の性質 | 取り方 | 理由 |
| --- | --- | --- |
| 数が命・移り気・払う習慣がない | 無料、むしろポイントを配る | 1人減ると反対側の価値が減るので、金を払ってでも留める |
| その人たちに会いたくて仕方ない | ここから回収する | 支払意思が高く、逃げにくい |

SNSの広告主、アプリストアの開発者、カード加盟店は全て後者。
「ユーザーが商品である」という言い方はやや乱暴だが、経済構造としては
**ユーザーの注意（アテンション）を広告主に売っている**のは事実である。
広告そのものの仕組み（入札・配信・計測）は [ネット広告](../07_ネット広告/README.md) 側に譲る。

## 6. マルチホーミングとスイッチングコスト

勝者総取りになるかどうかを決める2つの変数。

- **マルチホーミング（multi-homing）**＝複数のサービスを同時に使うこと。
  多くの人はInstagramもXもTikTokも入れている＝マルチホーミングしている。
- **スイッチングコスト**＝乗り換えるときに失うもの。
  友達関係、フォロワー数、購入履歴、評価スコア、慣れ。

```
【乗り換えやすさのマトリクス】

  マルチホーミング  易しい  │  複数が共存しやすい        │  1強になりにくいが
  （同時利用）              │  SNS・動画・ニュース        │  滞在時間を奪い合う
                            │                             │
                    難しい  │  ほぼ1強で固定される        │  OS・アプリストア
                            │  （端末に1つしか置けない）  │  決済網・メッセンジャー
                            └─────────────────────────────┘
                              低い          スイッチングコスト          高い
```

SNSは実はマルチホーミングが容易な分野で、
**「乗り換え」ではなく「時間の奪い合い」**として競争が起きる。
一方でOSとアプリストアは端末に実質1つしか載らないため、
競争が起きにくく規制の対象になる（→ [③ 規制と社会的論点](03_規制と社会的論点.md)）。

## 7. 勝者総取り（Winner-Takes-All）が起きる条件・起きない条件

| 勝者総取りになりやすい | 勝者総取りになりにくい |
| --- | --- |
| 直接ネットワーク効果が強い（友達がいないと成立しない） | 供給側の差別化が効く（コンテンツの中身で選ばれる） |
| マルチホーミングのコストが高い（端末に1つ） | 同時利用が簡単でタダ |
| データが効く領域で、規模＝精度になる | 一定量でデータの効き目が頭打ちになる |
| ローカル（地域）ではなくグローバルに効果が及ぶ | 地域ごとに供給が必要（配車・デリバリー・不動産） |
| 標準規格・互換性が握られている | 相互接続が制度で義務づけられている |

現実には**「グローバル1強」より「用途ごとの1強が併存」**になりやすい。
メッセージはLINE、写真はInstagram、短尺動画はTikTok、というように
**用途で棲み分けたうえで、それぞれの用途内では強い集中が起きる**のが日本の実情である。

## 8. テイクレート：手数料率をどこに置くか

**テイクレート（take rate）**＝プラットフォームを通った取引金額のうち、
プラットフォームが取る割合。プラットフォーム企業の利益率はほぼこれで決まる。

| 分野 | おおよそのテイクレート | 決まり方 |
| --- | --- | --- |
| アプリストア（従来の標準） | 15〜30% | 事実上の独占価格。規制の焦点になっている |
| フリマ・C2C | 6〜10%前後 | 出品者が逃げる水準が上限 |
| モール型EC | 数%〜10%台（出店料＋広告と併課金） | 広告で実質負担が上乗せされる |
| 動画・音楽の収益分配 | プラットフォーム取り分 30〜45%程度 | 権利者の交渉力が強いと下がる |
| 配車・デリバリー | 20〜30%台 | 供給側の離脱と行政の規制が上限 |

> 数値はいずれも各社の公表条件や報道からの**おおまかな目安**で、
> 国・カテゴリ・規模によって大きく変わる。最新は各社の利用規約で確認するのが確実。

テイクレートには物理的な原価の裏付けがない。
**「その水準でも供給側が逃げないか」だけが上限**なので、
逃げ先が無いほど高く設定できてしまう。これが独占禁止法の議論に直結する。

## 9. コスト構造：作るのは重く、配るのは軽い

```
【プラットフォームの費用の形】

  費用
   │      ┌──────── 初期開発・立ち上げ販促（巨額の固定費）
   │      │
   │      │              限界費用（ユーザー1人増やす追加費用）≒ ほぼゼロ
   │      │   ┌───────────────────────────────────────────
   │      │   │  ただし実際にはゼロではない：
   │      │   │  ・サーバ／通信／AI推論のコスト
   │      │   │  ・モデレーション（監視）の人件費
   │      │   │  ・不正・詐欺対応、法務、各国の規制対応
   │      └───┘
   └──────────────────────────────────────────── ユーザー数
```

限界費用がほぼゼロだから、クリティカルマスを超えた後の利益率は極端に高くなる。
一方で、**規模が大きくなるほど比例して増える費用が2つ**ある。
ひとつは動画・AIのインフラ費用（→ [データセンター](../03_データセンター/README.md)）、
もうひとつはコンテンツ監視の人件費（→ [② SNSの収益と運営](02_SNSの収益と運営.md)）。

## 10. 見るべき指標

| 指標 | 意味 | 何が読めるか |
| --- | --- | --- |
| MAU / DAU | 月間／日間の利用者数 | 規模。ただし「登録者」ではなく「使った人」で見る |
| DAU÷MAU（スティッキネス） | 月に使った人のうち毎日使う割合 | 習慣化の度合い。SNSでは50%超なら極めて強い |
| 滞在時間 | 1日あたりの利用分数 | 広告の在庫（売れる枠の量）そのもの |
| ARPU | 利用者1人あたり売上 | 地域差が大きい。北米が突出して高い |
| GMV | プラットフォーム上の取引総額 | 売上ではない。GMV×テイクレート≒売上 |
| テイクレート | 手数料率 | 収益性と、規制リスクの高さ |
| 解約率／離脱率 | 使わなくなる割合 | ネットワーク効果が逆回転していないかの早期警報 |

**売上とGMVを混同しない**こと。GMV 1兆円でテイクレート8%なら売上は800億円である。
報道で「流通総額◯兆円」と出ていても、企業の売上はその一部でしかない。

## 11. プラットフォームはどう衰退するか

一度勝つと強いが、不滅ではない。崩れ方には型がある。

| 崩れ方 | 中身 | 典型例のパターン |
| --- | --- | --- |
| 負のネットワーク効果 | 広告過多・スパム・治安悪化で居心地が悪くなる | 古参ユーザーの離脱 → 質の低下 → さらに離脱 |
| 環境の断層 | PC→スマホ、検索→推薦、のように土俵が変わる | 前の土俵での強みが資産ではなく重荷になる |
| 面の反乱 | 供給側が手数料や規約に耐えられず離脱 | 直販・自社サイト・別ストアへの移行 |
| 規制による強制開放 | 法律で他社への開放や選択画面を義務づけられる | → [③ 規制と社会的論点](03_規制と社会的論点.md) |
| 世代交代 | 新規の若年層が最初から別のサービスを使う | 「親が使っているSNS」は若者に敬遠される |

> ポイント：**ネットワーク効果は逆にも回る**。強さの源泉がそのまま崩壊の加速装置になる。

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **プラットフォーム** | 自ら商品を作らず、異なる利用者グループを出会わせて手数料や広告で稼ぐ事業 |
| **両面市場（two-sided market）** | 性質の違う2つの利用者グループがいて、互いの存在が価値になる市場 |
| **ネットワーク効果** | 利用者が増えるほどサービスの価値が上がる性質。直接／間接／データ由来／負の4型 |
| **クリティカルマス** | ネットワーク効果が自走し始める最低限の利用者数 |
| **ニワトリと卵の問題** | 買い手がいないと売り手が来ず、売り手がいないと買い手が来ない、立ち上げ時の袋小路 |
| **マルチホーミング** | 複数の競合サービスを同時に使うこと。これが容易だと1強になりにくい |
| **スイッチングコスト** | 乗り換えで失うもの（友人関係、評価、履歴、慣れ）。高いほど囲い込みが効く |
| **テイクレート** | 取引額に対してプラットフォームが取る割合。利益率と規制リスクを同時に決める |
| **GMV** | 流通取引総額。プラットフォーム上で動いた金額の合計であり、売上とは別物 |
| **DAU／MAU** | 日間／月間の実利用者数。その比が高いほど生活に組み込まれている |
| **ARPU** | 利用者1人あたり売上。SNSでは実質「1人あたり広告単価」 |
| **フライホイール** | 自己強化ループ。回り出すと加速するが、止まると逆回転する |
