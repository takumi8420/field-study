## 1. 業界の定義・範囲

**プラットフォーム**＝自ら商品やコンテンツを作らず、**異なる利用者グループを出会わせる場を運営し、
手数料や広告で稼ぐ事業**。**SNS**（ソーシャル・ネットワーキング・サービス）はそのうち、
人と人のつながりと投稿の流通を中心に据えたもの。


## 2. 市場規模と成長性

プラットフォーム・SNSには「業界売上」という公式統計がない。
**広告費**と**利用者数**の2つで規模をつかむのが実務的である。

| 指標 | 数値 | 年・出典 |
| --- | --- | --- |
| 日本の総広告費 | 8兆623億円（前年比105.1%、4年連続で過去最高） | 2025年／電通「2025年 日本の広告費」（2026年3月発表） |
| インターネット広告費 | 4兆459億円（構成比 **50.2%**、初の過半数） | 同上 |
| ソーシャル広告 | 1兆3,067億円（前年比118.7%） | 同上 |
| ── SNS系 | 5,508億円（ソーシャル広告内の構成比42.1%） | 同上 |
| ── 動画共有系 | 5,126億円（同39.2%） | 同上 |
| ビデオ（動画）広告 | 1兆275億円（初の1兆円超え） | 同上 |
| 日本のSNS利用率 | 全年代平均で8割超、10〜30代は9割超 | 2024年調査／総務省 情報通信白書（令和6〜7年版） |
| LINE利用率 | 全年代で約91% | 同上 |
| 国内クリエイターエコノミー | 約2兆894億円（2021年以降 年率約15.5%成長） | 2024年／調査会社の**推計** |
| 世界のクリエイターエコノミー | 2025年 約2,557億ドル → 2026年 約3,235億ドル | 調査会社の**推計**。定義により大きく変動 |

> **成長の性格**：SNSの利用者数は日本ではほぼ飽和している（伸びしろは高齢層のみ）。
> したがって成長は「人数」ではなく **「1人あたり滞在時間」と「広告単価」** から来る。
> 動画広告が1兆円を超えたのは、動画が最も長く時間を取れるフォーマットだからである。

## 3. バリューチェーン（川上 → 川下）

```
【誰が価値を作り、誰が受け取るか】

  ① コンテンツの供給                ② 場の運営                  ③ 換金
  ─────────────────             ─────────────            ──────────
  クリエイター／一般ユーザー  ──▶  SNS・プラットフォーム  ──▶  広告主
  メディア・企業アカウント          ・推薦アルゴリズム         代理店／運用会社
  （無償または収益分配）             ・モデレーション
                                     ・決済／ストア            ──▶  EC・課金
       ▲                                   │                        投げ銭・サブスク
       └──── 収益分配（3〜7割） ◀──────────┘

  ④ 土台                        ⑤ 端末・回線
  ─────────                   ──────────────
  データセンター／AI基盤         スマホOS・アプリストア・通信回線
  （費用として出ていく）          ← ここを握る者がさらに上位の関所になる
```

**付加価値がどこに溜まるか**は明快で、**②の場の運営と⑤の端末・ストア**に集中する。
①のクリエイターは数が多く代替されやすいため交渉力が弱く、
③の広告主は出稿先を選べるが、集中した在庫の前では価格交渉力が限られる。

そして**⑤（OS・アプリストア）は②（SNS）の上流にいる**。
SNSがどれだけ巨大でも、アプリの配信と課金でOS側に手数料を払う。
この「プラットフォームの上のプラットフォーム」構造こそが、
スマホ新法やDMAが狙っている場所である（→ [③](03_規制と社会的論点.md)）。

## 4. 主要プレイヤーとシェア

| 企業／サービス | 立ち位置 | 特徴 |
| --- | --- | --- |
| **Meta**（Facebook／Instagram／Threads／WhatsApp） | 世界最大のSNS広告事業者 | 売上のほぼ全て（2026年1Qで約98%）が広告。AIインフラに年1,250〜1,450億ドル規模の投資計画 |
| **Google／YouTube**（Alphabet） | 検索＋動画共有＋Android＋Playの複合 | 「上流の関所」を複数握る。日本では2025年に排除措置命令、スマホ新法でも指定事業者 |
| **Apple**（iOS／App Store） | 端末とストアを垂直統合 | 広告事業は小さいが、アプリ経済の関所としての影響力が最大。規制の主対象 |
| **ByteDance／TikTok** | 推薦型フィードの発明者 | 短尺動画で滞在時間を奪った。米国事業は2026年1月に分離（TikTok USDS） |
| **X Corp.（X）** | リアルタイム拡散に特化 | 日本での利用が国際比較で厚い。モデレーション方針の変更が論争の的 |
| **LINEヤフー** | 日本のメッセージ基盤＋ポータル | LINEは全年代で約91%利用。行政・企業の連絡手段にもなり事実上のインフラ |
| **その他国内**（ニコニコ、Ameba、掲示板系） | ニッチ／コミュニティ特化 | 情プラ法の指定対象に含まれ、大手と同じ運用義務を負う |

**シェアの読み方の注意**：SNSは [マルチホーミング](01_プラットフォームの経済学.md)（同時利用）が普通なので、
「シェア何%」という言い方が成立しにくい。
**用途ごと（連絡／拡散／写真／短尺／動画）に別々の1強がいる**と捉えるのが正確である。

## 5. 収益モデル・コスト構造

```
  売上 ＝ 利用者数 × 滞在時間 × 広告表示密度 × 広告単価  （＋課金・EC）
          ────────────────────────   ──────────────────
              広告在庫の「量」              在庫の「単価」
```

| 区分 | 項目 | 性質 |
| --- | --- | --- |
| 売上 | 広告（主力、大手では8〜9割超） | 景気感応度が高い。選挙・大型イベントで上下する |
| 売上 | 課金・サブスク・投げ銭 | 単価が高く安定。ただしアプリストア手数料が乗る |
| 売上 | EC・送客手数料 | 購買データが広告精度を上げる相乗効果 |
| 費用 | サーバ・帯域・AI推論 | 準変動費。動画とAIで急増中 |
| 費用 | 研究開発 | 固定費。大手で売上の2〜3割規模 |
| 費用 | モデレーション・安全対策 | 準固定費。多言語・24時間体制で高くつく |
| 費用 | 法務・規制対応・制裁金 | 不確実。EUでは数億ユーロ単位の事例 |

利益率は、限界費用（利用者1人増やす追加費用）がほぼゼロなので、
規模が出れば**営業利益率3〜4割**に達する例もある。
ただし近年は**AI投資とモデレーション費用がこの利益率を削る方向**に効いている。
詳細は [② SNSの収益と運営](02_SNSの収益と運営.md)。

## 6. 競争要因（KSF）と参入障壁

| 要因 | 中身 | 効き方 |
| --- | --- | --- |
| **ネットワーク効果** | 人が集まるほど価値が上がる | 最大の障壁。ただし用途を変えた新興には効かない |
| **推薦アルゴリズムの精度** | 面白いものを早く見つける力 | TikTok以降の主戦場。データ量と機械学習の力が効く |
| **クリエイターの供給** | 作り手がどれだけ居着くか | 収益分配率と発見されやすさで決まる。移りやすい |
| **信頼と治安** | 荒れていない、詐欺が少ない | 崩れると負のネットワーク効果で一気に離脱が進む |
| **広告主基盤と計測** | 出稿しやすさ、効果が見えるか | 広告主の乗り換えコストは低くない |
| **流通の関所（OS・ストア）** | 端末に載るかどうか | 自力では超えられない。規制でしか動かない |
| **規制対応の体力** | 各国の法対応・監視体制 | **新規参入者に不利に働く**。規制が既存大手を守る面がある |

> **参入障壁のねじれ**：規制は本来、競争を促すために導入される。
> しかしモデレーション体制や法対応のコストは固定費なので、
> **体力のある大手ほど負担しやすい**。この副作用は各国で議論されている。

## 7. 規制・法制度

| 制度 | 国・地域 | 施行 | 要点 |
| --- | --- | --- | --- |
| **スマホソフトウェア競争促進法（スマホ新法）** | 日本 | **2025年12月18日 全面施行** | OS・アプリストア・ブラウザ・検索が対象。Apple／iTunes／Googleを指定。他社ストア・外部課金の妨害禁止、自己優遇禁止、選択画面の義務。課徴金は国内売上の20%（再犯30%） |
| **独占禁止法（事後規制）** | 日本 | — | 2025年4月15日、Google LLCに**排除措置命令**（巨大IT企業では国内初） |
| **デジタルプラットフォーム取引透明化法** | 日本 | 2021年 | 大規模モール・アプリストア・広告に、規約変更の事前通知と情報開示を義務づけ |
| **情報流通プラットフォーム対処法（情プラ法）** | 日本 | 2025年4月1日 | 削除申出に**原則7日以内**の判断、削除基準と運用状況の公表。2026年7月に総務省が初の勧告 |
| **DMA（デジタル市場法）** | EU | 2023年〜 | ゲートキーパーへの事前規制。2025年4月にApple 5億ユーロ、Meta 2億ユーロの制裁金 |
| **DSA（デジタルサービス法）** | EU | 2023年〜 | 違法コンテンツ対応、推薦システムの透明性。中毒性のある設計にも予備的認定 |
| **16歳未満のSNS利用制限** | オーストラリア等 | 2025年12月 | 事業者に年齢確認措置を義務づけ。日本に法的制限はなく自主規制（13歳以上）に依存 |

論点の整理（立場は取らない）は [③ 規制と社会的論点](03_規制と社会的論点.md) に置いた。

## 8. 最近のトピック

→ [④ 直近トピック（2026年9月時点）](04_直近トピック_2026.md)

1. **スマホ新法は施行1年目を終えたが、App Store手数料は30%→26%、外部決済でもストア手数料21%が残り、
   「扉は開いたが経済実態は変わらない」との批判が続く。** 公取委は2026年2月・7月に遵守報告書を公表。
2. **規制が三方向で同時に執行段階へ。** 事前（スマホ新法）、事後（2025年4月のGoogle排除措置命令）、
   コンテンツ（2026年7月、情プラ法で5社に初の勧告）。
3. **EUはApple 5億／Meta 2億ユーロの制裁金を科したが両社が提訴し、司法判断は2026年後半以降。**
   米EU間の通商摩擦にも波及している。
4. **事業側は広告で最高益、投資はAIへ一極集中。** Metaは2026年1Qで売上563億ドル（＋33%）、
   通期CapEx見通し1,250〜1,450億ドル。日本ではネット広告費が構成比50.2%で初の過半数。
5. **「グローバルに1つのサービス」という前提が崩れつつある。** TikTok米国事業は2026年1月に分離完了、
   豪州は16歳未満のSNS利用を制限。国ごとに運営主体・ルール・年齢要件が分かれる時代へ。
