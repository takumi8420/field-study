# 規制と社会的論点

このノートで分かること：**強くなりすぎたプラットフォームに対して、各国が何を、どういう理屈で
規制しようとしているのか**。日本のスマホ新法を軸に、EUのDMA／DSA、手数料30%問題、
プライバシー、偽情報、子どもの利用規制までを、**立場を決めずに論点として**整理する。

## 1. 規制が出てきた理由：従来の独占禁止法では遅い

独占禁止法（競争法）は本来、**違反が起きてから**調査し、排除措置命令を出す「事後規制」である。
ところがプラットフォームでは、調査に数年かけている間に市場が固まってしまう。
そこで近年、**「大きい事業者にはあらかじめ守るべきルールを課す」事前規制**が世界で広がった。

```
【2つの規制のかたち】

  ● 事後規制（従来の独占禁止法）
     違反行為の発生 ──▶ 申告・調査（数年） ──▶ 違反認定 ──▶ 排除措置命令
                                                  ▲
                                          この間に市場は固定化

  ● 事前規制（DMA、スマホ新法、透明化法）
     一定規模の事業者を「指定」 ──▶ 指定した瞬間から禁止事項・義務が発生
                                      ──▶ 遵守報告 ──▶ 違反なら課徴金
```

| 観点 | 事後規制 | 事前規制 |
| --- | --- | --- |
| 発動のタイミング | 違反が起きてから | 規模で指定した時点から |
| 立証の負担 | 当局が競争制限を立証する | 行為の類型自体を禁止するので軽い |
| 速さ | 遅い | 速い |
| 批判 | 手遅れになる | 過剰規制になりうる、投資やセキュリティを損なう恐れ |

どちらが良いかは論者によって割れる。**「競争を取り戻すのに必要」という立場と、
「イノベーションと安全性を損なう」という立場が対立している**のが現状である。

## 2. 日本：スマホソフトウェア競争促進法（スマホ新法）

日本の規制の中心は、**スマートフォンにおいて利用される特定ソフトウェアに係る競争の促進に関する法律**
（通称：スマホソフトウェア競争促進法、スマホ新法、スマホ法）。
**2025年12月18日に全面施行**された。所管は公正取引委員会。

### 2-1. 何を対象にするか

規制対象のソフトウェアは4種類。**モバイルOS・アプリストア・ブラウザ・検索エンジン**。
これらを提供する大手が「指定事業者」とされる。
公正取引委員会は**2025年3月26日（公表は3月31日）に、Apple Inc.、iTunes株式会社、Google LLC を指定**した。

| 指定事業者 | 指定されたソフトウェア |
| --- | --- |
| Apple Inc. | モバイルOS、アプリストア、ブラウザ |
| iTunes株式会社 | アプリストア |
| Google LLC | モバイルOS、アプリストア、ブラウザ、検索エンジン |

### 2-2. 何を義務づけ、何を禁じるか

```
【スマホ新法の柱（概念図）】

  ┌─ 禁止されること ────────────────────────────────┐
  │ ・他社アプリストア／他社課金の利用を妨げること            │
  │ ・アプリ内から外部の購入先へ案内すること（誘導）の禁止    │
  │ ・自社サービスを検索結果などで不当に優遇すること（自己優遇）│
  │ ・取得したデータを自社アプリの優位のために流用すること      │
  └──────────────────────────────────────────────┘
  ┌─ 義務づけられること ────────────────────────────┐
  │ ・ブラウザ／検索エンジンの「選択画面」を利用者に出すこと    │
  │ ・OSの機能を他社アプリにも同等の条件で開放すること          │
  │ ・条件変更の事前通知、苦情・紛争処理の窓口設置              │
  │ ・遵守状況の報告書を公正取引委員会に提出すること            │
  └──────────────────────────────────────────────┘
```

制裁は課徴金で、**違反行為に係る国内売上高の20%（繰り返しの場合は30%）**という
高い水準が設定されている点が特徴である。

### 2-3. 施行後に実際に何が変わったか（2026年9月時点）

- Apple・Googleとも、日本市場で**外部決済手段と代替アプリストアを受け入れる規約**を公表した。
- **App Storeの標準アプリ内課金の手数料が30%→26%に引き下げ**られた（日本独自の対応と報じられる）。
- Appleは手数料を**「ストア手数料21%＋決済手数料5%」に分解**した。つまり外部決済を使っても
  ストア手数料21%は免除されない設計になっている。
- 公正取引委員会は**2026年2月17日**および**2026年7月27日**に、両社の遵守報告書を公表した。
- 一方、アプリ事業者側（モバイル・コンテンツ・フォーラム等）からは、
  **外部決済に10〜20%の手数料を課す設計は算定根拠が不明確**との批判が出ており（2026年1月）、
  追加の是正要望が続いている。

> **ここが論点**：形式的には外部決済が「解禁」されたが、
> 外部決済を使ってもストア手数料が残るため、**アプリ事業者の実質負担はあまり下がらない**
> という指摘がある。他方で、ストア提供側は「審査・配信・セキュリティ等の対価であり
> 決済手数料とは別物」と説明している。どちらの言い分が妥当かは決着していない。

## 3. 日本：その他の規制の柱

| 制度 | 施行 | 対象 | 中身 |
| --- | --- | --- | --- |
| **独占禁止法（事後規制）** | — | 全事業者 | 2025年4月15日、公正取引委員会は **Google LLC に排除措置命令**。Android端末メーカーへの検索アプリ・Chromeのプリインストール条件付けと、検索広告収益分配契約が拘束条件付取引に当たると認定。巨大IT企業への命令は国内初 |
| **デジタルプラットフォーム取引透明化法** | 2021年 | 大規模モール・アプリストア・広告 | 出店・出品者に対する規約変更の事前通知、取引条件の開示、運営状況の報告 |
| **情報流通プラットフォーム対処法（情プラ法）** | 2025年4月1日 | 大規模SNS等 | プロバイダ責任制限法を改組。削除申出への**原則7日以内の対応判断**、削除基準の公表、侵害情報調査専門員の選任、運用状況の年次公表 |
| **個人情報保護法** | 継続改正 | 全事業者 | 越境移転、Cookie等の第三者提供（外部送信規律は電気通信事業法側） |
| **青少年インターネット環境整備法** | 2009年〜 | 携帯事業者等 | フィルタリングの提供義務。年齢確認までは求めていない |

情プラ法については、指定事業者が**2026年8月時点で9社**（Google／YouTube、LINEヤフー、Meta、TikTok、X、
Pinterest、Amebaブログ、爆サイ.com、ニコニコ）であり、
**2026年7月24日に総務省がGoogle・X・Meta・ドワンゴ・湘南西武ホームの5社へ初の勧告**を行った。
理由は削除の運用状況の公表事項に欠落があったこと、と報じられている。

## 4. EU：DMAとDSA（世界の規制の雛形）

EUの2法が、日本を含む各国の制度設計の下敷きになっている。

| 法律 | 正式名 | 狙い | 対象 | 制裁の上限 |
| --- | --- | --- | --- | --- |
| **DMA** | デジタル市場法 | **競争**を取り戻す | 「ゲートキーパー」（門番）に指定された巨大IT | 全世界売上の10%（再犯で20%） |
| **DSA** | デジタルサービス法 | **安全と透明性**を確保する | 超大規模プラットフォーム（VLOP）等 | 全世界売上の6% |

**ゲートキーパー**＝利用者数と売上が一定基準を超え、事実上の「門番」として
他社のアクセスを左右できる事業者のこと。DMAはこれを指定して事前ルールを課す。

### 執行の実例

- 2025年4月、欧州委員会は **Appleに5億ユーロ、Metaに2億ユーロ**の制裁金を科した。
  Appleは外部への誘導を妨げる「アンチステアリング」違反、
  Metaは「pay or consent（広告付き無料か、有料で広告なしかの二択）」がデータ結合の
  同意取得として不十分と判断された。
- 両社とも提訴しており、**EU司法裁判所の判断は2026年後半以降**になる見通しと報じられる。
- DSA側では、Instagram・Facebookの「中毒性のある設計」や、TikTokの未成年アカウントの
  安全性について、欧州委員会が**予備的認定（preliminary findings）**を示している。

> **ここが論点**：EUの規制は、米国から「域外の自国企業を狙い撃ちにしている」という
> 批判を受けており、通商摩擦（関税での報復示唆）にまで発展している。
> 「消費者保護のための正当な規制」か「保護主義的な非関税障壁」かは評価が真っ二つに割れる。

## 5. 手数料30%問題：何が争われているのか

アプリストアの30%（近年は15〜26%の階層あり）は、この10年で最も争われたテイクレートである。
論点を両論併記で並べる。

| 争点 | ストアを運営する側の主張 | アプリ事業者・規制当局側の主張 |
| --- | --- | --- |
| 手数料の根拠 | 審査・配信・不正対策・SDK・決済・返金対応の対価。開発環境全体への投資回収 | 決済処理の実費は1〜3%程度。30%は独占的地位に基づく価格 |
| 外部決済の扱い | 外部決済でも配信・審査の価値は消えないのでストア手数料は残る | 外部決済に高い手数料を残せば「解禁」は名目だけ |
| セキュリティ | 単一ストア・単一課金がマルウェアと詐欺を防いでいる | 安全性を理由に競争を排除するのは目的外 |
| 利用者の利益 | 統一された返金・保護の仕組みがある | 手数料分が価格に転嫁され、利用者が負担している |
| 代替ストアの是非 | 端末の安全性が担保できない | 端末所有者が選べるべき |

```
【手数料はどこへ消えるか（利用者が1,000円払った場合の概念図）】

  利用者 1,000円
      │
      ├──▶ ストア手数料  150〜300円 ── 審査／配信／決済／不正対策
      │                                （どこまでが妥当かが争点）
      ├──▶ 決済実費       10〜 35円
      │
      └──▶ アプリ事業者  約 700〜850円
                  │
                  └─▶ さらに開発費・サーバ費・クリエイターへの分配
```

## 6. プライバシーと広告：追跡をやめると誰が困るか

SNS広告の精度は、利用者の行動データに支えられてきた。
そこに2つの変化が重なった。

1. **端末側の制御**：iOSのATT（アプリのトラッキング許可を利用者に聞く仕組み、2021年）により、
   アプリをまたいだ追跡が大幅に減った。
2. **ブラウザ側の制御**：サードパーティCookie（他社サイトでの行動を追う仕組み）の縮小。

| 影響 | 誰が | どうなったか |
| --- | --- | --- |
| 広告精度の低下 | 中小の広告事業者 | 計測できず、広告の費用対効果が悪化 |
| 相対的な強化 | 大手プラットフォーム | 自社内に大量のログイン利用者がいるため、自社完結で精度を保てる |
| 代替手段の台頭 | 全体 | 文脈連動広告、リテールメディア、AIによる推定モデル |

> **皮肉な論点**：プライバシー規制は大手を狙ったはずが、
> **自社内でデータが完結する大手ほど有利になった**という指摘がある。
> 規制が競争を促したのか、むしろ集中を強めたのかは実証的な議論が続いている。
> 広告技術側の詳細は [ネット広告](../07_ネット広告/README.md) を参照。

## 7. 偽情報・選挙への影響

推薦アルゴリズムが刺激の強い投稿を広げやすいことと、生成AIで偽の画像・音声・動画が
安価に作れるようになったことが重なり、選挙期間中の情報環境が各国で問題化している。

| 論点 | 一方の見方 | もう一方の見方 |
| --- | --- | --- |
| 影響の大きさ | 世論形成や投票行動を実際に動かしている | 影響は限定的で、既存の支持傾向を補強する程度という研究もある |
| 誰が真偽を判定するか | 専門のファクトチェック機関に委ねるべき | 判定主体が権力に近いと検閲になる |
| 削除か、表示抑制か | 明白な虚偽は削除すべき | 削除より、表示順位を下げる・注釈を付けるほうが副作用が小さい |
| 事業者の裁量 | 私企業が言論の線引きをするのは危険 | 私企業には自社サービスの規約を定める自由がある |

日本では、選挙期間中のSNS上の情報の扱い（候補者への虚偽情報、切り抜き動画、
報酬を伴う拡散など）が公職選挙法の枠組みで十分かという議論が継続している。
**本ノートでは、どの立場が正しいかは判断せず、論点の所在のみ示す。**

## 8. 子どもの利用規制：2025〜2026年の最大の動き

**オーストラリアが2025年12月、16歳未満のSNS利用を禁止する規制を施行**した。
対象となるプラットフォーム運営企業（10社程度）に、16歳未満がアカウントを作成・保有できないよう
**「合理的な年齢確認措置」を講じる義務**を課すもので、罰則は事業者側にかかり、
子どもや保護者は罰せられない。2026年に入って制裁金の上限が引き上げられたと報じられている。
スペイン、インドネシア、ギリシャなどにも同種の動きが広がっている。

日本には現時点で**法的なSNS年齢制限はなく、各社の自主規制（多くは13歳以上）に依存**している。

| 論点 | 賛成側の論拠 | 慎重側の論拠 |
| --- | --- | --- |
| 健康・発達 | 睡眠・学力・自己肯定感への悪影響を示す研究がある | 因果関係の立証は難しく、相関にとどまるという反論がある |
| 年齢確認の実効性 | 顔推定やID確認の技術は実用段階 | 確認のために**全利用者が身元を差し出す**ことになり、プライバシーが後退する |
| 子どもの権利 | 保護される権利 | 情報アクセス・表現・つながりの権利も子どもの権利 |
| 抜け道 | 主要サービスを押さえれば効果はある | VPN・年齢詐称・規制外サービスへ移るだけ |
| 責任の所在 | 事業者に負わせるのが妥当 | 家庭・学校の教育で対応すべき |

```
【年齢確認をどう実現するかの選択肢】

  自己申告        ◀── 実効性が低い              プライバシー負荷：小
  端末・OS側で判定
  顔画像による年齢推定
  クレジットカード／携帯契約での推定
  公的IDの提示    ◀── 実効性が高い              プライバシー負荷：大

  → 「効く方法ほど、全員の身元情報を集めることになる」というトレードオフ
```

## 9. プラットフォームの責任論：どこまで責任を負うか

SNSは「単なる場所の提供者」なのか、「内容に責任を持つ編集者」なのか。
この問いが全ての規制の根っこにある。

| 立場 | 考え方 | 制度上の現れ |
| --- | --- | --- |
| 導管（パイプ）論 | 通しただけ。中身に責任はない | 米国 通信品位法230条、旧プロバイダ責任制限法 |
| 条件付き免責 | 通報を受けて速やかに対応すれば免責 | EU電子商取引指令、情プラ法の7日ルール |
| 編集者論 | 推薦で並べ替えている以上、編集している | DSAの「推薦システムの透明性」義務の背景にある考え方 |
| 設計責任論 | 中毒性のある設計そのものが問題 | DSAの予備的認定、各国の訴訟 |

> 近年の潮流は**導管論から設計責任論へ**と動いている。
> 「何を載せたか」ではなく「**何を目立たせる設計にしたか**」を問う方向である。
> ただしこれは表現の自由との緊張が強く、各国で線の引き方が異なる。

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **スマホソフトウェア競争促進法（スマホ新法）** | OS・アプリストア・ブラウザ・検索を対象に、指定事業者へ事前ルールを課す日本の法律。2025年12月18日全面施行 |
| **指定事業者** | 規模要件を満たし、当局が名指しで規制対象とした事業者。日本ではApple・iTunes・Google |
| **事前規制／事後規制** | 違反前にルールを課すか、違反後に調べて措置するか |
| **DMA（デジタル市場法）** | EUの競争ルール。「ゲートキーパー」に事前義務を課す。制裁上限は全世界売上の10% |
| **DSA（デジタルサービス法）** | EUの安全・透明性ルール。違法コンテンツ対応、推薦システムの透明性など |
| **ゲートキーパー** | 他社の市場アクセスを左右できる「門番」として指定された巨大プラットフォーム |
| **アンチステアリング** | アプリ内から外部の安い購入先へ案内させない制約。DMA・スマホ新法とも禁止対象 |
| **自己優遇（セルフプリファレンシング）** | 自社サービスを検索結果などで有利に扱うこと |
| **情プラ法** | 情報流通プラットフォーム対処法。削除申出への原則7日以内の対応判断などを義務づけ |
| **排除措置命令** | 独占禁止法違反に対し、公正取引委員会が行為の取りやめ等を命じる処分 |
| **ATT** | App Tracking Transparency。アプリ横断の追跡に利用者の許可を必要とする仕組み |
| **VLOP** | Very Large Online Platform。DSAで追加義務を負う超大規模プラットフォーム |
