## 1. 業界の定義・範囲

情報セキュリティ産業とは、**情報システムを攻撃から守るための製品・サービスを
「商品として」提供する産業**を指す。守る技術の話ではなく、
**それが値付けされ、営業され、稟議され、更新される**という商取引の側面を扱う。

| 含む | 含まない（隣接） |
| --- | --- |
| セキュリティ製品（EDR、SASE、IAM、WAF…）の市場 | 攻撃の手口・脅威動向 → [注目テーマ](../../01_注目テーマ/10_サイバーセキュリティ/README.md) |
| ベンダーの事業構造・M&A・チャネル | 防御技術の中身・運用実務 → 同上 |
| 監視代行・診断・コンサルのサービス市場 | 法制度の逐条解説 → 同上 [04_規制と制度](../../01_注目テーマ/10_サイバーセキュリティ/04_規制と制度.md) |
| セキュリティ人材の需給と単価 | IT人材一般 → [SIer・ITサービス](../05_SIer・ITサービス/README.md) |
| サイバー保険という商品 | 損害保険業の全体 → [損害保険](../../05_金融/08_損害保険/README.md) |
| 中小企業向け制度・補助金 | 物理警備・入退室管理 |

> 境界の目印：「**これは誰がいくらで売っている商品か**」を問えるならこのフォルダ、
> 「**攻撃者は何をしてくるのか／どう守るのか**」なら注目テーマ側。

## 3. バリューチェーン（川上 → 川下）

```
【川上：作る】                【中流：届ける】              【川下：使う／運用する】
海外製品ベンダー ───────▶ ディストリビュータ ──▶ SIer・販社 ──▶ ユーザー企業
 Palo Alto / CrowdStrike     在庫・与信・物流       提案・導入・保守    情シス（少人数）
 Microsoft / Google / Zscaler        │                   │                │
 トレンドマイクロ（国内）             │                   │                ▼
        │                          薄利                粗利は役務       「運用できない」
        │                                                 │                │
        │                                                 ▼                ▼
        │                                        国内セキュリティ専業 ◀── 委託
        │                                        ラック / NRIセキュア /
        │                                        SBT / 大手SIer
        ▼                                          MSSP・診断・コンサル
 【脅威情報・研究】                            【第三者の目】
  各社リサーチ部門、JPCERT/CC、IPA            監査法人、診断事業者、ISMS審査機関

 利幅が薄い ◀──────────────────────────────────▶ 利幅が厚い
 （機器転売・単純導入）                    （継続監視・事故対応・高度診断）
```

付加価値は**両端**に集まる。川上（製品のライセンス、粗利7〜8割）と、
川下の**高スキル役務**（フォレンジック、ペネトレーションテスト）である。
中流の「入れるだけ」は最も薄い。日本では製品側がほぼ海外勢なので、
国内企業の取り分は構造的に**川下＝人の商売**に寄る。

## 4. 主要プレイヤーとシェア

セキュリティには「業界全体のシェア」という統計が存在しない。カテゴリごとに別市場だからである。
**カテゴリ別の立ち位置**で見るのが実務的。

| 企業 | 立ち位置 | 特徴（2026年時点） |
| --- | --- | --- |
| Microsoft（米） | 全方位・バンドル | ライセンスに同梱して単体製品の価格を崩す。**単体ベンダー最大の脅威** |
| Palo Alto Networks（米） | 統合プラットフォーム | NGS ARR 91億ドル（＋63%）、RPO 212億ドル。CyberArk（約250億ドル）を2026年3月に統合 |
| CrowdStrike（米） | EDR起点のモジュール積み上げ | ARR 52.5億ドル（＋24%）、NRR 115%、サブスク粗利率79% |
| Alphabet / Google Cloud（米） | クラウド基盤＋セキュリティ | Wiz買収（約320億ドル、2026年3月完了）。専業買収として過去最大 |
| Cisco / Splunk（米） | ネットワーク＋ログ基盤 | SIEMを取り込み、通信とログを束ねる |
| Zscaler / Cloudflare（米） | 接続そのものを置き換える | SASE／ZTNA。ブラウザ領域にも進出 |
| Fortinet / Check Point（米・イスラエル） | ネットワーク機器系 | 中堅市場に強い。機器＋保守の資産を持つ |
| Okta / CyberArk（米） | ID・特権管理 | CyberArkはPalo Alto傘下に |
| トレンドマイクロ（日） | 国内唯一の総合製品ベンダー | 2026年12月期Q1の連結経常利益は前年同期比＋42.3%の176億円（報道ベース） |
| ラック／NRIセキュア／SBテクノロジー（日） | SOC・診断・コンサル | **国内の稼ぎ頭は運用と役務**。官公庁・金融に実績 |
| NEC／富士通／NTTデータ（日） | SIer兼セキュリティ | 重要インフラ・官公庁案件。制度対応で強い |
| GMOサイバーセキュリティ byイエラエ（日） | 診断・ペンテスト特化 | 2026年5月にGMOナショナルセキュリティを設立（クリアランス対応） |

## 5. 収益モデル・コスト構造

| 事業 | 何で儲けるか | コストの中心 | 粗利の目安 |
| --- | --- | --- | --- |
| 製品（ソフト・サブスク） | 年額ライセンス（端末数・ユーザー数） | 研究開発、脅威情報の収集 | **7〜8割**。解約率が業績を左右 |
| 製品（アプライアンス） | 機器＋保守契約 | 製造原価、保守要員 | 機器は薄利、**保守で回収** |
| MSS／MDR（監視代行） | 月額（監視対象数・ログ量） | **24時間365日の人件費** | 3〜4割。1人あたり担当社数がすべて |
| 導入・構築（SIer） | 案件ごとの請負 | 技術者の人件費 | 人月ビジネス。継続性が弱い |
| 脆弱性診断 | 案件ごと（50万〜300万円規模） | 高スキル人材 | ツール自動化で改善可能 |
| ペネトレーションテスト | 案件ごと（50万〜1,000万円超） | 極めて希少な人材 | 単価は高いが**人数が増やせない** |
| フォレンジック・事故対応 | 時間単価・緊急対応 | 同上 | 最高単価。**平時は売上が立たない** |
| コンサル・認証支援 | 案件ごと | 人件費 | 規制強化が直接の需要 |

> 全体の癖：**製品は高粗利、運用は労働集約**。だから製品ベンダーは運用を取り込みたがり
> （＝プラットフォーム化）、運用事業者は自動化・AIで1人あたりの担当社数を増やしたがる。
> M&Aが止まらない理由も、AI SOCに資金が流れる理由も、突き詰めればこの一点にある。

## 6. 競争要因（KSF）と参入障壁

**KSF（成功の鍵）**

1. **顧客数＝脅威情報の量**。守っている先が多いほど攻撃の兆候を早く広く掴める。
   セキュリティは数少ない**ネットワーク効果が効く領域**
2. **誤検知の少なさ**。警報が多すぎると現場が見なくなる。精度＝運用の継続性
3. **統合の幅**。「ツールを減らしたい」という買い手の疲れが最大の営業トークになった
4. **運用できる人を出せるか**。製品を売っても運用できなければ効果が出ず更新もされない
5. **調達要件を満たすか**。資格・実績・国内対応が入札の可否を決める領域がある

**参入障壁**

| 障壁 | 中身 |
| --- | --- |
| 脅威情報の蓄積 | 後発は同じ検知精度を出せない。時間でしか埋まらない |
| 24時間体制の人員 | サービス事業は**採用できた人数が売上上限**になる |
| 既存導入の粘着性 | 入れ替えは業務停止リスクを伴う。乗り換えには肩代わり原資が要る |
| 認証・実績 | 政府調達、金融取引、クリアランス制度 |
| バンドルへの対抗 | 「もう払っている分に入っている」に価格で説明を迫られる |

一方、**尖った新領域への参入は容易**である。新カテゴリは常に専業スタートアップから生まれ、
成長すると大手に買われる。これが市場の新陳代謝の基本形になっている。

## 7. 規制・法制度

制度の中身は [注目テーマ 04_規制と制度](../../01_注目テーマ/10_サイバーセキュリティ/04_規制と制度.md) に譲り、
ここでは**それが産業にどう効くか**だけを書く。

```
  規制・制度              買い手の行動              産業への効き方
 ──────────            ──────────              ──────────────
  改正個人情報保護法  ─▶  漏えい時の損失が増える ─▶ 予防投資の稟議が通る
  サイバー対処能力強化法 ─▶ 報告義務・体制整備    ─▶ コンサル・監視の需要
  （2026年10月1日施行）
  経済安保／クリアランス ─▶ 有資格者しか扱えない  ─▶ **国内事業者の保護区**ができる
  EU NIS2 / CRA      ─▶  取引先経由で要求が来る ─▶ 日本企業にも対応需要
  米SEC開示規則       ─▶  上場子会社に波及      ─▶ 開示準備・訓練の需要
  補助金（中小向け）   ─▶  価格のハードルが下がる ─▶ 中小市場が商売になる
```

| 制度が作る市場 | 具体例 |
| --- | --- |
| **義務が需要を作る** | 報告体制、監査対応、ISMS取得支援 |
| **資格が参入を絞る** | 情報処理安全確保支援士、IPA適合サービスリスト、クリアランス |
| **補助金が価格を作る** | デジタル化・AI導入補助金2026「セキュリティ対策推進枠」（上限450万円、補助率原則1/2） |

> 要点：**セキュリティ産業にとって規制は「コスト」ではなく「需要」である。**
> 制度が変わる年に売上計画を合わせるのが、この業界の営業の常識になっている。

## 8. 最近のトピック

詳細と出典URLは [04_直近トピック_2026](04_直近トピック_2026.md)。要点は5つ。

1. **プラットフォーム化が決算で証明された**。Palo AltoはNGS ARR 91億ドル（＋63%）、
   RPO 212億ドル（初の200億ドル超）。CrowdStrikeはARR 52.5億ドル（＋24%）、NRR 115%
2. **過去最大級の買収が同じ月に2件完了**。Google×Wiz 約320億ドル、
   Palo Alto×CyberArk 約250億ドル（ともに2026年3月）。2026年上半期のM&Aは219件
3. **次の争奪地はブラウザ**。CrowdStrikeがSeraphic（2026年1月）、
   ZscalerがSquareX（2026年2月）を取得。SaaS時代の新しい検査点
4. **資金はAIセキュリティへ**。2026年上半期のVC調達106億ドル、
   AIネイティブ領域はQ1で41億ドル（＋47%）。**AI SOCはMSSPの人月商売を直接狙う**
5. **国内は堅調、勝ち筋は運用と制度対応**。国内ソフトウェア市場は2029年に1兆円規模（IDC予測）、
   伸びの中心はEDR・ID・分析。GMOはクリアランス対応の新会社を設立（2026年5月）
