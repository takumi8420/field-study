## 1. プラットフォーム化が、ついに決算の数字になった

2026年は「まとめ売り戦略が本当に儲かるのか」への答えが出た年になった。

| 指標 | 数値 | 時点・出典 |
| --- | --- | --- |
| Palo Alto Networks 第4四半期売上 | 34.1億ドル（前年比＋34%） | 2026年7月期Q4、同社IR |
| 同・NGS ARR（次世代セキュリティの年額契約残） | **91億ドル（前年比＋63%）** | 同上 |
| 同・四半期の純増NGS ARR | 約10億ドル（前年のほぼ2倍） | 同上 |
| 同・RPO（契約済み未計上残高） | **212億ドル**（初の200億ドル超） | 同上 |
| CyberArk（買収済み）のACV成長率 | 20%（Q2）→ 27%（Q4）へ加速 | 2026年、会社側説明 |
| CrowdStrike ARR | 52.5億ドル（前年比＋24%）。NRR 115%、GRR 97% | 2026年1月期、同社IR |
| CrowdStrike サブスク粗利率 | 79%（GAAP）／81%（非GAAP） | 同Q4 |

> 読みどころ：Palo Altoの「プラットフォーム化」は、**他社製品の残契約期間を実質肩代わりして
> 自社に乗り換えさせる**売り方で、短期の売上・利益率を犠牲にする。
> 2026年はその我慢が **NGS ARR＋63%／RPO 212億ドル** という形で回収局面に入ったと説明された。
> 一方で利益率への懸念も同時に報じられており（2026年9月、市場コメント）、
> **「安く束ねて後から回収する」モデルの持続性**がこの先の論点になる。

## 2. 過去最大の買収が2件、同じ月に完了した

| 案件 | 金額（報道ベース） | 完了 | 意味 |
| --- | --- | --- | --- |
| Alphabet（Google）→ Wiz | 約320億ドル | 2026年3月 | **専業セキュリティ企業の買収として過去最大**。クラウド基盤側がセキュリティを内製化 |
| Palo Alto Networks → CyberArk | 約250億ドル | 2026年3月 | ID・特権管理をプラットフォームの中核へ |

再編そのものの件数も高水準が続く。**2026年上半期のM&Aは219件**（Momentum Cyber集計）で
半期として過去最速ペースと報じられ、**2026年3月の1か月だけで38件**という集計もある（業界分析）。

```
 【2024〜2026年の再編の流れ】

  2024年  Cisco  × Splunk（約280億ドル）      ログ基盤を通信と束ねる
     │
  2026年3月 Alphabet × Wiz（約320億ドル）      クラウド事業者がクラウド防御を取り込む
  2026年3月 Palo Alto × CyberArk（約250億ドル） ネットワーク系がIDを取り込む
     │
  2026年前半 小型買収が多数（ブラウザ、AI、データ）
     │
     ▼
  残るのは「土台を持つ数社」＋「尖った専業」。中間サイズが一番苦しい
```

## 3. 次の争奪地はブラウザ：小型買収が相次いだ

2026年前半に目立ったのが**ブラウザセキュリティ**という新カテゴリの取り合いである。

| 買い手 → 対象 | 時期 |
| --- | --- |
| CrowdStrike → Seraphic Security | 2026年1月 |
| Zscaler → SquareX | 2026年2月 |

背景はシンプルで、**業務の大半がSaaS＝ブラウザの中で完結するようになった**ため、
端末とネットワークの中間に「ブラウザ」という新しい検査点が生まれたことにある。
[01_製品カテゴリと市場の地図](01_製品カテゴリと市場の地図.md) で見た
「新しい攻撃面 → 新カテゴリ → 大手が買う」の教科書どおりの展開になっている。

| 指標 | 数値 | 時点・出典 |
| --- | --- | --- |
| セキュリティ／プライバシー領域のVC調達 | 2026年上半期で106億ドル | Crunchbase |
| 同・2025年通年 | 187億ドル | 同上 |

| 個別事例 | Exaforce（AI SOCエージェント）1.25億ドルのシリーズB、Tenex.AI・Upwind Securityが各2.5億ドルのシリーズB | 2026年、同上 |

> 産業構造として重要なのは、これが**MSSP／SOCの人月商売を直接置き換えにいく投資**である点。
> [03_サービス事業と買い手の経済学](03_サービス事業と買い手の経済学.md) で見たとおり、
> 監視サービスの利益は「1人が何社見られるか」で決まる。
> AIが一次対応（Tier1）を担えば、**同じ人数で扱える社数が跳ね上がる**。
> 逆に言えば、自動化できなかった事業者は人件費の重さがそのまま残る。

なお、2026年4月にOpenAIが「Trusted Access for Cyber」プログラムで
Palo Alto・CrowdStrike・Zscalerを事実上の統合プレイヤーとして位置づけたと報じられており、
**AI基盤側がベンダーの序列に影響を与え始めている**（報道・業界分析ベース）。

## 5. 国内市場：ソフトウェアが二桁成長、2029年に1兆円へ

| 指標 | 数値 | 時点・出典 |
| --- | --- | --- |
| 国内セキュリティソフトウェア市場 | 2024年 5,861億100万円（前年比＋14.6%） | IDC Japan（2025年5月公表） |
| 同・2029年 | 1兆307億2,700万円（CAGR 12.0%） | 同予測 |
| 同・2025年上半期 | 前年同期比＋14.1% | IDC Japan |
| エンドポイント | 1,734億3,100万円（＋10.1%）。うち**EDRは＋22.8%** | 2024年、IDC Japan |
| IAM | 1,125億750万円（＋15.8%） | 同上 |
| セキュリティ分析 | 856億2,435万円（＋22.9%） | 同上 |

伸びの中身は**EDR・ID・分析**の3つに集中している。
「端末に入れる」「誰かを確かめる」「ログを見る」という、
いずれも**運用が前提の製品**であり、国内でサービス需要が縮まない理由もここにある。

参考までに、IDCが2022年時点で出していた予測は「国内セキュリティソフトウェア市場は2026年に4,637億円」
だった。**実績は2024年で5,861億円**と、2年前倒しで予測を超えている。
市場規模を引用するときは**いつ出された予測か**を必ず確認したい。

## 6. 国内：経済安全保障が新しい商材になった

2026年5月29日、GMOサイバーセキュリティ byイエラエが
**「GMOナショナルセキュリティ」**を設立した（同社発表）。
行政機関・重要インフラ事業者を対象に、**セキュリティ・クリアランス制度に準拠した支援**を行うとしている。

```
 制度ができる ─▶ 調達要件が変わる ─▶ 要件を満たす会社しか入札できない ─▶ 専用の子会社を作る

  重要経済安保情報保護活用法（クリアランス制度）
  サイバー対処能力強化法（2026年10月1日施行）
        │
        ▼
  「有資格の国内事業者」という参入障壁つきの市場が生まれる
```

> 制度は規制であると同時に**市場の仕切り**でもある。
> 日本のセキュリティ事業者にとって、海外プラットフォームと正面から戦わずに済む領域が
> 「国内対応・クリアランス・官公庁実績」であり、そこに資源を寄せる動きが具体化した例と言える。
> 制度そのものの中身は
> [注目テーマ側の 04_規制と制度](../../01_注目テーマ/10_サイバーセキュリティ/04_規制と制度.md) を参照。

## 7. 中小企業向け：補助金の器が変わった

2026年度から、**IT導入補助金が「デジタル化・AI導入補助金2026」に再編**された（中小企業庁）。
その中に**セキュリティ対策推進枠**が置かれ、中小企業のセキュリティ投資を支える構図は維持されている。

| 項目 | 内容 | 時点・出典 |
| --- | --- | --- |
| 制度名 | デジタル化・AI導入補助金2026（旧・IT導入補助金） | 2026年、中小企業庁 |
| 補助上限 | 1者あたり最大450万円（制度全体） | 同上。※枠別の上限は公募要領で要確認 |
| 補助率 | 原則1/2。小規模事業者は要件を満たせば最大4/5 | 同上 |
| お助け隊サービス | 全国1万社超が導入。補助金利用で月額1万円以下の水準になる場合がある | 2026年、経産省・IPA |

## 8. 全体の構図

2026年の情報セキュリティ産業は、**「束ねる側」と「尖る側」の二極化**がはっきりした年だった。

1. **束ねる側**は決算で結果を出した。Palo AltoのNGS ARR＋63%、RPO 212億ドルがその象徴で、
   GoogleのWiz買収（約320億ドル）はクラウド事業者が防御を内製化する流れを決定づけた
2. **尖る側**は資金で支えられている。VCは2026年上半期で106億ドル、
   とくにAIネイティブ領域が最速で伸び、**出口は大手への売却**という構図が定着した
3. **中間サイズが最も苦しい**。土台になるほど広くなく、買われるほど尖ってもいない
4. **サービス事業はAIに挟まれた**。AI SOCへの投資は、労働集約だったMSSPの利益構造を
   数年単位で書き換えにいく。自動化できた事業者だけが単価を維持できる
5. **日本は市場としては堅調、産業としては運用と制度対応が勝ち筋**。
   ソフトウェア市場は2029年に1兆円規模（IDC予測）だが売り物は海外製が中心で、
   国内勢の利益は「人」と「国内要件」に寄っていく

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **NGS ARR** | Palo Alto Networksが使う自社定義の指標。次世代セキュリティ（クラウド・AI系）製品の年額契約残高 |
| **RPO** | Remaining Performance Obligation。契約済みでまだ売上計上していない残高。将来の売上の予約分 |
| **ACV** | Annual Contract Value。1契約あたりの年額 |
| **NRR / GRR** | 既存顧客の増減を含む維持率／解約だけを見た維持率。サブスク事業の健康診断 |
| **ブラウザセキュリティ** | 業務がSaaS＝ブラウザ内で完結する前提で、ブラウザを検査点にする新しい製品カテゴリ |
| **AI SOC** | 監視センターの一次対応をAIエージェントに担わせる考え方。人月商売の原価構造を変えにいく |
| **セキュリティ・クリアランス** | 重要情報を扱う人物を国が適格性評価する制度。対応可能な事業者しか入れない市場が生まれる |
