# 日本市場の特殊事情と現在地

このノートで分かること：日本でeスポーツが「盛り上がっているのに儲からない」理由を、
**法制度（景品表示法・賭博罪・風営法）**、**JESU＝プロライセンス制度の経緯**、
**市場規模の実態と予測の甘さ**の3方向から見る。

結論を先に書く。日本のeスポーツが世界と違うのは、次の3点に尽きる。

1. **高額賞金を出しにくい法制度**が長く足かせになり、独自の回避策（プロライセンス）を生んだ
2. **賭け（ベッティング）が違法**なため、海外で最大の周辺収益が丸ごと存在しない
3. **市場規模が約161億円（2024年）と小さい**のに、報道と予測だけが先行してきた

## 1. 市場規模の実態 ── 161億円という数字の重さ

| 指標                  | 数値                                   | 時点・出所                                                     |
| --------------------- | -------------------------------------- | -------------------------------------------------------------- |
| 国内eスポーツ市場規模 | **約161億円**（前年比+9.9%）           | 2024年実績、日本eスポーツ協会『日本eスポーツ白書2025』（推計） |
| 同 予測               | **200億円超**                          | 2026年予測、同（推計）                                         |
| 国内eスポーツファン数 | 約967万人                              | 2024年、同（推計）                                             |
| 国内競技人口          | 約419万人（ファンの43.3%）             | 2024年、同（推計）                                             |
| 同 ファン数予測       | 約1,500万人に迫る                      | 2026年予測、同（推計）                                         |
| 市場の内訳            | イベント運営 37.3%／スポンサー 35%以上 | 2024年、同                                                     |
| 年平均成長率          | 約10%（2020年以降）                    | 同                                                             |

**この数字をどう読むか**が重要である。

```
   国内市場規模の比較（2024年前後、各種統計・推計）

   ゲーム市場（国内）      ██████████████████████████  2兆円超
   ネット広告（国内）      ██████████████████████████  3兆円超
   プロ野球12球団売上      ████████                     2,000億円規模
   Jリーグ全クラブ営業収益  ████████                     1,500億円規模
   eスポーツ（国内）       ▍                            161億円

   → eスポーツは「ゲーム産業の1%未満」の規模しかない。
     単独の産業というより、ゲームの販促・周辺領域と見るのが実態に近い
```

161億円という規模は、**中堅企業1社の売上**と同じ水準である。
「eスポーツ業界」と呼ばれてはいるが、**業界と呼べるほどの厚みはまだない**。
ゲーム本体の市場は [ゲーム](../10_ゲーム/README.md)、
広告市場との比較は [ネット広告](../07_ネット広告/README.md) を参照。

### 予測値を鵜呑みにしない

2018年前後には「2025年に国内600億〜3,000億円」といった予測が複数のレポートで出回った。
実績は2024年で161億円であり、**多くの予測が大きく外れた**。
外れた理由は構造的で、次の3つに整理できる。

| 予測が外れた理由                   | 中身                                                             |
| ---------------------------------- | ---------------------------------------------------------------- |
| ① 視聴者数＝市場と混同した         | 見る人が増えても、その人は競技に金を払わない（ゲーム本体に払う） |
| ② 海外の構成比をそのまま当てはめた | 日本にはベッティング収益がなく、放映権市場も小さい               |
| ③ スポンサー予算の性質を見誤った   | 広告費は景気で削られる。積み上げ式の成長を前提にできない         |

> 教訓：**「市場規模予測」が出たら、その内訳（何を市場に含めているか）を必ず見る。**
> 特にeスポーツでは、ゲーム内課金・ハードウェア・ベッティングを含めるかどうかで
> 数字が数倍変わる。世界市場でも2026年で約33億ドル〜約51億ドルと推計に開きがある。

## 2. 法制度 ── 高額賞金をめぐる3つの法律

日本でeスポーツの賞金が長く低額に抑えられてきた理由は、**3つの別々の法律**にある。
よく「景表法のせい」と一括りにされるが、**論点が異なるので分けて理解する必要がある**。

```
   大会の設計 ──┬─▶ ① 景品表示法      「賞金は景品類か？」
                 │                        → 該当すると上限規制がかかる
                 │
                 ├─▶ ② 刑法185条 賭博罪  「参加費を原資に賞金を配るのか？」
                 │                        → 該当すると主催も参加者も違法
                 │
                 └─▶ ③ 風営法           「店舗で有料ゲーム提供＋景品は？」
                                          → 施設営業の形態に制約
```

| 法律                           | 何が問題になるか                                                                                                               | 実務上の回避・整理                                                                  |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------- |
| **景品表示法**（景表法）       | ゲームの購入者を対象に賞金を出すと「**景品類**」に該当しうる。該当すると取引価額に応じた上限（一般懸賞で最高10万円等）がかかる | ①賞金を「**仕事の対価**」と構成する ②購入を条件にしない大会にする ③参加者を限定する |
| **刑法185条 賭博罪**           | **参加費を原資に勝者へ配る**と、参加者が財物を賭けた構図になり賭博に当たりうる                                                 | 賞金は**主催者・スポンサーが全額拠出**する。参加費は実費（会場費等）に留める        |
| **風営法**（風俗営業適正化法） | 店舗で遊技の結果に応じて客に利益を与える営業形態への規制。eスポーツ施設の設計に影響                                            | 時間貸し・施設利用料方式にし、賞品提供を切り離す                                    |

**最も重要な整理**：賞金が「**興行への出演・参加という労務の対価**」と位置づけられれば、
景表法の景品類には当たらない。つまり、**プロライセンスがなくても法的には対応できる**というのが
現在の一般的な理解である。ここが次節の論点につながる。

## 3. JESU（日本eスポーツ協会）とプロライセンス制度

### 経緯

| 時期         | できごと                                                                                                                 |
| ------------ | ------------------------------------------------------------------------------------------------------------------------ |
| 2018年2月    | 国内3団体が統合し **JeSU（日本eスポーツ連合）** 設立。同時に**プロライセンス制度**を発表                                 |
| 2018〜2019年 | 「賞金を受け取れるのはライセンス保持者だけ」という運用が広がり、批判が集中                                               |
| 2019年頃     | 消費者庁の見解等を踏まえ、**賞金は仕事の対価と整理でき、プロ・アマを問わず景品類に当たらない場合がある**との理解が広がる |
| 以降         | ライセンスの法的必要性が薄れ、**制度の意義そのものが論点**に                                                             |
| 2025年8月1日 | 法人名称を **一般社団法人日本eスポーツ協会（JESU）** に変更、共同代表制を導入                                            |

### 何が批判されたのか

JESU側の当初の説明は「ゴルフのプロ制度と同じで、信頼できる団体が認定すれば
メーカーが高額賞金を出せる」というものだった。これに対する主な反論は次の通り。

| 批判                           | 中身                                                                                                         |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------ |
| **ゴルフとの類比が成立しない** | ゴルフのプロ制度は景表法対策ではない。ゴルフは特定企業が所有する競技ではないため、そもそも前提が違う         |
| **ライセンスが不要である**     | 賞金を労務の対価と構成すれば足りる。ライセンスは法的必要条件ではない                                         |
| **権利構造と矛盾する**         | 競技を所有しているのはメーカーであり、JESUはメーカーの許諾なしにリーグを作れない。統括団体としての権限が弱い |
| **参入障壁になりうる**         | 認定団体が出場資格を握ると、選手の活動を制約する側に回る                                                     |

> ここが日本の特殊事情の核心。
> 「**統括団体が競技を統括できない**」という状態は、既存スポーツではありえない。
> 権利構造については [01_eスポーツは誰の商売か](01_eスポーツは誰の商売か.md) を参照。

現在のJESUの実質的な役割は、ライセンス発行よりも
**国際大会（アジア競技大会等）への日本代表派遣**、**統計（白書）の整備**、
**自治体・学校への普及**、**法的論点の整理**といった、地味だが必要な基盤整備に移っている。

## 4. ベッティング（賭け）が存在しないという構造差

海外のeスポーツでは、賭けが大きな収益基盤になっている。
Riot Games は2025年6月、北米・欧州の上位チームに**ベッティング企業のスポンサー**を解禁し、
その根拠として自社2タイトルに関連する世界のベッティング取扱高が2024年に**107億ドル**にのぼる
（Sportradar データ）と説明したと報じられる。

日本では刑法の賭博罪により、これが丸ごと存在しない。

```
   【海外のeスポーツ収益の裾野】      【日本】

   スポンサー ████                    スポンサー ████
   放映・配信 ███                     放映・配信 █
   グッズ     ██                      グッズ     ██
   ベッティング関連 ████              ベッティング  （存在しない）
   スキン取引／賭博的要素 ██          スキン取引   （ほぼ存在しない）

   → 日本は「裾野の収益」がない分、
     スポンサー依存度がさらに高くなる
```

| 海外にあって日本にないもの                           | 影響                                               |
| ---------------------------------------------------- | -------------------------------------------------- |
| **スポーツベッティング**                             | ブックメーカーのスポンサー料・データ販売収入がゼロ |
| **スキンギャンブル**（ゲーム内アイテムを賭ける行為） | 海外では規制対象だが視聴動機にはなっていた         |
| **大規模な放映権市場**                               | 地上波・有料放送がeスポーツに高額を払う土壌がない  |

日本でもスポーツベッティング解禁の議論は継続しているが、
2026年時点で**eスポーツへの適用の見通しは立っていない**。
なお、これは「日本が遅れている」という単純な話ではない。
賭けに依存した収益構造は、八百長・未成年保護の問題を抱えており、
海外でも規制強化の対象になっている。

## 5. 施設・大会運営の実態

| 形態                      | 中身                                 | 経済性                                           |
| ------------------------- | ------------------------------------ | ------------------------------------------------ |
| **eスポーツ施設・カフェ** | 高性能PCを時間貸し。飲食併設         | ネットカフェに近い**坪効率商売**。機材更新が重い |
| **大型イベント併設**      | 東京ゲームショウ等での大会           | 主催の販促予算で成立。単独収支は見ない           |
| **自主興行の大会**        | 会場を借りて有料観戦                 | 国内では黒字化が難しく、事例が限られる           |
| **受託運営**              | メーカー・スポンサーの大会を請け負う | **最も堅い**。ウェルプレイド・ライゼスト等       |
| **オンライン大会**        | 会場費ゼロ                           | 収益も小さい。裾野の拡大が目的                   |

施設ビジネスの落とし穴は、**ゲーミングPCが数年で陳腐化する**点にある。
1台20〜30万円のPCを数十台抱えると、**設備投資の償却が固定費として重くのしかかる**。
稼働率が落ちれば即赤字になる構造で、実際に開業から数年で閉店する施設が相次いでいる（報道ベース）。
施設型サービスの経済は [テーマパーク・レジャー](../../15_サービス・生活関連/08_テーマパーク・レジャー/README.md) と似た論点を持つ。

## 6. 学校・自治体の取り組み ── 「産業」ではなく「政策」として広がっている

日本のeスポーツで最も裾野が広がっているのは、実は商業領域ではなく**教育・地域政策の領域**である。

| 主体                 | 取り組み                                                                                    | ねらい                                         |
| -------------------- | ------------------------------------------------------------------------------------------- | ---------------------------------------------- |
| **高校**             | 部活動化。「STAGE:0」（テレビ東京・電通主催）等の高校対抗大会                               | 生徒の居場所づくり、学校の広報                 |
| **専門学校**         | eスポーツ学科の設置                                                                         | 学生募集の目玉。ただし就職先の受け皿は限られる |
| **自治体**           | 大会誘致、シニア向けeスポーツ講座、地域振興イベント                                         | 関係人口づくり、健康・福祉、シャッター街対策   |
| **日本スポーツ協会** | 国民スポーツ大会の文化プログラムとして都道府県対抗大会を実施 → **2028年から独立した大会へ** | 競技としての定着                               |
| **福祉・介護**       | 高齢者施設でのeスポーツ導入                                                                 | 認知機能・交流の維持                           |

2026年9月3日、日本スポーツ協会は国スポの文化プログラムとして開催してきた
都道府県対抗eスポーツ大会を**国スポから切り離して独立の大会にする**と発表した。
第1回は2028年1〜3月ごろを目指し、毎年開催する計画と報じられている。

> 冷静に見ておくべきこと：これらは**市場規模をほとんど押し上げない**。
> 自治体事業の単価は低く、学校の部活動は収益を生まない。
> 「盛り上がり」と「市場規模」が乖離する最大の理由がここにある。
> ただし、**競技人口と社会的受容を作る**という点では意味が大きく、
> 長期的には選手供給と観戦習慣の土台になりうる。

## 7. 日本市場の現在地 ── 3行でまとめると

> - 規模は**約161億円**（2024年）。ゲーム市場の1%未満で、**独立産業には至っていない**
> - 収入源が**イベント運営とスポンサー**にほぼ二分され、ベッティング・放映権という裾野がない
> - 制度整備（法的論点、統括団体、学校・自治体）は進んだが、**それが売上に変換されていない**

伸びる可能性があるとすれば、次の3経路である（いずれも確証はない）。

| 経路                           | 内容                                       | 実現性の見方                                 |
| ------------------------------ | ------------------------------------------ | -------------------------------------------- |
| **ゲーム会社の販促予算の拡大** | メーカーがタイトル延命策として投資を増やす | 最も現実的。ただし**メーカー都合で増減する** |
| **チームのメディア企業化**     | ストリーマー事業・グッズ・タイアップで自立 | 既に進行中。成功例は限られる                 |
| **観戦市場の成立**             | 有料観戦・サブスクが根付く                 | 難しい。無料視聴の慣習が強固                 |

## 用語メモ

| 用語                           | 意味                                                                                       |
| ------------------------------ | ------------------------------------------------------------------------------------------ |
| **JESU（日本eスポーツ協会）**  | 国内の統括団体。2018年設立、2025年8月に「日本eスポーツ連合」から改称                       |
| **プロライセンス**             | JESUが発行する選手認定。高額賞金の根拠とされたが、法的必要性は薄いとの整理が定着           |
| **景品表示法（景表法）**       | 商品の購入者に過大な景品を提供することを制限する法律。賞金が「景品類」に当たるかが論点     |
| **景品類**                     | 取引に付随して提供される経済的利益。一般懸賞で最高10万円等の上限がある                     |
| **仕事の対価**                 | 興行への出演・参加の報酬という構成。これなら景品類に当たらないとされる                     |
| **賭博罪（刑法185条）**        | 偶然の勝敗に財物を賭ける行為の禁止。**参加費を原資にした賞金**が問題になる                 |
| **風営法**                     | 風俗営業等の規制法。店舗型eスポーツ施設の営業形態に影響する                                |
| **ベッティング**               | 試合結果への賭け。海外では主要収益源だが日本では違法                                       |
| **スキンギャンブル**           | ゲーム内アイテム（スキン）を賭ける行為。海外で規制対象                                     |
| **日本eスポーツ白書**          | JESUが発行するデータ年鑑（制作・販売は角川アスキー総合研究所）。国内市場推計の標準的な出典 |
| **STAGE:0**                    | テレビ東京・電通主催の高校対抗eスポーツ大会。国内最大級                                    |
| **国スポ（国民スポーツ大会）** | 旧・国民体育大会。文化プログラムでeスポーツ大会を実施してきた                              |
