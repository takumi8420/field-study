# eスポーツ

- 大分類: 情報通信・IT・ネット
- 状態: done
- 更新日: 2026-09-20

ビデオゲームの対戦を競技・興行として成立させる産業。
既存スポーツと決定的に違うのは、**競技（＝ゲーム）そのものに著作権者がいて、
メーカーがリーグを所有している**点にある。
国内市場は**約161億円**（2024年、JESU推計）とゲーム市場の1%未満で、
**話題性と実際の規模の乖離が最も大きい分野**のひとつ。

## 1. 業界の定義・範囲

**eスポーツ**＝ビデオゲームの対戦を、観客のいる競技・興行として成立させる事業領域。
プレイ行為そのものではなく、**大会・リーグ・チーム・配信を成り立たせる経済**を指す。

| 区別すべき言葉                | 中身                                                                                                                   |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| **eスポーツ**（このフォルダ） | 競技としての大会・リーグ・チーム・観戦。**メーカーの許諾の上に成立する**                                               |
| ゲーム                        | ソフト・ハードの開発と販売、課金 → [ゲーム](../10_ゲーム/README.md)                                                    |
| ゲーム実況・配信              | 競技でない配信活動。収益源は広告・投げ銭 → [動画・音楽配信](../12_動画・音楽配信/README.md)                            |
| スポーツビジネス              | 既存競技のリーグ・クラブ経営 → [スポーツビジネス](../../14_メディア・広告・エンタメ/12_スポーツビジネス/README.md)     |
| アミューズメント施設          | ゲームセンター等の店舗営業 → [テーマパーク・レジャー](../../15_サービス・生活関連/08_テーマパーク・レジャー/README.md) |

```
  ゲームメーカー ─▶ ★eスポーツ（大会・リーグ）★ ─▶ 配信 ─▶ 視聴者
   著作権者          チーム／選手／運営会社          Twitch    ファン
      ▲                      ▲                      YouTube      │
      │ 課金                 │ スポンサー料                       │
      └──────────────────────┴──── 広告効果 ◀── スポンサー企業 ◀─┘

  ★のところは、実は「メーカーの販促予算の下流」にいる
```

**境界の引き方で注意すべきこと**：「eスポーツ市場」という言葉は、
ゲーム内課金やハードウェアまで含めて語られることがある。
本フォルダでは**競技・興行に関わる収支**に絞る。含める範囲で数字が数倍変わるため、
出典の定義を確認せずに市場規模を引用しないこと。

## 2. 市場規模と成長性

| 指標               | 数値                                               | 時点・出所                                        |
| ------------------ | -------------------------------------------------- | ------------------------------------------------- |
| **国内市場規模**   | **約161億円**（前年比+9.9%）                       | 2024年実績、JESU『日本eスポーツ白書2025』（推計） |
| 同 予測            | **200億円超**                                      | 2026年予測、同（推計）                            |
| 国内ファン数       | 約967万人 → 2026年に約1,500万人に迫る見込み        | 同（推計）                                        |
| 国内競技人口       | 約419万人（ファンの43.3%）                         | 2024年、同（推計）                                |
| 国内の内訳         | イベント運営 37.3%／スポンサー 35%以上             | 2024年、同                                        |
| 国内の年平均成長率 | 約10%（2020年以降）                                | 同                                                |
| 世界市場規模       | **約33億ドル〜約51億ドル**（推計に大きな開き）     | 2026年、Grand View Research／Statista（推計）     |
| 世界の収益構成     | スポンサーが40%超。スポンサー＋メディア権利で約65% | 2025年、調査会社推計                              |

**冷静に押さえること**：

- 国内161億円は**ゲーム市場（2兆円超）の1%未満**。プロ野球12球団の売上合計にも遠く及ばない
- ファン967万人で161億円 ＝ **1人あたり年間約1,700円**。単価の低さが構造的な弱点
- 2018年前後に出回った「2025年に600億〜3,000億円」といった予測は**大きく外れた**。
  視聴者数と市場規模を混同したこと、海外の収益構成（ベッティング含む）を当てはめたことが原因
- 世界市場の推計が1.5倍以上ばらつくのは、**含める範囲が統一されていない**ため

## 3. バリューチェーン（川上 → 川下）

```
 ① ゲームメーカー ─▶ ② リーグ／大会運営 ─▶ ③ チーム ─▶ ④ 配信PF ─▶ ⑤ 視聴者
   著作権・許諾        主催・制作受託        選手雇用    Twitch等     ファン
        │                                      ▲
        │  ◀── スポンサー料 ────── ⑥ スポンサー企業（広告予算）
        │
        └─▶ ゲーム内課金（ファンの支払いの大半はここへ戻る）
```

| 工程                   | 担い手                                                             | どこに価値が集まるか                                     |
| ---------------------- | ------------------------------------------------------------------ | -------------------------------------------------------- |
| ① ゲームメーカー       | Riot Games、カプコン、任天堂、セガ、Valve、Krafton 等              | **最強**。競技を所有し、開催可否・リーグの形を決める     |
| ② 大会・リーグ運営     | ウェルプレイド・ライゼスト、CyberZ（RAGE）、各メーカーの運営子会社 | **受託型は堅い**。発注元がリスクを持つため               |
| ③ チーム               | ZETA DIVISION、DetonatioN Gaming、REJECT、Crazy Raccoon 等         | **最も苦しい**。固定費を持ち、収入は他者依存             |
| ④ 配信プラットフォーム | Twitch、YouTube Live、ニコニコ生放送                               | 視聴の器。独占配信料バブルは終了                         |
| ⑤ 視聴者・ファン       | 一般ユーザー                                                       | 支払いの大半は**ゲーム本体**へ向かい、競技には向かわない |
| ⑥ スポンサー           | PC・周辺機器、通信、飲料、金融 等                                  | 実質の資金源。**景気で真っ先に削られる**                 |

> ポイント：ファンのお金は①へ戻り、③には広告経由でしか届かない。
> これが「観客は増えているのにチームは儲からない」ことの正体。詳細は
> [01_eスポーツは誰の商売か](01_eスポーツは誰の商売か.md)。

## 5. 収益モデル・コスト構造

| 収益源                         | 誰に入るか       | 安定性                                               |
| ------------------------------ | ---------------- | ---------------------------------------------------- |
| **スポンサーシップ**           | チーム・リーグ   | 世界で4割超と最大。**広告市況に直撃される**          |
| **イベント運営（受託・興行）** | 運営会社         | 国内市場の37.3%（2024年）。受託型は堅い              |
| 放映権・配信権                 | メーカー／リーグ | 独占配信バブルは2020年前後で終了                     |
| グッズ・チケット               | チーム・主催     | 小さいが自前で伸ばせる数少ない収入                   |
| 賞金                           | 選手・チーム     | **事業計画に組めない**。勝てばスパイク、負ければゼロ |
| ベッティング関連               | （海外のみ）     | 日本では賭博罪により存在しない                       |

**チームのコスト構造の核心**：

- 選手給与・スタッフ・ゲーミングハウス・配信体制が**すべて固定費**。成績と無関係に発生する
- 一方、収入の上振れ要因は賞金だけで、それが最も不確実 → **構造的に赤字が既定路線**
- 国内では「月給30万円の選手5人で年間3,500万円規模の赤字」という運営者の試算が話題になった（報道ベース）
- 結果、チームは「競技で勝つ会社」から「**ファンを持つメディア会社**」へ寄る
- 詳細は [01_eスポーツは誰の商売か](01_eスポーツは誰の商売か.md)

## 6. 競争要因（KSF）と参入障壁

| 要因                         | 中身                     | 障壁の高さ                                             |
| ---------------------------- | ------------------------ | ------------------------------------------------------ |
| **メーカーとの関係**         | 出場枠・許諾を得られるか | **最重要かつ最も不安定**。相手の都合で変わる           |
| ファンベース・SNS到達力      | スポンサー料の根拠になる | 高い。時間がかかる                                     |
| 有力選手・ストリーマーの保有 | 露出と交渉力の源泉       | 中。資金力で買えるため消耗戦になりやすい               |
| 運営実績・制作能力           | 受託を取り続ける力       | 中。人材依存                                           |
| 資本力                       | 赤字を継続できるか       | **実質的な参入障壁**。黒字化が前提にならない           |
| タイトル選択                 | どのゲームに賭けるか     | **経営の最大の賭け**。タイトルが衰退すれば資産が消える |

> チーム運営の参入自体は容易（法人を作り選手を雇えばよい）。
> 難しいのは**続けること**で、障壁は「入口」ではなく「継続」にある。

## 7. 規制・法制度

| 領域                         | 内容                                                                                                                                     |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| **景品表示法**               | 購入者向けに賞金を出すと「景品類」に該当しうる（一般懸賞で最高10万円等の上限）。賞金を**仕事の対価**と構成すれば該当しないとの整理が定着 |
| **刑法185条 賭博罪**         | 参加費を原資に賞金を配ると賭博に当たりうる。賞金は**主催者・スポンサーが全額拠出**するのが原則                                           |
| **風営法**                   | 店舗型eスポーツ施設の営業形態に制約。時間貸し方式が一般的                                                                                |
| **プロライセンス制度**       | JESUが2018年に開始。法的必要性は薄いとの理解が広がり、制度の意義自体が論点に                                                             |
| **著作権法**                 | 大会開催・配信にはメーカーの許諾が必要。**この業界の根本的な制約**                                                                       |
| **ベッティング**             | 日本では違法。海外の主要収益源が丸ごと存在しない                                                                                         |
| **スポーツ政策上の位置づけ** | 文科省・日本スポーツ協会での扱いは整理途上。2028年から国スポと切り離した独立大会へ                                                       |

詳細と経緯は [02_日本市場の特殊事情と現在地](02_日本市場の特殊事情と現在地.md)。

   メーカー所有型リーグのリスクが表面化した
