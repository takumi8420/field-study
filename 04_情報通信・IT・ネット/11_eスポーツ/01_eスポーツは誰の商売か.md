# eスポーツは誰の商売か

このノートで分かること：eスポーツの登場人物（メーカー・チーム・選手・大会運営・配信）が
それぞれ何で食べているのか、そして**なぜチームの多くが赤字なのか**。

結論を先に書く。**eスポーツは「既存スポーツのゲーム版」ではない。**
サッカーやプロ野球では競技そのものを誰も所有していないが、
eスポーツでは**競技＝ゲームの著作権者（ゲームメーカー）が、競技もリーグも所有している**。
この一点が、収益の配分・チームの立場・リーグの寿命のすべてを決めている。

## 1. 既存スポーツとの決定的な違い ── 「競技に所有者がいる」

野球やサッカーのルールは誰の著作物でもない。だからリーグは球団が集まって作れるし、
気に入らなければ別のリーグを作ることもできる（実際に歴史上そうやって増えた）。

eスポーツはそうではない。『League of Legends』の大会を開くには Riot Games の許諾が要る。
ゲームの著作権者は、**大会開催の可否・配信の可否・参加条件・賞金・リーグの存廃**を一方的に決められる。

```
  【既存スポーツ】                    【eスポーツ】

   競技ルール                          ゲーム（著作物）
   ＝誰のものでもない                   ＝メーカーの所有物
        │                                    │
        │  リーグはクラブの                   │  メーカーが許諾／主催
        │  共同事業体として成立               ▼
        ▼                              ┌───────────┐
   ┌───────────┐                 │  リーグ／大会  │ ◀── メーカーが設計
   │ リーグ（NPB等）│ ◀ クラブが出資       └───────────┘
   └───────────┘                        │ 出場許可
        │ 分配                                 ▼
        ▼                                 チーム・選手
   クラブ・選手                       ＝許諾をもらう側（立場が弱い）
```

| 論点           | 既存スポーツ                     | eスポーツ                                          |
| -------------- | -------------------------------- | -------------------------------------------------- |
| 競技そのもの   | 公共物。誰も所有しない           | **ゲームメーカーの著作物**                         |
| リーグの主催者 | クラブの連合体（NPB、Jリーグ等） | **メーカー、またはメーカーが指定した運営会社**     |
| 種目の寿命     | 数十年〜百年単位                 | **タイトルの人気次第。数年で消えることがある**     |
| 放映権         | リーグ（＝クラブ側）が売る       | **メーカーが握る。チームに分配されるとは限らない** |
| 競合リーグ     | 作れる                           | 作れない（著作権侵害になる）                       |
| 選手の移籍市場 | 種目が同じなら価値が持続         | タイトルを移ると価値がほぼ失われる                 |

> ポイント：チームは「リーグの共同オーナー」ではなく「出場を許された参加者」。
> メーカーがリーグの仕様を変えれば、チームの事業計画は翌日から崩れる。

実例がある。Riot Games は2025年、アジア太平洋の『LoL』リーグを **LCP**（League of Legends
Championship Pacific）に統合し、日本の **LJL** を国内リーグ＝下位のフィーダー（人材供給）階層に
位置づけ直した。日本の有力チームは上位リーグへ移り、LJLは公開予選型（最大64チーム）に作り替えられた。
チーム側は何も悪いことをしていないのに、**リーグの格が制度変更で下がった**（2025年、Riot Games発表・報道ベース）。

## 2. 登場人物と、それぞれの稼ぎ方

```
 ① ゲームメーカー（権利者）
      │ 許諾・リーグ運営・賞金拠出
      ▼
 ② 大会運営／リーグ運営会社 ──── ③ 配信プラットフォーム
      │ 出場枠                        （Twitch / YouTube）
      ▼                                     ▲ 視聴
 ④ チーム（運営法人） ── ⑤ 選手・ストリーマー ──┘
      ▲
      │ スポンサー料
 ⑥ スポンサー企業（PC・周辺機器・通信・飲料・金融 …）
      ▲
      │ 広告効果を期待
 ⑦ ファン（視聴・グッズ・課金・チケット）
```

| 登場人物                   | 主な収入                                                                | 経済的な立ち位置                                 |
| -------------------------- | ----------------------------------------------------------------------- | ------------------------------------------------ |
| **① ゲームメーカー**       | ゲーム本体・アイテム課金。eスポーツは**販促費**として扱われることが多い | **最強**。競技を所有する。大会自体は赤字でもよい |
| **② 大会運営会社**         | 主催企業からの受託費、協賛、チケット、配信                              | **受託型は堅い**。自主興行は当たり外れが大きい   |
| **③ 配信プラットフォーム** | 広告、サブスク、投げ銭手数料                                            | 視聴の器。独占配信料を払う時期もあったが縮小     |
| **④ チーム**               | スポンサー料、賞金、グッズ、配信収入、出演料                            | **最も苦しい**。固定費を持ち、収入は他者依存     |
| **⑤ 選手**                 | 給与、賞金分配、個人スポンサー、配信収益                                | 選手寿命が短い。多くは配信者としての収入が本体   |
| **⑥ スポンサー**           | （支出側）                                                              | 若年層リーチを買う。景気で真っ先に削られる       |
| **⑦ ファン**               | （支出側）                                                              | 課金の中心は**ゲーム本体**であり、競技ではない   |

**ここが肝心**：ファンが払うお金の大半は、①ゲームメーカーに向かう（スキン・バトルパス等）。
競技（チーム・リーグ）に直接向かう支払いは、既存スポーツに比べて著しく小さい。
だから eスポーツの収入は、ファンからの直接収入ではなく **スポンサーからの間接収入**に偏る。

## 3. 収益源の内訳 ── 「広告費でできている産業」

| 収益源               | 世界の構成比（2025年、調査会社推計） | 誰に入るか           | 安定性                                 |
| -------------------- | ------------------------------------ | -------------------- | -------------------------------------- |
| **スポンサーシップ** | **40%超**（最大）                    | リーグ・チーム       | 景気連動。**最も削られやすい**         |
| 放映権・配信権       | スポンサーと合わせて約65%            | 主にメーカー／リーグ | 独占配信バブルは2020年前後で終了       |
| グッズ・チケット     | 1割前後                              | チーム・主催         | 小さいが自前で伸ばせる                 |
| パブリッシャー拠出金 | （分類により変動）                   | リーグ・チーム       | メーカーの都合で増減                   |
| 賞金                 | 収益というより一時金                 | 選手・チーム         | **極端に上下する。事業計画に組めない** |

出所：Grand View Research 等の推計（2025〜2026年）。
**注意**：調査会社ごとに「何を市場に含めるか」が違い、世界市場は2026年で
約33億ドル（Grand View Research）〜約51億ドル（Statista）と**1.5倍以上の開き**がある。
単独の数字を根拠に語らないこと。

```
   お金の入口（世界のeスポーツ収益、概念図）

   スポンサー ████████████████████  約4割   ← 広告予算
   放映・配信 █████████             約2割   ← 縮小傾向
   グッズ等   ████                  約1割
   その他     ██████                残り

   → 「ファンが競技に払うお金」ではなく
      「企業が広告として払うお金」で回っている
```

これが意味するのは、**eスポーツは実質的に広告産業の下流にいる**ということ。
広告市況が冷えれば、競技の人気が変わらなくても収入が落ちる。
2022〜2023年に世界のリーグ・チームがまとめて苦境に陥ったのは、まさにこの経路である
（いわゆる「eスポーツの冬」。報道ベース）。
広告の仕組みそのものは [ネット広告](../07_ネット広告/README.md) を参照。

## 4. なぜチームは赤字になるのか

チーム運営の収支を単純化すると、次のようになる。

| 項目                             | 性質           | 特徴                                               |
| -------------------------------- | -------------- | -------------------------------------------------- |
| 選手給与                         | **固定費**     | 主力タイトルで5人＋控え。年俸は成績と無関係に発生  |
| コーチ・アナリスト・マネージャー | **固定費**     | 1タイトルにつき数名                                |
| ゲーミングハウス・練習施設       | **固定費**     | 家賃・光熱・機材更新                               |
| 遠征・大会参加費                 | 半固定         | 国際大会が増えるほど膨らむ                         |
| 配信・撮影・SNS運用              | **固定費**     | ここを削ると露出が落ち、スポンサーが離れる         |
| （収入）スポンサー料             | **変動**       | 年契約。更新されない前提で見るべき                 |
| （収入）賞金                     | **極めて変動** | 勝てなければゼロ。分配後の手取りは半分以下のことも |
| （収入）グッズ・配信             | 変動           | 伸ばせるが規模が小さい                             |

```
   チームの収支構造（典型）

   固定費 ████████████████████████  ほぼ動かない
   　　　 選手給与・スタッフ・施設・配信体制

   収入   ████████████░░░░░░░░░░░░  スポンサー（年次で消滅しうる）
          ░░░░██░░░░░░░░░░░░░░░░░░  賞金（勝てばスパイク、負ければゼロ）
          ██░░░░░░░░░░░░░░░░░░░░░░  グッズ・配信

          ↑ 収入の上振れは「賞金」だけ。
            しかし賞金は事業計画に入れられない。
            → 構造的に赤字が既定路線になる
```

国内では「月給30万円の選手5人を抱えると年間3,500万円規模の赤字になる」という
運営者によるシミュレーションが公開され、話題になった（報道・チーム運営者の発信ベース）。
金額そのものより、**固定費が先に立ち、収入が後から不確実に付いてくる**という順序が問題である。

赤字が常態化する理由を3つに整理すると：

1. **成績と収入が直結しない**。勝っても賞金は一時金で、スポンサー料の増額は翌年以降
2. **チームは競技を所有していない**。リーグの放映権収入はメーカー側に留まりがち
3. **見栄の競争が起きやすい**。有力選手の獲得競争で人件費だけが先に上がる

> だからチームは「競技で勝つ会社」から「**ファンを持つメディア会社**」へ寄っていく。
> ストリーマー（配信者）を抱え、グッズを売り、企業案件を受ける。
> 競技成績より**視聴者数とSNSのフォロワー**が事業の基盤になっている、というのが実態に近い。
> この構造は [芸能・マネジメント](../../14_メディア・広告・エンタメ/11_芸能・マネジメント/README.md) と
> [動画・音楽配信](../12_動画・音楽配信/README.md) の中間にある。

## 5. 大会運営会社は、なぜ比較的堅いのか

チームが苦しい一方で、**大会運営の受託は事業として成立しやすい**。

| 形態                                         | 収入の取り方                                 | リスク                             |
| -------------------------------------------- | -------------------------------------------- | ---------------------------------- |
| **受託運営**（メーカー・スポンサーから請負） | 制作費＋管理費。**赤字リスクが発注元にある** | 低い。人月商売に近い               |
| 自主興行（自前の大会ブランド）               | チケット・協賛・配信                         | 高い。集客に失敗すると直撃         |
| 施設運営（eスポーツ施設・カフェ）            | 時間貸し・飲食・イベント                     | 中〜高。坪効率の勝負で、閉店も多い |
| 学校・自治体向け事業                         | 講座・大会運営の受託                         | 低〜中。単価は低いが安定           |

日本では大会運営会社の**ウェルプレイド・ライゼスト**（東証グロース 9565）が2022年に上場し、
国内eスポーツ関連で初の上場企業となった。
この会社の主戦場は「自分たちが勝つ」ことではなく「**誰かの大会を作って請け負う**」ことである。
この違いが、チームとの収益安定性の差をそのまま表している。

## 6. 配信プラットフォームの役割

eスポーツは**無料視聴が前提**の競技である。テレビの放映権のように、視聴に高い対価を取れない。

| プラットフォーム                   | 位置づけ                         | 収益                                   |
| ---------------------------------- | -------------------------------- | -------------------------------------- |
| **Twitch**                         | 競技配信の中心。個人配信と地続き | 広告・サブスク・ビッツ（投げ銭）       |
| **YouTube Live**                   | 到達範囲が最大。アーカイブに強い | 広告・メンバーシップ・スーパーチャット |
| **ニコニコ生放送**                 | 国内の古参。コメント文化         | 会員課金                               |
| **各社の公式アプリ／ゲーム内観戦** | メーカーが視聴を囲い込む動き     | ゲーム内報酬との連動                   |

2020年前後は「独占配信権」を巡ってプラットフォームが高額を支払う局面があったが、
**視聴者が無料で他所へ流れるだけ**と分かり、独占料は縮小した（報道ベース）。
現在は「広く無料で見せ、ゲーム内課金とスポンサー露出で回収する」形に戻っている。
配信側の経済は [動画・音楽配信](../12_動画・音楽配信/README.md) を参照。

## 7. 賞金の見え方と、実際の手取り

賞金額は見出しになりやすいが、**産業規模を表す数字ではない**。

| 大会                        | 賞金総額                                         | 時点・出所       |
| --------------------------- | ------------------------------------------------ | ---------------- |
| Esports World Cup 2026      | **7,500万ドル**（25種目合計、史上最高額）        | 2026年、主催発表 |
| 同 2025                     | 7,000万ドル                                      | 2025年、主催発表 |
| 同 クラブチャンピオンシップ | 3,000万ドル（優勝700万ドル、上位24チームに配分） | 2026年、主催発表 |
| 同 LoL／VALORANT 各部門     | 各200万ドル                                      | 2026年、主催発表 |

賞金がチームの手元に残る割合は小さい。一般に **選手への分配が50〜80%**、
残りから遠征費・税を引くため、優勝しても年間赤字が埋まらないことは珍しくない。
しかも Esports World Cup の原資はサウジアラビアの国家系資金であり、
**産業が稼いだ利益ではなく外部からの注入**である点に注意がいる（後述 → [03_直近トピック_2026](03_直近トピック_2026.md)）。

## 8. まとめ ── この産業の構造を一文で

> **eスポーツは、ゲームメーカーが自社タイトルの販促のために作った競技場の上で、
> 広告予算を原資にチームと選手が興行する産業である。**
> 競技の所有権がメーカーにあるため、チーム側に資産（放映権・リーグ持分）が蓄積しない。
> これが「観客は増えているのに、チームは儲からない」という現象の正体である。

## 用語メモ

| 用語                         | 意味                                                                 |
| ---------------------------- | -------------------------------------------------------------------- |
| **パブリッシャー**           | ゲームの発売元。著作権者として競技・リーグを所有する側               |
| **タイトル**                 | 競技に使われるゲームソフトそのもの。eスポーツの「種目」に相当        |
| **フランチャイズリーグ**     | 参加枠を固定し、昇降格をなくしたリーグ方式。加盟金が高額になりやすい |
| **オープンリーグ**           | 予選を勝ち上がれば誰でも参加できる方式。LJLは2025年にこちらへ転換    |
| **LJL**                      | League of Legends Japan League。2025年から国内の下位階層リーグへ     |
| **LCP**                      | League of Legends Championship Pacific。アジア太平洋の上位統合リーグ |
| **ゲーミングハウス**         | 選手が共同生活・練習する拠点。チームの固定費の代表格                 |
| **ストリーマー**             | 配信を主活動とする人。競技成績より視聴者数が価値になる               |
| **投げ銭**                   | 視聴者が配信者に直接支払う少額課金（スパチャ、ビッツ等）             |
| **賞金プール**               | 大会賞金の総額。チームの手取りとは大きく異なる                       |
| **EWC（Esports World Cup）** | サウジアラビア主導の総合大会。2026年は賞金7,500万ドル                |
