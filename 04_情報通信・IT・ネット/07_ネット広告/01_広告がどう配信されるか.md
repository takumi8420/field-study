# ① 広告がどう配信されるか

このノートで分かること：ネット広告の**種類の地図**と、1本のバナーが表示されるまでの
**0.1秒のオークション（RTB）**の中身、誰を狙うか（ターゲティング）、何で成果を測るか（CPC/CPA/ROAS）。

> ポイント：ネット広告の正体は「広告枠の売買」ではなく、**1インプレッション（広告1回表示）ごとの
> 自動オークション**。日本のネット広告媒体費の **88.7%（2025年、電通）** がこの方式（＝運用型）で取引されている。

---

## 1. まず種類の地図

ネット広告は「どこに出るか」で分けると5種類に整理できる。
金額は電通「2025年 日本の広告費 インターネット広告媒体費 詳細分析」（2026年3月発表）。

| 種類                                                 | どこに出るか                                                | 何で課金するか          | 2025年の規模（日本の媒体費）                                                                                 |
| ---------------------------------------------------- | ----------------------------------------------------------- | ----------------------- | ------------------------------------------------------------------------------------------------------------ |
| **検索連動型**（リスティング）                       | 検索結果の上部。「弁護士 離婚」と打った人に法律事務所の広告 | ほぼCPC（クリック課金） | 媒体費全体の **38.7%**（＝約1.28兆円相当）                                                                   |
| **ディスプレイ**                                     | ニュースサイトやアプリのバナー枠                            | CPM（表示課金）／CPC    | 運用型ディスプレイは前年比111.5%                                                                             |
| **ビデオ（動画）**                                   | YouTube・TVer・SNS・CTV                                     | CPM／CPV（視聴課金）    | **1兆275億円**（前年比121.8%、初の1兆円超）                                                                  |
| **ソーシャル**                                       | Instagram・TikTok・X・LINE・Facebook                        | CPM／CPC                | **1兆3,067億円**（前年比118.7%、構成比39.5%）                                                                |
| **リテールメディア**（物販系ECプラットフォーム広告） | Amazon・楽天・小売アプリ・店頭サイネージ                    | CPC中心                 | 電通は「物販系ECプラットフォーム広告費」として別掲。急成長領域（→ [④直近トピック](04_直近トピック_2026.md)） |

補足：

- **ビデオとソーシャルは重複する**。Instagramリール広告は「ソーシャル広告」でも「ビデオ広告」でもある。
  電通の分類は「広告商品の種類別」と「メディア種別」で別々に集計されているので、足し算してはいけない
- 「インターネット広告費 **4兆459億円**（2025年、前年比110.8%）」と
  「インターネット広告**媒体費** 3兆3,093億円」は別物。差額の約7,400億円は
  **広告制作費**と**物販系ECプラットフォーム広告費**にあたる（電通発表値からの差分計算）
- 2025年は**インターネット広告費が総広告費 8兆623億円の 50.2% を占め、統計開始以来初めて過半数**になった

## 2. 「枠」を買う時代から「人」を買う時代へ

```
【昔：予約型（枠売り）】
 広告主 ──「Yahoo!トップに1週間、1,000万円で」──▶ 媒体社
        誰が見るかは分からない。枠の値段は事前に決まっている

【今：運用型（人買い）】
 広告主 ──「30代女性で化粧品を検索した人に、1クリック150円まで払う」──▶ システム
        誰に出すかを毎回システムが判断し、値段も毎回変わる
```

| 取引手法           | 中身                                             | 2025年の金額（日本、電通）       | 構成比    |
| ------------------ | ------------------------------------------------ | -------------------------------- | --------- |
| **運用型広告**     | 入札とターゲティングをシステムが毎回決める       | **2兆9,352億円**（前年比112.5%） | **88.7%** |
| **予約型広告**     | 枠と期間と金額を事前に契約                       | 3,042億円（前年比109.1%）        | 9.2%      |
| **成果報酬型広告** | 申込や購入が発生した分だけ払う（アフィリエイト） | 699億円（前年比**96.1%＝減少**） | 2.1%      |

> なぜ運用型が9割になったのか：予約型は「枠が売れ残るリスク」を媒体社が負い、広告主は
> 「効かない枠に払うリスク」を負う。**1回の表示ごとに値段を決めれば、両方のリスクが消える**。
> ただし代償として、広告主は「どこに出たか」を完全には把握できなくなった（→ [③規制と課題](03_規制と課題.md)）。

## 3. アドテクの登場人物

運用型広告を動かす仕組みを**アドテクノロジー（アドテク）**と呼ぶ。登場人物は4つだけ覚えればよい。

| 略称                   | 正式名称                                 | 日本語で言うと                                 | 誰の味方か                         |
| ---------------------- | ---------------------------------------- | ---------------------------------------------- | ---------------------------------- |
| **DSP**                | Demand Side Platform                     | 広告主の買い付け端末                           | **広告主**。安く・効く枠を買いたい |
| **SSP**                | Supply Side Platform                     | 媒体社の販売端末                               | **媒体社**。1枠でも高く売りたい    |
| **アドエクスチェンジ** | Ad Exchange                              | 広告枠の取引所（証券取引所の広告版）           | 中立（建前上）。売買を突き合わせる |
| **アドサーバ**         | Ad Server                                | 配信管理サーバ。どの広告を何回出したか記録する | 広告主側・媒体社側の両方にある     |
| （補助） **DMP／CDP**  | Data Management / Customer Data Platform | 誰にどう出すかを決めるためのデータ置き場       | 広告主・媒体社の双方               |

```
【アドテクの全体像】

  広告主                                            媒体社・アプリ
    │                                                    ▲
    ▼                                                    │
 ┌──────┐   入札リクエスト  ┌──────────┐   枠の在庫  ┌──────┐
 │ DSP  │◀─────────────│ アドエクスチェンジ │◀──────────│ SSP  │
 │ 買う │─────────────▶│   （取引所）      │──────────▶│ 売る │
 └──────┘   入札額を返す   └──────────┘   落札結果   └──────┘
    ▲                              ▲
    │                              │
 ┌──────┐                   ┌──────────┐
 │ DMP  │  「この人は誰か」  │ アドベリ   │ 詐欺枠・不適切面を弾く
 └──────┘                   └──────────┘  （→ ③規制と課題）
```

※ Google・Meta・Amazonのような巨大プラットフォームは、**DSPもSSPもエクスチェンジも媒体も
自社で持っている**。この「全部持ち」が独禁法で問題視された（→ [④直近トピック](04_直近トピック_2026.md)）。

## 4. RTB ＝ 1件あたり0.1秒のオークション

**RTB（Real-Time Bidding／リアルタイム入札）**＝ ユーザーがページを開いた**その瞬間**に、
その1回の表示権をオークションにかけて売る仕組み。所要時間は**おおむね100ミリ秒（0.1秒）以内**が
業界の標準的な制限時間とされる。人間がページの読み込みを待てる限界がそこだから。

```
【0.1秒の中で起きていること】

 0ms   ユーザーがニュース記事を開く
  │
 5ms   媒体のページから SSP へ「枠が1つ空いた。訪問者はこのID、東京、Android」
  │
 15ms  SSP → アドエクスチェンジ → 数十〜数百の DSP へ一斉に入札リクエスト
  │      （送る情報＝ページURL・広告枠サイズ・おおよその位置情報・Cookie/広告ID）
  │
 25ms  各DSPが自社データベースを照合
  │      「このIDは3日前に自社サイトでカートに商品を入れた人だ」→ 高く入札
  │      「知らないIDだ」→ 安く入札、または入札しない
  │
 60ms  入札額が返る：A社 320円CPM / B社 180円CPM / C社 入札なし …
  │
 70ms  最高額の A社 が落札。支払額は第一価格（＝入札額そのもの）が主流
  │
 85ms  A社の広告タグが媒体側に返り、クリエイティブ（画像・動画）を配信
  │
 100ms 画面に広告が表示される ＝ 1インプレッション成立
```

### 価格の決まり方が変わった話

| 方式                               | 支払額               | 使われた時期           | なぜ変わったか                                                                                                   |
| ---------------------------------- | -------------------- | ---------------------- | ---------------------------------------------------------------------------------------------------------------- |
| **セカンドプライス（第二価格）**   | 2位の入札額＋1円     | 〜2017年ごろまで主流   | 正直に上限額を入れても損しない設計。ただし媒体社から見て「本当に2位だったのか」が検証できない                    |
| **ファーストプライス（第一価格）** | 自分の入札額そのもの | 2018年ごろ〜現在の主流 | 媒体社の不信感と**ヘッダービディング**の普及で移行。広告主は「いくらまでなら払うか」を自分で計算する必要が生じた |

- **ヘッダービディング**：媒体社がページの読み込み時点で複数のSSPへ同時に声をかけ、
  最も高い値を付けたところに売る技術（2015年ごろ普及）。それ以前は
  Googleのアドサーバが**最後に入札額を見て上乗せできる立場**にあり、これが独禁法訴訟の争点になった
- **フロアプライス（最低落札価格）**：媒体社が「これ以下では売らない」と設定する下限。
  安売りを防ぐ一方、設定が高すぎると枠が売れ残る

> ポイント：**この1回のオークションが、日本だけで1日に数百億回**走っている。
> だからネット広告は「人が枠を売る商売」ではなく「システムの計算量で勝負する商売」になった。

### RTBを通らない取引もある

| 取引形態                                  | 中身                                                                                                                                      |
| ----------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| **PMP（プライベートマーケットプレイス）** | 招待された広告主だけが参加できる限定オークション。質の高い媒体を確保したいときに使う                                                      |
| **プログラマティック・ギャランティード**  | 枠と単価を事前に固定しつつ、配信はシステムで行う。予約型と運用型の中間                                                                    |
| **ウォールドガーデン（壁に囲まれた庭）**  | Google・Meta・Amazon・LINEヤフーの**自社完結型**。外部のDSPからは買えず、自社の管理画面からしか買えない。ネット広告費の大半はここに落ちる |

## 5. 誰を狙うか（ターゲティング）

| 種類                           | 何を根拠に狙うか           | 例                       | 精度／リスク                                               |
| ------------------------------ | -------------------------- | ------------------------ | ---------------------------------------------------------- |
| **デモグラ**                   | 年齢・性別・地域           | 「東京都・30代女性」     | 精度は中。プラットフォームの登録情報が根拠                 |
| **オーディエンス（興味関心）** | 閲覧履歴から推定した興味   | 「旅行に関心がある人」   | プラットフォームの推定。根拠は非公開                       |
| **リターゲティング（リタゲ）** | 自社サイトを訪れた履歴     | カート放棄者に再訴求     | 最も効くが、最もCookie依存が強い                           |
| **類似拡張（Lookalike）**      | 既存顧客と似た行動をする人 | 購入者リストから拡張     | 1st partyデータが原資。Cookie廃止に強い                    |
| **コンテキスト（文脈）**       | 出稿先ページの内容         | 登山記事にアウトドア用品 | 個人を特定しない。**プライバシー規制の回避先として復権中** |
| **リテール（購買）**           | 実際のレジ通過データ       | 「先月ビールを買った人」 | 最も購買に近い。小売しか持っていない                       |

### Cookieとは何か（ここを外すと後の章が分からない）

**Cookie（クッキー）**＝ ブラウザがサイトごとに保存する小さなメモ。ログイン状態の保持などに使う。

```
【ファーストパーティ Cookie】          【サードパーティ Cookie】
 example.com を閲覧                    example.com を閲覧
      ↓                                     ↓
 example.com がメモを置く              ページに埋まった adtech.com が
 「この人はカートに商品あり」            adtech.com 名義でメモを置く
      ↓                                     ↓
 example.com でしか読めない            news.com を見たときも adtech.com が
 → 自社の分析用                        同じメモを読める
                                       → サイトをまたいだ追跡ができる ＝ これが問題に
```

- **モバイルアプリではCookieが使えない**ので、代わりに**広告ID**を使う
  （iOSの **IDFA**、Androidの **AAID**）。2021年のApple **ATT**（App Tracking Transparency）で
  iOSは「追跡を許可しますか」の同意が必須になり、リターゲティングの精度が大きく落ちた
- サードパーティCookieの「廃止」がどうなったかは [③規制と課題](03_規制と課題.md) 第2章

## 6. クリエイティブと入札の自動化

いま起きている最大の変化は、**広告主が細かく設定しなくなった**こと。

| 世代                         | 広告主がやること                                       | 代表的な商品                               |
| ---------------------------- | ------------------------------------------------------ | ------------------------------------------ |
| 手動運用（〜2015ごろ）       | キーワード・入札額・配信面を1つずつ設定                | 個別キーワード入札                         |
| 自動入札（2016〜）           | 「CPA 3,000円で」と目標だけ渡す                        | Target CPA／Target ROAS                    |
| **フルオート（2021〜）**     | 素材・予算・目標だけ渡す。面もキーワードも機械が決める | Google **P-MAX**、Meta **Advantage+**      |
| **AIエージェント（2025〜）** | 素材そのものも生成AIが作る。運用の意思決定まで任せる   | → [④直近トピック](04_直近トピック_2026.md) |

> なぜそうなるか：オークションが0.1秒で数百億回走る世界では、**人間が手で最適化できる情報量を
> とっくに超えている**。一方で、機械が「どこに出したか」を広告主に開示しないため、
> 広告代理店の仕事が「設定作業」から「素材作りと計測設計」へ移った（→ [②お金の流れと取り分](02_お金の流れと取り分.md)）。

## 7. 何で成果を測るか

```
【ファネル（漏斗）と指標の対応】

 表示 ──▶ 視認 ──▶ クリック ──▶ サイト訪問 ──▶ 申込・購入 ──▶ 売上
  imp      viewable    click         session          CV          revenue
   │         │           │                             │            │
  CPM     ビューア     CTR・CPC                       CVR・CPA      ROAS
 (千回     ビリティ   (クリック率／                  (成約率／     (広告費用
  表示     (実際に     1クリック単価)                 1件獲得単価)   対効果)
  単価)    見えた率)
```

| 指標                        | 計算式                             | 読み方・使いどころ                                                   |
| --------------------------- | ---------------------------------- | -------------------------------------------------------------------- |
| **imp（インプレッション）** | 広告の表示回数                     | 分母。ただし「表示＝見られた」ではない                               |
| **ビューアビリティ**        | 見える位置に一定時間表示された割合 | ディスプレイは面積50%・1秒以上が目安（MRC基準）                      |
| **CTR**                     | クリック数 ÷ imp                   | 検索連動型は数%、ディスプレイは0.1%前後が普通                        |
| **CPM**                     | 広告費 ÷ imp × 1,000               | 認知目的の買い方。「千回表示いくら」                                 |
| **CPC**                     | 広告費 ÷ クリック数                | 集客目的。競争が激しい語ほど高い（弁護士・不動産・転職は数千円台も） |
| **CVR**                     | CV数 ÷ クリック数                  | サイト側の出来を映す。広告ではなくLPの責任                           |
| **CPA**                     | 広告費 ÷ CV数                      | 1件の申込にいくらかかったか。**運用型広告の最重要指標**              |
| **ROAS**                    | 売上 ÷ 広告費 × 100%               | EC向け。400%なら広告1円で売上4円。**利益ではない点に注意**           |
| **LTV**                     | 1顧客の生涯売上                    | CPAの許容ラインを決める根拠。LTV＞CPAでないと事業が回らない          |

> よくある誤解：**ROASが高い＝儲かっている、ではない**。原価率70%の商品でROAS 300%なら、
> 売上3に対し原価2.1＋広告費1＝3.1で赤字。**粗利ベースで見る（ROI）**のが本来。

アトリビューション（成果の配分）の問題は [③規制と課題](03_規制と課題.md) 第9章で扱う。

## 9. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **運用型広告／予約型広告** | 入札・ターゲティングをシステムが随時調整する取引手法（日本の媒体費の88.7%、2025年・電通）／枠・期間・金額を事前契約する従来型（純広告） |
| **インプレッション（imp）** | 広告が1回表示されること |
| **DSP／SSP／アドエクスチェンジ／アドサーバ** | 広告主側の買い付けシステム／媒体社側の販売システム／広告枠の取引所／配信とレポートを管理するサーバ |
| **RTB** | 1インプレッションごとのリアルタイム入札。制限時間はおおむね0.1秒 |
| **ファーストプライス／セカンドプライス** | 落札額＝入札額そのもの／2位の額＋α。2018年ごろに前者へ移行 |
| **ヘッダービディング／フロアプライス／PMP** | 媒体側が複数SSPへ同時に声をかける技術／最低落札価格／招待制の限定オークション |
| **ウォールドガーデン** | Google・Meta・Amazon等の自社完結型の広告環境 |
| **Cookie（1st／3rd party）／広告ID（IDFA・AAID）／ATT** | ブラウザのメモ（発行元が閲覧中のサイトか第三者か）／アプリ向け端末識別子（iOS・Android）／Appleの追跡同意制度（2021年） |
| **リターゲティング／類似拡張／コンテキストターゲティング** | 自社サイト訪問者を追う配信／既存顧客に似た層へ広げる配信／個人でなくページ内容に合わせる配信 |
| **P-MAX／Advantage+** | Google／Metaの全自動型キャンペーン商品 |
| **CPM／CPC／CPA／ROAS** | 千回表示単価／クリック単価／獲得単価／広告費用対効果 |
| **CTR／CVR／ビューアビリティ** | クリック率／成約率／実際に視認可能な状態で表示された割合 |
| **LTV** | 顧客生涯価値。CPAの上限を決める基準 |
| **CTV** | コネクテッドTV。ネット接続されたテレビ受像機での動画広告 |
