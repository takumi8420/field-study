# ② お金の流れと取り分

このノートで分かること：広告主が出した100円が**誰の手を何回通って媒体に届くか**、
代理店の手数料はどう決まるか、Google・Meta・Amazonの寡占がなぜ崩れないか、
そして運用型広告の時代に**代理店の役割がどう変わったか**。

> ポイント：ネット広告の産業構造は「広告主 → 代理店 → 媒体」という一直線ではない。
> **プラットフォームが媒体と取引所と買い付けシステムを同時に持っている**ため、
> 実質的には「広告主 → プラットフォーム」であり、代理店はその横に付く**運用の外注先**になっている。

---

## 1. 全体像：100円はどこへ行くか

```
【マス広告（テレビCM）の伝統的な流れ】

 広告主 ──100──▶ 広告代理店 ──80──▶ テレビ局
                  手数料20（総額の約20%＝コミッション）
                  役割：枠の仕入れ・番組交渉・制作・出稿管理

【ネット広告（運用型）の流れ】

 広告主 ──100──▶ 代理店 ──80〜85──▶ プラットフォーム（Google/Meta等）
                  手数料15〜20                     │
                  役割：運用・素材制作・計測設計    ▼
                                            媒体社・クリエイター
                                            （レベニューシェア後の取り分）

【オープンなアドテク経路（DSP→SSP→媒体）を通る場合】

 広告主 100 ──▶ 代理店 ──▶ DSP ──▶ エクスチェンジ ──▶ SSP ──▶ 媒体社
              −15〜20     −10〜20    −5〜15        −10〜20     残り
                                                         ▲
                     媒体に届くのは 40〜60円程度と言われる（＝アドテク税）
```

> なぜこうなるか：オープンな経路では**中間のシステムがそれぞれ手数料を取る**。
> 英ISBA/PwCの2020年調査で「広告主の支出のうち媒体に届くのは約51%、
> 使途を追跡できない“unknown delta”が15%」と報告されたのが業界に衝撃を与えた。
> 以来、広告主は**中間業者を減らす（サプライパス最適化＝SPO）**方向に動いている。

## 2. 代理店の手数料モデル

| モデル                     | 計算方法                  | 向いている場面                     | 論点                                                         |
| -------------------------- | ------------------------- | ---------------------------------- | ------------------------------------------------------------ |
| **コミッション（料率）**   | 広告費 × 15〜20%          | マス広告、運用型の一般的な形       | 広告費が増えれば代理店も儲かる＝**利益相反**が起きやすい     |
| **フィー（工数）**         | 担当者の人件費 × 稼働時間 | 大手広告主、インハウス支援         | 透明だが、代理店は稼働を増やすほど儲かる                     |
| **成果報酬**               | CV1件あたり◯円／売上の◯%  | アフィリエイト、獲得系             | 広告主のリスクが小さい。ただし不正誘因が生じる               |
| **マージン（仕入れ差益）** | 安く仕入れて高く売る差額  | 一部の枠買い、自社アドネットワーク | 広告主に原価が見えない（**プリンシパル取引**）。欧米で問題化 |
| **ハイブリッド**           | 基本フィー＋成果ボーナス  | 大型アカウント                     | 実務で最も増えている形                                       |

国内の運用型広告の代理店手数料は、**広告費の20%前後**が一つの目安として語られることが多い
（各社非公開のため、あくまで業界の相場観）。ただし、

- 広告費が小さい案件は20%では人件費が出ないため、**最低手数料（月額◯万円）**を置く
- 広告費が数億円規模になると料率は一桁台まで下がり、代わりにフィー型へ移る

## 3. 運用型広告で、代理店の役割はどう変わったか

```
【2010年ごろ】                      【2026年ごろ】
 代理店の仕事                        代理店の仕事
 ├ キーワード選定                    ├ （自動化で消滅）
 ├ 入札額の手動調整 ──────────────▶ ├ （自動入札で消滅）
 ├ 配信面の選定                      ├ （P-MAX等で消滅）
 ├ レポート作成                      ├ （BIツールで半自動）
 └ 媒体との枠交渉                    │
                                     ├ ＋ クリエイティブの大量生成と検証
                                     ├ ＋ 計測設計（CAPI・サーバーサイド計測）
                                     ├ ＋ ファーストパーティデータの設計
                                     ├ ＋ MMM・増分検証などの効果分析
                                     └ ＋ インハウス化の支援・教育
```

| 変化                             | 何が起きたか                                   | 代理店への影響                                                           |
| -------------------------------- | ---------------------------------------------- | ------------------------------------------------------------------------ |
| **自動入札の普及**               | 設定作業の付加価値が消えた                     | 「運用代行」だけでは料率を維持できない                                   |
| **クリエイティブが勝敗を決める** | 機械が配信先を決めるので、差が出るのは素材だけ | 制作機能を持つ代理店が強い                                               |
| **インハウス化（内製化）**       | 大手広告主が自社で運用を始めた                 | 代理店は「支援・教育」へ回る                                             |
| **計測の難化**                   | Cookie規制で成果が見えにくくなった             | 計測設計そのものが商品になった                                           |
| **生成AIによる素材量産**         | 素材制作の単価が下がる                         | 制作収入も圧縮される可能性（→ [④直近トピック](04_直近トピック_2026.md)） |

> ポイント：運用型広告では、**代理店は媒体の代理人ではなく広告主の運用チームの延長**になった。
> だから料率よりも「何人が何時間関わるか」で値段が決まる方向へ寄っている。

## 5. プラットフォームの寡占：なぜ崩れないか

```
【広告費の集まり方】

  広告主の予算
      │
      ├──────────▶ Google（検索＋YouTube＋GDN）
      │              買う理由：検索意図＝最も購買に近い需要
      │
      ├──────────▶ Meta（Instagram＋Facebook）
      │              買う理由：人の属性・関心データの量と質
      │
      ├──────────▶ Amazon（商品検索＋Prime Video）
      │              買う理由：実際の購買データと、その場で買えること
      │
      └── 残り ────▶ その他の媒体（ニュース・アプリ・個人メディア）
                     ↑ ここがオープンなアドテク経路。手数料の中抜きが大きい
```

- Amazonの広告売上は**2025年通期で680億ドル超**と報じられ、Google・Metaに次ぐ第3極になった
- 世界の広告収入は**2025年に1兆ドル前後**、2026年には1兆ドルを明確に超えるとの予測がある
  （GroupM・Magnaなどの推計。調査機関により定義・数値が異なる）
- 寡占が崩れない理由は3つ：

| 理由                 | 中身                                                                             |
| -------------------- | -------------------------------------------------------------------------------- |
| **データの自己強化** | 配信すればするほど学習データが増え、精度が上がる。後発は同じ量のデータを買えない |
| **在庫の所有**       | 自社サービスの中に広告枠があるので、仕入れコストがほぼゼロ                       |
| **計測の閉鎖性**     | 効果測定も自社の管理画面で行う。「自分の成績を自分で採点する」構造               |

> なぜ広告主が離れられないか：**代替がない**。検索意図を持った人に届く面はGoogle以外になく、
> 「今日買う気はないが関心はある人」に届く面はMeta以外にない。**媒体の代替可能性が低いほど
> テイクレート（手数料率）は高く維持される**。

## 6. 媒体社（パブリッシャー）側の取り分

| 指標                   | 意味                               | 目安の読み方                                                                                |
| ---------------------- | ---------------------------------- | ------------------------------------------------------------------------------------------- |
| **eCPM／RPM**          | 1,000回表示あたりの媒体の実収入    | 日本の一般的なWebメディアのディスプレイで数百円台と言われる（枠位置・ジャンルで大きく変動） |
| **フィルレート**       | 在庫のうち広告が埋まった割合       | 低いと収入機会を捨てている                                                                  |
| **レベニューシェア率** | プラットフォームと媒体の分配比     | YouTubeの広告収益はクリエイター側55%が公表値                                                |
| **直販比率**           | 代理店・広告主から直接受注する割合 | 高いほど単価が高い。人手がかかる                                                            |

```
【媒体社の収入構造】

 PV（見られた回数）× 1PVあたりの広告枠数 × フィルレート × eCPM ÷ 1000 ＝ 広告収入
   ▲                                          ▲
   │ ここがAI検索で減っている（→④直近トピック）   │ ここは寡占側が握る
```

媒体社はこの式の**どの変数も自分では動かしにくい**。
だからサブスク課金やイベントなど、広告以外の収入へ逃げる動きが続いている
（→ [新聞](../../14_メディア・広告・エンタメ/04_新聞/README.md)、[出版](../../14_メディア・広告・エンタメ/03_出版/README.md)）。

## 7. アフィリエイト：成果報酬型の世界

**アフィリエイト**＝「申込・購入が発生したときだけ報酬を払う」広告。
広告主・**ASP**（アフィリエイト・サービス・プロバイダ＝仲介事業者）・
**アフィリエイター**（掲載するメディアや個人）の3者で回る。

```
 広告主 ──成果報酬──▶ ASP ──報酬の一部──▶ アフィリエイター
        （例：1件5,000円）  （ASPの取り分：報酬の30%前後が相場と言われる）
                               ▲
                       広告主は成果が出るまで払わない＝リスクが小さい
                       ただし「成果」の定義を誤ると不正の温床になる
```

| 論点           | 中身                                                                                                                                 |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| 市場規模       | 国内アフィリエイト市場は**2024年度4,379億円 → 2025年度4,598億円**（矢野経済研究所の推計）。2029年度5,883億円の予測                   |
| 電通統計との差 | 電通の「成果報酬型広告」は**2025年に699億円（前年比96.1%＝減少）**。定義が媒体費ベースで狭いため、市場調査の数値とは一桁違う点に注意 |
| 成果地点       | 購入・申込・資料請求・アプリインストールなど。地点が浅いほど不正が増える                                                             |
| 主な問題       | 誇大表現・アドフラウド・クッキースタッフィング（→ [③規制と課題](03_規制と課題.md)）                                                  |

## 8. インフルエンサー：人が媒体になる

| 形態                         | 支払い方                                                           | 特徴                                                                                                                |
| ---------------------------- | ------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------- |
| **タイアップ投稿（PR案件）** | 固定フィー（フォロワー数×単価が目安。1フォロワー1〜5円と言われる） | 内容をコントロールしやすい。**ステマ規制でPR表記が必須**（→ [③](03_規制と課題.md)）                                 |
| **ギフティング**             | 商品提供のみ                                                       | 安価だが投稿を保証できない                                                                                          |
| **アフィリエイト型**         | 成果報酬                                                           | 売上と連動。クリエイター側のリスクが大きい                                                                          |
| **ブランドアンバサダー**     | 年間契約                                                           | 芸能マネジメントに近い（→ [芸能・マネジメント](../../14_メディア・広告・エンタメ/11_芸能・マネジメント/README.md)） |
| **ホワイトリスト配信**       | 投稿をそのまま広告素材として運用                                   | クリエイターの信頼性＋運用型の配信力。近年の主流                                                                    |

- 国内のインフルエンサーマーケティング市場は**860億円規模**、年平均13.8%成長との推計がある
  （調査会社により定義が大きく異なるため、数値は目安）
- 間に入る**キャスティング会社・MCN**が20〜30%程度を取るのが一般的と言われる

## 9. リテールメディア：小売が広告会社になる

**リテールメディア**＝ 小売業者が持つ購買データと自社の接点（ECサイト・アプリ・店頭サイネージ）を
広告枠として売る事業。Amazonが作り、いま国内小売が追っている。

```
【なぜ小売が広告をやるのか】

 小売の本業         広告事業
 売上100            売上100
 −仕入 75           −配信コスト 20
 −販管費 22         −人件費 15
 ────────          ────────
 営業利益 3          営業利益 65
   ▲ 粗利率が薄い     ▲ 一度作れば限界費用がほぼゼロ
```

- 小売の営業利益率は数%。**同じ売上でも広告事業の利益率は桁違い**なので、
  「広告で稼いで本業の価格競争に回す」構造が成立する
- 市場規模の推計は調査機関で大きく割れる（数百億円〜6,000億円超）。
  **何をリテールメディアに含めるか（ECサイト内広告のみか、店頭サイネージやクーポンも含むか）**で
  定義が違うため、単純比較できない。詳細は [④直近トピック](04_直近トピック_2026.md) 第3章
- 関連：[EC・ネット通販](../08_EC・ネット通販/README.md)、
  [コンビニエンスストア](../../07_小売・流通/01_コンビニエンスストア/README.md)、
  [ドラッグストア](../../07_小売・流通/04_ドラッグストア/README.md)

## 10. まとめ：付加価値はどこにあるか

| 立場                         | 交渉力       | 理由                                               |
| ---------------------------- | ------------ | -------------------------------------------------- |
| **プラットフォーム**         | 最強         | 在庫・データ・計測の三点を独占。代替がない         |
| **広告主（大手）**           | 強           | 予算という唯一の武器。インハウス化で代理店を外せる |
| **アドテク中間業者**         | 弱まっている | SPO（経路の最適化）で外されつつある                |
| **総合代理店**               | 中           | マス＋デジタルの統合提案と大規模制作が残る価値     |
| **運用専業代理店**           | 中〜弱       | 設定作業が自動化され、素材と分析でしか差が出ない   |
| **媒体社（一般メディア）**   | 弱           | eCPMもフィルレートも自分で決められない             |
| **小売（リテールメディア）** | 強まっている | 購買データという他が持てない資産                   |

## 12. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **コミッション／フィー** | 広告費に対する料率課金／工数に対する時間課金 |
| **プリンシパル取引** | 代理店が自ら枠を仕入れて転売する形。原価が広告主に見えない |
| **テイクレート／アドテク税** | 取引額に対しプラットフォームが取る割合／広告費が媒体に届くまでに中間業者が抜く総額 |
| **SPO（サプライパス最適化）** | 同じ枠に届く経路のうち無駄な中間を減らす取り組み |
| **取扱高（billings）／売上高** | 広告主から預かった総額／代理店の手数料収入 |
| **インハウス化** | 広告主が運用を自社内で行うこと |
| **eCPM／RPM／フィルレート** | 媒体から見た1,000表示あたりの実収入／在庫のうち実際に埋まった割合 |
| **レベニューシェア** | プラットフォームと媒体・クリエイターの収益分配 |
| **ASP／アフィリエイター／成果地点** | 成果報酬型の仲介事業者／掲載する個人・メディア／報酬が発生する行動の定義 |
| **ギフティング／ホワイトリスト配信／MCN** | 商品提供だけで投稿依頼／クリエイター名義のまま広告運用／クリエイターを束ねる事業者 |
| **リテールメディア** | 小売が購買データと自社接点を広告枠として売る事業 |
| **CAPI（コンバージョンAPI）** | ブラウザを経由せずサーバから成果データを送る計測方式 |
| **MMM** | 統計モデルで媒体ごとの売上寄与を推定する手法 |
