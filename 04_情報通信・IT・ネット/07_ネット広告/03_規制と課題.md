# ③ 規制と課題

このノートで分かること：**サードパーティCookie廃止がなぜ中止になったのか**、
プライバシー規制（GDPR・個人情報保護法）が広告に何を課しているか、
**アドフラウド（広告詐欺）**とブランドセーフティの実態、ステマ規制、
そして業界最大の未解決問題＝**広告の効果測定**。

> ポイント：ネット広告の課題は「技術で解ける問題」と「原理的に解けない問題」に分かれる。
> Cookieやフラウドは技術と制度で殴り合える。しかし**「その広告が売上をいくら増やしたか」は
> 原理的に観測できない**。ここが業界の根本問題であり、AI時代にさらに難しくなっている。

---

## 1. 規制の全体地図

```
【ネット広告にかかる規制の3層】

 ┌─ ① データの規制（誰の情報をどう使えるか） ────────────────┐
 │   GDPR（EU）／CCPA・CPRA（米加州）／個人情報保護法（日本）      │
 │   電気通信事業法 外部送信規律／ePrivacy指令（Cookie同意）      │
 └──────────────────────────────────────────────┘
 ┌─ ② 表示の規制（何をどう言ってよいか） ──────────────────┐
 │   景品表示法（優良誤認・有利誤認・**ステマ告示**）              │
 │   薬機法／医療広告ガイドライン／金商法（投資広告）              │
 └──────────────────────────────────────────────┘
 ┌─ ③ 市場の規制（プラットフォームの力をどう抑えるか） ──────────┐
 │   独占禁止法（米国 vs Google アドテク訴訟）                    │
 │   デジタルプラットフォーム取引透明化法（日本）／DMA（EU）        │
 │   情報流通プラットフォーム対処法（情プラ法、2025年4月施行）      │
 └──────────────────────────────────────────────┘
```

## 2. サードパーティCookie廃止の顛末

**何が起きるはずだったか**：Google Chromeが、サイトをまたいだ追跡に使われる
サードパーティCookie（→ [①](01_広告がどう配信されるか.md) 第5章）を廃止し、
代わりに「Privacy Sandbox」という匿名化された仕組みに置き換える——はずだった。

| 時期           | 出来事                                                                                           |
| -------------- | ------------------------------------------------------------------------------------------------ |
| 2017年         | AppleがSafariに **ITP**（Intelligent Tracking Prevention）を導入。実質的に3rd party Cookieを遮断 |
| 2019年         | Firefoxもデフォルトでブロック                                                                    |
| 2020年1月      | Googleが「2年以内にChromeで3rd party Cookieを段階的に廃止」と発表。業界が大騒ぎに                |
| 2021年         | 延期（2023年へ）。代替案 **FLoC** が批判を浴びて撤回、**Topics API** へ差し替え                  |
| 2022〜23年     | さらに延期（2024年後半へ）。英CMA（競争当局）の監督下に置かれる                                  |
| 2024年1月      | Chrome利用者の1%で試験ブロックを開始                                                             |
| **2024年7月**  | Googleが方針転換を発表。「廃止せず、利用者が選べる仕組みにする」                                 |
| **2025年4月**  | **廃止計画を事実上全面撤回**。専用の選択プロンプトも導入しないと表明                             |
| **2025年10月** | Privacy Sandboxの主要APIも事実上終了と報じられる                                                 |

```
【現在（2026年9月時点）のブラウザ別状況】

 Chrome  ：3rd party Cookie は既定で「許可」のまま（シークレットモードはブロック）
 Safari  ：既定でブロック（2020年から完全遮断）
 Firefox ：既定でブロック
 Edge    ：追跡防止機能あり。既定の強度は中程度

 → 日本のブラウザシェアではChromeが多数派だが、**iPhone経由のSafariも大きい**。
    「Chromeが撤回した＝対策不要」ではない。Safariユーザーにはもともと届いていない。
```

> なぜGoogleは撤回したのか（諸説あるが、報道ベースで整理すると）：
> ① 代替案が広告効果を落とし、業界とパブリッシャーが強く反発した、
> ② 英CMAが「Googleだけが有利になる」と競争上の懸念を示した、
> ③ 同時期にアドテク独禁訴訟を抱え、これ以上市場を握る形に見せたくなかった。

**実務上の結論**：廃止は止まったが、**Cookieに依存しない設計への移行は止まっていない**。
規制（同意取得）とAppleのATTがある以上、後戻りはできない。

## 3. Cookie後の代替手段

| 手段                             | 中身                                         | 弱点                                                                 |
| -------------------------------- | -------------------------------------------- | -------------------------------------------------------------------- |
| **ファーストパーティデータ**     | 自社の会員・購買・閲覧データ                 | 自社の接点がない企業は持てない                                       |
| **CDP**                          | 顧客データを一元化する基盤                   | 導入・運用コストが高い                                               |
| **サーバーサイド計測（CAPI等）** | ブラウザを経由せずサーバから成果を送る       | 同意管理の責任が自社に移る                                           |
| **データクリーンルーム**         | 生データを渡さず、統計的にだけ照合できる部屋 | 分析の自由度が低い。小規模だと精度が出ない                           |
| **共通ID（UID2など）**           | メールアドレス等をハッシュ化した業界共通ID   | 同意が前提。普及は限定的                                             |
| **コンテキストターゲティング**   | ページの内容に合わせる（個人を見ない）       | 精度は劣るが**規制に最も強い**。生成AIで文脈判定の精度が上がり復権中 |
| **リテールメディア**             | 小売の購買データを使う                       | 小売の中でしか使えない（→ [②](02_お金の流れと取り分.md) 第9章）      |

## 4. プライバシー規制：日本と海外

| 制度                                                 | 適用範囲                      | 広告への影響                                                                                                                                                                                                                         |
| ---------------------------------------------------- | ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **GDPR**（EU、2018年〜）                             | EU域内の個人データ            | 追跡には原則**明示的同意**が必要。違反時の制裁金は全世界売上の最大4%。Cookieバナーが世界中に広がった原因                                                                                                                             |
| **ePrivacy指令**                                     | 端末へのアクセス（Cookie）    | Cookie設置そのものに同意が必要                                                                                                                                                                                                       |
| **CCPA／CPRA**（米カリフォルニア）                   | 加州住民                      | 「販売のオプトアウト」権。米国は州ごとにバラバラ                                                                                                                                                                                     |
| **個人情報保護法**（日本）                           | 国内事業者                    | 2022年改正で**個人関連情報**の規律を新設。Cookie等それ単体では個人を特定しない情報でも、**提供先で個人データになるなら本人同意の確認が必要**に                                                                                       |
| **電気通信事業法 外部送信規律**（日本、2023年6月〜） | Webサイト・アプリ運営者の一部 | 利用者情報を外部（アドテク事業者等）へ送る際に**通知・公表が義務**。日本版Cookie規制と呼ばれる                                                                                                                                       |
| **2026年改正個人情報保護法**                         | 国内事業者                    | 3年ごと見直しに基づく改正法が**2026年7月に成立**と報じられる。統計目的の同意緩和、子どもの個人情報・生体データの規制強化、**個人関連情報の不適正利用の禁止**、課徴金制度の導入などが柱（→ [④直近トピック](04_直近トピック_2026.md)） |

### Appleの ATT が与えた衝撃

2021年、iOS 14.5で **ATT**（App Tracking Transparency）が導入され、
アプリが広告IDを使う前に「追跡を許可しますか」と尋ねることが義務化された。
許諾率は3割前後とされ、iOS上のリターゲティングと効果計測が一気に壊れた。
Metaは2022年に「**この影響で年間約100億ドルの売上機会を失う**」と説明している。

> ポイント：**規制はプラットフォームの寡占を強める方向にも働く**。
> 同意を取るには利用者との直接の接点が要るが、それを持っているのは
> Google・Meta・Amazon・Appleのような巨大サービスだけ。
> 「プライバシー保護がプラットフォームを有利にする」という皮肉が業界の共通認識になっている。

## 5. アドフラウド（広告詐欺）

**アドフラウド**＝ 人間が見ていない広告表示やクリックを作り出し、広告費を不正に取る行為。
運用型広告は「表示・クリックの回数」で自動的に金が動くため、**回数を偽造すれば金が取れる**。

```
【主な手口】

 ① ボットトラフィック     プログラムがサイトを巡回し、広告を表示・クリックさせる
 ② 広告の隠し表示         1×1ピクセルに押し込む／画面外に置く（人には見えないが imp は計上）
 ③ アドスタッキング       広告を何枚も重ねて置き、全部に imp を計上する
 ④ ドメインスプーフィング  「大手ニュースサイトの枠です」と偽って安い枠を高く売る
 ⑤ クッキースタッフィング  訪問していないのに成果Cookieを埋め、アフィリエイト報酬を横取り
 ⑥ MFA（Made for Advertising）
                         広告を出すためだけに作られた中身のないサイト。
                         生成AIで大量生産され、2025年に急増
```

| 指標                  | 数値                                         | 出典・注記                                                                        |
| --------------------- | -------------------------------------------- | --------------------------------------------------------------------------------- |
| 国内の推計被害額      | **約1,591億円**（2025年、前年比+82億円）     | Spider Labs「アドフラウド調査レポート2025」の推計。**推計値であり確定額ではない** |
| MFAサイトへの掲載件数 | 前年比 **1,409%** に急増、被害額は前年比533% | 同レポート。生成AIによる量産が主因とされる                                        |
| 2026年の被害見通し    | 1,816億円に達する可能性                      | 同レポートの予測                                                                  |

### 対策の仕組み

| 仕組み                                                         | 何をするか                                                                             |
| -------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| **ads.txt / app-ads.txt**                                      | 媒体側が「自社の枠を売ってよい事業者」を公開ファイルで宣言する。なりすまし販売を防ぐ   |
| **sellers.json / SupplyChain Object**                          | 取引経路の各事業者を開示し、経路をたどれるようにする                                   |
| **アドベリフィケーション**                                     | 第三者（IAS、DoubleVerify、Momentum等）が配信面と表示実態を検証する                    |
| **JICDAQ**（一般社団法人デジタル広告品質認証機構、2021年設立） | 国内の広告事業者に対し、無効トラフィック対策・ブランドセーフティ対策の**認証**を与える |

## 6. ブランドセーフティとブランドスータビリティ

| 概念                       | 意味                                         | 例                                                                                         |
| -------------------------- | -------------------------------------------- | ------------------------------------------------------------------------------------------ |
| **ブランドセーフティ**     | ブランドを毀損する面に広告が出ないようにする | 違法サイト・暴力・ヘイト・偽情報の横に自社広告が並ばないようにする                         |
| **ブランドスータビリティ** | 「安全か」ではなく「自社に適した文脈か」     | 航空会社の広告が航空事故の記事に出ない（記事自体は安全だが不適）                           |
| **キーワードブロック**     | NGワードを含むページを除外                   | 過剰にブロックすると報道メディアが軒並み除外され、良質な媒体の収入を削ぐという副作用がある |

> なぜ起きるか：運用型広告では**広告主が配信先を事前に指定していない**。
> 「人」を買った結果として、たまたまそのページに出る。
> 配信先リスト（プレースメントレポート）を確認しない運用が長年放置されてきたのが遠因。

## 7. ステマ規制（日本、2023年10月〜）

**ステルスマーケティング（ステマ）**＝ 広告であることを隠して、第三者の感想を装う宣伝。

- 2023年10月1日、**景品表示法第5条第3号**に基づく告示が施行され、
  「事業者の表示であるのに、それが分かりにくいもの」が**不当表示として禁止**された
- 規制されるのは**広告主（事業者）**であって、インフルエンサー本人ではない点が重要
- 違反すると**措置命令**（再発防止命令＋事業者名の公表）。命令違反には
  2年以下の拘禁刑または300万円以下の罰金

| 事例       | 内容                                                                                                                                         |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| 2024年11月 | 大正製薬が措置命令。インフルエンサーへ報酬を払って投稿させ、その投稿を自社サイトへ転載する際に「PR」表記をしなかったと認定されたと報じられる |
| 2025年3月  | 医療法人社団スマイルスクエアが措置命令。Googleマップへの高評価投稿の見返りに治療費を割り引いていたと認定されたと報じられる                   |

> 実務上のポイント：**「お客様の声」としてインフルエンサー投稿を自社サイトに転載する**という
> 行為が典型的な違反パターンになっている。投稿先（SNS）にPR表記があっても、
> 転載先に表記がなければ別の表示とみなされうる。

関連する表示規制：**薬機法**（化粧品・健康食品の効能表現）、**医療広告ガイドライン**（ビフォーアフター写真）、
**金商法**（投資広告）。ネット広告の審査で落ちる理由の大半はこれら。

## 8. 詐欺広告・なりすまし広告

- 著名人の写真やディープフェイク動画を使った投資詐欺広告がSNSに大量出稿された問題。
  警察庁によると**2025年のSNS型投資詐欺の認知件数は9,538件（前年比+48.7%）、
  被害額1,274.7億円**で過去最悪を更新したと報じられる
- 2025年4月、**情報流通プラットフォーム対処法（情プラ法）**が施行。
  大規模プラットフォームに削除申出の窓口設置・対応期限・削除基準の公表などを義務付けた
- 刑法改正で「私電磁的記録文書等偽造・行使罪」を新設し、なりすまし広告の摘発を可能にする
  法整備が進んだと報じられる
- 構造的な原因は [②お金の流れと取り分](02_お金の流れと取り分.md) にある。
  **出稿する側の審査が自動化されており、金さえ払えば通ってしまう**ため、
  詐欺グループにとって最も費用対効果の高い集客手段になっている

## 9. 効果測定という難問

ここが業界の根本問題。**「広告を出したから売れた」のか「出さなくても売れた」のかは、
原理的に観測できない**（同じ顧客の両方の世界を見ることはできない）。

```
【観測できるもの／できないもの】

 観測できる                        観測できない
 ├ 表示された回数                  ├ 見たか（ビューアビリティは近似）
 ├ クリックされた回数              ├ 記憶に残ったか
 ├ クリック後に買ったか            ├ **広告がなくても買ったか（＝増分）**
 └ 最後に触れた広告                └ 複数媒体の貢献度の真の配分
                                     ▲ ここが空白のまま予算配分が決まっている
```

| 手法                                            | 中身                                                   | 限界                                                                                       |
| ----------------------------------------------- | ------------------------------------------------------ | ------------------------------------------------------------------------------------------ |
| **ラストクリック**                              | 最後にクリックされた広告に成果を全振り                 | 最も普及。**リターゲティングを過大評価する**（買う直前の人に出せば成果が付く）             |
| **アトリビューション分析**                      | 接触した複数の広告に成果を按分                         | Cookie規制でユーザー単位の追跡が困難になり、機能しなくなった                               |
| **MMM（マーケティング・ミックス・モデリング）** | 売上を時系列の統計モデルで説明し、媒体ごとの寄与を推定 | 個人データ不要なので**規制時代に復権**。ただしデータが数年分必要で、細かい判断には使えない |
| **インクリメンタリティ（増分）テスト**          | 広告を出す群／出さない群を分けて比較する実験           | 因果を測れる唯一の方法。ただし機会損失が出るし、実験設計が難しい                           |
| **ジオリフト（地域実験）**                      | 地域単位で配信有無を分けて比較                         | 個人データ不要。日本では地域差が小さく精度が出にくいことも                                 |
| **ブランドリフト調査**                          | 配信群と非配信群にアンケートし認知・好意度の差を測る   | プラットフォーム自身が実施するので自己採点問題が残る                                       |

> ポイント：**指標が測れるようになったのがネット広告の強みだったのに、
> いま最も信頼される手法（MMM・実験）はマス広告時代の手法に戻っている**。
> Cookie規制とプラットフォームの閉鎖性が、測定の解像度を逆に下げた。

## 10. 課題の相互関係

```
 プライバシー規制 ──▶ 追跡が難しくなる ──▶ 計測精度が落ちる
        │                                        │
        │                                        ▼
        └──▶ 同意を取れる巨大PFが有利 ──▶ ウォールドガーデン化
                                                 │
 運用の自動化 ──▶ 配信先が見えない ───────────┤
        │                                        ▼
        └──▶ 審査も自動化 ──▶ アドフラウド／詐欺広告／MFAが通る
                                                 │
                                                 ▼
                                    広告の信頼が落ちる ──▶ 単価が下がる
```

**つまり**：プライバシー保護・自動化・寡占は別々の話ではなく、**同じ1つのループ**を回している。
この業界の議論は、ほぼすべてこの図のどこかの矢印を切ろうとする試みだと理解すると見通しがよい。

## 12. 用語メモ

| 用語 | 意味 |
| --- | --- |
| **サードパーティCookie** | 閲覧中のサイト以外のドメインが発行するCookie。サイト横断追跡に使われる |
| **ITP／Privacy Sandbox・Topics API** | Safariの追跡防止機能（2017年〜）／GoogleのCookie代替技術。2025年に主要APIが事実上終了 |
| **ATT** | Appleのアプリ追跡同意制度（2021年）。iOSのリターゲティングと計測を大きく損なった |
| **GDPR** | EU一般データ保護規則。制裁金は全世界売上の最大4% |
| **個人関連情報** | 単体では個人を特定しないが、提供先で個人データになりうる情報。日本の2022年改正で新設 |
| **外部送信規律** | 電気通信事業法に基づき利用者情報の外部送信を通知・公表させる制度（2023年6月〜） |
| **CDP／データクリーンルーム** | 顧客データ基盤／生データを持ち出さずに突合分析する環境 |
| **アドフラウド／MFA／ドメインスプーフィング** | 広告費を騙し取る不正の総称／広告表示のためだけの低品質サイト／掲載先ドメインの偽装 |
