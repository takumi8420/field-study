2. 生成AI検索とゼロクリック：広告の土台が削られている

いま業界で最も深刻に受け止められているのがこれ。

【何が起きているか】

 従来：  検索 ──▶ 検索結果 ──▶ サイトを訪問 ──▶ そのサイトの広告を見る
                   ▲ ここに検索広告        ▲ ここにディスプレイ広告

 いま：  検索 ──▶ AIが回答を生成 ──▶ （サイトに行かない＝ゼロクリック）
                   ▲ 広告枠が縮む        ▲ **媒体社の広告在庫がまるごと消える**
論点 報じられている数値 出典の性質
Google検索のゼロクリック率検索の約68%がサイト遷移なしで完結との調査調査会社の推計
AI Overviews導入によるCTR低下グローバルで約58%減、日本でも約38%減Ahrefsの調査（2026年、プレスリリース）
情報取得型キーワードの1位CTR1.76% → 0.61%（6割超の低下）調査ベースの報道
パブリッシャーの広告在庫2026年Q2にメディアの広告サプライが最大40%減、プログラマティック支出は前年同期比30.6%減DIGIDAYの報道

なぜ広告に効くのか（因果の整理）

  1. AIが検索結果画面で答えを完結させる → サイトへのクリックが減る
  2. サイトのPVが減る → ディスプレイ広告の在庫（imp）が物理的に減る
    （② 第6章の式で、最初の変数が縮む）
  3. 在庫が減ると需給は締まるはずだが、在庫の質も落ちるため単価は上がらない
  4. 一方、検索広告そのものはAI OverviewsやAI Modeの中に広告枠を新設することで
    Google側が防衛している（米国で先行。Googleは「AI MAX for サーチキャンペーン」を
    2026年の重点プロダクトとして推進していると報じられる）

構図：Googleは自分の検索広告は守れるが、Webメディアの広告在庫は守らない。
つまりこの変化は「広告市場全体の縮小」ではなく、「オープンWebからプラットフォームへの
さらなる集中」として現れている。

3. リテールメディアの伸び

購買データを持つ小売・ECが広告事業者になる流れが、国内でも本格化した。

指標 数値 注記
Amazonの広告売上（世界）2025年通期で680億ドル超と報じられるGoogle・Metaに次ぐ第3極。2025年にフルファネル戦略で120億ドル超の増収寄与との説明
国内リテールメディア広告市場2025年に6,066億円（前年比129%）、2029年に1.3兆円との推計調査機関の推計。定義により数値が大きく割れる
別系統の推計CARTA HOLDINGSは2022年135億円→2026年805億円と予測（2022年発表）店頭サイネージ等を含むか否かで一桁違う
実店舗事業者分の予測2035年に1兆円規模との見立て報道ベース
【なぜ数値が割れるのか】

 ┌─ 広い定義 ────────────────────────────────┐
 │  ECサイト内広告 ＋ 小売アプリ ＋ 店頭サイネージ ＋ レシートクーポン  │
 │  ＋ 小売のデータを使った外部媒体への配信（オフサイト）             │
 │      → 6,000億円クラスの数値になる                             │
 └───────────────────────────────────────┘
 ┌─ 狭い定義 ──────────────┐
 │  小売ECサイト内の広告枠のみ     │
 │      → 数百億円クラスになる     │
 └─────────────────────┘

 ※ Amazon・楽天を「リテールメディア」に含めるかどうかでも大きく変わる。
   電通統計では「物販系ECプラットフォーム広告費」として別立て集計されている。

伸びる理由は単純で、購買データが最も成果に直結し、かつ小売にとって利益率が桁違いに高いから
（→ ②お金の流れと取り分 第9章）。
Cookie規制で外部データが使いにくくなったことが追い風にもなっている。

4. Googleアドテク独禁法訴訟：分割は回避（2026年9月）

時期 出来事
2025年4月17日米バージニア州東部地区連邦地裁（ブリンケマ判事）が、Googleはパブリッシャー向け広告サーバとアドエクスチェンジの市場で違法に独占を維持したと認定。一方、広告主側ツールの独占は立証されずと判断
2026年9月2日同判事が是正措置を決定。司法省が求めたAdXの売却、DFPのオークションロジックのオープンソース化、DFP残余部分の条件付き売却という3つの構造的措置をいずれも却下し、行動是正措置にとどめる命令を出したと報じられる
内容AdXの入札情報の開示、統一価格ルール（Unified Pricing Rules）の撤廃など、Google側が提案していた是正案が概ね採用されたとされる
今後控訴を含め最終決着は先。別件の検索独占訴訟ではChrome分離が回避されている

意味合い：構造分割は当面回避されたが、広告主・媒体社から見ると
「入札の透明性が制度として担保された」点は実務上の変化になりうる。
① 第4章で触れたヘッダービディング以前の
「Googleだけが最後に入札額を見られる」構造が、司法の場で問題とされたことの帰結。

6. 個人情報保護法の2026年改正と、Cookie問題の「その後」

論点 状況（2026年9月時点）
サードパーティCookieGoogleは2025年4月に廃止計画を事実上全面撤回。Chromeでは既定で許可のまま。Privacy Sandboxの主要APIも2025年10月に事実上終了と報じられる。ただしSafari・Firefoxは従来どおりブロック
個人情報保護法の改正3年ごと見直しに基づく改正法案が2026年4月に国会提出、7月10日に成立と報じられる
改正の柱① 統計作成目的などでの同意義務の緩和（AI開発への配慮）、② 子どもの個人情報・生体データ・委託先の規制強化、③ 個人関連情報の不適正利用の禁止と第三者提供時の確認義務、④ 課徴金制度の導入を含む事後的規律の強化
広告実務への含意「Cookieは使えるが、使い方はより厳しく問われる」方向。課徴金の導入は、これまで行政指導止まりだった日本の運用を実質的に変える可能性がある
詐欺広告2025年のSNS型投資詐欺は認知9,538件・被害1,274.7億円で過去最悪（警察庁）。情プラ法（2025年4月施行）と刑法改正で対応が進む

7. 全体の構図

  1. 量としては史上最高。ネット広告費は4兆円を超え、総広告費の過半を占めた（2025年、電通）。
    伸ばしたのは動画・ソーシャル・リテールメディアで、いずれもプラットフォーム側の在庫である。
  2. 土台は削られている。生成AI検索によるゼロクリック化で、オープンWebの広告在庫は
    2026年に入って最大40%減との報道もある。伸びと縮みが同時に起きている。
  3. 集中がさらに進む。規制（同意取得）も、AI検索も、リテールメディアも、
    結論は「自前の接点とデータを持つ者が強い」で一致する。独禁法の是正措置は
    構造分割にまで至らなかった（2026年9月）。
  4. 運用の仕事は上流へ移る。入札も素材もAIが回すようになり、代理店の価値は
    計測設計・データ整備・検証設計に寄った。同時に自動化は詐欺広告の量産も助けている。
  5. 残る根本問題は効果測定。追跡が制限され、配信先がブラックボックス化した結果、
    信頼できる手法はMMMと実験というマス広告時代の道具に戻りつつある。
