① 広告がどう配信されるか

情報通信・IT・ネットネット広告

このノートで分かること：ネット広告の種類の地図と、1本のバナーが表示されるまでの
0.1秒のオークション（RTB）の中身、誰を狙うか（ターゲティング）、何で成果を測るか（CPC/CPA/ROAS）。

ポイント：ネット広告の正体は「広告枠の売買」ではなく、1インプレッション（広告1回表示）ごとの
自動オークション。日本のネット広告媒体費の 88.7%（2025年、電通） がこの方式（＝運用型）で取引されている。

1. まず種類の地図

ネット広告は「どこに出るか」で分けると5種類に整理できる。
金額は電通「2025年 日本の広告費 インターネット広告媒体費 詳細分析」（2026年3月発表）。

種類 どこに出るか 何で課金するか 2025年の規模（日本の媒体費）
検索連動型（リスティング）検索結果の上部。「弁護士 離婚」と打った人に法律事務所の広告ほぼCPC（クリック課金）媒体費全体の 38.7%（＝約1.28兆円相当）
ディスプレイニュースサイトやアプリのバナー枠CPM（表示課金）／CPC運用型ディスプレイは前年比111.5%
ビデオ（動画）YouTube・TVer・SNS・CTVCPM／CPV（視聴課金）1兆275億円（前年比121.8%、初の1兆円超）
ソーシャルInstagram・TikTok・X・LINE・FacebookCPM／CPC1兆3,067億円（前年比118.7%、構成比39.5%）
リテールメディア（物販系ECプラットフォーム広告）Amazon・楽天・小売アプリ・店頭サイネージCPC中心電通は「物販系ECプラットフォーム広告費」として別掲。急成長領域（→ ④直近トピック）

補足：

  • ビデオとソーシャルは重複する。Instagramリール広告は「ソーシャル広告」でも「ビデオ広告」でもある。
    電通の分類は「広告商品の種類別」と「メディア種別」で別々に集計されているので、足し算してはいけない
  • 「インターネット広告費 4兆459億円（2025年、前年比110.8%）」と
    「インターネット広告媒体費 3兆3,093億円」は別物。差額の約7,400億円は
    広告制作費と物販系ECプラットフォーム広告費にあたる（電通発表値からの差分計算）
  • 2025年はインターネット広告費が総広告費 8兆623億円の 50.2% を占め、統計開始以来初めて過半数になった

2. 「枠」を買う時代から「人」を買う時代へ

【昔：予約型（枠売り）】
 広告主 ──「Yahoo!トップに1週間、1,000万円で」──▶ 媒体社
        誰が見るかは分からない。枠の値段は事前に決まっている

【今：運用型（人買い）】
 広告主 ──「30代女性で化粧品を検索した人に、1クリック150円まで払う」──▶ システム
        誰に出すかを毎回システムが判断し、値段も毎回変わる
取引手法 中身 2025年の金額（日本、電通） 構成比
運用型広告入札とターゲティングをシステムが毎回決める2兆9,352億円（前年比112.5%）88.7%
予約型広告枠と期間と金額を事前に契約3,042億円（前年比109.1%）9.2%
成果報酬型広告申込や購入が発生した分だけ払う（アフィリエイト）699億円（前年比96.1%＝減少）2.1%

なぜ運用型が9割になったのか：予約型は「枠が売れ残るリスク」を媒体社が負い、広告主は
「効かない枠に払うリスク」を負う。1回の表示ごとに値段を決めれば、両方のリスクが消える。
ただし代償として、広告主は「どこに出たか」を完全には把握できなくなった（→ ③規制と課題）。

3. アドテクの登場人物

運用型広告を動かす仕組みをアドテクノロジー（アドテク）と呼ぶ。登場人物は4つだけ覚えればよい。

略称 正式名称 日本語で言うと 誰の味方か
DSPDemand Side Platform広告主の買い付け端末広告主。安く・効く枠を買いたい
SSPSupply Side Platform媒体社の販売端末媒体社。1枠でも高く売りたい
アドエクスチェンジAd Exchange広告枠の取引所（証券取引所の広告版）中立（建前上）。売買を突き合わせる
アドサーバAd Server配信管理サーバ。どの広告を何回出したか記録する広告主側・媒体社側の両方にある
（補助） DMP／CDPData Management / Customer Data Platform誰にどう出すかを決めるためのデータ置き場広告主・媒体社の双方

4. RTB ＝ 1件あたり0.1秒のオークション

RTB（Real-Time Bidding／リアルタイム入札）＝ ユーザーがページを開いたその瞬間に、
その1回の表示権をオークションにかけて売る仕組み。所要時間はおおむね100ミリ秒（0.1秒）以内が
業界の標準的な制限時間とされる。人間がページの読み込みを待てる限界がそこだから。

【0.1秒の中で起きていること】

 0ms   ユーザーがニュース記事を開く
  │
 5ms   媒体のページから SSP へ「枠が1つ空いた。訪問者はこのID、東京、Android」
  │
 15ms  SSP → アドエクスチェンジ → 数十〜数百の DSP へ一斉に入札リクエスト
  │      （送る情報＝ページURL・広告枠サイズ・おおよその位置情報・Cookie/広告ID）
  │
 25ms  各DSPが自社データベースを照合
  │      「このIDは3日前に自社サイトでカートに商品を入れた人だ」→ 高く入札
  │      「知らないIDだ」→ 安く入札、または入札しない
  │
 60ms  入札額が返る：A社 320円CPM / B社 180円CPM / C社 入札なし …
  │
 70ms  最高額の A社 が落札。支払額は第一価格（＝入札額そのもの）が主流
  │
 85ms  A社の広告タグが媒体側に返り、クリエイティブ（画像・動画）を配信
  │
 100ms 画面に広告が表示される ＝ 1インプレッション成立

価格の決まり方が変わった話

方式 支払額 使われた時期 なぜ変わったか
セカンドプライス（第二価格）2位の入札額＋1円〜2017年ごろまで主流正直に上限額を入れても損しない設計。ただし媒体社から見て「本当に2位だったのか」が検証できない
ファーストプライス（第一価格）自分の入札額そのもの2018年ごろ〜現在の主流媒体社の不信感とヘッダービディングの普及で移行。広告主は「いくらまでなら払うか」を自分で計算する必要が生じた
  • ヘッダービディング：媒体社がページの読み込み時点で複数のSSPへ同時に声をかけ、
    最も高い値を付けたところに売る技術（2015年ごろ普及）。それ以前は
    Googleのアドサーバが最後に入札額を見て上乗せできる立場にあり、これが独禁法訴訟の争点になった
  • フロアプライス（最低落札価格）：媒体社が「これ以下では売らない」と設定する下限。
    安売りを防ぐ一方、設定が高すぎると枠が売れ残る

ポイント：この1回のオークションが、日本だけで1日に数百億回走っている。
だからネット広告は「人が枠を売る商売」ではなく「システムの計算量で勝負する商売」になった。

RTBを通らない取引もある

取引形態 中身
PMP（プライベートマーケットプレイス）招待された広告主だけが参加できる限定オークション。質の高い媒体を確保したいときに使う
プログラマティック・ギャランティード枠と単価を事前に固定しつつ、配信はシステムで行う。予約型と運用型の中間
ウォールドガーデン（壁に囲まれた庭）Google・Meta・Amazon・LINEヤフーの自社完結型。外部のDSPからは買えず、自社の管理画面からしか買えない。ネット広告費の大半はここに落ちる

5. 誰を狙うか（ターゲティング）

種類 何を根拠に狙うか 例 精度／リスク
デモグラ年齢・性別・地域「東京都・30代女性」精度は中。プラットフォームの登録情報が根拠
オーディエンス（興味関心）閲覧履歴から推定した興味「旅行に関心がある人」プラットフォームの推定。根拠は非公開
リターゲティング（リタゲ）自社サイトを訪れた履歴カート放棄者に再訴求最も効くが、最もCookie依存が強い
類似拡張（Lookalike）既存顧客と似た行動をする人購入者リストから拡張1st partyデータが原資。Cookie廃止に強い
コンテキスト（文脈）出稿先ページの内容登山記事にアウトドア用品個人を特定しない。プライバシー規制の回避先として復権中
リテール（購買）実際のレジ通過データ「先月ビールを買った人」最も購買に近い。小売しか持っていない

Cookieとは何か（ここを外すと後の章が分からない）

Cookie（クッキー）＝ ブラウザがサイトごとに保存する小さなメモ。ログイン状態の保持などに使う。

【ファーストパーティ Cookie】          【サードパーティ Cookie】
 example.com を閲覧                    example.com を閲覧
      ↓                                     ↓
 example.com がメモを置く              ページに埋まった adtech.com が
 「この人はカートに商品あり」            adtech.com 名義でメモを置く
      ↓                                     ↓
 example.com でしか読めない            news.com を見たときも adtech.com が
 → 自社の分析用                        同じメモを読める
                                       → サイトをまたいだ追跡ができる ＝ これが問題に
  • モバイルアプリではCookieが使えないので、代わりに広告IDを使う
    （iOSの IDFA、Androidの AAID）。2021年のApple ATT（App Tracking Transparency）で
    iOSは「追跡を許可しますか」の同意が必須になり、リターゲティングの精度が大きく落ちた
  • サードパーティCookieの「廃止」がどうなったかは ③規制と課題 第2章

6. クリエイティブと入札の自動化

いま起きている最大の変化は、広告主が細かく設定しなくなったこと。

世代 広告主がやること 代表的な商品
手動運用（〜2015ごろ）キーワード・入札額・配信面を1つずつ設定個別キーワード入札
自動入札（2016〜）「CPA 3,000円で」と目標だけ渡すTarget CPA／Target ROAS
フルオート（2021〜）素材・予算・目標だけ渡す。面もキーワードも機械が決めるGoogle P-MAX、Meta Advantage+
AIエージェント（2025〜）素材そのものも生成AIが作る。運用の意思決定まで任せる→ ④直近トピック

なぜそうなるか：オークションが0.1秒で数百億回走る世界では、人間が手で最適化できる情報量を
とっくに超えている。一方で、機械が「どこに出したか」を広告主に開示しないため、
広告代理店の仕事が「設定作業」から「素材作りと計測設計」へ移った（→ ②お金の流れと取り分）。
