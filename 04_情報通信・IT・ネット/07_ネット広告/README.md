## 1. 業界の定義・範囲

**ネット広告（インターネット広告／デジタル広告）**＝ インターネット回線を通じて配信される広告と、
その配信・取引・計測を支える事業の総称。

```
【ネット広告の守備範囲】

 ┌──────────────────────────────────────────────────────┐
 │ 媒体面 ：検索結果／Webサイト／アプリ／SNS／動画／CTV／EC売場／店頭サイネージ│
 │ 商品   ：検索連動型・ディスプレイ・ビデオ・ソーシャル・リテールメディア      │
 │          ・アフィリエイト・タイアップ／インフルエンサー                    │
 │ 取引   ：運用型（RTB／PMP）・予約型・成果報酬型                            │
 │ 事業者 ：媒体社／プラットフォーム／広告代理店／アドテク事業者／ASP           │
 │          ／制作会社／計測・検証事業者                                      │
 └──────────────────────────────────────────────────────┘
      ▲ 電通統計では「インターネット広告費＝媒体費＋広告制作費＋物販系ECプラットフォーム広告費」
```

境界の引き方：

- **マス広告（テレビ・新聞・雑誌・ラジオ）とプロモーションメディア（交通・折込・DM）は範囲外**。
  ただしCTV（ネット接続テレビ）は**ネット広告側**に集計される。テレビCMとの境界がここで曖昧になる
- **デジタルサイネージ**は設置場所で扱いが変わる。小売店頭のものはリテールメディアに含める論者が多い
- **SEO・オウンドメディア運営**は広告費ではないが、実務上は同じ担当者が見る隣接領域
- **代理店業そのもの**は [広告代理店](../../14_メディア・広告・エンタメ/01_広告代理店/README.md)

## 3. バリューチェーン（川上 → 川下）

```
 広告主 ──▶ 代理店 ──▶ 買い付け基盤 ──▶ 取引所 ──▶ 販売基盤 ──▶ 媒体 ──▶ 生活者
 予算を持つ   企画・運用    DSP            Ad Exchange   SSP        枠を持つ
 メーカー     制作・計測    ＋ DMP/CDP                              メディア
 EC・アプリ                                                        SNS・アプリ
 人材・金融                  └────── ウォールドガーデン ──────┘
                              （Google/Meta/Amazon は全部自前で持つ）
      ▲ 交渉力は     ▲ 付加価値が      ▲ 中間手数料は       ▲ 価格決定権を
        予算の大きさ    「運用」から       SPOで削られつつある    持たない
        で決まる        「計測・素材」へ
```

- 付加価値が最も集まるのは**プラットフォーム**。在庫・データ・計測の3点を同時に握っているため
- **中間のアドテク事業者は薄くなる方向**。広告主が経路を絞る（SPO）動きが続く
- 逆に強まっているのは**リテールメディア**。購買データという他社が持てない資産があるため
- 詳細は [② お金の流れと取り分](02_お金の流れと取り分.md)

## 5. 収益モデル・コスト構造

```
【立場ごとの儲け方】

 プラットフォーム： imp × eCPM  −（サーバ費 ＋ 審査コスト）
                   ▲ 在庫の仕入れ原価がほぼゼロ → 営業利益率が極めて高い

 代理店        ： 広告費 × 手数料率（15〜20%が目安）または 工数 × 単価
                  −（人件費が費用のほぼ全て）
                   ▲ 典型的な労働集約。**広告費が増えても人が足りないと受けられない**

 媒体社        ： PV × 枠数 × フィルレート × eCPM ÷ 1000
                  −（制作費 ＋ サーバ費）
                   ▲ 4つの変数のうち3つを自分で決められない

 ASP          ： 成果報酬額 × 取り分（30%前後が相場と言われる）
                   ▲ 不正検知コストが収益を圧迫する
```

| 論点                     | 中身                                                                                                         |
| ------------------------ | ------------------------------------------------------------------------------------------------------------ |
| 代理店の手数料率         | 運用型で広告費の**20%前後**が一つの相場観（各社非公開）。大型案件ほど低率化しフィー型へ                      |
| 代理店の利益率           | 人件費が費用の大半。営業利益率は一桁台が一般的                                                               |
| プラットフォームの利益率 | 限界費用がほぼゼロのため、営業利益率30%前後も珍しくない                                                      |
| アドテク税               | オープン経路では広告費の**4〜6割程度しか媒体に届かない**とされる（ISBA/PwC 2020年調査ほか）                  |
| 季節性                   | 12月（年末商戦）と3月（期末）が山。1〜2月と8月が谷                                                           |
| 景気感応度               | 高い。広告費は景気後退局面で真っ先に削られる。ただし**運用型は即座に止められる**ぶん、マス広告より変動が速い |

→ 詳細は [② お金の流れと取り分](02_お金の流れと取り分.md)

## 6. 競争要因（KSF）と参入障壁

**KSF（成功の鍵）**

1. **自前の広告在庫とユーザー接点**：在庫を持つ者が最も強い。持たないなら購買データを持つ
2. **ファーストパーティデータ**：Cookie規制下で唯一確実に使えるターゲティング資源
3. **クリエイティブの量産力**：配信面を機械が決める以上、差が出るのは素材だけ
4. **計測設計力**：何をもって成功とするかを定義できる会社が予算を握る
5. **人材の採用と定着**：代理店側は完全に労働集約。運用人材の供給が成長の上限になる
6. **品質管理（フラウド・ブランドセーフティ）**：事故が1件起きると広告主を失う

**参入障壁**

| 障壁                             | 強さ     | 理由                                                                           |
| -------------------------------- | -------- | ------------------------------------------------------------------------------ |
| **プラットフォーム事業への参入** | 極めて強 | 在庫（ユーザー）とデータの蓄積に年数がかかる。資本では買えない                 |
| **アドテク事業への参入**         | 強       | 技術より「取引される量」がものを言う。後発は入札に呼ばれない                   |
| **運用代理店への参入**           | **弱**   | 認定パートナー資格と人がいれば始められる。だから事業者数が多く、価格競争になる |
| **制作・クリエイティブ**         | 弱〜中   | 生成AIで参入コストがさらに下がる方向                                           |
| **アフィリエイトASP**            | 中       | 広告主とアフィリエイターの両面を集める鶏卵問題                                 |

> ポイント：**この業界は「上に行くほど障壁が高く、下に行くほど誰でも入れる」**。
> 代理店の数が多く競争が激しい一方、プラットフォームの地位は10年以上動いていない。

## 7. 規制・法制度

| 法律・制度                                       | 内容                                                                                                                                                                                                                     |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **景品表示法**                                   | 優良誤認・有利誤認の禁止。違反は措置命令＋課徴金。**2023年10月からステマ告示**（広告であることを隠す表示の禁止）が施行                                                                                                   |
| **個人情報保護法**                               | 2022年改正で**個人関連情報**の規律を新設（Cookie等の第三者提供に本人同意の確認義務）。3年ごと見直しに基づく**改正法が2026年7月に成立**と報じられ、課徴金制度の導入、子ども・生体データの規制強化、統計目的の同意緩和が柱 |
| **電気通信事業法 外部送信規律**                  | 2023年6月施行。利用者情報を外部へ送信する際の通知・公表義務。日本版Cookie規制                                                                                                                                            |
| **GDPR／ePrivacy（EU）**                         | 追跡には明示的同意。制裁金は全世界売上の最大4%                                                                                                                                                                           |
| **CCPA／CPRA（米加州）**                         | 個人情報の「販売」のオプトアウト権                                                                                                                                                                                       |
| **薬機法／医療広告ガイドライン**                 | 化粧品・健康食品・医療の表現規制。広告審査で落ちる理由の最大要因                                                                                                                                                         |
| **金融商品取引法**                               | 投資関連広告の表示規制。SNS型投資詐欺広告の論点                                                                                                                                                                          |
| **独占禁止法**                                   | 米国 vs Googleのアドテク訴訟。2025年4月に違法独占を認定、**2026年9月に構造分割は却下され行動是正措置にとどまる**と報じられる                                                                                             |
| **デジタルプラットフォーム取引透明化法（日本）** | 2021年施行。2022年に広告分野（デジタル広告）が規制対象に追加。取引条件の開示・苦情処理体制の整備を義務付け                                                                                                               |
| **情報流通プラットフォーム対処法（情プラ法）**   | 2025年4月施行。削除申出窓口の設置・対応期限・基準公表を義務付け。詐欺広告対応の受け皿                                                                                                                                    |
| **自主規制**                                     | JIAA（日本インタラクティブ広告協会）のガイドライン、**JICDAQ**（2021年設立）の品質認証                                                                                                                                   |

- **生成AI検索によるゼロクリック化が広告の土台を削り始めた**。Googleの検索の約68%が
  サイト遷移なしで終わるとの調査、AI Overviewsによる日本のCTRは約38%減（Ahrefs調査）、
  2026年Q2にメディアの広告在庫が最大40%減との報道。**Googleは自社の検索広告はAI Overviews／AI Modeに
  広告枠を設けて守るが、Webメディアの在庫は守らない**
- **リテールメディアが伸びている**。Amazonの広告売上は2025年通期で680億ドル超と報じられ、
  国内でも2025年に6,000億円規模との推計がある（**定義により数値が大きく割れる**点に注意）
- **Googleアドテク独禁訴訟は分割回避**。2026年9月2日、連邦地裁が司法省の構造的措置3案を却下し、
  入札情報の開示など行動是正措置にとどめたと報じられる。一方で広告運用は**AIエージェント**へ移行中で、
  Metaは2026年末までの全自動化、サイバーエージェントは2026年4月にAI運用エージェントを投入
- **サードパーティCookieの廃止は2025年4月に事実上全面撤回**（Safari・Firefoxは従来どおりブロック）。
  ただし**2026年改正個人情報保護法**は課徴金導入を含み規制自体は強まる方向。
  アドフラウドの推計被害額は2025年に約1,591億円、MFAサイト掲載件数は前年比1,409%（Spider Labs推計）
