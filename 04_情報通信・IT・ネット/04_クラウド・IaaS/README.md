# クラウド・IaaS

- 大分類: 情報通信・IT・ネット
- 状態: done
- 更新日: 2026-09-20

データセンターの上で、計算資源と運用をサービスとして売る産業。
売り物はサーバではなく**「待たなくていい権利」**であり、
粗利の源泉は**稼働率（多数顧客での使い回し）と自社設計ハード**にある。
2026年時点の競争軸は価格ではなく、**いつGPU容量を渡せるか**に移っている。

## 1. 業界の定義・範囲

**クラウド（パブリッククラウド）**＝インターネット越しに、仮想化された計算資源・ストレージ・
ソフトウェア機能を、**必要な分だけ・使った分だけ課金する形**で提供するサービス、およびその事業。

| 区別すべき言葉 | 中身 |
| --- | --- |
| **IaaS** | 仮想サーバ・ストレージ・ネットワークを貸す。**このフォルダの中心** |
| **PaaS** | DB・実行環境など「運用込みの部品」を貸す。**このフォルダの中心** |
| SaaS | 完成した業務ソフトを貸す → [ソフトウェア・SaaS](../06_ソフトウェア・SaaS/README.md) |
| データセンター | 建物・電力・冷却・回線を提供する物理層 → [データセンター](../03_データセンター/README.md) |
| ホスティング | 事業者が用意した物理サーバ自体を貸す（クラウド以前の形態） |
| SI・システム構築 | クラウドへの移行・構築・運用を請け負う → [SIer・ITサービス](../05_SIer・ITサービス/README.md) |

```
  半導体 ─▶ データセンター ─▶ ★クラウド／IaaS★ ─▶ 基盤モデル ─▶ SaaS ─▶ ユーザー企業
  GPU/CPU    電気・冷却・箱      計算資源とAPI       AIモデル     業務ソフト    全産業
     ▲              ▲                  ▲                              ▲
   NVIDIA       電力・建設        3強＋ネオクラウド                 SIerが橋渡し
```

## 2. 市場規模と成長性

| 指標 | 数値 | 時点・出所 |
| --- | --- | --- |
| 世界クラウドインフラ支出 | **1,434億ドル／四半期、前年比約43%増** | 2026年4〜6月期、Synergy Research（推計） |
| AIが占めるクラウド支出比率 | 2023年 約8% → 2026年 約19% | 同（推計） |
| 国内パブリッククラウド市場 | 4兆1,423億円（前年比+26.1%） | 2024年実績、IDC Japan |
| 同 | 4兆4,930億円（前年比+20.3%） | 2025年、IDC Japan（2026年3月発表） |
| 同 2030年予測 | 10兆962億円（CAGR 17.6%） | IDC Japan 予測（推計） |
| 国内クラウド基盤（IaaS/PaaS） | 2兆7,100億円（前年比118.9%） | 2025年、矢野経済研究所（推計） |
| AWS四半期売上 | 422億ドル（前年比+36.7%）、営業利益率39% | 2026年4〜6月期、Amazon IR |

- 2022〜2023年の支出抑制局面は終わり、生成AIが成長を押し上げている
- **成長の制約は需要ではなく供給**（GPU、電力、用地）。予測は「建てられる前提」で作られている
- 「クラウド市場」の数字は定義（IaaSのみか、SaaS込みか）で桁が変わる。単独の数字を根拠にしない

## 3. バリューチェーン（川上 → 川下）

```
① チップ ─▶ ② DC（箱と電気）─▶ ③ クラウド事業者 ─▶ ④ SI・MSP ─▶ ⑤ 利用企業
 NVIDIA      ゼネコン・電力        AWS/Azure/GCP      SIer/代理店      全産業
 自社設計チップ  DC事業者          ネオクラウド        FinOps支援

  ◀────────── お金はこの向きに流れる（利用企業 → チップ） ──────────
```

| 工程 | 担い手 | どこに価値が集まるか |
| --- | --- | --- |
| ① チップ | NVIDIA、TSMC、各社の自社設計チップ | **最も強い交渉力**。GPUの価格決定権を握る |
| ② データセンター | DC事業者、電力、ゼネコン | 2026年は電力枠が希少資源 → [データセンター](../03_データセンター/README.md) |
| ③ クラウド事業者 | 3強、Oracle、ネオクラウド、国産勢 | **マネージドサービスで最も厚い粗利** |
| ④ SI・リセール・MSP | SIer、クラウド代理店、FinOpsベンダー | 移行需要。人月商売 → [SIer・ITサービス](../05_SIer・ITサービス/README.md) |
| ⑤ 利用企業 | 全産業 | 便益を受ける側。支出の29%が無駄とされる（2026年推計） |

> IaaS単体は値下げ圧力が強く薄利。
> **利益はPaaS＝マネージドサービスの層で作られる**というのが、この産業の最大の要点。

## 4. 主要プレイヤーとシェア

| 企業 | 立ち位置 | 特徴 |
| --- | --- | --- |
| **AWS**（Amazon） | 世界シェア28%（2026年Q2、推計） | 2006年開始の先行者。サービス数最多。Amazon営業利益の約74%を稼ぐ |
| **Microsoft Azure** | 世界シェア20%（同） | Windows／Officeの企業契約に抱き合わせて拡大。商用RPO 6,780億ドル |
| **Google Cloud** | 世界シェア15%（同） | 成長率約82%と突出。データ分析とTPUが武器 |
| **Oracle（OCI）** | 後発だがAI大型契約で急拡大 | RPO 約6,640億ドル（2026年8月末）。OpenAI依存が論点 |
| **Alibaba Cloud** | 中国最大 | AI関連が12四半期連続3桁成長。3年3,800億元の投資計画 |
| **CoreWeave、Nebius 等** | GPU特化のネオクラウド | 高成長・高リスク。原価をNVIDIAに握られる |
| **さくらインターネット** | 国産IaaSの代表格 | 2026年3月にガバメントクラウド正式採択 |
| NTT、富士通、NEC、IIJ 等 | 国内の企業向け・官公需 | ハイブリッド構成と運用受託が主戦場 |
| KDDI、ソフトバンク | 通信網と組み合わせた提供 | AI向けDC投資も → [通信キャリア](../01_通信キャリア/README.md) |

**シェアの見方**：売上シェアは3強で6割超だが、市場全体が年4割伸びているため
**順位よりも成長率の差**を見たほうが構造変化が分かる。詳細は [03_競争構造](03_競争構造.md)。

## 5. 収益モデル・コスト構造

| 収益モデル | 課金の単位 | 特徴 |
| --- | --- | --- |
| 従量課金（オンデマンド） | 秒・GB・リクエスト | 入口。単価は最も高い |
| コミット割引（RI／Savings Plans） | 1〜3年の利用約束 | 20〜70%割引。事業者は受注残に変換できる |
| 企業割引契約（EDP等） | 数年の総額コミット | 総額の囲い込み |
| データ転送料（エグレス） | GB単位 | 粗利が厚く、乗り換え抑止にも働く |
| マネージドサービス | 機能単位 | **粗利の中心**。運用を肩代わりする対価 |
| マーケットプレイス | 取引手数料 | 他社ソフトの流通で手数料を取る |

**コスト構造の核心**：

- **サーバ・GPUの減価償却が最大費目**（目安4〜5割）。**耐用年数の前提で利益率が数ポイント動く**
- 多数顧客で1台を共有する**マルチテナンシー**により稼働率を上げるのが粗利の源泉
- **自社設計チップ**（Graviton、Trainium、TPU等）でNVIDIA・Intelへのマージンを外す
- 人件費の比重が小さく、売上が伸びても人が比例して増えない（SIerとの決定的な違い）
- 詳しくは [02_儲け方と経済性](02_儲け方と経済性.md)

## 6. 競争要因（KSF）と参入障壁

| 要因 | 中身 | 障壁の高さ |
| --- | --- | --- |
| **容量（電力・GPU）の確保** | いつ顧客に渡せるか | **2026年時点で最も高い**。事実上の成長率上限 |
| 資本 | 年間1,000億ドル超の設備投資 | 非常に高い |
| サービス数・エコシステム | 数百のマネージドサービス | 高い。ただしAI用途では効きにくい |
| 自社設計チップ | 原価を下げる能力 | 高い。開発費を回収できる規模が要る |
| 既存の顧客基盤 | ライセンス契約・DB顧客から入る | 高い（AzureとOracleの勝ち筋） |
| ロックイン | エグレス料＋固有API | 中〜高。EU規制で転送料側は弱まる |
| 制度・主権要件 | 政府調達、データ主権 | **制度が国内勢に市場を作る** |

> 総合クラウドとして3強に正面から挑むのは事実上不可能に近い。
> 崩しうるのは**①用途を絞る（GPU専業）②制度で守られた領域に立つ③電力を先に押さえる**の3つ。

## 7. 規制・法制度

| 領域 | 内容 |
| --- | --- |
| **EU Data Act** | 2024年1月11日からスイッチング料金を実費に制限、**2027年1月12日から全面禁止**。乗り換え時のエグレス料が対象で、日常運用の転送料は対象外 |
| EU DMA（デジタル市場法） | ゲートキーパー規制。クラウドの抱き合わせ・ライセンス条件が論点 |
| **ガバメントクラウド** | デジタル庁が整備。20の基幹業務、1,700超の自治体が対象。2026年4月時点でAWS／Azure／Google Cloud／OCI＋さくらのクラウド |
| 政府調達・ISMAP | 政府情報システムのセキュリティ評価登録制度。登録がないと官公需に入れない |
| 経済安全保障推進法 | 重要インフラの供給網。国内保管・ソブリンクラウドの議論 |
| 米CLOUD Act | 米国事業者に国外保管データの開示を求めうる。**国内リージョンでも主権が完結しない**根拠 |
| 補助金・政策 | 経産省が5年で1兆円超の国内AI・クラウド基盤支援を打ち出したと報じられる（2026年） |
| 個人情報保護法 | 越境移転の規律。クラウド利用時の「委託」の整理 |

## 8. 最近のトピック

→ 詳細と出典URLは [04_直近トピック_2026](04_直近トピック_2026.md)

1. **市場が再加速**。世界の四半期支出1,434億ドル・前年比約43%増で8年ぶりの伸び（2026年Q2、Synergy推計）
2. **受注残が兆ドル規模へ**。Microsoft 6,780億／Oracle 6,640億／Google Cloud 5,140億／AWS 4,960億ドル。
   ただしOracleはOpenAI集中を理由に格下げされたと報じられる
3. **設備投資が桁を変えた**。Amazon 約2,200億ドル、Alphabet 1,950〜2,050億ドル、Microsoft 約1,750億ドル（2026年計画）
4. **日本ではさくらインターネットがガバメントクラウドに正式採択**（2026年3月27日）。国産初の本番環境提供
5. **EU Data Actで乗り換え料金が2027年1月12日から禁止**。ただし本丸のAPI依存は残る
6. **クラウド支出の29%が無駄**と推計され、5年ぶりに悪化。原因はAI関連資源の止め忘れ（2026年、Flexera推計）
