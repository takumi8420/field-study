## 1. 市場が再加速 ── 四半期1,434億ドル、8年ぶりの伸び

| 指標 | 数値 | 時点・出所 |
| --- | --- | --- |
| 世界クラウドインフラ支出 | **1,434億ドル／四半期、前年比約43%増** | 2026年4〜6月期、Synergy Research（推計） |
| シェア | AWS 28%／Azure 20%／Google Cloud 15% | 同上 |
| 前四半期のシェア | AWS 28%／Azure 21%／Google Cloud 14% | 2026年1〜3月期、同 |
| 各社成長率 | AWS 約37%／Azure 約43%／Google Cloud 約82% | 2026年4〜6月期、IR・推計 |
| AIが占めるクラウド支出比率 | 2023年 約8% → 2026年 **約19%** | 同（推計） |

**何が起きているか**：2022〜2023年の「クラウド最適化（＝支出抑制）」局面が終わり、
生成AIの学習・推論需要が上乗せされて伸びが跳ねた。
特筆すべきはGoogle Cloudの約82%で、AI案件の獲得がシェア順位に影響し始めている。

シェアの絶対値は横ばいに見えるが、**市場全体が43%伸びている中での横ばい**なので、
3社とも金額では大きく増えている。順位の議論より成長率の差を見るべき局面である。

## 3. 設備投資が桁を変えた ── 「利益率は高いが現金は出ていく」

| 企業 | 2026年通期の設備投資（会社計画・報道） |
| --- | --- |
| Amazon | 約2,200億ドル |
| Alphabet | 1,950〜2,050億ドル |
| Microsoft | 約1,750億ドル（データセンター資産の想定耐用年数を延ばしたと報じられる） |
| Meta（参考） | 1,300〜1,450億ドル |
| CoreWeave | 350〜390億ドル |
| Alibaba | 3年で3,800億元の計画。2026年6月までに累計1,900億元を投下、上振れの可能性に言及 |

四半期のハイパースケーラー合計設備投資は1,120億ドルに達したとされる（2026年1〜3月期、集計ベース）。

**論点**：AWSの営業利益率は39%（2026年4〜6月期）と高いが、
同時に全社で年2,200億ドルを投じている。
**会計上の利益と手元現金は別物**であり、このギャップを埋めているのが第2節の受注残である。
投資の回収が進まなければ、耐用年数の前提変更で利益を作っているのではないかという批判に晒される。

```
  日本国内に建つもの            日本に落ちる価値
 ┌──────────────────┐        ┌──────────────────────┐
 │ 土地・建物        │──────▶│ 建設・電気工事の受注    │
 │ 受変電設備・電力   │──────▶│ 電力会社の販売収入      │
```

## 5. ガバメントクラウド ── さくらインターネットが正式採択に

2026年3月27日、さくらインターネットはデジタル庁のガバメントクラウド提供事業者として
**正式に採択された**と発表した（同社リリース）。
2023年11月の条件付き採択から約2年半、2025年度末までに全技術要件を満たすことが条件だった。

| 論点 | 内容 |
| --- | --- |
| 対象サービス（2026年4月時点） | AWS、Microsoft Azure、Google Cloud、Oracle Cloud Infrastructure、**さくらのクラウド** |
| 意味 | 国産事業者として初めて本番環境を提供できる位置に立った |
| 移行の実態 | 自治体の移行完了は進捗が限定的で、コストが想定より増えた事例も報じられている（報道ベース） |
| 対象範囲 | 住民記録・地方税など20の基幹業務、1,700超の自治体 |

**評価の分かれ目**：技術要件を満たしたことと、価格・サービス数で外資と競えることは別問題である。
自治体が実際にどれだけ「さくらのクラウド」を選ぶかは2026年度以降の数字を見る必要がある。

## 6. GPUクラウド（ネオクラウド）が第2の柱に

| 事業者 | 2026年4〜6月期の数字 | 出所 |
| --- | --- | --- |
| CoreWeave | 売上 約25.8億ドル（前年比+112%）、受注残 約1,040億ドル、通期売上見通し124〜132億ドル | 同社IR |
| Nebius | 売上 5.82億ドル（前年比+454%）、顧客コミット400億ドル超 | 同社IR |

両社とも**売上は爆発的に伸びる一方、設備投資の先行で損失が拡大している**とされる。
GPUの購入を借入・社債で賄うため、金利環境と株価評価に極端に敏感な財務構造になっている。

また、GPUメーカーが顧客企業に出資し、その企業がGPUを買うという資金の循環について、
「循環取引ではないか」という指摘が2026年を通じて繰り返し報じられている。
**この論点が投資家心理を動かす主因**になっており、業界動向を読むうえで外せない。

## 7. 規制 ── EU Data Actでスイッチング料金が2027年1月に禁止へ

| 時期 | 内容 |
| --- | --- |
| 2024年1月11日〜 | 乗り換え支援料・エグレス料は「実費」まで、と上限規制 |
| 2024年 | AWS、Google Cloud、Microsoft が全面撤退時のデータ転送無償化を相次いで発表（条件・除外あり） |
| **2027年1月12日〜** | **スイッチング料金の徴収を全面禁止** |

**誤解されやすい点**：禁止されるのは**乗り換えに伴う**エグレスであって、
日常運用のエグレス（エンドユーザーへの配信、リージョン間複製など）は引き続き有料。
また、本質的なロックインは転送料ではなく**マネージドサービス固有のAPIへの依存**なので、
規制が効いても移行コストがゼロになるわけではない。

## 8. FinOps ── AIで「無駄」が5年ぶりに増加

| 指標 | 数値 | 時点・出所 |
| --- | --- | --- |
| 無駄になっているクラウド支出 | **29%**（前年27%） | 2026年、Flexera State of the Cloud（推計） |
| AI支出を管理する実務者の割合 | 2024年31% → 2025年63% → **2026年98%** | FinOps Foundation「State of FinOps 2026」 |
| 調査規模 | 実務者1,192名、年間クラウド支出830億ドル超 | 同上 |
| 自動最適化まで到達した組織 | 約14%（半数超は「手動で最適化」段階） | 同上（推計） |

**なぜ悪化したのか**：GPUクラスタや実験中の推論エンドポイントが、
タグ付け・予測・停止の運用が追いつかない速度で立ち上がるため。
5年続いた改善トレンドがAIで反転した、という点が2026年の象徴的な出来事である。

FinOps Foundationは同年、ミッションの対象を「クラウドの価値」から
「**テクノロジーの価値**」へ広げたとされ、SaaSやライセンスも含む支出管理へ職能が拡張している
（→ [02_儲け方と経済性](02_儲け方と経済性.md) の第9節）。

## 9. ハイブリッドへの揺り戻し ── 「クラウド撤退」ではなく「置き場所の最適化」

IDCの調査では、2025年時点でCIOの**86%**が一部ワークロードの自社設備への差し戻し
（クラウドリパトリエーション）を計画する一方、**完全撤退の計画は約8%**にとどまるとされる（報道ベース）。

国内上場企業向け調査でも、マルチクラウド運用の課題の上位は
「セキュリティ・ID管理」「ガバナンスとポリシー管理」「コストの可視化と最適化」で、
**動かす技術より統制**が問題になっている（2026年、調査ベース）。

> つまり「クラウドは終わった」ではない。
> 負荷が一定で読めるものは自社に、変動するもの・AIのように最新ハードが要るものはクラウドに、
> という**使い分けが定着した**と読むのが正確。

## 10. 全体の構図（まとめ）

1. **市場は再加速し、AIが成長の主因**になった（AI関連が支出の約19%、2026年推計）。3強で6割超は変わらない
2. **競争軸が価格から容量へ移った**。値下げ競争のループは半導体の減速と電力制約で鈍り、
   「いつGPUを渡せるか」が勝負になった
3. **受注残が兆ドル規模へ膨らんだ**が、顧客集中（とくにOracle）という新しいリスクを抱えた
4. **利益率は高いのに現金は出ていく**。設備投資が桁を変え、耐用年数の前提が利益を左右している
5. **日本は需要も投資も伸びるが、主体は外資**。ガバメントクラウドで国産が土俵に上がったのが2026年の変化
6. **規制はロックインを緩める方向**（EU Data Act、2027年1月）。ただし本丸のAPI依存は残る

## 用語メモ

| 用語 | 意味 |
| --- | --- |
| **RPO（残存履行義務）** | 契約済みで未計上の売上。受注残に相当する会計用語 |
| **backlog** | 受注残。RPOとほぼ同義で使われる |
| **capex（設備投資）** | データセンター・サーバ・チップへの投資額 |
| **ネオクラウド** | AI向けGPU提供に特化した新興クラウド事業者 |
| **循環取引の懸念** | チップメーカーが顧客に出資し、その資金でチップが買われる構図への指摘 |
| **ガバメントクラウド** | デジタル庁が整備する国・自治体共通のクラウド基盤 |
| **EU Data Act** | EUのデータ法。2027年1月12日からスイッチング料金を禁止 |
| **クラウドリパトリエーション** | クラウドから自社設備へワークロードを戻すこと |
| **State of FinOps** | FinOps Foundationによる年次の実務者調査 |
