1. 業界の定義・範囲

クラウド（パブリッククラウド）＝インターネット越しに、仮想化された計算資源・ストレージ・
ソフトウェア機能を、必要な分だけ・使った分だけ課金する形で提供するサービス、およびその事業。

区別すべき言葉 中身
IaaS仮想サーバ・ストレージ・ネットワークを貸す。このフォルダの中心
PaaSDB・実行環境など「運用込みの部品」を貸す。このフォルダの中心
SaaS完成した業務ソフトを貸す → ソフトウェア・SaaS
データセンター建物・電力・冷却・回線を提供する物理層 → データセンター
ホスティング事業者が用意した物理サーバ自体を貸す（クラウド以前の形態）
SI・システム構築クラウドへの移行・構築・運用を請け負う → SIer・ITサービス

指標 数値 時点・出所

AIが占めるクラウド支出比率2023年 約8% → 2026年 約19%同（推計）
国内パブリッククラウド市場4兆1,423億円（前年比+26.1%）2024年実績、IDC Japan

  • 「クラウド市場」の数字は定義（IaaSのみか、SaaS込みか）で桁が変わる。単独の数字を根拠にしない

4. 主要プレイヤーとシェア

企業 立ち位置 特徴
AWS（Amazon）世界シェア28%（2026年Q2、推計）2006年開始の先行者。サービス数最多。Amazon営業利益の約74%を稼ぐ
Microsoft Azure世界シェア20%（同）Windows／Officeの企業契約に抱き合わせて拡大。商用RPO 6,780億ドル
Google Cloud世界シェア15%（同）成長率約82%と突出。データ分析とTPUが武器
Oracle（OCI）後発だがAI大型契約で急拡大RPO 約6,640億ドル（2026年8月末）。OpenAI依存が論点
Alibaba Cloud中国最大AI関連が12四半期連続3桁成長。3年3,800億元の投資計画
CoreWeave、Nebius 等GPU特化のネオクラウド高成長・高リスク。原価をNVIDIAに握られる
さくらインターネット国産IaaSの代表格2026年3月にガバメントクラウド正式採択
NTT、富士通、NEC、IIJ 等国内の企業向け・官公需ハイブリッド構成と運用受託が主戦場
KDDI、ソフトバンク通信網と組み合わせた提供AI向けDC投資も → 通信キャリア

シェアの見方：売上シェアは3強で6割超だが、市場全体が年4割伸びているため
順位よりも成長率の差を見たほうが構造変化が分かる。詳細は 03_競争構造。

5. 収益モデル・コスト構造

収益モデル 課金の単位 特徴
従量課金（オンデマンド）秒・GB・リクエスト入口。単価は最も高い
コミット割引（RI／Savings Plans）1〜3年の利用約束20〜70%割引。事業者は受注残に変換できる
企業割引契約（EDP等）数年の総額コミット総額の囲い込み
データ転送料（エグレス）GB単位粗利が厚く、乗り換え抑止にも働く
マネージドサービス機能単位粗利の中心。運用を肩代わりする対価
マーケットプレイス取引手数料他社ソフトの流通で手数料を取る

コスト構造の核心：

  • サーバ・GPUの減価償却が最大費目（目安4〜5割）。耐用年数の前提で利益率が数ポイント動く
  • 多数顧客で1台を共有するマルチテナンシーにより稼働率を上げるのが粗利の源泉
  • 自社設計チップ（Graviton、Trainium、TPU等）でNVIDIA・Intelへのマージンを外す
  • 人件費の比重が小さく、売上が伸びても人が比例して増えない（SIerとの決定的な違い）
  • 詳しくは 02_儲け方と経済性

6. 競争要因（KSF）と参入障壁

要因 中身 障壁の高さ
容量（電力・GPU）の確保いつ顧客に渡せるか2026年時点で最も高い。事実上の成長率上限
資本年間1,000億ドル超の設備投資非常に高い
サービス数・エコシステム数百のマネージドサービス高い。ただしAI用途では効きにくい
自社設計チップ原価を下げる能力高い。開発費を回収できる規模が要る
既存の顧客基盤ライセンス契約・DB顧客から入る高い（AzureとOracleの勝ち筋）
ロックインエグレス料＋固有API中〜高。EU規制で転送料側は弱まる
制度・主権要件政府調達、データ主権制度が国内勢に市場を作る

総合クラウドとして3強に正面から挑むのは事実上不可能に近い。
崩しうるのは①用途を絞る（GPU専業）②制度で守られた領域に立つ③電力を先に押さえるの3つ。

7. 規制・法制度

領域 内容
EU Data Act2024年1月11日からスイッチング料金を実費に制限、2027年1月12日から全面禁止。乗り換え時のエグレス料が対象で、日常運用の転送料は対象外
EU DMA（デジタル市場法）ゲートキーパー規制。クラウドの抱き合わせ・ライセンス条件が論点
ガバメントクラウドデジタル庁が整備。20の基幹業務、1,700超の自治体が対象。2026年4月時点でAWS／Azure／Google Cloud／OCI＋さくらのクラウド
政府調達・ISMAP政府情報システムのセキュリティ評価登録制度。登録がないと官公需に入れない
経済安全保障推進法重要インフラの供給網。国内保管・ソブリンクラウドの議論
米CLOUD Act米国事業者に国外保管データの開示を求めうる。国内リージョンでも主権が完結しない根拠
補助金・政策経産省が5年で1兆円超の国内AI・クラウド基盤支援を打ち出したと報じられる（2026年）
個人情報保護法越境移転の規律。クラウド利用時の「委託」の整理
