# 業界地図ノート

業界地図に載っている各業界の「常識」を、1業界1フォルダで貯めていく学習用リポジトリ。
Markdown で書いて、静的 HTML に変換してブラウザで読む。

## 構成

```
.
├── index.html              ← 入口（全業界の一覧・進捗・検索）
├── assets/                 ← 共通CSS / JS / 検索インデックス（自動生成）
├── tools/
│   ├── industries.tsv      ← 業界マスタ（大分類 TAB 業界名）
│   ├── build_tree.py       ← TSV からフォルダと README 雛形を作る
│   ├── build_site.py       ← *.md → *.html に変換してサイトを生成
│   ├── check_links.py      ← リンク切れ・体裁チェック
│   └── mdlite.py           ← 依存ゼロの Markdown レンダラ
└── NN_大分類/
    ├── index.html          ← 大分類のトップ（自動生成）
    └── NN_業界名/
        ├── README.md       ← その業界の概要ノート（手で書く）
        ├── NN_〇〇.md      ← 掘り下げノート（任意の数だけ追加可）
        └── *.html          ← 自動生成（直接編集しない）
```

## 使い方

1. ノートを書く: `NN_大分類/NN_業界名/README.md` を編集。深掘りは同じフォルダに `02_〇〇.md` のように足す
2. 学習が済んだら README の `- 状態: todo` を `done` に変える（一覧の進捗に反映される）
3. 変換する:

```bash
python3 tools/build_site.py
```

4. 読む: `index.html` をブラウザで開く。ローカルサーバー経由でも可

```bash
python3 -m http.server 8765
```

## 業界を追加したいとき

`tools/industries.tsv` に `大分類<TAB>業界名` を追記してから:

```bash
python3 tools/build_tree.py && python3 tools/build_site.py
```

`build_tree.py` は既存の README を上書きしない。

## 業界を深掘りするとき

`.claude/skills/industry-deep-dive/` に深掘り用のスキルを置いてある。
Claude Code で「○○業界を深掘りして」と言えば起動する（明示起動は `/industry-deep-dive`）。

- 業界タイプ別（製造／金融／小売／インフラ…）の分解の型
- 執筆の作法と品質チェックリスト
- 調査手順と定番の統計・情報源
- 生成と検証の手順
- 実例（半導体10本立て）

## サイトの機能

- 右上の検索（`/` キー）で全235業界をどのページからでも絞り込み
- 左サイドバーに大分類ツリー、右に見出し目次（スクロール追従）
- 記事下部に前後ノートへのページ送り
- ライト / ダークテーマ切替（右上のボタン、設定は localStorage に保存）
- 各教材ページの末尾に、市場・業界構造・収益モデル・競争・規制などを自分の言葉で説明する理解度クイズを自動生成。回答観点との照合、復習対象だけの再挑戦、端末内の最高得点記録に対応

## Markdown の補助記法

- `[[シリコンサイクルとは何か]]` のように二重角括弧で囲むと、重要な学習用語をチップ表示にできる
- `[[シリコンサイクルとは何か|需要と供給が数年単位で循環する現象]]` のように `|` の後へ説明を書くと、ホバー・キーボードフォーカス・タップで説明を表示できる
- `用語 | 意味` または `用語 | 説明` で始まる用語集テーブルは、1列目が自動的に説明付きチップになるため、個別に記法を追加する必要はない
- 各ページ上部には、そのページの用語集テーブル・定義付き箇条書き・用語メモから集めた「このページの単語集」が自動生成される。別ページに同じ用語の説明があれば共通辞書から補完する
- 通常の強調には従来どおり `**太字**` を使う。説明文までチップ化しないよう、短い用語や問いに限って使う
